## 题目描述

表 `logs`：

```
+-----------+---------+
| Column Name| Type   |
+-----------+---------+
| log_id    | int     |
| ip        | varchar |
+-----------+---------+
```

`log_id` 是主键。

找出所有**无效的 IPv4 地址**。有效的 IPv4 地址格式：`a.b.c.d`，其中 a, b, c, d 是 0-255 的整数（无前导零，除非本身就是 0）。

返回所有包含无效 IP 地址的记录，按 `log_id` 升序排列。

**示例：**

输入：
```
+--------+-----------------+
| log_id | ip              |
+--------+-----------------+
| 1      | 192.168.1.1     |
| 2      | 256.1.2.3       |
| 3      | 192.168.01.1    |
| 4      | 192.168.1       |
+--------+-----------------+
```

输出：
```
+--------+-----------------+
| log_id | ip              |
+--------+-----------------+
| 2      | 256.1.2.3       |
| 3      | 192.168.01.1    |
| 4      | 192.168.1       |
+--------+-----------------+
```

## 解题思路

验证 IPv4 地址的规则：
1. 恰好包含 3 个点（分为 4 段）
2. 每段是 0-255 的整数
3. 每段无前导零（除非该段就是 "0"）

使用正则表达式验证，取反得到无效地址。

## SQL 代码实现

### 方法一：REGEXP 验证（推荐）

```sql
SELECT log_id, ip
FROM logs
WHERE ip NOT REGEXP '^(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])\\.(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])\\.(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])\\.(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])$'
ORDER BY log_id;
```

### 方法二：分段验证（更易读）

```sql
WITH parsed AS (
    SELECT
        log_id,
        ip,
        SUBSTRING_INDEX(ip, '.', 1) AS seg1,
        SUBSTRING_INDEX(SUBSTRING_INDEX(ip, '.', 2), '.', -1) AS seg2,
        SUBSTRING_INDEX(SUBSTRING_INDEX(ip, '.', 3), '.', -1) AS seg3,
        SUBSTRING_INDEX(ip, '.', -1) AS seg4,
        -- 点的数量
        LENGTH(ip) - LENGTH(REPLACE(ip, '.', '')) AS dot_count
    FROM logs
),
validated AS (
    SELECT
        log_id, ip,
        CASE
            WHEN dot_count != 3 THEN 0  -- 不是 4 段
            WHEN seg1 REGEXP '^(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])$'
             AND seg2 REGEXP '^(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])$'
             AND seg3 REGEXP '^(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])$'
             AND seg4 REGEXP '^(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])$'
            THEN 1
            ELSE 0
        END AS is_valid
    FROM parsed
)
SELECT log_id, ip
FROM validated
WHERE is_valid = 0
ORDER BY log_id;
```

### 方法三：简单正则

```sql
SELECT log_id, ip
FROM logs
WHERE NOT (
    ip REGEXP '^([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\\.([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\\.([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\\.([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])$'
)
ORDER BY log_id;
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为行数，L 为 IP 平均长度
- 空间复杂度：O(1)

## 关键点总结

1. IPv4 每段范围：0-255，无前导零
2. 正则模式：`(25[0-5]|2[0-4][0-9]|1[0-9]{2}|[1-9][0-9]|[0-9])` 精确匹配 0-255
3. 要求取反：找无效地址，所以用 `NOT REGEXP`

## 易错点

1. `[0-9]{1,3}` 不够精确（会匹配 999），需要区间判断
2. 前导零：`01` 无效，正则中 `[0-9]` 只匹配单个数字（无前导零）
3. 需要锚定 `^` 和 `$`，防止部分匹配
