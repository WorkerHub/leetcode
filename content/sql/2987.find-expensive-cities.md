## 题目描述

本题为数据库题目。

给定表 `Listings`：
```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| listing_id  | int      |
| city        | varchar  |
| price       | int      |
+-------------+----------+
```

找出平均挂牌价格高于全部挂牌价格平均值的城市，按城市名升序返回。

## SQL 代码实现

### 方法一：子查询（推荐）

```sql
SELECT city
FROM Listings
GROUP BY city
HAVING AVG(price) > (SELECT AVG(price) FROM Listings)
ORDER BY city;
```

### 方法二：使用 CTE

```sql
WITH global_avg AS (
    SELECT AVG(price) AS avg_price FROM Listings
),
city_avg AS (
    SELECT city, AVG(price) AS avg_price FROM Listings GROUP BY city
)
SELECT ca.city
FROM city_avg ca, global_avg ga
WHERE ca.avg_price > ga.avg_price
ORDER BY ca.city;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为城市数

## 关键点总结

1. 先计算全局平均价格
2. 按城市分组计算各城市平均价格
3. HAVING 子句过滤高于全局均价的城市

## 易错点

1. HAVING 中的比较是城市平均价格 vs 全局平均价格
2. 结果按城市名字母升序
