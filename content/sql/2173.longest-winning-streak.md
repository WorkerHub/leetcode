## 题目描述

表 `Matches`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| player_id   | int  |
| match_day   | date |
| result      | enum |
+-------------+------+
```

`(player_id, match_day)` 是主键，`result` 为 `Win`、`Draw` 或 `Lose`。

返回每个玩家的**最长连胜**场数。若某玩家从未获胜，则最长连胜为 0。

**示例：**
```
输入：
Matches:
+-----------+------------+--------+
| player_id | match_day  | result |
+-----------+------------+--------+
| 1         | 2022-01-17 | Win    |
| 1         | 2022-01-18 | Win    |
| 1         | 2022-01-25 | Win    |
| 1         | 2022-01-31 | Draw   |
| 1         | 2022-02-08 | Win    |
+-----------+------------+--------+

输出：
+-----------+----------------+
| player_id | longest_streak |
+-----------+----------------+
| 1         | 3              |
+-----------+----------------+
```

## 解题思路

**经典连续分组问题（差值法）**

对每个玩家按日期排序，标记连续的 Win 序列。

使用差值法（经典 SQL 连续序列分组）：
1. 对每个玩家的每条记录，按日期排序，分配行号 `rn`。
2. 对 Win 的记录，再按日期排序，分配行号 `win_rn`。
3. `rn - win_rn` 相同的 Win 记录属于同一连续组。
4. 统计每组的记录数，取最大值。

## 代码实现

### 方法一：差值法（经典连续分组）

```sql
WITH ranked AS (
    SELECT player_id, match_day, result,
           ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY match_day) AS rn,
           CASE WHEN result = 'Win'
                THEN ROW_NUMBER() OVER (PARTITION BY player_id, result ORDER BY match_day)
                ELSE NULL END AS win_rn
    FROM Matches
),
streaks AS (
    SELECT player_id,
           rn - win_rn AS grp,
           COUNT(*) AS streak_len
    FROM ranked
    WHERE result = 'Win'
    GROUP BY player_id, rn - win_rn
),
max_streaks AS (
    SELECT player_id, MAX(streak_len) AS longest_streak
    FROM streaks
    GROUP BY player_id
)
-- 确保从未胜利的玩家也出现，返回 0
SELECT DISTINCT m.player_id,
       COALESCE(ms.longest_streak, 0) AS longest_streak
FROM Matches m
LEFT JOIN max_streaks ms ON m.player_id = ms.player_id
ORDER BY player_id;
```

### 方法二：使用变量（MySQL 特有）

```sql
WITH ordered AS (
    SELECT player_id, match_day, result,
           ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY match_day) AS rn
    FROM Matches
),
win_ranked AS (
    SELECT player_id, match_day, result, rn,
           ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY match_day) AS overall_rn,
           CASE WHEN result = 'Win'
               THEN ROW_NUMBER() OVER (PARTITION BY player_id, CASE WHEN result='Win' THEN 1 ELSE 0 END ORDER BY match_day)
               ELSE NULL END AS win_seq
    FROM ordered
)
SELECT player_id,
       COALESCE(MAX(CASE WHEN result = 'Win' THEN rn - win_seq END), 0) -- 此处需重新设计
FROM win_ranked
GROUP BY player_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 差值法 | O(n log n) | O(n) |

## 关键点总结

1. 差值法：总行号 - Win 行号 = 相同值 => 同一连续 Win 组。
2. 用 COALESCE 处理从未胜利的玩家（返回 0）。
3. LEFT JOIN 保证所有玩家都出现在结果中。

## 易错点

- 分组时的 `rn - win_rn` 需要注意：两个 ROW_NUMBER 分属不同 PARTITION 时差值方有意义。
- 确保输出包含所有玩家（包括未胜利的），使用 LEFT JOIN 而非 INNER JOIN。
