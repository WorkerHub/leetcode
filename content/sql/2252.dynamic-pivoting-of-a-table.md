## 题目描述

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store       | varchar |
| price       | int     |
+-------------+---------+
(product_id, store) 是该表的主键。
```

编写一个 SQL 解决方案，对 `Products` 表进行**动态行转列**（Pivot），将每个不同的 store 作为列，显示每个产品在每家商店的价格。若某产品在某商店没有价格，则显示为 `null`。

**要求：** 列名应该是所有不同 store 名称，按**字典序排列**，第一列是 `product_id`。

**注意：** 由于商店名称动态变化，此题需要使用动态 SQL（存储过程或拼接 SQL 字符串）。

**示例：**
```
Products 表：
+------------+----------+-------+
| product_id | store    | price |
+------------+----------+-------+
| 1          | Shop     | 110   |
| 1          | LC_Store | 100   |
| 2          | Nozama   | 200   |
| 2          | Souq     | 190   |
| 3          | Shop     | 1000  |
| 3          | Souq     | 1900  |
+------------+----------+-------+

输出（商店按字典序排列）：
+------------+----------+--------+-------+------+
| product_id | LC_Store | Nozama | Shop  | Souq |
+------------+----------+--------+-------+------+
| 1          | 100      | null   | 110   | null |
| 2          | null     | 200    | null  | 190  |
| 3          | null     | null   | 1000  | 1900 |
+------------+----------+--------+-------+------+
```

## 解题思路

动态 Pivot 需要先获取所有不同的 store 名称，然后动态构建 SQL 查询。

**MySQL 方法：** 使用 `GROUP_CONCAT` 拼接列名，然后通过 `PREPARE` 执行动态 SQL。

每列对应一个 `MAX(CASE WHEN store='xxx' THEN price END)` 表达式。

## 代码实现

### 方法一：动态 SQL（MySQL 存储过程）

```sql
CREATE PROCEDURE PivotProducts()
BEGIN
    -- 动态获取所有不同的 store 名称（字典序）
    SET @sql = NULL;

    SELECT GROUP_CONCAT(
        CONCAT('MAX(CASE WHEN store = ''', store, ''' THEN price END) AS `', store, '`')
        ORDER BY store
        SEPARATOR ', '
    ) INTO @sql
    FROM (SELECT DISTINCT store FROM Products) t;

    -- 构建完整 SQL
    SET @sql = CONCAT('SELECT product_id, ', @sql,
                      ' FROM Products GROUP BY product_id ORDER BY product_id');

    -- 执行动态 SQL
    PREPARE stmt FROM @sql;
    EXECUTE stmt;
    DEALLOCATE PREPARE stmt;
END
```

### 方法二：静态 Pivot（如果 store 名称已知）

```sql
-- 如果 store 名称已知，可以直接写静态 PIVOT
SELECT
    product_id,
    MAX(CASE WHEN store = 'LC_Store' THEN price END) AS LC_Store,
    MAX(CASE WHEN store = 'Nozama'   THEN price END) AS Nozama,
    MAX(CASE WHEN store = 'Shop'     THEN price END) AS Shop,
    MAX(CASE WHEN store = 'Souq'     THEN price END) AS Souq
FROM Products
GROUP BY product_id
ORDER BY product_id;
```

## 复杂度分析

- 时间复杂度：O(n * k)，n 为产品数量，k 为商店数量。
- 空间复杂度：O(n * k)，结果矩阵大小。

## 关键点总结

1. 动态 Pivot 的核心是动态生成 `CASE WHEN` 列表。
2. `GROUP_CONCAT` 拼接列表，`PREPARE/EXECUTE` 执行动态 SQL。
3. 静态 Pivot 更直观，但无法处理动态列名。

## 易错点

- `GROUP_CONCAT` 中的字符串引号转义：单引号需要用 `''` 或 `\'` 转义。
- 动态 SQL 中 backtick 用于列名（防止与关键字冲突）。
