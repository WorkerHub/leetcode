## 题目描述

表：`Tree`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| N           | int  |
| P           | int  |
+-------------+------+
```

N 是节点编号，P 是父节点编号（根节点的 P 为 NULL）。

对每个节点分类：
- `Root`：根节点（P 为 NULL）
- `Leaf`：叶节点（不是任何节点的父节点）
- `Inner`：内部节点（既有父节点，又是某些节点的父节点）

## SQL 代码实现

### 方法一：子查询判断（推荐）

```sql
SELECT
    N,
    CASE
        WHEN P IS NULL THEN 'Root'
        WHEN N NOT IN (SELECT P FROM Tree WHERE P IS NOT NULL) THEN 'Leaf'
        ELSE 'Inner'
    END AS Type
FROM Tree
ORDER BY N;
```

### 方法二：LEFT JOIN

```sql
SELECT
    t.N,
    CASE
        WHEN t.P IS NULL THEN 'Root'
        WHEN child.N IS NULL THEN 'Leaf'
        ELSE 'Inner'
    END AS Type
FROM Tree t
LEFT JOIN Tree child ON child.P = t.N
GROUP BY t.N, t.P
ORDER BY t.N;
```

## 复杂度分析

- 时间复杂度：O(n^2)（子查询方法），O(n log n)（JOIN 方法）
- 空间复杂度：O(n)

## 关键点总结

1. 根节点：P 为 NULL
2. 叶节点：N 不出现在任何行的 P 中
3. 内部节点：既有父节点，又是某些节点的父节点

## 易错点

1. 子查询中过滤 `WHERE P IS NOT NULL`，防止把 NULL 误当节点编号
2. 判断是否为叶节点要用 `NOT IN` 或 `LEFT JOIN IS NULL`
