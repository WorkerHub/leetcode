## 题目描述

表：`Drivers`（驾驶员信息，包含 `driver_id` 和 `join_date`）

表：`Rides`（乘车记录，包含 `ride_id`、`user_id` 和 `requested_at`）

表：`AcceptedRides`（接受的行程，包含 `ride_id`、`driver_id`、`ride_distance` 和 `ride_duration`）

查询 2020 年每个季度的：
1. 截至该季度末的活跃驾驶员数（在该季度或之前加入的驾驶员）
2. 该季度接受的行程数
3. 该季度每个活跃驾驶员接受的行程数（若活跃驾驶员数为 0，则为 0）

结果包含 4 行，对应 2020 年的 4 个季度，按季度排序。

## 解题思路

1. 生成 4 个季度（Q1-Q4）的固定行序列
2. 统计每个季度截至季末加入的驾驶员数（活跃驾驶员）
3. 统计每个季度的接受行程数
4. 计算比率（保留两位小数）

## 代码实现

### 方法一：CTE + 子查询（推荐）

```sql
WITH quarters AS (
    SELECT 1 AS q, '2020-01-01' AS q_start, '2020-03-31' AS q_end
    UNION ALL
    SELECT 2, '2020-04-01', '2020-06-30'
    UNION ALL
    SELECT 3, '2020-07-01', '2020-09-30'
    UNION ALL
    SELECT 4, '2020-10-01', '2020-12-31'
),
active_drivers AS (
    SELECT
        qt.q,
        COUNT(d.driver_id) AS active_count
    FROM quarters qt
    LEFT JOIN Drivers d ON d.join_date <= qt.q_end
    GROUP BY qt.q
),
accepted_rides AS (
    SELECT
        QUARTER(r.requested_at) AS q,
        COUNT(ar.ride_id) AS accepted_count
    FROM Rides r
    JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY QUARTER(r.requested_at)
)
SELECT
    ad.q AS quarter,
    ad.active_count AS active_drivers,
    IFNULL(arc.accepted_count, 0) AS accepted_rides,
    IFNULL(ROUND(arc.accepted_count / ad.active_count, 2), 0) AS active_drivers_per_accepted_ride
FROM active_drivers ad
LEFT JOIN accepted_rides arc ON ad.q = arc.q
ORDER BY ad.q;
```

### 方法二：使用 CASE WHEN 处理季度

```sql
WITH quarters AS (
    SELECT 1 AS q UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL SELECT 4
),
driver_by_quarter AS (
    SELECT
        q.q,
        COUNT(d.driver_id) AS active_drivers
    FROM quarters q
    LEFT JOIN Drivers d
        ON YEAR(d.join_date) < 2020
        OR (YEAR(d.join_date) = 2020 AND QUARTER(d.join_date) <= q.q)
    GROUP BY q.q
),
rides_by_quarter AS (
    SELECT
        QUARTER(r.requested_at) AS q,
        COUNT(*) AS accepted_rides
    FROM Rides r
    INNER JOIN AcceptedRides ar USING (ride_id)
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY QUARTER(r.requested_at)
)
SELECT
    d.q AS quarter,
    d.active_drivers,
    IFNULL(r.accepted_rides, 0) AS accepted_rides,
    ROUND(IFNULL(r.accepted_rides, 0) / d.active_drivers, 2) AS active_drivers_per_accepted_ride
FROM driver_by_quarter d
LEFT JOIN rides_by_quarter r ON d.q = r.q
ORDER BY d.q;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| CTE | 清晰分步，先分别计算再合并 |
| CASE WHEN | 灵活处理跨年驾驶员（2020年前加入） |

## 关键点总结

1. 活跃驾驶员：在该季度末之前加入的所有驾驶员
2. 需要处理 2020 年之前就已加入的驾驶员（他们在所有 4 个季度都是活跃的）
3. 若某季度无接受行程，`accepted_count` 应为 0（使用 `IFNULL`）
4. 活跃驾驶员数为 0 时，比率为 0（题目保证每季度至少有驾驶员）

## 易错点

- 活跃驾驶员是**截至当前季度末**，不是当季加入的
- LEFT JOIN 确保没有接受行程的季度也有记录
- 除法时注意分母为 0 的情况（用 `IFNULL` 或 `NULLIF` 处理）
