## 题目描述

表 `Employees`：

| Column Name | Type    |
|-------------|---------|
| employee_id | int     |
| name        | varchar |
| salary      | int     |

`employee_id` 是主键。

编写 SQL 查询，将薪资**相同**的员工分组（每组至少 2 人），并按薪资升序分配组号（薪资最低的是第 1 组，依此类推）。

返回包含 `employee_id`、`name`、`salary`、`team_id` 的结果，按 `employee_id` 升序排列。

**示例：**
```
输入：
+-------------+---------+--------+
| employee_id | name    | salary |
+-------------+---------+--------+
| 2           | Meir    | 3000   |
| 3           | Michael | 3800   |
| 7           | Addilyn | 7400   |
| 8           | Juan    | 3800   |
| 11          | Antonie | 7400   |
+-------------+---------+--------+
输出：
+-------------+---------+--------+---------+
| employee_id | name    | salary | team_id |
+-------------+---------+--------+---------+
| 3           | Michael | 3800   | 1       |
| 7           | Addilyn | 7400   | 2       |
| 8           | Juan    | 3800   | 1       |
| 11          | Antonie | 7400   | 2       |
+-------------+---------+--------+---------+
```
（Meir 薪资 3000 唯一，不分组）

## 解题思路

1. 统计每个薪资的员工数，过滤出员工数 >= 2 的薪资
2. 对这些薪资按升序排列，用 DENSE_RANK() 或 RANK() 分配组号
3. 与原表 JOIN 返回结果

## 代码实现

### 方法一：窗口函数 DENSE_RANK（推荐）

```sql
SELECT e.employee_id, e.name, e.salary,
       DENSE_RANK() OVER (ORDER BY e.salary) AS team_id
FROM Employees e
WHERE e.salary IN (
    SELECT salary
    FROM Employees
    GROUP BY salary
    HAVING COUNT(*) >= 2
)
ORDER BY e.employee_id;
```

### 方法二：子查询 + JOIN

```sql
WITH ValidSalaries AS (
    SELECT salary,
           DENSE_RANK() OVER (ORDER BY salary) AS team_id
    FROM (
        SELECT DISTINCT salary
        FROM Employees
        WHERE salary IN (
            SELECT salary FROM Employees GROUP BY salary HAVING COUNT(*) >= 2
        )
    ) s
)
SELECT e.employee_id, e.name, e.salary, vs.team_id
FROM Employees e
JOIN ValidSalaries vs ON e.salary = vs.salary
ORDER BY e.employee_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和分组
- **空间复杂度**：O(n)

## 关键点总结

1. 先过滤出至少有 2 名员工的薪资
2. 对剩余薪资用 DENSE_RANK() 按升序分配连续组号
3. DENSE_RANK() 保证相同薪资相同组号，且组号连续

## 易错点

- 只有员工数 >= 2 的薪资才参与分组，单独薪资的员工不返回
- 使用 DENSE_RANK 而非 RANK（RANK 会跳过组号）
