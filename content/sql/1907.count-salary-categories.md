## 题目描述

表 `Accounts`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| account_id  | int  |
| income      | int  |
+-------------+------+
account_id 是该表的主键。
每一行包含一个银行账户的月收入。
```

编写一个 SQL 查询，统计各薪资类别的银行账户数量：
- **"Low Salary"**：收入严格少于 $20000
- **"Average Salary"**：收入在 [$20000, $50000] 之间（含端点）
- **"High Salary"**：收入严格大于 $50000

结果必须包含所有三个类别（即使某个类别账户数为 0），可以按任意顺序返回。

**示例：**
```
输入：
Accounts 表:
+------------+--------+
| account_id | income |
+------------+--------+
| 3          | 108939 |
| 2          | 12747  |
| 8          | 87709  |
| 6          | 91796  |
+------------+--------+

输出：
+----------------+----------------+
| category       | accounts_count |
+----------------+----------------+
| Low Salary     | 1              |
| Average Salary | 0              |
| High Salary    | 3              |
+----------------+----------------+
```

---

## 解题思路

### 核心思想：UNION ALL + 条件计数

最直接的方法是用三个独立的 SELECT 语句分别统计三个类别，再用 UNION ALL 合并。

关键点：使用 `COUNT(account_id)` 而非 `COUNT(*)`，两者在此题中结果相同，但语义更精确。也可以使用 `SUM(CASE WHEN ...)` 在单个 SELECT 中统计所有类别。

---

## 代码实现

### 方法一：UNION ALL（推荐，语义清晰）

```sql
-- 分别统计三个薪资类别的账户数
SELECT 'Low Salary' AS category,
       COUNT(*) AS accounts_count
FROM Accounts
WHERE income < 20000

UNION ALL

SELECT 'Average Salary' AS category,
       COUNT(*) AS accounts_count
FROM Accounts
WHERE income >= 20000 AND income <= 50000

UNION ALL

SELECT 'High Salary' AS category,
       COUNT(*) AS accounts_count
FROM Accounts
WHERE income > 50000;
```

### 方法二：CASE WHEN + SUM（单次扫描）

```sql
-- 使用 CASE WHEN 在一次扫描中完成所有分类统计
SELECT 'Low Salary' AS category,
       SUM(CASE WHEN income < 20000 THEN 1 ELSE 0 END) AS accounts_count
FROM Accounts
UNION ALL
SELECT 'Average Salary',
       SUM(CASE WHEN income BETWEEN 20000 AND 50000 THEN 1 ELSE 0 END)
FROM Accounts
UNION ALL
SELECT 'High Salary',
       SUM(CASE WHEN income > 50000 THEN 1 ELSE 0 END)
FROM Accounts;
```

### 方法三：预构造类别表 + LEFT JOIN

```sql
-- 预先构造三行类别表，确保即使某类别为 0 也能出现在结果中
WITH categories AS (
    SELECT 'Low Salary'     AS category, 0       AS low,   19999   AS high
    UNION ALL
    SELECT 'Average Salary' AS category, 20000   AS low,   50000   AS high
    UNION ALL
    SELECT 'High Salary'    AS category, 50001   AS low,   999999  AS high
)
SELECT c.category,
       COUNT(a.account_id) AS accounts_count
FROM categories c
LEFT JOIN Accounts a
    ON a.income BETWEEN c.low AND c.high
GROUP BY c.category;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| UNION ALL | O(n) 扫描三次 | O(1) |
| CASE WHEN + UNION | O(n) 扫描三次 | O(1) |
| 预构造 + LEFT JOIN | O(n) 扫描一次 | O(1) |

---

## 关键点总结

1. UNION ALL 保证即使某类别账户数为 0，该行也会出现（COUNT 返回 0）
2. `income BETWEEN 20000 AND 50000` 等价于 `income >= 20000 AND income <= 50000`（包含端点）
3. 三种方法都能正确处理某类别为 0 的情况（UNION ALL + COUNT 会返回 0，而非缺失该行）

---

## 易错点

- 不要用 GROUP BY income 分组，否则无法保证三个类别都出现
- UNION 会去重，应使用 UNION ALL
- 注意边界值：20000 和 50000 属于 Average Salary
