## 题目描述

表 `NPV`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| year          | int     |
| npv           | int     |
+---------------+---------+
(id, year) 是该表的主键。
该表存储每个 id 和年份对应的 npv 值。
```

表 `Queries`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| year          | int     |
+---------------+---------+
(id, year) 是该表的主键。
该表存储需要查询的 (id, year) 对。
```

写一个 SQL 查询，找出 `Queries` 中每个 `(id, year)` 对应的 `npv` 值。

如果 `NPV` 表中没有对应的记录，`npv` 应该为 `0`。

**结果可以以任意顺序返回。**

**示例：**

```sql
NPV 表：
+------+--------+--------+
| id   | year   | npv    |
+------+--------+--------+
| 1    | 2018   | 100    |
| 7    | 2020   | 30     |
| 13   | 2019   | 40     |
| 1    | 2019   | 113    |
| 2    | 2008   | 121    |
| 3    | 2009   | 12     |
| 11   | 2020   | 99     |
| 7    | 2019   | 0      |
+------+--------+--------+

Queries 表：
+------+--------+
| id   | year   |
+------+--------+
| 1    | 2019   |
| 2    | 2008   |
| 3    | 2009   |
| 7    | 2018   |
| 7    | 2019   |
| 7    | 2020   |
| 13   | 2019   |
+------+--------+

输出：
+------+--------+--------+
| id   | year   | npv    |
+------+--------+--------+
| 1    | 2019   | 113    |
| 2    | 2008   | 121    |
| 3    | 2009   | 12     |
| 7    | 2018   | 0      |
| 7    | 2019   | 0      |
| 7    | 2020   | 30     |
| 13   | 2019   | 40     |
+------+--------+--------+
```

**注意：** `(7, 2018)` 在 NPV 表中不存在，所以 npv 为 0。`(7, 2019)` 在 NPV 表中 npv 为 0。

## 解题思路

### LEFT JOIN + IFNULL/COALESCE

以 `Queries` 表为左表，`LEFT JOIN NPV` 表：

- 匹配到的行，取 NPV 中的 `npv` 值
- 未匹配到的行，`npv` 列为 NULL，用 `IFNULL` 或 `COALESCE` 替换为 0

这是"查询不存在时返回默认值"的经典 SQL 模式。

## SQL 解法

### 方法一：LEFT JOIN + IFNULL（MySQL）

```sql
SELECT
    q.id,
    q.year,
    IFNULL(n.npv, 0) AS npv
FROM Queries q
LEFT JOIN NPV n
    ON q.id = n.id AND q.year = n.year
ORDER BY q.id, q.year;
```

### 方法二：LEFT JOIN + COALESCE（通用 SQL）

```sql
SELECT
    q.id,
    q.year,
    COALESCE(n.npv, 0) AS npv
FROM Queries q
LEFT JOIN NPV n
    ON q.id = n.id AND q.year = n.year;
```

### 方法三：子查询（另一种思路）

```sql
SELECT
    q.id,
    q.year,
    (
        SELECT IFNULL(n.npv, 0)
        FROM NPV n
        WHERE n.id = q.id AND n.year = q.year
        LIMIT 1
    ) AS npv
FROM Queries q;
```

注意：子查询在 NPV 中找不到记录时返回 NULL，`IFNULL(NULL, 0) = 0`，但更简洁的方式是方法一。

## 复杂度分析

| 方法 | 时间复杂度 | 说明 |
|------|-----------|------|
| LEFT JOIN | O(n log n + m log m) | n, m 分别为两表行数，哈希连接 O(n+m) |

## 关键点总结

1. `LEFT JOIN`：以左表（Queries）为基准，右表（NPV）没有匹配时填 NULL
2. `IFNULL(expr, 0)`：MySQL 特有，相当于 `COALESCE(expr, 0)`（标准 SQL）
3. `COALESCE` 可以有多个参数，返回第一个非 NULL 的值，用法更灵活

## 易错点

1. 用 `INNER JOIN` 会丢失 NPV 中不存在的查询行（如 `(7, 2018)`）
2. 注意 ON 条件是两列同时匹配：`ON q.id = n.id AND q.year = n.year`
3. `IFNULL` 是 MySQL 函数，`COALESCE` 是标准 SQL 函数，移植性更好

## 学习建议

- `LEFT JOIN + COALESCE` 是 SQL 中处理"不存在时返回默认值"的标准模式，务必熟记
- 区分 `INNER JOIN`（只返回匹配行）和 `LEFT JOIN`（保留左表所有行）
- `IFNULL` vs `COALESCE`：都能替换 NULL，但 `COALESCE` 支持多个参数，使用更广泛
