## 题目描述

表：`Users`
```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| user_id        | int     |
| name           | varchar |
+----------------+---------+
user_id 是主键
name 只包含小写和大写英文字母
```

修复这张表中名字的格式，使得**只有第一个字符是大写**，其余都是小写。

返回按 `user_id` 排序的结果表。

## 解题思路

MySQL 中：
- `UPPER(str)` 将字符串转为大写
- `LOWER(str)` 将字符串转为小写
- `CONCAT(str1, str2)` 拼接字符串
- `LEFT(str, n)` 取前 n 个字符
- `SUBSTRING(str, pos, len)` 取子串（pos 从 1 开始）

**思路：** 将第一个字符大写，其余部分小写，然后拼接。

## 代码实现

### 方法一：CONCAT + UPPER + LOWER（推荐）

```sql
SELECT
    user_id,
    CONCAT(UPPER(LEFT(name, 1)), LOWER(SUBSTRING(name, 2))) AS name
FROM Users
ORDER BY user_id;
```

### 方法二：使用 SUBSTR 的别名写法

```sql
SELECT
    user_id,
    CONCAT(
        UPPER(SUBSTR(name, 1, 1)),
        LOWER(SUBSTR(name, 2))
    ) AS name
FROM Users
ORDER BY user_id;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| CONCAT + UPPER + LOWER | 标准字符串函数操作，O(n) 行处理 |

## 关键点总结

1. `LEFT(name, 1)` 取第一个字符
2. `SUBSTRING(name, 2)` 取从第 2 个字符开始的所有字符
3. `UPPER(first_char)` 大写首字母，`LOWER(rest)` 小写其余部分
4. `CONCAT(...)` 拼接两部分

## 易错点

- `SUBSTRING(name, 2)` 不指定长度时取到末尾（MySQL 支持此用法）
- `LEFT` 和 `SUBSTRING` 的下标从 1 开始（SQL 字符串下标从 1 起）
- 结果需按 `user_id` 升序排序
