## 题目描述

此题为 LeetCode Premium 题目。

表：`Project`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
+-------------+---------+
(project_id, employee_id) 是这个表的主键。
employee_id 是表 Employee 的外键。
```

表：`Employee`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| experience_years | int     |
+------------------+---------+
employee_id 是这个表的主键。
```

编写一个 SQL 查询，报告每个项目中**工作年限最长**的员工。如果一个项目中有多个工作年限最长的员工，返回所有这些员工。

查询结果格式如下示例所示。

**示例：**

输入：
```
Project 表：
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 2           |
| 1           | 3           |
| 2           | 1           |
| 2           | 4           |
+-------------+-------------+

Employee 表：
+-------------+--------+------------------+
| employee_id | name   | experience_years |
+-------------+--------+------------------+
| 1           | Khaled | 3                |
| 2           | Ali    | 2                |
| 3           | John   | 3                |
| 4           | Doe    | 2                |
+-------------+--------+------------------+
```

输出：
```
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 3           |
| 2           | 1           |
+-------------+-------------+
```

解释：
- 项目 1：员工 1 和 3 都有 3 年经验，是最长的
- 项目 2：员工 1 有 3 年经验，是最长的

## 解题思路

这是一道**窗口函数 + 分组排名**的经典问题。

### 核心思路

1. **关联表**：将 Project 和 Employee 表关联，获取每个项目员工的工作年限
2. **分组排名**：对每个项目内的员工，按工作年限排序
3. **筛选最大值**：选出每个项目中排名第一的员工（可能有多个）

### 方法对比

- **方法一**：窗口函数 RANK() 或 DENSE_RANK()
- **方法二**：子查询，找每个项目的最大工作年限
- **方法三**：相关子查询

## SQL 代码实现

### 方法一：窗口函数 RANK（推荐）

```sql
SELECT 
    project_id, 
    employee_id
FROM (
    SELECT 
        p.project_id,
        p.employee_id,
        e.experience_years,
        RANK() OVER (
            PARTITION BY p.project_id 
            ORDER BY e.experience_years DESC
        ) AS rnk
    FROM 
        Project p
    INNER JOIN 
        Employee e
    ON 
        p.employee_id = e.employee_id
) AS ranked
WHERE 
    rnk = 1;
```

### 方法二：使用 DENSE_RANK（等价）

```sql
SELECT 
    project_id, 
    employee_id
FROM (
    SELECT 
        p.project_id,
        p.employee_id,
        DENSE_RANK() OVER (
            PARTITION BY p.project_id 
            ORDER BY e.experience_years DESC
        ) AS rnk
    FROM 
        Project p
    INNER JOIN 
        Employee e
    ON 
        p.employee_id = e.employee_id
) AS ranked
WHERE 
    rnk = 1;
```

### 方法三：子查询（不使用窗口函数）

```sql
SELECT 
    p.project_id,
    p.employee_id
FROM 
    Project p
INNER JOIN 
    Employee e
ON 
    p.employee_id = e.employee_id
WHERE 
    (p.project_id, e.experience_years) IN (
        SELECT 
            p2.project_id,
            MAX(e2.experience_years)
        FROM 
            Project p2
        INNER JOIN 
            Employee e2
        ON 
            p2.employee_id = e2.employee_id
        GROUP BY 
            p2.project_id
    );
```

### 方法四：使用 ALL（相关子查询）

```sql
SELECT 
    p.project_id,
    p.employee_id
FROM 
    Project p
INNER JOIN 
    Employee e
ON 
    p.employee_id = e.employee_id
WHERE 
    e.experience_years >= ALL (
        SELECT e2.experience_years
        FROM Project p2
        INNER JOIN Employee e2
        ON p2.employee_id = e2.employee_id
        WHERE p2.project_id = p.project_id
    );
```

## 复杂度分析

**SQL 方法一、二（窗口函数）：**
- **时间复杂度**：O(n log n)
  - JOIN：O(n + m)
  - 窗口函数排序：O(n log n)（每个分区内排序）
- **空间复杂度**：O(n)

**SQL 方法三（子查询）：**
- **时间复杂度**：O(n²) 在最坏情况下
  - 外层查询：O(n)
  - 对每条记录，执行子查询：O(n)
- **空间复杂度**：O(n)

**Pandas 方法：**
- **时间复杂度**：O(n log n)
  - merge：O(n + m)
  - groupby + transform/rank：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **窗口函数 PARTITION BY**：按项目分组，在每组内排序
2. **RANK vs DENSE_RANK**：对于此题两者等价，都能正确处理并列
3. **子查询替代**：不支持窗口函数时，可用子查询 + MAX
4. **JOIN 顺序**：先 JOIN 获取完整信息，再排序筛选
5. **处理并列**：必须返回所有最大值，不能用 ROW_NUMBER

## 易错点

1. **使用 ROW_NUMBER**：会随机选择一个并列第一的员工，应该用 RANK 或 DENSE_RANK
2. **忘记 PARTITION BY**：直接 ORDER BY 会全局排序，而不是分组排序
3. **子查询条件**：使用 IN 时要同时匹配 project_id 和 experience_years
4. **Pandas transform**：`transform('max')` 会保持原 DataFrame 的形状，方便筛选
5. **结果排序**：题目可能要求结果有序，注意添加 ORDER BY

## SQL 语法要点

### 窗口函数 PARTITION BY
```sql
-- PARTITION BY 将数据分组，在每组内应用窗口函数
RANK() OVER (PARTITION BY group_column ORDER BY value_column DESC)

-- 示例：每个部门的工资排名
SELECT 
    employee_id,
    department_id,
    salary,
    RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dept_rank
FROM employees;
```

### RANK 函数族对比
```sql
-- 数据：scores = [100, 95, 95, 90]

-- RANK: 1, 2, 2, 4（并列后跳过）
-- DENSE_RANK: 1, 2, 2, 3（并列后不跳过）
-- ROW_NUMBER: 1, 2, 3, 4（强制唯一，随机处理并列）
```

### IN 子查询
```sql
-- 单列 IN
WHERE column IN (SELECT column FROM table)

-- 多列 IN（元组）
WHERE (col1, col2) IN (SELECT col1, col2 FROM table)
```
