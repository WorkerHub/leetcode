## 题目描述

表 `Signups`：
```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| user_id        | int      |
| time_stamp     | datetime |
+----------------+----------+
user_id 是主键。
```

表 `Confirmations`：
```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| user_id        | int      |
| time_stamp     | datetime |
| action         | ENUM     |
+----------------+----------+
(user_id, time_stamp) 是主键。
```

找出在 **24 小时**内请求了**至少两次**确认消息的用户。

返回结果中每个用户只出现一次，可以按任意顺序返回。

---

## 解题思路

### 核心思想：自连接 + 时间差条件

对 `Confirmations` 表做自连接，找同一用户两条记录时间差 ≤ 24 小时。

或者使用窗口函数 `LAG` 找前一条记录的时间，判断差值。

---

## 代码实现

### 方法一：自连接（推荐）

```sql
-- 找同一用户两次确认请求时间差 <= 24小时的用户
SELECT DISTINCT c1.user_id
FROM Confirmations c1
JOIN Confirmations c2
    ON c1.user_id = c2.user_id
    AND c1.time_stamp < c2.time_stamp
    AND TIMESTAMPDIFF(SECOND, c1.time_stamp, c2.time_stamp) <= 86400
ORDER BY c1.user_id;
```

### 方法二：窗口函数 LAG

```sql
-- 使用 LAG 获取同用户上一次请求的时间
SELECT DISTINCT user_id
FROM (
    SELECT
        user_id,
        time_stamp,
        LAG(time_stamp) OVER (PARTITION BY user_id ORDER BY time_stamp) AS prev_ts
    FROM Confirmations
) t
WHERE TIMESTAMPDIFF(SECOND, prev_ts, time_stamp) <= 86400;
```

### 方法三：子查询 EXISTS

```sql
SELECT DISTINCT c1.user_id
FROM Confirmations c1
WHERE EXISTS (
    SELECT 1
    FROM Confirmations c2
    WHERE c2.user_id = c1.user_id
      AND c2.time_stamp > c1.time_stamp
      AND TIMESTAMPDIFF(SECOND, c1.time_stamp, c2.time_stamp) <= 86400
);
```

---

## 复杂度分析

| 方法 | 说明 |
|------|------|
| 自连接 | O(n²) 最坏，n 为 Confirmations 行数 |
| LAG 窗口函数 | O(n log n)（排序） |

---

## 关键点总结

1. 24 小时 = 86400 秒，用 `TIMESTAMPDIFF(SECOND, ...)` 计算时间差
2. 自连接时用 `c1.time_stamp < c2.time_stamp` 避免自比较和重复
3. 使用 `DISTINCT` 确保每个用户只出现一次

---

## 易错点

- `TIMESTAMPDIFF` 参数顺序：`(单位, 早时间, 晚时间)`，结果为正数
- 注意是 ≤ 86400 而不是 < 86400（包含恰好 24 小时）
