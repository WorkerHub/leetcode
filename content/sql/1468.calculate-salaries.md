## 题目描述

表：`Salaries`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| company_id  | int      |
| employee_id | int      |
| employee_name | varchar|
| salary      | int      |
+-------------+----------+
(company_id, employee_id) 是这个表的主键。
```

编写 SQL 语句，根据以下规则，找出每个员工的薪水（税后）：

- 公司最高薪水 **< 1000**：所有员工税率 **0%**（不征税）
- 公司最高薪水在 **[1000, 10000]** 之间：所有员工税率 **24%**
- 公司最高薪水 **> 10000**：所有员工税率 **49%**

返回结果表（每个员工的 `company_id`、`employee_id`、`employee_name` 和税后薪水 `salary`），按任意顺序排列。

**示例：**

`Salaries` 表：
```

| company_id | employee_id | employee_name | salary |

| 1          | 1           | Tony          | 2000   |

| 1          | 3           | Tyrrox        | 10800  |

| 3          | 2           | Ognjen        | 2200   |
| 3          | 13          | Nyancat       | 3300   |

+------------+-------------+---------------+--------+
```

## 解题思路

**步骤：**

1. 用窗口函数 `MAX(salary) OVER(PARTITION BY company_id)` 计算每个公司的最高薪水
2. 根据最高薪水判断税率
3. 计算税后薪水：`FLOOR(salary * (1 - tax_rate))`

**税率判断：**
- max_salary < 1000 → 税率 0，乘以 1.0
- 1000 ≤ max_salary ≤ 10000 → 税率 0.24，乘以 0.76
- max_salary > 10000 → 税率 0.49，乘以 0.51

使用 `CASE WHEN` 语句来实现分段判断。

## SQL 解法

### 方法一：窗口函数 + CASE WHEN（推荐）

```sql
SELECT
    company_id,
    employee_id,
    employee_name,
    -- 根据公司最高薪水计算税后薪水（取整）
    ROUND(
        salary * CASE
            WHEN MAX(salary) OVER (PARTITION BY company_id) < 1000 THEN 1.0
            WHEN MAX(salary) OVER (PARTITION BY company_id) <= 10000 THEN 0.76
            ELSE 0.51
        END
    ) AS salary
FROM Salaries;
```

### 方法二：先计算最高薪水，再 JOIN（更清晰）

```sql
WITH max_salary AS (
    -- 计算每个公司的最高薪水
    SELECT
        company_id,
        MAX(salary) AS max_sal
    FROM Salaries
    GROUP BY company_id
),
tax_rate AS (
    -- 根据最高薪水确定税率
    SELECT
        company_id,
        CASE
            WHEN max_sal < 1000 THEN 1.0
            WHEN max_sal <= 10000 THEN 0.76
            ELSE 0.51
        END AS multiplier
    FROM max_salary
)
SELECT
    s.company_id,
    s.employee_id,
    s.employee_name,
    FLOOR(s.salary * t.multiplier) AS salary
FROM Salaries s
JOIN tax_rate t ON s.company_id = t.company_id;
```

### 方法三：子查询写法

```sql
SELECT
    s.company_id,
    s.employee_id,
    s.employee_name,
    FLOOR(s.salary *
        CASE
            WHEN m.max_sal < 1000 THEN 1.0
            WHEN m.max_sal <= 10000 THEN 0.76
            ELSE 0.51
        END
    ) AS salary
FROM Salaries s
JOIN (
    SELECT company_id, MAX(salary) AS max_sal
    FROM Salaries
    GROUP BY company_id
) m ON s.company_id = m.company_id;
```

## 复杂度分析

- 时间复杂度：O(n)，n 为记录总数
- 空间复杂度：O(n)，中间结果集

## 关键点总结

1. 窗口函数 `MAX() OVER(PARTITION BY company_id)` 在不折叠行的同时计算每组最大值
2. `CASE WHEN` 实现分段逻辑，注意边界值 1000 和 10000 的归属（闭区间）
3. `FLOOR()` 取整（向下取整），`ROUND()` 四舍五入，题目要求保留整数，用 `ROUND` 更符合通常税后薪水的计算

## 易错点

- 边界值：`< 1000`、`BETWEEN 1000 AND 10000`、`> 10000`，注意闭区间
- 题目说"保留整数"，需要使用 `ROUND()` 或 `FLOOR()`；通常税后薪水用 `ROUND` 四舍五入
- 窗口函数方法一中，`MAX()` 被调用两次，可以优化为先计算一次

## 学习建议

1. 窗口函数 `MAX() OVER(PARTITION BY ...)` 是分组计算而不折叠行的利器，务必掌握
2. `CASE WHEN` 是 SQL 的条件判断语句，等价于编程语言中的 `if-elif-else`
3. CTE（`WITH` 子句）将复杂查询分步骤，可读性更好，推荐在多步逻辑查询中使用
