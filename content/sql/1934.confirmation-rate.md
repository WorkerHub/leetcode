## 题目描述

表 `Signups`：
```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| user_id        | int      |
| time_stamp     | datetime |
+----------------+----------+
user_id 是主键。
```

表 `Confirmations`：
```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| user_id        | int      |
| time_stamp     | datetime |
| action         | ENUM     |
+----------------+----------+
(user_id, time_stamp) 是主键。
action 为 'confirmed' 或 'timeout'。
```

用户的**确认率**是 `'confirmed'` 消息数除以请求的确认消息总数。若没有请求过确认消息，确认率为 0。四舍五入保留两位小数。

编写查询，返回每个用户的确认率。可以按任意顺序返回。

---

## 解题思路

### 核心思想：LEFT JOIN + 条件聚合

从 `Signups` 出发 LEFT JOIN `Confirmations`，保留所有注册用户（即使没有确认记录）。

使用 `AVG(action = 'confirmed')` 计算确认率（在 MySQL 中布尔值为 1/0，AVG 即为比例）。

---

## 代码实现

### 方法一：LEFT JOIN + AVG 条件（推荐）

```sql
-- 计算每个用户的确认率（保留两位小数）
SELECT
    s.user_id,
    ROUND(AVG(IF(c.action = 'confirmed', 1, 0)), 2) AS confirmation_rate
FROM Signups s
LEFT JOIN Confirmations c
    ON s.user_id = c.user_id
GROUP BY s.user_id;
```

### 方法二：CASE WHEN + SUM/COUNT

```sql
SELECT
    s.user_id,
    ROUND(
        SUM(CASE WHEN c.action = 'confirmed' THEN 1 ELSE 0 END)
        /
        -- 总请求数，无记录时为 0 则整体为 0（COALESCE 处理 NULL）
        COALESCE(COUNT(c.action), 1),  -- 如果 COUNT = 0 则除以 1 得 0
        2
    ) AS confirmation_rate
FROM Signups s
LEFT JOIN Confirmations c ON s.user_id = c.user_id
GROUP BY s.user_id;
```

### 方法三：子查询

```sql
SELECT
    s.user_id,
    ROUND(
        IFNULL(
            (SELECT COUNT(*) FROM Confirmations c
             WHERE c.user_id = s.user_id AND c.action = 'confirmed')
            /
            NULLIF(
                (SELECT COUNT(*) FROM Confirmations c WHERE c.user_id = s.user_id),
                0
            ),
            0
        ),
        2
    ) AS confirmation_rate
FROM Signups s;
```

---

## 复杂度分析

| 方法 | 说明 |
|------|------|
| LEFT JOIN + AVG | 一次扫描，O(n + m) |
| 子查询 | 每行两次子查询，效率较低 |

---

## 关键点总结

1. `LEFT JOIN` 保留没有确认记录的用户（确认率为 0）
2. `AVG(IF(action = 'confirmed', 1, 0))` 直接计算 confirmed 比例，NULL 自动忽略
3. `ROUND(..., 2)` 保留两位小数

---

## 易错点

- 若某用户没有 Confirmations 记录，`AVG(NULL)` 返回 NULL，`ROUND(NULL, 2)` 返回 NULL，需要用 `COALESCE` 或 `IFNULL` 处理
- 方法一中 `IF(c.action = 'confirmed', 1, 0)` 当 c.action 为 NULL 时返回 0，`AVG` 结果正确
