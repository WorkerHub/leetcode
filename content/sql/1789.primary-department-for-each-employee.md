## 题目描述

表：`Employee`

```
+---------------+---------+
| Column Name   |  Type   |
+---------------+---------+
| employee_id   | int     |
| department_id | int     |
| primary_flag  | varchar |
+---------------+---------+
(employee_id, department_id) 是此表的主键。
primary_flag 是一个枚举类型，值为 ('Y', 'N')。
如果 primary_flag = 'Y'，则该部门是该员工的主要部门。
如果 primary_flag = 'N'，则该部门不是该员工的主要部门。
```

员工可以属于多个部门。当员工加入**其他**部门时，他们需要设定哪个部门是他们的**主要**部门。注意，当员工只加入一个部门时，那这个部门将默认就是他的主要部门，虽然表中 `primary_flag` 为 `'N'`。

查找每个员工的**主要部门**。对于只有一个部门的员工，主要部门即为他们所在的唯一部门。

以**任意顺序**返回结果。

**示例：**
```
输入：
Employee 表：
+-------------+---------------+--------------+
| employee_id | department_id | primary_flag |
+-------------+---------------+--------------+
| 1           | 1             | N            |
| 2           | 1             | Y            |
| 2           | 2             | N            |
| 3           | 3             | N            |
| 4           | 2             | N            |
| 4           | 3             | Y            |
| 4           | 4             | N            |
+-------------+---------------+--------------+

输出：
+-------------+---------------+
| employee_id | department_id |
+-------------+---------------+
| 1           | 1             |
| 2           | 1             |
| 3           | 3             |
| 4           | 3             |
+-------------+---------------+
```

## 解题思路

两种情况：
1. 员工只有一个部门：找出每个员工出现次数为 1 的记录
2. 员工有多个部门：找 `primary_flag = 'Y'` 的记录

用 `UNION` 合并两种情况的结果。

或者用 `HAVING` 子句：对 `primary_flag = 'Y'` 的记录取并集，对只有一个部门的员工（`COUNT = 1`）也取结果。

## 代码实现

### 方法一：UNION（推荐）

```sql
-- 情况1：只有一个部门的员工
SELECT employee_id, department_id
FROM Employee
GROUP BY employee_id
HAVING COUNT(*) = 1

UNION

-- 情况2：有多个部门，取 primary_flag = 'Y' 的部门
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y';
```

### 方法二：条件筛选（利用 primary_flag 和 COUNT）

```sql
SELECT employee_id, department_id
FROM (
    SELECT
        employee_id,
        department_id,
        primary_flag,
        COUNT(*) OVER (PARTITION BY employee_id) AS dept_count
    FROM Employee
) t
WHERE primary_flag = 'Y' OR dept_count = 1;
```

## 复杂度分析

- **时间复杂度**：O(n)，扫描表一次
- **空间复杂度**：O(n)，中间结果

## 关键点总结

1. 处理两种情况：只有一个部门（任何 primary_flag 都视为主要部门）和有多个部门（取 Y）
2. `UNION` 自动去重；`UNION ALL` 保留重复行（此处不需要重复，用 `UNION`）
3. 窗口函数 `COUNT(*) OVER (PARTITION BY employee_id)` 可以在不分组的情况下统计每员工的部门数

## 易错点

1. 当员工只有一个部门时，`primary_flag` 可能为 `'N'`，但仍应返回该部门
2. `UNION` 和 `UNION ALL` 的区别：前者去重，后者不去重
3. 方法二中用窗口函数一次扫描效率更高，避免子查询
