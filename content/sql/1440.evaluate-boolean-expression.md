## 题目描述

表 `Variables`：

| 列名 | 类型 |
|------|------|
| name | varchar |
| value | int |

- `name` 是主键。
- 存储变量名和对应的整数值。

表 `Expressions`：

| 列名 | 类型 |
|------|------|
| left_operand | varchar |
| operator | enum |
| right_operand | varchar |

- `(left_operand, operator, right_operand)` 是主键。
- `operator` 是枚举类型，值为 `'<'`、`'>'`、`'='`。
- 每个操作数都保证在 `Variables` 表中存在。

编写 SQL 查询，计算每个表达式的布尔值（`'true'` 或 `'false'`）。

以任意顺序返回结果表。

**示例：**

Variables 表：
| name | value |
|------|-------|
| x | 66 |
| y | 77 |

Expressions 表：
| left_operand | operator | right_operand |
|--------------|----------|---------------|
| x | > | y |
| x | < | y |
| x | = | y |
| y | > | x |
| y | < | x |
| x | = | x |

输出：
| left_operand | operator | right_operand | value |
|--------------|----------|---------------|-------|
| x | > | y | false |
| x | < | y | true |
| x | = | y | false |
| y | > | x | true |
| y < x | false |
| x | = | x | true |

## 解题思路

**思路：两次 JOIN 获取变量值，再用 CASE WHEN 判断**

1. 将 `Expressions` 表与 `Variables` 表做两次 JOIN：
   - 第一次 JOIN 获取 `left_operand` 对应的值。
   - 第二次 JOIN 获取 `right_operand` 对应的值。
2. 使用 `CASE WHEN` 根据 `operator` 和两个值的大小关系返回 `'true'` 或 `'false'`。

## SQL 解法

### 方法一：两次 JOIN + CASE WHEN（推荐）

```sql
SELECT
    e.left_operand,
    e.operator,
    e.right_operand,
    CASE
        WHEN e.operator = '>' AND v1.value > v2.value  THEN 'true'
        WHEN e.operator = '<' AND v1.value < v2.value  THEN 'true'
        WHEN e.operator = '=' AND v1.value = v2.value  THEN 'true'
        ELSE 'false'
    END AS value
FROM Expressions e
JOIN Variables v1 ON e.left_operand  = v1.name
JOIN Variables v2 ON e.right_operand = v2.name;
```

### 方法二：使用 IF 嵌套

```sql
SELECT
    e.left_operand,
    e.operator,
    e.right_operand,
    IF(
        (e.operator = '>' AND v1.value > v2.value) OR
        (e.operator = '<' AND v1.value < v2.value) OR
        (e.operator = '=' AND v1.value = v2.value),
        'true',
        'false'
    ) AS value
FROM Expressions e
JOIN Variables v1 ON v1.name = e.left_operand
JOIN Variables v2 ON v2.name = e.right_operand;
```

### 方法三：子查询替代 JOIN

```sql
SELECT
    e.left_operand,
    e.operator,
    e.right_operand,
    CASE
        WHEN e.operator = '=' AND
             (SELECT value FROM Variables WHERE name = e.left_operand) =
             (SELECT value FROM Variables WHERE name = e.right_operand) THEN 'true'
        WHEN e.operator = '>' AND
             (SELECT value FROM Variables WHERE name = e.left_operand) >
             (SELECT value FROM Variables WHERE name = e.right_operand) THEN 'true'
        WHEN e.operator = '<' AND
             (SELECT value FROM Variables WHERE name = e.left_operand) <
             (SELECT value FROM Variables WHERE name = e.right_operand) THEN 'true'
        ELSE 'false'
    END AS value
FROM Expressions e;
```

注意：子查询方法代码冗余，不如 JOIN 简洁，但逻辑更直观。

## 复杂度分析

- **时间复杂度：** O(n)，n 为 Expressions 表行数，每行做两次哈希查找（JOIN）。
- **空间复杂度：** O(n + m)，n 为表达式数，m 为变量数。

## 关键点总结

1. 同一张表 JOIN 两次（自连接模式）：一次取左操作数的值，一次取右操作数的值。
2. `CASE WHEN` 同时判断操作符和数值大小，逻辑清晰。
3. 结果字段 `value` 是字符串 `'true'` 或 `'false'`，不是布尔类型。
4. 两次 JOIN 的别名不同（`v1` 和 `v2`），避免命名冲突。

## 易错点

- 两次 JOIN 使用相同别名导致 SQL 错误。
- 将结果写成数字 `1/0` 而非字符串 `'true'/'false'`。
- 漏掉某个操作符（`<`、`>`、`=` 三种都要处理）。
- `CASE WHEN` 顺序错误或条件重叠。
