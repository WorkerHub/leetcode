## 题目描述

表 `Days`：

| Column Name | Type |
|-------------|------|
| day         | date |

`day` 是主键。

编写 SQL 查询，将每个日期的格式从 `YYYY-MM-DD` 转换为 `Day_name, Month_name DD, YYYY`。

例如：`2022-04-12` 转换为 `"Tuesday, April 12, 2022"`。

返回任意顺序的结果。

**示例：**
```
输入：
+------------+
| day        |
+------------+
| 2022-04-12 |
| 2021-08-09 |
| 2020-06-26 |
+------------+
输出：
+-------------------------+
| day                     |
+-------------------------+
| Tuesday, April 12, 2022 |
| Monday, August 9, 2021  |
| Friday, June 26, 2020   |
+-------------------------+
```

## 解题思路

使用 MySQL 的 `DATE_FORMAT` 函数：
- `%W`：完整的星期几名称（如 Monday）
- `%M`：完整的月份名称（如 April）
- `%e`：不带前导零的日期（如 9 而非 09）
- `%Y`：四位年份

格式字符串：`'%W, %M %e, %Y'`

## 代码实现

### 方法一：DATE_FORMAT 函数（推荐）

```sql
SELECT DATE_FORMAT(day, '%W, %M %e, %Y') AS day
FROM Days;
```

### 方法二：拼接多个函数

```sql
SELECT CONCAT(
    DAYNAME(day), ', ',
    MONTHNAME(day), ' ',
    DAY(day), ', ',
    YEAR(day)
) AS day
FROM Days;
```

## 复杂度分析

- **时间复杂度**：O(n)，处理每一行
- **空间复杂度**：O(1)

## 关键点总结

1. `DATE_FORMAT` 是 MySQL 日期格式化的标准函数
2. `%e` 不带前导零，`%d` 带前导零（08 vs 8），本题需要 `%e`
3. `DAYNAME()` 和 `MONTHNAME()` 可以直接获取星期和月份的英文名

## 易错点

- 日期中的日数不带前导零（题目要求 "9" 而非 "09"），使用 `%e` 而非 `%d`
- 注意逗号和空格的位置：`星期, 月份 日, 年`
