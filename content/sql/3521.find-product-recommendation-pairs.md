## 题目描述

表 `ProductPurchases`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| product_id  | int     |
+-------------+---------+
(user_id, product_id) 是主键。
每行表示某用户购买了某产品。
```

表 `ProductInfo`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| category    | varchar |
| price       | decimal |
+-------------+---------+
product_id 是主键。
```

找出所有"产品推荐对"：两个产品 `(product1, product2)`（`product1 < product2`），满足：
1. 至少有 3 个不同用户同时购买了这两个产品
2. 两个产品属于同一类别

结果按 `product1`，`product2` 升序排列。

**示例：**

```
输入：
ProductPurchases：
user_id | product_id
1       | 1
1       | 2
2       | 1
2       | 2
3       | 1
3       | 2
4       | 1

ProductInfo：
product_id | category | price
1          | Electronics | 100
2          | Electronics | 200
3          | Clothing    | 50

输出：
product1 | product2 | common_users
1        | 2        | 3
```

## 解题思路

1. 自连接 `ProductPurchases` 表，找同一用户购买的产品对
2. 过滤 `product1 < product2` 避免重复
3. 按产品对分组，统计共同用户数 >= 3
4. 连接 `ProductInfo` 确认两产品同属一类

## 代码实现

### 方法一：标准 SQL 解法（推荐）

```sql
SELECT 
    p1.product_id AS product1,
    p2.product_id AS product2,
    COUNT(DISTINCT p1.user_id) AS common_users
FROM ProductPurchases p1
JOIN ProductPurchases p2
    ON p1.user_id = p2.user_id
    AND p1.product_id < p2.product_id
JOIN ProductInfo pi1
    ON p1.product_id = pi1.product_id
JOIN ProductInfo pi2
    ON p2.product_id = pi2.product_id
    AND pi1.category = pi2.category
GROUP BY p1.product_id, p2.product_id
HAVING COUNT(DISTINCT p1.user_id) >= 3
ORDER BY product1, product2;
```

### 方法二：子查询分步实现

```sql
-- 第一步：找所有用户购买的产品对
WITH PairCounts AS (
    SELECT 
        p1.product_id AS product1,
        p2.product_id AS product2,
        COUNT(DISTINCT p1.user_id) AS common_users
    FROM ProductPurchases p1
    INNER JOIN ProductPurchases p2
        ON p1.user_id = p2.user_id
        AND p1.product_id < p2.product_id
    GROUP BY p1.product_id, p2.product_id
    HAVING COUNT(DISTINCT p1.user_id) >= 3
)
-- 第二步：过滤同类别的产品对
SELECT 
    pc.product1,
    pc.product2,
    pc.common_users
FROM PairCounts pc
JOIN ProductInfo pi1 ON pc.product1 = pi1.product_id
JOIN ProductInfo pi2 ON pc.product2 = pi2.product_id
WHERE pi1.category = pi2.category
ORDER BY pc.product1, pc.product2;
```

## 复杂度分析

- 时间复杂度：O(n^2)，自连接操作
- 空间复杂度：O(n^2)，存储中间结果

## 关键点总结

1. 自连接找同一用户购买的产品对
2. `product1 < product2` 避免重复对
3. `HAVING COUNT >= 3` 过滤共同用户数
4. 连接 ProductInfo 验证同类别条件

## 易错点

1. 不要忘记 `product1 < product2` 的约束，否则每对会被统计两次
2. `HAVING` 子句中使用 `COUNT(DISTINCT user_id)` 而不是 `COUNT(*)`
3. 两个产品必须同时满足同类别条件
