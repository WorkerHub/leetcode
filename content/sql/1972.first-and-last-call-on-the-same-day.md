## 题目描述

表 `Calls`：
```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| caller_id    | int     |
| recipient_id | int     |
| call_time    | datetime|
+--------------+---------+
(caller_id, recipient_id, call_time) 是主键。
```

找出那些**当天第一通和最后一通电话**（当天所有通话中时间最早和最晚的）**是同一个人**的用户 id。

返回这样的用户 id，每个用户只出现一次，按任意顺序。

---

## 解题思路

### 核心思想：窗口函数 + 自连接

1. 将 Calls 表双向化（caller 和 recipient 都算作参与者）
2. 对每个用户，用窗口函数 `FIRST_VALUE` 和 `LAST_VALUE`（或 `MIN`/`MAX` + GROUP BY）找当天第一和最后的对方用户
3. 若第一和最后的对方相同，则该用户满足条件

---

## 代码实现

### 方法一：窗口函数（推荐）

```sql
-- 将通话记录双向展开（每次通话对 caller 和 recipient 都生效）
WITH all_calls AS (
    SELECT caller_id AS user_id, recipient_id AS other_id, call_time
    FROM Calls
    UNION ALL
    SELECT recipient_id AS user_id, caller_id AS other_id, call_time
    FROM Calls
),
-- 对每个用户每天找第一通和最后一通的对方
daily_first_last AS (
    SELECT
        user_id,
        DATE(call_time) AS call_day,
        FIRST_VALUE(other_id) OVER (
            PARTITION BY user_id, DATE(call_time)
            ORDER BY call_time ASC
            ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
        ) AS first_other,
        FIRST_VALUE(other_id) OVER (
            PARTITION BY user_id, DATE(call_time)
            ORDER BY call_time DESC
            ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
        ) AS last_other
    FROM all_calls
)
SELECT DISTINCT user_id
FROM daily_first_last
WHERE first_other = last_other;
```

### 方法二：GROUP BY + 聚合

```sql
WITH all_calls AS (
    SELECT caller_id AS user_id, recipient_id AS other_id, call_time
    FROM Calls
    UNION ALL
    SELECT recipient_id AS user_id, caller_id AS other_id, call_time
    FROM Calls
),
daily_bounds AS (
    SELECT
        user_id,
        DATE(call_time) AS call_day,
        MIN(call_time) AS first_time,
        MAX(call_time) AS last_time
    FROM all_calls
    GROUP BY user_id, DATE(call_time)
),
first_calls AS (
    SELECT a.user_id, a.call_day, a.other_id AS first_other
    FROM all_calls a
    JOIN daily_bounds b
        ON a.user_id = b.user_id
        AND DATE(a.call_time) = b.call_day
        AND a.call_time = b.first_time
),
last_calls AS (
    SELECT a.user_id, a.call_day, a.other_id AS last_other
    FROM all_calls a
    JOIN daily_bounds b
        ON a.user_id = b.user_id
        AND DATE(a.call_time) = b.call_day
        AND a.call_time = b.last_time
)
SELECT DISTINCT fc.user_id
FROM first_calls fc
JOIN last_calls lc
    ON fc.user_id = lc.user_id
    AND fc.call_day = lc.call_day
    AND fc.first_other = lc.last_other;
```

## 复杂度分析

| 操作 | 说明 |
|------|------|
| 双向化 | O(n) |
| 窗口函数 | O(n log n)（分区排序） |

---

## 关键点总结

1. 双向化：每通电话对 caller 和 recipient 都算参与
2. 找每用户每天第一和最后通话的对方，判断是否相同
3. `FIRST_VALUE` 配合 `ORDER BY call_time DESC` 得到最后通话对方

---

## 易错点

- 注意双向化后同一通话对两个用户各生效一次
- `DISTINCT` 去重结果（同一用户可能多天满足条件）
