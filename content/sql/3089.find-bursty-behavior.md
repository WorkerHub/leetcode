## 题目描述

表：`PostActivity`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| user_id          | int     |
| activity_date    | date    |
| activity_count   | int     |
+------------------+---------+
```

如果用户最近一周（7 天）的活动总次数是过去一个月（28 天）平均每周活动次数的两倍以上，则该用户表现出"突发行为"。

返回满足条件的 `user_id` 和 `recent_activity`（最近一周总次数）及 `activity_ratio`（最近一周 / 过去28天每周平均次数，保留两位小数），按 `user_id` 升序排列。

## SQL 代码实现

### 方法一：CTE 分组计算（推荐）

```sql
WITH recent AS (
    SELECT
        user_id,
        SUM(activity_count) AS recent_activity
    FROM PostActivity
    WHERE activity_date >= CURDATE() - INTERVAL 6 DAY
    GROUP BY user_id
),
past AS (
    SELECT
        user_id,
        SUM(activity_count) / 4.0 AS avg_weekly
    FROM PostActivity
    WHERE activity_date >= CURDATE() - INTERVAL 27 DAY
      AND activity_date < CURDATE() - INTERVAL 6 DAY
    GROUP BY user_id
)
SELECT
    r.user_id,
    r.recent_activity,
    ROUND(r.recent_activity / p.avg_weekly, 2) AS activity_ratio
FROM recent r
JOIN past p ON r.user_id = p.user_id
WHERE r.recent_activity > 2 * p.avg_weekly
ORDER BY r.user_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，n 为活动记录数
- 空间复杂度：O(n)

## 关键点总结

1. "最近一周"：最近 7 天
2. "过去一个月"：过去 28 天（不含最近 7 天）
3. 平均每周 = 过去 28 天总次数 / 4

## 易错点

1. 日期范围计算：`CURDATE() - INTERVAL n DAY`
2. 过去 28 天的每周平均 = 总量 / 4（4 周）
3. 条件：最近一周 > 2 * 过去每周平均
