## 题目描述

表：`Tweets`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| tweet_id    | int     |
| tweet_date  | date    |
| tweet       | varchar |
+-------------+---------+
```

找出 2024 年 2 月出现次数最多的前 3 个话题标签（以 `#` 开头的词）。

返回 `hashtag` 和 `count`，按出现次数降序，次数相同则按话题标签降序排列，只返回前 3 条。

## SQL 代码实现

### 方法一：正则提取话题标签（推荐）

```sql
-- MySQL 没有直接提取所有 hashtag 的函数，需要拆分字符串
-- 使用 REGEXP_SUBSTR 和递归 CTE

WITH RECURSIVE split AS (
    SELECT
        tweet_id,
        tweet,
        tweet_date,
        TRIM(SUBSTRING_INDEX(tweet, ' ', 1)) AS word,
        IF(LOCATE(' ', tweet) > 0,
           SUBSTRING(tweet, LOCATE(' ', tweet) + 1),
           '') AS rest
    FROM Tweets
    WHERE YEAR(tweet_date) = 2024 AND MONTH(tweet_date) = 2

    UNION ALL

    SELECT
        tweet_id,
        tweet,
        tweet_date,
        TRIM(SUBSTRING_INDEX(rest, ' ', 1)) AS word,
        IF(LOCATE(' ', rest) > 0,
           SUBSTRING(rest, LOCATE(' ', rest) + 1),
           '') AS rest
    FROM split
    WHERE rest != ''
)
SELECT
    word AS hashtag,
    COUNT(*) AS count
FROM split
WHERE word LIKE '#%'
GROUP BY word
ORDER BY count DESC, hashtag DESC
LIMIT 3;
```

### 方法二：使用 JSON_TABLE（MySQL 8.0+）

```sql
WITH words AS (
    SELECT
        tweet_id,
        jt.word
    FROM Tweets,
    JSON_TABLE(
        CONCAT('["', REPLACE(tweet, ' ', '","'), '"]'),
        '$[*]' COLUMNS(word VARCHAR(255) PATH '$')
    ) AS jt
    WHERE YEAR(tweet_date) = 2024 AND MONTH(tweet_date) = 2
)
SELECT
    word AS hashtag,
    COUNT(*) AS count
FROM words
WHERE word LIKE '#%'
GROUP BY word
ORDER BY count DESC, hashtag DESC
LIMIT 3;
```

## 复杂度分析

- 时间复杂度：O(n * L)，L 为推文平均长度
- 空间复杂度：O(n * L)

## 关键点总结

1. 需要拆分每条推文为单词
2. 过滤出以 `#` 开头的词
3. 统计频率后排序取前 3

## 易错点

1. 只统计 2024 年 2 月的数据
2. 排序：首先按 count 降序，相同时按 hashtag 降序
