## 题目描述

表 `Products`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| name         | varchar |
| description  | varchar |
+--------------+---------+
```

`product_id` 是主键。

找出 `description` 字段包含**三个连续数字**的所有产品，返回 `product_id` 和 `name`，按 `product_id` 升序排列。

**示例：**

输入：
```
+------------+-------+------------------+
| product_id | name  | description      |
+------------+-------+------------------+
| 1          | prod1 | This has 123     |
| 2          | prod2 | No digits here   |
| 3          | prod3 | 4567 is here     |
| 4          | prod4 | abc 99 xyz       |
+------------+-------+------------------+
```

输出：
```
+------------+-------+
| product_id | name  |
+------------+-------+
| 1          | prod1 |
| 3          | prod3 |
+------------+-------+
```

**提示：**
- 三个连续数字指 `description` 中包含至少三个相邻的数字字符

## 解题思路

使用正则表达式匹配 description 中是否包含三个连续数字（`[0-9]{3}` 或 `\d{3}`）。

不同数据库的正则语法略有不同：
- MySQL：使用 `REGEXP` 或 `REGEXP_LIKE`
- PostgreSQL：使用 `~`
- SQLite：不直接支持，但 LeetCode 通常使用 MySQL

## SQL 代码实现

### 方法一：使用 REGEXP（MySQL，推荐）

```sql
SELECT product_id, name
FROM Products
WHERE description REGEXP '[0-9]{3}'
ORDER BY product_id;
```

### 方法二：使用 LIKE 模糊匹配三个连续数字（枚举，兼容性好）

```sql
SELECT product_id, name
FROM Products
WHERE description LIKE '%[0-9][0-9][0-9]%'
ORDER BY product_id;
```

注意：`LIKE` 不支持字符类 `[0-9]`，标准 SQL 中 `[0-9]` 在 LIKE 中无效。

### 方法三：MySQL REGEXP_LIKE 函数

```sql
SELECT product_id, name
FROM Products
WHERE REGEXP_LIKE(description, '[0-9]{3}')
ORDER BY product_id;
```

### 方法四：利用 REGEXP 匹配连续三个数字

```sql
SELECT product_id, name
FROM Products
WHERE description REGEXP '[[:digit:]]{3}'
ORDER BY product_id;
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为行数，L 为 description 平均长度
- 空间复杂度：O(1)

## 关键点总结

1. 正则表达式 `[0-9]{3}` 匹配恰好三个连续数字（或更多）
2. MySQL 中使用 `REGEXP` 关键字进行正则匹配
3. `[[:digit:]]` 是 POSIX 字符类，等价于 `[0-9]`

## 易错点

1. 注意 `{3}` 匹配至少 3 个还是恰好 3 个——`[0-9]{3}` 在 REGEXP 中匹配任何含连续 3 个数字的字符串（包括 4 个、5 个）
2. LIKE 的通配符是 `%`（任意字符）和 `_`（单字符），不支持字符类
3. 不同数据库正则语法不同，MySQL 用 `REGEXP`，PostgreSQL 用 `~`
