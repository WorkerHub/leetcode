## 题目描述

表 `Students`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| student_name| varchar |
+-------------+---------+
```

表 `Exam1`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
+-------------+---------+
```

表 `Exam2`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
+-------------+---------+
```

查找在两次考试中都缺席的学生（即不在 Exam1 也不在 Exam2 中），返回 `student_id` 和 `student_name`，按 `student_id` 升序排列。

**示例：**

```
Students:
student_id | student_name
1          | Alice
2          | Bob
3          | Carol
4          | David

Exam1: [1, 2]
Exam2: [2, 3]

输出：
student_id | student_name
4          | David
```

## 解题思路

使用 `NOT IN` 或 `LEFT JOIN` 找出不在两张考试表中的学生。

```sql
SELECT student_id, student_name
FROM Students
WHERE student_id NOT IN (SELECT student_id FROM Exam1)
  AND student_id NOT IN (SELECT student_id FROM Exam2)
ORDER BY student_id;
```

## 代码实现

### 方法一：SQL（推荐）

```sql
-- 方法一：NOT IN 子查询
SELECT s.student_id, s.student_name
FROM Students s
WHERE s.student_id NOT IN (
    SELECT student_id FROM Exam1
    UNION
    SELECT student_id FROM Exam2
)
ORDER BY s.student_id;
```

### 方法二：LEFT JOIN

```sql
-- 方法二：LEFT JOIN + IS NULL
SELECT s.student_id, s.student_name
FROM Students s
LEFT JOIN Exam1 e1 ON s.student_id = e1.student_id
LEFT JOIN Exam2 e2 ON s.student_id = e2.student_id
WHERE e1.student_id IS NULL
  AND e2.student_id IS NULL
ORDER BY s.student_id;
```

## 复杂度分析

- 时间复杂度：O(n + m + p)，n 为学生数，m, p 为两次考试人数
- 空间复杂度：O(m + p)，临时集合

## 关键点总结

1. `NOT IN` 简洁直观，但若子查询结果含 NULL 可能出错。
2. `LEFT JOIN + IS NULL` 更安全，也是常用的"不存在于"查询模式。
3. `UNION` 合并两次考试名单（去重），简化逻辑。

## 易错点

1. `NOT IN` 的子查询若含 NULL，整个条件变为 FALSE（SQL 的三值逻辑），推荐用 `LEFT JOIN`。
2. 记得 `ORDER BY student_id` 排序。
