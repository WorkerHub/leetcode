## 题目描述

编写SQL查询来报告每个员工的姓名和奖金金额。如果员工没有奖金或奖金少于1000，返回null。

## SQL 代码实现

```sql
SELECT e.name, b.bonus
FROM Employee e
LEFT JOIN Bonus b ON e.empId = b.empId
WHERE b.bonus < 1000 OR b.bonus IS NULL;
```

## 关键点总结

1. **LEFT JOIN**：保留所有员工记录
2. **NULL 处理**：员工可能没有奖金记录
3. **WHERE 条件**：bonus < 1000 或 bonus IS NULL

## 学习建议

掌握 LEFT JOIN 和 NULL 的处理。
