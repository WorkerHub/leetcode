## 题目描述

表：`Project`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
| workload    | int     |
+-------------+---------+
```

表：`Employees`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| team             | varchar |
+------------------+---------+
```

找出工作量超过同团队平均工作量的员工，返回员工 ID、姓名、团队、工作量，按员工 ID 升序排列。

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH emp_workload AS (
    SELECT
        e.employee_id,
        e.name,
        e.team,
        SUM(p.workload) AS workload
    FROM Employees e
    JOIN Project p ON e.employee_id = p.employee_id
    GROUP BY e.employee_id, e.name, e.team
),
team_avg AS (
    SELECT
        team,
        AVG(workload) AS avg_workload
    FROM emp_workload
    GROUP BY team
)
SELECT
    ew.employee_id,
    ew.name,
    ew.team,
    ew.workload
FROM emp_workload ew
JOIN team_avg ta ON ew.team = ta.team
WHERE ew.workload > ta.avg_workload
ORDER BY ew.employee_id ASC;
```

### 方法二：子查询

```sql
WITH emp_workload AS (
    SELECT
        e.employee_id,
        e.name,
        e.team,
        SUM(p.workload) AS workload
    FROM Employees e
    JOIN Project p ON e.employee_id = p.employee_id
    GROUP BY e.employee_id, e.name, e.team
)
SELECT
    employee_id,
    name,
    team,
    workload
FROM emp_workload ew
WHERE workload > (
    SELECT AVG(workload)
    FROM emp_workload
    WHERE team = ew.team
)
ORDER BY employee_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先计算每位员工的总工作量（SUM）
2. 再计算每个团队的平均工作量
3. 过滤出工作量超过团队平均值的员工

## 易错点

1. 比较的是个人总工作量与团队平均值（不是个别项目工作量）
2. 团队平均值是每位员工总工作量的平均，不是项目工作量的平均
