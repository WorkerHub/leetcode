## 题目描述

表：`CoffeeShop`

| Column Name | Type    |
|-------------|---------|
| id          | int     |
| drink       | varchar |

`id` 是该表的主键，`drink` 列包含 NULL 值，表示该行的饮料与上一行相同。

编写一条 SQL 语句，将表中所有 NULL 值替换为该列中最近的非 NULL 值（即上一行的值）。

**示例 1：**
```
输入：
CoffeeShop 表：
+----+------------+
| id | drink      |
+----+------------+
| 9  | Rum Cola   |
| 6  | NULL       |
| 7  | NULL       |
| 3  | St Germain |
| 1  | NULL       |
| 2  | NULL       |
+----+------------+

输出：
+----+------------+
| id | drink      |
+----+------------+
| 9  | Rum Cola   |
| 6  | Rum Cola   |
| 7  | Rum Cola   |
| 3  | St Germain |
| 1  | St Germain |
| 2  | St Germain |
+----+------------+
```

**提示：**
- 保证第一行的 `drink` 不为 NULL
- 表中至少有 1 行数据

## 解题思路

**方法一：变量模拟（MySQL 用户变量）**

用一个变量跟踪上一个非 NULL 值，逐行扫描替换。

**方法二：窗口函数分组**

利用 `SUM` 窗口函数给每个连续 NULL 分组，再用 `MAX` 或 `FIRST_VALUE` 获取组内第一个非 NULL 值。

## 代码实现

### 方法一：用户变量（MySQL）

```sql
-- 使用用户变量跟踪上一个非 NULL 值
SELECT id,
       @prev := IFNULL(drink, @prev) AS drink
FROM CoffeeShop,
     (SELECT @prev := NULL) init
ORDER BY id;
```

### 方法二：窗口函数（推荐，SQL 标准）

```sql
-- 步骤1：给每个"非 NULL 组"打上分组编号
-- 步骤2：用 MAX 获取每组中的非 NULL 值
WITH numbered AS (
    SELECT id,
           drink,
           -- 统计到当前行为止，非 NULL 值的个数（作为分组 ID）
           COUNT(drink) OVER (ORDER BY id) AS grp
    FROM CoffeeShop
)
SELECT id,
       -- 每组取第一个非 NULL 的 drink（即 grp 相同的行里最大值就是非 NULL 值）
       MAX(drink) OVER (PARTITION BY grp) AS drink
FROM numbered
ORDER BY id;
```

### 方法三：子查询关联

```sql
-- 对每行，找到最近的非 NULL 行的 drink 值
SELECT c1.id,
       (SELECT c2.drink
        FROM CoffeeShop c2
        WHERE c2.id <= c1.id
          AND c2.drink IS NOT NULL
        ORDER BY c2.id DESC
        LIMIT 1) AS drink
FROM CoffeeShop c1
ORDER BY c1.id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 用户变量 | O(n) | O(1) |
| 窗口函数 | O(n log n) | O(n) |
| 关联子查询 | O(n^2) | O(1) |

## 关键点总结

1. `COUNT(drink) OVER (ORDER BY id)` 统计非 NULL 值个数作为分组标识（NULL 不会被计数）。
2. 同一分组内，`MAX(drink) OVER (PARTITION BY grp)` 返回该组内唯一的非 NULL 值。
3. 窗口函数方法是 SQL 标准写法，兼容 MySQL 8.0+、PostgreSQL、SQL Server 等。

## 易错点

- MySQL 5.x 不支持窗口函数，需用用户变量。
- 用户变量方法依赖 `ORDER BY` 确保行顺序，子查询初始化 `@prev := NULL`。
- `COUNT(drink)` 会跳过 NULL，而 `COUNT(*)` 不跳过。
