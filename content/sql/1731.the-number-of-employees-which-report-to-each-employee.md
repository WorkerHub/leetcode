## 题目描述

表 `Employees`：

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| employee_id | int      |
| name        | varchar  |
| reports_to  | int      |
| age         | int      |
+-------------+----------+
```

`employee_id` 是该表的主键。`reports_to` 是该员工汇报的经理的 `employee_id`，可为 NULL（公司老板）。

对于此问题，我们将**至少有一个其他员工向其汇报**的员工称为经理。

编写解决方案，返回经理的 ID、名字、直接向该经理汇报的员工数量，以及这些员工年龄的平均值（四舍五入到最近的整数）。

返回结果按 `employee_id` 升序排序。

**示例：**
```
输入：
Employees 表
+-------------+---------+------------+-----+
| employee_id | name    | reports_to | age |
+-------------+---------+------------+-----+
| 9           | Hercy   | null       | 43  |
| 6           | Alice   | 9          | 41  |
| 4           | Bob     | 9          | 36  |
| 2           | Winston | null       | 37  |
+-------------+---------+------------+-----+
输出：
+-------------+-------+---------------+-------------+
| employee_id | name  | reports_count | average_age |
+-------------+-------+---------------+-------------+
| 9           | Hercy | 2             | 39          |
+-------------+-------+---------------+-------------+
```

## 解题思路

将表自连接：一个表作为员工表，另一个作为经理表。按经理的 `employee_id` 分组，统计汇报人数和平均年龄。

## 代码实现

### 方法一：自连接 + GROUP BY

```sql
-- e1 是员工，e2 是经理
-- 将 e1.reports_to = e2.employee_id 连接
SELECT
    e2.employee_id,
    e2.name,
    COUNT(e1.employee_id) AS reports_count,
    ROUND(AVG(e1.age)) AS average_age
FROM Employees e1
JOIN Employees e2 ON e1.reports_to = e2.employee_id
GROUP BY e2.employee_id, e2.name
ORDER BY e2.employee_id;
```

### 方法二：使用子查询

```sql
-- 先汇总直接汇报关系，再关联获取经理信息
SELECT
    m.employee_id,
    m.name,
    r.reports_count,
    r.average_age
FROM (
    SELECT
        reports_to AS manager_id,
        COUNT(*) AS reports_count,
        ROUND(AVG(age)) AS average_age
    FROM Employees
    WHERE reports_to IS NOT NULL
    GROUP BY reports_to
) r
JOIN Employees m ON r.manager_id = m.employee_id
ORDER BY m.employee_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序操作
- **空间复杂度**：O(n)，存储分组结果

## 关键点总结

1. 自连接将员工和经理关联
2. 按经理 `employee_id` 分组
3. `ROUND(AVG(age))` 四舍五入平均年龄

## 易错点

- `reports_to` 为 NULL 的员工没有经理，JOIN 会自然过滤（INNER JOIN 不会包含 NULL 的行）
- `ROUND` 不加小数位参数默认四舍五入到整数
