## 题目描述

`Customers` 表：

```
+---------------------+---------+
| Column Name         | Type    |
+---------------------+---------+
| customer_id         | int     |
| customer_name       | varchar |
+---------------------+---------+
```

`customer_id` 是该表主键。

`Orders` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| customer_id   | int     |
| product_name  | varchar |
+---------------+---------+
```

`order_id` 是该表主键。`customer_id` 是 `Customers` 表中 `customer_id` 的外键。

编写 SQL 语句，报告购买了产品 **A** 和产品 **B** 却没有购买产品 **C** 的客户的 `customer_id` 和 `customer_name`。

结果按 `customer_id` 升序排列。

**示例：**

```
输入：
Customers 表:
+-------------+---------------+
| customer_id | customer_name |
+-------------+---------------+
| 1           | Daniel        |
| 2           | Diana         |
| 3           | Elizabeth     |
| 4           | Jhon          |
+-------------+---------------+

Orders 表:
+------------+--------------+--------------+
| order_id   | customer_id  | product_name |
+------------+--------------+--------------+
| 10         | 1            | A            |
| 20         | 1            | B            |
| 30         | 1            | C            |
| 40         | 2            | A            |
| 50         | 2            | B            |
| 60         | 3            | A            |
| 70         | 4            | D            |
+------------+--------------+--------------+

输出：
+-------------+---------------+
| customer_id | customer_name |
+-------------+---------------+
| 2           | Diana         |
+-------------+---------------+
解释：
Daniel (1) 买了 A, B, C → 不满足（有 C）
Diana (2) 买了 A, B → 满足
Elizabeth (3) 只买了 A → 不满足（没有 B）
Jhon (4) 买了 D → 不满足
```

## 解题思路

**条件拆解：**

1. 买了产品 A
2. 买了产品 B
3. 没有买产品 C

**方法一（条件聚合）：** 按 `customer_id` 分组，用 `HAVING` 条件过滤：
- `MAX(CASE WHEN product_name='A' THEN 1 ELSE 0 END) = 1`（买了A）
- `MAX(CASE WHEN product_name='B' THEN 1 ELSE 0 END) = 1`（买了B）
- `MAX(CASE WHEN product_name='C' THEN 1 ELSE 0 END) = 0`（没买C）

**方法二（子查询/NOT IN）：** 先找买了A和B的客户，再排除买了C的。

## 代码实现

### 方法一：条件聚合 + HAVING（推荐）

```sql
SELECT
    c.customer_id,
    c.customer_name
FROM Customers c
JOIN Orders o ON c.customer_id = o.customer_id
GROUP BY c.customer_id, c.customer_name
HAVING
    -- 购买了产品 A
    MAX(CASE WHEN o.product_name = 'A' THEN 1 ELSE 0 END) = 1
    -- 购买了产品 B
    AND MAX(CASE WHEN o.product_name = 'B' THEN 1 ELSE 0 END) = 1
    -- 没有购买产品 C
    AND MAX(CASE WHEN o.product_name = 'C' THEN 1 ELSE 0 END) = 0
ORDER BY c.customer_id;
```

### 方法二：SUM + HAVING（等价写法）

```sql
SELECT
    c.customer_id,
    c.customer_name
FROM Customers c
JOIN Orders o ON c.customer_id = o.customer_id
GROUP BY c.customer_id, c.customer_name
HAVING
    SUM(o.product_name = 'A') > 0   -- 买了 A（至少一次）
    AND SUM(o.product_name = 'B') > 0  -- 买了 B
    AND SUM(o.product_name = 'C') = 0  -- 没买 C
ORDER BY c.customer_id;
```

**注意：** `SUM(product_name = 'A')` 是 MySQL 特有语法，`product_name = 'A'` 返回 0 或 1，`SUM` 统计为真的次数。

### 方法三：NOT IN 子查询

```sql
SELECT
    c.customer_id,
    c.customer_name
FROM Customers c
WHERE
    -- 买了 A
    c.customer_id IN (SELECT customer_id FROM Orders WHERE product_name = 'A')
    -- 买了 B
    AND c.customer_id IN (SELECT customer_id FROM Orders WHERE product_name = 'B')
    -- 没买 C
    AND c.customer_id NOT IN (SELECT customer_id FROM Orders WHERE product_name = 'C')
ORDER BY c.customer_id;
```

## 复杂度分析

- **时间复杂度 O(n)**：扫描 Orders 表一次，按 customer_id 分组聚合。
- **空间复杂度 O(k)**：k 是不同客户的数量。

## 关键点总结

1. 用 `HAVING` 对分组后的结果进行条件过滤，是多条件筛选的标准方法
2. `MAX(CASE WHEN ... THEN 1 ELSE 0 END)` 判断某个条件是否出现过（至少一次为1）
3. `SUM(product_name = 'A') > 0` 是 MySQL 的布尔值隐式转换，等价写法更简洁
4. 注意要 JOIN Customers 表来获取 `customer_name`

## 易错点

- `GROUP BY` 必须包含 `customer_name`（或在 `SELECT` 中只选 `customer_id`，然后再 JOIN 查名字）
- `SUM(product_name = 'A') > 0` 不等于 `COUNT(product_name = 'A') > 0`，`COUNT` 只统计非 NULL，不区分值
- `NOT IN` 子查询中若子查询结果含 NULL，整个 `NOT IN` 会返回空，需谨慎

1. 掌握"多条件筛选"的两种写法：`HAVING` + 条件聚合 vs `NOT IN` 子查询
2. `CASE WHEN ... THEN 1 ELSE 0 END` 配合 `MAX/SUM` 是 SQL 中判断"存在性"的经典模式
3. 对于"买了 A 且买了 B 但没买 C"这类问题，集合运算思维（交集减差集）非常直观
