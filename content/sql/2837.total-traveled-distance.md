## 题目描述

**表：Users**

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| name        | varchar |
+-------------+---------+
user_id 是主键。
```

**表：Rides**

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| ride_id     | int     |
| user_id     | int     |
| distance    | int     |
+-------------+---------+
ride_id 是主键。
```

查询每个用户的总行驶距离，包括那些从未乘过车的用户（距离显示为 0）。

按 `user_id` 升序排列。

**示例：**
```
Users 表：
+---------+----------+
| user_id | name     |
+---------+----------+
| 17      | Addison  |
| 14      | Ethan    |
| 4       | Peter    |
| 2       | Ilhan    |
| 1       | Kimie    |
+---------+----------+

Rides 表：
+---------+---------+----------+
| ride_id | user_id | distance |
+---------+---------+----------+
| 72      | 17      | 160      |
| 42      | 14      | 161      |
| 45      | 4       | 59       |
| 32      | 2       | 197      |
| 15      | 4       | 357      |
| 56      | 2       | 196      |
| 10      | 1       | 25       |
+---------+---------+----------+

输出：
+---------+----------+-------------------+
| user_id | name     | traveled_distance |
+---------+----------+-------------------+
| 1       | Kimie    | 25                |
| 2       | Ilhan    | 393               |
| 4       | Peter    | 416               |
| 14      | Ethan    | 161               |
| 17      | Addison  | 160               |
+---------+----------+-------------------+
```

## 解题思路

使用 LEFT JOIN 将 Users 表和 Rides 表连接，然后按 user_id 分组，对 distance 求和（用 COALESCE 处理 NULL）。

## 代码实现

### SQL 解法

```sql
SELECT 
    u.user_id,
    u.name,
    COALESCE(SUM(r.distance), 0) AS traveled_distance
FROM Users u
LEFT JOIN Rides r ON u.user_id = r.user_id
GROUP BY u.user_id, u.name
ORDER BY u.user_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和分组操作
- 空间复杂度：O(n)，中间结果

## 关键点总结

1. 使用 LEFT JOIN 保留所有用户，即使没有乘车记录
2. `COALESCE(SUM(distance), 0)` 处理没有行程的用户（SUM 返回 NULL）
3. 最终按 user_id 升序排列

## 易错点

1. 不能用 INNER JOIN，否则没有乘车记录的用户会被过滤掉
2. 对 NULL 求和在 SQL 中会返回 NULL，需要用 COALESCE 转换为 0
3. 按 user_id 和 name 分组（避免相同 user_id 不同 name 的数据被合并，虽然实际不会发生）
