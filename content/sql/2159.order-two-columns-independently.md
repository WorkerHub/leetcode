## 题目描述

表 `Data`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| first_col   | int  |
| second_col  | int  |
+-------------+------+
```

编写 SQL，将 `first_col` 按**升序**排列，`second_col` 按**降序**排列，然后将这两列**独立**配对（即第 i 小的 first_col 值与第 i 大的 second_col 值配对）。

**示例：**
```
输入：
+------------+------------+
| first_col  | second_col |
+------------+------------+
| 4          | 2          |
| 2          | 3          |
| 3          | 1          |
| 1          | 4          |
+------------+------------+
输出：
+------------+------------+
| first_col  | second_col |
+------------+------------+
| 1          | 4          |
| 2          | 3          |
| 3          | 2          |
| 4          | 1          |
+------------+------------+
```

## 解题思路

**ROW_NUMBER 独立排序后合并**

对 `first_col` 按升序分配行号，对 `second_col` 按降序分配行号，然后按行号连接。

## 代码实现

### 方法一：ROW_NUMBER 分别排序后 JOIN（推荐）

```sql
WITH fc AS (
    SELECT first_col,
           ROW_NUMBER() OVER (ORDER BY first_col ASC) AS rn
    FROM Data
),
sc AS (
    SELECT second_col,
           ROW_NUMBER() OVER (ORDER BY second_col DESC) AS rn
    FROM Data
)
SELECT fc.first_col, sc.second_col
FROM fc
JOIN sc ON fc.rn = sc.rn
ORDER BY fc.rn;
```

### 方法二：子查询版本

```sql
SELECT
    (SELECT first_col FROM Data ORDER BY first_col ASC LIMIT 1 OFFSET t.rn - 1) AS first_col,
    (SELECT second_col FROM Data ORDER BY second_col DESC LIMIT 1 OFFSET t.rn - 1) AS second_col
FROM (
    SELECT ROW_NUMBER() OVER () AS rn
    FROM Data
) t
ORDER BY t.rn;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| ROW_NUMBER | O(n log n) | O(n) |

## 关键点总结

1. 两列独立排序：`first_col` 升序，`second_col` 降序。
2. 用 `ROW_NUMBER()` 分别生成排名，然后按排名 JOIN。
3. 两个子查询的行数相同（同一张表），JOIN 后恰好 n 行。

## 易错点

- 两列是**独立**排序后配对，不是按某一列排序后取另一列的对应值。
- `ROW_NUMBER()` 无 PARTITION BY，对整个结果集排名。
