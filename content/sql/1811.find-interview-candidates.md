## 题目描述

表 `Contests`：

| Column Name  | Type |
|-------------|------|
| contest_id  | int  |
| gold_medal  | int  |
| silver_medal| int  |
| bronze_medal| int  |

`contest_id` 是主键，每一行表示竞赛 ID 及金、银、铜牌获得者的用户 ID。

表 `Users`：

| Column Name | Type    |
|-------------|---------|
| user_id     | int     |
| mail        | varchar |
| name        | varchar |

`user_id` 是主键。

编写 SQL 查询，查找满足以下条件的用户（可以是候选人）的用户名和邮件：
- **至少获得 3 枚金牌**，或者
- **在连续 3 场竞赛中均获得了奖牌（金银铜均算）**

返回任意顺序的结果。

**提示：**
- 竞赛 ID 是连续递增的整数

## 解题思路

分两个条件分别查询，然后取并集：

**条件 1**：金牌数 >= 3：统计每个用户在 gold_medal 中出现的次数，筛选 >= 3 的用户。

**条件 2**：连续 3 场均获奖：将三列展开（UNION ALL），找到每个用户在哪些 contest 中获过奖，然后判断是否有连续 3 场（contest_id 连续，且都获奖）。

用窗口函数：对每个用户的竞赛 ID 排序后，`contest_id - ROW_NUMBER()` 的差值相同表示连续。

## 代码实现

### 方法一：条件分离 + 窗口函数

```sql
-- 条件1：至少获得 3 枚金牌
WITH GoldCount AS (
    SELECT gold_medal AS user_id
    FROM Contests
    GROUP BY gold_medal
    HAVING COUNT(*) >= 3
),
-- 将所有奖牌展开为 (user_id, contest_id) 的形式
AllMedals AS (
    SELECT gold_medal AS user_id, contest_id FROM Contests
    UNION ALL
    SELECT silver_medal, contest_id FROM Contests
    UNION ALL
    SELECT bronze_medal, contest_id FROM Contests
),
-- 对每个用户的比赛 ID 排名，用差值判断连续
Ranked AS (
    SELECT user_id, contest_id,
           contest_id - ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY contest_id) AS diff
    FROM AllMedals
),
-- 条件2：连续 3 场获奖
Consecutive AS (
    SELECT user_id
    FROM Ranked
    GROUP BY user_id, diff
    HAVING COUNT(*) >= 3
),
-- 合并两个条件
Candidates AS (
    SELECT user_id FROM GoldCount
    UNION
    SELECT user_id FROM Consecutive
)
SELECT u.name, u.mail
FROM Users u
WHERE u.user_id IN (SELECT user_id FROM Candidates);
```

### 方法二：直接 UNION 两个子查询

```sql
SELECT u.name, u.mail
FROM Users u
WHERE u.user_id IN (
    -- 条件1：金牌 >= 3
    SELECT gold_medal
    FROM Contests
    GROUP BY gold_medal
    HAVING COUNT(*) >= 3
)
OR u.user_id IN (
    -- 条件2：连续3场获奖（用差值法检测连续）
    SELECT user_id
    FROM (
        SELECT user_id, contest_id,
               contest_id - ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY contest_id) AS grp
        FROM (
            SELECT gold_medal AS user_id, contest_id FROM Contests
            UNION ALL
            SELECT silver_medal, contest_id FROM Contests
            UNION ALL
            SELECT bronze_medal, contest_id FROM Contests
        ) t
    ) ranked
    GROUP BY user_id, grp
    HAVING COUNT(*) >= 3
);
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和窗口函数
- **空间复杂度**：O(n)，中间临时表

## 关键点总结

1. 连续 ID 判断的经典技巧：`contest_id - ROW_NUMBER() OVER (... ORDER BY contest_id)`，差值相同表示连续
2. 需要对三列奖牌 UNION ALL 展开，再去重（同一场比赛同一用户可能获多个奖，用 DISTINCT 处理）
3. 两个条件是"或"关系，取并集用 `UNION` 或 `OR`

## 易错点

- UNION ALL 会包含重复（同一用户同一场获多个奖），用窗口函数前可先 DISTINCT
- 差值法判断连续时，需要先对每个用户的比赛 ID 去重
