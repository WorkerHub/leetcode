## 题目描述

表：`Employee`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
```

id 是这个表的主键。
表的每一行包含员工的工资信息。

编写一个 SQL 查询，获取并返回 `Employee` 表中第二高的薪水。如果不存在第二高的薪水，查询应该返回 `null`。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+

输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| 200                 |
+---------------------+
```

**示例 2：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+

输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| null                |
+---------------------+
```

## 解题思路

这道题要求找出第二高的薪水，关键点在于：
1. 薪水需要去重（同一薪水可能有多个员工）
2. 如果不存在第二高薪水，返回 `null`

核心思路：
- 使用 `DISTINCT` 去除重复薪水
- 使用 `ORDER BY` 降序排列
- 使用 `LIMIT` 和 `OFFSET` 获取第二高的值
- 使用子查询配合 `IFNULL` 处理不存在的情况

## SQL 代码实现

### 方法一：LIMIT + OFFSET + IFNULL（推荐）

```sql
SELECT 
    IFNULL(
        (SELECT DISTINCT salary 
         FROM Employee 
         ORDER BY salary DESC 
         LIMIT 1 OFFSET 1),
        NULL
    ) AS SecondHighestSalary;
```

**代码解释：**
1. 内层查询：`SELECT DISTINCT salary` 去重获取所有不同的薪水
2. `ORDER BY salary DESC` 按薪水降序排列
3. `LIMIT 1 OFFSET 1` 跳过第一高，取第二高
4. `IFNULL()` 函数：如果内层查询返回 `NULL`（不存在第二高），则返回 `NULL`

### 方法二：MAX + 子查询

```sql
SELECT 
    MAX(salary) AS SecondHighestSalary
FROM 
    Employee
WHERE 
    salary < (SELECT MAX(salary) FROM Employee);
```

**代码解释：**
1. 子查询找出最高薪水
2. 外层查询在剩余薪水中找最大值，即第二高
3. 如果不存在第二高，`MAX()` 自动返回 `NULL`

### 方法三：使用窗口函数（MySQL 8.0+）

```sql
SELECT 
    IFNULL(
        (SELECT DISTINCT salary
         FROM (
             SELECT salary, 
                    DENSE_RANK() OVER (ORDER BY salary DESC) AS rk
             FROM Employee
         ) AS ranked
         WHERE rk = 2),
        NULL
    ) AS SecondHighestSalary;
```

**代码解释：**
1. `DENSE_RANK()` 为每个薪水分配排名（相同薪水排名相同）
2. 筛选排名为 2 的记录
3. 使用 `DISTINCT` 去重
4. `IFNULL()` 处理不存在的情况

### 方法四：自连接

```sql
SELECT 
    IFNULL(
        (SELECT DISTINCT e1.salary
         FROM Employee e1
         WHERE 1 = (SELECT COUNT(DISTINCT e2.salary) 
                    FROM Employee e2 
                    WHERE e2.salary > e1.salary)),
        NULL
    ) AS SecondHighestSalary;
```

**代码解释：**
1. 对于每个薪水，统计比它高的不同薪水个数
2. 个数为 1 的薪水即为第二高
3. 这种方法可扩展到求第 N 高薪水

## 复杂度分析

**方法一（LIMIT + OFFSET）：**
- 时间复杂度：O(n log n)，主要是排序的开销
- 空间复杂度：O(n)，去重需要额外空间

**方法二（MAX + 子查询）：**
- 时间复杂度：O(n)，两次全表扫描
- 空间复杂度：O(1)

**方法三（窗口函数）：**
- 时间复杂度：O(n log n)，排序开销
- 空间复杂度：O(n)，存储排名结果

**方法四（自连接）：**
- 时间复杂度：O(n²)，对每行都需要统计
- 空间复杂度：O(1)

## 关键点总结

1. **去重很重要**：必须使用 `DISTINCT`，否则相同薪水的多个员工会影响结果
2. **处理 NULL**：使用 `IFNULL()` 或 `COALESCE()` 确保不存在时返回 `NULL`
3. **子查询技巧**：将子查询放在 `SELECT` 子句中可以直接返回单个值
4. **LIMIT 与 OFFSET**：`LIMIT 1 OFFSET 1` 等价于跳过第一条取第二条
5. **方法选择**：对于小数据集，方法二最简洁高效；大数据集建议使用方法一

## 易错点

1. **忘记去重**
   ```sql
   -- 错误：没有 DISTINCT，可能返回错误结果
   SELECT salary FROM Employee ORDER BY salary DESC LIMIT 1 OFFSET 1
   ```

2. **不处理 NULL 情况**
   ```sql
   -- 错误：不存在第二高时，返回空结果集而不是 NULL
   SELECT DISTINCT salary AS SecondHighestSalary 
   FROM Employee 
   ORDER BY salary DESC 
   LIMIT 1 OFFSET 1
   ```

3. **列名错误**
   ```sql
   -- 错误：列名必须是 SecondHighestSalary
   SELECT ... AS salary  -- 应该是 AS SecondHighestSalary
   ```

4. **比较逻辑错误**
   ```sql
   -- 方法二中，WHERE 条件必须用 <（小于），不能用 <=
   WHERE salary <= (SELECT MAX(salary) FROM Employee)  -- 错误
   ```
