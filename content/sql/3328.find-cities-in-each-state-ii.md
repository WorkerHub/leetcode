## 题目描述

表：`cities`
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| state       | varchar |
| city        | varchar |
+-------------+---------+
(state, city) 是主键。
```

找出每个州中城市数量**至少为 3 个**的州，并将这些州的城市按字母顺序拼接成一个字符串，以逗号分隔。

返回：`state`、城市数量 `cities_count`、城市列表 `cities`（字母顺序逗号分隔）。

按 `cities_count` 降序，若相同按 `state` 升序排列。

## 解题思路

1. 按 `state` 分组，统计城市数量。
2. 过滤城市数 >= 3 的州。
3. 使用 `GROUP_CONCAT` 将城市按字母序拼接。
4. 排序输出。

## 代码实现

```sql
SELECT
    state,
    COUNT(city) AS cities_count,
    GROUP_CONCAT(city ORDER BY city ASC SEPARATOR ', ') AS cities
FROM cities
GROUP BY state
HAVING COUNT(city) >= 3
ORDER BY cities_count DESC, state ASC;
```

### PostgreSQL 版本（使用 STRING_AGG）

```sql
SELECT
    state,
    COUNT(city) AS cities_count,
    STRING_AGG(city, ', ' ORDER BY city ASC) AS cities
FROM cities
GROUP BY state
HAVING COUNT(city) >= 3
ORDER BY cities_count DESC, state ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组和排序
- 空间复杂度：O(n)

## 关键点总结

1. `GROUP_CONCAT(city ORDER BY city ASC SEPARATOR ', ')` 是 MySQL 中按顺序拼接字符串的函数。
2. `HAVING COUNT(city) >= 3` 过滤满足条件的分组。
3. 多级排序：先按城市数降序，再按州名升序。

## 易错点

1. `GROUP_CONCAT` 中必须指定排序方向（`ORDER BY city ASC`）。
2. 分隔符是 `, `（逗号加空格），不只是逗号。
3. `HAVING` 子句用于过滤分组，不能用 `WHERE`。
