## 题目描述

表：`Logs`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| log_id        | int     |
+---------------+---------+
log_id 是该表的主键（值唯一）。
该表的每一行包含日志表中的一个 ID。
```

编写 SQL 查询，找出 `Logs` 表中每个连续数字范围的**起始**和**结束**编号（`start_id` 和 `end_id`），结果按 `start_id` **升序排列**。

**示例：**

```
Logs 表：
+------------+
| log_id     |
+------------+
| 1          |
| 2          |
| 3          |
| 7          |
| 8          |
| 10         |
+------------+

Result 表：
+------------+--------------+
| start_id   | end_id       |
+------------+--------------+
| 1          | 3            |
| 7          | 8            |
| 10         | 10           |
+------------+--------------+
连续数字 1, 2, 3 形成了范围 [1, 3]。
连续数字 7, 8 形成了范围 [7, 8]。
10 单独形成了范围 [10, 10]。
```

---

## 解题思路

### 核心技巧：差值分组法（Islands and Gaps）

这是一道经典的"连续数字分组"问题，核心思路是：

**如果一组数字是连续的，那么每个数字与其行号之间的差值（`log_id - ROW_NUMBER()`）是相同的常数。**

**为什么？**

考虑连续数字序列 1, 2, 3（按行号 1, 2, 3 排列）：
```
log_id  ROW_NUMBER()  差值
1       1             0
2       2             0
3       3             0
```

考虑不连续序列 1, 2, 7, 8（按行号 1, 2, 3, 4 排列）：
```
log_id  ROW_NUMBER()  差值
1       1             0
2       2             0
7       3             4
8       4             4
```

同一个连续段内，差值相同；不同连续段，差值不同。因此可以按差值分组，每组即为一个连续范围。

**三步法：**
1. 使用窗口函数 `ROW_NUMBER()` 为每行编号（按 log_id 升序）。
2. 计算每行的 `log_id - ROW_NUMBER()` 作为分组键 `grp`。
3. 按 `grp` 分组，取每组的 `MIN(log_id)` 和 `MAX(log_id)` 作为起始和结束。

---

## SQL 解法

### 方法一：窗口函数 ROW_NUMBER()（推荐，标准解法）

```sql
SELECT
    MIN(log_id) AS start_id,
    MAX(log_id) AS end_id
FROM (
    SELECT
        log_id,
        -- log_id 减去其行号，相同差值的行属于同一连续段
        log_id - ROW_NUMBER() OVER (ORDER BY log_id) AS grp
    FROM Logs
) t
GROUP BY grp
ORDER BY start_id;
```

**执行过程（以示例数据为例）：**

```
子查询结果：
log_id  ROW_NUMBER()  grp (差值)
1       1             0
2       2             0
3       3             0
7       4             3
8       5             3
10      6             4

按 grp 分组后：
grp=0: MIN=1, MAX=3  -> (1, 3)
grp=3: MIN=7, MAX=8  -> (7, 8)
grp=4: MIN=10, MAX=10 -> (10, 10)
```

### 方法二：自连接（不使用窗口函数）

```sql
-- 找出所有"起始编号"：没有前一个连续数的编号
-- 找出所有"结束编号"：没有后一个连续数的编号
-- 将两者配对

SELECT
    l1.log_id AS start_id,
    MIN(l2.log_id) AS end_id
FROM Logs l1
JOIN Logs l2 ON l1.log_id <= l2.log_id
-- l1 是起始点：log_id - 1 不在表中（即没有前驱）
WHERE NOT EXISTS (
    SELECT 1 FROM Logs l3 WHERE l3.log_id = l1.log_id - 1
)
-- l2 是结束点：log_id + 1 不在表中（即没有后继）
AND NOT EXISTS (
    SELECT 1 FROM Logs l4 WHERE l4.log_id = l2.log_id + 1
)
GROUP BY l1.log_id
ORDER BY start_id;
```

**注意：** 方法二效率较低（多次子查询），仅用于理解思路。在大数据量时应优先使用方法一。

### 方法三：LAG 窗口函数（另一种思路）

```sql
-- 利用 LAG 找出每个连续段的开始和结束

WITH ranked AS (
    SELECT
        log_id,
        -- 与前一行的差值：若为 1 则连续，否则是新段的开始
        LAG(log_id, 1, log_id - 1) OVER (ORDER BY log_id) AS prev_id
    FROM Logs
),
-- 标记每个连续段的段号
segments AS (
    SELECT
        log_id,
        SUM(CASE WHEN log_id - prev_id > 1 THEN 1 ELSE 0 END)
            OVER (ORDER BY log_id) AS seg_id
    FROM ranked
)
SELECT
    MIN(log_id) AS start_id,
    MAX(log_id) AS end_id
FROM segments
GROUP BY seg_id
ORDER BY start_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| ROW_NUMBER() | O(n log n) | O(n) |
| 自连接 | O(n²) | O(1) |
| LAG | O(n log n) | O(n) |

- 方法一和三使用窗口函数，排序后线性扫描，时间复杂度 O(n log n)。
- 方法二（自连接）在大数据量下性能差，不推荐生产使用。

## 关键点总结

1. **差值分组法**（`value - ROW_NUMBER()`）是处理"连续数字分组"问题的标准模式，务必记住。
2. **ROW_NUMBER()** 是 SQL 窗口函数，按指定顺序为每行分配唯一的连续整数编号（从 1 开始）。
3. **连续性判断**：连续数字的特点是相邻两数差为 1，而行号也差 1，所以差值恒定。
4. 最终用 `MIN()` 和 `MAX()` 获取每组的起止值，这是聚合函数的标准用法。
5. `ORDER BY start_id` 在最外层确保结果按起始值升序输出。

---

## 易错点

1. **ROW_NUMBER() 必须加 ORDER BY**：`ROW_NUMBER() OVER (ORDER BY log_id)` 的 `ORDER BY` 不可省略，否则行号顺序不确定，差值分组会出错。
2. **差值可能为负**：如果 log_id 不是正整数，差值可能为负，但 GROUP BY 仍然有效（负数也是常数）。
3. **单元素的范围**：一个孤立的数字自成一个范围，`MIN = MAX = log_id`，查询结果中 `start_id = end_id`，这是正确的，不需要特殊处理。
4. **方法二的性能陷阱**：自连接在数据量大时会产生笛卡尔积，时间复杂度 O(n²)，实际应用中应避免。

## 学习建议

这道题是 SQL 中"**岛屿与间隙**"（Islands and Gaps）问题的经典代表：

1. **理解 ROW_NUMBER() 窗口函数**：它是 SQL 进阶必备知识，与 RANK()、DENSE_RANK()、LAG()、LEAD() 等窗口函数一起构成 SQL 分析的核心工具集。

2. **差值分组法**：`value - ROW_NUMBER()` 这个技巧非常经典，值得专门记忆和练习，在很多"连续"相关的 SQL 题中都会用到。

3. **与 Python 对比**：这道题如果用 Python 解，可以遍历排序后的数组，检查相邻差值是否为 1 来分组。SQL 的窗口函数将这一逻辑优雅地表达为声明式查询。
