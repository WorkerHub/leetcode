## 题目描述

表 `Products` 结构如下：

| Column Name | Type |
|-------------|------|
| product_id  | int  |
| price       | int  |

`product_id` 是主键。

表 `Purchases` 结构如下：

| Column Name | Type |
|-------------|------|
| invoice_id  | int  |
| product_id  | int  |
| quantity    | int  |

`(invoice_id, product_id)` 是主键。

查询**金额最大**的发票（invoice）的所有明细（product_id, quantity, price）。若金额相同则取 invoice_id 最大的。

价格 = quantity * price。每张发票的总金额为其所有商品的金额之和。

返回 `product_id`、`quantity`、`price`（单行总价 = quantity * price）。

## 解题思路

1. 计算每张发票的总金额。
2. 找出金额最大（若相同取 invoice_id 最大）的发票。
3. 返回该发票的所有明细。

## 代码实现

### 方法一：子查询 + CTE（推荐）

```sql
WITH invoice_total AS (
    SELECT 
        p.invoice_id,
        SUM(p.quantity * pr.price) AS total
    FROM Purchases p
    JOIN Products pr ON p.product_id = pr.product_id
    GROUP BY p.invoice_id
),
best_invoice AS (
    SELECT invoice_id
    FROM invoice_total
    WHERE total = (SELECT MAX(total) FROM invoice_total)
    ORDER BY invoice_id DESC
    LIMIT 1
)
SELECT 
    p.product_id,
    p.quantity,
    p.quantity * pr.price AS price
FROM Purchases p
JOIN Products pr ON p.product_id = pr.product_id
WHERE p.invoice_id = (SELECT invoice_id FROM best_invoice)
```

### 方法二：窗口函数

```sql
WITH invoice_detail AS (
    SELECT 
        p.invoice_id,
        p.product_id,
        p.quantity,
        p.quantity * pr.price AS price,
        SUM(p.quantity * pr.price) OVER (PARTITION BY p.invoice_id) AS total
    FROM Purchases p
    JOIN Products pr ON p.product_id = pr.product_id
),
ranked AS (
    SELECT *,
           RANK() OVER (ORDER BY total DESC, invoice_id DESC) AS rk
    FROM invoice_detail
)
SELECT product_id, quantity, price
FROM ranked
WHERE rk = 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| CTE + 子查询 | O(n log n) | O(n) |
| 窗口函数 | O(n log n) | O(n) |

## 关键点总结

1. 先按发票聚合计算总金额，找出最大金额的发票。
2. 当多张发票金额相同时，取 invoice_id 最大的，注意排序方向。
3. 返回该发票的所有行明细，而不是聚合后的结果。

## 易错点

- 返回的 `price` 列是单行的 `quantity * price`，不是发票总价。
- 同金额时取最大 invoice_id，注意 `ORDER BY total DESC, invoice_id DESC`。
