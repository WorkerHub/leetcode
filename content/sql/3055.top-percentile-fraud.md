## 题目描述

表：`Fraud`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| policy_id    | int     |
| state        | varchar |
| fraud_score  | int     |
+--------------+---------+
```

`policy_id` 是主键。

找出每个州中欺诈分数在**前 5%**（最高）的保险单。结果按州升序、欺诈分数降序、保险单 ID 升序排列。

## SQL 代码实现

### 方法一：NTILE 窗口函数（推荐）

```sql
WITH ranked AS (
    SELECT
        policy_id,
        state,
        fraud_score,
        NTILE(20) OVER (PARTITION BY state ORDER BY fraud_score DESC) AS tile
    FROM Fraud
)
SELECT policy_id, state, fraud_score
FROM ranked
WHERE tile = 1
ORDER BY state ASC, fraud_score DESC, policy_id ASC;
```

### 方法二：PERCENT_RANK

```sql
WITH ranked AS (
    SELECT
        policy_id,
        state,
        fraud_score,
        PERCENT_RANK() OVER (PARTITION BY state ORDER BY fraud_score DESC) AS pct_rank
    FROM Fraud
)
SELECT policy_id, state, fraud_score
FROM ranked
WHERE pct_rank < 0.05
ORDER BY state ASC, fraud_score DESC, policy_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，窗口函数排序
- 空间复杂度：O(n)

## 关键点总结

1. `NTILE(20)` 将数据分为 20 组，第 1 组即前 5%
2. `PERCENT_RANK()` 计算百分比排名，< 0.05 为前 5%
3. 按州分区（PARTITION BY state）

## 易错点

1. `NTILE` 可能不完全精确（当数据不能整除时），`PERCENT_RANK` 更准确
2. `PERCENT_RANK` 最小值为 0（排名第一），故用 `< 0.05` 而非 `<= 0.05`
