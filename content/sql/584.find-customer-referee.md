## 题目描述

找出那些推荐人不是 id = 2 的客户。

## SQL 代码实现

```sql
SELECT name
FROM Customer
WHERE referee_id != 2 OR referee_id IS NULL;
```

## 关键点总结

1. **NULL处理**：NULL != 2 返回 NULL（不是TRUE）
2. **OR条件**：需要同时考虑 != 2 和 IS NULL

## 学习建议

理解NULL的三值逻辑，掌握NULL的比较。
