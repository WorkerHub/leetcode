## 题目描述

表 `Terms`：

```
+----------+------+
| Column   | Type |
+----------+------+
| power    | int  |
| factor   | int  |
+----------+------+
```

`power` 是该表的主键，`power >= 0`，`factor != 0`。

方程的形式为：
`"<term1> + <term2> + ... + <termN> = 0"`

其中每一项形如 `factor * X^power`，按 **power 降序**排列。

格式规则：
- 指数为 0：只写系数（如 `2`，不写 `X^0`）。
- 指数为 1：只写 `X`（如 `2*X`，不写 `X^1`）。
- 系数为 1 且指数 > 0：不写 `1*`（如 `X^2`，不写 `1*X^2`）。
- 系数为 -1 且指数 > 0：只写 `-`（如 `-X^2`，不写 `-1*X^2`）。
- 符号：各项之间用 ` + ` 连接，每项的系数若为负，则包含负号（如 `-2*X^2`）。

**示例：**
```
Terms 表：
+-------+--------+
| power | factor |
+-------+--------+
| 2     | 1      |
| 1     | -4     |
| 0     | 2      |
+-------+--------+
输出：
+------------------------+
| equation               |
+------------------------+
| X^2 - 4*X + 2 = 0     |
+------------------------+
```

## 解题思路

**字符串拼接 + CASE WHEN 处理各种格式规则**

1. 按 power 降序排列。
2. 对每一项，按规则生成字符串：
   - power = 0：只输出 factor。
   - power = 1：输出 `factor*X`（但 factor 为 1 时输出 X，-1 时输出 -X）。
   - power > 1：输出 `factor*X^power`（factor 为 ±1 时特殊处理）。
3. 用 `GROUP_CONCAT` 将所有项拼接，再在末尾加上 ` = 0`。

## 代码实现

### 方法一：CASE WHEN + GROUP_CONCAT（MySQL）

```sql
SELECT CONCAT(
    GROUP_CONCAT(
        CASE
            -- power = 0：只写系数
            WHEN power = 0 THEN CAST(factor AS CHAR)
            -- power = 1
            WHEN power = 1 THEN
                CASE
                    WHEN factor = 1 THEN 'X'
                    WHEN factor = -1 THEN '-X'
                    ELSE CONCAT(CAST(factor AS CHAR), '*X')
                END
            -- power > 1
            ELSE
                CASE
                    WHEN factor = 1 THEN CONCAT('X^', CAST(power AS CHAR))
                    WHEN factor = -1 THEN CONCAT('-X^', CAST(power AS CHAR))
                    ELSE CONCAT(CAST(factor AS CHAR), '*X^', CAST(power AS CHAR))
                END
        END
        ORDER BY power DESC
        SEPARATOR ' + '
    ),
    ' = 0'
) AS equation
FROM Terms;
```

### 方法二：子查询生成每项字符串

```sql
WITH term_strings AS (
    SELECT
        power,
        CASE
            WHEN power = 0 THEN CAST(factor AS CHAR)
            WHEN power = 1 AND factor = 1 THEN 'X'
            WHEN power = 1 AND factor = -1 THEN '-X'
            WHEN power = 1 THEN CONCAT(factor, '*X')
            WHEN factor = 1 THEN CONCAT('X^', power)
            WHEN factor = -1 THEN CONCAT('-X^', power)
            ELSE CONCAT(factor, '*X^', power)
        END AS term_str
    FROM Terms
)
SELECT CONCAT(
    GROUP_CONCAT(term_str ORDER BY power DESC SEPARATOR ' + '),
    ' = 0'
) AS equation
FROM term_strings;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| GROUP_CONCAT | O(n log n) | O(n) |

## 关键点总结

1. `GROUP_CONCAT` 支持 `ORDER BY` 和 `SEPARATOR` 参数，用于按序拼接字符串。
2. CASE WHEN 处理各种特殊格式规则（系数 ±1、指数 0 或 1）。
3. 最终在结果末尾追加 ` = 0`。

## 易错点

- `factor` 为负数时，`GROUP_CONCAT` 中对应的项已包含负号（如 `-4*X`），连接符 `' + '` 不需要改为 `' - '`。
- MySQL 的 `CAST(factor AS CHAR)` 用于整数转字符串。
