## 题目描述

表 `TVProgram`：

| 列名         | 类型    |
|-------------|---------|
| program_date | date    |
| content_id   | int     |
| channel      | varchar |

`(program_date, content_id)` 是该表的主键。

表 `Content`：

| 列名          | 类型    |
|--------------|---------|
| content_id    | varchar |
| title         | varchar |
| Kids_content  | enum    |  -- ('Y','N')
| content_type  | varchar |  -- ('Movies', 'Series', ...)

`content_id` 是该表的主键。

请你编写 SQL 查询，找出在 **2020 年 6 月**播出的**儿童电影**（Kids_content = 'Y' 且 content_type = 'Movies'）的**不重复标题**。

结果以任意顺序返回。

**示例：**

```
TVProgram 表：
+--------------+------------+----------+
| program_date | content_id | channel  |
+--------------+------------+----------+
| 2020-06-10   | 1          | LC-channel|
| 2020-05-11   | 2          | LC-channel|
| 2020-05-12   | 3          | LC-channel|
| 2020-05-13   | 4          | Disney   |
| 2020-06-18   | 4          | Disney   |
| 2020-07-15   | 5          | DC-channel|
+--------------+------------+----------+

Content 表：
+------------+----------------+--------------+--------------+
| content_id | title          | Kids_content | content_type |
+------------+----------------+--------------+--------------+
| 1          | Leetcode Movie | N            | Movies       |
| 2          | Alg. for Kids  | Y            | Series       |
| 3          | Database Sols  | N            | Series       |
| 4          | Aladdin        | Y            | Movies       |
| 5          | Cinderella     | Y            | Movies       |
+------------+----------------+--------------+--------------+

Result 表：
+---------+
| title   |
+---------+
| Aladdin |
+---------+
```

## 解题思路

**SQL 思路：JOIN + WHERE 过滤 + DISTINCT 去重**

需要两个条件同时满足：
1. 在 2020 年 6 月播出：`program_date` 在 `'2020-06-01'` 到 `'2020-06-30'` 之间
2. 是儿童电影：`Kids_content = 'Y'` 且 `content_type = 'Movies'`

两个条件分别来自两张表，需要 JOIN 关联。由于同一电影可能在 6 月多次播出，用 DISTINCT 去重。

**注意：** `TVProgram.content_id` 是 int，`Content.content_id` 是 varchar，JOIN 时注意类型是否兼容（MySQL 中会隐式转换，但最好保持类型一致）。

## 代码实现

### 方法一：INNER JOIN + WHERE（标准解法，推荐）

```sql
SELECT DISTINCT c.title
FROM TVProgram t
INNER JOIN Content c ON t.content_id = c.content_id
WHERE t.program_date BETWEEN '2020-06-01' AND '2020-06-30'
  AND c.Kids_content = 'Y'
  AND c.content_type = 'Movies';
```

### 方法二：使用 YEAR 和 MONTH 函数

```sql
SELECT DISTINCT c.title
FROM TVProgram t
JOIN Content c ON t.content_id = c.content_id
WHERE YEAR(t.program_date) = 2020
  AND MONTH(t.program_date) = 6
  AND c.Kids_content = 'Y'
  AND c.content_type = 'Movies';
```

### 方法三：使用子查询

```sql
SELECT DISTINCT title
FROM Content
WHERE content_id IN (
    SELECT content_id
    FROM TVProgram
    WHERE program_date BETWEEN '2020-06-01' AND '2020-06-30'
)
AND Kids_content = 'Y'
AND content_type = 'Movies';
```

### 方法四：LEFT JOIN（保留所有内容，过滤播出记录）

```sql
SELECT DISTINCT c.title
FROM Content c
LEFT JOIN TVProgram t ON c.content_id = t.content_id
    AND t.program_date BETWEEN '2020-06-01' AND '2020-06-30'
WHERE t.content_id IS NOT NULL
  AND c.Kids_content = 'Y'
  AND c.content_type = 'Movies';
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| JOIN + WHERE | 最常用，依赖索引，通常最快 |
| 子查询 | 先缩小范围再 JOIN，在 content_id 有索引时高效 |
| LEFT JOIN | 语义略有差异，但结果等价 |

- 实际性能取决于数据量和索引建立情况
- `content_id` 和 `program_date` 建立索引可显著提升查询速度

## 关键点总结

1. **DISTINCT 去重**：同一电影可能在 6 月播出多次，需要去重标题。
2. **日期过滤**：`BETWEEN '2020-06-01' AND '2020-06-30'` 或 `YEAR()=2020 AND MONTH()=6`。
3. **多条件过滤**：Kids_content='Y' 且 content_type='Movies'，两个条件用 AND 连接。
4. **JOIN 的选择**：INNER JOIN 只返回两表都有的记录，是本题正确选择。

## 易错点

- **忘记 DISTINCT**：6 月同一电影可能多次出现，不去重会有重复标题。
- **日期范围错误**：`BETWEEN '2020-06-01' AND '2020-06-30'` 包含首尾日期，注意 BETWEEN 是闭区间。
- **大小写敏感**：MySQL 中字符串比较默认不区分大小写，但 'Y' 和 'Movies' 的大小写需与表中数据一致。
- **JOIN 条件混淆**：ON 子句指定关联条件，WHERE 子句用于过滤，不要混写。

1. 掌握 `JOIN` 的基本用法：`INNER JOIN`（交集）、`LEFT JOIN`（保留左表所有行）。
