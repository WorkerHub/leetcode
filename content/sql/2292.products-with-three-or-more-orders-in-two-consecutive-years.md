## 题目描述

表 `Orders` 包含字段：`order_id`（主键）、`product_id`、`quantity`、`purchase_date`（日期）。

找出在**两个连续年份**中每年至少有 **3** 个订单的产品，返回这些产品的 `product_id`，并按 `product_id` 升序排列。

**说明：** "两个连续年份" 意味着存在某一年 `y`，该产品在 `y` 年和 `y+1` 年各有 >= 3 个订单。

## 解题思路

**分组统计 + 自连接：**

1. 先按 `(product_id, YEAR(purchase_date))` 分组，统计每年的订单数。
2. 过滤出订单数 >= 3 的记录。
3. 自连接：找同一产品相差恰好 1 年的两条记录。

## 代码实现

### 方法一：子查询 + 自连接（推荐）

```sql
WITH yearly AS (
    SELECT
        product_id,
        YEAR(purchase_date) AS yr,
        COUNT(*) AS cnt
    FROM Orders
    GROUP BY product_id, YEAR(purchase_date)
    HAVING COUNT(*) >= 3
)
SELECT DISTINCT a.product_id
FROM yearly a
JOIN yearly b
  ON a.product_id = b.product_id
  AND b.yr = a.yr + 1
ORDER BY a.product_id;
```

### 方法二：窗口函数 LAG

```sql
WITH yearly AS (
    SELECT
        product_id,
        YEAR(purchase_date) AS yr,
        COUNT(*) AS cnt
    FROM Orders
    GROUP BY product_id, YEAR(purchase_date)
    HAVING COUNT(*) >= 3
),
with_lag AS (
    SELECT
        product_id,
        yr,
        LAG(yr) OVER (PARTITION BY product_id ORDER BY yr) AS prev_yr
    FROM yearly
)
SELECT DISTINCT product_id
FROM with_lag
WHERE yr = prev_yr + 1
ORDER BY product_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组 + 排序。
- 空间复杂度：O(k)，k 为不同 (product_id, year) 组合数。

## 关键点总结

1. 先用 `HAVING COUNT(*) >= 3` 过滤满足条件的 (产品, 年份)。
2. 自连接条件：同一产品，年份差为 1。
3. 使用 `DISTINCT` 避免重复返回同一产品（若某产品有多组连续年份）。

## 易错点

- 不要忘记 `DISTINCT`：一个产品可能在多个连续年份对中满足条件。
- `YEAR()` 函数提取年份，注意 MySQL 中的日期函数语法。
