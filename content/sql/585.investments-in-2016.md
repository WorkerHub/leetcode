## 题目描述

编写SQL查询来报告2016年（tiv_2016）所有满足下述条件的投保人的投保金额之和：
1. 2015年的投保额（tiv_2015）与其他投保人的2015年投保额相同
2. 所在城市的经纬度坐标（lat, lon）是唯一的

## SQL 代码实现

```sql
SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016
FROM Insurance
WHERE tiv_2015 IN (
    SELECT tiv_2015
    FROM Insurance
    GROUP BY tiv_2015
    HAVING COUNT(*) > 1
)
AND (lat, lon) IN (
    SELECT lat, lon
    FROM Insurance
    GROUP BY lat, lon
    HAVING COUNT(*) = 1
);
```

## 关键点总结

1. **分组过滤**：tiv_2015相同的有多个
2. **坐标唯一**：(lat,lon)只有一个
3. **四舍五入**：ROUND(SUM(), 2)

## 学习建议

掌握多条件组合查询，理解HAVING的使用。
