## 题目描述

表 `Transactions`：
```
+------------------+------+
| Column Name      | Type |
+------------------+------+
| transaction_id   | int  |
| customer_id      | int  |
| transaction_date | date |
| amount           | int  |
+------------------+------+
```
`transaction_id` 是主键。

找出拥有最多连续交易天数的客户（如有多位并列，全部返回）。结果按 `customer_id` 升序排列。

## 解题思路

1. 对每个客户找出所有不重复的交易日期
2. 用经典的"连续日期分组"技巧：`date - ROW_NUMBER()` 相同的日期属于同一连续段
3. 统计每个客户最长连续段的长度
4. 找到最大值并返回对应客户

## 代码实现

### 方法一：SQL 窗口函数（推荐）

```sql
WITH distinct_dates AS (
    -- 去除同一客户同一天的重复交易
    SELECT DISTINCT customer_id, transaction_date
    FROM Transactions
),
grouped AS (
    SELECT
        customer_id,
        transaction_date,
        -- 用日期减去行号（按客户分组、日期排序）来识别连续段
        DATE_SUB(transaction_date,
            INTERVAL ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY transaction_date) DAY
        ) AS grp
    FROM distinct_dates
),
streaks AS (
    SELECT
        customer_id,
        COUNT(*) AS streak_len
    FROM grouped
    GROUP BY customer_id, grp
),
max_streak AS (
    SELECT customer_id, MAX(streak_len) AS max_len
    FROM streaks
    GROUP BY customer_id
),
overall_max AS (
    SELECT MAX(max_len) AS global_max
    FROM max_streak
)
SELECT customer_id
FROM max_streak, overall_max
WHERE max_len = global_max
ORDER BY customer_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先去重（同客户同天多笔交易算同一天）
2. `date - row_number` 技巧识别连续日期段
3. 统计每位客户最长连续段，与全局最大值比较

## 易错点

1. 同一客户同一天可能有多笔交易，需先 DISTINCT
2. DATE_SUB 的写法因数据库不同而异
