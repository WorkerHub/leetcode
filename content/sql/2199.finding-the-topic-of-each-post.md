## 题目描述

表 `Posts`：

| 列名 | 类型 |
|------|------|
| post_id | int |
| content | varchar |

`post_id` 是该表主键。每行包含一个帖子的 id 和内容。

表 `Keywords`：

| 列名 | 类型 |
|------|------|
| topic_id | int |
| word | varchar |

`(topic_id, word)` 是该表主键。每行包含一个主题 id 和该主题对应的关键词。

编写 SQL 查询，找出每篇帖子所属的**所有**主题（按主题 id 升序排列，用逗号分隔）。若帖子不属于任何主题，则 `topic` 为 `"Ambiguous!"`。

帖子属于某主题：帖子内容中包含该主题的**至少一个**关键词（大小写不敏感）。

**提示：**
- 关键词匹配是**单词级别**（不是子字符串），即内容中的词语需要完整匹配关键词。

## 解题思路

**JOIN + GROUP_CONCAT + 正则**

将帖子内容与关键词进行匹配，使用正则确保单词级别匹配（使用 `REGEXP` 加单词边界），然后按 `post_id` 聚合所有匹配的 `topic_id`，用 `GROUP_CONCAT` 合并。未匹配到的帖子返回 `"Ambiguous!"`。

## 代码实现

### 方法一：REGEXP 单词匹配（推荐）

```sql
SELECT
    p.post_id,
    IFNULL(
        GROUP_CONCAT(DISTINCT k.topic_id ORDER BY k.topic_id ASC SEPARATOR ','),
        'Ambiguous!'
    ) AS topic
FROM Posts p
LEFT JOIN Keywords k
    ON p.content REGEXP CONCAT('(^|[^A-Za-z0-9])', k.word, '($|[^A-Za-z0-9])')
GROUP BY p.post_id
ORDER BY p.post_id;
```

### 方法二：LIKE 模糊匹配（效率较低）

```sql
-- 注意：LIKE 匹配可能有子字符串误匹配问题，但某些数据集可以接受
SELECT
    p.post_id,
    CASE
        WHEN COUNT(DISTINCT k.topic_id) = 0 THEN 'Ambiguous!'
        ELSE GROUP_CONCAT(DISTINCT k.topic_id ORDER BY k.topic_id SEPARATOR ',')
    END AS topic
FROM Posts p
LEFT JOIN Keywords k
    ON CONCAT(' ', LOWER(p.content), ' ') LIKE CONCAT('% ', LOWER(k.word), ' %')
GROUP BY p.post_id
ORDER BY p.post_id;
```

### 方法三：使用 LOCATE 和单词边界

```sql
SELECT
    p.post_id,
    IFNULL(
        GROUP_CONCAT(DISTINCT k.topic_id ORDER BY k.topic_id SEPARATOR ','),
        'Ambiguous!'
    ) AS topic
FROM Posts p
LEFT JOIN Keywords k
    ON LOWER(p.content) REGEXP CONCAT('\\b', LOWER(k.word), '\\b')
GROUP BY p.post_id;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| REGEXP | 支持单词边界，准确率高，但正则计算较慢 |
| LIKE | 简单但可能误匹配子字符串 |
| \\b 边界 | MySQL 支持 `\\b` 单词边界，最精确 |

## 关键点总结

1. 帖子匹配关键词需要**单词级别**，使用正则 `\\b` 单词边界是最准确的方式。
2. `LEFT JOIN` 保留没有匹配主题的帖子（结果为 NULL），然后用 `IFNULL` 替换为 `"Ambiguous!"`。
3. `GROUP_CONCAT(DISTINCT ... ORDER BY ... SEPARATOR ',')` 合并多个 topic_id 并去重排序。

## 易错点

- 关键词匹配区分大小写：MySQL 的 `REGEXP` 默认不区分大小写（取决于排序规则），可用 `LOWER()` 强制小写比较。
- `GROUP_CONCAT` 中需要 `DISTINCT` 去重（同一关键词可能多次匹配）。
- 注意 `SEPARATOR ','` 不含空格（题目要求格式）。
