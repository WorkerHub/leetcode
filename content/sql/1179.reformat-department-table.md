## 题目描述

表：`Department`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| revenue       | int     |
| month         | varchar |
+---------------+---------+
```

`(id, month)` 是表的联合主键。

这张表有关于每个部门每个月收入的信息。

月份（month）可以取下列值 ["Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"]。

编写一个 SQL 查询来重新格式化表，使得新的表中有一个部门 id 列和一些对应每个月的收入（revenue）列。

返回结果表可以按任意顺序排列。

查询结果格式如下面的示例所示。

示例 1：

```
输入：
Department 表：
+------+---------+-------+
| id   | revenue | month |
+------+---------+-------+
| 1    | 8000    | Jan   |
| 2    | 9000    | Jan   |
| 3    | 10000   | Feb   |
| 1    | 7000    | Feb   |
| 1    | 6000    | Mar   |
+------+---------+-------+

输出：
+------+-------------+-------------+-------------+-----+-------------+
| id   | Jan_Revenue | Feb_Revenue | Mar_Revenue | ... | Dec_Revenue |
+------+-------------+-------------+-------------+-----+-------------+
| 1    | 8000        | 7000        | 6000        | ... | null        |
| 2    | 9000        | null        | null        | ... | null        |
| 3    | null        | 10000       | null        | ... | null        |
+------+-------------+-------------+-------------+-----+-------------+
```

注意，结果表有 13 列（1 个部门 id 列 + 12 个月份的收入列）。

## 解题思路

这是一个经典的行转列（透视表/Pivot）问题。核心思想是将原本存储在 `month` 列中的值转换为新表的列名，同时将对应的 `revenue` 值填充到相应的列中。

关键步骤：

1. 按照 `id` 分组
2. 使用条件聚合（CASE WHEN）为每个月份创建一个独立的列
3. 对于每个部门，如果该月份有收入数据则显示具体数值，否则显示 NULL

这个问题的难点在于：
- 需要手动为每个月份创建一列
- 使用聚合函数（如 MAX 或 SUM）来提取符合条件的值
- 理解 CASE WHEN 与 GROUP BY 的配合使用

## SQL 代码实现

### 方法一：CASE WHEN + GROUP BY（标准解法）

```sql
SELECT 
    id,
    SUM(CASE WHEN month = 'Jan' THEN revenue ELSE NULL END) AS Jan_Revenue,
    SUM(CASE WHEN month = 'Feb' THEN revenue ELSE NULL END) AS Feb_Revenue,
    SUM(CASE WHEN month = 'Mar' THEN revenue ELSE NULL END) AS Mar_Revenue,
    SUM(CASE WHEN month = 'Apr' THEN revenue ELSE NULL END) AS Apr_Revenue,
    SUM(CASE WHEN month = 'May' THEN revenue ELSE NULL END) AS May_Revenue,
    SUM(CASE WHEN month = 'Jun' THEN revenue ELSE NULL END) AS Jun_Revenue,
    SUM(CASE WHEN month = 'Jul' THEN revenue ELSE NULL END) AS Jul_Revenue,
    SUM(CASE WHEN month = 'Aug' THEN revenue ELSE NULL END) AS Aug_Revenue,
    SUM(CASE WHEN month = 'Sep' THEN revenue ELSE NULL END) AS Sep_Revenue,
    SUM(CASE WHEN month = 'Oct' THEN revenue ELSE NULL END) AS Oct_Revenue,
    SUM(CASE WHEN month = 'Nov' THEN revenue ELSE NULL END) AS Nov_Revenue,
    SUM(CASE WHEN month = 'Dec' THEN revenue ELSE NULL END) AS Dec_Revenue
FROM Department
GROUP BY id;
```

### 方法二：使用 MAX 代替 SUM

```sql
SELECT 
    id,
    MAX(CASE WHEN month = 'Jan' THEN revenue END) AS Jan_Revenue,
    MAX(CASE WHEN month = 'Feb' THEN revenue END) AS Feb_Revenue,
    MAX(CASE WHEN month = 'Mar' THEN revenue END) AS Mar_Revenue,
    MAX(CASE WHEN month = 'Apr' THEN revenue END) AS Apr_Revenue,
    MAX(CASE WHEN month = 'May' THEN revenue END) AS May_Revenue,
    MAX(CASE WHEN month = 'Jun' THEN revenue END) AS Jun_Revenue,
    MAX(CASE WHEN month = 'Jul' THEN revenue END) AS Jul_Revenue,
    MAX(CASE WHEN month = 'Aug' THEN revenue END) AS Aug_Revenue,
    MAX(CASE WHEN month = 'Sep' THEN revenue END) AS Sep_Revenue,
    MAX(CASE WHEN month = 'Oct' THEN revenue END) AS Oct_Revenue,
    MAX(CASE WHEN month = 'Nov' THEN revenue END) AS Nov_Revenue,
    MAX(CASE WHEN month = 'Dec' THEN revenue END) AS Dec_Revenue
FROM Department
GROUP BY id;
```

## 复杂度分析

### SQL 方案

- 时间复杂度：O(n)，其中 n 是 Department 表的行数。需要扫描整个表一次，并对每一行应用 CASE WHEN 条件。
- 空间复杂度：O(m)，其中 m 是不同 id 的数量。结果表的行数等于不同部门的数量。

### Python Pandas 方案

- 时间复杂度：O(n)，其中 n 是输入 DataFrame 的行数。pivot_table 和 pivot 方法的内部实现都是线性时间复杂度。
- 空间复杂度：O(m × 12)，其中 m 是不同 id 的数量。结果表有 m 行和 13 列（1 个 id 列 + 12 个月份列）。

## 关键点总结

1. 行转列问题的本质是数据重塑，将某列的值转换为新的列名
2. SQL 中使用 CASE WHEN + GROUP BY 实现透视功能
3. Pandas 提供了多种方法：pivot、pivot_table、unstack，功能相似但细节不同
4. pivot 要求索引/列的组合唯一，pivot_table 可以处理重复值（通过聚合函数）
5. 注意处理缺失月份的情况，确保所有 12 个月的列都存在

## 易错点

1. **忘记 GROUP BY**：使用聚合函数（SUM、MAX）时必须配合 GROUP BY，否则会报错
2. **月份列顺序错误**：结果应该按照时间顺序排列月份，而不是字母顺序
3. **NULL 处理**：CASE WHEN 的 ELSE 分支应该返回 NULL 而不是 0，因为 NULL 表示该月没有数据，0 表示收入为 0
4. **SUM vs MAX**：
   - 如果每个部门每个月只有一条记录，SUM 和 MAX 效果相同
   - 如果可能有重复记录，SUM 会累加，MAX 取最大值
   - 本题中两者都可以，但语义上 MAX 更合适（因为题目说是联合主键，不会重复）
5. **Pandas 中 pivot vs pivot_table**：
   - pivot 不允许重复的索引/列组合
   - pivot_table 允许重复，会使用聚合函数处理
   - 如果数据保证唯一性，优先使用 pivot（性能更好）

## 学习建议

1. **理解数据重塑的概念**：
   - 长格式（Long Format）：多行，每行一个观测值
   - 宽格式（Wide Format）：少行多列，每列一个维度
   - 行转列是从长格式到宽格式的转换

2. **掌握 SQL 透视技巧**：
   - 熟练使用 CASE WHEN 进行条件判断
   - 理解聚合函数在分组中的作用
   - 某些数据库（如 SQL Server）提供 PIVOT 关键字，但 MySQL 不支持，需要手动实现

3. **熟悉 Pandas 数据重塑方法**：
   - pivot：简单快速，要求数据唯一
   - pivot_table：功能强大，支持聚合
   - stack/unstack：灵活但需要理解多级索引
   - melt：与 pivot 相反，宽格式转长格式

4. **练习建议**：
   - 先理解问题：明确输入输出格式
   - 手动模拟：在纸上画出数据转换过程
   - 逐步实现：先完成基本功能，再优化细节
   - 对比验证：用不同方法实现，比较结果是否一致
