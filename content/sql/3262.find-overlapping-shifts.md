## 题目描述

表：`EmployeeShifts`

```
+------------------+------+
| Column Name      | Type |
+------------------+------+
| employee_id      | int  |
| start_time       | time |
| end_time         | time |
+------------------+------+
```

`(employee_id, start_time)` 是主键。

编写 SQL 查询，找出每个员工的班次中**重叠**的班次对数量。

两个班次 `[s1, e1]` 和 `[s2, e2]` 重叠的条件是：`s1 < e2 AND s2 < e1`。

结果按 `employee_id` 升序，`overlapping_shifts` 降序排列。

**输出列：** `employee_id`, `overlapping_shifts`

## 解题思路

自连接：对每个员工，找所有满足重叠条件的班次对，避免重复计数（只计 i < j 的对）。

## 代码实现

```sql
SELECT
    e1.employee_id,
    COUNT(*) AS overlapping_shifts
FROM EmployeeShifts e1
JOIN EmployeeShifts e2
    ON e1.employee_id = e2.employee_id
    AND e1.start_time < e2.start_time  -- 避免重复，只算 e1 先开始的
    AND e1.end_time > e2.start_time     -- 重叠条件
GROUP BY e1.employee_id
ORDER BY e1.employee_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n^2)，自连接
- 空间复杂度：O(n)

## 关键点总结

1. 使用自连接找重叠班次对
2. 用 `e1.start_time < e2.start_time` 避免重复计数
3. 重叠条件：一个班次在另一个结束前开始

## 易错点

1. 注意只输出有重叠班次的员工（没有重叠的不显示）
2. `end_time` 时间格式可能需要特殊处理（跨午夜班次）
