## 题目描述

表 `Logins`：

| Column Name | Type     |
|-------------|----------|
| user_id     | int      |
| time_stamp  | datetime |

`(user_id, time_stamp)` 是主键。

编写 SQL 查询，找出 2020 年内每个用户的**最后一次登录时间**。

返回任意顺序的结果。

**示例：**
```
输入：
+---------+---------------------+
| user_id | time_stamp          |
+---------+---------------------+
| 6       | 2020-06-30 15:06:07 |
| 6       | 2021-04-21 14:06:06 |
| 6       | 2019-03-07 00:18:15 |
| 8       | 2020-02-01 05:10:53 |
| 8       | 2020-12-30 00:46:50 |
| 2       | 2020-01-16 02:49:50 |
| 2       | 2019-08-25 07:59:08 |
| 14      | 2019-07-14 09:00:00 |
| 14      | 2021-01-06 11:59:59 |
+----------+--------------------+
输出：
+---------+---------------------+
| user_id | last_stamp          |
+---------+---------------------+
| 6       | 2020-06-30 15:06:07 |
| 8       | 2020-12-30 00:46:50 |
| 2       | 2020-01-16 02:49:50 |
+---------+---------------------+
```

## 解题思路

过滤出 2020 年的登录记录，按 user_id 分组，取最大 time_stamp。

## 代码实现

### 方法一：WHERE + GROUP BY（推荐）

```sql
SELECT user_id, MAX(time_stamp) AS last_stamp
FROM Logins
WHERE YEAR(time_stamp) = 2020
GROUP BY user_id;
```

### 方法二：BETWEEN 范围过滤

```sql
SELECT user_id, MAX(time_stamp) AS last_stamp
FROM Logins
WHERE time_stamp BETWEEN '2020-01-01' AND '2020-12-31 23:59:59'
GROUP BY user_id;
```

## 复杂度分析

- **时间复杂度**：O(n)，扫描并分组
- **空间复杂度**：O(m)，m 为用户数

## 关键点总结

1. `YEAR(time_stamp) = 2020` 过滤出 2020 年的记录
2. `MAX(time_stamp)` 取最晚时间
3. 按 user_id 分组

## 易错点

- 结果列名为 `last_stamp`，注意别名
- 只返回 2020 年有登录记录的用户
