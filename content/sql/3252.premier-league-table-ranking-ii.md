## 题目描述

表：`SeasonStats`

```
+-----------------+---------+
| Column Name     | Type    |
+-----------------+---------+
| season_id       | int     |
| team_id         | int     |
| team_name       | varchar |
| matches_played  | int     |
| wins            | int     |
| draws           | int     |
| losses          | int     |
+-----------------+---------+
```

`(season_id, team_id)` 是该表主键。

编写 SQL 查询：对每个赛季，按积分排名，积分相同则按 `team_name` 升序。若某队排名与上一赛季相比**提升**，标记 `'Up'`；**下降**标记 `'Down'`；**不变**标记 `'Same'`；第一赛季标记 `'N/A'`。

结果包含：`season_id`, `team_id`, `team_name`, `position`, `movement`

按 `season_id` 升序，`position` 升序。

## 解题思路

先计算每个赛季每支球队的积分和排名，再用 LAG 窗口函数获取上一赛季的排名进行比较。

## 代码实现

```sql
WITH ranked AS (
    SELECT
        season_id,
        team_id,
        team_name,
        wins * 3 + draws AS points,
        RANK() OVER (
            PARTITION BY season_id
            ORDER BY wins * 3 + draws DESC, team_name ASC
        ) AS position
    FROM SeasonStats
),
with_prev AS (
    SELECT
        season_id,
        team_id,
        team_name,
        position,
        LAG(position) OVER (
            PARTITION BY team_id
            ORDER BY season_id
        ) AS prev_position
    FROM ranked
)
SELECT
    season_id,
    team_id,
    team_name,
    position,
    CASE
        WHEN prev_position IS NULL THEN 'N/A'
        WHEN position < prev_position THEN 'Up'
        WHEN position > prev_position THEN 'Down'
        ELSE 'Same'
    END AS movement
FROM with_prev
ORDER BY season_id ASC, position ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先用 RANK() 计算每赛季排名
2. 用 LAG() 获取同一球队上一赛季的排名
3. 比较排名变化：排名数字减小表示提升（Up）

## 易错点

1. 排名提升是 position 减小（排名数字越小越靠前）
2. 第一赛季无前一赛季，LAG 返回 NULL，对应 'N/A'
3. PARTITION BY team_id 按球队分窗口，ORDER BY season_id 按时间排
