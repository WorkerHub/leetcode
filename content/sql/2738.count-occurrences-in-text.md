## 题目描述

表 `Files`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| file_name   | varchar |
| content     | text    |
+-------------+---------+
```
`file_name` 是主键。每行包含文件名和文件内容。

统计内容中包含单词 `"bull"` 的文件数量，以及包含单词 `"bear"` 的文件数量。

**注意：** 单词前后必须有空格（如 `" bull "` 或行首/行尾）。可以假设单词不出现在句子开头或结尾（即前后均有空格）。

输出：一行包含 `word` 和 `count` 的结果，分别对应 bull 和 bear 的计数。

## 解题思路

使用 SQL 的 `LIKE` 或字符串函数检查内容中是否包含以空格包围的目标单词。

## 代码实现

### 方法一：SQL LIKE 子句（推荐）

```sql
SELECT 'bull' AS word,
       COUNT(*) AS count
FROM Files
WHERE content LIKE '% bull %'

UNION ALL

SELECT 'bear' AS word,
       COUNT(*) AS count
FROM Files
WHERE content LIKE '% bear %';
```

### 方法二：使用 REGEXP

```sql
SELECT 'bull' AS word, COUNT(*) AS count
FROM Files
WHERE content REGEXP '\\bbull\\b'
UNION ALL
SELECT 'bear' AS word, COUNT(*) AS count
FROM Files
WHERE content REGEXP '\\bbear\\b';
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为行数，L 为内容平均长度
- 空间复杂度：O(1)

## 关键点总结

1. 单词前后需要有空格，使用 `% bull %` 匹配
2. `UNION ALL` 合并两个查询结果

## 易错点

1. 不要用 `LIKE '%bull%'`，会匹配到 `"bullet"` 等包含 bull 的其他单词
2. `UNION ALL` 保留重复行，`UNION` 去重（这里用 ALL 更准确）
