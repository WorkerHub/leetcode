## 题目描述

表 `Flights`：

```
+------------------+----------+
| Column Name      | Type     |
+------------------+----------+
| departure_airport| int      |
| arrival_airport  | int      |
| flights_count    | int      |
+------------------+----------+
```

`(departure_airport, arrival_airport)` 是该表的主键。
每行表示从 `departure_airport` 到 `arrival_airport` 有 `flights_count` 架次航班。

编写 SQL，找出流量最多的机场（进出港航班数之和最大的机场）。

如果有多个机场并列最高，则**全部返回**，可以以任意顺序返回。

**示例：**
```
输入：
Flights 表：
+-------------------+-----------------+--------------+
| departure_airport | arrival_airport | flights_count|
+-------------------+-----------------+--------------+
| 1                 | 2               | 4            |
| 2                 | 1               | 5            |
| 2                 | 4               | 5            |
+-------------------+-----------------+--------------+
输出：
+----------+
| airport  |
+----------+
| 2        |
+----------+
解释：机场 1：进出港 4+5=9；机场 2：进出港 4+5+5=14；机场 4：5。机场 2 最大。
```

## 解题思路

**UNION ALL 合并进出港 + 分组求和**

将出发机场和到达机场都看作"经过"的机场，用 `UNION ALL` 合并，再按机场分组求 `flights_count` 之和，最后取最大值的机场。

## 代码实现

### 方法一：UNION ALL + GROUP BY（推荐）

```sql
WITH airport_traffic AS (
    -- 合并出发和到达记录
    SELECT departure_airport AS airport, flights_count
    FROM Flights
    UNION ALL
    SELECT arrival_airport AS airport, flights_count
    FROM Flights
),
traffic_sum AS (
    -- 按机场求总流量
    SELECT airport, SUM(flights_count) AS total
    FROM airport_traffic
    GROUP BY airport
)
-- 返回流量最大的机场（可能多个）
SELECT airport
FROM traffic_sum
WHERE total = (SELECT MAX(total) FROM traffic_sum);
```

### 方法二：RANK() 窗口函数

```sql
WITH traffic AS (
    SELECT airport, SUM(flights_count) AS total
    FROM (
        SELECT departure_airport AS airport, flights_count FROM Flights
        UNION ALL
        SELECT arrival_airport AS airport, flights_count FROM Flights
    ) t
    GROUP BY airport
)
SELECT airport
FROM (
    SELECT airport, RANK() OVER (ORDER BY total DESC) AS rk
    FROM traffic
) ranked
WHERE rk = 1;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| UNION ALL | O(n log n) | O(n) |

## 关键点总结

1. 用 `UNION ALL` 而非 `UNION`：需要保留重复行（同一机场可能多次出现）。
2. 最大值比较用子查询 `WHERE total = (SELECT MAX(...))` 处理并列情况。
3. 窗口函数 `RANK()` 同样可以处理并列（`RANK` 而非 `ROW_NUMBER`）。

## 易错点

- 使用 `UNION` 会去重，导致相同 flights_count 的记录被合并，结果错误。
- 只取 `LIMIT 1` 会漏掉并列最大的情况。
