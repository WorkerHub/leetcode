## 题目描述

表 `Sales` 结构如下：

| Column Name | Type  |
|-------------|-------|
| sale_id     | int   |
| product_id  | int   |
| user_id     | int   |
| quantity    | int   |

`sale_id` 是该表的主键。

表 `Product` 结构如下：

| Column Name | Type    |
|-------------|---------|
| product_id  | int     |
| price       | int     |

`product_id` 是该表的主键。

查询每个用户**花费最多**的产品（可能有多个产品花费相同的最高金额）。返回 `user_id` 和 `product_id`，按任意顺序排列。

花费 = `quantity * price`。

## 解题思路

1. 先计算每个用户在每个产品上的总花费（JOIN + SUM）。
2. 找出每个用户的最大花费。
3. 返回等于最大花费的产品记录。

## 代码实现

### 方法一：子查询 + GROUP BY（推荐）

```sql
WITH user_product_spend AS (
    SELECT 
        s.user_id,
        s.product_id,
        SUM(s.quantity * p.price) AS total_spend
    FROM Sales s
    JOIN Product p ON s.product_id = p.product_id
    GROUP BY s.user_id, s.product_id
),
user_max_spend AS (
    SELECT user_id, MAX(total_spend) AS max_spend
    FROM user_product_spend
    GROUP BY user_id
)
SELECT 
    ups.user_id,
    ups.product_id
FROM user_product_spend ups
JOIN user_max_spend ums 
    ON ups.user_id = ums.user_id 
    AND ups.total_spend = ums.max_spend
```

### 方法二：窗口函数 RANK()

```sql
SELECT user_id, product_id
FROM (
    SELECT 
        s.user_id,
        s.product_id,
        SUM(s.quantity * p.price) AS total_spend,
        RANK() OVER (
            PARTITION BY s.user_id 
            ORDER BY SUM(s.quantity * p.price) DESC
        ) AS rk
    FROM Sales s
    JOIN Product p ON s.product_id = p.product_id
    GROUP BY s.user_id, s.product_id
) t
WHERE rk = 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 子查询 | O(n log n) | O(n) |
| 窗口函数 | O(n log n) | O(n) |

## 关键点总结

1. 每个用户在每个产品上的总花费需要先 GROUP BY (user_id, product_id) 求和。
2. 使用 RANK() 可以同时处理多个产品花费相同最高金额的情况。
3. WITH CTE 语法让查询更易读。

## 易错点

- 花费是 `quantity * price` 的**总和**，同一用户可能多次购买同一产品。
- 题目要求返回所有花费最多的产品（可能多个），使用 RANK 而非 ROW_NUMBER。
