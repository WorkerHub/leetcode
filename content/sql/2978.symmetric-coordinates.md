## 题目描述

本题为数据库题目。

给定表 `Coordinates`：
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| X           | int  |
| Y           | int  |
+-------------+------+
```

（X, Y）是主键。

若存在坐标 `(Y, X)`（即两个坐标互换），则称 `(X, Y)` 和 `(Y, X)` 是一对对称坐标，且 `X != Y`。

从每对对称坐标中选 X < Y 的那个，返回这些坐标，按 X 升序排列。

**示例：**
```
输入：
Coordinates 表：
+----+----+
| X  | Y  |
+----+----+
| 20 | 20 |
| 20 | 30 |
| 30 | 20 |
+----+----+
输出：
+----+----+
| X  | Y  |
+----+----+
| 20 | 30 |
+----+----+
```

## 解题思路

自连接：将 Coordinates 与自身连接，条件 `a.X = b.Y AND a.Y = b.X AND a.X < a.Y`，找到所有满足条件的行。

## SQL 代码实现

### 方法一：自连接（推荐）

```sql
SELECT a.X, a.Y
FROM Coordinates a
JOIN Coordinates b ON a.X = b.Y AND a.Y = b.X
WHERE a.X < a.Y
ORDER BY a.X;
```

### 方法二：EXISTS 子查询

```sql
SELECT X, Y
FROM Coordinates c
WHERE X < Y
  AND EXISTS (
    SELECT 1
    FROM Coordinates
    WHERE X = c.Y AND Y = c.X
  )
ORDER BY X;
```

## 复杂度分析

- 时间复杂度：O(n^2)，自连接
- 空间复杂度：O(n)

## 关键点总结

1. 对称坐标对：(X, Y) 和 (Y, X) 互为对称
2. 条件 X != Y（X < Y 自然排除了 X == Y）
3. 每对只取 X < Y 的那个，避免重复

## 易错点

1. WHERE a.X < a.Y 过滤掉 X >= Y 的情况
2. 使用 JOIN 需要确保不漏掉任何对
