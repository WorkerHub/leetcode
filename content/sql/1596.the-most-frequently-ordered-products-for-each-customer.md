## 题目描述

表 `Customers`：`customer_id`（主键），`name`

表 `Orders`：`order_id`（主键），`order_date`，`customer_id`，`product_id`

表 `Products`：`product_id`（主键），`product_name`，`price`

查找每位顾客最常订购的商品（可能多个），返回 `customer_id`，`product_id`，`product_name`，按任意顺序返回。

**示例：**

Orders 表：
```
order_id | customer_id | product_id
1        | 1           | 1
2        | 1           | 2
3        | 1           | 3
4        | 2           | 1
5        | 2           | 2
6        | 3           | 5
```

输出：
```
customer_id | product_id | product_name
1           | 1          | keyboard
1           | 2          | mouse
1           | 3          | screen
2           | 1          | keyboard
2           | 2          | mouse
3           | 5          | headphone
```

## 解题思路

### 分组统计 + 窗口函数

**步骤：**
1. 按 `(customer_id, product_id)` 分组，统计每位顾客对每件商品的订购次数
2. 用 `RANK()` 或子查询找出每位顾客的最大订购次数
3. 筛选出等于最大次数的商品，关联 Products 表获取商品名

## 代码实现

### 方法一：窗口函数 RANK()（推荐）

```sql
SELECT o.customer_id, o.product_id, p.product_name
FROM (
    SELECT
        customer_id,
        product_id,
        COUNT(*) AS cnt,
        RANK() OVER (PARTITION BY customer_id ORDER BY COUNT(*) DESC) AS rk
    FROM Orders
    GROUP BY customer_id, product_id
) o
JOIN Products p ON o.product_id = p.product_id
WHERE o.rk = 1
ORDER BY o.customer_id, o.product_id;
```

### 方法二：子查询 MAX（兼容性更好）

```sql
SELECT a.customer_id, a.product_id, p.product_name
FROM (
    SELECT customer_id, product_id, COUNT(*) AS cnt
    FROM Orders
    GROUP BY customer_id, product_id
) a
JOIN (
    SELECT customer_id, MAX(cnt) AS max_cnt
    FROM (
        SELECT customer_id, product_id, COUNT(*) AS cnt
        FROM Orders
        GROUP BY customer_id, product_id
    ) t
    GROUP BY customer_id
) b ON a.customer_id = b.customer_id AND a.cnt = b.max_cnt
JOIN Products p ON a.product_id = p.product_id
ORDER BY a.customer_id, a.product_id;
```

### 方法三：HAVING 过滤（简洁）

```sql
SELECT a.customer_id, a.product_id, p.product_name
FROM (
    SELECT customer_id, product_id, COUNT(*) AS cnt
    FROM Orders
    GROUP BY customer_id, product_id
) a
JOIN Products p ON a.product_id = p.product_id
WHERE a.cnt = (
    SELECT MAX(cnt)
    FROM (
        SELECT customer_id, product_id, COUNT(*) AS cnt
        FROM Orders
        GROUP BY customer_id, product_id
    ) t
    WHERE t.customer_id = a.customer_id
)
ORDER BY a.customer_id, a.product_id;
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为订单数
- **空间复杂度**：O(N)

## 关键点总结

1. 先 GROUP BY `(customer_id, product_id)` 统计次数
2. 再按顾客找最大次数
3. 筛选等于最大次数的记录，关联商品名

## 易错点

- 每位顾客最常订购的商品可能不止一个（并列），需要全部返回
- `RANK()` 在并列时都返回 1，适合此场景（不能用 `ROW_NUMBER()`）
