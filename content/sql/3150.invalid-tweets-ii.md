## 题目描述

表：`Tweets`

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| tweet_id       | int     |
| content        | varchar |
+----------------+---------+
```

`tweet_id` 是该表的主键。

如果一条推文满足以下任意条件，则视为 **无效**：
- 内容超过 140 个字符
- 含有超过 3 个提及（`@username` 格式，每个提及以 `@` 开头后跟若干非空格字符）
- 含有超过 3 个话题标签（`#tag` 格式）

返回所有无效推文的 `tweet_id`，按 `tweet_id` 升序排列。

## 解题思路

对每条推文：
1. 用 `CHAR_LENGTH` 检查长度
2. 用 `REGEXP_COUNT` 或字符替换技巧统计 `@` 和 `#` 的个数

## 代码实现

### 方法一：正则统计（推荐）

```sql
SELECT tweet_id
FROM Tweets
WHERE
    CHAR_LENGTH(content) > 140
    OR (CHAR_LENGTH(content) - CHAR_LENGTH(REPLACE(content, '@', ''))) > 3
    OR (CHAR_LENGTH(content) - CHAR_LENGTH(REPLACE(content, '#', ''))) > 3
ORDER BY tweet_id;
```

### 方法二：MySQL 8.0 REGEXP_COUNT

```sql
SELECT tweet_id
FROM Tweets
WHERE
    CHAR_LENGTH(content) > 140
    OR REGEXP_COUNT(content, '@[^ ]+') > 3
    OR REGEXP_COUNT(content, '#[^ ]+') > 3
ORDER BY tweet_id;
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为推文数，L 为平均长度
- 空间复杂度：O(1)

## 关键点总结

1. 统计 `@` 数量：用 `CHAR_LENGTH(content) - CHAR_LENGTH(REPLACE(content, '@', ''))`
2. 类似方法统计 `#` 数量
3. 三个条件满足任意一个即无效

## 易错点

1. 注意提及和话题标签是 "超过 3 个"（> 3），不是 >= 3
2. CHAR_LENGTH 统计字符数，不是字节数
