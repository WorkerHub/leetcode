## 题目描述

表：`Sales`

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
(sale_id, year) 是该表的主键。
product_id 是 Product 表的外键。
该表的每一行表示：在某一年，售出了一些数量的某产品。
```

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
+--------------+---------+
product_id 是该表的主键。
该表的每一行表示每个产品的产品名称。
```

编写 SQL 查询，按产品 ID（`product_id`）分组，查询每个产品的总销售数量（`total_quantity`）。

返回结果表**无顺序要求**。

**示例：**

输入：
```
Sales 表：
+---------+------------+------+----------+-------+
| sale_id | product_id | year | quantity | price |
+---------+------------+------+----------+-------+
| 1       | 100        | 2008 | 10       | 5000  |
| 2       | 100        | 2009 | 12       | 5000  |
| 7       | 200        | 2011 | 15       | 9000  |
+---------+------------+------+----------+-------+

Product 表：
+------------+--------------+
| product_id | product_name |
+------------+--------------+
| 100        | Nokia        |
| 200        | Apple        |
| 300        | Samsung      |
+------------+--------------+
```

输出：
```
+------------+----------------+
| product_id | total_quantity |
+------------+----------------+
| 100        | 22             |
| 200        | 15             |
+------------+----------------+
```

解释：
- 产品 100 在 2008 年销售了 10 个，在 2009 年销售了 12 个，总共 22 个
- 产品 200 在 2011 年销售了 15 个

## 解题思路

这是一道基础的 **GROUP BY + 聚合函数** 题目。

**分析：**
1. 需要按 `product_id` 分组
2. 对每组的 `quantity` 求和
3. 不需要关联 `Product` 表（因为只需要 `product_id`）

**SQL 知识点：**
- GROUP BY 分组
- SUM() 聚合函数
- SELECT 别名

## SQL 代码实现

### 方法一：GROUP BY + SUM（推荐）

```sql
SELECT 
    product_id,
    SUM(quantity) AS total_quantity
FROM 
    Sales
GROUP BY 
    product_id;
```

### 方法二：显式指定表名

```sql
SELECT 
    s.product_id,
    SUM(s.quantity) AS total_quantity
FROM 
    Sales s
GROUP BY 
    s.product_id;
```

### 方法三：使用子查询（不推荐）

```sql
SELECT 
    product_id,
    (SELECT SUM(quantity) 
     FROM Sales s2 
     WHERE s2.product_id = s1.product_id) AS total_quantity
FROM 
    Sales s1
GROUP BY 
    product_id;
```

## 解题步骤

1. **确定分组字段**：按 `product_id` 分组
2. **选择聚合函数**：使用 `SUM()` 计算总数量
3. **设置别名**：将结果列命名为 `total_quantity`
4. **执行查询**：返回结果

## 关键点总结

1. **GROUP BY**：将相同 `product_id` 的行分为一组
2. **SUM()**：对每组的 `quantity` 求和
3. **AS 别名**：为计算结果设置有意义的列名
4. **不需要 JOIN**：本题只需要 Sales 表，不需要关联 Product 表

## 易错点

1. **忘记 GROUP BY**：如果不分组，SUM() 会计算所有行的总和
2. **列名错误**：注意题目要求的列名是 `total_quantity`
3. **NULL 处理**：如果 quantity 有 NULL，SUM() 会忽略它们
4. **重复计算**：不要在子查询中重复计算

## SQL 聚合函数对比

| 函数 | 说明 | 示例 |
|------|------|------|
| SUM() | 求和 | SUM(quantity) |
| AVG() | 平均值 | AVG(price) |
| COUNT() | 计数 | COUNT(*) |
| MAX() | 最大值 | MAX(year) |
| MIN() | 最小值 | MIN(year) |

## 扩展思考

**如果要同时统计销售次数怎么办？**

```sql
SELECT 
    product_id,
    SUM(quantity) AS total_quantity,
    COUNT(*) AS sale_count
FROM 
    Sales
GROUP BY 
    product_id;
```

**如果要包含产品名称怎么办？**

```sql
SELECT 
    p.product_name,
    SUM(s.quantity) AS total_quantity
FROM 
    Sales s
INNER JOIN 
    Product p
ON 
    s.product_id = p.product_id
GROUP BY 
    p.product_id, p.product_name;
```

注意：GROUP BY 中包含 `product_id` 是为了确保唯一性。
