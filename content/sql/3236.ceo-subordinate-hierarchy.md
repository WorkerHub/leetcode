## 题目描述

表：`employees`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| employee_id   | int     |
| employee_name | varchar |
| manager_id    | int     |
| salary        | int     |
+---------------+---------+
```

`employee_id` 为主键，`manager_id` 为上级的 `employee_id`，CEO 的 `manager_id` 为 NULL。

编写 SQL 查询，找出每个非 CEO 员工的：
- `employee_id`
- `employee_name`
- `salary`
- `manager_name`：直属上级的姓名
- `manager_salary`：直属上级的薪资
- `team_size`：直接或间接汇报给该员工（包含多级）的员工总数
- `salary_budget`：该员工及其所有直接和间接下属的薪资总和

按 `team_size` 降序排列，`employee_id` 升序。

## 解题思路

使用递归 CTE（WITH RECURSIVE）来遍历层级结构，统计每个员工的下属数量和薪资预算。

## 代码实现

```sql
WITH RECURSIVE subordinates AS (
    -- 基础情况：每个员工自身
    SELECT
        employee_id AS root_id,
        employee_id,
        salary
    FROM employees
    
    UNION ALL
    
    -- 递归：找下属
    SELECT
        s.root_id,
        e.employee_id,
        e.salary
    FROM subordinates s
    JOIN employees e ON e.manager_id = s.employee_id
),
stats AS (
    SELECT
        root_id AS employee_id,
        COUNT(*) - 1 AS team_size,       -- 减去自身
        SUM(salary) AS salary_budget
    FROM subordinates
    GROUP BY root_id
)
SELECT
    e.employee_id,
    e.employee_name,
    e.salary,
    m.employee_name AS manager_name,
    m.salary AS manager_salary,
    s.team_size,
    s.salary_budget
FROM employees e
JOIN employees m ON e.manager_id = m.employee_id  -- 非CEO（有上级）
JOIN stats s ON e.employee_id = s.employee_id
ORDER BY s.team_size DESC, e.employee_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n^2)（递归 CTE 层级遍历）
- 空间复杂度：O(n)

## 关键点总结

1. 递归 CTE 追踪每个节点的所有子树节点
2. `team_size` 为子树大小减去自身
3. `salary_budget` 包含自身薪资

## 易错点

1. 排除 CEO（通过 JOIN employees m ON e.manager_id = m.employee_id 自动排除）
2. team_size 计算要减去自身（COUNT(*) - 1）
