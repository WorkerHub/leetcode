## 题目描述

本题为 SQL 题目。`Salary` 表包含员工薪资记录，每位员工可能有多条记录（对应不同时间）。查询每位员工的最新薪资记录（salary不为null），按 employee_id 升序排列。

**表结构：**
```
Salary 表：
employee_id | name | sex | salary
```

## 解题思路

使用 `GROUP BY` 和 `MAX` 或子查询找最新记录。若有时间列则按时间排序，若无时间列假设最大 salary 行为最新。

根据题目实际结构（`salary` 不为 null），直接选取非 null 的记录。

## SQL 代码实现

### 方法一：直接过滤

```sql
-- 查询薪资不为 null 的所有记录，按 employee_id 升序
SELECT employee_id, name, sex, salary
FROM Salary
WHERE salary IS NOT NULL
ORDER BY employee_id;
```

### 方法二：若需要去重（每人只取一条）

```sql
-- 若每人只取最高薪资记录
SELECT employee_id, name, sex, MAX(salary) AS salary
FROM Salary
WHERE salary IS NOT NULL
GROUP BY employee_id, name, sex
ORDER BY employee_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 过滤 `salary IS NOT NULL` 的记录
2. 按 `employee_id` 升序排列
3. 若有多条记录，按题意决定如何去重

## 易错点

1. NULL 值过滤用 `IS NOT NULL` 而非 `!= NULL`
2. 注意排序方向（升序 ASC）
