## 题目描述

表 `Employees`：

| Column Name | Type    |
|-------------|---------|
| employee_id | int     |
| name        | varchar |
| salary      | int     |

`employee_id` 是主键。

编写 SQL 查询，计算每个员工的奖金：
- 员工 ID 为**奇数**且名字**不以 'M' 开头**：奖金为 `salary`
- 其他情况：奖金为 `0`

返回按 `employee_id` 升序排列的结果。

**示例：**
```
输入：
+-------------+---------+--------+
| employee_id | name    | salary |
+-------------+---------+--------+
| 2           | Meir    | 3000   |
| 3           | Michael | 3800   |
| 7           | Addilyn | 7400   |
| 8           | Juan    | 6100   |
| 11          | Antonie | 10000  |
+-------------+---------+--------+
输出：
+-------------+-------+
| employee_id | bonus |
+-------------+-------+
| 2           | 0     |
| 3           | 0     |
| 7           | 7400  |
| 8           | 0     |
| 11          | 10000 |
+-------------+-------+
```

## 解题思路

用 CASE WHEN 判断两个条件：employee_id 为奇数（`employee_id % 2 = 1`）且名字不以 'M' 开头（`name NOT LIKE 'M%'`）。

## 代码实现

### 方法一：CASE WHEN（推荐）

```sql
SELECT employee_id,
       CASE
           WHEN employee_id % 2 = 1 AND name NOT LIKE 'M%' THEN salary
           ELSE 0
       END AS bonus
FROM Employees
ORDER BY employee_id;
```

### 方法二：IF 函数

```sql
SELECT employee_id,
       IF(employee_id % 2 = 1 AND name NOT LIKE 'M%', salary, 0) AS bonus
FROM Employees
ORDER BY employee_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 奇数判断：`employee_id % 2 = 1`
2. 不以 'M' 开头：`name NOT LIKE 'M%'`（大小写敏感，视 MySQL 配置而定）
3. IF 和 CASE WHEN 语义等价，IF 更简洁

## 易错点

- 两个条件是 AND（同时满足），不是 OR
- `LIKE 'M%'` 匹配以大写 M 开头，注意大小写
