## 题目描述

表：`Contacts`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| first_name  | varchar |
| last_name   | varchar |
+-------------+---------+
```

`id` 是该表的主键。

表：`Calls`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| contact_id  | int  |
| type        | enum |
| duration    | int  |
+-------------+------+
```

`(contact_id, type, duration)` 共同唯一。`type` 为 `'incoming'` 或 `'outgoing'`。`duration` 为通话时长（秒）。

编写一个解决方案，找到每种通话类型时长最长的 3 条通话记录，返回联系人姓名（`first_name + ' ' + last_name`）、通话类型和通话时长，按类型升序、时长降序排列。

**示例输出格式：**
```
+--------------+----------+----------+
| first_name   | type     | duration |
+--------------+----------+----------+
```

## 解题思路

对每种 `type`，用窗口函数 `RANK()` 或 `ROW_NUMBER()` 按时长降序排名，取排名 <= 3 的记录，然后联接 Contacts 表获取姓名。

## 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH ranked AS (
    SELECT
        c.contact_id,
        c.type,
        c.duration,
        RANK() OVER (PARTITION BY c.type ORDER BY c.duration DESC) AS rk
    FROM Calls c
)
SELECT
    CONCAT(co.first_name, ' ', co.last_name) AS first_name,
    r.type,
    r.duration
FROM ranked r
JOIN Contacts co ON r.contact_id = co.id
WHERE r.rk <= 3
ORDER BY r.type ASC, r.duration DESC;
```

### 方法二：使用子查询

```sql
SELECT
    CONCAT(co.first_name, ' ', co.last_name) AS first_name,
    c.type,
    c.duration
FROM Calls c
JOIN Contacts co ON c.contact_id = co.id
WHERE (
    SELECT COUNT(DISTINCT c2.duration)
    FROM Calls c2
    WHERE c2.type = c.type AND c2.duration >= c.duration
) <= 3
ORDER BY c.type ASC, c.duration DESC;
```

## 复杂度分析

- 时间复杂度：取决于数据量
- 空间复杂度：O(n)

## 关键点总结

1. 用窗口函数 RANK() 按类型分组、时长降序排名
2. 筛选排名 <= 3 的记录
3. 联接 Contacts 获取完整姓名

## 易错点

1. 注意 RANK() 会对相同时长给相同排名，可能导致超过 3 条
2. 姓名拼接：first_name + ' ' + last_name
