## 题目描述

表 `Exam`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| exam_id     | int     |
| student_id  | int     |
| score       | int     |
+-------------+---------+
```

`(exam_id, student_id)` 是主键。

对于每次考试，找出分数最高的学生。如果有多个学生并列最高分，全部返回。

另外，计算每次考试的平均分（保留 2 位小数）。

返回结果包含 `exam_id`、最高分 `max_score`、达到最高分的学生 `top_students`（逗号分隔的学生 ID 列表，升序）、以及平均分 `avg_score`，按 `exam_id` 升序排列。

**示例：**

输入：
```
+---------+------------+-------+
| exam_id | student_id | score |
+---------+------------+-------+
| 1       | 1          | 90    |
| 1       | 2          | 85    |
| 1       | 3          | 90    |
| 2       | 1          | 75    |
| 2       | 2          | 80    |
+---------+------------+-------+
```

输出：
```
+---------+-----------+-------------------+-----------+
| exam_id | max_score | top_students      | avg_score |
+---------+-----------+-------------------+-----------+
| 1       | 90        | 1,3               | 88.33     |
| 2       | 80        | 2                 | 77.50     |
+---------+-----------+-------------------+-----------+
```

## 解题思路

1. 计算每次考试的最高分和平均分（GROUP BY exam_id）
2. 找到每次考试中达到最高分的学生
3. 将学生 ID 按升序拼接为字符串

## SQL 代码实现

### 方法一：使用 GROUP_CONCAT 和窗口函数（MySQL，推荐）

```sql
WITH exam_stats AS (
    SELECT
        exam_id,
        MAX(score) AS max_score,
        ROUND(AVG(score), 2) AS avg_score
    FROM Exam
    GROUP BY exam_id
),
top_students AS (
    SELECT
        e.exam_id,
        GROUP_CONCAT(e.student_id ORDER BY e.student_id SEPARATOR ',') AS top_students
    FROM Exam e
    JOIN exam_stats es
        ON e.exam_id = es.exam_id
       AND e.score = es.max_score
    GROUP BY e.exam_id
)
SELECT
    es.exam_id,
    es.max_score,
    ts.top_students,
    es.avg_score
FROM exam_stats es
JOIN top_students ts ON es.exam_id = ts.exam_id
ORDER BY es.exam_id;
```

### 方法二：子查询版本

```sql
SELECT
    e1.exam_id,
    MAX(e1.score) AS max_score,
    GROUP_CONCAT(
        CASE WHEN e1.score = m.max_score THEN e1.student_id END
        ORDER BY e1.student_id
        SEPARATOR ','
    ) AS top_students,
    ROUND(AVG(e1.score), 2) AS avg_score
FROM Exam e1
JOIN (
    SELECT exam_id, MAX(score) AS max_score
    FROM Exam
    GROUP BY exam_id
) m ON e1.exam_id = m.exam_id
GROUP BY e1.exam_id
ORDER BY e1.exam_id;
```

### 方法三：窗口函数

```sql
WITH ranked AS (
    SELECT
        exam_id,
        student_id,
        score,
        MAX(score) OVER (PARTITION BY exam_id) AS max_score,
        ROUND(AVG(score) OVER (PARTITION BY exam_id), 2) AS avg_score
    FROM Exam
)
SELECT
    exam_id,
    max_score,
    GROUP_CONCAT(
        CASE WHEN score = max_score THEN student_id END
        ORDER BY student_id
        SEPARATOR ','
    ) AS top_students,
    avg_score
FROM ranked
GROUP BY exam_id, max_score, avg_score
ORDER BY exam_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和分组
- 空间复杂度：O(n)

## 关键点总结

1. `GROUP_CONCAT` 可以将多行聚合为一个字符串，支持 `ORDER BY` 和自定义分隔符
2. 使用子查询或窗口函数找每次考试的最高分
3. 结合 `CASE WHEN` 过滤只有最高分的学生

## 易错点

1. `GROUP_CONCAT` 中的 `ORDER BY` 要正确设置（按 student_id 升序）
2. 平均分四舍五入到 2 位小数，使用 `ROUND(..., 2)`
3. 处理并列最高分：所有等于最高分的学生都要包含
