## 题目描述

表 `Products`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| low_fats    | enum    |
| recyclable  | enum    |
+-------------+---------+
```

`product_id` 是该表的主键。`low_fats` 是枚举类型，取值 `('Y', 'N')`，`recyclable` 是枚举类型，取值 `('Y', 'N')`。

找出**既是低脂又是可回收**的产品 id。

返回结果表按任意顺序排列。

**示例：**
```
输入：
Products 表
+-------------+----------+------------+
| product_id  | low_fats | recyclable |
+-------------+----------+------------+
| 0           | Y        | N          |
| 1           | Y        | Y          |
| 2           | N        | Y          |
| 3           | Y        | Y          |
| 4           | N        | N          |
+-------------+----------+------------+

输出：
+-------------+
| product_id  |
+-------------+
| 1           |
| 3           |
+-------------+
```

## 解题思路

直接用 WHERE 条件过滤，找 `low_fats = 'Y' AND recyclable = 'Y'` 的行。

## 代码实现

### 方法一：WHERE 条件过滤

```sql
-- 同时满足低脂和可回收的产品
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

### 方法二：使用 IN（不推荐，但了解语法）

```sql
-- 等价写法（此处不如直接 AND 直观）
SELECT product_id
FROM Products
WHERE low_fats = 'Y'
  AND recyclable = 'Y';
```

## 复杂度分析

- **时间复杂度**：O(n)，全表扫描
- **空间复杂度**：O(1)

## 关键点总结

1. 简单的双条件过滤
2. 枚举类型值用字符串 `'Y'` 比较

## 易错点

- 枚举值要用引号包围（字符串）
- 两个条件用 `AND` 连接
