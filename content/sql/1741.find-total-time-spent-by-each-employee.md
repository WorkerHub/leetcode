## 题目描述

表 `Employees`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| emp_id      | int  |
| event_day   | date |
| in_time     | int  |
| out_time    | int  |
+--------------+-----+
```

`(emp_id, event_day, in_time)` 是该表的主键。
该表显示了员工在办公室的出勤信息。`in_time` 和 `out_time` 都在 1 到 1440 之间。

请你编写解决方案，计算每位员工每天在办公室花费的**总时长**（分钟数）。

结果按 `event_day`、`emp_id` 升序排列。

## 解题思路

按 `event_day` 和 `emp_id` 分组，对每组计算 `SUM(out_time - in_time)` 即为当天的总时长。

## 代码实现

### 方法一：GROUP BY + SUM

```sql
-- 按员工和日期分组，计算总在职时间
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id
ORDER BY event_day, emp_id;
```

### 方法二：聚合并格式化

```sql
-- 效果相同，列名别名格式一致
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY day, emp_id
ORDER BY day ASC, emp_id ASC;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，分组和排序
- **空间复杂度**：O(n)，存储分组结果

## 关键点总结

1. 每次出勤的时长 = `out_time - in_time`
2. 按员工和日期分组求和
3. 输出列名 `day` 而不是 `event_day`

## 易错点

- 注意输出列名是 `day` 而不是 `event_day`
- 一个员工同一天可能有多条打卡记录
