## 题目描述

本题为数据库题目。

给定表 `Loans`：
```
+---------+-----------+
| loan_id | loan_type |
+---------+-----------+
```

返回同时拥有 'Refinance' 和 'Mortgage' 类型贷款的用户 ID。

**注意：** 表结构实际包含 user_id 列：
```
+---------+-----------+---------+
| loan_id | user_id   | loan_type |
+---------+-----------+---------+
```

## SQL 代码实现

### 方法一：GROUP BY + HAVING（推荐）

```sql
SELECT user_id
FROM Loans
WHERE loan_type IN ('Refinance', 'Mortgage')
GROUP BY user_id
HAVING COUNT(DISTINCT loan_type) = 2
ORDER BY user_id;
```

### 方法二：使用 INTERSECT

```sql
SELECT user_id FROM Loans WHERE loan_type = 'Refinance'
INTERSECT
SELECT user_id FROM Loans WHERE loan_type = 'Mortgage'
ORDER BY user_id;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 需要同时拥有两种类型的贷款
2. GROUP BY + HAVING COUNT(DISTINCT loan_type) = 2 最简洁
3. INTERSECT 语义清晰但部分数据库不支持

## 易错点

1. 用户可能有多笔同类型贷款，需要 DISTINCT
2. 两种类型都要有，不是任意一种
