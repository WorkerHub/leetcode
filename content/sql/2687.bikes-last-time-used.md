## 题目描述

本题为 SQL 题目。`Bikes` 表记录自行车使用情况（`bike_id`、`start_time`、`end_time`）。查询每辆自行车最后一次使用的结束时间，按结束时间降序排列。

**表结构：**
```
Bikes 表：
ride_id | bike_id | start_time | end_time
```

## SQL 代码实现

### 方法一：GROUP BY + MAX

```sql
-- 查询每辆自行车最后使用的结束时间
SELECT 
    bike_id,
    MAX(end_time) AS last_used
FROM Bikes
GROUP BY bike_id
ORDER BY last_used DESC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按 `bike_id` 分组，取 `MAX(end_time)`
2. 按最后使用时间降序排列

## 易错点

1. 按 `end_time` 降序，不是升序
2. 需要 `GROUP BY bike_id`
