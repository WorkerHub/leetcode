## 题目描述

表 `Tasks`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| task_id     | int  |
| subtasks_count | int |
+-------------+------+
```

`task_id` 是该表的主键。每一行表示 `task_id` 这个任务有 `subtasks_count` 个子任务，子任务编号从 `1` 到 `subtasks_count`。

表 `Executed`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| task_id     | int  |
| subtask_id  | int  |
+-------------+------+
```

`(task_id, subtask_id)` 是该表的主键。每一行表示 `task_id` 的第 `subtask_id` 个子任务**已执行**。

找出所有**没有被执行**的子任务。

**返回结果表**任意顺序。

## 解题思路

首先生成所有任务的子任务编号（展开），然后与 `Executed` 表做 LEFT JOIN，找出未执行的（NULL）。

在 SQL 中可以用递归 CTE 或数字表生成子任务编号。

## 代码实现

### 方法一：递归 CTE 生成子任务列表

```sql
-- 使用递归 CTE 展开每个任务的所有子任务编号
WITH RECURSIVE subtasks AS (
    -- 基础情况：每个任务的第 1 个子任务
    SELECT task_id, 1 AS subtask_id, subtasks_count
    FROM Tasks
    UNION ALL
    -- 递归：生成下一个子任务
    SELECT task_id, subtask_id + 1, subtasks_count
    FROM subtasks
    WHERE subtask_id < subtasks_count
)
-- 找出未执行的子任务（不在 Executed 表中）
SELECT s.task_id, s.subtask_id
FROM subtasks s
LEFT JOIN Executed e
    ON s.task_id = e.task_id AND s.subtask_id = e.subtask_id
WHERE e.subtask_id IS NULL
ORDER BY s.task_id, s.subtask_id;
```

### 方法二：使用数字辅助表

```sql
-- 方案二：利用内连接生成笛卡尔积，然后过滤
-- 先生成数字 1 到最大子任务数
WITH RECURSIVE nums AS (
    SELECT 1 AS n
    UNION ALL
    SELECT n + 1 FROM nums WHERE n < (SELECT MAX(subtasks_count) FROM Tasks)
),
all_subtasks AS (
    SELECT t.task_id, n.n AS subtask_id
    FROM Tasks t
    JOIN nums n ON n.n <= t.subtasks_count
)
SELECT a.task_id, a.subtask_id
FROM all_subtasks a
WHERE (a.task_id, a.subtask_id) NOT IN (
    SELECT task_id, subtask_id FROM Executed
)
ORDER BY a.task_id, a.subtask_id;
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 是任务数，m 是最大子任务数
- **空间复杂度**：O(n * m)，存储所有子任务

## 关键点总结

1. 递归 CTE 生成每个任务的所有子任务编号
2. LEFT JOIN 后找 NULL 来识别未执行的子任务
3. 也可用 NOT IN 或 NOT EXISTS 代替 LEFT JOIN + IS NULL

## 易错点

- 递归 CTE 需要有终止条件（`WHERE subtask_id < subtasks_count`）
- 注意 MySQL 默认递归深度限制（可设置 `SET @@cte_max_recursion_depth`）
