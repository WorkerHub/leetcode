## 题目描述

表：`Products`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| product_id       | int     |
| product_name     | varchar |
| product_category | varchar |
+------------------+---------+
product_id 是该表主键
```

表：`Orders`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| order_date    | date    |
| unit          | int     |
+---------------+---------+
该表无主键，可能有重复行
unit 是在 order_date 订购的 product_id 的数量
```

写一条 SQL 语句，查询在 **2020 年 2 月** 订购量至少为 **100** 的产品的产品名称和数量。

按任意顺序返回结果。

**示例：**

```
输入：
Products 表：
+------------+--------------+------------------+
| product_id | product_name | product_category |
+------------+--------------+------------------+
| 1          | Leetcode Solutions | Book         |
| 2          | Jewels of Stringology | Book     |
| 3          | HP            | Laptop           |
| 4          | Lenovo        | Laptop           |
| 5          | Leetcode Kit  | T-shirt          |
+------------+--------------+------------------+

Orders 表：
+-----------+------------+------+
| product_id| order_date | unit |
+-----------+------------+------+
| 1         | 2020-02-05 | 60   |
| 1         | 2020-02-10 | 70   |
| 2         | 2020-01-18 | 30   |
| 2         | 2020-02-11 | 80   |
| 3         | 2020-02-17 | 2    |
| 3         | 2020-02-24 | 3    |
| 4         | 2020-03-01 | 20   |
| 4         | 2020-03-04 | 30   |
| 4         | 2020-03-04 | 60   |
| 5         | 2020-02-25 | 50   |
| 5         | 2020-02-27 | 50   |
| 5         | 2020-03-01 | 50   |
+-----------+------------+------+

输出：
+--------------------+-------+
| product_name       | unit  |

| Leetcode Solutions | 130   |
| Leetcode Kit       | 100   |
+--------------------+-------+
```

## 解题思路

**步骤：**

1. 筛选 2020 年 2 月的订单（`order_date BETWEEN '2020-02-01' AND '2020-02-29'`）
2. 按 `product_id` 分组，统计总订购量 `SUM(unit)`
3. 过滤总量 >= 100 的产品
4. 连接 Products 表获取产品名称

## SQL 代码实现

### 方法一：JOIN + GROUP BY + HAVING（推荐）

```sql
SELECT 
    p.product_name,
    SUM(o.unit) AS unit
FROM Orders o
JOIN Products p ON o.product_id = p.product_id
WHERE o.order_date >= '2020-02-01' 
  AND o.order_date <= '2020-02-29'
GROUP BY o.product_id, p.product_name
HAVING SUM(o.unit) >= 100;
```

### 方法二：子查询先汇总再 JOIN

```sql
SELECT p.product_name, t.unit
FROM (
    SELECT product_id, SUM(unit) AS unit
    FROM Orders
    WHERE YEAR(order_date) = 2020 AND MONTH(order_date) = 2
    GROUP BY product_id
    HAVING SUM(unit) >= 100
) t
JOIN Products p ON t.product_id = p.product_id;
```

### 方法三：使用 DATE_FORMAT

```sql
SELECT 
    p.product_name,
    SUM(o.unit) AS unit
FROM Orders o
JOIN Products p ON o.product_id = p.product_id
WHERE DATE_FORMAT(o.order_date, '%Y-%m') = '2020-02'
GROUP BY o.product_id
HAVING SUM(o.unit) >= 100;
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 Orders 表行数（全表扫描 + GROUP BY）
- **空间复杂度**：O(k)，k 为 2020 年 2 月的不同产品数

## 关键点总结

1. 日期过滤：可以用 `BETWEEN`、`>=` 和 `<=`、`YEAR()` + `MONTH()`、`DATE_FORMAT()` 等多种方式
2. `HAVING` 用于过滤聚合后的结果（不能用 `WHERE` 过滤聚合函数的结果）
3. 可以先汇总再 JOIN，也可以先 JOIN 再聚合，效果相同

## 易错点

1. **2020 年 2 月有 29 天**（2020 是闰年），`BETWEEN '2020-02-01' AND '2020-02-29'` 是正确的
2. **WHERE vs HAVING**：`WHERE` 在 GROUP BY 之前过滤行，`HAVING` 在 GROUP BY 之后过滤组；聚合函数（如 SUM）的条件只能用 `HAVING`
3. **LEFT JOIN vs INNER JOIN**：题目要求查找的产品必须在 Orders 中有记录，用 INNER JOIN（JOIN）即可
