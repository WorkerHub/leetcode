## 题目描述

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store1      | int     |
| store2      | int     |
| store3      | int     |
+-------------+---------+
product_id 是这个表的主键。
每行存储了这一产品在不同商店 store1, store2, store3 中的价格。
如果这一产品在商店里没有出售，则值将为 null。
```

请你重新整理 `Products` 表，查询每个产品在不同商店的价格，使得输出的格式变为 `(product_id, store, price)`。如果这一产品在商店里没有出售，则不输出这一行。

以**任意顺序**输出结果。

**示例：**
```
输入：
Products 表：
+------------+--------+--------+--------+
| product_id | store1 | store2 | store3 |
+------------+--------+--------+--------+
| 0          | 95     | 100    | 105    |
| 1          | 70     | null   | 80     |
+------------+--------+--------+--------+

输出：
+------------+--------+-------+
| product_id | store  | price |
+------------+--------+-------+
| 0          | store1 | 95    |
| 0          | store2 | 100   |
| 0          | store3 | 105   |
| 1          | store1 | 70    |
| 1          | store3 | 80    |
+------------+--------+-------+
```

## 解题思路

将宽表（列是商店）转为长表（行是商店），即"列转行"（UNPIVOT）操作。

在 MySQL 中没有直接的 UNPIVOT 语法，需要用 `UNION ALL` 分别查询每个商店的记录，并用 `WHERE price IS NOT NULL` 过滤掉该商店没有售卖的产品。

## 代码实现

### 方法一：UNION ALL（推荐）

```sql
SELECT product_id, 'store1' AS store, store1 AS price
FROM Products
WHERE store1 IS NOT NULL

UNION ALL

SELECT product_id, 'store2' AS store, store2 AS price
FROM Products
WHERE store2 IS NOT NULL

UNION ALL

SELECT product_id, 'store3' AS store, store3 AS price
FROM Products
WHERE store3 IS NOT NULL;
```

### 方法二：使用 CASE WHEN（Pandas 风格，了解）

```sql
-- MySQL 不直接支持 UNPIVOT，但可以用以下方式产生行
SELECT
    product_id,
    store,
    price
FROM (
    SELECT product_id,
           'store1' AS store, store1 AS price FROM Products
    UNION ALL
    SELECT product_id,
           'store2' AS store, store2 AS price FROM Products
    UNION ALL
    SELECT product_id,
           'store3' AS store, store3 AS price FROM Products
) t
WHERE price IS NOT NULL;
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 Products 表的行数
- **空间复杂度**：O(n)，输出行数最多为 3n

## 关键点总结

1. 行列转换（宽表转长表）用 `UNION ALL` 实现
2. 字符串字面量 `'store1'` 作为列值
3. `WHERE price IS NOT NULL` 过滤掉无售卖记录

## 易错点

1. 要用 `UNION ALL` 而非 `UNION`（UNION 会去重，可能丢失相同价格的不同商店记录）
2. NULL 的过滤要用 `IS NOT NULL`，不能用 `!= NULL`
