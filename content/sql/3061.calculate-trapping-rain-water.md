## 题目描述

表：`Heights`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| height      | int  |
+-------------+------+
```

`id` 是主键，按 `id` 顺序排列代表柱子高度。

计算可以接住的雨水总量（经典接雨水问题，但用 SQL 实现）。

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH max_left AS (
    SELECT
        id,
        height,
        MAX(height) OVER (ORDER BY id ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS left_max
    FROM Heights
),
max_right AS (
    SELECT
        id,
        MAX(height) OVER (ORDER BY id ROWS BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING) AS right_max
    FROM Heights
)
SELECT
    COALESCE(SUM(LEAST(l.left_max, r.right_max) - l.height), 0) AS total_trapped_water
FROM max_left l
JOIN max_right r ON l.id = r.id
WHERE LEAST(l.left_max, r.right_max) > l.height;
```

### 方法二：子查询版本

```sql
SELECT COALESCE(SUM(water), 0) AS total_trapped_water
FROM (
    SELECT
        h.id,
        LEAST(
            (SELECT MAX(height) FROM Heights WHERE id <= h.id),
            (SELECT MAX(height) FROM Heights WHERE id >= h.id)
        ) - h.height AS water
    FROM Heights h
) t
WHERE water > 0;
```

## 复杂度分析

- 方法一：O(n log n)，窗口函数
- 方法二：O(n^2)，子查询
- 空间复杂度：O(n)

## 关键点总结

1. 每个位置能接的水 = min(左最高, 右最高) - 当前高度
2. 用窗口函数计算左边最大值和右边最大值
3. 求和即为总接水量

## 易错点

1. 接水量最小为 0（当当前柱子高于左右最高时）
2. 窗口函数计算左右最大值时方向要正确
