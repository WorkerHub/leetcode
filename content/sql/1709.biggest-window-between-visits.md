## 题目描述

表 `UserVisits`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| visit_date  | date |
+-------------+------+
```

该表没有主键，可能有重复行。
每行表示 `user_id` 在 `visit_date` 访问了某个网站。

找出每个用户**最大的窗口**，窗口定义为相邻两次访问之间的天数差。如果某个用户只访问了一次，则窗口为从访问日期到 `2021-1-1` 的天数差。

**注意：** 窗口的边界是连续访问之间，或者第一次访问/最后一次访问与 `2021-1-1` 之间。

返回结果表按 `user_id` 升序排序。

**示例：**
```
输入：
UserVisits 表
+---------+------------+
| user_id | visit_date |
+---------+------------+
| 1       | 2020-11-28 |
| 1       | 2020-10-20 |
| 1       | 2020-12-3  |
| 2       | 2020-10-5  |
| 2       | 2020-12-9  |
| 3       | 2020-11-11 |
+---------+------------+
输出：
+---------+---------------+
| user_id | biggest_window|
+---------+---------------+
| 1       | 39            |
| 2       | 65            |
| 3       | 51            |
+---------+---------------+
```

## 解题思路

使用窗口函数 `LAG` 获取上一次访问日期，计算相邻访问的天数差，再取每个用户的最大值。

关键点：
1. 用 `LAG(visit_date) OVER (PARTITION BY user_id ORDER BY visit_date)` 获取上次访问日期
2. 如果上次访问日期为 NULL（即第一次访问），则与最小边界日期（此处用 `2020-01-01` 或按题意）的差；若最后一次访问与 `2021-01-01` 的差也要考虑
3. 最终取每个用户所有窗口的最大值

## 代码实现

### 方法一：LAG 窗口函数 + DATEDIFF

```sql
-- 使用 LAG 获取上次访问日期，计算窗口大小
WITH ranked AS (
    SELECT
        user_id,
        visit_date,
        -- 获取同一用户的上次访问日期，若无则为 NULL
        LAG(visit_date) OVER (PARTITION BY user_id ORDER BY visit_date) AS prev_date
    FROM UserVisits
),
windows AS (
    SELECT
        user_id,
        -- 若 prev_date 为 NULL（第一次访问），则与虚拟起始日期无关
        -- 计算与上次访问的天数差
        DATEDIFF(visit_date, COALESCE(prev_date, visit_date)) AS window_size
    FROM ranked
    UNION ALL
    -- 每个用户最后一次访问到 2021-1-1 的差
    SELECT
        user_id,
        DATEDIFF('2021-01-01', MAX(visit_date)) AS window_size
    FROM UserVisits
    GROUP BY user_id
)
SELECT
    user_id,
    MAX(window_size) AS biggest_window
FROM windows
GROUP BY user_id
ORDER BY user_id;
```

### 方法二：子查询方式

```sql
-- 先找出每个用户相邻访问的最大间隔，再与最后访问到2021-1-1的间隔取最大
SELECT
    user_id,
    MAX(window_size) AS biggest_window
FROM (
    SELECT
        user_id,
        DATEDIFF(
            visit_date,
            COALESCE(
                LAG(visit_date) OVER (PARTITION BY user_id ORDER BY visit_date),
                visit_date
            )
        ) AS window_size
    FROM UserVisits
    UNION ALL
    SELECT
        user_id,
        DATEDIFF('2021-01-01', MAX(visit_date)) AS window_size
    FROM UserVisits
    GROUP BY user_id
) t
GROUP BY user_id
ORDER BY user_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，需要按用户和日期排序
- **空间复杂度**：O(n)，窗口函数的中间结果

## 关键点总结

1. `LAG` 函数获取同一用户的上次访问日期
2. 第一次访问没有上次记录，`LAG` 返回 NULL，`COALESCE` 处理
3. 最后一次访问到 `2021-01-01` 的间隔需要单独计算并合并

## 易错点

- 第一次访问的窗口是与 `2021-01-01`（或题目规定的边界）的差，不是与 `visit_date` 的差，本题中第一次访问日期与自身差为0，要通过 UNION 加入最后一次到边界的间隔
- `DATEDIFF(a, b)` 在 MySQL 中表示 a - b 的天数差，注意参数顺序
