## 题目描述

表 `Sales`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| sale_id      | int     |
| product_id   | int     |
| sale_date    | date    |
| quantity     | int     |
| price        | decimal |
+--------------+---------+
sale_id 是主键。
```

表 `Products`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| product_name| varchar |
| category    | varchar |
+-------------+---------+
product_id 是主键。
```

对于每个季度（Q1: 1-3月，Q2: 4-6月，Q3: 7-9月，Q4: 10-12月），找出销售总额最高的产品类别。返回结果包含 `season`（季度名称）、`category`（类别）、`total_sales`（总销售额），按季度和总销售额降序排列。

**示例：**

```
输出：
season | category | total_sales
Q1     | Electronics | 5000
Q2     | Clothing    | 3200
...
```

## 解题思路

1. 计算每个季度每个类别的总销售额
2. 对每个季度，找出总销售额最高的类别
3. 按季度顺序和总销售额降序排列

使用 CASE WHEN 或 EXTRACT 函数提取季度，GROUP BY 分组汇总。

## 代码实现

### 方法一：标准 SQL（推荐）

```sql
WITH SeasonSales AS (
    SELECT 
        CASE 
            WHEN MONTH(s.sale_date) BETWEEN 1 AND 3 THEN 'Q1'
            WHEN MONTH(s.sale_date) BETWEEN 4 AND 6 THEN 'Q2'
            WHEN MONTH(s.sale_date) BETWEEN 7 AND 9 THEN 'Q3'
            ELSE 'Q4'
        END AS season,
        p.category,
        SUM(s.quantity * s.price) AS total_sales
    FROM Sales s
    JOIN Products p ON s.product_id = p.product_id
    GROUP BY season, p.category
),
MaxSales AS (
    SELECT 
        season,
        MAX(total_sales) AS max_sales
    FROM SeasonSales
    GROUP BY season
)
SELECT 
    ss.season,
    ss.category,
    ss.total_sales
FROM SeasonSales ss
JOIN MaxSales ms 
    ON ss.season = ms.season 
    AND ss.total_sales = ms.max_sales
ORDER BY 
    CASE ss.season 
        WHEN 'Q1' THEN 1 
        WHEN 'Q2' THEN 2 
        WHEN 'Q3' THEN 3 
        ELSE 4 
    END,
    ss.total_sales DESC;
```

### 方法二：使用窗口函数

```sql
WITH SeasonSales AS (
    SELECT 
        CASE 
            WHEN MONTH(sale_date) BETWEEN 1 AND 3 THEN 'Q1'
            WHEN MONTH(sale_date) BETWEEN 4 AND 6 THEN 'Q2'
            WHEN MONTH(sale_date) BETWEEN 7 AND 9 THEN 'Q3'
            ELSE 'Q4'
        END AS season,
        p.category,
        SUM(s.quantity * s.price) AS total_sales
    FROM Sales s
    JOIN Products p ON s.product_id = p.product_id
    GROUP BY season, p.category
),
Ranked AS (
    SELECT 
        season,
        category,
        total_sales,
        RANK() OVER (PARTITION BY season ORDER BY total_sales DESC) AS rk
    FROM SeasonSales
)
SELECT season, category, total_sales
FROM Ranked
WHERE rk = 1
ORDER BY 
    CASE season WHEN 'Q1' THEN 1 WHEN 'Q2' THEN 2 WHEN 'Q3' THEN 3 ELSE 4 END;
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组排序
- 空间复杂度：O(n)，中间结果

## 关键点总结

1. 用 CASE WHEN 将月份映射为季度标识
2. GROUP BY 按季度和类别汇总
3. 窗口函数 RANK 找每季度的最大销售额类别
4. ORDER BY 时需要将季度字符串转换为数字排序

## 易错点

1. 总销售额 = `quantity * price`，不是只有 quantity 或 price
2. 多个类别并列最高时，窗口函数 RANK 会全部返回
3. 季度排序要用数字（Q1 < Q2 < Q3 < Q4），不能直接按字符串排
