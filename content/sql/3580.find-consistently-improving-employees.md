## 题目描述

表 `PerformanceReviews`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| employee_id   | int     |
| review_date   | date    |
| performance   | int     |
+---------------+---------+
(employee_id, review_date) 是主键。
performance 为 1-10 的整数。
```

找出所有"持续进步"的员工：这些员工的每次绩效评分都高于上一次（按时间顺序严格递增）。至少有两次评分记录的员工才被考虑。返回这些员工的 employee_id，按升序排列。

**示例：**

```
输入：
employee_id | review_date | performance
1           | 2024-01-01  | 5
1           | 2024-02-01  | 7
1           | 2024-03-01  | 9
2           | 2024-01-01  | 8
2           | 2024-02-01  | 6
3           | 2024-01-01  | 5

输出：[1]
解释：员工1的评分 5->7->9 持续递增，员工2不满足（8->6），员工3只有一次。
```

## 解题思路

使用窗口函数 `LAG` 获取前一次评分，然后检查是否所有相邻评分都是递增的。

按员工分组，若存在任一相邻评分不是严格递增的，则排除该员工。

## 代码实现

### 方法一：窗口函数 LAG（推荐）

```sql
WITH RankedReviews AS (
    SELECT 
        employee_id,
        performance,
        LAG(performance) OVER (PARTITION BY employee_id ORDER BY review_date) AS prev_performance,
        COUNT(*) OVER (PARTITION BY employee_id) AS review_count
    FROM PerformanceReviews
),
EmployeeStatus AS (
    SELECT 
        employee_id,
        review_count,
        MIN(CASE WHEN prev_performance IS NOT NULL AND performance <= prev_performance THEN 0 ELSE 1 END) AS is_improving
    FROM RankedReviews
    GROUP BY employee_id, review_count
)
SELECT employee_id
FROM EmployeeStatus
WHERE review_count >= 2 AND is_improving = 1
ORDER BY employee_id;
```

### 方法二：子查询检验

```sql
SELECT DISTINCT e.employee_id
FROM PerformanceReviews e
WHERE 
    -- 至少有2次评分
    (SELECT COUNT(*) FROM PerformanceReviews WHERE employee_id = e.employee_id) >= 2
    -- 所有相邻评分严格递增
    AND NOT EXISTS (
        SELECT 1
        FROM PerformanceReviews p1
        JOIN PerformanceReviews p2
            ON p1.employee_id = p2.employee_id
            AND p1.review_date < p2.review_date
            AND p1.performance >= p2.performance
            -- p2 是 p1 的直接下一次评分（没有中间评分）
            AND NOT EXISTS (
                SELECT 1 FROM PerformanceReviews p3
                WHERE p3.employee_id = p1.employee_id
                AND p3.review_date > p1.review_date
                AND p3.review_date < p2.review_date
            )
        WHERE p1.employee_id = e.employee_id
    )
ORDER BY e.employee_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 窗口函数
- 空间复杂度：O(n)

## 关键点总结

1. `LAG` 函数获取同一员工上一次评分
2. 检查是否存在非递增的相邻评分对
3. 至少有 2 次评分才被考虑

## 易错点

1. 必须是**严格**递增（不是非递减）
2. 只有一次评分的员工不满足条件
3. 评分按日期排序，而非 `review_id`
