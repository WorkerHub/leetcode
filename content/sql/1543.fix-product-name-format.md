## 题目描述

表 `Sales`：
```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| sale_id      | int     |
| product_name | varchar |
| sale_date    | date    |
+--------------+---------+
```

由于一些错误，`product_name` 中存在大小写不统一和首尾有多余空格的问题，`sale_date` 只需要保留年月。

请编写 SQL 查询：
1. 统计每个产品每月的销售数量
2. `product_name` 全部转小写并去除首尾空格
3. `sale_date` 格式化为 `YYYY-MM`
4. 结果按 `product_name` 升序，相同则按 `sale_date` 升序

## 解题思路

### 字符串处理 + 分组统计

1. 用 `LOWER(TRIM(product_name))` 统一产品名格式
2. 用 `DATE_FORMAT(sale_date, '%Y-%m')` 格式化日期
3. `GROUP BY` 分组后 `COUNT` 统计数量

## 代码实现

### 方法一：LOWER + TRIM + DATE_FORMAT（推荐）

```sql
-- 统一产品名格式，按月统计销售量
SELECT
    LOWER(TRIM(product_name)) AS product_name,
    DATE_FORMAT(sale_date, '%Y-%m') AS sale_date,
    COUNT(sale_id) AS total
FROM Sales
GROUP BY LOWER(TRIM(product_name)), DATE_FORMAT(sale_date, '%Y-%m')
ORDER BY product_name ASC, sale_date ASC;
```

### 方法二：使用 CTE 预处理

```sql
-- 先用 CTE 统一格式，再分组
WITH cleaned AS (
    SELECT
        LOWER(TRIM(product_name)) AS product_name,
        DATE_FORMAT(sale_date, '%Y-%m') AS sale_date
    FROM Sales
)
SELECT
    product_name,
    sale_date,
    COUNT(*) AS total
FROM cleaned
GROUP BY product_name, sale_date
ORDER BY product_name ASC, sale_date ASC;
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为 Sales 行数（分组排序）
- **空间复杂度**：O(K)，K 为不同 (product_name, sale_date) 组合数

## 关键点总结

1. `TRIM()` 去除首尾空格，`LOWER()` 转小写
2. `DATE_FORMAT(date, '%Y-%m')` 格式化为 YYYY-MM
3. `GROUP BY` 必须使用处理后的字段（或别名取决于 SQL 方言）

## 易错点

- `GROUP BY` 子句中也要使用 `LOWER(TRIM(...))` 而不是原始列，否则大小写不同的名字会被分到不同组
- MySQL 允许 `GROUP BY` 中使用 SELECT 别名，但其他数据库可能不支持
