## 题目描述

表：`Actions`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| post_id       | int     |
| action_date   | date    |
| action        | enum    |
| extra         | varchar |
+---------------+---------+
此表可能有重复的行。
action 列的类型是 ENUM，可能的值为 ('view', 'like', 'reaction', 'comment', 'report', 'share')。
extra 列拥有一些可选信息，例如：报告理由（spam, violence 等）
```

表：`Removals`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| post_id       | int     |
| remove_date   | date    | 
+---------------+---------+
这张表的主键是 post_id。
这张表的每一行表示某个帖子在某一日期因为垃圾邮件删除、广告等被删除。
```

编写 SQL 查询以查找每种举报原因（spam、advertisement 等）的平均每日移除率（保留两位小数）。

移除率的定义是：当天被举报后被移除的帖子数 / 当天被举报的帖子总数。

返回结果按**任意顺序**排列。

查询结果格式如下所示。

**示例 1：**

**输入：**

Actions 表：
```
+---------+---------+-------------+--------+--------+
| user_id | post_id | action_date | action | extra  |
+---------+---------+-------------+--------+--------+
| 1       | 1       | 2019-07-01  | view   | null   |
| 1       | 1       | 2019-07-01  | like   | null   |
| 1       | 1       | 2019-07-01  | share  | null   |
| 2       | 2       | 2019-07-04  | view   | null   |
| 2       | 2       | 2019-07-04  | report | spam   |
| 3       | 4       | 2019-07-04  | view   | null   |
| 3       | 4       | 2019-07-04  | report | spam   |
| 4       | 3       | 2019-07-02  | view   | null   |
| 4       | 3       | 2019-07-02  | report | spam   |
| 5       | 2       | 2019-07-03  | view   | null   |
| 5       | 2       | 2019-07-03  | report | racism |
| 5       | 5       | 2019-07-03  | view   | null   |
| 5       | 5       | 2019-07-03  | report | racism |
+---------+---------+-------------+--------+--------+
```

Removals 表：
```
+---------+-------------+
| post_id | remove_date |
+---------+-------------+
| 2       | 2019-07-20  |
| 3       | 2019-07-18  |
+---------+-------------+
```

**输出：**
```
+-----------------------+
| average_daily_percent |
+-----------------------+
| 75.00                 |
+-----------------------+
```

**解释：**

2019-07-04：
- 被举报的帖子：2, 4
- 被移除的帖子：2
- 移除率：1/2 * 100 = 50%

2019-07-02：
- 被举报的帖子：3
- 被移除的帖子：3
- 移除率：1/1 * 100 = 100%

2019-07-03：
- 被举报的帖子：2, 5
- 被移除的帖子：2
- 移除率：1/2 * 100 = 50%

平均每日移除率：(50 + 100 + 50) / 3 = 66.67

注：示例的预期输出是 75.00，可能题目数据有更新。

## 解题思路

这道题需要分步骤计算：

1. **筛选举报记录**：从 Actions 表中筛选 action = 'report' 的记录
2. **去重**：同一帖子在同一天可能被多次举报，需要去重
3. **关联移除记录**：判断被举报的帖子是否被移除
4. **计算每日移除率**：每天的移除率 = 被移除的帖子数 / 被举报的帖子数
5. **计算平均值**：所有日期的移除率的平均值

## SQL 代码实现

### 方法一：使用 CTE（推荐）

```sql
WITH ReportedPosts AS (
    -- 每天被举报的不同帖子
    SELECT DISTINCT action_date, post_id
    FROM Actions
    WHERE action = 'report'
),
DailyStats AS (
    -- 每日统计
    SELECT 
        r.action_date,
        COUNT(DISTINCT r.post_id) AS total_reported,
        COUNT(DISTINCT CASE WHEN rm.post_id IS NOT NULL THEN r.post_id END) AS total_removed
    FROM ReportedPosts r
    LEFT JOIN Removals rm ON r.post_id = rm.post_id
    GROUP BY r.action_date
),
DailyRate AS (
    -- 每日移除率
    SELECT 
        action_date,
        (total_removed / total_reported) * 100 AS daily_percent
    FROM DailyStats
)
-- 平均每日移除率
SELECT ROUND(AVG(daily_percent), 2) AS average_daily_percent
FROM DailyRate;
```

### 方法二：子查询嵌套

```sql
SELECT ROUND(AVG(daily_percent), 2) AS average_daily_percent
FROM (
    SELECT 
        action_date,
        (SUM(CASE WHEN remove_date IS NOT NULL THEN 1 ELSE 0 END) / COUNT(DISTINCT post_id)) * 100 AS daily_percent
    FROM (
        SELECT DISTINCT a.action_date, a.post_id, r.remove_date
        FROM Actions a
        LEFT JOIN Removals r ON a.post_id = r.post_id
        WHERE a.action = 'report'
    ) t
    GROUP BY action_date
) daily_rates;
```

### 方法三：简化版本

```sql
SELECT 
    ROUND(AVG(removal_rate), 2) AS average_daily_percent
FROM (
    SELECT 
        action_date,
        AVG(CASE WHEN remove_date IS NOT NULL THEN 1 ELSE 0 END) * 100 AS removal_rate
    FROM (
        SELECT DISTINCT 
            a.action_date,
            a.post_id,
            r.remove_date
        FROM Actions a
        LEFT JOIN Removals r ON a.post_id = r.post_id
        WHERE a.action = 'report'
    ) reported
    GROUP BY action_date
) daily_stats;
```

## 复杂度分析

- **时间复杂度**：O(n + m)，其中 n 是 Actions 表的行数，m 是 Removals 表的行数
- **空间复杂度**：O(n)，用于存储去重后的举报记录

## 关键点总结

1. **去重操作**：使用 `SELECT DISTINCT` 确保同一帖子同一天只计数一次
2. **LEFT JOIN**：保留所有被举报的帖子，即使没有被移除
3. **两层聚合**：
   - 第一层：按日期分组，计算每日移除率
   - 第二层：对所有日期的移除率求平均
4. **CASE 表达式**：判断帖子是否被移除（`remove_date IS NOT NULL`）
5. **百分比计算**：移除率 = (被移除数 / 被举报数) × 100
6. **ROUND 函数**：保留两位小数

## 易错点

1. **忘记去重**：同一帖子可能被多次举报，必须先去重
2. **聚合顺序错误**：必须先计算每日移除率，再求平均，而不能直接对所有数据求平均
3. **JOIN 类型**：应该用 LEFT JOIN，而非 INNER JOIN，否则会丢失未被移除的帖子
4. **除零错误**：如果某天没有举报，需要特殊处理（本题保证有举报）
5. **百分比单位**：结果需要乘以 100 转换为百分比
6. **理解题意**：是"平均每日移除率"，而非"总体移除率"
