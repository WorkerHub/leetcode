## 题目描述

表：`Inventory`

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| item_id        | int     |
| item_type      | varchar |
| item_category  | varchar |
| square_footage | decimal |
+----------------+---------+
```

`item_id` 是主键。包含商品信息和占地面积。

仓库有 500000 平方英尺。优先放置所有 `prime_eligible` 商品，剩余空间放 `not_prime` 商品（最大化商品数量，每种类型商品数量为同类商品数量的整数倍）。

返回每种类型的最大商品数，按 `item_type` 降序排列。

## SQL 代码实现

### 方法一：CTE 分析（推荐）

```sql
WITH prime_info AS (
    SELECT
        SUM(square_footage) AS prime_total_footage,
        COUNT(*) AS prime_count
    FROM Inventory
    WHERE item_type = 'prime_eligible'
),
not_prime_info AS (
    SELECT
        SUM(square_footage) AS np_total_footage,
        COUNT(*) AS np_count
    FROM Inventory
    WHERE item_type = 'not_prime'
),
calc AS (
    SELECT
        FLOOR(500000 / p.prime_total_footage) * p.prime_count AS prime_items,
        FLOOR((500000 - FLOOR(500000 / p.prime_total_footage) * p.prime_total_footage) /
              NULLIF(np.np_total_footage, 0)) * np.np_count AS np_items
    FROM prime_info p, not_prime_info np
)
SELECT 'prime_eligible' AS item_type,
       prime_items AS item_count
FROM calc
UNION ALL
SELECT 'not_prime' AS item_type,
       COALESCE(np_items, 0) AS item_count
FROM calc
ORDER BY item_type DESC;
```

## 复杂度分析

- 时间复杂度：O(n)，n 为商品数
- 空间复杂度：O(1)

## 关键点总结

1. 先计算所有 prime 商品放满仓库需要多少组（FLOOR 取整）
2. 剩余空间计算能放多少组 not_prime 商品
3. 商品数量 = 组数 × 每组商品数

## 易错点

1. 商品数量必须是"同类商品集合数量"的整数倍（不能拆分一组）
2. 若 prime_total_footage 为 NULL（无 prime 商品），需要处理边界
3. NULLIF 防止除以零
