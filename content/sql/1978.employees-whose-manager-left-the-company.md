## 题目描述

表 `Employees`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
| manager_id  | int     |
| salary      | int     |
+-------------+---------+
employee_id 是主键。
```

找出薪水**严格少于 30000** 且其**经理已离职**的员工的 ID。

**注意：** 当一个员工的 `manager_id` 不是任何员工的 `employee_id` 时，意味着其经理已离职。`manager_id` 可为 NULL（无经理）。

结果按 `employee_id` 升序排列。

---

## 解题思路

### 核心思想：LEFT JOIN 或 NOT IN

找出 `salary < 30000` 且 `manager_id IS NOT NULL` 且 `manager_id` 不在员工表中的记录。

---

## 代码实现

### 方法一：NOT IN 子查询（推荐）

```sql
SELECT employee_id
FROM Employees
WHERE salary < 30000
  AND manager_id IS NOT NULL
  AND manager_id NOT IN (
      SELECT employee_id FROM Employees
  )
ORDER BY employee_id;
```

### 方法二：LEFT JOIN

```sql
SELECT e.employee_id
FROM Employees e
LEFT JOIN Employees m ON e.manager_id = m.employee_id
WHERE e.salary < 30000
  AND e.manager_id IS NOT NULL
  AND m.employee_id IS NULL
ORDER BY e.employee_id;
```

### 方法三：NOT EXISTS

```sql
SELECT employee_id
FROM Employees e
WHERE salary < 30000
  AND manager_id IS NOT NULL
  AND NOT EXISTS (
      SELECT 1
      FROM Employees m
      WHERE m.employee_id = e.manager_id
  )
ORDER BY employee_id;
```

---

## 复杂度分析

| 操作 | 说明 |
|------|------|
| NOT IN | O(n) 扫描主表 + O(n) 子查询 |
| LEFT JOIN | O(n log n)（索引关联） |

---

## 关键点总结

1. 经理离职 = `manager_id` 不在员工表的 `employee_id` 中
2. 需过滤 `manager_id IS NOT NULL`（无经理的员工不符合条件）
3. 三种写法等价，NOT IN 最简洁

---

## 易错点

- 忘记过滤 `manager_id IS NOT NULL`，会把没有经理的员工也统计进来
- `NOT IN` 中若子查询含 NULL 值，结果为空，但 `employee_id` 是主键不含 NULL，故安全
