## 题目描述

给你两张表：

**Members 表：**
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| member_id   | int     |
| name        | varchar |
+-------------+---------+
member_id 是主键
```

**Contests 表：**
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| contest_id  | int  |
| gold_medal  | int  |
| silver_medal| int  |
| bronze_medal| int  |
+-------------+------+
contest_id 是主键
```

每个成员根据其获奖记录被分为以下类别：
- **"Gold Medal"**：至少一次赢得金牌
- **"Silver Medal"**：没有金牌，但至少一次银牌
- **"Bronze Medal"**：没有金牌和银牌，但至少一次铜牌
- **"Expert"**：没有任何奖牌

返回每位成员的 `member_id`、`name` 和 `category`，按 `member_id` 升序排列。

## 解题思路

使用 `LEFT JOIN` 将成员与比赛奖牌记录关联，用 `CASE WHEN` 判断分类。

## 代码实现

### 方法一：LEFT JOIN + CASE WHEN（推荐）

```sql
SELECT
    m.member_id,
    m.name,
    CASE
        WHEN m.member_id IN (SELECT gold_medal FROM Contests) THEN 'Gold Medal'
        WHEN m.member_id IN (SELECT silver_medal FROM Contests) THEN 'Silver Medal'
        WHEN m.member_id IN (SELECT bronze_medal FROM Contests) THEN 'Bronze Medal'
        ELSE 'Expert'
    END AS category
FROM Members m
ORDER BY m.member_id
```

### 方法二：多次 LEFT JOIN

```sql
WITH gold AS (SELECT DISTINCT gold_medal AS mid FROM Contests),
     silver AS (SELECT DISTINCT silver_medal AS mid FROM Contests),
     bronze AS (SELECT DISTINCT bronze_medal AS mid FROM Contests)
SELECT
    m.member_id,
    m.name,
    CASE
        WHEN g.mid IS NOT NULL THEN 'Gold Medal'
        WHEN s.mid IS NOT NULL THEN 'Silver Medal'
        WHEN b.mid IS NOT NULL THEN 'Bronze Medal'
        ELSE 'Expert'
    END AS category
FROM Members m
LEFT JOIN gold g ON m.member_id = g.mid
LEFT JOIN silver s ON m.member_id = s.mid
LEFT JOIN bronze b ON m.member_id = b.mid
ORDER BY m.member_id
```

### 方法三：聚合后分类

```sql
WITH awards AS (
    SELECT gold_medal AS mid, 'gold' AS award_type FROM Contests
    UNION ALL
    SELECT silver_medal, 'silver' FROM Contests
    UNION ALL
    SELECT bronze_medal, 'bronze' FROM Contests
),
best AS (
    SELECT
        mid,
        CASE
            WHEN SUM(CASE WHEN award_type = 'gold' THEN 1 ELSE 0 END) > 0 THEN 'Gold Medal'
            WHEN SUM(CASE WHEN award_type = 'silver' THEN 1 ELSE 0 END) > 0 THEN 'Silver Medal'
            WHEN SUM(CASE WHEN award_type = 'bronze' THEN 1 ELSE 0 END) > 0 THEN 'Bronze Medal'
        END AS category
    FROM awards
    GROUP BY mid
)
SELECT m.member_id, m.name, COALESCE(b.category, 'Expert') AS category
FROM Members m
LEFT JOIN best b ON m.member_id = b.mid
ORDER BY m.member_id
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为成员数，m 为比赛数
- 空间复杂度：O(n + m)

## 关键点总结

1. 分类有优先级：金 > 银 > 铜 > Expert
2. `CASE WHEN` 按优先级从高到低判断
3. `LEFT JOIN` 确保没有奖牌的成员也出现在结果中
4. 使用 `DISTINCT` 避免重复匹配

## 易错点

- 需要包含**所有**成员，即使没有奖牌（使用 `LEFT JOIN` 而非 `INNER JOIN`）
- 分类条件是互斥的（用 `ELSE` 的 `CASE` 结构）
- 结果按 `member_id` 升序排列
