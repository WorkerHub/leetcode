## 题目描述

表：`books`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| book_id          | int     |
| title            | varchar |
| author           | varchar |
| published_year   | int     |
| available_copies | int     |
| rating           | decimal |
+------------------+---------+
book_id 是主键。
```

查询所有 `rating` 为 NULL 的书籍，按 `book_id` 升序返回。

## 解题思路

直接使用 `WHERE rating IS NULL` 过滤空评分的书籍。

注意：SQL 中 NULL 值不能用 `= NULL` 判断，必须用 `IS NULL`。

## 代码实现

```sql
SELECT
    book_id,
    title,
    author,
    published_year,
    available_copies,
    rating
FROM books
WHERE rating IS NULL
ORDER BY book_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. `NULL` 值判断使用 `IS NULL`，不能使用 `= NULL`。
2. `rating IS NULL` 过滤没有评分的书籍。
3. 按 `book_id` 升序排列。

## 易错点

1. 不能写 `WHERE rating = NULL`，这永远为 False。
2. 若需要非 NULL，使用 `IS NOT NULL`。
