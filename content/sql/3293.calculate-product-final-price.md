## 题目描述

表：`Products`

```
+------------+---------+
| Column Name | Type   |
+------------+---------+
| product_id  | int    |
| category    | varchar|
| price       | decimal|
+------------+---------+
```

表：`Discounts`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| category    | varchar |
| discount    | int     |
+-------------+---------+
```

编写 SQL 查询，计算每个商品的最终价格（原价 * (1 - 折扣/100)），如果该商品所属类别没有折扣，则最终价格等于原价。

结果保留两位小数，按 `product_id` 升序排列。

**输出列：** `product_id`, `category`, `final_price`

## 解题思路

LEFT JOIN 连接两表，若没有折扣则 discount 为 NULL，用 COALESCE 处理为 0。

## 代码实现

```sql
SELECT
    p.product_id,
    p.category,
    ROUND(p.price * (1 - COALESCE(d.discount, 0) / 100.0), 2) AS final_price
FROM Products p
LEFT JOIN Discounts d ON p.category = d.category
ORDER BY p.product_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. LEFT JOIN 保留所有商品，即使没有对应折扣
2. COALESCE(d.discount, 0) 将 NULL 替换为 0
3. ROUND 保留两位小数

## 易错点

1. 折扣是百分比（如 10 表示 10%），需要除以 100
2. 没有折扣的商品不打折，对应 discount 为 0
