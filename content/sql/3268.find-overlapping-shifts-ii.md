## 题目描述

与 3262 类似，表结构相同，但需要找出**每个员工**在某一时刻**最大同时进行的班次数量**（不是重叠对数）。

返回每个员工的 `employee_id` 和 `max_overlapping_shifts`（某一时刻最多同时进行的班次数）。

按 `employee_id` 升序排列，只显示有至少 1 次重叠的员工。

## 解题思路

使用扫描线（差分）思路：
1. 对每个班次，在 `start_time` 加 1，在 `end_time` 减 1
2. 按时间排序，计算前缀和，找到最大值
3. 对每个员工单独计算

在 SQL 中可以用 UNION ALL + 窗口函数实现。

## 代码实现

```sql
WITH events AS (
    SELECT
        employee_id,
        start_time AS event_time,
        1 AS delta
    FROM EmployeeShifts
    
    UNION ALL
    
    SELECT
        employee_id,
        end_time AS event_time,
        -1 AS delta
    FROM EmployeeShifts
),
sorted_events AS (
    SELECT
        employee_id,
        event_time,
        delta,
        SUM(delta) OVER (
            PARTITION BY employee_id
            ORDER BY event_time, delta DESC  -- 先处理开始，再处理结束（保证同时刻先开始）
        ) AS running_sum
    FROM events
),
max_per_employee AS (
    SELECT
        employee_id,
        MAX(running_sum) AS max_overlapping_shifts
    FROM sorted_events
    GROUP BY employee_id
)
SELECT employee_id, max_overlapping_shifts
FROM max_per_employee
WHERE max_overlapping_shifts >= 2  -- 至少有2个班次同时进行才算重叠
ORDER BY employee_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 扫描线：开始时 +1，结束时 -1
2. 窗口函数计算运行前缀和
3. 同一时刻先处理开始事件（delta DESC）

## 易错点

1. 开始时间的事件应在相同时间的结束事件之前处理（delta DESC 排序）
2. max_overlapping_shifts >= 2 表示有重叠（同时有 2 个或更多班次）
