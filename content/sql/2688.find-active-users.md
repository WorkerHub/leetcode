## 题目描述

本题为 SQL 题目。`Users` 表记录用户活动（`user_id`、`item`、`created_at`、`amount`）。若用户在任意两笔消费间隔不超过 7 天，则称其为**活跃用户**。查询所有活跃用户的 ID 和名字（去重，按 ID 升序）。

**表结构：**
```
Users 表：
user_id | item | created_at | amount
```

## SQL 代码实现

### 方法一：自连接

```sql
-- 查找在任意两笔订单间隔 <= 7 天的活跃用户
SELECT DISTINCT u1.user_id
FROM Users u1
JOIN Users u2 ON u1.user_id = u2.user_id
    AND u1.created_at < u2.created_at
    AND DATEDIFF(u2.created_at, u1.created_at) <= 7
ORDER BY u1.user_id;
```

### 方法二：窗口函数

```sql
SELECT DISTINCT user_id
FROM (
    SELECT 
        user_id,
        created_at,
        LAG(created_at) OVER (PARTITION BY user_id ORDER BY created_at) AS prev_date
    FROM Users
) t
WHERE DATEDIFF(created_at, prev_date) <= 7
ORDER BY user_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 自连接找同一用户的两笔消费，检查间隔
2. 窗口函数 `LAG` 更高效
3. 注意 `DATEDIFF` 计算日期差

## 易错点

1. 间隔是 `u2.created_at - u1.created_at <= 7`
2. 需要 `DISTINCT` 去重
