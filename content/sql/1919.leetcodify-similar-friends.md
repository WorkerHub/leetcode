## 题目描述

表 `Listens`（同 1917）和表 `Friendship`（同 1917）。

如果用户 `x` 和用户 `y` **是朋友**，并且在**同一天**听了**至少一首相同的歌曲**，则认为他们是**相似朋友**。

返回所有相似朋友对 `(user1_id, user2_id)`（保证 `user1_id < user2_id`），按升序排列。

---

## 解题思路

### 核心思想：对朋友对，找同天共同听歌记录

1. 对 `Listens` 表按 `(user_id, song_id, day)` 去重
2. 将 `Friendship` 与 `Listens` 自连接：朋友对中的两人在同一天听同一首歌
3. 使用 DISTINCT 去除重复的朋友对

---

## 代码实现

### 方法一：JOIN + DISTINCT（推荐）

```sql
-- 去重后的听歌记录
WITH distinct_listens AS (
    SELECT DISTINCT user_id, song_id, day
    FROM Listens
)
SELECT DISTINCT
    f.user1_id,
    f.user2_id
FROM Friendship f
-- 朋友 user1 在某天听了某首歌
JOIN distinct_listens l1
    ON l1.user_id = f.user1_id
-- 朋友 user2 在同一天也听了同一首歌
JOIN distinct_listens l2
    ON l2.user_id = f.user2_id
    AND l2.song_id = l1.song_id
    AND l2.day = l1.day
ORDER BY f.user1_id, f.user2_id;
```

### 方法二：EXISTS 子查询

```sql
WITH distinct_listens AS (
    SELECT DISTINCT user_id, song_id, day FROM Listens
)
SELECT
    f.user1_id,
    f.user2_id
FROM Friendship f
WHERE EXISTS (
    -- 存在同一天听了同一首歌的记录
    SELECT 1
    FROM distinct_listens l1
    JOIN distinct_listens l2
        ON l1.song_id = l2.song_id
        AND l1.day = l2.day
        AND l1.user_id = f.user1_id
        AND l2.user_id = f.user2_id
)
ORDER BY f.user1_id, f.user2_id;
```

### 方法三：聚合后过滤

```sql
WITH distinct_listens AS (
    SELECT DISTINCT user_id, song_id, day FROM Listens
),
common AS (
    SELECT
        f.user1_id,
        f.user2_id,
        COUNT(*) AS common_count
    FROM Friendship f
    JOIN distinct_listens l1 ON l1.user_id = f.user1_id
    JOIN distinct_listens l2
        ON l2.user_id = f.user2_id
        AND l2.song_id = l1.song_id
        AND l2.day = l1.day
    GROUP BY f.user1_id, f.user2_id
    HAVING COUNT(*) >= 1
)
SELECT user1_id, user2_id
FROM common
ORDER BY user1_id, user2_id;
```

## 复杂度分析

| 操作 | 说明 |
|------|------|
| distinct_listens | 对 Listens 表去重，O(n log n) |
| JOIN | 与 Friendship 连接，O(n * m) 最坏 |
| DISTINCT | 去重结果对 |

---

## 关键点总结

1. 先对 Listens 去重，避免重复计数
2. 只需要找到是否存在共同听歌记录（>=1首），DISTINCT 去重即可
3. 与 1917 的区别：这里是找**已有朋友**中的相似对，而不是推荐新朋友

---

## 易错点

- 不去重可能导致同一对朋友出现多次
- 注意 Friendship 中 `user1_id < user2_id`，结果已满足该顺序
