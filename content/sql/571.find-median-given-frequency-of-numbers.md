## 题目描述

`Numbers` 表保存数字的值及其频率。找出所有数字的中位数并保留两位小数。

表：`Numbers`
```
+-----+------------+
|Num  | Frequency  |
+-----+------------+
|  0  | 7          |
|  1  | 1          |
|  2  | 3          |
|  3  | 1          |
+-----+------------+
```

输出应该是：
```
+--------+
| median |
+--------+
| 0.00   |
+--------+
```

## SQL 代码实现

### 方法一：窗口函数（推荐）⭐

```sql
WITH expanded AS (
    SELECT 
        Num,
        SUM(Frequency) OVER (ORDER BY Num) AS cumsum,
        SUM(Frequency) OVER () AS total
    FROM Numbers
)
SELECT ROUND(AVG(Num), 2) AS median
FROM expanded
WHERE cumsum >= total / 2.0 
  AND cumsum - (SELECT Frequency FROM Numbers WHERE Num = expanded.Num) <= total / 2.0;
```

### 方法二：变量法

```sql
SELECT ROUND(AVG(Num), 2) AS median
FROM (
    SELECT 
        Num,
        Frequency,
        SUM(Frequency) OVER (ORDER BY Num) AS cum_freq,
        SUM(Frequency) OVER () / 2.0 AS mid_pos
    FROM Numbers
) t
WHERE cum_freq >= mid_pos 
  AND (cum_freq - Frequency) < mid_pos;
```

## 关键点总结

1. **频率展开**：考虑每个数字的重复次数
2. **累计频率**：计算累计和
3. **中位数位置**：总频率的一半
