## 题目描述

表 `Teacher` 结构如下：

| Column Name | Type |
|-------------|------|
| teacher_id  | int  |
| subject_id  | int  |
| dept_id     | int  |

`(subject_id, dept_id)` 是该表的主键（复合主键）。

每位老师在不同的系里可能教同一门课（同一 `subject_id`）。

查询每位老师教的**唯一科目数量**（即去掉重复的 subject_id）。

返回 `teacher_id` 和 `cnt`，按任意顺序排列。

**示例：**
```
输入：
Teacher 表：
+------------+------------+---------+
| teacher_id | subject_id | dept_id |
+------------+------------+---------+
| 1          | 2          | 3       |
| 1          | 2          | 4       |
| 1          | 3          | 3       |
| 2          | 1          | 1       |
| 2          | 2          | 1       |
| 2          | 3          | 1       |
| 2          | 4          | 1       |
+------------+------------+---------+

输出：
+------------+-----+
| teacher_id | cnt |
+------------+-----+
| 1          | 2   |
| 2          | 4   |
+------------+-----+
```

## 解题思路

按 `teacher_id` 分组，对 `subject_id` 使用 `COUNT(DISTINCT ...)` 去重计数。

## 代码实现

### 方法一：GROUP BY + COUNT DISTINCT（推荐）

```sql
SELECT 
    teacher_id,
    COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id
```

### 方法二：子查询去重后计数

```sql
SELECT 
    teacher_id,
    COUNT(*) AS cnt
FROM (
    SELECT DISTINCT teacher_id, subject_id
    FROM Teacher
) t
GROUP BY teacher_id
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| COUNT DISTINCT | O(n log n) | O(n) |

## 关键点总结

1. `COUNT(DISTINCT subject_id)` 去重后统计每位老师的唯一科目数。
2. 同一老师在不同系教同一科目只算一次。
3. 这是 SQL 中 `GROUP BY` + `COUNT(DISTINCT)` 的经典用法。

## 易错点

- 不能直接用 `COUNT(subject_id)`，因为同一老师可能在不同系重复教同一科目。
- 必须使用 `DISTINCT` 去重。
