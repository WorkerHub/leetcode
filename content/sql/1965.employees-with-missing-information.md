## 题目描述

表 `Employees`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
+-------------+---------+
employee_id 是主键。
```

表 `Salaries`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| salary      | int     |
+-------------+---------+
employee_id 是主键。
```

找出所有**缺少信息**的员工 id——即在 Employees 中没有姓名，或在 Salaries 中没有薪水的员工。

结果按 `employee_id` 升序排列。

---

## 解题思路

### 核心思想：找两表的对称差

缺少信息的员工是：
- 在 Employees 中有但 Salaries 中没有的，或
- 在 Salaries 中有但 Employees 中没有的

即两表 employee_id 的**对称差**。

---

## 代码实现

### 方法一：UNION + NOT IN（推荐）

```sql
-- 在 Employees 中有但 Salaries 中没有的
SELECT employee_id
FROM Employees
WHERE employee_id NOT IN (SELECT employee_id FROM Salaries)

UNION

-- 在 Salaries 中有但 Employees 中没有的
SELECT employee_id
FROM Salaries
WHERE employee_id NOT IN (SELECT employee_id FROM Employees)

ORDER BY employee_id;
```

### 方法二：FULL OUTER JOIN（MySQL 不支持，需模拟）

```sql
-- MySQL 使用 UNION 模拟 FULL OUTER JOIN
SELECT COALESCE(e.employee_id, s.employee_id) AS employee_id
FROM Employees e
LEFT JOIN Salaries s ON e.employee_id = s.employee_id
WHERE s.employee_id IS NULL

UNION

SELECT COALESCE(e.employee_id, s.employee_id) AS employee_id
FROM Employees e
RIGHT JOIN Salaries s ON e.employee_id = s.employee_id
WHERE e.employee_id IS NULL

ORDER BY employee_id;
```

### 方法三：GROUP BY 计数

```sql
-- 将两表的 employee_id 合并，若某 id 只出现一次则缺少信息
SELECT employee_id
FROM (
    SELECT employee_id FROM Employees
    UNION ALL
    SELECT employee_id FROM Salaries
) t
GROUP BY employee_id
HAVING COUNT(*) = 1
ORDER BY employee_id;
```

---

## 复杂度分析

| 方法 | 说明 |
|------|------|
| NOT IN | O(n * m) |
| LEFT + RIGHT JOIN UNION | O(n + m) |
| GROUP BY | O((n+m) log(n+m)) |

---

## 关键点总结

1. 方法三最简洁：合并两表后，出现一次的 id 就是缺少信息的
2. UNION（去重）而非 UNION ALL 用于方法一
3. 方法三使用 UNION ALL（不去重），因为同一 id 在两表都存在时会出现两次，COUNT = 2

---

## 易错点

- 方法三中必须使用 `UNION ALL`（保留重复），`UNION` 会去重导致结果错误
- `HAVING COUNT(*) = 1` 筛选恰好出现一次的 id
