## 题目描述

一家公司想雇佣新员工，预算为 `70000` 美元。公司正在面试两类候选人：

- **高级员工**（Senior）：工资比初级员工高
- **初级员工**（Junior）：相对便宜

给你一张 `Candidates` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| employee_id | int  |
| experience  | enum |
| salary      | int  |
+-------------+------+
employee_id 是该表的主键。
experience 是枚举类型，值为 'Senior' 或 'Junior'。
```

公司的录用策略如下：
1. 先尽可能多地录用**高级员工**，但总薪资不超过 70000
2. 用剩余预算尽可能多地录用**初级员工**
3. 如果有多个候选人薪资相同，全部录用

返回所有被录用的员工（高级或初级），包含列 `employee_id`、`experience`。

**示例：**
```
输入：
Candidates 表：
+-------------+------------+--------+
| employee_id | experience | salary |
+-------------+------------+--------+
| 1           | Junior     | 10000  |
| 9           | Junior     | 10000  |
| 2           | Senior     | 20000  |
| 11          | Senior     | 20000  |
| 13          | Senior     | 50000  |
| 4           | Junior     | 40000  |
+-------------+------------+--------+

输出：
+-------------+------------+
| employee_id | experience |
+-------------+------------+
| 2           | Senior     |
| 11          | Senior     |
| 1           | Junior     |
| 9           | Junior     |
+-------------+------------+
```

## 解题思路

使用窗口函数（`SUM() OVER (ORDER BY salary)`）计算按薪资排序的前缀薪资和，然后筛选出预算范围内的员工。

**步骤：**
1. 对高级员工按薪资排序，计算累计薪资前缀和
2. 筛选累计薪资 ≤ 70000 的高级员工，记录已用预算
3. 对初级员工按薪资排序，计算累计薪资，在剩余预算内尽可能多录用

## 代码实现

### 方法一：窗口函数（推荐）

```sql
-- 使用 CTE 分别处理 Senior 和 Junior
WITH senior_cte AS (
    SELECT
        employee_id,
        experience,
        salary,
        SUM(salary) OVER (ORDER BY salary) AS running_total
    FROM Candidates
    WHERE experience = 'Senior'
),
junior_cte AS (
    SELECT
        employee_id,
        experience,
        salary,
        SUM(salary) OVER (ORDER BY salary) AS running_total
    FROM Candidates
    WHERE experience = 'Junior'
),
senior_budget AS (
    -- 录用的高级员工及其占用的预算
    SELECT COALESCE(SUM(salary), 0) AS used_budget
    FROM senior_cte
    WHERE running_total <= 70000
)
SELECT employee_id, experience
FROM senior_cte, senior_budget
WHERE running_total <= 70000

UNION ALL

SELECT j.employee_id, j.experience
FROM junior_cte j, senior_budget
WHERE j.running_total <= 70000 - senior_budget.used_budget
```

### 方法二：子查询方式

```sql
-- 计算高级员工可录用的最大前缀和
WITH ranked_senior AS (
    SELECT employee_id, experience, salary,
           SUM(salary) OVER (ORDER BY salary ASC) AS cum_salary
    FROM Candidates
    WHERE experience = 'Senior'
),
ranked_junior AS (
    SELECT employee_id, experience, salary,
           SUM(salary) OVER (ORDER BY salary ASC) AS cum_salary
    FROM Candidates
    WHERE experience = 'Junior'
),
senior_hired AS (
    SELECT * FROM ranked_senior WHERE cum_salary <= 70000
),
remaining AS (
    SELECT 70000 - COALESCE((SELECT SUM(salary) FROM senior_hired), 0) AS budget
)
SELECT employee_id, experience
FROM senior_hired

UNION ALL

SELECT j.employee_id, j.experience
FROM ranked_junior j
CROSS JOIN remaining r
WHERE j.cum_salary <= r.budget
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序开销
- 空间复杂度：O(n)

## 关键点总结

1. 窗口函数 `SUM() OVER (ORDER BY salary)` 计算按薪资排序的累计和
2. 先处理高级员工，计算剩余预算，再处理初级员工
3. 使用 `COALESCE` 处理没有录用高级员工时的空值情况
4. 两类员工用 `UNION ALL` 合并结果

## 易错点

- 如果高级员工一个也录用不了，剩余预算仍为 70000，初级员工照常招募
- 注意 `SUM` 使用 `COALESCE` 防止 NULL
- `UNION ALL` 不去重（同一员工不会同时是 Senior 和 Junior）
