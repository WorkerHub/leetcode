## 题目描述

与 3188 类似，但条件更复杂：

表：`students`、`courses`、`enrollments`

找满足以下所有条件的学生：
1. 选修了所有 **必修课**（`courses` 表中 `mandatory = 'yes'` 的课程）
2. 必修课成绩全为 'A'
3. 非必修课中选修了至少一门，且该门课成绩也为 'A'

按 `student_id` 升序返回满足条件的学生列表。

## 解题思路

1. 找所有选修了全部必修课且成绩为 'A' 的学生
2. 在这些学生中，筛选出在非必修课中也有成绩 'A' 的学生

## 代码实现

### 方法一：多重条件筛选（推荐）

```sql
WITH mandatory_courses AS (
    SELECT course_id FROM courses WHERE mandatory = 'yes'
),
students_with_all_mandatory AS (
    SELECT
        e.student_id,
        COUNT(DISTINCT e.course_id) AS mandatory_taken,
        SUM(CASE WHEN e.grade != 'A' THEN 1 ELSE 0 END) AS non_a_count
    FROM enrollments e
    WHERE e.course_id IN (SELECT course_id FROM mandatory_courses)
    GROUP BY e.student_id
    HAVING mandatory_taken = (SELECT COUNT(*) FROM mandatory_courses)
       AND non_a_count = 0
),
students_with_optional_a AS (
    SELECT DISTINCT e.student_id
    FROM enrollments e
    WHERE e.course_id NOT IN (SELECT course_id FROM mandatory_courses)
      AND e.grade = 'A'
)
SELECT s.student_id
FROM students s
WHERE s.student_id IN (SELECT student_id FROM students_with_all_mandatory)
  AND s.student_id IN (SELECT student_id FROM students_with_optional_a)
ORDER BY s.student_id;
```

### 方法二：联接方式

```sql
SELECT DISTINCT s.student_id
FROM students s
-- 条件1: 选修了所有必修课且全部 A
JOIN (
    SELECT student_id
    FROM enrollments
    WHERE course_id IN (SELECT course_id FROM courses WHERE mandatory = 'yes')
    GROUP BY student_id
    HAVING COUNT(DISTINCT course_id) = (SELECT COUNT(*) FROM courses WHERE mandatory = 'yes')
       AND SUM(grade != 'A') = 0
) m ON s.student_id = m.student_id
-- 条件2: 至少一门非必修课成绩为 A
JOIN (
    SELECT DISTINCT student_id
    FROM enrollments
    WHERE course_id NOT IN (SELECT course_id FROM courses WHERE mandatory = 'yes')
      AND grade = 'A'
) o ON s.student_id = o.student_id
ORDER BY s.student_id;
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为学生数，m 为课程数
- 空间复杂度：O(n)

## 关键点总结

1. 先找满足必修课条件的学生集合
2. 再筛选满足非必修课条件的学生
3. 两个集合取交集

## 易错点

1. 必须选修了所有必修课（不只是部分）
2. 非必修课至少一门 'A'（不需要全是 'A'）
