## 题目描述

表 `Buses`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| bus_id       | int  |
| arrival_time | int  |
+--------------+------+
```

表 `Passengers`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| passenger_id | int  |
| arrival_time | int  |
```

每辆公交车在 `arrival_time` 时刻到站，乘客也在某时刻到站等车。
乘客上公交的规则：乘客登上**第一辆**在其到站时间**之后（或同时）**到站的公交车。

返回每辆公交车上的乘客数量。

**示例：**
```
Buses: [(1,2),(2,4),(3,6)]
Passengers: [(11,1),(4,1),(5,2),(6,3),(3,5),(2,6)]
输出：
+--------+-----------------+
| bus_id | passengers_cnt  |
+--------+-----------------+
| 1      | 2               |
| 2      | 1               |
| 3      | 2               |
+--------+-----------------+
```

## 解题思路

对每个乘客，找到它登上的公交（到站时间 >= 乘客到站时间的最小 bus）。然后按 bus 分组计数。

## 代码实现

### 方法一：子查询（推荐）

```sql
SELECT 
    b.bus_id,
    COUNT(p.passenger_id) AS passengers_cnt
FROM Buses b
LEFT JOIN Passengers p ON p.arrival_time <= b.arrival_time
    AND b.bus_id = (
        SELECT b2.bus_id
        FROM Buses b2
        WHERE b2.arrival_time >= p.arrival_time
        ORDER BY b2.arrival_time ASC
        LIMIT 1
    )
GROUP BY b.bus_id
ORDER BY b.bus_id;
```

### 方法二：使用 ROW_NUMBER 窗口函数（更高效）

```sql
WITH ranked AS (
    -- 为每个乘客找出最早的公交（到站时间 >= 乘客到站时间）
    SELECT 
        p.passenger_id,
        b.bus_id,
        ROW_NUMBER() OVER (
            PARTITION BY p.passenger_id 
            ORDER BY b.arrival_time ASC
        ) AS rn
    FROM Passengers p
    JOIN Buses b ON b.arrival_time >= p.arrival_time
)
SELECT 
    b.bus_id,
    COUNT(r.passenger_id) AS passengers_cnt
FROM Buses b
LEFT JOIN ranked r ON r.bus_id = b.bus_id AND r.rn = 1
GROUP BY b.bus_id
ORDER BY b.bus_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 窗口函数 | O(P * B log B) | O(P * B) |

P = 乘客数，B = 公交数。

## 关键点总结

1. 每个乘客登上的是第一辆在其到站时间**之后**到达的公交。
2. 用窗口函数 `ROW_NUMBER() PARTITION BY passenger ORDER BY bus_arrival ASC` 取第一辆公交。
3. 公交与乘客之间是多对多关系（一辆公交可载多人），用 LEFT JOIN 确保没有乘客的公交也出现在结果中（计数为 0）。

## 易错点

- 若乘客到站时间晚于所有公交，该乘客不上任何公交（题目通常会保证不出现这种情况，但需注意）。
- LEFT JOIN 保证公交 id 全部出现，不会因为没有乘客而缺失。
