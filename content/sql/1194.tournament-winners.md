## 题目描述

表：`Players`

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| player_id   | int   |
| group_id    | int   |
+-------------+-------+
```

- `player_id` 是此表的主键。
- 此表的每一行表示每个玩家所属的组。

表：`Matches`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| match_id      | int     |
| first_player  | int     |
| second_player | int     |
| first_score   | int     |
| second_score  | int     |
+---------------+---------+
```

- `match_id` 是此表的主键。
- 每一行是一场比赛的记录，`first_player` 和 `second_player` 表示该场比赛的球员 ID。
- `first_score` 和 `second_score` 分别表示 `first_player` 和 `second_player` 的得分。
- 你可以假设，在每一场比赛中，球员都属于同一组。

每组的获胜者是在组内得分最高的选手。如果平局，`player_id` 最小的选手获胜。

编写一个 SQL 查询来查找每组中的获胜者。

以任意顺序返回结果表。

查询结果格式如下所示。

**示例 1：**

输入：
```
Players table:
+-----------+------------+
| player_id | group_id   |
+-----------+------------+
| 15        | 1          |
| 25        | 1          |
| 30        | 1          |
| 45        | 1          |
| 10        | 2          |
| 35        | 2          |
| 50        | 2          |
| 20        | 3          |
| 40        | 3          |
+-----------+------------+

Matches table:
+------------+--------------+---------------+-------------+--------------+
| match_id   | first_player | second_player | first_score | second_score |
+------------+--------------+---------------+-------------+--------------+
| 1          | 15           | 45            | 3           | 0            |
| 2          | 30           | 25            | 1           | 2            |
| 3          | 30           | 15            | 2           | 0            |
| 4          | 40           | 20            | 5           | 2            |
| 5          | 35           | 50            | 1           | 1            |
+------------+--------------+---------------+-------------+--------------+
```

输出：
```
+-----------+------------+
| group_id  | player_id  |
+-----------+------------+
| 1         | 15         |
| 2         | 35         |
| 3         | 40         |
+-----------+------------+
```

## 解题思路

这道题需要分三步完成：计算每个选手的总分、按组分组并找出最高分、处理平局情况。

**核心思路：**

1. **计算每个选手的总分**：
   - 每个选手可能作为 `first_player` 或 `second_player` 出现
   - 需要将两种情况的得分累加

2. **按组分组**：
   - 将选手信息与得分信息关联
   - 按 `group_id` 分组

3. **找出最高分选手**：
   - 使用 `MAX(score)` 找出每组的最高分
   - 使用 `MIN(player_id)` 处理平局

4. **关键技巧**：
   - 使用 `UNION ALL` 合并两种比赛角色的得分
   - 使用窗口函数或子查询找出每组的获胜者

## SQL 代码实现

### 方法一：UNION ALL + GROUP BY（推荐）⭐

```sql
SELECT 
    group_id,
    player_id
FROM (
    SELECT 
        p.group_id,
        p.player_id,
        SUM(score) AS total_score
    FROM Players p
    JOIN (
        -- 合并作为 first_player 和 second_player 的得分
        SELECT first_player AS player_id, first_score AS score
        FROM Matches
        UNION ALL
        SELECT second_player AS player_id, second_score AS score
        FROM Matches
    ) m ON p.player_id = m.player_id
    GROUP BY p.group_id, p.player_id
) player_scores
WHERE (group_id, total_score, player_id) IN (
    -- 找出每组得分最高且 player_id 最小的选手
    SELECT 
        group_id,
        MAX(total_score) AS max_score,
        MIN(player_id) AS min_player
    FROM (
        SELECT 
            p.group_id,
            p.player_id,
            SUM(score) AS total_score
        FROM Players p
        JOIN (
            SELECT first_player AS player_id, first_score AS score
            FROM Matches
            UNION ALL
            SELECT second_player AS player_id, second_score AS score
            FROM Matches
        ) m ON p.player_id = m.player_id
        GROUP BY p.group_id, p.player_id
    ) scores
    GROUP BY group_id
);
```

### 方法二：使用窗口函数

```sql
WITH player_scores AS (
    -- 计算每个选手的总分
    SELECT 
        p.group_id,
        p.player_id,
        SUM(CASE 
            WHEN m.first_player = p.player_id THEN m.first_score 
            WHEN m.second_player = p.player_id THEN m.second_score 
            ELSE 0 
        END) AS total_score
    FROM Players p
    LEFT JOIN Matches m 
        ON p.player_id = m.first_player OR p.player_id = m.second_player
    GROUP BY p.group_id, p.player_id
),
ranked_players AS (
    -- 使用窗口函数对每组的选手进行排名
    SELECT 
        group_id,
        player_id,
        total_score,
        ROW_NUMBER() OVER (
            PARTITION BY group_id 
            ORDER BY total_score DESC, player_id ASC
        ) AS rn
    FROM player_scores
)
-- 选择每组排名第一的选手
SELECT 
    group_id,
    player_id
FROM ranked_players
WHERE rn = 1;
```

### 方法三：简化的窗口函数版本

```sql
SELECT 
    group_id,
    player_id
FROM (
    SELECT 
        p.group_id,
        p.player_id,
        SUM(
            CASE 
                WHEN p.player_id = m.first_player THEN m.first_score
                WHEN p.player_id = m.second_player THEN m.second_score
                ELSE 0
            END
        ) AS total_score,
        RANK() OVER (
            PARTITION BY p.group_id 
            ORDER BY 
                SUM(CASE 
                    WHEN p.player_id = m.first_player THEN m.first_score
                    WHEN p.player_id = m.second_player THEN m.second_score
                    ELSE 0
                END) DESC,
                p.player_id ASC
        ) AS rnk
    FROM Players p
    LEFT JOIN Matches m 
        ON p.player_id = m.first_player OR p.player_id = m.second_player
    GROUP BY p.group_id, p.player_id
) AS ranked
WHERE rnk = 1;
```

### 方法四：使用 CTE 和 UNION ALL

```sql
WITH all_scores AS (
    -- 统一格式：每个选手和他们的得分
    SELECT player_id, first_score AS score
    FROM Matches
    UNION ALL
    SELECT player_id, second_score AS score
    FROM Matches
),
total_scores AS (
    -- 计算每个选手的总分并关联组信息
    SELECT 
        p.group_id,
        p.player_id,
        COALESCE(SUM(s.score), 0) AS total_score
    FROM Players p
    LEFT JOIN all_scores s ON p.player_id = s.player_id
    GROUP BY p.group_id, p.player_id
)
-- 找出每组得分最高且 ID 最小的选手
SELECT 
    group_id,
    player_id
FROM total_scores t1
WHERE total_score = (
    SELECT MAX(total_score)
    FROM total_scores t2
    WHERE t1.group_id = t2.group_id
)
AND player_id = (
    SELECT MIN(player_id)
    FROM total_scores t3
    WHERE t1.group_id = t3.group_id 
        AND t1.total_score = t3.total_score
);
```

## 关键点总结

1. **UNION ALL 的使用**：合并选手在不同比赛角色中的得分
2. **窗口函数排名**：`RANK()` 或 `ROW_NUMBER()` 用于分组排名
3. **平局处理**：按得分降序、ID 升序排序
4. **LEFT JOIN**：确保没有比赛记录的选手也被包含（得分为 0）
5. **COALESCE 函数**：处理 NULL 值，将其转换为 0

## 易错点

1. **遗漏 UNION ALL**：只统计了一种角色的得分
2. **平局处理错误**：没有正确处理相同得分时选择最小 ID
3. **窗口函数排序错误**：应该先按得分降序，再按 ID 升序
4. **JOIN 条件**：使用 OR 条件时要注意性能
5. **NULL 值处理**：没有比赛记录的选手得分应为 0，不是 NULL

## 不同数据库的注意事项

### MySQL 8.0+
- 支持 CTE (WITH 语句)
- 支持窗口函数

### MySQL 5.7
- 不支持窗口函数
- 需要使用子查询和 JOIN 实现

### PostgreSQL
- 完全支持窗口函数和 CTE
- 语法与 MySQL 8.0 类似
