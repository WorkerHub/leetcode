## 题目描述

表：`Servers`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| server_id   | int      |
| status_time | datetime |
| session_status | enum  |
+-------------+----------+
```

`(server_id, status_time)` 是该表的主键。`session_status` 为 `'start'` 或 `'stop'`。

每个服务器的会话成对出现（先 start 后 stop）。

编写一个解决方案，计算所有服务器运行的 **总时长**（以整数秒表示，向下取整为整数天）。

输出格式：
```
+-------------------+
| total_uptime_hours|
+-------------------+
```
实际上题目要求的是总天数（向下取整）。

## 解题思路

对每个服务器，将 start 和 stop 配对，计算每次会话时长，求所有会话时长之和，转换为天数（向下取整）。

## 代码实现

### 方法一：自连接配对（推荐）

```sql
WITH sessions AS (
    SELECT
        s1.server_id,
        s1.status_time AS start_time,
        MIN(s2.status_time) AS stop_time
    FROM Servers s1
    JOIN Servers s2
        ON s1.server_id = s2.server_id
        AND s2.status_time > s1.status_time
        AND s2.session_status = 'stop'
    WHERE s1.session_status = 'start'
    GROUP BY s1.server_id, s1.status_time
)
SELECT
    FLOOR(SUM(TIMESTAMPDIFF(SECOND, start_time, stop_time)) / 86400) AS total_uptime_hours
FROM sessions;
```

### 方法二：窗口函数配对

```sql
WITH ranked AS (
    SELECT
        server_id,
        status_time,
        session_status,
        ROW_NUMBER() OVER (PARTITION BY server_id ORDER BY status_time) AS rn
    FROM Servers
),
paired AS (
    SELECT
        r1.server_id,
        r1.status_time AS start_time,
        r2.status_time AS stop_time
    FROM ranked r1
    JOIN ranked r2
        ON r1.server_id = r2.server_id
        AND r1.rn + 1 = r2.rn
        AND r1.session_status = 'start'
        AND r2.session_status = 'stop'
)
SELECT
    FLOOR(SUM(TIMESTAMPDIFF(SECOND, start_time, stop_time)) / 86400) AS total_uptime_hours
FROM paired;
```

## 复杂度分析

- 时间复杂度：取决于数据量
- 空间复杂度：O(n)

## 关键点总结

1. start 和 stop 配对：每个 start 对应最近的 stop
2. 总时长转换为天数用 FLOOR(seconds / 86400)
3. TIMESTAMPDIFF 计算两个时间的差值（以秒为单位）

## 易错点

1. 配对时需要找 start 之后最近的 stop
2. 向下取整使用 FLOOR
