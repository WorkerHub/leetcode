## 题目描述

表 `UserActivity`：

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| user_id          | int     |
| activity_date    | date    |
| activity_type    | varchar |
| activity_duration| int     |
+------------------+---------+
```

`(user_id, activity_date)` 是主键。`activity_type` 为 `'free'` 或 `'paid'`。

找出从免费用户转变为付费用户的用户：即有免费活动记录，且在该记录之后有付费活动记录的用户。

返回这些用户的 `user_id` 和 `conversion_date`（第一次付费活动的日期），按 `user_id` 升序排列。

**示例：**

输入：
```
+---------+---------------+---------------+-------------------+
| user_id | activity_date | activity_type | activity_duration |
+---------+---------------+---------------+-------------------+
| 1       | 2024-01-01    | free          | 30                |
| 1       | 2024-02-01    | paid          | 60                |
| 2       | 2024-01-15    | paid          | 45                |
| 3       | 2024-01-10    | free          | 20                |
+---------+---------------+---------------+-------------------+
```

输出：
```
+---------+-----------------+
| user_id | conversion_date |
+---------+-----------------+
| 1       | 2024-02-01      |
+---------+-----------------+
```

## 解题思路

1. 找每个用户最早的免费活动日期
2. 找每个用户最早的付费活动日期
3. 筛选出付费日期晚于免费日期的用户，取其最早付费日期

## SQL 代码实现

### 方法一：子查询 + JOIN（推荐）

```sql
SELECT
    p.user_id,
    MIN(p.activity_date) AS conversion_date
FROM UserActivity p
JOIN (
    SELECT user_id, MIN(activity_date) AS first_free_date
    FROM UserActivity
    WHERE activity_type = 'free'
    GROUP BY user_id
) f ON p.user_id = f.user_id
WHERE p.activity_type = 'paid'
  AND p.activity_date > f.first_free_date
GROUP BY p.user_id
ORDER BY p.user_id;
```

### 方法二：GROUP BY + HAVING

```sql
SELECT
    user_id,
    MIN(CASE WHEN activity_type = 'paid' THEN activity_date END) AS conversion_date
FROM UserActivity
GROUP BY user_id
HAVING
    MIN(CASE WHEN activity_type = 'free' THEN activity_date END) IS NOT NULL
    AND MIN(CASE WHEN activity_type = 'paid' THEN activity_date END) IS NOT NULL
    AND MIN(CASE WHEN activity_type = 'paid' THEN activity_date END) >
        MIN(CASE WHEN activity_type = 'free' THEN activity_date END)
ORDER BY user_id;
```

### 方法三：窗口函数

```sql
WITH ranked AS (
    SELECT
        user_id,
        activity_date,
        activity_type,
        MIN(CASE WHEN activity_type = 'free' THEN activity_date END)
            OVER (PARTITION BY user_id) AS first_free,
        MIN(CASE WHEN activity_type = 'paid' THEN activity_date END)
            OVER (PARTITION BY user_id) AS first_paid
    FROM UserActivity
)
SELECT DISTINCT
    user_id,
    first_paid AS conversion_date
FROM ranked
WHERE first_free IS NOT NULL
  AND first_paid IS NOT NULL
  AND first_paid > first_free
ORDER BY user_id;
```

### 方法四：EXISTS 子查询

```sql
SELECT
    user_id,
    MIN(activity_date) AS conversion_date
FROM UserActivity p
WHERE activity_type = 'paid'
  AND EXISTS (
      SELECT 1
      FROM UserActivity f
      WHERE f.user_id = p.user_id
        AND f.activity_type = 'free'
        AND f.activity_date < p.activity_date
  )
GROUP BY user_id
ORDER BY user_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和聚合
- 空间复杂度：O(n)

## 关键点总结

1. 转化条件：先有免费记录，再有付费记录（时间上）
2. 转化日期：第一次付费的日期（在有免费记录之后的最早付费）
3. HAVING 子句中可以使用条件聚合

## 易错点

1. 付费日期必须严格晚于免费日期（`>` 而非 `>=`）
2. 需要确保用户既有免费记录又有付费记录
3. 找的是第一次符合条件的付费日期，不是全局最早的付费日期
