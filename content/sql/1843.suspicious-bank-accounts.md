## 题目描述

表 `Accounts`：

| Column Name    | Type |
|----------------|------|
| account_id     | int  |
| max_income     | int  |

`account_id` 是主键。

表 `Transactions`：

| Column Name    | Type    |
|----------------|---------|
| transaction_id | int     |
| account_id     | int     |
| type           | ENUM    |
| amount         | int     |
| day            | datetime|

`transaction_id` 是主键。`type` 为 `'Creditor'`（收入）或 `'Debtor'`（支出）。

编写 SQL 查询，找出**可疑账户**：某账户在连续两个月内，`Creditor` 类型的收入总和都超过了该账户的 `max_income`。

返回按 `account_id` 升序排列的可疑账户列表。

## 解题思路

1. 过滤出 `Creditor` 类型的交易，按 `account_id` 和年月分组，计算每月收入总和
2. 与 `Accounts` 表 JOIN，找出收入超标的（月收入 > max_income）的记录
3. 在超标记录中，找出存在连续两个月超标的账户（用自连接或窗口函数判断连续）

## 代码实现

### 方法一：月统计 + 自连接判断连续月份

```sql
WITH MonthlyIncome AS (
    SELECT t.account_id,
           DATE_FORMAT(t.day, '%Y-%m') AS yr_mo,
           YEAR(t.day) * 12 + MONTH(t.day) AS month_num,  -- 转为连续月份数
           SUM(t.amount) AS total_income
    FROM Transactions t
    WHERE t.type = 'Creditor'
    GROUP BY t.account_id, yr_mo, month_num
),
Exceeded AS (
    SELECT mi.account_id, mi.month_num
    FROM MonthlyIncome mi
    JOIN Accounts a ON mi.account_id = a.account_id
    WHERE mi.total_income > a.max_income
)
SELECT DISTINCT e1.account_id
FROM Exceeded e1
JOIN Exceeded e2
    ON e1.account_id = e2.account_id
    AND e2.month_num = e1.month_num + 1
ORDER BY e1.account_id;
```

### 方法二：窗口函数 LAG 判断连续

```sql
WITH MonthlyIncome AS (
    SELECT t.account_id,
           YEAR(t.day) * 12 + MONTH(t.day) AS month_num,
           SUM(t.amount) AS total_income
    FROM Transactions t
    WHERE t.type = 'Creditor'
    GROUP BY t.account_id, YEAR(t.day), MONTH(t.day)
),
Exceeded AS (
    SELECT mi.account_id, mi.month_num,
           LAG(mi.month_num) OVER (PARTITION BY mi.account_id ORDER BY mi.month_num) AS prev_month
    FROM MonthlyIncome mi
    JOIN Accounts a ON mi.account_id = a.account_id
    WHERE mi.total_income > a.max_income
)
SELECT DISTINCT account_id
FROM Exceeded
WHERE month_num = prev_month + 1
ORDER BY account_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和分组
- **空间复杂度**：O(n)

## 关键点总结

1. 将日期转为连续月份数（`YEAR * 12 + MONTH`），方便判断相邻月份
2. 自连接判断：找相同账户月份差为 1 的两条超标记录
3. 窗口函数 `LAG` 获取上一条记录的月份数，判断是否连续

## 易错点

- 月份连续性判断需要跨年处理（如 2020-12 和 2021-01），直接用月份不够，需要用年月数
