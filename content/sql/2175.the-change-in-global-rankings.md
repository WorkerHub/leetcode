## 题目描述

表 `TeamPoints`：

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| team_id     | int      |
| name        | varchar  |
| points      | int      |
+-------------+----------+
```

表 `PointsChange`：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| team_id       | int  |
| points_change | int  |
+---------------+------+
```

每个队伍 `points` 增加 `points_change`（可为负数）。

计算每个队伍的**排名变化**（新排名 - 旧排名，负数表示上升）。

排名规则：按分数降序，分数相同时，name 字典序更小的排名更靠前。

**示例：**
```
输出：
+---------+-----------+
| team_id | rank_diff |
+---------+-----------+
```

## 解题思路

**分别计算旧排名和新排名，然后做差**

1. 用 `RANK()` 计算旧排名（按 points 降序，name 升序）。
2. 将 `PointsChange` 中的变化加入后，再用 `RANK()` 计算新排名。
3. 两个排名相减得到变化。

## 代码实现

### 方法一：两次 RANK（推荐）

```sql
WITH old_rank AS (
    SELECT team_id, name, points,
           RANK() OVER (ORDER BY points DESC, name ASC) AS rk
    FROM TeamPoints
),
new_rank AS (
    SELECT tp.team_id, tp.name, tp.points + COALESCE(pc.points_change, 0) AS new_points,
           RANK() OVER (ORDER BY (tp.points + COALESCE(pc.points_change, 0)) DESC, tp.name ASC) AS rk
    FROM TeamPoints tp
    LEFT JOIN PointsChange pc ON tp.team_id = pc.team_id
)
SELECT o.team_id, o.name,
       o.rk - n.rk AS rank_diff
FROM old_rank o
JOIN new_rank n ON o.team_id = n.team_id
ORDER BY o.team_id;
```

### 方法二：合并计算

```sql
WITH combined AS (
    SELECT tp.team_id, tp.name,
           tp.points AS old_points,
           tp.points + COALESCE(pc.points_change, 0) AS new_points
    FROM TeamPoints tp
    LEFT JOIN PointsChange pc ON tp.team_id = pc.team_id
)
SELECT team_id, name,
       RANK() OVER (ORDER BY old_points DESC, name ASC) -
       RANK() OVER (ORDER BY new_points DESC, name ASC) AS rank_diff
FROM combined
ORDER BY team_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 两次 RANK | O(n log n) | O(n) |

## 关键点总结

1. 分别用 `RANK()` 窗口函数计算旧/新排名。
2. 排名规则：分数降序，同分时 name 升序。
3. `rank_diff = old_rank - new_rank`（正数表示排名下降，负数表示上升）。

## 易错点

- PointsChange 中可能不包含所有队伍，使用 LEFT JOIN 并 COALESCE 为 0。
- RANK 和 DENSE_RANK 的区别：有并列时 RANK 会跳过编号，DENSE_RANK 不跳，选用哪个取决于题意。
