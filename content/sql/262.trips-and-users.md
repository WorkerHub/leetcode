## 题目描述

表：`Trips`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| id          | int      |
| client_id   | int      |
| driver_id   | int      |
| city_id     | int      |
| status      | enum     |
| request_at  | date     |
+-------------+----------+
id 是这张表的主键。
status 是一个 ENUM 类型，包含 'completed', 'cancelled_by_driver', 'cancelled_by_client'。
```

表：`Users`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| users_id    | int      |
| banned      | enum     |
| role        | enum     |
+-------------+----------+
users_id 是这张表的主键。
role 是一个 ENUM 类型，包含 'client', 'driver', 'partner'。
banned 是一个 ENUM 类型，包含 'Yes', 'No'。
```

**取消率** 的计算方式：
- 取消率 = (被司机或乘客取消的订单数量) / (总订单数量)

编写 SQL 查询，找出 `"2013-10-01"` 至 `"2013-10-03"` 期间非禁止用户的取消率。

要求：
1. 基于上述表，查询每一天的取消率
2. 取消率保留 **两位小数**
3. **非禁止用户** 指的是乘客和司机都不是被禁止的用户
4. 结果按日期排序

**示例 1：**

输入：

Trips 表：
```
+----+-----------+-----------+---------+---------------------+------------+
| id | client_id | driver_id | city_id | status              | request_at |
+----+-----------+-----------+---------+---------------------+------------+
| 1  | 1         | 10        | 1       | completed           | 2013-10-01 |
| 2  | 2         | 11        | 1       | cancelled_by_driver | 2013-10-01 |
| 3  | 3         | 12        | 6       | completed           | 2013-10-01 |
| 4  | 4         | 13        | 6       | cancelled_by_client | 2013-10-01 |
| 5  | 1         | 10        | 1       | completed           | 2013-10-02 |
| 6  | 2         | 11        | 6       | completed           | 2013-10-02 |
| 7  | 3         | 12        | 6       | completed           | 2013-10-02 |
| 8  | 2         | 12        | 12      | completed           | 2013-10-03 |
| 9  | 3         | 10        | 12      | completed           | 2013-10-03 |
| 10 | 4         | 13        | 12      | cancelled_by_driver | 2013-10-03 |
+----+-----------+-----------+---------+---------------------+------------+
```

Users 表：
```
+----------+--------+--------+
| users_id | banned | role   |
+----------+--------+--------+
| 1        | No     | client |
| 2        | Yes    | client |
| 3        | No     | client |
| 4        | No     | client |
| 10       | No     | driver |
| 11       | No     | driver |
| 12       | No     | driver |
| 13       | No     | driver |
+----------+--------+--------+
```

输出：
```
+------------+-------------------+
| Day        | Cancellation Rate |
+------------+-------------------+
| 2013-10-01 | 0.33              |
| 2013-10-02 | 0.00              |
| 2013-10-03 | 0.50              |
+------------+-------------------+
```

**解释：**
- 2013-10-01：
  - 总共 4 个订单，其中 2 个被取消（id=2, id=4）
  - 但是 id=2 的乘客被禁止，所以只计算 id=1, 3, 4（3个订单）
  - 取消率 = 1/3 = 0.33
- 2013-10-02：
  - 总共 3 个订单，都完成，但 id=6 的乘客被禁止
  - 有效订单：id=5, 7（2个），取消数 0
  - 取消率 = 0/2 = 0.00
- 2013-10-03：
  - 总共 3 个订单都完成，取消 1 个（id=10）
  - 取消率 = 1/2 = 0.50

## 解题思路

这道题考查 SQL 的综合运用，包括：
1. 多表联接（JOIN）
2. 条件过滤（WHERE）
3. 聚合函数（COUNT, SUM）
4. 分组（GROUP BY）
5. 保留小数（ROUND）

**核心思路：**

1. **过滤禁止用户**：
   - 需要 JOIN Users 表两次，分别检查 client 和 driver 是否被禁止
   - 只保留双方都未被禁止的订单

2. **日期范围过滤**：
   - 使用 BETWEEN 或 >= AND <= 筛选日期

3. **计算取消率**：
   - 取消的订单：status != 'completed'
   - 总订单数：COUNT(*)
   - 取消率 = 取消订单数 / 总订单数

4. **格式化输出**：
   - 使用 ROUND 保留两位小数

## SQL 代码实现

### 方法一：标准写法（推荐）⭐

```sql
SELECT 
    t.request_at AS Day,
    ROUND(
        SUM(CASE WHEN t.status != 'completed' THEN 1 ELSE 0 END) / COUNT(*),
        2
    ) AS `Cancellation Rate`
FROM 
    Trips t
    JOIN Users u1 ON t.client_id = u1.users_id AND u1.banned = 'No'
    JOIN Users u2 ON t.driver_id = u2.users_id AND u2.banned = 'No'
WHERE 
    t.request_at BETWEEN '2013-10-01' AND '2013-10-03'
GROUP BY 
    t.request_at
ORDER BY 
    t.request_at;
```

### 方法二：使用 AVG 函数

```sql
SELECT 
    t.request_at AS Day,
    ROUND(
        AVG(CASE WHEN t.status = 'completed' THEN 0 ELSE 1 END),
        2
    ) AS `Cancellation Rate`
FROM 
    Trips t
    JOIN Users c ON t.client_id = c.users_id
    JOIN Users d ON t.driver_id = d.users_id
WHERE 
    c.banned = 'No'
    AND d.banned = 'No'
    AND t.request_at >= '2013-10-01'
    AND t.request_at <= '2013-10-03'
GROUP BY 
    t.request_at
ORDER BY 
    t.request_at;
```

### 方法三：使用 LIKE 判断取消

```sql
SELECT 
    t.request_at AS Day,
    ROUND(
        SUM(IF(t.status LIKE 'cancelled%', 1, 0)) / COUNT(*),
        2
    ) AS `Cancellation Rate`
FROM 
    Trips t
    INNER JOIN Users client ON t.client_id = client.users_id
    INNER JOIN Users driver ON t.driver_id = driver.users_id
WHERE 
    client.banned = 'No'
    AND driver.banned = 'No'
    AND t.request_at BETWEEN '2013-10-01' AND '2013-10-03'
GROUP BY 
    t.request_at;
```

### 方法四：子查询方式

```sql
SELECT 
    request_at AS Day,
    ROUND(
        COUNT(IF(status != 'completed', 1, NULL)) / COUNT(*),
        2
    ) AS `Cancellation Rate`
FROM 
    Trips
WHERE 
    client_id IN (SELECT users_id FROM Users WHERE banned = 'No')
    AND driver_id IN (SELECT users_id FROM Users WHERE banned = 'No')
    AND request_at BETWEEN '2013-10-01' AND '2013-10-03'
GROUP BY 
    request_at;
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 是 Trips 表行数，m 是 Users 表行数
- **空间复杂度**：O(1)，不考虑结果集

## 关键点总结

1. **双 JOIN 过滤**：需要 JOIN Users 表两次，分别验证 client 和 driver
2. **JOIN 条件优化**：可以在 ON 子句中直接加 `banned = 'No'` 条件
3. **取消率计算**：
   - `SUM(CASE WHEN ... THEN 1 ELSE 0 END) / COUNT(*)`
   - 或 `AVG(CASE WHEN ... THEN 1 ELSE 0 END)`
4. **保留小数**：使用 `ROUND(value, 2)` 保留两位小数
5. **列别名**：`Cancellation Rate` 需要用反引号或双引号包裹

## 易错点

1. **忘记双重过滤**：必须同时检查乘客和司机是否被禁止
2. **ROUND 位置错误**：应该对整个计算结果 ROUND，而不是对 SUM 或 COUNT
3. **日期过滤**：不要漏掉日期范围条件
4. **除零错误**：虽然本题不会出现，但实际中需要注意 `COUNT(*) = 0` 的情况
5. **列别名格式**：包含空格的别名需要用反引号 \`Cancellation Rate\` 或双引号
