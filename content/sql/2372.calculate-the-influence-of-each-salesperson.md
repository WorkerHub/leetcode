## 题目描述

表 `Salesperson` 结构如下：

| Column Name | Type    |
|-------------|---------|
| salesperson_id | int  |
| name        | varchar |

表 `Customer` 结构如下：

| Column Name | Type |
|-------------|------|
| customer_id | int  |
| salesperson_id | int |
| price       | int  |

查询每个销售员的影响力（总销售额）。若某销售员没有客户，则影响力为 0。

返回 `salesperson_id`、`name` 和 `total`（销售额），按任意顺序排列。

## 解题思路

LEFT JOIN `Customer` 表（保留没有客户的销售员），对 price 求和（NULL 用 IFNULL 或 COALESCE 处理为 0）。

## 代码实现

### 方法一：LEFT JOIN + GROUP BY（推荐）

```sql
SELECT 
    s.salesperson_id,
    s.name,
    COALESCE(SUM(c.price), 0) AS total
FROM Salesperson s
LEFT JOIN Customer c ON s.salesperson_id = c.salesperson_id
GROUP BY s.salesperson_id, s.name
```

### 方法二：子查询

```sql
SELECT 
    s.salesperson_id,
    s.name,
    IFNULL(
        (SELECT SUM(price) FROM Customer WHERE salesperson_id = s.salesperson_id),
        0
    ) AS total
FROM Salesperson s
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| LEFT JOIN | O(n log n) | O(n) |

## 关键点总结

1. 使用 `LEFT JOIN` 保留没有销售记录的销售员。
2. 使用 `COALESCE(SUM(...), 0)` 或 `IFNULL(SUM(...), 0)` 将 NULL 转换为 0。
3. `GROUP BY` 对每个销售员汇总。

## 易错点

- 用 `INNER JOIN` 会丢失没有客户的销售员，必须用 `LEFT JOIN`。
- `SUM(NULL)` 返回 NULL，需要用 `COALESCE` 或 `IFNULL` 处理。
