## 题目描述

表 `Weather`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| recordDate    | date    |
| temperature   | int     |
+---------------+---------+
```

`id` 是这个表的主键。

该表包含特定日期的温度信息。

编写一个 SQL 查询，来查找与之前（昨天的）日期相比温度更高的所有日期的 `id`。

返回结果表无顺序要求。

**示例 1：**

**输入：**

Weather 表：
```
+----+------------+-------------+
| id | recordDate | temperature |
+----+------------+-------------+
| 1  | 2015-01-01 | 10          |
| 2  | 2015-01-02 | 25          |
| 3  | 2015-01-03 | 20          |
| 4  | 2015-01-04 | 30          |
+----+------------+-------------+
```

**输出：**
```
+----+
| id |
+----+
| 2  |
| 4  |
+----+
```

**解释：**
- 2015-01-02 的温度比前一天高（25 > 10）
- 2015-01-04 的温度比前一天高（30 > 20）

## 解题思路

这道题要求找出温度比前一天高的所有记录。

**核心思想：**
1. 需要比较当前日期和前一天的温度
2. 使用自连接将同一表的不同日期记录关联起来
3. 通过日期差为 1 天来确定"昨天"和"今天"的关系

**关键点：**
- 日期计算：如何判断两个日期相差一天
- 温度比较：当前温度 > 前一天温度
- 自连接：同一表连接自身

**算法步骤：**
1. 表自连接，关联相邻日期
2. 过滤条件：日期差为 1 天且温度上升
3. 返回符合条件的记录 id

## SQL 代码实现

### 方法一：DATEDIFF 函数（推荐）⭐

```sql
-- Write your MySQL query statement below
SELECT w1.id
FROM Weather w1
JOIN Weather w2
ON DATEDIFF(w1.recordDate, w2.recordDate) = 1
WHERE w1.temperature > w2.temperature;
```

**代码说明：**
- `DATEDIFF(date1, date2)`：计算两个日期之间的天数差
- `DATEDIFF(w1.recordDate, w2.recordDate) = 1`：w1 是 w2 的后一天
- `w1.temperature > w2.temperature`：今天温度比昨天高
- 返回 `w1.id`：符合条件的今天的记录 id

### 方法二：DATE_SUB 函数

```sql
-- Write your MySQL query statement below
SELECT w1.id
FROM Weather w1
JOIN Weather w2
ON w1.recordDate = DATE_SUB(w2.recordDate, INTERVAL -1 DAY)
WHERE w1.temperature > w2.temperature;
```

**代码说明：**
- `DATE_SUB(date, INTERVAL -1 DAY)`：日期减去 -1 天，即加 1 天
- 等价于 `DATE_ADD(w2.recordDate, INTERVAL 1 DAY)`
- 直接比较日期是否相等

### 方法三：DATE_ADD 函数

```sql
-- Write your MySQL query statement below
SELECT w1.id
FROM Weather w1
JOIN Weather w2
ON w1.recordDate = DATE_ADD(w2.recordDate, INTERVAL 1 DAY)
WHERE w1.temperature > w2.temperature;
```

**代码说明：**
- `DATE_ADD(date, INTERVAL 1 DAY)`：日期加 1 天
- w2 的日期加 1 天等于 w1 的日期
- 逻辑更清晰：w2 是昨天，w1 是今天

### 方法四：使用 SUBDATE 函数

```sql
-- Write your MySQL query statement below
SELECT w1.id
FROM Weather w1
JOIN Weather w2
ON w1.recordDate = SUBDATE(w2.recordDate, -1)
WHERE w1.temperature > w2.temperature;
```

**代码说明：**
- `SUBDATE(date, days)`：从日期减去指定天数
- `SUBDATE(date, -1)` 等价于加 1 天
- `SUBDATE` 是 `DATE_SUB` 的简写

## 复杂度分析

**时间复杂度：** O(n²)
- 最坏情况下需要比较所有日期对
- 实际上，有索引时性能更好

**空间复杂度：** O(1)
- 不需要额外存储空间

## 关键点总结

1. **日期函数选择**：
   - `DATEDIFF(date1, date2)`：返回天数差
   - `DATE_ADD(date, INTERVAL n DAY)`：日期加 n 天
   - `DATE_SUB(date, INTERVAL n DAY)`：日期减 n 天

2. **自连接条件**：
   - 通过日期关系关联两条记录
   - w1 代表今天，w2 代表昨天

3. **温度比较**：
   - 使用 WHERE 子句过滤温度条件
   - 确保 w1.temperature > w2.temperature

4. **索引优化**：
   - 在 recordDate 列上建立索引可以提升性能
   - 考虑使用复合索引 (recordDate, temperature)

5. **日期连续性**：
   - 题目假设数据可能不连续（可能跳过某些日期）
   - DATEDIFF 方法自动处理这种情况

## 易错点

1. **日期差的方向**：
   - 错误：`DATEDIFF(w2.recordDate, w1.recordDate) = 1`（方向反了）
   - 正确：`DATEDIFF(w1.recordDate, w2.recordDate) = 1`

2. **温度比较的对象**：
   - 错误：`w2.temperature > w1.temperature`（比较反了）
   - 正确：`w1.temperature > w2.temperature`

3. **日期加减符号**：
   - `DATE_SUB(date, INTERVAL -1 DAY)` 等于加 1 天
   - `DATE_ADD(date, INTERVAL 1 DAY)` 等于加 1 天
   - 注意符号的含义

4. **返回错误的 id**：
   - 错误：`SELECT w2.id`（返回昨天的 id）
   - 正确：`SELECT w1.id`（返回今天的 id）

5. **忘记 JOIN 条件**：
   - 必须有日期关联条件，否则会产生笛卡尔积
   - WHERE 条件只能过滤，不能建立关联

**数据分析：**
```
id | recordDate | temperature
1  | 2015-01-01 | 10
2  | 2015-01-02 | 25          ← 25 > 10 ✓
3  | 2015-01-03 | 20          ← 20 < 25 ✗
4  | 2015-01-04 | 30          ← 30 > 20 ✓
```

**自连接匹配：**
```
w1 (今天)              w2 (昨天)              条件判断
id=2, date=01-02, T=25  id=1, date=01-01, T=10  25 > 10 ✓ → 输出 2
id=3, date=01-03, T=20  id=2, date=01-02, T=25  20 > 25 ✗
id=4, date=01-04, T=30  id=3, date=01-03, T=20  30 > 20 ✓ → 输出 4
```

**日期差计算：**
```
DATEDIFF('2015-01-02', '2015-01-01') = 1  ✓
DATEDIFF('2015-01-03', '2015-01-02') = 1  ✓
DATEDIFF('2015-01-04', '2015-01-03') = 1  ✓
```
