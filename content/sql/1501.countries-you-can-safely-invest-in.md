## 题目描述

表 `Person`：
```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| id             | int     |
| name           | varchar |
| phone_number   | varchar |
+----------------+---------+
```
`id` 是主键，`phone_number` 格式为 `'xxx-yyyyyyy'`，`xxx` 是国家代码（3位），`yyyyyyy` 是电话号码（7位）。

表 `Country`：
```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| name           | varchar |
| country_code   | varchar |
+----------------+---------+
```
`country_code` 是主键。

表 `Calls`：
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| caller_id   | int  |
| callee_id   | int  |
| duration    | int  |
+-------------+------+
```

查找平均通话时长大于全球平均通话时长的国家名称。

**示例输出：**
```
+----------+
| country  |
+----------+
| Peru     |
+----------+
```

## 解题思路

### 方法一：JOIN + HAVING 过滤

核心步骤：
1. 将 `Calls` 表中所有通话（caller 和 callee 都算）关联到对应国家
2. 计算每个国家的平均通话时长
3. 与全局平均通话时长比较，筛选出大于全局均值的国家

关键点：每通电话的 caller_id 和 callee_id 都属于某个国家，需要把两端都纳入统计，用 `UNION ALL` 合并。

## 代码实现

### 方法一：UNION ALL 合并两端 + 分组过滤（推荐）

```sql
-- 先用 UNION ALL 将主叫和被叫统一处理
-- 再关联 Person 获取 phone_number，再提取国家码
-- 最后 JOIN Country 获得国家名
SELECT co.name AS country
FROM (
    -- 合并主叫和被叫的所有通话记录
    SELECT caller_id AS person_id, duration
    FROM Calls
    UNION ALL
    SELECT callee_id AS person_id, duration
    FROM Calls
) AS all_calls
-- 关联 Person 表，获取电话号码前3位（国家代码）
JOIN Person p ON all_calls.person_id = p.id
-- 关联 Country 表，匹配国家
JOIN Country co ON LEFT(p.phone_number, 3) = co.country_code
GROUP BY co.name
-- 筛选平均通话时长大于全球平均的国家
HAVING AVG(all_calls.duration) > (SELECT AVG(duration) FROM Calls);
```

### 方法二：使用 CTE 分步骤写法

```sql
-- 使用 CTE 使逻辑更清晰
WITH all_calls AS (
    -- 将主叫和被叫统一为 person_id
    SELECT caller_id AS person_id, duration FROM Calls
    UNION ALL
    SELECT callee_id AS person_id, duration FROM Calls
),
global_avg AS (
    -- 计算全球平均通话时长
    SELECT AVG(duration) AS avg_duration FROM Calls
)
SELECT co.name AS country
FROM all_calls ac
JOIN Person p ON ac.person_id = p.id
JOIN Country co ON LEFT(p.phone_number, 3) = co.country_code
CROSS JOIN global_avg ga
GROUP BY co.name
HAVING AVG(ac.duration) > ga.avg_duration;
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为 Calls 表行数，主要来自排序和分组
- **空间复杂度**：O(N)，中间结果集大小

## 关键点总结

1. 每通电话有两方（caller 和 callee），都要算在各自国家的统计里，必须用 `UNION ALL`
2. 国家代码通过 `LEFT(phone_number, 3)` 提取
3. `HAVING AVG(...) > (子查询)` 是最简洁的过滤方式
4. 使用 `UNION ALL` 而非 `UNION`，因为可能存在相同的记录，不能去重

## 易错点

- 忘记 `UNION ALL`，只统计了主叫或被叫一方
- 使用 `UNION` 而不是 `UNION ALL`，导致重复记录被去除，统计结果有误
- 子查询中计算全局均值时，应该直接用 `Calls` 表，而非 `all_calls`（会导致重复计算）
