## 题目描述

表：`Ads`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| ad_id         | int     |
| user_id       | int     |
| action        | enum    |
+---------------+---------+
(ad_id, user_id) 是该表的主键
action 列是 ENUM 类型，可取值：('Clicked', 'Viewed', 'Ignored')
每行数据记录了一个用户对某广告的行为
```

一家公司正在运营这些广告并希望计算每条广告的点击率（CTR）。

**CTR（点击率）** 的计算公式如下：

```
如果广告没有点击也没有浏览：CTR = 0
否则：CTR = 点击次数 / (点击次数 + 浏览次数) * 100
```

写一条 SQL 语句来查找每条广告的 `ad_id` 和 `ctr`（点击率，保留两位小数），结果按 `ctr` **降序**，`ad_id` **升序**排列。

**示例：**

```
输入：
Ads 表：
+-------+---------+---------+
| ad_id | user_id | action  |
+-------+---------+---------+
| 1     | 1       | Clicked |
| 2     | 2       | Clicked |
| 3     | 3       | Viewed  |
| 5     | 5       | Ignored |
| 1     | 7       | Ignored |
| 2     | 7       | Viewed  |
| 3     | 5       | Clicked |
| 1     | 4       | Viewed  |
| 2     | 11      | Viewed  |
| 1     | 2       | Clicked |
+-------+---------+---------+

输出：
+-------+-------+
| ad_id | ctr   |
+-------+-------+
| 1     | 66.67 |
| 3     | 50.00 |
| 2     | 33.33 |
| 5     | 0.00  |
+-------+-------+
```

## 解题思路

**思路：按 ad_id 分组，条件聚合统计点击数和浏览数**

核心是使用条件聚合（`SUM(CASE WHEN ... END)` 或 `COUNT(CASE WHEN ...)`）分别统计每个广告的点击次数和浏览次数，然后计算 CTR。

**CTR 计算关键：**

- 分母为点击数 + 浏览数（Ignored 不算）
- 分母为 0 时 CTR = 0（用 `IFNULL` 或 `CASE WHEN` 处理）
- 结果保留两位小数

## SQL 代码实现

### 方法一：条件聚合 + IFNULL（推荐）

```sql
SELECT 
    ad_id,
    IFNULL(
        ROUND(
            SUM(action = 'Clicked') * 100.0 / 
            NULLIF(SUM(action IN ('Clicked', 'Viewed')), 0),
            2
        ),
        0.00
    ) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
```

### 方法二：CASE WHEN 显式处理（可读性强）

```sql
SELECT 
    ad_id,
    ROUND(
        CASE 
            WHEN SUM(CASE WHEN action = 'Clicked' THEN 1
                          WHEN action = 'Viewed'  THEN 1
                          ELSE 0 END) = 0 THEN 0
            ELSE SUM(CASE WHEN action = 'Clicked' THEN 1 ELSE 0 END) * 100.0
                 / SUM(CASE WHEN action IN ('Clicked', 'Viewed') THEN 1 ELSE 0 END)
        END, 
        2
    ) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
```

### 方法三：COUNT + IF（MySQL 特有）

```sql
SELECT 
    ad_id,
    ROUND(
        IF(
            COUNT(IF(action IN ('Clicked', 'Viewed'), 1, NULL)) = 0,
            0,
            COUNT(IF(action = 'Clicked', 1, NULL)) * 100.0 
            / COUNT(IF(action IN ('Clicked', 'Viewed'), 1, NULL))
        ),
        2
    ) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为表行数（GROUP BY 扫描全表一次）
- **空间复杂度**：O(k)，k 为不同广告数

## 关键点总结

1. `SUM(action = 'Clicked')` 在 MySQL 中等价于 `SUM(CASE WHEN action = 'Clicked' THEN 1 ELSE 0 END)`（布尔值自动转为 0/1）
2. 用 `NULLIF(x, 0)` 将分母为 0 转为 NULL，再用 `IFNULL(..., 0)` 处理 NULL 值
3. `action IN ('Clicked', 'Viewed')` 等价于 `action = 'Clicked' OR action = 'Viewed'`
4. `100.0` 确保整数除法变为浮点除法

## 易错点

1. **Ignored 不参与 CTR 计算**：分子只统计 Clicked，分母统计 Clicked + Viewed，Ignored 既不在分子也不在分母
2. **除以零的处理**：当某广告只有 Ignored 记录时，分母为 0，需要特殊处理为 0
3. **保留两位小数**：使用 `ROUND(..., 2)` 或 Python 中的 `round(..., 2)`
