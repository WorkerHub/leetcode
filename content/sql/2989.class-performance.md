## 题目描述

本题为数据库题目。

给定表 `Scores`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| assignment1 | int     |
| assignment2 | int     |
| assignment3 | int     |
+-------------+---------+
```

计算班级中所有学生的最大总分与最小总分之差。

## SQL 代码实现

### 方法一：直接计算（推荐）

```sql
SELECT
    MAX(assignment1 + assignment2 + assignment3) -
    MIN(assignment1 + assignment2 + assignment3) AS difference_in_score
FROM Scores;
```

### 方法二：子查询

```sql
SELECT
    (SELECT MAX(assignment1 + assignment2 + assignment3) FROM Scores) -
    (SELECT MIN(assignment1 + assignment2 + assignment3) FROM Scores)
    AS difference_in_score;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 计算每个学生的总分
2. 找最大总分和最小总分的差值

## 易错点

1. 是总分（三科之和）的最大最小差，不是单科差
2. 结果列名为 difference_in_score
