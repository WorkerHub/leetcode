## 题目描述

表 `Sessions`：

| 列名 | 类型 |
|------|------|
| session_id | int |
| duration | int |

- `session_id` 是主键。
- `duration` 是用户访问应用的时间，单位为**秒**。

编写 SQL 查询，统计各时间段内的会话数量，返回如下格式的结果：

| bin | total |
|-----|-------|
| [0-5> | 第 0 到 5 分钟（不含5分钟）的会话数 |
| [5-10> | 第 5 到 10 分钟（不含10分钟）的会话数 |
| [10-15> | 第 10 到 15 分钟（不含15分钟）的会话数 |
| 15 or more | 15 分钟及以上的会话数 |

注意：**所有四个区间都必须出现在结果中，即使某个区间的 total 为 0。**

**示例：**

Sessions 表：
| session_id | duration |
|------------|----------|
| 1 | 30 |
| 2 | 199 |
| 3 | 299 |
| 4 | 580 |
| 5 | 1000 |

输出：
| bin | total |
|-----|-------|
| [0-5> | 0 |
| [5-10> | 0 |
| [10-15> | 0 |
| 15 or more | 5 |

## 解题思路

**思路：固定区间 + UNION ALL 保证每行存在**

将 `duration`（秒）转换为分钟，然后按四个固定区间统计。

**注意：** 由于某些区间可能为 0，不能简单 GROUP BY，需要用 `UNION ALL` 将四个固定 label 与计数结合，保证每个区间都出现。

**转换公式：**
- `[0-5>` 分钟：`0 <= duration < 300`（300 秒 = 5 分钟）
- `[5-10>` 分钟：`300 <= duration < 600`
- `[10-15>` 分钟：`600 <= duration < 900`
- `15 or more` 分钟：`duration >= 900`

## SQL 解法

### 方法一：UNION ALL（推荐，保证全部区间出现）

```sql
SELECT '[0-5>'    AS bin, COUNT(session_id) AS total FROM Sessions WHERE duration < 300
UNION ALL
SELECT '[5-10>'   AS bin, COUNT(session_id) AS total FROM Sessions WHERE duration >= 300 AND duration < 600
UNION ALL
SELECT '[10-15>'  AS bin, COUNT(session_id) AS total FROM Sessions WHERE duration >= 600 AND duration < 900
UNION ALL
SELECT '15 or more' AS bin, COUNT(session_id) AS total FROM Sessions WHERE duration >= 900;
```

### 方法二：CASE WHEN + GROUP BY（配合数字表保证全行出现）

```sql
-- 先用 CASE WHEN 打标签，GROUP BY 统计
-- 但此方法若某区间为空则不会出现该行，需结合 UNION 处理

SELECT
    CASE
        WHEN duration < 300        THEN '[0-5>'
        WHEN duration < 600        THEN '[5-10>'
        WHEN duration < 900        THEN '[10-15>'
        ELSE '15 or more'
    END AS bin,
    COUNT(*) AS total
FROM Sessions
GROUP BY bin;
-- 注意：此方法若某 bin 没有数据则不会出现该行，不满足题目要求！
```

### 方法三：UNION ALL + 左连接（确保空值处理正确）

```sql
-- 使用固定的区间表，LEFT JOIN 真实统计结果
WITH bins AS (
    SELECT '[0-5>'      AS bin, 0    AS lo, 300  AS hi
    UNION ALL
    SELECT '[5-10>'     AS bin, 300  AS lo, 600  AS hi
    UNION ALL
    SELECT '[10-15>'    AS bin, 600  AS lo, 900  AS hi
    UNION ALL
    SELECT '15 or more' AS bin, 900  AS lo, NULL AS hi
)
SELECT
    b.bin,
    COUNT(s.session_id) AS total
FROM bins b
LEFT JOIN Sessions s
    ON s.duration >= b.lo
    AND (b.hi IS NULL OR s.duration < b.hi)
GROUP BY b.bin, b.lo
ORDER BY b.lo;
```

## 复杂度分析

- **时间复杂度：** O(n)，n 为 Sessions 表的行数，每行被扫描一次（或常数次）。
- **空间复杂度：** O(1)，仅存储四个计数值。

## 关键点总结

1. `duration` 单位是秒，换算为分钟需除以 60（或用秒的边界值：300, 600, 900）。
2. 必须保证所有四个区间都出现，即使 total 为 0，因此 `UNION ALL` 比 `GROUP BY` 更安全。
3. 方法一最简洁直观，方法三最通用（适合区间数量多时扩展）。
4. `COUNT(session_id)` 和 `COUNT(*)` 此处等价，但 `COUNT(*)` 更通用。

## 易错点

- 忘记将秒转换为分钟的边界（不是 5/10/15，而是 300/600/900）。
- 使用 `GROUP BY` + `CASE WHEN` 而不保证空区间行的存在。
- 区间边界用 `<=` 还是 `<` 混淆：`[0-5>` 是左闭右开，即 `duration < 300`。
