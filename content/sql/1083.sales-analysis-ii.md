## 题目描述

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
| unit_price   | int     |
+--------------+---------+
product_id 是这个表的主键。
```

表：`Sales`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| seller_id   | int     |
| product_id  | int     |
| buyer_id    | int     |
| sale_date   | date    |
| quantity    | int     |
| price       | int     |
+-------------+---------+
这个表没有主键，它可以有重复的行。
product_id 是 Product 表的外键。
```

编写一个 SQL 查询，报告**购买了 S8 但没有购买 iPhone 的买家**。注意 S8 和 iPhone 是 Product 表中的产品名称。

查询结果格式如下示例所示。

**示例：**

输入：
```
Product 表：
+------------+--------------+------------+
| product_id | product_name | unit_price |
+------------+--------------+------------+
| 1          | S8           | 1000       |
| 2          | G4           | 800        |
| 3          | iPhone       | 1400       |
+------------+--------------+------------+

Sales 表：
+-----------+------------+----------+------------+----------+-------+
| seller_id | product_id | buyer_id | sale_date  | quantity | price |
+-----------+------------+----------+------------+----------+-------+
| 1         | 1          | 1        | 2019-01-21 | 2        | 2000  |
| 1         | 2          | 2        | 2019-02-17 | 1        | 800   |
| 2         | 1          | 3        | 2019-06-02 | 1        | 1000  |
| 1         | 3          | 3        | 2019-05-13 | 2        | 2800  |
+-----------+------------+----------+------------+----------+-------+
```

输出：
```
+-------------+
| buyer_id    |
+-------------+
| 1           |
+-------------+
```

解释：
- 买家 1 购买了 S8，没有购买 iPhone
- 买家 2 购买了 G4，没有购买 S8
- 买家 3 购买了 S8 和 iPhone

只有买家 1 满足条件。

## 解题思路

这是一道**集合运算**问题，需要找到满足特定条件的买家。

### 核心思路

1. **找出购买了 S8 的买家**：
   - JOIN Product 表获取产品名称
   - 筛选 product_name = 'S8'

2. **排除购买了 iPhone 的买家**：
   - 找出购买了 iPhone 的买家
   - 使用 NOT IN 或 NOT EXISTS 排除

3. **去重**：
   - 使用 DISTINCT 去除重复的 buyer_id

### 方法对比

- **方法一**：NOT IN 子查询
- **方法二**：NOT EXISTS 相关子查询
- **方法三**：LEFT JOIN + NULL 判断
- **方法四**：GROUP BY + HAVING

## SQL 代码实现

### 方法一：NOT IN（推荐）

```sql
SELECT DISTINCT s.buyer_id
FROM Sales s
INNER JOIN Product p ON s.product_id = p.product_id
WHERE p.product_name = 'S8'
  AND s.buyer_id NOT IN (
      SELECT s2.buyer_id
      FROM Sales s2
      INNER JOIN Product p2 ON s2.product_id = p2.product_id
      WHERE p2.product_name = 'iPhone'
  );
```

### 方法二：NOT EXISTS（高效）

```sql
SELECT DISTINCT s.buyer_id
FROM Sales s
INNER JOIN Product p ON s.product_id = p.product_id
WHERE p.product_name = 'S8'
  AND NOT EXISTS (
      SELECT 1
      FROM Sales s2
      INNER JOIN Product p2 ON s2.product_id = p2.product_id
      WHERE p2.product_name = 'iPhone'
        AND s2.buyer_id = s.buyer_id
  );
```

### 方法三：LEFT JOIN + NULL

```sql
WITH S8_Buyers AS (
    SELECT DISTINCT s.buyer_id
    FROM Sales s
    INNER JOIN Product p ON s.product_id = p.product_id
    WHERE p.product_name = 'S8'
),
iPhone_Buyers AS (
    SELECT DISTINCT s.buyer_id
    FROM Sales s
    INNER JOIN Product p ON s.product_id = p.product_id
    WHERE p.product_name = 'iPhone'
)
SELECT sb.buyer_id
FROM S8_Buyers sb
LEFT JOIN iPhone_Buyers ib ON sb.buyer_id = ib.buyer_id
WHERE ib.buyer_id IS NULL;
```

### 方法四：GROUP BY + HAVING

```sql
SELECT s.buyer_id
FROM Sales s
INNER JOIN Product p ON s.product_id = p.product_id
WHERE p.product_name IN ('S8', 'iPhone')
GROUP BY s.buyer_id
HAVING SUM(CASE WHEN p.product_name = 'S8' THEN 1 ELSE 0 END) > 0
   AND SUM(CASE WHEN p.product_name = 'iPhone' THEN 1 ELSE 0 END) = 0;
```

## 复杂度分析

**SQL 方法一、二：**
- **时间复杂度**：O(n)
  - JOIN：O(n)
  - 子查询：O(n)
- **空间复杂度**：O(k)，k 是不同买家的数量

**SQL 方法三（LEFT JOIN）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

**Pandas 方法：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **集合运算**：购买了 A 但没有购买 B = A - (A ∩ B)
2. **NOT IN vs NOT EXISTS**：NOT EXISTS 通常性能更好，尤其是有索引时
3. **DISTINCT 必需**：一个买家可能多次购买同一产品，需要去重
4. **相关子查询**：NOT EXISTS 中的子查询引用外层查询的 buyer_id
5. **CTE 清晰度**：使用 WITH 提高可读性

## 易错点

1. **忘记 DISTINCT**：一个买家可能多次购买 S8，导致重复结果
2. **NULL 值处理**：NOT IN 遇到 NULL 会返回空结果，需注意
3. **JOIN 类型**：必须用 INNER JOIN 获取产品名称
4. **产品名称拼写**：注意大小写和空格
5. **Pandas 集合运算**：使用 set 操作更简洁

## SQL 语法要点

### NOT IN vs NOT EXISTS
```sql
-- NOT IN（注意 NULL 问题）
WHERE column NOT IN (SELECT column FROM table)

-- NOT EXISTS（推荐，性能更好）
WHERE NOT EXISTS (
    SELECT 1 
    FROM table 
    WHERE condition
)
```

### CASE WHEN 统计
```sql
-- 统计满足不同条件的记录数
SELECT 
    id,
    SUM(CASE WHEN condition THEN 1 ELSE 0 END) AS count
FROM table
GROUP BY id;
```

### CTE（公共表表达式）
```sql
WITH temp AS (
    SELECT columns
    FROM table
    WHERE conditions
)
SELECT * FROM temp;
```
