## 题目描述

本题为 SQL 题目。给定 `Streams` 表（记录音乐流媒体平台上的歌曲播放记录），查询每位艺术家出现的次数，按出现次数降序、艺术家名字升序排列。

**表结构：**
```
Streams 表：
session_id | user_id | media_id | artist
```

## SQL 代码实现

### 方法一：GROUP BY + COUNT

```sql
-- 统计每位艺术家的出现次数
SELECT 
    artist,
    COUNT(*) AS occurrences
FROM Streams
GROUP BY artist
ORDER BY occurrences DESC, artist ASC;
```

### 方法二：使用子查询

```sql
SELECT artist, COUNT(*) AS occurrences
FROM Streams
GROUP BY artist
ORDER BY 2 DESC, 1 ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. `GROUP BY artist` 按艺术家分组
2. `COUNT(*)` 统计每组出现次数
3. 双列排序：次数降序、名字升序

## 易错点

1. 排序是双列的（次数降序 + 名字升序）
2. `COUNT(*)` 包括所有行，包括 NULL
