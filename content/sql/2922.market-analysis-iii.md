## 题目描述

本题为数据库题目。

给定以下表：

**Users 表：**
```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| seller_id      | int     |
| join_date      | date    |
| favorite_brand | varchar |
+----------------+---------+
seller_id 是主键
```

**Items 表：**
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| item_id       | int     |
| item_brand    | varchar |
+---------------+---------+
item_id 是主键
```

**Orders 表：**
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| order_date    | date    |
| item_id       | int     |
| seller_id     | int     |
+---------------+---------+
order_id 是主键
```

查找每个卖家 2023 年内卖出的最受欢迎品牌（即卖出商品数量最多的品牌）中，是否是他们喜欢的品牌，返回每个卖家在 2023 年内是否只卖出了他们喜欢的品牌。

**输出格式：**
```
+-----------+------------+
| seller_id | 2023_items_sold |
+-----------+------------+
```

## 解题思路

1. 关联 Orders、Items、Users 表，筛选 2023 年的订单
2. 统计每个卖家在 2023 年出售的不同品牌数量
3. 找出每个卖家卖出最多的品牌
4. 与卖家喜欢的品牌对比

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH brand_sales AS (
    SELECT
        o.seller_id,
        i.item_brand,
        COUNT(*) AS cnt
    FROM Orders o
    JOIN Items i ON o.item_id = i.item_id
    WHERE YEAR(o.order_date) = 2023
    GROUP BY o.seller_id, i.item_brand
),
ranked AS (
    SELECT
        seller_id,
        item_brand,
        cnt,
        RANK() OVER (PARTITION BY seller_id ORDER BY cnt DESC) AS rnk
    FROM brand_sales
)
SELECT
    u.seller_id,
    r.item_brand AS most_sold_brand,
    u.favorite_brand,
    CASE WHEN r.item_brand = u.favorite_brand THEN 'yes' ELSE 'no' END AS is_favorite
FROM Users u
LEFT JOIN ranked r ON u.seller_id = r.seller_id AND r.rnk = 1
ORDER BY u.seller_id;
```

### 方法二：子查询

```sql
SELECT
    u.seller_id,
    CASE WHEN bs.item_brand = u.favorite_brand THEN 'yes' ELSE 'no' END AS 2023_fav_brand
FROM Users u
LEFT JOIN (
    SELECT
        o.seller_id,
        i.item_brand,
        COUNT(*) AS cnt
    FROM Orders o
    JOIN Items i ON o.item_id = i.item_id
    WHERE YEAR(o.order_date) = 2023
    GROUP BY o.seller_id, i.item_brand
    HAVING COUNT(*) = (
        SELECT MAX(cnt2)
        FROM (
            SELECT COUNT(*) AS cnt2
            FROM Orders o2
            JOIN Items i2 ON o2.item_id = i2.item_id
            WHERE o2.seller_id = o.seller_id AND YEAR(o2.order_date) = 2023
            GROUP BY i2.item_brand
        ) sub
    )
) bs ON u.seller_id = bs.seller_id
ORDER BY u.seller_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，窗口函数排序
- 空间复杂度：O(n)

## 关键点总结

1. 使用 RANK() 窗口函数找每个卖家销量最高的品牌
2. 用 LEFT JOIN 处理没有 2023 年订单的卖家
3. CASE WHEN 判断是否为喜爱品牌

## 易错点

1. 有销量相同时 RANK() 会并列，需要根据题意决定是否允许多条记录
2. LEFT JOIN 保留没有订单的卖家
3. 年份过滤用 YEAR() 函数或 BETWEEN
