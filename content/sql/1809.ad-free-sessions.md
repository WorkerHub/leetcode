## 题目描述

表 `Playback`：

| Column Name | Type |
|-------------|------|
| session_id  | int  |
| customer_id | int  |
| start_time  | int  |
| end_time    | int  |

`session_id` 是该表主键。`start_time` 和 `end_time` 分别是会话的开始时间和结束时间（以秒为单位），且 `start_time < end_time`。

表 `Ads`：

| Column Name | Type |
|-------------|------|
| ad_id       | int  |
| customer_id | int  |
| timestamp   | int  |

`ad_id` 是该表主键。`timestamp` 是广告显示的时间（以秒为单位）。

编写 SQL 查询，找出所有 **无广告** 的会话 ID（即在该会话期间，对应 `customer_id` 没有收到任何广告）。

返回按 `session_id` 升序排列的结果。

**示例：**
```
输入：
Playback 表：
+------------+-------------+------------+----------+
| session_id | customer_id | start_time | end_time |
+------------+-------------+------------+----------+
| 1          | 1           | 1          | 5        |
| 2          | 1           | 15         | 23       |
| 3          | 2           | 10         | 12       |
| 4          | 2           | 17         | 28       |
| 5          | 2           | 2          | 8        |
+------------+-------------+------------+----------+
Ads 表：
+-------+-------------+-----------+
| ad_id | customer_id | timestamp |
+-------+-------------+-----------+
| 1     | 1           | 5         |
| 2     | 2           | 17        |
| 3     | 2           | 20        |
+-------+-------------+-----------+
输出：
+------------+
| session_id |
+------------+
| 2          |
| 3          |
| 5          |
+------------+
```

## 解题思路

对于每个会话，判断是否在 `[start_time, end_time]` 区间内，该会话对应的 `customer_id` 收到过广告。

使用 LEFT JOIN 将 `Playback` 和 `Ads` 连接：条件为相同 `customer_id` 且广告时间在会话时间范围内。若连接后广告记录为 NULL，说明该会话无广告。

## 代码实现

### 方法一：LEFT JOIN + IS NULL（推荐）

```sql
SELECT p.session_id
FROM Playback p
LEFT JOIN Ads a
    ON p.customer_id = a.customer_id
    AND a.timestamp BETWEEN p.start_time AND p.end_time
WHERE a.ad_id IS NULL
ORDER BY p.session_id;
```

### 方法二：NOT EXISTS 子查询

```sql
SELECT session_id
FROM Playback p
WHERE NOT EXISTS (
    SELECT 1
    FROM Ads a
    WHERE a.customer_id = p.customer_id
      AND a.timestamp BETWEEN p.start_time AND p.end_time
)
ORDER BY session_id;
```

## 复杂度分析

- **时间复杂度**：O(m * n)，m 为 Playback 行数，n 为 Ads 行数（最坏情况笛卡尔积）
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. `BETWEEN start_time AND end_time` 是闭区间，包含端点
2. LEFT JOIN + WHERE IS NULL 用于查找"不存在匹配"的记录
3. NOT EXISTS 语义更清晰，在某些数据库中性能更优

## 易错点

- 不能直接对 Ads 表 GROUP BY 后 JOIN，需要基于时间范围条件进行 JOIN
- BETWEEN 是闭区间（包含两端），需确认题目边界定义
