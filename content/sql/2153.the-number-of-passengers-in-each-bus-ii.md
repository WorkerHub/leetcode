## 题目描述

表 `Buses`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| bus_id       | int  |
| arrival_time | int  |
| capacity     | int  |
+--------------+------+
```

表 `Passengers`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| passenger_id | int  |
| arrival_time | int  |
+--------------+------+
```

乘客上公交的规则与 2142 相同，但每辆公交有容量限制 `capacity`。先到的乘客先上车（到达时间更早或 id 更小的优先），超过容量的乘客等下一班车。

返回每辆公交车上的实际乘客数。

**提示：**
- 如果乘客比所有公交都晚到，则无法登车。
- 公交按到站时间顺序运行。

## 解题思路

这道题比 2142 难，因为有容量限制，需要按顺序模拟：
1. 按公交到站时间排序。
2. 对每辆公交，从候车的乘客中按优先级（到达时间, passenger_id）选取最多 capacity 个。

SQL 实现思路：用 ROW_NUMBER 为每个乘客按优先级排名，再分配到公交。

## 代码实现

### 方法一：分步 CTE（推荐）

```sql
WITH ordered_buses AS (
    -- 为每辆公交按到站时间编号
    SELECT bus_id, arrival_time, capacity,
           ROW_NUMBER() OVER (ORDER BY arrival_time) AS bus_rank
    FROM Buses
),
ordered_passengers AS (
    -- 为每个乘客按到站时间排序
    SELECT passenger_id, arrival_time,
           ROW_NUMBER() OVER (ORDER BY arrival_time, passenger_id) AS pax_rank
    FROM Passengers
),
bus_capacity_cumsum AS (
    -- 计算每辆公交之前所有车的累计容量
    SELECT bus_id, arrival_time, capacity, bus_rank,
           SUM(capacity) OVER (ORDER BY bus_rank) AS cum_capacity,
           SUM(capacity) OVER (ORDER BY bus_rank) - capacity AS prev_capacity
    FROM ordered_buses
),
passenger_assignment AS (
    -- 为每个乘客找到对应的公交
    SELECT op.passenger_id, bc.bus_id
    FROM ordered_passengers op
    JOIN bus_capacity_cumsum bc 
        ON op.arrival_time <= bc.arrival_time
        AND op.pax_rank <= bc.cum_capacity
        AND op.pax_rank > bc.prev_capacity
)
SELECT b.bus_id, COUNT(pa.passenger_id) AS passengers_cnt
FROM Buses b
LEFT JOIN passenger_assignment pa ON pa.bus_id = b.bus_id
GROUP BY b.bus_id
ORDER BY b.bus_id;
```

### 方法二：更简洁的实现

```sql
WITH cum_cap AS (
    SELECT bus_id, arrival_time, capacity,
           SUM(capacity) OVER (ORDER BY arrival_time, bus_id ROWS UNBOUNDED PRECEDING) AS cum_cap_end,
           SUM(capacity) OVER (ORDER BY arrival_time, bus_id ROWS UNBOUNDED PRECEDING) - capacity AS cum_cap_start
    FROM Buses
),
pax_rank AS (
    SELECT passenger_id, arrival_time,
           ROW_NUMBER() OVER (ORDER BY arrival_time, passenger_id) - 1 AS rk
    FROM Passengers
)
SELECT b.bus_id, COUNT(p.passenger_id) AS passengers_cnt
FROM Buses b
LEFT JOIN (
    SELECT pr.passenger_id, cc.bus_id
    FROM pax_rank pr
    JOIN cum_cap cc 
        ON pr.arrival_time <= cc.arrival_time
        AND pr.rk >= cc.cum_cap_start
        AND pr.rk < cc.cum_cap_end
) assigned ON assigned.bus_id = b.bus_id
GROUP BY b.bus_id
ORDER BY b.bus_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| CTE + 窗口函数 | O(P * B) | O(P + B) |

## 关键点总结

1. 关键思路：用累计容量的区间 `[cum_cap_start, cum_cap_end)` 匹配乘客的排名。
2. 需保证乘客到站时间 <= 公交到站时间（才能上这辆车）。
3. 容量限制通过累计容量的区间实现：第 bus_k 辆车容纳第 `[prev_sum, prev_sum+capacity)` 名的乘客。

## 易错点

- ROW_NUMBER 从 1 开始，而累计容量从 capacity 开始；需要确认偏移量一致。
- 多辆公交同时到站时需要按 bus_id 进一步排序。
