## 题目描述

编写SQL查询来计算每个员工的累计工资总和，排除最近一个月。

## SQL 代码实现

```sql
SELECT 
    e1.id,
    e1.month,
    SUM(e2.salary) AS Salary
FROM Employee e1
JOIN Employee e2 ON e1.id = e2.id AND e2.month <= e1.month
WHERE (e1.id, e1.month) NOT IN (
    SELECT id, MAX(month)
    FROM Employee
    GROUP BY id
)
GROUP BY e1.id, e1.month
ORDER BY e1.id ASC, e1.month DESC;
```

## 关键点总结

1. **自连接**：计算累计和
2. **排除最近月**：NOT IN (SELECT MAX(month))
3. **窗口函数替代**：可使用 SUM() OVER()

## 学习建议

掌握自连接计算累计和，学习窗口函数。
