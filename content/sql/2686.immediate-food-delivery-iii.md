## 题目描述

本题为 SQL 题目。`Delivery` 表记录外卖订单，包含客户 ID、订单日期和首选配送日期。若 `order_date == customer_pref_delivery_date`，则为即时订单，否则为计划订单。

查询每个月份中即时订单的百分比（保留两位小数）。

**表结构：**
```
Delivery 表：
delivery_id | customer_id | order_date | customer_pref_delivery_date
```

## SQL 代码实现

### 方法一：按月分组统计

```sql
-- 查询每个月的即时订单百分比
SELECT 
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    ROUND(
        100.0 * SUM(CASE WHEN order_date = customer_pref_delivery_date THEN 1 ELSE 0 END) / COUNT(*),
        2
    ) AS immediate_percentage
FROM Delivery
GROUP BY DATE_FORMAT(order_date, '%Y-%m')
ORDER BY month;
```

### 方法二：使用 AVG

```sql
SELECT
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    ROUND(
        100.0 * AVG(order_date = customer_pref_delivery_date),
        2
    ) AS immediate_percentage
FROM Delivery
GROUP BY month
ORDER BY month;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 即时订单：订单日期 = 首选配送日期
2. `DATE_FORMAT` 格式化日期为年月
3. 百分比需四舍五入到两位小数

## 易错点

1. 记得乘以 100（百分比）
2. 分母是该月的总订单数
