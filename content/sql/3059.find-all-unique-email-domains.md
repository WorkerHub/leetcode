## 题目描述

表：`Emails`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
```

`id` 是主键。

找出所有以 `.com` 结尾的唯一邮箱域名，按域名升序返回。

## SQL 代码实现

### 方法一：字符串截取（推荐）

```sql
SELECT DISTINCT
    SUBSTRING_INDEX(email, '@', -1) AS email_domain
FROM Emails
WHERE email LIKE '%.com'
ORDER BY email_domain ASC;
```

### 方法二：正则匹配

```sql
SELECT DISTINCT
    REGEXP_SUBSTR(email, '[^@]+$') AS email_domain
FROM Emails
WHERE email REGEXP '\\.com$'
ORDER BY email_domain;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(k)，k 为不同域名数

## 关键点总结

1. `SUBSTRING_INDEX(email, '@', -1)` 提取 @ 后面的部分（即域名）
2. `WHERE email LIKE '%.com'` 过滤 .com 域名
3. `DISTINCT` 去重

## 易错点

1. 需要以 `.com` **结尾**（不只是包含 .com）
2. 域名是 `@` 后面的完整字符串
