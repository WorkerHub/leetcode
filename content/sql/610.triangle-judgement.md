## 题目描述

表：`Triangle`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
| y           | int  |
| z           | int  |
+-------------+------+
```

在 SQL 中，`(x, y, z)` 是该表的主键列。
该表的每一行包含三个线段的长度。

对于表中的每一行，判断由这三条线段构成的三角形是否有效。

返回结果表**无顺序要求**。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Triangle 表：
+----+----+----+
| x  | y  | z  |
+----+----+----+
| 13 | 15 | 30 |
| 10 | 20 | 15 |
+----+----+----+

输出：
+----+----+----+----------+
| x  | y  | z  | triangle |
+----+----+----+----------+
| 13 | 15 | 30 | No       |
| 10 | 20 | 15 | Yes      |
+----+----+----+----------+
```

## 解题思路

这是一道简单的**三角形判定**问题。

**三角形成立条件：**

三条边 a、b、c 能构成三角形，当且仅当：
- `a + b > c`
- `a + c > b`
- `b + c > a`

**简化条件：**

由于三个不等式必须同时满足，可以简化为：
- **任意两边之和大于第三边**

## SQL 代码实现

### 方法一：CASE WHEN（推荐）⭐

```sql
SELECT x, y, z,
    CASE
        WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

### 方法二：使用 IF（MySQL）

```sql
SELECT x, y, z,
    IF(x + y > z AND x + z > y AND y + z > x, 'Yes', 'No') AS triangle
FROM Triangle;
```

### 方法三：简化条件（最优雅）⭐⭐

```sql
-- 由于对称性，可以先排序再判断
SELECT x, y, z,
    CASE
        WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历每一行
- **空间复杂度**：O(1)

## 关键点总结

1. **三角形成立条件**：任意两边之和大于第三边
2. **三个条件必须同时满足**：用 AND 连接
3. **CASE WHEN vs IF**：CASE WHEN 是标准 SQL，IF 仅 MySQL 支持
4. **边界情况**：等号不成立，必须是严格大于

## 易错点

1. **忘记某个条件**：
   ```sql
   -- ❌ 错误：只检查了两个条件
   WHEN x + y > z AND x + z > y
   -- 缺少 y + z > x
   ```

2. **使用大于等于**：
   ```sql
   -- ❌ 错误：三角形两边之和必须严格大于第三边
   WHEN x + y >= z
   -- 应该用 >
   ```

3. **逻辑运算符错误**：
   ```sql
   -- ❌ 错误：用 OR 而非 AND
   WHEN x + y > z OR x + z > y OR y + z > x
   -- 三个条件必须同时满足
   ```

## 学习建议

**新手学习路径：**

1. **理解三角形条件**：
   - 任意两边之和 > 第三边
   - 三个条件缺一不可

2. **CASE WHEN 语法**：
   ```sql
   CASE
       WHEN condition THEN value1
       ELSE value2
   END AS column_name
   ```

3. **手动验证**：
   - 示例 1：13 + 15 = 28 < 30 ❌
   - 示例 2：10 + 15 = 25 > 20 ✅，10 + 20 = 30 > 15 ✅，15 + 20 = 35 > 10 ✅
