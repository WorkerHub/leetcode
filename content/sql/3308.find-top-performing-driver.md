## 题目描述

表：`Drivers`
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| driver_id   | int     |
| name        | varchar |
| age         | int     |
| experience  | int     |
| accidents   | int     |
+-------------+---------+
driver_id 是该表的主键。
```

表：`Vehicles`
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| vehicle_id  | int     |
| driver_id   | int     |
| model       | varchar |
| fuel_type   | varchar |
| mileage     | int     |
+-------------+---------+
vehicle_id 是该表的主键。
```

表：`Trips`
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| trip_id     | int     |
| vehicle_id  | int     |
| distance    | int     |
| duration    | int     |
| rating      | int     |
+-------------+---------+
trip_id 是该表的主键。
```

查找每种燃料类型中表现最佳的司机。表现基于以下规则：
1. 计算每位司机的**平均评分**（保留2位小数）。
2. 平均评分最高的为最佳，若平均评分相同，取**总行驶里程**最高的。
3. 若仍相同，取 `driver_id` 最小的。

返回结果按 `fuel_type` 升序排列。

## 解题思路

1. 连接三张表：`Trips` JOIN `Vehicles` JOIN `Drivers`。
2. 按 `fuel_type` 和 `driver_id` 分组，计算每位司机在每种燃料类型下的平均评分和总里程。
3. 使用窗口函数 `RANK()` 或 `ROW_NUMBER()` 在每个燃料类型分组内排名。
4. 取排名第一的记录。

## 代码实现

```sql
-- 使用窗口函数找出每种燃料类型的最佳司机
WITH driver_stats AS (
    SELECT
        v.fuel_type,
        d.driver_id,
        d.name,
        ROUND(AVG(t.rating), 2) AS avg_rating,
        SUM(t.distance) AS total_distance
    FROM Trips t
    JOIN Vehicles v ON t.vehicle_id = v.vehicle_id
    JOIN Drivers d ON v.driver_id = d.driver_id
    GROUP BY v.fuel_type, d.driver_id, d.name
),
ranked AS (
    SELECT
        fuel_type,
        driver_id,
        name,
        avg_rating,
        total_distance,
        ROW_NUMBER() OVER (
            PARTITION BY fuel_type
            ORDER BY avg_rating DESC, total_distance DESC, driver_id ASC
        ) AS rk
    FROM driver_stats
)
SELECT
    fuel_type,
    driver_id,
    name,
    avg_rating,
    total_distance
FROM ranked
WHERE rk = 1
ORDER BY fuel_type ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和分组操作
- 空间复杂度：O(n)，中间结果集

## 关键点总结

1. 三表连接：Trips -> Vehicles -> Drivers，通过 `vehicle_id` 和 `driver_id` 关联。
2. 多级排序：先按平均评分降序，再按总里程降序，最后按 `driver_id` 升序。
3. `ROW_NUMBER()` 而非 `RANK()`：确保每个燃料类型只取一条记录。

## 易错点

1. `ROUND(AVG(rating), 2)` 保留 2 位小数。
2. 分组时需要同时按 `fuel_type`、`driver_id`、`name` 分组（或在外层处理）。
3. 最终结果需按 `fuel_type` 升序排列。
