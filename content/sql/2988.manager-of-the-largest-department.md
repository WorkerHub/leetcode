## 题目描述

本题为数据库题目。

给定表 `Employees`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_id      | int     |
| emp_name    | varchar |
| dep_id      | int     |
| position    | varchar |
+-------------+---------+
```

找出员工人数最多的部门的经理（position = 'Manager'），返回经理名称和部门 ID。若有并列，都返回。

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH dep_size AS (
    SELECT dep_id, COUNT(*) AS emp_count
    FROM Employees
    GROUP BY dep_id
),
max_size AS (
    SELECT MAX(emp_count) AS max_count FROM dep_size
)
SELECT e.emp_name, e.dep_id
FROM Employees e
JOIN dep_size ds ON e.dep_id = ds.dep_id
JOIN max_size ms ON ds.emp_count = ms.max_count
WHERE e.position = 'Manager'
ORDER BY e.dep_id;
```

### 方法二：HAVING 子句

```sql
SELECT e.emp_name, e.dep_id
FROM Employees e
WHERE e.position = 'Manager'
  AND e.dep_id IN (
    SELECT dep_id
    FROM Employees
    GROUP BY dep_id
    HAVING COUNT(*) = (
        SELECT MAX(cnt)
        FROM (SELECT COUNT(*) AS cnt FROM Employees GROUP BY dep_id) sub
    )
  )
ORDER BY e.dep_id;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为部门数

## 关键点总结

1. 先统计各部门人数，找最大值
2. 找包含最大人数部门的经理
3. 允许并列（多个最大部门）

## 易错点

1. 并列情况：多个部门员工数相同时都要返回
2. 要找 position = 'Manager' 的员工
