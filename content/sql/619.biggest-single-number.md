## 题目描述

编写一个 SQL 查询，找出所有只出现一次的数字中最大的数字。如果没有只出现一次的数字，返回 null。

表：`MyNumbers`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| num         | int  |
+-------------+------+
```

该表可能包含重复项（即没有主键）。该表的每一行都包含一个整数。

**示例 1：**

```
输入：
MyNumbers 表：
+-----+
| num |
+-----+
| 8   |
| 8   |
| 3   |
| 3   |
| 1   |
| 4   |
| 5   |
| 6   |
+-----+
输出：
+-----+
| num |
+-----+
| 6   |
+-----+
解释：只出现一次的数字有 1, 4, 5, 6。最大的是 6。
```

**示例 2：**

```
输入：
MyNumbers 表：
+-----+
| num |
+-----+
| 8   |
| 8   |
| 7   |
| 7   |
| 3   |
| 3   |
| 3   |
+-----+
输出：
+------+
| num  |
+------+
| null |
+------+
解释：没有只出现一次的数字，所以返回 null。
```

## 解题思路

这道题是一个典型的 SQL 聚合查询问题，需要：

1. 使用 `GROUP BY` 分组统计每个数字的出现次数
2. 使用 `HAVING` 筛选出只出现一次的数字
3. 使用 `MAX()` 找出最大值
4. 处理没有符合条件数字的情况（返回 null）

核心思想：
- 先分组计数，找出所有只出现一次的数字
- 然后在这些数字中找最大值
- 如果结果集为空，SQL 的 `MAX()` 函数会自动返回 null

## SQL 解法实现

### 方法一：使用子查询（推荐）

```sql
SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(num) = 1
) AS single_numbers;
```

**解释：**
1. 内层查询：使用 `GROUP BY num` 分组，`HAVING COUNT(num) = 1` 筛选只出现一次的数字
2. 外层查询：对筛选结果使用 `MAX()` 找出最大值
3. 如果内层查询返回空集，`MAX()` 会自动返回 null

### 方法二：直接使用聚合函数

```sql
SELECT MAX(num) AS num
FROM MyNumbers
GROUP BY num
HAVING COUNT(num) = 1;
```

**注意：** 这个方法在某些数据库中可能不正确，因为它会对每个分组返回 MAX，而不是全局的 MAX。

### 方法三：使用 LIMIT（适用于 MySQL）

```sql
SELECT num
FROM MyNumbers
GROUP BY num
HAVING COUNT(num) = 1
ORDER BY num DESC
LIMIT 1;
```

**问题：** 如果没有符合条件的数字，这个方法返回空结果集而不是 null。

### 方法四：使用 CASE WHEN 处理 null

```sql
SELECT 
    CASE 
        WHEN COUNT(*) = 0 THEN NULL
        ELSE MAX(num)
    END AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(num) = 1
) AS single_numbers;
```

## 复杂度分析

**SQL 方法一（推荐）：**
- 时间复杂度：O(n)，其中 n 是表中的行数，需要扫描一次表进行分组统计
- 空间复杂度：O(k)，其中 k 是不同数字的个数，用于存储分组结果

**Python 实现：**
- 时间复杂度：O(n)，需要遍历所有数据进行统计
- 空间复杂度：O(k)，k 是不同数字的个数

## 关键点总结

1. **使用 HAVING 而不是 WHERE**：`HAVING` 用于过滤分组后的结果，而 `WHERE` 在分组前过滤
2. **MAX() 自动处理 null**：当子查询返回空集时，`MAX()` 会返回 null，无需额外处理
3. **子查询的使用**：先筛选出符合条件的数字，再对结果集进行聚合操作
4. **COUNT() 的用法**：`COUNT(num)` 统计非 null 值的个数

## 易错点

1. **方法二的陷阱**：直接在 GROUP BY 后使用 MAX 可能得到多个分组的最大值，而不是全局最大值
2. **LIMIT 的局限性**：使用 LIMIT 1 时，如果没有结果会返回空集而不是 null
3. **COUNT(*) vs COUNT(num)**：在这个问题中两者等价，但 COUNT(*) 包括 null 值，COUNT(num) 不包括
4. **忘记处理空结果**：虽然 MAX 自动返回 null，但在某些实现中需要显式处理
