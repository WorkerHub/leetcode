## 题目描述

表 `Sales`：

| 列名 | 类型 |
|------|------|
| sale_date | date |
| fruit | enum |
| sold_num | int |

- `(sale_date, fruit)` 是主键。
- `fruit` 是枚举类型，值为 `'apples'` 或 `'oranges'`。
- 该表包含每天苹果和橙子的销售情况。

编写 SQL 查询，统计每天**苹果销售量与橙子销售量的差值**（苹果数 - 橙子数）。

结果按 `sale_date` 排序。

**示例：**

Sales 表：
| sale_date | fruit | sold_num |
|-----------|-------|----------|
| 2020-05-01 | apples | 10 |
| 2020-05-01 | oranges | 8 |
| 2020-05-02 | apples | 15 |
| 2020-05-02 | oranges | 15 |
| 2020-05-03 | apples | 20 |
| 2020-05-03 | oranges | 0 |
| 2020-05-04 | apples | 15 |
| 2020-05-04 | oranges | 16 |

输出：
| sale_date | diff |
|-----------|------|
| 2020-05-01 | 2 |
| 2020-05-02 | 0 |
| 2020-05-03 | 20 |
| 2020-05-04 | -1 |

## 解题思路

**方法一：GROUP BY + SUM + CASE WHEN**

在 `GROUP BY sale_date` 的基础上，用 `CASE WHEN` 区分苹果和橙子，分别求和再相减：
```
SUM(CASE WHEN fruit='apples' THEN sold_num ELSE 0 END)
- SUM(CASE WHEN fruit='oranges' THEN sold_num ELSE 0 END)
```

**方法二：自连接（Self Join）**

将苹果数据和橙子数据分别筛选出来，再以 `sale_date` 连接。

## SQL 解法

### 方法一：GROUP BY + CASE WHEN（推荐）

```sql
SELECT
    sale_date,
    SUM(CASE WHEN fruit = 'apples'  THEN sold_num ELSE 0 END) -
    SUM(CASE WHEN fruit = 'oranges' THEN sold_num ELSE 0 END) AS diff
FROM Sales
GROUP BY sale_date
ORDER BY sale_date;
```

### 方法二：GROUP BY + IF（MySQL 特有）

```sql
SELECT
    sale_date,
    SUM(IF(fruit = 'apples', sold_num, -sold_num)) AS diff
FROM Sales
GROUP BY sale_date
ORDER BY sale_date;
```

**解释：** 苹果的 `sold_num` 加正值，橙子的 `sold_num` 加负值，等价于苹果数 - 橙子数。

### 方法三：自连接

```sql
SELECT
    a.sale_date,
    a.sold_num - o.sold_num AS diff
FROM
    (SELECT sale_date, sold_num FROM Sales WHERE fruit = 'apples')  AS a
JOIN
    (SELECT sale_date, sold_num FROM Sales WHERE fruit = 'oranges') AS o
ON a.sale_date = o.sale_date
ORDER BY a.sale_date;
```

## 复杂度分析

- **时间复杂度：** O(n log n)，n 为 Sales 表行数（GROUP BY 和 ORDER BY 需要排序）。
- **空间复杂度：** O(d)，d 为不同日期数量。

## 关键点总结

1. 方法二最简洁：`IF(fruit='apples', sold_num, -sold_num)` 利用符号直接转化差值为求和问题。
2. `SUM(CASE WHEN ...)` 是标准 SQL，跨数据库兼容性最好。
3. 题目保证每天苹果和橙子都有数据，所以自连接不会有 NULL 问题（若不确定应用 LEFT JOIN + COALESCE）。
4. `ORDER BY sale_date` 按日期排序，日期类型自然有序。

## 易错点

- 忘记 `ORDER BY sale_date`，结果无序。
- 使用 `CASE WHEN` 但漏写 `ELSE 0`，导致没有该水果数据的行产生 NULL（本题不影响，因为保证每天都有两种）。
- 自连接时别名冲突或 ON 条件写错。
