## 题目描述

表 `Customers`：

| Column Name | Type |
|-------------|------|
| customer_id | int  |
| year        | int  |
| revenue     | int  |

`(customer_id, year)` 是主键。`revenue` 可以是负数。

编写 SQL 查询，找出 2021 年收入为 **正数** 的所有顾客 ID。

返回任意顺序的结果。

**示例：**
```
输入：
+-------------+------+---------+
| customer_id | year | revenue |
+-------------+------+---------+
| 1           | 2018 | 50      |
| 1           | 2021 | 30      |
| 1           | 2020 | 70      |
| 2           | 2021 | -50     |
| 3           | 2018 | 10      |
| 3           | 2016 | 50      |
| 4           | 2021 | 20      |
+-------------+------+---------+
输出：
+-------------+
| customer_id |
+-------------+
| 1           |
| 4           |
+-------------+
```

## 解题思路

直接用 `WHERE` 过滤 `year = 2021` 且 `revenue > 0` 的记录，返回 `customer_id`。

## 代码实现

### 方法一：直接 WHERE 过滤（推荐）

```sql
SELECT customer_id
FROM Customers
WHERE year = 2021
  AND revenue > 0;
```

### 方法二：子查询（语义等价）

```sql
SELECT DISTINCT customer_id
FROM Customers
WHERE year = 2021
  AND revenue > 0
ORDER BY customer_id;
```

## 复杂度分析

- **时间复杂度**：O(n)，扫描整张表
- **空间复杂度**：O(1)

## 关键点总结

1. 同时满足 `year = 2021` 和 `revenue > 0` 两个条件
2. 题目说 `(customer_id, year)` 是主键，所以每个 customer 在 2021 年最多一条记录，不需要 DISTINCT

## 易错点

- `revenue > 0` 不包含 revenue = 0（0 不是正数）
- 注意只查 2021 年，不是所有年份
