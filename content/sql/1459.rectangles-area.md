## 题目描述

表：`Points`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| x_value       | int     |
| y_value       | int     |
+---------------+---------+
id 是该表的主键。
每个点都表示为二维坐标（x_value, y_value）。
```

写一个 SQL 语句，从表中选出两个点，其中一个点作为矩形左下角，另一个点作为矩形右上角，组成一个**非退化**的矩形（面积不为零）。

查询每个满足条件的矩形的面积，以及组成它的点的 `id`（`p1` 和 `p2`，`p1 < p2`）。

结果按面积**降序**排列，若面积相同，按 `p1` **升序**，再按 `p2` **升序**。

**示例：**

`Points` 表：
```
+----------+-------------+-------------+
| id       | x_value     | y_value     |
+----------+-------------+-------------+
| 1        | 2           | 7           |
| 2        | 4           | 8           |
| 3        | 2           | 10          |
+----------+-------------+-------------+
```

结果表：
```
+----------+-------------+-------------+
| p1       | p2          | area        |
+----------+-------------+-------------+
| 2        | 3           | 4           |
| 1        | 2           | 2           |
| 1        | 3           | 2           |
+----------+-------------+-------------+
```
解释：
- (4,8) 和 (2,10)：宽 = |4-2| = 2，高 = |10-8| = 2，面积 = 4
- (2,7) 和 (4,8)：宽 = |4-2| = 2，高 = |8-7| = 1，面积 = 2
- (2,7) 和 (2,10)：x 坐标相同，退化（面积 = 0），不返回
- (4,8) 和 (2,10)：面积 = 4，p1=2，p2=3

## 解题思路

**思路：自连接枚举所有点对**

1. 对 Points 表做自连接，枚举所有 `p1 < p2` 的点对（避免重复）
2. 计算矩形面积：`|x1 - x2| * |y1 - y2|`
3. 过滤掉面积为 0 的退化矩形（即 x 坐标相同或 y 坐标相同）
4. 按面积降序、p1 升序、p2 升序排列

## SQL 解法

### 方法一：自连接（推荐）

```sql
SELECT
    p1.id AS p1,
    p2.id AS p2,
    ABS(p1.x_value - p2.x_value) * ABS(p1.y_value - p2.y_value) AS area
FROM Points p1
JOIN Points p2 ON p1.id < p2.id
WHERE p1.x_value != p2.x_value  -- 排除 x 相同（退化）
  AND p1.y_value != p2.y_value  -- 排除 y 相同（退化）
ORDER BY area DESC, p1 ASC, p2 ASC;
```

### 方法二：CROSS JOIN + HAVING（等价写法）

```sql
SELECT
    p1.id AS p1,
    p2.id AS p2,
    ABS(p1.x_value - p2.x_value) * ABS(p1.y_value - p2.y_value) AS area
FROM Points p1
CROSS JOIN Points p2
WHERE p1.id < p2.id
  AND ABS(p1.x_value - p2.x_value) * ABS(p1.y_value - p2.y_value) > 0
ORDER BY area DESC, p1 ASC, p2 ASC;
```

### 方法三：CTE 写法（更清晰）

```sql
WITH rectangle_candidates AS (
    SELECT
        p1.id AS p1,
        p2.id AS p2,
        ABS(p1.x_value - p2.x_value) AS width,
        ABS(p1.y_value - p2.y_value) AS height
    FROM Points p1
    JOIN Points p2 ON p1.id < p2.id
)
SELECT
    p1,
    p2,
    width * height AS area
FROM rectangle_candidates
WHERE width > 0 AND height > 0   -- 排除退化矩形
ORDER BY area DESC, p1 ASC, p2 ASC;
```

## 复杂度分析

- 时间复杂度：O(n^2)，自连接枚举所有点对
- 空间复杂度：O(n^2)，中间结果集大小

## 关键点总结

1. `p1.id < p2.id` 保证每对点只出现一次，且 p1 < p2
2. 面积不为零等价于两点 x 坐标不同**且** y 坐标不同（两个条件都要满足）
3. 使用 `ABS()` 处理坐标差的绝对值，避免负数

## 易错点

- **退化条件**：只有当 x 不同且 y 不同时，矩形才非退化。仅 x 不同或仅 y 不同都会导致面积为 0
- `WHERE area > 0` 和 `WHERE x1 != x2 AND y1 != y2` 等价，但后者在过滤阶段更早执行，效率更高
- 排序条件：先按 area 降序，相同 area 再按 p1 升序，再按 p2 升序
