## 题目描述

表：`logs`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| log_id           | int     |
| timestamp        | int     |
| value            | int     |
+------------------+---------+
log_id 是主键。
```

对每个 `log_id`，返回截至该日志（按 `timestamp` 排序）的累计统计信息：
- `minimum`：到目前为止的最小 `value`
- `maximum`：到目前为止的最大 `value`
- `first_value`：最早的 `value`（timestamp 最小）
- `last_value`：最新的 `value`（当前 log_id 的 value）
- `total`：累计 `value` 之和

按 `log_id` 升序返回。

## 解题思路

使用窗口函数实现累积统计：
- `MIN(value) OVER (ORDER BY timestamp)`：累积最小值
- `MAX(value) OVER (ORDER BY timestamp)`：累积最大值
- `FIRST_VALUE(value) OVER (ORDER BY timestamp)`：第一个值
- `value`：当前行的值（即 last_value）
- `SUM(value) OVER (ORDER BY timestamp)`：累积和

## 代码实现

```sql
SELECT
    log_id,
    timestamp,
    value,
    MIN(value) OVER (ORDER BY timestamp ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS minimum,
    MAX(value) OVER (ORDER BY timestamp ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS maximum,
    FIRST_VALUE(value) OVER (ORDER BY timestamp ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS first_value,
    value AS last_value,
    SUM(value) OVER (ORDER BY timestamp ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS total
FROM logs
ORDER BY log_id ASC;
```

### 简化版（隐式窗口）

```sql
SELECT
    log_id,
    MIN(value) OVER (ORDER BY timestamp) AS minimum,
    MAX(value) OVER (ORDER BY timestamp) AS maximum,
    FIRST_VALUE(value) OVER (ORDER BY timestamp) AS first_value,
    value AS last_value,
    SUM(value) OVER (ORDER BY timestamp) AS total
FROM logs
ORDER BY log_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 窗口函数
- 空间复杂度：O(n)

## 关键点总结

1. 窗口函数 `OVER (ORDER BY timestamp)` 默认是从第一行到当前行（累积窗口）。
2. `FIRST_VALUE` 返回窗口第一行的值（固定不变）。
3. `last_value` 直接取当前行的 `value`，不需要窗口函数。

## 易错点

1. 窗口函数的默认范围是 `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`（累积）。
2. `LAST_VALUE` 函数默认范围是当前行本身，需要显式指定全窗口（或直接用 `value`）。
3. 按 `log_id` 排序输出，但窗口计算按 `timestamp` 排序。
