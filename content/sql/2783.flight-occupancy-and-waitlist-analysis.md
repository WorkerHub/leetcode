## 题目描述

表 `Flights`（`flight_id`, `capacity`）和表 `Passengers`（`passenger_id`, `flight_id`, `boarding_time`）。

对每个航班，统计：
- 已登机乘客数（等于 `min(预订人数, capacity)`）
- 候补名单人数（超出容量的乘客数）

返回每个航班的 `flight_id`、`boarded`（已登机人数）、`waitlist`（候补人数）。

## 解题思路

1. 统计每个航班的预订人数
2. `boarded = min(预订人数, capacity)`
3. `waitlist = max(0, 预订人数 - capacity)`

## 代码实现

### 方法一：SQL 实现（推荐）

```sql
SELECT
    f.flight_id,
    -- 已登机：取预订人数和容量的较小值
    LEAST(COALESCE(p.passenger_count, 0), f.capacity) AS boarded,
    -- 候补：超出容量的乘客数（非负）
    GREATEST(0, COALESCE(p.passenger_count, 0) - f.capacity) AS waitlist
FROM Flights f
LEFT JOIN (
    SELECT flight_id, COUNT(*) AS passenger_count
    FROM Passengers
    GROUP BY flight_id
) p ON f.flight_id = p.flight_id
ORDER BY f.flight_id;
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为航班数，m 为乘客数
- 空间复杂度：O(n + m)

## 关键点总结

1. LEFT JOIN 确保没有乘客的航班也包含在结果中
2. `COALESCE` 处理没有乘客时的 NULL
3. `LEAST` 和 `GREATEST` 分别计算 min 和 max

## 易错点

1. 没有乘客的航班乘客数为 0（不是 NULL）
2. waitlist 不能为负
