## 题目描述

表 `Weather` 结构如下：

| Column Name | Type |
|-------------|------|
| city_id     | int  |
| day         | date |
| degree      | int  |

`(city_id, day)` 是该表的主键。每行包含某城市某天的气温记录。

查询每个城市记录**最高气温**当天的信息（如果最高气温出现在多天，选择最早的那天）。

返回结果包含：`city_id`、`day`、`degree`，按 `city_id` 升序排列。

**示例：**
```
输入：
Weather 表：
+---------+------------+--------+
| city_id | day        | degree |
+---------+------------+--------+
| 1       | 2022-01-07 | -12    |
| 1       | 2022-03-12 | 5      |
| 1       | 2022-06-01 | 18     |
| 2       | 2022-08-09 | 16     |
| 2       | 2022-01-21 | -7     |
| 2       | 2021-08-09 | 5      |
| 3       | 2021-08-09 | 17     |
+---------+------------+--------+

输出：
+---------+------------+--------+
| city_id | day        | degree |
+---------+------------+--------+
| 1       | 2022-06-01 | 18     |
| 2       | 2022-08-09 | 16     |
| 3       | 2021-08-09 | 17     |
+---------+------------+--------+
```

## 解题思路

**方法一：子查询 + GROUP BY**
先用 GROUP BY 找出每个城市的最高气温，再关联回原表找对应最早日期。

**方法二：窗口函数 RANK()**
按城市分组，按气温降序、日期升序排名，取排名为 1 的记录。

## 代码实现

### 方法一：子查询（推荐）

```sql
SELECT w.city_id, MIN(w.day) AS day, w.degree
FROM Weather w
INNER JOIN (
    -- 每个城市的最高气温
    SELECT city_id, MAX(degree) AS max_degree
    FROM Weather
    GROUP BY city_id
) m ON w.city_id = m.city_id AND w.degree = m.max_degree
GROUP BY w.city_id, w.degree
ORDER BY w.city_id
```

### 方法二：窗口函数 RANK()

```sql
SELECT city_id, day, degree
FROM (
    SELECT 
        city_id, 
        day, 
        degree,
        RANK() OVER (
            PARTITION BY city_id 
            ORDER BY degree DESC, day ASC
        ) AS rk
    FROM Weather
) ranked
WHERE rk = 1
ORDER BY city_id
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 子查询 | O(n log n) | O(n) |
| 窗口函数 | O(n log n) | O(n) |

## 关键点总结

1. 先找最高气温，再找对应最早日期，避免直接 GROUP BY 导致 day 字段不确定。
2. 窗口函数 `RANK()` 按气温降序、日期升序排列，第一名即为目标记录。
3. 若最高气温出现在多天，选最早一天，因此日期排序用 `ASC`。

## 易错点

- 不能直接 `SELECT city_id, day, MAX(degree)`，因为 `day` 不在聚合函数中会报错（MySQL 严格模式）。
- 需要在外层用 `MIN(day)` 或排序后取第一条。
