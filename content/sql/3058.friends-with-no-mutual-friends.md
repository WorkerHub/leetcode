## 题目描述

表：`Friends`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id1    | int  |
| user_id2    | int  |
+-------------+------+
```

`(user_id1, user_id2)` 是主键，`user_id1 < user_id2`。

找出所有没有共同朋友的朋友对。返回 `user_id1`、`user_id2`，按 `user_id1` 升序、`user_id2` 升序排列。

## SQL 代码实现

### 方法一：子查询排除有共同朋友的对（推荐）

```sql
WITH AllFriends AS (
    -- 将友谊关系双向化
    SELECT user_id1 AS uid, user_id2 AS friend FROM Friends
    UNION ALL
    SELECT user_id2 AS uid, user_id1 AS friend FROM Friends
)
SELECT f.user_id1, f.user_id2
FROM Friends f
WHERE NOT EXISTS (
    SELECT 1
    FROM AllFriends a1
    JOIN AllFriends a2 ON a1.friend = a2.friend
    WHERE a1.uid = f.user_id1 AND a2.uid = f.user_id2
)
ORDER BY f.user_id1, f.user_id2;
```

### 方法二：LEFT JOIN 找共同朋友

```sql
WITH AllFriends AS (
    SELECT user_id1 AS uid, user_id2 AS fid FROM Friends
    UNION ALL
    SELECT user_id2, user_id1 FROM Friends
)
SELECT f.user_id1, f.user_id2
FROM Friends f
LEFT JOIN (
    SELECT DISTINCT a1.uid AS u1, a2.uid AS u2
    FROM AllFriends a1
    JOIN AllFriends a2 ON a1.fid = a2.fid AND a1.uid < a2.uid
) mutual ON mutual.u1 = f.user_id1 AND mutual.u2 = f.user_id2
WHERE mutual.u1 IS NULL
ORDER BY f.user_id1, f.user_id2;
```

## 复杂度分析

- 时间复杂度：O(n^2)，需要比较所有朋友对的朋友集合
- 空间复杂度：O(n)

## 关键点总结

1. 共同朋友：两人都与第三人是朋友
2. 双向化友谊关系便于查询
3. NOT EXISTS 或 LEFT JOIN IS NULL 找没有共同朋友的对

## 易错点

1. 友谊表是单向存储（user_id1 < user_id2），查询时需要双向化
2. 共同朋友不包括两人自己
