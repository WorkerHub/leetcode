## 题目描述

编写一个SQL查询来报告获胜候选人的姓名（即获得最多选票的候选人）。

表：`Candidate`
```
+-----+------+
| id  | name |
+-----+------+
|  1  | A    |
|  2  | B    |
|  3  | C    |
|  4  | D    |
|  5  | E    |
+-----+------+
```

表：`Vote`
```
+------+--------------+
| id   | candidateId  |
+------+--------------+
|  1   |     2        |
|  2   |     4        |
|  3   |     3        |
|  4   |     2        |
|  5   |     5        |
+------+--------------+
```

输出应该是：
```
+------+
| name |
+------+
| B    |
+------+
```

## SQL 代码实现

### 方法一：GROUP BY + ORDER BY（推荐）⭐

```sql
SELECT name
FROM Candidate
WHERE id = (
    SELECT candidateId
    FROM Vote
    GROUP BY candidateId
    ORDER BY COUNT(*) DESC
    LIMIT 1
);
```

### 方法二：窗口函数

```sql
SELECT name
FROM (
    SELECT 
        c.name,
        RANK() OVER (ORDER BY COUNT(*) DESC) AS rk
    FROM Vote v
    JOIN Candidate c ON v.candidateId = c.id
    GROUP BY c.id, c.name
) AS ranked
WHERE rk = 1;
```

### 方法三：JOIN + GROUP BY

```sql
SELECT c.name
FROM Vote v
JOIN Candidate c ON v.candidateId = c.id
GROUP BY c.id, c.name
ORDER BY COUNT(*) DESC
LIMIT 1;
```

## 关键点总结

1. **分组计数**：GROUP BY candidateId, COUNT(*)
2. **排序取最大**：ORDER BY COUNT(*) DESC, LIMIT 1
3. **JOIN 关联**：Vote 表和 Candidate 表关联
