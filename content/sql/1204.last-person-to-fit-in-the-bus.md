## 题目描述

表：`Queue`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| person_id   | int     |
| person_name | varchar |
| weight      | int     |
| turn        | int     |
+-------------+---------+
```

`person_id` 是这个表的主键。

该表展示了所有候车乘客的信息。

表中 `person_id` 和 `turn` 列将包含从 1 到 n 的所有数字，其中 n 是表中的行数。

`turn` 决定了候车乘客上巴士的顺序，其中 `turn=1` 表示第一个上巴士，`turn=n` 表示最后一个上巴士。

`weight` 表示候车乘客的体重，以千克为单位。

有一队乘客在等着上巴士。然而，巴士有 1000 千克的重量限制，所以其中一部分乘客可能无法上巴士。

编写一个 SQL 查询，找出最后一个能够上巴士且不超过重量限制的乘客的 `person_name`。题目测试用例确保第一个人不会超过重量限制。

注意：只有一个人可以在每个回合上巴士。

查询结果格式如下所示。

示例 1：

```
输入：
Queue 表
+-----------+-------------+--------+------+
| person_id | person_name | weight | turn |
+-----------+-------------+--------+------+
| 5         | Alice       | 250    | 1    |
| 4         | Bob         | 175    | 5    |
| 3         | Alex        | 350    | 2    |
| 6         | John Cena   | 400    | 3    |
| 1         | Winston     | 500    | 6    |
| 2         | Marie       | 200    | 4    |
+-----------+-------------+--------+------+

输出：
+-------------+
| person_name |
+-------------+
| John Cena   |
+-------------+

解释：
上巴士的顺序按 turn 列排序：
- 第 1 回合：Alice，累计重量 = 250
- 第 2 回合：Alex，累计重量 = 250 + 350 = 600
- 第 3 回合：John Cena，累计重量 = 600 + 400 = 1000
- 第 4 回合：Marie，累计重量 = 1000 + 200 = 1200（超过限制）

因此，John Cena 是最后一个能够上巴士的人。
```

## 解题思路

这道题的核心是计算累计重量，并找出累计重量不超过 1000 的最后一个人。

解题步骤：

1. 按照 `turn` 排序，确定上车顺序
2. 计算累计重量（Running Total）
3. 筛选出累计重量不超过 1000 的所有人
4. 从这些人中选择 `turn` 最大的（即最后一个）

关键技巧：

- 使用窗口函数 `SUM() OVER()` 计算累计和
- 使用子查询或 CTE（公共表表达式）将计算过程分步实现
- 注意排序顺序：必须按 `turn` 排序

## SQL 代码实现

### 方法一：窗口函数 + 子查询（推荐）

```sql
SELECT person_name
FROM (
    SELECT 
        person_name,
        turn,
        SUM(weight) OVER (ORDER BY turn) AS cumulative_weight
    FROM Queue
) AS cumulative_table
WHERE cumulative_weight <= 1000
ORDER BY turn DESC
LIMIT 1;
```

### 方法二：使用 CTE（公共表表达式）

```sql
WITH CumulativeWeight AS (
    SELECT 
        person_name,
        turn,
        SUM(weight) OVER (ORDER BY turn) AS cumulative_weight
    FROM Queue
)
SELECT person_name
FROM CumulativeWeight
WHERE cumulative_weight <= 1000
ORDER BY turn DESC
LIMIT 1;
```

### 方法三：自连接计算累计和

```sql
SELECT q1.person_name
FROM Queue q1
JOIN Queue q2 ON q1.turn >= q2.turn
GROUP BY q1.turn, q1.person_name
HAVING SUM(q2.weight) <= 1000
ORDER BY q1.turn DESC
LIMIT 1;
```

### 方法四：使用变量模拟累计和（MySQL 特定）

```sql
SELECT person_name
FROM (
    SELECT 
        person_name,
        @cumulative := @cumulative + weight AS cumulative_weight
    FROM Queue, (SELECT @cumulative := 0) AS init
    ORDER BY turn
) AS temp
WHERE cumulative_weight <= 1000
ORDER BY cumulative_weight DESC
LIMIT 1;
```

## 复杂度分析

### SQL 方案

- 时间复杂度：O(n log n)，主要消耗在排序和窗口函数计算上。
  - 方法一、二：窗口函数需要排序，复杂度 O(n log n)
  - 方法三：自连接，复杂度 O(n²)，效率较低
- 空间复杂度：O(n)，需要存储中间结果和累计重量列。

### Python Pandas 方案

- 时间复杂度：O(n log n)
  - 排序：O(n log n)
  - cumsum 计算：O(n)
  - 总体：O(n log n)
- 空间复杂度：O(n)，需要存储累计重量列。

## 图解示例

按 turn 排序后的累计过程：

```
turn=1: Alice   (250)   累计=250   ✓
turn=2: Alex    (350)   累计=600   ✓
turn=3: John    (400)   累计=1000  ✓ (最后一个)
turn=4: Marie   (200)   累计=1200  ✗ (超重)
turn=5: Bob     (175)   累计=1375  ✗
turn=6: Winston (500)   累计=1875  ✗
```

答案是 John Cena（turn=3）。

## 关键点总结

1. 核心是计算累计和（Running Total），SQL 中使用窗口函数，Pandas 中使用 cumsum()
2. 必须按 turn 排序后再计算累计和，顺序很重要
3. 窗口函数 `SUM() OVER (ORDER BY turn)` 会自动处理累计逻辑
4. 筛选条件是 `cumulative_weight <= 1000`，不是 `weight <= 1000`
5. 最后需要找到 turn 最大的那个人，可以用 ORDER BY turn DESC LIMIT 1

## 易错点

1. **忘记排序**：
   - 错误：直接对原表计算累计和
   - 正确：必须先按 turn 排序
   
2. **排序字段错误**：
   - 错误：按 person_id 或 weight 排序
   - 正确：必须按 turn 排序（上车顺序）

3. **累计和的窗口范围**：
   - 错误：`SUM(weight) OVER (PARTITION BY turn)` - 这会为每个 turn 单独求和
   - 正确：`SUM(weight) OVER (ORDER BY turn)` - 这是累计和

4. **筛选最后一个人的方法**：
   - 错误：使用 `MIN(turn)` 或随机选择
   - 正确：使用 `MAX(turn)` 或 `ORDER BY turn DESC LIMIT 1`

5. **边界情况**：
   - 题目保证第一个人不会超重，所以至少有一个人能上车
   - 如果所有人累计都不超过 1000，则最后一个人（turn 最大）就是答案

6. **自连接方法的条件**：
   - 错误：`q1.turn = q2.turn`（只会连接自己）
   - 正确：`q1.turn >= q2.turn`（连接所有在自己之前或同时的人）

## 学习建议

1. **掌握窗口函数**：
   - 窗口函数是 SQL 中的高级功能，非常强大
   - 常用窗口函数：SUM、AVG、COUNT、ROW_NUMBER、RANK、DENSE_RANK
   - 语法：`函数名() OVER (PARTITION BY ... ORDER BY ...)`
   - `PARTITION BY` 相当于分组，`ORDER BY` 决定窗口内的顺序

2. **理解累计和的应用场景**：
   - 累计销售额、累计用户数
   - 时间序列分析
   - 排名和百分位数计算

3. **Pandas 中的累计计算**：
   - `cumsum()`：累计和
   - `cumprod()`：累计乘积
   - `cummax()`：累计最大值
   - `cummin()`：累计最小值
   - `expanding()`：扩展窗口
   - `rolling()`：滚动窗口

4. **练习建议**：
   - 先理解什么是累计和，手动计算几个例子
   - 对比 SQL 窗口函数和 Pandas cumsum() 的异同
   - 练习更多窗口函数的题目
   - 尝试用不同方法解决同一个问题，比较性能差异

5. **调试技巧**：
   - 先输出中间结果（累计重量列），验证计算是否正确
   - 检查排序是否正确
   - 验证筛选条件是否符合题意
