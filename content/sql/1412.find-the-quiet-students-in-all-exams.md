## 题目描述

表 `Student`：

```
+---------------------+---------+
| Column Name         | Type    |
+---------------------+---------+
| student_id          | int     |
| student_name        | varchar |
+---------------------+---------+
student_id 是该表的主键。
```

表 `Exam`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| exam_id       | int     |
| student_id    | int     |
| score         | int     |
+---------------+---------+
(exam_id, student_id) 是该表的主键。
```

找出所有 **安静学生** 的 `student_id` 和 `student_name`。

**安静学生**：在所有他参加的考试中，从来没有得到过最高分或最低分。

**结果可以以任意顺序返回。**

**示例：**

```sql
Student 表：
+-------------+---------------+
| student_id  | student_name  |
+-------------+---------------+
| 1           | Daniel        |
| 2           | Jade          |
| 3           | Stella        |
| 4           | Jonathan      |
| 5           | Will          |
+-------------+---------------+

Exam 表：
+------------+-------------+-------+
| exam_id    | student_id  | score |
+------------+-------------+-------+
| 10         | 1           | 70    |
| 10         | 2           | 80    |
| 10         | 3           | 90    |
| 20         | 1           | 80    |
| 30         | 1           | 70    |
| 30         | 3           | 80    |
| 30         | 4           | 90    |
| 40         | 1           | 60    |
| 40         | 2           | 70    |
| 40         | 4           | 80    |
+------------+-------------+-------+

输出：
+-------------+---------------+
| student_id  | student_name  |
+-------------+---------------+
| 2           | Jade          |
+-------------+---------------+
```

**解释：**

- Daniel(1)：在考试40中得了60分（最低），不是安静学生
- Jade(2)：在考试10中得80（不是最高最低），考试40中得70（不是最高最低），是安静学生
- Stella(3)：在考试10中得90（最高），不是安静学生
- Jonathan(4)：在考试30中得90（最高），不是安静学生
- Will(5)：没有参加任何考试，不算安静学生（需要参加过考试）

## 解题思路

### 方法一：窗口函数（推荐）

用 `MAX(score) OVER (PARTITION BY exam_id)` 和 `MIN(score) OVER (PARTITION BY exam_id)` 分别求每场考试的最高分和最低分。

然后筛选出那些在任何一场考试中，分数既不是最高也不是最低的学生。

步骤：
1. 对 Exam 表用窗口函数计算每场考试的最高分和最低分
2. 找出"不安静"的学生（曾经得过最高分或最低分）
3. 从参加过考试的学生中，排除不安静的学生
4. JOIN Student 表获取姓名

### 方法二：子查询 + NOT IN

先找出所有曾经得过最高分或最低分的学生 ID，然后从 Exam 中排除这些学生，再 JOIN Student 表。

## SQL 解法

### 方法一：窗口函数（推荐）

```sql
SELECT DISTINCT s.student_id, s.student_name
FROM Student s
-- 只保留参加过考试的学生
INNER JOIN Exam e ON s.student_id = e.student_id
WHERE s.student_id NOT IN (
    -- 找出所有曾经得到最高分或最低分的学生
    SELECT student_id
    FROM (
        SELECT student_id,
               score,
               MAX(score) OVER (PARTITION BY exam_id) AS max_score,
               MIN(score) OVER (PARTITION BY exam_id) AS min_score
        FROM Exam
    ) ranked
    WHERE score = max_score OR score = min_score
)
ORDER BY s.student_id;
```

### 方法二：GROUP BY 子查询（兼容性更好）

```sql
SELECT DISTINCT s.student_id, s.student_name
FROM Student s
INNER JOIN Exam e ON s.student_id = e.student_id
WHERE s.student_id NOT IN (
    -- 得到最高分的学生
    SELECT e1.student_id
    FROM Exam e1
    INNER JOIN (
        SELECT exam_id, MAX(score) AS max_score
        FROM Exam
        GROUP BY exam_id
    ) m ON e1.exam_id = m.exam_id AND e1.score = m.max_score
    
    UNION
    
    -- 得到最低分的学生
    SELECT e2.student_id
    FROM Exam e2
    INNER JOIN (
        SELECT exam_id, MIN(score) AS min_score
        FROM Exam
        GROUP BY exam_id
    ) n ON e2.exam_id = n.exam_id AND e2.score = n.min_score
)
ORDER BY s.student_id;
```

### 方法三：使用 HAVING（等价思路）

```sql
-- 先找出"不安静"学生的 ID
WITH noisy AS (
    SELECT DISTINCT student_id
    FROM (
        SELECT *,
               MAX(score) OVER (PARTITION BY exam_id) AS max_score,
               MIN(score) OVER (PARTITION BY exam_id) AS min_score
        FROM Exam
    ) t
    WHERE score = max_score OR score = min_score
),
-- 参加过考试的学生
participated AS (
    SELECT DISTINCT student_id FROM Exam
)
SELECT s.student_id, s.student_name
FROM Student s
-- 只保留参加过考试且不喧闹的学生
WHERE s.student_id IN (SELECT student_id FROM participated)
  AND s.student_id NOT IN (SELECT student_id FROM noisy)
ORDER BY s.student_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 说明 |
|------|-----------|------|
| 窗口函数 | O(n log n) | n 为 Exam 行数，排序+扫描 |
| GROUP BY 子查询 | O(n log n) | 两次聚合查询 |

## 关键点总结

1. "安静学生"需要满足两个条件：参加过考试，且从未得最高分或最低分
2. 窗口函数 `MAX/MIN OVER (PARTITION BY exam_id)` 可以在不聚合的情况下给每行加上该组的最大/最小值
3. `DISTINCT` 关键字防止同一学生被计算多次
4. 注意 Will(5) 没参加考试，不算安静学生（需要 INNER JOIN）

## 易错点

1. 忘记处理"没参加考试的学生"：必须用 INNER JOIN 或 WHERE EXISTS 限制只看参加过考试的学生
2. 考试只有一人时，那个学生的分数既是最高也是最低，他不是安静学生
3. NOT IN 与 NULL 的问题：如果子查询结果包含 NULL，NOT IN 可能返回空结果，使用 NOT EXISTS 更安全

- 建议先用简单的 GROUP BY 方法理解思路，再学习窗口函数的写法
