## 题目描述

表：`Rides`

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| ride_id      | int  |
| driver_id    | int  |
| passenger_id | int  |
+--------------+------+
ride_id 是该表的主键。driver_id != passenger_id。
```

编写一个 SQL 查询，找出每位驾驶员**在其他行程中作为乘客的次数**。

对于每位出现过驾驶员的用户，查询其作为乘客的次数。

按 `driver_id` 升序排列结果。

**示例：**
```
Rides 表：
+---------+-----------+--------------+
| ride_id | driver_id | passenger_id |
+---------+-----------+--------------+
| 1       | 7         | 1            |
| 2       | 7         | 2            |
| 3       | 11        | 1            |
| 4       | 11        | 7            |
| 5       | 11        | 7            |
| 6       | 11        | 3            |
+---------+-----------+--------------+

输出：
+-----------+-----+
| driver_id | cnt |
+-----------+-----+
| 7         | 2   |
| 11        | 0   |
+-----------+-----+
```

## 解题思路

1. 找出所有担任过驾驶员的用户（`drivers`）。
2. 统计每位驾驶员作为乘客出现的次数（左连接，没有当过乘客的驾驶员计为 0）。

## 代码实现

### 方法一：LEFT JOIN + GROUP BY（推荐）

```sql
SELECT
    d.driver_id,
    COUNT(r.passenger_id) AS cnt
FROM
    (SELECT DISTINCT driver_id FROM Rides) d
    LEFT JOIN Rides r ON d.driver_id = r.passenger_id
GROUP BY d.driver_id
ORDER BY d.driver_id;
```

### 方法二：子查询计数

```sql
SELECT
    driver_id,
    (
        SELECT COUNT(*)
        FROM Rides r2
        WHERE r2.passenger_id = r1.driver_id
    ) AS cnt
FROM (SELECT DISTINCT driver_id FROM Rides) r1
ORDER BY driver_id;
```

### 方法三：使用 SUM CASE WHEN

```sql
SELECT
    a.driver_id,
    SUM(CASE WHEN b.passenger_id IS NOT NULL THEN 1 ELSE 0 END) AS cnt
FROM
    (SELECT DISTINCT driver_id FROM Rides) a
    LEFT JOIN Rides b ON a.driver_id = b.passenger_id
GROUP BY a.driver_id
ORDER BY a.driver_id;
```

## 复杂度分析

- 时间复杂度：O(n^2) 最差（子查询方法），LEFT JOIN 方法 O(n log n)（有索引时）。
- 空间复杂度：O(d)，d 为不同驾驶员数量。

## 关键点总结

1. 先获取所有不同驾驶员（`DISTINCT driver_id`）。
2. 左连接统计每人作为乘客的次数（没有时为 0）。
3. `COUNT(r.passenger_id)` 忽略 NULL，故 LEFT JOIN 后没匹配到的返回 0。

## 易错点

- 使用 `COUNT(*)` 时 NULL 也会被计数，应使用 `COUNT(r.passenger_id)` 忽略 NULL。
- 若驾驶员从未作为乘客，使用 INNER JOIN 会漏掉这些驾驶员，必须用 LEFT JOIN。
