## 题目描述

`Stocks` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| stock_name    | varchar |
| operation     | enum    |
| operation_day | int     |
| price         | int     |
+---------------+---------+
```

此表没有主键，可能包含重复行。
`operation` 列是类型为 `('Sell', 'Buy')` 的枚举。
此表的每一行代表了名为 `stock_name` 的股票在 `operation_day` 当天的操作价格。
保证每次 `Sell` 操作前，都有一次对应的 `Buy` 操作，且 `Buy` 和 `Sell` 次数相同。

编写 SQL 语句，查询每支股票的**资本损益**。

股票的**资本损益**是指一支股票迄今为止所有操作的累计净利润（**卖出价之和 - 买入价之和**）。

以**任意顺序**返回结果。

**示例：**

```
输入：
Stocks 表:
+---------------+-----------+---------------+--------+
| stock_name    | operation | operation_day | price  |
+---------------+-----------+---------------+--------+
| Leetcode      | Buy       | 1             | 1000   |
| Corona Masks  | Buy       | 2             | 10     |
| Leetcode      | Sell      | 5             | 9000   |
| Handbags      | Buy       | 17            | 30000  |
| Corona Masks  | Sell      | 3             | 1010   |
| Corona Masks  | Buy       | 4             | 1000   |
| Corona Masks  | Sell      | 5             | 500    |
| Corona Masks  | Buy       | 6             | 1000   |
| Handbags      | Sell      | 29            | 7000   |
| Corona Masks  | Sell      | 10            | 10000  |
+---------------+-----------+---------------+--------+

输出：
+---------------+-------------------+
| stock_name    | capital_gain_loss |
+---------------+-------------------+
| Corona Masks  | 9500              |
| Handbags      | -23000            |
| Leetcode      | 8000              |
+---------------+-------------------+
```

## 解题思路

**核心思想：** 对每支股票，分别求所有卖出价之和与所有买入价之和，相减即得资本损益。

**SQL 技巧：CASE WHEN + GROUP BY + SUM**

- `SUM(CASE WHEN operation = 'Sell' THEN price ELSE 0 END)` 求卖出总价
- `SUM(CASE WHEN operation = 'Buy' THEN price ELSE 0 END)` 求买入总价
- 或者更简洁：`SUM(IF(operation = 'Sell', price, -price))` 直接求净值

## 代码实现

### 方法一：条件聚合（推荐）

```sql
SELECT
    stock_name,
    SUM(
        CASE
            WHEN operation = 'Sell' THEN price
            ELSE -price
        END
    ) AS capital_gain_loss
FROM Stocks
GROUP BY stock_name;
```

**解释：**

- `CASE WHEN operation = 'Sell' THEN price ELSE -price END`：卖出为正，买入为负
- `SUM(...)` 对每支股票求和，即卖出总价 - 买入总价
- `GROUP BY stock_name`：按股票名分组

### 方法二：两次聚合再相减

```sql
SELECT
    stock_name,
    SUM(CASE WHEN operation = 'Sell' THEN price ELSE 0 END) -
    SUM(CASE WHEN operation = 'Buy'  THEN price ELSE 0 END) AS capital_gain_loss
FROM Stocks
GROUP BY stock_name;
```

### 方法三：使用 IF 函数（MySQL 风格）

```sql
SELECT
    stock_name,
    SUM(IF(operation = 'Sell', price, -price)) AS capital_gain_loss
FROM Stocks
GROUP BY stock_name;
```

## 复杂度分析

- **时间复杂度 O(n)**：扫描一遍表，按 stock_name 分组聚合。
- **空间复杂度 O(k)**：k 是不同股票的数量。

## 图解示例

以 `Corona Masks` 为例：

```
操作   价格    记号后价格
Buy    10      -10
Sell   1010    +1010
Buy    1000    -1000
Sell   500     +500
Buy    1000    -1000
Sell   10000   +10000

资本损益 = -10 + 1010 - 1000 + 500 - 1000 + 10000 = 9500
```

## 关键点总结

1. `CASE WHEN ... ELSE ...` 或 `IF(...)` 可以根据条件给价格加正负号
2. `SUM()` 求和后就是净损益，一行代码搞定
3. `GROUP BY stock_name` 是必须的，否则无法按股票分组

## 易错点

- `ELSE 0` 和 `ELSE -price` 的区别：方法一用后者直接算净值，方法二用前者分别求两个总和
- 不要忘记 `GROUP BY`，否则返回的是全表汇总而非每支股票的损益
- 列名要用 `AS capital_gain_loss` 别名，符合题目输出要求
