## 题目描述

与 3368 相同，但数据可能更复杂。将每个单词的首字母大写，其余小写。

本题是 3368 的进阶版，处理更复杂的文本（包括标点、特殊字符等）。

## 解题思路

与 3368 相同，实现单词首字母大写。

在 MySQL 中，可以使用递归 CTE 或存储过程处理多单词文本。

## 代码实现

```sql
-- 方法：利用 MySQL 的字符串函数
-- 对于单个单词：CONCAT(UPPER(LEFT(word, 1)), LOWER(SUBSTRING(word, 2)))
-- 对于多个单词：需要递归或使用自定义函数

-- MySQL 8.0 使用递归 CTE
WITH RECURSIVE split AS (
    -- 初始：整个文本
    SELECT
        content_id,
        CONCAT(content_text, ' ') AS remaining,
        '' AS result
    FROM user_content
    
    UNION ALL
    
    SELECT
        content_id,
        SUBSTRING(remaining, LOCATE(' ', remaining) + 1),
        CONCAT(
            result,
            CONCAT(
                UPPER(LEFT(SUBSTRING_INDEX(remaining, ' ', 1), 1)),
                LOWER(SUBSTRING(SUBSTRING_INDEX(remaining, ' ', 1), 2))
            ),
            CASE WHEN LOCATE(' ', remaining) > 0 THEN ' ' ELSE '' END
        )
    FROM split
    WHERE LOCATE(' ', remaining) > 0
)
SELECT content_id, RTRIM(result) AS converted_text
FROM split
WHERE remaining = ''
ORDER BY content_id;
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 行，m 为最长文本长度
- 空间复杂度：O(n * m)

## 关键点总结

1. 使用递归 CTE 处理可变单词数的文本。
2. 每个单词：`UPPER(LEFT(word, 1)) + LOWER(SUBSTRING(word, 2))`。
3. MySQL 递归 CTE 的默认递归深度限制（1000），对极长文本可能需要调整。

## 易错点

1. 空单词（连续空格）需要特殊处理。
2. 递归 CTE 终止条件：`remaining` 为空时停止。
3. 最终结果需要 `RTRIM` 去掉末尾空格。
