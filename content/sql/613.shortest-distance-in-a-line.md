## 题目描述

表：`Point`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
+-------------+------+
```

在 SQL 中，x 是该表的主键列。
该表的每一行包含数轴上一个点的位置。

找出数轴上两点之间的最短距离。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Point 表：
+----+
| x  |
+----+
| -1 |
| 0  |
| 2  |
+----+

输出：
+----------+
| shortest |
+----------+
| 1        |
+----------+

解释：点 -1 和 0 之间的距离为 |(-1) - 0| = 1。
```

## 解题思路

一维数轴上的最短距离 = 排序后相邻两点的最小距离差。

## SQL 代码实现

### 方法一：自连接（通用）⭐

```sql
SELECT MIN(ABS(p1.x - p2.x)) AS shortest
FROM Point p1
JOIN Point p2 ON p1.x != p2.x;
```

### 方法二：窗口函数（最优）⭐⭐

```sql
SELECT MIN(diff) AS shortest
FROM (
    SELECT x - LAG(x) OVER (ORDER BY x) AS diff
    FROM Point
) t
WHERE diff IS NOT NULL;
```

### 方法三：简化版

```sql
SELECT MIN(p1.x - p2.x) AS shortest
FROM Point p1, Point p2
WHERE p1.x > p2.x;
```

## 复杂度分析

### 方法一
- **时间复杂度**：O(n²)

### 方法二（窗口函数）
- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. **一维距离**：相邻点距离最小
2. **窗口函数**：`LAG()` 获取前一个值
3. **过滤 NULL**：第一个点没有前驱
