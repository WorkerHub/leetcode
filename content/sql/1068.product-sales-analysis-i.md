## 题目描述

表：`Sales`

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
(sale_id, year) 是该表的主键。
product_id 是 Product 表的外键。
该表的每一行表示：在某一年，售出了一些数量的某产品。
```

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
+--------------+---------+
product_id 是该表的主键。
该表的每一行表示每个产品的产品名称。
```

编写 SQL 查询，查询每一条销售记录的产品名称（`product_name`）、年份（`year`）和价格（`price`）。

返回结果表**无顺序要求**。

**示例：**

输入：
```
Sales 表：
+---------+------------+------+----------+-------+
| sale_id | product_id | year | quantity | price |
+---------+------------+------+----------+-------+
| 1       | 100        | 2008 | 10       | 5000  |
| 2       | 100        | 2009 | 12       | 5000  |
| 7       | 200        | 2011 | 15       | 9000  |
+---------+------------+------+----------+-------+

Product 表：
+------------+--------------+
| product_id | product_name |
+------------+--------------+
| 100        | Nokia        |
| 200        | Apple        |
| 300        | Samsung      |
+------------+--------------+
```

输出：
```
+--------------+-------+-------+
| product_name | year  | price |
+--------------+-------+-------+
| Nokia        | 2008  | 5000  |
| Nokia        | 2009  | 5000  |
| Apple        | 2011  | 9000  |
+--------------+-------+-------+
```

## 解题思路

这是一道基础的 **JOIN** 操作题目。

**分析：**
1. 需要从 `Sales` 表获取 `year` 和 `price`
2. 需要从 `Product` 表获取 `product_name`
3. 通过 `product_id` 关联两张表

**SQL 知识点：**
- INNER JOIN / LEFT JOIN
- 表关联的基本语法
- SELECT 选择字段

## SQL 代码实现

### 方法一：INNER JOIN（推荐）

```sql
SELECT 
    p.product_name,
    s.year,
    s.price
FROM 
    Sales s
INNER JOIN 
    Product p
ON 
    s.product_id = p.product_id;
```

### 方法二：LEFT JOIN

```sql
SELECT 
    p.product_name,
    s.year,
    s.price
FROM 
    Sales s
LEFT JOIN 
    Product p
ON 
    s.product_id = p.product_id;
```

### 方法三：使用 WHERE 子句（旧式写法）

```sql
SELECT 
    p.product_name,
    s.year,
    s.price
FROM 
    Sales s, Product p
WHERE 
    s.product_id = p.product_id;
```

### 方法四：USING 关键字

```sql
SELECT 
    p.product_name,
    s.year,
    s.price
FROM 
    Sales s
INNER JOIN 
    Product p
USING 
    (product_id);
```

## 解题步骤

1. **确定主表**：`Sales` 表是主表，因为要保留所有销售记录
2. **选择 JOIN 类型**：
   - 如果每个销售记录都有对应的产品，用 `INNER JOIN`
   - 如果可能有销售记录没有对应产品，用 `LEFT JOIN`
3. **关联键**：`product_id` 是两表的关联键
4. **选择字段**：从结果中选择需要的三个字段

## 关键点总结

1. **JOIN 类型**：
   - `INNER JOIN`：只返回两表都有的记录
   - `LEFT JOIN`：返回左表所有记录，右表匹配不上则为 NULL
2. **表别名**：使用别名 `s` 和 `p` 简化代码
3. **字段选择**：明确指定需要的字段，避免返回多余数据
4. **USING 语法**：当关联字段同名时可以简化代码

## 易错点

1. **字段来源**：注意 `product_name` 来自 `Product` 表，不是 `Sales` 表
2. **JOIN 类型**：根据题意选择正确的 JOIN 类型
3. **字段顺序**：虽然题目说无顺序要求，但最好按题目示例的顺序返回
4. **NULL 值**：如果用 `LEFT JOIN` 且有未匹配的记录，注意 NULL 的处理

## 相关知识点

### SQL JOIN 类型对比

| JOIN 类型 | 说明 | 使用场景 |
|-----------|------|----------|
| INNER JOIN | 返回两表都有的记录 | 必须匹配才有意义 |
| LEFT JOIN | 返回左表所有记录 | 保留主表所有数据 |
| RIGHT JOIN | 返回右表所有记录 | 较少使用 |
| FULL OUTER JOIN | 返回两表所有记录 | 需要完整数据 |
