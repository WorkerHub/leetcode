## 题目描述

表：`user_permissions`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| permissions | int     |
+-------------+---------+
```

`user_id` 是该表的主键。`permissions` 是一个表示用户权限的整数（位掩码）。

编写一个 SQL 查询，计算以下内容：
- `common_perms`：所有用户权限的按位 AND 结果
- `any_perm`：所有用户权限的按位 OR 结果

以任意顺序返回结果。

**示例：**

输入：
```
+------+-------------+
| user_id | permissions |
+------+-------------+
| 1    | 5           |
| 2    | 12          |
| 3    | 7           |
| 4    | 2           |
+------+-------------+
```

输出：
```
+--------------+----------+
| common_perms | any_perm |
+--------------+----------+
| 0            | 15       |
+--------------+----------+
```

## 解题思路

直接使用 SQL 的聚合函数：
- `BIT_AND()` 对所有行做按位与
- `BIT_OR()` 对所有行做按位或

## 代码实现

```sql
SELECT
    BIT_AND(permissions) AS common_perms,
    BIT_OR(permissions) AS any_perm
FROM user_permissions;
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有行一次
- 空间复杂度：O(1)

## 关键点总结

1. `BIT_AND()` 是 MySQL 的聚合函数，对所有非 NULL 值做按位与
2. `BIT_OR()` 是 MySQL 的聚合函数，对所有非 NULL 值做按位或
3. 如果表为空，`BIT_AND()` 返回最大无符号整数，`BIT_OR()` 返回 0

## 易错点

1. 注意列名别名要与题目要求一致
2. 当表为空时返回值需要注意
