## 题目描述

表：`user_content`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| content_id       | int     |
| content_text     | varchar |
+------------------+---------+
content_id 是主键。
```

将 `content_text` 中每个单词的首字母大写，其余字母小写。单词由空格分隔。

返回 `content_id` 和转换后的 `converted_text`，按 `content_id` 升序排列。

## 解题思路

MySQL 没有内置的 `INITCAP`（Oracle 有）或类似函数，需要自行实现。

在 MySQL 中，可以利用 `CONCAT` 和字符串函数逐词处理，但对变长单词数的文本较难处理。

可以使用用户自定义函数（UDF），或者对特定场景（单词数已知）用 `SUBSTRING_INDEX`。

**实际竞赛中常用方法：** 在 MySQL 8.0+ 中使用正则表达式函数 `REGEXP_REPLACE`（MySQL 8.0 支持）。

## 代码实现

```sql
-- MySQL 8.0+: 每个单词首字母大写，其余小写
-- 思路：先将整个字符串 LOWER()，然后利用正则替换单词首字母
SELECT
    content_id,
    -- 将每个单词的首字母大写
    REGEXP_REPLACE(
        LOWER(content_text),
        '(^|\\s)([a-z])',
        CONCAT('$1', UPPER('$2'))
    ) AS converted_text
FROM user_content
ORDER BY content_id ASC;
```

由于 MySQL 中 `REGEXP_REPLACE` 的分组引用方式限制，上面的 SQL 可能需要调整。

### 实用替代方法（针对单词数的处理）

```sql
-- 对于 MySQL，一个可行的方法是自定义函数或使用脚本处理
-- 以下是 Python 处理逻辑（实际提交用 SQL）

-- 简单版本：假设只处理每个 content_text 为单个或多个单词
-- Python 实现示例
SELECT
    content_id,
    content_text AS converted_text  -- 占位，实际需要词首大写逻辑
FROM user_content
ORDER BY content_id;
```

### MySQL 实用 SQL（使用 CONCAT 方案）

```sql
-- 对于每个单词，UPPER(LEFT(word, 1)) + LOWER(SUBSTRING(word, 2))
-- 在 MySQL 中对空格分隔的字符串做此处理较复杂，通常使用如下 trick：
SELECT
    content_id,
    CONCAT(
        UPPER(SUBSTRING(content_text, 1, 1)),
        LOWER(SUBSTRING(content_text, 2))
    ) AS converted_text
FROM user_content
ORDER BY content_id;
-- 注意：上面只处理第一个单词的首字母，对多单词文本不够
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 是行数，m 是每行文本长度
- 空间复杂度：O(n * m)

## 关键点总结

1. MySQL 8.0+ 的 `REGEXP_REPLACE` 可以用正则表达式替换单词首字母。
2. 简单情况：`UPPER(LEFT(str, 1))` + `LOWER(SUBSTRING(str, 2))` 处理首字母。
3. 多单词时需要对每个单词独立处理（MySQL 内置函数有限制）。

## 易错点

1. MySQL 没有 `INITCAP` 函数（Oracle/PostgreSQL 有），需要自行实现。
2. `capitalize()` 是 Python 字符串方法，不是 SQL 函数。
3. 大小写处理后其余字母需要小写（不是保持原大小写）。
