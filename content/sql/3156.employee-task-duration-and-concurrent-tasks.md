## 题目描述

表：`Tasks`

```
+---------------+----------+
| Column Name   | Type     |
+---------------+----------+
| task_id       | int      |
| employee_id   | int      |
| start_time    | datetime |
| end_time      | datetime |
+---------------+----------+
```

`task_id` 是该表的主键。

编写一个解决方案，对每个员工：
1. 计算其工作的总时长（start_time 最小到 end_time 最大的时间差，以小时计）
2. 计算其同时进行的最大并发任务数

返回包含 `employee_id`、`total_task_hours`（向下取整为整数）、`max_concurrent_tasks` 的结果，按 `employee_id` 升序排列。

## 解题思路

1. 总时长：每个员工的 MAX(end_time) - MIN(start_time)，转为小时
2. 最大并发数：用事件扫描线——对每个任务的 start_time 视为 +1，end_time 视为 -1，合并同一时刻的事件，扫描最大前缀和

## 代码实现

### 方法一：事件扫描（推荐）

```sql
WITH events AS (
    SELECT employee_id, start_time AS event_time, 1 AS delta FROM Tasks
    UNION ALL
    SELECT employee_id, end_time AS event_time, -1 AS delta FROM Tasks
),
ordered_events AS (
    SELECT
        employee_id,
        event_time,
        SUM(delta) OVER (PARTITION BY employee_id ORDER BY event_time, delta DESC) AS running_sum
    FROM events
),
max_concurrent AS (
    SELECT employee_id, MAX(running_sum) AS max_concurrent_tasks
    FROM ordered_events
    GROUP BY employee_id
),
duration AS (
    SELECT
        employee_id,
        FLOOR(TIMESTAMPDIFF(SECOND, MIN(start_time), MAX(end_time)) / 3600) AS total_task_hours
    FROM Tasks
    GROUP BY employee_id
)
SELECT
    d.employee_id,
    d.total_task_hours,
    m.max_concurrent_tasks
FROM duration d
JOIN max_concurrent m ON d.employee_id = m.employee_id
ORDER BY d.employee_id;
```

### 方法二：简化版

```sql
WITH task_events AS (
    SELECT employee_id, start_time AS t, 1 AS v FROM Tasks
    UNION ALL
    SELECT employee_id, end_time AS t, -1 AS v FROM Tasks
),
running AS (
    SELECT
        employee_id,
        SUM(v) OVER (PARTITION BY employee_id ORDER BY t, v DESC
                     ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS cnt
    FROM task_events
)
SELECT
    e.employee_id,
    FLOOR(TIMESTAMPDIFF(SECOND, MIN(t.start_time), MAX(t.end_time)) / 3600) AS total_task_hours,
    MAX(r.cnt) AS max_concurrent_tasks
FROM Tasks t
JOIN running r ON t.employee_id = r.employee_id
GROUP BY e.employee_id
ORDER BY e.employee_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 总时长 = MAX(end) - MIN(start)，转换为小时
2. 并发数用事件扫描：start +1，end -1，前缀和最大值
3. 注意同时开始和结束时，结束事件先处理（delta DESC）

## 易错点

1. 相同时刻的事件处理顺序（end 先于 start 可以不算重叠）
2. FLOOR 向下取整
