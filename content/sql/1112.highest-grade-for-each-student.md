## 题目描述

表：`Enrollments`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| course_id     | int     |
| grade         | int     |
+---------------+---------+
(student_id, course_id) 是该表的主键
```

编写一个 SQL 查询，查询每位学生获得的最高成绩和相应的课程。如果最高成绩不唯一，则返回其中课程 ID 最小的那门课程。

查询结果按 `student_id` 升序排列。

查询结果格式如下所示。

**示例：**

输入：
```
Enrollments 表：
+------------+-------------------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 2          | 2         | 95    |
| 2          | 3         | 95    |
| 1          | 1         | 90    |
| 1          | 2         | 99    |
| 3          | 1         | 80    |
| 3          | 2         | 75    |
| 3          | 3         | 82    |
+------------+-----------+-------+
```

输出：
```
+------------+-------------------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 1          | 2         | 99    |
| 2          | 2         | 95    |
| 3          | 3         | 82    |
+------------+-----------+-------+
```

解释：
- 学生 1 的最高成绩是 99（课程 2）
- 学生 2 的最高成绩是 95，在课程 2 和 3 中都是 95，选择课程 ID 较小的课程 2
- 学生 3 的最高成绩是 82（课程 3）

## 解题思路

这道题需要解决两个问题：
1. 找出每个学生的最高成绩
2. 如果最高成绩对应多门课程，选择课程 ID 最小的

**解题步骤：**

1. **找最高成绩**：使用 `MAX(grade)` 按学生分组
2. **处理并列情况**：在最高成绩的基础上，选择最小的课程 ID
3. **排序输出**：按学生 ID 升序排列

**常用方法：**
- 窗口函数（推荐）
- 子查询
- 自连接

## SQL 代码实现

### 方法一：窗口函数 RANK（推荐）

```sql
-- 使用窗口函数找出每个学生的最高成绩和最小课程ID
SELECT 
    student_id,
    course_id,
    grade
FROM (
    SELECT 
        student_id,
        course_id,
        grade,
        RANK() OVER (
            PARTITION BY student_id 
            ORDER BY grade DESC, course_id ASC
        ) AS rk
    FROM 
        Enrollments
) AS ranked
WHERE 
    rk = 1
ORDER BY 
    student_id;
```

### 方法二：窗口函数 ROW_NUMBER

```sql
-- 使用 ROW_NUMBER 确保每个学生只有一条记录
SELECT 
    student_id,
    course_id,
    grade
FROM (
    SELECT 
        student_id,
        course_id,
        grade,
        ROW_NUMBER() OVER (
            PARTITION BY student_id 
            ORDER BY grade DESC, course_id ASC
        ) AS rn
    FROM 
        Enrollments
) AS ranked
WHERE 
    rn = 1
ORDER BY 
    student_id;
```

### 方法三：子查询 + JOIN

```sql
-- 先找出每个学生的最高成绩
WITH max_grades AS (
    SELECT 
        student_id,
        MAX(grade) AS max_grade
    FROM 
        Enrollments
    GROUP BY 
        student_id
),
-- 然后找出最高成绩对应的最小课程ID
min_courses AS (
    SELECT 
        e.student_id,
        MIN(e.course_id) AS min_course_id,
        e.grade
    FROM 
        Enrollments e
    INNER JOIN 
        max_grades mg
    ON 
        e.student_id = mg.student_id 
        AND e.grade = mg.max_grade
    GROUP BY 
        e.student_id, e.grade
)
SELECT 
    student_id,
    min_course_id AS course_id,
    grade
FROM 
    min_courses
ORDER BY 
    student_id;
```

### 方法四：自连接（标准 SQL）

```sql
-- 找出每个学生的最高成绩和最小课程ID
SELECT 
    e1.student_id,
    MIN(e1.course_id) AS course_id,
    e1.grade
FROM 
    Enrollments e1
WHERE 
    e1.grade = (
        SELECT MAX(e2.grade)
        FROM Enrollments e2
        WHERE e2.student_id = e1.student_id
    )
GROUP BY 
    e1.student_id, e1.grade
ORDER BY 
    e1.student_id;
```

### 方法五：NOT EXISTS（性能较差）

```sql
-- 找出不存在更高成绩或相同成绩但课程ID更小的记录
SELECT 
    e1.student_id,
    e1.course_id,
    e1.grade
FROM 
    Enrollments e1
WHERE NOT EXISTS (
    SELECT 1
    FROM Enrollments e2
    WHERE e2.student_id = e1.student_id
      AND (e2.grade > e1.grade 
           OR (e2.grade = e1.grade AND e2.course_id < e1.course_id))
)
ORDER BY 
    e1.student_id;
```

## 复杂度分析

**方法一、二（窗口函数）：**
- 时间复杂度：O(n log n)，排序的开销
- 空间复杂度：O(n)，窗口函数需要存储中间结果
- 推荐：性能好，代码简洁

**方法三（子查询 + JOIN）：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)
- 可读性好，逻辑清晰

**方法四（自连接）：**
- 时间复杂度：O(n²)，对每个学生都要扫描全表
- 空间复杂度：O(1)
- 兼容性好，但性能较差

## 关键点总结

1. **两层排序**：先按成绩降序，再按课程 ID 升序
2. **窗口函数的优势**：
   - `RANK()` 允许并列排名
   - `ROW_NUMBER()` 严格排序，每行唯一编号
   - 对本题两者效果相同
3. **分组聚合的陷阱**：直接使用 `MAX(grade)` 和 `MIN(course_id)` 可能得到错误结果
4. **PARTITION BY 的作用**：按学生分组，在每组内独立排序
5. **WHERE rk = 1**：只保留每个学生的第一条记录（最高成绩且课程 ID 最小）

## 易错点

1. **错误的聚合方式**：
   ```sql
   -- 错误示例：会得到错误的 course_id
   SELECT 
       student_id,
       MAX(grade) AS grade,
       MIN(course_id) AS course_id  -- 错误！
   FROM Enrollments
   GROUP BY student_id;
   ```
   这样会把最高成绩和最小课程 ID 分别取出，但它们可能不对应

2. **忘记处理并列**：只找最高成绩，没有考虑多门课程同分的情况

3. **排序顺序错误**：
   - 应该是 `ORDER BY grade DESC, course_id ASC`
   - 不能是 `ORDER BY grade DESC, course_id DESC`

4. **RANK vs DENSE_RANK vs ROW_NUMBER**：
   - 本题使用 RANK 或 ROW_NUMBER 都可以
   - DENSE_RANK 不适合（会保留所有并列第一的记录）

5. **忘记最终排序**：题目要求按 student_id 排序

## 学习建议

1. **掌握窗口函数**：
   - `ROW_NUMBER()`：为每行分配唯一编号
   - `RANK()`：允许并列，跳过编号
   - `DENSE_RANK()`：允许并列，不跳过编号
   - `PARTITION BY`：分组
   - `ORDER BY`：组内排序

2. **理解聚合函数的局限**：
   - `MAX()`、`MIN()` 只能在同一列上聚合
   - 不能跨列关联聚合结果
   - 需要窗口函数或子查询解决

3. **多种解法对比**：
   - 窗口函数：简洁高效（MySQL 8.0+）
   - 子查询：兼容性好，逻辑清晰
   - 自连接：传统方法，性能较差

4. **性能优化**：
   - 为 `(student_id, grade)` 创建索引
   - 窗口函数通常比自连接快
   - 使用 EXPLAIN 分析查询计划

5. **调试技巧**：
   - 先运行内层子查询，查看中间结果
   - 检查窗口函数的排名是否正确
   - 验证边界情况（只有一门课、所有课程同分等）

6. **扩展练习**：
   - 如果要求返回所有最高成绩的课程怎么办？
   - 如果要求返回每个学生的前 N 名课程？
   - 如何处理成绩为 NULL 的情况？
