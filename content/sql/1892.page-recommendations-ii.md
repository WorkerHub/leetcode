## 题目描述

表 `Friendship`：

| Column Name | Type |
|-------------|------|
| user1_id    | int  |
| user2_id    | int  |

`(user1_id, user2_id)` 是主键，`user1_id < user2_id`，表示两人是朋友。

表 `Likes`：

| Column Name | Type |
|-------------|------|
| user_id     | int  |
| page_id     | int  |

`(user_id, page_id)` 是主键。

为每个用户推荐页面：某页面被用户的朋友喜欢，但该用户自己没有喜欢该页面。

结果表：`user_id`、`page_id`（推荐页面）、`friends_likes`（有多少个朋友喜欢该页面）。

按任意顺序返回。

**示例：**
```
输入：
Friendship: (1,2),(1,3),(1,4),(2,3),(2,4)
Likes: user 1→page 88; user 2→pages 23,24,56; user 3→pages 23,56; user 4→pages 56,88

输出：
user_id=1, page_id=23, friends_likes=2
user_id=1, page_id=24, friends_likes=1
user_id=1, page_id=56, friends_likes=3
user_id=2, page_id=88, friends_likes=1
user_id=3, page_id=24, friends_likes=1
user_id=3, page_id=88, friends_likes=1
user_id=4, page_id=23, friends_likes=1
user_id=4, page_id=24, friends_likes=1
```

## 解题思路

**步骤：**
1. 将 Friendship 表展开为双向关系（user1->user2 和 user2->user1）
2. 关联朋友喜欢的页面
3. 排除用户自己已经喜欢的页面
4. 统计每个 (user_id, page_id) 组合的朋友数量

## 代码实现

### 方法一：UNION ALL + 子查询（推荐）

```sql
-- 第一步：将好友关系展开为双向
WITH Friends AS (
    SELECT user1_id AS user_id, user2_id AS friend_id FROM Friendship
    UNION ALL
    SELECT user2_id AS user_id, user1_id AS friend_id FROM Friendship
),
-- 第二步：获取用户的朋友喜欢的页面
FriendLikes AS (
    SELECT f.user_id, l.page_id
    FROM Friends f
    JOIN Likes l ON f.friend_id = l.user_id
)
-- 第三步：排除用户已喜欢的页面，统计朋友数
SELECT
    fl.user_id,
    fl.page_id,
    COUNT(*) AS friends_likes
FROM FriendLikes fl
WHERE NOT EXISTS (
    SELECT 1 FROM Likes l
    WHERE l.user_id = fl.user_id AND l.page_id = fl.page_id
)
GROUP BY fl.user_id, fl.page_id;
```

### 方法二：LEFT JOIN + IS NULL 排除

```sql
WITH Friends AS (
    SELECT user1_id AS user_id, user2_id AS friend_id FROM Friendship
    UNION ALL
    SELECT user2_id AS user_id, user1_id AS friend_id FROM Friendship
)
SELECT
    f.user_id,
    l.page_id,
    COUNT(*) AS friends_likes
FROM Friends f
JOIN Likes l ON f.friend_id = l.user_id
LEFT JOIN Likes self ON self.user_id = f.user_id AND self.page_id = l.page_id
WHERE self.user_id IS NULL  -- 用户自己没有喜欢该页面
GROUP BY f.user_id, l.page_id;
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为好友关系数，m 为 Likes 表行数
- **空间复杂度**：O(n + m)

## 关键点总结

1. Friendship 是单向存储（user1_id < user2_id），需要 UNION ALL 展开为双向
2. 用 LEFT JOIN + IS NULL 或 NOT EXISTS 排除用户已喜欢的页面
3. GROUP BY (user_id, page_id) 统计朋友喜欢数

## 易错点

- Friendship 表只存了一半关系，必须用 UNION ALL 展开双向
- 注意排除用户自己已喜欢的页面再统计
