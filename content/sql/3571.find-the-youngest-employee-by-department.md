## 题目描述

表 `Employees`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| age         | int     |
+-------------+---------+
employee_id 是主键。
```

找出每个部门中年龄最小的员工。若同一部门有多个年龄最小的员工，全部返回。结果按部门名称升序排列，同部门内按员工姓名升序排列。

**示例：**

```
输入：
Employees：
employee_id | name   | department | age
1           | Alice  | HR         | 25
2           | Bob    | HR         | 25
3           | Charlie| IT         | 30
4           | David  | IT         | 28

输出：
department | name    | age
HR         | Alice   | 25
HR         | Bob     | 25
IT         | David   | 28
```

## 解题思路

1. 找每个部门的最小年龄
2. 找所有年龄等于部门最小年龄的员工
3. 按部门和姓名排序

## 代码实现

### 方法一：子查询（推荐）

```sql
SELECT 
    e.department,
    e.name,
    e.age
FROM Employees e
WHERE e.age = (
    SELECT MIN(age) 
    FROM Employees 
    WHERE department = e.department
)
ORDER BY e.department ASC, e.name ASC;
```

### 方法二：窗口函数

```sql
WITH RankedEmployees AS (
    SELECT 
        department,
        name,
        age,
        RANK() OVER (PARTITION BY department ORDER BY age ASC) AS rk
    FROM Employees
)
SELECT department, name, age
FROM RankedEmployees
WHERE rk = 1
ORDER BY department ASC, name ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，窗口函数中间结果

## 关键点总结

1. 按部门分组找最小年龄（`MIN(age) PARTITION BY department`）
2. 窗口函数 `RANK()` 或相关子查询找并列最小值
3. `RANK()` 而非 `ROW_NUMBER()`，处理并列情况

## 易错点

1. 并列最小年龄要全部返回（用 `RANK` 不用 `ROW_NUMBER`）
2. ORDER BY 两个列：先部门升序，再姓名升序
3. 若部门为空（NULL），需要特殊处理
