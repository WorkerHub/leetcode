## 题目描述

表 `Users`：`account`, `name`

表 `Transactions`：`trans_id`, `account`, `amount`, `transacted_on`

查询余额（所有交易金额之和）超过 10000 的用户的 `name` 和 `balance`。

## 解题思路

### GROUP BY + HAVING

对每个账户求交易金额总和，筛选大于 10000 的，关联用户表获取用户名。

## 代码实现

### 方法一：GROUP BY + HAVING（推荐）

```sql
-- 按账户汇总余额，筛选超过 10000 的用户
SELECT
    u.name,
    SUM(t.amount) AS balance
FROM Users u
JOIN Transactions t ON u.account = t.account
GROUP BY u.account, u.name
HAVING SUM(t.amount) > 10000;
```

### 方法二：先汇总再 JOIN

```sql
-- 先计算每个账户余额，再关联用户表
WITH balances AS (
    SELECT account, SUM(amount) AS balance
    FROM Transactions
    GROUP BY account
    HAVING SUM(amount) > 10000
)
SELECT u.name, b.balance
FROM balances b
JOIN Users u ON b.account = u.account;
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(K)，K 为不同账户数

## 关键点总结

1. `SUM(amount)` 计算所有交易的总和（包括正负）
2. `HAVING SUM(amount) > 10000` 过滤余额
3. JOIN Users 获取用户名

## 易错点

- 余额是所有交易 amount 的总和（可能有存款和取款）
- `HAVING` 条件在 `GROUP BY` 之后执行
