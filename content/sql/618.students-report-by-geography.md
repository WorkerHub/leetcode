## 题目描述

Table: Student

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| name        | varchar |
| continent   | varchar |
+-------------+---------+
此表没有主键，可能包含重复行
每一行表示学生的姓名和他们来自的大陆
```

学生信息表存储了来自三个大陆（America、Asia、Europe）的学生姓名。

编写一个 SQL 查询，实现对大陆的数据透视。透视表的每一行应包含来自 America、Asia 和 Europe 的一个学生。

学生在每列中的显示顺序无关紧要，但每列中的学生名字应按字母顺序排列。

**示例：**
```
Student table:
+--------+-----------+
| name   | continent |
+--------+-----------+
| Jane   | America   |
| Pascal | Europe    |
| Xi     | Asia      |
| Jack   | America   |
+--------+-----------+

Result table:
+---------+------+--------+
| America | Asia | Europe |
+---------+------+--------+
| Jack    | Xi   | Pascal |
| Jane    | NULL | NULL   |
+---------+------+--------+
```

## 解题思路

这道题需要将三个大陆的学生数据横向展示。

**核心思想：**
1. 为每个大陆的学生按字母顺序编号
2. 使用行号作为连接键
3. 横向合并三个大陆的数据

## SQL 代码实现

### 方法一：使用窗口函数

```sql
SELECT 
    MAX(CASE WHEN continent = 'America' THEN name END) AS America,
    MAX(CASE WHEN continent = 'Asia' THEN name END) AS Asia,
    MAX(CASE WHEN continent = 'Europe' THEN name END) AS Europe
FROM (
    SELECT *,
           ROW_NUMBER() OVER (PARTITION BY continent ORDER BY name) AS rn
    FROM Student
) t
GROUP BY rn
ORDER BY rn;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 使用 ROW_NUMBER 为每个大陆的学生编号
2. 使用 CASE 语句进行数据透视
3. 使用 MAX 聚合函数合并数据
