## 题目描述

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
| unit_price   | int     |
+--------------+---------+
product_id 是这个表的主键。
```

表：`Sales`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| seller_id   | int     |
| product_id  | int     |
| buyer_id    | int     |
| sale_date   | date    |
| quantity    | int     |
| price       | int     |
+-------------+---------+
这个表没有主键，它可以有重复的行。
product_id 是 Product 表的外键。
```

编写一个 SQL 查询，报告在 **2019 年第一季度**（2019-01-01 至 2019-03-31 之间）**只**销售的产品。

也就是说，这些产品在 2019 年第一季度有销售记录，但在此之外的任何时间都没有销售记录。

查询结果格式如下示例所示。

**示例：**

输入：
```
Product 表：
+------------+--------------+------------+
| product_id | product_name | unit_price |
+------------+--------------+------------+
| 1          | S8           | 1000       |
| 2          | G4           | 800        |
| 3          | iPhone       | 1400       |
+------------+--------------+------------+

Sales 表：
+-----------+------------+----------+------------+----------+-------+
| seller_id | product_id | buyer_id | sale_date  | quantity | price |
+-----------+------------+----------+------------+----------+-------+
| 1         | 1          | 1        | 2019-01-21 | 2        | 2000  |
| 1         | 2          | 2        | 2019-02-17 | 1        | 800   |
| 2         | 2          | 3        | 2019-06-02 | 1        | 800   |
| 3         | 3          | 4        | 2019-05-13 | 2        | 2800  |
+-----------+------------+----------+------------+----------+-------+
```

输出：
```
+-------------+--------------+
| product_id  | product_name |
+-------------+--------------+
| 1           | S8           |
+-------------+--------------+
```

解释：
- S8 (product_id=1) 只在 2019-01-21 销售（第一季度内）
- G4 (product_id=2) 在 2019-02-17（第一季度）和 2019-06-02（第二季度）都有销售
- iPhone (product_id=3) 只在 2019-05-13 销售（第二季度）

只有 S8 满足条件。

## 解题思路

这是一道**日期范围 + 条件筛选**问题。

### 核心思路

1. **第一季度定义**：2019-01-01 到 2019-03-31
2. **"只"销售的含义**：
   - 所有销售日期都在第一季度内
   - 即：没有任何销售日期在第一季度之外

3. **实现方式**：
   - 找出有销售记录的产品
   - 筛选这些产品，使得所有销售日期都在 Q1
   - 等价于：最小日期 >= '2019-01-01' AND 最大日期 <= '2019-03-31'

## SQL 代码实现

### 方法一：MIN/MAX 日期（推荐）

```sql
SELECT 
    p.product_id,
    p.product_name
FROM 
    Product p
WHERE 
    p.product_id IN (
        SELECT product_id
        FROM Sales
        GROUP BY product_id
        HAVING MIN(sale_date) >= '2019-01-01'
           AND MAX(sale_date) <= '2019-03-31'
    );
```

### 方法二：NOT EXISTS（双重否定）

```sql
SELECT 
    DISTINCT p.product_id,
    p.product_name
FROM 
    Product p
INNER JOIN 
    Sales s ON p.product_id = s.product_id
WHERE 
    s.sale_date BETWEEN '2019-01-01' AND '2019-03-31'
    AND NOT EXISTS (
        SELECT 1
        FROM Sales s2
        WHERE s2.product_id = p.product_id
          AND (s2.sale_date < '2019-01-01' OR s2.sale_date > '2019-03-31')
    );
```

### 方法三：EXCEPT / MINUS（集合运算）

```sql
-- MySQL 不支持 EXCEPT，PostgreSQL 支持
SELECT 
    p.product_id,
    p.product_name
FROM 
    Product p
WHERE 
    p.product_id IN (
        SELECT product_id FROM Sales WHERE sale_date BETWEEN '2019-01-01' AND '2019-03-31'
    )
    AND p.product_id NOT IN (
        SELECT product_id FROM Sales WHERE sale_date < '2019-01-01' OR sale_date > '2019-03-31'
    );
```

### 方法四：GROUP BY + HAVING

```sql
SELECT 
    p.product_id,
    p.product_name
FROM 
    Product p
INNER JOIN 
    Sales s ON p.product_id = s.product_id
GROUP BY 
    p.product_id, p.product_name
HAVING 
    SUM(CASE WHEN s.sale_date BETWEEN '2019-01-01' AND '2019-03-31' THEN 1 ELSE 0 END) > 0
    AND SUM(CASE WHEN s.sale_date < '2019-01-01' OR s.sale_date > '2019-03-31' THEN 1 ELSE 0 END) = 0;
```

## 复杂度分析

**SQL 方法：**
- **时间复杂度**：O(n)
  - GROUP BY：O(n)
  - 子查询：O(k)
- **空间复杂度**：O(k)，k 是不同产品数

**Pandas 方法：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. **日期范围**：使用 BETWEEN 或比较运算符
2. **"只"的含义**：所有销售都在范围内，没有例外
3. **MIN/MAX 技巧**：快速判断所有记录是否在范围内
4. **双重否定**：存在 Q1 销售 AND 不存在 Q1 外销售
5. **CASE WHEN 统计**：灵活统计满足不同条件的记录数

## 易错点

1. **理解错题意**：误以为是"有销售在 Q1"，实际是"只在 Q1 销售"
2. **日期边界**：BETWEEN 是闭区间，包含起止日期
3. **产品信息丢失**：忘记 JOIN Product 表获取 product_name
4. **空集合**：某产品没有销售记录，不应出现在结果中
5. **日期格式**：SQL 中日期字符串格式为 'YYYY-MM-DD'

## SQL 语法要点

### BETWEEN 运算符
```sql
-- BETWEEN 是闭区间 [a, b]
WHERE column BETWEEN 'value1' AND 'value2'

-- 等价于
WHERE column >= 'value1' AND column <= 'value2'
```

### MIN/MAX 聚合
```sql
SELECT 
    id,
    MIN(date_column) AS earliest,
    MAX(date_column) AS latest
FROM table
GROUP BY id;
```

### CASE WHEN 条件计数
```sql
SELECT 
    id,
    SUM(CASE WHEN condition THEN 1 ELSE 0 END) AS count_true,
    SUM(CASE WHEN NOT condition THEN 1 ELSE 0 END) AS count_false
FROM table
GROUP BY id;
```
