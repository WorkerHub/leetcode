## 题目描述

表：`Employees`

| Column Name   | Type |
|---------------|------|
| employee_id   | int  |
| needed_hours  | int  |

`employee_id` 是该表的主键，`needed_hours` 是员工每月需要工作的小时数。

表：`Logs`

| Column Name | Type     |
|-------------|----------|
| employee_id | int      |
| in_time     | datetime |
| out_time    | datetime |

该表记录每次打卡日志，`out_time >= in_time`，可能有多条记录属于同一员工。

计算每个员工的实际工作时间（`out_time - in_time` 之和，向下取整到分钟），若实际工作时间 **< `needed_hours * 60`**，则该员工需要被扣款。

返回需要被扣款的员工的 `employee_id`，按 `employee_id` 升序排列。

## 解题思路

**分组聚合 + 时间计算：**

1. 对 `Logs` 按 `employee_id` 分组，计算总工作分钟数（用 `TIMESTAMPDIFF` 或 `DATEDIFF`）。
2. 与 `Employees` 表关联，比较实际分钟数和需要的分钟数（`needed_hours * 60`）。
3. 返回实际工作分钟数不足的员工（包括完全没有打卡记录的员工）。

## 代码实现

### 方法一：LEFT JOIN + GROUP BY（推荐）

```sql
-- 计算每个员工实际工作分钟数，并与需要的分钟数比较
SELECT e.employee_id
FROM Employees e
LEFT JOIN (
    SELECT employee_id,
           SUM(TIMESTAMPDIFF(MINUTE, in_time, out_time)) AS total_minutes
    FROM Logs
    GROUP BY employee_id
) l ON e.employee_id = l.employee_id
WHERE COALESCE(l.total_minutes, 0) < e.needed_hours * 60
ORDER BY e.employee_id;
```

### 方法二：子查询版

```sql
-- 先统计每员工实际工作分钟
WITH WorkMinutes AS (
    SELECT employee_id,
           SUM(TIMESTAMPDIFF(MINUTE, in_time, out_time)) AS worked
    FROM Logs
    GROUP BY employee_id
)
SELECT e.employee_id
FROM Employees e
LEFT JOIN WorkMinutes w ON e.employee_id = w.employee_id
WHERE COALESCE(w.worked, 0) < e.needed_hours * 60
ORDER BY e.employee_id;
```

### 方法三：HAVING 子查询

```sql
-- 找出工作时间满足要求的员工，再用 NOT IN 找不满足的
SELECT employee_id
FROM Employees
WHERE employee_id NOT IN (
    SELECT employee_id
    FROM Logs
    GROUP BY employee_id
    HAVING SUM(TIMESTAMPDIFF(MINUTE, in_time, out_time)) >=
           (SELECT needed_hours * 60
            FROM Employees e2
            WHERE e2.employee_id = Logs.employee_id)
)
ORDER BY employee_id;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| LEFT JOIN | O(n log n) | O(n) |
| CTE | O(n log n) | O(n) |

## 关键点总结

1. 使用 `TIMESTAMPDIFF(MINUTE, in_time, out_time)` 计算时间差（向下取整分钟）。
2. `LEFT JOIN` 确保没有打卡记录的员工也会被查询到（工作时间为 0）。
3. `COALESCE(total, 0)` 处理 NULL（左连接后没有记录的员工的总分钟数为 NULL）。

## 易错点

- 注意 `needed_hours * 60`，单位是分钟，而不是小时。
- 没有打卡记录的员工工作时间为 0，仍需判断（使用 `LEFT JOIN`）。
- `TIMESTAMPDIFF` 是向下取整，不需要额外处理。
