## 题目描述

表 `Contacts`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| id           | int     |
| name         | varchar |
| phone_number | varchar |
+--------------+---------+
```

`id` 是主键。`phone_number` 格式为 `'xxx-yyy-zzzz'`（无空格）。

编写查询，找出电话号码是另一个联系人电话号码前缀的所有联系人。

即找出存在另一个联系人 B，使得 A 的 `phone_number` 是 B 的 `phone_number` 的前缀（且 A != B）。

返回这些联系人的 `id`、`name`、`phone_number`，按 `id` 升序排列。

**示例：**

输入：
```
+----+-------+--------------+
| id | name  | phone_number |
+----+-------+--------------+
| 1  | Alice | 123-456-7890 |
| 2  | Bob   | 123-456      |
| 3  | Carol | 987-654-3210 |
+----+-------+--------------+
```

输出：
```
+----+------+--------------+
| id | name | phone_number |
+----+------+--------------+
| 2  | Bob  | 123-456      |
+----+------+--------------+
```

**解释：** Bob 的号码 `123-456` 是 Alice 的号码 `123-456-7890` 的前缀。

## 解题思路

自连接：对每一对 (A, B)，判断 A.phone_number 是否是 B.phone_number 的前缀。

使用 `LIKE` 或 `LOCATE`/`SUBSTRING` 判断前缀关系。

## SQL 代码实现

### 方法一：自连接 + LIKE（推荐）

```sql
SELECT DISTINCT a.id, a.name, a.phone_number
FROM Contacts a
JOIN Contacts b ON a.id != b.id
WHERE b.phone_number LIKE CONCAT(a.phone_number, '%')
ORDER BY a.id;
```

### 方法二：自连接 + SUBSTRING

```sql
SELECT DISTINCT a.id, a.name, a.phone_number
FROM Contacts a
JOIN Contacts b ON a.id != b.id
    AND a.phone_number != b.phone_number
    AND SUBSTRING(b.phone_number, 1, LENGTH(a.phone_number)) = a.phone_number
ORDER BY a.id;
```

### 方法三：自连接 + LEFT

```sql
SELECT DISTINCT a.id, a.name, a.phone_number
FROM Contacts a
INNER JOIN Contacts b
    ON b.id <> a.id
    AND LEFT(b.phone_number, LENGTH(a.phone_number)) = a.phone_number
    AND LENGTH(b.phone_number) > LENGTH(a.phone_number)
ORDER BY a.id;
```

### 方法四：EXISTS 子查询

```sql
SELECT id, name, phone_number
FROM Contacts a
WHERE EXISTS (
    SELECT 1
    FROM Contacts b
    WHERE b.id != a.id
      AND b.phone_number LIKE CONCAT(a.phone_number, '%')
      AND LENGTH(b.phone_number) > LENGTH(a.phone_number)
)
ORDER BY id;
```

## 复杂度分析

- 时间复杂度：O(n^2)，自连接
- 空间复杂度：O(n)

## 关键点总结

1. 前缀判断：`LIKE CONCAT(a.phone_number, '%')` 或 `LEFT(b, len_a) = a`
2. 排除自身：`a.id != b.id`
3. 严格前缀（A 的长度 < B 的长度），避免相等的情况算作前缀

## 易错点

1. LIKE 模式中，`a.phone_number` 本身若含 `%` 或 `_` 等特殊字符会有问题（电话号码通常不含）
2. 前缀关系不包含相等（A != B），条件中要排除自身
3. `LENGTH` vs `CHAR_LENGTH`：对于纯 ASCII 字符串相同
