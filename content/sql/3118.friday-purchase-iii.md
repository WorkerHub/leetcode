## 题目描述

表：`Purchases`

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| user_id       | int  |
| purchase_date | date |
| amount_spend  | int  |
+---------------+------+
```

`(user_id, purchase_date, amount_spend)` 是该表的主键（可能有多行同一天同一用户的记录）。

表：`Users`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| membership  | varchar |
+-------------+---------+
```

`user_id` 是该表的主键。`membership` 取值为 `'Standard'`、`'Premium'`、`'VIP'` 之一。

编写一个解决方案，计算 **2023 年 11 月** 每个 **周五** 每种会员类型的总消费金额。若某种会员类型在某个周五没有消费，结果中不需要包含该行。

按 `purchase_date` 和 `membership` 升序排列。

**示例：**
```
输出格式：
+---------------+----------+--------------+
| purchase_date | membership | total_amount |
+---------------+----------+--------------+
```

## 解题思路

筛选 2023 年 11 月且是周五的记录，联接 Users 表获取会员类型，然后按日期和会员类型分组求和。

MySQL 中用 `DAYOFWEEK()` 判断周几（1=Sunday, 2=Monday, ..., 6=Friday, 7=Saturday）。

## 代码实现

### 方法一：标准 SQL

```sql
SELECT
    p.purchase_date,
    u.membership,
    SUM(p.amount_spend) AS total_amount
FROM Purchases p
JOIN Users u ON p.user_id = u.user_id
WHERE p.purchase_date BETWEEN '2023-11-01' AND '2023-11-30'
  AND DAYOFWEEK(p.purchase_date) = 6  -- 6 表示周五
GROUP BY p.purchase_date, u.membership
ORDER BY p.purchase_date, u.membership;
```

### 方法二：使用 WEEKDAY 函数

```sql
-- WEEKDAY: 0=Monday, 1=Tuesday, ..., 4=Friday, 5=Saturday, 6=Sunday
SELECT
    p.purchase_date,
    u.membership,
    SUM(p.amount_spend) AS total_amount
FROM Purchases p
INNER JOIN Users u ON p.user_id = u.user_id
WHERE YEAR(p.purchase_date) = 2023
  AND MONTH(p.purchase_date) = 11
  AND WEEKDAY(p.purchase_date) = 4  -- 4 表示周五
GROUP BY p.purchase_date, u.membership
ORDER BY p.purchase_date ASC, u.membership ASC;
```

## 复杂度分析

- 时间复杂度：取决于表的大小和索引情况
- 空间复杂度：O(n)，n 为筛选后的记录数

## 关键点总结

1. `DAYOFWEEK()` 返回 1-7（1=周日），周五 = 6
2. `WEEKDAY()` 返回 0-6（0=周一），周五 = 4
3. 分组后若某会员类型无记录，自动不包含（不需要 CASE 处理）

## 易错点

1. 注意 DAYOFWEEK 和 WEEKDAY 函数对周几的编号方式不同
2. 日期范围限定在 2023 年 11 月
