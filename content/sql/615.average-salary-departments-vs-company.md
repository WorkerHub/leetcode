## 题目描述

Table: Salary

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| employee_id | int  |
| amount      | int  |
| pay_date    | date |
+-------------+------+
id 是此表的主键
此表的每一行表示员工在某个日期的工资
```

Table: Employee

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| employee_id   | int  |
| department_id | int  |
+---------------+------+
employee_id 是此表的主键
此表的每一行表示员工所属的部门
```

编写 SQL 查询以比较每个部门在每个月的平均工资与公司的平均工资。

返回结果表应包含所有的月份（pay_date 格式为 'YYYY-MM'）、部门 ID 以及比较结果（'higher'、'lower' 或 'same'）。

**示例：**
```
Salary table:
+----+-------------+--------+------------+
| id | employee_id | amount | pay_date   |
+----+-------------+--------+------------+
| 1  | 1           | 9000   | 2017-03-31 |
| 2  | 2           | 6000   | 2017-03-31 |
| 3  | 3           | 10000  | 2017-03-31 |
| 4  | 1           | 7000   | 2017-02-28 |
| 5  | 2           | 6000   | 2017-02-28 |
| 6  | 3           | 8000   | 2017-02-28 |
+----+-------------+--------+------------+

Employee table:
+-------------+---------------+
| employee_id | department_id |
+-------------+---------------+
| 1           | 1             |
| 2           | 2             |
| 3           | 2             |
+-------------+---------------+

Result table:
+---------+---------------+------------+
| pay_month | department_id | comparison |
+---------+---------------+------------+
| 2017-02 | 1             | same       |
| 2017-02 | 2             | higher     |
| 2017-03 | 1             | higher     |
| 2017-03 | 2             | lower      |
+---------+---------------+------------+
```

## 解题思路

这道题需要比较每个部门每月的平均工资与公司整体每月平均工资。

**核心步骤：**
1. 计算每个月公司的平均工资
2. 计算每个部门每个月的平均工资
3. 比较两者，返回比较结果

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
SELECT 
    DATE_FORMAT(s.pay_date, '%Y-%m') AS pay_month,
    e.department_id,
    CASE 
        WHEN AVG(s.amount) > AVG(s.amount) OVER (PARTITION BY DATE_FORMAT(s.pay_date, '%Y-%m')) THEN 'higher'
        WHEN AVG(s.amount) < AVG(s.amount) OVER (PARTITION BY DATE_FORMAT(s.pay_date, '%Y-%m')) THEN 'lower'
        ELSE 'same'
    END AS comparison
FROM Salary s
JOIN Employee e ON s.employee_id = e.employee_id
GROUP BY DATE_FORMAT(s.pay_date, '%Y-%m'), e.department_id;
```

### 方法二:子查询

```sql
WITH MonthlyCompanyAvg AS (
    SELECT 
        DATE_FORMAT(pay_date, '%Y-%m') AS pay_month,
        AVG(amount) AS company_avg
    FROM Salary
    GROUP BY DATE_FORMAT(pay_date, '%Y-%m')
),
MonthlyDeptAvg AS (
    SELECT 
        DATE_FORMAT(s.pay_date, '%Y-%m') AS pay_month,
        e.department_id,
        AVG(s.amount) AS dept_avg
    FROM Salary s
    JOIN Employee e ON s.employee_id = e.employee_id
    GROUP BY DATE_FORMAT(s.pay_date, '%Y-%m'), e.department_id
)
SELECT 
    d.pay_month,
    d.department_id,
    CASE 
        WHEN d.dept_avg > c.company_avg THEN 'higher'
        WHEN d.dept_avg < c.company_avg THEN 'lower'
        ELSE 'same'
    END AS comparison
FROM MonthlyDeptAvg d
JOIN MonthlyCompanyAvg c ON d.pay_month = c.pay_month
ORDER BY d.pay_month, d.department_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 使用 DATE_FORMAT 格式化日期
2. 分别计算部门和公司的平均工资
3. 使用 CASE 语句比较结果
4. JOIN 连接员工和工资表
