## 题目描述

本题为数据库题目。

给定表 `Orders`：
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| order_id    | int  |
| item_count  | int  |
| order_occurrences | int |
+-------------+------+
```

计算所有订单的平均 `item_count`（加权平均：每个 item_count 按其 order_occurrences 加权），结果保留两位小数。

**计算方式：** `mean = SUM(item_count * order_occurrences) / SUM(order_occurrences)`

## SQL 代码实现

### 方法一：直接计算（推荐）

```sql
SELECT ROUND(
    SUM(item_count * order_occurrences) / SUM(order_occurrences),
    2
) AS mean;
```

### 方法二：使用子查询

```sql
SELECT ROUND(
    (SELECT SUM(item_count * order_occurrences) FROM Orders) /
    (SELECT SUM(order_occurrences) FROM Orders),
    2
) AS mean;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 加权平均 = 总数量之和 / 总订单次数之和
2. ROUND(..., 2) 保留两位小数
3. 简单的聚合计算题

## 易错点

1. 注意是加权平均，不是简单平均（不能直接 AVG(item_count)）
2. 分母是 SUM(order_occurrences)，不是 COUNT(*)
