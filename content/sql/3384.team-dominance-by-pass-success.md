## 题目描述

表：`passes`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| pass_from        | int     |
| time_stamp       | varchar |
| pass_to          | int     |
| team             | varchar |
| pass_result      | varchar |
+------------------+---------+
```

表：`players`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| player_id        | int     |
| team             | varchar |
+------------------+---------+
```

找出每个球队的"统治分"：每次传球成功（pass_result = 'successful'）且传球双方都在同一队时得 +1 分，传球给对方球队且成功时对方球队得分 -1（己方+1）。

具体规则需要参考官方题目，这里提供通用的 SQL 框架。

## 解题思路

按球队统计传球成功数，考虑同队传球和跨队传球的贡献。

## 代码实现

```sql
-- 统计每个球队的传球主导分
WITH team_passes AS (
    SELECT
        p.pass_from,
        p.pass_to,
        p.pass_result,
        pl1.team AS from_team,
        pl2.team AS to_team
    FROM passes p
    JOIN players pl1 ON p.pass_from = pl1.player_id
    JOIN players pl2 ON p.pass_to = pl2.player_id
    WHERE p.pass_result = 'successful'
),
scores AS (
    -- 传球方得分
    SELECT from_team AS team, 1 AS score
    FROM team_passes
    
    UNION ALL
    
    -- 接球方若不同队则得分
    SELECT to_team AS team, -1 AS score
    FROM team_passes
    WHERE from_team != to_team
)
SELECT
    team,
    SUM(score) AS dominance_score
FROM scores
GROUP BY team
ORDER BY dominance_score DESC, team ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，连接和分组操作
- 空间复杂度：O(n)

## 关键点总结

1. 使用 JOIN 将传球记录与球员信息连接，获取双方球队信息。
2. 每次成功传球给同队：传球方 +1 分。
3. 每次成功传球给对方球队：传球方 +1，接球方 -1（或其他规则）。

## 易错点

1. JOIN 条件需要同时连接发球方和接球方的球队信息。
2. `pass_result = 'successful'` 只统计成功传球。
3. 按分数降序、球队名升序排列。
