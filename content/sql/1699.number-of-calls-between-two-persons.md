## 题目描述

表：`Calls`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| from_id     | int     |
| to_id       | int     |
| duration    | int     |
+-------------+---------+
该表没有主键，可能包含重复项。
from_id != to_id
```

编写解决方案，统计**每对**用户之间通话的次数以及通话的总时长。

每对 `(person1, person2)` 满足 `person1 < person2`。

以**任意顺序**返回结果。

**示例：**
```
输入：
Calls 表：
+---------+-------+----------+
| from_id | to_id | duration |
+---------+-------+----------+
| 1       | 2     | 59       |
| 2       | 1     | 11       |
| 1       | 3     | 20       |
| 3       | 4     | 100      |
| 3       | 4     | 200      |
| 3       | 4     | 200      |
| 4       | 3     | 499      |
+---------+-------+----------+

输出：
+---------+---------+------------+----------------+
| person1 | person2 | call_count | total_duration |
+---------+---------+------------+----------------+
| 1       | 2       | 2          | 70             |
| 1       | 3       | 1          | 20             |
| 3       | 4       | 4          | 999            |
+---------+---------+------------+----------------+
```

## 解题思路

关键在于将 `(from_id, to_id)` 和 `(to_id, from_id)` 视为同一对，且统一使用较小的 ID 作为 `person1`。

使用 `LEAST(from_id, to_id)` 和 `GREATEST(from_id, to_id)` 来规范化每条记录，然后按这两列分组，统计次数和总时长。

## 代码实现

### 方法一：LEAST/GREATEST 规范化（推荐）

```sql
SELECT
    LEAST(from_id, to_id) AS person1,
    GREATEST(from_id, to_id) AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY person1, person2;
```

### 方法二：UNION ALL 合并两个方向

```sql
-- 将每条记录生成两行（确保 from_id < to_id 的方向）
WITH normalized AS (
    SELECT
        CASE WHEN from_id < to_id THEN from_id ELSE to_id END AS person1,
        CASE WHEN from_id < to_id THEN to_id ELSE from_id END AS person2,
        duration
    FROM Calls
)
SELECT
    person1,
    person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM normalized
GROUP BY person1, person2;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，GROUP BY 需要分组
- **空间复杂度**：O(n)，分组中间结果

## 关键点总结

1. `LEAST(a, b)` 返回两者的较小值，`GREATEST(a, b)` 返回较大值
2. 通过这两个函数，无论谁打给谁，都能统一规范化为 `person1 < person2`
3. GROUP BY 后用 `COUNT(*)` 统计通话次数，`SUM(duration)` 统计总时长

## 易错点

1. 不能直接按 `from_id, to_id` 分组，否则 `(1,2)` 和 `(2,1)` 会被当作不同组
2. `LEAST/GREATEST` 是 MySQL 的函数，在不同数据库中可能有替代写法（如 CASE WHEN）
