## 题目描述

表：`Sales`

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
(sale_id, year) 是该表的主键。
product_id 是 Product 表的外键。
该表的每一行表示：在某一年，售出了一些数量的某产品。
```

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
+--------------+---------+
product_id 是该表的主键。
该表的每一行表示每个产品的产品名称。
```

编写 SQL 查询，为每个产品找到**第一年销售**的产品 ID、年份、数量和价格。

返回结果表**无顺序要求**。

**示例：**

输入：
```
Sales 表：
+---------+------------+------+----------+-------+
| sale_id | product_id | year | quantity | price |
+---------+------------+------+----------+-------+
| 1       | 100        | 2008 | 10       | 5000  |
| 2       | 100        | 2009 | 12       | 5000  |
| 7       | 200        | 2011 | 15       | 9000  |
+---------+------------+------+----------+-------+

Product 表：
+------------+--------------+
| product_id | product_name |
+------------+--------------+
| 100        | Nokia        |
| 200        | Apple        |
| 300        | Samsung      |
+------------+--------------+
```

输出：
```
+------------+------------+----------+-------+
| product_id | first_year | quantity | price |
+------------+------------+----------+-------+
| 100        | 2008       | 10       | 5000  |
| 200        | 2011       | 15       | 9000  |
+------------+------------+----------+-------+
```

解释：
- 产品 100 在 2008 年首次销售，数量 10，价格 5000
- 产品 200 在 2011 年首次销售，数量 15，价格 9000

## 解题思路

这道题的关键是找到每个产品的**第一年**（最早年份）销售记录。

**方法对比：**
1. **子查询 + GROUP BY**：先找到每个产品的最早年份，再关联获取完整记录
2. **窗口函数**：使用 ROW_NUMBER() 或 RANK() 标记第一条记录
3. **自连接**：将表与自己按最小年份连接

**推荐方法：子查询**，逻辑清晰，性能较好。

## SQL 代码实现

### 方法一：子查询（推荐）

```sql
SELECT 
    product_id,
    year AS first_year,
    quantity,
    price
FROM 
    Sales
WHERE 
    (product_id, year) IN (
        SELECT 
            product_id,
            MIN(year) AS first_year
        FROM 
            Sales
        GROUP BY 
            product_id
    );
```

### 方法二：自连接

```sql
SELECT 
    s.product_id,
    s.year AS first_year,
    s.quantity,
    s.price
FROM 
    Sales s
INNER JOIN (
    SELECT 
        product_id,
        MIN(year) AS min_year
    FROM 
        Sales
    GROUP BY 
        product_id
) t
ON 
    s.product_id = t.product_id 
    AND s.year = t.min_year;
```

### 方法三：窗口函数（MySQL 8.0+）

```sql
SELECT 
    product_id,
    year AS first_year,
    quantity,
    price
FROM (
    SELECT 
        product_id,
        year,
        quantity,
        price,
        ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY year) AS rn
    FROM 
        Sales
) t
WHERE 
    rn = 1;
```

### 方法四：使用 RANK()

```sql
SELECT 
    product_id,
    year AS first_year,
    quantity,
    price
FROM (
    SELECT 
        product_id,
        year,
        quantity,
        price,
        RANK() OVER (PARTITION BY product_id ORDER BY year) AS rnk
    FROM 
        Sales
) ranked
WHERE 
    rnk = 1;
```

## 解题步骤

**方法一（子查询）步骤：**
1. 内层查询：对每个 `product_id` 分组，找到 `MIN(year)`
2. 外层查询：筛选出 `(product_id, year)` 在子查询结果中的记录
3. 选择需要的字段，并将 `year` 重命名为 `first_year`

**方法三（窗口函数）步骤：**
1. 使用 `ROW_NUMBER()` 为每个产品的销售记录按年份排序编号
2. 筛选出 `rn = 1` 的记录（即第一年的记录）
3. 选择需要的字段

## 关键点总结

1. **找最早年份**：使用 `MIN(year)` 或 `ORDER BY year` + `LIMIT 1`
2. **多字段匹配**：使用 `(product_id, year) IN (...)` 进行组合匹配
3. **窗口函数**：`ROW_NUMBER()` 配合 `PARTITION BY` 和 `ORDER BY`
4. **列重命名**：将 `year` 重命名为 `first_year`

## 易错点

1. **只返回年份**：不要忘记返回对应的 `quantity` 和 `price`
2. **重复年份**：如果同一产品在同一年有多条记录，要考虑是否都返回
3. **NULL 处理**：如果 `year` 有 NULL，`MIN()` 会忽略它们
4. **列名**：注意题目要求的列名是 `first_year`，不是 `year`

## 窗口函数对比

| 函数 | 说明 | 相同值处理 |
|------|------|------------|
| ROW_NUMBER() | 唯一排名 | 不同排名 |
| RANK() | 跳跃排名 | 相同排名，下一个跳过 |
| DENSE_RANK() | 连续排名 | 相同排名，下一个连续 |

**示例：**
```
year:  2008, 2008, 2009
ROW_NUMBER: 1, 2, 3
RANK:       1, 1, 3
DENSE_RANK: 1, 1, 2
```

## 扩展思考

**如果要找最后一年的销售怎么办？**

```sql
-- 方法一：MAX instead of MIN
SELECT 
    product_id,
    year AS last_year,
    quantity,
    price
FROM 
    Sales
WHERE 
    (product_id, year) IN (
        SELECT 
            product_id,
            MAX(year)
        FROM 
            Sales
        GROUP BY 
            product_id
    );

-- 方法二：窗口函数倒序
SELECT 
    product_id,
    year AS last_year,
    quantity,
    price
FROM (
    SELECT 
        *,
        ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY year DESC) AS rn
    FROM 
        Sales
) t
WHERE 
    rn = 1;
```
