## 题目描述

表：`Transactions`

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| id             | int     |
| country        | varchar |
| state          | enum    |
| amount         | int     |
| trans_date     | date    |
+----------------+---------+
```

`id` 是这个表的主键。

该表包含有关传入事务的信息。

`state` 列类型为 ["approved", "declined"] 之一。

表：`Chargebacks`

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| trans_id       | int     |
| trans_date     | date    |
+----------------+---------+
```

Chargebacks 表包含有关放置在 Transactions 表中的某些事务的退单的基本信息。

`trans_id` 是 `Transactions` 表的 `id` 列的外键。

编写一个 SQL 查询，以查找每个月和每个国家/地区的已批准事务的数量及其总金额、退单的数量及其总金额。

注意：在你的查询中，给定月份和国家，忽略所有为零的行。

返回结果表可以按任意顺序排列。

查询结果格式如下所示。

示例 1：

```
输入：
Transactions 表：
+-----+---------+----------+--------+------------+
| id  | country | state    | amount | trans_date |
+-----+---------+----------+--------+------------+
| 101 | US      | approved | 1000   | 2019-05-18 |
| 102 | US      | declined | 2000   | 2019-05-19 |
| 103 | US      | approved | 3000   | 2019-06-10 |
| 104 | US      | declined | 4000   | 2019-06-13 |
| 105 | US      | approved | 5000   | 2019-06-15 |
+-----+---------+----------+--------+------------+

Chargebacks 表：
+----------+------------+
| trans_id | trans_date |
+----------+------------+
| 102      | 2019-05-29 |
| 101      | 2019-06-30 |
| 105      | 2019-09-18 |
+----------+------------+

输出：
+---------+---------+----------------+-----------------+------------------+-------------------+
| month   | country | approved_count | approved_amount | chargeback_count | chargeback_amount |
+---------+---------+----------------+-----------------+------------------+-------------------+
| 2019-05 | US      | 1              | 1000            | 1                | 2000              |
| 2019-06 | US      | 2              | 8000            | 1                | 1000              |
| 2019-09 | US      | 0              | 0               | 1                | 5000              |
+---------+---------+----------------+-----------------+------------------+-------------------+

解释：
2019-05：
  - 批准的交易：id=101（1000）
  - 退单：id=102（2000，原始交易在 05-19，退单在 05-29）
  
2019-06：
  - 批准的交易：id=103（3000）+ id=105（5000）= 8000
  - 退单：id=101（1000，原始交易在 05-18，退单在 06-30）
  
2019-09：
  - 批准的交易：0
  - 退单：id=105（5000，原始交易在 06-15，退单在 09-18）
```

## 解题思路

这道题需要同时统计批准的交易和退单信息，关键点在于：

1. 批准的交易按照 Transactions 表中的 `trans_date` 分组
2. 退单按照 Chargebacks 表中的 `trans_date` 分组（注意不是原始交易日期）
3. 退单的金额需要从 Transactions 表中获取
4. 两部分数据需要合并，可能在同一月份同一国家，也可能在不同月份

解题步骤：

1. 从 Transactions 表中提取已批准的交易，按月份和国家分组统计
2. 从 Chargebacks 和 Transactions 表关联，提取退单信息，按月份和国家分组统计
3. 使用 UNION ALL 或 FULL OUTER JOIN 合并两部分数据
4. 再次分组聚合，计算最终结果

关键难点：

- 退单的日期是 Chargebacks 表中的日期，不是原始交易日期
- 需要关联 Transactions 表获取退单的金额和国家信息
- 同一月份同一国家可能既有批准交易又有退单，也可能只有其中一种

## SQL 代码实现

### 方法一：UNION ALL + GROUP BY（推荐）

```sql
SELECT 
    month,
    country,
    SUM(CASE WHEN type = 'approved' THEN 1 ELSE 0 END) AS approved_count,
    SUM(CASE WHEN type = 'approved' THEN amount ELSE 0 END) AS approved_amount,
    SUM(CASE WHEN type = 'chargeback' THEN 1 ELSE 0 END) AS chargeback_count,
    SUM(CASE WHEN type = 'chargeback' THEN amount ELSE 0 END) AS chargeback_amount
FROM (
    -- 批准的交易
    SELECT 
        DATE_FORMAT(trans_date, '%Y-%m') AS month,
        country,
        amount,
        'approved' AS type
    FROM Transactions
    WHERE state = 'approved'
    
    UNION ALL
    
    -- 退单
    SELECT 
        DATE_FORMAT(c.trans_date, '%Y-%m') AS month,
        t.country,
        t.amount,
        'chargeback' AS type
    FROM Chargebacks c
    JOIN Transactions t ON c.trans_id = t.id
) AS combined
GROUP BY month, country;
```

### 方法二：LEFT JOIN + COALESCE

```sql
WITH ApprovedTransactions AS (
    SELECT 
        DATE_FORMAT(trans_date, '%Y-%m') AS month,
        country,
        COUNT(*) AS approved_count,
        SUM(amount) AS approved_amount
    FROM Transactions
    WHERE state = 'approved'
    GROUP BY DATE_FORMAT(trans_date, '%Y-%m'), country
),
ChargebackTransactions AS (
    SELECT 
        DATE_FORMAT(c.trans_date, '%Y-%m') AS month,
        t.country,
        COUNT(*) AS chargeback_count,
        SUM(t.amount) AS chargeback_amount
    FROM Chargebacks c
    JOIN Transactions t ON c.trans_id = t.id
    GROUP BY DATE_FORMAT(c.trans_date, '%Y-%m'), t.country
)
SELECT 
    COALESCE(a.month, ch.month) AS month,
    COALESCE(a.country, ch.country) AS country,
    COALESCE(a.approved_count, 0) AS approved_count,
    COALESCE(a.approved_amount, 0) AS approved_amount,
    COALESCE(ch.chargeback_count, 0) AS chargeback_count,
    COALESCE(ch.chargeback_amount, 0) AS chargeback_amount
FROM ApprovedTransactions a
LEFT JOIN ChargebackTransactions ch 
    ON a.month = ch.month AND a.country = ch.country

UNION

SELECT 
    COALESCE(a.month, ch.month) AS month,
    COALESCE(a.country, ch.country) AS country,
    COALESCE(a.approved_count, 0) AS approved_count,
    COALESCE(a.approved_amount, 0) AS approved_amount,
    COALESCE(ch.chargeback_count, 0) AS chargeback_count,
    COALESCE(ch.chargeback_amount, 0) AS chargeback_amount
FROM ChargebackTransactions ch
LEFT JOIN ApprovedTransactions a
    ON a.month = ch.month AND a.country = ch.country
WHERE a.month IS NULL;
```

### 方法三：分别统计再合并

```sql
SELECT 
    month,
    country,
    SUM(approved_count) AS approved_count,
    SUM(approved_amount) AS approved_amount,
    SUM(chargeback_count) AS chargeback_count,
    SUM(chargeback_amount) AS chargeback_amount
FROM (
    SELECT 
        DATE_FORMAT(trans_date, '%Y-%m') AS month,
        country,
        COUNT(*) AS approved_count,
        SUM(amount) AS approved_amount,
        0 AS chargeback_count,
        0 AS chargeback_amount
    FROM Transactions
    WHERE state = 'approved'
    GROUP BY DATE_FORMAT(trans_date, '%Y-%m'), country
    
    UNION ALL
    
    SELECT 
        DATE_FORMAT(c.trans_date, '%Y-%m') AS month,
        t.country,
        0 AS approved_count,
        0 AS approved_amount,
        COUNT(*) AS chargeback_count,
        SUM(t.amount) AS chargeback_amount
    FROM Chargebacks c
    JOIN Transactions t ON c.trans_id = t.id
    GROUP BY DATE_FORMAT(c.trans_date, '%Y-%m'), t.country
) AS all_transactions
GROUP BY month, country;
```

## 复杂度分析

### SQL 方案

- 时间复杂度：O(n + m)，其中 n 是 Transactions 表的行数，m 是 Chargebacks 表的行数
  - 扫描 Transactions 表：O(n)
  - 关联 Chargebacks 和 Transactions：O(m)
  - 分组聚合：O((n+m) log (n+m))
- 空间复杂度：O(n + m)，用于存储中间结果

### Python Pandas 方案

- 时间复杂度：O(n + m)
  - 筛选和分组：O(n + m)
  - merge 操作：O(m log n)
  - concat 和最终聚合：O(n + m)
- 空间复杂度：O(n + m)，存储中间结果

## 关键点总结

1. 退单的日期是 Chargebacks 表中的日期，不是原始交易的日期
2. 需要关联 Transactions 表获取退单的金额和国家信息
3. 使用 UNION ALL 可以优雅地合并两类数据，然后统一分组聚合
4. 月份格式化使用 `DATE_FORMAT(date, '%Y-%m')` 或 Pandas 的 `dt.to_period('M')`
5. 要处理同一月份同一国家既有批准又有退单的情况

## 易错点

1. **日期字段混淆**：
   - 批准交易使用 Transactions 的 trans_date
   - 退单使用 Chargebacks 的 trans_date（不是原交易日期）
   - 错误：统一使用 Transactions 的日期会导致退单月份错误

2. **忘记关联表获取退单信息**：
   - Chargebacks 表只有 trans_id 和 trans_date
   - 必须关联 Transactions 表才能获取 country 和 amount
   - 错误：直接对 Chargebacks 分组会缺少必要信息

3. **合并数据时缺失某些月份**：
   - 使用 FULL OUTER JOIN 或 UNION ALL 确保所有月份都包含
   - 错误：只用 INNER JOIN 会丢失只有批准或只有退单的月份

4. **NULL 值处理**：
   - 使用 COALESCE 或 IFNULL 将 NULL 转换为 0
   - Pandas 使用 fillna(0)
   - 错误：NULL 值在聚合时可能导致结果不正确

5. **分组键不一致**：
   - 确保月份格式化方式一致（如都是 'YYYY-MM'）
   - 确保国家字段名称一致
   - 错误：格式不一致会导致无法正确合并

6. **忽略题目要求"忽略所有为零的行"**：
   - 本题实际上不需要过滤全零行，因为题目数据不会产生全零的情况
   - 如果需要过滤，添加 WHERE 子句即可

## 学习建议

1. **理解 UNION 和 UNION ALL 的区别**：
   - UNION 会去重，UNION ALL 保留所有行
   - 本题使用 UNION ALL 性能更好（不需要去重）

2. **掌握多表关联技巧**：
   - INNER JOIN：只保留匹配的行
   - LEFT JOIN：保留左表所有行
   - FULL OUTER JOIN：保留两表所有行（MySQL 不直接支持，需用 UNION 模拟）

3. **熟练使用日期函数**：
   - MySQL: DATE_FORMAT(), YEAR(), MONTH()
   - Pandas: dt.strftime(), dt.to_period(), dt.year, dt.month

4. **学会拆解复杂问题**：
   - 先分别处理批准交易和退单
   - 再合并结果
   - 不要试图一步到位

5. **练习建议**：
   - 先手动模拟数据处理过程
   - 分步验证每个子查询的结果
   - 对比不同方法的性能和可读性
   - 尝试用 Pandas 实现 SQL 逻辑，加深理解
