## 题目描述

表 `Teams` 结构如下：

| Column Name | Type    |
|-------------|---------|
| team_name   | varchar |

`team_name` 是该表的主键。

查询每场比赛的对阵双方，其中 `home_team` 和 `away_team` 不同（即联赛中每两支球队互相比赛一次）。返回所有可能的比赛组合，按任意顺序排列。

**示例：**
```
输入：
Teams 表：
+-------------+
| team_name   |
+-------------+
| Leetcode FC |
| Ahly SC     |
| Real Madrid |
+-------------+

输出：
+-------------+-------------+
| home_team   | away_team   |
+-------------+-------------+
| Leetcode FC | Ahly SC     |
| Leetcode FC | Real Madrid |
| Ahly SC     | Leetcode FC |
| Ahly SC     | Real Madrid |
| Real Madrid | Leetcode FC |
| Real Madrid | Ahly SC     |
+-------------+-------------+
```

## 解题思路

自连接（Self Join）：将 Teams 表与自身连接，条件为 `home_team != away_team`，列出所有有序对。

## 代码实现

### 方法一：自连接（推荐）

```sql
SELECT 
    t1.team_name AS home_team,
    t2.team_name AS away_team
FROM Teams t1
CROSS JOIN Teams t2
WHERE t1.team_name != t2.team_name
ORDER BY home_team, away_team
```

### 方法二：INNER JOIN

```sql
SELECT 
    t1.team_name AS home_team,
    t2.team_name AS away_team
FROM Teams t1
JOIN Teams t2 ON t1.team_name <> t2.team_name
ORDER BY home_team, away_team
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 自连接 | O(n^2) | O(n^2) |

其中 n 为球队数量。

## 关键点总结

1. 自连接（CROSS JOIN）生成所有有序对，然后过滤掉 home_team == away_team 的情况。
2. 结果是有序对，`(A, B)` 和 `(B, A)` 都要输出（每队既是主场也是客场）。
3. 用 `!=` 或 `<>` 过滤相同球队对阵自身的情况。

## 易错点

- 不要用 `t1.team_name < t2.team_name`，那样只会输出无序对（只有 A vs B，没有 B vs A）。
- 题目要求每两队各主客场各打一次，所以两个方向都要输出。
