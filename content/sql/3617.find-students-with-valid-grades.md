## 题目描述

表 `Students`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| name        | varchar |
| grade       | int     |
+-------------+---------+
student_id 是主键。
grade 表示学生成绩（0-100）。
```

请找出所有成绩在 60 到 100 之间（含端点）的学生，按 `student_id` 升序返回。

**示例：**

```
输入：
Students 表：
+------------+-------+-------+
| student_id | name  | grade |
+------------+-------+-------+
| 1          | Alice | 85    |
| 2          | Bob   | 55    |
| 3          | Carol | 100   |
| 4          | Dave  | 60    |
+------------+-------+-------+

输出：
+------------+-------+-------+
| student_id | name  | grade |
+------------+-------+-------+
| 1          | Alice | 85    |
| 3          | Carol | 100   |
| 4          | Dave  | 60    |
+------------+-------+-------+
```

## 解题思路

使用 `WHERE` 子句过滤成绩范围，`BETWEEN` 或比较运算符均可，最后按 `student_id` 排序。

## 代码实现

### 方法二：SQL

```sql
SELECT student_id, name, grade
FROM Students
WHERE grade BETWEEN 60 AND 100
ORDER BY student_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主要开销
- 空间复杂度：O(n)

## 关键点总结

1. `BETWEEN 60 AND 100` 等价于 `grade >= 60 AND grade <= 100`（含端点）
2. `ORDER BY student_id` 保证结果有序
3. Pandas 中可以用布尔索引过滤

## 易错点

1. `BETWEEN` 是闭区间，不要漏掉边界值 60 和 100
2. 排序方向默认为升序（ASC），无需显式指定
