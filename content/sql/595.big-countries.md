## 题目描述

查询所有大国的名称、人口和面积。大国定义为：面积至少300万平方公里，或人口至少2500万。

## SQL 代码实现

```sql
SELECT name, population, area
FROM World
WHERE area >= 3000000 OR population >= 25000000;
```

## 关键点总结

1. **OR条件**：面积或人口满足其一即可
2. **简单查询**：WHERE条件过滤

## 学习建议

掌握基本的WHERE条件查询。
