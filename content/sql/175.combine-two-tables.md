## 题目描述

表：`Person`

```
+-------------+---------+
| 列名         | 类型     |
+-------------+---------+
| personId    | int     |
| lastName    | varchar |
| firstName   | varchar |
+-------------+---------+
personId 是该表的主键（具有唯一值的列）。
该表包含一些人的 ID 和他们的姓名信息。
```

表：`Address`

```
+-------------+---------+
| 列名         | 类型     |
+-------------+---------+
| addressId   | int     |
| personId    | int     |
| city        | varchar |
| state       | varchar |
+-------------+---------+
addressId 是该表的主键（具有唯一值的列）。
该表的每一行都包含一个 ID = personId 的人的城市和州的信息。
```

编写解决方案，报告 `Person` 表中每个人的姓、名、城市和州。如果 `personId` 的地址不在 `Address` 表中，则报告为 `null`。

以**任意顺序**返回结果表。

**示例 1：**

```
输入：
Person 表：
+----------+----------+-----------+
| personId | lastName | firstName |
+----------+----------+-----------+
| 1        | Wang     | Allen     |
| 2        | Alice    | Bob       |
+----------+----------+-----------+

Address 表：
+-----------+----------+---------------+------------+
| addressId | personId | city          | state      |
+-----------+----------+---------------+------------+
| 1         | 2        | New York City | New York   |
| 2         | 3        | Leetcode      | California |
+-----------+----------+---------------+------------+

输出：
+-----------+----------+---------------+----------+
| firstName | lastName | city          | state    |
+-----------+----------+---------------+----------+
| Allen     | Wang     | Null          | Null     |
| Bob       | Alice    | New York City | New York |
+-----------+----------+---------------+----------+

解释：
地址表中没有 personId = 1 的地址，所以他们的城市和州返回 null。
addressId = 1 包含了关于 personId = 2 的地址信息。
```

## 解题思路

这是一道 SQL 基础题，考查**表连接（JOIN）**的使用。

### 核心概念

**LEFT JOIN（左连接）**：
- 返回左表的所有记录
- 即使右表中没有匹配的记录
- 右表没有匹配时，相关字段显示 NULL

**为什么不能用 INNER JOIN？**
- INNER JOIN 只返回两表都有的记录
- 会遗漏没有地址的人

### 解题步骤

1. 以 `Person` 表为主表（左表）
2. 左连接 `Address` 表
3. 连接条件：`Person.personId = Address.personId`
4. 选择需要的列：firstName, lastName, city, state

### SQL 连接类型对比

| 连接类型 | 说明 | 适用场景 |
|---------|------|---------|
| INNER JOIN | 只返回两表都匹配的记录 | 不适合本题 |
| LEFT JOIN | 返回左表所有记录 | **本题使用** |
| RIGHT JOIN | 返回右表所有记录 | 可用但不推荐 |
| FULL OUTER JOIN | 返回两表所有记录 | MySQL 不支持 |

## SQL 代码实现

### 方法一：LEFT JOIN（推荐）

```sql
SELECT 
    p.firstName, 
    p.lastName, 
    a.city, 
    a.state
FROM Person p
LEFT JOIN Address a ON p.personId = a.personId;
```

### 方法二：使用表别名简化

```sql
SELECT 
    Person.firstName, 
    Person.lastName, 
    Address.city, 
    Address.state
FROM Person
LEFT JOIN Address USING (personId);
```

### 方法三：RIGHT JOIN（不推荐）

```sql
-- 可行但不直观，需要调整表顺序
SELECT 
    p.firstName, 
    p.lastName, 
    a.city, 
    a.state
FROM Address a
RIGHT JOIN Person p ON a.personId = p.personId;
```

### 方法四：完整写法（显式列名）

```sql
SELECT 
    Person.firstName AS firstName,
    Person.lastName AS lastName,
    Address.city AS city,
    Address.state AS state
FROM Person
LEFT JOIN Address ON Person.personId = Address.personId;
```

## SQL 语法说明

### LEFT JOIN 语法

```sql
SELECT 列名
FROM 表1
LEFT JOIN 表2 ON 连接条件;
```

### USING 简化写法

当两表的连接列名相同时，可以使用 `USING`：

```sql
-- 等价于 ON p.personId = a.personId
LEFT JOIN Address USING (personId)
```

### 表别名

```sql
FROM Person p        -- p 是 Person 的别名
LEFT JOIN Address a  -- a 是 Address 的别名
```

## 执行过程图解

```
Person 表（左表）        Address 表（右表）
personId | firstName     personId | city
---------|----------     ---------|-------------
    1    | Allen             2    | New York City
    2    | Bob               3    | Leetcode

LEFT JOIN 过程：

1. 遍历 Person 的每一行
2. 在 Address 中查找匹配的 personId

personId=1 (Allen):
  在 Address 中找不到 personId=1
  结果：Allen, Wang, NULL, NULL

personId=2 (Bob):
  在 Address 中找到 personId=2
  结果：Bob, Alice, New York City, New York

最终输出：
Allen | Wang  | NULL          | NULL
Bob   | Alice | New York City | New York
```

## 关键点总结

1. **LEFT JOIN 保留左表所有记录**：确保所有人都被包括
2. **NULL 处理**：没有匹配时自动显示 NULL
3. **连接条件**：`ON Person.personId = Address.personId`
4. **表别名**：简化代码，提高可读性
5. **列顺序**：按题目要求选择列

## 易错点

1. **使用 INNER JOIN**
   - 错误：会遗漏没有地址的人
   - 正确：使用 LEFT JOIN

2. **连接条件错误**
   - 错误：`ON p.addressId = a.addressId`
   - 正确：`ON p.personId = a.personId`

3. **表顺序颠倒**
   - LEFT JOIN 时左表是 Person
   - 如果颠倒需要改用 RIGHT JOIN

4. **列名错误**
   - 注意区分 `personId` 和 `addressId`
   - `addressId` 是 Address 表的主键，不用于连接

5. **忘记表前缀**
   - 当列名不明确时需要加表名：`Person.firstName`

## 相关知识点

### SQL 连接类型

```sql
-- INNER JOIN（内连接）
SELECT * FROM A INNER JOIN B ON A.id = B.id;
-- 只返回 A 和 B 都有的记录

-- LEFT JOIN（左连接）
SELECT * FROM A LEFT JOIN B ON A.id = B.id;
-- 返回 A 的所有记录，B 没有时为 NULL

-- RIGHT JOIN（右连接）
SELECT * FROM A RIGHT JOIN B ON A.id = B.id;
-- 返回 B 的所有记录，A 没有时为 NULL

-- FULL OUTER JOIN（全外连接，MySQL 不支持）
SELECT * FROM A FULL OUTER JOIN B ON A.id = B.id;
-- 返回 A 和 B 的所有记录
```

### MySQL 特定语法

```sql
-- 方法1：使用 LEFT JOIN（标准 SQL）
SELECT * FROM A LEFT JOIN B ON A.id = B.id;

-- 方法2：使用 USING（列名相同时）
SELECT * FROM A LEFT JOIN B USING (id);

-- 方法3：隐式连接（不推荐）
SELECT * FROM A, B WHERE A.id = B.id;
```
