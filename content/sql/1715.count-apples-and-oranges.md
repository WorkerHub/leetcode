## 题目描述

表 `Boxes`：
```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| box_id       | int  |
| chest_id     | int  |
| apple_count  | int  |
| orange_count | int  |
+--------------+------+
```
`box_id` 是该表的主键。`chest_id` 是 `Chests` 表的外键，可以为 NULL（表示箱子没有胸箱）。

表 `Chests`：
```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| chest_id     | int  |
| apple_count  | int  |
| orange_count | int  |
+--------------+------+
```
`chest_id` 是该表的主键。

统计每个箱子中苹果和橙子的总数。如果箱子包含胸箱，胸箱中的水果也计入该箱子。

返回结果表，包含 `box_id`、苹果总数和橙子总数，按 `box_id` 升序排序。

## 解题思路

使用 LEFT JOIN 连接 `Boxes` 和 `Chests` 表，将胸箱（如果存在）的水果数加到箱子的水果数上。用 `COALESCE` 或 `IFNULL` 处理 `chest_id` 为 NULL 的情况（即没有胸箱时，胸箱贡献 0）。

## 代码实现

### 方法一：LEFT JOIN + COALESCE

```sql
-- 左连接胸箱表，将胸箱水果数加入箱子总数
SELECT
    b.box_id,
    b.apple_count + COALESCE(c.apple_count, 0) AS apple_count,
    b.orange_count + COALESCE(c.orange_count, 0) AS orange_count
FROM Boxes b
LEFT JOIN Chests c ON b.chest_id = c.chest_id
ORDER BY b.box_id;
```

### 方法二：LEFT JOIN + IFNULL（MySQL 语法）

```sql
-- IFNULL 是 MySQL 中 COALESCE 的简写（只接受两个参数）
SELECT
    b.box_id,
    b.apple_count + IFNULL(c.apple_count, 0) AS apple_count,
    b.orange_count + IFNULL(c.orange_count, 0) AS orange_count
FROM Boxes b
LEFT JOIN Chests c USING (chest_id)
ORDER BY b.box_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序操作
- **空间复杂度**：O(n)，存储连接结果

## 关键点总结

1. 使用 LEFT JOIN 保留所有箱子（即使没有胸箱）
2. 用 `COALESCE` 或 `IFNULL` 将 NULL 替换为 0
3. 直接对应字段相加即可

## 易错点

- 必须用 LEFT JOIN 而不是 INNER JOIN，否则没有胸箱的箱子会丢失
- `chest_id` 为 NULL 时，JOIN 不会匹配，需要 COALESCE 处理 NULL 值
