## 题目描述

给你一张 `Transactions` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| account_id    | int     |
| day           | date    |
| type          | ENUM    |
| amount        | int     |
+---------------+---------+
(account_id, day) 是联合主键
type 是枚举类型：Deposit 或 Withdrawal
```

计算每个账户每天操作后的**余额**（假设初始余额为 0）。

如果某天有多笔操作，日期相同时无论先后，只输出最终余额。

返回所有账户的账户余额，按 `account_id` 和 `day` 升序排列。

**示例：**
```
输入：
+------------+------------+----------+--------+
| account_id | day        | type     | amount |
+------------+------------+----------+--------+
| 1          | 2021-11-07 | Deposit  | 2000   |
| 1          | 2021-11-09 | Withdrawal| 1000  |
| 1          | 2021-11-11 | Deposit  | 3000   |
| 2          | 2021-11-01 | Deposit  | 7000   |
| 2          | 2021-11-02 | Withdrawal| 7000  |
+------------+------------+----------+--------+

输出：
+------------+------------+---------+
| account_id | day        | balance |
+------------+------------+---------+
| 1          | 2021-11-07 | 2000    |
| 1          | 2021-11-09 | 1000    |
| 1          | 2021-11-11 | 4000    |
| 2          | 2021-11-01 | 7000    |
| 2          | 2021-11-02 | 0       |
+------------+------------+---------+
```

## 解题思路

对每个账户按日期排序，用窗口函数累计余额：
- `Deposit`：加
- `Withdrawal`：减

先转换金额符号（存款为正，取款为负），再按 `account_id` 和 `day` 排序后用 `SUM() OVER (PARTITION BY ... ORDER BY ...)` 计算累计和。

## 代码实现

### 方法一：窗口函数（推荐）

```sql
SELECT
    account_id,
    day,
    SUM(
        CASE
            WHEN type = 'Deposit' THEN amount
            ELSE -amount
        END
    ) OVER (
        PARTITION BY account_id
        ORDER BY day
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS balance
FROM Transactions
ORDER BY account_id, day
```

### 方法二：自连接

```sql
SELECT
    t1.account_id,
    t1.day,
    SUM(CASE WHEN t2.type = 'Deposit' THEN t2.amount ELSE -t2.amount END) AS balance
FROM Transactions t1
JOIN Transactions t2
    ON t1.account_id = t2.account_id
    AND t2.day <= t1.day
GROUP BY t1.account_id, t1.day
ORDER BY t1.account_id, t1.day
```

### 方法三：CTE + 窗口函数

```sql
WITH signed_amounts AS (
    SELECT
        account_id,
        day,
        CASE WHEN type = 'Deposit' THEN amount ELSE -amount END AS signed_amount
    FROM Transactions
)
SELECT
    account_id,
    day,
    SUM(signed_amount) OVER (
        PARTITION BY account_id
        ORDER BY day
    ) AS balance
FROM signed_amounts
ORDER BY account_id, day
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和窗口函数
- 空间复杂度：O(n)

## 关键点总结

1. 存款为正，取款为负，累计求和即为余额
2. 窗口函数 `SUM() OVER (PARTITION BY ... ORDER BY ...)` 计算前缀和
3. 结果按 `account_id` 和 `day` 升序排列

## 易错点

- 取款金额为负（需要取反）
- `ORDER BY day` 确保按日期顺序累加（不是随机顺序）
- 同账户同日期只有一条记录（联合主键保证）
