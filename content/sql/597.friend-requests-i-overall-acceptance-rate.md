## 题目描述

编写SQL查询来计算好友请求的总体接受率（接受数/发送数）。

## SQL 代码实现

```sql
SELECT 
    IFNULL(
        ROUND(
            (SELECT COUNT(DISTINCT requester_id, accepter_id) FROM RequestAccepted) /
            (SELECT COUNT(DISTINCT sender_id, send_to_id) FROM FriendRequest),
            2
        ),
        0.00
    ) AS accept_rate;
```

## 关键点总结

1. **DISTINCT去重**：去除重复的请求
2. **IFNULL处理**：处理除数为0的情况
3. **ROUND**：保留2位小数

## 学习建议

掌握聚合函数的嵌套使用和NULL处理。
