## 题目描述

表：`cities`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| state       | varchar |
| city        | varchar |
+-------------+---------+
```

`(state, city)` 是主键。

编写一个解决方案，找出每个州及其所有城市，城市名按字母顺序排列并用逗号分隔，结果按州名升序排列。

**示例输出：**
```
+-------+--------------------+
| state | cities             |
+-------+--------------------+
| CA    | Los Angeles, ??    |
```

## 解题思路

使用 GROUP_CONCAT 函数聚合每个州的城市名，并按字母顺序排列。

## 代码实现

### 方法一：GROUP_CONCAT（推荐）

```sql
SELECT
    state,
    GROUP_CONCAT(city ORDER BY city ASC SEPARATOR ', ') AS cities
FROM cities
GROUP BY state
ORDER BY state ASC;
```

### 方法二：使用 STRING_AGG（PostgreSQL）

```sql
-- PostgreSQL 语法
SELECT
    state,
    STRING_AGG(city, ', ' ORDER BY city) AS cities
FROM cities
GROUP BY state
ORDER BY state;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序聚合
- 空间复杂度：O(n)

## 关键点总结

1. GROUP_CONCAT 支持 ORDER BY 子句
2. SEPARATOR 指定分隔符（默认逗号）
3. 外层 ORDER BY state 对州名排序

## 易错点

1. GROUP_CONCAT 中的 ORDER BY 是按城市排序，不是按州
2. 分隔符是 ', '（逗号加空格），注意格式
