## 题目描述

表：`guests`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| hotel_id      | int     |
| guest_id      | int     |
| checkin_date  | date    |
| checkout_date | date    |
+---------------+---------+
```

`(hotel_id, guest_id, checkin_date)` 是主键。

编写查询，找到在 2024 年 7 月有超过（>= ）指定数量宾客同时入住的酒店。

实际题意：找到在 2024 年 7 月任意某天同时有至少 2 位客人入住的酒店，返回 hotel_id，按升序排列。

**注：** 具体阈值和日期范围见原题，这里以常见变体为例。

## 解题思路

统计 2024 年 7 月每个酒店的入住记录，联接日期生成每天的在住人数，找满足条件的酒店。

## 代码实现

### 方法一：直接筛选（常见变体）

```sql
-- 找 2024 年 7 月有 >= 指定数量客人入住记录的酒店
SELECT DISTINCT hotel_id
FROM guests
WHERE checkin_date BETWEEN '2024-07-01' AND '2024-07-31'
GROUP BY hotel_id
HAVING COUNT(guest_id) >= 2
ORDER BY hotel_id;
```

### 方法二：按日期统计同时在住人数

```sql
-- 生成 2024-07 每天，统计每天在住人数
WITH dates AS (
    SELECT DATE('2024-07-01') + INTERVAL n DAY AS d
    FROM (SELECT 0 n UNION SELECT 1 UNION ... UNION SELECT 30) nums
),
daily AS (
    SELECT g.hotel_id, d.d, COUNT(*) AS cnt
    FROM guests g
    JOIN dates d ON g.checkin_date <= d.d AND g.checkout_date > d.d
    WHERE YEAR(d.d) = 2024 AND MONTH(d.d) = 7
    GROUP BY g.hotel_id, d.d
)
SELECT DISTINCT hotel_id
FROM daily
WHERE cnt >= 2
ORDER BY hotel_id;
```

## 复杂度分析

- 时间复杂度：O(n * days)
- 空间复杂度：O(n)

## 关键点总结

1. 统计某时段内同时在住的客人数
2. 联接日期生成每天的统计是常见思路

## 易错点

1. checkout_date 是离开当天，通常算不在住（> 而非 >=）
2. 日期范围包含 7 月 1 日到 31 日
