## 题目描述

表：`Triangles`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| A           | int  |
| B           | int  |
| C           | int  |
+-------------+------+
```

每行代表三角形的三边长度。

对每个三角形分类：
- `Equilateral`：等边三角形（三边相等）
- `Isosceles`：等腰三角形（恰好两边相等）
- `Scalene`：不等边三角形
- `Not A Triangle`：不能构成三角形

## SQL 代码实现

### 方法一：CASE WHEN（推荐）

```sql
SELECT
    A, B, C,
    CASE
        WHEN A + B <= C OR A + C <= B OR B + C <= A THEN 'Not A Triangle'
        WHEN A = B AND B = C THEN 'Equilateral'
        WHEN A = B OR B = C OR A = C THEN 'Isosceles'
        ELSE 'Scalene'
    END AS triangle_type
FROM Triangles;
```

## 复杂度分析

- 时间复杂度：O(n)，逐行判断
- 空间复杂度：O(n)，结果集

## 关键点总结

1. 先判断是否构成三角形（任意两边之和 > 第三边）
2. 等边 > 等腰 > 不等边（CASE WHEN 顺序）

## 易错点

1. 三角形不等式：三条不等式都要检查（不只是 A+B>C）
2. 判断顺序：等边三角形也满足等腰条件，需要先判断等边
