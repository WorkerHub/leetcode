## 题目描述

表：`Cinema`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| seat_id     | int  |
| free        | bool |
+-------------+------+
```

`seat_id` 是该表的主键列。
该表的每一行表示第 i 个座位是否空闲。
1 表示空闲，0 表示被占用。

找出所有连续可用的座位，并按 `seat_id` **升序排列**。

测试用例的生成使得两个以上的座位连续可用。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Cinema 表：
+---------+------+
| seat_id | free |
+---------+------+
| 1       | 1    |
| 2       | 0    |
| 3       | 1    |
| 4       | 1    |
| 5       | 1    |
+---------+------+

输出：
+---------+
| seat_id |
+---------+
| 3       |
| 4       |
| 5       |
+---------+

解释：
只有座位 3、4 和 5 是连续可用的。
```

## 解题思路

这道题要求找出**连续可用**的座位，即至少两个相邻的空座位。

**核心思路：**

1. **相邻判断**：判断每个座位的前一个或后一个座位是否也空闲
2. **连续性**：seat_id 连续且 free 都为 1

**三种实现方法：**

**方法一：自连接（推荐）**
- 将表与自身连接，条件是座位号相差 1
- 筛选两个座位都空闲的情况

**方法二：窗口函数**
- 使用 LAG() 或 LEAD() 获取相邻座位的状态
- 判断当前座位与前/后座位是否都空闲

**方法三：子查询**
- 对每个空座位，检查其前后座位是否空闲

## SQL 代码实现

### 方法一：自连接（最直观）⭐

```sql
SELECT DISTINCT c1.seat_id
FROM Cinema c1
JOIN Cinema c2
  ON ABS(c1.seat_id - c2.seat_id) = 1
  AND c1.free = 1
  AND c2.free = 1
ORDER BY c1.seat_id;
```

**详细版本（更清晰）：**

```sql
SELECT DISTINCT c1.seat_id
FROM Cinema c1
JOIN Cinema c2
  ON (c1.seat_id = c2.seat_id + 1 OR c1.seat_id = c2.seat_id - 1)
WHERE c1.free = 1 AND c2.free = 1
ORDER BY c1.seat_id;
```

### 方法二：窗口函数（现代SQL）⭐

```sql
SELECT seat_id
FROM (
    SELECT seat_id,
           free,
           LAG(free, 1) OVER (ORDER BY seat_id) AS prev_free,
           LEAD(free, 1) OVER (ORDER BY seat_id) AS next_free
    FROM Cinema
) AS t
WHERE free = 1 
  AND (prev_free = 1 OR next_free = 1)
ORDER BY seat_id;
```

**优化版（检查 seat_id 连续性）：**

```sql
SELECT seat_id
FROM (
    SELECT seat_id,
           free,
           LAG(free, 1) OVER (ORDER BY seat_id) AS prev_free,
           LEAD(free, 1) OVER (ORDER BY seat_id) AS next_free,
           LAG(seat_id, 1) OVER (ORDER BY seat_id) AS prev_id,
           LEAD(seat_id, 1) OVER (ORDER BY seat_id) AS next_id
    FROM Cinema
) AS t
WHERE free = 1 
  AND (
      (prev_free = 1 AND prev_id = seat_id - 1)
      OR
      (next_free = 1 AND next_id = seat_id + 1)
  )
ORDER BY seat_id;
```

### 方法三：相关子查询

```sql
SELECT seat_id
FROM Cinema c1
WHERE c1.free = 1
  AND (
      -- 检查前一个座位
      EXISTS (
          SELECT 1 FROM Cinema c2
          WHERE c2.seat_id = c1.seat_id - 1 AND c2.free = 1
      )
      OR
      -- 检查后一个座位
      EXISTS (
          SELECT 1 FROM Cinema c3
          WHERE c3.seat_id = c1.seat_id + 1 AND c3.free = 1
      )
  )
ORDER BY seat_id;
```

### 方法四：简化自连接（推荐用于面试）⭐⭐

```sql
-- 找到前一个座位也空闲的
SELECT c1.seat_id
FROM Cinema c1, Cinema c2
WHERE c1.seat_id = c2.seat_id + 1
  AND c1.free = 1
  AND c2.free = 1

UNION

-- 找到后一个座位也空闲的
SELECT c1.seat_id
FROM Cinema c1, Cinema c2
WHERE c1.seat_id = c2.seat_id - 1
  AND c1.free = 1
  AND c2.free = 1

ORDER BY seat_id;
```

## 复杂度分析

### 方法一（自连接）
- **时间复杂度**：O(n²)，自连接会产生笛卡尔积
- **空间复杂度**：O(n)，连接结果
- **实际性能**：由于过滤条件 `ABS(...) = 1`，实际复杂度接近 O(n)

### 方法二（窗口函数）
- **时间复杂度**：O(n)，单次扫描
- **空间复杂度**：O(n)，窗口函数结果
- **最优解**：性能最好

### 方法三（子查询）
- **时间复杂度**：O(n²)，对每行执行子查询
- **空间复杂度**：O(1)
- **不推荐**：性能较差

## 关键点总结

1. **连续的定义**：至少两个相邻的座位都空闲
2. **相邻判断**：seat_id 相差 1（需要考虑 +1 和 -1 两种情况）
3. **DISTINCT 的使用**：自连接方法中，同一个座位可能匹配到前后两个相邻座位，需要去重
4. **UNION 自动去重**：方法四使用 UNION（而非 UNION ALL）可以自动去重
5. **边界处理**：第一个和最后一个座位只有一侧相邻

## 易错点

1. **忘记 DISTINCT**：
   ```sql
   -- ❌ 错误：会产生重复结果
   SELECT c1.seat_id  -- 应该加 DISTINCT
   FROM Cinema c1
   JOIN Cinema c2 ON ABS(c1.seat_id - c2.seat_id) = 1
   WHERE c1.free = 1 AND c2.free = 1
   ```
   例如：座位3空闲，座位2和4也空闲，则座位3会出现两次

2. **只检查一侧相邻**：
   ```sql
   -- ❌ 错误：只检查了前一个座位
   SELECT seat_id
   FROM Cinema c1
   WHERE c1.free = 1
     AND EXISTS (
         SELECT 1 FROM Cinema c2
         WHERE c2.seat_id = c1.seat_id - 1 AND c2.free = 1
     )
   ```
   应该同时检查前后两侧

3. **忘记检查 free = 1**：
   ```sql
   -- ❌ 错误：没有检查座位是否空闲
   SELECT DISTINCT c1.seat_id
   FROM Cinema c1, Cinema c2
   WHERE ABS(c1.seat_id - c2.seat_id) = 1
   ```

4. **忘记排序**：题目要求按 seat_id 升序排列

## 学习建议

**新手学习路径：**

1. **理解"连续"的含义**：
   - 至少两个座位
   - seat_id 相邻（相差1）
   - 都是空闲状态（free = 1）

2. **从简单开始**：
   - 第一步：找出所有空座位 `WHERE free = 1`
   - 第二步：对每个空座位，检查其相邻座位是否也空闲
   - 第三步：去重和排序

3. **推荐方法**：
   - 初学者：方法一（自连接），逻辑最直观
   - 进阶：方法二（窗口函数），性能更好

4. **手动验证示例**：
   ```
   seat_id | free | 前一个free | 后一个free | 是否连续
   --------|------|-----------|-----------|----------
   1       | 1    | NULL      | 0         | ❌
   2       | 0    | 1         | 1         | ❌ (本身不空)
   3       | 1    | 0         | 1         | ✅ (与4连续)
   4       | 1    | 1         | 1         | ✅ (与3,5连续)
   5       | 1    | 1         | NULL      | ✅ (与4连续)
   ```

5. **调试技巧**：
   - 先不加 DISTINCT，看看是否有重复
   - 检查边界座位（第一个和最后一个）
   - 确认 free = 1 的条件没有遗漏

**实战技巧：**
- 这是一道典型的"相邻记录比较"问题
- 自连接方法简单但要注意去重
- 窗口函数是现代 SQL 的标准做法，性能更好
- 在面试中，能够用多种方法解决会是加分项
