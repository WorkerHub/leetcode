## 题目描述

表：`Tweets`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| tweet_id    | int     |
| tweet_date  | date    |
| tweet       | varchar |
+-------------+---------+
```

`tweet_id` 是该表的主键。每行包含 `user_id`、`tweet_id`、`tweet_date` 和 `tweet`。

编写一个解决方案，找到 2024 年 **2 月** 最流行的 **前 3 个** 话题标签（hashtag）。话题标签是推文中以 `#` 开头的词，统计每个话题标签的出现次数，按出现次数降序排列，若相同则按话题标签字母序升序排列。

**示例：**
```
输入：
Tweets 表：
+---------+----------+------------+------------------+
| user_id | tweet_id | tweet_date | tweet            |
+---------+----------+------------+------------------+
| 135     | 13       | 2024-02-01 | Enjoying a great #Spring... #OpenSource  |
| 136     | 14       | 2024-02-02 | Diving deep #Python #OpenSource         |
| 137     | 15       | 2024-02-04 | Impressed by #OpenSource community      |
+---------+----------+------------+------------------+

输出：
+-----------+-------+
| hashtag   | count |
+-----------+-------+
| #OpenSource| 3    |
| #Python   | 1     |
| #Spring   | 1     |
+-----------+-------+
```

## 解题思路

需要从推文文本中提取所有话题标签（以 `#` 开头的词），统计 2024 年 2 月的出现次数。MySQL 中可以使用正则和字符串函数，或利用递归 CTE 来拆分单词。

## 代码实现

### 方法一：SQL 使用正则提取（推荐）

```sql
-- 使用 MySQL 8.0+ 的递归 CTE 提取话题标签
WITH RECURSIVE split AS (
    -- 初始：tweet_id, 完整推文, 剩余文本
    SELECT
        tweet_id,
        tweet_date,
        tweet,
        TRIM(SUBSTRING_INDEX(tweet, ' ', 1)) AS word,
        IF(LOCATE(' ', tweet) > 0,
           TRIM(SUBSTR(tweet, LOCATE(' ', tweet) + 1)),
           NULL) AS rest
    FROM Tweets
    WHERE tweet_date BETWEEN '2024-02-01' AND '2024-02-29'
    UNION ALL
    SELECT
        tweet_id,
        tweet_date,
        tweet,
        TRIM(SUBSTRING_INDEX(rest, ' ', 1)),
        IF(LOCATE(' ', rest) > 0,
           TRIM(SUBSTR(rest, LOCATE(' ', rest) + 1)),
           NULL)
    FROM split
    WHERE rest IS NOT NULL
)
SELECT
    word AS hashtag,
    COUNT(*) AS count
FROM split
WHERE word LIKE '#%'
GROUP BY word
ORDER BY count DESC, hashtag ASC
LIMIT 3;
```

### 方法二：使用 JSON_TABLE（MySQL 8.0+）

```sql
-- 将推文按空格拆分为数组后用 JSON_TABLE 展开
SELECT
    word AS hashtag,
    COUNT(*) AS count
FROM Tweets,
JSON_TABLE(
    CONCAT('["', REPLACE(tweet, ' ', '","'), '"]'),
    '$[*]' COLUMNS (word VARCHAR(100) PATH '$')
) AS jt
WHERE tweet_date BETWEEN '2024-02-01' AND '2024-02-29'
  AND word LIKE '#%'
GROUP BY word
ORDER BY count DESC, hashtag ASC
LIMIT 3;
```

## 复杂度分析

- 时间复杂度：取决于推文数量和平均长度
- 空间复杂度：O(n)，n 为提取出的话题标签总数

## 关键点总结

1. 需要按空格拆分推文中的每个词
2. 筛选以 `#` 开头的词作为话题标签
3. 统计后按次数降序、字母升序排列，取前 3

## 易错点

1. 需要过滤日期为 2024 年 2 月
2. 话题标签比较区分大小写，注意统一处理
3. 拆分时注意多余空格的处理
