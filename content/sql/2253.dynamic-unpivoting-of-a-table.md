## 题目描述

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store1      | int     |
| store2      | int     |
| store3      | int     |
+-------------+---------+
product_id 是主键。storeX 的值可以为 null（表示该商店没有该产品）。
```

编写一个 SQL 解决方案，将表从**宽格式（Pivot）转换为长格式（Unpivot）**，即将每个商店列转为一行（store, price 对），忽略 null 值。

**动态版本：** 商店列名不固定，需要动态处理。

**输出：**
- `product_id`：产品 ID。
- `store`：商店名称。
- `price`：价格（非 null）。

按 `product_id, store` 排序。

**示例：**
```
Products 表：
+------------+--------+--------+--------+
| product_id | store1 | store2 | store3 |
+------------+--------+--------+--------+
| 1          | 2      | 5      | 4      |
| 2          | 8      | null   | null   |
| 3          | null   | null   | 13     |
+------------+--------+--------+--------+

输出：
+------------+--------+-------+
| product_id | store  | price |
+------------+--------+-------+
| 1          | store1 | 2     |
| 1          | store2 | 5     |
| 1          | store3 | 4     |
| 2          | store1 | 8     |
| 3          | store3 | 13    |
+------------+--------+-------+
```

## 解题思路

Unpivot 操作：将宽表转为长表。MySQL 没有原生 UNPIVOT，可以用 UNION ALL 模拟，或用动态 SQL。

静态方法：对每个商店列，用 `SELECT product_id, 'store1' AS store, store1 AS price FROM Products WHERE store1 IS NOT NULL` 然后 UNION ALL 所有列。

动态方法：通过 `information_schema.COLUMNS` 获取列名，动态构建 UNION ALL 语句。

## 代码实现

### 方法一：静态 UNION ALL

```sql
SELECT product_id, 'store1' AS store, store1 AS price
FROM Products
WHERE store1 IS NOT NULL

UNION ALL

SELECT product_id, 'store2' AS store, store2 AS price
FROM Products
WHERE store2 IS NOT NULL

UNION ALL

SELECT product_id, 'store3' AS store, store3 AS price
FROM Products
WHERE store3 IS NOT NULL

ORDER BY product_id, store;
```

### 方法二：动态 UNPIVOT（MySQL 存储过程）

```sql
CREATE PROCEDURE UnpivotProducts()
BEGIN
    -- 获取所有商店列（除 product_id 外的列）
    SET @sql = NULL;

    SELECT GROUP_CONCAT(
        CONCAT(
            'SELECT product_id, ''', COLUMN_NAME, ''' AS store, ',
            COLUMN_NAME, ' AS price FROM Products WHERE ', COLUMN_NAME, ' IS NOT NULL'
        )
        ORDER BY COLUMN_NAME
        SEPARATOR ' UNION ALL '
    ) INTO @sql
    FROM INFORMATION_SCHEMA.COLUMNS
    WHERE TABLE_SCHEMA = DATABASE()
      AND TABLE_NAME = 'Products'
      AND COLUMN_NAME != 'product_id';

    SET @sql = CONCAT(@sql, ' ORDER BY product_id, store');

    PREPARE stmt FROM @sql;
    EXECUTE stmt;
    DEALLOCATE PREPARE stmt;
END
```

## 复杂度分析

- 时间复杂度：O(n * k)，n 为产品数量，k 为商店列数量。
- 空间复杂度：O(n * k)，结果行数。

## 关键点总结

1. UNPIVOT = 将多列转为多行，每行包含列名（作为 store）和列值（作为 price）。
2. 静态方法用 UNION ALL 拼接每个列的查询，简单直观。
3. 动态方法通过 `INFORMATION_SCHEMA.COLUMNS` 获取列名，灵活处理动态列。
4. 过滤 `IS NOT NULL`，避免输出空价格行。

## 易错点

- `INFORMATION_SCHEMA.COLUMNS` 查询时需要指定 `TABLE_SCHEMA = DATABASE()` 限定当前数据库。
- 动态 SQL 拼接字符串时注意单引号转义。
