## 题目描述

表：`students`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| name        | varchar |
+-------------+---------+
```

`student_id` 是主键。

表：`enrollments`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| course_id   | int     |
| grade       | varchar |
+-------------+---------+
```

`(student_id, course_id)` 是主键。

找出在所有已选课程中成绩均为 `'A'` 的学生，返回其 `student_id` 和 `name`，按 `student_id` 升序排列。

## 解题思路

找选了至少一门课且所有课成绩都是 'A' 的学生。

等价于：学生在 enrollments 中出现，且没有任何非 'A' 的成绩记录。

## 代码实现

### 方法一：排除有非 A 成绩的学生（推荐）

```sql
SELECT s.student_id, s.name
FROM students s
WHERE s.student_id IN (
    SELECT student_id FROM enrollments
    WHERE student_id NOT IN (
        SELECT student_id FROM enrollments WHERE grade != 'A'
    )
)
ORDER BY s.student_id;
```

### 方法二：聚合

```sql
SELECT s.student_id, s.name
FROM students s
JOIN enrollments e ON s.student_id = e.student_id
GROUP BY s.student_id, s.name
HAVING SUM(CASE WHEN e.grade != 'A' THEN 1 ELSE 0 END) = 0
ORDER BY s.student_id;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 需要选了至少一门课（JOIN 保证）
2. 所有课成绩都是 A：没有任何非 A 的记录
3. 用 HAVING COUNT(*) = SUM(grade='A') 也可以

## 易错点

1. 没有选课的学生也不应该出现
2. 成绩字符串比较区分大小写（取决于数据库配置）
