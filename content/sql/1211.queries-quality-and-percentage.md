## 题目描述

表：`Queries`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| query_name  | varchar |
| result      | varchar |
| position    | int     |
| rating      | int     |
+-------------+---------+
```

此表没有主键，可能有重复的行。

此表包含了一些从数据库中收集的查询信息。

`position` 列的值从 1 到 500。

`rating` 列的值从 1 到 5。评分小于 3 的查询被定义为质量很差的查询。

我们将查询质量 `quality` 定义为：

```
quality = 平均值(rating/position)
```

将劣质查询百分比 `poor_query_percentage` 定义为：

```
poor_query_percentage = (评分小于 3 的查询数量 / 查询总数) × 100
```

编写一个 SQL 查询来查找每个查询名称 `query_name`、质量 `quality` 和劣质查询百分比 `poor_query_percentage`。

`quality` 和 `poor_query_percentage` 都应四舍五入到小数点后 2 位。

查询结果格式如下所示。

示例 1：

输入：
Queries 表：
```
+------------+-------------------+----------+--------+
| query_name | result            | position | rating |
+------------+-------------------+----------+--------+
| Dog        | Golden Retriever  | 1        | 5      |
| Dog        | German Shepherd   | 2        | 5      |
| Dog        | Mule              | 200      | 1      |
| Cat        | Shirazi           | 5        | 2      |
| Cat        | Siamese           | 3        | 3      |
| Cat        | Sphynx            | 7        | 4      |
+------------+-------------------+----------+--------+
```

输出：
```
+------------+---------+-----------------------+
| query_name | quality | poor_query_percentage |
+------------+---------+-----------------------+
| Dog        | 2.50    | 33.33                 |
| Cat        | 2.67    | 33.33                 |
+------------+---------+-----------------------+
```

解释：
- Dog 查询的质量为 ((5/1) + (5/2) + (1/200)) / 3 = 2.50
- Dog 查询的劣质查询百分比为 (1/3) × 100 = 33.33
- Cat 查询的质量为 ((2/5) + (3/3) + (4/7)) / 3 = 2.67
- Cat 查询的劣质查询百分比为 (1/3) × 100 = 33.33

## 解题思路

这是一道典型的 SQL 聚合查询题目，需要按照 `query_name` 分组，然后计算两个指标：

1. **质量 (quality)**：需要计算每个查询的 `rating/position` 的平均值
2. **劣质查询百分比 (poor_query_percentage)**：计算评分小于 3 的查询占总查询数的百分比

核心思路：
1. 使用 `GROUP BY query_name` 对查询名称分组
2. 使用 `AVG(rating/position)` 计算质量
3. 使用条件聚合计算劣质查询百分比：
   - 方法 1：使用 `SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END) / COUNT(*) × 100`
   - 方法 2：使用 `AVG(IF(rating < 3, 1, 0)) × 100` (MySQL)
   - 方法 3：使用 `AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END) × 100`
4. 使用 `ROUND()` 函数将结果保留两位小数

## SQL 代码实现

### 方法一：使用 CASE WHEN 和 SUM（推荐，通用性强）

```sql
SELECT 
    query_name,
    ROUND(AVG(rating / position), 2) AS quality,
    ROUND(SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) AS poor_query_percentage
FROM 
    Queries
WHERE 
    query_name IS NOT NULL
GROUP BY 
    query_name;
```

**说明**：
- `AVG(rating / position)` 计算每个分组内 rating/position 的平均值
- `SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END)` 统计评分小于 3 的查询数量
- `COUNT(*)` 统计每个分组的总查询数
- 乘以 `100.0` 而不是 `100` 是为了避免整数除法，确保结果是浮点数
- `WHERE query_name IS NOT NULL` 过滤掉查询名称为空的记录
- `ROUND(..., 2)` 保留两位小数

### 方法二：使用 AVG 和 CASE WHEN（更简洁）

```sql
SELECT 
    query_name,
    ROUND(AVG(rating / position), 2) AS quality,
    ROUND(AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100, 2) AS poor_query_percentage
FROM 
    Queries
WHERE 
    query_name IS NOT NULL
GROUP BY 
    query_name;
```

**说明**：
- 使用 `AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END)` 直接计算百分比
- 这种方法更简洁，因为 AVG 本身就是 SUM/COUNT
- 平均值乘以 100 得到百分比

### 方法三：使用 IF 函数（MySQL 特有）

```sql
SELECT 
    query_name,
    ROUND(AVG(rating / position), 2) AS quality,
    ROUND(AVG(IF(rating < 3, 1, 0)) * 100, 2) AS poor_query_percentage
FROM 
    Queries
WHERE 
    query_name IS NOT NULL
GROUP BY 
    query_name;
```

**说明**：
- `IF(rating < 3, 1, 0)` 是 MySQL 的简化语法，等价于 CASE WHEN
- 这种写法最简洁，但只适用于 MySQL

## 复杂度分析

### SQL 解法

- **时间复杂度**：O(n)，其中 n 是 Queries 表的行数。需要扫描所有行进行分组和聚合
- **空间复杂度**：O(k)，其中 k 是不同 query_name 的数量，用于存储分组结果

### Python Pandas 解法

- **时间复杂度**：O(n log n)，主要来自于 groupby 操作的排序
- **空间复杂度**：O(n)，需要存储辅助列和中间结果

## 关键点总结

1. **分组聚合**：使用 `GROUP BY` 按 query_name 分组是解决此题的核心
2. **除法运算**：SQL 中要注意整数除法问题，应使用 `100.0` 而不是 `100` 来确保浮点运算
3. **条件聚合**：计算百分比时可以使用 `SUM(CASE WHEN...)` 或 `AVG(CASE WHEN...)` 两种方法
4. **精度控制**：使用 `ROUND()` 函数保留两位小数
5. **空值处理**：需要过滤掉 query_name 为 NULL 的记录

## 易错点

1. **整数除法陷阱**：
   ```sql
   -- 错误：在某些数据库中会被当作整数除法
   SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100 / COUNT(*)
   
   -- 正确：使用 100.0 确保浮点除法
   SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100.0 / COUNT(*)
   ```

2. **忘记过滤空值**：如果 query_name 可能为 NULL，需要添加 `WHERE query_name IS NOT NULL`

3. **精度问题**：
   ```sql
   -- 错误：先除法后乘法可能损失精度
   ROUND(AVG(rating / position * 1.0), 2)
   
   -- 正确：保持原有计算顺序
   ROUND(AVG(rating / position), 2)
   ```

4. **百分比计算顺序**：
   - 使用 `AVG(...) * 100` 时，应该先计算平均值，再乘以 100
   - 不要写成 `AVG(... * 100)`，这会改变计算逻辑

5. **ROUND 函数位置**：在 Pandas 中，应该在最后对整列进行 round，而不是在聚合函数内部

## 学习建议

### 对于 SQL 新手

1. **掌握 GROUP BY 基础**：
   - 理解分组的概念：相同 query_name 的行会被归为一组
   - 学习常用聚合函数：COUNT, SUM, AVG, MAX, MIN
   - 掌握 GROUP BY 后只能 SELECT 分组列和聚合函数

2. **条件聚合的两种写法**：
   - `SUM(CASE WHEN condition THEN 1 ELSE 0 END) / COUNT(*)` - 直观，易理解
   - `AVG(CASE WHEN condition THEN 1 ELSE 0 END)` - 简洁，原理是 AVG = SUM/COUNT

3. **数值精度处理**：
   - 熟悉 ROUND 函数的用法
   - 注意整数除法和浮点除法的区别
   - 了解不同数据库的除法行为差异（MySQL, PostgreSQL, SQL Server）

4. **建议练习步骤**：
   - 第一步：先写出按 query_name 分组的基本查询
   - 第二步：添加 quality 计算
   - 第三步：添加 poor_query_percentage 计算
   - 第四步：添加 ROUND 和空值过滤

### 对于 Python/Pandas 学习者

1. **groupby 操作**：
   - 理解 split-apply-combine 模式
   - 熟悉 apply, agg, transform 的区别和使用场景
   - 掌握命名聚合（Named Aggregation）语法

2. **条件统计**：
   - 使用布尔索引：`(df['column'] < 3).mean()` 可以直接计算百分比
   - 理解布尔值在数值运算中会被转换为 0 和 1

3. **方法对比**：
   - `apply + lambda`：最灵活，但性能较差
   - `agg`：性能好，适合多列聚合
   - `transform`：保持原始行数，适合添加分组统计列

4. **与 SQL 对应关系**：
   - SQL 的 GROUP BY → Pandas 的 groupby
   - SQL 的 CASE WHEN → Pandas 的布尔索引或 np.where
   - SQL 的 ROUND → Pandas 的 round 方法
