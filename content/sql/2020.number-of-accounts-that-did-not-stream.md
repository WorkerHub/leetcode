## 题目描述

给你两张表：

**Accounts 表：**
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| account_id  | int  |
| birthday    | date |
+-------------+------+
account_id 是主键
```

**Streams 表：**
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| session_id  | int  |
| account_id  | int  |
| stream_date | date |
+-------------+------+
session_id 是主键
```

计算在 2021 年没有流量记录（没有在 Streams 表中出现），且出生年份不是 2000 年的账户数量。

**示例：**
```
Accounts 表：
+------------+------------+
| account_id | birthday   |
+------------+------------+
| 1          | 1990-01-01 |
| 2          | 2000-01-01 |
| 3          | 1960-01-01 |
+------------+------------+

Streams 表：
+------------+------------+-------------+
| session_id | account_id | stream_date |
+------------+------------+-------------+
| 14         | 2          | 2021-03-01  |
| 16         | 3          | 2021-06-05  |
+------------+------------+-------------+

输出：1
解释：账户 1 在 2021 年没有流量，且出生年份不是 2000 年。
```

## 解题思路

1. 从 Accounts 表中筛选出生年份不是 2000 年的账户
2. 排除在 2021 年有流量记录的账户（使用 NOT IN 或 LEFT JOIN）
3. 统计剩余账户数量

## 代码实现

### 方法一：NOT IN 子查询

```sql
SELECT COUNT(*) AS accounts_count
FROM Accounts
WHERE YEAR(birthday) != 2000
  AND account_id NOT IN (
      SELECT DISTINCT account_id
      FROM Streams
      WHERE YEAR(stream_date) = 2021
  )
```

### 方法二：LEFT JOIN + NULL 过滤

```sql
SELECT COUNT(a.account_id) AS accounts_count
FROM Accounts a
LEFT JOIN (
    -- 2021 年有流量的账户
    SELECT DISTINCT account_id
    FROM Streams
    WHERE YEAR(stream_date) = 2021
) s ON a.account_id = s.account_id
WHERE YEAR(a.birthday) != 2000
  AND s.account_id IS NULL  -- 没有匹配（即 2021 年无流量）
```

### 方法三：NOT EXISTS

```sql
SELECT COUNT(*) AS accounts_count
FROM Accounts a
WHERE YEAR(a.birthday) != 2000
  AND NOT EXISTS (
      SELECT 1
      FROM Streams s
      WHERE s.account_id = a.account_id
        AND YEAR(s.stream_date) = 2021
  )
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为 Accounts 行数，m 为 Streams 行数
- 空间复杂度：O(m)，子查询结果集

## 关键点总结

1. 两个条件的交集：出生年份 != 2000 且 2021 年无流量
2. LEFT JOIN 方案性能通常优于 NOT IN（特别是数据量大时）
3. `YEAR()` 函数提取年份；也可以用 `BETWEEN '2021-01-01' AND '2021-12-31'`

## 易错点

- `NOT IN` 当子查询返回 NULL 时会导致结果为空，需要确保子查询无 NULL
- 注意题目要求是 2021 年**整年**无流量，不是某个特定日期
- 出生年份使用 `YEAR(birthday) != 2000`，不是 `!= '2000-01-01'`
