## 题目描述

表：`Teams`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| player_id        | int     |
| team_name        | varchar |
+------------------+---------+
```
`player_id` 是主键。

表：`Passes`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| pass_from        | int     |
+------------------+---------+
| time_stamp       | varchar |
| pass_to          | int     |
| pass_result      | varchar |
+------------------+---------+
```

找出每个球队的**最长传球连续成功串**（streak）：在连续传球序列中，中间没有任何失败传球，且传球方和接球方均属于同一球队。

返回每个球队的最长连续成功传球数，按球队名升序排列。

## 解题思路

**分组 + 窗口函数计算连续序列：**

1. 连接 `Passes` 和 `Teams`（发球方和接球方），筛选出同队传球且成功的记录。
2. 使用经典的"连续序列"技巧：
   - 对每个球队按时间戳排序，用行号减去组内行号得到分组标识。
   - 统计每个分组的长度，取最大值。

经典连续序列技巧：
- `ROW_NUMBER() OVER (ORDER BY time_stamp)` 全局行号
- `ROW_NUMBER() OVER (PARTITION BY team ORDER BY time_stamp)` 组内行号
- 差值相同的行属于同一连续组

## 代码实现

```sql
WITH same_team_success AS (
    -- 筛选同队且成功的传球
    SELECT
        p.pass_from,
        p.pass_to,
        p.time_stamp,
        t1.team_name AS team
    FROM Passes p
    JOIN Teams t1 ON p.pass_from = t1.player_id
    JOIN Teams t2 ON p.pass_to = t2.player_id
    WHERE p.pass_result = 'successful'
      AND t1.team_name = t2.team_name
),
ranked AS (
    -- 全局行号 - 组内行号 = 连续组标识
    SELECT
        team,
        time_stamp,
        ROW_NUMBER() OVER (ORDER BY time_stamp) AS global_rn,
        ROW_NUMBER() OVER (PARTITION BY team ORDER BY time_stamp) AS team_rn
    FROM same_team_success
),
groups AS (
    -- 按连续组分组统计
    SELECT
        team,
        (global_rn - team_rn) AS grp,
        COUNT(*) AS streak_len
    FROM ranked
    GROUP BY team, (global_rn - team_rn)
),
max_streaks AS (
    SELECT
        team,
        MAX(streak_len) AS longest_streak
    FROM groups
    GROUP BY team
)
SELECT
    team,
    longest_streak
FROM max_streaks
ORDER BY team ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和窗口函数操作
- 空间复杂度：O(n)

## 关键点总结

1. 连续序列的经典 SQL 技巧：全局行号 - 组内行号 = 分组标识。
2. 需要同时连接发球方和接球方的球队信息，确保同队传球。
3. 对每个连续分组统计长度，再取各球队的最大值。

## 易错点

1. 必须同时验证发球方和接球方都属于同一球队。
2. `pass_result = 'successful'` 只统计成功传球。
3. 时间戳排序是保证连续性的关键。
4. 若某球队没有同队成功传球，该球队不出现在结果中（或返回 0，取决于题目要求）。
