## 题目描述

表：`transaction_records`

```
+--------------------+---------+
| Column Name        | Type    |
+--------------------+---------+
| transaction_id     | int     |
| customer_id        | int     |
| product_id         | int     |
| transaction_date   | date    |
| amount             | decimal |
+--------------------+---------+
```

表：`product_info`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| category    | varchar |
| price       | decimal |
+-------------+---------+
```

编写 SQL 查询，对于 2023 年所有有交易记录的客户，计算：
- `customer_id`
- `total_amount`：总消费金额
- `transaction_count`：交易次数
- `unique_categories`：购买的不同类别数量
- `avg_transaction_amount`：平均每次交易金额（保留两位小数）
- `top_category`：购买最多的类别（按交易次数，同名取字母序最小的）

按 `total_amount` 降序排列，`customer_id` 升序。

## 解题思路

需要多个聚合计算，用子查询或 CTE：
1. 关联 `transaction_records` 和 `product_info`
2. 按 `customer_id` 聚合统计
3. 找每个客户的 `top_category` 需要额外的窗口函数或子查询

## 代码实现

```sql
WITH customer_stats AS (
    SELECT
        t.customer_id,
        SUM(t.amount) AS total_amount,
        COUNT(*) AS transaction_count,
        COUNT(DISTINCT p.category) AS unique_categories,
        ROUND(AVG(t.amount), 2) AS avg_transaction_amount
    FROM transaction_records t
    JOIN product_info p ON t.product_id = p.product_id
    WHERE YEAR(t.transaction_date) = 2023
    GROUP BY t.customer_id
),
category_counts AS (
    SELECT
        t.customer_id,
        p.category,
        COUNT(*) AS cat_count,
        ROW_NUMBER() OVER (
            PARTITION BY t.customer_id
            ORDER BY COUNT(*) DESC, p.category ASC
        ) AS rn
    FROM transaction_records t
    JOIN product_info p ON t.product_id = p.product_id
    WHERE YEAR(t.transaction_date) = 2023
    GROUP BY t.customer_id, p.category
)
SELECT
    cs.customer_id,
    cs.total_amount,
    cs.transaction_count,
    cs.unique_categories,
    cs.avg_transaction_amount,
    cc.category AS top_category
FROM customer_stats cs
JOIN category_counts cc ON cs.customer_id = cc.customer_id AND cc.rn = 1
ORDER BY cs.total_amount DESC, cs.customer_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 用 CTE 分步计算，逻辑清晰
2. 找 top_category 使用 `ROW_NUMBER()` 窗口函数，按次数降序、类别名升序排名
3. 过滤 2023 年用 `YEAR(transaction_date) = 2023`

## 易错点

1. `top_category` 同名时取字母序最小，需要在 ORDER BY 中加 `category ASC`
2. 注意 `ROUND` 保留两位小数
3. 确保只统计 2023 年的数据
