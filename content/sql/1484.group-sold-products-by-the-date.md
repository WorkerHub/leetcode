## 题目描述

表 `Activities`：

| 列名 | 类型 |
|------|------|
| sell_date | date |
| product | varchar |

该表没有主键，可能含有重复行。该表的每一行包含产品名称和在市场上销售的日期。

编写解决方案，找出每个日期售出的不同产品的数量及其名称。返回的结果表中的每行数据应该按照 `sell_date` **升序**排列，产品名称列表中的名称应按**字典序升序**排列，用逗号 `,` 分隔。

**示例：**

Activities 表：

| sell_date | product |
|-----------|---------|
| 2020-05-30 | Headphone |
| 2020-06-01 | Pencil |
| 2020-06-02 | Mask |
| 2020-05-30 | Basketball |
| 2020-06-01 | Bible |
| 2020-06-02 | Mask |
| 2020-05-30 | T-Shirt |

输出结果表：

| sell_date | num_sold | products |
|-----------|----------|---------|
| 2020-05-30 | 3 | Basketball,Headphone,T-Shirt |
| 2020-06-01 | 2 | Bible,Pencil |
| 2020-06-02 | 1 | Mask |

**提示：**
- Activities 表中的产品名称不含有任何特殊字符。

---

## 解题思路

**核心技术：**
1. 对每个日期，统计**不同产品**的数量（去重）。
2. 对每个日期，将所有不同产品按字典序拼接成字符串（逗号分隔）。
3. 按日期升序排列。

**MySQL 关键函数：**
- `COUNT(DISTINCT product)`：统计不同产品数量。
- `GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',')`：将不同产品按字典序拼接。
- `GROUP BY sell_date`：按日期分组。

---

## SQL 代码实现

### 方法一：GROUP_CONCAT（MySQL，推荐）

```sql
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') AS products
FROM
    Activities
GROUP BY
    sell_date
ORDER BY
    sell_date ASC;
```

### 方法二：STRING_AGG（PostgreSQL / SQL Server）

```sql
-- PostgreSQL 版本
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    STRING_AGG(DISTINCT product, ',' ORDER BY product) AS products
FROM
    Activities
GROUP BY
    sell_date
ORDER BY
    sell_date ASC;
```

### 方法三：先去重再聚合（两步法，兼容性更好）

```sql
-- 先对 (sell_date, product) 去重，再聚合
WITH deduplicated AS (
    SELECT DISTINCT sell_date, product
    FROM Activities
)
SELECT
    sell_date,
    COUNT(product) AS num_sold,
    GROUP_CONCAT(product ORDER BY product SEPARATOR ',') AS products
FROM
    deduplicated
GROUP BY
    sell_date
ORDER BY
    sell_date ASC;
```

## 关键点总结

1. `GROUP_CONCAT(DISTINCT ... ORDER BY ... SEPARATOR ',')` 是 MySQL 中将多行拼接成字符串的标准方法。
2. `DISTINCT` 关键字确保同一天同一产品只计算一次。
3. `ORDER BY product` 在 `GROUP_CONCAT` 内部指定拼接顺序（字典序）。
4. 最外层 `ORDER BY sell_date` 保证结果按日期升序。

---

## 易错点

- **去重是必须的**：同一天同一产品可能出现多次，需要用 `DISTINCT`，否则数量和列表都会重复。
- **`GROUP_CONCAT` 中 ORDER BY 的作用**：这里的 `ORDER BY product` 是对拼接顺序排序，与外层 `ORDER BY` 无关。
- **不同数据库的函数差异**：MySQL 用 `GROUP_CONCAT`，PostgreSQL 用 `STRING_AGG`，SQL Server 用 `STRING_AGG`（较新版本）。
