## 题目描述

表：`Sessions`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| session_start | datetime|
| session_end   | datetime|
| session_id    | int     |
| session_type  | enum    |
+---------------+---------+
```

`session_id` 是主键，`session_type` 为 'Viewer' 或 'Streamer'。

找出所有用户，他们至少有两个同类型的会话，且这两个会话之间的时间差不超过 12 小时。

返回满足条件的 `user_id`，按升序排列。

## SQL 代码实现

### 方法一：自连接（推荐）

```sql
SELECT DISTINCT s1.user_id
FROM Sessions s1
JOIN Sessions s2
    ON s1.user_id = s2.user_id
    AND s1.session_type = s2.session_type
    AND s1.session_id < s2.session_id
    AND TIMESTAMPDIFF(HOUR, s1.session_start, s2.session_start) <= 12
ORDER BY s1.user_id;
```

### 方法二：LAG 窗口函数

```sql
WITH ranked AS (
    SELECT
        user_id,
        session_type,
        session_start,
        LAG(session_start) OVER (PARTITION BY user_id, session_type ORDER BY session_start) AS prev_start
    FROM Sessions
)
SELECT DISTINCT user_id
FROM ranked
WHERE TIMESTAMPDIFF(HOUR, prev_start, session_start) <= 12
ORDER BY user_id;
```

## 复杂度分析

- 时间复杂度：O(n^2) 自连接，O(n log n) 窗口函数
- 空间复杂度：O(n)

## 关键点总结

1. 同类型会话：`session_type` 相同
2. 时间差：`TIMESTAMPDIFF(HOUR, start1, start2) <= 12`
3. LAG 获取同用户同类型的上一个会话时间

## 易错点

1. 注意时间差是会话**开始时间**之间的差
2. `<= 12` 小时（不是严格小于）
