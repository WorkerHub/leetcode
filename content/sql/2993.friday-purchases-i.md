## 题目描述

本题为数据库题目。

给定表 `Purchases`：
```
+---------------+----------+
| Column Name   | Type     |
+---------------+----------+
| user_id       | int      |
| purchase_date | date     |
| amount_spend  | decimal  |
+---------------+----------+
```

找出 2023 年 11 月每个周五的购买总金额。若某周五无购买记录，不需要显示该日期。

按日期升序返回。

## SQL 代码实现

### 方法一：直接过滤（推荐）

```sql
SELECT
    purchase_date,
    SUM(amount_spend) AS total_amount
FROM Purchases
WHERE YEAR(purchase_date) = 2023
  AND MONTH(purchase_date) = 11
  AND DAYOFWEEK(purchase_date) = 6  -- 6 代表周五（1=周日，2=周一，...，6=周五，7=周六）
GROUP BY purchase_date
ORDER BY purchase_date;
```

### 方法二：使用 WEEKDAY 函数

```sql
SELECT
    purchase_date,
    SUM(amount_spend) AS total_amount
FROM Purchases
WHERE purchase_date BETWEEN '2023-11-01' AND '2023-11-30'
  AND WEEKDAY(purchase_date) = 4  -- WEEKDAY: 0=周一, 4=周五
GROUP BY purchase_date
ORDER BY purchase_date;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为周五天数

## 关键点总结

1. DAYOFWEEK：1=周日，2=周一，...，6=周五，7=周六
2. WEEKDAY：0=周一，1=周二，...，4=周五，5=周六，6=周日
3. 只统计 2023 年 11 月的周五

## 易错点

1. DAYOFWEEK 和 WEEKDAY 的周几编号不同，容易混淆
2. 只取 11 月（不是整年）
3. 若某周五无购买则不显示（不需要补 0）
