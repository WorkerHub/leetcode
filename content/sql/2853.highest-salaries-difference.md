## 题目描述

**表：Salaries**

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_name    | varchar |
| department  | varchar |
| salary      | int     |
+-------------+---------+
(emp_name, department) 是主键。
```

找到工程（Engineering）部门和营销（Marketing）部门中最高薪酬的差值（绝对差）。

**示例：**
```
输入：
Salaries 表：
+--------+-------------+--------+
|emp_name| department  | salary |
+--------+-------------+--------+
| Kathy  | Engineering | 50000  |
| Roy    | Engineering | 55000  |
| Charles| Engineering | 45000  |
| John   | Marketing   | 53000  |
| Jack   | Marketing   | 62000  |
| Robert | Marketing   | 45000  |
+--------+-------------+--------+

输出：
+-----+
| difference |
+-----+
| 7000 |
+-----+
解释：
Engineering 最高薪酬：55000（Roy）
Marketing 最高薪酬：62000（Jack）
差值 = |55000 - 62000| = 7000
```

## 解题思路

1. 从 Salaries 表中分别获取 Engineering 和 Marketing 部门的最高薪酬
2. 计算两者的绝对差

## 代码实现

### SQL 解法

```sql
SELECT ABS(
    (SELECT MAX(salary) FROM Salaries WHERE department = 'Engineering') -
    (SELECT MAX(salary) FROM Salaries WHERE department = 'Marketing')
) AS difference;
```

### SQL 方法二（使用 CTE）

```sql
WITH dept_max AS (
    SELECT department, MAX(salary) AS max_salary
    FROM Salaries
    WHERE department IN ('Engineering', 'Marketing')
    GROUP BY department
)
SELECT ABS(
    MAX(CASE WHEN department = 'Engineering' THEN max_salary END) -
    MAX(CASE WHEN department = 'Marketing' THEN max_salary END)
) AS difference
FROM dept_max;
```

## 复杂度分析

- 时间复杂度：O(n)，扫描表格
- 空间复杂度：O(1)

## 关键点总结

1. 分别获取两个部门的最高薪酬
2. 取绝对差 `ABS()`
3. SQL 子查询或 GROUP BY + CASE WHEN 均可实现

## 易错点

1. 记得用 `ABS()` 取绝对差，防止结果为负
2. 部门名称大小写要与数据一致（'Engineering', 'Marketing'）
