## 题目描述

表：`ParkingTransactions`

```
+--------------+----------+
| Column Name  | Type     |
+--------------+----------+
| lot_id       | int      |
| car_id       | int      |
| entry_time   | datetime |
| exit_time    | datetime |
| fee_paid     | decimal  |
+--------------+----------+
```

`(lot_id, car_id, entry_time)` 是主键。

编写一个解决方案，计算每辆车在所有停车场停放的 **总费用**、**总停车时长**（小时，保留两位小数）以及 **停放时间最长的停车场**（若多个相同，取 lot_id 最小的）。

输出按 `car_id` 升序排列。

## 解题思路

1. 对每辆车汇总总费用和总时长
2. 找每辆车停放最久的停车场（用窗口函数排名）

## 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH car_lot AS (
    SELECT
        car_id,
        lot_id,
        SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) / 3600 AS lot_hours
    FROM ParkingTransactions
    GROUP BY car_id, lot_id
),
ranked AS (
    SELECT
        car_id,
        lot_id,
        lot_hours,
        RANK() OVER (PARTITION BY car_id ORDER BY lot_hours DESC, lot_id ASC) AS rk
    FROM car_lot
),
totals AS (
    SELECT
        car_id,
        SUM(fee_paid) AS total_fee_paid,
        ROUND(SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) / 3600, 2) AS total_duration
    FROM ParkingTransactions
    GROUP BY car_id
)
SELECT
    t.car_id,
    t.total_fee_paid,
    t.total_duration,
    r.lot_id AS most_time_lot
FROM totals t
JOIN ranked r ON t.car_id = r.car_id AND r.rk = 1
ORDER BY t.car_id;
```

### 方法二：子查询

```sql
SELECT
    car_id,
    SUM(fee_paid) AS total_fee_paid,
    ROUND(SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) / 3600, 2) AS total_duration,
    (
        SELECT lot_id
        FROM ParkingTransactions p2
        WHERE p2.car_id = p1.car_id
        GROUP BY lot_id
        ORDER BY SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) DESC, lot_id ASC
        LIMIT 1
    ) AS most_time_lot
FROM ParkingTransactions p1
GROUP BY car_id
ORDER BY car_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按 car_id, lot_id 分组统计各停车场时长
2. 用 RANK() 找时长最长的停车场（相同时取 lot_id 最小）
3. 总费用和总时长分别聚合

## 易错点

1. 停车场时长需要按 car_id, lot_id 分组后再排名
2. 总时长保留两位小数
