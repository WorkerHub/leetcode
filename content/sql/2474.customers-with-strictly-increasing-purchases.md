## 题目描述

表：`Orders`

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| order_id     | int  |
| customer_id  | int  |
| order_date   | date |
| price        | int  |
+--------------+------+
```

`order_id` 是该表的主键。每一行包含订单 ID、客户 ID、订单日期和价格。

编写 SQL 语句，找出每年都有订单且每年订单总价格 **严格递增** 的客户的 `customer_id`。

按任意顺序返回结果。

**示例 1：**
```
输入：
Orders 表：
+----------+-------------+------------+-------+
| order_id | customer_id | order_date | price |
+----------+-------------+------------+-------+
| 1        | 1           | 2019-07-01 | 1100  |
| 2        | 1           | 2019-11-01 | 1200  |
| 3        | 1           | 2020-05-26 | 3000  |
| 4        | 1           | 2021-08-31 | 3200  |
| 5        | 1           | 2021-12-07 | 4500  |
| 6        | 2           | 2018-12-01 | 4800  |
| 7        | 2           | 2019-12-01 | 4800  |
| 8        | 3           | 2019-01-01 | 4800  |
| 9        | 3           | 2021-01-01 | 4800  |
+----------+-------------+------------+-------+
输出：
+-------------+
| customer_id |
+-------------+
| 1           |
+-------------+
解释：
- 客户 1：2019 年总价 2300，2020 年总价 3000，2021 年总价 7700，严格递增。
- 客户 2：2018 年和 2019 年均为 4800，不递增。
- 客户 3：2019 年 4800，跳过 2020 年（无数据），2021 年 4800，不满足条件（跳年也算失败）。
```

## 解题思路

1. 按客户和年份分组，计算每年的总价格
2. 对每个客户，检查其年份是否连续（无间断）且价格严格递增
3. 通过自连接或窗口函数，比较每年与前一年的价格

**关键条件：**
- 年份必须连续（不能有跳年）
- 每年价格严格大于前一年

## 代码实现

### 方法一：使用窗口函数

```sql
WITH YearlyTotals AS (
    -- 按客户和年份分组，计算每年总价格
    SELECT
        customer_id,
        YEAR(order_date) AS yr,
        SUM(price) AS total_price
    FROM Orders
    GROUP BY customer_id, YEAR(order_date)
),
RankedYears AS (
    -- 对每个客户按年份排序，计算行号
    SELECT
        customer_id,
        yr,
        total_price,
        ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY yr) AS rn,
        LAG(total_price) OVER (PARTITION BY customer_id ORDER BY yr) AS prev_price,
        LAG(yr) OVER (PARTITION BY customer_id ORDER BY yr) AS prev_yr
    FROM YearlyTotals
),
ValidationCheck AS (
    -- 检查年份连续性和价格递增性
    SELECT
        customer_id,
        CASE
            WHEN prev_yr IS NULL THEN 1  -- 第一年，视为有效
            WHEN yr = prev_yr + 1 AND total_price > prev_price THEN 1  -- 连续且递增
            ELSE 0
        END AS is_valid
    FROM RankedYears
)
SELECT DISTINCT customer_id
FROM ValidationCheck
GROUP BY customer_id
HAVING MIN(is_valid) = 1
ORDER BY customer_id;
```

### 方法二：自连接法

```sql
WITH YearlyTotals AS (
    SELECT
        customer_id,
        YEAR(order_date) AS yr,
        SUM(price) AS total_price
    FROM Orders
    GROUP BY customer_id, YEAR(order_date)
)
SELECT DISTINCT a.customer_id
FROM YearlyTotals a
WHERE NOT EXISTS (
    -- 不存在某一年：前一年不存在，或价格不递增，或年份不连续
    SELECT 1
    FROM YearlyTotals b
    WHERE b.customer_id = a.customer_id
      AND b.yr > (SELECT MIN(yr) FROM YearlyTotals WHERE customer_id = a.customer_id)
      AND (
        -- 前一年不存在（年份间断）
        NOT EXISTS (
            SELECT 1 FROM YearlyTotals c
            WHERE c.customer_id = a.customer_id AND c.yr = b.yr - 1
        )
        -- 或价格不严格递增
        OR b.total_price <= (
            SELECT total_price FROM YearlyTotals c
            WHERE c.customer_id = a.customer_id AND c.yr = b.yr - 1
        )
      )
)
ORDER BY customer_id;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| 窗口函数 | 利用 LAG 函数比较相邻行，逻辑清晰 |
| 自连接 | 通过 EXISTS 子查询验证，适合复杂条件 |

## 关键点总结

1. 先按客户和年份聚合，计算每年总价格
2. 用 LAG 窗口函数获取前一年的数据进行比较
3. 年份连续 + 价格严格递增，两个条件都要满足
4. 只有第一年（无前年）的条件不需要检查

## 易错点

- 年份必须连续（无跳年），不只是价格递增
- 需要检查「不存在某一年只有一条记录」与「存在多年但不严格递增」的情况
