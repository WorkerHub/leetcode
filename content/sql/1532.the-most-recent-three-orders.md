## 题目描述

表 `Customers`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| customer_id   | int     |
| name          | varchar |
+---------------+---------+
```

表 `Orders`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| order_date    | date    |
| customer_id   | int     |
| cost          | int     |
+---------------+---------+
```

查询每位顾客的**最近 3 笔订单**。若顾客订单不足 3 笔，则全部返回。结果按 `customer_id` 升序，相同则按 `order_date` 降序。

## 解题思路

### 窗口函数 ROW_NUMBER

使用窗口函数 `ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date DESC)` 对每个顾客的订单按日期倒序编号，然后筛选编号 <= 3 的记录。

## 代码实现

### 方法一：ROW_NUMBER 窗口函数（推荐）

```sql
-- 使用窗口函数为每个顾客的订单按日期倒序编号
WITH ranked AS (
    SELECT
        o.order_id,
        o.order_date,
        o.customer_id,
        o.cost,
        ROW_NUMBER() OVER (
            PARTITION BY o.customer_id
            ORDER BY o.order_date DESC
        ) AS rn
    FROM Orders o
)
-- 取每个顾客的最近 3 笔订单
SELECT
    c.name AS customer_name,
    r.customer_id,
    r.order_id,
    r.order_date
FROM ranked r
JOIN Customers c ON r.customer_id = c.customer_id
WHERE r.rn <= 3
ORDER BY r.customer_id ASC, r.order_date DESC;
```

### 方法二：子查询过滤

```sql
-- 对每笔订单，统计同顾客有多少笔订单比它更新（日期更晚）
SELECT
    c.name AS customer_name,
    o1.customer_id,
    o1.order_id,
    o1.order_date
FROM Orders o1
JOIN Customers c ON o1.customer_id = c.customer_id
WHERE (
    -- 统计比 o1 更晚（或相同日期且 order_id 更大）的订单数
    SELECT COUNT(*)
    FROM Orders o2
    WHERE o2.customer_id = o1.customer_id
      AND o2.order_date >= o1.order_date
      AND o2.order_id >= o1.order_id
) <= 3
ORDER BY o1.customer_id ASC, o1.order_date DESC;
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为 Orders 表行数（窗口函数内部排序）
- **空间复杂度**：O(N)

## 关键点总结

1. `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ... DESC)` 对每个分组排名
2. 取最近 3 笔：`WHERE rn <= 3`
3. 结果排序：`ORDER BY customer_id ASC, order_date DESC`

## 易错点

- 使用 `ROW_NUMBER` 而不是 `RANK`：即使日期相同，也只取3行
- 最终排序要同时按两列排序（customer_id 升序，order_date 降序）
