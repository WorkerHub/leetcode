## 题目描述

表 `Visits`：`visit_id`, `customer_id`

表 `Transactions`：`transaction_id`, `visit_id`, `amount`

查询那些**访问了购物中心但没有进行任何交易的顾客**，以及他们访问的次数（仅统计无交易的访问）。

## 解题思路

### LEFT JOIN + IS NULL 或 NOT IN

找出 visit_id 在 Transactions 中不存在的访问记录，按顾客分组统计次数。

## 代码实现

### 方法一：LEFT JOIN + IS NULL（推荐）

```sql
-- 左连接后筛选无对应交易的访问
SELECT
    v.customer_id,
    COUNT(v.visit_id) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t ON v.visit_id = t.visit_id
WHERE t.transaction_id IS NULL
GROUP BY v.customer_id;
```

### 方法二：NOT IN 子查询

```sql
-- visit_id 不在 Transactions 中的访问
SELECT
    customer_id,
    COUNT(*) AS count_no_trans
FROM Visits
WHERE visit_id NOT IN (SELECT DISTINCT visit_id FROM Transactions)
GROUP BY customer_id;
```

### 方法三：NOT EXISTS

```sql
-- 使用 NOT EXISTS 相关子查询
SELECT
    v.customer_id,
    COUNT(*) AS count_no_trans
FROM Visits v
WHERE NOT EXISTS (
    SELECT 1 FROM Transactions t WHERE t.visit_id = v.visit_id
)
GROUP BY v.customer_id;
```

## 复杂度分析

- **时间复杂度**：O(N + M)，N = Visits 行数，M = Transactions 行数
- **空间复杂度**：O(K)，K 为不同顾客数

## 关键点总结

1. 需要找"有 visit 但无 transaction"的访问
2. LEFT JOIN 后 `t.transaction_id IS NULL` 表示无对应交易
3. 按 `customer_id` 分组，统计无交易访问次数

## 易错点

- 是统计无交易的**访问次数**（不是顾客数）
- 同一顾客可能多次无交易访问，都要计入
