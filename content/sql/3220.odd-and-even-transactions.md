## 题目描述

表：`transactions`

```
+------------------+------+
| Column Name      | Type |
+------------------+------+
| transaction_id   | int  |
| amount           | int  |
| transaction_date | date |
+------------------+------+
```

`transaction_id` 是该表的主键。

编写一个 SQL 查询，找出每天奇数金额交易的总和与偶数金额交易的总和。

结果表包含：
- `transaction_date`
- `odd_sum`：该日奇数金额交易总和
- `even_sum`：该日偶数金额交易总和

按 `transaction_date` 升序排列。

**示例：**

输入：
```
+----------------+--------+------------------+
| transaction_id | amount | transaction_date |
+----------------+--------+------------------+
| 1              | 150    | 2024-07-01       |
| 2              | 200    | 2024-07-01       |
| 3              | 75     | 2024-07-01       |
| 4              | 100    | 2024-07-02       |
| 5              | 150    | 2024-07-02       |
| 6              | 50     | 2024-07-03       |
+----------------+--------+------------------+
```

输出：
```
+------------------+---------+----------+
| transaction_date | odd_sum | even_sum |
+------------------+---------+----------+
| 2024-07-01       | 225     | 200      |
| 2024-07-02       | 150     | 100      |
| 2024-07-03       | 0       | 50       |
+------------------+---------+----------+
```

## 解题思路

按日期分组，使用条件聚合：
- `SUM(CASE WHEN amount % 2 != 0 THEN amount ELSE 0 END)` 计算奇数总和
- `SUM(CASE WHEN amount % 2 = 0 THEN amount ELSE 0 END)` 计算偶数总和

## 代码实现

```sql
SELECT
    transaction_date,
    SUM(CASE WHEN amount % 2 != 0 THEN amount ELSE 0 END) AS odd_sum,
    SUM(CASE WHEN amount % 2 = 0 THEN amount ELSE 0 END) AS even_sum
FROM transactions
GROUP BY transaction_date
ORDER BY transaction_date;
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组和排序
- 空间复杂度：O(n)

## 关键点总结

1. 使用条件聚合 `SUM(CASE WHEN ... THEN ... ELSE 0 END)` 分别统计
2. `amount % 2 != 0` 判断奇数，`amount % 2 = 0` 判断偶数
3. 按日期分组并升序排列

## 易错点

1. 没有奇数或偶数交易的日期，对应总和应为 0（ELSE 0 保证）
2. 注意 ORDER BY 按升序排列
