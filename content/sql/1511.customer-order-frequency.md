## 题目描述

表 `Customers`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| customer_id   | int     |
| name          | varchar |
| country       | varchar |
+---------------+---------+
```

表 `Product`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| description   | varchar |
| price         | int     |
+---------------+---------+
```

表 `Orders`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| customer_id   | int     |
| product_id    | int     |
| order_date    | date    |
| quantity      | int     |
+---------------+---------+
```

找出在 2020 年 6 月和 7 月都订购了 **至少 $100** 产品的客户的 `customer_id` 和 `name`。

## 解题思路

### 方法一：JOIN + HAVING + 条件聚合

1. 关联 Orders 和 Product 获得每笔订单金额
2. 按客户分组，分别统计 6 月和 7 月的消费总额
3. 筛选两个月均 >= 100 的客户

## 代码实现

### 方法一：HAVING + 条件聚合（推荐）

```sql
-- 关联订单和产品，计算每笔订单金额，按客户分组统计
SELECT c.customer_id, c.name
FROM Customers c
JOIN Orders o ON c.customer_id = o.customer_id
JOIN Product p ON o.product_id = p.product_id
GROUP BY c.customer_id, c.name
HAVING
    -- 6 月总消费 >= 100
    SUM(IF(DATE_FORMAT(o.order_date, '%Y-%m') = '2020-06', o.quantity * p.price, 0)) >= 100
    AND
    -- 7 月总消费 >= 100
    SUM(IF(DATE_FORMAT(o.order_date, '%Y-%m') = '2020-07', o.quantity * p.price, 0)) >= 100;
```

### 方法二：子查询分别过滤后 INNER JOIN

```sql
-- 先分别找出6月和7月消费 >= 100 的客户，再取交集
WITH june AS (
    SELECT o.customer_id
    FROM Orders o
    JOIN Product p ON o.product_id = p.product_id
    WHERE DATE_FORMAT(o.order_date, '%Y-%m') = '2020-06'
    GROUP BY o.customer_id
    HAVING SUM(o.quantity * p.price) >= 100
),
july AS (
    SELECT o.customer_id
    FROM Orders o
    JOIN Product p ON o.product_id = p.product_id
    WHERE DATE_FORMAT(o.order_date, '%Y-%m') = '2020-07'
    GROUP BY o.customer_id
    HAVING SUM(o.quantity * p.price) >= 100
)
SELECT c.customer_id, c.name
FROM Customers c
WHERE c.customer_id IN (SELECT customer_id FROM june)
  AND c.customer_id IN (SELECT customer_id FROM july);
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为 Orders 表行数，主要来自分组排序
- **空间复杂度**：O(K)，K 为不同客户数

## 关键点总结

1. 用 `SUM(IF(条件, 金额, 0))` 在同一个 GROUP BY 中同时统计多个月份
2. 订单金额 = `quantity * price`，需要 JOIN Product 表
3. 日期过滤用 `DATE_FORMAT(order_date, '%Y-%m')` 或 `YEAR()` + `MONTH()`

## 易错点

- 忘记金额 = `quantity * price`（不是直接用 price）
- 条件是"6月和7月**都**满足"，用 AND 而非 OR
