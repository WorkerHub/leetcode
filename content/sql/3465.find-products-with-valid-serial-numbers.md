## 题目描述

表 `products`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| product_name| varchar |
| description | varchar |
+-------------+---------+
```

找出 `description` 中包含**有效序列号**的产品。

有效序列号格式：以 `SNxxx-yyy` 形式出现，其中 `xxx` 是恰好 3 位数字，`yyy` 是恰好 3 位字母。（即 `SN[0-9]{3}-[A-Za-z]{3}`）

按 `product_id` 升序返回。

**示例：**

输入：
```
+------------+--------------+------------------------+
| product_id | product_name | description            |
+------------+--------------+------------------------+
| 1          | Widget A     | SN123-ABC is valid     |
| 2          | Widget B     | SN12-AB is invalid     |
| 3          | Widget C     | No serial number       |
| 4          | Widget D     | Code SN456-xyz here    |
+------------+--------------+------------------------+
```

输出：
```
+------------+--------------+
| product_id | product_name |
+------------+--------------+
| 1          | Widget A     |
| 4          | Widget D     |
+------------+--------------+
```

## 解题思路

使用正则表达式匹配 `SN[0-9]{3}-[A-Za-z]{3}` 模式。

注意：序列号是 description 中的子字符串，不需要从头到尾匹配。

## SQL 代码实现

### 方法一：REGEXP（MySQL，推荐）

```sql
SELECT product_id, product_name
FROM products
WHERE description REGEXP 'SN[0-9]{3}-[A-Za-z]{3}'
ORDER BY product_id;
```

### 方法二：REGEXP_LIKE（MySQL 8.0+）

```sql
SELECT product_id, product_name
FROM products
WHERE REGEXP_LIKE(description, 'SN[0-9]{3}-[A-Za-z]{3}')
ORDER BY product_id;
```

### 方法三：更严格的匹配（确保序列号边界）

```sql
SELECT product_id, product_name
FROM products
WHERE description REGEXP '(^|[^A-Za-z0-9])SN[0-9]{3}-[A-Za-z]{3}([^A-Za-z0-9]|$)'
ORDER BY product_id;
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为行数，L 为 description 平均长度
- 空间复杂度：O(1)

## 关键点总结

1. 正则 `SN[0-9]{3}-[A-Za-z]{3}` 精确匹配序列号格式
2. 不需要锚定 `^` 和 `$`（序列号是 description 的子串）
3. `[A-Za-z]` 匹配大小写字母

## 易错点

1. `{3}` 要求恰好 3 个，不是至少 3 个
2. 字母部分可能大写或小写，用 `[A-Za-z]` 或加 `i` 标志
3. 如果要求边界（不在更长的单词中间），需要额外的边界检查
