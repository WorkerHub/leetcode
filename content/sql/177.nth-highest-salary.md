## 题目描述

表：`Employee`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
```

id 是这个表的主键。
表的每一行包含员工的工资信息。

编写一个 SQL 查询来报告 `Employee` 表中第 `n` 高的工资。如果没有第 `n` 高的工资，查询应该报告为 `null`。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
n = 2

输出：
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| 200                    |
+------------------------+
```

**示例 2：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
n = 2

输出：
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| null                   |
+------------------------+
```

## 解题思路

这是第 176 题的扩展版本，需要找出第 N 高的薪水。关键挑战：

1. **动态 OFFSET**：需要根据参数 N 计算 OFFSET 值
2. **边界处理**：N 可能为 0、负数、超过记录数
3. **去重问题**：相同薪水只算一次

核心思路：
- 使用函数/存储过程接收参数 N
- 计算 `OFFSET = N - 1`
- 使用 `DISTINCT` 去重后按降序排列
- 使用 `LIMIT 1 OFFSET N-1` 获取第 N 高的值

## SQL 代码实现

### 方法一：LIMIT + OFFSET（推荐）

```sql
CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    -- 声明变量存储 OFFSET 值
    DECLARE M INT;
    SET M = N - 1;
    
    RETURN (
        -- 如果 N <= 0，直接返回 NULL
        SELECT DISTINCT salary
        FROM Employee
        ORDER BY salary DESC
        LIMIT 1 OFFSET M
    );
END
```

**代码解释：**
1. `DECLARE M INT` 声明变量 M 用于存储偏移量
2. `SET M = N - 1` 计算偏移量（第 N 高需要跳过 N-1 条）
3. `SELECT DISTINCT salary` 去重获取薪水
4. `ORDER BY salary DESC` 降序排列
5. `LIMIT 1 OFFSET M` 取第 N 个值
6. MySQL 自动处理 OFFSET 超出范围的情况，返回 NULL

### 方法二：使用窗口函数 DENSE_RANK

```sql
CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    RETURN (
        SELECT DISTINCT salary
        FROM (
            SELECT salary,
                   DENSE_RANK() OVER (ORDER BY salary DESC) AS rk
            FROM Employee
        ) AS ranked
        WHERE rk = N
    );
END
```

**代码解释：**
1. `DENSE_RANK()` 为每个不同薪水分配排名（相同薪水排名相同，无间隙）
2. `WHERE rk = N` 筛选排名为 N 的记录
3. `DISTINCT` 去重（虽然 DENSE_RANK 已经处理，但保险起见）
4. 如果不存在排名为 N 的记录，自动返回 NULL

### 方法三：子查询计数

```sql
CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    RETURN (
        SELECT DISTINCT e1.salary
        FROM Employee e1
        WHERE N - 1 = (
            SELECT COUNT(DISTINCT e2.salary)
            FROM Employee e2
            WHERE e2.salary > e1.salary
        )
    );
END
```

**代码解释：**
1. 对于每个薪水 `e1.salary`，统计比它高的不同薪水个数
2. 如果个数等于 `N - 1`，说明这是第 N 高的薪水
3. 例如：第 3 高的薪水，前面应该有 2 个不同的更高薪水

### 方法四：变量 + 排序（无窗口函数版本）

```sql
CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    RETURN (
        SELECT MAX(salary)
        FROM (
            SELECT salary, 
                   @row_num := @row_num + 1 AS row_num
            FROM (SELECT DISTINCT salary FROM Employee ORDER BY salary DESC) AS distinct_salaries,
                 (SELECT @row_num := 0) AS init
        ) AS ranked
        WHERE row_num = N
    );
END
```

**代码解释：**
1. 先用子查询获取去重并降序的薪水列表
2. 使用用户变量 `@row_num` 模拟行号
3. 筛选行号为 N 的记录
4. 使用 `MAX()` 确保返回单个值或 NULL

## 复杂度分析

**方法一（LIMIT + OFFSET）：**
- 时间复杂度：O(n log n)，排序开销
- 空间复杂度：O(n)，去重需要额外空间
- 优点：代码简洁，性能优秀

**方法二（DENSE_RANK）：**
- 时间复杂度：O(n log n)，窗口函数需要排序
- 空间复杂度：O(n)，存储排名
- 优点：逻辑清晰，易于扩展到更复杂场景

**方法三（子查询计数）：**
- 时间复杂度：O(n²)，每行都需要全表扫描统计
- 空间复杂度：O(1)
- 缺点：性能较差，不推荐用于大数据集

**方法四（变量）：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)
- 注意：用户变量在新版 MySQL 中可能有兼容性问题

## 关键点总结

1. **计算偏移量**：第 N 高对应 `OFFSET N-1`，必须先计算好再使用
2. **变量声明**：MySQL 函数中使用变量需要 `DECLARE` 和 `SET`
3. **去重关键**：`DISTINCT` 确保相同薪水只计算一次
4. **自动返回 NULL**：LIMIT OFFSET 超出范围时，MySQL 自动返回 NULL
5. **推荐方法**：方法一最简洁高效，方法二在复杂场景下更灵活

## 易错点

1. **直接在 OFFSET 中使用 N-1**
   ```sql
   -- 错误：MySQL 不允许在 OFFSET 中直接使用表达式
   LIMIT 1 OFFSET N-1  -- 语法错误
   
   -- 正确：必须先计算
   SET M = N - 1;
   LIMIT 1 OFFSET M
   ```

2. **忘记处理 N <= 0 的情况**
   ```sql
   -- 虽然 LIMIT OFFSET 会自动返回 NULL，但最好添加判断
   IF N <= 0 THEN
       RETURN NULL;
   END IF;
   ```

3. **RANK vs DENSE_RANK**
   ```sql
   -- 错误：RANK() 会产生间隙
   -- 例如：100, 100, 90 排名为 1, 1, 3（跳过 2）
   RANK() OVER (ORDER BY salary DESC)
   
   -- 正确：DENSE_RANK() 无间隙
   -- 例如：100, 100, 90 排名为 1, 1, 2
   DENSE_RANK() OVER (ORDER BY salary DESC)
   ```

4. **返回类型错误**
   ```sql
   -- 题目要求返回 INT，确保函数声明正确
   CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
   ```

5. **多行结果处理**
   ```sql
   -- 错误：如果有多个相同第 N 高薪水，需要用 DISTINCT
   SELECT salary  -- 可能返回多行
   
   -- 正确：
   SELECT DISTINCT salary  -- 确保返回单行
   ```
