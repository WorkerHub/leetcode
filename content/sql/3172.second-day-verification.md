## 题目描述

表：`emails`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| email_id    | int     |
| user_id     | int     |
| signup_date | date    |
+-------------+---------+
```

`email_id` 是主键。

表：`texts`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| text_id       | int     |
| email_id      | int     |
| signup_action | varchar |
| action_date   | date    |
+---------------+---------+
```

`text_id` 是主键。`signup_action` 为 `'Verified'` 或 `'Not Verified'`。

找出注册的第 **第二天** 完成验证的用户 ID。

返回按 `user_id` 升序排列的结果。

## 解题思路

联接两张表，筛选出 `action_date = signup_date + 1` 且 `signup_action = 'Verified'` 的用户。

## 代码实现

### 方法一：DATE_ADD（推荐）

```sql
SELECT DISTINCT e.user_id
FROM emails e
JOIN texts t ON e.email_id = t.email_id
WHERE t.signup_action = 'Verified'
  AND t.action_date = DATE_ADD(e.signup_date, INTERVAL 1 DAY)
ORDER BY e.user_id;
```

### 方法二：DATEDIFF

```sql
SELECT DISTINCT e.user_id
FROM emails e
JOIN texts t ON e.email_id = t.email_id
WHERE t.signup_action = 'Verified'
  AND DATEDIFF(t.action_date, e.signup_date) = 1
ORDER BY e.user_id;
```

## 复杂度分析

- 时间复杂度：O(n * m)（联接），加索引后 O(n + m)
- 空间复杂度：O(n)

## 关键点总结

1. 第二天 = signup_date + 1 天
2. 需要同时满足 action = 'Verified' 和日期条件
3. 用 DATE_ADD 或 DATEDIFF 计算日期差

## 易错点

1. 第二天是 +1 天，不是 +2 天
2. 可能存在多次验证，用 DISTINCT 去重
