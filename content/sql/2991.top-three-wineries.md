## 题目描述

本题为数据库题目。

给定表 `Wineries`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| country     | varchar |
| points      | int     |
| winery      | varchar |
+-------------+---------+
```

找出每个国家积分总和前三名的酒庄。若不足三名，则填充 "No second winery" 或 "No third winery"。

## SQL 代码实现

### 方法一：窗口函数（推荐）

```sql
WITH winery_scores AS (
    SELECT
        country,
        winery,
        SUM(points) AS total_points
    FROM Wineries
    GROUP BY country, winery
),
ranked AS (
    SELECT
        country,
        winery,
        total_points,
        RANK() OVER (PARTITION BY country ORDER BY total_points DESC, winery ASC) AS rnk
    FROM winery_scores
)
SELECT
    country,
    MAX(CASE WHEN rnk = 1 THEN CONCAT(winery, ' (', total_points, ')') END) AS top_winery,
    COALESCE(MAX(CASE WHEN rnk = 2 THEN CONCAT(winery, ' (', total_points, ')') END), 'No second winery') AS second_winery,
    COALESCE(MAX(CASE WHEN rnk = 3 THEN CONCAT(winery, ' (', total_points, ')') END), 'No third winery') AS third_winery
FROM ranked
WHERE rnk <= 3
GROUP BY country
ORDER BY country;
```

### 方法二：多次 JOIN

```sql
WITH scores AS (
    SELECT country, winery, SUM(points) AS pts
    FROM Wineries GROUP BY country, winery
),
r AS (
    SELECT *, RANK() OVER (PARTITION BY country ORDER BY pts DESC, winery) AS rnk FROM scores
)
SELECT
    r1.country,
    CONCAT(r1.winery, ' (', r1.pts, ')') AS top_winery,
    COALESCE(CONCAT(r2.winery, ' (', r2.pts, ')'), 'No second winery') AS second_winery,
    COALESCE(CONCAT(r3.winery, ' (', r3.pts, ')'), 'No third winery') AS third_winery
FROM (SELECT * FROM r WHERE rnk = 1) r1
LEFT JOIN (SELECT * FROM r WHERE rnk = 2) r2 USING (country)
LEFT JOIN (SELECT * FROM r WHERE rnk = 3) r3 USING (country)
ORDER BY r1.country;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按国家和酒庄分组求积分总和
2. 用 RANK() 找每国前三名
3. COALESCE 处理不足三名的情况
4. 输出格式：`winery (total_points)`

## 易错点

1. 若积分并列，按酒庄名字母序排
2. 不足三名时填充固定字符串而不是 NULL
3. 每个 country 的第一名必定存在
