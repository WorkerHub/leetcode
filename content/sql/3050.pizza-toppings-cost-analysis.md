## 题目描述

表：`Toppings`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| topping_name| varchar |
| cost        | decimal |
+-------------+---------+
```

`topping_name` 是该表的主键。每行包含配料名称及其成本。

编写查询，找出所有**三种不同配料**的组合，计算它们的总成本，按总成本降序、配料名称字典序升序返回结果。

返回列：`topping_1`，`topping_2`，`topping_3`，`total_cost`（保留两位小数）。

**注意：** 每种组合中 `topping_1 < topping_2 < topping_3`（字典序）。

## 解题思路

使用自连接，三次连接同一张表，枚举所有三元组，用 WHERE 条件保证 `topping_1 < topping_2 < topping_3`。

## SQL 代码实现

### 方法一：自连接三次（推荐）

```sql
SELECT
    t1.topping_name AS topping_1,
    t2.topping_name AS topping_2,
    t3.topping_name AS topping_3,
    ROUND(t1.cost + t2.cost + t3.cost, 2) AS total_cost
FROM Toppings t1
JOIN Toppings t2 ON t1.topping_name < t2.topping_name
JOIN Toppings t3 ON t2.topping_name < t3.topping_name
ORDER BY total_cost DESC, topping_1 ASC, topping_2 ASC, topping_3 ASC;
```

## 复杂度分析

- 时间复杂度：O(n^3)，n 为配料数量
- 空间复杂度：O(n^3)，结果集大小

## 关键点总结

1. 三次自连接枚举所有三元组
2. 使用 `<` 保证唯一性（字典序升序）
3. `ROUND` 函数保留两位小数

## 易错点

1. 排序中总成本降序，但字典序升序（多级排序）
2. 确保三种配料各不相同（通过 `<` 条件保证）
