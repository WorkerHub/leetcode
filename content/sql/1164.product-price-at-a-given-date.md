## 题目描述

写一个 SQL 查询，找出在 `2019-08-16` 所有产品的价格。假设所有产品的初始价格都是 `10`。

表：`Products`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| new_price     | int     |
| change_date   | date    |
+---------------+---------+
```

`(product_id, change_date)` 是这个表的主键。该表的每一行表示某个产品在特定日期的价格变更为新价格。

查询结果格式如下所示：

```
Products 表：
+------------+-----------+-------------+
| product_id | new_price | change_date |
+------------+-----------+-------------+
| 1          | 20        | 2019-08-14  |
| 2          | 50        | 2019-08-14  |
| 1          | 30        | 2019-08-15  |
| 1          | 35        | 2019-08-16  |
| 2          | 65        | 2019-08-17  |
| 3          | 20        | 2019-08-18  |
+------------+-----------+-------------+

Result 表：
+------------+-------+
| product_id | price |
+------------+-------+
| 2          | 50    |
| 1          | 35    |
| 3          | 10    |
+------------+-------+

产品 1 在 2019-08-16 之前有 3 次价格变更，价格为 35。
产品 2 在 2019-08-16 之前有 1 次价格变更，价格为 50。
产品 3 在 2019-08-16 之前没有价格变更，所以价格为 10。
```

## 解题思路

这道题的核心考点是：
1. 找出每个产品在指定日期或之前的最后一次价格变更
2. 处理从未变更过价格的产品（使用默认价格 10）

**解题步骤：**

1. 对于在 2019-08-16 或之前有价格变更的产品，找到最后一次变更的价格
2. 对于从未变更或者第一次变更在 2019-08-16 之后的产品，使用默认价格 10
3. 合并这两部分结果

**关键技巧：**

- 使用窗口函数 `ROW_NUMBER()` 或 `RANK()` 找出最后一次变更
- 或使用子查询 + `MAX(change_date)`
- 使用 `UNION` 合并有变更和无变更的产品

## SQL 代码实现

### 方法一：UNION + 子查询（推荐）

```sql
-- 有价格变更的产品（取最后一次变更）
SELECT 
    product_id,
    new_price AS price
FROM 
    Products
WHERE 
    (product_id, change_date) IN (
        SELECT 
            product_id,
            MAX(change_date) AS change_date
        FROM 
            Products
        WHERE 
            change_date <= '2019-08-16'
        GROUP BY 
            product_id
    )

UNION

-- 没有价格变更的产品（默认价格 10）
SELECT 
    DISTINCT product_id,
    10 AS price
FROM 
    Products
WHERE 
    product_id NOT IN (
        SELECT DISTINCT product_id
        FROM Products
        WHERE change_date <= '2019-08-16'
    );
```

**说明：**
- 第一部分查询：找出在 2019-08-16 或之前有价格变更的产品，取最后一次变更的价格
- 第二部分查询：找出在 2019-08-16 之前没有价格变更的产品，价格设为 10
- UNION 合并两部分结果

### 方法二：窗口函数 RANK()

```sql
WITH RankedPrices AS (
    SELECT 
        product_id,
        new_price,
        RANK() OVER (
            PARTITION BY product_id 
            ORDER BY change_date DESC
        ) AS rk
    FROM 
        Products
    WHERE 
        change_date <= '2019-08-16'
)
SELECT 
    product_id,
    new_price AS price
FROM 
    RankedPrices
WHERE 
    rk = 1

UNION

SELECT 
    DISTINCT product_id,
    10 AS price
FROM 
    Products
WHERE 
    product_id NOT IN (
        SELECT product_id 
        FROM Products 
        WHERE change_date <= '2019-08-16'
    );
```

**说明：**
- 使用窗口函数 RANK() 对每个产品的价格变更按日期降序排序
- rk = 1 表示最后一次变更
- 同样用 UNION 处理没有变更的产品

### 方法三：LEFT JOIN

```sql
WITH LatestPrices AS (
    SELECT 
        p1.product_id,
        p1.new_price
    FROM 
        Products p1
    WHERE 
        p1.change_date <= '2019-08-16'
        AND p1.change_date = (
            SELECT MAX(p2.change_date)
            FROM Products p2
            WHERE p2.product_id = p1.product_id
                AND p2.change_date <= '2019-08-16'
        )
),
AllProducts AS (
    SELECT DISTINCT product_id
    FROM Products
)
SELECT 
    ap.product_id,
    IFNULL(lp.new_price, 10) AS price
FROM 
    AllProducts ap
LEFT JOIN 
    LatestPrices lp ON ap.product_id = lp.product_id;
```

**说明：**
- 先找出所有产品
- LEFT JOIN 最后一次价格变更
- 使用 IFNULL 处理没有变更的情况

### 方法四：COALESCE + 子查询

```sql
SELECT 
    DISTINCT product_id,
    COALESCE(
        (
            SELECT new_price
            FROM Products p2
            WHERE p2.product_id = p1.product_id
                AND p2.change_date <= '2019-08-16'
            ORDER BY p2.change_date DESC
            LIMIT 1
        ),
        10
    ) AS price
FROM 
    Products p1;
```

**说明：**
- 使用相关子查询找出每个产品的最后一次价格变更
- COALESCE 在没有变更时返回默认值 10
- ORDER BY + LIMIT 1 取最后一次变更

## 复杂度分析

**方法一（UNION + 子查询）：**
- 时间复杂度：`O(n log n)`，需要分组和查找
- 空间复杂度：`O(n)`，临时结果集

**方法二（窗口函数）：**
- 时间复杂度：`O(n log n)`，窗口函数需要排序
- 空间复杂度：`O(n)`

**方法四（相关子查询）：**
- 时间复杂度：`O(n^2)`，每个产品执行一次子查询
- 空间复杂度：`O(1)`

推荐使用方法一或方法二，性能更好。

## 关键点总结

1. **默认值处理**：记住所有产品的初始价格是 10，要处理从未变更的情况

2. **最后一次变更**：可以用 `MAX(change_date)` 或窗口函数找到

3. **日期过滤**：`change_date <= '2019-08-16'` 表示包含当天

4. **UNION 的作用**：分别处理有变更和无变更的产品，然后合并

5. **DISTINCT 的必要性**：如果一个产品有多条记录，需要去重

## 易错点

1. **忘记默认价格**：
   ```sql
   -- 错误：只查询有变更的产品
   SELECT product_id, new_price
   FROM Products
   WHERE change_date <= '2019-08-16'
   
   -- 正确：要处理没有变更的产品
   ```

2. **日期比较错误**：
   ```sql
   -- 错误：< 会排除 2019-08-16 当天
   WHERE change_date < '2019-08-16'
   
   -- 正确：<= 包含当天
   WHERE change_date <= '2019-08-16'
   ```

3. **取多次变更的问题**：
   ```sql
   -- 错误：可能返回同一产品的多条记录
   SELECT product_id, new_price
   FROM Products
   WHERE change_date <= '2019-08-16'
   
   -- 正确：要取最后一次
   WHERE (product_id, change_date) IN (...)
   ```

4. **UNION vs UNION ALL**：
   ```sql
   -- UNION 会自动去重
   -- UNION ALL 不去重，性能更好但可能有重复
   -- 本题用 UNION 更安全
   ```

5. **NULL 处理**：
   ```sql
   -- IFNULL 和 COALESCE 的区别
   IFNULL(expr, default)  -- MySQL 特有，两个参数
   COALESCE(expr1, expr2, ...)  -- 标准 SQL，可多个参数
   ```
