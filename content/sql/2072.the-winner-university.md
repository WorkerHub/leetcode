## 题目描述

给你两张表，分别记录两所大学的学生成绩。

**NewYork 表：**
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| student_id  | int  |
| score       | int  |
+-------------+------+
student_id 是主键
```

**California 表：**
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| student_id  | int  |
| score       | int  |
+-------------+------+
student_id 是主键
```

两所大学分数高的学生数量更多的大学获胜。如果相同则是平局。

返回：`"New York University"` 或 `"California University"` 或 `"No Winner"`

**示例：**
```
NewYork: student_id=1,score=90; student_id=2,score=92
California: student_id=1,score=89; student_id=2,score=95

输出："California University"
解释：纽约高分学生1个(92>89但CalifS1=89<90)，加州高分学生1个
实际：NY学生1:90>CA学生1:89, NY学生2:92<CA学生2:95，NY赢1，CA赢1，平局
```

## 解题思路

1. 按 `student_id` 匹配两所大学的学生
2. 统计各大学分数更高的学生数
3. 比较两者的数量

## 代码实现

### 方法一：JOIN + CASE WHEN（推荐）

```sql
WITH comparison AS (
    SELECT
        n.student_id,
        n.score AS ny_score,
        c.score AS ca_score
    FROM NewYork n
    JOIN California c ON n.student_id = c.student_id
),
counts AS (
    SELECT
        SUM(CASE WHEN ny_score > ca_score THEN 1 ELSE 0 END) AS ny_wins,
        SUM(CASE WHEN ca_score > ny_score THEN 1 ELSE 0 END) AS ca_wins
    FROM comparison
)
SELECT
    CASE
        WHEN ny_wins > ca_wins THEN 'New York University'
        WHEN ca_wins > ny_wins THEN 'California University'
        ELSE 'No Winner'
    END AS winner
FROM counts
```

### 方法二：子查询

```sql
SELECT
    CASE
        WHEN ny_count > ca_count THEN 'New York University'
        WHEN ca_count > ny_count THEN 'California University'
        ELSE 'No Winner'
    END AS winner
FROM (
    SELECT
        COUNT(CASE WHEN n.score > c.score THEN 1 END) AS ny_count,
        COUNT(CASE WHEN c.score > n.score THEN 1 END) AS ca_count
    FROM NewYork n
    JOIN California c ON n.student_id = c.student_id
) t
```

## 复杂度分析

- 时间复杂度：O(n)，JOIN 和聚合
- 空间复杂度：O(n)

## 关键点总结

1. 按 `student_id` 一一对应比较（JOIN）
2. 分别统计纽约和加州分数更高的学生数
3. 用 `CASE WHEN` 根据两个计数输出结果

## 易错点

- 是按 student_id 配对比较，不是比较总分
- 三种结果：NY 赢、CA 赢、平局（`No Winner`）
- `CASE WHEN` 中 `ELSE 'No Winner'` 处理平局
