## 题目描述

编写一个SQL查询，找出至少有5名直接下属的经理。

表：`Employee`
```
+----+-------+--------+-----------+
| Id | Name  | Department | ManagerId |
+----+-------+--------+-----------+
| 101| John  | A      | null      |
| 102| Dan   | A      | 101       |
| 103| James | A      | 101       |
| 104| Amy   | A      | 101       |
| 105| Anne  | A      | 101       |
| 106| Ron   | B      | 101       |
+----+-------+--------+-----------+
```

输出应该是：
```
+-------+
| Name  |
+-------+
| John  |
+-------+
```

## SQL 代码实现

### 方法一：GROUP BY + HAVING（推荐）⭐

```sql
SELECT Name
FROM Employee
WHERE Id IN (
    SELECT ManagerId
    FROM Employee
    WHERE ManagerId IS NOT NULL
    GROUP BY ManagerId
    HAVING COUNT(*) >= 5
);
```

### 方法二：自连接

```sql
SELECT e1.Name
FROM Employee e1
JOIN Employee e2 ON e1.Id = e2.ManagerId
GROUP BY e1.Id, e1.Name
HAVING COUNT(e2.Id) >= 5;
```

### 方法三：子查询

```sql
SELECT Name
FROM Employee e1
WHERE (
    SELECT COUNT(*)
    FROM Employee e2
    WHERE e2.ManagerId = e1.Id
) >= 5;
```

## 关键点总结

1. **分组统计**：GROUP BY ManagerId
2. **HAVING 过滤**：统计后过滤
3. **JOIN 关联**：自连接找经理
