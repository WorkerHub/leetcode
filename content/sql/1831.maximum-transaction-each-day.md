## 题目描述

表 `Transactions`：

| Column Name    | Type     |
|----------------|----------|
| transaction_id | int      |
| day            | datetime |
| amount         | int      |

`transaction_id` 是主键。

编写 SQL 查询，找出每天金额最大的所有交易的 `transaction_id`。如果某天有多笔交易金额相同且均为最大，则全部返回。

返回按 `transaction_id` 升序排列的结果。

**示例：**
```
输入：
+----------------+--------------------+--------+
| transaction_id | day                | amount |
+----------------+--------------------+--------+
| 8              | 2021-4-3 15:57:28  | 57     |
| 9              | 2021-4-28 08:47:25 | 21     |
| 1              | 2021-4-29 13:28:30 | 58     |
| 5              | 2021-4-28 16:39:59 | 40     |
| 6              | 2021-4-29 23:39:28 | 58     |
+----------------+--------------------+--------+
输出：
+----------------+
| transaction_id |
+----------------+
| 1              |
| 5              |
| 6              |
| 8              |
+----------------+
```

## 解题思路

找每天最大金额：按 DATE(day) 分组，计算每天的 MAX(amount)。

然后与原表 JOIN，找出每天金额等于最大值的所有交易，并返回其 transaction_id。

也可以使用窗口函数 RANK() 或 DENSE_RANK()。

## 代码实现

### 方法一：子查询 + JOIN（推荐）

```sql
SELECT t.transaction_id
FROM Transactions t
JOIN (
    SELECT DATE(day) AS trans_day, MAX(amount) AS max_amount
    FROM Transactions
    GROUP BY DATE(day)
) m
ON DATE(t.day) = m.trans_day AND t.amount = m.max_amount
ORDER BY t.transaction_id;
```

### 方法二：窗口函数 RANK

```sql
SELECT transaction_id
FROM (
    SELECT transaction_id,
           RANK() OVER (PARTITION BY DATE(day) ORDER BY amount DESC) AS rnk
    FROM Transactions
) ranked
WHERE rnk = 1
ORDER BY transaction_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和分组
- **空间复杂度**：O(n)

## 关键点总结

1. 用 `DATE(day)` 提取日期部分（去掉时间），按天分组
2. 当天可能有多笔最大金额相同的交易，都需要返回
3. 窗口函数 `RANK()` 允许并列，适合此类"每组最大"的多行问题

## 易错点

- `day` 包含时间戳，需要用 `DATE()` 函数提取日期
- 同天多笔最大金额交易都要返回，不能只取一条（不能用 `LIMIT 1`）
