## 题目描述

表：`Activities`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| activity_id   | int     |
| user_id       | int     |
| activity_type | enum    |
| time_spent    | decimal |
+---------------+---------+
```

`activity_type` 为 'send' 或 'open'。

表：`Age`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| age_bucket  | varchar |
+-------------+---------+
```

计算每个年龄段用户发送（send）和打开（open）Snaps 的时间占比（send_pct 和 open_pct），保留两位小数。

## SQL 代码实现

### 方法一：条件聚合（推荐）

```sql
SELECT
    a.age_bucket,
    ROUND(SUM(CASE WHEN b.activity_type = 'send' THEN b.time_spent ELSE 0 END) /
          SUM(b.time_spent) * 100, 2) AS send_pct,
    ROUND(SUM(CASE WHEN b.activity_type = 'open' THEN b.time_spent ELSE 0 END) /
          SUM(b.time_spent) * 100, 2) AS open_pct
FROM Age a
JOIN Activities b ON a.user_id = b.user_id
GROUP BY a.age_bucket
ORDER BY a.age_bucket;
```

## 复杂度分析

- 时间复杂度：O(n)，n 为活动记录数
- 空间复杂度：O(k)，k 为年龄段数

## 关键点总结

1. 用 CASE WHEN 分别计算 send 和 open 的时间
2. 总时间 = send + open 时间之和
3. 占比 = 各类型时间 / 总时间 * 100

## 易错点

1. 分母是总时间（两种类型之和），不是记录数
2. ROUND 保留两位小数
