## 题目描述

给你一张 `Elements` 表，包含元素的类型（Metal/Nonmetal/Noble Gas）。

两种元素可以形成化学键的条件：
- Metal 和 Nonmetal 可以形成离子键（Ionic）
- Nonmetal 和 Nonmetal 可以形成共价键（Covalent）
- 其他组合不能形成键

返回所有可以形成化学键的元素对及其键的类型。

**表结构：**

```
Elements 表：
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| symbol      | varchar |
| type        | enum    |
| electrons   | int     |
+-------------+---------+
symbol 是主键，type 是 'Metal', 'Nonmetal', 'Noble Gas' 之一。
```

## 解题思路

**自连接 + CASE WHEN：**

1. 对 Elements 表做自连接，避免重复对（使用 `e1.symbol < e2.symbol`）
2. 根据两者类型判断键的类型：
   - 若一个是 Metal、一个是 Nonmetal，则为 Ionic
   - 若两者均为 Nonmetal，则为 Covalent
   - 其他情况过滤掉

## 代码实现

### 方法一：自连接 + CASE WHEN（推荐）

```sql
SELECT
    e1.symbol AS symbol1,
    e2.symbol AS symbol2,
    CASE
        WHEN (e1.type = 'Metal' AND e2.type = 'Nonmetal')
          OR (e1.type = 'Nonmetal' AND e2.type = 'Metal')
            THEN 'Ionic'
        WHEN e1.type = 'Nonmetal' AND e2.type = 'Nonmetal'
            THEN 'Covalent'
    END AS type
FROM Elements e1
JOIN Elements e2
    ON e1.symbol < e2.symbol
WHERE
    (e1.type = 'Metal' AND e2.type = 'Nonmetal')
    OR (e1.type = 'Nonmetal' AND e2.type = 'Metal')
    OR (e1.type = 'Nonmetal' AND e2.type = 'Nonmetal');
```

### 方法二：使用 IN 简化条件

```sql
SELECT
    e1.symbol AS symbol1,
    e2.symbol AS symbol2,
    CASE
        WHEN e1.type != e2.type THEN 'Ionic'
        ELSE 'Covalent'
    END AS type
FROM Elements e1
JOIN Elements e2
    ON e1.symbol < e2.symbol
WHERE 'Noble Gas' NOT IN (e1.type, e2.type)
  AND NOT (e1.type = 'Metal' AND e2.type = 'Metal');
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 自连接 | O(n^2) | O(n^2) |

## 关键点总结

1. 自连接时用 `e1.symbol < e2.symbol` 避免重复和自配对
2. Noble Gas 不参与任何键的形成，需要过滤
3. Metal + Metal 也不能形成化学键

## 易错点

- 忘记排除 Noble Gas 的情况
- 忘记排除 Metal + Metal 的情况
