## 题目描述

本题为数据库题目。

给定表 `Sessions`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| session_start | datetime|
| session_end   | datetime|
| session_id    | int     |
| session_type  | varchar |  -- 'Viewer' or 'Streamer'
+---------------+---------+
```

找出满足以下条件的用户：
- 最初的会话类型为 'Viewer'
- 后来至少有一次会话类型为 'Streamer'

即"从观看者转变为直播者"的用户，返回其 user_id 和该用户从观看者转变为直播者的次数（即其直播者会话数）。

## SQL 代码实现

### 方法一：子查询（推荐）

```sql
-- 找第一个会话是 Viewer 的用户
WITH first_session AS (
    SELECT user_id, MIN(session_start) AS first_start
    FROM Sessions
    GROUP BY user_id
),
viewer_first AS (
    SELECT fs.user_id
    FROM first_session fs
    JOIN Sessions s ON fs.user_id = s.user_id
                   AND fs.first_start = s.session_start
    WHERE s.session_type = 'Viewer'
)
-- 统计这些用户的 Streamer 会话数
SELECT
    vf.user_id,
    COUNT(*) AS sessions_count
FROM viewer_first vf
JOIN Sessions s ON vf.user_id = s.user_id
WHERE s.session_type = 'Streamer'
GROUP BY vf.user_id
ORDER BY sessions_count DESC, vf.user_id DESC;
```

### 方法二：窗口函数

```sql
WITH ranked AS (
    SELECT *,
           ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY session_start) AS rn
    FROM Sessions
)
SELECT
    r1.user_id,
    COUNT(*) AS sessions_count
FROM (SELECT user_id FROM ranked WHERE rn = 1 AND session_type = 'Viewer') r1
JOIN Sessions s ON r1.user_id = s.user_id AND s.session_type = 'Streamer'
GROUP BY r1.user_id
ORDER BY sessions_count DESC, r1.user_id DESC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 首先找第一个会话为 Viewer 的用户
2. 然后统计这些用户的 Streamer 会话数量
3. 按 sessions_count 降序，user_id 降序排列

## 易错点

1. 第一个会话按 session_start 时间排序
2. 若某用户第一个会话不是 Viewer，即使后来成为 Viewer 也不算
3. 用户必须有 Streamer 会话才会出现在结果中
