## 题目描述

本题为数据库题目。

给定表 `Transactions`：
```
+------------------+----------+
| Column Name      | Type     |
+------------------+----------+
| user_id          | int      |
| spend            | decimal  |
| transaction_date | datetime |
+------------------+----------+
```

找出每个用户的第三笔交易（按交易日期排序），返回 user_id、spend 和 transaction_date。

## SQL 代码实现

### 方法一：窗口函数 ROW_NUMBER（推荐）

```sql
WITH ranked AS (
    SELECT
        user_id,
        spend,
        transaction_date,
        ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY transaction_date) AS rn
    FROM Transactions
)
SELECT user_id, spend, transaction_date
FROM ranked
WHERE rn = 3
ORDER BY user_id;
```

### 方法二：子查询计数

```sql
SELECT t1.user_id, t1.spend, t1.transaction_date
FROM Transactions t1
WHERE (
    SELECT COUNT(*)
    FROM Transactions t2
    WHERE t2.user_id = t1.user_id
      AND t2.transaction_date <= t1.transaction_date
) = 3
ORDER BY t1.user_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 用 ROW_NUMBER() 按用户分组、日期排序
2. 取 rn = 3 的行
3. 不是所有用户都有第三笔，不存在则不返回

## 易错点

1. 按日期升序排列（最早的第一笔，第三早的是第三笔）
2. 只返回有第三笔交易的用户
