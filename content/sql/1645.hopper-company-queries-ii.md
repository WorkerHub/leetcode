## 题目描述

与 1635 类似，基于同样的表结构（`Drivers`、`Rides`、`AcceptedRides`），查询 2020 年每个季度的活跃驾驶员百分比，即：
- 接受了至少一次行程的驾驶员数占活跃驾驶员总数的百分比（保留两位小数）

结果包含 4 行，对应 2020 年的 4 个季度。

## 解题思路

1. 计算每季度的活跃驾驶员数（在该季度末之前加入）
2. 计算每季度实际接受过行程的驾驶员数（DISTINCT driver_id）
3. 计算百分比（活跃驾驶员为 0 则返回 0.00）

## 代码实现

### 方法一：CTE 分步计算（推荐）

```sql
WITH quarters AS (
    SELECT 1 AS q UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL SELECT 4
),
active_drivers AS (
    -- 统计每季度活跃驾驶员数
    SELECT
        qt.q,
        COUNT(d.driver_id) AS active_count
    FROM quarters qt
    LEFT JOIN Drivers d
        ON YEAR(d.join_date) < 2020
        OR (YEAR(d.join_date) = 2020 AND QUARTER(d.join_date) <= qt.q)
    GROUP BY qt.q
),
working_drivers AS (
    -- 统计每季度接受过行程的驾驶员数
    SELECT
        QUARTER(r.requested_at) AS q,
        COUNT(DISTINCT ar.driver_id) AS working_count
    FROM Rides r
    INNER JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY QUARTER(r.requested_at)
)
SELECT
    ad.q AS quarter,
    IFNULL(
        ROUND(wd.working_count * 100 / ad.active_count, 2),
        0.00
    ) AS working_percentage
FROM active_drivers ad
LEFT JOIN working_drivers wd ON ad.q = wd.q
ORDER BY ad.q;
```

### 方法二：使用 CASE WHEN 处理零除

```sql
WITH quarters AS (
    SELECT 1 AS q UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL SELECT 4
),
active_drivers AS (
    SELECT qt.q, COUNT(d.driver_id) AS active_count
    FROM quarters qt
    LEFT JOIN Drivers d
        ON d.join_date <= CASE qt.q
            WHEN 1 THEN '2020-03-31'
            WHEN 2 THEN '2020-06-30'
            WHEN 3 THEN '2020-09-30'
            WHEN 4 THEN '2020-12-31'
        END
    GROUP BY qt.q
),
working_drivers AS (
    SELECT QUARTER(r.requested_at) AS q, COUNT(DISTINCT ar.driver_id) AS working_count
    FROM Rides r
    JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY 1
)
SELECT
    ad.q AS quarter,
    CASE
        WHEN ad.active_count = 0 THEN 0.00
        ELSE ROUND(IFNULL(wd.working_count, 0) * 100.0 / ad.active_count, 2)
    END AS working_percentage
FROM active_drivers ad
LEFT JOIN working_drivers wd ON ad.q = wd.q
ORDER BY ad.q;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| CTE 分步 | 逻辑清晰，分步计算再合并 |
| CASE WHEN | 避免除零，处理边界更安全 |

## 关键点总结

1. 活跃驾驶员：截至该季度末已加入的所有驾驶员
2. 工作驾驶员：该季度内接受了至少一次行程的驾驶员（去重 DISTINCT）
3. 百分比 = `working_count * 100 / active_count`，保留两位小数
4. 无工作驾驶员时返回 0.00（使用 `IFNULL`）

## 易错点

- 活跃驾驶员跨年问题：2019年加入的在2020年所有季度都是活跃的
- 工作驾驶员要用 `DISTINCT driver_id`（同一驾驶员多次接单只算一次）
- 某季度没有工作驾驶员时需返回 0.00，不是 NULL
