## 题目描述

表：`Point2D`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
| y           | int  |
+-------------+------+
```

`(x, y)` 是该表的主键列。
该表的每一行包含平面上一个点的坐标。

编写一个 SQL 查询，报告平面上两点之间的最短距离，保留**两位小数**。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Point2D 表：
+----+----+
| x  | y  |
+----+----+
| -1 | -1 |
| 0  | 0  |
| -1 | -2 |
+----+----+

输出：
+----------+
| shortest |
+----------+
| 1.00     |
+----------+

解释：最短距离是 1.00，在点 (-1, -1) 和 (-1, -2) 之间。
```

## 解题思路

计算平面上所有点对之间的距离，找出最小值。

**距离公式：**

两点 (x1, y1) 和 (x2, y2) 之间的欧几里得距离：
```
d = sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

**SQL 实现要点：**
1. 自连接获取所有点对
2. 计算距离
3. 找出最小值
4. 保留两位小数

## SQL 代码实现

### 方法一：自连接（推荐）⭐

```sql
SELECT ROUND(MIN(SQRT(POW(p1.x - p2.x, 2) + POW(p1.y - p2.y, 2))), 2) AS shortest
FROM Point2D p1
JOIN Point2D p2 ON (p1.x, p1.y) != (p2.x, p2.y);
```

### 方法二：避免重复计算

```sql
SELECT ROUND(MIN(SQRT(POW(p1.x - p2.x, 2) + POW(p1.y - p2.y, 2))), 2) AS shortest
FROM Point2D p1
JOIN Point2D p2 ON p1.x < p2.x OR (p1.x = p2.x AND p1.y < p2.y);
```

### 方法三：使用 POWER

```sql
SELECT ROUND(MIN(SQRT(POWER(p1.x - p2.x, 2) + POWER(p1.y - p2.y, 2))), 2) AS shortest
FROM Point2D p1, Point2D p2
WHERE p1.x != p2.x OR p1.y != p2.y;
```

## 复杂度分析

- **时间复杂度**：O(n²)，自连接
- **空间复杂度**：O(n²)

## 关键点总结

1. **自连接**：获取所有点对
2. **距离公式**：`SQRT(POW(x2-x1, 2) + POW(y2-y1, 2))`
3. **排除自身**：`(p1.x, p1.y) != (p2.x, p2.y)`
4. **ROUND 函数**：保留两位小数
5. **优化**：避免重复计算 (A, B) 和 (B, A)
