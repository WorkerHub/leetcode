## 题目描述

此题为 LeetCode Premium 题目。

表：`Project`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
+-------------+---------+
(project_id, employee_id) 是这个表的主键。
employee_id 是表 Employee 的外键。
```

表：`Employee`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| experience_years | int     |
+------------------+---------+
employee_id 是这个表的主键。
```

编写一个 SQL 查询，报告拥有**最多员工**的项目。

查询结果格式如下示例所示。

**示例：**

输入：
```
Project 表：
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 2           |
| 1           | 3           |
| 2           | 1           |
| 2           | 4           |
+-------------+-------------+

Employee 表：
+-------------+--------+------------------+
| employee_id | name   | experience_years |
+-------------+--------+------------------+
| 1           | Khaled | 3                |
| 2           | Ali    | 2                |
| 3           | John   | 1                |
| 4           | Doe    | 2                |
+-------------+--------+------------------+
```

输出：
```
+-------------+
| project_id  |
+-------------+
| 1           |
+-------------+
```

解释：
- 项目 1 有 3 个员工
- 项目 2 有 2 个员工
- 项目 1 拥有最多员工

**注意**：如果有多个项目拥有相同的最多员工数，应该返回所有这些项目。

## 解题思路

这道题需要找出员工数量最多的项目，可以分为两步：

1. **统计每个项目的员工数**：使用 GROUP BY 和 COUNT
2. **找出员工数最多的项目**：使用子查询或窗口函数

### 方法对比

- **方法一**：使用子查询，先找出最大员工数，再筛选
- **方法二**：使用 LIMIT，先按员工数降序排序，取第一个（可能有多个）
- **方法三**：使用窗口函数 RANK()，找出排名第一的项目

## SQL 代码实现

### 方法一：子查询（推荐）

```sql
SELECT 
    project_id
FROM 
    Project
GROUP BY 
    project_id
HAVING 
    COUNT(employee_id) = (
        SELECT MAX(employee_count)
        FROM (
            SELECT COUNT(employee_id) AS employee_count
            FROM Project
            GROUP BY project_id
        ) AS counts
    );
```

### 方法二：简化的子查询

```sql
SELECT 
    project_id
FROM 
    Project
GROUP BY 
    project_id
HAVING 
    COUNT(employee_id) >= ALL (
        SELECT COUNT(employee_id)
        FROM Project
        GROUP BY project_id
    );
```

### 方法三：使用窗口函数（优雅）

```sql
WITH ProjectCounts AS (
    SELECT 
        project_id,
        COUNT(employee_id) AS employee_count
    FROM 
        Project
    GROUP BY 
        project_id
),
RankedProjects AS (
    SELECT 
        project_id,
        employee_count,
        RANK() OVER (ORDER BY employee_count DESC) AS rnk
    FROM 
        ProjectCounts
)
SELECT 
    project_id
FROM 
    RankedProjects
WHERE 
    rnk = 1;
```

### 方法四：使用 DENSE_RANK（处理并列）

```sql
SELECT 
    project_id
FROM (
    SELECT 
        project_id,
        DENSE_RANK() OVER (ORDER BY COUNT(employee_id) DESC) AS rnk
    FROM 
        Project
    GROUP BY 
        project_id
) AS ranked
WHERE 
    rnk = 1;
```

## 复杂度分析

**SQL 方法一、二：**
- **时间复杂度**：O(n)
  - 第一次 GROUP BY：O(n)
  - 子查询：O(k)，k 是项目数
  - HAVING 过滤：O(k)
- **空间复杂度**：O(k)，k 是不同项目的数量

**SQL 方法三、四（窗口函数）：**
- **时间复杂度**：O(n + k log k)
  - GROUP BY：O(n)
  - 排序（窗口函数）：O(k log k)
- **空间复杂度**：O(k)

**Pandas 方法：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. **COUNT 聚合**：使用 `COUNT(employee_id)` 统计每个项目的员工数
2. **HAVING 子句**：在分组后筛选，使用 HAVING 而不是 WHERE
3. **子查询**：先找出最大值，再筛选等于最大值的记录
4. **窗口函数**：RANK() 和 DENSE_RANK() 可以优雅地处理并列情况
5. **处理并列**：题目要求返回所有拥有最多员工的项目，不能用 LIMIT 1

## 易错点

1. **使用 LIMIT 1**：这会漏掉并列第一的项目，应该筛选所有最大值
2. **WHERE vs HAVING**：聚合函数的条件必须用 HAVING，不能用 WHERE
3. **子查询别名**：某些数据库（如 MySQL）要求子查询必须有别名
4. **COUNT(*) vs COUNT(column)**：对于此题两者等价，但理解区别很重要
5. **窗口函数支持**：确保数据库支持窗口函数（MySQL 8.0+）

## SQL 语法要点

### HAVING 子句
```sql
-- HAVING 用于过滤聚合后的结果
SELECT column, COUNT(*)
FROM table
GROUP BY column
HAVING COUNT(*) > 10;  -- 筛选计数大于 10 的组
```

### 窗口函数 RANK
```sql
-- RANK(): 1, 2, 2, 4（跳过排名）
-- DENSE_RANK(): 1, 2, 2, 3（不跳过排名）
-- ROW_NUMBER(): 1, 2, 3, 4（唯一排名）

SELECT 
    name, 
    score,
    RANK() OVER (ORDER BY score DESC) AS rank
FROM students;
```

### ALL 关键字
```sql
-- >= ALL 表示大于等于所有值（即最大值）
SELECT column
FROM table
WHERE value >= ALL (SELECT value FROM table);
```
