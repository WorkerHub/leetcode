## 题目描述

表 `LogInfo`：

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| account_id  | int      |
| ip_address  | int      |
| login       | datetime |
| logout      | datetime |
+-------------+----------+
```

该表可能包含重复行。
每行包含登录 IP 地址和登录/登出时间。

编写解决方案，找出那些同时有两个活跃会话（在不同 IP 地址上同时在线）的账号。

具体来说，如果账号 `account_id` 在时间 `t` 有一个 IP 为 `ip1` 的活跃会话，同时在时间 `t` 还有另一个 IP 为 `ip2`（`ip1 != ip2`）的活跃会话，则该账号被封禁。

返回被封禁的账号列表，按 `account_id` 升序排列，且每个账号只返回一次。

## 解题思路

将表自连接，找到同一账号、不同 IP、且时间段有重叠的记录。

两个时间段 `[login1, logout1]` 和 `[login2, logout2]` 有重叠当且仅当：
- `login1 <= logout2 AND login2 <= logout1`

## 代码实现

### 方法一：自连接检查时间段重叠

```sql
-- 自连接，找同一账号不同 IP 且时间段有重叠的记录
SELECT DISTINCT l1.account_id
FROM LogInfo l1
JOIN LogInfo l2
    ON l1.account_id = l2.account_id
    AND l1.ip_address != l2.ip_address
    -- 两个会话时间段有重叠
    AND l1.login <= l2.logout
    AND l2.login <= l1.logout
ORDER BY l1.account_id;
```

### 方法二：使用 EXISTS

```sql
-- 使用 EXISTS 子查询
SELECT DISTINCT account_id
FROM LogInfo l1
WHERE EXISTS (
    SELECT 1
    FROM LogInfo l2
    WHERE l1.account_id = l2.account_id
      AND l1.ip_address != l2.ip_address
      AND l1.login <= l2.logout
      AND l2.login <= l1.logout
)
ORDER BY account_id;
```

## 复杂度分析

- **时间复杂度**：O(n^2)，自连接
- **空间复杂度**：O(n)，存储结果

## 关键点总结

1. 两个区间重叠的条件：`A.start <= B.end AND B.start <= A.end`
2. 自连接时需要排除同一条记录（`ip_address` 不同）
3. `DISTINCT` 避免重复账号

## 易错点

- 注意重叠条件，不是严格包含，而是有任意重叠（包括端点相等）
- `DISTINCT` 很重要，同一账号可能有多对符合条件的记录
