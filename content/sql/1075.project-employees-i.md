## 题目描述

表：`Project`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
+-------------+---------+
(project_id, employee_id) 是这个表的主键。
employee_id 是表 Employee 的外键。
```

表：`Employee`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| experience_years | int     |
+------------------+---------+
employee_id 是这个表的主键。
```

请编写一个 SQL 查询，报告每个项目中所有员工的**平均工作年限**，**四舍五入到小数点后 2 位**。

查询结果格式如下示例所示。

**示例 1：**

输入：
```
Project 表：
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 2           |
| 1           | 3           |
| 2           | 1           |
| 2           | 4           |
+-------------+-------------+

Employee 表：
+-------------+--------+------------------+
| employee_id | name   | experience_years |
+-------------+--------+------------------+
| 1           | Khaled | 3                |
| 2           | Ali    | 2                |
| 3           | John   | 1                |
| 4           | Doe    | 2                |
+-------------+--------+------------------+
```

输出：
```
+-------------+---------------+
| project_id  | average_years |
+-------------+---------------+
| 1           | 2.00          |
| 2           | 2.50          |
+-------------+---------------+
```

解释：
- 项目 1 的员工平均工作年限 = (3 + 2 + 1) / 3 = 2.00
- 项目 2 的员工平均工作年限 = (3 + 2) / 2 = 2.50

## 解题思路

这是一道典型的 **SQL JOIN + 聚合函数** 问题。

### 核心思路

1. **关联两表**：
   - Project 表记录了项目和员工的对应关系
   - Employee 表包含员工的工作年限信息
   - 需要通过 employee_id 将两表关联

2. **分组聚合**：
   - 按 project_id 分组
   - 计算每组的平均工作年限

3. **格式化结果**：
   - 使用 ROUND 函数保留 2 位小数

### SQL 关键点

- `JOIN`：关联两表
- `GROUP BY`：按项目分组
- `AVG()`：计算平均值
- `ROUND(value, 2)`：四舍五入到 2 位小数

## SQL 代码实现

### 方法一：INNER JOIN + GROUP BY（推荐）

```sql
SELECT 
    p.project_id,
    ROUND(AVG(e.experience_years), 2) AS average_years
FROM 
    Project p
INNER JOIN 
    Employee e
ON 
    p.employee_id = e.employee_id
GROUP BY 
    p.project_id;
```

### 方法二：使用子查询（不推荐）

```sql
SELECT 
    project_id,
    ROUND(
        (SELECT AVG(experience_years) 
         FROM Employee 
         WHERE employee_id IN (
             SELECT employee_id 
             FROM Project p2 
             WHERE p2.project_id = p1.project_id
         )
        ), 2
    ) AS average_years
FROM 
    Project p1
GROUP BY 
    project_id;
```

### 方法三：LEFT JOIN（处理可能的空值）

```sql
SELECT 
    p.project_id,
    ROUND(AVG(IFNULL(e.experience_years, 0)), 2) AS average_years
FROM 
    Project p
LEFT JOIN 
    Employee e
ON 
    p.employee_id = e.employee_id
GROUP BY 
    p.project_id;
```

## 复杂度分析

**SQL 方法一（推荐）：**
- **时间复杂度**：O(n + m)，其中 n 是 Project 表的行数，m 是 Employee 表的行数
  - JOIN 操作：O(n + m)
  - GROUP BY 和 AVG：O(n)
- **空间复杂度**：O(k)，k 是不同项目的数量

**Pandas 方法：**
- **时间复杂度**：O(n + m)
  - merge：O(n + m)
  - groupby + agg：O(n)
- **空间复杂度**：O(n + m)

## 关键点总结

1. **JOIN 类型**：使用 INNER JOIN 因为题目要求计算现有员工的平均年限
2. **聚合函数**：AVG() 自动处理分组内的所有值
3. **ROUND 函数**：MySQL 中 `ROUND(value, 2)` 保留 2 位小数
4. **GROUP BY 必需**：使用聚合函数时必须指定分组列
5. **Pandas 等价**：`groupby().agg()` 是 SQL GROUP BY + 聚合函数的 Pandas 实现

## 易错点

1. **忘记 JOIN**：直接在 Project 表上聚合无法获取 experience_years
2. **ROUND 位置**：ROUND 应该在 AVG 外层，而不是内层
3. **GROUP BY 遗漏**：使用聚合函数时忘记 GROUP BY 会报错
4. **列名重命名**：注意输出列名是 `average_years`，不是 `avg_experience_years`
5. **Pandas 索引**：groupby 后需要 `reset_index()` 或 `as_index=False`

## SQL 语法要点

### ROUND 函数
```sql
-- MySQL / PostgreSQL
ROUND(value, decimals)

-- 示例
ROUND(2.666, 2)  -- 结果: 2.67
ROUND(2.333, 2)  -- 结果: 2.33
```

### AVG 函数
```sql
-- 计算平均值
AVG(column_name)

-- 配合 GROUP BY
SELECT category, AVG(price)
FROM products
GROUP BY category;
```

### JOIN 类型对比
```sql
-- INNER JOIN: 只返回匹配的行
SELECT * FROM A INNER JOIN B ON A.id = B.id;

-- LEFT JOIN: 返回左表所有行，右表不匹配则为 NULL
SELECT * FROM A LEFT JOIN B ON A.id = B.id;

-- RIGHT JOIN: 返回右表所有行，左表不匹配则为 NULL
SELECT * FROM A RIGHT JOIN B ON A.id = B.id;
```
