## 题目描述

表 `Genders` 的结构如下：

| Column Name | Type    |
|-------------|---------|
| user_id     | int     |
| gender      | varchar |

`user_id` 是该表的主键。`gender` 列的值为 `'female'`、`'male'` 或 `'other'`。

将该表重新排列，使得行的顺序交替出现 `'female'`、`'other'`、`'male'`，并且每种性别按 `user_id` 升序排列。返回结果表中的数据应如下示例所示。

**示例：**
```
输入：
Genders 表：
+---------+--------+
| user_id | gender |
+---------+--------+
| 4       | male   |
| 7       | female |
| 2       | other  |
| 5       | male   |
| 3       | female |
| 8       | male   |
| 6       | other  |
| 1       | female |
| 9       | other  |
+---------+--------+

输出：
+---------+--------+
| user_id | gender |
+---------+--------+
| 1       | female |
| 2       | other  |
| 4       | male   |
| 3       | female |
| 6       | other  |
| 5       | male   |
| 7       | female |
| 9       | other  |
| 8       | male   |
+---------+--------+
```

## 解题思路

**核心思想：**
为每种性别分配行号（按 user_id 排序），然后按行号排序，再在相同行号内按性别自定义顺序排列（female=1, other=2, male=3）。

## 代码实现

### 方法一：窗口函数分配行号（推荐）

```sql
SELECT user_id, gender
FROM (
    SELECT 
        user_id,
        gender,
        -- 为每种性别按 user_id 分配行号
        ROW_NUMBER() OVER (PARTITION BY gender ORDER BY user_id) AS rn
    FROM Genders
) ranked
ORDER BY 
    rn,  -- 先按行号排序（保证交替出现）
    FIELD(gender, 'female', 'other', 'male')  -- 再按自定义性别顺序
```

### 方法二：使用 CASE 语句定义排序权重

```sql
SELECT user_id, gender
FROM (
    SELECT 
        user_id,
        gender,
        ROW_NUMBER() OVER (
            PARTITION BY gender 
            ORDER BY user_id
        ) AS row_num
    FROM Genders
) t
ORDER BY 
    row_num ASC,
    CASE gender 
        WHEN 'female' THEN 1 
        WHEN 'other' THEN 2 
        WHEN 'male' THEN 3 
    END ASC
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 窗口函数 | O(n log n) | O(n) |

## 关键点总结

1. 使用 `ROW_NUMBER() OVER (PARTITION BY gender ORDER BY user_id)` 为每种性别独立编号。
2. 先按行号排序，确保三种性别"轮流"出现；再按性别顺序排序，确保同一轮次内 female → other → male。
3. `FIELD()` 函数可以自定义排序顺序（MySQL 特有），也可用 `CASE WHEN` 替代以提高跨数据库兼容性。

## 易错点

- 若某种性别的行数少于其他性别，交替排列后会自然结束，不影响结果。
- `FIELD()` 是 MySQL 特有函数，其他数据库需改用 `CASE WHEN`。
