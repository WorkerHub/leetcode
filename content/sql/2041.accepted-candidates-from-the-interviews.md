## 题目描述

给你两张表：

**Candidates 表：**
```
+--------------+----------+
| Column Name  | Type     |
+--------------+----------+
| candidate_id | int      |
| name         | varchar  |
| years_exp    | int      |
| interview_id | int      |
+--------------+----------+
candidate_id 是主键
```

**Rounds 表：**
```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| interview_id | int  |
| round_id     | int  |
| score        | int  |
+--------------+------+
(interview_id, round_id) 是联合主键
```

录取条件：候选人工作经验 >= 2 年**或者**面试所有轮次的分数总和 > 15。

返回满足条件的候选人的 `candidate_id`，结果按任意顺序排列。

**示例：**
```
输出：[4, 7, 8]（满足任一条件）
```

## 解题思路

1. 按 `interview_id` 对 `Rounds` 表按分组求总分
2. 将 `Candidates` 与分组后的 `Rounds` 连接
3. 过滤满足"years_exp >= 2 OR 总分 > 15"的候选人

## 代码实现

### 方法一：JOIN + GROUP BY（推荐）

```sql
SELECT c.candidate_id
FROM Candidates c
JOIN (
    SELECT interview_id, SUM(score) AS total_score
    FROM Rounds
    GROUP BY interview_id
) r ON c.interview_id = r.interview_id
WHERE c.years_exp >= 2 OR r.total_score > 15
```

### 方法二：使用 HAVING 过滤

```sql
WITH interview_scores AS (
    SELECT interview_id, SUM(score) AS total_score
    FROM Rounds
    GROUP BY interview_id
)
SELECT c.candidate_id
FROM Candidates c
LEFT JOIN interview_scores s ON c.interview_id = s.interview_id
WHERE c.years_exp >= 2
   OR COALESCE(s.total_score, 0) > 15
```

### 方法三：UNION 方式

```sql
-- 满足工作经验条件的候选人
SELECT candidate_id FROM Candidates WHERE years_exp >= 2

UNION

-- 满足面试分数条件的候选人
SELECT c.candidate_id
FROM Candidates c
JOIN Rounds r ON c.interview_id = r.interview_id
GROUP BY c.candidate_id
HAVING SUM(r.score) > 15
```

## 复杂度分析

- 时间复杂度：O(n log n)，GROUP BY 和 JOIN 操作
- 空间复杂度：O(n)

## 关键点总结

1. 两个条件用 `OR` 连接（满足任一即可）
2. 按 `interview_id` 聚合 `Rounds` 计算总分
3. `UNION` 方法自动去重（同一候选人满足两个条件时只出现一次）

## 易错点

- 使用 `UNION`（不是 `UNION ALL`）自动去重
- `LEFT JOIN` 时若候选人没有对应的面试记录，总分为 NULL，需要用 `COALESCE`
- 题目要求 OR，不是 AND
