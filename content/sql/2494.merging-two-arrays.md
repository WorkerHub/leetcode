## 题目描述

给你两张表 `Nums1` 和 `Nums2`，每张表只有一列 `num`，包含不同的正整数。

返回两张表合并后去重的所有数字，按升序排列。

**表结构：**

```
Nums1 表：
+-------------+------+
| Column Name | Type |
+-------------+------+
| num         | int  |
+-------------+------+
num 是 Nums1 的主键。

Nums2 表：
+-------------+------+
| Column Name | Type |
+-------------+------+
| num         | int  |
+-------------+------+
num 是 Nums2 的主键。
```

## 解题思路

**UNION 去重：**

使用 `UNION`（自动去重，区别于 `UNION ALL`）合并两张表，`ORDER BY` 排序。

## 代码实现

### 方法一：UNION（推荐）

```sql
SELECT num
FROM Nums1
UNION
SELECT num
FROM Nums2
ORDER BY num;
```

### 方法二：UNION ALL + DISTINCT

```sql
SELECT DISTINCT num
FROM (
    SELECT num FROM Nums1
    UNION ALL
    SELECT num FROM Nums2
) combined
ORDER BY num;
```

### 方法三：全外连接（MySQL 无全外连接，用 LEFT JOIN + RIGHT JOIN UNION）

```sql
SELECT COALESCE(n1.num, n2.num) AS num
FROM Nums1 n1
LEFT JOIN Nums2 n2 ON n1.num = n2.num
UNION
SELECT COALESCE(n1.num, n2.num) AS num
FROM Nums1 n1
RIGHT JOIN Nums2 n2 ON n1.num = n2.num
ORDER BY num;
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| UNION | O(n log n) | O(n) |

## 关键点总结

1. `UNION` 自动去重，`UNION ALL` 保留重复
2. `ORDER BY` 在最外层添加
3. 这是最简单的集合操作题

## 易错点

- `UNION` 和 `UNION ALL` 的区别：前者去重，后者保留重复
