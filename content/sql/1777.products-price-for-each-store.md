## 题目描述

表 `Products`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store       | enum    |
| price       | int     |
+-------------+---------+
```

`(product_id, store)` 是该表的主键。`store` 是枚举类型，取值 `('store1', 'store2', 'store3')`。

找出每种产品在各商店中的价格。如果某个产品在某个商店中未出售，则该商店对应的价格为 NULL。

**结果表**有四列：`product_id`、`store1`（该产品在商店 1 的价格）、`store2`、`store3`，按 `product_id` 升序排序。

## 解题思路

**行转列（PIVOT）**：将 `store` 列的不同值转为列名，对应的 `price` 值作为列值。

用条件聚合（`MAX(CASE WHEN ...)` 或 `IF`）实现。

## 代码实现

### 方法一：条件聚合（推荐）

```sql
-- 行转列：将 store 的不同值转为列
SELECT
    product_id,
    MAX(CASE WHEN store = 'store1' THEN price END) AS store1,
    MAX(CASE WHEN store = 'store2' THEN price END) AS store2,
    MAX(CASE WHEN store = 'store3' THEN price END) AS store3
FROM Products
GROUP BY product_id
ORDER BY product_id;
```

### 方法二：使用 IF（MySQL 语法）

```sql
-- MySQL 中 IF 函数可以替代 CASE WHEN
SELECT
    product_id,
    MAX(IF(store = 'store1', price, NULL)) AS store1,
    MAX(IF(store = 'store2', price, NULL)) AS store2,
    MAX(IF(store = 'store3', price, NULL)) AS store3
FROM Products
GROUP BY product_id
ORDER BY product_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，分组和排序
- **空间复杂度**：O(n)

## 关键点总结

1. 行转列使用条件聚合 `MAX(CASE WHEN ...)`
2. 未出现的 store-product 组合自然为 NULL（MAX 忽略 NULL）
3. GROUP BY product_id 将每个产品的行合并

## 易错点

- 用 `MAX` 而不是 `SUM`（每个产品在每个商店只有一个价格）
- 确保 NULL 值的输出（未出现的商店应为 NULL）
