## 题目描述

表：`Product`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
| unit_price   | int     |
+--------------+---------+
product_id 是这个表的主键。
该表的每一行表示每种产品的名称和价格。
```

表：`Sales`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| seller_id   | int     |
| product_id  | int     |
| buyer_id    | int     |
| sale_date   | date    |
| quantity    | int     |
| price       | int     |
+-------------+---------+
这个表没有主键，它可以有重复的行。
product_id 是 Product 表的外键。
该表的每一行包含一次销售的信息。
```

编写一个 SQL 查询，报告**销售总额最高的卖家**。如果有并列的情况，返回所有这些卖家。

返回结果表**按任意顺序**排列。

查询结果格式如下示例所示。

**示例：**

输入：
```
Product 表：
+------------+--------------+------------+
| product_id | product_name | unit_price |
+------------+--------------+------------+
| 1          | S8           | 1000       |
| 2          | G4           | 800        |
| 3          | iPhone       | 1400       |
+------------+--------------+------------+

Sales 表：
+-----------+------------+----------+------------+----------+-------+
| seller_id | product_id | buyer_id | sale_date  | quantity | price |
+-----------+------------+----------+------------+----------+-------+
| 1         | 1          | 1        | 2019-01-21 | 2        | 2000  |
| 1         | 2          | 2        | 2019-02-17 | 1        | 800   |
| 2         | 2          | 3        | 2019-06-02 | 1        | 800   |
| 3         | 3          | 4        | 2019-05-13 | 2        | 2800  |
+-----------+------------+----------+------------+----------+-------+
```

输出：
```
+-------------+
| seller_id   |
+-------------+
| 1           |
| 3           |
+-------------+
```

解释：
- 卖家 1 的总销售额 = 2000 + 800 = 2800
- 卖家 2 的总销售额 = 800
- 卖家 3 的总销售额 = 2800
- 卖家 1 和 3 都是总销售额最高的，所以都返回

## 解题思路

这是一道典型的 **SQL 聚合 + 子查询** 问题。

### 核心思路

1. **计算每个卖家的总销售额**：
   - 使用 GROUP BY 按 seller_id 分组
   - 使用 SUM(price) 计算每组的总销售额

2. **找出最大销售额**：
   - 使用子查询找出所有卖家中的最大销售额

3. **筛选最高销售额的卖家**：
   - 使用 HAVING 子句筛选总销售额等于最大值的卖家

### SQL 关键点

- `GROUP BY`：按卖家分组
- `SUM()`：计算总销售额
- `HAVING`：过滤分组后的结果
- 子查询：找出最大值

## SQL 代码实现

### 方法一：子查询（推荐）

```sql
SELECT 
    seller_id
FROM 
    Sales
GROUP BY 
    seller_id
HAVING 
    SUM(price) = (
        SELECT MAX(total_sales)
        FROM (
            SELECT SUM(price) AS total_sales
            FROM Sales
            GROUP BY seller_id
        ) AS seller_totals
    );
```

### 方法二：使用 ALL 关键字

```sql
SELECT 
    seller_id
FROM 
    Sales
GROUP BY 
    seller_id
HAVING 
    SUM(price) >= ALL (
        SELECT SUM(price)
        FROM Sales
        GROUP BY seller_id
    );
```

### 方法三：窗口函数 RANK（优雅）

```sql
WITH SellerSales AS (
    SELECT 
        seller_id,
        SUM(price) AS total_sales
    FROM 
        Sales
    GROUP BY 
        seller_id
),
RankedSellers AS (
    SELECT 
        seller_id,
        total_sales,
        RANK() OVER (ORDER BY total_sales DESC) AS rnk
    FROM 
        SellerSales
)
SELECT 
    seller_id
FROM 
    RankedSellers
WHERE 
    rnk = 1;
```

### 方法四：使用 MAX 直接筛选

```sql
SELECT 
    seller_id
FROM 
    Sales
GROUP BY 
    seller_id
HAVING 
    SUM(price) = (
        SELECT MAX(SUM(price))
        FROM Sales
        GROUP BY seller_id
    );
-- 注意：这种写法在某些数据库中不支持（MySQL 不支持嵌套聚合函数）
```

## 复杂度分析

**SQL 方法：**
- **时间复杂度**：O(n)
  - GROUP BY：O(n)
  - 子查询：O(k)，k 是卖家数量
- **空间复杂度**：O(k)

**Pandas 方法：**
- **时间复杂度**：O(n)
  - groupby：O(n)
  - 筛选：O(k)
- **空间复杂度**：O(k)

## 关键点总结

1. **聚合函数**：使用 SUM(price) 计算总销售额
2. **GROUP BY**：按 seller_id 分组
3. **HAVING vs WHERE**：HAVING 用于过滤聚合后的结果
4. **处理并列**：使用 = 而不是 LIMIT 1，确保返回所有并列第一的卖家
5. **子查询嵌套**：某些数据库要求子查询有别名

## 易错点

1. **使用 WHERE**：聚合函数的条件必须用 HAVING，不能用 WHERE
2. **忘记 GROUP BY**：使用聚合函数时必须指定分组
3. **LIMIT 1 错误**：会漏掉并列第一的卖家
4. **子查询别名**：MySQL 要求派生表必须有别名
5. **Product 表未使用**：本题实际不需要 JOIN Product 表，因为 price 在 Sales 表中

## SQL 语法要点

### HAVING 子句
```sql
-- HAVING 在 GROUP BY 之后，用于过滤聚合结果
SELECT column, COUNT(*)
FROM table
GROUP BY column
HAVING COUNT(*) > 10;
```

### ALL 关键字
```sql
-- >= ALL 表示大于等于所有值（即最大值）
SELECT column
FROM table
WHERE value >= ALL (SELECT value FROM table);
```

### 窗口函数 RANK
```sql
-- RANK() 为每行分配排名
SELECT 
    column,
    RANK() OVER (ORDER BY value DESC) AS rnk
FROM table;
```
