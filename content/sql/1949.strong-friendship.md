## 题目描述

表 `Friendship`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user1_id      | int     |
| user2_id      | int     |
+---------------+---------+
(user1_id, user2_id) 是主键，user1_id < user2_id。
```

若用户 `x` 和用户 `y` 是朋友，且他们有**至少 3 个共同朋友**，则称 `(x, y)` 是**坚定友谊**。

返回所有坚定友谊对 `(user1_id, user2_id)` 及共同朋友数 `common_friend`，按 `user1_id` 升序，再按 `user2_id` 升序排列。

---

## 解题思路

### 核心思想：将无向图扁平化 + 自连接找共同朋友

1. 将 `Friendship` 表扩展为双向：`(a, b)` 和 `(b, a)` 都存在
2. 对于朋友对 `(x, y)`，找既与 x 是朋友又与 y 是朋友的 z（即共同朋友）
3. 统计共同朋友数 ≥ 3

---

## 代码实现

### 方法一：双向化 + 三表连接（推荐）

```sql
-- 将友谊关系双向化
WITH all_friends AS (
    SELECT user1_id AS user_id, user2_id AS friend_id FROM Friendship
    UNION ALL
    SELECT user2_id AS user_id, user1_id AS friend_id FROM Friendship
)
SELECT
    f.user1_id,
    f.user2_id,
    COUNT(*) AS common_friend
FROM Friendship f
-- 找与 user1_id 是朋友的人
JOIN all_friends a1 ON a1.user_id = f.user1_id
-- 同一人也与 user2_id 是朋友
JOIN all_friends a2
    ON a2.user_id = f.user2_id
    AND a2.friend_id = a1.friend_id
    AND a1.friend_id != f.user1_id
    AND a1.friend_id != f.user2_id
GROUP BY f.user1_id, f.user2_id
HAVING COUNT(*) >= 3
ORDER BY f.user1_id, f.user2_id;
```

### 方法二：子查询统计共同朋友

```sql
WITH all_friends AS (
    SELECT user1_id AS u, user2_id AS v FROM Friendship
    UNION ALL
    SELECT user2_id AS u, user1_id AS v FROM Friendship
),
friend_pairs AS (
    SELECT DISTINCT
        a.u AS user1,
        b.u AS user2,
        a.v AS common
    FROM all_friends a
    JOIN all_friends b
        ON a.v = b.v
        AND a.u < b.u
    JOIN Friendship f
        ON f.user1_id = a.u AND f.user2_id = b.u
    WHERE a.v != a.u AND a.v != b.u
)
SELECT
    user1 AS user1_id,
    user2 AS user2_id,
    COUNT(*) AS common_friend
FROM friend_pairs
GROUP BY user1, user2
HAVING COUNT(*) >= 3
ORDER BY user1_id, user2_id;
```

## 复杂度分析

| 操作 | 说明 |
|------|------|
| 双向化 | O(n) |
| 三表 JOIN | O(n²) 最坏 |
| GROUP BY + HAVING | O(n log n) |

---

## 关键点总结

1. 先将有向友谊双向化，方便查找任意方向的友谊
2. 三方连接：朋友对 (x, y) + x 的朋友 + y 的朋友，找交集即共同朋友
3. 过滤掉 x 和 y 本身不算共同朋友

---

## 易错点

- `AND a1.friend_id != f.user1_id AND a1.friend_id != f.user2_id`：共同朋友不能是 x 或 y 本身
- `HAVING COUNT(*) >= 3`，不是 `> 3`
