## 题目描述

表 `Schools`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| school_id   | int     |
| capacity    | int     |
+-------------+---------+
school_id 是主键。capacity 表示学校最多接受的学生数。
```

表 `Exam`：
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| score       | int     |
| student_cnt | int     |
+-------------+---------+
score 是主键。student_cnt 表示分数 >= score 的学生数。
```

对每所学校，找出**最小的分数截止线**，使得分数 >= 截止线的学生数 <= 学校容量。若不存在（所有分数线学生数都超过容量），则截止线为 -1。

按 `school_id` 升序返回结果。

---

## 解题思路

### 核心思想：LEFT JOIN + 聚合取最小满足值

对每所学校，从 `Exam` 表找所有满足 `student_cnt <= capacity` 的分数，取最小分数（即最严格的截止线）。

用 `LEFT JOIN` + `MIN` 聚合，`LEFT JOIN` 保证没有满足条件的学校返回 NULL（映射为 -1）。

---

## 代码实现

### 方法一：LEFT JOIN + MIN（推荐）

```sql
SELECT
    s.school_id,
    COALESCE(MIN(e.score), -1) AS score
FROM Schools s
LEFT JOIN Exam e ON e.student_cnt <= s.capacity
GROUP BY s.school_id
ORDER BY s.school_id;
```

### 方法二：子查询版

```sql
SELECT
    school_id,
    COALESCE(
        (SELECT MIN(score)
         FROM Exam
         WHERE student_cnt <= capacity),
        -1
    ) AS score
FROM Schools
ORDER BY school_id;
```

### 方法三：使用 IFNULL

```sql
SELECT
    s.school_id,
    IFNULL(MIN(e.score), -1) AS score
FROM Schools s
LEFT JOIN Exam e ON e.student_cnt <= s.capacity
GROUP BY s.school_id
ORDER BY s.school_id;
```

---

## 复杂度分析

| 操作 | 说明 |
|------|------|
| LEFT JOIN | O(m * n)，m=学校数，n=考试分数数 |
| MIN 聚合 | O(k)，k 为每校满足条件的分数数 |

---

## 关键点总结

1. `LEFT JOIN ON student_cnt <= capacity`：对每所学校找所有满足容量的分数
2. `MIN(score)` 取最小截止线（最大范围，最宽松）
3. `COALESCE` 或 `IFNULL` 处理无满足条件时返回 -1

---

## 易错点

- 条件是 `student_cnt <= capacity`（学生数不超过容量），不是相等
- `LEFT JOIN` 而非 `INNER JOIN`，保证无满足条件的学校也出现在结果中
- 取 `MIN(score)` 而非 `MAX`（找最低截止线使容量满足）
