## 题目描述

表 `Scores`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student_id  | int     |
| subject     | varchar |
| score       | int     |
| exam_date   | varchar |
+-------------+---------+
```

`(student_id, subject, exam_date)` 是主键。`score` 在 0 到 100 之间。

找出在某个科目上有所进步的学生。学生在某科目上有进步，指的是该科目**最近一次考试**的分数**严格高于**该科目**最早一次考试**的分数。

返回满足条件的 `(student_id, subject)` 对，按 `student_id` 升序，再按 `subject` 升序排列。

**示例：**

输入：
```
+------------+---------+-------+------------+
| student_id | subject | score | exam_date  |
+------------+---------+-------+------------+
| 101        | Math    | 70    | 2023-01-15 |
| 101        | Math    | 85    | 2023-05-15 |
| 101        | Physics | 65    | 2023-01-15 |
| 101        | Physics | 60    | 2023-05-15 |
| 202        | Math    | 80    | 2023-01-15 |
| 202        | Math    | 85    | 2023-05-15 |
+------------+---------+-------+------------+
```

输出：
```
+------------+---------+
| student_id | subject |
+------------+---------+
| 101        | Math    |
| 202        | Math    |
+------------+---------+
```

**提示：**
- 每个学生在每个科目上可能有多次考试

## 解题思路

对每个 `(student_id, subject)` 组合：
1. 找最早考试的分数（按 `exam_date` 最小）
2. 找最近考试的分数（按 `exam_date` 最大）
3. 比较两次分数，若最近分数 > 最早分数，则满足条件

使用窗口函数或子查询实现。

## SQL 代码实现

### 方法一：使用 FIRST_VALUE / LAST_VALUE 窗口函数（推荐）

```sql
WITH ranked AS (
    SELECT
        student_id,
        subject,
        score,
        exam_date,
        FIRST_VALUE(score) OVER (
            PARTITION BY student_id, subject
            ORDER BY exam_date ASC
        ) AS first_score,
        FIRST_VALUE(score) OVER (
            PARTITION BY student_id, subject
            ORDER BY exam_date DESC
        ) AS last_score
    FROM Scores
)
SELECT DISTINCT student_id, subject
FROM ranked
WHERE last_score > first_score
ORDER BY student_id, subject;
```

### 方法二：使用 MIN/MAX 日期子查询

```sql
WITH first_last AS (
    SELECT
        student_id,
        subject,
        MIN(exam_date) AS first_date,
        MAX(exam_date) AS last_date
    FROM Scores
    GROUP BY student_id, subject
    HAVING MIN(exam_date) != MAX(exam_date)  -- 至少有两次考试
)
SELECT f.student_id, f.subject
FROM first_last f
JOIN Scores s1 ON s1.student_id = f.student_id
    AND s1.subject = f.subject
    AND s1.exam_date = f.first_date
JOIN Scores s2 ON s2.student_id = f.student_id
    AND s2.subject = f.subject
    AND s2.exam_date = f.last_date
WHERE s2.score > s1.score
ORDER BY f.student_id, f.subject;
```

### 方法三：使用聚合

```sql
SELECT
    student_id,
    subject
FROM (
    SELECT
        student_id,
        subject,
        -- 最早考试的分数
        MIN(CASE WHEN exam_date = min_date THEN score END) AS first_score,
        -- 最近考试的分数
        MIN(CASE WHEN exam_date = max_date THEN score END) AS last_score
    FROM (
        SELECT
            student_id,
            subject,
            score,
            exam_date,
            MIN(exam_date) OVER (PARTITION BY student_id, subject) AS min_date,
            MAX(exam_date) OVER (PARTITION BY student_id, subject) AS max_date
        FROM Scores
    ) t
    GROUP BY student_id, subject
) t2
WHERE last_score > first_score
ORDER BY student_id, subject;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和分组
- 空间复杂度：O(n)

## 关键点总结

1. 需要比较同一 (student_id, subject) 的最早和最近考试分数
2. 窗口函数 `FIRST_VALUE` 配合不同排序可获取首尾值
3. 若最早和最近日期相同（只考一次），不满足"有进步"条件

## 易错点

1. 同一日期可能有多次考试（理论上），但题目说 `(student_id, subject, exam_date)` 是主键，所以每个日期只有一次
2. 需要"严格大于"（not >=）
3. `HAVING MIN(exam_date) != MAX(exam_date)` 过滤只考了一次的情况
