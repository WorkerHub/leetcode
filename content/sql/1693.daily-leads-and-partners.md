## 题目描述

表：`DailySales`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| date_id     | date    |
| make_name   | varchar |
| lead_id     | int     |
| partner_id  | int     |
+-------------+---------+
该表没有主键，可能包含重复项。
date_id 和 make_name 的组合不一定唯一。
该表包含来自某汽车制造商每天的销售数据。
```

写一条 SQL 查询，返回每个 `date_id` 和 `make_name` 对应的**不同** `lead_id` 的数量和**不同** `partner_id` 的数量。

以**任意顺序**返回结果。

**示例：**
```
输入：
DailySales 表：
+-----------+-----------+---------+------------+
| date_id   | make_name | lead_id | partner_id |
+-----------+-----------+---------+------------+
| 2020-12-8 | toyota    | 0       | 1          |
| 2020-12-8 | toyota    | 1       | 0          |
| 2020-12-8 | toyota    | 1       | 2          |
| 2020-12-7 | toyota    | 0       | 2          |
| 2020-12-7 | toyota    | 0       | 1          |
| 2020-12-8 | honda     | 1       | 2          |
| 2020-12-8 | honda     | 2       | 1          |
| 2020-12-7 | honda     | 0       | 1          |
| 2020-12-7 | honda     | 1       | 2          |
| 2020-12-7 | honda     | 2       | 1          |
+-----------+-----------+---------+------------+

输出：
+-----------+-----------+--------------+-----------------+
| date_id   | make_name | unique_leads  | unique_partners |
+-----------+-----------+--------------+-----------------+
| 2020-12-8 | honda     | 2            | 2               |
| 2020-12-7 | honda     | 3            | 2               |
| 2020-12-8 | toyota    | 2            | 3               |
| 2020-12-7 | toyota    | 1            | 2               |
+-----------+-----------+--------------+-----------------+
```

## 解题思路

使用 `GROUP BY` 对 `date_id` 和 `make_name` 分组，然后用 `COUNT(DISTINCT ...)` 分别统计不重复的 `lead_id` 和 `partner_id` 数量。

## 代码实现

### 方法一：GROUP BY + COUNT DISTINCT（推荐）

```sql
SELECT
    date_id,
    make_name,
    COUNT(DISTINCT lead_id) AS unique_leads,
    COUNT(DISTINCT partner_id) AS unique_partners
FROM DailySales
GROUP BY date_id, make_name;
```

### 方法二：子查询方式（了解即可）

```sql
SELECT
    d1.date_id,
    d1.make_name,
    (SELECT COUNT(DISTINCT d2.lead_id)
     FROM DailySales d2
     WHERE d2.date_id = d1.date_id AND d2.make_name = d1.make_name) AS unique_leads,
    (SELECT COUNT(DISTINCT d3.partner_id)
     FROM DailySales d3
     WHERE d3.date_id = d1.date_id AND d3.make_name = d1.make_name) AS unique_partners
FROM DailySales d1
GROUP BY d1.date_id, d1.make_name;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，GROUP BY 需要排序或哈希分组
- **空间复杂度**：O(n)，存储分组中间结果

## 关键点总结

1. `COUNT(DISTINCT col)` 统计某列的不同值数量
2. 按多列 GROUP BY：`GROUP BY date_id, make_name`
3. 列别名：`AS unique_leads`，`AS unique_partners`

## 易错点

1. `COUNT(col)` 和 `COUNT(DISTINCT col)` 的区别：前者统计非 NULL 值，后者统计不重复的非 NULL 值
2. 多列分组时，所有非聚合列都必须出现在 GROUP BY 子句中
