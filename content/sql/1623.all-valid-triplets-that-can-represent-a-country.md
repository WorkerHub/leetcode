## 题目描述

表：`SchoolA`
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
```

表：`SchoolB`（结构同上）

表：`SchoolC`（结构同上）

每个表有一个唯一的学生 ID 和名字。

找出所有**有效的三元组**（每个学校各出一名学生），表示这三个学生可以代表一个国家参加比赛：
- 三个学生**两两不同名**

返回所有满足条件的三元组，顺序不限。

**示例：**
```
输入：
SchoolA: (1, Alice), (2, Bob)
SchoolB: (3, Bob), (4, Charlie)
SchoolC: (5, Alice), (6, Dave)

输出：
(Alice, Charlie, Dave)  -- Alice, Charlie, Dave 互不同名，但 Alice 在 A 和 C 都有... 需细看
实际：找 a.name != b.name AND b.name != c.name AND a.name != c.name
```

## 解题思路

三表笛卡尔积，加上三个名字互不相同的条件。

## 代码实现

### 方法一：CROSS JOIN（推荐）

```sql
SELECT
    a.student_name AS member_A,
    b.student_name AS member_B,
    c.student_name AS member_C
FROM SchoolA a
CROSS JOIN SchoolB b
CROSS JOIN SchoolC c
WHERE a.student_name != b.student_name
  AND b.student_name != c.student_name
  AND a.student_name != c.student_name;
```

### 方法二：隐式笛卡尔积

```sql
SELECT
    a.student_name AS member_A,
    b.student_name AS member_B,
    c.student_name AS member_C
FROM SchoolA a, SchoolB b, SchoolC c
WHERE a.student_name <> b.student_name
  AND b.student_name <> c.student_name
  AND a.student_name <> c.student_name;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| CROSS JOIN | 三表笛卡尔积，行数为 |A| * |B| * |C|，过滤重名三元组 |

## 关键点总结

1. 三表笛卡尔积（CROSS JOIN）枚举所有组合
2. 三个互不相同名的条件：A≠B、B≠C、A≠C（三个条件都需要）
3. `!=` 和 `<>` 在 SQL 中等价

## 易错点

- 条件必须是三对：`a!=b`、`b!=c`、`a!=c`，缺少任何一对都不完整
- `CROSS JOIN` 不需要 `ON` 子句
