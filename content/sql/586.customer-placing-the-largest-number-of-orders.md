## 题目描述

查询下了最多订单的客户编号。

## SQL 代码实现

```sql
SELECT customer_number
FROM Orders
GROUP BY customer_number
ORDER BY COUNT(*) DESC
LIMIT 1;
```

## 关键点总结

1. **分组计数**：GROUP BY + COUNT(*)
2. **排序取最大**：ORDER BY DESC + LIMIT 1

## 学习建议

掌握聚合函数和排序的组合使用。
