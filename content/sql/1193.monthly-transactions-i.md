## 题目描述

表：`Transactions`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| country       | varchar |
| state         | enum    |
| amount        | int     |
| trans_date    | date    |
+---------------+---------+
```

- `id` 是这个表的主键。
- 该表包含有关传入事务的信息。
- `state` 列类型为 `["approved", "declined"]` 之一。

编写一个 SQL 查询来查找每个月和每个国家/地区的事务数及其总金额、已批准的事务数及其总金额。

以任意顺序返回结果表。

查询结果格式如下所示。

**示例 1：**

输入：
```
Transactions table:
+------+---------+----------+--------+------------+
| id   | country | state    | amount | trans_date |
+------+---------+----------+--------+------------+
| 121  | US      | approved | 1000   | 2018-12-18 |
| 122  | US      | declined | 2000   | 2018-12-19 |
| 123  | US      | approved | 2000   | 2019-01-01 |
| 124  | DE      | approved | 2000   | 2019-01-07 |
+------+---------+----------+--------+------------+
```

输出：
```
+----------+---------+-------------+----------------+--------------------+-----------------------+
| month    | country | trans_count | approved_count | trans_total_amount | approved_total_amount |
+----------+---------+-------------+----------------+--------------------+-----------------------+
| 2018-12  | US      | 2           | 1              | 3000               | 1000                  |
| 2019-01  | US      | 1           | 1              | 2000               | 2000                  |
| 2019-01  | DE      | 1           | 1              | 2000               | 2000                  |
+----------+---------+-------------+----------------+--------------------+-----------------------+
```

## 解题思路

这是一道经典的 SQL 分组聚合题目，需要按月份和国家进行分组统计。

**核心思路：**

1. **提取月份**：使用 `DATE_FORMAT()` 函数将日期转换为年-月格式。

2. **分组聚合**：按月份和国家分组，计算各项指标。

3. **条件聚合**：
   - 使用 `COUNT(*)` 计算总事务数
   - 使用 `SUM(amount)` 计算总金额
   - 使用 `COUNT(IF(...))` 或 `SUM(CASE WHEN ...)` 计算已批准的事务数和金额

4. **关键函数**：
   - `DATE_FORMAT(date, '%Y-%m')`：提取年月
   - `COUNT(IF(condition, 1, NULL))`：条件计数
   - `SUM(CASE WHEN condition THEN amount ELSE 0 END)`：条件求和

## SQL 代码实现

### 方法一：使用 IF 函数（推荐）⭐

```sql
SELECT 
    DATE_FORMAT(trans_date, '%Y-%m') AS month,
    country,
    COUNT(*) AS trans_count,
    COUNT(IF(state = 'approved', 1, NULL)) AS approved_count,
    SUM(amount) AS trans_total_amount,
    SUM(IF(state = 'approved', amount, 0)) AS approved_total_amount
FROM 
    Transactions
GROUP BY 
    DATE_FORMAT(trans_date, '%Y-%m'), 
    country;
```

### 方法二：使用 CASE WHEN

```sql
SELECT 
    DATE_FORMAT(trans_date, '%Y-%m') AS month,
    country,
    COUNT(*) AS trans_count,
    SUM(CASE WHEN state = 'approved' THEN 1 ELSE 0 END) AS approved_count,
    SUM(amount) AS trans_total_amount,
    SUM(CASE WHEN state = 'approved' THEN amount ELSE 0 END) AS approved_total_amount
FROM 
    Transactions
GROUP BY 
    DATE_FORMAT(trans_date, '%Y-%m'), 
    country;
```

### 方法三：使用子查询

```sql
SELECT 
    month,
    country,
    trans_count,
    approved_count,
    trans_total_amount,
    approved_total_amount
FROM (
    SELECT 
        DATE_FORMAT(trans_date, '%Y-%m') AS month,
        country,
        COUNT(*) AS trans_count,
        COUNT(IF(state = 'approved', 1, NULL)) AS approved_count,
        SUM(amount) AS trans_total_amount,
        SUM(IF(state = 'approved', amount, 0)) AS approved_total_amount
    FROM 
        Transactions
    GROUP BY 
        DATE_FORMAT(trans_date, '%Y-%m'), 
        country
) AS monthly_stats;
```

### 方法四：使用 LEFT 函数（简化版）

```sql
SELECT 
    LEFT(trans_date, 7) AS month,
    country,
    COUNT(*) AS trans_count,
    COUNT(IF(state = 'approved', 1, NULL)) AS approved_count,
    SUM(amount) AS trans_total_amount,
    SUM(IF(state = 'approved', amount, 0)) AS approved_total_amount
FROM 
    Transactions
GROUP BY 
    LEFT(trans_date, 7), 
    country;
```

## 关键点总结

1. **日期格式化**：`DATE_FORMAT(date, '%Y-%m')` 或 `LEFT(date, 7)` 提取年月
2. **条件计数**：`COUNT(IF(condition, 1, NULL))` 只统计满足条件的行
3. **条件求和**：`SUM(IF(condition, value, 0))` 只累加满足条件的值
4. **GROUP BY 顺序**：必须与 SELECT 中的非聚合列一致
5. **聚合函数**：COUNT、SUM 等聚合函数用于统计

## 易错点

1. **日期格式错误**：必须输出 `YYYY-MM` 格式，不能包含日期
2. **条件计数错误**：使用 `COUNT(IF(...))` 时，false 情况必须返回 NULL 而非 0
3. **GROUP BY 遗漏**：忘记在 GROUP BY 中包含所有非聚合列
4. **NULL 处理**：未批准的金额应该累加为 0，不是 NULL
5. **函数在 GROUP BY 中的使用**：MySQL 允许在 GROUP BY 中使用函数

## 不同数据库的写法差异

### MySQL
```sql
-- 使用 DATE_FORMAT
DATE_FORMAT(trans_date, '%Y-%m')
```

### PostgreSQL
```sql
-- 使用 TO_CHAR
TO_CHAR(trans_date, 'YYYY-MM')
```

### SQL Server
```sql
-- 使用 FORMAT
FORMAT(trans_date, 'yyyy-MM')
```

### Oracle
```sql
-- 使用 TO_CHAR
TO_CHAR(trans_date, 'YYYY-MM')
```
