## 题目描述

编写一个 SQL 查询来交换所有的 `'f'` 和 `'m'` 值（即，将所有 `'f'` 值更改为 `'m'`，反之亦然），仅使用**单个 UPDATE 语句**，且不使用中间临时表。

注意，你必须仅使用一条 UPDATE 语句，且不能使用 SELECT 语句。

表：`Salary`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| id          | int      |
| name        | varchar  |
| sex         | ENUM     |
| salary      | int      |
+-------------+----------+
id 是该表的主键。
sex 列是 ENUM 类型，只能取 ('m', 'f') 之一。
该表包含公司员工的信息。
```

**示例 1：**

```
输入：
Salary 表：
+----+------+-----+--------+
| id | name | sex | salary |
+----+------+-----+--------+
| 1  | A    | m   | 2500   |
| 2  | B    | f   | 1500   |
| 3  | C    | m   | 5500   |
| 4  | D    | f   | 500    |
+----+------+-----+--------+

输出：
+----+------+-----+--------+
| id | name | sex | salary |
+----+------+-----+--------+
| 1  | A    | f   | 2500   |
| 2  | B    | m   | 1500   |
| 3  | C    | f   | 5500   |
| 4  | D    | m   | 500    |
+----+------+-----+--------+

解释：
(1, A) 和 (3, C) 从 'm' 变成了 'f'。
(2, B) 和 (4, D) 从 'f' 变成了 'm'。
```

## 解题思路

这道题的挑战在于**只能使用一条 UPDATE 语句**来交换两个不同的值。

**关键观察：**
- 不能先更新所有 'm' 为 'f'，再更新所有 'f' 为 'm'（这需要两条语句）
- 不能使用临时值（如先把 'm' 改为 'temp'）

**解决方案：**

1. **CASE WHEN**：在一条 UPDATE 语句中使用条件逻辑
   - 如果当前是 'm'，改为 'f'
   - 如果当前是 'f'，改为 'm'

2. **IF 函数**（MySQL）：使用 `IF(condition, true_value, false_value)`

3. **CHAR 函数**：利用 ASCII 码值的技巧

4. **XOR 位运算**：利用 'm' 和 'f' 的 ASCII 码差异

## SQL 解法实现

### 方法一：使用 CASE WHEN（推荐，标准 SQL）

```sql
UPDATE Salary
SET sex = CASE 
            WHEN sex = 'm' THEN 'f'
            ELSE 'm'
          END;
```

**解释：**
- 单条 UPDATE 语句
- CASE WHEN 为每一行计算新值
- 如果是 'm' 则改为 'f'，否则改为 'm'
- 所有更新在一个事务中完成，避免了中间状态

### 方法二：使用 IF 函数（MySQL）

```sql
UPDATE Salary
SET sex = IF(sex = 'm', 'f', 'm');
```

**解释：**
- `IF(条件, 真值, 假值)` 是 MySQL 的函数
- 如果 sex = 'm'，返回 'f'
- 否则返回 'm'
- 代码更简洁

### 方法三：使用 CHAR 和 ASCII（技巧性强）

```sql
UPDATE Salary
SET sex = CHAR(ASCII('m') + ASCII('f') - ASCII(sex));
```

**解释：**
- ASCII('m') = 109
- ASCII('f') = 102
- ASCII('m') + ASCII('f') = 211
- 如果 sex = 'm'：211 - 109 = 102 = 'f'
- 如果 sex = 'f'：211 - 102 = 109 = 'm'
- 利用数学技巧，但可读性较差

### 方法四：使用 XOR（位运算）

```sql
UPDATE Salary
SET sex = CHAR(ASCII(sex) ^ ASCII('m') ^ ASCII('f'));
```

**解释：**
- XOR 运算的性质：A ^ B ^ A = B
- 如果 sex = 'm'：109 ^ 109 ^ 102 = 102 = 'f'
- 如果 sex = 'f'：102 ^ 109 ^ 102 = 109 = 'm'

### 方法五：使用 REPLACE（不推荐）

```sql
-- 这个方法不符合题意，因为需要中间临时值
-- 仅作为错误示例
UPDATE Salary SET sex = 'temp' WHERE sex = 'm';
UPDATE Salary SET sex = 'm' WHERE sex = 'f';
UPDATE Salary SET sex = 'f' WHERE sex = 'temp';
```

**注意：** 这需要 3 条 UPDATE 语句，不符合题目要求。

## 复杂度分析

**SQL 方法：**
- 时间复杂度：O(n)，n 是表中的行数，需要更新每一行
- 空间复杂度：O(1)，原地更新，不需要额外空间

**Python 实现：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)（pandas 的 replace 可能创建副本）

## 图解示例

```
更新前：
id | name | sex | salary
1  | A    | m   | 2500
2  | B    | f   | 1500
3  | C    | m   | 5500
4  | D    | f   | 500

执行 UPDATE Salary SET sex = CASE WHEN sex = 'm' THEN 'f' ELSE 'm' END

处理过程（概念上同时发生）：
行1: sex = 'm' → CASE 判断为真 → 设置为 'f'
行2: sex = 'f' → CASE 判断为假 → 设置为 'm'
行3: sex = 'm' → CASE 判断为真 → 设置为 'f'
行4: sex = 'f' → CASE 判断为假 → 设置为 'm'

更新后：
id | name | sex | salary
1  | A    | f   | 2500
2  | B    | m   | 1500
3  | C    | f   | 5500
4  | D    | m   | 500
```

## 关键点总结

1. **单条 UPDATE**：CASE WHEN 或 IF 可以在一条语句中实现条件更新
2. **原子操作**：UPDATE 语句是原子的，不会出现中间状态
3. **避免临时值**：不需要使用第三个临时值来交换
4. **数据库差异**：IF 是 MySQL 特有的，CASE WHEN 是标准 SQL
5. **可读性优先**：虽然 ASCII 技巧很巧妙，但 CASE WHEN 更易读

## 易错点

1. **使用两条 UPDATE**：先更新 'm' 为 'f'，会导致所有值都变成 'f'
   ```sql
   -- 错误示例
   UPDATE Salary SET sex = 'f' WHERE sex = 'm';  -- 所有 m 变 f
   UPDATE Salary SET sex = 'm' WHERE sex = 'f';  -- 所有 f（包括刚变的）又变 m
   ```

2. **忘记 ELSE 分支**：CASE WHEN 要处理所有情况
   ```sql
   -- 错误示例
   UPDATE Salary SET sex = CASE WHEN sex = 'm' THEN 'f' END;
   -- 会导致 sex='f' 的行变成 NULL
   ```

3. **使用 SELECT**：题目要求只用 UPDATE，不能用 SELECT
   
4. **中间临时表**：不能创建临时表辅助交换

## 学习建议

1. **掌握 CASE WHEN**：这是 SQL 中最重要的条件逻辑结构
   ```sql
   CASE
       WHEN condition1 THEN result1
       WHEN condition2 THEN result2
       ELSE default_result
   END
   ```

2. **理解 UPDATE 机制**：UPDATE 语句的执行是原子的，先读取所有旧值，再统一更新

3. **MySQL 特性**：IF 函数只在 MySQL 中可用，写通用 SQL 用 CASE WHEN

4. **技巧 vs 可读性**：ASCII 技巧虽然巧妙，但实际工作中优先考虑代码可读性

5. **练习变体**：
   - 交换三个值（如 'A' → 'B' → 'C' → 'A'）
   - 条件交换（只交换满足某条件的行）
   - 批量更新多个字段
