## 题目描述

学校有三个数据表：

**Students 表**
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
student_id 是该表的主键
```

**Subjects 表**
```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| subject_name | varchar |
+--------------+---------+
subject_name 是该表的主键
```

**Examinations 表**
```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| student_id   | int     |
| subject_name | varchar |
+--------------+---------+
该表没有主键，可能有重复行
每行代表一个学生参加了一次某科目的考试
```

查询每个学生参加每门科目考试的次数，结果需要包含**所有学生**和**所有科目的组合**（即使次数为0）。

结果按 `student_id` 和 `subject_name` 排序。

**示例：**

Students 表：
```
+------------+--------------+
| student_id | student_name |
+------------+--------------+
| 1          | Alice        |
| 2          | Bob          |
| 13         | John         |
| 6          | Alex         |
+------------+--------------+
```

Subjects 表：
```
+--------------+
| subject_name |
+--------------+
| Math         |
| Physics      |
| Programming  |
+--------------+
```

Examinations 表：
```
+------------+--------------+
| student_id | subject_name |
+------------+--------------+
| 1          | Math         |
| 1          | Physics      |
| 1          | Programming  |
| 2          | Programming  |
| 1          | Physics      |
| 1          | Math         |
| 13         | Math         |
| 13         | Programming  |
| 13         | Physics      |
| 2          | Math         |
| 1          | Math         |
+------------+--------------+
```

输出：
```
+------------+--------------+--------------+----------------+
| student_id | student_name | subject_name | attended_exams |
+------------+--------------+--------------+----------------+
| 1          | Alice        | Math         | 3              |
| 1          | Alice        | Physics      | 2              |
| 1          | Alice        | Programming  | 1              |
| 2          | Bob          | Math         | 1              |
| 2          | Bob          | Physics      | 0              |
| 2          | Bob          | Programming  | 1              |
| 6          | Alex         | Math         | 0              |
| 6          | Alex         | Physics      | 0              |
| 6          | Alex         | Programming  | 0              |
| 13         | John         | Math         | 1              |
| 13         | John         | Physics      | 1              |
| 13         | John         | Programming  | 1              |
+------------+--------------+--------------+----------------+
```

## 解题思路

**核心问题：** 需要列出所有学生和所有科目的**笛卡尔积**（每个学生对应每门课），然后统计考试次数（允许次数为0）。

**分步分析：**

**第一步：** 生成所有 (student, subject) 组合  
用 `CROSS JOIN`（交叉连接）把 Students 表和 Subjects 表连接起来，生成所有可能的 (student_id, subject_name) 组合。

```
Students × Subjects = 4 学生 × 3 科目 = 12 行
```

**第二步：** 统计每个 (student, subject) 组合在 Examinations 中的出现次数  
用 `GROUP BY` 对 Examinations 表按 (student_id, subject_name) 分组，用 `COUNT` 统计行数。

**第三步：** 用 LEFT JOIN 关联两步结果  
用 `LEFT JOIN` 将第一步的结果（全部组合）与第二步的结果（有记录的考试）连接，没有考试记录的用 `COALESCE` 填充为 0。

**为什么用 LEFT JOIN 而不是 INNER JOIN？**
- INNER JOIN 只保留两表都有的记录，会丢失次数为 0 的组合
- LEFT JOIN 保留左表（全部组合）的所有记录，右表没有匹配时返回 NULL，再用 COALESCE 转为 0

## SQL 解法

### 方法一：CROSS JOIN + LEFT JOIN（推荐，标准写法）

```sql
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    COALESCE(e.attended_exams, 0) AS attended_exams
FROM Students s
-- 交叉连接：生成所有学生和科目的组合（笛卡尔积）
CROSS JOIN Subjects sub
-- 左连接：关联考试记录（允许次数为0）
LEFT JOIN (
    -- 子查询：统计每个学生每门课的考试次数
    SELECT student_id, subject_name, COUNT(*) AS attended_exams
    FROM Examinations
    GROUP BY student_id, subject_name
) e ON s.student_id = e.student_id AND sub.subject_name = e.subject_name
-- 按学生ID和科目名排序
ORDER BY s.student_id, sub.subject_name;
```

### 方法二：直接 LEFT JOIN（不使用子查询）

```sql
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.student_id) AS attended_exams  -- COUNT 字段值而非*，NULL不计数
FROM Students s
CROSS JOIN Subjects sub
-- 直接左连接 Examinations 表
LEFT JOIN Examinations e
    ON s.student_id = e.student_id
    AND sub.subject_name = e.subject_name
-- 注意：分组要包含 SELECT 中所有非聚合字段
GROUP BY s.student_id, s.student_name, sub.subject_name
ORDER BY s.student_id, sub.subject_name;
```

**方法二的技巧说明：**  
`COUNT(e.student_id)` 统计非 NULL 值的数量。当 LEFT JOIN 没有匹配时，`e.student_id` 为 NULL，`COUNT(NULL) = 0`，刚好符合需求，不需要 `COALESCE`。

### 方法三：使用 WHERE + 子查询（避免 CROSS JOIN 的写法）

```sql
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    (
        -- 相关子查询：统计该学生该科目的考试次数
        SELECT COUNT(*)
        FROM Examinations e
        WHERE e.student_id = s.student_id
          AND e.subject_name = sub.subject_name
    ) AS attended_exams
FROM Students s, Subjects sub  -- 隐式 CROSS JOIN
ORDER BY s.student_id, sub.subject_name;
```

**注意：** 方法三的相关子查询对每行都要执行一次，性能较差，不推荐在大数据量下使用。

### 方法四：MySQL 8.0+ 窗口函数写法

```sql
-- 方法2的等价写法，更符合现代 SQL 风格
WITH all_combinations AS (
    -- CTE：生成所有学生-科目组合
    SELECT s.student_id, s.student_name, sub.subject_name
    FROM Students s
    CROSS JOIN Subjects sub
),
exam_counts AS (
    -- CTE：统计每个学生每门课的考试次数
    SELECT student_id, subject_name, COUNT(*) AS cnt
    FROM Examinations
    GROUP BY student_id, subject_name
)
SELECT
    ac.student_id,
    ac.student_name,
    ac.subject_name,
    COALESCE(ec.cnt, 0) AS attended_exams
FROM all_combinations ac
LEFT JOIN exam_counts ec
    ON ac.student_id = ec.student_id
    AND ac.subject_name = ec.subject_name
ORDER BY ac.student_id, ac.subject_name;
```

## 复杂度分析

设 S = 学生数量，C = 科目数量，E = 考试记录数量

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| CROSS JOIN + LEFT JOIN | O(S*C + E) | O(S*C) |
| 直接 LEFT JOIN + GROUP BY | O(S*C + E) | O(S*C) |
| 相关子查询 | O(S*C*E) | O(1) |

## 关键点总结

1. **CROSS JOIN 生成全集**：要包含次数为0的情况，必须先生成所有 (学生, 科目) 的组合
2. **LEFT JOIN 保留左表**：LEFT JOIN 确保即使没有考试记录，该组合也保留在结果中
3. **COUNT 的选择**：`COUNT(*)` 计所有行包括 NULL，`COUNT(列名)` 只计非 NULL 行，方法二利用了这一差异
4. **COALESCE 处理 NULL**：`COALESCE(expr, 0)` 当 expr 为 NULL 时返回 0
5. **GROUP BY 完整性**：SELECT 中所有非聚合字段都必须出现在 GROUP BY 中（方法二中包括 student_name）

## 易错点

1. **使用 INNER JOIN 丢失次数为0的行**：INNER JOIN 只保留两表都有的行，必须用 LEFT JOIN
2. **忘记处理 NULL**：LEFT JOIN 后没有匹配的行会返回 NULL，要用 COALESCE 或 COUNT(列名) 处理
3. **GROUP BY 字段不完整**：方法二中必须 GROUP BY 所有非聚合字段（student_id, student_name, subject_name）
4. **排序字段**：题目要求按 student_id 然后 subject_name 排序，不能只排一个
5. **ON 条件两个字段**：LEFT JOIN Examinations 时需要同时匹配 student_id 和 subject_name，缺一不可

## 关键 SQL 概念解释

**CROSS JOIN（交叉连接/笛卡尔积）：**
```sql
-- 等价写法：
SELECT * FROM A CROSS JOIN B;
SELECT * FROM A, B;  -- 隐式CROSS JOIN（逗号分隔）
```
结果行数 = A 的行数 × B 的行数，每行 A 的记录与每行 B 的记录配对。

**LEFT JOIN 与 COALESCE：**
```sql
-- 无匹配时 b.val 为 NULL
SELECT a.id, COALESCE(b.val, 0)
FROM a LEFT JOIN b ON a.id = b.id;
-- COALESCE(expr1, expr2) 返回第一个非 NULL 的值
```

## 学习建议

1. **JOIN 类型**：先彻底理解 INNER JOIN、LEFT JOIN、RIGHT JOIN、CROSS JOIN 的区别
2. **CROSS JOIN 场景**：当需要"所有可能的组合"时，CROSS JOIN 是标准解法
3. **NULL 处理**：SQL 中 NULL 是特殊值，`COUNT(NULL) = 0`，`NULL = NULL` 为 false，要用 IS NULL 判断

5. **GROUP BY 与聚合**：理解 GROUP BY 的本质——将相同键的多行合并为一行，聚合函数（COUNT/SUM/AVG）对这一组行进行计算
