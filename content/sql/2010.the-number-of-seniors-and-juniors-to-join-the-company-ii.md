## 题目描述

本题是 [2004. 职员招募](https://leetcode.com/problems/the-number-of-seniors-and-juniors-to-join-the-company/) 的进阶版本。

表结构与 2004 题相同，但需要返回**每种 experience 的录用人数**（而不是员工列表）。

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| employee_id | int  |
| experience  | enum |
| salary      | int  |
+-------------+------+
```

录用规则与 2004 题相同：
1. 先按薪资从低到高录用高级员工，直到累计薪资超过 70000
2. 剩余预算用于录用初级员工

返回表包含两列：`experience`（Senior / Junior）和 `accepted_candidates`（录用人数）。

**示例输出：**
```
+------------+--------------------+
| experience | accepted_candidates|
+------------+--------------------+
| Senior     | 2                  |
| Junior     | 2                  |
+------------+--------------------+
```

## 解题思路

与 2004 题解法相似，但这里需要统计人数。使用窗口函数计算累计薪资，确定截止点，再统计数量。

## 代码实现

### 方法一：窗口函数 + CTE（推荐）

```sql
WITH senior_cte AS (
    SELECT
        employee_id,
        salary,
        SUM(salary) OVER (ORDER BY salary ASC) AS cum_salary
    FROM Candidates
    WHERE experience = 'Senior'
),
junior_cte AS (
    SELECT
        employee_id,
        salary,
        SUM(salary) OVER (ORDER BY salary ASC) AS cum_salary
    FROM Candidates
    WHERE experience = 'Junior'
),
-- 录用的高级员工数及其消耗的预算
senior_stats AS (
    SELECT
        COUNT(*) AS senior_count,
        COALESCE(SUM(salary), 0) AS senior_budget
    FROM senior_cte
    WHERE cum_salary <= 70000
)
SELECT 'Senior' AS experience,
       (SELECT senior_count FROM senior_stats) AS accepted_candidates
UNION ALL
SELECT 'Junior' AS experience,
       COUNT(*) AS accepted_candidates
FROM junior_cte j
CROSS JOIN senior_stats s
WHERE j.cum_salary <= 70000 - s.senior_budget
```

### 方法二：子查询统计方式

```sql
WITH ranked AS (
    SELECT
        employee_id,
        experience,
        salary,
        SUM(salary) OVER (PARTITION BY experience ORDER BY salary) AS cum_sal
    FROM Candidates
),
budget AS (
    SELECT COALESCE(SUM(salary), 0) AS used
    FROM ranked
    WHERE experience = 'Senior' AND cum_sal <= 70000
)
SELECT 'Senior' AS experience,
       COUNT(*) AS accepted_candidates
FROM ranked, budget
WHERE experience = 'Senior' AND cum_sal <= 70000

UNION ALL

SELECT 'Junior' AS experience,
       COUNT(*) AS accepted_candidates
FROM ranked, budget
WHERE experience = 'Junior' AND cum_sal <= 70000 - budget.used
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和窗口函数
- 空间复杂度：O(n)，中间 CTE 结果

## 关键点总结

1. 窗口函数 `SUM() OVER (PARTITION BY experience ORDER BY salary)` 分组计算累计薪资
2. 先确定高级员工录用数量和总薪资，再计算剩余预算
3. 使用 `UNION ALL` 合并两类结果
4. 即使某类员工数为 0，也需要在结果中输出（返回 0）

## 易错点

- 当没有高级员工被录用时，剩余预算仍是 70000，不是 NULL
- 注意结果中两种 experience 都需要输出，即使录用数为 0
- `COALESCE` 处理 `SUM` 为 NULL 的情况（没有满足条件的行时 SUM 返回 NULL）
