## 题目描述

表 `Patients`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| patient_id  | int     |
| patient_name| varchar |
| test_date   | date    |
| result      | varchar |
+-------------+---------+
(patient_id, test_date) 是主键。
result 为 'Positive' 或 'Negative'。
```

找出所有"新冠康复患者"：这些患者曾经检测阳性，且在阳性检测之后又有检测阴性的记录。返回这些患者的 patient_id 和 patient_name，按 patient_id 升序排列。

**示例：**

```
输入：
patient_id | patient_name | test_date  | result
1          | Alice        | 2023-01-01 | Positive
1          | Alice        | 2023-01-15 | Negative
2          | Bob          | 2023-02-01 | Positive
3          | Charlie      | 2023-03-01 | Negative

输出：
patient_id | patient_name
1          | Alice
```

## 解题思路

找出同时满足以下条件的患者：
1. 有阳性记录
2. 在阳性记录**之后**有阴性记录

使用自连接或相关子查询。

## 代码实现

### 方法一：自连接（推荐）

```sql
SELECT DISTINCT p1.patient_id, p1.patient_name
FROM Patients p1
JOIN Patients p2
    ON p1.patient_id = p2.patient_id
    AND p1.result = 'Positive'
    AND p2.result = 'Negative'
    AND p2.test_date > p1.test_date
ORDER BY p1.patient_id;
```

### 方法二：子查询

```sql
SELECT DISTINCT patient_id, patient_name
FROM Patients p1
WHERE result = 'Positive'
    AND EXISTS (
        SELECT 1
        FROM Patients p2
        WHERE p2.patient_id = p1.patient_id
            AND p2.result = 'Negative'
            AND p2.test_date > p1.test_date
    )
ORDER BY patient_id;
```

## 复杂度分析

- 时间复杂度：O(n^2)（自连接），可用索引优化
- 空间复杂度：O(n)

## 关键点总结

1. 阴性检测必须在阳性检测**之后**（`test_date >` 条件）
2. 使用 `DISTINCT` 避免一个患者被重复统计
3. 自连接时在 `patient_id` 上连接，比较 result 和 test_date

## 易错点

1. 必须确认阴性在阳性之后（不是任意阴性就算康复）
2. `DISTINCT` 是必要的，因为同一患者可能有多次阳性或多次阴性
3. 按 patient_id 升序排列（不是按 test_date）
