## 题目描述

表 `Flights`（`flight_id`, `capacity`）和表 `Passengers`（`passenger_id`, `flight_id`, `boarding_time`）。

对每位乘客，确定其状态：
- 若当前乘客按 `boarding_time` 排名（在同一航班中）<= `capacity`，状态为 `'Confirmed'`
- 否则状态为 `'Waitlist'`

返回所有乘客的 `passenger_id`、`flight_id` 和 `Status`，按 `passenger_id` 升序。

## 解题思路

1. 用 `ROW_NUMBER` 按 boarding_time 对每个航班的乘客排名
2. 与 Flights 表 JOIN 获取 capacity
3. 根据排名与容量比较确定状态

## 代码实现

### 方法一：SQL 窗口函数（推荐）

```sql
WITH ranked AS (
    SELECT
        p.passenger_id,
        p.flight_id,
        p.boarding_time,
        ROW_NUMBER() OVER (PARTITION BY p.flight_id ORDER BY p.boarding_time) AS rn,
        f.capacity
    FROM Passengers p
    JOIN Flights f ON p.flight_id = f.flight_id
)
SELECT
    passenger_id,
    flight_id,
    CASE WHEN rn <= capacity THEN 'Confirmed' ELSE 'Waitlist' END AS Status
FROM ranked
ORDER BY passenger_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，窗口函数排序
- 空间复杂度：O(n)

## 关键点总结

1. `ROW_NUMBER` 按 boarding_time 排名（越早越优先）
2. 排名 <= capacity 为已确认，否则为候补

## 易错点

1. 同一航班内按 boarding_time 排序（越早排名越靠前）
2. `ROW_NUMBER` 不考虑并列（每人唯一排名）
