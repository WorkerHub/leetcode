## 题目描述

表 `Students` 结构如下：

| Column Name  | Type    |
|--------------|---------|
| student_id   | int     |
| department_id| int     |
| mark         | int     |

`student_id` 是该表的主键。

查询每个学生在其系中的**百分比排名**（Percentage Rank）：
`percentage_rank = (rank - 1) / (total_students_in_dept - 1) * 100`（保留两位小数）

若该系只有一个学生，则 percentage_rank 为 0。

按 `student_id` 升序返回结果。

返回列：`student_id`、`department_id`、`percentage_rank`。

## 解题思路

使用窗口函数 `RANK()` 或 `PERCENT_RANK()` 计算百分比排名。`PERCENT_RANK()` 直接给出 `(rank - 1) / (total - 1)` 的值，乘以 100 即可。

## 代码实现

### 方法一：PERCENT_RANK 窗口函数（推荐）

```sql
SELECT 
    student_id,
    department_id,
    ROUND(
        PERCENT_RANK() OVER (
            PARTITION BY department_id 
            ORDER BY mark DESC
        ) * 100,
        2
    ) AS percentage_rank
FROM Students
ORDER BY student_id
```

### 方法二：手动计算排名和总数

```sql
SELECT 
    student_id,
    department_id,
    ROUND(
        (RANK() OVER (PARTITION BY department_id ORDER BY mark DESC) - 1) /
        (COUNT(*) OVER (PARTITION BY department_id) - 1) * 100,
        2
    ) AS percentage_rank
FROM Students
ORDER BY student_id
```

注意：当一个系只有 1 个学生时，分母为 0，需要处理。

```sql
SELECT 
    student_id,
    department_id,
    ROUND(
        CASE 
            WHEN COUNT(*) OVER (PARTITION BY department_id) = 1 THEN 0
            ELSE (RANK() OVER (PARTITION BY department_id ORDER BY mark DESC) - 1) /
                 (COUNT(*) OVER (PARTITION BY department_id) - 1) * 100
        END,
        2
    ) AS percentage_rank
FROM Students
ORDER BY student_id
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| PERCENT_RANK | O(n log n) | O(n) |

## 关键点总结

1. `PERCENT_RANK()` 计算公式为 `(rank - 1) / (rows - 1)`，范围 [0, 1]。
2. 只有一个学生时 PERCENT_RANK 自动返回 0，无需额外处理。
3. 用 `ROUND(..., 2)` 保留两位小数。

## 易错点

- 分母为 0（只有一个学生时）需要用 `PERCENT_RANK()` 或 `CASE WHEN` 处理。
- 成绩相同的学生排名相同（RANK 跳过），PERCENT_RANK 反映最后一个相同排名的百分位。
