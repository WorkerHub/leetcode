## 题目描述

`Users` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| name          | varchar |
+---------------+---------+
```

`id` 是该表主键。`name` 是用户名字，该列值不会为 NULL。

`Rides` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| user_id       | int     |
| distance      | int     |
+---------------+---------+
```

`id` 是该表主键。

编写 SQL 语句，报告每位用户的旅途距离。

返回结果表，按 `travelled_distance` 降序排列，如果有两个或更多的用户旅途距离相同，那么再按照他们的 `name` 升序排列。

**示例：**

```
输入：
Users 表:
+------+-----------+
| id   | name      |
+------+-----------+
| 1    | Alice     |
| 2    | Bob       |
| 3    | Alex      |
| 4    | Donald    |
| 7    | Lee       |
| 13   | Jonathan  |
| 19   | Elvis     |
+------+-----------+

Rides 表:
+------+----------+----------+
| id   | user_id  | distance |
+------+----------+----------+
| 1    | 1        | 120      |
| 2    | 2        | 317      |
| 3    | 3        | 222      |
| 4    | 7        | 100      |
| 5    | 13       | 312      |
| 6    | 19       | 50       |
| 7    | 7        | 120      |
| 8    | 19       | 400      |
| 9    | 7        | 230      |
+------+----------+----------+

输出：
+----------+--------------------+
| name     | travelled_distance |
+----------+--------------------+
| Elvis    | 450                |
| Lee      | 450                |
| Bob      | 317                |
| Jonathan | 312                |
| Alex     | 222                |
| Alice    | 120                |
| Donald   | 0                  |
+----------+--------------------+
```

## 解题思路

**关键点：**

1. 需要包含**所有用户**（即使没有行程的用户，距离为 0）
2. 使用 `LEFT JOIN` 从 Users 连接 Rides，保留所有用户
3. `COALESCE(SUM(distance), 0)` 处理没有行程的用户（SUM 为 NULL 时返回 0）
4. 按距离降序、名字升序排列

## 代码实现

### 方法一：LEFT JOIN + GROUP BY（推荐）

```sql
SELECT
    u.name,
    COALESCE(SUM(r.distance), 0) AS travelled_distance
FROM Users u
LEFT JOIN Rides r ON u.id = r.user_id
GROUP BY u.id, u.name
ORDER BY travelled_distance DESC, u.name ASC;
```

**解释：**

- `LEFT JOIN`：保留 Users 中所有用户，Rides 中没有匹配的行记为 NULL
- `COALESCE(SUM(r.distance), 0)`：若某用户无行程，`SUM(NULL)` = NULL，`COALESCE` 将其替换为 0
- `GROUP BY u.id, u.name`：按用户分组（用 id 分组更安全，避免同名用户合并）
- `ORDER BY travelled_distance DESC, u.name ASC`：双重排序

### 方法二：IFNULL 替代 COALESCE

```sql
SELECT
    u.name,
    IFNULL(SUM(r.distance), 0) AS travelled_distance
FROM Users u
LEFT JOIN Rides r ON u.id = r.user_id
GROUP BY u.id, u.name
ORDER BY travelled_distance DESC, u.name ASC;
```

`IFNULL(expr, 0)` 是 MySQL 特有的简写，等价于 `COALESCE(expr, 0)`。

### 方法三：子查询方式

```sql
SELECT
    u.name,
    COALESCE(
        (SELECT SUM(r.distance) FROM Rides r WHERE r.user_id = u.id),
        0
    ) AS travelled_distance
FROM Users u
ORDER BY travelled_distance DESC, u.name ASC;
```

## 复杂度分析

- **时间复杂度 O(n + m)**：n 是 Users 行数，m 是 Rides 行数，各扫描一遍。
- **空间复杂度 O(n)**：每个用户一行结果。

## 图解示例

```
Users: Alice(1), Bob(2), Alex(3), Donald(4), Lee(7), Jonathan(13), Elvis(19)

Rides 分组求和:
  user_id=1:  120       → Alice:    120
  user_id=2:  317       → Bob:      317
  user_id=3:  222       → Alex:     222
  user_id=7:  100+120+230=450 → Lee: 450
  user_id=13: 312       → Jonathan: 312
  user_id=19: 50+400=450 → Elvis:   450
  user_id=4:  无行程     → Donald:   0

排序：450(Elvis < Lee 字母序) > 450(Lee) > 317(Bob) > ...
结果：Elvis 450, Lee 450, Bob 317, Jonathan 312, Alex 222, Alice 120, Donald 0
```

## 关键点总结

1. 使用 `LEFT JOIN` 而非 `INNER JOIN`，确保没有行程的用户也出现在结果中
2. `COALESCE(SUM(distance), 0)` 处理 NULL（LEFT JOIN 无匹配时为 NULL）
3. `ORDER BY` 双重排序：先按距离降序，再按名字升序
4. `GROUP BY u.id` 比 `GROUP BY u.name` 更安全（避免同名用户合并）

## 易错点

- 用 `INNER JOIN` 会丢失没有行程的用户（如 Donald）
- `SUM(NULL)` 返回 NULL，需要用 `COALESCE` 或 `IFNULL` 处理
- 排序时注意：距离相同时按**名字升序**（ASC），距离本身是降序（DESC）
