## 题目描述

表 `Followers`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| follower_id | int  |
+-------------+------+
```

`(user_id, follower_id)` 是该表的主键。
每行描述 `follower_id` 关注了用户 `user_id`。

编写解决方案，对于每一个用户，返回该用户的关注者数量。

按 `user_id` 的升序排列结果。

**示例：**
```
输入：
Followers 表
+---------+-------------+
| user_id | follower_id |
+---------+-------------+
| 0       | 1           |
| 1       | 0           |
| 2       | 0           |
| 2       | 1           |
+---------+-------------+

输出：
+---------+----------------+
| user_id | followers_count|
+---------+----------------+
| 0       | 1              |
| 1       | 1              |
| 2       | 2              |
+---------+----------------+
```

## 解题思路

直接按 `user_id` 分组，统计每组的行数即为关注者数量，然后按 `user_id` 升序排列。

## 代码实现

### 方法一：GROUP BY + COUNT

```sql
-- 按 user_id 分组统计关注者数量
SELECT
    user_id,
    COUNT(follower_id) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id ASC;
```

### 方法二：COUNT(*) 写法

```sql
-- COUNT(*) 统计每组的行数（主键保证无重复）
SELECT
    user_id,
    COUNT(*) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，分组和排序
- **空间复杂度**：O(n)，存储分组结果

## 关键点总结

1. `GROUP BY user_id` 按用户分组
2. `COUNT(follower_id)` 或 `COUNT(*)` 统计每组行数
3. `ORDER BY user_id` 升序排列

## 易错点

- 由于 `(user_id, follower_id)` 是主键，不会有重复，`COUNT(*)` 和 `COUNT(follower_id)` 结果相同
- 注意排序方向为升序
