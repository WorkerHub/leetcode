## 题目描述

表 `Olympic` 结构如下：

| Column Name | Type    |
|-------------|---------|
| country     | varchar |
| gold_medals | int     |
| silver_medals | int   |
| bronze_medals | int   |

`country` 是该表的主键。

对奥运会奖牌榜进行排序，排序规则（优先级从高到低）：
1. 金牌数量（降序）。
2. 银牌数量（降序）。
3. 铜牌数量（降序）。
4. 国家名称（升序）。

返回排序后的结果。

## 解题思路

直接按照四个排序条件的优先级进行 `ORDER BY`。

## 代码实现

### 方法一：直接排序（推荐）

```sql
SELECT country, gold_medals, silver_medals, bronze_medals
FROM Olympic
ORDER BY 
    gold_medals DESC,
    silver_medals DESC,
    bronze_medals DESC,
    country ASC
```

### 方法二：使用 NULLS LAST（标准 SQL）

```sql
-- MySQL 不需要 NULLS，但标准 SQL 写法如下
SELECT country, gold_medals, silver_medals, bronze_medals
FROM Olympic
ORDER BY 
    gold_medals DESC,
    silver_medals DESC,
    bronze_medals DESC,
    country ASC
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 | O(n log n) | O(1) |

## 关键点总结

1. 多列排序：`ORDER BY col1 DESC, col2 DESC, col3 DESC, col4 ASC`。
2. 排序优先级按书写顺序，前面的条件优先级更高。
3. 国家名称升序（ASCII/字典序）是最后的决胜条件。

## 易错点

- 前三个条件是降序（DESC），最后一个是升序（ASC）。
- `ORDER BY` 中后面的条件只在前面条件相同时才起作用。
