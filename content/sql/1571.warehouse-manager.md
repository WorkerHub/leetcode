## 题目描述

表 `Warehouse`：`name`（仓库名）, `product_id`, `units`（库存件数）

表 `Products`：`product_id`, `product_name`, `Width`, `Length`, `Height`（产品尺寸，单位英尺）

计算每个仓库存储的所有商品的总体积（`Width * Length * Height * units`）。

## 解题思路

### JOIN + 聚合

计算每个产品的体积，然后乘以库存件数，按仓库分组求和。

## 代码实现

### 方法一：直接 JOIN + SUM（推荐）

```sql
-- 关联产品表计算每件商品体积，乘以数量后按仓库求和
SELECT
    w.name AS warehouse_name,
    SUM(w.units * p.Width * p.Length * p.Height) AS volume
FROM Warehouse w
JOIN Products p ON w.product_id = p.product_id
GROUP BY w.name
ORDER BY w.name;
```

### 方法二：先计算产品体积，再 JOIN

```sql
-- 先计算每个产品的单件体积
WITH product_vol AS (
    SELECT product_id, Width * Length * Height AS unit_volume
    FROM Products
)
SELECT
    w.name AS warehouse_name,
    SUM(w.units * pv.unit_volume) AS volume
FROM Warehouse w
JOIN product_vol pv ON w.product_id = pv.product_id
GROUP BY w.name;
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(M)，M 为仓库数

## 关键点总结

1. 总体积 = 所有产品的 `单件体积 × 件数` 之和
2. 单件体积 = `Width × Length × Height`
3. JOIN 后按仓库名 GROUP BY

## 易错点

- 体积单位已确定（英尺的立方），不需要转换
