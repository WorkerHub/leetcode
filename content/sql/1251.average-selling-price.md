## 题目描述

表：Prices

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| start_date    | date    |
| end_date      | date    |
| price         | int     |
+---------------+---------+
(product_id, start_date, end_date) 是 Prices 表的主键。
Prices 表的每一行表示的是某个产品在一段时期内的价格。
每个产品的对应时间段是不会重叠的，这也意味着同一个产品的价格时段不会出现交叉。
```

表：UnitsSold

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| purchase_date | date    |
| units         | int     |
+---------------+---------+
该表没有主键，它可能包含重复项。
UnitsSold 表的每一行表示的是每种产品的出售日期，单位和产品 id。
```

编写SQL查询以查找每种产品的平均售价。

average_price 应该四舍五入到小数点后两位。

查询结果格式如下例所示：

```
Prices table:
+------------+------------+------------+--------+
| product_id | start_date | end_date   | price  |
+------------+------------+------------+--------+
| 1          | 2019-02-17 | 2019-02-28 | 5      |
| 1          | 2019-03-01 | 2019-03-22 | 20     |
| 2          | 2019-02-01 | 2019-02-20 | 15     |
| 2          | 2019-02-21 | 2019-03-31 | 30     |
+------------+------------+------------+--------+

UnitsSold table:
+------------+---------------+-------+
| product_id | purchase_date | units |
+------------+---------------+-------+
| 1          | 2019-02-25    | 100   |
| 1          | 2019-03-01    | 15    |
| 2          | 2019-02-10    | 200   |
| 2          | 2019-03-22    | 30    |
+------------+---------------+-------+

Result table:
+------------+---------------+
| product_id | average_price |
+------------+---------------+
| 1          | 6.96          |
| 2          | 16.96         |
+------------+---------------+
平均售价 = 产品总价 / 销售的产品数量。
产品 1 的平均售价 = ((100 * 5) + (15 * 20)) / 115 = 6.96
产品 2 的平均售价 = ((200 * 15) + (30 * 30)) / 230 = 16.96
```

## 解题思路

这是一道SQL数据库题目，核心思路是：

1. 将 UnitsSold 表和 Prices 表进行连接，连接条件是产品ID相同且购买日期在价格的有效期内
2. 计算每个产品的总销售额（价格 * 数量）和总销售数量
3. 用总销售额除以总销售数量得到平均价格
4. 使用 ROUND 函数将结果四舍五入到两位小数

关键点：
- 使用 JOIN 连接两个表
- 购买日期必须在 start_date 和 end_date 之间
- 按 product_id 分组
- 计算加权平均价格而不是简单平均

## SQL 代码实现

### 方法一：LEFT JOIN + ROUND（推荐）

```sql
SELECT 
    p.product_id,
    ROUND(IFNULL(SUM(u.units * p.price) / SUM(u.units), 0), 2) AS average_price
FROM 
    Prices p
LEFT JOIN 
    UnitsSold u 
ON 
    p.product_id = u.product_id 
    AND u.purchase_date BETWEEN p.start_date AND p.end_date
GROUP BY 
    p.product_id;
```

### 方法二：INNER JOIN（简化版）

```sql
SELECT 
    u.product_id,
    ROUND(SUM(u.units * p.price) / SUM(u.units), 2) AS average_price
FROM 
    UnitsSold u
INNER JOIN 
    Prices p
ON 
    u.product_id = p.product_id
    AND u.purchase_date BETWEEN p.start_date AND p.end_date
GROUP BY 
    u.product_id;
```

## 复杂度分析

时间复杂度：O(n * m)，其中 n 是 UnitsSold 表的行数，m 是 Prices 表的行数
空间复杂度：O(k)，k 是不同产品的数量

## 关键点总结

1. 使用 BETWEEN 关键字判断日期是否在范围内
2. 计算加权平均价格：总销售额 / 总销售数量
3. ROUND 函数四舍五入到指定小数位
4. IFNULL 处理没有销售记录的产品
5. GROUP BY 按产品ID分组聚合

## 易错点

1. 忘记使用 BETWEEN 条件匹配日期范围
2. 计算简单平均而不是加权平均
3. 忘记 ROUND 函数保留两位小数
4. 没有处理空值情况
