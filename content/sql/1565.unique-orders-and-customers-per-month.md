## 题目描述

表 `Orders`：`order_id`, `order_date`, `customer_id`, `invoice`

查询每个月的订单总数和购买了至少一次（invoice > 20）的不同客户数。

结果按月份升序排列。

## 解题思路

### GROUP BY + COUNT DISTINCT

按年月分组，统计订单数和满足条件的不同客户数。

## 代码实现

### 方法一：GROUP BY + HAVING 过滤（推荐）

```sql
-- 只统计 invoice > 20 的订单
SELECT
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    COUNT(order_id) AS order_count,
    COUNT(DISTINCT customer_id) AS customer_count
FROM Orders
WHERE invoice > 20
GROUP BY DATE_FORMAT(order_date, '%Y-%m')
ORDER BY month ASC;
```

### 方法二：CTE + 聚合

```sql
-- 先过滤，再分组统计
WITH filtered AS (
    SELECT *
    FROM Orders
    WHERE invoice > 20
)
SELECT
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    COUNT(*) AS order_count,
    COUNT(DISTINCT customer_id) AS customer_count
FROM filtered
GROUP BY month
ORDER BY month ASC;
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(M)，M 为不同月份数

## 关键点总结

1. `WHERE invoice > 20` 先过滤不满足的记录
2. `COUNT(DISTINCT customer_id)` 统计不重复客户数
3. `DATE_FORMAT(order_date, '%Y-%m')` 提取年月

## 易错点

- 题目要求 `invoice > 20` 的订单，不是全部订单（先过滤再统计）
- `COUNT(DISTINCT ...)` 统计唯一客户，普通 `COUNT(*)` 统计订单总数
