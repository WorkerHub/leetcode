## 题目描述

表：`Customer`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| customer_id   | int     |
| name          | varchar |
| visited_on    | date    |
| amount        | int     |
+---------------+---------+
(customer_id, visited_on) 是该表的主键
该表包含一家餐厅的顾客事务数据
visited_on 是顾客访问餐厅的日期
amount 是一次交易的总金额
```

你是餐厅的老板，现在你想分析一下可能的营业额变化增长（窗口函数）。

计算以 7 天（某日期 + 该日期前的 6 天）为一个时间窗口的顾客消费总额和平均消费额。`average_amount` **保留两位小数**。

结果按 `visited_on` **升序排列**。

**注意**：只需要计算有 7 天数据的那些天（即从第 7 天开始统计）。

**示例：**

```
输入：
Customer 表：
+-------------+--------------+--------------+--------+
| customer_id | name         | visited_on   | amount |
+-------------+--------------+--------------+--------+
| 1           | Jhon         | 2019-01-01   | 100    |
| 2           | Daniel       | 2019-01-02   | 110    |
| 3           | Jade         | 2019-01-03   | 120    |
| 4           | Khaled       | 2019-01-04   | 130    |
| 5           | Winston      | 2019-01-05   | 110    |
| 6           | Elvis        | 2019-01-06   | 140    |
| 7           | Anna         | 2019-01-07   | 150    |
| 8           | Maria        | 2019-01-08   | 80     |
| 9           | Jaze         | 2019-01-09   | 110    |
| 1           | Jhon         | 2019-01-10   | 130    |
| 3           | Jade         | 2019-01-11   | 150    |
+-------------+--------------+--------------+--------+

输出：
+--------------+--------------+----------------+
| visited_on   | amount       | average_amount |
+--------------+--------------+----------------+
| 2019-01-07   | 860          | 122.86         |
| 2019-01-08   | 840          | 120.00         |

+--------------+--------------+----------------+
```

## 解题思路

**核心思路：滑动窗口求过去 7 天的总和**

**方法一：自连接（Self Join）**

对每一个日期 `d`，找出 `d-6` 到 `d` 之间的所有记录求和。

**方法二：窗口函数（推荐）**

先按日期汇总每天的总消费额，再用窗口函数 `SUM() OVER (ORDER BY visited_on ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)` 计算滑动 7 天窗口的总和。

## SQL 代码实现

### 方法一：自连接（兼容性好）

```sql
SELECT 
    a.visited_on,
    SUM(b.amount) AS amount,
    ROUND(SUM(b.amount) / 7, 2) AS average_amount
FROM (
    -- 先按日期汇总当天总消费
    SELECT visited_on, SUM(amount) AS amount
    FROM Customer
    GROUP BY visited_on
) a
JOIN (
    SELECT visited_on, SUM(amount) AS amount
    FROM Customer
    GROUP BY visited_on
) b
    -- b 的日期在 a 的日期前 6 天到当天之间
    ON b.visited_on BETWEEN DATE_SUB(a.visited_on, INTERVAL 6 DAY) AND a.visited_on
GROUP BY a.visited_on
-- 只保留有完整 7 天数据的记录（即日期 >= 最小日期 + 6天）
HAVING COUNT(DISTINCT b.visited_on) = 7
ORDER BY a.visited_on;
```

### 方法二：窗口函数（MySQL 8.0+，推荐）

```sql
SELECT 
    visited_on,
    amount,
    ROUND(amount / 7, 2) AS average_amount
FROM (
    SELECT 
        visited_on,
        -- 滑动窗口：当前行及前 6 行的总和
        SUM(SUM(amount)) OVER (
            ORDER BY visited_on 
            ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
        ) AS amount,
        -- 用 ROW_NUMBER 判断是否已有 7 天数据
        ROW_NUMBER() OVER (ORDER BY visited_on) AS rn
    FROM Customer
    GROUP BY visited_on
) t
WHERE rn >= 7  -- 至少有 7 天数据才统计
ORDER BY visited_on;
```

### 方法三：变量（MySQL 5.x 兼容版）

```sql
SELECT 
    a.visited_on,
    SUM(b.day_amount) AS amount,
    ROUND(SUM(b.day_amount) / 7, 2) AS average_amount
FROM (
    SELECT visited_on, SUM(amount) AS day_amount
    FROM Customer
    GROUP BY visited_on
) a
JOIN (
    SELECT visited_on, SUM(amount) AS day_amount
    FROM Customer
    GROUP BY visited_on
) b
ON DATEDIFF(a.visited_on, b.visited_on) BETWEEN 0 AND 6
GROUP BY a.visited_on
HAVING COUNT(*) = 7
ORDER BY a.visited_on;
```

## 复杂度分析

- **自连接**：O(n^2)，n 为不同日期数
- **窗口函数**：O(n log n)（排序），n 为不同日期数

## 关键点总结

1. 需要先按日期汇总（GROUP BY visited_on），再做 7 天滑动窗口
2. 只输出有完整 7 天数据的日期（从第 7 个日期开始）
3. 平均值保留两位小数，用 `ROUND(..., 2)`
4. 窗口函数 `ROWS BETWEEN 6 PRECEDING AND CURRENT ROW` 表示当前行及前 6 行

## 易错点

1. **注意同一天可能有多条记录**：需要先 GROUP BY visited_on 汇总
2. **7 天窗口**：是当天加上之前 6 天，共 7 天；不是 7 个不同日期（但题目数据每天有记录）
3. **HAVING COUNT = 7**：在方法一中，COUNT 统计的是不同日期数，确保恰好有 7 天数据
