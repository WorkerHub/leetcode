## 题目描述

表 `Users`：
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| name          | varchar |
| mail          | varchar |
+---------------+---------+
```
`user_id` 是主键。

编写一个 SQL 查询，查询**有效邮箱**的用户。

有效邮箱的规则：
- 前缀以字母开头
- 前缀只包含字母（大/小写）、数字、下划线 `_`、句点 `.`、横线 `-`
- 以 `@leetcode.com` 结尾

**示例：**
```
输入：Users = [[1,'Winston','winston@leetcode.com'],[2,'Jonathan','jonathanisgreat'],[3,'Annabelle','bella-@leetcode.com'],[4,'Sally','sally.come@leetcode.com'],[5,'Marwan','quarz#2020@leetcode.com'],[6,'David','david69@leetcode.com'],[7,'Shapiro','.shapo@leetcode.com']]
输出：user_id=1,3,4,6 的用户
```

## 解题思路

### 正则表达式过滤

使用 `REGEXP` 对邮箱进行正则匹配：
- `^[a-zA-Z]`：以字母开头
- `[a-zA-Z0-9_.-]*`：中间可包含字母、数字、`_`、`.`、`-`
- `@leetcode\\.com$`：以 `@leetcode.com` 结尾

## 代码实现

### 方法一：REGEXP 正则过滤（推荐）

```sql
-- 使用正则表达式匹配有效邮箱
SELECT user_id, name, mail
FROM Users
WHERE mail REGEXP '^[a-zA-Z][a-zA-Z0-9_.-]*@leetcode\\.com$';
```

### 方法二：LIKE + 额外判断（不推荐，无法完整验证前缀）

```sql
-- LIKE 只能做简单模式匹配，无法验证前缀规则
-- 仅做演示，实际应用 REGEXP
SELECT user_id, name, mail
FROM Users
WHERE mail LIKE '%@leetcode.com'
  AND mail REGEXP '^[a-zA-Z][a-zA-Z0-9_.-]*@leetcode\\.com$';
```

### MySQL 与其他数据库对比写法

```sql
-- MySQL (REGEXP 不区分大小写，或用 REGEXP BINARY 区分)
SELECT user_id, name, mail
FROM Users
WHERE mail REGEXP '^[A-Za-z][A-Za-z0-9_.-]*@leetcode[.]com$';

-- PostgreSQL (使用 ~ 运算符)
-- SELECT user_id, name, mail FROM Users
-- WHERE mail ~ '^[A-Za-z][A-Za-z0-9_.\\-]*@leetcode\\.com$';
```

## 复杂度分析

- **时间复杂度**：O(N * L)，N 为行数，L 为邮箱字符串平均长度
- **空间复杂度**：O(1)

## 关键点总结

1. 正则 `^` 匹配字符串开头，`$` 匹配结尾，保证完整匹配
2. `@leetcode\\.com` 中 `.` 在正则里需要转义，MySQL 中用 `\\.` 或 `[.]`
3. 前缀第一个字符必须是字母（不能是数字或特殊字符）

## 易错点

- 忘记 `^` 和 `$` 锚点，导致匹配到更大的字符串子串
- `.` 在正则中是"任意字符"，域名部分 `leetcode.com` 中的点需要转义
- MySQL `REGEXP` 默认不区分大小写，需要用 `REGEXP BINARY` 区分时另行处理
