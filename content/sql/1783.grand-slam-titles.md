## 题目描述

表 `Players`：

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| player_id      | int     |
| player_name    | varchar |
+----------------+---------+
```

`player_id` 是该表的主键。

表 `Championships`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| year          | int     |
| Wimbledon     | int     |
| Fr_open       | int     |
| US_open       | int     |
| Au_open       | int     |
+---------------+---------+
```

`year` 是该表的主键。每列存储那年对应大满贯冠军的 `player_id`。

编写解决方案，查找每位球员赢得大满贯赛事的次数。

结果包含所有球员的 `player_id`、`player_name` 和 `grand_slams_count`，只包含那些**至少赢得过一次**大满贯赛事的球员。

结果按任意顺序排列。

## 解题思路

将四列大满贯展开为行（UNION ALL），然后与 Players 表连接，按球员分组统计次数。

## 代码实现

### 方法一：UNION ALL 展开 + GROUP BY

```sql
-- 将四列大满贯冠军展开为行，再统计每位球员的次数
WITH all_winners AS (
    SELECT Wimbledon AS player_id FROM Championships
    UNION ALL
    SELECT Fr_open FROM Championships
    UNION ALL
    SELECT US_open FROM Championships
    UNION ALL
    SELECT Au_open FROM Championships
)
SELECT
    p.player_id,
    p.player_name,
    COUNT(*) AS grand_slams_count
FROM Players p
JOIN all_winners w ON p.player_id = w.player_id
GROUP BY p.player_id, p.player_name;
```

### 方法二：条件聚合

```sql
-- 对每个球员在四列中的出现次数求和
SELECT
    p.player_id,
    p.player_name,
    SUM(
        (CASE WHEN c.Wimbledon = p.player_id THEN 1 ELSE 0 END) +
        (CASE WHEN c.Fr_open = p.player_id THEN 1 ELSE 0 END) +
        (CASE WHEN c.US_open = p.player_id THEN 1 ELSE 0 END) +
        (CASE WHEN c.Au_open = p.player_id THEN 1 ELSE 0 END)
    ) AS grand_slams_count
FROM Players p
JOIN Championships c ON 
    c.Wimbledon = p.player_id OR 
    c.Fr_open = p.player_id OR 
    c.US_open = p.player_id OR 
    c.Au_open = p.player_id
GROUP BY p.player_id, p.player_name
HAVING grand_slams_count > 0;
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 是球员数，m 是锦标赛数
- **空间复杂度**：O(n * m)

## 关键点总结

1. UNION ALL 将四列展开为行，每行代表一次大满贯获胜
2. 与 Players 表 JOIN 获取球员名字
3. GROUP BY 统计每位球员的总次数

## 易错点

- 使用 INNER JOIN，只返回至少赢过一次的球员
- UNION ALL 而不是 UNION（允许同一球员在多年出现）
