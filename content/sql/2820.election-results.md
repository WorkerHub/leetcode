## 题目描述

**表：Votes**

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| voter          | varchar |
| candidate      | varchar |
+----------------+---------+
```

- `voter` 是表的主键（可能有重复，每个 voter 可以多次投票，但只有第一票有效？实际上这里每行是一次投票记录）
- 实际约束：每个投票者最多投两票，但每人只有一张有效票（选票分到票数最少的候选人，或有两个候选人时选其中一个）

实际规则：
- 每个投票者可以投票给一个或两个候选人
- 如果一个投票者投了两票，则两票各计 0.5 分
- 如果一个投票者只投了一票，则那票计 1 分

返回**得票分数**最高的候选人，如果有多个并列，返回所有并列的候选人（按候选人名字字典序升序排列）。

**示例 1：**
```
输入：
Votes 表
+----------+-----------+
| voter    | candidate |
+----------+-----------+
| Kathy    | Alliance  |
| Kathy    | Scrutiny  |
| Alfredo  | Alliance  |
| Alfredo  | Scrutiny  |
| Alisa    | Alliance  |
| Edward   | Scrutiny  |
+----------+-----------+

输出：
+-----------+
| candidate |
+-----------+
| Alliance  |
+-----------+
解释：
Kathy 投了 Alliance 和 Scrutiny，各 0.5 分
Alfredo 投了 Alliance 和 Scrutiny，各 0.5 分
Alisa 投了 Alliance，1 分
Edward 投了 Scrutiny，1 分
Alliance: 0.5+0.5+1 = 2.0
Scrutiny: 0.5+0.5+1 = 2.0
并列，返回字典序更小的
```

## 解题思路

1. 计算每个投票者的投票次数
2. 根据投票次数计算每一票的分值：一票 = 1.0，两票 = 0.5
3. 按候选人汇总得分
4. 找最高分，返回并列最高的候选人（字典序排列）

## 代码实现

### SQL 解法

```sql
-- 方法一：使用 COUNT 和 CASE 计算分数
WITH voter_counts AS (
    -- 计算每个投票者的投票次数
    SELECT voter, COUNT(*) AS vote_count
    FROM Votes
    GROUP BY voter
),
scored_votes AS (
    -- 为每票计算分值
    SELECT 
        v.candidate,
        CASE 
            WHEN vc.vote_count = 1 THEN 1.0
            ELSE 0.5
        END AS score
    FROM Votes v
    JOIN voter_counts vc ON v.voter = vc.voter
),
candidate_scores AS (
    -- 汇总每个候选人的总分
    SELECT candidate, SUM(score) AS total_score
    FROM scored_votes
    GROUP BY candidate
),
max_score AS (
    -- 找最高分
    SELECT MAX(total_score) AS max_score
    FROM candidate_scores
)
SELECT candidate
FROM candidate_scores
WHERE total_score = (SELECT max_score FROM max_score)
ORDER BY candidate;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和分组操作
- 空间复杂度：O(n)，中间表的存储

## 关键点总结

1. 每个投票者的得分 = 1.0 / 该投票者的总投票次数
2. 候选人总得分 = 所有投给他的票的分值之和
3. 并列情况下按候选人名字字典序升序排列

## 易错点

1. 用 0.5 而不是 1/2 整除（需要确保浮点除法）
2. 并列时需要返回所有并列的候选人，不只返回一个
3. 返回结果需要按 candidate 字典序排列
