## 题目描述

表：`Cinema`

```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| id             | int      |
| movie          | varchar  |
| description    | varchar  |
| rating         | float    |
+----------------+----------+
```

`id` 是该表的主键。
每一行包含电影的名称、类型和评分。
`rating` 的取值范围为 `[0, 10]`。

查找所有影片描述为**非** `boring`（不无聊）的并且 **id 为奇数**的影片，结果按 `rating` **降序排列**。

返回结果表。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Cinema 表：
+----+------------+-------------+--------+
| id | movie      | description | rating |
+----+------------+-------------+--------+
| 1  | War        | great 3D    | 8.9    |
| 2  | Science    | fiction     | 8.5    |
| 3  | irish      | boring      | 6.2    |
| 4  | Ice song   | Fantacy     | 8.6    |
| 5  | House card | Interesting | 9.1    |
+----+------------+-------------+--------+

输出：
+----+------------+-------------+--------+
| id | movie      | description | rating |
+----+------------+-------------+--------+
| 5  | House card | Interesting | 9.1    |
| 1  | War        | great 3D    | 8.9    |
+----+------------+-------------+--------+

解释：
我们有三部电影，它们的 id 为奇数：1、3 和 5。
id = 3 的电影是 boring 的，所以我们不把它包括在答案中。
```

## 解题思路

简单的筛选和排序问题。

**条件：**
1. `id` 为奇数
2. `description` 不等于 'boring'
3. 按 `rating` 降序排列

## SQL 代码实现

### 方法一：标准写法⭐

```sql
SELECT *
FROM Cinema
WHERE id % 2 = 1
  AND description != 'boring'
ORDER BY rating DESC;
```

### 方法二：使用 MOD 函数

```sql
SELECT *
FROM Cinema
WHERE MOD(id, 2) = 1
  AND description <> 'boring'
ORDER BY rating DESC;
```

### 方法三：使用 NOT LIKE

```sql
SELECT *
FROM Cinema
WHERE id % 2 = 1
  AND description NOT LIKE 'boring'
ORDER BY rating DESC;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. **奇数判断**：`id % 2 = 1` 或 `MOD(id, 2) = 1`
2. **不等于**：`!=` 或 `<>`
3. **降序**：`ORDER BY ... DESC`
