## 题目描述

表 `Orders` 包含字段：`order_id`（主键）、`customer_id`、`order_type`（0 或 1）。

规则：如果某个客户**同时有** type 0 和 type 1 的订单，则删除该客户所有的 type 1 订单。

返回删除后剩余的所有订单。

**示例：**
```
输入：
Orders 表：
+----------+-------------+------------+
| order_id | customer_id | order_type |
+----------+-------------+------------+
| 1        | 1           | 0          |
| 2        | 1           | 0          |
| 11       | 2           | 0          |
| 3        | 3           | 1          |
| 4        | 3           | 2          |  (注：题目只有0和1)
| 5        | 4           | 1          |
| 10       | 4           | 0          |
+----------+-------------+------------+

输出：保留所有 type 0，以及没有 type 0 的客户的 type 1 订单
```

## 解题思路

找出同时有 type 0 和 type 1 订单的客户，对这些客户只保留 type 0 订单；对其他客户（只有 type 1）保留所有订单。

**方法：**
- 找出有 type 0 订单的客户集合
- 过滤：`order_type = 0` OR（`order_type = 1` AND `customer_id` 不在有 type 0 的集合中）

## 代码实现

### 方法一：子查询过滤（推荐）

```sql
SELECT order_id, customer_id, order_type
FROM Orders
WHERE order_type = 0
   OR customer_id NOT IN (
       SELECT customer_id
       FROM Orders
       WHERE order_type = 0
   );
```

### 方法二：LEFT JOIN

```sql
SELECT o.order_id, o.customer_id, o.order_type
FROM Orders o
LEFT JOIN (
    SELECT DISTINCT customer_id
    FROM Orders
    WHERE order_type = 0
) t0 ON o.customer_id = t0.customer_id
WHERE o.order_type = 0
   OR t0.customer_id IS NULL;
```

### 方法三：分组统计

```sql
SELECT order_id, customer_id, order_type
FROM Orders
WHERE order_type = 0

UNION ALL

SELECT order_id, customer_id, order_type
FROM Orders
WHERE order_type = 1
  AND customer_id NOT IN (
      SELECT customer_id FROM Orders WHERE order_type = 0
  );
```

## 复杂度分析

- 时间复杂度：O(n)，扫描订单表
- 空间复杂度：O(m)，m 为有 type 0 的客户数

## 关键点总结

1. 核心逻辑：有 type 0 的客户，去掉其 type 1 订单；没有 type 0 的客户保留所有
2. 最简洁的写法：`WHERE order_type = 0 OR customer_id NOT IN (有 type 0 的客户)`
3. `NOT IN` 需注意子查询不能有 NULL 值（此题 customer_id 不为 NULL，安全）

## 易错点

- 若用 `NOT IN`，子查询中若有 NULL 行会导致整个 `NOT IN` 返回空，本题无此问题
- 不是删除 type 1 订单本身，而是对特定客户过滤 type 1 订单
