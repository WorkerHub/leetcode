## 题目描述

表 `OrdersDetails`：

| Column Name | Type    |
|-------------|---------|
| order_id    | int     |
| product_id  | int     |
| quantity    | int     |

`(order_id, product_id)` 是主键。

编写 SQL 查询，找出满足以下条件的所有订单 ID：该订单的**最大数量**严格大于**所有订单的平均数量（每个订单取平均数量，再求这些平均数量的最大值）**。

具体地：
- 对每个 `order_id`，计算其 `quantity` 的平均值（`avg_quantity`）
- 找出所有订单中 `avg_quantity` 的最大值（`max_avg`）
- 返回 `max_quantity > max_avg` 的 `order_id`

返回任意顺序的结果。

## 解题思路

1. 按 `order_id` 分组，计算每个订单的平均数量 `avg_qty` 和最大数量 `max_qty`
2. 计算全局最大平均数量
3. 找出最大数量严格大于全局最大平均数量的订单

## 代码实现

### 方法一：子查询（推荐）

```sql
WITH OrderStats AS (
    SELECT order_id,
           MAX(quantity) AS max_qty,
           AVG(quantity) AS avg_qty
    FROM OrdersDetails
    GROUP BY order_id
),
MaxAvg AS (
    SELECT MAX(avg_qty) AS global_max_avg
    FROM OrderStats
)
SELECT order_id
FROM OrderStats, MaxAvg
WHERE max_qty > global_max_avg;
```

### 方法二：嵌套子查询

```sql
SELECT order_id
FROM (
    SELECT order_id, MAX(quantity) AS max_qty
    FROM OrdersDetails
    GROUP BY order_id
) t
WHERE max_qty > (
    SELECT MAX(avg_qty)
    FROM (
        SELECT AVG(quantity) AS avg_qty
        FROM OrdersDetails
        GROUP BY order_id
    ) sub
);
```

## 复杂度分析

- **时间复杂度**：O(n)，分组和聚合
- **空间复杂度**：O(m)，m 为订单数

## 关键点总结

1. 注意题目要求：每个订单取平均，再对这些平均值求最大（不是对全局所有行求平均）
2. 严格大于（`>`），不是大于等于
3. 使用 CTE 分步计算，逻辑清晰

## 易错点

- 题目要求的是 `max_quantity > max(avg per order)`，不是 `avg_quantity > max_avg`
- 仔细区分每订单的平均值和全局平均值
