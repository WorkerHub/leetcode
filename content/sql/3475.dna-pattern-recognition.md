## 题目描述

表 `Samples`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| sample_id   | int     |
| dna_sequence| varchar |
+-------------+---------+
```

`sample_id` 是主键。DNA 序列只包含 `A`、`T`、`G`、`C` 四种字符。

找出 DNA 序列中包含以下特征的样本：
1. 包含至少 3 个连续的 `A`（即含有 `AAA`）
2. 包含子序列 `AT` 至少 2 次（注意：是子序列，`A` 在 `T` 前面，不一定相邻）
3. 不以 `GC` 开头

**示例：**

输入：
```
+-----------+------------------+
| sample_id | dna_sequence     |
+-----------+------------------+
| 1         | AAATCGATCGATCGA  |
| 2         | GCATCGATCGATCG   |
| 3         | ATATATAT         |
+-----------+------------------+
```

输出：
```
+-----------+------------------+
| sample_id | dna_sequence     |
+-----------+------------------+
| 3         | ATATATAT         |
+-----------+------------------+
```

**提示：** 每个条件的解释需结合实际题目确认。

## 解题思路

逐条件筛选：
1. `AAA` 出现：使用 LIKE '%AAA%'
2. `AT` 至少出现 2 次（相邻或子串）：统计 AT 出现次数
3. 不以 `GC` 开头：NOT LIKE 'GC%'

## SQL 代码实现

### 方法一：多条件过滤（推荐）

```sql
SELECT sample_id, dna_sequence
FROM Samples
WHERE
    -- 条件1：包含至少 3 个连续的 A
    dna_sequence LIKE '%AAA%'
    -- 条件2：包含子序列 AT 至少 2 次（作为子串出现）
    AND (LENGTH(dna_sequence) - LENGTH(REPLACE(dna_sequence, 'AT', 'X'))) >= 2
    -- 条件3：不以 GC 开头
    AND dna_sequence NOT LIKE 'GC%'
ORDER BY sample_id;
```

### 方法二：使用 REGEXP

```sql
SELECT sample_id, dna_sequence
FROM Samples
WHERE
    dna_sequence REGEXP 'AAA'
    AND (LENGTH(dna_sequence) - LENGTH(REPLACE(dna_sequence, 'AT', 'X'))) >= 2
    AND dna_sequence NOT REGEXP '^GC'
ORDER BY sample_id;
```

### 方法三：完整过滤

```sql
SELECT sample_id, dna_sequence
FROM Samples
WHERE dna_sequence LIKE '%AAA%'
  AND REPLACE(dna_sequence, 'AT', '__') != REPLACE(REPLACE(dna_sequence, 'AT', '__'), 'AT', '__')
  -- 注意：这种方式有限制，更好用计数方式
  AND LEFT(dna_sequence, 2) != 'GC'
ORDER BY sample_id;
```

### 方法四：统计 AT 出现次数（子串次数）

```sql
SELECT sample_id, dna_sequence
FROM Samples
WHERE dna_sequence LIKE '%AAA%'
  AND (
    (LENGTH(dna_sequence) - LENGTH(REPLACE(dna_sequence, 'AT', 'X'))) >= 2
  )
  AND dna_sequence NOT LIKE 'GC%'
ORDER BY sample_id;
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为行数，L 为序列平均长度
- 空间复杂度：O(1)

## 关键点总结

1. 字符串计数：LENGTH(s) - LENGTH(REPLACE(s, 'sub', 'x')) 计算子串出现次数（每次替换等长字符串）
2. LIKE 模式匹配用于连续字符检测
3. NOT LIKE 'GC%' 等价于 LEFT(s, 2) != 'GC'

## 易错点

1. REPLACE 统计子串次数时，替换的字符长度要与原子串等长（或单字符）
2. AT 统计时 REPLACE(s, 'AT', 'X') 会减少 1 个字符（AT->X），所以次数 = (原长 - 替换后长) / (2-1) = 原长 - 替换后长
3. 不以 GC 开头：只看前两个字符
