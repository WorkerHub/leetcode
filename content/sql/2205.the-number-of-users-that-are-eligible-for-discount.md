## 题目描述

表：`Purchases`

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| user_id     | int      |
| time_stamp  | datetime |
| amount      | int      |
+-------------+----------+
(user_id, time_stamp) 是该表的主键。
```

编写一个 SQL 查询，查找在 `[startDate, endDate]` 日期范围内，至少进行了一次金额 **严格少于** `minAmount` 的购买的用户数量。

函数签名：

```sql
CREATE FUNCTION getUserIDs(startDate DATE, endDate DATE, minAmount INT) RETURNS INT
BEGIN
  -- 实现
END
```

**注意：** LeetCode 该题是创建函数题，返回符合条件的用户数。

**示例：**
```
Purchases 表：
+---------+---------------------+--------+
| user_id | time_stamp          | amount |
+---------+---------------------+--------+
| 1       | 2022-04-20 09:03:00 | 4416   |
| 2       | 2022-03-19 19:24:00 | 678    |
| 3       | 2022-03-18 12:03:09 | 4523   |
| 4       | 2022-03-18 13:00:00 | 322    |
+---------+---------------------+--------+

getUserIDs('2022-03-08', '2022-03-20', 1000) 返回 2
```

## 解题思路

直接在 `Purchases` 表中筛选满足条件的记录：
1. `time_stamp` 在 `[startDate, endDate]` 范围内（注意 DATE 与 DATETIME 的比较）。
2. `amount < minAmount`（严格小于）。
3. 对 `user_id` 去重后计数。

## 代码实现

### 方法一：CREATE FUNCTION（LeetCode 要求格式）

```sql
CREATE FUNCTION getUserIDs(startDate DATE, endDate DATE, minAmount INT) RETURNS INT
BEGIN
    DECLARE result INT;

    -- 查询满足条件的不重复用户数
    SELECT COUNT(DISTINCT user_id)
    INTO result
    FROM Purchases
    WHERE DATE(time_stamp) BETWEEN startDate AND endDate
      AND amount < minAmount;

    RETURN result;
END
```

### 方法二：纯 SELECT 查询（理解题意用）

```sql
-- 如果只需要查询结果而非创建函数
SELECT COUNT(DISTINCT user_id) AS user_count
FROM Purchases
WHERE DATE(time_stamp) BETWEEN '2022-03-08' AND '2022-03-20'
  AND amount < 1000;
```

## 复杂度分析

- 时间复杂度：O(n)，n 为 Purchases 表的行数，全表扫描。
- 空间复杂度：O(k)，k 为满足条件的唯一用户数。

## 关键点总结

1. `BETWEEN` 对日期是闭区间，包含两端点。
2. `time_stamp` 是 DATETIME 类型，需要用 `DATE()` 函数转换后与 DATE 类型比较（或直接使用范围比较 `time_stamp >= startDate AND time_stamp < endDate + 1`）。
3. 用 `COUNT(DISTINCT user_id)` 避免同一用户多次购买被重复计数。

## 易错点

- `amount < minAmount` 是严格小于，不能写 `<=`。
- DATETIME 与 DATE 直接比较时，`time_stamp <= endDate` 会截断为 `endDate 00:00:00`，需用 `DATE(time_stamp) <= endDate`。
