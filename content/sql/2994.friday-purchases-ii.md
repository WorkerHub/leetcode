## 题目描述

本题为数据库题目，是 2993 题的进阶版。

给定表 `Purchases`（同 2993）。

找出 2023 年 11 月每个周五的购买总金额，若某周五无购买记录，需要显示该日期（金额为 0）。

即需要生成 2023 年 11 月所有周五的列表，与购买记录 LEFT JOIN。

## SQL 代码实现

### 方法一：生成日期序列 + LEFT JOIN（推荐）

```sql
-- 生成 2023 年 11 月所有周五
WITH RECURSIVE fridays AS (
    SELECT DATE('2023-11-03') AS friday  -- 2023-11-03 是第一个周五
    UNION ALL
    SELECT DATE_ADD(friday, INTERVAL 7 DAY)
    FROM fridays
    WHERE friday < '2023-11-30'
)
SELECT
    f.friday AS purchase_date,
    COALESCE(SUM(p.amount_spend), 0) AS total_amount
FROM fridays f
LEFT JOIN Purchases p
    ON f.friday = p.purchase_date
GROUP BY f.friday
ORDER BY f.friday;
```

### 方法二：已知周五日期手动列举

```sql
SELECT
    dates.purchase_date,
    COALESCE(SUM(p.amount_spend), 0) AS total_amount
FROM (
    SELECT '2023-11-03' AS purchase_date UNION ALL
    SELECT '2023-11-10' UNION ALL
    SELECT '2023-11-17' UNION ALL
    SELECT '2023-11-24'
) dates
LEFT JOIN Purchases p ON dates.purchase_date = p.purchase_date
GROUP BY dates.purchase_date
ORDER BY dates.purchase_date;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（日期序列固定）

## 关键点总结

1. 生成日期序列（递归 CTE 或手动枚举）
2. LEFT JOIN 确保所有周五都出现
3. COALESCE 将 NULL 转为 0

## 易错点

1. 2023 年 11 月第一个周五是 3 日（需要确认）
2. 使用 COALESCE 而不是 IFNULL，处理 NULL 金额
3. 递归 CTE 需要终止条件
