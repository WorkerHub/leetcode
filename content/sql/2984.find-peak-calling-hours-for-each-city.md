## 题目描述

本题为数据库题目。

给定表 `Calls`：
```
+--------------+----------+
| Column Name  | Type     |
+--------------+----------+
| caller_id    | int      |
| recipient_id | int      |
| call_time    | datetime |
| city         | varchar  |
+--------------+----------+
```

找出每个城市中通话次数最多的小时（0-23），返回城市、峰值小时和通话次数。

**输出格式：**
```
+------+------------+------------+
| city | peak_hour  | num_calls  |
+------+------------+------------+
```

## 解题思路

按城市和小时分组统计通话次数，找每个城市通话次数最多的小时。

## SQL 代码实现

### 方法一：窗口函数 RANK（推荐）

```sql
WITH hourly_calls AS (
    SELECT
        city,
        HOUR(call_time) AS peak_hour,
        COUNT(*) AS num_calls
    FROM Calls
    GROUP BY city, HOUR(call_time)
),
ranked AS (
    SELECT
        city,
        peak_hour,
        num_calls,
        RANK() OVER (PARTITION BY city ORDER BY num_calls DESC) AS rnk
    FROM hourly_calls
)
SELECT city, peak_hour, num_calls
FROM ranked
WHERE rnk = 1
ORDER BY city;
```

### 方法二：子查询

```sql
SELECT
    hc.city,
    hc.peak_hour,
    hc.num_calls
FROM (
    SELECT
        city,
        HOUR(call_time) AS peak_hour,
        COUNT(*) AS num_calls
    FROM Calls
    GROUP BY city, HOUR(call_time)
) hc
JOIN (
    SELECT city, MAX(num_calls) AS max_calls
    FROM (
        SELECT city, HOUR(call_time) AS h, COUNT(*) AS num_calls
        FROM Calls
        GROUP BY city, HOUR(call_time)
    ) sub
    GROUP BY city
) mx ON hc.city = mx.city AND hc.num_calls = mx.max_calls
ORDER BY hc.city;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 提取 HOUR 函数获取小时数（0-23）
2. 分组统计后用 RANK/MAX 找峰值小时
3. 可能有多个小时并列峰值（RANK 处理）

## 易错点

1. 若有并列情况（多个小时通话数相同），都要输出
2. HOUR() 函数提取 0-23 的小时
