## 题目描述

**表：Countries**

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| country_id    | int     |
| country_name  | varchar |
+---------------+---------+
country_id 是此表的主键。
此表包含国家 ID 和国家名称。
```

**表：Weather**

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| country_id    | int     |
| weather_state | varchar |
| day           | date    |
+---------------+---------+
(country_id, day) 是此表的主键。
此表包含每个国家每天的天气状态。
```

根据以下规则判断 2019 年 11 月每个国家的天气类型：

- 如果该国家 `weather_state` 的平均值 `<= 15`，则类型为 **Cold**
- 如果平均值 `>= 25`，则类型为 **Hot**
- 否则为 **Warm**

返回每个国家和对应的天气类型，**结果顺序无要求**。

**示例：**

```
Countries 表：

+------------+--------------+

+------------+--------------+

Weather 表：

| 2          | 12            | 2019-10-28 |
| 2          | 12            | 2019-10-27 |
| 3          | -2            | 2019-11-10 |
| 3          | 0             | 2019-11-11 |
| 3          | 3             | 2019-11-12 |
```

## 解题思路

### 核心步骤

1. **筛选时间范围**：只取 2019 年 11 月的天气数据（`day BETWEEN '2019-11-01' AND '2019-11-30'`）
2. **关联表**：将 Countries 表和 Weather 表按 `country_id` 做 JOIN
3. **分组聚合**：按国家分组，计算 `weather_state` 的平均值
4. **条件判断**：用 `CASE WHEN` 根据平均值判断天气类型

### 注意事项

- **只统计 11 月的数据**：示例中有 10 月和 12 月的数据，需要过滤掉
- **weather_state 是数字**：可以直接 `AVG(weather_state)` 计算平均值
- **没有天气数据的国家不出现在结果中**：用 INNER JOIN（不是 LEFT JOIN）

## SQL 代码实现

### 方法一：标准解法（推荐）

```sql
SELECT
    c.country_name,
    CASE
        WHEN AVG(w.weather_state) <= 15 THEN 'Cold'
        WHEN AVG(w.weather_state) >= 25 THEN 'Hot'
        ELSE 'Warm'
    END AS weather_type
FROM Countries c
JOIN Weather w ON c.country_id = w.country_id
WHERE w.day BETWEEN '2019-11-01' AND '2019-11-30'
GROUP BY c.country_id, c.country_name;
```

### 方法二：使用 YEAR 和 MONTH 函数过滤

```sql
SELECT
    c.country_name,
    CASE
        WHEN AVG(w.weather_state) <= 15 THEN 'Cold'
        WHEN AVG(w.weather_state) >= 25 THEN 'Hot'
        ELSE 'Warm'
    END AS weather_type
FROM Countries c
JOIN Weather w ON c.country_id = w.country_id
WHERE YEAR(w.day) = 2019
  AND MONTH(w.day) = 11
GROUP BY c.country_id, c.country_name;
```

### 方法三：使用 DATE_FORMAT 过滤

```sql
SELECT
    c.country_name,
    CASE
        WHEN AVG(w.weather_state) <= 15 THEN 'Cold'
        WHEN AVG(w.weather_state) >= 25 THEN 'Hot'
        ELSE 'Warm'
    END AS weather_type
FROM Countries c
JOIN Weather w ON c.country_id = w.country_id
WHERE DATE_FORMAT(w.day, '%Y-%m') = '2019-11'
GROUP BY c.country_id, c.country_name;
```

### 方法四：子查询方式

```sql
SELECT
    c.country_name,
    CASE
        WHEN w.avg_state <= 15 THEN 'Cold'
        WHEN w.avg_state >= 25 THEN 'Hot'
        ELSE 'Warm'
    END AS weather_type
FROM Countries c
JOIN (
    -- 先计算每个国家 11 月的平均天气状态
    SELECT
        country_id,
        AVG(weather_state) AS avg_state
    FROM Weather
    WHERE day BETWEEN '2019-11-01' AND '2019-11-30'
    GROUP BY country_id
) w ON c.country_id = w.country_id;
```

## 复杂度分析

假设 Countries 表有 `m` 行，Weather 表有 `n` 行：

| 方法 | 时间复杂度 | 备注 |
|------|-----------|------|
| 方法一 | O(n log n) | 过滤 + 分组聚合 |
| 方法二 | O(n log n) | YEAR/MONTH 函数可能影响索引利用 |
| 方法三 | O(n log n) | DATE_FORMAT 同样可能影响索引 |
| 方法四 | O(n log n) | 子查询逻辑更清晰 |

**推荐方法一**：`BETWEEN` 范围查询能利用 `day` 列上的索引，效率最高。

## 关键点总结

1. **时间过滤必不可少**：Weather 表中有 10 月和 12 月的数据，必须过滤掉
2. **CASE WHEN 顺序**：先判断 `<= 15`（Cold），再判断 `>= 25`（Hot），剩余为 Warm
3. **GROUP BY 包含主键或唯一列**：`GROUP BY c.country_id` 即可，加上 `country_name` 是为了 SELECT 中使用
4. **BETWEEN 是闭区间**：`BETWEEN '2019-11-01' AND '2019-11-30'` 包含两端日期
5. **INNER JOIN vs LEFT JOIN**：本题要求"每个国家"，但没有天气记录的国家不应出现，用 INNER JOIN

## 易错点

- **忘记过滤月份**：直接 JOIN 不加 WHERE 会把 10 月、12 月的数据也算进去
- **CASE WHEN 中使用 weather_state 而不是 AVG**：聚合函数在 CASE WHEN 中需要写完整，不能先存变量（除非用子查询）
- **BETWEEN 日期范围**：11 月最后一天是 30 日，不是 31 日
- **字符串大小写**：`'Cold'`、`'Hot'`、`'Warm'` 首字母大写，注意大小写与题目一致
