## 题目描述

表：`Activity`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| player_id    | int     |
| device_id    | int     |
| event_date   | date    |
| games_played | int     |
+--------------+---------+
(player_id, event_date) 是此表的主键（具有唯一值的列的组合）。
这张表显示了某些游戏的玩家活动情况。
每一行是一个玩家的记录，他在某一天使用某个设备注销之前登录并玩了若干游戏（可能为 0）。
```

编写解决方案，报告每位玩家**首次登录**的日期。

返回结果格式如下所示：

**示例 1：**

输入：
```
Activity 表：
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
```

输出：
```
+-----------+-------------+
| player_id | first_login |
+-----------+-------------+
| 1         | 2016-03-01  |
| 2         | 2017-06-25  |
| 3         | 2016-03-02  |
+-----------+-------------+
```

## 解题思路

这是一道简单的 SQL 分组查询题，核心是找每个玩家的**最早登录日期**。

### 核心思想：
1. 按玩家分组（GROUP BY player_id）
2. 找每组的最小日期（MIN(event_date)）

### SQL 知识点：
- **GROUP BY**：分组聚合
- **MIN()**：求最小值
- **AS**：列别名

## SQL 解决方案

### 方法一：GROUP BY + MIN（标准解法）⭐

```sql
-- MySQL / PostgreSQL / SQLite
SELECT 
    player_id,
    MIN(event_date) AS first_login
FROM 
    Activity
GROUP BY 
    player_id;
```

**解释：**
1. `GROUP BY player_id`：按玩家分组
2. `MIN(event_date)`：每组中最早的日期
3. `AS first_login`：重命名列

### 方法二：使用子查询

```sql
SELECT DISTINCT
    player_id,
    (SELECT MIN(event_date) 
     FROM Activity a2 
     WHERE a2.player_id = a1.player_id) AS first_login
FROM 
    Activity a1;
```

**说明：** 这种方法效率较低，不推荐，仅供理解。

### 方法三：使用窗口函数（RANK）

```sql
-- MySQL 8.0+, PostgreSQL, SQL Server
SELECT 
    player_id,
    event_date AS first_login
FROM (
    SELECT 
        player_id,
        event_date,
        RANK() OVER (PARTITION BY player_id ORDER BY event_date) AS rn
    FROM 
        Activity
) t
WHERE rn = 1;
```

**说明：** 这种方法过于复杂，对于本题不必要。

### 方法四：使用 ROW_NUMBER（去重）

```sql
-- MySQL 8.0+, PostgreSQL
SELECT 
    player_id,
    event_date AS first_login
FROM (
    SELECT 
        player_id,
        event_date,
        ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY event_date) AS rn
    FROM 
        Activity
) t
WHERE rn = 1;
```

## 复杂度分析

### 方法一（GROUP BY）：
- **时间复杂度**：O(n log n)
  - 需要排序和分组
- **空间复杂度**：O(n)
  - 临时存储分组结果

### 方法三、四（窗口函数）：
- **时间复杂度**：O(n log n)
  - 排序 + 窗口计算
- **空间复杂度**：O(n)

**结论：** 方法一最简单高效，是首选。

## 关键点总结

1. **分组聚合**：GROUP BY + 聚合函数（MIN/MAX/COUNT 等）
2. **列别名**：使用 AS 重命名输出列
3. **最小值**：MIN() 找最早日期
4. **SQL 风格**：简洁优于复杂，能用聚合就不用窗口函数
5. **主键理解**：(player_id, event_date) 是主键，保证每个玩家每天只有一条记录

## 易错点

1. **忘记 GROUP BY**：没有分组会返回全表的最小日期
2. **列名错误**：结果列应该是 `first_login`，不是 `event_date`
3. **重复数据**：如果用子查询，记得 DISTINCT
4. **语法兼容性**：窗口函数需要数据库支持（MySQL 8.0+）
5. **排序问题**：虽然不需要 ORDER BY，但如果要求结果有序需要加

## 相关 SQL 知识

### 常用聚合函数：
- `MIN()`：最小值
- `MAX()`：最大值
- `COUNT()`：计数
- `SUM()`：求和
- `AVG()`：平均值

### GROUP BY 用法：
```sql
-- 单列分组
SELECT column1, COUNT(*)
FROM table
GROUP BY column1;

-- 多列分组
SELECT column1, column2, COUNT(*)
FROM table
GROUP BY column1, column2;

-- 带条件过滤（HAVING）
SELECT column1, COUNT(*)
FROM table
GROUP BY column1
HAVING COUNT(*) > 5;
```
