## 题目描述

表：`Customers`
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| customer_id   | int     |
| customer_name | varchar |
+---------------+---------+
customer_id 是主键
```

找出所有缺失的顾客 ID。缺失的顾客 ID 是指那些**在 1 到 max(customer_id) 范围内，但不在 Customers 表中**的 ID。

注意，max(customer_id) 不超过 100。

请你返回一个结果表，包含所有缺失的顾客 ID，结果按**升序**排列。

**示例：**
```
输入：
Customers：customer_id=1, customer_name='Alice'
           customer_id=4, customer_name='Bob'
           customer_id=5, customer_name='Charlie'

输出：2, 3
```

## 解题思路

需要生成 1 到 `max(customer_id)` 的连续序列，然后找出不在 `Customers` 表中的值。

**方法：**
1. 生成连续数字序列（MySQL 中用递归 CTE 或 CROSS JOIN 等方法）
2. 用 `NOT IN` 或 `LEFT JOIN` 过滤已存在的 ID

## 代码实现

### 方法一：递归 CTE（MySQL 8.0+）（推荐）

```sql
WITH RECURSIVE seq AS (
    SELECT 1 AS id
    UNION ALL
    SELECT id + 1 FROM seq
    WHERE id < (SELECT MAX(customer_id) FROM Customers)
)
SELECT id AS ids
FROM seq
WHERE id NOT IN (SELECT customer_id FROM Customers)
ORDER BY ids;
```

### 方法二：LEFT JOIN + IS NULL

```sql
WITH RECURSIVE seq AS (
    SELECT 1 AS id
    UNION ALL
    SELECT id + 1 FROM seq
    WHERE id < (SELECT MAX(customer_id) FROM Customers)
)
SELECT s.id AS ids
FROM seq s
LEFT JOIN Customers c ON s.id = c.customer_id
WHERE c.customer_id IS NULL
ORDER BY s.id;
```

### 方法三：使用数字辅助表（不依赖递归 CTE）

```sql
-- 生成数字 1-100（用多个 UNION 或笛卡尔积）
SELECT n.id AS ids
FROM (
    SELECT a.N + b.N * 10 + 1 AS id
    FROM 
        (SELECT 0 AS N UNION SELECT 1 UNION SELECT 2 UNION SELECT 3 UNION SELECT 4 
         UNION SELECT 5 UNION SELECT 6 UNION SELECT 7 UNION SELECT 8 UNION SELECT 9) a,
        (SELECT 0 AS N UNION SELECT 1 UNION SELECT 2 UNION SELECT 3 UNION SELECT 4 
         UNION SELECT 5 UNION SELECT 6 UNION SELECT 7 UNION SELECT 8 UNION SELECT 9) b
) n
WHERE n.id <= (SELECT MAX(customer_id) FROM Customers)
AND n.id NOT IN (SELECT customer_id FROM Customers)
ORDER BY ids;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| 递归 CTE | 逐步生成序列，简洁清晰，MySQL 8.0+ 支持 |
| LEFT JOIN | 语义清晰，适合大表 |
| 笛卡尔积 | 兼容性好，无需 CTE |

## 关键点总结

1. 核心是生成 1 到 `max(customer_id)` 的连续整数序列
2. MySQL 中用递归 CTE 是最简洁的方式
3. 用 `NOT IN` 或 `LEFT JOIN ... IS NULL` 找缺失 ID
4. 题目保证 `max(customer_id) <= 100`，数据量小

## 易错点

- 递归 CTE 终止条件：`WHERE id < max_id`，不是 `<= max_id`（否则会多生成一个）
- 实际应是 `WHERE id < (SELECT MAX(...))` 来控制递归终止
- 结果需要 `ORDER BY` 升序
