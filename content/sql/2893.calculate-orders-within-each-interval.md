## 题目描述

**表：Orders**

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| minute      | int  |
| order_count | int  |
+-------------+------+
minute 是主键，表示第 minute 分钟内的订单数。
```

将时间按 6 分钟一组划分（第 1 组包含第 1-6 分钟，第 2 组包含第 7-12 分钟，以此类推）。计算每组的总订单数，按 interval_no 升序排列。

**示例：**
```
输入：
Orders 表：
+--------+-------------+
| minute | order_count |
+--------+-------------+
| 1      | 0           |
| 2      | 2           |
| 3      | 2           |
| 4      | 1           |
| 5      | 0           |
| 6      | 1           |
| 7      | 0           |
| 8      | 1           |
| 9      | 1           |
| 10     | 1           |
| 11     | 1           |
| 12     | 0           |
+--------+-------------+

输出：
+-------------+-------------+
| interval_no | total_orders|
+-------------+-------------+
| 1           | 6           |
| 2           | 4           |
+-------------+-------------+
```

## 解题思路

用 `CEIL(minute / 6)` 或 `(minute - 1) / 6 + 1` 计算每分钟属于哪个组，然后分组求和。

## 代码实现

### SQL 解法

```sql
SELECT 
    CEIL(minute / 6.0) AS interval_no,
    SUM(order_count) AS total_orders
FROM Orders
GROUP BY CEIL(minute / 6.0)
ORDER BY interval_no;
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 组号 = `CEIL(minute / 6)`，第 1-6 分钟为第 1 组，第 7-12 分钟为第 2 组，以此类推
2. `CEIL()` 向上取整，`FLOOR()` 向下取整
3. 按组号分组求和，按组号升序排列

## 易错点

1. `CEIL(minute / 6)` 中 6 要写成 6.0（或在 MySQL 中确保浮点除法）
2. 整数除法 `minute DIV 6` 会偏移 1，需要调整
