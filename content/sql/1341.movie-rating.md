## 题目描述

表：`Movies`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| title         | varchar |
+---------------+---------+
movie_id 是这个表的主键。
```

表：`Users`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| name          | varchar |
+---------------+---------+
user_id 是表的主键。
```

表：`MovieRating`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| user_id       | int     |
| rating        | int     |
| created_at    | date    |
+---------------+---------+
(movie_id, user_id) 是这个表的主键。
```

请你编写一段 SQL 查询：

- 查找评论电影数量最多的用户名。如果出现平局，返回字典序较小的用户名。
- 查找在 `2020年2月` 平均评分最高的电影名称。如果出现平局，返回字典序较小的电影名称。

查询结果格式如下例所示，两个查询结果用 `UNION ALL` 连接，结果列名为 `results`。

**示例：**
```
输出：
+-----------+
| results   |
+-----------+
| Daniel    |  <- 评论最多的用户
| Frozen 2  |  <- 2020年2月平均评分最高的电影
+-----------+
```

## 解题思路

**两个独立查询用 UNION ALL 合并：**

1. **查询1：** 找评论数最多的用户名（平局取字典序小的）
   - 统计每个用户的评论数
   - 按评论数降序、用户名升序排序
   - 取第一行

2. **查询2：** 找 2020年2月平均评分最高的电影（平局取字典序小的）
   - 筛选 2020-02 的评分记录
   - 统计每部电影的平均评分
   - 按平均分降序、电影名升序排序
   - 取第一行

## SQL 解法

### 方法一：子查询 + UNION ALL（推荐）

```sql
-- 查询1：评论最多的用户名
(
    SELECT u.name AS results
    FROM Users u
    JOIN MovieRating mr ON u.user_id = mr.user_id
    GROUP BY u.user_id, u.name
    ORDER BY COUNT(*) DESC, u.name ASC
    LIMIT 1
)

UNION ALL

-- 查询2：2020年2月平均评分最高的电影名
(
    SELECT m.title AS results
    FROM Movies m
    JOIN MovieRating mr ON m.movie_id = mr.movie_id
    WHERE mr.created_at BETWEEN '2020-02-01' AND '2020-02-29'
    GROUP BY m.movie_id, m.title
    ORDER BY AVG(mr.rating) DESC, m.title ASC
    LIMIT 1
)
;
```

### 方法二：CTE 分步骤写（清晰版）

```sql
-- 使用 CTE 分步骤查询，更易于理解和维护
WITH
-- 步骤1：计算每个用户的评论数
user_ratings AS (
    SELECT
        u.name,
        COUNT(mr.movie_id) AS rating_count
    FROM Users u
    JOIN MovieRating mr ON u.user_id = mr.user_id
    GROUP BY u.user_id, u.name
),

-- 步骤2：找出评论最多的用户（平局取字典序最小）
top_user AS (
    SELECT name AS results
    FROM user_ratings
    ORDER BY rating_count DESC, name ASC
    LIMIT 1
),

-- 步骤3：计算2020年2月每部电影的平均评分
feb_avg AS (
    SELECT
        m.title,
        AVG(mr.rating) AS avg_rating
    FROM Movies m
    JOIN MovieRating mr ON m.movie_id = mr.movie_id
    WHERE DATE_FORMAT(mr.created_at, '%Y-%m') = '2020-02'
    GROUP BY m.movie_id, m.title
),

-- 步骤4：找出平均评分最高的电影（平局取字典序最小）
top_movie AS (
    SELECT title AS results
    FROM feb_avg
    ORDER BY avg_rating DESC, title ASC
    LIMIT 1
)

-- 合并两个查询结果
SELECT results FROM top_user
UNION ALL
SELECT results FROM top_movie;
```

### 方法三：使用 YEAR/MONTH 函数过滤日期

```sql
(
    -- 评论最多的用户
    SELECT u.name AS results
    FROM MovieRating mr
    JOIN Users u ON mr.user_id = u.user_id
    GROUP BY mr.user_id
    ORDER BY COUNT(1) DESC, u.name
    LIMIT 1
)
UNION ALL
(
    -- 2020年2月平均分最高的电影
    SELECT m.title AS results
    FROM MovieRating mr
    JOIN Movies m ON mr.movie_id = m.movie_id
    WHERE YEAR(mr.created_at) = 2020 AND MONTH(mr.created_at) = 2
    GROUP BY mr.movie_id
    ORDER BY AVG(mr.rating) DESC, m.title
    LIMIT 1
)
;
```

### 方法四：使用窗口函数（MySQL 8.0+）

```sql
WITH
user_rank AS (
    SELECT
        u.name,
        COUNT(*) AS cnt,
        RANK() OVER (ORDER BY COUNT(*) DESC, u.name ASC) AS rk
    FROM Users u
    JOIN MovieRating mr ON u.user_id = mr.user_id
    GROUP BY u.user_id, u.name
),
movie_rank AS (
    SELECT
        m.title,
        AVG(mr.rating) AS avg_r,
        RANK() OVER (ORDER BY AVG(mr.rating) DESC, m.title ASC) AS rk
    FROM Movies m
    JOIN MovieRating mr ON m.movie_id = mr.movie_id
    WHERE mr.created_at >= '2020-02-01' AND mr.created_at < '2020-03-01'
    GROUP BY m.movie_id, m.title
)
SELECT name AS results FROM user_rank WHERE rk = 1
UNION ALL
SELECT title AS results FROM movie_rank WHERE rk = 1;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，n 为 MovieRating 表的行数（排序主导）
- **空间复杂度**：O(n)，中间结果存储

## 关键点总结

1. 两个独立查询用 `UNION ALL` 合并（`UNION` 会去重，但这里两行内容不同，用 `UNION ALL` 性能更好）
2. 平局处理：`ORDER BY count DESC, name ASC` 先按数量降序，再按字典序升序
3. 日期过滤：`BETWEEN '2020-02-01' AND '2020-02-29'` 或 `DATE_FORMAT(created_at, '%Y-%m') = '2020-02'`
4. 每个子查询用括号包裹，配合 `LIMIT 1` 使用

## 易错点

1. 使用 `UNION` 而非 `UNION ALL`：`UNION` 会去重，若两个查询结果相同则只返回一行
2. 2020年2月有29天（2020是闰年），用 `BETWEEN '2020-02-01' AND '2020-02-29'` 更准确
3. 子查询要用括号包裹，否则 `LIMIT` 可能作用于整个 `UNION` 而非单个子查询
4. GROUP BY 时要包含 SELECT 中所有非聚合列

## 学习建议

1. `UNION ALL` 是合并多个独立查询结果的标准方法，注意与 `UNION` 的区别
2. `ORDER BY ... LIMIT 1` 是"取第一名"的常用写法，配合 ORDER BY 可以灵活控制取哪一行
3. 日期过滤有多种写法（BETWEEN、DATE_FORMAT、YEAR+MONTH），选择最清晰的即可
4. 处理平局时，在 ORDER BY 中添加第二排序字段（如字典序）是常见技巧
