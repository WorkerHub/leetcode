## 题目描述

表 `Customers`、`Orders`、`Products`，查询每个产品**最近的一笔订单**，若最近日期有多笔，都返回。

结果按 `product_name` 升序，相同则按 `product_id` 升序，相同则按 `order_id` 升序。

## 解题思路

### 窗口函数 RANK 或子查询

找每个产品最新的订单日期，然后筛选出对应的所有订单。

## 代码实现

### 方法一：子查询（推荐）

```sql
-- 子查询找每个产品最新的订单日期，再关联筛选
SELECT
    p.product_name,
    o.product_id,
    o.order_id,
    o.order_date
FROM Orders o
JOIN Products p ON o.product_id = p.product_id
WHERE o.order_date = (
    SELECT MAX(o2.order_date)
    FROM Orders o2
    WHERE o2.product_id = o.product_id
)
ORDER BY p.product_name ASC, o.product_id ASC, o.order_id ASC;
```

### 方法二：窗口函数 RANK

```sql
-- 使用窗口函数对每个产品的订单按日期倒序排名
WITH ranked AS (
    SELECT
        o.order_id,
        o.order_date,
        o.product_id,
        RANK() OVER (
            PARTITION BY o.product_id
            ORDER BY o.order_date DESC
        ) AS rk
    FROM Orders o
)
SELECT
    p.product_name,
    r.product_id,
    r.order_id,
    r.order_date
FROM ranked r
JOIN Products p ON r.product_id = p.product_id
WHERE r.rk = 1
ORDER BY p.product_name ASC, r.product_id ASC, r.order_id ASC;
```

### 方法三：JOIN 最大日期

```sql
-- 先计算每个产品最新日期，再 JOIN 原表筛选
SELECT
    p.product_name,
    o.product_id,
    o.order_id,
    o.order_date
FROM Orders o
JOIN Products p ON o.product_id = p.product_id
JOIN (
    SELECT product_id, MAX(order_date) AS max_date
    FROM Orders
    GROUP BY product_id
) AS latest ON o.product_id = latest.product_id AND o.order_date = latest.max_date
ORDER BY p.product_name ASC, o.product_id ASC, o.order_id ASC;
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. 关键是找每个产品的最新订单日期（MAX）
2. `RANK()` 而非 `ROW_NUMBER()`：同日期多笔订单都要返回
3. 最终排序三列：`product_name, product_id, order_id`

## 易错点

- 用 `ROW_NUMBER()` 会只返回一条（相同日期时），应用 `RANK()` 或子查询 `MAX()`
- 排序需要三个字段
