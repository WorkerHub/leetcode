## 题目描述

表 `Teams`：

| Column Name   | Type    |
|---------------|---------|
| team_id       | int     |
| team_name     | varchar |

`team_id` 是主键。

表 `Matches`：

| Column Name   | Type |
|---------------|------|
| home_team_id  | int  |
| away_team_id  | int  |
| home_team_goals | int |
| away_team_goals | int |

`(home_team_id, away_team_id)` 是主键。

编写 SQL 查询，统计每支队伍的联赛数据：
- `team_name`：队伍名称
- `matches_played`：参加的比赛总场数
- `points`：积分（赢一场得 3 分，平局得 1 分，输得 0 分）
- `goal_for`：进球总数
- `goal_against`：失球总数
- `goal_diff`：进球差（goal_for - goal_against）

返回按积分降序，积分相同按 goal_diff 降序，仍相同按 team_name 升序排列的结果。

## 解题思路

将 Matches 表展开为每队每场比赛的视角（主队和客队分开处理），然后按队伍分组统计。

使用 UNION ALL 将主客场记录合并，每行代表一队在一场比赛中的数据。

## 代码实现

### 方法一：UNION ALL + GROUP BY（推荐）

```sql
WITH TeamStats AS (
    -- 主队视角
    SELECT home_team_id AS team_id,
           home_team_goals AS gf,
           away_team_goals AS ga,
           CASE
               WHEN home_team_goals > away_team_goals THEN 3
               WHEN home_team_goals = away_team_goals THEN 1
               ELSE 0
           END AS pts
    FROM Matches
    UNION ALL
    -- 客队视角
    SELECT away_team_id,
           away_team_goals,
           home_team_goals,
           CASE
               WHEN away_team_goals > home_team_goals THEN 3
               WHEN away_team_goals = home_team_goals THEN 1
               ELSE 0
           END
    FROM Matches
)
SELECT t.team_name,
       COUNT(*) AS matches_played,
       SUM(pts) AS points,
       SUM(gf) AS goal_for,
       SUM(ga) AS goal_against,
       SUM(gf) - SUM(ga) AS goal_diff
FROM TeamStats ts
JOIN Teams t ON ts.team_id = t.team_id
GROUP BY t.team_id, t.team_name
ORDER BY points DESC, goal_diff DESC, team_name ASC;
```

### 方法二：两次 JOIN 后合并

```sql
SELECT t.team_name,
       SUM(m.matches_played) AS matches_played,
       SUM(m.points) AS points,
       SUM(m.gf) AS goal_for,
       SUM(m.ga) AS goal_against,
       SUM(m.gf) - SUM(m.ga) AS goal_diff
FROM Teams t
JOIN (
    SELECT home_team_id AS tid, 1 AS matches_played,
           home_team_goals AS gf, away_team_goals AS ga,
           CASE WHEN home_team_goals > away_team_goals THEN 3
                WHEN home_team_goals = away_team_goals THEN 1
                ELSE 0 END AS points
    FROM Matches
    UNION ALL
    SELECT away_team_id, 1, away_team_goals, home_team_goals,
           CASE WHEN away_team_goals > home_team_goals THEN 3
                WHEN away_team_goals = home_team_goals THEN 1
                ELSE 0 END
    FROM Matches
) m ON t.team_id = m.tid
GROUP BY t.team_id, t.team_name
ORDER BY points DESC, goal_diff DESC, team_name;
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和分组
- **空间复杂度**：O(n)

## 关键点总结

1. UNION ALL 展开主客场为统一视角，每行为一队一场
2. 积分用 CASE WHEN 计算（胜 3 分，平 1 分，负 0 分）
3. goal_diff 可以在 SELECT 中直接计算，不用单独的列

## 易错点

- 每支队伍可能作为主队或客队参赛，两种情况都需要统计
- 排序优先级：积分 -> 净胜球 -> 队名
