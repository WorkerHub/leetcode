## 题目描述

表：`emp`
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_id      | int     |
| dept        | varchar |
| salary      | int     |
+-------------+---------+
emp_id 是主键。
```

找出每个部门中**工资第二高**（不是第二多的员工）的员工的 `emp_id`、`dept` 和 `salary`。

若部门内所有员工工资相同（没有第二高），则不返回该部门。

按 `emp_id` 升序返回。

## 解题思路

使用窗口函数 `DENSE_RANK()` 在每个部门内按工资降序排名，取排名为 2 的记录。

`DENSE_RANK()` 会将相同工资的员工赋予相同排名，并且下一个不同工资直接用下一个排名（不跳过）。

## 代码实现

```sql
WITH ranked AS (
    SELECT
        emp_id,
        dept,
        salary,
        DENSE_RANK() OVER (
            PARTITION BY dept
            ORDER BY salary DESC
        ) AS rnk
    FROM emp
)
SELECT
    emp_id,
    dept,
    salary
FROM ranked
WHERE rnk = 2
ORDER BY emp_id ASC;
```

### 方法二：不使用窗口函数

```sql
SELECT e.emp_id, e.dept, e.salary
FROM emp e
WHERE e.salary = (
    SELECT DISTINCT salary
    FROM emp e2
    WHERE e2.dept = e.dept
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1
)
ORDER BY e.emp_id ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，窗口函数内排序
- 空间复杂度：O(n)

## 关键点总结

1. `DENSE_RANK()` 是处理"第 N 高"问题的标准函数，相同值获得相同排名。
2. `PARTITION BY dept` 在每个部门内独立排名。
3. `DISTINCT salary` 确保取的是第二高的工资值（不是第二多的员工）。

## 易错点

1. 使用 `DENSE_RANK()` 而不是 `RANK()`（后者遇到并列会跳号）。
2. 部门内所有工资相同时，没有第 2 名，WHERE 子句自然会过滤掉这些情况。
3. 题目要求按 `emp_id` 升序，不要遗漏 ORDER BY。
