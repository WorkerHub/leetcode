## 题目描述

表 `Tasks` 包含字段：`task_id`（主键）、`assignee_id`、`submit_date`（提交日期）。

统计以下两个数字并返回：
- `weekend_cnt`：在周末（周六和周日）提交的任务数。
- `working_cnt`：在工作日（周一到周五）提交的任务数。

## 解题思路

使用 MySQL 的 `DAYOFWEEK()` 函数：返回值 1 = 周日，2 = 周一，...，7 = 周六。

周末：`DAYOFWEEK(submit_date) IN (1, 7)`。
工作日：`DAYOFWEEK(submit_date) IN (2, 3, 4, 5, 6)`。

## 代码实现

### 方法一：SUM + IF（推荐）

```sql
SELECT
    SUM(IF(DAYOFWEEK(submit_date) IN (1, 7), 1, 0)) AS weekend_cnt,
    SUM(IF(DAYOFWEEK(submit_date) IN (2, 3, 4, 5, 6), 1, 0)) AS working_cnt
FROM Tasks;
```

### 方法二：CASE WHEN

```sql
SELECT
    SUM(CASE WHEN DAYOFWEEK(submit_date) IN (1, 7) THEN 1 ELSE 0 END) AS weekend_cnt,
    SUM(CASE WHEN DAYOFWEEK(submit_date) BETWEEN 2 AND 6 THEN 1 ELSE 0 END) AS working_cnt
FROM Tasks;
```

### 方法三：WEEKDAY（0=周一,...,6=周日）

```sql
-- WEEKDAY() 返回 0=周一,...,4=周五,5=周六,6=周日
SELECT
    SUM(WEEKDAY(submit_date) >= 5) AS weekend_cnt,
    SUM(WEEKDAY(submit_date) < 5) AS working_cnt
FROM Tasks;
```

## 复杂度分析

- 时间复杂度：O(n)，全表扫描一次。
- 空间复杂度：O(1)。

## 关键点总结

1. `DAYOFWEEK(date)`：返回 1（周日）到 7（周六）。
2. `WEEKDAY(date)`：返回 0（周一）到 6（周日）。
3. 两个函数的周几编号不同，注意区分。

## 易错点

- `DAYOFWEEK` 中 1 = 周日，7 = 周六（非直觉顺序）。
- `WEEKDAY` 中 5 = 周六，6 = 周日。
- `SUM(condition)` 在 MySQL 中会将布尔值转为 0/1 求和，是简洁写法。
