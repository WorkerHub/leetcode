## 题目描述

表 `Store` 记录了客户的消费记录，包含字段：`bill_id`（主键）、`customer_id`、`amount`。

找出**消费金额超过 500** 的不同客户数量。

**示例：**
```
输入：
Store 表：
+---------+-------------+--------+
| bill_id | customer_id | amount |
+---------+-------------+--------+
| 6       | 1           | 549    |
| 8       | 1           | 834    |
| 4       | 2           | 394    |
| 11      | 3           | 657    |
| 13      | 3           | 257    |
+---------+-------------+--------+

输出：
+------------+
| rich_count |
+------------+
| 2          |
+------------+

解释：客户 1 和 3 各有一笔消费超过 500
```

## 解题思路

找出 `amount > 500` 的不同客户，使用 `COUNT(DISTINCT customer_id)` 或先筛选再 `DISTINCT`。

## 代码实现

### 方法一：直接聚合（推荐）

```sql
SELECT COUNT(DISTINCT customer_id) AS rich_count
FROM Store
WHERE amount > 500;
```

### 方法二：子查询

```sql
SELECT COUNT(*) AS rich_count
FROM (
    SELECT DISTINCT customer_id
    FROM Store
    WHERE amount > 500
) t;
```

## 复杂度分析

- 时间复杂度：O(n)，全表扫描
- 空间复杂度：O(n)，临时去重

## 关键点总结

1. 需要去重（`DISTINCT`），同一客户多次消费超过 500 只计一次
2. `WHERE amount > 500` 过滤条件
3. `COUNT(DISTINCT customer_id)` 可以一步完成

## 易错点

- 忘记 `DISTINCT`：同一客户多笔超额消费会被重复计算
- 条件是 `> 500`（严格大于），不是 `>= 500`
