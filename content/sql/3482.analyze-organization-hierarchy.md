## 题目描述

表 `Employees`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
| manager_id  | int     |
| salary      | int     |
+-------------+---------+
```

`employee_id` 是主键。`manager_id` 是自引用外键，根节点的 `manager_id` 为 NULL。

编写查询，对每个员工计算：
1. `level`：在层级结构中的层级（根节点为 1）
2. `team_size`：以该员工为根的子树中的员工总数（包含自身）
3. `salary_budget`：子树中所有员工薪资之和

按 `level` 升序，同层按 `employee_id` 升序排列。

**示例：**

输入：
```
+-------------+--------+------------+--------+
| employee_id | name   | manager_id | salary |
+-------------+--------+------------+--------+
| 1           | Alice  | NULL       | 10000  |
| 2           | Bob    | 1          | 8000   |
| 3           | Carol  | 1          | 7000   |
| 4           | Dave   | 2          | 5000   |
+-------------+--------+------------+--------+
```

输出：
```
+-------------+--------+-------+-----------+---------------+
| employee_id | name   | level | team_size | salary_budget |
+-------------+--------+-------+-----------+---------------+
| 1           | Alice  | 1     | 4         | 30000         |
| 2           | Bob    | 2     | 2         | 13000         |
| 3           | Carol  | 2     | 1         | 7000          |
| 4           | Dave   | 3     | 1         | 5000          |
+-------------+--------+-------+-----------+---------------+
```

## 解题思路

使用递归 CTE（公用表表达式）：
1. 第一步：递归计算每个员工的层级
2. 第二步：计算每个员工的子树员工数和薪资总和（需要递归聚合）

或者：先用递归 CTE 建立完整的祖先-后代关系，再聚合。

## SQL 代码实现

### 方法一：递归 CTE 计算层级 + 子树聚合

```sql
WITH RECURSIVE hierarchy AS (
    -- 锚定成员：根节点
    SELECT
        employee_id,
        name,
        manager_id,
        salary,
        1 AS level
    FROM Employees
    WHERE manager_id IS NULL

    UNION ALL

    -- 递归成员：子节点
    SELECT
        e.employee_id,
        e.name,
        e.manager_id,
        e.salary,
        h.level + 1
    FROM Employees e
    JOIN hierarchy h ON e.manager_id = h.employee_id
),
-- 计算所有祖先-后代关系（ancestor, descendant）
ancestor_descendant AS (
    -- 每个员工是自己的后代
    SELECT employee_id AS ancestor, employee_id AS descendant, salary
    FROM Employees

    UNION ALL

    SELECT h.manager_id AS ancestor, ad.descendant, ad.salary
    FROM ancestor_descendant ad
    JOIN Employees h ON ad.ancestor = h.employee_id
    WHERE h.manager_id IS NOT NULL
)
SELECT
    h.employee_id,
    h.name,
    h.level,
    COUNT(ad.descendant) AS team_size,
    SUM(ad.salary) AS salary_budget
FROM hierarchy h
JOIN ancestor_descendant ad ON h.employee_id = ad.ancestor
GROUP BY h.employee_id, h.name, h.level
ORDER BY h.level ASC, h.employee_id ASC;
```

### 方法二：分步递归 CTE

```sql
WITH RECURSIVE
-- 第一步：计算每个节点的层级
level_cte AS (
    SELECT employee_id, name, manager_id, salary, 1 AS lvl
    FROM Employees
    WHERE manager_id IS NULL

    UNION ALL

    SELECT e.employee_id, e.name, e.manager_id, e.salary, lc.lvl + 1
    FROM Employees e
    INNER JOIN level_cte lc ON e.manager_id = lc.employee_id
),

-- 第二步：计算后代关系
descendants AS (
    SELECT employee_id AS root_id, employee_id AS desc_id, salary AS desc_salary
    FROM Employees

    UNION ALL

    SELECT d.root_id, e.employee_id, e.salary
    FROM descendants d
    JOIN Employees e ON e.manager_id = d.desc_id
)

SELECT
    lc.employee_id,
    lc.name,
    lc.lvl AS level,
    COUNT(d.desc_id) AS team_size,
    SUM(d.desc_salary) AS salary_budget
FROM level_cte lc
JOIN descendants d ON lc.employee_id = d.root_id
GROUP BY lc.employee_id, lc.name, lc.lvl
ORDER BY lc.lvl, lc.employee_id;
```

### 方法三：合并递归 CTE

```sql
WITH RECURSIVE tree AS (
    SELECT
        employee_id,
        employee_id AS root_id,
        name,
        manager_id,
        salary,
        1 AS level
    FROM Employees
    WHERE manager_id IS NULL

    UNION ALL

    SELECT
        e.employee_id,
        e.employee_id AS root_id,
        e.name,
        e.manager_id,
        e.salary,
        t.level + 1
    FROM Employees e
    JOIN tree t ON e.manager_id = t.employee_id
),

-- 使用路径传播计算子树
subtree AS (
    SELECT
        ancestor.employee_id AS mgr_id,
        descendant.employee_id AS emp_id,
        descendant.salary
    FROM tree ancestor
    JOIN tree descendant ON descendant.level >= ancestor.level
    -- 此写法需要更多约束，推荐方法一
)

SELECT
    t.employee_id,
    t.name,
    t.level,
    COUNT(s.emp_id) AS team_size,
    SUM(s.salary) AS salary_budget
FROM tree t
JOIN subtree s ON t.employee_id = s.mgr_id
GROUP BY t.employee_id, t.name, t.level
ORDER BY t.level, t.employee_id;
```

## 复杂度分析

- 时间复杂度：O(n^2)（递归 CTE 遍历）
- 空间复杂度：O(n^2)（存储所有祖先-后代关系）

## 关键点总结

1. 递归 CTE：WITH RECURSIVE 处理树形结构
2. 层级计算：根节点 level=1，子节点 level=父+1
3. 子树聚合：通过祖先-后代关系表实现
4. 双重递归 CTE：一个算层级，一个算后代关系

## 易错点

1. team_size 包含员工自身（自己也是自己的后代）
2. salary_budget 包含自身薪资
3. ORDER BY 先按 level 再按 employee_id
