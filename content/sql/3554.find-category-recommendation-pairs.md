## 题目描述

表 `ProductPurchases`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| product_id  | int     |
| quantity    | int     |
+-------------+---------+
(user_id, product_id) 是主键。
```

表 `ProductInfo`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| category    | varchar |
| price       | decimal |
+-------------+---------+
product_id 是主键。
```

找出所有"类别推荐对"：两个类别 `(category1, category2)`（`category1 < category2`），满足：
至少有 3 个不同用户同时购买了这两个类别中的产品（每个类别至少购买一个）。

**示例：**

```
输入：
ProductPurchases：user_id=1购买product_id=1,2,3
ProductInfo：product 1 属于 A，product 2 属于 B，product 3 属于 A

输出：
category1 | category2 | common_users
```

## 解题思路

1. 连接 `ProductPurchases` 和 `ProductInfo`，得到每个用户购买的类别
2. 对用户-类别去重（同一用户同一类别只计一次）
3. 自连接找同一用户购买的不同类别对
4. 按类别对分组，统计共同用户数 >= 3

## 代码实现

### 方法一：标准 SQL（推荐）

```sql
WITH UserCategories AS (
    SELECT DISTINCT 
        pp.user_id,
        pi.category
    FROM ProductPurchases pp
    JOIN ProductInfo pi ON pp.product_id = pi.product_id
)
SELECT 
    uc1.category AS category1,
    uc2.category AS category2,
    COUNT(DISTINCT uc1.user_id) AS common_users
FROM UserCategories uc1
JOIN UserCategories uc2
    ON uc1.user_id = uc2.user_id
    AND uc1.category < uc2.category
GROUP BY uc1.category, uc2.category
HAVING COUNT(DISTINCT uc1.user_id) >= 3
ORDER BY category1, category2;
```

### 方法二：子查询分步实现

```sql
-- 先获取每个用户购买的类别（去重）
WITH UserCategories AS (
    SELECT DISTINCT pp.user_id, pi.category
    FROM ProductPurchases pp
    INNER JOIN ProductInfo pi ON pp.product_id = pi.product_id
),
-- 再找每对类别的共同用户数
CategoryPairs AS (
    SELECT 
        a.category AS category1,
        b.category AS category2,
        COUNT(*) AS common_users
    FROM UserCategories a
    JOIN UserCategories b 
        ON a.user_id = b.user_id 
        AND a.category < b.category
    GROUP BY a.category, b.category
)
SELECT category1, category2, common_users
FROM CategoryPairs
WHERE common_users >= 3
ORDER BY category1, category2;
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为用户数，m 为类别数（自连接）
- 空间复杂度：O(n * m)，中间结果集

## 关键点总结

1. 先对用户-类别去重（避免同一用户多次购买同一类别被重复计算）
2. 自连接时用 `category1 < category2` 避免重复对
3. `HAVING COUNT >= 3` 过滤共同用户数

## 易错点

1. 用户可以购买同一类别的多个产品，需要先去重
2. `category1 < category2` 是字符串比较（字典序）
3. 使用 `COUNT(DISTINCT user_id)` 确保计数准确
