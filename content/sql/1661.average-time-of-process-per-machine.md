## 题目描述

表：`Activity`
```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| machine_id     | int     |
| process_id     | int     |
| activity_type  | enum    |
| timestamp      | float   |
+----------------+---------+
(machine_id, process_id, activity_type) 是主键
activity_type 是 ENUM ('start', 'end')
```

找出每台机器各自完成一个进程任务平均花费的时间（`processing_time`）。

- 处理时间 = `end.timestamp - start.timestamp`
- 平均处理时间 = 所有进程处理时间之和 / 进程数量
- 结果保留三位小数，按 `machine_id` 升序排序

## 解题思路

1. 将 `start` 和 `end` 事件自连接，用 `machine_id` 和 `process_id` 关联
2. 计算每个进程的处理时间
3. 按机器分组求平均值

## 代码实现

### 方法一：自连接（推荐）

```sql
SELECT
    a1.machine_id,
    ROUND(AVG(a2.timestamp - a1.timestamp), 3) AS processing_time
FROM Activity a1
JOIN Activity a2
    ON a1.machine_id = a2.machine_id
    AND a1.process_id = a2.process_id
    AND a1.activity_type = 'start'
    AND a2.activity_type = 'end'
GROUP BY a1.machine_id
ORDER BY a1.machine_id;
```

### 方法二：使用条件聚合

```sql
SELECT
    machine_id,
    ROUND(
        SUM(CASE WHEN activity_type = 'end' THEN timestamp ELSE -timestamp END) 
        / COUNT(DISTINCT process_id),
        3
    ) AS processing_time
FROM Activity
GROUP BY machine_id
ORDER BY machine_id;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| 自连接 | 直观，每个进程的 start 和 end 配对计算 |
| 条件聚合 | 用正负号技巧，end 加，start 减，差值即处理时间 |

## 关键点总结

1. 自连接：将 start 和 end 分别作为两个别名，通过 machine_id 和 process_id 关联
2. 结果保留三位小数：`ROUND(..., 3)`
3. 方法二巧妙：end 时间戳相加，start 时间戳取负，SUM 即为总处理时间

## 易错点

- 自连接时必须同时匹配 `machine_id` 和 `process_id`
- 平均值 = 所有进程时间 / 进程数（不是行数）
- 结果保留 3 位小数
