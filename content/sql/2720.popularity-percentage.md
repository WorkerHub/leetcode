## 题目描述

表 `Friends`：
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user1       | int  |
| user2       | int  |
+-------------+------+
```
`(user1, user2)` 是该表的主键。每行表示 user1 和 user2 是朋友，user1 < user2。

查找每个用户的受欢迎程度百分比，计算方式为：与该用户是朋友的用户数除以平台总用户数，再乘以 100，四舍五入保留两位小数。

返回按 `user1` 升序排列的结果。

**提示：** 用户列表是 Friends 表中所有出现的用户。

## 解题思路

1. 将双向好友关系展开（user1 和 user2 互为朋友）
2. 统计每个用户的好友数
3. 统计平台总用户数（所有在表中出现的不同用户）
4. 计算百分比

## 代码实现

### 方法一：SQL 实现（推荐）

```sql
WITH all_friends AS (
    -- 展开双向关系
    SELECT user1 AS user_id, user2 AS friend_id FROM Friends
    UNION ALL
    SELECT user2 AS user_id, user1 AS friend_id FROM Friends
),
friend_count AS (
    -- 每个用户的好友数
    SELECT user_id, COUNT(*) AS friend_cnt
    FROM all_friends
    GROUP BY user_id
),
total_users AS (
    -- 平台总用户数
    SELECT COUNT(DISTINCT user_id) AS total
    FROM all_friends
)
SELECT
    user_id AS user1,
    ROUND(friend_cnt * 100.0 / total, 2) AS percentage_popularity
FROM friend_count, total_users
ORDER BY user1;
```

## 复杂度分析

- 时间复杂度：O(n)，n 为 Friends 表行数
- 空间复杂度：O(n)

## 关键点总结

1. 好友关系是双向的，需将 `(user1, user2)` 展开为两条记录
2. 总用户数从所有出现的用户中统计（不是某个固定数）
3. 用 `ROUND(..., 2)` 保留两位小数

## 易错点

1. 别忘了展开双向关系，否则某些用户的好友数统计不全
2. 百分比计算时使用浮点除法（乘以 100.0）
