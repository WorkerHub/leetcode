## 题目描述

查询至少有5名学生的所有班级。

## SQL 代码实现

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(DISTINCT student) >= 5;
```

## 关键点总结

1. **GROUP BY**：按班级分组
2. **HAVING**：过滤分组后的结果
3. **DISTINCT**：去重学生
