## 题目描述

表：`Teams`

```
+---------------+----------+
| Column Name   | Type     |
+---------------+----------+
| team_id       | int      |
| team_name     | varchar  |
+---------------+----------+
```

team_id 是该表的主键。

该表的每一行都代表一支足球队。

表：`Matches`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| match_id      | int     |
| host_team     | int     |
| guest_team    | int     |
| host_goals    | int     |
| guest_goals   | int     |
+---------------+---------+
```

match_id 是该表的主键。

该表的每一行都代表一场已结束的比赛，比赛双方分别是 host_team 和 guest_team。

host_team 和 guest_team 都是 Teams 表中 team_id 的外键。

host_goals 和 guest_goals 分别表示主队和客队的进球数。

你希望在所有比赛之后计算所有队伍的比分。积分奖励方式如下：

- 如果一支队伍赢了一场比赛（得分严格大于对手），就得 3 分。
- 如果一支队伍在一场比赛中打平（得分等于对手），就得 1 分。
- 如果一支队伍输掉了一场比赛（得分严格小于对手），就得 0 分。

编写一个 SQL 查询以选出所有队伍的 team_id，team_name 和 num_points。

返回的结果根据 num_points 降序排序。如果两队积分相同，则按 team_id 升序排列结果。

查询结果格式如下。

示例 1：

输入：
Teams 表：
```
+-----------+--------------+
| team_id   | team_name    |
+-----------+--------------+
| 10        | Leetcode FC  |
| 20        | NewYork FC   |
| 30        | Atlanta FC   |
| 40        | Chicago FC   |
| 50        | Toronto FC   |
+-----------+--------------+
```

Matches 表：
```
+------------+--------------+---------------+-------------+--------------+
| match_id   | host_team    | guest_team    | host_goals  | guest_goals  |
+------------+--------------+---------------+-------------+--------------+
| 1          | 10           | 20            | 3           | 0            |
| 2          | 30           | 10            | 2           | 2            |
| 3          | 10           | 50            | 5           | 1            |
| 4          | 20           | 30            | 1           | 0            |
| 5          | 50           | 30            | 1           | 0            |
+-----------+--------------+---------------+-------------+--------------+
```

输出：
```
+------------+--------------+---------------+
| team_id    | team_name    | num_points    |
+------------+--------------+---------------+
| 10         | Leetcode FC  | 7             |
| 20         | NewYork FC   | 3             |
| 50         | Toronto FC   | 3             |
| 30         | Atlanta FC   | 1             |
| 40         | Chicago FC   | 0             |
+------------+--------------+---------------+
```

解释：
- Leetcode FC（team_id=10）在 3 场比赛中得到 7 分：
  - match_id=1：作为主队，3-0 赢了 NewYork FC，得 3 分
  - match_id=2：作为客队，2-2 与 Atlanta FC 打平，得 1 分
  - match_id=3：作为主队，5-1 赢了 Toronto FC，得 3 分
- NewYork FC（team_id=20）在 2 场比赛中得到 3 分：
  - match_id=1：作为客队，0-3 输给 Leetcode FC，得 0 分
  - match_id=4：作为主队，1-0 赢了 Atlanta FC，得 3 分
- Toronto FC（team_id=50）在 2 场比赛中得到 3 分：
  - match_id=3：作为客队，1-5 输给 Leetcode FC，得 0 分
  - match_id=5：作为主队，1-0 赢了 Atlanta FC，得 3 分
- Atlanta FC（team_id=30）在 3 场比赛中得到 1 分：
  - match_id=2：作为主队，2-2 与 Leetcode FC 打平，得 1 分
  - match_id=4：作为客队，0-1 输给 NewYork FC，得 0 分
  - match_id=5：作为客队，0-1 输给 Toronto FC，得 0 分
- Chicago FC（team_id=40）没有参加任何比赛，得 0 分

## 解题思路

这道题的核心挑战在于：

1. **队伍双重身份**：每支队伍在不同比赛中可能是主队或客队，需要分别统计
2. **积分计算规则**：根据进球数差异判断胜/平/负，分别得 3/1/0 分
3. **包含未参赛队伍**：即使队伍没有参加任何比赛，也要显示其积分为 0

解决方案：

**核心思路**：将每支队伍的主场比赛和客场比赛分开统计，然后合并求和。

1. **分离主客场**：
   - 查询主场比赛，计算每支队伍作为主队的得分
   - 查询客场比赛，计算每支队伍作为客队的得分
   - 使用 UNION ALL 合并两个结果集

2. **积分计算**：
   - 使用 CASE WHEN 根据进球数差异计算积分
   - 主队：`host_goals > guest_goals` 得 3 分，`host_goals = guest_goals` 得 1 分，否则 0 分
   - 客队：`guest_goals > host_goals` 得 3 分，`guest_goals = host_goals` 得 1 分，否则 0 分

3. **汇总统计**：
   - 对合并后的结果按 team_id 分组求和
   - 使用 LEFT JOIN 确保所有队伍都出现在结果中（包括未参赛队伍）

4. **排序**：
   - 按 num_points 降序排列
   - 积分相同时按 team_id 升序排列

## SQL 代码实现

### 方法一：UNION ALL + LEFT JOIN（推荐，逻辑清晰）

```sql
SELECT 
    t.team_id,
    t.team_name,
    COALESCE(SUM(points), 0) AS num_points
FROM 
    Teams t
LEFT JOIN (
    -- 主场比赛积分
    SELECT 
        host_team AS team_id,
        CASE 
            WHEN host_goals > guest_goals THEN 3
            WHEN host_goals = guest_goals THEN 1
            ELSE 0
        END AS points
    FROM 
        Matches
    
    UNION ALL
    
    -- 客场比赛积分
    SELECT 
        guest_team AS team_id,
        CASE 
            WHEN guest_goals > host_goals THEN 3
            WHEN guest_goals = host_goals THEN 1
            ELSE 0
        END AS points
    FROM 
        Matches
) AS match_points ON t.team_id = match_points.team_id
GROUP BY 
    t.team_id, t.team_name
ORDER BY 
    num_points DESC, t.team_id ASC;
```

**说明**：
- 使用子查询将主场和客场比赛分开处理
- UNION ALL 合并两个结果集（不去重，因为同一队伍的不同比赛应该累加）
- LEFT JOIN 确保所有队伍都出现，即使没有参加比赛
- COALESCE 处理 NULL 值，未参赛队伍的积分为 0
- ORDER BY 先按积分降序，再按 team_id 升序

### 方法二：使用 CTE（公用表表达式）

```sql
WITH match_points AS (
    -- 主场积分
    SELECT 
        host_team AS team_id,
        CASE 
            WHEN host_goals > guest_goals THEN 3
            WHEN host_goals = guest_goals THEN 1
            ELSE 0
        END AS points
    FROM 
        Matches
    
    UNION ALL
    
    -- 客场积分
    SELECT 
        guest_team AS team_id,
        CASE 
            WHEN guest_goals > host_goals THEN 3
            WHEN guest_goals = host_goals THEN 1
            ELSE 0
        END AS points
    FROM 
        Matches
)
SELECT 
    t.team_id,
    t.team_name,
    COALESCE(SUM(mp.points), 0) AS num_points
FROM 
    Teams t
LEFT JOIN 
    match_points mp ON t.team_id = mp.team_id
GROUP BY 
    t.team_id, t.team_name
ORDER BY 
    num_points DESC, t.team_id ASC;
```

**说明**：
- 使用 CTE（WITH 子句）使代码结构更清晰
- 逻辑与方法一相同，但可读性更好
- CTE 可以被多次引用，便于后续扩展

### 方法三：使用 IFNULL/COALESCE 简化

```sql
SELECT 
    t.team_id,
    t.team_name,
    IFNULL(SUM(
        CASE 
            WHEN t.team_id = m.host_team THEN
                CASE 
                    WHEN m.host_goals > m.guest_goals THEN 3
                    WHEN m.host_goals = m.guest_goals THEN 1
                    ELSE 0
                END
            WHEN t.team_id = m.guest_team THEN
                CASE 
                    WHEN m.guest_goals > m.host_goals THEN 3
                    WHEN m.guest_goals = m.host_goals THEN 1
                    ELSE 0
                END
            ELSE 0
        END
    ), 0) AS num_points
FROM 
    Teams t
LEFT JOIN 
    Matches m ON t.team_id = m.host_team OR t.team_id = m.guest_team
GROUP BY 
    t.team_id, t.team_name
ORDER BY 
    num_points DESC, t.team_id ASC;
```

**说明**：
- 使用 OR 条件进行 JOIN，一次性匹配主场和客场
- 嵌套 CASE WHEN 判断队伍身份并计算积分
- 代码更紧凑，但可读性稍差
- 注意：在某些数据库中，OR 条件的 JOIN 性能可能较差

## 复杂度分析

### SQL 解法

- **时间复杂度**：O(m + n)，其中 m 是 Matches 表的行数，n 是 Teams 表的行数
  - UNION ALL 操作：O(m)，需要扫描两次 Matches 表
  - GROUP BY 聚合：O(m)，对合并后的结果进行分组
  - LEFT JOIN：O(n)，连接所有队伍
  - 排序：O(n log n)，对最终结果排序
- **空间复杂度**：O(m)，存储 UNION ALL 合并后的中间结果

### Python Pandas 解法

- **时间复杂度**：O(m + n log n)
  - concat 操作：O(m)
  - groupby 和 sum：O(m)
  - merge 操作：O(n)
  - 排序：O(n log n)
- **空间复杂度**：O(m + n)，存储中间结果和最终输出

## 关键点总结

1. **主客场分离处理**：每支队伍在不同比赛中角色不同，需要分别统计积分后再合并
2. **UNION ALL vs UNION**：使用 UNION ALL 保留所有记录（包括重复），因为同一队伍的不同比赛积分需要累加
3. **LEFT JOIN 的重要性**：确保所有队伍都出现在结果中，即使没有参加任何比赛
4. **NULL 值处理**：使用 COALESCE 或 IFNULL 将未参赛队伍的积分设为 0
5. **排序规则**：先按积分降序，积分相同时按 team_id 升序

## 易错点

1. **忘记处理未参赛队伍**：
   ```sql
   -- 错误：只会显示参加过比赛的队伍
   SELECT team_id, SUM(points) FROM match_points GROUP BY team_id
   
   -- 正确：使用 LEFT JOIN 确保所有队伍都出现
   SELECT t.team_id, COALESCE(SUM(points), 0) 
   FROM Teams t LEFT JOIN match_points mp ON ...
   ```

2. **使用 UNION 而不是 UNION ALL**：
   ```sql
   -- 错误：UNION 会去重，可能丢失某些比赛的积分
   SELECT host_team, points FROM ... UNION SELECT guest_team, points FROM ...
   
   -- 正确：UNION ALL 保留所有记录
   SELECT host_team, points FROM ... UNION ALL SELECT guest_team, points FROM ...
   ```

3. **积分计算逻辑错误**：
   ```sql
   -- 错误：主队和客队的胜负判断条件相同
   CASE WHEN host_goals > guest_goals THEN 3 ...  -- 主队
   CASE WHEN host_goals > guest_goals THEN 3 ...  -- 客队（应该是 guest_goals > host_goals）
   
   -- 正确：注意主客队的判断条件相反
   -- 主队：host_goals > guest_goals
   -- 客队：guest_goals > host_goals
   ```

4. **排序规则错误**：
   ```sql
   -- 错误：积分降序但 team_id 也降序
   ORDER BY num_points DESC, team_id DESC
   
   -- 正确：积分降序，team_id 升序
   ORDER BY num_points DESC, team_id ASC
   ```

5. **Pandas 中的数据类型**：
   ```python
   # 错误：fillna 后可能是浮点型
   result['num_points'] = result['num_points'].fillna(0)
   
   # 正确：需要转换为整数类型
   result['num_points'] = result['num_points'].fillna(0).astype(int)
   ```

6. **OR 条件 JOIN 的性能问题**：
   ```sql
   -- 可能性能较差，特别是在大数据集上
   FROM Teams t LEFT JOIN Matches m 
   ON t.team_id = m.host_team OR t.team_id = m.guest_team
   
   -- 推荐：使用 UNION ALL 分离处理
   ```

## 学习建议

### 对于 SQL 新手

1. **理解 UNION 和 UNION ALL 的区别**：
   - UNION：合并结果集并去重，性能较差
   - UNION ALL：合并结果集保留重复，性能更好
   - 本题场景：需要累加积分，应使用 UNION ALL

2. **掌握 LEFT JOIN 的使用**：
   - 用途：确保左表的所有记录都出现在结果中
   - 场景：本题中保证所有队伍（包括未参赛的）都出现
   - 配合 COALESCE 处理 NULL 值

3. **嵌套 CASE WHEN 的写法**：
   - 外层 CASE：判断队伍是主队还是客队
   - 内层 CASE：根据进球数判断胜平负
   - 建议先用简单的 CASE WHEN，熟练后再嵌套

4. **CTE（公用表表达式）的优势**：
   - 代码结构清晰，易于调试
   - 可以被多次引用
   - 提高 SQL 可读性

5. **建议练习步骤**：
   - 第一步：先查询主场比赛的积分
   - 第二步：再查询客场比赛的积分
   - 第三步：使用 UNION ALL 合并
   - 第四步：GROUP BY 统计总积分
   - 第五步：LEFT JOIN Teams 表
   - 第六步：添加排序规则

### 对于 Python/Pandas 学习者

1. **DataFrame 的拼接**：
   - `pd.concat()`：按行或列拼接多个 DataFrame
   - `axis=0`（默认）：纵向拼接（行）
   - `ignore_index=True`：重置索引

2. **条件逻辑的多种实现**：
   - `apply + lambda`：灵活但性能较差
   - `np.select()`：性能好，适合多条件判断
   - `np.where()`：适合简单的二分条件

3. **merge 的 how 参数**：
   - `how='left'`：左连接，保留左表所有记录
   - `how='right'`：右连接，保留右表所有记录
   - `how='inner'`：内连接，只保留匹配记录
   - `how='outer'`：外连接，保留所有记录

4. **处理缺失值**：
   - `fillna(0)`：填充 NULL 为 0
   - `astype(int)`：转换数据类型
   - 注意：先 fillna 再 astype，避免类型转换错误

5. **排序的多列条件**：
   - `sort_values(by=['col1', 'col2'], ascending=[False, True])`
   - 可以为不同列指定不同的排序方向
