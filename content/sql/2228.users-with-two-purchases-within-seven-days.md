## 题目描述

表：`Purchases`

```
+---------------+----------+
| Column Name   | Type     |
+---------------+----------+
| purchase_id   | int      |
| user_id       | int      |
| purchase_date | date     |
+---------------+----------+
purchase_id 是该表的主键。
```

编写一个 SQL 查询，找出在任意 7 天窗口内（包含两端）**至少进行了 2 次购买**的用户 ID，按 `user_id` 升序排列。

**示例：**
```
Purchases 表：
+-------------+---------+---------------+
| purchase_id | user_id | purchase_date |
+-------------+---------+---------------+
| 4           | 2       | 2022-03-13    |
| 1           | 5       | 2022-02-11    |
| 3           | 7       | 2022-06-19    |
| 6           | 2       | 2022-03-20    |
| 5           | 2       | 2022-03-20    |
| 2           | 2       | 2022-06-19    |
+-------------+---------+---------------+

输出：
+---------+
| user_id |
+---------+
| 2       |
+---------+
解释：user 2 在3月13日和3月20日有两次购买，差值7天，满足条件。
```

## 解题思路

自连接 `Purchases` 表，对同一用户的不同购买记录，检查两次购买日期之差是否在 0 到 6 天内（即 7 天窗口）。

- 自连接条件：`a.user_id = b.user_id AND a.purchase_id < b.purchase_id`（避免重复）。
- 日期差：`DATEDIFF(b.purchase_date, a.purchase_date) BETWEEN 0 AND 6`。
- 用 `DISTINCT` 去重，按 `user_id` 排序。

## 代码实现

### 方法一：自连接（推荐）

```sql
SELECT DISTINCT a.user_id
FROM Purchases a
JOIN Purchases b
  ON a.user_id = b.user_id
  AND a.purchase_id < b.purchase_id
  AND DATEDIFF(b.purchase_date, a.purchase_date) BETWEEN 0 AND 6
ORDER BY a.user_id;
```

### 方法二：窗口函数（LAG）

```sql
SELECT DISTINCT user_id
FROM (
    SELECT
        user_id,
        purchase_date,
        LAG(purchase_date) OVER (PARTITION BY user_id ORDER BY purchase_date) AS prev_date
    FROM Purchases
) t
WHERE DATEDIFF(purchase_date, prev_date) BETWEEN 0 AND 6
ORDER BY user_id;
```

## 复杂度分析

- 时间复杂度：O(n^2)（自连接），对每个用户的购买记录两两比较。使用索引可优化。
- 空间复杂度：O(n)，结果集大小。

## 关键点总结

1. 7 天窗口包含两端，`DATEDIFF` 范围是 `[0, 6]`（0 表示同一天）。
2. 自连接用 `purchase_id` 避免同一行自连接（`a.purchase_id < b.purchase_id`）。
3. 窗口函数 LAG 获取前一次购买日期，更高效。

## 易错点

- `DATEDIFF(b.purchase_date, a.purchase_date)` 中参数顺序：后减前。
- 7 天窗口：差值为 0（同一天）到 6（差6天，即7天内），不是 <= 7。
