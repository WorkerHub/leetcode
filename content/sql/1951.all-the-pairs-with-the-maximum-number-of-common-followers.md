## 题目描述

表 `Relations`：
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| follower_id | int  |
+-------------+------+
(user_id, follower_id) 是主键。
```

找出所有**共同粉丝数量最多**的用户对 `(user1_id, user2_id)`，要求 `user1_id < user2_id`。

返回结果（按 user1_id 升序，再按 user2_id 升序）。

---

## 解题思路

### 核心思想：自连接找共同粉丝 + 窗口函数取最大

1. 对 `Relations` 表自连接，找同一 `follower_id` 关注的两个不同用户（即共同被关注）
2. 统计每对用户的共同关注者数量
3. 用窗口函数找最大值，筛选等于最大值的对

---

## 代码实现

### 方法一：自连接 + 窗口函数（推荐）

```sql
WITH pairs AS (
    SELECT
        r1.user_id AS user1_id,
        r2.user_id AS user2_id,
        COUNT(*) AS common_cnt
    FROM Relations r1
    JOIN Relations r2
        ON r1.follower_id = r2.follower_id
        AND r1.user_id < r2.user_id
    GROUP BY r1.user_id, r2.user_id
)
SELECT user1_id, user2_id
FROM pairs
WHERE common_cnt = (SELECT MAX(common_cnt) FROM pairs)
ORDER BY user1_id, user2_id;
```

### 方法二：使用 RANK 窗口函数

```sql
WITH pairs AS (
    SELECT
        r1.user_id AS user1_id,
        r2.user_id AS user2_id,
        COUNT(*) AS common_cnt
    FROM Relations r1
    JOIN Relations r2
        ON r1.follower_id = r2.follower_id
        AND r1.user_id < r2.user_id
    GROUP BY r1.user_id, r2.user_id
),
ranked AS (
    SELECT
        user1_id,
        user2_id,
        RANK() OVER (ORDER BY common_cnt DESC) AS rk
    FROM pairs
)
SELECT user1_id, user2_id
FROM ranked
WHERE rk = 1
ORDER BY user1_id, user2_id;
```

---

## 复杂度分析

| 操作 | 说明 |
|------|------|
| 自连接 | O(n²) 最坏 |
| GROUP BY | O(n log n) |
| 子查询最大值 | O(n) |

---

## 关键点总结

1. 自连接条件：同一 `follower_id`，且 `r1.user_id < r2.user_id`（避免重复和自配对）
2. 可能有多对用户共同粉丝数相同（均为最大），需要全部返回
3. `RANK() = 1` 自动处理并列最大的情况

---

## 易错点

- 不能用 `LIMIT 1` 代替窗口函数（会漏掉并列第一的情况）
- 结果必须按 `user1_id, user2_id` 排序
