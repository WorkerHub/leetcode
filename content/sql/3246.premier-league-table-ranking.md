## 题目描述

表：`TeamStats`

```
+-----------------+---------+
| Column Name     | Type    |
+-----------------+---------+
| team_id         | int     |
| team_name       | varchar |
| matches_played  | int     |
| wins            | int     |
| draws           | int     |
| losses          | int     |
+-----------------+---------+
```

`team_id` 是主键。

编写 SQL 查询，计算每支球队的积分（赢得 3 分，平局 1 分，输了 0 分），并按积分降序排列（积分相同按队名升序），给出排名。

返回结果包含：
- `team_id`
- `team_name`
- `matches_played`
- `wins`
- `draws`
- `losses`
- `points`：总积分
- `position`：排名（相同积分排名相同，下一排名跳过）

**示例输出：**
```
+---------+------------+----------------+------+-------+--------+--------+----------+
| team_id | team_name  | matches_played | wins | draws | losses | points | position |
+---------+------------+----------------+------+-------+--------+--------+----------+
| ...     | ...        | ...            | ...  | ...   | ...    | ...    | ...      |
+---------+------------+----------------+------+-------+--------+--------+----------+
```

## 解题思路

计算积分 = `wins * 3 + draws * 1`，然后用 `RANK()` 窗口函数计算排名（相同积分同名次，下一名跳过）。

## 代码实现

```sql
SELECT
    team_id,
    team_name,
    matches_played,
    wins,
    draws,
    losses,
    wins * 3 + draws AS points,
    RANK() OVER (
        ORDER BY wins * 3 + draws DESC, team_name ASC
    ) AS position
FROM TeamStats
ORDER BY position ASC, team_name ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 积分公式：`wins * 3 + draws * 1`
2. 用 `RANK()` 实现相同积分同名次（有跳跃）
3. 排序：先按积分降序，再按队名升序

## 易错点

1. `RANK()` 和 `DENSE_RANK()` 的区别：相同积分有跳跃用 `RANK()`
2. 排序 ORDER BY 需要与 RANK() 的 ORDER BY 一致
