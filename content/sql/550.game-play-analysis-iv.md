## 题目描述

Table: Activity

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| player_id    | int     |
| device_id    | int     |
| event_date   | date    |
| games_played | int     |
+--------------+---------+
(player_id, event_date) 是此表的主键
这张表显示了某些游戏玩家的活动情况
每一行是一个玩家的记录，他在某一天使用某个设备登录，并玩了一定数量的游戏
```

编写一个 SQL 查询，报告在首次登录的第二天再次登录的玩家的比例，四舍五入到小数点后两位。换句话说，你需要计算从首次登录日期开始至少连续两天登录的玩家的数量，然后除以玩家总数。

查询结果格式如下所示：

**示例：**
```
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-03-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+

Result table:
+-----------+
| fraction  |
+-----------+
| 0.33      |
+-----------+
只有玩家 1 在首次登录的第二天（2016-03-02）再次登录
所以答案是 1/3 = 0.33
```

## 解题思路

这道题需要计算在首次登录后第二天再次登录的玩家比例。

**核心步骤：**
1. 找出每个玩家的首次登录日期
2. 检查该玩家是否在首次登录的第二天也有登录记录
3. 计算比例：符合条件的玩家数 / 总玩家数

**SQL技巧：**
- 使用 MIN() 找出首次登录日期
- 使用 DATE_ADD() 或 INTERVAL 计算第二天的日期
- 使用 JOIN 或子查询匹配记录
- 使用 ROUND() 四舍五入到两位小数

## SQL 代码实现

### 方法一：子查询 + JOIN（推荐）

```sql
SELECT ROUND(
    COUNT(DISTINCT a1.player_id) / COUNT(DISTINCT a2.player_id), 
    2
) AS fraction
FROM (
    -- 找出每个玩家的首次登录日期
    SELECT player_id, MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) a2
LEFT JOIN Activity a1
ON a2.player_id = a1.player_id
AND a1.event_date = DATE_ADD(a2.first_login, INTERVAL 1 DAY);
```

### 方法二：使用窗口函数

```sql
SELECT ROUND(
    SUM(CASE WHEN event_date = DATE_ADD(first_login, INTERVAL 1 DAY) 
        THEN 1 ELSE 0 END) / COUNT(DISTINCT player_id),
    2
) AS fraction
FROM (
    SELECT 
        player_id,
        event_date,
        MIN(event_date) OVER (PARTITION BY player_id) AS first_login
    FROM Activity
) t;
```

### 方法三：简化版本

```sql
SELECT ROUND(AVG(logged_in), 2) AS fraction
FROM (
    SELECT 
        a1.player_id,
        CASE WHEN a2.event_date IS NOT NULL THEN 1 ELSE 0 END AS logged_in
    FROM (
        SELECT player_id, MIN(event_date) AS first_login
        FROM Activity
        GROUP BY player_id
    ) a1
    LEFT JOIN Activity a2
    ON a1.player_id = a2.player_id
    AND a2.event_date = DATE_ADD(a1.first_login, INTERVAL 1 DAY)
) temp;
```

### 方法四：使用 CTE

```sql
WITH FirstLogin AS (
    SELECT player_id, MIN(event_date) AS first_date
    FROM Activity
    GROUP BY player_id
),
NextDayLogin AS (
    SELECT DISTINCT f.player_id
    FROM FirstLogin f
    INNER JOIN Activity a
    ON f.player_id = a.player_id
    AND a.event_date = DATE_ADD(f.first_date, INTERVAL 1 DAY)
)
SELECT ROUND(
    COUNT(*) / (SELECT COUNT(*) FROM FirstLogin),
    2
) AS fraction
FROM NextDayLogin;
```

## 复杂度分析

- 时间复杂度：O(n)，需要扫描整个表
- 空间复杂度：O(n)，需要存储中间结果

## 关键点总结

1. 使用 MIN() 聚合函数找出首次登录日期
2. 使用 DATE_ADD(date, INTERVAL 1 DAY) 计算第二天
3. 使用 LEFT JOIN 保留所有玩家记录
4. 使用 ROUND(value, 2) 四舍五入到两位小数
5. 注意除法运算要使用浮点数

## 易错点

1. 忘记使用 DISTINCT 导致重复计数
2. 整数除法结果为0，需要转换为浮点数
3. 没有正确处理没有第二天登录的玩家
4. ROUND 函数的位数参数错误
