## 题目描述

表：`SeasonStats`
```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| season_id        | int     |
| team_id          | int     |
| team_name        | varchar |
| matches_played   | int     |
| wins             | int     |
| draws            | int     |
| losses           | int     |
| goals_for        | int     |
| goals_against    | int     |
+------------------+---------+
(season_id, team_id) 是主键。
```

查询每个赛季的英超积分榜排名，规则如下：
- 积分 = 胜 * 3 + 平 * 1
- 排名：积分高的排前面；积分相同，则净胜球（goals_for - goals_against）高的排前面；若仍相同，则进球数多的排前面；若仍相同，则队名字母序小的排前面。

按赛季升序、排名升序返回结果。

## 解题思路

使用窗口函数 `RANK()` 在每个赛季内按排名规则排序。

计算积分和净胜球，然后用 `RANK() OVER (PARTITION BY season_id ORDER BY ...)` 得到排名。

## 代码实现

```sql
SELECT
    season_id,
    team_id,
    team_name,
    -- 计算积分
    wins * 3 + draws AS points,
    -- 净胜球
    goals_for - goals_against AS goal_difference,
    goals_for,
    -- 排名
    RANK() OVER (
        PARTITION BY season_id
        ORDER BY
            wins * 3 + draws DESC,               -- 积分降序
            (goals_for - goals_against) DESC,     -- 净胜球降序
            goals_for DESC,                        -- 进球数降序
            team_name ASC                          -- 队名升序
    ) AS position
FROM SeasonStats
ORDER BY season_id ASC, position ASC;
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组排序
- 空间复杂度：O(n)

## 关键点总结

1. 积分计算：`wins * 3 + draws`（平局 1 分，胜利 3 分，失败 0 分）。
2. 多级排序：积分 -> 净胜球 -> 进球数 -> 队名字母序。
3. 使用 `RANK()` 而非 `ROW_NUMBER()`，允许并列名次。

## 易错点

1. 净胜球 = 进球数 - 失球数，不要把方向搞反。
2. `RANK()` 允许并列，相同排名跳过后续编号；`ROW_NUMBER()` 不允许并列。
3. 排名相同时，队名按字母表**升序**（A 在前）。
