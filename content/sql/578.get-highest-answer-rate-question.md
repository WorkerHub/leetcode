## 题目描述

获取回答率最高的问题。回答率 = 回答次数 / 展示次数。

## SQL 代码实现

```sql
SELECT question_id AS survey_log
FROM (
    SELECT 
        question_id,
        SUM(CASE WHEN action = 'answer' THEN 1 ELSE 0 END) AS answers,
        SUM(CASE WHEN action = 'show' THEN 1 ELSE 0 END) AS shows
    FROM SurveyLog
    GROUP BY question_id
) AS stats
WHERE shows > 0
ORDER BY answers / shows DESC, question_id ASC
LIMIT 1;
```

## 关键点总结

1. **条件聚合**：使用 CASE WHEN
2. **比率计算**：answers / shows
3. **排序**：按比率降序，question_id 升序

## 学习建议

掌握条件聚合和排序优先级。
