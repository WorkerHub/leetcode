## 题目描述

表：`Cinema`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| seat_id     | int  |
| free        | bool |
+-------------+------+
```

`seat_id` 是该表的主键，`free` 表示座位是否空闲（1 空闲，0 已占）。

编写一个解决方案，找出 **最长** 连续空闲座位段的长度。如果有多段相同的最长长度，输出所有段。

输出：连续空闲座位段中第一个和最后一个座位的 ID，按第一个座位 ID 升序排列。

## 解题思路

使用窗口函数：对所有空闲座位，用 `seat_id - ROW_NUMBER()` 来标识连续段（同一连续段的值相同），然后对每段求长度和范围，找最大长度。

## 代码实现

### 方法一：窗口函数 + 分组（推荐）

```sql
WITH free_seats AS (
    SELECT seat_id,
           seat_id - ROW_NUMBER() OVER (ORDER BY seat_id) AS grp
    FROM Cinema
    WHERE free = 1
),
groups AS (
    SELECT
        MIN(seat_id) AS first_seat,
        MAX(seat_id) AS last_seat,
        COUNT(*) AS len
    FROM free_seats
    GROUP BY grp
),
max_len AS (
    SELECT MAX(len) AS max_length FROM groups
)
SELECT first_seat, last_seat
FROM groups
WHERE len = (SELECT max_length FROM max_len)
ORDER BY first_seat;
```

### 方法二：使用 DENSE_RANK

```sql
WITH consecutive AS (
    SELECT
        seat_id,
        seat_id - ROW_NUMBER() OVER (ORDER BY seat_id) AS island
    FROM Cinema
    WHERE free = 1
),
islands AS (
    SELECT
        MIN(seat_id) AS first_seat,
        MAX(seat_id) AS last_seat,
        COUNT(*) AS cnt
    FROM consecutive
    GROUP BY island
)
SELECT first_seat, last_seat
FROM islands
WHERE cnt = (SELECT MAX(cnt) FROM islands)
ORDER BY first_seat;
```

## 复杂度分析

- 时间复杂度：取决于表大小
- 空间复杂度：O(n)

## 关键点总结

1. 连续段识别技巧：`seat_id - ROW_NUMBER()` 对连续 seat_id 的空闲座位相同
2. 对每段求 MIN/MAX/COUNT
3. 筛选最大长度的段

## 易错点

1. ROW_NUMBER 只针对空闲座位（WHERE free = 1 之后）
2. 可能有多个等长最长段，需全部输出
