## 题目描述

表：`Customer`
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| customer_id   | int     |
| customer_name | varchar |
+---------------+---------+
customer_id 是主键
```

表：`Orders`
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| sale_date     | date    |
| order_cost    | int     |
| customer_id   | int     |
| seller_id     | int     |
+---------------+---------+
order_id 是主键
```

表：`Seller`
```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| seller_id     | int     |
| seller_name   | varchar |
+---------------+---------+
seller_id 是主键
```

请你报告**2020年**没有任何订单的所有卖家的名字，结果按**卖家名字升序**排列。

**示例：**
```
输入：
Seller：seller_id=1, seller_name='Daniel'
        seller_id=2, seller_name='Elizabeth'
        seller_id=3, seller_name='Frank'
Orders：order_id=1, sale_date='2020-03-01', seller_id=1
        order_id=2, sale_date='2019-10-01', seller_id=2

输出：
seller_name='Elizabeth'（2020年无订单，但 2019年有）
seller_name='Frank'（从未有过订单）
```

## 解题思路

找出在 2020 年没有销售记录的卖家：
1. 从 `Orders` 中筛选出 2020 年的订单，得到 2020 年有销售的 `seller_id` 集合
2. 从 `Seller` 中找出不在上述集合中的卖家

**方法：**
- `NOT IN` 子查询
- `LEFT JOIN` + `IS NULL`

## 代码实现

### 方法一：NOT IN 子查询（推荐）

```sql
SELECT seller_name
FROM Seller
WHERE seller_id NOT IN (
    SELECT DISTINCT seller_id
    FROM Orders
    WHERE YEAR(sale_date) = 2020
)
ORDER BY seller_name;
```

### 方法二：LEFT JOIN + IS NULL

```sql
SELECT s.seller_name
FROM Seller s
LEFT JOIN Orders o 
    ON s.seller_id = o.seller_id 
    AND YEAR(o.sale_date) = 2020
WHERE o.order_id IS NULL
ORDER BY s.seller_name;
```

### 方法三：NOT EXISTS

```sql
SELECT seller_name
FROM Seller s
WHERE NOT EXISTS (
    SELECT 1
    FROM Orders o
    WHERE o.seller_id = s.seller_id
    AND YEAR(o.sale_date) = 2020
)
ORDER BY seller_name;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| NOT IN | 简洁直观，子查询结果较小时效率高 |
| LEFT JOIN | 适合大数据量，可利用连接索引优化 |
| NOT EXISTS | 当子查询有匹配时立即停止，通常最高效 |

## 关键点总结

1. 过滤 2020 年订单：`YEAR(sale_date) = 2020` 或 `sale_date BETWEEN '2020-01-01' AND '2020-12-31'`
2. `LEFT JOIN` 方法中，过滤条件 `YEAR(o.sale_date) = 2020` 要放在 `ON` 子句而非 `WHERE` 子句
3. 最终结果需按 `seller_name` 升序排列

## 易错点

- `LEFT JOIN` 时若将年份条件放在 `WHERE` 而非 `ON` 中，会错误地过滤掉 2019 年有销售但 2020 年没有销售的卖家
- 忘记 `ORDER BY seller_name`
- `NOT IN` 中若子查询结果包含 `NULL`，整个 `NOT IN` 结果为空，需注意
