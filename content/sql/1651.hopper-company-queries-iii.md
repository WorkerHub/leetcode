## 题目描述

与 1635、1645 相同的表结构，查询 2020 年每个季度的：
1. 已完成行程的总里程数
2. 已完成行程的总时长（分钟）
3. 平均里程（总里程 / 行程数，保留两位小数，无行程时为 0.00）
4. 平均时长（总时长 / 行程数，保留两位小数，无行程时为 0.00）

结果包含 4 行，按季度排序。

## 解题思路

1. 生成 4 个季度的序列
2. 关联 `Rides` 和 `AcceptedRides` 按季度分组统计
3. 计算平均值，无行程时返回 0.00

## 代码实现

### 方法一：CTE + LEFT JOIN（推荐）

```sql
WITH quarters AS (
    SELECT 1 AS q UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL SELECT 4
),
ride_stats AS (
    SELECT
        QUARTER(r.requested_at) AS q,
        SUM(ar.ride_distance) AS total_distance,
        SUM(ar.ride_duration) AS total_duration,
        COUNT(ar.ride_id) AS total_rides
    FROM Rides r
    INNER JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY QUARTER(r.requested_at)
)
SELECT
    qt.q AS quarter,
    IFNULL(ROUND(rs.total_distance / rs.total_rides, 2), 0.00) AS average_ride_distance,
    IFNULL(ROUND(rs.total_duration / rs.total_rides, 2), 0.00) AS average_ride_duration
FROM quarters qt
LEFT JOIN ride_stats rs ON qt.q = rs.q
ORDER BY qt.q;
```

### 方法二：直接使用 AVG

```sql
WITH quarters AS (
    SELECT 1 AS q UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL SELECT 4
),
ride_stats AS (
    SELECT
        QUARTER(r.requested_at) AS q,
        ROUND(AVG(ar.ride_distance), 2) AS average_ride_distance,
        ROUND(AVG(ar.ride_duration), 2) AS average_ride_duration
    FROM Rides r
    INNER JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY QUARTER(r.requested_at)
)
SELECT
    qt.q AS quarter,
    IFNULL(rs.average_ride_distance, 0.00) AS average_ride_distance,
    IFNULL(rs.average_ride_duration, 0.00) AS average_ride_duration
FROM quarters qt
LEFT JOIN ride_stats rs ON qt.q = rs.q
ORDER BY qt.q;
```

## 复杂度分析

| 方法 | 说明 |
|------|------|
| CTE | 清晰分步计算 |
| AVG | 直接使用聚合函数更简洁 |

## 关键点总结

1. 无行程时平均值应为 0.00（用 `IFNULL` 处理）
2. `QUARTER(date)` 返回 1-4 表示季度
3. `LEFT JOIN` 确保无行程的季度也出现在结果中

## 易错点

- `AVG` 函数在组内无数据时返回 NULL，需要 `IFNULL`
- 注意是 `AcceptedRides`（已接受的行程），不是所有行程
- 按 `requested_at` 的季度分组，不是 `driver_id`
