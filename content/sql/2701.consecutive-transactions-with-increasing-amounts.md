## 题目描述

查找每位客户连续交易金额递增的最长连续天数段。

表 `Transactions`：
```
+------------------+----------+
| Column Name      | Type     |
+------------------+----------+
| transaction_id   | int      |
| customer_id      | int      |
| transaction_date | date     |
| amount           | int      |
+------------------+----------+
```
`transaction_id` 是主键。每行包含客户 ID、交易日期和交易金额。

对于每位客户，找到交易金额连续递增（每一天金额严格大于前一天）且持续时间最长的连续日期段。返回每位客户的 `customer_id`、`consecutive_start`（起始日期）和 `consecutive_end`（结束日期）。如果有多段相同最长长度，返回起始日期最早的一段。

**示例：**

输入 Transactions 表：
```
+----------------+-------------+------------------+--------+
| transaction_id | customer_id | transaction_date | amount |
+----------------+-------------+------------------+--------+
| 1              | 101         | 2023-05-01       | 100    |
| 2              | 101         | 2023-05-02       | 150    |
| 3              | 101         | 2023-05-03       | 200    |
| 4              | 102         | 2023-05-01       | 50     |
| 5              | 102         | 2023-05-03       | 100    |
| 6              | 102         | 2023-05-04       | 200    |
+----------------+-------------+------------------+--------+
```

输出：
```
+-------------+-------------------+-----------------+
| customer_id | consecutive_start | consecutive_end |
+-------------+-------------------+-----------------+
| 101         | 2023-05-01        | 2023-05-03      |
| 102         | 2023-05-03        | 2023-05-04      |
+-------------+-------------------+-----------------+
```

## 解题思路

使用窗口函数识别连续递增的分组：
1. 用 `LAG` 函数获取前一行的日期和金额
2. 判断当前行是否为连续日期且金额递增（否则标记为新分组起点）
3. 利用累加求和生成分组 ID
4. 按客户和分组统计长度，取最长的段

## 代码实现

### 方法一：SQL 窗口函数（推荐）

```sql
-- 步骤1：为每行标记是否是新分组的起点
WITH ranked AS (
    SELECT
        customer_id,
        transaction_date,
        amount,
        LAG(transaction_date) OVER (PARTITION BY customer_id ORDER BY transaction_date) AS prev_date,
        LAG(amount) OVER (PARTITION BY customer_id ORDER BY transaction_date) AS prev_amount
    FROM Transactions
),
flagged AS (
    SELECT
        customer_id,
        transaction_date,
        amount,
        -- 若前一天日期连续且金额严格递增，则不是新分组起点（标0），否则标1
        CASE
            WHEN prev_date IS NOT NULL
                 AND DATEDIFF(transaction_date, prev_date) = 1
                 AND amount > prev_amount
            THEN 0
            ELSE 1
        END AS is_new_group
    FROM ranked
),
-- 步骤2：累加生成分组 ID
grouped AS (
    SELECT
        customer_id,
        transaction_date,
        SUM(is_new_group) OVER (PARTITION BY customer_id ORDER BY transaction_date) AS grp_id
    FROM flagged
),
-- 步骤3：统计每个分组的起止日期和长度
agg AS (
    SELECT
        customer_id,
        grp_id,
        MIN(transaction_date) AS consecutive_start,
        MAX(transaction_date) AS consecutive_end,
        COUNT(*) AS grp_len
    FROM grouped
    GROUP BY customer_id, grp_id
),
-- 步骤4：取每位客户最长（最早）的分组
ranked2 AS (
    SELECT
        customer_id,
        consecutive_start,
        consecutive_end,
        grp_len,
        RANK() OVER (PARTITION BY customer_id ORDER BY grp_len DESC, consecutive_start ASC) AS rnk
    FROM agg
)
SELECT customer_id, consecutive_start, consecutive_end
FROM ranked2
WHERE rnk = 1
ORDER BY customer_id;
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和窗口函数
- 空间复杂度：O(n)，中间 CTE 结果集

## 关键点总结

1. `LAG` 函数用于获取同一客户前一条交易记录
2. `DATEDIFF = 1` 确保日期连续（相差恰好 1 天）
3. 利用累加 `SUM(is_new_group)` 生成分组编号
4. `RANK()` 处理最长相同时取最早开始日期

## 易错点

1. 注意 `DATEDIFF` 参数顺序在不同数据库中不同（MySQL 为后减前）
2. 金额递增要求严格大于，不包含相等情况
3. 需要同时满足日期连续和金额递增两个条件
