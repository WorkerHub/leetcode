## 题目描述

编写SQL查询来报告每个部门的学生人数。即使部门没有学生，也要显示。

## SQL 代码实现

```sql
SELECT 
    d.dept_name,
    COUNT(s.student_id) AS student_number
FROM Department d
LEFT JOIN Student s ON d.dept_id = s.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY student_number DESC, d.dept_name ASC;
```

## 关键点总结

1. **LEFT JOIN**：保留所有部门
2. **COUNT**：COUNT(student_id) 不计NULL
3. **排序**：人数降序，名称升序

## 学习建议

理解 COUNT 对 NULL 的处理，掌握多条件排序。
