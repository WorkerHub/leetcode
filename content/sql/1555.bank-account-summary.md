## 题目描述

表 `Users`：`user_id`, `user_name`, `credit`（初始信用额度）

表 `Transactions`：`trans_id`, `paid_by`, `paid_to`, `amount`, `transacted_on`（交易日期）

银行规定：每笔交易 `paid_by` 用户余额减少 `amount`，`paid_to` 用户余额增加 `amount`。

查询每个用户的当前信用额度，标注余额为负的用户（`credit_limit_breached` 为 `'Yes'`，否则为 `'No'`）。

## 解题思路

### 聚合所有交易的收支变化

对每个用户，汇总所有作为付款方（扣款）和收款方（增款）的交易，加上初始信用额度，得到最终余额。

## 代码实现

### 方法一：LEFT JOIN + SUM CASE（推荐）

```sql
-- 计算每个用户的总收入和总支出
SELECT
    u.user_id,
    u.user_name,
    u.credit
        + COALESCE(SUM(CASE WHEN t.paid_to = u.user_id THEN t.amount ELSE 0 END), 0)
        - COALESCE(SUM(CASE WHEN t.paid_by = u.user_id THEN t.amount ELSE 0 END), 0) AS credit,
    CASE
        WHEN u.credit
            + COALESCE(SUM(CASE WHEN t.paid_to = u.user_id THEN t.amount ELSE 0 END), 0)
            - COALESCE(SUM(CASE WHEN t.paid_by = u.user_id THEN t.amount ELSE 0 END), 0) < 0
        THEN 'Yes'
        ELSE 'No'
    END AS credit_limit_breached
FROM Users u
LEFT JOIN Transactions t ON t.paid_by = u.user_id OR t.paid_to = u.user_id
GROUP BY u.user_id, u.user_name, u.credit
ORDER BY u.user_id;
```

### 方法二：CTE 分步计算

```sql
-- 分步骤：先计算每个用户的净变动，再加初始信用额度
WITH changes AS (
    -- 收款方：+amount
    SELECT paid_to AS user_id, amount AS delta FROM Transactions
    UNION ALL
    -- 付款方：-amount
    SELECT paid_by AS user_id, -amount AS delta FROM Transactions
),
net_change AS (
    SELECT user_id, SUM(delta) AS total_change
    FROM changes
    GROUP BY user_id
)
SELECT
    u.user_id,
    u.user_name,
    u.credit + COALESCE(nc.total_change, 0) AS credit,
    IF(u.credit + COALESCE(nc.total_change, 0) < 0, 'Yes', 'No') AS credit_limit_breached
FROM Users u
LEFT JOIN net_change nc ON u.user_id = nc.user_id
ORDER BY u.user_id;
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N 为 Transactions 行数
- **空间复杂度**：O(U)，U 为用户数

## 关键点总结

1. 每笔交易影响两个用户（付款方扣减，收款方增加）
2. 用 `UNION ALL` 将两方向的变动合并，再 `GROUP BY` 求净变动
3. `COALESCE(..., 0)` 处理无交易记录的用户

## 易错点

- 用户可能没有任何交易，需要 `LEFT JOIN` 并用 `COALESCE` 处理 NULL
- 同一笔交易影响两个不同用户，不能用一次 GROUP BY 处理
