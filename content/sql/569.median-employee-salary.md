## 题目描述

编写一个SQL查询，找出每个公司的工资中位数。

表：`Employee`
```
+-----+------------+--------+
|Id   | Company    | Salary |
+-----+------------+--------+
|1    | A          | 2341   |
|2    | A          | 341    |
|3    | A          | 15     |
|4    | A          | 15314  |
|5    | A          | 451    |
|6    | A          | 513    |
|7    | B          | 15     |
|8    | B          | 13     |
|9    | B          | 1154   |
|10   | B          | 1345   |
|11   | B          | 1221   |
|12   | B          | 234    |
|13   | C          | 2345   |
|14   | C          | 2645   |
|15   | C          | 2645   |
|16   | C          | 2652   |
|17   | C          | 65     |
+-----+------------+--------+
```

输出应该是：
```
+-----+------------+--------+
|Id   | Company    | Salary |
+-----+------------+--------+
|5    | A          | 451    |
|6    | A          | 513    |
|12   | B          | 234    |
|9    | B          | 1154   |
|14   | C          | 2645   |
+-----+------------+--------+
```

## 解题思路

使用窗口函数计算每个员工在公司内的排名，然后找出中位数。

## SQL 代码实现

### 方法一：使用 ROW_NUMBER（推荐）⭐

```sql
SELECT Id, Company, Salary
FROM (
    SELECT 
        Id, 
        Company, 
        Salary,
        ROW_NUMBER() OVER (PARTITION BY Company ORDER BY Salary) AS rn,
        COUNT(*) OVER (PARTITION BY Company) AS cnt
    FROM Employee
) AS ranked
WHERE rn BETWEEN cnt / 2.0 AND cnt / 2.0 + 1;
```

### 方法二：自连接

```sql
SELECT e1.Id, e1.Company, e1.Salary
FROM Employee e1
WHERE (
    SELECT COUNT(*) 
    FROM Employee e2 
    WHERE e1.Company = e2.Company AND e1.Salary >= e2.Salary
) >= (
    SELECT COUNT(*) / 2 
    FROM Employee e3 
    WHERE e1.Company = e3.Company
)
AND (
    SELECT COUNT(*) 
    FROM Employee e4 
    WHERE e1.Company = e4.Company AND e1.Salary <= e4.Salary
) >= (
    SELECT COUNT(*) / 2 
    FROM Employee e5 
    WHERE e1.Company = e5.Company
)
ORDER BY e1.Company, e1.Salary;
```

## 关键点总结

1. **窗口函数**：ROW_NUMBER() 计算排名
2. **中位数计算**：根据总数判断中位数位置
3. **分组处理**：PARTITION BY Company
