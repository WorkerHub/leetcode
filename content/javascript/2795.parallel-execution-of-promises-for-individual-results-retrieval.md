## 题目描述

给你一个异步函数数组 `functions`，并行执行所有函数，收集每个 Promise 的结果（无论 resolved 还是 rejected）。

返回一个 Promise，resolve 为对象数组，每个对象为：
- `{ status: 'fulfilled', value: v }` 若 resolved
- `{ status: 'rejected', reason: r }` 若 rejected

类似于 `Promise.allSettled`，但不能使用它。

**示例：**
```javascript
functions = [() => Promise.resolve(5), () => Promise.reject("Error")]
// 返回 [{status:"fulfilled",value:5}, {status:"rejected",reason:"Error"}]
```

## 解题思路

手动实现 `Promise.allSettled`：对每个函数，无论成功失败都记录结果，全部完成后 resolve。

## Python 代码实现

### 方法一：手动实现 allSettled（推荐）

```javascript
/**
 * @param {Array<Function>} functions
 * @return {Promise<Array>}
 */
var promiseAllSettled = function(functions) {
    return new Promise((resolve) => {
        const results = new Array(functions.length);
        let completed = 0;

        if (functions.length === 0) return resolve([]);

        functions.forEach((fn, i) => {
            fn()
                .then(value => {
                    results[i] = { status: 'fulfilled', value };
                })
                .catch(reason => {
                    results[i] = { status: 'rejected', reason };
                })
                .finally(() => {
                    completed++;
                    if (completed === functions.length) resolve(results);
                });
        });
    });
};
```

### 方法二：使用 async/await 简化

```javascript
var promiseAllSettled = async function(functions) {
    return Promise.all(
        functions.map(fn =>
            fn()
                .then(value => ({ status: 'fulfilled', value }))
                .catch(reason => ({ status: 'rejected', reason }))
        )
    );
};
```

## 复杂度分析

- 时间复杂度：O(n)，并行执行
- 空间复杂度：O(n)

## 关键点总结

1. 无论 resolve 还是 reject，都要记录结果（不同于 Promise.all）
2. 使用 `.finally()` 统一计数，确保所有结果收集完毕

## 易错点

1. 不能在 reject 时直接 reject 外层 Promise
2. 结果顺序需与函数数组顺序一致（用索引 i）
