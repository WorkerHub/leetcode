## 题目描述

给你一个对象或数组 `obj`，判断它是否为 **空**。

- 空对象：不包含任何键值对
- 空数组：不包含任何元素

**示例 1：**
```
输入：obj = {"x": 5, "y": 42}
输出：false
```

**示例 2：**
```
输入：obj = {}
输出：true
```

**示例 3：**
```
输入：obj = [null, false, 0]
输出：false
```

**提示：**
- `obj` 是一个有效的 JSON 对象或数组

## 解题思路

- 数组：检查 `length === 0`
- 对象：检查 `Object.keys(obj).length === 0` 或用 `JSON.stringify(obj) === '{}'`

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Object|Array} obj
 * @return {boolean}
 */
var isEmpty = function(obj) {
    // 数组判断 length，对象判断键的数量
    if (Array.isArray(obj)) {
        return obj.length === 0;
    }
    return Object.keys(obj).length === 0;
};
```

### 方法二：统一判断（for...in 循环）

```javascript
/**
 * @param {Object|Array} obj
 * @return {boolean}
 */
var isEmpty = function(obj) {
    // for...in 遇到第一个键/索引就返回 false
    for (const _ in obj) return false;
    return true;
};
```

## 复杂度分析

- 时间复杂度：O(1)（`Object.keys` 本质遍历，但常数很小）
- 空间复杂度：O(n)（`Object.keys` 创建键数组）

## 关键点总结

1. 数组和对象都可以用 `Object.keys().length === 0` 判断
2. `for...in` 方法对两种类型都适用，且短路效率更高

## 易错点

1. `typeof [] === 'object'`，数组需要用 `Array.isArray` 区分
2. `null` 的 `typeof` 也是 `'object'`，但题目保证输入是对象或数组
