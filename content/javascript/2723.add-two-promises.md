## 题目描述

给你两个 Promise，`promise1` 和 `promise2`，它们都会 resolve 为一个数字。

返回一个新的 Promise，当两个 Promise 都 resolve 后，resolve 为两个数字的和。

**示例 1：**
```
输入：promise1 = new Promise(res => res(2)), promise2 = new Promise(res => res(5))
输出：7
```

**示例 2：**
```
输入：promise1 = new Promise(res => res(4)), promise2 = new Promise(res => res(-12))
输出：-8
```

## 解题思路

使用 `Promise.all` 等待两个 Promise 都 resolve，然后对结果求和。也可以使用 `async/await` 让代码更清晰。

## Python 代码实现

### 方法一：Promise.all（推荐）

```javascript
/**
 * @param {Promise} promise1
 * @param {Promise} promise2
 * @return {Promise}
 */
var addTwoPromises = async function(promise1, promise2) {
    // 并行等待两个 Promise，然后求和
    const [val1, val2] = await Promise.all([promise1, promise2]);
    return val1 + val2;
};
```

### 方法二：链式 then

```javascript
/**
 * @param {Promise} promise1
 * @param {Promise} promise2
 * @return {Promise}
 */
var addTwoPromises = function(promise1, promise2) {
    return Promise.all([promise1, promise2])
        .then(([v1, v2]) => v1 + v2);
};
```

## 复杂度分析

- 时间复杂度：O(1)（并行等待）
- 空间复杂度：O(1)

## 关键点总结

1. `Promise.all` 并行等待多个 Promise，效率高
2. `async/await` 使异步代码读起来像同步代码
3. 解构赋值 `[val1, val2]` 获取两个结果

## 易错点

1. 两个 Promise 是并行的，不要串行 await（会慢）
2. `async` 函数自动将返回值包装为 Promise
