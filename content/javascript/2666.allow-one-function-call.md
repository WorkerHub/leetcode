## 题目描述

本题原为 JavaScript 函数式编程题目。给定函数 `fn`，返回一个只能调用一次的版本：第一次调用返回 `fn` 的结果，之后所有调用返回 `undefined`。

**示例：**
```
fn = (a,b,c) => a+b+c
onceFn = onceCall(fn)
onceFn(1,2,3) -> 6
onceFn(2,3,6) -> undefined
```

## 解题思路

使用闭包记录是否已调用过，若已调用则返回 `None`（Python 等价于 `undefined`）。

## Python 代码实现

### 方法一：闭包实现（推荐）

```python
from typing import Callable, Any

def once(fn: Callable) -> Callable:
    """
    返回只能调用一次的函数版本
    """
    called = [False]

    def wrapper(*args) -> Any:
        if called[0]:
            return None  # 已调用过，返回 None（等价于 undefined）
        called[0] = True
        return fn(*args)

    return wrapper


# 使用示例
add = lambda a, b, c: a + b + c
once_add = once(add)
print(once_add(1, 2, 3))  # 6
print(once_add(2, 3, 6))  # None
```

### 方法二：使用 functools.lru_cache 变体

```python
from typing import Callable, Any

def once(fn: Callable) -> Callable:
    result = [None]
    has_result = [False]

    def wrapper(*args) -> Any:
        if not has_result[0]:
            result[0] = fn(*args)
            has_result[0] = True
            return result[0]
        return None

    return wrapper
```

### JavaScript 参考实现

```javascript
function once(fn) {
    let called = false;
    return function(...args) {
        if (called) return undefined;
        called = true;
        return fn(...args);
    };
}
```

## 复杂度分析

- 时间复杂度：O(1)（每次调用）
- 空间复杂度：O(1)

## 关键点总结

1. 用标志变量记录是否已调用
2. 已调用返回 None（Python 中的 undefined 等价物）
3. 第一次调用正常执行并返回结果

## 易错点

1. 非第一次调用返回 `None` 而非报错
2. 注意在闭包中修改外层变量需要用列表包装或 `nonlocal`
