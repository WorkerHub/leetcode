## 题目描述

本题原为 JavaScript 设计题目。实现防抖函数：给定函数 `fn` 和延迟时间 `t` 毫秒，返回防抖版本的函数。防抖函数在最后一次调用后 `t` 毫秒才执行，若在此期间再次调用，则重置计时器。

**示例：**
```
fn = (x) => x * 2
t = 20ms
调用顺序：t=50ms 调用(2)，t=60ms 调用(2)，t=100ms 调用(1)
实际执行：t=80ms 执行(2) [60+20]，t=120ms 执行(1) [100+20]
```

## 解题思路

使用定时器：每次调用时先取消旧定时器，再设置新定时器，延迟 `t` 毫秒后执行。

Python 中使用 `threading.Timer` 实现延迟执行，每次调用时取消上一个定时器。

## Python 代码实现

### 方法一：threading.Timer 实现

```python
from typing import Callable, Any
from threading import Timer

def debounce(fn: Callable, t: int) -> Callable:
    """
    返回防抖函数，t 毫秒内重复调用只执行最后一次
    """
    timer = [None]  # 使用列表存储定时器，方便在闭包中修改

    def debounced(*args) -> None:
        # 取消上一个定时器
        if timer[0] is not None:
            timer[0].cancel()
        # 设置新定时器
        timer[0] = Timer(t / 1000, fn, args=args)
        timer[0].start()

    return debounced


# 使用示例
import time

call_log = []
def log(x):
    call_log.append(x)

debounced_log = debounce(log, 100)  # 100ms 防抖
debounced_log(1)
debounced_log(2)  # 100ms 内再次调用，重置计时器
time.sleep(0.2)   # 等待执行
print(call_log)   # [2]（只执行最后一次）
```

### 方法二：使用 asyncio 的异步版本

```python
import asyncio
from typing import Callable

def debounce_async(fn: Callable, t: float):
    """
    异步防抖函数
    """
    task = [None]

    async def debounced(*args):
        if task[0]:
            task[0].cancel()

        async def delayed():
            await asyncio.sleep(t / 1000)
            await fn(*args)

        task[0] = asyncio.create_task(delayed())

    return debounced
```

### JavaScript 参考实现

```javascript
function debounce(fn, t) {
    let timer = null;
    return function(...args) {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), t);
    };
}
```

## 复杂度分析

- 时间复杂度：O(1)（每次调用）
- 空间复杂度：O(1)

## 关键点总结

1. 每次调用先取消旧计时器，再设置新计时器
2. 只有在 `t` 毫秒内无新调用时，函数才真正执行
3. 防抖常用于搜索框输入、窗口 resize 等高频事件

## 易错点

1. 注意取消旧计时器，否则会多次执行
2. Python 的 `Timer` 参数中时间单位是秒，需除以 1000
3. 与节流（throttle）的区别：防抖是最后一次，节流是第一次
