## 题目描述

给你一个对象 `obj` 和一个过滤函数 `fn`，实现深度过滤，返回过滤后的对象。

深度过滤规则：
- 如果 `fn(obj)` 返回 `true`，保留该节点
- 如果是对象/数组，递归对子节点过滤
- 如果过滤后的对象/数组为空，则删除该节点
- 数组保持原有顺序，删除不满足条件的元素后重新紧缩（compacted）

**示例 1：**
```
输入：obj = {"a": 1, "b": 2, "c": 3}, fn = (x) => x > 1
输出：{"b": 2, "c": 3}
```

**示例 2：**
```
输入：obj = {"a": {"b": 1, "c": 2}, "d": 3}, fn = (x) => x > 1
输出：{"a": {"c": 2}, "d": 3}
```

## 解题思路

本题是 JavaScript 题，考察递归处理嵌套对象。

深度优先遍历：
1. 如果是原始值（非对象非数组），用 `fn` 判断是否保留
2. 如果是数组，递归过滤每个元素，过滤掉 `undefined` 的结果
3. 如果是对象，递归过滤每个值，过滤掉值为空/undefined 的键

## Python 代码实现

### 方法一：Python 递归实现（理解用）

```python
from typing import Any, Callable, Union

def deep_filter(obj: Any, fn: Callable) -> Any:
    """深度过滤对象"""
    if isinstance(obj, list):
        # 递归过滤数组
        result = []
        for item in obj:
            filtered = deep_filter(item, fn)
            if filtered is not None:
                result.append(filtered)
        return result if result else None
    elif isinstance(obj, dict):
        # 递归过滤对象
        result = {}
        for k, v in obj.items():
            filtered = deep_filter(v, fn)
            if filtered is not None:
                result[k] = filtered
        return result if result else None
    else:
        # 原始值
        return obj if fn(obj) else None

# 使用示例
obj = {"a": 1, "b": 2, "c": 3}
print(deep_filter(obj, lambda x: x > 1))  # {'b': 2, 'c': 3}
```

### 方法二：JavaScript 实现（LeetCode 原题解）

```javascript
/**
 * @param {Object} obj
 * @param {Function} fn
 * @return {Object}
 */
var deepFilter = function(obj, fn) {
    // 递归过滤函数
    function filter(val) {
        if (Array.isArray(val)) {
            // 递归过滤数组，去掉 undefined 结果
            const filtered = val
                .map(item => filter(item))
                .filter(item => item !== undefined);
            return filtered.length > 0 ? filtered : undefined;
        } else if (typeof val === 'object' && val !== null) {
            // 递归过滤对象
            const result = {};
            for (const [k, v] of Object.entries(val)) {
                const filtered = filter(v);
                if (filtered !== undefined) {
                    result[k] = filtered;
                }
            }
            return Object.keys(result).length > 0 ? result : undefined;
        } else {
            // 原始值：用 fn 判断
            return fn(val) ? val : undefined;
        }
    }

    return filter(obj) ?? {};
};
```

## 复杂度分析

- 时间复杂度：O(n)，n 为对象中所有节点数
- 空间复杂度：O(d)，d 为最大嵌套深度（递归调用栈）

## 关键点总结

1. 递归处理：数组、对象、原始值三种情况分别处理
2. 空对象/数组应该删除（视为"不通过过滤"）
3. 只有原始值才真正调用 `fn` 判断
4. 数组过滤后用 `.filter(x => x !== undefined)` 紧缩

## 易错点

1. `null` 的类型是 `'object'`，需要额外检查 `val !== null`
2. 空对象/空数组应返回 `undefined`（删除该节点）
3. `fn` 只对原始值调用，不对嵌套对象/数组调用
