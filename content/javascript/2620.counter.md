## 题目描述

本题原为 JavaScript 闭包题目。给定初始值 `n`，返回一个计数函数，每次调用返回 `n` 并将 `n` 加 1。

**示例 1：**
```
输入：n = 10，依次调用 3 次
输出：[10, 11, 12]
```

**示例 2：**
```
输入：n = -2，依次调用 5 次
输出：[-2, -1, 0, 1, 2]
```

## 解题思路

使用闭包（或生成器）维护计数状态，每次调用返回当前值并自增。

Python 有多种实现方式：
1. 使用闭包（nonlocal 变量）
2. 使用生成器
3. 使用类

## Python 代码实现

### 方法一：闭包实现

```python
from typing import Callable

def create_counter(n: int) -> Callable:
    """
    返回一个计数函数，每次调用返回当前值并自增
    """
    count = [n]  # 使用列表包装，方便在闭包中修改

    def counter() -> int:
        result = count[0]
        count[0] += 1
        return result

    return counter


# 使用示例
counter = create_counter(10)
print(counter())  # 10
print(counter())  # 11
print(counter())  # 12
```

### 方法二：使用 nonlocal（Python 3）

```python
from typing import Callable

def create_counter(n: int) -> Callable:
    current = n

    def counter() -> int:
        nonlocal current  # 声明使用外层变量
        result = current
        current += 1
        return result

    return counter
```

### 方法三：生成器实现

```python
def counter_gen(n: int):
    """
    生成器版本的计数器
    """
    while True:
        yield n
        n += 1


# 使用示例
gen = counter_gen(10)
print(next(gen))  # 10
print(next(gen))  # 11
```

### JavaScript 参考实现

```javascript
function createCounter(n) {
    return function() {
        return n++;
    };
}
```

## 复杂度分析

- 时间复杂度：O(1)（每次调用）
- 空间复杂度：O(1)

## 关键点总结

1. 闭包捕获外层变量的引用，而非值
2. Python 中用 `nonlocal` 关键字修改外层变量
3. 每次调用先保存当前值，再自增，返回保存值

## 易错点

1. 直接使用 `n += 1` 不加 `nonlocal` 会报 `UnboundLocalError`
2. 用列表包装（`count = [n]`）是一种绕过 `nonlocal` 的老写法
