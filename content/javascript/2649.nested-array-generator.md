## 题目描述

本题原为 JavaScript 生成器题目。给定一个多维整数数组，实现一个生成器函数，按顺序 yield 所有整数（扁平化多维数组）。

**示例 1：**
```
输入：arr = [[[6]],[1,3],[[]]]
输出：[6,1,3]
```

**示例 2：**
```
输入：arr = [1,[7,[8]]]
输出：[1,7,8]
```

## 解题思路

递归生成器：对数组中的每个元素，若为整数则 yield，若为列表则递归 yield 其内部元素。

Python 支持 `yield from` 语法，可以直接委托给子生成器。

## Python 代码实现

### 方法一：递归生成器 + yield from（推荐）

```python
from typing import Any, Generator, List, Union

def inorder_traversal(arr: List[Any]) -> Generator[int, None, None]:
    """
    递归展平嵌套数组，依次产出所有整数
    """
    for item in arr:
        if isinstance(item, list):
            yield from inorder_traversal(item)  # 递归委托
        else:
            yield item  # 直接产出整数


# 使用示例
arr = [[[6]], [1, 3], [[]]]
print(list(inorder_traversal(arr)))  # [6, 1, 3]

arr2 = [1, [7, [8]]]
print(list(inorder_traversal(arr2)))  # [1, 7, 8]
```

### 方法二：迭代版（使用栈）

```python
from typing import Any, List, Generator

def inorder_traversal_iterative(arr: List[Any]) -> Generator[int, None, None]:
    """
    迭代版嵌套数组遍历（避免深度过大时的递归栈溢出）
    """
    stack = list(reversed(arr))  # 用栈模拟递归（反转保证顺序）
    while stack:
        item = stack.pop()
        if isinstance(item, list):
            stack.extend(reversed(item))  # 展开列表（反转保证顺序）
        else:
            yield item
```

### JavaScript 参考实现

```javascript
function* inorderTraversal(arr) {
    for (const item of arr) {
        if (Array.isArray(item)) {
            yield* inorderTraversal(item);
        } else {
            yield item;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(N)，N 为所有元素总数
- 空间复杂度：O(D)，D 为最大嵌套深度（递归栈）

## 关键点总结

1. `yield from` 是 Python 的生成器委托语法，与 JS 的 `yield*` 对应
2. 递归版代码简洁，迭代版避免栈溢出
3. 生成器惰性求值，不会预先展平整个数组

## 易错点

1. 空列表 `[]` 不产出任何值（跳过）
2. `yield from` 需要 Python 3.3+
3. 注意区分 `yield` 和 `return`，生成器中不能用 `return value`（Python 3.3 之前）
