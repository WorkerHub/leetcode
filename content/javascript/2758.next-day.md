## 题目描述

给你一个日期字符串 `date`（格式 `YYYY-MM-DD`），返回其后一天的日期字符串（格式相同）。

**示例 1：**
```
输入："2023-06-01"
输出："2023-06-02"
```

**示例 2：**
```
输入："2023-12-31"
输出："2024-01-01"
```

## 解题思路

将日期字符串解析为 Date 对象，加一天，再格式化为字符串。

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {string} date
 * @return {string}
 */
var nextDay = function(date) {
    const d = new Date(date);
    d.setDate(d.getDate() + 1);  // 加一天（自动处理月末/年末）
    return d.toISOString().slice(0, 10);  // 取 YYYY-MM-DD 部分
};
```

### 方法二：Python 实现

```python
from datetime import date, timedelta

def nextDay(date_str: str) -> str:
    # 解析日期字符串
    d = date.fromisoformat(date_str)
    # 加一天
    next_d = d + timedelta(days=1)
    return str(next_d)
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `Date.setDate()` 和 `Date.getDate()` 配合自动处理月末/年末进位
2. `toISOString()` 返回 ISO 8601 格式，截取前 10 字符即为 `YYYY-MM-DD`

## 易错点

1. `new Date("2023-06-01")` 解析为 UTC 时间，`toISOString()` 也是 UTC，无时区问题
2. 不要手动处理月末/年末，用 Date 对象自动处理
