## 题目描述

给你一个异步函数数组 `functions`，每个函数不接受任何参数并返回一个 Promise。

返回一个 Promise，当所有 Promise 都 resolved 时 resolve，值为所有 resolve 值的数组（与函数顺序相同）。如果任意一个 Promise reject，则整个 Promise 也 reject，传递第一个 reject 的原因。

要求：**不能使用内置的 `Promise.all` 函数**。

**示例 1：**
```
输入：functions = [() => new Promise(res => res(5))]
输出：{"resolved": [5]}
```

**示例 2：**
```
输入：functions = [() => new Promise(res => res(1)), () => new Promise((res,rej) => rej("Error"))]
输出：{"rejected": "Error"}
```

## 解题思路

手动实现 `Promise.all` 的逻辑：
1. 记录已完成的数量和结果数组
2. 对每个函数调用并注册 resolve/reject 处理
3. 当所有都 resolve 后，resolve 外层 Promise
4. 任一 reject 则 reject 外层 Promise

## Python 代码实现

### 方法一：手动实现 Promise.all（推荐）

```javascript
/**
 * @param {Array<Function>} functions
 * @return {Promise<any>}
 */
var promiseAll = function(functions) {
    return new Promise((resolve, reject) => {
        const results = new Array(functions.length);
        let completed = 0;

        functions.forEach((fn, index) => {
            fn()
                .then(val => {
                    results[index] = val;  // 保持原始顺序
                    completed++;
                    if (completed === functions.length) {
                        resolve(results);
                    }
                })
                .catch(err => {
                    reject(err);  // 第一个错误立即 reject
                });
        });

        // 空数组时直接 resolve
        if (functions.length === 0) resolve([]);
    });
};
```

### 方法二：使用 async/await 计数

```javascript
/**
 * @param {Array<Function>} functions
 * @return {Promise<any>}
 */
var promiseAll = function(functions) {
    return new Promise((resolve, reject) => {
        if (functions.length === 0) return resolve([]);
        const res = [];
        let count = 0;
        functions.forEach((f, i) => {
            f().then(v => {
                res[i] = v;
                if (++count === functions.length) resolve(res);
            }).catch(reject);
        });
    });
};
```

## 复杂度分析

- 时间复杂度：O(n)，并行执行所有函数
- 空间复杂度：O(n)，存储结果数组

## 关键点总结

1. 并行执行所有 Promise（不是串行）
2. 结果数组按原始顺序保存，不是按完成顺序
3. 任一 reject 则整体 reject

## 易错点

1. 使用 `results[index] = val` 而非 `results.push(val)` 保证顺序
2. 空数组特殊处理（直接 resolve 空数组）
3. `reject` 只会被调用一次（Promise 状态不可逆）
