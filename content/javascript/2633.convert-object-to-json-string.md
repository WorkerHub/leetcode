## 题目描述

本题原为 JavaScript 递归题目。不使用内置 `JSON.stringify` 方法，将对象转换为 JSON 字符串。支持的类型：null、boolean、number、string、array、object。

**示例 1：**
```
输入：object = {"y":1,"x":2}
输出：'{"y":1,"x":2}'
```

**示例 2：**
```
输入：object = {"a":{"b":{"c":{"d":1}}}}
输出：'{"a":{"b":{"c":{"d":1}}}}'
```

## 解题思路

递归处理各种类型：
- `null`：输出 `"null"`
- `bool`：输出 `"true"` 或 `"false"`
- `int/float`：输出数字字符串
- `str`：输出带引号的字符串
- `list`：递归处理每个元素，用逗号连接，外加方括号
- `dict`：递归处理每个键值对，键用引号，用逗号连接，外加大括号

## Python 代码实现

### 方法一：手动递归实现

```python
from typing import Any

def object_to_json(obj: Any) -> str:
    """
    将对象转换为 JSON 字符串（不使用内置 json 模块）
    """
    if obj is None:
        return "null"
    if isinstance(obj, bool):
        return "true" if obj else "false"
    if isinstance(obj, (int, float)):
        return str(obj)
    if isinstance(obj, str):
        # 字符串需要加双引号，处理转义字符
        escaped = obj.replace('\\', '\\\\').replace('"', '\\"')
        return f'"{escaped}"'
    if isinstance(obj, list):
        items = [object_to_json(item) for item in obj]
        return "[" + ",".join(items) + "]"
    if isinstance(obj, dict):
        pairs = [f'"{k}":{object_to_json(v)}' for k, v in obj.items()]
        return "{" + ",".join(pairs) + "}"
    return "null"


# 使用示例
print(object_to_json({"y": 1, "x": 2}))                     # {"y":1,"x":2}
print(object_to_json([1, True, None, "hello"]))              # [1,true,null,"hello"]
print(object_to_json({"a": {"b": {"c": {"d": 1}}}}))       # {"a":{"b":{"c":{"d":1}}}}
```

### 方法二：使用 Python 内置 json 模块（对比）

```python
import json
from typing import Any

def object_to_json_builtin(obj: Any) -> str:
    """
    使用内置 json 模块（不符合题目要求，仅供对比）
    separators=(',', ':') 去掉多余空格
    """
    return json.dumps(obj, separators=(',', ':'))
```

### JavaScript 参考实现

```javascript
var jsonStringify = function(object) {
    if (object === null) return 'null';
    if (typeof object === 'boolean') return String(object);
    if (typeof object === 'number') return String(object);
    if (typeof object === 'string') return `"${object}"`;
    if (Array.isArray(object)) {
        return '[' + object.map(jsonStringify).join(',') + ']';
    }
    const pairs = Object.entries(object).map(([k, v]) => `"${k}":${jsonStringify(v)}`);
    return '{' + pairs.join(',') + '}';
};
```

## 复杂度分析

- 时间复杂度：O(N)，N 为所有节点总数
- 空间复杂度：O(D)，D 为最大嵌套深度

## 关键点总结

1. 注意 bool 在 Python 中是 int 的子类，需先判断 bool
2. null 对应 Python 的 None，输出 "null"
3. 字符串需要转义特殊字符

## 易错点

1. Python 中 `True/False` 首字母大写，JSON 要求小写 `true/false`
2. `isinstance(True, int)` 为 True，需先检查 bool 类型
3. 字典键需要加双引号，不管原来是什么类型
