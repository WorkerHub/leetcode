## 题目描述

本题原为 JavaScript 递归题目。给定两个深层嵌套的 JSON 对象 `obj1` 和 `obj2`，返回一个表示**差异**的对象：
- 对于两者都有且值不同的叶子节点，记录其在 `obj1` 和 `obj2` 中的值
- 相同的键值对不记录
- 只存在于某一个对象中的键不记录

**示例 1：**
```
输入：obj1 = {}, obj2 = {"a": 1, "b": 2}
输出：{}
```

**示例 2：**
```
输入：
obj1 = {"a": 1, "v": {"x": 1, "y": 2}}
obj2 = {"a": 2, "v": {"x": 1, "z": 2}}
输出：{"a": {"obj1": 1, "obj2": 2}, "v": {"y": {"obj1": 2, "obj2": undefined}}}
```

## 解题思路

递归比较：
- 若两者都是对象（dict），对公共键递归比较，记录有差异的键
- 若值类型不同或不都是对象，且值不相等，则记录差异
- 相等的值直接跳过

## Python 代码实现

### 方法一：递归实现（推荐）

```python
from typing import Any, Dict

def find_difference(obj1: Any, obj2: Any) -> Any:
    """
    递归找出两个 JSON 对象的差异
    返回差异字典：只包含两者都有但值不同的键
    """
    # 若两者都是字典，递归比较公共键
    if isinstance(obj1, dict) and isinstance(obj2, dict):
        result = {}
        for key in set(obj1.keys()) & set(obj2.keys()):  # 只比较公共键
            diff = find_difference(obj1[key], obj2[key])
            if diff is not None:
                result[key] = diff
        return result if result else None

    # 叶子节点比较
    if obj1 == obj2:
        return None  # 相等，无差异
    else:
        return {"obj1": obj1, "obj2": obj2}  # 记录差异


# 使用示例
obj1 = {"a": 1, "v": {"x": 1, "y": 2}}
obj2 = {"a": 2, "v": {"x": 1, "z": 2}}
result = find_difference(obj1, obj2)
print(result)
# {"a": {"obj1": 1, "obj2": 2}, "v": {}}
# 注：y 只在 obj1 中，z 只在 obj2 中，所以都不记录
```

### 方法二：更完整实现（处理列表等类型）

```python
from typing import Any

def find_difference(obj1: Any, obj2: Any) -> Any:
    """
    更完整的差异对比实现
    """
    if isinstance(obj1, dict) and isinstance(obj2, dict):
        common_keys = set(obj1) & set(obj2)
        result = {}
        for k in common_keys:
            diff = find_difference(obj1[k], obj2[k])
            if diff is not None:
                result[k] = diff
        return result or None

    # 对于非字典值（包括列表、数字、字符串等）
    if obj1 != obj2:
        return {"obj1": obj1, "obj2": obj2}
    return None


# 对应 LeetCode 要求，空差异返回 {}
def diff_objects(obj1: Any, obj2: Any) -> dict:
    result = find_difference(obj1, obj2)
    return result if result is not None else {}
```

### JavaScript 参考实现

```javascript
var objDiff = function(obj1, obj2) {
    if (typeof obj1 !== 'object' || typeof obj2 !== 'object' || obj1 === null || obj2 === null) {
        return obj1 === obj2 ? {} : {obj1, obj2};
    }
    if (Array.isArray(obj1) !== Array.isArray(obj2)) return {obj1, obj2};
    const result = {};
    for (const key in obj1) {
        if (key in obj2) {
            const diff = objDiff(obj1[key], obj2[key]);
            if (Object.keys(diff).length > 0) result[key] = diff;
        }
    }
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(N)，N 为两个对象中公共节点总数
- 空间复杂度：O(D)，D 为最大嵌套深度

## 关键点总结

1. 只比较**两者都有**的键（公共键）
2. 递归处理嵌套对象
3. 叶子节点值不同时记录 `{"obj1": v1, "obj2": v2}`

## 易错点

1. 只在公共键中寻找差异，单独存在的键不记录
2. 若两个对象类型不同（一个是 dict，一个是非 dict），直接记录为差异
3. 空差异时返回 `{}`
