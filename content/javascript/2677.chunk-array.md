## 题目描述

本题原为 JavaScript 题目。给定数组 `arr` 和大小 `size`，将数组分割成若干长度为 `size` 的子数组（最后一个可能更短）。

**示例 1：**
```
输入：arr = [1,9,6,3,2], size = 3
输出：[[1,9,6],[3,2]]
```

**示例 2：**
```
输入：arr = [8,5,3,2,6], size = 6
输出：[[8,5,3,2,6]]
```

**示例 3：**
```
输入：arr = [], size = 1
输出：[]
```

## 解题思路

按步长 `size` 遍历数组，每次取 `size` 个元素作为一组。

## Python 代码实现

### 方法一：切片（推荐）

```python
from typing import List, Any

def chunk(arr: List[Any], size: int) -> List[List[Any]]:
    """
    将数组按 size 分块
    """
    return [arr[i:i + size] for i in range(0, len(arr), size)]


# 使用示例
print(chunk([1, 9, 6, 3, 2], 3))  # [[1, 9, 6], [3, 2]]
print(chunk([], 1))                # []
```

### 方法二：显式循环

```python
from typing import List, Any

def chunk(arr: List[Any], size: int) -> List[List[Any]]:
    result = []
    i = 0
    while i < len(arr):
        result.append(arr[i:i + size])
        i += size
    return result
```

### JavaScript 参考实现

```javascript
var chunk = function(arr, size) {
    const result = [];
    for (let i = 0; i < arr.length; i += size) {
        result.push(arr.slice(i, i + size));
    }
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `range(0, len, size)` 生成步长为 `size` 的下标序列
2. Python 切片自动处理末尾不足 `size` 的情况
3. 空数组直接返回空列表

## 易错点

1. 空数组不应报错
2. `size` 大于数组长度时返回包含整个数组的列表
