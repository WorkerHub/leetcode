## 题目描述

本题原为 JavaScript 设计题目。实现节流函数：给定函数 `fn` 和时间间隔 `t` 毫秒，返回节流版本。在 `t` 毫秒内，最多只执行一次 `fn`（以最新的参数执行）。

**示例：**
```
t=20ms, 调用序列：t=0,t=5,t=15ms
实际执行：t=0ms立即执行，t=20ms用t=15ms的参数执行
```

## 解题思路

使用定时器实现节流。第一次调用立即执行，在 `t` 毫秒内的后续调用被缓存（最新参数），定时器到期后若有等待的调用则执行。

## Python 代码实现

### 方法一：threading.Timer 实现

```python
from typing import Callable, Any
from threading import Timer

def throttle(fn: Callable, t: int) -> Callable:
    """
    节流函数：在 t 毫秒内最多执行一次，期间调用被缓存
    """
    waiting = [False]    # 是否有等待的调用
    pending_args = [None]  # 最新的等待参数

    def schedule():
        """定时器到期，执行等待的调用（如果有）"""
        if pending_args[0] is not None:
            args = pending_args[0]
            pending_args[0] = None
            waiting[0] = True
            fn(*args)
            Timer(t / 1000, schedule).start()
        else:
            waiting[0] = False

    def throttled(*args) -> None:
        if not waiting[0]:
            # 不在等待期，立即执行
            waiting[0] = True
            fn(*args)
            pending_args[0] = None
            Timer(t / 1000, schedule).start()
        else:
            # 在等待期，缓存最新参数
            pending_args[0] = args

    return throttled
```

### JavaScript 参考实现

```javascript
function throttle(fn, t) {
    let timer = null;
    let pendingArgs = null;
    function schedule() {
        if (pendingArgs !== null) {
            fn(...pendingArgs);
            pendingArgs = null;
            timer = setTimeout(schedule, t);
        } else {
            timer = null;
        }
    }
    return function(...args) {
        if (timer === null) {
            fn(...args);
            timer = setTimeout(schedule, t);
        } else {
            pendingArgs = args;
        }
    };
}
```

## 复杂度分析

- 时间复杂度：O(1)（每次调用）
- 空间复杂度：O(1)

## 关键点总结

1. 节流：控制函数执行频率，t 毫秒内最多一次
2. 与防抖的区别：节流第一次立即执行，防抖只执行最后一次
3. 等待期的调用缓存最新参数，等待期结束后执行

## 易错点

1. 节流执行的是最新参数（非第一次参数）
2. 等待期结束后若有等待的调用，需要继续执行并重新开始计时
