## 题目描述

编写一个生成器函数，接受一个整数 `n`，依次生成 `1!, 2!, 3!, ..., n!` 的值。

**示例 1：**
```
输入：n = 5
输出：[1, 2, 6, 24, 120]
解释：
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
```

**示例 2：**
```
输入：n = 2
输出：[1, 2]
```

**示例 3：**
```
输入：n = 0
输出：[]
```

**提示：**
- `0 <= n <= 18`

## 解题思路

本题是 JavaScript 专属题，要求实现一个**生成器函数（Generator Function）**。

生成器函数使用 `function*` 语法定义，通过 `yield` 关键字依次产出值，不需要一次性计算所有结果，而是惰性求值。

核心思路：
- 维护一个累积乘积变量 `fact`，初始为 1
- 从 1 到 n 依次循环，每次乘以当前数，然后 `yield` 出去
- 这样就依次产出 1!, 2!, 3!, ..., n!

**Python 等效实现：** Python 也有生成器（使用 `yield`），可以用来理解这道题的思想。

## Python 代码实现

### 方法一：Python 生成器（理解用）

```python
from typing import Generator

def factorial_generator(n: int) -> Generator[int, None, None]:
    """Python 生成器实现阶乘序列"""
    fact = 1
    for i in range(1, n + 1):
        fact *= i  # 累积乘以当前数
        yield fact  # 产出当前阶乘值

# 使用示例
for val in factorial_generator(5):
    print(val)  # 输出 1, 2, 6, 24, 120
```

### 方法二：JavaScript 生成器（LeetCode 原题解）

```javascript
/**
 * @param {number} n
 * @yields {number}
 */
function* factorial(n) {
    let result = 1;  // 保存当前阶乘值
    for (let i = 1; i <= n; i++) {
        result *= i;   // 乘以当前数
        yield result;  // 产出当前阶乘
    }
}

// 使用示例
const gen = factorial(5);
console.log(gen.next().value);  // 1  (1!)
console.log(gen.next().value);  // 2  (2!)
console.log(gen.next().value);  // 6  (3!)
console.log(gen.next().value);  // 24 (4!)
console.log(gen.next().value);  // 120 (5!)
```

## 复杂度分析

- 时间复杂度：O(n)，生成所有 n 个阶乘值
- 空间复杂度：O(1)，只需要常数额外空间（不包括输出）

## 关键点总结

1. 生成器的核心优势：惰性求值，不一次性计算所有结果
2. 用累乘变量避免每次从 1 开始重新计算，效率更高
3. Python 中用 `yield` 实现生成器，JavaScript 中用 `function*` + `yield`
4. n=0 时循环不执行，生成器直接结束，产出空序列

## 易错点

1. 每次迭代应该先乘后 yield，而不是先 yield 后乘
2. n=0 的边界情况：不需要特殊处理，循环自然跳过
3. JavaScript 中必须使用 `function*` 语法（注意星号），普通函数不能使用 yield
