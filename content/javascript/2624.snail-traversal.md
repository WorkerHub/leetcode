## 题目描述

本题原为 JavaScript 题目。为数组原型添加 `snail(rowsCount, colsCount)` 方法，将一维数组转换为蛇形遍历的二维矩阵（列优先，奇数列从上到下，偶数列从下到上）。若数组长度不等于 `rowsCount * colsCount`，返回空数组。

**示例 1：**
```
输入：nums = [19, 10, 3, 7, 9, 8, 5, 2, 1, 17, 16, 14, 12, 18, 6, 13, 11, 20, 4, 15]
       rowsCount = 5, colsCount = 4
输出：[[19,17,16,15],[10,1,14,4],[3,2,12,20],[7,5,18,11],[9,8,6,13]]
```

## 解题思路

按列填充，奇数列（1、3、5...）从上到下，偶数列（2、4、6...，0-indexed 的奇数列）从下到上。

## Python 代码实现

### 方法一：按列填充

```python
from typing import List

def snail_traversal(nums: List[int], rows_count: int, cols_count: int) -> List[List[int]]:
    """
    将一维数组转换为蛇形（蜗牛形）二维矩阵
    """
    if len(nums) != rows_count * cols_count:
        return []

    # 初始化结果矩阵
    result = [[0] * cols_count for _ in range(rows_count)]
    idx = 0

    for col in range(cols_count):
        if col % 2 == 0:
            # 偶数列（0-indexed）：从上到下
            for row in range(rows_count):
                result[row][col] = nums[idx]
                idx += 1
        else:
            # 奇数列（0-indexed）：从下到上
            for row in range(rows_count - 1, -1, -1):
                result[row][col] = nums[idx]
                idx += 1

    return result


# 使用示例
nums = [19, 10, 3, 7, 9, 8, 5, 2, 1, 17, 16, 14, 12, 18, 6, 13, 11, 20, 4, 15]
print(snail_traversal(nums, 5, 4))
```

### 方法二：切片填充

```python
from typing import List

def snail_traversal(nums: List[int], rows: int, cols: int) -> List[List[int]]:
    if len(nums) != rows * cols:
        return []

    result = []
    for col in range(cols):
        # 取当前列的 rows 个元素
        chunk = nums[col * rows: (col + 1) * rows]
        if col % 2 == 1:
            chunk = chunk[::-1]  # 偶数列反转
        result.append(chunk)

    # 转置：result 目前是列优先，需转为行优先
    return [[result[col][row] for col in range(cols)] for row in range(rows)]
```

### JavaScript 参考实现

```javascript
Array.prototype.snail = function(rowsCount, colsCount) {
    if (rowsCount * colsCount !== this.length) return [];
    const res = Array.from({length: rowsCount}, () => new Array(colsCount));
    for (let col = 0; col < colsCount; col++) {
        for (let row = 0; row < rowsCount; row++) {
            const idx = col * rowsCount + row;
            const r = col % 2 === 0 ? row : rowsCount - 1 - row;
            res[r][col] = this[idx];
        }
    }
    return res;
};
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 列优先填充，根据列的奇偶决定方向
2. 偶数列（0-indexed）从上到下，奇数列从下到上
3. 数组长度不匹配时返回空数组

## 易错点

1. 注意列的奇偶判断（0-indexed 还是 1-indexed）
2. 蛇形是按列遍历而非按行
