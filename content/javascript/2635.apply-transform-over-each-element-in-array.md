## 题目描述

本题原为 JavaScript 题目。不使用内置 `Array.map`，实现函数 `map(arr, fn)`：给定数组 `arr` 和函数 `fn(element, index)`，返回一个新数组，其中每个元素是 `fn` 对原数组对应元素的变换结果。

**示例 1：**
```
输入：arr = [1,2,3], fn = (x, i) => x * 2
输出：[2,4,6]
```

**示例 2：**
```
输入：arr = [1,2,3,4], fn = (x, i) => x * i
输出：[0,2,6,12]
```

## 解题思路

遍历数组，对每个元素（带下标）调用变换函数，收集结果。Python 的 `map` 内置函数不传下标，本题需手动实现。

## Python 代码实现

### 方法一：手动实现（推荐）

```python
from typing import Callable, List

def transform(arr: List[int], fn: Callable[[int, int], int]) -> List[int]:
    """
    对数组每个元素应用变换函数 fn(element, index)
    """
    return [fn(x, i) for i, x in enumerate(arr)]


# 使用示例
print(transform([1, 2, 3], lambda x, i: x * 2))      # [2, 4, 6]
print(transform([1, 2, 3, 4], lambda x, i: x * i))   # [0, 2, 6, 12]
print(transform([10, 20, 30], lambda x, i: x + i))   # [10, 21, 32]
```

### 方法二：显式循环

```python
from typing import Callable, List

def transform(arr: List[int], fn: Callable) -> List[int]:
    result = []
    for i, x in enumerate(arr):
        result.append(fn(x, i))  # 传入元素值和下标
    return result
```

### JavaScript 参考实现

```javascript
var map = function(arr, fn) {
    const result = new Array(arr.length);
    for (let i = 0; i < arr.length; i++) {
        result[i] = fn(arr[i], i);
    }
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 结果数组长度与原数组相同
2. 变换函数接受 `(element, index)` 两个参数
3. 列表推导式是 Python 中最简洁的实现方式

## 易错点

1. 注意变换函数接受两个参数：元素值和下标
2. 返回新数组，不修改原数组
