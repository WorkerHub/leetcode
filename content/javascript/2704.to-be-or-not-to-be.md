## 题目描述

请你编写一个名为 `expect` 的函数，用于帮助开发者测试他们的代码。它接受任何值 `val` 并返回一个包含以下两个函数的对象：

- `toBe(val)` 接受另一个值并在两个值全等（`===`）时返回 `true`，否则抛出错误 `"Not Equal"`。
- `notToBe(val)` 接受另一个值并在两个值不全等时返回 `true`，否则抛出错误 `"Equal"`。

**示例 1：**
```
输入：func = () => expect(5).toBe(5)
输出：{"value": true}
```

**示例 2：**
```
输入：func = () => expect(5).toBe(null)
输出：{"error": "Not Equal"}
```

**示例 3：**
```
输入：func = () => expect(5).notToBe(null)
输出：{"value": true}
```

## 解题思路

使用闭包保存传入的值 `val`，返回对象包含两个方法。`toBe` 使用严格相等 `===` 比较，`notToBe` 使用 `!==` 比较，不满足条件时抛出对应错误信息。

## Python 代码实现

### 方法一：JavaScript 闭包实现（推荐）

```javascript
/**
 * @param {string} val
 * @return {Object}
 */
var expect = function(val) {
    return {
        // 严格相等则返回 true，否则抛出错误
        toBe: function(other) {
            if (val === other) return true;
            throw new Error("Not Equal");
        },
        // 严格不等则返回 true，否则抛出错误
        notToBe: function(other) {
            if (val !== other) return true;
            throw new Error("Equal");
        }
    };
};
```

### 方法二：箭头函数简写

```javascript
/**
 * @param {string} val
 * @return {Object}
 */
var expect = (val) => ({
    toBe: (other) => {
        if (val !== other) throw new Error("Not Equal");
        return true;
    },
    notToBe: (other) => {
        if (val === other) throw new Error("Equal");
        return true;
    }
});
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 闭包使得内部函数可以访问外部函数的变量 `val`
2. `===` 是严格相等，同时比较值和类型
3. 抛出错误使用 `throw new Error("message")`

## 易错点

1. 使用 `===` 而非 `==`，避免类型隐式转换
2. 注意错误信息字符串要完全匹配题目要求
3. 抛出的是 `Error` 对象，不是字符串
