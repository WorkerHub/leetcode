## 题目描述

本题原为 JavaScript 题目。实现类似 `Array.prototype.reduce` 的功能：给定整数数组 `nums`、归约函数 `fn(accum, curr)` 和初始值 `init`，返回最终的归约结果。

**示例 1：**
```
输入：nums = [1,2,3,4], fn = (accum, curr) => accum + curr, init = 0
输出：10
```

**示例 2：**
```
输入：nums = [1,2,3,4], fn = (accum, curr) => accum + curr * curr, init = 100
输出：130
```

**示例 3：**
```
输入：nums = [], fn = (accum, curr) => accum + curr, init = 25
输出：25
```

## 解题思路

遍历数组，对每个元素调用 `fn(accumulator, current)`，将结果作为新的 accumulator。最终返回 accumulator。

Python 中 `functools.reduce` 提供了相同功能。

## Python 代码实现

### 方法一：手动实现

```python
from typing import Callable, List

def reduce(nums: List[int], fn: Callable[[int, int], int], init: int) -> int:
    """
    对数组进行归约操作
    """
    accumulator = init
    for num in nums:
        accumulator = fn(accumulator, num)  # 用当前结果和元素调用函数
    return accumulator


# 使用示例
print(reduce([1, 2, 3, 4], lambda acc, cur: acc + cur, 0))        # 10
print(reduce([1, 2, 3, 4], lambda acc, cur: acc + cur * cur, 100)) # 130
print(reduce([], lambda acc, cur: acc + cur, 25))                  # 25
```

### 方法二：使用 functools.reduce

```python
import functools
from typing import Callable, List

def reduce_with_init(nums: List[int], fn: Callable, init: int) -> int:
    """
    使用 functools.reduce 实现（带初始值）
    """
    return functools.reduce(fn, nums, init)
```

### JavaScript 参考实现

```javascript
var reduce = function(nums, fn, init) {
    let acc = init;
    for (const num of nums) {
        acc = fn(acc, num);
    }
    return acc;
};
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 初始值作为第一个 accumulator
2. 空数组时直接返回初始值
3. `functools.reduce` 是 Python 内置的等效实现

## 易错点

1. 空数组时不调用 fn，直接返回 init
2. accumulator 每次更新为 fn 的返回值
