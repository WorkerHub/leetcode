## 题目描述

给你一个 API `Road`，它表示一条环形街道，你不知道街道上有多少房屋。

你可以调用以下 API：
- `Road.moveToNextHouse()`：移动到下一个房屋（顺时针）
- `Road.openDoor()`：打开当前房屋的门
- `Road.isDoorOpen()`：返回当前房屋的门是否打开

你最多可以调用 API `k` 次，返回街道上房屋的数量。

**约束：** 初始位置在某个房屋，你可以用打开/关闭门的方式标记已访问。

## 解题思路

1. 打开当前房屋的门（标记起点）
2. 不断向前移动，直到再次遇到已打开的门（回到起点）
3. 计数移动次数即为房屋数量

由于只能打开不能关闭，需要先打开起点的门作为标记。

## Python 代码实现

### 方法一：标记起点（推荐）

```python
# API 定义（题目提供）
# class Road:
#     def moveToNextHouse(self) -> None: ...
#     def openDoor(self) -> None: ...
#     def isDoorOpen(self) -> bool: ...

class Solution:
    def houseCount(self, road: 'Road', k: int) -> int:
        # 打开起始房屋的门作为标记
        road.openDoor()
        count = 0

        # 移动直到回到起点（门是打开的）
        road.moveToNextHouse()
        count += 1
        while not road.isDoorOpen():
            road.moveToNextHouse()
            count += 1

        return count
```

### 方法二：JavaScript 实现

```javascript
/**
 * @param {Road} road
 * @param {number} k
 * @return {number}
 */
var houseCount = function(road, k) {
    // 标记起点：打开当前房屋的门
    road.openDoor();
    let count = 0;

    road.moveToNextHouse();
    count++;
    while (!road.isDoorOpen()) {
        road.moveToNextHouse();
        count++;
    }

    return count;
};
```

## 复杂度分析

- 时间复杂度：O(n)，n 为房屋数量
- 空间复杂度：O(1)

## 关键点总结

1. 打开起点门作为标记，移动后通过 `isDoorOpen()` 检测是否回到起点
2. 计数移动次数即为房屋总数

## 易错点

1. 先打开门再移动，而不是先移动再标记
2. 移动次数计数从第一次移动开始
