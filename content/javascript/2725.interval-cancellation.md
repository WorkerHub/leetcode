## 题目描述

给定一个函数 `fn`、一个参数数组 `args` 和一个时间间隔 `t`，立即调用 `fn` 并每隔 `t` 毫秒重复调用。

返回一个取消函数 `cancelFn`，调用后停止循环调用。

**示例 1：**
```
输入：fn = (x) => x * 2, args = [4], t = 35
输出：[{"time":0,"returned":8},{"time":35,"returned":8},{"time":70,"returned":8}]
（在 t=190ms 时取消）
```

## 解题思路

使用 `setInterval` 设置周期性调用，立即先执行一次 `fn`，返回的取消函数调用 `clearInterval` 清除定时器。

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @param {number} t
 * @return {Function}
 */
var cancellable = function(fn, args, t) {
    // 立即执行一次
    fn(...args);

    // 设置周期性调用
    const timer = setInterval(() => {
        fn(...args);
    }, t);

    // 返回取消函数
    return function cancelFn() {
        clearInterval(timer);
    };
};
```

### 方法二：箭头函数

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @param {number} t
 * @return {Function}
 */
var cancellable = (fn, args, t) => {
    fn(...args);
    const id = setInterval(() => fn(...args), t);
    return () => clearInterval(id);
};
```

## 复杂度分析

- 时间复杂度：O(1)（设置阶段）
- 空间复杂度：O(1)

## 关键点总结

1. `setInterval` 每隔 `t` 毫秒执行一次（不立即执行）
2. 需要在 `setInterval` 之前手动调用一次 `fn`
3. `clearInterval` 清除周期定时器

## 易错点

1. 立即执行容易忘记
2. `setTimeout` vs `setInterval`：前者只执行一次，后者周期执行
