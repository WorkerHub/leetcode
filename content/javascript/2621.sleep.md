## 题目描述

本题原为 JavaScript 异步题目。给定毫秒数 `millis`，实现一个异步函数，等待 `millis` 毫秒后 resolve。

**示例：**
```
输入：millis = 100
输出：约 100ms 后返回
```

## 解题思路

使用异步编程实现延时函数。Python 使用 `asyncio` 库实现异步等待。

## Python 代码实现

### 方法一：asyncio 实现

```python
import asyncio

async def sleep(millis: int) -> None:
    """
    异步等待 millis 毫秒
    """
    await asyncio.sleep(millis / 1000)  # asyncio.sleep 接受秒数


# 使用示例
async def main():
    import time
    start = time.time()
    await sleep(100)
    elapsed = (time.time() - start) * 1000
    print(f"等待了约 {elapsed:.0f} 毫秒")

asyncio.run(main())
```

### 方法二：同步版本（使用 time.sleep）

```python
import time

def sleep_sync(millis: int) -> None:
    """
    同步等待 millis 毫秒
    """
    time.sleep(millis / 1000)
```

### 方法三：结合 asyncio.Event 实现可取消的 sleep

```python
import asyncio

async def cancellable_sleep(millis: int, cancel_event: asyncio.Event = None) -> bool:
    """
    异步等待，支持取消
    返回 True 表示正常完成，False 表示被取消
    """
    try:
        await asyncio.sleep(millis / 1000)
        return True
    except asyncio.CancelledError:
        return False
```

### JavaScript 参考实现

```javascript
async function sleep(millis) {
    await new Promise(resolve => setTimeout(resolve, millis));
}
```

## 复杂度分析

- 时间复杂度：O(1)（不计等待时间）
- 空间复杂度：O(1)

## 关键点总结

1. JavaScript 的 `Promise` 对应 Python 的 `asyncio` 协程
2. `asyncio.sleep` 接受秒数，毫秒需除以 1000
3. 异步函数用 `async def` 定义，等待用 `await`

## 易错点

1. 记得将毫秒转换为秒（除以 1000）
2. `asyncio.sleep` 必须在 `async` 函数中使用
3. 运行 `async` 函数需要事件循环（`asyncio.run()`）
