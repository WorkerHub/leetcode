## 题目描述

本题原为 JavaScript 题目。给定一个对象数组，将其转换为 CSV 字符串：第一行为所有键（按字典序），后续行为对应的值（缺少的键用空字符串表示）。

**示例：**
```
输入：[{"a":1,"b":"Hello"},{"b":"World","c":3}]
输出："a,b,c\n1,Hello,\n,World,3"
```

## Python 代码实现

### 方法一：手动实现

```python
from typing import List, Dict, Any
import csv
import io

def json_to_csv(arr: List[Dict[str, Any]]) -> str:
    """
    将对象数组转换为 CSV 字符串
    """
    if not arr:
        return ""

    # 收集所有键并排序
    all_keys = sorted(set(key for obj in arr for key in obj))

    lines = [",".join(all_keys)]  # 表头
    for obj in arr:
        row = [str(obj.get(k, "")) for k in all_keys]  # 缺少的键用空字符串
        lines.append(",".join(row))

    return "\n".join(lines)


# 使用示例
data = [{"a": 1, "b": "Hello"}, {"b": "World", "c": 3}]
print(json_to_csv(data))
# a,b,c
# 1,Hello,
# ,World,3
```

### 方法二：使用 csv 模块

```python
from typing import List, Dict, Any
import csv
import io

def json_to_csv_module(arr: List[Dict[str, Any]]) -> str:
    if not arr:
        return ""
    all_keys = sorted(set(key for obj in arr for key in obj))
    output = io.StringIO()
    writer = csv.DictWriter(output, fieldnames=all_keys, extrasaction='ignore',
                            lineterminator='\n', restval='')
    writer.writeheader()
    writer.writerows(arr)
    return output.getvalue().strip()
```

### JavaScript 参考实现

```javascript
var jsonToCSV = function(arr) {
    const allKeys = [...new Set(arr.flatMap(obj => Object.keys(obj)))].sort();
    const rows = arr.map(obj => allKeys.map(k => k in obj ? obj[k] : '').join(','));
    return [allKeys.join(','), ...rows].join('\n');
};
```

## 复杂度分析

- 时间复杂度：O(n * m * log m)，n 为行数，m 为列数
- 空间复杂度：O(n * m)

## 关键点总结

1. 收集所有键并排序作为表头
2. 缺失的键用空字符串填充
3. 行用换行符 `\n` 分隔，列用逗号 `,` 分隔

## 易错点

1. 键要排序（字典序）
2. 值要转换为字符串
