## 题目描述

给定一个对象或数组 `obj`，返回一个 **紧凑对象**。**紧凑对象** 与原始对象相同，只是移除了值为 **假值** 的键。该操作适用于对象内的任何嵌套对象。

假值包括：`false`、`null`、`0`、`""`、`undefined`、`NaN`。

**示例 1：**
```
输入：obj = [null, 0, false, 1]
输出：[1]
```

**示例 2：**
```
输入：obj = {"a": null, "b": [false, 1]}
输出：{"b": [1]}
```

**示例 3：**
```
输入：obj = [null, 0, 5, [0], [false, 16]]
输出：[5, [], [16]]
```

## 解题思路

递归处理：
- 如果当前值是数组，过滤出真值元素，并对每个元素递归处理
- 如果当前值是对象，过滤出值为真值的键，并对每个值递归处理
- 否则直接返回当前值

注意数组也是对象，需要先判断数组类型。

## Python 代码实现

### 方法一：递归（推荐）

```javascript
/**
 * @param {Object|Array} obj
 * @return {Object|Array}
 */
var compactObject = function(obj) {
    // 数组情况：过滤假值后递归处理每个元素
    if (Array.isArray(obj)) {
        return obj.filter(Boolean).map(compactObject);
    }
    // 非对象（原始值）直接返回
    if (typeof obj !== 'object' || obj === null) {
        return obj;
    }
    // 普通对象：遍历键，过滤假值，递归处理值
    const result = {};
    for (const key in obj) {
        const val = obj[key];
        if (Boolean(val)) {
            result[key] = compactObject(val);
        }
    }
    return result;
};
```

### 方法二：使用 Object.entries 简化

```javascript
/**
 * @param {Object|Array} obj
 * @return {Object|Array}
 */
var compactObject = function(obj) {
    if (obj === null || typeof obj !== 'object') return obj;

    if (Array.isArray(obj)) {
        // 过滤假值并递归
        return obj.reduce((acc, val) => {
            if (val) acc.push(compactObject(val));
            return acc;
        }, []);
    }

    // 对象：过滤假值键并递归
    return Object.fromEntries(
        Object.entries(obj)
            .filter(([_, v]) => Boolean(v))
            .map(([k, v]) => [k, compactObject(v)])
    );
};
```

## 复杂度分析

- 时间复杂度：O(n)，n 为对象中所有节点数量
- 空间复杂度：O(d)，d 为对象最大嵌套深度（递归栈）

## 关键点总结

1. 先判断数组，再判断对象（`Array.isArray` 在 `typeof === 'object'` 之前）
2. `null` 的 `typeof` 是 `'object'`，需要单独处理
3. 递归深度取决于嵌套层数

## 易错点

1. 忘记处理 `null`：`typeof null === 'object'` 但不应递归
2. 数组中假值元素应被移除（不是变成 null），但嵌套对象中的假值键也应移除
3. 注意 `0`、`""`、`NaN` 等都是假值
