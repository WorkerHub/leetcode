## 题目描述

本题原为 JavaScript 设计题目。给定一个对象（或数组），返回一个不可变的代理版本：尝试修改属性时抛出错误 `"Cannot mutate"`。修改操作包括：设置属性、删除属性、向数组 push。

## 解题思路

JavaScript 使用 Proxy 拦截所有 set/deleteProperty 操作。Python 使用 `__setattr__`、`__delattr__` 拦截修改，或者用 `frozenset`、不可变数据结构。

## Python 代码实现

### 方法一：继承 + 拦截写操作

```python
from typing import Any

class ImmutableDict(dict):
    """不可变字典（拦截所有修改操作）"""

    def __setitem__(self, key, value):
        raise TypeError("Cannot mutate")

    def __delitem__(self, key):
        raise TypeError("Cannot mutate")

    def update(self, *args, **kwargs):
        raise TypeError("Cannot mutate")

    def pop(self, *args):
        raise TypeError("Cannot mutate")

    def clear(self):
        raise TypeError("Cannot mutate")


class ImmutableList(list):
    """不可变列表"""

    def __setitem__(self, index, value):
        raise TypeError("Cannot mutate")

    def __delitem__(self, index):
        raise TypeError("Cannot mutate")

    def append(self, value):
        raise TypeError("Cannot mutate")

    def extend(self, values):
        raise TypeError("Cannot mutate")

    def insert(self, index, value):
        raise TypeError("Cannot mutate")

    def pop(self, index=-1):
        raise TypeError("Cannot mutate")

    def remove(self, value):
        raise TypeError("Cannot mutate")


def make_immutable(obj: Any) -> Any:
    """
    将对象转为不可变版本
    """
    if isinstance(obj, dict):
        return ImmutableDict({k: make_immutable(v) for k, v in obj.items()})
    if isinstance(obj, list):
        return ImmutableList(make_immutable(item) for item in obj)
    return obj  # 基本类型已经是不可变的


# 使用示例
data = {"a": 1, "b": [1, 2, 3]}
immutable = make_immutable(data)
try:
    immutable["a"] = 2  # 抛出 TypeError: Cannot mutate
except TypeError as e:
    print(e)
```

### JavaScript 参考实现

```javascript
function makeImmutable(obj) {
    const handler = {
        set() { throw "Cannot mutate"; },
        deleteProperty() { throw "Cannot mutate"; },
        get(target, prop) {
            const val = target[prop];
            if (typeof val === 'object' && val !== null) return makeImmutable(val);
            if (typeof val === 'function') return val.bind(target);
            return val;
        }
    };
    return new Proxy(obj, handler);
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为对象节点总数
- 空间复杂度：O(n)

## 关键点总结

1. 拦截所有修改操作（set、delete、push 等）
2. 递归处理嵌套对象
3. 修改时抛出特定错误信息

## 易错点

1. 需要处理嵌套对象，不只是顶层
2. Python 中 `int`、`str` 等基本类型天然不可变
