## 题目描述

本题原为 JavaScript 设计题目。实现一个记忆化函数，与 2623 题不同的是，参数可以是任意对象（不限于原始类型），需要通过引用判断对象的唯一性。

**示例：**
```
fn = (a, b, c) => (a + b + c)
参数可以是对象引用，相同引用视为相同参数
```

## 解题思路

由于参数可以是对象，无法直接序列化为字符串键。需要为每个唯一对象分配一个唯一 ID，然后用 ID 组合作为缓存键。

Python 中可以用 `id()` 函数获取对象的唯一标识（内存地址），但需注意垃圾回收可能导致 ID 重用。更安全的方式是使用 `WeakKeyDictionary` 或自行维护对象 ID 映射。

## Python 代码实现

### 方法一：使用 id() 和 WeakKeyDictionary

```python
from typing import Callable, Any
import weakref

def memoize_ii(fn: Callable) -> Callable:
    """
    记忆化函数，支持对象参数（通过引用标识）
    """
    # 为每个对象分配唯一 ID
    obj_id_map = {}
    id_counter = [0]

    def get_obj_id(obj):
        """为对象分配稳定的唯一 ID（基于 id()）"""
        oid = id(obj)
        if oid not in obj_id_map:
            obj_id_map[oid] = id_counter[0]
            id_counter[0] += 1
        return obj_id_map[oid]

    cache = {}

    def memoized(*args) -> Any:
        # 为每个参数计算唯一键（可哈希对象用值，不可哈希用 id）
        key = []
        for arg in args:
            try:
                hash(arg)
                key.append(('v', arg))  # 可哈希：用值
            except TypeError:
                key.append(('id', id(arg)))  # 不可哈希：用引用 id
        key = tuple(key)
        if key not in cache:
            cache[key] = fn(*args)
        return cache[key]

    return memoized


# 使用示例
call_count = 0
def add(a, b, c):
    global call_count
    call_count += 1
    return a + b + c

memo_add = memoize_ii(add)
obj = {}
print(memo_add(obj, 2, 3))  # 计算
print(memo_add(obj, 2, 3))  # 缓存（同一个 obj 引用）
obj2 = {}
print(memo_add(obj2, 2, 3))  # 不同对象，重新计算
```

### 方法二：使用自定义 ID 分配器

```python
from typing import Callable, Any

def memoize_ii(fn: Callable) -> Callable:
    """
    为每个参数分配唯一 ID 用于缓存键
    """
    arg_to_id = {}  # 对象 id -> 分配的唯一编号
    next_id = [0]
    cache = {}

    def assign_id(arg):
        """为参数分配唯一编号"""
        try:
            hash(arg)
            # 可哈希对象（包括原始类型）直接用其哈希
            return ('hashable', arg)
        except TypeError:
            # 不可哈希对象用 id()
            obj_id = id(arg)
            if obj_id not in arg_to_id:
                arg_to_id[obj_id] = next_id[0]
                next_id[0] += 1
            return ('obj', arg_to_id[obj_id])

    def memoized(*args) -> Any:
        key = tuple(assign_id(arg) for arg in args)
        if key not in cache:
            cache[key] = fn(*args)
        return cache[key]

    return memoized
```

### JavaScript 参考实现

```javascript
function memoize(fn) {
    const cache = new Map();
    const getKey = (args) => {
        let node = cache;
        for (const arg of args) {
            if (!node.has(arg)) node.set(arg, new Map());
            node = node.get(arg);
        }
        return node;
    };
    return function(...args) {
        const node = getKey(args);
        if (!node.has('result')) node.set('result', fn(...args));
        return node.get('result');
    };
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为参数个数（每次调用）
- 空间复杂度：O(U)，U 为不同调用组合的数量

## 关键点总结

1. 通过对象引用（而非内容）判断相同性
2. JavaScript 的 Map 支持对象作为键（引用比较）
3. Python 中不可哈希对象用 id() 作为代理键

## 易错点

1. 短命对象的 id() 可能被重用，需要保持强引用
2. 可哈希和不可哈希对象需要区分处理
3. 与 memoize I 的区别：参数可以是任意类型
