## 题目描述

本题原为 JavaScript 函数式编程题目。给定函数数组 `[f1, f2, ..., fn]`，返回它们的复合函数 `fn(fn-1(...f2(f1(x))))`。若数组为空，返回恒等函数 `f(x) = x`。

**示例 1：**
```
输入：functions = [x => x + 1, x => x * x, x => 2 * x], x = 4
输出：65
解释：先 4+1=5，再 5*5=25，再 2*25=50... 实际从右到左：2*(4*4)+1? 
注：compose 是从右到左，即先执行最后一个函数
```

**示例 2：**
```
输入：functions = [], x = 42
输出：42（恒等函数）
```

## 解题思路

函数组合（从右到左）：对函数数组倒序执行，每个函数的输出作为下一个函数的输入。

Python 中 `functools.reduce` 可以优雅实现函数组合。

## Python 代码实现

### 方法一：手动实现（推荐）

```python
from typing import Callable, List, Any

def compose(functions: List[Callable]) -> Callable:
    """
    返回函数组合（从右到左执行）
    """
    def composed(x: Any) -> Any:
        # 从右到左依次执行函数
        for fn in reversed(functions):
            x = fn(x)
        return x

    return composed


# 使用示例
add1 = lambda x: x + 1
square = lambda x: x * x
double = lambda x: x * 2

# compose 从右到左：先 add1，再 square，再 double
f = compose([double, square, add1])
print(f(4))  # double(square(add1(4))) = double(square(5)) = double(25) = 50
```

### 方法二：使用 functools.reduce

```python
import functools
from typing import Callable, List, Any

def compose(functions: List[Callable]) -> Callable:
    """
    使用 reduce 实现函数组合
    """
    if not functions:
        return lambda x: x  # 空数组返回恒等函数

    def apply(f, g):
        return lambda x: f(g(x))

    return functools.reduce(apply, functions)


# Python 标准库 functools 没有内置 compose，但有 partial
```

### 方法三：管道（从左到右）

```python
from typing import Callable, List, Any

def pipe(functions: List[Callable]) -> Callable:
    """
    管道：从左到右执行（与 compose 相反）
    """
    def piped(x: Any) -> Any:
        for fn in functions:
            x = fn(x)
        return x
    return piped
```

### JavaScript 参考实现

```javascript
var compose = function(functions) {
    return function(x) {
        return functions.reduceRight((acc, fn) => fn(acc), x);
    };
};
```

## 复杂度分析

- 时间复杂度：O(n)（每次调用执行 n 个函数）
- 空间复杂度：O(1)

## 关键点总结

1. 组合函数（compose）从右到左执行
2. 管道函数（pipe）从左到右执行
3. 空函数组返回恒等函数

## 易错点

1. 注意执行顺序（从右到左还是从左到右）
2. 空数组时返回恒等函数而非报错
3. 每个函数只接受单个参数（本题）
