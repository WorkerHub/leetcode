## 题目描述

本题原为 JavaScript 题目。实现函数判断两个 JSON 值是否深度相等。支持的 JSON 值类型包括：数字、字符串、布尔值、null、数组和对象。

**示例 1：**
```
输入：o1 = {"x":1,"y":2}, o2 = {"x":1,"y":2}
输出：true
```

**示例 2：**
```
输入：o1 = {"x":1}, o2 = {"x":1,"y":2}
输出：false
```

**示例 3：**
```
输入：o1 = [1,2,3], o2 = [1,2,3]
输出：true
```

## 解题思路

递归比较：
- 若类型不同，返回 false
- 若为基本类型（数字、字符串、布尔、null），直接比较
- 若为列表（数组），长度相同且每个元素递归相等
- 若为字典（对象），键集合相同且每个键对应的值递归相等

## Python 代码实现

### 方法一：递归实现（推荐）

```python
from typing import Any

def are_deeply_equal(o1: Any, o2: Any) -> bool:
    """
    深度比较两个 JSON 值是否相等
    """
    # 类型不同则不等（注意 bool 是 int 的子类，需特殊处理）
    if type(o1) != type(o2):
        return False

    # 基本类型：直接比较
    if not isinstance(o1, (dict, list)):
        return o1 == o2

    # 列表：长度相同且每个元素递归相等
    if isinstance(o1, list):
        if len(o1) != len(o2):
            return False
        return all(are_deeply_equal(a, b) for a, b in zip(o1, o2))

    # 字典：键集合相同且每个值递归相等
    if isinstance(o1, dict):
        if set(o1.keys()) != set(o2.keys()):
            return False
        return all(are_deeply_equal(o1[k], o2[k]) for k in o1)

    return False


# 使用示例
print(are_deeply_equal({"x": 1, "y": 2}, {"x": 1, "y": 2}))  # True
print(are_deeply_equal([1, 2, 3], [1, 2, 3]))                  # True
print(are_deeply_equal({"x": 1}, {"x": 1, "y": 2}))           # False
```

### 方法二：使用 JSON 序列化比较（适用于简单情况）

```python
import json
from typing import Any

def are_deeply_equal_json(o1: Any, o2: Any) -> bool:
    """
    通过 JSON 序列化比较（注意：字典键的顺序不影响结果）
    但此方法要求对象可 JSON 序列化，且对象中键无序时可能不准确
    """
    def normalize(obj):
        if isinstance(obj, dict):
            return {k: normalize(v) for k, v in sorted(obj.items())}
        if isinstance(obj, list):
            return [normalize(v) for v in obj]
        return obj

    return json.dumps(normalize(o1), sort_keys=True) == json.dumps(normalize(o2), sort_keys=True)
```

### JavaScript 参考实现

```javascript
function areDeeplyEqual(o1, o2) {
    if (o1 === o2) return true;
    if (typeof o1 !== typeof o2) return false;
    if (o1 === null || o2 === null) return false;
    if (Array.isArray(o1) !== Array.isArray(o2)) return false;
    if (Array.isArray(o1)) {
        if (o1.length !== o2.length) return false;
        return o1.every((v, i) => areDeeplyEqual(v, o2[i]));
    }
    if (typeof o1 === 'object') {
        const keys1 = Object.keys(o1), keys2 = Object.keys(o2);
        if (keys1.length !== keys2.length) return false;
        return keys1.every(k => areDeeplyEqual(o1[k], o2[k]));
    }
    return false;
}
```

## 复杂度分析

- 时间复杂度：O(N)，N 为所有节点总数
- 空间复杂度：O(D)，D 为最大嵌套深度（递归栈）

## 关键点总结

1. 区分列表和字典（Python 中类型判断用 `isinstance`）
2. 基本类型直接比较
3. Python 中 `bool` 是 `int` 子类，`type()` 严格比较更准确

## 易错点

1. Python 中 `True == 1` 为 True，需用 `type()` 区分
2. `None` 和 `null` 对应，直接 `==` 比较即可
3. 字典键的顺序无关，需比较键集合
