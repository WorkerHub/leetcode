## 题目描述

本题原为 JavaScript 设计题目。给定初始值 `init`，返回一个包含三个方法的对象：
- `increment()`：计数加 1 并返回
- `decrement()`：计数减 1 并返回
- `reset()`：重置为初始值并返回

## 解题思路

使用闭包保存状态，返回包含三个方法的对象（Python 中用类实现）。

## Python 代码实现

### 方法一：类实现（推荐）

```python
class Counter:
    def __init__(self, init: int):
        self.init = init    # 保存初始值
        self.current = init # 当前值

    def increment(self) -> int:
        self.current += 1
        return self.current

    def decrement(self) -> int:
        self.current -= 1
        return self.current

    def reset(self) -> int:
        self.current = self.init
        return self.current


# 使用示例
counter = Counter(5)
print(counter.increment())  # 6
print(counter.reset())      # 5
print(counter.decrement())  # 4
```

### 方法二：闭包实现（模拟 JS 闭包）

```python
from typing import Dict, Callable

def create_counter(init: int) -> Dict[str, Callable]:
    """
    返回包含 increment/decrement/reset 三个方法的字典
    """
    state = [init]  # 用列表包装以便在闭包中修改

    def increment():
        state[0] += 1
        return state[0]

    def decrement():
        state[0] -= 1
        return state[0]

    def reset():
        state[0] = init
        return state[0]

    return {"increment": increment, "decrement": decrement, "reset": reset}
```

### JavaScript 参考实现

```javascript
function createCounter(init) {
    let current = init;
    return {
        increment: () => ++current,
        decrement: () => --current,
        reset: () => { current = init; return current; }
    };
}
```

## 复杂度分析

- 时间复杂度：O(1)（每次调用）
- 空间复杂度：O(1)

## 关键点总结

1. 需要同时保存初始值和当前值
2. `reset()` 恢复到初始值，而非 0
3. Python 中类比闭包更自然

## 易错点

1. `reset()` 恢复到 `init` 而非 0
2. 初始值需要单独保存，不能和当前值共用
