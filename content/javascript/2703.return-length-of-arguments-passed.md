## 题目描述

编写一个函数 `argumentsLength`，返回传递给它的参数数量。

**示例 1：**
```
输入：args = [5]
输出：1
解释：argumentsLength(5) 返回 1
```

**示例 2：**
```
输入：args = [{}, null, "3"]
输出：3
解释：argumentsLength({}, null, "3") 返回 3
```

**提示：**
- `args` 是一个有效的 JSON 数组
- `0 <= args.length <= 100`

## 解题思路

这是一道 JavaScript 题目，考察对 rest 参数（剩余参数）或 `arguments` 对象的理解。使用扩展运算符 `...args` 收集所有参数，返回 `args.length` 即可。

## Python 代码实现

### 方法一：JavaScript 实现（rest 参数）

```javascript
/**
 * @param {...(null|boolean|number|string|Array|Object)} args
 * @return {number}
 */
var argumentsLength = function(...args) {
    // 使用 rest 参数收集所有传入参数
    return args.length;
};
```

### 方法二：使用 arguments 对象

```javascript
/**
 * @param {...(null|boolean|number|string|Array|Object)} args
 * @return {number}
 */
var argumentsLength = function() {
    // arguments 是函数内置的类数组对象，包含所有传入参数
    return arguments.length;
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. JavaScript 中 rest 参数 `...args` 将所有传入参数收集为数组
2. `arguments` 对象是函数内所有参数的类数组（箭头函数中不可用）
3. 两种方式都可以获取参数数量

## 易错点

1. 箭头函数 `() => {}` 没有 `arguments` 对象，使用方法二时需用普通函数
2. rest 参数必须是最后一个参数
