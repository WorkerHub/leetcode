## 题目描述

设计一个 `Calculator` 类。该类提供以下方法：

- `Calculator(value)`：以给定初始值初始化
- `add(value)`：将 value 加到当前值，返回 `this`
- `subtract(value)`：从当前值减去 value，返回 `this`
- `multiply(value)`：当前值乘以 value，返回 `this`
- `divide(value)`：当前值除以 value，返回 `this`（若 value 为 0，抛出错误 `"Division by zero is not allowed"`）
- `power(value)`：当前值的 value 次方，返回 `this`
- `getResult()`：返回当前值

**示例 1：**
```
new Calculator(10).add(5).subtract(7).getResult() → 8
```

**示例 2：**
```
new Calculator(2).multiply(5).power(2).getResult() → 100
```

## 解题思路

每个方法修改内部状态后返回 `this`，实现链式调用（方法链模式 / Fluent Interface）。

## Python 代码实现

### 方法一：JavaScript 类实现（推荐）

```javascript
class Calculator {
    /**
     * @param {number} value
     */
    constructor(value) {
        this.result = value;  // 存储当前值
    }

    add(value) {
        this.result += value;
        return this;  // 返回 this 支持链式调用
    }

    subtract(value) {
        this.result -= value;
        return this;
    }

    multiply(value) {
        this.result *= value;
        return this;
    }

    divide(value) {
        if (value === 0) {
            throw new Error("Division by zero is not allowed");
        }
        this.result /= value;
        return this;
    }

    power(value) {
        this.result **= value;  // 幂运算符
        return this;
    }

    getResult() {
        return this.result;
    }
}
```

### 方法二：Python 类实现

```python
class Calculator:
    def __init__(self, value: float):
        self.result = value

    def add(self, value: float) -> 'Calculator':
        self.result += value
        return self

    def subtract(self, value: float) -> 'Calculator':
        self.result -= value
        return self

    def multiply(self, value: float) -> 'Calculator':
        self.result *= value
        return self

    def divide(self, value: float) -> 'Calculator':
        if value == 0:
            raise ValueError("Division by zero is not allowed")
        self.result /= value
        return self

    def power(self, value: float) -> 'Calculator':
        self.result **= value
        return self

    def getResult(self) -> float:
        return self.result
```

## 复杂度分析

- 时间复杂度：O(1) 每次操作
- 空间复杂度：O(1)

## 关键点总结

1. 每个修改方法返回 `this`（Python 中返回 `self`）实现链式调用
2. 除数为零时抛出错误
3. `**=` 是幂赋值运算符

## 易错点

1. 除法时要检查除数是否为 0
2. `getResult()` 不返回 `this`，返回实际值
