## 题目描述

本题原为 JavaScript 异步并发题目。给定一组异步函数 `functions` 和并发限制 `n`，实现 `promisePool` 函数，确保最多同时运行 `n` 个异步任务，所有任务完成后 resolve。

**示例：**
```
t=50ms 启动第1和第2个（并发2）
t=100ms 第2个完成，启动第3个
t=150ms 第1个完成，启动第4个
t=200ms 第3个完成
t=250ms 第4个完成
总时间约250ms
```

## 解题思路

使用信号量（Semaphore）限制并发数。Python 的 `asyncio.Semaphore` 内置支持并发控制。

## Python 代码实现

### 方法一：asyncio.Semaphore（推荐）

```python
import asyncio
from typing import Callable, List

async def promise_pool(functions: List[Callable], n: int) -> None:
    """
    并发执行异步函数，最多同时运行 n 个
    """
    semaphore = asyncio.Semaphore(n)  # 限制并发数为 n

    async def run(fn):
        async with semaphore:  # 获取信号量，超过 n 个时等待
            await fn()

    # 并发启动所有任务
    await asyncio.gather(*[run(fn) for fn in functions])


# 使用示例
async def main():
    results = []

    async def task(delay, value):
        await asyncio.sleep(delay / 1000)
        results.append(value)

    await promise_pool([
        lambda: task(200, 1),
        lambda: task(100, 2),
        lambda: task(150, 3),
    ], n=2)
    print(results)

asyncio.run(main())
```

### 方法二：手动实现队列调度

```python
import asyncio
from typing import Callable, List
from collections import deque

async def promise_pool_manual(functions: List[Callable], n: int) -> None:
    """
    手动实现：维护运行中的任务数量
    """
    running = 0
    queue = deque(functions)
    done_event = asyncio.Event()
    total = len(functions)
    completed = [0]

    async def worker():
        nonlocal running
        while queue:
            fn = queue.popleft()
            running += 1
            await fn()
            running -= 1
            completed[0] += 1
            if completed[0] == total:
                done_event.set()
            # 启动下一个任务（如果有）
            if queue and running < n:
                asyncio.create_task(worker())

    # 启动最多 n 个初始 worker
    for _ in range(min(n, len(functions))):
        asyncio.create_task(worker())

    await done_event.wait()
```

### JavaScript 参考实现

```javascript
async function promisePool(functions, n) {
    const executing = [];
    for (const fn of functions) {
        const p = fn().then(() => executing.splice(executing.indexOf(p), 1));
        executing.push(p);
        if (executing.length >= n) await Promise.race(executing);
    }
    await Promise.all(executing);
}
```

## 复杂度分析

- 时间复杂度：O(total_tasks / n * max_task_time)（理想情况）
- 空间复杂度：O(n)，最多 n 个并发任务

## 关键点总结

1. `asyncio.Semaphore` 是限制并发的标准工具
2. `asyncio.gather` 并发执行多个协程
3. 信号量确保任何时刻最多 n 个任务同时运行

## 易错点

1. 信号量的初始值就是最大并发数
2. `async with semaphore` 自动获取和释放
3. 任务完成后信号量自动释放，等待的任务会被唤醒
