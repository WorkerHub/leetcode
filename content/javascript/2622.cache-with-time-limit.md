## 题目描述

本题原为 JavaScript 设计题目。实现一个带有过期时间的缓存类，支持以下操作：

- `set(key, value, duration)`：若 `key` 不存在或已过期，创建缓存（返回 false）；若 `key` 存在且未过期，更新值（返回 true）。持续时间 `duration` 毫秒后过期。
- `get(key)`：若 `key` 存在且未过期，返回对应值；否则返回 -1。
- `count()`：返回未过期的键总数。

## 解题思路

用字典存储 `key -> (value, expire_time)` 的映射。`expire_time` 为过期的绝对时间戳，使用 Python 的 `time.time()` 获取当前时间。

## Python 代码实现

### 方法一：字典 + 时间戳

```python
import time

class TimeLimitedCache:
    def __init__(self):
        # 存储 key -> (value, expire_time_ms)
        self.cache = {}

    def set(self, key: int, value: int, duration: int) -> bool:
        """
        设置键值对，duration 毫秒后过期
        返回 True 如果 key 之前存在且未过期
        """
        now_ms = int(time.time() * 1000)  # 当前时间（毫秒）
        existed = key in self.cache and self.cache[key][1] > now_ms
        self.cache[key] = (value, now_ms + duration)
        return existed

    def get(self, key: int) -> int:
        """
        获取键对应值，已过期或不存在返回 -1
        """
        now_ms = int(time.time() * 1000)
        if key in self.cache and self.cache[key][1] > now_ms:
            return self.cache[key][0]
        return -1

    def count(self) -> int:
        """
        返回未过期键的数量
        """
        now_ms = int(time.time() * 1000)
        return sum(1 for v, exp in self.cache.values() if exp > now_ms)
```

### 方法二：支持自动清理的版本

```python
import time
from threading import Timer

class TimeLimitedCache:
    def __init__(self):
        self.cache = {}

    def _cleanup(self, key):
        """过期时自动删除"""
        if key in self.cache:
            del self.cache[key]

    def set(self, key: int, value: int, duration: int) -> bool:
        now_ms = int(time.time() * 1000)
        existed = key in self.cache and self.cache[key][1] > now_ms

        # 取消旧的定时器（如果存在）
        if key in self.cache and 'timer' in self.cache[key][2]:
            self.cache[key][2].cancel()

        timer = Timer(duration / 1000, self._cleanup, [key])
        timer.start()
        self.cache[key] = (value, now_ms + duration, timer)
        return existed

    def get(self, key: int) -> int:
        now_ms = int(time.time() * 1000)
        if key in self.cache and self.cache[key][1] > now_ms:
            return self.cache[key][0]
        return -1

    def count(self) -> int:
        now_ms = int(time.time() * 1000)
        return sum(1 for v, exp, *_ in self.cache.values() if exp > now_ms)
```

### JavaScript 参考实现

```javascript
class TimeLimitedCache {
    constructor() {
        this.cache = new Map();
    }
    set(key, value, duration) {
        const existed = this.cache.has(key) && this.cache.get(key).expire > Date.now();
        if (existed) clearTimeout(this.cache.get(key).timer);
        const timer = setTimeout(() => this.cache.delete(key), duration);
        this.cache.set(key, { value, expire: Date.now() + duration, timer });
        return existed;
    }
    get(key) {
        return this.cache.has(key) ? this.cache.get(key).value : -1;
    }
    count() {
        return this.cache.size;
    }
}
```

## 复杂度分析

- 时间复杂度：set/get O(1)，count O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 时间戳比较判断是否过期
2. `set` 操作需要判断旧值是否存在（且未过期）
3. `count` 需要遍历所有键检查过期状态

## 易错点

1. 过期判断用严格大于 `>`，等于过期时间时已过期
2. 更新已过期 key 时，返回 false（视为不存在）
3. 注意时间单位：`time.time()` 返回秒，需转换为毫秒
