## 题目描述

本题原为 JavaScript 函数式编程题目。实现 `curry(fn)` 函数，返回柯里化版本的 `fn`。柯里化函数可以部分应用参数，当参数累积到 `fn` 需要的数量时，自动执行并返回结果。

**示例：**
```
fn = (a, b, c) => a + b + c
curriedFn = curry(fn)
curriedFn(1)(2)(3)  -> 6
curriedFn(1, 2)(3)  -> 6
curriedFn(1)(2, 3)  -> 6
```

## 解题思路

柯里化（Currying）：将多参数函数转化为一系列单参数函数。

实现方式：每次调用返回一个新函数（等待更多参数），直到参数数量满足原函数需求时执行。

Python 中 `functools.partial` 提供了部分应用功能，`inspect.signature` 可以获取函数参数数量。

## Python 代码实现

### 方法一：手动实现柯里化

```python
import inspect
from typing import Callable, Any

def curry(fn: Callable) -> Callable:
    """
    返回函数的柯里化版本
    """
    arity = len(inspect.signature(fn).parameters)  # 函数需要的参数数量

    def curried(*args) -> Any:
        if len(args) >= arity:
            # 参数足够，执行原函数
            return fn(*args[:arity])
        else:
            # 参数不足，返回等待更多参数的函数
            def wait_for_more(*more_args):
                return curried(*(args + more_args))
            return wait_for_more

    return curried


# 使用示例
def add(a, b, c):
    return a + b + c

curried_add = curry(add)
print(curried_add(1)(2)(3))   # 6
print(curried_add(1, 2)(3))   # 6
print(curried_add(1)(2, 3))   # 6
print(curried_add(1, 2, 3))   # 6
```

### 方法二：使用 functools.partial

```python
import functools
from typing import Callable, Any

def curry(fn: Callable) -> Callable:
    """
    使用 functools.partial 实现柯里化
    """
    import inspect
    arity = len(inspect.signature(fn).parameters)

    def curried(*args):
        if len(args) >= arity:
            return fn(*args)
        return lambda *more: curried(*(args + more))

    return curried
```

### 方法三：Python 内置的偏函数

```python
import functools

# functools.partial 提供了部分应用功能（非完整柯里化）
def add(a, b, c):
    return a + b + c

add_1 = functools.partial(add, 1)       # 固定第一个参数
add_1_2 = functools.partial(add_1, 2)  # 固定前两个参数
print(add_1_2(3))  # 6
```

### JavaScript 参考实现

```javascript
function curry(fn) {
    return function curried(...args) {
        if (args.length >= fn.length) {
            return fn(...args);
        }
        return (...moreArgs) => curried(...args, ...moreArgs);
    };
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为参数数量（每次调用为 O(1)）
- 空间复杂度：O(n)，累积参数存储

## 关键点总结

1. 柯里化将 n 元函数转化为一系列单参数函数的链
2. 使用闭包累积参数，直到参数数量满足条件
3. `fn.length`（JS）或 `inspect.signature`（Python）获取参数数量

## 易错点

1. 注意处理多参数一次性传入的情况
2. 参数数量判断基于原函数需要的参数数量
3. 每次返回新函数，不修改原函数
