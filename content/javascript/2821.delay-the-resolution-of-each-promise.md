## 题目描述

给你一个 Promise 数组 `functions` 和一个整数 `ms`。

返回一个新的 Promise 数组，其中每个 Promise 被延迟 `ms` 毫秒后才开始执行/解析。

**示例 1：**
```
输入：functions = [() => new Promise(res => res(42))], ms = 500
输出：[{"t": 500, "resolved": 42}]
解释：Promise 在 500ms 后解析为 42
```

**提示：**
- `functions` 是有效的 Promise 工厂函数数组
- `0 <= ms <= 500`

## 解题思路

本题是 JavaScript 异步编程题。

核心思路：
- 对每个 function，包装一个新的 Promise
- 在新 Promise 内部，先 `await` 一个 `ms` 毫秒的延迟（用 `setTimeout` 实现）
- 延迟结束后，执行原函数并 resolve/reject

## Python 代码实现

### 方法一：Python 异步等效（理解用）

```python
import asyncio
from typing import List, Callable, Any, Awaitable

async def delay_each(functions: List[Callable], ms: float) -> List[Any]:
    """延迟每个函数 ms 毫秒后执行"""
    async def delayed(fn: Callable) -> Any:
        await asyncio.sleep(ms / 1000)  # ms 转换为秒
        return await fn()
    
    results = await asyncio.gather(*[delayed(fn) for fn in functions])
    return results
```

### 方法二：JavaScript 实现（LeetCode 原题解）

```javascript
/**
 * @param {Array<Function>} functions - Promise 工厂函数数组
 * @param {number} ms - 延迟毫秒数
 * @return {Array<Function>} - 延迟后的 Promise 工厂函数数组
 */
var delayAll = function(functions, ms) {
    return functions.map(fn => {
        return () => new Promise((resolve, reject) => {
            // 延迟 ms 毫秒后执行原函数
            setTimeout(() => {
                fn()
                    .then(resolve)   // 成功时 resolve
                    .catch(reject);  // 失败时 reject
            }, ms);
        });
    });
};

// 更简洁的 async/await 写法
var delayAll = function(functions, ms) {
    return functions.map(fn => async () => {
        // 等待 ms 毫秒
        await new Promise(resolve => setTimeout(resolve, ms));
        // 执行原函数并返回结果
        return fn();
    });
};
```

## 复杂度分析

- 时间复杂度：O(n)，映射每个函数
- 空间复杂度：O(n)，返回新数组

## 关键点总结

1. `setTimeout(fn, ms)` 是 JavaScript 中延迟执行的基本工具
2. 用 `new Promise((resolve, reject) => {...})` 包装异步操作
3. `.then(resolve).catch(reject)` 将原 Promise 的状态传递给新 Promise
4. `async/await` 写法更简洁，先 `await` 延迟，再调用原函数

## 易错点

1. 需要将 `fn()` 的成功和失败都正确传递（`resolve` 和 `reject`）
2. 延迟的是**执行时间**，不是创建 Promise 对象的时间
3. Python 的 `asyncio.sleep` 参数单位是秒，需要除以 1000
