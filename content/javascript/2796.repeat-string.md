## 题目描述

给所有字符串添加 `repeatify` 方法，`s.repeatify(n)` 返回字符串 `s` 重复 `n` 次的结果。

**示例：**
```javascript
"a".repeatify(5); // "aaaaa"
```

## 解题思路

通过 `String.prototype` 添加方法，内部使用字符串的 `repeat` 方法，或手动拼接。

## Python 代码实现

### 方法一：使用 repeat（推荐）

```javascript
/**
 * @param {number} times
 * @return {string}
 */
String.prototype.repeatify = function(times) {
    return this.repeat(times);
};
```

### 方法二：手动拼接（不用 repeat）

```javascript
String.prototype.repeatify = function(times) {
    let result = '';
    for (let i = 0; i < times; i++) {
        result += this;
    }
    return result;
};
```

### 方法三：Python 等效

```python
def repeatify(s: str, n: int) -> str:
    return s * n
```

## 复杂度分析

- 时间复杂度：O(n * len(s))
- 空间复杂度：O(n * len(s))

## 关键点总结

1. JavaScript 中通过 `prototype` 扩展内置类型
2. `this` 在普通方法中指向调用者（字符串对象）
3. Python 直接用 `*` 运算符重复字符串

## 易错点

1. 箭头函数中 `this` 不正确，需用普通函数
2. `repeat(0)` 返回空字符串
