## 题目描述

本题原为 JavaScript 异步题目。给定异步函数 `fn` 和时间限制 `t` 毫秒，返回一个有时间限制的版本：若函数在 `t` 毫秒内完成，返回结果；否则 reject 并返回 `"Time Limit Exceeded"`。

**示例：**
```
fn = () => new Promise(res => setTimeout(res, 100))
t = 50
结果：reject "Time Limit Exceeded"（100ms > 50ms）
```

## 解题思路

使用 `asyncio.wait_for` 实现超时控制：若协程在规定时间内未完成，抛出 `asyncio.TimeoutError`。

## Python 代码实现

### 方法一：asyncio.wait_for（推荐）

```python
import asyncio
from typing import Callable, Any

def time_limit(fn: Callable, t: int) -> Callable:
    """
    返回有时间限制的函数版本
    fn: 异步函数
    t: 时间限制（毫秒）
    """
    async def limited(*args) -> Any:
        try:
            return await asyncio.wait_for(fn(*args), timeout=t / 1000)
        except asyncio.TimeoutError:
            raise TimeoutError("Time Limit Exceeded")

    return limited


# 使用示例
async def slow_fn():
    await asyncio.sleep(0.1)  # 100ms
    return "done"

limited_fn = time_limit(slow_fn, 50)  # 50ms 限制

async def main():
    try:
        result = await limited_fn()
        print(result)
    except TimeoutError as e:
        print(str(e))  # "Time Limit Exceeded"

asyncio.run(main())
```

### 方法二：手动实现竞争

```python
import asyncio
from typing import Callable, Any

def time_limit(fn: Callable, t: int) -> Callable:
    async def limited(*args) -> Any:
        async def timeout_task():
            await asyncio.sleep(t / 1000)
            raise TimeoutError("Time Limit Exceeded")

        # 竞争：fn 和超时任务，哪个先完成
        task_fn = asyncio.create_task(fn(*args))
        task_timeout = asyncio.create_task(timeout_task())

        done, pending = await asyncio.wait(
            [task_fn, task_timeout],
            return_when=asyncio.FIRST_COMPLETED
        )

        # 取消未完成的任务
        for task in pending:
            task.cancel()

        # 返回第一个完成的结果（或抛出异常）
        return await next(iter(done))

    return limited
```

### JavaScript 参考实现

```javascript
var timeLimit = function(fn, t) {
    return async function(...args) {
        return Promise.race([
            fn(...args),
            new Promise((_, reject) => setTimeout(() => reject("Time Limit Exceeded"), t))
        ]);
    };
};
```

## 复杂度分析

- 时间复杂度：O(1)（包装逻辑）
- 空间复杂度：O(1)

## 关键点总结

1. `asyncio.wait_for` 是实现超时的最简洁方式
2. 超时后需要取消未完成的任务，避免资源泄漏
3. `Promise.race`（JS）对应 Python 的 `asyncio.wait + FIRST_COMPLETED`

## 易错点

1. 时间单位转换：毫秒 -> 秒（除以 1000）
2. 超时后要取消正在运行的任务
3. `asyncio.wait_for` 会自动取消超时任务
