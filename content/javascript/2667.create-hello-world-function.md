## 题目描述

本题原为 JavaScript 入门题目。实现一个函数 `createHelloWorld`，返回另一个函数，无论传入什么参数，被返回的函数都返回字符串 `"Hello World"`。

**示例：**
```
f = createHelloWorld()
f()        -> "Hello World"
f({}, null) -> "Hello World"
```

## 解题思路

返回一个忽略所有参数、始终返回固定字符串的函数。

## Python 代码实现

### 方法一：闭包（推荐）

```python
from typing import Callable, Any

def create_hello_world() -> Callable:
    """
    返回一个始终输出 'Hello World' 的函数
    """
    def hello(*args) -> str:
        return "Hello World"  # 忽略所有参数
    return hello


# 使用示例
f = create_hello_world()
print(f())           # "Hello World"
print(f(1, 2, 3))   # "Hello World"
print(f({}, None))  # "Hello World"
```

### 方法二：lambda

```python
from typing import Callable

def create_hello_world() -> Callable:
    return lambda *args: "Hello World"
```

### JavaScript 参考实现

```javascript
var createHelloWorld = function() {
    return function(...args) {
        return "Hello World";
    };
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 返回的函数忽略所有参数（使用 `*args` 接收）
2. 始终返回固定字符串
3. 这是一个最简单的闭包示例

## 易错点

1. 函数需要接受任意参数（不能不接受参数），但忽略它们
