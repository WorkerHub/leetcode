## 题目描述

给你一个 JSON 字符串 `str`，不使用内置的 `JSON.parse` 方法，将其解析并返回对应的 JavaScript 值。

支持的类型：`null`、`boolean`、`number`、`string`、`array`、`object`。

**示例 1：**
```
输入：str = '{"a":1,"b":{"c":2}}'
输出：{a:1, b:{c:2}}
```

**示例 2：**
```
输入：str = 'true'
输出：true
```

## 解题思路

手写递归下降解析器：
1. 跳过空白字符
2. 根据当前字符判断类型：
   - `{`：解析对象
   - `[`：解析数组
   - `"`：解析字符串
   - `t/f`：解析布尔值
   - `n`：解析 null
   - 数字/负号：解析数字

## Python 代码实现

### 方法一：递归下降解析（推荐）

```javascript
/**
 * @param {string} str
 * @return {null|boolean|number|string|Array|Object}
 */
var jsonParse = function(str) {
    let pos = 0;

    function parseValue() {
        skipWhitespace();
        const ch = str[pos];
        if (ch === '{') return parseObject();
        if (ch === '[') return parseArray();
        if (ch === '"') return parseString();
        if (ch === 't' || ch === 'f') return parseBoolean();
        if (ch === 'n') return parseNull();
        return parseNumber();
    }

    function skipWhitespace() {
        while (pos < str.length && ' \t\n\r'.includes(str[pos])) pos++;
    }

    function parseString() {
        pos++;  // 跳过开头的 "
        let result = '';
        while (str[pos] !== '"') {
            if (str[pos] === '\\') {
                pos++;
                const escapes = {'"':'"','\\':'\\','/':'/','n':'\n','r':'\r','t':'\t','b':'\b','f':'\f'};
                result += escapes[str[pos]] || str[pos];
            } else {
                result += str[pos];
            }
            pos++;
        }
        pos++;  // 跳过结尾的 "
        return result;
    }

    function parseNumber() {
        let start = pos;
        if (str[pos] === '-') pos++;
        while (pos < str.length && '0123456789.eE+-'.includes(str[pos])) pos++;
        return Number(str.slice(start, pos));
    }

    function parseBoolean() {
        if (str.startsWith('true', pos)) { pos += 4; return true; }
        pos += 5; return false;
    }

    function parseNull() {
        pos += 4; return null;
    }

    function parseArray() {
        pos++;  // 跳过 [
        const arr = [];
        skipWhitespace();
        while (str[pos] !== ']') {
            arr.push(parseValue());
            skipWhitespace();
            if (str[pos] === ',') pos++;
            skipWhitespace();
        }
        pos++;  // 跳过 ]
        return arr;
    }

    function parseObject() {
        pos++;  // 跳过 {
        const obj = {};
        skipWhitespace();
        while (str[pos] !== '}') {
            const key = parseString();
            skipWhitespace();
            pos++;  // 跳过 :
            skipWhitespace();
            obj[key] = parseValue();
            skipWhitespace();
            if (str[pos] === ',') pos++;
            skipWhitespace();
        }
        pos++;  // 跳过 }
        return obj;
    }

    return parseValue();
};
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(d)，d 为 JSON 最大嵌套深度

## 关键点总结

1. 递归下降：根据当前字符决定解析哪种类型
2. `pos` 指针全局共享，每个解析函数消耗对应的字符
3. 处理转义字符

## 易错点

1. 解析数字时注意科学计数法（`e/E`）
2. 字符串中的转义序列需要正确处理
