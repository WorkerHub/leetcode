## 题目描述

给你一个数组 `arr` 和一个函数 `fn`，返回一个 **排序后** 的数组 `sortedArr`。

你可以假设 `fn` 只返回数字，并且每个元素都会调用一次 `fn`。`sortedArr` 必须按 `fn(sortedArr[i])` 的值升序排列。

**示例 1：**
```
输入：arr = [5,4,1,2,3], fn = (x) => x
输出：[1,2,3,4,5]
```

**示例 2：**
```
输入：arr = [{"x":1},{"x":0},{"x":-1}], fn = (d) => d.x
输出：[{"x":-1},{"x":0},{"x":1}]
```

**示例 3：**
```
输入：arr = [[3,4],[5,2],[10,1]], fn = (x) => x[1]
输出：[[10,1],[5,2],[3,4]]
```

## 解题思路

使用 JavaScript 的 `Array.sort` 方法，自定义比较函数，以 `fn(a) - fn(b)` 作为排序依据。

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Array} arr
 * @param {Function} fn
 * @return {Array}
 */
var sortBy = function(arr, fn) {
    // 按 fn 的返回值升序排列
    return arr.sort((a, b) => fn(a) - fn(b));
};
```

### 方法二：Python 实现

```python
from typing import List, Callable, Any

def sortBy(arr: List[Any], fn: Callable) -> List[Any]:
    # 使用 key 参数指定排序依据
    return sorted(arr, key=fn)
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)（排序中间空间）

## 关键点总结

1. JavaScript `sort` 的比较函数返回负数、0、正数分别表示 a 在 b 前、相等、a 在 b 后
2. `fn(a) - fn(b)` 实现升序排列
3. Python 中 `sorted` 的 `key` 参数直接接受映射函数

## 易错点

1. 注意 JavaScript 默认排序是字典序，必须提供数值比较函数
2. `sort` 会原地修改数组，`sorted` 返回新数组
