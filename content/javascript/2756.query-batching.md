## 题目描述

给你一个异步函数 `queryMultiple(keys)`，它接受键数组并返回值数组（一一对应）。

实现 `QueryBatcher`，它接受 `queryMultiple` 和延迟时间 `t`，使得在 `t` ms 时间窗口内的所有查询被批量处理（合并调用一次 `queryMultiple`）。

## 解题思路

典型的批量请求合并（batch processing）模式：
1. 维护一个待处理队列和 Promise 的 resolve/reject 函数
2. 第一个查询触发定时器，`t` ms 后将队列中所有查询合并调用 `queryMultiple`
3. 返回各 Promise

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Function} queryMultiple
 * @param {number} t
 */
class QueryBatcher {
    constructor(queryMultiple, t) {
        this.queryMultiple = queryMultiple;
        this.t = t;
        this.queue = [];  // [{key, resolve, reject}]
        this.timer = null;
    }

    async queryOne(key) {
        return new Promise((resolve, reject) => {
            this.queue.push({ key, resolve, reject });
            // 第一个请求触发定时器
            if (!this.timer) {
                this.timer = setTimeout(() => this._flush(), this.t);
            }
        });
    }

    async _flush() {
        this.timer = null;
        const batch = this.queue.splice(0);  // 取出所有待处理请求
        const keys = batch.map(item => item.key);
        try {
            const values = await this.queryMultiple(keys);
            batch.forEach((item, i) => item.resolve(values[i]));
        } catch (err) {
            batch.forEach(item => item.reject(err));
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为批次内查询数
- 空间复杂度：O(n)

## 关键点总结

1. 用定时器实现时间窗口批量合并
2. 每个查询返回独立 Promise，在批量结果回来后 resolve
3. 错误处理：批量调用失败时，批次内所有 Promise 都 reject

## 易错点

1. `splice(0)` 清空队列，防止新到来的请求混入本次批次
2. 批次完成后重置 `timer` 为 null，允许下一批次触发
