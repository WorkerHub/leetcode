## 题目描述

给你一个函数 `fn` 和一个参数数组 `args`，其中一些参数可能是占位符 `_`（空字符串 `""`）。

返回一个偏函数，调用时传入参数按顺序填入占位符，剩余参数追加到末尾。

**示例：**
```javascript
const fn = (...args) => args;
const g = partial(fn, [2, _, 4]);
g(1, 3) // [2, 1, 4, 3]（_ 被 1 填入，4 后面跟 3）
```

## 解题思路

返回的函数收到参数后：
1. 遍历 `args`，遇到占位符 `_` 则用新参数替换
2. 新参数用完后，剩余原参数保留
3. 新参数中未用于填充的部分追加到末尾

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @return {Function}
 */
var partial = function(fn, args) {
    return function(...newArgs) {
        const filledArgs = [...args];
        let ni = 0;  // newArgs 的指针
        // 用 newArgs 填充占位符
        for (let i = 0; i < filledArgs.length; i++) {
            if (filledArgs[i] === _ && ni < newArgs.length) {
                filledArgs[i] = newArgs[ni++];
            }
        }
        // 剩余 newArgs 追加到末尾
        while (ni < newArgs.length) {
            filledArgs.push(newArgs[ni++]);
        }
        return fn(...filledArgs);
    };
};
```

### 方法二：Python 偏函数实现

```python
from typing import Any, Callable, List

PLACEHOLDER = "_"

def partial(fn: Callable, args: List[Any]) -> Callable:
    def wrapper(*new_args):
        filled = list(args)
        ni = 0
        for i in range(len(filled)):
            if filled[i] == PLACEHOLDER and ni < len(new_args):
                filled[i] = new_args[ni]
                ni += 1
        filled.extend(new_args[ni:])
        return fn(*filled)
    return wrapper
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为 args 长度，m 为新参数长度
- 空间复杂度：O(n + m)

## 关键点总结

1. 遍历 args，占位符处按顺序填入新参数
2. 新参数剩余部分追加到末尾
3. 闭包保存 fn 和 args

## 易错点

1. 占位符用完新参数后，剩余 args 中的占位符保持不变（题目保证足够）
2. 追加剩余新参数的顺序
