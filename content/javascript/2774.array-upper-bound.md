## 题目描述

给数组 `Array` 增加 `upperBound` 方法，该方法接受一个 `target` 值，返回数组中 **最后一个** 小于或等于 `target` 的元素的下标。如果不存在，返回 -1。

可以假设数组已排好序。

**示例 1：**
```javascript
[3,4,5].upperBound(5); // 2
```

**示例 2：**
```javascript
[1,4,5].upperBound(2); // 0 (1 <= 2)
```

**示例 3：**
```javascript
[1,2,3].upperBound(4); // 2 (3 <= 4)
```

## 解题思路

二分查找：找最后一个 <= target 的元素位置。`upperBound` 实际上是找"上界 - 1"，即最后一个不超过 target 的位置。

## Python 代码实现

### 方法一：JavaScript 二分查找（推荐）

```javascript
/**
 * @param {number} target
 * @return {number}
 */
Array.prototype.upperBound = function(target) {
    let lo = 0, hi = this.length - 1;
    let ans = -1;
    while (lo <= hi) {
        const mid = (lo + hi) >> 1;
        if (this[mid] <= target) {
            ans = mid;   // 记录满足条件的位置
            lo = mid + 1;  // 尝试更靠右的位置
        } else {
            hi = mid - 1;
        }
    }
    return ans;
};
```

### 方法二：Python 实现

```python
import bisect

def upperBound(arr: list, target: int) -> int:
    # bisect_right 返回第一个大于 target 的位置
    pos = bisect.bisect_right(arr, target)
    return pos - 1  # 最后一个 <= target 的位置（若 pos==0 则为 -1）
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 找最后一个 <= target 的位置
2. 二分：满足条件时记录 ans 并右移，否则左移
3. Python 中 `bisect_right(arr, target) - 1` 即为答案

## 易错点

1. 与 `bisect_right` 的关系：`bisect_right` 的结果减 1 即为答案（但要处理 -1 的情况）
2. 若所有元素 > target，返回 -1
