## 题目描述

本题原为 JavaScript 题目。为 Array 原型添加 `groupBy(fn)` 方法：给定分类函数 `fn`，返回一个对象，其中键为 `fn` 的返回值，值为对应元素的数组。

**示例：**
```
输入：array = [{"id":"1"},{"id":"1"},{"id":"2"}], fn = item => item.id
输出：{"1": [{"id": "1"},{"id": "1"}], "2": [{"id": "2"}]}
```

## 解题思路

遍历数组，对每个元素调用 `fn` 获取分组键，将元素放入对应分组。Python 中 `defaultdict` 和 `itertools.groupby` 提供了类似功能。

## Python 代码实现

### 方法一：defaultdict 实现（推荐）

```python
from typing import Callable, List, Any, Dict
from collections import defaultdict

def group_by(arr: List[Any], fn: Callable) -> Dict[str, List[Any]]:
    """
    按 fn 的返回值对数组分组
    """
    groups = defaultdict(list)
    for item in arr:
        key = fn(item)
        groups[key].append(item)
    return dict(groups)


# 使用示例
data = [{"id": "1"}, {"id": "1"}, {"id": "2"}]
result = group_by(data, lambda x: x["id"])
# {"1": [{"id": "1"}, {"id": "1"}], "2": [{"id": "2"}]}
print(result)

# 按奇偶分组
nums = [1, 2, 3, 4, 5]
result2 = group_by(nums, lambda x: "even" if x % 2 == 0 else "odd")
print(result2)  # {"odd": [1, 3, 5], "even": [2, 4]}
```

### 方法二：使用 itertools.groupby（需要预排序）

```python
import itertools
from typing import Callable, List, Any, Dict

def group_by_sorted(arr: List[Any], fn: Callable) -> Dict[str, List[Any]]:
    """
    使用 itertools.groupby（需要先按键排序）
    注意：与题目要求不同，此方法要求相同键的元素相邻
    """
    result = {}
    sorted_arr = sorted(arr, key=fn)
    for key, group in itertools.groupby(sorted_arr, key=fn):
        result[key] = list(group)
    return result
```

### JavaScript 参考实现

```javascript
Array.prototype.groupBy = function(fn) {
    return this.reduce((groups, item) => {
        const key = fn(item);
        (groups[key] = groups[key] || []).push(item);
        return groups;
    }, {});
};
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 用字典将元素按键分组
2. `defaultdict(list)` 自动处理键不存在的情况
3. 保持元素的原始顺序

## 易错点

1. `itertools.groupby` 需要预排序，而本题不需要
2. 分组键可以是任意类型（字符串、数字等）
