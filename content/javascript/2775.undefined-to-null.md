## 题目描述

给你一个深层嵌套的对象或数组 `obj`，将其中所有 `undefined` 值替换为 `null`，返回替换后的结果。

`undefined` 可能出现在对象的值或数组的元素中。

**示例 1：**
```
输入：obj = {"a": undefined, "b": 3}
输出：{"a": null, "b": 3}
```

**示例 2：**
```
输入：obj = [undefined, undefined]
输出：[null, null]
```

## 解题思路

递归遍历：
- 若当前值为 `undefined`，返回 `null`
- 若是数组，递归处理每个元素
- 若是普通对象，递归处理每个键值对
- 否则返回原值

## Python 代码实现

### 方法一：JavaScript 递归（推荐）

```javascript
/**
 * @param {Object|Array} obj
 * @return {Object|Array}
 */
var undefinedToNull = function(obj) {
    if (obj === undefined) return null;

    if (Array.isArray(obj)) {
        return obj.map(undefinedToNull);
    }

    if (typeof obj === 'object' && obj !== null) {
        const result = {};
        for (const key of Object.keys(obj)) {
            result[key] = undefinedToNull(obj[key]);
        }
        return result;
    }

    return obj;
};
```

### 方法二：Python 实现

```python
def undefinedToNull(obj):
    """Python 中没有 undefined，None 对应 null，此处模拟"""
    if obj is None:
        return None
    if isinstance(obj, list):
        return [undefinedToNull(x) for x in obj]
    if isinstance(obj, dict):
        return {k: undefinedToNull(v) for k, v in obj.items()}
    return obj
```

## 复杂度分析

- 时间复杂度：O(n)，n 为所有节点数
- 空间复杂度：O(d)，d 为最大嵌套深度

## 关键点总结

1. `undefined` 在 JavaScript 中是未赋值的特殊值，不同于 `null`
2. 使用 `=== undefined` 精确判断（不用 `== undefined`，后者会匹配 null）
3. 递归处理嵌套结构

## 易错点

1. `null` 不需要处理，只处理 `undefined`
2. 注意 `null` 的 `typeof` 是 `'object'`，需先检查 `=== null`
