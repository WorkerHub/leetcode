## 题目描述

给你一个对象 `obj`，返回其**反转**后的对象，即将 key 和 value 互换。

保证 `obj` 的所有 value 都是唯一的，类型为字符串或数字。

**示例 1：**
```
输入：obj = {"a": 1, "b": 2, "c": 3}
输出：{1: "a", 2: "b", 3: "c"}
```

**示例 2：**
```
输入：obj = {"1": "a", "2": "b", "3": "c"}
输出：{"a": "1", "b": "2", "c": "3"}
```

**示例 3：**
```
输入：obj = {1: {"c": 10}}
输出：错误，value 不是原始类型
```

## 解题思路

本题是 JavaScript 题，考察对象操作。

核心：遍历对象的所有键值对，交换 key 和 value 构建新对象。

在 JavaScript 中使用 `Object.entries()` 获取键值对，再用 `Object.fromEntries()` 重建对象。

Python 中等效为字典推导式：`{v: k for k, v in d.items()}`

## Python 代码实现

### 方法一：Python 字典反转（理解用）

```python
def invert_object(obj: dict) -> dict:
    """反转字典的键和值"""
    return {str(v): str(k) for k, v in obj.items()}

# 示例
print(invert_object({"a": 1, "b": 2, "c": 3}))  # {'1': 'a', '2': 'b', '3': 'c'}
```

### 方法二：JavaScript 实现（LeetCode 原题解）

```javascript
/**
 * @param {Object} obj
 * @return {Object}
 */
var invertObject = function(obj) {
    // 方法一：使用 Object.entries 和 reduce
    return Object.entries(obj).reduce((acc, [key, val]) => {
        acc[val] = key;  // 交换键值
        return acc;
    }, {});
};

// 方法二：使用 Object.fromEntries（更简洁）
var invertObject = function(obj) {
    return Object.fromEntries(
        Object.entries(obj).map(([key, val]) => [val, key])
    );
};

// 方法三：for...in 循环
var invertObject = function(obj) {
    const result = {};
    for (const key in obj) {
        result[obj[key]] = key;  // value 变 key，key 变 value
    }
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(n)，遍历对象所有键值对
- 空间复杂度：O(n)，存储反转后的对象

## 关键点总结

1. `Object.entries(obj)` 返回 `[[key1, val1], [key2, val2], ...]`
2. `Object.fromEntries(entries)` 从键值对数组构建对象
3. 题目保证 value 都是唯一的，所以反转后不会有重复 key
4. Python 中用字典推导式 `{v: k for k, v in d.items()}` 即可

## 易错点

1. JavaScript 中 key 都是字符串，value 可能是数字，反转后注意类型
2. `for...in` 也会遍历原型链属性，严格来说应加 `hasOwnProperty` 检查（但本题不需要）
3. 保证 value 唯一时才能安全反转，否则会有 key 冲突
