## 题目描述

增强所有函数，使其具有 `bindPolyfill` 方法，该方法接受 `context` 对象，返回一个新函数，调用时 `this` 绑定到 `context`。

**示例：**
```javascript
function f(multiplier) { return this.x * multiplier; }
const g = f.bindPolyfill({x: 2});
g(3); // 返回 6
```

## 解题思路

实现 `Function.prototype.bind` 的 polyfill：返回一个新函数，调用时使用 `apply` 或 `call` 将 `this` 设置为传入的 `context`。

## Python 代码实现

### 方法一：使用 apply 实现（推荐）

```javascript
/**
 * @param {Object} context
 * @return {Function}
 */
Function.prototype.bindPolyfill = function(context) {
    const fn = this;  // 保存原始函数
    return function(...args) {
        // 使用 apply 将 this 绑定到 context
        return fn.apply(context, args);
    };
};
```

### 方法二：使用 call

```javascript
Function.prototype.bindPolyfill = function(context) {
    const fn = this;
    return function(...args) {
        return fn.call(context, ...args);
    };
};
```

## 复杂度分析

- 时间复杂度：O(1)（返回函数，不执行）
- 空间复杂度：O(1)

## 关键点总结

1. `apply(context, args)` 和 `call(context, ...args)` 都可以改变 `this` 的指向
2. 闭包保存原始函数 `fn` 和 `context`
3. 返回的新函数转发所有参数

## 易错点

1. 不能用箭头函数返回（箭头函数没有自己的 `this`，但在这里不影响，因为我们用 apply）
2. `this` 指向原始函数，需要在闭包外先保存
