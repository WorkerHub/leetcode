## 题目描述

本题原为 JavaScript 设计题目。实现 `ArrayWrapper` 类，对整数数组包装：
- 当两个实例相加时，返回两个数组中所有元素的总和
- 转为字符串时，返回逗号分隔的元素（外加方括号）

**示例：**
```
a = new ArrayWrapper([1,2])
b = new ArrayWrapper([3,4])
a + b -> 10
String(a) -> "[1,2]"
```

## Python 代码实现

### 方法一：实现 `__add__` 和 `__str__`

```python
from typing import List

class ArrayWrapper:
    def __init__(self, nums: List[int]):
        self.nums = nums
        self._sum = sum(nums)  # 缓存总和

    def __add__(self, other: 'ArrayWrapper') -> int:
        """两个 ArrayWrapper 相加，返回所有元素的总和"""
        return self._sum + other._sum

    def __str__(self) -> str:
        """转为字符串：[元素1,元素2,...]"""
        return '[' + ','.join(map(str, self.nums)) + ']'

    def __repr__(self) -> str:
        return self.__str__()


# 使用示例
a = ArrayWrapper([1, 2])
b = ArrayWrapper([3, 4])
print(a + b)   # 10
print(str(a))  # [1,2]
```

### JavaScript 参考实现

```javascript
class ArrayWrapper {
    constructor(nums) {
        this.nums = nums;
    }
    valueOf() {
        return this.nums.reduce((a, b) => a + b, 0);
    }
    toString() {
        return '[' + this.nums.join(',') + ']';
    }
}
```

## 复杂度分析

- 时间复杂度：初始化 O(n)，`__add__` O(1)，`__str__` O(n)
- 空间复杂度：O(n)

## 关键点总结

1. Python 中 `__add__` 对应 `+` 运算符
2. `__str__` 对应 `String()` 转换
3. 预先缓存总和可以加速加法操作

## 易错点

1. 加法应返回数字而非 `ArrayWrapper`
2. 字符串格式：`[1,2]`（无空格）
