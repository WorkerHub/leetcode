## 题目描述

本题原为 JavaScript 题目。实现类似 `Array.prototype.filter` 的功能：给定整数数组 `arr` 和过滤函数 `fn(element, index)`，返回只包含 `fn` 返回值为真的元素的新数组。

**示例 1：**
```
输入：arr = [0,10,20,30], fn = (n, i) => n > 10
输出：[20,30]
```

**示例 2：**
```
输入：arr = [1,2,3], fn = (n, i) => n * i > 6
输出：[3]
```

**示例 3：**
```
输入：arr = [-2,-1,0,1,2], fn = (n) => n + 1
输出：[-1,1,2]（注意 -1+1=0 为假，0+1=1 为真）
```

## 解题思路

遍历数组，对每个元素（和下标）调用过滤函数，保留返回值为真的元素。

Python 中内置的 `filter` 函数或列表推导式提供了类似功能。

## Python 代码实现

### 方法一：手动实现

```python
from typing import Callable, List

def filter_array(arr: List[int], fn: Callable[[int, int], bool]) -> List[int]:
    """
    返回满足过滤条件的元素数组
    fn(element, index) -> bool
    """
    result = []
    for i, x in enumerate(arr):
        if fn(x, i):  # 过滤函数接受元素值和下标
            result.append(x)
    return result


# 使用示例
print(filter_array([0, 10, 20, 30], lambda n, i: n > 10))     # [20, 30]
print(filter_array([1, 2, 3], lambda n, i: n * i > 6))        # [3]
print(filter_array([-2, -1, 0, 1, 2], lambda n, i: n + 1))   # [-1, 1, 2]
```

### 方法二：列表推导式

```python
from typing import Callable, List

def filter_array(arr: List[int], fn: Callable) -> List[int]:
    """
    列表推导式实现
    """
    return [x for i, x in enumerate(arr) if fn(x, i)]
```

### 方法三：Python 内置 filter（不带索引）

```python
from typing import List, Callable

# Python 内置 filter 不传递索引
result = list(filter(lambda x: x > 10, [0, 10, 20, 30]))
# 若需要索引，用列表推导式
```

### JavaScript 参考实现

```javascript
var filter = function(arr, fn) {
    const result = [];
    for (let i = 0; i < arr.length; i++) {
        if (fn(arr[i], i)) result.push(arr[i]);
    }
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（最坏情况）

## 关键点总结

1. 过滤函数接受元素值和下标两个参数
2. 结果数组保持原始顺序
3. Python 的 `filter` 内置函数不传递索引，此题需要手动实现

## 易错点

1. 注意 `fn` 接受 `(element, index)` 两个参数，而非只有元素值
2. 过滤函数返回的是真假值，`0` 和空字符串等为假
