## 题目描述

本题原为 JavaScript 函数式编程题目。实现 `callPolyfill(fn, context, ...args)` 函数，使 `fn` 以 `context` 为 `this` 调用（相当于 `fn.call(context, ...args)`）。

**示例：**
```
fn = function() { return this.x * 2; }
context = {"x": 4}
callPolyfill(fn, context)  -> 8
```

## 解题思路

JavaScript 中函数的 `this` 上下文可以通过 `call/apply/bind` 改变。Python 中函数没有 `this` 概念，但可以通过将 `context` 作为第一个参数（或通过 `MethodType`）来模拟。

## Python 代码实现

### 方法一：使用 types.MethodType

```python
import types
from typing import Callable, Any

def call_with_context(fn: Callable, context: Any, *args) -> Any:
    """
    以 context 为 self 调用 fn（模拟 JavaScript 的 call）
    """
    # 将 fn 绑定到 context 对象
    bound_method = types.MethodType(fn, context)
    return bound_method(*args)


# 使用示例
class Context:
    def __init__(self, x):
        self.x = x

def double_x(self):
    return self.x * 2

ctx = Context(4)
print(call_with_context(double_x, ctx))  # 8
```

### 方法二：动态绑定到对象

```python
from typing import Callable, Any

def call_with_context(fn: Callable, context: dict, *args) -> Any:
    """
    将字典作为上下文，临时设置函数属性后调用
    """
    # 创建一个命名空间对象
    class Namespace:
        pass
    obj = Namespace()
    for k, v in context.items():
        setattr(obj, k, v)

    import types
    bound = types.MethodType(fn, obj)
    return bound(*args)
```

### JavaScript 参考实现

```javascript
Function.prototype.callPolyfill = function(context, ...args) {
    const sym = Symbol();
    context[sym] = this;
    const result = context[sym](...args);
    delete context[sym];
    return result;
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. JavaScript 的 `call/apply/bind` 改变 `this` 上下文
2. Python 用 `types.MethodType` 将函数绑定到对象
3. Python 不需要 `this`，通常通过类和 `self` 实现

## 易错点

1. Python 和 JavaScript 的对象模型不同
2. 注意 `MethodType` 需要函数第一个参数为 `self`
