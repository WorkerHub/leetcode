## 题目描述

编写一个方法，扩展 `Array.prototype`，实现 `Array.prototype.forEach` 的 polyfill（兼容实现），该方法不能使用原生的 `Array.prototype.forEach`。

**示例 1：**
```
输入：
arr = [1, 2, 3]
callback = (val, i, arr) => arr[i] = val * 2

输出：[2, 4, 6]
解释：callback 被调用三次，修改了数组的每个元素
```

**示例 2：**
```
输入：
arr = [1, 2, 3]
callback = (val, i, arr) => console.log(val, i)

输出：
1 0
2 1
3 2
```

**提示：**
- `-10^5 <= arr[i] <= 10^5`
- `0 <= arr.length <= 10^5`
- `callback` 是有效函数

## 解题思路

本题是 JavaScript 专属题，考察对 `Array.prototype.forEach` 的理解：
- `forEach` 遍历数组的每个元素
- 对每个元素调用回调函数 `callback(value, index, array)`
- 回调函数接收三个参数：当前值、当前索引、原数组
- 返回值为 `undefined`（即不需要 return）

核心思路：用普通 `for` 循环代替递归，依次调用 callback。

## Python 代码实现

### 方法一：Python 等效实现（理解用）

```python
from typing import List, Callable, Any

def array_forEach(arr: List[Any], callback: Callable) -> None:
    """模拟 JavaScript Array.prototype.forEach"""
    for i in range(len(arr)):
        callback(arr[i], i, arr)  # 调用回调：值、索引、原数组

# 使用示例
arr = [1, 2, 3]
array_forEach(arr, lambda val, i, a: a.__setitem__(i, val * 2))
print(arr)  # [2, 4, 6]
```

### 方法二：JavaScript 实现（LeetCode 原题解）

```javascript
/**
 * 为 Array.prototype 添加自定义 forEach 方法
 * @param {Function} callback - 回调函数，接收 (value, index, array)
 * @return {void}
 */
Array.prototype.forEach = function(callback) {
    // this 指向调用该方法的数组
    for (let i = 0; i < this.length; i++) {
        // 按照规范：只对存在的索引调用 callback
        if (i in this) {
            callback(this[i], i, this);  // 传入值、索引、原数组
        }
    }
    // forEach 返回 undefined，不需要 return
};

// 使用示例
const arr = [1, 2, 3];
arr.forEach((val, i) => {
    arr[i] = val * 2;
});
console.log(arr);  // [2, 4, 6]
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组每个元素一次
- 空间复杂度：O(1)，不使用额外空间

## 关键点总结

1. `forEach` 的回调接收三个参数：`(value, index, array)`
2. `this` 在方法内指向调用该方法的数组
3. `forEach` 的返回值是 `undefined`，不要加 `return`
4. 用 `i in this` 检查稀疏数组中的空洞（strict 规范）

## 易错点

1. 忘记传第三个参数 `array`（原数组）给回调
2. 对稀疏数组（如 `[1,,3]`）的处理：需要跳过未定义的索引
3. `forEach` 本身不返回任何值，不同于 `map` 会返回新数组
4. 不能在 callback 内部使用 `break`，这是 `forEach` 的设计限制
