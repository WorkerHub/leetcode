## 题目描述

给定一个函数 `fn`、一个参数数组 `args` 和一个超时时间 `t`（毫秒），返回一个取消函数 `cancelFn`。

在 `cancelTime` 毫秒后调用 `cancelFn`：
- 如果 `cancelTime < t`，则取消 `fn` 的执行（`fn` 不执行）
- 如果 `cancelTime >= t`，则 `fn` 会在 `t` 毫秒时正常执行

**示例 1：**
```
输入：fn = (x) => x * 5, args = [2], t = 20, cancelTime = 50
输出：[{"time": 20, "returned": 10}]
解释：在 50ms 调用取消，但 fn 已在 20ms 执行，返回 10
```

**示例 2：**
```
输入：fn = (x) => x * 5, args = [2], t = 20, cancelTime = 10
输出：[]
解释：在 10ms 调用取消，fn 尚未在 20ms 执行，被取消
```

## 解题思路

使用 `setTimeout` 延迟执行 `fn`，返回一个取消函数，取消函数内部调用 `clearTimeout` 清除定时器。

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @param {number} t
 * @return {Function}
 */
var cancellable = function(fn, args, t) {
    // 设置定时器，在 t 毫秒后执行 fn
    const timer = setTimeout(() => {
        fn(...args);
    }, t);

    // 返回取消函数
    return function cancelFn() {
        clearTimeout(timer);
    };
};
```

### 方法二：使用箭头函数简化

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @param {number} t
 * @return {Function}
 */
var cancellable = (fn, args, t) => {
    const timerId = setTimeout(() => fn(...args), t);
    return () => clearTimeout(timerId);
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `setTimeout` 返回一个定时器 ID，可通过 `clearTimeout` 取消
2. 闭包使取消函数可以访问 `timerId`
3. 展开运算符 `...args` 将数组作为参数传递

## 易错点

1. 必须保存 `setTimeout` 返回的 ID，才能取消
2. 取消函数只取消，不执行 `fn`
