## 题目描述

给你两个数组 `keysArr` 和 `valuesArr`，将它们对应合并为一个对象。若有重复键，保留第一次出现的值。

**示例 1：**
```javascript
createObject(["a","b","c"],[1,2,3])
// 返回 {"a":1,"b":2,"c":3}
```

**示例 2：**
```javascript
createObject(["a","b","b","a"],[1,2,3,4])
// 返回 {"a":1,"b":2}（重复键保留第一次）
```

## 解题思路

遍历两个数组，用对象/Map 存储键值对，遇到已有的键跳过。

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Array} keysArr
 * @param {Array} valuesArr
 * @return {Object}
 */
var createObject = function(keysArr, valuesArr) {
    const result = {};
    for (let i = 0; i < keysArr.length; i++) {
        const key = String(keysArr[i]);  // 键转为字符串
        if (!(key in result)) {
            result[key] = valuesArr[i];
        }
    }
    return result;
};
```

### 方法二：Python 实现

```python
from typing import List, Any

def createObject(keysArr: List[Any], valuesArr: List[Any]) -> dict:
    result = {}
    for k, v in zip(keysArr, valuesArr):
        key = str(k)
        if key not in result:
            result[key] = v
    return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 键需转为字符串（对象属性键都是字符串）
2. 重复键保留第一次出现的值

## 易错点

1. 键可能是非字符串类型，需转换
2. 先遇到的键优先，不要用后面的值覆盖
