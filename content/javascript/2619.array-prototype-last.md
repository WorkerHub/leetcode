## 题目描述

本题原为 JavaScript 题目。要求为 Array 原型添加一个 `last()` 方法，若数组非空则返回最后一个元素，否则返回 -1。

**示例 1：**
```
输入：nums = [null, {}, 3]
输出：3
```

**示例 2：**
```
输入：nums = []
输出：-1
```

**数据范围：**
- 0 <= arr.length <= 1000

## 解题思路

直接访问数组最后一个元素。若数组为空返回 -1，否则返回 `arr[-1]`。

Python 中可以用类的方式实现类似功能。

## Python 代码实现

### 方法一：函数封装

```python
from typing import Any, List

def array_last(arr: List[Any]) -> Any:
    """
    返回数组最后一个元素，若数组为空则返回 -1
    """
    return arr[-1] if arr else -1
```

### 方法二：使用类扩展（模拟 JS 原型方法）

```python
from typing import Any, List

class ArrayWithLast(list):
    """
    扩展列表，添加 last() 方法
    """
    def last(self) -> Any:
        # 若数组为空返回 -1，否则返回最后一个元素
        return self[-1] if self else -1


# 使用示例
arr = ArrayWithLast([1, 2, 3])
print(arr.last())  # 输出 3

empty = ArrayWithLast()
print(empty.last())  # 输出 -1
```

### JavaScript 参考实现

```javascript
// 为 Array 原型添加 last 方法
Array.prototype.last = function() {
    return this.length === 0 ? -1 : this[this.length - 1];
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 空数组返回 -1，而非 `undefined` 或 `null`
2. Python 中 `arr[-1]` 直接访问最后一个元素
3. 非空判断要在访问前进行

## 易错点

1. 空数组不能用 `arr[-1]` 访问，会抛出 `IndexError`
2. 需要先判断是否为空
