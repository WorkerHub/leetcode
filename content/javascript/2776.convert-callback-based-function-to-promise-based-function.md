## 题目描述

给你一个接受回调函数的函数 `fn`，将其转化为基于 Promise 的版本。

`fn` 的签名是 `fn(callbacks, ...args)`，其中 `callbacks` 是 `{resolve, reject}` 形式的对象。

返回一个新函数 `promisified`，调用 `promisified(...args)` 返回一个 Promise。

**示例：**
```javascript
const fn = (callbacks, value) => {
    if (value > 0) callbacks.resolve(value);
    else callbacks.reject('Error');
};
const p = promisify(fn);
p(1).then(v => console.log(v)); // 1
p(-1).catch(e => console.log(e)); // 'Error'
```

## 解题思路

返回一个新函数，该函数创建 Promise，将 Promise 的 resolve 和 reject 包装成 callbacks 对象，传给原函数 fn。

## Python 代码实现

### 方法一：Promise 包装（推荐）

```javascript
/**
 * @param {Function} fn
 * @return {Function}
 */
var promisify = function(fn) {
    return function(...args) {
        return new Promise((resolve, reject) => {
            // 将 resolve 和 reject 包装为 callbacks 对象
            const callbacks = { resolve, reject };
            fn(callbacks, ...args);
        });
    };
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. Promisify 模式：将回调式 API 转为 Promise 式
2. 创建 Promise，在内部调用原函数并传入 resolve/reject
3. rest 参数 `...args` 转发所有参数

## 易错点

1. callbacks 对象格式必须是 `{resolve, reject}`
2. `fn(callbacks, ...args)` 中 callbacks 是第一个参数
