## 题目描述

本题原为 JavaScript 设计题目。给定一个函数 `fn`，返回该函数的记忆化版本。记忆化函数会缓存相同参数的调用结果，再次调用时直接返回缓存结果而不重新执行函数。

**示例：**
```
fn = (a, b) => a + b
memoized(2, 3) -> 5（实际执行）
memoized(2, 3) -> 5（返回缓存）
memoized(1, 2) -> 3（实际执行）
```

## 解题思路

将参数转换为可哈希的键（字符串或元组），用字典缓存结果。Python 中可以直接使用 `functools.lru_cache` 或手动实现。

## Python 代码实现

### 方法一：手动实现记忆化

```python
from typing import Callable, Any

def memoize(fn: Callable) -> Callable:
    """
    返回函数的记忆化版本
    """
    cache = {}

    def memoized(*args) -> Any:
        # 使用参数元组作为缓存键
        key = args
        if key not in cache:
            cache[key] = fn(*args)  # 缓存结果
        return cache[key]

    return memoized


# 使用示例
def add(a, b):
    return a + b

memo_add = memoize(add)
print(memo_add(2, 3))  # 5（计算）
print(memo_add(2, 3))  # 5（缓存）
```

### 方法二：使用 functools.lru_cache（推荐，Python 内置）

```python
import functools
from typing import Callable

def memoize(fn: Callable) -> Callable:
    """
    使用内置 lru_cache 实现记忆化（无限缓存）
    """
    return functools.lru_cache(maxsize=None)(fn)


# 或直接使用装饰器
@functools.lru_cache(maxsize=None)
def fibonacci(n: int) -> int:
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)
```

### 方法三：支持关键字参数的版本

```python
from typing import Callable, Any
import json

def memoize_with_kwargs(fn: Callable) -> Callable:
    """
    支持关键字参数的记忆化（将参数序列化为 JSON 作为键）
    """
    cache = {}

    def memoized(*args, **kwargs) -> Any:
        # 将参数序列化为 JSON 字符串作为缓存键
        key = json.dumps((args, sorted(kwargs.items())), sort_keys=True)
        if key not in cache:
            cache[key] = fn(*args, **kwargs)
        return cache[key]

    return memoized
```

### JavaScript 参考实现

```javascript
function memoize(fn) {
    const cache = new Map();
    return function(...args) {
        const key = JSON.stringify(args);
        if (cache.has(key)) return cache.get(key);
        const result = fn(...args);
        cache.set(key, result);
        return result;
    };
}
```

## 复杂度分析

- 时间复杂度：第一次调用 O(fn 的复杂度)，后续相同参数调用 O(1)
- 空间复杂度：O(不同参数组合的数量)

## 关键点总结

1. 用字典缓存结果，参数元组为键
2. Python 内置 `functools.lru_cache` 是标准方案
3. 记忆化适用于纯函数（相同输入总是产生相同输出）

## 易错点

1. 参数必须可哈希才能作为字典键（列表等不可哈希）
2. 不适用于有副作用的函数
3. 需要注意缓存占用内存的问题
