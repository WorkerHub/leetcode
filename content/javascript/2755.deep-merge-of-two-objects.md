## 题目描述

给你两个值 `obj1` 和 `obj2`，实现一个函数 `deepMerge`，规则如下：

- 若两者都是对象：递归合并，`obj2` 的键覆盖 `obj1` 的同名键
- 否则：返回 `obj2`（非对象时 obj2 优先）

**示例 1：**
```javascript
deepMerge({a: 1, b: {c: 2}}, {b: {d: 3}})
// 返回 {a: 1, b: {c: 2, d: 3}}
```

**示例 2：**
```javascript
deepMerge({a: 1}, 2)
// 返回 2
```

## 解题思路

递归合并：只有当两者都是普通对象（非数组、非 null）时才合并，否则直接返回 `obj2`。

## Python 代码实现

### 方法一：递归（推荐）

```javascript
/**
 * @param {Object|Array|number|string} obj1
 * @param {Object|Array|number|string} obj2
 * @return {Object|Array|number|string}
 */
var deepMerge = function(obj1, obj2) {
    // 两者都是普通对象（排除 null 和数组）
    const isPlainObject = v =>
        typeof v === 'object' && v !== null && !Array.isArray(v);

    if (isPlainObject(obj1) && isPlainObject(obj2)) {
        const result = { ...obj1 };  // 复制 obj1
        for (const key of Object.keys(obj2)) {
            if (key in result) {
                // 递归合并
                result[key] = deepMerge(result[key], obj2[key]);
            } else {
                result[key] = obj2[key];
            }
        }
        return result;
    }
    // 否则 obj2 优先
    return obj2;
};
```

### 方法二：Python 实现（深度合并）

```python
def deepMerge(obj1, obj2):
    """深度合并两个对象，obj2 的键优先"""
    if isinstance(obj1, dict) and isinstance(obj2, dict):
        result = dict(obj1)
        for key, val in obj2.items():
            if key in result:
                result[key] = deepMerge(result[key], val)
            else:
                result[key] = val
        return result
    return obj2
```

## 复杂度分析

- 时间复杂度：O(n)，n 为两个对象所有键的总数
- 空间复杂度：O(d)，d 为最大嵌套深度

## 关键点总结

1. 只有两者都是普通对象时才递归合并
2. 数组不视为普通对象（`Array.isArray` 判断）
3. 合并时 obj2 的值覆盖 obj1 的同名值

## 易错点

1. 注意 `null` 的 `typeof` 是 `'object'`
2. 数组也是对象，需排除
