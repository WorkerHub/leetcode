## 题目描述

本题原为 JavaScript 生成器/异步题目。实现一个可取消的函数 `cancellable(generator)`：
- 返回 `[cancel, promise]`
- `cancel()` 被调用时，向生成器抛出 "Cancelled" 异常并 reject promise
- 若生成器正常完成，promise resolve 并返回返回值

## 解题思路

Python 中使用 `asyncio` 和可取消任务实现：`asyncio.Task` 支持 `cancel()` 方法，会向协程注入 `CancelledError`。

## Python 代码实现

### 方法一：asyncio.Task 实现

```python
import asyncio
from typing import Callable, Any, Tuple

def cancellable(generator_fn: Callable) -> Tuple[Callable, asyncio.Future]:
    """
    返回 (cancel_fn, future)
    cancel_fn() 取消执行
    future 在完成时 resolve
    """
    loop = asyncio.get_event_loop()
    future = loop.create_future()

    async def run():
        try:
            gen = generator_fn()
            result = None
            value_to_send = None
            while True:
                try:
                    value = gen.send(value_to_send)
                    # value 是 yield 产出的 Promise/awaitable
                    value_to_send = await asyncio.ensure_future(value)
                except StopIteration as e:
                    future.set_result(e.value)
                    break
        except asyncio.CancelledError:
            gen.throw(Exception("Cancelled"))
            future.set_exception(Exception("Cancelled"))
        except Exception as e:
            future.set_exception(e)

    task = loop.create_task(run())

    def cancel():
        task.cancel()

    return cancel, future
```

### 方法二：简化版 - 使用 asyncio 协程

```python
import asyncio
from typing import Any

async def run_cancellable(coro) -> Any:
    """
    运行可取消的协程
    支持通过 task.cancel() 取消
    """
    try:
        return await coro
    except asyncio.CancelledError:
        raise Exception("Cancelled")


# 使用示例
async def main():
    async def my_coro():
        await asyncio.sleep(1)
        return "done"

    task = asyncio.create_task(run_cancellable(my_coro()))

    # 0.5秒后取消
    await asyncio.sleep(0.5)
    task.cancel()

    try:
        result = await task
    except Exception as e:
        print(str(e))  # "Cancelled"

asyncio.run(main())
```

### JavaScript 参考实现

```javascript
function cancellable(generator) {
    let cancelled = false;
    const promise = new Promise((resolve, reject) => {
        function process(value) {
            const { value: result, done } = generator.next(value);
            if (cancelled) return;
            if (done) { resolve(result); return; }
            Promise.resolve(result).then(process, err => {
                if (!cancelled) generator.throw(err);
            });
        }
        process(undefined);
    });
    function cancel() {
        cancelled = true;
        generator.throw("Cancelled");
    }
    return [cancel, promise];
}
```

## 复杂度分析

- 时间复杂度：O(1)（包装逻辑）
- 空间复杂度：O(1)

## 关键点总结

1. Python 的 `asyncio.Task.cancel()` 向协程注入 `CancelledError`
2. 生成器的 `throw()` 方法可以向生成器注入异常
3. 可取消函数是异步编程中的重要模式

## 易错点

1. 取消后需要清理资源，避免泄漏
2. 异步取消是协作式的，协程需要有 await 点才能响应取消
3. `CancelledError` 应向上传播，而非被吞掉
