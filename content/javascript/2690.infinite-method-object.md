## 题目描述

本题原为 JavaScript 设计题目。创建一个对象，使得访问任意方法名时都返回包含该方法名的字符串。

**示例：**
```
obj = createInfiniteObject()
obj.abc123()     -> "abc123"
obj["def.456"]() -> "def.456"
```

## 解题思路

JavaScript 使用 Proxy 拦截属性访问。Python 中可以使用 `__getattr__` 魔法方法实现相似功能。

## Python 代码实现

### 方法一：`__getattr__` 实现

```python
class InfiniteObject:
    """
    访问任意属性时返回一个返回属性名的函数
    """
    def __getattr__(self, name: str):
        # 返回一个函数，调用时返回属性名
        return lambda: name


# 使用示例
obj = InfiniteObject()
print(obj.abc123())       # "abc123"
print(obj.hello_world())  # "hello_world"
```

### 方法二：使用字典访问

```python
class InfiniteObject:
    def __getitem__(self, name: str):
        """支持 obj["key"]() 方式"""
        return lambda: name

    def __getattr__(self, name: str):
        """支持 obj.attr() 方式"""
        return lambda: name


def create_infinite_object():
    return InfiniteObject()
```

### JavaScript 参考实现

```javascript
var createInfiniteObject = function() {
    return new Proxy({}, {
        get: (target, prop) => () => prop
    });
};
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `__getattr__` 在属性不存在时被调用（与 `__getattribute__` 不同）
2. 返回 lambda 函数，调用时返回属性名
3. JavaScript 的 Proxy 对应 Python 的 `__getattr__`

## 易错点

1. `__getattr__` 只在常规属性查找失败时调用
2. 注意不要和 `__getattribute__` 混淆（后者拦截所有属性访问）
