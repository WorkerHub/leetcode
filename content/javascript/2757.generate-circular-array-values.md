## 题目描述

给你一个循环数组 `arr` 和一个起始下标 `startIndex`，实现一个生成器函数 `circularArrayGenerator`，每次调用 `next(jump)` 时，产出当前下标的值，并将下标移动 `jump` 步（支持正负数，循环）。

**示例：**
```javascript
const gen = circularArrayGenerator([1,2,3,4,5], 0);
gen.next(1).value // 1（下标移到1）
gen.next(2).value // 2（下标移到3）
gen.next(-1).value // 4（下标移到2）
```

## 解题思路

JavaScript 生成器函数使用 `yield` 暂停并返回值，同时通过 `yield` 的返回值接收下一次 `next(jump)` 传入的跳跃步数。

## Python 代码实现

### 方法一：JavaScript 生成器（推荐）

```javascript
/**
 * @param {Array} arr
 * @param {number} startIndex
 * @return {Generator}
 */
function* circularArrayGenerator(arr, startIndex) {
    let idx = startIndex;
    const n = arr.length;

    while (true) {
        // yield 当前值，并接收 next(jump) 传入的 jump 值
        const jump = yield arr[idx];
        // 移动下标，取模保持循环（注意负数取模）
        idx = ((idx + jump) % n + n) % n;
    }
}
```

### 方法二：Python 生成器（供参考）

```python
from typing import Generator

def circularArrayGenerator(arr: list, startIndex: int) -> Generator:
    n = len(arr)
    idx = startIndex
    while True:
        jump = yield arr[idx]
        if jump is not None:
            idx = (idx + jump) % n
```

## 复杂度分析

- 时间复杂度：O(1) 每次 next
- 空间复杂度：O(1)

## 关键点总结

1. `yield` 既返回值（产出），也通过 `next(value)` 接收值
2. 负数取模需要 `((idx + jump) % n + n) % n`
3. Python `generator.send(value)` 对应 JavaScript `gen.next(value)`

## 易错点

1. JavaScript 中 `yield` 的返回值是 `next()` 传入的参数
2. 取模时需要处理负数情况
