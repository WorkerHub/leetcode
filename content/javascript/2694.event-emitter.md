## 题目描述

本题原为 JavaScript 设计题目。实现 `EventEmitter` 类，支持以下方法：
- `subscribe(eventName, callback)`：订阅事件，返回包含 `unsubscribe()` 方法的对象
- `emit(eventName, args)`：触发事件，调用所有订阅该事件的回调函数，返回所有回调的返回值数组

## Python 代码实现

### 方法一：字典 + 列表

```python
from typing import Callable, List, Any
from collections import defaultdict

class EventEmitter:
    def __init__(self):
        self.listeners = defaultdict(list)  # eventName -> [callback, ...]

    def subscribe(self, event_name: str, callback: Callable) -> object:
        """
        订阅事件，返回包含 unsubscribe 方法的对象
        """
        self.listeners[event_name].append(callback)

        class Subscription:
            def __init__(self, emitter, name, cb):
                self.emitter = emitter
                self.name = name
                self.cb = cb
                self.active = True

            def unsubscribe(self):
                if self.active:
                    self.emitter.listeners[self.name].remove(self.cb)
                    self.active = False

        return Subscription(self, event_name, callback)

    def emit(self, event_name: str, args: List[Any] = None) -> List[Any]:
        """
        触发事件，返回所有回调的返回值
        """
        if args is None:
            args = []
        results = []
        for cb in list(self.listeners.get(event_name, [])):
            results.append(cb(*args))
        return results


# 使用示例
emitter = EventEmitter()

def on_click(x, y):
    return x + y

sub = emitter.subscribe("click", on_click)
print(emitter.emit("click", [3, 4]))  # [7]
sub.unsubscribe()
print(emitter.emit("click", [3, 4]))  # []（已取消订阅）
```

### JavaScript 参考实现

```javascript
class EventEmitter {
    constructor() {
        this.events = {};
    }
    subscribe(eventName, callback) {
        if (!this.events[eventName]) this.events[eventName] = [];
        this.events[eventName].push(callback);
        return {
            unsubscribe: () => {
                this.events[eventName] = this.events[eventName].filter(cb => cb !== callback);
            }
        };
    }
    emit(eventName, args = []) {
        return (this.events[eventName] || []).map(cb => cb(...args));
    }
}
```

## 复杂度分析

- 时间复杂度：subscribe O(1)，emit O(n)，unsubscribe O(n)
- 空间复杂度：O(n * m)，n 为事件数，m 为监听器数

## 关键点总结

1. 用字典维护事件名到回调函数列表的映射
2. `subscribe` 返回包含 `unsubscribe` 的订阅对象
3. `emit` 返回所有回调的返回值列表

## 易错点

1. 同一回调可以多次订阅，需要逐一删除
2. `emit` 时应该遍历当前快照，避免回调中取消订阅影响迭代
