## 题目描述

本题原为 JavaScript 设计题目。实现一个不可变性辅助函数（类似 immutability-helper 库），支持通过操作路径更新不可变对象。支持的操作：`$push`（添加元素）、`$set`（设置值）、`$apply`（应用函数）、`$merge`（合并对象）。

## 解题思路

递归地处理更新规范（spec），对对象的每个键递归应用变更。Python 的深拷贝 + 递归更新可以实现相同效果。

## Python 代码实现

### 方法一：递归更新

```python
import copy
from typing import Any, Dict

def update(obj: Any, spec: Dict) -> Any:
    """
    根据 spec 更新 obj（不修改原对象，返回新对象）
    支持操作：$push, $set, $apply, $merge
    """
    if '$set' in spec:
        return spec['$set']

    if '$push' in spec:
        result = list(obj)
        result.extend(spec['$push'])
        return result

    if '$apply' in spec:
        return spec['$apply'](obj)

    if '$merge' in spec:
        result = dict(obj)
        result.update(spec['$merge'])
        return result

    # 递归处理嵌套对象
    if isinstance(obj, dict):
        result = dict(obj)
        for key, sub_spec in spec.items():
            if key.startswith('$'):
                continue
            result[key] = update(obj.get(key), sub_spec)
        return result

    if isinstance(obj, list):
        result = list(obj)
        for key, sub_spec in spec.items():
            idx = int(key)
            result[idx] = update(obj[idx], sub_spec)
        return result

    return obj


# 使用示例
original = {"a": {"b": 1, "c": [1, 2, 3]}}
updated = update(original, {"a": {"b": {"$set": 5}, "c": {"$push": [4, 5]}}})
print(updated)  # {"a": {"b": 5, "c": [1, 2, 3, 4, 5]}}
print(original)  # 原对象不变
```

### JavaScript 参考实现

```javascript
function update(obj, spec) {
    if ('$set' in spec) return spec.$set;
    if ('$push' in spec) return [...obj, ...spec.$push];
    if ('$apply' in spec) return spec.$apply(obj);
    if ('$merge' in spec) return {...obj, ...spec.$merge};

    if (Array.isArray(obj)) {
        const result = [...obj];
        for (const key in spec) result[key] = update(obj[key], spec[key]);
        return result;
    }
    const result = {...obj};
    for (const key in spec) result[key] = update(obj[key] ?? {}, spec[key]);
    return result;
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为对象节点总数
- 空间复杂度：O(n)，新对象的存储

## 关键点总结

1. 不修改原对象（不可变），返回新对象
2. 递归处理嵌套结构
3. 特殊操作以 `$` 开头

## 易错点

1. 需要深度复制而非浅拷贝
2. `$push` 应该是追加（extend）而不是替换
3. 未指定的键保持不变
