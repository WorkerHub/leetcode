## 题目描述

给你两个数组 `arr1` 和 `arr2`，每个数组包含若干对象，每个对象都有一个 `id` 字段（整数）。

合并两个数组，规则：
- 若某个 `id` 只在一个数组中出现，直接加入结果
- 若某个 `id` 在两个数组中都出现，合并两个对象（arr2 的字段覆盖 arr1 的同名字段）

返回按 `id` 升序排列的合并结果数组。

**示例：**
```
输入：
arr1 = [{"id":1,"x":1},{"id":2,"x":9}]
arr2 = [{"id":3,"x":5},{"id":1,"b":10}]
输出：[{"id":1,"x":1,"b":10},{"id":2,"x":9},{"id":3,"x":5}]
```

## 解题思路

使用 Map（字典）以 `id` 为键存储合并结果：
1. 遍历 `arr1`，将每个对象存入 Map
2. 遍历 `arr2`，若 `id` 已存在则用 `Object.assign` 合并（arr2 覆盖 arr1），否则直接存入
3. 将 Map 值按 `id` 排序后返回

## Python 代码实现

### 方法一：JavaScript 实现（推荐）

```javascript
/**
 * @param {Array} arr1
 * @param {Array} arr2
 * @return {Array}
 */
var join = function(arr1, arr2) {
    const map = new Map();

    // 先加入 arr1 的所有对象
    for (const obj of arr1) {
        map.set(obj.id, { ...obj });
    }

    // 处理 arr2，合并或新增
    for (const obj of arr2) {
        if (map.has(obj.id)) {
            // arr2 的字段覆盖 arr1
            Object.assign(map.get(obj.id), obj);
        } else {
            map.set(obj.id, { ...obj });
        }
    }

    // 按 id 升序返回
    return Array.from(map.values()).sort((a, b) => a.id - b.id);
};
```

### 方法二：Python 实现（供参考）

```python
from typing import List

def join(arr1: List[dict], arr2: List[dict]) -> List[dict]:
    merged = {}
    for obj in arr1:
        merged[obj['id']] = dict(obj)
    for obj in arr2:
        if obj['id'] in merged:
            merged[obj['id']].update(obj)  # arr2 覆盖 arr1
        else:
            merged[obj['id']] = dict(obj)
    return sorted(merged.values(), key=lambda x: x['id'])
```

## 复杂度分析

- 时间复杂度：O((m+n) log(m+n))，排序
- 空间复杂度：O(m+n)

## 关键点总结

1. 使用 Map/dict 以 id 为键进行合并
2. arr2 的字段优先（覆盖 arr1 同名字段）
3. 最终按 id 升序排序

## 易错点

1. 注意是 arr2 覆盖 arr1，而非 arr1 覆盖 arr2
2. 合并时使用扩展运算符或 Object.assign 保留所有字段
