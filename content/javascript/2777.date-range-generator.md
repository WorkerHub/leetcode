## 题目描述

给你一个起始日期 `start`、结束日期 `end` 和一个步长 `step`（天数），实现一个生成器函数，按步长生成日期范围内的所有日期字符串（格式 `YYYY-MM-DD`）。

**示例：**
```javascript
const gen = dateRangeGenerator('2023-04-01', '2023-04-04', 1);
gen.next().value; // '2023-04-01'
gen.next().value; // '2023-04-02'
gen.next().value; // '2023-04-03'
gen.next().value; // '2023-04-04'
gen.next().done;  // true
```

## 解题思路

使用 JavaScript 生成器函数，从 start 日期开始，每次加 step 天，直到超过 end 日期。

## Python 代码实现

### 方法一：JavaScript 生成器（推荐）

```javascript
/**
 * @param {string} start
 * @param {string} end
 * @param {number} step
 * @yield {string}
 */
function* dateRangeGenerator(start, end, step) {
    let current = new Date(start);
    const endDate = new Date(end);

    while (current <= endDate) {
        // 格式化为 YYYY-MM-DD
        yield current.toISOString().slice(0, 10);
        // 加 step 天
        current.setDate(current.getDate() + step);
    }
}
```

### 方法二：Python 生成器

```python
from datetime import date, timedelta
from typing import Generator

def dateRangeGenerator(start: str, end: str, step: int) -> Generator:
    current = date.fromisoformat(start)
    end_date = date.fromisoformat(end)
    delta = timedelta(days=step)

    while current <= end_date:
        yield str(current)
        current += delta
```

## 复杂度分析

- 时间复杂度：O(n/step)，n 为日期范围天数
- 空间复杂度：O(1)

## 关键点总结

1. 生成器函数按需产出，不一次性计算所有结果
2. `setDate` 自动处理月末/年末进位
3. 日期比较可以直接使用 `<=`

## 易错点

1. JavaScript 的 `new Date(str)` 默认解析为 UTC，使用 `toISOString().slice(0,10)` 也是 UTC，保持一致
2. 步长可以大于 1，每次加 step 天
