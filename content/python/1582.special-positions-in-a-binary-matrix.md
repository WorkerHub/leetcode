## 题目描述

给你一个大小为 `rows x cols` 的二进制矩阵 `mat`，如果位置 `(i, j)` 满足下述条件，则称它为一个**特殊位置**：
- `mat[i][j] == 1`
- 第 `i` 行和第 `j` 列中的所有其他元素均为 `0`（行和列中 1 的总数都是 1）

返回矩阵中特殊位置的数目。

**示例 1：**
```
输入：mat = [[1,0,0],[0,0,1],[1,0,0]]
输出：1
解释：(1,2) 是特殊位置，因为 mat[1][2]=1，第1行只有一个1，第2列只有一个1。
```

## 解题思路

### 预处理行列和

预计算每行 1 的个数 `row_sum[i]` 和每列 1 的个数 `col_sum[j]`。

遍历所有 `mat[i][j] == 1` 的位置，若 `row_sum[i] == 1` 且 `col_sum[j] == 1`，则是特殊位置。

## 代码实现

### 方法一：预计算行列和（推荐）

```python
from typing import List

class Solution:
    def numSpecial(self, mat: List[List[int]]) -> int:
        rows = len(mat)
        cols = len(mat[0])
        # 预计算每行和每列的1的数量
        row_sum = [sum(row) for row in mat]
        col_sum = [sum(mat[i][j] for i in range(rows)) for j in range(cols)]

        ans = 0
        for i in range(rows):
            for j in range(cols):
                if mat[i][j] == 1 and row_sum[i] == 1 and col_sum[j] == 1:
                    ans += 1
        return ans
```

### 方法二：使用 numpy 思路（列求和）

```python
from typing import List

class Solution:
    def numSpecial(self, mat: List[List[int]]) -> int:
        rows, cols = len(mat), len(mat[0])
        row_sums = [sum(row) for row in mat]
        col_sums = [0] * cols
        for row in mat:
            for j, v in enumerate(row):
                col_sums[j] += v

        return sum(
            1
            for i in range(rows)
            for j in range(cols)
            if mat[i][j] == 1 and row_sums[i] == 1 and col_sums[j] == 1
        )
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(M + N)

## 关键点总结

1. 特殊位置：`mat[i][j] == 1` 且所在行和列的总和都为 1
2. 预处理行列和，遍历时 O(1) 查询

## 易错点

- 行和列的总和都必须等于 1（不是仅检查 1 本身是否存在）
