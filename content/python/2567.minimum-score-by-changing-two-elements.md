## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

- 数组的 **低分** = `nums` 中任意两个元素的差的 **最小绝对值**
- 数组的 **高分** = `nums` 中任意两个元素的差的 **最大绝对值**

恰好执行两次操作（可以作用于相同元素），每次将某个元素修改为 `[1, 10^9]` 范围内的任意值。

返回执行操作后 **最小高分 - 低分**。

**示例 1：**

```
输入：nums = [1,4,3]
输出：0
解释：修改两个元素后使所有元素相等，低分和高分都为 0，差为 0。
```

**示例 2：**

```
输入：nums = [1,4,7,8,5]
输出：3
```

**提示：**

- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键结论**：
- 最小化低分：可以将任意两元素修改为相邻元素的值，低分始终可以为 0（只要有两个相邻元素或修改后相等）。排序后低分 = 0（修改两个元素后可以使数组有两个相同值）
- 最小化高分：排序后，高分 = 最大值 - 最小值。有两次操作，最优策略是修改最大值或最小值：
  - 去掉最小 2 个（修改为其他值）：高分 = nums[-1] - nums[2]
  - 去掉最大 2 个：高分 = nums[-3] - nums[0]
  - 去掉最小 1 个和最大 1 个：高分 = nums[-2] - nums[1]
  - 取三者最小值

低分可以通过将两个相邻元素设为相同来达到 0。

所以答案 = min(nums[-1]-nums[2], nums[-2]-nums[1], nums[-3]-nums[0]) - 0 = 三者最小值。

## Python 代码实现

### 方法一：排序 + 三种情况取最小（推荐）

```python
from typing import List

class Solution:
    def minimizeSum(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        # 低分可以为 0（两次操作可以制造两个相同元素）
        # 高分的最小化：三种边界删除方案
        return min(
            nums[-1] - nums[2],   # 删除最小 2 个
            nums[-2] - nums[1],   # 删除最小 1 个和最大 1 个
            nums[-3] - nums[0]    # 删除最大 2 个
        )
```

### 方法二：枚举端点修改方案

```python
from typing import List

class Solution:
    def minimizeSum(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)

        # 两次操作可以修改最多 2 个端点（极值）
        # 以下三种方案覆盖所有可能：
        candidates = [
            nums[-1] - nums[2],
            nums[-2] - nums[1],
            nums[-3] - nums[0],
        ]
        # 低分始终可以通过操作变为 0（将某两元素设为相等）
        return min(candidates)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 低分 = 0 是可以实现的（修改两元素使其相等）
2. 高分最小化：有两次操作，可以修改最多 2 个极值
3. 三种情况：去掉左2个、去掉左1右1、去掉右2个

## 易错点

1. 题目要求最小化（高分 - 低分），而低分可以为 0
2. 有两次操作，但不一定都修改不同元素（可以修改同一元素两次）
3. 排序后的极值即为最大高分的来源
