## 题目描述

给你一个字符串 `s`，你可以进行 **一次** 操作：选择 `s` 的任意 **非空子字符串**，将其中每个字符替换为字母表中的前一个字符（`'a'` 替换为 `'z'`）。

返回操作后字典序最小的字符串。

**示例 1：**
```
输入：s = "cbabc"
输出："baabc"
解释：选择子串 "cb"，分别替换为 "ba"，结果 "baabc"
```

**示例 2：**
```
输入：s = "acbbc"
输出："aabbc"
```

**示例 3：**
```
输入：s = "leetcode"
输出："kddsbncd"
```

**提示：**
- `1 <= s.length <= 3 * 10^5`
- `s` 只包含小写英文字母

## 解题思路

**贪心**：
- 找第一个不是 `'a'` 的字符，从该位置开始，连续将非 `'a'` 的字符都减一，直到遇到 `'a'` 或字符串末尾。
- 若整个字符串都是 `'a'`，只能将最后一个 `'a'` 变为 `'z'`（必须操作，且这样字典序最小的变化是将某个 `'a'` 变为 `'z'`，但这会增大，所以找最后一个 `'a'` 变 `'z'` 影响最小）。

注意：如果全是 `'a'`，操作会使字典序变大，不可避免，只能操作最后一个字符（变为 `'z'`）来最小化影响。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def smallestString(self, s: str) -> str:
        n = len(s)
        chars = list(s)

        # 找第一个不是 'a' 的位置
        i = 0
        while i < n and chars[i] == 'a':
            i += 1

        # 全是 'a'，将最后一个变为 'z'
        if i == n:
            chars[-1] = 'z'
            return ''.join(chars)

        # 从 i 开始，连续将非 'a' 的字符减一
        while i < n and chars[i] != 'a':
            chars[i] = chr(ord(chars[i]) - 1)
            i += 1

        return ''.join(chars)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：尽可能早地开始减少字符，且连续减少非 `'a'` 的字符
2. 遇到 `'a'` 停止（`'a'` 变为 `'z'` 反而增大）
3. 全为 `'a'` 时，强制将最后一个字符变为 `'z'`（影响最小）

## 易错点

1. 操作必须非空，所以不能选择不操作
2. 全为 `'a'` 是特殊情况，需单独处理
