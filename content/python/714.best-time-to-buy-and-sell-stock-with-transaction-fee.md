## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格；整数 `fee` 代表了交易股票的手续费用。

你可以无限次地完成交易，但是你每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前你就不能再继续购买股票了。

返回获得利润的最大值。

**注意：** 这里的一笔交易指买入持有并卖出股票的整个过程，每笔交易你只需要为支付一次手续费。

**示例 1：**

```
输入：prices = [1,3,2,8,4,9], fee = 2
输出：8
解释：能够达到的最大利润:  
在此处买入 prices[0] = 1
在此处卖出 prices[3] = 8
在此处买入 prices[4] = 4
在此处卖出 prices[5] = 9
总利润: ((8 - 1) - 2) + ((9 - 4) - 2) = 8
```

**示例 2：**

```
输入：prices = [1,3,7,5,10,3], fee = 3
输出：6
```

**提示：**
- `1 <= prices.length <= 5 * 10^4`
- `1 <= prices[i] < 5 * 10^4`
- `0 <= fee < 5 * 10^4`

## 解题思路

这是经典的股票买卖系列问题，需要考虑交易手续费。

**核心思想：**
- 使用动态规划，维护每天的两种状态：持有股票和不持有股票
- 手续费可以在买入时扣除，也可以在卖出时扣除（本题在卖出时扣除）

**动态规划定义：**
- `cash[i]`：第 i 天不持有股票时的最大利润
- `hold[i]`：第 i 天持有股票时的最大利润

**状态转移：**
1. 不持有股票：
   - 前一天就不持有：`cash[i-1]`
   - 前一天持有，今天卖出：`hold[i-1] + prices[i] - fee`
   - 取两者最大值：`cash[i] = max(cash[i-1], hold[i-1] + prices[i] - fee)`

2. 持有股票：
   - 前一天就持有：`hold[i-1]`
   - 前一天不持有，今天买入：`cash[i-1] - prices[i]`
   - 取两者最大值：`hold[i] = max(hold[i-1], cash[i-1] - prices[i])`

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        """
        动态规划：维护两个状态
        cash: 不持有股票的最大利润
        hold: 持有股票的最大利润
        """
        n = len(prices)
        if n == 0:
            return 0
        
        # 初始化
        cash = 0            # 第 0 天不持有股票，利润为 0
        hold = -prices[0]   # 第 0 天持有股票，花费 prices[0]
        
        # 状态转移
        for i in range(1, n):
            # 更新不持有股票的最大利润
            cash = max(cash, hold + prices[i] - fee)
            # 更新持有股票的最大利润
            hold = max(hold, cash - prices[i])
        
        # 最后一天不持有股票的利润一定大于等于持有股票
        return cash
```

### 方法二：数组版本（更清晰）

```python
class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        """
        使用数组存储每天的状态
        """
        n = len(prices)
        
        # cash[i]: 第 i 天不持有股票的最大利润
        # hold[i]: 第 i 天持有股票的最大利润
        cash = [0] * n
        hold = [0] * n
        
        # 初始化第 0 天
        cash[0] = 0
        hold[0] = -prices[0]
        
        # 状态转移
        for i in range(1, n):
            # 不持有：前一天不持有 or 今天卖出
            cash[i] = max(cash[i - 1], hold[i - 1] + prices[i] - fee)
            # 持有：前一天持有 or 今天买入
            hold[i] = max(hold[i - 1], cash[i - 1] - prices[i])
        
        return cash[n - 1]
```

### 方法三：贪心算法

```python
class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        """
        贪心思想：
        维护最小买入价格，遇到更好的卖出机会就卖出
        """
        profit = 0
        min_price = prices[0]  # 当前最低买入价格
        
        for price in prices[1:]:
            if price < min_price:
                # 更新最低买入价格
                min_price = price
            elif price > min_price + fee:
                # 有利可图，卖出
                profit += price - min_price - fee
                # 更新买入价格为 price - fee
                # 这样如果后续价格更高，可以继续获利
                min_price = price - fee
        
        return profit
```

### 方法四：详细注释版

```python
class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        """
        动态规划详解
        
        状态定义：
        - cash: 当前不持有股票的最大利润
        - hold: 当前持有股票的最大利润
        
        状态转移：
        - 不持有 = max(继续不持有, 卖出股票)
        - 持有 = max(继续持有, 买入股票)
        """
        cash = 0            # 初始不持有，利润 0
        hold = -prices[0]   # 初始持有，花费第一天的价格
        
        for i in range(1, len(prices)):
            # 保存前一天的状态（避免状态污染）
            prev_cash = cash
            prev_hold = hold
            
            # 今天不持有股票的最大利润
            # 选项1: 昨天就不持有，今天继续不持有
            # 选项2: 昨天持有，今天卖出（获得 prices[i]，支付手续费 fee）
            cash = max(prev_cash, prev_hold + prices[i] - fee)
            
            # 今天持有股票的最大利润
            # 选项1: 昨天就持有，今天继续持有
            # 选项2: 昨天不持有，今天买入（支付 prices[i]）
            hold = max(prev_hold, prev_cash - prices[i])
        
        # 返回最后不持有股票的利润（一定 >= 持有股票）
        return cash
```

## 复杂度分析

### 动态规划：
- **时间复杂度：** O(n)，遍历一次数组
- **空间复杂度：** O(1)，只使用两个变量

### 贪心算法：
- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 图解示例

以 `prices = [1,3,2,8,4,9]`, `fee = 2` 为例：

```
Day 0: price = 1
  cash = 0 (不持有)
  hold = -1 (买入，花费 1)

Day 1: price = 3
  cash = max(0, -1+3-2) = 0 (卖出不划算)
  hold = max(-1, 0-3) = -1 (继续持有)

Day 2: price = 2
  cash = max(0, -1+2-2) = 0
  hold = max(-1, 0-2) = -1

Day 3: price = 8
  cash = max(0, -1+8-2) = 5 (卖出！)
  hold = max(-1, 5-8) = -1

Day 4: price = 4
  cash = max(5, -1+4-2) = 5
  hold = max(-1, 5-4) = 1 (买入！)

Day 5: price = 9
  cash = max(5, 1+9-2) = 8 (卖出！)
  hold = max(1, 8-9) = 1

最终利润: 8
交易: 第0天买入(1) -> 第3天卖出(8) 获利5
      第4天买入(4) -> 第5天卖出(9) 获利3
      总利润: 5 + 3 = 8
```

## 关键点总结

1. **状态定义**：持有和不持有两种状态，维护各自的最大利润
2. **手续费扣除时机**：可以在买入或卖出时扣除，结果相同
3. **空间优化**：只需要维护两个变量，不需要数组
4. **贪心策略**：维护最低买入价，遇到好机会就卖出
5. **最终状态**：返回不持有股票的利润（一定最优）

## 易错点

1. **初始状态错误**：`hold` 初始化为 `-prices[0]`，不是 0
2. **手续费重复扣除**：每笔交易只扣一次，不要在买入和卖出时都扣
3. **状态污染**：更新 cash 和 hold 时，要用前一天的值，不要用已更新的值
4. **返回值错误**：应该返回 `cash`，不是 `max(cash, hold)`
5. **贪心算法的买入价更新**：卖出后更新为 `price - fee`，不是 `price`
