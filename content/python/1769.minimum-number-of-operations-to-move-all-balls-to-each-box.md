## 题目描述

有 `n` 个盒子。给你一个长度为 `n` 的二进制字符串 `boxes`，其中 `boxes[i]` 的值为 `'0'` 表示第 `i` 个盒子是**空**的，而 `boxes[i]` 的值为 `'1'` 表示盒子里有**一个**小球。

在一步操作中，你可以将**一个**小球从某个盒子移动到一个与之相邻的盒子中。`boxes[0]` 是最左边的盒子，`boxes[n-1]` 是最右边的盒子。

请你返回一个长度为 `n` 的整数数组 `answer`，其中 `answer[i]` 是将所有小球移动到第 `i` 个盒子所需的**最小**操作数。

**示例 1：**
```
输入：boxes = "110"
输出：[1,1,3]
```

## 解题思路

对每个位置 `i`，移动所有球到 `i` 的操作数 = 所有球的位置到 `i` 的距离之和。

**前缀和优化**：
- 左到右扫描：`left_ops[i]` = 左侧所有球移到 `i` 的操作数
  - 设左侧球数为 `left_cnt`，则 `left_ops[i] = left_ops[i-1] + left_cnt`
- 右到左扫描：同理计算右侧贡献

## 代码实现

### 方法一：前缀和两遍扫描（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        ans = [0] * n
        
        # 从左往右：计算左侧所有球移到当前位置的操作数
        cnt = 0   # 左侧球的数量
        ops = 0   # 左侧球移到当前位置的总操作数
        for i in range(n):
            ans[i] += ops
            cnt += int(boxes[i])
            ops += cnt   # 每向右移一步，左侧所有球各多走一步
        
        # 从右往左：计算右侧所有球移到当前位置的操作数
        cnt = 0
        ops = 0
        for i in range(n - 1, -1, -1):
            ans[i] += ops
            cnt += int(boxes[i])
            ops += cnt
        
        return ans
```

### 方法二：暴力枚举（O(n^2)，仅用于验证）

```python
from typing import List

class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        ans = []
        
        for i in range(n):
            total = 0
            for j in range(n):
                if boxes[j] == '1':
                    total += abs(i - j)
            ans.append(total)
        
        return ans
```

## 复杂度分析

- **方法一**：时间 O(n)，空间 O(1)（不算输出）
- **方法二**：时间 O(n^2)，空间 O(1)

## 关键点总结

1. 前缀和优化：维护当前位置左/右侧的球数和累计操作数
2. 每向右/左移动一步，当前方向所有球各多走一步，所以 `ops += cnt`
3. 两遍扫描合并即为答案

## 易错点

- 先累加 `ans[i] += ops`，再更新 `cnt` 和 `ops`（当前位置的球不算左侧/右侧）
