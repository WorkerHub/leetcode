## 题目描述

给你一个正整数数组 `nums`，判断是否存在两个或两个以上的元素的按位或（OR）有**尾随零**。

换句话说，OR 后的结果能被 2 整除（最低位为 0）。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：true
解释：2 | 4 = 6，二进制 110，有尾随零
```

**示例 2：**
```
输入：nums = [2,4,8,16]
输出：true
解释：2 | 4 = 6，有尾随零
```

**示例 3：**
```
输入：nums = [1,3,5,7,9]
输出：false
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

OR 有尾随零等价于 OR 的最低位为 0，即 OR 的结果是偶数。

OR 最低位为 0 当且仅当所有参与 OR 的元素最低位均为 0，即所有参与元素均为偶数。

因此，只需判断数组中是否有**至少两个偶数**。

## Python 代码实现

### 方法一：统计偶数个数（推荐）

```python
from typing import List

class Solution:
    def hasTrailingZeros(self, nums: List[int]) -> bool:
        even_count = sum(1 for x in nums if x % 2 == 0)
        return even_count >= 2
```

### 方法二：直接检查

```python
from typing import List

class Solution:
    def hasTrailingZeros(self, nums: List[int]) -> bool:
        evens = [x for x in nums if x % 2 == 0]
        return len(evens) >= 2
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. OR 结果有尾随零 <=> OR 结果是偶数 <=> 所有参与元素都是偶数
2. 只需找 2 个偶数即可（至少两个元素的 OR）
3. 偶数的最低位为 0，偶数 OR 偶数最低位仍为 0

## 易错点

1. 需要**两个或以上**的元素，单个元素不构成"按位或"
2. OR 结果为偶数 <=> 参与 OR 的所有元素均为偶数（不是任意一个偶数）
