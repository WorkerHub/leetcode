## 题目描述

给你一个整数 `finalSum`。请你将它拆分成若干个**不同**的**正偶数**之和，并使拆分出的正偶数数目**最多**，返回一个数组，元素为这些正偶数（顺序不限）；若无法分割，返回空数组。

**示例 1：**
```
输入：finalSum = 12
输出：[2,4,6]
解释：12 = 2+4+6，共 3 个不同的正偶数，且不能拆成 4 个。
```

**示例 2：**
```
输入：finalSum = 7
输出：[]
解释：7 是奇数，无法拆成正偶数之和。
```

**提示：**
- `1 <= finalSum <= 10^10`

## 解题思路

**贪心：从最小的正偶数开始分配**

若 `finalSum` 为奇数，直接返回空数组。

若为偶数，贪心地从 2 开始依次选取 2, 4, 6, ...，若剩余值够就选，最后一步将剩余值全部加入最后一个数（保证最后一个数不与前面重复）。

具体：遍历 `cur = 2, 4, 6, ...`：
- 若剩余值 `finalSum - cur > cur`（还能继续选下一个偶数），则选 cur，继续。
- 否则，将剩余值 `finalSum` 全部加入结果（最后一个数肯定比 cur 大，不重复）。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maximumEvenSplit(self, finalSum: int) -> List[int]:
        if finalSum % 2 != 0:
            return []

        result = []
        cur = 2  # 当前尝试选取的最小偶数
        remaining = finalSum

        while remaining > cur:
            result.append(cur)
            remaining -= cur
            cur += 2

        # 将剩余值加入最后一个（它比 cur 大，不重复）
        result.append(remaining)
        return result
```

### 方法二：数学计算数量再构造

```python
from typing import List

class Solution:
    def maximumEvenSplit(self, finalSum: int) -> List[int]:
        if finalSum % 2 != 0:
            return []

        # 贪心：选 2, 4, 6, ..., 2k 使得 2+4+...+2k = k(k+1) <= finalSum
        # 即找最大 k，使 k*(k+1) <= finalSum
        # 剩余 rem = finalSum - k*(k+1)，将 rem 加到最后一个数 2k
        k = 0
        total = 0
        while total + 2 * (k + 1) <= finalSum:
            k += 1
            total += 2 * k

        result = [2 * i for i in range(1, k + 1)]
        result[-1] += finalSum - total  # 最后一个数加上剩余部分
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(sqrt(finalSum)) | O(sqrt(finalSum)) |

选取的个数约为 O(sqrt(finalSum))（因为 2+4+...+2k ≈ k^2 = finalSum）。

## 关键点总结

1. 奇数无法拆分（偶数之和必须是偶数）。
2. 贪心：从最小正偶数开始依次选取。
3. 最后一步：将剩余值全部并入最后一个数，保证不重复（因为剩余 >= 下一个偶数）。

## 易错点

- 最后一步的数是 `remaining`（不是 `cur`），它包含了 `cur` 之前的累积剩余。
- `finalSum = 2` 时：`while 2 > 2` 为 false，直接将 2 加入结果。
