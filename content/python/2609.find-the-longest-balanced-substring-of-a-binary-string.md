## 题目描述

给你一个仅由字符 `'0'` 和 `'1'` 组成的字符串 `s`。如果子字符串中的所有 `'0'` 出现在 `'1'` 之前，且 `'0'` 和 `'1'` 的数量相同，则认为该子字符串是平衡子字符串。

返回 `s` 中最长的平衡子字符串的长度。

**示例 1：**
```
输入：s = "01000111"
输出：6
解释：最长平衡子串是 "000111"，长度 6
```

**示例 2：**
```
输入：s = "00111"
输出：4
解释：最长平衡子串是 "0011"，长度 4
```

**示例 3：**
```
输入：s = "111"
输出：0
```

**数据范围：**
- 1 <= s.length <= 50

## 解题思路

枚举所有可能的平衡子串：形如 `000...111...`，即若干个 `'0'` 紧跟若干个 `'1'`。

方法：统计连续的 `'0'` 段和紧接着的 `'1'` 段，取两者较小值的 2 倍作为该段的平衡子串长度。

## Python 代码实现

### 方法一：分段统计（推荐）

```python
class Solution:
    def findTheLongestBalancedSubstring(self, s: str) -> int:
        n = len(s)
        ans = 0
        i = 0
        while i < n:
            # 统计当前连续 '0' 的数量
            zeros = 0
            while i < n and s[i] == '0':
                zeros += 1
                i += 1
            # 统计紧接着的 '1' 的数量
            ones = 0
            while i < n and s[i] == '1':
                ones += 1
                i += 1
            # 平衡子串长度：取 zeros 和 ones 的较小值 * 2
            ans = max(ans, min(zeros, ones) * 2)
        return ans
```

### 方法二：枚举子串（暴力，适用于数据范围小）

```python
class Solution:
    def findTheLongestBalancedSubstring(self, s: str) -> int:
        n = len(s)
        ans = 0
        for i in range(n):
            zeros = ones = 0
            for j in range(i, n):
                if s[j] == '0':
                    if ones > 0:
                        break  # 0 出现在 1 之后，不满足条件
                    zeros += 1
                else:
                    ones += 1
                if zeros == ones:
                    ans = max(ans, zeros + ones)
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n^2)，空间复杂度 O(1)

## 关键点总结

1. 平衡子串必须是 `0...01...1` 的形式
2. 取相邻的 `'0'` 段和 `'1'` 段，有效平衡部分为较小值
3. 连续扫描即可，无需滑动窗口

## 易错点

1. `'0'` 必须全在 `'1'` 前面，中间不能穿插
2. 字符串末尾可能只有 `'0'` 段而没有 `'1'` 段，需要处理
3. 全为 `'1'` 或全为 `'0'` 时结果为 0
