## 题目描述

给定字符串 `s` 和模式字符串 `pattern`，模式串中每个字符代表一种"类型"（如相同的字符代表必须匹配相同的字母，不同字符代表必须匹配不同的字母）。

找出 `s` 中所有符合该模式的子串起始下标，返回下标列表（升序）。

类似于 WordPattern 的子串版本：`pattern[i] == pattern[j]` 当且仅当子串中对应位置的字符相同。

**示例 1：**
```
输入：s = "aabcbcc", pattern = "xyx"
输出：[1, 3]
解释：
- 子串 s[1..3] = "abc"：a<->x, b<->y, c<->x? 不匹配（x 对应 a 和 c 不同）。
- 子串 s[2..4] = "bcb"：b<->x, c<->y, b<->x，匹配！
- 子串 s[3..5] = "cbc"：c<->x, b<->y, c<->x，匹配！
  所以输出 [2, 3]。
```

**示例 2：**
```
输入：s = "aaaa", pattern = "xx"
输出：[0,1,2]
解释：所有长度为 2 的相同字符子串都匹配 "xx"。
```

**提示：**
- `1 <= pattern.length <= s.length <= 10^4`

## 解题思路

滑动窗口 + 哈希映射。

对于每个起始位置 `i`，检查 `s[i:i+len(pattern)]` 是否与 `pattern` 模式一致：
- 建立 `pattern_char -> s_char` 的映射（字符到字符）
- 建立 `s_char -> pattern_char` 的映射（保证双射，避免不同模式字符映射到同一 s 字符）

若映射一致则匹配成功。

## Python 代码实现

### 方法一：哈希映射检查（推荐）

```python
from typing import List

class Solution:
    def findSubstring(self, s: str, pattern: str) -> List[int]:
        n, m = len(s), len(pattern)
        result = []

        def matches(start: int) -> bool:
            """检查 s[start:start+m] 是否匹配 pattern"""
            p2s = {}  # pattern 字符 -> s 字符
            s2p = {}  # s 字符 -> pattern 字符
            for k in range(m):
                pc, sc = pattern[k], s[start + k]
                if pc in p2s:
                    if p2s[pc] != sc:
                        return False
                else:
                    if sc in s2p and s2p[sc] != pc:
                        return False
                    p2s[pc] = sc
                    s2p[sc] = pc
            return True

        for i in range(n - m + 1):
            if matches(i):
                result.append(i)

        return result
```

### 方法二：规范化比较

```python
from typing import List

class Solution:
    def findSubstring(self, s: str, pattern: str) -> List[int]:
        n, m = len(s), len(pattern)
        result = []

        def normalize(t: str) -> tuple:
            """将字符串规范化为下标序列"""
            mapping = {}
            idx = 0
            seq = []
            for c in t:
                if c not in mapping:
                    mapping[c] = idx
                    idx += 1
                seq.append(mapping[c])
            return tuple(seq)

        # 规范化 pattern
        pat_norm = normalize(pattern)

        for i in range(n - m + 1):
            if normalize(s[i:i+m]) == pat_norm:
                result.append(i)

        return result
```

## 复杂度分析

- 时间复杂度：O(n * m)，对每个起始位置检查长度 m 的子串
- 空间复杂度：O(m)，映射表大小

## 关键点总结

1. 双向映射（pattern->s 和 s->pattern）保证严格的双射关系
2. 规范化方法：将字符串转化为首次出现顺序的下标序列，统一比较
3. 两种方法等价，规范化方法代码更简洁

## 易错点

1. 只建立单向映射会导致错误：不同 pattern 字符可能错误地映射到相同 s 字符
2. 注意 `range(n - m + 1)` 而非 `range(n - m)`
