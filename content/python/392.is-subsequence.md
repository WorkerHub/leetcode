## 题目描述

给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的子序列。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，`"ace"` 是 `"abcde"` 的一个子序列，而 `"aec"` 不是）。

**进阶：**

如果有大量输入的 `s`，称作 `s1, s2, ... , sk` 其中 `k >= 10亿`，你需要依次检查它们是否为 `t` 的子序列。在这种情况下，你会怎样改变代码？

**示例 1:**

```
输入：s = "abc", t = "ahbgdc"
输出：true
```

**示例 2:**

```
输入：s = "axc", t = "ahbgdc"
输出：false
```

**提示:**

- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- 两个字符串都只由小写字符组成。

## 解题思路

本题是经典的**子序列匹配**问题，有多种解法。

### 核心思想

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|------------|------------|---------|
| 双指针 | O(m + n) | O(1) | 单次查询 |
| DP | O(m * n) | O(m * n) | 理解子序列 |
| 预处理 | O(n * 26) | O(n * 26) | 多次查询（进阶） |

### 思路一：双指针（推荐）

使用两个指针分别指向 `s` 和 `t`：
- 如果字符匹配，两个指针都前进
- 如果不匹配，只移动 `t` 的指针
- 最后检查 `s` 的指针是否到达末尾

### 思路二：预处理 + 二分（进阶）

对于多次查询的场景：
1. 预处理 `t`，记录每个字符出现的所有位置
2. 对每个查询 `s`，使用二分查找匹配

## Python 代码实现

### 方法一：双指针（推荐）⭐

```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        """
        双指针遍历
        时间复杂度: O(m + n)
        空间复杂度: O(1)
        """
        i, j = 0, 0
        
        while i < len(s) and j < len(t):
            if s[i] == t[j]:
                i += 1
            j += 1
        
        return i == len(s)
```

### 方法二：简化的双指针

```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        """
        使用单指针遍历 s
        """
        if not s:
            return True
        
        i = 0
        for char in t:
            if char == s[i]:
                i += 1
                if i == len(s):
                    return True
        
        return False
```

### 方法三：动态规划

```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        """
        动态规划
        dp[i][j] 表示 s[:i] 是否是 t[:j] 的子序列
        时间复杂度: O(m * n)
        空间复杂度: O(m * n)
        """
        m, n = len(s), len(t)
        
        # dp[i][j]: s[:i] 是否是 t[:j] 的子序列
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        
        # 空字符串是任何字符串的子序列
        for j in range(n + 1):
            dp[0][j] = True
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i-1] == t[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = dp[i][j-1]
        
        return dp[m][n]
```

### 方法四：预处理 + 二分（进阶）⭐⭐⭐

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        """
        预处理 t，适合多次查询
        时间复杂度: 
        - 预处理: O(n)
        - 查询: O(m * log n)
        空间复杂度: O(n)
        """
        # 预处理：记录每个字符在 t 中出现的所有位置
        char_indices = defaultdict(list)
        for i, char in enumerate(t):
            char_indices[char].append(i)
        
        # 当前在 t 中的位置
        current_pos = -1
        
        for char in s:
            if char not in char_indices:
                return False
            
            # 在 char_indices[char] 中二分查找第一个大于 current_pos 的位置
            indices = char_indices[char]
            idx = bisect.bisect_right(indices, current_pos)
            
            if idx == len(indices):
                # 没有找到合适的位置
                return False
            
            current_pos = indices[idx]
        
        return True
```

### 方法五：迭代器（Pythonic）

```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        """
        使用迭代器
        """
        t_iter = iter(t)
        return all(char in t_iter for char in s)
```

## 复杂度分析

### 方法一：双指针

**时间复杂度：** O(m + n)
- m 是 `s` 的长度，n 是 `t` 的长度
- 最坏情况下遍历两个字符串各一次

**空间复杂度：** O(1)
- 只使用常数额外空间

### 方法四：预处理 + 二分

**时间复杂度：**
- 预处理：O(n)
- 单次查询：O(m * log n)
- k 次查询：O(n + k * m * log n)

**空间复杂度：** O(n)
- 存储所有字符的位置信息

## 关键点总结

1. **双指针技巧**：贪心地匹配，不回退
2. **子序列定义**：保持相对顺序，可以跳过字符
3. **进阶优化**：多次查询时预处理 + 二分
4. **边界情况**：空字符串是任何字符串的子序列
5. **迭代器妙用**：Python 的 `iter` 可以优雅解决

## 易错点

1. **子序列 vs 子串**：子序列可以不连续
2. **空字符串**：`s` 为空时应返回 `True`
3. **匹配策略**：贪心地匹配第一个出现的字符
4. **双指针边界**：确保两个指针都不越界
5. **进阶题理解**：多次查询时重复计算浪费时间
