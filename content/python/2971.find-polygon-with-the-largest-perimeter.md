## 题目描述

给你一个长度为 `n` 的正整数数组 `nums`，选取其中 `k`（k >= 3）个元素组成多边形（凸多边形），最大化其周长。

多边形合法条件：任意一边长度小于其余各边的总和（即最大边 < 其余边之和）。

返回最大可能的周长，若不存在则返回 -1。

**示例 1：**
```
输入：nums = [5,5,5]
输出：15
```

**示例 2：**
```
输入：nums = [1,12,1,2,5,50,3]
输出：12
```

**提示：**
- `3 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

贪心：排序后，对于最大边 nums[i]，若 nums[i] < sum(nums[0..i-1])，则可以组成合法多边形，周长为 prefix[i+1]（所有前 i+1 个元素之和）。

从大到小枚举最大边，找第一个满足条件的（即周长最大）。

## Python 代码实现

### 方法一：排序 + 前缀和 + 贪心（推荐）

```python
from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 从最大边开始枚举
        for i in range(n - 1, 1, -1):
            # 最大边为 nums[i]，其余边之和为 prefix[i]
            if nums[i] < prefix[i]:
                return prefix[i + 1]

        return -1
```

### 方法二：反向遍历

```python
from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort()
        total = sum(nums)
        for i in range(len(nums) - 1, 1, -1):
            total_without = total - nums[i]  # 其余边之和
            if nums[i] < total_without:
                return total  # 整个数组都选，周长最大
            total -= nums[i]
        return -1
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，前缀和（方法一）；O(1)（方法二）

## 关键点总结

1. 贪心：包含更多元素的多边形周长更大，同时合法性更容易满足（其余边之和更大）
2. 排序后从最大边开始枚举，找第一个合法的，即为答案（周长最大）
3. 多边形合法条件：最大边 < 其余边总和

## 易错点

1. 至少需要 3 条边（k >= 3）
2. 从后往前枚举，找第一个满足 nums[i] < prefix[i] 的 i
3. 周长是所有选取元素的总和（包括最大边）
