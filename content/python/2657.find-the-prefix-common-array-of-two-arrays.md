## 题目描述

给你两个 0 下标的排列数组 `A` 和 `B`（即 1 到 n 的排列）。定义前缀公共数组 `C`：`C[i]` 等于 `A[0..i]` 和 `B[0..i]` 的公共元素数量。

返回 `A` 和 `B` 的前缀公共数组 `C`。

**示例 1：**
```
输入：A = [1,3,2,4], B = [3,1,2,4]
输出：[0,2,3,4]
```

**示例 2：**
```
输入：A = [2,3,1], B = [3,1,2]
输出：[0,1,3]
```

**数据范围：**
- 1 <= A.length == B.length == n <= 50
- 1 <= A[i], B[i] <= n
- A 和 B 都是 1 到 n 的排列

## 解题思路

用两个集合分别记录 A 和 B 的前缀元素，前缀公共数组 C[i] = 两集合的交集大小。

## Python 代码实现

### 方法一：集合交集（推荐）

```python
from typing import List

class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        seen_a = set()
        seen_b = set()
        ans = []
        for a, b in zip(A, B):
            seen_a.add(a)
            seen_b.add(b)
            ans.append(len(seen_a & seen_b))
        return ans
```

### 方法二：计数数组（更高效）

```python
from typing import List

class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        n = len(A)
        count = [0] * (n + 1)  # count[x]: x 出现在两者前缀中的次数
        ans = []
        common = 0

        for a, b in zip(A, B):
            # 处理 A 的当前元素
            count[a] += 1
            if count[a] == 2:  # A 和 B 的前缀都包含了 a
                common += 1
            # 处理 B 的当前元素
            count[b] += 1
            if count[b] == 2:
                common += 1
            ans.append(common)

        return ans
```

### 方法三：位运算（n <= 64 时适用）

```python
from typing import List

class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        mask_a = mask_b = 0
        ans = []
        for a, b in zip(A, B):
            mask_a |= 1 << a
            mask_b |= 1 << b
            ans.append(bin(mask_a & mask_b).count('1'))
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n^2)（集合交集），空间复杂度 O(n)
- 方法二：时间复杂度 O(n)，空间复杂度 O(n)
- 方法三：时间复杂度 O(n)，空间复杂度 O(1)

## 关键点总结

1. 某元素在两者前缀中都出现时，公共数增加 1
2. 计数数组：当某个值出现 2 次时，说明 A 和 B 的前缀都包含了它
3. 位运算：用整数的每一位表示对应值是否出现

## 易错点

1. 方法二中，当 a == b 时，同一个值会被累加两次（都满足 count == 2 的条件）
2. 需要在同一轮中先处理 a 再处理 b
