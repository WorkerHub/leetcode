## 题目描述

给你一个整数数组 `nums` 和整数 `k`。

每次操作，你可以删除 `nums` 中的最小元素。

返回使数组中所有剩余元素都 >= `k` 所需的最少操作次数。

**示例 1：**
```
输入：nums = [2,11,10,1,3], k = 10
输出：3
```

**示例 2：**
```
输入：nums = [1,1,2,4,9], k = 1
输出：0
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`

## 解题思路

统计 `nums` 中小于 `k` 的元素个数，即为需要删除（操作）的次数。

## Python 代码实现

### 方法一：直接统计（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        return sum(1 for x in nums if x < k)
```

### 方法二：排序统计

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        nums.sort()
        count = 0
        for x in nums:
            if x < k:
                count += 1
            else:
                break
        return count
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只需统计小于 k 的元素个数（必须全部删除）
2. 不需要真正执行删除操作

## 易错点

1. 条件是严格小于 `k`，等于 `k` 的元素满足条件不需删除
