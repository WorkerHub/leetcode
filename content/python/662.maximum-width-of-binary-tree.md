## 题目描述

给你一棵二叉树的根节点 `root`，返回树的**最大宽度**。

树的**最大宽度**是所有层中最大的**宽度**。

每一层的**宽度**被定义为该层最左和最右的非空节点（即，两个端点）之间的长度。将这个二叉树视作与满二叉树结构相同，两端点间会出现一些延伸到这一层的 `null` 节点，这些 `null` 节点也计入长度。

题目数据保证答案将会在 **32 位有符号整数**范围内。

**示例 1:**

```
输入：root = [1,3,2,5,3,null,9]
输出：4
解释：最大宽度出现在树的第 3 层，宽度为 4 (5,3,null,9)。
```

**示例 2:**

```
输入：root = [1,3,2,5,null,null,9,6,null,7]
输出：7
解释：最大宽度出现在树的第 4 层，宽度为 7 (6,null,null,null,null,null,7)。
```

**示例 3:**

```
输入：root = [1,3,2,5]
输出：2
解释：最大宽度出现在树的第 2 层，宽度为 2 (5,3)。
```

**提示:**
- 树中节点的数目范围是 `[1, 3000]`
- `-100 <= Node.val <= 100`

## 解题思路

这道题的关键是给每个节点**编号**，就像完全二叉树的编号规则：

### 核心思想

**完全二叉树的编号规则：**
- 根节点编号为 1（或 0）
- 对于编号为 `i` 的节点：
  - 左子节点编号为 `2 * i`（或 `2 * i + 1`）
  - 右子节点编号为 `2 * i + 1`（或 `2 * i + 2`）

**计算宽度：**
- 每一层的宽度 = 最右节点编号 - 最左节点编号 + 1

### 解法选择

1. **BFS（层序遍历）**：逐层计算宽度
2. **DFS（深度优先）**：记录每层的最左和最右节点编号

## Python 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```python
from typing import Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        """
        BFS + 节点编号
        """
        if not root:
            return 0
        
        max_width = 0
        # 队列：(节点, 编号)
        queue = deque([(root, 0)])
        
        while queue:
            level_size = len(queue)
            # 当前层的最左和最右编号
            _, left_index = queue[0]
            
            for i in range(level_size):
                node, index = queue.popleft()
                
                # 添加子节点
                if node.left:
                    queue.append((node.left, 2 * index))
                if node.right:
                    queue.append((node.right, 2 * index + 1))
            
            # 计算当前层宽度
            # index 是本层最右节点的编号
            max_width = max(max_width, index - left_index + 1)
        
        return max_width
```

### 方法二：DFS 深度优先⭐

```python
class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        """
        DFS + 记录每层最左节点
        """
        # left_most[depth]：记录每层最左节点的编号
        left_most = {}
        self.max_width = 0
        
        def dfs(node: Optional[TreeNode], depth: int, index: int):
            """
            node: 当前节点
            depth: 当前深度
            index: 当前节点编号
            """
            if not node:
                return
            
            # 如果是这一层第一个访问的节点，记录为最左
            if depth not in left_most:
                left_most[depth] = index
            
            # 计算当前层的宽度
            width = index - left_most[depth] + 1
            self.max_width = max(self.max_width, width)
            
            # 递归处理左右子树
            dfs(node.left, depth + 1, 2 * index)
            dfs(node.right, depth + 1, 2 * index + 1)
        
        dfs(root, 0, 0)
        return self.max_width
```

### 方法三：BFS 优化（防止编号溢出）

```python
class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        """
        每层重新归一化编号，防止溢出
        """
        if not root:
            return 0
        
        max_width = 0
        queue = deque([(root, 0)])
        
        while queue:
            level_size = len(queue)
            _, left_index = queue[0]
            
            for i in range(level_size):
                node, index = queue.popleft()
                
                # 将编号归一化（减去最左编号）
                normalized_index = index - left_index
                
                if node.left:
                    queue.append((node.left, 2 * normalized_index))
                if node.right:
                    queue.append((node.right, 2 * normalized_index + 1))
            
            # index 是归一化前的最右编号
            max_width = max(max_width, index - left_index + 1)
        
        return max_width
```

## 复杂度分析

### 方法一/二/三
- **时间复杂度**：O(n)，访问每个节点一次
- **空间复杂度**：O(h)，h 为树高
  - BFS：队列最多存储一层的节点，最坏 O(n)
  - DFS：递归栈深度 O(h)

## 关键点总结

1. **节点编号**：使用完全二叉树的编号规则
2. **宽度计算**：最右编号 - 最左编号 + 1
3. **BFS vs DFS**：都可以，BFS 更直观
4. **防止溢出**：可以每层重新归一化编号
5. **初始编号**：可以从 0 或 1 开始，保持一致即可

## 易错点

1. **编号规则**：
   ```python
   # 从 0 开始
   left = 2 * index
   right = 2 * index + 1
   
   # 从 1 开始
   left = 2 * index
   right = 2 * index + 1
   ```

2. **宽度公式**：
   ```python
   # 包含两端
   width = right_index - left_index + 1  # 不要忘记 +1
   ```

3. **层的识别**：
   ```python
   # BFS 要记录每层的大小
   level_size = len(queue)
   ```

4. **溢出问题**：
   ```python
   # 深树可能导致编号溢出
   # 解决：每层归一化或使用 Python（自动处理大整数）
   ```

5. **空节点处理**：
   ```python

   # 但要考虑它们占用的位置
   ```

**常见问题：**

Q: 为什么要用编号而不是实际位置？
A: 编号可以准确反映节点在满二叉树中的位置，包括 null 节点。

Q: 编号会溢出吗？
A: 在极端情况下可能，但 Python 会自动处理大整数。其他语言可以归一化。

Q: BFS 和 DFS 哪个更好？
A: BFS 更符合"层"的概念，代码也更直观。
