## 题目描述

给你一个下标从 0 开始的二维整数数组 `rectangles`，其中 `rectangles[i] = [widthi, heighti]` 表示第 `i` 个矩形的宽度和高度。

如果两个矩形 `i` 和 `j`（`i < j`）的宽高比相同，则认为这两个矩形**可互换**。更正式地，两个矩形满足 `widthi/heighti == widthj/heightj`（使用实数除法而非整数除法）。

返回可互换矩形对的数目。

**示例 1：**
```
输入：rectangles = [[4,8],[3,6],[10,20],[15,30]]
输出：6
解释：下面按宽高比将矩形进行分类：
- 宽高比为 1/2 的矩形：[4,8], [3,6], [10,20], [15,30]
- 共有 C(4,2) = 6 对可互换矩形
```

**示例 2：**
```
输入：rectangles = [[4,5],[7,8]]
输出：0
```

**提示：**
- `1 <= rectangles.length <= 10^5`
- `rectangles[i].length == 2`
- `1 <= widthi, heighti <= 10^5`

## 解题思路

核心思想：将宽高比化简为最简分数，用哈希表计数，对相同比例的矩形数量 `n` 求组合数 `C(n,2) = n*(n-1)/2`。

**关键步骤：**
1. 对每个矩形，求宽和高的最大公约数（GCD）
2. 将宽高都除以 GCD，得到最简比（w, h）
3. 用哈希表统计每种比例的矩形数量
4. 对每种比例的数量 `cnt`，累加 `cnt*(cnt-1)//2`

## 代码实现

### 方法一：哈希表 + 组合计数（推荐）

```python
from typing import List
from math import gcd
from collections import defaultdict

class Solution:
    def interchangeableRectangles(self, rectangles: List[List[int]]) -> int:
        ratio_count = defaultdict(int)  # 记录每种宽高比出现的次数

        for w, h in rectangles:
            g = gcd(w, h)  # 求最大公约数
            ratio_count[(w // g, h // g)] += 1  # 化简为最简分数作为键

        result = 0
        for cnt in ratio_count.values():
            # 从 cnt 个矩形中选2个的组合数
            result += cnt * (cnt - 1) // 2

        return result
```

### 方法二：排序 + 双指针计数

```python
from typing import List
from math import gcd

class Solution:
    def interchangeableRectangles(self, rectangles: List[List[int]]) -> int:
        # 将所有矩形转化为最简比，然后排序
        ratios = []
        for w, h in rectangles:
            g = gcd(w, h)
            ratios.append((w // g, h // g))

        ratios.sort()  # 排序后相同比例的矩形会相邻

        result = 0
        i = 0
        n = len(ratios)

        while i < n:
            j = i
            # 找到同一比例的连续区间
            while j < n and ratios[j] == ratios[i]:
                j += 1
            cnt = j - i  # 该比例的矩形数量
            result += cnt * (cnt - 1) // 2
            i = j

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（哈希表） | O(n log M)，M 为最大值 | O(n) |
| 方法二（排序） | O(n log n) | O(n) |

- `n` 为矩形数量，`log M` 来自 GCD 计算

## 关键点总结

1. 用 GCD 将宽高比化简为唯一的最简分数表示
2. 组合数公式 `C(n,2) = n*(n-1)//2` 计算对数
3. 哈希表的键使用元组 `(w//g, h//g)` 而非浮点数，避免精度问题
4. 不能直接用浮点数比较，`4/8 == 0.5` 可能因精度导致误差

## 易错点

- 不要用浮点除法比较宽高比，必须用整数最简分数
- 注意结果类型要用 `long`（Python 自动处理大整数）
- `gcd` 函数在 Python 3.5+ 中位于 `math` 模块
