## 题目描述

给定年份 `year` 和月份 `month`，返回该月有多少天。

**示例 1:**

```
输入: year = 1992, month = 7
输出: 31
```

**示例 2:**

```
输入: year = 2000, month = 2
输出: 29
```

**示例 3:**

```
输入: year = 1900, month = 2
输出: 28
```

**提示:**

- `1583 <= year <= 2100`
- `1 <= month <= 12`

## 解题思路

这道题考查对日期和闰年规则的理解。

核心知识点：
1. **普通月份天数**：1、3、5、7、8、10、12月有31天；4、6、9、11月有30天
2. **二月特殊处理**：需要判断是否为闰年
3. **闰年判定规则**：
   - 能被4整除但不能被100整除的年份是闰年
   - 能被400整除的年份是闰年

解题步骤：
1. 如果不是2月，直接返回固定天数
2. 如果是2月，判断是否为闰年
3. 闰年2月有29天，平年有28天

## Python 代码实现

### 方法一：直接判断（推荐）

```python
class Solution:
    def numberOfDays(self, year: int, month: int) -> int:
        # 每个月的天数（索引0不使用，1-12对应1-12月）
        days = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 如果不是2月，直接返回
        if month != 2:
            return days[month]
        
        # 判断是否为闰年
        # 能被400整除，或者能被4整除但不能被100整除
        if (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0):
            return 29
        else:
            return 28
```

### 方法二：使用字典

```python
class Solution:
    def numberOfDays(self, year: int, month: int) -> int:
        # 使用字典存储每月天数
        month_days = {
            1: 31, 3: 31, 5: 31, 7: 31, 8: 31, 10: 31, 12: 31,
            4: 30, 6: 30, 9: 30, 11: 30
        }
        
        # 非2月直接返回
        if month in month_days:
            return month_days[month]
        
        # 2月根据闰年判断
        return 29 if self.isLeapYear(year) else 28
    
    def isLeapYear(self, year: int) -> bool:
        """判断是否为闰年"""
        return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
```

### 方法三：使用 calendar 模块

```python
import calendar

class Solution:
    def numberOfDays(self, year: int, month: int) -> int:
        # Python标准库提供的方法
        return calendar.monthrange(year, month)[1]
```

## 复杂度分析

- 时间复杂度：O(1)，所有操作都是常数时间
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. **闰年判定**：记住两个条件的逻辑关系（能被400整除 OR 能被4整除且不能被100整除）
2. **月份天数记忆**：可以用"拳头记忆法"（凸起的月份31天，凹陷的月份30天，2月特殊）
3. **代码简洁性**：可以使用数组、字典或库函数，选择最清晰的方式

## 易错点

1. **闰年判断顺序错误**：必须先判断400，否则可能漏掉能被400整除的年份
   ```python
   # 错误写法
   if year % 4 == 0 and year % 100 != 0:  # 会漏掉2000年这种情况
   
   # 正确写法
   if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
   ```

2. **数组索引问题**：如果使用数组存储，注意月份从1开始，索引0要留空或不使用

3. **忘记2月特殊处理**：2月是唯一需要根据年份变化的月份
