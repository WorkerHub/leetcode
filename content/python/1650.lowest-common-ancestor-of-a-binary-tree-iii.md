## 题目描述

给定一棵二叉树中的两个节点 `p` 和 `q`，每个节点都有一个指向其**父节点**的指针（`parent`），返回这两个节点的最近公共祖先（LCA）。

**注意：** 本题的节点有父指针，但没有给出根节点。

**示例：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3（p=5 和 q=1 的公共祖先是 3）
```

## 解题思路

**方法一：哈希集合** 将 p 到根的路径上所有祖先存入集合，然后从 q 往上走，第一个在集合中的就是 LCA。

**方法二：双指针**（链表相交问题）将 p 和 q 同时向上走，若到达 None 则跳到另一条路径的起点，两者相遇即 LCA。类似 160 题找链表交点。

## 代码实现

### 方法一：哈希集合（直观）

```python
class Node:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
        self.parent = None

class Solution:
    def lowestCommonAncestor(self, p: Node, q: Node) -> Node:
        # 将 p 的所有祖先（含 p 自身）加入集合
        ancestors = set()
        node = p
        while node:
            ancestors.add(node)
            node = node.parent
        
        # 从 q 向上找第一个在集合中的祖先
        node = q
        while node:
            if node in ancestors:
                return node
            node = node.parent
        
        return None
```

### 方法二：双指针（推荐，O(1) 空间）

```python
class Solution:
    def lowestCommonAncestor(self, p: Node, q: Node) -> Node:
        # 类似找链表交点
        a, b = p, q
        
        while a != b:
            # 若 a 到达 None，则跳转到 q 的起点
            a = a.parent if a else q
            # 若 b 到达 None，则跳转到 p 的起点
            b = b.parent if b else p
        
        return a
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希集合 | O(h) | O(h) |
| 双指针 | O(h) | O(1) |

h 为树的高度。

## 关键点总结

1. 双指针思路来自链表交点问题：两条路径长度之和相同时会在 LCA 相遇
2. 路径 p->root 长度 + q->root 长度 = 固定总长，两指针各走一次完整路径后在 LCA 相遇
3. 方法二不需要额外空间，推荐使用

## 易错点

- 双指针中，到达 None 后跳转：`a = a.parent if a else q`（跳转到另一条路径）
- 注意跳转的是路径起点（p 跳 q，q 跳 p），而不是根节点
