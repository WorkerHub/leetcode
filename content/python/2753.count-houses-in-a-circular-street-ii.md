## 题目描述

给你一个 API `Road`（同 2728 题），但此时你 **不知道** k（最大调用次数），且 API 增加了关门操作：
- `Road.closeDoor()`：关闭当前房屋的门
- `Road.isDoorOpen()`：返回当前房屋的门是否打开
- `Road.moveToNextHouse()`：移动到下一个房屋

在最多 `k` 次 API 调用内，找出街道上的房屋数量。

**约束：** 可以假设房屋数量 <= `k/2`。

## 解题思路

由于可以开/关门：
1. 先用 `k/2` 步把所有经过的房子的门打开（标记已访问）
2. 回到起点，再走一圈，直到遇到第一个门已打开的房子（即起点的下一个未关闭的）

更简洁：
1. 关闭所有门（遍历一圈，关所有门）
2. 打开起点的门
3. 移动，直到再次遇到打开的门，计数

## Python 代码实现

### 方法一：关门标记（推荐）

```python
# class Road:
#     def moveToNextHouse(self) -> None: ...
#     def openDoor(self) -> None: ...
#     def closeDoor(self) -> None: ...
#     def isDoorOpen(self) -> bool: ...

class Solution:
    def houseCount(self, road: 'Road', k: int) -> int:
        # 第一步：将所有门关闭（遍历 k//2 步）
        for _ in range(k // 2):
            road.closeDoor()
            road.moveToNextHouse()

        # 此时已回到或接近起点，重置：打开当前门作为标记
        road.openDoor()
        count = 0
        road.moveToNextHouse()
        count += 1

        # 移动直到遇到已开的门（起点）
        while not road.isDoorOpen():
            road.moveToNextHouse()
            count += 1

        return count
```

### 方法二：更简单思路（利用 k >= 2n）

```python
class Solution:
    def houseCount(self, road: 'Road', k: int) -> int:
        # 关闭前 k//2 个房屋的门，确保覆盖整圈
        for _ in range(k // 2):
            road.closeDoor()
            road.moveToNextHouse()

        # 打开起始位置的门
        road.openDoor()
        ans = 0
        road.moveToNextHouse()
        ans += 1
        while not road.isDoorOpen():
            road.moveToNextHouse()
            ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，最多 k 次 API 调用
- 空间复杂度：O(1)

## 关键点总结

1. 先关门可以清除之前任意状态
2. 打开起点门后，移动计数直到再次遇到开着的门

## 易错点

1. 关门阶段需要覆盖至少一整圈（k >= 2n 保证了 k//2 >= n）
2. 打开门后立即移动，计数从 1 开始
