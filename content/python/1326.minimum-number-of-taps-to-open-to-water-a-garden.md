## 题目描述

在 x 轴上有一个一维的花园。花园的长度为 `n`，从点 `0` 开始，到点 `n` 结束。

花园里共有 `n + 1` 个水龙头，分别位于 `[0, 1, 2, ..., n]`。

给你一个长度为 `n + 1` 的整数数组 `ranges`，其中 `ranges[i]`（`0 <= i <= n`）表示如果打开点 `i` 处的水龙头，该水龙头可以灌溉到花园中 `[i - ranges[i], i + ranges[i]]` 的区域。

请你返回可以灌溉整个花园 `[0, n]` 的**最少水龙头数目**。如果无论如何都无法灌溉整个花园，请你返回 **-1**。

**示例 1：**

```
输入：n = 5, ranges = [3,4,1,1,0,0]
输出：1
解释：水龙头 1 的灌溉范围 [1-4, 1+4] = [-3, 5]，截断到 [0, 5]，覆盖整个花园
```

**示例 2：**

```
输入：n = 3, ranges = [0,0,0,0]
输出：-1
解释：即使打开所有水龙头也无法灌溉整个花园
```

**提示：**

- `1 <= n <= 10^4`
- `ranges.length == n + 1`
- `0 <= ranges[i] <= 100`

## 解题思路

**转化为区间覆盖问题**

将每个水龙头转化为一个区间：水龙头 `i` 覆盖 `[max(0, i-ranges[i]), min(n, i+ranges[i])]`。

问题变为：用最少数量的区间覆盖 `[0, n]`。

**方法一：贪心（跳跃游戏思路）**

类似跳跃游戏 II（LeetCode 45），贪心地在当前能到达的范围内，选择能覆盖最远右端的区间。

**预处理优化：**

对每个左端点 `l`，只需保留从 `l` 出发能到达的最远右端点 `max_reach[l]`。

```python
max_reach = [0] * (n + 1)  # max_reach[i] = 左端点为 i 时能覆盖的最远右端点
for i in range(n + 1):
    l = max(0, i - ranges[i])
    r = min(n, i + ranges[i])
    max_reach[l] = max(max_reach[l], r)
```

然后用贪心：维护当前已覆盖的右端 `curr_end`，在 `[0, curr_end]` 内选能扩展最远的区间。

**方法二：动态规划**

`dp[i]` = 覆盖 `[0, i]` 所需的最少水龙头数。

对每个水龙头产生的区间 `[l, r]`，更新 `dp[r] = min(dp[r], dp[l] + 1)`。

## Python 代码实现

### 方法一：贪心（跳跃游戏 II 思路，推荐）

```python
from typing import List

class Solution:
    def minTaps(self, n: int, ranges: List[int]) -> int:
        # max_reach[i] = 所有左端点 <= i 的区间中能覆盖的最远右端点
        max_reach = [0] * (n + 1)
        for i in range(n + 1):
            l = max(0, i - ranges[i])
            r = min(n, i + ranges[i])
            max_reach[l] = max(max_reach[l], r)
        
        # 贪心：类似跳跃游戏 II
        taps = 0        # 已打开的水龙头数
        curr_end = 0    # 当前已覆盖的右边界
        farthest = 0    # 下一步能覆盖的最远右边界
        
        for i in range(n + 1):
            if i > farthest:
                # 当前位置超出了所有可达范围，无法覆盖
                return -1
            farthest = max(farthest, max_reach[i])
            if i == curr_end and i < n:
                # 到达当前覆盖的边界，需要打开新水龙头
                taps += 1
                curr_end = farthest
        
        return taps
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def minTaps(self, n: int, ranges: List[int]) -> int:
        # dp[i] = 覆盖 [0, i] 所需的最少水龙头数，初始为无穷大
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0  # 覆盖 [0, 0] 不需要任何水龙头
        
        for i in range(n + 1):
            l = max(0, i - ranges[i])
            r = min(n, i + ranges[i])
            # 从 [l, r] 内的某个已知状态出发，更新 dp[r]
            # 找 [l, r] 内 dp 最小值来更新 dp[r]
            for j in range(l, r + 1):
                if dp[j] != INF:
                    dp[r] = min(dp[r], dp[j] + 1)
        
        return dp[n] if dp[n] != INF else -1
```

### 方法三：动态规划（优化版）

```python
from typing import List

class Solution:
    def minTaps(self, n: int, ranges: List[int]) -> int:
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        # 对每个水龙头，只需考虑其区间的左端点：
        # 如果 dp[l] 已知，则 dp[r] 可以由 dp[l]+1 更新
        for i in range(n + 1):
            l = max(0, i - ranges[i])
            r = min(n, i + ranges[i])
            # 枚举区间内所有可能的起点，找最优的
            for j in range(l, r + 1):
                if dp[j] + 1 < dp[r]:
                    dp[r] = dp[j] + 1
        
        return -1 if dp[n] == INF else dp[n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(n) |
| DP | O(n * max_range) | O(n) |

贪心方法是最优的，时间复杂度 O(n)。

## 图解示例

以 `n=5, ranges=[3,4,1,1,0,0]` 为例：

```
水龙头及其覆盖范围：
  0: [0,3] (0-3=-3截断到0, 0+3=3)
  1: [-3,5] -> [0,5]
  2: [1,3]
  3: [2,4]
  4: [4,4]
  5: [5,5]

max_reach: [3, 0, 0, 0, 0, 0] -> 但水龙头1覆盖[0,5]，max_reach[0]=max(3,5)=5
实际 max_reach = [5, 0, 3, 4, 4, 5]

贪心过程：
i=0: farthest=max(0,5)=5, curr_end=0, 打开一个水龙头，taps=1, curr_end=5
i=1..4: farthest 不断更新但不超过5
i=5==n=5: 结束

结果：1
```

## 关键点总结

1. 区间覆盖问题 = 跳跃游戏 II 的变体
2. 预处理 `max_reach[l]`：对每个左端点，记录能到达的最远右端点
3. 贪心：在当前范围内，选能扩展最远的区间，尽量少打开水龙头
4. 边界处理：`max(0, i-ranges[i])` 和 `min(n, i+ranges[i])` 截断到 `[0, n]`

## 易错点

1. **区间截断**：水龙头的范围可能超出 `[0, n]`，需要截断
2. **无法覆盖时返回 -1**：如果遍历时 `i > farthest`，说明有断点
3. **贪心循环终止**：当 `curr_end >= n` 时已覆盖完整花园
