## 题目描述

有 `n` 个人站成一排，给你一个**严格递增**的整数数组 `heights`，`heights[i]` 表示第 `i` 个人的身高。

对于第 `i` 个人，**右边**能被他看到的人是那些身高严格大于其中每个遮挡者的人（即从 i 向右看，j 可以被看到当且仅当 `heights[i..j-1]` 中的所有人高度都小于 `heights[j]`，或者 heights[j] > heights[i]？）

更准确的定义：第 `i` 个人能看到第 `j` 个人（`j > i`），当且仅当在 `i` 和 `j` 之间没有比 `heights[j]` 更高的人。

返回长度为 `n` 的答案数组 `ans`，`ans[i]` 是第 `i` 个人能看到的人数。

**示例 1：**
```
输入：heights = [10, 6, 8, 5, 11, 9]
输出：[3, 1, 2, 1, 1, 0]
```

**提示：**
- `n == heights.length`，`1 <= n <= 10^5`
- `1 <= heights[i] <= 10^5`，`heights` 中元素互不相同

---

## 解题思路

### 核心思想：单调递减栈

从右到左遍历，维护一个单调递减栈（从栈底到栈顶递减）：

对于第 `i` 个人，能看到的人是：
- 所有在 `i` 右边比他矮且没被更高的人挡住的人
- 以及第一个比他高的人（如果存在）

具体：从左到右遍历，维护单调递减栈。处理 `heights[i]` 时：
- 弹出所有比 `heights[i]` 矮的栈顶（这些人对当前人可见，因为没有更高的遮挡），弹出时 `ans[i] += 1`
- 若栈不为空，则栈顶的人也可见（第一个比当前人高的），`ans[i] += 1`
- 将 `heights[i]` 压栈

## 代码实现

### 方法一：单调递减栈（推荐）

```python
from typing import List

class Solution:
    def canSeePersonsCount(self, heights: List[int]) -> List[int]:
        n = len(heights)
        ans = [0] * n
        stack = []  # 单调递减栈（存高度）

        for i in range(n - 1, -1, -1):
            # 处理第 i 个人能看到多少人
            count = 0

            # 弹出所有比 heights[i] 矮的人（第 i 个人可以看到他们）
            while stack and stack[-1] < heights[i]:
                stack.pop()
                count += 1

            # 若栈不为空，栈顶的人（第一个比当前高的人）也可见
            if stack:
                count += 1

            ans[i] = count
            stack.append(heights[i])

        return ans
```

### 方法二：从左到右（另一种方向）

```python
from typing import List

class Solution:
    def canSeePersonsCount(self, heights: List[int]) -> List[int]:
        n = len(heights)
        ans = [0] * n
        stack = []  # 单调递减栈

        for i in range(n):
            # 当前人 i 可以被其左侧哪些人看到
            while stack and heights[stack[-1]] < heights[i]:
                j = stack.pop()
                # 第 j 个人能看到第 i 个人
                ans[j] += 1
            if stack:
                # 栈顶的人（第一个 >= heights[i] 的人）也能看到第 i 个人
                ans[stack[-1]] += 1
            stack.append(i)

        return ans
```

---

## 关键点总结

1. 单调递减栈的核心：被弹出的元素对当前人可见（它没有被更高的人挡住）
2. 弹出所有矮于当前人的元素后，若栈不为空，栈顶（第一个高于当前人的人）也可见
3. 每个元素最多入栈出栈一次，O(n) 总时间

---

## 易错点

- 从右到左遍历时，栈中存的是右侧还未被处理的高度
- 弹出条件是 `stack[-1] < heights[i]`（严格小于），确保更高的人能挡住视线
