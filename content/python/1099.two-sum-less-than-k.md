## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回最大和 `sum`，满足存在 `i < j` 使得 `nums[i] + nums[j] = sum` 且 `sum < k`。如果没有满足此等式的 `i, j` 存在，则返回 `-1`。

**示例 1:**

```
输入: nums = [34,23,1,24,75,33,54,8], k = 60
输出: 58
解释: 34 和 24 相加得到 58，58 小于 60，满足题意。
```

**示例 2:**

```
输入: nums = [10,20,30], k = 15
输出: -1
解释: 我们无法找到和小于 15 的两个元素。
```

**提示:**

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`
- `1 <= k <= 2000`

## 解题思路

这道题是经典「两数之和」问题的变体，不同之处在于：
1. 不是找等于目标值的两数，而是找小于 k 的最大两数之和
2. 返回的是和的值，而不是索引

有三种主要解法：

**方法一：暴力枚举**
- 遍历所有可能的数对，计算它们的和
- 如果和小于 k，更新最大值
- 时间复杂度 O(n²)，但代码简单易懂

**方法二：排序 + 双指针（推荐）**
- 先对数组排序
- 使用左右双指针从两端向中间移动
- 如果 `nums[left] + nums[right] < k`，更新最大值，左指针右移
- 如果 `nums[left] + nums[right] >= k`，右指针左移
- 时间复杂度 O(n log n)，空间复杂度 O(1)

**方法三：排序 + 二分查找**
- 先对数组排序
- 对每个元素 nums[i]，使用二分查找找到最大的 nums[j]，使得 nums[i] + nums[j] < k
- 时间复杂度 O(n log n)

双指针方法最优雅且易于理解，是这道题的标准解法。

## Python 代码实现

### 方法一：暴力枚举

```python
from typing import List

class Solution:
    def twoSumLessThanK(self, nums: List[int], k: int) -> int:
        """
        暴力解法：枚举所有数对
        时间复杂度: O(n²)
        空间复杂度: O(1)
        """
        max_sum = -1  # 初始化为 -1，表示未找到
        n = len(nums)
        
        # 遍历所有可能的数对
        for i in range(n):
            for j in range(i + 1, n):
                current_sum = nums[i] + nums[j]
                # 如果和小于 k，更新最大值
                if current_sum < k:
                    max_sum = max(max_sum, current_sum)
        
        return max_sum
```

### 方法二：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def twoSumLessThanK(self, nums: List[int], k: int) -> int:
        """
        排序 + 双指针解法
        时间复杂度: O(n log n)
        空间复杂度: O(1)
        """
        # 先对数组排序
        nums.sort()
        
        left, right = 0, len(nums) - 1
        max_sum = -1
        
        # 双指针从两端向中间移动
        while left < right:
            current_sum = nums[left] + nums[right]
            
            if current_sum < k:
                # 找到一个有效的和，更新最大值
                max_sum = max(max_sum, current_sum)
                # 左指针右移，尝试找更大的和
                left += 1
            else:
                # 和太大，右指针左移，减小和
                right -= 1
        
        return max_sum
```

### 方法三：排序 + 二分查找

```python
from typing import List
import bisect

class Solution:
    def twoSumLessThanK(self, nums: List[int], k: int) -> int:
        """
        排序 + 二分查找解法
        时间复杂度: O(n log n)
        空间复杂度: O(1)
        """
        nums.sort()
        max_sum = -1
        
        for i in range(len(nums) - 1):
            # 对于 nums[i]，找到最大的 nums[j] 使得 nums[i] + nums[j] < k
            target = k - nums[i] - 1  # 目标是找到小于 k - nums[i] 的最大值
            
            # 在 nums[i+1:] 中二分查找
            # bisect_right 返回插入位置，减 1 得到小于等于 target 的最大值位置
            pos = bisect.bisect_right(nums, target, i + 1) - 1
            
            if pos > i:  # 确保找到了有效的 j
                current_sum = nums[i] + nums[pos]
                max_sum = max(max_sum, current_sum)
        
        return max_sum
```

### 方法四：Python 简化版（使用 itertools）

```python
from typing import List
from itertools import combinations

class Solution:
    def twoSumLessThanK(self, nums: List[int], k: int) -> int:
        """
        使用 Python 标准库的简化解法
        时间复杂度: O(n²)
        空间复杂度: O(1)
        """
        # 生成所有两个元素的组合，计算和，过滤小于 k 的，取最大值
        sums = [a + b for a, b in combinations(nums, 2) if a + b < k]
        return max(sums) if sums else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力枚举 | O(n²) | O(1) | 简单直接，适合小数据量 |
| 排序 + 双指针 | O(n log n) | O(1) | 最优解，推荐 |
| 排序 + 二分查找 | O(n log n) | O(1) | 代码稍复杂 |
| itertools 方法 | O(n²) | O(n²) | 代码简洁，但效率较低 |

## 关键点总结

1. **排序的作用**：排序后可以使用双指针或二分查找，将 O(n²) 优化到 O(n log n)
2. **双指针移动策略**：
   - 如果和小于 k，说明可以尝试更大的数，左指针右移
   - 如果和大于等于 k，说明需要更小的数，右指针左移
3. **初始值设置**：max_sum 初始化为 -1，这样如果找不到满足条件的数对，直接返回 -1
4. **边界条件**：题目保证数组长度至少为 1，但需要至少两个元素才能求和
5. **与原始两数之和的区别**：这里不需要返回索引，所以可以放心排序

## 易错点

1. **忘记处理找不到的情况**：应该初始化 max_sum = -1，而不是 0
2. **双指针移动错误**：
   - 错误：当 sum < k 时移动右指针（会错过更大的和）
   - 正确：当 sum < k 时移动左指针
3. **二分查找边界错误**：使用 bisect 时要注意搜索范围是 `nums[i+1:]`，避免重复使用同一个元素
4. **排序后忘记题目不需要原始索引**：这道题可以安全排序，因为只需要返回和的值
5. **空数组或单元素数组**：虽然题目保证 `nums.length >= 1`，但最好检查是否有足够的元素
