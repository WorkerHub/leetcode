## 题目描述

给你两个字符串数组 `word1` 和 `word2`。如果两个数组表示的字符串**相同**，返回 `true`；否则，返回 `false`。

数组表示的字符串是数组中所有字符串**按顺序连接**得到的字符串。

**示例：**
```
输入：word1 = ["ab", "c"], word2 = ["a", "bc"]
输出：true（"ab"+"c"="abc" == "a"+"bc"="abc"）
```

## 解题思路

最简单的方法：将两个数组分别拼接成字符串，然后比较。

更高效的方法：用双指针逐字符比较，避免实际创建拼接字符串。

## 代码实现

### 方法一：直接拼接比较（推荐）

```python
from typing import List

class Solution:
    def arrayStringsAreEqual(self, word1: List[str], word2: List[str]) -> bool:
        return ''.join(word1) == ''.join(word2)
```

### 方法二：双指针逐字符比较（节省内存）

```python
from typing import List

class Solution:
    def arrayStringsAreEqual(self, word1: List[str], word2: List[str]) -> bool:
        # 双指针：(数组下标, 字符串内下标)
        i1, j1 = 0, 0  # word1 中的位置
        i2, j2 = 0, 0  # word2 中的位置
        
        while i1 < len(word1) and i2 < len(word2):
            if word1[i1][j1] != word2[i2][j2]:
                return False
            
            # 移动 word1 指针
            j1 += 1
            if j1 == len(word1[i1]):
                i1 += 1
                j1 = 0
            
            # 移动 word2 指针
            j2 += 1
            if j2 == len(word2[i2]):
                i2 += 1
                j2 = 0
        
        # 两个数组必须同时到达末尾
        return i1 == len(word1) and i2 == len(word2)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接拼接 | O(n) | O(n) |
| 双指针 | O(n) | O(1) |

n 为所有字符串的总字符数。

## 关键点总结

1. 方法一最简洁：`''.join(word1) == ''.join(word2)`
2. 双指针方法节省空间，避免创建大字符串
3. 双指针结束后要确认两个数组都恰好遍历完

## 易错点

- 双指针结束时，必须确保两个数组都同时到达末尾
- 空字符串情况下需特别注意指针移动
