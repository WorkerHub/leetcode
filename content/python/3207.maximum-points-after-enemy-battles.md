## 题目描述

给你一个整数数组 `enemyEnergies`，表示多个敌人的能量值，以及一个整数 `currentEnergy`，表示你当前的能量。

你可以执行以下操作**任意次**：
- 如果你的能量大于或等于某个敌人的能量，你可以打败该敌人，获得 1 分，并减少等同于该敌人能量的能量值。
- 你可以选择不打败某个敌人，而是获取该敌人所有能量，你的能量增加该敌人能量值，但不得分。

返回你能获得的**最大分数**。

**示例 1：**
```
输入：enemyEnergies = [3,2,2], currentEnergy = 2
输出：3
解释：先吸收能量值最大的敌人（3），能量变为 5；再打败所有其他敌人。
```

**示例 2：**
```
输入：enemyEnergies = [2], currentEnergy = 10
输出：5
```

**提示：**
- `1 <= enemyEnergies.length <= 10^5`
- `1 <= enemyEnergies[i] <= 10^9`
- `0 <= currentEnergy <= 10^9`

## 解题思路

贪心策略：
1. 如果当前能量不足以打败任何敌人，需要先吸收能量。吸收能量最多的敌人（最大值），但如果连最小的敌人都打不过，返回 0。
2. 打败敌人时，应先打败能量最小的敌人（每次花费最少，得分最多）。

具体步骤：
- 排序敌人能量
- 如果初始能量 < 最小敌人能量，先吸收最大的敌人能量
- 如果初始能量 >= 最小敌人能量，贪心地不断打败最弱的敌人

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def maximumPoints(self, enemyEnergies: List[int], currentEnergy: int) -> int:
        enemyEnergies.sort()
        n = len(enemyEnergies)

        # 如果连最弱的敌人都打不过，先吸收最强的
        if currentEnergy < enemyEnergies[0]:
            # 需要吸收能量，吸收最大的
            # 但吸收后若仍打不过最弱的，返回0
            currentEnergy += enemyEnergies[-1]
            if currentEnergy < enemyEnergies[0]:
                return 0
            # 最大的敌人已被吸收，考虑剩余
            # 实际上，如果初始能量为0，且只有一个敌人，无法得分
            if n == 1:
                return 0
            # 只剩前 n-1 个敌人可打
            enemies = enemyEnergies[:-1]
        else:
            enemies = enemyEnergies

        # 现在能打最弱的敌人，贪心：一直打最弱的
        ans = 0
        for e in enemies:
            if currentEnergy >= e:
                ans += currentEnergy // e
                currentEnergy %= e
            # 打不过则停止（已排序，后面更强）
            else:
                break
        return ans
```

### 方法二：模拟贪心

```python
from typing import List

class Solution:
    def maximumPoints(self, enemyEnergies: List[int], currentEnergy: int) -> int:
        min_e = min(enemyEnergies)
        max_e = max(enemyEnergies)

        # 打不过最弱的，先吸收最强的
        if currentEnergy < min_e:
            currentEnergy += max_e
            if currentEnergy < min_e:
                return 0
            # 最强的已吸收，从剩余中找最弱的
            tmp = sorted(enemyEnergies)
            tmp.remove(max_e)
            if not tmp:
                return 0
            enemies = tmp
        else:
            enemies = sorted(enemyEnergies)

        ans = 0
        for e in enemies:
            if currentEnergy >= e:
                ans += currentEnergy // e
                currentEnergy %= e
            else:
                break
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：打最弱敌人效率最高（每单位能量换最多分数）
2. 若初始无法打任何人，需要先吸收最强的敌人
3. 吸收操作只能用一次（或不用），多次吸收会减少得分机会

## 易错点

1. 如果初始能量为 0 且只有一个敌人，无法得分
2. 吸收后要从剩余敌人中继续操作
