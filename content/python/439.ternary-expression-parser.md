## 题目描述

给定一个由数字、字母、`'?'` 和 `':'` 组成的字符串，表示一个三元表达式，请你对其进行求值并返回结果。

三元表达式的格式为 `条件 ? 值1 : 值2`，其中条件为 `'T'`（true）或 `'F'`（false）。

**示例 1：**
```
输入：expression = "T?2:3"
输出："2"
解释：如果条件为真，结果为2；如果条件为假，结果为3。
```

**示例 2：**
```
输入：expression = "F?1:T?4:5"
输出："4"
解释：条件表达式从右向左结合。相当于 F ? 1 : (T ? 4 : 5) = (T ? 4 : 5) = 4
```

**示例 3：**
```
输入：expression = "T?T?F:5:3"
输出："F"
解释：条件表达式从右向左结合。相当于 T ? (T ? F : 5) : 3 = (T ? F : 5) = F
```

**提示：**
- `5 <= expression.length <= 10^4`
- `expression` 由数字、`'T'`、`'F'`、`'?'` 和 `':'` 组成
- 保证是一个有效的三元表达式，并且每个数字都是一位数

## 解题思路

这道题要求解析并求值三元表达式。核心思想是从右向左使用栈处理。

**关键观察：**
1. 三元表达式是右结合的：`a?b:c?d:e` = `a?b:(c?d:e)`
2. 从右向左扫描更容易处理
3. 可以使用栈或递归

**算法流程（栈）：**
1. 从右向左遍历表达式
2. 遇到字符就入栈
3. 遇到 `?` 时，栈顶应该是 `值1 : 值2`
4. 根据条件（栈中 `?` 前的字符）选择值

## Python 代码实现

### 方法一：栈（从右向左）⭐ 推荐

```python
class Solution:
    def parseTernary(self, expression: str) -> str:
        stack = []
        
        # 从右向左遍历
        for i in range(len(expression) - 1, -1, -1):
            char = expression[i]
            
            if char == '?':
                # 栈顶是 值1 : 值2
                # 需要弹出这三个字符
                true_val = stack.pop()
                stack.pop()  # 弹出 ':'
                false_val = stack.pop()
                
                # 条件在 char 的左边
                condition = expression[i - 1]
                i -= 1  # 跳过条件字符
                
                # 根据条件选择值
                if condition == 'T':
                    stack.append(true_val)
                else:
                    stack.append(false_val)
            elif char != ':':
                # 不是 ':'，入栈（数字、字母、T、F）
                stack.append(char)
        
        return stack[0]
```

### 方法二：栈（改进版）

```python
class Solution:
    def parseTernary(self, expression: str) -> str:
        stack = []
        i = len(expression) - 1
        
        while i >= 0:
            char = expression[i]
            
            # 如果不是 '?' 或 ':'，直接入栈
            if char not in '?:':
                stack.append(char)
            elif char == '?':
                # 弹出 值1 和 值2
                true_val = stack.pop()
                false_val = stack.pop()
                
                # 获取条件
                i -= 1
                condition = expression[i]
                
                # 根据条件选择
                if condition == 'T':
                    stack.append(true_val)
                else:
                    stack.append(false_val)
            
            i -= 1
        
        return stack[0]
```

### 方法三：递归

```python
class Solution:
    def parseTernary(self, expression: str) -> str:
        def parse(s):
            if len(s) == 1:
                return s
            
            # 找到第一个 '?'
            condition = s[0]
            
            # 找到对应的 ':'（要考虑嵌套）
            count = 0
            colon_idx = 0
            
            for i in range(1, len(s)):
                if s[i] == '?':
                    count += 1
                elif s[i] == ':':
                    if count == 0:
                        colon_idx = i
                        break
                    count -= 1
            
            # 分割出 值1 和 值2
            true_part = s[2:colon_idx]
            false_part = s[colon_idx + 1:]
            
            # 根据条件递归求值
            if condition == 'T':
                return parse(true_part)
            else:
                return parse(false_part)
        
        return parse(expression)
```

### 方法四：优化递归

```python
class Solution:
    def parseTernary(self, expression: str) -> str:
        self.index = 0
        
        def parse():
            # 读取当前字符
            char = expression[self.index]
            self.index += 1
            
            # 如果后面有 '?'，说明这是一个条件
            if self.index < len(expression) and expression[self.index] == '?':
                self.index += 1  # 跳过 '?'
                
                # 解析 true 部分
                true_val = parse()
                
                self.index += 1  # 跳过 ':'
                
                # 解析 false 部分
                false_val = parse()
                
                # 根据条件返回
                return true_val if char == 'T' else false_val
            else:
                # 叶子节点，直接返回
                return char
        
        return parse()
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，n 是表达式长度
  - 每个字符最多访问常数次
- 空间复杂度：O(n)
  - 栈或递归的深度

## 关键点总结

1. **右结合性**：三元表达式从右向左结合
2. **栈的使用**：从右向左扫描，用栈存储中间结果
3. **嵌套处理**：要正确处理嵌套的三元表达式
4. **递归思路**：也可以用递归自然地处理嵌套
5. **索引管理**：要正确维护当前处理位置

## 易错点

1. **结合方向**：要从右向左处理
2. **栈操作顺序**：弹出顺序要正确
3. **冒号处理**：遇到 `:` 要跳过，不入栈
4. **嵌套问题**：递归时要找到正确的 `:` 位置
5. **索引越界**：注意数组访问的边界
