## 题目描述

给你一个整数数组 `security`，其中 `security[i]` 是第 `i` 天的安保人员数量，以及整数 `time`。

如果第 `i` 天满足：
- 前 `time` 天（`i-time` 到 `i-1`）非递增
- 后 `time` 天（`i+1` 到 `i+time`）非递减

则第 `i` 天是**适合抢劫银行的好日子**。

返回所有好日子的下标（升序）。

**示例：**
```
输入：security = [5,3,3,3,5,6,2], time = 2
输出：[2,3]
解释：
第 2 天：前2天 [5,3] 非递增，后2天 [3,5] 非递减 → 好日子
第 3 天：前2天 [3,3] 非递增，后2天 [5,6] 非递减 → 好日子
```

**提示：**
- `1 <= security.length <= 10^5`
- `0 <= security[i] <= 10^5`
- `0 <= time <= 10^5`

## 解题思路

**前缀和（动态规划）：**

预计算两个辅助数组：
- `dec[i]`：以 `i` 为终点的非递增序列的最大长度（`security[i] <= security[i-1]` 则 `dec[i] = dec[i-1]+1`，否则为 0）
- `inc[i]`：以 `i` 为起点的非递减序列向右的最大长度（从右到左计算）

第 `i` 天是好日子当且仅当 `dec[i] >= time` 且 `inc[i] >= time`。

## 代码实现

### 方法一：前缀/后缀计数（推荐）

```python
from typing import List

class Solution:
    def goodDaysToRobBank(self, security: List[int], time: int) -> List[int]:
        n = len(security)
        if time == 0:
            return list(range(n))

        # dec[i]：i 之前连续非递增的天数
        dec = [0] * n
        for i in range(1, n):
            if security[i] <= security[i - 1]:
                dec[i] = dec[i - 1] + 1

        # inc[i]：i 之后连续非递减的天数
        inc = [0] * n
        for i in range(n - 2, -1, -1):
            if security[i] <= security[i + 1]:
                inc[i] = inc[i + 1] + 1

        # 找好日子
        result = []
        for i in range(time, n - time):
            if dec[i] >= time and inc[i] >= time:
                result.append(i)

        return result
```

### 方法二：更简洁写法

```python
from typing import List

class Solution:
    def goodDaysToRobBank(self, security: List[int], time: int) -> List[int]:
        n = len(security)
        left = [0] * n   # left[i] = 到 i 为止连续非递增的天数
        right = [0] * n  # right[i] = 从 i 开始连续非递减的天数

        for i in range(1, n):
            if security[i] <= security[i - 1]:
                left[i] = left[i - 1] + 1

        for i in range(n - 2, -1, -1):
            if security[i] <= security[i + 1]:
                right[i] = right[i + 1] + 1

        return [i for i in range(n) if left[i] >= time and right[i] >= time]
```

## 复杂度分析

- 时间复杂度：O(n)，三次线性遍历
- 空间复杂度：O(n)，两个辅助数组

## 关键点总结

1. `dec[i]`：记录以 i 结尾的非递增序列长度（从左往右）
2. `inc[i]`：记录以 i 起始的非递减序列长度（从右往左）
3. 好日子条件：`dec[i] >= time && inc[i] >= time`

## 易错点

- 非递增是 `security[i] <= security[i-1]`（允许相等）
- 非递减是 `security[i] <= security[i+1]`（允许相等）
- `time = 0` 时，所有天都是好日子（数组全部下标）
- 遍历范围：`i` 从 `time` 到 `n-time-1`（确保两侧有足够天数）
