## 题目描述

给你一个字符串 `word`，**元音子串**定义为只含元音字母（`a, e, i, o, u`）且包含所有五种元音的子串。

返回 `word` 中**元音子串**的数目。

**示例 1：**
```
输入：word = "aeiouu"
输出：2
解释：子串 "aeiou" 和 "aeiouu" 都是元音子串
```

**示例 2：**
```
输入：word = "unicornarihan"
输出：0
```

**提示：**
- `1 <= word.length <= 100`
- `word` 由小写英文字母组成

## 解题思路

**方法一（暴力）：** 枚举所有子串，检查是否满足条件（只含元音且包含所有5种）。

**方法二（滑动窗口）：** 用双指针找包含所有5种元音的最短子串。

由于数据规模小（n ≤ 100），暴力法完全可行。

## 代码实现

### 方法一：暴力枚举（推荐用于理解）

```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')
        count = 0
        n = len(word)

        for i in range(n):
            # 如果 word[i] 不是元音，以 i 开头的所有子串都不是元音子串
            if word[i] not in vowels:
                continue
            seen = set()
            for j in range(i, n):
                if word[j] not in vowels:
                    break  # 遇到非元音，停止
                seen.add(word[j])
                if len(seen) == 5:
                    count += 1  # 包含所有5种元音

        return count
```

### 方法二：滑动窗口（双指针）

```python
from collections import Counter

class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')

        def at_least_k_distinct(k: int) -> int:
            # 计算包含至少 k 种元音（且只含元音）的子串数
            count = 0
            left = 0
            freq = Counter()

            for right in range(len(word)):
                if word[right] not in vowels:
                    left = right + 1
                    freq.clear()
                    continue
                freq[word[right]] += 1
                while len(freq) >= k:
                    count += len(word) - right
                    freq[word[left]] -= 1
                    if freq[word[left]] == 0:
                        del freq[word[left]]
                    left += 1

            return count

        # 恰好5种 = 至少5种 - 至少6种（不可能） = 至少5种 - 至少6种
        # 更简单：恰好5种 = 至少5种 - 至少6种（但元音只有5种，所以不可能6种）
        # 用容斥：恰好5种 = 至少5种 - 至少5种且缺少某种
        # 或者：恰好k种 = 至少k种 - 至少(k+1)种
        return at_least_k_distinct(5) - at_least_k_distinct(6)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2) | O(1) |
| 滑动窗口 | O(n) | O(1) |

## 关键点总结

1. 暴力枚举：遇到非元音立即 break，效率较高
2. 滑动窗口：用"至少k种"的窗口技巧计算"恰好5种"
3. 恰好5种 = 至少5种 - 至少6种（其中至少6种=0，因为只有5种元音）

## 易错点

- 子串必须**只**含元音（遇到辅音要终止该窗口）
- 暴力法中，`seen` 要在外层循环重置（每次以 i 开头新建集合）
