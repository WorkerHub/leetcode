## 题目描述

给定两个一维向量，实现一个迭代器，交替返回它们的元素。

**示例 1:**

```
输入:
v1 = [1,2]
v2 = [3,4,5,6] 
输出: [1,3,2,4,5,6]
解释: 调用 next() 会逐个返回 [1,3,2,4,5,6]。
```

**示例 2:**

```
输入:
v1 = [1]
v2 = []
输出: [1]
```

**示例 3:**

```
输入:
v1 = []
v2 = [1]
输出: [1]
```

**进阶：** 如果给定 k 个一维向量，你的代码能否正确运行？

## 解题思路

这道题要求实现一个迭代器，能够交替返回两个列表的元素。核心思想是维护两个指针，分别指向两个列表的当前位置，并记录当前应该从哪个列表取元素。

**关键观察：**

1. 需要记录每个列表的当前索引位置
2. 需要标记当前轮到哪个列表
3. 当一个列表遍历完后，只从另一个列表取元素
4. 可以使用队列存储所有非空列表，实现更优雅的解法

**算法流程：**

方法一（双指针）：
1. 使用两个指针 `i1` 和 `i2` 分别跟踪两个列表的位置
2. 使用标志位 `turn` 标记当前轮到哪个列表
3. 在 `next()` 中，根据 `turn` 从对应列表取元素
4. 如果当前列表已用完，自动切换到另一个列表

方法二（队列）：
1. 将所有非空列表及其索引存入队列
2. 每次取队首列表的当前元素
3. 如果该列表还有剩余元素，将其重新加入队尾
4. 实现了真正的"轮转"机制

## Python 代码实现

### 方法一：双指针标记法

```python
class ZigzagIterator:
    def __init__(self, v1: List[int], v2: List[int]):
        """
        初始化迭代器
        """
        self.v1 = v1
        self.v2 = v2
        self.i1 = 0  # v1 的当前索引
        self.i2 = 0  # v2 的当前索引
        self.turn = 1  # 当前轮到哪个列表，1 表示 v1，2 表示 v2
        
        # 如果 v1 为空，从 v2 开始
        if not v1:
            self.turn = 2
        
    def next(self) -> int:
        """
        返回下一个元素
        """
        # 当前轮到 v1
        if self.turn == 1:
            val = self.v1[self.i1]
            self.i1 += 1
            
            # 切换到 v2，除非 v2 已用完
            if self.i2 < len(self.v2):
                self.turn = 2
            
            return val
        else:  # 当前轮到 v2
            val = self.v2[self.i2]
            self.i2 += 1
            
            # 切换到 v1，除非 v1 已用完
            if self.i1 < len(self.v1):
                self.turn = 1
            
            return val
    
    def hasNext(self) -> bool:
        """
        判断是否还有下一个元素
        """
        return self.i1 < len(self.v1) or self.i2 < len(self.v2)
```

### 方法二：队列法（推荐，支持 k 个列表）

```python
from collections import deque

class ZigzagIterator:
    def __init__(self, v1: List[int], v2: List[int]):
        """
        使用队列存储 (列表, 索引) 对
        """
        self.queue = deque()
        
        # 将非空列表加入队列
        if v1:
            self.queue.append((v1, 0))
        if v2:
            self.queue.append((v2, 0))
    
    def next(self) -> int:
        """
        取队首列表的当前元素，如果还有剩余则重新加入队尾
        """
        vec, index = self.queue.popleft()
        val = vec[index]
        
        # 如果该列表还有剩余元素，重新加入队尾
        if index + 1 < len(vec):
            self.queue.append((vec, index + 1))
        
        return val
    
    def hasNext(self) -> bool:
        """
        队列非空表示还有元素
        """
        return len(self.queue) > 0
```

### 方法三：通用的 k 个列表解法

```python
from collections import deque

class ZigzagIterator:
    def __init__(self, *vectors):
        """
        支持 k 个列表的通用解法
        vectors: 可变数量的列表参数
        """
        self.queue = deque()
        
        # 将所有非空列表加入队列
        for vec in vectors:
            if vec:
                self.queue.append((vec, 0))
    
    def next(self) -> int:
        vec, index = self.queue.popleft()
        val = vec[index]
        
        if index + 1 < len(vec):
            self.queue.append((vec, index + 1))
        
        return val
    
    def hasNext(self) -> bool:
        return len(self.queue) > 0
```

## 复杂度分析

**方法一：双指针法**
- 时间复杂度：`O(1)` 对于每次 `next()` 和 `hasNext()` 操作
- 空间复杂度：`O(1)` 只使用常数额外空间

**方法二：队列法**
- 时间复杂度：`O(1)` 对于每次 `next()` 和 `hasNext()` 操作，队列操作都是 O(1)
- 空间复杂度：`O(k)` 其中 k 是列表数量，队列中最多存储 k 个元素

## 关键点总结

1. **迭代器设计模式**：实现 `next()` 和 `hasNext()` 两个核心方法
2. **状态维护**：需要记录每个列表的当前位置和轮转状态
3. **边界处理**：当某个列表为空或遍历完时的处理逻辑
4. **扩展性**：队列法更容易扩展到 k 个列表的情况
5. **轮转机制**：队列的先进先出特性天然支持轮转访问

## 易错点

1. **空列表处理**：初始化时需要检查列表是否为空，避免访问越界
2. **切换逻辑**：在双指针法中，切换到下一个列表前需要检查是否还有元素
3. **队列为空**：`next()` 调用前应确保 `hasNext()` 返回 true
4. **索引越界**：确保在访问列表元素前检查索引有效性
5. **重新入队**：在队列法中，取出元素后要判断是否需要重新加入队尾
