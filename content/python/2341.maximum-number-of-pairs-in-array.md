## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。在一步操作中，你可以从数组中选出**两个**相等的整数，并将它们都从数组中删除。

返回一个下标从 **0** 开始、长度为 **2** 的整数数组 `answer`，其中：
- `answer[0]` 是执行操作的最大次数。
- `answer[1]` 是执行**最多**操作次数后，数组中剩余的元素数目。

**示例 1：**
```
输入：nums = [1,3,2,1,3,2,2]
输出：[3,1]
解释：3 对可以配对（三对），剩余 1 个元素。
```

**示例 2：**
```
输入：nums = [1,1]
输出：[1,0]
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 解题思路

统计每个数的出现次数，每个数出现 k 次可以配对 `k // 2` 次，剩余 `k % 2` 个。

- 总配对数 = sum(count[v] // 2)
- 剩余元素数 = sum(count[v] % 2)

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def numberOfPairs(self, nums: List[int]) -> List[int]:
        count = Counter(nums)
        pairs = 0
        remaining = 0
        
        for v in count.values():
            pairs += v // 2      # 每个数能配对的次数
            remaining += v % 2   # 每个数剩余的个数
        
        return [pairs, remaining]
```

### 方法二：位操作（利用奇偶性）

```python
from typing import List

class Solution:
    def numberOfPairs(self, nums: List[int]) -> List[int]:
        count = {}
        for x in nums:
            count[x] = count.get(x, 0) + 1
        
        pairs = sum(v // 2 for v in count.values())
        # 剩余元素 = 总元素 - 配对元素
        remaining = len(nums) - pairs * 2
        
        return [pairs, remaining]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表计数 | O(n) | O(n) |

## 关键点总结

1. 每个数出现次数的一半（整除）即为该数可配对次数。
2. 剩余元素总数 = 总元素数 - 已配对元素数 * 2。
3. 利用 `Counter` 快速统计频率。

## 易错点

- 剩余元素不是配对后的元素数，而是 `len(nums) - pairs * 2`，或 `sum(v % 2)`。
