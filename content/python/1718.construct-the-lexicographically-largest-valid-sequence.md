## 题目描述

给你一个整数 `n`，请你构造一个长度为 `2n - 1` 的**字典序最大**的序列，该序列同时满足下面两个条件：
- 整数 `1` 在序列中只出现一次
- `2` 到 `n` 之间的每个整数都恰好出现两次
- 对于每个 `2` 到 `n` 之间的整数 `i`，两个 `i` 之间的距离恰好为 `i`

**示例 1：**
```
输入：n = 3
输出：[3,1,2,3,2]
```

**示例 2：**
```
输入：n = 5
输出：[5,3,1,4,3,5,2,4,2]
```

## 解题思路

使用回溯法，从大到小尝试放置数字（保证字典序最大）：
1. 从第一个空位开始，尝试放置 `n, n-1, ..., 1`
2. 对于数字 `i`（i >= 2），需要同时放置在 `pos` 和 `pos + i` 两个位置
3. 如果 `pos + i` 超界或已被占用，跳过
4. 用递归+回溯搜索

## 代码实现

### 方法一：回溯（推荐）

```python
from typing import List

class Solution:
    def constructDistancedSequence(self, n: int) -> List[int]:
        size = 2 * n - 1
        result = [0] * size
        used = [False] * (n + 1)
        
        def backtrack(pos: int) -> bool:
            # 跳过已填充的位置
            while pos < size and result[pos] != 0:
                pos += 1
            
            # 所有位置都填好了
            if pos == size:
                return True
            
            # 从大到小尝试，保证字典序最大
            for num in range(n, 0, -1):
                if used[num]:
                    continue
                
                if num == 1:
                    # 1 只出现一次
                    result[pos] = 1
                    used[1] = True
                    if backtrack(pos + 1):
                        return True
                    result[pos] = 0
                    used[1] = False
                else:
                    # num 需要放在 pos 和 pos + num
                    second_pos = pos + num
                    if second_pos < size and result[second_pos] == 0:
                        result[pos] = num
                        result[second_pos] = num
                        used[num] = True
                        if backtrack(pos + 1):
                            return True
                        result[pos] = 0
                        result[second_pos] = 0
                        used[num] = False
            
            return False
        
        backtrack(0)
        return result
```

### 方法二：迭代回溯（用栈模拟）

```python
from typing import List

class Solution:
    def constructDistancedSequence(self, n: int) -> List[int]:
        size = 2 * n - 1
        result = [0] * size
        used = [False] * (n + 1)
        
        # 记录每个位置尝试到哪个数字了
        pos = 0
        # 从大到小尝试的数字
        choices = list(range(n, 0, -1))
        
        # 用递归的方式（Python 递归深度足够）
        def solve(idx):
            if idx == size:
                return True
            if result[idx] != 0:
                return solve(idx + 1)
            for num in range(n, 0, -1):
                if used[num]:
                    continue
                if num == 1:
                    result[idx] = 1
                    used[1] = True
                    if solve(idx + 1):
                        return True
                    result[idx] = 0
                    used[1] = False
                else:
                    j = idx + num
                    if j < size and result[j] == 0:
                        result[idx] = num
                        result[j] = num
                        used[num] = True
                        if solve(idx + 1):
                            return True
                        result[idx] = 0
                        result[j] = 0
                        used[num] = False
            return False
        
        solve(0)
        return result
```

## 复杂度分析

- **时间复杂度**：最坏 O(n!)，但实际因剪枝较快
- **空间复杂度**：O(n)，递归栈深度 + 结果数组

## 关键点总结

1. 从大到小放置数字，保证字典序最大
2. 每次找到第一个空位，尝试放置
3. 数字 `i`（i >= 2）需要同时占两个位置 `pos` 和 `pos + i`

## 易错点

- 数字 1 只出现一次，不需要找第二个位置
- 检查 `pos + num < size`（不越界）且 `result[pos + num] == 0`（未占用）
