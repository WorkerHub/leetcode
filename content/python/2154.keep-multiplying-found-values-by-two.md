## 题目描述

给你一个整数数组 `nums`，另给你一个整数 `original`，是需要在 `nums` 中搜索的第一个数字。

执行下述步骤：
1. 如果在 `nums` 中找到 `original`，将 `original` 乘以 2，得到新的 `original`。
2. 重复步骤 1，直到在 `nums` 中找不到 `original`。
3. 返回 `original`。

**示例：**
```
输入：nums = [5,3,6,1,12], original = 3
输出：24
解释：3 在 nums 中，3*2=6；6 在 nums 中，6*2=12；12 在 nums 中，12*2=24；24 不在 nums 中，返回 24。
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i], original <= 1000`

## 解题思路

将 `nums` 存入集合（O(1) 查找），然后循环翻倍查找即可。

## 代码实现

### 方法一：集合查找（推荐）

```python
from typing import List

class Solution:
    def findFinalValue(self, nums: List[int], original: int) -> int:
        num_set = set(nums)
        while original in num_set:
            original *= 2
        return original
```

### 方法二：排序模拟

```python
from typing import List

class Solution:
    def findFinalValue(self, nums: List[int], original: int) -> int:
        nums_sorted = sorted(set(nums))
        val = original
        for n in nums_sorted:
            if n == val:
                val *= 2
        return val
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合查找 | O(n + log(max_val)) | O(n) |
| 排序 | O(n log n) | O(n) |

循环次数最多 log2(max_val) 次（original 最大翻倍到 nums 范围外）。

## 关键点总结

1. 用集合存储 `nums`，每次查找 O(1)。
2. 循环上限由 `nums` 中最大值决定（一旦超出最大值就找不到了）。
3. 方法一最简洁，`while original in set` 直接表达逻辑。

## 易错点

- 不用集合而直接用 `in nums` 每次 O(n) 查找也可以通过（n <= 1000），但不如集合高效。
