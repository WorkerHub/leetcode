## 题目描述

给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。

这里的遵循指完全匹配，例如，`pattern` 里的每个字母和字符串 `s` 中的每个非空单词之间存在着双向连接的对应规律。

**示例 1:**

```
输入: pattern = "abba", s = "dog cat cat dog"
输出: true
```

**示例 2:**

```
输入: pattern = "abba", s = "dog cat cat fish"
输出: false
```

**示例 3:**

```
输入: pattern = "aaaa", s = "dog cat cat dog"
输出: false
```

**提示:**

- `1 <= pattern.length <= 300`
- `pattern` 只包含小写英文字母
- `1 <= s.length <= 3000`
- `s` 只包含小写英文字母和 `' '`
- `s` 不包含任何前导或尾随对空格
- `s` 中每个单词都被单个空格分隔

## 解题思路

这道题是同构字符串的变种，要求判断模式字符串和单词序列是否一一对应。核心是建立双向映射。

**核心思想：**

需要满足两个条件：
1. 每个字符唯一对应一个单词（字符 -> 单词）
2. 每个单词唯一对应一个字符（单词 -> 字符）

**关键观察：**

- `pattern = "abba"`, `s = "dog cat cat dog"` ✓
  - a -> dog, b -> cat, b -> cat, a -> dog
- `pattern = "abba"`, `s = "dog cat cat fish"` ✗
  - a -> dog, b -> cat, b -> cat, a -> fish（a 对应了两个不同单词）
- `pattern = "abba"`, `s = "dog dog dog dog"` ✗
  - a -> dog, b -> dog（两个不同字符对应同一个单词）

**算法思路：**

方法一：双哈希表
- 维护两个映射：char_to_word 和 word_to_char
- 遍历时检查映射的一致性

方法二：单哈希表 + 集合
- 哈希表记录字符到单词的映射
- 集合记录已使用的单词

方法三：利用索引
- 比较字符首次出现位置和单词首次出现位置是否一致

## Python 代码实现

### 方法一：双哈希表（推荐）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        """
        双哈希表建立双向映射
        时间复杂度 O(n+m)，空间复杂度 O(n+m)
        """
        words = s.split()
        
        # 长度不匹配直接返回 False
        if len(pattern) != len(words):
            return False
        
        char_to_word = {}  # 字符 -> 单词
        word_to_char = {}  # 单词 -> 字符
        
        for char, word in zip(pattern, words):
            # 检查字符到单词的映射
            if char in char_to_word:
                if char_to_word[char] != word:
                    return False
            else:
                char_to_word[char] = word
            
            # 检查单词到字符的映射
            if word in word_to_char:
                if word_to_char[word] != char:
                    return False
            else:
                word_to_char[word] = char
        
        return True
```

### 方法二：哈希表 + 集合

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        """
        哈希表 + 集合
        """
        words = s.split()
        
        if len(pattern) != len(words):
            return False
        
        mapping = {}       # 字符 -> 单词
        used_words = set() # 已使用的单词
        
        for char, word in zip(pattern, words):
            if char in mapping:
                # 字符已映射，检查是否一致
                if mapping[char] != word:
                    return False
            else:
                # 字符未映射，检查单词是否被其他字符使用
                if word in used_words:
                    return False
                mapping[char] = word
                used_words.add(word)
        
        return True
```

### 方法三：利用索引（最优雅）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        """
        比较首次出现的索引位置
        如果映射一致，则首次出现位置应该相同
        """
        words = s.split()
        
        if len(pattern) != len(words):
            return False
        
        # 比较每个位置的首次出现索引
        return (list(map(pattern.find, pattern)) == 
                list(map(words.index, words)))
```

### 方法四：详细注释版（新手友好）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        """
        判断字符串 s 是否遵循 pattern 的规律
        
        要求：双向一一对应
        - 每个字符唯一对应一个单词
        - 每个单词唯一对应一个字符
        
        示例：
        pattern = "abba"
        s = "dog cat cat dog"
        
        建立映射：
        a <-> dog
        b <-> cat
        
        验证：
        a -> dog ✓
        b -> cat ✓
        b -> cat ✓
        a -> dog ✓
        
        返回 True
        """
        # 按空格分割字符串
        words = s.split()
        
        # 长度必须相同
        if len(pattern) != len(words):
            return False
        
        # 双向映射
        char_map = {}  # 字符 -> 单词的映射
        word_map = {}  # 单词 -> 字符的映射
        
        # 遍历每一对 (字符, 单词)
        for i in range(len(pattern)):
            char = pattern[i]
            word = words[i]
            
            # 检查字符的映射
            if char in char_map:
                # 字符已经有映射，检查是否一致
                if char_map[char] != word:
                    return False
            else:
                # 建立新映射
                char_map[char] = word
            
            # 检查单词的映射
            if word in word_map:
                # 单词已经有映射，检查是否一致
                if word_map[word] != char:
                    return False
            else:
                # 建立新映射
                word_map[word] = char
        
        return True
```

### 方法五：一行代码（Python 特色）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        """
        利用 set 和 zip 的特性
        """
        words = s.split()
        return (len(pattern) == len(words) and 
                len(set(pattern)) == len(set(words)) == len(set(zip(pattern, words))))
```

### 方法六：简化双哈希表

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        
        if len(pattern) != len(words):
            return False
        
        p2w, w2p = {}, {}
        
        for p, w in zip(pattern, words):
            if (p in p2w and p2w[p] != w) or (w in w2p and w2p[w] != p):
                return False
            p2w[p] = w
            w2p[w] = p
        
        return True
```

## 复杂度分析

**方法一、二：哈希表**
- 时间复杂度：`O(n + m)` n 是 pattern 长度，m 是 s 长度
- 空间复杂度：`O(n)` 存储映射关系

**方法三：索引比较**
- 时间复杂度：`O(n^2)` index 方法是 O(n)
- 空间复杂度：`O(n)` 生成列表

## 关键点总结

1. **双向映射**：必须同时检查字符->单词和单词->字符两个方向
2. **长度检查**：pattern 和单词数量必须相等
3. **一一对应**：不能多对一，也不能一对多
4. **字符串分割**：使用 `split()` 分割单词
5. **映射冲突**：发现不一致立即返回 False

## 易错点

1. **忘记双向检查**：只检查字符到单词的映射，忘记检查反向
2. **长度不检查**：直接开始遍历，可能导致索引越界
3. **空格处理**：题目保证单词间只有单个空格，但需要使用 `split()`
4. **映射覆盖**：错误地允许映射被修改
5. **边界情况**：pattern 或 s 为空的情况

## 测试用例分析

```python
# 正常匹配
```
