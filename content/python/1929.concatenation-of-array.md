## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，请你构建一个长度为 `2n` 的答案数组 `ans`，使得 `ans` 的前 `n` 个元素和后 `n` 个元素都与 `nums` 相同。

具体而言，`ans[i] == nums[i]` 且 `ans[i + n] == nums[i]`（`0 <= i < n`）。

**示例 1：**
```
输入：nums = [1, 2, 1]
输出：[1, 2, 1, 1, 2, 1]
```

**示例 2：**
```
输入：nums = [1, 3, 2, 1]
输出：[1, 3, 2, 1, 1, 3, 2, 1]
```

**提示：**
- `n == nums.length`
- `1 <= n <= 1000`
- `1 <= nums[i] <= 1000`

---

## 解题思路

### 核心思想：直接拼接

将 `nums` 与自身拼接即可，Python 中列表相加运算 `nums + nums` 直接实现。

---

## 代码实现

### 方法一：列表拼接（推荐，最简洁）

```python
from typing import List

class Solution:
    def getConcatenation(self, nums: List[int]) -> List[int]:
        # 直接将 nums 与自身拼接
        return nums + nums
```

### 方法二：循环构建

```python
from typing import List

class Solution:
    def getConcatenation(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * (2 * n)
        for i in range(n):
            ans[i] = nums[i]        # 前半部分
            ans[i + n] = nums[i]    # 后半部分
        return ans
```

### 方法三：列表推导

```python
from typing import List

class Solution:
    def getConcatenation(self, nums: List[int]) -> List[int]:
        # 使用乘法运算符重复列表（效果同 nums + nums）
        return nums * 2
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(n) |
| 方法二 | O(n) | O(n) |
| 方法三 | O(n) | O(n) |

---

## 关键点总结

1. 直接用 `nums + nums` 或 `nums * 2` 是最简洁的 Python 写法
2. 两者等价，都创建新列表，不修改原列表

---

## 易错点

- `nums * 2` 是列表的浅复制，对于整数元素没有问题，但如果元素是可变对象（如列表）需注意
- 本题元素为整数，无此问题
