## 题目描述

如果一个密码满足以下所有条件，则认为它是一个**强密码**：

1. 长度至少为 8。
2. 包含至少一个小写字母。
3. 包含至少一个大写字母。
4. 包含至少一个数字。
5. 包含至少一个特殊字符（`!@#$%^&*()-+`）。
6. 不包含两个**相邻**的相同字符。

给你一个字符串 `password`，如果满足强密码条件返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：password = "IloveLe3tcode!"
输出：true
```

**示例 2：**
```
输入：password = "Me+You--IsMyDream"
输出：false（相邻两个 '--'）
```

## 解题思路

逐条检验六个条件即可，用集合或 `any()` 简化代码。

## 代码实现

### 方法一：逐条检验（推荐）

```python
class Solution:
    def strongPasswordCheckerII(self, password: str) -> bool:
        SPECIAL = set("!@#$%^&*()-+")

        if len(password) < 8:
            return False

        has_lower = any(c.islower() for c in password)
        has_upper = any(c.isupper() for c in password)
        has_digit = any(c.isdigit() for c in password)
        has_special = any(c in SPECIAL for c in password)

        # 检查相邻字符不相同
        no_adjacent = all(password[i] != password[i + 1]
                          for i in range(len(password) - 1))

        return has_lower and has_upper and has_digit and has_special and no_adjacent
```

### 方法二：标志位法

```python
class Solution:
    def strongPasswordCheckerII(self, password: str) -> bool:
        SPECIAL = "!@#$%^&*()-+"
        if len(password) < 8:
            return False

        lower = upper = digit = special = False
        for c in password:
            if c.islower():
                lower = True
            elif c.isupper():
                upper = True
            elif c.isdigit():
                digit = True
            elif c in SPECIAL:
                special = True

        if not (lower and upper and digit and special):
            return False

        # 检查相邻字符
        for i in range(len(password) - 1):
            if password[i] == password[i + 1]:
                return False

        return True
```

## 复杂度分析

- 时间复杂度：O(n)，遍历密码字符串。
- 空间复杂度：O(1)，常数空间。

## 关键点总结

1. 六个条件逐一检验，用 `any()` 简洁实现字符类型检查。
2. 相邻字符检查：遍历相邻对，发现相同则返回 `false`。
3. 特殊字符集合：`"!@#$%^&*()-+"`，注意包含哪些符号。

## 易错点

- 特殊字符集合要和题目一致，不要遗漏或多加。
- 条件 6 是不含两个**相邻**相同字符，不是不含重复字符。
