## 题目描述

给你一个整数 `n`（城市数量，编号 0 到 n-1），一个整数 `k`，以及一个整数数组 `highways`，`highways[i] = [city1_i, city2_i, toll_i]` 表示城市 `city1_i` 和 `city2_i` 之间有一条高速公路，过路费为 `toll_i`（无向）。

你需要选择一条**恰好经过 k 条**高速公路的路径（可以重复经过城市，但每条路径的起止城市可以是任意的），使得路径上的过路费之和**最大**。

返回这条路径的最大过路费，若不存在，返回 -1。

**提示：**
- `2 <= n <= 15`
- `k <= 50`
- `1 <= toll_i <= 100`

## 解题思路

n 最多 15，路径可以重复经过城市，要找恰好 k 条边的最大权路径。

**状态压缩 DP：**
- `dp[mask][v]`：经过的城市集合为 `mask`，当前在城市 `v`，所经过的最大过路费总和。
- 城市可以重复经过，但用 mask 追踪已访问过的城市集合（不是必须全覆盖）。

等等，由于城市可以重复，mask 表示经过的边数更合适。但 k 可达 50，而 mask 只能表示 2^15 种状态。

实际上，由于 n <= 15，且路径可以重复，但状态压缩 DP 是：`dp[steps][city]` = 恰好走了 `steps` 条边到达 `city` 的最大代价。但这样 steps 可达 50，时间 O(k * n^2)，可行。

**另一种状压**：`dp[mask][v]` = 访问过集合 mask（只包含已访问城市）且当前在 v 的最大代价，mask 中的位数等于经过的边数 + 1（路径长度 = mask.bit_count()）。这只适合不重复路径。

**正确解法**：由于可以重复经过，用简单 DP：`dp[i][j]` = 走了 i 条边，当前在城市 j 的最大代价。但由于可以重复，这个 DP 会漏掉中间状态。

实际上题目 n <= 15，k <= 50，直接 `dp[step][city]` O(k * n * n) = O(50 * 15 * 15) 是可行的，不需要状压。

## 代码实现

### 方法一：DP（步数 * 城市）

```python
from typing import List

class Solution:
    def maximumCost(self, n: int, highways: List[List[int]], k: int) -> int:
        INF = float('-inf')

        # 建邻接表
        adj = [[] for _ in range(n)]
        for u, v, toll in highways:
            adj[u].append((v, toll))
            adj[v].append((u, toll))

        # dp[city] = 走了当前步数，到达 city 的最大代价
        dp = [INF] * n

        # 初始状态：从任意城市出发（走了0条边）
        for i in range(n):
            dp[i] = 0

        for step in range(k):
            new_dp = [INF] * n
            for u in range(n):
                if dp[u] == INF:
                    continue
                for v, toll in adj[u]:
                    if dp[u] + toll > new_dp[v]:
                        new_dp[v] = dp[u] + toll
            dp = new_dp

        ans = max(dp)
        return ans if ans != INF else -1
```

### 方法二：状态压缩 DP（适合不重复路径）

```python
from typing import List

class Solution:
    def maximumCost(self, n: int, highways: List[List[int]], k: int) -> int:
        # 建邻接矩阵
        INF = float('-inf')
        graph = [[INF] * n for _ in range(n)]
        for u, v, toll in highways:
            graph[u][v] = max(graph[u][v], toll)
            graph[v][u] = max(graph[v][u], toll)

        # dp[mask][v]：访问集合 mask，当前在 v，最大代价
        # mask 的 bit 数 = 路径上城市数（路径上城市不重复时）
        # 路径有 k 条边，经过 k+1 个城市（可能重复）
        # 对于本题允许重复，用 step 方法更简单
        # 这里展示状压版（不允许重复城市）

        dp = [[INF] * n for _ in range(1 << n)]
        for i in range(n):
            dp[1 << i][i] = 0

        ans = INF
        for mask in range(1 << n):
            cnt = bin(mask).count('1')
            if cnt > k + 1:
                continue
            for u in range(n):
                if not (mask >> u & 1) or dp[mask][u] == INF:
                    continue
                for v in range(n):
                    if mask >> v & 1:
                        continue
                    if graph[u][v] == INF:
                        continue
                    new_mask = mask | (1 << v)
                    new_cost = dp[mask][u] + graph[u][v]
                    if new_cost > dp[new_mask][v]:
                        dp[new_mask][v] = new_cost
                    if cnt == k:  # 路径有 k 条边
                        ans = max(ans, new_cost)

        return ans if ans != INF else -1
```

## 复杂度分析

**方法一（步数 DP）：**
- 时间复杂度：O(k * (n + m))，m 为边数。
- 空间复杂度：O(n)。

**方法二（状压）：**
- 时间复杂度：O(2^n * n^2)。
- 空间复杂度：O(2^n * n)。

## 关键点总结

1. 题目允许重复经过城市，方法一的步数 DP 直接处理。
2. 状压 DP 适合不重复城市的哈密顿路径问题。
3. 初始状态：从任意城市出发，cost = 0。

## 易错点

- 题目允许重复经过城市，不能用普通的状压 DP（会漏掉重复情况）。
- 方法一中 `new_dp` 必须初始化为 INF（负无穷），避免到不了的城市污染结果。
