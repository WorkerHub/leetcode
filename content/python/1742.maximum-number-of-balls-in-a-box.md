## 题目描述

你在整理一些带编号的球，准备把它们放进盒子里。球的编号范围是 `lowLimit` 到 `highLimit`（包括 `lowLimit` 和 `highLimit`），且每个编号的球正好有一个。

盒子的编号是这个球各位数字之和。例如，编号 `321` 的球放进编号 `3 + 2 + 1 = 6` 的盒子。

请你返回装球数量**最多**的盒子的球数。

**示例 1：**
```
输入：lowLimit = 1, highLimit = 10
输出：2
解释：盒子1中有2个球（编号1和10，因为1+0=1）
```

**提示：**
- `1 <= lowLimit <= highLimit <= 10^5`

## 解题思路

枚举每个球的编号，计算各位数字之和，用哈希表统计每个盒子中的球数，最后返回最大值。

数字各位之和的最大值：`99999` 的各位之和 = `9*5 = 45`，所以盒子编号范围 1-45。

## 代码实现

### 方法一：哈希表统计（推荐）

```python
from collections import defaultdict

class Solution:
    def countBalls(self, lowLimit: int, highLimit: int) -> int:
        box_count = defaultdict(int)
        
        for num in range(lowLimit, highLimit + 1):
            # 计算各位数字之和
            digit_sum = sum(int(d) for d in str(num))
            box_count[digit_sum] += 1
        
        return max(box_count.values())
```

### 方法二：数组统计（更快）

```python
class Solution:
    def countBalls(self, lowLimit: int, highLimit: int) -> int:
        # 盒子编号最大为 45（99999的各位之和）
        boxes = [0] * 46
        
        for num in range(lowLimit, highLimit + 1):
            # 逐位累加
            s, n = 0, num
            while n:
                s += n % 10
                n //= 10
            boxes[s] += 1
        
        return max(boxes)
```

## 复杂度分析

- **时间复杂度**：O((highLimit - lowLimit) * log(highLimit))，计算各位数字之和
- **空间复杂度**：O(45) = O(1)，盒子数量固定

## 关键点总结

1. 各位数字之和作为哈希表的键
2. 最大盒子编号不超过 45

## 易错点

- 注意 `highLimit` 包含在范围内
