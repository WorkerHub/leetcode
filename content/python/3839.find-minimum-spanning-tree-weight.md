## 题目描述

给你一个有 `n` 个节点（编号 0 到 n-1）的无向加权图和一组边 `edges[i] = [u, v, w]`，返回该图的最小生成树的总权重。如果图不连通则返回 -1。

**示例 1：**

```
输入：n = 4, edges = [[0,1,1],[1,2,2],[2,3,3],[0,3,4]]
输出：6
解释：MST 为 {(0,1,1),(1,2,2),(2,3,3)}，权重和 = 6。
```

**示例 2：**

```
输入：n = 3, edges = [[0,1,5],[1,2,3]]
输出：8
解释：MST 为所有边，权重 5+3=8。
```

**提示：**
- `2 <= n <= 2 * 10^5`
- `1 <= edges.length <= 5 * 10^5`
- `1 <= w <= 10^9`

## 解题思路

经典最小生成树问题，使用 **Kruskal 算法**（按边权排序 + 并查集）或 **Prim 算法**（优先队列）。

Kruskal 步骤：
1. 将所有边按权重从小到大排序。
2. 遍历每条边，若两端点不在同一连通分量，则加入 MST 并合并。
3. 若最终 MST 包含 n-1 条边，返回总权重；否则返回 -1。

## Python 代码实现

### 方法一：Kruskal + 并查集（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        # 按秩合并
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        self.components -= 1
        return True


class Solution:
    def minimumSpanningTree(self, n: int, edges: List[List[int]]) -> int:
        uf = UnionFind(n)
        edges.sort(key=lambda x: x[2])  # 按权重排序

        total_weight = 0
        edges_used = 0

        for u, v, w in edges:
            if uf.union(u, v):
                total_weight += w
                edges_used += 1
                if edges_used == n - 1:
                    break  # MST 完成

        # 检查图是否连通
        return total_weight if edges_used == n - 1 else -1
```

### 方法二：Prim 算法（稠密图更优）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumSpanningTree(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((w, v))
            graph[v].append((w, u))

        visited = [False] * n
        heap = [(0, 0)]  # (权重, 节点)
        total = 0
        count = 0

        while heap and count < n:
            w, u = heapq.heappop(heap)
            if visited[u]:
                continue
            visited[u] = True
            total += w
            count += 1
            for cost, v in graph[u]:
                if not visited[v]:
                    heapq.heappush(heap, (cost, v))

        return total if count == n else -1
```

## 复杂度分析

- 时间复杂度：O(m log m)（Kruskal）；O((n + m) log n)（Prim）
- 空间复杂度：O(n + m)

## 关键点总结

1. Kruskal 适合稀疏图，按边排序，用并查集检测环。
2. Prim 适合稠密图，从任意节点出发，用优先队列选最小边。
3. MST 恰好包含 n-1 条边，若最终边数不足则图不连通。

## 易错点

1. 并查集路径压缩和按秩合并缺一不可，否则效率低。
2. Kruskal 中排序后需逐边检查，不能跳过。
3. 图可能不连通，必须检查最终 MST 边数是否为 n-1。
