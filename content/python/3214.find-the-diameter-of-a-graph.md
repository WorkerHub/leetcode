## 题目描述

给你一个无向图，节点编号从 `0` 到 `n-1`，以及一个二维整数数组 `edges`，其中 `edges[i] = [ui, vi, wi]` 表示节点 `ui` 和 `vi` 之间有一条权重为 `wi` 的边。

返回图的**直径**——即图中最短路径最长的两点之间的距离。假设图是连通的。

**示例 1：**
```
输入：n = 4, edges = [[0,1,1],[1,2,1],[2,3,1]]
输出：3
```

**示例 2：**
```
输入：n = 4, edges = [[0,1,1],[0,2,1],[0,3,1]]
输出：2
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= edges.length <= 10^4`
- `edges[i].length == 3`
- `0 <= ui, vi < n`
- `1 <= wi <= 10^6`
- 图是连通的，没有重复边

## 解题思路

图的直径：所有节点对之间最短路径的最大值。

对于带权图，使用 Dijkstra 算法求从每个节点出发的最短路径，取最大值。但 O(n * (n + m) log n) 对大图会超时。

更优方法：两次 BFS/Dijkstra（类似树的直径求法）在一般图上不一定正确，但对于树形结构有效。

本题是一般图，需要对每个节点做 Dijkstra，或者用 Floyd-Warshall 全对最短路。

由于 n 较小（≤ 10^4），可以从两个端点做两次 Dijkstra。

## Python 代码实现

### 方法一：Dijkstra 多源（推荐）

```python
from typing import List
import heapq

class Solution:
    def findDiameter(self, n: int, edges: List[List[int]]) -> int:
        graph = [[] for _ in range(n)]
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))
        
        def dijkstra(start):
            dist = [float('inf')] * n
            dist[start] = 0
            heap = [(0, start)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in graph[u]:
                    if dist[u] + w < dist[v]:
                        dist[v] = dist[u] + w
                        heapq.heappush(heap, (dist[v], v))
            return dist
        
        # 两次 Dijkstra：先从节点 0 找最远点，再从最远点找直径
        dist0 = dijkstra(0)
        far1 = max(range(n), key=lambda x: dist0[x])
        dist1 = dijkstra(far1)
        return max(dist1)
```

### 方法二：Floyd-Warshall（适合小图）

```python
from typing import List

class Solution:
    def findDiameter(self, n: int, edges: List[List[int]]) -> int:
        INF = float('inf')
        dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            dist[i][i] = 0
        for u, v, w in edges:
            dist[u][v] = min(dist[u][v], w)
            dist[v][u] = min(dist[v][u], w)
        
        # Floyd-Warshall
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]
        
        ans = 0
        for i in range(n):
            for j in range(n):
                if dist[i][j] != INF:
                    ans = max(ans, dist[i][j])
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O((n + m) log n)，空间复杂度 O(n + m)
- 方法二：时间复杂度 O(n^3)，空间复杂度 O(n^2)，适合 n ≤ 500

## 关键点总结

1. 图的直径是所有节点对最短路径的最大值
2. 两次 Dijkstra 方法在树上一定正确，一般图上也常用
3. 连通图上从任意点出发找最远点，再从最远点找直径

## 易错点

1. 图可能有多条边，需要取最小权重
2. Floyd-Warshall 对大图内存和时间都不够
