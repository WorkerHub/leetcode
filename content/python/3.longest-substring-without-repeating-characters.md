## 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。

**示例 1：**
```
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3
```

**示例 2：**
```
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1
```

**示例 3：**
```
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3
请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串
```

**提示：**
- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

## 解题思路

核心思想：滑动窗口 + 哈希表

**关键步骤：**
1. 使用双指针维护一个滑动窗口
2. 使用哈希表记录字符最后出现的位置
3. 遇到重复字符时，移动左指针
4. 不断更新最大长度

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 记录字符最后出现的位置
        char_index = {}
        max_len = 0
        left = 0
        
        for right, char in enumerate(s):
            # 如果字符已出现且在当前窗口内
            if char in char_index and char_index[char] >= left:
                # 移动左指针到重复字符的下一个位置
                left = char_index[char] + 1
            
            # 更新字符位置
            char_index[char] = right
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

### 方法二：使用集合

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        char_set = set()
        left = 0
        max_len = 0
        
        for right, char in enumerate(s):
            # 如果遇到重复字符，移除左边字符直到没有重复
            while char in char_set:
                char_set.remove(s[left])
                left += 1
            
            # 添加当前字符
            char_set.add(char)
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

### 方法三：优化的滑动窗口

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 使用数组代替哈希表（ASCII字符）
        last_index = [-1] * 128
        max_len = 0
        left = 0
        
        for right, char in enumerate(s):
            # 更新左指针
            left = max(left, last_index[ord(char)] + 1)
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
            
            # 更新字符最后出现位置
            last_index[ord(char)] = right
        
        return max_len
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)
- 空间复杂度：O(min(m, n))，m 为字符集大小

## 图解示例

以 `s = "abcabcbb"` 为例：

```
初始：left = 0, right = 0
a -> {a}, max_len = 1
ab -> {a,b}, max_len = 2
abc -> {a,b,c}, max_len = 3
abca -> 遇到重复'a'，left移到1, {b,c,a}, max_len = 3
...
```

## 关键点总结

1. **滑动窗口**：双指针维护无重复字符的窗口
2. **哈希表**：快速查找字符是否在窗口内
3. **左指针移动**：跳到重复字符的下一个位置
4. **实时更新**：每次移动右指针都更新最大长度

## 易错点

1. **左指针更新**：`left = max(left, char_index[char] + 1)`，不能直接赋值
2. **索引含义**：`char_index` 存的是索引，不是次数
3. **边界情况**：空字符串返回 0
