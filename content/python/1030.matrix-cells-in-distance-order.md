## 题目描述

给定四个整数 `rows`、`cols`、`rCenter` 和 `cCenter`。有一个 `rows x cols` 的矩阵，你在单元格 `[rCenter, cCenter]` 上。

返回矩阵中的所有单元格的坐标 `[r, c]`，按照它们与 `[rCenter, cCenter]` 的曼哈顿距离从最小到最大的顺序排列。

两个单元格 `(r1, c1)` 和 `(r2, c2)` 之间的曼哈顿距离为 `|r1 - r2| + |c1 - c2|`。

你可以按任何满足此条件的顺序返回答案。

**示例 1：**

```
输入: rows = 1, cols = 2, rCenter = 0, cCenter = 0
输出: [[0,0],[0,1]]
解释: 距离 [0,0] 和 [0,1] 的距离分别为 0 和 1
```

**示例 2：**

```
输入: rows = 2, cols = 2, rCenter = 0, cCenter = 1
输出: [[0,1],[0,0],[1,1],[1,0]]
解释: 距离 [0,1], [0,0], [1,1], [1,0] 的距离分别为 0, 1, 1, 2
按照距离从小到大排列，相同距离的顺序任意
```

**示例 3：**

```
输入: rows = 2, cols = 3, rCenter = 1, cCenter = 2
输出: [[1,2],[0,2],[1,1],[0,1],[1,0],[0,0]]
解释: 距离排序结果为 0, 1, 1, 2, 2, 3
可以有多种满足条件的答案顺序
```

**提示：**

- `1 <= rows, cols <= 100`
- `0 <= rCenter < rows`
- `0 <= cCenter < cols`

## 解题思路

这道题的核心是计算曼哈顿距离并按距离排序。有多种解法：

1. **直接排序法**：生成所有坐标，计算每个坐标到中心点的曼哈顿距离，然后排序
2. **BFS 广度优先搜索**：从中心点开始，按层扩展，自然按距离顺序访问所有单元格
3. **桶排序优化**：因为曼哈顿距离范围有限，可以用桶排序优化

关键观察：
- 曼哈顿距离的最大值为 `(rows - 1) + (cols - 1)`
- 相同距离的单元格可以任意顺序排列
- BFS 天然按距离层次访问，无需排序

## Python 代码实现

### 方法一：直接排序法（推荐新手）

```python
from typing import List

class Solution:
    def allCellsDistOrder(self, rows: int, cols: int, rCenter: int, cCenter: int) -> List[List[int]]:
        """
        生成所有坐标，计算曼哈顿距离后排序
        
        时间复杂度: O(RC * log(RC))，其中 R 是行数，C 是列数
        空间复杂度: O(RC)
        """
        # 生成所有单元格坐标
        cells = []
        for r in range(rows):
            for c in range(cols):
                cells.append([r, c])
        
        # 定义曼哈顿距离计算函数
        def manhattan_distance(cell):
            return abs(cell[0] - rCenter) + abs(cell[1] - cCenter)
        
        # 按曼哈顿距离排序
        cells.sort(key=manhattan_distance)
        
        return cells
```

### 方法二：使用 Lambda 表达式简化

```python
from typing import List

class Solution:
    def allCellsDistOrder(self, rows: int, cols: int, rCenter: int, cCenter: int) -> List[List[int]]:
        """
        使用列表推导式和 lambda 表达式的简洁写法
        
        时间复杂度: O(RC * log(RC))
        空间复杂度: O(RC)
        """
        # 生成所有坐标并按曼哈顿距离排序
        cells = [[r, c] for r in range(rows) for c in range(cols)]
        cells.sort(key=lambda cell: abs(cell[0] - rCenter) + abs(cell[1] - cCenter))
        return cells
```

### 方法三：BFS 广度优先搜索（最优解）

```python
from typing import List
from collections import deque

class Solution:
    def allCellsDistOrder(self, rows: int, cols: int, rCenter: int, cCenter: int) -> List[List[int]]:
        """
        使用 BFS 从中心点扩展，自然按距离顺序访问
        
        时间复杂度: O(RC)
        空间复杂度: O(RC)
        """
        result = []
        visited = [[False] * cols for _ in range(rows)]
        queue = deque([[rCenter, cCenter]])
        visited[rCenter][cCenter] = True
        
        # 四个方向：上、下、左、右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        while queue:
            r, c = queue.popleft()
            result.append([r, c])
            
            # 扩展四个方向
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                # 检查边界和是否已访问
                if 0 <= nr < rows and 0 <= nc < cols and not visited[nr][nc]:
                    visited[nr][nc] = True
                    queue.append([nr, nc])
        
        return result
```

### 方法四：桶排序优化

```python
from typing import List

class Solution:
    def allCellsDistOrder(self, rows: int, cols: int, rCenter: int, cCenter: int) -> List[List[int]]:
        """
        使用桶排序，将相同距离的坐标放入同一个桶
        
        时间复杂度: O(RC)
        空间复杂度: O(RC)
        """
        # 最大曼哈顿距离
        max_dist = (rows - 1) + (cols - 1)
        
        # 创建桶，索引表示距离
        buckets = [[] for _ in range(max_dist + 1)]
        
        # 将每个坐标放入对应距离的桶中
        for r in range(rows):
            for c in range(cols):
                dist = abs(r - rCenter) + abs(c - cCenter)
                buckets[dist].append([r, c])
        
        # 按距离顺序合并所有桶
        result = []
        for bucket in buckets:
            result.extend(bucket)
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 直接排序 | O(RC log(RC)) | O(RC) | 简单直观，适合新手 |
| BFS | O(RC) | O(RC) | 无需排序，时间最优 |
| 桶排序 | O(RC) | O(RC) | 利用距离范围有限的特性 |

其中 R 是矩阵行数，C 是矩阵列数。

## 关键点总结

1. 曼哈顿距离公式：`|r1 - r2| + |c1 - c2|`
2. 排序方法简单直观，适合快速实现
3. BFS 方法最优雅，天然按距离层次访问
4. 桶排序利用了距离范围有限的特性，时间复杂度最优
5. 相同距离的单元格顺序可以任意排列

## 易错点

1. **边界条件**：注意 `rCenter` 和 `cCenter` 的范围检查
2. **BFS 访问标记**：使用 visited 数组避免重复访问
3. **排序 key 函数**：确保正确计算曼哈顿距离
4. **桶的大小**：最大距离为 `(rows - 1) + (cols - 1)`，需要 `max_dist + 1` 个桶
5. **坐标格式**：返回的是二维数组 `[[r, c]]`，不是元组
