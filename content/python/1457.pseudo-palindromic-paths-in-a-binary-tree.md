## 题目描述

给你一棵二叉树，每个节点的值为 1 到 9 。我们称二叉树中的一条路径是**「伪回文路径」**，如果路径经过的所有节点值的排列中，存在一个回文序列。

请你返回从根到叶节点的所有路径中**伪回文路径**的数目。

**示例 1：**
```
输入：root = [2,3,1,3,1,null,1]
输出：2
解释：上图为给定的二叉树，每个叶节点对应一条根到叶的路径。
路径 [2,3,3] 可以重排为回文 [3,2,3]，是伪回文路径。
路径 [2,1,1] 可以重排为回文 [1,2,1]，是伪回文路径。
路径 [2,3,1] 不能重排为回文，不是伪回文路径。
```

**示例 2：**
```
输入：root = [2,1,1,1,3,null,null,null,null,null,1]
输出：1
```

**提示：**
- 给定二叉树的节点数目在 1 到 10^5 之间
- 1 <= Node.val <= 9

## 解题思路

**什么是伪回文路径？**

一条路径可以重排成回文，当且仅当路径上的数字中，**奇数次出现的数字最多只有一个**（回文中心可以有一个奇数次出现的字符，其余都必须是偶数次）。

**位掩码技巧：**

用一个整数的二进制位来追踪每个数字出现次数的奇偶性：
- 第 d 位（bit d）为 1 表示数字 d 出现了奇数次
- 第 d 位为 0 表示数字 d 出现了偶数次
- 每遇到数字 d，对掩码执行 `mask ^= (1 << d)`（异或翻转）

到达叶节点时，检查掩码：
- `mask == 0`：所有数字出现偶数次，可以排成回文
- `mask & (mask - 1) == 0`：恰好只有一位为 1（只有一个数字出现奇数次），也可以排成回文

**核心条件：** `mask == 0 or mask & (mask - 1) == 0`

等价于 `mask & (mask - 1) == 0`（因为 mask=0 时，0 & (-1) 不对，所以要单独判断，或者用 `bin(mask).count('1') <= 1`）。

## Python 代码实现

### 方法一：DFS + 位掩码（推荐）

```python
from typing import Optional

# 二叉树节点定义
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def pseudoPalindromicPaths(self, root: Optional[TreeNode]) -> int:
        self.count = 0

        def dfs(node: Optional[TreeNode], mask: int) -> None:
            if node is None:
                return

            # 翻转当前数字对应的位
            mask ^= (1 << node.val)

            if node.left is None and node.right is None:
                # 到达叶节点，检查是否为伪回文路径
                # 掩码中最多只有一位为 1（奇数次出现的数字 <= 1）
                if mask == 0 or (mask & (mask - 1)) == 0:
                    self.count += 1
                return

            # 继续向下递归
            dfs(node.left, mask)
            dfs(node.right, mask)

        dfs(root, 0)
        return self.count
```

### 方法二：DFS 返回值（不用实例变量）

```python
from typing import Optional

class Solution:
    def pseudoPalindromicPaths(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], mask: int) -> int:
            if node is None:
                return 0

            # 翻转当前数字对应的位
            mask ^= (1 << node.val)

            # 叶节点：判断伪回文
            if node.left is None and node.right is None:
                # mask 是 2 的幂（或为 0）则满足条件
                return 1 if mask & (mask - 1) == 0 else 0

            # 左右子树的结果相加
            return dfs(node.left, mask) + dfs(node.right, mask)

        return dfs(root, 0)
```

### 方法三：迭代 DFS（用栈，避免递归栈溢出）

```python
from typing import Optional

class Solution:
    def pseudoPalindromicPaths(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        count = 0
        # 栈中存储 (节点, 当前路径掩码)
        stack = [(root, 0)]

        while stack:
            node, mask = stack.pop()
            # 翻转当前节点对应的位
            mask ^= (1 << node.val)

            if node.left is None and node.right is None:
                # 叶节点：检查伪回文条件
                if mask & (mask - 1) == 0:
                    count += 1
            else:
                # 将左右子节点入栈
                if node.left:
                    stack.append((node.left, mask))
                if node.right:
                    stack.append((node.right, mask))

        return count
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树的高度（递归栈深度），最坏 O(n)（退化为链表）

## 图解示例

以示例 1 为例，`root = [2,3,1,3,1,null,1]`：

```
路径 [2,3,3]：mask 变化
  遇到 2：mask = 0b0000000100 = 4
  遇到 3：mask = 0b0000001100 = 12
  遇到 3：mask = 0b0000000100 = 4  (翻转，3 出现偶数次被消除)
  实际：mask = 1<<2 = 4，只有数字 2 出现奇数次
  4 & 3 = 0b100 & 0b011 = 0 -> 伪回文！

路径 [2,3,1]：
  遇到 2：mask ^= (1<<2) = 4
  遇到 3：mask ^= (1<<3) = 12
  遇到 1：mask ^= (1<<1) = 14 = 0b1110
  14 & 13 = 0b1110 & 0b1101 = 0b1100 != 0 -> 不是伪回文
```

## 关键点总结

1. 回文条件：奇数次出现的数字个数 <= 1
2. 位掩码用异或追踪奇偶性：遇到数字 d 就 `mask ^= (1 << d)`
3. 判断 mask 最多一位为 1：`mask & (mask - 1) == 0`（包含 mask=0 的情况）
4. 把掩码作为参数传递（不修改），DFS 回溯时无需恢复状态

## 易错点

- `mask & (mask - 1) == 0` 同时处理了 `mask == 0` 的情况（0 & (-1) 在 Python 中...需要特别注意，Python 的 -1 是无限精度整数）
- 实际上在 Python 中，`0 & (0 - 1)` = `0 & -1` = `0`，所以 `mask & (mask - 1) == 0` 对 mask=0 也成立
- 节点值从 1 到 9，所以用 `1 << node.val` 无需担心 bit 0
