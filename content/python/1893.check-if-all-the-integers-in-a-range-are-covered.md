## 题目描述

给你一个二维整数数组 `ranges` 和两个整数 `left` 和 `right`，其中 `ranges[i] = [starti, endi]` 表示一个区间。

判断 `[left, right]` 范围内的**每个**整数是否都被 `ranges` 中**至少一个**区间覆盖。

若是，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：ranges = [[1,2],[3,4],[5,6]], left = 2, right = 5
输出：true
解释：[2,2] 被 [1,2] 覆盖，[3,4] 被 [3,4] 覆盖，[5,5] 被 [5,6] 覆盖
```

**示例 2：**
```
输入：ranges = [[1,10],[10,20]], left = 21, right = 21
输出：false
```

**提示：**
- `1 <= ranges.length <= 50`
- `1 <= starti <= endi <= 50`
- `1 <= left <= right <= 50`

## 解题思路

**方法一：暴力检查**

由于数据范围小（1-50），直接枚举 `[left, right]` 的每个整数，检查是否被至少一个区间覆盖。

**方法二：差分数组**

使用差分数组标记覆盖情况，对每个区间 `[s, e]`，在差分数组上 `diff[s]++`, `diff[e+1]--`，前缀和后若所有位置 >= 1 则覆盖。

## 代码实现

### 方法一：暴力枚举（推荐，简单直接）

```python
from typing import List

class Solution:
    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:
        for num in range(left, right + 1):
            # 检查 num 是否被至少一个区间覆盖
            covered = False
            for start, end in ranges:
                if start <= num <= end:
                    covered = True
                    break
            if not covered:
                return False
        return True
```

### 方法二：差分数组

```python
from typing import List

class Solution:
    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:
        # 差分数组，下标范围 1~51
        diff = [0] * 52

        # 对每个区间进行差分标记
        for start, end in ranges:
            diff[start] += 1
            diff[end + 1] -= 1

        # 计算前缀和（覆盖次数）
        cover = 0
        for i in range(1, 51):
            cover += diff[i]
            # 检查 [left, right] 内每个数是否被覆盖
            if left <= i <= right and cover <= 0:
                return False

        return True
```

### 方法三：集合法

```python
from typing import List

class Solution:
    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:
        # 收集所有被覆盖的整数
        covered = set()
        for start, end in ranges:
            for x in range(start, end + 1):
                covered.add(x)

        # 检查 [left, right] 是否完全被覆盖
        return all(x in covered for x in range(left, right + 1))
```

## 复杂度分析

- **方法一**：时间 O(n * (right-left))，空间 O(1)
- **方法二（差分）**：时间 O(n + 50)，空间 O(50)
- **方法三**：时间 O(n * 50)，空间 O(50)

## 关键点总结

1. 数据范围小（1-50），暴力完全可行
2. 差分数组适合区间覆盖统计：`diff[l]++, diff[r+1]--`，前缀和即覆盖次数
3. 用集合收集所有覆盖点是最直观的方法

## 易错点

- 差分数组的 `diff[end+1]--` 中 `end+1` 不要越界
- 前缀和累积时注意顺序，要从小到大
