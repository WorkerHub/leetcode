## 题目描述

给你一个字符串 `s` 和一个二维整数数组 `queries`，其中 `queries[i] = [li, ri]`。

对于每个查询，统计子字符串 `s[li..ri]` 中满足以下条件的子字符串数目：以相同字符开头和结尾。

返回每个查询的答案数组。

**示例 1：**
```
输入：s = "abcba", queries = [[0,2],[1,4],[2,3]]
输出：[7,9,3]
```

**示例 2：**
```
输入：s = "abacaba", queries = [[0,6],[1,4],[2,4]]
输出：[18,12,12]
```

**提示：**
- `2 <= s.length <= 3 * 10^4`
- `1 <= queries.length <= 3 * 10^4`
- `0 <= queries[i][0] <= queries[i][1] < s.length`
- `s` 只含小写英文字母

## 解题思路

预处理前缀计数：`cnt[c][i]` = 字符 c 在 s[0..i-1] 中出现的次数。

对于查询 [l, r]，字符 c 在 s[l..r] 中出现次数为 `freq[c] = cnt[c][r+1] - cnt[c][l]`。

以字符 c 开头和结尾的子字符串数 = C(freq[c], 2) + freq[c] = freq[c] * (freq[c] + 1) / 2（选两端相同字符的所有子字符串）。

等价地，选 2 个或 1 个（单字符子串开头=结尾）位置：`freq[c] * (freq[c] + 1) / 2`。

总答案 = sum over all c。

## Python 代码实现

### 方法一：前缀计数（推荐）

```python
from typing import List

class Solution:
    def sameEndSubstringCount(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        # cnt[c][i] = 字符 c 在 s[0..i-1] 中的出现次数
        cnt = [[0] * (n + 1) for _ in range(26)]
        for i, c in enumerate(s):
            for ch in range(26):
                cnt[ch][i + 1] = cnt[ch][i]
            cnt[ord(c) - ord('a')][i + 1] += 1

        result = []
        for l, r in queries:
            total = 0
            for ch in range(26):
                freq = cnt[ch][r + 1] - cnt[ch][l]
                total += freq * (freq + 1) // 2
            result.append(total)

        return result
```

### 方法二：二维前缀计数（更直观）

```python
from typing import List

class Solution:
    def sameEndSubstringCount(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        # prefix[i][c] = s[0..i-1] 中字符 c 的出现次数
        prefix = [[0] * 26 for _ in range(n + 1)]
        for i in range(n):
            prefix[i + 1] = prefix[i][:]
            prefix[i + 1][ord(s[i]) - ord('a')] += 1

        def query(l, r):
            ans = 0
            for c in range(26):
                freq = prefix[r + 1][c] - prefix[l][c]
                ans += freq * (freq + 1) // 2
            return ans

        return [query(l, r) for l, r in queries]
```

## 复杂度分析

- 时间复杂度：O(26 * (n + q))，预处理 O(26n)，每个查询 O(26)
- 空间复杂度：O(26n)，前缀计数数组

## 关键点总结

1. 以字符 c 开头和结尾的子字符串数 = freq_c * (freq_c + 1) / 2（包含长度 1 的单字符子串）
2. 预处理 26 个字符的前缀计数，可以 O(1) 查询任意区间的字符频率
3. 所有字符的贡献相加就是答案

## 易错点

1. 包含单字符子字符串（长度为 1 时也满足开头=结尾）
2. freq * (freq+1) / 2 是选 2 个或 1 个位置的方案数
3. 前缀计数复制时用 `prefix[i+1] = prefix[i][:]`（深拷贝）
