## 题目描述

给你一个由大小写英文字母组成的字符串 `s`。

一个字符串是**好字符串**当它不包含相邻字符同字母但不同大小写的组合（如 `'a'` 和 `'A'` 相邻，或 `'B'` 和 `'b'` 相邻）。

每次操作，可以选择一对满足上述条件的相邻字符并删除它们。

返回经过若干次操作后使字符串变成好字符串的结果（答案唯一）。

**示例 1：**
```
输入：s = "leEeetcode"
输出："leetcode"
解释："eE" 是一对，删除后得到 "leetcode"
```

**示例 2：**
```
输入：s = "abBAcC"
输出：""
```

**提示：**
- `1 <= s.length <= 100`

## 解题思路

### 栈模拟

遍历字符串，用栈维护已处理的字符：
- 若当前字符与栈顶字符"互为大小写"（同一字母，一大一小），则弹出栈顶（相当于删除这对字符）
- 否则，将当前字符入栈

最终栈中剩下的就是结果。

## 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def makeGood(self, s: str) -> str:
        stack = []
        for c in s:
            if stack and stack[-1] != c and stack[-1].lower() == c.lower():
                # 栈顶与当前字符同字母但大小写不同，互相消除
                stack.pop()
            else:
                stack.append(c)
        return ''.join(stack)
```

### 方法二：递归（每次找一对删除）

```python
class Solution:
    def makeGood(self, s: str) -> str:
        # 找到第一对相邻的"坏对"并删除，递归处理
        for i in range(len(s) - 1):
            if s[i] != s[i+1] and s[i].lower() == s[i+1].lower():
                return self.makeGood(s[:i] + s[i+2:])
        return s
```

### 方法三：循环迭代

```python
class Solution:
    def makeGood(self, s: str) -> str:
        changed = True
        while changed:
            changed = False
            new_s = []
            i = 0
            while i < len(s):
                if (i + 1 < len(s) and
                        s[i] != s[i+1] and
                        s[i].lower() == s[i+1].lower()):
                    # 跳过这对字符
                    i += 2
                    changed = True
                else:
                    new_s.append(s[i])
                    i += 1
            s = ''.join(new_s)
        return s
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（栈） | O(N) | O(N) |
| 方法二（递归） | O(N^2) | O(N) |
| 方法三（循环） | O(N^2) | O(N) |

## 关键点总结

1. 使用栈，一次遍历即可
2. 判断条件：`c1 != c2` 且 `c1.lower() == c2.lower()`（同字母不同大小写）
3. 栈方法保证了处理顺序的正确性

## 易错点

- 必须同时满足"不相等"和"小写相等"两个条件（不能用 `abs(ord(a)-ord(b)) == 32`，因为 `a` 和 `a` 本身不是坏对）
- 方法一中 `stack[-1] != c` 避免了相同字符（如 'a','a'）被误删
