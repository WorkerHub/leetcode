## 题目描述

你有无限枚价值为 1、2、6 的硬币（这是 2023 年的变体，实际题目使用特定面值）。

实际题意（3183）：你有无限枚硬币，面值为 1, 2, 6，另外还有一种特殊硬币数量有限。给定目标 `n`，返回用这些硬币凑成 `n` 的方案数，对 `10^6 + 3` 取模。

题目描述从 LeetCode 原题：给你一个整数 `n`，返回用面值为 1, 2, 6（无限）的硬币凑成 n 的方案数，对 `10^6 + 3` 取模。

**提示：**
- `1 <= n <= 10^4`

## 解题思路

经典完全背包问题，dp[i] = 凑成 i 的方案数。

## Python 代码实现

### 方法一：完全背包（推荐）

```python
class Solution:
    def numberOfWays(self, n: int) -> int:
        MOD = 10 ** 6 + 3
        coins = [1, 2, 6]
        dp = [0] * (n + 1)
        dp[0] = 1

        for c in coins:
            for i in range(c, n + 1):
                dp[i] = (dp[i] + dp[i - c]) % MOD

        return dp[n]
```

### 方法二：递归 + 记忆化

```python
from functools import lru_cache

class Solution:
    def numberOfWays(self, n: int) -> int:
        MOD = 10 ** 6 + 3
        coins = [1, 2, 6]

        @lru_cache(maxsize=None)
        def dp(remain: int, idx: int) -> int:
            if remain == 0:
                return 1
            if idx == len(coins) or remain < 0:
                return 0
            ans = 0
            c = coins[idx]
            for k in range(remain // c + 1):
                ans += dp(remain - k * c, idx + 1)
            return ans % MOD

        return dp(n, 0)
```

## 复杂度分析

- 时间复杂度：O(n * len(coins))
- 空间复杂度：O(n)

## 关键点总结

1. 完全背包：每种硬币可以用无限次
2. 外层遍历硬币，内层遍历金额（正序）
3. dp[0] = 1（凑成 0 有 1 种方法）

## 易错点

1. 完全背包内层正序遍历（01 背包倒序）
2. 注意取模
