## 题目描述

给你一个 8x8 的棋盘，上面有一个白色车（Rook）、一个白色象（Bishop）和一个黑色皇后（Queen）。

给你整数 `a`、`b` 表示白色车的位置，整数 `c`、`d` 表示白色象的位置，整数 `e`、`f` 表示黑色皇后的位置，其中 `(a, b)`、`(c, d)` 和 `(e, f)` 互不相同。

返回白方捕获黑色皇后所需的最少移动次数。

**示例 1：**
```
输入：a = 1, b = 1, c = 8, d = 8, e = 2, f = 3
输出：2
```

**示例 2：**
```
输入：a = 5, b = 3, c = 3, d = 4, e = 5, f = 2
输出：1
```

**提示：**
- `1 <= a, b, c, d, e, f <= 8`
- 两个棋子不在同一位置

## 解题思路

关键观察：答案只有 1 或 2。

1 步直接捕获的条件：
- 车与皇后同行且中间没有象阻挡
- 车与皇后同列且中间没有象阻挡
- 象与皇后在同一对角线且中间没有车阻挡

否则答案为 2（车总能通过两步到达任意位置）。

## Python 代码实现

### 方法一：枚举判断（推荐）

```python
class Solution:
    def minMovesToCaptureTheQueen(self, a: int, b: int, c: int, d: int, e: int, f: int) -> int:
        # 判断车能否一步吃掉皇后
        # 同行
        if a == e:
            # 判断象是否在车和皇后之间（同行）
            if not (c == a and min(b, f) < d < max(b, f)):
                return 1
        # 同列
        if b == f:
            # 判断象是否在车和皇后之间（同列）
            if not (d == b and min(a, e) < c < max(a, e)):
                return 1

        # 判断象能否一步吃掉皇后（同一对角线）
        if abs(c - e) == abs(d - f):
            # 判断车是否在象和皇后之间（对角线上）
            if not (abs(c - a) == abs(d - b) and
                    min(c, e) < a < max(c, e) and
                    min(d, f) < b < max(d, f)):
                return 1

        # 否则车两步必能捕获
        return 2
```

### 方法二：辅助函数简化

```python
class Solution:
    def minMovesToCaptureTheQueen(self, a: int, b: int, c: int, d: int, e: int, f: int) -> int:
        def between(x, lo, hi):
            # 判断 x 是否严格在 lo 和 hi 之间
            return min(lo, hi) < x < max(lo, hi)

        # 车同行攻击
        if a == e and not (c == a and between(d, b, f)):
            return 1
        # 车同列攻击
        if b == f and not (d == b and between(c, a, e)):
            return 1
        # 象同对角线攻击
        if abs(c - e) == abs(d - f):
            if not (abs(a - c) == abs(b - d) and between(a, c, e) and between(b, d, f)):
                return 1

        return 2
```

## 复杂度分析

- 时间复杂度：O(1)，棋盘固定大小，只做常数次判断
- 空间复杂度：O(1)

## 关键点总结

1. 答案只有 1 或 2，不可能是 0（初始不在同一位置）
2. 车沿行列移动，象沿对角线移动
3. 判断阻挡时，需要确认阻挡棋子严格在两者之间
4. 车两步内必能捕获：先移到皇后所在行或列，再直接攻击

## 易错点

1. 判断象阻挡车时，象必须在同一行/列上且在两者之间
2. 判断车阻挡象时，车必须在同一对角线上且在两者之间
3. `between` 要用严格不等号，端点（棋子自身位置）不算阻挡
