## 题目描述

给你一个二进制矩阵 `grid`，用 **3 个** 不重叠（可以共边）的矩形覆盖所有值为 1 的格子，返回这 3 个矩形 **面积之和** 的最小值。

**提示：**
- `1 <= m, n <= 30`
- `grid[i][j] == 0 or 1`

## 解题思路

由于矩阵最大 30x30，可以枚举如何将矩阵切分为 3 个部分：
1. 横切两刀（两条水平线，得到上中下 3 块）
2. 竖切两刀（两条垂直线，得到左中右 3 块）
3. 一横一竖（上下两块，其中一块再竖切；或左右两块，其中一块再横切）

共 6 种切法（横横、竖竖、横竖-上左、横竖-上右、横竖-下左、横竖-下右）。

## Python 代码实现

### 方法一：枚举切法（推荐）

```python
from typing import List

class Solution:
    def minimumSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')

        def min_rect(r1, r2, c1, c2):
            # 子矩阵 grid[r1:r2][c1:c2] 包含所有 1 的最小矩形面积
            min_r = m
            max_r = -1
            min_c = n
            max_c = -1
            for i in range(r1, r2):
                for j in range(c1, c2):
                    if grid[i][j] == 1:
                        min_r = min(min_r, i)
                        max_r = max(max_r, i)
                        min_c = min(min_c, j)
                        max_c = max(max_c, j)
            if max_r == -1:
                return 0  # 没有 1
            return (max_r - min_r + 1) * (max_c - min_c + 1)

        ans = INF

        # 方案1：横切两刀
        for i1 in range(1, m):
            for i2 in range(i1 + 1, m):
                a = min_rect(0, i1, 0, n)
                b = min_rect(i1, i2, 0, n)
                c = min_rect(i2, m, 0, n)
                ans = min(ans, a + b + c)

        # 方案2：竖切两刀
        for j1 in range(1, n):
            for j2 in range(j1 + 1, n):
                a = min_rect(0, m, 0, j1)
                b = min_rect(0, m, j1, j2)
                c = min_rect(0, m, j2, n)
                ans = min(ans, a + b + c)

        # 方案3：先横后竖（上块再竖切）
        for i in range(1, m):
            for j in range(1, n):
                a = min_rect(0, i, 0, j)
                b = min_rect(0, i, j, n)
                c = min_rect(i, m, 0, n)
                ans = min(ans, a + b + c)
                a = min_rect(0, i, 0, n)
                b = min_rect(i, m, 0, j)
                c = min_rect(i, m, j, n)
                ans = min(ans, a + b + c)

        return ans
```

## 复杂度分析

- 时间复杂度：O(m^2 * n * m + m * n^2 * n + m^2 * n^2) ≈ O(m^2 * n^2 * (m+n))，但 m,n <= 30 所以可行
- 空间复杂度：O(1)

## 关键点总结

1. 枚举 3 种切分方式（横横、竖竖、横竖）共 6 种情况
2. 对每个子区域，找包含所有 1 的最小矩形
3. 矩阵小（30x30），暴力枚举可行

## 易错点

1. 若某区域没有 1，面积为 0
2. 需要覆盖所有 1，不能遗漏
