## 题目描述

给定两个整数 `l` 和 `r`，统计区间 `[l, r]` 内各位数字非递减（即从高位到低位数字不减小）的整数个数。

**示例 1：**

```
输入：l = 10, r = 15
输出：2
解释：[11, 12, 13, 14, 15] 中，11 (1<=1), 12 (1<=2)... 满足的有 11, 12, 13, 14, 15，共5个。
     等等，10 = 1,0 -> 1 > 0，不满足。11,12,13,14,15 都满足。共5个。
```

**示例 2：**

```
输入：l = 1, r = 100
输出：54
```

**提示：**
- `1 <= l <= r <= 10^18`

## 解题思路

数位动态规划（Digit DP）经典题。

定义 `f(n)` = 1 到 n 中各位非递减的整数个数。
答案 = `f(r) - f(l - 1)`。

数位 DP 状态：
- `pos`：当前处理的数字位置（从高位到低位）
- `last_digit`：上一位的数字（保证非递减）
- `tight`：当前是否受上界约束
- `started`：是否已经开始填入非零数字

转移：枚举当前位的数字（从 `last_digit` 到 9，且不超过约束）

## Python 代码实现

### 方法一：记忆化数位 DP（推荐）

```python
from functools import lru_cache

class Solution:
    def countNumbers(self, l: int, r: int) -> int:
        def f(n: int) -> int:
            s = str(n)
            m = len(s)

            @lru_cache(maxsize=None)
            def dp(pos, last, tight, started):
                if pos == m:
                    return 1 if started else 0
                limit = int(s[pos]) if tight else 9
                res = 0
                for d in range(0 if not started else last, limit + 1):
                    new_tight = tight and (d == limit)
                    new_started = started or (d != 0)
                    new_last = d if new_started else 0
                    if not new_started:
                        res += dp(pos + 1, 0, new_tight, False)
                    elif d >= last or not started:
                        res += dp(pos + 1, d, new_tight, True)
                return res

            # 重新定义，更清晰
            @lru_cache(maxsize=None)
            def solve(pos, last, tight, started):
                if pos == m:
                    return 1 if started else 0
                limit = int(s[pos]) if tight else 9
                res = 0
                start_d = 0
                for d in range(start_d, limit + 1):
                    if not started and d == 0:
                        # 前导零，不算作已开始
                        res += solve(pos + 1, 0, tight and (d == limit), False)
                    elif started and d < last:
                        # 违反非递减条件
                        continue
                    else:
                        new_last = d if (started or d > 0) else 0
                        new_started = started or (d > 0)
                        res += solve(pos + 1, new_last, tight and (d == limit), new_started)
                return res

            result = solve(0, 0, True, False)
            solve.cache_clear()
            return result

        return f(r) - f(l - 1)
```

### 方法二：迭代数位 DP

```python
class Solution:
    def countNumbers(self, l: int, r: int) -> int:
        def count_up_to(n: int) -> int:
            if n <= 0:
                return 0
            digits = list(map(int, str(n)))
            m = len(digits)

            # dp[last][tight] = 从当前位置开始，上一位为 last，是否受约束的方案数
            # 使用迭代方式
            # dp[d] = 在不受约束情况下，上一位为 d，后续可填的非递减数字数量
            # 预计算：C(remaining_positions, choices) 的组合
            from math import comb

            total = 0
            prev_digit = 0
            is_tight = True
            started = False

            for i in range(m):
                limit = digits[i] if is_tight else 9
                for d in range(prev_digit if started else 0, limit):
                    if not started and d == 0:
                        # 前导零情况
                        # 后续 m-i-1 位的非递减数字数
                        # 以0开头，等价于 m-i-1 位数字中非递减的数量
                        # 这里不计入（前导零不构成有效数字）
                        pass
                    else:
                        # 选 d，后续 m-i-1 位需要 >= d 的非递减序列
                        # 从 d 到 9 中选 m-i-1 个（可重复）= C(9-d + m-i-1, m-i-1)
                        remaining = m - i - 1
                        total += comb(9 - d + remaining, remaining)

                if is_tight:
                    if (started or digits[i] > 0) and digits[i] < prev_digit:
                        return total  # 当前数字违反了非递减
                    prev_digit = digits[i] if (started or digits[i] > 0) else 0
                    started = started or (digits[i] > 0)

            # 加上 n 本身（如果满足条件）
            if all(digits[i] <= digits[i+1] for i in range(m-1)):
                total += 1

            return total

        return count_up_to(r) - count_up_to(l - 1)
```

## 复杂度分析

- 时间复杂度：O(D * 10^2)，D 为数字位数（最多 19 位），每位枚举 10 个数字
- 空间复杂度：O(D * 10)，DP 状态空间

## 关键点总结

1. 数位 DP 的前缀计数技巧：`f(r) - f(l-1)`
2. 非递减约束通过记录上一位数字实现
3. 前导零需要特殊处理（不算入数字位数）
4. 组合数公式：从 d 到 9 选 k 个（可重复）= C(9-d+k, k)

## 易错点

1. 前导零处理：前导零不参与非递减判断
2. 数位 DP 缓存在每次调用后需要清空（不同 n 共用缓存会出错）
3. `l - 1` 可能为 0，需要处理边界
