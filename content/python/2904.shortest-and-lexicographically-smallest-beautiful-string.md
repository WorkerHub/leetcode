## 题目描述

给你一个二进制字符串 `s` 和一个正整数 `k`。

如果 `s` 的某个子字符串中 1 的数量恰好等于 `k`，则称这个子字符串是一个 **美丽子字符串**。

设 `len` 为 `s` 中 **最短美丽子字符串** 的长度，返回 `s` 的长度为 `len` 且字典序最小的美丽子字符串。若不存在这样的子字符串，返回空字符串 `""`。

**示例 1：**
```
输入：s = "100011001", k = 3
输出："11001"
解释：最短美丽子字符串长度为 5，字典序最小的是 "11001"
```

**示例 2：**
```
输入：s = "1011", k = 4
输出："1011"
```

**提示：**
- `1 <= s.length <= 100`
- `1 <= k <= s.length`

## 解题思路

用滑动窗口枚举所有包含恰好 `k` 个 1 的子字符串，记录最短长度，再从所有最短的中选字典序最小的。

步骤：
1. 遍历所有子字符串，记录 1 的个数恰好为 k 的子串
2. 筛选出长度最短的
3. 在最短子串中选字典序最小的

## Python 代码实现

### 方法一：枚举所有子字符串（推荐）

```python
class Solution:
    def shortestBeautifulSubstring(self, s: str, k: int) -> str:
        n = len(s)
        best = ""
        min_len = n + 1

        for i in range(n):
            ones = 0
            for j in range(i, n):
                if s[j] == '1':
                    ones += 1
                if ones == k:
                    # 当前子串 s[i..j] 包含恰好 k 个 1
                    length = j - i + 1
                    sub = s[i:j + 1]
                    if length < min_len or (length == min_len and sub < best):
                        min_len = length
                        best = sub
                elif ones > k:
                    break  # 1 的个数超过 k，后续更长也不会变少，跳出

        return best
```

### 方法二：滑动窗口（更规范）

```python
class Solution:
    def shortestBeautifulSubstring(self, s: str, k: int) -> str:
        n = len(s)
        best = ""
        left = 0
        ones = 0

        # 先用滑动窗口找所有恰好含 k 个 1 的最短子串
        candidates = []
        for right in range(n):
            if s[right] == '1':
                ones += 1
            # 收缩左边界，保持 ones <= k
            while ones > k:
                if s[left] == '1':
                    ones -= 1
                left += 1
            # 此时 ones <= k
            if ones == k:
                # 尽量收缩左边界（去除开头的 0）
                while s[left] == '0':
                    left += 1
                candidates.append(s[left:right + 1])

        if not candidates:
            return ""

        # 找最短且字典序最小
        min_len = min(len(c) for c in candidates)
        result = ""
        for c in candidates:
            if len(c) == min_len:
                if not result or c < result:
                    result = c
        return result
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子字符串
- 空间复杂度：O(n)，存储候选子字符串

## 关键点总结

1. 最短美丽子字符串一定以 1 开头和以 1 结尾（去除多余的前缀/后缀 0 不会减少 1 的个数）
2. 在相同长度中比较字典序，直接用字符串比较即可
3. 如果没有包含 k 个 1 的子字符串，返回空字符串

## 易错点

1. 最短美丽子字符串的两端必须都是 1，否则可以缩短
2. 字典序比较时，Python 字符串直接用 `<` 即可，'0' < '1'
