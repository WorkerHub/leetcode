## 题目描述

给你一个由 **正整数** 组成的数组 `nums`。

每次操作你可以将两个 **相邻** 的元素合并（将它们替换为一个等于它们之和的元素）。

返回将数组变成 **回文数组** 所需的 **最少** 操作数。

**示例 1：**
```
输入：nums = [4,3,2,1,2,3,1]
输出：2
解释：将 nums[0] 和 nums[1] 合并得到 [7,2,1,2,3,1]，再将 nums[3] 和 nums[4] 合并得到 [7,2,1,5,1] 不对...
```

**示例 2：**
```
输入：nums = [1,2,3,4]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**贪心 + 双指针：**

用两个指针 `left` 和 `right` 分别指向数组两端，同时维护两端的当前累加值 `l_val` 和 `r_val`：

1. 若 `l_val == r_val`，两端已匹配，双指针同时向中间移动
2. 若 `l_val < r_val`，左边偏小，合并左边的下一个元素（操作数加一，`left++`，`l_val += nums[left]`）
3. 若 `l_val > r_val`，右边偏小，合并右边的下一个元素（操作数加一，`right--`，`r_val += nums[right]`）

**贪心正确性：** 当一端比另一端小时，合并该端的下一个元素（因为都是正整数，合并只会让值增大，不会越过目标值）。

## 代码实现

### 方法一：双指针贪心（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        l_val = nums[left]
        r_val = nums[right]
        ops = 0

        while left < right:
            if l_val == r_val:
                # 两端相等，同时向中间移动
                left += 1
                right -= 1
                if left < right:
                    l_val = nums[left]
                    r_val = nums[right]
            elif l_val < r_val:
                # 左端偏小，合并左端的下一个元素
                left += 1
                l_val += nums[left]
                ops += 1
            else:
                # 右端偏小，合并右端的下一个元素
                right -= 1
                r_val += nums[right]
                ops += 1

        return ops
```

### 方法二：递归实现

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        def solve(left: int, right: int, l_val: int, r_val: int) -> int:
            if left >= right:
                return 0
            if l_val == r_val:
                return solve(left + 1, right - 1, nums[left + 1], nums[right - 1])
            elif l_val < r_val:
                return 1 + solve(left + 1, right, l_val + nums[left + 1], r_val)
            else:
                return 1 + solve(left, right - 1, l_val, r_val + nums[right - 1])

        if len(nums) == 1:
            return 0
        return solve(0, len(nums) - 1, nums[0], nums[-1])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n) | O(1) |
| 递归 | O(n) | O(n)（栈深度）|

## 关键点总结

1. 双指针从两端向中间靠拢，每次对较小的一端进行合并
2. 所有元素为正整数，合并只增大值，贪心策略有效
3. 每次合并操作数加一，直到两端相等再同时内移

## 易错点

- 两端相等后内移时，需要检查 `left < right` 防止越界
- 递归版本需要防止栈溢出（可用迭代代替）
