## 题目描述

给你一个正整数组成的数组 `nums`，返回 `nums` 中一个**升序**子数组的最大可能**元素和**。

子数组是数组中的一个连续数字序列。

已知子数组 `[nums[l], nums[l+1], ..., nums[r-1], nums[r]]` 是**升序**的，当且仅当对任意 `l <= i < r`，均有 `nums[i] < nums[i+1]`。注意，大小为 1 的子数组也是升序的。

**示例 1：**
```
输入：nums = [10,20,30,5,10,50]
输出：65
解释：[5,10,50] 是和最大的升序子数组，和为 65
```

**示例 2：**
```
输入：nums = [10,20,30,40,50]
输出：150
解释：[10,20,30,40,50] 是升序子数组，和为 150
```

**示例 3：**
```
输入：nums = [12,17,15,13,10,11,12]
输出：33
解释：[10,11,12] 是和最大的升序子数组，和为 33
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

遍历数组，维护当前升序子数组的和 `current_sum`：
- 若当前元素比前一个元素大，则继续扩展当前升序子数组
- 否则，重新开始新的升序子数组（当前元素作为新子数组的起点）
- 每次更新最大和

## 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def maxAscendingSum(self, nums: List[int]) -> int:
        max_sum = nums[0]
        current_sum = nums[0]

        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                # 继续扩展升序子数组
                current_sum += nums[i]
            else:
                # 重新开始新的升序子数组
                current_sum = nums[i]
            max_sum = max(max_sum, current_sum)

        return max_sum
```

### 方法二：双指针（显式记录子数组边界）

```python
from typing import List

class Solution:
    def maxAscendingSum(self, nums: List[int]) -> int:
        n = len(nums)
        max_sum = 0
        l = 0

        while l < n:
            r = l
            current_sum = nums[l]
            # 向右扩展升序子数组
            while r + 1 < n and nums[r + 1] > nums[r]:
                r += 1
                current_sum += nums[r]
            max_sum = max(max_sum, current_sum)
            l = r + 1  # 跳到下一个子数组的起点

        return max_sum
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)

## 关键点总结

1. 升序：严格递增（`nums[i] < nums[i+1]`），不含等号
2. 每次遇到不升序的位置，重置当前和为当前元素
3. 每步都更新最大值

## 易错点

1. 升序条件是严格小于，不包含等于
2. 初始化 `current_sum = nums[0]`，`max_sum = nums[0]`（至少包含第一个元素）
3. 单元素子数组也是升序的，所以最小结果是 `max(nums)`
