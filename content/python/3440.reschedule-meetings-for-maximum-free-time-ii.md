## 题目描述

与 3439 相同的背景，但只能移动**恰好 1 个**会议，且移动后的会议可以插入任意空闲时间段（不限于移走原位置）。

给你 `eventTime`，以及 `startTime`、`endTime` 数组（已排序，无重叠）。

移动一个会议后，返回能获得的最大连续空闲时间。

**示例 1：**

```
输入：eventTime = 5, k = 1, startTime = [1,3], endTime = [2,5]
输出：4
解释：将 [3,5] 移到 [0,1] 之前或合并到一个空隙中...
```

**提示：**
- `1 <= eventTime <= 10^9`
- `1 <= n <= 10^5`
- 会议不重叠，已按时间排序

## 解题思路

移动恰好 1 个会议。设移动第 i 个会议后，其原位置的空隙与相邻空隙合并。

若移动会议 i（时长 d[i]）：
- 原来第 i 个会议两侧的空隙 gaps[i] 和 gaps[i+1] 合并，得到新的连续空闲 = gaps[i] + d[i] + gaps[i+1]
- 但这个会议需要插入某个地方，要找一个空隙 >= d[i] 的位置

若某个其他空隙 gaps[j] >= d[i]，则可以将会议插入其中，合并得到的连续空闲 = gaps[i] + d[i] + gaps[i+1]（移走位置的合并空间）。

若 gaps[j] < d[i] 对所有 j != i（原位置两侧外），则不能完全释放原位置。

## Python 代码实现

### 方法一：贪心枚举（推荐）

```python
from typing import List

class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)

        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])

        durations = [endTime[i] - startTime[i] for i in range(n)]

        # 对每个会议 i，若移走它，原位置产生空闲 = gaps[i] + d[i] + gaps[i+1]
        # 但会议需要被安排到某处（能安排的条件：存在某个空隙 >= d[i]）
        # 若能安排（不改变其他地方），则最大空闲 = gaps[i] + d[i] + gaps[i+1]
        # 若不能安排到其他地方，则会议必须插回原位附近（无贡献）

        # 预计算：left_max[i] = max(gaps[0..i])，right_max[i] = max(gaps[i..n])
        left_max = [0] * (n + 2)
        right_max = [0] * (n + 2)

        for i in range(n + 1):
            left_max[i + 1] = max(left_max[i], gaps[i])

        for i in range(n, -1, -1):
            right_max[i] = max(right_max[i + 1] if i + 1 <= n else 0, gaps[i])

        ans = max(gaps)  # 不移动任何会议

        for i in range(n):
            d = durations[i]
            merged = gaps[i] + d + gaps[i + 1]

            # 检查是否能将会议 i 安排到 [i+1..n] 的某个空隙中（不包括 gaps[i] 和 gaps[i+1]）
            # 即 max(gaps[0..i-1]) >= d 或 max(gaps[i+2..n]) >= d
            can_place_left = left_max[i] >= d   # gaps[0..i-1] 中有 >= d 的空隙
            can_place_right = right_max[i + 2] >= d if i + 2 <= n else False  # gaps[i+2..n]

            if can_place_left or can_place_right:
                # 可以移走会议 i，原位置完全合并
                ans = max(ans, merged)
            else:
                # 不能移走，只能合并两侧空隙（会议仍在附近）
                # 最大只能获得 gaps[i] + gaps[i+1]（但不能完全合并 d）
                # 实际上会议插入后占 d，只有空隙可用
                # 若将会议塞入 gaps[i]（但 gaps[i] < d）...
                # 贪心：不移动时的最优
                pass

        # 不移动任何会议的基准答案
        ans = max(ans, max(gaps))

        return ans
```

### 方法二：预计算前后最大空隙

```python
from typing import List

class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)

        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])

        durations = [endTime[i] - startTime[i] for i in range(n)]

        # 前缀最大值
        prefix_max = [0] * (len(gaps) + 1)
        for i, g in enumerate(gaps):
            prefix_max[i + 1] = max(prefix_max[i], g)

        # 后缀最大值
        suffix_max = [0] * (len(gaps) + 1)
        for i in range(len(gaps) - 1, -1, -1):
            suffix_max[i] = max(suffix_max[i + 1], gaps[i])

        ans = max(gaps)

        for i in range(n):
            d = durations[i]
            # 移走会议 i 后合并空间
            merged = gaps[i] + d + gaps[i + 1]
            # 检查是否存在可以放置会议 i 的位置（除了 gaps[i] 和 gaps[i+1]）
            left_ok = prefix_max[i] >= d      # gaps[0..i-1]
            right_ok = suffix_max[i + 2] >= d  # gaps[i+2..]

            if left_ok or right_ok:
                ans = max(ans, merged)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 移动会议 i 后，原位置的三段（gaps[i] + d[i] + gaps[i+1]）合并
2. 需要验证是否能将会议 i 安排到其他地方（需要某个空隙 >= d[i]）
3. 用前后缀最大值快速检查是否存在可用空隙

## 易错点

1. 检查可用空隙时要排除 gaps[i] 和 gaps[i+1]（它们被合并了）
2. 前缀最大 `prefix_max[i]` 对应 `gaps[0..i-1]`（不包含 gaps[i]）
3. 基准答案是不移动任何会议时的最大空隙
