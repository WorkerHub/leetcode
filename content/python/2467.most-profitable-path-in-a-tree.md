## 题目描述

一棵无向树，有 `n` 个节点（编号 0 到 n-1），根节点为 0。

Alice 从根节点 0 出发，沿着树到达某个叶子节点，Bob 从节点 `bob` 出发，一定会到达根节点 0。Alice 和 Bob 每秒钟各走一步。

当 Alice 和 Bob 同时到达某个节点时，门的收益平分。如果 Alice 先到达，Alice 获得全部收益。

每个节点有一个收益 `amount[i]`（可以是负数）。Alice 想要最大化到达叶子节点时的总收益，Bob 的路径是固定的。

返回 Alice 能获得的 **最大** 净收益。

**提示：**
- `2 <= n <= 10^5`
- `edges.length == n - 1`

## 解题思路

1. 先用 DFS/BFS 找到 Bob 到达根节点的路径，记录 Bob 在每个节点的到达时间 `bob_time[node]`
2. 再用 DFS 遍历 Alice 的所有路径（从根到各叶子），模拟收益计算：
   - 若 `alice_time < bob_time[node]`：Alice 独享全部收益
   - 若 `alice_time == bob_time[node]`：各得一半
   - 若 `alice_time > bob_time[node]`：Bob 已经过，节点收益为 0

## 代码实现

### 方法一：两次 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def mostProfitablePath(self, edges: List[List[int]], bob: int, amount: List[int]) -> int:
        n = len(amount)
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 第一步：找 Bob 的路径（bob -> 0），记录到达时间
        bob_time = {}

        def find_bob_path(node: int, parent: int, time: int) -> bool:
            """DFS 寻找 bob 到根节点的路径"""
            if node == 0:
                bob_time[node] = time
                return True
            for neighbor in adj[node]:
                if neighbor != parent:
                    if find_bob_path(neighbor, node, time + 1):
                        bob_time[node] = time
                        return True
            return False

        find_bob_path(bob, -1, 0)

        # 第二步：DFS 遍历 Alice 的所有路径，计算最大收益
        ans = float('-inf')

        def alice_dfs(node: int, parent: int, alice_time: int, profit: int) -> None:
            nonlocal ans
            # 计算当前节点的收益
            if alice_time < bob_time.get(node, float('inf')):
                profit += amount[node]
            elif alice_time == bob_time.get(node, float('inf')):
                profit += amount[node] // 2

            # 检查是否是叶子节点
            is_leaf = all(neighbor == parent for neighbor in adj[node])
            if is_leaf:
                ans = max(ans, profit)
                return

            for neighbor in adj[node]:
                if neighbor != parent:
                    alice_dfs(neighbor, node, alice_time + 1, profit)

        alice_dfs(0, -1, 0, 0)
        return ans
```

### 方法二：BFS 找 Bob 路径

```python
from typing import List
from collections import defaultdict

class Solution:
    def mostProfitablePath(self, edges: List[List[int]], bob: int, amount: List[int]) -> int:
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 找 bob 到根节点的路径
        parent = {0: -1}
        stack = [0]
        visited = {0}
        while stack:
            node = stack.pop()
            for neighbor in adj[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    parent[neighbor] = node
                    stack.append(neighbor)

        bob_time = {}
        cur, t = bob, 0
        while cur != -1:
            bob_time[cur] = t
            cur = parent.get(cur, -1)
            t += 1

        ans = float('-inf')

        def dfs(node, par, time, profit):
            nonlocal ans
            if time < bob_time.get(node, float('inf')):
                profit += amount[node]
            elif time == bob_time.get(node, float('inf')):
                profit += amount[node] // 2

            children = [nb for nb in adj[node] if nb != par]
            if not children:
                ans = max(ans, profit)
            for child in children:
                dfs(child, node, time + 1, profit)

        dfs(0, -1, 0, 0)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 两次 DFS | O(n) | O(n) |

## 关键点总结

1. 先确定 Bob 到达每个路径节点的时间，再模拟 Alice 的 DFS
2. 同时到达时收益各半（整除 2）
3. 叶子节点判断：除父节点外没有其他邻居

## 易错点

- Bob 的路径是固定的（bob 到根节点 0），不是 Alice 的路径
- 收益可以是负数，不能剪枝不访问负收益节点
