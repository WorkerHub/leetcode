## 题目描述

给定一个整数数组 `nums` 和整数 `k`，通过若干次操作使数组中所有元素的最大值不超过 `k`。每次操作可以移除数组中的一段连续子数组（代价等于子数组长度）。求移除所有大于 `k` 的元素所需的最小总代价。

**示例 1：**
```
输入：nums = [1,3,4,2,4,3], k = 3
输出：3
解释：大于 3 的元素为下标 1(3), 2(4), 4(4)... 实际大于 3 的是下标 2(4) 和 4(4)。
     可以一次移除 [2,4,2,4,3] -> 不对，移除的是子数组且代价是长度。
     最优：移除 [4] 代价 1，再移除 [4] 代价 1，总代价 2？
     或合并：移除 [4,2,4] 代价 3，总代价 3。取最小。
```

**示例 2：**
```
输入：nums = [5,4,3,2,1], k = 2
输出：4
解释：移除 [5,4,3] 代价 3，保留 [2,1]。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

动态规划。设需要移除的"坏"元素（值 > k）的位置集合为 `bad`。

问题等价于：选择若干区间覆盖所有坏位置，每个区间代价为区间长度，但可以共享区间（合并），求最小总代价。

**贪心 DP：** 设 `dp[i]` 为处理完前 `i` 个坏元素（含第 `i` 个）所需的最小代价。

若连续两个坏位置 `bad[i]` 和 `bad[i+1]`，可以选择：
1. 分开移除：各自单独代价 1，总代价 2
2. 合并移除：一段 `[bad[i], bad[i+1]]`，代价 `bad[i+1] - bad[i] + 1`

选代价小的方案。

整体 DP：`dp[i] = min(dp[i-1] + 1, dp[i-2] + bad[i] - bad[i-1] + 1)` 等

实际上，DP 转移需要考虑合并多个坏位置的情况。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minimumDistance(self, nums: List[int], k: int) -> int:
        # 找出所有"坏"元素的位置
        bad = [i for i, x in enumerate(nums) if x > k]
        if not bad:
            return 0

        m = len(bad)
        # dp[i]: 移除 bad[0..i] 所有坏元素的最小代价
        # 每次操作移除一段连续区间，代价为区间长度
        # 最优策略：合并代价 <= 分开代价时合并

        # 将相邻坏位置的间隙作为合并代价考量
        # 初始：每个坏位置单独移除，代价为 1
        dp = [0] * m
        dp[0] = 1

        for i in range(1, m):
            # 选项1：单独移除 bad[i]，代价 1
            option1 = dp[i-1] + 1
            # 选项2：将 bad[i] 与 bad[i-1] 合并为一段，额外代价为间隙 bad[i]-bad[i-1]-1
            gap = bad[i] - bad[i-1] - 1  # 两个坏位置之间的"好"元素数
            option2 = dp[i-1] - 1 + (bad[i] - bad[i-1] + 1)  # 延长已有区间

            # 实际上 option2 = dp[i-1] + gap + 1（多付出间隙代价，但不需要新开区间）
            option2 = (dp[i-1]) + gap  # 合并后多覆盖 gap 个好元素，总代价增加 gap

            dp[i] = min(option1, option2 + 1)

        return dp[m-1]
```

### 方法二：贪心合并

```python
from typing import List

class Solution:
    def minimumDistance(self, nums: List[int], k: int) -> int:
        bad = [i for i, x in enumerate(nums) if x > k]
        if not bad:
            return 0

        # 贪心：若合并相邻坏位置比分开便宜，则合并
        total = 1  # 第一个坏位置代价 1
        for i in range(1, len(bad)):
            gap = bad[i] - bad[i-1] - 1
            if gap + 1 < 2:
                # 合并代价 gap+1 <= 2（分开代价），选合并
                total += gap  # 只增加间隙代价，不新开区间
            else:
                total += 1  # 单独开一个新区间

        return total
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（存储坏位置）

## 关键点总结

1. 关注"坏"元素位置的间隙：间隙为 0 时合并必然更优
2. 合并代价 = 间隙长度；分开代价 = 2（各 1）；当间隙 < 2 时合并更优（间隙 0 或 1）
3. DP 或贪心均可解决此问题

## 易错点

1. 间隙计算：`bad[i] - bad[i-1] - 1`（两坏位置之间的元素数）
2. 合并与不合并的临界条件：间隙代价 vs 重新开区间代价
