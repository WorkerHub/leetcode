## 题目描述

给你一个字符串 `num`（大整数的十进制表示）和一个整数数组 `change`，`change[i]` 是将数字 `i` 替换后的新数字。

你可以选择**最多一次**将 `num` 的某个**子字符串**的每个数字替换为对应的 `change` 映射后的数字。

返回能得到的**最大**整数字符串。

**示例 1：**
```
输入：num = "132", change = [9,8,5,0,3,6,4,2,6,8]
输出："832"
解释：将 "1" 替换为 change[1]=8，得到 "832"
```

**示例 2：**
```
输入：num = "021", change = [9,4,3,5,7,2,1,9,0,6]
输出："934"
```

**提示：**
- `1 <= num.length <= 10^5`
- `change.length == 10`
- `0 <= change[i] <= 9`

---

## 解题思路

### 核心思想：贪心 - 找第一个可替换的起点，然后持续替换直到不再增大

1. 从左到右扫描，找到第一个 `change[d] > d` 的位置（替换会使数字变大），开始替换
2. 继续向右替换，直到 `change[d] < d`（替换会使数字变小，停止）
3. 遇到 `change[d] == d` 时继续（不影响大小，可以跳过也可以继续替换）

## 代码实现

### 方法一：贪心扫描（推荐）

```python
from typing import List

class Solution:
    def maximumNumber(self, num: str, change: List[int]) -> str:
        digits = list(num)
        n = len(digits)
        started = False  # 是否已开始替换

        for i in range(n):
            d = int(digits[i])
            c = change[d]

            if not started:
                if c > d:
                    # 开始替换
                    digits[i] = str(c)
                    started = True
                # 若 c == d 也可以开始（但没有收益），若 c < d 不替换
            else:
                if c >= d:
                    # 继续替换（c > d 收益正，c == d 中性）
                    digits[i] = str(c)
                else:
                    # c < d，停止替换
                    break

        return ''.join(digits)
```

### 方法二：找替换区间（稍微不同的思路）

```python
from typing import List

class Solution:
    def maximumNumber(self, num: str, change: List[int]) -> str:
        digits = list(num)
        n = len(digits)
        i = 0

        # 找第一个 change[d] > d 的位置
        while i < n and change[int(digits[i])] <= int(digits[i]):
            i += 1

        # 从 i 开始替换，直到 change[d] < d
        while i < n:
            d = int(digits[i])
            if change[d] >= d:
                digits[i] = str(change[d])
                i += 1
            else:
                break

        return ''.join(digits)
```

## 关键点总结

1. 贪心：从左到右找第一个可以增大的数字，替换直到不再增大
2. 替换为等于时（change[d] == d）继续，不影响大小也无损
3. 只能替换**一个连续的子字符串**（不能跳跃）

---

## 易错点

- 替换等于（change[d] == d）时要继续，不要中断（因为后面可能还有增大机会）
- 遇到第一个 change[d] < d 就必须停止
