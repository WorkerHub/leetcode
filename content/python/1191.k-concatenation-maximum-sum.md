## 题目描述

给定一个整数数组 `arr` 和一个整数 `k`，通过重复 `k` 次来修改数组。

例如，如果 `arr = [1, 2]` 且 `k = 3`，则修改后的数组为 `[1, 2, 1, 2, 1, 2]`。

返回修改后数组的最大子数组和。由于答案可能会很大，需要返回答案对 `10^9 + 7` 取模的结果。

**示例 1：**
```
输入：arr = [1,2], k = 3
输出：9
解释：修改后的数组为 [1,2,1,2,1,2]，最大子数组和为 1+2+1+2+1+2 = 9。
```

**示例 2：**
```
输入：arr = [1,-2,1], k = 5
输出：2
解释：修改后的数组为 [1,-2,1,1,-2,1,1,-2,1,1,-2,1,1,-2,1]，
最大子数组和为 1+1 = 2。
```

**示例 3：**
```
输入：arr = [-1,-2], k = 7
输出：0
解释：所有元素都是负数，最大子数组和为 0（空子数组）。
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= k <= 10^5`
- `-10^4 <= arr[i] <= 10^4`

## 解题思路

这道题是经典的 Kadane 算法（最大子数组和）的变体，需要考虑数组重复 k 次的情况。

**核心思路：**

1. **分情况讨论**：
   - 如果 `k = 1`：直接使用 Kadane 算法
   - 如果 `k >= 2`：需要考虑数组总和的正负

2. **关键观察**：
   - 如果数组总和 `sum > 0`，那么中间的 `k-2` 个完整数组都应该被包含
   - 最大子数组可能跨越多个重复的数组

3. **三种情况**：
   - **情况1**：最大子数组在单个数组内（使用 Kadane 算法）
   - **情况2**：最大子数组跨越两个数组（前缀 + 后缀）
   - **情况3**：k >= 2 且总和 > 0，包含中间的完整数组

## Python 代码实现

### 方法一：Kadane 算法变体（推荐）⭐

```python
from typing import List

class Solution:
    def kConcatenationMaxSum(self, arr: List[int], k: int) -> int:
        MOD = 10**9 + 7
        
        def kadane(nums: List[int]) -> int:
            """
            Kadane 算法：计算最大子数组和
            """
            max_sum = 0
            current_sum = 0
            
            for num in nums:
                current_sum = max(0, current_sum + num)
                max_sum = max(max_sum, current_sum)
            
            return max_sum
        
        # 计算数组总和
        total_sum = sum(arr)
        
        # 情况1：k = 1，直接使用 Kadane 算法
        if k == 1:
            return kadane(arr) % MOD
        
        # 情况2：k >= 2
        # 先计算两个数组拼接的最大子数组和
        max_two = kadane(arr + arr)
        
        # 如果总和 > 0，中间的 (k-2) 个完整数组应该被包含
        if total_sum > 0:
            # 最大值 = 两个数组的最大子数组和 + (k-2) * 总和
            return (max_two + (k - 2) * total_sum) % MOD
        else:
            # 总和 <= 0，不需要包含中间的完整数组
            return max_two % MOD
```

### 方法二：分别计算前缀、后缀和中间部分

```python
from typing import List

class Solution:
    def kConcatenationMaxSum(self, arr: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        
        # 计算最大前缀和
        max_prefix = 0
        current_sum = 0
        for num in arr:
            current_sum += num
            max_prefix = max(max_prefix, current_sum)
        
        # 计算最大后缀和
        max_suffix = 0
        current_sum = 0
        for i in range(n - 1, -1, -1):
            current_sum += arr[i]
            max_suffix = max(max_suffix, current_sum)
        
        # 计算单个数组的最大子数组和
        max_single = 0
        current_sum = 0
        for num in arr:
            current_sum = max(0, current_sum + num)
            max_single = max(max_single, current_sum)
        
        # 数组总和
        total_sum = sum(arr)
        
        # k = 1 的情况
        if k == 1:
            return max_single % MOD
        
        # k >= 2 的情况
        # 最大值可能是：
        # 1. 单个数组的最大子数组和
        # 2. 跨越两个数组的和（后缀 + 前缀）
        # 3. 如果总和 > 0，后缀 + (k-2)*总和 + 前缀
        result = max(max_single, max_suffix + max_prefix)
        
        if total_sum > 0:
            result = max(result, max_suffix + (k - 2) * total_sum + max_prefix)
        
        return result % MOD
```

### 方法三：简化版本

```python
from typing import List

class Solution:
    def kConcatenationMaxSum(self, arr: List[int], k: int) -> int:
        MOD = 10**9 + 7
        
        # 计算单个数组和两个数组拼接的最大子数组和
        def max_subarray(nums):
            max_sum = current = 0
            for num in nums:
                current = max(num, current + num)
                max_sum = max(max_sum, current)
            return max_sum
        
        total = sum(arr)
        
        # k = 1
        if k == 1:
            return max_subarray(arr) % MOD
        
        # k >= 2
        # 计算两个数组的最大子数组和
        max_two = max_subarray(arr * 2)
        
        # 如果总和 > 0，加上中间的完整数组
        if total > 0:
            return (max_two + (k - 2) * total) % MOD
        else:
            return max_two % MOD
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，其中 n 是数组长度，只需要遍历常数次数组
- **空间复杂度**：O(1) 或 O(n)（如果创建新数组则为 O(n)）

## 关键点总结

1. **Kadane 算法**：核心是计算最大子数组和的经典算法
2. **分情况讨论**：k = 1 和 k >= 2 需要不同的处理方式
3. **总和的作用**：当总和 > 0 时，中间的完整数组应该被包含
4. **前缀和后缀**：最大子数组可能跨越数组边界，需要考虑前缀和后缀
5. **取模运算**：最后结果要对 10^9 + 7 取模

## 易错点

1. **忘记取模**：题目要求对 10^9 + 7 取模，不要忘记
2. **k = 1 的特殊情况**：需要单独处理
3. **总和为负的情况**：当总和 <= 0 时，不应该包含中间的完整数组
4. **空子数组**：Kadane 算法允许空子数组，最小值为 0
5. **溢出问题**：使用 Python 不存在整数溢出，但其他语言要注意
