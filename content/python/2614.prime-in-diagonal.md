## 题目描述

给你一个下标从 0 开始的二维整数数组 `nums`。

返回位于 `nums` 至少一条对角线上的最大质数，若不存在则返回 0。

注意：主对角线（左上到右下）和副对角线（右上到左下）上的元素都算。

**示例 1：**
```
输入：nums = [[1,2,3],[5,6,7],[9,10,11]]
输出：11
解释：主对角线：1,6,11；副对角线：3,6,9；质数有 11,7（不在对角线）,5（不在对角线）等
实际对角线质数：11（主对角线），3（副对角线），最大为 11
```

**示例 2：**
```
输入：nums = [[1,2,3],[5,17,7],[9,11,10]]
输出：17
```

**数据范围：**
- 1 <= nums.length == nums[i].length <= 300
- 1 <= nums[i][j] <= 4 * 10^6

## 解题思路

直接遍历两条对角线上的所有元素，判断是否为质数，维护最大质数值。

## Python 代码实现

### 方法一：直接遍历 + 质数判断（推荐）

```python
from typing import List

class Solution:
    def diagonalPrime(self, nums: List[List[int]]) -> int:
        def is_prime(n):
            if n < 2:
                return False
            if n == 2:
                return True
            if n % 2 == 0:
                return False
            i = 3
            while i * i <= n:
                if n % i == 0:
                    return False
                i += 2
            return True

        n = len(nums)
        ans = 0
        for i in range(n):
            # 主对角线元素 nums[i][i]
            if is_prime(nums[i][i]):
                ans = max(ans, nums[i][i])
            # 副对角线元素 nums[i][n-1-i]
            if is_prime(nums[i][n - 1 - i]):
                ans = max(ans, nums[i][n - 1 - i])
        return ans
```

### 方法二：收集对角线元素后统一判断

```python
from typing import List

class Solution:
    def diagonalPrime(self, nums: List[List[int]]) -> int:
        def is_prime(n):
            if n < 2:
                return False
            for i in range(2, int(n**0.5) + 1):
                if n % i == 0:
                    return False
            return True

        n = len(nums)
        # 收集两条对角线的元素（去重）
        diag_elements = set()
        for i in range(n):
            diag_elements.add(nums[i][i])
            diag_elements.add(nums[i][n - 1 - i])

        primes = [x for x in diag_elements if is_prime(x)]
        return max(primes) if primes else 0
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(M))，n 为矩阵边长，M 为元素最大值
- 空间复杂度：O(1)

## 关键点总结

1. 矩阵大小为 n×n，两条对角线各有 n 个元素
2. 主对角线：`(i, i)`；副对角线：`(i, n-1-i)`
3. 质数判断：试除法，仅需到 sqrt(n)

## 易错点

1. 矩阵中心元素（n 为奇数时）同时在两条对角线上，注意去重（但统计最大值时无影响）
2. 1 不是质数
3. 对角线的副对角线下标：`n-1-i`
