## 题目描述

给你一个整数数组 `nums`（下标从 0 开始），每次操作可以选择数组中的任意一个元素，将其增加 1。

返回使 `nums` 成为**严格递增**数组所需的最少操作次数。

**示例 1：**
```
输入：nums = [1,1,1]
输出：3
解释：需要将 nums 变为 [1,2,3]，共 3 次操作
```

**示例 2：**
```
输入：nums = [1,5,2,4,1]
输出：14
```

**提示：**
- `1 <= nums.length <= 5000`
- `1 <= nums[i] <= 10^4`

## 解题思路

**贪心**：从左到右扫描，对于每个位置 `i`，若 `nums[i] <= nums[i-1]`，则需要将 `nums[i]` 增加到 `nums[i-1] + 1`，记录所需操作次数。将 `nums[i]` 就地更新为增加后的值，用于后续比较。

## 代码实现

### 方法一：贪心原地修改（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        ops = 0
        for i in range(1, len(nums)):
            if nums[i] <= nums[i - 1]:
                # 需要将 nums[i] 增加到 nums[i-1] + 1
                target = nums[i - 1] + 1
                ops += target - nums[i]
                nums[i] = target  # 更新 nums[i]，用于后续比较
        return ops
```

### 方法二：不修改原数组

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        ops = 0
        prev = nums[0]
        for i in range(1, len(nums)):
            # 目标值：max(nums[i], prev + 1)
            target = max(nums[i], prev + 1)
            ops += target - nums[i]
            prev = target
        return ops
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心策略：尽量少增加，每个元素只增加到比前一个多 1 即可
2. 每次更新后，用更新后的值作为下一个元素的参考
3. 只允许增加不允许减少，所以贪心取最小值即可

## 易错点

- 不能减少元素值，只能增加
- 需要及时更新当前元素值（或用变量 prev 记录），否则后续比较基准错误
