## 题目描述

给你一个正整数 `n`，请你计算在 `[1, n]` 范围内能被 3、5 或 7 整除的所有整数之和。

**示例 1：**
```
输入：n = 7
输出：40
解释：3+5+6+7 = 21... 实际：3+5+6+7=21？
能被3整除：3,6；能被5整除：5；能被7整除：7
3+5+6+7 = 21，但 3 和 6 都计入，5 计入，7 计入
3+5+6+7 = 21，不对，让我重算：3+6=9, 5, 7 = 9+5+7=21？
实际上 n=7 时：3,5,6,7 都满足，3+5+6+7=21
```

**示例 2：**
```
输入：n = 10
输出：40
解释：3+5+6+7+9+10 = 40
```

**数据范围：**
- 1 <= n <= 10^3

## 解题思路

枚举 1 到 n 的所有整数，若能被 3、5 或 7 整除则加入总和。

## Python 代码实现

### 方法一：直接枚举（推荐）

```python
class Solution:
    def sumOfMultiples(self, n: int) -> int:
        return sum(x for x in range(1, n + 1) if x % 3 == 0 or x % 5 == 0 or x % 7 == 0)
```

### 方法二：容斥原理（数学方法）

```python
class Solution:
    def sumOfMultiples(self, n: int) -> int:
        def sum_of_divisors(d):
            """1 到 n 中 d 的倍数之和"""
            k = n // d
            return d * k * (k + 1) // 2

        # 容斥原理：|A∪B∪C| = |A|+|B|+|C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|
        return (sum_of_divisors(3) + sum_of_divisors(5) + sum_of_divisors(7)
                - sum_of_divisors(15) - sum_of_divisors(21) - sum_of_divisors(35)
                + sum_of_divisors(105))
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(1)，空间复杂度 O(1)

## 关键点总结

1. 能被多个数整除的数只计算一次（集合并集）
2. 容斥原理避免重复计数
3. 等差数列求和：前 k 项之和 = k * (k+1) / 2 * d

## 易错点

1. 同时被多个数整除的数不能重复计算（如 15 被 3 和 5 整除）
2. 容斥原理需要减去两两交集，加回三者交集
