## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在两个 **不同的索引** `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。如果存在，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1], k = 3
输出：true
```

**示例 2：**

```
输入：nums = [1,0,1,1], k = 1
输出：true
```

**示例 3：**

```
输入：nums = [1,2,3,1,2,3], k = 2
输出：false
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 解题思路

这是 [217. 存在重复元素](https://leetcode.com/problems/contains-duplicate/) 的进阶版，增加了索引距离的限制。

**核心思想：**

1. **哈希表存储索引**：记录每个值最近出现的索引
2. **滑动窗口**：维护大小为 k 的窗口，检查窗口内是否有重复
3. **距离检查**：找到重复元素时，检查索引差是否 <= k

**多种解法：**

1. **哈希表 + 索引**：记录每个值的最新索引，检查距离
2. **滑动窗口 + 集合**：维护大小为 k+1 的窗口，检查重复
3. **暴力法**：双循环检查（会超时）

## Python 代码实现

### 方法一：哈希表存储索引（推荐）⭐

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        """记录每个值最近出现的索引"""
        index_map = {}  # {值: 最新索引}
        
        for i, num in enumerate(nums):
            if num in index_map:
                # 检查索引距离
                if i - index_map[num] <= k:
                    return True
            # 更新最新索引
            index_map[num] = i
        
        return False
```

### 方法二：滑动窗口 + 集合（经典解法）

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        """维护大小为 k 的滑动窗口"""
        window = set()  # 窗口内的元素
        
        for i, num in enumerate(nums):
            # 窗口太大，移除最左边的元素
            if i > k:
                window.remove(nums[i - k - 1])
            
            # 检查窗口内是否有重复
            if num in window:
                return True
            
            window.add(num)
        
        return False
```

### 方法三：哈希表存储所有索引（过度设计）

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        """存储每个值的所有索引"""
        from collections import defaultdict
        
        index_map = defaultdict(list)
        
        for i, num in enumerate(nums):
            # 检查之前出现的索引
            for prev_i in index_map[num]:
                if i - prev_i <= k:
                    return True
            index_map[num].append(i)
        
        return False
```

### 方法四：暴力法（会超时，仅供理解）

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        """双循环检查"""
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, min(i + k + 1, n)):
                if nums[i] == nums[j]:
                    return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希表索引（方法一） | O(N) | O(N) | 最优解 |
| 滑动窗口（方法二） | O(N) | O(min(N, K)) | 空间更优 |
| 暴力法（方法四） | O(N × K) | O(1) | 会超时 |

**推荐：** 方法一（哈希表存储索引），代码简洁且性能最优

## 关键点总结

1. **哈希表优化**：将查找从 O(N) 降到 O(1)
2. **索引距离检查**：`abs(i - j) <= k` 等价于 `i - j <= k`（因为 i > j）
3. **滑动窗口思想**：维护固定大小的窗口，检查窗口内的重复
4. **空间优化**：滑动窗口最多存储 k+1 个元素
5. **提前返回**：找到满足条件的立即返回，无需遍历全部

## 易错点

1. **索引距离计算错误**：
   ```python
   # 错误：忘记取绝对值（实际上不需要，因为 i > 前索引）
   if abs(i - index_map[num]) <= k:
   # 正确：i 总是大于之前的索引
   if i - index_map[num] <= k:
   ```

2. **滑动窗口边界错误**：
   ```python
   # 错误：窗口大小应该是 k，不是 k+1
   if i >= k:
       window.remove(nums[i - k])
   # 正确：保持窗口大小为 k
   if i > k:
       window.remove(nums[i - k - 1])
   ```

3. **更新索引时机**：
   ```python
   # 错误：检查前就更新索引
   index_map[num] = i
   if num in index_map:
   # 正确：先检查，再更新
   if num in index_map:
       # 检查距离
   index_map[num] = i
   ```

4. **边界情况遗漏**：
   ```python
   # k = 0 时，要求相同索引，不可能
   k = 0  # 应返回 False
   # 数组长度为 1
   nums = [1]  # 应返回 False
   ```

5. **窗口内元素移除错误**：
   ```python
   # 错误：移除不存在的元素会报错
   window.remove(nums[i - k - 1])  # 如果已被移除会报错
   # 正确：检查后移除，或使用 discard
   window.discard(nums[i - k - 1])
   ```
