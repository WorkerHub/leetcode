## 题目描述

给你两个空数组 `arr1` 和 `arr2`，以及正整数 `divisor1`、`divisor2` 和 `uniqueCnt1`、`uniqueCnt2`。

你需要往这两个数组中添加正整数，使得：
- `arr1` 包含 `uniqueCnt1` 个不同的正整数，这些整数均 **不** 能被 `divisor1` 整除
- `arr2` 包含 `uniqueCnt2` 个不同的正整数，这些整数均 **不** 能被 `divisor2` 整除
- `arr1` 和 `arr2` 中的元素 **互不相同**

返回两个数组中 **最大元素** 的 **最小值**。

**示例 1：**

```
输入：divisor1 = 2, divisor2 = 7, uniqueCnt1 = 1, uniqueCnt2 = 3
输出：4
```

**示例 2：**

```
输入：divisor1 = 3, divisor2 = 5, uniqueCnt1 = 2, uniqueCnt2 = 1
输出：3
```

**提示：**

- `1 <= divisor1, divisor2 <= 10^5`
- `1 <= uniqueCnt1, uniqueCnt2 < 10^9`
- 答案不超过 `10^18`

## 解题思路

**二分答案**。对最大值 m 进行二分，判断 m 是否足够大以满足条件。

对于最大值 m：
- 不能被 divisor1 整除的 1 到 m 中的数：`m - m // divisor1` 个
- 不能被 divisor2 整除的 1 到 m 中的数：`m - m // divisor2` 个
- 两者都不能被整除（可以放在任一数组，灵活分配）：`m - m // divisor1 - m // divisor2 + m // lcm(d1, d2)` 个

使用容斥定理，确保两个数组的需求都能被满足。

## Python 代码实现

### 方法一：二分 + 容斥定理（推荐）

```python
import math

class Solution:
    def minimizeSet(self, divisor1: int, divisor2: int, uniqueCnt1: int, uniqueCnt2: int) -> int:
        lcm = divisor1 * divisor2 // math.gcd(divisor1, divisor2)

        def check(m: int) -> bool:
            # 仅能放入 arr1（不被 d1 整除，但被 d2 整除）
            only1 = m - m // divisor1 - (m - m // divisor1 - (m - m // divisor2) + (m - m // lcm))
            # 简化计算
            can1 = m - m // divisor1        # 可放 arr1 的数量（不被 d1 整除）
            can2 = m - m // divisor2        # 可放 arr2 的数量（不被 d2 整除）
            both = m - m // divisor1 - m // divisor2 + m // lcm  # 两者都可放的数量

            # 需要: arr1 至少 uniqueCnt1 个，arr2 至少 uniqueCnt2 个，总共 uniqueCnt1+uniqueCnt2 个
            # can1 >= uniqueCnt1, can2 >= uniqueCnt2, can1+can2-both >= uniqueCnt1+uniqueCnt2
            return (can1 >= uniqueCnt1 and
                    can2 >= uniqueCnt2 and
                    can1 + can2 - both >= uniqueCnt1 + uniqueCnt2)

        lo, hi = 1, 2 * 10**9 + 10
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：更清晰的 check 函数

```python
import math

class Solution:
    def minimizeSet(self, divisor1: int, divisor2: int, uniqueCnt1: int, uniqueCnt2: int) -> int:
        lcm_val = divisor1 // math.gcd(divisor1, divisor2) * divisor2

        def feasible(m: int) -> bool:
            # 1..m 中不被 d1 整除的数
            avail1 = m - m // divisor1
            # 1..m 中不被 d2 整除的数
            avail2 = m - m // divisor2
            # 1..m 中既不被 d1 也不被 d2 整除的数（两个数组都能用）
            avail_both = m - m // divisor1 - m // divisor2 + m // lcm_val

            # arr1 需要 uniqueCnt1 个，arr2 需要 uniqueCnt2 个
            # 先检查各自能否满足，再检查总量
            return (avail1 >= uniqueCnt1 and
                    avail2 >= uniqueCnt2 and
                    avail_both >= max(0, uniqueCnt1 - (avail1 - avail_both)) +
                                  max(0, uniqueCnt2 - (avail2 - avail_both)))

        left, right = 1, 2 * 10**9 + 1
        while left < right:
            mid = (left + right) // 2
            if feasible(mid):
                right = mid
            else:
                left = mid + 1
        return left
```

## 复杂度分析

- 时间复杂度：O(log(maxVal))，二分范围约 2*10^9，需约 31 次迭代
- 空间复杂度：O(1)

## 关键点总结

1. 二分最大值，check 函数用容斥原理判断可行性
2. LCM 用于计算两个条件都满足的数的数量
3. 总量约束：两数组合计需要 uniqueCnt1 + uniqueCnt2 个不同正整数

## 易错点

1. LCM 可能很大，注意整数溢出（Python 无此问题）
2. check 中需同时满足三个条件：each array 和 total
3. 二分上界要足够大，约 2 * max(uniqueCnt) 即可
