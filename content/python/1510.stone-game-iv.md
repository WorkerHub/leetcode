## 题目描述

Alice 和 Bob 两人轮流玩一个游戏，Alice 先手。

初始时，石子堆中有 `n` 个石子。每个玩家轮流操作，每次可以移走任意个 **完全平方数** 个石子（如 1, 4, 9, 16, ...）。如果某个玩家无法进行操作，该玩家 **输掉** 游戏。

给你正整数 `n`，若 Alice 能赢得游戏返回 `True`，否则返回 `False`，假设两人都采取最优策略。

**示例 1：**
```
输入：n = 1
输出：true（拿走1个，Bob无法操作）
```

**示例 2：**
```
输入：n = 2
输出：true（拿走1个，剩1给Bob，Bob拿走1，Alice无法动...等等，不对）
```

**示例 3：**
```
输入：n = 4
输出：true（直接拿走4个）
```

**示例 4：**
```
输入：n = 7
输出：false
```

## 解题思路

### 动态规划 + 博弈论

定义 `dp[i]` 表示当前轮到的玩家面对 `i` 个石子时**是否能赢**。

**状态转移：**
- `dp[0] = False`（无法操作，当前玩家输）
- 对于每个 `i`，枚举所有完全平方数 `s <= i`：
  - 若 `dp[i - s] == False`（对手面对 `i-s` 时必输），则当前玩家必赢
- 即 `dp[i] = any(not dp[i - s] for s in squares if s <= i)`

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def winnerSquareGame(self, n: int) -> bool:
        # dp[i] = True 表示面对 i 个石子时先手必赢
        dp = [False] * (n + 1)
        # dp[0] = False：无法操作，当前玩家输
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                # 如果拿走 j*j 个后对手必输，则当前玩家必赢
                if not dp[i - j * j]:
                    dp[i] = True
                    break
                j += 1
        return dp[n]
```

### 方法二：记忆化递归

```python
from functools import lru_cache

class Solution:
    def winnerSquareGame(self, n: int) -> bool:
        @lru_cache(maxsize=None)
        def can_win(stones: int) -> bool:
            if stones == 0:
                return False  # 无法操作，当前玩家输
            j = 1
            while j * j <= stones:
                # 拿走 j*j 个，如果对手不能赢，则当前玩家赢
                if not can_win(stones - j * j):
                    return True
                j += 1
            return False

        return can_win(n)
```

### 方法三：预处理完全平方数列表

```python
import math
from typing import List

class Solution:
    def winnerSquareGame(self, n: int) -> bool:
        # 预处理所有 <= n 的完全平方数
        squares = []
        i = 1
        while i * i <= n:
            squares.append(i * i)
            i += 1

        dp = [False] * (n + 1)
        for i in range(1, n + 1):
            for s in squares:
                if s > i:
                    break
                # 如果拿走 s 个后对手必输
                if not dp[i - s]:
                    dp[i] = True
                    break
        return dp[n]
```

## 复杂度分析

- **时间复杂度**：O(N * sqrt(N))，对每个 i，枚举至多 sqrt(i) 个完全平方数
- **空间复杂度**：O(N)，dp 数组大小

## 关键点总结

1. 博弈论经典模型：`dp[i] = True` 当且仅当存在一种操作让对手陷入必输态
2. `dp[0] = False` 是边界条件（无石子则无法操作）
3. 状态转移：枚举所有完全平方数，若移除后对手必输，则当前玩家必赢
4. 可以提前 `break`，找到一种必赢操作即可

## 易错点

- 忘记 `dp[0] = False` 的设置（默认就是 False，但要理解含义）
- 枚举时 `j * j <= i` 是 `<=`，不是 `<`（等于 i 表示可以拿走所有）
- 记忆化递归时函数参数必须是可哈希的（int 本身可哈希）
