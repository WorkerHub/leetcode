## 题目描述

给定一个整数数组 `nums`，请找出并返回能被 3 整除的元素**最大和**。

**示例 1：**

```
输入：nums = [3,6,5,1,8]
输出：18
解释：选出数字 3, 6, 1 和 8，它们的和是 18（能被 3 整除）
```

**示例 2：**

```
输入：nums = [4]
输出：0
解释：4 不能被 3 整除，所以无法选出任何数字，和为 0
```

**示例 3：**

```
输入：nums = [1,2,3,4,4]
输出：12
解释：选出数字 1, 3, 4 和 4，它们的和是 12（能被 3 整除）
```

**提示：**

- `1 <= nums.length <= 4 * 10^4`
- `1 <= nums[i] <= 10^4`

## 解题思路

这道题的核心是**找到和能被 3 整除的最大子集**。

**关键观察：**

1. 任何整数除以 3 的余数只有三种：0、1、2
2. 若干个数的和能被 3 整除，当且仅当它们的余数之和能被 3 整除
3. 我们需要从数组中选择一些数，使得总和能被 3 整除且尽可能大

**解法思路：**

### 方法一：动态规划（状态机）

定义 `dp[i]` 表示当前选择的数字之和除以 3 余数为 `i` 时的最大和。

- `dp[0]`：余数为 0 的最大和（初始为 0）
- `dp[1]`：余数为 1 的最大和（初始为负无穷）
- `dp[2]`：余数为 2 的最大和（初始为负无穷）

对于每个数字 `num`，其余数为 `r = num % 3`：
- 如果加上 `num`，原本余数为 `i` 的和会变成余数为 `(i + r) % 3` 的和
- 状态转移：`new_dp[(i + r) % 3] = max(new_dp[(i + r) % 3], dp[i] + num)`

### 方法二：贪心（移除最小元素）

1. 计算所有元素的总和 `total`
2. 根据 `total % 3` 的结果：
   - 余数为 0：直接返回 `total`
   - 余数为 1：移除一个余数为 1 的最小元素，或两个余数为 2 的最小元素
   - 余数为 2：移除一个余数为 2 的最小元素，或两个余数为 1 的最小元素

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        # dp[i] 表示余数为 i 时的最大和
        # dp[0] = 0：余数为 0 的初始状态（不选任何数）
        # dp[1], dp[2] = -inf：余数为 1 或 2 的初始状态（不可达）
        dp = [0, float('-inf'), float('-inf')]
        
        for num in nums:
            # 为了避免状态覆盖，需要用临时数组
            temp = dp[:]
            
            for i in range(3):
                # 加上 num 后，余数变为 (i + num%3) % 3
                new_remainder = (i + num) % 3
                temp[new_remainder] = max(temp[new_remainder], dp[i] + num)
            
            dp = temp
        
        # 返回余数为 0 的最大和
        return dp[0]
```

### 方法二：动态规划（简化版）

```python
class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        dp = [0, 0, 0]  # dp[i] 表示余数为 i 的最大和
        
        for num in nums:
            # 对当前 dp 的每个状态，尝试加上 num
            for i in dp[:]:  # 遍历当前状态的副本
                dp[(i + num) % 3] = max(dp[(i + num) % 3], i + num)
        
        return dp[0]
```

### 方法三：贪心（移除最小元素）

```python
class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        # 按余数分组
        mod = [[], [], []]
        for num in nums:
            mod[num % 3].append(num)
        
        # 对每组排序（升序）
        for i in range(3):
            mod[i].sort()
        
        total = sum(nums)
        remainder = total % 3
        
        # 余数为 0，直接返回
        if remainder == 0:
            return total
        
        # 需要移除的最小值
        to_remove = float('inf')
        
        if remainder == 1:
            # 选项 1：移除 1 个余数为 1 的最小元素
            if mod[1]:
                to_remove = min(to_remove, mod[1][0])
            
            # 选项 2：移除 2 个余数为 2 的最小元素
            if len(mod[2]) >= 2:
                to_remove = min(to_remove, mod[2][0] + mod[2][1])
        
        else:  # remainder == 2
            # 选项 1：移除 1 个余数为 2 的最小元素
            if mod[2]:
                to_remove = min(to_remove, mod[2][0])
            
            # 选项 2：移除 2 个余数为 1 的最小元素
            if len(mod[1]) >= 2:
                to_remove = min(to_remove, mod[1][0] + mod[1][1])
        
        # 如果无法移除，返回 0
        return max(0, total - to_remove)
```

### 方法四：Python 极简写法

```python
class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        dp = [0, 0, 0]
        for num in nums:
            for x in dp[:]:
                dp[(x + num) % 3] = max(dp[(x + num) % 3], x + num)
        return dp[0]
```

## 复杂度分析

### 方法一、二、四（动态规划）

- **时间复杂度**：O(n)
  - 遍历数组：O(n)
  - 内层循环固定 3 次：O(3) = O(1)
  - 总计 O(n)

- **空间复杂度**：O(1)
  - DP 数组大小固定为 3

### 方法三（贪心）

- **时间复杂度**：O(n log n)
  - 分组：O(n)
  - 排序：O(n log n)（最坏情况所有元素余数相同）

- **空间复杂度**：O(n)
  - 存储分组

## 关键点总结

1. **余数分类**：任何数除以 3 的余数只有 0、1、2 三种
2. **DP 状态设计**：`dp[i]` 表示余数为 i 的最大和
3. **状态转移**：加上余数为 r 的数，余数从 i 变为 `(i + r) % 3`
4. **初始化**：`dp[0] = 0`（不选任何数），`dp[1] = dp[2] = -inf`（不可达）
5. **贪心思路**：移除最小的元素使余数变为 0

## 易错点

1. **初始化**：`dp[1]` 和 `dp[2]` 应初始化为 `-inf` 或 0，而不是任意值
2. **状态覆盖**：更新 dp 时需要使用临时数组或遍历副本，避免覆盖
3. **返回值**：返回 `dp[0]`，而不是 `max(dp)`
4. **贪心边界**：移除元素前需要检查是否有足够的元素
5. **负数情况**：题目中 `nums[i] >= 1`，无需考虑负数

```

  dp[0] → (0+5)%3=2: dp[2] = max(-inf, 0+5) = 5
  dp[0] → (0+5)%3=2: dp[2] = max(5, 9+5) = 14
  dp = [9, -inf, 14]

处理 1（余数 1）：
  dp[0] → (0+1)%3=1: dp[1] = max(-inf, 0+1) = 1
  dp[0] → (0+1)%3=1: dp[1] = max(1, 9+1) = 10
```
