## 题目描述

给你一个字符串 `s` 和一个整数 `k`。请你用 `s` 字符串中**所有字符**构造 `k` 个非空**回文字符串**。

如果你可以用 `s` 中所有字符构造 `k` 个回文字符串，那么请你返回 `True`；否则，返回 `False`。

**示例 1：**

```
输入：s = "annabelle", k = 2
输出：true
解释：可以用 s 中所有字符构造 2 个回文字符串如下:
"anna" + "elble"，"anbna" + "elle"，"anellena" + "b"
```

**示例 2：**

```
输入：s = "leetcode", k = 3
输出：false
解释：无法用 s 中所有字符构造 3 个回文字符串。
```

**示例 3：**

```
输入：s = "true", k = 4
输出：true
解释：唯一可行的方案是让 k 个回文字符串都是长度为 1 的字符串。
```

**示例 4：**

```
输入：s = "yzyzyzyzyzyzyzy", k = 2
输出：true
解释：只需要将所有的 z 放在第一个字符串中，所有的 y 放在第二个字符串中。两个字符串都是回文字符串。
```

**提示：**

- `1 <= k <= 10^5`
- `1 <= s.length <= 10^5`
- `s` 中所有字符都是小写英文字母

## 解题思路

**贪心分析：**

回文字符串有以下性质：
- 最多只有一个字符出现奇数次（位于中间）
- 其余字符出现偶数次（左右对称）

因此，字符串 `s` 能构造回文的**最少**数量限制是：出现奇数次的字符个数 `odd_count`。

因为每个出现奇数次的字符，至少需要独占一个回文字符串的"中心位置"，不能和其他奇数次字符共用一个回文。

**两个必要且充分条件：**

1. `k <= len(s)`：不能把 `s` 拆成超过 `len(s)` 个字符串（每个字符串至少有一个字符）
2. `k >= odd_count`：奇数频率字符数不能超过 k（每个奇数频率字符至少需要一个独立的回文）

**当两个条件都满足时，答案是 True；否则是 False。**

**证明充分性：** 满足条件时，我们可以：
- 把每个奇数频率字符各放一个回文（只含该字符）
- 把剩余字符分配到这些回文或新的回文中（偶数频率字符可以对半拆开加到任意回文两侧）
- 还剩 `k - odd_count` 个空槽，从任意回文中取偶数对字符填充即可

## Python 代码实现

### 方法一：Counter 统计（推荐）

```python
from collections import Counter

class Solution:
    def canConstruct(self, s: str, k: int) -> bool:
        n = len(s)
        # 条件一：k 不能超过字符串长度
        if k > n:
            return False

        # 统计每个字符的出现频率
        count = Counter(s)
        # 统计出现奇数次的字符个数
        odd_count = sum(1 for freq in count.values() if freq % 2 == 1)

        # 条件二：k 必须不小于奇数频率字符个数
        return odd_count <= k
```

### 方法二：位运算（进阶，仅适用于小写英文字母）

```python
class Solution:
    def canConstruct(self, s: str, k: int) -> bool:
        n = len(s)
        if k > n:
            return False

        # 用一个整数的二进制位表示每个字母出现次数的奇偶性
        # 第 i 位为 1 表示第 i 个字母出现了奇数次
        mask = 0
        for c in s:
            mask ^= (1 << (ord(c) - ord('a')))  # 异或翻转对应位

        # 统计 mask 中 1 的个数（即出现奇数次的字母数）
        odd_count = bin(mask).count('1')
        return odd_count <= k
```

### 方法三：排序 + 统计（直观）

```python
from collections import Counter

class Solution:
    def canConstruct(self, s: str, k: int) -> bool:
        if k > len(s):
            return False
        # 统计奇数频率字符数
        odd_count = 0
        for freq in Counter(s).values():
            if freq % 2 != 0:
                odd_count += 1
        return odd_count <= k
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（Counter） | O(n) | O(1)，最多26个字符 |
| 方法二（位运算） | O(n) | O(1) |

## 图解示例

以 `s = "annabelle"` 为例：

```
字符频率：a:2, n:2, b:1, e:2, l:2
出现奇数次的字符：b（1次）
odd_count = 1

k=2: len(s)=9 >= k=2, odd_count=1 <= k=2, 返回 True
k=2 个回文可以这样构造：
  - "b" 单独成一个回文
  - 剩余 a:2,n:2,e:2,l:2 全部偶数次，构成一个回文 "anella"... 
```

以 `s = "leetcode"` 为例：

```
字符频率：l:1, e:3, t:1, c:1, o:1, d:1
出现奇数次的字符：l, e, t, c, o, d → odd_count = 6

k=3: odd_count=6 > k=3, 返回 False
```

## 关键点总结

1. 回文字符串最多只有一个"奇数频率"字符（即中心字符）
2. 最少需要 `odd_count` 个回文字符串（每个奇数频率字符需要独占一个中心位置）
3. 最多只能构造 `len(s)` 个回文字符串（每个非空）
4. 两个条件：`odd_count <= k <= len(s)`

## 易错点

- 只检查 `odd_count <= k` 而忘了 `k <= len(s)`：`k = 100, s = "a"` 时返回应为 False
- 误以为必须每个字符等量分配，实际上只要满足两个条件就一定可以构造
- 位运算方法中 `^= (1 << bit)` 是翻转位，累积后 `bin(mask).count('1')` 统计奇数位数
