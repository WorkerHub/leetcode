## 题目描述

给定一个员工列表，每个员工对象包含他的 id、重要度和直接下属的 id 列表。

给定一个员工 id，返回这个员工和他所有下属的重要度之和。

**示例：**
```
输入：[[1, 5, [2, 3]], [2, 3, []], [3, 3, []]], 1
输出：11
解释：
员工1的重要度是5，他有两个直接下属2和3，而且2和3的重要度均为3
因此员工1的总重要度是 5 + 3 + 3 = 11
```

## Python 代码实现

### 方法一：DFS

```python
class Employee:
    def __init__(self, id: int, importance: int, subordinates: List[int]):
        self.id = id
        self.importance = importance
        self.subordinates = subordinates

class Solution:
    def getImportance(self, employees: List['Employee'], id: int) -> int:
        # 构建 id 到员工对象的映射
        emp_map = {emp.id: emp for emp in employees}
        
        def dfs(emp_id):
            emp = emp_map[emp_id]
            total = emp.importance
            for sub_id in emp.subordinates:
                total += dfs(sub_id)
            return total
        
        return dfs(id)
```

### 方法二：BFS

```python
from collections import deque

class Solution:
    def getImportance(self, employees: List['Employee'], id: int) -> int:
        emp_map = {emp.id: emp for emp in employees}
        
        queue = deque([id])
        total = 0
        
        while queue:
            emp_id = queue.popleft()
            emp = emp_map[emp_id]
            total += emp.importance
            for sub_id in emp.subordinates:
                queue.append(sub_id)
        
        return total
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 使用哈希表快速查找员工
2. DFS 或 BFS 遍历所有下属
3. 累加所有重要度
