## 题目描述

你的赛车起始停留在位置 `0`，速度为 `+1`，行驶在一根无限长的数轴上。（车也可以向负数方向行驶。）

你的车会根据一系列由 `A`（加速）和 `R`（倒车）组成的指令进行自动驾驶。

当车得到指令 `"A"` 时，将会做以下操作：
- `position += speed`
- `speed *= 2`

当车得到指令 `"R"` 时，将会做以下操作：
- 如果当前速度是正数，则将速度变为 `-1`
- 否则将速度变为 `1`
- 速度会改变但位置不变

例如，当得到一系列指令 `"AAR"` 后，你的车会走过位置 `0 --> 1 --> 3 --> 3`，并且速度变化为 `1 --> 2 --> 4 --> -1`。

给定目标位置 `target`，返回能到达目标位置的最短指令列表的长度。

**示例 1:**
```
输入: target = 3
输出: 2
解释: 
最短指令列表为 "AA"
位置变化为 0 --> 1 --> 3
```

**示例 2:**
```
输入: target = 6
输出: 5
解释: 
最短指令列表为 "AAARA"
位置变化为 0 --> 1 --> 3 --> 7 --> 7 --> 6
```

## Python 代码实现

```python
from collections import deque

class Solution:
    def racecar(self, target: int) -> int:
        queue = deque([(0, 1, 0)])  # (position, speed, steps)
        visited = {(0, 1)}
        
        while queue:
            pos, speed, steps = queue.popleft()
            
            if pos == target:
                return steps
            
            # 指令 A：加速
            new_pos = pos + speed
            new_speed = speed * 2
            if (new_pos, new_speed) not in visited and abs(new_pos) < 2 * target:
                visited.add((new_pos, new_speed))
                queue.append((new_pos, new_speed, steps + 1))
            
            # 指令 R：倒车
            new_speed = -1 if speed > 0 else 1
            if (pos, new_speed) not in visited:
                visited.add((pos, new_speed))
                queue.append((pos, new_speed, steps + 1))
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(T log T)
- **空间复杂度**：O(T log T)

## 关键点总结

1. **BFS搜索**：找最短路径
2. **状态剪枝**：限制位置范围
3. **状态定义**：(位置, 速度)

## 学习建议

1. **BFS应用**：最短路径问题
2. **状态空间**：(位置, 速度) 的二元组
