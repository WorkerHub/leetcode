## 题目描述

给你一棵 `n` 个节点的树（0 号为根），`parent[i]` 为第 `i` 个节点的父节点（`parent[0] = -1`）。

实现 `LockingTree` 类：
- `LockingTree(parent)`: 初始化
- `lock(num, user)`: 若节点 `num` 未被锁定，则锁定给 `user`，返回 `true`，否则返回 `false`
- `unlock(num, user)`: 若节点 `num` 被 `user` 锁定，则解锁，返回 `true`，否则返回 `false`
- `upgrade(num, user)`: 满足以下所有条件时锁定节点 `num`：
  1. 节点 `num` 未被锁定
  2. 至少有一个后代被任意用户锁定
  3. 没有祖先被任意用户锁定
  返回是否成功，成功时解锁所有被锁定的后代。

**提示：**
- `n == parent.length`，`1 <= n <= 2000`
- `1 <= user <= 10^4`

---

## 解题思路

### 核心思想：树结构 + 直接模拟

- 维护每个节点的锁定者（0 表示未锁定）
- `lock`/`unlock` 直接判断并修改
- `upgrade`：
  1. 向上检查祖先（沿 parent 走到根）
  2. 向下检查后代（BFS/DFS）收集被锁定的后代
  3. 条件满足则锁定并解锁所有后代

## 代码实现

### 方法一：树模拟（推荐）

```python
from typing import List
from collections import defaultdict, deque

class LockingTree:

    def __init__(self, parent: List[int]):
        n = len(parent)
        self.parent = parent
        self.locked = [0] * n  # 0 表示未锁定，>0 表示锁定者
        # 构建子节点列表
        self.children = defaultdict(list)
        for i in range(1, n):
            self.children[parent[i]].append(i)

    def lock(self, num: int, user: int) -> bool:
        if self.locked[num] == 0:
            self.locked[num] = user
            return True
        return False

    def unlock(self, num: int, user: int) -> bool:
        if self.locked[num] == user:
            self.locked[num] = 0
            return True
        return False

    def upgrade(self, num: int, user: int) -> bool:
        # 条件 1：节点未被锁定
        if self.locked[num] != 0:
            return False

        # 条件 3：祖先均未被锁定
        cur = self.parent[num]
        while cur != -1:
            if self.locked[cur] != 0:
                return False
            cur = self.parent[cur]

        # 条件 2：至少一个后代被锁定
        # 同时收集所有被锁定的后代
        locked_descendants = []

        def dfs(node):
            for child in self.children[node]:
                if self.locked[child] != 0:
                    locked_descendants.append(child)
                dfs(child)

        dfs(num)

        if not locked_descendants:
            return False

        # 解锁所有后代，锁定 num
        for node in locked_descendants:
            self.locked[node] = 0
        self.locked[num] = user
        return True
```

### 方法二：BFS 版本的 upgrade

```python
from typing import List
from collections import defaultdict, deque

class LockingTree:

    def __init__(self, parent: List[int]):
        n = len(parent)
        self.parent = parent
        self.locked = [0] * n
        self.children = defaultdict(list)
        for i in range(1, n):
            self.children[parent[i]].append(i)

    def lock(self, num: int, user: int) -> bool:
        if self.locked[num] == 0:
            self.locked[num] = user
            return True
        return False

    def unlock(self, num: int, user: int) -> bool:
        if self.locked[num] == user:
            self.locked[num] = 0
            return True
        return False

    def upgrade(self, num: int, user: int) -> bool:
        if self.locked[num] != 0:
            return False

        # 检查祖先
        p = self.parent[num]
        while p != -1:
            if self.locked[p] != 0:
                return False
            p = self.parent[p]

        # BFS 找后代中的锁定节点
        queue = deque(self.children[num])
        to_unlock = []
        while queue:
            node = queue.popleft()
            if self.locked[node] != 0:
                to_unlock.append(node)
            queue.extend(self.children[node])

        if not to_unlock:
            return False

        for node in to_unlock:
            self.locked[node] = 0
        self.locked[num] = user
        return True
```

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| lock/unlock | O(1) | O(1) |
| upgrade | O(n) | O(n) |

---

## 关键点总结

1. 用 `locked` 数组直接记录每个节点的锁定者
2. `upgrade` 需检查祖先链 + 后代子树，均为 O(n)
3. DFS/BFS 后代收集后统一解锁

---

## 易错点

- `upgrade` 需全部条件成立后才修改状态（先检查再修改）
- `locked == 0` 表示未锁定，用户编号从 1 开始
