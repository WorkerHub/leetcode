## 题目描述

给定整数数组 `nums`，对于每个下标 `i`，定义其前缀异或值 `prefix_xor[i] = nums[0] XOR nums[1] XOR ... XOR nums[i]`。

找出数组中两个前缀异或值的最大异或（即 `max(prefix_xor[i] XOR prefix_xor[j])` 对所有 `i, j`）。

**示例 1：**
```
输入：nums = [3,10,5,25,2,8]
输出：28
解释：前缀异或：[3,9,12,21,23,31]，最大异或为 25 XOR 5 = 28... 
     实际：31 XOR 3 = 28。
```

**示例 2：**
```
输入：nums = [0]
输出：0
```

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `0 <= nums[i] <= 2^31 - 1`

## 解题思路

字典树（Trie）求最大异或。

先计算所有前缀异或值，然后用字典树找最大异或对。

对于两个前缀异或值 `a` 和 `b`，`a XOR b = (nums[0..i]) XOR (nums[0..j]) = nums[i+1..j]`（若 i < j）。

**Trie 方法：** 将所有前缀异或值插入 Trie（位从高到低），对每个新值，在 Trie 中贪心匹配最大异或。

## Python 代码实现

### 方法一：字典树（推荐）

```python
from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        # 计算前缀异或
        prefix = [0]
        for x in nums:
            prefix.append(prefix[-1] ^ x)

        # 字典树求最大异或
        max_bits = 31
        trie = {}

        def insert(num):
            node = trie
            for i in range(max_bits, -1, -1):
                bit = (num >> i) & 1
                if bit not in node:
                    node[bit] = {}
                node = node[bit]

        def query(num):
            node = trie
            xor = 0
            for i in range(max_bits, -1, -1):
                bit = (num >> i) & 1
                want = 1 - bit  # 希望异或为 1
                if want in node:
                    xor = (xor << 1) | 1
                    node = node[want]
                else:
                    xor = xor << 1
                    node = node[bit]
            return xor

        ans = 0
        for p in prefix:
            insert(p)
            ans = max(ans, query(p))

        return ans
```

### 方法二：位运算贪心（O(32n)）

```python
from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        prefix = [0]
        for x in nums:
            prefix.append(prefix[-1] ^ x)

        ans = 0
        # 逐位贪心确定最大 XOR 的每一位
        for i in range(31, -1, -1):
            prefix_set = set()
            for p in prefix:
                prefix_set.add(p >> i)

            candidate = ans | (1 << i)
            for p in prefix_set:
                if (candidate ^ p) in prefix_set:
                    ans = candidate
                    break

        # 注意：上面的方法不正确（针对子数组，不直接适用前缀）
        # 直接用集合方法
        prefix_set = set(prefix)
        ans = 0
        mask = 0
        for i in range(31, -1, -1):
            mask |= (1 << i)
            prefix_masked = {p & mask for p in prefix}
            candidate = ans | (1 << i)
            for p in prefix_masked:
                if candidate ^ p in prefix_masked:
                    ans = candidate
                    break

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 32)，Trie 方法
- 空间复杂度：O(n * 32)，Trie 存储

## 关键点总结

1. 前缀异或值 `prefix[i] XOR prefix[j]` 等于子数组 `[i+1, j]` 的 XOR（若 i < j）
2. Trie 贪心：从最高位开始，尽量选与当前位不同的分支（使异或为 1）
3. 包含 `prefix[0] = 0`，确保考虑了以 0 开始的子数组

## 易错点

1. 前缀列表包含初始值 0（空前缀）
2. 字典树插入时需要完整处理所有 32 位
