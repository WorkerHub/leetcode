## 题目描述

在一条无限长的 X 轴上有 n 个石子，每个石子的位置由整数数组 `stones` 给出。

我们称位置最小或最大的石子为端点石子。在一次移动中，你可以选择一个端点石子，将其移动到一个未占用的位置，使其不再是端点石子。

当你无法进行任何移动时，即所有石子的位置都是连续的，游戏结束。

返回一个长度为 2 的整数数组 `answer`，其中：
- `answer[0]` 是你能完成游戏的最少移动次数
- `answer[1]` 是你能完成游戏的最多移动次数

**示例 1：**
```
输入：stones = [7,4,9]
输出：[1,2]
解释：
我们可以移动一次，4 -> 8，游戏结束。
或者，我们可以移动两次 9 -> 5，4 -> 6，游戏结束。
```

**示例 2：**
```
输入：stones = [6,5,4,3,10]
输出：[2,3]
解释：
我们可以移动 3 -> 8，然后移动 10 -> 7，游戏结束。
或者，我们可以移动 3 -> 7, 4 -> 8, 5 -> 9，游戏结束。
注意，我们不能移动 10 -> 2 来结束游戏，因为这是不合法的移动。
```

**示例 3：**
```
输入：stones = [100,101,104,102,103]
输出：[0,0]
解释：
石子已经是连续的，无需移动。
```

**提示：**
- `3 <= stones.length <= 10^4`
- `1 <= stones[i] <= 10^9`
- `stones[i]` 的值各不相同

## 解题思路

这道题要求计算最少和最多的移动次数，需要分别考虑：

### 最多移动次数

最多移动次数比较容易理解：
- 为了让移动次数最多，我们应该每次只移动一个格子
- 由于只能移动端点石子，我们可以选择从左端或右端开始移动
- 从左端移动：将最左边的石子依次向右移动到空位
- 从右端移动：将最右边的石子依次向左移动到空位

关键观察：
- 排序后，假设石子位置为 `[s0, s1, ..., sn-1]`
- 如果从左端移动：最左石子 s0 可以移动到 s1+1, s1+2, ..., sn-1-1 的空位
  - 移动次数 = (sn-1 - s1) - (n-2)，即空位数量
- 如果从右端移动：最右石子 sn-1 可以移动到 s0+1, s0+2, ..., sn-2-1 的空位
  - 移动次数 = (sn-2 - s0) - (n-2)

最大值取两者之大。

### 最少移动次数

最少移动次数需要用滑动窗口思想：
- 目标是找到一个长度为 n 的连续区间，使得已有的石子数量最多
- 使用滑动窗口找到一个区间 `[stones[l], stones[r]]`，使得 `stones[r] - stones[l] + 1 <= n`
- 区间内已有 `r - l + 1` 个石子，需要移动 `n - (r - l + 1)` 次

特殊情况：
- 如果已有 n-1 个石子在连续的 n-1 个位置上（如 [1,2,3,5]），需要 2 次移动
- 因为不能一次移动端点石子到中间的空位

## Python 代码实现

### 方法一：滑动窗口 + 贪心（推荐）

```python
from typing import List

class Solution:
    def numMovesStonesII(self, stones: List[int]) -> List[int]:
        n = len(stones)
        stones.sort()  # 先排序
        
        # 计算最大移动次数
        # 从左端移动：将 s0 依次移动到 s1 右边的空位
        max_moves_from_left = stones[n-1] - stones[1] - (n-2)
        # 从右端移动：将 sn-1 依次移动到 sn-2 左边的空位
        max_moves_from_right = stones[n-2] - stones[0] - (n-2)
        max_moves = max(max_moves_from_left, max_moves_from_right)
        
        # 计算最小移动次数 - 使用滑动窗口
        min_moves = n  # 初始化为最大可能值
        left = 0
        
        for right in range(n):
            # 保持窗口大小不超过 n
            while stones[right] - stones[left] + 1 > n:
                left += 1
            
            # 当前窗口内已有的石子数量
            stones_in_window = right - left + 1
            
            # 特殊情况：如果有 n-1 个石子在连续的 n-1 个位置
            # 例如 [1,2,3,5]，需要 2 次移动而不是 1 次
            if stones_in_window == n - 1 and stones[right] - stones[left] + 1 == n - 1:
                min_moves = min(min_moves, 2)
            else:
                # 需要移动的石子数 = 总数 - 窗口内已有的石子数
                min_moves = min(min_moves, n - stones_in_window)
        
        return [min_moves, max_moves]
```

### 方法二：详细注释版（便于理解）

```python
from typing import List

class Solution:
    def numMovesStonesII(self, stones: List[int]) -> List[int]:
        n = len(stones)
        stones.sort()
        
        # ===== 计算最大移动次数 =====
        # 策略：每次只移动一格，最大化移动次数
        
        # 选项1：固定最右边的 n-1 个石子，移动最左边的石子
        # 最左边石子可以移动到 [stones[1]+1, stones[n-1]-1] 的空位
        # 空位数 = (stones[n-1] - stones[1] - 1) - (n-2)
        #        = stones[n-1] - stones[1] - n + 1
        max_option1 = stones[n-1] - stones[1] - n + 2
        
        # 选项2：固定最左边的 n-1 个石子，移动最右边的石子
        # 最右边石子可以移动到 [stones[0]+1, stones[n-2]-1] 的空位
        max_option2 = stones[n-2] - stones[0] - n + 2
        
        max_moves = max(max_option1, max_option2)
        
        # ===== 计算最小移动次数 =====
        # 策略：找到一个长度为 n 的区间，使得区间内已有的石子最多
        # 使用滑动窗口
        
        min_moves = n
        left = 0
        
        for right in range(n):
            # 窗口区间为 [stones[left], stones[right]]
            # 区间长度为 stones[right] - stones[left] + 1
            
            # 如果区间长度大于 n，缩小窗口
            while stones[right] - stones[left] + 1 > n:
                left += 1
            
            # 当前窗口内有多少个石子
            count = right - left + 1
            
            # 特殊情况处理
            # 如果有 n-1 个石子占据了连续的 n-1 个位置
            # 例如：[1,2,3,5]，n=4，窗口 [1,3] 有 3 个石子，占据 3 个连续位置
            # 此时不能一次移动完成，需要 2 次
            if count == n - 1 and stones[right] - stones[left] + 1 == n - 1:
                min_moves = min(min_moves, 2)
            else:
                # 需要移动 n - count 个石子进入这个窗口
                min_moves = min(min_moves, n - count)
        
        return [min_moves, max_moves]
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def numMovesStonesII(self, stones: List[int]) -> List[int]:
        stones.sort()
        n, min_moves = len(stones), len(stones)
        
        # 最大移动次数
        max_moves = max(stones[-1] - stones[1] - n + 2, 
                       stones[-2] - stones[0] - n + 2)
        
        # 最小移动次数 - 滑动窗口
        l = 0
        for r in range(n):
            while stones[r] - stones[l] >= n:
                l += 1
            if r - l + 1 == n - 1 and stones[r] - stones[l] == n - 2:
                min_moves = min(min_moves, 2)
            else:
                min_moves = min(min_moves, n - (r - l + 1))
        
        return [min_moves, max_moves]
```

## 复杂度分析

- **时间复杂度**：O(n log n)，主要是排序的时间复杂度，滑动窗口遍历是 O(n)
- **空间复杂度**：O(1)，只使用常数额外空间（排序可能需要 O(log n) 栈空间）

## 图解示例

以 `stones = [6,5,4,3,10]` 为例：

```
排序后：[3,4,5,6,10]

最大移动次数：
选项1：固定 [4,5,6,10]，移动 3
  3 可以移动到 5,7,8,9（4个空位中的3个）
  移动次数 = 10 - 4 - 5 + 2 = 3
  
选项2：固定 [3,4,5,6]，移动 10
  10 可以移动到 7（1个空位）
  移动次数 = 6 - 3 - 5 + 2 = 0（不对）
  实际：10 可以移动到 [4,6] 之间的 5 已被占用，无法移动

实际计算：max(3, 0) = 3（但第二个应该是贪心计算）

最小移动次数：
窗口 [3,6]：长度4，有4个石子 -> 需要移动1个（10进来）

最优窗口：[3,6] 或 [4,10-4=6]
```

## 关键点总结

1. **排序是基础**：首先对石子位置排序
2. **最大移动贪心**：每次移动一格，考虑固定左边 n-1 个或右边 n-1 个石子
3. **最小移动滑动窗口**：找一个长度不超过 n 的区间，使得区间内石子最多
4. **特殊情况**：n-1 个石子占据连续 n-1 个位置时，需要 2 次移动
5. **端点限制**：只能移动端点石子，这是问题的核心约束

## 易错点

1. **特殊情况处理**：容易忽略 n-1 个连续石子的特殊情况，误认为只需 1 次移动
2. **滑动窗口条件**：窗口长度应该是 `stones[r] - stones[l] + 1 <= n`，不是 `< n`
3. **最大移动计算**：要考虑两种方向的移动，取最大值
4. **边界情况**：所有石子已经连续时，返回 `[0, 0]`
