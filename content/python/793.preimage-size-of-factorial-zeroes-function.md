## 题目描述

`f(x)` 是 `x!` 末尾是 0 的数量。回想一下 `x! = 1 * 2 * 3 * ... * x`，且 `0! = 1`。

例如，`f(3) = 0`，因为 `3! = 6` 的末尾没有 0；而 `f(11) = 2`，因为 `11! = 39916800` 末尾有 2 个 0。

给定 `k`，找出返回能满足 `f(x) = k` 的非负整数 `x` 的数量。

**示例 1：**
```
输入：k = 0
输出：5
解释：0!, 1!, 2!, 3!, 和 4! 末尾的零的个数都是 0
```

**示例 2：**
```
输入：k = 5
输出：0
解释：没有 x 满足 f(x) = 5
```

**示例 3：**
```
输入：k = 3
输出：5
```

**提示：**
- `0 <= k <= 10^9`

## 解题思路

这道题是 [LeetCode 172. 阶乘后的零](https://leetcode.com/problems/factorial-trailing-zeroes/) 的进阶版本。

**背景知识：如何计算 n! 末尾有多少个 0？**

末尾的 0 来自于 10 = 2 × 5，而在阶乘中：
- 因子 2 的数量总是比因子 5 多
- 所以 0 的个数取决于因子 5 的个数

计算 n! 中因子 5 的个数：
```
f(n) = n/5 + n/25 + n/125 + ...
```

例如：
- `f(10) = 10/5 + 10/25 = 2 + 0 = 2`
- `f(25) = 25/5 + 25/25 + 25/125 = 5 + 1 + 0 = 6`

**核心观察：**
1. `f(n)` 是单调递增的（随着 n 增大，f(n) 不会减少）
2. 但 `f(n)` 不是连续的，有些 k 值不可能出现
3. 如果 k 可以出现，那么满足 `f(n) = k` 的 n 的个数要么是 0，要么是 5

**为什么是 0 或 5？**

关键观察：如果存在 n 使得 `f(n) = k`，那么 `f(n+1)`, `f(n+2)`, `f(n+3)`, `f(n+4)` 也都等于 k（除非 n+1, n+2 等能被 5 整除）。

具体来说：
- 只有当 n 是 5 的倍数时，f(n) 才会增加
- 所以如果 f(n) = k，那么 f(n), f(n+1), f(n+2), f(n+3), f(n+4) 都等于 k（假设 n 不是 5 的倍数）
- 下一个改变发生在 n+5 处

因此，**答案只能是 0 或 5**。

**解法：二分查找**

1. 使用二分查找找到最小的 n 使得 `f(n) >= k`
2. 检查 `f(n) == k` 是否成立
3. 如果成立，返回 5；否则返回 0

## Python 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def preimageSizeFZF(self, k: int) -> int:
        """
        计算有多少个 x 满足 f(x) = k
        
        思路：使用二分查找，答案只能是 0 或 5
        
        参数：
            k: 目标零的个数
            
        返回：
            满足条件的 x 的个数
        """
        # 如果能找到 n 使得 f(n) = k，返回 5，否则返回 0
        return 5 if self.find_first(k) != -1 else 0
    
    def find_first(self, k: int) -> int:
        """
        找到最小的 n 使得 f(n) = k
        
        参数：
            k: 目标零的个数
            
        返回：
            最小的 n，如果不存在返回 -1
        """
        # 二分查找范围：0 到 5 * (k + 1)
        # 因为 f(n) 大约是 n/5，所以 n 大约是 5*k
        left, right = 0, 5 * (k + 1)
        
        while left <= right:
            mid = (left + right) // 2
            zeros = self.trailing_zeros(mid)
            
            if zeros == k:
                return mid
            elif zeros < k:
                left = mid + 1
            else:
                right = mid - 1
        
        return -1
    
    def trailing_zeros(self, n: int) -> int:
        """
        计算 n! 末尾零的个数
        
        参数：
            n: 阶乘的数
            
        返回：
            n! 末尾零的个数
        """
        count = 0
        while n > 0:
            n //= 5
            count += n
        return count
```

### 方法二：优化的二分查找

```python
class Solution:
    def preimageSizeFZF(self, k: int) -> int:
        """
        优化版本：直接在二分中判断
        """
        def trailing_zeros(n: int) -> int:
            """计算 n! 末尾零的个数"""
            count = 0
            while n > 0:
                n //= 5
                count += n
            return count
        
        # 二分查找 k 是否存在
        left, right = 0, 5 * k + 1
        
        # 找到第一个 f(n) >= k 的位置
        while left < right:
            mid = (left + right) // 2
            zeros = trailing_zeros(mid)
            
            if zeros < k:
                left = mid + 1
            else:
                right = mid
        
        # 检查 f(left) 是否等于 k
        return 5 if trailing_zeros(left) == k else 0
```

### 方法三：数学分析

```python
class Solution:
    def preimageSizeFZF(self, k: int) -> int:
        """
        基于数学性质的解法
        
        思路：答案只能是 0 或 5
        检查是否存在 n 使得 f(n) = k
        """
        def trailing_zeros(n: int) -> int:
            """计算 n! 末尾零的个数"""
            result = 0
            power_of_5 = 5
            while power_of_5 <= n:
                result += n // power_of_5
                power_of_5 *= 5
            return result
        
        # 二分搜索上下界
        def binary_search_lower(target: int) -> int:
            """找到第一个 >= target 的位置"""
            left, right = 0, 5 * target + 1
            while left < right:
                mid = (left + right) // 2
                if trailing_zeros(mid) < target:
                    left = mid + 1
                else:
                    right = mid
            return left
        
        # 检查是否存在
        n = binary_search_lower(k)
        return 5 if trailing_zeros(n) == k else 0
```

## 复杂度分析

### 所有方法
- **时间复杂度：** O(log²k)
  - 二分查找：O(log k)
  - 每次计算 trailing_zeros：O(log k)
  - 总计：O(log k × log k) = O(log²k)
- **空间复杂度：** O(1)，只使用常数额外空间

## 关键点总结

1. **阶乘零的计算**：`f(n) = n/5 + n/25 + n/125 + ...`，这是基础知识
2. **单调性**：f(n) 随 n 单调递增，可以使用二分查找
3. **离散性**：f(n) 不是连续的，某些值（如 5）不可能出现
4. **答案规律**：答案只能是 0 或 5，不会是其他数字
5. **二分范围**：上界可以设为 `5 * (k + 1)`，因为 f(n) 大约等于 n/5

## 易错点

1. **二分上界**：不要设置过小，`5 * k` 可能不够，建议用 `5 * (k + 1)`
2. **trailing_zeros 实现**：循环条件是 `n > 0`，不是 `power_of_5 <= n`
3. **返回值**：只能返回 0 或 5，不要返回其他值
4. **边界情况**：k = 0 时，0!, 1!, 2!, 3!, 4! 都满足，返回 5
5. **整数溢出**：Python 没有整数溢出问题，但其他语言需要注意
