## 题目描述

给你一个正整数数组 `nums`，你可以对数组执行若干次替换操作：将 `nums[i]` 替换为**两个**正整数，满足这两个正整数之和等于 `nums[i]`。

返回使 `nums` **非递减**所需的**最少替换次数**。

**示例 1：**
```
输入：nums = [3,9,3]
输出：2
解释：将 9 替换为 [3,6]，数组变为 [3,3,6,3]；再将 6 替换为 [3,3]，变为 [3,3,3,3,3]，非递减。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**从后向前贪心：**

从右到左处理，维护当前允许的最大上界 `limit`（初始为 `nums[n-1]`）。

对于 `nums[i]`：
- 若 `nums[i] <= limit`：不需要替换，更新 `limit = nums[i]`。
- 若 `nums[i] > limit`：需要将 `nums[i]` 分成若干个 <= `limit` 的数。
  - 分成 `k = ceil(nums[i] / limit)` 份，每份不超过 `limit`。
  - 为了让最左边的那份尽可能小（给左边更多空间），最左边的份 = `nums[i] // k`。
  - 替换次数 += `k - 1`（分成 k 份需要 k-1 次操作）。
  - 更新 `limit = nums[i] // k`。

## 代码实现

### 方法一：从后向前贪心（推荐）

```python
from typing import List
import math

class Solution:
    def minimumReplacement(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0
        limit = nums[-1]  # 当前允许的最大值
        
        for i in range(n - 2, -1, -1):
            if nums[i] <= limit:
                limit = nums[i]  # 无需替换，更新 limit
            else:
                # 需要将 nums[i] 分成 k 份，每份 <= limit
                k = math.ceil(nums[i] / limit)
                ops += k - 1  # k 份需要 k-1 次操作
                # 最左边的份尽量小，给左边的元素更多空间
                limit = nums[i] // k
        
        return ops
```

### 方法二：手动向上取整版

```python
from typing import List

class Solution:
    def minimumReplacement(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        upper = nums[-1]
        
        for i in range(n - 2, -1, -1):
            v = nums[i]
            if v <= upper:
                upper = v
                continue
            # 向上取整：(v + upper - 1) // upper
            k = (v + upper - 1) // upper
            ans += k - 1
            upper = v // k  # 最小的那份
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(1) |

## 关键点总结

1. 从右向左处理，维护左边元素的上界 `limit`。
2. 若当前元素 > limit，分成 `ceil(v/limit)` 份；最左份尽量小（`v // k`），为左边留空间。
3. 分成 k 份需要 k-1 次操作。

## 易错点

- 最左份的值是 `v // k`（整除），不是 `v / k`。
- 贪心方向：从右向左，因为右边的元素不能再修改（已确定上界）。
