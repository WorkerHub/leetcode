## 题目描述

给定两个整数组 `group1`（大小 `m`）和 `group2`（大小 `n`），以及代价矩阵 `cost`，其中 `cost[i][j]` 表示连接 `group1[i]` 和 `group2[j]` 的代价。

每个 `group1[i]` 必须连接到至少一个 `group2[j]`，每个 `group2[j]` 必须连接到至少一个 `group1[i]`。求最小总代价。

本题与 LeetCode 1595 类似，但数据范围或约束有所不同。

**示例 1：**
```
输入：cost = [[15,96],[36,2]]
输出：17
解释：连接 (0,1) 代价 96，连接 (1,1) 代价 2，连接 (1,0) 代价 36... 
     最优：(0,0)=15 和 (1,1)=2，总代价 17。
```

**示例 2：**
```
输入：cost = [[1,3,5],[4,1,1],[1,5,3]]
输出：4
```

**提示：**
- `1 <= m, n <= 12`
- `1 <= cost[i][j] <= 100`

## 解题思路

状态压缩 DP（位掩码 DP）。

由于 `n <= 12`，可以用 `n` 位的掩码表示 `group2` 中已被连接的节点集合。

`dp[i][mask]`：前 `i` 个 `group1` 节点已处理，`group2` 中被覆盖的节点集合为 `mask` 时的最小代价。

转移：处理第 `i` 个节点时，选择连接 `group2` 的某个子集 `s`，代价为 `min(cost[i][j] for j in s)`（需覆盖至少一个节点）。

实际上每个 `group1[i]` 至少连接一个 `group2[j]`，选择连接 `group2` 的哪些节点。

最终 `dp[m][(1<<n)-1]` 为答案（所有 `group2` 节点均被覆盖）。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        m, n = len(cost), len(cost[0])
        full = (1 << n) - 1
        INF = float('inf')

        # min_cost[j]: 连接 group2[j] 的最小代价
        min_cost = [min(cost[i][j] for i in range(m)) for j in range(n)]

        # dp[mask]: 处理完所有 group1 节点，group2 已覆盖集合为 mask 的最小代价
        dp = [INF] * (1 << n)
        dp[0] = 0

        for i in range(m):
            new_dp = [INF] * (1 << n)
            for mask in range(1 << n):
                if dp[mask] == INF:
                    continue
                # 枚举第 i 个 group1 节点连接 group2 的某个节点 j
                for j in range(n):
                    new_mask = mask | (1 << j)
                    new_dp[new_mask] = min(new_dp[new_mask], dp[mask] + cost[i][j])
            dp = new_dp

        # 对未覆盖的 group2 节点，用 min_cost 补充
        ans = INF
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            extra = 0
            for j in range(n):
                if not (mask >> j & 1):
                    extra += min_cost[j]
            ans = min(ans, dp[mask] + extra)

        return ans
```

### 方法二：递推 DP + 位掩码

```python
from typing import List

class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        m, n = len(cost), len(cost[0])
        min_j = [min(cost[i][j] for i in range(m)) for j in range(n)]
        INF = float('inf')

        # dp[i][mask]
        dp = [[INF] * (1 << n) for _ in range(m + 1)]
        dp[0][0] = 0

        for i in range(1, m + 1):
            for mask in range(1 << n):
                for j in range(n):
                    prev_mask = mask & ~(1 << j)  # 去掉 j 位
                    if dp[i-1][prev_mask] != INF:
                        dp[i][mask] = min(dp[i][mask],
                                         dp[i-1][prev_mask] + cost[i-1][j])

        ans = INF
        for mask in range(1 << n):
            if dp[m][mask] == INF:
                continue
            extra = sum(min_j[j] for j in range(n) if not (mask >> j & 1))
            ans = min(ans, dp[m][mask] + extra)

        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n * 2^n)
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 12 使得状态压缩 DP 可行（2^12 = 4096 个状态）
2. 未被覆盖的 group2 节点用其最便宜的连接方式补充
3. 每次 group1 节点处理时，选一个 group2 节点，更新掩码

## 易错点

1. 最终需要确保所有 group2 节点均被覆盖，未覆盖的需额外处理
2. 处理顺序：先 group1 节点，再补充未覆盖的 group2 节点
