## 题目描述

给定一个化学式 `formula`（字符串），返回每种原子的数量。

原子总是以一个大写字母开始，接着可能有若干小写字母。如果数字出现在元素后面，表示该元素的数量，没有数字则默认为1。

括号可以嵌套，括号后面的数字表示括号内所有元素的倍数。

返回格式：按字母序排列，每个元素名称后跟数量（数量为1时也要显示）。

**示例 1：**
```
输入: formula = "H2O"
输出: "H2O"
解释: 原子数量为 {"H": 2, "O": 1}
```

**示例 2：**
```
输入: formula = "Mg(OH)2"
输出: "H2MgO2"
解释: 原子数量为 {"H": 2, "Mg": 1, "O": 2}
```

**示例 3：**
```
输入: formula = "K4(ON(SO3)2)2"
输出: "K4N2O14S4"
解释:
括号展开后: K4 + 2 * (ON(SO3)2)
= K4 + 2 * (O + N + 2*(SO3))
= K4 + 2 * (O + N + 2*S + 2*3*O)
= K4 + 2*O + 2*N + 4*S + 12*O
= K4 + N2 + S4 + 14*O
```

**提示：**
- `1 <= formula.length <= 1000`
- `formula` 由英文字母、数字、`(` 和 `)` 组成
- `formula` 是有效的化学式

## 解题思路

这是一个典型的表达式解析问题，需要处理括号嵌套和数字倍数。使用栈来处理括号是最直观的方法。

**核心思想：**
1. 使用栈存储不同层级的原子计数
2. 遇到 `(` 时，压入新的字典到栈
3. 遇到 `)` 时，弹出栈顶字典，读取倍数，合并到上一层
4. 遇到元素名时，读取完整的元素名和数量

**解析流程：**
```
K4(ON(SO3)2)2

1. 读取 K4 → {K: 4}
2. 遇到 ( → 栈压入新字典
3. 读取 O → 当前层 {O: 1}
4. 读取 N → 当前层 {O: 1, N: 1}
5. 遇到 ( → 栈再压入新字典
6. 读取 SO3 → 当前层 {S: 1, O: 3}
7. 遇到 )2 → 弹出并乘以2，合并到上层 {O: 1, N: 1, S: 2, O: 6}
8. 遇到 )2 → 弹出并乘以2，合并到最外层
```

## Python 代码实现

### 方法一：栈 + 哈希表（推荐）

```python
from typing import Dict
from collections import defaultdict

class Solution:
    def countOfAtoms(self, formula: str) -> str:
        n = len(formula)
        stack = [defaultdict(int)]  # 栈，每层存储一个字典
        i = 0
        
        while i < n:
            # 情况1：遇到左括号
            if formula[i] == '(':
                stack.append(defaultdict(int))
                i += 1
            
            # 情况2：遇到右括号
            elif formula[i] == ')':
                i += 1
                # 读取括号后的数字
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                multiplier = int(formula[start:i]) if start < i else 1
                
                # 弹出栈顶，合并到上一层
                top = stack.pop()
                for atom, count in top.items():
                    stack[-1][atom] += count * multiplier
            
            # 情况3：遇到元素名
            else:
                # 读取元素名（大写字母开头）
                start = i
                i += 1
                while i < n and formula[i].islower():
                    i += 1
                atom = formula[start:i]
                
                # 读取数量
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                count = int(formula[start:i]) if start < i else 1
                
                # 添加到当前层
                stack[-1][atom] += count
        
        # 构建结果字符串
        result = []
        atom_count = stack[0]
        for atom in sorted(atom_count.keys()):
            result.append(atom)
            if atom_count[atom] > 1:
                result.append(str(atom_count[atom]))
        
        return ''.join(result)
```

### 方法二：递归解析

```python
from typing import Dict
from collections import defaultdict

class Solution:
    def countOfAtoms(self, formula: str) -> str:
        self.formula = formula
        self.index = 0
        
        def parse() -> Dict[str, int]:
            """递归解析化学式，返回原子计数字典"""
            counts = defaultdict(int)
            
            while self.index < len(self.formula):
                char = self.formula[self.index]
                
                if char == '(':
                    self.index += 1
                    # 递归解析括号内的内容
                    sub_counts = parse()
                    # 读取倍数
                    multiplier = self.read_number()
                    # 合并结果
                    for atom, count in sub_counts.items():
                        counts[atom] += count * multiplier
                
                elif char == ')':
                    self.index += 1
                    return counts
                
                else:
                    # 读取元素名和数量
                    atom = self.read_atom()
                    count = self.read_number()
                    counts[atom] += count
            
            return counts
        
        def read_atom() -> str:
            """读取元素名"""
            start = self.index
            self.index += 1
            while self.index < len(self.formula) and self.formula[self.index].islower():
                self.index += 1
            return self.formula[start:self.index]
        
        def read_number() -> int:
            """读取数字，默认返回1"""
            start = self.index
            while self.index < len(self.formula) and self.formula[self.index].isdigit():
                self.index += 1
            return int(self.formula[start:self.index]) if start < self.index else 1
        
        # 解析化学式
        atom_counts = parse()
        
        # 构建结果
        result = []
        for atom in sorted(atom_counts.keys()):
            result.append(atom)
            if atom_counts[atom] > 1:
                result.append(str(atom_counts[atom]))
        
        return ''.join(result)
```

### 方法三：正则表达式辅助

```python
import re
from collections import defaultdict

class Solution:
    def countOfAtoms(self, formula: str) -> str:
        # 使用栈处理括号
        stack = [defaultdict(int)]
        i = 0
        
        while i < len(formula):
            if formula[i] == '(':
                stack.append(defaultdict(int))
                i += 1
            elif formula[i] == ')':
                i += 1
                # 匹配数字
                match = re.match(r'\d+', formula[i:])
                multiplier = int(match.group()) if match else 1
                i += len(match.group()) if match else 0
                
                top = stack.pop()
                for atom, count in top.items():
                    stack[-1][atom] += count * multiplier
            else:
                # 匹配元素名和数量
                match = re.match(r'([A-Z][a-z]*)(\d*)', formula[i:])
                atom = match.group(1)
                count = int(match.group(2)) if match.group(2) else 1
                stack[-1][atom] += count
                i += len(match.group())
        
        # 构建结果
        counts = stack[0]
        return ''.join(atom + (str(counts[atom]) if counts[atom] > 1 else '') 
                      for atom in sorted(counts))
```

## 复杂度分析

**时间复杂度：** O(n²)，其中 n 是字符串长度。最坏情况下需要多次合并字典，每次合并最多涉及 O(n) 个元素

**空间复杂度：** O(n)，栈的深度最多为 O(n)（嵌套括号），每层字典最多存储 O(n) 个元素

## 关键点总结

1. **栈处理括号**：每层括号对应栈中的一个字典
2. **字符串解析**：需要区分大写字母、小写字母、数字、括号
3. **倍数处理**：括号后的数字影响整个括号内的所有元素
4. **字典合并**：使用 `defaultdict(int)` 简化计数逻辑
5. **结果排序**：最终按字母序输出

## 易错点

1. **元素名解析**
   - 元素名可能是一个字母（如 H）或两个字母（如 Mg）
   - 必须读取完整的元素名（大写字母 + 可能的小写字母）

2. **数字默认值**
   - 元素或括号后没有数字时，默认为1

3. **括号倍数**
   - 右括号后的数字影响整个括号内的内容
   - 需要先弹出字典，乘以倍数，再合并到上一层

4. **结果格式**
   - 按字母序排列
   - 数量为1时不显示（题目示例中显示，需要检查具体要求）

5. **栈初始化**
   - 栈初始应包含一个空字典，而不是空栈
