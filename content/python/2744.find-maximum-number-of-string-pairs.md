## 题目描述

给你一个下标从 **0** 开始的字符串数组 `words`，每个字符串长度为 2。

如果 `words[i]` 等于 `words[j]` 的反转，则称 `(i, j)` 为一对字符串（`i < j`）。每个字符串最多只能属于一对。

返回最多能形成的字符串对数目。

**示例 1：**
```
输入：words = ["cd","ac","dc","ca","zz"]
输出：2
解释：("cd","dc") 和 ("ac","ca") 各一对，共 2 对
```

**示例 2：**
```
输入：words = ["ab","ba","cc"]
输出：1
```

**提示：**
- `1 <= words.length <= 50`
- `words[i].length == 2`

## 解题思路

用哈希集合存已见过的字符串，遍历每个字符串时检查其反转是否在集合中。注意 `"zz"` 的反转是 `"zz"` 本身。

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def maximumNumberOfStringPairs(self, words: List[str]) -> int:
        seen = set()
        ans = 0

        for word in words:
            rev = word[::-1]
            if rev in seen:
                ans += 1
                seen.discard(rev)  # 已配对，从集合移除（每个字符串只配对一次）
            else:
                seen.add(word)

        return ans
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def maximumNumberOfStringPairs(self, words: List[str]) -> int:
        n = len(words)
        used = [False] * n
        ans = 0
        for i in range(n):
            if used[i]:
                continue
            for j in range(i + 1, n):
                if not used[j] and words[i] == words[j][::-1]:
                    ans += 1
                    used[i] = used[j] = True
                    break
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n^2)，空间复杂度 O(n)

## 关键点总结

1. 每个字符串最多参与一对
2. 字符串长度固定为 2，反转操作很快

## 易错点

1. 字符串已配对后要从集合中移除，防止重复配对
2. `"zz"` 自己的反转是 `"zz"`，可以自配对
