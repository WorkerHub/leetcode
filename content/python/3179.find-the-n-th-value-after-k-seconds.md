## 题目描述

给你两个整数 `n` 和 `k`。

初始有一个数组 `a = [1, 1, ..., 1]`（共 `n` 个 1）。

每秒，将每个元素替换为其自身到末尾的前缀和：即 `a[i] = sum(a[i..n-1])`（原值用于计算，不是就地更新）。

返回 `k` 秒后数组第一个元素 `a[0]` 的值，对 `10^9 + 7` 取模。

**示例：**
```
输入：n = 4, k = 5
输出：56
```

**提示：**
- `1 <= n, k <= 1000`

## 解题思路

观察规律：k 秒后，`a[0] = C(n-1+k, k)`（组合数）。

可以通过模拟验证，或用数学推导。

实际上 `a[0]` 的值等于 `C(n + k - 1, k)`。

## Python 代码实现

### 方法一：数学（组合数）（推荐）

```python
from math import comb

class Solution:
    def valueAfterKSeconds(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        return comb(n + k - 1, k) % MOD
```

### 方法二：模拟

```python
from typing import List

class Solution:
    def valueAfterKSeconds(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        a = [1] * n
        for _ in range(k):
            # 从右到左计算后缀和（从后往前，这样可以就地更新）
            for i in range(n - 2, -1, -1):
                a[i] = (a[i] + a[i + 1]) % MOD
        return a[0]
```

## 复杂度分析

- 时间复杂度：O(n * k)（模拟），O(n + k)（组合数）
- 空间复杂度：O(n)（模拟），O(1)（组合数）

## 关键点总结

1. k 秒后 a[0] = C(n+k-1, k)
2. 可以通过模拟验证规律
3. 使用 Python 内置 comb 函数计算组合数

## 易错点

1. 模拟时注意是从右向左更新（后缀和）
2. 注意对 MOD 取模
