## 题目描述

给定两个长度相同的字符串 `s1` 和 `s2`，以及一个字符串 `baseStr`。

在每一个位置 `i`，字符 `s1[i]` 和 `s2[i]` 是等价的。等价关系具有传递性：
- 如果 `a` 和 `b` 等价，`b` 和 `c` 等价，那么 `a` 和 `c` 等价

返回 `baseStr` 的**字典序最小等价字符串**。即将 `baseStr` 中的每个字符替换成与其等价的字典序最小的字符。

**示例 1：**
```
输入：s1 = "parker", s2 = "morris", baseStr = "parser"
输出："makkek"
解释：
等价关系：p-m, a-o, r-r(无意义), k-i, e-s
等价类：{p,m}, {a,o}, {r}, {k,i}, {e,s}
最小代表：p→m, a→a, r→r, s→e, e→e, r→r
结果："makkek"
```

**示例 2：**
```
输入：s1 = "hello", s2 = "world", baseStr = "hold"
输出："hdld"
解释：
等价关系：h-w, e-o, l-r, l-l, o-d
等价类：{h,w}, {e,o,d}, {l,r}
最小代表：h→h, o→d, l→l, d→d
结果："hdld"
```

**示例 3：**
```
输入：s1 = "leetcode", s2 = "programs", baseStr = "sourcecode"
输出："aauaaaaada"
```

**提示：**
- `1 <= s1.length, s2.length, baseStr.length <= 1000`
- `s1.length == s2.length`
- `s1`、`s2` 和 `baseStr` 只包含小写英文字母

## 解题思路

这道题是**并查集（Union-Find）**的经典应用。

**核心思想：**
1. 使用并查集维护字符的等价关系
2. 每个等价类选择字典序最小的字符作为代表
3. 将 `baseStr` 中的每个字符替换为其等价类的最小代表

**算法流程：**
1. 初始化并查集，每个字符的父节点是自己
2. 遍历 `s1` 和 `s2`，将等价的字符合并（union）
3. 合并时保证较小的字符成为父节点（代表元素）
4. 对 `baseStr` 中的每个字符，找到其等价类的最小代表并替换

## Python 代码实现

### 方法一：并查集（推荐）

```python
class Solution:
    def smallestEquivalentString(self, s1: str, s2: str, baseStr: str) -> str:
        """
        时间复杂度：O(n + m)，n 是 s1 长度，m 是 baseStr 长度
        空间复杂度：O(26) = O(1)
        """
        # 并查集：每个字符映射到其父节点
        parent = {chr(i): chr(i) for i in range(ord('a'), ord('z') + 1)}
        
        def find(x: str) -> str:
            """查找根节点（代表元素）"""
            if parent[x] != x:
                parent[x] = find(parent[x])  # 路径压缩
            return parent[x]
        
        def union(x: str, y: str):
            """合并两个集合，保证较小的字符成为根"""
            root_x = find(x)
            root_y = find(y)
            
            if root_x != root_y:
                # 让字典序小的成为父节点
                if root_x < root_y:
                    parent[root_y] = root_x
                else:
                    parent[root_x] = root_y
        
        # 建立等价关系
        for c1, c2 in zip(s1, s2):
            union(c1, c2)
        
        # 构建结果字符串
        result = []
        for char in baseStr:
            result.append(find(char))
        
        return ''.join(result)
```

### 方法二：更简洁的并查集

```python
class Solution:
    def smallestEquivalentString(self, s1: str, s2: str, baseStr: str) -> str:
        """
        简化版并查集
        """
        parent = list(range(26))  # 使用数字索引代替字符
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int):
            px, py = find(x), find(y)
            if px != py:
                if px < py:
                    parent[py] = px
                else:
                    parent[px] = py
        
        # 建立等价关系
        for c1, c2 in zip(s1, s2):
            union(ord(c1) - ord('a'), ord(c2) - ord('a'))
        
        # 构建结果
        result = []
        for char in baseStr:
            idx = find(ord(char) - ord('a'))
            result.append(chr(idx + ord('a')))
        
        return ''.join(result)
```

### 方法三：带注释的详细版本

```python
class Solution:
    def smallestEquivalentString(self, s1: str, s2: str, baseStr: str) -> str:
        """
        并查集详细实现
        """
        # 初始化：每个字符的父节点是自己
        parent = {}
        for c in 'abcdefghijklmnopqrstuvwxyz':
            parent[c] = c
        
        def find(x):
            """
            查找 x 的根节点，并进行路径压缩
            路径压缩：将路径上的所有节点直接连接到根节点
            """
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            """
            合并 x 和 y 所在的集合
            策略：让字典序小的字符成为根节点（代表元素）
            """
            root_x = find(x)
            root_y = find(y)
            
            # 如果已经在同一个集合，无需合并
            if root_x == root_y:
                return
            
            # 让字典序小的成为父节点
            if root_x < root_y:
                parent[root_y] = root_x
            else:
                parent[root_x] = root_y
        
        # 步骤1：建立等价关系
        for i in range(len(s1)):
            union(s1[i], s2[i])
        
        # 步骤2：替换 baseStr 中的字符
        result = []
        for char in baseStr:
            # 找到字符所在等价类的最小代表
            smallest = find(char)
            result.append(smallest)
        
        return ''.join(result)
```

## 复杂度分析

**时间复杂度：** O((n + m) × α(26))，其中 α 是阿克曼函数的反函数，近似 O(1)
- 建立等价关系：O(n)，n 是 s1 的长度
- 构建结果：O(m)，m 是 baseStr 的长度
- 并查集操作近似 O(1)

**空间复杂度：** O(26) = O(1)
- 只需要存储 26 个小写字母的父节点信息

## 关键点总结

1. **并查集应用**：维护等价关系的标准数据结构
2. **合并策略**：让字典序小的字符成为根节点
3. **路径压缩**：优化查找效率
4. **字符映射**：可以用字符或索引表示

## 易错点

1. **合并方向**：必须让字典序小的成为父节点
2. **路径压缩**：不要忘记路径压缩优化
3. **初始化**：确保所有26个字母都初始化
4. **传递性**：理解等价关系的传递性
