## 题目描述

给你一个整数 `n`，表示一个有 `n` 个节点（下标 0 到 n-1）的有向加权图，以及一个二维整数数组 `edges`，其中 `edges[i] = [fromi, toi, weighti]`。

还给你三个整数 `src1`、`src2` 和 `dest`，表示三个不同的节点。

请你找出图中权值最小的子图，使得从 `src1` 和 `src2` 出发，都有一条路径到达 `dest`。返回该子图的最小权值总和，若不存在这样的路径，返回 -1。

**示例 1：**
```
输入：n = 6, edges = [[0,2,2],[0,3,1],[1,2,3],[1,3,2],[3,4,2],[4,2,1],[4,5,1],[2,5,1]], src1 = 0, src2 = 1, dest = 5
输出：9
```

**提示：**
- `3 <= n <= 10^5`
- `0 <= edges.length <= 10^5`
- `src1, src2, dest` 互不相同

## 解题思路

经典三点最短路问题。

关键观察：最优子图一定是两条路径在某个中间节点 `v` 汇合，再一起到达 `dest`。即：

```
src1 -> v -> dest
src2 -> v -> dest
```

形成一个"Y"字形。`v` 可以是任意节点（包括 src1、src2、dest 本身）。

**算法：**
1. 从 `src1` 正向 Dijkstra，得 `dist1[v]`。
2. 从 `src2` 正向 Dijkstra，得 `dist2[v]`。
3. 在**反向图**上从 `dest` 进行 Dijkstra，得 `dist_rev[v]`（即原图中 `v -> dest` 的最短路）。
4. 答案为 `min(dist1[v] + dist2[v] + dist_rev[v])` 对所有节点 `v`。

## 代码实现

### 方法一：三次 Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]], src1: int, src2: int, dest: int) -> int:
        INF = float('inf')

        # 构建正向图和反向图
        graph = defaultdict(list)   # 正向：u -> [(w, v)]
        rgraph = defaultdict(list)  # 反向：v -> [(w, u)]
        for u, v, w in edges:
            graph[u].append((w, v))
            rgraph[v].append((w, u))

        def dijkstra(start: int, adj: dict) -> List[int]:
            """从 start 出发，在 adj 图上运行 Dijkstra"""
            dist = [INF] * n
            dist[start] = 0
            heap = [(0, start)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for w, v in adj[u]:
                    nd = d + w
                    if nd < dist[v]:
                        dist[v] = nd
                        heapq.heappush(heap, (nd, v))
            return dist

        # 三次最短路
        dist1 = dijkstra(src1, graph)   # src1 到各点
        dist2 = dijkstra(src2, graph)   # src2 到各点
        dist3 = dijkstra(dest, rgraph)  # 各点到 dest（反向图）

        # 枚举汇合点 v
        ans = INF
        for v in range(n):
            if dist1[v] < INF and dist2[v] < INF and dist3[v] < INF:
                ans = min(ans, dist1[v] + dist2[v] + dist3[v])

        return ans if ans < INF else -1
```

### 方法二：同上，代码更紧凑

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]], src1: int, src2: int, dest: int) -> int:
        INF = float('inf')
        g = [defaultdict(lambda: INF) for _ in range(2)]  # g[0]=正向, g[1]=反向

        for u, v, w in edges:
            g[0][u][v] = min(g[0][u][v], w)
            g[1][v][u] = min(g[1][v][u], w)

        def dijkstra(s, adj):
            d = [INF] * n
            d[s] = 0
            pq = [(0, s)]
            while pq:
                du, u = heapq.heappop(pq)
                if du > d[u]: continue
                for v, w in adj[u].items():
                    if d[u] + w < d[v]:
                        d[v] = d[u] + w
                        heapq.heappush(pq, (d[v], v))
            return d

        d1 = dijkstra(src1, g[0])
        d2 = dijkstra(src2, g[0])
        d3 = dijkstra(dest, g[1])

        res = min(d1[v] + d2[v] + d3[v] for v in range(n))
        return res if res < INF else -1
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，三次 Dijkstra，每次 O((n + m) log n)。
- 空间复杂度：O(n + m)，图和距离数组。

## 关键点总结

1. 最优子图是"Y"形，两路径在某点汇合后共同到达终点。
2. 反向图上从 `dest` 跑 Dijkstra，等价于原图各点到 `dest` 的最短路。
3. 三数组逐元素求和取最小，非常优雅。

## 易错点

- 忘记构建反向图，导致无法计算各点到 dest 的距离。
- 有重边时需取最小权值（或 Dijkstra 本身能处理，无需预处理）。
- 答案为 INF 时要返回 -1。
