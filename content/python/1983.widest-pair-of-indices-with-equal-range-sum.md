## 题目描述

给你两个等长的整数数组 `nums1` 和 `nums2`，请你找出满足以下条件的**最宽的下标对** `(i, j)`（`i <= j`）：

- `nums1[i] + nums1[i+1] + ... + nums1[j] == nums2[i] + nums2[i+1] + ... + nums2[j]`

返回满足条件的最大 `j - i + 1`（即子数组宽度）。若不存在，返回 0。

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^5`

---

## 解题思路

### 核心思想：前缀和差 + 哈希表

设 `diff[i] = nums1[i] - nums2[i]`，则条件等价于 `diff[i] + ... + diff[j] = 0`，即 `prefix[j+1] - prefix[i] = 0`，即 `prefix[j+1] = prefix[i]`。

用哈希表记录每个前缀差值第一次出现的下标，求最大区间长度。

---

## 代码实现

### 方法一：前缀和差 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def widestPairOfIndices(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        # 记录每个前缀差值第一次出现的位置
        first_seen = {0: -1}  # 前缀差为 0 出现在 -1（即下标 0 前）
        prefix = 0
        ans = 0

        for j in range(n):
            prefix += nums1[j] - nums2[j]
            if prefix in first_seen:
                # 子数组宽度：j - first_seen[prefix]
                ans = max(ans, j - first_seen[prefix])
            else:
                # 只记录第一次出现（要找最宽）
                first_seen[prefix] = j

        return ans
```

### 方法二：前缀和数组版

```python
from typing import List

class Solution:
    def widestPairOfIndices(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        # 构造差数组的前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (nums1[i] - nums2[i])

        # 找最远的相同前缀和对
        first_seen = {}
        ans = 0
        for k in range(n + 1):
            if prefix[k] in first_seen:
                ans = max(ans, k - first_seen[prefix[k]])
            else:
                first_seen[prefix[k]] = k

        return ans
```

## 关键点总结

1. 两数组区间和相等 ⟺ 差数组的区间和为 0 ⟺ 前缀差值相等
2. 用哈希表记录每个前缀差值**第一次**出现的位置，保证区间最宽
3. 初始化 `first_seen = {0: -1}`，处理从头开始的子数组

---

## 易错点

- 初始前缀差设为 0，需将 `first_seen[0] = -1` 提前放入哈希表
- 只记录第一次出现（不更新），才能保证找到最宽区间
