## 题目描述

给你一个整数数组 `nums`、整数数组 `queries` 和整数 `x`。

对每个查询 `queries[i]`，返回 `x` 在 `nums` 中第 `queries[i]` 次出现时的下标。如果 `x` 出现次数不足 `queries[i]` 次，返回 -1。

**示例 1：**
```
输入：nums = [1,3,1,7], queries = [1,3,2,4], x = 1
输出：[0,-1,2,-1]
解释：1 在 nums 中出现在下标 0 和 2（第1次和第2次）。
```

**提示：**
- `1 <= nums.length, queries.length <= 10^5`
- `1 <= nums[i], queries[i] <= 10^5`

## 解题思路

预处理：收集 x 在 nums 中所有出现位置的有序列表 `positions`。对每个查询 q，若 q <= len(positions)，则返回 positions[q-1]，否则返回 -1。

## Python 代码实现

### 方法一：预处理位置列表（推荐）

```python
from typing import List

class Solution:
    def occurrencesOfElement(self, nums: List[int], queries: List[int], x: int) -> List[int]:
        # 收集 x 的所有出现位置
        positions = [i for i, v in enumerate(nums) if v == x]

        ans = []
        for q in queries:
            if q <= len(positions):
                ans.append(positions[q - 1])  # 第 q 次出现（1-indexed）
            else:
                ans.append(-1)
        return ans
```

### 方法二：使用字典

```python
from typing import List

class Solution:
    def occurrencesOfElement(self, nums: List[int], queries: List[int], x: int) -> List[int]:
        positions = []
        for i, v in enumerate(nums):
            if v == x:
                positions.append(i)
        return [positions[q - 1] if q <= len(positions) else -1 for q in queries]
```

## 复杂度分析

- 时间复杂度：O(n + q)，n 为数组长度，q 为查询数
- 空间复杂度：O(n)，存储位置列表

## 关键点总结

1. 预处理 x 的所有出现位置，查询 O(1)
2. 第 q 次出现对应 positions[q-1]（1-indexed）

## 易错点

1. 查询是 1-indexed 的，访问 positions[q-1]
2. q > len(positions) 时返回 -1
