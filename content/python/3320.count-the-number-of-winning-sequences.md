## 题目描述

Alice 和 Bob 玩游戏。Alice 先展示一个长度为 `n` 的字符串 `s`（每个字符是 `F`、`W` 或 `E` 之一，分别代表 Fire、Water、Earth）。

Bob 在看到 Alice 的每一步后，选择 `F`、`W`、`E` 之一（但**不能连续两次选同一字符**），规则：
- Fire 胜 Earth，Earth 胜 Water，Water 胜 Fire。
- 胜利得 +1 分，平局得 0 分，失败得 -1 分。

Bob 获胜的条件是总分 > 0。

返回 Bob 获胜的不同策略数，对 `10^9 + 7` 取模。

**提示：**
- `1 <= s.length <= 1000`

## 解题思路

**动态规划：**

定义 `dp[i][j][last]`：
- 处理到第 `i` 轮（0 索引），Bob 当前得分差为 `j`（范围 `-i 到 +i`，偏移处理），上一步选的是 `last`（0=F, 1=W, 2=E）。

为了方便处理负分，使用偏移量 `offset = n`，实际分数 = `j - offset`。

转移：
- 对每个 `last` 和每个新选择 `cur`（`cur != last`），计算得分变化 `delta`（+1, 0, -1），更新下一轮状态。

初始状态：第 0 轮，Bob 的得分为 0（偏移后为 `n`），上一步选择为任意三种之一。

最终答案：`sum(dp[n][j][*])` for `j > n`（得分 > 0，即偏移后 > n）。

## Python 代码实现

### 方法一：三维 DP（推荐）

```python
class Solution:
    def countWinningSequences(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        
        # 映射字符
        char_map = {'F': 0, 'W': 1, 'E': 2}
        # delta[alice][bob] = bob 得分变化
        # Fire(0) > Earth(2), Earth(2) > Water(1), Water(1) > Fire(0)
        delta = [[0] * 3 for _ in range(3)]
        # bob wins: W>F, F>E, E>W -> (1,0),(0,2),(2,1)
        wins = {(1, 0), (0, 2), (2, 1)}  # (bob, alice) bob 胜的组合
        for bob in range(3):
            for alice in range(3):
                if (bob, alice) in wins:
                    delta[alice][bob] = 1
                elif bob == alice:
                    delta[alice][bob] = 0
                else:
                    delta[alice][bob] = -1
        
        # dp[score_offset][last] 用偏移量处理负分
        # 分数范围：-n 到 +n，偏移 n 后为 0 到 2n
        offset = n
        # dp[score + offset][last_choice]
        dp = [[0] * 3 for _ in range(2 * n + 1)]
        
        # 第一轮
        alice_first = char_map[s[0]]
        for bob in range(3):
            d = delta[alice_first][bob]
            dp[d + offset][bob] = 1
        
        # 后续轮
        for i in range(1, n):
            alice_i = char_map[s[i]]
            new_dp = [[0] * 3 for _ in range(2 * n + 1)]
            
            for score in range(2 * n + 1):
                for last in range(3):
                    if dp[score][last] == 0:
                        continue
                    for cur in range(3):
                        if cur == last:
                            continue  # 不能连续相同
                        d = delta[alice_i][cur]
                        new_score = score + d
                        if 0 <= new_score <= 2 * n:
                            new_dp[new_score][cur] = (new_dp[new_score][cur] + dp[score][last]) % MOD
            
            dp = new_dp
        
        # 统计得分 > 0（偏移后 > n）的所有方案
        ans = 0
        for score in range(offset + 1, 2 * n + 1):
            for last in range(3):
                ans = (ans + dp[score][last]) % MOD
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，n 轮，每轮遍历 O(n) 个分数状态 * 3 * 3
- 空间复杂度：O(n)，DP 数组大小 O(n)

## 关键点总结

1. 使用偏移量处理负分，将分数范围 `[-n, n]` 映射到 `[0, 2n]`。
2. 状态转移时，禁止连续相同选择（`cur != last`）。
3. 得分规则：Bob 用 Water 胜 Fire，Fire 胜 Earth，Earth 胜 Water。

## 易错点

1. 胜负关系：Fire > Earth, Earth > Water, Water > Fire（循环克制）。
2. 分数偏移后需确保新分数在 `[0, 2n]` 范围内。
3. 统计答案时是得分严格 > 0，即偏移后 > n（`score > offset`）。
