## 题目描述

[LeetCode 1214. Two Sum Bsts](https://leetcode.com/problems/two-sum-bsts/)

给定两个二叉搜索树 `root1` 和 `root2`，以及一个整数 `target`，如果在第一个树中存在一个值 `v1`，在第二个树中存在一个值 `v2`，使得 `v1 + v2 = target`，则返回 `true`，否则返回 `false`。

示例 1：
```
输入：root1 = [2,1,4], root2 = [1,0,3], target = 5
输出：true
解释：2 + 3 = 5
```

示例 2：
```
输入：root1 = [0,-10,10], root2 = [5,1,7,0,2], target = 18
输出：false
```

提示：
- 每棵树的节点数在范围 [1, 5000] 内
- -10^9 <= Node.val, target <= 10^9

## 解题思路

这道题结合了经典的 Two Sum 问题和二叉搜索树的特性。

核心思路：
1. 遍历一棵树，将所有值存入哈希集合
2. 遍历另一棵树，检查 target - val 是否在集合中
3. 利用 BST 的中序遍历得到有序数组，使用双指针

关键观察：
- BST 的中序遍历是有序的，可以转化为有序数组的 Two Sum 问题
- 可以在遍历第一棵树时建立哈希表，遍历第二棵树时查找
- 双指针法需要先将 BST 转换为有序数组

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def twoSumBSTs(self, root1: Optional[TreeNode], root2: Optional[TreeNode], target: int) -> bool:
        # 方法：将第一棵树的所有值存入哈希集合
        # 遍历第二棵树时检查 target - val 是否在集合中
        
        # 存储第一棵树的所有值
        values = set()
        
        def traverse(node):
            """遍历树，将所有值加入集合"""
            if not node:
                return
            values.add(node.val)
            traverse(node.left)
            traverse(node.right)
        
        # 遍历第一棵树
        traverse(root1)
        
        # 在第二棵树中查找配对
        def search(node):
            """在第二棵树中查找是否存在配对值"""
            if not node:
                return False
            
            # 检查当前节点
            if target - node.val in values:
                return True
            
            # 递归检查左右子树
            return search(node.left) or search(node.right)
        
        return search(root2)
```

### 方法二：中序遍历 + 双指针（利用 BST 特性）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def twoSumBSTs(self, root1: Optional[TreeNode], root2: Optional[TreeNode], target: int) -> bool:
        # 方法：利用 BST 中序遍历有序的特性
        # 先转换为两个有序数组，再用双指针查找
        
        def inorder(node: Optional[TreeNode]) -> List[int]:
            """中序遍历，返回有序数组"""
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        # 获取两棵树的有序数组
        arr1 = inorder(root1)
        arr2 = inorder(root2)
        
        # 双指针查找
        left, right = 0, len(arr2) - 1
        
        for num1 in arr1:
            # 对于 arr1 中的每个数，在 arr2 中查找配对
            # 重置右指针（也可以不重置，但为了清晰起见）
            right = len(arr2) - 1
            
            while right >= 0:
                current_sum = num1 + arr2[right]
                if current_sum == target:
                    return True
                elif current_sum > target:
                    right -= 1
                else:
                    break
        
        return False
```

### 方法三：优化的双指针（推荐，最优解）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def twoSumBSTs(self, root1: Optional[TreeNode], root2: Optional[TreeNode], target: int) -> bool:
        # 方法：先中序遍历得到两个有序数组
        # 然后使用标准的双指针 Two Sum 算法
        
        def inorder(node: Optional[TreeNode]) -> List[int]:
            """中序遍历，返回有序数组"""
            result = []
            stack = []
            current = node
            
            while current or stack:
                while current:
                    stack.append(current)
                    current = current.left
                
                current = stack.pop()
                result.append(current.val)
                current = current.right
            
            return result
        
        # 获取两棵树的有序数组
        arr1 = inorder(root1)
        arr2 = inorder(root2)
        
        # 双指针法：arr1 从左往右，arr2 从右往左
        i, j = 0, len(arr2) - 1
        
        while i < len(arr1) and j >= 0:
            current_sum = arr1[i] + arr2[j]
            
            if current_sum == target:
                return True
            elif current_sum < target:
                i += 1  # 需要更大的和，移动 arr1 的指针
            else:
                j -= 1  # 需要更小的和，移动 arr2 的指针
        
        return False
```

### 方法四：DFS + 剪枝优化

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def twoSumBSTs(self, root1: Optional[TreeNode], root2: Optional[TreeNode], target: int) -> bool:
        # 方法：在第二棵树中搜索时利用 BST 的性质进行剪枝
        
        # 收集第一棵树的所有值
        values = set()
        
        def collect(node):
            if not node:
                return
            values.add(node.val)
            collect(node.left)
            collect(node.right)
        
        collect(root1)
        
        # 在第二棵树中进行优化搜索
        def search_bst(node, needed):
            """在 BST 中搜索指定值，利用 BST 性质剪枝"""
            if not node:
                return False
            
            if node.val == needed:
                return True
            
            # 利用 BST 性质：如果需要的值小于当前值，只搜索左子树
            if needed < node.val:
                return search_bst(node.left, needed)
            else:
                return search_bst(node.right, needed)
        
        # 对第一棵树的每个值，在第二棵树中搜索配对
        def check(node):
            if not node:
                return False
            
            needed = target - node.val
            if search_bst(root2, needed):
                return True
            
            return check(node.left) or check(node.right)
        
        return check(root1)
```

## 复杂度分析

### 方法一：哈希集合
- 时间复杂度：O(n + m)，其中 n 和 m 分别是两棵树的节点数
- 空间复杂度：O(n)，需要存储第一棵树的所有值

### 方法二/三：中序遍历 + 双指针
- 时间复杂度：O(n + m)，需要遍历两棵树
- 空间复杂度：O(n + m)，需要存储两个有序数组

### 方法四：DFS + 剪枝
- 时间复杂度：O(n × h)，其中 n 是第一棵树的节点数，h 是第二棵树的高度
- 空间复杂度：O(n + h)，哈希集合和递归栈

## 关键点总结

1. 可以将 BST 问题转化为数组问题，利用中序遍历的有序性
2. 哈希集合法简单直接，代码清晰易懂
3. 双指针法充分利用了两个有序数组的特性
4. 在 BST 中搜索时可以利用其性质进行剪枝优化

## 易错点

1. 忘记 BST 的中序遍历是有序的，直接使用普通的遍历
2. 双指针法的边界条件要注意：一个从左往右，一个从右往左
3. 使用递归时要注意返回值的处理，用 `or` 来连接左右子树的结果
4. 方法四中，在第二棵树中搜索时要利用 BST 性质，不要全树遍历
