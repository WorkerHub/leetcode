## 题目描述

给你一个整数数组 `jobs` 和一个整数 `k`，有 `k` 名工人，每名工人可以处理一个或多个任务（一次只能处理一个）。

返回所有工人完成所有任务所需的最小最大工作时间。

**示例 1：**

```
输入：jobs = [3, 2, 3], k = 3
输出：3
解释：每人分配一个任务，最大工作时间为 3。
```

**示例 2：**

```
输入：jobs = [1, 2, 4, 7, 8], k = 2
输出：11
解释：将 [1, 2, 4, 7] 分给工人 1（和为 14），将 [8] 分给工人 2（和为 8）...
最优分配使最大工作时间最小为 11。
```

**提示：**
- `1 <= k <= jobs.length <= 12`
- `1 <= jobs[i] <= 10^7`

## 解题思路

n <= 12，使用**状态压缩 DP**：
1. 预计算每个子集的任务总时间 `sum[mask]`。
2. `dp[j][mask]` = 前 j 名工人完成 mask 中任务的最小最大工作时间。
3. 转移：枚举当前工人负责的子集 `sub`（mask 的子集）。
4. 最终答案为 `dp[k][all_tasks]`。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        n = len(jobs)
        total_masks = 1 << n

        # 预计算每个子集的总时间
        subset_sum = [0] * total_masks
        for mask in range(1, total_masks):
            lsb = mask & (-mask)
            bit = lsb.bit_length() - 1
            subset_sum[mask] = subset_sum[mask ^ lsb] + jobs[bit]

        # dp[mask] = 用最少工人分配，最大工作时间最小
        # 逐层递推：dp[j][mask]
        INF = float('inf')
        dp = [INF] * total_masks
        dp[0] = 0
        for mask in range(total_masks):
            dp[mask] = subset_sum[mask]  # 全由第 1 个工人做

        # 重新定义：dp[mask] = 分配完 mask 中任务，k 名工人时的最小最大时间
        prev = [0] * total_masks
        for mask in range(total_masks):
            prev[mask] = subset_sum[mask]  # 1 名工人时，最大时间即总时间

        for j in range(1, k):
            curr = [INF] * total_masks
            for mask in range(total_masks):
                # 枚举当前工人负责的非空子集 sub
                sub = mask
                while sub > 0:
                    curr[mask] = min(curr[mask],
                                     max(prev[mask ^ sub], subset_sum[sub]))
                    sub = (sub - 1) & mask
            prev = curr

        return prev[total_masks - 1]
```

### 方法二：二分 + 回溯剪枝

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        jobs.sort(reverse=True)
        n = len(jobs)

        def can_finish(limit):
            workers = [0] * k

            def backtrack(idx):
                if idx == n:
                    return True
                seen = set()
                for i in range(k):
                    if workers[i] in seen:
                        continue
                    if workers[i] + jobs[idx] <= limit:
                        seen.add(workers[i])
                        workers[i] += jobs[idx]
                        if backtrack(idx + 1):
                            return True
                        workers[i] -= jobs[idx]
                return False

            return backtrack(0)

        lo, hi = max(jobs), sum(jobs)
        while lo < hi:
            mid = (lo + hi) // 2
            if can_finish(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

## 复杂度分析

- 时间复杂度：O(k * 3^n)，枚举子集的子集
- 空间复杂度：O(2^n)，子集和与 DP 数组

## 关键点总结

1. n <= 12 是状态压缩 DP 的信号。
2. 枚举子集的子集可以用 `sub = (sub - 1) & mask` 实现。
3. 预计算子集和可以用 `mask & (-mask)` 快速提取最低位。

## 易错点

1. 初始化时每个子集可以全部交给一名工人（`prev[mask] = subset_sum[mask]`）。
2. 枚举子集时不能漏掉空子集（此处从 mask 开始，逐步减小）。
3. 最终答案对应 `all_tasks = (1 << n) - 1`。
