## 题目描述

给你一个整数 `n` 和一个在范围 `[0, n - 1]` 内的整数 `p`，另外还有一个下标从 0 开始的整数数组 `banned`，其中包含一些在 `[0, n - 1]` 范围内被禁止的下标。

数组 `nums` 由 0 到 `n-1` 共 `n` 个下标组成，初始时 1 位于下标 `p` 处，其余下标值为 0。

每步操作，你可以选择一个大小为 `k` 的不越界子数组进行翻转（子数组中包含的 1 会移动到新位置）。你不能将 1 翻转到被禁止的下标处。

对所有下标 `i`，返回 1 从初始位置 `p` 到达下标 `i` 的最少操作次数，若无法到达则为 -1。

**数据范围：**
- 1 <= n <= 10^5
- 0 <= p <= n - 1
- 0 <= banned.length <= n - 1
- 1 <= k <= n

## 解题思路

BFS + 有序集合优化：

关键观察：对位于下标 `x` 的 1，经过一次翻转大小为 `k` 的子数组后，新位置 `y = l + r - x`，其中 `[l, r]` 是长度为 `k` 的区间，满足 `l <= x <= r`，且 `r - l + 1 = k`。

从 `x` 一步可到达的位置：将包含 `x` 的所有长度为 `k` 的区间端点之和减去 `x`。
- 区间范围：`l in [max(0, x-k+1), min(n-k, x)]`，`r = l + k - 1`
- 新位置：`y = l + r - x = 2*l + k - 1 - x`，当 `l` 从 `max(0, x-k+1)` 到 `min(n-k, x)` 时
- 从 `x` 可达的位置范围：`y = x - 2*(x - l)` 或 `y = x + 2*(r - x)`

使用有序集合（`SortedList`）维护未访问节点，BFS 时批量删除已访问节点，避免重复处理。

## Python 代码实现

### 方法一：BFS + SortedList（推荐）

```python
from typing import List
from collections import deque
from sortedcontainers import SortedList

class Solution:
    def minReverseOperations(self, n: int, p: int, banned: List[int], k: int) -> List[int]:
        ans = [-1] * n
        ans[p] = 0
        banned_set = set(banned)

        # 将未访问且未禁止的节点放入两个有序集合（奇偶分开）
        # 奇偶分开：从位置 x 出发，一步到达的位置奇偶性确定
        # 到达 y = (2*l + k - 1 - x)，奇偶性由 k-1-x 决定（固定），即所有可达位置奇偶相同
        unvisited = [SortedList(), SortedList()]
        for i in range(n):
            if i != p and i not in banned_set:
                unvisited[i % 2].add(i)

        queue = deque([p])
        while queue:
            x = queue.popleft()
            # 计算从 x 出发可到达的位置范围
            # l 范围：[max(0, x-k+1), min(n-k, x)]
            l_min = max(0, x - k + 1)
            l_max = min(n - k, x)
            # y = 2*l + k - 1 - x，y 的范围
            y_min = 2 * l_min + k - 1 - x
            y_max = 2 * l_max + k - 1 - x

            # 找奇偶性与 y_min 相同的所有未访问位置（在 [y_min, y_max] 内）
            parity = y_min % 2
            sl = unvisited[parity]
            # 批量处理范围内的未访问节点
            idx = sl.bisect_left(y_min)
            to_remove = []
            while idx < len(sl) and sl[idx] <= y_max:
                y = sl[idx]
                ans[y] = ans[x] + 1
                queue.append(y)
                to_remove.append(y)
                idx += 1
            for y in to_remove:
                sl.remove(y)

        return ans
```

### 方法二：简化版（不使用 SortedList，适用于小数据）

```python
from typing import List
from collections import deque

class Solution:
    def minReverseOperations(self, n: int, p: int, banned: List[int], k: int) -> List[int]:
        ans = [-1] * n
        ans[p] = 0
        banned_set = set(banned)
        visited = set(banned_set)
        visited.add(p)

        queue = deque([p])
        while queue:
            x = queue.popleft()
            l_min = max(0, x - k + 1)
            l_max = min(n - k, x)
            y_min = 2 * l_min + k - 1 - x
            y_max = 2 * l_max + k - 1 - x
            # 步长为 2（同奇偶）
            y = y_min
            while y <= y_max:
                if y not in visited:
                    visited.add(y)
                    ans[y] = ans[x] + 1
                    queue.append(y)
                y += 2

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)，每个节点最多被访问一次
- 方法二：时间复杂度 O(n * k)，最坏情况较慢
- 空间复杂度：O(n)

## 关键点总结

1. 从位置 `x` 出发，一次翻转可到达位置范围是一个等差为 2 的序列
2. 使用有序集合维护未访问节点，实现范围内批量删除
3. 奇偶分组减少查找范围

## 易错点

1. 可达位置奇偶固定（由 `k-1-x` 的奇偶决定）
2. `y_min` 和 `y_max` 的边界计算要精确
3. 需要用有序集合优化，否则会超时
