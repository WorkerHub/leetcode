## 题目描述

给定两个数组 `arr1` 和 `arr2`，`arr2` 中的元素各不相同，`arr2` 中的每个元素都出现在 `arr1` 中。

对 `arr1` 中的元素进行排序，使 `arr1` 中项的相对顺序和 `arr2` 中的相对顺序相同。未在 `arr2` 中出现的元素需要按照升序放在 `arr1` 的末尾。

**示例 1:**

```
输入: arr1 = [2,3,1,3,2,4,6,7,9,2,19], arr2 = [2,1,4,3,9,6]
输出: [2,2,2,1,4,3,3,9,6,7,19]
```

**示例 2:**

```
输入: arr1 = [28,6,22,8,44,17], arr2 = [22,28,8,6]
输出: [22,28,8,6,17,44]
```

**提示:**

- `1 <= arr1.length, arr2.length <= 1000`
- `0 <= arr1[i], arr2[i] <= 1000`
- `arr2` 中的元素各不相同
- `arr2` 中的每个元素都出现在 `arr1` 中

## 解题思路

这道题需要自定义排序规则：
1. 在 arr2 中出现的元素，按照 arr2 的顺序排列
2. 不在 arr2 中的元素，按升序排在最后

解题方法：
1. **计数 + 重建**：统计 arr1 中每个元素的频率，按规则重新构建数组
2. **自定义排序**：定义排序键，使用内置排序
3. **计数排序**：利用值的范围有限，使用计数排序

## Python 代码实现

### 方法一：计数 + 重建（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def relativeSortArray(self, arr1: List[int], arr2: List[int]) -> List[int]:
        # 统计arr1中每个元素的出现次数
        count = Counter(arr1)
        result = []
        
        # 按照arr2的顺序添加元素
        for num in arr2:
            # 将num添加count[num]次
            result.extend([num] * count[num])
            # 从计数器中删除，避免后续重复添加
            del count[num]
        
        # 将不在arr2中的元素按升序添加到结果末尾
        remaining = sorted(count.elements())
        result.extend(remaining)
        
        return result
```

### 方法二：自定义排序键

```python
class Solution:
    def relativeSortArray(self, arr1: List[int], arr2: List[int]) -> List[int]:
        # 创建arr2元素到索引的映射
        order = {num: i for i, num in enumerate(arr2)}
        
        # 自定义排序键
        def sort_key(num):
            # 如果在arr2中，返回其在arr2中的索引
            # 如果不在arr2中，返回一个大值（1000）加上num本身，保证升序
            if num in order:
                return (0, order[num])  # (0, 索引)
            else:
                return (1, num)  # (1, 值)
        
        return sorted(arr1, key=sort_key)
```

### 方法三：计数排序（最快）

```python
class Solution:
    def relativeSortArray(self, arr1: List[int], arr2: List[int]) -> List[int]:
        # 值的范围是0-1000，使用计数数组
        count = [0] * 1001
        
        # 统计arr1中每个元素的频率
        for num in arr1:
            count[num] += 1
        
        result = []
        
        # 按arr2的顺序添加
        for num in arr2:
            result.extend([num] * count[num])
            count[num] = 0  # 清零，避免重复
        
        # 添加剩余元素（按升序）
        for num in range(1001):
            if count[num] > 0:
                result.extend([num] * count[num])
        
        return result
```

### 方法四：使用列表推导式优化

```python
class Solution:
    def relativeSortArray(self, arr1: List[int], arr2: List[int]) -> List[int]:
        count = Counter(arr1)
        arr2_set = set(arr2)
        
        # arr2中的元素按顺序
        part1 = [num for num in arr2 for _ in range(count[num])]
        
        # 不在arr2中的元素按升序
        part2 = sorted([num for num in arr1 if num not in arr2_set])
        
        return part1 + part2
```

## 复杂度分析

**方法一（计数 + 重建）：**
- 时间复杂度：O(n + m + k log k)，其中 n 是 arr1 长度，m 是 arr2 长度，k 是不在 arr2 中的元素数量
- 空间复杂度：O(n)，Counter 存储

**方法二（自定义排序）：**
- 时间复杂度：O(n log n)，排序的时间复杂度
- 空间复杂度：O(m)，order 字典

**方法三（计数排序）：**
- 时间复杂度：O(n + m + 1001) = O(n + m)，最优
- 空间复杂度：O(1001) = O(1)，常数空间

## 关键点总结

1. **计数排序适用性**：当值的范围有限（0-1000）时，计数排序非常高效
2. **自定义排序键**：返回元组 (优先级, 值) 可以实现复杂的排序规则
3. **哈希表映射**：将 arr2 转为索引映射，快速查找元素顺序
4. **分步处理**：先处理 arr2 中的元素，再处理剩余元素

## 易错点

1. **重复添加元素**：
   ```python
   # 错误：arr2中的元素会被重复添加
   for num in arr2:
       result.extend([num] * count[num])
   # 如果不删除或清零count[num]，后续遍历还会再加一次
   
   # 正确：及时清零或删除
   del count[num]  # 或 count[num] = 0
   ```

2. **排序键设计错误**：
   ```python
   # 错误：不在arr2中的元素可能排在前面
   def sort_key(num):
       return order.get(num, num)  # 如果num小于arr2的索引，会排前面
   
   # 正确：使用元组确保优先级
   def sort_key(num):
       return (0, order[num]) if num in order else (1, num)
   ```

3. **边界情况**：
   - arr2为空：所有元素按升序排列
   - arr1中有元素不在arr2中
   - arr1中某元素出现多次
