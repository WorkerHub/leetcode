## 题目描述

给定一个 C++ 程序的源代码，需要移除其中的注释。

C++ 中有两种类型的注释：
1. **行注释**：`//` 开始，到行尾结束
2. **块注释**：`/*` 开始，`*/` 结束，可以跨越多行

注释的规则：
- 字符串 `//` 或 `/*` 出现在行注释或块注释中时，不会开始新的注释
- 字符串 `//` 或 `/*` 出现在字符串字面量中时，不会开始注释
- 本题中不需要考虑字符串字面量的情况

输出时：
- 移除所有注释后的代码
- 空行不应该出现在输出中
- 可以假设给定的源代码是有效的

**示例 1：**
```
输入: source = ["/*Test program */", "int main()", "{ ", "  // variable declaration ", "int a, b, c;", "/* This is a test", "   multiline  ", "   comment for ", "   testing */", "a = b + c;", "}"]
输出: ["int main()","{ ","  ","int a, b, c;","a = b + c;","}"]
解释:
/*Test program */ 整行是注释，移除
// variable declaration 后面是行注释，移除
/* This is a test ... testing */ 是多行块注释，移除
```

**示例 2：**
```
输入: source = ["a/*comment", "line", "more_comment*/b"]
输出: ["ab"]
解释: 块注释跨越多行，移除后剩余 "a" 和 "b" 在同一行
```

**提示：**
- `1 <= source.length <= 100`
- `0 <= source[i].length <= 80`
- `source[i]` 由可打印的 ASCII 字符组成
- 每个块注释都会被正确关闭

## 解题思路

这道题需要模拟注释移除的过程，核心是使用状态机来处理不同的情况。

**状态机设计：**
- 正常状态：遇到 `//` 进入行注释，遇到 `/*` 进入块注释
- 行注释状态：当前行剩余部分都跳过，换行后回到正常状态
- 块注释状态：直到遇到 `*/` 才回到正常状态

**处理流程：**
1. 逐字符扫描源代码
2. 使用布尔变量 `in_block` 标记是否在块注释中
3. 使用字符串 `new_line` 暂存当前行的有效内容
4. 遇到注释符号时切换状态
5. 只有正常状态下的字符才添加到结果中

## Python 代码实现

### 方法一：状态机模拟（推荐）

```python
from typing import List

class Solution:
    def removeComments(self, source: List[str]) -> List[str]:
        result = []
        in_block = False  # 是否在块注释中
        new_line = []  # 当前构建的新行
        
        for line in source:
            i = 0
            # 如果不在块注释中，需要清空 new_line
            # 注意：如果在块注释中，new_line 可能包含块注释前的内容
            
            while i < len(line):
                # 情况1：当前在块注释中
                if in_block:
                    # 查找块注释结束符 */
                    if i + 1 < len(line) and line[i:i+2] == '*/':
                        in_block = False
                        i += 2  # 跳过 */
                    else:
                        i += 1
                
                # 情况2：当前不在注释中
                else:
                    # 检查是否是块注释开始
                    if i + 1 < len(line) and line[i:i+2] == '/*':
                        in_block = True
                        i += 2
                    # 检查是否是行注释开始
                    elif i + 1 < len(line) and line[i:i+2] == '//':
                        # 行注释：跳过本行剩余部分
                        break
                    # 普通字符
                    else:
                        new_line.append(line[i])
                        i += 1
            
            # 处理当前行结束
            # 只有不在块注释中且当前行有内容时，才添加到结果
            if not in_block and new_line:
                result.append(''.join(new_line))
                new_line = []
        
        return result
```

### 方法二：简化版本

```python
from typing import List

class Solution:
    def removeComments(self, source: List[str]) -> List[str]:
        in_block = False
        result = []
        buffer = []
        
        for line in source:
            i = 0
            while i < len(line):
                char = line[i]
                
                if in_block:
                    # 在块注释中，寻找 */
                    if char == '*' and i + 1 < len(line) and line[i + 1] == '/':
                        in_block = False
                        i += 1  # 额外跳过 /
                else:
                    # 不在注释中
                    if char == '/' and i + 1 < len(line):
                        next_char = line[i + 1]
                        if next_char == '/':
                            # 行注释，跳过本行剩余
                            break
                        elif next_char == '*':
                            # 块注释开始
                            in_block = True
                            i += 1  # 额外跳过 *
                        else:
                            buffer.append(char)
                    else:
                        buffer.append(char)
                
                i += 1
            
            # 如果不在块注释中，将缓冲区内容作为一行
            if not in_block and buffer:
                result.append(''.join(buffer))
                buffer = []
        
        return result
```

### 方法三：使用正则表达式（不推荐）

```python
from typing import List
import re

class Solution:
    def removeComments(self, source: List[str]) -> List[str]:
        # 将所有行合并，用换行符分隔
        text = '\n'.join(source)
        
        # 移除块注释（非贪婪匹配，支持跨行）
        # 注意：正则表达式的 . 默认不匹配换行符，需要使用 re.DOTALL
        text = re.sub(r'/\*.*?\*/', '', text, flags=re.DOTALL)
        
        # 移除行注释
        text = re.sub(r'//.*', '', text)
        
        # 分割成行，移除空行
        result = [line for line in text.split('\n') if line.strip()]
        
        return result
```

## 复杂度分析

**方法一和方法二：**
- 时间复杂度：O(n × m)，其中 n 是源代码行数，m 是每行的平均长度
- 空间复杂度：O(n × m)，用于存储结果

**方法三：**
- 时间复杂度：O(n × m)，正则表达式匹配
- 空间复杂度：O(n × m)

## 关键点总结

1. **状态机思想**：使用布尔变量跟踪当前是否在块注释中
2. **双字符检查**：`//` 和 `/*` 都是两个字符，需要检查边界
3. **行注释处理**：遇到 `//` 后直接 break，跳过本行剩余内容
4. **块注释跨行**：块注释可能跨越多行，需要保持状态
5. **缓冲区管理**：只有在不在块注释中时，才将缓冲区内容添加到结果

## 易错点

1. **索引越界**
   - 检查 `//` 或 `/*` 时，必须确保 `i + 1 < len(line)`

2. **块注释跨行问题**
   - 块注释可能在一行开始，在另一行结束
   - 必须保持 `in_block` 状态跨越多行

3. **空行处理**
   - 只有当 `new_line` 非空且不在块注释中时，才添加到结果
   - 移除注释后的空行不应出现在输出中

4. **行注释后的处理**
   - 遇到 `//` 后应该 break 而不是 continue，因为行已结束

5. **结果行的拼接**
   - 块注释可能将多行代码拼接成一行（如示例2）
