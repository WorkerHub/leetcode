## 题目描述

给你两个整数数组 `arr` 和 `brr`，长度相同，以及整数 `k`。

在一次操作中，你可以：
- 将 `arr` 中任意元素增加或减少 1，代价为 `1`
- 将整个 `arr` 排序，代价为 `k`

返回使 `arr` 和 `brr` 相等的**最小总代价**。

**示例 1：**

```
输入：arr = [1,2,3], brr = [2,3,4], k = 1
输出：3
解释：不排序，每个元素加 1，代价 3
或者排序（代价 1）后调整，共 1+2=3
```

**示例 2：**

```
输入：arr = [1,2,3], brr = [1,5,2], k = 2
输出：5
```

**提示：**
- `1 <= arr.length == brr.length <= 10^5`
- `0 <= arr[i], brr[i] <= 10^9`
- `0 <= k <= 2 * 10^9`

## 解题思路

两种策略：
1. **不排序**：直接将 arr[i] 调整为 brr[i]，代价 = sum(|arr[i] - brr[i]|)
2. **排序一次**：代价 k + 将排序后的 arr 调整为排序后的 brr，即 k + sum(|sorted(arr)[i] - sorted(brr)[i]|)

**为什么排序后代价最小**：将两个数组都排序后，按序匹配是使总绝对差最小的方式（贪心：小的配小的，大的配大的）。

取两种策略的最小值。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minCost(self, arr: List[int], brr: List[int], k: int) -> int:
        n = len(arr)

        # 策略 1：不排序，直接逐位调整
        cost_no_sort = sum(abs(arr[i] - brr[i]) for i in range(n))

        # 策略 2：将 arr 排序（代价 k），然后与 sorted(brr) 逐位匹配
        sorted_arr = sorted(arr)
        sorted_brr = sorted(brr)
        cost_with_sort = k + sum(abs(sorted_arr[i] - sorted_brr[i]) for i in range(n))

        return min(cost_no_sort, cost_with_sort)
```

### 方法二：加注释的详细版

```python
from typing import List

class Solution:
    def minCost(self, arr: List[int], brr: List[int], k: int) -> int:
        n = len(arr)

        # 策略一：不使用排序操作
        # 每个位置独立调整：arr[i] -> brr[i]
        cost1 = 0
        for i in range(n):
            cost1 += abs(arr[i] - brr[i])

        # 策略二：使用一次排序操作（代价 k）
        # 排序后，最优匹配是两个排序数组的逐位匹配
        # 原因：若 a1 < a2, b1 < b2，则 |a1-b1|+|a2-b2| <= |a1-b2|+|a2-b1|
        sorted_arr = sorted(arr)
        sorted_brr = sorted(brr)
        cost2 = k
        for i in range(n):
            cost2 += abs(sorted_arr[i] - sorted_brr[i])

        return min(cost1, cost2)
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(n)，存储排序后的数组

## 关键点总结

1. 两种策略：排序或不排序
2. 排序后按位置匹配是最优的（贪心：避免"交叉"匹配）
3. 比较两种策略的总代价，取最小值

## 图解示例

```
arr  = [1, 3, 5]
brr  = [2, 4, 6]

不排序：|1-2|+|3-4|+|5-6| = 3

排序（代价 k=1）+ 匹配：sorted(arr)=[1,3,5], sorted(brr)=[2,4,6]
匹配代价 = 3，总代价 = 1+3 = 4

选最小：3
```

## 易错点

1. 排序的代价是 `k`，只计算一次（无论 arr 是否已经有序）
2. 不能对 brr 排序而不对 arr 排序（两者必须同时排序以保持对应关系）
3. 在策略二中，arr 和 brr 都要排序后再比较
