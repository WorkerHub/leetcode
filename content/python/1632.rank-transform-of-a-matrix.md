## 题目描述

给你一个 `m x n` 的矩阵 `matrix`，请你返回一个新的矩阵 `answer`，其中 `answer[row][col]` 是 `matrix[row][col]` 的**秩**。

秩代表元素相对大小的一个排名，规则：
- 秩从 1 开始
- 如果两个元素 p 和 q 在同一行或同一列，且 `p < q`，则 `p` 的秩必须小于 `q` 的秩
- 每个元素的秩应尽可能小

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 500`
- `-10^9 <= matrix[i][j] <= 10^9`

## 解题思路

1. 将矩阵中所有元素按值**从小到大排序**
2. 对相同值的元素，它们可能在同一行或列，需要使用**并查集**分组
3. 对每个分组，同组内的秩必须相同，且秩 = 分组内所有元素所在行/列的当前最大秩 + 1
4. 更新每行每列的最大秩

## 代码实现

### 方法一：并查集 + 按值排序（推荐）

```python
from typing import List
from collections import defaultdict

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int):
        self.parent[self.find(x)] = self.find(y)

class Solution:
    def matrixRankTransform(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        answer = [[0] * n for _ in range(m)]
        
        # 每行/每列当前已分配的最大秩
        row_max = [0] * m
        col_max = [0] * n
        
        # 按值分组：值 -> [(row, col)]
        val_pos = defaultdict(list)
        for r in range(m):
            for c in range(n):
                val_pos[matrix[r][c]].append((r, c))
        
        for val in sorted(val_pos.keys()):
            positions = val_pos[val]
            
            # 使用并查集将同行或同列的元素分组
            uf = UnionFind(m + n)  # 前 m 个是行，后 n 个是列
            for r, c in positions:
                uf.union(r, m + c)  # 行 r 和列 c 合并
            
            # 对每个连通组，找最大秩
            group_max = defaultdict(int)
            for r, c in positions:
                root = uf.find(r)
                group_max[root] = max(group_max[root], row_max[r], col_max[c])
            
            # 给每个元素分配秩
            for r, c in positions:
                root = uf.find(r)
                rank = group_max[root] + 1
                answer[r][c] = rank
                row_max[r] = max(row_max[r], rank)
                col_max[c] = max(col_max[c], rank)
        
        return answer
```

### 方法二：拓扑排序

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def matrixRankTransform(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        answer = [[0] * n for _ in range(m)]
        row_max = [0] * m
        col_max = [0] * n
        
        # 按值分组
        val_pos = defaultdict(list)
        for r in range(m):
            for c in range(n):
                val_pos[matrix[r][c]].append((r, c))
        
        for val in sorted(val_pos.keys()):
            positions = val_pos[val]
            
            # 相同值元素中，同行/列的必须有相同的秩
            # 直接用并查集确定连通组，然后取组内最大约束
            parent = {}
            
            def find(x):
                if x not in parent:
                    parent[x] = x
                if parent[x] != x:
                    parent[x] = find(parent[x])
                return parent[x]
            
            def union(x, y):
                parent[find(x)] = find(y)
            
            for r, c in positions:
                union(('r', r), ('c', c))
            
            group_max = defaultdict(int)
            for r, c in positions:
                root = find(('r', r))
                group_max[root] = max(group_max[root], row_max[r], col_max[c])
            
            for r, c in positions:
                root = find(('r', r))
                rank = group_max[root] + 1
                answer[r][c] = rank
                row_max[r] = max(row_max[r], rank)
                col_max[c] = max(col_max[c], rank)
        
        return answer
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 | O(m*n * log(m*n) * α(m+n)) | O(m*n + m+n) |

## 关键点总结

1. 按值从小到大处理，确保较小值的秩先确定
2. 相同值的元素，同行或同列的必须有相同的秩（并查集分组）
3. 每个连通组的秩 = 组内所有元素所在行/列的已用最大秩 + 1
4. 处理完后更新对应行列的最大秩

## 易错点

- 并查集使用 `m + n` 个节点（行和列分别编号）
- 相同值的元素可能通过中间节点传递连通（A和B同行，B和C同列，则ABC同组）
- 更新行/列最大秩时用 `max` 而不是直接赋值
