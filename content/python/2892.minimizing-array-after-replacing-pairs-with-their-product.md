## 题目描述

给你一个整数数组 `nums` 和一个整数 `limit`。

每次操作，可以将 `nums` 中相邻的两个元素替换为它们的乘积，条件是乘积 <= `limit`。

返回通过**最多**次操作后，数组的**最短长度**。

**示例 1：**
```
输入：nums = [2,3,1,512,3,2,4], limit = 10
输出：4
解释：
[2,3,1,512,3,2,4]
合并 2*3=6 -> [6,1,512,3,2,4]
合并 6*1=6 -> [6,512,3,2,4]（6<=10）
合并 3*2=6 -> [6,512,6,4]
合并 6*4=24 > 10，不合并
合并...
等等，这个例子有点复杂，需要贪心分析
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], limit <= 10^6`

## 解题思路

**贪心：** 从左到右扫描，维护当前段的乘积，尽可能合并相邻元素。

- 若 `cur_product * nums[i] <= limit`，合并
- 否则，当前段结束，计数 +1，从 nums[i] 开始新段

**注意：** 若某个元素本身 > limit，它是独立的一段（不能与任何元素合并），单独计数。

## Python 代码实现

### 方法一：贪心扫描（推荐）

```python
from typing import List

class Solution:
    def minArrayLength(self, nums: List[int], limit: int) -> int:
        n = len(nums)
        if n == 0:
            return 0

        count = 1  # 当前段数
        cur = nums[0]

        for i in range(1, n):
            if cur * nums[i] <= limit:
                cur *= nums[i]  # 合并
            else:
                count += 1  # 开始新段
                cur = nums[i]

        return count
```

### 方法二：更明确的注释

```python
from typing import List

class Solution:
    def minArrayLength(self, nums: List[int], limit: int) -> int:
        segments = 1
        product = nums[0]

        for i in range(1, len(nums)):
            if product * nums[i] <= limit:
                product *= nums[i]
            else:
                # 无法合并，开始新段
                segments += 1
                product = nums[i]

        return segments
```

## 复杂度分析

- 时间复杂度：O(n)，一次扫描
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：能合并就合并（尽量减少段数）
2. 相邻合并：只能合并当前段的末尾与下一个元素
3. 乘积可能快速增大，超过 limit 时分段

## 易错点

1. 乘积可能超出整数范围（Python 无限精度整数不用担心）
2. 只能合并相邻元素，不能跳跃
3. nums[0] > limit 时也是单独一段
