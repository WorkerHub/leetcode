## 题目描述

给你一个整数 `x`，如果 `x` 是一个回文整数，返回 `true`；否则，返回 `false`。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

**示例 1：**
```
输入：x = 121
输出：true
```

**示例 2：**
```
输入：x = -121
输出：false
解释：从左向右读为 -121，从右向左读为 121-，不是回文数
```

**示例 3：**
```
输入：x = 10
输出：false
解释：从右向左读为 01，不是回文数
```

**提示：**
- `-2^31 <= x <= 2^31 - 1`

**进阶：** 你能不将整数转为字符串来解决这个问题吗？

## 解题思路

**方法对比：**
1. **转字符串**：简单直接
2. **数学方法**：反转一半数字进行比较

## Python 代码实现

### 方法一：转字符串

```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        return str(x) == str(x)[::-1]
```

### 方法二：数学方法（推荐）

```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        # 负数和以 0 结尾的非零数不是回文
        if x < 0 or (x % 10 == 0 and x != 0):
            return False
        
        # 反转一半数字
        reversed_half = 0
        while x > reversed_half:
            reversed_half = reversed_half * 10 + x % 10
            x //= 10
        
        # 偶数位：x == reversed_half
        # 奇数位：x == reversed_half // 10
        return x == reversed_half or x == reversed_half // 10
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(log n)
- 空间复杂度：
  - 方法一 O(log n)
  - 方法二 O(1)

## 关键点总结

1. **负数**：一定不是回文
2. **末尾为 0**：除了 0 本身，其他都不是回文
3. **反转一半**：避免溢出

## 易错点

1. **特殊情况**：0 是回文，10 不是
2. **奇数位数**：需要除以 10 去掉中间位
