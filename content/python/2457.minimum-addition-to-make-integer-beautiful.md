## 题目描述

给你两个正整数 `n` 和 `target`。

如果某个整数每一位上的数字相加小于或等于 `target`，则认为这个整数是 **美丽整数**。

找出并返回满足 `n + x` 是 **美丽整数** 的 **最小** 非负整数 `x`。生成的输入保证总可以使 `n` 变成一个美丽整数。

**示例 1：**
```
输入：n = 16, target = 6
输出：4
解释：n + 4 = 20，2 + 0 = 2 <= 6，x = 4 是最小的。
```

**示例 2：**
```
输入：n = 467, target = 6
输出：33
解释：n + 33 = 500，5 + 0 + 0 = 5 <= 6，x = 33 最小。
```

**提示：**
- `1 <= n <= 10^12`
- `1 <= target <= 150`

## 解题思路

**贪心：**

从最低位开始处理，如果当前数字的各位之和已经 <= target，则 x = 0。

否则，将最低位通过进位清零（加上 `10 - last_digit` 使末位变为 0，同时向高位进 1），重复直到各位之和 <= target。

**具体步骤：**
1. 计算 `n` 的各位数字之和
2. 若已满足，返回 0
3. 否则，将最低非零位（从右往左找）进位，清零该位及其右侧所有位，重复检查

实际上，可以从低位开始，每次把当前最低位变为 0（进位），直到各位之和 <= target。

## 代码实现

### 方法一：贪心进位（推荐）

```python
class Solution:
    def makeIntegerBeautiful(self, n: int, target: int) -> int:
        def digit_sum(x: int) -> int:
            return sum(int(d) for d in str(x))

        if digit_sum(n) <= target:
            return 0

        ans = 0
        base = 1  # 当前处理的位数（个位、十位、...）

        while digit_sum(n) > target:
            # 将 n 的最低位（个位）进位：加上使该位变为 0 的值
            # 即加上 base - (n % (base * 10)) % base 的进位
            # 简单来说：找下一个 base * 10 的倍数
            r = n % (base * 10)  # n 当前 base 及以下的数值
            if r > 0:
                carry = base * 10 - r  # 使该位进位所需的值
            else:
                carry = 0
                base *= 10
                continue
            n += carry
            ans += carry
            base *= 10

        return ans
```

### 方法二：字符串处理

```python
class Solution:
    def makeIntegerBeautiful(self, n: int, target: int) -> int:
        original = n
        base = 1

        while sum(int(d) for d in str(n)) > target:
            # 进位：使最低 base 位变为 0
            n = (n // (base * 10) + 1) * (base * 10)
            base *= 10

        return n - original
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心进位 | O(log n) | O(1) |

每次处理一位，最多处理 log10(n) 次。

## 关键点总结

1. 贪心：从低位到高位，每次进位使低位变为 0
2. 进位后更低位的数字之和减少，但可能使高位增加
3. 方法二更简洁：直接找下一个 `base * 10` 的整数倍

## 易错点

- 进位后需要重新计算各位之和，因为高位可能因进位增加
- 注意记录增加的总量：`ans += carry`
