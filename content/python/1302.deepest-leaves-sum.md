## 题目描述

给你一棵二叉树的根节点 `root`，请你返回层数最深的叶子节点的和。

示例 1：
```
输入：root = [1,2,3,4,5,null,6,7,null,null,null,null,8]
输出：15
```

示例 2：
```
输入：root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
输出：19
```

提示：
- 树中节点数目在范围 `[1, 10^4]` 之间
- `1 <= Node.val <= 100`

## 解题思路

这道题要求找到二叉树中最深层的所有叶子节点，并返回它们的和。有两种主要思路：

### 思路一：BFS（广度优先搜索）
使用层序遍历，逐层访问节点，最后一层的所有节点就是最深的叶子节点，返回它们的和即可。

### 思路二：DFS（深度优先搜索）
1. 先通过 DFS 找到树的最大深度
2. 再次 DFS，累加深度等于最大深度的所有节点值

## Python 代码实现

### 方法一：BFS 层序遍历（推荐）

```python
from typing import Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def deepestLeavesSum(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        queue = deque([root])
        
        # 逐层遍历
        while queue:
            level_size = len(queue)
            level_sum = 0
            
            # 处理当前层的所有节点
            for _ in range(level_size):
                node = queue.popleft()
                level_sum += node.val
                
                # 将下一层节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 如果队列为空，说明当前层是最后一层
            if not queue:
                return level_sum
        
        return 0
```

### 方法二：DFS 两次遍历

```python
from typing import Optional

class Solution:
    def deepestLeavesSum(self, root: Optional[TreeNode]) -> int:
        # 第一次 DFS：找到最大深度
        def find_max_depth(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return 1 + max(find_max_depth(node.left), find_max_depth(node.right))
        
        max_depth = find_max_depth(root)
        
        # 第二次 DFS：累加最深层节点的值
        def sum_at_depth(node: Optional[TreeNode], depth: int) -> int:
            if not node:
                return 0
            
            # 到达最深层
            if depth == max_depth:
                return node.val
            
            # 继续向下搜索
            return sum_at_depth(node.left, depth + 1) + sum_at_depth(node.right, depth + 1)
        
        return sum_at_depth(root, 1)
```

### 方法三：DFS 一次遍历（优化）

```python
from typing import Optional

class Solution:
    def deepestLeavesSum(self, root: Optional[TreeNode]) -> int:
        self.max_depth = 0
        self.total_sum = 0
        
        def dfs(node: Optional[TreeNode], depth: int) -> None:
            if not node:
                return
            
            # 发现更深的层，重置总和
            if depth > self.max_depth:
                self.max_depth = depth
                self.total_sum = node.val
            # 在相同深度，累加
            elif depth == self.max_depth:
                self.total_sum += node.val
            
            # 继续遍历左右子树
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        
        dfs(root, 1)
        return self.total_sum
```

### 方法四：Python 简洁写法

```python
from typing import Optional
from collections import deque

class Solution:
    def deepestLeavesSum(self, root: Optional[TreeNode]) -> int:
        queue = deque([root])
        
        while queue:
            # 当前层的和
            level_sum = sum(node.val for node in queue)
            # 收集下一层的所有节点
            queue = deque([child for node in queue 
                          for child in (node.left, node.right) if child])
            # 如果没有下一层，返回当前层的和
            if not queue:
                return level_sum
        
        return 0
```

## 复杂度分析

### 方法一：BFS
- 时间复杂度：O(n)，其中 n 是树中节点的数量，需要遍历所有节点
- 空间复杂度：O(w)，其中 w 是树的最大宽度（队列最大长度）

### 方法二：DFS 两次遍历
- 时间复杂度：O(n)，需要遍历两次树
- 空间复杂度：O(h)，其中 h 是树的高度（递归栈空间）

### 方法三：DFS 一次遍历
- 时间复杂度：O(n)，只需遍历一次树
- 空间复杂度：O(h)，递归栈空间

## 关键点总结

1. BFS 方法最直观，层序遍历到最后一层就是答案
2. DFS 方法需要维护当前深度信息
3. 可以通过一次 DFS 同时找最大深度和累加和
4. 注意区分"最深的叶子节点"和"最深的节点"（本题不要求是叶子）

## 易错点

1. 混淆"最深的叶子"和"所有叶子"的概念
2. BFS 中忘记在每层开始时重置计数
3. DFS 中深度计数从 0 还是从 1 开始要保持一致
4. 忘记处理空树的情况
