## 题目描述

给你一棵 `n` 个节点的无根树（节点编号 0 到 n-1），以及一个整数数组 `cost`，其中 `cost[i]` 是放置在节点 i 的硬币代价。

对于每个节点 `v`，在其中放置硬币，代价为其子树中**最多 3 个节点**（包含 v）的代价的乘积的最大值（若子树节点数 < 3，则代价为 0）。

返回长度为 n 的数组 `result`，其中 `result[v]` 是节点 v 中放置的硬币数。

注意：节点代价可能为负数。

**示例 1：**
```
输入：edges = [[0,1],[0,2],[0,3],[0,4]], cost = [1,2,3,4,5]
输出：[2,2,3,4,5]
```

**提示：**
- `2 <= n <= 3 * 10^4`
- `edges.length == n-1`
- `0 <= cost[i] <= 10^4`
- `1 <= cost[i].length == 2`

## 解题思路

对每个节点 v，需要从其子树中选最多 3 个节点使得乘积最大。

选法：
- 若子树节点 < 3：乘积为 0
- 若 3 个节点代价都为正：选最大的 3 个
- 若有负数：选最大的 3 个，或选最大的 1 个（正）+ 最小的 2 个（负*负为正）

用 DFS，每个节点收集子树中最大的 5 个值（最大 3 个正数和最小 2 个负数），用于计算乘积。

## Python 代码实现

### 方法一：DFS + 维护子树 Top-5（推荐）

```python
from typing import List
import heapq

class Solution:
    def placedCoins(self, edges: List[List[int]], cost: List[int]) -> List[int]:
        n = len(cost)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        result = [0] * n

        def dfs(node: int, parent: int) -> List[int]:
            # 返回子树中的 cost 值列表（至多保留最大 3 个和最小 2 个）
            subtree = [cost[node]]
            for child in graph[node]:
                if child == parent:
                    continue
                child_vals = dfs(child, node)
                subtree.extend(child_vals)

            # 若子树节点数 >= 3，计算最大乘积
            if len(subtree) >= 3:
                # 候选：最大的 3 个，或最大的 1 个 + 最小的 2 个
                subtree_sorted = sorted(subtree)
                # 选项 1：最大的 3 个
                opt1 = subtree_sorted[-1] * subtree_sorted[-2] * subtree_sorted[-3]
                # 选项 2：最大的 1 个 + 最小的 2 个（若最小两个都为负，乘积更大）
                opt2 = subtree_sorted[-1] * subtree_sorted[0] * subtree_sorted[1]
                result[node] = max(opt1, opt2)

            # 只保留最大 3 个和最小 2 个（共最多 5 个）
            if len(subtree) > 5:
                sorted_sub = sorted(subtree)
                subtree = sorted_sub[:2] + sorted_sub[-3:]

            return subtree

        import sys
        sys.setrecursionlimit(100000)
        dfs(0, -1)
        return result
```

### 方法二：迭代 DFS（避免递归深度限制）

```python
from typing import List

class Solution:
    def placedCoins(self, edges: List[List[int]], cost: List[int]) -> List[int]:
        n = len(cost)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        result = [0] * n
        parent = [-1] * n
        order = []  # 后序遍历顺序
        visited = [False] * n
        stack = [0]
        while stack:
            node = stack.pop()
            if visited[node]:
                order.append(node)
                continue
            visited[node] = True
            stack.append(node)
            for child in graph[node]:
                if child != parent[node]:
                    parent[child] = node
                    stack.append(child)

        # 存储每个节点子树的 top-5 值
        vals = [[cost[i]] for i in range(n)]

        for node in order:
            children = [c for c in graph[node] if c != parent[node]]
            all_vals = list(vals[node])
            for child in children:
                all_vals.extend(vals[child])

            if len(all_vals) >= 3:
                s = sorted(all_vals)
                result[node] = max(s[-1] * s[-2] * s[-3],
                                   s[-1] * s[0] * s[1])

            # 只保留 top-5
            s = sorted(all_vals)
            if len(s) > 5:
                vals[node] = s[:2] + s[-3:]
            else:
                vals[node] = s

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)，每个节点的子树值合并排序
- 空间复杂度：O(n)

## 关键点总结

1. 从子树中选最多 3 个节点最大化乘积，考虑两种情况：最大 3 个或最大 1 个 + 最小 2 个
2. 每个节点只需保留子树中最大 3 个和最小 2 个值（共 5 个），减少合并代价
3. 后序遍历（从叶到根）合并子树信息

## 易错点

1. 子树节点数 < 3 时乘积为 0（不够选 3 个）
2. 负数代价的处理：两个负数相乘为正，可能比三个正数乘积更大
3. 保留 top-5 而不是只保留 top-3，因为需要最小的 2 个
