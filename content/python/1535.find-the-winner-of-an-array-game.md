## 题目描述

给你一个由 **不同** 整数组成的整数数组 `arr` 和一个整数 `k`。

每轮游戏，将数组最前面两个元素进行比较，较大的整数**保留**在数组最前面，较小的整数移到数组末尾。当某个整数赢得 `k` 个连续回合后，游戏结束，该整数就是比赛的**赢家**。

返回赢家的值。题目确保游戏一定会结束。

**示例 1：**
```
输入：arr = [2,1,3,5,4], k = 2
输出：5
```

**示例 2：**
```
输入：arr = [3,2,1], k = 10
输出：3
```

**提示：**
- `2 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^6`
- `arr` 中元素各不相同
- `1 <= k <= 10^9`

## 解题思路

### 关键观察

如果 `k >= n-1`，那么最终赢家一定是数组中的最大元素（因为最多 n-1 轮后所有元素都和最大元素比较过）。

否则，从下标 1 开始扫描，维护当前"擂台冠军"和其连续胜利次数：
- 若 `arr[i] > current_winner`，更新冠军，重置连续胜利次数为 1
- 若 `arr[i] < current_winner`，连续胜利次数加 1
- 若连续胜利次数达到 `k`，返回当前冠军

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def getWinner(self, arr: List[int], k: int) -> int:
        n = len(arr)
        # 若 k 很大，最大元素一定能赢
        if k >= n - 1:
            return max(arr)

        # 从 arr[0] 开始作为初始冠军
        current = arr[0]
        wins = 0

        for i in range(1, n):
            if arr[i] > current:
                current = arr[i]
                wins = 1
            else:
                wins += 1
            if wins == k:
                return current

        return current
```

### 方法二：使用队列模拟（直观）

```python
from collections import deque
from typing import List

class Solution:
    def getWinner(self, arr: List[int], k: int) -> int:
        if k >= len(arr) - 1:
            return max(arr)

        dq = deque(arr)
        wins = 0
        current = dq[0]

        while wins < k:
            a, b = dq.popleft(), dq.popleft()
            if a > b:
                winner, loser = a, b
            else:
                winner, loser = b, a

            if winner == current:
                wins += 1
            else:
                current = winner
                wins = 1

            dq.appendleft(winner)
            dq.append(loser)

        return current
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N) | O(1) |
| 方法二（队列） | O(N * k)，最坏 O(N^2) | O(N) |

方法一是最优解，O(N) 一次扫描。

## 关键点总结

1. 若 `k >= n-1`，最大元素必然获胜（不需要模拟）
2. 从第二个元素开始扫描，维护当前冠军和连续胜利数
3. 当 `arr[i] > current` 时，冠军换人，胜利数重置为 1

## 易错点

- `k >= n-1` 时直接返回 `max(arr)`，否则模拟可能超时
- 冠军换人时胜利数重置为 **1**（不是 0），因为 `arr[i]` 刚赢了一场
