## 题目描述

有一幅从 1 到 `10^9` 范围的细长画布。给你一个二维整数数组 `segments`，`segments[i] = [l_i, r_i, color_i]` 表示在区间 `[l_i, r_i]` 涂上颜色 `color_i`（多段可重叠，颜色叠加）。

画完后，画布上每段**颜色组合**（颜色集合）相同的连续区间可以合并描述。

返回 **非空** 部分的描述列表，每个元素形如 `[l_i, r_i, sum_i]`，表示区间 `[l_i, r_i]` 颜色集合对应的颜色值之和为 `sum_i`，且与相邻区间颜色组合不同。

**示例：**
```
输入：segments = [[1,4,5],[4,7,7],[1,7,9]]
输出：[[1,4,14],[4,7,16]]
解释：[1,4] 有颜色 5 和 9，和为 14；[4,7] 有颜色 7 和 9，和为 16
```

**提示：**
- `1 <= segments.length <= 2 * 10^4`
- `1 <= l_i < r_i <= 10^9`
- `1 <= color_i <= 10^9`

---

## 解题思路

### 核心思想：差分数组 + 离散化

由于坐标可以到 10^9，需要**坐标压缩（离散化）**：
1. 收集所有区间端点，排序去重
2. 用差分思想：在 `l` 处加上颜色，在 `r` 处减去颜色
3. 从左到右扫描，维护当前颜色集合和颜色之和

具体：用差分记录每个坐标处颜色的加入和移除：
- `diff[l] += color`
- `diff[r] -= color`

## 代码实现

### 方法一：差分 + 离散化（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def splitPainting(self, segments: List[List[int]]) -> List[List[int]]:
        # 差分：diff[x] = 在 x 处颜色之和的变化
        diff = defaultdict(int)
        # 记录所有端点
        endpoints = set()

        for l, r, color in segments:
            diff[l] += color
            diff[r] -= color
            endpoints.add(l)
            endpoints.add(r)

        # 对端点排序
        sorted_pts = sorted(endpoints)

        result = []
        cur_sum = 0  # 当前颜色之和

        for i in range(len(sorted_pts) - 1):
            x = sorted_pts[i]
            cur_sum += diff[x]  # 更新当前颜色和
            next_x = sorted_pts[i + 1]

            if cur_sum > 0:
                # 当前区间 [x, next_x] 有颜色
                if result and result[-1][1] == x and result[-1][2] == cur_sum:
                    # 与上一区间颜色和相同，合并（但颜色集合可能不同？）
                    # 实际上颜色和相同但集合可能不同，不能合并
                    result.append([x, next_x, cur_sum])
                else:
                    result.append([x, next_x, cur_sum])

        return result
```

### 方法二：优化合并相邻颜色和相同的区间（如需严格按颜色集合）

```python
from typing import List
from collections import defaultdict

class Solution:
    def splitPainting(self, segments: List[List[int]]) -> List[List[int]]:
        diff = defaultdict(int)
        endpoints = set()

        for l, r, color in segments:
            diff[l] += color
            diff[r] -= color
            endpoints.add(l)
            endpoints.add(r)

        sorted_pts = sorted(endpoints)
        result = []
        cur_sum = 0

        for i in range(len(sorted_pts) - 1):
            cur_sum += diff[sorted_pts[i]]
            if cur_sum > 0:
                # 相邻区间颜色和相同时合并（题目要求相邻颜色组合不同才分开）
                # 颜色和相同时不能合并（颜色集合可能不同）
                # 直接添加
                result.append([sorted_pts[i], sorted_pts[i + 1], cur_sum])

        # 合并颜色和相同的相邻区间
        merged = []
        for seg in result:
            if merged and merged[-1][1] == seg[0] and merged[-1][2] == seg[2]:
                merged[-1][1] = seg[1]  # 扩展右端点
            else:
                merged.append(seg[:])
        return merged
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 差分 + 离散化 | O(n log n) | O(n) |

## 关键点总结

1. 用差分处理区间颜色叠加：start 处 +color，end 处 -color
2. 离散化处理坐标范围大的情况
3. 颜色和相同的相邻区间可以合并描述

---

## 易错点

- `diff` 是颜色值之和的差分，不是颜色 id 的集合
- 端点排序后，相邻两个端点之间的区间颜色和才是有意义的
