## 题目描述

有一个超市，超市里有 `n` 件商品。超市给每隔 `n` 位顾客（第 `n`、`2n`、`3n`……位）提供折扣。

请你实现 `Cashier` 类：
- `Cashier(int n, int discount, int[] products, int[] prices)` — 初始化对象，其中 `n` 表示每 n 个顾客一次折扣，`discount` 是折扣的百分比，`products` 和 `prices` 分别为商品编号和价格的数组（对应关系）。
- `double getBill(int[] product, int[] amount)` — 返回账单的总金额。`product[i]` 是第 i 件商品的编号，`amount[i]` 是购买数量。如果当前顾客是享受折扣的顾客（第 n、2n…位），则账单打折。最终结果需保留小数。

**示例：**
```
输入：
["Cashier","getBill","getBill","getBill","getBill","getBill","getBill","getBill"]
[[3,50,[1,2,3,4,5,6,7],[100,200,300,400,300,200,100]],
 [[1,2],[1,2]],[[3,7],[10,10]],[[1,2,3,4,5,6,7],[1,1,1,1,1,1,1]],
 [[4],[10]],[[7,3],[10,10]],[[7,5,3,1,6,4,2],[10,10,10,9,9,9,7]],
 [[2,3,5],[5,3,2]]]
输出：[null,500.0,4000.0,800.0,4000.0,4000.0,7350.0,2500.0]

解释：
第1个顾客：[1,2] 各买 [1,2] -> 1*100 + 2*200 = 500，不打折
第2个顾客：[3,7] 各买 [10,10] -> 10*300 + 10*100 = 4000，不打折
第3个顾客（第3位，享受折扣）：买7件，原价 = 1*100+1*200+1*300+1*400+1*300+1*200+1*100 = 1600，
  打五折（50%折扣） -> 1600 * 0.5 = 800
第4个顾客：[4] 买 [10] -> 10*400 = 4000，不打折
...
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= discount <= 100`
- `1 <= products.length <= 200`
- `1 <= products[i] <= 200`
- `products` 数组中的元素各不相同
- `prices.length == products.length`
- `1 <= prices[i] <= 1000`
- `1 <= product.length <= products.length`
- `product[i]` 为 `products` 中出现过的商品
- `amount.length == product.length`
- `1 <= amount[i] <= 1000`
- `getBill` 最多被调用 1000 次

## 解题思路

这道题是直接模拟题，核心逻辑简单：

1. 在 `__init__` 中建立商品价格的哈希表，维护顾客计数器。
2. 在 `getBill` 中：
   - 顾客计数器加 1。
   - 按商品和数量计算总价。
   - 判断是否是第 n、2n、3n… 位顾客（即计数器能被 n 整除），是则打折。

折扣计算：原价 `total` 打 `discount` 折扣后为 `total * (100 - discount) / 100`。

## Python 代码实现

### 方法一：哈希表 + 计数器（推荐）

```python
from typing import List

class Cashier:

    def __init__(self, n: int, discount: int, products: List[int], prices: List[int]):
        self.n = n                    # 每隔 n 位顾客享受折扣
        self.discount = discount      # 折扣百分比（如 50 表示打五折）
        self.customer_count = 0       # 顾客计数器
        # 建立商品编号到价格的哈希表
        self.price_map = {p: pr for p, pr in zip(products, prices)}

    def getBill(self, product: List[int], amount: List[int]) -> float:
        self.customer_count += 1  # 新顾客来了
        
        # 计算本次购物的原价总额
        total = sum(self.price_map[p] * a for p, a in zip(product, amount))
        
        # 判断是否享受折扣（第 n, 2n, 3n... 位顾客）
        if self.customer_count % self.n == 0:
            total *= (100 - self.discount) / 100
        
        return total
```

### 方法二：更完整的注释版

```python
from typing import List

class Cashier:

    def __init__(self, n: int, discount: int, products: List[int], prices: List[int]):
        """
        初始化收银机
        :param n: 每 n 位顾客中的最后一位享受折扣
        :param discount: 折扣百分比，如 discount=30 表示打 7 折（减免 30%）
        :param products: 商品编号列表
        :param prices: 对应的商品价格列表
        """
        self.n = n
        self.discount = discount
        self.count = 0  # 已服务的顾客总数
        
        # 用字典快速查询商品价格
        self.price_of = {}
        for prod, price in zip(products, prices):
            self.price_of[prod] = price

    def getBill(self, product: List[int], amount: List[int]) -> float:
        """
        计算当前顾客的账单金额
        :param product: 购买的商品编号列表
        :param amount: 对应的购买数量列表
        :return: 账单金额（打折后）
        """
        self.count += 1  # 顾客进店，计数加 1
        
        # 计算总价 = sum(单价 * 数量)
        total = 0.0
        for prod, amt in zip(product, amount):
            total += self.price_of[prod] * amt
        
        # 是第 n、2n、3n... 位顾客则享受折扣
        if self.count % self.n == 0:
            # 折扣：减去 discount% 的金额
            total = total * (100 - self.discount) / 100
        
        return total
```

### 方法三：支持动态添加商品的扩展版

```python
from typing import List

class Cashier:
    """
    扩展版：支持后续添加新商品
    """
    
    def __init__(self, n: int, discount: int, products: List[int], prices: List[int]):
        self.n = n
        self.discount = discount
        self.count = 0
        self.prices = dict(zip(products, prices))

    def add_product(self, product_id: int, price: int) -> None:
        """动态添加新商品"""
        self.prices[product_id] = price

    def getBill(self, product: List[int], amount: List[int]) -> float:
        self.count += 1
        # 使用 .get() 安全查询，未知商品价格视为 0
        total = sum(self.prices.get(p, 0) * a for p, a in zip(product, amount))
        
        if self.count % self.n == 0:
            total *= (100 - self.discount) / 100
        
        return total
```

## 复杂度分析

- `__init__` 时间复杂度：O(P)，P 是商品数量，建立哈希表。
- `getBill` 时间复杂度：O(Q)，Q 是本次购买的商品种数。
- 空间复杂度：O(P)，存储商品价格的哈希表。

## 关键点总结

1. 用哈希表（字典）存储商品价格，实现 O(1) 查询。
2. 维护顾客计数器 `count`，每次 `getBill` 时加 1，用 `count % n == 0` 判断是否打折。
3. 折扣计算：`total * (100 - discount) / 100`，注意除以浮点数（不是整除）。
4. 题目保证 `product` 中的商品编号都在初始化时提供过，无需处理未知商品。

## 易错点

- 折扣是"减去 discount%"，而非"乘以 discount%"。折后价格 = 原价 * (1 - discount/100) = 原价 * (100-discount)/100。
- 计数器必须在每次 `getBill` 开头就加 1（先到先得），不能在最后加，否则第一个顾客编号会是 0 而不是 1。
- `count % n == 0` 注意当 `count = 0` 时也满足（`0 % n == 0`），但由于 `count` 初始化为 0 且在进入函数后立即加 1，所以第一次调用时 `count = 1`，不会有这个问题。
