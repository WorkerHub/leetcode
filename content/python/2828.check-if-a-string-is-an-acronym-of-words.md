## 题目描述

给你一个字符串数组 `words` 和一个字符串 `s`，判断 `s` 是否是 `words` 的**首字母缩写词**。

首字母缩写词：取每个单词的第一个字母，按顺序拼接形成的字符串。

**示例 1：**
```
输入：words = ["alice","bob","charlie"], s = "abc"
输出：true
解释：a+b+c = "abc"
```

**示例 2：**
```
输入：words = ["an","apple"], s = "a"
输出：false
解释：a+a = "aa"，不等于 "a"
```

**示例 3：**
```
输入：words = ["never","gonna","give","up","to"], s = "ngut"
输出：false
解释：首字母 = "nggut"，不等于 "ngut"
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 10`
- `1 <= s.length <= 100`
- 字符串只包含小写字母

## 解题思路

直接取每个单词的第一个字母，拼接后与 `s` 比较。

## Python 代码实现

### 方法一：列表推导式（推荐）

```python
from typing import List

class Solution:
    def isAcronym(self, words: List[str], s: str) -> bool:
        # 取每个单词的第一个字母，拼接后与 s 比较
        return ''.join(word[0] for word in words) == s
```

### 方法二：逐个比较

```python
from typing import List

class Solution:
    def isAcronym(self, words: List[str], s: str) -> bool:
        # 长度不匹配直接返回 False
        if len(words) != len(s):
            return False
        # 逐个比较每个单词的首字母
        for i, word in enumerate(words):
            if word[0] != s[i]:
                return False
        return True
```

### 方法三：zip 比较

```python
from typing import List

class Solution:
    def isAcronym(self, words: List[str], s: str) -> bool:
        if len(words) != len(s):
            return False
        return all(word[0] == ch for word, ch in zip(words, s))
```

## 复杂度分析

- 时间复杂度：O(n)，n = len(words)
- 空间复杂度：O(n)，生成首字母字符串（方法一）；O(1)（方法二/三）

## 关键点总结

1. 首字母缩写 = 每个单词的第一个字母按序拼接
2. 先检查长度是否相等，快速排除
3. Python 的 `join` 配合生成器是最简洁的实现

## 易错点

1. 检查长度：words 长度必须等于 s 长度
2. `word[0]` 取第一个字符，注意单词不为空（题目保证 word.length >= 1）
