## 题目描述

给你一个下标从 0 开始的正整数数组 `nums`。

每次操作，你可以：
- 删除两个相等的元素（如果存在）
- 删除三个相等的元素（如果存在）

返回使数组变为**空**所需的**最少操作次数**。如果无法清空，返回 -1。

**示例 1：**
```
输入：nums = [2,3,3,2,2,4,2,3,4]
输出：4
解释：[2,2,2,2] -> 两次删 2（4/2=2），[3,3,3] -> 一次删 3（3/3=1），[4,4] -> 一次删 4（2/2=1）
总共 4 次
```

**示例 2：**
```
输入：nums = [2,1,2,2,3,3]
输出：-1
解释：元素 1 只出现 1 次，无法删除
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

统计每种元素出现次数 `cnt`：
- 若 `cnt == 1`，无法删除，返回 -1
- 否则，最少操作次数 = `ceil(cnt / 3)`

**原理：**
- 若 cnt = 3k：k 次三删
- 若 cnt = 3k + 1：可以用 (k-1) 次三删 + 2 次二删 = k+1 次（比 k+1 次三删+... 更好）
  - 实际：3k+1 = 3(k-1) + 4 = 3(k-1) + 2 + 2，共 k-1+2 = k+1 次
- 若 cnt = 3k + 2：k 次三删 + 1 次二删 = k+1 次

都等于 `ceil(cnt / 3)`。

## Python 代码实现

### 方法一：Counter + ceil（推荐）

```python
from collections import Counter
from math import ceil
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        ops = 0
        for c in cnt.values():
            if c == 1:
                return -1
            ops += ceil(c / 3)
        return ops
```

### 方法二：整数除法

```python
from collections import Counter
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        ops = 0
        for c in cnt.values():
            if c == 1:
                return -1
            # ceil(c / 3) = (c + 2) // 3
            ops += (c + 2) // 3
        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，统计频次 + 遍历
- 空间复杂度：O(k)，k 为不同元素数

## 关键点总结

1. 每种元素独立处理
2. 出现 1 次：无法删除，返回 -1
3. 出现 cnt 次：最少操作数 = `ceil(cnt / 3)`

## 易错点

1. cnt=1 的情况必须提前处理
2. `ceil(c / 3)` 用整数写法：`(c + 2) // 3`
3. 所有元素独立，总操作数是各元素操作数之和

## 图解示例

```
cnt=2: ceil(2/3) = 1（二删一次）
cnt=3: ceil(3/3) = 1（三删一次）
cnt=4: ceil(4/3) = 2（二删+二删）
cnt=5: ceil(5/3) = 2（三删+二删）
cnt=6: ceil(6/3) = 2（三删+三删）
```
