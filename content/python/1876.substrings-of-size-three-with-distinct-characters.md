## 题目描述

如果一个字符串不含重复字符，我们称这个字符串为 **好字符串**。

给你一个字符串 `s`，返回 `s` 中长度为 3 且无重复字符的子字符串数量。

**示例 1：**
```
输入：s = "xyzzaz"
输出：2
解释：长度为3的子串：xyz, yzz, zza, zaz；其中 xyz 和 zaz 不含重复字符
```

**示例 2：**
```
输入：s = "aababcabc"
输出：4
```

**提示：**
- `1 <= s.length <= 100`

## 解题思路

滑动窗口大小固定为 3，枚举所有长度为 3 的子串，判断是否有重复字符（3 个字符各不相同）。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def countGoodSubstrings(self, s: str) -> int:
        count = 0
        for i in range(len(s) - 2):
            # 判断 s[i], s[i+1], s[i+2] 是否各不相同
            if s[i] != s[i+1] and s[i+1] != s[i+2] and s[i] != s[i+2]:
                count += 1
        return count
```

### 方法二：集合判断

```python
class Solution:
    def countGoodSubstrings(self, s: str) -> int:
        return sum(1 for i in range(len(s) - 2) if len(set(s[i:i+3])) == 3)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 窗口大小固定为 3，只需比较 3 个字符两两不同
2. 3 个字符两两不同等价于集合大小为 3

## 易错点

- 枚举范围：`range(len(s) - 2)`，最后两个字符不能作为起点
