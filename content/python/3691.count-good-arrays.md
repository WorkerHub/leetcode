## 题目描述

给你三个整数 `n`、`m` 和 `k`。构造一个长度为 `n` 的数组，每个元素在 `[1, m]` 之间，且恰好有 `k` 对相邻元素相等。返回这样的数组数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 3, m = 2, k = 1
输出：4
解释：[1,1,2],[1,2,2],[2,2,1],[2,1,1]，共4个
```

**示例 2：**

```
输入：n = 2, m = 3, k = 2
输出：0
解释：长度2的数组最多1对相邻相等
```

**提示：**

- `2 <= n <= 10^5`
- `2 <= m <= 10^5`
- `0 <= k <= n - 1`

## 解题思路

组合数学：

构造方式：选择 `k` 个位置使得相邻元素相等，其余相邻对不相等。

- 共有 `n-1` 个相邻对，选 `k` 个相等：`C(n-1, k)` 种位置选法
- 数组中"不同段"的数量：选了 k 个相等对后，相当于把数组分成了 `n-k` 个"变化段"
  - 第一段：m 种选择
  - 后续每段：选一个与前段不同的值，即 `m-1` 种选择
- 总方案数 = `C(n-1, k) * m * (m-1)^(n-1-k)`

## Python 代码实现

### 方法一：组合数公式（推荐）

```python
from math import comb

class Solution:
    def countGoodArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        if k >= n:
            return 0
        # C(n-1, k) * m * (m-1)^(n-1-k)
        ans = comb(n - 1, k) * m % MOD
        ans = ans * pow(m - 1, n - 1 - k, MOD) % MOD
        return ans
```

### 方法二：验证思路

```python
from math import comb

class Solution:
    def countGoodArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # 共 n-1 对相邻，选 k 对相等
        # 剩余 n-1-k 对不相等
        # 段数 = n - k（将相等的对合并成同一段）
        # 第1段 m 种，后续每段 m-1 种
        if k > n - 1:
            return 0
        segments = n - k
        ans = comb(n - 1, k) % MOD
        ans = ans * m % MOD
        ans = ans * pow(m - 1, segments - 1, MOD) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（计算组合数和快速幂）
- 空间复杂度：O(1)

## 关键点总结

1. 核心公式：`C(n-1, k) * m * (m-1)^(n-1-k)`
2. 组合数选择 k 个相等位置，然后为每段赋值
3. 第一段 m 种，后续每段 m-1 种（不同于前一段）

## 易错点

1. k 必须 <= n-1（不能有比相邻对更多的相等对）
2. 段数 = n - k（k 个相等对合并了 k 对相邻节点）
3. 后续段数为 `n-k-1` 个，每段 `m-1` 种
