## 题目描述

给你一个整数数组 `nums` 和整数 `k`。每次操作可以将数组中的某个元素加 1 或减 1，最多操作 `k` 次。

请返回操作后数组中**出现频率最高**的元素的最大可能频率。

**示例 1：**

```
输入：nums = [1,2,4], k = 5
输出：3
解释：将1→3(+2)，2→3(+1)，4→3(-1)，总操作4次<=5，频率3
```

**示例 2：**

```
输入：nums = [1,4,8,13], k = 5
输出：2
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

排序 + 滑动窗口：

1. 排序数组
2. 对于窗口 `[left, right]`，将所有元素变为 `nums[right]`（最大值）的代价 = `nums[right] * (right - left + 1) - sum(window)`
3. 若代价 <= k，窗口合法，记录窗口大小
4. 否则收缩左边界

## Python 代码实现

### 方法一：排序 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        nums.sort()
        left = 0
        window_sum = 0
        ans = 1

        for right in range(len(nums)):
            window_sum += nums[right]
            # 将窗口内所有元素变为 nums[right] 的代价
            while nums[right] * (right - left + 1) - window_sum > k:
                window_sum -= nums[left]
                left += 1
            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：二分查找（针对每个目标值）

```python
from typing import List
import bisect

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = 1
        for right in range(n):
            target = nums[right]
            # 二分找最小的 left 使得代价 <= k
            lo, hi = 0, right
            while lo < hi:
                mid = (lo + hi) // 2
                cost = target * (right - mid + 1) - (prefix[right + 1] - prefix[mid])
                if cost <= k:
                    hi = mid
                else:
                    lo = mid + 1
            ans = max(ans, right - lo + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 排序后，最优目标值一定是某个数组元素
2. 将窗口内所有元素变为窗口最大值的代价可用前缀和快速计算
3. 滑动窗口保证窗口内代价始终 <= k
4. 窗口大小即为该目标值的最大可达频率

## 易错点

1. 只考虑变大而非变小（排序后变为最大值代价最小）
2. 代价公式：`target * len - sum`，不是 `sum - target * len`
3. 窗口收缩时同步更新 `window_sum`
