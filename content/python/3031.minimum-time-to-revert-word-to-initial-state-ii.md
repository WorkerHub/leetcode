## 题目描述

与 3029 相同题意，但 `word.length` 扩大到 `10^6`，需要更高效的算法。

**提示：**
- `1 <= word.length <= 10^6`
- `1 <= k <= word.length`

## 解题思路

与 3029 相同思路：经过 `t` 次操作后，恢复条件是 `word[t*k:]` 是 `word` 的前缀。

用 Z 函数 O(n) 预处理，然后对每个 `t` 的 `start = t * k`，检查 `z[start] >= n - start`。

Z 函数 `z[i]` 表示 `word[i:]` 与 `word` 的最长公共前缀长度。

## Python 代码实现

### 方法一：Z 函数（推荐）

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)

        # 计算 Z 数组
        z = [0] * n
        z[0] = n
        l, r = 0, 0
        for i in range(1, n):
            if i < r:
                z[i] = min(r - i, z[i - l])
            while i + z[i] < n and word[z[i]] == word[i + z[i]]:
                z[i] += 1
            if i + z[i] > r:
                l, r = i, i + z[i]

        # 检查最少操作次数
        for t in range(1, (n + k - 1) // k + 1):
            start = t * k
            if start >= n:
                return t  # 全部替换，任意构造
            if z[start] >= n - start:
                return t

        return (n + k - 1) // k
```

### 方法二：滚动哈希验证

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)
        MOD = (1 << 61) - 1  # 梅森素数
        BASE = 131

        # 预计算哈希和幂次
        h = [0] * (n + 1)
        pw = [1] * (n + 1)
        for i in range(n):
            h[i + 1] = (h[i] * BASE + ord(word[i])) % MOD
            pw[i + 1] = pw[i] * BASE % MOD

        def get_hash(l, r):
            # word[l..r-1] 的哈希值
            return (h[r] - h[l] * pw[r - l]) % MOD

        for t in range(1, (n + k - 1) // k + 1):
            start = t * k
            if start >= n:
                return t
            # 检查 word[start:n] 是否等于 word[0:n-start]
            suffix_len = n - start
            if get_hash(start, n) == get_hash(0, suffix_len):
                return t

        return (n + k - 1) // k
```

## 复杂度分析

- 时间复杂度：O(n)，Z 函数预处理 O(n)，检查 O(n/k) 次
- 空间复杂度：O(n)

## 关键点总结

1. Z 函数是解决"前缀匹配"问题的利器
2. `z[start] >= n - start` 说明 `word[start:]` 完全是 `word` 的前缀
3. 大数据量下必须使用 O(n) 算法

## 易错点

1. Z 数组中 `z[0]` 定义为 `n`（整个字符串）
2. 检查 `start >= n` 需要在访问 `z[start]` 之前
3. 滚动哈希中取模运算需要注意负数情况（Python 中 `%` 已正确处理）
