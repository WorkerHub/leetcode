## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个正整数 `k`。

如果满足以下条件，则下标 `i` 是 **k-big**：
- 存在至少 `k` 个不同的下标 `idx1`，使得 `idx1 < i` 且 `nums[idx1] < nums[i]`
- 存在至少 `k` 个不同的下标 `idx2`，使得 `idx2 > i` 且 `nums[idx2] < nums[i]`

返回 k-big 下标的数目。

**示例 1：**

```
输入：nums = [2,3,6,5,2,3], k = 2
输出：2
解释：下标 2（值 6）左边有 2 个更小的，右边也有 2 个更小的，是 k-big。
```

**示例 2：**

```
输入：nums = [1,1,1], k = 3
输出：0
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

对每个下标 i，需要知道左边有多少个严格小于 nums[i] 的元素，以及右边有多少个。

**方法**：维护有序结构（如 SortedList 或 BIT），从左到右扫描统计左侧小于当前值的数量；从右到左扫描统计右侧小于当前值的数量。两者均 >= k 则计数。

## Python 代码实现

### 方法一：使用 SortedList（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def kBigIndices(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # left[i] = nums[i] 左边严格小于 nums[i] 的元素数量
        left = [0] * n
        sl = SortedList()
        for i, v in enumerate(nums):
            left[i] = sl.bisect_left(v)  # 小于 v 的元素数量
            sl.add(v)

        # right[i] = nums[i] 右边严格小于 nums[i] 的元素数量
        right = [0] * n
        sl = SortedList()
        for i in range(n - 1, -1, -1):
            right[i] = sl.bisect_left(nums[i])
            sl.add(nums[i])

        return sum(1 for i in range(n) if left[i] >= k and right[i] >= k)
```

### 方法二：树状数组（BIT）

```python
from typing import List

class BIT:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i):
        while i <= self.n:
            self.tree[i] += 1
            i += i & (-i)

    def query(self, i):
        # 查询 [1, i] 的前缀和
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

class Solution:
    def kBigIndices(self, nums: List[int], k: int) -> int:
        n = len(nums)
        max_v = max(nums)

        # 左侧小于 nums[i] 的数量
        left = [0] * n
        bit = BIT(max_v)
        for i, v in enumerate(nums):
            left[i] = bit.query(v - 1) if v > 1 else 0
            bit.update(v)

        # 右侧小于 nums[i] 的数量
        right = [0] * n
        bit = BIT(max_v)
        for i in range(n - 1, -1, -1):
            v = nums[i]
            right[i] = bit.query(v - 1) if v > 1 else 0
            bit.update(v)

        return sum(1 for i in range(n) if left[i] >= k and right[i] >= k)
```

## 复杂度分析

- 时间复杂度：O(n log n)，SortedList 每次操作 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 问题分解为：左侧小于当前值的数量 + 右侧小于当前值的数量
2. SortedList 的 `bisect_left(v)` 返回 < v 的元素个数
3. 树状数组（BIT）也可高效实现，适合没有 sortedcontainers 的环境

## 易错点

1. 需要"严格小于"，使用 `bisect_left` 而不是 `bisect_right`
2. 从右向左扫描时，先查询后更新（和从左向右一致）
3. 树状数组下标从 1 开始，注意映射关系
