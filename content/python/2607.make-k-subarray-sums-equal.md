## 题目描述

给你一个下标从 0 开始的整数数组 `arr` 和一个整数 `k`。数组 `arr` 是循环的，即 `arr[arr.length - 1]` 之后是 `arr[0]`。

每次操作，你可以将 `arr` 中的任意一个元素加 1 或减 1（可以为负数）。返回使每个长度为 `k` 的子数组之和相等所需的最少操作次数。

**示例 1：**
```
输入：arr = [1,4,1,3], k = 2
输出：1
解释：一次操作后可使每个长度2的子数组和相等
```

**示例 2：**
```
输入：arr = [2,5,3,7], k = 3
输出：5
```

**数据范围：**
- 1 <= arr.length <= 10^5
- 1 <= arr[i] <= 10^9
- 1 <= k <= arr.length

## 解题思路

数学 + 数论分析：

若所有长度为 `k` 的循环子数组和相等，则 `arr[i] == arr[i + k]`（对所有 `i` 取模 `n`）。这意味着每个 `arr[i]` 必须等于所有与 `i` 模 `gcd(k, n)` 同余的元素。

因此，按下标模 `gcd(k, n)` 分组，组内所有元素必须相等。使一组数相等的最少操作次数，将所有元素变为中位数时最优（最小绝对偏差之和）。

## Python 代码实现

### 方法一：GCD 分组 + 中位数（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def makeSubKSumEqual(self, arr: List[int], k: int) -> int:
        n = len(arr)
        g = gcd(n, k)  # 关键：分组依据

        # 按下标模 g 分组
        groups = [[] for _ in range(g)]
        for i, x in enumerate(arr):
            groups[i % g].append(x)

        total_ops = 0
        for group in groups:
            group.sort()
            median = group[len(group) // 2]
            # 将组内所有元素变为中位数的操作数
            total_ops += sum(abs(x - median) for x in group)

        return total_ops
```

### 方法二：显式分析过程

```python
from typing import List
from math import gcd

class Solution:
    def makeSubKSumEqual(self, arr: List[int], k: int) -> int:
        n = len(arr)
        g = gcd(n, k)
        visited = [False] * n
        ans = 0

        for start in range(g):
            # 收集同一"等价类"的元素
            group = []
            i = start
            while not visited[i]:
                visited[i] = True
                group.append(arr[i])
                i = (i + k) % n  # 下一个等价元素

            # 求最小绝对偏差：变为中位数
            group.sort()
            mid = group[len(group) // 2]
            ans += sum(abs(x - mid) for x in group)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要来自排序
- 空间复杂度：O(n)，分组存储

## 关键点总结

1. 循环数组中，所有长度为 `k` 的子数组和相等 等价于 `arr[i] = arr[(i+k) % n]`
2. 等价关系将数组划分为 `gcd(n, k)` 个等价类
3. 将一组数变为同一值，选择中位数操作数最少

## 易错点

1. 分组大小是 `gcd(n, k)` 而非 `k`
2. 最优目标值是中位数（偶数个时取哪个都可以）
3. 循环数组下标处理：`(i + k) % n`
