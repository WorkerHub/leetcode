## 题目描述

给你一个长度为 `n` 的整数数组 `books`，其中 `books[i]` 表示第 `i` 个书架的书的数量。

你可以按连续顺序从一个或多个书架取书，但**每个书架取的书必须严格少于它右边书架取的书**，也就是说，对于取书区间 `[l, r]`，取书数量形成**严格递增**的序列，且每个书架的取书数量不超过其实际书数。

返回最多能取多少本书。

**示例 1：**
```
输入：books = [8,5,2,7,3]
输出：12
解释：从 books[1..3]=[5,2,7] 中取 [1,2,3,6]->最大，或取 [2,3,7]->12。
```

**提示：**
- `1 <= books.length <= 10^5`
- `0 <= books[i] <= 10^5`

## 解题思路

**单调栈 + DP：**

以 `i` 为右端点，最优取法是从右端取 `books[i]` 本，往左依次递减 1，直到某书架书数不够或到达左端。

定义 `dp[i]` 为以书架 `i` 结尾的最大取书数。

**关键：** 以 `i` 结尾的最优段，如果从 `j` 开始，取的数为连续的 `books[i]-k, ..., books[i]-1, books[i]`（k = i-j）。若 `books[j] >= books[i] - (i-j)`，则 j 满足条件，否则需要更靠右。

用单调栈维护满足条件的左端点。

## 代码实现

### 方法一：单调栈 + DP（推荐）

```python
from typing import List

class Solution:
    def maximumBooks(self, books: List[int]) -> int:
        n = len(books)
        dp = [0] * n
        stack = []  # 单调栈，存储 (有效左端点 l, dp[l] 对应的前缀信息)
        
        def calc(l, r):
            # 从 l 到 r 的最优取书数
            # 最多取 books[r] 本，形成严格递增序列
            # 长度为 r - l + 1，最大可取 books[r], books[r]-1, ..., books[r]-k
            # 若 books[l] >= books[r] - (r - l)，则全段都够
            k = r - l  # 区间长度 - 1
            low = books[r] - k  # l 处需要取的书数
            if low <= 0:
                # books[r] 不够用来形成长为 r-l+1 的递增序列
                # 实际能用的长度为 books[r]
                actual_len = books[r]
                low = 1
            else:
                actual_len = k + 1
            # 等差数列求和：low, low+1, ..., books[r]
            return (low + books[r]) * actual_len // 2
        
        ans = 0
        for i in range(n):
            # 弹出栈中不满足条件的元素
            # 若 books[stack[-1]] >= books[i] - (i - stack[-1])，则 stack[-1] 的左边的书可以纳入
            while stack and books[stack[-1]] >= books[i] - (i - stack[-1]):
                stack.pop()
            
            if not stack:
                dp[i] = calc(0, i)
            else:
                l = stack[-1]
                dp[i] = dp[l] + calc(l + 1, i)
            
            ans = max(ans, dp[i])
            stack.append(i)
        
        return ans
```

### 方法二：暴力 DP（会超时，用于理解）

```python
from typing import List

class Solution:
    def maximumBooks(self, books: List[int]) -> int:
        n = len(books)
        ans = 0
        
        for r in range(n):
            # 以 r 为右端点，找最优左端点
            total = books[r]
            cur = books[r]
            for l in range(r - 1, -1, -1):
                cur -= 1  # l 处应取的书数（比右边少 1）
                take = min(books[l], cur)
                if take <= 0:
                    break
                if take < cur:
                    cur = take
                total += take
            ans = max(ans, total)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单调栈 + DP | O(n) | O(n) |
| 暴力 | O(n^2) | O(1) |

## 关键点总结

1. 以 i 为右端点，形成严格递增取书序列，等差公式计算总数。
2. 单调栈维护有效的左边界：若左边某书架书数"足够大"，则可以从更左边开始。
3. `dp[i]` 利用之前的结果，避免重复计算。

## 易错点

- 当 `books[r]` 小于区间长度时，实际能形成的序列长度为 `books[r]`。
- 等差数列求和需注意首项（low）和末项（books[r]）的正确计算。
