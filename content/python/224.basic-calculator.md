## 题目描述

给你一个字符串表达式 `s`，请你实现一个基本计算器来计算并返回它的值。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()`。

**示例 1：**

```
输入：s = "1 + 1"
输出：2
```

**示例 2：**

```
输入：s = " 2-1 + 2 "
输出：3
```

**示例 3：**

```
输入：s = "(1+(4+5+2)-3)+(6+8)"
输出：23
```

**提示：**

- `1 <= s.length <= 3 * 10^5`
- `s` 由数字、`'+'`、`'-'`、`'('`、`')'`、和 `' '` 组成
- `s` 表示一个有效的表达式
- `'+'` 不能用作一元运算符（例如， `"+1"` 和 `"+(2 + 3)"` 无效）
- `'-'` 可以用作一元运算符（例如， `"-1"` 和 `"-(2 + 3)"` 是有效的）
- 输入中不存在两个连续的操作符
- 每个数字和运行的计算将适合于一个有符号的 32 位整数

## 解题思路

这道题的核心是处理加减运算和括号。由于只有加减法，**不需要考虑运算符优先级**，但需要处理括号改变符号的情况。

### 核心思想

使用**栈**来处理括号：
1. 遇到数字：累加到当前数字
2. 遇到 `+`：将之前的数字加到结果中
3. 遇到 `-`：将之前的数字的相反数加到结果中
4. 遇到 `(`：将当前结果和符号压入栈中，重置结果
5. 遇到 `)`：计算括号内的结果，与栈顶的结果合并

### 关键观察

1. **符号传递**：括号前的符号会影响括号内的所有运算
   - `-(a+b)` = `-a-b`
   - `+(a-b)` = `+a-b`

2. **栈的作用**：保存括号外的状态，以便括号结束后恢复

## Python 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def calculate(self, s: str) -> int:
        stack = []  # 存储括号外的结果和符号
        result = 0  # 当前结果
        num = 0     # 当前数字
        sign = 1    # 当前符号：1 表示正，-1 表示负
        
        for char in s:
            if char.isdigit():
                # 构建多位数字
                num = num * 10 + int(char)
            elif char == '+':
                # 将之前的数字加到结果中
                result += sign * num
                num = 0
                sign = 1
            elif char == '-':
                # 将之前的数字加到结果中
                result += sign * num
                num = 0
                sign = -1
            elif char == '(':
                # 遇到左括号，保存当前结果和符号
                stack.append(result)
                stack.append(sign)
                # 重置结果和符号
                result = 0
                sign = 1
            elif char == ')':
                # 遇到右括号，先处理括号内最后一个数字
                result += sign * num
                num = 0
                # 弹出括号前的符号
                result *= stack.pop()
                # 弹出括号前的结果，加上括号内的结果
                result += stack.pop()
        
        # 处理最后一个数字
        result += sign * num
        return result
```

### 方法二：递归

```python
class Solution:
    def calculate(self, s: str) -> int:
        self.index = 0
        return self.helper(s)
    
    def helper(self, s: str) -> int:
        result = 0
        num = 0
        sign = 1
        
        while self.index < len(s):
            char = s[self.index]
            
            if char.isdigit():
                num = num * 10 + int(char)
            elif char == '+':
                result += sign * num
                num = 0
                sign = 1
            elif char == '-':
                result += sign * num
                num = 0
                sign = -1
            elif char == '(':
                # 递归处理括号内的表达式
                self.index += 1
                num = self.helper(s)
            elif char == ')':
                # 括号结束，返回括号内的结果
                result += sign * num
                return result
            
            self.index += 1
        
        result += sign * num
        return result
```

### 方法三：去括号法

```python
class Solution:
    def calculate(self, s: str) -> int:
        """
        通过符号栈处理括号对内部符号的影响
        """
        stack = [1]  # 符号栈，初始为正号
        sign = 1     # 当前符号
        result = 0
        num = 0
        
        for char in s:
            if char.isdigit():
                num = num * 10 + int(char)
            elif char in '+-':
                # 将之前的数字加到结果
                result += sign * num
                num = 0
                # 更新符号：当前符号 * 栈顶符号
                sign = stack[-1] * (1 if char == '+' else -1)
            elif char == '(':
                # 左括号：将当前符号压栈
                stack.append(sign)
            elif char == ')':
                # 右括号：弹出符号
                stack.pop()
        
        # 处理最后一个数字
        result += sign * num
        return result
```

### 方法四：详细注释版（便于理解）

```python
class Solution:
    def calculate(self, s: str) -> int:
        """
        基本计算器：支持加减法和括号
        
        核心思想：
        1. 用栈保存括号外的状态
        2. 遇到左括号时，保存当前结果和符号
        3. 遇到右括号时，恢复之前的状态
        """
        stack = []   # 栈：[结果1, 符号1, 结果2, 符号2, ...]
        result = 0   # 当前层级的计算结果
        num = 0      # 当前正在构建的数字
        sign = 1     # 当前数字的符号（1或-1）
        
        for i, char in enumerate(s):
            if char == ' ':
                # 跳过空格
                continue
            elif char.isdigit():
                # 构建多位数字
                num = num * 10 + int(char)
            elif char == '+':
                # 遇到加号：将之前的数字加入结果
                result += sign * num
                num = 0      # 重置数字
                sign = 1     # 下一个数字是正数
            elif char == '-':
                # 遇到减号：将之前的数字加入结果
                result += sign * num
                num = 0      # 重置数字
                sign = -1    # 下一个数字是负数
            elif char == '(':
                # 遇到左括号：保存当前状态
                stack.append(result)  # 保存当前结果
                stack.append(sign)    # 保存当前符号
                result = 0  # 重置结果，准备计算括号内的表达式
                sign = 1    # 重置符号
            elif char == ')':
                # 遇到右括号：处理括号内的最后一个数字
                result += sign * num
                num = 0
                # 恢复括号前的状态
                result *= stack.pop()  # 乘以括号前的符号
                result += stack.pop()  # 加上括号前的结果
                # 注意：不需要重置 sign，因为括号后可能还有运算符
        
        # 处理表达式末尾的数字
        result += sign * num
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是字符串长度，需要遍历一次
- 空间复杂度：O(n)，栈的深度取决于括号的嵌套层数，最坏情况下为 O(n)

## 关键点总结

1. **栈的使用**：保存括号外的结果和符号
2. **符号处理**：用 1 和 -1 表示正负号
3. **数字构建**：`num = num * 10 + digit` 处理多位数
4. **括号处理**：左括号压栈，右括号弹栈并合并结果
5. **最后一个数字**：循环结束后要处理表达式末尾的数字

## 易错点

1. **忘记处理最后一个数字**：循环结束后要 `result += sign * num`
2. **空格处理**：题目中有空格，可以跳过或去除
3. **符号初始化**：sign 初始应该是 1
4. **栈的顺序**：先压结果，再压符号；弹出时先弹符号，再弹结果
5. **多位数处理**：连续的数字要合并成一个完整的数
