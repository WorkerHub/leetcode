## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，每次操作可以将任意元素 `nums[i]` 改变为 `[nums[i] - k, nums[i] + k]` 范围内的任意整数。

返回经过任意次操作后，数组中**不同元素**的最大数量。

**示例：**
```
输入：nums = [1,2,2,3,3], k = 2
输出：5
解释：可以将元素改为 [-1, 0, 2, 3, 5]（每个相差 >= 1），得到 5 个不同值。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

**贪心 + 排序：**

对数组排序，从左到右贪心地为每个元素分配尽可能小的不重复值。

对于排序后的元素 `nums[i]`，其可调整范围为 `[nums[i] - k, nums[i] + k]`。

贪心策略：维护"上一个已分配的值 `prev`"，对当前元素 `nums[i]`：
- 允许范围：`[nums[i] - k, nums[i] + k]`
- 贪心选择：`max(prev + 1, nums[i] - k)`（在范围内尽量小，为后续元素留余地）
- 若贪心选出的值 `> nums[i] + k`，则无法为该元素分配不同值（可能与其他元素冲突，但可以尝试其他值）

注意：若两个元素的区间无法分配不同值，则它们共用一个值，不增加计数。

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        ans = 0
        prev = float('-inf')  # 上一个分配的值
        
        for x in nums:
            # 当前元素可调整范围：[x - k, x + k]
            lo, hi = x - k, x + k
            
            # 贪心：选尽可能小的值（至少比 prev 大 1，且在 [lo, hi] 内）
            chosen = max(prev + 1, lo)
            
            if chosen <= hi:
                # 成功分配一个新的不同值
                ans += 1
                prev = chosen
            # 否则：当前元素无法分配不同值（该元素可以留在 prev+1 的下一个位置，
            # 但 prev+1 > hi，所以没有可用值，跳过，不增加 ans）
        
        return ans
```

### 方法二：排序 + 贪心（更清晰的写法）

```python
from typing import List

class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        ans = 0
        last = float('-inf')  # 上一次成功分配的值
        
        for x in nums:
            # 可用范围 [x-k, x+k]
            # 最优分配：恰好比上次大 1，但不超出范围
            target = max(last + 1, x - k)
            if target <= x + k:
                ans += 1
                last = target
            # 如果 target > x + k，跳过（不分配新值）
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（不计排序栈空间）

## 图解示例

```
nums = [1,2,2,3,3], k = 2
排序后: [1,2,2,3,3]
各元素范围: [-1,3] [0,4] [0,4] [1,5] [1,5]

贪心分配:
- x=1, 范围[-1,3], 选 max(-inf+1, -1) = -1, -1 <= 3 ✓, ans=1, last=-1
- x=2, 范围[0,4], 选 max(-1+1, 0) = 0, 0 <= 4 ✓, ans=2, last=0
- x=2, 范围[0,4], 选 max(0+1, 0) = 1, 1 <= 4 ✓, ans=3, last=1
- x=3, 范围[1,5], 选 max(1+1, 1) = 2, 2 <= 5 ✓, ans=4, last=2
- x=3, 范围[1,5], 选 max(2+1, 1) = 3, 3 <= 5 ✓, ans=5, last=3

最终答案: 5
```

## 关键点总结

1. 排序后贪心，每次选在范围内尽量小的值（`max(last+1, x-k)`）。
2. 若选出的值超出范围上界，则无法为该元素分配新值。
3. 贪心正确性：选尽量小的值为后续元素保留更多空间。

## 易错点

1. 贪心选的是 `max(prev + 1, lo)`，不是直接选 `lo`（需要避免重复）。
2. 若 `chosen > hi`，跳过该元素，不更新 `prev`（该元素无法增加不同值数量）。
3. 排序是必要的，保证贪心策略的正确性。
