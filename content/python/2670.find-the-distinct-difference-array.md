## 题目描述

给你一个下标从 0 开始的数组 `nums`，长度为 `n`。`nums` 的**差异数组** `diff` 满足：`diff[i] = |前缀 nums[0..i] 中不同元素的数量| - |后缀 nums[i+1..n-1] 中不同元素的数量|`。

返回差异数组 `diff`。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：[-3,-1,1,3,5]
解释：每个位置前缀和后缀的不同元素数之差
```

**示例 2：**
```
输入：nums = [3,2,3,4,2]
输出：[-2,-1,0,2,3]
```

**数据范围：**
- 1 <= n <= 50
- 1 <= nums[i] <= 50

## 解题思路

对每个位置 `i`，计算前缀 `nums[0..i]` 和后缀 `nums[i+1..n-1]` 各自的不同元素数量。

## Python 代码实现

### 方法一：直接计算（推荐）

```python
from typing import List

class Solution:
    def distinctDifferenceArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        diff = []
        for i in range(n):
            prefix_distinct = len(set(nums[:i + 1]))
            suffix_distinct = len(set(nums[i + 1:]))
            diff.append(prefix_distinct - suffix_distinct)
        return diff
```

### 方法二：前缀和后缀预计算

```python
from typing import List

class Solution:
    def distinctDifferenceArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 预计算前缀不同元素数
        prefix = []
        seen = set()
        for x in nums:
            seen.add(x)
            prefix.append(len(seen))

        # 预计算后缀不同元素数
        suffix = [0] * n
        seen = set()
        for i in range(n - 1, -1, -1):
            if i < n - 1:
                seen.add(nums[i + 1])
            suffix[i] = len(seen)

        return [prefix[i] - suffix[i] for i in range(n)]
```

## 复杂度分析

- 方法一：时间复杂度 O(n^2)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n)，空间复杂度 O(n)

## 关键点总结

1. `diff[i] = 前缀不同数量 - 后缀不同数量`
2. 后缀从 `i+1` 开始（不包括 `i`）
3. 用集合快速计算不同元素数量

## 易错点

1. 后缀是 `nums[i+1..]` 而非 `nums[i..]`
2. 最后一个元素的后缀为空集，后缀不同数量为 0
