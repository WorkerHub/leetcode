## 题目描述

给你一个字符串 `time`，格式为 `hh:mm`，其中一些数字被 `?` 替代，表示未知。

有效的时间格式为 `00:00` 到 `23:59`，返回 `time` 可以表示的有效时间数目。

**示例 1：**
```
输入：time = "?5:00"
输出：2
解释：?5 可以是 05 或 15，其他小时数字（25 等）无效。
```

**示例 2：**
```
输入：time = "0?:0?"
输出：100
解释：小时 0? 可以是 00-09，分钟 0? 也可以是 00-09，共 10 * 10 = 100 种。
```

**示例 3：**
```
输入：time = "??:??"
输出：1440
解释：24 小时 * 60 分钟 = 1440 种。
```

**提示：**
- `time` 是一个 5 字符的字符串
- `time[2]` 是 `':'`
- `time[0..1]` 的每个字符是数字或 `?`
- `time[3..4]` 的每个字符是数字或 `?`

## 解题思路

枚举所有可能的时间（0-23 小时，0-59 分钟），检查是否与给定模式匹配。

或者分开枚举小时（0-23）和分钟（0-59），统计各自合法的个数后相乘。

## 代码实现

### 方法一：枚举小时和分钟（推荐）

```python
class Solution:
    def countTime(self, time: str) -> int:
        def match(pattern: str, value: str) -> bool:
            """检查 value 是否匹配 pattern（? 可以匹配任何数字）"""
            for p, v in zip(pattern, value):
                if p != '?' and p != v:
                    return False
            return True

        h_pattern = time[:2]
        m_pattern = time[3:]

        # 统计合法小时数
        h_count = sum(1 for h in range(24) if match(h_pattern, f"{h:02d}"))
        # 统计合法分钟数
        m_count = sum(1 for m in range(60) if match(m_pattern, f"{m:02d}"))

        return h_count * m_count
```

### 方法二：枚举全部时间

```python
class Solution:
    def countTime(self, time: str) -> int:
        count = 0
        for h in range(24):
            for m in range(60):
                # 格式化为 hh:mm
                t = f"{h:02d}:{m:02d}"
                # 检查是否匹配
                if all(time[i] == '?' or time[i] == t[i] for i in range(5)):
                    count += 1
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分开枚举 | O(24 + 60) = O(1) | O(1) |
| 枚举全部 | O(24 * 60) = O(1) | O(1) |

所有枚举范围固定，时间复杂度为 O(1)。

## 关键点总结

1. 小时和分钟独立匹配，结果相乘
2. `?` 可以匹配任何数字字符
3. 小时范围 0-23，分钟范围 0-59

## 易错点

- 小时最大是 23，不是 24
- 格式化时需要补前导零：`f"{h:02d}"`
