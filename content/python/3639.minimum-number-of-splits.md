## 题目描述

给你一个正整数 `n`，将其分解为若干正整数之和，使得这些正整数的最大公约数（GCD）等于 1，且分解的数量尽可能少。

返回最少分解数量。

**示例 1：**

```
输入：n = 6
输出：2
解释：6 = 1 + 5（GCD(1,5)=1）或 6 = 2 + 4（GCD(2,4)=2，不行），最少2个
```

**示例 2：**

```
输入：n = 1
输出：1
解释：1 本身 GCD=1（单个数的GCD就是自身）
```

**提示：**

- `1 <= n <= 10^9`

## 解题思路

分析：
- 若 `n = 1`：答案为 1（只有 1 本身，GCD=1）
- 若 `n` 是奇数：答案为 1（`n` 本身是奇数，GCD=n，但单个数的"分解"要求 GCD=1...）

实际上题目要求分解为若干数之和，且这些数的 GCD = 1。
- 若 n = 1：答案 1
- 若 n >= 2：可以分为 1 和 n-1，GCD(1, n-1)=1，答案 2
- 但如果 n 本身就是 1，不需要分解

总结：若 n = 1，答案 1；否则答案 2（分出一个 1，剩余 n-1，GCD=1）。

## Python 代码实现

### 方法一：直接判断（推荐）

```python
class Solution:
    def minimumSplits(self, n: int) -> int:
        if n == 1:
            return 1
        # 分成 1 和 n-1，GCD(1, n-1) = 1，只需 2 个数
        return 2
```

### 方法二：数学分析

```python
from math import gcd

class Solution:
    def minimumSplits(self, n: int) -> int:
        # 检查 n 本身是否满足（单个数）
        # 单个数的GCD等于自身，只有 n=1 满足
        if n == 1:
            return 1
        # 两个数：1 + (n-1)，GCD=1，最优
        return 2
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 只有 n=1 时单个数满足 GCD=1
2. n>=2 时，分成 1 和 n-1 即可，GCD(1, x)=1 对任意 x 成立
3. 无需考虑分成 3 个或更多

## 易错点

1. 注意题目要求 GCD=1（互质），不是要求每个数为质数
2. 1 和任意正整数的 GCD 都是 1
