## 题目描述

给你一个正整数数组 `nums`，每次操作可以选择相邻两个元素，将其中一个替换为两者的 GCD。请返回将数组所有元素变为 1 所需的最少操作次数，若不可能则返回 -1。

**示例 1：**
```
输入：nums = [2,6,3,4]
输出：4
解释：
操作：gcd(6,3)=3 -> [2,3,3,4]
      gcd(3,4)=1 -> [2,3,1,4]
      然后把 1 扩散到其他位置（3次）
```

**示例 2：**
```
输入：nums = [2,10,6,14]
输出：-1
解释：所有元素的 GCD 为 2，无法变为 1
```

**数据范围：**
- 1 <= nums.length <= 2000
- 1 <= nums[i] <= 10^9

## 解题思路

分两步：

1. **判断可行性**：若整个数组的 GCD != 1，返回 -1
2. **计算最少操作数**：
   - 若已有 1，每个其他元素需要 1 次操作（和 1 取 GCD），共 `n - 1 - count(1)` 次
   - 若没有 1，需要先找最短子数组使其 GCD 为 1（设长度为 `len`，需要 `len - 1` 次），然后用这个 1 扩散到所有元素（`n - 1` 次）

## Python 代码实现

### 方法一：两阶段计算（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)

        # 统计已有 1 的个数
        ones = nums.count(1)
        if ones > 0:
            # 已有 1，每个非 1 元素需要 1 次操作
            return n - ones

        # 检查总 GCD 是否为 1
        total_gcd = nums[0]
        for x in nums:
            total_gcd = gcd(total_gcd, x)
        if total_gcd != 1:
            return -1

        # 找最短子数组，使得子数组的 GCD 为 1
        min_len = float('inf')
        for i in range(n):
            g = nums[i]
            for j in range(i + 1, n):
                g = gcd(g, nums[j])
                if g == 1:
                    min_len = min(min_len, j - i + 1)
                    break  # 更长的子数组只会更长

        # 先用 min_len - 1 次操作生成一个 1
        # 再用 n - 1 次操作把 1 扩散到所有位置
        return (min_len - 1) + (n - 1)
```

### 方法二：双指针优化

```python
from typing import List
from math import gcd

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ones = nums.count(1)
        if ones > 0:
            return n - ones

        # 找最短 GCD 为 1 的子数组
        min_ops = float('inf')
        for i in range(n):
            g = 0
            for j in range(i, n):
                g = gcd(g, nums[j])
                if g == 1:
                    min_ops = min(min_ops, j - i)
                    break

        return -1 if min_ops == float('inf') else min_ops + n - 1
```

## 复杂度分析

- 时间复杂度：O(n^2 log M)，M 为最大值
- 空间复杂度：O(1)

## 关键点总结

1. 若总 GCD != 1，不可能全变 1
2. 已有 1 时：`n - 1 - (ones - 1) = n - ones` 次操作
3. 无 1 时：先找最短 GCD=1 的子数组（长度为 len），需要 `len - 1 + n - 1` 次

## 易错点

1. 找最短子数组时，内层循环 GCD 一旦为 1 就 break（更长的一定更差）
2. 操作次数：生成 1 需要 `len - 1` 次，扩散需要 `n - 1` 次
3. 若已有 ones 个 1，扩散只需 `n - ones` 次
