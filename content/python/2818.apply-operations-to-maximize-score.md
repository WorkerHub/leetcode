## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个正整数 `k`。

**得分** 定义为：对于长度为 `m` 的子数组，得分 = 子数组中**质数分数**最高的元素 × m。

**质数分数**定义：整数 x 的质数分数是 x 的不同质因子个数。例如 300 = 2^2 × 3 × 5^2，质数分数 = 3。

你可以选择 `k` 次子数组（可以重复），每次操作对应一个子数组及其得分，目标是**最大化所有操作得分的乘积**，对 `10^9 + 7` 取模。

**提示：**
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= min(n * (n + 1) / 2, 10^10)`

## 解题思路

**关键：** 对每个元素 `nums[i]`，计算它能作为质数分数最高元素的子数组数量。

**步骤：**
1. 计算每个元素的质数分数（线性筛或直接分解）
2. 用单调栈，对每个元素找：
   - `left[i]`：左边第一个质数分数 >= prime_score[i] 的位置（严格大于时向右找）
   - `right[i]`：右边第一个质数分数 > prime_score[i] 的位置
   - 相邻相等时，左边优先级高（防止重复计算）
3. 元素 i 作为最大质数分数的子数组数 = `(i - left[i]) × (right[i] - i)`
4. 按 `nums[i]` 降序排序，贪心选取：每个元素贡献的子数组数乘以 `nums[i]`
5. 用快速幂计算答案

## Python 代码实现

### 方法一：单调栈 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)

        # 步骤 1：计算每个数的质数分数（不同质因子个数）
        max_val = max(nums)
        # 线性筛法
        prime_score = [0] * (max_val + 1)
        for p in range(2, max_val + 1):
            if prime_score[p] == 0:  # p 是质数
                for multiple in range(p, max_val + 1, p):
                    prime_score[multiple] += 1

        scores = [prime_score[v] for v in nums]

        # 步骤 2：单调栈求 left[i] 和 right[i]
        # left[i]：左边第一个 score >= scores[i] 的位置（不存在则 -1）
        # right[i]：右边第一个 score > scores[i] 的位置（不存在则 n）
        left = [-1] * n
        right = [n] * n

        stack = []
        for i in range(n):
            # 右边：score 严格大于 i
            while stack and scores[stack[-1]] < scores[i]:
                j = stack.pop()
                right[j] = i
            stack.append(i)

        stack = []
        for i in range(n - 1, -1, -1):
            # 左边：score 大于等于 i
            while stack and scores[stack[-1]] <= scores[i]:
                j = stack.pop()
                left[j] = i
            stack.append(i)

        # 步骤 3：计算每个元素能控制的子数组数
        # 用 (nums[i], 子数组数) 排序，贪心选取
        elements = []
        for i in range(n):
            l_cnt = i - left[i]      # 左边可选的位置数
            r_cnt = right[i] - i     # 右边可选的位置数
            cnt = l_cnt * r_cnt      # 以 i 为最大质数分数元素的子数组数
            elements.append((nums[i], cnt))

        # 按 nums 值降序排序
        elements.sort(reverse=True)

        # 步骤 4：贪心计算答案（用快速幂）
        ans = 1
        remaining = k
        for val, cnt in elements:
            take = min(cnt, remaining)
            ans = ans * pow(val, take, MOD) % MOD
            remaining -= take
            if remaining == 0:
                break

        return ans
```

## 复杂度分析

- 时间复杂度：O(M log log M + n log n)，其中 M = max(nums)，线性筛 O(M log log M)，单调栈 O(n)，排序 O(n log n)
- 空间复杂度：O(M + n)

## 关键点总结

1. 质数分数通过线性筛高效计算
2. 单调栈找左右边界：左边找 >= 的，右边找 > 的（防止重复）
3. 贪心：优先选 nums 值最大的元素，每次能用的子数组数 = l_cnt × r_cnt
4. `pow(val, take, MOD)` 是 Python 内置快速幂

## 易错点

1. 左右边界的严格/非严格区分：左边 >=，右边 > （统一处理相等情况，避免重复计数）
2. k 可以很大，需要用 `min(cnt, remaining)` 控制取的次数
3. 线性筛中 prime_score[p] == 0 是判断质数的条件
