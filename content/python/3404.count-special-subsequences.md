## 题目描述

给你一个整数数组 `nums`。

如果一个长度为 4 的下标四元组 `(a, b, c, d)` 满足以下条件，则称其为**特殊**的：
- `0 <= a < b < c < d < nums.length`
- `nums[a] * nums[d] == nums[b] * nums[c]`

返回特殊四元组的数量。

**示例 1：**

```
输入：nums = [1,2,3,6]
输出：1
解释：(0,1,2,3) 满足 1*6 = 2*3 = 6
```

**示例 2：**

```
输入：nums = [3,3,3,3,3]
输出：40
```

**提示：**
- `4 <= nums.length <= 200`
- `1 <= nums[i] <= 200`

## 解题思路

条件 `nums[a] * nums[d] == nums[b] * nums[c]` 等价于 `nums[a] / nums[b] == nums[c] / nums[d]`（即比值相等）。

**枚举中间两个元素 b 和 c**：
- 对于每对 `(b, c)`，枚举 `a < b` 的所有 `nums[a]`，统计每种值的出现次数
- 再枚举 `d > c` 的所有 `nums[d]`，检查是否存在某个 `nums[a]` 使得 `nums[a] * nums[d] == nums[b] * nums[c]`

更高效的方式：固定 `b` 和 `c`，令乘积 `P = nums[b] * nums[c]`。计数满足：
- `a < b` 且 `P % nums[a] == 0` 且在 `nums[d]` 范围中（`d > c`）有 `nums[d] == P // nums[a]` 的个数

利用哈希表：枚举 `(b, c)` 对，左侧用哈希表存已见过的 `nums` 值，右侧预处理后缀计数。

## Python 代码实现

### 方法一：枚举中间对 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSpecialSubsequences(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0

        # 枚举 b 和 c（中间两个位置）
        for b in range(1, n - 2):
            for c in range(b + 1, n - 1):
                product = nums[b] * nums[c]

                # 统计 a < b 中，nums[a] 能整除 product 且 product//nums[a] 出现在 d > c 中的组合数
                # 先统计左边 [0, b-1] 各值出现次数
                left_count = defaultdict(int)
                for a in range(b):
                    left_count[nums[a]] += 1

                # 统计右边 [c+1, n-1] 各值出现次数
                right_count = defaultdict(int)
                for d in range(c + 1, n):
                    right_count[nums[d]] += 1

                # 枚举 nums[a] 的可能值
                for val_a, cnt_a in left_count.items():
                    if product % val_a == 0:
                        val_d = product // val_a
                        count += cnt_a * right_count[val_d]

        return count
```

### 方法二：O(n^2) 预处理前后缀，O(n^2) 枚举

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSpecialSubsequences(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0

        # 预处理：suffix_count[i][v] = i 之后（不含i）值为 v 的元素个数
        # 为节省空间，边枚举边维护右侧计数
        for b in range(1, n - 2):
            # 左侧计数（a 从 0 到 b-1）
            left = defaultdict(int)
            for a in range(b):
                left[nums[a]] += 1

            for c in range(b + 1, n - 1):
                product = nums[b] * nums[c]

                # 右侧计数（d 从 c+1 到 n-1）
                right = defaultdict(int)
                for d in range(c + 1, n):
                    right[nums[d]] += 1

                for va, ca in left.items():
                    if product % va == 0:
                        vd = product // va
                        count += ca * right.get(vd, 0)

        return count
```

### 方法三：暴力四重循环（用于理解，n<=200时可接受）

```python
from typing import List

class Solution:
    def countSpecialSubsequences(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0

        for a in range(n - 3):
            for b in range(a + 1, n - 2):
                for c in range(b + 1, n - 1):
                    for d in range(c + 1, n):
                        # 检查条件
                        if nums[a] * nums[d] == nums[b] * nums[c]:
                            count += 1

        return count
```

## 复杂度分析

- 方法一（枚举中间对）：
  - 时间复杂度：O(n^3)，枚举 (b,c) 对后再遍历哈希表
  - 空间复杂度：O(n)

- 方法三（暴力）：
  - 时间复杂度：O(n^4)
  - 空间复杂度：O(1)

## 关键点总结

1. `nums[a] * nums[d] == nums[b] * nums[c]` 是等比关系
2. 固定中间对 (b,c) 后，利用哈希表减少枚举量
3. 整除检查 `product % val_a == 0` 保证 val_d 为整数

## 易错点

1. 下标顺序必须严格：`a < b < c < d`
2. 整数乘积可能很大，Python 不会溢出，但其他语言需注意
3. 枚举 val_a 时必须检查整除性，否则 val_d 不是整数
