## 题目描述

给定一个整数 `n`，如果它是阿姆斯特朗数则返回 `true`，否则返回 `false`。

阿姆斯特朗数（也称为水仙花数）定义为：一个 k 位数，它的每个位上的数字的 k 次幂之和等于它本身。

**示例 1：**
```
输入：n = 153
输出：true
解释：153 是一个 3 位数，且 153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153
```

**示例 2：**
```
输入：n = 123
输出：false
解释：123 是一个 3 位数，但 123 != 1^3 + 2^3 + 3^3 = 1 + 8 + 27 = 36
```

**提示：**
- `1 <= n <= 10^8`

## 解题思路

这道题的关键是：
1. 计算数字的位数 k
2. 将数字拆分成各个位
3. 计算每个位的 k 次幂之和
4. 判断和是否等于原数字

## Python 代码实现

### 方法一：字符串转换（推荐，简洁）

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        # 转换为字符串，方便获取位数和各位数字
        s = str(n)
        k = len(s)
        
        # 计算各位数字的 k 次幂之和
        total = sum(int(digit) ** k for digit in s)
        
        return total == n
```

### 方法二：数学方法

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        # 计算位数
        original = n
        k = len(str(n))
        
        # 计算各位数字的 k 次幂之和
        total = 0
        while n > 0:
            digit = n % 10
            total += digit ** k
            n //= 10
        
        return total == original
```

### 方法三：使用列表存储各位数字

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        # 提取各位数字
        digits = []
        temp = n
        while temp > 0:
            digits.append(temp % 10)
            temp //= 10
        
        # 计算位数
        k = len(digits)
        
        # 计算各位数字的 k 次幂之和
        total = sum(digit ** k for digit in digits)
        
        return total == n
```

### 方法四：一行代码

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        return n == sum(int(d) ** len(str(n)) for d in str(n))
```

### 方法五：数学优化（避免多次计算位数）

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        # 先计算位数
        s = str(n)
        k = len(s)
        
        # 计算各位数字的 k 次幂之和
        total = 0
        temp = n
        while temp > 0:
            digit = temp % 10
            total += digit ** k
            temp //= 10
        
        return total == n
```

## 复杂度分析

### 所有方法

- **时间复杂度**：O(log n)，n 的位数是 log₁₀(n)，需要遍历每一位
- **空间复杂度**：
  - 方法一、四：O(log n)，字符串存储
  - 方法二、五：O(1)
  - 方法三：O(log n)，列表存储

## 关键点总结

1. **阿姆斯特朗数定义**：k 位数的每个位的 k 次幂之和等于自身
2. **字符串转换技巧**：`str(n)` 可以方便地获取位数和各位数字
3. **取模运算**：`n % 10` 获取个位数，`n //= 10` 去掉个位数
4. **幂运算**：Python 的 `**` 运算符或 `pow()` 函数
5. **生成器表达式**：使用 `sum(... for ... in ...)` 简洁地计算总和

## 易错点

1. **位数计算**：必须先计算位数 k，不能在循环中重复计算
2. **原值保存**：如果用数学方法，需要先保存原始值
3. **边界情况**：单位数（1-9）也是阿姆斯特朗数（1^1 = 1, 2^1 = 2, ...）
4. **整数除法**：Python 3 中使用 `//` 进行整数除法，而非 `/`
5. **字符串遍历**：`for digit in str(n)` 中的 `digit` 是字符串，需要 `int(digit)` 转换

1. **掌握数字拆分技巧**：
