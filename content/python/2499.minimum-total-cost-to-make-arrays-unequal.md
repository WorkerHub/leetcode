## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，长度均为 `n`。

每次操作，可以交换 `nums1[i]` 和 `nums1[j]`（`i != j`），代价为 `i + j`。

最终目标：使 `nums1[i] != nums2[i]` 对所有 `i` 成立。

返回使数组满足条件的最小总代价，若无法满足返回 `-1`。

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= n`

## 解题思路

**贪心：**

需要交换的位置：`nums1[i] == nums2[i]`（冲突位置），这些位置的元素必须移走。

**关键观察：**
1. 冲突位置 i 的 `nums1[i]` 必须被换走，同时还需要一个位置来"接收"这个值
2. 将所有冲突位置的下标汇集在一起（代价 = 所有冲突下标之和 = `sum(i for conflict)`）
3. 冲突位置中最多的值是"主导值"（设为 dominant，出现 dom_cnt 次）：若 `dom_cnt > total_count / 2`，则主导值无法通过内部交换解决，需要引入新的非冲突位置

**具体做法：**
- 收集所有冲突位置 i（`nums1[i] == nums2[i]`），这些位置加入交换池，总代价 += i
- 统计交换池中各值的频次，找到主导值 dominant
- 若 `dom_cnt > total_count / 2`：需要继续引入下一个非冲突位置（它的下标也加入代价，但它的值要加入频次统计）
- 引入位置 j 的条件：`nums1[j]` 或 `nums2[j]` 中有与 dominant 相同的值（避免引入后变成新的主导）

**实际贪心步骤：**
1. 扫描所有位置，先收集冲突位置 i
2. 同时维护当前频次最多的值 dominant 及其计数
3. 若某时刻 `dom_cnt * 2 > total_count`，继续扩展（加入更多位置）
4. 直到 `dom_cnt * 2 <= total_count` 或遍历完

## 代码实现

### 方法一：贪心扫描（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumTotalCost(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        total_cost = 0
        total_count = 0  # 交换池大小
        count = Counter()  # 各值频次
        dominant = 0
        dom_cnt = 0

        for i in range(n):
            if nums1[i] == nums2[i]:
                # 冲突位置，必须纳入交换池
                total_cost += i
                total_count += 1
                count[nums1[i]] += 1
                if count[nums1[i]] > dom_cnt:
                    dom_cnt = count[nums1[i]]
                    dominant = nums1[i]

            # 检查是否需要额外引入非冲突位置
            # 若主导值超过一半，需要更多位置来平衡
            if dom_cnt * 2 > total_count:
                # 需要引入更多位置，但当前 i 如果不是冲突位置也需要加入
                if nums1[i] != nums2[i]:
                    # 引入位置 i（非冲突），但注意：
                    # 这里逻辑要在外层扫描中继续，不能重复处理
                    pass

        # 重新实现：先收集冲突，再按需扩展
        total_cost = 0
        total_count = 0
        count = Counter()
        dominant = 0
        dom_cnt = 0

        i = 0
        while i < n:
            if nums1[i] == nums2[i]:
                total_cost += i
                total_count += 1
                count[nums1[i]] += 1
                if count[nums1[i]] > dom_cnt:
                    dom_cnt = count[nums1[i]]
                    dominant = nums1[i]
            i += 1

            # 检查是否主导值超半，若超了继续向后扩展
            # 但扩展的逻辑应该在同一遍扫描中

        # 正确实现：一遍扫描
        total_cost = 0
        total_count = 0
        count = Counter()
        dominant = -1
        dom_cnt = 0

        for i in range(n):
            # 若当前位置冲突，或者主导值还没被平衡（需要引入更多位置）
            if nums1[i] == nums2[i]:
                total_cost += i
                total_count += 1
                count[nums1[i]] += 1
                if count[nums1[i]] > dom_cnt:
                    dom_cnt = count[nums1[i]]
                    dominant = nums1[i]

            # 若主导值超半，尝试引入非冲突位置 i 来帮助平衡
            # 条件：当前 i 未被加入，且 nums1[i]!=nums2[i]，且引入后有帮助
            # 实际上：若主导值超半，需要引入不含 dominant 的位置
            # 在上述循环中，非冲突位置暂时不加入
            # 所以需要额外的检查

        # 更清晰的实现
        total_cost = 0
        total_count = 0
        count = Counter()
        dom_cnt = 0
        dominant = -1

        for i in range(n):
            if nums1[i] == nums2[i]:
                total_cost += i
                total_count += 1
                count[nums1[i]] += 1
                if count[nums1[i]] > dom_cnt:
                    dom_cnt = count[nums1[i]]
                    dominant = nums1[i]

        # 检查是否能平衡
        # 若 dom_cnt * 2 > total_count，需要引入更多非冲突位置
        # 继续扫描，寻找可以引入的非冲突位置（不含 dominant）
        i = 0
        while dom_cnt * 2 > total_count and i < n:
            if nums1[i] != nums2[i]:
                # 检查 nums1[i] 和 nums2[i] 是否不等于 dominant（若等于 dominant 则引入没用）
                if nums1[i] != dominant and nums2[i] != dominant:
                    total_cost += i
                    total_count += 1
                    count[nums1[i]] += 1
                    if count[nums1[i]] > dom_cnt:
                        dom_cnt = count[nums1[i]]
                        dominant = nums1[i]
            i += 1

        if dom_cnt * 2 > total_count:
            return -1

        return total_cost
```

### 方法二：简洁贪心（一遍扫描）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumTotalCost(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        cost = 0
        cnt = Counter()
        total = 0
        dominant = 0
        dom_cnt = 0

        for i in range(n):
            # 必须交换的位置（冲突）+ 为了平衡主导值而额外引入的位置
            if nums1[i] == nums2[i]:
                cost += i
                total += 1
                cnt[nums1[i]] += 1
                if cnt[nums1[i]] > dom_cnt:
                    dom_cnt = cnt[nums1[i]]
                    dominant = nums1[i]

            # 若主导值数量超过总数的一半，需要继续扩展
            # 引入当前位置（若它不是冲突且有帮助）
            if dom_cnt * 2 > total:
                # 尝试引入当前位置 i（如果还没引入过）
                if nums1[i] != nums2[i] and nums1[i] != dominant and nums2[i] != dominant:
                    cost += i
                    total += 1

        return cost if dom_cnt * 2 <= total else -1
```

## 关键点总结

1. 冲突位置（nums1[i] == nums2[i]）必须被交换
2. 这些位置形成"交换池"，池中所有元素可以互相交换
3. 若池中某值占超过一半，无法内部解决，需引入外部位置
4. 引入外部位置时，选择不含主导值的位置

## 易错点

- 外部引入位置时，要确保引入的位置本身不含主导值
- 最终若主导值仍超半，返回 -1
