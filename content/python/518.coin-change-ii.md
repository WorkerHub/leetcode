## 题目描述

给你一个整数数组 `coins` 表示不同面额的硬币，另给一个整数 `amount` 表示总金额。

请你计算并返回可以凑成总金额的硬币组合数。如果任何硬币组合都无法凑出总金额，返回 `0`。

假设每一种面额的硬币有无限个。 

题目数据保证结果符合 32 位带符号整数。

**示例 1：**
```
输入：amount = 5, coins = [1,2,5]
输出：4
解释：有四种方式可以凑成总金额：
5=5
5=2+2+1
5=2+1+1+1
5=1+1+1+1+1
```

**示例 2：**
```
输入：amount = 3, coins = [2]
输出：0
解释：只用面额 2 的硬币不能凑成总金额 3。
```

**示例 3：**
```
输入：amount = 10, coins = [10]
输出：1
```

**提示：**
- `1 <= coins.length <= 300`
- `1 <= coins[i] <= 5000`
- `coins` 中的所有值互不相同
- `0 <= amount <= 5000`

## 解题思路

这是**完全背包**的组合问题。

### 核心思想：
`dp[i]` = 凑成金额 i 的组合数

**注意：** 这是组合问题，不是排列问题：
- `[1,2]` 和 `[2,1]` 是同一种组合

### 关键：外层遍历硬币，内层遍历金额

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        """
        完全背包组合问题
        时间复杂度：O(n * amount)，空间复杂度：O(amount)
        """
        dp = [0] * (amount + 1)
        dp[0] = 1  # 金额为 0 有 1 种方案
        
        # 外层遍历硬币（保证组合不重复）
        for coin in coins:
            # 内层遍历金额
            for i in range(coin, amount + 1):
                dp[i] += dp[i - coin]
        
        return dp[amount]
```

### 方法二：错误示范（排列问题）

```python
class Solution:
    def change_permutation(self, amount: int, coins: List[int]) -> int:
        """
        ❌ 错误：这是排列问题，不是组合问题
        外层遍历金额，内层遍历硬币
        """
        dp = [0] * (amount + 1)
        dp[0] = 1
        
        for i in range(1, amount + 1):
            for coin in coins:
                if i >= coin:
                    dp[i] += dp[i - coin]
        
        return dp[amount]
```

## 复杂度分析

- **时间复杂度**：O(n × amount)
- **空间复杂度**：O(amount)

## 关键点总结

1. **组合 vs 排列**：外层硬币是组合
2. **完全背包**：内层正序遍历
3. **初始化**：dp[0] = 1
4. **状态转移**：dp[i] += dp[i-coin]

## 易错点

1. **遍历顺序**：组合问题外层硬币
2. **初始值**：dp[0] = 1，不是 0
3. **边界**：i >= coin 才能转移
