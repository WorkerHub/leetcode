## 题目描述

给定一棵 N 叉树的根节点 `root`，计算树的直径长度。

N 叉树的直径是树中任意两个节点之间最长路径的**边数**。该路径可能经过根节点，也可能不经过根节点。

**示例 1：**
树结构：1 -> [3,2,4]，3 -> [5,6]
输出：3（路径 5-3-1-2 或 6-3-1-2 或 5-3-1-4 等，长度为3）

**提示：**
- 树的节点数在 `[1, 10^4]` 之间
- `1 <= Node.val <= 10^4`

## 解题思路

### DFS 后序遍历

对每个节点，维护从该节点出发的最长路径（向下延伸的最大深度）。

**关键：** 对于每个节点 `u`，经过 `u` 的最长路径 = 其所有子节点中最长的两条路径之和（若子节点数量 >= 2）或最长的一条路径（若只有一个子节点）。

**直径更新：** 对每个节点，用最长的两个子路径之和更新全局答案。

## 代码实现

### 方法一：DFS 返回最大深度（推荐）

```python
class Solution:
    def diameter(self, root: 'Node') -> int:
        self.ans = 0

        def dfs(node: 'Node') -> int:
            if not node:
                return 0
            # 获取所有子节点的最大深度
            depths = sorted([dfs(child) for child in node.children], reverse=True)

            # 更新直径：最长两条路径之和（至少取前两大值）
            if len(depths) >= 2:
                self.ans = max(self.ans, depths[0] + depths[1])
            elif len(depths) == 1:
                self.ans = max(self.ans, depths[0])

            # 返回该节点能延伸的最长路径
            return (depths[0] + 1) if depths else 0

        dfs(root)
        return self.ans
```

### 方法二：DFS 不使用 sort（更高效）

```python
class Solution:
    def diameter(self, root: 'Node') -> int:
        self.ans = 0

        def dfs(node: 'Node') -> int:
            # 找最长和次长子路径
            max1 = max2 = 0
            for child in node.children:
                d = dfs(child) + 1  # 子节点到该节点的距离
                if d > max1:
                    max2 = max1
                    max1 = d
                elif d > max2:
                    max2 = d
            # 更新直径
            self.ans = max(self.ans, max1 + max2)
            return max1  # 返回当前节点能延伸的最长路径

        dfs(root)
        return self.ans
```

### 方法三：使用 heapq.nlargest

```python
import heapq

class Solution:
    def diameter(self, root: 'Node') -> int:
        self.ans = 0

        def dfs(node: 'Node') -> int:
            child_depths = [dfs(c) + 1 for c in node.children]
            # 取最大的两个值
            top2 = heapq.nlargest(2, child_depths)
            self.ans = max(self.ans, sum(top2))
            return top2[0] if top2 else 0

        dfs(root)
        return self.ans
```

## 复杂度分析

- **时间复杂度**：O(N)，每个节点访问一次
- **空间复杂度**：O(H)，H 为树的高度，递归栈深度

## 关键点总结

1. 树的直径 = 每个节点处，最长和次长子路径之和的最大值
2. DFS 返回的是"从当前节点出发能向下走的最长路径长度"
3. 对每个节点维护最长和次长两个值，O(N) 即可完成

## 易错点

- 路径长度是**边数**，不是节点数。`dfs(child)` 返回的是边数，加 1 表示加上当前节点到子节点的边
- 单个子节点时不能把该路径计两次（直径是两条不同子路径之和）
