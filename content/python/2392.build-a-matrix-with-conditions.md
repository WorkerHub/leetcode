## 题目描述

给你一个正整数 `k`，和两个非负整数数组 `rowConditions` 和 `colConditions`，其中 `rowConditions[i] = [above_i, below_i]`，`colConditions[j] = [left_j, right_j]`。

构造一个 `k x k` 矩阵，使得：
- 数字 `above_i` 所在行 **严格高于** `below_i` 所在行。
- 数字 `left_j` 所在列 **严格左于** `right_j` 所在列。
- 每个 `1 ~ k` 的数字恰好出现**一次**，其他位置为 `0`。

若存在这样的矩阵，返回它；否则返回空矩阵。

**示例 1：**
```
输入：k = 3, rowConditions = [[1,2],[3,2]], colConditions = [[2,1],[3,2]]
输出：[[3,0,0],[0,0,1],[0,2,0]]
```

**提示：**
- `2 <= k <= 400`
- `1 <= rowConditions.length, colConditions.length <= 10^4`
- `rowConditions[i].length == colConditions[j].length == 2`
- `1 <= above_i, below_i, left_j, right_j <= k`

## 解题思路

**拓扑排序：**

1. 对行约束做拓扑排序，得到数字 `1~k` 的行顺序（若有环则无解）。
2. 对列约束做拓扑排序，得到数字 `1~k` 的列顺序（若有环则无解）。
3. 根据两个顺序，将数字填入矩阵。

## 代码实现

### 方法一：Kahn 算法（BFS 拓扑排序，推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def buildMatrix(self, k: int, rowConditions: List[List[int]],
                    colConditions: List[List[int]]) -> List[List[int]]:
        
        def topo_sort(conditions):
            """Kahn 算法拓扑排序，返回排列顺序（1~k），有环则返回 None"""
            graph = defaultdict(list)
            in_degree = [0] * (k + 1)
            
            for u, v in conditions:
                graph[u].append(v)
                in_degree[v] += 1
            
            # 入度为 0 的节点入队
            queue = deque(i for i in range(1, k + 1) if in_degree[i] == 0)
            order = []
            
            while queue:
                node = queue.popleft()
                order.append(node)
                for neighbor in graph[node]:
                    in_degree[neighbor] -= 1
                    if in_degree[neighbor] == 0:
                        queue.append(neighbor)
            
            return order if len(order) == k else None
        
        # 分别对行和列做拓扑排序
        row_order = topo_sort(rowConditions)
        col_order = topo_sort(colConditions)
        
        if row_order is None or col_order is None:
            return []
        
        # 构建矩阵
        matrix = [[0] * k for _ in range(k)]
        
        # 记录每个数字的行号和列号
        row_pos = {num: i for i, num in enumerate(row_order)}
        col_pos = {num: j for j, num in enumerate(col_order)}
        
        for num in range(1, k + 1):
            r = row_pos[num]
            c = col_pos[num]
            matrix[r][c] = num
        
        return matrix
```

### 方法二：DFS 拓扑排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def buildMatrix(self, k: int, rowConditions: List[List[int]],
                    colConditions: List[List[int]]) -> List[List[int]]:
        
        def topo_dfs(conditions):
            """DFS 拓扑排序，返回逆序列表，有环返回 None"""
            graph = defaultdict(list)
            for u, v in conditions:
                graph[u].append(v)
            
            visited = [0] * (k + 1)  # 0:未访问, 1:访问中, 2:已完成
            order = []
            has_cycle = [False]
            
            def dfs(node):
                if has_cycle[0]:
                    return
                visited[node] = 1
                for neighbor in graph[node]:
                    if visited[neighbor] == 1:
                        has_cycle[0] = True
                        return
                    if visited[neighbor] == 0:
                        dfs(neighbor)
                visited[node] = 2
                order.append(node)
            
            for i in range(1, k + 1):
                if visited[i] == 0:
                    dfs(i)
            
            return None if has_cycle[0] else order[::-1]
        
        row_order = topo_dfs(rowConditions)
        col_order = topo_dfs(colConditions)
        
        if row_order is None or col_order is None:
            return []
        
        matrix = [[0] * k for _ in range(k)]
        row_pos = {num: i for i, num in enumerate(row_order)}
        col_pos = {num: j for j, num in enumerate(col_order)}
        
        for num in range(1, k + 1):
            matrix[row_pos[num]][col_pos[num]] = num
        
        return matrix
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Kahn BFS | O(k + n) | O(k + n) |
| DFS | O(k + n) | O(k + n) |

其中 n 为约束条件数量。

## 关键点总结

1. 行约束和列约束可以**独立**做拓扑排序，互不干扰。
2. 有环则无解（约束矛盾）；无环则拓扑序即为对应维度的排列顺序。
3. 构建矩阵时：`matrix[row_pos[num]][col_pos[num]] = num`。

## 易错点

- DFS 检测环：需要区分"访问中"（灰色）和"已完成"（黑色）。
- Kahn 算法验证：排序后的长度必须等于 k，否则有环。
- 行顺序和列顺序是数字 `1~k` 的排列，不是下标。
