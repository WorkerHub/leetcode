## 题目描述

如果二叉树每个节点都具有相同的值，那么该二叉树就是**单值**二叉树。

只有给定的树是单值二叉树时，才返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：[1,1,1,1,1,null,1]
输出：true
```

**示例 2：**
```
输入：[2,2,2,5,2]
输出：false
```

**提示：**
- 给定树的节点数范围是 `[1, 100]`
- `0 <= Node.val < 100`

## 解题思路

判断二叉树是否所有节点值都相同，是一道简单的树遍历题。

**核心思想：**
1. 遍历整棵树，检查每个节点的值是否与根节点相同
2. 可以使用 DFS、BFS 或递归等多种方法
3. 一旦发现不同的值，立即返回 False

## Python 代码实现

### 方法一：递归 DFS（推荐）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        def dfs(node, val):
            """检查以 node 为根的子树是否所有值都等于 val"""
            if not node:
                return True
            
            # 如果当前节点值不等于目标值，返回 False
            if node.val != val:
                return False
            
            # 递归检查左右子树
            return dfs(node.left, val) and dfs(node.right, val)
        
        return dfs(root, root.val)
```

### 方法二：递归（简化版）

```python
class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        def dfs(node):
            if not node:
                return True
            
            # 检查左子节点
            if node.left and node.left.val != root.val:
                return False
            
            # 检查右子节点
            if node.right and node.right.val != root.val:
                return False
            
            # 递归检查左右子树
            return dfs(node.left) and dfs(node.right)
        
        return dfs(root)
```

### 方法三：BFS（层序遍历）

```python
from collections import deque

class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        target_val = root.val
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            
            # 检查当前节点值
            if node.val != target_val:
                return False
            
            # 将子节点加入队列
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        return True
```

### 方法四：迭代 DFS（栈）

```python
class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        target_val = root.val
        stack = [root]
        
        while stack:
            node = stack.pop()
            
            if node.val != target_val:
                return False
            
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        
        return True
```

### 方法五：一行解法（列表推导）

```python
class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        def get_all_vals(node):
            """获取树中所有节点的值"""
            if not node:
                return []
            return [node.val] + get_all_vals(node.left) + get_all_vals(node.right)
        
        vals = get_all_vals(root)
        return len(set(vals)) == 1
```

### 方法六：优雅的递归

```python
class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        # 空节点视为单值树
        if not root:
            return True
        
        # 检查左子节点（如果存在）
        left_ok = not root.left or (root.left.val == root.val and self.isUnivalTree(root.left))
        
        # 检查右子节点（如果存在）
        right_ok = not root.right or (root.right.val == root.val and self.isUnivalTree(root.right))
        
        return left_ok and right_ok
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n)，需要访问树中的每个节点
- **空间复杂度**：
  - 递归：O(h)，h 是树的高度，最坏 O(n)
  - 迭代：O(w)，w 是树的最大宽度，最坏 O(n)

## 关键点总结

1. **遍历方式**：DFS、BFS、递归都可以解决
2. **早停优化**：发现不同值立即返回，无需遍历完整棵树
3. **空节点处理**：空节点不影响单值性质
4. **比较对象**：所有节点与根节点比较即可
5. **代码简洁性**：Python 可以用很简洁的方式实现

## 易错点

1. **空树处理**：空树应该返回 True
2. **空节点检查**：访问子节点前要先判空
3. **逻辑运算**：要用 `and`，不是 `or`
4. **过度优化**：题目很简单，不要写得过于复杂
5. **递归边界**：空节点的处理要正确
