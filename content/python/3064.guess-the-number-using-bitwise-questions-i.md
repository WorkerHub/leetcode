## 题目描述

这是一道**交互题**。

有一个隐藏的正整数 `n`（1 <= n <= 2^30 - 1）。

你可以调用 `commonSetBits(num)` 函数，它返回 `num` 和隐藏数 `n` 的**按位与** 的置位数（即 `bin(num & n).count('1')`）。

你最多可以调用 30 次。

返回隐藏的整数 `n`。

**提示：**
- `1 <= n <= 2^30 - 1`

## 解题思路

逐位确定 `n` 的每一位：
- 对于第 `i` 位（0-indexed），调用 `commonSetBits(1 << i)`
- 若返回值 >= 1，说明 `n` 的第 `i` 位为 1；否则为 0

最多 30 次调用，恰好覆盖 30 位。

## Python 代码实现

### 方法一：逐位询问（推荐）

```python
# 接口定义（LeetCode 提供）
def commonSetBits(num: int) -> int:
    pass

class Solution:
    def findNumber(self) -> int:
        n = 0
        for i in range(30):
            if commonSetBits(1 << i) > 0:
                n |= (1 << i)
        return n
```

### 方法二：等价写法

```python
class Solution:
    def findNumber(self) -> int:
        result = 0
        for bit in range(30):
            # 询问第 bit 位
            mask = 1 << bit
            if commonSetBits(mask) == 1:
                # n 的第 bit 位为 1
                result |= mask
        return result
```

## 复杂度分析

- 时间复杂度：O(30) = O(1)，恰好 30 次询问
- 空间复杂度：O(1)

## 关键点总结

1. 每次只询问一个位（2 的幂次方），独立确定每一位
2. `commonSetBits(1 << i)` 的结果只有 0 或 1
3. 30 次询问完全确定 n 的值

## 易错点

1. 注意 n 的范围：1 到 2^30 - 1，需要询问 0 到 29 位（共 30 位）
2. 每次询问用 `1 << i`（只有一位为 1），结果只可能是 0 或 1
