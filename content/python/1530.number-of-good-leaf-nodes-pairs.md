## 题目描述

给你二叉树的根节点 `root` 和一个整数 `distance`。

如果二叉树中两个叶节点之间的 **最短路径长度** 小于或等于 `distance`，那么它们就可以构成一组**好叶子节点对**。

返回树中**好叶子节点对的数目**。

**示例 1：**
```
输入：root = [1,2,3,null,4], distance = 3
输出：1
解释：叶节点 4 和 3 之间的最短路径为 3 个节点，路径长度为 2 条边，满足 distance = 3
```

**示例 2：**
```
输入：root = [1,2,3,4,5,6,7], distance = 3
输出：2
```

**提示：**
- `1 <= distance <= 10`
- 树中节点数在 `[1, 2^10]` 范围内

## 解题思路

### DFS 后序遍历 + 距离统计

对每个节点，DFS 返回从该节点出发到各个叶子节点的距离列表。

对每个内部节点，将左右子树返回的叶子距离列表两两比较，若两距离之和 `<= distance`，则计入答案。

**关键：** 叶子节点返回 `[0]`（距离为 0），向上传递时每个距离加 1。

## 代码实现

### 方法一：DFS 返回距离列表（推荐）

```python
from typing import Optional, List

class Solution:
    def countPairs(self, root: Optional['TreeNode'], distance: int) -> int:
        self.ans = 0

        def dfs(node: Optional['TreeNode']) -> List[int]:
            if not node:
                return []
            if not node.left and not node.right:
                return [1]  # 叶子节点，到父节点距离为 1

            left_dists = dfs(node.left)
            right_dists = dfs(node.right)

            # 左右叶子两两配对，检查距离之和是否 <= distance
            for l in left_dists:
                for r in right_dists:
                    if l + r <= distance:
                        self.ans += 1

            # 返回当前节点的所有叶子距离（各加 1）
            return [d + 1 for d in left_dists + right_dists]

        dfs(root)
        return self.ans
```

### 方法二：返回频次数组（减少枚举开销）

```python
from typing import Optional, List

class Solution:
    def countPairs(self, root: Optional['TreeNode'], distance: int) -> int:
        self.ans = 0

        def dfs(node: Optional['TreeNode']) -> List[int]:
            # 返回长度为 distance+1 的数组，count[d] = 到叶子距离为 d 的叶子数
            if not node:
                return [0] * (distance + 1)
            if not node.left and not node.right:
                # 叶子节点：到自身距离为 0
                res = [0] * (distance + 1)
                res[0] = 1
                return res

            left = dfs(node.left)
            right = dfs(node.right)

            # 配对：左边距离 i，右边距离 j，经过当前节点路径长度 = i+1 + j+1 = i+j+2
            for i in range(distance + 1):
                for j in range(distance + 1):
                    if i + j + 2 <= distance:
                        self.ans += left[i] * right[j]

            # 向上传递：所有距离加 1
            res = [0] * (distance + 1)
            for d in range(distance):
                res[d + 1] = left[d] + right[d]
            return res

        dfs(root)
        return self.ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N * distance^2) | O(N * distance) |
| 方法二 | O(N * distance^2) | O(N * distance) |

由于 `distance <= 10`，实际非常高效。

## 关键点总结

1. DFS 返回当前子树各叶子到当前节点的距离列表
2. 对每个内部节点，两两配对左右子树的叶子距离
3. 叶子节点经过当前节点的路径长度 = 左距离 + 右距离（注意是否+1）

## 易错点

- 方法一中叶子返回 `[1]` 表示到父节点距离为 1（不是到自身为 0）
- 方法二中需要精确处理"到自身为 0"和向上传递时加 1 的逻辑
