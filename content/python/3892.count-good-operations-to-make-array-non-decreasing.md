## 题目描述

给你一个整数数组 `nums`，统计有多少个下标 `i`（0-indexed），使得将 `nums[i]` 替换为 `nums[i] + 1` 后数组仍然是非递减序列。

**示例 1：**

```
输入：nums = [1, 2, 3]
输出：3
解释：
- 将 nums[0]=1 改为 2：[2,2,3]，非递减，合法。
- 将 nums[1]=2 改为 3：[1,3,3]，非递减，合法。
- 将 nums[2]=3 改为 4：[1,2,4]，非递减，合法。
共 3 个。
```

**示例 2：**

```
输入：nums = [3, 2, 1]
输出：0
解释：数组已递减，任何加 1 操作都不能使其非递减。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对每个位置 i，将 `nums[i] + 1` 替换后检查数组是否仍然非递减：
1. 需要 `nums[i] + 1 >= nums[i-1]`（若 i > 0，前一个元素约束）。
2. 需要 `nums[i] + 1 <= nums[i+1]`（若 i < n-1，后一个元素约束）。

条件合并：`nums[i-1] <= nums[i] + 1 <= nums[i+1]`

## Python 代码实现

### 方法一：逐个检查（推荐）

```python
from typing import List

class Solution:
    def countGoodOperations(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0

        for i in range(n):
            new_val = nums[i] + 1

            # 检查前一个元素约束
            ok_left = (i == 0 or nums[i - 1] <= new_val)
            # 检查后一个元素约束
            ok_right = (i == n - 1 or new_val <= nums[i + 1])

            if ok_left and ok_right:
                count += 1

        return count
```

### 方法二：直接条件检查

```python
from typing import List

class Solution:
    def countGoodOperations(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0

        for i in range(n):
            # 修改 nums[i] 为 nums[i]+1 后，检查整个数组是否仍非递减
            # 只影响 nums[i-1] <= nums[i]+1 和 nums[i]+1 <= nums[i+1] 这两个关系
            left_ok = i == 0 or nums[i - 1] <= nums[i] + 1
            right_ok = i == n - 1 or nums[i] + 1 <= nums[i + 1]

            if left_ok and right_ok:
                count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个操作只影响与相邻元素的大小关系，无需重新检查整个数组。
2. 条件 1：修改后的值 >= 左邻；条件 2：修改后的值 <= 右邻。
3. 边界处理：首元素无左邻约束，末元素无右邻约束。

## 易错点

1. 两个条件必须同时满足，不是任意一个。
2. 边界情况：i = 0 或 i = n-1 时只有一个方向的约束。
