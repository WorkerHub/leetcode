## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。每次操作，你需要选择数组中的最大元素，删除它，并将 `max + 1` 插入数组。执行 `k` 次操作后，返回数组中所有元素的总和。

**示例 1：**
```
输入：nums = [1,2,3,4,5], k = 3
输出：18
解释：
第1次操作：取最大5，插入6，得分+5，数组[1,2,3,4,6]
第2次操作：取最大6，插入7，得分+6，数组[1,2,3,4,7]
第3次操作：取最大7，插入8，得分+7，数组[1,2,3,4,8]
总和 = (1+2+3+4) + (5+6+7) = 10 + 18 = 28？
wait，题目说返回执行k次操作后数组中所有元素的总和
原数组总和 = 15，每次操作相当于给数组总和 +1
所以结果 = 15 - 5 + (5+6+7) = 10 + 18 = 28
```

**示例 2：**
```
输入：nums = [5,5,5], k = 3
输出：31
```

**数据范围：**
- 1 <= nums.length <= 100
- 1 <= nums[i] <= 100
- 1 <= k <= 100

## 解题思路

每次取最大值 `m`，加入 `m`，然后插入 `m+1`。总和变化为 `+1`（删掉 m 加入 m+1）。

所以最终总和 = 原总和 + k * (原始最大值 + (k-1)/2 ... ) = 原总和 - max + sum(max, max+1, ..., max+k-1)

更直接地：k 次操作后，取走的值为 max, max+1, ..., max+k-1，每次操作总和 +1。最终总和 = sum(nums) + k（每次+1，共k次）... 不对，让我重新推导。

原总和 S，取走最大值 m，插入 m+1，总和变为 S - m + (m+1) = S + 1。
所以每次操作总和 +1。k 次操作后总和 = S + k。

但要注意每次都取当前最大值，需要确认每次最大值是递增的（第一次取 m，第二次取 m+1，...）。

若原数组最大值为 m，则 k 次操作后总和 = sum(nums) + k ... 等等，但如果 m+1 仍然是最大值（比其他元素大），那就是这种情况。

实际上，最终结果 = sum(nums) - m + (m + m+1 + ... + m+k-1) = sum(nums) - m + k*m + k*(k-1)/2 = sum(nums) + (k-1)*m + k*(k-1)/2

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def maximizeSum(self, nums: List[int], k: int) -> int:
        m = max(nums)
        # 每次取最大值并 +1，k 次后的增量
        # 第 i 次取 m+i-1（i 从 1 到 k），总增量 = sum(m..m+k-1) - m
        # 最终总和 = sum(nums) - m + sum(m..m+k-1)
        total = sum(nums) - m
        for i in range(k):
            total += m + i  # 第 i 次操作取走并加入 m+i
        return total
```

### 方法二：数学公式

```python
from typing import List

class Solution:
    def maximizeSum(self, nums: List[int], k: int) -> int:
        m = max(nums)
        # sum(m, m+1, ..., m+k-1) = k*m + k*(k-1)//2
        return sum(nums) - m + k * m + k * (k - 1) // 2
```

## 复杂度分析

- 时间复杂度：O(n)，找最大值和求和
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作取最大值 m，下次最大值变为 m+1
2. k 次操作取走的值为 m, m+1, ..., m+k-1
3. 最终总和 = 原总和 - m + sum(m..m+k-1)

## 易错点

1. 注意最终总和包含未被取走的元素
2. 每次取走最大值并插入 max+1，因此序列单调递增
