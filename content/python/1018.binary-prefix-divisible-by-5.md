## 题目描述

给定一个二进制数组 `nums`（索引从0开始）。

我们将 `nums[0..i]` 视为一个二进制数，从最高有效位到最低有效位。

例如，如果 `nums = [1,0,1]`，则 `nums[0..0]` 是 `1`，`nums[0..1]` 是 `10`（二进制），`nums[0..2]` 是 `101`（二进制）。

返回布尔值列表 `answer`，只有当 `nums[0..i]` 表示的数字可以被 `5` 整除时，才为 `answer[i] = true`，否则为 `false`。

**示例 1：**
```
输入：nums = [0,1,1]
输出：[true,false,false]
解释：
输入数字为 0, 01, 011，分别对应十进制的 0, 1, 3。
只有第一个数可以被 5 整除，所以 answer[0] 为 true。
```

**示例 2：**
```
输入：nums = [1,1,1]
输出：[false,false,false]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i]` 只能是 `0` 或 `1`

## 解题思路

**核心观察**：
1. 二进制转十进制：每次左移一位加上新的位
2. `num = num * 2 + nums[i]`
3. 只需判断是否能被5整除，不需要完整的数值
4. 使用取模运算防止溢出

**关键技巧**：
- 只保留 `num % 5` 的余数即可
- `(num * 2 + bit) % 5 = ((num % 5) * 2 + bit) % 5`

## Python 代码实现

### 方法一：取模运算（推荐）⭐

```python
from typing import List

class Solution:
    def prefixesDivBy5(self, nums: List[int]) -> List[bool]:
        """
        使用取模运算避免大数溢出
        时间复杂度：O(n)
        空间复杂度：O(1) 不算输出数组
        """
        result = []
        num = 0
        
        for bit in nums:
            # 左移一位（乘以2）并加上当前位
            num = (num * 2 + bit) % 5
            
            # 判断是否能被5整除
            result.append(num == 0)
        
        return result
```

### 方法二：位运算优化

```python
class Solution:
    def prefixesDivBy5(self, nums: List[int]) -> List[bool]:
        """
        使用位运算代替乘法
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        result = []
        num = 0
        
        for bit in nums:
            # num * 2 等价于 num << 1
            num = ((num << 1) | bit) % 5
            result.append(num == 0)
        
        return result
```

### 方法三：详细注释版

```python
class Solution:
    def prefixesDivBy5(self, nums: List[int]) -> List[bool]:
        """
        逐位构建二进制数并判断能否被5整除
        
        原理：
        - 二进制转十进制：num = num * 2 + bit
        - 取模性质：(a + b) % m = ((a % m) + (b % m)) % m
        - 只需维护 num % 5 即可
        """
        answer = []
        remainder = 0  # 当前数对5的余数
        
        for bit in nums:
            # 更新余数
            # (remainder * 2 + bit) % 5
            remainder = (remainder * 2 + bit) % 5
            
            # 余数为0表示能被5整除
            answer.append(remainder == 0)
        
        return answer
```

### 方法四：列表推导式（简洁版）

```python
class Solution:
    def prefixesDivBy5(self, nums: List[int]) -> List[bool]:
        """
        使用列表推导式的简洁写法
        """
        result = []
        num = 0
        
        for bit in nums:
            num = num * 2 + bit
            result.append(num % 5 == 0)
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)，不算输出数组

## 图解示例

以 `nums = [0,1,1]` 为例：

```
索引0：bit=0
  num = (0 * 2 + 0) % 5 = 0
  0 % 5 == 0 → true

索引1：bit=1  
  num = (0 * 2 + 1) % 5 = 1
  1 % 5 != 0 → false

索引2：bit=1
  num = (1 * 2 + 1) % 5 = 3
  3 % 5 != 0 → false

结果：[true, false, false]

二进制表示：
0 → 十进制0 → 0%5=0 ✓
01 → 十进制1 → 1%5=1 ✗
011 → 十进制3 → 3%5=3 ✗
```

## 关键点总结

1. **二进制转十进制**：`num = num * 2 + bit`
2. **取模性质**：只保留余数，避免溢出
3. **位运算优化**：`num * 2` 可用 `num << 1` 代替
4. **空间优化**：不需要存储完整的数字
5. **边界处理**：从0开始累加

## 易错点

1. **大数溢出**：数组长度可达10^5，不取模会溢出
2. **初始值**：num初始为0，不是1
3. **判断条件**：是 `num % 5 == 0`，不是 `num == 5`
4. **取模时机**：每次计算后立即取模
5. **位运算顺序**：先左移再或运算
