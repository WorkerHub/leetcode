## 题目描述

给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**示例 1：**

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

```
    3
   / \
  1   4
   \
    2
```

**示例 2：**

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

```
        5
       / \
      3   6
     / \
    2   4
   /
  1
```

**提示：**

- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶：** 如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

## 解题思路

这道题的关键是利用**二叉搜索树（BST）的性质**：中序遍历 BST 得到的序列是**升序**的。

### 核心思想

**中序遍历 BST，第 k 个访问的节点就是第 k 小的元素。**

中序遍历顺序：左 -> 根 -> 右

### 三种实现方式

1. **递归中序遍历**：完整遍历后取第 k 个
2. **迭代中序遍历**：边遍历边计数，找到第 k 个立即停止
3. **优化：提前终止**：递归时记录计数，找到后立即返回

## Python 代码实现

### 方法一：递归中序遍历（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        self.count = 0   # 当前访问的是第几个节点
        self.result = 0  # 结果
        
        def inorder(node):
            if not node:
                return
            
            # 遍历左子树
            inorder(node.left)
            
            # 访问当前节点
            self.count += 1
            if self.count == k:
                self.result = node.val
                return
            
            # 遍历右子树
            inorder(node.right)
        
        inorder(root)
        return self.result
```

### 方法二：迭代中序遍历（栈）

```python
from typing import Optional

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        stack = []
        node = root
        count = 0
        
        while stack or node:
            # 一直往左走，将左节点入栈
            while node:
                stack.append(node)
                node = node.left
            
            # 弹出栈顶节点（当前最小的未访问节点）
            node = stack.pop()
            count += 1
            
            # 如果是第 k 个节点，返回
            if count == k:
                return node.val
            
            # 转向右子树
            node = node.right
        
        return -1  # 不会到达这里
```

### 方法三：完整中序遍历后取第 k 个

```python
from typing import Optional, List

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        def inorder(node: Optional[TreeNode]) -> List[int]:
            """中序遍历，返回升序数组"""
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        # 获取完整的中序遍历序列
        sorted_vals = inorder(root)
        # 返回第 k 小的元素（索引 k-1）
        return sorted_vals[k - 1]
```

### 方法四：Morris 遍历（空间 O(1)）

```python
from typing import Optional

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        """Morris 中序遍历，不使用栈和递归"""
        count = 0
        current = root
        
        while current:
            if not current.left:
                # 左子树为空，访问当前节点
                count += 1
                if count == k:
                    return current.val
                current = current.right
            else:
                # 找到左子树的最右节点（前驱节点）
                predecessor = current.left
                while predecessor.right and predecessor.right != current:
                    predecessor = predecessor.right
                
                if not predecessor.right:
                    # 建立线索
                    predecessor.right = current
                    current = current.left
                else:
                    # 恢复树结构，访问当前节点
                    predecessor.right = None
                    count += 1
                    if count == k:
                        return current.val
                    current = current.right
        
        return -1
```

### 方法五：详细注释版（迭代）

```python
from typing import Optional

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        """
        查找二叉搜索树中第 k 小的元素
        
        核心思想：
        1. BST 的中序遍历是升序的
        2. 中序遍历的第 k 个节点就是第 k 小的元素
        3. 使用迭代 + 栈实现中序遍历
        """
        stack = []       # 栈：存储待访问的节点
        node = root      # 当前节点
        count = 0        # 已访问的节点数
        
        while stack or node:
            # 步骤1：一直往左走，将路径上的节点压栈
            while node:
                stack.append(node)
                node = node.left
            
            # 步骤2：弹出栈顶节点（当前最小的未访问节点）
            node = stack.pop()
            
            # 步骤3：访问节点（计数）
            count += 1
            if count == k:
                # 找到第 k 小的元素
                return node.val
            
            # 步骤4：转向右子树
            node = node.right
        
        return -1
```

## 复杂度分析

**方法一：递归中序遍历**
- 时间复杂度：O(k)，最好情况下访问 k 个节点就可以停止
- 空间复杂度：O(h)，递归栈深度为树的高度

**方法二：迭代中序遍历**
- 时间复杂度：O(k)，访问前 k 个节点
- 空间复杂度：O(h)，栈的深度为树的高度

**方法三：完整遍历**
- 时间复杂度：O(n)，需要遍历所有节点
- 空间复杂度：O(n)，需要存储所有节点的值

**方法四：Morris 遍历**
- 时间复杂度：O(k)，虽然每条边最多访问 2 次，但只访问前 k 个节点
- 空间复杂度：O(1)，不使用额外空间

## 图解示例

以示例 2 为例：

```
        5
       / \
      3   6
     / \
    2   4
   /
  1

中序遍历顺序：1 -> 2 -> 3 -> 4 -> 5 -> 6

k = 3，第 3 小的元素是 3

迭代过程：
1. 一路向左：5 -> 3 -> 2 -> 1，栈：[5, 3, 2, 1]
2. 弹出 1，count=1，转向右子树（null）
3. 弹出 2，count=2，转向右子树（null）
4. 弹出 3，count=3，找到！返回 3
```

## 关键点总结

1. **BST 性质**：中序遍历得到升序序列
2. **提前终止**：找到第 k 个节点后立即停止，不需要遍历整棵树
3. **中序遍历模板**：掌握递归和迭代两种实现
4. **空间优化**：Morris 遍历可以做到 O(1) 空间
5. **计数技巧**：使用变量记录已访问的节点数

## 易错点

1. **索引问题**：题目是从 1 开始计数，不是从 0
2. **遍历顺序**：必须是中序遍历（左-根-右），不能是前序或后序
3. **提前返回**：找到第 k 个节点后要立即返回，不要继续遍历
4. **空节点检查**：递归和迭代都要检查空节点
5. **栈的使用**：迭代时要正确使用栈模拟递归
