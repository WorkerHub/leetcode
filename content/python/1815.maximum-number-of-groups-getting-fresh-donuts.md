## 题目描述

给你一个整数 `batchSize` 和一个整数数组 `groups`，`groups[i]` 表示第 `i` 批顾客的人数。

烘焙师每次能烤 `batchSize` 个甜甜圈，每批顾客到来时，若剩余的甜甜圈加上新鲜甜甜圈恰好满足该批顾客，则该批顾客是**快乐的**。

请你安排顾客到来的顺序，使快乐的顾客批次数目最大，返回最大快乐批次数。

**规则**：如果当前剩余 r 个甜甜圈，顾客人数为 groups[i]，那么：
- 吃完后剩余 `(r + groups[i]) % batchSize`
- 若 `r == 0`，该批顾客是快乐的

**示例 1：**
```
输入：batchSize = 3, groups = [1,2,3,4,5,6]
输出：4
```

**示例 2：**
```
输入：batchSize = 4, groups = [1,3,2,5,2,2,1,6]
输出：4
```

## 解题思路

**贪心 + 状态压缩 DP**：

1. **贪心处理**：`groups[i] % batchSize == 0` 的组一定快乐（放最前面），先统计这些组。
2. **剩余分组**：对于其他组，只有其 `groups[i] % batchSize` 的余数有意义（余数相同可视为等价）。余数范围 1 到 batchSize-1。
3. **凑对**：余数 r 和余数 `batchSize - r` 的两组搭配放在一起，总贡献为 0 mod batchSize（余数之和为 batchSize），可快乐。优先将这些对配对，贡献快乐组数。
4. **状态压缩 DP**：剩余不能凑对的余数组，用状态压缩 DP，状态为各余数的剩余数量（由于 batchSize <= 9，余数最多 8 种，每种最多几十个，可用元组表示状态）。

## 代码实现

### 方法一：贪心 + 状态压缩 DP（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxHappyGroups(self, batchSize: int, groups: List[int]) -> int:
        # 统计各余数的个数
        remainders = [0] * batchSize
        result = 0

        for g in groups:
            r = g % batchSize
            if r == 0:
                result += 1  # 余数为 0 的组直接快乐
            else:
                remainders[r] += 1

        # 凑对：余数 r 和 batchSize - r 配对，每对贡献 1 个快乐组
        for r in range(1, batchSize // 2 + 1):
            complement = batchSize - r
            if r == complement:
                # 余数为 batchSize/2 时（偶数），每两个配一对
                result += remainders[r] // 2
                remainders[r] %= 2
            else:
                pairs = min(remainders[r], remainders[complement])
                result += pairs
                remainders[r] -= pairs
                remainders[complement] -= pairs

        # 剩余余数用状态压缩 DP
        state = tuple(remainders[1:])  # 去掉 r=0（已处理）

        @lru_cache(maxsize=None)
        def dp(state: tuple, current_sum: int) -> int:
            """
            state: 各余数（1~batchSize-1）的剩余数量
            current_sum: 当前剩余的甜甜圈数（mod batchSize）
            返回：还能获得的最大快乐组数
            """
            best = 0
            for r in range(1, batchSize):
                if state[r - 1] > 0:
                    new_state = list(state)
                    new_state[r - 1] -= 1
                    new_state = tuple(new_state)
                    happy = 1 if current_sum == 0 else 0
                    best = max(best, happy + dp(new_state, (current_sum + r) % batchSize))
            return best

        return result + dp(state, 0)
```

### 方法二：简化版（仅用记忆化搜索）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxHappyGroups(self, batchSize: int, groups: List[int]) -> int:
        cnt = [0] * batchSize
        for g in groups:
            cnt[g % batchSize] += 1

        @lru_cache(maxsize=None)
        def dp(state: tuple, leftover: int) -> int:
            happy = 0
            for r in range(batchSize):
                if state[r] > 0:
                    new_state = list(state)
                    new_state[r] -= 1
                    bonus = 1 if leftover == 0 and r != 0 else (1 if leftover == 0 and r == 0 else 0)
                    # 若当前 leftover==0 且选择的组到来时剩余为 0，快乐
                    add = 1 if leftover == 0 else 0
                    val = dp(tuple(new_state), (leftover + r) % batchSize)
                    happy = max(happy, (add if r > 0 or leftover == 0 else 0) + val)
            return happy

        # 更简洁的实现
        cnt[0] = 0  # 余数0单独处理
        base = sum(1 for g in groups if g % batchSize == 0)

        @lru_cache(maxsize=None)
        def solve(state: tuple, rem: int) -> int:
            res = 0
            for r in range(1, batchSize):
                if state[r - 1] > 0:
                    ns = list(state)
                    ns[r - 1] -= 1
                    gain = 1 if rem == 0 else 0
                    res = max(res, gain + solve(tuple(ns), (rem + r) % batchSize))
            return res

        cnt2 = [0] * batchSize
        for g in groups:
            r = g % batchSize
            if r != 0:
                cnt2[r] += 1
        return base + solve(tuple(cnt2[1:]), 0)
```

## 复杂度分析

- **时间复杂度**：O(batchSize * 状态数)，状态数由各余数的个数决定，较小
- **空间复杂度**：O(状态数)，记忆化缓存

## 关键点总结

1. 贪心预处理：余数为 0 的组直接快乐，互补余数的组配对也各贡献 1 个快乐
2. 状态只与各余数的剩余数量和当前剩余有关，与排列顺序无关
3. batchSize <= 9，余数范围小，状态空间可接受

## 易错点

- 凑对时余数 r 和 batchSize-r 的配对数取二者的最小值
- 当 batchSize 为偶数时，余数 batchSize/2 的组之间两两配对
