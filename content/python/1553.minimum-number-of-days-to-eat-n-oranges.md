## 题目描述

橱柜里有 `n` 个橘子，每天你可以做以下之一：
1. 吃 1 个橘子
2. 若剩余橘子数能被 2 整除，吃 n/2 个
3. 若剩余橘子数能被 3 整除，吃 2*(n/3) 个

返回吃掉所有橘子最少需要多少天。

**示例 1：**
```
输入：n = 10
输出：4
解释：第1天吃1个，剩9；第2天吃6个（9的2/3），剩3；第3天吃2个（3的2/3），剩1；第4天吃1个，完成。
```

**提示：**
- `1 <= n <= 2 * 10^9`

## 解题思路

### 记忆化搜索

直接 DP 会有 O(N) 状态，N 最大 2*10^9 会超内存/时间。

**关键：** 最优策略总是尽快除以 2 或 3。从 n 到整除点只需 1-2 步（吃 `n%2` 或 `n%3` 个橘子先凑整）。

**递推：**
- `dp(n) = min(n%2 + 1 + dp(n//2), n%3 + 1 + dp(n//3))`
- `dp(0) = 0`, `dp(1) = 1`

用字典做记忆化（不会超过 O(log N) 层递归，实际状态数很少）。

## 代码实现

### 方法一：记忆化递归（推荐）

```python
from functools import lru_cache

class Solution:
    def minDays(self, n: int) -> int:
        @lru_cache(maxsize=None)
        def dp(n: int) -> int:
            if n <= 1:
                return n
            # 两种策略：凑整后除以2，或凑整后除以3
            # 凑整需要 n%2 天（吃 n%2 个）+ 1天（吃 n//2 个）
            return min(
                n % 2 + 1 + dp(n // 2),
                n % 3 + 1 + dp(n // 3)
            )

        return dp(n)
```

### 方法二：字典记忆化（等价）

```python
class Solution:
    def minDays(self, n: int) -> int:
        memo = {0: 0, 1: 1}

        def dp(n: int) -> int:
            if n in memo:
                return memo[n]
            # 先凑整为 2 的倍数或 3 的倍数，再一次性吃掉一半或三分之二
            res = min(
                n % 2 + 1 + dp(n // 2),   # 先吃 n%2 个凑整，再吃 n//2 个
                n % 3 + 1 + dp(n // 3)    # 先吃 n%3 个凑整，再吃 2*(n//3) 个
            )
            memo[n] = res
            return res

        return dp(n)
```

## 复杂度分析

- **时间复杂度**：O(log^2 N)，每层分支成 n//2 和 n//3，层数约为 log N
- **空间复杂度**：O(log^2 N)，记忆化存储的状态数

## 关键点总结

1. 贪心：每步都尽量除以 2 或 3（必须先凑整）
2. 凑整代价：吃 `n%2` 或 `n%3` 个橘子（最多 2 天）
3. 状态数远小于 N（约 `log^2 N`），记忆化高效

## 易错点

- 不能直接 `dp(n) = 1 + dp(n-1)` 这样线性递推（N 太大）
- 凑整后的操作是"一次吃掉一半/三分之二"，算一天，不是多天
