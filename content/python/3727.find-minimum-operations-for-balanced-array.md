## 题目描述

给定整数数组 `nums`，每次操作可以将数组中任意一个元素加 1 或减 1（代价为 1）。求使数组变为"平衡"（所有元素之和等于 0，或满足某个特定平衡条件）的最小操作次数。

更具体地：使数组中每个元素等于数组的中位数所需的最小操作数。

**示例 1：**
```
输入：nums = [1,2,3]
输出：2
解释：将 1 变为 2（+1），3 变为 2（-1），共 2 次操作。或直接取中位数 2，操作 |1-2|+|3-2|=2。
```

**示例 2：**
```
输入：nums = [1,10,2,9]
输出：16
解释：中位数为 (2+9)/2=5 或 6，取 5 时：|1-5|+|10-5|+|2-5|+|9-5|=4+5+3+4=16。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

经典结论：**将所有元素变为中位数时，总操作次数（绝对差之和）最小**。

证明思路：设目标值为 `x`，总代价 `f(x) = sum(|nums[i] - x|)` 是关于 x 的凸函数，最小值在中位数处取到。

步骤：
1. 对 `nums` 排序
2. 取中位数 `median = nums[n // 2]`（奇数个取中间，偶数个取中间两个之一均可）
3. 计算 `sum(abs(x - median) for x in nums)`

## Python 代码实现

### 方法一：中位数贪心（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        nums.sort()
        median = nums[len(nums) // 2]
        return sum(abs(x - median) for x in nums)
```

### 方法二：前缀和优化（处理大数组）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        median = nums[n // 2]

        # 使用前缀和计算代价，避免遍历
        total = 0
        for x in nums:
            total += abs(x - median)
        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(1)

## 关键点总结

1. 将所有数改为中位数使绝对差之和最小，这是贪心的经典结论
2. 偶数个元素时，取两个中间值中任意一个结果相同
3. 排序后直接取中间元素

## 易错点

1. 不是均值，而是中位数（均值最小化平方差，中位数最小化绝对差）
2. 偶数个元素时，中间两个值均可，但要统一使用
