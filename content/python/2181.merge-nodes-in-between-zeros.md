## 题目描述

给你一个链表的头节点 `head`，该链表包含由 `0` 分隔的一系列整数。链表的开始和结束处均有 `0`。

对于每两个相邻的 `0` 之间的节点，将这些节点的值相加，合并成一个节点，其值为这些节点值的总和。返回修改后链表的头节点。注意：返回的链表不应含有任何 `0`。

**示例 1：**
```
输入：head = [0,3,1,0,4,5,2,0]
输出：[4,11]
解释：
- 两个 0 之间的节点为 [3,1]，求和 = 4
- 两个 0 之间的节点为 [4,5,2]，求和 = 11
```

**示例 2：**
```
输入：head = [0,1,0,3,0,2,2,0]
输出：[1,3,4]
```

**提示：**
- 链表中节点数目在范围 `[3, 2 * 10^5]` 内
- `0 <= Node.val <= 1000`
- 不存在连续两个 `Node.val == 0` 的节点
- 链表的开始和结束处均有 `0`

## 解题思路

**模拟遍历**

遍历链表，遇到非零节点就累加到当前段的和；遇到 `0` 节点（且不是最后一个 `0`）就将当前段的和作为新节点加入结果链表。

## 代码实现

### 方法一：就地修改（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # dummy 指针指向结果链表的虚拟头节点
        dummy = ListNode(0)
        tail = dummy

        cur = head.next  # 跳过开头的 0
        segment_sum = 0

        while cur is not None:
            if cur.val == 0:
                # 遇到 0，将当前段和加入结果
                if segment_sum > 0:
                    tail.next = ListNode(segment_sum)
                    tail = tail.next
                    segment_sum = 0
            else:
                segment_sum += cur.val
            cur = cur.next

        return dummy.next
```

### 方法二：复用原链表节点

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 复用原有节点，不额外分配
        result_head = None  # 结果链表头
        result_tail = None  # 结果链表尾

        cur = head.next  # 跳过第一个 0
        segment_sum = 0

        while cur:
            if cur.val == 0:
                if segment_sum > 0:
                    # 复用当前节点存储段和
                    node = ListNode(segment_sum)
                    if result_head is None:
                        result_head = node
                        result_tail = node
                    else:
                        result_tail.next = node
                        result_tail = node
                    segment_sum = 0
            else:
                segment_sum += cur.val
            cur = cur.next

        return result_head
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(n) | O(1)（不计输出） |

## 关键点总结

1. 跳过头部的 `0`，从第一个非零节点开始遍历。
2. 遇到 `0` 时提交当前段的累加和。
3. 最后一个 `0` 处 `segment_sum` 归零后不再有后续节点，自然结束。

## 易错点

- 头节点是 `0`，要从 `head.next` 开始遍历。
- 尾部的 `0` 触发最后一段的提交，不要漏掉。
