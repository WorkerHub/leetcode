## 题目描述

给你两个正整数 `n` 和 `k`，二进制字符串 `S_n` 定义如下：
- `S_1 = "0"`
- `S_i = S_{i-1} + "1" + reverse(invert(S_{i-1}))`，其中 `i > 1`

其中 `reverse` 是颠倒字符串，`invert` 是将 0 变 1、1 变 0。

返回 `S_n` 中第 `k` 位（1-indexed）。

**示例 1：**
```
输入：n = 3, k = 1
输出："0"
S_3 = "0111001"
```

**示例 2：**
```
输入：n = 4, k = 11
输出："1"
```

## 解题思路

### 递归

`S_n` 的长度为 `2^n - 1`，中间位是 `2^(n-1)` 位（中间那个 `"1"`）。

- 若 `k == 2^(n-1)`，返回 `'1'`
- 若 `k < 2^(n-1)`，`k` 在前半段 `S_{n-1}` 中，递归 `findKthBit(n-1, k)`
- 若 `k > 2^(n-1)`，`k` 在后半段 `reverse(invert(S_{n-1}))` 中：
  - 在后半段的位置 `k' = 2^n - k`（从后往前数的位置，对应在 `S_{n-1}` 中的位置）
  - 该位是 `S_{n-1}` 中第 `k'` 位的反转

## 代码实现

### 方法一：递归（推荐）

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        def helper(n: int, k: int) -> int:
            """返回 S_n 第 k 位的值（0 或 1）"""
            if n == 1:
                return 0  # S_1 = "0"

            mid = 1 << (n - 1)  # 2^(n-1)，中间位

            if k == mid:
                return 1
            elif k < mid:
                # 在前半段 S_{n-1}
                return helper(n - 1, k)
            else:
                # 在后半段：对应 S_{n-1} 中第 (2^n - k) 位的反转
                mirror = (1 << n) - k  # 2^n - k
                return 1 - helper(n - 1, mirror)

        return str(helper(n, k))
```

### 方法二：迭代

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        # 迭代版本：记录需要翻转的次数
        invert = 0

        while n > 1:
            mid = 1 << (n - 1)
            if k == mid:
                return str(1 ^ invert)
            elif k > mid:
                # k 在后半段，镜像到前半段，需要翻转
                k = (1 << n) - k
                invert ^= 1
            # k < mid：直接在前半段，不需要翻转
            n -= 1

        # n == 1, k == 1, S_1 = "0"
        return str(0 ^ invert)
```

### 方法三：构造字符串（小 n 时可用）

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        s = "0"
        for _ in range(n - 1):
            inverted = ''.join('1' if c == '0' else '0' for c in s)
            s = s + "1" + inverted[::-1]
        return s[k - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（递归） | O(N) | O(N)（递归栈） |
| 方法二（迭代） | O(N) | O(1) |
| 方法三（构造） | O(2^N) | O(2^N) |

## 关键点总结

1. `S_n` 长度为 `2^n - 1`，中间位（第 `2^(n-1)` 位）恒为 `'1'`
2. 后半段是前半段的反转取反，查后半段可以映射到前半段+一次翻转
3. 迭代方法用 `invert` 标记累积的翻转次数

## 易错点

- `mirror = 2^n - k`（不是 `2^(n-1) - (k - 2^(n-1))`，两者等价但后者容易写错）
- 迭代版本中最后 `n==1, k==1` 时对应 `S_1[0] = '0'`，再应用 `invert`
