## 题目描述

你正在参加一场竞赛，竞赛中有 `n` 个对手，顺序对阵。你的**精力**和**经验**初始值分别为 `initialEnergy` 和 `initialExperience`。

对于第 `i` 个对手：
- 你必须拥有**严格大于**对手的精力（`energy[i]`）和经验（`experience[i]`）才能获胜。
- 获胜后，你的精力减少 `energy[i]`，经验增加 `experience[i]`。

你可以在竞赛前进行训练：每小时训练增加 1 点精力**或** 1 点经验。

返回至少需要训练的**最少小时数**。

**示例 1：**
```
输入：initialEnergy = 5, initialExperience = 3, energy = [1,4,3,2], experience = [2,6,3,1]
输出：8
```

**提示：**
- `n == energy.length == experience.length`
- `1 <= n <= 100`
- `1 <= energy[i], experience[i] <= 100`

## 解题思路

**精力和经验分开计算：**

- **精力**：精力在每次对阵后减少，需要整个竞赛过程中不耗尽。最少初始精力 = `sum(energy) + 1`（要严格大于累计消耗）。若 `initialEnergy >= sum(energy) + 1`，无需训练；否则需要训练 `sum(energy) + 1 - initialEnergy` 小时。

- **经验**：经验只增不减，只需保证每次对阵时当前经验 > 对手经验。贪心模拟：若当前经验 <= 对手经验，补充到 `opponent_experience + 1`，统计补充总量。

## 代码实现

### 方法一：分别贪心计算（推荐）

```python
from typing import List

class Solution:
    def minNumberOfHours(self, initialEnergy: int, initialExperience: int,
                         energy: List[int], experience: List[int]) -> int:
        hours = 0
        
        # 精力：必须严格大于所有对手精力之和
        energy_needed = sum(energy) + 1
        if initialEnergy < energy_needed:
            hours += energy_needed - initialEnergy
        
        # 经验：模拟，若不足则补充
        cur_exp = initialExperience
        for exp in experience:
            if cur_exp <= exp:
                hours += exp + 1 - cur_exp
                cur_exp = exp + 1
            cur_exp += exp  # 获胜后经验增加
        
        return hours
```

### 方法二：同时模拟精力和经验

```python
from typing import List

class Solution:
    def minNumberOfHours(self, initialEnergy: int, initialExperience: int,
                         energy: List[int], experience: List[int]) -> int:
        hours = 0
        cur_e = initialEnergy
        cur_exp = initialExperience
        
        for e, exp in zip(energy, experience):
            # 检查精力
            if cur_e <= e:
                hours += e + 1 - cur_e
                cur_e = e + 1
            cur_e -= e  # 精力消耗
            
            # 检查经验
            if cur_exp <= exp:
                hours += exp + 1 - cur_exp
                cur_exp = exp + 1
            cur_exp += exp  # 经验增加
        
        return hours
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(1) |

## 关键点总结

1. 精力在竞赛前总额固定（每场必减），只需保证初始精力 > 总消耗。
2. 经验每场增加，只需确保每场对阵前经验 > 对手经验。
3. 两者独立计算，分别求最少训练时间后求和。

## 易错点

- 条件是**严格大于**（`>`），不是大于等于，所以需要 `exp + 1`。
- 精力初始不足时，补足到 `sum(energy) + 1` 而不是 `sum(energy)`。
