## 题目描述

给你一个字符串数组 `arr`（长度 `n`）。

对数组中每个字符串 `arr[i]`，找出它的最短子字符串，使该子字符串不是数组中任何**其他**字符串的子字符串。

如果存在多个最短子字符串，返回字典序最小的。如果不存在，返回 `""`。

**示例 1：**
```
输入：arr = ["cab","ad","bad","c"]
输出：["ab","","ba",""]
```

**提示：**
- `n == arr.length`
- `2 <= n <= 100`
- `1 <= arr[i].length <= 20`

## 解题思路

对每个字符串 `arr[i]`，枚举其所有子字符串，按长度从短到长、字典序排序，找第一个不出现在其他字符串中的子字符串。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def shortestSubstrings(self, arr: List[str]) -> List[str]:
        n = len(arr)
        result = []

        for i in range(n):
            s = arr[i]
            # 找 s 中最短的、不是其他字符串子串的子字符串
            ans = ""
            found = False

            # 枚举长度从短到长
            for length in range(1, len(s) + 1):
                if found:
                    break
                # 枚举该长度的所有子字符串，按字典序排序
                candidates = sorted(set(s[j:j+length] for j in range(len(s) - length + 1)))

                for sub in candidates:
                    # 检查 sub 是否不出现在任何其他字符串中
                    is_unique = True
                    for j in range(n):
                        if j != i and sub in arr[j]:
                            is_unique = False
                            break
                    if is_unique:
                        ans = sub
                        found = True
                        break

            result.append(ans)

        return result
```

### 方法二：哈希表预处理

```python
from typing import List
from collections import defaultdict

class Solution:
    def shortestSubstrings(self, arr: List[str]) -> List[str]:
        # 统计每个子字符串出现在哪些字符串中
        sub_count = defaultdict(set)
        for i, s in enumerate(arr):
            for l in range(1, len(s) + 1):
                for start in range(len(s) - l + 1):
                    sub_count[s[start:start+l]].add(i)

        result = []
        for i, s in enumerate(arr):
            best = ""
            for l in range(1, len(s) + 1):
                if best:
                    break
                candidates = sorted(set(s[j:j+l] for j in range(len(s) - l + 1)))
                for sub in candidates:
                    # 只出现在第 i 个字符串中
                    if sub_count[sub] == {i}:
                        best = sub
                        break
            result.append(best)

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 * L^3)，n 个字符串，L 为最大长度，枚举子串 O(L^2)，检查 O(n * L)
- 空间复杂度：O(n * L^2)，存储子串集合

## 关键点总结

1. 枚举所有子字符串，按长度优先、字典序其次排序
2. 找第一个只属于当前字符串的子字符串
3. 预处理子字符串到字符串集合的映射，提高查询效率

## 易错点

1. 需要的子字符串不能是**任何其他**字符串的子串（可以是自身的子串）
2. 若无满足条件的子串，返回空字符串 `""`
