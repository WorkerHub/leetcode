## 题目描述

给你一个 **严格升序排列** 的正整数数组 `arr` 和一个整数 `k`。

请你找到这个数组里第 `k` 个缺失的正整数。

**示例 1：**
```
输入：arr = [2,3,4,7,11], k = 5
输出：9
解释：缺失的正整数为 1,5,6,8,9,10...，第 5 个是 9
```

**示例 2：**
```
输入：arr = [1,2,3,4], k = 2
输出：6
```

**提示：**
- `1 <= arr.length <= 1000`
- `1 <= arr[i] <= 1000`
- `1 <= k <= 1000`
- 对于所有 `1 <= i < j <= arr.length` 的 i, j 满足 `arr[i] < arr[j]`

## 解题思路

### 方法一：线性扫描

维护当前应该出现的数字（从 1 开始），遇到缺失的就减少 k，直到 k=0。

### 方法二：二分查找（推荐）

在位置 `i`（0-indexed），`arr[i]` 前应该有 `arr[i] - 1` 个正整数，实际只有 `i` 个，所以 `arr[i]` 前缺失了 `arr[i] - 1 - i` 个正整数。

二分找到最小的 `i` 使得 `arr[i] - 1 - i >= k`，答案为 `arr[i-1] + (k - (arr[i-1] - i))`... 即 `i + k`（利用 lo = 左边界）。

## 代码实现

### 方法一：线性扫描（直观）

```python
from typing import List

class Solution:
    def findKthPositive(self, arr: List[int], k: int) -> int:
        arr_set = set(arr)
        count = 0
        num = 0
        while count < k:
            num += 1
            if num not in arr_set:
                count += 1
        return num
```

### 方法二：二分查找（推荐）

```python
from typing import List

class Solution:
    def findKthPositive(self, arr: List[int], k: int) -> int:
        # 在 arr[i] 之前，缺失的数量 = arr[i] - (i+1) = arr[i] - i - 1
        # 二分找最小的 i 使得 arr[i] - i - 1 >= k
        lo, hi = 0, len(arr)
        while lo < hi:
            mid = (lo + hi) // 2
            if arr[mid] - mid - 1 >= k:
                hi = mid
            else:
                lo = mid + 1
        # lo 是第一个缺失数 >= k 的位置
        # 在 arr[lo-1] 之后缺失了 k - missing(lo-1) 个数
        # 答案 = arr[lo-1] + (k - missing(lo-1))
        # missing(lo-1) = arr[lo-1] - (lo-1) - 1 = arr[lo-1] - lo
        # 答案 = arr[lo-1] + k - arr[lo-1] + lo = k + lo
        return lo + k
```

### 方法三：暴力遍历

```python
from typing import List

class Solution:
    def findKthPositive(self, arr: List[int], k: int) -> int:
        missing = 0
        prev = 0
        for num in arr:
            # prev 到 num 之间缺失了 (num - prev - 1) 个数
            gap = num - prev - 1
            if missing + gap >= k:
                return prev + (k - missing)
            missing += gap
            prev = num
        # 超出数组范围
        return prev + (k - missing)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（线性） | O(N + k) | O(N) |
| 方法二（二分） | O(log N) | O(1) |
| 方法三（遍历） | O(N) | O(1) |

## 关键点总结

1. `arr[i]` 位置前缺失数量 = `arr[i] - (i+1)`（应有 arr[i]-1 个，实际有 i 个）
2. 二分找临界位置，答案公式 = `lo + k`
3. 方法三在 arr 末尾之后也能正确处理

## 易错点

- 二分的公式推导：`lo + k` 的来源要理解清楚
- 方法一用 set 提高查找效率
