## 题目描述

给你一个整数 `n`，请你返回任意一个由 `n` 个各不相同的整数组成的数组，并且这 `n` 个数相加和为 `0`。

示例 1：
```
输入：n = 5
输出：[-7,-1,1,3,4]
解释：这些数组也是正确的 [-5,-1,1,2,3]，[-3,-1,2,-2,4]。
```

示例 2：
```
输入：n = 3
输出：[-1,0,1]
```

示例 3：
```
输入：n = 1
输出：[0]
```

提示：
- `1 <= n <= 1000`

## 解题思路

这道题要求构造 n 个不同的整数，使得它们的和为 0。有多种构造方法：

### 思路一：对称构造
最简单的方法是利用正负数对称的特点：
- 如果 n 是偶数，构造 `[-n, -(n-1), ..., -1, 1, ..., n-1, n]` 的一半
- 如果 n 是奇数，在中间加一个 0

例如：
- n = 5: `[-2, -1, 0, 1, 2]`
- n = 4: `[-2, -1, 1, 2]`

### 思路二：简化版对称
从 1 开始，交替添加正数和负数：
- 添加 1, -1, 2, -2, 3, -3, ...
- 重复 n//2 次
- 如果 n 是奇数，最后添加 0

## Python 代码实现

### 方法一：对称构造（推荐）⭐

```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        result = []
        
        # 添加成对的正负数
        for i in range(1, n // 2 + 1):
            result.append(i)
            result.append(-i)
        
        # 如果 n 是奇数，添加 0
        if n % 2 == 1:
            result.append(0)
        
        return result
```

### 方法二：列表推导式（Python 简洁写法）

```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        # 生成 [-n//2, ..., -1, 1, ..., n//2] 或加上 0
        return list(range(1, n // 2 + 1)) + list(range(-n // 2, 0)) + [0] * (n % 2)
```

### 方法三：更简洁的写法

```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        # 生成 1 到 n-1，然后加上它们的负和
        if n == 1:
            return [0]
        
        result = list(range(1, n))
        result.append(-sum(result))
        return result
```

### 方法四：数学构造

```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        # 构造 [-n+1, -n+2, ..., -1, 0, 1, ..., n-2, n-1]
        # 然后去掉 0（如果 n 是偶数）
        result = list(range(-n + 1, n, 2))
        
        # 如果 n 是奇数，已经自动包含 0
        # 如果 n 是偶数，需要调整
        if n % 2 == 0:
            result = list(range(1, n // 2 + 1)) + list(range(-1, -n // 2 - 1, -1))
        else:
            result = list(range(1, n // 2 + 1)) + [0] + list(range(-1, -n // 2 - 1, -1))
        
        return result
```

### 方法五：极简一行（推荐）

```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        return list(range(1 - n, n, 2))
```

## 复杂度分析

所有方法的复杂度相同：
- 时间复杂度：O(n)，需要生成 n 个数
- 空间复杂度：O(1)，不计返回值的空间

## 关键点总结

1. 利用正负数相加为 0 的特性
2. 对称构造是最直观的方法
3. 奇数个数时，中间放 0
4. Python 的 range 和列表推导式可以简化代码

## 易错点

1. 忘记处理 n 为奇数的情况
2. 生成的数字不是唯一的（有重复）
3. range 的参数设置错误，导致生成的数字数量不对
