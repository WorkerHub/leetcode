## 题目描述

Alice 和 Bob 计划在罗马开会。给你四个字符串 `arriveAlice`、`leaveAlice`、`arriveBob` 和 `leaveBob`，分别表示 Alice 到达/离开以及 Bob 到达/离开的日期，格式均为 `"MM-DD"`。

Alice 和 Bob 同时在罗马的天数是多少？

你可以假设每次 Alice 和 Bob 来访时间内，年份相同且为非闰年，且 Alice 的到达时间不晚于离开时间，Bob 也是如此。

**示例 1：**
```
输入：arriveAlice = "08-15", leaveAlice = "08-18", arriveBob = "08-16", leaveBob = "08-19"
输出：3
解释：Alice 在 08-15 到 08-18 期间在罗马，Bob 在 08-16 到 08-19 期间在罗马。两人同时在场的时间为 08-16 到 08-18，共 3 天。
```

**示例 2：**
```
输入：arriveAlice = "10-01", leaveAlice = "10-31", arriveBob = "11-01", leaveBob = "11-30"
输出：0
解释：Alice 和 Bob 没有同时在罗马。
```

**提示：**
- 所有日期格式为 `"MM-DD"`，月份在 `01` 到 `12` 之间，日期在 `01` 到 `30` 或 `31` 之间

## 解题思路

将日期转换为一年中的第几天（日期序号），然后求两段区间的重叠天数。

- 两段区间 `[a1, a2]` 和 `[b1, b2]` 的重叠为 `[max(a1,b1), min(a2,b2)]`
- 若 `max(a1,b1) > min(a2,b2)` 则无重叠，返回 0

**每月天数（非闰年）：** `[31,28,31,30,31,30,31,31,30,31,30,31]`

## 代码实现

### 方法一：转换为天数（推荐）

```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
        # 每月天数（非闰年）
        days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        def to_day(date: str) -> int:
            """将 'MM-DD' 转换为年中第几天"""
            month, day = int(date[:2]), int(date[3:])
            return sum(days_in_month[:month - 1]) + day

        # 转换为年中天数
        a1, a2 = to_day(arriveAlice), to_day(leaveAlice)
        b1, b2 = to_day(arriveBob), to_day(leaveBob)

        # 计算重叠区间长度
        overlap = min(a2, b2) - max(a1, b1) + 1
        return max(0, overlap)
```

### 方法二：直接比较字符串（利用字典序）

```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
        # 每月天数（非闰年）
        days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        def to_day(date: str) -> int:
            month, day = int(date[:2]), int(date[3:])
            return sum(days_in_month[:month - 1]) + day

        # 取两人到达的较晚日期和离开的较早日期
        start = max(arriveAlice, arriveBob)  # 字符串比较可以用于 MM-DD 格式
        end = min(leaveAlice, leaveBob)

        if start > end:
            return 0

        return to_day(end) - to_day(start) + 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 转换为天数 | O(1) | O(1) |

所有操作都是常数级别（固定长度的日期字符串和固定 12 个月）。

## 关键点总结

1. 将日期转为年中第几天，便于比较和计算差值
2. 两区间重叠 = `max(0, min(end1, end2) - max(start1, start2) + 1)`
3. `MM-DD` 格式下，字符串字典序等价于日期大小顺序

## 易错点

- 重叠天数公式中要加 1（两端都包含）
- 无重叠时需要返回 0，而不是负数
