## 题目描述

给你一个整数数组 `nums`。你需要选择**恰好一个**下标（0-indexed）并删除对应的元素。请注意剩下元素的下标可能会因为删除操作而改变。

如果删除后剩余数组满足**奇偶交替性**（奇数下标的元素之和等于偶数下标的元素之和），则称该数组是**公平的**。

返回删除后可以得到**公平数组**的删除方案数。

**示例：**
```
输入：nums = [2,1,6,4]
输出：1
解释：删除 index=1（值=1）后：[2,6,4]，偶数位之和=2+4=6，奇数位之和=6，相等
```

## 解题思路

当删除第 `i` 个元素时：
- `i` 之前的元素下标不变
- `i` 之后的元素奇偶性翻转

**预处理前缀和：**
- `even_prefix[i]` = 前 i 个元素中偶数下标之和
- `odd_prefix[i]` = 前 i 个元素中奇数下标之和

删除第 `i` 个元素后：
- 偶数位之和 = `even_prefix[i]` + `(odd_sum_suffix[i] - nums[i]（若i是奇数）或 odd_sum_suffix[i])`

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def waysToMakeFair(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 计算总的偶数下标和、奇数下标和
        total_even = sum(nums[i] for i in range(0, n, 2))
        total_odd = sum(nums[i] for i in range(1, n, 2))
        
        result = 0
        prefix_even = 0  # 前缀偶数和
        prefix_odd = 0   # 前缀奇数和
        
        for i in range(n):
            # 删除 nums[i] 后：
            # 左边偶数下标和 = prefix_even（不变）
            # 左边奇数下标和 = prefix_odd（不变）
            # 右边：下标翻转，原偶数变奇数，原奇数变偶数
            suffix_even = total_even - prefix_even - (nums[i] if i % 2 == 0 else 0)
            suffix_odd = total_odd - prefix_odd - (nums[i] if i % 2 == 1 else 0)
            
            # 删除后的偶数位和 = 左边偶数 + 右边原奇数（翻转后变偶数）
            new_even = prefix_even + suffix_odd
            # 删除后的奇数位和 = 左边奇数 + 右边原偶数（翻转后变奇数）
            new_odd = prefix_odd + suffix_even
            
            if new_even == new_odd:
                result += 1
            
            # 更新前缀和
            if i % 2 == 0:
                prefix_even += nums[i]
            else:
                prefix_odd += nums[i]
        
        return result
```

### 方法二：差值法（更简洁）

```python
from typing import List

class Solution:
    def waysToMakeFair(self, nums: List[int]) -> int:
        total_even = sum(nums[i] for i in range(0, len(nums), 2))
        total_odd = sum(nums[i] for i in range(1, len(nums), 2))
        
        result = 0
        running_even = 0
        running_odd = 0
        
        for i, x in enumerate(nums):
            if i % 2 == 0:
                total_even -= x
            else:
                total_odd -= x
            
            # 删除 i 后：左边保持，右边翻转
            new_even = running_even + total_odd
            new_odd = running_odd + total_even
            
            if new_even == new_odd:
                result += 1
            
            if i % 2 == 0:
                running_even += x
            else:
                running_odd += x
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(1) |

## 关键点总结

1. 删除第 i 个元素后，右边所有元素的奇偶性翻转
2. 新偶数位和 = 左边偶数 + 右边原奇数
3. 新奇数位和 = 左边奇数 + 右边原偶数
4. 用差值法（先减去当前元素的贡献）更新总和

## 易错点

- 删除后右侧元素奇偶性**完全翻转**（原来偶数下标变奇数，反之亦然）
- 注意区分 suffix_even 和 suffix_odd 的计算（需减去被删除元素的贡献）
