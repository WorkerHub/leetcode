## 题目描述

给你一个由 `n` 个正整数组成的数组 `nums`。

你可以对数组执行任意次以下两类操作之一：
- 如果元素是**奇数**，将其乘以 `2`
- 如果元素是**偶数**，将其除以 `2`

数组的**偏差**是数组中最大值和最小值的差值。

返回数组执行若干次操作后可能的**最小偏差**。

## 解题思路

**关键观察：** 先将所有奇数乘以 2，使所有元素变为偶数，然后只做"除以 2"操作（将最大值减半）。

**贪心策略（最大堆）：**
1. 将所有奇数乘以 2（确保所有元素可以无限除 2）
2. 用最大堆维护当前最大值
3. 每次将最大值除以 2（若最大值是偶数），更新最小值
4. 记录每次操作后的偏差，取最小值

## 代码实现

### 方法一：最大堆 + 贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        # 将所有奇数乘以 2，确保所有元素都是偶数
        # 同时初始化最大堆（取负模拟最大堆）
        heap = []
        min_val = float('inf')
        
        for x in nums:
            if x % 2 == 1:
                x *= 2
            heap.append(-x)
            min_val = min(min_val, x)
        
        heapq.heapify(heap)
        ans = -heap[0] - min_val  # 初始偏差
        
        while True:
            max_val = -heapq.heappop(heap)
            
            # 更新当前偏差
            ans = min(ans, max_val - min_val)
            
            # 若最大值是奇数，无法再除，停止
            if max_val % 2 == 1:
                break
            
            # 将最大值除以 2
            new_val = max_val // 2
            min_val = min(min_val, new_val)
            heapq.heappush(heap, -new_val)
        
        return ans
```

### 方法二：有序集合（SortedList）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        sl = SortedList()
        
        for x in nums:
            if x % 2 == 1:
                x *= 2
            sl.add(x)
        
        ans = sl[-1] - sl[0]
        
        while sl[-1] % 2 == 0:
            max_val = sl.pop()
            sl.add(max_val // 2)
            ans = min(ans, sl[-1] - sl[0])
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最大堆 | O(n log n * log(max_val)) | O(n) |
| SortedList | O(n log n * log(max_val)) | O(n) |

## 关键点总结

1. 先将奇数乘以 2，使所有元素可以通过"除 2"操作减小
2. 贪心：每次减小最大值（除以 2），同时更新最小值
3. 停止条件：最大值是奇数（无法再除 2）
4. 每次操作后记录当前偏差，取最小值

## 易错点

- 先乘以 2 再除，不要直接对原始奇数操作
- 最大值变为奇数时停止（奇数不能除 2）
- 每次除 2 后要更新最小值
