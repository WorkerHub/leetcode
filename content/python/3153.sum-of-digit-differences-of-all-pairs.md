## 题目描述

给你一个正整数数组 `nums`，其中所有数字的位数相同。

两个整数之间的 **数字差** 定义为每个对应位上数字不同的位数。

返回数组中所有数对的数字差之和。

**示例 1：**
```
输入：nums = [13,23,12]
输出：4
解释：(13,23): 第1位不同(1vs2)，第2位相同(3vs3) -> 差1; (13,12): 1相同,3vs2不同 -> 差1; (23,12): 2vs1不同,3vs2不同 -> 差2；总和=4
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] < 10^9`
- 所有 nums[i] 有相同位数

## 解题思路

对每一位单独统计贡献。对第 k 位，若有 d 种数字，每种数字 count[d] 个，则第 k 位的贡献 = sum over all pairs (i<j): 1 if nums[i]第k位 != nums[j]第k位。

等价于：n*(n-1)/2 - sum(c*(c-1)/2 for c in counts)，其中 counts 是各数字在第 k 位的出现次数。

## Python 代码实现

### 方法一：按位统计（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def sumDigitDifferences(self, nums: List[int]) -> int:
        n = len(nums)
        total_pairs = n * (n - 1) // 2

        # 确定位数
        digits = len(str(nums[0]))
        ans = 0

        for k in range(digits):
            # 统计第 k 位（从右数）的数字分布
            cnt = Counter()
            for x in nums:
                d = (x // (10 ** k)) % 10
                cnt[d] += 1
            # 贡献 = 总对数 - 同位数字相同的对数
            same = sum(c * (c - 1) // 2 for c in cnt.values())
            ans += total_pairs - same

        return ans
```

### 方法二：字符串处理

```python
from typing import List
from collections import Counter

class Solution:
    def sumDigitDifferences(self, nums: List[int]) -> int:
        n = len(nums)
        strs = [str(x) for x in nums]
        digits = len(strs[0])
        total_pairs = n * (n - 1) // 2
        ans = 0

        for k in range(digits):
            cnt = Counter(s[k] for s in strs)
            same = sum(c * (c - 1) // 2 for c in cnt.values())
            ans += total_pairs - same

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * d)，d 为位数（最多 9 位）
- 空间复杂度：O(10) = O(1)（每位只有 10 种数字）

## 关键点总结

1. 按位分解问题，各位独立贡献
2. 第 k 位的贡献 = 总对数 - 该位上相同数字的对数
3. 相同数字对数 = sum(c*(c-1)/2 for c in counts)

## 易错点

1. 幂次从 0 开始（最低位），注意位的提取方式
2. 总对数 = n*(n-1)/2，注意整数除法
