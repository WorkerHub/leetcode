## 题目描述

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

**示例 1：**
```
输入: a = "11", b = "1"
输出："100"
```

**示例 2：**
```
输入：a = "1010", b = "1011"
输出："10101"
```

**提示：**
- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"`，就不含前导零

## 解题思路

模拟二进制加法，从右向左逐位相加。

## Python 代码实现

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        result = []
        carry = 0
        i, j = len(a) - 1, len(b) - 1
        
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1
            
            result.append(str(total % 2))
            carry = total // 2
        
        return ''.join(reversed(result))
```

## 复杂度分析

- 时间复杂度：O(max(m, n))
- 空间复杂度：O(max(m, n))

## 关键点总结

1. **从右向左**：逐位相加
2. **进位处理**：carry
3. **长度不同**：用i, j分别控制

## 学习建议

与十进制加法类似，理解进位处理。
