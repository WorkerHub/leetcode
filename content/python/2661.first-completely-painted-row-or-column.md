## 题目描述

给你一个下标从 0 开始的整数数组 `arr` 和一个 `m x n` 整数矩阵 `mat`。`arr` 和 `mat` 都包含 `[1, m*n]` 中的所有整数。

按 `arr` 的顺序给矩阵格子涂色（`arr[i]` 对应 `mat` 中值为 `arr[i]` 的格子）。返回第一次某行或某列被完全涂色时 `arr` 的下标。

**示例 1：**
```
输入：arr = [2,8,7,4,1,3,5,6,9], mat = [[3,2,5],[1,4,6],[8,7,9]]
输出：3
解释：涂 2,8,7,4 后，第1行（3,2,5中的3没涂，但2已涂）不对...
实际第0列 [3,1,8]: 涂到 8 时（下标3），[8]已涂但还缺 3 和 1；
第2列 [5,6,9]: 涂 5(下标6),6(下标5)...
让我重新理解：arr[0]=2涂(0,1), arr[1]=8涂(2,0), arr[2]=7涂(2,1), arr[3]=4涂(1,1)
第1列 [2,4,7]: 下标0涂2，下标2涂7，下标3涂4，此时第1列全涂，返回3
```

**数据范围：**
- m == mat.length, n == mat[0].length
- 1 <= m, n <= 10^5
- 1 <= m * n <= 10^5

## 解题思路

哈希表记录位置 + 行列计数：

1. 先建立 `value -> (row, col)` 的映射
2. 维护每行和每列的已涂格数
3. 每涂一格，更新对应行列计数
4. 若某行计数 == n（列数）或某列计数 == m（行数），返回当前下标

## Python 代码实现

### 方法一：哈希表 + 计数（推荐）

```python
from typing import List

class Solution:
    def firstCompleteIndex(self, arr: List[int], mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])

        # 建立值到坐标的映射
        pos = {}
        for r in range(m):
            for c in range(n):
                pos[mat[r][c]] = (r, c)

        # 每行/列的已涂格数
        row_cnt = [0] * m
        col_cnt = [0] * n

        for i, val in enumerate(arr):
            r, c = pos[val]
            row_cnt[r] += 1
            col_cnt[c] += 1
            # 检查是否完成某行或某列
            if row_cnt[r] == n or col_cnt[c] == m:
                return i

        return -1  # 不会到达
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 建立值到位置的逆映射
2. 维护行列计数，实时判断是否完成

## 易错点

1. 行完成条件是计数 == n（列数），列完成条件是计数 == m（行数）
2. 映射中 val 的范围是 [1, m*n]，直接用字典
