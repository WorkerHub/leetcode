## 题目描述

一家快递公司希望在新城市建立新的服务中心。公司统计了该城市所有客户的位置，并希望能够以此为依据建立新的服务中心，使所有客户到服务中心距离的总和最小。

给你一个数组 `positions`，其中 `positions[i] = [xi, yi]` 表示第 `i` 个客户在二维地图上的位置，返回到所有客户的**欧几里得距离之和最小**的服务中心所在位置与所有客户之间的总距离。

答案与标准答案的误差在 `1e-5` 以内都视为正确。

**提示：**
- `1 <= positions.length <= 50`
- `positions[i].length == 2`
- `0 <= xi, yi <= 100`

## 解题思路

### 模拟退火 / 几何中位数

这是求**加权费马点（几何中位数）**问题。对于最小化欧几里得距离之和，答案是几何中位数，不是算术平均值。

**方法：模拟退火（梯度下降思想）**

从所有点的重心出发，不断向四个方向（上下左右）以步长 `step` 移动，取能使总距离减小的方向。每次迭代后缩小步长，直到步长足够小为止。

## 代码实现

### 方法一：模拟退火（推荐）

```python
import math
from typing import List

class Solution:
    def getMinDistSum(self, positions: List[List[int]]) -> float:
        def total_dist(cx: float, cy: float) -> float:
            # 计算当前点 (cx, cy) 到所有客户的距离之和
            return sum(math.sqrt((cx - x)**2 + (cy - y)**2) for x, y in positions)

        # 初始点：所有客户的重心
        n = len(positions)
        cx = sum(x for x, y in positions) / n
        cy = sum(y for x, y in positions) / n

        step = 100.0  # 初始步长
        # 四个移动方向：上下左右
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while step > 1e-7:
            moved = False
            for dx, dy in directions:
                nx, ny = cx + dx * step, cy + dy * step
                if total_dist(nx, ny) < total_dist(cx, cy):
                    cx, cy = nx, ny
                    moved = True
                    break
            # 如果任何方向都没有改进，缩小步长
            if not moved:
                step *= 0.5

        return total_dist(cx, cy)
```

### 方法二：Weiszfeld 迭代算法（数学方法）

```python
import math
from typing import List

class Solution:
    def getMinDistSum(self, positions: List[List[int]]) -> float:
        def total_dist(cx, cy):
            return sum(math.sqrt((cx - x)**2 + (cy - y)**2) for x, y in positions)

        # 初始点：重心
        n = len(positions)
        cx = sum(x for x, y in positions) / n
        cy = sum(y for x, y in positions) / n

        # Weiszfeld 迭代
        for _ in range(1000):
            wx_sum, wy_sum, w_sum = 0.0, 0.0, 0.0
            for x, y in positions:
                d = math.sqrt((cx - x)**2 + (cy - y)**2)
                if d < 1e-10:
                    continue  # 避免除以零
                w = 1.0 / d
                wx_sum += w * x
                wy_sum += w * y
                w_sum += w
            if w_sum < 1e-10:
                break
            new_cx, new_cy = wx_sum / w_sum, wy_sum / w_sum
            # 判断是否收敛
            if abs(new_cx - cx) < 1e-8 and abs(new_cy - cy) < 1e-8:
                break
            cx, cy = new_cx, new_cy

        return total_dist(cx, cy)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟退火 | O(N * 迭代次数) | O(1) |
| Weiszfeld | O(N * 迭代次数) | O(1) |

实践中迭代次数通常较小，实际效率很高。

## 关键点总结

1. 最小化欧几里得距离之和的点是**几何中位数**，不是算术均值
2. 模拟退火：从重心出发，逐步缩小步长
3. Weiszfeld 算法有更强的数学保证，收敛更快
4. 避免当前点与某客户重合导致除零错误

## 易错点

- 用算术均值（重心）作为答案是错的（只在距离平方和时才正确）
- 模拟退火步长缩减不能太快，`1e-7` 精度要求较高
