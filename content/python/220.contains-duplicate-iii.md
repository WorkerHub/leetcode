## 题目描述

给你一个整数数组 `nums` 和两个整数 `indexDiff` 和 `valueDiff`。

找出满足下述条件的下标对 `(i, j)`：

- `i != j`
- `abs(i - j) <= indexDiff`
- `abs(nums[i] - nums[j]) <= valueDiff`

如果存在，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0
输出：true
解释：可以找出 (i, j) = (0, 3)。
满足下述 3 个条件：
i != j --> 0 != 3
abs(i - j) <= indexDiff --> abs(0 - 3) <= 3
abs(nums[i] - nums[j]) <= valueDiff --> abs(1 - 1) <= 0
```

**示例 2：**

```
输入：nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3
输出：false
解释：尝试所有可能的下标对 (i, j)，都无法满足这 3 个条件，因此返回 false。
```

**提示：**

- `2 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `1 <= indexDiff <= nums.length`
- `0 <= valueDiff <= 10^9`

## 解题思路

这是"存在重复元素"系列的最难版本，需要同时满足索引差和值差的限制。

**核心思想：**

1. **滑动窗口**：维护大小为 `indexDiff` 的窗口
2. **桶排序思想**：将值域划分为大小为 `valueDiff + 1` 的桶
3. **桶内检查**：同一桶内的任意两个数，值差 <= valueDiff
4. **相邻桶检查**：相邻桶之间也可能满足值差条件

**算法流程（桶排序法）：**

1. 将值域划分为桶，桶的大小为 `valueDiff + 1`
2. 维护滑动窗口，窗口内的元素对应的桶存入字典
3. 对于当前元素：
   - 计算它所在的桶号
   - 检查同一桶是否已有元素（必然满足值差）
   - 检查相邻桶是否有满足值差的元素
4. 将当前元素加入桶
5. 窗口移动时，移除最左边元素对应的桶

**其他方法：**
- 滑动窗口 + 有序集合（如 SortedList）
- 滑动窗口 + 暴力检查（会超时）

## Python 代码实现

### 方法一：桶排序（推荐）⭐

```python
class Solution:
    def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool:
        if valueDiff < 0 or indexDiff < 0:
            return False
        
        # 桶的大小
        bucket_size = valueDiff + 1
        buckets = {}  # {桶号: 桶内的值}
        
        for i, num in enumerate(nums):
            # 计算桶号（处理负数）
            bucket_id = num // bucket_size
            
            # 检查同一桶
            if bucket_id in buckets:
                return True
            
            # 检查相邻桶
            if bucket_id - 1 in buckets and abs(num - buckets[bucket_id - 1]) <= valueDiff:
                return True
            if bucket_id + 1 in buckets and abs(num - buckets[bucket_id + 1]) <= valueDiff:
                return True
            
            # 加入当前桶
            buckets[bucket_id] = num
            
            # 维护窗口大小
            if i >= indexDiff:
                # 移除最左边的元素
                old_bucket_id = nums[i - indexDiff] // bucket_size
                del buckets[old_bucket_id]
        
        return False
```

### 方法二：滑动窗口 + 有序集合（需要 sortedcontainers）

```python
class Solution:
    def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool:
        from sortedcontainers import SortedList
        
        window = SortedList()
        
        for i, num in enumerate(nums):
            # 维护窗口大小
            if i > indexDiff:
                window.remove(nums[i - indexDiff - 1])
            
            # 在有序窗口中查找 [num - valueDiff, num + valueDiff] 范围的数
            # 使用二分查找找到 >= num - valueDiff 的位置
            pos = window.bisect_left(num - valueDiff)
            
            # 检查该位置的元素是否满足条件
            if pos < len(window) and abs(window[pos] - num) <= valueDiff:
                return True
            
            window.add(num)
        
        return False
```

### 方法三：滑动窗口 + 暴力检查（会超时，仅供理解）

```python
class Solution:
    def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool:
        """双循环检查"""
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, min(i + indexDiff + 1, n)):
                if abs(nums[i] - nums[j]) <= valueDiff:
                    return True
        return False
```

### 方法四：桶排序（详细注释版）

```python
class Solution:
    def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool:
        """
        桶排序思想：
        将数值范围划分为大小为 valueDiff + 1 的桶
        同一桶内的任意两个数，值差必然 <= valueDiff
        """
        if valueDiff < 0:
            return False
        
        # 桶的大小（+1 是为了处理边界）
        w = valueDiff + 1
        buckets = {}
        
        for i, num in enumerate(nums):
            # 计算桶号
            # 例如 valueDiff=3，则桶大小=4
            # [0,3]->桶0, [4,7]->桶1, [-4,-1]->桶-1
            bucket_id = num // w
            
            # 情况1：同一桶内已有元素
            # 由于桶大小 = valueDiff + 1，同桶元素值差必然 <= valueDiff
            if bucket_id in buckets:
                return True
            
            # 情况2：检查左邻桶
            # 左邻桶的最大值是 bucket_id*w - 1
            # 当前值是 num，需要检查 abs(num - 左邻桶值) <= valueDiff
            if bucket_id - 1 in buckets:
                if abs(num - buckets[bucket_id - 1]) <= valueDiff:
                    return True
            
            # 情况3：检查右邻桶
            if bucket_id + 1 in buckets:
                if abs(num - buckets[bucket_id + 1]) <= valueDiff:
                    return True
            
            # 将当前元素加入桶
            buckets[bucket_id] = num
            
            # 维护滑动窗口
            # 当窗口大小超过 indexDiff 时，移除最左边的元素
            if i >= indexDiff:
                old_num = nums[i - indexDiff]
                old_bucket_id = old_num // w
                del buckets[old_bucket_id]
        
        return False
```

## 复杂度分析

**方法一（桶排序）：**

- **时间复杂度：** O(N)
  - 每个元素处理一次
  - 桶的操作（查找、插入、删除）都是 O(1)
- **空间复杂度：** O(min(N, indexDiff))
  - 窗口内最多 indexDiff 个桶

**方法二（有序集合）：**

- **时间复杂度：** O(N log K)
  - K 是窗口大小 min(N, indexDiff)
  - 二分查找：O(log K)
- **空间复杂度：** O(min(N, indexDiff))

**方法三（暴力）：**

- **时间复杂度：** O(N × indexDiff)
- **空间复杂度：** O(1)

## 关键点总结

1. **桶排序思想**：将值域划分为固定大小的桶，同桶元素值差必然满足
2. **桶的大小**：`valueDiff + 1`，确保同桶元素值差 <= valueDiff
3. **相邻桶检查**：相邻桶的元素也可能满足条件
4. **滑动窗口**：维护索引差限制，超出窗口的桶及时移除
5. **负数处理**：桶号计算 `num // bucket_size` 对负数也适用

## 易错点

1. **桶的大小计算错误**：
   ```python
   # 错误：桶大小设为 valueDiff
   bucket_size = valueDiff  # 错误
   # 正确：桶大小应该是 valueDiff + 1
   bucket_size = valueDiff + 1
   ```

2. **负数的桶号计算**：
   ```python
   # Python 的 // 对负数向下取整，已经正确处理
   # -1 // 4 = -1（而不是 0）
   bucket_id = num // bucket_size  # 正确
   ```

3. **相邻桶检查遗漏**：
   ```python
   # 错误：只检查同一桶
   if bucket_id in buckets:
       return True
   # 正确：还要检查相邻桶
   if bucket_id - 1 in buckets and ...:
   if bucket_id + 1 in buckets and ...:
   ```

4. **窗口边界错误**：
   ```python
   # 错误：窗口大小应该是 indexDiff，不是 indexDiff + 1
   if i >= indexDiff + 1:
   # 正确
   if i >= indexDiff:
       del buckets[nums[i - indexDiff] // bucket_size]
   ```

5. **valueDiff = 0 的特殊情况**：
   ```python
   # valueDiff = 0 时，桶大小 = 1
   # 相当于检查完全相同的数
   # 不需要特殊处理，算法仍然适用
   ```

6. **桶内元素覆盖**：
   ```python
   # 每个桶最多存一个元素
   # 因为窗口内不会有两个元素在同一桶
   # （如果有，早就返回 True 了）
   buckets[bucket_id] = num  # 正确
   ```
