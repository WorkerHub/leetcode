## 题目描述

设计 Excel 的求和公式功能。你需要实现一个 `Excel` 类：

- `Excel(int height, char width)` 用给定的高度和宽度初始化对象。高度为 `1 ~ height` 的正整数，宽度为从 'A' 到 `width` 的大写英文字母。
- `void set(int row, char column, int val)` 更改由 `(row, column)` 表示的单元格的值为 `val`。
- `int get(int row, char column)` 返回由 `(row, column)` 表示的单元格的值。
- `int sum(int row, char column, List<String> numbers)` 将单元格 `(row, column)` 的值设置为 `numbers` 中表示的单元格值的总和，并返回该值。这个函数将删除单元格的任何公式或值，并设置该单元格的值为 `numbers` 中的值的总和。

`numbers[i]` 可以是：
- 单个单元格，如 `"A1"`
- 单个单元格范围，如 `"A1:B2"`（表示左上角 A1 到右下角 B2 的所有单元格）

**注意：**
- 你可以假设不会有循环求和引用。例如，A1 = sum(A1:B1) 这种情况不会发生。

**示例：**

```
输入：
["Excel", "set", "sum", "set", "get"]
[[3, "C"], [1, "A", 2], [3, "C", ["A1", "A1:B2"]], [2, "B", 2], [3, "C"]]

输出：
[null, null, 4, null, 6]

解释：
Excel excel = new Excel(3, "C");
excel.set(1, "A", 2);     // 设置 A1 = 2
excel.sum(3, "C", ["A1", "A1:B2"]);  
// C3 = sum(A1, A1:B2) = A1 + A1 + A2 + B1 + B2 = 2 + 2 + 0 + 0 + 0 = 4
excel.set(2, "B", 2);     // 设置 B2 = 2
excel.get(3, "C");        
// C3 应该自动更新为 2 + 2 + 0 + 0 + 2 = 6
```

**提示：**
- `1 <= height <= 26`
- `'A' <= width <= 'Z'`
- `1 <= row <= height`
- `'A' <= column <= width`
- `-100 <= val <= 100`
- `1 <= numbers.length <= 5`
- 保证不会有循环引用

## 解题思路

这道题的核心挑战是实现 **自动更新** 机制：当一个单元格的值改变时，所有依赖它的单元格（通过 sum 公式）也要自动更新。

**关键观察：**

1. **依赖关系图**：单元格之间形成依赖关系（类似图的边）
   - 如果 C3 = sum(A1:B2)，那么 C3 依赖 A1, A2, B1, B2
   - 当 A1 改变时，C3 要自动更新

2. **存储公式而非值**：对于有公式的单元格，存储其依赖的单元格列表，计算时实时求和

3. **两种单元格**：
   - 普通单元格：直接存储值
   - 公式单元格：存储依赖关系，get 时动态计算

**数据结构设计：**

- `cells`：存储单元格的值（普通单元格）或 None（公式单元格）
- `formulas`：存储每个单元格的公式（依赖的单元格列表）

**算法流程：**

- `set(row, col, val)`：设置值，清除公式
- `get(row, col)`：如果有公式，递归计算；否则返回值
- `sum(row, col, numbers)`：解析 numbers，存储公式

## Python 代码实现

### 方法一：递归计算（推荐）

```python
from typing import List
from collections import defaultdict

class Excel:
    def __init__(self, height: int, width: str):
        """
        初始化 Excel 表格
        
        参数:
            height: 行数（1 到 height）
            width: 列宽（'A' 到 width）
        """
        self.height = height
        self.width = ord(width) - ord('A') + 1
        
        # 存储单元格的值（普通单元格）
        self.cells = {}
        
        # 存储单元格的公式（依赖的单元格列表）
        # 格式：{(row, col): [(r1, c1), (r2, c2), ...]}
        self.formulas = {}
    
    def _parse_cell(self, cell_str: str) -> tuple:
        """解析单元格字符串，如 'A1' -> (1, 0)"""
        col = ord(cell_str[0]) - ord('A')
        row = int(cell_str[1:])
        return (row, col)
    
    def _parse_range(self, range_str: str) -> List[tuple]:
        """
        解析单元格范围，如 'A1:B2' -> [(1,0), (1,1), (2,0), (2,1)]
        或单个单元格 'A1' -> [(1, 0)]
        """
        cells = []
        
        if ':' in range_str:
            # 范围：'A1:B2'
            start, end = range_str.split(':')
            r1, c1 = self._parse_cell(start)
            r2, c2 = self._parse_cell(end)
            
            for r in range(r1, r2 + 1):
                for c in range(c1, c2 + 1):
                    cells.append((r, c))
        else:
            # 单个单元格：'A1'
            cells.append(self._parse_cell(range_str))
        
        return cells
    
    def set(self, row: int, column: str, val: int) -> None:
        """设置单元格的值"""
        col = ord(column) - ord('A')
        key = (row, col)
        
        # 设置值
        self.cells[key] = val
        
        # 清除公式（如果有）
        if key in self.formulas:
            del self.formulas[key]
    
    def get(self, row: int, column: str) -> int:
        """获取单元格的值"""
        col = ord(column) - ord('A')
        key = (row, col)
        
        # 如果有公式，递归计算
        if key in self.formulas:
            total = 0
            for cell in self.formulas[key]:
                r, c = cell
                # 递归获取依赖单元格的值
                col_char = chr(ord('A') + c)
                total += self.get(r, col_char)
            return total
        
        # 否则返回存储的值
        return self.cells.get(key, 0)
    
    def sum(self, row: int, column: str, numbers: List[str]) -> int:
        """设置单元格为公式"""
        col = ord(column) - ord('A')
        key = (row, col)
        
        # 解析所有依赖的单元格
        dependent_cells = []
        for num_str in numbers:
            dependent_cells.extend(self._parse_range(num_str))
        
        # 存储公式
        self.formulas[key] = dependent_cells
        
        # 清除直接值（如果有）
        if key in self.cells:
            del self.cells[key]
        
        # 返回当前计算的值
        return self.get(row, column)
```

### 方法二：带缓存的优化版本

```python
class Excel:
    def __init__(self, height: int, width: str):
        self.cells = {}
        self.formulas = {}
        self.cache = {}  # 缓存计算结果
    
    def _parse_cell(self, cell_str: str) -> tuple:
        col = ord(cell_str[0]) - ord('A')
        row = int(cell_str[1:])
        return (row, col)
    
    def _parse_range(self, range_str: str) -> List[tuple]:
        cells = []
        if ':' in range_str:
            start, end = range_str.split(':')
            r1, c1 = self._parse_cell(start)
            r2, c2 = self._parse_cell(end)
            for r in range(r1, r2 + 1):
                for c in range(c1, c2 + 1):
                    cells.append((r, c))
        else:
            cells.append(self._parse_cell(range_str))
        return cells
    
    def set(self, row: int, column: str, val: int) -> None:
        col = ord(column) - ord('A')
        key = (row, col)
        self.cells[key] = val
        if key in self.formulas:
            del self.formulas[key]
        # 清除缓存
        self.cache.clear()
    
    def get(self, row: int, column: str) -> int:
        col = ord(column) - ord('A')
        key = (row, col)
        
        # 检查缓存
        if key in self.cache:
            return self.cache[key]
        
        if key in self.formulas:
            total = 0
            for cell in self.formulas[key]:
                r, c = cell
                col_char = chr(ord('A') + c)
                total += self.get(r, col_char)
            self.cache[key] = total
            return total
        
        return self.cells.get(key, 0)
    
    def sum(self, row: int, column: str, numbers: List[str]) -> int:
        col = ord(column) - ord('A')
        key = (row, col)
        
        dependent_cells = []
        for num_str in numbers:
            dependent_cells.extend(self._parse_range(num_str))
        
        self.formulas[key] = dependent_cells
        
        if key in self.cells:
            del self.cells[key]
        
        # 清除缓存
        self.cache.clear()
        
        return self.get(row, column)
```

## 复杂度分析

**方法一（递归）：**
- `set`: O(1)
- `get`: O(d)，d 是依赖深度（递归计算所有依赖）
- `sum`: O(n)，n 是 numbers 中涉及的单元格数量

**方法二（缓存）：**
- `set`: O(1)（清除缓存是 O(1) 均摊）
- `get`: O(d) 首次，O(1) 缓存命中
- `sum`: O(n)

**空间复杂度：** O(h * w)，h 是高度，w 是宽度

## 关键点总结

1. **公式与值分离**：用两个字典分别存储普通值和公式
2. **递归计算**：get 时如果有公式，递归计算所有依赖单元格
3. **范围解析**：正确解析 'A1:B2' 这样的范围表示
4. **清除机制**：set 时要清除公式，sum 时要清除旧值
5. **默认值**：未设置的单元格默认为 0

## 易错点

1. **坐标转换**：
   - 列：字符 'A' -> 数字 0
   - 行：从 1 开始，不是 0

2. **范围解析错误**：
   ```python
   # 错误：忘记处理单个单元格
   if ':' in range_str:
       # 只处理范围，单个单元格会漏掉
   
   # 正确：分别处理
   if ':' in range_str:
       # 范围
   else:
       # 单个单元格
   ```

3. **忘记清除**：
   - set 时要清除公式
   - sum 时要清除旧值

4. **重复计数**：'A1:B2' 包含 A1, A2, B1, B2，如果 numbers = ['A1', 'A1:B2']，A1 会被计算两次（这是正确的）

5. **循环引用**：题目保证不会有，但实际应用中需要检测
