## 题目描述

给定一个不重复的整数数组 `nums`。**最大二叉树**可以用下面的算法从 `nums` 递归地构建:

1. 创建一个根节点，其值为 `nums` 中的最大值。
2. 递归地在最大值**左边**的**子数组前缀**上构建左子树。
3. 递归地在最大值**右边**的**子数组后缀**上构建右子树。

返回 `nums` 构建的**最大二叉树**。

**示例 1:**

```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,null,0,null,null,2,null,1]
解释：递归调用如下所示：
- [3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 [3,2,1] ，右边部分是 [0,5] 。
    - [3,2,1] 中的最大值是 3 ，左边部分是 [] ，右边部分是 [2,1] 。
        - 空数组，无子节点。
        - [2,1] 中的最大值是 2 ，左边部分是 [] ，右边部分是 [1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - [0,5] 中的最大值是 5 ，左边部分是 [0] ，右边部分是 [] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。
```

**示例 2:**

```
输入：nums = [3,2,1]
输出：[3,null,2,null,1]
```

**提示:**
- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- `nums` 中的所有整数**互不相同**

## 解题思路

这是一道典型的**分治**问题，也可以用**单调栈**优化。

### 思路一：递归分治（最直观）

按照题目描述直接递归构建：

1. 找到数组中的最大值及其索引
2. 最大值作为根节点
3. 最大值左边的子数组构建左子树
4. 最大值右边的子数组构建右子树

**时间复杂度分析：**
- 最好情况 O(n log n)：数组递增或递减，每次二分
- 最坏情况 O(n²)：数组有序，每次只减少一个元素

### 思路二：单调栈（优化到 O(n)）

观察规律：
- 从左到右扫描数组
- 对于当前数字 `nums[i]`：
  - 它左边比它小的最近的数字是它的某个祖先的左子树
  - 它左边比它大的最近的数字是它的父节点

使用**单调递减栈**：
- 栈中存储节点，保持从栈底到栈顶递减
- 遇到更大的数时，弹出栈中较小的数

## Python 代码实现

### 方法一：递归分治（推荐新手）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        """
        递归构建最大二叉树
        """
        if not nums:
            return None
        
        # 找到最大值及其索引
        max_val = max(nums)
        max_idx = nums.index(max_val)
        
        # 创建根节点
        root = TreeNode(max_val)
        
        # 递归构建左右子树
        root.left = self.constructMaximumBinaryTree(nums[:max_idx])
        root.right = self.constructMaximumBinaryTree(nums[max_idx + 1:])
        
        return root
```

### 方法二：递归 + 索引优化（避免数组切片）

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        """
        使用索引代替切片，减少空间开销
        """
        def build(left: int, right: int) -> Optional[TreeNode]:
            """构建 nums[left:right] 的最大二叉树"""
            if left >= right:
                return None
            
            # 找到最大值的索引
            max_idx = left
            for i in range(left + 1, right):
                if nums[i] > nums[max_idx]:
                    max_idx = i
            
            # 创建根节点
            root = TreeNode(nums[max_idx])
            
            # 递归构建左右子树
            root.left = build(left, max_idx)
            root.right = build(max_idx + 1, right)
            
            return root
        
        return build(0, len(nums))
```

### 方法三：单调栈（最优解）⭐

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        """
        使用单调递减栈，O(n) 时间复杂度
        """
        stack = []  # 单调递减栈
        
        for num in nums:
            # 创建当前节点
            node = TreeNode(num)
            
            # 当栈顶元素小于当前值时，弹出并作为当前节点的左子树
            while stack and stack[-1].val < num:
                node.left = stack.pop()
            
            # 如果栈不为空，当前节点是栈顶的右子节点
            if stack:
                stack[-1].right = node
            
            # 当前节点入栈
            stack.append(node)
        
        # 栈底元素是根节点
        return stack[0] if stack else None
```

### 方法四：单调栈（更清晰的版本）

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        """
        单调栈的另一种实现，更容易理解
        """
        stack = []
        
        for num in nums:
            curr = TreeNode(num)
            last = None
            
            # 弹出所有小于当前值的节点
            while stack and stack[-1].val < num:
                last = stack.pop()
            
            # 最后弹出的节点作为当前节点的左子树
            if last:
                curr.left = last
            
            # 如果栈不为空，当前节点作为栈顶的右子树
            if stack:
                stack[-1].right = curr
            
            stack.append(curr)
        
        return stack[0]
```

## 复杂度分析

### 方法一：递归分治
- **时间复杂度**：O(n²) 最坏情况（数组有序），O(n log n) 平均情况
- **空间复杂度**：O(n)，递归栈 + 数组切片

### 方法二：递归 + 索引优化
- **时间复杂度**：O(n²) 最坏情况
- **空间复杂度**：O(h)，h 为树高，只有递归栈

### 方法三/四：单调栈
- **时间复杂度**：O(n)，每个元素最多入栈出栈一次
- **空间复杂度**：O(n)，栈的大小

## 图解示例

示例 1：`nums = [3,2,1,6,0,5]`

**递归过程：**

```
第1步：[3,2,1,6,0,5] -> 最大值 6
        6
       / \
     [3,2,1] [0,5]

第2步：左子树 [3,2,1] -> 最大值 3
        6
       / \
      3   [0,5]
       \
      [2,1]

第3步：右子树 [2,1] -> 最大值 2
        6
       / \
      3   [0,5]
       \
        2
         \
         [1]

...最终结果：
        6
       / \
      3   5
       \ /
        2 0
         \
          1
```

**单调栈过程：**

```
处理 3: stack = [3]
处理 2: stack = [3, 2]  (2 < 3，作为3的右子节点)
处理 1: stack = [3, 2, 1]  (1 < 2，作为2的右子节点)
处理 6: stack = [6]  (弹出3,2,1，它们构成6的左子树)
        3 -> 2 -> 1 作为 6 的左子树
处理 0: stack = [6, 0]  (0 < 6，作为6的右子节点)
处理 5: stack = [6, 5]  (弹出0，0作为5的左子节点；5作为6的右子节点)
```

## 关键点总结

1. **分治思想**：递归地将问题分解为子问题
2. **最大值分割**：最大值作为根，分割左右子数组
3. **单调栈优化**：利用单调性质，O(n) 时间构建
4. **栈的性质**：单调递减栈维护可能的父节点
5. **左右子树规律**：弹出的节点作为左子树，新节点作为右子树

## 易错点

1. **数组切片边界**：
   ```python
   # 注意索引范围
   left = nums[:max_idx]      # 不包含 max_idx
   right = nums[max_idx + 1:] # 不包含 max_idx
   ```

2. **空数组处理**：
   ```python
   if not nums:
       return None
   ```

3. **单调栈的左右子树关系**：
   ```python
   # 弹出的节点是左子树
   while stack and stack[-1].val < num:
       node.left = stack.pop()  # 不断更新，最后一个是直接左子节点
   
   # 当前节点是栈顶的右子节点
   if stack:
       stack[-1].right = node
   ```

4. **单调栈返回值**：
   ```python
   # 返回栈底元素（最大值）
   return stack[0]  # 不是 stack[-1]
   ```

5. **找最大值的方法**：
   ```python
   max_val = max(nums)
   max_idx = nums.index(max_val)  # 找到第一个最大值的位置
   ```

4. **对比总结**：
   - 递归：直观，易实现，但可能较慢
   - 单调栈：高效，O(n)，但需要理解

   - 记录节点的左右子树连接情况

**常见问题：**

Q: 单调栈为什么是 O(n)？
A: 每个元素最多入栈一次、出栈一次，总操作次数是 2n。

Q: 单调栈中弹出的节点为什么是左子树？
A: 因为弹出的是之前遍历过的（在左边的）且比当前值小的节点。

Q: 什么时候用递归，什么时候用单调栈？
A: 递归简单直观，适合理解和实现；单调栈高效，适合追求性能。
