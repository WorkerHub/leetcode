## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，返回 `nums` 中异或值恰好等于 `k` 的子集数目（模 `10^9 + 7`）。

**示例 1：**

```
输入：nums = [1, 2, 3], k = 1
输出：2
解释：
- 子集 {1}：异或值为 1
- 子集 {2, 3}：异或值为 1
共 2 个子集。
```

**示例 2：**

```
输入：nums = [0], k = 0
输出：2
解释：空集异或值为 0，子集 {0} 异或值为 0，共 2 个。
```

**提示：**
- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 10^6`
- `0 <= k <= 10^6`

## 解题思路

使用**位运算 DP**（也称异或背包）：
- `dp[x]` 表示异或值为 x 的子集数目。
- 初始状态：`dp[0] = 1`（空集的异或值为 0）。
- 对每个元素 `num`，更新：`dp[x ^ num] += dp[x]`（用当前元素更新所有状态）。
- 注意要倒序或使用新数组避免重复使用同一元素。

## Python 代码实现

### 方法一：异或 DP（推荐）

```python
from typing import List

class Solution:
    def countSubsets(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[x] = 异或值为 x 的子集数目
        max_xor = 1 << 20  # nums[i] <= 10^6 < 2^20
        dp = [0] * max_xor
        dp[0] = 1  # 空集

        for num in nums:
            # 倒序遍历避免重复选取（0-1 背包思路）
            # 但 XOR 的特殊性：需要从后往前或使用临时数组
            new_dp = dp[:]
            for x in range(max_xor):
                if dp[x]:
                    new_dp[x ^ num] = (new_dp[x ^ num] + dp[x]) % MOD
            dp = new_dp

        return dp[k]
```

### 方法二：回溯枚举（适用于小数组）

```python
from typing import List

class Solution:
    def countSubsets(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        count = 0

        # 枚举所有 2^n 个子集
        for mask in range(1 << n):
            xor_val = 0
            for i in range(n):
                if mask & (1 << i):
                    xor_val ^= nums[i]
            if xor_val == k:
                count = (count + 1) % MOD

        return count
```

## 复杂度分析

- 时间复杂度：
  - 方法一：O(n * 2^20)，每个元素更新全部 DP 状态
  - 方法二：O(n * 2^n)，枚举所有子集
- 空间复杂度：O(2^20) = O(10^6)（方法一）；O(1)（方法二除递归栈）

## 关键点总结

1. 异或 DP 是 XOR 类子集计数的标准做法。
2. 每次用新数组 `new_dp` 存储更新结果，避免同一元素多次选取。
3. 当 n 较小时（n <= 20），位枚举暴力法也可通过。

## 易错点

1. 不能原地更新 dp 数组，否则会重复选取同一元素。
2. XOR 的最大值为所有 nums[i] 的 OR，需正确设置 dp 数组大小。
3. k 可能为 0，需要包含空集（dp[0] 初始为 1）。
