## 题目描述

给你一个正整数数组 `nums`，你需要从中任选一些子集，然后将子集中每个数乘以一个**任意整数**，并求出他们的和。

假如该和结果为 `1`，那么原数组就是一个「好数组」，则返回 `True`；否则请返回 `False`。

**示例 1：**
```
输入：nums = [12,5,7,23]
输出：true
解释：挑选数字 5 和 7。
5*3 + 7*(-2) = 1
```

**示例 2：**
```
输入：nums = [29,6,10]
输出：true
解释：挑选数字 29, 6 和 10。
29*1 + 6*(-3) + 10*(-1) = 1
```

**示例 3：**
```
输入：nums = [3,6]
输出：false
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

这道题看似复杂，实际上是一道数论问题，核心在于理解**贝祖定理（Bézout's Identity）**。

**关键理论：贝祖定理**

贝祖定理指出：对于整数 a 和 b，如果存在整数 x 和 y 使得 `ax + by = d`，那么 d 一定是 a 和 b 的最大公约数 gcd(a, b) 的倍数。

推广到多个整数：对于整数 a₁, a₂, ..., aₙ，如果存在整数 x₁, x₂, ..., xₙ 使得 `a₁x₁ + a₂x₂ + ... + aₙxₙ = 1`，那么这些整数的最大公约数必须为 1。

**转化问题：**

题目要求判断是否能从数组中选取若干数字，通过线性组合得到 1。根据贝祖定理，这等价于判断：
- **数组中所有数字的最大公约数是否为 1**

**算法流程：**
1. 计算数组中所有数字的最大公约数（GCD）
2. 如果 GCD = 1，返回 True
3. 否则返回 False

**为什么这样做？**
- 如果 gcd(nums) = 1，说明这些数互质，根据贝祖定理，一定存在整数系数使得线性组合等于 1
- 如果 gcd(nums) > 1，那么任何线性组合的结果都是 gcd 的倍数，不可能等于 1

## Python 代码实现

### 方法一：使用 math.gcd（推荐）

```python
from typing import List
import math

class Solution:
    def isGoodArray(self, nums: List[int]) -> bool:
        # 计算数组所有元素的最大公约数
        result = nums[0]
        for num in nums[1:]:
            result = math.gcd(result, num)
            # 优化：如果 GCD 已经是 1，可以提前返回
            if result == 1:
                return True
        
        return result == 1
```

**时间复杂度：** O(n log m)，其中 n 是数组长度，m 是数组中的最大值，gcd 计算的时间复杂度是 O(log m)  
**空间复杂度：** O(1)

### 方法二：使用 functools.reduce

```python
from typing import List
import math
from functools import reduce

class Solution:
    def isGoodArray(self, nums: List[int]) -> bool:
        # 使用 reduce 函数对数组所有元素求 GCD
        return reduce(math.gcd, nums) == 1
```

**时间复杂度：** O(n log m)  
**空间复杂度：** O(1)

### 方法三：手动实现 GCD（教学版）

```python
from typing import List

class Solution:
    def isGoodArray(self, nums: List[int]) -> bool:
        def gcd(a: int, b: int) -> int:
            """辗转相除法（欧几里得算法）计算最大公约数"""
            while b:
                a, b = b, a % b
            return a
        
        # 计算数组所有元素的 GCD
        result = nums[0]
        for num in nums[1:]:
            result = gcd(result, num)
            # 提前退出优化
            if result == 1:
                return True
        
        return result == 1
```

**时间复杂度：** O(n log m)  
**空间复杂度：** O(1)

### 方法四：递归实现

```python
from typing import List
import math

class Solution:
    def isGoodArray(self, nums: List[int]) -> bool:
        def array_gcd(arr: List[int], index: int) -> int:
            """递归计算数组 GCD"""
            if index == len(arr) - 1:
                return arr[index]
            return math.gcd(arr[index], array_gcd(arr, index + 1))
        
        return array_gcd(nums, 0) == 1
```

**时间复杂度：** O(n log m)  
**空间复杂度：** O(n)，递归调用栈

## 复杂度分析

所有方法的时间复杂度都是 O(n log m)，其中：
- n 是数组长度
- m 是数组中的最大值
- 每次 GCD 计算的时间复杂度是 O(log m)

**方法对比：**
- 方法一：最清晰，有提前退出优化
- 方法二：最简洁，利用 Python 函数式编程
- 方法三：教学用，展示 GCD 的实现原理
- 方法四：递归风格，但有额外的空间开销

实际应用中推荐使用方法一或方法二。

## 图解示例

以 `nums = [12, 5, 7, 23]` 为例：

```
Step 1: gcd(12, 5)
        12 = 5 * 2 + 2
        5 = 2 * 2 + 1
        2 = 1 * 2 + 0
        → gcd(12, 5) = 1

Step 2: gcd(1, 7) = 1（任何数与1的GCD都是1）

Step 3: gcd(1, 23) = 1

最终 GCD = 1 → 返回 True
```

验证线性组合：`5 * 3 + 7 * (-2) = 15 - 14 = 1` ✓

以 `nums = [3, 6]` 为例：

```
gcd(3, 6) = 3

任何形式的 3x + 6y = 3(x + 2y) 都是3的倍数，不可能等于1
→ 返回 False
```

## 关键点总结

1. **贝祖定理是核心**：理解线性组合与最大公约数的关系
2. **问题转化**：将复杂的线性组合问题转化为简单的 GCD 计算
3. **GCD 的性质**：
   - gcd(a, b, c) = gcd(gcd(a, b), c)
   - 任何数与 1 的 GCD 都是 1
4. **提前退出优化**：一旦 GCD 为 1，可以立即返回
5. **数学背景**：这道题需要数论基础，属于数学类的困难题

## 易错点

1. **误解题意**：容易被"任意整数"和"子集"误导，实际上只需要关注 GCD
2. **忘记贝祖定理**：不知道这个定理很难想到解法，会尝试复杂的动态规划
3. **GCD 计算错误**：
   - 注意 GCD 的计算顺序不影响结果：gcd(a, b, c) = gcd(a, gcd(b, c)) = gcd(gcd(a, b), c)
4. **边界情况**：
   - 单个元素：`[1]` → True，`[2]` → False
   - 全是相同数字：`[6, 6, 6]` → False（gcd = 6）
5. **溢出问题**：虽然数字可能很大（10^9），但 GCD 不会溢出，Python 自动处理大整数
