## 题目描述

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：

- 只使用数字 1 到 9
- 每个数字最多使用一次

返回所有可能的有效组合的列表。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

**示例 1：**

```
输入：k = 3, n = 7
输出：[[1,2,4]]
解释：
1 + 2 + 4 = 7
没有其他符合的组合了。
```

**示例 2：**

```
输入：k = 3, n = 9
输出：[[1,2,6],[1,3,5],[2,3,4]]
解释：
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。
```

**示例 3：**

```
输入：k = 4, n = 1
输出：[]
解释：不存在有效的组合。
在 [1,9] 范围内使用 4 个不同的数字，我们可以得到的最小和是 1+2+3+4 = 10，因为 10 > 1，没有有效的组合。
```

**提示：**

- `2 <= k <= 9`
- `1 <= n <= 60`

## 解题思路

这是经典的回溯（Backtracking）问题，类似于组合问题，但增加了和的约束。

**核心思想：**

1. **回溯搜索**：从 1 到 9 中选择 k 个数，使其和为 n
2. **剪枝优化**：
   - 如果当前和已经超过 n，停止搜索
   - 如果剩余数字不够，停止搜索
   - 如果剩余数字的最小和都大于目标，停止搜索

**算法流程：**

1. 定义回溯函数 `backtrack(start, path, current_sum)`
2. 终止条件：
   - 如果 `len(path) == k` 且 `current_sum == n`，加入结果
   - 如果 `len(path) == k` 但和不等于 n，返回
   - 如果 `current_sum > n`，返回（剪枝）
3. 递归：从 `start` 到 9，依次选择数字
4. 回溯：移除最后一个数字，尝试其他选择

## Python 代码实现

### 方法一：回溯 + 剪枝（推荐）⭐

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result = []
        
        def backtrack(start: int, path: List[int], current_sum: int):
            # 剪枝：和已经超过目标
            if current_sum > n:
                return
            
            # 找到一个有效组合
            if len(path) == k:
                if current_sum == n:
                    result.append(path[:])
                return
            
            # 剪枝：剩余数字不够
            if 9 - start + 1 < k - len(path):
                return
            
            # 从 start 到 9 选择数字
            for num in range(start, 10):
                path.append(num)
                backtrack(num + 1, path, current_sum + num)
                path.pop()  # 回溯
        
        backtrack(1, [], 0)
        return result
```

### 方法二：回溯 + 更多剪枝

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result = []
        
        def backtrack(start: int, path: List[int], current_sum: int):
            # 剪枝1：和已经超过目标
            if current_sum > n:
                return
            
            # 剪枝2：已选 k 个数
            if len(path) == k:
                if current_sum == n:
                    result.append(path[:])
                return
            
            # 剩余需要选择的数字个数
            remain_count = k - len(path)
            # 剪枝3：剩余数字不够
            if 9 - start + 1 < remain_count:
                return
            
            # 剪枝4：剩余最小和都大于目标
            # 剩余最小和 = start + (start+1) + ... + (start+remain_count-1)
            min_sum = remain_count * start + remain_count * (remain_count - 1) // 2
            if current_sum + min_sum > n:
                return
            
            # 剪枝5：剩余最大和都小于目标
            # 剩余最大和 = 9 + 8 + ... + (9-remain_count+1)
            max_sum = remain_count * 9 - remain_count * (remain_count - 1) // 2
            if current_sum + max_sum < n:
                return
            
            for num in range(start, 10):
                path.append(num)
                backtrack(num + 1, path, current_sum + num)
                path.pop()
        
        backtrack(1, [], 0)
        return result
```

### 方法三：迭代版本（使用栈）

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result = []
        stack = [(1, [], 0)]  # (起始数字, 当前路径, 当前和)
        
        while stack:
            start, path, current_sum = stack.pop()
            
            # 找到有效组合
            if len(path) == k:
                if current_sum == n:
                    result.append(path)
                continue
            
            # 剪枝
            if current_sum >= n:
                continue
            
            # 从大到小遍历（栈的特性）
            for num in range(9, start - 1, -1):
                if current_sum + num <= n:
                    stack.append((num + 1, path + [num], current_sum + num))
        
        return result
```

### 方法四：简洁版（易理解）

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result = []
        
        def backtrack(start: int, path: List[int]):
            # 找到有效组合
            if len(path) == k and sum(path) == n:
                result.append(path[:])
                return
            
            # 剪枝：数字已经够了
            if len(path) == k:
                return
            
            # 选择数字
            for num in range(start, 10):
                # 剪枝：和已经超过
                if sum(path) + num > n:
                    break
                path.append(num)
                backtrack(num + 1, path)
                path.pop()
        
        backtrack(1, [])
        return result
```

## 复杂度分析

**方法一（回溯 + 剪枝）：**

- **时间复杂度：** O(C(9, k))，最多从 9 个数中选 k 个
  - 实际复杂度远小于此，因为剪枝大幅减少搜索空间
- **空间复杂度：** O(k)
  - 递归栈深度：O(k)
  - 路径数组：O(k)

**方法三（迭代）：**

- **时间复杂度：** O(C(9, k))
- **空间复杂度：** O(k × 结果数量)，栈中存储路径副本

## 关键点总结

1. **回溯模板**：选择 → 递归 → 撤销选择
2. **去重策略**：通过 `start` 参数保证只向后选择，避免重复
3. **剪枝优化**：
   - 和超过目标：提前返回
   - 数字不够：提前返回
   - 最小和/最大和检查：减少无效搜索
4. **边界处理**：`len(path) == k` 时检查和是否等于 n
5. **路径复制**：`result.append(path[:])` 而不是 `path`

## 易错点

1. **忘记复制路径**：
   ```python
   # 错误：path 会继续变化
   result.append(path)
   # 正确：复制一份
   result.append(path[:])
   ```

2. **去重逻辑错误**：
   ```python
   # 错误：从 1 开始会产生重复
   for num in range(1, 10):
   # 正确：从 start 开始
   for num in range(start, 10):
   ```

3. **剪枝条件遗漏**：
   ```python
   # 不剪枝会超时
   if current_sum > n:
       return
   ```

4. **边界情况未处理**：
   ```python
   # k=9, n=45 时，结果是 [1,2,3,4,5,6,7,8,9]
   # k=2, n=1 时，结果是 []（最小和是 1+2=3）
   ```

5. **sum() 重复计算**：
   ```python
   # 效率低：每次都重新计算 sum
   if sum(path) > n:
   # 优化：传递 current_sum 参数
   if current_sum > n:
   ```
