## 题目描述

给你一个下标从 **0** 开始的字符串 `word`，字符串只包含小写英文字母。你需要从 `word` 中选出一个字母，**仅** 删除一个该字母的 **出现次数**，使得 `word` 中剩余每个字母出现的频率都相同。

返回是否可以完成此操作。

**注意：** 字母的 **频率** 是指这个字母在 `word` 中的出现次数。

**示例 1：**
```
输入：word = "abcc"
输出：true
解释：删除一个 'c'，使得 "abc" 中每个字母出现 1 次。
```

**示例 2：**
```
输入：word = "aazz"
输出：false
解释：无法使每个字母出现次数相同。
```

**提示：**
- `2 <= word.length <= 100`
- `word` 由小写英文字母组成

## 解题思路

统计每个字母的频率，然后枚举每个字母（最多 26 个），将其频率减一后，检查所有字母的频率是否都相等。

**特殊情况：**
1. 删除后某字母频率为 0，等同于从字母表中移除该字母
2. 检查剩余字母频率是否全部相同

## 代码实现

### 方法一：枚举 + 验证（推荐）

```python
from collections import Counter

class Solution:
    def equalFrequency(self, word: str) -> bool:
        count = Counter(word)

        for ch in list(count.keys()):
            # 尝试将字母 ch 的频率减一
            count[ch] -= 1

            if count[ch] == 0:
                del count[ch]  # 移除频率为 0 的字母

            # 检查所有剩余字母频率是否相同
            if len(set(count.values())) == 1:
                return True

            # 恢复：撤销修改
            count[ch] = count.get(ch, 0) + 1
            # 若之前删掉了（频率为0），需要重新添加
            if count[ch] == 0:
                # 不应出现此情况，因为原始频率 >= 1
                pass

        return False
```

### 方法二：更简洁的枚举

```python
from collections import Counter

class Solution:
    def equalFrequency(self, word: str) -> bool:
        freq = Counter(word)

        for ch in set(word):
            # 临时减少字母 ch 的频率
            freq[ch] -= 1

            # 如果频率降为 0，该字母不再计入
            remaining = {f for f in freq.values() if f > 0}

            # 剩余所有字母频率相同则成功
            if len(remaining) == 1:
                freq[ch] += 1
                return True

            freq[ch] += 1  # 恢复

        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 + 验证 | O(26 * 26) = O(1) | O(1) |

字母最多 26 种，每次验证 O(26)，总体 O(1)。

## 关键点总结

1. 枚举每个出现的字母，临时减去一次出现，检查频率是否均等
2. 频率为 0 的字母从字母表中移除（不参与频率比较）
3. 验证时只需检查非零频率的集合大小是否为 1

## 易错点

- 必须在检查后恢复频率（枚举下一个字母时需要原始频率）
- 频率减为 0 时，该字母应被排除在比较之外
- 单独一个字母的字符串：只有一种字母，任何操作后频率集合大小为 0 或 1
