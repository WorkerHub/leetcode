## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

定义下标 `i` 和 `j`（i < j）为 **平衡** 的，如果满足：`nums[j] - nums[i] >= j - i`。

选取下标的子序列（保持原始顺序），若其中相邻下标两两平衡，则称该子序列为 **平衡子序列**。

返回所有平衡子序列的元素和的最大值（子序列可以为空，空子序列和为 0）。

**示例 1：**
```
输入：nums = [3,3,5,6]
输出：14
解释：选 [3,5,6]，和为 14
```

**示例 2：**
```
输入：nums = [5,-1,-3,8]
输出：13
解释：选 [5,8]，和为 13
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

条件 `nums[j] - nums[i] >= j - i` 等价于 `nums[j] - j >= nums[i] - i`。

令 `a[i] = nums[i] - i`，则条件变为 `a[j] >= a[i]`（即 a 值不减）。

问题转化：在数组 `a` 中选取一个不减子序列，使得对应 `nums` 元素之和最大。

定义 `dp[i]` = 以下标 i 结尾的最大平衡子序列和。

`dp[i] = nums[i] + max(0, max{dp[j] : j < i 且 a[j] <= a[i]})`

使用树状数组（离散化 a 值后）维护前缀最大值。

## Python 代码实现

### 方法一：树状数组 + 离散化（推荐）

```python
from typing import List

class Solution:
    def maxBalancedSubsequenceSum(self, nums: List[int]) -> int:
        n = len(nums)
        # a[i] = nums[i] - i
        a = [nums[i] - i for i in range(n)]

        # 离散化 a
        sorted_a = sorted(set(a))
        rank = {v: idx + 1 for idx, v in enumerate(sorted_a)}
        m = len(sorted_a)

        # 树状数组：维护前缀最大值
        # bit[i] = 在 a 值 rank <= i 的所有下标中，dp 的最大值
        bit = [-float('inf')] * (m + 2)

        def update(i, val):
            while i <= m:
                if bit[i] < val:
                    bit[i] = val
                i += i & (-i)

        def query(i):
            res = -float('inf')
            while i > 0:
                if bit[i] > res:
                    res = bit[i]
                i -= i & (-i)
            return res

        import bisect

        ans = max(nums)  # 至少选一个元素（最大单个元素）

        for i in range(n):
            r = rank[a[i]]
            # 查询 a[j] <= a[i] 的最大 dp 值
            prev_max = query(r)
            dp_i = nums[i] + max(0, prev_max)
            ans = max(ans, dp_i)
            # 更新
            update(r, dp_i)

        return ans
```

### 方法二：排序 + 贪心（思路验证）

```python
from typing import List

class Solution:
    def maxBalancedSubsequenceSum(self, nums: List[int]) -> int:
        n = len(nums)
        a = [nums[i] - i for i in range(n)]

        # dp[i] = 以 i 结尾的最大平衡子序列和（暴力版，O(n^2)）
        dp = list(nums)  # 单独选自己
        for i in range(n):
            for j in range(i):
                if a[j] <= a[i] and dp[j] > 0:
                    dp[i] = max(dp[i], dp[j] + nums[i])

        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(n log n)，离散化排序 + 树状数组操作
- 空间复杂度：O(n)，树状数组和离散化映射

## 关键点总结

1. 关键变换：`nums[j] - j >= nums[i] - i`，将二维条件降为一维
2. 树状数组维护前缀最大值（区别于前缀和），支持 `query(rank)` = `a 值 <= sorted_a[rank-1]` 的最大 dp
3. 空子序列和为 0，单个元素也可以选

## 易错点

1. 前缀最大值树状数组的 update 操作取 max，而非加法
2. 负数元素：若 prev_max <= 0，不如不选前驱，从自身开始（dp_i = nums[i]）
3. 答案可能是负数（所有 nums[i] 为负时，最优选最大的单个负数）
