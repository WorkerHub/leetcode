## 题目描述

给你一个正整数数组 `nums`，返回 `nums` 中所有非空子集的按位 OR 结果中，**最小的** 无法被表示的正整数。

**示例 1：**

```
输入：nums = [2,1]
输出：4
解释：子集 OR 可以得到 1, 2, 3，无法得到 4。
```

**示例 2：**

```
输入：nums = [5,3,2]
输出：1
解释：任何子集 OR 都不能得到 1（最小元素为 2，但 OR 不减小，1 无法构成）。
```

**提示：**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`

## 解题思路

关键观察：若 2^k 不在 nums 中，则不可能通过 OR 得到任何包含第 k 位的奇数... 实际上：

若 nums 包含所有的 2^0, 2^1, ..., 2^(k-1)，则通过子集 OR 可以表示 1 到 2^k - 1 的所有值。若缺少 2^k（而存在 2^0 到 2^(k-1)），则 2^k 是无法被表示的最小正整数。

贪心：按位从小到大检查，若当前 2^k 在 nums 中，则可以表示 2^k，继续；否则 2^k 就是答案。

## Python 代码实现

### 方法一：检查 2 的幂次（推荐）

```python
from typing import List

class Solution:
    def minImpossibleOR(self, nums: List[int]) -> int:
        num_set = set(nums)
        # 从 1 开始（2^0），检查每个 2 的幂次是否存在
        power = 1
        while power in num_set:
            power *= 2
        return power
```

### 方法二：位枚举

```python
from typing import List

class Solution:
    def minImpossibleOR(self, nums: List[int]) -> int:
        num_set = set(nums)
        for k in range(30):
            if (1 << k) not in num_set:
                return 1 << k
        return 1 << 30
```

## 复杂度分析

- 时间复杂度：O(n + log(max_val))，集合构建 O(n) + 最多检查 30 个幂次
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 若 nums 包含 1, 2, 4, ..., 2^(k-1)，则通过 OR 可表示 [1, 2^k - 1] 的所有值
2. 第一个缺失的 2 的幂次即为答案
3. OR 操作只能增加或保持位的数量，不能减少

## 易错点

1. 查找的是 2 的幂次，不是任意整数
2. 若 1 不在 nums 中，答案直接是 1
3. nums 中可能有重复元素，但集合去重后不影响结果
