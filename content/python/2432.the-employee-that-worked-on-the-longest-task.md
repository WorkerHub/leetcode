## 题目描述

共有 `n` 位员工，每位员工都有一个从 `0` 到 `n - 1` 的唯一 id。

给你一个二维整数数组 `logs`，其中 `logs[i] = [idi, leaveTimei]`：

- `idi` 是处理第 `i` 个任务的员工的 id。
- `leaveTimei` 是员工完成第 `i` 个任务的时间。所有 `leaveTimei` 的值都是 **唯一** 的。

第 `i` 个任务从第 `i - 1` 个任务结束时开始（如果是第 0 个任务，则从时间 `0` 开始）。

返回花费时间 **最长** 的任务对应员工的 id，如果存在两个或多个员工完成任务所花费时间相同且最长，则返回几人中 **员工 id 最小** 的那个。

**示例 1：**
```
输入：n = 10, logs = [[0,3],[2,5],[0,9],[1,15]]
输出：1
解释：员工 1 花费 15-9=6 分钟，是最长的。
```

**示例 2：**
```
输入：n = 26, logs = [[1,1],[3,7],[2,12],[7,17]]
输出：3
解释：
- 任务 0：员工 1，花费 1 分钟
- 任务 1：员工 3，花费 6 分钟
- 任务 2：员工 2，花费 5 分钟
- 任务 3：员工 7，花费 5 分钟
员工 3 花费最长（6 分钟）。
```

**提示：**
- `2 <= n <= 500`
- `1 <= logs.length <= 500`
- `logs[i].length == 2`

## 解题思路

顺序遍历 `logs`，计算每个任务的耗时（当前离开时间 - 上一个离开时间），更新最长耗时和对应员工 ID。相同耗时时取较小的员工 ID。

## 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def hardestWorker(self, n: int, logs: List[List[int]]) -> int:
        ans_id = logs[0][0]
        max_time = logs[0][1]  # 第一个任务从时间 0 开始
        prev_time = logs[0][1]

        for i in range(1, len(logs)):
            emp_id, leave_time = logs[i]
            duration = leave_time - prev_time
            if duration > max_time or (duration == max_time and emp_id < ans_id):
                max_time = duration
                ans_id = emp_id
            prev_time = leave_time

        return ans_id
```

### 方法二：使用 zip 前后两项

```python
from typing import List

class Solution:
    def hardestWorker(self, n: int, logs: List[List[int]]) -> int:
        # 计算每个任务的耗时
        ans_id = 0
        max_time = 0
        prev = 0

        for emp_id, leave in logs:
            t = leave - prev
            prev = leave
            # 更新最长耗时，同时间取较小 ID
            if t > max_time or (t == max_time and emp_id < ans_id):
                max_time = t
                ans_id = emp_id

        return ans_id
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(m)（m 为日志条数） | O(1) |

## 关键点总结

1. 第一个任务耗时 = `logs[0][1] - 0`（从时间 0 开始）
2. 后续任务耗时 = 当前离开时间 - 上一个离开时间
3. 相同耗时时取更小的员工 ID

## 易错点

- 初始化 `prev = 0`（第一个任务从时间 0 开始）
- 相同耗时条件：`t == max_time and emp_id < ans_id`（需同时满足）
