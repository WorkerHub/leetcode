## 题目描述

给你一个字符串 `s` 和整数 `k`。

在每次操作中，你可以将 `s` 中某个字母替换为字母表中和它 **循环距离** 最近的字母（循环距离：`a` 和 `z` 的距离为 1）。

返回执行 **至多** `k` 次操作后可以得到的 **字典序最小** 的字符串。

**示例 1：**
```
输入：s = "zbbz", k = 3
输出："azaz"
解释：将 s[0]='z' 改为 'a'（距离 1），将 s[2]='b' 改为 'a'（距离 1），将 s[3]='z' 改为 'a'（距离 1）。
```

**示例 2：**
```
输入：s = "xaxcd", k = 4
输出："aawcd"
```

**提示：**
- `1 <= s.length <= 100`
- `0 <= k <= 100`
- `s` 只由小写英文字母组成

## 解题思路

贪心策略：从左到右遍历每个字符，对当前字符计算其变为 `'a'` 所需的最小循环距离（即 `min(c - 'a', 'z' - c + 1)`），若该距离不超过剩余的 `k`，则将其替换为 `'a'` 并扣减 `k`；否则将当前字符尽量减小（减少 `k` 步），然后停止（后续字符不再操作，因为改变后面字符会使字典序更大）。

## Python 代码实现

### 方法一：贪心逐字符处理（推荐）

```python
class Solution:
    def getSmallestString(self, s: str, k: int) -> str:
        res = list(s)
        for i, c in enumerate(s):
            # 计算变为 'a' 的最小循环距离
            dist = min(ord(c) - ord('a'), ord('z') - ord(c) + 1)
            if dist <= k:
                k -= dist
                res[i] = 'a'  # 直接变为 'a'
            else:
                # 只能向 'a' 方向移动 k 步
                res[i] = chr(ord(c) - k)
                break  # 剩余字符不再动
        return ''.join(res)
```

### 方法二：显式计算

```python
class Solution:
    def getSmallestString(self, s: str, k: int) -> str:
        res = []
        for c in s:
            val = ord(c) - ord('a')  # 0-25
            # 向 'a' 方向的距离：val；向 'a' 绕圈的距离：26 - val
            dist = min(val, 26 - val)
            if k >= dist:
                k -= dist
                res.append('a')
            else:
                # 向字典序减小方向移动 k 步
                res.append(chr(ord(c) - k))
                k = 0
                # 剩余字符保持原样
        return ''.join(res) + s[len(res):]
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(n)，存储结果字符串

## 关键点总结

1. 贪心：尽量让靠前的字符变小
2. 循环距离 = min(正向距离, 反向距离)
3. 一旦不能将某字符变为 'a'，只能部分减小并立即停止

## 易错点

1. 注意循环距离是 min(val, 26-val)，而不仅仅是 val
2. 部分移动时要向 'a' 方向减小（减去 k），而不是增加
