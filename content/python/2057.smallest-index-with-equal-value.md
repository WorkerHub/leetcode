## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，返回满足 `i % 10 == nums[i]` 的最小下标 `i`；若不存在这样的下标，返回 `-1`。

**示例 1：**
```
输入：nums = [0,1,2]
输出：0
解释：i=0: 0%10=0=nums[0]=0
```

**示例 2：**
```
输入：nums = [4,3,2,1]
输出：2
解释：i=2: 2%10=2=nums[2]=2
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 9`

## 解题思路

直接遍历数组，返回满足条件的第一个下标。

## 代码实现

### 方法一：遍历（推荐）

```python
from typing import List

class Solution:
    def smallestEqual(self, nums: List[int]) -> int:
        for i, num in enumerate(nums):
            if i % 10 == num:
                return i
        return -1
```

### 方法二：列表推导式 + next

```python
from typing import List

class Solution:
    def smallestEqual(self, nums: List[int]) -> int:
        return next((i for i, num in enumerate(nums) if i % 10 == num), -1)
```

### 方法三：循环变量

```python
from typing import List

class Solution:
    def smallestEqual(self, nums: List[int]) -> int:
        for i in range(len(nums)):
            if i % 10 == nums[i]:
                return i
        return -1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 条件 `i % 10 == nums[i]`，注意是 `i` 的最后一位数字
2. 由于 `nums[i]` 在 0-9 范围内，当 `i >= 10` 时只有 `i` 的个位数可能等于 `nums[i]`
3. 返回最小下标，所以找到第一个满足的就返回

## 易错点

- 注意是 `i % 10` 而不是 `i`（下标可能 >= 10）
- 返回的是下标 `i`，不是 `nums[i]`
