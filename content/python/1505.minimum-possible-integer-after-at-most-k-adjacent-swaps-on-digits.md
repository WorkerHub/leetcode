## 题目描述

给你一个表示大整数的字符串 `num`，和一个整数 `k`。

你可以对这个整数进行最多 `k` 次操作：每次操作，选择相邻两位数字并交换。

请你返回操作完后可能得到的最小整数。

**示例 1：**
```
输入：num = "4321", k = 4
输出："1342"
```

**示例 2：**
```
输入：num = "100", k = 1
输出："010"（即 "010"）
```

**示例 3：**
```
输入：num = "36789", k = 1000
输出："36789"
```

**提示：**
- `1 <= num.length <= 30000`
- `1 <= k <= 10^9`
- `num` 只含数字，不含前导零

## 解题思路

### 贪心 + 树状数组（BIT）

**贪心思路：**
- 从高位到低位，每次找能用剩余步数 `k` 移动到当前位置的最小数字
- 找到数字 `d`（0..9）在后面第一次出现的位置 `pos`，把它移到当前位置需要 `pos - i` 步（其中 i 是当前填充位）
- 注意：之前已经移走了一些数字，需要用树状数组维护"偏移量"

**树状数组的作用：**
- 记录哪些位置的数字已经被移走
- 对于位置 `pos`，它实际需要移动的步数是 `pos - i - (已移走的数量在 [i, pos] 之间)`

## 代码实现

### 方法一：贪心 + 树状数组（推荐）

```python
class Solution:
    def minInteger(self, num: str, k: int) -> str:
        n = len(num)
        # 树状数组，记录某位置是否还在（1=在，0=已被移走）
        bit = [0] * (n + 1)

        def update(i, delta):
            # 将位置 i+1 更新
            i += 1
            while i <= n:
                bit[i] += delta
                i += i & (-i)

        def query(i):
            # 查询 [0, i] 中还存在的元素数量
            i += 1
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        # 初始化：所有位置都在
        for i in range(n):
            update(i, 1)

        # 预处理每个数字各位置的下标列表（队列）
        from collections import deque
        pos = [deque() for _ in range(10)]
        for i, c in enumerate(num):
            pos[int(c)].append(i)

        result = []
        for i in range(n):
            # 当前还剩 k 步，尝试找最小的数字
            for d in range(10):
                if not pos[d]:
                    continue
                # 该数字在原字符串中的位置
                j = pos[d][0]
                # 实际需要移动的步数：j 前面有多少个数字还没被用掉
                # 即 query(j) - query(i-1) - 1... 其实是 j 到当前的"实际距离"
                # 实际距离 = j 的位置 - 已填充的位置数 = query(j) - 1
                # 因为已经填了 i 个，所以实际步数是 query(j) - 1 - (i - query(i-1) - ...)
                # 简化：当前实际步数 = pos_in_remaining = query(j) - 1 - (i - ...)
                # 更准确地：steps = j - i - (已被移走的在 [0..j] 中的数量)
                # 已被移走的 = j + 1 - query(j)（query(j) 是还在的数量）
                # steps = j - i - (j + 1 - query(j)) = query(j) - 1 - i
                steps = query(j) - 1 - (i - 0)
                # query(j) 是 [0..j] 中还在的数量，前 i 个位置都已被填
                # 实际 steps = query(j) - 1 (因为当前位就是第 i 个要填的位)
                # 再减去已填的 i 个
                steps = query(j) - 1
                if steps <= k:
                    k -= steps
                    result.append(str(d))
                    pos[d].popleft()
                    update(j, -1)  # 标记该位置已被移走
                    break
            else:
                # 0..9 都没找到（不可能发生），直接跳过
                pass

        return ''.join(result)
```

### 方法二：暴力贪心（适合 num 较短）

```python
class Solution:
    def minInteger(self, num: str, k: int) -> str:
        num = list(num)
        n = len(num)
        for i in range(n):
            # 在 [i, min(i+k, n-1)] 范围内找最小数字
            best = i
            for j in range(i + 1, min(i + k + 1, n)):
                if num[j] < num[best]:
                    best = j
            # 将 best 位移到 i，需要 best-i 步
            k -= (best - i)
            # 向前冒泡
            for j in range(best, i, -1):
                num[j], num[j-1] = num[j-1], num[j]
            if k <= 0:
                break
        return ''.join(num)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（BIT） | O(N log N) | O(N) |
| 方法二（暴力） | O(N^2) | O(N) |

方法二在 N=30000 时会超时，必须用树状数组。

## 关键点总结

1. 贪心策略：每次从最高位开始，找能在剩余步数内移过来的最小数字
2. 树状数组用于 O(log N) 地计算"某位置前还有多少个数字未被使用"
3. 实际移动步数 = 原位置 j 前面还剩多少元素 - 1（即 `query(j) - 1`）
4. 用队列存储每个数字的所有位置，O(1) 获取下一个该数字的位置

## 易错点

- 步数计算：要用树状数组查询"实际剩余距离"，不能直接用原始下标之差
- 树状数组初始化时所有元素都标记为 1（存在）
