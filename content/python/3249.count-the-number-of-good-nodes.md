## 题目描述

给你一棵 `n` 个节点（编号 0 到 n-1）的无向树，以节点 0 为根。

如果一个节点的所有子树都有**相同大小**，则该节点称为**好节点**。

返回**好节点**的数量。

**示例 1：**
```
输入：n = 7, edges = [[0,1],[1,2],[2,3],[3,4],[0,5],[5,6]]
输出：6
```

**示例 2：**
```
输入：n = 7, edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
输出：7
```

**提示：**
- `2 <= n <= 10^5`
- `edges.length == n - 1`

## 解题思路

DFS 后序遍历：对每个节点，计算所有子树的大小，若所有子树大小相同，则该节点是好节点。

叶节点（无子节点）自动是好节点（0 个子树，所有子树大小相同，满足条件）。

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodNodes(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        ans = 0
        
        def dfs(node, parent):
            nonlocal ans
            child_sizes = []
            for child in graph[node]:
                if child != parent:
                    child_sizes.append(dfs(child, node))
            
            # 检查是否是好节点：所有子树大小相同
            if len(set(child_sizes)) <= 1:
                ans += 1
            
            # 返回以 node 为根的子树大小
            return sum(child_sizes) + 1
        
        dfs(0, -1)
        return ans
```

### 方法二：迭代 DFS

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodNodes(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # 迭代后序遍历
        parent = [-1] * n
        order = []
        visited = [False] * n
        stack = [0]
        visited[0] = True
        
        while stack:
            u = stack.pop()
            order.append(u)
            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    parent[v] = u
                    stack.append(v)
        
        subtree_size = [1] * n
        ans = 0
        
        for u in reversed(order):
            child_sizes = []
            for v in graph[u]:
                if v != parent[u]:
                    child_sizes.append(subtree_size[v])
                    subtree_size[u] += subtree_size[v]
            
            if len(set(child_sizes)) <= 1:
                ans += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. DFS 后序遍历，先计算子节点再判断当前节点
2. 好节点条件：所有子树大小相同（用 set 判断）
3. 叶节点满足条件（`set([]) == set()`，长度 <= 1）

## 易错点

1. 无向树用 DFS 时需要记录父节点，避免回头
2. 叶节点（无子节点）自动是好节点
