## 题目描述

给你两个正整数 `l` 和 `r`，如果一个数 `x` 恰好有 **2 个约数**（不含自身），则称 `x` 为**特殊数**（即 `x = p^2`，`p` 为质数）。

返回区间 `[l, r]` 中**非特殊数**的数量。

**示例 1：**
```
输入：l = 5, r = 7
输出：3
解释：5, 6, 7 都不是特殊数。
```

**示例 2：**
```
输入：l = 4, r = 16
输出：9
解释：特殊数为 4(=2^2), 9(=3^2)，剩余 9 个非特殊数。
```

**提示：**
- `1 <= l <= r <= 10^9`

## 解题思路

特殊数 = 质数的平方（`p^2`，p 为质数）。

统计 `[l, r]` 中有多少个质数的平方，用线性筛（埃氏筛）找出 `[2, sqrt(r)]` 内的所有质数，然后统计 `p^2` 在 `[l, r]` 内的质数个数。

`sqrt(10^9) ≈ 31623`，筛质数到 31623 即可。

## Python 代码实现

### 方法一：埃氏筛 + 统计（推荐）

```python
import math

class Solution:
    def nonSpecialCount(self, l: int, r: int) -> int:
        # 找出所有 p^2 在 [l, r] 内的质数 p
        # p 的范围：sqrt(l) <= p <= sqrt(r)
        max_p = int(math.isqrt(r))
        
        # 埃氏筛找出 [2, max_p] 内的所有质数
        is_prime = [True] * (max_p + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(math.isqrt(max_p)) + 1):
            if is_prime[i]:
                for j in range(i * i, max_p + 1, i):
                    is_prime[j] = False
        
        # 统计 p^2 在 [l, r] 内的质数个数
        special_count = 0
        for p in range(2, max_p + 1):
            if is_prime[p] and l <= p * p <= r:
                special_count += 1
        
        total = r - l + 1
        return total - special_count
```

### 方法二：简化写法

```python
import math

class Solution:
    def nonSpecialCount(self, l: int, r: int) -> int:
        max_p = int(math.isqrt(r))
        
        # 线性筛
        primes = []
        is_prime = [True] * (max_p + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, max_p + 1):
            if is_prime[i]:
                primes.append(i)
                for j in range(i * i, max_p + 1, i):
                    is_prime[j] = False
        
        # 统计特殊数
        special = sum(1 for p in primes if l <= p * p <= r)
        return r - l + 1 - special
```

## 复杂度分析

- 时间复杂度：O(sqrt(r) * log(log(sqrt(r))))，埃氏筛
- 空间复杂度：O(sqrt(r))

## 关键点总结

1. 特殊数 = 恰好有 2 个约数（除自身），即质数的平方
2. 在 `[l, r]` 内的特殊数对应 `[sqrt(l), sqrt(r)]` 内的质数
3. 埃氏筛快速找出范围内的质数

## 易错点

1. `sqrt(r)` 可能不是整数，要用 `math.isqrt` 取整
2. 注意 l=1 时，1 不是特殊数（1 的约数只有 1 本身）
3. 质数平方在 [l,r] 的条件：`l <= p*p <= r`
