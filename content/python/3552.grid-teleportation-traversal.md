## 题目描述

给定一个 `m x n` 的字符矩阵 `grid`，从左上角 `(0, 0)` 出发，到达右下角 `(m-1, n-1)`。移动规则：
1. 每步可以向上下左右移动一格（非 `#` 的格子）
2. 若当前格子和另一格子都是相同的字母（`'a'` 到 `'z'`），可以瞬间传送到任意同字母格子（代价为 0）

求到达终点的最少步数，若无法到达返回 `-1`。

**示例 1：**

```
输入：grid = ["..a", "a..", "..."]
输出：2
解释：(0,0) -> 移动到 (0,2) 有 'a'，传送到 (1,0) 有 'a'，再移动到 (2,2)。
```

**提示：**
- `1 <= m, n <= 1000`
- 字符为 `.`、`#` 或小写字母

## 解题思路

0-1 BFS（双端队列 BFS）：
- 普通移动代价为 1
- 传送（同字母格子之间）代价为 0

将传送视为 0 代价边，使用 0-1 BFS（deque）：
- 代价 0 的操作加入队列头部
- 代价 1 的操作加入队列尾部

哈希表记录每种字母的所有坐标，传送时将所有同字母坐标加入队列。

注意：一旦使用过某字母的传送功能，该字母的所有格子已处理完毕，无需重复处理。

## Python 代码实现

### 方法一：0-1 BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minMoves(self, grid: List[str]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')

        # 收集每种字母的坐标
        letter_pos = defaultdict(list)
        for r in range(m):
            for c in range(n):
                if grid[r][c].isalpha():
                    letter_pos[grid[r][c]].append((r, c))

        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0
        dq = deque([(0, 0)])
        used_letters = set()  # 已使用过传送的字母

        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        while dq:
            r, c = dq.popleft()
            d = dist[r][c]

            if r == m-1 and c == n-1:
                return d

            # 传送（0代价）
            letter = grid[r][c]
            if letter.isalpha() and letter not in used_letters:
                used_letters.add(letter)
                for nr, nc in letter_pos[letter]:
                    if dist[nr][nc] > d:
                        dist[nr][nc] = d
                        dq.appendleft((nr, nc))  # 0代价加入队头

            # 普通移动（1代价）
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] != '#':
                    if dist[nr][nc] > d + 1:
                        dist[nr][nc] = d + 1
                        dq.append((nr, nc))  # 1代价加入队尾

        return dist[m-1][n-1] if dist[m-1][n-1] != INF else -1
```

### 方法二：Dijkstra 算法

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def minMoves(self, grid: List[str]) -> int:
        m, n = len(grid), len(grid[0])
        letter_pos = defaultdict(list)
        for r in range(m):
            for c in range(n):
                if grid[r][c].isalpha():
                    letter_pos[grid[r][c]].append((r, c))

        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]
        used_letters = set()

        while heap:
            d, r, c = heapq.heappop(heap)
            if d > dist[r][c]:
                continue
            if r == m-1 and c == n-1:
                return d
            letter = grid[r][c]
            if letter.isalpha() and letter not in used_letters:
                used_letters.add(letter)
                for nr, nc in letter_pos[letter]:
                    if dist[nr][nc] > d:
                        dist[nr][nc] = d
                        heapq.heappush(heap, (d, nr, nc))
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r+dr, c+dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] != '#':
                    if dist[nr][nc] > d + 1:
                        dist[nr][nc] = d + 1
                        heapq.heappush(heap, (d+1, nr, nc))

        return -1
```

## 复杂度分析

- 时间复杂度：O(m * n * 26)（0-1 BFS），O(m * n * log(m*n))（Dijkstra）
- 空间复杂度：O(m * n)

## 关键点总结

1. 传送为 0 代价，普通移动为 1 代价，使用 0-1 BFS
2. 每种字母只需处理一次传送（`used_letters` 集合避免重复）
3. 传送到同字母的所有位置，加入队列头部（0代价）

## 易错点

1. `#` 格子不可通行，需要过滤
2. 已使用过的字母不再重复传送（否则可能死循环）
3. 0-1 BFS 中，0代价入队头，1代价入队尾
