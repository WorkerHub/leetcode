## 题目描述

与 2865 相同，但数据量更大（n 最大 10^5），需要单调栈优化。

给你一个长度为 `n` 的整数数组 `maxHeights`，找到和最大的山形 heights 数组（每个位置高度 <= maxHeights[i]）。

**提示：**
- `1 <= n <= 10^5`
- `1 <= maxHeights[i] <= 10^9`

## 解题思路

**单调栈 O(n) 解法：**

对每个峰顶 i，需要快速计算左侧和与右侧和。

**预处理 left_sum[i]：** 以 i 为峰顶时，左侧（含 i）的最优高度之和。

- 用单调递增栈维护左侧"障碍点"
- 当栈顶下标 j 满足 `maxHeights[j] > maxHeights[i]` 时，i 可以继承 j 左侧的部分
- 否则 j 成为新障碍，left_sum[i] = left_sum[j] + (i - j) * maxHeights[i]

类似地计算 **right_sum[i]**（从右到左）。

最终答案 = max(left_sum[i] + right_sum[i] - maxHeights[i]) over all i。

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def maximumSumOfHeights(self, maxHeights: List[int]) -> int:
        n = len(maxHeights)
        left_sum = [0] * n   # 以 i 为峰顶时，[0, i] 的最优高度之和
        right_sum = [0] * n  # 以 i 为峰顶时，[i, n-1] 的最优高度之和

        # 计算 left_sum（从左到右）
        stack = []  # 单调不减栈（存下标）
        for i in range(n):
            # 弹出比 maxHeights[i] 大的（不符合非递减约束）
            while stack and maxHeights[stack[-1]] > maxHeights[i]:
                stack.pop()
            if not stack:
                left_sum[i] = (i + 1) * maxHeights[i]
            else:
                j = stack[-1]
                left_sum[i] = left_sum[j] + (i - j) * maxHeights[i]
            stack.append(i)

        # 计算 right_sum（从右到左）
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and maxHeights[stack[-1]] > maxHeights[i]:
                stack.pop()
            if not stack:
                right_sum[i] = (n - i) * maxHeights[i]
            else:
                j = stack[-1]
                right_sum[i] = right_sum[j] + (j - i) * maxHeights[i]
            stack.append(i)

        # 取每个峰顶时的最大和（减去重复计算的峰顶本身）
        return max(left_sum[i] + right_sum[i] - maxHeights[i] for i in range(n))
```

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def maximumSumOfHeights(self, maxHeights: List[int]) -> int:
        n = len(maxHeights)

        # left[i] = 以 i 为峰顶，左半部分（0..i）的最优和
        # 左半部分非递减：从 i 往左，高度 = min(maxH[j], maxH[j+1]) 依次递推
        left = [0] * n
        stk = []  # 单调不减（存下标，从底到顶 maxH 值不减）

        for i in range(n):
            # 维护单调性：弹出 maxH > maxH[i] 的（它们被 i 限制了）
            while stk and maxHeights[stk[-1]] >= maxHeights[i]:
                stk.pop()
            if not stk:
                # i 是左侧最大，所有 [0, i] 高度都等于 maxH[i]
                left[i] = (i + 1) * maxHeights[i]
            else:
                j = stk[-1]
                # [0, j] 的最优和是 left[j]，[j+1, i] 高度都等于 maxH[i]
                left[i] = left[j] + (i - j) * maxHeights[i]
            stk.append(i)

        # right[i] = 以 i 为峰顶，右半部分（i..n-1）的最优和
        right = [0] * n
        stk = []

        for i in range(n - 1, -1, -1):
            while stk and maxHeights[stk[-1]] >= maxHeights[i]:
                stk.pop()
            if not stk:
                right[i] = (n - i) * maxHeights[i]
            else:
                j = stk[-1]
                right[i] = right[j] + (j - i) * maxHeights[i]
            stk.append(i)

        return max(left[i] + right[i] - maxHeights[i] for i in range(n))
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素最多进出栈一次
- 空间复杂度：O(n)，left_sum、right_sum 数组和单调栈

## 关键点总结

1. 单调栈维护"从左到 i 的最小高度障碍点"
2. left_sum[i] = left_sum[j] + (i - j) * maxH[i]（j 是栈顶，[j+1, i] 高度均为 maxH[i]）
3. 最终答案：left[i] + right[i] - maxH[i]（减去峰顶重复计算）

## 易错点

1. 弹出条件用 `>=`（允许相等时合并区间）还是 `>`？这里用 `>=` 防止重复累加
2. `left[i] + right[i] - maxHeights[i]` 因为 left[i] 和 right[i] 都包含了 i 点
3. 单调栈方向：left 从左到右，right 从右到左
