## 题目描述

`3 x 3` 的幻方是一个填充有 **从 `1` 到 `9`** 的不同数字的 `3 x 3` 矩阵，使得每行，每列以及两条对角线上的各数之和都相等。

给你一个由整数组成的 `row x col` 的 `grid`，其中有多少个 `3 × 3` 的 "幻方" 子矩阵？（每个子矩阵都是连续的）。

## Python 代码实现

```python
from typing import List

class Solution:
    def numMagicSquaresInside(self, grid: List[List[int]]) -> int:
        def is_magic(square):
            # 检查是否包含 1-9 且无重复
            nums = [square[i][j] for i in range(3) for j in range(3)]
            if sorted(nums) != list(range(1, 10)):
                return False
            
            # 检查行、列、对角线和是否都为 15
            return (
                sum(square[0]) == 15 and
                sum(square[1]) == 15 and
                sum(square[2]) == 15 and
                sum(square[i][0] for i in range(3)) == 15 and
                sum(square[i][1] for i in range(3)) == 15 and
                sum(square[i][2] for i in range(3)) == 15 and
                sum(square[i][i] for i in range(3)) == 15 and
                sum(square[i][2-i] for i in range(3)) == 15
            )
        
        rows, cols = len(grid), len(grid[0])
        count = 0
        
        for i in range(rows - 2):
            for j in range(cols - 2):
                square = [grid[i+r][j:j+3] for r in range(3)]
                if is_magic(square):
                    count += 1
        
        return count
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)

## 关键点总结

1. **幻方条件**：包含1-9，所有行列对角线和为15
2. **枚举子矩阵**：遍历所有3×3窗口
3. **验证**：检查所有条件
