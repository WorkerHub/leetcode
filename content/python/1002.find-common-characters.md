## 题目描述

给你一个字符串数组 `words`，请你找出所有在 `words` 的每个字符串中都出现的共用字符（包括重复字符），并以数组形式返回。你可以按任意顺序返回答案。

**示例 1：**
```
输入：words = ["bella","label","roller"]
输出：["e","l","l"]
```

**示例 2：**
```
输入：words = ["cool","lock","cook"]
输出：["c","o"]
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 由小写英文字母组成

## 解题思路

这道题的核心是找出所有字符串中的**共同字符**，包括重复的字符。

**关键观察：**
1. 一个字符在结果中出现的次数 = 它在所有字符串中出现次数的**最小值**
2. 例如：如果字符 'l' 在三个字符串中分别出现 2次、3次、2次，那么结果中 'l' 应该出现 2 次

**算法流程：**
1. 统计第一个字符串中每个字符的出现次数（作为初始计数）
2. 遍历后续每个字符串，更新每个字符的最小出现次数
3. 根据最终的计数结果，构造返回数组

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # 统计第一个单词中每个字符的出现次数
        common_count = Counter(words[0])
        
        # 遍历剩余单词，更新最小计数
        for word in words[1:]:
            word_count = Counter(word)
            # 对每个字符，取最小出现次数
            for char in common_count:
                common_count[char] = min(common_count[char], word_count[char])
        
        # 根据计数构造结果
        result = []
        for char, count in common_count.items():
            result.extend([char] * count)
        
        return result
```

### 方法二：使用 & 运算符优化

```python
from typing import List
from collections import Counter

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # Counter 对象的 & 运算会取每个键的最小值
        common = Counter(words[0])
        
        for word in words[1:]:
            common &= Counter(word)
        
        # elements() 方法会根据计数展开元素
        return list(common.elements())
```

### 方法三：数组计数（不使用 Counter）

```python
from typing import List

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # 用数组记录每个字母的最小出现次数（26个小写字母）
        min_freq = [float('inf')] * 26
        
        for word in words:
            # 统计当前单词中每个字母的出现次数
            freq = [0] * 26
            for char in word:
                freq[ord(char) - ord('a')] += 1
            
            # 更新最小出现次数
            for i in range(26):
                min_freq[i] = min(min_freq[i], freq[i])
        
        # 构造结果
        result = []
        for i in range(26):
            if min_freq[i] != float('inf'):
                result.extend([chr(i + ord('a'))] * min_freq[i])
        
        return result
```

### 方法四：一行代码（Python 特色）

```python
from typing import List
from collections import Counter
from functools import reduce

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        return list(reduce(lambda a, b: a & b, map(Counter, words)).elements())
```

## 复杂度分析

**时间复杂度：** O(n * m)
- n 是字符串数组的长度，m 是字符串的平均长度
- 需要遍历所有字符串的所有字符

**空间复杂度：** O(1)
- 只需要存储 26 个字母的计数，与输入规模无关
- 如果考虑返回结果，空间复杂度为 O(k)，k 为结果长度

## 关键点总结

1. **最小值思想**：共同字符的数量由最少出现次数决定
2. **Counter 的使用**：
   - `Counter` 是统计字符频率的利器
   - `&` 运算符会自动取最小值
   - `elements()` 方法可以根据计数展开元素
3. **数组优化**：对于小写字母，可以用长度为 26 的数组代替哈希表
4. **函数式编程**：`reduce` + `Counter` 可以写出简洁的代码

## 易错点

1. **初始值设置**：最小计数应该初始化为第一个单词的计数，而不是无穷大
2. **重复字符**：如果字符出现多次，结果中也要包含多次
3. **空集合处理**：如果某个字符在某个单词中不存在，其计数为 0，最终结果中不应包含
4. **返回格式**：要返回字符列表，不是计数字典
