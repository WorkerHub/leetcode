## 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**
```
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**
```
输入: nums = [0,3,7,2,5,8,4,6,0,1]
输出: 9
```

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这道题的关键是要在 **O(n)** 时间内完成，所以不能排序（排序至少 O(n log n)）。

### 核心思想：哈希表 + 智能跳过

1. **使用哈希集合存储所有数字**：O(1) 时间判断某个数是否存在
2. **只从序列起点开始计数**：如果 `num-1` 存在，说明不是起点，跳过
3. **从起点向后延伸**：计算以当前数字为起点的连续序列长度
4. **记录最大长度**

### 为什么时间复杂度是 O(n)？

虽然有嵌套循环，但每个数字**最多只会被访问两次**：
- 外层循环：遍历每个数字 O(n)
- 内层循环：只有序列起点才会进入，总共也是 O(n)
- 总时间复杂度：O(n) + O(n) = O(n)

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 转换为集合，O(1) 查找
        num_set = set(nums)
        max_length = 0
        
        for num in num_set:
            # 只从序列起点开始计数
            # 如果 num-1 存在，说明不是起点，跳过
            if num - 1 not in num_set:
                current_num = num
                current_length = 1
                
                # 向后延伸，计算序列长度
                while current_num + 1 in num_set:
                    current_num += 1
                    current_length += 1
                
                max_length = max(max_length, current_length)
        
        return max_length
```

### 方法二：哈希表优化版（记忆化）

```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        num_set = set(nums)
        max_length = 0
        visited = set()  # 记录已经处理过的数字
        
        for num in num_set:
            if num in visited:
                continue
            
            # 向左查找边界
            left = num - 1
            while left in num_set:
                visited.add(left)
                left -= 1
            
            # 向右查找边界
            right = num + 1
            while right in num_set:
                visited.add(right)
                right += 1
            
            # 计算长度
            current_length = right - left - 1
            max_length = max(max_length, current_length)
            visited.add(num)
        
        return max_length
```

### 方法三：并查集（进阶）

```python
from typing import List

class UnionFind:
    def __init__(self, nums):
        self.parent = {num: num for num in nums}
        self.size = {num: 1 for num in nums}
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]
    
    def union(self, x, y):
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x != root_y:
            # 按大小合并
            if self.size[root_x] < self.size[root_y]:
                root_x, root_y = root_y, root_x
            
            self.parent[root_y] = root_x
            self.size[root_x] += self.size[root_y]
    
    def get_max_size(self):
        return max(self.size.values()) if self.size else 0

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        num_set = set(nums)
        uf = UnionFind(num_set)
        
        for num in num_set:
            # 将连续的数字合并
            if num + 1 in num_set:
                uf.union(num, num + 1)
        
        return uf.get_max_size()
```

### 方法四：排序法（不满足 O(n) 要求）

```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 排序 O(n log n)
        nums.sort()
        
        max_length = 1
        current_length = 1
        
        for i in range(1, len(nums)):
            # 跳过重复元素
            if nums[i] == nums[i-1]:
                continue
            
            # 连续
            if nums[i] == nums[i-1] + 1:
                current_length += 1
            else:
                # 不连续，重新开始
                max_length = max(max_length, current_length)
                current_length = 1
        
        return max(max_length, current_length)
```

## 复杂度分析

### 方法一：哈希表（推荐）
- **时间复杂度**：O(n)
  - 构建集合：O(n)
  - 遍历集合：每个元素最多访问两次，O(n)
- **空间复杂度**：O(n)，哈希集合

### 方法三：并查集
- **时间复杂度**：O(n × α(n)) ≈ O(n)，α 是反阿克曼函数，几乎为常数
- **空间复杂度**：O(n)

### 方法四：排序法
- **时间复杂度**：O(n log n)，不满足题目要求
- **空间复杂度**：O(1) 或 O(n)，取决于排序算法

## 关键点总结

1. **哈希表是关键**：O(1) 查找使得整体复杂度为 O(n)
2. **只从起点开始**：通过 `num-1 not in num_set` 判断起点，避免重复计算
3. **时间复杂度分析**：虽然有嵌套循环，但每个数最多访问两次
4. **集合去重**：转换为集合自动去重
5. **边界处理**：空数组返回 0

## 易错点

1. **忘记检查空数组**
   ```python
   if not nums:
       return 0
   ```

2. **时间复杂度理解错误**
   ```python
   # 看起来是 O(n^2)，实际是 O(n)
   # 因为内层循环总共只执行 n 次
   for num in num_set:
       if num - 1 not in num_set:
           while current_num + 1 in num_set:
               # 每个数最多访问一次
   ```

3. **没有跳过非起点**
   ```python
   # 错误：所有数字都计算
   for num in num_set:
       current_length = 1
       while current_num + 1 in num_set:
           ...
   
   # 正确：只从起点开始
   if num - 1 not in num_set:
       ...
   ```

4. **使用列表而不是集合**
   ```python
   # 错误：列表查找 O(n)
   if num in nums:  # O(n)
   
   # 正确：集合查找 O(1)
   if num in num_set:  # O(1)
   ```
