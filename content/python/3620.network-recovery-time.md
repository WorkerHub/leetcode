## 题目描述

给你一个 `n` 个节点的有向图，边集 `edges[i] = [u, v, time]`，表示从 `u` 到 `v` 需要 `time` 时间。节点 `0` 是源节点，其余节点在收到信号后才能激活。一个节点激活后，会立即向其所有出边传递信号。

返回所有节点都激活所需的最短时间，若无法全部激活返回 `-1`。

**示例 1：**

```
输入：n = 4, edges = [[0,1,1],[0,2,4],[1,3,1],[2,3,1]]
输出：3
解释：
t=0: 节点0激活
t=1: 节点1激活
t=2: 节点3激活（via 0→1→3）
t=4: 节点2激活（via 0→2，但3已经在t=2激活了）
最慢：节点2在t=4激活，但其实节点3更早，所以答案是max(所有节点激活时间)=4
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= edges.length <= 2 * 10^5`
- `0 <= u, v < n`，`u != v`
- `1 <= time <= 10^3`

## 解题思路

经典 Dijkstra 单源最短路问题：从节点 0 出发，计算到所有节点的最短时间，答案为所有节点中最短时间的最大值。若存在无法到达的节点，返回 -1。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def networkRecoveryTime(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))

        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, node = heapq.heappop(heap)
            if d > dist[node]:
                continue
            for neighbor, t in graph[node]:
                new_d = d + t
                if new_d < dist[neighbor]:
                    dist[neighbor] = new_d
                    heapq.heappush(heap, (new_d, neighbor))

        ans = max(dist)
        return ans if ans != float('inf') else -1
```

### 方法二：BFS（等权图）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def networkRecoveryTime(self, n: int, edges: List[List[int]]) -> int:
        # 若所有边权相等，BFS 即可
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))

        dist = [float('inf')] * n
        dist[0] = 0
        queue = deque([(0, 0)])

        while queue:
            d, node = queue.popleft()
            for neighbor, t in graph[node]:
                if d + t < dist[neighbor]:
                    dist[neighbor] = d + t
                    queue.append((dist[neighbor], neighbor))

        ans = max(dist)
        return ans if ans != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)
- 空间复杂度：O(V + E)

## 关键点总结

1. 单源最短路，Dijkstra 是标准解法
2. 答案为所有节点最短距离中的最大值
3. 若最大值为无穷大，说明存在不可达节点
4. 有向图需注意边的方向

## 易错点

1. 求最大值不是最小值（所有节点都要激活）
2. 若图不是强连通，可能有不可达节点
3. 不要忘记检查 `d > dist[node]` 来跳过过时状态
