## 题目描述

给你二维平面上两个由直线构成且边与坐标轴平行/垂直的矩形，请你计算并返回两个矩形覆盖的总面积。

每个矩形由其左下顶点和右上顶点坐标表示：

- 第一个矩形由其左下顶点 `(ax1, ay1)` 和右上顶点 `(ax2, ay2)` 定义。
- 第二个矩形由其左下顶点 `(bx1, by1)` 和右上顶点 `(bx2, by2)` 定义。

**示例 1：**

```
输入：ax1 = -3, ay1 = 0, ax2 = 3, ay2 = 4, bx1 = 0, by1 = -1, bx2 = 9, by2 = 2
输出：45
```

**示例 2：**

```
输入：ax1 = -2, ay1 = -2, ax2 = 2, ay2 = 2, bx1 = -2, by1 = -2, bx2 = 2, by2 = 2
输出：16
```

**提示：**

- `-10^4 <= ax1, ay1, ax2, ay2, bx1, by1, bx2, by2 <= 10^4`

## 解题思路

这是一道几何计算题，核心思想是：**总面积 = 矩形A面积 + 矩形B面积 - 重叠面积**

### 关键步骤

1. **计算两个矩形的面积**
   - 矩形A面积：`(ax2 - ax1) * (ay2 - ay1)`
   - 矩形B面积：`(bx2 - bx1) * (by2 - by1)`

2. **计算重叠部分的面积**
   - 重叠矩形的左下角：`(max(ax1, bx1), max(ay1, by1))`
   - 重叠矩形的右上角：`(min(ax2, bx2), min(ay2, by2))`
   - 如果没有重叠，宽度或高度会是负数或0

3. **应用容斥原理**
   - 总面积 = area1 + area2 - overlap

### 判断是否重叠

两个矩形重叠的条件：
- 水平方向：`max(ax1, bx1) < min(ax2, bx2)`
- 垂直方向：`max(ay1, by1) < min(ay2, by2)`

## Python 代码实现

### 方法一：容斥原理（推荐）

```python
class Solution:
    def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, 
                    bx1: int, by1: int, bx2: int, by2: int) -> int:
        # 计算两个矩形的面积
        area1 = (ax2 - ax1) * (ay2 - ay1)
        area2 = (bx2 - bx1) * (by2 - by1)
        
        # 计算重叠部分的宽度和高度
        overlap_width = max(0, min(ax2, bx2) - max(ax1, bx1))
        overlap_height = max(0, min(ay2, by2) - max(ay1, by1))
        
        # 重叠面积
        overlap_area = overlap_width * overlap_height
        
        # 总面积 = 两个矩形面积之和 - 重叠面积
        return area1 + area2 - overlap_area
```

### 方法二：分情况讨论

```python
class Solution:
    def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, 
                    bx1: int, by1: int, bx2: int, by2: int) -> int:
        # 计算两个矩形的面积
        area1 = (ax2 - ax1) * (ay2 - ay1)
        area2 = (bx2 - bx1) * (by2 - by1)
        
        # 判断是否有重叠
        if ax2 <= bx1 or bx2 <= ax1 or ay2 <= by1 or by2 <= ay1:
            # 没有重叠
            return area1 + area2
        
        # 有重叠，计算重叠面积
        overlap_x1 = max(ax1, bx1)
        overlap_y1 = max(ay1, by1)
        overlap_x2 = min(ax2, bx2)
        overlap_y2 = min(ay2, by2)
        
        overlap_area = (overlap_x2 - overlap_x1) * (overlap_y2 - overlap_y1)
        
        return area1 + area2 - overlap_area
```

### 方法三：详细注释版（便于理解）

```python
class Solution:
    def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, 
                    bx1: int, by1: int, bx2: int, by2: int) -> int:
        """
        计算两个矩形覆盖的总面积
        
        思路：总面积 = 矩形A + 矩形B - 重叠部分
        """
        # 步骤1：计算矩形A的面积
        area_a = (ax2 - ax1) * (ay2 - ay1)
        
        # 步骤2：计算矩形B的面积
        area_b = (bx2 - bx1) * (by2 - by1)
        
        # 步骤3：计算重叠部分
        # 重叠矩形的左边界是两个矩形左边界的较大值
        overlap_left = max(ax1, bx1)
        # 重叠矩形的右边界是两个矩形右边界的较小值
        overlap_right = min(ax2, bx2)
        # 重叠矩形的下边界是两个矩形下边界的较大值
        overlap_bottom = max(ay1, by1)
        # 重叠矩形的上边界是两个矩形上边界的较小值
        overlap_top = min(ay2, by2)
        
        # 计算重叠部分的宽度和高度
        # 如果没有重叠，宽度或高度会 <= 0
        overlap_width = max(0, overlap_right - overlap_left)
        overlap_height = max(0, overlap_top - overlap_bottom)
        
        # 重叠面积
        overlap_area = overlap_width * overlap_height
        
        # 步骤4：应用容斥原理
        return area_a + area_b - overlap_area
```

## 关键点总结

1. **容斥原理**：总面积 = A + B - A∩B
2. **重叠计算**：取左右边界的 max 和 min
3. **边界处理**：使用 `max(0, ...)` 处理无重叠的情况
4. **坐标理解**：左下角坐标小于右上角坐标
5. **特殊情况**：完全重叠、部分重叠、不重叠

## 易错点

1. **忘记减去重叠部分**：直接返回 area1 + area2
2. **负数处理**：重叠宽度/高度可能为负，需要用 max(0, ...)
3. **边界情况**：两个矩形刚好相邻（边重合但不重叠）
4. **坐标混淆**：左下角和右上角的坐标关系
5. **整数溢出**：虽然本题数据范围不会溢出，但在其他类似题目中需注意
