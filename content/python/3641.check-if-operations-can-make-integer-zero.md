## 题目描述

给你一个整数 `n` 和一个整数 `k`，每次操作可以将 `n` 减去 `k` 的任意正整数次幂（即减去 `k^1, k^2, k^3, ...`）。判断能否通过若干次操作将 `n` 变为 0。

**示例 1：**

```
输入：n = 10, k = 2
输出：true
解释：10 - 8(2^3) - 2(2^1) = 0
```

**示例 2：**

```
输入：n = 9, k = 3
输出：true
解释：9 - 9(3^2) = 0
```

**示例 3：**

```
输入：n = 7, k = 2
输出：false
```

**提示：**

- `1 <= n <= 10^6`
- `2 <= k <= 10^6`

## 解题思路

若 `k = 1`，则 `k^i = 1` 对所有 `i` 成立，可以减任意次 1，只要 n >= 0 就能变为 0，所以 `k=1` 答案总是 True（但题目约束 k >= 2）。

对于 `k >= 2`，判断 `n` 能否写成若干个 `k` 的幂次之和。注意：同一个幂次可以多次使用（不是要求每次不同）。

若 `k = 2`，等价于 `n` 能用 2 的幂次之和表示，而任意正整数都能表示为 2 的幂次之和（二进制），所以 k=2 时答案总为 True（若 n > 0）。

一般情况：BFS/DFS 搜索，或用数学分析在 `k` 进制表示下每位是否合法。

## Python 代码实现

### 方法一：BFS/递归搜索（推荐）

```python
class Solution:
    def checkZero(self, n: int, k: int) -> bool:
        # 收集所有 k 的幂次（不超过 n）
        powers = []
        p = k
        while p <= n:
            powers.append(p)
            if p > n // k:  # 防止溢出
                break
            p *= k

        # DFS：能否从 n 减去若干幂次（可重复）得到 0
        from functools import lru_cache
        @lru_cache(maxsize=None)
        def dfs(remaining):
            if remaining == 0:
                return True
            if remaining < 0:
                return False
            return any(dfs(remaining - pw) for pw in powers if pw <= remaining)

        return dfs(n)
```

### 方法二：检查 k 进制表示

```python
class Solution:
    def checkZero(self, n: int, k: int) -> bool:
        # 在 k 进制下，n 的每一位最多可以选对应次幂，
        # 实际上只要能凑出 n 即可（可重复使用幂次）
        # 等价于：n 能否用 k^0, k^1, ... 的非负整数线性组合表示
        # 即 n 在以 k 为基的数制下的表示是否每位都 >= 0（总成立）
        # 特殊情况：若 k = 1（题目中不会出现），n 减若干次 1 到 0
        # 关键：幂次可以重复使用，等价于完全背包问题
        powers = []
        p = k
        while p <= n:
            powers.append(p)
            if p > n // k:
                break
            p *= k

        # 完全背包：能否凑成 n
        dp = [False] * (n + 1)
        dp[0] = True
        for pw in powers:
            for i in range(pw, n + 1):
                if dp[i - pw]:
                    dp[i] = True

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n * log_k(n))，完全背包
- 空间复杂度：O(n)

## 关键点总结

1. 问题等价于完全背包：物品为 k 的各幂次，背包容量为 n
2. k 的幂次数量为 O(log_k(n))
3. 可以使用相同幂次多次

## 易错点

1. 幂次可以重复使用（完全背包，非 0/1 背包）
2. k=1 特殊情况（题目约束中不出现）
3. 幂次上界：不超过 n
