## 题目描述

给你 `n` 个二维平面上的点 `points`，其中 `points[i] = [xi, yi]`。

两点之间的**垂直区域**定义为 x 轴上两点之间的最大空白区域（不包含任何其他点的 x 坐标）。

请找到**最宽的垂直区域**。注意：垂直区域的宽度只由 x 坐标决定，y 坐标不影响宽度。

**示例：**
```
输入：points = [[8,7],[9,9],[7,4],[9,7]]
输出：1
解释：x 坐标排序后：7, 8, 9, 9。最大间隔为 8-7=1 或 9-8=1
```

## 解题思路

只需关注 x 坐标：
1. 提取所有点的 x 坐标
2. 排序后，找相邻 x 坐标之差的最大值

## 代码实现

### 方法一：提取 x 坐标并排序（推荐）

```python
from typing import List

class Solution:
    def maxWidthOfVerticalArea(self, points: List[List[int]]) -> int:
        # 提取所有 x 坐标并排序
        xs = sorted(p[0] for p in points)
        # 找相邻差的最大值
        return max(xs[i] - xs[i-1] for i in range(1, len(xs)))
```

### 方法二：直接对点按 x 坐标排序

```python
from typing import List

class Solution:
    def maxWidthOfVerticalArea(self, points: List[List[int]]) -> int:
        # 按 x 坐标排序
        points.sort()
        ans = 0
        for i in range(1, len(points)):
            ans = max(ans, points[i][0] - points[i-1][0])
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 提取排序 | O(n log n) | O(n) |
| 直接排序 | O(n log n) | O(1) |

## 关键点总结

1. 题目只关注 x 坐标，y 坐标完全不影响结果
2. 排序后找最大相邻差
3. 方法一更清晰，方法二原地排序更节省空间

## 易错点

- 不要被"垂直区域"和 y 坐标混淆，只看 x 坐标
- 相邻差的最大值，注意是排序后的相邻差
