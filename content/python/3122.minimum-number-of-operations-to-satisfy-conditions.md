## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。

一次操作可以将 `grid[i][j]` 改为 0 或 1。

你需要满足如下条件：
- 同一列中所有格子的值相同
- 相邻两列的值不同

返回使矩阵满足条件所需的 **最少** 操作次数。

**示例 1：**
```
输入：grid = [[0,1],[1,0],[0,1]]
输出：3
```

**示例 2：**
```
输入：grid = [[1],[0],[1]]
输出：0
```

**提示：**
- `1 <= m, n <= 1000`
- `0 <= grid[i][j] <= 1`

## 解题思路

目标：每列统一为 0 或 1，且相邻列不同（即交替 0、1）。

方案只有两种：奇数列为 0 偶数列为 1，或奇数列为 1 偶数列为 0。

对每列 j，统计 0 和 1 的个数，修改为全 0 的代价是 1 的个数，修改为全 1 的代价是 0 的个数。

动态规划：`dp[j][v]` 表示第 j 列值为 v 时的最小操作数。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 预计算每列改为 0 和改为 1 的代价
        cost = []
        for j in range(n):
            ones = sum(grid[i][j] for i in range(m))
            zeros = m - ones
            cost.append((zeros, ones))  # cost[j][0]=改为0的代价, cost[j][1]=改为1的代价

        # dp[v] 表示当前列值为 v 时的最小操作总数
        INF = float('inf')
        dp = [cost[0][0], cost[0][1]]  # 第 0 列

        for j in range(1, n):
            new_dp = [INF, INF]
            # 当前列为 0
            new_dp[0] = min(dp[1]) + cost[j][0]  # 前一列必须为 1
            # 当前列为 1
            new_dp[1] = min(dp[0]) + cost[j][1]  # 前一列必须为 0
            dp = new_dp

        return min(dp)
```

### 方法二：直接枚举两种方案

```python
from typing import List

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 两种方案：偶数列为 0/1
        ans = float('inf')
        for start in range(2):  # 第 0 列为 start
            ops = 0
            for j in range(n):
                target = (start + j) % 2
                # 将第 j 列改为 target 的代价
                ops += sum(1 for i in range(m) if grid[i][j] != target)
            ans = min(ans, ops)
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历矩阵
- 空间复杂度：O(n)（方法一）或 O(1)（方法二）

## 关键点总结

1. 最终矩阵一定是两种交替方案之一
2. 每列独立计算修改代价，选最优即可
3. DP 只需维护上一列的两个状态

## 易错点

1. 只有两种合法交替方案，不要遗漏
2. 每列的代价要重新计算（不能复用）
