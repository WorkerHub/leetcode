## 题目描述

[LeetCode 1207. Unique Number of Occurrences](https://leetcode.com/problems/unique-number-of-occurrences/)

给你一个整数数组 `arr`，请你帮忙统计数组中每个数的出现次数。

如果每个数的出现次数都是独一无二的，就返回 `true`；否则返回 `false`。

**示例 1:**
```
输入：arr = [1,2,2,1,1,3]
输出：true
解释：在该数组中，1 出现了 3 次，2 出现了 2 次，3 只出现了 1 次。没有两个数的出现次数相同。
```

**示例 2:**
```
输入：arr = [1,2]
输出：false
```

**示例 3:**
```
输入：arr = [-3,0,1,-3,1,1,1,-3,10,0]
输出：true
```

**提示:**
- 1 <= arr.length <= 1000
- -1000 <= arr[i] <= 1000

## 解题思路

这是一道经典的哈希表应用题，考查的是基础的统计和去重操作。

### 解题步骤

1. **统计频率**：使用哈希表统计每个数字的出现次数
2. **检查唯一性**：检查所有出现次数是否都是唯一的

### 如何检查唯一性

有两种常用方法：
- **方法一**：使用集合（Set），如果出现次数的个数等于不同出现次数的个数，则唯一
- **方法二**：遍历出现次数，检查是否有重复

集合方法更简洁：`len(频率列表) == len(set(频率列表))`

## Python 代码实现

### 方法一：哈希表 + 集合（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        # 统计每个数字的出现次数
        count = Counter(arr)
        
        # 获取所有出现次数
        frequencies = count.values()
        
        # 检查出现次数是否唯一
        # 如果有重复，集合的长度会小于列表长度
        return len(frequencies) == len(set(frequencies))
```

### 方法二：手动实现哈希表

```python
from typing import List

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        # 手动统计频率
        count = {}
        for num in arr:
            count[num] = count.get(num, 0) + 1
        
        # 获取所有出现次数
        frequencies = list(count.values())
        
        # 使用集合检查唯一性
        return len(frequencies) == len(set(frequencies))
```

### 方法三：一次遍历（空间优化）

```python
from typing import List
from collections import Counter

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        # 统计频率
        count = Counter(arr)
        
        # 用集合存储已见过的出现次数
        seen = set()
        
        for freq in count.values():
            # 如果出现次数已经存在，说明不唯一
            if freq in seen:
                return False
            seen.add(freq)
        
        return True
```

### 方法四：Python 一行解法

```python
from typing import List
from collections import Counter

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        # Counter(arr).values() 获取所有出现次数
        # 转为列表后与集合比较长度
        return len(set(Counter(arr).values())) == len(Counter(arr).values())
```

### 方法五：更简洁的一行解法

```python
from typing import List
from collections import Counter

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        c = Counter(arr).values()
        return len(set(c)) == len(list(c))
```

## 复杂度分析

### 方法一、二、三

- **时间复杂度**：O(n)
  - 统计频率：O(n)，需要遍历整个数组
  - 构建集合：O(k)，k 是不同数字的个数，最多为 n
  - 总体：O(n)
  
- **空间复杂度**：O(n)
  - 哈希表存储频率：最多 O(n) 个不同数字
  - 集合存储出现次数：最多 O(n) 个不同频率
  - 总体：O(n)

## 关键点总结

1. **Counter 的使用**：Python 的 `Counter` 是统计频率的利器，返回一个字典

2. **集合去重**：集合自动去重的特性可以用来检查是否有重复元素

3. **字典的 values() 方法**：返回所有值的视图对象，可以转为列表或集合

4. **长度比较技巧**：`len(list) == len(set(list))` 是检查列表元素唯一性的常用方法

5. **一行解法**：虽然简洁，但可读性较差，实际项目中建议使用方法一

## 易错点

1. **混淆统计对象**：
   - 要统计的是"出现次数"是否唯一，不是"数字"是否唯一
   - 例如 [1,2,2,1,1,3]，数字有 1、2、3，出现次数有 3、2、1

2. **Counter 重复调用**：
   - 方法四中 `Counter(arr)` 被调用了两次，效率较低
   - 应该先赋值给变量再使用

3. **空数组处理**：
   - 虽然题目保证 arr.length >= 1，但空数组应该返回 `true`
   - Counter({}) 的 values() 是空的，`len([]) == len(set([]))` 为 `true`

4. **理解 Counter.values()**：
   - 返回的是 dict_values 对象，不是列表
   - 可以直接迭代，但某些操作需要转为列表

5. **集合的开销**：
   - 构建集合有一定开销，对于大数据量，方法三可能更快（早停）
