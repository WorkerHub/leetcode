## 题目描述

有 `n` 个工人要将仓库中的物品搬运到对面。桥的一次只能过一个人。

每个工人有四个参数：`leftToRight[i]`（从左到右的时间）、`pickOld[i]`（在旧仓库取货时间）、`rightToLeft[i]`（从右到左的时间）、`putNew[i]`（在新仓库放货时间）。

搬运总共需要进行 `k` 次。请返回最后一个工人将物品放到新仓库（左侧）后，到达左岸的时间。

**示例：**

```
输入：n = 3, k = 2, time = [[1,9,1,8],[10,10,10,10],[6,2,6,2]]
输出：6
```

**提示：**

- `1 <= n, k <= 10^4`
- `time.length == n`

## 解题思路

**模拟 + 多个堆**：

维护四个堆：
- `wait_left`：等待过桥（从右到左）的工人（按效率排，效率低的优先）
- `wait_right`：等待过桥（从左到右）的工人
- `work_left`：在左侧仓库放货的工人（按完成时间排）
- `work_right`：在右侧仓库取货的工人（按完成时间排）

效率定义为 `leftToRight + rightToLeft`，越大越低效，优先级越高（先过桥）。

## Python 代码实现

### 方法一：四堆模拟（推荐）

```python
from typing import List
import heapq

class Solution:
    def findCrossingTime(self, n: int, k: int, time: List[List[int]]) -> int:
        # 工人效率：leftToRight + rightToLeft 越大优先级越高（用负值表示）
        # wait_left/wait_right: (-效率, 工人编号)
        # work_left/work_right: (完成时间, 工人编号)

        wait_left = [(-time[i][0] - time[i][2], i) for i in range(n)]
        heapq.heapify(wait_left)
        wait_right = []
        work_left = []
        work_right = []

        cur_time = 0
        remaining = k  # 还需要搬运的次数

        while True:
            # 将完成工作的工人移到等待队列
            while work_left and work_left[0][0] <= cur_time:
                t, i = heapq.heappop(work_left)
                heapq.heappush(wait_left, (-time[i][0] - time[i][2], i))
            while work_right and work_right[0][0] <= cur_time:
                t, i = heapq.heappop(work_right)
                heapq.heappush(wait_right, (-time[i][0] - time[i][2], i))

            # 决定谁过桥
            if wait_right:
                # 右侧有工人等待回来（优先）
                _, i = heapq.heappop(wait_right)
                cur_time += time[i][2]  # 从右到左
                if remaining == 0 and not wait_right and not work_right:
                    return cur_time
                # 在左侧仓库放货
                heapq.heappush(work_left, (cur_time + time[i][3], i))
            elif wait_left and remaining > 0:
                # 左侧有工人等待去搬运
                _, i = heapq.heappop(wait_left)
                cur_time += time[i][0]  # 从左到右
                remaining -= 1
                # 在右侧仓库取货
                heapq.heappush(work_right, (cur_time + time[i][1], i))
            else:
                # 没有等待的工人，时间跳跃到最近完成的工人
                next_time = float('inf')
                if wait_right or work_right:
                    if work_right:
                        next_time = min(next_time, work_right[0][0])
                if remaining > 0 and (wait_left or work_left):
                    if work_left:
                        next_time = min(next_time, work_left[0][0])
                if next_time == float('inf'):
                    break
                cur_time = next_time
```

### 方法二：更简洁的时间跳跃版本

```python
from typing import List
import heapq

class Solution:
    def findCrossingTime(self, n: int, k: int, time: List[List[int]]) -> int:
        wait_l = [(-time[i][0]-time[i][2], i) for i in range(n)]
        heapq.heapify(wait_l)
        wait_r, work_l, work_r = [], [], []
        cur = 0
        rem = k

        while rem > 0 or wait_r or work_r:
            # 释放完成工作的工人
            while work_r and work_r[0][0] <= cur:
                ft, i = heapq.heappop(work_r)
                heapq.heappush(wait_r, (-time[i][0]-time[i][2], i))
            while work_l and work_l[0][0] <= cur:
                ft, i = heapq.heappop(work_l)
                heapq.heappush(wait_l, (-time[i][0]-time[i][2], i))

            if wait_r:
                _, i = heapq.heappop(wait_r)
                cur += time[i][2]
                if rem == 0 and not wait_r and not work_r:
                    return cur
                heapq.heappush(work_l, (cur + time[i][3], i))
            elif rem > 0 and wait_l:
                _, i = heapq.heappop(wait_l)
                cur += time[i][0]
                rem -= 1
                heapq.heappush(work_r, (cur + time[i][1], i))
            else:
                # 时间跳跃
                nxt = float('inf')
                if work_r:
                    nxt = min(nxt, work_r[0][0])
                if rem > 0 and work_l:
                    nxt = min(nxt, work_l[0][0])
                cur = nxt

        return cur
```

## 复杂度分析

- 时间复杂度：O(k log n)，每次搬运涉及堆操作
- 空间复杂度：O(n)，四个堆的总大小

## 关键点总结

1. 四个堆：等待过桥（左/右）和正在工作（左/右）
2. 优先级：效率低（`leftToRight + rightToLeft` 大）的工人优先过桥
3. 右侧等待的工人优先于左侧（需要先把货物送回来）

## 易错点

1. 当 remaining == 0 且右侧无人等待时，最后一个过桥的工人到达左岸即为答案
2. 时间跳跃时要找最近完成的工作的时刻
3. 桥同一时刻只能一人通过
