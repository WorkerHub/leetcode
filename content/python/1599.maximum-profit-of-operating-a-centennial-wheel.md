## 题目描述

有一个摩天轮，每次旋转可以搭载最多 4 名乘客，每次旋转成本为 `runningCost`，每位乘客支付 `boardingCost`。

给你一个数组 `customers`，`customers[i]` 表示第 `i` 次旋转前到达的乘客数（最多等待，下次上车）。

每次旋转时，等候区有人就运行；等候区为空则停止。

返回**最大利润时**已经旋转的次数，如果始终无法盈利则返回 `-1`。

**示例 1：**
```
输入：customers = [8,3], boardingCost = 5, runningCost = 6
输出：3
解释：
第1轮：8人到，上4人，等待4人，收入 4*5-6=14，累计14
第2轮：3人到，上4人，等待3人，收入 4*5-6=14，累计28
第3轮：0人到，上3人，等待0人，收入 3*5-6=9，累计37
第4轮无人等待，停止。最大利润37，在第3轮。
```

**提示：**
- `1 <= customers.length <= 10^5`

## 解题思路

### 模拟

直接按顺序模拟每一轮旋转：
1. 累积等待人数
2. 每轮最多上 4 人
3. 计算每轮净利润，更新最大利润和对应轮次

**注意：** 处理完 `customers` 后，若等待区仍有人，需继续运行直到等待区清空。

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def minOperationsMaxProfit(self, customers: List[int], boardingCost: int, runningCost: int) -> int:
        waiting = 0       # 等候区人数
        profit = 0        # 当前累计利润
        max_profit = 0    # 历史最大利润
        best_rot = -1     # 最大利润时的旋转次数
        rot = 0           # 当前旋转次数

        i = 0
        while i < len(customers) or waiting > 0:
            # 新乘客到达（若还在 customers 范围内）
            if i < len(customers):
                waiting += customers[i]
                i += 1

            # 本轮上车人数（最多4人）
            board = min(4, waiting)
            waiting -= board

            # 本轮利润
            profit += board * boardingCost - runningCost
            rot += 1

            # 更新最大利润
            if profit > max_profit:
                max_profit = profit
                best_rot = rot

        return best_rot
```

### 方法二：两阶段模拟（更清晰）

```python
from typing import List

class Solution:
    def minOperationsMaxProfit(self, customers: List[int], boardingCost: int, runningCost: int) -> int:
        waiting = 0
        total_profit = 0
        max_profit = 0
        best_rot = -1
        rot = 0

        # 阶段1：处理有新客到来的轮次
        for c in customers:
            waiting += c
            board = min(4, waiting)
            waiting -= board
            total_profit += board * boardingCost - runningCost
            rot += 1
            if total_profit > max_profit:
                max_profit = total_profit
                best_rot = rot

        # 阶段2：清空等待区（无新客到来）
        # 每轮上4人，共需 ceil(waiting/4) 轮
        while waiting > 0:
            board = min(4, waiting)
            waiting -= board
            total_profit += board * boardingCost - runningCost
            rot += 1
            if total_profit > max_profit:
                max_profit = total_profit
                best_rot = rot

        return best_rot
```

## 复杂度分析

- **时间复杂度**：O(N + waiting_max / 4)，通常 O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. 等候区人数滚动累加，每轮最多消耗 4 人
2. 需要在全部 `customers` 处理后，继续清空等候区
3. 记录累计利润的**严格最大值**对应的旋转轮次

## 易错点

- 最大利润需要是**严格大于**历史最大（`>`，而非 `>=`），因为题目要"最大利润时最早的轮次"
- 若始终不盈利（`max_profit` 从未被更新），返回 `-1`
