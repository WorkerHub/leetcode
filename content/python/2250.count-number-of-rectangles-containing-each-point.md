## 题目描述

给你一个二维整数数组 `rectangles`，其中 `rectangles[i] = [li, hi]` 表示第 `i` 个矩形，左下角在原点 `(0, 0)`，右上角在 `(li, hi)`。

另有一个二维整数数组 `points`，其中 `points[j] = [xj, yj]` 是第 `j` 个查询点。

对于每个查询点，统计包含该点的矩形数量（矩形边界上的点也算包含）。

返回一个数组 `count`，`count[j]` 是包含第 `j` 个查询点的矩形数量。

**提示：**
- `h <= 100`（高度范围小）

## 解题思路

由于矩形左下角固定在原点，矩形 `(l, h)` 包含点 `(x, y)` 当且仅当 `x <= l` 且 `y <= h`。

**利用高度范围小（1 到 100）：** 对每个高度 h，维护该高度下所有矩形的宽度列表（排序）。

对每个查询点 `(x, y)`，遍历所有 `h >= y` 的高度，在对应的宽度列表中二分查找 `>= x` 的数量（即 `l >= x` 的矩形数）。

时间复杂度 O((m + n) * H_MAX / scale * log m)，其中 H_MAX = 100。

## 代码实现

### 方法一：按高度分组 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def countRectangles(self, rectangles: List[List[int]], points: List[List[int]]) -> List[int]:
        H_MAX = 101
        # 对每个高度 h，存储所有具有该高度的矩形宽度（已排序）
        by_height = [[] for _ in range(H_MAX)]

        for l, h in rectangles:
            by_height[h].append(l)

        for h in range(H_MAX):
            by_height[h].sort()

        ans = []
        for x, y in points:
            count = 0
            # 遍历所有 h >= y 的高度
            for h in range(y, H_MAX):
                if not by_height[h]:
                    continue
                # 在 by_height[h] 中找第一个 >= x 的位置
                pos = bisect.bisect_left(by_height[h], x)
                count += len(by_height[h]) - pos
            ans.append(count)

        return ans
```

### 方法二：暴力（适合理解）

```python
from typing import List

class Solution:
    def countRectangles(self, rectangles: List[List[int]], points: List[List[int]]) -> List[int]:
        ans = []
        for x, y in points:
            count = sum(1 for l, h in rectangles if l >= x and h >= y)
            ans.append(count)
        return ans
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(m log m + n * H * log m / H) = O(m log m + n * H_MAX + n * log m)。实际 O((m + n) * H_MAX)。
- 空间复杂度：O(m + H_MAX)。

**方法二（暴力）：**
- 时间复杂度：O(m * n)，可能超时。

## 关键点总结

1. 利用 `h <= 100` 的约束，按高度分桶存储矩形宽度。
2. 查询时遍历所有满足 `h >= y` 的桶，二分查找 `l >= x` 的矩形数。
3. 二分 `bisect_left` 找到第一个 `>= x` 的位置，之后的元素都满足。

## 易错点

- 矩形包含点的条件：`l >= x AND h >= y`（左下角在原点，所以要 `l >= x`）。
- 遍历高度时从 `y` 到 `H_MAX - 1`，包含等于 `y` 的情况。
