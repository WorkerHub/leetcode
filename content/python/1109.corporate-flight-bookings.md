## 题目描述

这里有 `n` 个航班，它们分别从 `1` 到 `n` 进行编号。

有一份航班预订表 `bookings`，表中第 `i` 条预订记录 `bookings[i] = [firsti, lasti, seatsi]` 意味着在从 `firsti` 到 `lasti`（包含 `firsti` 和 `lasti`）的每个航班上预订了 `seatsi` 个座位。

请你返回一个长度为 `n` 的数组 `answer`，里面的元素是每个航班预定的座位总数。

**示例 1：**
```
输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
解释：
航班编号        1   2   3   4   5
预订记录 1 ：   10  10
预订记录 2 ：       20  20
预订记录 3 ：       25  25  25  25
总座位数：      10  55  45  25  25
因此，answer = [10,55,45,25,25]
```

**示例 2：**
```
输入：bookings = [[1,2,10],[2,2,15]], n = 2
输出：[10,25]
解释：
航班编号        1   2
预订记录 1 ：   10  10
预订记录 2 ：       15
总座位数：      10  25
因此，answer = [10,25]
```

**提示：**
- `1 <= n <= 2 * 10^4`
- `1 <= bookings.length <= 2 * 10^4`
- `bookings[i].length == 3`
- `1 <= firsti <= lasti <= n`
- `1 <= seatsi <= 10^4`

## 解题思路

这道题是经典的**区间修改、单点查询**问题，最优解是使用**差分数组**。

**暴力解法思路：**
- 遍历每个预订记录，将 `[first, last]` 区间内的每个航班都加上 `seats`
- 时间复杂度：O(m × n)，其中 m 是预订记录数，n 是航班数
- 当数据量大时会超时

**差分数组优化：**

差分数组是一种巧妙的技巧，用于高效处理区间修改问题。

**核心思想：**
- 对于区间 `[l, r]` 加上 `val`，我们只需要：
  - 在位置 `l` 处加上 `val`
  - 在位置 `r+1` 处减去 `val`
- 最后对差分数组求前缀和，就得到了最终结果

**为什么有效？**
- 差分数组记录的是"变化量"
- 前缀和会将这个"变化量"累积到后面的所有位置
- 在 `r+1` 处减去，可以让累积效果在 `r` 之后停止

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        # 创建差分数组，长度为 n+2 以避免边界检查
        diff = [0] * (n + 2)
        
        # 对每个预订记录进行差分操作
        for first, last, seats in bookings:
            # 在起始位置增加 seats
            diff[first] += seats
            # 在结束位置的下一个位置减去 seats
            diff[last + 1] -= seats
        
        # 对差分数组求前缀和，得到最终结果
        answer = []
        current_sum = 0
        for i in range(1, n + 1):
            current_sum += diff[i]
            answer.append(current_sum)
        
        return answer
```

### 方法二：差分数组（简化版）

```python
from typing import List

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        # 直接使用长度为 n 的数组
        answer = [0] * n
        
        # 差分操作
        for first, last, seats in bookings:
            # 注意：航班编号从 1 开始，数组索引从 0 开始
            answer[first - 1] += seats
            # 只在不越界的情况下减去
            if last < n:
                answer[last] -= seats
        
        # 求前缀和
        for i in range(1, n):
            answer[i] += answer[i - 1]
        
        return answer
```

### 方法三：暴力解法（会超时）

```python
from typing import List

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        # 初始化结果数组
        answer = [0] * n
        
        # 遍历每个预订记录
        for first, last, seats in bookings:
            # 将区间 [first, last] 内的每个航班都加上 seats
            for i in range(first - 1, last):
                answer[i] += seats
        
        return answer
```

### 方法四：使用 itertools.accumulate

```python
from typing import List
from itertools import accumulate

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        # 创建差分数组
        diff = [0] * (n + 1)
        
        # 差分操作
        for first, last, seats in bookings:
            diff[first - 1] += seats
            if last < n:
                diff[last] -= seats
        
        # 使用 accumulate 求前缀和
        return list(accumulate(diff[:n]))
```

## 复杂度分析

**方法一、二（差分数组）：**
- 时间复杂度：O(m + n)，其中 m 是预订记录数，n 是航班数
  - 遍历 bookings：O(m)
  - 求前缀和：O(n)
- 空间复杂度：O(1)，不计算返回值的空间

**方法三（暴力）：**
- 时间复杂度：O(m × n)，每个预订记录可能影响 O(n) 个航班
- 空间复杂度：O(1)

## 关键点总结

1. **差分数组的本质**：记录相邻元素之间的差值，将区间修改转化为单点修改
2. **区间操作的优化**：
   - 原始方法：O(n) 的区间修改
   - 差分方法：O(1) 的两次单点修改
3. **前缀和与差分的关系**：
   - 差分是前缀和的逆运算
   - 对差分数组求前缀和，得到原数组
4. **边界处理**：注意 `r+1` 可能越界，需要检查或使用更大的数组
5. **索引转换**：航班编号从 1 开始，数组索引从 0 开始，注意转换

## 易错点

1. **索引偏移错误**：
   - 航班编号是 1-indexed
   - 数组索引是 0-indexed
   - 需要 `first - 1` 和 `last - 1` 转换

2. **边界越界**：
   - `diff[last + 1]` 可能越界
   - 解决方法：创建 `n+2` 大小的数组或者增加边界检查

3. **前缀和的起始位置**：
   - 要从索引 1 开始求前缀和（对应航班 1）
   - 或者从索引 0 开始（需要正确转换）

4. **累加方向错误**：
   - 必须从左到右累加
   - 不能从右到左

5. **忘记减去**：
   - 只在起始位置加，忘记在结束位置后减去
   - 导致后续所有位置都被错误累加
