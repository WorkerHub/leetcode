## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，其中 `nums[i]` 是 0 到 9 之间（含两端）的一个数字。

**三角形和** 的定义如下：
- 不断用相邻两数之和（取个位数，即模 10）替换数组，直到数组只剩一个元素。
- 返回最终剩下的那个元素。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：8
解释：
[1,2,3,4,5] -> [3,5,7,9] -> [8,12,16] -> [20,28] -> [48] -> 8
```

**示例 2：**
```
输入：nums = [5]
输出：5
```

## 解题思路

**方法一（模拟）：** 直接模拟每一步操作，每步数组长度减 1，共操作 n-1 次。

**方法二（组合数学）：** 最终答案是原数组每个元素乘以对应系数之和（模 10）。系数是二项式系数 C(n-1, 0), C(n-1, 1), ..., C(n-1, n-1)（即杨辉三角第 n-1 行），每个系数模 2 和模 5 后再组合（由于是模 10）。

对于小数据（n <= 1000），直接模拟即可。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def triangularSum(self, nums: List[int]) -> int:
        # 模拟每一轮操作直到数组长度为1
        while len(nums) > 1:
            nums = [(nums[i] + nums[i + 1]) % 10 for i in range(len(nums) - 1)]
        return nums[0]
```

### 方法二：原地修改（节省空间）

```python
from typing import List

class Solution:
    def triangularSum(self, nums: List[int]) -> int:
        n = len(nums)
        # 每轮将 nums[i] 更新为 (nums[i] + nums[i+1]) % 10
        for length in range(n, 1, -1):
            for i in range(length - 1):
                nums[i] = (nums[i] + nums[i + 1]) % 10
        return nums[0]
```

### 方法三：组合数学（利用二项式系数）

```python
from typing import List
from math import comb

class Solution:
    def triangularSum(self, nums: List[int]) -> int:
        n = len(nums)
        # 答案 = sum(C(n-1, i) * nums[i]) mod 10
        # 由于 mod 10 = mod 2 * mod 5，用中国剩余定理
        total = 0
        for i, x in enumerate(nums):
            total += comb(n - 1, i) * x
        return total % 10
```

## 复杂度分析

**方法一（模拟）：**
- 时间复杂度：O(n^2)，共 n-1 轮，每轮 O(n)。
- 空间复杂度：O(n)，新数组。

**方法二（原地）：**
- 时间复杂度：O(n^2)。
- 空间复杂度：O(1)，原地修改。

**方法三（组合）：**
- 时间复杂度：O(n)（预计算二项式系数后）。
- 空间复杂度：O(1)。

## 关键点总结

1. 模拟法直观，适合理解题意。
2. 组合数学法 O(n)，利用每个元素对最终结果的贡献是二项式系数。
3. 注意取个位数（模 10），不是普通的求和。

## 易错点

- 每次操作取个位，即 `(a + b) % 10`，不是直接相加。
- 方法三中 comb(n-1, i) 可能很大，但模 10 后不影响正确性。
