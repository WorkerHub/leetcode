## 题目描述

给你一个整数数组 `nums`（长度 `n`）和整数数组 `pattern`（长度 `m`）。

如果子数组 `nums[i..i+m]` 满足：对每个 `j`（0 <= j < m），
- `nums[i+j] < nums[i+j+1]` 时 `pattern[j] == 1`
- `nums[i+j] == nums[i+j+1]` 时 `pattern[j] == 0`
- `nums[i+j] > nums[i+j+1]` 时 `pattern[j] == -1`

则称该子数组匹配 `pattern`。

返回匹配 `pattern` 的子数组数量。

**示例 1：**
```
输入：nums = [1,2,3,4,5,6], pattern = [1,1]
输出：4
```

**示例 2：**
```
输入：nums = [1,4,4,1,3,5,5,3], pattern = [1,0,-1]
输出：2
```

**提示：**
- `2 <= n <= 100`
- `1 <= m <= n - 1`
- `-1 <= pattern[j] <= 1`

## 解题思路

1. 将 `nums` 转换为差分符号数组 `sign`：`sign[i] = sign(nums[i+1] - nums[i])`
2. 在 `sign` 中找 `pattern` 出现的次数（字符串匹配问题）
3. 可以使用 KMP 或直接暴力匹配（n <= 100 时）

## Python 代码实现

### 方法一：转换 + KMP（推荐）

```python
from typing import List

class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        n = len(nums)
        m = len(pattern)

        # 将 nums 转换为相邻比较的符号数组
        def sign(x):
            if x > 0: return 1
            if x < 0: return -1
            return 0

        diff = [sign(nums[i+1] - nums[i]) for i in range(n-1)]

        # KMP 在 diff 中搜索 pattern
        def compute_fail(pat):
            k = len(pat)
            fail = [0] * k
            j = 0
            for i in range(1, k):
                while j > 0 and pat[i] != pat[j]:
                    j = fail[j-1]
                if pat[i] == pat[j]:
                    j += 1
                fail[i] = j
            return fail

        fail = compute_fail(pattern)
        count = 0
        j = 0
        for i in range(len(diff)):
            while j > 0 and diff[i] != pattern[j]:
                j = fail[j-1]
            if diff[i] == pattern[j]:
                j += 1
            if j == m:
                count += 1
                j = fail[j-1]

        return count
```

### 方法二：暴力匹配（n <= 100 时）

```python
from typing import List

class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        n = len(nums)
        m = len(pattern)

        def sign(x):
            return 1 if x > 0 else (-1 if x < 0 else 0)

        count = 0
        for i in range(n - m):
            match = True
            for j in range(m):
                if sign(nums[i+j+1] - nums[i+j]) != pattern[j]:
                    match = False
                    break
            if match:
                count += 1

        return count
```

## 复杂度分析

- KMP：O(n + m)
- 暴力：O(n * m)，n, m <= 100 时可行
- 空间复杂度：O(n + m)

## 关键点总结

1. 将数值比较转换为符号 (-1, 0, 1) 后，问题变为字符串匹配
2. KMP 算法适合子序列匹配计数
3. `sign` 函数将差值映射到 {-1, 0, 1}

## 易错点

1. `diff` 数组长度为 `n-1`，pattern 长度 `m` <= `n-1`
2. 注意 `sign(0) == 0` 对应 `pattern[j] == 0`
