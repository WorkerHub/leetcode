## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，`nums` 的一个子数组如果满足其中任意两个元素之差的绝对值 <= 2，则称该子数组为 **连续子数组**。

返回 `nums` 中连续子数组的总数目。

**示例 1：**
```
输入：nums = [5,4,2,4]
输出：8
解释：长度1有4个，长度2有3个，长度3有1个（[5,4,2]中max-min=3>2，不算），[4,2,4]：4-2=2<=2，算
```

**示例 2：**
```
输入：nums = [1,2,3]
输出：6
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**滑动窗口 + 单调队列**：维护窗口 `[left, right]`，保证窗口内 `max - min <= 2`。

用两个单调队列分别维护窗口的最大值和最小值：
- `max_deque`：单调递减队列（队首为最大值）
- `min_deque`：单调递增队列（队首为最小值）

右端每移动一步，若 `max - min > 2` 则移动左端。每个右端位置，以它结尾的合法子数组数量为 `right - left + 1`。

## Python 代码实现

### 方法一：单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def continuousSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        left = 0
        max_dq = deque()  # 单调递减，维护窗口最大值
        min_dq = deque()  # 单调递增，维护窗口最小值

        for right in range(n):
            # 维护单调递减队列（最大值）
            while max_dq and nums[max_dq[-1]] <= nums[right]:
                max_dq.pop()
            max_dq.append(right)

            # 维护单调递增队列（最小值）
            while min_dq and nums[min_dq[-1]] >= nums[right]:
                min_dq.pop()
            min_dq.append(right)

            # 若窗口不满足条件，移动 left
            while nums[max_dq[0]] - nums[min_dq[0]] > 2:
                left += 1
                if max_dq[0] < left:
                    max_dq.popleft()
                if min_dq[0] < left:
                    min_dq.popleft()

            ans += right - left + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素入队/出队各一次
- 空间复杂度：O(n)

## 关键点总结

1. 单调队列同时维护窗口最大值和最小值
2. 当最大值 - 最小值 > 2 时，缩小窗口
3. 以 right 结尾的合法子数组数等于 `right - left + 1`

## 易错点

1. 移动 left 后，需要检查两个队列的队首是否过期（< left）
2. 单调队列的递增/递减方向要搞清楚
