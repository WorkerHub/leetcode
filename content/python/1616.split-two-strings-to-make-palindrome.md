## 题目描述

给你两个字符串 `a` 和 `b`，它们长度相同。选择两个下标 `i` 和 `j`（`0 <= i <= j < s.length`），从每个字符串中分别取出子串，然后将它们拼接成一个新字符串，看新字符串是否是回文串。

具体来说，你需要检验字符串 `aprefix + bsuffix` 或者 `bprefix + asuffix` 是否是回文串。

- `aprefix` 是字符串 `a[0..i]`
- `asuffix` 是字符串 `a[j..]`
- `bprefix` 是字符串 `b[0..i]`
- `bsuffix` 是字符串 `b[j..]`

如果存在使得任一拼接结果是回文串，返回 `true`，否则返回 `false`。

**示例：**
```
输入：a = "x", b = "y"
输出：false

输入：a = "abdef", b = "fecab"
输出：true
（a[0..1] + b[2..4] = "ab" + "cab" = "abcab" 是回文串）
```

## 解题思路

使用**双指针**从两端向中间匹配：

对于 `aprefix + bsuffix`：
1. 用左指针 `l` 从 `a` 的左端和右指针 `r` 从 `b` 的右端开始
2. 若 `a[l] == b[r]`，则两端可以匹配，`l++, r--`
3. 当 `a[l] != b[r]` 时，中间剩余部分必须是回文串（只从 `a` 或只从 `b` 中取）

同理对 `bprefix + asuffix` 也做一次检测。

## 代码实现

### 方法一：双指针贪心（推荐）

```python
class Solution:
    def checkPalindromeFormation(self, a: str, b: str) -> bool:
        def is_palindrome(s: str, l: int, r: int) -> bool:
            """检查 s[l..r] 是否是回文串"""
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True
        
        def can_form(a: str, b: str) -> bool:
            """检查 a 的某前缀 + b 的对应后缀是否能构成回文"""
            n = len(a)
            l, r = 0, n - 1
            # 从两端向中间匹配
            while l < r and a[l] == b[r]:
                l += 1
                r -= 1
            # 剩余中间部分必须是回文（只用 a 或只用 b 的中间部分）
            return is_palindrome(a, l, r) or is_palindrome(b, l, r)
        
        return can_form(a, b) or can_form(b, a)
```

### 方法二：分情况枚举（较详细）

```python
class Solution:
    def checkPalindromeFormation(self, a: str, b: str) -> bool:
        n = len(a)
        
        def is_palindrome(s: str) -> bool:
            return s == s[::-1]
        
        def check(x: str, y: str) -> bool:
            """检查 x 的某前缀 + y 的对应后缀能否构成回文"""
            l, r = 0, n - 1
            while l < r and x[l] == y[r]:
                l += 1
                r -= 1
            if l >= r:
                return True  # 整体已经匹配
            # 中间 [l, r] 要么全从 x 取，要么全从 y 取
            return is_palindrome(x[l:r+1]) or is_palindrome(y[l:r+1])
        
        return check(a, b) or check(b, a)
```

|------|-----------|-----------|
| 双指针 | O(n) | O(1) |

## 关键点总结

1. 核心思路：双指针从两端同时匹配，直到遇到不匹配的字符
2. 此时中间部分只能来自单一字符串，检查这段子串是否是回文
3. 需要对 `(a, b)` 和 `(b, a)` 两种情况分别检测
4. 当双指针完全匹配（`l >= r`）时，直接返回 `True`

## 易错点

- 要对两种拼接方式（`a前缀+b后缀` 和 `b前缀+a后缀`）都检测
- 中间部分有两种选择（从 `a` 或从 `b` 取），需要 `or` 关系
- 当 `n = 1` 时，单个字符是回文，返回 `True`
