## 题目描述

给你一个浮点数 `hour`（表示你有多少小时赶火车），以及一个整数数组 `dist`，其中 `dist[i]` 表示第 `i` 段行程的距离。

每段行程都以**整点**时刻开始，速度为 `speed`（整数）。除最后一段外，每段结束时需要等到下一个整点才能开始下一段（即每段总花费时间向上取整）。

返回能准时赶到的**最小正整数速度**，若无法赶到（无论速度多快），则返回 -1。

**示例 1：**
```
输入：dist = [1,3,2], hour = 6
输出：1
```

**示例 2：**
```
输入：dist = [1,3,2], hour = 2.7
输出：3
```

**提示：**
- `1 <= dist.length <= 10^5`
- `1 <= hour <= 10^9`
- `dist.length - 1 < hour`（保证可能赶到）

## 解题思路

**二分查找**：对速度进行二分查找。

给定速度 `speed`，计算总花费时间：
- 前 n-1 段：每段时间 = `ceil(dist[i] / speed)`（向上取整，等到下一整点）
- 最后一段：时间 = `dist[-1] / speed`（可以是小数）

若总时间 <= `hour`，则 `speed` 可行。

时间关于速度单调递减，二分查找最小可行速度。

**上界估计**：最大速度为 `max(dist) * (n-1) / (hour - 1)` 附近，但直接取 10^7 即可。

## 代码实现

### 方法一：二分查找（推荐）

```python
import math
from typing import List

class Solution:
    def minSpeedOnTime(self, dist: List[List[int]], hour: float) -> int:
        n = len(dist)
        # 若行程段数 > hour（每段至少 1 小时），则无解
        if n - 1 >= hour:
            return -1

        def can_arrive(speed: int) -> bool:
            total = 0.0
            for i in range(n - 1):
                # 每段时间向上取整
                total += math.ceil(dist[i] / speed)
            total += dist[-1] / speed  # 最后一段不取整
            return total <= hour

        lo, hi = 1, 10 ** 7
        while lo < hi:
            mid = (lo + hi) // 2
            if can_arrive(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：整数技巧避免浮点误差

```python
import math
from typing import List

class Solution:
    def minSpeedOnTime(self, dist: List[int], hour: float) -> int:
        n = len(dist)
        if n - 1 >= hour:
            return -1

        # 将 hour 转为整数分母处理（避免浮点误差）
        # hour 可能是小数，如 2.7 = 27/10
        # 用 hour * 10^x 转整数
        def feasible(speed: int) -> bool:
            total = 0
            for i in range(n - 1):
                total += math.ceil(dist[i] / speed)
            # 最后一段用精确除法
            # 检查 total + dist[-1]/speed <= hour
            # 即 total * speed + dist[-1] <= hour * speed
            return total + dist[-1] / speed <= hour

        lo, hi = 1, 10 ** 7
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- **时间复杂度**：O(n * log(max_speed))，二分查找 O(log(10^7)) ≈ 23 次，每次验证 O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 对速度二分，验证给定速度是否可行
2. 前 n-1 段每段花费时间向上取整（`math.ceil`），最后一段不取整
3. 若 `n - 1 >= hour`，无论速度多快都需要至少 n-1 小时等待，不可能准时

## 易错点

- 最后一段时间不向上取整，直接除以速度
- 无解条件：`n-1 >= hour`（行程数 - 1 段等待时间已超过时限）
