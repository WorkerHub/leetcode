## 题目描述

你有两个 **有序** 整数数组 `nums1` 和 `nums2`，它们可能包含**重复**元素。从 `nums1[0]` 或 `nums2[0]` 出发，每次可以：
1. 沿当前数组向右走一步
2. 若当前值在两个数组中都出现，可以切换到另一个数组继续走

求从开头走到末尾（`nums1[-1]` 或 `nums2[-1]`）经过的数之和的最大值，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums1 = [2,4,5,8,10], nums2 = [4,6,8,9]
输出：30
解释：路径 2->4->6->8->10，和为 30
```

## 解题思路

### 双指针 + 贪心

两数组都有序，公共元素（出现在两数组中的值）是可以切换的节点。

**算法：**
1. 用双指针扫描两数组
2. 在两个公共元素之间，分别累加 `nums1` 和 `nums2` 的段和 `s1`、`s2`
3. 到达公共元素时，将 `max(s1, s2)` 加到答案，并将公共元素值加入答案
4. 重置 `s1 = s2 = 0`，继续

## 代码实现

### 方法一：双指针贪心（推荐）

```python
from typing import List

class Solution:
    def maxSum(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10**9 + 7
        i, j = 0, 0
        s1, s2 = 0, 0
        ans = 0
        n1, n2 = len(nums1), len(nums2)

        while i < n1 and j < n2:
            if nums1[i] < nums2[j]:
                s1 += nums1[i]
                i += 1
            elif nums1[i] > nums2[j]:
                s2 += nums2[j]
                j += 1
            else:
                # 公共元素，取两段的较大值
                ans += max(s1, s2) + nums1[i]
                s1 = s2 = 0
                i += 1
                j += 1

        # 处理剩余部分
        while i < n1:
            s1 += nums1[i]
            i += 1
        while j < n2:
            s2 += nums2[j]
            j += 1

        ans += max(s1, s2)
        return ans % MOD
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def maxSum(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10**9 + 7
        # 合并两数组，记录公共元素位置
        common = set(nums1) & set(nums2)

        # 在每段公共元素之间，累加各自的段和，取最大
        i, j = 0, 0
        n1, n2 = len(nums1), len(nums2)
        s1, s2 = 0, 0
        ans = 0

        while i < n1 or j < n2:
            v1 = nums1[i] if i < n1 else float('inf')
            v2 = nums2[j] if j < n2 else float('inf')

            if v1 < v2:
                s1 += v1; i += 1
            elif v1 > v2:
                s2 += v2; j += 1
            else:
                # 公共节点
                ans = (ans + max(s1, s2) + v1) % MOD
                s1 = s2 = 0
                i += 1; j += 1

        ans = (ans + max(s1, s2)) % MOD
        return ans
```

## 复杂度分析

- **时间复杂度**：O(M + N)，M 和 N 分别为两数组长度
- **空间复杂度**：O(1)

## 关键点总结

1. 两数组有序，用双指针找公共元素
2. 在两个公共元素之间，选择段和更大的那条路径
3. 最后不要忘记处理末尾剩余元素

## 易错点

- 最后剩余的 s1、s2 也要取最大值加入答案
- 取模在最后统一处理（或每步都取模，注意不能混用）
