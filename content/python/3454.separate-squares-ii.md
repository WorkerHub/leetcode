## 题目描述

与 3453 相同，但正方形数量更大，且要求精确计算（结果是有理数，精确到小数点后 5 位）。

给你一个二维整数数组 `squares`，找一条水平线使上下面积相等，返回最小高度 h。

**提示：**
- `1 <= squares.length <= 10^5`
- 坐标和边长可达 `10^9`

## 解题思路

与 3453 解法相似，但需要更高精度的计算。

由于 `below_area(h)` 是分段线性函数，转折点在正方形的 y 坐标和 y+l 坐标处。

在每个区间内，`below_area(h)` 是关于 h 的线性函数，可以精确求解。

**算法**：
1. 排序所有 y 坐标关键点
2. 对每段区间 [y1, y2]，计算该区间内面积增量的速率（斜率）
3. 利用累积面积找到恰好达到总面积/2 的 h

线段树用于高效统计每个高度处"穿过"的正方形的宽度之和（即斜率）。

## Python 代码实现

### 方法一：扫描线 + 精确计算

```python
from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        total = sum(l * l for _, _, l in squares)
        half = total / 2  # 目标下方面积

        # 收集所有 y 坐标关键点
        events = []
        for x, y, l in squares:
            events.append((y, l, 1))    # 进入
            events.append((y + l, l, -1))  # 离开
        events.sort()

        # 扫描线从下到上
        # 当前高度处，穿过的正方形边长之和 = 当前面积增速
        current_sum_l = 0  # 当前穿过的正方形宽度之和
        accumulated = 0.0  # 已累积的下方面积
        prev_h = events[0][0]  # 上一个关键高度

        ei = 0
        n_events = len(events)

        while ei < n_events:
            cur_h = events[ei][0]

            # 从 prev_h 到 cur_h，面积增量 = current_sum_l * (cur_h - prev_h)
            delta = current_sum_l * (cur_h - prev_h)

            if accumulated + delta >= half:
                # 目标在 [prev_h, cur_h] 内
                # accumulated + current_sum_l * (h - prev_h) = half
                # h = prev_h + (half - accumulated) / current_sum_l
                if current_sum_l == 0:
                    return float(prev_h)
                return prev_h + (half - accumulated) / current_sum_l

            accumulated += delta
            prev_h = cur_h

            # 处理所有在 cur_h 的事件
            while ei < n_events and events[ei][0] == cur_h:
                _, l, typ = events[ei]
                current_sum_l += l * typ
                ei += 1

        return float(prev_h)
```

### 方法二：二分 + 精确计算（简化版）

```python
from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        total = sum(l * l for _, _, l in squares)
        half = total / 2

        def below(h):
            s = 0.0
            for _, y, l in squares:
                t = y + l
                if t <= h:
                    s += l * l
                elif y < h:
                    s += l * (h - y)
            return s

        lo = float(min(y for _, y, _ in squares))
        hi = float(max(y + l for _, y, l in squares))

        for _ in range(200):
            mid = (lo + hi) / 2.0
            if below(mid) < half:
                lo = mid
            else:
                hi = mid

        return (lo + hi) / 2.0
```

## 复杂度分析

- 方法一（扫描线）：
  - 时间复杂度：O(n log n)，事件排序
  - 空间复杂度：O(n)

- 方法二（二分）：
  - 时间复杂度：O(n * 200)
  - 空间复杂度：O(1)

## 关键点总结

1. `below_area(h)` 是分段线性函数，在关键高度处斜率改变
2. 扫描线算法：维护当前穿过的正方形宽度之和，精确找到目标高度
3. 在目标区间内使用线性插值求精确解

## 易错点

1. 面积可能非常大（l 和坐标都到 10^9），需要使用 float 或高精度计算
2. 同一高度可能有多个事件，要全部处理完再继续
3. 扫描线中，进入事件 (+l) 和离开事件 (-l) 要正确处理
