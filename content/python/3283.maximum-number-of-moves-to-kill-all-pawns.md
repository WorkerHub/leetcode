## 题目描述

在 `50 x 50` 的棋盘上有一个骑士和若干个兵（pawns）。骑士和 Alice 轮流行动（骑士先），Alice 每次移动骑士，Bob 每次移除一个兵。

骑士可以捕获兵（骑士所在位置的兵被消灭），得 1 分。Alice 想最大化捕获的兵数，Bob 想最小化。

**注意：** Alice 移动骑士（骑士走日字），当骑士走到兵的位置时自动捕获。Bob 可以移除任何剩余的兵（不需要骑士走到）。

返回在最优策略下 Alice 能捕获的最多兵数。

**提示：**
- `0 <= kx, ky <= 49`
- `1 <= positions.length <= 15`
- `positions[i].length == 2`

## 解题思路

状态压缩 DP + BFS：

1. 预计算骑士从任意位置到任意兵的最少步数（BFS）
2. `dp[mask][last]` = 骑士已捕获 mask 中的兵，最后捕获的是 `last`，在最优策略下 Alice 能额外捕获的兵数
3. Alice 最大化，Bob 最小化（博弈 DP）

## Python 代码实现

### 方法一：状态压缩 DP + BFS（推荐）

```python
from typing import List
from collections import deque
from functools import lru_cache

class Solution:
    def maxMoves(self, kx: int, ky: int, positions: List[List[int]]) -> int:
        n = len(positions)
        
        # BFS 求骑士从 (x, y) 到每个兵的最少步数
        def bfs(sx, sy):
            dist = {}
            dist[(sx, sy)] = 0
            q = deque([(sx, sy)])
            directions = [(-2,-1),(-2,1),(-1,-2),(-1,2),(1,-2),(1,2),(2,-1),(2,1)]
            while q:
                x, y = q.popleft()
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < 50 and 0 <= ny < 50 and (nx, ny) not in dist:
                        dist[(nx, ny)] = dist[(x, y)] + 1
                        q.append((nx, ny))
            return dist
        
        # 预计算各点到各兵的距离
        # 包括起始位置和所有兵的位置
        all_pos = [(kx, ky)] + [tuple(p) for p in positions]
        dists = [bfs(x, y) for x, y in all_pos]
        
        # positions 中的兵编号 0..n-1，起始位置编号 n
        # dp[mask][i] = 已捕获 mask 中的兵，上一次捕获（或起始）为 i 时，
        #               在最优策略下额外捕获的兵数
        
        @lru_cache(maxsize=None)
        def dp(mask, last):
            # mask: 已捕获的兵集合
            # last: 上次捕获的兵（-1 表示从起始位置出发）
            if mask == (1 << n) - 1:
                return 0
            
            # 确定当前行动者
            # 已捕获的兵数 = popcount(mask)
            captured = bin(mask).count('1')
            is_alice = (captured % 2 == 0)  # Alice 先行（捕获 0 个后 Alice 行动）
            
            # 当前骑士位置：last+1 在 all_pos 中（last=-1 时为 0）
            pos_idx = last + 1  # 0 是起始位置，1..n 是兵
            
            best = 0 if is_alice else float('inf')
            
            for i in range(n):
                if mask & (1 << i):
                    continue  # 已捕获
                
                # 移动到兵 i
                target_pos = tuple(positions[i])
                steps = dists[pos_idx].get(target_pos, float('inf'))
                
                if steps == float('inf'):
                    continue
                
                new_mask = mask | (1 << i)
                result = 1 + dp(new_mask, i)  # 捕获兵 i，得1分
                
                if is_alice:
                    best = max(best, result)
                else:
                    best = min(best, result)
            
            return best
        
        return dp(0, -1)
```

## 复杂度分析

- 时间复杂度：O(n * 2^n * n + n * 50^2)
- 空间复杂度：O(n * 2^n)

## 关键点总结

1. BFS 预计算骑士的移动距离
2. 状态压缩 DP 处理博弈问题
3. Alice 行动时最大化，Bob 行动时最小化

## 易错点

1. 确定谁在行动：已捕获兵数为偶数时 Alice 行动，奇数时 Bob 行动
2. Bob 移除兵不需要骑士走到，只是减少了可捕获目标
