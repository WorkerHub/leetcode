## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`,返回从 `(0, 0)` 开始到 `(m - 1, n - 1)` 的路径的最大得分。

路径的得分是该路径上的最小值。例如,路径 `8 → 4 → 5 → 9` 的得分是 `4`。

你只能向上、下、左、右四个方向移动。

**示例 1:**
```
输入: grid = [[5,4,5],[1,2,6],[7,4,6]]
输出: 4
解释: 得分最大的路径为 5 → 4 → 5 → 6 → 6,最小值为 4
```

**示例 2:**
```
输入: grid = [[2,2,1,2,2,2],[1,2,2,2,1,2]]
输出: 2
```

**示例 3:**
```
输入: grid = [[3,4,6,3,4],[0,2,1,1,7],[8,8,3,2,7],[3,2,4,9,8],[4,1,2,0,0],[4,6,5,4,3]]
输出: 3
```

**提示:**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `0 <= grid[i][j] <= 10^9`

## 解题思路

这道题要找一条从左上角到右下角的路径,使得路径上的最小值尽可能大。

**核心思想:**
1. 这是一个求最优路径的问题,需要在所有可能路径中找到最小值最大的那条
2. 可以使用多种方法:最大堆(优先队列)、二分查找+BFS/DFS、并查集

**方法对比:**
- **最大堆**: 贪心地选择当前能到达的最大值点,时间复杂度 O(mn log(mn))
- **二分查找**: 二分答案,然后验证是否存在满足条件的路径,O(mn log(max_val))
- **并查集**: 从大到小处理所有格子,直到起点和终点连通,O(mn log(mn))

## Python 代码实现

### 方法一: 最大堆 + Dijkstra(推荐) ⭐

```python
from typing import List
import heapq

class Solution:
    def maximumMinimumPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 使用最大堆,存储 (-当前路径最小值, 行, 列)
        # Python heapq 是最小堆,所以用负数模拟最大堆
        max_heap = [(-grid[0][0], 0, 0)]
        visited = [[False] * n for _ in range(m)]
        visited[0][0] = True
        
        # 四个方向: 上下左右
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while max_heap:
            # 取出当前路径最小值最大的点
            curr_min, x, y = heapq.heappop(max_heap)
            curr_min = -curr_min  # 转回正数
            
            # 到达终点
            if x == m - 1 and y == n - 1:
                return curr_min
            
            # 探索四个方向
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                # 检查边界和是否访问过
                if 0 <= nx < m and 0 <= ny < n and not visited[nx][ny]:
                    visited[nx][ny] = True
                    # 新路径的最小值是当前最小值和下一个格子值的较小者
                    new_min = min(curr_min, grid[nx][ny])
                    heapq.heappush(max_heap, (-new_min, nx, ny))
        
        return -1  # 理论上不会到这里
```

### 方法二: 二分查找 + BFS

```python
from typing import List
from collections import deque

class Solution:
    def maximumMinimumPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        def canReach(min_val: int) -> bool:
            """判断是否存在路径,路径上所有值都 >= min_val"""
            if grid[0][0] < min_val or grid[m-1][n-1] < min_val:
                return False
            
            visited = [[False] * n for _ in range(m)]
            queue = deque([(0, 0)])
            visited[0][0] = True
            
            directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
            
            while queue:
                x, y = queue.popleft()
                
                if x == m - 1 and y == n - 1:
                    return True
                
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    
                    if (0 <= nx < m and 0 <= ny < n and 
                        not visited[nx][ny] and grid[nx][ny] >= min_val):
                        visited[nx][ny] = True
                        queue.append((nx, ny))
            
            return False
        
        # 二分查找最大的最小值
        left, right = 0, min(grid[0][0], grid[m-1][n-1])
        result = 0
        
        while left <= right:
            mid = (left + right) // 2
            if canReach(mid):
                result = mid
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```

### 方法三: 并查集

```python
from typing import List

class UnionFind:
    def __init__(self, size: int):
        self.parent = list(range(size))
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int):
        root_x, root_y = self.find(x), self.find(y)
        if root_x != root_y:
            self.parent[root_x] = root_y
    
    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

class Solution:
    def maximumMinimumPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 将所有格子按值从大到小排序
        cells = []
        for i in range(m):
            for j in range(n):
                cells.append((grid[i][j], i, j))
        cells.sort(reverse=True)
        
        # 并查集
        uf = UnionFind(m * n)
        visited = [[False] * n for _ in range(m)]
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        start, end = 0, m * n - 1
        
        # 从大到小处理每个格子
        for val, x, y in cells:
            visited[x][y] = True
            curr = x * n + y
            
            # 与相邻已访问的格子合并
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and visited[nx][ny]:
                    neighbor = nx * n + ny
                    uf.union(curr, neighbor)
            
            # 如果起点和终点连通,当前值就是答案
            if uf.connected(start, end):
                return val
        
        return grid[0][0]  # 单格情况
```

## 复杂度分析

### 方法一(最大堆):
- **时间复杂度**: O(mn log(mn)),每个格子最多入堆一次
- **空间复杂度**: O(mn),visited 数组和堆的空间

### 方法二(二分查找):
- **时间复杂度**: O(mn log(max_val)),二分查找 O(log(max_val)) 次,每次 BFS O(mn)
- **空间复杂度**: O(mn),visited 数组和队列

### 方法三(并查集):
- **时间复杂度**: O(mn log(mn)),排序 O(mn log(mn)),并查集操作接近 O(1)
- **空间复杂度**: O(mn),并查集和 visited 数组

## 关键点总结

1. **问题转化**: 路径最小值最大化 → 找到从起点到终点的最优路径
2. **贪心策略**: 方法一使用最大堆,总是选择当前能到达的最大值
3. **二分思想**: 方法二二分答案,将优化问题转化为判定问题
4. **逆向思维**: 方法三从大到小处理格子,第一次连通时的值就是答案
5. **Dijkstra变形**: 方法一本质是 Dijkstra 算法的变形(求最大化路径最小值)

## 易错点

1. **堆的使用**: Python heapq 是最小堆,需要用负数模拟最大堆
2. **visited 标记**: 必须标记已访问,否则会重复访问导致超时
3. **边界条件**: 注意起点或终点值为0的情况
4. **路径最小值更新**: `min(当前路径最小值, 下一格值)`,不是加法
