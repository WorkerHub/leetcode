## 题目描述

有一个 `n x n` 的网格，网格 `(i, j)` 有 `fruits[i][j]` 个水果。

三个孩子从不同位置出发，同时到达 `(n-1, n-1)`：
- 孩子 1：从 `(0, 0)` 出发，只能向右或向下移动。
- 孩子 2：从 `(0, n-1)` 出发，只能向下或向左移动。
- 孩子 3：从 `(n-1, 0)` 出发，只能向右或向上移动。

每个格子的水果只能被收集一次（被其中一个孩子收集后，其他孩子路过时该格子为空）。

返回三个孩子能收集的水果总数最大值。

**提示：**
- `1 <= n <= 1000`
- `0 <= fruits[i][j] <= 1000`

## 解题思路

**关键观察：**

三条路径都经过 `(n-1, n-1)`。孩子 2 和孩子 3 的路径可以独立用 DP 计算（各自从起点到终点的最大收益），因为它们的路径互不相交（可以证明）。

孩子 1 的路径从 `(0,0)` 到 `(n-1, n-1)`，沿途收集水果。孩子 2 和 3 的路径不与孩子 1 重叠（路径特性决定）。

**简化：**
- 孩子 2（从 `(0, n-1)` 到 `(n-1, n-1)`）：只能向下或向左，用 DP 计算最大收益。
- 孩子 3（从 `(n-1, 0)` 到 `(n-1, n-1)`）：只能向右或向上，用 DP 计算最大收益。
- 孩子 1（从 `(0, 0)` 到 `(n-1, n-1)`）：收集路径上的所有水果（终点 (n-1,n-1) 处的水果可能已被孩子 2 或 3 收集）。

**注意路径重叠：** 孩子 1 的路径中，格子 `(n-1, n-1)` 会被 2 和 3 也经过，需要处理重叠。

**实际做法：** 孩子 2 的路径在 "右上三角" 区域，孩子 3 的路径在 "左下三角" 区域，孩子 1 的路径是对角线区域，三者可能重叠。

## Python 代码实现

### 方法一：分离 DP（推荐）

```python
from typing import List

class Solution:
    def maxCollectedFruits(self, fruits: List[List[int]]) -> int:
        n = len(fruits)
        
        # 孩子 2：(0, n-1) -> (n-1, n-1)，只能向下或向左
        # dp2[i][j] = 到达 (i, j) 的最大水果数
        INF = float('-inf')
        dp2 = [[INF] * n for _ in range(n)]
        dp2[0][n-1] = fruits[0][n-1]
        for i in range(n):
            for j in range(n-1, -1, -1):
                if i == 0 and j == n-1:
                    continue
                val = INF
                if i > 0 and dp2[i-1][j] != INF:  # 从上方来
                    val = max(val, dp2[i-1][j])
                if j < n-1 and dp2[i][j+1] != INF:  # 从右方来
                    val = max(val, dp2[i][j+1])
                if val != INF:
                    dp2[i][j] = val + fruits[i][j]
        
        # 孩子 3：(n-1, 0) -> (n-1, n-1)，只能向右或向上
        dp3 = [[INF] * n for _ in range(n)]
        dp3[n-1][0] = fruits[n-1][0]
        for i in range(n-1, -1, -1):
            for j in range(n):
                if i == n-1 and j == 0:
                    continue
                val = INF
                if i < n-1 and dp3[i+1][j] != INF:  # 从下方来
                    val = max(val, dp3[i+1][j])
                if j > 0 and dp3[i][j-1] != INF:  # 从左方来
                    val = max(val, dp3[i][j-1])
                if val != INF:
                    dp3[i][j] = val + fruits[i][j]
        
        # 孩子 1：(0, 0) -> (n-1, n-1)，对角线路径 (只能向右或向下)
        # 孩子 1 的路径总和（不考虑重叠）
        dp1 = [[INF] * n for _ in range(n)]
        dp1[0][0] = fruits[0][0]
        for i in range(n):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                val = INF
                if i > 0 and dp1[i-1][j] != INF:
                    val = max(val, dp1[i-1][j])
                if j > 0 and dp1[i][j-1] != INF:
                    val = max(val, dp1[i][j-1])
                if val != INF:
                    dp1[i][j] = val + fruits[i][j]
        
        child1 = dp1[n-1][n-1] if dp1[n-1][n-1] != INF else 0
        child2 = dp2[n-1][n-1] if dp2[n-1][n-1] != INF else 0
        child3 = dp3[n-1][n-1] if dp3[n-1][n-1] != INF else 0
        
        # 减去终点的重复计数（3 个孩子都会经过 (n-1, n-1)）
        return child1 + child2 + child3 - 2 * fruits[n-1][n-1]
```

## 复杂度分析

- 时间复杂度：O(n^2)，三次 DP
- 空间复杂度：O(n^2)

## 关键点总结

1. 三条路径可以独立用 DP 计算（路径特性决定它们主要不重叠）。
2. 终点 `(n-1, n-1)` 被三个孩子都经过，需要减去多余计数。
3. 孩子 1 路径在对角线附近，孩子 2 在右上，孩子 3 在左下，几乎不重叠。

## 易错点

1. 终点 `(n-1, n-1)` 计入了三次，需要减去 2 次。
2. 各孩子的移动方向不同，DP 遍历方向也不同。
3. 初始化为 `-inf` 表示不可达，需要检查是否为 `-inf` 再更新。
