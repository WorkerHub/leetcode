## 题目描述

给你一个字符串 `s` 和一个模式字符串 `p`，其中 `p` 恰好包含两个 `'*'`。

`'*'` 可以匹配任意（包括空）字符序列。

找到 `s` 中能被 `p` 匹配的**最短子串**，并返回其长度。如果不存在，返回 -1。

**示例 1：**

```
输入：s = "abaacbaecebce", p = "ba*c*ce"
输出：8
解释：s[2..9] = "aacbaece" 满足 "ba*c*ce"... 需要重新验证
```

**示例 2：**

```
输入：s = "baccbabc", p = "**"
输出：0
解释：两个 '*' 可以匹配空串，最短子串长度为 0
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= p.length <= 10^4`
- `p` 恰好包含两个 `'*'`

## 解题思路

将 p 按 `'*'` 分为三段：`prefix`, `middle`, `suffix`。

需要在 s 中找一个子串 `s[l..r]`，使得：
1. `s[l..]` 以 `prefix` 开头
2. 在 prefix 之后有 middle 的出现
3. 在 middle 之后的位置，s 以 suffix 结尾（在 r 之前）

使用 KMP 预计算 prefix, middle, suffix 在 s 中的所有出现位置。

然后用双指针（滑动窗口）或二分查找找最短子串。

## Python 代码实现

### 方法一：KMP 预处理 + 双指针

```python
class Solution:
    def shortestMatchingSubstring(self, s: str, p: str) -> int:
        # 分割 p
        parts = p.split('*')
        # 恰好 2 个 '*'，所以 parts 有 3 段
        pre, mid, suf = parts[0], parts[1], parts[2]

        n = len(s)

        def kmp_search(text, pattern):
            """返回 pattern 在 text 中所有出现的起始位置"""
            if not pattern:
                return list(range(len(text) + 1))
            m = len(pattern)
            # 构建失败函数
            fail = [0] * m
            j = 0
            for i in range(1, m):
                while j > 0 and pattern[i] != pattern[j]:
                    j = fail[j - 1]
                if pattern[i] == pattern[j]:
                    j += 1
                fail[i] = j

            positions = []
            j = 0
            for i, c in enumerate(text):
                while j > 0 and c != pattern[j]:
                    j = fail[j - 1]
                if c == pattern[j]:
                    j += 1
                if j == m:
                    positions.append(i - m + 1)
                    j = fail[j - 1]
            return positions

        # 找 pre, mid, suf 在 s 中的出现位置
        pre_pos = kmp_search(s, pre)    # pre 在 s 中的起始位置
        mid_pos = kmp_search(s, mid)    # mid 在 s 中的起始位置
        suf_pos = kmp_search(s, suf)    # suf 在 s 中的起始位置

        if not pre_pos or not suf_pos:
            if not pre and not suf:
                pass  # 两者都空
            elif not pre_pos and pre:
                return -1
            elif not suf_pos and suf:
                return -1

        lp, lm, ls = len(pre), len(mid), len(suf)

        # 对每个 pre 的起始位置 pi，找最近的 mid 和 suf
        # 要求：pi + lp <= mid_start, mid_start + lm <= suf_start, suf_start + ls <= r+1
        # 最短子串长度 = r - pi = suf_start + ls - pi

        import bisect

        ans = -1
        mi = 0  # mid_pos 的指针
        si = 0  # suf_pos 的指针

        for pi in pre_pos:
            # mid 必须在 pi + lp 之后开始
            min_mid_start = pi + lp
            mi = bisect.bisect_left(mid_pos, min_mid_start)
            if mi >= len(mid_pos) and mid:
                continue
            if not mid:
                # 中间段为空，直接找 suf
                min_suf_start = min_mid_start
            else:
                mid_start = mid_pos[mi]
                min_suf_start = mid_start + lm

            # suf 必须在 min_suf_start 之后开始
            si = bisect.bisect_left(suf_pos, min_suf_start)
            if si >= len(suf_pos) and suf:
                continue
            if not suf:
                suf_start = min_suf_start
            else:
                suf_start = suf_pos[si]

            length = suf_start + ls - pi
            if ans == -1 or length < ans:
                ans = length

        return ans
```

### 方法二：暴力枚举（适合小规模）

```python
class Solution:
    def shortestMatchingSubstring(self, s: str, p: str) -> int:
        import re
        # 将 p 中的 * 替换为正则的 .*
        pattern = re.escape(p).replace(r'\*', '.*?')

        n = len(s)
        ans = -1
        for l in range(n):
            for r in range(l, n + 1):
                sub = s[l:r]
                if re.fullmatch(pattern, sub):
                    if ans == -1 or r - l < ans:
                        ans = r - l

        return ans
```

## 复杂度分析

- 方法一：O((n + m) * log n)，KMP + 二分
- 方法二：O(n^2 * m)，暴力

## 关键点总结

1. 将 p 分为三段（两个 * 分割的前中后）
2. KMP 找三段各自在 s 中的所有出现位置
3. 双指针或二分找满足顺序约束的最短组合

## 易错点

1. 某段可能为空（p 以 * 开头或结尾）
2. 三段的位置必须满足顺序且不重叠
3. 子串长度 = suf_start + len(suf) - pre_start
