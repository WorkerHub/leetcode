## 题目描述

给你一个下标从 0 开始的 `m x n` 整数矩阵 `grid`。矩阵中某一列的宽度等于该列中最长字符串的长度（字符串由整数的绝对值表示，负号也计入长度）。

返回一个整数数组 `ans`，其中 `ans[i]` 是第 `i` 列的宽度。

**示例 1：**
```
输入：grid = [[1],[22],[333]]
输出：[3]
解释：第 0 列最长字符串为 "333"，长度 3
```

**示例 2：**
```
输入：grid = [[-15,1,3],[15,7,12],[5,6,-2]]
输出：[3,1,2]
解释：
- 第0列："-15","15","5" 最长为 "-15" 长度 3
- 第1列："1","7","6" 最长为 1
- 第2列："3","12","-2" 最长为 "12"/"-2" 长度 2
```

**数据范围：**
- m == grid.length
- n == grid[0].length
- 1 <= m, n <= 100
- -10^9 <= grid[i][j] <= 10^9

## 解题思路

对每一列，找出所有元素转为字符串后的最大长度。负数要包含负号（即直接用 `str()` 转换）。

## Python 代码实现

### 方法一：列遍历（推荐）

```python
from typing import List

class Solution:
    def findColumnWidth(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        ans = []
        for j in range(n):
            # 对第 j 列，找最长字符串长度
            max_len = max(len(str(grid[i][j])) for i in range(m))
            ans.append(max_len)
        return ans
```

### 方法二：zip 转置

```python
from typing import List

class Solution:
    def findColumnWidth(self, grid: List[List[int]]) -> List[int]:
        # 用 zip(*grid) 转置矩阵，对每列操作
        return [max(len(str(x)) for x in col) for col in zip(*grid)]
```

## 复杂度分析

- 时间复杂度：O(m * n * log M)，M 为最大绝对值（字符串转换）
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 负数的字符串长度包括负号
2. `str(x)` 自动处理负号
3. `zip(*grid)` 可以优雅地按列遍历

## 易错点

1. 负号计入宽度，不能只看绝对值
2. 宽度是字符串长度而非数值大小
