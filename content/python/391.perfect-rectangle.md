## 题目描述

给你一个数组 `rectangles`，其中 `rectangles[i] = [xi, yi, ai, bi]` 表示一个坐标轴平行的矩形。这个矩形的左下顶点是 `(xi, yi)`，右上顶点是 `(ai, bi)`。

如果所有矩形一起精确覆盖了某个矩形区域，则返回 `true`；否则，返回 `false`。

**示例 1:**

![](https://assets.leetcode.com/uploads/2021/03/27/perectrec1-plane.jpg)

```
输入：rectangles = [[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]
输出：true
解释：5 个矩形一起可以精确地覆盖一个矩形区域。
```

**示例 2:**

![](https://assets.leetcode.com/uploads/2021/03/27/perfectrec2-plane.jpg)

```
输入：rectangles = [[1,1,2,3],[1,3,2,4],[3,1,4,2],[3,2,4,4]]
输出：false
解释：两个矩形之间有间隔，无法覆盖成一个大的矩形。
```

**示例 3:**

![](https://assets.leetcode.com/uploads/2021/03/27/perfecrrec4-plane.jpg)

```
输入：rectangles = [[1,1,3,3],[3,1,4,2],[1,3,2,4],[2,2,4,4]]
输出：false
解释：因为中间有相交区域，虽然形成了矩形，但不是精确覆盖。
```

**提示:**

- `1 <= rectangles.length <= 2 * 10^4`
- `rectangles[i].length == 4`
- `-10^5 <= xi < ai <= 10^5`
- `-10^5 <= yi < bi <= 10^5`

## 解题思路

这是一道经典的**几何问题**，需要判断多个矩形是否恰好组成一个大矩形（无重叠、无间隙）。

### 核心思想

**判断条件：**

1. **面积相等**：所有小矩形面积之和 = 大矩形面积
2. **顶点唯一性**：
   - 大矩形的 4 个顶点各出现 1 次
   - 内部顶点（公共点）必须出现偶数次（2 次或 4 次）

**为什么检查顶点？**

- 如果矩形完美拼接，内部的点会被多个矩形共享
- 每个内部点被偶数个矩形的角覆盖（2 次或 4 次）
- 只有大矩形的 4 个角点出现奇数次（1 次）

**算法流程：**

1. 计算大矩形的边界和面积
2. 计算所有小矩形面积之和
3. 使用集合记录每个顶点的出现次数
4. 检查：
   - 面积是否相等
   - 是否恰好有 4 个出现奇数次的点
   - 这 4 个点是否是大矩形的 4 个角

## Python 代码实现

### 方法一：顶点计数 + 面积检查（推荐）⭐

```python
from typing import List

class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        """
        检查顶点出现次数和面积
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        # 计算大矩形的边界
        x1 = min(rect[0] for rect in rectangles)
        y1 = min(rect[1] for rect in rectangles)
        x2 = max(rect[2] for rect in rectangles)
        y2 = max(rect[3] for rect in rectangles)
        
        # 大矩形的面积
        expected_area = (x2 - x1) * (y2 - y1)
        
        # 所有小矩形的面积之和
        actual_area = 0
        
        # 记录每个顶点出现的次数
        points = set()
        
        for x_left, y_bottom, x_right, y_top in rectangles:
            # 累加面积
            actual_area += (x_right - x_left) * (y_top - y_bottom)
            
            # 记录 4 个顶点
            corners = [
                (x_left, y_bottom),
                (x_left, y_top),
                (x_right, y_bottom),
                (x_right, y_top)
            ]
            
            for corner in corners:
                if corner in points:
                    points.remove(corner)  # 出现偶数次，删除
                else:
                    points.add(corner)  # 出现奇数次，添加
        
        # 检查条件：
        # 1. 面积相等
        # 2. 只有 4 个点出现奇数次
        # 3. 这 4 个点恰好是大矩形的 4 个角
        if actual_area != expected_area:
            return False
        
        if len(points) != 4:
            return False
        
        expected_corners = {(x1, y1), (x1, y2), (x2, y1), (x2, y2)}
        return points == expected_corners
```

### 方法二：使用字典计数

```python
from typing import List
from collections import defaultdict

class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        """
        使用字典记录顶点出现次数
        """
        # 计算边界
        x1 = min(r[0] for r in rectangles)
        y1 = min(r[1] for r in rectangles)
        x2 = max(r[2] for r in rectangles)
        y2 = max(r[3] for r in rectangles)
        
        expected_area = (x2 - x1) * (y2 - y1)
        actual_area = 0
        
        point_count = defaultdict(int)
        
        for x_left, y_bottom, x_right, y_top in rectangles:
            actual_area += (x_right - x_left) * (y_top - y_bottom)
            
            # 记录 4 个顶点
            point_count[(x_left, y_bottom)] += 1
            point_count[(x_left, y_top)] += 1
            point_count[(x_right, y_bottom)] += 1
            point_count[(x_right, y_top)] += 1
        
        # 面积检查
        if actual_area != expected_area:
            return False
        
        # 找出出现奇数次的点
        odd_points = set()
        for point, count in point_count.items():
            if count % 2 == 1:
                odd_points.add(point)
            elif count not in [2, 4]:
                # 内部点必须出现 2 次或 4 次
                return False
        
        # 检查奇数点是否是 4 个角
        expected_corners = {(x1, y1), (x1, y2), (x2, y1), (x2, y2)}
        return odd_points == expected_corners
```

### 方法三：优化的集合操作

```python
from typing import List

class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        """
        简化版本
        """
        area = 0
        points = set()
        
        x_min = float('inf')
        y_min = float('inf')
        x_max = float('-inf')
        y_max = float('-inf')
        
        for x1, y1, x2, y2 in rectangles:
            # 更新边界
            x_min = min(x_min, x1)
            y_min = min(y_min, y1)
            x_max = max(x_max, x2)
            y_max = max(y_max, y2)
            
            # 累加面积
            area += (x2 - x1) * (y2 - y1)
            
            # 切换顶点状态
            for point in [(x1, y1), (x1, y2), (x2, y1), (x2, y2)]:
                if point in points:
                    points.remove(point)
                else:
                    points.add(point)
        
        # 检查
        expected_area = (x_max - x_min) * (y_max - y_min)
        expected_corners = {(x_min, y_min), (x_min, y_max), (x_max, y_min), (x_max, y_max)}
        
        return area == expected_area and points == expected_corners
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历所有矩形一次
- 每个矩形处理 4 个顶点，集合操作 O(1)

**空间复杂度：** O(n)
- 最坏情况下，集合需要存储所有顶点
- 实际上内部顶点会抵消，空间较小

## 关键点总结

1. **面积检查**：必要但不充分条件，还需要检查顶点
2. **顶点奇偶性**：内部点出现偶数次，角点出现奇数次
3. **集合的妙用**：通过添加/删除实现计数的奇偶性检查
4. **边界计算**：找到所有矩形的最小/最大坐标
5. **完整性检查**：面积 + 顶点两个条件缺一不可

## 易错点

1. **只检查面积**：面积相等不代表无重叠
2. **顶点计数错误**：内部点可能出现 2 次或 4 次
3. **浮点数精度**：本题是整数坐标，不用担心精度问题
4. **边界情况**：单个矩形、矩形退化为线等
5. **忘记检查角点**：必须验证 4 个奇数点是否是预期的角
