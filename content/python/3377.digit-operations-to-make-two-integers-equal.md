## 题目描述

给你两个整数 `n` 和 `m`（均为 4 位数，`1000 <= n, m <= 9999`）。

每次操作可以将 `n` 的某一位数字加 1 或减 1（不能使数字变为 0 如果该位是最高位，不能让最高位变为 0；也不能将某位从 9 加到 10 或从 0 减到 -1）。

每次操作的代价等于操作后的 `n` 本身（如果 n 是质数，则不能操作）。

返回将 `n` 变成 `m` 的最小总代价，若不可能则返回 -1。

**提示：**
- `1000 <= n, m <= 9999`

## 解题思路

**Dijkstra 最短路：**

将每个 4 位整数看作图中的节点，相邻节点是通过一次合法操作可以到达的整数。

- 边权：到达某个整数的代价 = 该整数本身的值（前提：该整数不是质数）。
- 若一个整数是质数，则无法从它出发进行操作（陷入死锁）。

实际上：**代价是操作后的值（目标值）**，还是当前值？

重新理解：每次操作的代价 = 操作后的数的值。若操作后的数是质数，则不允许该操作（不能停在质数上...除非是目标 m）。

用 Dijkstra 从 `n` 出发，找到 `m` 的最短路。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
import heapq
from sympy import isprime

class Solution:
    def minOperations(self, n: int, m: int) -> int:
        if n == m:
            return 0
        
        # 预处理质数（4位数范围）
        def sieve(max_n):
            is_prime = [True] * (max_n + 1)
            is_prime[0] = is_prime[1] = False
            for i in range(2, int(max_n**0.5) + 1):
                if is_prime[i]:
                    for j in range(i*i, max_n + 1, i):
                        is_prime[j] = False
            return is_prime
        
        is_prime = sieve(9999)
        
        if is_prime[n]:
            return -1  # n 是质数，无法操作
        
        INF = float('inf')
        dist = {n: 0}
        heap = [(0, n)]
        
        while heap:
            cost, curr = heapq.heappop(heap)
            
            if curr == m:
                return cost
            
            if cost > dist.get(curr, INF):
                continue
            
            # 枚举每一位的 +1 和 -1
            digits = list(str(curr))
            for i in range(4):
                d = int(digits[i])
                for delta in [-1, 1]:
                    nd = d + delta
                    if nd < 0 or nd > 9:
                        continue
                    if i == 0 and nd == 0:
                        continue  # 最高位不能为 0
                    
                    new_digits = digits[:]
                    new_digits[i] = str(nd)
                    new_val = int(''.join(new_digits))
                    
                    # 若 new_val 是质数且 new_val != m，则不合法
                    if is_prime[new_val] and new_val != m:
                        continue
                    
                    new_cost = cost + new_val
                    if new_cost < dist.get(new_val, INF):
                        dist[new_val] = new_cost
                        heapq.heappush(heap, (new_cost, new_val))
        
        return -1
```

## 复杂度分析

- 时间复杂度：O(V * log V)，V = 9000（4位数数量）
- 空间复杂度：O(V)

## 关键点总结

1. 将整数变换问题建模为最短路问题。
2. 边权 = 到达的整数的值，质数（除目标 m）不能作为中间节点。
3. Dijkstra 找从 n 到 m 的最小代价路径。

## 易错点

1. n 本身是质数时直接返回 -1（无法从 n 出发操作）。
2. m 如果是质数，可以到达（作为终点不受限制）。
3. 最高位不能变为 0（避免变成 3 位数）。
