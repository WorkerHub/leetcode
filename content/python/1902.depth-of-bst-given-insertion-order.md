## 题目描述

给你一个下标从 **0** 开始的整数数组 `order`，其中 `order` 是 `1` 到 `n` 的一个排列，`order[i]` 表示 BST 中第 `i` 次插入的节点值。

返回插入所有节点后 BST 的**深度**（根节点深度为 1）。

**示例 1：**
```
输入：order = [2, 1, 4, 3]
输出：3
解释：
插入 2 → 根节点，深度 1
插入 1 → 2 的左子节点，深度 2
插入 4 → 2 的右子节点，深度 2
插入 3 → 4 的左子节点，深度 3
```

**示例 2：**
```
输入：order = [2, 1, 3, 4]
输出：3
```

**提示：**
- `n == order.length`
- `1 <= n <= 10^5`
- `order` 是 `1` 到 `n` 的排列

---

## 解题思路

### 核心思想：有序集合 + 找前驱后继

在 BST 中，一个新节点的父节点，必定是已插入节点中与其值**最接近的前驱或后继**。

具体来说：
- 设新插入值为 `x`
- 在已有节点中，找到最大的小于 `x` 的值 `pred`（前驱）
- 在已有节点中，找到最小的大于 `x` 的值 `succ`（后继）
- `x` 的深度 = `max(depth[pred], depth[succ]) + 1`

为什么？因为 `x` 插入时会沿着 BST 往下走，其父节点就是前驱或后继中深度更大的那个。

使用 `SortedList` 维护已插入节点，可以高效查找前驱后继。使用哨兵值 `0` 和 `n+1` 避免边界判断。

## 代码实现

### 方法一：有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def maxDepthBST(self, order: List[int]) -> int:
        n = len(order)
        # 使用哨兵 0 和 n+1，深度均为 0
        depth = {0: 0, n + 1: 0}
        sl = SortedList([0, n + 1])
        max_depth = 0

        for num in order:
            # 找到有序集合中 num 的插入位置
            idx = sl.bisect_left(num)
            # 前驱（左邻居）和后继（右邻居）
            pred = sl[idx - 1]
            succ = sl[idx]
            # 当前节点深度 = 较深的父节点深度 + 1
            d = max(depth[pred], depth[succ]) + 1
            depth[num] = d
            max_depth = max(max_depth, d)
            sl.add(num)

        return max_depth
```

### 方法二：模拟建树（直观但较慢）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
        self.depth = 1  # 根节点深度为 1

class Solution:
    def maxDepthBST(self, order: List[int]) -> int:
        root = None
        max_depth = 0

        def insert(node, val, d):
            nonlocal max_depth
            if node is None:
                # 创建新节点
                new_node = TreeNode(val)
                new_node.depth = d
                max_depth = max(max_depth, d)
                return new_node
            if val < node.val:
                node.left = insert(node.left, val, d + 1)
            else:
                node.right = insert(node.right, val, d + 1)
            return node

        for num in order:
            root = insert(root, num, 1)

        return max_depth
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（有序集合） | O(n log n) | O(n) |
| 方法二（模拟建树） | O(n²) 最坏 | O(n) |

---

## 关键点总结

1. 新节点的父节点一定是已插入节点中的前驱或后继
2. 使用有序集合（SortedList）可在 O(log n) 时间内查找前驱后继
3. 哨兵值 `0` 和 `n+1` 避免边界特判
4. 深度取前驱和后继中的较大值加一

---

## 易错点

- 必须用 `max(depth[pred], depth[succ])` 而不是任意一个
- 模拟建树在最坏情况（有序插入）会退化为链表，导致 O(n²) 超时
- 注意哨兵值的深度初始化为 0（不是 1）
