## 题目描述

给你一个 **二进制** 字符串 `s` 和一个正整数 `k`。

你可以对字符串 `s` 执行以下操作 **任意次**：

- 选择 `s` 中长度为 `k` 的任意子字符串，将子字符串中的 **每一个** 字符翻转（即 `0` 变成 `1`，`1` 变成 `0`）。

返回执行上述操作后，`s` 可以变成的 **不同字符串** 的数目。由于答案可能很大，返回对 `10^9 + 7` **取余** 的结果。

**示例 1：**
```
输入：s = "0001", k = 2
输出：4
解释：可以翻转位置 [0,1]、[1,2]、[2,3] 的子字符串，共有 4 种不同结果。
```

**示例 2：**
```
输入：s = "10110", k = 5
输出：2
```

**提示：**
- `1 <= k <= s.length <= 10^5`

## 解题思路

**关键数学结论：**

通过对 k 长度子字符串进行翻转，操作之间相互影响。

**结论：** 答案是 `2^(n - k + 1)`，其中 `n = len(s)`。

**推导：**
- 有 `n - k + 1` 个可以操作的位置（长度为 k 的子字符串起点）
- 每个操作位置可以独立地「选择翻转或不翻转」
- 不同的操作序列（每个位置选择/不选择）会产生不同的结果字符串
- 可以证明这 `2^(n-k+1)` 种结果互不相同

**证明简述：** 第 `i` 个位置（0-indexed）的字符，只能被起点 <= i 且 i < 起点+k 的操作影响。通过构造逆变换可知不同操作序列产生不同字符串。

## 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def countDistinctStrings(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        # 答案 = 2^(n - k + 1)
        return pow(2, n - k + 1, MOD)
```

### 方法二：理解验证（小规模枚举）

```python
class Solution:
    def countDistinctStrings(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        # 共有 n - k + 1 个可操作位置，每个位置 2 种选择
        ops = n - k + 1
        return pow(2, ops, MOD)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学公式 | O(log n)（快速幂） | O(1) |

## 关键点总结

1. 可操作的位置数为 `n - k + 1`（所有长度为 k 的子字符串的起点）
2. 每个操作独立，结果数为 `2^(n-k+1)`
3. Python 的 `pow(a, b, mod)` 内置快速幂

## 易错点

- 答案与字符串 `s` 的具体内容无关，只与长度和 k 有关
- 注意取模：`10^9 + 7`
