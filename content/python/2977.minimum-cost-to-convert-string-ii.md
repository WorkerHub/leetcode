## 题目描述

给你两个长度为 `n` 的字符串 `source` 和 `target`，以及字符串数组 `original` 和 `changed`，整数数组 `cost`，其中每次操作可以将**子字符串** `original[i]` 转换为 `changed[i]`，代价为 `cost[i]`。

每次操作针对 `source` 中的某个子字符串进行。

返回将 `source` 转换为 `target` 的最少总代价，若不可能则返回 -1。

**提示：**
- `1 <= source.length == target.length <= 1000`
- `1 <= original.length == changed.length == cost.length <= 100`
- `original[i].length, changed[i].length >= 1`

## 解题思路

将每个唯一的字符串映射到整数 ID，构建图，每条边 (original[i], changed[i]) 代价为 cost[i]。

用 Floyd-Warshall 预计算所有字符串对之间的最短路。

然后在 source/target 上做 DP：
- `dp[i]`：将 source[0..i-1] 转换为 target[0..i-1] 的最少代价
- 枚举以 i 为右端的所有子串：若 source[j..i-1] 可以转换为 target[j..i-1]，则 dp[i] = min(dp[i], dp[j] + dist[source[j..i-1]][target[j..i-1]])

## Python 代码实现

### 方法一：字典树 + 最短路 + 动态规划（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, source: str, target: str, original: List[str], changed: List[str], cost: List[int]) -> int:
        INF = float('inf')
        n = len(source)

        # 将所有字符串映射到整数 ID
        string_id = {}
        def get_id(s: str) -> int:
            if s not in string_id:
                string_id[s] = len(string_id)
            return string_id[s]

        for s in original + changed:
            get_id(s)

        m = len(string_id)
        dist = [[INF] * m for _ in range(m)]
        for i in range(m):
            dist[i][i] = 0

        for o, c, w in zip(original, changed, cost):
            u, v = get_id(o), get_id(c)
            dist[u][v] = min(dist[u][v], w)

        # Floyd-Warshall
        for k in range(m):
            for i in range(m):
                for j in range(m):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        # 构建从位置 j 到 i 的转换代价缓存
        # conv[j][i] = 将 source[j..i-1] 转换为 target[j..i-1] 的最小代价
        # 对于所有 j <= i，预计算

        # DP
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            # 情况 1：source[i-1] == target[i-1]，不转换
            if source[i - 1] == target[i - 1]:
                if dp[i - 1] != INF:
                    dp[i] = min(dp[i], dp[i - 1])

            # 情况 2：枚举子串 source[j..i-1] -> target[j..i-1]
            for j in range(i):
                if dp[j] == INF:
                    continue
                s_sub = source[j:i]
                t_sub = target[j:i]
                sid = string_id.get(s_sub)
                tid = string_id.get(t_sub)
                if sid is not None and tid is not None and dist[sid][tid] != INF:
                    dp[i] = min(dp[i], dp[j] + dist[sid][tid])

        return dp[n] if dp[n] != INF else -1
```

### 方法二：暴力枚举子串

```python
from typing import List

class Solution:
    def minimumCost(self, source: str, target: str, original: List[str], changed: List[str], cost: List[int]) -> int:
        INF = float('inf')
        n = len(source)

        # 构建转换图（字符串到字符串，带权）
        from collections import defaultdict
        import heapq

        string_set = set(original + changed)
        string_id = {s: i for i, s in enumerate(string_set)}
        m = len(string_id)
        graph = [[] for _ in range(m)]

        for o, c, w in zip(original, changed, cost):
            u, v = string_id[o], string_id[c]
            graph[u].append((v, w))

        # Dijkstra 从每个源字符串
        def dijkstra(src_id):
            dist = [INF] * m
            dist[src_id] = 0
            heap = [(0, src_id)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in graph[u]:
                    if dist[u] + w < dist[v]:
                        dist[v] = dist[u] + w
                        heapq.heappush(heap, (dist[v], v))
            return dist

        # 预计算所有需要的字符串的最短路
        all_dists = {}
        for s in string_set:
            sid = string_id[s]
            all_dists[sid] = dijkstra(sid)

        # DP
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            if source[i - 1] == target[i - 1] and dp[i - 1] != INF:
                dp[i] = min(dp[i], dp[i - 1])
            for j in range(i):
                if dp[j] == INF:
                    continue
                s_sub = source[j:i]
                t_sub = target[j:i]
                if s_sub in string_id and t_sub in string_id:
                    sid = string_id[s_sub]
                    tid = string_id[t_sub]
                    d = all_dists.get(sid, [INF] * m)[tid]
                    if d != INF:
                        dp[i] = min(dp[i], dp[j] + d)

        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(K^3 + n^2 * K)，K 为不同字符串数，n 为字符串长度
- 空间复杂度：O(K^2 + n)

## 关键点总结

1. 每次转换的是子字符串，而非单字符，需要将字符串映射为节点
2. Floyd-Warshall 计算所有字符串对之间的最短转换代价
3. DP 枚举所有可能的子串分割

## 易错点

1. source[i-1] == target[i-1] 时可以不做任何操作，代价为 0
2. 转换代价包含中间路径（一个字符串经多次转换到达目标）
3. 字符串可能不在转换列表中，需要检查 None
