## 题目描述

给定一个非负整数 `c`，你要判断是否存在两个整数 `a` 和 `b`，使得 `a^2 + b^2 = c`。

**示例 1：**

```
输入：c = 5
输出：true
解释：1 * 1 + 2 * 2 = 5
```

**示例 2：**

```
输入：c = 3
输出：false
```

**提示：**

- `0 <= c <= 2^31 - 1`

## 解题思路

**方法：双指针**

从两端向中间逼近：
- left = 0, right = sqrt(c)
- 如果 `left^2 + right^2 == c`，返回 true
- 如果小于 c，left++
- 如果大于 c，right--

## Python 代码实现

```python
class Solution:
    def judgeSquareSum(self, c: int) -> bool:
        """
        双指针
        
        时间复杂度：O(√c)
        空间复杂度：O(1)
        """
        import math
        
        left = 0
        right = int(math.sqrt(c))
        
        while left <= right:
            current = left * left + right * right
            if current == c:
                return True
            elif current < c:
                left += 1
            else:
                right -= 1
        
        return False
```
