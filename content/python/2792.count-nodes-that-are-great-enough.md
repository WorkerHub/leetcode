## 题目描述

给你一棵二叉树的根节点 `root` 和一个整数 `k`。

一个节点是 **足够大** 的，如果它的值大于以该节点为根的子树中 **至少 k 个** 其他节点的值。

返回树中足够大的节点数目。

**示例：**
```
输入：root = [7,6,5,4,3,2,1], k = 2
输出：3
解释：节点 7,6,5 都满足（7>6个，6>5个，5>2个都满足）
```

**提示：**
- `1 <= k <= 10^4`
- `1 <= 节点数 <= 10^4`

## 解题思路

**DFS + 小根堆（大小为 k）**：对每个节点，维护其子树中最小的 k 个值的堆。

- 对叶节点：子树只有自身，若 k=0 才算（一般 k>=1，叶不计入）
- 合并左右子树的堆，大小保持 <= k
- 插入当前节点值到堆，若堆顶（最小值）< 当前节点值，说明当前节点 >= 堆中至少一个元素

## Python 代码实现

### 方法一：DFS + 小根堆（推荐）

```python
from typing import Optional, List
import heapq

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def countGreatEnoughNodes(self, root: Optional[TreeNode], k: int) -> int:
        ans = 0

        def dfs(node) -> List[int]:
            nonlocal ans
            if not node:
                return []
            left_heap = dfs(node.left)
            right_heap = dfs(node.right)

            # 合并两个堆（保留较大的堆，逐个加入较小的堆）
            if len(left_heap) < len(right_heap):
                left_heap, right_heap = right_heap, left_heap
            # left_heap 更大，将 right_heap 元素加入 left_heap
            for v in right_heap:
                heapq.heappush(left_heap, v)
                if len(left_heap) > k:
                    heapq.heappop(left_heap)  # 保留最大的 k 个

            # 加入当前节点
            heapq.heappush(left_heap, node.val)
            if len(left_heap) > k:
                heapq.heappop(left_heap)  # 保留最大的 k 个

            # 检查：若堆大小 == k，当前节点值 > 堆中最小值（堆顶）
            if len(left_heap) == k and node.val > left_heap[0]:
                ans += 1

            return left_heap

        dfs(root)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log k)（堆操作）
- 空间复杂度：O(n + k)

## 关键点总结

1. 用最大堆（Python 用负数模拟）保留子树中最大的 k 个值
2. 若子树中有 >= k 个节点且当前节点值 > 堆中第 k 大的值，则当前节点足够大
3. 合并时用启发式（小堆并入大堆）减少操作

## 易错点

1. "子树中其他节点"不包括自身
2. 堆大小严格等于 k 时才能判断
