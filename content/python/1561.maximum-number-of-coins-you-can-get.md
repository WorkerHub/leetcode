## 题目描述

有 3n 堆数量不一的硬币，按规则分成 n 组（每组3堆），游戏规则：
- Alice 拿最多的一堆
- 你拿第二多的一堆
- Bob 拿最少的一堆

你选择如何分组，目的是让自己获得的硬币总数最多。

**示例 1：**
```
输入：piles = [2,4,1,2,7,8]
输出：9
解释：分组为 [2,8,4] 和 [1,7,2]，你分别拿 4 和 7，共 9
```

**提示：**
- `3 <= piles.length <= 3 * 10^4`
- `piles.length % 3 == 0`
- `1 <= piles[i] <= 10^4`

## 解题思路

### 贪心策略

排序后，最优策略：
1. 让 Bob 拿最小的 n 堆（让最小的 n 个元素全给 Bob）
2. 剩余 2n 堆中，每两堆一组（从大到小），你拿次大的

排序后，下标 n, n+2, n+4, ..., 3n-2（0-indexed）就是你能拿的。

即从排序后的第 n 个元素开始，每隔一个取一个。

## 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maxCoins(self, piles: List[int]) -> int:
        piles.sort()
        n = len(piles) // 3
        # 最小的 n 堆给 Bob，剩余从大到小每两堆取第一大
        ans = 0
        for i in range(n, len(piles), 2):
            ans += piles[i]
        return ans
```

### 方法二：切片写法

```python
from typing import List

class Solution:
    def maxCoins(self, piles: List[int]) -> int:
        piles.sort()
        n = len(piles) // 3
        # 从第 n 个元素开始（0-indexed），每隔一个取一个
        return sum(piles[n::2])
```

### 方法三：逆向取

```python
from typing import List

class Solution:
    def maxCoins(self, piles: List[int]) -> int:
        piles.sort(reverse=True)
        # 从最大开始，每组取第2大（下标 1, 3, 5, ...，共 n 个）
        n = len(piles) // 3
        return sum(piles[i] for i in range(1, 2*n, 2))
```

## 复杂度分析

- **时间复杂度**：O(N log N)，排序主导
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后，最优分配：最小 n 堆全给 Bob，大的堆 Alice 和你交替取
2. 你取到的是下标 n, n+2, n+4, ..., 3n-2（0-indexed）
3. 切片 `piles[n::2]` 非常简洁

## 易错点

- 分组大小固定为每组 3 堆，共 n 组
- `piles[n::2]` 步长为 2，从第 n 个取到倒数第 2 个
