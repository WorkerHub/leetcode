## 题目描述

公司有编号为 `1` 到 `n` 的 `n` 名工程师，给你两个数组 `speed` 和 `efficiency`，其中 `speed[i]` 和 `efficiency[i]` 分别代表第 `i` 位工程师的速度和效率。

请你返回由最多 `k` 名工程师组成的**最佳团队**的团队表现值，由于答案可能很大，请返回结果对 `10^9 + 7` 取余后的结果。

**团队表现值**的定义：一个团队中「所有工程师速度的和」乘以他们「效率值中的最小值」。

`performance = sum(speed) * min(efficiency)`

**示例 1：**
```
输入：n = 6, speed = [2,10,3,1,5,8], efficiency = [5,4,3,9,7,2], k = 2
输出：60
解释：
我们选择工程师 2（速度10，效率4）和工程师 5（速度5，效率7）。
团队表现值 = (10+5) * min(4,7) = 15 * 4 = 60
```

**示例 2：**
```
输入：n = 6, speed = [2,10,3,1,5,8], efficiency = [5,4,3,9,7,2], k = 3
输出：68
解释：
工程师 1（2,5），2（10,4），5（5,7）。
(2+10+5) * min(5,4,7) = 17 * 4 = 68
```

**示例 3：**
```
输入：n = 6, speed = [2,10,3,1,5,8], efficiency = [5,4,3,9,7,2], k = 4
输出：72
```

**提示：**
- `1 <= n <= 10^5`
- `speed.length == n`
- `efficiency.length == n`
- `1 <= speed[i] <= 10^5`
- `1 <= efficiency[i] <= 10^8`
- `1 <= k <= n`

## 解题思路

### 核心思想：贪心 + 排序 + 最小堆

**关键观察：**
团队表现 = `sum(speed) * min(efficiency)`，其中 `min(efficiency)` 是团队中效率最低的成员决定的。

**贪心策略：枚举效率最小值**

对每个工程师，假设他是团队中**效率最低**的那个人，则：
1. 团队中其他成员的效率都必须 ≥ 他的效率。
2. 在效率 ≥ 他的成员中，尽量选速度最快的（最多选 k-1 个，加上他自己共 k 个）。

**算法流程：**
1. 将工程师按**效率从大到小**排序。
2. 依次处理每个工程师（效率递减），假设其为当前团队的最低效率：
   - 将该工程师的速度加入最小堆。
   - 若堆大小超过 k，弹出速度最小的（淘汰速度最慢的人）。
   - 计算当前速度之和 × 当前工程师效率，更新最大值。
3. 返回最大值。

**为什么按效率降序枚举？**
- 每次处理效率 e_i 的工程师时，堆中的所有工程师效率都 ≥ e_i（因为之前已处理效率更高的）。
- 所以 min(efficiency) = e_i，满足贪心假设。

## Python 代码实现

### 方法一：贪心 + 最小堆（推荐，O(n log k)）

```python
from typing import List
import heapq

class Solution:
    def maxPerformance(self, n: int, speed: List[int], efficiency: List[int], k: int) -> int:
        MOD = 10**9 + 7

        # 将工程师按效率从大到小排序
        engineers = sorted(zip(efficiency, speed), reverse=True)

        min_heap = []   # 最小堆，维护当前选中工程师的速度
        speed_sum = 0   # 当前选中工程师的速度之和
        ans = 0

        for eff, spd in engineers:
            # 将当前工程师加入堆
            heapq.heappush(min_heap, spd)
            speed_sum += spd

            # 若堆大小超过 k，移除速度最小的工程师
            if len(min_heap) > k:
                speed_sum -= heapq.heappop(min_heap)

            # 计算当前配置的团队表现（当前工程师是效率最低的）
            ans = max(ans, speed_sum * eff)

        return ans % MOD
```

### 方法二：同方法一，添加详细注释版本

```python
from typing import List
import heapq

class Solution:
    def maxPerformance(self, n: int, speed: List[int], efficiency: List[int], k: int) -> int:
        MOD = 10**9 + 7

        # 步骤1：按效率降序排列工程师
        # 这样在枚举到第 i 个工程师时，前 i-1 个效率都更高
        engineers = sorted(zip(efficiency, speed), key=lambda x: -x[0])

        # 最小堆：动态维护选中的 k 名工程师（堆顶是最小速度）
        min_heap = []
        speed_sum = 0  # 当前选中工程师的速度总和
        ans = 0

        for i, (eff, spd) in enumerate(engineers):
            # 将当前工程师纳入候选
            heapq.heappush(min_heap, spd)
            speed_sum += spd

            # 人数超过 k：移除速度最小的人（不影响最大团队表现）
            if len(min_heap) > k:
                removed_speed = heapq.heappop(min_heap)
                speed_sum -= removed_speed

            # 此时 min_heap 中最多 k 人，且所有人效率 >= eff
            # 当前工程师（效率为 eff）是这组人中效率最低的
            # 团队表现 = speed_sum * eff
            current_performance = speed_sum * eff
            if current_performance > ans:
                ans = current_performance

        # 最后对 MOD 取余（中间不取余，避免影响大小比较）
        return ans % MOD
```

### 方法三：暴力枚举（O(n^2 log n)，仅用于理解）

```python
from typing import List
import heapq

class Solution:
    def maxPerformance(self, n: int, speed: List[int], efficiency: List[int], k: int) -> int:
        MOD = 10**9 + 7
        ans = 0

        # 枚举每种可能的 min(efficiency)
        for i in range(n):
            min_eff = efficiency[i]
            # 找出所有 efficiency >= min_eff 的工程师，取速度最大的 k 个
            candidates = [speed[j] for j in range(n) if efficiency[j] >= min_eff]
            top_k_speeds = sorted(candidates, reverse=True)[:k]
            performance = sum(top_k_speeds) * min_eff
            ans = max(ans, performance)

        return ans % MOD
        # 时间复杂度 O(n^2 log n)，会超时
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 + 最小堆 | O(n log n) | O(n) |
| 暴力枚举 | O(n² log n) | O(n) |

- **排序**：O(n log n)。
- **堆操作**：每次 push/pop 是 O(log k)，共 n 次，合计 O(n log k)。
- **总时间**：O(n log n)（排序主导）。
- **空间**：O(k) 堆 + O(n) 排序辅助。

## 关键点总结

1. **枚举最小效率**：将 min(efficiency) 固定后，贪心选速度最大的 k 人。
2. **效率降序处理**：保证在枚举到效率 e_i 时，前面所有人的效率都 ≥ e_i。
3. **最小堆维护速度 top-k**：堆顶是当前选中 k 人中速度最小的，超出 k 时弹出最小速度。
4. **取模在最后**：中间计算时不取模（否则影响 max 比较），只在最终返回时取模。
5. 可以选择 **少于 k 人**的团队（堆中最多 k 人，但可以少于 k 人），这是因为有时候加入效率低的人反而降低团队表现。

## 易错点

1. **取模时机**：`ans % MOD` 只在返回时做，若在循环中取模会导致 max 比较失去意义。
2. **可以少于 k 人**：题目说"最多 k 名"，所以堆大小 ≤ k 即可，不需要恰好 k 人。
3. **效率降序，不是速度降序**：是枚举效率最小值，所以要按效率排序。
4. **堆中超过 k 后才弹出**：先 push 再判断是否超出 k，保证当前枚举的工程师也在考虑范围内。
