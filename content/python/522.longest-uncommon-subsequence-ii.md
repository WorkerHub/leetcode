## 题目描述

给定字符串列表 `strs`，返回其中**最长的特殊序列**的长度。如果最长特殊序列不存在，返回 `-1`。

**特殊序列** 定义如下：该序列为某字符串**独有的子序列**（即不能是其他字符串的子序列）。

`s` 的**子序列**可以通过删去字符串 `s` 中的某些字符实现。

**示例 1：**
```
输入：strs = ["aba","cdc","eae"]
输出：3
```

**示例 2：**
```
输入：strs = ["aaa","aaa","aa"]
输出：-1
```

**提示：**
- `2 <= strs.length <= 50`
- `1 <= strs[i].length <= 10`
- `strs[i]` 只包含小写英文字母

## 解题思路

### 核心思想：
1. 按字符串长度降序排序
2. 检查每个字符串是否是其他字符串的子序列
3. 如果某字符串不是任何其他字符串的子序列，它就是答案

### 关键观察：
- 重复的字符串不可能是特殊序列
- 从最长的开始检查可以尽早找到答案

## Python 代码实现

```python
from typing import List

class Solution:
    def findLUSlength(self, strs: List[str]) -> int:
        """
        排序 + 子序列判断
        时间复杂度：O(n^2 * m)，空间复杂度：O(1)
        """
        def is_subsequence(s, t):
            """判断 s 是否是 t 的子序列"""
            i = 0
            for c in t:
                if i < len(s) and s[i] == c:
                    i += 1
            return i == len(s)
        
        # 按长度降序排序
        strs.sort(key=len, reverse=True)
        
        for i, s in enumerate(strs):
            # 检查 s 是否是特殊序列
            is_special = True
            
            for j, t in enumerate(strs):
                if i != j and is_subsequence(s, t):
                    is_special = False
                    break
            
            if is_special:
                return len(s)
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(n² × m)，n 是字符串数量，m 是平均长度
- **空间复杂度**：O(1)

## 关键点总结

1. 排序优化查找顺序
2. 子序列判断使用双指针
3. 重复字符串不可能是答案
