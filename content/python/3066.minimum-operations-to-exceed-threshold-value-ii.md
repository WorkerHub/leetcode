## 题目描述

给你一个整数数组 `nums` 和整数 `k`。

每次操作：
1. 取出 `nums` 中最小的两个元素 `x` 和 `y`（x <= y）
2. 将它们替换为 `min(x, y) * 2 + max(x, y)`（即 `x*2 + y`）

重复操作直到所有元素 >= k，返回最少操作次数。

**示例 1：**
```
输入：nums = [2,11,10,1,3], k = 10
输出：2
```

**示例 2：**
```
输入：nums = [1,1,2,4,9], k = 1
输出：0
```

**提示：**
- `2 <= nums.length <= 2 * 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 2 * 10^9`

## 解题思路

使用最小堆模拟操作：
1. 将数组构建为最小堆
2. 每次取出最小的两个元素，合并后放回堆
3. 当堆顶元素 >= k 时停止

## Python 代码实现

### 方法一：最小堆模拟（推荐）

```python
from typing import List
import heapq

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        heapq.heapify(nums)
        ops = 0

        while nums[0] < k:
            if len(nums) < 2:
                break  # 理论上题目保证操作终止
            x = heapq.heappop(nums)  # 最小元素
            y = heapq.heappop(nums)  # 次小元素
            new_val = x * 2 + y
            heapq.heappush(nums, new_val)
            ops += 1

        return ops
```

### 方法二：更清晰的版本

```python
from typing import List
import heapq

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        heap = nums[:]
        heapq.heapify(heap)
        count = 0

        while heap[0] < k:
            x = heapq.heappop(heap)
            y = heapq.heappop(heap)
            merged = min(x, y) * 2 + max(x, y)  # x <= y 故 merged = x*2 + y
            heapq.heappush(heap, merged)
            count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次操作 O(log n)，最多 O(n) 次操作
- 空间复杂度：O(n)，堆

## 关键点总结

1. 最小堆高效获取最小两个元素
2. 合并规则：`min*2 + max`（注意乘以 2 的是较小值）
3. 循环直到堆顶元素 >= k

## 易错点

1. 合并公式：`x*2 + y`（x 是较小值），不是 `(x+y)*2`
2. 操作后数组大小减 1（取 2 个，放 1 个）
