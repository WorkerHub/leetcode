## 题目描述

Alice 管理一栋楼，楼层范围是 `bottom` 到 `top`（包含两端）。

另有一个整数数组 `special`，`special[i]` 表示第 `i` 个特殊楼层（都在 `bottom` 和 `top` 之间）。

返回**没有特殊楼层**的最长连续楼层段的长度。

**示例 1：**
```
输入：bottom = 2, top = 9, special = [4,6]
输出：3
解释：区间 [2,3], [5,5], [7,9] 没有特殊层，最长为 [7,9] 共 3 层。
```

**示例 2：**
```
输入：bottom = 6, top = 8, special = [7,6,8]
输出：0
```

## 解题思路

将 `special` 排序，然后计算相邻特殊层之间的空隙长度，以及首尾的空隙。

**间隔计算：**
- `bottom` 到 `special[0]-1` 的空隙。
- `special[i-1]+1` 到 `special[i]-1` 的空隙（相邻特殊层之间）。
- `special[-1]+1` 到 `top` 的空隙。

## 代码实现

### 方法一：排序后计算空隙（推荐）

```python
from typing import List

class Solution:
    def maxConsecutive(self, bottom: int, top: int, special: List[int]) -> int:
        special.sort()
        ans = 0

        # 首段：bottom 到 special[0] - 1
        ans = max(ans, special[0] - bottom)

        # 中间段：special[i-1] + 1 到 special[i] - 1
        for i in range(1, len(special)):
            ans = max(ans, special[i] - special[i - 1] - 1)

        # 尾段：special[-1] + 1 到 top
        ans = max(ans, top - special[-1])

        return ans
```

### 方法二：使用哨兵简化

```python
from typing import List

class Solution:
    def maxConsecutive(self, bottom: int, top: int, special: List[int]) -> int:
        # 在首尾加哨兵，统一处理
        special = sorted([bottom - 1] + special + [top + 1])
        ans = 0
        for i in range(1, len(special)):
            # 区间 (special[i-1], special[i]) 的长度
            ans = max(ans, special[i] - special[i - 1] - 1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(1)（方法一），O(n)（方法二加了哨兵）。

## 关键点总结

1. 排序后，问题转化为找相邻特殊层（以及边界）之间的最大间隔。
2. 哨兵法将边界情况统一处理，代码更简洁。
3. 间隔长度 = `special[i] - special[i-1] - 1`（两端都不包含特殊层）。

## 易错点

- 首段：`special[0] - bottom`（不是 `special[0] - bottom - 1`，因为 `bottom` 到 `special[0]-1` 共 `special[0] - bottom` 层）。
- 尾段：`top - special[-1]`。
