## 题目描述

给你一个 **下标从 0 开始** 的整数数组 `nums`，包含 `0` 到 `n - 1` 的所有整数。

每次操作中，你可以将 **任意** 一个元素移到 **空格**（值为 `0` 的位置）。

进行若干次操作后，你需要将数组变成 **有序** 状态（升序排列），返回最少所需的操作次数。

**示例 1：**
```
输入：nums = [4,2,0,3,1]
输出：3
```

**示例 2：**
```
输入：nums = [1,2,3,4,0]
输出：0
```

**示例 3：**
```
输入：nums = [0,3,1,2]
输出：3
```

**提示：**
- `2 <= n <= 10^5`
- `0 <= nums[i] <= n - 1`
- `nums` 中的所有整数 **不重复**

## 解题思路

**排列环的思想：**

目标数组中，`nums[i]` 应该在位置 `i`（0 在位置 0）。

**情况一：0 在位置 0（目标）** 时，对每个不在正确位置的置换环，操作数 = 环长度。
**情况二：0 不在位置 0（目标为 sorted(nums)）** 时，有两种策略：
1. 先将 0 移到正确位置再处理每个环
2. 不先移 0，处理每个环时把 0 带进去

可以分别计算两种情况（0 参与第一个不在正确位置的环 vs 先移 0），取最小值。

由于最终目标是 `[0, 1, 2, ..., n-1]`，同时也需要考虑把 0 单独移出去的策略。

实际上需要考虑两种目标状态：
- 方案 A：0 在索引 0 位置，其余 1 到 n-1 按升序
- 方案 B：0 在最后，1 到 n-1 按升序放在 0 到 n-2

对每种方案，通过置换环分析计算操作数。

## 代码实现

### 方法一：置换环分析

```python
from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> int:
        n = len(nums)

        def count_ops(target_pos):
            """
            target_pos[i] = 元素 i 的目标位置
            返回最少操作数
            """
            # pos[v] = 当前值 v 的位置
            pos = [0] * n
            for i, v in enumerate(nums):
                pos[v] = i

            visited = [False] * n
            ops = 0

            for start in range(n):
                if visited[start] or pos[start] == target_pos[start]:
                    visited[start] = True
                    continue

                # 追踪这个置换环
                cycle_len = 0
                cur = start
                while not visited[cur]:
                    visited[cur] = True
                    cur = pos[cur]  # 从目标位置找当前谁在那里，不对
                    # 应该跟随排列
                    cycle_len += 1

                # 每个长度为 k 的环需要 k + 1 或 k - 1 次操作，取决于 0 是否在环内
                # 简化：如果 0 在环中，操作数 = k - 1；否则 = k + 1
                ops += cycle_len + (1 if start != 0 else -1)

            return ops

        # 方案 A: 目标 [0,1,2,...,n-1]，target_pos[v] = v
        # 方案 B: 目标 [1,2,...,n-1,0]，target_pos[0] = n-1，target_pos[v] = v-1 for v>0
        # 比较两个方案

        def solve(target):
            """target[i] 表示位置 i 应该放什么值"""
            # want[v] = 值 v 的目标位置
            want = [0] * n
            for i, v in enumerate(target):
                want[v] = i

            # pos[v] = 值 v 当前的位置
            pos = [0] * n
            for i, v in enumerate(nums):
                pos[v] = i

            visited = [False] * n
            ops = 0

            for v in range(n):
                if visited[v] or pos[v] == want[v]:
                    visited[v] = True
                    continue

                # 计算包含 v 的环的长度，以及 0 是否在环中
                cycle = []
                cur = v
                while not visited[cur]:
                    visited[cur] = True
                    cycle.append(cur)
                    cur = target[pos[cur]]  # 当前在 v 目标位置的值的目标值

                k = len(cycle)
                if 0 in cycle:
                    ops += k - 1  # 0 在环中
                else:
                    ops += k + 1  # 0 不在环中（需额外移动 0 入环）

            return ops

        target_a = list(range(n))  # [0,1,...,n-1]
        target_b = list(range(1, n)) + [0]  # [1,2,...,n-1,0]

        return min(solve(target_a), solve(target_b))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 置换环 | O(n) | O(n) |

## 关键点总结

1. 置换环分析：每个长度 k 的环
   - 若 0 在环中：k-1 次操作
   - 若 0 不在环中：k+1 次操作
2. 需要考虑两种目标状态（0 在头部或尾部）

## 易错点

- 两种目标状态都要考虑，取最小值
- 置换环中 0 的角色很重要（0 是空格，操作的媒介）
