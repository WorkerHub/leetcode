## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`，在 `s` 中添加加粗标签 `<b>` 和 `</b>` 来使得 `words` 中的所有字符串在 `s` 中都加粗。

返回添加加粗标签后的字符串。

如果两个加粗的子字符串重叠或相邻，你应该把它们合并成一个加粗的子字符串。

**示例 1:**
```
输入: s = "abcxyz123", words = ["abc","123"]
输出: "<b>abc</b>xyz<b>123</b>"
```

**示例 2:**
```
输入: s = "aaabbcc", words = ["aaa","aab","bc"]
输出: "<b>aaabbc</b>c"
解释:
"aaa" 在位置 0-2
"aab" 在位置 1-3
"bc" 在位置 4-5
合并后是 0-5
```

**提示:**
- `1 <= s.length <= 1000`
- `0 <= words.length <= 100`
- `1 <= words[i].length <= 1000`
- `s` 和 `words[i]` 仅由小写英文字母组成

**注意：** 此题与 [616. Add Bold Tag in String](https://leetcode.com/problems/add-bold-tag-in-string/) 相同

## 解题思路

这道题需要两个步骤：
1. 标记所有需要加粗的位置
2. 合并相邻和重叠的区间，然后添加标签

**算法流程：**
1. 创建一个布尔数组标记每个字符是否需要加粗
2. 遍历所有 words，标记在 s 中出现的位置
3. 根据标记数组构建结果字符串

## Python 代码实现

### 方法一：标记数组（推荐）⭐

```python
from typing import List

class Solution:
    def boldWords(self, words: List[str], s: str) -> str:
        n = len(s)
        bold = [False] * n
        
        # 标记所有需要加粗的位置
        for word in words:
            # 查找 word 在 s 中的所有出现位置
            start = 0
            while True:
                pos = s.find(word, start)
                if pos == -1:
                    break
                # 标记 [pos, pos + len(word)) 范围
                for i in range(pos, pos + len(word)):
                    bold[i] = True
                start = pos + 1
        
        # 根据标记构建结果
        result = []
        i = 0
        while i < n:
            if bold[i]:
                result.append("<b>")
                while i < n and bold[i]:
                    result.append(s[i])
                    i += 1
                result.append("</b>")
            else:
                result.append(s[i])
                i += 1
        
        return "".join(result)
```

### 方法二：区间合并

```python
class Solution:
    def boldWords(self, words: List[str], s: str) -> str:
        # 收集所有需要加粗的区间
        intervals = []
        
        for word in words:
            start = 0
            while True:
                pos = s.find(word, start)
                if pos == -1:
                    break
                intervals.append([pos, pos + len(word)])
                start = pos + 1
        
        if not intervals:
            return s
        
        # 合并重叠和相邻的区间
        intervals.sort()
        merged = [intervals[0]]
        
        for start, end in intervals[1:]:
            if start <= merged[-1][1]:
                # 重叠或相邻，合并
                merged[-1][1] = max(merged[-1][1], end)
            else:
                merged.append([start, end])
        
        # 构建结果
        result = []
        prev = 0
        
        for start, end in merged:
            result.append(s[prev:start])
            result.append("<b>")
            result.append(s[start:end])
            result.append("</b>")
            prev = end
        
        result.append(s[prev:])
        return "".join(result)
```

### 方法三：字典树优化

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_word = True
    
    def search_from(self, s, start):
        """从 s[start] 开始搜索，返回所有匹配的单词长度"""
        node = self.root
        lengths = []
        for i in range(start, len(s)):
            char = s[i]
            if char not in node.children:
                break
            node = node.children[char]
            if node.is_word:
                lengths.append(i - start + 1)
        return lengths

class Solution:
    def boldWords(self, words: List[str], s: str) -> str:
        # 构建字典树
        trie = Trie()
        for word in words:
            trie.insert(word)
        
        n = len(s)
        bold = [False] * n
        
        # 对每个起始位置，查找匹配的单词
        for i in range(n):
            lengths = trie.search_from(s, i)
            for length in lengths:
                for j in range(i, i + length):
                    bold[j] = True
        
        # 构建结果
        result = []
        i = 0
        while i < n:
            if bold[i]:
                result.append("<b>")
                while i < n and bold[i]:
                    result.append(s[i])
                    i += 1
                result.append("</b>")
            else:
                result.append(s[i])
                i += 1
        
        return "".join(result)
```

### 方法四：简洁版本

```python
class Solution:
    def boldWords(self, words: List[str], s: str) -> str:
        bold = [False] * len(s)
        
        # 标记所有匹配位置
        for word in words:
            for i in range(len(s)):
                if s[i:i+len(word)] == word:
                    bold[i:i+len(word)] = [True] * len(word)
        
        # 构建结果
        result = []
        i = 0
        while i < len(s):
            if bold[i]:
                result.append("<b>")
                while i < len(s) and bold[i]:
                    result.append(s[i])
                    i += 1
                result.append("</b>")
            else:
                result.append(s[i])
                i += 1
        
        return "".join(result)
```

## 复杂度分析

**方法一：标记数组**
- **时间复杂度：** O(n * m * k)，其中 n 是 s 的长度，m 是 words 的数量，k 是平均单词长度
- **空间复杂度：** O(n)，标记数组

**方法二：区间合并**
- **时间复杂度：** O(n * m * k + I log I)，其中 I 是区间数量
- **空间复杂度：** O(I)，存储区间

**方法三：字典树**
- **时间复杂度：** O(n^2 + m * k)，构建字典树 O(m * k)，查找 O(n^2)
- **空间复杂度：** O(m * k)，字典树空间

## 关键点总结

1. **标记法：** 使用布尔数组标记需要加粗的位置
2. **字符串查找：** 使用 `str.find()` 查找所有出现位置
3. **区间合并：** 相邻和重叠的区间要合并
4. **构建结果：** 根据标记数组构建最终字符串
5. **优化技巧：** 字典树可以优化多模式匹配

## 易错点

1. **重复出现：** 一个单词可能在 s 中多次出现
2. **重叠处理：** 重叠的区间要合并，不能添加多个标签
3. **相邻合并：** 相邻的加粗区间也要合并
4. **索引边界：** 标记数组时注意不要越界
5. **空字符串：** words 可能为空，s 也可能不包含任何 word
