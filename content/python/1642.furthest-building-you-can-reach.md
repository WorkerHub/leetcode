## 题目描述

给你一个整数数组 `heights`，表示建筑物的高度。另有一些砖块 `bricks` 和梯子 `ladders`。

你从建筑物 `0` 开始旅程，能否移动到下一栋建筑：
- 如果当前建筑**更矮或相同高度**，可以直接移动
- 如果当前建筑**更高**，可以使用一定数量的砖块（差值）或一个梯子

返回你**最远**能到达的建筑下标。

**提示：**
- `1 <= heights.length <= 10^5`
- `0 <= bricks <= 10^9`
- `0 <= ladders <= heights.length`

## 解题思路

**贪心 + 最小堆：**

尽可能将梯子用在**高度差最大**的地方（梯子无视高度差），其余用砖块。

**贪心策略：**
1. 遇到上坡时，先假装用梯子（把高度差存入最小堆）
2. 如果使用的梯子数超过了 `ladders`，把堆中最小的高度差"换回"砖块（因为梯子应用在最大处）
3. 如果砖块不够，停止

## 代码实现

### 方法一：贪心 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def furthestBuilding(self, heights: List[int], bricks: int, ladders: int) -> int:
        # 最小堆，存放已使用梯子的高度差
        heap = []
        
        for i in range(len(heights) - 1):
            diff = heights[i + 1] - heights[i]
            
            if diff <= 0:
                continue  # 下坡或平路，直接走
            
            # 先用梯子（压入堆中）
            heapq.heappush(heap, diff)
            
            # 如果梯子用超了，把最小的高度差换成砖块
            if len(heap) > ladders:
                smallest = heapq.heappop(heap)
                bricks -= smallest  # 用砖块弥补
                
                if bricks < 0:
                    return i  # 砖块不够，停在当前建筑
        
        return len(heights) - 1  # 能到达最后一栋
```

### 方法二：二分查找 + 贪心验证

```python
from typing import List
import heapq

class Solution:
    def furthestBuilding(self, heights: List[int], bricks: int, ladders: int) -> int:
        # 方法一已足够高效，这里提供另一种思路
        # 二分查找能到达的最远位置
        
        def can_reach(idx: int) -> bool:
            """检查是否能到达 idx"""
            diffs = []
            for i in range(idx):
                d = heights[i + 1] - heights[i]
                if d > 0:
                    diffs.append(d)
            
            diffs.sort(reverse=True)
            
            # 梯子用在最大的 k 个高度差上
            brick_usage = sum(diffs[ladders:])
            return brick_usage <= bricks
        
        lo, hi = 0, len(heights) - 1
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_reach(mid):
                lo = mid
            else:
                hi = mid - 1
        
        return lo
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心+堆 | O(n log k) | O(k) |
| 二分+贪心 | O(n log n * log n) | O(n) |

k 为梯子数量。

## 关键点总结

1. 贪心：梯子用在最大的高度差处，小的差值用砖块
2. 最小堆存放已用梯子的高度差，超出 ladders 数量时换出最小值改用砖块
3. 砖块不够时，立即返回当前位置
4. 整个过程维持堆大小 <= ladders

## 易错点

- 只有上坡（diff > 0）才需要资源，下坡/平路直接走
- 用砖块替换最小高度差（贪心：保留大差值给梯子）
- 砖块变负说明此步走不了，返回 i（不是 i+1）
