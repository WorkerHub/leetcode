## 题目描述

给定一个整数数组 `preorder`，如果它是以二叉搜索树的前序遍历排列，返回 `true`；否则，返回 `false`。

**重要提示：** 你能否使用恒定的空间复杂度来做？

**示例 1：**

```
输入：preorder = [5,2,1,3,6]
输出：true
解释：对应的 BST 为：
      5
     / \
    2   6
   / \
  1   3
```

**示例 2：**

```
输入：preorder = [5,2,6,1,3]
输出：false
解释：无法构成有效的 BST 前序遍历
```

**提示：**
- `1 <= preorder.length <= 10^4`
- `1 <= preorder[i] <= 10^4`
- `preorder` 中所有值互不相同

## 解题思路

这道题的关键是理解二叉搜索树（BST）前序遍历的特性：

BST 前序遍历的规律：
1. 遍历顺序：根 → 左子树 → 右子树
2. 左子树的所有节点 < 根节点
3. 右子树的所有节点 > 根节点
4. 在前序遍历中，当遇到第一个比当前节点大的值时，说明进入了右子树

核心思想：
- 使用单调栈维护一个递减序列
- 当遇到比栈顶大的元素时，说明要进入右子树
- 记录右子树的下界（必须大于这个值）
- 如果后续元素违反了这个下界，返回 false

## Python 代码实现

### 方法一：单调栈（推荐）⭐

```python
from typing import List

class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        """
        使用单调栈验证前序遍历
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        stack = []
        lower_bound = float('-inf')  # 右子树的下界
        
        for num in preorder:
            # 如果当前值小于下界，违反了 BST 性质
            if num < lower_bound:
                return False
            
            # 当前值大于栈顶，说明要进入右子树
            # 弹出所有小于当前值的元素
            while stack and num > stack[-1]:
                # 更新下界为弹出的最大值
                lower_bound = stack.pop()
            
            # 将当前值入栈
            stack.append(num)
        
        return True
```

### 方法二：原地修改（O(1) 空间）⭐

```python
from typing import List

class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        """
        使用数组本身作为栈，实现 O(1) 空间复杂度
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        lower_bound = float('-inf')
        i = -1  # 栈顶指针
        
        for num in preorder:
            # 检查是否违反下界
            if num < lower_bound:
                return False
            
            # 模拟出栈操作
            while i >= 0 and num > preorder[i]:
                lower_bound = preorder[i]
                i -= 1
            
            # 模拟入栈操作
            i += 1
            preorder[i] = num
        
        return True
```

### 方法三：递归分治

```python
from typing import List

class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        """
        递归分治验证
        时间复杂度：O(n^2) 最坏情况
        空间复杂度：O(n) 递归栈
        """
        def verify(arr: List[int], min_val: float, max_val: float) -> bool:
            if not arr:
                return True
            
            root = arr[0]
            
            # 根节点必须在范围内
            if root <= min_val or root >= max_val:
                return False
            
            # 找到第一个大于根节点的位置（右子树起点）
            split = 1
            while split < len(arr) and arr[split] < root:
                split += 1
            
            # 递归验证左右子树
            left_valid = verify(arr[1:split], min_val, root)
            right_valid = verify(arr[split:], root, max_val)
            
            return left_valid and right_valid
        
        return verify(preorder, float('-inf'), float('inf'))
```

### 方法四：递归 + 索引优化

```python
from typing import List

class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        """
        递归方法的优化版本，使用索引避免数组切片
        时间复杂度：O(n)
        空间复杂度：O(h)，h 为树高
        """
        self.index = 0
        
        def verify(min_val: float, max_val: float) -> bool:
            if self.index >= len(preorder):
                return True
            
            val = preorder[self.index]
            
            # 当前值不在有效范围内，回溯
            if val <= min_val or val >= max_val:
                return True
            
            # 处理当前节点
            self.index += 1
            
            # 递归左子树（值必须小于当前节点）
            verify(min_val, val)
            
            # 递归右子树（值必须大于当前节点）
            verify(val, max_val)
            
            return True
        
        verify(float('-inf'), float('inf'))
        return self.index == len(preorder)
```

## 复杂度分析

**方法一（单调栈）：**
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈的大小

**方法二（原地修改）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法三（递归分治）：**
- 时间复杂度：O(n^2) 最坏情况（链状树）
- 空间复杂度：O(n) 递归栈

## 图解示例

以 `preorder = [5,2,1,3,6]` 为例：

```
BST 结构：
      5
     / \
    2   6
   / \
  1   3

前序遍历：5 → 2 → 1 → 3 → 6

单调栈模拟过程：
步骤1: num=5, lower=-∞, stack=[] 
       → stack=[5]

步骤2: num=2, lower=-∞, stack=[5]
       2 < 5, 入栈 → stack=[5,2]

步骤3: num=1, lower=-∞, stack=[5,2]
       1 < 2, 入栈 → stack=[5,2,1]

步骤4: num=3, lower=-∞, stack=[5,2,1]
       3 > 1, 弹出1, lower=1
       3 > 2, 弹出2, lower=2
       3 < 5, 停止
       → stack=[5,3], lower=2

步骤5: num=6, lower=2, stack=[5,3]
       6 > 3, 弹出3, lower=3
       6 > 5, 弹出5, lower=5
       → stack=[6], lower=5

结果：所有元素都满足条件，返回 true
```

反例 `preorder = [5,2,6,1,3]`：

```
步骤1-3: 同上，stack=[5,2,6], lower=5

步骤4: num=1, lower=5
       1 < 5，违反下界！
       返回 false
```

## 关键点总结

1. **单调栈的应用**：维护递减栈，检测拐点（进入右子树）
2. **下界的意义**：记录当前元素所在右子树的根节点值
3. **空间优化**：可以原地修改数组作为栈，实现 O(1) 空间
4. **BST 性质**：左子树 < 根 < 右子树
5. **前序遍历特点**：根 → 左 → 右，先遇到的是祖先节点

## 易错点

1. **下界更新时机**
   ```python
   # 错误：只更新一次
   if stack and num > stack[-1]:
       lower_bound = stack.pop()
   
   # 正确：循环弹出，取最大值
   while stack and num > stack[-1]:
       lower_bound = stack.pop()
   ```

2. **下界初始值**
   ```python
   # 错误：初始化为 0
   lower_bound = 0
   
   # 正确：初始化为负无穷
   lower_bound = float('-inf')
   ```

3. **检查顺序**
   ```python
   # 先检查下界，再处理栈
   if num < lower_bound:
       return False
   while stack and num > stack[-1]:
       lower_bound = stack.pop()
   ```

4. **原地修改时的索引**
   ```python
   # 注意 i 从 -1 开始，表示栈为空
   i = -1
   # 入栈时先 i += 1，再赋值
   i += 1
   preorder[i] = num
   ```
