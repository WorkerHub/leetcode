## 题目描述

设计一个日志存储系统来接收日志（包括 id 和时间戳），并根据给定的时间范围和粒度检索日志。

实现 `LogSystem` 类：

- `LogSystem()` 初始化 `LogSystem` 对象
- `void put(int id, string timestamp)` 存储给定的日志 `(id, timestamp)`
- `List<Integer> retrieve(string start, string end, string granularity)` 返回在给定时间范围 `[start, end]`（闭区间）内的所有日志的 id，时间范围由 `granularity` 指定的粒度确定

**时间戳格式：**
- `Year:Month:Day:Hour:Minute:Second`
- 例如：`2017:01:01:23:59:59`

**粒度等级（从粗到细）：**
1. `"Year"`
2. `"Month"`
3. `"Day"`
4. `"Hour"`
5. `"Minute"`
6. `"Second"`

**说明：**
- 当粒度为 `"Day"` 时，比较时只考虑年月日，忽略时分秒
- 例如：`start = "2017:01:01:23:59:59"`, `end = "2017:01:02:23:59:59"`, `granularity = "Day"`
  - 范围是 2017 年 1 月 1 日到 1 月 2 日（包含）
  - 时分秒被忽略

**示例：**

```
输入：
["LogSystem", "put", "put", "put", "retrieve", "retrieve"]
[[], [1, "2017:01:01:23:59:59"], [2, "2017:01:01:22:59:59"], [3, "2016:01:01:00:00:00"], ["2016:01:01:01:01:01", "2017:01:01:23:00:00", "Year"], ["2016:01:01:01:01:01", "2017:01:01:23:00:00", "Hour"]]

输出：
[null, null, null, null, [3, 2, 1], [2, 1]]

解释：
LogSystem logSystem = new LogSystem();
logSystem.put(1, "2017:01:01:23:59:59");
logSystem.put(2, "2017:01:01:22:59:59");
logSystem.put(3, "2016:01:01:00:00:00");

// 按 Year 粒度检索：2016-2017 年的所有日志
logSystem.retrieve("2016:01:01:01:01:01", "2017:01:01:23:00:00", "Year");
// 返回 [3, 2, 1]，因为 2016 和 2017 年的日志都在范围内

// 按 Hour 粒度检索：2016:01:01:01 到 2017:01:01:23 小时范围
logSystem.retrieve("2016:01:01:01:01:01", "2017:01:01:23:00:00", "Hour");
// 返回 [2, 1]，因为：
// - id=3: 2016:01:01:00 不在 [2016:01:01:01, 2017:01:01:23] 范围内
// - id=2: 2017:01:01:22 在范围内
// - id=1: 2017:01:01:23 在范围内
```

**提示：**
- `1 <= id <= 500`
- `2000 <= Year <= 2017`
- `1 <= Month <= 12`
- `1 <= Day <= 31`
- `0 <= Hour <= 23`
- `0 <= Minute, Second <= 59`
- `granularity` 是 `["Year", "Month", "Day", "Hour", "Minute", "Second"]` 之一
- 最多调用 `put` 和 `retrieve` 共 `500` 次

## 解题思路

这道题的核心是根据不同的粒度截断时间戳进行比较。

**关键观察：**

1. **时间戳格式固定**：`Year:Month:Day:Hour:Minute:Second`，可以直接字符串比较
2. **粒度决定比较长度**：
   - `"Year"`: 只比较前 4 个字符（`2017`）
   - `"Month"`: 比较前 7 个字符（`2017:01`）
   - `"Day"`: 比较前 10 个字符（`2017:01:01`）
   - `"Hour"`: 比较前 13 个字符（`2017:01:01:23`）
   - `"Minute"`: 比较前 16 个字符（`2017:01:01:23:59`）
   - `"Second"`: 比较全部 19 个字符

3. **截断策略**：
   - 对于 `start`，低精度部分用最小值（`00:00:00`）
   - 对于 `end`，低精度部分用最大值（`23:59:59` 或 `12:31:23:59:59`）

**算法策略：**

1. **存储日志**：使用列表存储 `(id, timestamp)` 对
2. **检索日志**：
   - 根据粒度截断时间戳
   - 遍历所有日志，比较截断后的时间戳是否在范围内
   - 返回符合条件的 id 列表

**优化思路（可选）：**
- 使用索引（如按时间排序）加速检索
- 使用字典按粒度分组存储

## Python 代码实现

### 方法一：简单实现（推荐）

```python
from typing import List

class LogSystem:
    def __init__(self):
        """初始化日志存储系统"""
        # 存储所有日志：[(id, timestamp), ...]
        self.logs = []
        
        # 粒度到时间戳长度的映射
        self.granularity_map = {
            "Year": 4,      # 2017
            "Month": 7,     # 2017:01
            "Day": 10,      # 2017:01:01
            "Hour": 13,     # 2017:01:01:23
            "Minute": 16,   # 2017:01:01:23:59
            "Second": 19    # 2017:01:01:23:59:59
        }
    
    def put(self, id: int, timestamp: str) -> None:
        """存储日志"""
        self.logs.append((id, timestamp))
    
    def retrieve(self, start: str, end: str, granularity: str) -> List[int]:
        """
        检索指定时间范围内的日志
        
        参数:
            start: 起始时间
            end: 结束时间
            granularity: 粒度级别
        
        返回:
            符合条件的日志 id 列表
        """
        # 获取粒度对应的截断长度
        length = self.granularity_map[granularity]
        
        # 截断时间戳
        start_truncated = start[:length]
        end_truncated = end[:length]
        
        # 检索符合条件的日志
        result = []
        for log_id, timestamp in self.logs:
            timestamp_truncated = timestamp[:length]
            # 字符串比较（时间戳格式保证了字典序等于时间序）
            if start_truncated <= timestamp_truncated <= end_truncated:
                result.append(log_id)
        
        return result
```

### 方法二：优化的实现（使用辅助函数）

```python
class LogSystem:
    def __init__(self):
        self.logs = []
        self.granularity_lengths = {
            "Year": 4, "Month": 7, "Day": 10,
            "Hour": 13, "Minute": 16, "Second": 19
        }
    
    def put(self, id: int, timestamp: str) -> None:
        self.logs.append((id, timestamp))
    
    def _truncate(self, timestamp: str, granularity: str) -> str:
        """根据粒度截断时间戳"""
        length = self.granularity_lengths[granularity]
        return timestamp[:length]
    
    def retrieve(self, start: str, end: str, granularity: str) -> List[int]:
        """检索日志"""
        start_trunc = self._truncate(start, granularity)
        end_trunc = self._truncate(end, granularity)
        
        return [
            log_id 
            for log_id, timestamp in self.logs
            if start_trunc <= self._truncate(timestamp, granularity) <= end_trunc
        ]
```

### 方法三：使用索引优化（适合大量查询）

```python
from bisect import bisect_left, bisect_right
from typing import List

class LogSystem:
    def __init__(self):
        # 按时间戳排序存储
        self.logs = []  # [(timestamp, id), ...] 有序
        self.granularity_lengths = {
            "Year": 4, "Month": 7, "Day": 10,
            "Hour": 13, "Minute": 16, "Second": 19
        }
    
    def put(self, id: int, timestamp: str) -> None:
        """插入并保持有序"""
        # 使用二分查找插入位置
        from bisect import insort
        insort(self.logs, (timestamp, id))
    
    def retrieve(self, start: str, end: str, granularity: str) -> List[int]:
        """使用二分查找加速"""
        length = self.granularity_lengths[granularity]
        start_trunc = start[:length]
        end_trunc = end[:length]
        
        result = []
        for timestamp, log_id in self.logs:
            timestamp_trunc = timestamp[:length]
            if start_trunc <= timestamp_trunc <= end_trunc:
                result.append(log_id)
            elif timestamp_trunc > end_trunc:
                # 由于有序，后续都不满足
                break
        
        return result
```

### 方法四：详细注释版本（教学用）

```python
class LogSystem:
    def __init__(self):
        """
        初始化日志系统
        存储结构：列表，每个元素是 (id, timestamp) 对
        """
        self.logs = []
        
        # 不同粒度对应的字符串截断长度
        # 例如："2017:01:01:23:59:59"
        # Year:   "2017"           (4 chars)
        # Month:  "2017:01"        (7 chars)
        # Day:    "2017:01:01"     (10 chars)
        # Hour:   "2017:01:01:23"  (13 chars)
        # Minute: "2017:01:01:23:59" (16 chars)
        # Second: "2017:01:01:23:59:59" (19 chars)
        self.index_map = {
            "Year": 4,
            "Month": 7,
            "Day": 10,
            "Hour": 13,
            "Minute": 16,
            "Second": 19
        }
    
    def put(self, id: int, timestamp: str) -> None:
        """
        存储一条日志
        
        参数:
            id: 日志 ID
            timestamp: 时间戳，格式 "Year:Month:Day:Hour:Minute:Second"
        """
        self.logs.append((id, timestamp))
    
    def retrieve(self, start: str, end: str, granularity: str) -> List[int]:
        """
        检索指定时间范围的日志
        
        参数:
            start: 起始时间（包含）
            end: 结束时间（包含）
            granularity: 时间粒度
        
        返回:
            符合条件的日志 ID 列表
        
        示例:
            start = "2016:01:01:01:01:01"
            end = "2017:01:01:23:00:00"
            granularity = "Hour"
            
            截断后:
            start_prefix = "2016:01:01:01"
            end_prefix = "2017:01:01:23"
            
            检查每条日志的时间戳前缀是否在 [start_prefix, end_prefix] 范围内
        """
        # 获取截断长度
        prefix_len = self.index_map[granularity]
        
        # 截断起止时间
        start_prefix = start[:prefix_len]
        end_prefix = end[:prefix_len]
        
        # 遍历所有日志，筛选符合条件的
        result = []
        for log_id, log_timestamp in self.logs:
            # 截断日志时间戳
            log_prefix = log_timestamp[:prefix_len]
            
            # 比较（字符串比较等价于时间比较，因为格式固定）
            if start_prefix <= log_prefix <= end_prefix:
                result.append(log_id)
        
        return result
```

## 复杂度分析

**方法一、二：**
- `put`: O(1)，直接添加
- `retrieve`: O(n)，n 是日志总数，需要遍历所有日志

**方法三（有序存储）：**
- `put`: O(n)，插入保持有序
- `retrieve`: O(n)，虽然可以提前终止，但最坏仍是 O(n)

**空间复杂度：** O(n)，存储所有日志

## 关键点总结

1. **字符串比较**：时间戳格式固定，可以直接用字符串比较
2. **截断策略**：根据粒度截断到相应长度
3. **简单有效**：不需要复杂的时间解析，字符串操作即可
4. **闭区间**：范围是 `[start, end]`，两端都包含
5. **粒度映射**：提前建立粒度到长度的映射表

## 易错点

1. **截断长度错误**：
   ```
   "Year:Month:Day:Hour:Minute:Second"
    012345678901234567890
    
   Year:   0-3   (4 chars)
   Month:  0-6   (7 chars, 包括冒号)
   Day:    0-9   (10 chars)
   Hour:   0-12  (13 chars)
   Minute: 0-15  (16 chars)
   Second: 0-18  (19 chars)
   ```

2. **比较符号**：应该是 `<=`，不是 `<`（闭区间）

3. **返回顺序**：按插入顺序返回，不需要排序

4. **粒度大小写**：题目中粒度首字母大写

5. **时间戳格式**：格式固定，不需要验证，但要理解结构

## 优化思考

**如果日志量很大，查询很频繁怎么办？**

1. **按粒度建索引**：为每个粒度维护一个有序列表
2. **使用树结构**：如平衡二叉树、B 树
3. **范围索引**：使用区间树（Interval Tree）
4. **时间分区**：按年、月分区存储

**如果需要支持删除日志呢？**

使用字典存储：`{id: timestamp}`，方便按 id 删除。
