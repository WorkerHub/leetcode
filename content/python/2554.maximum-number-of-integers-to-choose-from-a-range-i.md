## 题目描述

给你一个整数数组 `banned` 和两个整数 `n` 和 `maxSum`。

你需要从 `[1, n]` 中选择一些整数，每个整数 **最多** 选 1 次。选出的整数满足：
- 不在 `banned` 中
- 选出的整数之和 <= `maxSum`

在满足以上条件的前提下，返回最多能选出的整数数目。

**示例 1：**

```
输入：banned = [1,6,5], n = 5, maxSum = 6
输出：2
解释：可以选 [2, 3]，和为 5 <= 6，数目为 2。
```

**示例 2：**

```
输入：banned = [1,2,3,4,5,6,7], n = 8, maxSum = 1
输出：0
```

**提示：**

- `1 <= banned.length <= 10^4`
- `1 <= banned[i] <= n <= 10^4`
- `1 <= maxSum <= 10^9`

## 解题思路

贪心：从小到大依次选取不在 banned 中的整数（贪心选小数可以选更多）。用集合快速判断是否被禁用。

## Python 代码实现

### 方法一：贪心 + 集合（推荐）

```python
from typing import List

class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        banned_set = set(banned)
        count = 0
        total = 0

        for num in range(1, n + 1):
            if num in banned_set:
                continue
            if total + num > maxSum:
                break
            total += num
            count += 1

        return count
```

### 方法二：排序 + 二分

```python
from typing import List
import bisect

class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        banned_set = set(banned)
        available = [i for i in range(1, n + 1) if i not in banned_set]

        count = 0
        total = 0
        for num in available:
            if total + num > maxSum:
                break
            total += num
            count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n + len(banned))，线性扫描
- 空间复杂度：O(len(banned))，集合

## 关键点总结

1. 贪心：优先选最小的合法整数，可以选更多
2. 从 1 到 n 顺序扫描，跳过 banned 中的数
3. 当累计和超过 maxSum 时立即停止

## 易错点

1. banned 中可能有重复元素，集合去重后使用
2. 选的是 [1, n] 中的整数，不是 banned 的子集
3. 超过 maxSum 时不能选，即使后面有更小的数也不考虑（已按序扫描）
