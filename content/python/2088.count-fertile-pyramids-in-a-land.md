## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`（1 表示肥沃土地，0 表示不肥沃）。

**金字塔**是指：以顶点 `(r, c)` 为尖，向下扩展的三角形，高度为 `h`（h >= 1）时，覆盖位置：
- 第 `r+i` 行（`0 <= i < h`）上，列从 `c-i` 到 `c+i`

**倒置金字塔**是金字塔翻转。

统计 `grid` 中肥沃金字塔和肥沃倒置金字塔的**总数**（金字塔的每个单元格都必须为 1）。

**提示：**
- `m == grid.length, n == grid[i].length`
- `1 <= m, n <= 1000`

## 解题思路

**DP 计算最大金字塔高度：**

对每个位置 `(r, c)`，设 `dp[r][c]` = 以 `(r, c)` 为顶点，向下能形成的最大金字塔高度。

递推关系：如果 `grid[r][c] == 1`，则：
```
dp[r][c] = min(dp[r+1][c-1], dp[r+1][c], dp[r+1][c+1]) + 1
```

即下一行的左中右三个位置的最小值 + 1。

每个 `dp[r][c]` 的值表示可以形成高度为 1, 2, ..., dp[r][c] 的金字塔，共 `dp[r][c]` 个以此为顶点的金字塔。

**倒置金字塔：** 反转矩阵（上下翻转）后，用同样方法处理。

## 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def countPyramids(self, grid: List[List[int]]) -> int:
        def count(g):
            """统计以每行为顶点、向下的金字塔数量"""
            m, n = len(g), len(g[0])
            # dp[c] = 以当前行第 c 列为顶点的最大金字塔高度
            dp = g[-1][:]  # 最后一行，高度最多为 1
            total = sum(dp)

            for r in range(m - 2, -1, -1):
                new_dp = g[r][:]
                for c in range(1, n - 1):
                    if g[r][c] == 1:
                        # 取下一行三个位置的最小值
                        new_dp[c] = min(dp[c - 1], dp[c], dp[c + 1]) + 1
                    # g[r][c] == 0 时，new_dp[c] = 0
                total += sum(new_dp)
                dp = new_dp

            return total

        # 正向金字塔（向下）
        res = count(grid)
        # 倒置金字塔（向上）= 上下翻转后的正向金字塔
        res += count(grid[::-1])

        return res
```

### 方法二：二维 DP 数组

```python
from typing import List

class Solution:
    def countPyramids(self, grid: List[List[int]]) -> int:
        def count(g):
            m, n = len(g), len(g[0])
            dp = [row[:] for row in g]
            total = 0

            # 从倒数第二行往上计算
            for r in range(m - 2, -1, -1):
                for c in range(1, n - 1):
                    if g[r][c] == 1:
                        dp[r][c] = min(dp[r+1][c-1], dp[r+1][c], dp[r+1][c+1]) + 1
                    else:
                        dp[r][c] = 0

            # 每个位置贡献 dp[r][c] 个金字塔（高度 1 到 dp[r][c]）
            for r in range(m):
                for c in range(n):
                    total += dp[r][c]

            return total

        return count(grid) + count(grid[::-1])
```

## 复杂度分析

- 时间复杂度：O(m * n)，DP 两次
- 空间复杂度：O(m * n) 或 O(n)（滚动数组优化）

## 关键点总结

1. `dp[r][c]` 表示以 `(r, c)` 为顶点的最大金字塔高度
2. 递推：取下一行左中右三个位置的最小值 + 1
3. 每个 `dp[r][c]` 值贡献 `dp[r][c]` 个不同高度的金字塔
4. 倒置金字塔：上下翻转矩阵后重复计算

## 易错点

- 边界列（第一列和最后一列）不能作为顶点（左右无扩展空间）
- `grid[r][c] == 0` 时，`dp[r][c]` 应设为 0
- 注意翻转 `grid[::-1]` 得到的是行翻转（不是列翻转）
