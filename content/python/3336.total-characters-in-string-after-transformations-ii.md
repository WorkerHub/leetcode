## 题目描述

与 3335 类似，但每个字符 `i` 不再是固定变为下一个字符，而是变为接下来 `nums[i]` 个字符（按字母顺序循环）。

给你字符串 `s`、整数 `t` 和长度为 26 的数组 `nums`，其中 `nums[i]` 表示字符 `i`（0 索引）转换后会扩展为接下来 `nums[i]` 个连续字母（循环，'z' 之后是 'a'）。

返回 `t` 次转换后字符串的长度，对 `10^9 + 7` 取模。

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= t <= 10^9`（注意 t 很大！）
- `1 <= nums[i] <= 26`

## 解题思路

**矩阵快速幂：**

由于 `t` 可达 `10^9`，必须用矩阵快速幂。

构造 26x26 转移矩阵 `M`：
- 字符 `i` 转换后产生字符 `i+1, i+2, ..., i+nums[i]`（模 26）。
- `M[j][i] = 1` 若 `j` 在 `i` 转换产生的字符集中，否则为 0。

初始向量 `v`：`v[i]` = 字符 `i` 在 `s` 中的出现次数。

经过 `t` 次转换后，字符 `j` 的数量 = `(M^t * v)[j]`。

总长度 = 所有字符数量之和。

## Python 代码实现

### 方法一：矩阵快速幂（推荐）

```python
from typing import List

class Solution:
    def lengthAfterTransformations(self, s: str, t: int, nums: List[int]) -> int:
        MOD = 10**9 + 7
        
        # 构建转移矩阵
        M = [[0] * 26 for _ in range(26)]
        for i in range(26):
            for k in range(1, nums[i] + 1):
                j = (i + k) % 26
                M[j][i] = (M[j][i] + 1) % MOD
        
        def mat_mul(A, B):
            n = len(A)
            C = [[0] * n for _ in range(n)]
            for i in range(n):
                for k in range(n):
                    if A[i][k] == 0:
                        continue
                    for j in range(n):
                        if B[k][j]:
                            C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
            return C
        
        def mat_pow(M, p):
            n = len(M)
            # 单位矩阵
            R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
            while p:
                if p & 1:
                    R = mat_mul(R, M)
                M = mat_mul(M, M)
                p >>= 1
            return R
        
        # 初始字符计数
        cnt = [0] * 26
        for c in s:
            cnt[ord(c) - ord('a')] += 1
        
        # 计算 M^t
        Mt = mat_pow(M, t)
        
        # 计算转换后各字符数量
        total = 0
        for j in range(26):
            val = 0
            for i in range(26):
                val = (val + Mt[j][i] * cnt[i]) % MOD
            total = (total + val) % MOD
        
        return total
```

## 复杂度分析

- 时间复杂度：O(26^3 * log t + n)，矩阵快速幂 + 初始化
- 空间复杂度：O(26^2)

## 关键点总结

1. 转移矩阵 `M[j][i]` 表示字符 `i` 转换后在字符 `j` 中贡献的数量。
2. `t` 次转换对应矩阵的 `t` 次幂。
3. 26x26 矩阵乘法 O(26^3)，快速幂 O(log t)，总时间 O(26^3 * log t)。

## 易错点

1. 转移矩阵的方向：`M[j][i]` 而不是 `M[i][j]`（列向量乘法）。
2. `nums[i]` 的范围是 1 到 26，即字符 `i` 变为 `nums[i]` 个字符（而不是变为第 `nums[i]` 个字符）。
3. 循环处理：`(i + k) % 26` 处理 'z' 之后循环到 'a'。
