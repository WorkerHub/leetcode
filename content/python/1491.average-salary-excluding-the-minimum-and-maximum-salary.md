## 题目描述

给你一个整数数组 `salary`，数组里每个数都是**唯一**的，且都是正整数。

请你返回去掉最低工资和最高工资以后，剩余员工工资的**平均值**。

**示例 1：**

```
输入：salary = [4000, 3000, 1000, 2000]
输出：2500.00000
解释：最低工资 1000，最高工资 4000，去掉后平均值 = (3000+2000)/2 = 2500
```

**示例 2：**

```
输入：salary = [1000, 2000, 3000]
输出：2000.00000
解释：最低工资 1000，最高工资 3000，去掉后平均值 = 2000/1 = 2000
```

**提示：**

- `3 <= salary.length <= 100`
- `10^3 <= salary[i] <= 10^6`
- `salary` 中的所有数字都是唯一的。

## 解题思路

**方法一：数学公式（O(n)，推荐）**

直接利用公式：

```
平均值 = (总和 - 最大值 - 最小值) / (n - 2)
```

一次遍历同时求总和、最大值、最小值，效率最高。

**方法二：排序**

将数组排序后，去掉第一个（最小值）和最后一个（最大值），对中间元素求平均。

排序需要 O(n log n)，比方法一慢，但代码更直观。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
from typing import List

class Solution:
    def average(self, salary: List[int]) -> float:
        # 利用公式：(总和 - 最大 - 最小) / (n - 2)
        total = sum(salary)
        return (total - max(salary) - min(salary)) / (len(salary) - 2)
```

### 方法二：排序后截取

```python
from typing import List

class Solution:
    def average(self, salary: List[int]) -> float:
        # 排序后去掉头尾元素
        salary.sort()
        # salary[1:-1] 取中间部分
        middle = salary[1:-1]
        return sum(middle) / len(middle)
```

### 方法三：一次遍历（手动维护最大最小值）

```python
from typing import List

class Solution:
    def average(self, salary: List[int]) -> float:
        min_sal = float('inf')   # 最低工资
        max_sal = float('-inf')  # 最高工资
        total = 0

        for s in salary:
            total += s
            if s < min_sal:
                min_sal = s
            if s > max_sal:
                max_sal = s

        # 去掉最高和最低后求平均
        return (total - min_sal - max_sal) / (len(salary) - 2)
```

### 方法四：Python 特色写法（简洁版）

```python
from typing import List

class Solution:
    def average(self, salary: List[int]) -> float:
        # 利用 sorted 和切片，一行解决
        s = sorted(salary)
        return sum(s[1:-1]) / (len(s) - 2)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（公式） | O(n) | O(1) |
| 方法二（排序） | O(n log n) | O(1) 或 O(n) |
| 方法三（一次遍历） | O(n) | O(1) |
| 方法四（sorted） | O(n log n) | O(n) |

- 对于 `n <= 100` 的数据规模，所有方法实际运行时间几乎相同
- 方法一最优，O(n) 时间，O(1) 空间

## 关键点总结

1. **公式推导**：`(sum - max - min) / (n - 2)` 是最简洁的解法。
2. **Python 内置函数**：`sum()`、`max()`、`min()` 各自遍历一次，总体仍是 O(n)。
3. **切片技巧**：`salary[1:-1]` 去掉排序后的首尾元素。
4. **题目保证**：所有数字唯一，数组长度 >= 3，无需处理边界情况。

## 易错点

- **整除问题**：Python 3 中 `/` 返回浮点数，无需担心整除。Python 2 中需要 `float(...)` 转换。
- **分母计算**：去掉两个元素后，分母是 `len(salary) - 2`，不要写成 `len(salary)`。
- **不要修改原数组**：`sort()` 会修改原数组，如需保留原数组应使用 `sorted()`。
