## 题目描述

给定 `m × n` 的矩阵，其中 `0` 表示空格，`1` 表示障碍物。从左上角 `(0,0)` 出发，到达右下角 `(m-1,n-1)`，求最短路径长度（步数）。若不可达返回 `-1`。

**示例 1：**
```
输入：grid = [[0,0,0],[1,1,0],[1,1,0]]
输出：4
解释：路径 (0,0)->(0,1)->(0,2)->(1,2)->(2,2)，共 4 步。
```

**示例 2：**
```
输入：grid = [[0,1],[1,0]]
输出：-1
```

**提示：**
- `1 <= m, n <= 1000`
- `grid[i][j]` 为 0 或 1
- 起点和终点均为 0

## 解题思路

标准 BFS，从起点开始层序遍历，找到终点时返回步数。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def shortestPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][0] == 1 or grid[m-1][n-1] == 1:
            return -1
        if m == 1 and n == 1:
            return 0

        visited = [[False] * n for _ in range(m)]
        visited[0][0] = True
        queue = deque([(0, 0, 0)])  # (行, 列, 步数)
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        while queue:
            r, c, steps = queue.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc] and grid[nr][nc] == 0:
                    if nr == m-1 and nc == n-1:
                        return steps + 1
                    visited[nr][nc] = True
                    queue.append((nr, nc, steps + 1))

        return -1
```

### 方法二：双向 BFS（加速）

```python
from typing import List
from collections import deque

class Solution:
    def shortestPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][0] == 1 or grid[m-1][n-1] == 1:
            return -1
        if m == 1 and n == 1:
            return 0

        dirs = [(0,1),(0,-1),(1,0),(-1,0)]
        front = {(0, 0)}
        back = {(m-1, n-1)}
        visited_front = {(0, 0): 0}
        visited_back = {(m-1, n-1): 0}
        step = 0

        while front and back:
            step += 1
            new_front = set()
            for r, c in front:
                for dr, dc in dirs:
                    nr, nc = r+dr, c+dc
                    if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 0 and (nr,nc) not in visited_front:
                        if (nr, nc) in visited_back:
                            return step + visited_back[(nr,nc)]
                        visited_front[(nr,nc)] = step
                        new_front.add((nr,nc))
            front = new_front
            # 交换前后队列（总是扩展较小的）
            if len(front) > len(back):
                front, back = back, front
                visited_front, visited_back = visited_back, visited_front

        return -1
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. BFS 保证找到最短路径（无权图）
2. 标记 visited 防止重复访问
3. 双向 BFS 可以将搜索空间减半

## 易错点

1. 起点或终点为障碍物时直接返回 -1
2. 起点 == 终点（1×1 矩阵）时返回 0
