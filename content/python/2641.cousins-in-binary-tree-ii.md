## 题目描述

给你一棵二叉树的根节点 `root`，用 **堂兄弟节点之和** 替换每个节点的值：堂兄弟节点是具有相同深度但父节点不同的节点，每个节点的新值 = 同层所有堂兄弟节点值之和（不包含兄弟节点，即同父节点的节点）。

返回修改后的树的根节点。

**示例 1：**
```
输入：root = [5,4,9,1,10,null,7]
输出：[0,0,0,7,7,null,11]
解释：
- 第0层：根 5，堂兄弟为空，新值 0
- 第1层：4和9，堂兄弟互为零（兄弟不算），新值都为 0
- 第2层：1和10（父4），7（父9）；
  - 1的堂兄弟是7，新值=7；10的堂兄弟是7，新值=7；7的堂兄弟是1+10=11，新值=11
```

**数据范围：**
- 树中节点数在 [1, 10^5]
- 1 <= Node.val <= 10^4

## 解题思路

BFS 两次遍历（或 DFS 两次遍历）：

1. 第一次遍历：计算每层的节点值总和 `level_sum`
2. 第二次遍历：对每个节点，其新值 = `level_sum[depth] - 兄弟节点值和 - 自身值`

其中"兄弟节点值和"就是同一父节点下所有子节点的值和（包括自身）。

可以用 BFS，每次处理一整层，计算该层总和，然后更新上一层节点的值。

## Python 代码实现

### 方法一：两次 BFS（推荐）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def replaceValueInTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return root

        # BFS，每次处理一整层
        queue = deque([root])
        root.val = 0  # 根节点没有堂兄弟，新值为 0

        while queue:
            level_size = len(queue)
            # 收集当前层所有父节点及其子节点
            level_sum = 0
            children = []

            for _ in range(level_size):
                node = queue.popleft()
                child_sum = 0
                if node.left:
                    child_sum += node.left.val
                if node.right:
                    child_sum += node.right.val
                level_sum += child_sum
                children.append((node, child_sum))

            # 更新子节点的值
            for node, child_sum in children:
                if node.left:
                    node.left.val = level_sum - child_sum
                    queue.append(node.left)
                if node.right:
                    node.right.val = level_sum - child_sum
                    queue.append(node.right)

        return root
```

### 方法二：DFS 两次遍历

```python
from typing import Optional
from collections import defaultdict

class Solution:
    def replaceValueInTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        # 第一次 DFS：计算每层总和
        level_sums = defaultdict(int)

        def dfs1(node, depth):
            if not node:
                return
            level_sums[depth] += node.val
            dfs1(node.left, depth + 1)
            dfs1(node.right, depth + 1)

        dfs1(root, 0)

        # 第二次 DFS：更新每个节点的值
        def dfs2(node, depth, sibling_sum):
            if not node:
                return
            node.val = level_sums[depth] - sibling_sum
            # 计算子节点的兄弟和
            child_sum = (node.left.val if node.left else 0) + \
                        (node.right.val if node.right else 0)
            dfs2(node.left, depth + 1, child_sum)
            dfs2(node.right, depth + 1, child_sum)

        dfs2(root, 0, root.val)
        return root
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问常数次
- 空间复杂度：O(n)，BFS 队列

## 关键点总结

1. 每个节点的新值 = 同层总和 - 兄弟节点总和（兄弟 = 同父节点的子节点）
2. BFS 按层处理，先累积当前层的父节点子节点总和，再更新
3. 根节点没有堂兄弟，新值为 0

## 易错点

1. 兄弟节点不算入堂兄弟（同父的兄弟不计入新值）
2. 根节点直接设为 0，无需计算
