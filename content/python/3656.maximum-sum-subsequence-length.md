## 题目描述

给你一个整数数组 `nums` 和整数 `k`，找到长度至多为 `k` 的子数组（连续子数组），使其元素之和最大。

**示例 1：**

```
输入：nums = [1,-1,5,-2,3], k = 3
输出：7
解释：[5,-2,3] 或 [1,-1,5] 最大
```

**示例 2：**

```
输入：nums = [-2,-1,3,4,-5], k = 3
输出：7
解释：[3,4] 或 [3,4,-5]? [-1,3,4]=6 或 [3,4]=7
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

**前缀和 + 单调队列**：

`sum[i..j] = prefix[j+1] - prefix[i]`，最大化 `prefix[j+1] - prefix[i]`，约束 `j - i + 1 <= k`，即 `i >= j + 1 - k`。

对每个 `j`，在 `[j+1-k, j]` 范围内找最小的 `prefix[i]`，用单调队列维护。

## Python 代码实现

### 方法一：前缀和 + 单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maxSumSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = float('-inf')
        dq = deque()  # 单调递增队列，存下标

        for j in range(1, n + 1):
            # 移除窗口外的元素
            while dq and dq[0] < j - k:
                dq.popleft()
            # 当前 sum[i..j-1] = prefix[j] - prefix[i]，i 在 dq 中
            if dq:
                ans = max(ans, prefix[j] - prefix[dq[0]])
            # 维护单调递增队列（从队尾移除大于 prefix[j] 的元素）
            while dq and prefix[dq[-1]] >= prefix[j]:
                dq.pop()
            dq.append(j)

        return ans
```

### 方法二：滑动窗口最大和（暴力）

```python
from typing import List

class Solution:
    def maxSumSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = float('-inf')
        for length in range(1, k + 1):
            for i in range(n - length + 1):
                ans = max(ans, prefix[i + length] - prefix[i])
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n * k)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 前缀和将子数组和转为两端前缀和之差
2. 单调队列维护滑动窗口内的最小前缀和
3. 窗口大小约束转化为下标范围约束

## 易错点

1. 队列存的是前缀和下标，`prefix[0..j]` 对应子数组 `[0..j-1]`
2. 队列维护最小值，从队尾弹出大于当前值的元素
3. 窗口外的元素从队头弹出
