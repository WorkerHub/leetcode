## 题目描述

给你一个数组 `nums`，请你找到一个长度最小的子序列，满足该子序列的元素之和**严格大于**未包含在该子序列中的元素之和。

如果存在多个满足条件的子序列，请返回**元素之和最大**的子序列（也就是说，子序列按**非递增顺序**排序）。

题目数据保证满足所有条件的子序列存在。

**注意：** 子序列的元素不一定要连续。返回子序列需按**非递增顺序**排序。

**示例 1：**

```
输入：nums = [4,3,10,9,8]
输出：[10,9]
解释：子序列 [10,9] 和 [10,8] 是最小的、满足元素之和大于其他元素之和的子序列。
但是 [10,9] 的元素之和最大，所以返回 [10,9]。
```

**示例 2：**

```
输入：nums = [4,4,7,6,7]
输出：[7,7,6]
解释：子序列 [7,7] 和 [7,6] 都是最小的满足条件的子序列。但是 [7,7] 有两个 7，而 [7,6] 的元素和为 13 < 14，所以应返回 [7,7,6]。
实际上 7+7=14 > 4+4+6=14 不成立（要严格大于），所以需要取 [7,7,6]。
```

**示例 3：**

```
输入：nums = [6]
输出：[6]
```

**提示：**

- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`

## 解题思路

**贪心策略：**

要找"元素和最大的最短子序列"，自然想到**排序后从大到小取元素**：

1. 将 `nums` 降序排序
2. 从最大值开始逐个加入子序列，同时维护"子序列之和"和"剩余元素之和"
3. 一旦子序列之和 > 剩余元素之和，立即返回结果

**正确性证明：**
- 降序贪心保证了每次加入的都是当前最大值，使得子序列以最快速度超过剩余元素之和
- 这样得到的子序列长度最短，且在同等长度下元素之和最大

## Python 代码实现

### 方法一：降序排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        # 降序排序
        nums.sort(reverse=True)
        total = sum(nums)  # 所有元素之和

        sub_sum = 0   # 子序列当前之和
        result = []   # 子序列结果

        for num in nums:
            sub_sum += num
            result.append(num)
            remaining = total - sub_sum  # 剩余元素之和
            # 子序列之和严格大于剩余之和时停止
            if sub_sum > remaining:
                break

        return result
```

### 方法二：用前缀和判断（等价写法）

```python
from typing import List

class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        nums.sort(reverse=True)
        total = sum(nums)
        half = total / 2  # 子序列之和需超过一半

        result = []
        current_sum = 0

        for num in nums:
            current_sum += num
            result.append(num)
            # 当前子序列之和超过总和的一半时，就满足严格大于剩余之和
            if current_sum > half:
                break

        return result
```

### 方法三：迭代器写法（Python 精简）

```python
from typing import List
from itertools import accumulate

class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        nums.sort(reverse=True)
        total = sum(nums)
        # 前缀累积和
        for i, prefix in enumerate(accumulate(nums)):
            # 子序列前 i+1 个元素的和 > 剩余元素的和
            if prefix > total - prefix:
                return nums[:i + 1]
        return nums  # 题目保证不会走到这里
```

## 复杂度分析

- **时间复杂度 O(n log n)**：排序主导。
- **空间复杂度 O(n)**：存储结果（最坏全部元素）。

## 图解示例

以 `nums = [4,3,10,9,8]` 为例：

```
排序后：[10, 9, 8, 4, 3]
total = 34, half = 17

i=0: 取 10, sub_sum=10, remaining=24, 10 <= 24，继续
i=1: 取 9,  sub_sum=19, remaining=15, 19 > 15，停止

返回 [10, 9]
```

以 `nums = [4,4,7,6,7]` 为例：

```
排序后：[7, 7, 6, 4, 4]
total = 28, half = 14

i=0: 取 7, sub_sum=7,  remaining=21, 7 <= 21，继续
i=1: 取 7, sub_sum=14, remaining=14, 14 <= 14（注意是严格大于），继续
i=2: 取 6, sub_sum=20, remaining=8,  20 > 8，停止

返回 [7, 7, 6]
```

## 关键点总结

1. 降序排序后从大到小贪心取元素，保证最短且和最大
2. 停止条件：子序列之和**严格大于**剩余之和（`sub_sum > total - sub_sum`）
3. 等价条件：`sub_sum > total / 2`（两者严格等价）
4. 结果直接按降序排列，满足题目"非递增顺序"的要求

## 易错点

- 条件是**严格大于**（`>`），不是 `>=`，示例 2 中 `14 > 14` 不成立
- 用 `total / 2` 判断时注意整数除法：Python 3 中 `/` 是浮点除法，不用担心；若用 `//` 则需改为 `sub_sum * 2 > total`
- 不需要从原数组中找子序列的下标，只需返回值即可（降序排序后直接取前若干个）
