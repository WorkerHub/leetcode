## 题目描述

有一个餐厅，只有一位厨师。你有一个顾客数组 `customers`，其中 `customers[i] = [arrival_i, time_i]`：
- `arrival_i` 是第 `i` 位顾客到达的时间（保证非递减）
- `time_i` 是为第 `i` 位顾客做饭需要的时间

每当厨师空闲时，厨师会立即为下一位顾客服务。顾客会一直等待，直到厨师完成他的订单。厨师同时只能服务一位顾客。

返回所有顾客需要等待的**平均**时间，误差不超过 `1e-5`。

**示例 1：**
```
输入：customers = [[1,2],[2,5],[4,3]]
输出：5.00000
解释：
顾客 1：到达时间 1，开始服务 1，结束 3，等待 3-1=2
顾客 2：到达时间 2，开始服务 3，结束 8，等待 8-2=6
顾客 3：到达时间 4，开始服务 8，结束 11，等待 11-4=7
平均等待时间 (2+6+7)/3 = 5.0
```

**示例 2：**
```
输入：customers = [[5,2],[5,4],[10,3],[20,1]]
输出：3.25000
```

**提示：**
- `1 <= customers.length <= 10^5`
- `1 <= arrival_i, time_i <= 10^4`
- `arrival_i` 按非递减顺序排列

## 解题思路

用模拟的方式，维护厨师当前可以开始服务的时间（即厨师空闲时间）：
1. 对每位顾客，开始服务时间 = max(厨师空闲时间, 顾客到达时间)
2. 完成时间 = 开始服务时间 + 做饭时间
3. 等待时间 = 完成时间 - 顾客到达时间
4. 更新厨师空闲时间为完成时间

最后求平均值即可。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def averageWaitingTime(self, customers: List[List[int]]) -> float:
        # 厨师当前空闲的时间点
        free_time = 0
        # 累计等待时间
        total_wait = 0
        
        for arrival, cook_time in customers:
            # 厨师开始服务的时间：要么顾客到达时厨师已空闲，要么等厨师做完上一单
            start = max(free_time, arrival)
            # 做完的时间
            finish = start + cook_time
            # 顾客等待时间 = 完成时间 - 到达时间
            total_wait += finish - arrival
            # 更新厨师空闲时间
            free_time = finish
        
        return total_wait / len(customers)
```

### 方法二：使用 enumerate 逐步累计

```python
from typing import List

class Solution:
    def averageWaitingTime(self, customers: List[List[int]]) -> float:
        n = len(customers)
        total_wait = 0
        # 记录厨师完成上一订单的时间
        prev_finish = 0
        
        for i in range(n):
            arrival = customers[i][0]
            cook_time = customers[i][1]
            
            if prev_finish <= arrival:
                # 厨师空闲，顾客一到就开始
                finish = arrival + cook_time
            else:
                # 顾客需要等待厨师
                finish = prev_finish + cook_time
            
            # 等待时间 = 完成时间 - 到达时间
            total_wait += finish - arrival
            prev_finish = finish
        
        return total_wait / n
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历一次顾客数组
- **空间复杂度**：O(1)，只用了常数额外空间

## 关键点总结

1. 等待时间 = 完成时间 - 到达时间（不是完成时间 - 开始服务时间）
2. 厨师下一次开始服务的时间 = max(上次完成时间, 当前顾客到达时间)
3. 顾客到达时间已经保证有序，不需要排序

## 易错点

- 等待时间包含了被服务的时间，是"完成时间 - 到达时间"，而不是"开始时间 - 到达时间"
- 当厨师空闲时间小于顾客到达时间，开始时间要取顾客到达时间，不能用厨师空闲时间
