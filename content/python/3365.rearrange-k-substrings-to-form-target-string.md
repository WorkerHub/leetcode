## 题目描述

给你两个字符串 `s` 和 `t`，以及整数 `k`。

将 `s` 分成 `k` 个等长的子串（若 `s.length` 不能被 `k` 整除则无解）。

判断这 `k` 个子串能否重新排列组成字符串 `t`。

**示例：**
```
输入：s = "abab", t = "baba", k = 2
输出：true
解释：s 分成 ["ab", "ab"]，可以拼成 "abab"，但 t = "baba"，需要 "ba" + "ba"
```

**提示：**
- `1 <= s.length <= 10^5`
- `k` 能整除 `s.length`

## 解题思路

**哈希表计数：**

将 `s` 分成 `k` 个长为 `m = s.length / k` 的子串，将 `t` 也分成 `k` 个长为 `m` 的子串。

统计 `s` 分割后各子串的频率，以及 `t` 分割后各子串的频率，若两者相同则可以重排。

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from collections import Counter

class Solution:
    def isPossibleToRearrange(self, s: str, t: str, k: int) -> bool:
        n = len(s)
        if n % k != 0:
            return False
        
        m = n // k  # 每个子串的长度
        
        # 统计 s 和 t 分割后的子串频率
        s_parts = Counter(s[i:i+m] for i in range(0, n, m))
        t_parts = Counter(t[i:i+m] for i in range(0, n, m))
        
        return s_parts == t_parts
```

### 方法二：排序比较

```python
class Solution:
    def isPossibleToRearrange(self, s: str, t: str, k: int) -> bool:
        n = len(s)
        m = n // k
        
        s_sorted = sorted(s[i:i+m] for i in range(0, n, m))
        t_sorted = sorted(t[i:i+m] for i in range(0, n, m))
        
        return s_sorted == t_sorted
```

## 复杂度分析

- 时间复杂度：O(n)，字符串分割和哈希
- 空间复杂度：O(n)，存储子串

## 关键点总结

1. 将 `s` 和 `t` 都按 `k` 等分，得到各 `k` 个子串。
2. 两组子串的多重集合相同，则可以重排。
3. 使用 `Counter` 统计频率，直接比较两个 `Counter` 对象。

## 易错点

1. 若 `len(s) % k != 0`，直接返回 False。
2. 子串需要完整提取（步长为 m），不能只比较字符频率。
3. `Counter` 比较是逐键值对比较，相等则返回 True。
