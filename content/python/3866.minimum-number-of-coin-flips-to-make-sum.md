## 题目描述

给你一个整数数组 `coins`（每个元素为 1 或 -1）和一个目标和 `target`，每次操作可以翻转任意一个硬币（1 变为 -1，-1 变为 1）。

返回使所有硬币之和等于 `target` 所需的最少翻转次数。如果无法达到则返回 -1。

**示例 1：**

```
输入：coins = [1, 1, -1, 1], target = 2
输出：1
解释：翻转 coins[2]=-1 为 1，总和变为 4... 不对。
翻转一个 1 为 -1，总和变为 2。翻转 1 次。
```

**示例 2：**

```
输入：coins = [1, -1], target = 0
输出：0
解释：总和 1+(-1)=0，无需操作。
```

**提示：**
- `1 <= coins.length <= 10^5`
- `coins[i]` 为 1 或 -1
- `-10^5 <= target <= 10^5`

## 解题思路

设 p 为 1 的个数，q 为 -1 的个数，n = p + q。
初始总和 = p - q。

翻转一个 1 为 -1：总和减 2，翻转次数加 1。
翻转一个 -1 为 1：总和加 2，翻转次数加 1。

需要使总和从 `p - q` 到 `target`，差值 `d = target - (p - q)`。

若 d 为奇数，不可能达到（每次操作改变 2），返回 -1。
若 d > 0（需要增大）：翻转 d/2 个 -1 为 1，需 q >= d/2。
若 d < 0（需要减小）：翻转 |d|/2 个 1 为 -1，需 p >= |d|/2。

## Python 代码实现

### 方法一：数学计算（推荐）

```python
from typing import List

class Solution:
    def minFlips(self, coins: List[int], target: int) -> int:
        p = coins.count(1)
        q = len(coins) - p
        current_sum = p - q

        diff = target - current_sum
        if diff % 2 != 0:
            return -1

        flips = diff // 2
        if flips > 0:
            # 需要将 flips 个 -1 翻转为 1
            return flips if q >= flips else -1
        else:
            # 需要将 |flips| 个 1 翻转为 -1
            return -flips if p >= -flips else -1
```

### 方法二：验证边界

```python
from typing import List

class Solution:
    def minFlips(self, coins: List[int], target: int) -> int:
        n = len(coins)
        p = sum(1 for c in coins if c == 1)
        q = n - p

        # 总和范围：[-n, n]（全翻 -1 或全翻 1）
        if target < -n or target > n:
            return -1
        if (target - (p - q)) % 2 != 0:
            return -1

        diff = (target - (p - q)) // 2
        if diff >= 0:
            return diff if diff <= q else -1
        else:
            return -diff if -diff <= p else -1
```

## 复杂度分析

- 时间复杂度：O(n)，统计正负数个数
- 空间复杂度：O(1)

## 关键点总结

1. 每次翻转使总和改变 2，因此差值必须为偶数。
2. 增大总和：翻转 -1 为 1；减小总和：翻转 1 为 -1。
3. 最少翻转次数 = `|diff| / 2`，其中 diff 为目标与当前总和之差。

## 易错点

1. 差值为奇数时返回 -1（无解）。
2. 可用的翻转数量受限（不能翻转超过可用的正/负数个数）。
3. target 超出可能范围（[-n, n]）时返回 -1。
