## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，找出它们的最长公共子数组（连续子序列）的长度。

本题与 LeetCode 718 类似，但数组长度更大，需要更高效的解法。

**示例 1：**
```
输入：nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出：3
解释：公共子数组 [3,2,1] 长度为 3。
```

**示例 2：**
```
输入：nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出：5
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^4`
- `0 <= nums1[i], nums2[i] <= 10^9`

## 解题思路

**方法一：动态规划 O(mn)**

`dp[i][j]`：以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的公共子数组长度。
- 若 `nums1[i-1] == nums2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = 0`

**方法二：滚动哈希 + 二分查找 O((m+n) log(min(m,n)))**

二分子数组长度 `k`，用滚动哈希判断 `nums1` 中是否存在某长度 `k` 的子数组也出现在 `nums2` 中。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        # 使用滚动数组优化空间
        dp = [0] * (n + 1)
        ans = 0

        for i in range(1, m + 1):
            # 需要从右往左更新，防止覆盖
            for j in range(n, 0, -1):
                if nums1[i-1] == nums2[j-1]:
                    dp[j] = dp[j-1] + 1
                    ans = max(ans, dp[j])
                else:
                    dp[j] = 0

        return ans
```

### 方法二：滚动哈希 + 二分查找

```python
from typing import List

class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = (1 << 61) - 1  # 梅森素数
        BASE = 131

        def check(length: int) -> bool:
            if length == 0:
                return True
            # 计算 nums1 中所有长度为 length 的子数组的哈希值
            h = 0
            power = pow(BASE, length, MOD)
            hashes = set()

            for i in range(length):
                h = (h * BASE + nums1[i] + 1) % MOD

            hashes.add(h)
            for i in range(length, len(nums1)):
                h = (h * BASE - (nums1[i-length] + 1) * power + nums1[i] + 1) % MOD
                hashes.add(h)

            # 计算 nums2 中长度为 length 的子数组哈希值，检查是否存在于 hashes 中
            h = 0
            for i in range(length):
                h = (h * BASE + nums2[i] + 1) % MOD

            if h in hashes:
                return True
            for i in range(length, len(nums2)):
                h = (h * BASE - (nums2[i-length] + 1) * power + nums2[i] + 1) % MOD
                if h in hashes:
                    return True

            return False

        lo, hi = 0, min(len(nums1), len(nums2))
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

## 复杂度分析

- 时间复杂度：方法一 O(mn)；方法二 O((m+n) log(min(m,n)))
- 空间复杂度：方法一 O(n)（滚动数组）；方法二 O(m)（哈希集合）

## 关键点总结

1. DP 的状态只依赖上一行，可用滚动数组从 O(mn) 空间降至 O(n)
2. 滚动哈希二分：二分查找长度 k，用哈希 O(m+n) 判断是否存在公共子数组
3. 从右往左更新 DP 数组，防止覆盖当前行需要的上一行数据

## 易错点

1. 滚动数组更新方向：必须从右往左，防止 `dp[j-1]` 被提前覆盖
2. 哈希取模中负数处理（加 MOD 后再取模）
