## 题目描述

给定两个整数 `left` 和 `right`，返回在闭区间 `[left, right]` 内有多少个数字的二进制表示中 `1` 的个数是质数。

**示例 1:**
```
输入: left = 6, right = 10
输出: 4
解释:
6  -> 110 (2 个 1，2 是质数)
7  -> 111 (3 个 1，3 是质数)
8  -> 1000 (1 个 1，1 不是质数)
9  -> 1001 (2 个 1，2 是质数)
10 -> 1010 (2 个 1，2 是质数)
共 4 个数字满足条件。
```

**示例 2:**
```
输入: left = 10, right = 15
输出: 5
解释:
10 -> 1010 (2 个 1，2 是质数)
11 -> 1011 (3 个 1，3 是质数)
12 -> 1100 (2 个 1，2 是质数)
13 -> 1101 (3 个 1，3 是质数)
14 -> 1110 (3 个 1，3 是质数)
15 -> 1111 (4 个 1，4 不是质数)
共 5 个数字满足条件。
```

**提示:**
- `1 <= left <= right <= 10^6`
- `0 <= right - left <= 10^4`

## 解题思路

这道题分为两个子问题：
1. 计算一个数字二进制表示中 1 的个数
2. 判断一个数是否为质数

**关键观察：**
- 由于 `right <= 10^6 < 2^20`，所以二进制位数最多 20 位
- 1 的个数最多为 20
- 只需要预先计算 20 以内的质数：2, 3, 5, 7, 11, 13, 17, 19

## Python 代码实现

### 方法一：位运算 + 质数集合（推荐）⭐

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        # 20 以内的质数
        primes = {2, 3, 5, 7, 11, 13, 17, 19}
        
        count = 0
        for num in range(left, right + 1):
            # 计算二进制中 1 的个数
            bits = bin(num).count('1')
            # 判断是否为质数
            if bits in primes:
                count += 1
        
        return count
```

### 方法二：使用 Brian Kernighan 算法

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        primes = {2, 3, 5, 7, 11, 13, 17, 19}
        
        def count_bits(n):
            """Brian Kernighan 算法：计算 1 的个数"""
            count = 0
            while n:
                n &= n - 1  # 清除最右边的 1
                count += 1
            return count
        
        return sum(1 for num in range(left, right + 1) 
                   if count_bits(num) in primes)
```

### 方法三：使用位掩码

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        # 使用位掩码表示质数
        # 第 i 位为 1 表示 i 是质数
        # 2, 3, 5, 7, 11, 13, 17, 19
        # 对应位: 0b10101000101000100100 = 665772
        prime_mask = 0b10101000101000100100
        
        count = 0
        for num in range(left, right + 1):
            bits = bin(num).count('1')
            # 检查第 bits 位是否为 1
            if (prime_mask >> bits) & 1:
                count += 1
        
        return count
```

### 方法四：详细注释版（易理解）

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        """
        计算区间内二进制 1 的个数为质数的数字个数
        
        步骤:
        1. 对于区间内的每个数字
        2. 计算其二进制表示中 1 的个数
        3. 判断这个个数是否为质数
        4. 如果是，计数加 1
        """
        # 预先列出可能的质数
        # 由于 right <= 10^6 < 2^20，所以最多 20 个 1
        # 20 以内的质数有: 2, 3, 5, 7, 11, 13, 17, 19
        prime_numbers = {2, 3, 5, 7, 11, 13, 17, 19}
        
        result = 0
        
        # 遍历区间内的每个数字
        for number in range(left, right + 1):
            # 方法 1: 使用 Python 内置函数
            # bin(number) 将数字转为二进制字符串，如 "0b110"
            # count('1') 计算字符串中 '1' 的个数
            ones_count = bin(number).count('1')
            
            # 方法 2: 手动计算（更底层）
            # ones_count = 0
            # temp = number
            # while temp:
            #     ones_count += temp & 1
            #     temp >>= 1
            
            # 判断 1 的个数是否为质数
            if ones_count in prime_numbers:
                result += 1
        
        return result
```

### 方法五：一行解法

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        return sum(bin(i).count('1') in {2,3,5,7,11,13,17,19} 
                   for i in range(left, right + 1))
```

## 复杂度分析

- **时间复杂度：** O((right - left) * log(right))，遍历区间，每个数字计算位数需要 O(log n) 时间
- **空间复杂度：** O(1)，只使用常数空间

## 关键点总结

1. **范围限制：** right <= 10^6，所以最多 20 位
2. **质数预计算：** 20 以内的质数只有 8 个
3. **位运算技巧：** bin(n).count('1') 快速计算 1 的个数
4. **集合查找：** 使用集合判断质数，O(1) 时间
5. **优化空间：** 可以用位掩码代替集合

## 易错点

1. **质数定义：** 1 不是质数
2. **边界情况：** left 和 right 都要包含在内
3. **效率问题：** 每次都判断质数会很慢，应该预先存储
4. **位数计算：** bin() 返回的字符串包含 '0b' 前缀
5. **范围理解：** 理解为什么只需要考虑 20 以内的质数
