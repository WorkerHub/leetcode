## 题目描述

给你一个整数数组 `nums`，你需要通过最少的操作次数使数组变为交替数组（奇数位置的元素大于偶数位置的元素，或偶数位置的元素大于奇数位置的元素）。

每次操作可以将数组中的任意元素替换为另一个整数（1 到 `10^5` 之间）。

返回最少操作次数。

**示例 1：**

```
输入：nums = [3, 1, 3, 2, 4, 3]
输出：3
解释：将下标 1, 3, 5 的元素替换，使奇数下标元素均小于相邻偶数下标元素。
```

**示例 2：**

```
输入：nums = [1, 2, 2, 2, 1]
输出：2
解释：
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

分别统计偶数位置和奇数位置各值的出现频率。

目标：偶数位置的值 != 奇数位置的值（或满足大小关系）。

贪心策略：
1. 对偶数位置的值取频率最高的（需要修改最少）。
2. 对奇数位置的值取频率最高的。
3. 若两者不同，不需要额外操作；若相同，取次高频的一方。
4. 最少操作数 = n - (最多保留的元素数)。

## Python 代码实现

### 方法一：贪心 + 频率统计（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        # 统计偶数下标和奇数下标的元素频率
        even_cnt = Counter(nums[i] for i in range(0, n, 2))
        odd_cnt = Counter(nums[i] for i in range(1, n, 2))

        # 取各自频率最高的两个值（备选）
        def top2(counter):
            items = counter.most_common(2)
            if len(items) == 1:
                return items[0], (None, 0)
            return items[0], items[1]

        (e1_val, e1_cnt), (e2_val, e2_cnt) = top2(even_cnt)
        (o1_val, o1_cnt), (o2_val, o2_cnt) = top2(odd_cnt)

        # 若偶数最高频值 != 奇数最高频值，直接选各自最高频
        if e1_val != o1_val:
            keep = e1_cnt + o1_cnt
        else:
            # 冲突：一方选次高频
            keep = max(e1_cnt + o2_cnt, e2_cnt + o1_cnt)

        return n - keep
```

### 方法二：枚举所有可能的值对

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        even_cnt = Counter(nums[i] for i in range(0, n, 2))
        odd_cnt = Counter(nums[i] for i in range(1, n, 2))

        # 获取频率最高的前 2 个
        even_top = even_cnt.most_common(2)
        odd_top = odd_cnt.most_common(2)

        best = 0
        for ev, ec in even_top:
            for ov, oc in odd_top:
                if ev != ov:
                    best = max(best, ec + oc)

        # 如果没有找到不冲突的组合（所有值都相同）
        if best == 0:
            if even_top:
                best = max(best, even_top[0][1])
            if odd_top:
                best = max(best, odd_top[0][1])

        return n - best
```

## 复杂度分析

- 时间复杂度：O(n)，统计频率 O(n)，取最大值 O(1)
- 空间复杂度：O(n)，计数器

## 关键点总结

1. 贪心：保留尽可能多的元素不变，最小化操作数。
2. 偶数位和奇数位分别选频率最高的值，若不冲突直接使用。
3. 冲突时，一方选次高频，取两种方案的较优者。

## 易错点

1. 若只有一种值（counter 只有一个元素），次高频为 0。
2. 操作数 = n - 保留元素数，不是替换次数（这里相同）。
3. 两方向（偶大奇小 / 偶小奇大）都要考虑。
