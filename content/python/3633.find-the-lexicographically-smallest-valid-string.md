## 题目描述

给你一个字符串 `s` 和整数 `k`，你需要将 `s` 修改为字典序最小的字符串，但每次修改只能将某个字符替换为字母表中排在其之前最多 `k` 位的字符（即 `s[i]` 可以改为 `c`，其中 `ord(s[i]) - ord(c) <= k`）。

返回修改后字典序最小的字符串。

**示例 1：**

```
输入：s = "zmd", k = 3
输出："wja"
解释：z→w(z-3=w), m→j(m-3=j), d→a(d-3=a)
```

**示例 2：**

```
输入：s = "abc", k = 2
输出："aaa"
解释：a→a, b→a(b-2), c→a(c-2)
```

**提示：**

- `1 <= s.length <= 10^5`
- `1 <= k <= 25`

## 解题思路

贪心：对每个字符，尽量替换为最小的合法字符（即 `max(ord(s[i]) - k, ord('a'))`）。

因为每个字符的替换独立，直接取 `chr(max(ord(c) - k, ord('a')))` 即可。

## Python 代码实现

### 方法一：贪心直接替换（推荐）

```python
class Solution:
    def getSmallestString(self, s: str, k: int) -> str:
        result = []
        for c in s:
            # 尽量向前移动 k 位，但不能小于 'a'
            new_c = chr(max(ord(c) - k, ord('a')))
            result.append(new_c)
        return ''.join(result)
```

### 方法二：字符串映射

```python
class Solution:
    def getSmallestString(self, s: str, k: int) -> str:
        return ''.join(
            chr(max(ord(c) - k, 97))  # 97 = ord('a')
            for c in s
        )
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每个字符独立处理，贪心最优
2. 最多减少 k，但不能低于 `'a'`
3. `max(ord(c) - k, ord('a'))` 一行搞定

## 易错点

1. `ord('a') = 97`，不是 0
2. 不能替换为 `'a'` 之前的字符
3. 若 `k >= 25` 所有字符都可以变为 `'a'`
