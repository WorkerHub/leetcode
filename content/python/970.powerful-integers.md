## 题目描述

给定三个整数 `x` 、`y` 和 `bound` ，返回**值小于或等于** `bound` 的所有**强整数**组成的列表。

如果某一整数可以表示为 `x^i + y^j` ，其中整数 `i >= 0` 且 `j >= 0`，那么我们认为该整数是一个**强整数**。

你可以按**任何顺序**返回答案。在你的回答中，每个值**最多**出现一次。

**示例 1：**
```
输入：x = 2, y = 3, bound = 10
输出：[2,3,4,5,7,9,10]
解释：
2 = 2^0 + 3^0
3 = 2^1 + 3^0
4 = 2^0 + 3^1
5 = 2^1 + 3^1
7 = 2^2 + 3^1
9 = 2^3 + 3^0
10 = 2^0 + 3^2
```

**示例 2：**
```
输入：x = 3, y = 5, bound = 15
输出：[2,4,6,8,10,14]
```

**提示：**
- `1 <= x, y <= 100`
- `0 <= bound <= 10^6`

## 解题思路

这道题要求生成所有满足 `x^i + y^j <= bound` 的值。

**核心思想：**
1. 枚举所有可能的 i 和 j
2. 由于 `x^i` 增长很快，i 的范围有限
3. 使用哈希集合去重
4. 特殊情况：x = 1 或 y = 1 时，幂次只需要考虑 0 和 1

**边界分析：**
- 当 x = 1 时，`x^i = 1` 对所有 i
- 当 y = 1 时，`y^j = 1` 对所有 j
- 最大幂次：`x^i <= bound`，即 `i <= log(bound) / log(x)`

## Python 代码实现

### 方法一：暴力枚举 + 哈希集合（推荐）⭐

```python
from typing import List

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        result = set()
        
        # x^i 的最大值
        x_limit = 1 if x == 1 else bound
        # y^j 的最大值
        y_limit = 1 if y == 1 else bound
        
        # 枚举 x^i
        xi = 1
        while xi < bound:
            # 枚举 y^j
            yj = 1
            while xi + yj <= bound:
                result.add(xi + yj)
                
                # 如果 y = 1，yj 不会增长，退出
                if y == 1:
                    break
                yj *= y
            
            # 如果 x = 1，xi 不会增长，退出
            if x == 1:
                break
            xi *= x
        
        return list(result)
```

### 方法二：预计算幂次

```python
from typing import List

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        # 预计算 x 的幂次
        x_powers = []
        val = 1
        while val < bound:
            x_powers.append(val)
            if x == 1:
                break
            val *= x
        
        # 预计算 y 的幂次
        y_powers = []
        val = 1
        while val < bound:
            y_powers.append(val)
            if y == 1:
                break
            val *= y
        
        # 生成所有组合
        result = set()
        for xi in x_powers:
            for yj in y_powers:
                if xi + yj <= bound:
                    result.add(xi + yj)
        
        return list(result)
```

### 方法三：数学计算幂次上限

```python
from typing import List
import math

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        result = set()
        
        # 计算 i 和 j 的上限
        max_i = 1 if x == 1 else int(math.log(bound) / math.log(x)) + 1
        max_j = 1 if y == 1 else int(math.log(bound) / math.log(y)) + 1
        
        # 枚举所有 (i, j) 组合
        for i in range(max_i + 1):
            for j in range(max_j + 1):
                val = x ** i + y ** j
                if val <= bound:
                    result.add(val)
        
        return list(result)
```

### 方法四：优化的循环

```python
from typing import List

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        result = set()
        
        # i 从 0 开始枚举
        i = 0
        while True:
            xi = x ** i
            if xi >= bound:
                break
            
            # j 从 0 开始枚举
            j = 0
            while True:
                yj = y ** j
                total = xi + yj
                
                if total > bound:
                    break
                
                result.add(total)
                
                # 如果 y = 1，j 再大也没用
                if y == 1:
                    break
                j += 1
            
            # 如果 x = 1，i 再大也没用
            if x == 1:
                break
            i += 1
        
        return list(result)
```

### 方法五：简洁版

```python
from typing import List

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        res = set()
        
        # x^i
        xi = 1
        for i in range(20):  # 2^20 > 10^6
            # y^j
            yj = 1
            for j in range(20):
                if xi + yj <= bound:
                    res.add(xi + yj)
                else:
                    break
                yj *= y
                if y == 1:
                    break
            
            xi *= x
            if x == 1 or xi >= bound:
                break
        
        return list(res)
```

## 复杂度分析

### 方法一/二
- **时间复杂度**：O(log²(bound))，i 和 j 的范围都是 O(log(bound))
- **空间复杂度**：O(log²(bound))，哈希集合空间

### 方法三
- **时间复杂度**：O(log²(bound))
- **空间复杂度**：O(log²(bound))

## 关键点总结

1. **幂次增长快**：x^i 增长很快，循环次数很少
2. **特殊情况**：x = 1 或 y = 1 时需要特殊处理，避免无限循环
3. **哈希去重**：使用集合自动去重
4. **边界判断**：及时退出循环，避免溢出
5. **双层循环**：枚举所有 (i, j) 组合

## 易错点

1. **无限循环**：x = 1 或 y = 1 时，幂次不增长，会死循环
2. **溢出问题**：x^i 可能很大，要及时退出
3. **边界条件**：x^i 或 y^j 超过 bound 时的处理
4. **去重**：要使用集合去重，列表会有重复
5. **幂次计算**：可以用循环乘法，也可以用 `**` 运算符
