## 题目描述

设计一个找到数据流中第 `k` 大元素的类（class）。注意是排序后的第 `k` 大元素，不是第 `k` 个不同的元素。

请实现 `KthLargest` 类：

- `KthLargest(int k, int[] nums)` 使用整数 `k` 和整数流 `nums` 初始化对象。
- `int add(int val)` 将 `val` 插入数据流 `nums` 后，返回当前数据流中第 `k` 大的元素。

**示例：**
```
输入：
["KthLargest", "add", "add", "add", "add", "add"]
[[3, [4, 5, 8, 2]], [3], [5], [10], [9], [4]]
输出：
[null, 4, 5, 5, 8, 8]

解释：
KthLargest kthLargest = new KthLargest(3, [4, 5, 8, 2]);
kthLargest.add(3);   // 返回 4，数据流为 [2, 3, 4, 5, 8]，第3大元素是4
kthLargest.add(5);   // 返回 5，数据流为 [2, 3, 4, 5, 5, 8]，第3大元素是5
kthLargest.add(10);  // 返回 5，数据流为 [2, 3, 4, 5, 5, 8, 10]，第3大元素是5
kthLargest.add(9);   // 返回 8，数据流为 [2, 3, 4, 5, 5, 8, 9, 10]，第3大元素是8
kthLargest.add(4);   // 返回 8，数据流为 [2, 3, 4, 4, 5, 5, 8, 9, 10]，第3大元素是8
```

**提示：**
- `1 <= k <= 10^4`
- `0 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `-10^4 <= val <= 10^4`
- 最多调用 `add` 方法 `10^4` 次
- 题目数据保证，在查找第 `k` 大元素时，数组中至少有 `k` 个元素

## 解题思路

这是一道经典的**数据流问题**，核心是维护动态变化的第 k 大元素。

**关键洞察：最小堆（Min Heap）**

维护一个大小为 `k` 的最小堆：
- 堆顶元素就是第 `k` 大的元素
- 堆中存储当前数据流中最大的 `k` 个元素
- 新元素插入时，若大于堆顶，则弹出堆顶并插入新元素

**为什么用最小堆？**
1. 我们需要快速访问第 k 大元素（堆顶）
2. 需要快速判断新元素是否在前 k 大（与堆顶比较）
3. 最小堆堆顶是最小值，刚好是第 k 大元素

**操作流程：**
1. 初始化：将 `nums` 中所有元素加入堆，保持堆大小为 `k`
2. 添加元素：
   - 如果堆大小 < k，直接加入
   - 如果新元素 > 堆顶，弹出堆顶，加入新元素
   - 返回堆顶元素

## Python 代码实现

### 方法一：最小堆实现（推荐）⭐

```python
import heapq
from typing import List

class KthLargest:
    def __init__(self, k: int, nums: List[int]):
        """
        初始化：维护大小为 k 的最小堆
        """
        self.k = k
        self.heap = nums
        heapq.heapify(self.heap)  # 堆化，O(n)
        
        # 保持堆大小为 k，移除多余的较小元素
        while len(self.heap) > k:
            heapq.heappop(self.heap)
    
    def add(self, val: int) -> int:
        """
        添加元素并返回第 k 大元素
        """
        # 如果堆未满 k 个元素，直接加入
        if len(self.heap) < self.k:
            heapq.heappush(self.heap, val)
        # 如果新元素大于堆顶（第 k 大元素），更新堆
        elif val > self.heap[0]:
            heapq.heapreplace(self.heap, val)  # 弹出堆顶并插入新值
        
        # 堆顶元素就是第 k 大元素
        return self.heap[0]
```

### 方法二：优化版（简化逻辑）

```python
import heapq
from typing import List

class KthLargest:
    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.heap = []
        
        # 逐个添加元素，利用 add 方法的逻辑
        for num in nums:
            self.add(num)
    
    def add(self, val: int) -> int:
        """
        统一的添加逻辑
        """
        heapq.heappush(self.heap, val)
        
        # 如果堆大小超过 k，弹出最小元素
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        
        return self.heap[0]
```

### 方法三：使用 heappushpop

```python
import heapq
from typing import List

class KthLargest:
    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.heap = nums
        heapq.heapify(self.heap)
        
        # 只保留最大的 k 个元素
        while len(self.heap) > k:
            heapq.heappop(self.heap)
    
    def add(self, val: int) -> int:
        if len(self.heap) < self.k:
            heapq.heappush(self.heap, val)
        else:
            # heappushpop：先 push 再 pop，比分开调用更高效
            heapq.heappushpop(self.heap, val)
        
        return self.heap[0]
```

## 复杂度分析

**初始化 `__init__`：**
- 时间复杂度：O(n + (n-k)log k)
  - `heapify`：O(n)
  - 移除 n-k 个元素：O((n-k)log k)
  - 整体可简化为 O(n log k)
- 空间复杂度：O(k)，堆的大小

**添加元素 `add`：**
- 时间复杂度：O(log k)
  - 堆的插入/删除操作：O(log k)
- 空间复杂度：O(1)

**总体效率：**
- 初始化：O(n log k)
- m 次 add 操作：O(m log k)
- 总时间：O((n+m) log k)

## 关键点总结

1. **数据结构选择**：最小堆维护前 k 大元素
2. **堆的性质**：堆顶是最小值，恰好是第 k 大元素
3. **堆大小控制**：始终保持堆大小为 k
4. **heapq 模块**：Python 内置最小堆实现
5. **API 选择**：`heapreplace` 和 `heappushpop` 比分开操作更高效

## 易错点

1. **堆的类型混淆**：Python `heapq` 是最小堆（不是最大堆）
2. **堆大小管理**：忘记限制堆大小为 k
3. **边界条件**：堆未满 k 个元素时的处理
4. **返回值错误**：应返回 `heap[0]`（堆顶），不是 `heap[-1]`
5. **初始化优化**：直接 `heapify` 比逐个 `heappush` 更快

## 图解示例

以 `k=3, nums=[4,5,8,2]` 为例：

```
初始化过程：
1. heapify([4,5,8,2]) → 最小堆: [2,4,8,5]
2. 保持大小为3，弹出最小的2 → [4,5,8]
   堆结构：
       4
      / \
     5   8

add(3):
   3 < 4（堆顶），不操作 → 返回 4

add(5):
   5 > 4，替换堆顶 → [5,5,8] → 返回 5
   
add(10):
   10 > 5，替换堆顶 → [5,8,10] → 返回 5
```
