## 题目描述

一个句子是若干个单词组成，单词之间以空格分隔，没有前导或尾随空格。每个单词都是小写字母和一个 1 到 9 的数字（在结尾）的组合。

给你一个打乱顺序的句子 `s`，将其恢复成正确顺序后返回（去掉末尾数字）。

**示例 1：**
```
输入：s = "is2 sentence4 This1 a3"
输出："This is a sentence"
```

**示例 2：**
```
输入：s = "Myself2 Me1 I4 and3"
输出："Me Myself and I"
```

## 解题思路

分割字符串，根据每个单词末尾的数字排序，然后拼接去掉数字的单词。

## 代码实现

### 方法一：按末尾数字排序（推荐）

```python
class Solution:
    def sortSentence(self, s: str) -> str:
        words = s.split()
        # 按末尾数字排序，去掉末尾数字后拼接
        words.sort(key=lambda w: w[-1])
        return ' '.join(w[:-1] for w in words)
```

### 方法二：直接放置到对应位置

```python
class Solution:
    def sortSentence(self, s: str) -> str:
        words = s.split()
        result = [''] * len(words)
        for word in words:
            idx = int(word[-1]) - 1  # 末尾数字转为 0-indexed
            result[idx] = word[:-1]  # 去掉末尾数字
        return ' '.join(result)
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为字符串长度
- **空间复杂度**：O(n)，存储分割后的单词

## 关键点总结

1. 每个单词末尾的数字是其在句子中的位置（1-indexed）
2. 方法二直接按位置填充，避免排序，O(n) 时间

## 易错点

- 末尾数字是字符，用 `int(word[-1]) - 1` 转为 0-indexed
- `word[:-1]` 去掉最后一个字符（数字），不是 `word[:-2]`
