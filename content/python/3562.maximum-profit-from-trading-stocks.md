## 题目描述

给定两个整数数组 `present` 和 `future`（长度均为 `n`），以及整数 `budget`。`present[i]` 是第 `i` 支股票的当前价格，`future[i]` 是其未来价格。每支股票最多购买一次（不超过 1 股）。在预算 `budget` 内购买若干股票，卖出时获得利润 `future[i] - present[i]`（若利润为负则不购买）。求最大利润。

**示例 1：**

```
输入：present = [5, 4, 6, 2, 3], future = [8, 5, 4, 3, 5], budget = 10
输出：6
解释：购买股票 0（5元，利润3），股票 3（2元，利润1），股票 4（3元，利润2），共花 10 元，利润 6。
```

**示例 2：**

```
输入：present = [2, 2], future = [3, 3], budget = 3
输出：1
```

**提示：**
- `n == present.length == future.length`
- `1 <= n <= 10^5`
- `0 <= present[i] <= 10^9`
- `0 <= future[i] <= 10^9`
- `0 <= budget <= 10^9`

## 解题思路

0-1 背包问题：
- 每支股票（物品）的代价为 `present[i]`，价值为 `max(0, future[i] - present[i])`
- 背包容量为 `budget`
- 只考虑利润为正的股票

由于 budget 可能很大（最大 10^9），直接 DP 不可行。需要优化。

优化：只考虑利润为正的股票，且按价值密度排序，使用贪心或特殊情况处理。

注意：当预算很大时，可以购买所有利润为正的股票。当预算受限时，用背包 DP（此时有效股票数量有限）。

实际上由于 n 最大 10^5，present[i] 和 budget 都可能很大，标准 0-1 背包 O(n*budget) 不可行。需要其他方法。

## Python 代码实现

### 方法一：0-1 背包（适合小 budget）

```python
from typing import List

class Solution:
    def maximumProfit(self, present: List[int], future: List[int], budget: int) -> int:
        n = len(present)
        # 只考虑有利润的股票
        stocks = [(present[i], future[i] - present[i])
                  for i in range(n) if future[i] > present[i]]

        # 标准 0-1 背包（当 budget <= 10^4 时可行）
        dp = [0] * (budget + 1)
        for cost, profit in stocks:
            if cost > budget:
                continue
            for j in range(budget, cost - 1, -1):
                dp[j] = max(dp[j], dp[j - cost] + profit)

        return dp[budget]
```

### 方法二：贪心（价值密度排序）

```python
from typing import List

class Solution:
    def maximumProfit(self, present: List[int], future: List[int], budget: int) -> int:
        # 只考虑有利润的股票，按"投入产出比"排序
        stocks = [(present[i], future[i] - present[i])
                  for i in range(len(present)) if future[i] > present[i]]

        # 按利润/代价 降序排序（贪心选最高性价比）
        stocks.sort(key=lambda x: -x[1] / x[0] if x[0] > 0 else float('inf'))

        total_profit = 0
        remaining = budget
        for cost, profit in stocks:
            if cost <= remaining:
                remaining -= cost
                total_profit += profit

        return total_profit
```

## 复杂度分析

- 时间复杂度：O(n * budget)（方法一 DP），O(n log n)（方法二贪心，但不保证最优）
- 空间复杂度：O(budget)（方法一），O(n)（方法二）

## 关键点总结

1. 只购买利润为正的股票（future > present）
2. 标准 0-1 背包：dp[j] = 预算为 j 时的最大利润
3. 大 budget 时需要特殊处理（方法一在 budget 大时可能超时）

## 易错点

1. 背包遍历时从大到小（防止同一物品被选多次）
2. 利润为负的股票直接跳过
3. 贪心法对于整数背包问题不一定最优（但可以作为启发）
