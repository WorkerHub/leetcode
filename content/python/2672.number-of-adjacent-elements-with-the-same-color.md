## 题目描述

给你一个长度为 `n` 的初始全 0 数组 `nums`（表示颜色），以及一个操作数组 `queries`（`queries[i] = [index, color]` 表示将 `nums[index]` 的颜色改为 `color`）。在每次操作后，返回相邻且颜色相同的元素对数（统计满足 `nums[i] == nums[i+1] != 0` 的下标对数）。

**示例：**
```
输入：n = 4, queries = [[0,2],[1,2],[3,1],[1,1],[2,1]]
输出：[0,1,0,0,2]
```

**数据范围：**
- 1 <= n <= 10^5
- 1 <= queries.length <= 10^5

## 解题思路

维护当前的相邻同色对数 `ans`。每次操作时：
1. 先减去受影响的配对（位置 `index` 与左邻和右邻的配对）
2. 更新颜色
3. 再加上新产生的配对

## Python 代码实现

### 方法一：差分更新（推荐）

```python
from typing import List

class Solution:
    def colorTheArray(self, n: int, queries: List[List[int]]) -> List[int]:
        nums = [0] * n
        ans = 0
        result = []

        for idx, color in queries:
            # 减去原来的配对
            if nums[idx] != 0:
                if idx > 0 and nums[idx - 1] == nums[idx]:
                    ans -= 1
                if idx < n - 1 and nums[idx + 1] == nums[idx]:
                    ans -= 1
            # 更新颜色
            nums[idx] = color
            # 加上新的配对
            if idx > 0 and nums[idx - 1] == nums[idx]:
                ans += 1
            if idx < n - 1 and nums[idx + 1] == nums[idx]:
                ans += 1

            result.append(ans)

        return result
```

## 复杂度分析

- 时间复杂度：O(n + q)，q 为操作数
- 空间复杂度：O(n)

## 关键点总结

1. 每次操作只影响与 `index` 相邻的配对
2. 先减去旧配对，更新颜色后加上新配对
3. 0 不参与统计（颜色 0 表示未着色）

## 易错点

1. 操作前先检查原颜色是否为 0（若为 0 则没有旧配对）
2. 边界检查（左邻和右邻是否存在）
