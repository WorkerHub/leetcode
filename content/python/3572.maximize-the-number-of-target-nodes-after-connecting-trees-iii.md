## 题目描述

给定两棵树，树1有 `n` 个节点，树2有 `m` 个节点。可以在树1的任意节点和树2的任意节点之间添加一条边（只添加一条）。对每个树1的节点 `v`，"目标节点数"是指到 `v` 的距离不超过 `k` 的节点总数（包括两棵树的节点）。返回每个节点对应的最大目标节点数。

**示例：**

```
输入：edges1 = [[0,1],[0,2]], edges2 = [[0,1]], k = 1
输出：[3, 2, 2]
解释：k=1，节点0可以到达1,2（树1），加上连接树2的节点，最多再多1个节点。
```

**提示：**
- `2 <= n, m <= 1000`
- `0 <= k <= 1000`

## 解题思路

对每个树1的节点 `v`：
1. 计算树1中到 `v` 距离 <= k 的节点数 `cnt1(v)`
2. 连接树2中某个节点 `u`，可以获得树2中到 `u` 距离 <= k-1 的节点数 `cnt2(u)`
3. 最优选择：选树2中 `cnt2(u)` 最大的节点，即 `max_cnt2 = max(cnt2(u) for all u)`
4. 答案 = `cnt1(v) + max_cnt2`

预处理：
- 计算树1每个节点的 `cnt1(v)`（BFS 或 DFS 统计距离 <= k 的节点数）
- 计算树2每个节点的 `cnt2(u)`（类似）
- 取 `max_cnt2`

## Python 代码实现

### 方法一：BFS 预处理（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]], k: int) -> List[int]:
        def build_graph(n, edges):
            graph = defaultdict(list)
            for u, v in edges:
                graph[u].append(v)
                graph[v].append(u)
            return graph

        def count_within_k(graph, start, max_dist):
            # 计算从 start 出发，距离 <= max_dist 的节点数
            if max_dist < 0:
                return 0
            visited = {start}
            queue = deque([(start, 0)])
            count = 1
            while queue:
                node, d = queue.popleft()
                if d >= max_dist:
                    continue
                for nb in graph[node]:
                    if nb not in visited:
                        visited.add(nb)
                        queue.append((nb, d+1))
                        count += 1
            return count

        n = len(edges1) + 1
        m = len(edges2) + 1

        graph1 = build_graph(n, edges1)
        graph2 = build_graph(m, edges2)

        # 计算树1每个节点的 cnt1
        cnt1 = [count_within_k(graph1, v, k) for v in range(n)]

        # 计算树2每个节点的 cnt2（k-1 距离，因为连接边消耗1步）
        if k >= 1:
            cnt2 = [count_within_k(graph2, u, k-1) for u in range(m)]
            max_cnt2 = max(cnt2)
        else:
            max_cnt2 = 0

        return [cnt1[v] + max_cnt2 for v in range(n)]
```

### 方法二：DFS 计算

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]], k: int) -> List[int]:
        def build(edges):
            graph = defaultdict(list)
            for u, v in edges:
                graph[u].append(v)
                graph[v].append(u)
            return graph

        def dfs_count(graph, node, parent, max_d):
            if max_d < 0:
                return 0
            count = 1
            for nb in graph[node]:
                if nb != parent:
                    count += dfs_count(graph, nb, node, max_d - 1)
            return count

        n = len(edges1) + 1
        m = len(edges2) + 1
        g1 = build(edges1)
        g2 = build(edges2)

        cnt1 = [dfs_count(g1, v, -1, k) for v in range(n)]
        max_cnt2 = max(dfs_count(g2, u, -1, k-1) for u in range(m)) if k >= 1 else 0

        return [c + max_cnt2 for c in cnt1]
```

## 复杂度分析

- 时间复杂度：O(n^2 + m^2)，对每个节点 BFS/DFS
- 空间复杂度：O(n + m)

## 关键点总结

1. 连接一条边后，树2中的节点距离 = 树2内距离 + 1（连接边）
2. 最优连接：选树2中"k-1 距离内节点数最多"的节点
3. 对每个树1节点独立计算答案

## 易错点

1. 连接边消耗 1 步，所以树2中用 k-1 距离
2. k=0 时，只能到达自身（1个节点），不能连接树2
3. 节点编号从 0 开始
