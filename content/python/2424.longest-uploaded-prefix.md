## 题目描述

给你一个 `n` 个视频的上传平台，视频编号从 `1` 到 `n`。每个视频上传之后，该视频 ID 会进入一个 **待上传** 队列。当一个新视频的前缀（即编号 `1` 到 `i` 的所有视频）都已上传，则认为前缀长度 `i` 的前缀是**已上传的**。

实现类 `LUPrefix`：
- `LUPrefix(int n)`：初始化，共有 `n` 个视频。
- `void upload(int video)`：上传视频编号 `video`。
- `int longest()`：返回当前最长的已上传前缀的长度。

**示例：**
```
输入：
["LUPrefix", "upload", "longest", "upload", "longest", "upload", "longest"]
[[4], [3], [], [1], [], [2], []]
输出：[null, null, 0, null, 1, null, 3]
```

## 解题思路

维护一个变量 `prefix` 表示当前最长已上传前缀的长度。

- 每次上传视频时，记录该视频已上传
- 检查是否能延伸 `prefix`：若 `prefix + 1` 的视频也已上传，则 `prefix` 加一，继续检查

**方法一（集合 + 逐步推进）：**
- 用 `uploaded` 集合记录已上传的视频
- 每次 upload 后，从 `prefix + 1` 开始向上检查，更新 `prefix`

**方法二（并查集）：**
- 将已上传视频与其右侧相邻的已上传视频合并
- `longest` 就是包含 1 的连通分量的最大值

## 代码实现

### 方法一：集合 + 维护前缀（推荐）

```python
class LUPrefix:
    def __init__(self, n: int):
        self.uploaded = set()
        self.prefix = 0  # 当前最长已上传前缀

    def upload(self, video: int) -> None:
        self.uploaded.add(video)
        # 尝试延伸前缀
        while self.prefix + 1 in self.uploaded:
            self.prefix += 1

    def longest(self) -> int:
        return self.prefix
```

### 方法二：布尔数组（更高效的空间）

```python
class LUPrefix:
    def __init__(self, n: int):
        self.done = [False] * (n + 2)  # 下标 1 到 n
        self.prefix = 0

    def upload(self, video: int) -> None:
        self.done[video] = True
        # 尝试向右延伸已上传前缀
        while self.done[self.prefix + 1]:
            self.prefix += 1

    def longest(self) -> int:
        return self.prefix
```

## 复杂度分析

| 操作 | 时间复杂度（均摊）| 空间复杂度 |
|------|-----------|-----------|
| upload | O(1) 均摊 | - |
| longest | O(1) | - |
| 总空间 | - | O(n) |

`prefix` 单调递增到 n，while 循环总共最多执行 n 次，均摊 O(1)。

## 关键点总结

1. 维护一个「最长已上传前缀」变量，只需在 upload 时尝试延伸
2. `while self.prefix + 1 in uploaded` 的均摊代价很低
3. 用布尔数组代替集合，查询 O(1) 且常数更小

## 易错点

- 视频编号从 1 开始，不是 0，布尔数组大小需要 n+1 或 n+2
- `prefix` 只能递增，不会递减
