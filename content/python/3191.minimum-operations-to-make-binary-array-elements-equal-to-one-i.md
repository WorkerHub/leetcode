## 题目描述

给你一个二进制数组 `nums`。

每次操作可以翻转三个连续元素（将 0 变 1，1 变 0）。

返回使所有元素都变为 1 所需的 **最少** 操作次数，如果无法完成则返回 -1。

**示例 1：**
```
输入：nums = [0,1,1,1,0,0]
输出：3
```

**示例 2：**
```
输入：nums = [0,1,1,1]
输出：-1
```

**提示：**
- `3 <= nums.length <= 10^5`

## 解题思路

贪心：从左到右扫描，遇到 0 时立即翻转 [i, i+1, i+2]，这是消除当前 0 的唯一选择（不能影响左侧已处理的部分）。

使用差分数组（或队列）记录翻转效果，避免实际修改数组。

## Python 代码实现

### 方法一：贪心 + 差分（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0
        flips = deque()  # 记录翻转操作的右端点

        for i in range(n):
            # 移除已过期的翻转操作
            while flips and flips[0] < i:
                flips.popleft()

            # 当前值（考虑翻转次数的奇偶性）
            cur = nums[i] ^ (len(flips) % 2)

            if cur == 0:
                if i + 2 >= n:
                    return -1  # 无法翻转（越界）
                ops += 1
                flips.append(i + 2)  # 翻转 [i, i+1, i+2]

        return ops
```

### 方法二：直接修改数组

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0
        a = nums[:]

        for i in range(n - 2):
            if a[i] == 0:
                a[i] ^= 1
                a[i + 1] ^= 1
                a[i + 2] ^= 1
                ops += 1

        return ops if all(x == 1 for x in a) else -1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（差分方法）或 O(1)（直接修改）

## 关键点总结

1. 贪心：从左到右，遇到 0 立即翻转以当前位为起点的三个元素
2. 差分记录翻转效果，避免重复修改
3. 若最后两个元素之一为 0 则无解

## 易错点

1. 最后两个位置（i+2 >= n）无法翻转，直接返回 -1
2. 需要考虑之前翻转对当前元素的影响
