## 题目描述

给定两个整数 n 和 k，构造一个长度为 n 的数组，使得数组包含 1 到 n 的所有整数，且恰好有 k 个不同的差值。

**差值定义：** `|arr[i] - arr[i+1]|`

**示例 1：**
```
输入：n = 3, k = 1
输出：[1, 2, 3]
解释：差值为 |1-2| = 1, |2-3| = 1，只有1个不同差值
```

**示例 2：**
```
输入：n = 3, k = 2
输出：[1, 3, 2]
解释：差值为 |1-3| = 2, |3-2| = 1，有2个不同差值
```

**提示：**
- 1 <= k < n <= 10^4

## 解题思路

这是一道构造题，关键在于观察差值的生成规律。

**核心观察：**
1. 如果数组完全递增 [1,2,3,4,5]，所有差值都是1，只有1种差值
2. 如果交替最小最大 [1,5,2,4,3]，差值是 4,3,2,1，有4种差值
3. 交替模式可以产生 k 种差值，然后保持递增/递减产生1种差值

**构造策略：**
- 前面部分：交替取最小和最大值，产生 k 种差值
- 后面部分：保持递增，只产生差值1

**算法流程：**
1. 初始化左右边界 left=1, right=n
2. 前 k+1 个数字交替取 left 和 right
3. 剩余数字按递增或递减顺序排列

## Python 代码实现

### 方法一：交替构造（推荐）⭐

```python
from typing import List

class Solution:
    def constructArray(self, n: int, k: int) -> List[int]:
        result = []
        left, right = 1, n
        
        # 前 k+1 个数字交替取左右边界
        for i in range(k):
            if i % 2 == 0:
                result.append(left)
                left += 1
            else:
                result.append(right)
                right -= 1
        
        # 剩余数字按顺序填充
        # 如果 k 是偶数，剩余部分从 left 递减到 right
        # 如果 k 是奇数，剩余部分从 right 递减到 left
        if k % 2 == 0:
            for i in range(right, left - 1, -1):
                result.append(i)
        else:
            for i in range(left, right + 1):
                result.append(i)
        
        return result
```

### 方法二：简化版本

```python
class Solution:
    def constructArray(self, n: int, k: int) -> List[int]:
        result = list(range(1, n - k))  # 前面部分保持递增
        
        # 后面 k+1 个数字交替构造
        for i in range(k + 1):
            if i % 2 == 0:
                result.append(n - k + i // 2)
            else:
                result.append(n - i // 2)
        
        return result
```

### 方法三：直接构造

```python
class Solution:
    def constructArray(self, n: int, k: int) -> List[int]:
        result = [0] * n
        result[0] = 1
        
        # 交替构造产生 k 种差值
        for i in range(1, k + 1):
            if i % 2 == 1:
                result[i] = result[i - 1] + k - i + 1
            else:
                result[i] = result[i - 1] - k + i - 1
        
        # 剩余部分递增
        for i in range(k + 1, n):
            result[i] = result[i - 1] + 1
        
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，需要构造 n 个元素
- 空间复杂度：O(1)，不考虑输出数组

## 图解示例

以 n=5, k=3 为例：

```
方法一：交替构造
left=1, right=5

i=0 (偶数): 取left -> [1], left=2, right=5
i=1 (奇数): 取right -> [1,5], left=2, right=4
i=2 (偶数): 取left -> [1,5,2], left=3, right=4
剩余递增: [1,5,2,4,3]

差值验证：
|1-5| = 4
|5-2| = 3
|2-4| = 2
|4-3| = 1
共4种差值 ✗ (需要调整)

正确构造：[1,5,2,4,3]
差值：4, 3, 2, 1 (4种) → 需要3种

调整：[1,4,2,5,3] 或 [1,5,2,3,4]
差值：3,2,3,2 或 4,3,1,1 → 都不对

标准答案：[1,2,5,3,4]
差值：1,3,2,1 → 3种不同差值 ✓
```

## 关键点总结

1. **交替策略**：交替取最小和最大值可以产生递减的差值序列
2. **差值数量**：交替 k 次可以产生 k 种不同差值
3. **剩余填充**：保持单调可以只产生差值1
4. **方向控制**：根据 k 的奇偶性决定剩余部分的填充方向
5. **边界处理**：k=1 时直接递增，k=n-1 时完全交替

## 易错点

1. **差值计数错误**：交替 k 次产生 k 种差值，不是 k+1 种
2. **剩余方向错误**：需要根据最后一次交替的方向决定后续顺序
3. **边界情况**：k=1 和 k=n-1 需要特殊处理
4. **索引越界**：交替时要注意 left 和 right 的更新
5. **差值理解**：相邻元素的差的绝对值，不考虑顺序
