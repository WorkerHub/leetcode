## 题目描述

现有一个 `n x n` 大小的网格，机器人从位置 `(startRow, startColumn)` 出发。给你整数 `n` 和字符串 `s`，`s[i]` 是第 `i` 条指令（`'L'`、`'R'`、`'U'`、`'D'`）。

对于从第 `i` 条指令（0 索引）开始的后缀指令，计算机器人能执行多少条指令（直到越界为止）。

返回长度为 `s.length` 的数组 `answer`，`answer[i]` 表示从第 `i` 条指令开始能执行的指令数。

**示例：**
```
输入：n = 3, startPos = [0,1], s = "RRDDLL"
输出：[1,5,4,3,1,0]
解释：
- i=0：从(0,1)执行R->越界（0,2是合法的但再执行R就越界），执行1条
- i=1：从(0,1)执行RDDLL，执行5条（不越界）
```

**提示：**
- `m == s.length`
- `1 <= n, m <= 500`
- `startPos.length == 2`
- `0 <= startPos[0], startPos[1] < n`
- `s` 仅含 `'L'`、`'R'`、`'U'`、`'D'`

## 解题思路

**直接模拟**

由于 m <= 500，对每个起点 i，从 (startRow, startColumn) 出发执行 `s[i:]`，记录能执行的步数，时间复杂度 O(m^2) 完全可接受。

方向映射：`'L'` 列-1，`'R'` 列+1，`'U'` 行-1，`'D'` 行+1。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def executeInstructions(self, n: int, startPos: List[int], s: str) -> List[int]:
        m = len(s)
        # 方向映射
        delta = {'L': (0, -1), 'R': (0, 1), 'U': (-1, 0), 'D': (1, 0)}
        answer = []

        for i in range(m):
            r, c = startPos[0], startPos[1]
            count = 0
            for j in range(i, m):
                dr, dc = delta[s[j]]
                r += dr
                c += dc
                # 检查是否越界
                if 0 <= r < n and 0 <= c < n:
                    count += 1
                else:
                    break
            answer.append(count)

        return answer
```

### 方法二：模拟（更清晰版本）

```python
from typing import List

class Solution:
    def executeInstructions(self, n: int, startPos: List[int], s: str) -> List[int]:
        m = len(s)
        move = {'L': (0, -1), 'R': (0, 1), 'U': (-1, 0), 'D': (1, 0)}
        result = [0] * m

        for start in range(m):
            row, col = startPos
            for k in range(start, m):
                dr, dc = move[s[k]]
                row += dr
                col += dc
                if row < 0 or row >= n or col < 0 or col >= n:
                    break
                result[start] += 1
            # 若从未越界，count 已在循环中累加

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力模拟 | O(m^2) | O(m) |

m <= 500，O(m^2) = 25 万次操作，完全可接受。

## 关键点总结

1. 对每个起点 i 独立模拟，总复杂度 O(m^2)。
2. 方向用字典映射，代码简洁。
3. 一旦越界立即 break，不需要继续执行后续指令。

## 易错点

- 每个起点 i 需要重置机器人位置为 `startPos`。
- 越界判断：`r < 0 or r >= n or c < 0 or c >= n`，是 `n` 不是 `n-1`。
