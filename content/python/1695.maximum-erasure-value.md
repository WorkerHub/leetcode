## 题目描述

给你一个正整数数组 `nums`，请你从中擦除一个子数组，使得剩余元素的**乘积**...

不，实际上：给你一个正整数数组 `nums`，请你擦除一个子数组，并获得**该子数组所有元素之和**。

限制：擦除的子数组中的所有元素**必须是不同的**（即没有重复元素）。

返回你能获得的**最大得分**（最大子数组和，要求元素各不相同）。

**示例 1：**
```
输入：nums = [4,2,4,5,6]
输出：17
解释：最优子数组是 [2,4,5,6]，其和为 17
```

**示例 2：**
```
输入：nums = [5,2,1,2,5,2,1,2,5]
输出：8
解释：最优子数组是 [5,2,1] 或 [1,2,5]，其和为 8
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

## 解题思路

使用**滑动窗口**（双指针）维护一个无重复元素的窗口，同时维护窗口内的元素和。

- 右指针 `r` 不断向右移动，将 `nums[r]` 加入窗口
- 若 `nums[r]` 已经在窗口中，则移动左指针 `l` 直到窗口中没有 `nums[r]`
- 每次更新最大和

用哈希集合记录窗口中的元素，用变量维护当前窗口的元素和。

## 代码实现

### 方法一：滑动窗口 + 哈希集合（推荐）

```python
from typing import List

class Solution:
    def maximumUniqueSubarray(self, nums: List[int]) -> int:
        seen = set()  # 窗口中的元素集合
        window_sum = 0  # 当前窗口的元素和
        max_sum = 0
        l = 0  # 窗口左指针

        for r in range(len(nums)):
            # 如果 nums[r] 已在窗口中，缩小左边界
            while nums[r] in seen:
                seen.remove(nums[l])
                window_sum -= nums[l]
                l += 1
            # 将 nums[r] 加入窗口
            seen.add(nums[r])
            window_sum += nums[r]
            max_sum = max(max_sum, window_sum)

        return max_sum
```

### 方法二：滑动窗口 + 哈希字典（记录元素位置，跳跃移动）

```python
from typing import List

class Solution:
    def maximumUniqueSubarray(self, nums: List[int]) -> int:
        # 记录每个元素最近出现的位置
        last_pos = {}
        window_sum = 0
        max_sum = 0
        l = 0
        # 前缀和，方便计算窗口和
        prefix = [0] * (len(nums) + 1)
        for i, x in enumerate(nums):
            prefix[i + 1] = prefix[i] + x

        for r, x in enumerate(nums):
            if x in last_pos and last_pos[x] >= l:
                # 左指针跳过重复元素（直接跳到上次出现位置的下一位）
                # 需要更新 window_sum，用前缀和重新计算
                l = last_pos[x] + 1
            last_pos[x] = r
            # 窗口和 = prefix[r+1] - prefix[l]
            window_sum = prefix[r + 1] - prefix[l]
            max_sum = max(max_sum, window_sum)

        return max_sum
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，左右指针各移动最多 n 次
- 空间复杂度：O(n)，哈希集合大小

**方法二：**
- 时间复杂度：O(n)，每个元素只访问一次
- 空间复杂度：O(n)，哈希字典和前缀和数组

## 关键点总结

1. 滑动窗口维护无重复元素的最优区间
2. 方法一：遇到重复就逐步缩小左边界
3. 方法二：记录上次出现位置，直接跳过，配合前缀和快速计算区间和
4. 时间复杂度均为 O(n)

## 易错点

1. 方法二中 `last_pos[x] >= l` 的判断很关键：元素上次出现的位置必须在当前窗口内才需要移动左指针
2. 方法一中 while 循环的每次迭代都要更新 `window_sum`
