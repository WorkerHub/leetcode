## 题目描述

如果二叉树的深度小于 5，可以用一个由三位整数组成的数组来表示。

对于每个整数：
- 百位数表示节点的深度 D，1 <= D <= 4
- 十位数表示节点在当前层的位置 P，1 <= P <= 8，位置从左到右编号
- 个位数表示节点的值 V，0 <= V <= 9

给定一个包含三位整数的升序数组 nums，返回其表示的二叉树中从根到所有叶子节点的路径和。

**示例 1：**
```
输入：nums = [113, 215, 221]
输出：12
解释：
树的形状如下：
    3
   / \
  5   1

路径和 = (3 + 5) + (3 + 1) = 16
```

**示例 2：**
```
输入：nums = [113, 221]
输出：4
解释：
树的形状如下：
    3
     \
      1

路径和 = (3 + 1) = 4
```

**提示：**
- 1 <= nums.length <= 15
- 110 <= nums[i] <= 489
- nums 是一个升序数组

## 解题思路

这道题的关键是理解编码规则，并识别叶子节点。

**核心思想：**
1. 使用哈希表存储每个节点的信息（深度-位置 -> 值）
2. 通过 DFS 遍历所有路径
3. 叶子节点的判断：没有左右子节点的节点

**节点关系：**
- 对于节点 (depth, pos)
- 左子节点：(depth+1, 2*pos-1)
- 右子节点：(depth+1, 2*pos)

**算法流程：**
1. 解析数组，建立哈希表
2. 从根节点开始 DFS
3. 遇到叶子节点时累加路径和
4. 返回总和

## Python 代码实现

### 方法一：DFS + 哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def pathSum(self, nums: List[int]) -> int:
        # 构建哈希表：(depth, position) -> value
        tree = {}
        for num in nums:
            depth = num // 100
            pos = (num // 10) % 10
            val = num % 10
            tree[(depth, pos)] = val
        
        self.total = 0
        
        def dfs(depth: int, pos: int, current_sum: int):
            """DFS遍历，累加路径和"""
            # 当前节点值
            current_sum += tree[(depth, pos)]
            
            # 计算左右子节点的坐标
            left = (depth + 1, 2 * pos - 1)
            right = (depth + 1, 2 * pos)
            
            # 检查是否为叶子节点
            has_left = left in tree
            has_right = right in tree
            
            if not has_left and not has_right:
                # 叶子节点，累加路径和
                self.total += current_sum
                return
            
            # 递归遍历子节点
            if has_left:
                dfs(left[0], left[1], current_sum)
            if has_right:
                dfs(right[0], right[1], current_sum)
        
        # 从根节点开始（深度1，位置1）
        dfs(1, 1, 0)
        return self.total
```

### 方法二：迭代方式

```python
class Solution:
    def pathSum(self, nums: List[int]) -> int:
        # 构建哈希表
        tree = {}
        for num in nums:
            key = num // 10  # 深度和位置
            val = num % 10
            tree[key] = val
        
        # 使用栈进行迭代：(key, path_sum)
        stack = [(11, tree[11])]  # 根节点
        total = 0
        
        while stack:
            key, path_sum = stack.pop()
            depth = key // 10
            pos = key % 10
            
            # 计算子节点的key
            left_key = (depth + 1) * 10 + 2 * pos - 1
            right_key = (depth + 1) * 10 + 2 * pos
            
            # 检查是否为叶子节点
            if left_key not in tree and right_key not in tree:
                total += path_sum
            
            # 将子节点加入栈
            if left_key in tree:
                stack.append((left_key, path_sum + tree[left_key]))
            if right_key in tree:
                stack.append((right_key, path_sum + tree[right_key]))
        
        return total
```

## 复杂度分析

**方法一：DFS**
- 时间复杂度：O(n)，其中 n 是数组长度，每个节点访问一次
- 空间复杂度：O(n)，哈希表存储和递归栈空间

**方法二：迭代**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **编码规则理解**：正确解析三位数的深度、位置、值
2. **节点关系**：左子节点 (d+1, 2p-1)，右子节点 (d+1, 2p)
3. **叶子判断**：没有子节点的节点才累加路径和
4. **哈希表优化**：快速查找节点是否存在
5. **根节点坐标**：(1, 1) 对应 key = 11

## 易错点

1. **错误累加**：在每个节点都累加，而不是只在叶子节点累加
2. **节点关系计算错误**：位置编号从1开始，不是从0开始
3. **编码解析错误**：需要用整除和取模正确分解三位数
4. **根节点识别**：根节点总是 (1, 1)
5. **边界情况**：只有根节点时也要返回其值
