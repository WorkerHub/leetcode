## 题目描述

你有一个整数数组 `power`，其中 `power[i]` 是第 `i` 个怪物的力量值。

你从第 `0` 天开始，每天获得 `1` 点魔法，每天可以消耗 `power[i]` 点魔法来杀死第 `i` 个怪物。你还有一个增益 `gain`，初始值为 `1`，每杀死一个怪物，`gain` 的值增加 `1`，从下一天开始每天获得 `gain` 点魔法（而不是 `1` 点）。

返回杀死所有怪物所需的 **最少** 天数。

**示例 1：**
```
输入：power = [3,1,4]
输出：4
解释：最优顺序是先杀第 2 个（需要 1 天），再杀第 1 个（gain=2，需要 ceil(3/2)=2 天），最后杀第 3 个（gain=3，需要 ceil(4/3)=2 天），总计 1+2+2=5 天。
等等，让我重新算...
```

**提示：**
- `1 <= power.length <= 17`
- `1 <= power[i] <= 10^9`

## 解题思路

**状态压缩动态规划**：怪物数量最多 17 个，可以用一个整数的二进制位表示哪些怪物已被杀死。

**状态定义：** `dp[mask]` 表示已杀死 `mask` 中对应怪物所用的最少天数。

**转移方程：**
- 设 `mask` 中已有 `k` 个怪物被杀死，则当前 `gain = k + 1`
- 对每个未被杀死的怪物 `i`，计算加入后的天数：`dp[mask | (1 << i)] = min(dp[mask] + ceil(power[i] / gain))`

**初始条件：** `dp[0] = 0`（未杀死任何怪物，用 0 天）

**最终答案：** `dp[(1 << n) - 1]`（所有怪物都被杀死时的最少天数）

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
import math

class Solution:
    def minimumTime(self, power: List[int]) -> int:
        n = len(power)
        total = 1 << n  # 总状态数 2^n
        # dp[mask] = 杀死 mask 中所有怪物所需最少天数
        dp = [float('inf')] * total
        dp[0] = 0

        for mask in range(total):
            # 当前已杀死的怪物数量，即当前 gain 为 k+1
            k = bin(mask).count('1')
            gain = k + 1

            for i in range(n):
                if mask >> i & 1:
                    # 第 i 个怪物已被杀死，跳过
                    continue
                # 尝试下一个杀死第 i 个怪物
                new_mask = mask | (1 << i)
                # 需要 ceil(power[i] / gain) 天
                days = math.ceil(power[i] / gain)
                dp[new_mask] = min(dp[new_mask], dp[mask] + days)

        return dp[total - 1]
```

### 方法二：状态压缩 DP（位运算优化）

```python
from typing import List

class Solution:
    def minimumTime(self, power: List[int]) -> int:
        n = len(power)
        total = 1 << n
        dp = [float('inf')] * total
        dp[0] = 0

        for mask in range(total):
            if dp[mask] == float('inf'):
                continue
            # 已杀死怪物数量，位运算求 popcount
            k = bin(mask).count('1')
            gain = k + 1

            # 枚举未杀死的怪物（通过枚举 mask 的补集中的位）
            rest = ((1 << n) - 1) ^ mask  # 未杀死的怪物集合
            j = rest
            while j:
                # 取最低位的 1，即下一个未杀死的怪物
                lsb = j & (-j)
                i = lsb.bit_length() - 1  # 怪物编号
                new_mask = mask | lsb
                # 向上取整：(power[i] + gain - 1) // gain
                days = (power[i] + gain - 1) // gain
                if dp[mask] + days < dp[new_mask]:
                    dp[new_mask] = dp[mask] + days
                j ^= lsb  # 移除最低位

        return dp[total - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 状态压缩 DP | O(2^n * n) | O(2^n) |

n <= 17，所以 2^17 * 17 = 约 200 万次操作，完全可以接受。

## 关键点总结

1. 用整数二进制位表示怪物被杀死的状态（状态压缩）
2. `gain = popcount(mask) + 1`，即已杀死数量加一
3. 天数向上取整：`math.ceil(power[i] / gain)` 或 `(power[i] + gain - 1) // gain`
4. 遍历所有状态，枚举下一个要杀的怪物

## 易错点

- `gain` 是当前已杀死数量加一，不是下一步杀完后的 gain
- 不要漏掉 `dp[mask] == inf` 的剪枝，否则会更新无效状态
