## 题目描述

给你一个 **有向无环图**，`n` 个节点（编号 0 到 n-1）和 `edges` 数组。

找到最小的顶点集合，使得从这些顶点出发可以到达所有节点。

**示例 1：**
```
输入：n = 6, edges = [[0,1],[0,2],[2,5],[3,4],[4,2]]
输出：[0,3]
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= edges.length <= min(10^5, n*(n-1)/2)`

## 解题思路

### 关键观察

在有向无环图中，**没有入边的节点**必须包含在答案集中（因为它们无法从其他节点到达）。

有入边的节点可以通过其他节点到达，不需要加入答案集。

所以答案就是所有**入度为 0** 的节点集合。

## 代码实现

### 方法一：统计入度（推荐）

```python
from typing import List

class Solution:
    def findSmallestSetOfVertices(self, n: int, edges: List[List[int]]) -> List[int]:
        # 统计每个节点的入度
        in_degree = [0] * n
        for _, v in edges:
            in_degree[v] += 1
        # 返回所有入度为 0 的节点
        return [i for i in range(n) if in_degree[i] == 0]
```

### 方法二：使用集合

```python
from typing import List

class Solution:
    def findSmallestSetOfVertices(self, n: int, edges: List[List[int]]) -> List[int]:
        # 所有有入边的节点（能被到达的节点）
        has_incoming = set(v for _, v in edges)
        # 没有入边的节点必须作为起点
        return [i for i in range(n) if i not in has_incoming]
```

### 方法三：一行写法

```python
from typing import List

class Solution:
    def findSmallestSetOfVertices(self, n: int, edges: List[List[int]]) -> List[int]:
        return list(set(range(n)) - {v for _, v in edges})
```

## 复杂度分析

- **时间复杂度**：O(E + N)，E 为边数，N 为节点数
- **空间复杂度**：O(N)

## 关键点总结

1. 有向无环图中，没有入边的节点无法被其他节点到达，必须作为起点
2. 有入边的节点可以从前驱节点到达，不需要作为起点
3. 直接统计哪些节点出现在 `edges` 的第二列（有入边），其余都是答案

## 易错点

- 不需要 DFS/BFS，只需判断入度
- 方法三的集合差运算很简洁，但需要确保顺序不重要（题目未要求排序）
