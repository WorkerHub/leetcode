## 题目描述

在由 2D 网格表示的校园里，有 `n` 名工人和 `m` 辆自行车，其中 `n <= m`。

每个工人和每辆自行车的位置都用一对整数 `[x, y]` 表示。

我们为每个工人分配一辆自行车，使得分配给每个工人的自行车与工人之间的**曼哈顿距离**最小化。

返回长度为 `n` 的数组 `answer`，其中 `answer[i]` 是第 `i` 个工人分配到的自行车的索引（从 0 开始）。如果有多个可行方案：
- 首先选择曼哈顿距离最小的
- 如果曼哈顿距离相同，选择工人索引最小的
- 如果工人索引相同，选择自行车索引最小的

两点 `p1` 和 `p2` 之间的**曼哈顿距离**为：`|p1.x - p2.x| + |p1.y - p2.y|`。

**示例 1：**
```
输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出：[1,0]
解释：
工人 0 到自行车 0 的距离为 3，到自行车 1 的距离为 6。
工人 1 到自行车 0 的距离为 1，到自行车 1 的距离为 2。
最优分配：工人 1 → 自行车 0（距离 1），工人 0 → 自行车 1（距离 6）。
```

**示例 2：**
```
输入：workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]]
输出：[0,2,1]
```

**提示：**
- `n == workers.length`
- `m == bikes.length`
- `1 <= n <= m <= 1000`
- `workers[i].length == bikes[j].length == 2`
- `0 <= workers[i][0], workers[i][1] < 1000`
- `0 <= bikes[j][0], bikes[j][1] < 1000`
- 所有工人和自行车的位置都不相同

## 解题思路

这道题的核心是**贪心策略**：按照题目要求的优先级依次分配自行车。

**关键观察：**
1. 需要考虑所有工人和自行车的配对
2. 按照距离、工人索引、自行车索引的优先级排序
3. 每个工人和自行车只能分配一次

**算法流程：**
1. 计算所有工人和自行车之间的距离
2. 按照 `(距离, 工人索引, 自行车索引)` 排序
3. 从小到大遍历，如果工人和自行车都未分配，则进行分配
4. 当所有工人都分配完毕时结束

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> List[int]:
        """
        时间复杂度：O(mn log(mn))
        空间复杂度：O(mn)
        """
        # 计算所有配对的距离
        distances = []
        for i, (wx, wy) in enumerate(workers):
            for j, (bx, by) in enumerate(bikes):
                dist = abs(wx - bx) + abs(wy - by)
                distances.append((dist, i, j))
        
        # 按照 (距离, 工人索引, 自行车索引) 排序
        distances.sort()
        
        # 分配
        result = [-1] * len(workers)
        used_bikes = set()
        assigned_count = 0
        
        for dist, worker, bike in distances:
            # 如果工人已分配或自行车已被使用，跳过
            if result[worker] != -1 or bike in used_bikes:
                continue
            
            # 分配自行车
            result[worker] = bike
            used_bikes.add(bike)
            assigned_count += 1
            
            # 所有工人都分配完毕
            if assigned_count == len(workers):
                break
        
        return result
```

### 方法二：桶排序优化

```python
from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> List[int]:
        """
        利用距离范围有限，使用桶排序优化
        时间复杂度：O(mn + max_dist)
        空间复杂度：O(mn)
        """
        # 曼哈顿距离的最大值为 1998（坐标范围 0-999）
        MAX_DIST = 2000
        buckets = [[] for _ in range(MAX_DIST)]
        
        # 将所有配对按距离放入桶中
        for i, (wx, wy) in enumerate(workers):
            for j, (bx, by) in enumerate(bikes):
                dist = abs(wx - bx) + abs(wy - by)
                buckets[dist].append((i, j))
        
        # 分配
        result = [-1] * len(workers)
        used_bikes = set()
        assigned_count = 0
        
        # 按距离从小到大遍历桶
        for dist in range(MAX_DIST):
            if not buckets[dist]:
                continue
            
            # 同一距离内按 (工人索引, 自行车索引) 排序
            buckets[dist].sort()
            
            for worker, bike in buckets[dist]:
                if result[worker] != -1 or bike in used_bikes:
                    continue
                
                result[worker] = bike
                used_bikes.add(bike)
                assigned_count += 1
                
                if assigned_count == len(workers):
                    return result
        
        return result
```

### 方法三：使用堆（优先队列）

```python
from typing import List
import heapq

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> List[int]:
        """
        使用最小堆存储所有配对
        时间复杂度：O(mn log(mn))
        空间复杂度：O(mn)
        """
        # 构建最小堆
        heap = []
        for i, (wx, wy) in enumerate(workers):
            for j, (bx, by) in enumerate(bikes):
                dist = abs(wx - bx) + abs(wy - by)
                heapq.heappush(heap, (dist, i, j))
        
        result = [-1] * len(workers)
        used_bikes = set()
        assigned_count = 0
        
        while heap and assigned_count < len(workers):
            dist, worker, bike = heapq.heappop(heap)
            
            if result[worker] != -1 or bike in used_bikes:
                continue
            
            result[worker] = bike
            used_bikes.add(bike)
            assigned_count += 1
        
        return result
```

## 复杂度分析

**方法一：排序 + 贪心**
- 时间复杂度：O(mn log(mn))，排序所有配对
- 空间复杂度：O(mn)，存储所有配对

**方法二：桶排序**
- 时间复杂度：O(mn + k)，k 是最大距离（2000）
- 空间复杂度：O(mn)
- 适用于距离范围有限的场景

**方法三：堆**
- 时间复杂度：O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. **贪心策略**：按照距离、工人索引、自行车索引的优先级排序
2. **去重检查**：确保每个工人和自行车只分配一次
3. **排序关键字**：三元组 `(距离, 工人索引, 自行车索引)` 自然满足优先级
4. **优化方法**：利用距离范围有限可以使用桶排序

## 易错点

1. **排序优先级**：必须严格按照距离 → 工人索引 → 自行车索引排序
2. **重复分配**：需要同时检查工人是否已分配和自行车是否已使用
3. **提前终止**：当所有工人都分配完毕时可以提前结束
4. **边界情况**：
   - 只有一个工人和一辆自行车
   - 所有距离相同时，按索引排序
