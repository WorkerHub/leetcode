## 题目描述

给你一个下标从 **0** 开始、长度为 `n` 的字符串 `num`，`num` 仅由数字组成。

如果对于每个 `0 <= i < n`，数字 `i` 在 `num` 中出现的次数等于 `num[i]`（转化为整数），则认为这个字符串是**自描述**的，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：num = "1210"
输出：true
解释：num[0] = '1'，数字 0 出现 1 次 ✓；num[1] = '2'，数字 1 出现 2 次 ✓；num[2] = '1'，数字 2 出现 1 次 ✓；num[3] = '0'，数字 3 出现 0 次 ✓
```

**示例 2：**
```
输入：num = "030"
输出：false
```

## 解题思路

统计 `num` 中每个数字的出现频次，然后逐位验证 `num[i]` 是否等于数字 `i` 的实际出现次数。

## 代码实现

### 方法一：Counter 统计（推荐）

```python
from collections import Counter

class Solution:
    def digitCount(self, num: str) -> bool:
        cnt = Counter(num)  # 统计每个字符出现次数
        for i, ch in enumerate(num):
            # num[i] 应等于数字 i 出现的次数
            expected = int(ch)
            actual = cnt.get(str(i), 0)
            if expected != actual:
                return False
        return True
```

### 方法二：数组统计

```python
class Solution:
    def digitCount(self, num: str) -> bool:
        # 统计 0-9 各数字出现次数
        freq = [0] * 10
        for ch in num:
            freq[int(ch)] += 1

        # 验证每位
        for i, ch in enumerate(num):
            if int(ch) != freq[i]:
                return False
        return True
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串两次。
- 空间复杂度：O(1)，数字只有 0-9 共 10 种。

## 关键点总结

1. 用 Counter 或长度为 10 的数组统计各数字频次。
2. 检验第 `i` 位：`int(num[i])` 应等于 `i` 在字符串中出现的次数。
3. 字符串长度至多为 10，因为只有 0-9 这些数字。

## 易错点

- 注意 `cnt.get(str(i), 0)` 而不是 `cnt[str(i)]`，防止 KeyError。
- `i` 是整数，转为字符串 `str(i)` 再查 Counter。
