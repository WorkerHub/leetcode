## 题目描述

一条铁路线有 `n + 1` 个车站，编号从 `0` 到 `n`。你从第 `0` 站出发，目标到达第 `n` 站。

有两种方式前进：
- **普通铁路（regular）**：从站 `i` 到站 `i+1` 的费用是 `regular[i]`。
- **快速铁路（express）**：在快速铁路上，从站 `i` 到站 `i+1` 费用是 `express[i]`，但进入快速铁路时需额外支付 `expressCost`。
- 可以随时从普通切换到快速（支付 `expressCost`），但从快速到普通免费。

返回一个长度为 `n` 的数组 `costs`，其中 `costs[i]` 表示从第 `0` 站到第 `i+1` 站的最小费用。

**提示：**
- `n == regular.length == express.length`
- `1 <= n <= 10^5`
- `1 <= regular[i], express[i], expressCost <= 10^5`

## 解题思路

**动态规划：**

设 `dp_r[i]`：到达第 `i` 站时在普通铁路上的最小花费。
设 `dp_e[i]`：到达第 `i` 站时在快速铁路上的最小花费。

转移：
- `dp_r[i+1] = min(dp_r[i] + regular[i], dp_e[i] + express[i])`（从普通到普通，或从快速转到普通）
- `dp_e[i+1] = min(dp_r[i] + expressCost + express[i], dp_e[i] + express[i])`（从普通切换到快速，或继续在快速上）

答案：`costs[i] = min(dp_r[i+1], dp_e[i+1])`。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minimumCosts(self, regular: List[int], express: List[int], expressCost: int) -> List[int]:
        n = len(regular)
        INF = float('inf')
        
        # dp_r：当前在普通铁路的最小费用
        # dp_e：当前在快速铁路的最小费用
        dp_r = 0
        dp_e = expressCost  # 初始在普通铁路，切换到快速需要支付 expressCost
        
        costs = []
        
        for i in range(n):
            # 到达 i+1 站
            new_r = min(dp_r + regular[i], dp_e + express[i])
            new_e = min(dp_r + expressCost + express[i], dp_e + express[i])
            dp_r, dp_e = new_r, new_e
            costs.append(min(dp_r, dp_e))
        
        return costs
```

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def minimumCosts(self, regular: List[int], express: List[int], expressCost: int) -> List[int]:
        n = len(regular)
        
        # 初始状态：在第 0 站
        # on_regular：在普通铁路的最小费用，初始 0
        # on_express：在快速铁路的最小费用，初始 expressCost（要切换进去）
        on_r = 0
        on_e = expressCost
        
        result = []
        
        for i in range(n):
            # 从普通铁路走到 i+1
            r_from_r = on_r + regular[i]
            # 从快速铁路走到普通（免费切换）
            r_from_e = on_e + express[i]
            
            # 从普通铁路切换到快速铁路后走到 i+1
            e_from_r = on_r + expressCost + express[i]
            # 继续在快速铁路
            e_from_e = on_e + express[i]
            
            on_r = min(r_from_r, r_from_e)
            on_e = min(e_from_r, e_from_e)
            
            # 到达 i+1 的最小费用（可以从两种铁路到达）
            result.append(min(on_r, on_e))
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n) | O(1)（不含输出数组） |

## 关键点总结

1. 维护两个 DP 状态：在普通铁路和在快速铁路的最小费用。
2. 每步更新时考虑从哪种铁路转移过来，取最小值。
3. 初始时在普通铁路花费 0，在快速铁路需要先支付 expressCost。

## 易错点

- 从快速铁路切换到普通铁路是免费的，但从普通切换到快速需要支付 `expressCost`。
- 答案是每一站的最小值，不只是最终站。
