## 题目描述

给定一个字符串 `s`，返回 `s` 的不同的非空子序列的个数。由于答案可能很大，请返回答案对 `10^9 + 7` 取模的结果。

字符串的子序列是经由原字符串删除一些（也可能不删除）字符但不改变剩余字符相对位置的一个新字符串。

例如，`"ace"` 是 `"abcde"` 的一个子序列，但 `"aec"` 不是。

**示例 1：**
```
输入：s = "abc"
输出：7
解释：7 个不同的子序列分别是 "a", "b", "c", "ab", "ac", "bc", 以及 "abc"。
```

**示例 2：**
```
输入：s = "aba"
输出：6
解释：6 个不同的子序列分别是 "a", "b", "ab", "ba", "aa", 以及 "aba"。
```

**示例 3：**
```
输入：s = "aaa"
输出：3
解释：3 个不同的子序列分别是 "a", "aa", 以及 "aaa"。
```

**提示：**
- `1 <= s.length <= 2000`
- `s` 仅由小写英文字母组成

## 解题思路

这是一道经典的动态规划问题，关键在于如何避免重复计数。

**核心思想：**
1. 使用动态规划思想，逐步累加每个位置能形成的不同子序列数量
2. 用一个数组 `last` 记录每个字符最后出现时对应的子序列数量
3. 当遇到字符 `c` 时：
   - 可以在所有已有的子序列后面加上 `c`，形成新的子序列
   - 也可以单独形成一个只包含 `c` 的子序列
   - 如果之前出现过 `c`，需要减去上次 `c` 贡献的数量（避免重复）

**算法流程：**
1. 维护 `dp` 表示当前所有不同子序列的总数
2. 维护数组 `last[26]` 记录每个字符上次出现时的贡献值
3. 遍历字符串，对每个字符：
   - 计算新增的子序列数：`new_count = dp + 1`
   - 如果该字符之前出现过，减去上次的贡献：`new_count -= last[c]`
   - 更新总数和该字符的贡献记录
4. 返回最终结果对 `10^9 + 7` 取模

**关键观察：**
- 每个新字符都可以接在所有已有子序列后面，数量翻倍加一
- 重复字符会导致重复子序列，需要减去上次的贡献

## Python 代码实现

### 方法一：动态规划 + 字符记录（推荐）

```python
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        
        # last[i] 记录字符 chr(ord('a') + i) 最后一次出现时的贡献值
        last = [0] * 26
        
        # dp 表示当前所有不同子序列的总数
        dp = 0
        
        for char in s:
            idx = ord(char) - ord('a')
            
            # 当前字符可以：
            # 1. 接在所有已有子序列后面，贡献 dp 个新子序列
            # 2. 单独形成一个子序列，贡献 1 个
            # 总共贡献 dp + 1 个
            new_count = dp + 1
            
            # 如果这个字符之前出现过，需要减去上次的贡献
            # 避免重复计数
            new_count = (new_count - last[idx]) % MOD
            
            # 更新 dp 和该字符的贡献记录
            dp = (dp + new_count) % MOD
            last[idx] = new_count
        
        return dp
```

### 方法二：简化版动态规划

```python
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10**9 + 7
        
        # end[c] 表示以字符 c 结尾的不同子序列数量
        end = {}
        
        for char in s:
            # 当前字符结尾的子序列数 = 所有子序列数 + 1（单个字符）
            end[char] = sum(end.values()) % MOD + 1
        
        # 总数是所有以不同字符结尾的子序列数之和
        return sum(end.values()) % MOD
```

### 方法三：优化版（一次遍历）

```python
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10**9 + 7
        
        # dp[i] 表示以字符 chr(ord('a') + i) 结尾的子序列数量
        dp = [0] * 26
        
        for char in s:
            idx = ord(char) - ord('a')
            # 以当前字符结尾的子序列数 = 所有子序列数 + 1
            dp[idx] = (sum(dp) + 1) % MOD
        
        return sum(dp) % MOD
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，其中 n 是字符串长度，只需遍历一次字符串
- 空间复杂度：O(26) = O(1)，只需要固定大小的数组记录26个字母

**方法二和方法三：**
- 时间复杂度：O(n × 26) = O(n)，每次计算 sum 需要 O(26)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. **动态规划思想**：逐步累加每个位置能形成的不同子序列数量
2. **去重策略**：记录每个字符上次的贡献值，遇到重复字符时减去避免重复计数
3. **状态转移**：`new_count = dp + 1 - last[c]`，表示当前字符带来的新增子序列数
4. **取模运算**：所有运算都需要对 `10^9 + 7` 取模，防止溢出
5. **字符映射**：使用 `ord(char) - ord('a')` 将字符映射到 0-25 的索引

## 易错点

1. **忘记取模**：每次计算都要取模，特别是减法运算后可能为负数
2. **重复计数**：没有正确处理重复字符导致的重复子序列
3. **初始化错误**：`last` 数组初始化为 0，`dp` 也初始化为 0
4. **减法取模**：Python 中 `(a - b) % MOD` 自动处理负数，但其他语言需注意
5. **空字符串**：题目要求非空子序列，不包含空字符串
