## 题目描述

给你一个由 **正** 整数组成的数组 `nums`。

你必须取出 `nums` 中的每个整数，**反转其中每个数字**，并将反转后得到的数字添加到数组的末尾。这一操作只针对 `nums` 中原有的整数执行。

返回结果数组中 **不同** 整数的数目。

**示例 1：**
```
输入：nums = [1,13,10,12,31]
输出：6
解释：nums 反转后为 [1,31,1,21,13]，合并后不同整数有 {1,10,12,13,21,31}，共 6 个。
```

**示例 2：**
```
输入：nums = [2,2,2]
输出：1
解释：反转后还是 2，合并后只有 {2}，共 1 个。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

将原数组中每个整数和其反转后的数字都加入集合中，返回集合大小。

**数字反转：** 将整数转换为字符串，反转后再转回整数（自动去掉前导零）。

## 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def countDistinctIntegers(self, nums: List[int]) -> int:
        seen = set()
        for x in nums:
            seen.add(x)
            seen.add(int(str(x)[::-1]))  # 加入反转后的数字
        return len(seen)
```

### 方法二：数学反转

```python
from typing import List

class Solution:
    def countDistinctIntegers(self, nums: List[int]) -> int:
        def reverse_num(x: int) -> int:
            """数学方法反转整数"""
            rev = 0
            while x > 0:
                rev = rev * 10 + x % 10
                x //= 10
            return rev

        seen = set(nums)
        for x in nums:
            seen.add(reverse_num(x))

        return len(seen)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希集合 | O(n * log(max_val)) | O(n) |

反转操作的时间与数字位数成正比，即 O(log(max_val))。

## 关键点总结

1. 将原数组和反转后的数字都放入集合，统计不同元素数
2. 字符串反转后转整数会自动去掉前导零（如 130 的反转是 31，不是 031）
3. 利用集合自动去重

## 易错点

- 反转后要去掉前导零（用 `int(str(x)[::-1])` 自动处理）
- 原数组中的重复数字只计一次（集合去重）
