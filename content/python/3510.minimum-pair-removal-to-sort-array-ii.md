## 题目描述

给定一个整数数组 `nums`。每次操作可以选择相邻两个元素，将它们替换为它们的和（删除一个，保留和）。求使数组变为非递减有序所需的最少操作次数。

本题与 3507 相同问题，但数据规模更大：`1 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`。

**示例 1：**

```
输入：nums = [5, 2, 3, 1]
输出：2
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

由于规模扩大，需要使用高效数据结构：

使用**有序集合（SortedList）+ 链表**模拟：
1. 用链表模拟数组，支持 O(1) 的相邻元素访问和 O(1) 的合并
2. 用有序集合（按值排序的逆序对优先队列）维护当前所有逆序相邻对
3. 每次取"最小逆序差"的相邻对合并（贪心），重新检查新的相邻关系

更简单的贪心：每次找到第一个逆序对（`nums[i] > nums[i+1]`）并合并。合并后重新检查周围的逆序关系。

用双向链表 + 优先队列（按逆序对的差值排序）实现高效操作。

## Python 代码实现

### 方法一：链表 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0

        # 用数组模拟双向链表
        val = list(nums)
        prev = list(range(-1, n - 1))  # prev[i] = i 的前驱
        next_ = list(range(1, n + 1))  # next_[i] = i 的后继，n 表示末尾
        next_[n - 1] = n  # 哨兵

        # 逆序对计数
        inv_count = 0
        # 有序集合存储所有逆序相邻对 (val[i], i)，按 val[i]+val[next_[i]] 的和升序
        # 实际用优先队列，存 (sum, i)，sum = val[i] + val[next[i]]
        import heapq
        heap = []
        removed = [False] * n

        for i in range(n - 1):
            if val[i] > val[i + 1]:
                inv_count += 1

        # 贪心：每次合并"和最小"的逆序对（减少后续影响）
        # 简化：直接模拟，找第一个逆序对
        ops = 0
        arr = list(nums)

        # 使用有序集合维护逆序对数
        # 当逆序对数为 0 时停止
        while True:
            # 检查是否有逆序对
            inv = 0
            for i in range(len(arr) - 1):
                if arr[i] > arr[i+1]:
                    inv += 1
            if inv == 0:
                break
            # 找第一个逆序对合并
            for i in range(len(arr) - 1):
                if arr[i] > arr[i+1]:
                    arr[i] = arr[i] + arr[i+1]
                    arr.pop(i+1)
                    ops += 1
                    break

        return ops
```

### 方法二：高效双向链表实现

```python
from typing import List
import heapq

class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        n = len(nums)
        # 双向链表节点
        val = list(map(float, nums))
        prv = list(range(-1, n - 1))
        nxt = list(range(1, n + 1))

        # 统计初始逆序对数
        inv = sum(1 for i in range(n - 1) if val[i] > val[i+1])

        # 堆：(和, 左节点索引)
        heap = []
        for i in range(n - 1):
            heapq.heappush(heap, (val[i] + val[i+1], i))

        deleted = [False] * n
        ops = 0

        while inv > 0:
            # 取堆顶（和最小的相邻对）
            s, i = heapq.heappop(heap)
            j = nxt[i]
            # 检查是否过期
            if deleted[i] or j >= n or deleted[j] or abs(val[i] + val[j] - s) > 1e-9:
                continue
            # 检查是否是逆序对
            if val[i] <= val[j]:
                continue

            # 合并 i 和 j
            merged = val[i] + val[j]
            # 更新逆序对计数
            # i 和 j 的逆序关系消失
            inv -= 1  # 原来 val[i] > val[j]

            # 检查 prv[i] 和 i 的关系变化
            pi = prv[i]
            if pi >= 0:
                if val[pi] > val[i] and val[pi] <= merged:
                    inv -= 1  # 原来逆序，现在不逆序
                elif val[pi] <= val[i] and val[pi] > merged:
                    inv += 1  # 原来不逆序，现在逆序

            # 检查 j 和 nxt[j] 的关系变化
            nj = nxt[j]
            if nj < n:
                if val[j] > val[nj] and merged <= val[nj]:
                    inv -= 1
                elif val[j] <= val[nj] and merged > val[nj]:
                    inv += 1

            val[i] = merged
            deleted[j] = True
            nxt[i] = nxt[j]
            if nxt[j] < n:
                prv[nxt[j]] = i

            # 新的相邻对入堆
            if pi >= 0:
                heapq.heappush(heap, (val[pi] + merged, pi))
            if nxt[i] < n:
                heapq.heappush(heap, (merged + val[nxt[i]], i))

            ops += 1

        return ops
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次操作 O(log n)，共 O(n) 次操作
- 空间复杂度：O(n)

## 关键点总结

1. 用双向链表模拟数组，合并操作 O(1)
2. 用最小堆维护待合并的相邻对，优先合并和最小的
3. 合并后更新相邻关系和逆序对计数
4. 逆序对数为 0 时停止

## 易错点

1. 堆中的元素可能因已删除而过期，需要验证
2. 合并后需要正确更新前后相邻节点的逆序关系
3. 浮点精度问题（可改用整数避免）
