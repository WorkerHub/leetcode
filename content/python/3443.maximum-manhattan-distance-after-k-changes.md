## 题目描述

给你一个字符串 `s`，只包含 `'N'`、`'S'`、`'E'`、`'W'` 四种方向字符，以及一个整数 `k`。

从原点出发，按字符串指令移动（N 向上，S 向下，E 向右，W 向左）。

你可以**改变** s 中最多 k 个字符（改为任意方向），以**最大化**移动过程中**任意时刻**的曼哈顿距离。

返回可以达到的最大曼哈顿距离。

**示例 1：**

```
输入：s = "NWSE", k = 1
输出：3
解释：将 'S' 改为 'N' 得 "NWNE"，过程中曼哈顿距离最大为 3
```

**示例 2：**

```
输入：s = "NSWWEW", k = 3
输出：6
```

**提示：**
- `1 <= s.length <= 10^5`
- `0 <= k <= s.length`
- `s` 只包含 'N', 'S', 'E', 'W'

## 解题思路

曼哈顿距离 = |x| + |y|，其中 x 是东西方向偏移，y 是南北方向偏移。

枚举目标方向组合（4种象限：NE, NW, SE, SW），对每种组合，在前缀 i 步内：
- 贪心地将与目标方向相反的字符改为目标方向

对于目标是 NE 象限：
- 在前 i 步中，改变 S 为 N，W 为 E（使 |x|+|y| 最大）
- 可改变 min(count_S + count_W, k) 次
- 曼哈顿距离 = (count_N - count_S + 2*changed_S) + (count_E - count_W + 2*changed_W)

枚举 4 种方向后，对每个前缀 i 计算最大距离。

## Python 代码实现

### 方法一：枚举方向组合（推荐）

```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        n = len(s)
        ans = 0

        # 枚举 4 种目标象限方向
        for d1, d2 in [('N', 'E'), ('N', 'W'), ('S', 'E'), ('S', 'W')]:
            # d1 和 d2 是我们想要的主方向
            # 对立方向
            op1 = {'N': 'S', 'S': 'N', 'E': 'W', 'W': 'E'}[d1]
            op2 = {'N': 'S', 'S': 'N', 'E': 'W', 'W': 'E'}[d2]

            cnt = {c: 0 for c in 'NSEW'}
            for i, c in enumerate(s):
                cnt[c] += 1

                # 当前方向统计
                # 可以改变 op1 -> d1，op2 -> d2，用 k 次改变
                # 改 op1 次数 + 改 op2 次数 <= k
                # 优先选能最大化距离的改变
                # 每次改变增加 2（从 -1 变 +1）

                # 可改变的数量
                change1 = min(cnt[op1], k)       # 改 op1 的数量
                change2 = min(cnt[op2], k - change1)  # 剩余 k 给 op2

                dist = (cnt[d1] - cnt[op1] + 2 * change1) + (cnt[d2] - cnt[op2] + 2 * change2)
                ans = max(ans, dist)

        return ans
```

### 方法二：前缀统计优化

```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        ans = 0

        for dirs in [('N', 'E'), ('N', 'W'), ('S', 'E'), ('S', 'W')]:
            d1, d2 = dirs
            op1 = 'S' if d1 == 'N' else 'N'
            op2 = 'W' if d2 == 'E' else 'E'

            c = {'N': 0, 'S': 0, 'E': 0, 'W': 0}

            for ch in s:
                c[ch] += 1
                # 最优：先改 op1，再改 op2
                ch1 = min(c[op1], k)
                ch2 = min(c[op2], k - ch1)
                dist = (c[d1] - c[op1] + 2 * ch1) + (c[d2] - c[op2] + 2 * ch2)
                ans = max(ans, dist)

        return ans
```

## 复杂度分析

- 时间复杂度：O(4 * n) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 曼哈顿距离 = |x| + |y|，分解为两个独立方向
2. 枚举 4 种象限，分别贪心地使用 k 次改变
3. 对每种象限，优先改与目标方向相反的字符

## 易错点

1. 改变次数分配：先把 k 次尽量用在第一方向，再用剩余给第二方向
2. 距离公式：改了 ch1 次 op1 后，d1 方向距离 = (cnt[d1] - cnt[op1] + 2*ch1)
   （op1 减少 ch1，d1 增加 ch1，净变化 +2*ch1）
3. 要枚举所有前缀（每步后更新最大值）
