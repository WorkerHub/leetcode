## 题目描述

给你一个无向图，有 `n` 个节点和一个整数 `threshold`，要求图中任意两个连通分量之间的边数不超过 `threshold`。

在满足约束的前提下，图中最多可以有多少条边？

**示例 1：**

```
输入：n = 5, threshold = 3
输出：6
解释：完全图C(5,2)=10条边，但需要满足连通分量约束
```

**提示：**

- `2 <= n <= 10^5`
- `0 <= threshold <= 10^4`

## 解题思路

**贪心构造**：

- 若 `threshold >= n-1`：可以构成完全图，共 `n*(n-1)/2` 条边
- 否则：每个连通分量最多有 `threshold + 1` 个节点，若分量有 `k` 个节点，最多有 `C(k, 2)` 条边

最大化边数：将 n 个节点分成若干组，每组大小 <= `threshold + 1`，每组内构成完全图。

最优分组：尽量让每组大小都等于 `threshold + 1`（边数最多）。

## Python 代码实现

### 方法一：贪心分组（推荐）

```python
class Solution:
    def maximumEdges(self, n: int, threshold: int) -> int:
        if threshold >= n - 1:
            return n * (n - 1) // 2

        # 每组最多 threshold+1 个节点
        group_size = threshold + 1
        full_groups = n // group_size
        remainder = n % group_size

        # 完整组的边数
        edges = full_groups * (group_size * (group_size - 1) // 2)
        # 余数组的边数
        edges += remainder * (remainder - 1) // 2

        return edges
```

### 方法二：数学分析

```python
class Solution:
    def maximumEdges(self, n: int, threshold: int) -> int:
        # 特殊情况
        if threshold == 0:
            return 0  # 每个节点独立，不能有边
        if threshold >= n - 1:
            return n * (n - 1) // 2

        k = threshold + 1
        q, r = divmod(n, k)
        return q * k * (k - 1) // 2 + r * (r - 1) // 2
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 每个连通分量最多 `threshold + 1` 个节点
2. 最优：尽量用最大组（充分利用 threshold）
3. 每组内构成完全图（边数最多）

## 易错点

1. `threshold = 0` 时每个节点独立，无边
2. `threshold >= n-1` 时可以构成全连通图
3. 完全图边数公式：`k*(k-1)/2`
