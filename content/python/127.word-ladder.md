## 题目描述

字典 `wordList` 中从单词 `beginWord` 到 `endWord` 的转换序列是一个按下述规格形成的序列 `beginWord -> s1 -> s2 -> ... -> sk`：

- 每一对相邻的单词只差一个字母
- 对于 `1 <= i <= k` 时，每个 `si` 都在 `wordList` 中。注意，`beginWord` 不需要在 `wordList` 中
- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord` 和一个字典 `wordList`，返回从 `beginWord` 到 `endWord` 的**最短转换序列**中的**单词数目**。如果不存在这样的转换序列，返回 `0`。

**示例 1：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出: 5
解释: 一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog", 返回它的长度 5。
```

**示例 2：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出: 0
解释: endWord "cog" 不在字典中，所以无法进行转换。
```

**提示：**
- `1 <= beginWord.length <= 10`
- `endWord.length == beginWord.length`
- `1 <= wordList.length <= 5000`
- `wordList[i].length == beginWord.length`
- `beginWord`、`endWord` 和 `wordList[i]` 由小写英文字母组成
- `beginWord != endWord`
- `wordList` 中的所有字符串互不相同

## 解题思路

这是一道典型的**无权图最短路径问题**，适合用 **BFS（广度优先搜索）** 解决。

### 核心思想：

1. **建图**：每个单词是一个节点，只差一个字母的两个单词之间有一条边
2. **BFS 搜索**：从 `beginWord` 开始，层层扩展，直到找到 `endWord`
3. **返回层数**：第一次遇到 `endWord` 时的层数就是最短路径长度

### 算法步骤：

1. 先检查 `endWord` 是否在字典中，不在则直接返回 0
2. 将 `beginWord` 加入队列，开始 BFS
3. 对于当前单词，尝试改变每个位置的字符（a-z），查看是否在字典中
4. 如果在字典中且未访问过，加入队列并标记为已访问
5. 如果遇到 `endWord`，返回当前步数
6. 如果队列为空还没找到，返回 0

### 优化技巧：

- **使用集合存储字典**：O(1) 时间查找
- **双向 BFS**：从两端同时搜索，减少搜索空间
- **预处理通配符模式**：建立中间状态映射，加速邻居查找

## Python 代码实现

### 方法一：BFS + 逐字符替换（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        # endWord 必须在字典中
        word_set = set(wordList)
        if endWord not in word_set:
            return 0
        
        # BFS 队列，存储 (当前单词, 步数)
        queue = deque([(beginWord, 1)])
        visited = {beginWord}
        
        while queue:
            current_word, steps = queue.popleft()
            
            # 尝试改变每个位置的字符
            for i in range(len(current_word)):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    # 构造新单词
                    next_word = current_word[:i] + c + current_word[i+1:]
                    
                    # 找到目标单词
                    if next_word == endWord:
                        return steps + 1
                    
                    # 新单词在字典中且未访问过
                    if next_word in word_set and next_word not in visited:
                        visited.add(next_word)
                        queue.append((next_word, steps + 1))
        
        return 0
```

### 方法二：双向 BFS（优化版）

```python
from typing import List

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        word_set = set(wordList)
        if endWord not in word_set:
            return 0
        
        # 双向 BFS 的两个集合
        begin_set = {beginWord}
        end_set = {endWord}
        visited = set()
        steps = 1
        word_len = len(beginWord)
        
        while begin_set and end_set:
            # 优化：总是从小的一端开始搜索
            if len(begin_set) > len(end_set):
                begin_set, end_set = end_set, begin_set
            
            # 下一层的单词集合
            next_set = set()
            
            for word in begin_set:
                for i in range(word_len):
                    for c in 'abcdefghijklmnopqrstuvwxyz':
                        next_word = word[:i] + c + word[i+1:]
                        
                        # 两端相遇
                        if next_word in end_set:
                            return steps + 1
                        
                        # 有效的未访问单词
                        if next_word in word_set and next_word not in visited:
                            visited.add(next_word)
                            next_set.add(next_word)
            
            # 移动到下一层
            begin_set = next_set
            steps += 1
        
        return 0
```

### 方法三：预处理通配符模式

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        if endWord not in wordList:
            return 0
        
        # 预处理：建立通配符模式到单词的映射
        # 例如: "hot" -> "*ot", "h*t", "ho*"
        pattern_dict = defaultdict(list)
        word_len = len(beginWord)
        
        for word in wordList:
            for i in range(word_len):
                pattern = word[:i] + '*' + word[i+1:]
                pattern_dict[pattern].append(word)
        
        # BFS
        queue = deque([(beginWord, 1)])
        visited = {beginWord}
        
        while queue:
            current_word, steps = queue.popleft()
            
            # 通过通配符模式找到所有邻居
            for i in range(word_len):
                pattern = current_word[:i] + '*' + current_word[i+1:]
                
                for next_word in pattern_dict[pattern]:
                    if next_word == endWord:
                        return steps + 1
                    
                    if next_word not in visited:
                        visited.add(next_word)
                        queue.append((next_word, steps + 1))
                
                # 避免重复访问同一模式
                pattern_dict[pattern] = []
        
        return 0
```

### 方法四：简化版（容易理解）

```python
from typing import List
from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        # 检查 endWord 是否在字典中
        word_set = set(wordList)
        if endWord not in word_set:
            return 0
        
        # 判断两个单词是否只差一个字母
        def is_adjacent(word1, word2):
            diff_count = 0
            for i in range(len(word1)):
                if word1[i] != word2[i]:
                    diff_count += 1
                    if diff_count > 1:
                        return False
            return diff_count == 1
        
        # BFS
        queue = deque([beginWord])
        visited = {beginWord}
        level = 1
        
        while queue:
            level_size = len(queue)
            
            for _ in range(level_size):
                current = queue.popleft()
                
                # 遍历字典中所有单词
                for word in list(word_set):
                    if is_adjacent(current, word):
                        if word == endWord:
                            return level + 1
                        
                        queue.append(word)
                        visited.add(word)
                        word_set.remove(word)  # 从字典中移除已访问的词
            
            level += 1
        
        return 0
```

## 复杂度分析

设单词长度为 L，字典大小为 N。

### 方法一：BFS + 逐字符替换
- **时间复杂度**：O(N * L * 26) = O(N * L)
  - 每个单词访问一次，每次尝试 L 个位置 * 26 个字母
- **空间复杂度**：O(N)，队列和访问集合

### 方法二：双向 BFS
- **时间复杂度**：O(N * L)，但实际运行更快
- **空间复杂度**：O(N)

### 方法三：预处理通配符
- **时间复杂度**：O(N * L^2)，预处理 O(N * L)，查询 O(L)
- **空间复杂度**：O(N * L)，存储模式映射

### 方法四：简化版
- **时间复杂度**：O(N^2 * L)，每个单词与所有其他单词比较
- **空间复杂度**：O(N)

## 关键点总结

1. **BFS 适合无权图最短路径**：每条边权重相同，BFS 第一次到达即最短
2. **使用集合优化查找**：`set` 提供 O(1) 的查找时间
3. **标记已访问避免重复**：防止循环和重复搜索
4. **双向 BFS 优化**：从两端搜索可显著减少搜索空间
5. **字符串构造技巧**：`word[:i] + c + word[i+1:]` 高效构造新单词

## 易错点

1. **忘记检查 endWord 是否在字典中**
   ```python
   # 必须先检查
   if endWord not in word_set:
       return 0
   ```

2. **返回值错误**
   ```python
   # 错误：返回步数而不是单词数
   return steps
   
   # 正确：返回单词数（步数 + 1）
   return steps + 1
   ```

3. **重复访问问题**
   ```python
   # 必须标记已访问，防止重复
   visited.add(next_word)
   ```

4. **字符串不可变性**
   ```python
   # Python 字符串不可变，不能直接修改
   # 错误：word[i] = c
   # 正确：word[:i] + c + word[i+1:]
   ```

5. **beginWord 不在字典中**：题目说明 beginWord 可以不在字典中，不需要检查
