## 题目描述

给你两个字符串 `s` 和 `t`，两者均为小写字母组成，且 `t` 是 `s` 的某个排列。

对于 `s` 中的每个字符，找到该字符在 `s` 和 `t` 中位置的绝对差值，将所有字符的绝对差值之和称为 **排列差**。

返回 `s` 和 `t` 的 **排列差**。

**示例 1：**
```
输入：s = "abc", t = "bac"
输出：2
解释：a: |0-1|=1, b: |1-0|=1, c: |2-2|=0, 总和 = 2
```

**示例 2：**
```
输入：s = "abcd", t = "cdab"
输出：8
```

**提示：**
- `1 <= s.length <= 26`
- `s` 的每个字符都不同
- `t` 是 `s` 的排列

## 解题思路

用哈希表记录每个字符在 `t` 中的位置，然后遍历 `s`，计算每个字符在 `s` 和 `t` 中位置的绝对差之和。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
class Solution:
    def findPermutationDifference(self, s: str, t: str) -> int:
        pos_t = {c: i for i, c in enumerate(t)}
        return sum(abs(i - pos_t[c]) for i, c in enumerate(s))
```

### 方法二：两个哈希表

```python
class Solution:
    def findPermutationDifference(self, s: str, t: str) -> int:
        pos_s = {c: i for i, c in enumerate(s)}
        pos_t = {c: i for i, c in enumerate(t)}
        return sum(abs(pos_s[c] - pos_t[c]) for c in s)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 用字典存储每个字符在 t 中的索引
2. 遍历 s，对每个字符计算位置差的绝对值并累加

## 易错点

1. 绝对值不能漏掉
2. 每个字符在 s 中唯一，直接用枚举索引
