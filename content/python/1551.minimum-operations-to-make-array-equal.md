## 题目描述

存在一个长度为 `n` 的数组 `arr`，其中 `arr[i] = (2 * i) + 1`（从 0 开始索引），即 `arr = [1, 3, 5, ..., 2n-1]`。

每次操作，选择两个下标 `i` 和 `j`，并令 `arr[i] -= 1`、`arr[j] += 1`，使 `arr[j]` 变为 `arr[i]`……

实际上，每次操作可以选两个相差 2 的相邻元素，将较大的减 1，较小的加 1，最终目标是让所有元素都等于 `n`。

返回最少操作次数。

**示例 1：**
```
输入：n = 3
输出：2
解释：arr = [1,3,5]，目标值 = 3，需要 2 次操作
```

**示例 2：**
```
输入：n = 6
输出：9
```

## 解题思路

### 数学公式

数组 `arr = [1, 3, 5, ..., 2n-1]`，目标是让所有元素等于平均值 `n`。

每次操作使一个元素加 1、另一个减 1，总和不变。操作次数等于将左半部分（小于 n 的元素）提升到 n 所需的总和。

**左半部分：** `arr[0..n/2-1]` 中的元素分别为 `1, 3, 5, ..., n-1`（若 n 为奇数，中间那个已经等于 n）

需要的增量总和 = `(n - 1) + (n - 3) + ... + 1`（若 n 为偶数）
= `n/2 * n/2`（等差数列求和）

一般公式：`ans = n^2 // 4`

## 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def minOperations(self, n: int) -> int:
        # 操作次数 = n^2 // 4（整数除法）
        return n * n // 4
```

### 方法二：模拟计算

```python
class Solution:
    def minOperations(self, n: int) -> int:
        # 构造数组，计算左半部分与 n 的差之和
        ans = 0
        for i in range(n // 2):
            val = 2 * i + 1  # arr[i]
            ans += n - val    # 每个左半元素需要增加的量
        return ans
```

### 方法三：等差数列求和

```python
class Solution:
    def minOperations(self, n: int) -> int:
        # 左半部分为 1, 3, 5, ..., n-1（共 n//2 项，n 为偶数时）
        # 差值为 n-1, n-3, ..., 1
        # 等差数列求和 = (首项 + 末项) * 项数 / 2 = (n-1 + 1) * (n//2) / 2 = n * n//2 / 2 = n^2/4
        half = n // 2
        return half * half
```

## 复杂度分析

- **时间复杂度**：O(1)（方法一/三）；O(N)（方法二）
- **空间复杂度**：O(1)

## 关键点总结

1. 数组平均值为 n，目标是所有元素变为 n
2. 操作次数 = 左半部分元素与 n 的差之和
3. 等差数列求和得到公式 `n^2 // 4`（`(n//2)^2`）

## 易错点

- `n * n // 4` 和 `(n // 2) ** 2` 在奇数时等价（奇数时 n//2 截断，结果相同）
