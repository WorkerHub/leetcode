## 题目描述

我们定义分割数组的方案是**好方案**，当且仅当将数组分成的三个连续子数组满足：
- 第一部分的元素和 <= 第二部分的元素和 <= 第三部分的元素和

给你一个**非负**整数数组 `nums`，请你返回将数组分割成**三个非空连续子数组**的好方案数目。

由于答案可能会很大，请你将结果对 `10^9 + 7` 取余后返回。

**示例：**
```
输入：nums = [1,1,1]
输出：1
```

**提示：**
- `3 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^4`

## 解题思路

用前缀和 + 二分查找。设三段为 `[0, i]`, `[i+1, j]`, `[j+1, n-1]`。

枚举第一段的结尾 `i`，对每个 `i`：
- 设 `s1 = prefix[i+1]`（第一段和）
- 第二段需满足：和 >= s1，且和 <= total - s1 - sum2（即剩余部分 >= sum2）
- 用二分找第二段结尾 `j` 的有效范围 `[j_min, j_max]`

## 代码实现

### 方法一：前缀和 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def waysToSplit(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        
        # 构建前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        total = prefix[n]
        ans = 0
        
        # 枚举第一段的结尾 i（0-indexed，第一段为 nums[0..i]）
        for i in range(n - 2):
            s1 = prefix[i + 1]
            # 剪枝：第一段太大，即使剩余两段相等也不满足
            if s1 * 3 > total:
                break
            
            # 第二段最小结尾 j：second_sum >= s1
            # prefix[j+1] - prefix[i+1] >= s1
            # prefix[j+1] >= s1 + prefix[i+1] = 2 * s1
            # 在 prefix 中二分找最小的 j+1 >= 2*s1
            j_min = bisect.bisect_left(prefix, 2 * s1, i + 2, n) - 1
            
            # 第二段最大结尾 j：third_sum >= second_sum
            # prefix[n] - prefix[j+1] >= prefix[j+1] - prefix[i+1]
            # 2 * prefix[j+1] <= total + prefix[i+1]
            # prefix[j+1] <= (total + prefix[i+1]) // 2
            # 找最大 j+1，使 prefix[j+1] <= (total + prefix[i+1]) // 2
            bound = (total + prefix[i + 1]) // 2
            j_max = bisect.bisect_right(prefix, bound, i + 2, n) - 1
            # j 最大不超过 n-2（第三段至少一个元素）
            j_max = min(j_max, n - 2)
            
            if j_min <= j_max:
                ans = (ans + j_max - j_min + 1) % MOD
        
        return ans
```

### 方法二：前缀和 + 双指针（O(n)）

```python
from typing import List

class Solution:
    def waysToSplit(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        total = prefix[n]
        ans = 0
        j_min = 0
        j_max = 0
        
        for i in range(n - 2):
            s1 = prefix[i + 1]
            if s1 * 3 > total:
                break
            
            # j_min 单调递增，用双指针
            j_min = max(j_min, i + 1)
            while j_min < n - 1 and prefix[j_min + 1] - s1 < s1:
                j_min += 1
            
            j_max = max(j_max, j_min)
            while j_max < n - 1 and 2 * (prefix[j_max + 1] - s1) <= total - s1:
                j_max += 1
            # 回退一步（不满足条件的那个j_max要减1）
            j_max_valid = j_max - (1 if 2 * (prefix[j_max + 1] - s1) > total - s1 else 0)
            
            if j_min <= j_max_valid:
                ans = (ans + j_max_valid - j_min + 1) % MOD
        
        return ans
```

## 复杂度分析

- **方法一**：时间 O(n log n)，空间 O(n)
- **方法二**：时间 O(n)，空间 O(n)

## 关键点总结

1. 枚举第一段结尾，用二分确定第二段结尾的合法范围
2. 前缀和预处理使区间和查询 O(1)
3. 注意各段至少包含一个元素

## 易错点

- 二分时注意 `prefix` 的索引范围（第二段 j+1 的范围是 `[i+2, n-1]`，第三段至少一个元素）
- 结果取模
