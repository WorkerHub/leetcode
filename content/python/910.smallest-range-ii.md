## 题目描述

给你一个整数数组 `nums`，和一个整数 `k`。

对于每个索引 `i`，其中 `0 <= i < nums.length`，将 `nums[i]` 变成 `nums[i] + k` 或 `nums[i] - k`。

`nums` 的 **分数** 是 `nums` 中最大和最小元素的差值。

在更改每个索引对应的值之后，返回 `nums` 的最小 **分数**。

**示例 1：**
```
输入：nums = [1], k = 0
输出：0
解释：分数是 max(nums) - min(nums) = 1 - 1 = 0。
```

**示例 2：**
```
输入：nums = [0,10], k = 2
输出：6
解释：将 nums 改为 [2,8]。分数是 max(nums) - min(nums) = 8 - 2 = 6。
```

**示例 3：**
```
输入：nums = [1,3,6], k = 3
输出：3
解释：将 nums 改为 [4,6,3]。分数是 max(nums) - min(nums) = 6 - 3 = 3。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^4`
- `0 <= k <= 10^4`

## 解题思路

这道题与 908 题不同，每个元素必须选择加 k 或减 k（不能选择其他值），这增加了难度。

**关键观察：**
1. 对数组排序后，最优解一定存在某个分界点，使得：
   - 分界点左边的元素都加 k
   - 分界点右边的元素都减 k
   （或者全部加 k，或者全部减 k）

2. **为什么排序后存在分界点？**
   - 假设排序后 `nums[i] < nums[j]`
   - 如果 `nums[i]` 减 k，`nums[j]` 加 k，差值会变得更大
   - 因此最优策略是：小的数字加 k，大的数字减 k
   - 存在某个分界点，左边加 k，右边减 k

3. **枚举策略：**
   - 对于每个可能的分界点 i：
     - `[0, i]` 加 k
     - `[i+1, n-1]` 减 k
   - 计算此时的最大值和最小值
   - 最大值可能是：`nums[i] + k` 或 `nums[n-1] - k`
   - 最小值可能是：`nums[0] + k` 或 `nums[i+1] - k`

## Python 代码实现

### 方法一：排序 + 枚举分界点（推荐 ⭐）

```python
from typing import List

class Solution:
    def smallestRangeII(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        
        # 初始情况：所有元素都加 k 或都减 k
        result = nums[-1] - nums[0]
        
        # 枚举分界点：[0, i] 加 k，[i+1, n-1] 减 k
        for i in range(n - 1):
            # 可能的最大值
            max_val = max(nums[i] + k, nums[-1] - k)
            # 可能的最小值
            min_val = min(nums[0] + k, nums[i + 1] - k)
            # 更新结果
            result = min(result, max_val - min_val)
        
        return result
```

### 方法二：详细说明版

```python
from typing import List

class Solution:
    def smallestRangeII(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        
        # 边界情况：只有一个元素
        if n == 1:
            return 0
        
        # 初始化：所有元素都进行相同操作（都加 k 或都减 k）
        # 此时差值不变
        result = nums[-1] - nums[0]
        
        # 枚举所有可能的分界点
        # 分界点 i 表示：[0, i] 加 k，[i+1, n-1] 减 k
        for i in range(n - 1):
            # 左边部分的最大值：nums[i] + k
            left_max = nums[i] + k
            # 右边部分的最小值：nums[i+1] - k
            right_min = nums[i + 1] - k
            
            # 整体的最大值
            # 可能来自左边的最大值，或右边的原最大值减 k
            max_val = max(left_max, nums[-1] - k)
            
            # 整体的最小值
            # 可能来自左边的原最小值加 k，或右边的最小值
            min_val = min(nums[0] + k, right_min)
            
            # 更新答案
            result = min(result, max_val - min_val)
        
        return result
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def smallestRangeII(self, nums: List[int], k: int) -> int:
        nums.sort()
        result = nums[-1] - nums[0]
        
        for i in range(len(nums) - 1):
            high = max(nums[i] + k, nums[-1] - k)
            low = min(nums[0] + k, nums[i + 1] - k)
            result = min(result, high - low)
        
        return result
```

## 复杂度分析

**时间复杂度：** O(n log n)
- 排序的时间复杂度是 O(n log n)
- 枚举分界点的时间复杂度是 O(n)
- 总体是 O(n log n)

**空间复杂度：** O(log n)
- 排序所需的栈空间（Python 的 Timsort）

## 图解示例

以 `nums = [1, 3, 6], k = 3` 为例：

```
排序后：[1, 3, 6]

分界点 0：[1] +3, [3, 6] -3
调整后：[4, 0, 3]
最大值 = max(4, 6-3) = max(4, 3) = 4
最小值 = min(1+3, 3-3) = min(4, 0) = 0
差值 = 4 - 0 = 4

分界点 1：[1, 3] +3, [6] -3
调整后：[4, 6, 3]
最大值 = max(3+3, 6-3) = max(6, 3) = 6
最小值 = min(1+3, 6-3) = min(4, 3) = 3
差值 = 6 - 3 = 3  ✓ 最优

全部加 k：[4, 6, 9]，差值 = 5
全部减 k：[-2, 0, 3]，差值 = 5
```

## 关键点总结

1. **排序的重要性**：排序后才能找到最优分界点
2. **贪心策略**：小的数加 k，大的数减 k
3. **分界点枚举**：尝试所有可能的分界点
4. **四个候选值**：最大值和最小值各有两个候选
   - 最大值：`nums[i] + k` 或 `nums[-1] - k`
   - 最小值：`nums[0] + k` 或 `nums[i+1] - k`
5. **初始化**：不要忘记考虑全部加 k 或全部减 k 的情况

## 易错点

1. **忘记排序**：必须先排序才能应用贪心策略
2. **分界点范围**：应该是 `[0, n-2]`，不是 `[0, n-1]`
3. **最大最小值**：要考虑所有可能的候选值
4. **初始值**：result 应该初始化为 `nums[-1] - nums[0]`（全部同向操作）
5. **边界情况**：单元素数组差值为 0
