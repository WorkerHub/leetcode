## 题目描述

给你一个字符串 `s`，请你返回**两个相同字符之间的最长子字符串**的长度，计算长度时**不含**这两个字符。

如果不存在这样的子字符串，返回 `-1`。

**示例：**
```
输入：s = "aa"
输出：0
解释：最优的子字符串是两个 'a' 之间的空字符串。

输入：s = "abca"
输出：2
解释：最优的子字符串是 "bc"。

输入：s = "cbzxy"
输出：-1
解释：没有相同的字符，返回 -1。
```

**提示：**
- `1 <= s.length <= 300`
- `s` 只包含小写英文字母

## 解题思路

用哈希表记录每个字符**第一次出现**的位置，遍历字符串时：
- 若当前字符已在哈希表中，计算两次出现位置之间的长度
- 否则将当前字符及其位置存入哈希表

## 代码实现

### 方法一：哈希表记录首次出现位置（推荐）

```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first_pos = {}  # 记录每个字符第一次出现的位置
        ans = -1
        
        for i, c in enumerate(s):
            if c in first_pos:
                # 两次出现之间的子串长度（不含两端）
                ans = max(ans, i - first_pos[c] - 1)
            else:
                first_pos[c] = i  # 记录首次出现位置
        
        return ans
```

### 方法二：数组代替哈希表

```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        # 用大小 26 的数组记录每个字母的首次出现位置
        first_pos = [-1] * 26
        ans = -1
        
        for i, c in enumerate(s):
            idx = ord(c) - ord('a')
            if first_pos[idx] != -1:
                ans = max(ans, i - first_pos[idx] - 1)
            else:
                first_pos[idx] = i
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(26) = O(1) |
| 数组 | O(n) | O(26) = O(1) |

## 关键点总结

1. 只需记录每个字符**第一次**出现的位置
2. 遇到重复字符时，长度 = `当前位置 - 首次位置 - 1`
3. 初始答案为 -1，若未找到重复字符则返回 -1
4. 字符只有 26 个小写字母，空间 O(1)

## 易错点

- 计算长度要减 1（不含两端字符本身）
- 遇到相同字符时**不更新**首次位置（保留最早的位置以最大化子串长度）
- 若没有重复字符，保持返回 -1
