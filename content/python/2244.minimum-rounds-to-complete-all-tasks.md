## 题目描述

给你一个下标从 0 开始的整数数组 `tasks`，其中 `tasks[i]` 表示任务的难度级别。每轮可以完成 **2 个或 3 个** 相同难度级别的任务。

返回完成所有任务所需的 **最少轮数**，如果无法完成，返回 `-1`。

**示例 1：**
```
输入：tasks = [2,2,3,3,2,4,4,4,4,4]
输出：4
解释：难度2出现3次：1轮(3个)；难度3出现2次：1轮(2个)；难度4出现5次：2轮(3+2)。总计4轮。
```

**示例 2：**
```
输入：tasks = [2,3,3]
输出：-1
解释：难度2只有1个，无法完成（必须2或3个）。
```

## 解题思路

统计每个难度级别的任务数量 `cnt`：
- 若 `cnt == 1`：无法完成，返回 -1。
- 否则：尽量用 3 个一轮，最多需要 `ceil(cnt / 3)` 轮。

**贪心：** 对于 `cnt` 个任务：
- `cnt % 3 == 0`：全用 3 个，`cnt // 3` 轮。
- `cnt % 3 == 1`：最后 4 个用 2 轮（2+2），其余用 3 个，共 `cnt // 3 - 1 + 2 = cnt // 3 + 1` 轮。
- `cnt % 3 == 2`：最后 2 个用 1 轮，其余用 3 个，共 `cnt // 3 + 1` 轮。

统一公式：`ceil(cnt / 3) = (cnt + 2) // 3`。

## 代码实现

### 方法一：贪心计数（推荐）

```python
from typing import List
from collections import Counter
import math

class Solution:
    def minimumRounds(self, tasks: List[int]) -> int:
        count = Counter(tasks)
        ans = 0

        for cnt in count.values():
            if cnt == 1:
                return -1  # 无法完成
            # 向上取整：每轮最多完成3个，最少2个
            ans += math.ceil(cnt / 3)

        return ans
```

### 方法二：位运算向上取整

```python
from typing import List
from collections import Counter

class Solution:
    def minimumRounds(self, tasks: List[int]) -> int:
        count = Counter(tasks)
        ans = 0

        for cnt in count.values():
            if cnt == 1:
                return -1
            # (cnt + 2) // 3 等价于 ceil(cnt / 3)
            ans += (cnt + 2) // 3

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，计数和遍历。
- 空间复杂度：O(d)，d 为不同难度级别数量。

## 关键点总结

1. 每个难度独立处理，互不影响。
2. `cnt == 1` 时无法完成（不能凑成 2 或 3 个）。
3. `cnt >= 2` 时，最少轮数 = `ceil(cnt / 3)`，这是因为每轮 2-3 个，尽量用 3 个最省。

## 易错点

- `cnt == 1` 时直接返回 -1，不要尝试其他计算。
- `ceil(cnt / 3)` 用整数运算 `(cnt + 2) // 3`，避免浮点精度问题。
