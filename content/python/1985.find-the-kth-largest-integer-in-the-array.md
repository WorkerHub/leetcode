## 题目描述

给你一个字符串数组 `nums` 和整数 `k`，`nums` 中每个元素表示一个**非负整数**（无前导零，但可以是 "0"）。

返回 `nums` 中第 `k` 大的整数（以字符串形式返回）。

**示例 1：**
```
输入：nums = ["3","6","7","10"], k = 4
输出："3"
```

**示例 2：**
```
输入：nums = ["2","21","12","1"], k = 3
输出："2"
```

**提示：**
- `1 <= k <= nums.length <= 10^4`
- `1 <= nums[i].length <= 100`（数字可达 100 位）

---

## 解题思路

### 核心思想：字符串大数比较 + 排序

数字可达 100 位，不能直接转 int 排序（会超出普通整型但 Python 的 int 支持大整数）。

两种方法：
1. 直接用 Python 大整数排序
2. 自定义字符串比较：先比长度，长度相同再字典序比较

---

## 代码实现

### 方法一：Python 大整数排序（推荐）

```python
from typing import List

class Solution:
    def kthLargestNumber(self, nums: List[str], k: int) -> str:
        # Python 支持任意精度整数，直接转换排序
        nums.sort(key=lambda x: int(x), reverse=True)
        return nums[k - 1]
```

### 方法二：自定义字符串比较

```python
from typing import List
import functools

class Solution:
    def kthLargestNumber(self, nums: List[str], k: int) -> str:

        def cmp(a: str, b: str) -> int:
            # 先比长度，长度大的数更大
            if len(a) != len(b):
                return len(a) - len(b)
            # 长度相同，按字典序比较（字典序等价于数值大小）
            if a < b:
                return -1
            elif a > b:
                return 1
            return 0

        # 按降序排列（从大到小），取第 k 个
        nums.sort(key=functools.cmp_to_key(cmp), reverse=True)
        return nums[k - 1]
```

### 方法三：快速选择（O(n) 平均）

```python
from typing import List
import random

class Solution:
    def kthLargestNumber(self, nums: List[str], k: int) -> str:

        def greater(a: str, b: str) -> bool:
            """a 是否大于 b"""
            if len(a) != len(b):
                return len(a) > len(b)
            return a > b

        def partition(lo, hi):
            pivot_idx = random.randint(lo, hi)
            nums[pivot_idx], nums[hi] = nums[hi], nums[pivot_idx]
            pivot = nums[hi]
            store = lo
            for i in range(lo, hi):
                if greater(nums[i], pivot):  # 降序：大的放前面
                    nums[store], nums[i] = nums[i], nums[store]
                    store += 1
            nums[store], nums[hi] = nums[hi], nums[store]
            return store

        lo, hi = 0, len(nums) - 1
        target = k - 1  # 第 k 大对应下标 k-1
        while lo <= hi:
            p = partition(lo, hi)
            if p == target:
                return nums[p]
            elif p < target:
                lo = p + 1
            else:
                hi = p - 1
        return nums[target]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n log n * L)，L 为字符串长度 | O(1) |
| 方法二 | O(n log n * L) | O(1) |
| 方法三 | O(n * L) 平均 | O(1) |

---

## 关键点总结

1. Python 大整数支持任意精度，直接 `int(x)` 转换最简单
2. 纯字符串比较：先比长度，再比字典序
3. 快速选择可达平均 O(n) 但实现复杂

---

## 易错点

- 字符串比较大数：长度不同时，长度更长的更大
- 快速选择中降序分区方向要正确
