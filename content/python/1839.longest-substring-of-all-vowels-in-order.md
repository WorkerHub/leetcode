## 题目描述

如果一个字符串满足：
- 只由元音字母 `'a'`、`'e'`、`'i'`、`'o'`、`'u'` 组成
- 每个元音字母都出现至少一次
- 字符非严格递增（`a <= e <= i <= o <= u`）

则该字符串是一个**美丽字符串**。

给你一个字符串 `word`，返回其中最长的**美丽子字符串**的长度，若没有则返回 0。

**示例 1：**
```
输入：word = "aeiaaioaaaaeiiiiouuuooaauuaeiu"
输出：13
```

**示例 2：**
```
输入：word = "aeeeiiiioooauuuaeiou"
输出：5
```

## 解题思路

**滑动窗口 / 线性扫描**：

扫描字符串，维护当前美丽字符串的长度和已出现的不同元音数：
- 若当前字符 >= 前一个字符，则扩展当前子字符串
- 若当前字符 > 前一个字符，则新出现了一个元音，计数 +1
- 若当前字符 < 前一个字符，则当前子字符串不再是美丽的，重新开始
- 当不同元音数等于 5 时，更新最大长度

## 代码实现

### 方法一：线性扫描（推荐）

```python
class Solution:
    def longestBeautifulSubstring(self, word: str) -> int:
        vowels = "aeiou"
        # vowel_order 记录元音的顺序（用于判断是否非递减）
        order = {v: i for i, v in enumerate(vowels)}

        max_len = 0
        cur_len = 1
        unique_count = 1  # 当前子字符串中不同元音的数量

        for i in range(1, len(word)):
            if word[i] == word[i - 1]:
                # 相同元音，扩展
                cur_len += 1
            elif order.get(word[i], -1) == order.get(word[i - 1], -1) + 1:
                # 下一个元音，扩展并增加不同元音计数
                cur_len += 1
                unique_count += 1
            else:
                # 不满足条件，重新开始
                cur_len = 1
                unique_count = 1

            if unique_count == 5:
                max_len = max(max_len, cur_len)

        return max_len
```

### 方法二：分段收集

```python
class Solution:
    def longestBeautifulSubstring(self, word: str) -> int:
        max_len = 0
        i = 0
        n = len(word)
        vowel_idx = {'a': 0, 'e': 1, 'i': 2, 'o': 3, 'u': 4}

        while i < n:
            if word[i] not in vowel_idx:
                i += 1
                continue
            # 从当前位置开始收集美丽子字符串
            j = i + 1
            unique = 1
            while j < n and word[j] in vowel_idx and word[j] >= word[j - 1]:
                if word[j] > word[j - 1]:
                    unique += 1
                j += 1
            if unique == 5:
                max_len = max(max_len, j - i)
            i = j

        return max_len
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 美丽字符串需要同时满足：仅含元音、每种出现至少一次、字符非递减
2. 扫描时判断当前字符与前一字符的关系：相同扩展、前进一个元音扩展并计数、否则重置
3. 只有 unique_count == 5 时才更新最大长度

## 易错点

- 字符必须按顺序 `a -> e -> i -> o -> u`，不能跳过（如 `ae -> ai` 是非法的）
- 检查 `order[word[i]] == order[word[i-1]] + 1` 来确保是连续的元音顺序
