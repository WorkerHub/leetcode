## 题目描述

不使用任何内建的哈希表库设计一个哈希集合（HashSet）。

实现 `MyHashSet` 类：

- `void add(key)` 向哈希集合中插入值 `key`
- `bool contains(key)` 返回哈希集合中是否存在这个值 `key`
- `void remove(key)` 将给定值 `key` 从哈希集合中删除。如果哈希集合中没有这个值，什么也不做

**示例：**
```
输入：
["MyHashSet", "add", "add", "contains", "contains", "add", "contains", "remove", "contains"]
[[], [1], [2], [1], [3], [2], [2], [2], [2]]
输出：
[null, null, null, true, false, null, true, null, false]

解释：
MyHashSet myHashSet = new MyHashSet();
myHashSet.add(1);      // set = [1]
myHashSet.add(2);      // set = [1, 2]
myHashSet.contains(1); // 返回 True
myHashSet.contains(3); // 返回 False，(未找到)
myHashSet.add(2);      // set = [1, 2]
myHashSet.contains(2); // 返回 True
myHashSet.remove(2);   // set = [1]
myHashSet.contains(2); // 返回 False，(已移除)
```

**提示：**
- `0 <= key <= 10^6`
- 最多调用 `10^4` 次 `add`、`remove` 和 `contains`

## 解题思路

这道题要求从零实现哈希集合，核心是理解**哈希表的底层原理**。

**哈希表核心概念：**
1. **哈希函数**：将 key 映射到数组索引
2. **冲突处理**：不同 key 可能映射到同一索引
3. **常见冲突解决方案**：
   - 链地址法（Chaining）：每个桶存储链表
   - 开放寻址法（Open Addressing）：探测下一个空位

**设计方案对比：**

| 方案 | 优点 | 缺点 |
|------|------|------|
| 布尔数组 | 最简单，O(1) | 空间浪费（需要 10^6 大小数组） |
| 链地址法 | 空间效率高，易扩展 | 需要额外链表结构 |
| 开放寻址 | 缓存友好 | 删除操作复杂 |

## Python 代码实现

### 方法一：布尔数组（最简单）⭐

```python
class MyHashSet:
    """
    使用固定大小的布尔数组
    适用于 key 范围已知且不太大的情况
    """
    def __init__(self):
        # key 范围是 [0, 10^6]
        self.size = 1000001
        self.buckets = [False] * self.size
    
    def add(self, key: int) -> None:
        self.buckets[key] = True
    
    def remove(self, key: int) -> None:
        self.buckets[key] = False
    
    def contains(self, key: int) -> bool:
        return self.buckets[key]
```

### 方法二：链地址法（推荐学习）⭐⭐

```python
class MyHashSet:
    """
    链地址法：使用数组 + 链表处理哈希冲突
    """
    def __init__(self):
        self.buckets = 1000  # 桶的数量
        self.table = [[] for _ in range(self.buckets)]
    
    def _hash(self, key: int) -> int:
        """哈希函数：取模运算"""
        return key % self.buckets
    
    def add(self, key: int) -> None:
        hash_key = self._hash(key)
        # 如果 key 不存在，才添加
        if key not in self.table[hash_key]:
            self.table[hash_key].append(key)
    
    def remove(self, key: int) -> None:
        hash_key = self._hash(key)
        if key in self.table[hash_key]:
            self.table[hash_key].remove(key)
    
    def contains(self, key: int) -> bool:
        hash_key = self._hash(key)
        return key in self.table[hash_key]
```

### 方法三：优化的链地址法（使用集合）

```python
class MyHashSet:
    """
    使用 Python 的 set 作为桶（虽然有点取巧）
    """
    def __init__(self):
        self.buckets = 1009  # 使用质数减少冲突
        self.table = [set() for _ in range(self.buckets)]
    
    def _hash(self, key: int) -> int:
        return key % self.buckets
    
    def add(self, key: int) -> None:
        self.table[self._hash(key)].add(key)
    
    def remove(self, key: int) -> None:
        self.table[self._hash(key)].discard(key)  # discard 不会抛异常
    
    def contains(self, key: int) -> bool:
        return key in self.table[self._hash(key)]
```

### 方法四：二维数组（分桶优化）

```python
class MyHashSet:
    """
    二维数组：平衡空间和时间
    """
    def __init__(self):
        self.base = 1000
        self.data = [None] * self.base
    
    def add(self, key: int) -> None:
        bucket_idx = key // self.base
        item_idx = key % self.base
        
        if self.data[bucket_idx] is None:
            self.data[bucket_idx] = [False] * self.base
        
        self.data[bucket_idx][item_idx] = True
    
    def remove(self, key: int) -> None:
        bucket_idx = key // self.base
        item_idx = key % self.base
        
        if self.data[bucket_idx] is not None:
            self.data[bucket_idx][item_idx] = False
    
    def contains(self, key: int) -> bool:
        bucket_idx = key // self.base
        item_idx = key % self.base
        
        return (self.data[bucket_idx] is not None and 
                self.data[bucket_idx][item_idx])
```

## 复杂度分析

**方法一（布尔数组）：**
- 时间复杂度：O(1) 所有操作
- 空间复杂度：O(max_key)，需要 10^6 空间

**方法二、三（链地址法）：**
- 时间复杂度：
  - 平均：O(n/b)，n 是元素数量，b 是桶数量
  - 最坏：O(n)，所有元素哈希到同一个桶
- 空间复杂度：O(n + b)

**方法四（二维数组）：**
- 时间复杂度：O(1)
- 空间复杂度：O(max_key)，但延迟分配，实际使用更少

## 关键点总结

1. **哈希函数**：简单的取模运算 `key % buckets`
2. **冲突处理**：链地址法最常用，易于理解和实现
3. **桶数量选择**：使用质数可以减少哈希冲突
4. **空间权衡**：布尔数组最快但浪费空间，链表节省空间但稍慢
5. **延迟初始化**：二维数组方法按需分配内存

## 易错点

1. **哈希函数选择**：简单取模即可，不要过度复杂化
2. **重复添加**：add 操作需要检查元素是否已存在
3. **删除不存在的元素**：remove 操作要先检查是否存在
4. **空指针**：二维数组方法需要检查桶是否已初始化
5. **桶数量**：不要太小（冲突多）也不要太大（浪费空间）
