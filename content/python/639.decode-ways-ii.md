## 题目描述

一条包含字母 A-Z 的消息通过以下映射进行了编码：

'A' -> "1"
'B' -> "2"
...
'Z' -> "26"

要解码已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。

此外，编码消息中可能包含 '*' 字符，'*' 可以表示从 '1' 到 '9' 的任一数字。

给定一个只包含数字和 '*' 字符的字符串 s，返回解码该字符串的方法数。答案可能很大，所以结果需要对 10^9 + 7 取模。

**示例 1：**
```
输入：s = "*"
输出：9
解释：'*' 可以表示 1-9 中的任意数字
```

**示例 2：**
```
输入：s = "1*"
输出：18
解释：
'1*' 可以解码为：
- 单独解码：1 和 * (1-9)，共 9 种
- 组合解码：10-19，共 10 种
但 '10'-'19' 只有 9 种有效（去掉重复）
实际是：11-19 (9种) + 单独的1和* (9种) = 18
```

**提示：**
- 1 <= s.length <= 10^5
- s[i] 是数字或 '*'

## 解题思路

使用动态规划，考虑 '*' 的所有可能取值。

## Python 代码实现

### 方法一：动态规划

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        
        # dp[i] 表示 s[0:i] 的解码方法数
        dp = [0] * (n + 1)
        dp[0] = 1
        
        # 处理第一个字符
        if s[0] == '*':
            dp[1] = 9
        elif s[0] != '0':
            dp[1] = 1
        else:
            return 0
        
        for i in range(2, n + 1):
            # 单独解码 s[i-1]
            if s[i-1] == '*':
                dp[i] = 9 * dp[i-1] % MOD
            elif s[i-1] != '0':
                dp[i] = dp[i-1]
            
            # 与前一个字符组合解码 s[i-2:i]
            if s[i-2] == '*':
                if s[i-1] == '*':
                    dp[i] = (dp[i] + 15 * dp[i-2]) % MOD  # 11-19, 21-26
                elif s[i-1] <= '6':
                    dp[i] = (dp[i] + 2 * dp[i-2]) % MOD  # 1*, 2*
                else:
                    dp[i] = (dp[i] + dp[i-2]) % MOD  # 1*
            elif s[i-2] == '1':
                if s[i-1] == '*':
                    dp[i] = (dp[i] + 9 * dp[i-2]) % MOD  # 11-19
                else:
                    dp[i] = (dp[i] + dp[i-2]) % MOD
            elif s[i-2] == '2':
                if s[i-1] == '*':
                    dp[i] = (dp[i] + 6 * dp[i-2]) % MOD  # 21-26
                elif s[i-1] <= '6':
                    dp[i] = (dp[i] + dp[i-2]) % MOD
        
        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 考虑 '*' 的所有可能取值
2. 分情况讨论单独解码和组合解码
3. 注意取模运算

## 学习建议

1. 先理解不含 '*' 的解码问题
2. 分情况讨论所有可能
3. 注意边界条件处理
