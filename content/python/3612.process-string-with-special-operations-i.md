## 题目描述

给你一个字符串 `s`，按以下规则处理：

- 遇到普通字符：追加到结果字符串末尾
- 遇到 `'*'`：删除结果字符串的最后一个字符（若非空）
- 遇到 `'#'`：将结果字符串翻转

返回处理完所有字符后的结果字符串。

**示例 1：**

```
输入：s = "abc*d"
输出："abd"
解释：a→b→c→删除c→d，结果"abd"
```

**示例 2：**

```
输入：s = "ab#c"
输出："bac"
解释：a→b→翻转"ba"→c→"bac"
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含小写字母、`'*'` 和 `'#'`

## 解题思路

用栈模拟字符串构建过程：

- 普通字符：入栈
- `'*'`：栈非空则弹出栈顶
- `'#'`：翻转栈（用方向标志代替实际翻转，节省时间）

优化：用一个方向标志 `reversed` 表示当前方向，翻转时只切换标志而不实际翻转栈内容。入栈时根据方向决定在栈首还是栈尾追加，弹出时也根据方向操作。

## Python 代码实现

### 方法一：双端队列 + 方向标志（推荐）

```python
from collections import deque

class Solution:
    def processStr(self, s: str) -> str:
        dq = deque()
        # False: 从右追加/删除（正向），True: 从左追加/删除（翻转状态）
        is_reversed = False

        for c in s:
            if c == '*':
                if dq:
                    if not is_reversed:
                        dq.pop()
                    else:
                        dq.popleft()
            elif c == '#':
                is_reversed = not is_reversed
            else:
                if not is_reversed:
                    dq.append(c)
                else:
                    dq.appendleft(c)

        result = ''.join(dq)
        if is_reversed:
            result = result[::-1]
        return result
```

### 方法二：直接模拟（简单实现）

```python
class Solution:
    def processStr(self, s: str) -> str:
        stack = []
        for c in s:
            if c == '*':
                if stack:
                    stack.pop()
            elif c == '#':
                stack.reverse()
            else:
                stack.append(c)
        return ''.join(stack)
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二，翻转可能为 O(n)）
- 空间复杂度：O(n)

## 关键点总结

1. 双端队列配合方向标志，O(1) 实现逻辑翻转
2. 方向标志切换时，追加和删除方向都要对应切换
3. 最终输出时需根据方向标志决定是否反转

## 易错点

1. `'#'` 操作翻转的是已构建的字符串，而非输入字符串
2. 连续多个 `'#'` 会交替翻转
3. 方向标志是对当前栈内容的语义解释，不是物理翻转
