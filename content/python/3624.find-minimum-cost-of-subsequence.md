## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。定义一个子序列的 **代价** 为其所有元素的按位或（OR）。

请返回长度为 `k` 且代价最小的子序列的代价值。

**示例 1：**

```
输入：nums = [1,2,3], k = 2
输出：1
解释：子序列 [1,2] 代价为 1|2=3，[1,3] 代价为 1|3=3，[2,3] 代价为 2|3=3，[1,2] 不对
实际 [1] 长度为1不满足，[1,2]=3，[1,3]=3，[2,3]=3 最小为3
```

**示例 2：**

```
输入：nums = [6,3,5,4], k = 2
输出：3
解释：选 [3,4]=3|4=7，不对，选 [3,5]=3|5=7，选 [3,6]=3|6=7
实际最小为选两个最小值的OR
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**贪心 + 位运算**：

OR 操作具有单调性（只增不减）。要最小化 k 个数的 OR 值，应该选择尽量"相似"的数。

对于每个可能的答案 `target`（从小到大枚举），检查是否能从 `nums` 中选出 `k` 个数使得它们的 OR = target。

**DP 方法**：`dp[mask]` = 能使 OR 结果为 `mask` 的最多元素数。

实际上，OR 的最小值就是选出 `k` 个数后 OR 结果最小，可以用贪心：按二进制位从高到低，如果删去某位还能选够 `k` 个数，就删去该位。

## Python 代码实现

### 方法一：贪心按位决策（推荐）

```python
from typing import List

class Solution:
    def minOrAfterOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for bit in range(29, -1, -1):
            # 尝试将第 bit 位设为 0
            candidate = ans  # 不包含第 bit 位的前缀
            # 统计 OR 结果中第 bit 位为 0 时，能选出多少个"连续段"
            # 实际：统计 nums[i] & candidate_mask == 0 的连续段合并
            mask = (1 << (bit + 1)) - 1  # 考虑高 bit 位
            # 统计在约束高位为 ans 的情况下，有多少个段满足条件
            count = 0
            curr_or = 0
            for x in nums:
                curr_or |= x & mask
                if curr_or == candidate:
                    # 这个段有效，重置
                    count += 1
                    curr_or = 0

            if count >= k:
                ans = candidate  # 第 bit 位可以为 0
            else:
                ans |= (1 << bit)  # 第 bit 位必须为 1

        return ans
```

### 方法二：动态规划（小值域）

```python
from typing import List

class Solution:
    def minOrAfterOperations(self, nums: List[int], k: int) -> int:
        # 对每种可能的 OR 值，统计可以选的最多元素数
        # 贪心：从最高位到最低位，尝试把该位清 0
        ans = 0
        for bit in range(29, -1, -1):
            new_ans = ans  # 尝试当前位不选（为 0）
            mask = ~(1 << bit) & ((1 << 30) - 1)
            # 统计有多少段，每段的 OR 在 new_ans 的约束下为 0（忽略当前位）
            groups = 0
            cur = 0
            for x in nums:
                cur |= (x & ((1 << 30) - 1))
                if (cur & ~new_ans) == 0:
                    groups += 1
                    cur = 0
            if groups < k:
                ans |= (1 << bit)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 30)，对每个位扫描整个数组
- 空间复杂度：O(1)

## 关键点总结

1. OR 操作单调递增，贪心从高位到低位决策
2. 统计"段数"：若连续 OR 满足约束就分一段，统计分段数 >= k 则该位可为 0
3. 逐位决定答案的每一位

## 易错点

1. 段的计算需要结合已决定的高位约束
2. 当前段 OR 满足约束后需要重置为 0
3. 位操作中注意 Python 整数无符号问题
