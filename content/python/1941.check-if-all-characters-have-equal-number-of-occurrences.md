## 题目描述

给你一个字符串 `s`，若 `s` 中所有字符出现次数**全部相同**，则返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "abacbc"
输出：true
解释：a 出现 2 次，b 出现 2 次，c 出现 2 次。
```

**示例 2：**
```
输入：s = "aaabb"
输出：false
解释：a 出现 3 次，b 出现 2 次。
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 只包含小写英文字母

---

## 解题思路

### 核心思想：统计频次 + 判断所有频次相同

用哈希表统计每个字符出现次数，再判断所有次数是否相等。

---

## 代码实现

### 方法一：Counter（推荐）

```python
from collections import Counter

class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        cnt = Counter(s)
        # 判断所有频次是否相同（使用集合去重后只有一个值）
        return len(set(cnt.values())) == 1
```

### 方法二：手动统计

```python
class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        freq = {}
        for c in s:
            freq[c] = freq.get(c, 0) + 1
        values = list(freq.values())
        # 所有值与第一个相同
        return all(v == values[0] for v in values)
```

### 方法三：排序比较

```python
from collections import Counter

class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        counts = sorted(Counter(s).values())
        return counts[0] == counts[-1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(26) |
| 方法二 | O(n) | O(26) |
| 方法三 | O(n + k log k) | O(26) |

---

## 关键点总结

1. `Counter(s).values()` 获取所有字符频次
2. `len(set(values)) == 1` 判断所有频次相同（集合大小为 1）

---

## 易错点

- 不要忘记字符频次是否为 0 的情况（Counter 不会统计未出现的字符，无需考虑）
