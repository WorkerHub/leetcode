## 题目描述

给你一个整数 `n`，按字典序返回范围 `[1, n]` 内所有整数。

你必须设计一个时间复杂度为 `O(n)` 且使用 `O(1)` 额外空间的算法。

**示例 1:**

```
输入：n = 13
输出：[1,10,11,12,13,2,3,4,5,6,7,8,9]
```

**示例 2:**

```
输入：n = 2
输出：[1,2]
```

**提示:**

- `1 <= n <= 5 * 10^4`

## 解题思路

**字典序（Lexicographical Order）** 是按照字符串的字典顺序排列，而不是数值大小。

例如：`1, 10, 11, ..., 19, 2, 20, 21, ...`

### 核心思想

**观察规律：**

字典序的遍历类似于**十叉树的深度优先搜索（DFS）**：

```
        1           2           3    ...    9
      /   \
    10    11  ...  19
   / \
 100 101 ... 109
```

**遍历规则：**

1. 从 1 开始
2. 尽可能向下（乘以 10）：`1 -> 10 -> 100 -> 1000 ...`
3. 如果不能向下，向右（加 1）：`1000 -> 1001`
4. 如果不能向右，回退到上一层再向右

### 迭代算法

```
current = 1
while result.length < n:
    add current to result
    
    if current * 10 <= n:
        current = current * 10  # 向下
    else:
        # 不能向下，需要向右或回退
        while current % 10 == 9 or current + 1 > n:
            current = current // 10  # 回退
        current += 1  # 向右
```

## Python 代码实现

### 方法一：迭代模拟（推荐）⭐

```python
from typing import List

class Solution:
    def lexicalOrder(self, n: int) -> List[int]:
        """
        迭代模拟字典树的 DFS
        时间复杂度: O(n)
        空间复杂度: O(1) - 不算结果数组
        """
        result = []
        current = 1
        
        for _ in range(n):
            result.append(current)
            
            # 尝试向下（乘以 10）
            if current * 10 <= n:
                current *= 10
            else:
                # 不能向下，需要向右或回退
                # 如果当前数以 9 结尾或者 +1 会超过 n，需要回退
                while current % 10 == 9 or current + 1 > n:
                    current //= 10
                current += 1
        
        return result
```

### 方法二：递归 DFS（直观）

```python
from typing import List

class Solution:
    def lexicalOrder(self, n: int) -> List[int]:
        """
        递归深度优先搜索
        时间复杂度: O(n)
        空间复杂度: O(log n) - 递归栈深度
        """
        result = []
        
        def dfs(current: int):
            if current > n:
                return
            
            result.append(current)
            
            # 尝试向下（添加 0-9）
            for i in range(10):
                next_num = current * 10 + i
                if next_num > n:
                    break
                dfs(next_num)
        
        # 从 1-9 开始
        for i in range(1, 10):
            dfs(i)
        
        return result
```

### 方法三：简化的递归

```python
from typing import List

class Solution:
    def lexicalOrder(self, n: int) -> List[int]:
        """
        简化的递归实现
        """
        result = []
        
        def dfs(num: int):
            if num > n:
                return
            result.append(num)
            
            # 扩展到下一层
            num *= 10
            for i in range(10):
                if num + i > n:
                    break
                dfs(num + i)
        
        for i in range(1, 10):
            dfs(i)
        
        return result
```

### 方法四：排序（不推荐，不满足要求）

```python
from typing import List

class Solution:
    def lexicalOrder(self, n: int) -> List[int]:
        """
        直接排序（不满足 O(1) 空间要求）
        时间复杂度: O(n log n)
        空间复杂度: O(n) - 字符串转换
        """
        return sorted(range(1, n + 1), key=str)
```

## 复杂度分析

### 方法一：迭代

**时间复杂度：** O(n)
- 恰好生成 n 个数字，每个数字处理 O(1) 时间

**空间复杂度：** O(1)
- 不算结果数组，只使用常数额外空间
- 满足题目要求

### 方法二：递归

**时间复杂度：** O(n)
- 每个数字访问一次

**空间复杂度：** O(log n)
- 递归调用栈的深度最多为数字的位数
- 不满足 O(1) 空间要求

## 关键点总结

1. **字典序规律**：按字符串排序，不是数值排序
2. **十叉树模型**：问题可以建模为十叉树的 DFS 遍历
3. **迭代实现**：通过规则模拟 DFS，避免递归栈空间
4. **向下优先**：优先 `current * 10`，尽可能深入
5. **回退条件**：当前数以 9 结尾或 +1 超过 n 时需要回退

## 易错点

1. **起始数字**：从 1 开始，不是 0
2. **回退逻辑**：需要同时检查 `current % 10 == 9` 和 `current + 1 > n`
3. **边界处理**：n = 1 的情况
4. **理解字典序**：10 在字典序中排在 2 前面
5. **空间复杂度**：递归方法不满足 O(1) 要求
