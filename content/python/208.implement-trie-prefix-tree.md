## 题目描述

**Trie**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word`。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false`。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix`，返回 `true`；否则，返回 `false`。

**示例：**
```
输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 true
trie.search("app");     // 返回 false
trie.startsWith("app"); // 返回 true
trie.insert("app");
trie.search("app");     // 返回 true
```

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数总计不超过 `3 * 10^4` 次

## 解题思路

**Trie（前缀树/字典树）** 是一种专门处理字符串的树形数据结构。

### Trie 的特点

1. **根节点不包含字符**，其他每个节点包含一个字符
2. **从根到某一节点的路径**，路径上的字符连接起来，就是该节点对应的字符串
3. **每个节点的所有子节点**包含的字符都不相同
4. **标记结束**：需要标记某个节点是否为单词的结尾

### 节点设计

每个节点需要包含：
1. **子节点**：通常用字典或数组存储（26个小写字母）
2. **标记位**：表示从根到当前节点是否构成一个完整的单词

### 基本操作

1. **插入（insert）**：
   - 从根节点开始，逐个字符创建或查找节点
   - 最后标记单词结束

2. **搜索（search）**：
   - 从根节点开始，逐个字符查找
   - 最后检查是否为单词结束标记

3. **前缀搜索（startsWith）**：
   - 类似 search，但不需要检查结束标记

## Python 代码实现

### 方法一：使用字典存储子节点（推荐）⭐

```python
class TrieNode:
    """Trie 的节点"""
    def __init__(self):
        # 子节点字典，key 是字符，value 是 TrieNode
        self.children = {}
        # 标记是否为单词的结尾
        self.is_end = False

class Trie:
    def __init__(self):
        # 初始化根节点
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        """插入单词"""
        node = self.root
        
        # 遍历单词的每个字符
        for char in word:
            # 如果字符不在子节点中，创建新节点
            if char not in node.children:
                node.children[char] = TrieNode()
            # 移动到子节点
            node = node.children[char]
        
        # 标记单词结束
        node.is_end = True

    def search(self, word: str) -> bool:
        """搜索完整单词"""
        node = self.root
        
        # 遍历单词的每个字符
        for char in word:
            # 如果字符不存在，返回 False
            if char not in node.children:
                return False
            # 移动到子节点
            node = node.children[char]
        
        # 检查是否为单词结尾
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        """搜索前缀"""
        node = self.root
        
        # 遍历前缀的每个字符
        for char in prefix:
            # 如果字符不存在，返回 False
            if char not in node.children:
                return False
            # 移动到子节点
            node = node.children[char]
        
        # 只要能找到完整路径就返回 True
        return True
```

**代码说明**：
- **TrieNode 类**：表示 Trie 的节点
  - `children`：字典存储子节点
  - `is_end`：标记是否为单词结尾
- **insert**：逐字符插入，最后标记结束
- **search**：逐字符查找，最后检查结束标记
- **startsWith**：逐字符查找，不检查结束标记

### 方法二：使用数组存储子节点

```python
class TrieNode:
    def __init__(self):
        # 26 个小写字母
        self.children = [None] * 26
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            # 计算字符对应的索引
            index = ord(char) - ord('a')
            if not node.children[index]:
                node.children[index] = TrieNode()
            node = node.children[index]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self.root
        for char in word:
            index = ord(char) - ord('a')
            if not node.children[index]:
                return False
            node = node.children[index]
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        node = self.root
        for char in prefix:
            index = ord(char) - ord('a')
            if not node.children[index]:
                return False
            node = node.children[index]
        return True
```

**优点**：
- 数组访问速度快（O(1)）
- 适合字符集固定且较小的情况

**缺点**：
- 空间浪费（每个节点都占用 26 个空间）
- 不适合字符集大或字符种类多的情况

### 方法三：优化版（提取公共方法）

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def _search_prefix(self, prefix: str) -> TrieNode:
        """辅助方法：搜索前缀，返回最后的节点"""
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node

    def search(self, word: str) -> bool:
        node = self._search_prefix(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._search_prefix(prefix) is not None
```

**优化说明**：
- 提取公共的前缀搜索逻辑
- 代码更简洁，复用性更好

### 方法四：使用 defaultdict

```python
from collections import defaultdict

class TrieNode:
    def __init__(self):
        # 自动创建不存在的键
        self.children = defaultdict(TrieNode)
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            # defaultdict 会自动创建节点
            node = node.children[char]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```

**优点**：
- insert 代码更简洁
- 自动处理节点创建

## 复杂度分析

设 n 为单词长度，m 为单词数量。

### 时间复杂度
- **insert**：O(n)，需要遍历单词的每个字符
- **search**：O(n)，需要遍历单词的每个字符
- **startsWith**：O(n)，需要遍历前缀的每个字符

### 空间复杂度
- **总空间**：O(m × n)，最坏情况下所有单词没有公共前缀
- **单个节点**：
  - 字典实现：O(字符种类数)
  - 数组实现：O(26)

## 关键点总结

1. **节点设计**：children（子节点）+ is_end（结束标记）
2. **字典 vs 数组**：
   - 字典：灵活，节省空间，适合字符集大
   - 数组：快速，适合字符集小且固定
3. **search vs startsWith**：区别在于是否检查 is_end
4. **前缀共享**：Trie 的核心优势，节省空间
5. **应用场景**：自动补全、拼写检查、IP 路由、字符串匹配

## 易错点

1. **忘记标记结束**：insert 后忘记设置 `is_end = True`

2. **search 和 startsWith 混淆**：
   - search 需要检查 `is_end`
   - startsWith 只需要找到路径

3. **节点初始化错误**：
   ```python
   # 错误：所有节点共享同一个字典
   class TrieNode:
       children = {}  # 应该在 __init__ 中初始化
   ```

4. **边界情况**：
   - 空字符串（题目保证长度 >= 1）
   - 重复插入相同单词

5. **数组实现的索引错误**：
   ```python
   index = ord(char) - ord('a')  # 正确
   index = ord(char)              # 错误，索引会超出范围
   ```
