## 题目描述

给你一个整数数组 `nums`，找出满足 `i < j < k` 且 `nums[i] < nums[j]` 且 `nums[k] > nums[j]` 的三元组 `(i, j, k)`，使 `nums[i] + nums[j] + nums[k]` 最大。

返回这个最大值，若不存在满足条件的三元组，返回 0。

**示例 1：**
```
输入：nums = [2,5,3,4,5]
输出：12
解释：(0,1,4): 2+5+5=12 或 (0,3,4): 2+4+5=11，最大为 12
```

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对每个中间元素 `j`：
- 需要找 `i < j` 中满足 `nums[i] < nums[j]` 的最大 `nums[i]`（最大化 nums[i]）
- 需要找 `k > j` 中满足 `nums[k] > nums[j]` 的最大 `nums[k]`（最大化 nums[k]）

使用两个预处理数组：
- `left_max[j]`：`nums[0..j-1]` 中小于 `nums[j]` 的最大值
- `right_max[j]`：`nums[j+1..n-1]` 中大于 `nums[j]` 的最大值

然后枚举 `j`，计算 `left_max[j] + nums[j] + right_max[j]`。

## Python 代码实现

### 方法一：预处理左右最大值（推荐）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)

        # left_max[j] = nums[0..j-1] 中 < nums[j] 的最大值
        left_max = [-1] * n
        cur_max = -1
        for j in range(n):
            if cur_max < nums[j]:
                left_max[j] = cur_max  # 左侧最大值小于 nums[j]
            # 注意：cur_max 存的是前缀最大值，但我们需要小于 nums[j] 的最大值
            cur_max = max(cur_max, nums[j])

        # 上面的实现不对，需要重新考虑
        # left_max[j] = i < j 中满足 nums[i] < nums[j] 的最大 nums[i]
        # 用 SortedList 或 维护有序结构

        from sortedcontainers import SortedList
        sl_left = SortedList()
        left_best = [-1] * n
        for j in range(n):
            # 在 sl_left 中找最大的 < nums[j] 的元素
            idx = sl_left.bisect_left(nums[j]) - 1
            left_best[j] = sl_left[idx] if idx >= 0 else -1
            sl_left.add(nums[j])

        # right_max[j] = k > j 中满足 nums[k] > nums[j] 的最大 nums[k]
        sl_right = SortedList()
        right_best = [-1] * n
        for j in range(n - 1, -1, -1):
            # 在 sl_right 中找最大的 > nums[j] 的元素
            idx = sl_right.bisect_right(nums[j])
            if idx < len(sl_right):
                right_best[j] = sl_right[-1]  # 最大的大于 nums[j] 的元素
            sl_right.add(nums[j])

        ans = 0
        for j in range(1, n - 1):
            if left_best[j] != -1 and right_best[j] != -1:
                ans = max(ans, left_best[j] + nums[j] + right_best[j])

        return ans
```

### 方法二：简化版（O(n) 预处理）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)

        # 从右往左：right_max[j] = j+1..n-1 中 > nums[j] 的最大值
        right_max = [0] * n
        suffix_max = 0
        for j in range(n - 1, -1, -1):
            right_max[j] = suffix_max if suffix_max > nums[j] else 0
            suffix_max = max(suffix_max, nums[j])

        # 从左往右：维护前缀最大值，找小于当前值的最大值
        ans = 0
        prefix_max = 0  # 注意：这里需要小于 nums[j] 的最大值，不是所有前缀最大值
        # 需要用更精确的结构...

        # 简化：枚举所有三元组中间点，用 O(n^2) 实现
        for j in range(1, n - 1):
            # 找左侧最大的小于 nums[j] 的值
            left_best = 0
            for i in range(j):
                if nums[i] < nums[j]:
                    left_best = max(left_best, nums[i])
            # 找右侧最大的大于 nums[j] 的值
            right_best = 0
            for k in range(j + 1, n):
                if nums[k] > nums[j]:
                    right_best = max(right_best, nums[k])

            if left_best > 0 and right_best > 0:
                ans = max(ans, left_best + nums[j] + right_best)

        return ans
```

## 复杂度分析

- 方法一：O(n log n)（SortedList）
- 方法二：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 枚举中间元素 `j`，分别找左侧最大的小于 `nums[j]` 的值和右侧最大的大于 `nums[j]` 的值
2. 有序集合（SortedList）支持 O(log n) 查询
3. 若不存在满足条件的三元组，返回 0

## 易错点

1. 左侧需要找**小于** `nums[j]` 的最大值（不是任意前缀最大值）
2. 右侧需要找**大于** `nums[j]` 的最大值
3. 若左侧或右侧找不到满足条件的值，则跳过该 `j`
