## 题目描述

给你两个整数数组 `wizard` 和 `potion`，长度分别为 n 和 m。

每个巫师 `wizard[i]` 独立酿造所有 m 种药水，酿造药水 j 需要 `wizard[i] * potion[j]` 的时间。

所有巫师**同时**开始，且每个巫师**按顺序**（从 j=0 到 j=m-1）酿造药水。

返回所有药水都被酿造完成的最短时间。

**示例：**

```
输入：wizard = [3,6], potion = [2,3,5]
输出：22
解释：
巫师0 酿造时间：6,9,15，完成时刻：6,15,30
巫师1 酿造时间：12,18,30，完成时刻：12,30,60
...实际分配需要更多分析
```

**提示：**
- `1 <= wizard.length, potion.length <= 10^5`

## 解题思路

每个巫师按顺序酿造药水，巫师 i 酿造前 k 个药水的总时间为 `wizard[i] * (potion[0] + ... + potion[k-1])`。

用前缀和 `prefix[k] = sum(potion[0..k-1])`，巫师 i 完成前 k 个药水的时间为 `wizard[i] * prefix[k]`。

题目要求所有药水都被酿造完成（每个巫师酿造所有药水，不是分配），所以结束时间是所有巫师的最大完成时间：`max(wizard[i] * prefix[m] for all i) = max(wizard) * prefix[m]`。

等等，重新理解：每个巫师都要独立酿造所有 m 种药水。

## Python 代码实现

### 方法一：直接计算

```python
from typing import List

class Solution:
    def minTime(self, wizard: List[int], potion: List[int]) -> int:
        # 每个巫师酿造所有药水，巫师 i 的总时间 = wizard[i] * sum(potion)
        total_potion = sum(potion)
        # 所有巫师同时开始，结束时间 = max(wizard[i] * total_potion)
        # 但题目说"所有药水被酿造完成"可能是分配问题

        # 若每种药水只需酿造一次，各巫师分担：
        # 类似流水线，每个巫师从某个药水开始连续酿造到某个药水结束

        # 贪心：将 m 种药水分配给 n 个巫师（每人分连续的一段）
        # 巫师 i 酿造药水 [l_i, r_i]，时间为 wizard[i] * prefix[r_i - l_i]
        # 最小化最大完成时间

        # 二分答案 T：判断所有巫师能在 T 内完成所有分配的药水
        prefix = [0] * (len(potion) + 1)
        for j, p in enumerate(potion):
            prefix[j + 1] = prefix[j] + p

        n, m = len(wizard), len(potion)

        def feasible(T):
            # 贪心：从左到右，每个巫师尽量多做
            j = 0
            for w in wizard:
                if j >= m:
                    break
                # 巫师 w 最多做 potion 中从 j 开始的连续段，时间 <= T
                # w * (prefix[k] - prefix[j]) <= T
                # prefix[k] - prefix[j] <= T // w
                limit = T // w if w > 0 else float('inf')
                # 找最大 k 使 prefix[k] - prefix[j] <= limit
                import bisect
                target = prefix[j] + limit
                k = bisect.bisect_right(prefix, target, j, m + 1) - 1
                j = k  # 下一个巫师从 k 开始
            return j >= m

        lo, hi = 0, max(wizard) * sum(potion)
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：二分 + 前缀和

```python
from typing import List
import bisect

class Solution:
    def minTime(self, wizard: List[int], potion: List[int]) -> int:
        prefix = [0]
        for p in potion:
            prefix.append(prefix[-1] + p)

        n, m = len(wizard), len(potion)

        def check(T):
            pos = 0  # 当前未分配的第一个药水
            for w in wizard:
                if pos >= m:
                    return True
                # 巫师 w 能在时间 T 内完成 prefix 差值 <= T // w 的药水
                if w == 0:
                    continue
                max_sum = T // w
                # 找从 pos 开始最多能做多少
                cur_prefix = prefix[pos]
                target = cur_prefix + max_sum
                next_pos = bisect.bisect_right(prefix, target) - 1
                pos = next_pos
            return pos >= m

        lo, hi = 0, int(max(wizard) * sum(potion))
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

## 复杂度分析

- 时间复杂度：O((n + m) log(W * P))，W 为最大巫师值，P 为最大药水前缀和
- 空间复杂度：O(m)

## 关键点总结

1. 二分答案：枚举最大完成时间 T
2. 贪心分配：每个巫师尽量多做（使前缀和增量最大）
3. 前缀和 + 二分查找：O(log m) 找每个巫师能做的最多药水数

## 易错点

1. 巫师的 wizard[i] 可能为 0（无限快），特殊处理
2. 二分上界要足够大：max(wizard) * sum(potion)
3. 贪心方向：从速度慢的巫师开始，或直接按顺序
