## 题目描述

给你一个字符串数组 `words` 和一个字符 `separator`，对 `words` 中的每个字符串按 `separator` 分割，将所有分割结果（**非空**）收集到一个新数组中并返回。

**示例 1：**
```
输入：words = ["one.two.three","four.five","six"], separator = "."
输出：["one","two","three","four","five","six"]
```

**示例 2：**
```
输入：words = ["$easy$","$problem$"], separator = "$"
输出：["easy","problem"]
```

**提示：**
- `1 <= words.length <= 100`

## 解题思路

对每个字符串调用 `split(separator)` 方法，过滤空字符串后加入结果列表。

## Python 代码实现

### 方法一：Python split（推荐）

```python
from typing import List

class Solution:
    def splitWordsBySeparator(self, words: List[str], separator: str) -> List[str]:
        result = []
        for word in words:
            # split 后过滤空字符串
            parts = [p for p in word.split(separator) if p]
            result.extend(parts)
        return result
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def splitWordsBySeparator(self, words: List[str], separator: str) -> List[str]:
        return [part for word in words
                for part in word.split(separator) if part]
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为字符串数，L 为平均长度
- 空间复杂度：O(n * L)

## 关键点总结

1. `split(separator)` 会产生空字符串（如 `"..".split(".")` 得到 `['', '', '']`）
2. 过滤 `if part` 去除空字符串

## 易错点

1. 分隔符可能连续出现，需要过滤空结果
2. `split` 不同于 `re.split`，前者按字符串分割
