## 题目描述

给你一个 `n x n` 的整数矩阵 `grid`。

对矩阵的每条对角线（从左上到右下方向）独立排序：
- **左下半部分**的对角线（包括主对角线以下的部分）：按**升序**排列（从左上到右下）
- **右上半部分**的对角线（主对角线以上）：按**降序**排列（从左上到右下）

返回排序后的矩阵。

**示例：**

```
输入：grid = [[1,7,3],[9,8,2],[4,5,6]]
输出：[[8,2,3],[4,6,7],[9,5,1]]
```

**提示：**
- `1 <= n <= 10`
- `1 <= grid[i][j] <= 100`

## 解题思路

按对角线分组处理：
- 同一对角线上的元素满足 `row - col = 常数`（d = row - col）
- d >= 0（左下半部分，包括主对角线）：升序排列
- d < 0（右上半部分）：降序排列

对每条对角线，提取元素，排序后放回。

## Python 代码实现

### 方法一：按对角线分组（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)

        # 按对角线分组（d = row - col）
        diag = defaultdict(list)
        for i in range(n):
            for j in range(n):
                diag[i - j].append(grid[i][j])

        # 对每条对角线排序
        for d in diag:
            if d >= 0:
                # 左下半部分：升序
                diag[d].sort()
            else:
                # 右上半部分：降序
                diag[d].sort(reverse=True)

        # 将排序后的值放回矩阵
        # 对角线元素的位置顺序（从左上到右下）
        result = [[0] * n for _ in range(n)]
        pos = defaultdict(int)  # 每条对角线当前填到哪个位置

        for i in range(n):
            for j in range(n):
                d = i - j
                result[i][j] = diag[d][pos[d]]
                pos[d] += 1

        return result
```

### 方法二：提取-排序-填回

```python
from typing import List
from collections import defaultdict

class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        result = [row[:] for row in grid]

        # 枚举每条对角线（由 d = row - col 唯一确定）
        for d in range(-(n-1), n):
            # 提取该对角线的所有 (row, col) 对
            positions = []
            if d >= 0:
                # 从 (d, 0) 开始
                r, c = d, 0
            else:
                # 从 (0, -d) 开始
                r, c = 0, -d

            while r < n and c < n:
                positions.append((r, c))
                r += 1
                c += 1

            values = [grid[r][c] for r, c in positions]

            if d >= 0:
                values.sort()  # 升序
            else:
                values.sort(reverse=True)  # 降序

            for idx, (r, c) in enumerate(positions):
                result[r][c] = values[idx]

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 log n)，每条对角线排序
- 空间复杂度：O(n^2)

## 关键点总结

1. 对角线由 `row - col` 唯一确定
2. `d >= 0`（下半部分）升序，`d < 0`（上半部分）降序
3. 对角线上的元素按 row（或 col）升序排列

## 易错点

1. 排序方向：左下（包括主对角线）升序，右上降序
2. `row - col = d` 的对角线，起始位置不同
3. 结果要放回原位置，而不是新建一个不相关的矩阵
