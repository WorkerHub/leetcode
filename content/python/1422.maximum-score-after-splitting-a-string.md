## 题目描述

给你一个由若干 `0` 和 `1` 组成的字符串 `s`，请你计算并返回将该字符串分割成两个 **非空** 子字符串（即 **左** 子字符串和 **右** 子字符串）所能获得的最大得分。

「分割字符串的得分」为 **左** 子字符串中 `0` 的数量加上 **右** 子字符串中 `1` 的数量。

**示例 1：**

```
输入：s = "011101"
输出：5
解释：
将字符串分割成两个子字符串：
左 = "0"  得分 = 1（0的个数）
右 = "11101"  得分 = 4（1的个数）
总得分 = 1 + 4 = 5（最优分割）
```

**示例 2：**

```
输入：s = "00111"
输出：5
解释：
左 = "00"  得分 = 2
右 = "111"  得分 = 3
总得分 = 5
```

**示例 3：**

```
输入：s = "1111"
输出：3
```

**提示：**

- `2 <= s.length <= 500`
- 字符串 `s` 仅由字符 `'0'` 和 `'1'` 组成

## 解题思路

### 方法一：枚举分割点（推荐）

枚举所有可能的分割点（左子串至少1个字符，右子串至少1个字符），对每种分割计算得分，取最大值。

分割点 `i` 表示左子串为 `s[0:i+1]`，右子串为 `s[i+1:]`，`i` 从 0 到 `n-2`。

```
score(i) = count('0', s[0:i+1]) + count('1', s[i+1:])
```

直接枚举时间复杂度 O(n^2)（每次计算要扫描子串），可以用前缀和优化到 O(n)。

### 方法二：前缀计数（O(n)）

预先计算：
- `zeros[i]`：前 `i` 个字符中 '0' 的个数
- `ones_total`：字符串中 '1' 的总数

则 `score(i) = zeros[i+1] + (ones_total - ones[i+1])`，其中 `ones[i+1]` 为前 `i+1` 个字符中 '1' 的个数。

### 方法三：一次遍历（最优）

使用数学推导，一次遍历得到答案：

`score = count('0', left) + count('1', right)`

设 `total_ones = s.count('1')`，从左到右扫描，维护：
- `left_zeros`：当前左子串中 '0' 的个数
- `left_ones`：当前左子串中 '1' 的个数

则 `score = left_zeros + (total_ones - left_ones)`

## Python 代码实现

### 方法一：枚举分割点（直观）

```python
class Solution:
    def maxScore(self, s: str) -> int:
        n = len(s)
        max_score = 0

        # 枚举分割点 i（左子串 s[0:i+1]，右子串 s[i+1:]）
        for i in range(n - 1):
            # 左边 0 的个数 + 右边 1 的个数
            left_zeros = s[:i+1].count('0')
            right_ones = s[i+1:].count('1')
            max_score = max(max_score, left_zeros + right_ones)

        return max_score
```

### 方法二：前缀和（O(n)）

```python
from typing import List
import itertools

class Solution:
    def maxScore(self, s: str) -> int:
        n = len(s)

        # 前缀 0 的个数：prefix_zeros[i] = s[0:i] 中 '0' 的个数
        prefix_zeros = [0] * (n + 1)
        for i in range(n):
            prefix_zeros[i + 1] = prefix_zeros[i] + (1 if s[i] == '0' else 0)

        total_ones = s.count('1')
        # prefix_ones[i] = s[0:i] 中 '1' 的个数
        prefix_ones = [0] * (n + 1)
        for i in range(n):
            prefix_ones[i + 1] = prefix_ones[i] + (1 if s[i] == '1' else 0)

        max_score = 0
        # 分割点 i：左子串 s[0:i]（长度 i），右子串 s[i:]（长度 n-i）
        # i 从 1 到 n-1（左右均非空）
        for i in range(1, n):
            score = prefix_zeros[i] + (total_ones - prefix_ones[i])
            max_score = max(max_score, score)

        return max_score
```

### 方法三：一次遍历（最优，O(n) 时间 O(1) 空间）

```python
class Solution:
    def maxScore(self, s: str) -> int:
        # 总 1 的个数
        total_ones = s.count('1')

        left_zeros = 0  # 当前左子串中 0 的个数
        left_ones = 0   # 当前左子串中 1 的个数
        max_score = 0

        # 遍历到 n-2（留一个字符给右子串）
        for i in range(len(s) - 1):
            if s[i] == '0':
                left_zeros += 1
            else:
                left_ones += 1

            # 当前分割的得分
            score = left_zeros + (total_ones - left_ones)
            max_score = max(max_score, score)

        return max_score
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举分割点 | O(n^2) | O(1) |
| 前缀和 | O(n) | O(n) |
| 一次遍历 | O(n) | O(1) |

最优解为一次遍历方法。

## 关键点总结

1. 核心公式：`score = left_zeros + right_ones = left_zeros + (total_ones - left_ones)`
2. 分割点范围：`i` 从 1 到 `n-1`（左右子串均非空）
3. 一次遍历只需维护左子串的 0 和 1 计数，加上总 1 数即可

## 易错点

1. 分割点的范围：左子串至少 1 个字符，右子串至少 1 个字符，所以分割点是 `1` 到 `n-1`
2. 不要用字符串切片的 `count()`（O(n)），因为在循环内会导致 O(n^2)
3. `s.count('1')` 预计算总 1 数，后续不需要重新计算
