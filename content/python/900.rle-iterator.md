## 题目描述

我们可以使用游程编码(即 RLE )来编码一个整数序列。在偶数长度 encoding ( 从 0 开始 )的游程编码数组中，对于所有偶数 i ，encoding[i] 告诉我们非负整数 encoding[i + 1] 在序列中重复的次数。

例如，序列 arr = [8,8,8,5,5] 可以被编码为 encoding =[3,8,2,5] 。encoding =[3,8,0,9,2,5] 和 encoding =[2,8,1,8,2,5] 也是 arr 有效的 RLE 。

给定一个游程长度的编码数组，设计一个迭代器来遍历它。

实现 RLEIterator 类：
- RLEIterator(int[] encoded) 用编码后的数组初始化对象。
- int next(int n) 以这种方式耗尽后 n 个元素并返回最后一个耗尽的元素。如果没有剩余的元素要耗尽，则返回 -1 。

**提示：**
- 2 <= encoding.length <= 1000
- encoding.length 为偶数
- 0 <= encoding[i] <= 10^9
- 1 <= n <= 10^9
- 每个测试用例调用 next 不高于 1000 次

## 解题思路

维护当前位置和已消耗数量。

## Python 代码实现

```python
class RLEIterator:
    def __init__(self, encoding: List[int]):
        self.encoding = encoding
        self.index = 0
        self.used = 0
    
    def next(self, n: int) -> int:
        while self.index < len(self.encoding):
            # 当前段剩余数量
            remaining = self.encoding[self.index] - self.used
            
            if n <= remaining:
                # 当前段够用
                self.used += n
                return self.encoding[self.index + 1]
            else:
                # 当前段不够，消耗完并移到下一段
                n -= remaining
                self.index += 2
                self.used = 0
        
        return -1
```

## 复杂度分析

- **时间复杂度**：next O(k)，k 是段数
- **空间复杂度**：O(1)

## 关键点总结

1. **游程编码**：[count, value] 对
2. **维护状态**：当前段和已用数量
3. **跨段处理**：一次 next 可能跨多个段
