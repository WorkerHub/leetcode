## 题目描述

给定一个整数数组 `nums`。若一个元素在数组中出现次数超过数组长度一半，则称其为"支配元素"。将数组在某位置分割为两个非空部分，若两部分都各自拥有支配元素（且为同一个元素），则称该分割为"合法分割"。返回最小的合法分割位置，若不存在则返回 `-1`。

**示例 1：**

```
输入：nums = [1, 2, 2, 2]
输出：2
解释：支配元素为 2（出现3次，>4/2=2）。
     在索引 2 分割：[1,2,2] 和 [2]。
     左半：2出现2次，>3/2=1.5，是支配元素。
     右半：2出现1次，>1/2=0.5，是支配元素。
     最小分割位置为 2。
```

**示例 2：**

```
输入：nums = [2, 1, 3, 1, 1]
输出：4
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

1. 先找整个数组的支配元素（用 Boyer-Moore 投票算法，O(n)）
2. 若不存在支配元素，返回 -1
3. 从左到右枚举分割位置，维护前缀中支配元素的出现次数
4. 对每个分割位置，检查左半和右半是否都有同一个支配元素

## Python 代码实现

### 方法一：Boyer-Moore 投票 + 前缀计数（推荐）

```python
from typing import List

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        n = len(nums)

        # Boyer-Moore 找支配元素候选
        candidate, count = nums[0], 1
        for x in nums[1:]:
            if count == 0:
                candidate, count = x, 1
            elif x == candidate:
                count += 1
            else:
                count -= 1

        # 验证候选是否是支配元素
        total = nums.count(candidate)
        if total * 2 <= n:
            return -1

        # 枚举分割位置
        left_count = 0
        for i in range(n - 1):
            if nums[i] == candidate:
                left_count += 1
            left_len = i + 1
            right_count = total - left_count
            right_len = n - left_len
            # 左半支配元素：left_count * 2 > left_len
            # 右半支配元素：right_count * 2 > right_len
            if left_count * 2 > left_len and right_count * 2 > right_len:
                return i

        return -1
```

### 方法二：哈希表计数

```python
from typing import List
from collections import Counter

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        n = len(nums)
        total_cnt = Counter(nums)

        # 找支配元素
        dominant = None
        for val, freq in total_cnt.items():
            if freq * 2 > n:
                dominant = val
                break

        if dominant is None:
            return -1

        total = total_cnt[dominant]
        left_count = 0
        for i in range(n - 1):
            if nums[i] == dominant:
                left_count += 1
            left_len = i + 1
            right_count = total - left_count
            right_len = n - left_len
            if left_count * 2 > left_len and right_count * 2 > right_len:
                return i

        return -1
```

## 复杂度分析

- 时间复杂度：O(n)，Boyer-Moore + 前缀扫描
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. Boyer-Moore 投票算法 O(n) 找支配元素
2. 分割后，左右两半的支配元素必须相同（即整个数组的支配元素）
3. 从左到右枚举，维护前缀计数

## 易错点

1. 支配元素是出现次数**严格大于**数组长度一半
2. 分割后左右两半都必须非空
3. 返回的是分割位置的索引（分割在索引 i 后，即左半为 `nums[0..i]`）
