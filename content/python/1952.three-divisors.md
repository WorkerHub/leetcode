## 题目描述

给你一个整数 `n`，若 `n` 恰好有**三个**正因子（包括 1 和 n 本身），返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：n = 2
输出：false
解释：2 的因子是 1 和 2，只有 2 个因子
```

**示例 2：**
```
输入：n = 4
输出：true
解释：4 的因子是 1、2、4，恰好 3 个
```

**提示：**
- `1 <= n <= 10^4`

---

## 解题思路

### 核心思想：恰好 3 个因子等价于 n 是质数的平方

一个数恰好有 3 个因子，当且仅当它是**某个质数 p 的平方**（n = p²），因子为 1、p、p²。

**验证：** 枚举 1 到 sqrt(n)，统计因子个数是否等于 3。

---

## 代码实现

### 方法一：数学（质数平方）

```python
import math

class Solution:
    def isThree(self, n: int) -> bool:
        # n = p^2 时有 3 个因子（1, p, p²）
        sqrt_n = int(math.isqrt(n))
        if sqrt_n * sqrt_n != n:
            return False
        # 检查 sqrt_n 是否为质数
        if sqrt_n < 2:
            return False
        for i in range(2, int(math.isqrt(sqrt_n)) + 1):
            if sqrt_n % i == 0:
                return False
        return True
```

### 方法二：枚举因子（直接统计）

```python
class Solution:
    def isThree(self, n: int) -> bool:
        # 统计 n 的因子数量
        count = 0
        for i in range(1, n + 1):
            if n % i == 0:
                count += 1
        return count == 3
```

### 方法三：优化枚举（O(sqrt(n))）

```python
import math

class Solution:
    def isThree(self, n: int) -> bool:
        count = 0
        for i in range(1, int(math.isqrt(n)) + 1):
            if n % i == 0:
                count += 1
                if i != n // i:
                    count += 1
        return count == 3
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（数学） | O(sqrt(n)) | O(1) |
| 方法二（暴力） | O(n) | O(1) |
| 方法三（优化） | O(sqrt(n)) | O(1) |

---

## 关键点总结

1. 恰好 3 个因子的充要条件：n = p²（p 为质数）
2. 三个因子分别为：1、p、p²
3. 先判断 n 是否为完全平方数，再判断其平方根是否为质数

---

## 易错点

- n=1 只有 1 个因子，不满足
- `math.isqrt(n)` 精确整数平方根，比 `int(math.sqrt(n))` 更安全
