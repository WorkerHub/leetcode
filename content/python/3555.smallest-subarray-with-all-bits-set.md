## 题目描述

给定一个正整数数组 `nums` 和整数 `k`。找出最短的子数组，使得子数组中所有元素按位 OR 的结果等于 `k`（即包含 `k` 的所有设置位）。返回该子数组的长度，若不存在则返回 `-1`。

**示例 1：**

```
输入：nums = [1, 2, 3], k = 3
输出：1
解释：子数组 [3] 的 OR = 3 = k，长度为1。
```

**示例 2：**

```
输入：nums = [1, 2, 4], k = 7
输出：3
解释：必须取全部三个元素，1|2|4 = 7 = k，长度为3。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

滑动窗口。

先检查整个数组的 OR 是否包含 k 的所有位（若不包含，返回 -1）。

使用双指针（滑动窗口）：
- 右指针右移，将 OR 值更新
- 当 OR 值 & k == k（包含 k 的所有位）时，尝试左指针右移缩小窗口
- 但 OR 是"只增不减"的，左指针右移后需要重新计算 OR 值

维护窗口内每个 bit 的出现次数，左指针右移时，若某个 bit 的计数变为 0，则该 bit 从 OR 中消失。

## Python 代码实现

### 方法一：滑动窗口 + bit 计数（推荐）

```python
from typing import List

class Solution:
    def smallestSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 检查整体 OR 是否包含 k
        if not (eval('|'.join(map(str, nums))) & k == k):
            total_or = 0
            for x in nums:
                total_or |= x
            if total_or & k != k:
                return -1

        # 滑动窗口：维护每个 bit 的出现次数
        bit_count = [0] * 30
        window_or = 0
        left = 0
        ans = n + 1

        for right in range(n):
            x = nums[right]
            # 更新 bit 计数
            for b in range(30):
                if x >> b & 1:
                    bit_count[b] += 1
                    window_or |= (1 << b)

            # 若当前窗口 OR 包含 k，尝试缩小
            while window_or & k == k:
                ans = min(ans, right - left + 1)
                y = nums[left]
                for b in range(30):
                    if y >> b & 1:
                        bit_count[b] -= 1
                        if bit_count[b] == 0:
                            window_or &= ~(1 << b)
                left += 1

        return ans if ans <= n else -1
```

### 方法二：暴力枚举（适合小数据）

```python
from typing import List

class Solution:
    def smallestSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = n + 1

        for i in range(n):
            cur_or = 0
            for j in range(i, n):
                cur_or |= nums[j]
                if cur_or & k == k:
                    ans = min(ans, j - i + 1)
                    break

        return ans if ans <= n else -1
```

## 复杂度分析

- 时间复杂度：O(n * 30)（方法一），O(n^2)（方法二）
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. OR 操作只增不减，需要用 bit 计数跟踪每个位是否还在窗口中
2. 窗口缩小时，若某位计数变 0，该位从 OR 值中消失
3. 条件是 `window_or & k == k`（包含 k 的所有位，不要求等于 k）

## 易错点

1. 条件是 OR 包含 k 的所有位（`& k == k`），而不是 OR 等于 k
2. 需要先检查整个数组的 OR 是否包含 k
3. bit 位数根据数据范围确定（nums[i] <= 10^9，用 30 位足够）
