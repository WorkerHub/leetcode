## 题目描述

给你一个下标从 0 开始的整数数组 `nums`（长度为 `n`）和一个整数 `m` 的数组 `queries`。

对于第 `i` 次查询 `queries[i] = [x_i, y_i]`，计算索引 `x_i, x_i + y_i, x_i + 2*y_i, ...` 处的元素之和（即以步长 `y_i` 从 `x_i` 开始的所有合法索引处元素之和）。

返回一个 `m` 长度的数组 `ans`，其中 `ans[i]` 是第 `i` 次查询的结果，所有答案取模 `10^9 + 7`。

**示例 1：**
```
输入：nums = [0,1,2,3,4,5,6,7], queries = [[0,3],[5,1],[4,2]]
输出：[9,18,10]
```

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 10^9`
- `1 <= m <= 1500`
- `0 <= x_i < nums.length`
- `1 <= y_i <= 5 * 10^4`

## 解题思路

**分类讨论（根号分治）**：
- 设阈值 `T = sqrt(n)`
- 若 `y >= T`：步长大，序列长度 <= sqrt(n)，直接暴力求和即可
- 若 `y < T`：步长小，预处理。对每个步长 `y`（1 到 T-1），用动态规划从右到左预计算后缀和 `dp[y][i]` = 从 i 开始步长 y 的元素之和

## 代码实现

### 方法一：根号分治 + 预处理（推荐）

```python
from typing import List
import math

class Solution:
    def solve(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7
        n = len(nums)
        T = int(math.sqrt(n)) + 1  # 阈值
        
        # 预处理步长 < T 的情况
        # dp[y][i] = nums[i] + nums[i+y] + nums[i+2y] + ...
        # 从右到左递推：dp[y][i] = nums[i] + dp[y][i+y] (若 i+y < n)
        dp = [[0] * n for _ in range(T)]
        for y in range(1, T):
            for i in range(n - 1, -1, -1):
                dp[y][i] = nums[i]
                if i + y < n:
                    dp[y][i] = (dp[y][i] + dp[y][i + y]) % MOD
        
        ans = []
        for x, y in queries:
            if y < T:
                # 直接查预处理结果
                ans.append(dp[y][x])
            else:
                # 步长大，暴力求和（步数最多 n/T ≈ sqrt(n)）
                total = 0
                idx = x
                while idx < n:
                    total = (total + nums[idx]) % MOD
                    idx += y
                ans.append(total)
        
        return ans
```

### 方法二：暴力（适合数据小时验证）

```python
from typing import List

class Solution:
    def solve(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7
        n = len(nums)
        ans = []
        
        for x, y in queries:
            total = 0
            idx = x
            while idx < n:
                total = (total + nums[idx]) % MOD
                idx += y
            ans.append(total)
        
        return ans
```

## 复杂度分析

- **方法一**：
  - 预处理：O(T * n) = O(n * sqrt(n))
  - 每次查询：O(sqrt(n))（y >= T 时）或 O(1)（y < T 时）
  - 总时间：O(n * sqrt(n) + m * sqrt(n))
  - 空间：O(T * n) = O(n * sqrt(n))
- **方法二**：时间 O(m * n)，空间 O(1)

## 关键点总结

1. 根号分治：大步长直接暴力，小步长预处理
2. 预处理用后缀和思路（从右到左）
3. 阈值 T 取 sqrt(n) 使两种情况时间复杂度均衡

## 易错点

- 预处理时注意 `i + y` 的越界判断
- 答案对 `10^9 + 7` 取余
