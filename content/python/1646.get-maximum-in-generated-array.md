## 题目描述

给你一个整数 `n`，按下述规则生成一个长度为 `n + 1` 的数组 `nums`：
- `nums[0] = 0`
- `nums[1] = 1`
- 当 `2 <= 2 * i <= n` 时，`nums[2 * i] = nums[i]`
- 当 `2 <= 2 * i + 1 <= n` 时，`nums[2 * i + 1] = nums[i] + nums[i + 1]`

返回生成数组 `nums` 中的**最大值**。

**示例：**
```
输入：n = 7
输出：3
解释：nums = [0,1,1,2,1,3,2,3]，最大值为 3
```

## 解题思路

按照规则直接模拟生成数组即可，然后返回最大值。

## 代码实现

### 方法一：直接模拟（推荐）

```python
class Solution:
    def getMaximumGenerated(self, n: int) -> int:
        if n == 0:
            return 0
        
        nums = [0] * (n + 1)
        nums[0] = 0
        if n >= 1:
            nums[1] = 1
        
        for i in range(1, n // 2 + 1):
            # nums[2*i] = nums[i]
            if 2 * i <= n:
                nums[2 * i] = nums[i]
            # nums[2*i+1] = nums[i] + nums[i+1]
            if 2 * i + 1 <= n:
                nums[2 * i + 1] = nums[i] + nums[i + 1]
        
        return max(nums)
```

### 方法二：递归（带记忆化）

```python
from functools import lru_cache

class Solution:
    def getMaximumGenerated(self, n: int) -> int:
        @lru_cache(maxsize=None)
        def get(i: int) -> int:
            if i == 0:
                return 0
            if i == 1:
                return 1
            if i % 2 == 0:
                return get(i // 2)
            else:
                return get(i // 2) + get(i // 2 + 1)
        
        return max(get(i) for i in range(n + 1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接模拟 | O(n) | O(n) |
| 记忆化递归 | O(n) | O(n) |

## 关键点总结

1. 直接按定义模拟即可，无需额外技巧
2. 特殊处理 n=0 和 n=1 的边界情况
3. 迭代生成比递归更直观且无递归栈开销

## 易错点

- n=0 时只有 `nums[0]=0`，返回 0
- 注意下标越界：检查 `2*i <= n` 和 `2*i+1 <= n`
