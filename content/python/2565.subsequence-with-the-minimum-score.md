## 题目描述

给你两个字符串 `s` 和 `t`。

在一次操作中，你可以从字符串 `t` 中删除任意字符。

返回需要删除的 **最少字符数**，使得 `t` 成为 `s` 的子序列。

（等价于：`t` 的得分 = 删除后 `t` 变为 `s` 子序列所需最少删除数 = |t| - 最长能成为 `s` 子序列的 `t` 子序列长度）

等价于：找 `t` 中最长的子序列，使其为 `s` 的子序列。答案 = `|t| - 最长子序列长度`。

但题目要求删除"连续子串"，即删除 `t[l..r]` 后 `t` 的前缀 + 后缀能成为 `s` 的子序列。

**提示：**

- `1 <= s.length, t.length <= 10^5`

## 解题思路

**二分 + 前缀后缀匹配**：

预计算：
- `pre[i]`：t[0..i] 匹配 s 的前缀，最多能匹配到 s 的哪个位置（从左往右）
- `suf[i]`：t[i..m-1] 匹配 s 的后缀，最少需要从 s 的哪个位置开始（从右往左）

枚举删除 t[l..r]：t[0..l-1] 用前 pre 匹配 s 的前缀，t[r+1..m-1] 用后 suf 匹配 s 的后缀。

二分删除区间长度，验证是否合法。

## Python 代码实现

### 方法一：预计算前缀后缀 + 枚举（推荐）

```python
class Solution:
    def minimumScore(self, s: str, t: str) -> int:
        m, n = len(t), len(s)

        # pre[i] = t[0..i-1] 能匹配 s 的前几个字符（s 的匹配指针位置）
        pre = [-1] * (m + 1)  # pre[0] = -1（空前缀，s 指针在 -1）
        j = 0
        for i in range(m):
            if j < n and t[i] == s[j]:
                j += 1
            pre[i + 1] = j - 1  # s 中已匹配到位置 j-1

        # suf[i] = t[i..m-1] 匹配 s 的后缀，最少从 s 的位置 suf[i] 开始
        suf = [n] * (m + 1)  # suf[m] = n（空后缀，s 指针在 n）
        j = n - 1
        for i in range(m - 1, -1, -1):
            if j >= 0 and t[i] == s[j]:
                j -= 1
            suf[i] = j + 1  # s 中后缀从位置 j+1 开始匹配

        # 二分删除长度
        def feasible(del_len):
            # 删除 t[l..l+del_len-1]，即保留 t[0..l-1] 和 t[l+del_len..m-1]
            for l in range(del_len, m + 1):
                r = l  # 删除 t[l-del_len..l-1]，等价于保留 t[0..l-del_len-1] 和 t[l..m-1]
                # 前缀：t[0..l-del_len-1] 匹配 s 的前缀，到 pre[l-del_len]
                plen = l - del_len
                s_pre_end = pre[plen]  # s 中前缀匹配到 s_pre_end
                # 后缀：t[l..m-1] 匹配 s 的后缀，从 suf[l] 开始
                s_suf_start = suf[l]
                if s_pre_end + 1 <= s_suf_start:
                    return True
            return False

        lo, hi = 0, m
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：直接枚举删除区间

```python
class Solution:
    def minimumScore(self, s: str, t: str) -> int:
        m, n = len(t), len(s)

        # 前缀：pre[i] = t[0..i-1] 在 s 中匹配的最远位置（s 的下标）
        pre = [0] * (m + 1)
        j = 0
        for i in range(m):
            if j < n and t[i] == s[j]:
                j += 1
            pre[i+1] = j

        # 后缀：suf[i] = t[i..m-1] 在 s 中后缀匹配，s 需从 suf[i] 开始
        suf = [n] * (m + 1)
        j = n - 1
        for i in range(m - 1, -1, -1):
            if j >= 0 and t[i] == s[j]:
                j -= 1
            suf[i] = j + 1

        ans = m  # 最多删除 m 个
        # 枚举删除 t[l..r-1]（长度 r-l）
        for l in range(m + 1):
            # 前缀 t[0..l-1] 匹配到 s[pre[l]-1]
            # 后缀 t[l..m-1] 需要 s 从 suf[l] 开始
            # 若 pre[l] <= suf[l]，则合法（无需删除后缀部分）
            # 对不同 r，也可以 binary search
            # 这里简化：找最小 r >= l 使 pre[l] <= suf[r]
            # 使用二分
            import bisect
            suf_vals = [suf[i] for i in range(l, m + 1)]
            # 找最小 r 使 suf[r] >= pre[l]
            # suf 是非递减的（从右往左处理，suf 单调不减）
            # 二分 suf[r] >= pre[l]
            idx = bisect.bisect_left(suf_vals, pre[l])
            r = l + idx
            ans = min(ans, r - l)

        return ans
```

## 复杂度分析

- 时间复杂度：O((m + n) + m log m)，预计算 O(m+n)，枚举二分 O(m log m)
- 空间复杂度：O(m + n)

## 关键点总结

1. 预计算前缀匹配和后缀匹配数组
2. 枚举删除起点 l，用二分找最短合法删除区间
3. suf 数组单调性确保二分正确

## 易错点

1. pre[i] 和 suf[i] 的含义要明确（s 的指针位置）
2. 合法条件：前缀匹配到 pre[l]，后缀从 suf[r] 开始，需 pre[l] <= suf[r]
3. 注意 suf 数组是从右向左处理，具有单调性
