## 题目描述

设计一个电话目录管理系统，让它支持以下功能：

- `PhoneDirectory(int maxNumbers)` 初始化电话目录，最多可以存储 `maxNumbers` 个号码
- `int get()` 获取一个未分配的号码，如果有可用号码则返回该号码，否则返回 -1
- `bool check(int number)` 检查指定的号码是否可用
- `void release(int number)` 释放（回收）一个号码

**示例：**

```
输入：
["PhoneDirectory", "get", "get", "check", "get", "check", "release", "check"]
[[3], [], [], [2], [], [2], [2], [2]]

输出：
[null, 0, 1, true, 2, false, null, true]

解释：
PhoneDirectory phoneDirectory = new PhoneDirectory(3);
phoneDirectory.get();      // 返回 0，可以返回任意可用的号码，这里我们假定第一次调用返回 0
phoneDirectory.get();      // 返回 1
phoneDirectory.check(2);   // 返回 true，号码 2 尚未分配
phoneDirectory.get();      // 返回 2
phoneDirectory.check(2);   // 返回 false，号码 2 已经被分配了
phoneDirectory.release(2); // 释放号码 2
phoneDirectory.check(2);   // 返回 true，号码 2 已经被释放
```

**提示：**
- `1 <= maxNumbers <= 10^4`
- `0 <= number < maxNumbers`
- 调用方法的总次数在 `[0, 10^4]` 范围内

## 解题思路

这道题是一个设计题，需要高效地管理号码的分配和释放。

### 核心需求

1. **get()**：O(1) 获取可用号码
2. **check(number)**：O(1) 检查号码是否可用
3. **release(number)**：O(1) 释放号码

### 设计思路

**方法一：集合 + 队列（推荐）**
- 使用集合存储所有可用号码（快速检查）
- 使用队列维护可用号码（快速获取）

**方法二：布尔数组 + 队列**
- 使用布尔数组标记号码是否可用
- 使用队列存储可用号码

**方法三：位图（进阶）**
- 使用位图压缩存储状态

## Python 代码实现

### 方法一：集合 + 队列（推荐）

```python
from collections import deque

class PhoneDirectory:
    def __init__(self, maxNumbers: int):
        """
        初始化电话目录
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        self.available = set(range(maxNumbers))  # 可用号码集合
        self.queue = deque(range(maxNumbers))    # 可用号码队列
    
    def get(self) -> int:
        """
        获取一个可用号码
        时间复杂度：O(1)
        """
        if not self.queue:
            return -1
        
        number = self.queue.popleft()
        self.available.remove(number)
        return number
    
    def check(self, number: int) -> bool:
        """
        检查号码是否可用
        时间复杂度：O(1)
        """
        return number in self.available
    
    def release(self, number: int) -> None:
        """
        释放号码
        时间复杂度：O(1)
        """
        if number not in self.available:
            self.available.add(number)
            self.queue.append(number)
```

### 方法二：布尔数组 + 队列

```python
from collections import deque

class PhoneDirectory:
    def __init__(self, maxNumbers: int):
        """
        使用布尔数组标记
        """
        self.is_available = [True] * maxNumbers  # 标记数组
        self.queue = deque(range(maxNumbers))    # 可用号码队列
    
    def get(self) -> int:
        """
        获取一个可用号码
        """
        if not self.queue:
            return -1
        
        number = self.queue.popleft()
        self.is_available[number] = False
        return number
    
    def check(self, number: int) -> bool:
        """
        检查号码是否可用
        """
        return self.is_available[number]
    
    def release(self, number: int) -> None:
        """
        释放号码
        """
        if not self.is_available[number]:
            self.is_available[number] = True
            self.queue.append(number)
```

### 方法三：只用集合（简化版）

```python
class PhoneDirectory:
    def __init__(self, maxNumbers: int):
        """
        只使用集合，不用队列
        get() 时直接 pop
        """
        self.available = set(range(maxNumbers))
    
    def get(self) -> int:
        """
        从集合中弹出一个元素
        注意：集合的 pop 是 O(1)，但元素顺序不确定
        """
        if not self.available:
            return -1
        return self.available.pop()
    
    def check(self, number: int) -> bool:
        """
        检查号码是否在集合中
        """
        return number in self.available
    
    def release(self, number: int) -> None:
        """
        将号码加回集合
        """
        self.available.add(number)
```

### 方法四：位图（进阶）

```python
class PhoneDirectory:
    def __init__(self, maxNumbers: int):
        """
        使用位图压缩存储
        每个整数可以存储 32 个号码的状态
        """
        self.max_numbers = maxNumbers
        # 需要多少个整数来存储所有号码
        self.bitmap_size = (maxNumbers + 31) // 32
        self.bitmap = [(1 << 32) - 1] * self.bitmap_size  # 初始全为 1（可用）
        self.next_available = 0  # 下一个可能可用的号码
    
    def get(self) -> int:
        """
        获取可用号码
        """
        # 从 next_available 开始查找
        for i in range(self.next_available, self.max_numbers):
            if self._is_available(i):
                self._set_unavailable(i)
                self.next_available = i + 1
                return i
        
        # 从头再找一遍
        for i in range(self.next_available):
            if self._is_available(i):
                self._set_unavailable(i)
                return i
        
        return -1
    
    def check(self, number: int) -> bool:
        """
        检查号码是否可用
        """
        return self._is_available(number)
    
    def release(self, number: int) -> None:
        """
        释放号码
        """
        self._set_available(number)
        self.next_available = min(self.next_available, number)
    
    def _is_available(self, number: int) -> bool:
        """
        检查位图中某位是否为 1
        """
        idx = number // 32
        bit = number % 32
        return (self.bitmap[idx] & (1 << bit)) != 0
    
    def _set_unavailable(self, number: int) -> None:
        """
        将位图中某位设为 0
        """
        idx = number // 32
        bit = number % 32
        self.bitmap[idx] &= ~(1 << bit)
    
    def _set_available(self, number: int) -> None:
        """
        将位图中某位设为 1
        """
        idx = number // 32
        bit = number % 32
        self.bitmap[idx] |= (1 << bit)
```

## 复杂度分析

### 方法一/二：集合 + 队列
- `__init__`：O(n) 时间，O(n) 空间
- `get`：O(1) 时间
- `check`：O(1) 时间
- `release`：O(1) 时间
- 空间复杂度：O(n)

### 方法三：只用集合
- 时间复杂度：所有操作 O(1)
- 空间复杂度：O(n)

### 方法四：位图
- 时间复杂度：
  - `get`：最坏 O(n)，平均 O(1)
  - `check`：O(1)
  - `release`：O(1)
- 空间复杂度：O(n/32)，节省空间

## 关键点总结

1. **数据结构选择**：
   - 集合：快速查找和删除
   - 队列：快速获取下一个可用号码
   - 位图：节省空间
2. **操作效率**：所有操作都应该是 O(1)
3. **释放检查**：释放前要检查号码是否已被分配
4. **空间优化**：位图可以大幅减少空间占用
5. **边界处理**：没有可用号码时返回 -1

## 易错点

1. **重复释放**：释放已经可用的号码，要避免重复加入队列
2. **越界检查**：虽然题目保证输入合法，但实际应用中要检查
3. **初始化**：确保所有号码初始都是可用的
4. **集合 pop**：集合的 pop 顺序不确定，可能不是先进先出
5. **位图边界**：位图大小要正确计算
