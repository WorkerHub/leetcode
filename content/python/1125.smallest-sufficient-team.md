## 题目描述

公司需要组建一个小团队来完成某个项目。给定一个技能列表 `req_skills` 和一个人员列表 `people`，其中 `people[i]` 表示第 i 个人拥有的技能集合。

你需要返回一个足够的人的下标列表，使得这些人的技能集合包含所有必需的技能。可以保证答案存在。

如果有多个答案，返回其中任何一个即可。但是，你应该返回人数最少的团队（即最小的团队）。

**示例 1：**
```
输入：req_skills = ["java","nodejs","reactjs"], people = [["java"],["nodejs"],["nodejs","reactjs"]]
输出：[0,2]
```

**示例 2：**
```
输入：req_skills = ["algorithms","math","java","reactjs","csharp","aws"], people = [["algorithms","math","java"],["algorithms","math","reactjs"],["java","csharp","aws"],["reactjs","csharp"],["csharp","math"],["aws","java"]]
输出：[1,2]
```

**提示：**
- `1 <= req_skills.length <= 16`
- `1 <= req_skills[i].length <= 16`
- `req_skills[i]` 由小写英文字母组成
- `req_skills` 中的所有字符串互不相同
- `1 <= people.length <= 60`
- `0 <= people[i].length <= 16`
- `1 <= people[i][j].length <= 16`
- `people[i][j]` 由小写英文字母组成
- `people[i]` 中的所有字符串互不相同
- `people[i]` 中的每个技能都是 `req_skills` 中的技能
- 题目保证有足够的人覆盖所有技能

## 解题思路

这是一个经典的**集合覆盖问题**，需要用最少的人覆盖所有技能。由于技能数量最多 16 个，我们可以使用**状态压缩动态规划**。

### 核心思想

1. **状态压缩**：用一个整数的二进制位表示技能集合，第 i 位为 1 表示拥有第 i 个技能
2. **动态规划**：`dp[state]` 表示达到状态 state（拥有某些技能）所需的最小团队
3. **状态转移**：遍历每个人，尝试将其加入团队，更新能达到的新状态

### 算法流程

1. 将技能列表转换为技能到索引的映射
2. 将每个人的技能集合转换为二进制状态
3. 使用 DP 遍历所有可能的状态，记录最小团队
4. 返回覆盖所有技能的最小团队

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def smallestSufficientTeam(self, req_skills: List[str], people: List[List[str]]) -> List[int]:
        # 技能总数
        n = len(req_skills)
        # 技能名称到索引的映射
        skill_to_idx = {skill: i for i, skill in enumerate(req_skills)}
        
        # 将每个人的技能转换为二进制状态
        people_skills = []
        for person in people:
            skill_mask = 0
            for skill in person:
                skill_mask |= (1 << skill_to_idx[skill])
            people_skills.append(skill_mask)
        
        # dp[state] = 达到状态 state 的最小团队（存储人员索引列表）
        # 目标状态：所有技能都被覆盖，即 (1 << n) - 1
        target = (1 << n) - 1
        
        # 初始化 DP 数组
        dp = {0: []}  # 初始状态：没有技能，团队为空
        
        # 遍历每个人
        for i, skill_mask in enumerate(people_skills):
            # 如果这个人没有任何技能，跳过
            if skill_mask == 0:
                continue
            
            # 遍历当前所有已知状态（需要复制，因为会修改字典）
            for cur_state in list(dp.keys()):
                # 加入第 i 个人后的新状态
                new_state = cur_state | skill_mask
                
                # 如果新状态还未记录，或者新团队更小，则更新
                if new_state not in dp or len(dp[new_state]) > len(dp[cur_state]) + 1:
                    dp[new_state] = dp[cur_state] + [i]
        
        return dp[target]
```

### 方法二：优化的状态压缩 DP

```python
from typing import List

class Solution:
    def smallestSufficientTeam(self, req_skills: List[str], people: List[List[str]]) -> List[int]:
        n = len(req_skills)
        skill_to_idx = {skill: i for i, skill in enumerate(req_skills)}
        
        # 将每个人的技能转换为二进制状态
        people_skills = []
        for person in people:
            skill_mask = 0
            for skill in person:
                skill_mask |= (1 << skill_to_idx[skill])
            people_skills.append(skill_mask)
        
        target = (1 << n) - 1
        
        # 使用数组代替字典，索引即为状态
        # dp[state] = (team_size, team_members)
        INF = float('inf')
        dp = [(INF, [])] * (1 << n)
        dp[0] = (0, [])
        
        for i, skill_mask in enumerate(people_skills):
            if skill_mask == 0:
                continue
            
            # 从后向前遍历，避免重复使用同一个人
            for state in range((1 << n) - 1, -1, -1):
                if dp[state][0] == INF:
                    continue
                
                new_state = state | skill_mask
                new_size = dp[state][0] + 1
                
                if new_size < dp[new_state][0]:
                    dp[new_state] = (new_size, dp[state][1] + [i])
        
        return dp[target][1]
```

### 方法三：BFS 搜索（简化理解版）

```python
from typing import List
from collections import deque

class Solution:
    def smallestSufficientTeam(self, req_skills: List[str], people: List[List[str]]) -> List[int]:
        n = len(req_skills)
        skill_to_idx = {skill: i for i, skill in enumerate(req_skills)}
        
        # 将每个人的技能转换为二进制状态
        people_skills = []
        for person in people:
            skill_mask = 0
            for skill in person:
                skill_mask |= (1 << skill_to_idx[skill])
            people_skills.append(skill_mask)
        
        target = (1 << n) - 1
        
        # BFS：队列存储 (当前状态, 团队成员列表)
        queue = deque([(0, [])])
        visited = {0}
        
        while queue:
            cur_state, team = queue.popleft()
            
            # 如果已经覆盖所有技能
            if cur_state == target:
                return team
            
            # 尝试加入每个人
            for i, skill_mask in enumerate(people_skills):
                new_state = cur_state | skill_mask
                
                # 如果新状态未访问过
                if new_state not in visited:
                    visited.add(new_state)
                    queue.append((new_state, team + [i]))
        
        return []
```

## 复杂度分析

### 方法一：状态压缩 DP

- **时间复杂度**：O(2^n × m)，其中 n 是技能数（最多 16），m 是人数（最多 60）。最多有 2^n 个状态，每个状态需要尝试 m 个人。
- **空间复杂度**：O(2^n × m)，需要存储每个状态对应的团队成员列表。

### 方法二：优化版本

- **时间复杂度**：O(2^n × m)
- **空间复杂度**：O(2^n × m)

### 方法三：BFS

- **时间复杂度**：O(2^n × m)，最坏情况下需要遍历所有状态。
- **空间复杂度**：O(2^n × m)

## 关键点总结

1. **状态压缩技巧**：用整数的二进制位表示集合，第 i 位为 1 表示包含第 i 个元素
2. **位运算操作**：
   - `|` (或运算)：合并两个集合
   - `&` (与运算)：求交集
   - `1 << i`：表示只有第 i 位为 1 的数
3. **DP 状态设计**：`dp[state]` 记录达到该状态的最优解（最小团队）
4. **剪枝优化**：只更新能得到更小团队的状态
5. **技能数量限制**：题目限制技能数 ≤ 16，使得状态压缩可行（2^16 = 65536）

## 易错点

1. **技能映射错误**：必须先将技能名称映射到索引（0 到 n-1），才能进行位运算
2. **状态遍历顺序**：在方法二中，需要从后向前遍历状态，避免重复使用同一个人
3. **空技能处理**：有些人可能没有任何必需技能，需要跳过这些人
4. **DP 初始化**：初始状态 dp[0] = [] 表示没有技能时团队为空
5. **目标状态计算**：目标是 `(1 << n) - 1`，即所有 n 位都为 1 的二进制数
