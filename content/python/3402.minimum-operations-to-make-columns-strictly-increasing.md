## 题目描述

给你一个 `m x n` 的非负整数矩阵 `grid`。

一次操作中，你可以将任意元素 `grid[i][j]` 增加 `1`。

返回使每一列严格递增所需的**最少操作次数**。

**示例 1：**

```
输入：grid = [[3,2],[1,3],[3,4],[0,1]]
输出：15
```

**示例 2：**

```
输入：grid = [[3,2,1],[2,1,4]]
输出：6
```

**提示：**
- `1 <= m, n <= 50`
- `0 <= grid[i][j] <= 1000`

## 解题思路

贪心策略：对每一列独立处理。从上到下遍历每列，若当前元素不满足 `grid[i][j] > grid[i-1][j]`，则将其增加到 `grid[i-1][j] + 1`，所需操作次数就是增量。

关键观察：每次只需将当前元素调整为前一个元素加 1，这是使列严格递增的最小代价，因为任何更小的目标值都无法满足条件。

## Python 代码实现

### 方法一：贪心逐列扫描（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        total_ops = 0

        for col in range(n):
            for row in range(1, m):
                # 如果当前元素不大于上方元素，需要增加
                if grid[row][col] <= grid[row - 1][col]:
                    # 需要增加到 grid[row-1][col] + 1
                    needed = grid[row - 1][col] + 1
                    total_ops += needed - grid[row][col]
                    # 更新当前元素，供下一行参考
                    grid[row][col] = needed

        return total_ops
```

### 方法二：不修改原数组（使用变量追踪前一行值）

```python
from typing import List

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        total_ops = 0

        for col in range(n):
            # 追踪当前列上一行的实际值（经过调整后）
            prev = grid[0][col]
            for row in range(1, m):
                cur = grid[row][col]
                if cur <= prev:
                    # 必须至少等于 prev + 1
                    total_ops += prev + 1 - cur
                    prev = prev + 1
                else:
                    prev = cur

        return total_ops
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历矩阵每个元素一次
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. 每列独立处理，互不影响
2. 贪心地将当前元素调整为"恰好比前一个元素大 1"是最优策略
3. 调整后的值需要传递给下一行作为参考基准
4. 只能增加元素，不能减少

## 易错点

1. 调整后的 `grid[row][col]` 值（即 `prev`）要用于和下一行比较，而不是原始值
2. 操作次数是 `needed - grid[row][col]`，而不是 `1`
3. 题目要求严格递增，所以目标是 `grid[row-1][col] + 1` 而不是 `grid[row-1][col]`
