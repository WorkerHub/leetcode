## 题目描述

给你一个由非负整数组成的数组 `nums`，另有一个查询数组 `queries`，其中 `queries[i] = [xi, mi]`。

第 `i` 个查询的答案是 `xi` 和任何 `nums` 中不超过 `mi` 的元素按位异或（XOR）得到的最大值。换句话说，答案是 `max(nums[j] XOR xi)` 其中所有 `j` 均满足 `nums[j] <= mi`，如果 `nums` 中所有元素都大于 `mi`，则最终答案是 `-1`。

返回一个整数数组 `answer`，其中 `answer.length == queries.length` 且 `answer[i]` 是第 `i` 个查询的答案。

**示例 1：**
```
输入：nums = [0,1,2,3,4], queries = [[3,1],[1,3],[5,6]]
输出：[3,3,7]
```

**提示：**
- `1 <= nums.length, queries.length <= 10^5`
- `0 <= nums[j], xi, mi <= 10^9`

## 解题思路

**离线排序 + 字典树（Trie）**：

1. 对 `queries` 按 `mi` 排序（离线处理）
2. 对 `nums` 升序排序
3. 用双指针：处理每个查询时，将 `nums` 中 `<= mi` 的数插入字典树
4. 在字典树中查询与 `xi` 异或最大的数

**字典树异或最大值**：从高位到低位，尽量选与当前位不同的分支。

## 代码实现

### 方法一：离线排序 + 字典树（推荐）

```python
from typing import List

class Trie:
    def __init__(self):
        # 每个节点有两个子节点：0 和 1
        self.children = [None, None]
    
    def insert(self, num: int):
        node = self
        # 从高位（第30位）到低位插入
        for i in range(30, -1, -1):
            bit = (num >> i) & 1
            if node.children[bit] is None:
                node.children[bit] = Trie()
            node = node.children[bit]
    
    def query(self, num: int) -> int:
        node = self
        xor_val = 0
        for i in range(30, -1, -1):
            bit = (num >> i) & 1
            # 尽量走与当前位不同的分支（使异或结果为1）
            want = 1 - bit
            if node.children[want] is not None:
                xor_val |= (1 << i)
                node = node.children[want]
            elif node.children[bit] is not None:
                node = node.children[bit]
            else:
                return -1  # 字典树为空
        return xor_val

class Solution:
    def maximizeXor(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        # 对 nums 排序
        nums.sort()
        n_nums = len(nums)
        
        # 对 queries 按 mi 排序，同时记录原始下标
        indexed_queries = sorted(enumerate(queries), key=lambda x: x[1][1])
        
        trie = Trie()
        ans = [-1] * len(queries)
        j = 0  # nums 的指针
        
        for orig_idx, (xi, mi) in indexed_queries:
            # 将所有 <= mi 的 nums 插入字典树
            while j < n_nums and nums[j] <= mi:
                trie.insert(nums[j])
                j += 1
            
            # 如果字典树不为空（有合法元素），查询最大异或值
            if j > 0:
                ans[orig_idx] = trie.query(xi)
        
        return ans
```

### 方法二：暴力枚举（适合小数据理解）

```python
from typing import List

class Solution:
    def maximizeXor(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        ans = []
        for xi, mi in queries:
            best = -1
            for num in nums:
                if num <= mi:
                    best = max(best, xi ^ num)
            ans.append(best)
        return ans
```

## 复杂度分析

- **方法一**：
  - 时间复杂度：O((n + q) log max_val)，排序 O(n log n + q log q)，字典树操作 O(31)
  - 空间复杂度：O(n * 31)
- **方法二**：
  - 时间复杂度：O(n * q)
  - 空间复杂度：O(1)

## 关键点总结

1. 离线处理：对查询按上界排序，用双指针维护满足条件的元素集合
2. 字典树存储数字的二进制，支持高效的最大异或查询
3. 查询时贪心：每一位尽量选与目标不同的方向

## 易错点

- 数字范围最大 10^9，需要用 31 位（而非 32 位）来表示
- 字典树为空时要返回 -1
