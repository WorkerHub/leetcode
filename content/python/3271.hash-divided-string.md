## 题目描述

给你一个字符串 `s` 和一个正整数 `k`，你的任务是哈希该字符串。

哈希过程如下：
1. 将字符串 `s` 分成每段长度为 `k` 的子字符串（最后一段可能不足 k 个字符，但题目保证 `s.length` 是 `k` 的倍数）
2. 对每段，将其中每个字符的值（a=0, b=1, ..., z=25）求和，再对 26 取模，得到对应字母
3. 将所有结果字母拼接成哈希值

**示例 1：**
```
输入：s = "abcd", k = 2
输出："bf"
解释：
"ab" -> (0+1) % 26 = 1 -> 'b'
"cd" -> (2+3) % 26 = 5 -> 'f'
输出 "bf"
```

**示例 2：**
```
输入：s = "mxz", k = 3
输出："m"
```

**提示：**
- `1 <= k <= 100`
- `k <= s.length <= 1000`
- `s.length % k == 0`
- `s` 只含小写字母

## 解题思路

按 k 分组，每组求字符值之和对 26 取模，转换回字母。

## Python 代码实现

### 方法一：逐段处理（推荐）

```python
class Solution:
    def stringHash(self, s: str, k: int) -> str:
        result = []
        n = len(s)
        for i in range(0, n, k):
            # 当前段
            segment = s[i:i + k]
            # 求和后取模
            total = sum(ord(c) - ord('a') for c in segment) % 26
            result.append(chr(total + ord('a')))
        return ''.join(result)
```

### 方法二：列表推导

```python
class Solution:
    def stringHash(self, s: str, k: int) -> str:
        return ''.join(
            chr(sum(ord(c) - ord('a') for c in s[i:i+k]) % 26 + ord('a'))
            for i in range(0, len(s), k)
        )
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n/k)

## 关键点总结

1. 按 k 分组，每组独立处理
2. 字符值：'a'=0, ..., 'z'=25
3. 求和 mod 26 得到新字符

## 易错点

1. 字符值从 0 开始，不是从 'a' 的 ASCII 值
2. 使用 `ord(c) - ord('a')` 获取 0-25 的值
