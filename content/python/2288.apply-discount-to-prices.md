## 题目描述

给你一个字符串 `sentence`，代表一条购物清单，其中包含以空格分隔的单词。每个以 `'$'` 开头的单词表示价格。

给你一个整数 `discount`，将每个价格打折 `discount%`，然后返回修改后的句子。

**注意：** 所有价格最多保留 **两位小数**（使用 `f` 字符串格式化为 `$xxx.xx`）。

**示例 1：**
```
输入：sentence = "there are $1 $2 and 5$ candies in the shop", discount = 50
输出："there are $0.50 $1.00 and 5$ candies in the shop"
```

**示例 2：**
```
输入：sentence = "1 2 $3 4 $10 $100 195 $40", discount = 0
输出："1 2 $3.00 4 $10.00 $100.00 195 $40.00"
```

## 解题思路

按空格分割句子，对每个单词：
- 若以 `'$'` 开头且后续部分是有效数字，计算折后价格 = `price * (1 - discount/100)`，格式化为 `$%.2f`。
- 否则保持原样。

## 代码实现

### 方法一：split + 逐词处理（推荐）

```python
class Solution:
    def discountPrices(self, sentence: str, discount: int) -> str:
        words = sentence.split()
        result = []

        for word in words:
            if word[0] == '$' and len(word) > 1 and word[1:].isdigit():
                # 是价格标签
                price = int(word[1:])
                discounted = price * (100 - discount) / 100
                result.append(f'${discounted:.2f}')
            else:
                result.append(word)

        return ' '.join(result)
```

### 方法二：正则表达式

```python
import re

class Solution:
    def discountPrices(self, sentence: str, discount: int) -> str:
        def replace(m):
            price = int(m.group(1))
            discounted = price * (100 - discount) / 100
            return f'${discounted:.2f}'

        # 匹配以 $ 开头后跟纯数字的单词（词边界确保前面是空格或开头）
        return re.sub(r'(?<!\S)\$(\d+)(?!\S)', replace, sentence)
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度。
- 空间复杂度：O(n)，存储结果列表。

## 关键点总结

1. 判断价格单词：以 `'$'` 开头，且去掉 `$` 后的部分是纯数字（`isdigit()`）。
2. 折扣计算：`price * (100 - discount) / 100`。
3. 格式化保留两位小数：`f'${value:.2f}'`。

## 易错点

- `'$5'` 是价格，`'5$'` 不是（`$` 在末尾不算）。
- `word[1:].isdigit()` 要确保 `len(word) > 1`，即 `'$'` 后面有内容。
- 浮点精度：Python 的 `:.2f` 会四舍五入，满足题目要求。
