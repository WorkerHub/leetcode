## 题目描述

你站在 `-1` 位置，有一个容量为 `capacity` 的水壶。花园里有 `n` 株植物，第 `i` 株植物在位置 `i`，需要 `plants[i]` 单位的水。

每次从左往右浇水，到达植物 `i` 时，如果水壶里的水不够，就先回到 `-1` 处重新装满（花费来回的步数），然后继续前进浇水。

返回浇完所有植物所需的**总步数**。

**示例：**
```
输入：plants = [2,2,3,3], capacity = 5
输出：14
解释：
- 从 -1 出发，走 1 步到植物 0 浇水（壶还剩 3）
- 走 1 步到植物 1 浇水（壶还剩 1）
- 水不够（需要 3），走 2 步回 -1，再走 3 步到植物 2 浇水（壶剩 2）
- 走 1 步到植物 3 浇水
- 共 1+1+2+3+1 = 14（实际 1+1+(2+3)+1+...，见解析）
```

**提示：**
- `n == plants.length`
- `1 <= n <= 1000`
- `1 <= plants[i] <= 10^6`
- `max(plants[i]) <= capacity <= 10^9`

## 解题思路

**模拟：** 直接按题目描述模拟每步操作：

- 当前位置 `pos`，当前水量 `water`
- 到达每株植物前检查水是否够，不够则回到 -1 重新装满
- 累计步数

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def wateringPlants(self, plants: List[int], capacity: int) -> int:
        steps = 0
        water = capacity  # 初始满壶
        pos = -1  # 当前位置

        for i, need in enumerate(plants):
            # 走到植物 i 的位置
            if water < need:
                # 水不够，回到 -1 重新装满
                steps += pos - (-1)  # 从 pos 回到 -1
                water = capacity
                pos = -1

            # 从 pos 走到 i
            steps += i - pos
            pos = i
            water -= need

        return steps
```

### 方法二：公式计算

```python
from typing import List

class Solution:
    def wateringPlants(self, plants: List[int], capacity: int) -> int:
        steps = 0
        water = capacity
        n = len(plants)

        for i in range(n):
            if water < plants[i]:
                # 来回步数：从 i-1 回到 -1 再到 i，共 2*i 步（替代正向的 1 步）
                steps += 2 * i  # 去掉原本 1 步，加上来回
                water = capacity
            steps += 1  # 前进 1 步
            water -= plants[i]

        return steps
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每次到达植物前检查水量是否充足
2. 不够时加上"返回取水再回来"的额外步数
3. 最终答案包含所有向前走的步数和补充取水的来回步数

## 易错点

- 方法二中，当需要返回时，额外步数是 `2*i`（而非 `2*(i+1)`），因为正向那 1 步已经在 `steps += 1` 中计入
- 水量更新要在每次浇水后进行
- 初始在 `-1` 位置，不是 `0`
