## 题目描述

给定整数 `n`，每次操作可以将 `n` 加 1 或减 1，求使 `n` 变为素数所需的最少操作次数。

**示例 1：**
```
输入：n = 10
输出：1
解释：10 - 1 = 9（不是素数），10 + 1 = 11（是素数），最少 1 次操作。
```

**示例 2：**
```
输入：n = 15
输出：2
解释：15 -> 13（-2），15 -> 17（+2），最少 2 次操作。
```

**提示：**
- `1 <= n <= 10^6`

## 解题思路

简单贪心：从 `n` 出发，向两侧搜索最近的素数。

分别向上和向下找最近的素数，取步数较小的那个。

素数判断：对于 `x`，只需检查 2 到 `sqrt(x)` 内是否有因数。

## Python 代码实现

### 方法一：双向搜索（推荐）

```python
import math

class Solution:
    def minOperations(self, n: int) -> int:
        def is_prime(x: int) -> bool:
            if x < 2:
                return False
            if x == 2:
                return True
            if x % 2 == 0:
                return False
            for i in range(3, int(math.sqrt(x)) + 1, 2):
                if x % i == 0:
                    return False
            return True

        # 向下搜索
        lo = n
        while lo >= 2 and not is_prime(lo):
            lo -= 1

        # 向上搜索
        hi = n
        while not is_prime(hi):
            hi += 1

        # 取最近的素数
        if lo < 2:
            return hi - n
        return min(n - lo, hi - n)
```

### 方法二：埃拉托斯特尼筛法预处理

```python
class Solution:
    def minOperations(self, n: int) -> int:
        # 预处理到 n + 1000 范围内的素数（保证能找到上界）
        limit = n + 1000
        is_prime = [True] * (limit + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(limit**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, limit + 1, i):
                    is_prime[j] = False

        # 向下找
        lo_dist = float('inf')
        for x in range(n, 1, -1):
            if is_prime[x]:
                lo_dist = n - x
                break

        # 向上找
        hi_dist = 0
        for x in range(n, limit + 1):
            if is_prime[x]:
                hi_dist = x - n
                break

        return min(lo_dist, hi_dist)
```

## 复杂度分析

- 时间复杂度：方法一 O(sqrt(n) * gap)，gap 为到最近素数的距离（通常很小）；方法二 O(n log log n) 预处理
- 空间复杂度：方法一 O(1)；方法二 O(n)

## 关键点总结

1. 素数间隔：对于较大的数，相邻素数间隔通常为 2（孪生素数）或更小
2. 双向搜索：同时向上和向下找，取最近的
3. 素数判断：只需检查到 `sqrt(x)`

## 易错点

1. `n = 2` 时已经是素数，操作次数为 0
2. 向下搜索时不能低于 2（最小素数）
