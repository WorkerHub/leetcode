## 题目描述

给你一个字符串 `s`、字符串 `a`、字符串 `b` 和整数 `k`。

如果下标 `i` 满足以下条件，则认为该下标是 **美丽下标**：
- `0 <= i <= len(s) - len(a)`
- `s[i..i+len(a)-1] == a`
- 存在下标 `j` 使得 `s[j..j+len(b)-1] == b`，且 `|i - j| <= k`

以升序方式返回所有美丽下标。

**与 3006 的区别：** 本题数据范围更大，`s.length` 达到 `5 * 10^5`，要求更高效的算法。

**提示：**
- `1 <= k <= s.length <= 5 * 10^5`
- `1 <= a.length, b.length <= 5 * 10^5`
- `s`、`a`、`b` 只包含小写英文字母

## 解题思路

与 3006 相同，但数据量更大，必须使用 O(n) 的 KMP 算法找所有匹配位置，再用双指针或二分查找配对。

**KMP 算法步骤：**
1. 构建模式串的失配函数（prefix function）
2. 利用失配函数在文本串中线性扫描，记录所有匹配起始位置

**双指针步骤：**
- `posA` 和 `posB` 均有序
- 用双指针在 `posB` 中维护满足 `|i - j| <= k` 的最左合法位置

## Python 代码实现

### 方法一：KMP + 双指针（推荐）

```python
from typing import List

class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        def compute_fail(pattern: str) -> List[int]:
            """构建 KMP 失配表（前缀函数）"""
            m = len(pattern)
            fail = [0] * m
            j = 0
            for i in range(1, m):
                while j > 0 and pattern[i] != pattern[j]:
                    j = fail[j - 1]
                if pattern[i] == pattern[j]:
                    j += 1
                fail[i] = j
            return fail

        def kmp_search(text: str, pattern: str) -> List[int]:
            """KMP 搜索，返回所有匹配起始位置"""
            if not pattern:
                return []
            fail = compute_fail(pattern)
            m = len(pattern)
            positions = []
            j = 0
            for i, c in enumerate(text):
                while j > 0 and c != pattern[j]:
                    j = fail[j - 1]
                if c == pattern[j]:
                    j += 1
                if j == m:
                    positions.append(i - m + 1)
                    j = fail[j - 1]
            return positions

        posA = kmp_search(s, a)
        posB = kmp_search(s, b)

        result = []
        ptr = 0  # posB 的双指针

        for i in posA:
            # 推进 ptr 直到 posB[ptr] >= i - k
            while ptr < len(posB) and posB[ptr] < i - k:
                ptr += 1
            # 检查 posB[ptr] <= i + k
            if ptr < len(posB) and posB[ptr] <= i + k:
                result.append(i)

        return result
```

### 方法二：Z 函数方法

```python
from typing import List

class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        def z_function(t: str) -> List[int]:
            """计算 Z 数组：z[i] 为 t[i:] 与 t 的最长公共前缀长度"""
            n = len(t)
            z = [0] * n
            z[0] = n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and t[z[i]] == t[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z

        def find_all(text: str, pattern: str) -> List[int]:
            if len(pattern) > len(text):
                return []
            combined = pattern + '#' + text
            z = z_function(combined)
            m = len(pattern)
            return [i - m - 1 for i in range(m + 1, len(combined)) if z[i] >= m]

        posA = find_all(s, a)
        posB = find_all(s, b)

        result = []
        ptr = 0
        for i in posA:
            while ptr < len(posB) and posB[ptr] < i - k:
                ptr += 1
            if ptr < len(posB) and posB[ptr] <= i + k:
                result.append(i)

        return result
```

## 复杂度分析

- 时间复杂度：O(n + m1 + m2)，KMP 搜索均为线性，双指针 O(p + q)
- 空间复杂度：O(n + m1 + m2)，存储匹配位置和失配表

## 关键点总结

1. KMP 保证线性时间搜索，是处理大数据量的关键
2. 双指针利用两个有序列表的单调性，避免重复遍历
3. Z 函数是另一种线性字符串匹配方法，原理略有不同

## 易错点

1. KMP 失配表构建中 `j = fail[j-1]` 是核心回退步骤
2. 双指针的 `ptr` 不应在每次 `i` 循环时重置，利用其单调性
3. Z 函数中拼接字符串时，分隔符 `#` 不能出现在文本或模式中
