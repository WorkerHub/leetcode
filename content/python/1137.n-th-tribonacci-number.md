## 题目描述

泰波那契序列 Tn 定义如下：

T0 = 0, T1 = 1, T2 = 1, 且在 n >= 0 的条件下 Tn+3 = Tn + Tn+1 + Tn+2

给你整数 n，请返回第 n 个泰波那契数 Tn 的值。

**示例 1：**
```
输入：n = 4
输出：4
解释：
T_3 = 0 + 1 + 1 = 2
T_4 = 1 + 1 + 2 = 4
```

**示例 2：**
```
输入：n = 25
输出：1389537
```

**提示：**
- 0 <= n <= 37
- 答案保证是一个 32 位整数，即 answer <= 2^31 - 1

## 解题思路

这是斐波那契数列的变形，从两项和变成三项和。可以使用多种方法求解：

1. **动态规划**：使用数组存储所有中间结果
2. **空间优化**：只保存最近三个数
3. **记忆化递归**：使用缓存避免重复计算
4. **矩阵快速幂**：适用于大数情况（本题不需要）

核心观察：
- 泰波那契数列每个数由前三个数相加得到
- 可以从底向上计算，也可以从顶向下递归
- 由于 n <= 37，计算量很小，所有方法都能通过

## Python 代码实现

### 方法一：动态规划（数组存储）⭐

```python
from typing import List

class Solution:
    def tribonacci(self, n: int) -> int:
        """
        使用动态规划数组存储所有泰波那契数
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 处理边界情况
        if n == 0:
            return 0
        if n <= 2:
            return 1
        
        # 创建 dp 数组
        dp = [0] * (n + 1)
        dp[0], dp[1], dp[2] = 0, 1, 1
        
        # 从第3项开始计算
        for i in range(3, n + 1):
            dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
        
        return dp[n]
```

### 方法二：空间优化（只保存三个变量）⭐ 推荐

```python
class Solution:
    def tribonacci(self, n: int) -> int:
        """
        空间优化版本，只使用三个变量滚动更新
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 处理边界情况
        if n == 0:
            return 0
        if n <= 2:
            return 1
        
        # 初始化前三个数
        a, b, c = 0, 1, 1
        
        # 滚动计算
        for i in range(3, n + 1):
            a, b, c = b, c, a + b + c
        
        return c
```

### 方法三：记忆化递归

```python
from functools import lru_cache

class Solution:
    def tribonacci(self, n: int) -> int:
        """
        使用记忆化递归（自顶向下）
        时间复杂度：O(n)
        空间复杂度：O(n) 包括递归栈
        """
        @lru_cache(maxsize=None)
        def helper(n: int) -> int:
            # 递归基础情况
            if n == 0:
                return 0
            if n <= 2:
                return 1
            # 递归计算
            return helper(n-1) + helper(n-2) + helper(n-3)
        
        return helper(n)
```

### 方法四：预计算（适合多次查询）

```python
class Solution:
    # 预计算所有可能的泰波那契数
    _tribonacci_cache = [0, 1, 1]
    
    def tribonacci(self, n: int) -> int:
        """
        预计算所有结果，适合多次查询
        时间复杂度：O(1) 查询，O(37) 预计算
        空间复杂度：O(37)
        """
        # 如果缓存中没有，继续计算
        while len(self._tribonacci_cache) <= n:
            cache = self._tribonacci_cache
            cache.append(cache[-1] + cache[-2] + cache[-3])
        
        return self._tribonacci_cache[n]
```

## 复杂度分析

**方法一（DP数组）：**
- 时间复杂度：O(n)，需要计算 n 个数
- 空间复杂度：O(n)，需要长度为 n+1 的数组

**方法二（空间优化）：**
- 时间复杂度：O(n)，需要计算 n 个数
- 空间复杂度：O(1)，只使用三个变量

**方法三（记忆化递归）：**
- 时间复杂度：O(n)，每个数只计算一次
- 空间复杂度：O(n)，缓存和递归栈

**方法四（预计算）：**
- 时间复杂度：O(1)，查询时间
- 空间复杂度：O(37)，存储所有结果

## 关键点总结

1. **状态转移方程**：`T[n] = T[n-1] + T[n-2] + T[n-3]`
2. **初始状态**：`T[0]=0, T[1]=1, T[2]=1`
3. **空间优化技巧**：使用滚动变量代替数组
4. **边界处理**：注意 n=0 和 n<=2 的特殊情况
5. **Python 技巧**：使用 `@lru_cache` 装饰器实现记忆化

## 易错点

1. **边界条件遗漏**：忘记处理 n=0 或 n=1, n=2 的情况
2. **滚动变量更新顺序**：必须使用 `a, b, c = b, c, a+b+c` 同时更新
3. **数组索引越界**：创建数组时长度应为 n+1
4. **递归无缓存**：纯递归会超时，必须加缓存
