## 题目描述

给你一个整数 `n`。请你先求出从 `1` 到 `n` 的每个整数的**数字之和**（每一位上的数字相加），然后把数字之和相同的整数分在同一组。

请问共有多少组整数，满足该组内含有的整数个数是所有组中**最多**的？

**示例 1：**

```
输入：n = 13
输出：4
解释：
总共有 9 组，[1,10], [2,11], [3,12], [4,13], [5], [6], [7], [8], [9]。
拥有最多数字的组含有 2 个整数（有4个这样的组）。
```

**示例 2：**

```
输入：n = 2
输出：2
解释：
总共有 2 组，[1], [2]。
两组都含有 1 个整数，因此有 2 个组含有最多数字。
```

**提示：**

- `1 <= n <= 10^4`

## 解题思路

**直接模拟：**

1. 对 1 到 n 的每个数，计算其数字之和
2. 用哈希表（或字典）统计每个数字之和对应的整数个数
3. 找出最大组的大小 `max_size`
4. 统计有多少组的大小等于 `max_size`

Python 的 `Counter` 可以方便地完成这些操作。

**数字之和的计算：** 对整数 `x`，用 `sum(int(d) for d in str(x))` 或者逐位取余的方式。

## Python 代码实现

### 方法一：Counter + 数字字符串转换（推荐）

```python
from collections import Counter

class Solution:
    def countLargestGroup(self, n: int) -> int:
        # 统计每个"数字之和"对应的整数个数
        # key: 数字之和, value: 整数个数
        digit_sum_count = Counter()

        for num in range(1, n + 1):
            # 计算 num 的数字之和
            s = sum(int(d) for d in str(num))
            digit_sum_count[s] += 1

        # 找出最大组的大小
        max_size = max(digit_sum_count.values())
        # 统计有多少组达到最大大小
        return sum(1 for v in digit_sum_count.values() if v == max_size)
```

### 方法二：辅助函数 + 字典

```python
class Solution:
    def countLargestGroup(self, n: int) -> int:

        def digit_sum(x: int) -> int:
            """计算整数 x 的各位数字之和"""
            total = 0
            while x > 0:
                total += x % 10  # 取个位
                x //= 10         # 去掉个位
            return total

        groups = {}  # {数字之和: 整数个数}
        for num in range(1, n + 1):
            key = digit_sum(num)
            groups[key] = groups.get(key, 0) + 1

        max_size = max(groups.values())
        return sum(1 for v in groups.values() if v == max_size)
```

### 方法三：一行写法（Python 高级用法）

```python
from collections import Counter

class Solution:
    def countLargestGroup(self, n: int) -> int:
        # 一行统计
        c = Counter(sum(int(d) for d in str(i)) for i in range(1, n + 1))
        m = max(c.values())
        return sum(v == m for v in c.values())
```

## 复杂度分析

- **时间复杂度 O(n * log n)**：共 n 个数，每个数的位数为 O(log n)，数字之和计算为 O(log n)。
  实际上 n ≤ 10^4，每个数最多 4 位，可视为 O(n)。
- **空间复杂度 O(log n)**：数字之和最大为 9 * 4 = 36（n ≤ 10^4），哈希表最多 36 个键。

## 关键点总结

1. 数字之和的计算：字符串方式 `sum(int(d) for d in str(x))` 简洁，逐位取余方式高效
2. 用 `Counter` 或字典统计各数字之和对应的整数数量
3. `max(d.values())` 获取最大组大小，再统计等于该大小的组数

## 易错点

- 范围是 `1` 到 `n`（含 n），不要写成 `range(n)` 漏掉 n 或从 0 开始
- 统计"有多少组达到最大大小"，而不是"最大组的大小是多少"
- `sum(v == m for v in c.values())` 利用了 Python 中 `True == 1, False == 0` 的特性
