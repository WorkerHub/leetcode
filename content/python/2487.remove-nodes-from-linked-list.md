## 题目描述

给你一个链表的头节点 `head`，移除所有满足「其右侧存在一个更大的节点」的节点，返回修改后的链表头节点。

**示例：**
```
输入：head = [5,2,13,3,8]
输出：[13,8]
解释：节点 5、2、3 右侧都有更大的节点，被移除
```

**提示：**
- 链表中节点数目在范围 `[1, 10^5]` 内
- `1 <= Node.val <= 10^5`

## 解题思路

**单调栈（从右到左维护递减栈）：**

从右到左遍历链表，维护一个单调递减栈：
- 若当前节点值 >= 栈顶，则当前节点可以保留
- 若当前节点值 < 栈顶，则当前节点右边有更大的值，应删除

**方法：**
1. 将链表转为数组
2. 从右到左遍历，维护单调递减栈
3. 从栈中重建链表

或者使用递归：后序处理，先递归处理后半部分，再决定当前节点是否保留。

## 代码实现

### 方法一：单调栈（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 收集所有节点值
        vals = []
        node = head
        while node:
            vals.append(node.val)
            node = node.next

        # 从右到左，维护单调递减栈
        stack = []
        for v in reversed(vals):
            # 当前值比栈顶大，可以保留
            while stack and stack[-1] < v:
                stack.pop()  # 栈里比 v 小的都会被 v 淘汰（等等，这逻辑反了）
            stack.append(v)

        # 实际上：保留的节点是那些右侧没有比它更大的值的节点
        # 即：从右到左，保留当前 >= 已见最大值的节点
        result = []
        max_val = 0
        for v in reversed(vals):
            if v >= max_val:
                result.append(v)
                max_val = v
        result.reverse()

        # 重建链表
        dummy = ListNode(0)
        cur = dummy
        for v in result:
            cur.next = ListNode(v)
            cur = cur.next

        return dummy.next
```

### 方法二：递归

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None

        # 递归处理后续节点
        head.next = self.removeNodes(head.next)

        # 若当前节点的下一个节点值更大，则删除当前节点
        if head.next and head.val < head.next.val:
            return head.next

        return head
```

### 方法三：翻转链表 + 单调栈

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        def reverse(node):
            prev = None
            while node:
                nxt = node.next
                node.next = prev
                prev = node
                node = nxt
            return prev

        # 翻转链表，从左到右处理（原来从右到左的最大值问题变成从左到右）
        head = reverse(head)

        # 维护单调递减链表（翻转后要保留递增的节点）
        cur = head
        while cur and cur.next:
            if cur.val > cur.next.val:
                cur.next = cur.next.next  # 删除 cur.next
            else:
                cur = cur.next

        # 再翻转回来
        return reverse(head)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数组+从右扫 | O(n) | O(n) |
| 递归 | O(n) | O(n)（栈空间） |
| 翻转链表 | O(n) | O(1) |

## 关键点总结

1. 保留节点的条件：右侧不存在比它大的节点 ↔ 它是从该位置到末尾的最大值
2. 从右到左维护最大值，大于等于当前最大值的节点保留
3. 递归写法最简洁：若下一节点更大，删除当前节点

## 易错点

- 递归可能导致栈溢出（n=10^5 时要小心 Python 默认递归深度）
- 翻转链表法的方向判断要仔细
