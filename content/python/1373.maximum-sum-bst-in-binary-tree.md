## 题目描述

给你一棵以 `root` 为根的**二叉树**，请你返回**任意**二叉搜索树子树的**最大键值和**。

若该二叉搜索树的键值和为负数，则返回 `0`。

**示例 1：**
```
        1
       / \
      4   3
     / \ / \
    2  4 2  5
           / \
          4   6
```
```
输入：root = [1,4,3,2,4,2,5,null,null,null,null,null,null,4,6]
输出：20
解释：键值之和最大的合法 BST 子树是以 3 为根的子树（值为 3+5+4+6+2 = 20）
```

**示例 2：**
```
输入：root = [4,3,null,1,2]
输出：2
解释：键值之和最大的合法 BST 子树是以 2 为根的单节点子树
```

**示例 3：**
```
输入：root = [-4,-2,-5]
输出：0
解释：所有合法 BST 子树的键值和都为负数，返回 0
```

**提示：**
- 树中节点数在 `[1, 40000]` 范围内
- `-4 * 10^4 <= Node.val <= 4 * 10^4`

## 解题思路

### 核心思想：后序 DFS，每个节点返回四元组

**什么是 BST？**
二叉搜索树满足：
- 左子树所有节点值 < 根节点值
- 右子树所有节点值 > 根节点值
- 左右子树也分别是 BST

**后序 DFS 的设计：**
对每个节点，我们需要知道：
1. 以该节点为根的子树**是否是 BST**
2. 子树中的**最小值**（用于判断父节点的右子树条件）
3. 子树中的**最大值**（用于判断父节点的左子树条件）
4. 子树中**所有节点的键值和**

**判断当前节点是否构成 BST（设当前节点值为 `val`）：**
- 左子树是 BST
- 右子树是 BST
- 左子树的最大值 < `val`
- 右子树的最小值 > `val`

若以上条件均满足，则当前子树是 BST，更新全局最大和。

**对非 BST 节点：** 返回一个"无效"标记，向上传播时父节点也会变为非 BST。

## Python 代码实现

### 方法一：后序 DFS 四元组（推荐）

```python
from typing import Optional
import math

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxSumBST(self, root: Optional[TreeNode]) -> int:
        self.ans = 0  # 全局最大 BST 键值和

        def dfs(node):
            """
            返回四元组 (is_bst, min_val, max_val, total_sum)：
            - is_bst:    当前子树是否是合法 BST
            - min_val:   子树中的最小节点值
            - max_val:   子树中的最大节点值
            - total_sum: 子树所有节点值之和

            若 is_bst 为 False，min_val/max_val/total_sum 无意义。
            """
            if not node:
                # 空树：是 BST，最小值=+inf，最大值=-inf，和=0
                # 使用 +inf/-inf 是为了让空子树不影响父节点的 BST 判断
                return True, math.inf, -math.inf, 0

            # 后序：先递归处理左右子树
            left_bst, left_min, left_max, left_sum = dfs(node.left)
            right_bst, right_min, right_max, right_sum = dfs(node.right)

            val = node.val

            # 判断当前子树是否是 BST
            if (left_bst and right_bst
                    and left_max < val < right_min):
                # 当前子树是 BST
                total_sum = left_sum + right_sum + val
                self.ans = max(self.ans, total_sum)  # 更新最大和
                # 返回当前子树的 min/max/sum
                cur_min = min(left_min, val)
                cur_max = max(right_max, val)
                return True, cur_min, cur_max, total_sum
            else:
                # 当前子树不是 BST，向上传播"非BST"标记
                return False, 0, 0, 0

        dfs(root)
        return self.ans
```

### 方法二：使用哨兵值简化空节点处理

```python
from typing import Optional

class Solution:
    def maxSumBST(self, root: Optional[TreeNode]) -> int:
        ans = 0
        INF = float('inf')

        def dfs(node):
            nonlocal ans
            if not node:
                return True, INF, -INF, 0

            l_bst, l_min, l_max, l_sum = dfs(node.left)
            r_bst, r_min, r_max, r_sum = dfs(node.right)

            v = node.val

            # BST 条件：左子树最大值 < v，右子树最小值 > v，且左右都是 BST
            if l_bst and r_bst and l_max < v < r_min:
                s = l_sum + r_sum + v
                ans = max(ans, s)
                # 注意：若左子树为空，l_min=INF，min(INF, v)=v，正确
                # 若右子树为空，r_max=-INF，max(-INF, v)=v，正确
                return True, min(l_min, v), max(r_max, v), s

            return False, 0, 0, 0

        dfs(root)
        return ans
```

### 方法三：暴力方法（对每个节点单独验证是否为 BST）

```python
from typing import Optional

class Solution:
    def maxSumBST(self, root: Optional[TreeNode]) -> int:
        def is_bst(node, min_val, max_val):
            """验证以 node 为根、值域在 (min_val, max_val) 内是否是 BST"""
            if not node:
                return True
            if not (min_val < node.val < max_val):
                return False
            return (is_bst(node.left, min_val, node.val)
                    and is_bst(node.right, node.val, max_val))

        def subtree_sum(node):
            """计算以 node 为根的子树的节点值之和"""
            if not node:
                return 0
            return node.val + subtree_sum(node.left) + subtree_sum(node.right)

        def dfs(node):
            if not node:
                return 0
            result = 0
            if is_bst(node, float('-inf'), float('inf')):
                result = max(result, subtree_sum(node))
            result = max(result, dfs(node.left), dfs(node.right))
            return result

        return dfs(root)
        # 注意：此方法时间复杂度 O(n²)，会超时，仅用于理解
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 后序 DFS 四元组 | O(n) | O(h) |
| 暴力验证 | O(n²) | O(h) |

- **方法一**：每个节点只访问一次，O(n)；递归栈深度 O(h)。
- **方法三**：每个节点作为根时都需重新验证整棵子树，最坏 O(n²)。

## 关键点总结

1. **后序 DFS**：必须先知道子树信息才能判断当前节点，所以用后序（先处理子节点）。
2. **四元组返回值**：同时维护 is_bst、min_val、max_val、total_sum，一次遍历获得所有信息。
3. **空节点的哨兵值**：空节点返回 `(True, +inf, -inf, 0)`，保证叶子节点的 BST 判断正确（左空→左max=-inf<val，右空→右min=+inf>val）。
4. **仅在当前子树是 BST 时更新答案**：一旦某子树非 BST，其父树也一定非 BST。
5. **结果可能为0**：若所有 BST 子树的键值和均为负，返回0（题目保证）。

## 易错点

1. **空节点的 min/max 值**：空节点的 `min_val` 应为 `+inf`，`max_val` 应为 `-inf`，不能用0，否则会误判叶子节点的 BST 条件。
2. **严格不等号**：BST 要求左子树最大值**严格小于**根，右子树最小值**严格大于**根，不含等号（BST 中无重复值）。
3. **非 BST 向上传播**：一旦某节点的子树非 BST，该节点本身也非 BST，返回的 min/max/sum 无需正确（会被忽略）。
4. **最大和可为负**：题目说如果为负返回0，但代码中初始化 `ans = 0` 已经处理了这种情况。
