## 题目描述

给你一个数组 `maximumHeight`，其中 `maximumHeight[i]` 表示第 `i` 座塔的最大高度。

你需要为每座塔设置一个正整数高度，要求：
1. 每座塔的高度不超过其最大高度限制。
2. 所有塔的高度互不相同。

返回所有塔的高度之和的最大值，若无法满足要求，返回 `-1`。

**示例 1：**
```
输入：maximumHeight = [2, 3, 4, 3]
输出：10
解释：设置高度为 [1, 2, 4, 3]，总和为 10
```

**示例 2：**
```
输入：maximumHeight = [15, 10]
输出：25
解释：设置高度为 [15, 10]，总和为 25
```

**提示：**
- `1 <= maximumHeight.length <= 10^5`
- `1 <= maximumHeight[i] <= 10^9`

## 解题思路

使用贪心策略：

1. 将数组连同原始下标一起排序（按最大高度降序）。
2. 从最大限制开始，第一座塔取其最大高度，后续每座塔取 `min(当前限制, 前一座塔的高度 - 1)`。
3. 若某座塔的高度被迫降至 `0` 或以下，则返回 `-1`。

核心思想：限制最大的塔优先分配高值，每次取不超过限制且不与已分配高度重复的最大值。

## Python 代码实现

### 方法一：贪心 + 排序（推荐）

```python
from typing import List

class Solution:
    def maximumTotalSum(self, maximumHeight: List[int]) -> int:
        # 对最大高度进行排序，同时跟踪原始索引
        n = len(maximumHeight)
        # 将 (最大高度, 原始下标) 排序
        sorted_heights = sorted(enumerate(maximumHeight), key=lambda x: x[1], reverse=True)
        
        result = 0
        # 当前可分配的最大高度
        current_max = sorted_heights[0][1]
        
        for i, (idx, max_h) in enumerate(sorted_heights):
            if i == 0:
                # 第一座塔直接取最大高度
                result += max_h
                current_max = max_h
            else:
                # 当前塔的高度不超过限制，且必须小于前一座塔的高度
                current_max = min(max_h, current_max - 1)
                if current_max <= 0:
                    return -1
                result += current_max
        
        return result
```

### 方法二：纯排序简化版

```python
from typing import List

class Solution:
    def maximumTotalSum(self, maximumHeight: List[int]) -> int:
        # 降序排序
        heights = sorted(maximumHeight, reverse=True)
        total = heights[0]
        
        for i in range(1, len(heights)):
            # 每座塔最多比前一座矮 1
            heights[i] = min(heights[i], heights[i-1] - 1)
            if heights[i] <= 0:
                return -1
            total += heights[i]
        
        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序的时间复杂度
- 空间复杂度：O(n)，排序所用的额外空间

## 关键点总结

1. 贪心策略：限制最大的塔优先分配高度，能分配的最大值就是其限制值。
2. 排序后从大到小依次确定每座塔的高度，确保每座塔高度都是当前可分配的最大值。
3. 若当前塔的高度被压缩到 0 或以下，则无解。

## 易错点

1. 忘记处理无解情况（返回 -1）。
2. 排序方向错误，应当从大到小排序。
3. 第一座塔的高度初始化处理。
