## 题目描述

给你一个长度为 `2n` 的整数数组，你需要将这些整数分成两个长度为 `n` 的数组 `first` 和 `second`，然后：
- 计算 `first` 中所有元素之和，记为 `sum_first`
- 计算 `second` 中所有元素之和，记为 `sum_second`

请你返回两数组之差绝对值 `|sum_first - sum_second|` 的**最小值**。

**示例 1：**
```
输入：nums = [3,9,7,3]
输出：2
解释：first = [3,9], second = [7,3], |12-10| = 2
```

**提示：**
- `1 <= n <= 15`
- `nums.length == 2 * n`
- `-10^7 <= nums[i] <= 10^7`

## 解题思路

`n <= 15`，`2n <= 30`，可以使用**折半枚举（Meet in the Middle）**。

**思路：**
- 将 `nums` 分为左右两半，各 `n` 个元素
- 左半部分：枚举所有子集，计算从左半选 `k` 个元素时的可能和（对每个 `k` 存储所有可能的和）
- 右半部分：同样枚举所有子集
- 对于左半选 `k` 个时，右半必须选 `n - k` 个
- 目标：使 `|2 * (sum_left + sum_right) - total|` 最小，即 `sum_left + sum_right` 尽量接近 `total / 2`

## 代码实现

### 方法一：折半枚举 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 2
        total = sum(nums)
        left, right = nums[:n], nums[n:]

        # 对左半部分枚举：left_sums[k] = 从 left 中选 k 个元素的所有可能和
        left_sums = [[] for _ in range(n + 1)]
        for mask in range(1 << n):
            k = bin(mask).count('1')
            s = sum(left[i] for i in range(n) if mask >> i & 1)
            left_sums[k].append(s)

        # 对右半部分枚举：right_sums[k] = 从 right 中选 k 个元素的所有可能和
        right_sums = [[] for _ in range(n + 1)]
        for mask in range(1 << n):
            k = bin(mask).count('1')
            s = sum(right[i] for i in range(n) if mask >> i & 1)
            right_sums[k].append(s)

        # 对每个 k，排序 right_sums[n-k]，然后二分查找最接近 total/2 - left_sum 的值
        for k in range(n + 1):
            right_sums[k].sort()

        ans = float('inf')
        target = total / 2.0  # 目标：两半各选 n 个，和接近 total/2

        for k in range(n + 1):
            nk = n - k
            for ls in left_sums[k]:
                # 在 right_sums[nk] 中找最接近 target - ls 的值
                need = target - ls
                arr = right_sums[nk]
                pos = bisect.bisect_left(arr, need)

                # 检查 pos-1 和 pos 两个候选
                for p in [pos - 1, pos]:
                    if 0 <= p < len(arr):
                        s = ls + arr[p]
                        diff = abs(2 * s - total)
                        ans = min(ans, diff)

        return ans
```

### 方法二：位运算优化枚举

```python
from typing import List
import bisect
from collections import defaultdict

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 2
        total = sum(nums)
        half_target = total / 2

        def get_sums(arr):
            # 返回字典：k -> 从 arr 中选 k 个元素的所有可能和（排序后）
            d = defaultdict(list)
            for mask in range(1 << len(arr)):
                k = bin(mask).count('1')
                s = sum(arr[i] for i in range(len(arr)) if mask >> i & 1)
                d[k].append(s)
            for v in d.values():
                v.sort()
            return d

        left_d = get_sums(nums[:n])
        right_d = get_sums(nums[n:])

        ans = float('inf')
        for k in range(n + 1):
            if k not in left_d or (n - k) not in right_d:
                continue
            rs = right_d[n - k]
            for ls in left_d[k]:
                need = half_target - ls
                pos = bisect.bisect_left(rs, need)
                for p in [pos - 1, pos]:
                    if 0 <= p < len(rs):
                        diff = abs(2 * (ls + rs[p]) - total)
                        ans = min(ans, diff)

        return ans
```

## 复杂度分析

- 时间复杂度：O(2^n * n + 2^n * log(2^n)) = O(n * 2^n)
- 空间复杂度：O(2^n * n)

## 关键点总结

1. 折半枚举（Meet in the Middle）：将问题分为左右两半，分别枚举
2. 对左半选 `k` 个，右半必须选 `n-k` 个（总共 n 个）
3. 目标和等于 `total / 2`，二分查找最接近的值
4. 时间从 O(2^(2n)) 降为 O(2^n * n)

## 易错点

- 目标差为 `|2*(ls+rs) - total|`，不是 `|ls+rs - total/2|`（避免浮点运算）
- 二分查找后要检查相邻两个位置（可能不存在精确匹配）
- n <= 15 时 2^n = 32768，可接受
