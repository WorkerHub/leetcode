## 题目描述

你的国家有无数多个湖泊，所有湖泊一开始都是空的。当第 `n` 个湖泊下雨前是满的，它将会**发洪水**。你的目标是避免任何湖泊发洪水。

给你一个整数数组 `rains`，其中：
- `rains[i] > 0`：第 `i` 天，编号为 `rains[i]` 的湖泊下雨，湖泊变满。
- `rains[i] == 0`：第 `i` 天是晴天，你可以选择**一个**湖泊进行抽水，使其变空。

请返回一个数组 `ans`，满足：
- `ans.length == rains.length`
- 若 `rains[i] != 0`：`ans[i] == -1`。
- 若 `rains[i] == 0`：`ans[i]` 是你选择抽水的湖泊编号（1 到 10^9 之间）。

如果没有办法阻止洪水，请返回一个**空数组**。

**示例 1：**

```
输入：rains = [1,2,3,4]
输出：[-1,-1,-1,-1]
解释：没有晴天，每个湖泊只下一次雨，不会发洪水。
```

**示例 2：**

```
输入：rains = [1,2,0,0,2,1]
输出：[-1,-1,2,1,-1,-1]
解释：
第0天：湖1下雨，满。
第1天：湖2下雨，满。
第2天：晴天，选择抽空湖2（因为湖2即将再次下雨）。
第3天：晴天，选择抽空湖1（因为湖1即将再次下雨）。
第4天：湖2下雨，满（之前已抽空）。
第5天：湖1下雨，满（之前已抽空）。
```

**示例 3：**

```
输入：rains = [1,2,0,1,2]
输出：[]
解释：第2天是唯一的晴天，无法同时抽空湖1和湖2，发洪水。
```

**提示：**
- `1 <= rains.length <= 10^5`
- `0 <= rains[i] <= 10^9`

---

## 解题思路

**贪心策略：** 晴天选择抽水时，应优先抽**最快会下雨**的湖泊，这样可以最大化利用晴天。

**具体算法：**
1. 用哈希表 `full` 记录当前装满水的湖泊及其**上次下雨的日期**。
2. 用有序集合（SortedList）记录所有**晴天的日期**。
3. 遇到下雨天（`rains[i] > 0`）：
   - 如果该湖泊已满 → 返回 `[]`（洪水不可避免，除非之前有晴天可以抽干）。
   - 否则将湖泊标记为满。
4. 遇到晴天（`rains[i] == 0`）：
   - 将该天加入晴天集合，暂不决定抽哪个湖（延迟决策）。
5. 当某个湖泊第二次下雨时，必须找到一个**在两次下雨之间的晴天**来抽干它（二分查找最近的晴天）。

## Python 代码实现

### 方法一：哈希表 + SortedList（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def avoidFlood(self, rains: List[int]) -> List[int]:
        n = len(rains)
        ans = [-1] * n

        full = {}        # 湖泊编号 -> 上次下雨的天数
        dry_days = SortedList()  # 还未被使用的晴天（存储下标）

        for i in range(n):
            if rains[i] == 0:
                # 晴天：先加入集合，等待分配
                dry_days.add(i)
                ans[i] = 1  # 占位，后续可能更新（抽任意湖）
            else:
                lake = rains[i]
                if lake in full:
                    # 该湖已满，必须在 full[lake] 之后找一个晴天来抽水
                    prev_rain = full[lake]

                    # 二分查找：找 prev_rain 之后最近的一个晴天
                    idx = dry_days.bisect_right(prev_rain)
                    if idx == len(dry_days):
                        # 没有可用的晴天 → 洪水无法避免
                        return []

                    dry_day = dry_days[idx]  # 找到的晴天
                    ans[dry_day] = lake       # 在这一天抽干该湖
                    dry_days.remove(dry_day)  # 该晴天已被使用

                # 更新：湖泊 lake 在第 i 天下雨，现在是满的
                full[lake] = i
                ans[i] = -1  # 下雨天，ans 为 -1

        # 处理剩余未使用的晴天（可以抽任意湖，抽 1 即可）
        # ans[i] = 1 已经在上面设置了占位值

        return ans
```

### 方法三：暴力法（超时，仅用于理解）

```python
from typing import List

class Solution:
    def avoidFlood(self, rains: List[int]) -> List[int]:
        n = len(rains)
        ans = [-1] * n
        full = {}   # 湖泊编号 -> 上次下雨天数
        sunny = []  # 晴天列表（下标）

        for i in range(n):
            if rains[i] == 0:
                sunny.append(i)
                ans[i] = 1  # 占位
            else:
                lake = rains[i]
                if lake in full:
                    # 暴力：线性查找第一个合适的晴天
                    found = False
                    for j, day in enumerate(sunny):
                        if day > full[lake]:
                            ans[day] = lake   # 这一天抽干湖 lake
                            sunny.pop(j)
                            found = True
                            break
                    if not found:
                        return []
                full[lake] = i

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| SortedList（方法一） | O(n log n) | O(n) |
| 暴力（方法三） | O(n^2) | O(n) |

- `SortedList` 的插入、删除、查找均为 O(log n)，总体 O(n log n)。
- 暴力线性查找每次 O(n)，最坏 O(n^2)，数据量大时会超时。

## 关键点总结

1. **贪心策略**：晴天应该用来抽即将发洪水的湖泊，且应使用**最近的**可用晴天（贪心最优）。
2. **SortedList** 支持 O(log n) 的插入、删除和范围二分查找，是解决本题的关键数据结构。
3. 二分查找 `bisect_right(prev_rain)` 找到上次下雨之后的第一个晴天。
4. 如果找不到合适的晴天，返回空数组 `[]`。

---

## 易错点

- **晴天的决策是延迟的**：遇到晴天时不立即决定抽哪个湖，而是等到需要时（某湖将发洪水时）再分配。
- **`bisect_right` vs `bisect_left`**：用 `bisect_right(prev_rain)` 找严格大于 `prev_rain` 的第一个晴天（因为当天下雨就不能同时抽水）。
- **剩余晴天的处理**：未分配的晴天可以抽任意不满的湖（或虚拟抽某个湖），`ans[i] = 1` 是合法的占位值。
