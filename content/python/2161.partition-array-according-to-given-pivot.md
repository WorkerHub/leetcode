## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `pivot`。请你将 `nums` 重新排列，满足以下条件：

- 每个**小于** `pivot` 的元素都出现在每个**大于** `pivot` 的元素**之前**。
- 每个**等于** `pivot` 的元素都出现在小于 `pivot` 的元素之后，大于 `pivot` 的元素之前。
- 小于 `pivot` 的元素之间，以及大于 `pivot` 的元素之间，**保持原有相对顺序**。

返回重新排列后的数组。

**示例：**
```
输入：nums = [9,12,5,10,14,3,10], pivot = 10
输出：[9,5,3,10,10,12,14]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^6 <= nums[i], pivot <= 10^6`

## 解题思路

**三分法（分离三组再合并）**

将 nums 分成三组：小于 pivot、等于 pivot、大于 pivot，分别保持相对顺序，再拼接。

## 代码实现

### 方法一：三分合并（推荐）

```python
from typing import List

class Solution:
    def pivotArray(self, nums: List[int], pivot: int) -> List[int]:
        less = [x for x in nums if x < pivot]
        equal = [x for x in nums if x == pivot]
        greater = [x for x in nums if x > pivot]
        return less + equal + greater
```

### 方法二：双指针（O(1) 额外空间风格）

```python
from typing import List

class Solution:
    def pivotArray(self, nums: List[int], pivot: int) -> List[int]:
        n = len(nums)
        result = [0] * n
        lo = 0          # 下一个小于 pivot 的位置
        hi = n - 1      # 下一个大于 pivot 的位置（从右侧填入）
        
        # 分两次遍历：先填小于的，再填大于的
        less = [x for x in nums if x < pivot]
        greater = [x for x in nums if x > pivot]
        pivot_count = nums.count(pivot)
        
        result[:len(less)] = less
        result[len(less):len(less)+pivot_count] = [pivot] * pivot_count
        result[len(less)+pivot_count:] = greater
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三分合并 | O(n) | O(n) |

## 关键点总结

1. 分三组，分别保持相对顺序（列表推导式自然保持顺序）。
2. 拼接三组得到结果。
3. 与快速排序的 partition 不同，本题需要保持相对顺序（稳定分区）。

## 易错点

- 保持相对顺序：小于/大于 pivot 的元素各自内部顺序不变（稳定分区）。
- 不能使用原地快速排序的 partition（不稳定）。
