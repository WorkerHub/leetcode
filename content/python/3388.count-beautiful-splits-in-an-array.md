## 题目描述

给你一个整数数组 `nums`，将数组分成三个非空子数组 `nums1`、`nums2`、`nums3`（`nums1 + nums2 + nums3 = nums`）。

如果满足以下任一条件，则该分割是"美丽分割"：
- `nums1` 是 `nums2` 的前缀（即 `nums2` 以 `nums1` 开头）
- `nums2` 是 `nums3` 的前缀（即 `nums3` 以 `nums2` 开头）

返回美丽分割的数量。

**示例：**
```
输入：nums = [1,1,2,1]
输出：2
解释：美丽分割为 ([1],[1,2],[1]) 和 ([1],[1],[2,1])
```

**提示：**
- `1 <= nums.length <= 5000`

## 解题思路

**LCP（最长公共前缀）+ 动态规划：**

关键是快速判断某个子数组是否是另一个子数组的前缀。

设 `lcp[i][j]` 为 `nums[i:]` 和 `nums[j:]` 的最长公共前缀长度。

利用动态规划计算 LCP：
- 若 `nums[i] == nums[j]`，则 `lcp[i][j] = lcp[i+1][j+1] + 1`
- 否则 `lcp[i][j] = 0`

从右向左，从下向上填充。

对于分割点 `i`（`nums1 = nums[0..i-1]`）和 `j`（`nums2 = nums[i..j-1]`，`nums3 = nums[j..n-1]`）：
- `nums1` 是 `nums2` 前缀：`lcp[0][i] >= i`（即 `nums1` 长度 `i`，满足 `lcp[0][i] >= i`）
- `nums2` 是 `nums3` 前缀：`lcp[i][j] >= j - i`（即 `nums2` 长度 `j - i`，满足 `lcp[i][j] >= j - i`）

枚举所有有效的分割点对 `(i, j)` 即可。

## Python 代码实现

### 方法一：LCP 数组预计算（推荐）

```python
from typing import List

class Solution:
    def beautifulSplits(self, nums: List[int]) -> int:
        n = len(nums)
        
        # lcp[i][j] = nums[i:] 和 nums[j:] 的最长公共前缀
        lcp = [[0] * (n + 1) for _ in range(n + 1)]
        
        # 从右往左，从下往上填充
        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if nums[i] == nums[j]:
                    lcp[i][j] = lcp[i + 1][j + 1] + 1
                else:
                    lcp[i][j] = 0
        
        ans = 0
        
        # nums1 = nums[0:i], nums2 = nums[i:j], nums3 = nums[j:n]
        # 要求：i >= 1, j - i >= 1, n - j >= 1
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                len1 = i          # nums1 长度
                len2 = j - i      # nums2 长度
                len3 = n - j      # nums3 长度
                
                # 条件1：nums1 是 nums2 的前缀 => len1 <= len2 且 lcp[0][i] >= len1
                cond1 = (len1 <= len2) and (lcp[0][i] >= len1)
                
                # 条件2：nums2 是 nums3 的前缀 => len2 <= len3 且 lcp[i][j] >= len2
                cond2 = (len2 <= len3) and (lcp[i][j] >= len2)
                
                if cond1 or cond2:
                    ans += 1
        
        return ans
```

### 方法二：Z-函数优化（更快）

```python
from typing import List

class Solution:
    def beautifulSplits(self, nums: List[int]) -> int:
        n = len(nums)
        
        def z_function(arr):
            """计算 Z 数组：z[i] = arr[i:] 与 arr 的最长公共前缀"""
            m = len(arr)
            z = [0] * m
            z[0] = m
            l, r = 0, 0
            for i in range(1, m):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < m and arr[z[i]] == arr[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z
        
        # 预计算从每个位置开始的 Z 函数
        # z1[i] = nums[i:] 与 nums[0:] 的 LCP（即 lcp[0][i]）
        z1 = z_function(nums)
        
        ans = 0
        for i in range(1, n - 1):
            # 计算从 i 开始的 Z 函数
            zi = z_function(nums[i:])
            
            for j in range(i + 1, n):
                len1 = i
                len2 = j - i
                len3 = n - j
                
                # 条件1：nums1 是 nums2 前缀
                cond1 = (len1 <= len2) and (z1[i] >= len1)
                
                # 条件2：nums2 是 nums3 前缀
                # zi[j-i] = nums[j:] 与 nums[i:] 的 LCP
                lcp_23 = zi[j - i] if j - i < len(zi) else 0
                cond2 = (len2 <= len3) and (lcp_23 >= len2)
                
                if cond1 or cond2:
                    ans += 1
        
        return ans
```

## 复杂度分析

**方法一（LCP 预计算）：**
- 时间复杂度：O(n^2) 预计算 + O(n^2) 枚举 = O(n^2)
- 空间复杂度：O(n^2)，LCP 数组

**方法二（Z-函数）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. `lcp[i][j]` 表示 `nums[i:]` 和 `nums[j:]` 的最长公共前缀，用 DP 预计算。
2. 判断 `A` 是 `B` 的前缀：`len(A) <= len(B)` 且 `lcp[start_A][start_B] >= len(A)`。
3. 枚举两个分割点 `i`（1 到 n-2）和 `j`（i+1 到 n-1）。

## 易错点

1. LCP 需要从右下角往左上角填充（因为 `lcp[i][j]` 依赖 `lcp[i+1][j+1]`）。
2. 三段都必须非空：`i >= 1`, `j > i`, `j < n`。
3. "A 是 B 的前缀"需要满足长度条件 `len(A) <= len(B)`。
