## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，你可以从中选取一个或多个元素组成一个 **组**。一个组的 **强度** 等于组内所有元素的 **乘积**。

返回组的 **最大强度**。

**示例 1：**
```
输入：nums = [3,-1,-5,2,5,-9]
输出：1350
解释：选取 [3,-1,-5,2,5,-9]，乘积 = 3*(-1)*(-5)*2*5*(-9) = -1350；
选取 [3,-5,2,5,-9]，乘积 = 1350（去掉 -1）
```

**示例 2：**
```
输入：nums = [-4,-5,-4]
输出：20
解释：选取 [-4,-5]，乘积 = 20
```

**提示：**
- `1 <= nums.length <= 13`
- `-10 <= nums[i] <= 10`

## 解题思路

**贪心策略**：
- 正数全选
- 负数：偶数个全选，奇数个去掉绝对值最小的（即去掉最接近 0 的负数）
- 数字 0：若结果为负，可以用 0 替代（但直接忽略 0 更简单）
- 特殊情况：所有元素均为 0，返回 0

由于数组长度 <= 13，也可以用枚举所有子集（2^13 = 8192）。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxStrength(self, nums: List[int]) -> int:
        # 分离正负零
        pos = sorted([x for x in nums if x > 0])
        neg = sorted([x for x in nums if x < 0])  # 升序，绝对值大的在前

        # 负数如果是奇数个，去掉绝对值最小的（即最大的负数，neg[-1]）
        if len(neg) % 2 == 1:
            neg = neg[:-1]

        result = 1
        selected = pos + neg
        if not selected:
            # 全是0，或只剩 0
            return max(nums)  # 包含 0 的情况
        for x in selected:
            result *= x
        return result
```

### 方法二：枚举所有子集（暴力，适用于小数据）

```python
from typing import List

class Solution:
    def maxStrength(self, nums: List[int]) -> int:
        n = len(nums)
        ans = float('-inf')
        # 枚举所有非空子集
        for mask in range(1, 1 << n):
            prod = 1
            for i in range(n):
                if mask >> i & 1:
                    prod *= nums[i]
            ans = max(ans, prod)
        return ans
```

### 方法三：动态规划

```python
from typing import List

class Solution:
    def maxStrength(self, nums: List[int]) -> int:
        # dp_max, dp_min 分别维护当前可选子集的最大和最小乘积
        dp_max = dp_min = nums[0]
        for i in range(1, len(nums)):
            x = nums[i]
            # 当前元素可以加入之前的最大或最小乘积组，也可以单独成组
            candidates = [dp_max * x, dp_min * x, x]
            dp_max, dp_min = max(candidates), min(candidates)
        return dp_max
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(2^n * n)，空间复杂度 O(1)
- 方法三：时间复杂度 O(n)，空间复杂度 O(1)

## 关键点总结

1. 正数全部选取以最大化乘积
2. 负数成对选取（绝对值最大的优先），奇数个时丢弃绝对值最小的
3. 数字 0 不贡献（排除）；但若只有 0，返回 0
4. 方法三 DP 优雅，同时维护最大和最小乘积

## 易错点

1. 全为 0 时需返回 0，不能返回 1（空乘积）
2. 注意只有一个元素时也必须选（至少选一个）
3. 方法一中若 selected 为空说明所有非零元素都被过滤掉了（全是0）
