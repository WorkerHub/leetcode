## 题目描述

给你一个正整数数组 `candidates`，计算 `candidates` 的所有非空子集中按位与（AND）结果**大于 0** 的**最大子集长度**。

**示例 1：**
```
输入：candidates = [16,17,71,62,12,24,14]
输出：4
解释：子集 [16,17,62,24] 按位与结果为 16 > 0。
```

**示例 2：**
```
输入：candidates = [8,8]
输出：2
```

## 解题思路

按位与大于 0，等价于存在某个二进制位 `k`，所有子集中的数在第 `k` 位都为 1。

因此，对每个二进制位 `k`（0 到 23，因为候选值最大 10^7 < 2^23），统计候选数中第 `k` 位为 1 的数的个数，答案就是这些计数中的最大值。

## 代码实现

### 方法一：按位统计（推荐）

```python
from typing import List

class Solution:
    def largestCombination(self, candidates: List[int]) -> int:
        ans = 0
        # 对每个二进制位
        for bit in range(24):  # 10^7 < 2^24
            # 统计第 bit 位为 1 的候选数个数
            count = sum(1 for x in candidates if x >> bit & 1)
            ans = max(ans, count)
        return ans
```

### 方法二：哈希表统计（位计数）

```python
from typing import List
from collections import Counter

class Solution:
    def largestCombination(self, candidates: List[int]) -> int:
        # 统计每个位上 1 的总数
        bit_count = Counter()
        for x in candidates:
            for bit in range(24):
                if x >> bit & 1:
                    bit_count[bit] += 1
        return max(bit_count.values()) if bit_count else 0
```

## 复杂度分析

- 时间复杂度：O(n * B)，B = 24，枚举每个候选数的每一位。
- 空间复杂度：O(1)，常数额外空间。

## 关键点总结

1. 关键洞察：AND > 0 等价于存在某位 k 使所有数在第 k 位都为 1。
2. 对每位统计计数，取最大值即为答案。
3. 候选值范围 `<= 10^7 < 2^24`，枚举 24 位即可。

## 易错点

- 要枚举到足够多的位（24 位覆盖最大值 `10^7`）。
- `x >> bit & 1` 正确提取第 bit 位（注意运算符优先级：`>>`比`&`高）。
