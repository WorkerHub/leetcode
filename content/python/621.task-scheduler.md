## 题目描述

给你一个用字符数组 `tasks` 表示的 CPU 需要执行的任务列表。其中每个字母表示一种不同种类的任务。任务可以以任意顺序执行，并且每个任务都可以在 1 个单位时间内执行完。在任何一个单位时间，CPU 可以完成一个任务，或者处于待命状态。

然而，两个**相同种类**的任务之间必须有长度为整数 `n` 的冷却时间，因此至少有连续 `n` 个单位时间内 CPU 在执行不同的任务，或者在待命状态。

你需要计算完成所有任务所需要的**最短时间**。

**示例 1：**

```
输入：tasks = ["A","A","A","B","B","B"], n = 2
输出：8
解释：A -> B -> 待命 -> A -> B -> 待命 -> A -> B
     在本示例中，两个相同类型任务之间必须间隔长度为 n = 2 的冷却时间，而执行一个任务只需要一个单位时间，所以中间出现了（待命）状态。
```

**示例 2：**

```
输入：tasks = ["A","A","A","B","B","B"], n = 0
输出：6
解释：在这种情况下，任何大小为 6 的排列都可以满足要求，因为 n = 0
["A","A","A","B","B","B"]
["A","B","A","B","A","B"]
["B","B","B","A","A","A"]
...
诸如此类
```

**示例 3：**

```
输入：tasks = ["A","A","A","A","A","A","B","C","D","E","F","G"], n = 2
输出：16
解释：一种可能的解决方案是：
     A -> B -> C -> A -> D -> E -> A -> F -> G -> A -> 待命 -> 待命 -> A -> 待命 -> 待命 -> A
```

**提示：**

- `1 <= tasks.length <= 10^4`
- `tasks[i]` 是大写英文字母
- `0 <= n <= 100`

## 解题思路

**核心思想：贪心算法**

关键观察：
1. **最多的任务决定总时间**：出现次数最多的任务会产生最多的间隔
2. **公式推导**：设最多任务出现 `maxCount` 次，有 `maxTasks` 个任务达到这个次数

**最短时间公式：**
```
时间 = max(len(tasks), (maxCount - 1) * (n + 1) + maxTasks)
```

**解释：**
- `(maxCount - 1) * (n + 1)`：最多任务的间隔框架
- `+ maxTasks`：最后一组任务
- 与 `len(tasks)` 取最大值：任务足够多时不需要待命

## Python 代码实现

### 方法一：数学公式（推荐）⭐

```python
from typing import List
from collections import Counter

class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        """
        贪心 + 数学公式
        
        时间复杂度：O(m)，m 为任务数
        空间复杂度：O(1)，最多 26 个字母
        """
        # 统计每个任务的频率
        freq = Counter(tasks)
        
        # 找到最大频率
        max_count = max(freq.values())
        
        # 统计有多少个任务达到最大频率
        max_tasks = sum(1 for count in freq.values() if count == max_count)
        
        # 计算最短时间
        # (max_count - 1) * (n + 1) + max_tasks：按框架排列
        # len(tasks)：任务总数（当间隔足够小时）
        return max(len(tasks), (max_count - 1) * (n + 1) + max_tasks)
```

### 方法二：模拟（堆）

```python
import heapq
from collections import Counter

class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        """
        使用最大堆模拟执行过程
        
        时间复杂度：O(m log 26)
        空间复杂度：O(1)
        """
        freq = Counter(tasks)
        # 最大堆（Python 是最小堆，取负数）
        heap = [-count for count in freq.values()]
        heapq.heapify(heap)
        
        time = 0
        
        while heap:
            temp = []
            # 执行 n+1 个任务（一个周期）
            for _ in range(n + 1):
                if heap:
                    count = heapq.heappop(heap)
                    if count < -1:  # 还有剩余
                        temp.append(count + 1)
                time += 1
                
                # 如果堆空且临时列表空，说明完成
                if not heap and not temp:
                    break
            
            # 将剩余任务放回堆
            for count in temp:
                heapq.heappush(heap, count)
        
        return time
```

### 方法三：贪心排序

```python
class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        """
        贪心：优先执行剩余次数最多的任务
        """
        freq = [0] * 26
        for task in tasks:
            freq[ord(task) - ord('A')] += 1
        
        freq.sort(reverse=True)
        max_count = freq[0]
        idle_slots = (max_count - 1) * n
        
        for i in range(1, 26):
            if freq[i] == 0:
                break
            idle_slots -= min(freq[i], max_count - 1)
        
        return len(tasks) + max(0, idle_slots)
```

## 关键点总结

1. **贪心思想**：最多的任务决定最小时间
2. **数学公式**：`(maxCount - 1) * (n + 1) + maxTasks`
3. **边界情况**：当任务足够多时，不需要待命，直接返回任务总数
4. **多个最大频率**：最后一组需要容纳所有最大频率的任务
5. **冷却时间为 0**：直接返回任务总数

## 易错点

1. **忘记考虑多个最大频率**：
   ```python
   # ❌ 错误：假设只有一个任务达到最大频率
   return (max_count - 1) * (n + 1) + 1
   
   # ✅ 正确：计算有多少个任务达到最大频率
   max_tasks = sum(1 for c in freq.values() if c == max_count)
   ```

2. **没有与任务总数比较**：
   ```python
   # ❌ 错误：没有考虑任务数量足够多的情况
   return (max_count - 1) * (n + 1) + max_tasks
   
   # ✅ 正确：取最大值
   return max(len(tasks), ...)
   ```

3. **公式理解错误**：
   - `(maxCount - 1)`：最多任务之间有 maxCount - 1 个间隔
   - `(n + 1)`：每个间隔包含 n+1 个位置（1个任务 + n个冷却）
   - `+ maxTasks`：最后一组需要放置所有达到最大频率的任务
