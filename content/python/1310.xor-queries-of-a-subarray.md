## 题目描述

给出整数数组 `arr` 和查询数组 `queries`，其中 `queries[i] = [Li, Ri]`。

对于每个查询 `i`，计算：

```
arr[Li] XOR arr[Li+1] XOR ... XOR arr[Ri]
```

返回包含所有查询结果的数组。

**示例 1：**

```
输入：arr = [1,3,4,8], queries = [[0,1],[1,2],[0,3],[3,3]]
输出：[2,7,14,8]
解释：
数组中元素的二进制表示形式：
1  = 0001
3  = 0011
4  = 0100
8  = 1000
查询的 XOR 值：
[0,1] = 1 xor 3 = 2
[1,2] = 3 xor 4 = 7
[0,3] = 1 xor 3 xor 4 xor 8 = 14
[3,3] = 8
```

**示例 2：**

```
输入：arr = [4,8,2,10], queries = [[2,3],[1,3],[0,0],[0,3]]
输出：[8,0,4,4]
```

**提示：**

- `1 <= arr.length, queries.length <= 3 * 10^4`
- `1 <= arr[i] <= 10^9`
- `0 <= queries[i][0] <= queries[i][1] < arr.length`

## 解题思路

**核心思想：前缀异或数组**

与前缀和思路完全相同，利用 XOR 的性质：

```
A XOR A = 0
A XOR 0 = A
XOR 满足交换律和结合律
```

构建前缀异或数组 `prefix`，其中 `prefix[i]` 表示 `arr[0] XOR arr[1] XOR ... XOR arr[i-1]`。

对于区间查询 `[L, R]`：

```
arr[L] XOR ... XOR arr[R]
= prefix[R+1] XOR prefix[L]
```

**原理推导：**

```
prefix[L]   = arr[0] XOR arr[1] XOR ... XOR arr[L-1]
prefix[R+1] = arr[0] XOR arr[1] XOR ... XOR arr[L-1] XOR arr[L] XOR ... XOR arr[R]

prefix[R+1] XOR prefix[L]
= (arr[0] XOR ... XOR arr[L-1]) XOR (arr[0] XOR ... XOR arr[L-1]) XOR arr[L] XOR ... XOR arr[R]
= 0 XOR arr[L] XOR ... XOR arr[R]
= arr[L] XOR ... XOR arr[R]
```

## Python 代码实现

### 方法一：前缀异或数组（推荐）

```python
from typing import List

class Solution:
    def xorQueries(self, arr: List[int], queries: List[List[int]]) -> List[int]:
        n = len(arr)
        # 构建前缀异或数组，prefix[i] 表示 arr[0..i-1] 的异或值
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] ^ arr[i]
        
        # 对每个查询，利用前缀异或快速求区间异或
        result = []
        for L, R in queries:
            result.append(prefix[R + 1] ^ prefix[L])
        
        return result
```

### 方法二：列表推导式（简洁写法）

```python
from typing import List
from itertools import accumulate
from operator import xor

class Solution:
    def xorQueries(self, arr: List[int], queries: List[List[int]]) -> List[int]:
        # 使用 itertools.accumulate 构建前缀异或，initial=0 使索引对齐
        prefix = list(accumulate(arr, xor, initial=0))
        return [prefix[R + 1] ^ prefix[L] for L, R in queries]
```

### 方法三：暴力解法（对照理解用）

```python
from typing import List

class Solution:
    def xorQueries(self, arr: List[int], queries: List[List[int]]) -> List[int]:
        result = []
        for L, R in queries:
            # 对区间内每个元素逐一异或
            xor_val = 0
            for i in range(L, R + 1):
                xor_val ^= arr[i]
            result.append(xor_val)
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀异或 | O(n + q) | O(n) |
| 暴力 | O(n * q) | O(1) |

其中 n 为数组长度，q 为查询次数。

- **前缀异或**：预处理 O(n)，每次查询 O(1)，总共 O(n + q)
- **暴力**：每次查询最坏 O(n)，总共 O(n * q)

## 关键点总结

1. XOR 的核心性质：`A XOR A = 0`，任何数与自身异或为 0
2. 前缀异或数组下标偏移 1，即 `prefix[0] = 0`，`prefix[i] = arr[0..i-1]` 的异或值
3. 区间 `[L, R]` 的异或值等于 `prefix[R+1] ^ prefix[L]`
4. 与前缀和的思路完全类似，只是把加法换成 XOR

## 易错点

1. **下标越界**：`prefix` 数组长度为 `n+1`，查询时用 `prefix[R+1]`，注意 R 最大为 `n-1`，所以 `R+1` 最大为 `n`，不会越界
2. **混淆前缀和与前缀异或**：前缀和用加法，前缀异或用 `^`，两者原理相同但运算符不同
3. **暴力超时**：数据范围 3*10^4，暴力 O(n*q) = O(9*10^8)，会超时
