## 题目描述

给你一个字符串 `s` 和整数 `k`，返回恰好包含 `k` 个元音字母（a, e, i, o, u）的子字符串数量。

**示例 1：**

```
输入：s = "aeiou", k = 2
输出：4
解释：ae,ei,io,ou 各含2个元音
```

**示例 2：**

```
输入：s = "abc", k = 1
输出：2
解释：a 和 ab... 需要准确计算含1个元音的子串
```

**提示：**

- `1 <= s.length <= 10^5`
- `1 <= k <= s.length`
- `s` 只包含小写字母

## 解题思路

**至多 k 个减至多 k-1 个**：

恰好 k 个元音 = 至多 k 个 - 至多 k-1 个

用滑动窗口计算至多 k 个元音的子字符串数。

## Python 代码实现

### 方法一：双滑动窗口（推荐）

```python
class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')

        def at_most(limit: int) -> int:
            count = 0
            left = 0
            vowel_count = 0
            for right in range(len(s)):
                if s[right] in vowels:
                    vowel_count += 1
                while vowel_count > limit:
                    if s[left] in vowels:
                        vowel_count -= 1
                    left += 1
                count += right - left + 1
            return count

        return at_most(k) - at_most(k - 1)
```

### 方法二：前缀和

```python
from collections import defaultdict

class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        prefix = [0]
        for c in s:
            prefix.append(prefix[-1] + (1 if c in vowels else 0))

        count = defaultdict(int)
        ans = 0
        for i, p in enumerate(prefix):
            # 以 prefix[i+1] 结尾，找 prefix[j] = prefix[i+1] - k
            target = p - k
            ans += count[target]
            count[p] += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. "恰好 k 个" = "至多 k 个" - "至多 k-1 个"（标准技巧）
2. 滑动窗口计算至多 k 个的子串数
3. `count += right - left + 1` 统计以 right 结尾的合法子串数

## 易错点

1. 元音集合：{a, e, i, o, u}
2. `at_most(k-1)` 当 k=0 时返回所有子串数（0 个元音）
3. k=0 时恰好 0 个元音 = 总子串数 - 至少 1 个元音的子串数
