## 题目描述

给定一个字符串 `s`，找出并返回其中最长的重复子串的长度。如果不存在重复子串，则返回 `0`。

**示例 1：**
```
输入：s = "abcd"
输出：0
解释：没有重复的子串。
```

**示例 2：**
```
输入：s = "abbaba"
输出：2
解释：最长的重复子串是 "ab" 和 "ba"，长度为 2。
```

**示例 3：**
```
输入：s = "aabcaabdaab"
输出：3
解释：最长的重复子串是 "aab"，出现了 3 次。
```

**示例 4：**
```
输入：s = "aaaaa"
输出：4
解释：最长的重复子串是 "aaaa"。
```

**提示：**
- `1 <= s.length <= 1500`
- `s` 由小写英文字母组成

## 解题思路

这道题有多种解法，核心是如何高效地检测重复子串。

**方法对比：**
1. **暴力法**：枚举所有子串，检查是否重复 - O(n³)
2. **动态规划**：类似最长公共子串 - O(n²)
3. **二分查找 + 哈希**：二分长度，用哈希检测重复 - O(n log n)
4. **后缀数组**：构建后缀数组，找最长公共前缀 - O(n log n)

**推荐方法：二分查找 + 滚动哈希**
- 二分查找可能的长度（0 到 n-1）
- 对于每个长度，用滚动哈希检测是否存在重复子串
- 滚动哈希可以在 O(n) 时间内检测所有该长度的子串

## Python 代码实现

### 方法一：二分查找 + 滚动哈希（推荐）

```python
class Solution:
    def longestRepeatingSubstring(self, s: str) -> int:
        """
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        n = len(s)
        
        def has_duplicate(length: int) -> bool:
            """检查是否存在长度为 length 的重复子串"""
            if length == 0:
                return True
            
            # 使用滚动哈希
            MOD = 10**9 + 7
            BASE = 26
            
            # 计算 BASE^length % MOD
            power = pow(BASE, length, MOD)
            
            # 计算第一个窗口的哈希值
            hash_val = 0
            for i in range(length):
                hash_val = (hash_val * BASE + ord(s[i]) - ord('a')) % MOD
            
            # 存储已见过的哈希值
            seen = {hash_val}
            
            # 滚动窗口
            for i in range(1, n - length + 1):
                # 移除最左边的字符，添加最右边的字符
                hash_val = (hash_val * BASE - (ord(s[i - 1]) - ord('a')) * power + ord(s[i + length - 1]) - ord('a')) % MOD
                
                if hash_val in seen:
                    return True
                seen.add(hash_val)
            
            return False
        
        # 二分查找最大长度
        left, right = 0, n - 1
        result = 0
        
        while left <= right:
            mid = (left + right) // 2
            if has_duplicate(mid):
                result = mid
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```

### 方法二：动态规划

```python
class Solution:
    def longestRepeatingSubstring(self, s: str) -> int:
        """
        动态规划：类似最长公共子串
        时间复杂度：O(n²)
        空间复杂度：O(n²)
        """
        n = len(s)
        # dp[i][j] 表示 s[0:i] 和 s[0:j] 的最长公共后缀长度
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        max_len = 0
        
        for i in range(1, n + 1):
            for j in range(i + 1, n + 1):
                if s[i - 1] == s[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                    max_len = max(max_len, dp[i][j])
        
        return max_len
```

### 方法三：暴力 + 哈希集合（简单但慢）

```python
class Solution:
    def longestRepeatingSubstring(self, s: str) -> int:
        """
        暴力枚举所有子串
        时间复杂度：O(n²)
        空间复杂度：O(n²)
        """
        n = len(s)
        max_len = 0
        
        # 从长到短枚举长度
        for length in range(n - 1, 0, -1):
            seen = set()
            for i in range(n - length + 1):
                substring = s[i:i + length]
                if substring in seen:
                    return length
                seen.add(substring)
        
        return 0
```

### 方法四：优化的 DP（空间优化）

```python
class Solution:
    def longestRepeatingSubstring(self, s: str) -> int:
        """
        空间优化的 DP
        时间复杂度：O(n²)
        空间复杂度：O(n)
        """
        n = len(s)
        prev = [0] * (n + 1)
        max_len = 0
        
        for i in range(1, n + 1):
            curr = [0] * (n + 1)
            for j in range(i + 1, n + 1):
                if s[i - 1] == s[j - 1]:
                    curr[j] = prev[j - 1] + 1
                    max_len = max(max_len, curr[j])
            prev = curr
        
        return max_len
```

## 复杂度分析

**方法一：二分查找 + 滚动哈希**
- 时间复杂度：O(n log n)
  - 二分查找：O(log n)
  - 每次检查：O(n)
- 空间复杂度：O(n)，存储哈希值

**方法二：动态规划**
- 时间复杂度：O(n²)
- 空间复杂度：O(n²) 或 O(n)（优化后）

**方法三：暴力枚举**
- 时间复杂度：O(n²) 平均，O(n³) 最坏（字符串比较）
- 空间复杂度：O(n²)

## 关键点总结

1. **二分优化**：二分查找长度，配合哈希检测
2. **滚动哈希**：O(1) 时间更新窗口哈希值
3. **DP 转移**：`dp[i][j] = dp[i-1][j-1] + 1` if `s[i-1] == s[j-1]`
4. **剪枝优化**：从大到小枚举长度，找到即可返回

## 易错点

1. **哈希冲突**：滚动哈希可能有冲突，可以使用双哈希
2. **边界条件**：长度为 0 的处理，n=1 的情况
3. **DP 初始化**：注意索引偏移，`i` 和 `j` 的关系
4. **空间优化**：DP 可以用滚动数组优化到 O(n)
