## 题目描述

你在玩一款电子游戏，城市由 `n` 只怪兽包围。给你两个整数数组 `dist` 和 `speed`，其中 `dist[i]` 是第 `i` 只怪兽与城市的初始距离，`speed[i]` 是该怪兽的速度。

从第 0 分钟开始，每分钟你可以消灭**一只**怪兽。如果任意怪兽在**第 0 分钟结束前**（即时间 0 之前）或**到达城市时**进入城市，游戏结束。

返回你可以消灭的最多怪兽数量。

**注意：** 怪兽到达城市的时间为 `ceil(dist[i] / speed[i])`（向上取整）。

**示例 1：**
```
输入：dist = [1, 3, 4], speed = [1, 1, 1]
输出：3
解释：第 0 分钟消灭怪兽 0（距离 1），第 1 分钟消灭怪兽 1（距离 3），第 2 分钟消灭怪兽 2（距离 4）
```

**示例 2：**
```
输入：dist = [1, 1, 2, 3], speed = [1, 2, 1, 1]
输出：1
解释：只能消灭 1 只，第 0 分钟必须消灭到达最快的怪兽
```

**提示：**
- `n == dist.length == speed.length`
- `1 <= n <= 10^5`
- `1 <= dist[i], speed[i] <= 10^5`

---

## 解题思路

### 核心思想：贪心 - 按到达时间排序

1. 计算每只怪兽到达城市的时间：`t[i] = ceil(dist[i] / speed[i])`
2. 按到达时间升序排序
3. 贪心地依次消灭：在第 `k` 分钟（0-indexed）消灭第 `k` 只怪兽
4. 如果第 `k` 只怪兽到达时间 `t[k] <= k`，说明它已经在第 `k` 分钟前到达，游戏结束

---

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List
import math

class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        n = len(dist)
        # 计算每只怪兽到达城市的时间（向上取整）
        arrive = sorted(math.ceil(d / s) for d, s in zip(dist, speed))

        for i, t in enumerate(arrive):
            # 第 i 分钟消灭第 i 只怪兽
            # 如果该怪兽在第 i 分钟前已到达（t <= i），则游戏结束
            if t <= i:
                return i
        return n
```

### 方法二：使用整数除法（避免浮点）

```python
from typing import List

class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        # ceil(d / s) = (d + s - 1) // s（整数向上取整）
        arrive = sorted((d + s - 1) // s for d, s in zip(dist, speed))

        for i, t in enumerate(arrive):
            if t <= i:
                return i
        return len(dist)
```

### 方法三：计数桶优化（O(n) 平均）

```python
from typing import List

class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        n = len(dist)
        # 将到达时间限制在 [1, n] 范围（超过 n 则肯定能消灭）
        bucket = [0] * (n + 1)

        for d, s in zip(dist, speed):
            t = (d + s - 1) // s
            if t <= n:
                bucket[t] += 1
            # 否则 t > n，不影响

        # 从第 0 分钟开始，检查每分钟能否消灭所有到达的怪兽
        alive = 0  # 当前存活但未消灭的怪兽
        for minute in range(1, n + 1):
            alive += bucket[minute]  # 本分钟到达的怪兽
            alive -= 1               # 本分钟消灭一只
            if alive >= 1:
                # 有怪兽没有及时被消灭
                return minute
        return n
```

| 方法三（桶） | O(n) | O(n) |

## 关键点总结

1. 贪心策略：优先消灭最快到达的怪兽（按到达时间升序处理）
2. 在第 `i` 分钟消灭第 `i` 只怪兽，若该怪兽到达时间 ≤ i，则已无法阻止
3. 向上取整：`ceil(d/s) = (d + s - 1) // s`

---

## 易错点

- 注意到达时间是向上取整（不是向下）
- 第 `i` 分钟（0-indexed）消灭时，怪兽到达时间必须 > i（即在第 i 分钟结束后才到达）
