## 题目描述

在歌曲列表中，第 `i` 首歌曲的持续时间为 `time[i]` 秒。

返回其总持续时间（以秒为单位）可被 `60` 整除的歌曲对的数量。形式上，我们希望下标数字 `i` 和 `j` 满足 `i < j` 且 `(time[i] + time[j]) % 60 == 0`。

**示例 1：**
```
输入：time = [30,20,150,100,40]
输出：3
解释：这三对的总持续时间可被 60 整除：
(time[0] = 30, time[2] = 150): 总持续时间 180
(time[1] = 20, time[3] = 100): 总持续时间 120
(time[1] = 20, time[4] = 40): 总持续时间 60
```

**示例 2：**
```
输入：time = [60,60,60]
输出：3
解释：所有三对的总持续时间都是 120，可以被 60 整除。
```

**提示：**
- `1 <= time.length <= 6 * 10^4`
- `1 <= time[i] <= 500`

## 解题思路

这道题类似于"两数之和"问题，但目标是找和能被60整除的配对。

**核心观察**：
- `(a + b) % 60 == 0` 等价于 `(a % 60 + b % 60) % 60 == 0`
- 只需关注每个数对60的余数
- 余数范围：0-59

**配对规律**：
1. 余数为0的数，需要配对另一个余数为0的数
2. 余数为30的数，需要配对另一个余数为30的数
3. 余数为r的数，需要配对余数为(60-r)的数

**算法步骤**：
1. 统计每个余数出现的次数
2. 遍历数组，对每个数找它的配对余数
3. 累加配对数量

## Python 代码实现

### 方法一：哈希表计数（推荐）⭐

```python
from typing import List

class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        """
        使用哈希表记录余数出现次数
        时间复杂度：O(n)
        空间复杂度：O(1) 最多60个余数
        """
        # 记录每个余数出现的次数
        remainder_count = [0] * 60
        result = 0
        
        for t in time:
            # 计算当前时间的余数
            r = t % 60
            
            # 需要配对的余数
            # 如果r=0，需要找余数也为0的
            # 否则需要找余数为60-r的
            target = (60 - r) % 60
            
            # 累加之前出现过的配对数
            result += remainder_count[target]
            
            # 更新当前余数的计数
            remainder_count[r] += 1
        
        return result
```

### 方法二：字典计数

```python
from collections import defaultdict

class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        """
        使用字典记录余数
        时间复杂度：O(n)
        空间复杂度：O(min(n, 60))
        """
        remainder_map = defaultdict(int)
        result = 0
        
        for t in time:
            r = t % 60
            # 计算需要的配对余数
            target = (60 - r) % 60
            
            # 如果之前存在配对，累加数量
            if target in remainder_map:
                result += remainder_map[target]
            
            # 更新当前余数计数
            remainder_map[r] += 1
        
        return result
```

### 方法三：详细分类讨论

```python
class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        """
        分类讨论余数为0、30和其他情况
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        remainder_count = [0] * 60
        
        # 统计所有余数
        for t in time:
            remainder_count[t % 60] += 1
        
        result = 0
        
        # 余数为0的情况：任意两个配对
        # C(n, 2) = n * (n-1) / 2
        if remainder_count[0] > 0:
            n = remainder_count[0]
            result += n * (n - 1) // 2
        
        # 余数为30的情况：任意两个配对
        if remainder_count[30] > 0:
            n = remainder_count[30]
            result += n * (n - 1) // 2
        
        # 其他余数：r和60-r配对
        for r in range(1, 30):
            result += remainder_count[r] * remainder_count[60 - r]
        
        return result
```

### 方法四：Counter简化版

```python
from collections import Counter

class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        """
        使用Counter简化代码
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 计算所有时间对60的余数
        remainders = [t % 60 for t in time]
        counter = Counter(remainders)
        
        result = 0
        
        # 余数0和30的特殊情况
        for r in [0, 30]:
            if r in counter:
                n = counter[r]
                result += n * (n - 1) // 2
        
        # 其他余数配对
        for r in range(1, 30):
            result += counter[r] * counter[60 - r]
        
        return result
```

### 方法五：一次遍历优化

```python
class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        """
        边遍历边计数，节省空间
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        count = [0] * 60
        result = 0
        
        for t in time:
            r = t % 60
            
            # 如果余数为0，找余数为0的配对
            if r == 0:
                result += count[0]
            else:
                # 否则找余数为60-r的配对
                result += count[60 - r]
            
            # 更新当前余数计数
            count[r] += 1
        
        return result
```

## 复杂度分析

所有方法的时间和空间复杂度：
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)，最多存储60个余数

其中 n 为数组长度

## 关键点总结

1. **取模运算**：`(a + b) % 60 == 0` 转化为余数问题
2. **哈希表应用**：记录余数出现次数，快速查找配对
3. **特殊情况**：余数0和30需要自己配对
4. **一次遍历**：边遍历边统计，避免重复计算
5. **组合数学**：n个相同余数配对数 = C(n,2) = n*(n-1)/2

## 易错点

1. **重复计数**：使用一次遍历时，先查找后更新，避免重复
2. **余数为0**：`(60 - 0) % 60 = 0`，需要特殊处理
3. **余数为30**：30+30=60，也能整除，不要遗漏
4. **配对公式**：相同余数配对用组合数，不同余数用乘法
5. **边界情况**：数组长度为1时返回0
