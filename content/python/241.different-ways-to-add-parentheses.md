## 题目描述

给你一个由数字和运算符组成的字符串 `expression`，按不同优先级组合数字和运算符，计算并返回所有可能组合的结果。你可以按任意顺序返回答案。

生成的测试用例满足其对应输出值符合 32 位整数范围，不同结果的数量不超过 10^4。

**示例 1：**
```
输入：expression = "2-1-1"
输出：[0,2]
解释：
((2-1)-1) = 0 
(2-(1-1)) = 2
```

**示例 2：**
```
输入：expression = "2*3-4*5"
输出：[-34,-14,-10,-10,10]
解释：
(2*(3-(4*5))) = -34 
((2*3)-(4*5)) = -14 
((2*(3-4))*5) = -10 
(2*((3-4)*5)) = -10 
(((2*3)-4)*5) = 10
```

**提示：**
- 1 <= expression.length <= 20
- expression 由数字和算符 '+'、'-' 和 '*' 组成
- 输入表达式中的所有整数值在范围 [0, 99] 

## 解题思路

这是一道经典的**分治算法**题目，核心思想是：

1. **分治的本质**：遇到运算符就将表达式分成左右两部分，分别递归计算
2. **递归终止条件**：当表达式中没有运算符时，说明是纯数字，直接返回
3. **合并结果**：左右两部分的所有可能结果进行运算符操作，得到当前的所有可能结果

**关键观察：**
- 每个运算符都可以作为"最后一个计算的运算符"
- 以某个运算符为界，左边表达式的所有结果 × 右边表达式的所有结果 = 当前的所有结果
- 这是一个标准的分治问题，类似于表达式求值的所有可能

**优化思路：**
- 使用记忆化搜索避免重复计算相同的子表达式
- 用哈希表存储已计算过的表达式结果

## Python 代码实现

### 方法一：分治 + 递归（推荐）⭐

```python
from typing import List

class Solution:
    def diffWaysToCompute(self, expression: str) -> List[int]:
        """
        分治思想：遇到运算符就分成左右两部分
        时间复杂度：O(2^n)，最坏情况下指数级
        空间复杂度：O(2^n)，递归栈和结果存储
        """
        # 如果表达式中没有运算符，说明是纯数字
        if expression.isdigit():
            return [int(expression)]
        
        result = []
        
        # 遍历表达式，遇到运算符就分治
        for i, char in enumerate(expression):
            if char in ['+', '-', '*']:
                # 分治：计算左边部分的所有可能结果
                left = self.diffWaysToCompute(expression[:i])
                # 分治：计算右边部分的所有可能结果
                right = self.diffWaysToCompute(expression[i+1:])
                
                # 合并：左边的每个结果与右边的每个结果进行运算
                for l in left:
                    for r in right:
                        if char == '+':
                            result.append(l + r)
                        elif char == '-':
                            result.append(l - r)
                        else:  # char == '*'
                            result.append(l * r)
        
        return result
```

### 方法二：分治 + 记忆化搜索（优化版）⭐

```python
from typing import List

class Solution:
    def diffWaysToCompute(self, expression: str) -> List[int]:
        """
        在方法一基础上添加记忆化，避免重复计算
        时间复杂度：O(n * 2^n)，记忆化后显著减少重复计算
        空间复杂度：O(n * 2^n)
        """
        memo = {}
        return self.helper(expression, memo)
    
    def helper(self, expression: str, memo: dict) -> List[int]:
        # 如果已经计算过，直接返回
        if expression in memo:
            return memo[expression]
        
        # 递归终止条件：纯数字
        if expression.isdigit():
            return [int(expression)]
        
        result = []
        
        # 遍历表达式，以运算符为分界点
        for i, char in enumerate(expression):
            if char in ['+', '-', '*']:
                # 递归计算左右两部分
                left = self.helper(expression[:i], memo)
                right = self.helper(expression[i+1:], memo)
                
                # 合并结果
                for l in left:
                    for r in right:
                        if char == '+':
                            result.append(l + r)
                        elif char == '-':
                            result.append(l - r)
                        else:
                            result.append(l * r)
        
        # 记忆化存储
        memo[expression] = result
        return result
```

### 方法三：动态规划（自底向上）

```python
from typing import List

class Solution:
    def diffWaysToCompute(self, expression: str) -> List[int]:
        """
        动态规划方法：先处理小区间，再处理大区间
        时间复杂度：O(n^3 * 2^n)
        空间复杂度：O(n^2 * 2^n)
        """
        # 分离数字和运算符
        nums = []
        ops = []
        num = 0
        
        for char in expression:
            if char.isdigit():
                num = num * 10 + int(char)
            else:
                nums.append(num)
                ops.append(char)
                num = 0
        nums.append(num)
        
        n = len(nums)
        # dp[i][j] 表示从第 i 个数到第 j 个数的所有可能结果
        dp = [[[] for _ in range(n)] for _ in range(n)]
        
        # 初始化：单个数字
        for i in range(n):
            dp[i][i] = [nums[i]]
        
        # 区间 DP：从小到大枚举区间长度
        for length in range(2, n + 1):  # 区间长度
            for i in range(n - length + 1):  # 起点
                j = i + length - 1  # 终点
                
                # 枚举分割点（运算符位置）
                for k in range(i, j):
                    # 左边是 [i, k]，右边是 [k+1, j]
                    # 运算符是 ops[k]
                    for left_val in dp[i][k]:
                        for right_val in dp[k + 1][j]:
                            if ops[k] == '+':
                                dp[i][j].append(left_val + right_val)
                            elif ops[k] == '-':
                                dp[i][j].append(left_val - right_val)
                            else:
                                dp[i][j].append(left_val * right_val)
        
        return dp[0][n - 1]
```

## 复杂度分析

**方法一（分治递归）：**
- 时间复杂度：O(2^n)，其中 n 是表达式长度。最坏情况下每个运算符都会产生分支
- 空间复杂度：O(2^n)，递归调用栈和结果存储

**方法二（记忆化搜索）：**
- 时间复杂度：O(n * 2^n)，记忆化避免了大量重复计算
- 空间复杂度：O(n * 2^n)，memo 字典存储中间结果

**方法三（动态规划）：**
- 时间复杂度：O(n^3 * 2^n)
- 空间复杂度：O(n^2 * 2^n)

## 关键点总结

1. **分治思想**：遇到运算符就分成左右两部分，这是解决该题的核心
2. **递归终止条件**：当字符串是纯数字时，直接返回该数字
3. **结果合并**：左边所有结果 × 右边所有结果，进行对应运算符的计算
4. **记忆化优化**：使用字典存储已计算的子表达式结果，避免重复计算
5. **Python 技巧**：使用 `str.isdigit()` 判断是否为纯数字

## 易错点

1. **字符串切片边界**：`expression[:i]` 和 `expression[i+1:]` 要正确分割
2. **数字识别**：要正确判断是否为纯数字（可能是多位数）
3. **运算符处理**：注意减法和除法不满足交换律
4. **空结果处理**：如果表达式格式错误，要考虑返回空列表
5. **整数溢出**：虽然题目保证了范围，但在实际应用中要注意
