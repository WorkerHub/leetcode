## 题目描述

设计一个视频共享平台，支持以下操作：

- `upload(video)`：上传视频，返回分配的 `videoId`（从 0 开始，优先复用已删除的最小 ID）。
- `remove(videoId)`：删除视频。
- `watch(videoId, startMinute, endMinute)`：观看视频 `videoId` 的 `[startMinute, endMinute]` 部分，返回该视频这部分内容（字符串切片），若视频不存在返回 `"-1"`。
- `like(videoId)`：视频点赞（无效 ID 忽略）。
- `dislike(videoId)`：视频点踩（无效 ID 忽略）。
- `getLikesAndDislikes(videoId)`：返回 `[likes, dislikes]`，若 ID 无效返回 `[-1]`。
- `getViews(videoId)`：返回观看次数，若 ID 无效返回 `-1`。

## 解题思路

- 用**最小堆**维护可用的视频 ID（优先使用最小的已删除 ID）。
- 用**字典**存储视频内容、点赞数、点踩数、观看次数。
- `next_id` 维护下一个未曾使用的新 ID。

## 代码实现

### 方法一：最小堆 + 哈希表（推荐）

```python
import heapq
from typing import List

class VideoSharingPlatform:
    def __init__(self):
        self.videos = {}       # videoId -> video string
        self.likes = {}        # videoId -> like count
        self.dislikes = {}     # videoId -> dislike count
        self.views = {}        # videoId -> view count
        self.available = []    # 可复用的最小堆 ID
        self.next_id = 0       # 下一个新 ID

    def upload(self, video: str) -> int:
        # 优先复用已删除的最小 ID
        if self.available:
            vid = heapq.heappop(self.available)
        else:
            vid = self.next_id
            self.next_id += 1
        self.videos[vid] = video
        self.likes[vid] = 0
        self.dislikes[vid] = 0
        self.views[vid] = 0
        return vid

    def remove(self, videoId: int) -> None:
        if videoId in self.videos:
            del self.videos[videoId]
            del self.likes[videoId]
            del self.dislikes[videoId]
            del self.views[videoId]
            heapq.heappush(self.available, videoId)  # 归还 ID

    def watch(self, videoId: int, startMinute: int, endMinute: int) -> str:
        if videoId not in self.videos:
            return "-1"
        self.views[videoId] += 1
        # 切片（min 防止越界）
        v = self.videos[videoId]
        return v[startMinute:min(endMinute + 1, len(v))]

    def like(self, videoId: int) -> None:
        if videoId in self.videos:
            self.likes[videoId] += 1

    def dislike(self, videoId: int) -> None:
        if videoId in self.videos:
            self.dislikes[videoId] += 1

    def getLikesAndDislikes(self, videoId: int) -> List[int]:
        if videoId not in self.videos:
            return [-1]
        return [self.likes[videoId], self.dislikes[videoId]]

    def getViews(self, videoId: int) -> int:
        if videoId not in self.videos:
            return -1
        return self.views[videoId]
```

### 方法二：使用 dataclass 整合数据

```python
import heapq
from dataclasses import dataclass, field
from typing import List, Dict

@dataclass
class Video:
    content: str
    likes: int = 0
    dislikes: int = 0
    views: int = 0

class VideoSharingPlatform:
    def __init__(self):
        self.store: Dict[int, Video] = {}
        self.recycled: List[int] = []  # 最小堆
        self.next_id = 0

    def upload(self, video: str) -> int:
        vid = heapq.heappop(self.recycled) if self.recycled else (
            (self.next_id := self.next_id + 1) - 1
        )
        self.store[vid] = Video(content=video)
        return vid

    def remove(self, videoId: int) -> None:
        if videoId in self.store:
            del self.store[videoId]
            heapq.heappush(self.recycled, videoId)

    def watch(self, videoId: int, startMinute: int, endMinute: int) -> str:
        if videoId not in self.store:
            return "-1"
        v = self.store[videoId]
        v.views += 1
        return v.content[startMinute:endMinute + 1]

    def like(self, videoId: int) -> None:
        if videoId in self.store:
            self.store[videoId].likes += 1

    def dislike(self, videoId: int) -> None:
        if videoId in self.store:
            self.store[videoId].dislikes += 1

    def getLikesAndDislikes(self, videoId: int) -> List[int]:
        if videoId not in self.store:
            return [-1]
        v = self.store[videoId]
        return [v.likes, v.dislikes]

    def getViews(self, videoId: int) -> int:
        return self.store[videoId].views if videoId in self.store else -1
```

## 复杂度分析

- upload：O(log n)，堆操作。
- remove：O(log n)，堆操作。
- watch/like/dislike：O(1)。
- getLikesAndDislikes/getViews：O(1)。

## 关键点总结

1. 最小堆管理可复用 ID，`heappop` 取最小已删除 ID，`heappush` 归还 ID。
2. 上传时优先使用已删除的最小 ID，其次使用递增的新 ID。
3. 被删除的视频不能进行点赞/观看等操作，所以先判断是否在字典中。

## 易错点

- 删除视频后，该 videoId 的所有统计数据应同时清除。
- `watch` 方法返回字符串切片，`endMinute` 超出视频长度时截断（`min(endMinute+1, len(v))`）。
