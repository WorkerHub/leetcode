## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。请你向 `nums` 中追加 `k` 个**未出现**在 `nums` 中的、**互不相同**的**正整数**，并使结果数组的元素和**最小**。

返回追加到 `nums` 中的 `k` 个整数之和。

**示例 1：**
```
输入：nums = [1,4,25,10,25], k = 2
输出：5
解释：追加 2 和 3（均不在 nums 中），和为 5。
```

**示例 2：**
```
输入：nums = [5,6], k = 6
输出：25
解释：追加 1,2,3,4,7,8，和为 25。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^8`

## 解题思路

**贪心：从 1 开始选最小的未出现正整数**

为了使和最小，应尽量选最小的 `k` 个不在 `nums` 中的正整数。

先对 `nums` 去重排序，然后在间隙中逐段填入未出现的整数：

- 考虑区间 `[prev+1, nums[i]-1]`（当前数和前一个数之间的空隙），将其中的整数尽量加入结果。
- 用等差数列公式快速计算一段连续整数的和：`sum(a, b) = (a + b) * (b - a + 1) // 2`。

## 代码实现

### 方法一：排序 + 等差数列（推荐）

```python
from typing import List

class Solution:
    def minimalKSum(self, nums: List[int], k: int) -> int:
        # 去重排序
        nums = sorted(set(nums))
        ans = 0
        prev = 0  # 上一个已排除的数

        for x in nums:
            if k <= 0:
                break
            # [prev+1, x-1] 之间的整数都可以使用
            available = x - 1 - prev  # 可用数量
            use = min(available, k)   # 实际使用数量
            if use > 0:
                # 等差数列求和：prev+1 到 prev+use
                a, b = prev + 1, prev + use
                ans += (a + b) * use // 2
                k -= use
            prev = x

        # 如果还需要更多，从 prev+1 开始继续
        if k > 0:
            a, b = prev + 1, prev + k
            ans += (a + b) * k // 2

        return ans
```

### 方法二：手动标记（小数据）

```python
from typing import List

class Solution:
    def minimalKSum(self, nums: List[int], k: int) -> int:
        excluded = set(nums)
        ans = 0
        cur = 1
        count = 0
        while count < k:
            if cur not in excluded:
                ans += cur
                count += 1
            cur += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 等差数列 | O(n log n) | O(n) |
| 逐一标记 | O(n + k)，当 k 大时很慢 | O(n) |

## 关键点总结

1. 排序去重后，遍历每对相邻数之间的"空隙"，用等差数列公式快速求和。
2. 最后若还差 `k` 个，从最大数之后继续取连续整数。
3. 等差数列公式：`1 + 2 + ... + n = n*(n+1)//2`。

## 易错点

- 去重：`nums` 中可能有重复元素，要先 `set` 去重再排序。
- 等差数列求和时注意整数范围（Python 无溢出问题）。
