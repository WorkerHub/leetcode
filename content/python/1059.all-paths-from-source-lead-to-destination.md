## 题目描述

给定有向图的边 `edges`，以及该图的起始节点 `source` 和目标节点 `destination`，确定从起始节点 `source` 出发的所有路径是否最终都以目标节点 `destination` 结束。

也就是说：
- 至少存在一条从 `source` 到 `destination` 的路径
- 如果从 `source` 出发存在路径，则该路径必须以 `destination` 结束
- 路径数量必须是有限的

当从 `source` 出发的所有路径都以 `destination` 结束时，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：n = 3, edges = [[0,1],[0,2]], source = 0, destination = 2
输出：false
解释：存在从节点 0 到节点 1 的路径，但它不以节点 2 结束。
```

**示例 2：**
```
输入：n = 4, edges = [[0,1],[0,3],[1,2],[2,1]], source = 0, destination = 3
输出：false
解释：存在环 1 → 2 → 1，路径数量无限。
```

**示例 3：**
```
输入：n = 4, edges = [[0,1],[0,2],[1,3],[2,3]], source = 0, destination = 3
输出：true
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= edges.length <= 10^4`
- `edges[i].length == 2`
- `0 <= source <= n - 1`
- `0 <= destination <= n - 1`
- 给定的图可能存在自环和平行边

## 解题思路

这道题需要验证三个条件：
1. **目标节点无出边**：`destination` 不能有出边，否则路径可以继续
2. **无环**：图中不能有环，否则路径无限
3. **所有路径都到达目标**：从 `source` 出发的所有路径都必须到达 `destination`

**算法流程（DFS + 三色标记）：**
- **白色（0）**：未访问
- **灰色（1）**：正在访问（在当前 DFS 路径中）
- **黑色（2）**：已完成访问

**检查条件：**
1. 如果遇到灰色节点 → 有环
2. 如果非目标节点无出边 → 存在不到达目标的路径
3. 如果目标节点有出边 → 路径不会终止

## Python 代码实现

### 方法一：DFS + 三色标记（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def leadsToDestination(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        """
        时间复杂度：O(V + E)
        空间复杂度：O(V + E)
        """
        # 构建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
        
        # 目标节点不能有出边
        if graph[destination]:
            return False
        
        # 状态：0-未访问，1-访问中（灰色），2-已完成（黑色）
        state = [0] * n
        
        def dfs(node: int) -> bool:
            # 如果是目标节点，路径有效
            if node == destination:
                return True
            
            # 标记为访问中
            state[node] = 1
            
            # 如果节点无出边且不是目标节点，路径无效
            if not graph[node]:
                return False
            
            # 遍历所有邻居
            for neighbor in graph[node]:
                # 如果邻居在当前路径中（灰色），说明有环
                if state[neighbor] == 1:
                    return False
                
                # 如果邻居未访问，递归检查
                if state[neighbor] == 0:
                    if not dfs(neighbor):
                        return False
            
            # 标记为已完成
            state[node] = 2
            return True
        
        return dfs(source)
```

### 方法二：带记忆化的 DFS

```python
from typing import List
from collections import defaultdict

class Solution:
    def leadsToDestination(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        """
        使用记忆化避免重复计算
        """
        # 构建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
        
        # 目标节点不能有出边
        if graph[destination]:
            return False
        
        # memo[node] = True/False 表示从 node 出发是否都到达 destination
        memo = {}
        visiting = set()  # 记录正在访问的节点（检测环）
        
        def dfs(node: int) -> bool:
            # 到达目标节点
            if node == destination:
                return True
            
            # 已经计算过
            if node in memo:
                return memo[node]
            
            # 检测环
            if node in visiting:
                return False
            
            # 无出边但不是目标节点
            if not graph[node]:
                return False
            
            # 标记为访问中
            visiting.add(node)
            
            # 检查所有邻居
            result = all(dfs(neighbor) for neighbor in graph[node])
            
            # 移除访问标记
            visiting.remove(node)
            
            # 记忆化
            memo[node] = result
            return result
        
        return dfs(source)
```

### 方法三：简化版

```python
from typing import List
from collections import defaultdict

class Solution:
    def leadsToDestination(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        """
        简化的 DFS 实现
        """
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
        
        # 检查目标节点无出边
        if graph[destination]:
            return False
        
        state = {}  # 0: 白色, 1: 灰色, 2: 黑色
        
        def dfs(node):
            if node == destination:
                return True
            
            if node in state:
                return state[node] == 2  # 只有黑色节点才是有效的
            
            if not graph[node]:  # 非目标节点无出边
                return False
            
            state[node] = 1  # 标记为灰色
            
            for neighbor in graph[node]:
                if not dfs(neighbor):
                    return False
            
            state[node] = 2  # 标记为黑色
            return True
        
        return dfs(source)
```

## 复杂度分析

**时间复杂度：** O(V + E)
- V 是节点数，E 是边数
- 每个节点最多访问一次
- 每条边最多遍历一次

**空间复杂度：** O(V + E)
- 图的存储：O(E)
- 递归栈：O(V)
- 状态数组：O(V)

## 关键点总结

1. **三色标记**：白色（未访问）、灰色（访问中）、黑色（已完成）
2. **环检测**：如果遇到灰色节点，说明有环
3. **目标节点检查**：目标节点必须无出边
4. **叶子节点检查**：非目标节点如果无出边，则路径无效

## 易错点

1. **目标节点出边**：忘记检查目标节点是否有出边
2. **环检测**：只检查已访问不够，必须区分灰色和黑色
3. **叶子节点**：非目标的叶子节点应该返回 `False`
4. **记忆化陷阱**：记忆化时要注意环的影响
