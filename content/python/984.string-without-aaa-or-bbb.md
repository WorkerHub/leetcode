## 题目描述

给定两个整数 a 和 b，返回任意字符串 s，要求满足：

- s 只包含字母 'a' 和 'b'
- s 中 'a' 的数量为 a
- s 中 'b' 的数量为 b
- s 不包含 "aaa" 或 "bbb" 作为子串

## Python 代码实现

```python
class Solution:
    def strWithout3a3b(self, a: int, b: int) -> str:
        result = []
        
        while a > 0 or b > 0:
            if len(result) >= 2 and result[-1] == result[-2]:
                # 上两个字符相同，必须添加另一个字符
                write_a = result[-1] == 'b'
            else:
                # 添加数量较多的字符
                write_a = a >= b
            
            if write_a:
                result.append('a')
                a -= 1
            else:
                result.append('b')
                b -= 1
        
        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O(a + b)
- 空间复杂度：O(1)
