## 题目描述

给你一个字符串 `s` 和一个机器人，机器人当前有一个空字符串 `t`。执行以下操作之一，直到 `s` 和 `t` 都变为空：

- 将字符 `s[0]` 从 `s` 中取出，并将它添加到 `t` 的末尾。
- 将字符 `t[t.length - 1]` 从 `t` 中取出，并写到纸上（即弹出 t 的末尾字符到结果中）。

返回写到纸上的字符串，要求这个字符串的字典序最小。

**示例 1：**
```
输入：s = "zza"
输出："azz"
解释：把 "zza" 按顺序压入 t，再依次弹出 a、z、z。
```

**示例 2：**
```
输入：s = "bac"
输出："abc"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

**贪心 + 栈：**

`t` 是一个栈（只能从末尾弹出）。贪心地决定何时弹出：

**贪心策略：** 当栈顶元素 `t[-1]` 小于等于 `s` 中**剩余字符的最小值**时，弹出栈顶（否则继续压栈）。

**原因：** 如果栈顶比后面所有字符都小，那么现在弹出是最优的（字典序最小要尽早输出小字符）。如果后面还有更小的字符，应先入栈等更小字符，让更小字符更早出现。

**实现：**
1. 预计算 `suffix_min[i]` = `s[i:]` 中的最小字符
2. 从左到右读 `s`，将字符压入栈
3. 每次压栈后，检查栈顶是否 <= `suffix_min[当前位置]`，若是则弹出（循环直到条件不满足）

## 代码实现

### 方法一：贪心 + 栈（推荐）

```python
class Solution:
    def robotWithString(self, s: str) -> str:
        n = len(s)
        # 预计算后缀最小值：suffix_min[i] = s[i:] 的最小字符
        suffix_min = [''] * (n + 1)
        suffix_min[n] = 'z'  # 哨兵，比所有字母都大
        for i in range(n - 1, -1, -1):
            suffix_min[i] = min(s[i], suffix_min[i + 1])

        stack = []   # 模拟 t（栈）
        result = []  # 输出结果

        for i, ch in enumerate(s):
            stack.append(ch)  # 将字符压入栈
            # 当栈顶字符 <= s[i+1:] 中的最小字符时，弹出
            while stack and stack[-1] <= suffix_min[i + 1]:
                result.append(stack.pop())

        # 清空栈中剩余字符
        while stack:
            result.append(stack.pop())

        return ''.join(result)
```

### 方法二：实时计算后缀最小值

```python
from collections import Counter

class Solution:
    def robotWithString(self, s: str) -> str:
        # 用计数器维护 s 中剩余字符的频率
        cnt = Counter(s)
        stack = []
        result = []

        def get_min_remaining() -> str:
            """返回当前剩余字符中的最小值"""
            for c in 'abcdefghijklmnopqrstuvwxyz':
                if cnt[c] > 0:
                    return c
            return '{' # 所有字符用完时，返回比 z 大的字符

        for ch in s:
            stack.append(ch)
            cnt[ch] -= 1
            # 贪心：只要栈顶 <= 剩余最小字符，就弹出
            while stack and stack[-1] <= get_min_remaining():
                result.append(stack.pop())

        while stack:
            result.append(stack.pop())

        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 预计算后缀最小值 | O(n) | O(n) |
| 实时计算 | O(26n) = O(n) | O(n) |

## 关键点总结

1. 贪心：栈顶比后面所有字符都小（等于也行），立即弹出
2. 后缀最小值 `suffix_min[i]` 预计算，O(1) 比较
3. 循环弹出：一次压栈后可能弹出多个元素

## 易错点

- 每次压栈后都需要循环检查（不只检查一次）
- 后缀最小值的边界：`suffix_min[n] = 'z'`（s 读完后，后缀最小值为无穷大）
