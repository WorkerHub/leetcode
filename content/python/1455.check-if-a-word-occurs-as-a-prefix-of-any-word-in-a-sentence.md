## 题目描述

给你一个字符串 `sentence` 作为句子，并指定检索词为 `searchWord`，其中句子由若干用**单个空格**分隔的单词组成。

请你检查检索词 `searchWord` 是否为句子 `sentence` 中任意单词的**前缀**。

- 如果 `searchWord` 是某一个单词的前缀，则返回句子 `sentence` 中该单词所对应的下标（**下标从 1 开始**）。
- 如果 `searchWord` 是多个单词的前缀，则返回匹配的第一个单词的下标。
- 如果 `searchWord` 不是任何单词的前缀，则返回 `-1`。

**示例 1：**
```
输入：sentence = "i love eating burger", searchWord = "burg"
输出：4
解释："burg" 是 "burger" 的前缀，"burger" 是句子第 4 个单词。
```

**示例 2：**
```
输入：sentence = "this problem is an easy problem", searchWord = "pro"
输出：2
解释："pro" 是 "problem" 的前缀，"problem" 分别是第 2 个和第 6 个单词，返回最小下标 2。
```

**示例 3：**
```
输入：sentence = "i am tired", searchWord = "you"
输出：-1
```

**提示：**
- `1 <= sentence.length <= 100`
- `1 <= searchWord.length <= 10`
- `sentence` 由小写英文字母和空格组成
- `searchWord` 由小写英文字母组成
- 句子中单词之间只有单个空格

## 解题思路

分割句子为单词列表，然后逐个检查每个单词是否以 `searchWord` 开头。

Python 的字符串方法 `startswith()` 可以直接完成前缀判断，配合 `enumerate` 获取 1-indexed 的位置。

## Python 代码实现

### 方法一：split + enumerate + startswith（推荐）

```python
class Solution:
    def isPrefixOfWord(self, sentence: str, searchWord: str) -> int:
        # 分割句子为单词列表
        words = sentence.split()

        # enumerate 从 1 开始计数（题目要求 1-indexed）
        for i, word in enumerate(words, start=1):
            if word.startswith(searchWord):
                return i  # 返回第一个匹配的下标

        return -1  # 没有找到
```

### 方法二：字符串切片手动判断前缀

```python
class Solution:
    def isPrefixOfWord(self, sentence: str, searchWord: str) -> int:
        words = sentence.split()
        n = len(searchWord)

        for i, word in enumerate(words, start=1):
            # 手动检查前缀：截取单词前 n 个字符比较
            if len(word) >= n and word[:n] == searchWord:
                return i

        return -1
```

### 方法三：find 方法（不推荐，但可以了解）

```python
class Solution:
    def isPrefixOfWord(self, sentence: str, searchWord: str) -> int:
        words = sentence.split()

        for i, word in enumerate(words, start=1):
            # find 返回 searchWord 在 word 中首次出现的位置
            # 如果是前缀，则出现在位置 0
            if word.find(searchWord) == 0:
                return i

        return -1
```

## 复杂度分析

- 时间复杂度：O(n × m)，n 为单词数，m 为 searchWord 长度
- 空间复杂度：O(n)，split 后的单词列表

## 关键点总结

1. `str.startswith(prefix)` 是 Python 判断前缀的最简洁方式
2. `enumerate(iterable, start=1)` 可以从 1 开始计数，符合题目要求
3. 遇到第一个匹配就立刻返回，自然保证返回最小下标

## 易错点

- 注意下标从 **1** 开始，不是 0；使用 `enumerate(words, start=1)` 即可
- 不要混淆"前缀"和"包含"：`"pro" in "problem"` 是包含，`"problem".startswith("pro")` 才是前缀判断
