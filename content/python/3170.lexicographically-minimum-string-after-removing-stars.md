## 题目描述

给你一个字符串 `s`，其中包含小写英文字母和星号 `*`。

每次遇到 `*` 时，必须删除 `*` 以及其左边 **最小字典序** 的字符（若有多个相同最小字符，删除最靠右的那个）。

返回删除所有 `*` 后的字符串。

**示例 1：**
```
输入：s = "aaba*"
输出："aab"
解释：遇到 * 时删除最小字符 'a'（最靠右的 a，下标 1），得到 "aab"。
```

**示例 2：**
```
输入：s = "abc"
输出："abc"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写字母和 `*`

## 解题思路

维护 26 个字母各自的下标列表（或堆）。遇到 `*` 时，找最小字母的最靠右下标并标记删除。最后按顺序输出未删除的字符。

## Python 代码实现

### 方法一：26 个列表维护（推荐）

```python
class Solution:
    def clearStars(self, s: str) -> str:
        # 每个字母的下标列表（从左到右加入）
        buckets = [[] for _ in range(26)]
        deleted = [False] * len(s)

        for i, c in enumerate(s):
            if c == '*':
                # 找最小字母（字典序最小），删除最靠右的那个
                deleted[i] = True
                for k in range(26):
                    if buckets[k]:
                        j = buckets[k].pop()  # 最靠右的下标
                        deleted[j] = True
                        break
            else:
                buckets[ord(c) - ord('a')].append(i)

        return ''.join(s[i] for i in range(len(s)) if not deleted[i])
```

### 方法二：使用堆（负索引）

```python
import heapq

class Solution:
    def clearStars(self, s: str) -> str:
        heap = []  # (字母, -下标) 的最小堆
        deleted = set()

        for i, c in enumerate(s):
            if c == '*':
                deleted.add(i)
                # 弹出字典序最小、下标最大的字母
                ch, neg_i = heapq.heappop(heap)
                deleted.add(-neg_i)
            else:
                heapq.heappush(heap, (c, -i))

        return ''.join(s[i] for i in range(len(s)) if i not in deleted)
```

## 复杂度分析

- 时间复杂度：O(n * 26)（方法一），O(n log n)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 遇到 `*` 时贪心删除最小字母中最靠右的那个
2. 用 26 个列表分别维护每个字母的下标（栈）
3. 最后按原顺序输出未删除字符

## 易错点

1. "最靠右"等价于栈顶（最后加入的）
2. `*` 本身也要被删除
