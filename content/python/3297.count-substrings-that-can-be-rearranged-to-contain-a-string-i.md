## 题目描述

给你两个字符串 `word1` 和 `word2`。

如果一个字符串 `x` 可以**重排**成包含 `word2` 作为前缀（即 `x` 的某个排列以 `word2` 开头），则称该字符串满足条件。

返回 `word1` 中满足条件的**子字符串**数量。

**示例 1：**
```
输入：word1 = "bcca", word2 = "abc"
输出：1
解释：子字符串 "bcca" 包含 a>=1, b>=1, c>=2，可以重排为 "abcc"，以 "abc" 开头
```

**示例 2：**
```
输入：word1 = "abcabc", word2 = "abc"
输出：10
```

**提示：**
- `1 <= word1.length <= 10^5`
- `1 <= word2.length <= 10^4`

## 解题思路

**滑动窗口**：一个子字符串能重排包含 word2 作为前缀，等价于该子字符串**包含 word2 中每个字符所需的数量**（即子字符串中每种字符数量 >= word2 中对应字符数量）。

用双指针滑动窗口：
- 维护窗口 `[left, right]`，统计窗口内每种字符的数量
- 当窗口满足条件时，所有以 `right` 结尾且以 `left` 或更早开始的子字符串都满足条件
- 计数 += left（表示满足条件的左端选择）

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def validSubstringCount(self, word1: str, word2: str) -> int:
        need = Counter(word2)
        have = Counter()
        deficit = len(need)  # 还需要满足的字符种数
        
        ans = 0
        left = 0
        
        for right in range(len(word1)):
            c = word1[right]
            have[c] += 1
            if c in need and have[c] == need[c]:
                deficit -= 1
            
            # 当窗口满足条件时，收缩左端直到不满足
            while deficit == 0:
                ans += len(word1) - right  # 以 right 结尾，左端从 left 到某处的子串都满足
                lc = word1[left]
                have[lc] -= 1
                if lc in need and have[lc] < need[lc]:
                    deficit += 1
                left += 1
        
        return ans
```

### 方法二：双指针统计

```python
from collections import Counter

class Solution:
    def validSubstringCount(self, word1: str, word2: str) -> int:
        need = Counter(word2)
        win = Counter()
        satisfied = 0  # 已满足的字符种数
        total_need = len(need)
        
        left = 0
        ans = 0
        
        for right, c in enumerate(word1):
            win[c] += 1
            if win[c] == need.get(c, 0) and c in need:
                satisfied += 1
            
            while satisfied == total_need:
                # 当前窗口满足，以 right 为右端，left 及之前的都可以作为左端
                ans += len(word1) - right
                lc = word1[left]
                if lc in need and win[lc] == need[lc]:
                    satisfied -= 1
                win[lc] -= 1
                left += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(|word1| + |word2|)
- 空间复杂度：O(26)

## 关键点总结

1. 子字符串能包含 word2 的重排 = 字符数量满足 word2 的要求
2. 滑动窗口找最小满足窗口，统计满足条件的子串数
3. 当窗口 [l, r] 满足时，[0, r], [1, r], ..., [l, r] 都满足，共 l+1 个

## 易错点

1. 统计的是满足条件的子字符串数量，不是唯一子字符串
2. 满足条件后向右扩展，以当前右端结尾的都满足
