## 题目描述

基因序列可以表示为一条由 8 个字符组成的字符串，其中每个字符都是 `'A'`、`'C'`、`'G'` 和 `'T'` 之一。

假设我们需要调查从基因序列 `start` 变为 `end` 所发生的基因变化。一次基因变化就意味着这个基因序列中的一个字符发生了变化。

- 例如，`"AACCGGTT" --> "AACCGGTA"` 就是一次基因变化。

另有一个基因库 `bank` 记录了所有有效的基因变化，只有基因库中的基因才是有效的基因序列。（变化后的基因必须位于基因库 `bank` 中）

给你两个基因序列 `start` 和 `end`，以及一个基因库 `bank`，请你找出并返回能够使 `start` 变化为 `end` 所需的最少变化次数。如果无法完成此基因变化，返回 `-1`。

注意：起始基因序列 `start` 默认是有效的，但是它并不一定会出现在基因库中。

**示例 1：**
```
输入：start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]
输出：1
```

**示例 2：**
```
输入：start = "AACCGGTT", end = "AAACGGTA", bank = ["AACCGGTA","AACCGCTA","AAACGGTA"]
输出：2
```

**提示：**
- `0 <= bank.length <= 10`
- `start.length == end.length == bank[i].length == 8`
- `start`、`end` 以及 `bank[i]` 仅由字符 `['A', 'C', 'G', 'T']` 组成

## 解题思路

这道题本质是一个最短路径问题，可以使用广度优先搜索（BFS）解决。

**关键观察：**
1. 每次只能改变一个字符
2. 变化后的基因必须在 bank 中
3. 要找最少的变化次数 -> BFS

**算法流程：**
1. 将 bank 转为集合，方便快速查找
2. 使用 BFS 从 start 开始搜索
3. 每次尝试改变一个位置的字符（4种可能）
4. 如果新基因在 bank 中且未访问过，加入队列
5. 直到找到 end 或队列为空

## Python 代码实现

### 方法一：BFS ⭐ 推荐

```python
from typing import List
from collections import deque

class Solution:
    def minMutation(self, start: str, end: str, bank: List[str]) -> int:
        # 如果 end 不在基因库中，无法到达
        if end not in bank:
            return -1
        
        # 转为集合，快速查找
        bank_set = set(bank)
        
        # BFS
        queue = deque([(start, 0)])  # (当前基因, 变化次数)
        visited = {start}
        genes = ['A', 'C', 'G', 'T']
        
        while queue:
            current, steps = queue.popleft()
            
            # 找到目标
            if current == end:
                return steps
            
            # 尝试改变每个位置
            for i in range(8):
                # 尝试每种字符
                for gene in genes:
                    if gene == current[i]:
                        continue
                    
                    # 生成新基因
                    new_gene = current[:i] + gene + current[i+1:]
                    
                    # 如果在基因库中且未访问过
                    if new_gene in bank_set and new_gene not in visited:
                        queue.append((new_gene, steps + 1))
                        visited.add(new_gene)
        
        return -1
```

### 方法二：优化版（预先计算差异）

```python
from typing import List
from collections import deque

class Solution:
    def minMutation(self, start: str, end: str, bank: List[str]) -> int:
        if end not in bank:
            return -1
        
        # 判断两个基因是否只差一个字符
        def one_diff(gene1, gene2):
            diff = 0
            for c1, c2 in zip(gene1, gene2):
                if c1 != c2:
                    diff += 1
                    if diff > 1:
                        return False
            return diff == 1
        
        # BFS
        queue = deque([(start, 0)])
        visited = {start}
        
        while queue:
            current, steps = queue.popleft()
            
            if current == end:
                return steps
            
            # 遍历基因库，找到所有相差一个字符的基因
            for gene in bank:
                if gene not in visited and one_diff(current, gene):
                    queue.append((gene, steps + 1))
                    visited.add(gene)
        
        return -1
```

### 方法三：双向 BFS

```python
from typing import List

class Solution:
    def minMutation(self, start: str, end: str, bank: List[str]) -> int:
        if end not in bank:
            return -1
        
        bank_set = set(bank)
        genes = ['A', 'C', 'G', 'T']
        
        # 双向 BFS
        begin_set = {start}
        end_set = {end}
        visited = set()
        steps = 0
        
        while begin_set and end_set:
            # 始终从小的集合开始搜索
            if len(begin_set) > len(end_set):
                begin_set, end_set = end_set, begin_set
            
            next_set = set()
            
            for current in begin_set:
                # 尝试所有可能的变化
                for i in range(8):
                    for gene in genes:
                        if gene == current[i]:
                            continue
                        
                        new_gene = current[:i] + gene + current[i+1:]
                        
                        # 如果在另一端找到，返回结果
                        if new_gene in end_set:
                            return steps + 1
                        
                        if new_gene in bank_set and new_gene not in visited:
                            next_set.add(new_gene)
                            visited.add(new_gene)
            
            begin_set = next_set
            steps += 1
        
        return -1
```

## 复杂度分析

**方法一：BFS**
- 时间复杂度：O(N × L × C)
  - N = bank 的长度
  - L = 基因长度（8）
  - C = 字符集大小（4）
- 空间复杂度：O(N)，visited 集合

**方法二：优化版**
- 时间复杂度：O(N² × L)
- 空间复杂度：O(N)

**方法三：双向 BFS**
- 时间复杂度：O(N × L × C)，但实际更快
- 空间复杂度：O(N)

## 关键点总结

1. **BFS 应用**：最短路径问题用 BFS
2. **状态表示**：基因序列就是状态
3. **转移条件**：只改变一个字符，且在 bank 中
4. **visited 集合**：避免重复访问
5. **双向 BFS**：从两端同时搜索，提高效率

## 易错点

1. **end 不在 bank**：要先检查 end 是否在 bank 中
2. **字符串不可变**：Python 字符串不可变，要用切片拼接
3. **visited 初始化**：start 要加入 visited
4. **返回值**：找不到路径返回 -1
5. **步数计数**：每层结束后才加 1
