## 题目描述

给你单链表的头指针 `head` 和两个整数 `left` 和 `right`，其中 `left <= right`。请你反转从位置 `left` 到位置 `right` 的链表节点，返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5], left = 2, right = 4
输出：[1,4,3,2,5]
```

**示例 2：**
```
输入：head = [5], left = 1, right = 1
输出：[5]
```

**提示：**
- 链表中节点数目为 `n`
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

**进阶：** 你可以使用一趟扫描完成反转吗？

## 解题思路

**核心思想：部分链表反转**

这道题是在完整链表反转的基础上，只反转指定区间 `[left, right]` 的节点。

**关键观察：**
1. 需要找到 `left - 1` 位置的节点（反转区域的前一个节点）
2. 反转 `[left, right]` 区间的节点
3. 将反转后的部分重新连接到原链表

**步骤分解：**
1. 找到第 `left - 1` 个节点（称为 `pre`）
2. 从第 `left` 个节点开始反转，反转 `right - left + 1` 个节点
3. 连接三部分：前半部分 → 反转部分 → 后半部分

**两种方法：**
- 方法一：头插法（一次遍历）
- 方法二：穿针引线法（先反转再连接）

## Python 代码实现

### 方法一：头插法（推荐）

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        # 使用哑节点简化边界处理
        dummy = ListNode(0, head)
        pre = dummy
        
        # 找到 left - 1 位置的节点
        for _ in range(left - 1):
            pre = pre.next
        
        # cur 指向 left 位置的节点
        cur = pre.next
        
        # 反转 right - left 次
        # 每次将 cur.next 移动到 pre.next
        for _ in range(right - left):
            # 保存要移动的节点
            next_node = cur.next
            # 将 cur.next 指向 next_node.next
            cur.next = next_node.next
            # 将 next_node 插入到 pre 后面
            next_node.next = pre.next
            pre.next = next_node
        
        return dummy.next
```

### 方法二：穿针引线法

```python
class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        # 反转链表的辅助函数
        def reverse_list(head: ListNode) -> ListNode:
            pre = None
            cur = head
            while cur:
                next_node = cur.next
                cur.next = pre
                pre = cur
                cur = next_node
            return pre
        
        # 哑节点
        dummy = ListNode(0, head)
        pre = dummy
        
        # 找到 left - 1 位置的节点
        for _ in range(left - 1):
            pre = pre.next
        
        # left 位置的节点
        left_node = pre.next
        
        # 找到 right 位置的节点
        right_node = left_node
        for _ in range(right - left):
            right_node = right_node.next
        
        # 保存 right 后面的节点
        succ = right_node.next
        
        # 切断链表
        pre.next = None
        right_node.next = None
        
        # 反转 [left, right] 部分
        reverse_list(left_node)
        
        # 重新连接
        pre.next = right_node  # right_node 现在是反转后的头节点
        left_node.next = succ  # left_node 现在是反转后的尾节点
        
        return dummy.next
```

### 方法三：递归法

```python
class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        # 递归反转前 n 个节点
        successor = None  # 后驱节点
        
        def reverse_n(head: ListNode, n: int) -> ListNode:
            nonlocal successor
            if n == 1:
                # 记录第 n + 1 个节点
                successor = head.next
                return head
            
            # 反转前 n - 1 个节点
            last = reverse_n(head.next, n - 1)
            
            # 反转指针
            head.next.next = head
            # 连接后驱
            head.next = successor
            
            return last
        
        # 如果 left == 1，相当于反转前 right 个节点
        if left == 1:
            return reverse_n(head, right)
        
        # 前进到 left 位置，问题转化为反转前 right - left + 1 个节点
        head.next = self.reverseBetween(head.next, left - 1, right - 1)
        
        return head
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，n 为链表长度，遍历一次
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法三：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归调用栈

## 图解示例

以 `head = [1,2,3,4,5], left = 2, right = 4` 为例（方法一：头插法）：

```
初始状态：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
        pre  cur

第 1 次操作（将节点 3 移到前面）：
dummy -> 1 -> 3 -> 2 -> 4 -> 5 -> null
        pre       cur

第 2 次操作（将节点 4 移到前面）：
dummy -> 1 -> 4 -> 3 -> 2 -> 5 -> null
        pre            cur

结果：[1,4,3,2,5]
```

**穿针引线法图解：**
```
原链表：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
        pre  left      right succ

切断：
dummy -> 1    2 -> 3 -> 4    5 -> null
        pre  left      right succ

反转中间部分：
dummy -> 1    4 -> 3 -> 2    5 -> null
        pre  right     left succ

重新连接：
dummy -> 1 -> 4 -> 3 -> 2 -> 5 -> null
```

## 关键点总结

1. **哑节点**：处理从头节点开始反转的情况（left = 1）
2. **头插法**：每次将待反转的节点插入到反转区域的头部
3. **穿针引线**：先找到关键节点，断开、反转、重连
4. **反转次数**：需要反转 `right - left` 次，不是 `right - left + 1` 次
5. **指针维护**：pre 始终指向反转区域的前一个节点

## 易错点

1. **边界情况**：left = 1 时，需要反转头节点（使用哑节点解决）
2. **反转次数**：头插法需要操作 `right - left` 次
3. **指针混乱**：头插法中 cur 始终不动，移动的是 cur.next
4. **连接错误**：穿针引线法要正确连接三部分
5. **递归理解**：递归法需要理解"反转前 n 个节点"的子问题
