## 题目描述

给定一个许可密钥字符串 s，仅由字母、数字字符和破折号组成。字符串由 n 个破折号分隔成 n + 1 组。你也会得到一个整数 k。

我们想要重新格式化字符串 s，使每一组包含 k 个字符，除了第一组，它可以比 k 短，但仍必须包含至少一个字符。此外，两组之间必须插入破折号，并且应该将所有小写字母转换为大写字母。

返回重新格式化的许可密钥。

**示例 1：**
```
输入：s = "5F3Z-2e-9-w", k = 4
输出："5F3Z-2E9W"
解释：字符串 s 被分成了两个部分，每部分 4 个字符；
     注意，两个额外的破折号需要删掉。
```

**示例 2：**
```
输入：s = "2-5g-3-J", k = 2
输出："2-5G-3J"
解释：字符串 s 被分成了 3 个部分，按照前面的规则描述，第一部分的字符可以少于给定的数量，其余部分皆为 2 个字符。
```

**提示：**
- 1 <= s.length <= 10^5
- s 只包含字母、数字和破折号 '-'
- 1 <= k <= 10^4

## 解题思路

这是一道字符串格式化题目，核心思路是：

1. **移除所有破折号**：先将字符串中的所有 '-' 去掉
2. **转换为大写**：将所有字母转为大写
3. **从后向前分组**：
   - 从字符串末尾开始，每 k 个字符分为一组
   - 第一组（最前面）可以少于 k 个字符
4. **插入破折号**：在各组之间插入 '-'

**关键观察**：
- 从后向前处理更简单，因为最后一组一定是满的（k 个字符）
- 第一组是剩余的字符，可能少于 k 个
- 使用反转可以简化逻辑

## Python 代码实现

### 方法一：逆序处理（推荐）

```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        """
        从后向前每 k 个字符分组
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 移除破折号并转大写
        s = s.replace('-', '').upper()
        
        # 如果字符串为空，返回空字符串
        if not s:
            return ''
        
        # 从后向前每 k 个字符分组
        result = []
        for i in range(len(s) - 1, -1, -1):
            # 每 k 个字符添加一个破折号（第一个字符除外）
            if result and len(result) % (k + 1) == k:
                result.append('-')
            result.append(s[i])
        
        # 反转结果（因为是从后向前构建的）
        return ''.join(reversed(result))
```

### 方法二：切片分组（更直观）

```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        """
        使用切片从后向前分组
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 移除破折号并转大写
        s = s.replace('-', '').upper()
        
        if not s:
            return ''
        
        # 计算第一组的长度
        first_group_len = len(s) % k
        if first_group_len == 0:
            first_group_len = k
        
        # 构建结果
        result = []
        
        # 添加第一组
        if first_group_len > 0:
            result.append(s[:first_group_len])
        
        # 添加后续组（每组 k 个字符）
        for i in range(first_group_len, len(s), k):
            result.append(s[i:i + k])
        
        return '-'.join(result)
```

### 方法三：使用栈（从后向前）

```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        """
        使用栈从后向前处理
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 移除破折号并转大写
        s = s.replace('-', '').upper()
        
        if not s:
            return ''
        
        result = []
        count = 0  # 当前组中的字符数
        
        # 从后向前遍历
        for i in range(len(s) - 1, -1, -1):
            if count == k:
                # 当前组满了，添加破折号
                result.append('-')
                count = 0
            result.append(s[i])
            count += 1
        
        # 反转并返回
        return ''.join(reversed(result))
```

### 方法四：正向处理（计算偏移）

```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        """
        正向处理，先计算第一组的大小
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 移除破折号并转大写
        cleaned = s.replace('-', '').upper()
        
        if not cleaned:
            return ''
        
        n = len(cleaned)
        # 第一组的大小
        first = n % k if n % k != 0 else k
        
        # 构建结果
        groups = []
        idx = 0
        
        # 添加第一组
        groups.append(cleaned[idx:idx + first])
        idx += first
        
        # 添加剩余组
        while idx < n:
            groups.append(cleaned[idx:idx + k])
            idx += k
        
        return '-'.join(groups)
```

## 复杂度分析

所有方法的复杂度都相同：

- **时间复杂度**：O(n)
  - 遍历字符串一次：O(n)
  - 构建结果：O(n)
  - 总复杂度：O(n)

- **空间复杂度**：O(n)
  - 需要存储处理后的字符串
  - 结果数组也是 O(n)

## 关键点总结

1. **预处理字符串**：先移除破折号并转大写
2. **从后向前处理**：避免计算第一组大小的复杂性
3. **边界处理**：空字符串、第一组大小的特殊情况
4. **使用内置函数**：`replace()`, `upper()`, `join()` 简化代码
5. **反转技巧**：从后向前构建，最后反转结果

## 易错点

1. **忘记转大写**
   - 题目要求将所有小写字母转为大写
   - 在预处理阶段就应该处理

2. **第一组长度计算错误**
   - 第一组长度 = len(s) % k
   - 但如果恰好整除，第一组应该是 k 个，不是 0 个

3. **空字符串处理**
   - 移除所有破折号后可能为空
   - 需要特殊处理

4. **破折号位置**
   - 不应该在开头或结尾添加破折号
   - 只在组与组之间添加

5. **索引越界**
   - 使用切片时注意不要越界
   - Python 的切片会自动处理，但逻辑要清晰
