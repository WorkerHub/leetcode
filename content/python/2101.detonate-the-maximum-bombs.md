## 题目描述

给你一个炸弹列表。一个炸弹的**爆炸范围**定义为以炸弹为圆心的圆。

炸弹用一个下标从 **0** 开始的二维整数数组 `bombs` 表示，其中 `bombs[i] = [xi, yi, ri]`。`xi` 和 `yi` 表示第 `i` 个炸弹的 X 和 Y 坐标，`ri` 表示爆炸范围的半径。

你需要选择引爆**一个**炸弹，若某个炸弹的爆炸范围内有其他炸弹，则其他炸弹也会被引爆，且这个过程持续下去，直到再没有可以被引爆的炸弹。

**请返回在引爆一个炸弹的前提下，最多能引爆多少个炸弹。**

**示例 1：**
```
输入：bombs = [[2,1,3],[6,1,4]]
输出：2
解释：
- 引爆炸弹 0：炸弹 0 的爆炸范围内包含炸弹 1，炸弹 1 也被引爆。共引爆 2 个炸弹。
- 引爆炸弹 1：炸弹 1 的爆炸范围内不包含炸弹 0。共引爆 1 个炸弹。
```

**示例 2：**
```
输入：bombs = [[1,1,5],[10,10,5]]
输出：1
```

**提示：**
- `1 <= bombs.length <= 100`
- `1 <= xi, yi, ri <= 10^5`

## 解题思路

**建图 + BFS/DFS 求最大可达节点数**

核心思想：
1. 若炸弹 i 能触发炸弹 j，当且仅当两炸弹之间距离 `d <= r[i]`（注意是 i 的半径，不是 j 的）。
2. 建立有向图：若 i 能触发 j，则加入有向边 i → j。
3. 对每个起点做 DFS/BFS，统计可达节点数，取最大值。

**关键判断：** 避免浮点误差，用平方比较：`(x1-x2)^2 + (y1-y2)^2 <= r^2`

## 代码实现

### 方法一：建图 + DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        # 建有向图：i 能触发 j
        graph = defaultdict(list)
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                xi, yi, ri = bombs[i]
                xj, yj, _ = bombs[j]
                # 用平方避免浮点误差
                dist_sq = (xi - xj) ** 2 + (yi - yj) ** 2
                if dist_sq <= ri * ri:
                    graph[i].append(j)

        def dfs(node: int, visited: set) -> int:
            # 深度优先搜索，返回从 node 出发可引爆的炸弹总数
            visited.add(node)
            count = 1
            for neighbor in graph[node]:
                if neighbor not in visited:
                    count += dfs(neighbor, visited)
            return count

        ans = 0
        for i in range(n):
            ans = max(ans, dfs(i, set()))
        return ans
```

### 方法二：建图 + BFS

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        graph = defaultdict(list)
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                xi, yi, ri = bombs[i]
                xj, yj, _ = bombs[j]
                if (xi - xj) ** 2 + (yi - yj) ** 2 <= ri * ri:
                    graph[i].append(j)

        ans = 0
        for start in range(n):
            # BFS 计算从 start 出发的可达节点数
            visited = {start}
            queue = deque([start])
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
            ans = max(ans, len(visited))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS  | O(n^3)    | O(n^2)    |
| BFS  | O(n^3)    | O(n^2)    |

- 建图 O(n^2)，对每个节点做 DFS/BFS O(n + E) = O(n^2)，共 n 次，总体 O(n^3)。
- n <= 100，O(n^3) = 10^6，完全可接受。

## 关键点总结

1. 建有向图而非无向图，因为 i 触发 j 不等于 j 触发 i。
2. 用平方比较避免 `sqrt` 带来的浮点精度问题。
3. 每次 DFS/BFS 需要重新初始化 visited 集合。

## 易错点

- 误用无向图：炸弹触发是单向的，半径是触发者的半径。
- 浮点精度：直接用 `math.sqrt` 可能导致边界误判，应用平方比较。
- 忘记判断 `i == j` 的自环情况。
