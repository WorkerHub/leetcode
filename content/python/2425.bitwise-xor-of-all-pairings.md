## 题目描述

给你两个下标从 **0** 开始的数组 `nums1` 和 `nums2`，两个数组都只包含非负整数。请你求出另外一个数组 `nums3`，包含 `nums1` 和 `nums2` 中 **所有数对** 的异或值（`nums1[i] XOR nums2[j]`）。

返回 `nums3` 中所有整数的 **异或值**。

**示例 1：**
```
输入：nums1 = [2,1,3], nums2 = [10,2,5,0]
输出：13
```

**示例 2：**
```
输入：nums1 = [1,2], nums2 = [3,4]
输出：0
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `0 <= nums1[i], nums2[j] <= 10^9`

## 解题思路

**脑筋急转弯：**

`nums3` 中每个元素是 `nums1[i] XOR nums2[j]` 的形式，共 `m * n` 个元素（m = len(nums1)，n = len(nums2)）。

对所有这些元素求 XOR：
`result = XOR of all (nums1[i] XOR nums2[j])`

**分析每个元素的出现次数：**
- `nums1[i]` 在 `nums3` 中出现 `n` 次（与 `nums2` 的每个元素各配对一次）
- `nums2[j]` 在 `nums3` 中出现 `m` 次

**利用 XOR 的性质（a XOR a = 0）：**
- 若 `n` 是偶数：`nums1` 中每个元素出现偶数次，XOR 结果抵消为 0
- 若 `n` 是奇数：`nums1` 中每个元素有效，结果包含 `XOR(nums1)`
- 类似地对 `nums2`

**结论：**
- 若 `n` 为奇数，结果 XOR `XOR(nums1)`
- 若 `m` 为奇数，结果 XOR `XOR(nums2)`

## 代码实现

### 方法一：脑筋急转弯（O(m+n)，推荐）

```python
from typing import List
from functools import reduce
from operator import xor

class Solution:
    def xorAllNums(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        ans = 0

        # nums1 中每个元素出现 n 次
        if n % 2 == 1:
            for x in nums1:
                ans ^= x  # 奇数次出现，参与异或

        # nums2 中每个元素出现 m 次
        if m % 2 == 1:
            for x in nums2:
                ans ^= x  # 奇数次出现，参与异或

        return ans
```

### 方法二：暴力枚举（超时，仅供理解）

```python
from typing import List

class Solution:
    def xorAllNums(self, nums1: List[int], nums2: List[int]) -> int:
        ans = 0
        # 枚举所有数对
        for x in nums1:
            for y in nums2:
                ans ^= (x ^ y)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 脑筋急转弯 | O(m + n) | O(1) |
| 暴力枚举 | O(m * n) | O(1) |

## 关键点总结

1. 利用 XOR 的性质：`a ^ a = 0`，偶数次出现的元素抵消
2. `nums1[i]` 出现 `n` 次，`nums2[j]` 出现 `m` 次
3. 只有在出现奇数次时，才对答案产生贡献

## 易错点

- 判断的是对方数组的长度奇偶，不是自身
- 两个条件独立，可能都满足、都不满足或各满足一个
