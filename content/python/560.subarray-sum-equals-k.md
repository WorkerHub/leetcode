## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的**连续子数组**的个数。

**示例 1：**
```
输入：nums = [1,1,1], k = 2
输出：2
```

**示例 2：**
```
输入：nums = [1,2,3], k = 3
输出：2
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 解题思路

这是一道经典的**前缀和 + 哈希表**问题。

核心思想：
- 如果 `prefixSum[j] - prefixSum[i] = k`，说明 `nums[i+1:j+1]` 的和为 k
- 转化为：`prefixSum[i] = prefixSum[j] - k`
- 使用哈希表记录每个前缀和出现的次数

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        """
        前缀和 + 哈希表
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 哈希表记录前缀和出现的次数
        prefix_count = defaultdict(int)
        prefix_count[0] = 1  # 前缀和为 0 出现 1 次
        
        prefix_sum = 0
        count = 0
        
        for num in nums:
            prefix_sum += num
            # 查找是否存在 prefix_sum - k
            if prefix_sum - k in prefix_count:
                count += prefix_count[prefix_sum - k]
            # 更新当前前缀和的次数
            prefix_count[prefix_sum] += 1
        
        return count
```

### 方法二：简洁版本

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        """
        更简洁的实现
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        count = 0
        prefix_sum = 0
        prefix_map = {0: 1}
        
        for num in nums:
            prefix_sum += num
            count += prefix_map.get(prefix_sum - k, 0)
            prefix_map[prefix_sum] = prefix_map.get(prefix_sum, 0) + 1
        
        return count
```

### 方法三：暴力解法（用于理解）

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        """
        暴力枚举所有子数组
        
        时间复杂度：O(n^2)
        空间复杂度：O(1)
        """
        count = 0
        n = len(nums)
        
        for i in range(n):
            current_sum = 0
            for j in range(i, n):
                current_sum += nums[j]
                if current_sum == k:
                    count += 1
        
        return count
```

## 复杂度分析

**方法一、二（哈希表）：**
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(n)，哈希表最多存储 n 个不同的前缀和

**方法三（暴力）：**
- **时间复杂度**：O(n²)，双重循环
- **空间复杂度**：O(1)

## 图解示例

以 `nums = [1, 2, 3], k = 3` 为例：

```
索引：    0  1  2
nums:    [1, 2, 3]
前缀和：  1  3  6

哈希表变化：
初始：{0: 1}
i=0, sum=1: count += map[1-3=−2] = 0, map = {0:1, 1:1}
i=1, sum=3: count += map[3-3=0] = 1, map = {0:1, 1:1, 3:1}
i=2, sum=6: count += map[6-3=3] = 1, map = {0:1, 1:1, 3:1, 6:1}

结果：count = 2
子数组：[1,2] 和 [3]
```

## 关键点总结

1. **前缀和思想**：prefixSum[j] - prefixSum[i] = sum(nums[i+1:j+1])
2. **哈希表优化**：将 O(n²) 优化到 O(n)
3. **初始化**：`prefix_count[0] = 1` 表示空前缀
4. **边遍历边更新**：先查找再更新，避免重复计数
5. **负数处理**：算法支持负数和 0

## 易错点

1. **初始化**：必须设置 `prefix_count[0] = 1`
2. **更新顺序**：先查找 `prefix_sum - k`，再更新 `prefix_sum`
3. **累加计数**：`count += prefix_count[prefix_sum - k]`，不是 `+= 1`
4. **负数情况**：数组包含负数时，前缀和可能相同
5. **理解前缀和**：`prefix_sum - k` 对应的是起点位置
