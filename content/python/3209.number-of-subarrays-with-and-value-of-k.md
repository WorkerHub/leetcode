## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，返回 `nums` 中**按位与值等于 `k`** 的子数组数量。

**示例 1：**
```
输入：nums = [1,1,1], k = 1
输出：6
```

**示例 2：**
```
输入：nums = [1,2,3], k = 2
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i], k <= 10^9`

## 解题思路

关键观察：固定右端点 `r`，随着 `l` 从 `r` 向左移动，`AND(nums[l..r])` 单调不增（AND 只会让位变 0）。

因此，固定 `r` 后，不同的 AND 值**最多有 O(log(max_val))** 种（约 30 种），可以用一个列表维护 `(AND值, 最左起始位置)` 的列表。

对于每个 `r`，更新上一轮的列表，将所有 AND 值与 `nums[r]` 做 AND 运算，合并相同值，然后统计值等于 `k` 的区间数。

## Python 代码实现

### 方法一：维护不同 AND 值的区间（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        ans = 0
        # groups: [(and_value, count)] 表示以当前 r 为右端，
        # AND 值为 and_value 的子数组数量
        groups = []
        
        for x in nums:
            new_groups = []
            for val, cnt in groups:
                new_val = val & x
                if new_groups and new_groups[-1][0] == new_val:
                    new_groups[-1] = (new_val, new_groups[-1][1] + cnt)
                else:
                    new_groups.append((new_val, cnt))
            # 加上只含当前元素的子数组
            if new_groups and new_groups[-1][0] == x:
                new_groups[-1] = (x, new_groups[-1][1] + 1)
            else:
                new_groups.append((x, 1))
            
            groups = new_groups
            # 统计 AND 值等于 k 的子数组数量
            for val, cnt in groups:
                if val == k:
                    ans += cnt
        
        return ans
```

### 方法二：二分查找 + 前缀 AND

```python
from typing import List
import bisect

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        # 对于固定右端 r，AND 值随 l 减小单调不增
        # 用二分找出 AND == k 的 l 范围
        n = len(nums)
        ans = 0
        
        # 维护以 r 为右端的所有不同 AND 值及其最左位置
        prev = []  # (and_value, left_most_index)
        
        for r in range(n):
            curr = []
            for val, left in prev:
                nv = val & nums[r]
                if curr and curr[-1][0] == nv:
                    curr[-1] = (nv, curr[-1][1])
                else:
                    curr.append((nv, left))
            curr.append((nums[r], r))
            # 合并相同值
            merged = []
            for val, left in curr:
                if merged and merged[-1][0] == val:
                    pass  # 保留最左的 left
                else:
                    merged.append((val, left))
            prev = merged
            
            for i, (val, left) in enumerate(prev):
                if val == k:
                    right_boundary = prev[i - 1][1] - 1 if i > 0 else r
                    ans += right_boundary - left + 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log C)，C 为最大值，每个右端点维护的不同 AND 值最多 O(log C) 个
- 空间复杂度：O(log C)

## 关键点总结

1. 固定右端时，AND 值最多 O(log C) 种，可以分组维护
2. 每次向右扩展时，将所有组的 AND 值与新元素做 AND，合并相同值
3. 统计 AND == k 的组的计数即可

## 易错点

1. 合并 AND 值相同的组时要保留正确的计数
2. 注意 AND 值永远不会增加，只会保持或减小
