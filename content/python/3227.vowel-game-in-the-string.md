## 题目描述

Alice 和 Bob 玩游戏，Bob 先选择一个非空字符串 `s`。然后 Alice 和 Bob 轮流进行：
- Alice 从 `s` 中取一个**以元音字母开头且以元音字母结尾**的非空子字符串
- Bob 从 `s` 中取一个**以辅音字母开头且以辅音字母结尾**的非空子字符串

每次取走后，该子字符串从 `s` 中删除。不能操作的人输。

如果 Alice **先**进行操作，且两人都采用最优策略，Alice 能赢吗？

**示例 1：**
```
输入：s = "leetcoder"
输出：true
```

**示例 2：**
```
输入：s = "bbbb"
输出：false
```

**示例 3：**
```
输入：s = "letlt"
输出：false
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只含小写字母

## 解题思路

观察：
- Alice 需要找"以元音开头且以元音结尾"的子串
- Bob 需要找"以辅音开头且以辅音结尾"的子串

关键数学推导：
- 设元音数量为 `v`，辅音数量为 `c`
- Alice 赢当且仅当：`v` 为奇数（即总元音数为奇数）

原因：
- 如果 `v == 0`，Alice 无法操作，Alice 输
- 如果 `v > 0`：Alice 每次取走一个包含奇数个元音的子串（最简单：取一个单独的元音字母）
  - 实际上 Alice 总能取单个元音字母，每次操作后元音数减1
  - v 为奇数时，Alice 先取后变偶数，Bob 操作后 Alice 面对奇数，Alice 最终胜
  - v 为偶数时，Bob 调整策略可以让 Alice 先无法操作

更精确：只要 `v` 是奇数，Alice 必胜；否则 Alice 必败。

## Python 代码实现

### 方法一：统计元音数量（推荐）

```python
class Solution:
    def doesAliceWin(self, s: str) -> bool:
        vowels = set('aeiou')
        v = sum(1 for c in s if c in vowels)
        # Alice 赢当且仅当 v 为奇数
        return v % 2 == 1
```

### 方法二：位操作

```python
class Solution:
    def doesAliceWin(self, s: str) -> bool:
        vowels = 'aeiou'
        count = s.count('a') + s.count('e') + s.count('i') + s.count('o') + s.count('u')
        return count % 2 == 1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 博弈结果只取决于元音数量的奇偶性
2. Alice 总能取单个元音字母（满足以元音开头且结尾的条件）
3. 元音奇数时 Alice 必胜，偶数（含0）时 Bob 必胜

## 易错点

1. 不需要分析辅音数量，只需统计元音
2. 空字符串情况（v=0）Alice 输，`0 % 2 == 0` 返回 False 正确
