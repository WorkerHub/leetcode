## 题目描述

给你三个整数 `a`、`b` 和 `n`，返回 `(a XOR x) * (b XOR x)` 的最大值，其中 `0 <= x < 2^n`，结果对 `10^9 + 7` 取余。

**示例 1：**
```
输入：a = 12, b = 5, n = 4
输出：98
解释：x = 2，(12 XOR 2) * (5 XOR 2) = 14 * 7 = 98
```

**示例 2：**
```
输入：a = 6, b = 7, n = 5
输出：930
```

**提示：**
- `0 <= a, b < 2^50`
- `0 <= n <= 50`

## 解题思路

设 `A = a XOR x`，`B = b XOR x`。x < 2^n 意味着 x 只有低 n 位。

对于第 `k` 位（0 <= k < n）：
- 若 `a` 和 `b` 在第 k 位相同（都是 0 或都是 1）：
  - 将 x 的第 k 位设为 1，可以让 A 和 B 在该位都翻转
  - 将 x 的第 k 位设为 0，A 和 B 在该位不变
  - 为最大化乘积，选择让 A 和 B 该位都为 1（更大）
- 若 `a` 和 `b` 在第 k 位不同（一个是 0，一个是 1）：
  - x 的第 k 位 = 0：A 和 B 的第 k 位保持原来的 0 和 1
  - x 的第 k 位 = 1：A 和 B 的第 k 位翻转为 1 和 0
  - 两种情况下，A 和 B 在第 k 位的和（0+1=1）不变，为最大化乘积，应该让较小的那个更大

贪心：若 a 和 b 在第 k 位不同，设当前 A > B（不含第 k 位的贡献），则让 B 的第 k 位为 1（将 2^k 加给 B），使 A*B 更大（AM-GM 不等式：两数差越小乘积越大）。

## Python 代码实现

### 方法一：逐位贪心（推荐）

```python
class Solution:
    def maximumXorProduct(self, a: int, b: int, n: int) -> int:
        MOD = 10**9 + 7

        # 处理高于 n 位的部分（n 位以上 x=0，不变）
        # 对低 n 位逐位确定 x
        A, B = a, b

        for k in range(n - 1, -1, -1):
            bit_a = (a >> k) & 1
            bit_b = (b >> k) & 1
            if bit_a == bit_b:
                # 将 x 第 k 位设为 1，A 和 B 的第 k 位都翻转为 1
                # 无论原来是 0 还是 1，设为 1 更好（增大两者）
                A |= (1 << k)
                B |= (1 << k)
            else:
                # A 和 B 该位一个是 0，一个是 1
                # 将 1 给较小的那个，使两者差减小
                if A > B:
                    # B 的该位设为 1
                    B |= (1 << k)
                    # A 的该位对应 (bit_a XOR x_k)，若 bit_a=1 且 x_k=0 则为 1，若 bit_a=0 且 x_k=1 则为 1
                    # 实际：选 x_k 使 B 的该位为 1：若 bit_b=0 则 x_k=1（B 翻转），若 bit_b=1 则 x_k=0
                    # 对应 A：若 bit_a != bit_b，选 x_k 使 B=1，则 A 变为 bit_a XOR x_k
                    if bit_b == 0:
                        # x_k = 1，A = bit_a XOR 1 = 1 - bit_a = 0（因为 bit_a != bit_b，bit_a=1）
                        A &= ~(1 << k)  # A 的该位为 0
                    else:
                        # x_k = 0，A = bit_a = 0
                        A &= ~(1 << k)  # A 的该位为 0（因为 bit_a=0，bit_b=1）
                else:
                    # A 的该位设为 1
                    A |= (1 << k)
                    B &= ~(1 << k)

        return (A % MOD) * (B % MOD) % MOD
```

### 方法二：简洁版贪心

```python
class Solution:
    def maximumXorProduct(self, a: int, b: int, n: int) -> int:
        MOD = 10**9 + 7
        A, B = a, b
        for k in range(n - 1, -1, -1):
            ba = (a >> k) & 1
            bb = (b >> k) & 1
            if ba == bb:
                # 都设为 1（若都是 1 则不变，若都是 0 则设 x_k=1 翻转）
                A |= 1 << k
                B |= 1 << k
            else:
                # 将 1 分配给当前较小值
                if A < B:
                    A |= 1 << k
                    B &= ~(1 << k)
                else:
                    A &= ~(1 << k)
                    B |= 1 << k
        return A % MOD * (B % MOD) % MOD
```

## 复杂度分析

- 时间复杂度：O(n)，对每一位做 O(1) 操作
- 空间复杂度：O(1)

## 关键点总结

1. 高位 n 及以上的位：x 无法影响，A 和 B 保持原值
2. 对低 n 位：若 a、b 该位相同，让两者该位都为 1（增大乘积）
3. 若 a、b 该位不同，将 1 分配给当前较小的那个（减小差值，增大乘积）

## 易错点

1. 不能修改 a 和 b，需要用 A 和 B 表示当前累计结果
2. 取模：A 和 B 可能很大（50 位），最后取模
3. 从高位到低位处理，高位影响更大
