## 题目描述

给你一个整数数组 `nums` 和两个整数：`left` 及 `right`。找出 `nums` 中连续、非空且其中最大元素在范围 `[left, right]` 内的子数组个数。

**示例 1：**
```
输入：nums = [2,1,4,3], left = 2, right = 3
输出：3
解释：满足条件的三个子数组：[2], [2,1], [3]
```

**示例 2：**
```
输入：nums = [2,9,2,5,6], left = 2, right = 8
输出：7
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= left <= right <= 10^9`

## 解题思路

这道题的关键是理解什么样的子数组满足条件：**子数组的最大值必须在 [left, right] 范围内**。

**朴素思路（暴力法）：**
- 枚举所有子数组，检查其最大值是否在 [left, right] 内
- 时间复杂度 O(n²)，会超时

**优化思路：转化问题**

核心观察：**满足条件的子数组数量 = 最大值 ≤ right 的子数组数 - 最大值 < left 的子数组数**

即：`count(max ≤ right) - count(max < left) = count(left ≤ max ≤ right)`

这样我们只需要实现一个辅助函数：**统计最大值不超过 k 的子数组个数**。

**如何统计最大值 ≤ k 的子数组个数？**

使用双指针/滑动窗口：
1. 遍历数组，维护一个指针 `i`
2. 如果 `nums[i] <= k`，说明以 `i` 结尾的合法子数组有 `i - last + 1` 个
   - 其中 `last` 是上一个大于 k 的元素的位置
3. 如果 `nums[i] > k`，更新 `last = i`

**举例说明：**
```
nums = [2,1,4,3], left = 2, right = 3

最大值 ≤ 3 的子数组：
[2], [1], [2,1], [3], [2,1,3] 不对，因为 4 > 3
实际：[2], [1], [2,1], [3] 共 4 个（4 之前的）

最大值 < 2 的子数组：
[1] 共 1 个

结果：4 - 1 = 3
```

## Python 代码实现

### 方法一：双指针 + 数学转化（推荐）

```python
from typing import List

class Solution:
    def numSubarrayBoundedMax(self, nums: List[int], left: int, right: int) -> int:
        """
        统计最大值在 [left, right] 范围内的子数组个数
        
        思路：count(max ≤ right) - count(max < left)
        
        参数：
            nums: 整数数组
            left: 范围下界
            right: 范围上界
            
        返回：
            满足条件的子数组个数
        """
        def count_at_most(k: int) -> int:
            """
            统计最大值不超过 k 的子数组个数
            
            参数：
                k: 最大值上限
                
            返回：
                子数组个数
            """
            result = 0
            last = -1  # 上一个大于 k 的元素位置
            
            for i in range(len(nums)):
                if nums[i] > k:
                    last = i  # 更新分界点
                else:
                    # 以 i 结尾的合法子数组有 i - last 个
                    result += i - last
            
            return result
        
        # 最大值在 [left, right] = 最大值 ≤ right - 最大值 < left
        return count_at_most(right) - count_at_most(left - 1)
```

### 方法二：一次遍历（优化）

```python
from typing import List

class Solution:
    def numSubarrayBoundedMax(self, nums: List[int], left: int, right: int) -> int:
        """
        一次遍历解决问题
        
        思路：将数组分段，每段内的元素都 ≤ right，段间由 > right 的元素分隔
        """
        result = 0
        prev_count = 0  # 上一个合法位置贡献的子数组数
        last_large = -1  # 上一个 > right 的元素位置
        
        for i in range(len(nums)):
            if nums[i] > right:
                # 遇到大于 right 的元素，重置
                last_large = i
                prev_count = 0
            elif nums[i] >= left:
                # 在 [left, right] 范围内
                # 以 i 结尾的合法子数组个数
                prev_count = i - last_large
                result += prev_count
            else:
                # 小于 left
                # 可以延续之前的合法子数组
                result += prev_count
        
        return result
```

### 方法三：分段计数

```python
from typing import List

class Solution:
    def numSubarrayBoundedMax(self, nums: List[int], left: int, right: int) -> int:
        """
        将数组按 > right 的元素分段，每段单独计算
        
        思路：每个段内计算满足条件的子数组数
        """
        def count_segment(segment: List[int]) -> int:
            """
            计算单个段内满足条件的子数组数
            
            段内所有元素都 ≤ right
            需要统计最大值 >= left 的子数组
            """
            count = 0
            last_valid = -1  # 上一个 >= left 的元素位置
            
            for i in range(len(segment)):
                if segment[i] >= left:
                    last_valid = i
                
                # 以 i 结尾且包含至少一个 >= left 元素的子数组数
                count += last_valid + 1
            
            return count
        
        # 按 > right 的元素分段
        segments = []
        segment = []
        
        for num in nums:
            if num > right:
                if segment:
                    segments.append(segment)
                    segment = []
            else:
                segment.append(num)
        
        if segment:
            segments.append(segment)
        
        # 统计每个段的贡献
        return sum(count_segment(seg) for seg in segments)
```

## 复杂度分析

### 方法一：双指针 + 数学转化
- **时间复杂度：** O(n)，两次遍历数组
- **空间复杂度：** O(1)，只使用常数额外空间

### 方法二：一次遍历
- **时间复杂度：** O(n)，只遍历一次
- **空间复杂度：** O(1)

### 方法三：分段计数
- **时间复杂度：** O(n)
- **空间复杂度：** O(n)，需要存储分段

```
索引：   0  1  2  3
数组：  [2, 1, 4, 3]
       
       ≥left?  Y  N  N  Y
       ≤right? Y  Y  N  Y
       合法?   Y  N  N  Y
```

分段分析（按 > right 分段）：
- 段 1：[2, 1]（索引 0-1）
- 元素 4 > right，分隔
- 段 2：[3]（索引 3）

段 1 的子数组：
- 以 0 结尾：[2]，最大值 2，合法
- 以 1 结尾：[1]（不合法），[2,1]（最大值 2，合法）

段 2 的子数组：
- 以 3 结尾：[3]，最大值 3，合法

总计：3 个

## 关键点总结

1. **问题转化**：将复杂条件转化为两个简单条件的差
2. **辅助函数**：`count_at_most(k)` 统计最大值 ≤ k 的子数组
3. **数学技巧**：`count(a ≤ x ≤ b) = count(x ≤ b) - count(x < a)`
4. **双指针应用**：维护 `last` 指针记录分界点
5. **子数组计数公式**：以 i 结尾的合法子数组数 = `i - last`

## 易错点

1. **边界条件**：`count_at_most(left - 1)` 不要写成 `count_at_most(left)`
2. **初始化**：`last` 初始化为 -1，而不是 0
3. **计数公式**：是 `i - last` 而不是 `i - last + 1`（因为 last 位置本身不合法）
4. **分段遗漏**：最后一个分段可能没有结尾的大元素，不要忘记处理
5. **理解子数组**：子数组必须连续，不能跳过元素
