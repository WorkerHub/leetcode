## 题目描述

给你一个整数 `n`，共有编号 `0` 到 `n - 1` 的 `n` 个会议室。

给你一个二维整数数组 `meetings`，其中 `meetings[i] = [starti, endi]` 表示一场会议将会在 **半闭** 时间区间 `[starti, endi)` 举办，且每场会议都需要在 **独占** 整个会议室的前提下举办。

会议室分配规则如下：

1. 每场会议都将会在编号 **最小** 的可用会议室举办。
2. 如果没有可用会议室，则推迟这场会议，直到最早结束的会议室变为空闲。会议室可用时，和它 **相同时间** 结束的会议同样视为可用。如果有两个会议室在同一时间变为空闲，则优先分配编号 **更小** 的会议室。

返回举办 **最多** 次会议的房间 **编号**。如果存在多个房间满足此条件，则返回编号 **最小** 的房间。

**示例 1：**
```
输入：n = 2, meetings = [[0,10],[1,5],[2,7],[3,4]]
输出：0
```

**示例 2：**
```
输入：n = 3, meetings = [[1,20],[2,10],[3,5],[4,9],[6,8]]
输出：1
```

**提示：**
- `1 <= n <= 100`
- `1 <= meetings.length <= 10^5`
- `0 <= starti < endi <= 5 * 10^5`

## 解题思路

使用两个优先队列（堆）来模拟会议室分配：

1. **空闲堆（idle）**：最小堆，存储空闲会议室编号，按编号排序
2. **使用堆（used）**：最小堆，存储 `(结束时间, 会议室编号)`，按结束时间排序

**处理流程：**
- 先将所有会议按开始时间排序
- 对每场会议：
  1. 将所有已结束的会议室（结束时间 <= 当前开始时间）释放到空闲堆
  2. 若空闲堆非空，取编号最小的空闲房间分配
  3. 若空闲堆为空，等待最早结束的会议室，推迟到其结束时间后分配

## 代码实现

### 方法一：双堆模拟（推荐）

```python
from typing import List
import heapq

class Solution:
    def mostBooked(self, n: int, meetings: List[List[int]]) -> int:
        # 统计每个会议室的使用次数
        count = [0] * n
        # 空闲会议室堆（按编号排序）
        idle = list(range(n))
        heapq.heapify(idle)
        # 使用中的会议室堆（按结束时间、编号排序）
        used = []

        # 按会议开始时间排序
        meetings.sort()

        for start, end in meetings:
            # 释放所有已结束（结束时间 <= 当前开始时间）的会议室
            while used and used[0][0] <= start:
                end_time, room = heapq.heappop(used)
                heapq.heappush(idle, room)

            if idle:
                # 有空闲会议室，取编号最小的
                room = heapq.heappop(idle)
                heapq.heappush(used, (end, room))
            else:
                # 没有空闲会议室，等待最早结束的
                earliest_end, room = heapq.heappop(used)
                # 会议推迟，新的结束时间 = 最早结束时间 + 会议持续时长
                new_end = earliest_end + (end - start)
                heapq.heappush(used, (new_end, room))

            count[room] += 1

        # 返回使用次数最多且编号最小的会议室
        return count.index(max(count))
```

### 方法二：暴力模拟（对比学习）

```python
from typing import List

class Solution:
    def mostBooked(self, n: int, meetings: List[List[int]]) -> int:
        count = [0] * n
        # end_time[i] 表示第 i 个会议室的结束时间
        end_time = [0] * n

        meetings.sort()

        for start, end in meetings:
            duration = end - start
            assigned = -1
            earliest_end = float('inf')

            # 先找空闲且编号最小的会议室
            for i in range(n):
                if end_time[i] <= start:
                    assigned = i
                    break

            # 没有空闲则找最早结束的
            if assigned == -1:
                for i in range(n):
                    if end_time[i] < earliest_end:
                        earliest_end = end_time[i]
                        assigned = i
                # 推迟会议
                end_time[assigned] = earliest_end + duration
            else:
                end_time[assigned] = end_time[assigned] + duration if end_time[assigned] > start else start + duration

            count[assigned] += 1

        return count.index(max(count))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双堆模拟 | O(m log m + m log n) | O(n + m) |
| 暴力模拟 | O(m log m + m * n) | O(n) |

其中 m 为会议数量，n 为会议室数量。

## 关键点总结

1. 维护空闲堆和使用中的堆，分别按编号和（结束时间，编号）排序
2. 每次处理新会议时，先释放已结束的会议室
3. 推迟的会议：新结束时间 = 最早可用时间 + 原始会议时长
4. 最终找 count 数组中最大值的最小索引

## 易错点

- 推迟会议时，新结束时间是 `earliest_end + (end - start)`，不是 `earliest_end + end`
- 空闲堆按编号排序（最小堆默认），使用堆按 `(结束时间, 编号)` 排序以保证编号最小优先
