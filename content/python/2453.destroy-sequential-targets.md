## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，它包含若干正整数，表示数轴上你需要摧毁的目标所在的位置。同时给你一个整数 `space`。

你有一台机器可以摧毁目标。给机器 **一个整数** `seed`，这台机器会摧毁所有位置为 `seed, seed + space, seed + 2 * space, ...` 的目标（所有正整数）。

返回摧毁 **最多** 数目的目标所对应的 **最小** 整数 `seed`。

**示例 1：**
```
输入：nums = [3,7,8,1,1,5], space = 2
输出：1
解释：seed = 1，摧毁 1, 3, 5, 7（nums 中有 1,1,3,5,7 不对...）
seed = 1 摧毁 1,3,5,7。nums 中 1,3,7 满足，还有另一个 1，共 4 个。
```

**示例 2：**
```
输入：nums = [1,3,5,2,4,6], space = 2
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= space <= 5 * 10^8`

## 解题思路

**关键观察：** 若 `seed = s`，则摧毁的目标是所有 `num % space == s % space` 的位置（模 space 同余）。

因此，问题等价于：对每个余数 `r = num % space`，统计 `nums` 中余数等于 `r` 的元素个数，找出个数最多的余数，返回对应的最小 `num`。

**步骤：**
1. 按余数分组，统计每组的大小
2. 找出最大组的大小 `max_count`
3. 在所有余数组中，找出组大小等于 `max_count` 的、包含最小 `num` 的那组

## 代码实现

### 方法一：哈希表统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def destroyTargets(self, nums: List[int], space: int) -> int:
        # 按余数分组，记录每组的最小值和大小
        groups = defaultdict(lambda: [float('inf'), 0])  # {余数: [最小值, 计数]}

        for x in nums:
            r = x % space
            groups[r][0] = min(groups[r][0], x)  # 更新最小值
            groups[r][1] += 1                     # 计数加一

        # 找最大计数，相同计数取最小值
        max_count = max(v[1] for v in groups.values())
        ans = min(v[0] for v in groups.values() if v[1] == max_count)

        return ans
```

### 方法二：两次排序

```python
from typing import List
from collections import Counter

class Solution:
    def destroyTargets(self, nums: List[int], space: int) -> int:
        # 统计每个余数的出现次数
        count = Counter(x % space for x in nums)
        max_count = max(count.values())

        # 在所有 nums 中，找余数出现次数最多且值最小的
        ans = float('inf')
        for x in nums:
            if count[x % space] == max_count:
                ans = min(ans, x)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表统计 | O(n) | O(n) |
| 两次遍历 | O(n) | O(n) |

## 关键点总结

1. seed `s` 能摧毁所有 `num % space == s % space` 的目标
2. 按余数分组统计，找最大组
3. 最大组中，取最小的 `num` 作为 seed

## 易错点

- 选的是最小的 `num`，不是最小的余数
- 多个余数可能有相同的最大组大小，要在所有满足条件的 num 中取最小值
