## 题目描述

给你一个大小为 `n x n` 的整数矩阵 `grid`，其中包含 1 到 n*n 范围内的整数，有一个数字出现了两次，有一个数字缺失了一次。

找出重复出现的数字 `a` 和缺失的数字 `b`，以数组 `[a, b]` 的形式返回。

**示例 1：**
```
输入：grid = [[1,3],[2,2]]
输出：[2,4]
```

**示例 2：**
```
输入：grid = [[9,1,7],[8,9,2],[3,4,6]]
输出：[9,5]
```

**提示：**
- `2 <= n == grid.length == grid[i].length <= 50`
- `1 <= grid[i][j] <= n * n`
- 1 到 n*n 的所有整数中恰好一个出现两次，一个缺失

## 解题思路

用计数数组统计每个数字的出现次数，找出现 2 次的（重复）和出现 0 次的（缺失）。

## Python 代码实现

### 方法一：计数数组（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findMissingAndRepeatedValues(self, grid: List[List[int]]) -> List[int]:
        n = len(grid)
        cnt = Counter()
        for row in grid:
            for x in row:
                cnt[x] += 1

        repeated = missing = -1
        for num in range(1, n * n + 1):
            if cnt[num] == 2:
                repeated = num
            elif cnt[num] == 0:
                missing = num

        return [repeated, missing]
```

### 方法二：数学方法

```python
from typing import List

class Solution:
    def findMissingAndRepeatedValues(self, grid: List[List[int]]) -> List[int]:
        n = len(grid)
        total = n * n
        # 实际和 S 与期望和 E = n*(n+1)/2 (对 total) = total*(total+1)/2
        # S - E = a - b
        # 实际平方和 S2 与期望平方和 E2 = sum(i^2 for i in 1..total)
        # S2 - E2 = a^2 - b^2 = (a-b)(a+b)
        # 联立求解

        S = sum(x for row in grid for x in row)
        S2 = sum(x * x for row in grid for x in row)
        E = total * (total + 1) // 2
        E2 = total * (total + 1) * (2 * total + 1) // 6

        # a - b = S - E
        # a + b = (S2 - E2) / (a - b)
        diff = S - E        # a - b
        sum_ab = (S2 - E2) // diff  # a + b
        a = (diff + sum_ab) // 2
        b = sum_ab - a

        return [a, b]
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵
- 空间复杂度：O(n^2)（方法一，计数数组）；O(1)（方法二）

## 关键点总结

1. 计数方法最直观：统计每个数出现次数，找 2 次和 0 次的
2. 数学方法利用和差、平方和差联立方程
3. 两种方法都 O(n^2) 时间，方法二更省空间

## 易错点

1. 数学方法中 diff = a - b 可能为负，需要确保 diff != 0（题目保证 a != b）
2. 方法二需要整数除法（Python 的 `//`），但可能有精度问题（数字很大时）
3. 矩阵大小 n x n，数字范围 1 到 n^2
