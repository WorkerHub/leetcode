## 题目描述

给你一个整数数组 `nums` 和一个整数数组 `queries`。

对于每个查询 `queries[j]`，找出所有满足 `i < j` 的 `gcd(nums[i], nums[j])` 值，将这些 gcd 值按升序排列后，返回第 `queries[j]` 个（0 索引）。

**示例：**
```
输入：nums = [2, 3, 4], queries = [0, 2, 2]
输出：[1, 2, 2]
解释：所有对的 gcd：gcd(2,3)=1, gcd(2,4)=2, gcd(3,4)=1，排序后 [1,1,2]
      queries[0]=0 -> 1, queries[1]=2 -> 2, queries[2]=2 -> 2
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 5 * 10^4`
- `1 <= queries.length <= 10^5`
- `0 <= queries[j] < n*(n-1)/2`

## 解题思路

**核心思路：**

1. **统计 gcd 为 d 的对数**：设 `cnt[d]` 为 `nums` 中 `d` 的倍数的个数。那么 gcd 恰好为 `d` 的对数（记为 `exact[d]`）可以用容斥原理计算：
   `exact[d] = C(cnt[d], 2) - sum(exact[k])` for all k = 2d, 3d, ... (k <= max_val)

2. **前缀和**：计算排好序后的 gcd 值的累计对数（前缀和），便于二分查找。

3. **二分查找**：对每个查询，用二分找到第 `q` 小的 gcd 值。

## Python 代码实现

### 方法一：莫比乌斯反演 + 前缀和 + 二分（推荐）

```python
from typing import List
from math import comb
from bisect import bisect_right

class Solution:
    def gcdValues(self, nums: List[int], queries: List[int]) -> List[int]:
        max_val = max(nums)
        
        # cnt[d] = nums 中 d 的倍数个数
        cnt = [0] * (max_val + 1)
        for x in nums:
            cnt[x] += 1
        # 前缀和（实际是后缀累加：cnt[d] = nums中d的倍数数量）
        for d in range(max_val, 0, -1):
            for k in range(2 * d, max_val + 1, d):
                cnt[d] += cnt[k]
        
        # exact[d] = gcd 恰好为 d 的对数（初始为 C(cnt[d], 2)）
        exact = [0] * (max_val + 1)
        for d in range(max_val, 0, -1):
            exact[d] = cnt[d] * (cnt[d] - 1) // 2
            for k in range(2 * d, max_val + 1, d):
                exact[d] -= exact[k]
        
        # 构建前缀和数组（prefix[d] = gcd <= d 的对数）
        prefix = [0] * (max_val + 2)
        for d in range(1, max_val + 1):
            prefix[d] = prefix[d - 1] + exact[d]
        
        # 回答每个查询：第 q 小的 gcd（0 索引）
        result = []
        for q in queries:
            # 找最小的 d 使得 prefix[d] > q
            lo, hi = 1, max_val
            while lo < hi:
                mid = (lo + hi) // 2
                if prefix[mid] > q:
                    hi = mid
                else:
                    lo = mid + 1
            result.append(lo)
        
        return result
```

## 复杂度分析

- 时间复杂度：O(max_val * log(max_val) + q * log(max_val))，统计和查询
- 空间复杂度：O(max_val)

## 关键点总结

1. 利用因数枚举（调和级数）统计每个 gcd 值对应的对数，时间复杂度 O(max_val * log(max_val))。
2. 容斥原理（莫比乌斯反演）：从"倍数对数"到"恰好等于"的对数。
3. 前缀和 + 二分查找高效回答每个查询。

## 易错点

1. `cnt[d]` 是 d 的倍数个数（包含 d 本身），需要从大到小累加。
2. `exact[d]` 计算时需要减去所有 `exact[2d], exact[3d], ...`，而不是 `exact[d+1], ...`。
3. 查询是 0 索引，`prefix[d] > q` 找第一个超过的位置。
