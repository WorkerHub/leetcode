## 题目描述

请在一个 `n × n` 的棋盘上，实现一个判定井字棋（Tic-Tac-Toe）胜负的神器，判断每一次玩家落子后，是否有胜出的玩家。

在这个井字棋游戏中，会有 2 名玩家，他们将轮流在棋盘上放置自己的棋子。

第一个玩家（player 1）的棋子是 `X`，第二个玩家（player 2）的棋子是 `O`。

**规则如下：**
玩家轮流将棋子放在空方格（`" "`）上。
第一个玩家总是放棋子 `X`，且第二个玩家总是放棋子 `O`。
棋子只能放在空方格上，不能放在已经有棋子的方格上。
如果有 `n` 个相同的棋子排成一行（行、列、对角线）时，游戏结束，该玩家获胜。
如果所有方块都放满棋子了，还没有出现获胜的玩家，那么游戏平局。

实现 `TicTacToe` 类：

- `TicTacToe(int n)` 初始化游戏棋盘的大小 `n`。
- `int move(int row, int col, int player)` 玩家在坐标 `(row, col)` 放置棋子，返回游戏状态：
  - 如果玩家获胜，返回玩家编号（1 或 2）
  - 如果游戏平局或未结束，返回 0

**示例：**

输入：

**提示：**
- `2 <= n <= 100`
- player 的值为 1 或 2
- `0 <= row, col < n`
- `(row, col)` 是一个有效的空格位置
- 最多调用 `n^2` 次 `move`

**进阶：** 你能设计一个时间复杂度为 O(1) 的算法吗？

## 解题思路

这道题的关键是如何高效判断胜负。

**朴素解法：** 每次落子后检查该行、该列、两条对角线，时间复杂度 O(n)。

**优化思路：**
为每个玩家维护计数器：
- `n` 个行计数器
- `n` 个列计数器  
- 2 个对角线计数器

**核心观察：**
- 玩家 1 落子：对应计数器 +1
- 玩家 2 落子：对应计数器 -1
- 如果某个计数器的绝对值等于 n，说明该玩家获胜

这样每次 move 只需 O(1) 时间更新计数器并判断。

## Python 代码实现

### 方法一：计数器优化（推荐）⭐

```python
class TicTacToe:
    def __init__(self, n: int):
        """
        初始化棋盘大小和计数器
        """
        self.n = n
        # 行计数器
        self.rows = [0] * n
        # 列计数器
        self.cols = [0] * n
        # 主对角线计数器（左上到右下）
        self.diagonal = 0
        # 副对角线计数器（右上到左下）
        self.anti_diagonal = 0
    
    def move(self, row: int, col: int, player: int) -> int:
        """
        玩家落子，返回游戏状态
        
        玩家 1: +1
        玩家 2: -1
        如果某个计数器绝对值等于 n，该玩家获胜
        """
        # 确定增量：玩家 1 为 +1，玩家 2 为 -1
        delta = 1 if player == 1 else -1
        
        # 更新行计数器
        self.rows[row] += delta
        
        # 更新列计数器
        self.cols[col] += delta
        
        # 更新主对角线计数器（行号 == 列号）
        if row == col:
            self.diagonal += delta
        
        # 更新副对角线计数器（行号 + 列号 == n-1）
        if row + col == self.n - 1:
            self.anti_diagonal += delta
        
        # 检查是否获胜
        if (abs(self.rows[row]) == self.n or
            abs(self.cols[col]) == self.n or
            abs(self.diagonal) == self.n or
            abs(self.anti_diagonal) == self.n):
            return player
        
        # 无人获胜
        return 0
```

**时间复杂度：** O(1)
**空间复杂度：** O(n)

### 方法二：朴素解法（每次检查）

```python
class TicTacToe:
    def __init__(self, n: int):
        self.n = n
        self.board = [[0] * n for _ in range(n)]
    
    def move(self, row: int, col: int, player: int) -> int:
        # 落子
        self.board[row][col] = player
        
        # 检查行
        if all(self.board[row][c] == player for c in range(self.n)):
            return player
        
        # 检查列
        if all(self.board[r][col] == player for r in range(self.n)):
            return player
        
        # 检查主对角线
        if row == col:
            if all(self.board[i][i] == player for i in range(self.n)):
                return player
        
        # 检查副对角线
        if row + col == self.n - 1:
            if all(self.board[i][self.n - 1 - i] == player for i in range(self.n)):
                return player
        
        return 0
```

**时间复杂度：** O(n)
**空间复杂度：** O(n^2)

### 方法三：使用字典记录

```python
class TicTacToe:
    def __init__(self, n: int):
        self.n = n
        # 使用字典记录每个位置的计数
        self.count = {}
    
    def move(self, row: int, col: int, player: int) -> int:
        delta = 1 if player == 1 else -1
        
        # 定义所有需要更新的键
        keys = [
            ('row', row),
            ('col', col),
        ]
        
        if row == col:
            keys.append(('diag', 0))
        
        if row + col == self.n - 1:
            keys.append(('anti_diag', 0))
        
        # 更新计数
        for key in keys:
            self.count[key] = self.count.get(key, 0) + delta
            
            # 检查是否获胜
            if abs(self.count[key]) == self.n:
                return player
        
        return 0
```

## 复杂度分析

| 方法 | move() 时间 | 空间复杂度 | 优点 | 缺点 |
|------|------------|-----------|------|------|
| 计数器 | O(1) | O(n) | 最优解 | 需要理解技巧 |
| 朴素检查 | O(n) | O(n^2) | 直观 | 时间慢，空间大 |
| 字典 | O(1) | O(n) | 灵活 | 稍复杂 |

## 关键点总结

1. **计数器技巧**：用正负数区分两个玩家
2. **绝对值判断**：`abs(count) == n` 判断获胜
3. **对角线条件**：主对角线 `row == col`，副对角线 `row + col == n-1`
4. **空间优化**：只需 O(n) 而不是 O(n^2)
5. **时间优化**：O(1) 判断而不是 O(n) 遍历

## 易错点

1. **玩家编号和增量**
   ```python
   # 错误：直接用 player 作为增量
   delta = player  # player 是 1 或 2
   
   # 正确：player 1 为 +1，player 2 为 -1
   delta = 1 if player == 1 else -1
   ```

2. **对角线判断**
   ```python
   # 错误：没有判断是否在对角线上
   self.diagonal += delta  # 每次都更新
   
   # 正确：只有在对角线上才更新
   if row == col:
       self.diagonal += delta
   ```

3. **副对角线条件**
   ```python
   # 错误：
   if row == self.n - 1 - col:
   
   # 正确（两种写法都可以）：
   if row + col == self.n - 1:
   # 或
   if row == self.n - 1 - col:
   ```

4. **绝对值判断**
   ```python
   # 错误：只判断正数
   if self.rows[row] == self.n:
   
   # 正确：用绝对值
   if abs(self.rows[row]) == self.n:
   ```

5. **返回值**
   ```python
   # 错误：获胜时返回 1
   if abs(self.rows[row]) == self.n:
       return 1
   
   # 正确：返回玩家编号
   if abs(self.rows[row]) == self.n:
       return player
   ```
