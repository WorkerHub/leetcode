## 题目描述

给定一个由 `'B'`（黑色像素）和 `'W'`（白色像素）组成的二维数组 `picture` 以及一个整数 `target`，返回黑色孤独像素的数量。

黑色孤独像素是指字符 `'B'`，它位于特定位置 `(r, c)` 且满足以下条件：

1. 行 `r` 和列 `c` 都恰好包含 `target` 个黑色像素
2. 对于所有在列 `c` 上有黑色像素的行，它们必须与行 `r` 完全相同

**示例 1：**
```
输入: picture = [["W","B","W","B","B","W"],
                ["W","B","W","B","B","W"],
                ["W","B","W","B","B","W"],
                ["W","W","B","W","B","W"]], target = 3
输出: 6
解释: 所有绿色的 'B' 都是我们需要的黑色像素（列 1 和列 3 的所有 'B'）
以第 r = 0 行和第 c = 1 列的 'B' 为例：
 - 规则 1：第 0 行和第 1 列都恰好有 target = 3 个黑色像素
 - 规则 2：在第 1 列有黑色像素的行是第 0、1、2 行，它们与第 0 行完全相同
```

**示例 2：**
```
输入: picture = [["W","W","B"],
                ["W","W","B"],
                ["W","W","B"]], target = 1
输出: 0
解释: 虽然每列有 target = 1 个黑色像素，但每行有 1 个黑色像素，不满足条件
```

**提示：**
- `m == picture.length`
- `n == picture[i].length`
- `1 <= m, n <= 200`
- `picture[i][j]` 只能是 `'W'` 或 `'B'`
- `1 <= target <= min(m, n)`

## 解题思路

这道题是 LeetCode 531（Lonely Pixel I）的升级版，增加了两个关键约束：

1. 行和列都必须恰好有 `target` 个黑色像素（而不是 1 个）
2. 在同一列有黑色像素的所有行必须完全相同

**核心思想：**

问题的第二个条件等价于：对于每个包含黑色像素的列，这些行必须完全相同。

**算法流程：**

1. **统计阶段**：
   - 统计每行的黑色像素数量 `rows[i]`
   - 对每列 `j`，记录所有包含黑色像素的行索引 `g[j]`

2. **验证阶段**：
   - 遍历每一列
   - 对于列 `j`，取第一个包含黑色像素的行 `i1`
   - 检查 `rows[i1]` 是否等于 `target`
   - 检查列 `j` 中所有包含黑色像素的行数是否等于 `rows[i1]`
   - 检查这些行是否都与行 `i1` 完全相同

3. **计数结果**：
   - 如果列 `j` 满足所有条件，该列的所有黑色像素都是孤独像素
   - 累加 `target` 到答案（因为该列有 `target` 个孤独像素）

**关键观察：**
- 使用哈希表（字典）存储每列的黑色像素行索引
- 通过比较整行来验证行是否相同
- 按列遍历，而不是按像素遍历，避免重复计数

## Python 代码实现

### 方法一：哈希表统计法（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findBlackPixel(self, picture: List[List[str]], target: int) -> int:
        """
        使用哈希表存储每列的黑色像素行索引
        验证行是否相同以及数量是否匹配
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        
        # rows[i] 表示第 i 行的黑色像素数量
        rows = [0] * m
        # g[j] 存储第 j 列所有包含黑色像素的行索引
        g = defaultdict(list)
        
        # 统计每行的黑色像素数量，并记录每列的黑色像素位置
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    rows[i] += 1
                    g[j].append(i)
        
        ans = 0
        # 遍历每一列
        for j in g:
            if not g[j]:  # 如果该列没有黑色像素，跳过
                continue
            
            # 取该列第一个包含黑色像素的行
            i1 = g[j][0]
            
            # 检查该行的黑色像素数量是否等于 target
            if rows[i1] != target:
                continue
            
            # 检查该列包含黑色像素的行数是否等于该行的黑色像素数
            # 并且所有这些行都与第一行完全相同
            if len(g[j]) == rows[i1] and all(picture[i2] == picture[i1] for i2 in g[j]):
                # 该列的所有黑色像素都是孤独像素
                ans += target
        
        return ans
```

### 方法二：行签名优化法

```python
from typing import List
from collections import defaultdict

class Solution:
    def findBlackPixel(self, picture: List[List[str]], target: int) -> int:
        """
        使用行签名（字符串）来快速比较行是否相同
        优化行比较的性能
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        
        # 将每行转换为字符串作为签名
        row_signatures = [''.join(row) for row in picture]
        
        # 统计每行的黑色像素数量
        rows = [0] * m
        # g[j] 存储第 j 列所有包含黑色像素的行索引
        g = defaultdict(list)
        
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    rows[i] += 1
                    g[j].append(i)
        
        ans = 0
        for j in g:
            if not g[j]:
                continue
            
            i1 = g[j][0]
            
            # 检查行黑色像素数量
            if rows[i1] != target:
                continue
            
            # 检查列中黑色像素的行数
            if len(g[j]) != rows[i1]:
                continue
            
            # 使用字符串签名快速比较所有行是否相同
            signature = row_signatures[i1]
            if all(row_signatures[i2] == signature for i2 in g[j]):
                ans += target
        
        return ans
```

### 方法三：详细注释版（适合初学者）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findBlackPixel(self, picture: List[List[str]], target: int) -> int:
        """
        最详细的实现，包含每个步骤的解释
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        
        # 步骤 1: 统计每行的黑色像素数量
        rows = [0] * m
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    rows[i] += 1
        
        # 步骤 2: 记录每列包含黑色像素的行索引
        g = defaultdict(list)
        for j in range(n):
            for i in range(m):
                if picture[i][j] == 'B':
                    g[j].append(i)
        
        # 步骤 3: 验证每一列
        ans = 0
        for j in range(n):
            # 如果该列没有黑色像素，跳过
            if j not in g or not g[j]:
                continue
            
            # 取该列第一个黑色像素所在的行
            first_row = g[j][0]
            
            # 条件 1: 检查该行是否恰好有 target 个黑色像素
            if rows[first_row] != target:
                continue
            
            # 条件 2: 检查该列是否恰好有 target 个黑色像素
            # （即包含黑色像素的行数是否等于第一行的黑色像素数）
            if len(g[j]) != rows[first_row]:
                continue
            
            # 条件 3: 检查该列所有包含黑色像素的行是否都相同
            all_same = True
            for row_idx in g[j]:
                if picture[row_idx] != picture[first_row]:
                    all_same = False
                    break
            
            # 如果所有条件都满足，该列的所有黑色像素都是孤独像素
            if all_same:
                ans += target
        
        return ans
```

## 复杂度分析

### 方法一：哈希表统计法
- **时间复杂度**：O(m × n × n)
  - 第一次遍历矩阵：O(m × n)
  - 遍历每列并验证：O(n)，每列最多比较 m 行，每行比较 O(n)
  - 总体：O(m × n + n × m × n) = O(m × n²)
- **空间复杂度**：O(m × n)
  - `rows` 数组：O(m)
  - `g` 字典：最坏情况 O(m × n)

### 方法二：行签名优化法
- **时间复杂度**：O(m × n²)，与方法一相同
- **空间复杂度**：O(m × n)
  - 行签名字符串：O(m × n)
  - 其他数据结构：O(m × n)

### 方法三：详细注释版
- **时间复杂度**：O(m × n²)
- **空间复杂度**：O(m × n)

**推荐使用方法一或方法二**，它们在实际应用中更高效。

## 关键点总结

1. **理解题意的关键**：第二个条件"所有在列 c 上有黑色像素的行必须完全相同"是核心约束
2. **按列处理**：按列遍历而不是按像素遍历，避免重复计数
3. **行相等判断**：使用列表比较 `picture[i1] == picture[i2]` 或字符串签名比较
4. **计数技巧**：满足条件的列，一次性累加 `target` 个孤独像素
5. **数据结构选择**：使用 `defaultdict(list)` 存储每列的行索引更方便

## 易错点

1. **忘记检查行数量**
   ```python
   # 错误：只检查了第一行的黑色像素数量
   if rows[i1] != target:
       continue
   # 还需要检查该列的黑色像素行数
   if len(g[j]) != rows[i1]:
       continue
   ```

2. **重复计数**
   ```python
   # 错误：按像素计数会导致同一列的像素被重复计数
   for i in range(m):
       for j in range(n):
           if is_lonely(i, j):
               ans += 1
   
   # 正确：按列计数，一次性累加整列
   for j in g:
       if is_valid_column(j):
           ans += target
   ```

3. **行比较方法**
   ```python
   # 错误：比较行索引而不是行内容
   if i1 == i2:  # 错误
   
   # 正确：比较整行内容
   if picture[i1] == picture[i2]:  # 正确
   ```

4. **边界情况处理**
   ```python
   # 必须检查列是否有黑色像素
   if j not in g or not g[j]:
       continue
   ```
