## 题目描述

给你一个有 `n` 个节点的**有向无环图**（DAG），请你找出所有从节点 `0` 到节点 `n-1` 的路径并输出（不要求按特定顺序）。

`graph[i]` 是一个从节点 `i` 可以访问的所有节点的列表（即从节点 `i` 到节点 `graph[i][j]` 存在一条有向边）。

**示例 1：**
```
输入：graph = [[1,2],[3],[3],[]]
输出：[[0,1,3],[0,2,3]]
解释：有两条路径 0 -> 1 -> 3 和 0 -> 2 -> 3
```

**示例 2：**
```
输入：graph = [[4,3,1],[3,2,4],[3],[4],[]]
输出：[[0,4],[0,3,4],[0,1,3,4],[0,1,2,3,4],[0,1,4]]
```

**提示：**
- `n == graph.length`
- `2 <= n <= 15`
- `0 <= graph[i][j] < n`
- `graph[i][j] != i`（即不存在自环）
- `graph[i]` 中的所有元素互不相同
- 保证输入为有向无环图（DAG）

## 解题思路

这是一道经典的**图的路径搜索问题**，需要找出从起点到终点的所有可能路径。

**核心思想：**
- 使用**深度优先搜索（DFS）**或**回溯算法**遍历所有可能的路径
- 从节点 0 开始，递归访问所有邻接节点
- 当到达节点 n-1 时，记录当前路径
- 由于是有向无环图（DAG），不需要记录访问状态，不会出现环

**DFS 遍历过程：**
1. 从节点 0 开始，将 0 加入当前路径
2. 遍历节点 0 的所有邻居节点
3. 对每个邻居节点递归执行 DFS
4. 如果到达目标节点 n-1，将当前路径加入结果
5. 回溯：移除当前节点，尝试其他路径

**为什么不需要 visited 数组？**
- 因为题目保证是**有向无环图**（DAG）
- 不存在环，所以不会无限循环
- 但如果同一个节点在不同路径中可以重复访问

## Python 代码实现

### 方法一：DFS + 回溯（推荐）

```python
from typing import List

class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        """
        使用 DFS 找出所有从 0 到 n-1 的路径
        
        思路：深度优先搜索，遍历所有可能的路径
        
        参数：
            graph: 邻接表表示的有向图
            
        返回：
            所有从 0 到 n-1 的路径列表
        """
        result = []
        n = len(graph)
        
        def dfs(node: int, path: List[int]):
            """
            DFS 递归函数
            
            参数：
                node: 当前访问的节点
                path: 当前路径
            """
            # 到达目标节点，记录路径
            if node == n - 1:
                result.append(path[:])  # 注意：需要复制路径
                return
            
            # 遍历所有邻居节点
            for neighbor in graph[node]:
                path.append(neighbor)  # 选择
                dfs(neighbor, path)     # 递归
                path.pop()              # 回溯
        
        # 从节点 0 开始搜索
        dfs(0, [0])
        return result
```

### 方法二：DFS（不使用回溯）

```python
from typing import List

class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        """
        DFS 方法，每次递归传递新的路径列表
        
        思路：不修改原路径，每次创建新路径
        """
        result = []
        n = len(graph)
        
        def dfs(node: int, path: List[int]):
            """
            DFS 递归函数
            
            参数：
                node: 当前访问的节点
                path: 当前路径（不会被修改）
            """
            # 到达目标节点
            if node == n - 1:
                result.append(path)
                return
            
            # 遍历所有邻居节点
            for neighbor in graph[node]:
                # 创建新路径，包含当前邻居
                dfs(neighbor, path + [neighbor])
        
        # 从节点 0 开始
        dfs(0, [0])
        return result
```

### 方法三：BFS（广度优先搜索）

```python
from typing import List
from collections import deque

class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        """
        使用 BFS 找出所有路径
        
        思路：层序遍历，每个队列元素是一条路径
        """
        result = []
        n = len(graph)
        
        # 队列中存储路径
        queue = deque([[0]])
        
        while queue:
            path = queue.popleft()
            node = path[-1]  # 当前路径的最后一个节点
            
            # 到达目标节点
            if node == n - 1:
                result.append(path)
                continue
            
            # 遍历所有邻居节点
            for neighbor in graph[node]:
                # 创建新路径并加入队列
                new_path = path + [neighbor]
                queue.append(new_path)
        
        return result
```

### 方法四：迭代 + 栈

```python
from typing import List

class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        """
        使用栈实现 DFS 的迭代版本
        
        思路：用栈模拟递归过程
        """
        result = []
        n = len(graph)
        
        # 栈中存储 (当前节点, 当前路径)
        stack = [(0, [0])]
        
        while stack:
            node, path = stack.pop()
            
            # 到达目标节点
            if node == n - 1:
                result.append(path)
                continue
            
            # 将所有邻居加入栈
            for neighbor in graph[node]:
                stack.append((neighbor, path + [neighbor]))
        
        return result
```

## 复杂度分析

### 方法一、二：DFS
- **时间复杂度：** O(2^n × n)
  - 最坏情况下，图是完全图，从 0 到 n-1 有 2^(n-2) 条路径
  - 每条路径最多包含 n 个节点，复制路径需要 O(n)
- **空间复杂度：** O(n)，递归栈深度最多为 n

### 方法三：BFS
- **时间复杂度：** O(2^n × n)，与 DFS 相同
- **空间复杂度：** O(2^n × n)，队列中可能存储所有路径

### 方法四：迭代 + 栈
- **时间复杂度：** O(2^n × n)
- **空间复杂度：** O(2^n × n)，栈中可能存储大量路径

## 图解示例

以示例 1 为例：`graph = [[1,2],[3],[3],[]]`

```
    0
   / \
  1   2
   \ /
    3
```

DFS 搜索过程：
1. 从 0 开始，路径 [0]
2. 访问 1，路径 [0,1]
3. 访问 3，路径 [0,1,3]，到达终点，记录
4. 回溯到 0，访问 2，路径 [0,2]
5. 访问 3，路径 [0,2,3]，到达终点，记录

最终结果：`[[0,1,3], [0,2,3]]`

## 关键点总结

1. **DFS vs BFS**：两种方法都可以，DFS 代码更简洁，BFS 更直观
2. **路径复制**：使用 `path[:]` 或 `path + [x]` 创建新列表，避免引用问题
3. **无需 visited**：有向无环图不会有环，不需要标记访问状态
4. **回溯技巧**：方法一使用回溯，方法二每次创建新路径
5. **终止条件**：到达节点 n-1 时记录路径

## 易错点

1. **路径引用问题**：`result.append(path)` 应该改为 `result.append(path[:])`，否则所有路径都指向同一个列表
2. **忘记回溯**：使用回溯时，递归后要 `path.pop()` 恢复状态
3. **目标节点错误**：目标是节点 `n-1`，不是节点 `n`
4. **空图处理**：虽然题目保证 n >= 2，但要注意边界情况
5. **路径顺序**：题目不要求特定顺序，DFS 和 BFS 的结果顺序可能不同
