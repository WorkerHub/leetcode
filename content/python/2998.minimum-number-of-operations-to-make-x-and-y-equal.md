## 题目描述

给你两个正整数 `x` 和 `y`，每次可以进行以下操作之一：
1. 若 `x` 整除 11，则将 `x` 除以 11
2. 若 `x` 整除 5，则将 `x` 除以 5
3. 将 `x` 加 1
4. 将 `x` 减 1

返回使 `x == y` 的最少操作次数。

**示例 1：**
```
输入：x = 26, y = 1
输出：3
解释：26 -> 25 -> 5 -> 1，3 次操作
```

**示例 2：**
```
输入：x = 54, y = 2
输出：4
```

**提示：**
- `1 <= x, y <= 10^4`

## 解题思路

BFS 从 x 出发，找到 y 的最短路径（最少操作次数）。

状态：当前值。
转移：+1, -1, /11（若整除），/5（若整除）。

也可以用双向 BFS 优化，或记忆化搜索。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from collections import deque

class Solution:
    def minimumOperationsToMakeEqual(self, x: int, y: int) -> int:
        if x <= y:
            return y - x  # 只能 +1

        visited = set()
        queue = deque([(x, 0)])
        visited.add(x)

        while queue:
            curr, steps = queue.popleft()
            if curr == y:
                return steps

            for nxt in [curr + 1, curr - 1,
                        curr // 11 if curr % 11 == 0 else None,
                        curr // 5 if curr % 5 == 0 else None]:
                if nxt is None or nxt <= 0:
                    continue
                if nxt not in visited:
                    visited.add(nxt)
                    queue.append((nxt, steps + 1))

        return -1
```

### 方法二：记忆化 DFS

```python
from functools import lru_cache

class Solution:
    def minimumOperationsToMakeEqual(self, x: int, y: int) -> int:
        @lru_cache(maxsize=None)
        def dp(val: int) -> int:
            if val == y:
                return 0
            if val < y:
                return y - val  # 只能 +1
            # 选项 1：减 1
            res = dp(val - 1) + 1
            # 选项 2：加 1 然后除（若接近 11 或 5 的倍数）
            if val % 11 == 0:
                res = min(res, dp(val // 11) + 1)
            else:
                # 先加减使其变为 11 的倍数再除
                next11 = (val // 11 + 1) * 11
                res = min(res, val - next11 + dp(next11) if next11 <= val else res)
            if val % 5 == 0:
                res = min(res, dp(val // 5) + 1)
            return res

        return dp(x)
```

### 方法三：优化 BFS（限制搜索范围）

```python
from collections import deque

class Solution:
    def minimumOperationsToMakeEqual(self, x: int, y: int) -> int:
        if x == y:
            return 0
        if x < y:
            return y - x

        dist = {x: 0}
        queue = deque([x])

        while queue:
            curr = queue.popleft()
            d = dist[curr]

            for nxt in [curr - 1, curr + 1,
                        curr // 11 if curr % 11 == 0 else -1,
                        curr // 5 if curr % 5 == 0 else -1]:
                if nxt < 0:
                    continue
                if nxt == y:
                    return d + 1
                if nxt not in dist and nxt >= y:
                    dist[nxt] = d + 1
                    queue.append(nxt)
            # 也允许 nxt < y（通过 +1 到达 y）
            if curr - 1 >= y and curr - 1 not in dist:
                pass  # 已处理

        return dist.get(y, abs(x - y))
```

## 复杂度分析

- 时间复杂度：O(x)，BFS 最多访问 x 个状态
- 空间复杂度：O(x)

## 关键点总结

1. BFS 找最短路，操作类型为 +1, -1, /11, /5
2. 状态不需要超过 x（超过 x 只会更难到达 y）
3. 到达 < y 的状态后，最优策略是直接 +1 补差

## 易错点

1. x < y 时只能 +1，直接返回 y - x
2. BFS 需要限制状态范围（不超过 x 的合理范围）
3. /11 和 /5 仅在整除时才可以执行
