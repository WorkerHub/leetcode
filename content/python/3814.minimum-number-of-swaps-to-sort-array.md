## 题目描述

给你一个长度为 `n` 的整数数组 `nums`（元素各不相同），你可以在每次操作中交换任意两个元素。

返回将数组排好序所需的最少交换次数。

**示例 1：**

```
输入：nums = [2, 3, 1, 4]
输出：2
解释：
- 交换 nums[0] 和 nums[2]：[1, 3, 2, 4]
- 交换 nums[1] 和 nums[2]：[1, 2, 3, 4]
共 2 次。
```

**示例 2：**

```
输入：nums = [1, 2, 3, 4]
输出：0
解释：已经有序，无需交换。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `nums` 中元素各不相同

## 解题思路

将问题转化为**置换环**：
1. 将 nums 排序，得到目标位置映射：`pos[v] = i`（值 v 应该在位置 i）。
2. 对每个位置构建置换图：`perm[i] = pos[nums[i]]`（位置 i 的元素应该去哪里）。
3. 分析置换图中的环：长度为 k 的环需要 k-1 次交换。
4. 总交换次数 = sum(环的长度 - 1) = n - 环的数量。

## Python 代码实现

### 方法一：置换环（推荐）

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        # 排序后每个元素的目标位置
        sorted_nums = sorted(range(n), key=lambda i: nums[i])
        # perm[i] = 位置 i 的元素在排序后应在的位置
        perm = [0] * n
        for target_pos, original_pos in enumerate(sorted_nums):
            perm[original_pos] = target_pos

        visited = [False] * n
        swaps = 0

        for i in range(n):
            if visited[i] or perm[i] == i:
                continue
            # 找到以 i 开头的环
            cycle_len = 0
            j = i
            while not visited[j]:
                visited[j] = True
                j = perm[j]
                cycle_len += 1
            # 长度为 cycle_len 的环需要 cycle_len - 1 次交换
            swaps += cycle_len - 1

        return swaps
```

### 方法二：直接模拟交换

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        arr = nums[:]
        # 记录每个值当前所在的位置
        pos = {v: i for i, v in enumerate(arr)}
        sorted_arr = sorted(arr)
        swaps = 0

        for i in range(n):
            if arr[i] != sorted_arr[i]:
                # 找到目标值的当前位置
                j = pos[sorted_arr[i]]
                # 记录交换前的位置信息
                pos[arr[i]] = j
                pos[sorted_arr[i]] = i
                arr[i], arr[j] = arr[j], arr[i]
                swaps += 1

        return swaps
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序占主导
- 空间复杂度：O(n)，置换数组和访问标记

## 关键点总结

1. 置换环是求最少交换次数的经典数学模型。
2. 长度为 k 的环需要恰好 k-1 次交换才能使其内部有序。
3. 总次数 = n - 置换环的数量（含长度为 1 的自环）。

## 易错点

1. 长度为 1 的环（元素已在正确位置）不需要交换，不要计入。
2. 坐标压缩：如果 nums 值域很大，需先离散化再构建置换。
3. 方法二中 pos 字典需要在每次交换后更新。
