## 题目描述

给你两个正整数 `low` 和 `high`，统计 `[low, high]` 范围内**对称整数**的个数。

**对称整数**：位数为偶数，且前一半数字之和等于后一半数字之和。例如 1230 前两位和=3，后两位和=3，是对称整数；1231 不是。

**示例 1：**
```
输入：low = 1, high = 100
输出：9
解释：11,22,33,44,55,66,77,88,99 共 9 个
```

**示例 2：**
```
输入：low = 1200, high = 1230
输出：4
解释：1203,1212,1221,1230
```

**提示：**
- `1 <= low <= high <= 10^4`

## 解题思路

数据范围 [1, 10000]，直接枚举每个数，判断是否为对称整数：
1. 转为字符串，检查长度是否为偶数
2. 计算前半部分数字和与后半部分数字和
3. 判断是否相等

## Python 代码实现

### 方法一：枚举（推荐）

```python
class Solution:
    def countSymmetricIntegers(self, low: int, high: int) -> int:
        def is_symmetric(n: int) -> bool:
            s = str(n)
            if len(s) % 2 != 0:
                return False  # 奇数位不是对称整数
            half = len(s) // 2
            return sum(int(c) for c in s[:half]) == sum(int(c) for c in s[half:])

        return sum(1 for n in range(low, high + 1) if is_symmetric(n))
```

### 方法二：分位数求和

```python
class Solution:
    def countSymmetricIntegers(self, low: int, high: int) -> int:
        count = 0
        for n in range(low, high + 1):
            s = str(n)
            m = len(s)
            if m % 2 == 0:
                half = m // 2
                front = sum(int(c) for c in s[:half])
                back = sum(int(c) for c in s[half:])
                if front == back:
                    count += 1
        return count
```

### 方法三：针对范围优化

```python
class Solution:
    def countSymmetricIntegers(self, low: int, high: int) -> int:
        count = 0
        for n in range(low, high + 1):
            # 2 位数：11, 22, ..., 99
            if 10 <= n <= 99:
                if n // 10 == n % 10:
                    count += 1
            # 4 位数：ABCD，A+B == C+D
            elif 1000 <= n <= 9999:
                a, b, c, d = n // 1000, (n // 100) % 10, (n // 10) % 10, n % 10
                if a + b == c + d:
                    count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O((high - low) × log high)，枚举所有数并判断
- 空间复杂度：O(log high)，字符串转换

## 关键点总结

1. 对称整数必须有偶数个位数
2. 前半部分数字和 == 后半部分数字和
3. 数据范围 10^4，直接枚举即可

## 易错点

1. 奇数位数（如 1 位、3 位）不是对称整数，直接跳过
2. 字符串下标：前半 `s[:half]`，后半 `s[half:]`，注意 Python 切片
