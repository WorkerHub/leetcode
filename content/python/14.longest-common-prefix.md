## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**
```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**
```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**提示：**
- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 解题思路

### 方法一：横向扫描（推荐）⭐
依次遍历字符串数组，更新最长公共前缀。

**思路：**
1. 将第一个字符串作为初始前缀
2. 依次与后面的字符串比较，更新前缀
3. 如果前缀变为空，直接返回

### 方法二：纵向扫描
从第一列开始，逐列比较所有字符串的字符。

**思路：**
1. 从第0列开始，比较所有字符串的第0个字符
2. 如果都相同，继续下一列
3. 如果不同或某个字符串已结束，返回当前前缀

### 方法三：分治法
利用分治思想，将问题分解为求两两字符串的公共前缀。

### 方法四：二分查找
在最短字符串长度范围内进行二分查找。

## Python 代码实现

### 方法一：横向扫描（简单易懂）

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        # 以第一个字符串为基准
        prefix = strs[0]
        
        # 依次与其他字符串比较
        for i in range(1, len(strs)):
            # 不断缩短prefix，直到它是strs[i]的前缀
            while not strs[i].startswith(prefix):
                prefix = prefix[:-1]
                # 如果prefix为空，说明没有公共前缀
                if not prefix:
                    return ""
        
        return prefix
```

### 方法二：纵向扫描

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        # 以第一个字符串的长度为基准
        for i in range(len(strs[0])):
            # 取第一个字符串的第i个字符
            char = strs[0][i]
            
            # 检查其他所有字符串的第i个字符
            for j in range(1, len(strs)):
                # 如果到达某个字符串末尾，或字符不匹配
                if i == len(strs[j]) or strs[j][i] != char:
                    return strs[0][:i]
        
        # 如果循环正常结束，说明第一个字符串就是公共前缀
        return strs[0]
```

### 方法三：使用 Python 内置函数

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        # 找到最短和最长的字符串
        min_str = min(strs)
        max_str = max(strs)
        
        # 只需要比较最短和最长的字符串
        for i in range(len(min_str)):
            if min_str[i] != max_str[i]:
                return min_str[:i]
        
        return min_str
```

**解释：** 
- `min()` 和 `max()` 在字符串列表上按字典序比较
- 最短和最长字符串的公共前缀就是所有字符串的公共前缀

### 方法四：使用 zip 函数（Python 特色）

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        result = []
        # zip(*strs) 会将所有字符串的第i个字符组成一个元组
        for chars in zip(*strs):
            # 如果这一列的所有字符都相同
            if len(set(chars)) == 1:
                result.append(chars[0])
            else:
                break
        
        return ''.join(result)
```

**示例说明：**
```python
strs = ["flower", "flow", "flight"]
zip(*strs) 生成：
('f', 'f', 'f')  # 第0列
('l', 'l', 'l')  # 第1列
('o', 'o', 'i')  # 第2列，不同了，停止
```

### 方法五：分治法

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        def commonPrefix(left, right):
            """求两个字符串的公共前缀"""
            min_len = min(len(left), len(right))
            for i in range(min_len):
                if left[i] != right[i]:
                    return left[:i]
            return left[:min_len]
        
        def divide(start, end):
            """分治求解"""
            if start == end:
                return strs[start]
            
            mid = (start + end) // 2
            left_prefix = divide(start, mid)
            right_prefix = divide(mid + 1, end)
            
            return commonPrefix(left_prefix, right_prefix)
        
        return divide(0, len(strs) - 1)
```

## 复杂度分析

### 横向扫描
- **时间复杂度**：O(m × n)，m 是字符串数量，n 是字符串平均长度
- **空间复杂度**：O(1)

### 纵向扫描
- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)

### min/max 方法
- **时间复杂度**：O(m × n)，min/max 需要遍历所有字符串
- **空间复杂度**：O(1)

### zip 方法
- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m)，set 需要存储一列的字符

### 分治法
- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × log m)，递归调用栈

## 关键点总结

1. **边界条件**：空数组、空字符串需要特殊处理
2. **提前终止**：一旦发现不匹配，可以提前返回
3. **多种方法**：这道题有多种解法，都很直观
4. **Python 技巧**：可以利用 `min/max`、`zip` 等内置函数简化代码
5. **最优选择**：对于新手，推荐横向扫描或纵向扫描，代码简单易懂

## 易错点

1. **空数组检查**：要先判断 `strs` 是否为空
2. **空字符串处理**：数组中可能包含空字符串
3. **字符串长度**：不同字符串长度可能不同，注意越界
