## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，实现以下功能的数据结构：

- `FindSumPairs(nums1, nums2)` 用 `nums1` 和 `nums2` 初始化
- `add(index, val)` 将 `val` 加到 `nums2[index]` 上
- `count(tot)` 返回满足 `nums1[i] + nums2[j] == tot` 的下标对 `(i, j)` 的数目

**提示：**
- `nums1.length <= 1000`，`nums2.length <= 10^5`
- `add` 和 `count` 最多调用 `1000` 次

## 解题思路

**哈希表**：

- `nums1` 较短（最多 1000），`nums2` 较长（最多 10^5）
- 用哈希表 `freq2` 记录 `nums2` 中每个值的出现频次
- `count(tot)`：遍历 `nums1`，对每个 `x`，查询 `freq2[tot - x]`，累加
- `add(index, val)`：更新 `nums2[index]` 并同步更新 `freq2`

## 代码实现

### 方法一：哈希表（推荐）

```python
from collections import defaultdict
from typing import List

class FindSumPairs:
    def __init__(self, nums1: List[int], nums2: List[int]):
        self.nums1 = nums1
        self.nums2 = nums2
        # 用哈希表维护 nums2 的频率
        self.freq2 = defaultdict(int)
        for x in nums2:
            self.freq2[x] += 1

    def add(self, index: int, val: int) -> None:
        old = self.nums2[index]
        self.freq2[old] -= 1
        if self.freq2[old] == 0:
            del self.freq2[old]
        self.nums2[index] += val
        self.freq2[self.nums2[index]] += 1

    def count(self, tot: int) -> int:
        result = 0
        for x in self.nums1:
            result += self.freq2.get(tot - x, 0)
        return result
```

### 方法二：Counter 版本

```python
from collections import Counter
from typing import List

class FindSumPairs:
    def __init__(self, nums1: List[int], nums2: List[int]):
        self.nums1 = nums1
        self.nums2 = nums2
        self.cnt2 = Counter(nums2)

    def add(self, index: int, val: int) -> None:
        old = self.nums2[index]
        self.cnt2[old] -= 1
        self.nums2[index] += val
        self.cnt2[self.nums2[index]] += 1

    def count(self, tot: int) -> int:
        return sum(self.cnt2[tot - x] for x in self.nums1)
```

## 复杂度分析

- **add**：O(1)
- **count**：O(len(nums1))，最多 1000
- **空间**：O(len(nums2))，哈希表

## 关键点总结

1. 对较长的 nums2 维护哈希表，count 只需遍历较短的 nums1
2. add 操作需要同步更新原数组和哈希表，先删旧值再加新值
3. 总时间复杂度：O(n2 + q * n1)，q 为查询次数，n1 <= 1000，q <= 1000

## 易错点

- add 时先减少旧值频率，再增加新值频率，不能只更新一个
- Counter 减少到 0 后不会自动删除，查询时 `counter.get(key, 0)` 或直接 `counter[key]`（Counter 默认返回 0）
