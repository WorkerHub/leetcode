## 题目描述

给定一个有 `n` 个节点的有向加权图，边集为 `edges`，其中 `edges[i] = [u, v, w]` 表示从节点 `u` 到节点 `v` 有权重为 `w` 的边。

给定源节点 `src` 和目标值 `target`，找到最小的节点编号 `x`（0-indexed），使得从 `src` 到 `x` 的最短路径长度不超过 `target`。若不存在，返回 `-1`。

**示例 1：**
```
输入：n = 5, edges = [[0,1,2],[1,2,3],[0,3,1],[3,4,2]], src = 0, target = 4
输出：1
解释：从节点 0 出发：
     到 1：最短路 2 <= 4，满足条件
     到 2：最短路 5 > 4，不满足
     到 3：最短路 1 <= 4，满足
     到 4：最短路 3 <= 4，满足
     满足条件的最小节点编号为 1（0 本身不算，或题目要求从 src 出发到其他节点）。
```

**示例 2：**
```
输入：n = 3, edges = [[0,1,10],[1,2,1]], src = 0, target = 5
输出：-1
解释：无法在代价 <= 5 内到达任何节点。
```

**提示：**
- `2 <= n <= 5 * 10^4`
- `1 <= edges.length <= 10^5`
- `0 <= w <= 10^9`
- `0 <= src < n`

## 解题思路

先用 Dijkstra 算法求从 `src` 出发到所有节点的最短路径，然后在结果中找满足 `dist[x] <= target` 的最小节点编号 `x`。

若需要找"最小编号"，则直接线性扫描距离数组即可，无需二分查找。

二分查找可以用于：当查询多次（不同 target）时，将满足条件的节点按编号预排序，二分定位。

## Python 代码实现

### 方法一：Dijkstra + 线性扫描（推荐）

```python
from typing import List
import heapq

class Solution:
    def findMinimumTarget(self, n: int, edges: List[List[int]], src: int, target: int) -> int:
        # 建图
        graph = [[] for _ in range(n)]
        for u, v, w in edges:
            graph[u].append((v, w))

        # Dijkstra 求最短路
        INF = float('inf')
        dist = [INF] * n
        dist[src] = 0
        heap = [(0, src)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        # 找满足 dist[x] <= target 的最小节点编号（不含 src）
        for x in range(n):
            if x != src and dist[x] <= target:
                return x

        return -1
```

### 方法二：Dijkstra + 二分查找（适合多次查询）

```python
from typing import List
import heapq
import bisect

class Solution:
    def findMinimumTarget(self, n: int, edges: List[List[int]], src: int, target: int) -> int:
        graph = [[] for _ in range(n)]
        for u, v, w in edges:
            graph[u].append((v, w))

        INF = float('inf')
        dist = [INF] * n
        dist[src] = 0
        heap = [(0, src)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        # 收集满足条件的节点并排序（已按编号顺序）
        valid = [x for x in range(n) if x != src and dist[x] <= target]

        return valid[0] if valid else -1
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，Dijkstra 算法
- 空间复杂度：O(n + m)，图的邻接表

## 关键点总结

1. Dijkstra 适用于非负权有向图的单源最短路
2. 找最小编号直接从 0 开始线性扫描即可，无需额外数据结构
3. 若有多个查询，可以预处理 Dijkstra 结果，对每个 target 二分查找

## 易错点

1. 注意源节点本身是否需要排除（距离为 0，若题目要求到达其他节点）
2. 使用惰性删除（检查 `d > dist[u]`）提高 Dijkstra 效率
