## 题目描述

给你一个整数 `mass`，代表一颗行星的初始质量，以及一个整数数组 `asteroids`，表示一些小行星的质量。

你可以按**任意顺序**与小行星相撞。若行星质量 `>= 小行星质量`，则吸收小行星（行星质量增加小行星质量）；否则行星被摧毁。

判断行星是否能消灭**所有**小行星，返回 `true` 或 `false`。

**示例 1：**
```
输入：mass = 10, asteroids = [3,9,19,5,21]
输出：true
解释：排序后 [3,5,9,19,21]，依次吸收：10+3=13, 13+5=18, 18+9=27, 27+19=46, 46+21=67。
```

**示例 2：**
```
输入：mass = 5, asteroids = [4,9,23,4]
输出：false
```

**提示：**
- `1 <= mass <= 10^5`
- `1 <= asteroids.length <= 10^5`
- `1 <= asteroids[i] <= 10^5`

## 解题思路

**贪心：排序后从小到大吸收**

最优策略是先吸收最小的小行星，以便积累足够质量来吸收更大的。

将 `asteroids` 排序后依次判断：
- 若 `mass >= asteroids[i]`：吸收，`mass += asteroids[i]`。
- 否则：无法消灭，返回 false。

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: List[int]) -> bool:
        asteroids.sort()
        for a in asteroids:
            if mass < a:
                return False
            mass += a
        return True
```

### 方法二：使用 all() 和 reduce（函数式风格）

```python
from typing import List

class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: List[int]) -> bool:
        asteroids.sort()
        for a in asteroids:
            if a > mass:
                return False
            mass += a
        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(n log n) | O(1) |

## 关键点总结

1. 贪心：先吸收小的，积累足够质量再吸收大的，是全局最优策略。
2. 排序后线性扫描，简洁高效。
3. 注意 `mass` 会不断增加，可能溢出 int 范围（Python 无限精度整数无此问题）。

## 易错点

- 比较条件：`mass >= a`（可以等于），不是严格大于。
- 不能使用 Python 内置 `sum`，因为质量的积累是有序依赖的（后一步依赖前一步的 mass）。
