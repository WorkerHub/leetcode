## 题目描述

在一个 `8 x 8` 的棋盘上，有多个黑皇后和一个白国王。

给定一个由整数坐标组成的二维数组 `queens`，表示黑皇后的位置。给定一对坐标 `king`，表示白国王的位置。

返回可以直接攻击到国王的所有皇后的坐标（任意顺序）。

**注意**：在国际象棋中，皇后可以沿着直线（水平、垂直）或对角线攻击。

**示例 1：**

```
输入：queens = [[0,1],[1,0],[4,0],[0,4],[3,3],[2,4]], king = [0,0]
输出：[[0,1],[1,0],[3,3]]
解释：
[0,1] 的皇后可以攻击到国王，因为他们在同一行。
[1,0] 的皇后可以攻击到国王，因为他们在同一列。
[3,3] 的皇后可以攻击到国王，因为他们在同一条对角线上。
[0,4] 的皇后无法攻击到国王，因为她被 [0,1] 的皇后挡住了。
[4,0] 的皇后无法攻击到国王，因为她被 [1,0] 的皇后挡住了。
[2,4] 的皇后无法攻击到国王，因为她和国王不在同一条直线或对角线上。
```

**示例 2：**

```
输入：queens = [[0,0],[1,1],[2,2],[3,4],[3,5],[4,4],[4,5]], king = [3,3]
输出：[[2,2],[3,4],[4,4]]
```

**示例 3：**

```
输入：queens = [[5,6],[7,7],[2,1],[0,7],[1,6],[5,1],[3,7],[0,3],[4,0],[1,2],[6,3],[5,0],[0,4],[2,2],[1,1],[6,4],[5,4],[0,0],[2,6],[4,5],[5,2],[1,4],[7,5],[2,3],[0,5],[4,2],[1,0],[2,7],[0,1],[4,6],[6,1],[0,6],[4,3],[1,7]], king = [3,4]
输出：[[2,3],[1,4],[1,6],[3,7],[4,3],[5,4],[4,5]]
```

**提示：**

- `1 <= queens.length < 64`
- `queens[i].length == king.length == 2`
- `0 <= xQueen, yQueen, xKing, yKing < 8`
- 所有给定的位置互不相同

## 解题思路

这道题的核心是模拟皇后的攻击路径。

**核心思想：**

从国王的位置出发，向8个方向（上、下、左、右、4个对角线）进行搜索，找到每个方向上**最近的**皇后。

**为什么从国王出发？**

- 如果从皇后出发，需要判断路径上是否有其他皇后阻挡，较复杂
- 从国王出发，只需找每个方向的第一个皇后，非常简单

**算法步骤：**

1. 将所有皇后位置存入集合（便于 O(1) 查找）
2. 定义8个方向的移动向量
3. 从国王位置出发，沿每个方向搜索
4. 遇到的第一个皇后就是可以攻击国王的皇后
5. 继续下一个方向

## Python 代码实现

### 方法一：方向搜索（推荐）⭐

```python
from typing import List

class Solution:
    def queensAttacktheKing(self, queens: List[List[int]], king: List[int]) -> List[List[int]]:
        """
        从国王位置向8个方向搜索最近的皇后
        
        时间复杂度：O(1)，最多搜索 8 * 8 = 64 个格子
        空间复杂度：O(n)，n 是皇后数量
        """
        # 将皇后位置转换为集合，便于快速查找
        queen_set = set(map(tuple, queens))
        result = []
        
        # 8个方向：上、下、左、右、左上、右上、左下、右下
        directions = [
            (-1, 0),   # 上
            (1, 0),    # 下
            (0, -1),   # 左
            (0, 1),    # 右
            (-1, -1),  # 左上
            (-1, 1),   # 右上
            (1, -1),   # 左下
            (1, 1)     # 右下
        ]
        
        # 从国王位置向每个方向搜索
        for dx, dy in directions:
            x, y = king[0], king[1]
            
            # 沿着当前方向移动
            while 0 <= x + dx < 8 and 0 <= y + dy < 8:
                x += dx
                y += dy
                
                # 如果当前位置有皇后
                if (x, y) in queen_set:
                    result.append([x, y])
                    break  # 找到这个方向上最近的皇后，继续下一个方向
        
        return result
```

### 方法二：简化版本

```python
from typing import List

class Solution:
    def queensAttacktheKing(self, queens: List[List[int]], king: List[int]) -> List[List[int]]:
        """
        代码更简洁的版本
        """
        queen_set = {tuple(q) for q in queens}
        result = []
        
        # 8个方向
        for dx in [-1, 0, 1]:
            for dy in [-1, 0, 1]:
                if dx == 0 and dy == 0:  # 跳过 (0,0)
                    continue
                
                # 从国王位置开始搜索
                x, y = king
                for _ in range(8):  # 最多搜索8步
                    x, y = x + dx, y + dy
                    if (x, y) in queen_set:
                        result.append([x, y])
                        break
        
        return result
```

### 方法三：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def queensAttacktheKing(self, queens: List[List[int]], king: List[int]) -> List[List[int]]:
        """
        模拟皇后攻击国王的过程
        """
        # 步骤1：创建皇后位置的哈希集合
        # 使用集合的目的：O(1) 时间检查某个位置是否有皇后
        queen_positions = set()
        for queen in queens:
            queen_positions.add((queen[0], queen[1]))
        
        # 步骤2：定义8个方向
        # 国际象棋中，皇后可以沿着8个方向攻击
        directions = [
            (-1, 0),   # 向上（行减少）
            (1, 0),    # 向下（行增加）
            (0, -1),   # 向左（列减少）
            (0, 1),    # 向右（列增加）
            (-1, -1),  # 左上对角线
            (-1, 1),   # 右上对角线
            (1, -1),   # 左下对角线
            (1, 1)     # 右下对角线
        ]
        
        # 步骤3：存储可以攻击国王的皇后
        attacking_queens = []
        
        # 步骤4：从国王位置向每个方向搜索
        for direction_x, direction_y in directions:
            # 从国王的位置开始
            current_x = king[0]
            current_y = king[1]
            
            # 沿着当前方向一步步移动
            # 棋盘是 8x8，所以最多移动7步
            for step in range(1, 8):
                # 计算新位置
                current_x = king[0] + direction_x * step
                current_y = king[1] + direction_y * step
                
                # 检查是否越界
                if current_x < 0 or current_x >= 8 or current_y < 0 or current_y >= 8:
                    break
                
                # 检查当前位置是否有皇后
                if (current_x, current_y) in queen_positions:
                    # 找到这个方向上最近的皇后
                    attacking_queens.append([current_x, current_y])
                    # 不再继续这个方向，因为更远的皇后被挡住了
                    break
        
        return attacking_queens
```

## 复杂度分析

- **时间复杂度**：O(1)
  - 棋盘固定大小 8×8，最多检查 8 个方向 × 7 步 = 56 个位置
  - 创建集合需要 O(n)，n 是皇后数量，但 n < 64 也是常数

- **空间复杂度**：O(n)
  - 存储皇后位置的集合

## 关键点总结

1. **方向遍历**：定义8个方向的移动向量
2. **从国王出发**：比从皇后出发更简单
3. **最近原则**：每个方向只取第一个遇到的皇后
4. **集合优化**：使用集合实现 O(1) 查找
5. **边界检查**：确保不越界

## 易错点

1. **方向定义错误**：
   - 8个方向要完整，不要遗漏对角线
   - 注意 (0, 0) 不是方向

2. **搜索起点**：
   - 错误：从皇后位置开始搜索
   - 正确：从国王位置开始搜索

3. **忘记 break**：
   - 找到第一个皇后后要 break
   - 否则会把同一方向上的所有皇后都加入结果

4. **边界判断**：
   - 要检查 0 <= x < 8 和 0 <= y < 8
   - 注意是小于 8，不是小于等于

5. **数据结构选择**：
   - 使用列表查找是 O(n)
   - 使用集合查找是 O(1)
