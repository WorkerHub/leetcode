## 题目描述

给你一个长度为 `n` 的整数数组 `nums`。

考虑 `nums` 中进行 **按位与（AND）**运算得到的值 **最大** 的 **非空** 子数组。

换言之，令 `k` 是 `nums` 任意 子数组执行按位与运算所能得到的最大值。那么，只需要考虑那些执行按位与运算后等于 `k` 的子数组。

返回满足要求的 **最长** 子数组的长度。

**示例 1：**
```
输入：nums = [1,2,3,3,2,2]
输出：2
解释：子数组 [3,3] 按位 AND 结果为 3，是最大值，且长度最长为 2。
```

**示例 2：**
```
输入：nums = [1,2,3,4]
输出：1
解释：最大按位 AND 为 4，只有单个元素 [4]。
```

## 解题思路

**脑筋急转弯：**

子数组的按位 AND 值随着子数组增长只能减小或不变（AND 操作会抹去位）。

**关键结论：** 按位 AND 最大值 = 数组中的最大元素本身。

**证明：**
- 任意子数组 `[i..j]` 的 AND 值 <= `nums[k]`（对任意 k 在 [i, j] 内）
- 因此最大 AND 值 <= max(nums)
- 单个元素 `[max_val]` 的 AND 值 = `max_val`
- 所以最大 AND 值 = `max_val`，且只能在全为 `max_val` 的连续子数组中达到

因此，问题变为：**找最长的由最大值构成的连续子数组**。

## 代码实现

### 方法一：找最长连续最大值子数组（推荐）

```python
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        max_val = max(nums)  # 最大 AND 值就是数组最大值
        ans = 0
        cur = 0

        for x in nums:
            if x == max_val:
                cur += 1  # 连续最大值长度加一
                ans = max(ans, cur)
            else:
                cur = 0  # 连续中断，重置

        return ans
```

### 方法二：一次遍历（合并步骤）

```python
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        max_val = max(nums)
        ans = 1
        cur = 0

        for x in nums:
            if x == max_val:
                cur += 1
            else:
                ans = max(ans, cur)
                cur = 0

        return max(ans, cur)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(n) | O(1) |

## 关键点总结

1. AND 操作的最大值就是数组的最大值（单元素）
2. 任何包含非最大值的子数组，AND 值必然小于最大值
3. 问题简化为：找由最大值组成的最长连续子数组

## 易错点

- 不要真的去枚举所有子数组计算 AND，会超时
- 最大 AND 值不一定是 2 的幂次，也可以是任意值
