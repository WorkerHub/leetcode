## 题目描述

给你一个字符串 `s` 和一个整数 `k`。你可以选择字符串中的任一字符，并将其更改为任何其他大写英文字符。该操作最多可执行 `k` 次。

在执行上述操作后，返回包含相同字母的最长子字符串的长度。

**示例 1：**
```
输入：s = "ABAB", k = 2
输出：4
解释：用两个'A'替换两个'B',反之亦然。
```

**示例 2：**
```
输入：s = "AABABBA", k = 1
输出：4
解释：
将中间的一个'A'替换为'B',字符串变为 "AABBBBA"。
子串 "BBBB" 有最长重复字母, 答案为 4。
可能存在其他的方法来得到同样的结果。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由大写英文字母组成
- `0 <= k <= s.length`

## 解题思路

这道题要求找到替换 k 个字符后，能得到的最长相同字符子串。核心思想是使用滑动窗口。

**关键观察：**
1. 在一个窗口内，如果要让所有字符相同，应该保留出现次数最多的字符
2. 需要替换的字符数 = 窗口大小 - 窗口内出现最多的字符次数
3. 只要需要替换的字符数 ≤ k，窗口就是有效的

**算法流程（滑动窗口）：**
1. 使用左右指针维护一个窗口
2. 右指针不断扩展，统计窗口内每个字符的出现次数
3. 维护窗口内出现最多的字符次数 `max_count`
4. 如果 `窗口大小 - max_count > k`，说明需要替换的字符太多，左指针右移
5. 更新最大窗口大小

## Python 代码实现

### 方法一：滑动窗口 + 哈希表 ⭐ 推荐

```python
from collections import defaultdict

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        # 记录窗口内每个字符的出现次数
        count = defaultdict(int)
        
        left = 0  # 左指针
        max_count = 0  # 窗口内出现最多的字符次数
        max_length = 0  # 最长子串长度
        
        # 右指针遍历字符串
        for right in range(len(s)):
            # 扩展窗口：加入右边的字符
            count[s[right]] += 1
            
            # 更新窗口内出现最多的字符次数
            max_count = max(max_count, count[s[right]])
            
            # 窗口大小
            window_size = right - left + 1
            
            # 如果需要替换的字符数 > k，收缩窗口
            if window_size - max_count > k:
                count[s[left]] -= 1
                left += 1
            
            # 更新最大长度
            max_length = max(max_length, right - left + 1)
        
        return max_length
```

### 方法二：优化版（不需要每次更新 max_count）

```python
from collections import defaultdict

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        count = defaultdict(int)
        left = 0
        max_count = 0
        
        for right in range(len(s)):
            count[s[right]] += 1
            max_count = max(max_count, count[s[right]])
            
            # 注意：这里 max_count 不会减小
            # 因为我们只关心能否找到更大的窗口
            # 如果当前窗口无效，left 右移，窗口大小不变
            # 只有找到更大的有效窗口时，窗口才会扩大
            if right - left + 1 - max_count > k:
                count[s[left]] -= 1
                left += 1
        
        return len(s) - left
```

### 方法三：暴力解法（超时，仅用于理解）

```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        max_length = 0
        n = len(s)
        
        # 枚举所有可能的子串
        for i in range(n):
            count = {}
            max_count = 0
            
            for j in range(i, n):
                # 统计字符频率
                count[s[j]] = count.get(s[j], 0) + 1
                max_count = max(max_count, count[s[j]])
                
                # 计算需要替换的字符数
                window_size = j - i + 1
                if window_size - max_count <= k:
                    max_length = max(max_length, window_size)
        
        return max_length
```

## 复杂度分析

**方法一：滑动窗口**
- 时间复杂度：O(n)，其中 n 是字符串长度
  - 左右指针各遍历一次字符串
  - 每次操作都是 O(1)
- 空间复杂度：O(Σ)，Σ 是字符集大小（本题为 26）

**方法二：优化版**
- 时间复杂度：O(n)
- 空间复杂度：O(Σ)

**方法三：暴力**
- 时间复杂度：O(n²)
- 空间复杂度：O(Σ)

## 关键点总结

1. **滑动窗口思想**：维护一个有效窗口，不断扩展和收缩
2. **替换策略**：始终保留窗口内出现最多的字符，替换其他字符
3. **max_count 维护**：可以不用每次都重新计算，只需要在加入新字符时更新
4. **窗口有效性判断**：`窗口大小 - max_count ≤ k`
5. **优化技巧**：max_count 不需要减小，因为只关心是否能找到更大的窗口

## 易错点

1. **max_count 更新时机**：只在加入新字符时更新即可，不需要在左指针移动时重算
2. **窗口收缩条件**：是 `>k` 而不是 `>=k`
3. **结果计算**：是 `right - left + 1`，不要忘记 `+1`
4. **边界情况**：k = 0（不能替换）或 k >= n（可以全部替换）
5. **字符计数**：使用 defaultdict 避免 KeyError
