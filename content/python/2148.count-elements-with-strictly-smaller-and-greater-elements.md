## 题目描述

给你一个整数数组 `nums`，统计其中同时满足以下两个条件的元素数量：

- 在 `nums` 中**存在**一个比它更小的元素。
- 在 `nums` 中**存在**一个比它更大的元素。

返回满足条件的元素数量。

**示例 1：**
```
输入：nums = [11,7,2,15]
输出：2
解释：7 和 11 满足条件（2 < 7 < 15，2 < 11 < 15）。
```

**示例 2：**
```
输入：nums = [-3,3,3,90]
输出：2
解释：两个 3 都满足条件。
```

**提示：**
- `1 <= nums.length <= 100`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

等价于：**既不是数组最大值、也不是数组最小值**的元素数量。

找出最大值和最小值，统计既不等于最大值也不等于最小值的元素数量。

注意：若所有元素相等，则最大值等于最小值，答案为 0。

## 代码实现

### 方法一：统计非极值（推荐）

```python
from typing import List

class Solution:
    def countElements(self, nums: List[int]) -> int:
        min_val = min(nums)
        max_val = max(nums)
        # 若 min == max，所有元素相等，答案为 0
        if min_val == max_val:
            return 0
        # 统计既不是最小值也不是最大值的元素数量
        return sum(1 for x in nums if x != min_val and x != max_val)
```

### 方法二：排序后统计

```python
from typing import List

class Solution:
    def countElements(self, nums: List[int]) -> int:
        s = sorted(set(nums))
        if len(s) < 3:
            return 0
        return sum(1 for x in nums if s[0] < x < s[-1])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 统计非极值 | O(n) | O(1) |
| 排序 | O(n log n) | O(n) |

## 关键点总结

1. 满足条件 = 既不是最大值也不是最小值。
2. 边界处理：所有元素相等时 min == max，答案为 0。
3. 方法一最简洁，O(n) 时间，O(1) 空间。

## 易错点

- 仅有一个或两个不同值时（如 `[1,1]` 或 `[1,2]`），答案为 0。
- 用 `!=` 而非 `<>`（Python 3 中 `<>` 已废弃）。
