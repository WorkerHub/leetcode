## 题目描述

不使用任何库函数，设计一个跳表（Skiplist）。

跳表是一种数据结构，它使得包含 n 个元素的有序序列的查找和插入操作的平均时间复杂度都是 O(log n)，优于数组的 O(n)。

跳表是在 O(log(n)) 时间内完成增加、删除、搜索操作的数据结构。相比于树堆与红黑树，跳表的功能与性能相当，并且跳表的代码长度相较下更短，其设计思想与链表相似。

跳表中有很多层，每一层是一个有序的链表。最底层(Level 0)的链表包含所有元素。每个元素以某个随机的概率（通常是 0.5）出现在上一层。

实现 `Skiplist` 类：

- `Skiplist()` 初始化跳表对象
- `bool search(int target)` 返回 target 是否存在于跳表中
- `void add(int num)` 插入一个元素到跳表
- `bool erase(int num)` 在跳表中删除一个值，如果 num 不存在，直接返回 false。如果存在多个 num，删除其中任意一个即可

**示例：**

```
输入：
["Skiplist", "add", "add", "add", "search", "add", "search", "erase", "erase", "search"]
[[], [1], [2], [3], [0], [4], [1], [0], [1], [1]]
输出：
[null, null, null, null, false, null, true, false, true, false]

解释：
Skiplist skiplist = new Skiplist();
skiplist.add(1);
skiplist.add(2);
skiplist.add(3);
skiplist.search(0);   // 返回 false
skiplist.add(4);
skiplist.search(1);   // 返回 true
skiplist.erase(0);    // 返回 false，0 不在跳表中
skiplist.erase(1);    // 返回 true
skiplist.search(1);   // 返回 false，1 已被删除
```

**提示：**
- 0 <= num, target <= 2 × 10^4
- 调用 search、add 和 erase 操作次数不大于 5 × 10^4
- 跳表中可能存在重复的值

## 解题思路

跳表是一种**概率型数据结构**，通过多层链表的组织实现快速查找。

### 核心思想

1. **分层结构**：
   - 最底层(Level 0)包含所有元素，按升序排列
   - 上层是下层的子集，元素以一定概率（通常0.5）晋升到上层
   - 最上层元素最少，查找最快

2. **查找过程**：
   - 从最高层开始，向右查找
   - 如果右边节点值 >= 目标值，则向下一层
   - 如果右边节点值 < 目标值，则继续向右
   - 重复直到找到目标或到达底层

3. **插入过程**：
   - 先查找插入位置（记录每层的前驱节点）
   - 随机生成层数（通过抛硬币决定）
   - 在相应层级插入新节点

4. **删除过程**：
   - 查找目标节点（记录每层的前驱节点）
   - 从所有层级删除该节点

### 为什么使用跳表？

- **时间复杂度**：平均 O(log n)，与平衡树相当
- **空间复杂度**：O(n)
- **实现简单**：比红黑树、AVL树简单得多
- **并发友好**：容易实现无锁操作

## Python 代码实现

### 方法一：标准跳表实现（推荐）

```python
import random
from typing import Optional

class Node:
    """跳表节点"""
    def __init__(self, val: int = -1, level: int = 0):
        self.val = val
        # forward[i] 指向第 i 层的下一个节点
        self.forward = [None] * (level + 1)

class Skiplist:
    def __init__(self):
        self.MAX_LEVEL = 16  # 最大层数
        self.P = 0.5  # 晋升概率
        self.level = 0  # 当前最高层数
        # 创建头节点，包含所有层
        self.head = Node(-1, self.MAX_LEVEL)
    
    def random_level(self) -> int:
        """随机生成层数"""
        level = 0
        while random.random() < self.P and level < self.MAX_LEVEL:
            level += 1
        return level
    
    def search(self, target: int) -> bool:
        """搜索目标值"""
        curr = self.head
        # 从最高层开始向下查找
        for i in range(self.level, -1, -1):
            # 在当前层向右移动，直到下一个节点 >= target
            while curr.forward[i] and curr.forward[i].val < target:
                curr = curr.forward[i]
        
        # 移动到底层的下一个节点
        curr = curr.forward[0]
        return curr is not None and curr.val == target
    
    def add(self, num: int) -> None:
        """添加元素"""
        update = [None] * (self.MAX_LEVEL + 1)
        curr = self.head
        
        # 找到每层的插入位置（记录前驱节点）
        for i in range(self.level, -1, -1):
            while curr.forward[i] and curr.forward[i].val < num:
                curr = curr.forward[i]
            update[i] = curr
        
        # 随机生成新节点的层数
        new_level = self.random_level()
        
        # 如果新层数大于当前最大层数，更新头节点的引用
        if new_level > self.level:
            for i in range(self.level + 1, new_level + 1):
                update[i] = self.head
            self.level = new_level
        
        # 创建新节点并插入
        new_node = Node(num, new_level)
        for i in range(new_level + 1):
            new_node.forward[i] = update[i].forward[i]
            update[i].forward[i] = new_node
    
    def erase(self, num: int) -> bool:
        """删除元素"""
        update = [None] * (self.MAX_LEVEL + 1)
        curr = self.head
        
        # 找到每层的删除位置（记录前驱节点）
        for i in range(self.level, -1, -1):
            while curr.forward[i] and curr.forward[i].val < num:
                curr = curr.forward[i]
            update[i] = curr
        
        # 检查目标节点是否存在
        curr = curr.forward[0]
        if curr is None or curr.val != num:
            return False
        
        # 从所有层删除该节点
        for i in range(self.level + 1):
            if update[i].forward[i] != curr:
                break
            update[i].forward[i] = curr.forward[i]
        
        # 更新当前最高层数（如果最高层已空）
        while self.level > 0 and self.head.forward[self.level] is None:
            self.level -= 1
        
        return True
```

### 方法二：简化版跳表（固定层数）

```python
import random
from typing import List

class Node:
    def __init__(self, val: int, max_level: int):
        self.val = val
        self.next = [None] * max_level

class Skiplist:
    def __init__(self):
        self.max_level = 16
        self.head = Node(-1, self.max_level)
        self.level = 0
    
    def _find(self, target: int) -> List[Node]:
        """查找目标位置，返回每层的前驱节点"""
        update = [None] * self.max_level
        curr = self.head
        
        for i in range(self.level, -1, -1):
            while curr.next[i] and curr.next[i].val < target:
                curr = curr.next[i]
            update[i] = curr
        
        return update
    
    def search(self, target: int) -> bool:
        update = self._find(target)
        curr = update[0].next[0]
        return curr is not None and curr.val == target
    
    def add(self, num: int) -> None:
        update = self._find(num)
        
        # 随机层数
        level = 0
        while random.random() < 0.5 and level < self.max_level - 1:
            level += 1
        
        if level > self.level:
            for i in range(self.level + 1, level + 1):
                update[i] = self.head
            self.level = level
        
        # 插入节点
        new_node = Node(num, self.max_level)
        for i in range(level + 1):
            new_node.next[i] = update[i].next[i]
            update[i].next[i] = new_node
    
    def erase(self, num: int) -> bool:
        update = self._find(num)
        curr = update[0].next[0]
        
        if curr is None or curr.val != num:
            return False
        
        for i in range(self.level + 1):
            if update[i].next[i] != curr:
                break
            update[i].next[i] = curr.next[i]
        
        while self.level > 0 and self.head.next[self.level] is None:
            self.level -= 1
        
        return True
```

### 方法三：使用有序列表模拟（简化实现，非标准跳表）

```python
from typing import List
import bisect

class Skiplist:
    def __init__(self):
        self.data: List[int] = []
    
    def search(self, target: int) -> bool:
        """二分查找"""
        idx = bisect.bisect_left(self.data, target)
        return idx < len(self.data) and self.data[idx] == target
    
    def add(self, num: int) -> None:
        """二分插入"""
        bisect.insort(self.data, num)
    
    def erase(self, num: int) -> bool:
        """查找并删除"""
        idx = bisect.bisect_left(self.data, num)
        if idx < len(self.data) and self.data[idx] == num:
            self.data.pop(idx)
            return True
        return False
```

## 复杂度分析

**标准跳表实现：**
- **时间复杂度：**
  - search: O(log n) 平均，O(n) 最坏（所有元素都在底层）
  - add: O(log n) 平均
  - erase: O(log n) 平均
- **空间复杂度：** O(n)，平均每个元素占用 2 个指针（期望层数为 2）

**有序列表模拟：**
- **时间复杂度：**
  - search: O(log n)（二分查找）
  - add: O(n)（插入需要移动元素）
  - erase: O(n)（删除需要移动元素）
- **空间复杂度：** O(n)

## 关键点总结

1. **随机化是核心**：通过随机层数保证平衡，避免退化
2. **多层链表**：每层都是下层的子集，上层稀疏、查找快
3. **记录前驱节点**：插入和删除都需要记录每层的前驱节点
4. **层数动态调整**：删除后需要检查并降低最高层数
5. **概率选择**：通常使用 P=0.5，期望层数为 log₂(n)

## 易错点

1. **忘记更新层数**：插入时新层数可能超过当前最大层数，需要更新
2. **删除后层数未降低**：删除顶层元素后，需要降低 level
3. **边界条件**：空跳表、单个元素、重复元素的处理
4. **随机数种子**：在测试时注意随机性可能导致的不稳定
5. **指针更新顺序**：插入时先更新新节点的 forward，再更新前驱的 forward
6. **重复值处理**：题目允许重复，删除时只删除一个即可
