## 题目描述

将一个给定字符串 `s` 根据给定的行数 `numRows`，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 `"PAYPALISHIRING"` 行数为 `3` 时，排列如下：

```
P   A   H   N
A P L S I I G
Y   I   R
```

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如：`"PAHNAPLSIIGYIR"`。

请你实现这个将字符串进行指定行数变换的函数。

**示例 1：**
```
输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"
```

**示例 2：**
```
输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
解释：
P     I    N
A   L S  I G
Y A   H R
P     I
```

**示例 3：**
```
输入：s = "A", numRows = 1
输出："A"
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 由英文字母（小写和大写）、`','` 和 `'.'` 组成
- `1 <= numRows <= 1000`

## 解题思路

核心思想：按行存储字符

关键观察：
- 第一行和最后一行：方向只有一个
- 中间行：方向会改变（向下→向上）
- 用一个标志位控制方向

## Python 代码实现

### 方法一：按行存储（推荐）

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1 or numRows >= len(s):
            return s
        
        # 创建 numRows 个列表存储每一行
        rows = [''] * numRows
        current_row = 0
        going_down = False
        
        for char in s:
            rows[current_row] += char
            
            # 到达第一行或最后一行时改变方向
            if current_row == 0 or current_row == numRows - 1:
                going_down = not going_down
            
            # 移动到下一行
            current_row += 1 if going_down else -1
        
        return ''.join(rows)
```

### 方法二：找规律（数学方法）

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1 or numRows >= len(s):
            return s
        
        result = []
        cycle_len = 2 * numRows - 2  # 一个周期的长度
        
        for i in range(numRows):
            j = i
            while j < len(s):
                result.append(s[j])
                
                # 中间行还有斜向的字符
                if i != 0 and i != numRows - 1:
                    k = j + cycle_len - 2 * i
                    if k < len(s):
                        result.append(s[k])
                
                j += cycle_len
        
        return ''.join(result)
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **方向控制**：到达边界时改变方向
2. **边界情况**：numRows = 1 时直接返回
3. **周期规律**：每 `2*numRows-2` 个字符为一个周期

## 易错点

1. **边界**：numRows = 1 或 numRows >= len(s) 时
2. **方向改变**：在第一行和最后一行改变

## 学习建议

方法一更直观，方法二需要找规律。建议先掌握方法一。
