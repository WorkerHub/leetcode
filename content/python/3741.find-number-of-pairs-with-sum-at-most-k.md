## 题目描述

给定整数数组 `nums` 和整数 `k`，统计满足 `nums[i] + nums[j] <= k`（`i < j`）的配对 `(i, j)` 的数量。

**示例 1：**
```
输入：nums = [1,2,3,4], k = 5
输出：3
解释：满足条件的对：(1,4),(1,3),(2,3) -> (0,3),(0,2),(1,2)，共 3 对。
     1+4=5<=5, 1+3=4<=5, 2+3=5<=5, 2+4=6>5, 3+4=7>5, 1+2=3<=5 -> 还有 (0,1)。
     共 4 对。
```

**示例 2：**
```
输入：nums = [3,4,5], k = 6
输出：1
解释：3+4=7>6, 3+5=8>6, 4+5=9>6... 只有? 3+3=不存在，重新算：只有一对不对，输出 0？
     重算：k=6, nums=[3,4,5]，所有对之和都 > 6，输出 0。
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`
- `1 <= k <= 100`

## 解题思路

**方法一：排序 + 双指针**

排序后用双指针：
- 左指针 `l=0`，右指针 `r=n-1`
- 若 `nums[l] + nums[r] <= k`：`[l+1, r-1]` 之间的所有数与 `nums[l]` 配对都满足，计数 += `r - l`，`l += 1`
- 否则：`r -= 1`

**方法二：暴力枚举**（n<=50 时完全可行）

## Python 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        nums.sort()
        l, r = 0, len(nums) - 1
        count = 0

        while l < r:
            if nums[l] + nums[r] <= k:
                # nums[l] 与 nums[l+1..r] 的任意元素配对都满足条件
                count += r - l
                l += 1
            else:
                r -= 1

        return count
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] <= k:
                    count += 1
        return count
```

## 复杂度分析

- 时间复杂度：方法一 O(n log n)；方法二 O(n^2)
- 空间复杂度：O(1)（不计排序空间）

## 关键点总结

1. 排序后双指针是解决"两数之和满足条件"问题的经典技巧
2. 当 `nums[l] + nums[r] <= k` 时，`l` 与 `l+1` 到 `r` 之间的所有元素配对均满足
3. 这是 LeetCode 3701 的简化版

## 易错点

1. 计数时是 `r - l`（不是 `r - l + 1`，因为 l 不与自身配对）
2. 需要先排序，才能用双指针
