## 题目描述

给你一个字符串 `s` 和一个整数 `k`，找到长度恰好为 `k` 的子串中，出现频率最高的字符的最大频率。

**示例 1：**

```
输入：s = "aababcabc", k = 3
输出：2
解释：长度为 3 的子串中，"aab"，"aba" 等，最大字符频率为 2。
```

**示例 2：**

```
输入：s = "aaaa", k = 2
输出：2
解释：子串 "aa"，最大字符频率为 2。
```

**提示：**
- `1 <= k <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

使用**滑动窗口 + 哈希表**：
1. 维护大小为 k 的窗口，用哈希表记录各字符频率。
2. 每次窗口右移时更新频率，同时追踪窗口内最大频率。
3. 记录全局最大频率。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import defaultdict

class Solution:
    def maxFreq(self, s: str, k: int) -> int:
        n = len(s)
        freq = defaultdict(int)
        max_freq = 0
        ans = 0

        for i in range(n):
            # 加入右端字符
            freq[s[i]] += 1
            if freq[s[i]] > max_freq:
                max_freq = freq[s[i]]

            # 窗口大小超过 k，移除左端字符
            if i >= k:
                left_char = s[i - k]
                freq[left_char] -= 1
                if freq[left_char] == 0:
                    del freq[left_char]
                # 最大频率可能需要重新计算
                if max_freq > k - 1:
                    max_freq = max(freq.values()) if freq else 0

            # 窗口大小恰好为 k
            if i >= k - 1:
                ans = max(ans, max_freq)

        return ans
```

### 方法二：简化版（每次重新计算最大值）

```python
from collections import Counter

class Solution:
    def maxFreq(self, s: str, k: int) -> int:
        ans = 0
        for i in range(len(s) - k + 1):
            cnt = Counter(s[i:i + k])
            ans = max(ans, max(cnt.values()))
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一优化版）；O(n * k)（方法二）
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 滑动窗口维护固定大小 k 的字符频率表。
2. 最大频率更新：加入新字符时可能增大，移除字符时可能需要重算。
3. 简化版清晰但效率低，适合理解算法。

## 易错点

1. 窗口内的最大频率在移除左端字符后可能降低，需要重新计算。
2. 窗口达到大小 k 时（`i >= k - 1`）才记录答案。
