## 题目描述

给定二叉树的根节点 `root`，找出存在于不同节点 `A` 和 `B` 之间的最大值 `V`，其中 `V = |A.val - B.val|`，且 `A` 是 `B` 的祖先。

**祖先定义：** 如果节点 `A` 的任一子节点等于 `B`，或者 `A` 的任一子节点是 `B` 的祖先，那么我们称 `A` 是 `B` 的祖先。

**示例 1：**

```
输入：root = [8,3,10,1,6,null,14,null,null,4,7,13]
输出：7
解释：
我们有多种祖先节点与子孙节点的差值，其中一些如下：
|8 - 3| = 5
|3 - 7| = 4
|8 - 1| = 7
|10 - 13| = 3
在所有可能的差值中，最大值 7 由 |8 - 1| = 7 得出。
```

**示例 2：**

```
输入：root = [1,null,2,null,0,3]
输出：3
```

**提示：**

- 树中节点数目在范围 `[2, 5000]` 内
- `0 <= Node.val <= 10^5`

## 解题思路

这道题要求找出二叉树中祖先节点和后代节点之间的最大差值。关键观察是：

1. **核心思想：** 对于任意一条从根到叶子的路径，路径上任意两个节点都满足祖先-后代关系。因此，这条路径上的最大差值就是 **路径最大值 - 路径最小值**。

2. **DFS 遍历：** 我们可以使用深度优先搜索（DFS）遍历树，在遍历过程中维护从根节点到当前节点路径上的最大值和最小值。

3. **更新答案：** 在每个节点处，计算当前路径的最大差值 `max(|当前值 - 路径最大值|, |当前值 - 路径最小值|)`，更新全局答案。

4. **递归传递：** 向子节点递归时，更新路径的最大值和最小值。

## Python 代码实现

### 方法一：DFS 传递最大最小值（推荐）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxAncestorDiff(self, root: Optional[TreeNode]) -> int:
        """
        使用 DFS 遍历树，传递路径上的最大值和最小值
        时间复杂度：O(n)，空间复杂度：O(h)，h 为树的高度
        """
        def dfs(node: Optional[TreeNode], min_val: int, max_val: int) -> int:
            # 递归终止条件：遇到空节点
            if not node:
                return max_val - min_val
            
            # 更新路径上的最大值和最小值
            min_val = min(min_val, node.val)
            max_val = max(max_val, node.val)
            
            # 递归遍历左右子树，取两者中的最大差值
            left_diff = dfs(node.left, min_val, max_val)
            right_diff = dfs(node.right, min_val, max_val)
            
            return max(left_diff, right_diff)
        
        # 从根节点开始，初始最大最小值都是根节点的值
        return dfs(root, root.val, root.val)
```

### 方法二：DFS + 全局变量

```python
class Solution:
    def maxAncestorDiff(self, root: Optional[TreeNode]) -> int:
        """
        使用全局变量记录最大差值
        """
        self.max_diff = 0
        
        def dfs(node: Optional[TreeNode], min_val: int, max_val: int) -> None:
            if not node:
                return
            
            # 计算当前节点与路径最大最小值的差值
            self.max_diff = max(
                self.max_diff,
                abs(node.val - min_val),
                abs(node.val - max_val)
            )
            
            # 更新路径上的最大最小值
            min_val = min(min_val, node.val)
            max_val = max(max_val, node.val)
            
            # 递归遍历左右子树
            dfs(node.left, min_val, max_val)
            dfs(node.right, min_val, max_val)
        
        dfs(root, root.val, root.val)
        return self.max_diff
```

### 方法三：DFS 传递路径列表（直观但低效）

```python
class Solution:
    def maxAncestorDiff(self, root: Optional[TreeNode]) -> int:
        """
        传递完整的路径列表（用于学习理解，实际不推荐）
        时间复杂度：O(n * h)，空间复杂度：O(n * h)
        """
        def dfs(node: Optional[TreeNode], path: list) -> int:
            if not node:
                return 0
            
            # 将当前节点加入路径
            path.append(node.val)
            
            # 计算当前路径的最大差值
            max_diff = 0
            if len(path) > 1:
                max_diff = max(path) - min(path)
            
            # 递归遍历左右子树
            left_diff = dfs(node.left, path[:])
            right_diff = dfs(node.right, path[:])
            
            return max(max_diff, left_diff, right_diff)
        
        return dfs(root, [])
```

## 复杂度分析

**方法一和方法二（推荐）：**

- **时间复杂度：** O(n)，其中 n 是树中节点的数量。每个节点被访问一次。
- **空间复杂度：** O(h)，其中 h 是树的高度。递归调用栈的深度最多为树的高度。在最坏情况下（树退化为链表），空间复杂度为 O(n)；在最好情况下（完全平衡二叉树），空间复杂度为 O(log n)。

**方法三：**

- **时间复杂度：** O(n * h)，每个节点需要计算路径的最大最小值。
- **空间复杂度：** O(n * h)，需要复制路径列表。

## 图解示例

以示例 1 为例：`root = [8,3,10,1,6,null,14,null,null,4,7,13]`

```
          8
        /   \
       3     10
      / \      \
     1   6     14
        / \    /
       4   7  13
```

**DFS 遍历路径：**

1. 路径 `8 -> 3 -> 1`：min=1, max=8，差值=7 ✓（最大）
2. 路径 `8 -> 3 -> 6 -> 4`：min=3, max=8，差值=5
3. 路径 `8 -> 3 -> 6 -> 7`：min=3, max=8，差值=5
4. 路径 `8 -> 10 -> 14 -> 13`：min=8, max=14，差值=6

最终答案为 7。

## 关键点总结

1. **转化问题：** 将"祖先-后代差值"问题转化为"路径最大值-最小值"问题。
2. **信息传递：** 在 DFS 过程中传递路径的最大值和最小值，避免重复计算。
3. **递归设计：** 终止条件是遇到空节点时返回当前路径的最大差值。
4. **优化思路：** 只需要维护最大最小值，不需要保存完整路径。
5. **边界处理：** 题目保证至少有 2 个节点，因此不需要特殊处理单节点情况。

## 易错点

1. **理解祖先定义：** 祖先必须在节点的上方，路径必须是从上到下的。不能是兄弟节点或跨子树的节点。
2. **初始值设置：** DFS 的初始最大最小值应该设置为根节点的值，而不是 0 或无穷大。
3. **返回值混淆：** 在递归函数中，应该返回子树中的最大差值，而不是当前节点的值。
4. **空节点处理：** 当遇到空节点时，应该返回当前路径的差值 `max_val - min_val`，而不是 0。
5. **更新时机：** 最大最小值的更新应该在计算差值之后，确保包含当前节点。
