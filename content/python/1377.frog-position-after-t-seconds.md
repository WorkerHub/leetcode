## 题目描述

给你一棵有 `n` 个顶点的无向树，顶点编号从 `1` 到 `n`。树的边由二维数组 `edges` 给出，`edges[i] = [ui, vi]` 表示顶点 `ui` 和 `vi` 之间有一条边。

青蛙从顶点 `1` 出发，每秒随机跳到一个**未访问过**的相邻顶点。如果没有未访问的相邻顶点，青蛙就**停留在原地**。

请你计算青蛙在 `t` 秒后恰好在顶点 `target` 上的概率。

**示例 1：**
```
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 2, target = 4
输出：0.16666666666666666
解释：
t=0: 青蛙在顶点1
t=1: 以1/3概率跳到2（或1或3，共3个邻居）
t=2: 从2出发，未访问邻居是4和6（共2个），以1/2概率跳到4
最终概率 = 1/3 × 1/2 = 1/6 ≈ 0.1667
```

**示例 2：**
```
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 1, target = 7
输出：0.3333333333333333
解释：t=1时，青蛙从1出发，共3个未访问邻居（2,3,7），跳到7的概率 = 1/3
```

**提示：**
- `1 <= n <= 100`
- `edges.length == n - 1`
- `edges[i].length == 2`
- `1 <= ui, vi <= n`
- `1 <= t <= 50`
- `1 <= target <= n`
- 答案精度误差在 `10^-5` 以内

## 解题思路

### 核心思想：DFS 路径概率

本题的关键：青蛙只在**树**上跳动（无向树，无环），且每步只能去**未访问**的邻居，等价于只能往**子节点**方向跳（不回头）。

**DFS 设计：**
- 从节点1出发，每到一个节点，其"未访问的相邻节点"就是它在树中的子节点（父节点已访问）。
- 到达某节点时的概率 = 父节点概率 × 1/（父节点未访问邻居数）。

**停留条件：**
- 到达 target 后，若 t 秒用完（时间恰好为0），直接返回当前概率。
- 若 target 是叶子节点（无子节点），即使 t 还未用完，青蛙也停留在原地，仍满足条件。
- 若 target 有子节点且 t 还有剩余，青蛙会继续跳走，不会停留，概率为0。

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        # 建立邻接表（无向图）
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def dfs(node, parent, time, prob):
            """
            node:   当前节点
            parent: 父节点（用于避免回头）
            time:   剩余时间
            prob:   到达当前节点的概率
            返回：到达 target 的概率
            """
            # 找到未访问的邻居（即子节点，排除父节点）
            children = [nb for nb in graph[node] if nb != parent]

            if node == target:
                # 到达目标节点
                # 条件1：时间正好用完（time == 0）
                # 条件2：没有子节点（青蛙停留在此，即使 time > 0）
                if time == 0 or len(children) == 0:
                    return prob
                else:
                    # 还有时间且有子节点，青蛙会继续跳走
                    return 0.0

            if time == 0:
                # 时间用完但还未到达 target
                return 0.0

            # 每个子节点被跳到的概率均等
            num_children = len(children)
            if num_children == 0:
                # 叶子节点且不是 target，概率为0
                return 0.0

            # 递归搜索各子节点
            for child in children:
                result = dfs(child, node, time - 1, prob / num_children)
                if result > 0:
                    return result

            return 0.0

        return dfs(1, -1, t, 1.0)
```

### 方法二：BFS 层序遍历

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        if n == 1:
            return 1.0  # 只有一个节点，青蛙只能一直在节点1

        # 建立邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS：(当前节点, 父节点, 到达概率)
        queue = deque([(1, -1, 1.0)])
        visited = {1}

        for step in range(t):
            size = len(queue)
            found_target = False

            for _ in range(size):
                node, parent, prob = queue.popleft()

                # 子节点（未访问的邻居）
                children = [nb for nb in graph[node] if nb not in visited]

                if node == target:
                    # 目标节点：若无子节点则停留，否则会离开
                    if len(children) == 0:
                        return prob  # 停留，直到 t 秒结束
                    else:
                        found_target = True
                        # 继续到下一步，目标节点的后代会入队
                        # 但我们需要追踪目标节点何时离开

                if len(children) == 0:
                    # 叶子节点停留，加回队列
                    queue.append((node, parent, prob))
                else:
                    for child in children:
                        visited.add(child)
                        queue.append((child, node, prob / len(children)))

        # BFS 结束后，检查队列中是否有 target
        for node, parent, prob in queue:
            if node == target:
                return prob

        return 0.0
```

### 方法三：DFS 简化版（利用 Python 特性）

```python
from typing import List
from collections import defaultdict

class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 0.0

        def dfs(node, parent, time, prob):
            nonlocal ans
            children = [v for v in graph[node] if v != parent]

            # 到达 target：时间用完 或 没有子节点（停留）
            if node == target:
                if time == 0 or not children:
                    ans = prob
                return

            # 时间到或是叶子节点（非target），停止搜索
            if time == 0 or not children:
                return

            # 继续向子节点搜索
            for child in children:
                dfs(child, node, time - 1, prob / len(children))

        dfs(1, 0, t, 1.0)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 递归 | O(n) | O(n) |
| BFS | O(n × t) | O(n) |

- **时间复杂度**：O(n)，树中每个节点最多访问一次。
- **空间复杂度**：O(n)，递归栈或队列的最大深度/大小。

## 关键点总结

1. **无向树 = 有根树（以1为根）**：由于无环，每个节点的邻居中，除了父节点都是子节点，不会重复访问。
2. **跳到 target 时的两种情况**：
   - 时间恰好用完：`time == 0` 时在 target，返回当前概率。
   - target 是叶子节点：即使还有时间，青蛙无处可跳，停留在 target，返回当前概率。
3. **等概率跳向子节点**：每个子节点的跳跃概率 = `1 / 子节点数量`。
4. **找到 target 后可以提前返回**：树是无环的，每条根到叶子的路径唯一，找到 target 后不需要继续其他分支。
5. **n=1 的特殊情况**：只有节点1，直接返回1.0。

## 易错点

1. **忘记"停留"条件**：target 是叶子节点时，即使 t > 0，青蛙也无法离开，需要返回概率。
2. **time == 0 但有子节点**：此时青蛙在 target 且时间用完，满足条件（返回概率）；若 node != target，则不满足。
3. **子节点排除父节点**：无向图中，父节点也在邻接表中，DFS 时需排除已访问的父节点。
4. **树上路径唯一**：找到 target 后可以立即返回，不需要继续搜索其他分支。

## 学习建议

1. **无向树的 DFS**：与有向树不同，无向树的 DFS 需要记录父节点以避免回头，这是树上 DFS 的基本技巧。
2. **概率 DFS**：在 DFS 的同时传递当前路径的概率（累乘），是很多概率路径问题的通用模式。
3. 建议先画树图，手动模拟从节点1到各节点的路径和概率，再编码验证。
4. **停留条件的分析**：本题最容易出错的地方是何时返回概率（停留 vs 继续跳），需仔细分析 `time == 0` 和"叶子节点"两种情况。
