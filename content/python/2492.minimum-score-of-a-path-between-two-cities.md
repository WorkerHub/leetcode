## 题目描述

给你一个正整数 `n`，表示共有 `n` 个城市（编号 1 到 n），以及一个二维整数数组 `roads`，其中 `roads[i] = [a_i, b_i, distance_i]` 表示城市 a 和城市 b 之间有一条道路，距离为 distance_i。

路径的 **分数** 定义为路径上所有道路的 **最小距离**。

返回城市 1 和城市 n 之间所有路径的 **最小分数**。

注意：路径可以重复经过同一条道路，也可以重复经过同一个节点。

**提示：**
- `2 <= n <= 10^5`
- `1 <= roads.length <= 10^5`
- `1 <= distance_i <= 10^4`

## 解题思路

**关键观察：** 由于路径可以重复走边，城市 1 和城市 n 若连通，则 1 和 n 所在连通分量中的所有边都可以被使用。

因此，答案就是城市 1 和城市 n 所在连通分量中**所有边的最小权重**。

可用 BFS/DFS 或并查集求连通分量。

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        # 构建邻接表（包含边权）
        adj = defaultdict(list)
        for a, b, d in roads:
            adj[a].append((b, d))
            adj[b].append((a, d))

        # BFS 求城市 1 所在连通分量的最小边权
        visited = set()
        queue = deque([1])
        visited.add(1)
        min_score = float('inf')

        while queue:
            node = queue.popleft()
            for neighbor, dist in adj[node]:
                min_score = min(min_score, dist)  # 更新最小边权
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)

        return min_score
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        parent = list(range(n + 1))
        rank = [0] * (n + 1)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1

        # 先合并所有边
        for a, b, _ in roads:
            union(a, b)

        # 找到与节点 1 同一连通分量的所有边的最小权值
        root1 = find(1)
        min_score = float('inf')
        for a, b, d in roads:
            if find(a) == root1:
                min_score = min(min_score, d)

        return min_score
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n + m) | O(n + m) |
| 并查集 | O(m * alpha(n)) | O(n) |

## 关键点总结

1. 路径可以重复经过边，所以只要 1 和 n 连通，它们连通分量内的所有边都可使用
2. 答案 = 1 和 n 的连通分量中所有边的最小权重
3. BFS/DFS 从节点 1 出发，遍历所有可达节点，收集最小边权

## 易错点

- 不需要找从 1 到 n 的最短路，而是找连通分量的最小边
- 题目保证 1 和 n 一定连通（如果不连通就不会有路径）
