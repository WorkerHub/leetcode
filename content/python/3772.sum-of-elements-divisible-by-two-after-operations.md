## 题目描述

给定整数数组 `nums`，对其执行 `k` 次操作：每次将数组中的最大元素除以 2（向下取整）并替换回数组。返回 `k` 次操作后，数组中所有偶数元素的总和。

**示例 1：**
```
输入：nums = [2,4,6], k = 2
输出：10
解释：初始偶数和：2+4+6=12。
     操作1：最大值 6 -> 3（奇数），偶数和：2+4=6。
     操作2：最大值 4 -> 2，偶数和：2+2=4... 
     等等，操作后 nums=[2,4,3]，偶数和=2+4=6；操作2：[2,2,3]，偶数和=2+2=4。
     结果为 4？还是返回操作后的状态。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

使用最大堆模拟：每次取最大元素，除以 2 后放回堆中。

但 k 最大为 10^9，不能每次都操作。

**优化：** 注意到任何正整数经过最多 30 次除 2 后变为 0，一旦所有元素都是 0 则结果不变。因此最多只需操作 `min(k, 30 * n)` 次。

最终统计所有偶数元素的和。

## Python 代码实现

### 方法一：最大堆模拟（推荐）

```python
from typing import List
import heapq

class Solution:
    def sumDivisibleByTwo(self, nums: List[int], k: int) -> int:
        # 最大堆（Python 用负数模拟）
        heap = [-x for x in nums]
        heapq.heapify(heap)

        # 最多操作 min(k, 30*n) 次（超过后所有元素为 0）
        max_ops = min(k, 30 * len(nums))

        for _ in range(max_ops):
            top = -heapq.heappop(heap)
            if top == 0:
                heapq.heappush(heap, 0)
                break  # 最大值为 0，后续无变化
            new_val = top // 2
            heapq.heappush(heap, -new_val)

        # 统计偶数元素之和
        return sum(-x for x in heap if -x % 2 == 0)
```

### 方法二：直接模拟（k 较小时）

```python
from typing import List

class Solution:
    def sumDivisibleByTwo(self, nums: List[int], k: int) -> int:
        nums = sorted(nums, reverse=True)
        actual_k = min(k, 30 * len(nums))

        for _ in range(actual_k):
            nums[0] = nums[0] // 2
            # 重新排序（可用插入排序优化）
            i = 0
            while i + 1 < len(nums) and nums[i] < nums[i+1]:
                nums[i], nums[i+1] = nums[i+1], nums[i]
                i += 1

        return sum(x for x in nums if x % 2 == 0)
```

## 复杂度分析

- 时间复杂度：O((n + min(k, 30n)) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 最大值最多 30 次除 2 后变为 0（`log2(10^9) ≈ 30`）
2. 用最大堆高效取最大元素，O(log n) 操作
3. 操作次数上限为 `30 * n`，超过后结果不变

## 易错点

1. Python 只有最小堆，用负数模拟最大堆
2. 一旦堆顶为 0，后续操作无效，可以提前退出
