## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，数组大小为 `n`，且全部由 **非负** 整数组成。

你需要对数组执行 `n - 1` 次操作，其中第 `i` 次操作（**从 0 开始** 计数）要求对 `nums` 的前 `n - 1 - i` 个元素执行：

- 如果 `nums[i] == nums[i + 1]`，则 `nums[i]` 乘以 `2` 并将 `nums[i + 1]` 赋值为 `0`。否则，跳过这次操作。

完成所有操作后，将所有 `0` 移动到数组的 **末尾**。

返回结果数组。

**注意：** 操作应当 **依次顺序** 执行，而不是同时执行。

**示例 1：**
```
输入：nums = [1,2,2,1,1,0]
输出：[1,4,2,0,0,0]
解释：
- i=0: nums[0]=1, nums[1]=2，不相等，跳过。
- i=1: nums[1]=2, nums[2]=2，相等，nums[1]=4, nums[2]=0 -> [1,4,0,1,1,0]
- i=2: nums[2]=0, nums[3]=1，不相等，跳过。
- i=3: nums[3]=1, nums[4]=1，相等，nums[3]=2, nums[4]=0 -> [1,4,0,2,0,0]
- i=4: 跳过
将 0 移到末尾：[1,4,2,0,0,0]
```

**提示：**
- `2 <= nums.length <= 2000`
- `0 <= nums[i] <= 1000`

## 解题思路

1. 按顺序执行 n-1 次操作（合并相邻相等元素）
2. 将所有 0 移到末尾（保持非零元素的相对顺序）

## 代码实现

### 方法一：模拟 + 双指针（推荐）

```python
from typing import List

class Solution:
    def applyOperations(self, nums: List[int]) -> List[int]:
        n = len(nums)

        # 执行操作：相邻相等则合并
        for i in range(n - 1):
            if nums[i] == nums[i + 1]:
                nums[i] *= 2
                nums[i + 1] = 0

        # 将非零元素移到前面，0 移到末尾
        result = [x for x in nums if x != 0]
        result += [0] * (n - len(result))

        return result
```

### 方法二：原地双指针移零

```python
from typing import List

class Solution:
    def applyOperations(self, nums: List[int]) -> List[int]:
        n = len(nums)

        # 执行合并操作
        for i in range(n - 1):
            if nums[i] != 0 and nums[i] == nums[i + 1]:
                nums[i] *= 2
                nums[i + 1] = 0

        # 双指针：将非零元素往前移
        write = 0
        for read in range(n):
            if nums[read] != 0:
                nums[write] = nums[read]
                write += 1

        # 填充 0
        for i in range(write, n):
            nums[i] = 0

        return nums
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 + 列表推导 | O(n) | O(n) |
| 原地双指针 | O(n) | O(1) |

## 关键点总结

1. 先执行所有合并操作（按顺序），再将 0 移到末尾
2. 两个步骤不能颠倒：必须先合并，后移零
3. 双指针移零：用 write 指针追踪下一个非零写入位置

## 易错点

- 合并操作必须按顺序执行，且只合并相邻相等的非零元素（若有 0 则跳过）
- 注意题目说操作 `n-1` 次，循环范围是 `range(n-1)`
