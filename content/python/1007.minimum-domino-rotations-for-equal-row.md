## 题目描述

在一排多米诺骨牌中，`tops[i]` 和 `bottoms[i]` 分别代表第 `i` 个多米诺骨牌的上半部分和下半部分。（一个多米诺是两个从 1 到 6 的数字同列平铺形成的，该列的每一半上都有一个数字。）

我们可以旋转第 `i` 个多米诺，使得 `tops[i]` 和 `bottoms[i]` 的值交换。

返回能使 `tops` 中所有值或者 `bottoms` 中所有值都相同的最小旋转次数。

如果无法做到，返回 `-1`。

**示例 1：**
```
输入：tops = [2,1,2,4,2,2], bottoms = [5,2,6,2,3,2]
输出：2
解释：
图一表示：在我们旋转之前，tops 和 bottoms
图二表示：旋转位置 2 和 4 之后，使得 bottoms 中所有元素都是 2
```

**示例 2：**
```
输入：tops = [3,5,1,2,3], bottoms = [3,6,3,3,4]
输出：-1
解释：
在这种情况下，无论怎样旋转都不能使所有值都相同。
```

**提示：**
- `2 <= tops.length <= 2 * 10^4`
- `bottoms.length == tops.length`
- `1 <= tops[i], bottoms[i] <= 6`

## 解题思路

这道题的关键观察是：

**核心思想：**
1. 如果能让所有值相同，这个值**必定是** `tops[0]` 或 `bottoms[0]`
2. 因为每一列都必须包含这个目标值（否则无法旋转得到）
3. 所以我们只需要检查 `tops[0]` 和 `bottoms[0]` 这两个候选值

**算法流程：**
1. 尝试将所有位置的 top 或 bottom 变成 `tops[0]`
2. 尝试将所有位置的 top 或 bottom 变成 `bottoms[0]`
3. 计算每种情况所需的最小旋转次数
4. 返回最小值，如果都无法实现则返回 -1

**旋转次数计算：**
- 如果第 i 列的 top 已经是目标值，不需要旋转
- 如果第 i 列的 bottom 是目标值，需要旋转一次
- 如果两者都不是目标值，说明无法实现

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minDominoRotations(self, tops: List[int], bottoms: List[int]) -> int:
        def check(target: int) -> int:
            """
            检查能否让所有位置的 top 或 bottom 都变成 target
            返回最小旋转次数，如果无法实现返回 -1
            """
            rotations_to_top = 0  # 将 target 都旋转到 top 的次数
            rotations_to_bottom = 0  # 将 target 都旋转到 bottom 的次数
            
            for i in range(len(tops)):
                if tops[i] != target and bottoms[i] != target:
                    # 该列既没有 target 在 top，也没有在 bottom
                    return -1
                
                # 如果 top 不是 target，需要旋转到 top
                if tops[i] != target:
                    rotations_to_top += 1
                
                # 如果 bottom 不是 target，需要旋转到 bottom
                if bottoms[i] != target:
                    rotations_to_bottom += 1
            
            # 返回两种方案的最小值
            return min(rotations_to_top, rotations_to_bottom)
        
        # 只需要检查 tops[0] 和 bottoms[0]
        result = check(tops[0])
        
        # 如果 tops[0] 和 bottoms[0] 不同，还需要检查 bottoms[0]
        if tops[0] != bottoms[0]:
            result2 = check(bottoms[0])
            if result == -1:
                return result2
            elif result2 != -1:
                result = min(result, result2)
        
        return result
```

### 方法二：简化版

```python
from typing import List

class Solution:
    def minDominoRotations(self, tops: List[int], bottoms: List[int]) -> int:
        n = len(tops)
        
        # 尝试 tops[0] 和 bottoms[0] 两个候选值
        candidates = [tops[0]]
        if bottoms[0] != tops[0]:
            candidates.append(bottoms[0])
        
        for target in candidates:
            top_rotations = 0
            bottom_rotations = 0
            valid = True
            
            for i in range(n):
                if tops[i] != target and bottoms[i] != target:
                    valid = False
                    break
                
                if tops[i] != target:
                    top_rotations += 1
                if bottoms[i] != target:
                    bottom_rotations += 1
            
            if valid:
                return min(top_rotations, bottom_rotations)
        
        return -1
```

### 方法三：一次遍历

```python
from typing import List

class Solution:
    def minDominoRotations(self, tops: List[int], bottoms: List[int]) -> int:
        def check_and_count(x: int) -> int:
            """检查是否可以让所有 top 或 bottom 都是 x"""
            top_count = bottom_count = 0
            for i in range(len(tops)):
                if tops[i] != x and bottoms[i] != x:
                    return -1
                elif tops[i] != x:
                    top_count += 1
                elif bottoms[i] != x:
                    bottom_count += 1
            return min(top_count, bottom_count)
        
        # 尝试两个候选值
        ans = check_and_count(tops[0])
        if tops[0] != bottoms[0]:
            ans2 = check_and_count(bottoms[0])
            ans = ans2 if ans == -1 else min(ans, ans2) if ans2 != -1 else ans
        
        return ans
```

### 方法四：计数优化

```python
from typing import List
from collections import Counter

class Solution:
    def minDominoRotations(self, tops: List[int], bottoms: List[int]) -> int:
        n = len(tops)
        
        # 统计每个数字在 top 和 bottom 中出现的次数
        # 以及同时在 top[i] 和 bottom[i] 出现的次数
        top_count = Counter(tops)
        bottom_count = Counter(bottoms)
        same_count = Counter()
        
        for i in range(n):
            if tops[i] == bottoms[i]:
                same_count[tops[i]] += 1
        
        # 检查每个可能的目标值（1-6）
        for target in range(1, 7):
            # 如果 target 出现的总次数（去重）等于 n，说明可行
            if top_count[target] + bottom_count[target] - same_count[target] == n:
                # 旋转次数 = n - 该数字在某一行中出现的次数
                return n - max(top_count[target], bottom_count[target])
        
        return -1
```

## 复杂度分析

**方法一、二、三：**
- **时间复杂度：** O(n)，最多遍历数组两次
- **空间复杂度：** O(1)

**方法四：**
- **时间复杂度：** O(n)
- **空间复杂度：** O(1)，虽然用了 Counter，但只存储 1-6 的数字

## 关键点总结

1. **候选值限定**：目标值只能是 `tops[0]` 或 `bottoms[0]`
2. **必要条件**：每一列都必须包含目标值（在 top 或 bottom 中）
3. **两种方案**：将目标值都移到 top，或都移到 bottom
4. **贪心选择**：选择旋转次数较少的方案
5. **优化技巧**：只需要检查最多 2 个候选值，而不是 6 个

## 易错点

1. **候选值遗漏**：忘记检查 `bottoms[0]`（当它与 `tops[0]` 不同时）
2. **返回值错误**：应该返回最小旋转次数，不是最大次数
3. **边界情况**：
   - 所有 top 和 bottom 都相同
   - 无法实现的情况
4. **计数错误**：同一位置 top 和 bottom 相同时，不要重复计数
