## 题目描述

给你一个二叉树的根节点 `root`，计算并返回整个树的坡度。

一个树的节点的**坡度**定义即为，该节点左子树的节点之和和右子树节点之和的**差的绝对值**。如果没有左子树的话，左子树的节点之和为 0；没有右子树的话也是一样。空节点的坡度是 0。

整个树的坡度就是其所有节点的坡度之和。

**示例 1：**
```
输入：root = [1,2,3]
输出：1
解释：
节点 2 的坡度：|0-0| = 0（没有子节点）
节点 3 的坡度：|0-0| = 0（没有子节点）
节点 1 的坡度：|2-3| = 1（左子树节点和为 2，右子树节点和为 3）
坡度总和：0 + 0 + 1 = 1
```

**示例 2：**
```
输入：root = [4,2,9,3,5,null,7]
输出：15
解释：
节点 3 的坡度：|0-0| = 0
节点 5 的坡度：|0-0| = 0
节点 7 的坡度：|0-0| = 0
节点 2 的坡度：|3-5| = 2
节点 9 的坡度：|0-7| = 7
节点 4 的坡度：|(3+5+2)-(9+7)| = |10-16| = 6
坡度总和：0 + 0 + 0 + 2 + 7 + 6 = 15
```

**提示：**
- 树中节点数目在范围 `[0, 10^4]` 内
- `-1000 <= Node.val <= 1000`

## 解题思路

使用后序遍历（DFS），先计算子树的和，再计算坡度。

## Python 代码实现

### 方法一：递归 DFS（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findTilt(self, root: Optional[TreeNode]) -> int:
        """
        递归 DFS：后序遍历
        
        时间复杂度：O(n)
        空间复杂度：O(h)
        """
        self.total_tilt = 0
        
        def sum_and_tilt(node):
            """返回子树的节点和，同时累加坡度"""
            if not node:
                return 0
            
            left_sum = sum_and_tilt(node.left)
            right_sum = sum_and_tilt(node.right)
            
            # 计算当前节点的坡度
            tilt = abs(left_sum - right_sum)
            self.total_tilt += tilt
            
            # 返回子树和（包括当前节点）
            return left_sum + right_sum + node.val
        
        sum_and_tilt(root)
        return self.total_tilt
```

### 方法二：返回元组

```python
from typing import Optional, Tuple

class Solution:
    def findTilt(self, root: Optional[TreeNode]) -> int:
        """
        返回 (子树和, 坡度和)
        
        时间复杂度：O(n)
        空间复杂度：O(h)
        """
        def dfs(node) -> Tuple[int, int]:
            """返回 (子树和, 坡度和)"""
            if not node:
                return 0, 0
            
            left_sum, left_tilt = dfs(node.left)
            right_sum, right_tilt = dfs(node.right)
            
            current_sum = left_sum + right_sum + node.val
            current_tilt = abs(left_sum - right_sum)
            total_tilt = left_tilt + right_tilt + current_tilt
            
            return current_sum, total_tilt
        
        return dfs(root)[1]
```

## 复杂度分析

- **时间复杂度**：O(n)，访问每个节点一次
- **空间复杂度**：O(h)，递归栈深度

## 关键点总结

1. **后序遍历**：先计算子树再计算当前节点
2. **一次遍历**：同时计算和与坡度
3. **绝对值**：坡度是差的绝对值
