## 题目描述

给你一个字符串 `s`，只包含数字字符。

找出字符串中一对相邻的相同数字，且该数字在整个字符串中恰好出现 2 次（即这两个相邻数字就是字符串中该数字的全部出现）。

如果存在多对，返回在字符串中最靠左的那对中的数字（即两个相邻数字的字符）。如果不存在，返回空字符串。

**示例 1：**

```
输入：s = "2523533"
输出："23"
等等... 相邻且相同的对，且数字只出现 2 次
"2523533" 中：
- 5 出现 1 次，不满足
- 2 出现 2 次，相邻对在位置 0,1？ s[0]='2', s[1]='5' 不相邻相同
- 3 出现 3 次，不满足
- 5 出现 1 次...
重新理解：找相邻且相同的数字对 s[i]==s[i+1]，且 s[i] 在 s 中恰好出现 2 次
```

**示例 2：**

```
输入：s = "2223"
输出："22"... 2 出现 3 次，不满足
```

**提示：**
- `2 <= s.length <= 100`
- `s` 只包含数字字符

## 解题思路

1. 统计每个数字在字符串中出现的次数
2. 遍历字符串，找相邻且相同的字符对 `s[i] == s[i+1]`
3. 检查该数字的出现次数是否恰好为 2
4. 返回最左边的满足条件的对（即 `s[i]` + `s[i+1]`，都是同一个字符）

## Python 代码实现

### 方法一：先统计频率，再扫描（推荐）

```python
from collections import Counter

class Solution:
    def findValidPair(self, s: str) -> str:
        # 统计每个字符的出现次数
        freq = Counter(s)

        # 从左到右扫描相邻相同对
        for i in range(len(s) - 1):
            if s[i] == s[i + 1] and freq[s[i]] == 2:
                return s[i] + s[i + 1]

        return ""
```

### 方法二：一行写法

```python
from collections import Counter

class Solution:
    def findValidPair(self, s: str) -> str:
        freq = Counter(s)
        for i in range(len(s) - 1):
            if s[i] == s[i + 1] and freq[s[i]] == 2:
                return s[i:i + 2]
        return ""
```

### 方法三：不用 Counter

```python
class Solution:
    def findValidPair(self, s: str) -> str:
        for i in range(len(s) - 1):
            if s[i] == s[i + 1] and s.count(s[i]) == 2:
                return s[i] * 2
        return ""
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n)
  - 空间复杂度：O(1)（最多 10 个数字）

- 方法三：
  - 时间复杂度：O(n^2)（count 调用 O(n)，共 n 次）
  - 空间复杂度：O(1)

## 关键点总结

1. 两个条件：相邻相同 + 该数字恰好出现 2 次
2. 先计算频率，再扫描，避免重复计算
3. 返回最靠左的满足条件的对

## 易错点

1. 要求数字在**整个字符串**中出现恰好 2 次，不只是相邻对
2. 返回两个字符（该数字两次），不是一个字符
3. 若不存在满足条件的对，返回空字符串 `""`
