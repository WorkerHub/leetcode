## 题目描述

LeetCode 想让一位员工在 N 个城市出差 K 周。每周你可以选择留在当前城市或飞到另一个城市。每个城市每周有不同的休假天数。

给定两个矩阵 `flights` 和 `days`：
- `flights[i][j]` 表示城市 i 到城市 j 是否有航班（1 表示有，0 表示没有）
- `days[i][j]` 表示在第 j 周在城市 i 可以休假的天数

返回你可以获得的最大休假天数。初始时你在城市 0。

**示例：**
```
输入：flights = [[0,1,1],[1,0,1],[1,1,0]], days = [[1,3,1],[6,0,3],[3,3,3]]
输出：12
解释：
周0: 城市0 -> 城市1 (休假3天)
周1: 城市1 -> 城市2 (休假3天)
周2: 城市2 (休假3天)
```

**提示：**
- `n == flights.length`
- `n == flights[i].length`
- `n == days.length`
- `k == days[i].length`
- `1 <= n, k <= 100`
- `0 <= flights[i][j] <= 1`
- `0 <= days[i][j] <= 7`
- `flights[i][i] == 0`

## 解题思路

动态规划问题。

状态定义：
- `dp[i][j]` 表示第 j 周在城市 i 能获得的最大休假天数

转移方程：
- `dp[i][week] = max(dp[k][week-1]) + days[i][week]`，其中 k 可以飞到 i

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def maxVacationDays(self, flights: List[List[int]], days: List[List[int]]) -> int:
        """
        动态规划
        
        时间复杂度：O(n^2 * k)
        空间复杂度：O(n * k)
        """
        n, k = len(days), len(days[0])
        
        # dp[i][j] = 第 j 周在城市 i 的最大休假天数
        dp = [[-1] * k for _ in range(n)]
        dp[0][0] = days[0][0]
        
        for week in range(k):
            for city in range(n):
                if week == 0 and city == 0:
                    continue
                
                # 从其他城市飞来
                for prev_city in range(n):
                    if prev_city == city or flights[prev_city][city]:
                        if week == 0:
                            if prev_city == 0:  # 初始在城市0
                                dp[city][week] = max(dp[city][week], days[city][week])
                        else:
                            if dp[prev_city][week - 1] != -1:
                                dp[city][week] = max(
                                    dp[city][week],
                                    dp[prev_city][week - 1] + days[city][week]
                                )
        
        return max(dp[i][k - 1] for i in range(n))
```

### 方法二：空间优化

```python
from typing import List

class Solution:
    def maxVacationDays(self, flights: List[List[int]], days: List[List[int]]) -> int:
        """
        滚动数组优化空间
        
        时间复杂度：O(n^2 * k)
        空间复杂度：O(n)
        """
        n, k = len(days), len(days[0])
        
        prev = [-float('inf')] * n
        prev[0] = 0
        
        for week in range(k):
            curr = [-float('inf')] * n
            for city in range(n):
                for prev_city in range(n):
                    if prev_city == city or flights[prev_city][city]:
                        curr[city] = max(curr[city], prev[prev_city] + days[city][week])
            prev = curr
        
        return max(prev)
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n × k)

**方法二：**
- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n)

## 关键点总结

1. **DP 状态**：`dp[city][week]` 表示该周在该城市的最大休假天数
2. **转移条件**：可以从同一城市或有航班的城市转移
3. **初始状态**：第 0 周在城市 0
4. **空间优化**：只需要前一周的状态
