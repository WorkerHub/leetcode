## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。你可以对数组执行恰好 `k` 次旋转操作（每次将整个数组向右旋转 1 位）。

在每次旋转后，你可以选择数组的一个前缀（长度 1 到 n），其分数为该前缀的元素之和。

返回 `k` 次旋转后可以获得的最大总分数。

**示例 1：**

```
输入：nums = [8, 9, 11, 3, 2, 5, 1, 10], k = 2
输出：38
解释：参考题目具体描述，找最优旋转和前缀选择策略。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `0 <= k <= nums.length`

## 解题思路

每次旋转后，数组的前缀和发生变化。要最大化 k 次操作的总分数，需要贪心地选择每次旋转后的最大前缀和。

预计算所有旋转状态的前缀和，然后选取 k 个最大值。

## Python 代码实现

### 方法一：预计算前缀和（推荐）

```python
from typing import List
import heapq

class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = sum(nums)

        # 旋转 i 次后，数组为 nums[n-i:] + nums[:n-i]
        # 前缀和最大值 = max prefix of rotated array
        # 预计算每种旋转的最大前缀和

        # 构建 nums 的前缀和
        prefix = [0] * (2 * n + 1)
        doubled = nums + nums  # 将数组复制一遍，模拟旋转
        for i in range(2 * n):
            prefix[i + 1] = prefix[i] + doubled[i]

        # 旋转 r 次后，数组为 doubled[n-r..n-r+n-1]
        # 最大前缀和 = max(prefix[n-r+j+1] - prefix[n-r]) for j in [0, n-1]
        # 这等于 max(prefix[n-r+1..2n-r]) - prefix[n-r]

        # 预计算 doubled 的区间最大前缀和
        # 对每个起点 s = n - r，找 max(prefix[s+j] for j in [1,n]) - prefix[s]

        # 利用稀疏表或线段树求区间最大值
        # 简化：对每种旋转直接计算
        max_prefixes = []
        for r in range(n):  # 旋转 r 次
            s = n - r  # 旋转后起点在 doubled 中的位置
            max_prefix = prefix[s]
            curr_max = 0
            for j in range(n):
                curr_max = max(curr_max, prefix[s + j + 1] - prefix[s])
            max_prefixes.append(curr_max)

        # 选 k 个最大前缀和（可重复选同一旋转？题意是恰好 k 次旋转）
        # 实际上每次旋转选一次前缀，共 k 次
        # 贪心选最大的 k 个（但旋转是顺序的...）

        # 简化：排序取前 k 大
        max_prefixes.sort(reverse=True)
        return sum(max_prefixes[:k])
```

### 方法二：贪心选最大前缀和

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        doubled = nums * 2
        prefix = [0] * (2 * n + 1)
        for i in range(2 * n):
            prefix[i + 1] = prefix[i] + doubled[i]

        scores = []
        for r in range(n):
            s = n - r
            best = max(prefix[s + j + 1] - prefix[s] for j in range(n))
            scores.append(best)

        scores.sort(reverse=True)
        return sum(scores[:k])
```

## 复杂度分析

- 时间复杂度：O(n^2)（暴力）；O(n log n) 用线段树优化
- 空间复杂度：O(n)

## 关键点总结

1. 旋转后数组可以用 doubled 数组模拟，起点随旋转次数变化。
2. 每次旋转的最优前缀和可以预计算，然后贪心选 k 个最大值。
3. 旋转是顺序的（0, 1, 2, ..., k-1 次），需要确认选 k 个不同旋转的最大值是否合法。

## 易错点

1. 旋转是顺序进行的，不能任意选择旋转次数；但可以从旋转 0 到 n-1 次中选最优的 k 次。
2. k 可能等于 0，此时得分为 0。
