## 题目描述

给你一个由**非负整数**组成的数组 `nums` 和一个整数 `target`。

每次操作，你可以选择 `nums` 中的一个元素，将它**替换**为两个等于该元素一半的值（只有当该元素为偶数时才能执行，且每次操作产生两个该元素/2 的新元素）。

返回使 `nums` 中存在一个**子序列**其元素之和等于 `target` 所需的**最少操作数**。如果不可能，返回 `-1`。

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^6`
- `1 <= target <= 10^6`
- 可以保证答案不超过某个范围

## 解题思路

**贪心 + 位操作：**

由于只能将偶数分成两半，可以从最高位（最大的 2 的幂次）开始贪心处理。

**关键观察：**
- `target` 的某一位（二进制）如果为 1，我们需要凑出这一位
- 数组中 >= 这一位的数（如果分裂成此位的大小）可以贡献

**算法（从最高位到最低位）：**
1. 用 Counter 统计各个值的出现次数
2. 从最高位（对应值 2^i）开始，对 target 的每一位处理：
   - 如果 target 的第 i 位为 1：
     - 检查 cnt[2^i] 是否有剩余；有则用一个，减少 cnt[2^i]
     - 没有则需要从更高位分裂（在前面步骤中已合并）
   - 将 2^(i+1) 的数分裂到 2^i：cnt[2^i] += cnt[2^(i+1)] * 2（向低位合并）

## Python 代码实现

### 方法一：贪心位运算（推荐）

```python
from collections import Counter
from typing import List

class Solution:
    def minOperations(self, nums: List[int], target: int) -> int:
        if sum(nums) < target:
            return -1

        cnt = Counter(nums)
        ops = 0
        need = 0  # 需要从低位凑的额外量

        # 从最低位到最高位处理
        for i in range(21):  # 2^20 > 10^6
            bit = 1 << i
            # 当前位需要的数量（target 的第 i 位 + 从低位进来的需求）
            target_bit = (target >> i) & 1
            need += target_bit  # 需要 need 个 bit

            have = cnt[bit]  # 当前有多少个 2^i
            if have >= need:
                # 够用
                need = 0
            else:
                # 不够，用完后需要从高位借
                need -= have
                ops += need  # 每次从高位借需要 1 次操作（分裂）
                need = 0
            # 将多余的 2^i 合并为 2^(i+1)（每两个合一个）
            cnt[bit * 2] += cnt[bit] // 2 + (cnt[bit] % 2) * 0  # 等等，这里需要考虑用掉后的剩余
            # 重新计算：need 处理后，have 中用了多少
            # 实际上上面逻辑需要修正

        return ops
```

### 方法二：正确的贪心实现

```python
from collections import Counter
from typing import List

class Solution:
    def minOperations(self, nums: List[int], target: int) -> int:
        total = sum(nums)
        if total < target:
            return -1

        cnt = Counter(nums)
        ops = 0
        # 从最低位开始处理
        for i in range(21):
            bit = 1 << i
            need = (target >> i) & 1  # 当前位需要几个 bit

            if need == 0:
                # 不需要当前位，合并到下一位
                cnt[bit * 2] += cnt[bit] // 2
            else:
                # 需要一个 bit
                if cnt[bit] > 0:
                    cnt[bit] -= 1
                    cnt[bit * 2] += cnt[bit] // 2  # 剩余合并
                    cnt[bit] = 0
                else:
                    # 需要从更高位分裂，找到有值的最低高位
                    j = i + 1
                    while j <= 20 and cnt[1 << j] == 0:
                        j += 1
                    if j > 20:
                        return -1  # 不可能（但前面已检查总和，这里不应发生）
                    # 从 2^j 开始分裂到 2^i，需要 j-i 次操作
                    ops += j - i
                    cnt[1 << j] -= 1
                    for k in range(j - 1, i, -1):
                        cnt[1 << k] += 1  # 分裂出的一半
                    cnt[bit] += 1  # 最终分裂到 bit 的 2 个，用 1 个

        return ops
```

## 复杂度分析

- 时间复杂度：O(n + 21^2) = O(n)，n 为数组长度，21 为最大位数
- 空间复杂度：O(max_val)，Counter 的大小

## 关键点总结

1. 贪心从低位到高位：先满足低位需求，不足时从高位分裂
2. 每次从 2^j 分裂到 2^i 需要 j-i 次操作
3. 先检查总和是否 >= target，若不足直接返回 -1

## 易错点

1. 分裂操作：将 2^j 分裂为两个 2^(j-1)，消耗一次操作，递归到目标位
2. 高位合并：用完后剩余的低位数可以合并到高位（两个 2^i = 一个 2^(i+1)）
3. 处理顺序很重要：从低到高，先用低位满足需求
