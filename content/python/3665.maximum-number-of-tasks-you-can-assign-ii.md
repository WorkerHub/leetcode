## 题目描述

给你若干个任务和工人，`tasks[i]` 表示任务 i 的难度，`workers[j]` 表示工人 j 的能力。每个工人最多完成一个任务，完成任务需要工人能力 >= 任务难度。另外有 `pills` 个药丸，每个药丸可以给一个工人增加 `strength` 点能力。

返回最多能完成的任务数量。

**示例 1：**

```
输入：tasks = [3,2,1], workers = [0,3,3], pills = 1, strength = 1
输出：3
解释：工人1(3)做任务1(3)，工人2(3)做任务2(2)，工人0(0+1)做任务3(1)
```

**提示：**

- `1 <= tasks.length, workers.length <= 5 * 10^4`
- `0 <= pills <= workers.length`
- `0 <= strength <= 10^9`

## 解题思路

**二分答案 + 贪心验证**：

二分能完成的任务数 `mid`。

验证是否能完成最简单的 `mid` 个任务（排序后取最小的 `mid` 个）：
- 取最强的 `mid` 个工人
- 贪心：尽量用能力足够的工人，不够时才用药丸
- 对最难的任务：先用最强的工人，若不够则用最弱的但加药丸的工人

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def maxTaskAssign(self, tasks: List[int], workers: List[int],
                      pills: int, strength: int) -> int:
        tasks.sort()
        workers.sort()
        n, m = len(tasks), len(workers)

        def check(mid: int) -> bool:
            # 尝试完成最简单的 mid 个任务，用最强的 mid 个工人
            p = pills
            worker_pool = SortedList(workers[m - mid:])

            for i in range(mid - 1, -1, -1):  # 从最难任务到最简单
                task = tasks[i]
                # 找能直接完成该任务的最弱工人
                idx = worker_pool.bisect_left(task)
                if idx < len(worker_pool):
                    # 找到合适工人，直接用
                    worker_pool.pop(idx)
                else:
                    # 需要用药丸：找加了药丸后能完成的最弱工人
                    if p == 0:
                        return False
                    idx2 = worker_pool.bisect_left(task - strength)
                    if idx2 >= len(worker_pool):
                        return False
                    worker_pool.pop(idx2)
                    p -= 1

            return True

        lo, hi = 0, min(n, m)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：贪心（无 SortedList）

```python
from typing import List
import bisect

class Solution:
    def maxTaskAssign(self, tasks: List[int], workers: List[int],
                      pills: int, strength: int) -> int:
        tasks.sort()
        workers.sort()
        n, m = len(tasks), len(workers)

        def check(mid):
            p = pills
            wk = sorted(workers[m - mid:])
            for i in range(mid - 1, -1, -1):
                t = tasks[i]
                pos = bisect.bisect_left(wk, t)
                if pos < len(wk):
                    wk.pop(pos)
                else:
                    if p == 0:
                        return False
                    pos2 = bisect.bisect_left(wk, t - strength)
                    if pos2 >= len(wk):
                        return False
                    wk.pop(pos2)
                    p -= 1
            return True

        lo, hi = 0, min(n, m)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- 时间复杂度：O((n + m) log(min(n,m)) * log(min(n,m)))
- 空间复杂度：O(min(n, m))

## 关键点总结

1. 二分最终完成任务数
2. 验证时贪心：对最难任务优先用最强工人，或用药丸加强最弱工人
3. SortedList 提供 O(log n) 的插入删除

## 易错点

1. 药丸只用于不够的情况，优先直接分配
2. 从最难任务开始处理（确保最难任务被完成）
3. 验证用最强的 mid 个工人
