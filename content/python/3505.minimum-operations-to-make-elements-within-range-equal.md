## 题目描述

给定一个整数数组 `nums` 和两个整数 `lower` 和 `upper`。每次操作可以将数组中某个元素增加或减少 `1`。求最少操作次数，使得数组中所有不在 `[lower, upper]` 范围内的元素都变为该范围内的某个值。

**示例 1：**

```
输入：nums = [1, 2, 3, 4, 5], lower = 2, upper = 4
输出：2
解释：将 1 变为 2（1次），将 5 变为 4（1次），共 2 次。
```

**示例 2：**

```
输入：nums = [1, 10], lower = 3, upper = 7
输出：4
解释：将 1 变为 3（2次），将 10 变为 7（3次），共 5 次。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= lower <= upper <= 10^9`

## 解题思路

贪心策略：
- 对于小于 `lower` 的元素，最少操作次数是将其变为 `lower`，代价为 `lower - nums[i]`
- 对于大于 `upper` 的元素，最少操作次数是将其变为 `upper`，代价为 `nums[i] - upper`
- 已在 `[lower, upper]` 范围内的元素无需操作

直接遍历数组，对每个不在范围内的元素计算代价并累加。

## Python 代码实现

### 方法一：直接贪心（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], lower: int, upper: int) -> int:
        total = 0
        for x in nums:
            if x < lower:
                # 需要增加到 lower
                total += lower - x
            elif x > upper:
                # 需要减少到 upper
                total += x - upper
            # 在范围内，不需要操作
        return total
```

### 方法二：使用 max/min 夹紧

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], lower: int, upper: int) -> int:
        # 将每个元素夹紧到 [lower, upper]，代价为偏差量
        return sum(
            max(0, lower - x) + max(0, x - upper)
            for x in nums
        )
```

## 复杂度分析

- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. 每个元素独立处理，贪心地选择代价最小的目标值
2. 小于 `lower` 的元素目标为 `lower`，大于 `upper` 的目标为 `upper`
3. 已在范围内的元素代价为 `0`

## 易错点

1. 注意 `lower` 和 `upper` 都可以作为合法目标值（闭区间）
2. 不要遗漏 `x == lower` 或 `x == upper` 的边界情况（代价为 0）
3. 累加时注意使用 `int` 避免溢出（Python 中无此问题）
