## 题目描述

一个数组的**最小乘积**定义为这个数组中**最小值**与数组**总和**的乘积。

给你一个正整数数组 `nums`，返回最大**最小乘积**，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：nums = [1,2,3,2]
输出：14
解释：子数组 [2,3,2] 的最小值为 2，总和为 7，最小乘积为 14
```

**示例 2：**
```
输入：nums = [2,3,3,1,2]
输出：18
```

## 解题思路

**单调栈 + 前缀和**：

对于每个元素 `nums[i]`，找到以 `nums[i]` 为最小值的最大子数组（即找左右两侧第一个比 `nums[i]` 小的位置 `left[i]` 和 `right[i]`）。

子数组范围为 `(left[i], right[i])`（开区间），子数组总和为 `prefix[right[i]] - prefix[left[i]+1]`。

最小乘积为 `nums[i] * 子数组总和`，取所有情况的最大值。

用**单调递增栈**求每个元素的左右边界（第一个更小值的位置）。

## 代码实现

### 方法一：单调栈 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maxSumMinProduct(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 单调递增栈，求左边界（左侧第一个比当前元素小的位置）
        left = [-1] * n  # left[i] = 左侧第一个比 nums[i] 小的元素的下标
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)

        # 单调递增栈，求右边界
        right = [n] * n  # right[i] = 右侧第一个比 nums[i] 小的元素的下标
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)

        # 计算每个元素作为最小值时的最小乘积
        ans = 0
        for i in range(n):
            l, r = left[i] + 1, right[i]  # 子数组下标范围 [l, r)
            subarray_sum = prefix[r] - prefix[l]
            ans = max(ans, nums[i] * subarray_sum)

        return ans % MOD
```

### 方法二：一次扫描（栈出栈时计算）

```python
from typing import List

class Solution:
    def maxSumMinProduct(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        stack = []  # 单调递增栈（存下标）
        ans = 0
        nums = nums + [0]  # 哨兵，确保所有元素出栈

        for i in range(n + 1):
            while stack and nums[stack[-1]] > nums[i]:
                mid = stack.pop()
                l = stack[-1] + 1 if stack else 0
                r = i
                subarray_sum = prefix[r] - prefix[l]
                ans = max(ans, nums[mid] * subarray_sum)
            stack.append(i)

        return ans % MOD
```

## 复杂度分析

- **时间复杂度**：O(n)，单调栈每个元素入栈出栈各一次
- **空间复杂度**：O(n)，前缀和和栈

## 关键点总结

1. 枚举每个元素作为最小值，找到以其为最小值的最大子数组
2. 单调递增栈求左右边界（第一个严格小的位置）
3. 前缀和快速计算子数组总和
4. 乘积可能超过 long，但 Python 自动处理，最后取模

## 易错点

- 边界处理：左右边界是开区间，子数组范围为 `[left+1, right-1]`（即 `(left, right)` 的开区间）
- 取模操作：ans 计算时不取模（避免取模后大小关系错乱），最后返回时取模
