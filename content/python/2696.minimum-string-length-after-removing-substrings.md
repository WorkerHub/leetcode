## 题目描述

给你一个仅由大写英文字母组成的字符串 `s`，可以重复执行以下操作：选择 `s` 中的子串 `"AB"` 或 `"CD"`，将其删除。

返回执行所有可能删除后，`s` 的最小长度。

**示例 1：**
```
输入：s = "ABFCACDB"
输出：2
解释：删除 AB -> FCACDB -> FCADB -> FCDB（删CD）-> FB，长度2
```

**示例 2：**
```
输入：s = "ACBBD"
输出：5
解释：没有 AB 或 CD 子串，无法删除
```

**数据范围：**
- 1 <= s.length <= 100
- s 只含大写英文字母

## 解题思路

用栈模拟：遍历字符，若当前字符和栈顶形成 "AB" 或 "CD" 则弹出栈顶（删除这一对），否则入栈。最终栈的大小即为剩余长度。

## Python 代码实现

### 方法一：栈模拟（推荐）

```python
class Solution:
    def minLength(self, s: str) -> int:
        stack = []
        for c in s:
            if stack and ((stack[-1] == 'A' and c == 'B') or (stack[-1] == 'C' and c == 'D')):
                stack.pop()  # 删除 AB 或 CD
            else:
                stack.append(c)
        return len(stack)
```

### 方法二：循环替换（暴力）

```python
class Solution:
    def minLength(self, s: str) -> int:
        while 'AB' in s or 'CD' in s:
            s = s.replace('AB', '').replace('CD', '')
        return len(s)
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n^2)（每轮删除后字符串缩短），空间复杂度 O(n)

## 关键点总结

1. 栈模拟：遇到 B 且栈顶为 A，或遇到 D 且栈顶为 C，就弹出
2. 贪心：及时删除，不会错过任何可删除的情况

## 易错点

1. 注意配对是 "AB" 和 "CD"，而非 "BA" 或 "DC"
2. 删除后可能产生新的 "AB" 或 "CD"（栈模拟自动处理）
