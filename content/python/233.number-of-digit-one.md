## 题目描述

给定一个整数 `n`，计算所有小于等于 `n` 的非负整数中数字 `1` 出现的个数。

**示例 1：**
```
输入：n = 13
输出：6
解释：数字 1 出现在以下数字中：1, 10, 11, 12, 13
1 出现的次数为：1 + 1 + 2 + 1 + 1 = 6
```

**示例 2：**
```
输入：n = 0
输出：0
```

**提示：**
- `0 <= n <= 10^9`

## 解题思路

这是一道经典的数学题，需要找到规律来计算数字 1 出现的次数。

**核心思想：按位统计**

对于每一位（个位、十位、百位...），分别统计 1 出现的次数，最后相加。

**以 n = 13 为例，分析十位上 1 出现的次数：**

- 当十位为 1 时：10, 11, 12, 13（4 次）
- 规律：
  - 看十位左边的数字（higher）：0
  - 看当前位数字（cur）：1
  - 看十位右边的数字（lower）：3

**一般规律（以某一位为基准）：**

设当前位是第 i 位（从右往左，从 0 开始），digit = 10^i

1. **当前位数字 cur > 1**：
   - 1 出现次数 = (higher + 1) * digit

2. **当前位数字 cur = 1**：
   - 1 出现次数 = higher * digit + lower + 1

3. **当前位数字 cur = 0**：
   - 1 出现次数 = higher * digit

**举例说明（n = 3141）：**

- 个位（i=0, digit=1）：cur=1, higher=314, lower=0
  - 公式：314 * 1 + 0 + 1 = 315

- 十位（i=1, digit=10）：cur=4, higher=31, lower=1
  - 公式：(31 + 1) * 10 = 320

- 百位（i=2, digit=100）：cur=1, higher=3, lower=41
  - 公式：3 * 100 + 41 + 1 = 342

- 千位（i=3, digit=1000）：cur=3, higher=0, lower=141
  - 公式：(0 + 1) * 1000 = 1000

总计：315 + 320 + 342 + 1000 = 1977

## Python 代码实现

### 方法一：数学规律（推荐）⭐

```python
class Solution:
    def countDigitOne(self, n: int) -> int:
        """
        按位统计法：对每一位分别计算 1 出现的次数
        """
        if n <= 0:
            return 0
        
        count = 0
        digit = 1  # 当前位的权重（1, 10, 100, 1000...）
        
        while digit <= n:
            # 计算当前位左边的数字
            higher = n // (digit * 10)
            # 计算当前位的数字
            cur = (n // digit) % 10
            # 计算当前位右边的数字
            lower = n % digit
            
            # 根据当前位的数字分三种情况
            if cur == 0:
                # 当前位为 0，1 的个数由高位决定
                count += higher * digit
            elif cur == 1:
                # 当前位为 1，1 的个数由高位和低位共同决定
                count += higher * digit + lower + 1
            else:
                # 当前位大于 1，1 的个数由高位决定，需要加上当前轮次
                count += (higher + 1) * digit
            
            # 移动到下一位
            digit *= 10
        
        return count
```

### 方法二：递归实现

```python
class Solution:
    def countDigitOne(self, n: int) -> int:
        """
        递归方法：将问题分解为更小的子问题
        """
        if n <= 0:
            return 0
        if n < 10:
            return 1
        
        # 获取 n 的位数
        num_str = str(n)
        length = len(num_str)
        
        # 获取最高位数字
        highest = int(num_str[0])
        # 最高位的权重
        power = 10 ** (length - 1)
        # 除去最高位后的数字
        rest = n - highest * power
        
        # 计算最高位为 1 的个数
        if highest == 1:
            # 最高位为 1：0001 到 1xxx，共 rest + 1 个
            highest_count = rest + 1
        else:
            # 最高位大于 1：0001 到 0999，共 power 个
            highest_count = power
        
        # 其他位为 1 的个数（递归计算）
        # 从 0 到 power-1 的所有数字中 1 的个数
        other_count = self.countDigitOne(power - 1) * highest
        
        # 递归计算 rest 部分
        rest_count = self.countDigitOne(rest)
        
        return highest_count + other_count + rest_count
```

### 方法三：暴力法（仅用于理解，不推荐）

```python
class Solution:
    def countDigitOne(self, n: int) -> int:
        """
        暴力方法：遍历所有数字，统计 1 的个数
        时间复杂度：O(n * log n)，会超时
        """
        count = 0
        for i in range(1, n + 1):
            # 统计 i 中 1 的个数
            num = i
            while num > 0:
                if num % 10 == 1:
                    count += 1
                num //= 10
        return count
```

### 方法四：简化版（使用字符串统计）

```python
class Solution:
    def countDigitOne(self, n: int) -> int:
        """
        简化版：通过字符串统计（仅用于小规模数据）
        """
        if n <= 0:
            return 0
        
        # 将所有数字转为字符串并拼接
        all_digits = ''.join(str(i) for i in range(1, n + 1))
        # 统计字符 '1' 的个数
        return all_digits.count('1')
```

## 复杂度分析

**方法一（数学规律）：**
- 时间复杂度：O(log n)，需要遍历 n 的每一位
- 空间复杂度：O(1)

**方法二（递归）：**
- 时间复杂度：O((log n)^2)
- 空间复杂度：O(log n)，递归栈的深度

**方法三（暴力法）：**
- 时间复杂度：O(n * log n)，会超时
- 空间复杂度：O(1)

## 关键点总结

1. **按位统计**：对每一位分别计算，避免重复统计
2. **分三种情况**：当前位为 0、1、>1 时，公式不同
3. **数学规律**：higher、cur、lower 的含义和计算方法
4. **避免暴力**：O(n) 的方法会超时，必须用数学方法优化到 O(log n)
5. **边界处理**：n = 0 时返回 0

## 易错点

1. **公式记错**：
   ```python
   # cur = 0：count += higher * digit
   # cur = 1：count += higher * digit + lower + 1
   # cur > 1：count += (higher + 1) * digit
   ```

2. **边界条件**：n = 0 时应返回 0

3. **整数溢出**：Python 不会溢出，但其他语言需要注意

4. **位权计算错误**：digit 应该是 1, 10, 100, 1000...

5. **lower 的计算**：`lower = n % digit` 不是 `n % 10`
