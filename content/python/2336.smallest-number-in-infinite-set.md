## 题目描述

现有一个包含所有正整数的集合 `[1, 2, 3, 4, 5, ...]`，实现 `SmallestInfiniteSet` 类：

- `SmallestInfiniteSet()`：初始化 SmallestInfiniteSet 对象，包含所有正整数。
- `int popSmallest()`：移除并返回集合中的最小整数。
- `void addBack(int num)`：将一个正整数 `num` 添加回集合（若集合中已存在，则不进行任何操作）。

**示例：**
```
["SmallestInfiniteSet", "addBack", "popSmallest", "popSmallest", "popSmallest", "addBack", "popSmallest", "popSmallest", "popSmallest"]
[[], [2], [], [], [], [1], [], [], []]
输出：[null, null, 1, 2, 3, null, 1, 4, 5]
```

**提示：**
- `1 <= num <= 1000`
- 最多调用 `popSmallest` 和 `addBack` 各 `1000` 次

## 解题思路

维护一个**当前未被取出的最小值 `cur`**（初始为 1），以及一个**已被添加回来的数的集合**（用最小堆+哈希表维护）。

- `popSmallest`：若小堆非空且堆顶 < cur，返回堆顶；否则返回 cur 并 cur++。
- `addBack`：若 num < cur 且不在已添加集合中，加入小堆和集合。

## 代码实现

### 方法一：最小堆 + 指针（推荐）

```python
import heapq

class SmallestInfiniteSet:
    def __init__(self):
        self.cur = 1          # 当前连续最小值
        self.added_back = []  # 已添加回来的数（最小堆）
        self.added_set = set() # 避免重复添加

    def popSmallest(self) -> int:
        # 若有被添加回来且比 cur 小的数
        if self.added_back and self.added_back[0] < self.cur:
            val = heapq.heappop(self.added_back)
            self.added_set.remove(val)
            return val
        # 否则取 cur
        val = self.cur
        self.cur += 1
        return val

    def addBack(self, num: int) -> None:
        # 只有 num < cur 且不在集合中才需要添加
        if num < self.cur and num not in self.added_set:
            heapq.heappush(self.added_back, num)
            self.added_set.add(num)
```

### 方法二：有序集合（SortedList）

```python
from sortedcontainers import SortedList

class SmallestInfiniteSet:
    def __init__(self):
        self.cur = 1
        self.back = SortedList()
        self.back_set = set()

    def popSmallest(self) -> int:
        if self.back and self.back[0] < self.cur:
            val = self.back.pop(0)
            self.back_set.remove(val)
            return val
        val = self.cur
        self.cur += 1
        return val

    def addBack(self, num: int) -> None:
        if num < self.cur and num not in self.back_set:
            self.back.add(num)
            self.back_set.add(num)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最小堆 | popSmallest O(log n)，addBack O(log n) | O(n) |

## 关键点总结

1. 用指针 `cur` 表示"未被取出的连续正整数从哪里开始"。
2. 用最小堆存放被添加回来的数（都 < cur）。
3. `popSmallest` 优先从堆中取，堆为空或堆顶 >= cur 时取 cur。

## 易错点

- `addBack(num)` 只对 num < cur 的情况有意义（num >= cur 意味着它还在无限集中）。
- 用哈希集合避免重复加入堆。
