## 题目描述

有 `n` 个网络节点，标记为 `1` 到 `n`。

给你一个列表 `times`，表示信号经过有向边的传递时间。`times[i] = (ui, vi, wi)`，其中 `ui` 是源节点，`vi` 是目标节点，`wi` 是一个信号从源节点传递到目标节点的时间。

现在，从某个节点 `k` 发出一个信号。需要多久才能使所有节点都收到信号？如果不能使所有节点收到信号，返回 `-1`。

**示例 1：**
```
输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2
```

**示例 2：**
```
输入：times = [[1,2,1]], n = 2, k = 1
输出：1
```

**示例 3：**
```
输入：times = [[1,2,1]], n = 2, k = 2
输出：-1
```

**提示：**
- `1 <= k <= n <= 100`
- `1 <= times.length <= 6000`
- `times[i].length == 3`
- `1 <= ui, vi <= n`
- `ui != vi`
- `0 <= wi <= 100`
- 所有 `(ui, vi)` 对都互不相同（即，不含重复边）

## 解题思路

这是一道经典的**单源最短路径**问题，可以使用 Dijkstra 算法求解。

**核心思想：**
1. 从节点 `k` 开始，计算到所有其他节点的最短距离
2. 所有节点都收到信号的时间 = 到达最远节点的最短距离
3. 如果有节点无法到达，返回 -1

**Dijkstra 算法流程：**
1. 初始化距离数组，起点距离为 0，其他为无穷大
2. 使用优先队列（最小堆）存储 `(距离, 节点)`
3. 每次取出距离最小的节点，更新其邻居的距离
4. 重复直到队列为空

## Python 代码实现

### 方法一：Dijkstra 算法 + 最小堆（推荐）⭐

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        # 构建邻接表：graph[u] = [(v, w), ...]
        graph = defaultdict(list)
        for u, v, w in times:
            graph[u].append((v, w))
        
        # 距离数组，初始化为无穷大
        dist = {i: float('inf') for i in range(1, n + 1)}
        dist[k] = 0  # 起点距离为 0
        
        # 最小堆：(距离, 节点)
        heap = [(0, k)]
        
        while heap:
            # 取出当前距离最小的节点
            curr_dist, u = heapq.heappop(heap)
            
            # 如果当前距离大于已记录的距离，跳过
            if curr_dist > dist[u]:
                continue
            
            # 遍历所有邻居
            for v, w in graph[u]:
                # 计算通过 u 到达 v 的距离
                new_dist = curr_dist + w
                
                # 如果找到更短的路径，更新距离并加入堆
                if new_dist < dist[v]:
                    dist[v] = new_dist
                    heapq.heappush(heap, (new_dist, v))
        
        # 找到所有节点中的最大距离
        max_dist = max(dist.values())
        
        # 如果有节点无法到达，返回 -1
        return max_dist if max_dist < float('inf') else -1
```

### 方法二：Bellman-Ford 算法

```python
class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        # 初始化距离数组
        dist = [float('inf')] * (n + 1)
        dist[k] = 0
        
        # 松弛操作，进行 n-1 轮
        for _ in range(n - 1):
            for u, v, w in times:
                # 如果通过 u 到 v 的距离更短，更新
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
        
        # 找到最大距离
        max_dist = max(dist[1:])
        
        return max_dist if max_dist < float('inf') else -1
```

### 方法三：DFS + 记忆化（适合理解）

```python
class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v, w in times:
            graph[u].append((v, w))
        
        # 记录到每个节点的最短距离
        dist = {}
        
        def dfs(node, elapsed):
            """DFS 遍历，更新最短距离"""
            # 如果已经访问过且当前时间不优于已记录时间，剪枝
            if node in dist and dist[node] <= elapsed:
                return
            
            # 更新最短距离
            dist[node] = elapsed
            
            # 遍历所有邻居
            for neighbor, time in sorted(graph[node], key=lambda x: x[1]):
                dfs(neighbor, elapsed + time)
        
        dfs(k, 0)
        
        # 检查是否所有节点都访问到
        if len(dist) != n:
            return -1
        
        return max(dist.values())
```

## 复杂度分析

### Dijkstra 算法（方法一）
- **时间复杂度**：O(E log V)，其中 E 是边数，V 是节点数
  - 每条边最多被访问一次
  - 堆操作的时间复杂度为 O(log V)
- **空间复杂度**：O(V + E)
  - 邻接表存储需要 O(E)
  - 堆和距离数组需要 O(V)

### Bellman-Ford 算法（方法二）
- **时间复杂度**：O(V × E)
- **空间复杂度**：O(V)

### DFS（方法三）
- **时间复杂度**：O(V^V)，最坏情况
- **空间复杂度**：O(V)

## 关键点总结

1. **Dijkstra 算法适用于无负权边的图**：本题所有边权重为正，适合使用 Dijkstra
2. **最小堆优化**：使用堆可以高效地找到当前距离最小的节点
3. **结果判断**：最大距离即为答案，如果有无穷大则说明有节点不可达
4. **邻接表存储**：使用 defaultdict(list) 方便构建图结构

## 易错点

1. **节点编号从 1 开始**：注意数组索引的处理
2. **重复访问优化**：在 Dijkstra 中，如果当前距离大于已记录距离，需要跳过
3. **无法到达的判断**：检查是否所有节点都被访问到
4. **边的方向**：这是有向图，`(u, v)` 只能从 u 到 v

## 图解示例

以示例 1 为例：`times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2`

```
初始状态：dist = {1: ∞, 2: 0, 3: ∞, 4: ∞}

第1步：从节点 2 出发
  - 2 -> 1，距离 1，更新 dist[1] = 1
  - 2 -> 3，距离 1，更新 dist[3] = 1

第2步：从节点 1 出发（距离 1）
  - 无出边

第3步：从节点 3 出发（距离 1）
  - 3 -> 4，距离 1，更新 dist[4] = 2

最终：dist = {1: 1, 2: 0, 3: 1, 4: 2}
答案：max(dist.values()) = 2
```
