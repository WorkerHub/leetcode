## 题目描述

给你两个**正整数** `startPos` 和 `endPos`，表示在无限整数线上的起始位置和终止位置。另给你一个正整数 `k`。

每一步，你可以向左或向右移动一个位置。

返回从 `startPos` 出发，恰好移动 `k` 步到达 `endPos` 的**不同移动方式数**。由于答案可能很大，返回对 `10^9 + 7` 取模后的结果。

注意：`startPos` 到 `endPos` 可以在两个方向上任意移动。

**示例 1：**
```
输入：startPos = 1, endPos = 2, k = 3
输出：3
解释：从 1 到 2，距离 1，共走 3 步。向右 2 次向左 1 次：C(3,1) = 3 种。
```

**示例 2：**
```
输入：startPos = 2, endPos = 5, k = 10
输出：0
```

**提示：**
- `1 <= startPos, endPos, k <= 1000`

## 解题思路

**组合数学：**

设距离 `d = |endPos - startPos|`。

- 若 `k < d` 或 `(k - d) % 2 != 0`，无法到达，返回 0。
- 否则，设向正方向走 `r` 步，负方向走 `l` 步，则：
  - `r - l = d`（净位移）
  - `r + l = k`（总步数）
  - 解得 `r = (k + d) / 2`，`l = (k - d) / 2`
- 答案 = `C(k, r)`（从 k 步中选 r 步向正方向走）。

## 代码实现

### 方法一：组合数（推荐）

```python
from math import comb

class Solution:
    def numberOfWays(self, startPos: int, endPos: int, k: int) -> int:
        MOD = 10**9 + 7
        d = abs(endPos - startPos)
        
        # 无法到达的两种情况
        if d > k or (k - d) % 2 != 0:
            return 0
        
        # 向正方向走 r 步，向负方向走 k-r 步
        r = (k + d) // 2
        
        # 答案为 C(k, r) mod MOD
        return comb(k, r) % MOD
```

### 方法二：动态规划

```python
class Solution:
    def numberOfWays(self, startPos: int, endPos: int, k: int) -> int:
        MOD = 10**9 + 7
        d = abs(endPos - startPos)
        
        if d > k or (k - d) % 2 != 0:
            return 0
        
        # dp[i][j] = 从 startPos 走 i 步，位移量为 j 的方案数
        # 但可以简化为 Pascal 三角（杨辉三角）计算 C(k, r)
        
        # 手动计算组合数（避免直接用 comb 的模运算不准确）
        r = (k + d) // 2
        
        # 用 dp 计算 C(k, r) mod MOD
        # C(k, r) = C(k-1, r-1) + C(k-1, r)
        dp = [[0] * (k + 1) for _ in range(k + 1)]
        dp[0][0] = 1
        for i in range(1, k + 1):
            dp[i][0] = 1
            for j in range(1, i + 1):
                dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j]) % MOD
        
        return dp[k][r]
```

### 方法三：递推计算组合数（空间优化）

```python
class Solution:
    def numberOfWays(self, startPos: int, endPos: int, k: int) -> int:
        MOD = 10**9 + 7
        d = abs(endPos - startPos)
        
        if d > k or (k - d) % 2 != 0:
            return 0
        
        r = (k + d) // 2
        
        # 计算 C(k, r) mod MOD（用逐步递推）
        result = 1
        for i in range(min(r, k - r)):
            result = result * (k - i) // (i + 1)
        
        return result % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 组合数 | O(k) | O(1) |
| 动态规划 | O(k^2) | O(k^2) |
| 逐步递推 | O(min(r, k-r)) | O(1) |

## 关键点总结

1. 净位移 `d`，总步数 `k`：若 `(k - d)` 为奇数或 `d > k`，无解。
2. 正方向步数 `r = (k + d) / 2`，负方向步数 `k - r`。
3. 答案 = `C(k, r) mod (10^9 + 7)`。

## 易错点

- `(k - d) % 2 != 0`：奇偶性不同无法到达（每步改变奇偶性）。
- 注意取模：`comb(k, r) % MOD`，Python 的 `comb` 不自动取模。
- 逐步递推计算 `C(k, r)` 时，需先整除再取模，防止中间结果误差。
