## 题目描述

一条走廊上有一些座位（`'S'`）和植物（`'P'`）。你需要在走廊中安装一些隔板，将走廊分成若干段，使每段恰好有**两把椅子**。

隔板只能安装在两个相邻空间之间（椅子或植物均可作为分隔点），且不能在走廊端点处安装。

返回有多少种不同的安装隔板方式，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：corridor = "SSPPSPS"
输出：3
```

**示例 2：**
```
输入：corridor = "PPSPSP"
输出：1
```

**提示：**
- `1 <= corridor.length <= 10^5`

## 解题思路

**数学 + 统计座位位置**

首先，如果座位总数为奇数或为 0，则无法分割，返回 0。

记录所有 'S' 的位置。每两个座位为一组（第 1-2 个、第 3-4 个、...），隔板必须安装在第 2k 个座位和第 2k+1 个座位之间（即每组的最后一个座位和下一组的第一个座位之间）。

在第 2k 个座位（下标 `pos[2k-1]`）和第 2k+1 个座位（下标 `pos[2k]`）之间，有 `pos[2k] - pos[2k-1]` 个位置可以安装隔板（每个间隙都是一个位置）。

所有组间隙的位置数相乘即为总方案数。

## 代码实现

### 方法一：数学乘积（推荐）

```python
class Solution:
    def numberOfWays(self, corridor: str) -> int:
        MOD = 10 ** 9 + 7
        # 收集所有座位的位置
        seats = [i for i, c in enumerate(corridor) if c == 'S']
        n = len(seats)

        # 座位数为奇数或 0，无法分割
        if n == 0 or n % 2 == 1:
            return 0

        ans = 1
        # 每对座位之间的组间隙
        for i in range(1, n // 2):
            # 第 2i-1 和第 2i 个座位之间的间隙数
            gap = seats[2 * i] - seats[2 * i - 1]
            ans = ans * gap % MOD

        return ans
```

### 方法二：DP 方法

```python
class Solution:
    def numberOfWays(self, corridor: str) -> int:
        MOD = 10 ** 9 + 7
        seats = [i for i, c in enumerate(corridor) if c == 'S']
        n = len(seats)

        if n == 0 or n % 2 != 0:
            return 0

        # dp[i] = 前 i 对座位的分割方案数
        result = 1
        for k in range(1, n // 2):
            # 第 2k 个和第 2k+1 个座位之间的间隙
            result = result * (seats[2*k] - seats[2*k - 1]) % MOD

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学乘积 | O(n) | O(n) |

## 关键点总结

1. 每段恰好包含 2 把椅子，因此总椅子数必须为偶数。
2. 隔板必须放在第 2k 和第 2k+1 把椅子之间（`k = 1, 2, ...`）。
3. 每个间隙有多种放置位置，乘法原理得到总方案数。

## 易错点

- 座位总数为 0 或奇数时返回 0。
- 间隙 = 相邻两个座位的下标之差（就是可安装隔板的位置数）。
