## 题目描述

给你一个数组 `nums`，每次操作可以将 `nums` 中任一元素更改为任意值。

在每次操作之后，数组中每个数字都必须是唯一的。

请你返回执行最多 3 次操作后，数组中最大值与最小值的差的最小值。

**示例 1：**
```
输入：nums = [5,3,2,4]
输出：0
解释：将 3 和 4 改成 2 和 5，或者改成其他，可以使最大最小值相等。
```

**示例 2：**
```
输入：nums = [1,5,0,10,14]
输出：1
解释：将 5 和 10 改成 1 和 14，最小值 0，最大值 14，差为 1。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

### 贪心策略

排序后，最大值和最小值分别在两端。最多 3 次操作，可以改变至多 3 个端点的值（把它们变成另一端的值，使它们不再是极值）。

有 4 种删除方案：
1. 从左边删 3 个（修改最小的 3 个）：差值 = `nums[n-1] - nums[3]`
2. 从左边删 2 个，右边删 1 个：差值 = `nums[n-2] - nums[2]`
3. 从左边删 1 个，右边删 2 个：差值 = `nums[n-3] - nums[1]`
4. 从右边删 3 个（修改最大的 3 个）：差值 = `nums[n-4] - nums[0]`

取这 4 种方案中的最小值。

**注意：** 若 `n <= 4`，则可以把所有极值都改掉，直接返回 0。

## 代码实现

### 方法一：排序 + 枚举四种方案（推荐）

```python
from typing import List

class Solution:
    def minDifference(self, nums: List[int]) -> int:
        n = len(nums)
        # 若元素不超过 4 个，3 次操作可以全部改掉
        if n <= 4:
            return 0
        nums.sort()
        # 四种方案：从左删 i 个，从右删 (3-i) 个
        ans = float('inf')
        for i in range(4):
            # 保留的最小值是 nums[i]，最大值是 nums[n-1-(3-i)] = nums[n-4+i]
            ans = min(ans, nums[n-4+i] - nums[i])
        return ans
```

### 方法二：明确列出四种情况

```python
from typing import List

class Solution:
    def minDifference(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 4:
            return 0
        nums.sort()
        # 方案1：改最小3个 → 区间 [nums[3], nums[n-1]]
        opt1 = nums[n-1] - nums[3]
        # 方案2：改最小2个 + 最大1个 → 区间 [nums[2], nums[n-2]]
        opt2 = nums[n-2] - nums[2]
        # 方案3：改最小1个 + 最大2个 → 区间 [nums[1], nums[n-3]]
        opt3 = nums[n-3] - nums[1]
        # 方案4：改最大3个 → 区间 [nums[0], nums[n-4]]
        opt4 = nums[n-4] - nums[0]
        return min(opt1, opt2, opt3, opt4)
```

## 复杂度分析

- **时间复杂度**：O(N log N)，主要是排序
- **空间复杂度**：O(1)，不计排序内部空间

## 关键点总结

1. 3 次操作可以"消除"两端共 3 个极值
2. 排序后只需枚举 4 种分配方式（左删几个，右删几个）
3. `n <= 4` 时，直接返回 0
4. 答案只与最终保留区间的两端点之差有关

## 易错点

- 忘记 `n <= 4` 的特判
- 错误理解"可以修改任意值"——改成什么值不重要，只关心保留哪些元素
