## 题目描述

设计一个三维二进制矩阵类 `Matrix3D`，支持以下操作：

- `Matrix3D(int n)`：初始化 `n x n x n` 的三维矩阵，所有元素为 0。
- `void setCell(int x, int y, int z)`：将 `(x, y, z)` 处的值设为 1。
- `void unsetCell(int x, int y, int z)`：将 `(x, y, z)` 处的值设为 0。
- `int largestMatrix()`：返回 1 的数量最多的"层"（layer）的索引。

每个"层"是固定 `x` 坐标的 `n x n` 切片，若有多个层的 1 数量相同，返回最大的 `x` 索引。

**提示：**
- `1 <= n <= 100`
- 调用次数不超过 `10^5`

## 解题思路

**按层维护计数 + 有序集合：**

核心是高效维护每层（固定 `x` 的切面）中 1 的数量，并快速找到 1 最多的层。

- 维护 `layer_count[x]`：第 `x` 层中 1 的数量
- 维护一个有序集合（或用最大堆），支持找到计数最大的层（相同计数取 x 最大）
- `setCell`：若 `(x,y,z)` 当前为 0，则 `layer_count[x] += 1`
- `unsetCell`：若 `(x,y,z)` 当前为 1，则 `layer_count[x] -= 1`
- `largestMatrix`：返回 `layer_count[x]` 最大的 `x`（相同取最大 x）

用 Python 的 `SortedList` 或直接遍历（n <= 100 时 O(n) 足够）。

## Python 代码实现

### 方法一：层计数 + 线性查找（推荐，n <= 100 时高效）

```python
class Matrix3D:

    def __init__(self, n: int):
        self.n = n
        # 三维矩阵
        self.matrix = [[[0] * n for _ in range(n)] for _ in range(n)]
        # 每层（固定 x）的 1 计数
        self.layer_count = [0] * n

    def setCell(self, x: int, y: int, z: int) -> None:
        if self.matrix[x][y][z] == 0:
            self.matrix[x][y][z] = 1
            self.layer_count[x] += 1

    def unsetCell(self, x: int, y: int, z: int) -> None:
        if self.matrix[x][y][z] == 1:
            self.matrix[x][y][z] = 0
            self.layer_count[x] -= 1

    def largestMatrix(self) -> int:
        # 找 1 最多的层，相同时取最大 x
        best_x = 0
        best_count = -1
        for x in range(self.n):
            if self.layer_count[x] >= best_count:
                best_count = self.layer_count[x]
                best_x = x
        return best_x
```

### 方法二：使用 SortedList 维护有序结构（调用频繁时更快）

```python
from sortedcontainers import SortedList

class Matrix3D:

    def __init__(self, n: int):
        self.n = n
        self.matrix = [[[0] * n for _ in range(n)] for _ in range(n)]
        self.layer_count = [0] * n
        # 有序集合存储 (count, x)，支持 O(log n) 查最大
        # 用 (-count, -x) 使得最大 count 和最大 x 排在最前
        self.sl = SortedList((-0, -x) for x in range(n))

    def setCell(self, x: int, y: int, z: int) -> None:
        if self.matrix[x][y][z] == 0:
            self.matrix[x][y][z] = 1
            # 更新有序集合
            old_count = self.layer_count[x]
            self.sl.remove((-old_count, -x))
            self.layer_count[x] += 1
            self.sl.add((-(old_count + 1), -x))

    def unsetCell(self, x: int, y: int, z: int) -> None:
        if self.matrix[x][y][z] == 1:
            self.matrix[x][y][z] = 0
            old_count = self.layer_count[x]
            self.sl.remove((-old_count, -x))
            self.layer_count[x] -= 1
            self.sl.add((-(old_count - 1), -x))

    def largestMatrix(self) -> int:
        # 最小的 (-count, -x) 对应最大的 count 和最大的 x
        neg_count, neg_x = self.sl[0]
        return -neg_x
```

## 复杂度分析

**方法一：**
- `setCell` / `unsetCell`：O(1)
- `largestMatrix`：O(n)

**方法二：**
- `setCell` / `unsetCell`：O(log n)
- `largestMatrix`：O(1)

## 关键点总结

1. "层"是固定 `x` 坐标的切面，维护每层的 1 计数是核心。
2. 更新时先判断是否需要修改（避免重复操作）。
3. 相同计数取最大 x：遍历时用 `>=` 更新（而非 `>`）。

## 易错点

1. `setCell` 时若该位置已经是 1，不应重复计数。
2. 相同计数时返回**最大**的 x，遍历时需要注意方向或比较符号。
3. `largestMatrix` 要返回层的 x 索引（0-indexed）。
