## 题目描述

给你一个整数数组 `nums` 和两个整数 `x`、`y`。每次操作可以选择数组中的一个元素，将其加 1 或减 1，费用为 1。你还可以以费用 `x` 将所有元素加 1，以费用 `y` 将所有元素减 1。

请问将数组所有元素变为相同值的最小费用是多少？

**示例 1：**

```
输入：nums = [1,3,5,3], x = 2, y = 1
输出：4
解释：目标值为 3，将 1 变为 3 花费 2，将 5 变为 3 花费 2，总费用 4
```

**示例 2：**

```
输入：nums = [2,2,2], x = 5, y = 3
输出：0
解释：所有元素已相同
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= x, y <= 10^6`

## 解题思路

枚举目标值，计算将所有元素变为该值的最小费用。

对于每个元素，将其变为目标值 `t`：
- 若 `nums[i] < t`，需增加 `t - nums[i]`，单步费用为 1，或用全局加操作（费用 x）
- 若 `nums[i] > t`，需减少 `nums[i] - t`，单步费用为 1，或用全局减操作（费用 y）

注意：全局操作会影响所有元素，实际上应对每个差值取最小单步费用（个体 vs 全局均摊）。

枚举的目标值范围为 `[min(nums), max(nums)]`，可以利用排序和前缀和优化。

## Python 代码实现

### 方法一：排序 + 前缀和枚举（推荐）

```python
from typing import List

class Solution:
    def minCost(self, nums: List[int], x: int, y: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = float('inf')
        for i in range(n):
            t = nums[i]  # 目标值枚举数组中每个值
            # 小于 t 的元素需要增加
            left_count = i  # nums[0..i-1] 都 < t
            left_sum = prefix[i]
            cost_up = t * left_count - left_sum  # 逐个增加费用

            # 大于 t 的元素需要减少
            right_count = n - i - 1  # nums[i+1..n-1] 都 > t
            right_sum = prefix[n] - prefix[i + 1]
            cost_down = right_sum - t * right_count  # 逐个减少费用

            ans = min(ans, cost_up + cost_down)

        return ans
```

### 方法二：哈希表 + 枚举（含全局操作）

```python
from typing import List
from collections import Counter

class Solution:
    def minCost(self, nums: List[int], x: int, y: int) -> int:
        # 每步操作费用取 min(1, 全局均摊)
        # 全局操作实际上是 x 或 y 除以 n 的均摊
        # 简化：若 x < n 则用全局加更优，否则逐个加
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 单步增加费用：min(1, x/n) 近似为 1（整数情形精确计算）
        unit_up = min(1, x)    # 每增加1的有效费用
        unit_down = min(1, y)  # 每减少1的有效费用

        ans = float('inf')
        for i in range(n):
            t = nums[i]
            left_sum = prefix[i]
            left_count = i
            right_sum = prefix[n] - prefix[i + 1]
            right_count = n - i - 1

            cost = (t * left_count - left_sum) * unit_up + \
                   (right_sum - t * right_count) * unit_down
            ans = min(ans, cost)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主要开销
- 空间复杂度：O(n)，存储前缀和

## 关键点总结

1. 最优目标值一定在数组元素中（中位数附近最优）
2. 前缀和快速计算区间总增/减量
3. 排序后枚举每个值作为目标值
4. 全局操作的均摊效果需结合数组大小判断

## 易错点

1. 目标值不必是数组中的值，但对整数数组而言枚举数组值是充分的
2. 前缀和下标偏移：`prefix[i]` 表示前 `i` 个元素之和
3. 全局操作费用 `x`、`y` 是每次整体移动的费用，而非每步均摊
