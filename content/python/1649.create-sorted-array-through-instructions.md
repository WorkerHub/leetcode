## 题目描述

给你一个整数数组 `instructions`，你需要根据以下规则来创建一个有序数组：

- 从左到右遍历 `instructions`，将当前元素插入有序数组中
- 插入元素 `x` 的代价为：`min(严格小于 x 的元素个数, 严格大于 x 的元素个数)`
- 返回所有插入代价之和（结果对 `10^9 + 7` 取余）

**示例：**
```
输入：instructions = [1,5,6,4,1,5]
输出：10
```

## 解题思路

核心问题：对于每个新插入的元素 x，快速查询当前数组中**严格小于 x 的数量**和**严格大于 x 的数量**。

**方法一：树状数组（BIT）**：维护每个数值的出现次数，前缀和查询 < x 和 > x 的个数。

**方法二：归并排序**：利用归并排序统计逆序数（类似 315 题）。

## 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List

class BIT:
    """树状数组（Binary Indexed Tree）"""
    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (n + 1)
    
    def update(self, i: int, delta: int = 1):
        """将位置 i 的值增加 delta"""
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)
    
    def query(self, i: int) -> int:
        """查询前缀和 [1, i]"""
        res = 0
        while i > 0:
            res += self.tree[i]
            i -= i & (-i)
        return res

class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        MOD = 10 ** 9 + 7
        max_val = max(instructions)
        bit = BIT(max_val)
        
        total_cost = 0
        
        for idx, x in enumerate(instructions):
            # 严格小于 x 的数量
            less = bit.query(x - 1) if x > 1 else 0
            # 严格大于 x 的数量 = 当前插入数 - 小于等于 x 的数量
            greater = idx - bit.query(x)
            
            total_cost = (total_cost + min(less, greater)) % MOD
            bit.update(x)
        
        return total_cost
```

### 方法二：SortedList（Python 特有，简洁但较慢）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        MOD = 10 ** 9 + 7
        sl = SortedList()
        total_cost = 0
        
        for x in instructions:
            # 严格小于 x 的数量
            less = sl.bisect_left(x)
            # 严格大于 x 的数量
            greater = len(sl) - sl.bisect_right(x)
            
            total_cost = (total_cost + min(less, greater)) % MOD
            sl.add(x)
        
        return total_cost
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 树状数组 | O(n log M) | O(M) |
| SortedList | O(n log n) | O(n) |

M 为最大值（最大 10^5），n 为数组长度。

## 关键点总结

1. 树状数组支持 O(log M) 的单点更新和前缀和查询
2. 严格小于 x：`query(x-1)`
3. 严格大于 x：`idx - query(x)`（当前已插入 idx 个元素，减去 <= x 的数量）
4. 每次插入后更新树状数组

## 易错点

- 树状数组的下标从 1 开始（需要坐标转换）
- 严格小于：`query(x-1)`，不是 `query(x)`
- 严格大于：`idx - query(x)`，其中 `idx` 是当前已处理的元素数（0-based 时是当前下标）
