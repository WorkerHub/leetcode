## 题目描述

给定一个由 `'0'` 和 `'1'` 组成的二进制字符串 `s`，以及若干查询。每个查询给出区间 `[l, r]`，你可以在该区间内执行一次"交换操作"：将某段连续的 `'1'` 替换为 `'0'`，并将相邻的某段连续的 `'0'` 替换为 `'1'`（即把一个 `'1'` 块和一个 `'0'` 块对调）。求每次查询后字符串中 `'1'` 的最大连续段长度。

**示例 1：**

```
输入：s = "01", queries = [[0,1]]
输出：[1]
```

**示例 2：**

```
输入：s = "0110", queries = [[0,3]]
输出：[3]
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `0 <= l <= r < s.length`

## 解题思路

核心思路是预处理字符串中所有连续 `'1'` 段和 `'0'` 段的信息，然后对每个查询在区间 `[l, r]` 内枚举相邻的两个 `'1'` 块合并（通过中间 `'0'` 块的交换）能得到的最大长度。

关键观察：
1. 一次交换可以把某个 `'1'` 块"移动"到相邻 `'0'` 块的位置，实际上是把左边 `'1'` 块、中间 `'0'` 块、右边 `'1'` 块三者中的两个 `'1'` 块合并。
2. 对于查询区间 `[l, r]`，需要找区间内相邻两个 `'1'` 块，合并后的最大长度 = 左 `'1'` 块长度 + 右 `'1'` 块长度（跨越中间 `'0'` 块）。
3. 还需处理边界：区间端点可能截断 `'1'` 块。

使用预处理 + 稀疏表（Sparse Table）或线段树对区间查询加速。

## Python 代码实现

### 方法一：预处理块信息 + 稀疏表（推荐）

```python
from typing import List
import math

class Solution:
    def maximizeActiveSections(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        # 构建块列表：(字符, 起始位置, 结束位置)
        blocks = []
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            blocks.append((s[i], i, j - 1))
            i = j

        m = len(blocks)
        # block_idx[pos] = 该位置所在块的索引
        block_idx = [0] * n
        for bi, (c, l, r) in enumerate(blocks):
            for pos in range(l, r + 1):
                block_idx[pos] = bi

        # 对每个查询暴力枚举（优化版本用稀疏表）
        def query(l, r):
            # 获取区间内所有块
            bl = block_idx[l]
            br = block_idx[r]
            res = 0
            # 单块全是1
            if bl == br:
                if blocks[bl][0] == '1':
                    return r - l + 1
                return 0
            # 枚举中间的 '0' 块，合并左右 '1' 块
            for bi in range(bl, br + 1):
                c, sl, sr = blocks[bi]
                if c == '0' and bl < bi < br:
                    # 左侧 '1' 块
                    lc, ll, lr = blocks[bi - 1]
                    # 右侧 '1' 块
                    rc, rl, rr = blocks[bi + 1]
                    if lc == '1' and rc == '1':
                        left_len = lr - max(ll, l) + 1
                        right_len = min(rr, r) - rl + 1
                        res = max(res, left_len + right_len)
            # 也考虑不交换，单个 '1' 块的最大长度
            for bi in range(bl, br + 1):
                c, sl, sr = blocks[bi]
                if c == '1':
                    res = max(res, min(sr, r) - max(sl, l) + 1)
            return res

        return [query(l, r) for l, r in queries]
```

### 方法二：线段树区间查询

```python
from typing import List

class Solution:
    def maximizeActiveSections(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        # 构建块列表
        blocks = []
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            blocks.append([s[i], i, j - 1])
            i = j

        # 对每个查询单独处理
        results = []
        for l, r in queries:
            best = 0
            # 找到 l 所在块和 r 所在块
            # 简单线性扫描（适合小规模）
            active_blocks = []
            for c, sl, sr in blocks:
                if sr < l or sl > r:
                    continue
                # 截断
                al = max(sl, l)
                ar = min(sr, r)
                active_blocks.append((c, ar - al + 1))

            # 单独最大 '1' 块
            for c, length in active_blocks:
                if c == '1':
                    best = max(best, length)

            # 枚举相邻 '1' 块（通过 '0' 块合并）
            for i in range(1, len(active_blocks) - 1):
                if active_blocks[i][0] == '0':
                    if i > 0 and i < len(active_blocks) - 1:
                        lc, ll = active_blocks[i - 1]
                        rc, rl = active_blocks[i + 1]
                        if lc == '1' and rc == '1':
                            best = max(best, ll + rl)

            results.append(best)
        return results
```

## 复杂度分析

- 时间复杂度：方法一 O(n + q * B)，B 为每次查询涉及的块数；方法二 O(n + q * n)
- 空间复杂度：O(n)，存储块信息

## 关键点总结

1. 将字符串压缩成"块"（连续相同字符段），减少枚举量
2. 一次交换本质是合并两个相邻 `'1'` 块
3. 需要处理查询边界对块的截断
4. 枚举中间 `'0'` 块，左右两侧各取一个 `'1'` 块合并

## 易错点

1. 查询边界处的块需要截断计算长度
2. 相邻 `'1'` 块之间必须恰好有一个 `'0'` 块才能合并
3. 不要漏掉不交换情况下单个 `'1'` 块的长度
