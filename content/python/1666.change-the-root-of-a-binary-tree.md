## 题目描述

给你一棵二叉树，树中节点都有父指针（parent）。给你一个叶节点 `leaf`，将这棵树重新生根，使 `leaf` 成为新的根节点。

**重新生根的规则：**
- 若节点 `x` 在从 `leaf` 到原根的路径上，其**子指针**和**父指针**需要翻转
- 路径外的节点保持不变

返回新的根节点（即 `leaf`）。

## 解题思路

沿着从 `leaf` 到原根的路径，逐步翻转父子关系：

1. 从 `leaf` 开始，记当前节点为 `child`，父节点为 `parent`
2. 将 `parent` 的左/右指针（指向 `child` 的那个）设为 `child` 原来的父指针
3. 设 `child` 的父指针为 None（新根的父是 None）
4. 设 `parent` 的子指针（指向 `child` 的）指向 `child`（翻转）
5. 向上移动，直到原根

## 代码实现

### 方法一：沿路径翻转（推荐）

```python
class Node:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
        self.parent = None

class Solution:
    def flipBinaryTree(self, root: Node, leaf: Node) -> Node:
        child = leaf
        parent = leaf.parent
        
        while parent:
            # 记录 parent 的父节点（下一步迭代用）
            grandparent = parent.parent
            
            # 记录 child 原来在 parent 的哪个方向
            is_left_child = (parent.left == child)
            
            # 翻转：parent 成为 child 的子节点
            if is_left_child:
                parent.left = child.parent  # 原来 child 的父（即 parent 的父）
                child.right = parent  # child 的右指针指向 parent（翻转）
            else:
                parent.right = child.parent
                child.left = parent  # child 的左指针指向 parent（翻转）
            
            # 设置 parent 的新父指针
            parent.parent = child
            
            # 向上移动
            child = parent
            parent = grandparent
        
        # leaf 成为新根，父指针设为 None
        leaf.parent = None
        return leaf
```

### 方法二：递归翻转

```python
class Solution:
    def flipBinaryTree(self, root: Node, leaf: Node) -> Node:
        def flip(node: Node, child: Node):
            """将 node 节点与其子节点 child 之间的关系翻转"""
            if node is None:
                return
            
            parent = node.parent
            flip(parent, node)  # 先递归处理上层
            
            if node.left == child:
                # child 是左子节点，翻转后 node 成为 child 的右子节点
                node.left = node.parent  # 原父变成左子
                node.parent = child
            elif node.right == child:
                node.right = node.parent
                node.parent = child
        
        flip(leaf.parent, leaf)
        leaf.parent = None
        return leaf
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 迭代翻转 | O(h) | O(1) |
| 递归翻转 | O(h) | O(h) |

h 为从叶节点到根节点的路径长度。

## 关键点总结

1. 只需翻转从 `leaf` 到原根路径上的节点
2. 翻转规则：若 `child` 是 `parent` 的左子，则翻转后 `child` 的右子变为 `parent`
3. 最终 `leaf` 的父指针设为 None，成为新根
4. 路径外的节点不受影响

## 易错点

- 翻转时注意是左子还是右子：左子 -> 翻转后父成为右子；右子 -> 翻转后父成为左子
- 迭代时需要预先记录 `grandparent`，因为翻转后 parent 的 parent 会改变
- 新根的 `parent` 指针要置为 None
