## 题目描述

给你两个正整数 `n` 和 `target`。

如果一个由 `n` 个**互不相同**正整数组成的数组中，**不存在**任意两个元素之和等于 `target`，则该数组是**美丽数组**。

返回美丽数组可能的**最小元素之和**，对 `10^9 + 7` 取模。

**示例 1：**
```
输入：n = 2, target = 3
输出：4
解释：美丽数组 [1, 3]（1+3=4，但没有两个元素和为 3），和 = 4
```

**示例 2：**
```
输入：n = 3, target = 3
输出：8
解释：数组 [1, 4, 3] 无法：1+3=4≠3，1+4=5≠3，3+4=7≠3，和=8？等等...实际是 [1, 5, 2]? 不对
最小应该是 [1, 2, 4]，和 = 7... 但 1+2=3=target，不行。
正确：[1, 4, 5]，但还有 [1, 3, 4]？1+3=4≠3，1+4=5≠3，3+4=7≠3 ✓ 和=8
```

**提示：**
- `1 <= n <= 10^9`
- `1 <= target <= 10^9`

## 解题思路

**贪心：** 从最小的正整数开始选，如果选了 `x`，则不能选 `target - x`。

**关键分析：**
- 对于 `x < target/2`，选了 `x` 就不能选 `target - x`（两者都 < target，互相限制）
- 从 1 开始：可以安全选 `1, 2, ..., floor((target-1)/2)`，共 `floor((target-1)/2)` 个
- 如果 n <= floor((target-1)/2)，选前 n 个，和 = n*(n+1)/2
- 否则，还需要从 target, target+1, ... 继续选（跳过了 target/2 对应的配对）

**数学推导：**
设 `half = (target - 1) // 2`（可选的小数最多到 half）
- 若 n <= half：选 1, 2, ..., n，和 = n*(n+1)//2
- 否则：先选 1, 2, ..., half，再从 target 开始选 n-half 个
  - 注意：target 本身与 0 配对，但 0 不在数组中，target 可以选
  - 从 target 开始：target, target+1, ..., target+(n-half-1)
  - 这些数 >= target，互相之和 >= 2*target，不等于 target（满足）

## Python 代码实现

### 方法一：数学推导（推荐）

```python
class Solution:
    def minimumPossibleSum(self, n: int, target: int) -> int:
        MOD = 10**9 + 7
        half = (target - 1) // 2  # 可以安全选的小数：1 到 half

        if n <= half:
            # 选 1, 2, ..., n
            return n * (n + 1) // 2 % MOD
        else:
            # 选 1, 2, ..., half，再从 target 开始选 n-half 个
            sum1 = half * (half + 1) // 2  # 1+2+...+half
            remaining = n - half
            # target + (target+1) + ... + (target+remaining-1)
            # = remaining * target + 0+1+...+(remaining-1)
            # = remaining * target + remaining*(remaining-1)//2
            sum2 = remaining * target + remaining * (remaining - 1) // 2
            return (sum1 + sum2) % MOD
```

### 方法二：贪心模拟（验证用）

```python
class Solution:
    def minimumPossibleSum(self, n: int, target: int) -> int:
        MOD = 10**9 + 7
        chosen = set()
        total = 0
        num = 1
        count = 0

        while count < n:
            if target - num not in chosen or target - num == num:
                # num 可以选（配对数不在集合中，或配对就是自身但不选重复）
                # 实际上 target - num == num 意味着 target 为偶数且 num = target/2
                # 两个相同数不能都选，所以跳过
                if target - num != num:
                    chosen.add(num)
                    total = (total + num) % MOD
                    count += 1
            num += 1

        return total
```

## 复杂度分析

- 方法一：时间 O(1)，空间 O(1)
- 方法二：时间 O(n + target)，空间 O(n)（当 n 很大时不适用）

## 关键点总结

1. 可安全选的小数：1 到 `(target-1)//2`，选了 x 不能选 target-x
2. 超出 half 后，从 target 开始继续选（这些数与 target 以内的不配对）
3. 注意 target/2（target 为偶数时）：target/2 与 target/2 配对为 target，不能选两个相同的，实际上只能选一个，但由于 target/2 + target/2 = target，也不能选

## 易错点

1. `half = (target - 1) // 2` 而不是 `target // 2`，当 target 为偶数时 target//2 与 target//2 配对，不能选
2. 结果需要对 10^9+7 取模
3. n 可以很大（10^9），不能用模拟
