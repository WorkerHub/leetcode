## 题目描述

给你一个列表 `interests`，其中 `interests[i]` 是第 `i` 个人的兴趣集合。如果两个人有共同兴趣，他们就是朋友，朋友关系可以传递。返回朋友群体的数量。

**示例 1：**

```
输入：interests = [[1,3],[1,2],[3]]
输出：2
解释：人0和人1有共同兴趣1，人0和人2有共同兴趣3，所以0,1,2在同一群体
实际：人0(兴趣1,3)，人1(兴趣1,2)，共同兴趣1→合并；人0和人2共同兴趣3→合并。共1个群体
```

**示例 2：**

```
输入：interests = [[1],[2]]
输出：2
解释：无共同兴趣
```

**提示：**

- `1 <= interests.length <= 300`
- `1 <= interests[i].length <= 300`
- `1 <= interests[i][j] <= 10^5`

## 解题思路

并查集：对每个兴趣，将拥有该兴趣的所有人合并到同一集合。

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def friendGroups(self, interests: List[List[int]]) -> int:
        n = len(interests)
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        # 按兴趣建立映射
        interest_to_people = defaultdict(list)
        for i, ints in enumerate(interests):
            for interest in ints:
                interest_to_people[interest].append(i)

        # 合并有共同兴趣的人
        for people in interest_to_people.values():
            for i in range(1, len(people)):
                union(people[0], people[i])

        # 统计连通分量数
        return len(set(find(i) for i in range(n)))
```

### 方法二：BFS

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def friendGroups(self, interests: List[List[int]]) -> int:
        n = len(interests)
        interest_to_people = defaultdict(set)
        for i, ints in enumerate(interests):
            for interest in ints:
                interest_to_people[interest].add(i)

        visited = [False] * n
        groups = 0

        for start in range(n):
            if not visited[start]:
                groups += 1
                queue = deque([start])
                visited[start] = True
                while queue:
                    person = queue.popleft()
                    for interest in interests[person]:
                        for friend in interest_to_people[interest]:
                            if not visited[friend]:
                                visited[friend] = True
                                queue.append(friend)
        return groups
```

## 复杂度分析

- 时间复杂度：O(n * k * α(n))，k 为平均兴趣数
- 空间复杂度：O(n + total_interests)

## 关键点总结

1. 按兴趣将人分组，同兴趣的人用并查集合并
2. 最终统计不同连通分量数
3. 朋友关系传递 = 并查集的传递合并

## 易错点

1. 同一兴趣的所有人合并到第一个人（代表元）
2. 统计连通分量：对每人取 find，不同 find 结果就是不同群体
3. 一个人独立也是一个群体
