## 题目描述

给你一个数组 `nums`。`nums` 的源数组中，若存在元素 `x`，则也存在 `x + 1`（按照顺序）。

如果 `nums` 是由某个排序数组在某个位置**旋转**得到的，返回 `true`，否则返回 `false`。

注意：`nums` 可能含有**重复数字**。

**示例 1：**
```
输入：nums = [3,4,5,1,2]
输出：true
解释：[1,2,3,4,5] 在 x = 3 处旋转
```

**示例 2：**
```
输入：nums = [2,1,3,4]
输出：false
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

统计数组中"下降点"的数量，即满足 `nums[i] > nums[i+1]` 的位置（循环比较，包括最后一个和第一个）。

- 如果下降点数量为 0，数组本身是排序的（旋转了 0 次）
- 如果下降点数量为 1，数组是由某个排序数组旋转得到的
- 如果下降点数量 >= 2，不是由排序数组旋转得到的

## 代码实现

### 方法一：统计下降点（推荐）

```python
from typing import List

class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        # 统计下降点数量（包括循环比较）
        drops = 0
        for i in range(n):
            if nums[i] > nums[(i + 1) % n]:
                drops += 1
        
        # 至多 1 个下降点则满足条件
        return drops <= 1
```

### 方法二：找旋转点验证

```python
from typing import List

class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        
        # 找下降点
        drop_idx = -1
        for i in range(n):
            if nums[i] > nums[(i + 1) % n]:
                if drop_idx != -1:
                    return False  # 已有一个下降点了，第二个直接返回 False
                drop_idx = i
        
        return True
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 旋转数组最多有一个"下降点"
2. 循环比较最后一个元素和第一个元素
3. 允许重复元素（`>=` 不算下降，只有 `>` 才算）

## 易错点

- 用 `(i+1) % n` 实现循环比较
- 排序数组本身也满足条件（0 个下降点）
