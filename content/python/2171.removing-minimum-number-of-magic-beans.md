## 题目描述

给你一个正整数数组 `beans`，其中每个整数表示一个袋子里的魔法豆数目。

请你从每个袋子中**去除**一些豆子（也可以**不去除**任何豆子），使得剩下的**非空**袋子中，任意两个袋子的豆数**相等**。一旦豆数不为零，袋子就视为非空。

返回你需要去除的**最少**魔法豆的数目。

**示例：**
```
输入：beans = [4,1,6,5]
输出：4
解释：从袋子 [4,1,6,5] 中：
- 去除 4 中的 4（全部），去除 6 中的 1 = 5 个？
- 最优：选目标值为 4，去除 beans[1]=1(全1)，去除 beans[3] 中 5-4=1，去除 beans[2] 中 6-4=2，总共 1+1+2=4。
```

**提示：**
- `1 <= beans.length <= 10^5`
- `1 <= beans[i] <= 10^5`

## 解题思路

**排序 + 枚举目标值**

设目标值为 `target`：
- 豆数 < target 的袋子：将其清空（去除全部豆数）。
- 豆数 >= target 的袋子：将其减到 target（去除超出部分）。
- 豆数等于 0 的袋子：不变（空袋子不计入）。

最少去除 = 总豆数 - 最多保留的豆数。

目标值只需枚举 `beans` 中的值（排序后枚举每个位置 i，以 `beans[i]` 为目标值，左侧全部清空，右侧减到 `beans[i]`）。

设排序后的数组为 `b`，前缀和为 `prefix`：
- 选 `b[i]` 为目标：保留 = `b[i] * (n - i)`（右侧包含 i 的元素全保留为 b[i]）。
- 去除 = 总和 - b[i] * (n - i)。

## 代码实现

### 方法一：排序 + 枚举（推荐）

```python
from typing import List

class Solution:
    def minimumRemoval(self, beans: List[int]) -> int:
        beans.sort()
        n = len(beans)
        total = sum(beans)
        # 枚举每个位置 i 作为目标值 beans[i]
        # 保留 = beans[i] * (n - i)（右侧全部保留为 beans[i]）
        ans = total  # 最坏情况：全部去除
        for i in range(n):
            keep = beans[i] * (n - i)
            ans = min(ans, total - keep)
        return ans
```

### 方法二：前缀和优化（等价）

```python
from typing import List

class Solution:
    def minimumRemoval(self, beans: List[int]) -> int:
        beans.sort()
        n = len(beans)
        total = sum(beans)
        ans = total
        for i, b in enumerate(beans):
            # 以 b 为目标，去除 = 前 i 个全部 + 后面每个超出 b 的部分
            # = prefix[i] + (total - prefix[i+1]) - b*(n-i-1)
            # = total - b*(n-i)  （等价于上面的方法）
            ans = min(ans, total - b * (n - i))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序枚举 | O(n log n) | O(1) |

## 关键点总结

1. 排序后，以 `beans[i]` 为目标值时，左侧全部清空，右侧减到 `beans[i]`。
2. 保留豆数 = `beans[i] * (n - i)`（从 i 到末尾，每袋保留 beans[i] 个）。
3. 最少去除 = 总数 - 最大保留数。

## 易错点

- 目标值为 0 时所有袋子都清空，去除 = 总数（可以通过公式得到）。
- 可以枚举 0 作为目标值（即选择不保留任何豆子），但题目要求非空袋子相等，全清空也合法（没有非空袋子，条件空满足）。
