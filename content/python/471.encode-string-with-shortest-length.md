## 题目描述

给定一个非空字符串，将其编码为具有最短长度的字符串。

编码规则是：`k[encoded_string]`，其中在方括号 `encoded_string` 中的内容重复 `k` 次。

**注意：**
- `k` 为正整数
- 如果编码的过程不能使字符串缩短，则不要对其进行编码。如果有多种编码方式，返回任意一种即可。

**示例 1：**
```
输入：s = "aaa"
输出："aaa"
解释：无法将其编码为更短的字符串，因此不进行编码。
```

**示例 2：**
```
输入：s = "aaaaa"
输出："5[a]"
解释："5[a]" 比 "aaaaa" 短 1 个字符。
```

**示例 3：**
```
输入：s = "aaaaaaaaaa"
输出："10[a]"
解释："a9[a]" 或 "9[a]a" 都是合法的编码，但 "10[a]" 是最短的。
```

**示例 4：**
```
输入：s = "aabcaabcd"
输出："2[aabc]d"
解释："aabc" 出现两次，因此一种答案可以是 "2[aabc]d"。
```

**示例 5：**
```
输入：s = "abbbabbbcabbbabbbc"
输出："2[2[abbb]c]"
解释："abbbabbbc" 出现两次，但 "abbbabbbc" 可以编码为 "2[abbb]c"，因此一种答案可以是 "2[2[abbb]c]"。
```

**提示：**
- `1 <= s.length <= 150`
- `s` 由小写英文字母组成

## 解题思路

这是一道**区间动态规划**问题，需要考虑字符串的嵌套编码。

**核心思想：**
1. 对于字符串的每个子串，找到最短编码
2. 考虑两种情况：
   - 不编码（保持原样）
   - 编码（找重复模式）
   - 分割（左右两部分分别编码）

**动态规划定义：**
- `dp[i][j]` 表示 `s[i:j+1]` 的最短编码

**状态转移：**
1. 初始化：`dp[i][j] = s[i:j+1]`
2. 分割点：尝试所有分割点 k，`dp[i][j] = dp[i][k] + dp[k+1][j]`
3. 重复模式：如果 `s[i:j+1]` 可以表示为重复模式，编码为 `count[pattern]`

**关键：如何判断重复模式？**
- 子串长度为 n
- 尝试所有可能的模式长度 len（n 的因子）
- 检查 `s[i:i+len]` 重复 `n/len` 次是否等于 `s[i:j+1]`

## Python 代码实现

### 方法一：区间 DP（推荐）⭐

```python
class Solution:
    def encode(self, s: str) -> str:
        n = len(s)
        
        # dp[i][j] 表示 s[i:j+1] 的最短编码
        dp = [["" for _ in range(n)] for _ in range(n)]
        
        # 枚举区间长度
        for length in range(1, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                substr = s[i:j+1]
                
                # 初始化为原字符串
                dp[i][j] = substr
                
                # 如果长度小于 5，编码不会更短（如 "aa" 编码为 "2[a]" 反而更长）
                if length < 5:
                    continue
                
                # 尝试找重复模式
                encoded = self.findRepeatedPattern(substr)
                if len(encoded) < len(dp[i][j]):
                    dp[i][j] = encoded
                
                # 尝试分割点
                for k in range(i, j):
                    left_right = dp[i][k] + dp[k+1][j]
                    if len(left_right) < len(dp[i][j]):
                        dp[i][j] = left_right
        
        return dp[0][n-1]
    
    def findRepeatedPattern(self, s: str) -> str:
        """查找字符串的重复模式并编码"""
        n = len(s)
        
        # 尝试所有可能的模式长度
        for pattern_len in range(1, n // 2 + 1):
            if n % pattern_len == 0:  # 长度必须是 n 的因子
                pattern = s[:pattern_len]
                count = n // pattern_len
                
                # 检查是否真的重复
                if pattern * count == s:
                    # 递归编码模式本身
                    encoded_pattern = self.encode(pattern)
                    return f"{count}[{encoded_pattern}]"
        
        return s  # 没有找到重复模式
```

### 方法二：记忆化搜索

```python
class Solution:
    def encode(self, s: str) -> str:
        memo = {}
        
        def dp(i, j):
            if (i, j) in memo:
                return memo[(i, j)]
            
            substr = s[i:j+1]
            result = substr
            
            if len(substr) < 5:
                memo[(i, j)] = result
                return result
            
            # 尝试重复模式
            n = len(substr)
            for plen in range(1, n // 2 + 1):
                if n % plen == 0:
                    pattern = substr[:plen]
                    if pattern * (n // plen) == substr:
                        encoded = f"{n // plen}[{dp(i, i + plen - 1)}]"
                        if len(encoded) < len(result):
                            result = encoded
            
            # 尝试分割
            for k in range(i, j):
                split = dp(i, k) + dp(k + 1, j)
                if len(split) < len(result):
                    result = split
            
            memo[(i, j)] = result
            return result
        
        return dp(0, len(s) - 1)
```

## 复杂度分析

- 时间复杂度：O(n^4)
  - O(n^2) 个子问题
  - 每个子问题尝试 O(n) 个分割点和模式
  - 每次检查需要 O(n)
- 空间复杂度：O(n^2)

## 关键点总结

1. **区间 DP：** 从小区间到大区间
2. **重复模式：** 长度必须是因子
3. **分割策略：** 尝试所有分割点
4. **长度阈值：** 长度 < 5 不编码
5. **递归编码：** 模式本身也可能需要编码

## 易错点

1. **长度阈值：** `"aa"` 编码为 `"2[a]"` 反而更长
   ```python
   if length < 5:
       continue
   ```

2. **因子检查：**
   ```python
   if n % pattern_len == 0:  # 必须整除
   ```

3. **递归编码：** 模式本身也需要编码
   ```python
   encoded_pattern = self.encode(pattern)
   return f"{count}[{encoded_pattern}]"
   ```
