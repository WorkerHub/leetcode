## 题目描述

Alice 和 Bob 轮流玩一个游戏，Alice 先手。

有 `n` 块石头。每块石头对 Alice 来说有一个对应的价值 `aliceValues[i]`，对 Bob 来说也有一个价值 `bobValues[i]`。Alice 和 Bob 有不同的价值观，在他们的眼中，同一块石头的价值是不同的。

每一轮，在所有**剩下**的石头中，Alice（或者 Bob）选择价值**最高**的石头（就他自己的价值而言）。如果两块石头价值相同，那就选**下标最小**的那块石头。然后，被选中的石头就从游戏中移除。

当所有石头都被取走后，Alice 和 Bob 分别统计他们手中石头的**总价值**。如果 Alice 的总价值**大于** Bob 的，则 Alice 获胜；如果两者**相同**则为平局；如果 Bob 的总价值**更大**，则 Bob 获胜。

假设 Alice 和 Bob 都**足够聪明**，都会选择对自己**最优**的策略，请你**返回游戏的结果**：
- 如果 Alice 赢，返回 `1`
- 如果两者打平，返回 `0`
- 如果 Bob 赢，返回 `-1`

**示例 1：**
```
输入：aliceValues = [1,3], bobValues = [2,1]
输出：1
解释：Alice 选石头 1（价值 3），Bob 选石头 0（价值 2），Alice 赢
```

**提示：**
- `n == aliceValues.length == bobValues.length`
- `1 <= n <= 10^5`
- `1 <= aliceValues[i], bobValues[i] <= 100`

## 解题思路

关键洞察：每次选择一块石头，相当于：
1. 自己获得这块石头的价值
2. **同时阻止对方**获得这块石头的价值

因此，一块石头的"综合价值"应该是 `aliceValues[i] + bobValues[i]`。

贪心策略：按照 `aliceValues[i] + bobValues[i]` 降序排序，Alice 和 Bob 交替取石头（Alice 先取），每人取价值最大的那块。

证明：当 Alice 取石头 A 而非 B 时，Alice 收益 `A_a`，Bob 下一轮取 B 收益 `B_b`；若反过来 Alice 取 B，Bob 取 A，则 Alice 收益 `B_a`，Bob 收益 `A_b`。两种方案对 Alice 的"差值"（Alice分数-Bob分数）分别为 `A_a - B_b` 和 `B_a - A_b`。选择使差值更大的方案，即最大化 `(A_a+A_b) - (B_a+B_b)`，所以排序依据是 `a+b` 之和。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def stoneGameVI(self, aliceValues: List[int], bobValues: List[int]) -> int:
        n = len(aliceValues)
        # 按两人价值之和降序排序
        stones = sorted(
            [(aliceValues[i] + bobValues[i], aliceValues[i], bobValues[i])
             for i in range(n)],
            reverse=True
        )

        alice_score = 0
        bob_score = 0

        for idx, (total, av, bv) in enumerate(stones):
            if idx % 2 == 0:
                # Alice 的回合（偶数轮，从 0 开始）
                alice_score += av
            else:
                # Bob 的回合
                bob_score += bv

        if alice_score > bob_score:
            return 1
        elif alice_score < bob_score:
            return -1
        else:
            return 0
```

### 方法二：使用堆（优先队列）

```python
from typing import List
import heapq

class Solution:
    def stoneGameVI(self, aliceValues: List[int], bobValues: List[int]) -> int:
        # 用最大堆（Python 用负数模拟）
        heap = [-(a + b) for a, b in zip(aliceValues, bobValues)]
        # 同时记录各自的价值
        pairs = sorted(zip(aliceValues, bobValues),
                       key=lambda x: x[0] + x[1], reverse=True)

        alice_score = 0
        bob_score = 0

        for i, (av, bv) in enumerate(pairs):
            if i % 2 == 0:
                alice_score += av
            else:
                bob_score += bv

        if alice_score > bob_score:
            return 1
        elif alice_score < bob_score:
            return -1
        return 0
```

## 复杂度分析

- **时间复杂度**：O(n log n)，主要是排序的时间
- **空间复杂度**：O(n)，存储排序后的数组

## 关键点总结

1. 核心贪心思路：选一块石头的"综合价值"是自己得到的价值加上对方失去的价值
2. 排序依据是 `aliceValues[i] + bobValues[i]`
3. 排好序后，Alice 取偶数下标（0, 2, 4...），Bob 取奇数下标
4. 这道题是博弈论问题，但贪心策略可以证明是最优的

## 易错点

1. 贪心排序依据不是各自的最大价值，而是两者之和
2. 轮次从 0 开始：Alice 取第 0、2、4... 轮，对应下标为偶数
3. 若价值相同按下标排序，但贪心策略下不影响最终结果
