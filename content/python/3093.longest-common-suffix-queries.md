## 题目描述

给你两个字符串数组 `wordsContainer` 和 `wordsQuery`。

对每个查询字符串 `wordsQuery[i]`，在 `wordsContainer` 中找出与其有最长公共后缀的字符串。

若有多个最长公共后缀相同的字符串，返回长度最短的那个；若长度也相同，返回下标最小的那个。

返回一个整数数组，`answer[i]` 为满足条件的字符串在 `wordsContainer` 中的下标。

**提示：**
- `1 <= wordsContainer.length, wordsQuery.length <= 10^4`
- `1 <= wordsContainer[i].length, wordsQuery[i].length <= 5 * 10^3`

## 解题思路

反转所有字符串，将"公共后缀"问题转化为"公共前缀"问题，然后使用 Trie（字典树）。

构建反转后的 `wordsContainer` 的 Trie，每个 Trie 节点存储"最优字符串"（最短且下标最小）。

对每个查询，在 Trie 中查找最长匹配前缀，返回对应节点的最优字符串下标。

## Python 代码实现

### 方法一：Trie（后缀 = 反转后前缀）（推荐）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.best = -1  # 当前节点记录的最优字符串下标

class Solution:
    def stringIndices(self, wordsContainer: List[str], wordsQuery: List[str]) -> List[int]:
        # 构建 Trie（存储反转后的字符串）
        root = TrieNode()

        def get_best(container, old_idx, new_idx):
            """比较两个候选，返回更优的那个（更短，相同则下标更小）"""
            if old_idx == -1:
                return new_idx
            old_len = len(container[old_idx])
            new_len = len(container[new_idx])
            if new_len < old_len or (new_len == old_len and new_idx < old_idx):
                return new_idx
            return old_idx

        # 将 wordsContainer 中每个字符串反转后插入 Trie
        for i, word in enumerate(wordsContainer):
            node = root
            # 更新根节点的最优
            node.best = get_best(wordsContainer, node.best, i)
            for ch in reversed(word):
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]
                node.best = get_best(wordsContainer, node.best, i)

        # 查询
        result = []
        for query in wordsQuery:
            node = root
            best = node.best
            for ch in reversed(query):
                if ch not in node.children:
                    break
                node = node.children[ch]
                best = node.best

            result.append(best)

        return result
```

### 方法二：暴力（n, m 较小时）

```python
from typing import List

class Solution:
    def stringIndices(self, wordsContainer: List[str], wordsQuery: List[str]) -> List[int]:
        def common_suffix_len(a, b):
            i, j = len(a) - 1, len(b) - 1
            cnt = 0
            while i >= 0 and j >= 0 and a[i] == b[j]:
                cnt += 1
                i -= 1
                j -= 1
            return cnt

        result = []
        for query in wordsQuery:
            best_idx = 0
            best_suffix = -1
            for i, word in enumerate(wordsContainer):
                sl = common_suffix_len(word, query)
                if sl > best_suffix or (sl == best_suffix and
                    (len(word) < len(wordsContainer[best_idx]) or
                     (len(word) == len(wordsContainer[best_idx]) and i < best_idx))):
                    best_suffix = sl
                    best_idx = i
            result.append(best_idx)

        return result
```

## 复杂度分析

- Trie 方法：O((n + m) * L)，L 为最大字符串长度
- 暴力：O(n * m * L)
- 空间复杂度：O(n * L)，Trie 大小

## 关键点总结

1. 将后缀匹配转化为前缀匹配（反转字符串）
2. Trie 每个节点记录"最优"字符串（最短、下标最小）
3. 查询时沿 Trie 走，最深匹配节点的最优值即为答案

## 易错点

1. 反转字符串时用 `reversed(word)` 或 `word[::-1]`
2. 更新最优时要比较长度和下标两个维度
3. 查询终止条件：字符不在 Trie 中则停止，取当前节点的最优
