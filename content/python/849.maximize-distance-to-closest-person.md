## 题目描述

给你一个数组 `seats` 表示一排座位，其中 `seats[i] = 1` 代表有人坐在第 `i` 个座位上，`seats[i] = 0` 代表第 `i` 个座位为空（下标从 0 开始）。

至少有一个空座位，且至少有一人已经坐在座位上。

亚历克斯希望坐在一个能够使他与离他最近的人之间的距离达到最大化的座位上。

返回他到离他最近的人的最大距离。

**示例 1:**
```
输入: seats = [1,0,0,0,1,0,1]
输出: 2
解释: 如果亚历克斯坐在第二个空位（seats[2]）上，他到离他最近的人的距离为 2。
如果亚历克斯坐在其它任何一个空位上，他到离他最近的人的距离为 1。
因此，他到离他最近的人的最大距离是 2。
```

**示例 2:**
```
输入: seats = [1,0,0,0]
输出: 3
解释: 如果亚历克斯坐在最后一个座位上，他离最近的人有 3 个座位远。
这是可能的最大距离，所以答案是 3。
```

**示例 3:**
```
输入: seats = [0,1]
输出: 1
```

**提示:**
- `2 <= seats.length <= 2 * 10^4`
- `seats[i]` 为 `0` 或 `1`
- 至少有一个 **空座位**
- 至少有一个 **座位上有人**

## 解题思路

分三种情况考虑：
1. **开头的空位**：距离 = 第一个人的位置
2. **中间的空位**：距离 = 两人之间距离 / 2
3. **结尾的空位**：距离 = 最后一个位置 - 最后一个人的位置

## Python 代码实现

### 方法一：三种情况（推荐）⭐

```python
from typing import List

class Solution:
    def maxDistToClosest(self, seats: List[int]) -> int:
        n = len(seats)
        
        # 找到所有有人的位置
        people = [i for i, seat in enumerate(seats) if seat == 1]
        
        # 开头的空位
        max_dist = people[0]
        
        # 中间的空位（两人之间）
        for i in range(1, len(people)):
            max_dist = max(max_dist, (people[i] - people[i - 1]) // 2)
        
        # 结尾的空位
        max_dist = max(max_dist, n - 1 - people[-1])
        
        return max_dist
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def maxDistToClosest(self, seats: List[int]) -> int:
        n = len(seats)
        prev = -1  # 上一个有人的位置
        max_dist = 0
        
        for i in range(n):
            if seats[i] == 1:
                if prev == -1:
                    # 开头的空位
                    max_dist = i
                else:
                    # 中间的空位
                    max_dist = max(max_dist, (i - prev) // 2)
                prev = i
        
        # 结尾的空位
        max_dist = max(max_dist, n - 1 - prev)
        
        return max_dist
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1) 或 O(k)，k 是人数

## 关键点总结

1. **三种情况**：开头、中间、结尾
2. **中间距离**：两人间距除以 2
3. **边界处理**：开头和结尾的特殊情况

## 易错点

1. **整数除法**：中间距离要除以 2
2. **结尾处理**：不要忘记检查结尾
3. **空位判断**：prev == -1 表示开头
