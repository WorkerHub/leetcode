## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，返回满足下述条件的 **不同** 四元组 `(a, b, c, d)` 的数目：
- `nums[a] + nums[b] + nums[c] == nums[d]`
- `a < b < c < d`

**示例 1：**
```
输入：nums = [1,2,3,6]
输出：1
解释：(0,1,2,3)：1+2+3=6
```

**示例 2：**
```
输入：nums = [3,3,6,4,5]
输出：0
```

**提示：**
- `4 <= nums.length <= 50`
- `1 <= nums[i] <= 100`

---

## 解题思路

### 核心思想：枚举 + 哈希表

**方法一**：枚举 c 和 d，固定 d，从右向左枚举 c，用哈希表维护 `nums[a]+nums[b]` 的频次（a<b<c）。

**方法二**：直接四重循环（n<=50，O(n^4) 可接受）。

---

## 代码实现

### 方法一：哈希表优化（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        # cnt[v] = nums[a]+nums[b] 等于 v 的对数，a<b<当前c
        cnt = defaultdict(int)

        for c in range(2, n - 1):
            # 新加入 b = c-1：所有 a < b = c-1 形成的对
            for a in range(c - 1):
                cnt[nums[a] + nums[c - 1]] += 1

            # 枚举 d（d > c）
            for d in range(c + 1, n):
                # 需要 nums[a]+nums[b] = nums[d]-nums[c]
                target = nums[d] - nums[c]
                if target >= 0:
                    ans += cnt[target]

        return ans
```

### 方法二：四重循环暴力

```python
from typing import List

class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for a in range(n - 3):
            for b in range(a + 1, n - 2):
                for c in range(b + 1, n - 1):
                    for d in range(c + 1, n):
                        if nums[a] + nums[b] + nums[c] == nums[d]:
                            ans += 1
        return ans
```

### 方法三：三重循环 + 哈希集

```python
from typing import List
from collections import Counter

class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        # 预处理 d 右侧出现的数
        for a in range(n - 3):
            for b in range(a + 1, n - 2):
                for c in range(b + 1, n - 1):
                    target = nums[a] + nums[b] + nums[c]
                    for d in range(c + 1, n):
                        if nums[d] == target:
                            ans += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（哈希表） | O(n²) | O(n²) |
| 方法二（暴力） | O(n⁴) | O(1) |
| 方法三 | O(n⁴) | O(1) |

---

## 关键点总结

1. `n <= 50`，暴力 O(n^4) 约 625 万次，完全可行
2. 哈希表优化：固定 c，维护所有 `(a,b)` 对之和

---

## 易错点

- 四元组要求下标严格递增，不是值不同
- 方法一中 `target = nums[d] - nums[c]` 需保证 `>= 0`
