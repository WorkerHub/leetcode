## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**
```
输入：s = "()"
输出：true
```

**示例 2：**
```
输入：s = "()[]{}"
输出：true
```

**示例 3：**
```
输入：s = "(]"
输出：false
```

**示例 4：**
```
输入：s = "([])"
输出：true
```

**提示：**
- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 解题思路

这是栈的经典应用题目：

**核心思想：**
- 遇到左括号，压入栈
- 遇到右括号，检查栈顶是否为匹配的左括号
- 最后栈应该为空

**为什么用栈？**
- 括号匹配具有"后进先出"的特点
- 最近的左括号应该先被匹配

## Python 代码实现

### 方法一：栈 + 哈希表（推荐）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 奇数长度直接返回 False
        if len(s) % 2 == 1:
            return False
        
        # 建立右括号到左括号的映射
        pairs = {
            ')': '(',
            ']': '[',
            '}': '{'
        }
        
        stack = []
        
        for char in s:
            if char in pairs:  # 遇到右括号
                # 检查栈是否为空或栈顶是否匹配
                if not stack or stack[-1] != pairs[char]:
                    return False
                stack.pop()
            else:  # 遇到左括号
                stack.append(char)
        
        # 栈为空说明所有括号都匹配
        return not stack
```

### 方法二：使用列表作为栈（简化版）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        mapping = {')': '(', ']': '[', '}': '{'}
        
        for char in s:
            if char in mapping:
                # 弹出栈顶元素，如果栈为空则用 '#' 占位
                top = stack.pop() if stack else '#'
                if mapping[char] != top:
                    return False
            else:
                stack.append(char)
        
        return len(stack) == 0
```

### 方法三：替换法（不推荐，仅作思路参考）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 不断删除相邻的配对括号
        while '()' in s or '[]' in s or '{}' in s:
            s = s.replace('()', '').replace('[]', '').replace('{}', '')
        
        return s == ''
```

## 复杂度分析

**方法一和二：**
- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(n)，最坏情况下栈存储所有左括号

**方法三：**
- 时间复杂度：O(n^2)，每次 replace 都是 O(n)，可能需要多次
- 空间复杂度：O(n)，字符串操作产生的临时空间

## 图解示例

以 `s = "([{}])"` 为例：

```
步骤    字符    栈状态         操作
1       (      [(]           压栈
2       [      [(, []         压栈
3       {      [(, [, {]      压栈
4       }      [(, []         匹配 {，弹栈
5       ]      [(]           匹配 [，弹栈
6       )      []            匹配 (，弹栈

最终栈为空 → 返回 true
```

不匹配的例子 `s = "(]"`:

```
步骤    字符    栈状态         操作
1       (      [(]           压栈
2       ]      -             栈顶是 (，不匹配 ]

返回 false
```

## 关键点总结

1. **栈的应用**：括号匹配是栈的典型应用场景
2. **哈希表优化**：用字典存储配对关系，简化匹配逻辑
3. **提前剪枝**：奇数长度直接返回 false
4. **边界检查**：弹栈前检查栈是否为空

## 易错点

1. **忘记检查栈是否为空**：遇到右括号时，栈可能已经空了
2. **最后忘记检查栈**：即使没有报错，栈中可能还有未匹配的左括号
3. **映射关系搞反**：应该是右括号 → 左括号的映射
4. **边界情况**：
   - 空字符串（题目保证长度 >= 1）
   - 单个括号 `"("`
   - 全是左括号 `"((("`
   - 全是右括号 `")))"`
