## 题目描述

给你一个整数数组 `nums`。从下标 `0` 开始，每次跳跃可以从下标 `i` 跳到任意下标 `j`（`i < j <= n-1`），得分为 `(j - i) * nums[j]`。

返回从下标 `0` 跳到下标 `n - 1` 所能获得的**最大总分**。

**示例 1：**
```
输入：nums = [1,3,3,3,4]
输出：25
解释：从 0 -> 4，得分 = 4 * 4 = 16；或 0 -> 1 -> 4，得分 = 1*3 + 3*4 = 15；最优路径 0 -> 4，得分 25-不对，重新分析。
```

**提示：**
- `2 <= nums.length <= 10^3`
- `0 <= nums[i] <= 10^5`

## 解题思路

**贪心思路**：对于每次跳跃，只有跳到"之后最大值"才有意义。

使用单调栈，维护一个从右往左的递减序列。对于每个位置，只考虑跳到其右边的最大值位置。

实际上，最优策略是：从每个位置出发，贪心地跳到其右侧比当前更大的第一个数（单调栈中的下一个元素）。

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        # 用单调递减栈找出所有"有价值"的跳跃点
        # 从右到左维护单调递减栈
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] <= nums[i]:
                stack.pop()
            stack.append(i)
        stack.reverse()  # 现在从左到右，单调递增

        ans = 0
        # 按单调栈中的点顺序跳跃
        prev = 0
        for i in range(1, len(stack)):
            j = stack[i]
            p = stack[i - 1]
            ans += (j - p) * nums[j]
        return ans
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        # dp[i] 表示从下标 0 到下标 i 的最大得分
        dp = [0] * n
        for j in range(1, n):
            for i in range(j):
                dp[j] = max(dp[j], dp[i] + (j - i) * nums[j])
        return dp[n - 1]
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n^2)，空间复杂度 O(n)

## 关键点总结

1. 贪心策略：只跳到"单调递增"的关键节点
2. 单调栈可以高效找出这些关键节点
3. 跳过的中间节点不会带来更高收益

## 易错点

1. 注意跳跃时 j > i 严格大于
2. 单调栈方向要弄清楚
