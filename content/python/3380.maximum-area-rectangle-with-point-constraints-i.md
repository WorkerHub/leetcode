## 题目描述

给你一个二维平面上的点集 `points`，其中每个点是 `(x, y)`。

找一个**轴对齐矩形**（边与坐标轴平行），满足：
1. 矩形的四个顶点都在 `points` 中。
2. 矩形内部（不包括边界）**没有任何 `points` 中的点**。

返回满足条件的最大矩形面积，若不存在则返回 -1。

**提示：**
- `1 <= points.length <= 10`（数据很小）

## 解题思路

由于数据量极小（n <= 10），可以枚举所有四边形的四个顶点组合，检验是否形成轴对齐矩形且内部无点。

枚举两个 x 坐标（矩形的左右边）和两个 y 坐标（矩形的上下边），检验四个角是否都在 points 中，且矩形内部无点。

## Python 代码实现

### 方法一：枚举四点组合（推荐）

```python
from typing import List
from itertools import combinations

class Solution:
    def maxRectangleArea(self, points: List[List[int]]) -> int:
        point_set = set(map(tuple, points))
        xs = sorted(set(p[0] for p in points))
        ys = sorted(set(p[1] for p in points))
        
        best = -1
        
        # 枚举两个 x 坐标（左右边）
        for i in range(len(xs)):
            for j in range(i + 1, len(xs)):
                x1, x2 = xs[i], xs[j]
                # 枚举两个 y 坐标（上下边）
                for k in range(len(ys)):
                    for l in range(k + 1, len(ys)):
                        y1, y2 = ys[k], ys[l]
                        
                        # 检查四个角是否都在 points 中
                        corners = [(x1, y1), (x1, y2), (x2, y1), (x2, y2)]
                        if not all(c in point_set for c in corners):
                            continue
                        
                        # 检查矩形内部（严格内部）是否有 points 中的点
                        has_inner = False
                        for p in points:
                            px, py = p
                            if x1 < px < x2 and y1 < py < y2:
                                has_inner = True
                                break
                        
                        if not has_inner:
                            area = (x2 - x1) * (y2 - y1)
                            best = max(best, area)
        
        return best
```

## 复杂度分析

- 时间复杂度：O(n^5)，枚举 4 组坐标 * n 个点检验（但 n <= 10，实际很快）
- 空间复杂度：O(n)

## 关键点总结

1. 轴对齐矩形由左右 x 坐标和上下 y 坐标确定。
2. 四个角都在 points 中。
3. 矩形严格内部（不含边界）无其他点。

## 易错点

1. 严格内部：`x1 < px < x2 AND y1 < py < y2`（不含边界上的点）。
2. 枚举时 x1 < x2，y1 < y2（确保是矩形，不是线段）。
3. 数据量小（n <= 10），暴力即可。
