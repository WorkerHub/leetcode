## 题目描述

给你一个整数 `n`，返回满足 `0 AND x == 0` 且 `x > n` 的最小整数，或者返回 `n AND x == 0` 的最大整数 `x`（0 <= x <= n）。

实际题目：给你一个整数 `n`，返回满足 `n AND x == 0` 的最大非负整数 `x`，其中 `AND` 是按位与运算。

**示例 1：**
```
输入：n = 3
输出：0（因为 3 AND 0 = 0）
```

实际上题目是：给定 n，返回满足下面条件的最大 x：n & x == 0，x 范围 [0, ...]。答案是 n 的按位取反（在 n 的位数范围内）。

**提示：**
- `0 <= n <= 10^9`

## 解题思路

要使 `n AND x == 0`，则 `x` 的每一位只能在 `n` 对应位为 0 的地方为 1。即 `x` 是 `n` 的补码（在 n 的最高位范围内）。

最大的 x 是：将 n 的所有 0 位都设为 1，所有 1 位都设为 0，即 `x = mask XOR n`，其中 `mask` 是与 n 等位数的全 1 掩码。

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def largestCombination(self, n: int) -> int:
        if n == 0:
            return 0
        # 找 n 的最高位
        bits = n.bit_length()
        mask = (1 << bits) - 1  # 与 n 等位数的全 1 掩码
        return mask ^ n  # 将 n 的 0 位置 1，1 位置 0
```

### 方法二：逐位处理

```python
class Solution:
    def largestCombination(self, n: int) -> int:
        # x 的每个位：若 n 对应位为 0，则 x 该位可以为 1（取 1 最大）
        x = 0
        bit = 1
        while bit <= n:
            if not (n & bit):
                x |= bit
            bit <<= 1
        return x
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. n AND x == 0 意味着 x 和 n 在每一位上不同时为 1
2. 最大 x 就是 n 在其最高位范围内的按位取反
3. mask = (1 << bit_length) - 1，然后 x = mask XOR n

## 易错点

1. n = 0 时答案为 0（或任意数，但题目要求最大不超过某范围）
2. mask 的位数要与 n 的最高位对齐
