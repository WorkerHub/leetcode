## 题目描述

如果字符串 `s` 满足以下条件，则称其为 **快乐字符串**：

- `s` 只包含小写字母 `['a', 'b', 'c']`
- `s` 中所有相邻字母都不相同，即对 `1 <= i < s.length`，有 `s[i] != s[i-1]`

给你两个整数 `n` 和 `k`，按字典序排列所有长度为 `n` 的快乐字符串，返回第 `k` 个（1-indexed）。若不存在第 `k` 个，返回空字符串 `""`。

**示例 1：**

```
输入：n = 1, k = 3
输出："c"
解释：长度为 1 的快乐字符串：["a", "b", "c"]，第 3 个是 "c"。
```

**示例 2：**

```
输入：n = 1, k = 4
输出：""
解释：只有 3 个，不存在第 4 个。
```

**示例 3：**

```
输入：n = 3, k = 9
输出："cab"
解释：长度为 3 的快乐字符串按字典序排列：
["aba","abc","aca","acb","bab","bac","bca","bcb","cab","cac","cba","cbc"]
第 9 个是 "cab"。
```

**提示：**

- `1 <= n <= 10`
- `1 <= k <= 100`

## 解题思路

### 方法一：回溯法（推荐）

用回溯依次生成所有快乐字符串，按字典序排列（天然有序，因为我们按 a, b, c 顺序尝试），找到第 k 个即可。

长度为 n 的快乐字符串总数为 `3 * 2^(n-1)`（第一位 3 种选择，之后每位 2 种选择），最多 `3 * 2^9 = 1536` 个，完全可以枚举。

### 方法二：数学直接定位（推荐，不需要枚举所有字符串）

每个位置的字母选择决定了该字母后面有多少种可能的字符串。

设当前已选 `i` 个字母（0-indexed），剩余 `n - i` 个位置待填，且下一个字母不能等于第 `i` 个字母：

- 剩余每个位置有 2 种选择（不等于前一个）
- 从当前位置开始的字符串数量 = `2^(n - i - 1)`（不含当前位置）
- 每个候选字母（共 2 个）对应 `2^(n - i - 1)` 种字符串

通过 k 和 `2^(n-i-1)` 的关系，可以直接确定每个位置的字母。

## Python 代码实现

### 方法一：回溯（直观）

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        results = []

        def backtrack(path: list):
            # 已找够 k 个，提前终止
            if len(results) >= k:
                return

            if len(path) == n:
                # 生成了一个完整的快乐字符串
                results.append("".join(path))
                return

            for c in ['a', 'b', 'c']:
                # 不能与前一个字符相同
                if path and path[-1] == c:
                    continue
                path.append(c)
                backtrack(path)
                path.pop()

        backtrack([])

        return results[k - 1] if k <= len(results) else ""
```

### 方法二：数学直接定位（推荐，最优）

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        # 长度为 n 的快乐字符串总数
        total = 3 * (2 ** (n - 1))
        if k > total:
            return ""

        result = []
        chars = ['a', 'b', 'c']

        # 第一个字符：3 种选择，每种对应 2^(n-1) 个字符串
        group_size = 2 ** (n - 1)
        # 确定第一个字符的索引（0, 1, 或 2）
        idx = (k - 1) // group_size
        result.append(chars[idx])
        k -= idx * group_size  # 更新 k 为在当前组内的排名（1-indexed）

        # 后续字符：每次有 2 种选择（不等于前一个），每种对应 group_size/2 个字符串
        for i in range(1, n):
            group_size //= 2
            # 候选字符：从 ['a', 'b', 'c'] 中去掉前一个字符
            candidates = [c for c in chars if c != result[-1]]
            # 确定选哪个候选字符
            idx = (k - 1) // group_size
            result.append(candidates[idx])
            k -= idx * group_size

        return "".join(result)
```

### 方法三：回溯 + 计数剪枝（更快的回溯）

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        # 计算以 prev_char 结尾、还剩 remaining 个字符的快乐字符串数量
        # 实际上就是 2^(remaining-1) 如果 remaining >= 1 else 1
        # 但更直接：remaining 位的字符串数量 = 2^(remaining-1) 如果有前缀限制

        self.k = k
        self.result = ""

        def backtrack(path: list) -> bool:
            if self.k == 0:
                return True
            if len(path) == n:
                self.k -= 1
                if self.k == 0:
                    self.result = "".join(path)
                    return True
                return False

            remaining = n - len(path)
            # 当前子树中快乐字符串数量：2^(remaining-1) * 候选字符数
            # 第一层有 3 种，后续每层有 2 种
            num_candidates = 3 if not path else 2
            subtree_size = num_candidates * (2 ** (remaining - 1))

            # 如果 k 大于整个子树大小，跳过
            if self.k > subtree_size:
                return False

            for c in ['a', 'b', 'c']:
                if path and path[-1] == c:
                    continue
                path.append(c)
                if backtrack(path):
                    return True
                path.pop()

            return False

        backtrack([])
        return self.result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 回溯 | O(3 * 2^n) | O(n) |
| 数学定位 | O(n) | O(n) |

方法二是最优解，O(n) 直接确定每个字符。

## 图解示例

以 `n=3, k=9` 为例（数学方法）：

```
总数 = 3 * 2^2 = 12，k=9 合法

第1位：group_size = 4
  idx = (9-1)//4 = 2 → 'c'
  k = 9 - 2*4 = 1

第2位：group_size = 2，候选 = ['a', 'b']（不含'c'）
  idx = (1-1)//2 = 0 → 'a'
  k = 1 - 0*2 = 1

第3位：group_size = 1，候选 = ['b', 'c']（不含'a'）
  idx = (1-1)//1 = 0 → 'b'
  k = 1 - 0*1 = 1

结果："cab" ✓
```

## 关键点总结

1. 长度为 n 的快乐字符串总数为 `3 * 2^(n-1)`，超过则返回 ""
2. 数学方法：每个位置通过 `(k-1) // group_size` 确定当前字符
3. 每次更新 k 为组内相对排名：`k -= idx * group_size`
4. 后续每位的候选字符只有 2 个（排除前一个字符）

## 易错点

1. k 是 1-indexed，所以用 `(k-1) // group_size` 而不是 `k // group_size`
2. 第一位有 3 种候选，从第二位开始只有 2 种候选（不等于前一个）
3. `group_size` 在每一步需要减半
