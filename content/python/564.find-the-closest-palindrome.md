## 题目描述

给定一个表示整数的字符串 `n`，返回与它最近的回文整数（不包括自身）。如果有多个结果，返回较小的那个。

"最近的"定义为两个整数差的绝对值最小。

**示例 1：**
```
输入：n = "123"
输出："121"
```

**示例 2：**
```
输入：n = "1"
输出："0"
解释：0 和 2 是最近的回文数，但我们返回最小的，也就是 0。
```

**提示：**
- `1 <= n.length <= 18`
- `n` 只由数字组成
- `n` 不含前导 0
- `n` 代表范围在 `[1, 10^18 - 1]` 内的整数

## 解题思路

这是一道困难的数学题，需要考虑多种情况。

候选回文数：
1. 镜像中间部分（99999 的情况）
2. 镜像中间部分 + 1
3. 镜像中间部分 - 1
4. 10^(n-1) - 1（例如：999）
5. 10^n + 1（例如：10001）

## Python 代码实现

### 方法一：枚举候选（推荐）⭐

```python
class Solution:
    def nearestPalindromic(self, n: str) -> str:
        """
        枚举所有可能的候选回文数
        
        时间复杂度：O(1)，候选数量固定
        空间复杂度：O(1)
        """
        length = len(n)
        num = int(n)
        
        candidates = set()
        
        # 候选1: 999...9 (length - 1 位)
        candidates.add(10**(length - 1) - 1)
        
        # 候选2: 100...001 (length + 1 位)
        candidates.add(10**length + 1)
        
        # 候选3, 4, 5: 基于前半部分的镜像
        prefix = int(n[:(length + 1) // 2])
        for delta in (-1, 0, 1):
            new_prefix = str(prefix + delta)
            # 根据长度奇偶决定镜像方式
            if length % 2 == 0:
                palin = new_prefix + new_prefix[::-1]
            else:
                palin = new_prefix + new_prefix[-2::-1]
            candidates.add(int(palin))
        
        # 移除自身
        candidates.discard(num)
        
        # 找最接近的
        return str(min(candidates, key=lambda x: (abs(x - num), x)))
```

### 方法二：辅助函数版本

```python
class Solution:
    def nearestPalindromic(self, n: str) -> str:
        """
        使用辅助函数构造回文数
        
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        def get_palindrome(half, is_odd):
            """根据前半部分构造回文数"""
            s = str(half)
            if is_odd:
                return int(s + s[-2::-1])
            return int(s + s[::-1])
        
        length = len(n)
        num = int(n)
        is_odd = length % 2 == 1
        mid_length = (length + 1) // 2
        prefix = int(n[:mid_length])
        
        candidates = [
            get_palindrome(prefix, is_odd),
            get_palindrome(prefix + 1, is_odd),
            get_palindrome(prefix - 1, is_odd),
            10**(length - 1) - 1,
            10**length + 1
        ]
        
        candidates = [c for c in candidates if c != num]
        
        return str(min(candidates, key=lambda x: (abs(x - num), x)))
```

## 复杂度分析

- **时间复杂度**：O(1)，候选数量固定（最多 5 个）
- **空间复杂度**：O(1)

## 关键点总结

1. **候选枚举**：关键是找到所有可能的候选
2. **特殊情况**：999, 10001 等边界情况
3. **镜像构造**：根据长度奇偶性构造回文数
4. **最小优先**：距离相同时选较小的

## 易错点

1. **排除自身**：候选中要排除 n 本身
2. **奇偶处理**：长度奇偶影响镜像方式
3. **边界情况**：10^k - 1 和 10^k + 1
4. **最小优先**：key 要使用元组 `(差值, 值)`
