## 题目描述

一个演唱会共有 `n` 排，每排有 `m` 个座位（编号 1 到 m）。

实现 `BookMyShow` 类：

- `BookMyShow(n, m)`：初始化，共 n 排 m 列。
- `gather(k, maxRow)`：将 k 个人安排在同一排，且排号不超过 `maxRow`（0 索引），返回 `[排号, 起始列号]`，若不可能返回 `[]`。
- `scatter(k, maxRow)`：将 k 个人尽量从前到后、从左到右安排在多排，排号不超过 `maxRow`，若不可能返回 `false`，否则安排并返回 `true`。

## 解题思路

**线段树维护区间最大剩余座位数和区间剩余座位总数：**

- `gather(k, maxRow)`：需要找前 `maxRow+1` 排中，某一排剩余 `>= k`，用线段树区间最大值二分找到最前的满足条件的排。
- `scatter(k, maxRow)`：需要前 `maxRow+1` 排总剩余 `>= k`，用线段树区间求和，然后逐排填充（用当前填充指针）。

线段树维护：
1. `max_tree`：区间最大剩余座位数。
2. `sum_tree`：区间剩余座位总数之和。

## 代码实现

### 方法一：线段树（推荐）

```python
class BookMyShow:
    def __init__(self, n: int, m: int):
        self.n = n
        self.m = m
        # 线段树：max_val 和 sum_val
        self.max_tree = [m] * (4 * n)
        self.sum_tree = [m] * (4 * n)
        # 建树
        self._build(1, 0, n - 1)

    def _build(self, node, l, r):
        if l == r:
            self.max_tree[node] = self.m
            self.sum_tree[node] = self.m
            return
        mid = (l + r) // 2
        self._build(2 * node, l, mid)
        self._build(2 * node + 1, mid + 1, r)
        self.max_tree[node] = max(self.max_tree[2 * node], self.max_tree[2 * node + 1])
        self.sum_tree[node] = self.sum_tree[2 * node] + self.sum_tree[2 * node + 1]

    def _update(self, node, l, r, idx, val):
        """将第 idx 排的剩余数量更新为 val"""
        if l == r:
            self.max_tree[node] = val
            self.sum_tree[node] = val
            return
        mid = (l + r) // 2
        if idx <= mid:
            self._update(2 * node, l, mid, idx, val)
        else:
            self._update(2 * node + 1, mid + 1, r, idx, val)
        self.max_tree[node] = max(self.max_tree[2 * node], self.max_tree[2 * node + 1])
        self.sum_tree[node] = self.sum_tree[2 * node] + self.sum_tree[2 * node + 1]

    def _query_max(self, node, l, r, ql, qr):
        """查询 [ql, qr] 内最大剩余"""
        if ql > qr:
            return 0
        if ql == l and qr == r:
            return self.max_tree[node]
        mid = (l + r) // 2
        if qr <= mid:
            return self._query_max(2 * node, l, mid, ql, qr)
        elif ql > mid:
            return self._query_max(2 * node + 1, mid + 1, r, ql, qr)
        else:
            return max(
                self._query_max(2 * node, l, mid, ql, mid),
                self._query_max(2 * node + 1, mid + 1, r, mid + 1, qr)
            )

    def _query_sum(self, node, l, r, ql, qr):
        """查询 [ql, qr] 内总剩余"""
        if ql > qr:
            return 0
        if ql == l and qr == r:
            return self.sum_tree[node]
        mid = (l + r) // 2
        if qr <= mid:
            return self._query_sum(2 * node, l, mid, ql, qr)
        elif ql > mid:
            return self._query_sum(2 * node + 1, mid + 1, r, ql, qr)
        else:
            return (
                self._query_sum(2 * node, l, mid, ql, mid)
                + self._query_sum(2 * node + 1, mid + 1, r, mid + 1, qr)
            )

    def _find_first(self, node, l, r, ql, qr, k):
        """在 [ql, qr] 中找第一个剩余 >= k 的排"""
        if self.max_tree[node] < k or l > qr or r < ql:
            return -1
        if l == r:
            return l
        mid = (l + r) // 2
        left_res = self._find_first(2 * node, l, mid, ql, qr, k)
        if left_res != -1:
            return left_res
        return self._find_first(2 * node + 1, mid + 1, r, ql, qr, k)

    # 当前 scatter 的填充位置
    def _get_row_remain(self, row):
        return self._query_max(1, 0, self.n - 1, row, row)

    def gather(self, k: int, maxRow: int) -> list:
        # 找 [0, maxRow] 中第一个剩余 >= k 的排
        row = self._find_first(1, 0, self.n - 1, 0, maxRow, k)
        if row == -1:
            return []
        # 当前该排的剩余量
        remain = self._get_row_remain(row)
        col = self.m - remain  # 起始列（0 索引）
        # 更新该排剩余
        self._update(1, 0, self.n - 1, row, remain - k)
        return [row, col]

    def scatter(self, k: int, maxRow: int) -> bool:
        # 检查总剩余是否足够
        total = self._query_sum(1, 0, self.n - 1, 0, maxRow)
        if total < k:
            return False

        # 从第一个有剩余的排开始填充
        # 用二分找第一个有剩余的排
        remaining = k
        row = self._find_first(1, 0, self.n - 1, 0, maxRow, 1)
        while remaining > 0 and row <= maxRow:
            r = self._get_row_remain(row)
            take = min(r, remaining)
            self._update(1, 0, self.n - 1, row, r - take)
            remaining -= take
            if remaining > 0:
                row = self._find_first(1, 0, self.n - 1, row + 1, maxRow, 1)
        return True
```

## 复杂度分析

- `gather`：O(log n)，线段树查找 + 更新。
- `scatter`：O(k log n)，最坏情况逐排填充（均摊 O(log^2 n)）。
- 空间复杂度：O(n)，线段树数组。

## 关键点总结

1. 线段树同时维护区间最大值（用于 `gather`）和区间求和（用于 `scatter`）。
2. `_find_first` 在线段树上二分，找最前面满足剩余 `>= k` 的叶子。
3. `scatter` 从最前有剩余的排依次填充，每次找下一个有剩余的排。

## 易错点

- 列号是 0 索引：`col = m - remain`（已预订的座位数即为起始列）。
- `scatter` 中需要重新查找下一个有剩余的排，而不是简单 row += 1。
