## 题目描述

给定一个 `m × n` 的整数矩阵 `grid`，其中 `grid[i][j]` 表示在时间 `t < grid[i][j]` 时不能进入该单元格。从 `(0,0)` 出发（时间 0 可进入），每次移动到相邻单元格耗时 1。

求到达 `(m-1, n-1)` 的最短时间，若无法到达返回 `-1`。

**示例 1：**
```
输入：grid = [[0,1,3,2],[5,1,2,5],[4,3,8,6]]
输出：7
解释：时间 7 时到达右下角是最优的。
```

**示例 2：**
```
输入：grid = [[0,2,4],[3,2,1],[1,0,4]]
输出：4
```

**提示：**
- `m == grid.length, n == grid[0].length`
- `2 <= m, n <= 1000`
- `0 <= grid[i][j] <= 10^9`
- `grid[0][0] == 0`

## 解题思路

最短时间 BFS / Dijkstra 变体（类似于 LeetCode 2577）。

用优先队列（最小堆），维护 `(当前时间, 行, 列)`。

对于移动到 `(ni, nj)`，到达时间为：
- 若当前时间 + 1 >= `grid[ni][nj]`，则到达时间 = 当前时间 + 1。
- 若当前时间 + 1 < `grid[ni][nj]`，需要等待，但等待时可以在两个格子来回移动（若允许），将时间"蹦"到满足条件的最早时刻：
  - 需要的等待步数 = `grid[ni][nj] - (当前时间 + 1)`
  - 若等待步数为偶数，到达时间 = `grid[ni][nj]`
  - 若等待步数为奇数，到达时间 = `grid[ni][nj] + 1`

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 若起点的上方和左方都无法移动，则无法通过等待绕路
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]  # (时间, 行, 列)
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while heap:
            t, i, j = heapq.heappop(heap)
            if i == m - 1 and j == n - 1:
                return t
            if t > dist[i][j]:
                continue
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    # 计算到达 (ni,nj) 的最早时间
                    wait = max(0, grid[ni][nj] - t - 1)
                    # 若 wait 为奇数，需要额外 +1（来回等待）
                    arrive = t + 1 + wait
                    if wait % 2 == 1:
                        arrive += 1
                    if arrive < dist[ni][nj]:
                        dist[ni][nj] = arrive
                        heapq.heappush(heap, (arrive, ni, nj))

        return -1
```

### 方法二：BFS（适用于 grid 值较小时）

```python
from typing import List
from collections import deque

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        # 当 grid 值有界时可用 BFS（Dijkstra 更通用）
        # 此处用 Dijkstra
        import heapq
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        while heap:
            t, i, j = heapq.heappop(heap)
            if t > dist[i][j]:
                continue
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    diff = grid[ni][nj] - t - 1
                    if diff <= 0:
                        arrive = t + 1
                    elif diff % 2 == 0:
                        arrive = grid[ni][nj]
                    else:
                        arrive = grid[ni][nj] + 1
                    if arrive < dist[ni][nj]:
                        dist[ni][nj] = arrive
                        heapq.heappush(heap, (arrive, ni, nj))

        return dist[m-1][n-1] if dist[m-1][n-1] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))，Dijkstra
- 空间复杂度：O(mn)

## 关键点总结

1. 时间约束的格子可以通过"来回等待"提前满足，等待奇偶性决定到达时间
2. 若起点周围均受限（grid 值 > 1），可能无法到达终点
3. 此问题是 LeetCode 2577 的扩展版本

## 易错点

1. 不能简单地等到 `grid[ni][nj]` 时刻，需要考虑奇偶性（等待时来回移动）
2. 特判起点四邻域全部受限的情况
