## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

如果 `nums` 从下标 `l` 到 `r`（包含两端）的子数组满足以下条件，则该子数组为 **交替子数组**：

- `nums[l] % 2 == 0`
- 对所有 `l <= i < r`，`nums[i] % 2 != nums[i + 1] % 2`（奇偶交替）

返回所有 **交替子数组** 中最长的长度，如果不存在则返回 -1。

**示例 1：**
```
输入：nums = [2,3,4,3,4]
输出：4
解释：子数组 [2,3,4,3]，起始偶数，奇偶交替，长度 4
```

**示例 2：**
```
输入：nums = [4,5,6]
输出：2
解释：子数组 [4,5]，长度 2；[6] 不算（长度1且起始偶数，也算）
```

**提示：**
- `1 <= nums.length <= 100`

## 解题思路

枚举每个偶数起点，向右延伸，统计最大长度。

## Python 代码实现

### 方法一：枚举起点（推荐）

```python
from typing import List

class Solution:
    def alternatingSubarray(self, nums: List[int]) -> int:
        n = len(nums)
        ans = -1

        for i in range(n):
            if nums[i] % 2 != 0:
                continue
            # 从 i 向右延伸
            length = 1
            for j in range(i + 1, n):
                if nums[j] % 2 == nums[j - 1] % 2:
                    break
                length += 1
            ans = max(ans, length)

        return ans
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def alternatingSubarray(self, nums: List[int]) -> int:
        n = len(nums)
        ans = -1
        i = 0
        while i < n:
            if nums[i] % 2 != 0:
                i += 1
                continue
            j = i + 1
            while j < n and nums[j] % 2 != nums[j - 1] % 2:
                j += 1
            ans = max(ans, j - i)
            # 下一个起点可以从 i+1 开始（若 i+1 是偶数），避免跳过
            i += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法二）或 O(n^2)（方法一最坏）
- 空间复杂度：O(1)

## 关键点总结

1. 起点必须是偶数
2. 奇偶严格交替
3. 长度为 1（只有起点）的子数组也合法

## 易错点

1. 起点必须是偶数，不要遗漏这个条件
2. 若不存在任何合法子数组（全为奇数），返回 -1
