## 题目描述

给你一个字符串数组 `words`，找出并返回数组中第一个**回文字符串**。如果不存在回文字符串，返回一个**空字符串** `""`。

**回文字符串**是正读和反读都相同的字符串。

**示例 1：**
```
输入：words = ["abc","car","ada","racecar","cool"]
输出："ada"
解释：第一个回文字符串是 "ada"。
```

**示例 2：**
```
输入：words = ["notapalindrome","racecar"]
输出："racecar"
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 仅由小写英文字母组成

## 解题思路

遍历数组，对每个字符串判断是否为回文，返回第一个满足条件的字符串。

判断回文的两种方式：
1. 直接比较 `s == s[::-1]`（Python 切片反转）。
2. 双指针从两端向中间比较。

## 代码实现

### 方法一：Python 切片（推荐简洁）

```python
from typing import List

class Solution:
    def firstPalindrome(self, words: List[str]) -> str:
        for word in words:
            # Python 字符串反转比较
            if word == word[::-1]:
                return word
        return ""
```

### 方法二：双指针判断回文

```python
from typing import List

class Solution:
    def firstPalindrome(self, words: List[str]) -> str:
        def is_palindrome(s: str) -> bool:
            # 双指针从两端向中间比较
            l, r = 0, len(s) - 1
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        for word in words:
            if is_palindrome(word):
                return word
        return ""
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 切片 | O(n * m)，m 为平均长度 | O(m)（切片创建新字符串） |
| 双指针 | O(n * m) | O(1) |

## 关键点总结

1. Python 中 `s[::-1]` 快速反转字符串，代码最简洁。
2. 双指针方法空间 O(1)，适合对空间有要求的场景。
3. 找到第一个即返回，无需遍历全部。

## 易错点

- 未找到时记得返回空字符串 `""`，而非 `None`。
- 双指针结束条件是 `l < r`，不能是 `l <= r`（否则奇数长度时中间字符会自比较）。
