## 题目描述

给你一个正整数 `n`，表示 0 到 `n-1` 共 `n` 个节点。同时给你一个二维整数数组 `edges`，其中 `edges[i] = [ui, vi]` 表示节点 `ui` 和 `vi` 之间有一条无向边。

返回图中最短环的长度，若不存在环则返回 -1。

**示例 1：**
```
输入：n = 7, edges = [[0,1],[1,2],[2,0],[3,4],[4,5],[5,6],[6,3]]
输出：3
```

**示例 2：**
```
输入：n = 4, edges = [[0,1],[0,2]]
输出：-1
```

**数据范围：**
- 2 <= n <= 1000
- 1 <= edges.length <= 1000
- edges[i].length == 2
- 0 <= ui, vi < n
- ui != vi
- 不存在重复边

## 解题思路

从每个节点出发做 BFS，记录每个节点的 BFS 层数（距离）。当遍历一条边 `(u, v)` 时，若 `v` 已被访问过（且不是 `u` 的父节点），则发现了一个环，环长 = `dist[u] + dist[v] + 1`。

对所有节点做 BFS，取最小环长。

## Python 代码实现

### 方法一：每个节点出发 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def findShortestCycle(self, n: int, edges: List[List[int]]) -> int:
        # 建无向图邻接表
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = float('inf')

        def bfs(start):
            dist = [-1] * n
            dist[start] = 0
            queue = deque([(start, -1)])  # (节点, 父节点)
            nonlocal ans
            while queue:
                u, parent = queue.popleft()
                for v in graph[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        queue.append((v, u))
                    elif v != parent:
                        # 发现一条回边，构成环
                        cycle_len = dist[u] + dist[v] + 1
                        ans = min(ans, cycle_len)

        for i in range(n):
            bfs(i)

        return ans if ans != float('inf') else -1
```

### 方法二：使用 dist 数组简化

```python
from typing import List
from collections import deque

class Solution:
    def findShortestCycle(self, n: int, edges: List[List[int]]) -> int:
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        min_cycle = float('inf')

        for src in range(n):
            # BFS 从 src 出发
            dist = [-1] * n
            dist[src] = 0
            parent = [-1] * n
            q = deque([src])

            while q:
                u = q.popleft()
                for v in adj[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        parent[v] = u
                        q.append(v)
                    elif parent[u] != v:
                        # 回边，形成环
                        min_cycle = min(min_cycle, dist[u] + dist[v] + 1)

        return -1 if min_cycle == float('inf') else min_cycle
```

## 复杂度分析

- 时间复杂度：O(n * (n + m))，每个节点做一次 BFS，BFS 的时间复杂度为 O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. 从每个节点出发 BFS，当发现已访问邻居（非父节点）时就找到了环
2. 环长 = 两端到起点的距离之和 + 1
3. 遍历所有起点取最小值

## 易错点

1. 无向图中处理父节点，避免将回边误认为成环（实际上 `parent != v` 时才是回边）
2. 有重边时需要特别处理（本题无重边，不需额外处理）
3. 完全不连通的图可能返回 -1
