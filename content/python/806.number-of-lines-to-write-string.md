## 题目描述

我们要把给定的字符串 `s` 写到宽度为 `100` 个单位的纸上。字母 `'a'` 到 `'z'` 的每一个都有一个特定的宽度 `widths[0]` 到 `widths[25]`。

现在，我们想要写字符串 `s`（按照给定顺序）到纸上。我们使用以下规则：
- 如果当前行的剩余空间不足以容纳下一个字符，我们就换一行
- 每一行最多可以容纳 `100` 个单位的宽度

返回一个长度为 2 的数组 `result`：
- `result[0]` 是所需的行数
- `result[1]` 是最后一行使用的宽度

**示例 1:**
```
输入: widths = [10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10], s = "abcdefghijklmnopqrstuvwxyz"
输出: [3,60]
解释:
所有的字符拥有相同的宽度 10。所以语句可以被分为三行，每行 10 个字符。
第一行: abcdefghij (100 units)
第二行: klmnopqrst (100 units)
第三行: uvwxyz (60 units)
```

**示例 2:**
```
输入: widths = [4,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10], s = "bbbcccdddaaa"
输出: [2,4]
解释:
除了 'a' 占用 4 个单位外，其余字符都占用 10 个单位。
我们可以将字符串分为两行:
第一行: bbbcccddd (98 units)
第二行: aaa (12 units)
注意 aaa 不能放在第一行，因为会超过 100 个单位。
```

**提示:**
- `widths.length == 26`
- `2 <= widths[i] <= 10`
- `1 <= s.length <= 1000`
- `s` 只包含小写英文字母

## 解题思路

这是一道简单的模拟题。核心思路是遍历字符串，累计每个字符的宽度，当超过 100 时换行。

**步骤：**
1. 初始化行数为 1，当前行宽度为 0
2. 遍历字符串中的每个字符
3. 获取字符对应的宽度
4. 如果加上当前字符宽度超过 100，则换行，并将当前字符放到新行
5. 否则，将字符宽度累加到当前行
6. 返回行数和最后一行的宽度

## Python 代码实现

### 方法一：直接模拟（推荐）⭐

```python
from typing import List

class Solution:
    def numberOfLines(self, widths: List[int], s: str) -> List[int]:
        lines = 1  # 至少需要一行
        current_width = 0  # 当前行的宽度
        
        for char in s:
            # 获取字符的宽度
            char_width = widths[ord(char) - ord('a')]
            
            # 如果当前行放不下，换行
            if current_width + char_width > 100:
                lines += 1
                current_width = char_width
            else:
                current_width += char_width
        
        return [lines, current_width]
```

### 方法二：简化版本

```python
from typing import List

class Solution:
    def numberOfLines(self, widths: List[int], s: str) -> List[int]:
        lines, width = 1, 0
        
        for c in s:
            w = widths[ord(c) - ord('a')]
            if width + w > 100:
                lines, width = lines + 1, w
            else:
                width += w
        
        return [lines, width]
```

### 方法三：使用字典映射

```python
from typing import List

class Solution:
    def numberOfLines(self, widths: List[int], s: str) -> List[int]:
        # 创建字符到宽度的映射
        char_width = {chr(ord('a') + i): widths[i] for i in range(26)}
        
        lines = 1
        current_width = 0
        
        for char in s:
            w = char_width[char]
            if current_width + w > 100:
                lines += 1
                current_width = w
            else:
                current_width += w
        
        return [lines, current_width]
```

### 方法四：函数式编程风格

```python
from typing import List
from functools import reduce

class Solution:
    def numberOfLines(self, widths: List[int], s: str) -> List[int]:
        def process_char(state, char):
            lines, width = state
            char_width = widths[ord(char) - ord('a')]
            
            if width + char_width > 100:
                return (lines + 1, char_width)
            else:
                return (lines, width + char_width)
        
        return list(reduce(process_char, s, (1, 0)))
```

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 是字符串 s 的长度，需要遍历一次
- **空间复杂度**：O(1)，只使用常量额外空间

## 关键点总结

1. **模拟过程**：按照题目描述直接模拟排版过程
2. **换行判断**：当前宽度 + 字符宽度 > 100 时换行
3. **字符索引**：通过 `ord(char) - ord('a')` 获取字符在字母表中的位置
4. **初始状态**：至少有一行，初始宽度为 0
5. **边界处理**：最后一个字符的宽度需要记录

## 易错点

1. **初始行数**：应该初始化为 1 而不是 0
2. **换行后的宽度**：换行后当前字符放在新行，宽度应该是该字符的宽度
3. **等于 100**：如果正好等于 100，不需要换行
4. **最后一行**：返回的是最后一行的实际宽度，不是 100
