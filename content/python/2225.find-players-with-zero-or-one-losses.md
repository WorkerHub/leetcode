## 题目描述

给你一个整数数组 `matches`，其中 `matches[i] = [winner_i, loser_i]` 表示第 `i` 场比赛的胜者和败者。

返回一个长度为 2 的列表 `answer`：
- `answer[0]` 是所有没有输过比赛的玩家的列表（排序）。
- `answer[1]` 是恰好输了一场比赛的玩家的列表（排序）。

结果列表必须按升序排列。

**示例 1：**
```
输入：matches = [[1,3],[2,3],[3,6],[5,6],[5,7],[4,5],[4,8],[4,9],[10,4],[10,9]]
输出：[[1,2,10],[4,5,7,8]]
```

**示例 2：**
```
输入：matches = [[2,3],[1,3],[5,4],[6,4]]
输出：[[1,2,5,6],[]]
```

## 解题思路

统计每个玩家的失败次数：
- 失败次数 = 0：进入 `answer[0]`（但必须参加过比赛）。
- 失败次数 = 1：进入 `answer[1]`。

遍历所有比赛，用字典统计每个人的败场数，同时记录所有参赛玩家。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findWinners(self, matches: List[List[int]]) -> List[List[int]]:
        # 统计每位玩家的失败次数（初始为0）
        loss_count = defaultdict(int)

        for winner, loser in matches:
            if winner not in loss_count:
                loss_count[winner] = 0  # 确保胜者也被记录
            loss_count[loser] += 1

        no_loss = []    # 从未失败
        one_loss = []   # 恰好失败一次

        for player, losses in loss_count.items():
            if losses == 0:
                no_loss.append(player)
            elif losses == 1:
                one_loss.append(player)

        return [sorted(no_loss), sorted(one_loss)]
```

### 方法二：集合操作

```python
from typing import List

class Solution:
    def findWinners(self, matches: List[List[int]]) -> List[List[int]]:
        from collections import Counter

        # 所有参赛玩家
        all_players = set()
        # 失败次数统计
        loss_cnt = Counter()

        for w, l in matches:
            all_players.add(w)
            all_players.add(l)
            loss_cnt[l] += 1

        no_loss = sorted(p for p in all_players if loss_cnt[p] == 0)
        one_loss = sorted(p for p in all_players if loss_cnt[p] == 1)

        return [no_loss, one_loss]
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导，n 为玩家总数。
- 空间复杂度：O(n)，哈希表存储。

## 关键点总结

1. 需要区分"完全没输过"和"恰好输一次"。
2. 胜者也可能在其他比赛中输过，不能简单地把所有胜者加入 `answer[0]`。
3. 结果需要排序。

## 易错点

- 只赢过比赛但也输过其他场的玩家，不应进入 `answer[0]`。
- 需要确保只赢过没输过的玩家也被记录在字典中（初始化为 0）。
