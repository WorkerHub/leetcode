## 题目描述

给你一维数轴上共有 `n+1` 个点，点的位置为 `0` 到 `n`。给你一个整数 `k`，请你返回所有 **k 个互不重叠的线段**的方案数，线段端点必须是整数点，并且线段长度至少为 1。

由于答案可能很大，请将答案对 `10^9 + 7` 取余后返回。

**示例：**
```
输入：n = 2, k = 1
输出：3
解释：[0,1], [0,2], [1,2]

输入：n = 3, k = 2
输出：5
```

**提示：**
- `2 <= n <= 1000`
- `1 <= k <= n/2`

## 解题思路

**数学转化：** k 个线段，每个长度至少 1，端点可以共享（即端点可以相同）。

可以用**隔板法**：将问题转化为组合数。

k 个线段需要 2k 个端点，但相邻线段可以共享端点。我们有 n+1 个点（0 到 n），等价于从 n+1 个点中选 k 个线段（每个线段贡献 2 个端点，但可以共享）。

**等价问题：** 在 n+2k 个点中选 2k 个点的方案数（通过变量替换），结果为 `C(n+k, 2k)`。

但动态规划更直观，可以避免记错公式。

**DP 定义：** `dp[i][j]` = 前 i 个点中选 j 个线段的方案数（线段右端点在 i 处，且不同结尾状态）。

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i][j][0]: 点 i 没有线段在此结尾时，选了 j 个线段的方案数
        # dp[i][j][1]: 点 i 有线段在此结尾时，选了 j 个线段的方案数
        # 状态转移：
        # dp[i][j][0] = dp[i-1][j][0] + dp[i-1][j][1]（点 i 不作为线段右端）
        # dp[i][j][1] = dp[i][j-1][0] + dp[i][j][1]（点 i 是线段右端，扩展或新建）
        
        # 简化：dp[i][j] = 使用前 i+1 个点，选 j 条线段的方案数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = 1  # 不选任何线段，有 1 种方案
        
        # 用前缀和优化
        # 实际上使用组合数公式更简单
        
        # 隔板法：C(n+k, 2k)
        # 选 k 个不重叠线段 = 在 n + k 个元素中选 2k 个
        # 使用 Python 的 math.comb
        import math
        return math.comb(n + k, 2 * k) % MOD
```

### 方法二：标准 DP（前缀和优化）

```python
class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i][j][s]: 考虑到点 i，已选 j 个线段，s=0 表示点 i 不在线段末尾，s=1 表示在
        # 初始化
        dp = [[[0, 0] for _ in range(k + 1)] for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0][0] = 1
        
        for i in range(1, n + 1):
            for j in range(1, k + 1):
                # 点 i 不是线段末尾
                dp[i][j][0] = (dp[i-1][j][0] + dp[i-1][j][1]) % MOD
                # 点 i 是线段末尾（新建 or 延伸）
                dp[i][j][1] = (dp[i-1][j-1][0] + dp[i-1][j-1][1] + dp[i][j][1]) % MOD
                # 上面 dp[i][j][1] 右边包含自己需要注意顺序
        
        # 实际等价于 C(n+k, 2k)
        import math
        return math.comb(n + k, 2 * k) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 组合数公式 | O(n + k) | O(1) |
| DP | O(n * k) | O(n * k) |

## 关键点总结

1. k 个不重叠线段（端点可共享）的方案数等于 `C(n+k, 2k)`
2. 变量替换的关键思想：将共享端点变为独立端点，拓展问题空间
3. Python 的 `math.comb` 可以直接计算组合数
4. DP 方法使用两个状态（是否以点 i 为线段末尾）

## 易错点

- 线段**可以**共享端点（即相邻线段可以连续），不是严格不重叠
- 需要对 `10^9 + 7` 取模
- 组合数公式：`C(n+k, 2k)`，注意 n 和 k 的对应关系
