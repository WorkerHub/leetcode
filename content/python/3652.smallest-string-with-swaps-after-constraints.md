## 题目描述

给你一个字符串 `s` 和一组配对下标 `pairs`，其中 `pairs[i] = [a, b]` 表示可以交换 `s[a]` 和 `s[b]`（可以重复任意次）。

返回交换后字典序最小的字符串。

**示例 1：**

```
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
```

**示例 2：**

```
输入：s = "dcab", pairs = [[0,3],[1,2],[0,2]]
输出："abcd"
```

**提示：**

- `1 <= s.length <= 10^5`
- `0 <= pairs.length <= 10^5`
- `0 <= pairs[i][0], pairs[i][1] < s.length`

## 解题思路

并查集找连通分量，同一连通分量内的字符可以任意排列。对每个分量的字符排序后按原下标顺序填入。

## Python 代码实现

### 方法一：并查集 + 排序（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        for a, b in pairs:
            union(a, b)

        # 按连通分量分组
        groups = defaultdict(list)
        for i in range(n):
            groups[find(i)].append(i)

        result = list(s)
        for group in groups.values():
            chars = sorted(s[i] for i in group)
            for i, idx in enumerate(sorted(group)):
                result[idx] = chars[i]

        return ''.join(result)
```

### 方法二：DFS 找连通分量

```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        graph = defaultdict(list)
        for a, b in pairs:
            graph[a].append(b)
            graph[b].append(a)

        visited = [False] * n
        result = list(s)

        for start in range(n):
            if not visited[start]:
                # BFS 找连通分量
                from collections import deque
                comp = []
                queue = deque([start])
                visited[start] = True
                while queue:
                    node = queue.popleft()
                    comp.append(node)
                    for nb in graph[node]:
                        if not visited[nb]:
                            visited[nb] = True
                            queue.append(nb)
                # 排序后按顺序填入
                chars = sorted(s[i] for i in comp)
                for i, idx in enumerate(sorted(comp)):
                    result[idx] = chars[i]

        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O((n + E) * alpha(n) + n log n)
- 空间复杂度：O(n + E)

## 关键点总结

1. 可以传递交换：a-b 和 b-c 可以连接，a-b-c 可以任意排列
2. 并查集找连通分量
3. 每个分量内字符排序，按原下标顺序填入

## 易错点

1. 交换是可传递的，用并查集合并，不是只考虑直接相连的对
2. 填入时，分量内的原下标需排序（保证字典序最小）
3. `sorted(group)` 而非直接枚举
