## 题目描述

给你一个 `n x n` 整数矩阵 `grid`，其中 `grid[row][col]` 表示在 `(row, col)` 处的骑士的访问顺序（从 1 开始）。

骑士访问序列（从 1 到 n*n）若合法，则相邻两步之间的移动符合国际象棋骑士的走法（L 形移动：横纵之一差 2，另一差 1）。

如果 `grid` 表示了骑士的一次合法游览，则返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：grid = [[0,11,16,5,20],[17,4,19,10,15],[12,1,8,13,6],[3,18,23,14,9],[24,7,2,21,22]]
输出：true
```

**示例 2：**

```
输入：grid = [[0,3,6],[5,8,1],[2,7,4]]
输出：false
```

**提示：**

- `n == grid.length == grid[i].length`
- `3 <= n <= 7`
- `0 <= grid[row][col] < n * n`
- `grid` 中的所有整数互不相同

## 解题思路

**模拟验证**：

1. 记录每个序号对应的坐标
2. 按序号 0, 1, 2, ..., n*n-1 顺序检查相邻两步是否是合法骑士移动

骑士合法移动：行差为 1 列差为 2，或行差为 2 列差为 1（绝对值）。

## Python 代码实现

### 方法一：位置映射 + 逐步验证（推荐）

```python
from typing import List

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        # 记录每个序号对应的 (行, 列)
        pos = [None] * (n * n)
        for r in range(n):
            for c in range(n):
                pos[grid[r][c]] = (r, c)

        # 起点必须是 (0, 0)
        if pos[0] != (0, 0):
            return False

        # 验证相邻步之间是否是合法骑士移动
        for i in range(1, n * n):
            r1, c1 = pos[i - 1]
            r2, c2 = pos[i]
            dr, dc = abs(r2 - r1), abs(c2 - c1)
            # 骑士 L 形：(1,2) 或 (2,1)
            if not ((dr == 1 and dc == 2) or (dr == 2 and dc == 1)):
                return False

        return True
```

### 方法二：直接从矩阵中遍历

```python
from typing import List

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        if grid[0][0] != 0:
            return False

        # 构建 step -> (row, col) 映射
        step_to_pos = {}
        for r in range(n):
            for c in range(n):
                step_to_pos[grid[r][c]] = (r, c)

        for step in range(n * n - 1):
            r1, c1 = step_to_pos[step]
            r2, c2 = step_to_pos[step + 1]
            dr = abs(r2 - r1)
            dc = abs(c2 - c1)
            if sorted([dr, dc]) != [1, 2]:
                return False

        return True
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵和序列各一次
- 空间复杂度：O(n^2)，位置映射数组

## 关键点总结

1. 起点必须是 `grid[0][0] == 0`
2. 骑士移动：行差和列差的绝对值分别为 1 和 2（或 2 和 1）
3. 用 `sorted([dr, dc]) == [1, 2]` 简洁判断合法移动

## 易错点

1. 序号从 0 开始（起点为 0 不是 1）
2. 用绝对值判断差距，不能用带符号的差
3. n 最大为 7，n*n = 49，规模很小，模拟即可
