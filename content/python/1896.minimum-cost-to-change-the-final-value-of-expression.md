## 题目描述

给你一个合法的布尔表达式字符串 `expression`，可以包含 `'1'`、`'0'`、`'&'`（与）、`'|'`（或）和括号。

你可以将表达式中**任意**一个 `1` 改为 `0`，或将 `0` 改为 `1`，或将 `&` 改为 `|`，或将 `|` 改为 `&`。

返回改变表达式**最终值**所需的**最小操作数**。

**示例 1：**
```
输入：expression = "1&(0|1)"
输出：1
解释：将 "1&(0|1)" 改为 "1&(0|0)" 共 1 次操作，结果从 1 变为 0
```

**示例 2：**
```
输入：expression = "(0&0)&(0&0&0)"
输出：3
```

**示例 3：**
```
输入：expression = "(0|(1|0&1))"
输出：1
```

**提示：**
- `1 <= expression.length <= 10^5`
- `expression` 是合法的布尔表达式

## 解题思路

**栈 + DP**：

对每个子表达式维护两个值：
- `cost[0]`：将该子表达式的值变为 `0` 的最小代价
- `cost[1]`：将该子表达式的值变为 `1` 的最小代价

合并规则（以 & 和 | 为例）：

对于 `A op B`，当前值为 `val = A_val op B_val`：

| 目标值 | op=& | op=\| |
|--------|------|-------|
| 0      | min(cost_a[0], cost_b[0]) | cost_a[0] + cost_b[0] |
| 1      | cost_a[1] + cost_b[1] | min(cost_a[1], cost_b[1]) |

但改变操作符也算一次操作：
- `A & B` 改为 `A | B`（花费 1），然后使得结果为目标值

完整推导：

将 `(val_a, cost_a)` 和 `(val_b, cost_b)` 用操作符 `op` 合并，求改变结果的最小代价：

对于每个 `(target_a in {0,1}, target_b in {0,1})`，考虑：
- 选择操作符 `op'`（`op` 不变代价 0，改变代价 1）
- `target_a op' target_b == new_target`，累加 `cost_a[target_a] + cost_b[target_b]`

## 代码实现

### 方法一：栈模拟（推荐）

```python
class Solution:
    def minOperationsToFlip(self, expression: str) -> int:
        # 栈中存储 (val, cost0, cost1)
        # val: 当前表达式的值
        # cost0: 变为 0 的最小代价
        # cost1: 变为 1 的最小代价
        stack = []
        op_stack = []  # 操作符栈

        def combine(a, op, b):
            """合并 a 和 b，op 为操作符，返回 (val, cost0, cost1)"""
            val_a, c0a, c1a = a
            val_b, c0b, c1b = b

            # 当前值
            if op == '&':
                val = val_a & val_b
            else:
                val = val_a | val_b

            # 枚举所有可能的 (target_a, target_b, new_op) 组合
            # new_op 与 op 不同则代价+1
            best0 = float('inf')
            best1 = float('inf')

            for ta in range(2):
                for tb in range(2):
                    ca = c0a if ta == 0 else c1a
                    cb = c0b if tb == 0 else c1b
                    for new_op in ['&', '|']:
                        op_cost = 0 if new_op == op else 1
                        result = ta & tb if new_op == '&' else ta | tb
                        total = ca + cb + op_cost
                        if result == 0:
                            best0 = min(best0, total)
                        else:
                            best1 = min(best1, total)

            return (val, best0, best1)

        i = 0
        while i < len(expression):
            ch = expression[i]
            if ch == '(':
                op_stack.append('(')
            elif ch in '01':
                v = int(ch)
                # 变为 0 代价：v=0 则 0，v=1 则 1
                # 变为 1 代价：v=1 则 0，v=0 则 1
                stack.append((v, v, 1 - v))
            elif ch in '&|':
                op_stack.append(ch)
            elif ch == ')':
                # 弹出括号内的结果
                b = stack.pop()
                op_stack.pop()  # 弹出 '('
                if stack and op_stack and op_stack[-1] in '&|':
                    op = op_stack.pop()
                    a = stack.pop()
                    stack.append(combine(a, op, b))
                else:
                    stack.append(b)
            i += 1

            # 若操作符栈顶有操作符且操作数栈有两个，合并
            while (len(stack) >= 2 and op_stack and
                   op_stack[-1] in '&|' and
                   (i >= len(expression) or expression[i] not in '0123456789(')):
                if i < len(expression) and expression[i] == '(':
                    break
                # 检查下一个字符是否为操作符
                break

        # 合并剩余的操作数和操作符
        while len(op_stack) >= 1 and op_stack[-1] in '&|' and len(stack) >= 2:
            b = stack.pop()
            op = op_stack.pop()
            a = stack.pop()
            stack.append(combine(a, op, b))

        val, cost0, cost1 = stack[0]
        # 返回将当前值改变的代价
        return cost0 if val == 1 else cost1
```

### 方法二：递归解析（更清晰）

```python
class Solution:
    def minOperationsToFlip(self, expression: str) -> int:
        self.i = 0

        def parse():
            """递归解析，返回 (val, cost0, cost1)"""
            left = parse_atom()

            while self.i < len(expression) and expression[self.i] in '&|':
                op = expression[self.i]
                self.i += 1
                right = parse_atom()
                left = combine(left, op, right)

            return left

        def parse_atom():
            ch = expression[self.i]
            self.i += 1
            if ch == '(':
                result = parse()
                self.i += 1  # 跳过 ')'
                return result
            else:
                v = int(ch)
                return (v, v, 1 - v)

        def combine(a, op, b):
            val_a, c0a, c1a = a
            val_b, c0b, c1b = b
            val = (val_a & val_b) if op == '&' else (val_a | val_b)
            best0, best1 = float('inf'), float('inf')
            for ta in range(2):
                for tb in range(2):
                    ca = c0a if ta == 0 else c1a
                    cb = c0b if tb == 0 else c1b
                    for nop in ['&', '|']:
                        oc = 0 if nop == op else 1
                        res = ta & tb if nop == '&' else ta | tb
                        tot = ca + cb + oc
                        if res == 0:
                            best0 = min(best0, tot)
                        else:
                            best1 = min(best1, tot)
            return (val, best0, best1)

        val, cost0, cost1 = parse()
        return cost0 if val == 1 else cost1
```

## 复杂度分析

- **时间复杂度**：O(n)，每个字符处理常数次
- **空间复杂度**：O(n)，栈深度

## 关键点总结

1. 每个子表达式维护 `(val, cost0, cost1)` 三元组
2. 合并时枚举 `(目标a值, 目标b值, 新操作符)` 的所有 8 种组合
3. 改变操作符也算一次操作，代价为 1

## 易错点

- 改变操作符代价为 1，不是 0
- 合并时需要穷举两个操作数的目标值和操作符的所有组合
- 最终答案取「将当前值改变」的代价
