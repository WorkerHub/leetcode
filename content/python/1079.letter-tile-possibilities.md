## 题目描述

你有一套字母瓷砖，每块瓷砖上都刻有一个字母 `tiles[i]`。返回你使用所给字母瓷砖可以组成的**非空字母序列的数量**。

**示例 1：**
```
输入：tiles = "AAB"
输出：8
解释：可能的序列为 "A", "B", "AA", "AB", "BA", "AAB", "ABA", "BAA"
```

**示例 2：**
```
输入：tiles = "AAABBC"
输出：188
```

**示例 3：**
```
输入：tiles = "V"
输出：1
```

**提示：**
- `1 <= tiles.length <= 7`
- `tiles` 由大写英文字母组成

## 解题思路

这是一道经典的**回溯 + 剪枝**问题，需要生成所有可能的排列组合。

### 核心思想

1. **问题拆解**：
   - 需要找出所有长度从 1 到 n 的排列
   - 相同字母的排列视为一种（去重）
   - 例如："AAB" 不能产生两个 "A"（作为不同序列）

2. **回溯框架**：
   - 对于每个位置，尝试放置每种不同的字母
   - 使用频率计数避免重复
   - 每次放置后递归，撤销后继续尝试

3. **去重策略**：
   - 使用字母频率统计（Counter）
   - 每次只选择频率 > 0 的字母
   - 同一层不重复选择相同字母

4. **剪枝优化**：
   - 如果某字母已用完（频率为 0），跳过
   - 每选择一个字母，计数器加 1（因为形成了新序列）

## Python 代码实现

### 方法一：回溯 + 频率统计（推荐）

```python
from collections import Counter

class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        # 统计每个字母的频率
        counter = Counter(tiles)
        
        def backtrack():
            # 计数当前可以形成的序列数
            count = 0
            
            # 尝试每个不同的字母
            for char in counter:
                # 如果该字母还有剩余
                if counter[char] > 0:
                    # 使用这个字母（形成一个新序列）
                    count += 1
                    
                    # 减少该字母的可用数量
                    counter[char] -= 1
                    
                    # 递归计算后续可能的序列
                    count += backtrack()
                    
                    # 回溯：恢复该字母的可用数量
                    counter[char] += 1
            
            return count
        
        return backtrack()
```

### 方法二：显式构建序列（理解用）

```python
from collections import Counter
from typing import Set

class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        result = set()  # 使用集合自动去重
        counter = Counter(tiles)
        
        def backtrack(current: str):
            # 如果当前序列非空，加入结果集
            if current:
                result.add(current)
            
            # 尝试每个字母
            for char in counter:
                if counter[char] > 0:
                    counter[char] -= 1
                    backtrack(current + char)
                    counter[char] += 1
        
        backtrack("")
        return len(result)
```

### 方法三：使用列表标记（传统回溯）

```python
class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        self.count = 0
        tiles_list = sorted(list(tiles))  # 排序便于去重
        used = [False] * len(tiles)
        
        def backtrack(path):
            if path:
                self.count += 1
            
            for i in range(len(tiles_list)):
                # 跳过已使用的
                if used[i]:
                    continue
                
                # 去重：如果当前字母与前一个相同，且前一个未使用，跳过
                if i > 0 and tiles_list[i] == tiles_list[i-1] and not used[i-1]:
                    continue
                
                used[i] = True
                backtrack(path + tiles_list[i])
                used[i] = False
        
        backtrack("")
        return self.count
```

### 方法四：数学公式（排列组合）

```python
from collections import Counter
from math import factorial

class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        """
        使用排列组合公式计算
        对于长度为 k 的序列，有字母 a(n_a个), b(n_b个), ...
        排列数 = k! / (n_a! * n_b! * ...)
        """
        counter = Counter(tiles)
        n = len(tiles)
        total = 0
        
        def count_permutations(length, remaining):
            """计算长度为 length 的排列数"""
            if length == 0:
                return 1
            
            # 计算分子：length!
            numerator = factorial(length)
            
            # 计算分母：每个字母的阶乘乘积
            denominator = 1
            for char, freq in remaining.items():
                if freq > 0:
                    # 使用的数量不能超过 length 和 freq
                    use = min(freq, length)
                    denominator *= factorial(use)
            
            # 这里需要更复杂的逻辑，实际上数学方法不如回溯直接
            return 0
        
        # 数学方法对此题较复杂，推荐使用回溯
        return self.numTilePossibilitiesBacktrack(tiles)
    
    def numTilePossibilitiesBacktrack(self, tiles: str) -> int:
        counter = Counter(tiles)
        
        def backtrack():
            count = 0
            for char in counter:
                if counter[char] > 0:
                    count += 1
                    counter[char] -= 1
                    count += backtrack()
                    counter[char] += 1
            return count
        
        return backtrack()
```

## 复杂度分析

**方法一（推荐）：**
- **时间复杂度**：O(n! × n)，其中 n 是字符串长度（最多 7）
  - 最坏情况下生成所有排列：O(n!)
  - 每个排列处理：O(n)
  - 实际上由于去重和剪枝，远小于理论上界
- **空间复杂度**：O(n)
  - 递归调用栈：O(n)
  - Counter：O(26) = O(1)

**方法二：**
- **时间复杂度**：O(n! × n)
- **空间复杂度**：O(n! × n)，需要存储所有序列

**方法三：**
- **时间复杂度**：O(n! × n)
- **空间复杂度**：O(n)

## 关键点总结

1. **频率统计去重**：使用 Counter 避免重复计算相同字母
2. **回溯模板**：选择 → 递归 → 撤销
3. **计数技巧**：每次选择字母就形成一个新序列，直接计数
4. **不需要构建序列**：只需计数，不需要存储具体序列（节省空间）
5. **剪枝优化**：频率为 0 的字母自动跳过

## 易错点

1. **重复计数**：没有正确去重，导致 "A" 被计算多次
2. **忘记回溯**：修改 counter 后忘记恢复
3. **边界条件**：空序列不计入结果（题目要求非空）
4. **集合 vs 计数**：方法二用集合存储序列，方法一直接计数（更优）
5. **排列 vs 组合**：注意是排列问题，"AB" 和 "BA" 是不同的
