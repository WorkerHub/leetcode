## 题目描述

给你一个下标从 1 开始的整数数组 `nums`。

如果下标集合 `S` 满足：对于集合中任意两个下标 `i` 和 `j`，`i × j` 是**完全平方数**，则称 S 为**完全子集**。

返回完全子集中元素之和的最大值。

**示例 1：**
```
输入：nums = [8,7,3,5,7,2,4,9]
输出：16
解释：下标 1 和 4（1×4=4=2^2）构成完全子集，nums[1]+nums[4]=8+7=15
下标 1,4,9 不存在（数组长度 8），1 和 9 构成完全子集，nums[1]+nums[9]...
等等，最大是 1+4 = 15，或者 2+8=...(2×8=16 非完全平方)，还是 1,4（sum=15）或 4,9（7+... 没有9）
下标 4 和 1 构成，sum = nums[3] + nums[0] = 5+8 = 13？
注意：下标从 1 开始！nums[1]=8, nums[4]=7, sum=15
但还有 2 和 8：2×8=16=4^2，nums[2]+nums[8]=7+9=16
答案 = 16
```

**提示：**
- `1 <= nums.length <= 10^4`

## 解题思路

**关键：** 两个下标 `i` 和 `j` 的乘积为完全平方数，等价于它们有相同的**无平方因子部分**（square-free part）。

一个正整数 n 的 square-free part = 将 n 中所有质因子的偶数次幂去掉后的结果。例如：
- 4 = 2^2，square-free part = 1
- 12 = 2^2 × 3，square-free part = 3
- 18 = 2 × 3^2，square-free part = 2

若 i 和 j 的 square-free part 相同，则 `i × j` 是完全平方数。

**算法：**
1. 对每个下标（1 到 n），计算其 square-free part
2. 按 square-free part 分组，同组下标可以互相配对
3. 返回最大组的元素和

## Python 代码实现

### 方法一：square-free 分组（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)

        def square_free_part(x: int) -> int:
            """计算 x 的无平方因子部分"""
            result = 1
            d = 2
            while d * d <= x:
                cnt = 0
                while x % d == 0:
                    cnt += 1
                    x //= d
                if cnt % 2 == 1:  # 奇数次幂，保留
                    result *= d
                d += 1
            if x > 1:
                result *= x  # 剩余质因子（必然奇数次）
            return result

        # 按 square-free part 分组
        groups = defaultdict(int)
        for i in range(1, n + 1):
            key = square_free_part(i)
            groups[key] += nums[i - 1]  # nums 是 0-indexed

        return max(groups.values())
```

### 方法二：优化分解（预处理质因子）

```python
from collections import defaultdict
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)

        def sqfree(x: int) -> int:
            res = 1
            p = 2
            while p * p <= x:
                exp = 0
                while x % p == 0:
                    x //= p
                    exp += 1
                if exp & 1:
                    res *= p
                p += 1
            return res * x  # 剩余质数（exp=1，奇数次）

        groups = defaultdict(int)
        for i in range(1, n + 1):
            groups[sqfree(i)] += nums[i - 1]

        return max(groups.values())
```

## 复杂度分析

- 时间复杂度：O(n × sqrt(n))，对每个下标分解质因子 O(sqrt(n))
- 空间复杂度：O(n)，哈希表分组

## 关键点总结

1. 乘积为完全平方数 ⟺ 两个数的 square-free part 相同
2. Square-free part：去掉所有偶数次幂质因子
3. 贪心：同组所有下标都选（都取最大），故每组和即为答案候选

## 易错点

1. 下标从 1 开始，`nums[i-1]` 对应下标 i
2. Square-free part 计算：奇数次幂保留，偶数次幂去掉
3. 最大值取所有组中的最大值
