## 题目描述

给你一个正整数数组 `nums`。

如果数组中所有元素的乘积等于所有元素的最小公倍数（LCM），则称该子数组为**等积子数组**。

返回**最长等积子数组**的长度。

**示例 1：**

```
输入：nums = [1,2,1,2,1,1,1]
输出：5
解释：子数组 [1,2,1,2,1]，乘积 = 4，LCM = 2，不等... 
等等，[1,1,1,1,1] 乘积=1, LCM=1, 等积。长度=5
```

**示例 2：**

```
输入：nums = [2,3,4,5,6]
输出：2
解释：[2,3] 乘积=6，LCM=6，等积，长度=2
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 10`

## 解题思路

乘积 == LCM 等价于所有元素**两两互质**（即没有任何两个元素共享大于 1 的公因子）。

因为：若所有元素两两互质，则它们的 LCM 等于它们的乘积；反之，若有两个元素 gcd > 1，则 LCM < 乘积。

滑动窗口：维护一个窗口，检查窗口内所有元素两两互质。若不满足，缩小窗口。

由于数组范围小（nums[i] <= 10），可以直接枚举所有子数组。

## Python 代码实现

### 方法一：枚举所有子数组（推荐，n<=100）

```python
from typing import List
from math import gcd, lcm
from functools import reduce

class Solution:
    def maxLength(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 1

        for i in range(n):
            product = 1
            lcm_val = 1
            for j in range(i, n):
                product *= nums[j]
                lcm_val = lcm(lcm_val, nums[j])
                if product == lcm_val:
                    ans = max(ans, j - i + 1)

        return ans
```

### 方法二：检查两两互质

```python
from typing import List
from math import gcd

class Solution:
    def maxLength(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 1

        for i in range(n):
            # 检查 nums[i..j] 是否所有元素两两互质
            pairwise_coprime = True
            for j in range(i + 1, n):
                # 新加入 nums[j]，检查与已有元素的 gcd
                for k in range(i, j):
                    if gcd(nums[k], nums[j]) > 1:
                        pairwise_coprime = False
                        break
                if not pairwise_coprime:
                    break
                ans = max(ans, j - i + 1)

        return ans
```

### 方法三：利用数值范围小的优化（数组元素 <= 10）

```python
from typing import List
from math import gcd

class Solution:
    def maxLength(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 1

        for i in range(n):
            # 追踪已见素因子
            seen_primes = set()
            valid = True
            product = 1
            for j in range(i, n):
                v = nums[j]
                # 检查 v 的素因子是否已出现
                # nums[i] <= 10，素因子只有 2,3,5,7
                primes_v = set()
                for p in [2, 3, 5, 7]:
                    if v % p == 0:
                        primes_v.add(p)
                if primes_v & seen_primes:
                    break  # 有重复素因子，不满足
                seen_primes |= primes_v
                ans = max(ans, j - i + 1)

        return ans
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n^2)，枚举所有子数组
  - 空间复杂度：O(1)

- 方法三：
  - 时间复杂度：O(n^2 * C)，C 为小常数（素因子个数）
  - 空间复杂度：O(1)

## 关键点总结

1. 乘积 == LCM 等价于所有元素两两互质
2. 对于 nums[i] <= 10，素因子只有 2, 3, 5, 7，可以用位掩码优化
3. 发现不互质即可提前终止内层循环

## 易错点

1. 乘积可能很大（虽然 nums[i] <= 10，但长子数组的乘积会超出 int 范围），Python 自动处理大整数
2. 单个元素的子数组一定满足（乘积 = 值 = LCM），长度至少为 1
3. LCM 函数在 Python 3.9+ 中可用 `math.lcm`，低版本需自行实现
