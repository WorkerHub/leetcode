## 题目描述

有 `n` 台电脑，编号 `0` 到 `n-1`，每台电脑有一个密码 `complexity[i]`。电脑 `0` 默认解锁。若要解锁电脑 `i`（`i > 0`），需要先解锁某台密码小于 `complexity[i]` 的电脑。给定一个解锁顺序的排列，若满足条件则称为"合法排列"。求合法排列的数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：complexity = [1, 2, 3]
输出：2
解释：合法排列为 [0,1,2] 和 [0,2,1]（0 先解锁，然后 1 和 2 的顺序可以互换）
```

**示例 2：**

```
输入：complexity = [1, 1, 1]
输出：1
解释：只有 [0,1,2] 合法（密码相同的不能互相解锁）
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= complexity[i] <= 10^9`

## 解题思路

关键观察：
- 电脑 0 最先解锁
- 电脑 i 可以在任何已解锁的密码小于 `complexity[i]` 的电脑之后解锁
- 等价于：将 n 台电脑按 complexity 排序，密码相同的不能互相解锁（需要密码严格小于）

数学分析：
- 排序后，对每个密码值，同密码的电脑数量 `cnt` 中，除了其中一台可以被"较小密码的电脑"解锁外，其余 `cnt-1` 台可以在同一层中自由排列
- 答案 = 每个密码组中 `cnt-1` 台的排列数之积

更准确：按 complexity 排序后，对每个电脑，它可以在前面所有 complexity 严格小于它的电脑都解锁后再解锁。答案等于每个电脑 i（除 0 外）到其"必须在其之前解锁"的电脑数的"自由度"之积。

## Python 代码实现

### 方法一：排序 + 计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countPermutations(self, complexity: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(complexity)

        # 若电脑 0 不是密码最小的，则无解
        if complexity[0] != min(complexity):
            return 0

        # 按 complexity 排序（不包含电脑 0）
        # 统计各密码值的数量
        cnt = Counter(complexity)
        min_val = complexity[0]

        # 对每个密码值 v（v > min_val），有 cnt[v] 台电脑
        # 这些电脑可以在密码 < v 的电脑解锁后，相互任意排列
        # 贡献 cnt[v]! 的排列

        # 但实际上需要更仔细分析
        # 简化：答案 = (n-1)! / (密码相同组的组内排列受限情况)

        result = 1
        # 对每个密码值，其组内的 cnt[v] 台电脑（v > min_val）
        # 可以在它们"前驱"解锁后任意排列，贡献 cnt[v]! / ... 
        # 实际答案 = product of cnt[v] for v != min_val... 不对

        # 最简洁的分析：
        # 排序后，每台电脑能插入的位置数 = 前面已解锁且密码严格小于自身的数量
        sorted_c = sorted(complexity)
        result = 1
        unlocked = 1  # 电脑 0 已解锁
        for i in range(1, n):
            if sorted_c[i] > sorted_c[i-1]:
                unlocked = i  # 前 i 台已解锁，当前第 i 台（0-indexed）
            # 当前电脑可以插入的位置数
            # 实际上是前面严格小于 sorted_c[i] 的数量
            result = result * unlocked % MOD

        return result
```

### 方法二：直接数学计算

```python
from typing import List
from collections import Counter

class Solution:
    def countPermutations(self, complexity: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(complexity)

        if complexity[0] != min(complexity):
            return 0

        # 计算每个位置（按 complexity 排序后）的选择数
        sorted_c = sorted(complexity[1:])  # 排除电脑 0
        result = 1
        smaller_count = 1  # 初始有电脑 0（complexity[0]）已解锁

        for i, c in enumerate(sorted_c):
            # 当前电脑的 complexity 为 c
            # 能解锁它的（已解锁且密码 < c）的数量
            # = 排序后，在当前位置前且密码严格小于 c 的数量
            if c > complexity[0]:
                result = result * (i + 1) % MOD
            else:
                # 密码 == complexity[0]，只有电脑 0 能解锁但不能（相等不行）
                # 实际上等于 complexity[0] 的电脑无法被解锁（需要严格小于）
                return 0

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 电脑 0 必须是密码最小的（否则无法开始）
2. 按密码值排序后，每台电脑的"可用前驱数"决定了它的插入自由度
3. 答案 = 所有电脑插入自由度的乘积

## 易错点

1. 严格小于（不是小于等于）的密码才能解锁
2. 若多台电脑密码与最小值相同但无法被解锁，直接返回 0
3. 乘积结果对 MOD 取模
