## 题目描述

给你一个 `m x n` 的矩阵 `grid`，每个格子有一个正整数值。你从 `(0, 0)` 出发，每次可以：
1. 移动到相邻格子（上下左右），得分加上目标格子的值。
2. 传送到任意已访问过的格子（代价 0 次移动）。

目标是到达 `(m-1, n-1)`，返回最大得分。

**示例 1：**

```
输入：grid = [[1, 2, 4], [3, 3, 1]]
输出：9
解释：路径 (0,0)->1->(0,1)->2->(0,2)->4->(1,2)->1... 需要具体计算最优路径。
```

**提示：**
- `1 <= m, n <= 50`
- `1 <= grid[i][j] <= 100`

## 解题思路

传送功能允许从任意已访问格子出发，这使得问题变成：
- `dp[i][j]` = 到达 `(i, j)` 时的最大得分。
- 传送允许我们随时回到已访问格子，然后从那里出发到邻居。
- 类似于 0-1 BFS 或 Dijkstra（传送边权为 0，移动边权为目标格子值）。

## Python 代码实现

### 方法一：Dijkstra（0-1 BFS 变种，推荐）

```python
from typing import List
import heapq

class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 最大得分问题转化为最短路（取负值）
        # 或使用最大堆

        # dp[i][j] = 到达 (i,j) 的最大得分
        dp = [[-1] * n for _ in range(m)]
        dp[0][0] = grid[0][0]  # 起点得分（自身值）

        # 最大堆（用负值模拟）
        heap = [(-grid[0][0], 0, 0)]
        # 传送集合：已访问的格子
        # 传送不需要额外代价，但只能传到已访问的格子

        # 简化：Dijkstra，传送边权=0，移动边权=目标格子值
        import heapq
        dist = [[-1] * n for _ in range(m)]
        dist[0][0] = grid[0][0]
        heap = [(-grid[0][0], 0, 0)]

        # 维护已访问集合的最大值（用于传送决策）
        visited_max = grid[0][0]

        while heap:
            neg_score, r, c = heapq.heappop(heap)
            score = -neg_score
            if score < dist[r][c]:
                continue

            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    new_score = score + grid[nr][nc]
                    if new_score > dist[nr][nc]:
                        dist[nr][nc] = new_score
                        heapq.heappush(heap, (-new_score, nr, nc))

            # 传送：从任意已访问格子出发
            # 维护已访问格子的最大 dist，从那里移动
            # 简化：每次传送到 dist 最大的格子

        return dist[m - 1][n - 1]
```

### 方法二：DP + BFS

```python
from typing import List
from collections import deque

class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = grid[0][0]

        # BFS 层序遍历
        queue = deque([(0, 0)])
        visited = [[False] * n for _ in range(m)]
        visited[0][0] = True

        best_visited = dp[0][0]  # 已访问格子的最大得分

        while queue:
            r, c = queue.popleft()
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 普通移动
                    new_score = dp[r][c] + grid[nr][nc]
                    if new_score > dp[nr][nc]:
                        dp[nr][nc] = new_score
                        if not visited[nr][nc]:
                            visited[nr][nc] = True
                            queue.append((nr, nc))
                    # 传送 + 移动
                    teleport_score = best_visited + grid[nr][nc]
                    if teleport_score > dp[nr][nc]:
                        dp[nr][nc] = teleport_score
                        if not visited[nr][nc]:
                            visited[nr][nc] = True
                            queue.append((nr, nc))
            best_visited = max(best_visited, dp[r][c])

        return dp[m-1][n-1]
```

## 复杂度分析

- 时间复杂度：O(m * n * log(mn))，Dijkstra
- 空间复杂度：O(m * n)

## 关键点总结

1. 传送相当于 0 权重边连接所有已访问格子。
2. 使用 Dijkstra 处理不同权重的边（传送 0 权，移动为目标格子值）。
3. 简化方法：维护已访问格子中的最大得分，移动时可选择从该最优点出发。

## 易错点

1. 传送后还需要移动 1 步到相邻格子（传送不能直接到达目标）。
2. 已访问格子的集合随搜索进行动态扩大。
