## 题目描述

给你一个整数数组 `nums`，每次操作可以选择一个非空子数组，将其从数组中移除，得分为子数组中所有元素乘积。

返回通过多次操作能获得的最大总得分。

**示例 1：**

```
输入：nums = [1, 2, 3]
输出：9
解释：移除 [3] 得 3，移除 [2] 得 2，移除 [1] 得 1，总分 6。
或移除 [1,2,3] 得 6，或移除 [2,3] 得 6，再移除 [1] 得 1，总分 7。
或移除 [3] 得 3，移除 [1,2] 得 2，总分 5。
最优策略：移除 [1,2,3] 一次得 6？
或移除 [3] 得 3，[2] 得 2，[1] 得 1：总分 6。
```

**提示：**
- `1 <= nums.length <= 20`
- `1 <= nums[i] <= 10`

## 解题思路

状态压缩 DP：
- `dp[mask]` = 将 mask 对应的元素全部移除后获得的最大总得分。
- 枚举 mask 的子集作为一次操作的范围（要求子集对应的元素在原数组中是连续的）。

注意：这里的"子数组"要求是原数组中的连续部分，不是任意子集。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumPoints(self, nums: List[int]) -> int:
        n = len(nums)
        # 预计算每个连续区间的乘积
        # interval_product[i][j] = nums[i] * nums[i+1] * ... * nums[j]
        interval_product = [[0] * n for _ in range(n)]
        for i in range(n):
            p = 1
            for j in range(i, n):
                p *= nums[j]
                interval_product[i][j] = p

        @lru_cache(maxsize=None)
        def dp(remaining):
            """remaining 是一个元组，表示剩余元素的下标"""
            if not remaining:
                return 0

            best = 0
            m = len(remaining)
            # 枚举从 remaining 中选一个连续子数组移除
            for i in range(m):
                for j in range(i, m):
                    # 移除 remaining[i..j]，但需要是原数组中连续的
                    # 检查 remaining[i..j] 在原数组中是否连续
                    is_continuous = all(remaining[k + 1] == remaining[k] + 1
                                       for k in range(i, j))
                    if is_continuous:
                        score = interval_product[remaining[i]][remaining[j]]
                        new_remaining = remaining[:i] + remaining[j + 1:]
                        best = max(best, score + dp(new_remaining))

            return best

        return dp(tuple(range(n)))
```

### 方法二：区间 DP

```python
from typing import List

class Solution:
    def maximumPoints(self, nums: List[int]) -> int:
        n = len(nums)
        # 尝试所有分割方式
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(mask):
            # 从 mask 表示的"已移除"集合出发，最大化分数
            if mask == (1 << n) - 1:
                return 0

            best = 0
            # 找剩余元素中的连续段，尝试每种移除
            remaining = [i for i in range(n) if not (mask >> i & 1)]

            # 枚举连续子数组
            for i in range(len(remaining)):
                for j in range(i, len(remaining)):
                    # 检查是否连续
                    if remaining[j] - remaining[i] != j - i:
                        break
                    # 计算该段乘积
                    prod = 1
                    for k in range(i, j + 1):
                        prod *= nums[remaining[k]]
                    # 移除该段
                    new_mask = mask
                    for k in range(i, j + 1):
                        new_mask |= (1 << remaining[k])
                    best = max(best, prod + dp(new_mask))

            return best

        return dp(0)
```

## 复杂度分析

- 时间复杂度：O(2^n * n^2)，状态数 2^n，每个状态枚举 O(n^2) 个连续子数组
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 20，状态压缩 DP 可行（2^20 约 100 万）。
2. 每次操作移除的必须是当前剩余数组中的连续子数组（在原数组中连续）。
3. 预计算区间乘积避免重复计算。

## 易错点

1. "连续子数组"要求在原数组中连续，不是 remaining 数组中连续（但未移除的元素中连续）。
2. 状态压缩时 mask 表示已移除的元素集合。
