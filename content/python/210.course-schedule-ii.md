## 题目描述

现在你总共有 `numCourses` 门课需要选，记为 `0` 到 `numCourses - 1`。给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]`，表示在选修课程 `ai` 前必须先选修 `bi`。

- 例如，想要学习课程 `0`，你需要先完成课程 `1`，我们用一个匹配来表示：`[0,1]`。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回**任意一种**就可以了。如果不可能完成所有课程，返回一个**空数组**。

**示例 1：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]
解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1]。
```

**示例 2：**
```
输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,2,1,3]
解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。
因此，一个正确的课程顺序是 [0,1,2,3]。另一个正确的排序是 [0,2,1,3]。
```

**示例 3：**
```
输入：numCourses = 1, prerequisites = []
输出：[0]
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `ai != bi`
- 所有`[ai, bi]` **互不相同**

## 解题思路

这道题是 [207. 课程表](https://leetcode.com/problems/course-schedule/) 的进阶版，不仅要判断能否完成，还要**返回一个合法的学习顺序**。

### 问题建模

1. **有向图**：课程是节点，`[a, b]` 表示边 `b → a`
2. **拓扑排序**：找到有向无环图（DAG）的拓扑序列
3. **有环检测**：如果有环，无法完成所有课程

### 拓扑排序的定义

对于有向无环图（DAG），**拓扑排序**是所有节点的一个线性排序，满足：
- 如果存在边 `u → v`，那么 `u` 在排序中出现在 `v` 之前

### 解决方案

1. **BFS（Kahn 算法）**：基于入度的广度优先搜索 ⭐
2. **DFS**：深度优先搜索，后序遍历

## Python 代码实现

### 方法一：BFS 拓扑排序（Kahn 算法）推荐⭐

```python
from collections import deque, defaultdict
from typing import List

class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        # 1. 构建图和入度数组
        graph = defaultdict(list)  # 邻接表
        in_degree = [0] * numCourses  # 入度数组
        
        for course, prereq in prerequisites:
            graph[prereq].append(course)  # prereq -> course
            in_degree[course] += 1
        
        # 2. 将所有入度为 0 的节点加入队列
        queue = deque()
        for i in range(numCourses):
            if in_degree[i] == 0:
                queue.append(i)
        
        # 3. BFS 拓扑排序
        order = []  # 存储拓扑排序结果
        
        while queue:
            course = queue.popleft()
            order.append(course)  # 加入结果
            
            # 处理所有依赖当前课程的课程
            for next_course in graph[course]:
                in_degree[next_course] -= 1
                # 入度变为 0，加入队列
                if in_degree[next_course] == 0:
                    queue.append(next_course)
        
        # 4. 检查是否所有课程都被访问
        # 如果有环，部分节点的入度永远不会为 0
        if len(order) == numCourses:
            return order
        else:
            return []  # 有环，无法完成
```

**算法思路**：
1. **构建图**：邻接表 + 入度数组
2. **初始化队列**：所有入度为 0 的节点（无前置依赖）
3. **BFS 过程**：
   - 取出节点，加入结果
   - 将后继节点的入度减 1
   - 入度变为 0 的节点加入队列
4. **检查结果**：如果结果长度等于课程数，说明无环

**为什么是拓扑序？**
- 入度为 0 的节点没有前置依赖，可以直接学习
- 处理完一个节点，它的后继节点的依赖减少
- 当后继节点的所有前置依赖都处理完，入度变为 0，可以学习

### 方法二：DFS 拓扑排序⭐

```python
from collections import defaultdict
from typing import List

class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        # 1. 构建图
        graph = defaultdict(list)
        for course, prereq in prerequisites:
            graph[prereq].append(course)
        
        # 2. 状态数组：0=未访问，1=访问中，2=已完成
        visited = [0] * numCourses
        order = []  # 存储拓扑排序结果（逆序）
        
        # 3. DFS 函数
        def dfs(course: int) -> bool:
            """返回 True 表示无环，False 表示有环"""
            if visited[course] == 1:
                # 访问到「访问中」的节点，有环
                return False
            if visited[course] == 2:
                # 已访问过，直接返回
                return True
            
            # 标记为「访问中」
            visited[course] = 1
            
            # 递归访问所有后继节点
            for next_course in graph[course]:
                if not dfs(next_course):
                    return False
            
            # 标记为「已完成」
            visited[course] = 2
            # 后序位置加入结果（重要！）
            order.append(course)
            return True
        
        # 4. 对每个未访问的节点进行 DFS
        for i in range(numCourses):
            if visited[i] == 0:
                if not dfs(i):
                    return []  # 有环，返回空数组
        
        # 5. DFS 的后序遍历是逆拓扑序，需要反转
        return order[::-1]
```

**算法思路**：
- **DFS 后序遍历**：在递归返回前加入结果
- **为什么要反转？**
  - DFS 后序遍历得到的是**逆拓扑序**
  - 后处理的节点依赖先处理的节点
  - 反转后得到正确的拓扑序

**关键理解**：
```
如果有边 A → B，DFS(A) 会先递归 DFS(B)
B 先加入 order，A 后加入 order
order = [..., B, A]
反转后：[A, B, ...]，正确的拓扑序
```

### 方法三：BFS 优化版

```python
from collections import deque
from typing import List

class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        # 使用列表代替 defaultdict
        graph = [[] for _ in range(numCourses)]
        in_degree = [0] * numCourses
        
        for course, prereq in prerequisites:
            graph[prereq].append(course)
            in_degree[course] += 1
        
        # 列表推导式初始化队列
        queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
        order = []
        
        while queue:
            course = queue.popleft()
            order.append(course)
            
            for next_course in graph[course]:
                in_degree[next_course] -= 1
                if in_degree[next_course] == 0:
                    queue.append(next_course)
        
        return order if len(order) == numCourses else []
```

**优化说明**：
- 代码更简洁
- 使用列表代替字典，速度更快

## 复杂度分析

### 方法一、三：BFS
- **时间复杂度**：O(V + E)
  - V 是课程数（节点数）
  - E 是依赖关系数（边数）
- **空间复杂度**：O(V + E)
  - 邻接表：O(E)
  - 入度数组：O(V)
  - 队列：O(V)

### 方法二：DFS
- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V + E)
  - 递归栈：O(V)

## 关键点总结

1. **拓扑排序应用**：有向无环图的线性排序
2. **两种实现**：
   - BFS（Kahn 算法）：基于入度，更直观
   - DFS：后序遍历，需要反转结果
3. **环检测**：
   - BFS：结果长度 < 节点数
   - DFS：访问到「访问中」的节点
4. **多个答案**：拓扑排序可能有多个合法结果
5. **与 207 题对比**：207 只判断能否完成，210 要返回顺序

## 易错点

1. **边的方向**：`[a, b]` 表示 `b → a`，容易搞反

2. **DFS 结果需要反转**：
   - 后序遍历是逆拓扑序
   - 忘记反转会导致顺序错误

3. **环检测遗漏**：
   ```python
   # 错误：直接返回 order，没检查是否有环
   return order
   
   # 正确：检查长度
   return order if len(order) == numCourses else []
   ```

4. **DFS 状态错误**：
   - 忘记标记「访问中」
   - 忘记标记「已完成」

5. **初始化错误**：
   ```python
   # 错误：defaultdict 的默认值类型
   graph = defaultdict(int)  # 应该是 list
   
   # 正确
   graph = defaultdict(list)
   ```
