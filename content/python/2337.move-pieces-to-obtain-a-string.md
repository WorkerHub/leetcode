## 题目描述

给你两个字符串 `start` 和 `target`，长度均为 `n`。每个字符串**仅**由字符 `'L'`、`'R'` 和 `'_'` 组成，其中：
- `'L'` 和 `'R'` 表示棋子，`'_'` 表示空格。
- **移动规则**：`'L'` 可以向左移动到相邻空格（即 `"_L"` -> `"L_"`），`'R'` 可以向右移动（即 `"R_"` -> `"_R"`）。
- 棋子不能互相穿越。

判断是否可以通过若干次移动，将 `start` 变成 `target`。

**示例 1：**
```
输入：start = "_L__R__R_", target = "L______RR"
输出：true
```

**示例 2：**
```
输入：start = "R_L_", target = "_LR_"
输出：false
```

**提示：**
- `n == start.length == target.length`
- `1 <= n <= 10^5`

## 解题思路

**双指针条件判断：**

1. 去掉下划线后，`start` 和 `target` 的字符序列必须完全一致（L/R 的相对顺序不变）。
2. 对于每个 L（在 start 中位置 i，target 中位置 j）：L 只能向左移，所以 `i >= j`（start 中的 L 在 target 中的对应 L 的右边或同位置）。
3. 对于每个 R（在 start 中位置 i，target 中位置 j）：R 只能向右移，所以 `i <= j`。

## 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def canChange(self, start: str, target: str) -> bool:
        n = len(start)
        i = j = 0  # 双指针分别遍历 start 和 target 的非下划线字符
        
        while i < n or j < n:
            # 跳过 start 中的下划线
            while i < n and start[i] == '_':
                i += 1
            # 跳过 target 中的下划线
            while j < n and target[j] == '_':
                j += 1
            
            # 若一个到头，另一个也必须到头
            if i == n and j == n:
                return True
            if i == n or j == n:
                return False
            
            # 字符类型必须相同
            if start[i] != target[j]:
                return False
            
            # 检查移动方向的合法性
            if start[i] == 'L' and i < j:
                return False  # L 只能向左移，start 中的位置应 >= target 中的位置
            if start[i] == 'R' and i > j:
                return False  # R 只能向右移
            
            i += 1
            j += 1
        
        return True
```

### 方法二：提取字符序列对比

```python
class Solution:
    def canChange(self, start: str, target: str) -> bool:
        # 提取非下划线字符及其位置
        s_chars = [(c, i) for i, c in enumerate(start) if c != '_']
        t_chars = [(c, j) for j, c in enumerate(target) if c != '_']
        
        if len(s_chars) != len(t_chars):
            return False
        
        for (sc, si), (tc, tj) in zip(s_chars, t_chars):
            if sc != tc:
                return False
            if sc == 'L' and si < tj:
                return False  # L 不能向右移
            if sc == 'R' and si > tj:
                return False  # R 不能向左移
        
        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n) | O(1) |
| 提取序列 | O(n) | O(n) |

## 关键点总结

1. L/R 的相对顺序在任何合法移动中不变（无法穿越）。
2. L 只能左移（start 位置 >= target 位置），R 只能右移（start 位置 <= target 位置）。
3. 两步验证：字符序列相同 + 位置约束满足。

## 易错点

- 忽略棋子顺序不变的约束（L/R 在移除下划线后顺序必须一致）。
- 方向约束：L 的 `start_pos >= target_pos`，R 的 `start_pos <= target_pos`。
