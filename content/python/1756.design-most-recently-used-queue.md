## 题目描述

设计一种最近使用队列（MRU 队列）的数据结构，初始化时接受 `n` 个元素（1 到 n），支持以下操作：

- `fetch(k)`：将**第 k 个**（1-indexed）元素移到队列末尾，并返回该元素

**示例：**
```
MRUQueue mRUQueue = new MRUQueue(8); // [1,2,3,4,5,6,7,8]
mRUQueue.fetch(3); // 返回 3，队列变为 [1,2,4,5,6,7,8,3]
mRUQueue.fetch(5); // 返回 5，队列变为 [1,2,4,6,7,8,3,5]
```

**提示：**
- `1 <= n <= 2000`
- `1 <= k <= queue.length`（操作次数 <= 2000）

## 解题思路

**方法一（暴力）**：用列表模拟，`fetch(k)` 取出第 k 个元素（O(k)），移到末尾。适合小数据。

**方法二（树状数组）**：用树状数组维护有效元素，支持 O(log^2 n) 的 `fetch` 操作。适合大数据。

## 代码实现

### 方法一：列表模拟（推荐，适合本题数据量）

```python
class MRUQueue:
    def __init__(self, n: int):
        # 初始化队列为 [1, 2, ..., n]
        self.queue = list(range(1, n + 1))
    
    def fetch(self, k: int) -> int:
        # 取出第 k 个（1-indexed）
        val = self.queue[k - 1]
        # 从原位删除
        del self.queue[k - 1]
        # 移到末尾
        self.queue.append(val)
        return val
```

### 方法二：树状数组 + 二分（高效版）

```python
class MRUQueue:
    def __init__(self, n: int):
        self.n = n
        self.size = n  # 当前队列大小（会增加，因为移到末尾）
        # 树状数组记录每个位置是否有元素
        # 实际用扩展数组（初始 n 个，后续在 n+1... 追加）
        max_size = n + 2001  # 最多 2000 次操作
        self.bit = [0] * (max_size + 1)
        self.vals = [0] * (max_size + 1)  # vals[i] = 第 i 个位置的值
        
        # 初始化
        for i in range(1, n + 1):
            self.vals[i] = i
            self._update(i, 1)
        
        self.cur_pos = n  # 下一个追加位置
    
    def _update(self, i, delta):
        while i <= len(self.bit) - 1:
            self.bit[i] += delta
            i += i & (-i)
    
    def _query(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & (-i)
        return s
    
    def _find_kth(self, k):
        """找第 k 个有效位置（二分）"""
        lo, hi = 1, len(self.bit) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if self._query(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
    
    def fetch(self, k: int) -> int:
        # 找第 k 个元素的位置
        pos = self._find_kth(k)
        val = self.vals[pos]
        # 从原位置删除
        self._update(pos, -1)
        # 追加到末尾
        self.cur_pos += 1
        self.vals[self.cur_pos] = val
        self._update(self.cur_pos, 1)
        return val
```

## 复杂度分析

- **方法一**：`fetch` O(n)（删除操作），空间 O(n)
- **方法二**：`fetch` O(log^2 n)，空间 O(n)

## 关键点总结

1. 方法一适合本题约束（n, 操作数 <= 2000），简单直观
2. 方法二用树状数组支持高效的第 k 个元素查询和更新
3. 树状数组 + 二分查找第 k 个元素

## 易错点

- 方法一删除用 `del queue[k-1]`（O(n)），不是 pop
- 树状数组的数组大小要考虑追加的元素
