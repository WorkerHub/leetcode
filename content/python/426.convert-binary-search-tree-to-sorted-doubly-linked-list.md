## 题目描述

将一个二叉搜索树就地转化为一个已排序的双向循环链表。

对于双向循环列表，你可以将左右孩子指针作为双向循环链表的前驱和后继指针，第一个节点的前驱是最后一个节点，最后一个节点的后继是第一个节点。

特别地，我们希望可以就地完成转换操作。当转化完成以后，树中节点的左指针需要指向前驱，树中节点的右指针需要指向后继。还需要返回链表中最小元素的指针。

**示例 1：**
```
输入：root = [4,2,5,1,3]

    4
   / \
  2   5
 / \
1   3

输出：[1,2,3,4,5]
解释：返回的链表节点1，其前驱指向5，后继指向2
```

**示例 2：**
```
输入：root = [2,1,3]
输出：[1,2,3]
```

**提示：**
- 节点数在 `[0, 2000]` 范围内
- `-1000 <= Node.val <= 1000`
- 所有节点值都是独一无二的

## 解题思路

这道题要求将二叉搜索树转换为有序的双向循环链表。核心思想是利用中序遍历。

**关键观察：**
1. 二叉搜索树的中序遍历结果是有序的
2. 在中序遍历过程中，可以同时建立前驱和后继关系
3. 需要记录第一个节点（最小值）和最后一个节点（最大值）
4. 最后将首尾连接形成循环链表

**算法流程：**
1. 使用中序遍历（左-根-右）
2. 维护前驱节点 `prev`
3. 对于当前节点，建立与前驱的双向连接
4. 记录第一个节点（最小值）
5. 遍历结束后，连接首尾节点

## Python 代码实现

### 方法一：递归中序遍历 ⭐ 推荐

```python
class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def treeToDoublyList(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        # 记录第一个节点（最小值）和前驱节点
        self.first = None
        self.prev = None
        
        def inorder(node):
            if not node:
                return
            
            # 递归处理左子树
            inorder(node.left)
            
            # 处理当前节点
            if self.prev:
                # 建立前驱和当前节点的双向连接
                self.prev.right = node
                node.left = self.prev
            else:
                # 第一个节点（最小值）
                self.first = node
            
            # 更新前驱节点
            self.prev = node
            
            # 递归处理右子树
            inorder(node.right)
        
        # 中序遍历
        inorder(root)
        
        # 连接首尾，形成循环链表
        self.first.left = self.prev
        self.prev.right = self.first
        
        return self.first
```

### 方法二：迭代中序遍历

```python
class Solution:
    def treeToDoublyList(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        stack = []
        current = root
        first = None
        prev = None
        
        # 迭代中序遍历
        while stack or current:
            # 一直向左走到底
            while current:
                stack.append(current)
                current = current.left
            
            # 处理当前节点
            current = stack.pop()
            
            if prev:
                # 建立双向连接
                prev.right = current
                current.left = prev
            else:
                # 记录第一个节点
                first = current
            
            # 更新前驱
            prev = current
            
            # 转向右子树
            current = current.right
        
        # 连接首尾
        first.left = prev
        prev.right = first
        
        return first
```

### 方法三：分治法

```python
class Solution:
    def treeToDoublyList(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        def convert(node):
            """
            返回 (head, tail) 表示转换后链表的头尾节点
            """
            if not node:
                return None, None
            
            # 递归处理左右子树
            left_head, left_tail = convert(node.left)
            right_head, right_tail = convert(node.right)
            
            # 当前节点作为单个节点
            node.left = node
            node.right = node
            
            # 连接左子树和当前节点
            if left_tail:
                left_tail.right = node
                node.left = left_tail
                head = left_head
            else:
                head = node
            
            # 连接当前节点和右子树
            if right_head:
                node.right = right_head
                right_head.left = node
                tail = right_tail
            else:
                tail = node
            
            return head, tail
        
        head, tail = convert(root)
        
        # 连接首尾形成循环
        head.left = tail
        tail.right = head
        
        return head
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是树中节点数量
  - 需要访问每个节点一次
- 空间复杂度：
  - 方法一（递归）：O(h)，h 是树的高度，递归栈空间
  - 方法二（迭代）：O(h)，栈的空间
  - 方法三（分治）：O(h)，递归栈空间

## 图解示例

以树 `[4,2,5,1,3]` 为例：

```
原始树：
    4
   / \
  2   5
 / \
1   3

中序遍历顺序：1 -> 2 -> 3 -> 4 -> 5

转换过程：
1. 访问节点1（最小值）：
   first = 1, prev = 1

2. 访问节点2：
   1 <-> 2
   prev = 2

3. 访问节点3：
   1 <-> 2 <-> 3
   prev = 3

4. 访问节点4：
   1 <-> 2 <-> 3 <-> 4
   prev = 4

5. 访问节点5（最大值）：
   1 <-> 2 <-> 3 <-> 4 <-> 5
   prev = 5

6. 连接首尾：
   5 <-> 1（形成循环）

最终结果：
1 <-> 2 <-> 3 <-> 4 <-> 5 <-> 1（循环）
```

## 关键点总结

1. **中序遍历**：利用 BST 中序遍历有序的性质
2. **双向连接**：在遍历过程中同时建立 left 和 right 指针
3. **前驱维护**：使用变量记录前一个访问的节点
4. **首尾连接**：遍历结束后记得连接第一个和最后一个节点
5. **边界处理**：空树的情况要特殊处理

## 易错点

1. **忘记连接首尾**：转换成循环链表需要最后连接首尾
2. **prev 初始化**：第一个节点时 prev 为 None，需要特殊处理
3. **指针顺序**：建立双向连接时，要同时设置 left 和 right
4. **返回值**：应该返回最小节点（第一个节点），不是 root
5. **就地转换**：不能创建新节点，要复用原树的节点
