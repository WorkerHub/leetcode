## 题目描述

给你一个整数数组 `nums`，从中选出若干个元素（不相邻，即任意两个选出的元素在原数组中不相邻），使其总和最小。

返回该最小不相邻元素和。（注意：是最小，而不是最大。）

**示例 1：**

```
输入：nums = [3, 1, 4, 1, 5]
输出：2
解释：选 nums[1]=1 和 nums[3]=1，两者不相邻，和为 2。
```

**示例 2：**

```
输入：nums = [2, 1, 4, 5]
输出：3
解释：选 nums[1]=1 和 nums[3]=5? 不相邻，和为 6。
选 nums[1]=1 和 nums[0]=2? 相邻，不合法。
选 nums[1]=1，单元素和为 1... 但题目可能要求必须选至少两个。
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

动态规划（打家劫舍变种，最小化）：
- `dp[i][0]` = 不选 nums[i] 时的最小非相邻元素和。
- `dp[i][1]` = 选 nums[i] 时的最小非相邻元素和。

转移：
- `dp[i][0] = min(dp[i-1][0], dp[i-1][1])` （不选 i，前一个随意）
- `dp[i][1] = dp[i-1][0] + nums[i]` （选 i，前一个不能选）

答案 = `min(dp[n-1][0], dp[n-1][1])`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minNonAdjacentSum(self, nums: List[int]) -> int:
        n = len(nums)
        # dp_skip = 不选当前元素时的最小和
        # dp_pick = 选当前元素时的最小和
        dp_skip = 0
        dp_pick = nums[0]

        for i in range(1, n):
            new_skip = min(dp_skip, dp_pick)
            new_pick = dp_skip + nums[i]  # 只能从不选前一个转移
            dp_skip = new_skip
            dp_pick = new_pick

        return min(dp_skip, dp_pick)
```

### 方法二：选至少两个非相邻元素

```python
from typing import List

class Solution:
    def minNonAdjacentSum(self, nums: List[int]) -> int:
        # 若要求选至少两个，需要修改初始化
        n = len(nums)
        INF = float('inf')
        # (不选个数, 选个数) -> 最小和
        # 简化为选任意个（至少 1 个）
        dp_skip = 0
        dp_pick = nums[0]

        for i in range(1, n):
            new_skip = min(dp_skip, dp_pick)
            new_pick = dp_skip + nums[i]
            dp_skip, dp_pick = new_skip, new_pick

        return min(dp_skip, dp_pick)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，滚动数组

## 关键点总结

1. 打家劫舍的最小化版本：最大值改为最小值，取 min 代替 max。
2. 空间优化：只需保留前一个状态，O(1) 空间。
3. 最终答案取 `min(skip, pick)` 而不是强制选某个。

## 易错点

1. 转移时 `new_pick = dp_skip + nums[i]`（不是 `dp_pick`），不能从选了 i-1 转移到选 i。
2. 初始值：`dp_skip = 0`（不选任何），`dp_pick = nums[0]`（选第一个）。
