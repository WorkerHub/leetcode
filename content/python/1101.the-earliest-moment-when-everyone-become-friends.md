## 题目描述

在一个社交圈子中,有 `n` 个人,编号从 `0` 到 `n-1`。给你一个日志数组 `logs`,其中 `logs[i] = [timestampi, xi, yi]` 表示 `xi` 和 `yi` 将在同一时间 `timestampi` 成为朋友。

友谊是相互的,如果 `a` 和 `b` 是朋友,那么 `b` 和 `a` 也是朋友。

我们说,如果 `a` 和 `b` 是朋友,或者 `a` 是某个人的朋友,而这个人又是 `b` 的朋友,那么 `a` 和 `b` 就是熟人。

返回所有人都成为熟人的最早时间。如果不存在这样的时间,返回 `-1`。

**示例 1:**
```
输入: logs = [[20190101,0,1],[20190104,3,4],[20190107,2,3],[20190211,1,5],[20190224,2,4],[20190301,0,3],[20190312,1,2],[20190322,4,5]], n = 6
输出: 20190301
解释:
第一次: 0 和 1 成为朋友,社交朋友圈分组为 [0,1], [2], [3,4], [5]
第二次: 3 和 4 成为朋友,社交朋友圈分组为 [0,1], [2], [3,4], [5]
第三次: 2 和 3 成为朋友,社交朋友圈分组为 [0,1], [2,3,4], [5]
第四次: 1 和 5 成为朋友,社交朋友圈分组为 [0,1,5], [2,3,4]
第五次: 2 和 4 成为朋友,社交朋友圈分组为 [0,1,5], [2,3,4]
第六次: 0 和 3 成为朋友,社交朋友圈分组为 [0,1,2,3,4,5]
在第六次时,所有人都成为熟人
```

**示例 2:**
```
输入: logs = [[0,2,0],[1,0,1],[3,0,3],[4,1,2],[7,3,1]], n = 4
输出: 3
```

**提示:**
- `2 <= n <= 100`
- `1 <= logs.length <= 10^4`
- `logs[i].length == 3`
- `0 <= timestampi <= 10^9`
- `0 <= xi, yi <= n - 1`
- `xi != yi`
- 所有的时间戳都是唯一的
- 所有的交友事件都按时间戳排序

## 解题思路

这道题本质上是一个**图的连通性问题**,需要找到所有节点首次连通的时刻。

**核心思想:**
1. 使用并查集(Union-Find)数据结构维护连通分量
2. 按时间戳顺序处理每个交友事件
3. 每次合并两个人时,连通分量数减1
4. 当连通分量数变为1时,所有人都连通了

**算法流程:**
1. 按时间戳对日志排序(题目已保证有序)
2. 初始化并查集,每个人自成一个连通分量(共n个)
3. 遍历每个日志:
   - 如果两个人不在同一集合,合并它们
   - 连通分量数减1
   - 如果连通分量数为1,返回当前时间戳
4. 遍历结束后仍未连通,返回-1

## Python 代码实现

### 方法一: 并查集(推荐) ⭐

```python
from typing import List

class Solution:
    def earliestAcq(self, logs: List[List[int]], n: int) -> int:
        # 并查集的父节点数组
        parent = list(range(n))
        # 连通分量的数量,初始为n(每个人都是独立的)
        count = n
        
        def find(x: int) -> int:
            """查找x的根节点,并进行路径压缩"""
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            """合并x和y所在的集合,返回是否成功合并"""
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False  # 已经在同一集合,无需合并
            parent[root_x] = root_y  # 合并
            return True
        
        # 按时间戳排序(题目已保证有序,此步骤可选)
        logs.sort(key=lambda x: x[0])
        
        # 遍历每个交友事件
        for timestamp, x, y in logs:
            if union(x, y):
                count -= 1  # 成功合并,连通分量数减1
                if count == 1:  # 所有人都连通了
                    return timestamp
        
        return -1  # 无法让所有人连通

```

### 方法二: 并查集优化版(按秩合并)

```python
from typing import List

class Solution:
    def earliestAcq(self, logs: List[List[int]], n: int) -> int:
        # 并查集初始化
        parent = list(range(n))
        rank = [0] * n  # 秩(树的高度)
        count = n
        
        def find(x: int) -> int:
            """查找根节点,路径压缩"""
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            """按秩合并"""
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False
            
            # 将秩小的树接到秩大的树下
            if rank[root_x] < rank[root_y]:
                parent[root_x] = root_y
            elif rank[root_x] > rank[root_y]:
                parent[root_y] = root_x
            else:
                parent[root_y] = root_x
                rank[root_x] += 1
            
            return True
        
        # 按时间排序并处理
        logs.sort()
        
        for timestamp, x, y in logs:
            if union(x, y):
                count -= 1
                if count == 1:
                    return timestamp
        
        return -1
```

### 方法三: 使用集合类(简化版)

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.count = n
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False
        self.parent[root_x] = root_y
        self.count -= 1
        return True

class Solution:
    def earliestAcq(self, logs: List[List[int]], n: int) -> int:
        uf = UnionFind(n)
        logs.sort()  # 按时间戳排序
        
        for timestamp, x, y in logs:
            uf.union(x, y)
            if uf.count == 1:  # 所有人连通
                return timestamp
        
        return -1
```

## 复杂度分析

### 方法一和方法二:
- **时间复杂度**: O(m log m + m α(n)),其中 m 是 logs 的长度,n 是人数
  - 排序: O(m log m)
  - 并查集操作: O(m α(n)),α 是阿克曼函数的反函数,几乎为常数
- **空间复杂度**: O(n),并查集需要 O(n) 的空间

## 关键点总结

1. **并查集的应用**: 这是并查集的典型应用场景,用于动态维护连通性
2. **路径压缩优化**: find 操作中将路径上的节点直接连到根节点,降低树高
3. **按秩合并优化**: 将小树接到大树下,保持树的平衡,进一步优化性能
4. **连通分量计数**: 维护 count 变量追踪连通分量数,避免每次都遍历检查
5. **时间顺序**: 必须按时间戳顺序处理事件,题目已保证有序

## 易错点

1. **忘记排序**: 虽然题目保证日志按时间排序,但最好显式排序以防万一
2. **判断条件**: 是 `count == 1` 而不是 `count == 0`
3. **合并判断**: union 返回 false 时不应该减少 count(已经在同一集合)
4. **边界情况**: n = 1 时直接返回任意时间戳,但题目保证 n >= 2
