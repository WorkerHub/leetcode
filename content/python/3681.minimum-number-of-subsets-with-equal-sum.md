## 题目描述

给你一个整数数组 `nums`，将其分成若干非空子集，使得每个子集的元素之和相等。返回最少的子集数量，若无法完成则返回 -1。

**示例 1：**

```
输入：nums = [1,2,3,4,2,3]
输出：3
解释：{1,4,1?}，不对，实际：{1,4},{2,3},{2,3}，每组和5，共3组
```

**示例 2：**

```
输入：nums = [1,2,3]
输出：1
解释：整个数组作为一个子集，和6
```

**提示：**

- `1 <= nums.length <= 16`
- `1 <= nums[i] <= 10^8`

## 解题思路

枚举目标和 `target = total / k`（k 为子集数），检验是否可以分成 k 组和为 target 的子集。

用回溯 + 状态压缩（n <= 16）：`dp[mask]` = mask 对应子集是否可以被恰好分割成若干个和为 target 的子集。

## Python 代码实现

### 方法一：回溯（推荐）

```python
from typing import List

class Solution:
    def minimumSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)

        for k in range(1, n + 1):
            if total % k != 0:
                continue
            target = total // k

            # 检验是否能分成 k 组，每组和为 target
            used = [False] * n
            nums.sort(reverse=True)

            def backtrack(group, curr_sum, start):
                if group == k:
                    return True
                if curr_sum == target:
                    return backtrack(group + 1, 0, 0)
                for i in range(start, n):
                    if not used[i] and curr_sum + nums[i] <= target:
                        used[i] = True
                        if backtrack(group, curr_sum + nums[i], i + 1):
                            return True
                        used[i] = False
                        # 剪枝：若 curr_sum == 0，后续相同值也会失败
                        if curr_sum == 0:
                            break
                return False

            if backtrack(0, 0, 0):
                return k

        return -1
```

### 方法二：状态压缩 DP

```python
from typing import List

class Solution:
    def minimumSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)

        for k in range(1, n + 1):
            if total % k != 0:
                continue
            target = total // k

            # dp[mask] = 能否将 mask 中的元素分成若干组，每组和为 target
            dp = [False] * (1 << n)
            dp[0] = True

            # 每次找一个满足和为 target 的子集
            subset_sums = {}
            for mask in range(1, 1 << n):
                s = sum(nums[i] for i in range(n) if mask >> i & 1)
                if s == target:
                    subset_sums[mask] = True

            # 贪心检验（状态压缩 DP）
            full = (1 << n) - 1
            reachable = {0}
            for _ in range(k):
                new_reachable = set()
                for state in reachable:
                    remaining = full ^ state
                    # 枚举 remaining 的子集
                    sub = remaining
                    while sub:
                        if sub in subset_sums:
                            new_reachable.add(state | sub)
                        sub = (sub - 1) & remaining
                reachable = new_reachable
            if full in reachable:
                return k

        return -1
```

## 复杂度分析

- 时间复杂度：O(k * 2^n * n)（状态压缩），O(k!)（回溯）
- 空间复杂度：O(2^n)

## 关键点总结

1. 枚举子集数 k，检验是否可行
2. 回溯剪枝：元素降序排列，相同和的起始点剪枝
3. 状态压缩适合 n <= 16

## 易错点

1. 总和不能被 k 整除时跳过
2. 最大元素不能超过 target（若超过，k 不可行）
3. 回溯剪枝：`curr_sum == 0` 时重复元素跳过
