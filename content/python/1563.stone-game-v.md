## 题目描述

Alice 和 Bob 玩石子游戏。Alice 先手。

规则：每轮玩家把当前石子序列分成**非空左右两段**，然后**移除和更大的那段**（和相等时可移除任一段），该轮得分为剩下那段石子的总和。游戏继续直到只剩一颗石子为止。

Alice 想**最大化**自己的总分，Bob 想**最小化** Alice 的总分，假设双方都采取最优策略。

返回 Alice 可能的最大得分。

**提示：**
- `1 <= stoneValue.length <= 500`
- `1 <= stoneValue[i] <= 1000`

## 解题思路

### 区间 DP

定义 `dp[i][j]` = 对子数组 `stoneValue[i..j]`，当前轮玩家能获得的最大分数（Alice 先手，双方最优）。

**状态转移：**
枚举分割点 `k`（在 `i` 和 `j-1` 之间）：
- `left_sum = prefix[k+1] - prefix[i]`
- `right_sum = prefix[j+1] - prefix[k+1]`
- 若 `left_sum < right_sum`：移除右段，保留左段，得 `left_sum + dp[i][k]`
- 若 `left_sum > right_sum`：移除左段，保留右段，得 `right_sum + dp[k+1][j]`
- 若 `left_sum == right_sum`：选最大的

`dp[i][j]` = 所有 k 的最大值。

## 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def stoneGameV(self, stoneValue: List[int]) -> int:
        n = len(stoneValue)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + stoneValue[i]

        @lru_cache(maxsize=None)
        def dp(i: int, j: int) -> int:
            if i == j:
                return 0  # 只有一个石子，无法再分
            res = 0
            for k in range(i, j):
                left = prefix[k+1] - prefix[i]
                right = prefix[j+1] - prefix[k+1]
                if left < right:
                    res = max(res, left + dp(i, k))
                elif left > right:
                    res = max(res, right + dp(k+1, j))
                else:
                    res = max(res, left + dp(i, k), right + dp(k+1, j))
            return res

        return dp(0, n - 1)
```

### 方法二：迭代 DP

```python
from typing import List

class Solution:
    def stoneGameV(self, stoneValue: List[int]) -> int:
        n = len(stoneValue)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + stoneValue[i]

        dp = [[0] * n for _ in range(n)]

        # 按区间长度从小到大
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                for k in range(i, j):
                    left = prefix[k+1] - prefix[i]
                    right = prefix[j+1] - prefix[k+1]
                    if left < right:
                        dp[i][j] = max(dp[i][j], left + dp[i][k])
                    elif left > right:
                        dp[i][j] = max(dp[i][j], right + dp[k+1][j])
                    else:
                        dp[i][j] = max(dp[i][j], left + dp[i][k], right + dp[k+1][j])

        return dp[0][n-1]
```

## 复杂度分析

- **时间复杂度**：O(N^3)，三重循环
- **空间复杂度**：O(N^2)，dp 表

N=500 时约 1.25 * 10^8，较慢但通常可以通过。

## 关键点总结

1. 区间 DP 经典题，状态为区间 `[i, j]`，答案为 `dp[0][n-1]`
2. 保留小的那段并继续，得分 = 保留段的和 + 子问题最优解
3. 两段相等时，两种选择都要考虑

## 易错点

- 分割点 `k` 在 `[i, j-1]`（确保两段非空）
- `left_sum == right_sum` 时要取两边递归的最大值
