## 题目描述

你有一个骰子（面值 1 到 6），抛了 `n + m` 次，目前只记录了 `m` 次观测结果（存在 `rolls` 数组中）。已知所有 `n + m` 次抛掷的**平均值**为 `mean`。

你需要找出另外 `n` 次抛掷的结果（每次结果在 1 到 6 之间），使得所有 `n + m` 次抛掷的平均值恰好为 `mean`。

若存在答案，返回任意一个合法的结果数组；否则返回空数组。

**示例 1：**
```
输入：rolls = [3,2,4,3], mean = 4, n = 2
输出：[6,6]
解释：总和应为 (3+2+4+3+6+6)/(2+4) = 24/6 = 4
```

**示例 2：**
```
输入：rolls = [1,5,6], mean = 3, n = 4
输出：[2,3,2,2]
```

**提示：**
- `m == rolls.length`
- `1 <= n, m <= 10^5`
- `1 <= rolls[i] <= 6`
- `1 <= mean <= 6`

## 解题思路

1. 计算目标总和：`target = mean * (n + m)`
2. 计算 `n` 次观测的期望总和：`need = target - sum(rolls)`
3. 验证合法性：`n <= need <= 6 * n`（每次在 1 到 6 之间）
4. 将 `need` 均匀分配给 `n` 个结果：每个先分 `need // n`，前 `need % n` 个各多加 1

## 代码实现

### 方法一：均匀分配（推荐）

```python
from typing import List

class Solution:
    def missingRolls(self, rolls: List[int], mean: int, n: int) -> List[int]:
        m = len(rolls)
        total = mean * (n + m)   # 所有投掷的目标总和
        need = total - sum(rolls) # n 次观测的目标总和

        # 验证合法性
        if need < n or need > 6 * n:
            return []

        # 均匀分配：每个基础值为 need // n，余数 need % n 个各加 1
        base = need // n
        remainder = need % n

        result = [base + 1] * remainder + [base] * (n - remainder)
        return result
```

### 方法二：逐个贪心分配

```python
from typing import List

class Solution:
    def missingRolls(self, rolls: List[int], mean: int, n: int) -> List[int]:
        m = len(rolls)
        need = mean * (n + m) - sum(rolls)

        if need < n or need > 6 * n:
            return []

        result = []
        remaining = need

        for i in range(n, 0, -1):
            # 当前位置分配尽量合法的值
            val = remaining - (i - 1)  # 剩余 i-1 个位置各至少分 1
            val = min(val, 6)          # 不超过 6
            result.append(val)
            remaining -= val

        return result
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. `need = mean * (n + m) - sum(rolls)`，验证 `n <= need <= 6n`
2. 均匀分配：`base = need // n`，前 `need % n` 个值为 `base + 1`
3. 所有分配值均在 `[1, 6]` 范围内（因为 `n <= need <= 6n`）

## 易错点

- 验证条件：最小总和为 `n`（每次1），最大总和为 `6n`（每次6）
- `need` 可能为负（rolls 的和超过总目标），直接返回空
- 余数处理：`need % n` 个位置加 1，其余为基础值
