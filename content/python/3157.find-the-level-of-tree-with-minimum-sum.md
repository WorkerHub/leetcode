## 题目描述

给你一棵二叉树的根节点 `root`，找出节点值之和 **最小** 的层，返回该层的层编号（根节点为第 1 层）。

如果有多层和相同（最小），返回编号最小的层。

**示例 1：**
```
输入：root = [50,1,2,3,4,5]
输出：2
解释：第1层和=50；第2层和=1+2=3；第3层和=3+4+5=12；最小和为3，在第2层。
```

**提示：**
- 树中节点数量在 [1, 10^4]
- -10^5 <= Node.val <= 10^5

## 解题思路

BFS 层序遍历，记录每层的节点值之和，返回和最小的层号。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minimumLevel(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        q = deque([root])
        level = 1
        min_sum = float('inf')
        min_level = 1

        while q:
            layer_sum = 0
            for _ in range(len(q)):
                node = q.popleft()
                layer_sum += node.val
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            if layer_sum < min_sum:
                min_sum = layer_sum
                min_level = level
            level += 1

        return min_level
```

### 方法二：DFS 收集每层和

```python
from typing import Optional

class Solution:
    def minimumLevel(self, root: Optional[TreeNode]) -> int:
        level_sums = []

        def dfs(node, depth):
            if not node:
                return
            if depth == len(level_sums):
                level_sums.append(0)
            level_sums[depth] += node.val
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)

        dfs(root, 0)
        min_sum = min(level_sums)
        return level_sums.index(min_sum) + 1  # 层号从 1 开始
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有节点
- 空间复杂度：O(n)，BFS 队列或递归栈

## 关键点总结

1. BFS 天然按层处理，逐层求和
2. 记录最小和及对应层号
3. 层号从 1 开始

## 易错点

1. 若多层和相同（最小），返回层号最小的，用 `<` 严格小于更新
2. 层号从 1 开始（不是 0）
