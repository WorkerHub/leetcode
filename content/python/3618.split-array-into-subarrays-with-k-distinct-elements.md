## 题目描述

给你一个整数数组 `nums` 和整数 `k`。请将 `nums` 分割成尽可能少的子数组，使得每个子数组中恰好包含 `k` 个不同的整数。

返回最少子数组数，若无法完成分割返回 `-1`。

**示例 1：**

```
输入：nums = [1,2,1,3,2], k = 2
输出：2
解释：[1,2,1] 和 [3,2]，各含2种不同整数
```

**示例 2：**

```
输入：nums = [1,2,3], k = 2
输出：-1
解释：无法每个子数组都恰好含2种
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

贪心 + 滑动窗口：

从左到右，贪心地尽量延伸每个子数组，使其恰好包含 `k` 种不同整数。

策略：
1. 维护当前窗口的不同整数计数
2. 当不同整数数 = k 时，继续延伸（贪心，延伸越长越好）
3. 当下一个元素会导致不同整数数 > k 时，在当前位置切割
4. 若不同整数数 < k 且已到达末尾，返回 -1

## Python 代码实现

### 方法一：贪心滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        i = 0

        while i < n:
            freq = defaultdict(int)
            distinct = 0
            j = i

            # 贪心延伸当前子数组
            while j < n:
                if nums[j] not in freq or freq[nums[j]] == 0:
                    # 新元素
                    if distinct == k:
                        break  # 再加就超过 k 了，切割
                    distinct += 1
                freq[nums[j]] += 1
                j += 1

            if distinct < k:
                return -1  # 剩余元素不足 k 种

            count += 1
            i = j  # 从下一段开始

        return count
```

### 方法二：双指针精确控制

```python
from typing import List
from collections import defaultdict

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        left = 0

        while left < n:
            freq = {}
            right = left
            while right < n:
                x = nums[right]
                freq[x] = freq.get(x, 0) + 1
                if len(freq) > k:
                    # 超过 k 种，不能包含 nums[right]
                    break
                right += 1

            if len(freq) < k:
                return -1

            result += 1
            left = right

        return result
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素至多被访问两次
- 空间复杂度：O(k)，哈希表最多存 k 个键

## 关键点总结

1. 贪心：每段尽量长（延伸至不得不切割）
2. 切割条件：再加一个新元素会使不同数 > k
3. 若最后一段不足 k 种，返回 -1
4. 遍历一次即可，O(n) 时间

## 易错点

1. 区分"不同整数数 = k"（可继续加相同元素）和"> k"（必须切割）
2. 最后一段结束时需检查是否恰好 k 种
3. 不要提前切割，贪心要延伸到极限
