## 题目描述

给你一棵 `n` 个节点的无向无根树，节点编号 0 到 `n-1`，`price[i]` 是节点 `i` 的价格，`edges` 描述树的边。

还有一个行程数组 `trips`，每次行程需要从 `start` 走到 `end`（取最短路径）。

你可以选择若干节点，将其价格减半（减半的节点不能相邻），最小化所有行程的总价格。

返回最小总价格。

**示例 1：**
```
输入：n=4, edges=[[0,1],[1,2],[1,3]], price=[2,2,10,6], trips=[[0,3],[2,1],[2,3]]
输出：23
```

**数据范围：**
- 1 <= n <= 50
- 0 <= edges.length <= n - 1
- price.length == n
- 1 <= price[i] <= 1000
- 1 <= trips.length <= 100

## 解题思路

两步解法：

1. **统计节点经过次数**：对每次行程，用 DFS 找路径，统计路径上每个节点的经过次数（`cnt[i]`）。
2. **树上 DP**：类似打家劫舍，对树 DP，`dp(node, parent, halved)` 表示以 `node` 为根的子树（父节点为 `parent`）在 `node` 是否减半的情况下的最小总费用。
   - `halved=True`：当前节点减半，子节点不能减半
   - `halved=False`：当前节点不减半，子节点可减可不减

## Python 代码实现

### 方法一：DFS 统计 + 树 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumTotalPrice(self, n: int, edges: List[List[int]],
                          price: List[int], trips: List[List[int]]) -> int:
        # 建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 统计每个节点被经过的次数
        cnt = [0] * n

        def find_path(node, parent, target, path):
            """DFS 找从 node 到 target 的路径"""
            if node == target:
                return True
            for nb in graph[node]:
                if nb != parent:
                    path.append(nb)
                    if find_path(nb, node, target, path):
                        return True
                    path.pop()
            return False

        for start, end in trips:
            path = [start]
            find_path(start, -1, end, path)
            for node in path:
                cnt[node] += 1

        # 树上 DP
        def dp(node, parent):
            """
            返回 (不减半时的最小费用, 减半时的最小费用)
            """
            # 当前节点的费用贡献
            full_cost = price[node] * cnt[node]
            half_cost = (price[node] // 2) * cnt[node]

            not_halved = full_cost  # 不减半
            halved = half_cost      # 减半

            for nb in graph[node]:
                if nb != parent:
                    child_not_half, child_half = dp(nb, node)
                    # 当前不减半：子节点可减可不减
                    not_halved += min(child_not_half, child_half)
                    # 当前减半：子节点不能减半
                    halved += child_not_half

            return not_halved, halved

        not_h, h = dp(0, -1)
        return min(not_h, h)
```

## 复杂度分析

- 时间复杂度：O(trips * n + n)，统计经过次数 O(trips * n)，树 DP O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 先用 DFS 找每次行程的路径，统计节点经过次数
2. 树上 DP：减半的节点不能相邻（类似打家劫舍）
3. 每个节点实际代价 = `price[node] * cnt[node]`（考虑经过次数）

## 易错点

1. 减半是 `price[i] // 2`（整除），不是 `price[i] / 2`
2. 路径统计时注意避免重复计数（树结构，路径唯一）
3. 根节点可以是任意节点，DP 从任意根出发即可
