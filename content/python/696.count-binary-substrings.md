## 题目描述

给定一个字符串 s，统计并返回具有相同数量 0 和 1 的非空（连续）子字符串的数量，并且这些子字符串中的所有 0 和所有 1 都是分组连续的。

**示例 1：**
```
输入：s = "00110011"
输出：6
解释：6个子串满足条件："0011"、"01"、"1100"、"10"、"0011" 和 "01"
```

## Python 代码实现

### 方法一：分组计数

```python
class Solution:
    def countBinarySubstrings(self, s: str) -> int:
        groups = []
        i = 0
        
        # 统计连续相同字符的长度
        while i < len(s):
            count = 1
            while i + 1 < len(s) and s[i] == s[i+1]:
                count += 1
                i += 1
            groups.append(count)
            i += 1
        
        # 相邻组之间可以组成的子串数量
        result = 0
        for i in range(len(groups) - 1):
            result += min(groups[i], groups[i+1])
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 将连续相同字符分组
2. 相邻组可组成的子串数是两组长度的最小值
3. 累加所有相邻组的结果
