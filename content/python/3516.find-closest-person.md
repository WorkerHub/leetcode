## 题目描述

有三个人站在数轴上，位置分别为 `x1`、`x2` 和 `x3`（其中 `x1 <= x2 <= x3`）。你需要找到距离 `x1` 和 `x2` 都最近的位置。换句话说，找一个整数位置 `p`，使得 `|p - x1|` 和 `|p - x2|` 的最大值最小，返回该最大值。

实际题目：给定 `x1, x2, y`（三个位置），其中两个人在 `x1` 和 `x2`，找到与这两个人距离相等（或尽可能接近）的位置 `y` 相关的计算。

**示例 1：**

```
输入：x1 = 1, x2 = 5, y = 2
输出：1
解释：person1 在 1，person2 在 5，y = 2。
     距 person1 的距离 = |2-1| = 1，距 person2 的距离 = |2-5| = 3。
     最近的人是 person1，距离为 1。
```

**示例 2：**

```
输入：x1 = 2, x2 = 2, y = 3
输出：0
解释：两人在同一位置 2，y = 3，但返回 0 表示两人距离相同或相关情形。
```

**提示：**
- `1 <= x1, x2, y <= 100`

## 解题思路

计算 `y` 到 `x1` 和 `y` 到 `x2` 的距离，比较大小：
- 若 `y` 到 `x1` 更近，返回 `1`
- 若 `y` 到 `x2` 更近，返回 `2`
- 若距离相等，返回 `0`

## Python 代码实现

### 方法一：直接比较（推荐）

```python
class Solution:
    def findClosestPerson(self, x1: int, x2: int, y: int) -> int:
        d1 = abs(y - x1)  # y 到 person1 的距离
        d2 = abs(y - x2)  # y 到 person2 的距离
        if d1 < d2:
            return 1
        elif d2 < d1:
            return 2
        else:
            return 0  # 距离相等
```

### 方法二：三元表达式简化

```python
class Solution:
    def findClosestPerson(self, x1: int, x2: int, y: int) -> int:
        d1, d2 = abs(y - x1), abs(y - x2)
        # 返回更近的人的编号，相等时返回 0
        return 0 if d1 == d2 else (1 if d1 < d2 else 2)
```

## 复杂度分析

- 时间复杂度：O(1)，常数时间计算
- 空间复杂度：O(1)

## 关键点总结

1. 计算 `y` 到两个位置的绝对距离
2. 比较大小，返回对应编号
3. 距离相等时返回 `0` 作为特殊标识

## 易错点

1. 相等情况要单独处理，不能遗漏
2. 返回值是人的编号（1 或 2），不是距离本身
3. 注意题目中 `0` 的含义（相等）
