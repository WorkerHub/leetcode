## 题目描述

与 3291 相同的问题，但数据范围更大：
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 5 * 10^4`
- `1 <= target.length <= 5 * 10^4`

需要更高效的算法。

## 解题思路

使用**后缀自动机（SAM）**或**字符串哈希**优化匹配。

对每个位置 i，需要找到能从 i 开始匹配的最长前缀长度。

用 **AC 自动机** 或 **后缀自动机** 预处理 words，然后从每个位置 i 开始二分查找最长可匹配长度。

另一种方法：字符串哈希 + 二分。

预计算所有 words 中长度 l 的前缀集合（哈希值），然后对每个位置 i，二分查找最长可匹配长度。

## Python 代码实现

### 方法一：哈希 + 二分（推荐）

```python
from typing import List

class Solution:
    def minValidStrings(self, words: List[str], target: List[str]) -> int:
        if isinstance(target, list):
            target = ''.join(target)
        
        n = len(target)
        MOD = (1 << 61) - 1
        BASE = 131
        
        # 预计算 target 的哈希前缀
        h = [0] * (n + 1)
        pw = [1] * (n + 1)
        for i in range(n):
            h[i + 1] = (h[i] * BASE + ord(target[i])) % MOD
            pw[i + 1] = pw[i] * BASE % MOD
        
        def get_hash(l, r):
            # hash of target[l..r-1]
            return (h[r] - h[l] * pw[r - l]) % MOD
        
        # 按长度收集所有 words 前缀的哈希集合
        # prefix_hashes[l] = set of hash values of length-l prefixes
        from collections import defaultdict
        max_word_len = max(len(w) for w in words)
        prefix_hashes = defaultdict(set)
        
        for word in words:
            h_w = 0
            for i, c in enumerate(word):
                h_w = (h_w * BASE + ord(c)) % MOD
                prefix_hashes[i + 1].add(h_w)
        
        # DP + 二分
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(n):
            if dp[i] == INF:
                continue
            # 二分查找最长可匹配长度
            lo, hi = 1, min(n - i, max_word_len)
            # 找最大 len 使得 target[i..i+len-1] 在某 word 前缀中
            best = 0
            while lo <= hi:
                mid = (lo + hi) // 2
                if get_hash(i, i + mid) in prefix_hashes[mid]:
                    best = mid
                    lo = mid + 1
                else:
                    hi = mid - 1
            
            for j in range(i + 1, i + best + 1):
                if dp[i] + 1 < dp[j]:
                    dp[j] = dp[i] + 1
        
        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n log n + sum(|words|))
- 空间复杂度：O(n + sum(|words|))

## 关键点总结

1. 字符串哈希预处理 target 的前缀哈希
2. 将所有 words 的前缀按长度分组，存入哈希集合
3. 对每个位置二分查找最长可匹配前缀长度

## 易错点

1. 哈希冲突可能导致错误，可以使用双哈希
2. 最大匹配长度不超过 max word length
