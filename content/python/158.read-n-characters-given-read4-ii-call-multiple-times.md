## 题目描述

给你一个文件，并且该文件只能通过给定的 `read4` 方法来读取，请实现一个方法 `read` 使其能够读取 n 个字符。注意：你的 `read` 方法可能会被调用多次。

**read4 方法：**

API `read4` 可以从文件中读取 4 个连续的字符，并且将它们写入缓存数组 `buf4` 中。

返回值为实际读取的字符个数。

注意 `read4()` 自身拥有文件指针，很像 C 语言中的 `FILE *fp`。

read4 的定义：

```
参数类型: char[] buf4
返回类型: int
```

**read 方法：**

通过使用 `read4` 方法，实现 `read` 方法。该方法可以从文件中读取 n 个字符并将其存储到缓存数组 `buf` 中。您不能直接操作文件。

`read` 方法可能会被调用多次。

read 的定义：

```
参数类型: char[] buf, int n
返回类型: int
```

**示例 1：**
```
输入：file = "abc", queries = [1, 2, 1]
输出：[1, 2, 0]
解释：测试用例表示以下场景:
File file("abc");
Solution sol;
sol.read(buf, 1); // 调用 read 方法后，buf 应该包含 "a"。我们从文件中总共读取了 1 个字符，所以返回 1。
sol.read(buf, 2); // 现在 buf 应该包含 "bc"。我们从文件中总共读取了 2 个字符，所以返回 2。
sol.read(buf, 1); // 我们已经到达文件末尾，不能读取更多字符，所以返回 0。
```

**示例 2：**
```
输入：file = "abc", queries = [4, 1]
输出：[3, 0]
解释：
sol.read(buf, 4); // 调用 read 方法后，buf 应该包含 "abc"。我们从文件中总共读取了 3 个字符，所以返回 3。
sol.read(buf, 1); // 我们已经到达文件末尾，不能读取更多字符，所以返回 0。
```

**提示：**
- 1 <= file.length <= 500
- file 由英文字母和数字组成
- 1 <= queries.length <= 10
- 1 <= queries[i] <= 500

## 解题思路

这道题是 157 题的进阶版，关键区别在于 `read` 方法会被多次调用，而 `read4` 有文件指针会持续向前移动。

**核心问题：**

1. 第一次调用 `read(buf, 1)` 时，`read4` 可能读取了 4 个字符，但只需要返回 1 个
2. 剩余的 3 个字符需要保存起来，供下次调用 `read` 时使用
3. 需要维护一个内部缓冲区来存储上次读取但未使用的字符

**解决方案：**

使用一个内部缓冲区（成员变量）来保存上次调用 `read4` 时多读取的字符：
- `buffer`：存储上次多读的字符
- `buffer_ptr`：指向 buffer 中下一个要读取的字符
- `buffer_count`：buffer 中剩余可用的字符数

**算法流程：**

1. 先从内部缓冲区读取字符（如果有）
2. 如果内部缓冲区不够，调用 `read4` 继续读取
3. 如果 `read4` 读取的字符超过需求，将多余字符存入内部缓冲区
4. 返回实际读取的字符数

## Python 代码实现

### 方法一：使用内部缓冲区（推荐）⭐

```python
"""
The read4 API is already defined for you.

    @param buf4, List[str]: a list of characters
    @return an integer
    def read4(buf4: List[str]) -> int:
"""

class Solution:
    def __init__(self):
        """
        初始化内部缓冲区
        buffer: 存储上次 read4 多读的字符
        buffer_ptr: buffer 中下一个要读取的位置
        buffer_count: buffer 中剩余的字符数
        """
        self.buffer = [''] * 4  # 内部缓冲区，最多 4 个字符
        self.buffer_ptr = 0     # 缓冲区读取指针
        self.buffer_count = 0   # 缓冲区中剩余字符数
    
    def read(self, buf: List[str], n: int) -> int:
        """
        读取 n 个字符到 buf 中
        时间复杂度：O(n)
        空间复杂度：O(1)，内部缓冲区大小固定为 4
        """
        total_read = 0  # 已经读取的字符数
        
        while total_read < n:
            # 情况 1：内部缓冲区还有字符，先使用缓冲区的字符
            if self.buffer_count > 0:
                buf[total_read] = self.buffer[self.buffer_ptr]
                self.buffer_ptr += 1
                self.buffer_count -= 1
                total_read += 1
            else:
                # 情况 2：内部缓冲区为空，调用 read4 读取新字符
                buf4 = [''] * 4
                count = read4(buf4)
                
                # 文件读完了
                if count == 0:
                    break
                
                # 将读取的字符存入内部缓冲区
                self.buffer = buf4
                self.buffer_ptr = 0
                self.buffer_count = count
        
        return total_read
```

### 方法二：优化版本（批量复制）

```python
class Solution:
    def __init__(self):
        self.buffer = [''] * 4
        self.buffer_ptr = 0
        self.buffer_count = 0
    
    def read(self, buf: List[str], n: int) -> int:
        """
        优化版本：批量复制字符，减少循环次数
        """
        total_read = 0
        
        while total_read < n:
            # 先从内部缓冲区读取
            if self.buffer_count > 0:
                # 计算本次可以从缓冲区读取的字符数
                chars_to_read = min(self.buffer_count, n - total_read)
                
                # 批量复制
                for i in range(chars_to_read):
                    buf[total_read] = self.buffer[self.buffer_ptr]
                    total_read += 1
                    self.buffer_ptr += 1
                    self.buffer_count -= 1
            else:
                # 内部缓冲区为空，调用 read4
                buf4 = [''] * 4
                count = read4(buf4)
                
                if count == 0:
                    break
                
                # 重置内部缓冲区
                self.buffer = buf4
                self.buffer_ptr = 0
                self.buffer_count = count
        
        return total_read
```

### 方法三：使用队列（更直观）

```python
from collections import deque

class Solution:
    def __init__(self):
        # 使用队列存储字符，更直观
        self.queue = deque()
    
    def read(self, buf: List[str], n: int) -> int:
        """
        使用队列作为内部缓冲区
        时间复杂度：O(n)
        空间复杂度：O(k)，k 是队列中字符数，最多 3
        """
        total_read = 0
        
        # 先从队列中读取
        while total_read < n and self.queue:
            buf[total_read] = self.queue.popleft()
            total_read += 1
        
        # 如果还需要更多字符，调用 read4
        while total_read < n:
            buf4 = [''] * 4
            count = read4(buf4)
            
            if count == 0:
                break
            
            # 将字符加入队列或直接复制到 buf
            for i in range(count):
                if total_read < n:
                    buf[total_read] = buf4[i]
                    total_read += 1
                else:
                    # 多余的字符加入队列
                    self.queue.append(buf4[i])
        
        return total_read
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，每个字符最多被处理常数次
- 空间复杂度：O(1)，内部缓冲区大小固定（方法一、二）或 O(k)（方法三，k ≤ 3）

## 图解示例

示例 1：file = "abc", queries = [1, 2, 1]

```
初始状态：
文件指针在 'a'
buffer = []

第 1 次调用 read(buf, 1)：
- buffer 为空，调用 read4
- read4 读取 ['a','b','c',''] (count=3，文件只有 3 个字符)
- 需要 1 个字符，返回 'a'
- buffer 保存 ['b','c']
- 返回 1

第 2 次调用 read(buf, 2)：
- buffer 有 ['b','c']
- 需要 2 个字符，buffer 正好够用
- 返回 'b', 'c'
- buffer 变空
- 返回 2

第 3 次调用 read(buf, 1)：
- buffer 为空，调用 read4
- read4 返回 0（文件已读完）
- 返回 0
```

## 关键点总结

1. **状态保持**：使用成员变量保存内部缓冲区状态
2. **优先使用缓冲区**：先从内部缓冲区读取，再调用 read4
3. **缓冲区管理**：正确维护 buffer_ptr 和 buffer_count
4. **多次调用**：每次调用 read 时，内部状态会延续
5. **文件指针**：read4 的文件指针会一直向前，不会回退

## 易错点

1. **忘记保存多余字符**：read4 读取的多余字符必须保存到内部缓冲区
2. **缓冲区指针错误**：buffer_ptr 和 buffer_count 的更新要同步
3. **重复读取**：不要重新初始化内部缓冲区（除非 read4 返回新数据）
4. **边界处理**：第一次调用时 buffer_count 为 0，需要先调用 read4
5. **状态混淆**：区分内部缓冲区状态和 read4 的状态
