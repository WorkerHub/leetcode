## 题目描述

给定字符串 `s` 和整数 `k`，统计满足以下条件的子串数量：子串中每种出现的字母恰好出现 `k` 次。

**示例 1：**
```
输入：s = "abab", k = 2
输出：1
解释：子串 "abab" 中 'a' 出现 2 次，'b' 出现 2 次，满足条件。
```

**示例 2：**
```
输入：s = "aaa", k = 1
输出：3
解释："a"(0,0)，"a"(1,1)，"a"(2,2) 各自 'a' 出现 1 次，满足条件。
```

**提示：**
- `1 <= s.length <= 10^4`
- `1 <= k <= s.length`
- `s` 只包含小写字母

## 解题思路

**滑动窗口 + 「恰好 k 次」转化：**

统计每种字母恰好出现 k 次，等价于：
- 「每种字母出现次数 >= k 次」的子串数
- 减去「每种字母出现次数 >= k+1 次」的子串数

用函数 `at_least(m)` 统计"每种字母出现次数 >= m"的子串数，答案为 `at_least(k) - at_least(k+1)`。

`at_least(m)` 用滑动窗口：维护窗口内所有字母频率均 >= m 的最小右边界（不直接适用），实际上改为：统计"存在某字母出现次数 < m"的子串，再用总数相减也较复杂。

更直接的做法：枚举左端点，用右端点滑动。

**直接 O(n^2) 方法：** 固定左端点，扩展右端点，维护频率字典，满足条件时计数。

## Python 代码实现

### 方法一：枚举左端点（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        ans = 0

        for left in range(n):
            freq = defaultdict(int)
            # 记录超过 k 次的字母数量
            over = 0  # 出现次数 > k 的字母种类数
            # 记录恰好 k 次的字母数量
            exact = 0  # 出现次数恰好为 k 的字母种类数
            total_kinds = 0  # 出现过的字母种类数

            for right in range(left, n):
                c = s[right]
                freq[c] += 1

                if freq[c] == 1:
                    total_kinds += 1
                if freq[c] == k:
                    exact += 1
                elif freq[c] == k + 1:
                    exact -= 1
                    over += 1

                # 满足条件：所有出现过的字母都恰好 k 次
                # 即 over == 0 且 exact == total_kinds
                if over == 0 and exact == total_kinds:
                    ans += 1

        return ans
```

### 方法二：滑动窗口（at_least 转化）

```python
from collections import defaultdict

class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        # 统计每种出现字母均 >= min_k 次的子串数
        def at_least(min_k: int) -> int:
            freq = defaultdict(int)
            satisfied = 0  # 已达到 min_k 次的字母种类
            kinds = 0       # 出现过的字母种类
            res = 0
            left = 0

            for right in range(len(s)):
                c = s[right]
                freq[c] += 1
                if freq[c] == 1:
                    kinds += 1
                if freq[c] == min_k:
                    satisfied += 1

                # 收缩左端点：直到某字母不满足 >= min_k
                while satisfied == kinds and kinds > 0:
                    res += len(s) - right
                    lc = s[left]
                    if freq[lc] == min_k:
                        satisfied -= 1
                    freq[lc] -= 1
                    if freq[lc] == 0:
                        kinds -= 1
                    left += 1

            return res

        return at_least(k) - at_least(k + 1)
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一），O(n * 26)（方法二）
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 「恰好 k 次」= 「至少 k 次」- 「至少 k+1 次」
2. 滑动窗口维护满足条件的子串范围
3. 追踪 `over`（超过 k 次的种类数）判断是否满足

## 易错点

1. 子串中"每种出现的字母"都要恰好 k 次，不是特定字母
2. 方法二的双指针方向是当全部满足时累加右侧子串数
