## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，表示英雄的能力值。一个英雄组的力量定义为：最大能力值的平方乘以最小能力值。

返回所有**非空**英雄组的力量之和（对 `10^9 + 7` 取模）。

**示例 1：**
```
输入：nums = [2,1,4]
输出：141
解释：所有非空子集的力量：
[2]:2^2*2=8; [1]:1; [4]:64; [2,1]:4*1=4; [2,4]:16*2=32; [1,4]:16*1=16; [2,1,4]:16*1=16
8+1+64+4+32+16+16=141
```

**数据范围：**
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^9

## 解题思路

排序后，枚举最大值。对于排序后的数组，若 `nums[i]` 是最大值，枚举所有包含 `nums[i]` 且最大值恰为 `nums[i]` 的子集。

对于固定最大值 `nums[i]`，最小值可以是 `nums[0..i]` 中的任意一个，且子集还可以包含任意 `nums[j]`（j < i, j != min_idx）。

用前缀和优化：设 `dp = sum(nums[0..i-1])` 的所有可能子集的权重，每个子集中最小值的贡献为其值，在 `nums[i]` 作为最大值时贡献 `nums[i]^2 * min`。

推导：对每个 `i`，贡献 = `nums[i]^2 * sum(nums[j] * 2^(i-1-j) for j in 0..i-1) + nums[i]^2 * nums[i]`

即 `dp[i] = 2 * dp[i-1] + nums[i-1]`，ans += `nums[i]^2 * dp[i]`（其中 dp[i] 为以 nums[i] 为最大时的最小值加权前缀和）。

## Python 代码实现

### 方法一：排序 + DP（推荐）

```python
from typing import List

class Solution:
    def sumOfPower(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        nums.sort()
        n = len(nums)

        ans = 0
        # dp 表示以 nums[0..i-1] 中元素为最小值时的加权和
        # 加权：每次 i 增加，旧最小值的贡献翻倍（多一个2的幂次选择）
        dp = 0
        for i in range(n):
            # nums[i] 作为最大值，贡献 nums[i]^2 * (dp + nums[i])
            # dp 是前面所有可能最小值的加权和，nums[i] 作为自身最小值的情况
            ans = (ans + nums[i] * nums[i] % MOD * (dp + nums[i])) % MOD
            # 更新 dp：旧的每个子集可以不选 nums[i+1]（贡献翻倍，因为下一个最大值来时多一种选择）
            dp = (2 * dp + nums[i]) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后枚举最大值 `nums[i]`
2. DP：`dp = sum(nums[j] * 2^(i-1-j))` 表示前 i 个元素作为最小值的加权和
3. 更新公式：`dp = 2 * dp + nums[i]`（新加入 nums[i] 后，旧贡献翻倍，nums[i] 加入一次）

## 易错点

1. 注意取模
2. dp 的含义：考虑以前面某个元素为最小时，该元素值乘以"有多少个超集以 nums[i] 为最大"
3. `dp + nums[i]` = 前面所有子集中最小值的加权总和 + nums[i] 自身作为最小值的贡献
