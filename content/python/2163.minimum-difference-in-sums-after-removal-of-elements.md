## 题目描述

给你一个下标从 **0** 开始、长度为 `3 * n` 的整数数组 `nums`。

你需要从中去除**恰好 n 个元素**，剩余 `2n` 个元素中前 n 个（下标更小）之和称为 `sumFirst`，后 n 个之和称为 `sumSecond`。

返回 `sumFirst - sumSecond` 的**最小值**。

**示例：**
```
输入：nums = [3,1,2]
输出：-1
解释：去除 nums[0]=3，剩余 [1,2]，sumFirst=1，sumSecond=2，差=-1。
```

**提示：**
- `nums.length == 3 * n`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**双堆（前 n 最小 + 后 n 最大）**

分割点 i（n <= i <= 2n）将 `nums` 分为：
- 前半部分：`nums[0..i-1]`（从中选 n 个最小，最小化 sumFirst）。
- 后半部分：`nums[i..3n-1]`（从中选 n 个最大，最大化 sumSecond）。

**预计算：**
- `left[i]`：从 `nums[0..i-1]` 中选 n 个最小值的和（前缀最小 n 个之和）。
- `right[i]`：从 `nums[i..3n-1]` 中选 n 个最大值的和（后缀最大 n 个之和）。

用最大堆维护前缀最小 n 个：遍历时维护一个大小为 n 的最大堆，堆顶是当前 n 个最小值中最大的，若新元素比堆顶小则替换。

用最小堆维护后缀最大 n 个：类似地从右往左。

## 代码实现

### 方法一：双堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 3
        total = 3 * n

        # left[i]: nums[0..i-1] 中 n 个最小值之和（i 从 n 到 2n）
        left = [0] * (total + 1)
        max_heap = []  # 最大堆（用负数模拟）
        cur_sum = 0
        for i in range(n):
            heapq.heappush(max_heap, -nums[i])
            cur_sum += nums[i]
        left[n] = cur_sum

        for i in range(n, 2 * n):
            heapq.heappush(max_heap, -nums[i])
            cur_sum += nums[i]
            # 若堆中有 n+1 个，弹出最大的
            cur_sum += heapq.heappop(max_heap)  # 弹出的是最大的（负数取反）
            left[i + 1] = cur_sum

        # right[i]: nums[i..3n-1] 中 n 个最大值之和（i 从 n 到 2n）
        right = [0] * (total + 1)
        min_heap = []
        cur_sum = 0
        for i in range(total - 1, total - n - 1, -1):
            heapq.heappush(min_heap, nums[i])
            cur_sum += nums[i]
        right[2 * n] = cur_sum

        for i in range(2 * n - 1, n - 1, -1):
            heapq.heappush(min_heap, nums[i])
            cur_sum += nums[i]
            # 若堆中有 n+1 个，弹出最小的
            cur_sum -= heapq.heappop(min_heap)
            right[i] = cur_sum

        # 枚举分割点
        return min(left[i] - right[i] for i in range(n, 2 * n + 1))
```

### 方法二：更清晰的实现

```python
from typing import List
import heapq

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 3

        # 计算前缀最小 n 个之和
        pre_min = [0] * (3 * n + 1)
        heap = []  # 最大堆
        s = 0
        for i in range(2 * n):
            x = nums[i]
            heapq.heappush(heap, -x)
            s += x
            if len(heap) > n:
                s += heapq.heappop(heap)  # 加回负数（即减去最大值）
            if len(heap) == n:
                pre_min[i + 1] = s

        # 计算后缀最大 n 个之和
        suf_max = [0] * (3 * n + 1)
        heap2 = []  # 最小堆
        s2 = 0
        for i in range(3 * n - 1, n - 1, -1):
            x = nums[i]
            heapq.heappush(heap2, x)
            s2 += x
            if len(heap2) > n:
                s2 -= heapq.heappop(heap2)
            if len(heap2) == n:
                suf_max[i] = s2

        return min(pre_min[i] - suf_max[i] for i in range(n, 2 * n + 1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双堆 | O(n log n) | O(n) |

## 关键点总结

1. 问题转化：枚举分割点 i，前 i 个取最小 n 个，后 3n-i 个取最大 n 个，最小化差值。
2. 前缀最小 n 个用最大堆维护，后缀最大 n 个用最小堆维护。
3. 堆超过 n 个时弹出最大/最小元素，保持大小恰好为 n。

## 易错点

- Python 的 heapq 是最小堆，模拟最大堆需要存负数。
- 注意前缀和 `left[i]` 表示 `nums[0..i-1]` 的最小 n 个之和（i 从 n 到 2n+1）。
