## 题目描述

给你一个整数数组 `nums` 和两个整数 `k` 和 `p`。

返回满足以下条件的**不同**子数组数量：
- 子数组中整除 `p` 的元素数量**最多为 `k` 个**。

**两个子数组相同**：内容完全一致（相同元素同一顺序）。

**示例 1：**
```
输入：nums = [2,3,3,2,2], k = 2, p = 2
输出：11
```

**示例 2：**
```
输入：nums = [1,2,3,4], k = 4, p = 1
输出：10
```

## 解题思路

**方法一：哈希集合（枚举子数组）：** 枚举所有子数组，将满足条件的子数组转为元组（或字符串）加入集合去重，最后返回集合大小。

时间 O(n^2)，空间 O(n^3)（存所有不同子数组），n <= 200 可行。

**方法二：字典树（Trie）去重：** 每个子数组对应字典树中的一条路径，通过字典树统计不同子数组数量。

## 代码实现

### 方法一：哈希集合（推荐，n<=200可行）

```python
from typing import List

class Solution:
    def countDistinct(self, nums: List[int], k: int, p: int) -> int:
        n = len(nums)
        seen = set()

        for i in range(n):
            cnt = 0  # 当前子数组中整除 p 的元素数
            for j in range(i, n):
                if nums[j] % p == 0:
                    cnt += 1
                if cnt > k:
                    break  # 超出限制，停止扩展
                # 将子数组转为元组加入集合
                seen.add(tuple(nums[i:j + 1]))

        return len(seen)
```

### 方法二：字典树（Trie）去重

```python
from typing import List

class Solution:
    def countDistinct(self, nums: List[int], k: int, p: int) -> int:
        # 字典树节点
        trie = {}  # 嵌套字典模拟 Trie
        count = 0
        n = len(nums)

        for i in range(n):
            node = trie
            div_count = 0
            for j in range(i, n):
                if nums[j] % p == 0:
                    div_count += 1
                if div_count > k:
                    break
                # 将 nums[j] 作为下一个节点
                if nums[j] not in node:
                    node[nums[j]] = {}
                    count += 1  # 新的子数组
                node = node[nums[j]]

        return count
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n^3)，枚举 O(n^2)，元组哈希 O(n)。
- 空间复杂度：O(n^3)，存储所有子数组。

**方法二（字典树）：**
- 时间复杂度：O(n^2)，每个子数组只访问字典树 O(1) 次（均摊）。
- 空间复杂度：O(n^2)，字典树节点数。

## 关键点总结

1. 方法一简单直观，用集合存储所有不同子数组（元组形式）。
2. 方法二字典树更高效，沿树路径判断是否为新子数组。
3. 字典树中每个新节点对应一个新的不同子数组。

## 易错点

- 题目要的是"不同"子数组，即内容不同，不是下标不同。
- 方法一用 `tuple` 作为集合元素，`list` 不可哈希。
- 超出 `k` 个整除元素时立即 `break`（后续子数组只会更多）。
