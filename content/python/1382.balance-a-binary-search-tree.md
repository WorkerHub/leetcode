## 题目描述

给你一棵二叉搜索树，请你返回一棵**平衡后**的二叉搜索树，新生成的树应该与原来的树有着**相同的节点值**。

如果有多种构造方法，请你返回任意一种。

**平衡二叉树**是指：一棵二叉树中，每一个节点的左右两个子树的高度差的绝对值不超过 1。

**示例 1：**
```
输入：root = [1,null,2,null,3,null,4]
输出：[2,1,3,null,null,null,4]
或：  [3,1,4,null,2]
（任意一种平衡 BST 都可以）
```

**示例 2：**
```
输入：root = [2,1,3]
输出：[2,1,3]（已经平衡）
```

**提示：**
- 树节点的数目在 `[1, 10^4]` 范围内
- `1 <= Node.val <= 10^5`

## 解题思路

### 核心思想：中序遍历 + 分治建树

**BST 的中序遍历是有序数组！**

利用这个性质，可以分两步解决：
1. **中序遍历**原 BST，得到有序数组 `nodes`。
2. **分治构建**平衡 BST：每次取数组中间元素作为根，左半部分构建左子树，右半部分构建右子树。

**为什么取中间元素能保证平衡？**
- 每次选中点分割，左右两半的大小之差最多为1。
- 递归构建时，每层都保持这个性质，最终高度差不超过1。
- 这本质上是将有序数组转化为高度最小（最平衡）的 BST。

## Python 代码实现

### 方法一：中序遍历 + 递归分治建树（推荐）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def balanceBST(self, root: TreeNode) -> TreeNode:
        # 步骤1：中序遍历得到有序节点值列表
        nodes = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)
            nodes.append(node.val)   # 也可以 append(node) 复用节点对象
            inorder(node.right)

        inorder(root)

        # 步骤2：递归分治，从有序数组构建平衡 BST
        def build(left, right):
            """
            从 nodes[left..right] 构建平衡 BST
            取中间元素为根，左半建左子树，右半建右子树
            """
            if left > right:
                return None
            mid = (left + right) // 2   # 取中间下标
            node = TreeNode(nodes[mid])  # 以中间值创建新节点
            node.left = build(left, mid - 1)
            node.right = build(mid + 1, right)
            return node

        return build(0, len(nodes) - 1)
```

### 方法二：复用原有节点（节省内存）

```python
from typing import Optional, List

class Solution:
    def balanceBST(self, root: TreeNode) -> TreeNode:
        # 中序遍历，收集节点对象（复用节点，节省内存分配）
        nodes = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)
            nodes.append(node)
            inorder(node.right)

        inorder(root)

        def build(left, right):
            if left > right:
                return None
            mid = (left + right) // 2
            node = nodes[mid]
            # 重新连接左右子树（必须重新设置，否则原有连接可能造成错误）
            node.left = build(left, mid - 1)
            node.right = build(mid + 1, right)
            return node

        return build(0, len(nodes) - 1)
```

### 方法三：将中序遍历与建树合并（一次遍历）

```python
from typing import Optional

class Solution:
    def balanceBST(self, root: TreeNode) -> TreeNode:
        # 先获取 BST 大小
        def get_size(node):
            if not node:
                return 0
            return 1 + get_size(node.left) + get_size(node.right)

        # 中序遍历生成器
        def inorder_gen(node):
            if not node:
                return
            yield from inorder_gen(node.left)
            yield node.val
            yield from inorder_gen(node.right)

        nodes = list(inorder_gen(root))

        # 递归建树
        def build(l, r):
            if l > r:
                return None
            m = (l + r) // 2
            return TreeNode(nodes[m], build(l, m-1), build(m+1, r))

        return build(0, len(nodes) - 1)
```

### 方法四：迭代中序遍历（避免递归栈溢出）

```python
from typing import Optional, List

class Solution:
    def balanceBST(self, root: TreeNode) -> TreeNode:
        # 迭代版中序遍历，避免深树时递归栈溢出
        nodes = []
        stack = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            nodes.append(cur.val)
            cur = cur.right

        # 递归建树（节点数最多10^4，递归深度约14，不会溢出）
        def build(l, r):
            if l > r:
                return None
            m = (l + r) // 2
            return TreeNode(nodes[m], build(l, m-1), build(m+1, r))

        return build(0, len(nodes) - 1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（新建节点） | O(n) | O(n) |
| 方法二（复用节点） | O(n) | O(n) |
| 方法四（迭代中序） | O(n) | O(n) |

- **时间复杂度**：O(n)，中序遍历 O(n) + 建树 O(n)。
- **空间复杂度**：O(n)，存储中序序列，以及递归栈 O(log n)（建树时已平衡）。

## 关键点总结

1. **BST 中序遍历 = 有序序列**：这是本题的基础，也是 BST 最重要的性质。
2. **有序数组 → 平衡 BST**：取中点为根，递归建左右子树，保证高度最小。
3. **分治的平衡性证明**：每次将长度 n 的区间分为 `[0, mid-1]` 和 `[mid+1, n-1]`，长度差最多为1，递归保证整体平衡。
4. 建树时使用下标范围 `[left, right]`，避免数组切片带来的额外内存开销。
5. 结果不唯一，任何合法的平衡 BST 都可以接受。

## 易错点

1. **`mid = (left + right) // 2`**：注意整除取下界，确保递归正确终止。
2. **复用节点时必须重新设置 left/right 指针**：否则原有的子节点连接会导致错误或循环。
3. **build(left, mid-1) 而不是 build(left, mid)**：根节点是 `mid`，左子树的范围是 `[left, mid-1]`，不包含 `mid`。
4. **当 left > right 时返回 None**：递归终止条件。
