## 题目描述

给你一个下标从 **0** 开始的字符串数组 `words`。

如果两个字符串由相同的字符组成（包含相同的字母，不计重复），则认为这两个字符串 **相似**。

- 例如，`"abca"` 和 `"cba"` 相似，因为它们都由字符 `'a'`、`'b'`、`'c'` 组成。
- 然而，`"abacba"` 和 `"bcfd"` 不相似，因为它们包含不同的字符。

请你返回满足字符串 `words[i]` 和 `words[j]` 相似的下标对 `(i, j)` 的数目，其中 `0 <= i < j <= words.length - 1`。

**示例 1：**

```
输入：words = ["aba","aabb","abcd","bac","aabc"]
输出：2
解释：(0,1) 对应 "aba" 和 "aabb"，都由 {a,b} 组成。(1,4) 对应 "aabb" 和 "aabc"，都由 {a,b,c} 组成。
```

**示例 2：**

```
输入：words = ["aabb","ab","ba"]
输出：3
```

**提示：**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 只包含小写英文字母

## 解题思路

将每个字符串转为其字符集合的"指纹"（frozenset 或位掩码），然后用哈希表统计相同指纹出现的次数，对同一指纹出现 k 次，贡献 k*(k-1)/2 对。

位掩码方法：用一个 26 位整数表示字符集，第 i 位为 1 表示第 i 个小写字母存在。

## Python 代码实现

### 方法一：frozenset + 哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def similarPairs(self, words: List[str]) -> int:
        # 每个单词的字符集合用 frozenset 表示
        count = Counter(frozenset(w) for w in words)
        # 相同字符集合的单词两两配对
        return sum(v * (v - 1) // 2 for v in count.values())
```

### 方法二：位掩码

```python
from typing import List
from collections import Counter

class Solution:
    def similarPairs(self, words: List[str]) -> int:
        def word_mask(w: str) -> int:
            # 用 26 位整数表示字符集
            mask = 0
            for ch in w:
                mask |= (1 << (ord(ch) - ord('a')))
            return mask

        count = Counter(word_mask(w) for w in words)
        return sum(v * (v - 1) // 2 for v in count.values())
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为单词数，L 为平均单词长度
- 空间复杂度：O(n)，哈希表存储每个单词的指纹

## 关键点总结

1. 字符集合用 frozenset 或位掩码表示，去除重复字符和顺序影响
2. 相同指纹出现 k 次，贡献 C(k, 2) = k*(k-1)/2 对
3. 位掩码方法更高效，26 位整数即可表示所有小写字母组合

## 易错点

1. 字符集合只关注"是否存在"，不关注出现次数，需要去重
2. 组合数公式：k 个元素中取 2 个 = k*(k-1)/2
3. frozenset 是不可变集合，可以作为字典的 key
