## 题目描述

给你一个数组 `heights`，其中 `heights[i]` 代表第 `i` 座建筑的高度。所有建筑都在海洋的一侧。

如果从建筑 `i` 能看到海洋，则这座建筑的右侧**不存在**相同或更高的建筑，即对于右侧所有建筑 `j`（`j > i`），都有 `heights[j] < heights[i]`。

请你返回能看到海洋的建筑的下标（从小到大排列）。

**示例 1：**
```
输入：heights = [4,2,3,1]
输出：[0,2,3]
```

**提示：**
- `1 <= heights.length <= 10^5`
- `1 <= heights[i] <= 10^8`

## 解题思路

从右往左遍历，维护当前右侧最大高度。若当前建筑比右侧所有建筑都高，则可以看到海洋。

或者从右往左遍历，用单调栈维护。

## 代码实现

### 方法一：从右往左扫描（推荐）

```python
from typing import List

class Solution:
    def findBuildings(self, heights: List[int]) -> List[int]:
        n = len(heights)
        result = []
        max_right = 0  # 当前建筑右侧的最大高度
        
        for i in range(n - 1, -1, -1):
            if heights[i] > max_right:
                result.append(i)
                max_right = heights[i]
        
        # 反转结果（从右往左添加的，需要反序）
        return result[::-1]
```

### 方法二：单调栈

```python
from typing import List

class Solution:
    def findBuildings(self, heights: List[int]) -> List[int]:
        # 从左往右，维护严格递减的单调栈
        stack = []
        
        for i, h in enumerate(heights):
            # 弹出所有高度 <= h 的建筑（它们被当前建筑挡住了）
            while stack and heights[stack[-1]] <= h:
                stack.pop()
            stack.append(i)
        
        return stack
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，结果数组

## 关键点总结

1. 能看到海洋 = 右侧没有比它高或一样高的建筑
2. 从右往左扫描，维护右侧最大高度
3. 单调栈方法从左往右，维护严格递减栈（被遮挡就弹出）

## 易错点

- 严格大于（`>`），等高也算被遮挡
- 从右往左扫描后结果需要反转
