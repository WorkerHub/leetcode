## 题目描述

给你一个字符串 `s`，请你返回满足以下条件且出现次数最大的**任意**子串的出现次数：

- 子串中不同字母的数目必须小于或等于 `maxLetters`
- 子串的长度必须大于或等于 `minSize` 且小于或等于 `maxSize`

**示例 1：**

```
输入：s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4
输出：2
解释：子串 "aab" 在原字符串中出现了 2 次。
它满足所有的要求：2 个不同的字母，长度为 3（在 minSize 和 maxSize 范围内）。
```

**示例 2：**

```
输入：s = "aaaa", maxLetters = 1, minSize = 3, maxSize = 3
输出：2
解释：子串 "aaa" 在字符串中出现了 2 次，且它们有重叠部分。
```

**提示：**

- `1 <= s.length <= 10^5`
- `1 <= maxLetters <= 26`
- `1 <= minSize <= maxSize <= min(26, s.length)`
- `s` 只包含小写英文字母

## 解题思路

### 关键观察（贪心剪枝）

直觉上，我们需要枚举长度从 `minSize` 到 `maxSize` 的所有子串，但这样代价太高。

**核心结论**：只需检查长度恰好为 `minSize` 的子串即可。

**证明**：假设某个长度为 `L`（`L > minSize`）的子串出现了 `k` 次，那么它的某个长度为 `minSize` 的前缀（子串）至少也出现了 `k` 次（因为每次出现长子串，其前缀也必然出现）。因此，长度为 `minSize` 的子串的最大出现次数一定 >= 任何更长子串的最大出现次数。

有了这个结论，算法变为：
1. 用长度为 `minSize` 的滑动窗口遍历字符串
2. 对每个窗口内的子串，检查不同字符数是否 <= `maxLetters`
3. 用哈希表统计满足条件的子串出现次数
4. 返回最大值

### 滑动窗口维护不同字符数

为了高效判断窗口内的不同字符数，使用一个字符频率字典：
- 窗口右移时，加入新字符
- 移出旧字符时，若其计数降为 0，则从字典中删除
- 字典的键数量即为不同字符数

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def maxFreq(self, s: str, maxLetters: int, minSize: int, maxSize: int) -> int:
        # 关键结论：只需检查长度为 minSize 的子串
        # 因为长子串若出现 k 次，其长度为 minSize 的前缀也至少出现 k 次

        n = len(s)
        # 统计满足条件的子串出现次数
        substr_count = defaultdict(int)
        # 滑动窗口内的字符频率
        window_freq = defaultdict(int)
        # 当前窗口的不同字符数
        distinct = 0

        # 初始化第一个窗口
        for i in range(minSize):
            ch = s[i]
            if window_freq[ch] == 0:
                distinct += 1
            window_freq[ch] += 1

        # 判断第一个窗口是否满足条件
        if distinct <= maxLetters:
            substr_count[s[:minSize]] += 1

        # 滑动窗口向右移动
        for i in range(minSize, n):
            # 加入右边新字符
            new_ch = s[i]
            if window_freq[new_ch] == 0:
                distinct += 1
            window_freq[new_ch] += 1

            # 移出左边旧字符
            old_ch = s[i - minSize]
            window_freq[old_ch] -= 1
            if window_freq[old_ch] == 0:
                distinct -= 1
                del window_freq[old_ch]

            # 判断当前窗口是否满足条件
            if distinct <= maxLetters:
                substr = s[i - minSize + 1 : i + 1]
                substr_count[substr] += 1

        # 返回最大出现次数（若无满足条件的子串，返回 0）
        return max(substr_count.values(), default=0)
```

### 方法二：直接截取子串统计（简洁版）

不显式维护窗口字符频率，直接对每个位置截取子串，用 `set` 判断不同字符数：

```python
from collections import defaultdict

class Solution:
    def maxFreq(self, s: str, maxLetters: int, minSize: int, maxSize: int) -> int:
        substr_count = defaultdict(int)
        n = len(s)

        # 遍历所有起始位置，只取长度为 minSize 的子串
        for i in range(n - minSize + 1):
            sub = s[i : i + minSize]
            # 用 set 统计不同字符数，O(minSize) 时间
            if len(set(sub)) <= maxLetters:
                substr_count[sub] += 1

        return max(substr_count.values(), default=0)
```

**说明**：方法二更简洁，代码量少，适合面试快速实现。由于 `minSize <= 26`，`set(sub)` 的开销可以接受。实际测试中方法二通常也能通过。

### 方法三：暴力枚举（理解用，不推荐）

枚举所有长度在 `[minSize, maxSize]` 范围内的子串（不利用贪心结论）：

```python
from collections import defaultdict

class Solution:
    def maxFreq(self, s: str, maxLetters: int, minSize: int, maxSize: int) -> int:
        substr_count = defaultdict(int)
        n = len(s)

        # 枚举所有长度（时间复杂度更高）
        for length in range(minSize, maxSize + 1):
            for i in range(n - length + 1):
                sub = s[i : i + length]
                if len(set(sub)) <= maxLetters:
                    substr_count[sub] += 1

        return max(substr_count.values(), default=0)
```

**缺点**：时间复杂度为 O(n * maxSize^2)，在极端情况下会超时。

## 复杂度分析

### 方法一（滑动窗口）

- **时间复杂度**：O(n * minSize)
  - 滑动窗口本身是 O(n)
  - 每次截取子串 `s[i-minSize+1:i+1]` 需要 O(minSize) 时间
  - 由于 minSize <= 26，实际近似 O(n)
- **空间复杂度**：O(n * minSize)，哈希表存储所有不同子串

### 方法二（简洁版）

- **时间复杂度**：O(n * minSize)，与方法一相同
- **空间复杂度**：O(n * minSize)

## 关键点总结

1. **贪心剪枝是本题关键**：只需检查长度为 `minSize` 的子串，大幅降低复杂度
2. **滑动窗口维护不同字符数**：用字符频率字典，O(1) 更新，比每次调用 `set()` 更高效
3. **哈希表计数**：`defaultdict(int)` 天然处理键不存在的情况
4. **`minSize <= 26`**：这个约束保证了子串截取的开销很小
5. **返回默认值 0**：使用 `max(..., default=0)` 处理空字典的边界情况

## 易错点

1. **忘记贪心结论**：直接枚举所有长度会超时，必须只枚举 `minSize`
2. **滑动窗口边界**：初始窗口为 `s[0:minSize]`，滑动时注意 `i - minSize` 是被移出的字符下标
3. **空结果处理**：如果没有任何子串满足条件，`substr_count` 为空，直接取 `max` 会报错
4. **字符串切片开销**：Python 字符串切片是 O(k) 的，需要考虑在计算复杂度时
