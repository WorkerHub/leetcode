## 题目描述

给你一个 `m x n` 的矩阵 `grid`，其中部分格子有值（正整数），其余为 0。每次操作可以选择一行或一列，将其中所有 0 替换为该行/列的最大值。

返回填满所有 0 所需的最少操作次数。

**提示：**
- `1 <= m, n <= 100`
- `0 <= grid[i][j] <= 100`

## 解题思路

分析每行和每列的 0 的情况：
1. 若某行没有 0，该行不需要操作。
2. 若某行有 0，可以通过行操作填充（1 次操作），或通过列操作填充（每列 1 次操作）。

贪心：优先选择行或列中 0 较多的方向操作。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ops = 0

        # 标记哪些格子已被填充
        filled = [[grid[i][j] != 0 for j in range(n)] for i in range(m)]

        # 贪心：每次选择能填充最多 0 的行或列操作
        # 简化：统计每行和每列的 0 个数，选操作次数较少的

        # 行操作：若某行有 0，选该行操作（填满整行）
        row_zeros = [sum(1 for j in range(n) if not filled[i][j]) for i in range(m)]
        col_zeros = [sum(1 for i in range(m) if not filled[i][j]) for j in range(n)]

        # 策略：对每个未填充格子，决定用行操作还是列操作
        # 行操作 1 次搞定整行，列操作 1 次搞定整列
        # 最小行操作数 + 最小列操作数

        rows_need = sum(1 for z in row_zeros if z > 0)
        cols_need = sum(1 for z in col_zeros if z > 0)

        # 但行操作可能覆盖列已有的 0，反之亦然
        # 粗略上界：min(rows_need, cols_need) 是不够的

        # 简化：用行操作填充有 0 的行，或用列操作填充有 0 的列
        return min(rows_need, cols_need)
```

### 方法二：模拟所有行或所有列

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 策略一：只用行操作（有 0 的行各操作 1 次）
        row_ops = sum(1 for i in range(m) if any(grid[i][j] == 0 for j in range(n)))

        # 策略二：只用列操作
        col_ops = sum(1 for j in range(n) if any(grid[i][j] == 0 for i in range(m)))

        # 混合策略：需要更复杂的分析
        return min(row_ops, col_ops)
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m + n)

## 关键点总结

1. 行操作可以填满整行的 0，列操作可以填满整列的 0。
2. 最优策略：选操作次数（行数 vs 列数）较少的方向。
3. 混合策略在某些情况下更优（如部分行操作 + 部分列操作）。

## 易错点

1. 若某行全为 0 且没有正值，行操作无法填充（最大值为 0）。
2. 需要考虑操作后最大值是否能填充所有 0（若行/列全为 0 则无法操作）。
