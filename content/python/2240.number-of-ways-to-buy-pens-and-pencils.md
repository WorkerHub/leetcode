## 题目描述

给你一个整数 `total`，表示你拥有的金额。同时给你两个整数 `cost1` 和 `cost2`，分别表示一支钢笔和一支铅笔的价格（每种都可以买任意数量，包括 0）。

返回购买方案的总数，使得购买的钢笔和铅笔的总花费**不超过** `total`。

**示例 1：**
```
输入：total = 20, cost1 = 10, cost2 = 5
输出：9
解释：(0,0),(0,1),(0,2),(0,3),(0,4),(1,0),(1,1),(1,2),(2,0)
```

**示例 2：**
```
输入：total = 5, cost1 = 10, cost2 = 10
输出：1
解释：只有 (0,0)。
```

## 解题思路

枚举购买钢笔的数量 `i`（从 0 到 `total // cost1`），对每种数量，计算剩余金额 `rem = total - i * cost1`，则铅笔的购买数量为 `0` 到 `rem // cost2`，共 `rem // cost2 + 1` 种。

答案 = `sum(rem // cost2 + 1)` 对所有合法 i。

## 代码实现

### 方法一：枚举钢笔数量（推荐）

```python
class Solution:
    def waysToBuyPensPencils(self, total: int, cost1: int, cost2: int) -> int:
        ans = 0
        # 枚举购买钢笔的数量（包括0）
        for i in range(total // cost1 + 1):
            remaining = total - i * cost1
            # 铅笔可购买 0 到 remaining // cost2 支
            ans += remaining // cost2 + 1
        return ans
```

### 方法二：保证 cost1 >= cost2 优化常数

```python
class Solution:
    def waysToBuyPensPencils(self, total: int, cost1: int, cost2: int) -> int:
        # 让 cost1 >= cost2，减少外层循环次数
        if cost1 < cost2:
            cost1, cost2 = cost2, cost1

        ans = 0
        for pen_count in range(total // cost1 + 1):
            rem = total - pen_count * cost1
            ans += rem // cost2 + 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(total / cost1)，外层枚举钢笔数量。
- 空间复杂度：O(1)。

## 关键点总结

1. 枚举其中一种物品的数量，另一种用整除快速计算。
2. 铅笔数量从 0 到 `rem // cost2`，共 `rem // cost2 + 1` 种。
3. 将更贵的放外层枚举，减少循环次数。

## 易错点

- 购买数量包括 0（不买也是一种方案）。
- `rem // cost2 + 1` 中的 `+1` 不要漏掉（包含 0 支铅笔的情况）。
