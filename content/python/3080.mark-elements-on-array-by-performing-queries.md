## 题目描述

给你一个整数数组 `nums`（长度 `n`）和二维数组 `queries`（每个查询为 `[index, k]`）。

每次查询：
1. 标记 `nums[index]`（若未标记）
2. 按**未标记元素的值**升序（若相等则按下标升序）标记最小的 `k` 个未标记元素

每次查询后，计算所有未标记元素的总和。

返回所有查询结果组成的数组。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

使用最小堆模拟：
1. 维护一个最小堆（元素为 `(value, index)`），按值升序、下标升序排列
2. 维护总和 `total = sum(nums)`
3. 对每次查询：
   - 先标记 `nums[index]`（若未标记，total 减去该值）
   - 从堆中弹出最多 `k` 个未标记元素并标记（total 减去各值）
   - 记录当前 total

## Python 代码实现

### 方法一：最小堆模拟（推荐）

```python
from typing import List
import heapq

class Solution:
    def unmarkedSumArray(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        marked = [False] * n
        total = sum(nums)

        # 最小堆：(value, index)
        heap = [(nums[i], i) for i in range(n)]
        heapq.heapify(heap)

        result = []

        for idx, k in queries:
            # 标记 nums[idx]
            if not marked[idx]:
                marked[idx] = True
                total -= nums[idx]

            # 标记最小的 k 个未标记元素
            remaining = k
            while remaining > 0 and heap:
                val, i = heap[0]
                if marked[i]:
                    heapq.heappop(heap)  # 懒删除：已标记的跳过
                else:
                    heapq.heappop(heap)
                    marked[i] = True
                    total -= val
                    remaining -= 1

            result.append(total)

        return result
```

### 方法二：使用 SortedList

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def unmarkedSumArray(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        marked = [False] * n
        total = sum(nums)

        # 有序集合：(value, index)
        sl = SortedList((nums[i], i) for i in range(n))
        result = []

        for idx, k in queries:
            if not marked[idx]:
                marked[idx] = True
                sl.discard((nums[idx], idx))
                total -= nums[idx]

            # 标记最小的 k 个
            count = 0
            to_remove = []
            for val, i in sl:
                if count >= k:
                    break
                to_remove.append((val, i))
                total -= val
                marked[i] = True
                count += 1

            for item in to_remove:
                sl.discard(item)

            result.append(total)

        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，堆操作 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 懒删除：堆中已标记的元素在弹出时跳过
2. 维护全局未标记总和，每次标记时减去对应值
3. 堆按 `(value, index)` 排序，保证按值升序、下标升序处理

## 易错点

1. 每次查询先标记 `nums[index]`，再标记最小 k 个（顺序不同会影响结果）
2. 懒删除时要判断弹出元素是否已标记（不要忘记将 `remaining` 减少）
