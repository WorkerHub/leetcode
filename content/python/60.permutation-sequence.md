## 题目描述

给出集合 `[1,2,3,...,n]`，其所有元素共有 `n!` 种排列。

按大小顺序列出所有排列情况，并一一标记，当 `n = 3` 时, 所有排列如下：

1. "123"
2. "132"
3. "213"
4. "231"
5. "312"
6. "321"

给定 `n` 和 `k`，返回第 `k` 个排列。

**示例 1：**
```
输入：n = 3, k = 3
输出："213"
```

**示例 2：**
```
输入：n = 4, k = 9
输出："2314"
```

**示例 3：**
```
输入：n = 3, k = 1
输出："123"
```

**提示：**
- `1 <= n <= 9`
- `1 <= k <= n!`

## 解题思路

核心思想：数学规律（康托展开）

关键观察：
- 第一位确定后，后面有 (n-1)! 种排列
- 可以直接计算第 k 个排列，不需要生成所有排列

## Python 代码实现

```python
class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        # 计算阶乘
        factorial = [1] * n
        for i in range(1, n):
            factorial[i] = factorial[i-1] * i
        
        # 候选数字
        nums = list(range(1, n + 1))
        result = []
        k -= 1  # 转为0索引
        
        for i in range(n):
            # 确定第 i 位的数字
            idx = k // factorial[n - 1 - i]
            result.append(str(nums[idx]))
            nums.pop(idx)
            k %= factorial[n - 1 - i]
        
        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. **康托展开**：直接计算第k个排列
2. **阶乘**：每一位的选择数
3. **索引转换**：k转为0索引
