## 题目描述

给你一个正整数 `n`，表示有 `n` 个城市，城市编号为 `1` 到 `n`。给你一个二维整数数组 `roads`，其中 `roads[i] = [ai, bi, costi]` 表示在城市 `ai` 和城市 `bi` 之间有一条 **双向** 道路，两城市之间的旅行费用为 `costi`。

同时给你一个整数数组 `appleCost`，其中 `appleCost[i]` 是从城市 `i` 购买一个苹果的费用。

你从某个城市出发，你可以沿路走到其他城市并购买苹果，或者直接在当前城市购买苹果。购买后，你需要返回出发城市。

对每个城市 `i`，计算从城市 `i` 出发，购买一个苹果所需的 **最小总费用**。

**注意：** 从城市 `i` 到城市 `j` 去购买苹果，总费用包括：往返旅行费用（两倍的路径费用）+ 购买苹果的费用。

**提示：**
- `2 <= n <= 1000`
- `1 <= roads.length <= 2000`

## 解题思路

**Dijkstra 最短路：**

对每个城市 `i`，从 `i` 出发购买苹果的最小费用 = `min over all j of (2 * dist(i, j) + appleCost[j])`。

**优化：** 将所有城市作为超级源点，设 `total_cost[j] = appleCost[j]`（在城市 j 购买时的出发费用）。从所有城市同时出发，每个城市 j 的初始费用为 `appleCost[j]`，跑一次多源 Dijkstra：

`result[i] = min dist from i to any j via the modified graph`

改变建图：每条边 (u, v, c) 对应双倍权重（来回），修改边权为 `2 * c`，初始化所有城市的 dist 为 `appleCost[j]`，跑 Dijkstra。

## 代码实现

### 方法一：多源 Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minCost(self, n: int, roads: List[List[int]], appleCost: List[int], k: int) -> List[int]:
        # 建图（边权乘以 k+1，表示走一段路的代价增加 k 倍）
        adj = [[] for _ in range(n + 1)]
        for a, b, cost in roads:
            adj[a].append((b, cost * (k + 1)))
            adj[b].append((a, cost * (k + 1)))

        # 多源 Dijkstra：初始化每个城市的 dist 为 appleCost[i]
        dist = [float('inf')] * (n + 1)
        heap = []

        for i in range(1, n + 1):
            dist[i] = appleCost[i - 1]  # appleCost 是 0-indexed
            heapq.heappush(heap, (dist[i], i))

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in adj[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        return dist[1:]
```

### 方法二：逐个 Dijkstra（暴力，适合小数据）

```python
from typing import List
import heapq

class Solution:
    def minCost(self, n: int, roads: List[List[int]], appleCost: List[int], k: int) -> List[int]:
        adj = [[] for _ in range(n + 1)]
        for a, b, cost in roads:
            adj[a].append((b, cost))
            adj[b].append((a, cost))

        def dijkstra(src: int) -> int:
            dist = [float('inf')] * (n + 1)
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in adj[u]:
                    if dist[u] + w < dist[v]:
                        dist[v] = dist[u] + w
                        heapq.heappush(heap, (dist[v], v))
            # 从 src 出发，去城市 j 买苹果，总费用 = dist[j] * (k+1) + appleCost[j-1]
            return min(dist[j] * (k + 1) + appleCost[j - 1] for j in range(1, n + 1))

        return [dijkstra(i) for i in range(1, n + 1)]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 多源 Dijkstra | O((n + m) log n) | O(n + m) |
| 逐个 Dijkstra | O(n * (n + m) log n) | O(n + m) |
