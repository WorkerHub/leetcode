## 题目描述

给你一个字符串 `s`，它仅包含字符 `'a'` 和 `'b'`。

你可以删除 `s` 中任意数目的字符，使得 `s` **平衡**。当 `s` 中不存在 `"ba"` 子序列时，`s` 是**平衡**的（所有 `'a'` 都在 `'b'` 之前）。

请返回使 `s` 平衡所需要删除的**最少字符数**。

**示例：**
```
输入：s = "aababbab"
输出：2
```

## 解题思路

**方法一：贪心（栈）**：遍历字符串，用栈模拟：遇到 `'b'` 压栈；遇到 `'a'` 时，若栈顶是 `'b'`，说明有 "ba" 子序列，选择删除 `'b'`（弹栈）。

**方法二：DP**：`dp[i]` = 前 i 个字符使其平衡的最少删除数。

**方法三：枚举分割点**：枚举分割点 i，左边全保留 'a'（删除其中的 'b'），右边全保留 'b'（删除其中的 'a'），找最小总代价。

## 代码实现

### 方法一：贪心（栈）（推荐）

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        # 用栈计数（只需统计 'b' 的数量）
        b_count = 0  # 栈中的 'b' 数量
        deletions = 0
        
        for c in s:
            if c == 'b':
                b_count += 1  # 'b' 压栈
            else:  # c == 'a'
                if b_count > 0:
                    # 有未匹配的 'b' 在前面，删除一个 'b'
                    b_count -= 1
                    deletions += 1
        
        return deletions
```

### 方法二：动态规划

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        # dp = 使当前前缀平衡的最少删除数
        # b_count = 当前前缀中 'b' 的数量
        dp = 0
        b_count = 0
        
        for c in s:
            if c == 'b':
                b_count += 1
            else:
                # 选择：删除这个 'a'（dp+1），或删除前面某个 'b'（dp+1 中的1 换成减少 b_count）
                dp = min(dp + 1, b_count)
        
        return dp
```

### 方法三：枚举分割点（前后缀数组）

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        n = len(s)
        # left_b[i] = s[0..i-1] 中 'b' 的数量（需要删除的）
        # right_a[i] = s[i..n-1] 中 'a' 的数量（需要删除的）
        
        left_b = [0] * (n + 1)
        for i in range(n):
            left_b[i+1] = left_b[i] + (1 if s[i] == 'b' else 0)
        
        right_a = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            right_a[i] = right_a[i+1] + (1 if s[i] == 'a' else 0)
        
        # 枚举分割点：左边保留'a'，右边保留'b'
        return min(left_b[i] + right_a[i] for i in range(n + 1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心（栈） | O(n) | O(1) |
| DP | O(n) | O(1) |
| 前后缀 | O(n) | O(n) |

## 关键点总结

1. 平衡字符串 = 所有 'a' 都在 'b' 之前，即不含 "ba" 子序列
2. 贪心：遇到 'a' 且前面有 'b' 时，选择删除 'b'（不删 'a'）更优
3. DP：每遇到 'a' 时，比较删 'a' 和删前面某个 'b' 哪个代价更小

## 易错点

- 贪心中删除的是 'b'（不是 'a'），因为要保留 'a' 在前
- DP 中 `dp = min(dp + 1, b_count)` 的含义：删 'a' 代价 dp+1，删掉 b_count 中某个 'b' 代价是 b_count（b_count 是积累的 'b' 数量，表示若以此处为分界点）
