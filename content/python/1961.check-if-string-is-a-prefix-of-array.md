## 题目描述

给你一个字符串 `s` 和一个字符串数组 `words`，若 `s` 等于 `words` 中**前若干个字符串的拼接**，则返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "iloveleetcode", words = ["i","love","leetcode","apples"]
输出：true
解释：s = words[0] + words[1] + words[2]
```

**示例 2：**
```
输入：s = "iloveleetcodeq", words = ["i","love","leetcode","apples"]
输出：false
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 20`
- `1 <= s.length <= 1000`

---

## 解题思路

### 核心思想：逐步拼接

逐一拼接 `words` 中的字符串，检查是否等于 `s`，或是否已经超过 `s` 的长度。

---

## 代码实现

### 方法一：逐步拼接（推荐）

```python
from typing import List

class Solution:
    def isPrefixString(self, s: str, words: List[str]) -> bool:
        cur = ""
        for word in words:
            cur += word
            if cur == s:
                return True
            if len(cur) > len(s):
                return False
        return False
```

### 方法二：双指针

```python
from typing import List

class Solution:
    def isPrefixString(self, s: str, words: List[str]) -> bool:
        idx = 0  # s 中当前匹配位置
        for word in words:
            for c in word:
                if idx >= len(s) or s[idx] != c:
                    return False
                idx += 1
            if idx == len(s):
                return True
        return False
```

### 方法三：join 拼接检查

```python
from typing import List

class Solution:
    def isPrefixString(self, s: str, words: List[str]) -> bool:
        concat = ""
        for word in words:
            concat += word
            if concat == s:
                return True
            if not s.startswith(concat):
                return False
        return False
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n * k) | O(n) |
| 方法二 | O(n * k) | O(1) |

n 为 s 长度，k 为 words 中字符总数。

---

## 关键点总结

1. 拼接超过 s 长度时提前返回 false
2. 恰好等于 s 时返回 true
3. 遍历完所有 words 仍未等于 s 时返回 false

---

## 易错点

- 不能只判断 `s.startswith(concat)`，因为可能拼接后比 s 短但前缀一致
- 拼接 words 后长度超过 s 时直接返回 false
