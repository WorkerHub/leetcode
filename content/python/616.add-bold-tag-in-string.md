## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`，请你在 `s` 中找到所有 `words` 中的字符串，并在其前后添加粗体标签 `<b>` 和 `</b>`。

如果两个这样的字符串重叠，你应该把它们合并成一个只有一对粗体标签的字符串。如果两个字符串接连发生，你也应该把它们合并成一个粗体字符串。

**示例：**

```
输入：s = "abcxyz123", words = ["abc","123"]
输出："<b>abc</b>xyz<b>123</b>"
```

## Python 代码实现

```python
from typing import List

class Solution:
    def addBoldTag(self, s: str, words: List[str]) -> str:
        """
        标记需要加粗的位置
        
        时间复杂度：O(n*m*k)
        空间复杂度：O(n)
        """
        n = len(s)
        bold = [False] * n
        
        # 标记所有匹配位置
        for word in words:
            start = 0
            while True:
                pos = s.find(word, start)
                if pos == -1:
                    break
                for i in range(pos, pos + len(word)):
                    bold[i] = True
                start = pos + 1
        
        # 构建结果
        result = []
        i = 0
        while i < n:
            if bold[i]:
                result.append("<b>")
                while i < n and bold[i]:
                    result.append(s[i])
                    i += 1
                result.append("</b>")
            else:
                result.append(s[i])
                i += 1
        
        return ''.join(result)
```
