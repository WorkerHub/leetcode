## 题目描述

有时候人们会用重复写一些字母来表示额外的感受，比如 `"hello" -> "heeellooo"`, `"hi" -> "hiii"`。我们将相邻字母都相同的一串字符定义为相同字母组，例如："h", "eee", "ll", "ooo"。

对于一个给定的字符串 `s`，如果另一个单词能够通过将一些字母组扩张从而使其和 `s` 相同，我们将这个单词定义为 **可扩张的**（stretchy）。扩张操作定义如下：选择一个字母组（包含字母 `c`），然后往其中添加相同的字母 `c` 使其长度达到 **3 或以上**。

例如，以 `"hello"` 为例，我们可以对字母组 `"o"` 扩张得到 `"hellooo"`，但是无法以同样的方法得到 `"helloo"` 因为字母组 `"oo"` 长度小于 3。此外，我们可以进行另一种扩张 `"ll" -> "lllll"` 以获得 `"helllllooo"`。如果 `s = "helllllooo"`，那么查询词 `"hello"` 是可扩张的，因为可以对它执行这两种扩张操作使得 `query = "hello" -> "hellooo" -> "helllllooo" = s`。

给你一个字符串 `s` 和一个字符串数组 `words` ，返回 `words` 中可扩张的单词个数。

**示例 1:**
```
输入: s = "heeellooo", words = ["hello", "hi", "helo"]
输出: 1
解释:
我们能通过扩张 "hello" 的 "e" 和 "o" 来得到 "heeellooo"。
我们不能通过扩张 "helo" 来得到 "heeellooo" 因为 "ll" 的长度小于 3。
```

**示例 2:**
```
输入: s = "zzzzzyyyyy", words = ["zzyy","zy","zyy"]
输出: 3
```

**提示:**
- `1 <= s.length, words.length <= 100`
- `1 <= words[i].length <= 100`
- `s` 和 `words[i]` 只由小写字母组成

## 解题思路

这道题的核心是理解"可扩张"的规则，然后使用双指针比较字符串。

**关键规则：**
1. 字母顺序必须完全相同
2. 对于 s 中的每个字母组：
   - 如果长度 >= 3，word 中对应组可以是任意长度（1 到 s 中的长度）
   - 如果长度 < 3，word 中对应组长度必须相等

**算法步骤：**
1. 将字符串转换为字母组表示：`[(字母, 长度), ...]`
2. 比较 s 和 word 的字母组：
   - 字母必须相同
   - 长度关系必须满足扩张规则

## Python 代码实现

### 方法一：字母组比较（推荐）⭐

```python
from typing import List

class Solution:
    def expressiveWords(self, s: str, words: List[str]) -> int:
        def get_groups(string: str) -> List[tuple]:
            """将字符串转换为 [(字母, 长度), ...] 格式"""
            if not string:
                return []
            
            groups = []
            i = 0
            while i < len(string):
                char = string[i]
                count = 1
                while i + count < len(string) and string[i + count] == char:
                    count += 1
                groups.append((char, count))
                i += count
            
            return groups
        
        def is_stretchy(word: str) -> bool:
            """判断 word 是否可以扩张成 s"""
            s_groups = get_groups(s)
            w_groups = get_groups(word)
            
            # 字母组数量必须相同
            if len(s_groups) != len(w_groups):
                return False
            
            # 检查每个字母组
            for (s_char, s_count), (w_char, w_count) in zip(s_groups, w_groups):
                # 字母必须相同
                if s_char != w_char:
                    return False
                
                # word 的长度不能大于 s
                if w_count > s_count:
                    return False
                
                # 如果 s 的长度 < 3，word 必须长度相同
                if s_count < 3 and s_count != w_count:
                    return False
            
            return True
        
        return sum(is_stretchy(word) for word in words)
```

### 方法二：双指针直接比较

```python
from typing import List

class Solution:
    def expressiveWords(self, s: str, words: List[str]) -> int:
        def is_stretchy(word: str) -> bool:
            i, j = 0, 0
            
            while i < len(s) and j < len(word):
                # 字母不同，无法匹配
                if s[i] != word[j]:
                    return False
                
                # 统计 s 中当前字母的数量
                s_count = 1
                while i + s_count < len(s) and s[i + s_count] == s[i]:
                    s_count += 1
                
                # 统计 word 中当前字母的数量
                w_count = 1
                while j + w_count < len(word) and word[j + w_count] == word[j]:
                    w_count += 1
                
                # 检查是否满足扩张规则
                if w_count > s_count:
                    return False
                if s_count < 3 and s_count != w_count:
                    return False
                
                i += s_count
                j += w_count
            
            # 两个字符串都必须完全遍历
            return i == len(s) and j == len(word)
        
        return sum(is_stretchy(word) for word in words)
```

### 方法三：简化版本

```python
from typing import List
from itertools import groupby

class Solution:
    def expressiveWords(self, s: str, words: List[str]) -> int:
        def get_key(string: str):
            """返回字母和长度的列表"""
            return [(char, len(list(group))) for char, group in groupby(string)]
        
        s_key = get_key(s)
        count = 0
        
        for word in words:
            w_key = get_key(word)
            
            # 检查是否可扩张
            if len(s_key) != len(w_key):
                continue
            
            is_valid = True
            for (sc, sn), (wc, wn) in zip(s_key, w_key):
                if sc != wc or wn > sn or (sn < 3 and sn != wn):
                    is_valid = False
                    break
            
            if is_valid:
                count += 1
        
        return count
```

### 方法四：函数式风格

```python
from typing import List
from itertools import groupby

class Solution:
    def expressiveWords(self, s: str, words: List[str]) -> int:
        def encode(string):
            return [(k, len(list(g))) for k, g in groupby(string)]
        
        def can_extend(s_enc, w_enc):
            if len(s_enc) != len(w_enc):
                return False
            return all(
                sc == wc and wn <= sn and (sn >= 3 or sn == wn)
                for (sc, sn), (wc, wn) in zip(s_enc, w_enc)
            )
        
        s_enc = encode(s)
        return sum(can_extend(s_enc, encode(w)) for w in words)
```

## 复杂度分析

- **时间复杂度**：O(n × (m + k))，其中 n 是 words 的长度，m 是 s 的长度，k 是每个 word 的平均长度
- **空间复杂度**：O(m + k)，存储字母组信息

## 关键点总结

1. **字母组概念**：将字符串分解为连续相同字母的组
2. **扩张规则**：长度 >= 3 的组可以扩张，< 3 的组不能
3. **双指针技巧**：同时遍历两个字符串的字母组
4. **边界条件**：长度关系的判断很关键
5. **Python 工具**：`itertools.groupby` 可以简化代码

## 易错点

1. **长度 < 3 的情况**：必须长度完全相等
2. **字母顺序**：不能改变字母的顺序
3. **完全遍历**：两个字符串都必须完全匹配
4. **groupby 使用**：需要用 `list(group)` 获取实际元素
5. **边界情况**：空字符串、单字母等
