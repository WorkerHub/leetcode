## 题目描述

你和朋友玩一个叫做「翻转游戏」的游戏。游戏规则如下：

给你一个字符串 currentState，其中只包含 '+' 和 '-'。你和朋友轮流将连续的两个 "++" 反转成 "--"。当一方无法进行有效的翻转时便意味着游戏结束，另一方获胜。

请你写出一个函数来判定起始玩家是否存在必胜的方案。如果存在，返回 true；否则，返回 false。

**示例 1：**
```
输入：currentState = "++++"
输出：true
解释：起始玩家可以翻转中间的 "++" 变成 "+--+"，使得对手无法进行有效的翻转。
```

**示例 2：**
```
输入：currentState = "+"
输出：false
```

**提示：**
- 1 <= currentState.length <= 60
- currentState[i] 不是 '+' 就是 '-'
- 进阶：推导你算法的时间复杂度

## 解题思路

这是一道经典的博弈论问题，需要判断先手是否必胜。

**核心思想：递归 + 博弈论**

1. **博弈论基础：**
   - 如果当前玩家可以通过某一步操作，让对手进入必败状态，则当前玩家必胜
   - 如果当前玩家的所有操作都让对手进入必胜状态，则当前玩家必败

2. **递归思路：**
   - 枚举所有可能的翻转位置
   - 对每个翻转后的状态，递归判断对手是否能赢
   - 如果存在一个翻转让对手必败，则当前玩家必胜

3. **优化方向：**
   - 记忆化搜索：避免重复计算相同状态
   - 剪枝：提前判断无解情况

## Python 代码实现

### 方法一：递归 + 记忆化（推荐）

```python
class Solution:
    def canWin(self, currentState: str) -> bool:
        """
        递归判断当前玩家是否能赢
        使用记忆化避免重复计算
        """
        memo = {}
        
        def can_win_helper(state: str) -> bool:
            # 查询缓存
            if state in memo:
                return memo[state]
            
            # 尝试所有可能的翻转
            for i in range(len(state) - 1):
                if state[i] == '+' and state[i + 1] == '+':
                    # 翻转后的状态
                    next_state = state[:i] + '--' + state[i + 2:]
                    
                    # 如果对手在这个状态下必败，当前玩家必胜
                    if not can_win_helper(next_state):
                        memo[state] = True
                        return True
            
            # 所有翻转都让对手必胜，当前玩家必败
            memo[state] = False
            return False
        
        return can_win_helper(currentState)
```

### 方法二：简洁的递归

```python
class Solution:
    def canWin(self, currentState: str) -> bool:
        """
        简洁版本，不使用辅助函数
        """
        # 尝试所有可能的翻转
        for i in range(len(currentState) - 1):
            if currentState[i:i + 2] == '++':
                # 翻转并递归检查
                next_state = currentState[:i] + '--' + currentState[i + 2:]
                # 如果对手必败，返回 True
                if not self.canWin(next_state):
                    return True
        
        # 无法找到必胜策略
        return False
```

### 方法三：使用装饰器的记忆化

```python
from functools import lru_cache

class Solution:
    def canWin(self, currentState: str) -> bool:
        """
        使用 lru_cache 装饰器实现记忆化
        """
        @lru_cache(maxsize=None)
        def can_win_helper(state: str) -> bool:
            # 尝试所有翻转
            for i in range(len(state) - 1):
                if state[i] == '+' and state[i + 1] == '+':
                    next_state = state[:i] + '--' + state[i + 2:]
                    if not can_win_helper(next_state):
                        return True
            return False
        
        return can_win_helper(currentState)
```

### 方法四：带详细注释的版本

```python
class Solution:
    def canWin(self, currentState: str) -> bool:
        """
        详细版本，便于理解
        """
        def can_current_player_win(state: str, memo: dict) -> bool:
            """
            判断当前状态下，轮到行动的玩家是否能赢
            """
            # 已经计算过这个状态
            if state in memo:
                return memo[state]
            
            # 尝试所有可能的翻转操作
            for i in range(len(state) - 1):
                # 找到连续的 ++
                if state[i] == '+' and state[i + 1] == '+':
                    # 执行翻转操作
                    new_state = state[:i] + '--' + state[i + 2:]
                    
                    # 递归判断：在新状态下，对手能否赢
                    opponent_can_win = can_current_player_win(new_state, memo)
                    
                    # 如果对手不能赢，说明当前玩家找到了必胜策略
                    if not opponent_can_win:
                        memo[state] = True
                        return True
            
            # 尝试了所有操作，都无法让对手必败
            # 说明当前玩家必败
            memo[state] = False
            return False
        
        return can_current_player_win(currentState, {})
```

### 方法五：优化的记忆化（使用列表）

```python
class Solution:
    def canWin(self, currentState: str) -> bool:
        """
        使用列表操作，可能稍快一些
        """
        memo = {}
        
        def helper(s: str) -> bool:
            if s in memo:
                return memo[s]
            
            chars = list(s)
            
            for i in range(len(chars) - 1):
                if chars[i] == '+' and chars[i + 1] == '+':
                    # 翻转
                    chars[i] = chars[i + 1] = '-'
                    next_state = ''.join(chars)
                    
                    # 检查对手
                    opponent_wins = helper(next_state)
                    
                    # 恢复状态
                    chars[i] = chars[i + 1] = '+'
                    
                    # 如果对手输了，当前玩家赢
                    if not opponent_wins:
                        memo[s] = True
                        return True
            
            memo[s] = False
            return False
        
        return helper(currentState)
```

## 复杂度分析

### 未优化的递归：

**时间复杂度：** O(n!!)
- n!! 表示双阶乘
- 状态数量呈指数级增长
- 会有大量重复计算

**空间复杂度：** O(n)
- 递归调用栈深度最多为 n/2

### 记忆化搜索：

**时间复杂度：** O(2^n)
- 最多有 2^n 个不同的状态（每个位置是 + 或 -）
- 实际状态数会少很多，因为只能通过翻转 ++ 到达
- 每个状态计算一次，需要 O(n) 时间遍历

**空间复杂度：** O(2^n)
- memo 字典存储最多 2^n 个状态
- 递归栈深度 O(n)

## 图解示例

以 `currentState = "++++"` 为例：

```
初始状态: ++++（先手）

先手可选操作：
1. 翻转位置0: --++ → 后手面对 --++
2. 翻转位置1: +--+ → 后手面对 +--+
3. 翻转位置2: ++-- → 后手面对 ++--

分析操作2: +--+
后手面对 +--+，无法翻转（没有连续的++）
后手输 → 先手赢！

所以先手选择翻转位置1，必胜。
```

详细博弈树（部分）：

```
                    ++++（先手）
                /      |      \
            --++    +--+    ++--
           (后手)   (后手)  (后手)
              |       |        |
            无法翻转  无法    可翻转
            后手败   翻转    ----
                    后手败   (先手)
                             |
                           无法翻转
                           先手败
                           
结论：先手选择翻转成 +--+，后手无法翻转，先手必胜
```

## 关键点总结

1. **博弈论思想**：如果存在一步让对手必败，当前玩家必胜
2. **递归结构**：当前玩家能赢 = 存在一步让对手不能赢
3. **记忆化必需**：相同状态会被多次计算，必须缓存
4. **状态表示**：直接用字符串作为状态，简单清晰
5. **终止条件**：无法翻转时，当前玩家必败

## 易错点

1. **递归逻辑反向**
   ```python
   # 错误：条件判断反了
   if can_win_helper(next_state):  # 如果对手能赢
       return True  # 当前玩家反而赢？错误！
   
   # 正确：如果对手不能赢，当前玩家才能赢
   if not can_win_helper(next_state):
       return True
   ```

2. **忘记记忆化**
   ```python
   # 错误：每次都重新计算，超时
   def can_win(state):
       for i in range(len(state) - 1):
           if state[i:i+2] == '++':
               if not can_win(state[:i] + '--' + state[i+2:]):
                   return True
       return False
   
   # 正确：使用 memo
   if state in memo:
       return memo[state]
   # ... 计算后
   memo[state] = result
   ```

3. **状态恢复错误**（如果使用列表）
   ```python
   # 错误：忘记恢复状态
   chars[i] = chars[i+1] = '-'
   if not helper(''.join(chars)):
       return True
   # 忘记恢复，会影响后续尝试
   
   # 正确：记得恢复
   chars[i] = chars[i+1] = '-'
   result = not helper(''.join(chars))
   chars[i] = chars[i+1] = '+'  # 恢复
   if result:
       return True
   ```

4. **边界条件**
   ```python
   # 错误：没有处理无法翻转的情况
   # 如果没有任何 ++，循环不会执行，应该返回 False
   
   # 正确：循环结束返回 False
   for i in range(len(state) - 1):
       if state[i:i+2] == '++':
           if not can_win(next_state):
               return True
   return False  # 所有尝试都失败，当前玩家必败
   ```
