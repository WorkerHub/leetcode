## 题目描述

给你一个整数数组 `nums`，如果子数组中**相邻元素之差的绝对值恰好为 1**，则称该子数组为**连续子数组**（consecutive subarray）。

返回所有**连续子数组**的元素之和的总和，答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3]
输出：20
解释：
连续子数组：[1],[2],[3],[1,2],[2,3],[1,2,3]
对应的和：1+2+3+3+5+6=20
```

**示例 2：**
```
输入：nums = [1,3,5,7]
输出：16
解释：连续子数组只有单个元素（差不为1），和 = 1+3+5+7 = 16
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

每个元素 `nums[i]` 对总和的贡献等于包含它的连续子数组数量乘以其值。

对于每个位置 i，它属于哪些连续子数组？以 i 为右端点的连续子数组和以 i 为左端点的连续子数组。

用 DP 计算：
- `left[i]` = 以 i 结尾的最长连续（步长1）序列长度（向左）
- `right[i]` = 以 i 开头的最长连续序列长度（向右）

但连续子数组不一定是单调的，差可以是 +1 或 -1。

分两类：
- 递增连续（差为+1）：`inc[i]` = 以 i 结尾的最长递增连续序列长度
- 递减连续（差为-1）：`dec[i]` = 以 i 结尾的最长递减连续序列长度

用容斥原理统计。

## Python 代码实现

### 方法一：分向计数（推荐）

```python
from typing import List

class Solution:
    def getSum(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        
        # inc[i]: 以 i 结尾的递增连续子数组数量（nums[i]-nums[i-1]==1）
        # dec[i]: 以 i 结尾的递减连续子数组数量（nums[i]-nums[i-1]==-1）
        inc = [0] * n
        dec = [0] * n
        
        # 每个单个元素贡献1个（自身是长度1的连续子数组）
        for i in range(n):
            inc[i] = 1
            dec[i] = 1
        
        for i in range(1, n):
            diff = nums[i] - nums[i - 1]
            if diff == 1:
                inc[i] = inc[i - 1] + 1  # 以 i 结尾的递增连续子数组增加
            elif diff == -1:
                dec[i] = dec[i - 1] + 1
        
        # 总和 = sum(nums[i] * (包含 i 的连续子数组数量))
        # 包含 i 的连续子数组：以 i 为右端的递增子数组 + 以 i 为右端的递减子数组 - 1（减去自身重复）
        # 但这样会重复，需要更精细
        
        # 简单方法：对每个以 i 结尾的连续子数组 [j, i]，贡献 sum(nums[j..i])
        # sum(nums[j..i]) = prefix[i+1] - prefix[j]
        
        # 用前缀和 + DP
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        # 对每个 i，计算所有以 i 结尾的连续子数组的和之和
        # dp_inc[i] = sum of sums of all consecutive increasing subarrays ending at i
        dp_inc = [0] * n
        dp_dec = [0] * n
        
        for i in range(n):
            dp_inc[i] = nums[i]  # 自身
            dp_dec[i] = nums[i]
            if i > 0:
                if nums[i] - nums[i - 1] == 1:
                    dp_inc[i] = dp_inc[i - 1] + nums[i] * inc[i]
                    # 等价：dp_inc[i] = dp_inc[i-1] + nums[i] * (inc[i-1] + 1)
                if nums[i] - nums[i - 1] == -1:
                    dp_dec[i] = dp_dec[i - 1] + nums[i] * dec[i]
        
        ans = sum(dp_inc[i] + dp_dec[i] - nums[i] for i in range(n)) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 分递增和递减两种连续子数组分别处理
2. `dp[i]` = 以 i 结尾的所有连续子数组的和之和
3. 减去自身重复（单个元素被计算两次）

## 易错点

1. 单个元素既是递增又是递减连续子数组，计算时要减去重复
2. 连续是指差为 ±1，不是单调递增或递减
