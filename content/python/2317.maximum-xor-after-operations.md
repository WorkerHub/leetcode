## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。每次操作，你可以选择任意非负整数 `x`，将 `nums[i]` 修改为 `nums[i] AND (nums[i] XOR x)`（即可以将 `nums[i]` 的任意位从 1 变为 0，但不能从 0 变为 1）。

在所有操作完成后，计算数组的 XOR 值（将所有元素异或），返回可以得到的**最大** XOR 值。

**示例 1：**
```
输入：nums = [3,2,4,6]
输出：7
解释：将 nums[1] 变为 2 AND (2 XOR 5) = 0，将 nums[0] 变为 3 AND (3 XOR 4) = 3... 最终可得到 7。
```

**示例 2：**
```
输入：nums = [1,2,3,9,2]
输出：11
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^8`

## 解题思路

**核心观察：**
操作 `nums[i] AND (nums[i] XOR x)` 等价于：对于 `nums[i]` 的每一位，可以选择将该位保留或清零。即每次操作可以将某个元素的某些位从 1 变为 0。

**关键结论：**
若某一位在数组中至少有一个元素该位为 1，则可以将该位在异或结果中设为 1（将其他所有该位为 1 的元素清零该位，保留一个）。因此，最大 XOR 值 = 所有元素的按位 OR。

**证明：**
- OR 值的每一位为 1 意味着至少一个元素该位为 1。
- 可以将其他同位为 1 的元素该位清零，使得只有一个元素该位为 1，从而 XOR 时该位为 1。

## 代码实现

### 方法一：按位 OR（推荐）

```python
from typing import List

class Solution:
    def maximumXOR(self, nums: List[int]) -> int:
        result = 0
        for num in nums:
            result |= num  # 所有元素按位 OR
        return result
```

### 方法二：使用 functools.reduce

```python
from typing import List
from functools import reduce
from operator import or_

class Solution:
    def maximumXOR(self, nums: List[int]) -> int:
        # 利用 reduce 计算所有元素的按位 OR
        return reduce(or_, nums)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 按位 OR | O(n) | O(1) |

## 关键点总结

1. 操作本质是可以将任意元素的任意位从 1 变为 0，不能增加 1。
2. 最大可能的 XOR = 所有元素的按位 OR（每一位至少出现一次 1 就能保留）。
3. 直接对所有元素求 OR 即可，无需实际执行操作。

## 易错点

- 不要误以为是求最大子集异或（那是另一类题）。
- 理解操作的本质：只能清位（1->0），不能置位（0->1）。
