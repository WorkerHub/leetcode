## 题目描述

给你一棵 `n` 个节点的无向连通树，节点编号从 `0` 到 `n - 1`，根节点为节点 `0`，树上每个节点都有一个值 `nums[i]`。

你需要从这棵树上删除**两条不同的边**，使其分裂成三个连通分量。三个分量的 XOR 值分别为 `x1, x2, x3`，**分数**定义为 `max(x1,x2,x3) - min(x1,x2,x3)`。

返回所有删边方案中的**最小分数**。

**提示：**
- `n == nums.length`
- `3 <= n <= 1000`
- `1 <= nums[i] <= 10^8`

## 解题思路

**DFS + 枚举：**
1. 预处理：用 DFS 求出每个节点子树的 XOR 值 `sub[v]`（包含该节点及其所有后代）。
2. 整棵树的 XOR 总值 `total = sub[0]`。
3. 枚举所有边对 `(e1, e2)`，利用子树 XOR 值快速计算三个分量的 XOR 值。

**判断 u 是否是 v 的祖先：**
用 DFS 进出时间 `[in[v], out[v]]` 判断。若 `in[u] <= in[v] <= out[v] <= out[u]`，则 u 是 v 的祖先。

**三个分量的 XOR：**
- 若 u 是 v 的祖先（v 的子树在 u 的子树内）：
  - 三个分量的 XOR：`sub[v]`, `sub[u] ^ sub[v]`, `total ^ sub[u]`
- 若 u 和 v 无祖孙关系：
  - 三个分量的 XOR：`sub[u]`, `sub[v]`, `total ^ sub[u] ^ sub[v]`

## 代码实现

### 方法一：DFS + 枚举边对（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumScore(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        sub = [0] * n      # 子树 XOR 值
        tin = [0] * n      # 进入时间
        tout = [0] * n     # 离开时间
        timer = [0]

        def dfs(node, parent):
            sub[node] = nums[node]
            tin[node] = timer[0]
            timer[0] += 1
            for nb in graph[node]:
                if nb != parent:
                    dfs(nb, node)
                    sub[node] ^= sub[nb]
            tout[node] = timer[0]
            timer[0] += 1

        dfs(0, -1)
        total = sub[0]

        def is_ancestor(u, v):
            # 判断 u 是否是 v 的祖先（包括 u==v）
            return tin[u] <= tin[v] and tout[v] <= tout[u]

        ans = float('inf')
        # 枚举所有节点对（删去 u 和 v 与其父的边）
        for u in range(1, n):
            for v in range(u + 1, n):
                if is_ancestor(u, v):
                    # u 是 v 的祖先
                    x1, x2, x3 = sub[v], sub[u] ^ sub[v], total ^ sub[u]
                elif is_ancestor(v, u):
                    # v 是 u 的祖先
                    x1, x2, x3 = sub[u], sub[v] ^ sub[u], total ^ sub[v]
                else:
                    # 无祖孙关系
                    x1, x2, x3 = sub[u], sub[v], total ^ sub[u] ^ sub[v]
                score = max(x1, x2, x3) - min(x1, x2, x3)
                ans = min(ans, score)

        return ans
```

### 方法二：迭代 DFS（避免递归深度问题）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumScore(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        sub = nums[:]
        parent = [-1] * n
        order = []  # BFS 顺序
        visited = [False] * n
        stack = [0]
        visited[0] = True
        while stack:
            node = stack.pop()
            order.append(node)
            for nb in graph[node]:
                if not visited[nb]:
                    visited[nb] = True
                    parent[nb] = node
                    stack.append(nb)

        # 逆序计算子树 XOR（叶到根）
        depth = [0] * n
        for node in order:
            if parent[node] != -1:
                depth[node] = depth[parent[node]] + 1

        for node in reversed(order):
            if parent[node] != -1:
                sub[parent[node]] ^= sub[node]

        # 用深度和顺序判断祖孙关系（简化版：用 DFS 时间戳更精确）
        # 这里用另一种方式：重新 DFS
        tin = [0] * n
        tout = [0] * n
        timer = [0]

        def dfs2(node, par):
            tin[node] = timer[0]
            timer[0] += 1
            for nb in graph[node]:
                if nb != par:
                    dfs2(nb, node)
            tout[node] = timer[0]
            timer[0] += 1

        dfs2(0, -1)

        def is_ancestor(u, v):
            return tin[u] <= tin[v] and tout[v] <= tout[u]

        total = sub[0]
        ans = float('inf')
        for u in range(1, n):
            for v in range(u + 1, n):
                if is_ancestor(u, v):
                    x1, x2, x3 = sub[v], sub[u] ^ sub[v], total ^ sub[u]
                elif is_ancestor(v, u):
                    x1, x2, x3 = sub[u], sub[v] ^ sub[u], total ^ sub[v]
                else:
                    x1, x2, x3 = sub[u], sub[v], total ^ sub[u] ^ sub[v]
                ans = min(ans, max(x1, x2, x3) - min(x1, x2, x3))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS + 枚举 | O(n^2) | O(n) |

## 关键点总结

1. 删去连向父节点的边，等价于将子树"割离"，子树 XOR 值就是该分量的 XOR。
2. 利用 DFS 时间戳判断祖孙关系，O(1) 完成。
3. 三个分量的 XOR 可由子树 XOR 和总 XOR 推导出来。

## 易错点

- 枚举的是节点（代表删去该节点与其父的边），而不是直接枚举边。
- 需要排除根节点（0），因为根节点没有父边。
