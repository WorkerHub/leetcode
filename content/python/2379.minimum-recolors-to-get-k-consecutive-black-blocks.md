## 题目描述

给你一个长度为 `n` 的字符串 `blocks`，其中 `blocks[i]` 要么是 `'W'`（白色），要么是 `'B'`（黑色）。

另给你一个整数 `k`，表示想要的**连续黑色块**的数量。

每次操作，你可以选择一个白色块，将其**涂成黑色**。

返回至少出现一次连续 `k` 个黑色块所需的**最少操作次数**。

**示例 1：**
```
输入：blocks = "WBBWWBBWBW", k = 7
输出：3
解释：找长度为 7 的窗口中白色块最少的：WBBWWBB（3个W）、BBWWBBW（3个W）等，最少 3 次。
```

**示例 2：**
```
输入：blocks = "WBWBBBW", k = 2
输出：0
```

**提示：**
- `n == blocks.length`
- `1 <= n <= 100`
- `blocks[i]` 为 `'W'` 或 `'B'`
- `1 <= k <= n`

## 解题思路

**滑动窗口：**
在所有长度为 k 的窗口中，找白色块 `'W'` 最少的那个，该窗口内白色块数即为最少操作次数。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        n = len(blocks)
        
        # 初始化第一个窗口
        white = blocks[:k].count('W')
        min_white = white
        
        # 滑动窗口
        for i in range(k, n):
            # 移入右边新字符
            if blocks[i] == 'W':
                white += 1
            # 移出左边旧字符
            if blocks[i - k] == 'W':
                white -= 1
            min_white = min(min_white, white)
        
        return min_white
```

### 方法二：枚举所有窗口

```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        return min(blocks[i:i+k].count('W') for i in range(len(blocks) - k + 1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 枚举 | O(n * k) | O(k) |

## 关键点总结

1. 将问题转化为：在所有长度为 k 的子串中，找白色块最少的。
2. 滑动窗口维护当前窗口的白色块数，只需 O(1) 更新。

## 易错点

- 最少操作次数等于窗口内白色块数（每个白色块需要一次涂色）。
- 窗口右端点从 k 到 n-1，枚举所有长度为 k 的窗口。
