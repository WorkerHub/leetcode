## 题目描述

给你一个正整数 `primeFactors`，请你构造一个正整数 `n` 满足以下条件：
- `n` 的质因子分解中，每个质因子的出现次数之和等于 `primeFactors`
- `n` 的 **漂亮因子** 数目最大化

**漂亮因子** 是 `n` 的因子中，能被 `n` 的所有质因子整除的因子数。

返回 `n` 的漂亮因子的最大数目，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：primeFactors = 5
输出：6
```

**示例 2：**
```
输入：primeFactors = 8
输出：18
```

**提示：**
- `1 <= primeFactors <= 10^9`

## 解题思路

**数学转化**：设 `n = p1^a1 * p2^a2 * ... * pk^ak`，满足 `a1 + a2 + ... + ak = primeFactors`。

漂亮因子必须包含每个质因子至少一个，因此漂亮因子数为 `a1 * a2 * ... * ak`（每个质因子的幂次从 1 到 ai，各自选取一个）。

问题转化为：**将 `primeFactors` 拆分为若干正整数之和，使乘积最大**。这与 [LeetCode 343. Integer Break](https://leetcode.com/problems/integer-break/) 完全相同：
- 不使用 1（1 不增加乘积）
- 尽量拆成 3，最后剩余 1 时合并到一个 4 = 2*2，剩余 2 时直接保留

快速幂计算 `3^k mod (10^9+7)`。

## 代码实现

### 方法一：数学贪心 + 快速幂（推荐）

```python
class Solution:
    def maxNiceDivisors(self, primeFactors: int) -> int:
        MOD = 10 ** 9 + 7

        def fast_pow(base: int, exp: int, mod: int) -> int:
            """快速幂：计算 base^exp % mod"""
            result = 1
            base %= mod
            while exp > 0:
                if exp & 1:
                    result = result * base % mod
                base = base * base % mod
                exp >>= 1
            return result

        n = primeFactors
        if n == 1:
            return 1
        if n == 2:
            return 2
        if n == 3:
            return 3

        # 尽量拆成 3
        remainder = n % 3
        threes = n // 3

        if remainder == 0:
            # 全部拆成 3：3^(n//3)
            return fast_pow(3, threes, MOD)
        elif remainder == 1:
            # 最后剩 1，合并为 4 = 2*2：3^(n//3 - 1) * 4
            return fast_pow(3, threes - 1, MOD) * 4 % MOD
        else:
            # 最后剩 2：3^(n//3) * 2
            return fast_pow(3, threes, MOD) * 2 % MOD
```

### 方法二：Python 内置幂函数（简化代码）

```python
class Solution:
    def maxNiceDivisors(self, primeFactors: int) -> int:
        MOD = 10 ** 9 + 7
        n = primeFactors

        if n <= 3:
            return n

        remainder = n % 3
        threes = n // 3

        if remainder == 0:
            return pow(3, threes, MOD)
        elif remainder == 1:
            # 4 = 2*2，比 3+1 = 1*3 更优
            return pow(3, threes - 1, MOD) * 4 % MOD
        else:
            return pow(3, threes, MOD) * 2 % MOD
```

## 复杂度分析

- **时间复杂度**：O(log n)，快速幂的时间复杂度
- **空间复杂度**：O(1)

## 关键点总结

1. 本题与"整数拆分"本质相同：最大化若干正整数之积，且这些数之和固定
2. 数学结论：尽量拆成 3，余 1 时用 2+2 代替 3+1，余 2 时直接保留 2
3. 结果需要对 10^9+7 取模，注意使用快速幂
4. Python 内置 `pow(base, exp, mod)` 已实现快速幂

## 易错点

- n=1,2,3 时需要特殊处理（不能拆，直接返回 n）
- 余 1 时减少一个 3，用 2*2=4 代替，而非直接加 1
