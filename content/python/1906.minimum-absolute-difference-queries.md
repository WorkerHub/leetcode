## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，其中 `1 <= nums[i] <= 100`，以及查询数组 `queries`，`queries[i] = [li, ri]`。

对于每个查询 `i`，计算子数组 `nums[li..ri]` 中所有元素之间的**最小绝对差**（不要求元素的位置不同，但两个元素必须**不同**）。如果子数组中所有元素相同，则最小绝对差为 `-1`。

返回查询结果数组 `ans`，其中 `ans[i]` 是第 `i` 个查询的答案。

**示例 1：**
```
输入：nums = [1,3,4,8], queries = [[0,1],[1,2],[2,3],[0,3]]
输出：[2,1,4,1]
```

**示例 2：**
```
输入：nums = [4,5,2,2,7,10], queries = [[2,3],[0,2],[0,5],[3,5]]
输出：[-1,1,1,3]
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 100`
- `1 <= queries.length <= 2 * 10^4`
- `0 <= li < ri < nums.length`

---

## 解题思路

### 核心思想：前缀和计数数组

由于 `nums[i]` 的值域只有 `1` 到 `100`，可以用前缀和统计每个值的出现次数：

- `prefix[i][v]` = `nums[0..i-1]` 中值 `v` 的出现次数
- 对于查询 `[l, r]`，值 `v` 在该范围内的出现次数 = `prefix[r+1][v] - prefix[l][v]`

对每个查询，遍历值域 `1` 到 `100`，找出所有在 `[l, r]` 中出现的值，相邻两个值的差的最小值即为答案。

---

## 代码实现

### 方法一：前缀和 + 值域枚举（推荐）

```python
from typing import List

class Solution:
    def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        # prefix[i][v] 表示 nums[0..i-1] 中值 v 的出现次数
        # 值域为 1..100，共 101 个槽
        prefix = [[0] * 101 for _ in range(n + 1)]

        for i, x in enumerate(nums):
            # 复制上一行
            prefix[i + 1] = prefix[i][:]
            # 更新当前值的计数
            prefix[i + 1][x] += 1

        result = []
        for l, r in queries:
            prev = -1       # 上一个出现的值
            min_diff = float('inf')

            for v in range(1, 101):
                # 判断值 v 是否在 [l, r] 范围内出现
                if prefix[r + 1][v] - prefix[l][v] > 0:
                    if prev != -1:
                        # 更新最小差值
                        min_diff = min(min_diff, v - prev)
                    prev = v

            result.append(min_diff if min_diff != float('inf') else -1)

        return result
```

### 方法二：空间优化版（每行只存差分）

```python
from typing import List

class Solution:
    def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        MAX_VAL = 101

        # prefix[i][v] = nums[0..i-1] 中 v 的出现次数
        # 使用列表推导构建
        prefix = [[0] * MAX_VAL]
        for x in nums:
            row = prefix[-1][:]
            row[x] += 1
            prefix.append(row)

        result = []
        for l, r in queries:
            prev = -1
            ans = float('inf')
            for v in range(1, MAX_VAL):
                # 判断 v 是否在区间 [l, r] 内出现
                cnt = prefix[r + 1][v] - prefix[l][v]
                if cnt > 0:
                    if prev >= 0:
                        ans = min(ans, v - prev)
                    prev = v
            result.append(-1 if ans == float('inf') else ans)

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n * 100 + q * 100) | O(n * 100) |
| 方法二 | 同上 | O(n * 100) |

其中 n 为数组长度，q 为查询数，值域固定为 100。

---

## 关键点总结

1. 值域有限（1~100）是关键约束，可用前缀和计数
2. 对每个查询遍历值域，找到区间内存在的相邻值之间的最小差
3. 前缀和思路：`prefix[r+1][v] - prefix[l][v]` 判断 v 是否在区间内出现

---

## 易错点

- 前缀和索引注意：查询 `[l, r]` 对应 `prefix[r+1][v] - prefix[l][v]`（左闭右闭区间）
- 当区间内只有一种不同的值时，答案为 `-1`
- 空间占用较大（n * 101），可用差分数组进行优化
