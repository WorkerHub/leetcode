## 题目描述

给定一个 DataFrame `products`，将 `quantity` 列中所有缺失值（NaN）填充为 0。

**示例：**
```
输入：quantity 列有部分 NaN

输出：NaN 填充为 0
```

## Python 代码实现

### 方法一：fillna（推荐）

```python
import pandas as pd

def fillMissingValues(products: pd.DataFrame) -> pd.DataFrame:
    products['quantity'] = products['quantity'].fillna(0)
    return products
```

### 方法二：就地填充

```python
import pandas as pd

def fillMissingValues(products: pd.DataFrame) -> pd.DataFrame:
    products.fillna({'quantity': 0}, inplace=True)
    return products
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（就地操作）

## 关键点总结

1. `df['col'].fillna(value)` 填充指定列的缺失值
2. `df.fillna({'col': val})` 字典方式批量填充不同列
3. `inplace=True` 就地修改，不返回新 DataFrame
