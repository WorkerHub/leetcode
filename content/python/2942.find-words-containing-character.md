## 题目描述

给你一个字符串数组 `words` 和一个字符 `x`，返回所有包含字符 `x` 的单词的下标组成的数组（顺序不限）。

**示例 1：**
```
输入：words = ["leet","code"], x = "e"
输出：[0,1]
```

**示例 2：**
```
输入：words = ["abc","bcd","aaaa","cbc"], x = "a"
输出：[0,2]
```

**提示：**
- `1 <= words.length <= 50`
- `1 <= words[i].length <= 50`
- `x` 是一个小写字母
- `words[i]` 只含小写英文字母

## 解题思路

直接遍历所有单词，检查每个单词是否包含字符 `x`，若包含则将其下标加入结果。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def findWordsContaining(self, words: List[str], x: str) -> List[int]:
        return [i for i, word in enumerate(words) if x in word]
```

### 方法二：显式循环

```python
from typing import List

class Solution:
    def findWordsContaining(self, words: List[str], x: str) -> List[int]:
        result = []
        for i, word in enumerate(words):
            if x in word:
                result.append(i)
        return result
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为单词数，m 为最长单词长度
- 空间复杂度：O(k)，k 为结果数组长度

## 关键点总结

1. Python 的 `in` 操作符检查字符串包含关系，时间 O(m)
2. `enumerate` 同时获取下标和元素，简洁高效
3. 列表推导式是 Python 惯用写法

## 易错点

1. 返回下标而不是单词本身
2. `x` 是字符（长度为 1 的字符串），`in` 检查字符包含
