## 题目描述

给定一个字符串数组 words，找到以 words 中每个字符串作为子字符串的最短字符串。

如果有多个有效最短字符串，返回其中任意一个。

## Python 代码实现

```python
from typing import List

class Solution:
    def shortestSuperstring(self, words: List[str]) -> str:
        n = len(words)
        
        # 计算重叠长度
        overlap = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if i != j:
                    for k in range(min(len(words[i]), len(words[j])), 0, -1):
                        if words[i][-k:] == words[j][:k]:
                            overlap[i][j] = k
                            break
        
        # 状态压缩DP
        dp = [[0] * n for _ in range(1 << n)]
        parent = [[-1] * n for _ in range(1 << n)]
        
        for mask in range(1 << n):
            for i in range(n):
                if mask & (1 << i):
                    prev_mask = mask ^ (1 << i)
                    if prev_mask == 0:
                        continue
                    for j in range(n):
                        if prev_mask & (1 << j):
                            if dp[prev_mask][j] + overlap[j][i] > dp[mask][i]:
                                dp[mask][i] = dp[prev_mask][j] + overlap[j][i]
                                parent[mask][i] = j
        
        # 找到最优路径
        full_mask = (1 << n) - 1
        last = max(range(n), key=lambda i: dp[full_mask][i])
        
        # 重建字符串
        path = []
        mask = full_mask
        while last != -1:
            path.append(last)
            new_last = parent[mask][last]
            mask ^= (1 << last)
            last = new_last
        
        path = path[::-1]
        
        # 构建结果
        result = words[path[0]]
        for i in range(1, len(path)):
            result += words[path[i]][overlap[path[i-1]][path[i]]:]
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 * 2^n)
- 空间复杂度：O(n * 2^n)
