## 题目描述

给你一个二维整数数组 `queries`，其中 `queries[i] = [n_i, k_i]`。

对于第 `i` 个查询，在满足下列条件的前提下，请你计算长度为 `n_i` 的数组中元素乘积等于 `k_i` 的方案数：
- 数组中每个元素都是正整数
- 最小的整数是 1

由于答案可能很大，返回对 `10^9 + 7` 取余的结果。

**示例：**
```
输入：queries = [[2,6],[5,1],[73,660]]
输出：[4,1,50734910]
```

**提示：**
- `1 <= queries.length <= 10^4`
- `1 <= n_i, k_i <= 10^4`

## 解题思路

问题转化为：将 `k` 分解为 `n` 个正整数的乘积，有多少种方案（考虑顺序）。

用隔板法（星与条）：
- 将 `k` 做质因数分解 `k = p1^a1 * p2^a2 * ...`
- 对每个质因数 `p^a`，把 `a` 个 `p` 分配到 `n` 个位置的方案数为 `C(a + n - 1, n - 1)`（隔板法，允许某些位置分到 0 个）
- 所有质因数独立，方案总数为各方案数之积

**预处理组合数** `C(a + n - 1, n - 1)`：用 Lucas 定理或直接预处理。由于 `a <= log2(k) <= 14`，`n <= 10^4`，最大参数为 `a + n - 1 <= 10^4 + 14`。

## 代码实现

### 方法一：质因数分解 + 组合数（推荐）

```python
from typing import List

MOD = 10 ** 9 + 7
MAX = 10014 + 14  # 最大 C(n + a - 1, a) 中 n + a - 1 的上界

# 预处理阶乘和逆元
fact = [1] * (MAX + 1)
for i in range(1, MAX + 1):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (MAX + 1)
inv_fact[MAX] = pow(fact[MAX], MOD - 2, MOD)
for i in range(MAX - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n, r):
    """计算 C(n, r)"""
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

def count_ways(n, k):
    """将 k 分配为 n 个正整数乘积的方案数"""
    result = 1
    # 质因数分解 k
    d = 2
    while d * d <= k:
        if k % d == 0:
            exp = 0
            while k % d == 0:
                exp += 1
                k //= d
            # 将 exp 个 d 分配到 n 个位置，方案数 = C(exp + n - 1, n - 1)
            result = result * comb(exp + n - 1, n - 1) % MOD
        d += 1
    if k > 1:
        # k 本身是质数
        result = result * comb(1 + n - 1, n - 1) % MOD
    return result

class Solution:
    def waysToFillArray(self, queries: List[List[int]]) -> List[int]:
        return [count_ways(n, k) for n, k in queries]
```

### 方法二：动态规划（逐步分解）

```python
from typing import List
from functools import lru_cache

MOD = 10 ** 9 + 7

class Solution:
    def waysToFillArray(self, queries: List[List[int]]) -> List[int]:
        # 预处理组合数
        MAX_C = 14000
        C = [[0] * (MAX_C + 1) for _ in range(MAX_C + 1)]
        C[0][0] = 1
        for i in range(1, MAX_C + 1):
            C[i][0] = 1
            for j in range(1, i + 1):
                C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD
        
        def solve(n, k):
            res = 1
            d = 2
            while d * d <= k:
                if k % d == 0:
                    exp = 0
                    while k % d == 0:
                        exp += 1
                        k //= d
                    # C(exp + n - 1, n - 1)
                    row = exp + n - 1
                    col = n - 1
                    if row <= MAX_C and col <= MAX_C:
                        res = res * C[row][col] % MOD
                d += 1
            if k > 1:
                row = n  # C(n, n-1)
                col = n - 1
                if row <= MAX_C and col <= MAX_C:
                    res = res * C[row][col] % MOD
            return res
        
        return [solve(n, k) for n, k in queries]
```

## 复杂度分析

- **时间复杂度**：O(Q * sqrt(k))，Q 为查询数量，sqrt(k) 用于质因数分解
- **空间复杂度**：O(MAX) 预处理组合数

## 关键点总结

1. 质因数分解后，每个质因数独立分配，方案数相乘
2. 将 `a` 分配到 `n` 个位置（可以为 0）的方案数 = 隔板法 `C(a + n - 1, n - 1)`
3. 预处理阶乘和逆元加速组合数计算

## 易错点

- 组合数取模要用费马小定理或预处理逆元
- 每次 `count_ways` 需要一份 `k` 的副本（质因数分解会修改 k）
