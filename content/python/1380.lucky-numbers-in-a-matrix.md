## 题目描述

给你一个 `m x n` 的矩阵，矩阵中的数字各不相同。请你返回矩阵中所有的**幸运数**。

**幸运数**是指矩阵中满足同时满足下列两个条件的元素：
1. 在同一行的所有元素中最小。
2. 在同一列的所有元素中最大。

你可以按**任意顺序**返回答案。

**示例 1：**
```
输入：matrix = [[3,7,8],[9,11,13],[15,16,17]]
输出：[15]
解释：15 是第 3 行中最小的元素，也是第 1 列中最大的元素。
```

**示例 2：**
```
输入：matrix = [[1,10,4,2],[9,3,8,7],[15,16,17,12]]
输出：[12]
解释：12 是第 3 行中最小值，也是第 4 列中最大值。
```

**示例 3：**
```
输入：matrix = [[7,8],[1,2]]
输出：[7]
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 50`
- `1 <= matrix[i][j] <= 10^5`
- 矩阵中的所有元素都是不同的

## 解题思路

### 核心思想

幸运数需要同时满足两个条件：行最小值 且 列最大值。

**方法：集合交集**
1. 找出每行的最小值，放入集合 `row_mins`。
2. 找出每列的最大值，放入集合 `col_maxs`。
3. 两个集合的**交集**就是所有幸运数。

**为什么集合交集可行？**
- 如果某值是行最小值，那它一定在 `row_mins` 中。
- 如果它同时又是列最大值，那它也在 `col_maxs` 中。
- 矩阵中所有数字各不相同，所以用值来标识位置不会有歧义。

### 方法一：集合交集（推荐，O(m×n)）

### 方法二：暴力枚举（O(m×n×(m+n))）

## Python 代码实现

### 方法一：集合交集（推荐）

```python
from typing import List

class Solution:
    def luckyNumbers(self, matrix: List[List[int]]) -> List[int]:
        # 每行的最小值集合
        row_mins = {min(row) for row in matrix}

        # 每列的最大值集合
        # zip(*matrix) 可以转置矩阵，每个元素变成对应列的元素
        col_maxs = {max(col) for col in zip(*matrix)}

        # 两个集合的交集即为幸运数
        return list(row_mins & col_maxs)
```

### 方法二：暴力枚举（直观，对新手友好）

```python
from typing import List

class Solution:
    def luckyNumbers(self, matrix: List[List[int]]) -> List[int]:
        m = len(matrix)
        n = len(matrix[0])
        result = []

        for i in range(m):
            for j in range(n):
                val = matrix[i][j]

                # 检查是否是第 i 行的最小值
                is_row_min = all(val <= matrix[i][k] for k in range(n))

                # 检查是否是第 j 列的最大值
                is_col_max = all(val >= matrix[k][j] for k in range(m))

                if is_row_min and is_col_max:
                    result.append(val)

        return result
```

### 方法三：预计算行最小值和列最大值

```python
from typing import List

class Solution:
    def luckyNumbers(self, matrix: List[List[int]]) -> List[int]:
        m = len(matrix)
        n = len(matrix[0])

        # 预计算每行最小值
        row_min = [min(matrix[i]) for i in range(m)]

        # 预计算每列最大值
        col_max = [max(matrix[i][j] for i in range(m)) for j in range(n)]

        result = []
        for i in range(m):
            for j in range(n):
                # 既是行最小值又是列最大值
                if matrix[i][j] == row_min[i] and matrix[i][j] == col_max[j]:
                    result.append(matrix[i][j])

        return result
```

### 方法四：numpy 向量化（大矩阵适用）

```python
from typing import List
import numpy as np

class Solution:
    def luckyNumbers(self, matrix: List[List[int]]) -> List[int]:
        mat = np.array(matrix)

        # 每行最小值（沿列方向 axis=1）
        row_min = mat.min(axis=1, keepdims=True)  # shape: (m, 1)

        # 每列最大值（沿行方向 axis=0）
        col_max = mat.max(axis=0, keepdims=True)  # shape: (1, n)

        # 找出既是行最小值又是列最大值的元素
        mask = (mat == row_min) & (mat == col_max)

        return mat[mask].tolist()
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合交集 | O(m×n) | O(m+n) |
| 暴力枚举 | O(m×n×(m+n)) | O(1) |
| 预计算 | O(m×n) | O(m+n) |

- **方法一/三**：两次线性扫描，O(m×n)，推荐。
- **方法二**：对每个元素分别检查其所在行和列，O(m×n×(m+n))，小数据可接受。

## 关键点总结

1. **集合交集**：将"行最小值"和"列最大值"分别收集到集合，取交集是最优雅的写法。
2. **`zip(*matrix)` 转置矩阵**：Python 中快速获取列元素的技巧，`zip(*matrix)` 将行列互换。
3. **元素唯一性**：矩阵中所有数字不同，所以可以用值作为集合元素，不会出现歧义。
4. **集合运算 `&`**：Python 中两个集合取交集的简洁写法。
5. 幸运数最多只有1个（可以证明：若存在两个幸运数，则出现矛盾）。

## 易错点

1. **只检查行最小值而忘记列最大值**：两个条件缺一不可。
2. **用值而不是坐标**：本题矩阵元素唯一，可以用值来标识，但若元素可重复则需改用坐标。
3. **`zip(*matrix)` 的用法**：`zip(*matrix)` 中 `*` 是解包操作，将矩阵的各行作为独立参数传给 zip，得到列的迭代器。
4. **集合交集结果转列表**：题目要求返回列表，`set & set` 返回集合，需用 `list()` 转换。
