## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，如果 `nums` 有一个好的子数组返回 `true`，否则返回 `false`：

一个**好的子数组**是：
- 长度至少为 2
- 元素总和为 `k` 的倍数

**示例 1：**
```
输入：nums = [23,2,4,6,7], k = 6
输出：true
解释：[2, 4] 是一个大小为 2 的子数组，并且和为 6。
```

**示例 2：**
```
输入：nums = [23,2,6,4,7], k = 6
输出：true
解释：[23, 2, 6, 4, 7] 是大小为 5 的子数组，并且和为 42。
42 是 6 的倍数，因为 42 = 7 × 6 且 7 是一个整数。
```

**示例 3：**
```
输入：nums = [23,2,6,4,7], k = 13
输出：false
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= sum(nums[i]) <= 2^31 - 1`
- `1 <= k <= 2^31 - 1`

## 解题思路

### 核心思想：
使用**前缀和 + 哈希表**记录余数。

**数学原理：**
- 如果 `(preSum[j] - preSum[i]) % k == 0`
- 等价于 `preSum[j] % k == preSum[i] % k`

### 算法流程：
1. 用哈希表记录每个余数第一次出现的位置
2. 如果当前余数之前出现过，且距离 ≥ 2，返回 true

## Python 代码实现

```python
from typing import List

class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        """
        前缀和 + 哈希表
        时间复杂度：O(n)，空间复杂度：O(min(n, k))
        """
        # 余数 -> 第一次出现的索引
        remainder_map = {0: -1}  # 初始余数 0 在索引 -1
        prefix_sum = 0
        
        for i, num in enumerate(nums):
            prefix_sum += num
            remainder = prefix_sum % k
            
            if remainder in remainder_map:
                # 长度至少为 2
                if i - remainder_map[remainder] >= 2:
                    return True
            else:
                remainder_map[remainder] = i
        
        return False
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(min(n, k))

## 关键点总结

1. **余数性质**：同余定理
2. **长度限制**：至少为 2
3. **初始化**：`{0: -1}` 处理从头开始的子数组

## 易错点

1. **k = 0**：题目保证 k ≥ 1
2. **长度检查**：要 ≥ 2
3. **初始化**：余数 0 要放在索引 -1
