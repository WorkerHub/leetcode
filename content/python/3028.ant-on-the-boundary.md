## 题目描述

一只蚂蚁在数轴上，初始位于 0。给你一个整数数组 `nums`，每次操作蚂蚁沿数轴移动 `nums[i]`（正数向右，负数向左）。

返回蚂蚁**回到边界**（即数轴原点 0）的次数。

**注意：** 蚂蚁是在执行完每步操作后才检查是否到达原点。

**示例 1：**
```
输入：nums = [2,3,-5]
输出：1
解释：操作后位置：2, 5, 0，回到原点 1 次
```

**示例 2：**
```
输入：nums = [3,2,-3,-4]
输出：0
```

**提示：**
- `1 <= nums.length <= 100`
- `-10 <= nums[i] <= 10`

## 解题思路

计算前缀和，统计前缀和等于 0 的次数（即每次操作后位置为 0 的次数）。

## Python 代码实现

### 方法一：前缀和统计（推荐）

```python
from typing import List

class Solution:
    def returnToBoundaryCount(self, nums: List[int]) -> int:
        pos = 0
        count = 0
        for x in nums:
            pos += x
            if pos == 0:
                count += 1
        return count
```

### 方法二：使用 itertools.accumulate

```python
from typing import List
from itertools import accumulate

class Solution:
    def returnToBoundaryCount(self, nums: List[int]) -> int:
        return sum(1 for s in accumulate(nums) if s == 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 蚂蚁位置 = 前缀和
2. 统计前缀和为 0 的次数即为回到边界的次数

## 易错点

1. 是每步后检查（前缀和），不是移动过程中经过 0
2. 初始位置 0 不算一次"回到边界"
