## 题目描述

给定整数数组 `nums` 和整数 `k`，对于每个下标 `i`，定义其"美丽分"为：与 `nums[i]` 的差值绝对值不超过 `k` 的其他元素的个数。

返回所有下标中最大的美丽分。

**示例 1：**
```
输入：nums = [9,7,2,5], k = 3
输出：2
解释：
- nums[0]=9: |9-7|=2<=3, |9-2|=7>3, |9-5|=4>3 -> 1 个
- nums[1]=7: |7-9|=2<=3, |7-2|=5>3, |7-5|=2<=3 -> 2 个
- nums[2]=2: |2-9|=7>3, |2-7|=5>3, |2-5|=3<=3 -> 1 个
- nums[3]=5: |5-9|=4>3, |5-7|=2<=3, |5-2|=3<=3 -> 2 个
最大美丽分为 2。
```

**示例 2：**
```
输入：nums = [1,1,1,1], k = 10
输出：3
解释：每个元素与其他 3 个差值均为 0 <= 10，美丽分为 3。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i], k <= 10^5`

## 解题思路

排序 + 滑动窗口。

对 `nums[i]`，满足条件的元素是 `[nums[i]-k, nums[i]+k]` 范围内的元素。

排序后，对每个 `nums[i]`，用二分查找或双指针找范围内元素的个数，减去 1（排除自身）。

## Python 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        sorted_nums = sorted(nums)
        n = len(sorted_nums)
        ans = 0
        left = 0

        for right in range(n):
            # 保持窗口内的最小值 >= sorted_nums[right] - k
            while sorted_nums[right] - sorted_nums[left] > k:
                left += 1
            # 窗口 [left, right] 内所有元素差值 <= k
            # 美丽分（对于 sorted_nums[right]）= right - left（排除自身）
            ans = max(ans, right - left)

        return ans
```

### 方法二：排序 + 二分查找

```python
from typing import List
import bisect

class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        sorted_nums = sorted(nums)
        n = len(sorted_nums)
        ans = 0

        for i in range(n):
            lo = bisect.bisect_left(sorted_nums, sorted_nums[i] - k)
            hi = bisect.bisect_right(sorted_nums, sorted_nums[i] + k)
            ans = max(ans, hi - lo - 1)  # 减去自身

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序加线性扫描（双指针）
- 空间复杂度：O(n)，排序数组

## 关键点总结

1. 排序后，满足差值 <= k 的元素构成连续区间
2. 双指针维护满足条件的滑动窗口
3. 美丽分 = 窗口大小 - 1（减去元素自身）

## 易错点

1. 计算美丽分时需要减去自身（不计自己）
2. 双指针中，`sorted_nums[right] - sorted_nums[left] > k` 是正确的收缩条件
