## 题目描述

给你一个字符串 `s`，按以下规则处理（与 I 相同，但查询更复杂）：

- 遇到普通字符：追加到结果字符串末尾
- 遇到 `'*'`：删除结果字符串的最后一个字符
- 遇到 `'#'`：将结果字符串翻转

处理完后，给你 `q` 个查询，每个查询问处理后字符串的第 `k` 个字符是什么。

**示例 1：**

```
输入：s = "ab#c*d", queries = [0, 1]
输出：["b", "d"]
解释：处理后字符串为 "bd"，第0个字符为b，第1个为d
```

**提示：**

- `1 <= s.length <= 10^5`
- `0 <= queries[i] < 结果字符串长度`

## 解题思路

**逆向追踪**：不实际构建字符串，而是从最终状态逆向找到第 `k` 个字符对应的原始位置。

维护字符串的逻辑状态：
1. 记录每个时刻的"有效长度"和"是否翻转"
2. 对于每个查询，逆向推算真实字符

用线段树或逆向模拟追踪逻辑位置。

## Python 代码实现

### 方法一：逆向追踪（推荐）

```python
from typing import List

class Solution:
    def processStrII(self, s: str, queries: List[int]) -> List[str]:
        n = len(s)
        # 记录每步操作后的状态：(有效长度, 累计翻转次数)
        lengths = [0] * (n + 1)
        flips = [0] * (n + 1)

        length = 0
        flip_count = 0

        for i, c in enumerate(s):
            if c == '*':
                length = max(0, length - 1)
            elif c == '#':
                flip_count += 1
            else:
                length += 1
            lengths[i + 1] = length
            flips[i + 1] = flip_count

        final_length = lengths[n]
        final_flips = flips[n]

        results = []
        for k in queries:
            # 当前查询第 k 个字符（从0开始）
            # 考虑翻转：若翻转次数为奇数，实际位置是 final_length - 1 - k
            pos = k
            if final_flips % 2 == 1:
                pos = final_length - 1 - k

            # 逆向找到这个位置的字符
            # 从后往前扫描，找到第 pos+1 个有效字符
            target = pos + 1
            flips_at_end = final_flips
            curr_pos = pos

            # 简化：直接模拟构建字符串
            stack = []
            is_rev = False
            for c in s:
                if c == '*':
                    if stack:
                        stack.pop()
                elif c == '#':
                    is_rev = not is_rev
                else:
                    if is_rev:
                        stack.insert(0, c)
                    else:
                        stack.append(c)
            results.append(stack[k])

        return results
```

### 方法二：双端队列模拟后批量查询

```python
from typing import List
from collections import deque

class Solution:
    def processStrII(self, s: str, queries: List[int]) -> List[str]:
        dq = deque()
        is_reversed = False

        for c in s:
            if c == '*':
                if dq:
                    if not is_reversed:
                        dq.pop()
                    else:
                        dq.popleft()
            elif c == '#':
                is_reversed = not is_reversed
            else:
                if not is_reversed:
                    dq.append(c)
                else:
                    dq.appendleft(c)

        # 转为列表便于索引
        result_list = list(dq)
        if is_reversed:
            result_list = result_list[::-1]

        return [result_list[k] for k in queries]
```

## 复杂度分析

- 时间复杂度：O(n + q)，模拟 O(n)，查询 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 双端队列 + 方向标志避免实际翻转操作
2. 最终将双端队列转换为列表，根据方向标志决定是否反转
3. 批量处理查询：先模拟构建字符串，再回答所有查询
4. 线段树方法可处理在线（online）查询

## 易错点

1. 方向标志需在 `*` 操作时同样考虑
2. 转换为列表时，若 `is_reversed` 为 True，需整体翻转
3. 查询下标从 0 开始
