## 题目描述

给出一些不同颜色的盒子 boxes，盒子的颜色由不同的正数表示。

你将经过若干轮操作去去掉盒子，直到所有的盒子都去掉为止。每一轮你可以移除具有相同颜色的连续 k 个盒子（k >= 1），这样一轮之后你将得到 k * k 分。

返回你能获得的最大积分和。

**示例 1：**
```
输入：boxes = [1,3,2,2,2,3,4,3,1]
输出：23
解释：
[1, 3, 2, 2, 2, 3, 4, 3, 1] 
----> [1, 3, 3, 4, 3, 1] (3*3=9 分) 
----> [1, 3, 3, 3, 1] (1*1=1 分) 
----> [1, 1] (3*3=9 分) 
----> [] (2*2=4 分)
总分 = 9 + 1 + 9 + 4 = 23
```

**示例 2：**
```
输入：boxes = [1,1,1]
输出：9
```

**示例 3：**
```
输入：boxes = [1]
输出：1
```

**提示：**
- 1 <= boxes.length <= 100
- 1 <= boxes[i] <= 100

## 解题思路

这是一道困难的动态规划题目，关键在于如何定义状态和设计状态转移。

**核心思想：**

不能简单地使用区间DP，因为移除某段盒子后，两端可能会连接形成新的连续盒子。

**状态定义：**
- `dp[l][r][k]` 表示移除 boxes[l...r] 区间的盒子，且 boxes[r] 右侧有 k 个与 boxes[r] 颜色相同的盒子时，能获得的最大积分

**状态转移：**
1. 直接移除 boxes[r] 及右侧的 k 个相同颜色盒子：`(k+1)^2 + dp[l][r-1][0]`
2. 在区间中找到与 boxes[r] 相同颜色的位置 i，先移除中间部分，让两端的相同颜色盒子合并：`dp[l][i][k+1] + dp[i+1][r-1][0]`

## Python 代码实现

### 方法一：记忆化搜索（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def removeBoxes(self, boxes: List[int]) -> int:
        n = len(boxes)
        
        # 使用装饰器实现记忆化
        @lru_cache(None)
        def dp(l: int, r: int, k: int) -> int:
            """
            计算移除 boxes[l...r] 的最大积分
            k 表示 boxes[r] 右侧有 k 个与 boxes[r] 颜色相同的盒子
            """
            # 基础情况
            if l > r:
                return 0
            
            # 优化：将右侧连续相同的盒子合并到 k 中
            while r > l and boxes[r] == boxes[r-1]:
                r -= 1
                k += 1
            
            # 情况1：直接移除 boxes[r] 及其右侧的 k 个相同颜色盒子
            res = dp(l, r-1, 0) + (k + 1) * (k + 1)
            
            # 情况2：在区间中找到与 boxes[r] 相同颜色的位置
            for i in range(l, r):
                if boxes[i] == boxes[r]:
                    # 先移除 boxes[i+1...r-1]，然后 boxes[i] 和 boxes[r] 及右侧的 k 个合并
                    res = max(res, dp(l, i, k+1) + dp(i+1, r-1, 0))
            
            return res
        
        return dp(0, n-1, 0)
```

### 方法二：动态规划数组

```python
from typing import List

class Solution:
    def removeBoxes(self, boxes: List[int]) -> int:
        n = len(boxes)
        # dp[l][r][k] 表示移除 boxes[l...r] 且 boxes[r] 右侧有 k 个相同颜色盒子的最大积分
        dp = [[[0] * n for _ in range(n)] for _ in range(n)]
        
        # 递归计算
        def calculate(l: int, r: int, k: int) -> int:
            if l > r:
                return 0
            
            if dp[l][r][k] > 0:
                return dp[l][r][k]
            
            # 优化：合并右侧连续相同的盒子
            original_r = r
            original_k = k
            while r > l and boxes[r] == boxes[r-1]:
                r -= 1
                k += 1
            
            # 情况1：直接移除
            dp[l][r][k] = calculate(l, r-1, 0) + (k + 1) * (k + 1)
            
            # 情况2：寻找相同颜色的盒子合并
            for i in range(l, r):
                if boxes[i] == boxes[r]:
                    dp[l][r][k] = max(dp[l][r][k], 
                                     calculate(l, i, k+1) + calculate(i+1, r-1, 0))
            
            return dp[l][r][k]
        
        return calculate(0, n-1, 0)
```

### 方法三：简化版记忆化搜索

```python
from typing import List

class Solution:
    def removeBoxes(self, boxes: List[int]) -> int:
        n = len(boxes)
        memo = {}
        
        def dp(l: int, r: int, k: int) -> int:
            if l > r:
                return 0
            
            if (l, r, k) in memo:
                return memo[(l, r, k)]
            
            # 合并连续相同颜色的盒子
            while r > l and boxes[r] == boxes[r-1]:
                r -= 1
                k += 1
            
            # 直接移除最右侧
            result = dp(l, r-1, 0) + (k + 1) ** 2
            
            # 尝试与前面相同颜色的盒子合并
            for i in range(l, r):
                if boxes[i] == boxes[r]:
                    result = max(result, dp(l, i, k+1) + dp(i+1, r-1, 0))
            
            memo[(l, r, k)] = result
            return result
        
        return dp(0, n-1, 0)
```

## 复杂度分析

- 时间复杂度：O(n^4)
  - 状态数量：O(n^3)，l、r、k 三个维度
  - 每个状态的计算：O(n)，需要遍历区间
- 空间复杂度：O(n^3)，记忆化存储所有状态

## 关键点总结

1. 状态定义要考虑右侧相同颜色盒子的个数
2. 合并连续相同颜色的盒子可以优化计算
3. 需要考虑两种策略：直接移除或寻找合并机会
4. 使用记忆化搜索避免重复计算
5. 这是一道非常难的DP题，需要深入理解状态设计

## 易错点

1. 状态定义不完整，没有考虑右侧相同颜色盒子
2. 忘记合并连续相同颜色的盒子导致超时
3. 状态转移方程理解错误
4. 没有使用记忆化导致超时
