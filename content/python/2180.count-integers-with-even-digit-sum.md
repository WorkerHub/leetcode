## 题目描述

给你一个正整数 `num`，请你统计在范围 `[1, num]` 内，各位数字之和为**偶数**的正整数数目，并返回该数目。

**示例 1：**
```
输入：num = 4
输出：2
解释：2 和 4 的各位数字之和为偶数（2 和 4）。
```

**示例 2：**
```
输入：num = 30
输出：14
```

**提示：**
- `1 <= num <= 1000`

## 解题思路

**直接模拟**

n <= 1000，遍历 1 到 num，判断各位数字之和是否为偶数。

## 代码实现

### 方法一：直接模拟（推荐）

```python
class Solution:
    def countEven(self, num: int) -> int:
        count = 0
        for n in range(1, num + 1):
            # 计算各位数字之和
            if sum(int(d) for d in str(n)) % 2 == 0:
                count += 1
        return count
```

### 方法二：数学规律

```python
class Solution:
    def countEven(self, num: int) -> int:
        # 计算 num 的各位数字之和
        digit_sum = sum(int(d) for d in str(num))
        # 在 [1, num] 中，各位和为偶数的个数
        # num // 2 个偶数 + 可能的额外一个
        if digit_sum % 2 == 0:
            return num // 2
        else:
            return (num - 1) // 2
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(num * d)，d 为位数 | O(1) |
| 数学 | O(d) | O(1) |

## 关键点总结

1. 数学规律：1 到 num 中，各位和为偶数的数约占一半。
2. 若 num 的各位数字之和为偶数，则恰好 `num // 2` 个。
3. 若为奇数，则 `(num - 1) // 2` 个。

**规律推导：** 
- 对每个 k，k 和 k+1 中恰好有一个各位和为偶数（奇偶交替，除非进位改变奇偶性，但 1 到 num 中各位和奇偶大致交替）。
- 实际上：`f(num) = num // 2` 如果 num 的各位数字和为偶数，否则 `(num - 1) // 2`。

## 易错点

- 各位数字之和（不是数字本身的奇偶）。
- 方法二的数学规律需要仔细推导，建议直接用模拟法。
