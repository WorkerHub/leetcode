## 题目描述

给你一个 `n` 个节点的无向图，边集为 `edges`。请将节点分成尽可能多的组，使得每条边连接的两个节点属于相邻组（组编号差 1）。

返回最多可以分的组数，若无法满足条件返回 `-1`。

**示例 1：**

```
输入：n = 6, edges = [[1,2],[1,4],[1,5],[2,6],[2,3],[4,6]]
输出：4
```

**示例 2：**

```
输入：n = 3, edges = [[1,2],[2,3],[3,1]]
输出：-1
解释：含奇数环，无法二分
```

**提示：**

- `1 <= n <= 500`
- `1 <= edges.length <= 10^4`

## 解题思路

1. 首先检查每个连通分量是否是二部图（无奇数环）。若有奇数环返回 -1。
2. 对于每个连通分量，答案是该分量中任意两节点间的最大距离 + 1。
3. 用 BFS 计算每个节点到分量内所有节点的最大距离。
4. 最终答案是所有连通分量最大距离之和。

## Python 代码实现

### 方法一：并查集 + BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 检查二部图并找连通分量
        color = [-1] * (n + 1)
        components = []

        def bfs_color(start):
            comp = [start]
            color[start] = 0
            queue = deque([start])
            is_bipartite = True
            while queue:
                node = queue.popleft()
                for nb in graph[node]:
                    if color[nb] == -1:
                        color[nb] = 1 - color[node]
                        comp.append(nb)
                        queue.append(nb)
                    elif color[nb] == color[node]:
                        is_bipartite = False
            return comp, is_bipartite

        for i in range(1, n + 1):
            if color[i] == -1:
                comp, ok = bfs_color(i)
                if not ok:
                    return -1
                components.append(comp)

        def bfs_depth(start, comp_set):
            dist = {start: 0}
            queue = deque([start])
            max_d = 0
            while queue:
                node = queue.popleft()
                for nb in graph[node]:
                    if nb in comp_set and nb not in dist:
                        dist[nb] = dist[node] + 1
                        max_d = max(max_d, dist[nb])
                        queue.append(nb)
            return max_d + 1  # 层数

        ans = 0
        for comp in components:
            comp_set = set(comp)
            max_groups = max(bfs_depth(node, comp_set) for node in comp)
            ans += max_groups

        return ans
```

### 方法二：DFS 二部图检验 + BFS 直径

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u - 1].append(v - 1)
            graph[v - 1].append(u - 1)

        visited = [-1] * n
        ans = 0

        def get_depth(src):
            dist = [-1] * n
            dist[src] = 0
            q = deque([src])
            max_d = 0
            while q:
                u = q.popleft()
                for v in graph[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        max_d = max(max_d, dist[v])
                        q.append(v)
            return max_d + 1

        for i in range(n):
            if visited[i] != -1:
                continue
            comp = []
            color = {}
            q = deque([i])
            color[i] = 0
            is_bip = True
            while q:
                u = q.popleft()
                comp.append(u)
                visited[u] = i
                for v in graph[u]:
                    if v not in color:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        is_bip = False
            if not is_bip:
                return -1
            ans += max(get_depth(node) for node in comp)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * (n + E))，每个节点做一次 BFS
- 空间复杂度：O(n + E)

## 关键点总结

1. 奇数环（非二部图）直接返回 -1
2. 每个连通分量独立计算最大分组数
3. 分组数 = 分量中最大 BFS 深度（即任意节点出发的最大层数）
4. 各分量的最大分组数累加

## 易错点

1. 检查二部图不能只看单个连通分量，要对整个图检查
2. 每个分量内每个节点都要尝试作为 BFS 起点，取最大值
3. 节点编号可能从 1 开始，注意偏移
