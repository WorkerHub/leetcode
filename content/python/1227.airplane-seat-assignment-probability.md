## 题目描述

有 `n` 名乘客即将登机，飞机正好有 `n` 个座位。第一位乘客的票丢了，他随机选择了一个座位坐下。

剩下的乘客将会：

- 如果他们自己的座位还空着，就坐到自己的座位上
- 如果他们自己的座位被占了，就随机选择一个空座位坐下

返回第 `n` 位乘客坐在自己座位上的概率。

示例 1：
```
输入：n = 1
输出：1.00000
解释：第一个人只能坐在自己的座位上。
```

示例 2：
```
输入：n = 2
输出：0.50000
解释：第二个乘客有 50% 的概率坐在自己的座位上（当第一个人坐在第一个座位时）。
```

提示：
- `1 <= n <= 10^5`

## 解题思路

这是一道经典的概率论问题，看似复杂，但答案出人意料的简单。

### 直觉分析

让我们分析几种情况：

**n = 1：** 第一个人只能坐自己的座位，概率 = 1

**n = 2：**
- 第一个人坐座位 1：第二个人坐座位 2，概率 = 1/2 × 1 = 1/2
- 第一个人坐座位 2：第二个人无法坐座位 2，概率 = 1/2 × 0 = 0
- 总概率 = 1/2

**n = 3：**
- 第一个人坐座位 1：后续都坐自己的位置，概率 = 1/3
- 第一个人坐座位 2：
  - 第二个人随机选，问题变成了 n=2 的情况，概率 = 1/3 × 1/2 = 1/6
- 第一个人坐座位 3：第三个人无法坐自己位置，概率 = 1/3 × 0 = 0
- 总概率 = 1/3 + 1/6 + 0 = 1/2

### 数学归纳法证明

可以用数学归纳法证明：对于 n ≥ 2，答案都是 0.5。

关键观察：
1. 如果第一个人坐了座位 1（自己的座位），则所有人都能坐自己的座位
2. 如果第一个人坐了座位 n（最后一个人的座位），则最后一个人必然坐不到自己的座位
3. 如果第一个人坐了中间某个座位 k（2 ≤ k ≤ n-1），那么：
   - 座位 2 到 k-1 的人都能坐自己的座位
   - 第 k 个人会随机选座位，问题变成了一个规模更小的子问题

关键洞察：在任何时刻，只有座位 1 和座位 n 是"危险"的（可能被占）。每次随机选择时，选中座位 1 和座位 n 的概率是相等的，所以最终结果是 50%。

### 简洁证明

想象一个简化模型：
- 只要座位 1 还空着，后续乘客都能正常就座
- 一旦座位 1 被占，就会有新的"问题乘客"产生
- 最终，要么座位 1 被占（最后一个人坐不到），要么座位 n 被占（最后一个人能坐到）
- 这两种情况的概率完全对称，都是 0.5

## Python 代码实现

### 方法一：数学结论（推荐）

```python
class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        """
        直接返回数学结论
        
        Args:
            n: 乘客数量
            
        Returns:
            第n个乘客坐在自己座位上的概率
        """
        # n = 1 时，第一个人必然坐自己的座位
        # n >= 2 时，答案都是 0.5
        return 1.0 if n == 1 else 0.5
```

### 方法二：递推公式（用于理解）

```python
class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        """
        使用递推公式计算（实际不需要，但有助于理解）
        
        P(n) 表示第 n 个人坐到自己座位的概率
        
        P(1) = 1
        P(n) = 1/n + (1/n) * sum(P(k) for k in 2..n-1)
             = 1/n + (1/n) * (n-2) * 0.5  (因为 P(k) = 0.5 对于 k >= 2)
             = 1/n + (n-2)/(2n)
             = (2 + n - 2) / (2n)
             = 0.5
        """
        if n == 1:
            return 1.0
        return 0.5
```

### 方法三：蒙特卡洛模拟（验证答案）

```python
import random

class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        """
        使用蒙特卡洛模拟验证答案（不是实际解法）
        注意：这个方法效率低，仅用于理解和验证
        """
        if n == 1:
            return 1.0
        
        # 小规模时可以精确计算
        if n <= 10:
            return self._simulate(n, 100000)
        
        # 大规模直接返回理论值
        return 0.5
    
    def _simulate(self, n: int, trials: int) -> float:
        """模拟实验"""
        success_count = 0
        
        for _ in range(trials):
            seats = [False] * (n + 1)  # seats[i] 表示座位 i 是否被占
            seats[0] = True  # 0 号座位不存在，标记为已占
            
            # 第一个人随机选座位
            first_choice = random.randint(1, n)
            seats[first_choice] = True
            
            # 后续乘客
            for passenger in range(2, n + 1):
                if not seats[passenger]:
                    # 自己的座位空着，坐自己的
                    seats[passenger] = True
                else:
                    # 自己的座位被占，随机选一个空座位
                    available = [i for i in range(1, n + 1) if not seats[i]]
                    if available:
                        choice = random.choice(available)
                        seats[choice] = True
            
            # 检查最后一个人是否坐在座位 n
            if seats[n]:
                success_count += 1
        
        return success_count / trials
```

### 方法四：详细的递推实现

```python
class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        """
        展示递推逻辑的实现（帮助理解）
        """
        if n == 1:
            return 1.0
        
        # dp[i] 表示有 i 个座位时，第 i 个人坐到自己座位的概率
        dp = [0.0] * (n + 1)
        dp[1] = 1.0
        
        for i in range(2, n + 1):
            # 第一个人有 1/i 的概率坐座位 1（正确座位）
            # 有 1/i 的概率坐座位 i（最后一个人的座位）
            # 有 (i-2)/i 的概率坐中间某个座位
            
            # 坐座位 1：后续所有人都能坐对，概率贡献 1/i * 1
            # 坐座位 i：最后一个人坐不到，概率贡献 1/i * 0
            # 坐座位 k (2 <= k <= i-1)：等价于子问题，概率贡献 1/i * 0.5
            
            dp[i] = 1.0 / i + (i - 2) / i * 0.5
            # 简化后 dp[i] = 0.5
        
        return dp[n]
```

## 关键点总结

1. 这是一道脑筋急转弯类型的题目，答案非常简洁
2. 关键观察：问题具有对称性，座位 1 和座位 n 的地位是对称的
3. 可以用数学归纳法严格证明
4. 实际编码非常简单：n=1 返回 1.0，否则返回 0.5
