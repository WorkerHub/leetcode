## 题目描述

给定一个平衡括号字符串 s，按下述规则计算该字符串的分数：

- `()` 得 1 分。
- `AB` 得 `A + B` 分，其中 A 和 B 是平衡括号字符串。
- `(A)` 得 `2 * A` 分，其中 A 是平衡括号字符串。

**示例 1：**
```
输入：s = "()"
输出：1
```

**示例 2：**
```
输入：s = "(())"
输出：2
```

**示例 3：**
```
输入：s = "()()"
输出：2
```

**示例 4：**
```
输入：s = "(()(()))"
输出：6
解释：
( () (()) )
= ( 1 + 2 )
= ( 3 )
= 6
```

**提示：**
- 2 <= s.length <= 50
- s 由且仅由 '(' 和 ')' 组成
- s 是一个平衡括号字符串

## 解题思路

这道题有多种解法，核心是理解括号的嵌套结构和得分规则。

**核心观察：**
1. `()` 基础分数是 1
2. 每增加一层嵌套，分数翻倍
3. 并列的括号对分数相加

**关键发现：**
- 只有 `()` 贡献基础分数 1
- 外层每多一个括号，分数 × 2
- 可以用深度来计算：`()` 在深度 d 时贡献 2^(d-1) 分

**三种解法思路：**

1. **栈模拟**：按规则模拟计算过程
2. **深度计算**：遇到 `()` 时，根据深度计算贡献
3. **分治递归**：递归计算子问题

## Python 代码实现

### 方法一：栈模拟（推荐）⭐

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack = [0]  # 栈底存储当前层的分数
        
        for char in s:
            if char == '(':
                # 遇到左括号，进入新的一层
                stack.append(0)
            else:
                # 遇到右括号，计算当前层的分数
                curr = stack.pop()
                # () 得 1 分，(A) 得 2*A 分
                score = max(2 * curr, 1)
                # 加到上一层
                stack[-1] += score
        
        return stack[0]
```

**代码说明：**
- 栈存储每一层的分数累加和
- `(` 入栈一个新层（0）
- `)` 计算当前层分数并加到上一层
- `max(2 * curr, 1)` 处理 `()` 和 `(A)` 两种情况

### 方法二：深度计算（最优解）⭐⭐

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        result = 0
        depth = 0  # 当前深度
        
        for i, char in enumerate(s):
            if char == '(':
                depth += 1
            else:
                depth -= 1
                # 如果是 ()，贡献 2^depth 分
                if s[i - 1] == '(':
                    result += 2 ** depth
        
        return result
```

**代码说明：**
- 只有 `()` 贡献分数
- 深度为 d 时，`()` 贡献 2^d 分
- 时间复杂度 O(n)，空间复杂度 O(1)

### 方法三：位运算优化深度

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        result = 0
        depth = 0
        
        for i, char in enumerate(s):
            if char == '(':
                depth += 1
            else:
                depth -= 1
                if s[i - 1] == '(':
                    result += 1 << depth  # 2^depth 用位运算
        
        return result
```

**代码说明：**
- `1 << depth` 等价于 `2 ** depth`
- 位运算更快

### 方法四：分治递归

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        def helper(left: int, right: int) -> int:
            """计算 s[left:right] 的分数"""
            if right - left == 2:  # ()
                return 1
            
            # 找到第一个完整的括号对
            balance = 0
            for i in range(left, right):
                balance += 1 if s[i] == '(' else -1
                if balance == 0:
                    # 找到第一个完整的部分
                    if i == right - 1:
                        # 整个是 (A) 形式
                        return 2 * helper(left + 1, right - 1)
                    else:
                        # AB 形式
                        return helper(left, i + 1) + helper(i + 1, right)
            
            return 0
        
        return helper(0, len(s))
```

**代码说明：**
- 递归处理子问题
- 区分 `(A)` 和 `AB` 两种情况

### 方法五：栈存储字符串

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack = []
        
        for char in s:
            if char == '(':
                stack.append(char)
            else:
                # 计算当前括号对的分数
                if stack[-1] == '(':
                    stack.pop()
                    stack.append(1)
                else:
                    # 累加同层的分数
                    curr = 0
                    while stack and stack[-1] != '(':
                        curr += stack.pop()
                    stack.pop()  # 弹出 '('
                    stack.append(2 * curr)
        
        return sum(stack)
```

## 复杂度分析

### 方法一：栈模拟
- **时间复杂度**：O(n)，遍历一次字符串。
- **空间复杂度**：O(n)，栈的空间。

### 方法二、三：深度计算
- **时间复杂度**：O(n)。
- **空间复杂度**：O(1)，最优解。

### 方法四：分治递归
- **时间复杂度**：O(n²)，最坏情况。
- **空间复杂度**：O(n)，递归栈。

## 关键点总结

1. **深度理解**：只有 `()` 贡献基础分数，深度决定倍数
2. **栈的应用**：用栈模拟括号匹配和分数计算
3. **数学规律**：深度 d 的 `()` 贡献 2^d 分
4. **空间优化**：方法二只用 O(1) 空间
5. **位运算**：`1 << depth` 代替 `2 ** depth`

## 易错点

1. **栈初始化**：`stack = [0]` 而不是 `stack = []`
   - 需要一个底层元素存储总分

2. **分数计算**：`max(2 * curr, 1)` 而不是简单的 `2 * curr`
   - `()` 是特殊情况，分数是 1

3. **深度判断**：只有遇到 `()` 时才计算分数
   ```python
   # ✅ 正确：检查前一个字符
   if s[i - 1] == '(':
       result += 2 ** depth
   
   # ❌ 错误：所有 ')' 都计算
   result += 2 ** depth
   ```

4. **深度变化时机**：
   - `(` 后 depth += 1
   - `)` 前计算，再 depth -= 1
