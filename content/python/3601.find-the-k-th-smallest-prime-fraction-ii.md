## 题目描述

给你一个按递增顺序排列的整数数组 `arr`，其中 `arr[i]` 为质数。对于每对满足 `0 <= i < j < arr.length` 的下标，可以得到分数 `arr[i] / arr[j]`。

返回第 `k` 个最小的分数，结果以大小为 2 的整数数组形式给出，`answer[0] == arr[i]` 且 `answer[1] == arr[j]`。

**示例 1：**

```
输入：arr = [1,2,3,5], k = 3
输出：[2,5]
解释：按递增顺序排列的分数：1/5, 1/3, 2/5, 1/2, 3/5, 2/3
所以第 3 个最小分数是 2/5
```

**示例 2：**

```
输入：arr = [1,7,23,29,47], k = 20
输出：[47,29]
```

**提示：**

- `2 <= arr.length <= 1000`
- `1 <= arr[i] <= 3 * 10^4`
- `arr[i]` 是质数
- `arr` 严格递增
- `1 <= k <= arr.length * (arr.length - 1) / 2`

## 解题思路

使用二分查找，对分数值进行二分。对于给定的中间值 `mid`，统计数组中有多少对 `(i, j)` 使得 `arr[i] / arr[j] <= mid`。利用双指针可以在 O(n) 时间内完成统计。

当统计数量恰好等于 `k` 时，记录下最大的满足条件的分数即为答案。

## Python 代码实现

### 方法一：二分查找 + 双指针（推荐）

```python
from typing import List

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        left, right = 0.0, 1.0

        while True:
            mid = (left + right) / 2
            # 统计 arr[i]/arr[j] <= mid 的对数
            count = 0
            max_frac = (0, 1)  # 记录最大分数的分子分母
            j = 0
            for i in range(n):
                # 找到最小的 j 使得 arr[i]/arr[j] <= mid
                while j < n and arr[i] > mid * arr[j]:
                    j += 1
                count += n - j
                # 更新最大分数
                if j < n and arr[i] * max_frac[1] > max_frac[0] * arr[j]:
                    max_frac = (arr[i], arr[j])

            if count == k:
                return list(max_frac)
            elif count < k:
                left = mid
            else:
                right = mid
```

### 方法二：最小堆

```python
from typing import List
import heapq

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        # 堆中存储 (分数值, 分子下标, 分母下标)
        heap = [(arr[0] / arr[j], 0, j) for j in range(1, n)]
        heapq.heapify(heap)

        for _ in range(k - 1):
            val, i, j = heapq.heappop(heap)
            # 分子下标后移
            if i + 1 < j:
                heapq.heappush(heap, (arr[i + 1] / arr[j], i + 1, j))

        _, i, j = heapq.heappop(heap)
        return [arr[i], arr[j]]
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))，二分查找约 50 次，每次 O(n)
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 对分数值进行二分而非对下标二分
2. 双指针统计不超过 mid 的分数对数
3. 同时记录最接近 mid 的最大分数作为候选答案
4. 浮点二分收敛条件：统计数恰好等于 k

## 易错点

1. 双指针方向：外层遍历分子，内层找分母的最小合法位置
2. 最大分数更新时需用乘法比较避免浮点误差
3. 二分终止条件不是 `left < right - eps`，而是 `count == k`
