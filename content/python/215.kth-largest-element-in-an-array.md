## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**

```
输入：[3,2,1,5,6,4], k = 2
输出：5
```

**示例 2：**

```
输入：[3,2,3,1,2,4,5,5,6], k = 4
输出：4
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

这是经典的 "TopK" 问题，有多种解法，各有优劣。

**核心思想：**

1. **排序法**：直接排序后取第 k 大元素（简单但不是最优）
2. **堆排序**：使用小顶堆维护 k 个最大元素
3. **快速选择**：基于快速排序的分治思想（最优解）
4. **Python 内置函数**：`heapq.nlargest()`

**快速选择算法（Quick Select）：**

- 类似快速排序，但只需递归一侧
- 每次选择一个 pivot，将数组分为三部分：`< pivot`、`= pivot`、`> pivot`
- 根据 pivot 位置决定在哪一侧继续查找
- 平均时间复杂度 O(N)，最坏 O(N²)

**算法流程（快速选择）：**

1. 随机选择 pivot（降低最坏情况概率）
2. 分区：将数组分为三部分
3. 判断第 k 大元素在哪个部分：
   - 如果在右侧（大于 pivot），递归右侧
   - 如果等于 pivot，直接返回
   - 如果在左侧（小于 pivot），递归左侧

## Python 代码实现

### 方法一：快速选择（推荐）⭐

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """快速选择算法"""
        import random
        
        def quick_select(left: int, right: int) -> int:
            # 随机选择 pivot（避免最坏情况）
            pivot_index = random.randint(left, right)
            pivot = nums[pivot_index]
            
            # 三路划分：小于、等于、大于 pivot
            less, equal, greater = [], [], []
            for i in range(left, right + 1):
                if nums[i] < pivot:
                    less.append(nums[i])
                elif nums[i] == pivot:
                    equal.append(nums[i])
                else:
                    greater.append(nums[i])
            
            # 判断第 k 大在哪个部分
            if k <= len(greater):
                # 在大于 pivot 的部分
                nums[left:right+1] = greater + equal + less
                return quick_select(left, left + len(greater) - 1)
            elif k <= len(greater) + len(equal):
                # 就是 pivot
                return pivot
            else:
                # 在小于 pivot 的部分
                nums[left:right+1] = greater + equal + less
                return quick_select(right - len(less) + 1, right)
        
        return quick_select(0, len(nums) - 1)
```

### 方法二：快速选择（原地分区版）

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """原地分区，更节省空间"""
        import random
        
        def partition(left: int, right: int) -> int:
            # 随机选择 pivot 并移到末尾
            pivot_index = random.randint(left, right)
            nums[pivot_index], nums[right] = nums[right], nums[pivot_index]
            pivot = nums[right]
            
            # 双指针分区
            i = left
            for j in range(left, right):
                if nums[j] > pivot:  # 注意：大于 pivot 的放左边
                    nums[i], nums[j] = nums[j], nums[i]
                    i += 1
            
            # 将 pivot 放到正确位置
            nums[i], nums[right] = nums[right], nums[i]
            return i
        
        def quick_select(left: int, right: int, k: int) -> int:
            if left == right:
                return nums[left]
            
            # 分区
            pivot_index = partition(left, right)
            
            # 判断第 k 大在哪里（从大到小排序）
            if k == pivot_index + 1:
                return nums[pivot_index]
            elif k < pivot_index + 1:
                return quick_select(left, pivot_index - 1, k)
            else:
                return quick_select(pivot_index + 1, right, k)
        
        return quick_select(0, len(nums) - 1, k)
```

### 方法三：小顶堆（稳定高效）

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """使用小顶堆维护 k 个最大元素"""
        import heapq
        
        # 构建大小为 k 的小顶堆
        heap = nums[:k]
        heapq.heapify(heap)
        
        # 遍历剩余元素
        for num in nums[k:]:
            if num > heap[0]:  # 如果比堆顶大
                heapq.heapreplace(heap, num)  # 替换堆顶
        
        return heap[0]  # 堆顶就是第 k 大
```

### 方法四：Python 内置函数（最简洁）

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """使用 heapq.nlargest()"""
        import heapq
        return heapq.nlargest(k, nums)[-1]
```

### 方法五：排序法（基准解法）

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """直接排序"""
        nums.sort(reverse=True)
        return nums[k - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 快速选择（原地） | 平均 O(N)，最坏 O(N²) | O(log N) | 递归栈空间 |
| 快速选择（三路） | 平均 O(N)，最坏 O(N²) | O(N) | 额外数组 |
| 小顶堆 | O(N log K) | O(K) | 稳定性能 |
| 排序 | O(N log N) | O(log N) | 简单但不最优 |
| heapq.nlargest | O(N log K) | O(K) | 内部使用堆 |

**最优解：** 快速选择（原地分区版）

## 关键点总结

1. **快速选择精髓**：每次只需递归一侧，平均 O(N)
2. **随机 pivot**：降低最坏情况概率，提高稳定性
3. **第 k 大 vs 第 k 小**：注意分区时的比较方向
4. **堆的选择**：第 k 大用小顶堆，第 k 小用大顶堆
5. **权衡**：快速选择最快但不稳定，堆稳定但慢一些

## 易错点

1. **第 k 大的索引**：
   ```python
   # 错误：排序后索引为 k
   nums.sort()
   return nums[k]
   # 正确：索引为 k-1
   nums.sort(reverse=True)
   return nums[k - 1]
   ```

2. **分区方向错误**：
   ```python
   # 找第 k 大：大于 pivot 的放左边
   if nums[j] > pivot:
       nums[i], nums[j] = nums[j], nums[i]
   # 找第 k 小：小于 pivot 的放左边
   if nums[j] < pivot:
       nums[i], nums[j] = nums[j], nums[i]
   ```

3. **堆的类型搞反**：
   ```python
   # 错误：第 k 大用大顶堆
   heap = [-num for num in nums[:k]]  # 错误
   # 正确：第 k 大用小顶堆
   heap = nums[:k]
   heapq.heapify(heap)
   ```

4. **快速选择的递归条件**：
   ```python
   # 注意：pivot_index 是绝对位置，k 是相对位置
   if k == pivot_index + 1:  # 从 1 开始计数
       return nums[pivot_index]
   ```

5. **随机化忘记导入**：
   ```python
   import random
   pivot_index = random.randint(left, right)
   ```
