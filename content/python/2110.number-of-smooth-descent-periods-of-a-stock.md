## 题目描述

给你一个整数数组 `prices`，表示一支股票的每日价格。

一个**平滑下降时段**是一个连续日期子数组，该子数组中每天的价格恰好比**前一天**价格少 **1**（长度为 1 的子数组也属于平滑下降时段）。

返回 `prices` 中**平滑下降时段**的数目。

**示例 1：**
```
输入：prices = [3,2,1,4]
输出：7
解释：
共有 6 个长度大于 1 的子数组，加上 4 个长度为 1 的子数组（每个元素本身），
但只有以下是平滑下降时段：
[3], [2], [1], [4], [3,2], [2,1], [3,2,1] → 共 7 个
```

**示例 2：**
```
输入：prices = [8,6,7,7]
输出：4
解释：[8], [6], [7], [7] 各自为平滑下降时段，共 4 个。
```

**提示：**
- `1 <= prices.length <= 10^5`
- `1 <= prices[i] <= 10^5`

## 解题思路

**动态规划**

设 `dp[i]` 为以 `prices[i]` 结尾的平滑下降时段数量。

- 若 `prices[i] == prices[i-1] - 1`：以 `prices[i]` 结尾的时段 = 以 `prices[i-1]` 结尾的时段 + 本身，即 `dp[i] = dp[i-1] + 1`。
- 否则：只有 `prices[i]` 本身，`dp[i] = 1`。

总答案 = 所有 `dp[i]` 之和。

**数学等价说明：** 一段连续的平滑下降序列长度为 L，其中包含 `L*(L+1)/2` 个平滑下降时段（与等差数列求和相同）。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def getDescentPeriods(self, prices: List[int]) -> int:
        n = len(prices)
        ans = 0
        dp = 1  # 以当前元素结尾的平滑下降时段数
        ans = 1  # 第一个元素本身

        for i in range(1, n):
            if prices[i] == prices[i - 1] - 1:
                # 价格恰好少 1，可以延伸前一段
                dp += 1
            else:
                # 断开，重新开始
                dp = 1
            ans += dp

        return ans
```

### 方法二：分段计算（按连续递减段）

```python
from typing import List

class Solution:
    def getDescentPeriods(self, prices: List[int]) -> int:
        n = len(prices)
        ans = 0
        length = 1  # 当前连续递减段的长度

        for i in range(1, n):
            if prices[i] == prices[i - 1] - 1:
                length += 1
            else:
                # 当前段结束，贡献 length*(length+1)//2 个时段
                ans += length * (length + 1) // 2
                length = 1

        # 最后一段
        ans += length * (length + 1) // 2
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n) | O(1) |
| 分段计算 | O(n) | O(1) |

## 关键点总结

1. `dp[i]` 表示以 `i` 结尾的平滑下降时段数，满足递推 `dp[i] = dp[i-1]+1` 或 `1`。
2. 连续递减段长度 L 对应 `L*(L+1)/2` 个时段（等差数列）。
3. 两种方法等价，动态规划版本每步累加，分段版本遇到断点才结算。

## 易错点

- 条件是**恰好少 1**（`prices[i] == prices[i-1] - 1`），不是小于或递减即可。
- 最后一段在循环结束后需要单独处理（分段计算方法）。
