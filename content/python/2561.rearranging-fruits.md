## 题目描述

给你两个非空整数数组 `basket1` 和 `basket2`，每个篮子里都有若干水果。两个篮子大小相同。

你可以执行若干次操作：每次操作，你交换两个篮子之间的一个水果。

返回使两个篮子中 **相同** 水果数目相等的最小操作次数，若无法实现则返回 `-1`。

每次操作的代价是交换的两个水果中 **较小** 值。

返回最小总代价。

**示例 1：**

```
输入：basket1 = [4,2,2,2], basket2 = [1,4,1,2]
输出：1
解释：交换 basket1[0]=4 和 basket2[0]=1，代价 1，两篮子各有 [4,2,2,2] 和 [1,4,1,2] 变为相等。
```

**提示：**

- `basket1.length == basket2.length == n`
- `1 <= n <= 10^5`
- `1 <= basket1[i], basket2[i] <= 10^9`

## 解题思路

统计两个篮子中每个水果的差值（basket1 多出的 - basket2 多出的）。若每种水果总数为奇数，则无法平衡，返回 -1。

需要交换的水果：basket1 中多出的 >= 2 的每种水果，需要移到 basket2，反之亦然。

贪心：将需要交换的水果排序，直接两两配对（basket1 多的最小 vs basket2 多的最小），代价取两个水果中的较小值。

若中间水果（两个篮子中都有的最小值）更小，可以用它做"中转"（代价 = 最小水果值 * 2），取直接交换和中转两者的最小值。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minCost(self, basket1: List[int], basket2: List[int]) -> int:
        cnt = Counter(basket1)
        for x in basket2:
            cnt[x] -= 1

        # 检查每种水果总数是否为偶数
        to_move = []
        for fruit, diff in cnt.items():
            if diff % 2 != 0:
                return -1
            # basket1 多出 diff//2 个 fruit 需要移到 basket2
            to_move.extend([fruit] * (abs(diff) // 2))

        # 排序：小的先处理
        to_move.sort()
        min_all = min(min(basket1), min(basket2))  # 全局最小值（用于中转）

        total_cost = 0
        m = len(to_move) // 2
        for i in range(m):
            # 直接交换：to_move[i]（basket1多的）和 to_move[-(i+1)]（basket2多的）
            # 代价 = min(to_move[i], to_move[-(i+1)])
            direct = min(to_move[i], to_move[-(i+1)])
            # 中转：用全局最小值中转，代价 = 2 * min_all
            relay = 2 * min_all
            total_cost += min(direct, relay)

        return total_cost
```

### 方法二：分别统计 basket1 多出和 basket2 多出的水果

```python
from typing import List
from collections import Counter

class Solution:
    def minCost(self, basket1: List[int], basket2: List[int]) -> int:
        cnt1, cnt2 = Counter(basket1), Counter(basket2)
        all_fruits = set(cnt1) | set(cnt2)

        extra1, extra2 = [], []
        for f in all_fruits:
            diff = cnt1[f] - cnt2[f]
            if diff % 2 != 0:
                return -1
            if diff > 0:
                extra1.extend([f] * (diff // 2))
            elif diff < 0:
                extra2.extend([f] * ((-diff) // 2))

        extra1.sort()
        extra2.sort()
        min_all = min(basket1 + basket2)
        cost = 0

        for a, b in zip(extra1, extra2):
            cost += min(min(a, b), 2 * min_all)

        return cost
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，extra 列表

## 关键点总结

1. 若某水果总数为奇数，无法平衡，返回 -1
2. 贪心：将 basket1 多出的和 basket2 多出的水果分别排序，配对交换
3. 中转策略：用全局最小值做中转，代价 2 * min_val，可能比直接交换更便宜

## 易错点

1. 配对时，basket1 多出的最小水果应与 basket2 多出的最大水果配对（贪心最优）
2. 或者：不分 basket1/basket2，将所有需要移动的水果排序，每次取两头配对
3. 每次操作代价是两个水果中的"较小值"
