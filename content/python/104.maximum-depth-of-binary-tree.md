## 题目描述

给定一个二叉树 `root`，返回其最大深度。

二叉树的**最大深度**是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**
```
    3
   / \
  9  20
    /  \
   15   7
```
输入：root = [3,9,20,null,null,15,7]
输出：3

**示例 2：**
输入：root = [1,null,2]
输出：2

**提示：**
- 树中节点的数量在 [0, 10⁴] 范围内
- -100 <= Node.val <= 100

## 解题思路

求二叉树的最大深度，可以用**递归**或**迭代**两种方法。

**递归思路：**
- 树的深度 = max(左子树深度, 右子树深度) + 1
- 空树深度为 0

**迭代思路：**
- 使用 BFS 层序遍历，统计层数
- 使用 DFS 栈遍历，记录每个节点的深度

## Python 代码实现

### 方法一：递归 DFS（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        """递归求最大深度"""
        # 空树深度为 0
        if not root:
            return 0
        
        # 树的深度 = max(左子树深度, 右子树深度) + 1
        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)
        
        return max(left_depth, right_depth) + 1
```

**简化版：**
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        """递归求最大深度 - 一行版"""
        return 0 if not root else max(self.maxDepth(root.left), self.maxDepth(root.right)) + 1
```

### 方法二：BFS 层序遍历

```python
from typing import Optional
from collections import deque

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        """BFS 层序遍历统计层数"""
        if not root:
            return 0
        
        queue = deque([root])
        depth = 0
        
        while queue:
            depth += 1
            level_size = len(queue)
            
            for _ in range(level_size):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return depth
```

### 方法三：DFS 栈（迭代）

```python
from typing import Optional

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        """DFS 栈迭代 - 记录每个节点的深度"""
        if not root:
            return 0
        
        stack = [(root, 1)]  # (节点, 深度)
        max_depth = 0
        
        while stack:
            node, depth = stack.pop()
            max_depth = max(max_depth, depth)
            
            if node.left:
                stack.append((node.left, depth + 1))
            if node.right:
                stack.append((node.right, depth + 1))
        
        return max_depth
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是树中节点总数，每个节点访问一次
- 空间复杂度：
  - 递归：O(h)，h 为树的高度，递归调用栈。最坏 O(n)（链状树），最好 O(log n)（平衡树）
  - BFS：O(w)，w 为树的最大宽度，队列中最多存储一层节点
  - DFS 栈：O(h)，栈的最大深度等于树的高度

## 关键点总结

1. **递归公式**：depth(root) = max(depth(left), depth(right)) + 1
2. **边界条件**：空树深度为 0
3. **方法选择**：
   - 递归：代码简洁，适合面试
   - BFS：清晰直观，易于理解
   - DFS 栈：练习栈的使用
4. **深度 vs 高度**：
   - 深度：从根到当前节点的距离
   - 高度：从当前节点到叶子节点的最大距离
   - 树的最大深度 = 树的高度

## 易错点

1. **空树处理**：空树深度是 0，不是 -1
2. **叶子节点**：叶子节点深度是 1，不是 0
3. **递归终止**：要在节点为空时返回 0，而不是在叶子节点返回
