## 题目描述

此题为 LeetCode Premium 题目。

给定一个成绩列表 `items`，其中 `items[i] = [IDi, scorei]` 表示学生 `IDi` 的一次考试成绩为 `scorei`。

计算每个学生的**前五名**平均成绩。

返回结果数组 `answer`，其中 `answer[j] = [IDj, topFiveAveragej]` 表示学生 `IDj` 的前五名平均成绩。结果按学生 ID **升序**排列。

一个学生的前五名平均成绩是该学生成绩最高的五个分数的平均值（使用**整数除法**）。

**示例 1：**
```
输入：items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
输出：[[1,87],[2,88]]
解释：
学生 1 的成绩：91, 92, 60, 65, 87, 100
前五名：100, 92, 91, 87, 65，平均值 = (100+92+91+87+65) / 5 = 87

学生 2 的成绩：93, 97, 77, 100, 76
前五名：100, 97, 93, 77, 76，平均值 = (100+97+93+77+76) / 5 = 88.6 → 88（整数除法）
```

**提示：**
- `1 <= items.length <= 1000`
- `items[i].length == 2`
- `1 <= IDi <= 1000`
- `0 <= scorei <= 100`
- 每个学生至少有 5 个分数

## 解题思路

这是一道**分组 + 排序 + Top K**问题。

### 核心思路

1. **按学生ID分组**：将所有成绩按学生 ID 分组
2. **排序取前五**：对每个学生的成绩降序排序，取前 5 个
3. **计算平均值**：求和除以 5（整数除法）
4. **按ID排序**：结果按学生 ID 升序排列

## Python 代码实现

### 方法一：哈希表 + 排序（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        # 按学生 ID 分组存储成绩
        scores = defaultdict(list)
        
        for student_id, score in items:
            scores[student_id].append(score)
        
        # 计算每个学生的前五名平均成绩
        result = []
        for student_id in sorted(scores.keys()):
            # 降序排序，取前 5 个
            top_five = sorted(scores[student_id], reverse=True)[:5]
            # 计算平均值（整数除法）
            average = sum(top_five) // 5
            result.append([student_id, average])
        
        return result
```

### 方法二：使用 heapq.nlargest

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        scores = defaultdict(list)
        
        for student_id, score in items:
            scores[student_id].append(score)
        
        result = []
        for student_id in sorted(scores.keys()):
            # 使用堆找出最大的 5 个元素
            top_five = heapq.nlargest(5, scores[student_id])
            average = sum(top_five) // 5
            result.append([student_id, average])
        
        return result
```

### 方法三：维护固定大小的最小堆

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        scores = defaultdict(list)
        
        # 边读边维护每个学生的 top 5
        for student_id, score in items:
            heap = scores[student_id]
            heapq.heappush(heap, score)
            # 保持堆大小为 5，只保留最大的 5 个
            if len(heap) > 5:
                heapq.heappop(heap)
        
        result = []
        for student_id in sorted(scores.keys()):
            average = sum(scores[student_id]) // 5
            result.append([student_id, average])
        
        return result
```

### 方法四：列表推导式（简洁版）

```python
from typing import List
from collections import defaultdict

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        scores = defaultdict(list)
        for sid, score in items:
            scores[sid].append(score)
        
        return [
            [sid, sum(sorted(scores[sid], reverse=True)[:5]) // 5]
            for sid in sorted(scores.keys())
        ]
```

## 复杂度分析

**方法一、四：**
- **时间复杂度**：O(n log n + k log k)
  - 遍历items：O(n)
  - 对每个学生排序：O(m log m)，m 是该学生的成绩数
  - 总排序：O(n log n)
  - 结果排序：O(k log k)，k 是学生数
- **空间复杂度**：O(n)

**方法二（heapq.nlargest）：**
- **时间复杂度**：O(n log 5) = O(n)
  - nlargest 的时间复杂度为 O(n log k)，k=5
- **空间复杂度**：O(n)

**方法三（维护最小堆）：**
- **时间复杂度**：O(n log 5) = O(n)
- **空间复杂度**：O(k)，k 是学生数，每个学生最多存 5 个成绩

## 关键点总结

1. **分组统计**：使用 defaultdict(list) 按 ID 分组
2. **Top K 问题**：可以用排序、堆等多种方法
3. **整数除法**：Python 中使用 `//` 而不是 `/`
4. **结果排序**：`sorted(scores.keys())` 按 ID 排序
5. **heapq 优化**：对于 Top K，堆比完全排序更高效

## 易错点

1. **浮点除法**：使用 `/` 而不是 `//`，导致结果是浮点数
2. **排序方向**：忘记 `reverse=True`，导致取到最小的 5 个
3. **未排序输出**：忘记按学生 ID 排序结果
4. **堆的理解**：Python 的 heapq 是最小堆，要取最大的需要用 nlargest
5. **边界情况**：题目保证至少 5 个成绩，无需额外处理
