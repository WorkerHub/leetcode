## 题目描述

我们从二叉树的根节点 `root` 开始进行深度优先搜索（DFS）。

在遍历中的每个节点处，我们输出 `D` 条短划线（其中 `D` 是该节点的深度），然后输出该节点的值。

如果节点的深度为 `D`，则其直接子节点的深度为 `D + 1`。根节点的深度为 `0`。

如果节点只有一个子节点，那么保证该子节点为左子节点。

给定遍历输出 `S`，恢复树并返回其根节点 `root`。

**示例 1：**

```
输入: S = "1-2--3--4-5--6--7"
输出: [1,2,5,3,4,6,7]
解释:
        1
       / \
      2   5
     / \ / \
    3  4 6  7
```

**示例 2：**

```
输入: S = "1-2--3---4-5--6---7"
输出: [1,2,5,3,null,6,null,4,null,7]
解释:
          1
         / \
        2   5
       /   /
      3   6
     /   /
    4   7
```

**示例 3：**

```
输入: S = "1-401--349---90--88"
输出: [1,401,null,349,88,90]
解释:
        1
         \
        401
        / \
      349 88
      /
     90
```

**提示：**

- 原始树中的节点数在范围 `[1, 1000]` 内
- `1 <= Node.val <= 10^9`

## 解题思路

这道题的核心是理解前序遍历的深度编码规则，然后通过解析字符串重建二叉树。

**关键观察：**

1. **深度信息**：短划线 `-` 的数量代表节点的深度（根节点深度为 0）
2. **前序遍历性质**：先访问根节点，再访问左子树，最后访问右子树
3. **子节点判断**：深度为 `D+1` 的节点是深度为 `D` 的节点的子节点
4. **左右子节点区分**：
   - 第一个深度为 `D+1` 的节点是左子节点
   - 第二个深度为 `D+1` 的节点是右子节点

**解题步骤：**

1. 遍历字符串，解析出每个节点的深度和值
2. 使用栈来维护当前路径上的节点
3. 根据深度关系，确定父子关系和左右子节点关系
4. 构建二叉树并返回根节点

**算法流程（栈方法）：**

1. 初始化栈，用于存储 `(节点, 深度)` 对
2. 遍历字符串：
   - 统计连续的 `-` 数量得到深度
   - 解析数字得到节点值
   - 创建新节点
   - 调整栈：弹出所有深度 >= 当前深度的节点
   - 栈顶节点就是当前节点的父节点
   - 如果父节点没有左子节点，设为左子节点；否则设为右子节点
   - 将当前节点入栈

## Python 代码实现

### 方法一：迭代 + 栈（推荐）

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def recoverFromPreorder(self, traversal: str) -> Optional[TreeNode]:
        # 栈存储 (节点, 深度) 对
        stack = []
        i = 0
        
        while i < len(traversal):
            # 统计短划线数量，得到当前节点深度
            depth = 0
            while i < len(traversal) and traversal[i] == '-':
                depth += 1
                i += 1
            
            # 解析节点值
            val = 0
            while i < len(traversal) and traversal[i].isdigit():
                val = val * 10 + int(traversal[i])
                i += 1
            
            # 创建新节点
            node = TreeNode(val)
            
            # 调整栈：弹出所有深度 >= 当前深度的节点
            # 保证栈顶节点深度为 depth - 1（即当前节点的父节点）
            while len(stack) > depth:
                stack.pop()
            
            # 如果栈不为空，建立父子关系
            if stack:
                parent = stack[-1]
                # 如果父节点没有左子节点，设为左子节点
                if parent.left is None:
                    parent.left = node
                # 否则设为右子节点
                else:
                    parent.right = node
            
            # 将当前节点入栈
            stack.append(node)
        
        # 栈底元素就是根节点
        return stack[0]
```

### 方法二：递归解析

```python
from typing import Optional

class Solution:
    def recoverFromPreorder(self, traversal: str) -> Optional[TreeNode]:
        self.index = 0  # 当前解析位置
        
        def parseNode(depth: int) -> Optional[TreeNode]:
            # 统计当前位置的短划线数量
            dash_count = 0
            while self.index + dash_count < len(traversal) and traversal[self.index + dash_count] == '-':
                dash_count += 1
            
            # 如果深度不匹配，说明当前深度没有节点
            if dash_count != depth:
                return None
            
            # 跳过短划线
            self.index += dash_count
            
            # 解析节点值
            val = 0
            while self.index < len(traversal) and traversal[self.index].isdigit():
                val = val * 10 + int(traversal[self.index])
                self.index += 1
            
            # 创建节点
            node = TreeNode(val)
            
            # 递归构建左右子树
            node.left = parseNode(depth + 1)
            node.right = parseNode(depth + 1)
            
            return node
        
        return parseNode(0)
```

### 方法三：正则表达式解析

```python
import re
from typing import Optional

class Solution:
    def recoverFromPreorder(self, traversal: str) -> Optional[TreeNode]:
        # 使用正则表达式提取所有 (深度, 值) 对
        # 模式: 连续的短划线后跟数字
        pattern = r'(-*)(\d+)'
        matches = re.findall(pattern, traversal)
        
        # 转换为 (深度, 值) 列表
        nodes = [(len(dashes), int(val)) for dashes, val in matches]
        
        # 使用栈构建树
        stack = []
        
        for depth, val in nodes:
            node = TreeNode(val)
            
            # 调整栈深度
            while len(stack) > depth:
                stack.pop()
            
            # 建立父子关系
            if stack:
                parent = stack[-1]
                if parent.left is None:
                    parent.left = node
                else:
                    parent.right = node
            
            stack.append(node)
        
        return stack[0]
```

## 复杂度分析

**方法一：迭代 + 栈**

- **时间复杂度**：O(n)，其中 n 是字符串的长度。我们只需要遍历一次字符串。
- **空间复杂度**：O(h)，其中 h 是树的高度。栈中最多存储树的一条路径上的所有节点，最坏情况下为 O(n)（链式树）。

**方法二：递归解析**

- **时间复杂度**：O(n)，每个字符最多被访问一次。
- **空间复杂度**：O(h)，递归调用栈的深度等于树的高度。

**方法三：正则表达式**

- **时间复杂度**：O(n)，正则匹配和后续处理都是线性时间。
- **空间复杂度**：O(n)，需要存储所有匹配结果。

## 关键点总结

1. **深度信息编码**：短划线数量表示节点深度，这是解析的关键
2. **栈的使用**：栈维护从根到当前节点的路径，通过深度控制栈的大小
3. **父子关系判断**：栈顶元素是当前节点的父节点（深度恰好小1）
4. **左右子节点区分**：通过判断父节点的 `left` 是否为空来决定
5. **字符串解析技巧**：需要同时处理短划线计数和数字解析

## 易错点

1. **多位数处理**：节点值可能是多位数（如 401），需要正确解析
2. **深度控制**：弹出栈元素时的条件是 `len(stack) > depth`，而不是 `>=`
3. **根节点特殊处理**：根节点深度为 0，没有短划线前缀
4. **左右子节点判断**：必须先检查左子节点是否存在，再决定是否设置右子节点
5. **字符串边界**：解析时要注意索引不要越界
