## 题目描述

一个房间里有 `n` 个座位和 `n` 个学生，由数组 `seats` 和 `students` 分别给出它们的位置。

每次移动，可以将一名学生的位置增加或减少 1。

返回将所有学生安排到座位上所需的**最少移动次数**（每个座位分配一个学生）。

**示例 1：**
```
输入：seats = [3,1,5], students = [2,7,4]
输出：4
解释：排序后 seats=[1,3,5], students=[2,4,7]，移动距离 |1-2|+|3-4|+|5-7|=1+1+2=4
```

**示例 2：**
```
输入：seats = [4,1,5,9], students = [1,3,2,6]
输出：7
```

**提示：**
- `n == seats.length == students.length`
- `1 <= n <= 100`
- `1 <= seats[i], students[i] <= 100`

## 解题思路

**贪心结论：** 将 `seats` 和 `students` 分别排序后，第 `i` 个学生去第 `i` 个座位，总移动次数最少。

这是因为交叉分配会增加总移动距离（排列不等式定理）。

## 代码实现

### 方法一：排序后配对（推荐）

```python
from typing import List

class Solution:
    def minMovesToSeat(self, seats: List[int], students: List[int]) -> int:
        seats.sort()
        students.sort()
        # 对应位置的差之和即为最少移动次数
        return sum(abs(s - t) for s, t in zip(seats, students))
```

### 方法二：暴力枚举（理解贪心正确性）

```python
from typing import List
from itertools import permutations

class Solution:
    def minMovesToSeat(self, seats: List[int], students: List[int]) -> int:
        n = len(seats)
        min_moves = float('inf')

        # 枚举所有学生的分配方案（仅适用于小数据）
        for perm in permutations(range(n)):
            moves = sum(abs(seats[i] - students[perm[i]]) for i in range(n))
            min_moves = min(min_moves, moves)

        return min_moves
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序配对 | O(n log n) | O(1) |
| 暴力枚举 | O(n! * n) | O(n) |

## 关键点总结

1. 排序后按顺序配对，总移动距离最小（贪心最优）
2. 不同分配方案中，排序配对方案满足"不交叉"原则

## 易错点

- 排序后配对是充分条件，不需要枚举所有排列
- 移动距离是绝对值之和（不是平方和）
