## 题目描述

给你一个整数数组 `nums`，将 `nums` 划分为若干个非空子集，使每个子集的异或值相等。

返回满足条件的最大子集数量。如果无法划分则返回 0。

**示例 1：**

```
输入：nums = [1, 2, 3]
输出：3
解释：
- 总异或值 = 1 XOR 2 XOR 3 = 0
- 可以划分为 3 个子集：{1}, {2}, {3}，每个子集异或值分别为 1, 2, 3 ... 不等。
- 或划分为：{1,2,3}，XOR = 0，1 个子集。
- 若总 XOR = 0，理论上可划分多个子集。
```

**示例 2：**

```
输入：nums = [5, 5]
输出：2
解释：划分为 {5} 和 {5}，每个子集 XOR = 5，共 2 个子集。
```

**示例 3：**

```
输入：nums = [1, 2, 3, 4]
输出：4
```

**提示：**
- `1 <= nums.length <= 16`
- `1 <= nums[i] <= 1000`

## 解题思路

**关键观察：**
1. 若总异或值 `total_xor != 0`，则每个子集的 XOR 都等于 `total_xor`，最多划分为分数个子集，但需要通过状态压缩验证。
2. 若 `total_xor == 0`，则可以有更多的划分方式。

**状态压缩 DP 方法：**
- `dp[mask]` = 使用集合 `mask` 中的元素所能得到的最大子集划分数，其中每个子集的 XOR 值相等。
- 通过枚举 `mask` 的所有子集，检验子集的 XOR 是否符合条件。

**简化方法：**
- 枚举目标 XOR 值 `x`（`x` 可以是 0 到最大可能的 XOR）。
- 对每个 `x`，用 DP 计算能分成多少个 XOR 值为 `x` 的子集。
- 取最大值。

## Python 代码实现

### 方法一：状态压缩 DP + 枚举子集（推荐）

```python
from typing import List

class Solution:
    def maximumSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        for v in nums:
            total ^= v

        # 预计算每个子集的 XOR 值
        xor_val = [0] * (1 << n)
        for mask in range(1, 1 << n):
            # 利用最低位加速
            lsb = mask & (-mask)
            bit = lsb.bit_length() - 1
            xor_val[mask] = xor_val[mask ^ lsb] ^ nums[bit]

        # dp[mask] = 使用 mask 中元素恰好划分为若干 XOR 相等子集的最大子集数
        # 若 total == 0，目标 XOR 可以是 0；否则目标 XOR = total（固定）
        # 枚举目标 XOR 值
        max_xor = max(nums)
        best = 1  # 整个数组作为一个子集

        for target in range(0, (1 << 10) + 1):
            # dp[mask] = 将 mask 的元素分成若干 XOR=target 的子集的最大数量
            # -1 表示不可达
            dp = [-1] * (1 << n)
            dp[0] = 0  # 空集分 0 个子集

            for mask in range(1, 1 << n):
                # 枚举 mask 的所有非空子集 sub
                sub = mask
                while sub > 0:
                    prev = mask ^ sub
                    if dp[prev] >= 0 and xor_val[sub] == target:
                        dp[mask] = max(dp[mask], dp[prev] + 1)
                    sub = (sub - 1) & mask

            full = (1 << n) - 1
            if dp[full] > best:
                best = dp[full]

        return best
```

### 方法二：贪心 + XOR 线性基

```python
from typing import List

class Solution:
    def maximumSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        total_xor = 0
        for v in nums:
            total_xor ^= v

        # 若 total_xor != 0，最多能分成的子集数是有限的
        # 每个子集 XOR = total_xor，分 k 个子集要求 total_xor ^ total_xor ^ ... (k times) = total_xor
        # 即 k 个 total_xor 的 XOR = total_xor，所以 k 必须是奇数
        # 若 total_xor == 0，任意偶数 k 都满足（每两个 total_xor XOR = 0）

        # 线性基方法：找到数组的 XOR 线性基的秩 r
        # 可能的子集 XOR 值有 2^r 种，利用此推断最大分组数

        basis = []

        def insert(val):
            for b in basis:
                val = min(val, val ^ b)
            if val > 0:
                basis.append(val)
                return True
            return False

        for v in nums:
            insert(v)

        rank = len(basis)

        if total_xor != 0:
            # 每个子集的 XOR 都等于 total_xor，最多分 2^(rank-1) 个子集
            return 1 << (rank - 1)
        else:
            # total_xor == 0，最多分 2^rank 个子集（每个 XOR = 0）
            # 但需要至少 1 个子集，若 rank == 0（全为 0），特殊处理
            return 1 << rank if rank < n else 1 << rank
```

## 复杂度分析

- 方法一：时间复杂度 O(3^n)（子集枚举），空间复杂度 O(2^n)
- 方法二：时间复杂度 O(n * max_bit)，空间复杂度 O(max_bit)

## 关键点总结

1. 总 XOR = 0 时，子集可以分成 XOR 均为 0 的若干组；否则每组 XOR = 总 XOR。
2. XOR 线性基的秩 r 决定了可表示的 XOR 值个数（2^r 种）。
3. 状态压缩 DP 暴力枚举子集划分，适合 n <= 16 的小规模数据。
4. 子集枚举 `sub = (sub - 1) & mask` 是经典写法，可枚举 mask 的所有非空子集。

## 易错点

1. n <= 16 时状态空间为 2^16 = 65536，三重枚举可能超时，需合理剪枝。
2. 线性基方法的秩计算中，要注意重复元素（相同元素插入后秩不变）。
3. `total_xor == 0` 与 `total_xor != 0` 的分组上界公式不同。
4. XOR 线性基中应保存规约后的基底，避免重复。
