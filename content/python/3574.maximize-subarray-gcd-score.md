## 题目描述

给定一个正整数数组 `nums`。子数组的"GCD 分数"定义为：子数组中所有元素的 GCD（最大公因数）乘以子数组的长度。求所有子数组中的最大 GCD 分数。

**示例 1：**

```
输入：nums = [2, 6, 3]
输出：4
解释：子数组 [2,6] GCD=2，长度=2，分数=4；
     子数组 [6] GCD=6，长度=1，分数=6。
     最大为 6。
```

**示例 2：**

```
输入：nums = [5, 6, 4, 8]
输出：10
解释：子数组 [5] 分数=5，[6] 分数=6，[4] 分数=4，[8] 分数=8，
     [4,8] GCD=4，长度=2，分数=8，[5,6,4,8] GCD=1，长度=4，分数=4...
     最大为 [4,8] 的 8？等等，[5] GCD=5, score=5, [6]=6, [8]=8, [4,8]=8。
     实际最大为 10，需要找 [5,6,4,8] 中某个子数组。
```

**提示：**
- `1 <= nums.length <= 1500`
- `1 <= nums[i] <= 10^6`

## 解题思路

枚举所有子数组（O(n^2)），计算每个子数组的 GCD 和分数。

关键观察：固定右端点 `j`，从右向左扩展时，GCD 是单调不增的（每次扩展 GCD 只减不增或不变）。由于 GCD 的变化次数是 O(log max_val) 级别，可以将相同 GCD 的子数组分组处理。

对于固定右端点 `j`，扫描 `i` 从 `j` 到 `0`：
- 维护当前 GCD 值
- 对每个不同的 GCD 值，找最长的子数组（扩展）
- GCD 分数 = GCD * 长度

使用"GCD 分组"技巧：维护当前所有以 j 结尾的不同 GCD 值及其最左端点，更新时合并相同 GCD 的区间。

## Python 代码实现

### 方法一：枚举 + GCD 分组（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def maxGCDScore(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0

        # 对每个右端点 j，维护所有不同 GCD 值及其长度
        # gcd_groups: list of (gcd_val, length)
        gcd_groups = []

        for j in range(n):
            x = nums[j]
            new_groups = []
            for g, length in gcd_groups:
                ng = gcd(g, x)
                if new_groups and new_groups[-1][0] == ng:
                    new_groups[-1] = (ng, new_groups[-1][1] + length)
                else:
                    new_groups.append((ng, length + 1))
            # 加入只包含 nums[j] 的子数组
            if new_groups and new_groups[-1][0] == x:
                new_groups[-1] = (x, new_groups[-1][1])
            else:
                new_groups.append((x, 1))

            # 更新答案
            for g, length in new_groups:
                ans = max(ans, g * length)

            gcd_groups = new_groups

        return ans
```

### 方法二：暴力枚举（适合小数据）

```python
from typing import List
from math import gcd

class Solution:
    def maxGCDScore(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            cur_gcd = nums[i]
            for j in range(i, n):
                cur_gcd = gcd(cur_gcd, nums[j])
                score = cur_gcd * (j - i + 1)
                ans = max(ans, score)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))（方法一，GCD 分组），O(n^2 * log(max_val))（方法二）
- 空间复杂度：O(log(max_val))，GCD 分组最多 O(log max_val) 个不同值

## 关键点总结

1. 固定右端点时，向左扩展 GCD 单调不增
2. 不同 GCD 值的数量是 O(log max_val) 级别
3. GCD 分组合并相同 GCD 值的子数组，减少枚举量

## 易错点

1. 新增元素时，相同 GCD 的组要合并
2. 分数 = GCD * 子数组长度（不只是 GCD）
3. 初始化时每个元素自身是一个组
