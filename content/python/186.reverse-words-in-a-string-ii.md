## 题目描述

给你一个字符数组 `s`，反转字符串中的所有单词。

**单词** 的定义是：单词是一个由非空格字符组成的序列。`s` 中的单词将会由单个空格分隔。

**注意：**
- 输入字符串 `s` 中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。
- 要求使用 O(1) 额外空间复杂度的原地算法解决此问题。

**示例 1：**
```
输入：s = ["t","h","e"," ","s","k","y"," ","i","s"," ","b","l","u","e"]
输出：["b","l","u","e"," ","i","s"," ","s","k","y"," ","t","h","e"]
```

**示例 2：**
```
输入：s = ["a"]
输出：["a"]
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 可以是一个英文字母（大写或小写）、数字、或空格 `' '`
- `s` 中至少存在一个单词
- `s` 不含前导或尾随空格
- `s` 里的所有单词都被单个空格分隔

## 解题思路

这是一道经典的原地反转问题，核心思想是**两次反转**：

1. **第一次反转**：反转整个字符数组
2. **第二次反转**：逐个反转每个单词

**为什么这样做？**

假设原字符串是 `"the sky is blue"`：
1. 整体反转后变成 `"eulb si yks eht"`
2. 然后逐个反转每个单词：
   - `"eulb"` → `"blue"`
   - `"si"` → `"is"`
   - `"yks"` → `"sky"`
   - `"eht"` → `"the"`
3. 最终得到 `"blue is sky the"`

这个方法的巧妙之处在于：两次反转抵消了字符顺序的变化，但保留了单词顺序的反转。

## Python 代码实现

### 方法一：双指针两次反转（推荐）⭐

```python
from typing import List

class Solution:
    def reverseWords(self, s: List[str]) -> None:
        """
        原地反转单词顺序
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 辅助函数：反转数组的指定区间
        def reverse(left: int, right: int) -> None:
            while left < right:
                s[left], s[right] = s[right], s[left]
                left += 1
                right -= 1
        
        n = len(s)
        
        # 第一步：反转整个数组
        reverse(0, n - 1)
        
        # 第二步：反转每个单词
        start = 0  # 当前单词的起始位置
        for i in range(n):
            if s[i] == ' ':
                # 遇到空格，反转前一个单词
                reverse(start, i - 1)
                start = i + 1  # 下一个单词的起始位置
        
        # 反转最后一个单词（因为末尾没有空格）
        reverse(start, n - 1)
```

### 方法二：使用 Python 特性（简洁版）

```python
from typing import List

class Solution:
    def reverseWords(self, s: List[str]) -> None:
        """
        利用 Python 切片和字符串操作
        注意：这种方法不是严格的 O(1) 空间，仅供学习
        """
        # 将字符数组转为字符串
        string = ''.join(s)
        
        # 分割、反转、重新组合
        words = string.split(' ')
        reversed_string = ' '.join(reversed(words))
        
        # 更新原数组
        for i, char in enumerate(reversed_string):
            s[i] = char
```

### 方法三：手动查找单词边界

```python
from typing import List

class Solution:
    def reverseWords(self, s: List[str]) -> None:
        """
        手动管理单词边界，更清晰的逻辑
        """
        def reverse(left: int, right: int) -> None:
            while left < right:
                s[left], s[right] = s[right], s[left]
                left += 1
                right -= 1
        
        n = len(s)
        # 反转整个字符串
        reverse(0, n - 1)
        
        # 查找并反转每个单词
        i = 0
        while i < n:
            # 跳过空格
            if s[i] == ' ':
                i += 1
                continue
            
            # 找到单词的开始
            start = i
            
            # 找到单词的结束
            while i < n and s[i] != ' ':
                i += 1
            
            # 反转这个单词
            reverse(start, i - 1)
```

## 复杂度分析

**方法一（推荐）：**
- **时间复杂度**：O(n)，其中 n 是字符数组的长度。需要遍历数组两次。
- **空间复杂度**：O(1)，只使用了常数个额外变量。

**方法二：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，需要额外的字符串空间，不符合题目要求。

## 图解示例

以 `["t","h","e"," ","s","k","y"]` 为例：

```
初始状态：
t h e   s k y

步骤 1：反转整个数组
y k s   e h t

步骤 2：反转每个单词
- 反转 "yks" → "sky"
- 反转 "eht" → "the"

最终结果：
s k y   t h e
```

## 关键点总结

1. **两次反转技巧**：先整体反转，再局部反转，是处理此类问题的经典方法
2. **双指针**：用于原地反转数组的某个区间
3. **边界处理**：注意最后一个单词的处理（没有空格结尾）
4. **原地算法**：通过交换元素实现 O(1) 空间复杂度
5. **单词边界识别**：通过空格字符来确定单词的起始和结束位置

## 易错点

1. **忘记反转最后一个单词**：循环结束后，最后一个单词还没有被反转
   ```python
   # 容易漏掉这一步
   reverse(start, n - 1)
   ```

2. **索引越界**：在反转时注意 `i - 1` 可能为负数
   ```python
   if s[i] == ' ' and i > 0:  # 确保 i > 0
       reverse(start, i - 1)
   ```

3. **空格处理错误**：题目保证没有多余空格，但实际编程中需要考虑边界情况

4. **修改了原数组但返回了新数组**：题目要求原地修改，不需要返回值
   ```python
   # 错误示例
   def reverseWords(self, s: List[str]) -> List[str]:
       return new_array  # ❌ 不应该返回新数组
   
   # 正确示例
   def reverseWords(self, s: List[str]) -> None:
       # 直接修改 s
   ```
