## 题目描述

给你一个数组 `arr`，其中 `arr[i]` 表示第 i 步（1-indexed）将下标 `arr[i]` 的位置设为 1。

初始时所有位置都是 0。

返回**最后一步**，在这一步结束后，存在**恰好长度为 m 的全 1 连续子串**。若不存在，返回 -1。

**示例 1：**
```
输入：arr = [3,5,1,2,4], m = 1
输出：4
解释：第4步后数组为 [1,1,1,1,0]...不对，arr = [3,5,1,2,4] 表示按顺序设置位置3,5,1,2,4为1
```

**提示：**
- `n == arr.length`
- `1 <= m <= n <= 10^5`

## 解题思路

### 区间合并（倒序或正序）

**正序方法：** 维护每个连续 1 的区间端点，每次设置位置后更新区间，统计长度为 m 的区间数。

**用 `left` 和 `right` 数组记录区间端点：**
- `left[i]`：以 i 为右端点的连续 1 区间的左端点
- `right[i]`：以 i 为左端点的连续 1 区间的右端点

每次设置位置 `pos`，检查左右邻居，合并区间并更新统计。

## 代码实现

### 方法一：区间端点维护（推荐）

```python
from typing import List

class Solution:
    def findLatestStep(self, arr: List[int], m: int) -> int:
        n = len(arr)
        # left[i]: 以 i 为右端点的区间的长度（0 = 未设置）
        # 实际用 length[i] 表示位置 i 所在区间的长度
        length = [0] * (n + 2)  # 加边界
        count = [0] * (n + 1)   # count[l]: 长度为 l 的区间数
        ans = -1

        for step, pos in enumerate(arr, 1):
            # 合并左右区间
            left_len = length[pos - 1]
            right_len = length[pos + 1]
            new_len = left_len + right_len + 1

            # 更新端点长度（只需更新两端）
            length[pos - left_len] = new_len  # 新区间的左端点
            length[pos + right_len] = new_len  # 新区间的右端点

            # 更新 count
            if left_len > 0:
                count[left_len] -= 1
            if right_len > 0:
                count[right_len] -= 1
            count[new_len] += 1

            # 检查是否有长度为 m 的区间
            if count[m] > 0:
                ans = step

        return ans
```

### 方法二：集合模拟

```python
from typing import List

class Solution:
    def findLatestStep(self, arr: List[int], m: int) -> int:
        n = len(arr)
        # 用集合存储所有"长度为m的区间"的左端点
        ones = [0] * (n + 2)  # ones[i] = 1 if pos i is set
        # 区间起点和终点
        start = {}  # start[l] = r: 区间 [l, r]
        end = {}    # end[r] = l: 区间 [l, r]
        m_count = 0
        ans = -1

        for step, pos in enumerate(arr, 1):
            ones[pos] = 1
            l, r = pos, pos
            # 合并左邻
            if pos - 1 in end:
                l = end[pos - 1]
                del start[l]
                del end[pos - 1]
                if pos - l == m:
                    m_count -= 1
            # 合并右邻
            if pos + 1 in start:
                r = start[pos + 1]
                del end[r]
                del start[pos + 1]
                if r - pos == m:
                    m_count -= 1
            # 新区间
            start[l] = r
            end[r] = l
            if r - l + 1 == m:
                m_count += 1
            if m_count > 0:
                ans = step

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N)，每步操作 O(1)
- **空间复杂度**：O(N)

## 关键点总结

1. 维护每个位置所在连续区间的长度（用端点记录）
2. 每次合并区间时，更新长度为 m 的区间数
3. 记录最后一次有长度为 m 的区间的步骤

## 易错点

- `length` 数组更新的是区间两端（左端和右端），不是中间位置
- 合并前要先减去原有的长度 m 统计，合并后再加上新的
