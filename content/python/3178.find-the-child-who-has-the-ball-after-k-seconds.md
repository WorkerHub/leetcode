## 题目描述

有 `n` 个孩子站成一排，编号 0 到 n-1。第 0 秒，0 号孩子拿着球。

每秒，球传给相邻的孩子：若球在最左（0）或最右（n-1）端，方向反转。

返回 `k` 秒后拿着球的孩子的编号。

**示例 1：**
```
输入：n = 3, k = 2
输出：2
解释：0->1->2，第2秒在2号
```

**示例 2：**
```
输入：n = 3, k = 4
输出：0
解释：0->1->2->1->0
```

**提示：**
- `2 <= n <= 50`
- `1 <= k <= 50`

## 解题思路

球的运动是周期性的，周期为 2*(n-1)。在一个周期内，位置序列为 0, 1, 2, ..., n-1, n-2, ..., 1。

k mod (2*(n-1)) 后，确定在哪半个周期。

## Python 代码实现

### 方法一：数学（推荐）

```python
class Solution:
    def numberOfChild(self, n: int, k: int) -> int:
        period = 2 * (n - 1)
        k = k % period
        if k < n:
            return k
        else:
            return period - k
```

### 方法二：模拟

```python
class Solution:
    def numberOfChild(self, n: int, k: int) -> int:
        pos = 0
        direction = 1  # 1 向右，-1 向左
        for _ in range(k):
            pos += direction
            if pos == n - 1:
                direction = -1
            elif pos == 0:
                direction = 1
        return pos
```

## 复杂度分析

- 时间复杂度：O(1)（方法一）
- 空间复杂度：O(1)

## 关键点总结

1. 周期为 2*(n-1)
2. k mod period 后，在 [0, n-1] 范围内直接返回，否则用 period - k

## 易错点

1. 周期是 2*(n-1)，不是 n
2. 对 period 取模后分两段处理
