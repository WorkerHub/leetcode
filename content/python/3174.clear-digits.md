## 题目描述

给你一个字符串 `s`，其中包含小写英文字母和数字字符。

重复以下操作直到字符串中不再含有数字：
- 删除字符串中 **第一个** 数字字符以及其 **左侧最近** 的非数字字符

返回最终的字符串。**保证操作总是可行的**（即每个数字左边都有非数字字符）。

**示例 1：**
```
输入：s = "abc"
输出："abc"
```

**示例 2：**
```
输入：s = "cb34"
输出：""
解释：'3' 和 'b' 同时删除得 "c4"，再删 '4' 和 'c' 得 ""
```

**提示：**
- `1 <= s.length <= 100`
- 保证操作总可行

## 解题思路

用栈模拟：遍历字符串，若是字母则入栈；若是数字则弹出栈顶（最近的字母），数字本身不入栈。

## Python 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def clearDigits(self, s: str) -> str:
        stack = []
        for c in s:
            if c.isdigit():
                if stack:
                    stack.pop()  # 删除最近的字母
            else:
                stack.append(c)
        return ''.join(stack)
```

### 方法二：模拟

```python
class Solution:
    def clearDigits(self, s: str) -> str:
        s = list(s)
        while any(c.isdigit() for c in s):
            for i, c in enumerate(s):
                if c.isdigit():
                    # 找左侧最近的非数字字符
                    for j in range(i - 1, -1, -1):
                        if not s[j].isdigit():
                            s[j] = ''
                            break
                    s[i] = ''
                    break
            s = [c for c in s if c]
        return ''.join(s)
```

## 复杂度分析

- 时间复杂度：O(n)，栈方法
- 空间复杂度：O(n)

## 关键点总结

1. 栈模拟：字母入栈，数字弹出栈顶
2. 数字本身不入栈
3. 最终栈中的内容就是答案

## 易错点

1. 数字自身也需要被"跳过"（不入栈）
2. 保证可行，不需要处理数字左边无字母的情况
