## 题目描述

对一个大小为 `n x n` 的矩阵，如果其中每一行和每一列都包含 `1` 到 `n` 中的**所有整数**（即是 1 到 n 的排列），则称该矩阵为**有效矩阵**。

给你一个 `n x n` 整数矩阵 `matrix`，如果它是有效矩阵，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：matrix = [[1,2,3],[3,1,2],[2,3,1]]
输出：true
```

**示例 2：**
```
输入：matrix = [[1,1,1],[1,2,3],[1,2,3]]
输出：false
```

**提示：**
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 100`
- `1 <= matrix[i][j] <= n`

## 解题思路

对每一行和每一列，判断是否包含 1 到 n 的所有整数（即转为集合后大小为 n 且均为有效值）。

## 代码实现

### 方法一：集合判断（推荐）

```python
from typing import List

class Solution:
    def checkValid(self, matrix: List[List[int]]) -> bool:
        n = len(matrix)
        target = set(range(1, n + 1))

        # 检查每一行
        for row in matrix:
            if set(row) != target:
                return False

        # 检查每一列
        for j in range(n):
            col = {matrix[i][j] for i in range(n)}
            if col != target:
                return False

        return True
```

### 方法二：用 sorted 验证

```python
from typing import List

class Solution:
    def checkValid(self, matrix: List[List[int]]) -> bool:
        n = len(matrix)
        expected = list(range(1, n + 1))

        # 检查行
        for row in matrix:
            if sorted(row) != expected:
                return False

        # 检查列（转置后检查）
        for col in zip(*matrix):
            if sorted(col) != expected:
                return False

        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合判断 | O(n^2) | O(n) |
| 排序验证 | O(n^2 log n) | O(n) |

## 关键点总结

1. 集合判断：直接将行/列转为集合，与 `{1,...,n}` 比较。
2. Python 的 `zip(*matrix)` 可方便地获取列数据。
3. 若矩阵值均在 `[1, n]` 内（题目保证），则集合大小等于 n 即可证明是排列。

## 易错点

- 仅判断集合大小（`len(set(row)) == n`）是不够的，因为值必须在 `[1, n]` 范围内（题目保证了这一点，但保险起见可以和目标集合比较）。
