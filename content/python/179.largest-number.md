## 题目描述

给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。

注意：输出结果可能非常大，所以你需要返回一个字符串而不是整数。

**示例 1：**

```
输入：nums = [10,2]
输出："210"
```

**示例 2：**

```
输入：nums = [3,30,34,5,9]
输出："9534330"
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`

## 解题思路

这道题的关键在于：**如何定义两个数字的大小关系**？

### 核心观察

对于两个数字 `a` 和 `b`，有两种拼接方式：
- 方式1：`ab`（a 在前，b 在后）
- 方式2：`ba`（b 在前，a 在后）

我们应该选择拼接结果更大的方式。例如：
- `3` 和 `30`：比较 `"330"` 和 `"303"`，显然 `"330" > "303"`，所以 `3` 应该排在 `30` 前面
- `10` 和 `2`：比较 `"102"` 和 `"210"`，显然 `"210" > "102"`，所以 `2` 应该排在 `10` 前面

### 解题步骤

1. 将所有数字转换为字符串
2. 自定义比较规则：对于字符串 `x` 和 `y`，如果 `x + y > y + x`，则 `x` 应该排在 `y` 前面
3. 按照自定义规则排序
4. 拼接排序后的字符串
5. 处理特殊情况：如果结果全是 0，返回 `"0"`

## Python 代码实现

### 方法一：自定义排序（推荐）

```python
from typing import List
from functools import cmp_to_key

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        # 将数字转换为字符串
        nums_str = [str(num) for num in nums]
        
        # 自定义比较函数
        def compare(x: str, y: str) -> int:
            # 如果 x + y > y + x，则 x 应该排在前面（返回 -1）
            # 如果 x + y < y + x，则 y 应该排在前面（返回 1）
            if x + y > y + x:
                return -1
            elif x + y < y + x:
                return 1
            else:
                return 0
        
        # 使用自定义比较函数排序
        nums_str.sort(key=cmp_to_key(compare))
        
        # 拼接结果
        result = ''.join(nums_str)
        
        # 处理特殊情况：全是 0 的情况（例如 [0, 0]）
        return '0' if result[0] == '0' else result
```

### 方法二：简化版自定义排序

```python
from typing import List
from functools import cmp_to_key

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        # 自定义比较：比较 y+x 和 x+y（注意顺序，实现降序）
        nums_str = sorted(map(str, nums), key=cmp_to_key(lambda x, y: -1 if x + y > y + x else 1))
        
        # 拼接并处理全 0 情况
        return '0' if nums_str[0] == '0' else ''.join(nums_str)
```

### 方法三：使用 key 函数（更 Pythonic）

```python
from typing import List
from functools import cmp_to_key

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        # 转换为字符串
        nums = list(map(str, nums))
        
        # 定义比较类
        class LargerNumKey(str):
            def __lt__(x, y):
                return x + y > y + x  # 注意：这里反转比较，实现降序
        
        # 排序
        nums.sort(key=LargerNumKey)
        
        # 拼接并处理全 0 情况
        result = ''.join(nums)
        return '0' if result[0] == '0' else result
```

### 方法四：暴力法（不推荐，仅用于理解）

```python
from typing import List
from itertools import permutations

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        # 生成所有排列
        max_num = '0'
        for perm in permutations(nums):
            current = ''.join(map(str, perm))
            if current > max_num:
                max_num = current
        
        return max_num
```

**注意：** 方法四时间复杂度为 O(n!)，仅适用于数据量极小的情况（n <= 8），不推荐使用。

## 复杂度分析

**方法一、二、三（自定义排序）：**
- 时间复杂度：O(n log n × k)
  - `n` 是数组长度
  - `k` 是数字的平均位数（字符串比较的复杂度）
  - 排序的时间复杂度为 O(n log n)，每次比较需要 O(k)
- 空间复杂度：O(n × k)，存储字符串数组

**方法四（暴力法）：**
- 时间复杂度：O(n! × n × k)，不可接受
- 空间复杂度：O(n! × n × k)

## 关键点总结

1. **自定义比较规则**：核心是比较 `x + y` 和 `y + x` 的大小
2. **字符串比较**：Python 字符串可以直接用 `>` 比较字典序
3. **functools.cmp_to_key**：将比较函数转换为 key 函数
4. **边界情况**：全 0 的数组（如 `[0, 0, 0]`）应返回 `"0"` 而不是 `"000"`
5. **贪心思想**：局部最优（每次选择拼接结果更大的顺序）能得到全局最优

## 易错点

1. **忘记处理全 0 情况**
   ```python
   # 错误：[0, 0] 会返回 "00"
   return ''.join(nums_str)
   
   # 正确：检查第一个字符
   return '0' if result[0] == '0' else result
   ```

2. **比较规则错误**
   ```python
   # 错误：直接比较数字大小
   nums.sort(reverse=True)  # [3, 30, 34, 5, 9] -> [9, 5, 34, 30, 3] -> "95343030"
   
   # 正确：比较拼接后的字符串
   compare(x, y): return -1 if x + y > y + x else 1
   ```

3. **__lt__ 方向错误**
   ```python
   # 错误：这会导致升序
   def __lt__(x, y):
       return x + y < y + x
   
   # 正确：降序（注意是 >）
   def __lt__(x, y):
       return x + y > y + x
   ```

4. **字符串与整数混用**
   ```python
   # 错误：整数拼接会报错
   result = nums[0] + nums[1]  # TypeError
   
   # 正确：先转换为字符串
   nums_str = [str(num) for num in nums]
   ```

5. **忘记导入 cmp_to_key**
   ```python
   # 错误：cmp_to_key 未定义
   nums.sort(key=cmp_to_key(compare))
   
   # 正确：导入
   from functools import cmp_to_key
   ```
