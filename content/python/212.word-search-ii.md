## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个单词（字符串）列表 `words`，返回所有二维网格上的单词。

单词必须按照字母顺序，通过 **相邻的单元格** 内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母在一个单词中 **不允许被重复使用**。

**示例 1：**

```
输入：board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]
输出：["eat","oath"]
```

**示例 2：**

```
输入：board = [["a","b"],["c","d"]], words = ["abcb"]
输出：[]
```

**提示：**

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 12`
- `board[i][j]` 是一个小写英文字母
- `1 <= words.length <= 3 * 10^4`
- `1 <= words[i].length <= 10`
- `words[i]` 由小写英文字母组成
- `words` 中的所有字符串互不相同

## 解题思路

这道题是 [79. 单词搜索](https://leetcode.com/problems/word-search/) 的进阶版，需要在网格中查找多个单词。

**核心思想：**

如果对每个单词都进行一次 DFS，会导致大量重复搜索。更优的方法是：
1. **构建字典树（Trie）**：将所有单词存入 Trie
2. **一次 DFS 遍历**：从每个格子出发，同时匹配 Trie 中的所有单词
3. **剪枝优化**：找到单词后立即从 Trie 中删除，避免重复

**算法流程：**

1. 构建 Trie：将 `words` 中所有单词插入字典树
2. 遍历网格：从每个格子 `(i, j)` 出发进行 DFS
3. DFS 搜索：
   - 检查当前字符是否在 Trie 的子节点中
   - 如果是单词结尾，加入结果集
   - 标记当前格子为已访问（修改为特殊字符）
   - 递归搜索四个方向
   - 回溯：恢复格子原值
4. 剪枝：找到单词后从 Trie 中删除，避免重复查找

## Python 代码实现

### 方法一：字典树 + DFS + 剪枝（推荐）⭐

```python
class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        # 构建字典树
        trie = {}
        for word in words:
            node = trie
            for char in word:
                node = node.setdefault(char, {})
            node['#'] = word  # 存储完整单词
        
        m, n = len(board), len(board[0])
        result = []
        
        def dfs(i: int, j: int, node: dict):
            """从 (i, j) 开始 DFS 搜索"""
            # 边界检查
            if i < 0 or i >= m or j < 0 or j >= n:
                return
            
            char = board[i][j]
            # 字符不在 Trie 中，或已访问过
            if char not in node:
                return
            
            node = node[char]
            
            # 找到一个单词
            if '#' in node:
                result.append(node['#'])
                del node['#']  # 删除避免重复
            
            # 标记为已访问
            board[i][j] = '@'
            
            # 四个方向递归搜索
            for di, dj in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                dfs(i + di, j + dj, node)
            
            # 回溯：恢复原值
            board[i][j] = char
            
            # 剪枝：如果节点没有子节点，从父节点删除
            if not node:
                del trie[char]
        
        # 从每个格子出发搜索
        for i in range(m):
            for j in range(n):
                dfs(i, j, trie)
        
        return result
```

### 方法二：字典树类封装版

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.word = None  # 存储完整单词

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word: str):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.word = word

class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        # 构建字典树
        trie = Trie()
        for word in words:
            trie.insert(word)
        
        m, n = len(board), len(board[0])
        result = []
        
        def dfs(i: int, j: int, node: TrieNode):
            # 边界检查
            if i < 0 or i >= m or j < 0 or j >= n:
                return
            
            char = board[i][j]
            if char not in node.children:
                return
            
            node = node.children[char]
            
            # 找到单词
            if node.word:
                result.append(node.word)
                node.word = None  # 避免重复
            
            # 标记已访问
            board[i][j] = '#'
            
            # 四个方向搜索
            for di, dj in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                dfs(i + di, j + dj, node)
            
            # 回溯
            board[i][j] = char
        
        for i in range(m):
            for j in range(n):
                dfs(i, j, trie.root)
        
        return result
```

### 方法三：暴力解法（供对比学习）

```python
class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        """对每个单词单独进行 DFS"""
        m, n = len(board), len(board[0])
        result = []
        
        def dfs(i: int, j: int, word: str, index: int, visited: set) -> bool:
            """搜索单个单词"""
            if index == len(word):
                return True
            
            if i < 0 or i >= m or j < 0 or j >= n:
                return False
            
            if (i, j) in visited or board[i][j] != word[index]:
                return False
            
            visited.add((i, j))
            
            # 四个方向搜索
            for di, dj in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                if dfs(i + di, j + dj, word, index + 1, visited):
                    visited.remove((i, j))
                    return True
            
            visited.remove((i, j))
            return False
        
        for word in words:
            found = False
            for i in range(m):
                for j in range(n):
                    if board[i][j] == word[0]:
                        if dfs(i, j, word, 0, set()):
                            result.append(word)
                            found = True
                            break
                if found:
                    break
        
        return result
```

## 复杂度分析

**方法一（字典树 + DFS）：**

- **时间复杂度：** O(M × N × 4^L)
  - M × N 是网格大小
  - L 是单词最大长度
  - 每个格子最多有 4 个方向
  - Trie 剪枝可显著降低实际复杂度
- **空间复杂度：** O(K × L)
  - K 是单词数量
  - L 是单词平均长度
  - 递归栈深度：O(L)

**方法三（暴力）：**

- **时间复杂度：** O(K × M × N × 4^L)
  - K 个单词，每个都要遍历整个网格
- **空间复杂度：** O(L)

## 关键点总结

1. **字典树优化**：一次 DFS 同时匹配多个单词，避免重复搜索
2. **剪枝策略**：找到单词后立即删除，防止重复结果
3. **回溯模板**：标记访问 → 递归搜索 → 恢复状态
4. **空间优化**：直接修改 `board` 标记访问，无需额外 `visited` 数组
5. **方向数组**：使用 `[(0,1), (1,0), (0,-1), (-1,0)]` 简化代码

## 易错点

1. **重复结果**：
   ```python
   # 错误：未删除已找到的单词
   if '#' in node:
       result.append(node['#'])
   # 正确：删除避免重复
   if '#' in node:
       result.append(node['#'])
       del node['#']
   ```

2. **回溯遗漏**：
   ```python
   # 错误：忘记恢复原值
   board[i][j] = '#'
   dfs(...)
   # 正确：必须回溯
   board[i][j] = '#'
   dfs(...)
   board[i][j] = char
   ```

3. **边界检查顺序**：先检查边界，再访问 `board[i][j]`，避免越界

4. **Trie 节点删除**：删除空节点可以优化性能，但要注意不要误删

5. **特殊字符冲突**：标记访问时选择的特殊字符（如 `#`）不能与题目字符冲突
