## 题目描述

给你一个数组 `nums`，其中包含整数 1、2、3。

数组中有些位置是"锁定"的（不能移动），其余位置是"未锁定"的（可以任意重排）。

给你一个布尔数组 `locked`，`locked[i] == true` 表示位置 i 被锁定。

返回**最少需要解锁的位置数量**，使得数组可以被排成不递减序列。

如果不可能排成不递减序列，返回 -1。

**示例 1：**

```
输入：nums = [1,2,1,1], locked = [true,true,false,true]
输出：0
解释：nums 已经有序，不需要解锁
```

**示例 2：**

```
输入：nums = [1,2,1,1], locked = [true,false,true,true]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i]` 是 1、2 或 3
- `locked.length == nums.length`

## 解题思路

由于 nums 只包含 1、2、3，排序后结果固定（先所有 1，再所有 2，再所有 3）。

设排序后数组为 `target`。对于每个位置 i，若 `locked[i]` 为 true，则 `nums[i]` 必须等于 `target[i]`（否则不可能，返回 -1）。若 `locked[i]` 为 false（未锁定），无论如何都可以调整（不需要解锁）。

需要解锁的情况：某位置 i 是"锁定"的，但 `nums[i] != target[i]`，此时必须解锁该位置。

等等，重新理解题意：解锁一个位置意味着可以改变该位置的值（移动它）。我们希望最少解锁多少个被锁定的位置，使得通过重排未锁定位置和解锁位置的元素，得到有序数组。

## Python 代码实现

### 方法一：确定哪些锁定位置需要解锁

```python
from typing import List

class Solution:
    def minUnlockedIndices(self, nums: List[int], locked: List[bool]) -> int:
        n = len(nums)

        # 目标排序数组
        target = sorted(nums)

        # 检查每个锁定位置
        # 若 locked[i] 且 nums[i] != target[i]，该锁定位置必须解锁
        # 但解锁后，该位置的元素可以和未锁定位置互换

        # 关键：锁定的位置不能移动，只有解锁或未锁定的位置可以重排
        # 最少解锁数 = 最少解锁多少个 locked=true 的位置，使得剩余可排序

        # 对于最终有序数组，位置 i 的值为 target[i]
        # 已满足条件的锁定位置：locked[i]=true 且 nums[i]==target[i]（无需动）
        # 需解锁的：locked[i]=true 且 nums[i]!=target[i]（必须解锁）

        # 但未锁定位置可以填入任意剩余值
        # 所以：锁定但不在正确位置的都需要解锁

        # 贪心：
        # 统计每个值在目标中的位置与当前锁定位置的冲突
        # 若某个锁定位置的值和目标不匹配，就需要解锁

        # 简化：由于只有 1,2,3
        # 目标中前 cnt1 个是 1，接着 cnt2 个是 2，最后 cnt3 个是 3
        cnt = [0, 0, 0, 0]
        for v in nums:
            cnt[v] += 1

        # 目标：位置 [0, cnt[1]-1] 是 1，[cnt[1], cnt[1]+cnt[2]-1] 是 2，...
        boundaries = [0, cnt[1], cnt[1] + cnt[2], n]

        # 统计需要解锁的位置数
        unlock_count = 0
        for i in range(n):
            if locked[i]:
                # 该位置应有什么值
                if i < boundaries[1]:
                    expected = 1
                elif i < boundaries[2]:
                    expected = 2
                else:
                    expected = 3
                if nums[i] != expected:
                    unlock_count += 1

        return unlock_count
```

### 方法二：验证可行性后计算

```python
from typing import List

class Solution:
    def minUnlockedIndices(self, nums: List[int], locked: List[bool]) -> int:
        n = len(nums)
        target = sorted(nums)

        # 对于锁定的位置，其值必须等于 target[i]（否则需要解锁）
        # 未锁定的位置可以填任意值

        # 计算需要解锁的位置数（锁定但值不对的位置）
        unlock = 0
        for i in range(n):
            if locked[i] and nums[i] != target[i]:
                unlock += 1

        return unlock
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 目标排序数组 target 是唯一的（sorted(nums)）
2. 锁定位置必须保持原值，若不匹配目标就需要解锁
3. 未锁定位置可以任意重排，不计入解锁数

## 易错点

1. 注意 nums 只含 1、2、3，目标数组唯一确定
2. 解锁一个位置后它就可以自由移动，可以和其他未锁定/解锁位置交换
3. 若锁定位置的值与目标匹配，不需要解锁
