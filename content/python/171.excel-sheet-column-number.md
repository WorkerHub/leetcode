## 题目描述

给你一个字符串 `columnTitle`，表示 Excel 表格中的列名称。返回该列名称对应的列序号。

例如：
```
A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...
```

**示例 1：**
```
输入：columnTitle = "A"
输出：1
```

**示例 2：**
```
输入：columnTitle = "AB"
输出：28
```

**示例 3：**
```
输入：columnTitle = "ZY"
输出：701
```

**提示：**
- 1 <= columnTitle.length <= 7
- columnTitle 仅由大写英文组成
- columnTitle 在范围 ["A", "FXSHRXW"] 内

## 解题思路

这是**第 168 题的逆过程**，本质是**26 进制转十进制**，但索引从 1 开始而非 0。

**核心思想：**
- 这是一个类 26 进制的问题
- 从左到右，每一位的权重依次为 26^(n-1), 26^(n-2), ..., 26^0
- 每个字母对应的值：A=1, B=2, ..., Z=26

**转换公式：**
```
"AB" = A * 26^1 + B * 26^0
     = 1 * 26 + 2 * 1
     = 28
```

**算法步骤：**
1. 从左到右遍历字符串
2. 将当前结果乘以 26（进位）
3. 加上当前字符对应的值（A=1, B=2, ...）
4. 返回最终结果

**对比第 168 题：**
- 168 题：数字 → 字母（除法 + 取模，需要减 1）
- 171 题：字母 → 数字（乘法 + 加法，不需要减 1）

## Python 代码实现

### 方法一：迭代乘 26（推荐）

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        result = 0
        
        for char in columnTitle:
            # 计算当前字符对应的数值（A=1, B=2, ...）
            digit = ord(char) - ord('A') + 1
            # 进位并累加
            result = result * 26 + digit
        
        return result
```

### 方法二：右到左计算（权重法）

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        result = 0
        n = len(columnTitle)
        
        # 从右到左计算，手动计算权重
        for i, char in enumerate(columnTitle):
            digit = ord(char) - ord('A') + 1
            # 当前位的权重是 26^(n-1-i)
            result += digit * (26 ** (n - 1 - i))
        
        return result
```

### 方法三：递归实现

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        if not columnTitle:
            return 0
        
        # 最后一位的值
        last_digit = ord(columnTitle[-1]) - ord('A') + 1
        # 递归处理前面的部分
        return self.titleToNumber(columnTitle[:-1]) * 26 + last_digit
```

### 方法四：函数式编程（Python 特色）

```python
from functools import reduce

class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        return reduce(
            lambda result, char: result * 26 + ord(char) - ord('A') + 1,
            columnTitle,
            0
        )
```

## 复杂度分析

**时间复杂度：** O(n)
- n 是字符串长度，需要遍历每个字符

**空间复杂度：**
- 方法一、二、四：O(1)
- 方法三：O(n)，递归调用栈

## 图解示例

以 `columnTitle = "ZY"` 为例：

```
方法一（从左到右）：
初始：result = 0

处理 'Z':
  digit = ord('Z') - ord('A') + 1 = 26
  result = 0 * 26 + 26 = 26

处理 'Y':
  digit = ord('Y') - ord('A') + 1 = 25
  result = 26 * 26 + 25 = 676 + 25 = 701

最终结果：701
```

```
方法二（从右到左，权重法）：
字符串："ZY"，长度 n = 2

位置 0 ('Z'):
  digit = 26
  权重 = 26^(2-1-0) = 26^1 = 26
  贡献 = 26 * 26 = 676

位置 1 ('Y'):
  digit = 25
  权重 = 26^(2-1-1) = 26^0 = 1
  贡献 = 25 * 1 = 25

总和：676 + 25 = 701
```

## 关键点总结

1. **26 进制转换**：本质是进制转换，但从 1 开始计数
2. **字符映射**：`ord(char) - ord('A') + 1` 将 A-Z 映射到 1-26
3. **进位规则**：每次乘 26 相当于左移一位
4. **不需要减 1**：与 168 题不同，这里不需要索引调整
5. **从左到右最优**：避免计算幂次，效率更高

## 易错点

1. **字符映射错误**
   - 错误：`ord(char) - ord('A')`（映射到 0-25）
   - 正确：`ord(char) - ord('A') + 1`（映射到 1-26）

2. **进位计算错误**
   - 错误：`result + digit * 26`
   - 正确：`result * 26 + digit`

3. **幂次计算错误**
   - 方法二中，从左到右第 i 位的权重是 `26^(n-1-i)` 而非 `26^i`

4. **与 168 题混淆**
   - 168 题需要减 1 是因为要处理 26 的倍数问题
   - 171 题不需要减 1，直接累加即可

5. **边界情况**
   - 单字符："A" -> 1, "Z" -> 26
   - 最大值："FXSHRXW"（7 位字符）
