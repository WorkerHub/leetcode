## 题目描述

给你一个正方形字符数组 `board`，你从数组最右下角的字符 `'S'` 出发。

你的目标是到达数组最左上角的字符 `'E'`，数组剩余的部分为数字字符 `1, 2, ..., 9` 或者障碍 `'X'`。在每一次移动中，你可以向上、向左或者左上方移动，前提是移动的格子没有障碍。

一条路径的 得分定义为：路径上所有数字的和。

请你返回一个列表，包含两个整数：第一个整数是最大得分，第二个整数是得到最大得分的方案数，请把结果对 `10^9 + 7` 取余。

如果没有任何路径可以到达终点，请返回 `[0, 0]`。

示例 1：
```
输入：board = ["E23","2X2","12S"]
输出：[7,1]
```

示例 2：
```
输入：board = ["E12","1X1","21S"]
输出：[4,2]
```

示例 3：
```
输入：board = ["E11","XXX","11S"]
输出：[0,0]
```

提示：
- `2 <= board.length == board[i].length <= 100`

## 解题思路

这是一道动态规划问题。我们需要从起点 'S'（右下角）走到终点 'E'（左上角），找出最大得分和对应的路径数。

核心思想：
1. 使用动态规划，定义 `dp[i][j]` 表示从起点到达位置 `(i, j)` 的最大得分
2. 同时维护 `count[i][j]` 表示达到最大得分的路径数
3. 由于只能向上、向左、左上三个方向移动，我们从右下角开始倒推
4. 对于每个位置，它可以从右边、下边、右下角三个位置转移而来

状态转移：
- 如果 `board[i][j]` 是障碍 'X'，则 `dp[i][j] = -1`
- 否则，从三个可能的前驱位置（右、下、右下）中选择得分最大的
- 如果有多个前驱位置得分相同，路径数要累加

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def pathsWithMaxScore(self, board: List[str]) -> List[int]:
        n = len(board)
        MOD = 10**9 + 7
        
        # dp[i][j] 表示从起点到 (i, j) 的最大得分
        # count[i][j] 表示达到最大得分的路径数
        dp = [[-1] * n for _ in range(n)]
        count = [[0] * n for _ in range(n)]
        
        # 初始化起点
        dp[n-1][n-1] = 0
        count[n-1][n-1] = 1
        
        # 从右下到左上进行 DP
        for i in range(n-1, -1, -1):
            for j in range(n-1, -1, -1):
                # 跳过起点（已初始化）
                if i == n-1 and j == n-1:
                    continue
                
                # 如果是障碍，跳过
                if board[i][j] == 'X':
                    continue
                
                # 三个可能的来源：右边、下边、右下角
                max_score = -1
                total_count = 0
                
                for di, dj in [(0, 1), (1, 0), (1, 1)]:
                    ni, nj = i + di, j + dj
                    
                    # 检查边界
                    if ni >= n or nj >= n:
                        continue
                    
                    # 如果前驱位置不可达，跳过
                    if dp[ni][nj] == -1:
                        continue
                    
                    # 更新最大得分和路径数
                    if dp[ni][nj] > max_score:
                        max_score = dp[ni][nj]
                        total_count = count[ni][nj]
                    elif dp[ni][nj] == max_score:
                        total_count = (total_count + count[ni][nj]) % MOD
                
                # 如果有可达路径
                if max_score != -1:
                    # 如果不是终点，加上当前格子的分数
                    if board[i][j] != 'E':
                        dp[i][j] = max_score + int(board[i][j])
                    else:
                        dp[i][j] = max_score
                    count[i][j] = total_count
        
        # 返回结果
        if dp[0][0] == -1:
            return [0, 0]
        return [dp[0][0], count[0][0]]
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def pathsWithMaxScore(self, board: List[str]) -> List[int]:
        n = len(board)
        MOD = 10**9 + 7
        
        @lru_cache(None)
        def dfs(i: int, j: int) -> tuple:
            # 返回 (最大得分, 路径数)
            
            # 到达起点
            if i == n-1 and j == n-1:
                return (0, 1)
            
            # 越界或遇到障碍
            if i >= n or j >= n or board[i][j] == 'X':
                return (-1, 0)
            
            # 三个方向：右、下、右下
            max_score = -1
            total_count = 0
            
            for di, dj in [(0, 1), (1, 0), (1, 1)]:
                ni, nj = i + di, j + dj
                score, cnt = dfs(ni, nj)
                
                if score == -1:
                    continue
                
                if score > max_score:
                    max_score = score
                    total_count = cnt
                elif score == max_score:
                    total_count = (total_count + cnt) % MOD
            
            if max_score == -1:
                return (-1, 0)
            
            # 加上当前格子的分数
            if board[i][j] != 'E':
                max_score += int(board[i][j])
            
            return (max_score, total_count)
        
        score, cnt = dfs(0, 0)
        if score == -1:
            return [0, 0]
        return [score, cnt]
```

## 复杂度分析

### 方法一：动态规划
- 时间复杂度：O(n²)，其中 n 是矩阵的边长，需要遍历整个矩阵
- 空间复杂度：O(n²)，需要两个 n×n 的数组存储 dp 和 count

### 方法二：记忆化搜索
- 时间复杂度：O(n²)，每个状态最多计算一次
- 空间复杂度：O(n²)，递归栈和缓存空间

## 关键点总结

1. 这是一个倒推的动态规划问题，从起点推向终点
2. 需要同时维护两个状态：最大得分和路径数
3. 当有多个前驱位置得分相同时，路径数要累加
4. 注意处理起点 'S' 和终点 'E' 不计入得分
5. 障碍位置标记为不可达（-1）

## 易错点

1. 忘记对路径数取模
2. 混淆起点和终点的位置（起点在右下，终点在左上）
3. 没有正确处理三个方向的转移
4. 忘记处理无法到达终点的情况
