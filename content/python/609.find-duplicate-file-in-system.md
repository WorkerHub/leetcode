## 题目描述

给你一个目录信息列表 `paths`，包括目录路径，以及该目录中的所有文件及其内容，请你找到文件系统中的所有重复文件组的路径。答案可按**任意顺序**返回。

一组重复的文件至少包括**两个**具有完全相同内容的文件。

**单个**目录信息字符串的格式如下：

- `"root/d1/d2/.../dm f1.txt(f1_content) f2.txt(f2_content) ... fn.txt(fn_content)"`

这意味着，在目录 `root/d1/d2/.../dm` 下，有 n 个文件（`f1.txt`、`f2.txt` ... `fn.txt`），`f1.txt` 的内容为 `f1_content`，`f2.txt` 的内容为 `f2_content`，以此类推。

返回一个由重复文件组成的列表。其中，每组都由具有相同内容的文件路径组成。

**示例 1：**

```
输入：paths = ["root/a 1.txt(abcd) 2.txt(efgh)","root/c 3.txt(abcd)","root/c/d 4.txt(efgh)","root 4.txt(efgh)"]
输出：[["root/a/2.txt","root/c/d/4.txt","root/4.txt"],["root/a/1.txt","root/c/3.txt"]]
```

**示例 2：**

```
输入：paths = ["root/a 1.txt(abcd) 2.txt(efgh)","root/c 3.txt(abcd)","root/c/d 4.txt(efgh)"]
输出：[["root/a/2.txt","root/c/d/4.txt"],["root/a/1.txt","root/c/3.txt"]]
```

**提示：**

- `1 <= paths.length <= 2 * 10^4`
- `1 <= paths[i].length <= 3000`
- `1 <= sum(paths[i].length) <= 5 * 10^5`
- `paths[i]` 由英文字母、数字、字符 `'/'`、`'.'`、`'('`、`')'` 和 `' '` 组成
- 你可以假设在同一目录中没有任何文件或目录共享相同的名称
- 你可以假设每一个给定的目录信息代表一个唯一的目录。目录路径和文件信息用一个空格分隔

**进阶：**

- 如果文件内容非常大（GB 级别），你会如何修改你的解决方案？

- 如何确保你发现的重复文件不是误报？

## 解题思路

这道题的核心是**根据文件内容分组**，找出内容相同的文件。

**解题步骤：**

1. **解析字符串**：提取目录路径、文件名和内容
2. **哈希映射**：用文件内容作为 key，文件路径列表作为 value
3. **筛选结果**：只返回至少有 2 个文件的组

**数据结构：**
- 使用 `defaultdict(list)` 或 `dict`
- key: 文件内容
- value: 包含该内容的所有文件路径列表

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def findDuplicate(self, paths: List[str]) -> List[List[str]]:
        """
        使用哈希表根据文件内容分组
        
        时间复杂度：O(n * m)，n 为路径数，m 为平均文件数
        空间复杂度：O(n * m)，存储所有文件路径
        """
        # 文件内容 -> 文件路径列表
        content_map = defaultdict(list)
        
        for path in paths:
            # 分割目录和文件信息
            parts = path.split(' ')
            directory = parts[0]
            
            # 处理每个文件
            for file_info in parts[1:]:
                # 解析文件名和内容
                # 格式：filename.txt(content)
                name_end = file_info.index('(')
                filename = file_info[:name_end]
                content = file_info[name_end + 1:-1]  # 去掉括号
                
                # 构建完整路径
                full_path = f"{directory}/{filename}"
                
                # 按内容分组
                content_map[content].append(full_path)
        
        # 筛选出至少有2个文件的组
        return [paths for paths in content_map.values() if len(paths) >= 2]
```

### 方法二：使用正则表达式

```python
import re
from collections import defaultdict

class Solution:
    def findDuplicate(self, paths: List[str]) -> List[List[str]]:
        """
        使用正则表达式解析文件信息
        """
        content_map = defaultdict(list)
        
        for path in paths:
            parts = path.split(' ')
            directory = parts[0]
            
            for file_info in parts[1:]:
                # 正则匹配：文件名(内容)
                match = re.match(r'(.+)\((.+)\)', file_info)
                if match:
                    filename, content = match.groups()
                    full_path = f"{directory}/{filename}"
                    content_map[content].append(full_path)
        
        return [paths for paths in content_map.values() if len(paths) >= 2]
```

### 方法三：手动解析（最快）⭐⭐

```python
class Solution:
    def findDuplicate(self, paths: List[str]) -> List[List[str]]:
        """
        手动解析，避免正则表达式开销
        """
        content_map = {}
        
        for path in paths:
            parts = path.split(' ')
            directory = parts[0]
            
            for file_info in parts[1:]:
                # 找到括号位置
                idx = file_info.index('(')
                filename = file_info[:idx]
                content = file_info[idx+1:-1]
                
                # 构建完整路径
                full_path = directory + '/' + filename
                
                # 分组
                if content not in content_map:
                    content_map[content] = []
                content_map[content].append(full_path)
        
        # 返回结果
        result = []
        for file_list in content_map.values():
            if len(file_list) >= 2:
                result.append(file_list)
        
        return result
```

### 方法四：一行流（Python 特色）

```python
class Solution:
    def findDuplicate(self, paths: List[str]) -> List[List[str]]:
        """
        极简版本
        """
        from collections import defaultdict
        
        content_map = defaultdict(list)
        
        for path in paths:
            parts = path.split()
            dir_path = parts[0]
            for file_info in parts[1:]:
                name, content = file_info.split('(')
                content_map[content[:-1]].append(f"{dir_path}/{name}")
        
        return [v for v in content_map.values() if len(v) > 1]
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n × m × k)
  - n：paths 数量
  - m：每个 path 中的文件数
  - k：解析字符串的平均长度
- **空间复杂度**：O(n × m)，存储所有文件路径

## 关键点总结

1. **字符串解析**：正确提取目录、文件名、内容三部分
2. **哈希分组**：使用内容作为 key 进行分组
3. **路径拼接**：注意目录和文件名之间的 `/`
4. **结果筛选**：只返回至少 2 个文件的组
5. **性能优化**：手动解析比正则表达式快

## 易错点

1. **路径拼接错误**：
   ```python
   # ❌ 错误：缺少斜杠
   full_path = directory + filename  # "root/a1.txt"
   
   # ✅ 正确
   full_path = f"{directory}/{filename}"  # "root/a/1.txt"
   ```

2. **括号处理不当**：
   ```python
   # ❌ 错误：没有去掉右括号
   content = file_info[idx+1:]  # "efgh)"
   
   # ✅ 正确
   content = file_info[idx+1:-1]  # "efgh"
   ```

3. **忘记筛选**：
   ```python
   # ❌ 错误：返回所有组，包括只有1个文件的
   return list(content_map.values())
   
   # ✅ 正确：只返回 >= 2 的组
   return [v for v in content_map.values() if len(v) >= 2]
   ```

4. **split 参数**：
   ```python
   # ⚠️ split() 默认按所有空白符分割，等同于 split(' ')
   parts = path.split()  # 正确
   parts = path.split(' ')  # 也正确
   ```

   - 一组：至少 2 个文件
   - 路径格式：`目录 文件1(内容1) 文件2(内容2) ...`

2. **字符串解析技巧**：

3. **循序渐进**：
   - 第一步：解析单个文件信息
   - 第二步：处理多个文件
   - 第三步：分组和筛选

4. **推荐方法**：
   - 初学者：方法一，逻辑清晰
   - 追求性能：方法三，手动解析最快
   - 代码简洁：方法四

5. **测试用例**：
   ```python
   # 单个目录多个文件
   ["root/a 1.txt(a) 2.txt(b)"]
   
   # 多个目录
   ["root/a 1.txt(a)", "root/b 2.txt(a)"]
   ```

**进阶问题解答：**

1. **真实文件系统搜索**：
   - DFS 更节省内存（递归深度有限）
   - BFS 更适合并行处理

2. **大文件处理（GB级别）**：
   - 不存储完整内容，使用文件哈希（MD5、SHA256）
   - 先比较文件大小，再比较哈希值

3. **分块读取（1KB）**：
   - 流式计算哈希值
   - 使用 `hashlib.md5().update()` 分块更新

4. **避免误报**：
   - 使用多种哈希算法
   - 哈希冲突时，逐字节比较确认
   - 考虑文件大小、修改时间等元数据

**实战优化：**
```python
# 大文件处理示例
import hashlib

def file_hash(filepath):
    """计算文件哈希值"""
    hasher = hashlib.md5()
    with open(filepath, 'rb') as f:
        while chunk := f.read(8192):  # 分块读取
            hasher.update(chunk)
    return hasher.hexdigest()
```
