## 题目描述

由范围 [0,n] 内所有整数组成的 n + 1 个整数的排列序列可以表示为长度为 n 的字符串 s，其中:

- 如果 perm[i] < perm[i + 1]，那么 s[i] == 'I'
- 如果 perm[i] > perm[i + 1]，那么 s[i] == 'D'

给定一个字符串 s，重构排列 perm 并返回它。如果有多个有效排列perm，则返回其中任意一个。

## Python 代码实现

```python
from typing import List

class Solution:
    def diStringMatch(self, s: str) -> List[int]:
        n = len(s)
        low, high = 0, n
        result = []
        
        for char in s:
            if char == 'I':
                result.append(low)
                low += 1
            else:
                result.append(high)
                high -= 1
        
        result.append(low)  # 或者 high，此时 low == high
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
