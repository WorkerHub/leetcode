## 题目描述

给你一个大小为 `m x n` 的矩阵 `mat` 和一个整数阈值 `threshold`。

请你返回元素总和小于或等于阈值的正方形区域的**最大边长**；如果没有这样的正方形区域，则返回 **0**。

**示例 1：**

```
输入：mat = [[1,1,3,2,4,3,2],[1,1,3,2,4,3,2],[1,1,3,2,4,3,2]], threshold = 4
输出：2
解释：总和小于等于 4 的正方形的最大边长为 2，如图所示。
```

**示例 2：**

```
输入：mat = [[2,2,2,2,2]], threshold = 1
输出：1
```

**示例 3：**

```
输入：mat = [[1,1,1,1],[1,0,0,0],[1,0,0,0],[1,0,0,0]], threshold = 6
输出：3
```

**提示：**

- `1 <= m, n <= 300`
- `0 <= mat[i][j] <= 10000`
- `0 <= threshold <= 10^5 * 300 * 300`

## 解题思路

### 核心思路

本题需要找最大边长为 `k` 的正方形，使其内部元素之和 `<= threshold`。

解法分两部分：

**第一部分：二维前缀和**

快速计算任意矩形区域的元素和，避免每次重新求和。

定义 `prefix[i][j]` 为从左上角 `(0, 0)` 到 `(i-1, j-1)`（含）的矩形区域元素之和（偏移 1 以简化边界处理）。

递推公式：
```
prefix[i][j] = mat[i-1][j-1]
             + prefix[i-1][j]   （上方矩形）
             + prefix[i][j-1]   （左方矩形）
             - prefix[i-1][j-1] （左上重叠部分）
```

查询以 `(r1, c1)` 为左上角、`(r2, c2)` 为右下角的矩形和：
```
sum = prefix[r2+1][c2+1]
    - prefix[r1][c2+1]
    - prefix[r2+1][c1]
    + prefix[r1][c1]
```

**第二部分：二分查找**

最大边长答案具有单调性：如果边长 `k` 可行，则所有小于 `k` 的边长也可行。

对边长 `[1, min(m, n)]` 做二分查找，每次检查边长 `mid` 是否存在满足条件的正方形。

**方法二：线性扫描（不用二分）**

直接从大到小（或从小到大）扫描边长，找到第一个满足条件的答案。

## Python 代码实现

### 方法一：二维前缀和 + 二分查找（推荐）

```python
from typing import List

class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])

        # 构建二维前缀和矩阵，大小为 (m+1) x (n+1)，初始全 0
        prefix = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 容斥原理计算前缀和
                prefix[i][j] = (mat[i - 1][j - 1]
                                + prefix[i - 1][j]
                                + prefix[i][j - 1]
                                - prefix[i - 1][j - 1])

        def get_sum(r1: int, c1: int, r2: int, c2: int) -> int:
            """查询 (r1, c1) 到 (r2, c2) 的矩形元素和（0-indexed）"""
            return (prefix[r2 + 1][c2 + 1]
                    - prefix[r1][c2 + 1]
                    - prefix[r2 + 1][c1]
                    + prefix[r1][c1])

        def can_fit(side: int) -> bool:
            """判断是否存在边长为 side 的正方形，其元素和 <= threshold"""
            for i in range(m - side + 1):
                for j in range(n - side + 1):
                    # 检查以 (i, j) 为左上角，边长为 side 的正方形
                    if get_sum(i, j, i + side - 1, j + side - 1) <= threshold:
                        return True
            return False

        # 对边长做二分查找
        lo, hi = 0, min(m, n)
        while lo < hi:
            mid = (lo + hi + 1) // 2  # 向上取整，避免死循环
            if can_fit(mid):
                lo = mid  # 边长 mid 可行，尝试更大
            else:
                hi = mid - 1  # 边长 mid 不可行，缩小范围

        return lo
```

### 方法二：二维前缀和 + 线性扫描（不用二分）

```python
from typing import List

class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])

        # 构建二维前缀和
        prefix = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                prefix[i][j] = (mat[i - 1][j - 1]
                                + prefix[i - 1][j]
                                + prefix[i][j - 1]
                                - prefix[i - 1][j - 1])

        ans = 0

        # 枚举所有可能的正方形左上角和边长
        # 技巧：用双指针思路，先枚举正方形的右下角，再检查最大可能边长
        for i in range(m):
            for j in range(n):
                # 尝试以 (i, j) 为右下角，边长为 ans+1 的正方形是否满足条件
                k = ans + 1
                r1, c1 = i - k + 1, j - k + 1
                if r1 >= 0 and c1 >= 0:
                    rect_sum = (prefix[i + 1][j + 1]
                                - prefix[r1][j + 1]
                                - prefix[i + 1][c1]
                                + prefix[r1][c1])
                    if rect_sum <= threshold:
                        ans += 1  # 找到更大的正方形

        return ans
```

### 方法三：暴力解法（仅供理解，时间超限）

```python
from typing import List

class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])
        ans = 0

        # 枚举所有正方形
        for i in range(m):
            for j in range(n):
                for side in range(1, min(m - i, n - j) + 1):
                    # 计算以 (i, j) 为左上角，边长为 side 的正方形元素和
                    total = 0
                    for r in range(i, i + side):
                        for c in range(j, j + side):
                            total += mat[r][c]
                    if total <= threshold:
                        ans = max(ans, side)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（前缀和+二分） | O(mn * log(min(m,n))) | O(mn) |
| 方法二（前缀和+线性） | O(mn) | O(mn) |
| 方法三（暴力） | O(m^2 * n^2) | O(1) |

**方法二**时间复杂度最优，但理解稍难（利用了答案单调递增的性质，每个点只检查一次当前最优答案+1）。**方法一**逻辑更清晰，推荐掌握。

**查询边长为 3 的正方形（左上角 (1, 1)，右下角 (3, 3)）：**

```
get_sum(1, 1, 3, 3)
```

## 关键点总结

1. **二维前缀和**是解决矩形区域求和问题的标准工具，公式需要熟练掌握
2. **容斥原理**：前缀和加法时，上方和左方各被加一次，左上角被减了两次，需补回一次
3. **查询公式**：`sum(r1,c1,r2,c2) = prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]`
4. **答案具有单调性**：可行的最大边长唯一，二分查找优化枚举
5. **二分模板**：搜索满足条件的最大值，使用 `mid = (lo + hi + 1) // 2` 的上取整写法

## 易错点

- **前缀和下标偏移**：prefix 比 mat 多一行一列（全 0 的哨兵行/列），下标计算容易出错
- **二分的左右边界**：lo 初始为 0（边长为 0 一定可行），hi 为 `min(m, n)`
- **二分模板选择**：搜索最大可行值时，`mid = (lo + hi + 1) // 2`（向上取整），避免 `lo = mid` 时的死循环
