## 题目描述

给你一个整数数组 `nums`，以及整数 `k`、`op1` 和 `op2`。

操作：
- **操作 1**：可以对某个元素除以 2 并向上取整，最多执行 `op1` 次（每个元素最多用一次）。
- **操作 2**：可以对某个 >= `k` 的元素减去 `k`，最多执行 `op2` 次（每个元素最多用一次）。

返回执行操作后数组元素之和的最小值。

**提示：**
- `1 <= nums.length <= 100`
- `0 <= k <= 100`
- `0 <= op1, op2 <= nums.length`
- `0 <= nums[i] <= 100`

## 解题思路

**动态规划：**

数据范围小（n <= 100，op1/op2 <= n），可以用 DP。

`dp[i][j1][j2]` = 处理前 `i` 个元素，已使用 `j1` 次操作 1 和 `j2` 次操作 2，的最小总和。

对每个元素，可以选择：
1. 不操作。
2. 只用操作 1（ceil(nums[i] / 2)）。
3. 只用操作 2（若 nums[i] >= k，则 nums[i] - k）。
4. 先操作 1 再操作 2（ceil(nums[i]/2) - k，若可行）。
5. 先操作 2 再操作 1（ceil((nums[i]-k)/2)，若 nums[i] >= k）。

取所有可能的最小值。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List
import math

class Solution:
    def minArraySum(self, nums: List[int], k: int, op1: int, op2: int) -> int:
        n = len(nums)
        INF = float('inf')
        
        # dp[j1][j2] = 使用了 j1 次操作1 和 j2 次操作2 时的最小总和
        dp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
        dp[0][0] = 0
        
        for x in nums:
            new_dp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
            
            for j1 in range(op1 + 1):
                for j2 in range(op2 + 1):
                    if dp[j1][j2] == INF:
                        continue
                    base = dp[j1][j2]
                    
                    # 不操作
                    new_dp[j1][j2] = min(new_dp[j1][j2], base + x)
                    
                    # 只用操作 1
                    if j1 < op1:
                        new_dp[j1+1][j2] = min(new_dp[j1+1][j2], base + math.ceil(x / 2))
                    
                    # 只用操作 2（x >= k）
                    if j2 < op2 and x >= k:
                        new_dp[j1][j2+1] = min(new_dp[j1][j2+1], base + x - k)
                    
                    # 操作 1 + 操作 2
                    if j1 < op1 and j2 < op2:
                        # 先 1 后 2
                        after_op1 = math.ceil(x / 2)
                        if after_op1 >= k:
                            new_dp[j1+1][j2+1] = min(new_dp[j1+1][j2+1], base + after_op1 - k)
                        # 先 2 后 1
                        if x >= k:
                            after_op2 = x - k
                            new_dp[j1+1][j2+1] = min(new_dp[j1+1][j2+1], base + math.ceil(after_op2 / 2))
            
            dp = new_dp
        
        return min(dp[j1][j2] for j1 in range(op1+1) for j2 in range(op2+1) if dp[j1][j2] != INF)
```

## 复杂度分析

- 时间复杂度：O(n * op1 * op2)，DP
- 空间复杂度：O(op1 * op2)

## 关键点总结

1. 对每个元素，最多执行操作 1 一次、操作 2 一次（每个元素上各最多用一次）。
2. 两种操作可以组合（先 1 后 2 或先 2 后 1），需要分别计算。
3. 操作 2 要求元素 >= k，对 0 到 k-1 的元素无效。

## 易错点

1. 每个元素每种操作最多用一次（即 j1 和 j2 各增加至多 1）。
2. 操作顺序影响结果（先 1 后 2 vs 先 2 后 1 可能不同）。
3. `math.ceil(x / 2)` 等于 `(x + 1) // 2`（整数除法向上取整）。
