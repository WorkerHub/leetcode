## 题目描述

"快乐前缀" 是在原字符串中既是**非空前缀**也是**非空后缀**（两者不能相等于原字符串）的字符串。

给你一个字符串 `s`，请你返回这个字符串的**最长快乐前缀**。如果不存在满足条件的前缀，则返回一个空字符串 `""`。

**示例 1：**

```
输入：s = "level"
输出："l"
解释：不包括 s 本身，一共有 4 个前缀（"l", "le", "lev", "leve"）和 4 个后缀（"l", "el", "vel", "evel"）。
最长的既是前缀也是后缀的字符串为 "l"。
```

**示例 2：**

```
输入：s = "ababab"
输出："abab"
解释："abab" 是最长的既是前缀也是后缀的字符串。题目要注意前缀与后缀不能相等于整个字符串。
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 仅含有小写英文字母

## 解题思路

**核心思想：KMP 算法的 next 数组（失配函数）**

KMP 算法的 `next[i]` 的定义：`s[0..i]` 这个子串中，既是真前缀又是真后缀的最长字符串的长度。

**最终答案就是 `next[n-1]`**，即整个字符串 `s` 的最长公共前后缀长度。

### KMP next 数组的构建

- `next[0] = 0`（单个字符没有真前后缀）
- 对于 `i >= 1`，设 `j = next[i-1]`（上一个位置的最长公共前后缀长度）：
  - 若 `s[i] == s[j]`：`next[i] = j + 1`（可以延伸一位）
  - 若 `s[i] != s[j]`：回退 `j = next[j-1]`，直到 `j == 0` 或 `s[i] == s[j]`

### 方法二：滚动哈希

用两个方向的哈希值（前缀哈希从左到右，后缀哈希从右到左），找最长匹配长度。

## Python 代码实现

### 方法一：KMP 失配函数（推荐）

```python
class Solution:
    def longestPrefix(self, s: str) -> str:
        n = len(s)
        # next[i] 表示 s[0..i] 的最长公共真前后缀长度
        next_arr = [0] * n
        # j 是当前最长公共前后缀的长度（也是下一个待匹配的前缀位置）
        j = 0

        for i in range(1, n):
            # 当前字符不匹配，回退到上一个可能的最长公共前后缀
            while j > 0 and s[i] != s[j]:
                j = next_arr[j - 1]
            # 当前字符匹配，延伸一位
            if s[i] == s[j]:
                j += 1
            next_arr[i] = j

        # next_arr[n-1] 就是整个字符串的最长公共真前后缀长度
        length = next_arr[n - 1]
        return s[:length]
```

### 方法二：滚动哈希（Rabin-Karp）

```python
class Solution:
    def longestPrefix(self, s: str) -> str:
        n = len(s)
        MOD = (1 << 61) - 1  # 梅森素数，减少哈希冲突
        BASE = 131

        prefix_hash = 0   # 前缀哈希（从左到右）
        suffix_hash = 0   # 后缀哈希（从右到左）
        power = 1          # BASE 的幂次，用于后缀哈希的位置权重
        ans = 0

        for i in range(n - 1):
            # 前缀哈希：s[0..i]
            prefix_hash = (prefix_hash * BASE + ord(s[i])) % MOD
            # 后缀哈希：s[n-1-i..n-1]
            suffix_hash = (suffix_hash + ord(s[n - 1 - i]) * power) % MOD
            power = power * BASE % MOD

            # 两个哈希值相等，说明长度为 i+1 的前缀和后缀相同
            if prefix_hash == suffix_hash:
                ans = i + 1

        return s[:ans]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（KMP） | O(n) | O(n) |
| 方法二（滚动哈希） | O(n) | O(1) |

- KMP 方法：构建 next 数组是 O(n)，虽然有 `while` 循环，但 j 的总增量为 O(n)，退出也不超过 O(n) 次。
- 滚动哈希：只需一次遍历，空间 O(1)，但存在哈希冲突的极小概率。

## 图解示例

以 `s = "ababab"` 为例，构建 next 数组：

```
i=0, s[0]='a': next[0]=0
i=1, s[1]='b', j=0: s[1]!= s[0], next[1]=0
i=2, s[2]='a', j=0: s[2]==s[0], j=1, next[2]=1
i=3, s[3]='b', j=1: s[3]==s[1], j=2, next[3]=2
i=4, s[4]='a', j=2: s[4]==s[2], j=3, next[4]=3
i=5, s[5]='b', j=3: s[5]==s[3], j=4, next[5]=4

next = [0, 0, 1, 2, 3, 4]
答案长度 = next[5] = 4, 返回 s[:4] = "abab"
```

## 关键点总结

1. KMP 的 next 数组（失配函数）的含义：`next[i]` = `s[0..i]` 的最长公共真前后缀长度
2. 整个字符串 `s` 的最长快乐前缀长度恰好就是 `next[n-1]`
3. 构建 next 数组时，`while j > 0 and s[i] != s[j]` 这个回退操作是核心
4. 滚动哈希可以 O(1) 空间解决，但 KMP 更加经典和安全

## 易错点

- KMP 的下标细节：`next_arr[j-1]` 是回退到上一个公共前后缀的长度
- 不要把 KMP 搜索和 KMP 构建 next 数组混淆：本题只需构建 next 数组
- 哈希冲突问题：使用大素数 MOD 可以降低冲突概率，但不能完全消除
- 返回的是 `s[:length]` 而非 `length` 本身
