## 题目描述

给你一个仅由字符 `'0'` 和 `'1'` 组成的字符串 `s`。一步操作中，你可以将任一 `'0'` 变成 `'1'`，或者将任一 `'1'` 变成 `'0'`。

**交替字符串**定义：如果字符串中不存在相邻两个字符相等的情况，那么该字符串就是交替字符串。例如，`"010"` 和 `"1010"` 都是交替字符串，但 `"0100"` 不是。

请你返回将 `s` 转化为交替字符串所需的**最少**操作数。

**示例 1：**
```
输入：s = "0100"
输出：1
解释：将最后一个 '0' 变成 '1'，得到 "0101"
```

**提示：**
- `1 <= s.length <= 10^4`
- `s[i]` 是 `'0'` 或 `'1'`

## 解题思路

只有两种交替字符串：
1. `"010101..."` - 偶数位为 0，奇数位为 1
2. `"101010..."` - 偶数位为 1，奇数位为 0

统计当前字符串与这两种目标的不同字符数，取最小值。

注意：这两种不同字符数之和等于字符串长度 `n`，所以只需计算一种，另一种为 `n - cost1`。

## 代码实现

### 方法一：统计不同字符数（推荐）

```python
class Solution:
    def minOperations(self, s: str) -> int:
        n = len(s)
        # 统计与 "010101..." 的不同字符数
        cost1 = 0
        for i, c in enumerate(s):
            expected = str(i % 2)  # 偶数位应为 '0'，奇数位应为 '1'
            if c != expected:
                cost1 += 1
        
        # 另一种目标与 cost1 互补
        cost2 = n - cost1
        
        return min(cost1, cost2)
```

### 方法二：直接比较

```python
class Solution:
    def minOperations(self, s: str) -> int:
        # 目标一：以 '0' 开头的交替字符串
        target1 = ''.join('0' if i % 2 == 0 else '1' for i in range(len(s)))
        cost1 = sum(1 for a, b in zip(s, target1) if a != b)
        
        # 目标二：以 '1' 开头的交替字符串
        cost2 = len(s) - cost1
        
        return min(cost1, cost2)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只有两种目标交替字符串
2. 两种目标的不同字符数互补（和为 n）
3. 只需计算一种，取 min

## 易错点

- 字符串下标从 0 开始，偶数下标为 '0' 或 '1'（取决于选择哪种目标）
