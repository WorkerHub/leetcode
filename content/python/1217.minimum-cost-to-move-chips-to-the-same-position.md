## 题目描述

[LeetCode 1217. Minimum Cost To Move Chips To The Same Position](https://leetcode.com/problems/minimum-cost-to-move-chips-to-the-same-position/)

有 `n` 个筹码，第 `i` 个筹码的位置是 `position[i]`。

我们需要把所有筹码移动到同一个位置。在每一步中，我们可以：
- 将第 `i` 个筹码向左或向右移动 2 个单位，代价为 0
- 将第 `i` 个筹码向左或向右移动 1 个单位，代价为 1

返回将所有筹码移动到同一位置所需的最小代价。

示例 1：
```
输入：position = [1,2,3]
输出：1
解释：
第一步：将位置 3 的筹码移动到位置 1，代价为 0
第二步：将位置 2 的筹码移动到位置 1，代价为 1
总代价为 1
```

示例 2：
```
输入：position = [2,2,2,3,3]
输出：2
解释：我们可以把位置 3 的两个筹码移动到位置 2。每一步的代价为 1。总代价为 2。
```

示例 3：
```
输入：position = [1,1000000000]
输出：1
```

提示：
- 1 <= position.length <= 100
- 1 <= position[i] <= 10^9

## 解题思路

这道题的关键是理解移动规则：
- 移动 2 个单位：代价为 0
- 移动 1 个单位：代价为 1

核心观察：
1. 移动偶数个单位总是免费的（可以分解为多次移动 2 个单位）
2. 移动奇数个单位至少需要一次代价 1 的移动（一次移动 1 + 若干次移动 2）
3. 位置的奇偶性是关键：
   - 奇数位置的筹码可以免费移动到任何奇数位置
   - 偶数位置的筹码可以免费移动到任何偶数位置
   - 跨越奇偶性需要代价 1

策略：
- 统计在奇数位置和偶数位置的筹码数量
- 将少的那一组移动到多的那一组
- 最小代价 = min(奇数位置筹码数, 偶数位置筹码数)

## Python 代码实现

### 方法一：奇偶计数（推荐）

```python
from typing import List

class Solution:
    def minCostToMoveChips(self, position: List[int]) -> int:
        # 方法：统计奇数位置和偶数位置的筹码数量
        # 将数量少的一组移动到数量多的一组
        
        # 统计奇数位置和偶数位置的筹码数
        odd_count = 0  # 奇数位置的筹码数
        even_count = 0  # 偶数位置的筹码数
        
        for pos in position:
            if pos % 2 == 0:
                even_count += 1
            else:
                odd_count += 1
        
        # 移动数量少的那一组
        return min(odd_count, even_count)
```

### 方法二：使用 sum 和列表推导式（Python 特色）

```python
from typing import List

class Solution:
    def minCostToMoveChips(self, position: List[int]) -> int:
        # 方法：使用 Python 的 sum 函数统计奇数位置
        
        # 统计奇数位置的筹码数
        odd_count = sum(pos % 2 for pos in position)
        
        # 偶数位置的筹码数 = 总数 - 奇数位置数
        even_count = len(position) - odd_count
        
        return min(odd_count, even_count)
```

### 方法三：Counter 统计（更清晰）

```python
from typing import List
from collections import Counter

class Solution:
    def minCostToMoveChips(self, position: List[int]) -> int:
        # 方法：使用 Counter 统计奇偶性
        
        # 将位置转换为奇偶性（0 代表偶数，1 代表奇数）
        parity = [pos % 2 for pos in position]
        
        # 统计每种奇偶性的数量
        count = Counter(parity)
        
        # 返回较小的数量
        return min(count.get(0, 0), count.get(1, 0))
```

### 方法四：详细解释版（理解用）

```python
from typing import List

class Solution:
    def minCostToMoveChips(self, position: List[int]) -> int:
        # 方法：详细说明移动策略
        
        # 第一步：统计奇数和偶数位置的筹码
        odd_positions = []
        even_positions = []
        
        for pos in position:
            if pos % 2 == 0:
                even_positions.append(pos)
            else:
                odd_positions.append(pos)
        
        # 第二步：确定移动策略
        # 如果奇数位置筹码更多，将偶数位置筹码移动到奇数位置
        # 如果偶数位置筹码更多，将奇数位置筹码移动到偶数位置
        
        odd_count = len(odd_positions)
        even_count = len(even_positions)
        
        # 移动数量少的那一组，每个筹码代价为 1
        if odd_count < even_count:
            # 将所有奇数位置筹码移动到任一偶数位置
            return odd_count
        else:
            # 将所有偶数位置筹码移动到任一奇数位置
            return even_count
```

### 所有方法
- 时间复杂度：O(n)，需要遍历一次 position 数组
- 空间复杂度：O(1)，只使用常数额外空间

```
策略：将偶数位置的筹码移动到奇数位置
- 位置 2 的筹码移动 1 步到位置 1 或 3，代价 = 1
```

```
- 每个奇数位置的筹码移动 1 步，代价 = 2
```

## 关键点总结

1. 核心洞察：移动 2 步代价为 0，所以奇偶性决定了移动代价
2. 相同奇偶性的位置之间可以零代价移动
3. 跨越奇偶性需要至少 1 次移动 1 步的操作
4. 贪心策略：将数量少的一组移动到数量多的一组
5. 与具体位置无关，只与奇偶性有关

## 易错点

1. 误以为需要考虑具体位置，实际上只需要考虑奇偶性
2. 忘记移动 2 步是免费的这个关键信息
3. 试图找到最优目标位置，实际上任意同奇偶性位置都可以
4. 计算复杂的移动路径，实际上只需要统计数量即可
5. 没有理解奇数位置和偶数位置之间的移动代价
