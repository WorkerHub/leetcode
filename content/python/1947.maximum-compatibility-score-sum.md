## 题目描述

有一份由 `n` 个问题组成的调查问卷，每个问题答案为 0 或 1。

给你一个二维整数数组 `students` 和 `mentors`，`students[i]` 和 `mentors[j]` 分别是第 `i` 个学生和第 `j` 个导师的答案列表。

**兼容性得分**是两人答案相同的问题数量。每个导师只能匹配一个学生，每个学生只能匹配一个导师。

返回所有匹配的**最大兼容性得分之和**。

**示例 1：**
```
输入：students = [[1,1,0],[1,0,1],[0,0,1]], mentors = [[1,0,0],[0,0,1],[1,1,0]]
输出：8
解释：学生 0 与导师 2 配对（得分 3），学生 1 与导师 0 配对（得分 2），学生 2 与导师 1 配对（得分 3）
```

**提示：**
- `m == students.length == mentors.length`，`1 <= m <= 8`
- `n == students[i].length == mentors[j].length`，`1 <= n <= 8`

---

## 解题思路

### 核心思想：状态压缩 DP

由于 `m <= 8`，可以用 `2^m` 的状态压缩 DP：

`dp[mask]` = 已经安排了 `mask` 中为 1 的导师（即安排了 `popcount(mask)` 个学生）时的最大得分。

遍历顺序：从小 mask 到大 mask，对每个 mask 枚举最后加入的导师。

也可以用回溯枚举所有全排列，由于 m ≤ 8，全排列最多 8! = 40320 种。

---

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def maxCompatibilitySum(self, students: List[List[int]], mentors: List[List[int]]) -> int:
        m = len(students)
        n = len(students[0])

        # 预计算兼容性得分矩阵
        score = [[0] * m for _ in range(m)]
        for i in range(m):
            for j in range(m):
                score[i][j] = sum(a == b for a, b in zip(students[i], mentors[j]))

        # dp[mask] = 导师 mask 已被分配时的最大得分
        # 第 k 个学生（mask 中第 k 个 1 对应的学生）
        dp = [0] * (1 << m)

        for mask in range(1, 1 << m):
            # 当前已分配的学生索引 = popcount(mask) - 1
            student_idx = bin(mask).count('1') - 1
            # 枚举最后加入的导师
            for j in range(m):
                if mask & (1 << j):
                    # 导师 j 被当前 mask 分配，前一状态为 mask ^ (1 << j)
                    prev_mask = mask ^ (1 << j)
                    dp[mask] = max(dp[mask], dp[prev_mask] + score[student_idx][j])

        return dp[(1 << m) - 1]
```

### 方法二：回溯枚举全排列

```python
from typing import List

class Solution:
    def maxCompatibilitySum(self, students: List[List[int]], mentors: List[List[int]]) -> int:
        m = len(students)
        n = len(students[0])

        # 预计算兼容性得分
        score = [[sum(a == b for a, b in zip(students[i], mentors[j]))
                  for j in range(m)] for i in range(m)]

        used = [False] * m
        self.best = 0

        def backtrack(student: int, cur_score: int):
            if student == m:
                self.best = max(self.best, cur_score)
                return
            for j in range(m):
                if not used[j]:
                    used[j] = True
                    backtrack(student + 1, cur_score + score[student][j])
                    used[j] = False

        backtrack(0, 0)
        return self.best
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 状态压缩 DP | O(m² * 2^m) | O(2^m) |
| 回溯 | O(m!) | O(m) |

---

## 关键点总结

1. m ≤ 8，两种方法都可行（回溯 8! = 40320，DP 8 * 256 = 2048）
2. 状态压缩 DP 中，mask 的 popcount 表示已安排的学生数
3. 预计算兼容性矩阵避免重复计算

---

## 易错点

- DP 中 `student_idx = popcount(mask) - 1`（0-indexed 学生）
- 回溯中注意 `used` 数组回溯时需要恢复
