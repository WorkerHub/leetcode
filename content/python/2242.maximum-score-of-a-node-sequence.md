## 题目描述

给你一个无向图，`n` 个节点（下标 0 到 n-1），`scores[i]` 是节点 `i` 的分数。

另有一个二维整数数组 `edges`，`edges[j] = [ai, bi]`，表示节点 `ai` 和 `bi` 之间有一条无向边。

**节点序列的分数**：选择 4 个节点 `a, b, c, d`，使得 `(a,b)`, `(b,c)`, `(c,d)` 都是图中的边（即形成一条路径），且 4 个节点互不相同。分数 = `scores[a] + scores[b] + scores[c] + scores[d]`。

返回所有满足条件的节点序列的最大分数，若不存在返回 -1。

**提示：**
- `n <= 5 * 10^4`
- `edges.length <= 5 * 10^4`

## 解题思路

枚举中间的边 `(b, c)`，对于每条边，分别在 `b` 的邻居中找两个分数最大且不等于 c 的节点，在 `c` 的邻居中找两个分数最大且不等于 b 的节点，再选出不重复的最大组合。

**优化：** 对每个节点只保留分数最大的 3 个邻居（因为选 `a != c` 且 `d != b` 且 `a != d`，最多需要 3 个候选）。

**枚举边 (b,c)**，对每条边：
- 从 b 的 top-3 邻居中选一个不等于 c 的（作为 a）
- 从 c 的 top-3 邻居中选一个不等于 b 的（作为 d），且 a != d
- 枚举所有组合取最大。

## 代码实现

### 方法一：保留 top-3 邻居 + 枚举边（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumScore(self, scores: List[int], edges: List[List[int]]) -> int:
        n = len(scores)
        # 对每个节点，保留分数最大的 top-3 邻居
        top3 = defaultdict(list)

        for u, v in edges:
            top3[u].append(v)
            top3[v].append(u)

        # 对每个节点的邻居按分数降序，只保留前3个
        for node in range(n):
            top3[node].sort(key=lambda x: -scores[x])
            top3[node] = top3[node][:3]

        ans = -1

        # 枚举每条边 (b, c)
        for b, c in edges:
            # 从 b 的 top-3 邻居选 a（a != c）
            # 从 c 的 top-3 邻居选 d（d != b, d != a）
            for a in top3[b]:
                if a == c:
                    continue
                for d in top3[c]:
                    if d == b or d == a:
                        continue
                    total = scores[a] + scores[b] + scores[c] + scores[d]
                    ans = max(ans, total)

        return ans
```

### 方法二：同上，优化边界

```python
from typing import List

class Solution:
    def maximumScore(self, scores: List[int], edges: List[List[int]]) -> int:
        n = len(scores)
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 每个节点保留分数前3的邻居
        for i in range(n):
            adj[i].sort(key=lambda x: -scores[x])
            adj[i] = adj[i][:3]

        ans = -1
        for u, v in edges:
            for a in adj[u]:
                if a == v:
                    continue
                for b in adj[v]:
                    if b != u and b != a:
                        ans = max(ans, scores[a] + scores[u] + scores[v] + scores[b])

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + m) log n + m * 9) = O(m log n)，排序邻居 + 枚举边（每边 9 次比较）。
- 空间复杂度：O(n + m)，邻接表。

## 关键点总结

1. 只保留每个节点 top-3 分数的邻居，因为 4 个节点互不相同，最多需要 3 个候选。
2. 枚举中间边，从两端各选最大合法邻居。
3. 保留 3 个（而不是 2 个）是为了应对两端节点相同的情况（a != d）。

## 易错点

- 保留 top-3 而非 top-2，因为选 a 时需要跳过 c，选 d 时需要跳过 b 和 a。
- 4 个节点严格互不相同。
