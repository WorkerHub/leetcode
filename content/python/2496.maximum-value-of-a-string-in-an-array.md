## 题目描述

给你一个字符串数组 `strs`，每个字符串要么全是数字，要么全是小写字母（不混合）。

字符串的 **值** 定义：
- 若字符串全是数字，则值为该字符串的整数值
- 若字符串全是字母，则值为字符串的长度

返回字符串数组中的最大值。

**提示：**
- `1 <= strs.length <= 100`
- `1 <= strs[i].length <= 9`
- `strs[i]` 只包含小写英文字母或数字字符

## 解题思路

**直接模拟：**

遍历数组，对每个字符串判断类型：
- 若是数字字符串，值 = `int(s)`
- 若是字母字符串，值 = `len(s)`

取所有值的最大值。

## 代码实现

### 方法一：遍历判断（推荐）

```python
from typing import List

class Solution:
    def maximumValue(self, strs: List[str]) -> int:
        ans = 0
        for s in strs:
            if s.isdigit():
                val = int(s)
            else:
                val = len(s)
            ans = max(ans, val)
        return ans
```

### 方法二：使用辅助函数

```python
from typing import List

class Solution:
    def maximumValue(self, strs: List[str]) -> int:
        def value(s):
            return int(s) if s.isdigit() else len(s)

        return max(value(s) for s in strs)
```

### 方法三：try-except

```python
from typing import List

class Solution:
    def maximumValue(self, strs: List[str]) -> int:
        ans = 0
        for s in strs:
            try:
                val = int(s)
            except ValueError:
                val = len(s)
            ans = max(ans, val)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 遍历判断 | O(n * L)（L 为最长字符串长度） | O(1) |

## 关键点总结

1. `str.isdigit()` 判断字符串是否全为数字
2. 数字字符串的值是其整数值，字母字符串的值是其长度
3. Python 的 `int()` 可以直接转换数字字符串

## 易错点

- 题目说明字符串不混合（要么全数字要么全字母），不需要处理混合情况
