## 题目描述

给你一个字符串 `s`，返回 `s` 中**长度为 3 的不同回文子序列**的数量。

**注意：** 即使有多种方法得到相同的子序列，也只计算一次。

一个**回文**字符串，正着读和反着读一样。

**示例 1：**
```
输入：s = "aabca"
输出：3
解释：长度为 3 的回文子序列为 "aba"、"aaa"、"aca"
```

**示例 2：**
```
输入：s = "adc"
输出：0
```

**示例 3：**
```
输入：s = "bbcbaba"
输出：4
解释："bbb"、"bcb"、"bab"、"aba"
```

**提示：**
- `3 <= s.length <= 10^5`
- `s` 只包含小写英文字母

---

## 解题思路

### 核心思想：枚举回文的首尾字符

长度为 3 的回文形如 `a_a`（首尾相同），因此：

对每个字母 `c`（'a' 到 'z'）：
- 找 `c` 在字符串中最左出现位置 `left` 和最右出现位置 `right`
- `left` 和 `right` 之间（不含端点）出现的**不同字符种数**，就是以 `c` 为首尾的不同长度 3 回文子序列数

统计所有字母的结果之和即为答案。

**优化：** 用前缀计数数组快速统计区间内不同字符种类。

## 代码实现

### 方法一：枚举首尾字符 + 集合（推荐）

```python
class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        result = 0

        for c in 'abcdefghijklmnopqrstuvwxyz':
            # 找字符 c 的最左和最右位置
            left = s.find(c)
            right = s.rfind(c)
            if left == -1 or left == right:
                # c 不存在或只出现一次，无法构成回文
                continue
            # 统计 left 和 right 之间出现的不同字符数
            middle_chars = set(s[left + 1:right])
            result += len(middle_chars)

        return result
```

### 方法二：前缀和计数（O(26n) 但常数更小）

```python
class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        n = len(s)
        # prefix[i][c] = s[0..i-1] 中字符 c 的出现次数
        prefix = [[0] * 26 for _ in range(n + 1)]

        for i, ch in enumerate(s):
            prefix[i + 1] = prefix[i][:]
            prefix[i + 1][ord(ch) - ord('a')] += 1

        result = 0
        for c in range(26):
            ch = chr(c + ord('a'))
            left = s.find(ch)
            right = s.rfind(ch)
            if left == -1 or left == right:
                continue
            # 统计 (left, right) 开区间内出现的不同字符种类
            for m in range(26):
                count = prefix[right][m] - prefix[left + 1][m]
                if count > 0:
                    result += 1

        return result
```

### 方法三：位运算优化（更紧凑）

```python
class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        n = len(s)
        # 每个字符最左和最右位置
        first = {}
        last = {}
        for i, c in enumerate(s):
            if c not in first:
                first[c] = i
            last[c] = i

        result = 0
        for c in first:
            l, r = first[c], last[c]
            if l < r:
                # 用集合统计中间字符
                result += len(set(s[l+1:r]))

        return result
```

| 方法三 | O(26n) | O(26) |

## 关键点总结

1. 长度 3 的回文只有首尾相同的 `a_a` 形式
2. 枚举 26 个字母作为首尾，统计中间的不同字符种数
3. `s.find(c)` 找最左位置，`s.rfind(c)` 找最右位置

---

## 易错点

- 若某字符只出现一次（`left == right`），无法构成 3 长度回文，需跳过
- 中间部分是**开区间** `(left, right)`，不含端点
