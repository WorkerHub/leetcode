## 题目描述

在本问题中，有根树指满足以下条件的有向图：
- 树中每个节点只有一个父节点，除了根节点没有父节点
- 树中所有节点都从根节点可达

但是，现在这棵有根树被破坏了，添加了一条额外的边。请找到并返回这条边。如果有多个答案，返回最后出现在数组中的边。

**示例 1：**
```
输入：edges = [[1,2],[1,3],[2,3]]
输出：[2,3]
```

**示例 2：**
```
输入：edges = [[1,2],[2,3],[3,4],[4,1],[1,5]]
输出：[4,1]
```

## 解题思路

有向树的冗余边有三种情况：
1. 某个节点有两个父节点
2. 形成环但没有节点有两个父节点
3. 某个节点有两个父节点且形成环

## Python 代码实现

### 方法一：并查集

```python
from typing import List

class Solution:
    def findRedundantDirectedConnection(self, edges: List[List[int]]) -> List[int]:
        n = len(edges)
        parent = list(range(n + 1))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False
            parent[root_x] = root_y
            return True
        
        # 找到有两个父节点的节点
        in_degree = {}
        candidate1 = candidate2 = None
        
        for u, v in edges:
            if v in in_degree:
                candidate1 = [in_degree[v], v]
                candidate2 = [u, v]
                break
            in_degree[v] = u
        
        # 情况1：如果没有节点有两个父节点，直接找环
        if not candidate2:
            for u, v in edges:
                if not union(u, v):
                    return [u, v]
        
        # 情况2：有节点有两个父节点
        # 先尝试删除 candidate2
        parent = list(range(n + 1))
        for u, v in edges:
            if [u, v] == candidate2:
                continue
            if not union(u, v):
                return candidate1
        
        return candidate2
```

## 复杂度分析

- 时间复杂度：O(n * α(n))
- 空间复杂度：O(n)

## 关键点总结

1. 区分有向图和无向图的环检测
2. 处理节点有两个父节点的情况
3. 使用并查集检测环
