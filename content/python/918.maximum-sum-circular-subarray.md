## 题目描述

给定一个长度为 `n` 的**环形整数数组** `nums`，返回 *`nums` 的非空 **子数组** 的最大可能和*。

**环形数组** 意味着数组的末端将会与开头相连呈环状。形式上，`nums[i]` 的下一个元素是 `nums[(i + 1) % n]`，`nums[i]` 的前一个元素是 `nums[(i - 1 + n) % n]`。

**子数组** 最多只能包含固定缓冲区 `nums` 中的每个元素一次。形式上，对于子数组 `nums[i], nums[i + 1], ..., nums[j]`，不存在 `i <= k1, k2 <= j` 其中 `k1 % n == k2 % n`。

**示例 1：**
```
输入：nums = [1,-2,3,-2]
输出：3
解释：从子数组 [3] 得到最大和 3
```

**示例 2：**
```
输入：nums = [5,-3,5]
输出：10
解释：从子数组 [5,5] 得到最大和 5 + 5 = 10
```

**示例 3：**
```
输入：nums = [-3,-2,-3]
输出：-2
解释：从子数组 [-2] 得到最大和 -2
```

**提示：**
- `n == nums.length`
- `1 <= n <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`

## 解题思路

环形数组的最大子数组和有两种情况：

**情况 1：最大子数组不跨越边界**
- 这种情况和普通的最大子数组和问题相同
- 使用 Kadane 算法求解

**情况 2：最大子数组跨越边界**
- 跨越边界意味着从数组末尾到开头
- 可以转化为：总和 - 最小子数组和
- 因为最大跨越和 = 总和 - 中间未选部分的和
- 中间未选部分的和最小时，跨越和最大

**算法步骤：**
1. 使用 Kadane 算法求最大子数组和（情况1）
2. 使用 Kadane 算法求最小子数组和
3. 计算跨越边界的最大和 = 总和 - 最小子数组和（情况2）
4. 返回两种情况的最大值

**特殊情况：**
- 如果所有数都是负数，最小子数组和就是总和
- 此时跨越边界的和为 0（选空数组），不符合题意
- 因此如果最大和 < 0，直接返回最大和

## Python 代码实现

### 方法一：Kadane 算法（推荐 ⭐）

```python
from typing import List

class Solution:
    def maxSubarraySumCircular(self, nums: List[int]) -> int:
        def kadane_max(arr):
            """Kadane 算法求最大子数组和"""
            max_sum = arr[0]
            current_sum = arr[0]
            
            for num in arr[1:]:
                current_sum = max(num, current_sum + num)
                max_sum = max(max_sum, current_sum)
            
            return max_sum
        
        def kadane_min(arr):
            """Kadane 算法求最小子数组和"""
            min_sum = arr[0]
            current_sum = arr[0]
            
            for num in arr[1:]:
                current_sum = min(num, current_sum + num)
                min_sum = min(min_sum, current_sum)
            
            return min_sum
        
        # 情况1：最大子数组不跨越边界
        max_kadane = kadane_max(nums)
        
        # 情况2：最大子数组跨越边界
        # 跨越边界的最大和 = 总和 - 最小子数组和
        total_sum = sum(nums)
        min_kadane = kadane_min(nums)
        max_circular = total_sum - min_kadane
        
        # 特殊情况：所有数都是负数
        # 此时 max_circular = 0，应该返回 max_kadane
        if max_kadane < 0:
            return max_kadane
        
        return max(max_kadane, max_circular)
```

### 方法二：一次遍历优化

```python
from typing import List

class Solution:
    def maxSubarraySumCircular(self, nums: List[int]) -> int:
        total_sum = 0
        max_sum = nums[0]  # 最大子数组和
        min_sum = nums[0]  # 最小子数组和
        current_max = 0    # 当前最大和
        current_min = 0    # 当前最小和
        
        for num in nums:
            # 更新总和
            total_sum += num
            
            # Kadane 算法求最大子数组和
            current_max = max(current_max + num, num)
            max_sum = max(max_sum, current_max)
            
            # Kadane 算法求最小子数组和
            current_min = min(current_min + num, num)
            min_sum = min(min_sum, current_min)
        
        # 如果所有数都是负数，返回最大值
        if max_sum < 0:
            return max_sum
        
        # 返回两种情况的最大值
        return max(max_sum, total_sum - min_sum)
```

### 方法三：详细注释版

```python
from typing import List

class Solution:
    def maxSubarraySumCircular(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 计算普通最大子数组和
        max_ending_here = nums[0]
        max_so_far = nums[0]
        
        # 计算普通最小子数组和
        min_ending_here = nums[0]
        min_so_far = nums[0]
        
        # 计算总和
        total_sum = nums[0]
        
        for i in range(1, n):
            total_sum += nums[i]
            
            # 更新最大子数组和
            max_ending_here = max(nums[i], max_ending_here + nums[i])
            max_so_far = max(max_so_far, max_ending_here)
            
            # 更新最小子数组和
            min_ending_here = min(nums[i], min_ending_here + nums[i])
            min_so_far = min(min_so_far, min_ending_here)
        
        # 情况1：最大子数组在中间（不跨越边界）
        # 情况2：最大子数组跨越边界（总和 - 最小子数组）
        
        # 如果所有元素都是负数，min_so_far = total_sum
        # 此时 total_sum - min_so_far = 0，但题目要求非空子数组
        # 所以返回 max_so_far（最大的负数）
        if max_so_far < 0:
            return max_so_far
        
        # 返回两种情况的最大值
        return max(max_so_far, total_sum - min_so_far)
```

## 复杂度分析

**时间复杂度：** O(n)
- 只需要遍历数组一次或两次

**空间复杂度：** O(1)
- 只使用常数额外空间

## 关键点总结

1. **两种情况**：子数组跨越边界或不跨越边界
2. **问题转化**：跨越边界 = 总和 - 最小子数组和
3. **Kadane 算法**：求最大/最小子数组和的经典算法
4. **特殊情况**：所有数为负数时的处理
5. **一次遍历**：可以同时计算最大和最小子数组和

## 易错点

1. **忘记特殊情况**：所有数为负数时，不能返回 0
2. **理解跨越**：跨越边界的和等于总和减去中间的最小和
3. **Kadane 算法**：要正确实现 Kadane 算法
4. **初始化**：max_sum 和 min_sum 要初始化为第一个元素
5. **非空子数组**：题目要求非空，所以不能全部不选

## 图解示例

示例 2：`nums = [5,-3,5]`

```
情况1：不跨越边界
[5], [-3], [5], [5,-3], [-3,5], [5,-3,5]
最大和 = max(5, -3, 5, 2, 2, 7) = 7

情况2：跨越边界
总和 = 5 + (-3) + 5 = 7
最小子数组和 = -3
跨越边界的最大和 = 7 - (-3) = 10

对应子数组：[5] + [5] = [5, ..., 5]（跨越中间）

答案：max(7, 10) = 10
```
