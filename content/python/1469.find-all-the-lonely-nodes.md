## 题目描述

给你一棵二叉树的根节点 `root`，请你返回所有**孤独节点**的值所构成的列表。

**孤独节点**是指该节点是其父节点的唯一子节点，即它的父节点没有两个子节点。节点的顺序不限。

**示例 1：**

```
输入：root = [1,2,3,null,4]
输出：[4]
解释：节点 4 是节点 2 的唯一子节点，所以是孤独节点。
```

**示例 2：**

```
输入：root = [7,1,4,6,null,5,3,null,null,null,null,null,2]
输出：[6, 2]
```

**示例 3：**

```
输入：root = [11,99,88,77,null,null,66,55,null,null,44,33,null,null,22]
输出：[77, 55, 33, 66, 44, 22]
```

**提示：**
- 树中节点个数在 `[1, 500]` 范围内
- 节点值的范围是 `[1, 10^6]`

---

## 解题思路

**核心思想：** 孤独节点 = 父节点只有一个子节点的那个子节点。

**判断方法：**
- 在遍历树的过程中，检查每个节点的左右子节点情况：
  - 如果只有左子节点（没有右子节点），左子节点是孤独节点
  - 如果只有右子节点（没有左子节点），右子节点是孤独节点
  - 如果左右子节点都有，两个都不是孤独节点

可以用深度优先搜索（DFS）或广度优先搜索（BFS）遍历树。

## Python 代码实现

### 方法一：深度优先搜索 DFS（推荐）

```python
from typing import List, Optional

# 定义二叉树节点
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def getLonelyNodes(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                return

            # 只有左子节点，左子节点是孤独节点
            if node.left and not node.right:
                result.append(node.left.val)

            # 只有右子节点，右子节点是孤独节点
            if node.right and not node.left:
                result.append(node.right.val)

            # 继续递归遍历左右子树
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return result
```

### 方法二：广度优先搜索 BFS（层序遍历）

```python
from typing import List, Optional
from collections import deque

class Solution:
    def getLonelyNodes(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        result = []
        queue = deque([root])  # 用队列实现 BFS

        while queue:
            node = queue.popleft()

            # 只有左子节点，左子节点是孤独节点
            if node.left and not node.right:
                result.append(node.left.val)

            # 只有右子节点，右子节点是孤独节点
            if node.right and not node.left:
                result.append(node.right.val)

            # 将子节点加入队列
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        return result
```

### 方法三：递归返回列表（函数式风格）

```python
from typing import List, Optional

class Solution:
    def getLonelyNodes(self, root: Optional[TreeNode]) -> List[int]:
        def dfs(node: Optional[TreeNode]) -> List[int]:
            if not node:
                return []

            lonely = []

            # 只有左子节点
            if node.left and not node.right:
                lonely.append(node.left.val)

            # 只有右子节点
            if node.right and not node.left:
                lonely.append(node.right.val)

            # 合并左右子树的结果
            return lonely + dfs(node.left) + dfs(node.right)

        return dfs(root)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS（递归） | O(n) | O(h)，h 为树高 |
| BFS（队列） | O(n) | O(w)，w 为树的最大宽度 |

- **时间复杂度 O(n)**：每个节点恰好访问一次。
- **空间复杂度**：DFS 递归栈深度为树高 h（最坏 O(n)，平衡树 O(log n)）；BFS 队列最多存储一层节点。

## 关键点总结

1. 孤独节点的定义：父节点只有一个子节点。
2. 判断方法：在父节点处检查是否只有一侧子节点存在。
3. DFS 和 BFS 都适用，DFS 代码更简洁。
4. 根节点本身不算孤独节点（题目没有父节点的概念）。
5. 遍历时在父节点处判断，不在子节点处判断。

---

## 易错点

- **误判根节点**：根节点没有父节点，不可能是孤独节点，但代码自然不会处理它（因为我们总在父节点处判断子节点）。
- **两侧都有子节点时忘记递归**：即使父节点两侧都有子节点（不是孤独节点），也需要继续递归遍历子树。
- **空节点处理**：需要判断 `not node` 的情况直接返回。
