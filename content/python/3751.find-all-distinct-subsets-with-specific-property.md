## 题目描述

给定整数数组 `nums` 和整数 `k`，找出所有满足以下条件的不重复子集：
- 子集中所有元素之和等于 `k`
- 子集中元素各不相同（即每个元素只使用一次）

返回所有满足条件的子集，子集内元素按非递减顺序排列，结果不包含重复子集。

**示例 1：**
```
输入：nums = [1,2,3], k = 3
输出：[[1,2],[3]]
解释：和为 3 的子集：{1,2} 和 {3}。
```

**示例 2：**
```
输入：nums = [2,3,6,7], k = 7
输出：[[7],[3,2,2] -> 2不重复] -> [[7]]
     等等，nums=[2,3,6,7]: {7}=7, {2,3,..}=7? 2+3+2=不行（只能用一次）... 
     {7}=7, 和为 7 的其他子集？不存在。输出 [[7]]。
```

**提示：**
- `1 <= nums.length <= 20`
- `1 <= nums[i] <= 30`
- `1 <= k <= 150`
- `nums` 可能有重复元素

## 解题思路

回溯 + 去重（类似 LeetCode 40 Combination Sum II）。

先排序，然后回溯枚举所有子集：
- 剪枝：当前和已超过 k 时停止
- 去重：同一层递归中，相同的数字只选一次（跳过重复元素）

## Python 代码实现

### 方法一：回溯（推荐）

```python
from typing import List

class Solution:
    def findSubsets(self, nums: List[int], k: int) -> List[List[int]]:
        nums.sort()
        result = []

        def backtrack(start: int, current: List[int], remaining: int) -> None:
            if remaining == 0:
                result.append(current[:])
                return
            for i in range(start, len(nums)):
                if nums[i] > remaining:
                    break  # 排序后后面更大，剪枝
                if i > start and nums[i] == nums[i-1]:
                    continue  # 跳过同层重复元素
                current.append(nums[i])
                backtrack(i + 1, current, remaining - nums[i])
                current.pop()

        backtrack(0, [], k)
        return result
```

### 方法二：哈希集合去重

```python
from typing import List

class Solution:
    def findSubsets(self, nums: List[int], k: int) -> List[List[int]]:
        nums.sort()
        result = set()

        def backtrack(start: int, current: tuple, remaining: int) -> None:
            if remaining == 0:
                result.add(current)
                return
            for i in range(start, len(nums)):
                if nums[i] > remaining:
                    break
                backtrack(i + 1, current + (nums[i],), remaining - nums[i])

        backtrack(0, (), k)
        return [list(s) for s in result]
```

## 复杂度分析

- 时间复杂度：O(2^n)，最坏情况枚举所有子集
- 空间复杂度：O(n)，递归栈深度

## 关键点总结

1. 排序 + 回溯是解决"组合求和"问题的标准模式
2. 同层跳过重复元素：`if i > start and nums[i] == nums[i-1]: continue`
3. 排序后可以提前剪枝（当前元素超过剩余值）

## 易错点

1. 去重条件是 `i > start`（同一层），而非 `i > 0`
2. 子集内不重复使用同一元素：每次从 `i+1` 开始递归
