## 题目描述

你正在把积木堆成金字塔。每个块都有一个颜色，用一个字母表示。每一行的块比它下面的行少一个块，并且居中。

为了让金字塔美观，只有特定的三角形可以被允许。一个三角形的形式是 `ABC`，表示你可以把 `C` 放在 `A` 和 `B` 上面。

你从底部的一行开始，表示为一个字符串 `bottom`，其中每个字符代表该行中的块的颜色。

你还会得到一个字符串列表 `allowed`。`allowed[i]` 的形式是 `XYZ`，表示你可以把 `Z` 块放在 `X` 和 `Y` 块上面。

如果你可以按照这些规则建造金字塔一直到顶部，返回 `true`。否则，返回 `false`。

**示例 1:**
```
输入: bottom = "BCD", allowed = ["BCC","CDE","CEA","FFF"]
输出: true
解释:
允许的三角形有:
    BCC
    CDE
    CEA
    FFF

金字塔可以这样构建:
    A
   C E
  B C D

另一种有效的方式:
    E
   D E
  B C D
```

**示例 2:**
```
输入: bottom = "AAAA", allowed = ["AAB","AAC","BCD","BBE","DEF"]
输出: false
解释:
无法构建一个金字塔。
```

**提示：**
- `2 <= bottom.length <= 6`
- `0 <= allowed.length <= 216`
- `allowed[i].length == 3`
- 所有字符串中的字母都在 `{'A', 'B', 'C', 'D', 'E', 'F', 'G'}` 中

## 解题思路

这是一个典型的回溯问题。我们需要逐层构建金字塔，每一层都基于下一层。

**核心思想：**
1. 从底层开始，逐层向上构建
2. 对于每一对相邻的块，尝试所有可能的上层块
3. 使用回溯法探索所有可能的构建方式
4. 如果能构建到顶部（只有一个块），返回 true

**优化策略：**
1. 预处理 allowed 数组，构建映射表
2. 使用位运算优化状态存储
3. 使用记忆化避免重复计算

## Python 代码实现

### 方法一：回溯 + 哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        # 构建映射：(left, right) -> [可能的上层块]
        mapping = defaultdict(list)
        for triple in allowed:
            mapping[(triple[0], triple[1])].append(triple[2])
        
        def build_level(current_level, next_level, pos):
            """
            尝试构建下一层
            current_level: 当前层的字符串
            next_level: 正在构建的下一层
            pos: 当前处理的位置
            """
            # 如果当前层只有一个块，成功
            if len(current_level) == 1:
                return True
            
            # 如果下一层构建完成，递归构建更上一层
            if pos == len(current_level) - 1:
                return build_level(next_level, "", 0)
            
            # 尝试所有可能的上层块
            left = current_level[pos]
            right = current_level[pos + 1]
            
            for top in mapping[(left, right)]:
                # 在下一层添加这个块，继续构建
                if build_level(current_level, next_level + top, pos + 1):
                    return True
            
            return False
        
        return build_level(bottom, "", 0)
```

### 方法二：BFS + 位运算优化

```python
from collections import deque

class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        # 使用位运算优化存储
        # 将每个三元组编码为一个整数
        mapping = defaultdict(int)
        for triple in allowed:
            base = (ord(triple[0]) - ord('A')) * 7 + (ord(triple[1]) - ord('A'))
            top_bit = 1 << (ord(triple[2]) - ord('A'))
            mapping[base] |= top_bit
        
        def get_possible_tops(left, right):
            """获取可能的上层块（使用位运算）"""
            base = (ord(left) - ord('A')) * 7 + (ord(right) - ord('A'))
            bits = mapping[base]
            result = []
            for i in range(7):
                if bits & (1 << i):
                    result.append(chr(ord('A') + i))
            return result
        
        def build_next_level(current):
            """从当前层构建所有可能的下一层"""
            if len(current) == 1:
                return [current]
            
            def backtrack(pos, path):
                if pos == len(current) - 1:
                    return [path]
                
                results = []
                for top in get_possible_tops(current[pos], current[pos + 1]):
                    results.extend(backtrack(pos + 1, path + top))
                return results
            
            return backtrack(0, "")
        
        # BFS
        queue = deque([bottom])
        
        while queue:
            current = queue.popleft()
            
            if len(current) == 1:
                return True
            
            next_levels = build_next_level(current)
            queue.extend(next_levels)
        
        return False
```

### 方法三：DFS + 记忆化

```python
class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        # 构建映射
        mapping = defaultdict(list)
        for triple in allowed:
            mapping[triple[:2]].append(triple[2])
        
        # 记忆化
        memo = {}
        
        def dfs(current):
            """
            检查是否可以从当前层构建到顶部
            """
            if len(current) == 1:
                return True
            
            if current in memo:
                return memo[current]
            
            # 尝试构建下一层
            def build_next(pos, next_level):
                if pos == len(current) - 1:
                    # 下一层构建完成，递归检查
                    return dfs(next_level)
                
                # 尝试所有可能的块
                for top in mapping[current[pos:pos+2]]:
                    if build_next(pos + 1, next_level + top):
                        return True
                return False
            
            result = build_next(0, "")
            memo[current] = result
            return result
        
        return dfs(bottom)
```

### 方法四：详细注释版（易理解）

```python
class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        # 步骤 1: 预处理 allowed，构建查找表
        # 键: (左块, 右块)，值: 可以放在上面的块的列表
        rules = defaultdict(list)
        for rule in allowed:
            left_block = rule[0]
            right_block = rule[1]
            top_block = rule[2]
            rules[(left_block, right_block)].append(top_block)
        
        def can_build(current_row):
            """
            判断是否可以从当前行构建到金字塔顶部
            
            参数:
                current_row: 当前行的字符串
            
            返回:
                True 如果可以构建到顶部，否则 False
            """
            # 基本情况: 如果只剩一个块，说明到达顶部
            if len(current_row) == 1:
                return True
            
            # 尝试构建下一行
            # 下一行的长度比当前行少 1
            def try_build_next_row(position, next_row_so_far):
                """
                尝试构建下一行
                
                参数:
                    position: 当前处理到 current_row 的第几对
                    next_row_so_far: 已经构建的下一行的部分
                """
                # 如果所有对都处理完了，下一行构建完成
                if position == len(current_row) - 1:
                    # 递归检查能否从下一行继续构建
                    return can_build(next_row_so_far)
                
                # 获取当前对的左右块
                left = current_row[position]
                right = current_row[position + 1]
                
                # 查找可以放在这对上面的所有块
                possible_tops = rules.get((left, right), [])
                
                # 尝试每一个可能的上层块
                for top in possible_tops:
                    # 递归尝试下一对
                    if try_build_next_row(position + 1, next_row_so_far + top):
                        return True
                
                # 所有可能都试过了，都不行
                return False
            
            # 从第 0 对开始构建下一行
            return try_build_next_row(0, "")
        
        # 从底部开始构建
        return can_build(bottom)
```

## 复杂度分析

- **时间复杂度：** O(A^L)，其中 A 是字母表大小（最多 7），L 是底部字符串长度。最坏情况下需要尝试所有可能的金字塔。
- **空间复杂度：** O(L^2)，递归深度为 L，每层需要存储字符串。

## 关键点总结

1. **映射表构建：** 预处理 allowed 数组，快速查找可能的上层块
2. **回溯框架：** 逐层构建，每层尝试所有可能性
3. **递归结构：** 构建完一层后，递归构建上一层
4. **剪枝优化：** 如果某个位置找不到合法的块，立即回溯
5. **记忆化：** 缓存已经计算过的层，避免重复计算

## 易错点

1. **索引越界：** 构建下一层时，循环范围是 `len(current) - 1`
2. **映射表键值：** 键是 `(left, right)` 元组，不要搞混
3. **基本情况：** 长度为 1 时要返回 True，不是 0
4. **回溯逻辑：** 要尝试所有可能，找到一个成功的就返回 True
5. **空列表处理：** 如果某对块没有对应的规则，要正确处理
