## 题目描述

一个数组的**分数**定义为数组之和乘以数组长度。比如 `[1, 2, 3, 4, 5]` 的分数为 `(1 + 2 + 3 + 4 + 5) * 5 = 75`。

给你一个正整数数组 `nums` 和一个整数 `k`，请你返回 `nums` 中分数**严格小于** `k` 的**非空子数组数目**。

**示例 1：**
```
输入：nums = [2,1,4,3,5], k = 10
输出：6
解释：6个分数小于10的子数组：[2],[1],[4],[3],[5],[2,1]
```

**示例 2：**
```
输入：nums = [1,1,1], k = 5
输出：5
解释：分数小于5的子数组：[1],[1],[1],[1,1],[1,1]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^15`

## 解题思路

**方法一：滑动窗口（推荐）**

由于 `nums` 全为正整数，窗口扩大时分数单调不减，因此可以使用滑动窗口：
- 维护窗口 `[left, right]`，保证窗口内的分数 < k。
- 对于每个右端点 `right`，找到最小的 `left` 使窗口分数 < k。
- 以 `right` 结尾且满足条件的子数组数目为 `right - left + 1`。

**方法二：二分查找 + 前缀和**

固定右端点 `right`，用二分查找找到满足条件的最左端点 `left`，利用前缀和快速计算子数组和。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        ans = 0
        left = 0
        total = 0  # 窗口内元素之和

        for right in range(len(nums)):
            total += nums[right]
            # 若当前窗口分数 >= k，缩小左边界
            while total * (right - left + 1) >= k:
                total -= nums[left]
                left += 1
            # 以 right 结尾的满足条件的子数组数目
            ans += right - left + 1
        
        return ans
```

### 方法二：二分查找 + 前缀和

```python
from typing import List
import bisect

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 构建前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        ans = 0
        for right in range(n):
            # 固定右端点 right，找最大的左端点使得分数 < k
            # sum(left..right) * (right - left + 1) < k
            # 即 (prefix[right+1] - prefix[left]) * (right - left + 1) < k
            # 二分查找满足条件的最小 left
            lo, hi = 0, right
            while lo < hi:
                mid = (lo + hi) // 2
                length = right - mid + 1
                s = prefix[right + 1] - prefix[mid]
                if s * length < k:
                    hi = mid
                else:
                    lo = mid + 1
            # 检查 lo 本身是否满足条件
            length = right - lo + 1
            s = prefix[right + 1] - prefix[lo]
            if s * length < k:
                ans += right - lo + 1
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 二分查找 | O(n log n) | O(n) |

## 关键点总结

1. 全为正整数时，子数组和随长度增加而单调不减，适合滑动窗口。
2. 分数 = 和 * 长度，两者都随窗口扩大而增大，单调性保证正确性。
3. 对于每个右端点，合法子数组数目为 `right - left + 1`。

## 易错点

- 注意分数计算可能溢出，Python 整数无上限，无需担心，但其他语言要注意。
- 缩小窗口时要先减去 `nums[left]` 再移动 `left`。
