## 题目描述

给定两个等长字符串 `s` 和 `t`。每次操作可以：
1. 选择 `s` 中某个字符，将其改为字母表中的下一个字母（'z' 变为 'a'）
2. 选择 `s` 中某个子串，将整个子串循环移位（最后一个字符移到最前面）

求将 `s` 变为 `t` 的最少操作次数。

**示例 1：**

```
输入：s = "abcd", t = "dcba"
输出：3
解释：循环移位 "abcd" -> "dabc"（1次），然后逐字符修改...
```

**示例 2：**

```
输入：s = "ab", t = "ba"
输出：1
解释：循环移位整个字符串，1次即可。
```

**提示：**
- `1 <= s.length <= 100`
- `s` 和 `t` 只含小写字母

## 解题思路

动态规划。

状态：`dp[i][j]` = 将 `s[i..j]` 变为 `t[i..j]` 的最少操作次数（区间 DP）。

操作分析：
1. 逐字符修改（不使用循环移位）：每个位置独立处理，代价为字符距离之和
2. 使用一次循环移位 + 后续操作

区间 DP 转移：
- `dp[i][j] = dp[i+1][j] + dist(s[i], t[i])` （不用循环移位处理 i）
- 枚举循环移位的子串 `[i, k]`：将 `s[i..k]` 循环移位后，与 `t[i..k]` 匹配，代价为 1 + 后续处理

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
from functools import lru_cache

class Solution:
    def minOperations(self, s: str, t: str) -> int:
        n = len(s)

        def char_dist(a, b):
            return (ord(b) - ord(a)) % 26

        @lru_cache(maxsize=None)
        def dp(i, j):
            # 将 s[i..j] 变为 t[i..j] 的最少操作数
            if i > j:
                return 0
            # 方法1：逐字符修改 s[i]，然后处理剩余
            res = char_dist(s[i], t[i]) + dp(i+1, j)

            # 方法2：循环移位子串 s[i..k]（1次操作）
            for k in range(i, j+1):
                # 循环移位：s[i..k] -> s[k] + s[i..k-1]
                # 希望移位后匹配 t[i..k]
                # 移位后 s[i..k] 变为 s[k] + s[i] + s[i+1] + ... + s[k-1]
                # 想让 s[k] == t[i] 且 s[i..k-1] == t[i+1..k]
                # 若 s[k] == t[i]，则循环移位后 s[i] 的位置变了
                # 这里简化：1次循环移位代价为1，加上后续处理的代价
                # 移位后新 s 为 s[k] + s[i:k] + (s 的其余部分不变)
                new_s_segment = s[k] + s[i:k]  # 循环移位后的 s[i..k]
                # 计算新的 dp（将 new_s_segment 变为 t[i..k] 的代价）
                # 这需要知道每个位置的字符距离
                cost_after = sum(char_dist(new_s_segment[p], t[i+p]) for p in range(k-i+1))
                res = min(res, 1 + cost_after + dp(k+1, j))

            return res

        return dp(0, n-1)
```

### 方法二：BFS（状态搜索）

```python
from collections import deque

class Solution:
    def minOperations(self, s: str, t: str) -> int:
        n = len(s)
        if s == t:
            return 0

        # BFS
        queue = deque([(s, 0)])
        visited = {s}

        while queue:
            curr, steps = queue.popleft()
            if curr == t:
                return steps
            # 单字符改变
            for i in range(n):
                new_c = chr((ord(curr[i]) - ord('a') + 1) % 26 + ord('a'))
                next_s = curr[:i] + new_c + curr[i+1:]
                if next_s not in visited:
                    visited.add(next_s)
                    queue.append((next_s, steps + 1))
            # 循环移位
            for i in range(n):
                for j in range(i, n):
                    seg = curr[i:j+1]
                    new_seg = seg[-1] + seg[:-1]
                    next_s = curr[:i] + new_seg + curr[j+1:]
                    if next_s not in visited:
                        visited.add(next_s)
                        queue.append((next_s, steps + 1))

        return -1
```

## 复杂度分析

- 时间复杂度：O(n^3)（方法一区间 DP），O(指数级)（方法二 BFS）
- 空间复杂度：O(n^2)（方法一）

## 关键点总结

1. 区间 DP 处理字符串转换问题
2. 循环移位操作可以一步将末尾字符移到开头
3. 分析操作的影响，分情况计算代价

## 易错点

1. 字符距离是"向前"的（循环：a->b->...->z->a），用 `(b-a) % 26`
2. 循环移位的子串范围需要枚举所有可能
3. BFS 对长字符串可能超时，优先使用 DP
