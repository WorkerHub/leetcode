## 题目描述

给你一个整数数组 `nums`，两名玩家轮流从数组的左端或右端取走一个数字并加入自己的得分。玩家甲先手，两人都采取最优策略。

返回玩家甲能获得的最大得分。

**示例 1：**

```
输入：nums = [1, 5, 2]
输出：6
解释：
- 甲取右端 2：nums = [1, 5]，甲得 2
- 乙取右端 5：nums = [1]，乙得 5
- 甲取 1：甲得 3，总得 3
或：
- 甲取右端 2，乙取左端 1，甲取 5，甲得 7
最优甲得 6。
```

**示例 2：**

```
输入：nums = [1, 2, 3, 7]
输出：10
解释：甲先取 7，乙取 3，甲取 2，乙取 1。甲得 9。
或甲取 7、甲取 2...
```

**提示：**
- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^4`

## 解题思路

经典**博弈论区间 DP**：
- `dp[i][j]` = 在子数组 `nums[i..j]` 上，先手玩家可以获得的最大得分差（自己得分 - 对手得分）。
- 递推：`dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`
  - 取左端：自己得 `nums[i]`，对手在 `[i+1, j]` 上的最优值为 `dp[i+1][j]`
  - 取右端：自己得 `nums[j]`，对手在 `[i, j-1]` 上的最优值为 `dp[i][j-1]`
- 最终答案：若 `dp[0][n-1] >= 0`，甲获胜，甲的得分 = `(total + dp[0][n-1]) / 2`

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)
        # dp[i][j] = 在 nums[i..j] 上先手可获得的最大得分差
        dp = [[0] * n for _ in range(n)]

        # 初始化：单个元素时先手取走全部
        for i in range(n):
            dp[i][i] = nums[i]

        # 按区间长度递推
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                # 取左端 nums[i]，对手面对 [i+1, j]
                take_left = nums[i] - dp[i + 1][j]
                # 取右端 nums[j]，对手面对 [i, j-1]
                take_right = nums[j] - dp[i][j - 1]
                dp[i][j] = max(take_left, take_right)

        # 甲的得分 = (总分 + 得分差) / 2
        return (total + dp[0][n - 1]) // 2
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumScore(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)

        @lru_cache(maxsize=None)
        def dp(i, j):
            """先手在 nums[i..j] 上的最大得分差"""
            if i == j:
                return nums[i]
            take_left = nums[i] - dp(i + 1, j)
            take_right = nums[j] - dp(i, j - 1)
            return max(take_left, take_right)

        diff = dp(0, n - 1)
        return (total + diff) // 2
```

## 复杂度分析

- 时间复杂度：O(n^2)，所有子区间
- 空间复杂度：O(n^2)，DP 表格

## 关键点总结

1. 博弈论 DP 的关键：记录得分差而非绝对得分，因为两人得分总和为定值。
2. `dp[i][j]` 表示先手在当前区间的最优优势，正值表示先手占优。
3. 最终甲的得分 = `(总分 + 得分差) / 2`（总分 = 甲 + 乙，差 = 甲 - 乙）。

## 易错点

1. DP 数组初始化：单元素时 `dp[i][i] = nums[i]`（先手取走所有）。
2. 递推顺序：从短区间到长区间（长度为 2 的先算）。
3. 最终计算甲的得分需要做整数除法（总分和得分差同奇偶）。
