## 题目描述

给定一个正整数 `n`，将其拆分为 `k` 个正整数的和（`k >= 2`），并使这些整数的乘积最大化。

返回你可以获得的最大乘积。

**示例 1：**
```
输入：n = 2
输出：1
解释：2 = 1 + 1, 1 × 1 = 1
```

**示例 2：**
```
输入：n = 10
输出：36
解释：10 = 3 + 3 + 4, 3 × 3 × 4 = 36
```

**提示：**
- `2 <= n <= 58`

## 解题思路

这道题有两种解法：动态规划和数学规律。

**核心观察：**
1. 要让乘积最大，应该尽可能拆分成相等或接近的数
2. 拆分成 2 和 3 的组合通常能获得最大乘积
3. 通过数学推导可以发现：**应该尽可能多地拆分成 3，其次是 2**

**数学推导：**
- 当 n >= 5 时，拆出一个 2 或 3 比保留 n 本身更优
- 证明：对于 n >= 5，有 3(n-3) > n，即拆出 3 更优
- 同样 2(n-2) > n 对于 n >= 4 成立
- 但 3 × 3 = 9 > 2 × 2 × 2 = 8，所以 3 优于 2

**最优策略：**
- 尽可能多拆成 3
- 如果余数是 1，则将最后一个 3 改为两个 2（因为 2 × 2 > 3 × 1）
- 如果余数是 2，则保留一个 2

## Python 代码实现

### 方法一：动态规划（推荐新手）

```python
class Solution:
    def integerBreak(self, n: int) -> int:
        # dp[i] 表示整数 i 拆分后的最大乘积
        dp = [0] * (n + 1)
        
        # 初始化
        dp[1] = 1
        
        # 从 2 开始计算每个数的最大乘积
        for i in range(2, n + 1):
            # 尝试拆分成 j 和 i-j
            for j in range(1, i):
                # 有两种情况：
                # 1. i-j 不继续拆分：j * (i-j)
                # 2. i-j 继续拆分：j * dp[i-j]
                dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
        
        return dp[n]
```

**时间复杂度：** O(n^2)
**空间复杂度：** O(n)

**优化版动态规划：**
```python
class Solution:
    def integerBreak(self, n: int) -> int:
        if n <= 3:
            return n - 1
        
        dp = [0] * (n + 1)
        dp[2] = 2
        dp[3] = 3
        
        for i in range(4, n + 1):
            # 只需考虑拆分成 2 或 3
            dp[i] = max(2 * dp[i - 2], 3 * dp[i - 3])
        
        return dp[n]
```

### 方法二：数学规律（最优解）⭐

```python
class Solution:
    def integerBreak(self, n: int) -> int:
        # 特殊情况
        if n <= 3:
            return n - 1
        
        # 计算能拆分出多少个 3
        quotient = n // 3
        remainder = n % 3
        
        if remainder == 0:
            # n 是 3 的倍数，全部拆成 3
            return 3 ** quotient
        elif remainder == 1:
            # 余数为 1，将一个 3 和 1 组合成两个 2
            # 3^(q-1) * 4 = 3^(q-1) * 2 * 2
            return 3 ** (quotient - 1) * 4
        else:  # remainder == 2
            # 余数为 2，保留一个 2
            return 3 ** quotient * 2
```

**时间复杂度：** O(1) 或 O(log n)（取决于幂运算实现）
**空间复杂度：** O(1)

### 方法三：记忆化递归

```python
class Solution:
    def integerBreak(self, n: int) -> int:
        memo = {}
        
        def dp(num):
            # 基本情况
            if num <= 3:
                return num
            
            # 查找缓存
            if num in memo:
                return memo[num]
            
            # 尝试所有可能的拆分
            max_product = 0
            for i in range(2, num):
                # i 不再拆分，num-i 可能继续拆分
                max_product = max(max_product, i * max(num - i, dp(num - i)))
            
            memo[num] = max_product
            return max_product
        
        return dp(n)
```

### 方法四：贪心算法（直观理解）

```python
class Solution:
    def integerBreak(self, n: int) -> int:
        if n == 2:
            return 1
        if n == 3:
            return 2
        
        product = 1
        
        # 不断拆出 3
        while n > 4:
            product *= 3
            n -= 3
        
        # 处理剩余部分
        product *= n
        
        return product
```

## 图解示例

```
n = 10 的最优拆分：

尝试不同拆分方案：
10 = 5 + 5        → 5 × 5 = 25
10 = 2 + 2 + 2 + 2 + 2 → 2^5 = 32
10 = 3 + 3 + 4    → 3 × 3 × 4 = 36 ✓
10 = 3 + 3 + 3 + 1 → 3 × 3 × 3 × 1 = 27

为什么 3 最优？
对于足够大的 n：
- 拆成 2: 需要 n/2 个，乘积 2^(n/2)
- 拆成 3: 需要 n/3 个，乘积 3^(n/3)
- 拆成 4: 等同于两个 2，不如直接拆 2

比较 2^(n/2) 和 3^(n/3)：
取对数：(n/2)log2 vs (n/3)log3
即：0.5log2 vs 0.333log3
计算：0.301 vs 0.477
所以 3^(n/3) > 2^(n/2)

各种情况的处理：
n % 3 == 0: 全部拆成 3         → 3^(n/3)
n % 3 == 1: 拆成 3...3 + 2 + 2 → 3^(n/3-1) * 4
n % 3 == 2: 拆成 3...3 + 2     → 3^(n/3) * 2
```

## 数学证明

**为什么拆成 3 最优？**

对于正数 x1, x2, ..., xk，满足 x1 + x2 + ... + xk = n（常数）

要使乘积 x1 × x2 × ... × xk 最大，根据算术-几何平均值不等式（AM-GM）：
```
(x1 + x2 + ... + xk) / k >= (x1 × x2 × ... × xk)^(1/k)
```

当所有 xi 相等时等号成立，即每个数应该接近 n/k。

对 f(x) = x^(n/x) 求导，可以证明当 x = e ≈ 2.718 时取得最大值。

因为只能用整数，所以应该选择 3（最接近 e）。

## 关键点总结

1. **贪心策略**：尽可能多地拆成 3
2. **特殊处理**：余数为 1 时，要把一个 3 改成两个 2
3. **边界情况**：n = 2 和 n = 3 需要特殊处理
4. **数学基础**：基于 AM-GM 不等式的证明
5. **动态规划**：作为通用方法，适用于不明显的规律

## 易错点

1. **忘记特殊情况**
   ```python
   # 错误：n=2 和 n=3 也按一般规律处理
   # n=2: 期望 1，但 3^0 * 2 = 2
   # n=3: 期望 2，但 3^1 = 3
   
   # 正确：
   if n <= 3:
       return n - 1
   ```

2. **余数为 1 的处理**
   ```python
   # 错误：直接保留 1
   # n=4: 3^1 * 1 = 3，但应该是 2*2 = 4
   
   # 正确：将 3+1 改为 2+2
   if remainder == 1:
       return 3 ** (quotient - 1) * 4
   ```

3. **动态规划初始化**
   ```python
   # 错误：dp[2] = 1（认为 2 只能拆成 1+1）
   # 这会影响后续计算，如 dp[5] = 3 * dp[2]
   
   # 正确：对于作为子问题，dp[2] = 2, dp[3] = 3
   if n <= 3:
       return n - 1
   dp[2] = 2
   dp[3] = 3
   ```

4. **动态规划转移**
   ```python
   # 错误：只考虑继续拆分
   dp[i] = max(j * dp[i - j] for j in range(1, i))
   
   # 正确：既考虑继续拆分，也考虑不拆分
   dp[i] = max(j * (i - j), j * dp[i - j])
   ```
