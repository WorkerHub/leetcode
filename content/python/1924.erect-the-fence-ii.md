## 题目描述

给你一个二维整数数组 `trees`，其中 `trees[i] = [xi, yi]` 表示花园中一棵树的位置。

你需要用**最小半径的圆形围栏**将所有的树都圈在里面（允许树在围栏边界上）。

返回该圆形围栏的圆心 `[x, y]` 和半径 `r`。答案与实际答案误差不超过 `10^-5` 即为正确。

**示例 1：**
```
输入：trees = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]
输出：[2.0, 2.0, 2.0]
```

**提示：**
- `1 <= trees.length <= 3000`
- `trees[i].length == 2`
- `0 <= xi, yi <= 3000`

---

## 解题思路

### 核心思想：最小外接圆（Welzl 算法）

**最小包围圆**（Minimum Enclosing Circle, MEC）问题，可用 **Welzl 随机增量算法**求解：

- 最小包围圆由**至多 3 个点**确定（在边界上）
- 算法思路：随机打乱点的顺序，逐点加入：
  - 若当前点在圆内，不处理
  - 若不在，则当前点必须在最小圆的边界上，递归求包含该点的最小包围圆

**辅助函数：**
- 两点确定的圆：圆心在两点中点，半径为距离的一半
- 三点确定的圆：外接圆（使用行列式公式）

## 代码实现

### 方法一：Welzl 算法（推荐）

```python
from typing import List
import random

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[float]:

        def dist2(p1, p2):
            """两点距离的平方"""
            return (p1[0]-p2[0])**2 + (p1[1]-p2[1])**2

        def circle_from_1(p):
            """一个点确定的最小圆（半径 0）"""
            return (p[0], p[1], 0)

        def circle_from_2(p1, p2):
            """两点确定的最小圆（以两点中点为圆心）"""
            cx = (p1[0] + p2[0]) / 2
            cy = (p1[1] + p2[1]) / 2
            r = dist2(p1, p2) ** 0.5 / 2
            return (cx, cy, r)

        def circle_from_3(p1, p2, p3):
            """三点确定的外接圆"""
            ax, ay = p1
            bx, by = p2
            cx, cy = p3
            d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
            if abs(d) < 1e-10:
                # 三点共线，取两端点的圆
                candidates = [
                    circle_from_2(p1, p2),
                    circle_from_2(p1, p3),
                    circle_from_2(p2, p3)
                ]
                return min(candidates, key=lambda c: c[2])
            ux = ((ax**2 + ay**2) * (by - cy) + (bx**2 + by**2) * (cy - ay) + (cx**2 + cy**2) * (ay - by)) / d
            uy = ((ax**2 + ay**2) * (cx - bx) + (bx**2 + by**2) * (ax - cx) + (cx**2 + cy**2) * (bx - ax)) / d
            r = dist2((ux, uy), p1) ** 0.5
            return (ux, uy, r)

        def in_circle(c, p):
            """点 p 是否在圆 c 内（含边界）"""
            return dist2((c[0], c[1]), p) <= (c[2] + 1e-7) ** 2

        def min_circle(pts, boundary):
            """Welzl 递归：pts 为待处理点，boundary 为边界点（最多 3 个）"""
            if not pts or len(boundary) == 3:
                if len(boundary) == 0:
                    return (0, 0, 0)
                elif len(boundary) == 1:
                    return circle_from_1(boundary[0])
                elif len(boundary) == 2:
                    return circle_from_2(boundary[0], boundary[1])
                else:
                    return circle_from_3(boundary[0], boundary[1], boundary[2])

            p = pts[0]
            c = min_circle(pts[1:], boundary)
            if in_circle(c, p):
                return c
            return min_circle(pts[1:], boundary + [p])

        points = [tuple(t) for t in trees]
        random.shuffle(points)
        circle = min_circle(points, [])
        return [circle[0], circle[1], circle[2]]
```

### 方法二：迭代 Welzl（避免递归栈溢出）

```python
from typing import List
import random

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[float]:

        def dist(p1, p2):
            return ((p1[0]-p2[0])**2 + (p1[1]-p2[1])**2) ** 0.5

        def make_circle(pts):
            """由 1-3 个边界点构造最小圆"""
            if len(pts) == 0:
                return [0, 0, 0]
            elif len(pts) == 1:
                return [pts[0][0], pts[0][1], 0]
            elif len(pts) == 2:
                cx = (pts[0][0]+pts[1][0])/2
                cy = (pts[0][1]+pts[1][1])/2
                return [cx, cy, dist(pts[0], pts[1])/2]
            else:
                # 三点外接圆
                ax, ay = pts[0]; bx, by = pts[1]; cx, cy = pts[2]
                d = 2*(ax*(by-cy)+bx*(cy-ay)+cx*(ay-by))
                if abs(d) < 1e-10:
                    pairs = [(pts[0],pts[1]),(pts[0],pts[2]),(pts[1],pts[2])]
                    best = min(pairs, key=lambda p: dist(p[0],p[1]))
                    return make_circle([best[0], best[1]])
                ux = ((ax**2+ay**2)*(by-cy)+(bx**2+by**2)*(cy-ay)+(cx**2+cy**2)*(ay-by))/d
                uy = ((ax**2+ay**2)*(cx-bx)+(bx**2+by**2)*(ax-cx)+(cx**2+cy**2)*(bx-ax))/d
                return [ux, uy, dist((ux,uy), pts[0])]

        def in_circle(c, p):
            return dist((c[0],c[1]), p) <= c[2] + 1e-7

        pts = [tuple(t) for t in trees]
        random.shuffle(pts)
        n = len(pts)
        c = make_circle([])

        for i in range(n):
            if not in_circle(c, pts[i]):
                c = make_circle([pts[i]])
                for j in range(i):
                    if not in_circle(c, pts[j]):
                        c = make_circle([pts[i], pts[j]])
                        for k in range(j):
                            if not in_circle(c, pts[k]):
                                c = make_circle([pts[i], pts[j], pts[k]])
        return c
```

---

## 关键点总结

1. 最小包围圆由至多 3 个点确定（在边界上）
2. 随机打乱保证期望 O(n) 时间复杂度
3. 使用浮点数时加小量 eps 避免边界误差

---

## 易错点

- 三点共线时外接圆公式分母为 0，需特判
- 浮点精度问题，判断点是否在圆内时加 1e-7 容差
