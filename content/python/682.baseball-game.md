## 题目描述

你现在是一场采用特殊赛制棒球比赛的记录员。这场比赛由若干回合组成,过去几回合的得分可能会影响以后几回合的得分。

比赛开始时,记录是空白的。你会得到一个记录操作的字符串列表 ops,其中 ops[i] 是你需要记录的第 i 项操作,ops 遵循下述规则:

1. 整数 x - 表示本回合新获得分数 x
2. "+" - 表示本回合新获得的得分是前两次得分的总和。题目数据保证记录此操作时前面总是存在两个有效的分数
3. "D" - 表示本回合新获得的得分是前一次得分的两倍。题目数据保证记录此操作时前面总是存在一个有效的分数
4. "C" - 表示前一次得分无效,将其从记录中移除。题目数据保证记录此操作时前面总是存在一个有效的分数

请你返回记录中所有得分的总和。

**示例 1:**
```
输入: ops = ["5","2","C","D","+"]
输出: 30
解释:
"5" - 记录加 5,记录现在是 [5]
"2" - 记录加 2,记录现在是 [5, 2]
"C" - 使前一次得分无效并将其移除,记录现在是 [5]
"D" - 记录加 2 * 5 = 10,记录现在是 [5, 10]
"+" - 记录加 5 + 10 = 15,记录现在是 [5, 10, 15]
总分: 5 + 10 + 15 = 30
```

**示例 2:**
```
输入: ops = ["5","-2","4","C","D","9","+","+"]
输出: 27
解释:
"5" - 记录加 5,记录现在是 [5]
"-2" - 记录加 -2,记录现在是 [5, -2]
"4" - 记录加 4,记录现在是 [5, -2, 4]
"C" - 使前一次得分无效并将其移除,记录现在是 [5, -2]
"D" - 记录加 2 * -2 = -4,记录现在是 [5, -2, -4]
"9" - 记录加 9,记录现在是 [5, -2, -4, 9]
"+" - 记录加 -4 + 9 = 5,记录现在是 [5, -2, -4, 9, 5]
"+" - 记录加 9 + 5 = 14,记录现在是 [5, -2, -4, 9, 5, 14]
总分: 5 + -2 + -4 + 9 + 5 + 14 = 27
```

**示例 3:**
```
输入: ops = ["1"]
输出: 1
```

**提示:**
- 1 <= ops.length <= 1000
- ops[i] 为 "C"、"D"、"+" 或者一个表示整数的字符串,整数范围是 [-3 * 10^4, 3 * 10^4]
- 对于 "+" 操作,题目数据保证记录中至少存在两个分数
- 对于 "C" 和 "D" 操作,题目数据保证记录中至少存在一个分数

## 解题思路

这道题是一个典型的**栈(Stack)**应用场景:
- 需要频繁访问最近添加的元素
- 需要删除最近添加的元素
- 操作顺序严格按照时间先后

**解题步骤:**
1. 使用栈(列表)维护有效的得分记录
2. 遍历每个操作:
   - 数字: 直接入栈
   - "+": 计算栈顶两个元素之和并入栈
   - "D": 计算栈顶元素的两倍并入栈
   - "C": 移除栈顶元素
3. 返回栈中所有元素的总和

**为什么用栈:**
- 栈的后进先出(LIFO)特性完美契合题意
- 访问栈顶元素 O(1)
- 删除栈顶元素 O(1)
- 添加元素 O(1)

## Python 代码实现

### 方法一:栈(推荐)

```python
from typing import List

class Solution:
    def calPoints(self, ops: List[str]) -> int:
        stack = []  # 用列表模拟栈
        
        for op in ops:
            if op == "+":
                # 前两次得分的总和
                stack.append(stack[-1] + stack[-2])
            elif op == "D":
                # 前一次得分的两倍
                stack.append(2 * stack[-1])
            elif op == "C":
                # 移除前一次得分
                stack.pop()
            else:
                # 整数,直接加入
                stack.append(int(op))
        
        # 返回所有得分的总和
        return sum(stack)
```

### 方法二:优化的栈实现

```python
from typing import List

class Solution:
    def calPoints(self, ops: List[str]) -> int:
        record = []
        
        for op in ops:
            if op == "C":
                record.pop()  # 移除上一轮得分
            elif op == "D":
                record.append(record[-1] * 2)  # 加倍
            elif op == "+":
                record.append(record[-1] + record[-2])  # 求和
            else:
                record.append(int(op))  # 添加新得分
        
        return sum(record)
```

### 方法三:边计算边累加(空间优化)

```python
from typing import List

class Solution:
    def calPoints(self, ops: List[str]) -> int:
        stack = []
        
        for op in ops:
            if op == "+":
                new_score = stack[-1] + stack[-2]
                stack.append(new_score)
            elif op == "D":
                new_score = 2 * stack[-1]
                stack.append(new_score)
            elif op == "C":
                stack.pop()
            else:
                stack.append(int(op))
        
        # 直接返回总和
        return sum(stack)
```

### 方法四:使用字典映射操作

```python
from typing import List

class Solution:
    def calPoints(self, ops: List[str]) -> int:
        stack = []
        
        # 操作映射表
        operations = {
            "+": lambda s: s[-1] + s[-2],
            "D": lambda s: 2 * s[-1],
            "C": lambda s: s.pop() and None  # pop并返回None
        }
        
        for op in ops:
            if op in operations:
                if op == "C":
                    stack.pop()
                else:
                    stack.append(operations[op](stack))
            else:
                stack.append(int(op))
        
        return sum(stack)
```

## 复杂度分析

**所有方法:**
- 时间复杂度: O(n),需要遍历所有操作,每个操作的处理时间为 O(1)
- 空间复杂度: O(n),最坏情况下所有操作都是数字,栈的大小为 n

## 关键点总结

1. **栈的应用**: 识别需要频繁访问/删除最近元素的场景
2. **字符串转整数**: 使用 int() 转换数字字符串
3. **负数处理**: 题目中可能有负数,要正确处理
4. **栈顶访问**: Python 中使用 stack[-1] 访问栈顶,stack[-2] 访问次栈顶
5. **边界条件**: 题目保证操作合法,不需要额外检查

## 易错点

1. **字符串判断**: 要区分操作符("C", "D", "+")和数字字符串("-2", "10")
2. **负数识别**: "-2" 是数字,不是操作符
3. **栈为空**: 本题保证操作合法,但实际应用中要注意栈空检查
4. **索引错误**: 访问 stack[-2] 前确保栈中至少有两个元素
5. **类型转换**: 记得将数字字符串转为 int 类型
