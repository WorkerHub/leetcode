## 题目描述

设计一个使用单词列表进行初始化的数据结构，单词列表中的单词互不相同。

实现 `MagicDictionary` 类：
- `MagicDictionary()` 初始化对象
- `void buildDict(String[] dictionary)` 使用字符串数组 dictionary 设定该数据结构
- `bool search(String searchWord)` 给定一个字符串 searchWord，判定能否只将字符串中的一个字母换成另一个字母，使得修改后的字符串能与字典中的任一字符串匹配。如果可以，返回 true；否则，返回 false

**示例：**
```
输入：
["MagicDictionary", "buildDict", "search", "search", "search", "search"]
[[], [["hello", "leetcode"]], ["hello"], ["hhllo"], ["hell"], ["leetcoded"]]
输出：
[null, null, false, true, false, false]

解释：
MagicDictionary magicDictionary = new MagicDictionary();
magicDictionary.buildDict(["hello", "leetcode"]);
magicDictionary.search("hello"); // 返回 False
magicDictionary.search("hhllo"); // 将第二个 'h' 替换为 'e' 可以匹配 "hello" ，返回 True
magicDictionary.search("hell"); // 返回 False
magicDictionary.search("leetcoded"); // 返回 False
```

**提示：**
- 1 <= dictionary.length <= 100
- 1 <= dictionary[i].length <= 100
- dictionary[i] 仅由小写英文字母组成
- dictionary 中的所有字符串互不相同
- 1 <= searchWord.length <= 100
- searchWord 仅由小写英文字母组成
- buildDict 仅在 search 之前调用一次
- 最多调用 100 次 search

## 解题思路

有多种实现方式，从简单到优化。

**核心要求：**
恰好修改一个字符后能匹配字典中的某个单词。

**方法思路：**
1. **暴力匹配**：遍历字典，检查每个单词是否恰好差一个字符
2. **按长度分组**：将字典单词按长度分组，减少比较次数
3. **通配符哈希**：预处理所有可能的"修改一个字符"的模式
4. **字典树**：使用Trie树进行高效匹配

## Python 代码实现

### 方法一：按长度分组 + 暴力匹配（推荐）⭐

```python
from typing import List
from collections import defaultdict

class MagicDictionary:
    def __init__(self):
        self.words_by_length = defaultdict(list)
    
    def buildDict(self, dictionary: List[str]) -> None:
        """按长度分组存储"""
        for word in dictionary:
            self.words_by_length[len(word)].append(word)
    
    def search(self, searchWord: str) -> bool:
        """检查是否能通过修改一个字符匹配"""
        length = len(searchWord)
        
        # 只检查相同长度的单词
        for word in self.words_by_length[length]:
            diff_count = 0
            for i in range(length):
                if searchWord[i] != word[i]:
                    diff_count += 1
                    if diff_count > 1:
                        break
            
            if diff_count == 1:
                return True
        
        return False
```

### 方法二：通配符哈希

```python
class MagicDictionary:
    def __init__(self):
        self.patterns = set()
    
    def buildDict(self, dictionary: List[str]) -> None:
        """预处理所有可能的模式"""
        for word in dictionary:
            # 对每个位置生成通配符模式
            for i in range(len(word)):
                pattern = word[:i] + '*' + word[i+1:]
                self.patterns.add((pattern, word))
    
    def search(self, searchWord: str) -> bool:
        """检查修改一个字符后的模式是否存在"""
        for i in range(len(searchWord)):
            pattern = searchWord[:i] + '*' + searchWord[i+1:]
            
            # 检查是否有匹配的模式，但原词不同
            for pat, original in self.patterns:
                if pat == pattern and original != searchWord:
                    return True
        
        return False
```

### 方法三：优化的通配符集合

```python
class MagicDictionary:
    def __init__(self):
        self.patterns = defaultdict(list)
    
    def buildDict(self, dictionary: List[str]) -> None:
        """存储每个模式对应的原词"""
        for word in dictionary:
            for i in range(len(word)):
                pattern = word[:i] + '*' + word[i+1:]
                self.patterns[pattern].append(word)
    
    def search(self, searchWord: str) -> bool:
        """生成所有可能的模式并查找"""
        for i in range(len(searchWord)):
            pattern = searchWord[:i] + '*' + searchWord[i+1:]
            
            # 检查该模式下是否有不同的词
            for word in self.patterns[pattern]:
                if word != searchWord:
                    return True
        
        return False
```

### 方法四：字典树(Trie)

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False

class MagicDictionary:
    def __init__(self):
        self.root = TrieNode()
    
    def buildDict(self, dictionary: List[str]) -> None:
        """构建字典树"""
        for word in dictionary:
            node = self.root
            for char in word:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
            node.is_word = True
    
    def search(self, searchWord: str) -> bool:
        """DFS搜索，允许恰好一次字符替换"""
        def dfs(node, index, modified):
            """
            node: 当前Trie节点
            index: searchWord的当前索引
            modified: 是否已经修改过一个字符
            """
            if index == len(searchWord):
                return node.is_word and modified
            
            char = searchWord[index]
            
            # 尝试所有可能的字符
            for next_char in node.children:
                if next_char == char:
                    # 不修改，继续搜索
                    if dfs(node.children[next_char], index + 1, modified):
                        return True
                elif not modified:
                    # 修改这个字符
                    if dfs(node.children[next_char], index + 1, True):
                        return True
            
            return False
        
        return dfs(self.root, 0, False)
```

## 复杂度分析

**方法一：按长度分组**
- buildDict: O(n)，n为字典单词总数
- search: O(m × L)，m为相同长度的单词数，L为单词长度
- 空间复杂度：O(n × L)

**方法二/三：通配符哈希**
- buildDict: O(n × L²)，每个单词生成L个模式
- search: O(L²)
- 空间复杂度：O(n × L²)

**方法四：字典树**
- buildDict: O(n × L)
- search: O(26^L)，最坏情况
- 空间复杂度：O(n × L × 26)

## 关键点总结

1. **恰好一次**：必须修改一个字符，不能不修改
2. **长度相同**：只需比较相同长度的单词
3. **预处理优化**：通过预处理减少查询时的计算
4. **通配符技巧**：用*表示可替换的位置
5. **Trie应用**：DFS时允许一次不匹配

## 易错点

1. **恰好修改**：search("hello") 对于字典中的 "hello" 应返回false
2. **长度不同**：不同长度的单词不可能匹配
3. **重复处理**：通配符方法要避免重复计数
4. **空字典**：buildDict可能传入空数组
5. **修改标志**：Trie方法中要准确传递modified标志
