## 题目描述

给两个整数数组 `nums1` 和 `nums2`，返回 两个数组中 **公共的**、长度最长的子数组的长度。

**示例 1：**

```
输入：nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出：3
解释：长度最长的公共子数组是 [3,2,1]。
```

**示例 2：**

```
输入：nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出：5
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 100`

## 解题思路

这是一道经典的最长公共子数组问题，类似于最长公共子序列，但要求元素必须连续。

**核心思想：动态规划**

`dp[i][j]` 表示以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度。

**状态转移：**
- 如果 `nums1[i-1] == nums2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = 0`（不连续则重新开始）

## Python 代码实现

### 方法一：二维 DP（推荐）⭐

```python
from typing import List

class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        max_len = 0
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                    max_len = max(max_len, dp[i][j])
        
        return max_len
```

### 方法二：空间优化

```python
class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        dp = [0] * (n + 1)
        max_len = 0
        
        for i in range(1, m + 1):
            # 从后往前更新，避免覆盖
            for j in range(n, 0, -1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[j] = dp[j - 1] + 1
                    max_len = max(max_len, dp[j])
                else:
                    dp[j] = 0
        
        return max_len
```

### 方法三:滑动窗口

```python
class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        def maxLength(i: int, j: int, length: int) -> int:
            """计算从 nums1[i] 和 nums2[j] 开始，长度为 length 的最长公共前缀"""
            count = 0
            max_count = 0
            for k in range(length):
                if nums1[i + k] == nums2[j + k]:
                    count += 1
                    max_count = max(max_count, count)
                else:
                    count = 0
            return max_count
        
        m, n = len(nums1), len(nums2)
        result = 0
        
        # nums1 固定，nums2 滑动
        for i in range(m):
            length = min(m - i, n)
            result = max(result, maxLength(i, 0, length))
        
        # nums2 固定，nums1 滑动
        for j in range(n):
            length = min(m, n - j)
            result = max(result, maxLength(0, j, length))
        
        return result
```

## 复杂度分析

### 二维 DP：
- **时间复杂度：** O(m × n)
- **空间复杂度：** O(m × n)

### 一维 DP：
- **时间复杂度：** O(m × n)
- **空间复杂度：** O(n)

## 关键点总结

1. **连续性**：子数组必须连续，不匹配时归零
2. **DP 定义**：以当前位置结尾的最长长度
3. **空间优化**：可以优化到 O(n)
4. **记录最大值**：在转移过程中记录全局最大值

## 易错点

1. **子数组 vs 子序列**：子数组必须连续
2. **DP 初始化**：边界为 0
3. **索引对应**：`dp[i][j]` 对应 `nums1[i-1]` 和 `nums2[j-1]`
4. **空间优化时的遍历方向**：要从后往前
