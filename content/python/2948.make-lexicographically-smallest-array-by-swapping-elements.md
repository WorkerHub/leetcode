## 题目描述

给你一个下标从 0 开始的非严格递增整数数组 `nums` 和一个正整数 `limit`。

若两个下标 `i` 和 `j` 满足 `|nums[i] - nums[j]| <= limit`，则可以互相交换 `nums[i]` 和 `nums[j]`（通过若干次操作）。

返回经过若干次此类操作后，能得到的字典序最小的 `nums`。

**示例 1：**
```
输入：nums = [1,5,3,9,8], limit = 2
输出：[1,3,5,8,9]
```

**示例 2：**
```
输入：nums = [1,7,6,18,2,1], limit = 3
输出：[1,6,7,2,1,18] -- 不对，答案是 [1,6,7,2,1,18]
实际：[1,2,6,7,1,18]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= limit <= 10^9`

## 解题思路

可以交换的元素构成一个连通分量（可达性是传递的）。

步骤：
1. 将 nums 按值排序，记录原始下标
2. 相邻元素（排序后）若差值 <= limit，则属于同一组（用并查集合并）
3. 对每个连通分量（一组），将该组的值（排序后）按原始下标（排序后）依次填入

## Python 代码实现

### 方法一：排序 + 并查集（推荐）

```python
from typing import List

class Solution:
    def lexicographicallySmallestArray(self, nums: List[int], limit: int) -> int:
        n = len(nums)

        # 并查集
        parent = list(range(n))
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py

        # 按值排序，获取排序后的下标
        sorted_idx = sorted(range(n), key=lambda i: nums[i])

        # 相邻排序后的元素，若差值 <= limit，合并
        for i in range(1, n):
            if nums[sorted_idx[i]] - nums[sorted_idx[i - 1]] <= limit:
                union(sorted_idx[i], sorted_idx[i - 1])

        # 按连通分量分组，每组内按下标排序，填入排序后的值
        from collections import defaultdict
        groups_val = defaultdict(list)   # 组的根 -> 按原始下标排序的 nums 值
        groups_idx = defaultdict(list)   # 组的根 -> 按原始下标排序的下标

        for i in range(n):
            r = find(sorted_idx[i])
            groups_val[r].append(nums[sorted_idx[i]])
            groups_idx[r].append(sorted_idx[i])

        ans = list(nums)
        for r in groups_val:
            indices = sorted(groups_idx[r])    # 按原始下标排序
            values = groups_val[r]             # 已经是按值排序的（因为 sorted_idx 是按值排序的）
            for idx, val in zip(indices, values):
                ans[idx] = val

        return ans
```

### 方法二：分组贪心（不用并查集）

```python
from typing import List
from collections import defaultdict

class Solution:
    def lexicographicallySmallestArray(self, nums: List[int], limit: int) -> int:
        n = len(nums)
        sorted_idx = sorted(range(n), key=lambda i: nums[i])

        ans = list(nums)
        i = 0
        while i < n:
            j = i
            # 找连续的一组（差值 <= limit）
            while j + 1 < n and nums[sorted_idx[j + 1]] - nums[sorted_idx[j]] <= limit:
                j += 1
            # sorted_idx[i..j] 是一组
            group_indices = sorted_idx[i:j + 1]
            group_values = [nums[k] for k in group_indices]
            # 按原始下标分配排序后的值
            for orig_idx, val in zip(sorted(group_indices), sorted(group_values)):
                ans[orig_idx] = val
            i = j + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 按值排序后，相邻差值 <= limit 的元素属于同一组（可以互相交换）
2. 同一组内，原始下标越小的位置应该填入值越小的元素（字典序最小）
3. 传递性：a 可与 b 互换，b 可与 c 互换 => a 可与 c 互换

## 易错点

1. 组是按排序后相邻元素的差值确定的，不是按原始顺序
2. 组内按原始下标排序后，依次填入排序后的值（贪心）
3. 不同组之间无法互换
