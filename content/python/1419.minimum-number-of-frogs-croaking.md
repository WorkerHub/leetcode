## 题目描述

给你一个字符串 `croakOfFrogs`，它表示不同青蛙发出的蛙鸣声（字符串 `"croak"`）的组合。由于同一时间可以有多只青蛙呱呱作响，所以 `croakOfFrogs` 中会混合多个 `"croak"`。

请你返回模拟字符串中所有蛙鸣所需不同青蛙的 **最少数目**。

若不能把字符串中的所有蛙鸣声都合法还原为 `"croak"`，则返回 `-1`。

**示例 1：**

```
输入：croakOfFrogs = "croakcroak"
输出：1
解释：1 只青蛙先叫完第一个 "croak"，再叫第二个 "croak"。
```

**示例 2：**

```
输入：croakOfFrogs = "crcoakroak"
输出：2
解释：需要 2 只青蛙，一只叫 c_r_o_a_k（位置0,1,4,7,9），一只叫 _c__oak（位置2,3,5,6,8）。
```

**示例 3：**

```
输入：croakOfFrogs = "croakcrook"
输出：-1
解释：给出的字符串不是 "croak" 的有效组合。
```

**提示：**

- `1 <= croakOfFrogs.length <= 10^5`
- 字符串中只含有 `'c'`、`'r'`、`'o'`、`'a'`、`'k'` 五种字符

## 解题思路

### 计数法

把每只青蛙的叫声 `"croak"` 看成 5 个阶段。当前字符串中，每只"活跃"的青蛙正处于某个阶段。

设计数器：
- `c`：正在等待发 'r' 的青蛙数（已发完 'c'）
- `r`：正在等待发 'o' 的青蛙数（已发完 'r'）
- `o`：正在等待发 'a' 的青蛙数（已发完 'o'）
- `a`：正在等待发 'k' 的青蛙数（已发完 'a'）

遍历每个字符：

- 遇到 `'c'`：一只新青蛙（或已完成的青蛙）开始叫，`c += 1`
- 遇到 `'r'`：一只叫了 'c' 的青蛙继续叫，需要 `c > 0`，否则非法，`c -= 1, r += 1`
- 遇到 `'o'`：一只叫了 'r' 的青蛙继续叫，需要 `r > 0`，`r -= 1, o += 1`
- 遇到 `'a'`：需要 `o > 0`，`o -= 1, a += 1`
- 遇到 `'k'`：一只青蛙完成整个叫声，需要 `a > 0`，`a -= 1`（青蛙空闲）

当前所需青蛙数 = `c + r + o + a`（正在叫的青蛙数）

答案 = 过程中 `c + r + o + a` 的最大值。

**最终检查：** 结束后 `c + r + o + a` 必须为 0（所有青蛙都叫完了）。

**非法情况：**
- 遇到某个字符时，前一个字符的计数为 0（顺序不对）

## Python 代码实现

### 方法一：计数法（推荐）

```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        # 各阶段正在等待下一步的青蛙数
        c = r = o = a = 0
        max_frogs = 0  # 记录最多同时活跃的青蛙数

        for ch in croakOfFrogs:
            if ch == 'c':
                c += 1
            elif ch == 'r':
                if c == 0:  # 没有等待发 'r' 的青蛙，非法
                    return -1
                c -= 1
                r += 1
            elif ch == 'o':
                if r == 0:
                    return -1
                r -= 1
                o += 1
            elif ch == 'a':
                if o == 0:
                    return -1
                o -= 1
                a += 1
            elif ch == 'k':
                if a == 0:
                    return -1
                a -= 1
                # 青蛙完成叫声，不需要记录（可复用）

            # 当前活跃青蛙数
            current = c + r + o + a
            max_frogs = max(max_frogs, current)

        # 最终所有青蛙必须叫完
        if c + r + o + a != 0:
            return -1

        return max_frogs
```

### 方法二：使用字典简化代码

```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        order = "croak"
        # prev_char[ch] 表示 ch 的前一个字符
        prev = {ch: order[i - 1] if i > 0 else None
                for i, ch in enumerate(order)}

        count = {ch: 0 for ch in order}
        max_frogs = 0

        for ch in croakOfFrogs:
            p = prev[ch]
            if p is not None:
                # ch 的前一个字符计数必须 > 0
                if count[p] == 0:
                    return -1
                count[p] -= 1

            count[ch] += 1

            # 'k' 表示叫完，直接减（青蛙空闲）
            if ch == 'k':
                count['k'] -= 1  # 完成的青蛙不计入活跃

            # 计算当前活跃青蛙数（处于 c/r/o/a 阶段的）
            active = count['c'] + count['r'] + count['o'] + count['a']
            max_frogs = max(max_frogs, active)

        # 所有青蛙必须叫完
        if any(count[ch] != 0 for ch in order):
            return -1

        return max_frogs
```

### 方法三：更简洁的写法

```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        c = r = o = a = k = 0
        res = 0

        for ch in croakOfFrogs:
            if   ch == 'c': c += 1
            elif ch == 'r': r += 1
            elif ch == 'o': o += 1
            elif ch == 'a': a += 1
            elif ch == 'k': k += 1

            # 检查合法性：在任意时刻，c >= r >= o >= a >= k
            # 因为每个后续字符的数量不能超过前面字符的数量
            if not (c >= r >= o >= a >= k):
                return -1

            # 当前活跃青蛙数 = c - k（已开始但未完成的）
            # 更准确：正在叫的青蛙数 = c - k
            res = max(res, c - k)

        # 最终所有字符数必须相等（每只青蛙叫完整的 croak）
        if c == r == o == a == k:
            return res
        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 所有方法 | O(n) | O(1) |

只需一次遍历，使用常数个计数器。

## 关键点总结

1. 关键不变量：在任意时刻，`c >= r >= o >= a >= k`（前面发出的字符数 >= 后面字符数）
2. 同时活跃的青蛙数 = 已经发出 'c' 但还没发出 'k' 的青蛙数 = `c - k`
3. 最终必须 `c == r == o == a == k`（所有青蛙都叫完了）
4. 方法三最简洁：维护5个计数器，检查单调性，答案是 `c - k` 的最大值

## 易错点

1. 中间状态合法但最终不合法：例如 "croakcroa"，过程中没有违规但最终有青蛙没叫完
2. 字符只能是 'c','r','o','a','k'，题目保证，但逻辑上要处理好顺序
3. 方法三中 `c - k` 是活跃青蛙数，而不是 `c + r + o + a`（两者等价，但 `c-k` 更简洁）
