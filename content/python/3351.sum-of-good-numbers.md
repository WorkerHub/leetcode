## 题目描述

给你两个整数 `num1` 和 `num2`。

如果一个整数 `x` 满足 `x` 能被 `num1` 整除，且 `num1` 的十进制表示是 `x` 的十进制表示的子序列，则称 `x` 是一个**好数**。

返回满足条件且在 `[1, num2]` 范围内的所有好数之和。

**提示：**
- `1 <= num1, num2 <= 10^6`

## 解题思路

枚举 `num1` 的所有倍数（在 `[num1, num2]` 范围内），对每个倍数 `x`，验证 `num1` 的字符串是否是 `x` 的字符串的子序列。

子序列检验：用双指针在 `str(x)` 中顺序匹配 `str(num1)` 的每个字符。

倍数枚举：最多 `num2 / num1` 个倍数，约 `10^6 / 1 = 10^6` 次。

## Python 代码实现

### 方法一：枚举倍数 + 子序列检验（推荐）

```python
class Solution:
    def sumOfGoodNumbers(self, num1: int, num2: int) -> int:
        s1 = str(num1)
        total = 0
        
        # 枚举 num1 的倍数
        x = num1
        while x <= num2:
            # 检验 s1 是否是 str(x) 的子序列
            sx = str(x)
            i = 0  # s1 的指针
            for c in sx:
                if i < len(s1) and c == s1[i]:
                    i += 1
            if i == len(s1):
                total += x
            x += num1
        
        return total
```

### 方法二：使用 Python 内置函数简化

```python
class Solution:
    def sumOfGoodNumbers(self, num1: int, num2: int) -> int:
        s1 = str(num1)
        total = 0
        
        # 子序列检验函数
        def is_subseq(sub, main):
            it = iter(main)
            return all(c in it for c in sub)
        
        x = num1
        while x <= num2:
            if is_subseq(s1, str(x)):
                total += x
            x += num1
        
        return total
```

## 复杂度分析

- 时间复杂度：O(num2/num1 * log(num2))，枚举倍数 * 子序列检验（O(位数)）
- 空间复杂度：O(log(num2))，字符串转换

## 关键点总结

1. 好数必须是 num1 的倍数，直接枚举倍数。
2. 子序列检验用双指针实现，O(len)。
3. 枚举数量约为 `num2/num1`，最坏情况 `10^6` 次（num1=1 时），每次验证 O(6)，总时间可接受。

## 易错点

1. 子序列是有序的，不是子集（字符顺序必须保持）。
2. `x = num1` 开始，步长为 `num1`（枚举 num1 的倍数）。
3. 当 num1 = 1 时，所有正整数都包含 "1" 作为子序列... 不对，"1" 需要作为子序列出现，任何含 '1' 的数都满足，但数字本身是 1 的倍数（所有正整数），需要包含字符 '1'。
