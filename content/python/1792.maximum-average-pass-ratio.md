## 题目描述

一所学校里有一些班级，每个班级里有一些学生，现在每个班都会进行一场期末考试。给你一个二维数组 `classes`，其中 `classes[i] = [passi, totali]`，表示你提前知道了第 `i` 个班级总共有 `totali` 个学生，其中只有 `passi` 个学生可以通过考试。

给你一个整数 `extraStudents`，表示额外有这么多个聪明的学生，他们**一定**能通过任何班级的期末考。你需要给这 `extraStudents` 个学生每人都安排一个班级，使得所有班级的**平均通过率**最大。

一个班级的通过率等于这个班通过考试的学生人数除以这个班的总人数，即 `pass / total`。平均通过率是所有班级的通过率之和除以班级数量。

返回在安排这 `extraStudents` 个学生之后的**最大**平均通过率。答案与标准答案的误差在 `10^-5` 以内都可以接受。

**提示：**
- `1 <= classes.length <= 10^5`
- `classes[i].length == 2`
- `1 <= passi <= totali <= 10^5`
- `1 <= extraStudents <= 10^5`

## 解题思路

贪心：每次将额外学生加入"增益最大"的班级。

一个班级加入一个额外学生后，通过率的增量为：
`gain = (pass+1)/(total+1) - pass/total`

使用**最大堆**，以增益为优先级，每次取出增益最大的班级，加入一名学生，再放回堆中，重复 `extraStudents` 次。

## 代码实现

### 方法一：最大堆贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxAverageRatio(self, classes: List[List[int]], extraStudents: int) -> float:
        # 计算加入一名额外学生的增益
        def gain(p, t):
            return (p + 1) / (t + 1) - p / t

        # Python 使用最小堆，用负增益模拟最大堆
        heap = [(-gain(p, t), p, t) for p, t in classes]
        heapq.heapify(heap)

        for _ in range(extraStudents):
            g, p, t = heapq.heappop(heap)
            # 加入一名额外学生
            p += 1
            t += 1
            heapq.heappush(heap, (-gain(p, t), p, t))

        # 计算最终平均通过率
        return sum(p / t for _, p, t in heap) / len(heap)
```

### 方法二：详细注释版

```python
from typing import List
import heapq

class Solution:
    def maxAverageRatio(self, classes: List[List[int]], extraStudents: int) -> float:
        def gain(p, t):
            # 加一名额外学生后通过率的增量
            return (p + 1) / (t + 1) - p / t

        # 构建最大堆（用负值模拟）
        # 堆元素：(-增益, 通过人数, 总人数)
        heap = []
        for p, t in classes:
            heapq.heappush(heap, (-gain(p, t), p, t))

        # 贪心分配额外学生
        for _ in range(extraStudents):
            neg_g, p, t = heapq.heappop(heap)
            p += 1
            t += 1
            # 更新该班级的增益并重新入堆
            heapq.heappush(heap, (-gain(p, t), p, t))

        # 求所有班级平均通过率
        n = len(heap)
        total_ratio = sum(p / t for _, p, t in heap)
        return total_ratio / n
```

## 复杂度分析

- **时间复杂度**：O((n + extraStudents) * log n)，每次堆操作 O(log n)
- **空间复杂度**：O(n)，堆的大小

## 关键点总结

1. 贪心策略：每次将学生加入通过率增益最大的班级
2. 增益函数：`(p+1)/(t+1) - p/t`，分析每班加一人的边际收益
3. 最大堆高效维护每次操作后的最优班级
4. Python 最大堆用负数模拟（heapq 默认最小堆）

## 易错点

1. 增益会随着班级人数增加而减小（边际递减），所以每次都要重新计算
2. 最终求平均时要对所有班级取平均，不要对堆中元素顺序有假设
3. 浮点精度：Python 的 float 足够精确，不需要特别处理
