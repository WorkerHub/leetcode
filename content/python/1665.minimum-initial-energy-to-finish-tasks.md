## 题目描述

给你一个任务数组 `tasks`，其中 `tasks[i] = [actual_i, minimum_i]`：
- `actual_i` 是完成第 i 个任务需要消耗的实际能量
- `minimum_i` 是开始第 i 个任务前需要具备的最低能量

返回完成所有任务所需的**最少初始能量**。

**提示：**
- `minimum_i >= actual_i`

## 解题思路

**贪心排序：**

关键问题是确定任务的最优执行顺序。

**交换论证：** 假设有两个任务 A 和 B，当前能量为 e：
- 先 A 后 B 的条件：`e >= min_A` 且 `e - actual_A >= min_B`
- 先 B 后 A 的条件：`e >= min_B` 且 `e - actual_B >= min_A`

令 `slack = min - actual`（余量），当 `slack_A > slack_B` 时，A 应在 B 之前执行。

**结论：** 按 `min - actual`（余量）从大到小排序。

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minimumEffort(self, tasks: List[List[int]]) -> int:
        # 按 min - actual 从大到小排序
        tasks.sort(key=lambda x: x[0] - x[1])
        
        # 从后往前确定最少初始能量
        # 从最后一个任务开始，逆序确定每步需要的最低能量
        energy = 0  # 当前需要的最低能量（从后往前）
        
        for actual, minimum in reversed(tasks):
            # 执行此任务需要 minimum 的能量
            # 执行后剩余 energy 的能量（用于后续任务）
            # 所以执行前需要 max(minimum, energy + actual)
            energy = max(minimum, energy + actual)
        
        return energy
```

### 方法二：前向模拟验证

```python
from typing import List

class Solution:
    def minimumEffort(self, tasks: List[List[int]]) -> int:
        # 按 min - actual 降序排序
        tasks.sort(key=lambda x: x[1] - x[0], reverse=True)
        
        # 从后往前反推最少初始能量
        ans = 0
        for actual, minimum in reversed(tasks):
            ans = max(minimum, ans + actual)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(n log n) | O(1) |

## 关键点总结

1. 贪心排序：按 `min - actual`（余量/松弛度）从大到小排序
2. 余量大的任务先做（它们对初始能量要求更"苛刻"）
3. 从最后一个任务反推：`energy = max(minimum, energy + actual)`
4. 反推时，`energy` 表示"执行此任务及之后所有任务需要的最低能量"

## 易错点

- 排序方向：余量（`min - actual`）大的排前面
- 反推公式：若执行后还需要 `energy`，则执行前需要 `energy + actual`，但还要满足 `>= minimum`
- 不能反向（从前往后确定能量太复杂）
