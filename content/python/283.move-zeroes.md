## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意，必须在不复制数组的情况下原地对数组进行操作。

**示例 1:**

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

**示例 2:**

```
输入: nums = [0]
输出: [0]
```

**提示:**

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

**进阶：** 你能尽量减少完成的操作次数吗？

## 解题思路

这是一道经典的双指针问题，要求原地移动数组元素。核心思想是将所有非零元素移到前面，保持相对顺序，剩余位置填零。

**关键观察：**

1. 需要保持非零元素的相对顺序
2. 必须原地操作，不能使用额外数组
3. 本质上是将非零元素向前"压缩"

**算法思路：**

方法一（双指针 - 快慢指针）：
- 使用慢指针 `slow` 指向下一个非零元素应该放置的位置
- 使用快指针 `fast` 遍历数组
- 遇到非零元素时，将其放到 `slow` 位置，然后 `slow++`
- 最后将 `slow` 之后的位置全部填零

方法二（优化的交换法）：
- 类似方法一，但遇到非零元素时直接交换
- 减少了最后填零的步骤
- 当数组中零较少时，性能更优

## Python 代码实现

### 方法一：双指针覆盖法（推荐）

```python
from typing import List

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        双指针：先移动非零元素，再填充零
        时间复杂度 O(n)，空间复杂度 O(1)
        """
        slow = 0  # 慢指针：下一个非零元素应该放的位置
        
        # 第一遍：将所有非零元素移到前面
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        
        # 第二遍：将剩余位置填零
        for i in range(slow, len(nums)):
            nums[i] = 0
```

### 方法二：双指针交换法（操作次数更少）

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        双指针交换法：遇到非零元素直接交换
        当非零元素较多时，减少不必要的赋值操作
        """
        slow = 0  # 指向第一个零的位置
        
        for fast in range(len(nums)):
            if nums[fast] != 0:
                # 只有当 slow != fast 时才交换（避免自己和自己交换）
                if slow != fast:
                    nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

### 方法三：详细注释版（新手友好）

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        移动零到数组末尾，保持非零元素相对顺序
        
        思路：
        1. 使用双指针，slow 指向"已处理区域"的末尾
        2. fast 遍历整个数组
        3. 遇到非零元素就放到 slow 位置
        
        示例：[0, 1, 0, 3, 12]
        初始: slow=0, fast=0
        fast=0: nums[0]=0, 跳过
        fast=1: nums[1]=1, nums[0]=1, slow=1  -> [1, 1, 0, 3, 12]
        fast=2: nums[2]=0, 跳过
        fast=3: nums[3]=3, nums[1]=3, slow=2  -> [1, 3, 0, 3, 12]
        fast=4: nums[4]=12, nums[2]=12, slow=3 -> [1, 3, 12, 3, 12]
        最后填零: [1, 3, 12, 0, 0]
        """
        slow = 0
        
        # 遍历数组，将非零元素移到前面
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        
        # 将剩余位置填充为 0
        while slow < len(nums):
            nums[slow] = 0
            slow += 1
```

### 方法四：暴力法（不推荐，但便于理解）

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        暴力法：每次找到零就移到末尾
        时间复杂度 O(n^2)，仅用于理解思路
        """
        n = len(nums)
        # 从后往前找零
        i = 0
        while i < n:
            if nums[i] == 0:
                # 将这个零移到末尾
                for j in range(i, n - 1):
                    nums[j] = nums[j + 1]
                nums[n - 1] = 0
                n -= 1  # 减少遍历范围
            else:
                i += 1
```

### 方法五：Python 特色解法（使用列表推导）

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        利用 Python 列表推导式
        注意：虽然简洁，但不是严格的原地操作
        """
        # 提取所有非零元素
        non_zeros = [x for x in nums if x != 0]
        # 计算零的个数
        zero_count = len(nums) - len(non_zeros)
        
        # 重新赋值（修改原数组）
        nums[:] = non_zeros + [0] * zero_count
```

## 复杂度分析

**方法一、二：双指针法**
- 时间复杂度：`O(n)` 最多遍历数组两次
- 空间复杂度：`O(1)` 只使用常数额外空间

**方法四：暴力法**
- 时间复杂度：`O(n^2)` 每次移动需要 O(n)
- 空间复杂度：`O(1)`

**方法五：列表推导**
- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)` 创建了新列表（虽然最后赋值回原数组）

## 关键点总结

1. **双指针技巧**：快指针遍历，慢指针标记插入位置
2. **原地操作**：通过覆盖或交换实现，不使用额外数组
3. **保持顺序**：从前往后遍历，自然保持非零元素的相对顺序
4. **两种策略**：覆盖+填零 vs 直接交换，适用场景不同
5. **边界处理**：全零、全非零、单元素等特殊情况

## 易错点

1. **忘记填零**：方法一中只移动了非零元素，忘记将后面填零
2. **破坏顺序**：错误地从后往前处理，导致顺序混乱
3. **不是原地操作**：使用了额外数组，不符合题目要求
4. **自我交换**：方法二中忘记判断 `slow != fast`，导致不必要的交换
5. **边界条件**：空数组、只有一个元素的情况
