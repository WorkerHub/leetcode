## 题目描述

给定一个 DataFrame `customers`，删除 `email` 列中重复的行（保留第一次出现的行）。

**示例：**
```
输入：包含重复 email 的 customers DataFrame

输出：去重后的 DataFrame（每个 email 只保留一条）
```

## Python 代码实现

### 方法一：drop_duplicates（推荐）

```python
import pandas as pd

def dropDuplicateEmails(customers: pd.DataFrame) -> pd.DataFrame:
    # 按 email 列去重，保留第一次出现的行
    return customers.drop_duplicates(subset='email', keep='first')
```

### 方法二：基于 email 过滤

```python
import pandas as pd

def dropDuplicateEmails(customers: pd.DataFrame) -> pd.DataFrame:
    return customers[~customers['email'].duplicated(keep='first')]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `df.drop_duplicates(subset=col, keep='first')` 按指定列去重
2. `keep='first'` 保留第一次出现的行（默认值），`keep='last'` 保留最后一次
3. `keep=False` 删除所有重复行（包括第一次出现）
