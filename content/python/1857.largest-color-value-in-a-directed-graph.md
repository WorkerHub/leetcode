## 题目描述

给你一个**有向图**，它含有 `n` 个节点和 `m` 条边。节点下标从 0 开始，每个节点都被赋予一个颜色（小写字母）。

求从任意节点出发，某条**最长路径**中颜色出现次数最多的颜色数量，若图中存在环则返回 -1。

**示例：**
```
输入：colors = "abaca", edges = [[0,1],[0,2],[2,3],[3,4]]
输出：3
解释：路径 0 -> 2 -> 3 -> 4，颜色为 a b a c a，其中 a 出现 3 次
```

## 解题思路

**拓扑排序 + DP**：

`dp[u][c]` = 从某条以 u 结尾的路径中，颜色 c 出现的最大次数。

拓扑排序中，处理节点 u 时，对每条边 (u, v)：
`dp[v][c] = max(dp[v][c], dp[u][c] + (colors[v] == c))`

初始化：`dp[u][colors[u]] = 1`（仅自身）

若图有环（存在无法拓扑排序的节点），返回 -1。

答案为所有 `dp[u][c]` 的最大值。

## 代码实现

### 方法一：拓扑排序 + DP（推荐）

```python
from collections import deque
from typing import List

class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        graph = [[] for _ in range(n)]
        in_degree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            in_degree[v] += 1

        # dp[u][c] = 以 u 结尾的路径中颜色 c 的最大出现次数
        dp = [[0] * 26 for _ in range(n)]
        for u in range(n):
            dp[u][ord(colors[u]) - ord('a')] = 1  # 节点自身贡献

        # 拓扑排序（BFS）
        queue = deque(u for u in range(n) if in_degree[u] == 0)
        processed = 0
        ans = 0

        while queue:
            u = queue.popleft()
            processed += 1
            ans = max(ans, max(dp[u]))  # 更新答案

            for v in graph[u]:
                # 更新 v 的 dp 值
                for c in range(26):
                    dp[v][c] = max(dp[v][c], dp[u][c] + (ord(colors[v]) - ord('a') == c))
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)

        # 若未处理所有节点，说明有环
        return ans if processed == n else -1
```

### 方法二：记忆化 DFS

```python
from typing import List
from functools import lru_cache

class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)

        # 状态：0=未访问，1=访问中，2=已完成
        state = [0] * n
        # dp[u] = 长度为 26 的数组，dp[u][c] 表示从 u 出发的路径中颜色 c 的最大数量
        memo = [None] * n

        def dfs(u: int):
            if state[u] == 1:
                return None  # 有环
            if state[u] == 2:
                return memo[u]
            state[u] = 1
            cnt = [0] * 26
            cnt[ord(colors[u]) - ord('a')] = 1
            for v in graph[u]:
                sub = dfs(v)
                if sub is None:
                    return None  # 子树有环，传播
                for c in range(26):
                    cnt[c] = max(cnt[c], sub[c] + (ord(colors[u]) - ord('a') == c))
            state[u] = 2
            memo[u] = cnt
            return cnt

        ans = 0
        for u in range(n):
            res = dfs(u)
            if res is None:
                return -1
            ans = max(ans, max(res))
        return ans
```

## 复杂度分析

- **时间复杂度**：O((n + m) * 26)，每个节点处理一次，每次更新 26 个颜色
- **空间复杂度**：O(n * 26)，DP 数组

## 关键点总结

1. 对每个颜色独立维护 DP，总共 26 种颜色
2. 拓扑排序确保处理每个节点时其所有前驱已处理
3. 未处理节点数 < n 说明有环，返回 -1

## 易错点

- 初始化时只将节点自身颜色的计数设为 1，其余为 0
- 更新 dp[v] 时，是 `dp[u][c] + (colors[v] == c)`（加上 v 的颜色贡献）
