## 题目描述

给你一个二进制字符串 `boxes`，其中 `boxes[i]` 为 '1' 表示第 i 个箱子里有一个球，'0' 表示为空。

返回一个数组 `answer`，`answer[i]` 为将所有球移到第 i 个箱子所需的最少操作数（每次操作将一个球移动一步）。

**示例 1：**

```
输入：boxes = "110"
输出：[1, 1, 3]
解释：
- 将所有球移到箱 0：ball(1)移1步，共1步。
- 将所有球移到箱 1：ball(0)移1步，共1步。
- 将所有球移到箱 2：ball(0)移2步+ball(1)移1步=3步。
```

**示例 2：**

```
输入：boxes = "001011"
输出：[11, 8, 5, 4, 3, 4]
```

**提示：**
- `1 <= boxes.length <= 2000`
- `boxes[i]` 为 '0' 或 '1'

## 解题思路

使用**前缀和**优化：
1. 从左到右遍历，维护左边的球数 `left_balls` 和左边球到当前位置的距离 `left_cost`。
2. 从右到左遍历，维护右边的球数 `right_balls` 和右边球到当前位置的距离 `right_cost`。
3. `answer[i] = left_cost[i] + right_cost[i]`。

## Python 代码实现

### 方法一：前缀和双扫描（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        ans = [0] * n

        # 从左到右：统计每个位置的左侧贡献
        balls = 0
        cost = 0
        for i in range(n):
            ans[i] += cost
            if boxes[i] == '1':
                balls += 1
            cost += balls  # 每个球向右移动 1 步，代价加 balls

        # 从右到左：统计每个位置的右侧贡献
        balls = 0
        cost = 0
        for i in range(n - 1, -1, -1):
            ans[i] += cost
            if boxes[i] == '1':
                balls += 1
            cost += balls

        return ans
```

### 方法二：暴力（O(n^2)，理解用）

```python
class Solution:
    def minOperations(self, boxes: str) -> list:
        n = len(boxes)
        ans = []
        for i in range(n):
            total = sum(abs(i - j) for j, c in enumerate(boxes) if c == '1')
            ans.append(total)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n^2)（方法二）
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. 前缀和扫描两遍：左扫贡献所有左侧球，右扫贡献所有右侧球。
2. 向右移动时，每多走 1 步，所有左侧球各多贡献 1（总贡献 += 球数）。
3. 这是 LeetCode 1769（相同思路）的变体。

## 易错点

1. 两次扫描分别统计左侧和右侧，最后相加。
2. 当前位置的球本身也算在"左侧"或"右侧"的范围内（`i` 处的球在到 `i` 之前就已经贡献了）。
