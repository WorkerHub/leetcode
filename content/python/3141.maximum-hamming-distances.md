## 题目描述

给你一个整数数组 `nums` 和整数 `m`，数组中的数范围在 `[0, 2^m - 1]`。

对每个元素 `nums[i]`，返回 `nums[i]` 与 `nums` 中其他所有元素的 **最大汉明距离**。

汉明距离指两个整数二进制表示中不同位的数量。

返回数组 `answer`，`answer[i]` 为 `nums[i]` 与 `nums` 中所有元素（包括自身）的最大汉明距离。

**提示：**
- `1 <= m <= 17`
- `2 <= nums.length <= 5 * 10^4`

## 解题思路

对每个 `nums[i]`，最大汉明距离等于 m 减去"与 nums[i] 汉明距离最小的数"的汉明距离中，应找与 nums[i] 最相似的元素。

等价于：找 `nums` 中与 `nums[i]` 汉明距离最小的元素，设为 `min_dist`，则最大汉明距离 = m - min_dist（与 `nums[i]` 的按位取反最接近的汉明距离... 不对）。

实际上：最大汉明距离 = m - min_{x in nums} hamming(nums[i], x)，但这是最小汉明距离，应该求最大。

正确：最大汉明距离 = max_{x in nums} hamming(nums[i], x)。

用超集枚举/BFS 在超立方体上找：`nums` 中存在的数的补集上离 `~nums[i]` 最近的数，利用多源 BFS。

## Python 代码实现

### 方法一：多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maximumHammingDistances(self, nums: List[int], m: int) -> List[int]:
        # 最大汉明距离 = m - 最小汉明距离(nums[i] 的按位取反 在 nums 中的最近距离)
        # 对 nums[i] 的按位取反，找 nums 中与之汉明距离最小的元素
        # 等价于：对所有 ~nums[i]（mod 2^m），BFS 找 nums 中的最近点

        size = 1 << m
        mask = size - 1

        # 多源 BFS：从 nums 中的所有点出发，求每个点到 nums 的最短汉明距离
        dist = [-1] * size
        q = deque()
        for x in nums:
            if dist[x] == -1:
                dist[x] = 0
                q.append(x)

        while q:
            x = q.popleft()
            for i in range(m):
                y = x ^ (1 << i)  # 翻转第 i 位
                if dist[y] == -1:
                    dist[y] = dist[x] + 1
                    q.append(y)

        # 最大汉明距离 = m - dist[~nums[i] & mask]
        return [m - dist[~x & mask] for x in nums]
```

### 方法二：暴力（小数据）

```python
from typing import List

class Solution:
    def maximumHammingDistances(self, nums: List[int], m: int) -> List[int]:
        def hamming(a, b):
            return bin(a ^ b).count('1')
        return [max(hamming(x, y) for y in nums) for x in nums]
```

## 复杂度分析

- 时间复杂度：O(2^m * m)，BFS 遍历所有 2^m 个节点
- 空间复杂度：O(2^m)

## 关键点总结

1. 关键转化：nums[i] 的最大汉明距离 = m - dist[~nums[i]]
2. 多源 BFS 同时从所有 nums 中的点出发，O(2^m * m) 时间
3. 需要对 ~nums[i] 取 mask（低 m 位）

## 易错点

1. 取反时需要 `& mask`，否则高位也被翻转
2. BFS 时每个节点翻转 m 个位，枚举所有相邻节点
