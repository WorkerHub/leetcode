## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，长度均为 `n`。

对每个下标 `i`（0 到 n-1），你需要从 `nums1[i]` 和 `nums2[i]` 中选择其中**一个**。

设选出的值之和为 S1（来自 nums1 的值之和）和 S2（来自 nums2 的值之和），**返回使 S1 等于 S2 的选择方式数**（模 10^9+7）。

**示例：**
```
输入：nums1 = [1,2,3], nums2 = [2,2,2]
输出：1
解释：只有一种选法使 S1=S2（全选 nums2：2+2+2=6，但那样 S1=0）
实际：选 nums1[0]=1, nums2[1]=2, nums2[2]=2：S1=1, S2=4，不等...
需仔细分析。
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 500`
- `1 <= nums1[i], nums2[i] <= 500`

## 解题思路

**动态规划**

设 `diff[i] = nums1[i] - nums2[i]`，选 `nums1[i]` 贡献 `+diff[i]`，选 `nums2[i]` 贡献 `0`（基准）。

最终希望选择之后，总差值为 0（即 S1 = S2）。

设 `dp[j]` = 当前总差值为 `j` 时的方案数，`j` 的范围需要考虑差值的范围。

差值范围：最小为 `sum(min(0, diff[i]))`，最大为 `sum(max(0, diff[i]))`。

用偏移量处理负数下标。

## 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countWays(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums1)

        # dp[diff] = 当差值为 diff 时的方案数
        # 初始状态：差值为 0，方案数为 1
        dp = defaultdict(int)
        dp[0] = 1

        for i in range(n):
            d = nums1[i] - nums2[i]
            new_dp = defaultdict(int)
            for diff, ways in dp.items():
                # 选 nums1[i]：差值增加 d
                new_dp[diff + d] = (new_dp[diff + d] + ways) % MOD
                # 选 nums2[i]：差值不变（基准）
                new_dp[diff] = (new_dp[diff] + ways) % MOD
            dp = new_dp

        return dp[0]
```

### 方法二：DP 数组（偏移量）

```python
from typing import List

class Solution:
    def countWays(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums1)
        # 最大差值范围：sum(nums1) 最大 = 500*500 = 250000
        # 最小差值：-250000
        max_diff = sum(max(a, b) for a, b in zip(nums1, nums2))
        min_diff = -max_diff
        offset = max_diff  # 偏移量使下标非负

        size = 2 * max_diff + 1
        dp = [0] * size
        dp[offset] = 1  # 初始差值为 0

        for a, b in zip(nums1, nums2):
            d = a - b
            new_dp = [0] * size
            for j in range(size):
                if dp[j] == 0:
                    continue
                # 选 nums1（差值 + d）
                nj1 = j + d
                if 0 <= nj1 < size:
                    new_dp[nj1] = (new_dp[nj1] + dp[j]) % MOD
                # 选 nums2（差值不变）
                new_dp[j] = (new_dp[j] + dp[j]) % MOD
            dp = new_dp

        return dp[offset]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 DP | O(n * max_diff) | O(max_diff) |
| 数组 DP | O(n * max_diff) | O(max_diff) |

max_diff 最大为 n * 500 = 250000。

## 关键点总结

1. 将选择问题转化为差值问题：选 nums1 贡献 `nums1[i] - nums2[i]`，选 nums2 贡献 0。
2. 最终差值为 0 即 S1 = S2。
3. 用哈希表 DP 处理差值范围，避免固定大小数组的内存浪费。

## 易错点

- 差值可以是负数，需要用偏移量或哈希表处理。
- 对答案取模 `10^9 + 7`。
