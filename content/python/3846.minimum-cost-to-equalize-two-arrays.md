## 题目描述

给你两个整数数组 `nums1` 和 `nums2`（长度相同），以及两个整数 `cost1` 和 `cost2`。每次操作可以选择：
- 操作一：花费 `cost1`，将 `nums1` 中任意一个元素加 1。
- 操作二：花费 `cost2`，将 `nums1` 和 `nums2` 中各一个元素同时加 1。

使得 `nums1[i] >= nums2[i]` 对所有 i 成立，返回最小总花费。

**示例 1：**

```
输入：nums1 = [1, 4], nums2 = [2, 3], cost1 = 2, cost2 = 1
输出：2
解释：对 (nums1[0], nums2[0])：差为 1，用操作二（cost 1）补上，cost1[0]+=1。
```

**示例 2：**

```
输入：nums1 = [4, 3], nums2 = [2, 3], cost1 = 2, cost2 = 3
输出：0
解释：已满足 nums1[i] >= nums2[i]。
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^9`

## 解题思路

对每个位置 i，若 `nums1[i] < nums2[i]`，需要增加 `diff[i] = nums2[i] - nums1[i]`。

操作二可以同时增加某对 `(nums1[j], nums2[j])` 的值（对 j 处的差没有帮助，但对某些其他情况有用）。

贪心：对每个 diff[i] > 0，优先用操作二（若 `2 * cost2 < cost1` 则操作二便宜，否则用操作一）。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minCost(self, nums1: List[int], nums2: List[int], cost1: int, cost2: int) -> int:
        total_ops = 0  # 需要增加 nums1 的总次数

        for a, b in zip(nums1, nums2):
            if a < b:
                total_ops += b - a

        # 每个 diff 单位，用操作一花费 cost1，或配合操作二（若有配对）
        # 操作二 cost2 可以同时+1给两个位置，但对当前 diff 位置帮助+1
        # 若 2*cost2 < cost1：用操作二代替操作一（但操作二需要另一个位置也+1）
        # 贪心：total_ops 次增加，用操作二还是操作一？

        if 2 * cost2 < cost1:
            # 操作二更划算：每对操作二花费 cost2*2 = 两个 cost1 花费 cost1*2
            # 总花费 = total_ops * cost2（若 total_ops 为偶数）
            # 若奇数：(total_ops - 1) * cost2 + cost1
            # 因为操作二每次同时给两个位置+1，若只需要一个位置的1次，需用操作一
            return (total_ops // 2) * (2 * cost2) + (total_ops % 2) * cost1
        else:
            # 操作一更划算
            return total_ops * cost1
```

### 方法二：考虑操作二的配对

```python
from typing import List

class Solution:
    def minCost(self, nums1: List[int], nums2: List[int], cost1: int, cost2: int) -> int:
        diffs = [max(0, b - a) for a, b in zip(nums1, nums2)]
        total = sum(diffs)

        if total == 0:
            return 0

        # 单次增加的最优成本
        unit_cost = min(cost1, 2 * cost2)

        if unit_cost == cost1:
            return total * cost1
        else:
            # 2*cost2 < cost1，尽量用操作二
            # 操作二同时+1给两个"位置"（不一定是 diff 位置）
            # 若 total 为奇数，最后一次用 cost1
            return (total // 2) * 2 * cost2 + (total % 2) * cost1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个需要补足的 diff 单位可以用操作一（cost1）或配合操作二（2*cost2）。
2. 若 `2*cost2 < cost1`，则用操作二更经济。
3. 奇数个单位操作时，最后一个必须用操作一（操作二需要两个）。

## 易错点

1. 操作二同时给两个位置 +1，要补 total_ops 个单位需要 `total_ops / 2` 次操作二（若为偶数）。
2. 剩余 1 个单位（奇数时）必须用操作一。
