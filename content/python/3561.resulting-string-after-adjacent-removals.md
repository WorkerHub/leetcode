## 题目描述

给定一个字符串 `s`，重复执行以下操作直到无法继续：找到相邻的两个字符，它们在字母表中相邻（如 'a' 和 'b'，或 'z' 和 'a'），将它们删除。返回最终剩余的字符串。

**示例 1：**

```
输入：s = "abba"
输出：""
解释："abba" -> 删除 "ab" -> "ba" -> 删除 "ba" -> ""
```

**示例 2：**

```
输入：s = "foo"
输出："foo"
解释：没有相邻字母表相邻的字符对，无法删除。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只含小写字母

## 解题思路

使用栈模拟：
1. 遍历字符串，将字符逐个压入栈
2. 若栈顶字符与当前字符在字母表中相邻（差为 1），则弹出栈顶（相当于删除这对字符）
3. 否则压入当前字符
4. 注意循环情况：'a' 和 'z' 也相邻（差为 25）

## Python 代码实现

### 方法一：栈模拟（推荐）

```python
class Solution:
    def resultingString(self, s: str) -> str:
        stack = []
        for c in s:
            if stack:
                top = stack[-1]
                diff = abs(ord(c) - ord(top))
                # 相邻字母：差为1，或 'a' 和 'z'（差为25）
                if diff == 1 or diff == 25:
                    stack.pop()
                    continue
            stack.append(c)
        return ''.join(stack)
```

### 方法二：递归模拟（不推荐，效率低）

```python
class Solution:
    def resultingString(self, s: str) -> str:
        def adjacent(a, b):
            d = abs(ord(a) - ord(b))
            return d == 1 or d == 25

        while True:
            found = False
            for i in range(len(s) - 1):
                if adjacent(s[i], s[i+1]):
                    s = s[:i] + s[i+2:]
                    found = True
                    break
            if not found:
                break
        return s
```

## 复杂度分析

- 时间复杂度：O(n)（方法一栈），O(n^2)（方法二递归）
- 空间复杂度：O(n)，栈的空间

## 关键点总结

1. 栈模拟：字符与栈顶字符相邻则消除
2. 字母表相邻包括 'a' 和 'z'（循环字母表）
3. 消除可以连锁触发（因为删除后新的相邻对可能出现）

## 易错点

1. 不要忘记 'a' 和 'z' 是字母表上相邻的（循环）
2. 差值判断：`diff == 1 or diff == 25`（25 = 26 - 1）
3. 栈操作保证了连锁消除的正确处理
