## 题目描述

给你一个整数数组 `nums`、整数 `lo`、`hi` 和整数 `k`。找出在范围 `[lo, hi]` 内，未出现在 `nums` 中的第 `k` 个缺失数。

**示例 1：**

```
输入：nums = [2,4], lo = 1, hi = 5, k = 2
输出：3
解释：范围[1,5]内缺失：1,3,5，第2个是3
```

**示例 2：**

```
输入：nums = [1,2,3,4], lo = 1, hi = 5, k = 1
输出：5
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= lo <= hi <= 10^5`
- `1 <= k <= (hi - lo + 1)`

## 解题思路

建立 nums 的集合，遍历 `[lo, hi]`，统计不在集合中的数，返回第 k 个。

## Python 代码实现

### 方法一：集合查询（推荐）

```python
from typing import List

class Solution:
    def findKthMissing(self, nums: List[int], lo: int, hi: int, k: int) -> int:
        num_set = set(nums)
        count = 0
        for x in range(lo, hi + 1):
            if x not in num_set:
                count += 1
                if count == k:
                    return x
        return -1  # 不应到达
```

### 方法二：二分查找

```python
from typing import List

class Solution:
    def findKthMissing(self, nums: List[int], lo: int, hi: int, k: int) -> int:
        # 在 [lo, x] 内缺失的数量 = (x - lo + 1) - count(nums 中在 [lo,x] 内的数)
        num_set = set(nums)

        def missing_count(x):
            return (x - lo + 1) - sum(1 for n in nums if lo <= n <= x)

        # 二分找第 k 个缺失
        left, right = lo, hi
        while left < right:
            mid = (left + right) // 2
            cnt = sum(1 for n in nums if lo <= n <= mid)
            missing = mid - lo + 1 - cnt
            if missing >= k:
                right = mid
            else:
                left = mid + 1
        return left
```

## 复杂度分析

- 时间复杂度：O(n + (hi - lo + 1))（方法一），O((hi-lo) log(hi-lo) * n)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 集合查找 O(1)，遍历范围一次即可
2. 范围较小时直接遍历最简单
3. 二分在范围很大但 k 很小时更高效

## 易错点

1. 范围是 `[lo, hi]`，包含端点
2. nums 中可能有范围外的数，不影响答案
3. 保证第 k 个缺失数存在
