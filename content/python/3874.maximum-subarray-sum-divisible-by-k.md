## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，找到和能被 `k` 整除的子数组中和最大的那个，返回该最大和。如果不存在这样的子数组则返回 0。

**示例 1：**

```
输入：nums = [4, 5, 0, -2, -3, 1], k = 5
输出：7
解释：[4,5,0,-2,-3,1] 中，[4,5,0,-2,-3,1] 和为 5，[5] 和为 5，[5,0,-2,-3,1]=1...
最大被 k=5 整除的子数组和为 10（[4,5,0,-2,-3,1]? 和为5，或[5,0,-2,-3]=0...）
```

**示例 2：**

```
输入：nums = [5], k = 5
输出：5
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= 10^4`

## 解题思路

使用**前缀和 + 哈希表**：
1. 计算前缀和 `prefix[i]`，子数组 `[l, r]` 的和 = `prefix[r+1] - prefix[l]`。
2. 要使和被 k 整除，需要 `(prefix[r+1] - prefix[l]) % k == 0`，即 `prefix[r+1] % k == prefix[l] % k`。
3. 对每个余数，记录前缀和中出现的最大值，找 `prefix[r+1] - max_prefix_with_same_remainder`。

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarraySumDivisibleByK(self, nums: List[int], k: int) -> int:
        # best[r] = 具有余数 r 的最大前缀和
        best = defaultdict(lambda: float('-inf'))
        best[0] = 0  # 空前缀，余数为 0，前缀和为 0

        prefix = 0
        ans = 0  # 初始为 0（不存在时返回 0）

        for v in nums:
            prefix += v
            rem = prefix % k
            # 子数组和 = prefix - best[rem]，需要最大化
            if best[rem] != float('-inf'):
                candidate = prefix - best[rem]
                if candidate > 0:  # 只记录正数和（若要求最大，可能为负）
                    ans = max(ans, candidate)
            # 更新 best[rem]
            best[rem] = max(best[rem], prefix)

        return ans
```

### 方法二：处理负余数

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarraySumDivisibleByK(self, nums: List[int], k: int) -> int:
        # Python 的取模对负数结果非负，但前缀和可能为负
        best = {0: 0}  # 余数 -> 最大前缀和
        prefix = 0
        ans = 0

        for v in nums:
            prefix += v
            rem = prefix % k  # Python 保证 rem >= 0

            if rem in best:
                # 子数组和 = prefix - best[rem]
                candidate = prefix - best[rem]
                ans = max(ans, candidate)

            # 更新：保存具有余数 rem 的最大前缀和
            if rem not in best or best[rem] < prefix:
                best[rem] = prefix

        return max(ans, 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，哈希表存储 k 个不同余数

## 关键点总结

1. 两个前缀和余数相同 => 其差（子数组和）被 k 整除。
2. 要最大化子数组和，对每个余数保存最小前缀和（使差最大），不是最大前缀和。
3. 修正：应该是 `prefix - min_prefix_with_same_rem`，而不是 `prefix - max`。

## 易错点

1. 应保存**最小**前缀和（不是最大），这样 `prefix - min_prefix` 最大。
2. Python 中负数取模结果是非负的，注意与 C++ 的不同。
3. 若所有满足条件的子数组和为负数，返回 0（题目要求不存在时返回 0）。
