## 题目描述

给你一个整数数组 `nums`。

你可以选择**一个**元素值，并从数组中删除**该值的所有出现**（或者不删除任何元素）。

返回操作后，数组的**最大子数组和**。如果数组为空，子数组和为 0。

**示例 1：**

```
输入：nums = [-3,2,-2,-1,3,-2,3]
输出：7
解释：删除 -2，数组变为 [-3,2,-1,3,3]，最大子数组和为 2+(-1)+3+3=7
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：10
解释：不删除任何元素，最大子数组和为 10
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^6 <= nums[i] <= 10^6`

## 解题思路

枚举要删除的值 `v`（或不删除）。对于每个 `v`，相当于把数组中所有 `v` 的位置视为"不存在"，在剩余元素中求最大子数组和（Kadane 算法）。

但元素值范围可达 10^6，枚举每个值需要 O(n) 时间，总复杂度 O(n * distinct_values)。

**优化**：对于正值元素，删除负数才有意义。只需枚举数组中出现的负数值。另外，不删除时用标准 Kadane 算法。

实际上只需枚举所有出现在数组中的不同值（至多 n 个不同值），每次 O(n) 执行 Kadane 算法。总复杂度 O(n^2)，对于 n=10^5 可能超时。

**进一步优化**：使用线段树维护区间最大子数组和，删除某个值时，将其位置设为 0，动态查询最大子数组和。

## Python 代码实现

### 方法一：枚举删除值 + Kadane（适合 n <= 10^4）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarraySum(self, nums: List[int]) -> int:
        def kadane_skip(arr, skip_val):
            """Kadane 算法，跳过值为 skip_val 的元素"""
            max_sum = 0  # 空子数组和为 0
            cur = 0
            for x in arr:
                if x == skip_val:
                    continue  # 跳过该元素（相当于删除）
                cur = max(x, cur + x)
                max_sum = max(max_sum, cur)
            return max_sum

        # 不删除任何元素
        result = kadane_skip(nums, None)

        # 枚举删除每个出现过的值
        distinct_vals = set(nums)
        for v in distinct_vals:
            result = max(result, kadane_skip(nums, v))

        return result
```

### 方法二：线段树（推荐，O(n log n)）

```python
from typing import List
from collections import defaultdict

class SegTree:
    """支持单点修改、查询区间最大子数组和的线段树"""
    def __init__(self, n):
        self.n = n
        # 每个节点存：(最大子数组和, 最大前缀和, 最大后缀和, 区间总和)
        self.tree = [(0, 0, 0, 0)] * (4 * n)

    def _merge(self, left, right):
        lmax, lpre, lsuf, ltot = left
        rmax, rpre, rsuf, rtot = right
        total = ltot + rtot
        prefix = max(lpre, ltot + rpre)
        suffix = max(rsuf, rtot + lsuf)
        max_sum = max(lmax, rmax, lsuf + rpre)
        return (max_sum, prefix, suffix, total)

    def build(self, arr, node, start, end):
        if start == end:
            v = arr[start]
            self.tree[node] = (max(0, v), max(0, v), max(0, v), v)
            return
        mid = (start + end) // 2
        self.build(arr, 2*node, start, mid)
        self.build(arr, 2*node+1, mid+1, end)
        self.tree[node] = self._merge(self.tree[2*node], self.tree[2*node+1])

    def update(self, node, start, end, idx, val):
        if start == end:
            self.tree[node] = (max(0, val), max(0, val), max(0, val), val)
            return
        mid = (start + end) // 2
        if idx <= mid:
            self.update(2*node, start, mid, idx, val)
        else:
            self.update(2*node+1, mid+1, end, idx, val)
        self.tree[node] = self._merge(self.tree[2*node], self.tree[2*node+1])

    def query_all(self):
        return self.tree[1][0]


class Solution:
    def maxSubarraySum(self, nums: List[int]) -> int:
        n = len(nums)
        seg = SegTree(n)
        seg.build(nums, 1, 0, n - 1)

        # 不删除任何元素
        result = seg.query_all()

        # 按值分组，记录每个值的所有位置
        val_indices = defaultdict(list)
        for i, v in enumerate(nums):
            val_indices[v].append(i)

        # 枚举每个不同值，将其所有位置设为 0
        for v, indices in val_indices.items():
            # 将所有 v 删除（设为 0）
            for idx in indices:
                seg.update(1, 0, n - 1, idx, 0)

            result = max(result, seg.query_all())

            # 恢复
            for idx in indices:
                seg.update(1, 0, n - 1, idx, v)

        return result
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n * k)，k 为不同值的数量，最坏 O(n^2)
  - 空间复杂度：O(k)

- 方法二（线段树）：
  - 时间复杂度：O(n log n)，每次更新 O(log n)
  - 空间复杂度：O(n)

## 关键点总结

1. 删除某个值的所有出现，相当于把这些位置跳过
2. Kadane 算法可以跳过特定值
3. 线段树维护最大子数组和时，每个节点需存储 (最大子数组和, 最大前缀和, 最大后缀和, 区间总和)

## 易错点

1. 不删除任何元素也是合法操作，需要单独考虑
2. 空子数组和为 0（而不是负无穷）
3. 线段树合并时要正确处理跨左右子树的子数组
