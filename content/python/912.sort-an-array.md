## 题目描述

给你一个整数数组 `nums`，请你将该数组升序排列。

你必须在 **不使用任何内置函数** 的情况下解决问题，时间复杂度为 `O(n log n)`，并且空间复杂度尽可能小。

**示例 1：**
```
输入：nums = [5,2,3,1]
输出：[1,2,3,5]
```

**示例 2：**
```
输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
```

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `-5 * 10^4 <= nums[i] <= 5 * 10^4`

## 解题思路

这是一道经典的排序算法题，要求实现 O(n log n) 的排序。常见的 O(n log n) 排序算法有：

1. **归并排序（Merge Sort）**：稳定，空间 O(n)
2. **快速排序（Quick Sort）**：不稳定，平均 O(log n) 空间，最坏 O(n)
3. **堆排序（Heap Sort）**：不稳定，空间 O(1)

由于题目要求空间尽可能小，推荐使用 **堆排序** 或 **快速排序**（随机化版本）。

## Python 代码实现

### 方法一：归并排序（推荐 ⭐）

```python
from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def merge_sort(arr):
            # 递归终止条件
            if len(arr) <= 1:
                return arr
            
            # 分割数组
            mid = len(arr) // 2
            left = merge_sort(arr[:mid])
            right = merge_sort(arr[mid:])
            
            # 合并两个有序数组
            return merge(left, right)
        
        def merge(left, right):
            result = []
            i, j = 0, 0
            
            # 比较两个数组的元素，按序合并
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    result.append(left[i])
                    i += 1
                else:
                    result.append(right[j])
                    j += 1
            
            # 添加剩余元素
            result.extend(left[i:])
            result.extend(right[j:])
            
            return result
        
        return merge_sort(nums)
```

### 方法二：快速排序（随机化）

```python
from typing import List
import random

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def quick_sort(arr, left, right):
            if left >= right:
                return
            
            # 随机选择基准，避免最坏情况
            pivot_index = random.randint(left, right)
            arr[left], arr[pivot_index] = arr[pivot_index], arr[left]
            
            # 分区操作
            pivot = partition(arr, left, right)
            
            # 递归排序左右两部分
            quick_sort(arr, left, pivot - 1)
            quick_sort(arr, pivot + 1, right)
        
        def partition(arr, left, right):
            pivot = arr[left]
            i = left + 1
            j = right
            
            while True:
                # 从左找大于 pivot 的元素
                while i <= j and arr[i] <= pivot:
                    i += 1
                # 从右找小于 pivot 的元素
                while i <= j and arr[j] >= pivot:
                    j -= 1
                
                if i > j:
                    break
                
                # 交换
                arr[i], arr[j] = arr[j], arr[i]
            
            # 将 pivot 放到正确位置
            arr[left], arr[j] = arr[j], arr[left]
            return j
        
        quick_sort(nums, 0, len(nums) - 1)
        return nums
```

### 方法三：堆排序

```python
from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def heapify(arr, n, i):
            """维护最大堆性质"""
            largest = i
            left = 2 * i + 1
            right = 2 * i + 2
            
            # 找到最大值
            if left < n and arr[left] > arr[largest]:
                largest = left
            if right < n and arr[right] > arr[largest]:
                largest = right
            
            # 如果最大值不是根节点，交换并继续堆化
            if largest != i:
                arr[i], arr[largest] = arr[largest], arr[i]
                heapify(arr, n, largest)
        
        n = len(nums)
        
        # 构建最大堆
        for i in range(n // 2 - 1, -1, -1):
            heapify(nums, n, i)
        
        # 依次取出堆顶元素（最大值）
        for i in range(n - 1, 0, -1):
            # 将堆顶（最大值）与末尾交换
            nums[0], nums[i] = nums[i], nums[0]
            # 重新堆化（不包括已排序的部分）
            heapify(nums, i, 0)
        
        return nums
```

### 方法四：计数排序（利用数据范围）

```python
from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        # 由于题目限制了范围 [-5*10^4, 5*10^4]
        # 可以使用计数排序
        
        # 偏移量，处理负数
        offset = 50000
        count = [0] * 100001
        
        # 计数
        for num in nums:
            count[num + offset] += 1
        
        # 重构数组
        result = []
        for i in range(100001):
            if count[i] > 0:
                result.extend([i - offset] * count[i])
        
        return result
```

### 方法五：三路快排（处理重复元素）

```python
from typing import List
import random

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def three_way_quick_sort(arr, left, right):
            if left >= right:
                return
            
            # 随机选择基准
            pivot_index = random.randint(left, right)
            pivot = arr[pivot_index]
            
            # 三路分区：< pivot | = pivot | > pivot
            lt = left  # arr[left...lt-1] < pivot
            gt = right  # arr[gt+1...right] > pivot
            i = left    # arr[lt...i-1] = pivot
            
            while i <= gt:
                if arr[i] < pivot:
                    arr[i], arr[lt] = arr[lt], arr[i]
                    lt += 1
                    i += 1
                elif arr[i] > pivot:
                    arr[i], arr[gt] = arr[gt], arr[i]
                    gt -= 1
                else:
                    i += 1
            
            # 递归排序两部分
            three_way_quick_sort(arr, left, lt - 1)
            three_way_quick_sort(arr, gt + 1, right)
        
        three_way_quick_sort(nums, 0, len(nums) - 1)
        return nums
```

## 复杂度分析

**归并排序：**
- 时间复杂度：O(n log n)，稳定
- 空间复杂度：O(n)，需要额外数组

**快速排序（随机化）：**
- 时间复杂度：O(n log n) 平均，O(n^2) 最坏（通过随机化避免）
- 空间复杂度：O(log n) 平均（递归栈），O(n) 最坏

**堆排序：**
- 时间复杂度：O(n log n)，稳定
- 空间复杂度：O(1)，原地排序

**计数排序：**
- 时间复杂度：O(n + k)，k 是数据范围
- 空间复杂度：O(k)

## 关键点总结

1. **归并排序**：稳定，适合链表，空间 O(n)
2. **快速排序**：平均最快，随机化避免最坏情况，原地排序
3. **堆排序**：空间 O(1)，适合空间受限场景
4. **计数排序**：数据范围小时效率高
5. **三路快排**：大量重复元素时效率更高

## 易错点

1. **快排最坏情况**：不随机化时，有序数组会退化到 O(n^2)
2. **归并排序空间**：需要额外 O(n) 空间
3. **堆排序索引**：左子节点 `2*i+1`，右子节点 `2*i+2`
4. **边界条件**：递归终止条件，防止栈溢出
5. **稳定性**：归并排序稳定，快排和堆排序不稳定
