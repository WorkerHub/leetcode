## 题目描述

给你一个字符串 `s`，将其划分为若干非空子字符串，要求每个子字符串中所有字符出现的频率相同（即均衡字符串）。

返回最少的划分数。

**示例 1：**
```
输入：s = "fabccddg"
输出：3
解释："f", "abcc", "ddg" 不都均衡。"fab", "ccdd", "g" -> "fab"(f:1,a:1,b:1), "ccdd"(c:2,d:2), "g"(g:1)，均衡，划分数为 3。
```

**示例 2：**
```
输入：s = "abababaccddb"
输出：2
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 只包含小写字母

## 解题思路

动态规划：`dp[i]` 表示 `s[0..i-1]` 的最少划分数。

转移：`dp[i] = min(dp[j] + 1)`，其中 `s[j..i-1]` 是均衡字符串。

判断 `s[j..i-1]` 是否均衡：统计各字符频率，若所有频率相同则均衡。

## Python 代码实现

### 方法一：DP（推荐）

```python
from collections import Counter

class Solution:
    def minimumSubstringsInPartition(self, s: str) -> int:
        n = len(s)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        def is_balanced(cnt: Counter) -> bool:
            vals = list(cnt.values())
            return len(set(vals)) == 1

        for i in range(1, n + 1):
            cnt = Counter()
            for j in range(i - 1, -1, -1):
                cnt[s[j]] += 1
                if is_balanced(cnt) and dp[j] < INF:
                    dp[i] = min(dp[i], dp[j] + 1)

        return dp[n]
```

### 方法二：优化判断

```python
from collections import Counter

class Solution:
    def minimumSubstringsInPartition(self, s: str) -> int:
        n = len(s)
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            freq = {}
            for j in range(i - 1, -1, -1):
                c = s[j]
                freq[c] = freq.get(c, 0) + 1
                # 检查是否均衡
                vals = set(freq.values())
                if len(vals) == 1 and dp[j] < float('inf'):
                    dp[i] = min(dp[i], dp[j] + 1)

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^2 * 26)，DP 转移时遍历子串并统计
- 空间复杂度：O(n + 26)

## 关键点总结

1. 均衡字符串：所有出现字符的频率相同
2. DP 枚举所有可能的划分点
3. 判断均衡只需检查频率集合大小是否为 1

## 易错点

1. 子串为空不合法，需要非空
2. 只统计出现的字符，不统计未出现的字符
