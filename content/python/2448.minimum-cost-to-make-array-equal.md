## 题目描述

给你两个下标从 **0** 开始的数组 `nums` 和 `cost`，分别包含 `n` 个 **正** 整数。

你可以执行下面操作 **任意** 次：

- 将 `nums` 中 **任意** 元素增加或减少 `1`。

对第 `i` 个元素执行一次操作的开销是 `cost[i]`。

返回使 `nums` 中所有元素 **相等** 所需的 **最小** 总开销。

**示例 1：**
```
输入：nums = [1,3,5,2], cost = [2,3,1,14]
输出：8
解释：将所有元素变为 2 的总开销：|1-2|*2 + |3-2|*3 + |5-2|*1 + |2-2|*14 = 2+3+3+0 = 8。
```

**示例 2：**
```
输入：nums = [2,2,2,2,2], cost = [4,2,8,1,3]
输出：0
```

**提示：**
- `n == nums.length == cost.length`
- `1 <= n <= 10^5`
- `1 <= nums[i], cost[i] <= 10^6`

## 解题思路

目标函数 `f(t) = sum(|nums[i] - t| * cost[i])` 是关于 `t` 的凸函数（V 形或 U 形）。

最优 `t` 是加权中位数（用 cost 作为权重的中位数）。

**方法一（二分查找）：** `f(t)` 是凸函数，可以通过三分搜索或计算差分函数来找最小值。

**方法二（前缀和 + 排序）：** 排序后计算每个可能值的开销，利用前缀和 O(n log n) 求解。

**三分搜索：** 对整数值域三分，找到 f 值最小的点。

## 代码实现

### 方法一：三分搜索（推荐）

```python
from typing import List

class Solution:
    def minCost(self, nums: List[int], cost: List[int]) -> int:
        def f(t: int) -> int:
            """计算将所有元素变为 t 的总开销"""
            return sum(abs(nums[i] - t) * cost[i] for i in range(len(nums)))

        # 三分搜索（凸函数极值）
        lo, hi = min(nums), max(nums)
        while hi - lo > 2:
            m1 = lo + (hi - lo) // 3
            m2 = hi - (hi - lo) // 3
            if f(m1) <= f(m2):
                hi = m2
            else:
                lo = m1

        # 在缩小范围内暴力找最小值
        return min(f(t) for t in range(lo, hi + 1))
```

### 方法二：排序 + 前缀和（数学推导）

```python
from typing import List

class Solution:
    def minCost(self, nums: List[int], cost: List[int]) -> int:
        # 排序（按 nums 值排序）
        pairs = sorted(zip(nums, cost))
        total_cost = sum(cost)
        half = total_cost / 2  # 找加权中位数

        # 找加权中位数
        prefix = 0
        median = pairs[-1][0]
        for val, c in pairs:
            prefix += c
            if prefix > half:
                median = val
                break

        # 计算将所有元素变为加权中位数的开销
        return sum(abs(nums[i] - median) * cost[i] for i in range(len(nums)))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三分搜索 | O(n log(max_val)) | O(1) |
| 排序 + 前缀和 | O(n log n) | O(n) |

## 关键点总结

1. 目标函数是加权绝对差之和，是凸函数
2. 最优解是加权中位数
3. 三分搜索适用于整数域上的凸函数

## 易错点

- 三分搜索需要处理整数区间，终止条件和暴力遍历范围要仔细
- 加权中位数：排序后找第一个累计权重超过总权重一半的位置
