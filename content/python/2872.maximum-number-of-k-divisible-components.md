## 题目描述

给你一棵 `n` 个节点的无向树，节点编号 0 到 n-1，以及每个节点的值 `values[]` 和整数 `k`。

每次操作，你可以删除一条边，将树分成两个连通分量。

返回可以通过删边将树分成的**每个连通分量的值之和都能被 k 整除**的最多分量数。

**提示：**
- `1 <= n <= 3 × 10^4`
- `sum(values) % k == 0`（总和能被 k 整除）

## 解题思路

**树形 DP：**

1. 以任意节点为根（如 0）DFS
2. 计算每个子树的值之和（mod k）
3. 若子树的和 mod k == 0，说明可以切掉这条边，将该子树分离为独立分量，计数 +1

**关键：** 总和能被 k 整除，所以分离子树后，剩余部分也能被 k 整除（由数学性质保证）。

## Python 代码实现

### 方法一：DFS 树形 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxKDivisibleComponents(self, n: int, edges: List[List[int]], values: List[int], k: int) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 0

        def dfs(node: int, parent: int) -> int:
            nonlocal ans
            subtree_sum = values[node] % k  # 当前子树的和 mod k

            for nei in graph[node]:
                if nei != parent:
                    child_sum = dfs(nei, node)
                    subtree_sum = (subtree_sum + child_sum) % k

            if subtree_sum % k == 0:
                ans += 1  # 这个子树可以分割出去
                return 0  # 分割后，贡献给父节点的为 0
            return subtree_sum

        dfs(0, -1)
        return ans
```

### 方法二：迭代 DFS（避免递归深度限制）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maxKDivisibleComponents(self, n: int, edges: List[List[int]], values: List[int], k: int) -> int:
        if n == 1:
            return 1

        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 拓扑排序（从叶节点开始处理）
        degree = [len(graph[i]) for i in range(n)]
        subtree_sum = [v % k for v in values]
        ans = 0

        queue = deque(node for node in range(n) if degree[node] == 1)

        while queue:
            node = queue.popleft()
            # 找到父节点（degree=1 的节点的邻居中 degree > 0 的）
            for par in graph[node]:
                if degree[par] > 0:
                    if subtree_sum[node] % k == 0:
                        ans += 1
                    else:
                        subtree_sum[par] = (subtree_sum[par] + subtree_sum[node]) % k
                    degree[node] -= 1
                    degree[par] -= 1
                    if degree[par] == 1:
                        queue.append(par)

        ans += 1  # 最后根节点自身也是一个分量
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，DFS 或拓扑排序
- 空间复杂度：O(n)，图和辅助数组

## 关键点总结

1. 若子树值之和 mod k == 0，可以分割出去（独立成分量）
2. 分割后，子树贡献为 0，不影响父节点
3. 因为总和 mod k == 0，分割是合法的（剩余部分也满足）

## 易错点

1. 子树和要对 k 取模（防止溢出）
2. 分割后返回 0（子树对父节点的贡献）
3. 方法二最后根节点也是一个分量，需要额外 +1
