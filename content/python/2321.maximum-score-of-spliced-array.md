## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，两数组长度都是 `n`。

你可以选择两个整数 `left` 和 `right`（`0 <= left <= right < n`），将 `nums1` 中下标从 `left` 到 `right`（含端点）的元素替换为 `nums2` 中对应位置的元素，或将 `nums2` 中对应位置的元素替换为 `nums1` 的。

你的目标是最大化**某一个**数组的元素之和。返回可以得到的**最大** 元素之和。

**示例 1：**
```
输入：nums1 = [60,60,60], nums2 = [10,90,10]
输出：210
解释：将 nums1[1] 替换为 nums2[1]=90，得 [60,90,60]，和为 210。
```

**示例 2：**
```
输入：nums1 = [20,40,20,70,30], nums2 = [50,20,50,40,20]
输出：220
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^4`

## 解题思路

**问题转化：**
将 `nums1[left..right]` 替换为 `nums2` 中对应区间，最终 `nums1` 的和变为：
`sum(nums1) + sum(nums2[l..r]) - sum(nums1[l..r]) = sum(nums1) + sum((nums2[i]-nums1[i]) for i in [l,r])`

所以目标是最大化 `diff[i] = nums2[i] - nums1[i]` 的最大子数组和，再加上 `sum(nums1)`。

对称地，对 `nums2` 也做同样处理（最大化 `nums1[i] - nums2[i]` 的最大子数组和加 `sum(nums2)`）。

**最大子数组和用 Kadane 算法求解。**

## 代码实现

### 方法一：Kadane 算法（推荐）

```python
from typing import List

class Solution:
    def maximumsSplicedArray(self, nums1: List[int], nums2: List[int]) -> int:
        def max_subarray_sum(arr: List[int]) -> int:
            # Kadane 算法求最大子数组和（允许和为负则取0）
            max_sum = 0
            cur = 0
            for x in arr:
                cur = max(0, cur + x)
                max_sum = max(max_sum, cur)
            return max_sum

        sum1 = sum(nums1)
        sum2 = sum(nums2)
        n = len(nums1)

        # 将 nums1 的一段换成 nums2：增益为 max_subarray(nums2-nums1)
        diff1 = [nums2[i] - nums1[i] for i in range(n)]
        # 将 nums2 的一段换成 nums1：增益为 max_subarray(nums1-nums2)
        diff2 = [nums1[i] - nums2[i] for i in range(n)]

        return max(sum1 + max_subarray_sum(diff1),
                   sum2 + max_subarray_sum(diff2))
```

### 方法二：直接 DP

```python
from typing import List

class Solution:
    def maximumsSplicedArray(self, nums1: List[int], nums2: List[int]) -> int:
        def best_swap(a: List[int], b: List[int]) -> int:
            # 将 a 的一段换成 b 后，a 的最大和
            sa = sum(a)
            cur = 0
            best_gain = 0
            for x, y in zip(a, b):
                # 当前位置替换带来的收益 = y - x
                cur = max(0, cur + y - x)
                best_gain = max(best_gain, cur)
            return sa + best_gain

        return max(best_swap(nums1, nums2), best_swap(nums2, nums1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Kadane | O(n) | O(n) |
| 直接 DP | O(n) | O(1) |

## 关键点总结

1. 操作本质是在某个子数组区间内，以另一个数组的值替换，改变量为 `diff[i]` 的区间和。
2. 最大化 `diff` 的子数组和等价于 Kadane 算法求最大子数组和。
3. 两种方向（用 nums2 替换 nums1 的一段，或反过来）都要考虑。

## 易错点

- Kadane 算法初始 `cur = 0`，允许不替换任何元素（即改变量为 0）。
- 两个方向都要尝试并取最大值。
