## 题目描述

给你一个二进制字符串 `s` 以及两个整数 `num1` 和 `num2`，找出 `s` 中满足如下条件的子字符串的数目：

子字符串中 `0` 的数目和 `1` 的数目之比等于 `num1 : num2`。

返回满足条件的子字符串数目。

**提示：**
- `1 <= s.length <= 10^5`
- `s[i] 是 '0' 或 '1'`
- `1 <= num1, num2 <= s.length`

## 解题思路

**前缀和 + 哈希表：**

设 `cnt0[i]` 和 `cnt1[i]` 为前 i 个字符中 0 和 1 的个数。

子串 `[l, r]` 满足条件：
`(cnt0[r] - cnt0[l]) : (cnt1[r] - cnt1[l]) = num1 : num2`

等价于：
`num2 * (cnt0[r] - cnt0[l]) = num1 * (cnt1[r] - cnt1[l])`
`num2 * cnt0[r] - num1 * cnt1[r] = num2 * cnt0[l] - num1 * cnt1[l]`

设 `f(i) = num2 * cnt0[i] - num1 * cnt1[i]`，则需要 `f(r) == f(l)`。

用哈希表统计各 f 值出现次数，枚举右端点即可。

## 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from collections import defaultdict

class Solution:
    def fixedRatio(self, s: str, num1: int, num2: int) -> int:
        # f(i) = num2 * cnt0[i] - num1 * cnt1[i]
        # 满足条件的子串数 = f 值相同的前缀对数

        count = defaultdict(int)
        count[0] = 1  # f(0) = 0，空前缀

        cnt0, cnt1 = 0, 0
        ans = 0

        for c in s:
            if c == '0':
                cnt0 += 1
            else:
                cnt1 += 1

            key = num2 * cnt0 - num1 * cnt1
            ans += count[key]  # 与之前 f 值相同的前缀配对
            count[key] += 1

        return ans
```

### 方法二：显式前缀数组

```python
from collections import defaultdict

class Solution:
    def fixedRatio(self, s: str, num1: int, num2: int) -> int:
        n = len(s)
        cnt0 = cnt1 = 0
        freq = defaultdict(int)
        freq[0] = 1
        ans = 0

        for i in range(n):
            if s[i] == '0':
                cnt0 += 1
            else:
                cnt1 += 1
            # key = num2 * 0的数 - num1 * 1的数
            key = num2 * cnt0 - num1 * cnt1
            ans += freq[key]
            freq[key] += 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和+哈希 | O(n) | O(n) |

## 关键点总结

1. 比例条件转化为等式：`num2 * cnt0 == num1 * cnt1`
2. 利用前缀和将区间问题转化为两个前缀的差
3. 哈希表统计等价前缀个数，枚举右端点时加上左端点的个数

## 易错点

- 初始化哈希表时需要加入 f(0) = 0（空前缀）
- 比例 num1:num2 对应 0 和 1 的比例（num1 是 0 的比例，num2 是 1 的比例）
