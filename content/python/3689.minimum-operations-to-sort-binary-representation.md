## 题目描述

给你一个二进制字符串 `s`，每次操作可以交换相邻两位。返回使字符串变为非递减（所有 0 在所有 1 之前）所需的最少操作次数。

**示例 1：**

```
输入：s = "1100"
输出：4
解释：1100→1010→1001→0101→0011，4次操作
```

**示例 2：**

```
输入：s = "10"
输出：1
```

**提示：**

- `1 <= s.length <= 10^4`

## 解题思路

等价于将字符串排序（所有 0 到前面），类似冒泡排序中 0 和 1 的交换次数。

每个 0 需要跨过其左边的 1 的数量（即当前 0 的左边有多少个 1），这就是它需要的操作次数。

总操作数 = 每个 0 左边的 1 的总个数（即逆序对数）。

## Python 代码实现

### 方法一：统计逆序对（推荐）

```python
class Solution:
    def minOperations(self, s: str) -> int:
        ones_count = 0
        ops = 0
        for c in s:
            if c == '1':
                ones_count += 1
            else:  # c == '0'
                ops += ones_count  # 这个 0 需要跨过左边的 ones_count 个 1
        return ops
```

### 方法二：归并排序计逆序对

```python
class Solution:
    def minOperations(self, s: str) -> int:
        arr = [int(c) for c in s]
        # 计算逆序对数（1 在 0 之前的对数）
        self.count = 0

        def merge_sort(a):
            if len(a) <= 1:
                return a
            mid = len(a) // 2
            left = merge_sort(a[:mid])
            right = merge_sort(a[mid:])
            merged = []
            i = j = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i])
                    i += 1
                else:
                    self.count += len(left) - i  # 右边的 0 比左边 i 到 end 的 1 都小
                    merged.append(right[j])
                    j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged

        merge_sort(arr)
        return self.count
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n log n)（方法二）
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 逆序对数 = 最少相邻交换次数（冒泡排序原理）
2. 每个 0 需要跨过的步数 = 其左边 1 的个数
3. 线性扫描累加即可

## 易错点

1. 注意是 0 向左移，不是 1 向右移（等价但计数方式不同）
2. 最终目标是所有 0 在前（非递减：0000...1111）
