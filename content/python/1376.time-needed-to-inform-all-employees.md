## 题目描述

公司里有 `n` 名员工，每个员工的 ID 从 `0` 到 `n-1`。

- `headID` 是公司唯一的老板（没有上级）。
- `manager[i]` 是第 `i` 名员工的直属上级（`manager[headID] == -1`）。
- `informTime[i]` 是第 `i` 名员工通知其**所有直属下属**所需要的分钟数（若没有下属，则 `informTime[i] == 0`）。

老板想通知所有员工公司的紧急消息。他会通知所有直属下属，然后所有下属再通知各自的直属下属，以此类推，直到所有员工都被告知。

**注意**：员工接到消息后立即开始通知自己的下属，可以并行进行。

返回通知所有员工所需要的**总分钟数**。

**示例 1：**
```
输入：n = 1, headID = 0, manager = [-1], informTime = [0]
输出：0
解释：只有老板，不需要通知。
```

**示例 2：**
```
输入：n = 6, headID = 2,
      manager = [2,2,-1,2,2,2],
      informTime = [0,0,1,0,0,0]
输出：1
解释：老板是员工2，通知所有5个直属下属需要1分钟。
```

**示例 3：**
```
输入：n = 7, headID = 6,
      manager = [1,2,3,4,5,6,-1],
      informTime = [0,6,5,4,3,2,1]
输出：21
```

**提示：**
- `1 <= n <= 10^5`
- `0 <= headID < n`
- `manager.length == n`
- `manager[headID] == -1`
- `0 <= informTime[i] <= 1000`
- `informTime[i] == 0`（如果员工 i 没有下属）

## 解题思路

### 核心思想

本题等价于：从 `headID` 出发，找到树中从根到**最远叶子节点**的路径上所有 `informTime` 之和的最大值。

**建树 + DFS/BFS：**
1. 将 `manager` 数组转化为树结构（邻接表）：对每个员工，记录其直属下属列表。
2. 从 `headID` 出发，对每个节点计算"从 headID 到该节点"所需的累计时间。
3. 答案为所有节点中的最大累计时间。

**为什么是累计时间的最大值？**
- 消息沿树向下传播，每个节点需要等父节点通知完才能开始通知自己的下属。
- 到达某个叶子节点的时间 = 从根到该叶子路径上所有 `informTime` 之和。
- 全部通知完成的时间 = 所有叶子路径中最长的那个。

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numOfMinutes(self, n: int, headID: int, manager: List[int], informTime: List[int]) -> int:
        # 建立邻接表：每个节点的直属下属列表
        subordinates = defaultdict(list)
        for emp, mgr in enumerate(manager):
            if mgr != -1:  # headID 的 manager 为 -1，跳过
                subordinates[mgr].append(emp)

        def dfs(node):
            """
            返回从 node 出发，通知 node 下面所有员工所需的最长时间
            """
            # 叶子节点：没有下属，不需要时间
            if not subordinates[node]:
                return 0

            # 取所有下属子树中耗时最长的
            max_time = 0
            for sub in subordinates[node]:
                # node 通知 sub 需要 informTime[node] 分钟
                # sub 再通知其下属需要 dfs(sub) 分钟
                max_time = max(max_time, dfs(sub))

            # node 的通知时间 + 下属中最慢的
            return informTime[node] + max_time

        return dfs(headID)
```

### 方法二：BFS（队列）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def numOfMinutes(self, n: int, headID: int, manager: List[int], informTime: List[int]) -> int:
        # 建立邻接表
        subordinates = defaultdict(list)
        for emp, mgr in enumerate(manager):
            if mgr != -1:
                subordinates[mgr].append(emp)

        # BFS：(当前员工, 到达该员工时的累计时间)
        queue = deque([(headID, 0)])
        max_time = 0

        while queue:
            node, time_so_far = queue.popleft()

            # 累计时间 = 到达该节点的时间（父节点已通知该节点）
            max_time = max(max_time, time_so_far)

            # 将所有直属下属加入队列
            # 下属收到消息的时间 = time_so_far + informTime[node]
            for sub in subordinates[node]:
                queue.append((sub, time_so_far + informTime[node]))

        return max_time
```

### 方法三：自底向上（沿 manager 数组向上累加）

```python
from typing import List
from functools import lru_cache

class Solution:
    def numOfMinutes(self, n: int, headID: int, manager: List[int], informTime: List[int]) -> int:
        @lru_cache(maxsize=None)
        def time_to_reach(emp):
            """
            计算从 headID 通知到 emp 所需的时间
            等于 emp 的经理通知 emp 的时间 + 经理被通知的时间
            """
            if manager[emp] == -1:
                # emp 是 headID，被通知时间为 0
                return 0
            return time_to_reach(manager[emp]) + informTime[manager[emp]]

        # 对所有员工求被通知时间的最大值
        return max(time_to_reach(i) for i in range(n))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 递归 | O(n) | O(n) |
| BFS 队列 | O(n) | O(n) |
| 自底向上 DP | O(n) | O(n) |

- **时间复杂度**：O(n)，每个节点访问一次。
- **空间复杂度**：O(n)，存储邻接表和递归栈/队列。

## 关键点总结

1. **树上最长路径**：答案等于从根到最远叶子的路径上 `informTime` 之和的最大值。
2. **建邻接表**：将 `manager[]` 数组（父指针表示）转化为子节点列表，便于 DFS/BFS 向下遍历。
3. **DFS 的递推关系**：`f(node) = informTime[node] + max(f(sub) for sub in subordinates[node])`
4. **BFS 维护累计时间**：在队列中同时存储"到达当前节点的累计时间"，到叶子时取最大值。
5. **并行通知**：同一层的员工可以**同时**通知各自的下属，所以取最长路径（不是求和）。

## 易错点

1. **并行 vs 串行**：员工接到消息后**立即**开始通知，所以是并行的，取最大路径而不是所有路径之和。
2. **informTime 的含义**：`informTime[i]` 是 i 通知所有**直属下属**所需时间（同时通知所有人），不是逐一通知。
3. **headID 的 manager 为 -1**：建邻接表时需跳过 `manager[headID] == -1` 的情况。
4. **只有1个节点时**：headID 自己是老板，没有下属，`informTime[headID]` 不计入，答案为0。
