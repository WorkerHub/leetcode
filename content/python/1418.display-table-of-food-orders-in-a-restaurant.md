## 题目描述

给你一个数组 `orders`，表示客户在餐厅中完成的订单，其中 `orders[i] = [customerName, tableNumber, foodItem]`。

请你返回该餐厅的 **展示表**。在展示表中：

- 第一行包含所有不同的菜品名称，第一列为 `"Table"`，其余列按菜品名称的字典序排列
- 从第二行开始，每行展示每张桌子的订单情况：第一列是桌号（升序排列），其余列为对应菜品的订单数量（如果没点该菜则为 `"0"`）

**示例：**

```
输入：orders = [["David","3","Ceviche"],["Corina","10","Beef Burrito"],
                ["David","3","Fried Chicken"],["Carla","5","Water"],
                ["Carla","5","Ceviche"],["Rina","10","Beef Burrito"]]
输出：
[["Table","Beef Burrito","Ceviche","Fried Chicken","Water"],
 ["3","0","1","1","0"],
 ["5","0","1","0","1"],
 ["10","2","0","0","0"]]
```

**提示：**

- `1 <= orders.length <= 5 * 10^4`
- `orders[i].length == 3`
- `1 <= customerName.length, foodItem.length <= 20`
- `1 <= tableNumber <= 500`
- `customerName` 和 `foodItem` 由小写和大写英文字母及空格组成

## 解题思路

### 哈希表 + 排序

1. 用集合收集所有菜品名称，用集合收集所有桌号
2. 用嵌套字典记录每张桌子每种菜品的数量：`table_orders[table][food] += 1`
3. 对菜品名称按字典序排序，对桌号按数字升序排序
4. 构建结果矩阵：第一行为表头，后续每行为桌子数据

**关键细节：**
- 桌号按**数字**升序（不是字符串字典序），需要 `sorted(tables, key=int)` 或存储为整数
- 不存在的菜品数量填 "0"

## Python 代码实现

### 方法一：嵌套字典（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def displayTable(self, orders: List[List[str]]) -> List[List[str]]:
        # 收集所有菜品（用集合去重）
        food_set = set()
        # 收集所有桌号（用集合去重）
        table_set = set()
        # 记录每张桌子每种菜品的数量
        # table_orders[桌号][菜品名] = 数量
        table_orders = defaultdict(lambda: defaultdict(int))

        for _, table, food in orders:
            food_set.add(food)
            table_set.add(table)
            table_orders[table][food] += 1

        # 菜品名按字典序排序
        foods = sorted(food_set)
        # 桌号按数字升序排序
        tables = sorted(table_set, key=int)

        # 构建结果
        result = [["Table"] + foods]  # 第一行：表头

        for table in tables:
            # 每行：桌号 + 各菜品数量
            row = [table]
            for food in foods:
                row.append(str(table_orders[table][food]))
            result.append(row)

        return result
```

### 方法二：使用 Counter（更 Pythonic）

```python
from typing import List
from collections import defaultdict, Counter

class Solution:
    def displayTable(self, orders: List[List[str]]) -> List[List[str]]:
        # 用 defaultdict(Counter) 记录每张桌子的点餐计数
        table_orders = defaultdict(Counter)
        food_set = set()
        table_set = set()

        for _, table, food in orders:
            table_orders[table][food] += 1
            food_set.add(food)
            table_set.add(table)

        # 排序
        foods = sorted(food_set)
        tables = sorted(table_set, key=int)

        # 构建结果
        header = ["Table"] + foods
        result = [header]

        for table in tables:
            # Counter.get(key, 0) 不存在时返回 0
            row = [table] + [str(table_orders[table].get(food, 0)) for food in foods]
            result.append(row)

        return result
```

### 方法三：pandas（面试不常用，但理解数据透视思想）

```python
from typing import List
import pandas as pd

class Solution:
    def displayTable(self, orders: List[List[str]]) -> List[List[str]]:
        # 构建 DataFrame
        df = pd.DataFrame(orders, columns=['customer', 'table', 'food'])
        df['table'] = df['table'].astype(int)  # 桌号转整数，以便数字排序

        # 数据透视：行=桌号，列=菜品，值=数量（不存在填0）
        pivot = df.pivot_table(
            index='table', columns='food', values='customer',
            aggfunc='count', fill_value=0
        )

        # 按桌号升序，按菜品字典序
        pivot = pivot.sort_index()
        pivot = pivot[sorted(pivot.columns)]

        # 构建结果
        result = [["Table"] + list(pivot.columns)]
        for table, row in pivot.iterrows():
            result.append([str(table)] + [str(v) for v in row])

        return result
```

## 复杂度分析

设 `n = orders.length`，`F` 为不同菜品数，`T` 为不同桌号数。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 嵌套字典 | O(n + F log F + T log T + T * F) | O(n + T * F) |
| Counter | 同上 | 同上 |

构建结果矩阵需要 O(T * F)。

## 关键点总结

1. 用嵌套字典记录 `table -> food -> count` 的映射
2. 菜品名按**字典序**排序，桌号按**数字大小**排序（不是字符串排序）
3. 表头第一列固定为 `"Table"`
4. 不存在的菜品数量填 `"0"`（字符串，不是整数）

## 易错点

1. 桌号排序：`sorted(tables)` 按字符串排序（"10" < "3"），必须用 `sorted(tables, key=int)` 按数字排序
2. 结果矩阵中所有元素都是字符串（包括数字和桌号）
3. 使用 `defaultdict(lambda: defaultdict(int))` 可以避免 KeyError
