## 题目描述

给你两个长度为 `n` 的字符串 `s1` 和 `s2`，以及一个字符串 `evil`。请你返回**好字符串**的数目。

**好字符串**的定义如下：

- 长度为 `n`
- 字典序大于等于 `s1`
- 字典序小于等于 `s2`
- 不包含 `evil` 作为子字符串

由于答案可能很大，返回答案对 `10^9 + 7` 取余的结果。

**示例 1：**

```
输入：n = 2, s1 = "aa", s2 = "da", evil = "b"
输出：51
解释：共有 25 个以 'a' 开头的好字符串和 25 个以 'c' 开头，以及 1 个 "aa"。
```

**示例 2：**

```
输入：n = 8, s1 = "leetcode", s2 = "leetcode", evil = "leet"
输出：0
```

**提示：**

- `n` 的范围是 `[1, 500]`
- `s1.length == n`
- `s2.length == n`
- `1 <= evil.length <= 50`
- 所有字符串只包含小写英文字母。

## 解题思路

**数位 DP + KMP**，这是经典的"计数满足区间字典序且不含特定子串的字符串数"问题。

### 核心思路

用数位 DP 计算 `f(s)` = 长度为 n、字典序 <= s、且不含 `evil` 子串的字符串数。

答案 = `f(s2) - f(s1) + [s1 本身是好字符串]`

等价地，答案 = `count(s1, s2)` = 直接在 DP 中引入 `tight_lo` 和 `tight_hi` 两个状态。

### DP 状态定义

`dp(pos, evil_pos, tight_lo, tight_hi)`

- `pos`：当前填到第几位（0-indexed）
- `evil_pos`：当前已匹配 `evil` 前缀的长度（KMP 状态）
- `tight_lo`：当前字符串是否与 `s1` 的前 `pos` 位完全相同（是否受下界约束）
- `tight_hi`：当前字符串是否与 `s2` 的前 `pos` 位完全相同（是否受上界约束）

### KMP 的作用

预先计算 `evil` 的失配数组 `next_arr`，在 DP 中每填入一个字符就更新 KMP 状态（已匹配的前缀长度）。若 KMP 状态达到 `len(evil)`，说明包含了 `evil`，该方案无效。

## Python 代码实现

### 方法一：记忆化搜索（数位 DP + KMP）

```python
from functools import lru_cache

class Solution:
    def findGoodStrings(self, n: int, s1: str, s2: str, evil: str) -> int:
        MOD = 10 ** 9 + 7
        m = len(evil)

        # 构建 evil 的 KMP 失配数组（next 数组）
        next_arr = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and evil[i] != evil[j]:
                j = next_arr[j - 1]
            if evil[i] == evil[j]:
                j += 1
            next_arr[i] = j

        # 计算在 evil 的 KMP 状态为 cur_state 时，再输入字符 c，转移到哪个状态
        def kmp_next(cur_state: int, c: str) -> int:
            while cur_state > 0 and c != evil[cur_state]:
                cur_state = next_arr[cur_state - 1]
            if c == evil[cur_state]:
                cur_state += 1
            return cur_state

        @lru_cache(maxsize=None)
        def dp(pos: int, evil_pos: int, tight_lo: bool, tight_hi: bool) -> int:
            """
            pos: 当前填第 pos 位
            evil_pos: 当前 KMP 匹配状态
            tight_lo: 是否受 s1 下界约束
            tight_hi: 是否受 s2 上界约束
            """
            # 已经包含 evil，无效
            if evil_pos == m:
                return 0
            # 所有位填完，当前字符串有效
            if pos == n:
                return 1

            # 确定当前位可填的字符范围
            lo = s1[pos] if tight_lo else 'a'
            hi = s2[pos] if tight_hi else 'z'

            result = 0
            # 枚举当前位填入的字符 c
            c = lo
            while c <= hi:
                new_evil_pos = kmp_next(evil_pos, c)
                new_tight_lo = tight_lo and (c == s1[pos])
                new_tight_hi = tight_hi and (c == s2[pos])
                result += dp(pos + 1, new_evil_pos, new_tight_lo, new_tight_hi)
                result %= MOD
                # 字符递增（'a' -> 'b' -> ... -> 'z'）
                c = chr(ord(c) + 1)

            return result

        return dp(0, 0, True, True)
```

### 方法二：迭代 DP（减少递归开销）

```python
class Solution:
    def findGoodStrings(self, n: int, s1: str, s2: str, evil: str) -> int:
        MOD = 10 ** 9 + 7
        m = len(evil)

        # 构建 KMP next 数组
        next_arr = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and evil[i] != evil[j]:
                j = next_arr[j - 1]
            if evil[i] == evil[j]:
                j += 1
            next_arr[i] = j

        def kmp_next(state: int, c: str) -> int:
            while state > 0 and c != evil[state]:
                state = next_arr[state - 1]
            if c == evil[state]:
                state += 1
            return state

        # dp[(evil_pos, tight_lo, tight_hi)] = 当前状态下的方案数
        # 初始状态
        dp = {(0, True, True): 1}

        for pos in range(n):
            new_dp = {}
            for (evil_pos, tight_lo, tight_hi), cnt in dp.items():
                lo = s1[pos] if tight_lo else 'a'
                hi = s2[pos] if tight_hi else 'z'
                for ci in range(ord(lo), ord(hi) + 1):
                    c = chr(ci)
                    new_ep = kmp_next(evil_pos, c)
                    if new_ep == m:
                        continue  # 包含 evil，跳过
                    new_tl = tight_lo and (c == s1[pos])
                    new_th = tight_hi and (c == s2[pos])
                    key = (new_ep, new_tl, new_th)
                    new_dp[key] = (new_dp.get(key, 0) + cnt) % MOD
            dp = new_dp

        return sum(dp.values()) % MOD
```

## 复杂度分析

- **时间复杂度 O(n * m * 26)**：n 个位置，m 个 KMP 状态，每位 26 个字符选择。
- **空间复杂度 O(n * m)**：DP 状态数。

## 关键点总结

1. 数位 DP 模板：用 `tight_lo` 和 `tight_hi` 两个布尔变量控制上下界
2. KMP 在 DP 中的作用：维护"当前已匹配 evil 的前缀长度"状态，避免包含 evil
3. `kmp_next(state, c)` 函数：给定当前 KMP 状态和新字符，返回下一个 KMP 状态
4. `evil_pos == m` 时说明 evil 已完整出现，当前路径无效

## 易错点

- 数位 DP 中 `tight_lo` 和 `tight_hi` 同时存在（不只是一个 `tight`），需要分别维护
- KMP 转移时不要遗漏边界：`state > 0` 才能回退
- 字符范围 `[lo, hi]` 是闭区间，`c <= hi` 而不是 `c < hi`
- 最终答案包含 `evil_pos == m` 被过滤的情况，只统计合法状态
