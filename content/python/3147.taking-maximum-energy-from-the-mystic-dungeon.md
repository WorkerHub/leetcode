## 题目描述

在神秘地牢中，`n` 个法师站成一排，第 `i` 个法师的能量为 `energy[i]`，可能为负。

你从某个法师开始，每次向后移动 `k` 步（即 i, i+k, i+2k, ...），直到数组末尾，收集沿途所有法师的能量。

返回你能收集到的 **最大** 能量值。

**示例 1：**
```
输入：energy = [5,2,-10,-5,1], k = 3
输出：3
解释：从下标 1 开始：energy[1] + energy[4] = 2 + 1 = 3
```

**示例 2：**
```
输入：energy = [-2,-3,-1], k = 2
输出：-1
```

**提示：**
- `1 <= energy.length <= 10^5`
- `-10^3 <= energy[i] <= 10^3`
- `1 <= k <= energy.length - 1`

## 解题思路

对每个可能的起始下标 i（0 到 k-1），计算从 i 出发每次跳 k 步的总能量。

等价于：从后往前遍历，对每个 i，`suffix[i] = energy[i] + (suffix[i+k] if i+k < n else 0)`。

答案为所有 `suffix[i]` 的最大值。

## Python 代码实现

### 方法一：后缀和（推荐）

```python
from typing import List

class Solution:
    def maximumEnergy(self, energy: List[int], k: int) -> int:
        n = len(energy)
        # 从后往前计算后缀和
        suffix = energy[:]
        for i in range(n - k - 1, -1, -1):
            suffix[i] += suffix[i + k]
        # 答案是最后 k 个位置的最大值（每个起点的总能量）
        return max(suffix[n - k:])
```

### 方法二：直接遍历

```python
from typing import List

class Solution:
    def maximumEnergy(self, energy: List[int], k: int) -> int:
        n = len(energy)
        ans = float('-inf')
        for start in range(k):
            total = sum(energy[i] for i in range(start, n, k))
            ans = max(ans, total)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，线性扫描
- 空间复杂度：O(n)（方法一），O(1)（方法二）

## 关键点总结

1. 枚举 k 个可能的起始位置（0 到 k-1）
2. 用后缀和避免重复计算
3. 答案是所有起始位置中的最大总能量

## 易错点

1. 起始位置只有 k 种（0 到 k-1）
2. 注意能量可能为负
