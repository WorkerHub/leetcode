## 题目描述

给你两个字符串 `s1` 和 `s2`，它们长度相同，每个字符串都只含有小写英文字母。

如果某个字符串 `s` 能打破字符串 `t`，需要满足：对 `s` 和 `t` 的某一排列，使得所有下标 `i` 满足 `s[i] >= t[i]`（即 `s` 的每个字符都大于或等于 `t` 对应位置的字符）。

判断字符串 `s1` 是否能打破 `s2`，**或者** `s2` 是否能打破 `s1`。若任意一个成立则返回 `true`。

**示例 1：**
```
输入：s1 = "abc", s2 = "xya"
输出：true
解释：s2 排列 "ayx" 可被 s1 "abc" 打破（a>=a, b>=y? 否）
实际：s1="abc"排序, s2="axy"排序，逐位 a>=a, b>=x? 否
     s2="axy" vs s1="abc"，a>=a, x>=b, y>=c，全部满足，s2 打破 s1，返回 true
```

**示例 2：**
```
输入：s1 = "abe", s2 = "acd"
输出：false
解释：排序后 s1="abe", s2="acd"
     s1打破s2：a>=a, b>=c? 否（不满足）
     s2打破s1：a>=a, c>=b, d>=e? 否（不满足）
     返回 false
```

**示例 3：**
```
输入：s1 = "leetcodee", s2 = "interview"
输出：true
```

**提示：**
- `s1.length == s2.length`
- `1 <= s1.length <= 10^5`
- `s1` 和 `s2` 仅由小写英文字母组成

## 解题思路

**贪心观察：**

要使 `s1` 的某个排列能打破 `s2` 的某个排列，最优策略是对两者都排序后逐位比较。

**证明：**  
如果存在某排列使得 `s1[i] >= s2[i]` 对所有 `i` 成立，那么对两者都排序（升序）后同样满足。这是因为排序是一种"最优匹配"——将最小的对应最小的，保证差距最合理。

**算法：**
1. 将 `s1` 和 `s2` 各自排序。
2. 检查 `s1` 是否逐位 `>=` `s2`（即 `s1` 打破 `s2`）。
3. 检查 `s2` 是否逐位 `>=` `s1`（即 `s2` 打破 `s1`）。
4. 任意一个条件成立则返回 `True`。

## Python 代码实现

### 方法一：排序 + 逐位比较（推荐）

```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        # 对两个字符串排序
        sorted_s1 = sorted(s1)
        sorted_s2 = sorted(s2)
        n = len(s1)

        # 检查 s1 是否能打破 s2（排序后逐位 s1[i] >= s2[i]）
        def can_break(a: list, b: list) -> bool:
            return all(a[i] >= b[i] for i in range(len(a)))

        return can_break(sorted_s1, sorted_s2) or can_break(sorted_s2, sorted_s1)
```

### 方法二：一次遍历同时判断两个方向

```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        sorted_s1 = sorted(s1)
        sorted_s2 = sorted(s2)

        s1_breaks_s2 = True  # s1 是否能打破 s2
        s2_breaks_s1 = True  # s2 是否能打破 s1

        for c1, c2 in zip(sorted_s1, sorted_s2):
            if c1 < c2:
                s1_breaks_s2 = False  # s1 有位置不够大
            if c2 < c1:
                s2_breaks_s1 = False  # s2 有位置不够大

        return s1_breaks_s2 or s2_breaks_s1
```

### 方法三：计数排序优化（适合字符集小的情况）

```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        # 使用计数数组代替排序，复杂度从 O(n log n) 降至 O(n + 26)
        count1 = [0] * 26
        count2 = [0] * 26

        for c in s1:
            count1[ord(c) - ord('a')] += 1
        for c in s2:
            count2[ord(c) - ord('a')] += 1

        # 生成排序后的字符序列（通过计数还原）
        def expand(count):
            result = []
            for i, cnt in enumerate(count):
                result.extend([chr(i + ord('a'))] * cnt)
            return result

        sorted_s1 = expand(count1)
        sorted_s2 = expand(count2)

        s1_breaks_s2 = all(c1 >= c2 for c1, c2 in zip(sorted_s1, sorted_s2))
        s2_breaks_s1 = all(c2 >= c1 for c1, c2 in zip(sorted_s1, sorted_s2))

        return s1_breaks_s2 or s2_breaks_s1
```

## 复杂度分析

- **时间复杂度：** O(n log n)，主要来自排序。使用计数排序可降至 O(n + 26) = O(n)。
- **空间复杂度：** O(n)，存储排序后的字符串。

## 图解示例

```
s1 = "abc", s2 = "xya"

排序后：
sorted_s1 = ['a', 'b', 'c']
sorted_s2 = ['a', 'x', 'y']

检查 s1 打破 s2：
  a >= a -> True
  b >= x -> False（'b' < 'x'）
  s1 不能打破 s2

检查 s2 打破 s1：
  a >= a -> True
  x >= b -> True
  y >= c -> True
  s2 能打破 s1！

返回 True
```

## 关键点总结

1. 排序后比较是贪心最优策略：升序对升序，使得匹配最"公平"。
2. 只需要检查两个方向（s1 打破 s2，或 s2 打破 s1），任一成立即可。
3. 使用 `all()` + 生成器表达式可以简洁地表达"逐位全部满足"的条件。
4. 计数排序适用于字符集固定且小的场景，能优化常数。

## 易错点

- 不对字符串排序直接比较，漏掉了"可以重新排列"这一关键条件。
- 只检查一个方向（s1 打破 s2），忘记检查 s2 打破 s1。
- 字符串比较用 `>=` 而非 `>`（允许相等）。
