## 题目描述

给你一个整数 `n`，表示有 `n` 栋房屋（编号 0 到 n-1）。还有一个二维数组 `offers`，`offers[i] = [start_i, end_i, gold_i]` 表示买家 i 愿意用 `gold_i` 的价格购买编号在 `[start_i, end_i]` 范围内的所有房屋。

你可以选择任意多个买家（不重叠的区间），最大化总利润。返回最大利润。

**示例 1：**
```
输入：n = 5, offers = [[0,0,1],[0,2,2],[1,3,2]]
输出：3
解释：选择 [0,0,1] 和 [1,3,2]，利润 = 1+2 = 3
```

**示例 2：**
```
输入：n = 5, offers = [[0,0,1],[0,2,10],[1,3,2]]
输出：10
解释：选择 [0,2,10]，利润 = 10
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= offers.length <= 10^5`
- `0 <= start_i <= end_i <= n - 1`
- `1 <= gold_i <= 10^4`

## 解题思路

经典**区间调度 DP + 二分查找**：

`dp[i]` = 考虑前 i 栋房屋（0 到 i-1）能获得的最大利润。

- `dp[0] = 0`（0 栋房屋，利润为 0）
- 对于每个位置 i，先继承 `dp[i-1]`（不卖第 i-1 栋房屋的 offer）
- 对所有以 i-1 结尾的 offer `[start, end=i-1, gold]`，考虑 `dp[start] + gold`

**按 end 分组**（或排序），对每个 i，找所有 end=i-1 的 offer，更新 dp。

用哈希表将 offer 按 end 分组，时间 O(n + m) (m = offers 数量)。

## Python 代码实现

### 方法一：DP + 哈希表分组（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def maximizeTheProfit(self, n: int, offers: List[List[int]]) -> int:
        # 将 offers 按 end 分组
        end_offers = defaultdict(list)
        for start, end, gold in offers:
            end_offers[end].append((start, gold))

        # dp[i] = 卖出 [0, i-1] 范围内房屋的最大利润
        dp = [0] * (n + 1)

        for i in range(1, n + 1):
            # 不选以 i-1 结尾的 offer，继承前一个状态
            dp[i] = dp[i - 1]
            # 选择以 i-1 结尾的某个 offer
            for start, gold in end_offers[i - 1]:
                # offer 覆盖 [start, i-1]，价值 gold
                dp[i] = max(dp[i], dp[start] + gold)

        return dp[n]
```

### 方法二：排序 + 二分查找（学习版）

```python
import bisect
from typing import List

class Solution:
    def maximizeTheProfit(self, n: int, offers: List[List[int]]) -> int:
        # 按 end 排序
        offers.sort(key=lambda x: x[1])
        m = len(offers)

        # dp[i] = 选前 i 个 offer 的最大利润
        dp = [0] * (m + 1)
        ends = [o[1] for o in offers]  # 用于二分查找

        for i in range(m):
            start, end, gold = offers[i]
            # 不选当前 offer
            dp[i + 1] = dp[i]
            # 选当前 offer：找最后一个 end < start 的 offer
            j = bisect.bisect_left(ends, start, 0, i)  # 找第一个 end >= start
            # dp[j] 是前 j 个 offer 的最大利润（所有 end < start 的）
            dp[i + 1] = max(dp[i + 1], dp[j] + gold)

        return dp[m]
```

## 复杂度分析

- 方法一：时间 O(n + m)，空间 O(n + m)
- 方法二：时间 O(m log m)，空间 O(m)

## 关键点总结

1. 区间不重叠的最大收益是经典 DP 问题
2. `dp[i]` 表示处理前 i 个位置的最大利润
3. 哈希表分组：避免对所有 offer 二分，直接查找对应位置的 offer

## 易错点

1. dp 数组大小为 n+1（下标 0 到 n）
2. `dp[start]` 表示处理 start 之前所有位置的最优解（即 offer 不与前面的重叠）
3. 方法二中二分查找的边界处理
