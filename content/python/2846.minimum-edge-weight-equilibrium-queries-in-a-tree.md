## 题目描述

给你一棵 `n` 个节点的树（无向图），边的权重为 1 到 26 之间的整数，以及 `q` 个查询 `queries[i] = [a, b]`。

对于每个查询，找到将路径 `a -> b` 上所有边的权重变为**相同值**所需的**最少操作数**（每次操作可以修改一条边的权重）。

最少操作数 = 路径长度 - 路径上出现次数最多的权重的次数

返回所有查询的答案数组。

**提示：**
- `1 <= n <= 10^4`
- `1 <= queries.length <= 2 × 10^4`
- `1 <= weight_i <= 26`

## 解题思路

**LCA（最近公共祖先）+ 前缀计数：**

对于查询 `(a, b)`，路径 `a -> b` 经过 LCA。

1. 预处理：对每个节点，记录从根到该节点的路径上各权重的出现次数（前缀计数数组）
2. 路径 `a -> b` 上权重 `w` 的出现次数 = `cnt[a][w] + cnt[b][w] - 2 × cnt[lca][w]`
3. 路径长度 = `depth[a] + depth[b] - 2 × depth[lca]`
4. 最多出现权重次数 = 26 种权重中的最大值
5. 最少操作数 = 路径长度 - 最多出现次数

**LCA：** 用 DFS 和二进制提升预处理。

## Python 代码实现

### 方法一：LCA + 前缀计数（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minOperationsQueries(self, n: int, edges: List[List[int]], queries: List[List[int]]) -> List[int]:
        # 建图
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        LOG = 14  # 2^14 > 10^4
        depth = [0] * n
        parent = [[0] * n for _ in range(LOG)]
        # cnt[i][w] = 从根到节点 i 的路径上权重 w 的次数
        cnt = [[0] * 27 for _ in range(n)]

        # DFS 预处理
        visited = [False] * n
        stack = [(0, -1, 0)]  # (节点, 父节点, 深度)
        while stack:
            node, par, d = stack.pop()
            if visited[node]:
                continue
            visited[node] = True
            depth[node] = d
            parent[0][node] = par if par != -1 else node
            for nei, w in graph[node]:
                if not visited[nei]:
                    # cnt[nei] = cnt[node] + 1 (weight w)
                    cnt[nei] = cnt[node][:]
                    cnt[nei][w] += 1
                    stack.append((nei, node, d + 1))

        # 二进制提升预处理 LCA
        for j in range(1, LOG):
            for i in range(n):
                parent[j][i] = parent[j-1][parent[j-1][i]]

        def lca(u: int, v: int) -> int:
            if depth[u] < depth[v]:
                u, v = v, u
            diff = depth[u] - depth[v]
            for j in range(LOG):
                if (diff >> j) & 1:
                    u = parent[j][u]
            if u == v:
                return u
            for j in range(LOG - 1, -1, -1):
                if parent[j][u] != parent[j][v]:
                    u = parent[j][u]
                    v = parent[j][v]
            return parent[0][u]

        ans = []
        for a, b in queries:
            l = lca(a, b)
            path_len = depth[a] + depth[b] - 2 * depth[l]
            # 各权重在路径上的出现次数
            max_freq = max(cnt[a][w] + cnt[b][w] - 2 * cnt[l][w] for w in range(1, 27))
            ans.append(path_len - max_freq)

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) × log n × 26)，LCA 预处理 O(n log n)，每次查询 O(log n + 26)
- 空间复杂度：O(n × (log n + 26))，前缀计数和 LCA 表

## 关键点总结

1. 路径权重统计：用从根到节点的前缀计数，再用 LCA 去掉公共部分
2. 最少操作 = 路径长度 - 最频繁的权重出现次数
3. 二进制提升预处理 LCA，查询 O(log n)

## 易错点

1. DFS 用迭代（避免 Python 递归深度限制）
2. 路径上权重计数公式：`cnt[a][w] + cnt[b][w] - 2*cnt[lca][w]`（减两次 LCA 到根的路径）
3. 二进制提升中根节点的父节点设为自身（边界处理）
