## 题目描述

给定一个模式 pattern 和一个字符串 s，请你判断 s 是否遵循相同的模式。

这里的遵循指完全匹配，例如，pattern 中的每个字母和字符串 s 中的每个非空单词之间存在双向连接的对应模式。

**示例 1：**
```
输入：pattern = "abab", s = "redblueredblue"
输出：true
解释：一种可能的映射如下：
'a' -> "red"
'b' -> "blue"
```

**示例 2：**
```
输入：pattern = "aaaa", s = "asdasdasdasd"
输出：true
解释：一种可能的映射如下：
'a' -> "asd"
```

**示例 3：**
```
输入：pattern = "abab", s = "asdasdasdasd"
输出：true
解释：一种可能的映射如下：
'a' -> "a"
'b' -> "sd"
```

**提示：**
- 1 <= pattern.length, s.length <= 20
- pattern 只包含小写英文字母
- s 只包含小写英文字母

## 解题思路

这道题是 290. 单词规律的进阶版，区别在于：
- 290 题中字符串已经被空格分割好了
- 本题需要自己决定如何分割字符串 s

**核心思想：回溯 + 哈希表**

1. 使用两个哈希表维护双向映射关系
   - `pattern_to_word`：模式字符到单词的映射
   - `word_to_pattern`：单词到模式字符的映射

2. 递归回溯过程：
   - 如果 pattern 和 s 都遍历完，返回 True
   - 如果只有一个遍历完，返回 False
   - 获取当前模式字符，尝试所有可能的单词分割
   - 检查映射关系是否一致
   - 递归处理剩余部分
   - 回溯恢复状态

3. 剪枝优化：
   - 如果当前字符已有映射，直接验证
   - 提前判断剩余长度是否足够

## Python 代码实现

### 方法一：回溯 + 双向哈希表（推荐）

```python
class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        """
        使用回溯算法尝试所有可能的映射关系
        """
        def backtrack(p_idx: int, s_idx: int) -> bool:
            # 基础情况：都遍历完了
            if p_idx == len(pattern) and s_idx == len(s):
                return True
            
            # 只有一个遍历完，说明不匹配
            if p_idx == len(pattern) or s_idx == len(s):
                return False
            
            # 获取当前模式字符
            char = pattern[p_idx]
            
            # 如果该字符已经有映射
            if char in pattern_to_word:
                word = pattern_to_word[char]
                # 检查 s 中是否有对应的单词
                if not s[s_idx:].startswith(word):
                    return False
                # 递归检查剩余部分
                return backtrack(p_idx + 1, s_idx + len(word))
            
            # 如果该字符还没有映射，尝试所有可能的单词
            for end in range(s_idx + 1, len(s) + 1):
                word = s[s_idx:end]
                
                # 如果这个单词已经被其他字符映射了，跳过
                if word in word_to_pattern:
                    continue
                
                # 建立映射关系
                pattern_to_word[char] = word
                word_to_pattern[word] = char
                
                # 递归检查
                if backtrack(p_idx + 1, end):
                    return True
                
                # 回溯，撤销映射
                del pattern_to_word[char]
                del word_to_pattern[word]
            
            return False
        
        # 初始化两个哈希表
        pattern_to_word = {}
        word_to_pattern = {}
        
        return backtrack(0, 0)
```

### 方法二：回溯 + 剪枝优化

```python
class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        """
        添加剪枝优化的回溯算法
        """
        def backtrack(p_idx: int, s_idx: int) -> bool:
            # 基础情况
            if p_idx == len(pattern) and s_idx == len(s):
                return True
            if p_idx == len(pattern) or s_idx == len(s):
                return False
            
            char = pattern[p_idx]
            
            # 如果已有映射，直接验证
            if char in mapping:
                word = mapping[char]
                if s[s_idx:s_idx + len(word)] == word:
                    return backtrack(p_idx + 1, s_idx + len(word))
                return False
            
            # 尝试所有可能的单词长度
            # 剪枝：至少为剩余pattern每个字符留一个字符
            remaining_chars = len(pattern) - p_idx - 1
            max_len = len(s) - s_idx - remaining_chars
            
            for length in range(1, max_len + 1):
                word = s[s_idx:s_idx + length]
                
                # 检查是否已被映射
                if word in used:
                    continue
                
                # 建立映射
                mapping[char] = word
                used.add(word)
                
                # 递归
                if backtrack(p_idx + 1, s_idx + length):
                    return True
                
                # 回溯
                del mapping[char]
                used.remove(word)
            
            return False
        
        mapping = {}  # pattern字符 -> 单词
        used = set()  # 已使用的单词集合
        
        return backtrack(0, 0)
```

### 方法三：简化版回溯

```python
class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        """
        简化版实现，代码更简洁
        """
        def dfs(p: str, s: str, mapping: dict, used: set) -> bool:
            # 递归终止条件
            if not p:
                return not s
            
            char = p[0]
            
            # 已有映射
            if char in mapping:
                word = mapping[char]
                if s.startswith(word):
                    return dfs(p[1:], s[len(word):], mapping, used)
                return False
            
            # 尝试新映射
            for i in range(1, len(s) + 1):
                word = s[:i]
                if word not in used:
                    # 建立映射并递归
                    if dfs(p[1:], s[i:], {**mapping, char: word}, used | {word}):
                        return True
            
            return False
        
        return dfs(pattern, s, {}, set())
```

## 复杂度分析

### 方法一和方法二：

**时间复杂度：** O(n^m)
- n 是字符串 s 的长度
- m 是 pattern 的长度
- 最坏情况下需要尝试所有可能的分割方式
- 实际运行中由于剪枝，性能会好很多

**空间复杂度：** O(m)
- 递归调用栈深度为 m
- 哈希表存储最多 m 个映射关系

### 方法三：

**时间复杂度：** O(n^m)
- 与方法一相同

**空间复杂度：** O(m · n)
- 每次递归都创建新的字典和集合副本

## 关键点总结

1. **双向映射**：需要同时维护 pattern→word 和 word→pattern 的映射，确保一对一关系
2. **回溯框架**：建立映射 → 递归 → 撤销映射，这是标准的回溯模板
3. **边界条件**：pattern 和 s 必须同时遍历完才算匹配成功
4. **剪枝优化**：计算最大可能的单词长度，避免无效尝试
5. **状态恢复**：回溯时必须完全恢复状态，包括删除映射关系

## 易错点

1. **忘记双向检查**
   ```python
   # 错误：只检查 pattern -> word
   if char in mapping:
       # ...
   
   # 正确：还要检查 word -> pattern
   if word in used:
       continue
   ```

2. **边界条件处理不当**
   ```python
   # 错误：只检查一个是否为空
   if not p:
       return True
   
   # 正确：两个都要检查
   if not p:
       return not s
   ```

3. **回溯时忘记恢复状态**
   ```python
   # 错误：没有删除映射
   mapping[char] = word
   if backtrack(...):
       return True
   # 忘记 del mapping[char]
   
   # 正确：必须恢复
   mapping[char] = word
   if backtrack(...):
       return True
   del mapping[char]
   ```

4. **剪枝条件计算错误**
   ```python
   # 注意：要为剩余的每个pattern字符至少留一个字符
   remaining = len(pattern) - p_idx - 1  # 注意减1
   max_len = len(s) - s_idx - remaining
   ```
