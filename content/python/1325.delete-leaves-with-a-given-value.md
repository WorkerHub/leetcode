## 题目描述

给你一棵以 `root` 为根的二叉树和一个整数 `target`，请你删除**所有值为 `target` 的叶子节点**。

注意，一旦删除值为 `target` 的叶子节点，它的父节点就可能变成叶子节点；如果新的叶子节点的值恰好也是 `target`，那么这个节点也需要被删除。

也就是说，你需要重复此过程直到不能继续删除。

**示例 1：**

```
输入：root = [1,2,3,2,null,2,4], target = 2
输出：[1,null,3,null,4]
解释：
删除叶子节点 2 后，2（左子叶）消失，然后其父节点 2 变成叶子，再删除...
```

**示例 2：**

```
输入：root = [1,3,3,3,2], target = 3
输出：[1,3,null,null,2]
```

**示例 3：**

```
输入：root = [1,2,null,2,null,2], target = 2
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[1, 3000]` 内
- `1 <= Node.val, target <= 1000`

## 解题思路

**后序 DFS（推荐）**

关键观察：删除操作是自底向上的——只有先处理完子树，才能知道父节点是否变成了叶子节点。

因此使用**后序遍历（左右根）**：先递归处理左右子树，再判断当前节点。

**后序 DFS 的逻辑：**

```
dfs(node):
    1. 递归处理左子树：node.left = dfs(node.left)
    2. 递归处理右子树：node.right = dfs(node.right)
    3. 判断当前节点：
       - 如果 node 是叶子（no children）且 node.val == target：返回 None（删除）
       - 否则：返回 node（保留）
```

**为什么后序有效？**

处理完子树后，子树中所有符合条件的叶子已被删除。此时当前节点可能变成了新的叶子，再检查一次即可。不需要循环多次，一次后序遍历就能完成所有删除。

## Python 代码实现

### 方法一：后序 DFS（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def removeLeafNodes(self, root: Optional[TreeNode], target: int) -> Optional[TreeNode]:
        
        def dfs(node: Optional[TreeNode]) -> Optional[TreeNode]:
            if not node:
                return None
            
            # 后序：先处理左右子树
            node.left = dfs(node.left)
            node.right = dfs(node.right)
            
            # 判断当前节点是否为叶子且值等于 target
            if node.left is None and node.right is None and node.val == target:
                return None  # 删除该节点
            
            return node  # 保留该节点
        
        return dfs(root)
```

### 方法二：迭代（使用栈模拟后序遍历）

```python
from typing import Optional

class Solution:
    def removeLeafNodes(self, root: Optional[TreeNode], target: int) -> Optional[TreeNode]:
        if not root:
            return None
        
        # 使用父节点映射，便于删除子节点
        parent = {root: None}  # 记录每个节点的父节点
        stack = [root]
        order = []  # 后序遍历顺序
        
        # 利用前序遍历的逆序来模拟后序
        while stack:
            node = stack.pop()
            order.append(node)
            if node.left:
                parent[node.left] = node
                stack.append(node.left)
            if node.right:
                parent[node.right] = node
                stack.append(node.right)
        
        # 按后序（逆序）处理
        for node in reversed(order):
            # 判断是否为叶子且值为 target
            if node.left is None and node.right is None and node.val == target:
                par = parent[node]
                if par is None:
                    return None  # 根节点本身被删除
                if par.left == node:
                    par.left = None
                else:
                    par.right = None
        
        return root
```

### 方法三：递归简化版（一行）

```python
from typing import Optional

class Solution:
    def removeLeafNodes(self, root: Optional[TreeNode], target: int) -> Optional[TreeNode]:
        if not root:
            return None
        root.left = self.removeLeafNodes(root.left, target)
        root.right = self.removeLeafNodes(root.right, target)
        # 如果当前节点变成了值为 target 的叶子，返回 None
        return None if (not root.left and not root.right and root.val == target) else root
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 为树高，递归栈深度；最坏 O(n)，平均 O(log n)

## 图解示例

以 `root = [1,2,3,2,null,2,4], target = 2` 为例：

```
初始树：
        1
       / \
      2   3
     /   / \
    2   2   4

后序处理：
1. 处理节点 2（最左叶子）：是叶子且值=2，删除 -> 返回 None
2. 处理节点 2（左子根）：左子变 None，无子节点，值=2，删除 -> 返回 None
3. 处理节点 2（3的左子）：是叶子且值=2，删除 -> 返回 None
4. 处理节点 4：是叶子且值=4，保留
5. 处理节点 3：左子变 None，保留
6. 处理节点 1：左子变 None，保留

最终：
    1
     \
      3
       \
        4
```

## 关键点总结

1. **后序遍历**是关键：先处理子树，再处理当前节点
2. 删除叶子的操作：让父节点的对应指针指向 `None`，在递归中即返回 `None`
3. 一次后序遍历即可完成所有删除，不需要多次遍历

## 易错点

1. **前序遍历不行**：如果先处理当前节点再处理子树，子节点变化不能反映到当前节点
2. **返回值的处理**：`node.left = dfs(node.left)` 这一行至关重要，它接收子树处理后的返回值（可能是 None）
3. **叶子判断时机**：在递归处理完左右子树之后才判断，此时子树中的叶子已经被删除
