## 题目描述

给你一个以 `(radius, xCenter, yCenter)` 表示的圆和一个与坐标轴平行的矩形 `(x1, y1, x2, y2)`，其中 `(x1, y1)` 是矩形左下角，`(x2, y2)` 是矩形右上角。

如果圆和矩形有重叠的部分，请你返回 `true`，否则返回 `false`。

**注意：** 圆和矩形只有在存在公共面积时才算重叠，线或点的接触（切线）也算重叠。

**示例 1：**

```
输入：radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1
输出：true
解释：圆和矩形有公共面积，所以返回 true。
```

**示例 2：**

```
输入：radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1
输出：false
```

**示例 3：**

```
输入：radius = 1, xCenter = 0, yCenter = 0, x1 = -1, y1 = 0, x2 = 0, y2 = 1
输出：true
```

**提示：**

- `1 <= radius <= 2000`
- `-10^4 <= xCenter, yCenter <= 10^4`
- `-10^4 <= x1 < x2 <= 10^4`
- `-10^4 <= y1 < y2 <= 10^4`

## 解题思路

**核心数学结论：**

圆和矩形重叠，等价于：**矩形上距离圆心最近的点，到圆心的距离 <= 半径**。

**如何找矩形内距圆心最近的点？**

对 x 坐标和 y 坐标分别做"夹紧"（clamp）操作：
- 最近点的 x 坐标：`closest_x = clamp(xCenter, x1, x2) = max(x1, min(xCenter, x2))`
- 最近点的 y 坐标：`closest_y = clamp(yCenter, y1, y2) = max(y1, min(yCenter, y2))`

**分析：**
- 若圆心在矩形内（`x1 <= xCenter <= x2`），则 `closest_x = xCenter`，x 方向距离为 0
- 若圆心在矩形左侧（`xCenter < x1`），则 `closest_x = x1`
- 若圆心在矩形右侧（`xCenter > x2`），则 `closest_x = x2`
- y 方向同理

最后判断 `(closest_x - xCenter)^2 + (closest_y - yCenter)^2 <= radius^2`。

注意用平方比较，避免浮点数精度问题。

## Python 代码实现

### 方法一：夹紧操作（推荐）

```python
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int,
                     x1: int, y1: int, x2: int, y2: int) -> bool:
        # 找矩形上距圆心最近的点
        # x 方向夹紧：将 xCenter 限制在 [x1, x2] 范围内
        closest_x = max(x1, min(xCenter, x2))
        # y 方向夹紧：将 yCenter 限制在 [y1, y2] 范围内
        closest_y = max(y1, min(yCenter, y2))

        # 计算最近点到圆心的距离平方（避免浮点数开方）
        dist_sq = (closest_x - xCenter) ** 2 + (closest_y - yCenter) ** 2

        # 若距离 <= 半径，则重叠
        return dist_sq <= radius * radius
```

### 方法二：分轴判断（等价但更详细）

```python
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int,
                     x1: int, y1: int, x2: int, y2: int) -> bool:
        # 计算 x 轴方向上圆心与矩形的最短距离
        if xCenter < x1:
            dx = x1 - xCenter   # 圆心在矩形左侧
        elif xCenter > x2:
            dx = xCenter - x2   # 圆心在矩形右侧
        else:
            dx = 0              # 圆心在矩形 x 范围内

        # 计算 y 轴方向上圆心与矩形的最短距离
        if yCenter < y1:
            dy = y1 - yCenter
        elif yCenter > y2:
            dy = yCenter - y2
        else:
            dy = 0

        # 判断最近距离是否 <= 半径
        return dx * dx + dy * dy <= radius * radius
```

## 复杂度分析

- **时间复杂度 O(1)**：只需常数次计算。
- **空间复杂度 O(1)**。

## 图解示例

```
情况1：圆心在矩形内
  closest = (xCenter, yCenter)，距离 = 0 <= radius，重叠

情况2：圆心在矩形正上方
  closest_x = xCenter，closest_y = y2
  距离 = |yCenter - y2|

情况3：圆心在矩形右上角外侧
  closest_x = x2，closest_y = y2
  距离 = sqrt((xCenter-x2)^2 + (yCenter-y2)^2)
```

以示例2为例：`radius=1, center=(1,1), rect=[1,-3,2,-1]`

```
closest_x = max(1, min(1, 2)) = 1
closest_y = max(-3, min(1, -1)) = -1
dist_sq = (1-1)^2 + (-1-1)^2 = 0 + 4 = 4
radius^2 = 1
4 > 1，返回 False
```

## 关键点总结

1. 核心技巧：找矩形上距离圆心最近的点（分 x、y 两轴做夹紧操作）
2. 用 `clamp(val, lo, hi) = max(lo, min(val, hi))` 将值限制在范围内
3. 用距离平方比较（`dist_sq <= radius^2`），避免浮点数 `sqrt` 的精度问题
4. 圆心在矩形内部时，最近点就是圆心本身，距离为 0，一定重叠

## 易错点

- 用 `sqrt` 计算距离可能导致浮点误差，应直接比较平方值
- 注意题目说"切线也算重叠"，所以是 `<=` 而不是 `<`
- `clamp` 操作的方向：`min(xCenter, x2)` 限制上界，`max(x1, ...)` 限制下界
