## 题目描述

给你一个字典 `replacements`（键值对），以及一个字符串 `text`。

`text` 中可能包含 `%key%` 格式的占位符，需要将其替换为对应的值。值本身也可能包含占位符（嵌套替换）。

保证不存在循环替换。

返回完全展开后的字符串。

**示例：**

```
输入：replacements = [["A","abc"],["B","A is %A%"]], text = "B is %B%"
输出："B is A is abc"
```

**提示：**
- 所有替换键唯一
- 没有循环依赖

## 解题思路

记忆化 DFS：对每个键，递归展开其值中的所有占位符。用缓存避免重复计算。

步骤：
1. 建立哈希表存储 key -> value
2. 对每个键，展开其值（递归替换所有 `%key%`）
3. 最终展开 text

## Python 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from typing import List
import re

class Solution:
    def applySubstitutions(self, replacements: List[List[str]], text: str) -> str:
        # 建立哈希表
        rep_map = {k: v for k, v in replacements}
        memo = {}

        def expand(s: str) -> str:
            if s in memo:
                return memo[s]

            # 找所有 %key% 并替换
            result = []
            i = 0
            while i < len(s):
                if s[i] == '%':
                    j = s.find('%', i + 1)
                    if j != -1:
                        key = s[i+1:j]
                        if key in rep_map:
                            result.append(expand(rep_map[key]))
                            i = j + 1
                            continue
                result.append(s[i])
                i += 1

            res = ''.join(result)
            memo[s] = res
            return res

        return expand(text)
```

### 方法二：正则替换 + 记忆化

```python
from typing import List
import re
from functools import lru_cache

class Solution:
    def applySubstitutions(self, replacements: List[List[str]], text: str) -> str:
        rep_map = {k: v for k, v in replacements}

        @lru_cache(maxsize=None)
        def expand(key: str) -> str:
            val = rep_map.get(key, key)
            # 展开 val 中的所有占位符
            return re.sub(r'%(\w+)%', lambda m: expand(m.group(1)), val)

        # 展开 text 中的占位符
        return re.sub(r'%(\w+)%', lambda m: expand(m.group(1)), text)
```

### 方法三：拓扑排序后展开

```python
from typing import List
from collections import defaultdict, deque
import re

class Solution:
    def applySubstitutions(self, replacements: List[List[str]], text: str) -> str:
        rep_map = {k: v for k, v in replacements}

        # 找依赖关系：key A 依赖 key B（A 的值中包含 %B%）
        deps = defaultdict(set)
        for k, v in rep_map.items():
            for m in re.finditer(r'%(\w+)%', v):
                deps[k].add(m.group(1))

        # 拓扑排序，从无依赖的键开始展开
        in_degree = {k: len(deps[k]) for k in rep_map}
        dependents = defaultdict(set)  # B -> {A: A 依赖 B}
        for k in rep_map:
            for d in deps[k]:
                dependents[d].add(k)

        queue = deque([k for k in rep_map if in_degree[k] == 0])
        expanded = {}

        while queue:
            k = queue.popleft()
            val = rep_map[k]
            expanded[k] = re.sub(r'%(\w+)%', lambda m: expanded.get(m.group(1), '%' + m.group(1) + '%'), val)
            for dep in dependents[k]:
                in_degree[dep] -= 1
                if in_degree[dep] == 0:
                    queue.append(dep)

        def replace_text(s):
            return re.sub(r'%(\w+)%', lambda m: expanded.get(m.group(1), m.group(0)), s)

        return replace_text(text)
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为替换规则数，L 为平均字符串长度
- 空间复杂度：O(n * L)，缓存存储展开结果

## 关键点总结

1. 记忆化：对每个键只展开一次，避免重复工作
2. 递归展开：值中的占位符递归替换
3. 无循环依赖保证递归一定终止

## 易错点

1. 展开时要用展开后的值替换，而不是原始值
2. 占位符格式是 `%key%`，两端都有 `%`
3. 若键不在 replacements 中，保持原样
