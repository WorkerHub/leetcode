## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，请你判断在**最多**改变 1 个元素的情况下，该数组能否变成一个非递减数列。

我们是这样定义一个非递减数列的：对于数组中任意的 `i` (0 <= i <= n-2)，总满足 `nums[i] <= nums[i + 1]`。

**示例 1:**

```
输入: nums = [4,2,3]
输出: true
解释: 你可以通过把第一个 4 变成 1 来使得它成为一个非递减数列。
```

**示例 2:**

```
输入: nums = [4,2,1]
输出: false
解释: 你不能在只改变一个元素的情况下将其变为非递减数列。
```

**提示:**
- `n == nums.length`
- `1 <= n <= 10^4`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

这道题的关键是**贪心策略**：遇到逆序对时如何修改。

### 核心观察

当发现 `nums[i] > nums[i+1]` 时，有两种修改方式：

1. **降低 nums[i]**：`nums[i] = nums[i+1]`
2. **提高 nums[i+1]**：`nums[i+1] = nums[i]`

### 贪心选择

为了不影响后续元素，应该：

- 如果 `i == 0` 或 `nums[i-1] <= nums[i+1]`：降低 nums[i]（更安全）
- 否则：提高 nums[i+1]

### 算法流程

1. 遍历数组，统计逆序对数量
2. 如果逆序对 > 1，返回 False
3. 如果恰好 1 个逆序对，按贪心策略修改
4. 检查修改后是否非递减

## Python 代码实现

### 方法一：贪心（推荐）⭐

```python
from typing import List

class Solution:
    def checkPossibility(self, nums: List[int]) -> bool:
        """
        贪心策略：遇到逆序对时选择最优修改方式
        """
        count = 0  # 逆序对数量
        n = len(nums)
        
        for i in range(n - 1):
            if nums[i] > nums[i + 1]:
                count += 1
                
                # 超过 1 次，无法修复
                if count > 1:
                    return False
                
                # 决定如何修改
                if i == 0 or nums[i - 1] <= nums[i + 1]:
                    # 降低 nums[i]
                    nums[i] = nums[i + 1]
                else:
                    # 提高 nums[i+1]
                    nums[i + 1] = nums[i]
        
        return True
```

### 方法二：不修改原数组

```python
class Solution:
    def checkPossibility(self, nums: List[int]) -> bool:
        """
        不修改原数组的版本
        """
        count = 0
        n = len(nums)
        
        for i in range(n - 1):
            if nums[i] > nums[i + 1]:
                count += 1
                if count > 1:
                    return False
                
                # 检查修改后能否继续
                # 尝试降低 nums[i]
                if i > 0 and nums[i - 1] > nums[i + 1]:
                    # 必须提高 nums[i+1]
                    # 检查后续是否可行
                    if i + 2 < n and nums[i] > nums[i + 2]:
                        return False
        
        return True
```

### 方法三：简洁版

```python
class Solution:
    def checkPossibility(self, nums: List[int]) -> bool:
        count = 0
        for i in range(len(nums) - 1):
            if nums[i] <= nums[i + 1]:
                continue
            
            count += 1
            if count > 1:
                return False
            
            if i > 0 and nums[i - 1] > nums[i + 1]:
                nums[i + 1] = nums[i]
            else:
                nums[i] = nums[i + 1]
        
        return True
```

## 复杂度分析

- **时间复杂度**：O(n)，单次遍历
- **空间复杂度**：O(1)，原地修改

## 关键点总结

1. **最多一次修改**：逆序对不能超过 1 个
2. **贪心策略**：优先降低前一个元素
3. **边界判断**：考虑 i-1 和 i+1 的关系
4. **修改原则**：不影响后续元素

## 易错点

1. **修改选择**：
   ```python
   # 错误：总是降低 nums[i]
   nums[i] = nums[i + 1]
   
   # 正确：根据情况选择
   if i == 0 or nums[i - 1] <= nums[i + 1]:
       nums[i] = nums[i + 1]
   else:
       nums[i + 1] = nums[i]
   ```

2. **计数判断**：
   ```python
   # 要及时返回
   if count > 1:
       return False
   ```

3. **边界情况**：
   ```python
   # i == 0 时没有 nums[i-1]
   if i == 0 or nums[i - 1] <= nums[i + 1]:
   ```
