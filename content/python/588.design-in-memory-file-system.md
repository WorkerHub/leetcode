## 题目描述

设计一个内存文件系统，模拟以下功能：

- `ls`：列出路径下的文件和目录
- `mkdir`：创建目录
- `addContentToFile`：添加内容到文件
- `readContentFromFile`：读取文件内容

## Python 代码实现

```python
from collections import defaultdict

class FileSystem:
    def __init__(self):
        self.root = {'dirs': {}, 'files': {}}
    
    def ls(self, path: str) -> List[str]:
        node = self._navigate(path)
        if 'content' in node:  # 是文件
            return [path.split('/')[-1]]
        return sorted(list(node['dirs'].keys()) + list(node['files'].keys()))
    
    def mkdir(self, path: str) -> None:
        self._navigate(path)
    
    def addContentToFile(self, filePath: str, content: str) -> None:
        node = self._navigate(filePath)
        node['content'] = node.get('content', '') + content
    
    def readContentFromFile(self, filePath: str) -> str:
        node = self._navigate(filePath)
        return node['content']
    
    def _navigate(self, path: str):
        if path == '/':
            return self.root
        
        parts = path.split('/')[1:]
        node = self.root
        
        for part in parts[:-1]:
            if part not in node['dirs']:
                node['dirs'][part] = {'dirs': {}, 'files': {}}
            node = node['dirs'][part]
        
        last = parts[-1]
        if last not in node['dirs'] and last not in node['files']:
            node['files'][last] = {}
        
        return node['files'].get(last) or node['dirs'][last]
```

## 关键点总结

1. **树形结构**：使用嵌套字典
2. **路径导航**：split分割路径
3. **文件vs目录**：使用不同的键区分
