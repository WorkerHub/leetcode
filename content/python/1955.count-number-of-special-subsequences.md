## 题目描述

**特殊序列**是包含若干个 0，接着若干个 1，再接着若干个 2 的子序列（每段至少一个）。

给你一个只包含 0、1、2 的数组 `nums`，返回 `nums` 中特殊子序列的数量，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：nums = [0, 1, 2, 2]
输出：3
解释：特殊子序列：[0,1,2], [0,1,2], [0,1,2,2]
```

**示例 2：**
```
输入：nums = [2, 0, 1, 2, 0]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 2`

---

## 解题思路

### 核心思想：动态规划

定义三个 DP 状态：
- `dp0`：只包含 0（长度 >= 1）的子序列数
- `dp1`：包含若干 0 接着若干 1（各至少 1 个）的子序列数
- `dp2`：完整特殊子序列数（0..1..2）

对每个元素：
- 若 `nums[i] == 0`：
  - 可以新开一个 "0" 子序列，或将之前的 0 子序列后面加一个 0
  - `dp0 = dp0 * 2 + 1`
- 若 `nums[i] == 1`：
  - 新开一个 "01" 子序列（在任意 dp0 后面加 1），或将 dp1 后面加 1
  - `dp1 = dp1 * 2 + dp0`
- 若 `nums[i] == 2`：
  - 新开一个完整序列（在 dp1 后面加 2），或将 dp2 后面加 2
  - `dp2 = dp2 * 2 + dp1`

## 代码实现

### 方法一：DP 三状态（推荐）

```python
from typing import List

class Solution:
    def countSpecialSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        dp0 = dp1 = dp2 = 0  # 三种子序列的计数

        for x in nums:
            if x == 0:
                # 用当前 0 扩展现有 dp0，或新起一个
                dp0 = (dp0 * 2 + 1) % MOD
            elif x == 1:
                # 用当前 1 扩展现有 dp1，或接在任意 dp0 之后
                dp1 = (dp1 * 2 + dp0) % MOD
            else:  # x == 2
                # 用当前 2 扩展现有 dp2，或接在任意 dp1 之后
                dp2 = (dp2 * 2 + dp1) % MOD

        return dp2
```

### 方法二：显式二维 DP（对比学习）

```python
from typing import List

class Solution:
    def countSpecialSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        # dp[i][k] = 前 i 个元素中，阶段 k 的子序列数
        # k=0: 纯0, k=1: 0...1..., k=2: 0...1...2...
        dp = [0, 0, 0]

        for x in nums:
            new_dp = dp[:]
            if x == 0:
                new_dp[0] = (dp[0] * 2 + 1) % MOD
            elif x == 1:
                new_dp[1] = (dp[1] * 2 + dp[0]) % MOD
            else:
                new_dp[2] = (dp[2] * 2 + dp[1]) % MOD
            dp = new_dp

        return dp[2]
```

## 关键点总结

1. DP 状态：当前形成的子序列处于哪个阶段（全 0、0..1..、完整）
2. 转移：遇到相同数字时可以扩展（*2）或新接（+dp[k-1]）
3. 三个状态独立更新，顺序不影响

---

## 易错点

- 每次遇到数字只影响对应阶段的状态，不要混淆
- 注意取模：中间结果可能很大
