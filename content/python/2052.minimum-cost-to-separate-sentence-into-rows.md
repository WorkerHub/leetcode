## 题目描述

给你一个字符串 `sentence`，表示一个句子（由若干单词用空格分隔）。还有一个整数 `k`，每行最多容纳 `k` 个字符。

你可以把句子分成多行，规则是：
- 单词不能跨行
- 相邻单词在同一行时，中间有一个空格
- 除最后一行外，每行多余的空格（即行长度不足 k 的部分）产生代价：`(k - 行长度)^2`
- 最后一行不产生代价

返回最小总代价。

**示例：**
```
输入：sentence = "i love leetcode", k = 12
输出：0
解释：将全部放在一行刚好12字符，代价为0
```

**提示：**
- `1 <= sentence.length <= 5000`
- `sentence` 由小写字母和空格组成，且单词由单个空格分隔

## 解题思路

**DP 定义：** `dp[i]` = 将前 `i` 个单词放置好（第 i 个单词在某行末尾）时的最小代价。

**状态转移：** 枚举最后一行放置的单词区间 `[j+1, i]`：
- 计算区间长度 `len = sum(word_lengths[j+1..i]) + (i - j - 1)` 个空格
- 若 `len <= k` 且不是最后一行：代价 = `(k - len)^2`
- 若是最后一行：代价 = 0

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def minimumCost(self, sentence: str, k: int) -> int:
        words = sentence.split()
        n = len(words)
        lens = [len(w) for w in words]

        # dp[i] = 分割前 i 个单词的最小代价（0-indexed）
        INF = float('inf')
        dp = [INF] * n
        dp[0] = 0  # 第一个单词单独一行，如果是最后一行代价为 0

        # 前缀和加速区间长度计算
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + lens[i]

        def row_len(j, i):
            # 从第 j 个到第 i 个单词放一行的总字符数（含空格）
            return prefix[i + 1] - prefix[j] + (i - j)

        for i in range(n):
            # 枚举最后一行的起始单词 j
            for j in range(i + 1):
                rl = row_len(j, i)
                if rl > k:
                    break  # 超过行宽度，更早的 j 也不行了（其实应该反向）

            # 重新：枚举 j 从 0 到 i
            for j in range(i + 1):
                rl = row_len(j, i)
                if rl > k:
                    continue
                # [j, i] 这些单词放最后一行（无代价）
                prev_cost = dp[j - 1] if j > 0 else 0
                # 但我们要确保 [0..j-1] 的代价是已知的
                # dp[i] 应该是最小代价

        # 正确实现
        dp = [INF] * (n + 1)
        dp[0] = 0  # 0 个单词时代价为 0

        for i in range(1, n + 1):
            for j in range(i, 0, -1):
                rl = row_len(j - 1, i - 1)  # 第 j 到 i 个单词（1-indexed）
                if rl > k:
                    break
                # 最后一行（i == n）代价为 0
                if i == n:
                    dp[i] = min(dp[i], dp[j - 1])
                else:
                    dp[i] = min(dp[i], dp[j - 1] + (k - rl) ** 2)

        return dp[n]
```

### 方法二：简化实现

```python
class Solution:
    def minimumCost(self, sentence: str, k: int) -> int:
        words = sentence.split()
        n = len(words)
        psum = [0]
        for w in words:
            psum.append(psum[-1] + len(w))

        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            row_width = 0
            for j in range(i, 0, -1):
                # 第 j..i 个单词在一行（1-indexed）
                word_len = psum[i] - psum[j - 1]
                spaces = i - j
                row_width = word_len + spaces
                if row_width > k:
                    break
                extra = k - row_width
                if i == n:
                    dp[i] = min(dp[i], dp[j - 1])
                else:
                    dp[i] = min(dp[i], dp[j - 1] + extra * extra)

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^2)，双层循环
- 空间复杂度：O(n)，DP 数组

## 关键点总结

1. 前缀和快速计算区间内单词字符总数
2. 最后一行代价为 0，其他行代价为 `(k - 行长)^2`
3. 行长 = 单词字符总数 + 空格数（单词数 - 1）

## 易错点

- 最后一行（第 n 个单词结束那行）代价为 0
- 若行长 > k，该分割方案无效
- 前缀和要包含空格（不含空格），空格单独计算
