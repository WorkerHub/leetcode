## 题目描述

给你一个整数数组 `nums`、一个整数 `k` 和一个整数 `multiplier`。

每次操作：找出 `nums` 中的**最小值**（若有多个，取最左边的），将其乘以 `multiplier`。

执行 `k` 次操作后，返回最终的数组。

**示例 1：**
```
输入：nums = [2,1,3,5,6], k = 5, multiplier = 2
输出：[8,4,6,5,6]
```

**示例 2：**
```
输入：nums = [1,2,3,4,5], k = 3, multiplier = 4
输出：[16,8,3,4,5]
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= k <= 10`
- `1 <= multiplier <= 5`
- `1 <= nums[i] <= 100`

## 解题思路

由于数据范围小，直接模拟：每次找到最小值（最左边）并乘以 multiplier，重复 k 次。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def getFinalState(self, nums: List[int], k: int, multiplier: int) -> List[int]:
        for _ in range(k):
            # 找最小值的最左位置
            min_idx = 0
            for i in range(1, len(nums)):
                if nums[i] < nums[min_idx]:
                    min_idx = i
            nums[min_idx] *= multiplier
        return nums
```

### 方法二：最小堆模拟

```python
from typing import List
import heapq

class Solution:
    def getFinalState(self, nums: List[int], k: int, multiplier: int) -> List[int]:
        # 最小堆：(值, 下标)
        heap = [(v, i) for i, v in enumerate(nums)]
        heapq.heapify(heap)
        
        result = nums[:]
        for _ in range(k):
            val, idx = heapq.heappop(heap)
            result[idx] = val * multiplier
            heapq.heappush(heap, (val * multiplier, idx))
        
        return result
```

## 复杂度分析

- 方法一：时间复杂度 O(k * n)
- 方法二：时间复杂度 O((k + n) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 每次找最小值（同值取左边），乘以 multiplier
2. 数据范围小，模拟足够
3. 最小堆可以高效找最小值

## 易错点

1. 多个最小值时选最左边，堆中用 (值, 下标) 排序可以保证
2. 注意是在原数组上修改，不是新建
