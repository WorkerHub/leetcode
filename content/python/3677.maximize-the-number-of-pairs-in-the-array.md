## 题目描述

给你一个整数数组 `nums`，每次操作可以选择两个相等的元素配对并移除。返回最多可以配对的对数。

**示例 1：**

```
输入：nums = [1,3,2,1,3,2,2]
输出：3
解释：配对 (1,1),(3,3),(2,2)，还剩一个2
```

**示例 2：**

```
输入：nums = [1,1]
输出：1
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 解题思路

统计每个元素的出现次数，每个元素可以配 `freq[v] // 2` 对。

## Python 代码实现

### 方法一：Counter 计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maximumPairs(self, nums: List[int]) -> int:
        freq = Counter(nums)
        return sum(v // 2 for v in freq.values())
```

### 方法二：直接枚举

```python
from typing import List

class Solution:
    def maximumPairs(self, nums: List[int]) -> int:
        count = [0] * 101
        for x in nums:
            count[x] += 1
        return sum(c // 2 for c in count)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(max_val)

## 关键点总结

1. 每种元素独立配对
2. 频率除以 2 取整即为配对数

## 易错点

1. 不同元素不能配对
2. 取整（floor division）而非四舍五入
