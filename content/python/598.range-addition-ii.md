## 题目描述

给你一个 `m x n` 的矩阵 `M`，初始化时所有元素都是 0。另外给你一个操作数组 `ops`，其中 `ops[i] = [ai, bi]` 意味着当所有元素 `M[x][y]` 满足 `0 <= x < ai` 且 `0 <= y < bi` 时，`M[x][y]` 都应加 1。

在执行完所有操作后，计算并返回矩阵中最大整数的个数。

**示例：**
```
输入：m = 3, n = 3, ops = [[2,2],[3,3]]
输出：4
解释：M 中最大的整数是 2，而且有 4 个值为 2 的元素（位于 [0,0]、[0,1]、[1,0]、[1,1]）
```

**提示：**
- `1 <= m, n <= 4 * 10^4`
- `0 <= ops.length <= 10^4`
- `ops[i].length == 2`
- `1 <= ai <= m`
- `1 <= bi <= n`

## Python 代码实现

```python
from typing import List

class Solution:
    def maxCount(self, m: int, n: int, ops: List[List[int]]) -> int:
        """
        找最小的覆盖范围
        
        时间复杂度：O(k)，k是操作数
        空间复杂度：O(1)
        """
        if not ops:
            return m * n
        
        min_a = min(op[0] for op in ops)
        min_b = min(op[1] for op in ops)
        
        return min_a * min_b
```

## 关键点总结

1. **观察规律**：最大值出现在所有操作的交集
2. **交集面积**：min(所有a) × min(所有b)
3. **空操作**：返回 m × n
