## 题目描述

给你一个二维数组 `tasks`，其中 `tasks[i] = [enqueueTimei, processingTimei]`，分别表示第 i 个任务的入队时间和处理时长。

CPU 按以下规则运行任务（单线程，每次只处理一个任务）：
1. 若 CPU 空闲且任务队列为空，则等待下一个任务入队
2. 若 CPU 空闲，从已入队的任务中选择处理时间最短的任务（相同则选下标最小的）
3. 处理完一个任务后，立即选择下一个

返回执行任务的顺序（以任务下标表示）。

**示例：**
```
输入：tasks = [[1,2],[2,4],[3,2],[4,1]]
输出：[0,2,3,1]
```

## 解题思路

**排序 + 最小堆模拟**：
1. 将任务按入队时间排序（保留原始下标）
2. 维护一个最小堆 `available`，存储已入队但未处理的任务（按处理时间、下标排序）
3. 模拟 CPU 时钟，每次从堆中取出最优任务处理
4. 若堆为空且当前时间 < 下一个任务的入队时间，跳跃到该时间

## 代码实现

### 方法一：排序 + 最小堆（推荐）

```python
import heapq
from typing import List

class Solution:
    def getOrder(self, tasks: List[List[int]]) -> List[int]:
        n = len(tasks)
        # 将任务按入队时间排序，保留原始下标
        indexed = sorted(range(n), key=lambda i: tasks[i][0])

        result = []
        heap = []       # 最小堆：(处理时间, 原始下标)
        time = 0        # 当前 CPU 时钟
        task_ptr = 0    # 指向下一个待入队的任务

        while len(result) < n:
            # 将所有在 time 时刻之前已入队的任务加入堆
            while task_ptr < n and tasks[indexed[task_ptr]][0] <= time:
                i = indexed[task_ptr]
                heapq.heappush(heap, (tasks[i][1], i))  # (处理时间, 下标)
                task_ptr += 1

            if not heap:
                # 堆为空，CPU 跳跃到下一个任务的入队时间
                time = tasks[indexed[task_ptr]][0]
                continue

            # 取处理时间最短（相同则下标最小）的任务
            proc_time, orig_idx = heapq.heappop(heap)
            result.append(orig_idx)
            time += proc_time  # 更新时钟

        return result
```

### 方法二：使用 enumerate 保留下标

```python
import heapq
from typing import List

class Solution:
    def getOrder(self, tasks: List[List[int]]) -> List[int]:
        # 带原始下标的任务列表，按入队时间排序
        sorted_tasks = sorted(enumerate(tasks), key=lambda x: x[1][0])

        result = []
        heap = []   # (处理时间, 原始下标)
        time = 0
        ptr = 0
        n = len(tasks)

        while len(result) < n:
            # 加入所有可用任务
            while ptr < n and sorted_tasks[ptr][1][0] <= time:
                idx, (enq, proc) = sorted_tasks[ptr]
                heapq.heappush(heap, (proc, idx))
                ptr += 1

            if heap:
                proc, idx = heapq.heappop(heap)
                result.append(idx)
                time += proc
            else:
                # 跳跃时钟
                time = sorted_tasks[ptr][1][0]

        return result
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序和堆操作
- **空间复杂度**：O(n)，堆大小

## 关键点总结

1. 任务先按入队时间排序，用指针依次加入堆
2. 堆以（处理时间，下标）为键，保证选取最优任务
3. CPU 空闲且堆为空时，直接跳跃到下一个任务的入队时间

## 易错点

- 时间跳跃后要重新检查堆，可能多个任务同时入队
- 任务下标需要保留，排序后要通过原始下标来查 tasks
