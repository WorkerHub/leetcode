## 题目描述

[LeetCode 1201. Ugly Number III](https://leetcode.com/problems/ugly-number-iii/)

给你四个整数：`n`、`a`、`b`、`c`，请你设计一个算法来找出第 `n` 个丑数。

丑数是可以被 `a` 或 `b` 或 `c` 整除的正整数。

**示例 1:**
```
输入：n = 3, a = 2, b = 3, c = 5
输出：4
解释：丑数序列为 2, 3, 4, 5, 6, 8, 9, 10... 其中第 3 个是 4。
```

**示例 2:**
```
输入：n = 4, a = 2, b = 3, c = 4
输出：6
解释：丑数序列为 2, 3, 4, 6, 8, 9, 10, 12... 其中第 4 个是 6。
```

**示例 3:**
```
输入：n = 5, a = 2, b = 11, c = 13
输出：10
解释：丑数序列为 2, 4, 6, 8, 10, 11, 12, 13... 其中第 5 个是 10。
```

**提示:**
- 1 <= n, a, b, c <= 10^9
- 1 <= a * b * c <= 10^18
- 本题结果在 [1, 2 * 10^9] 的范围内

## 解题思路

这道题的核心是：在给定范围内找第 n 个能被 a、b 或 c 整除的数。

### 关键观察

1. **单调性**：丑数序列是单调递增的，这提示我们可以使用二分查找
2. **计数问题**：如果我们能快速计算出 `[1, x]` 范围内有多少个丑数，就可以二分查找第 n 个丑数
3. **容斥原理**：计算能被 a、b 或 c 整除的数的个数，需要用容斥原理避免重复计数

### 容斥原理详解

在 `[1, x]` 范围内：
- 能被 a 整除的数有 `x / a` 个
- 能被 b 整除的数有 `x / b` 个
- 能被 c 整除的数有 `x / c` 个

但直接相加会重复计数，比如同时被 a 和 b 整除的数。根据容斥原理：

```
count = x/a + x/b + x/c - x/lcm(a,b) - x/lcm(a,c) - x/lcm(b,c) + x/lcm(a,b,c)
```

其中 lcm 表示最小公倍数。

### 算法流程

1. 使用二分查找，在 `[1, 2*10^9]` 范围内搜索
2. 对于每个中间值 mid，计算 `[1, mid]` 中丑数的个数
3. 如果个数 >= n，说明答案在左半部分（包括 mid）
4. 如果个数 < n，说明答案在右半部分
5. 最终找到第 n 个丑数

## Python 代码实现

### 方法一：二分查找 + 容斥原理（推荐）

```python
from typing import List
import math

class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        # 计算最大公约数
        def gcd(x: int, y: int) -> int:
            while y:
                x, y = y, x % y
            return x
        
        # 计算最小公倍数
        def lcm(x: int, y: int) -> int:
            return x * y // gcd(x, y)
        
        # 计算三个数的最小公倍数
        def lcm3(x: int, y: int, z: int) -> int:
            return lcm(lcm(x, y), z)
        
        # 计算 [1, num] 范围内有多少个丑数
        def count_ugly(num: int) -> int:
            # 容斥原理
            return (num // a + num // b + num // c 
                    - num // lcm(a, b) - num // lcm(a, c) - num // lcm(b, c)
                    + num // lcm3(a, b, c))
        
        # 二分查找第 n 个丑数
        left, right = 1, 2 * 10**9
        
        while left < right:
            mid = (left + right) // 2
            if count_ugly(mid) < n:
                left = mid + 1
            else:
                right = mid
        
        return left
```

### 方法二：使用 math.gcd（Python 3.5+）

```python
from typing import List
import math

class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        # 使用 Python 内置的 gcd 函数
        def lcm(x: int, y: int) -> int:
            return x * y // math.gcd(x, y)
        
        # 预计算所有需要的最小公倍数
        lcm_ab = lcm(a, b)
        lcm_ac = lcm(a, c)
        lcm_bc = lcm(b, c)
        lcm_abc = lcm(lcm_ab, c)
        
        # 计算 [1, num] 范围内的丑数个数
        def count_ugly(num: int) -> int:
            return (num // a + num // b + num // c 
                    - num // lcm_ab - num // lcm_ac - num // lcm_bc
                    + num // lcm_abc)
        
        # 二分查找
        left, right = 1, 2 * 10**9
        
        while left < right:
            mid = left + (right - left) // 2
            if count_ugly(mid) < n:
                left = mid + 1
            else:
                right = mid
        
        return left
```

### 方法三：优化的二分查找（避免溢出）

```python
from typing import List
import math

class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        def lcm(x: int, y: int) -> int:
            return x * y // math.gcd(x, y)
        
        # 预计算最小公倍数
        ab, ac, bc = lcm(a, b), lcm(a, c), lcm(b, c)
        abc = lcm(ab, c)
        
        # 容斥原理计数
        def count(num: int) -> int:
            return (num // a + num // b + num // c 
                    - num // ab - num // ac - num // bc + num // abc)
        
        # 二分查找，使用更安全的中点计算
        left, right = min(a, b, c), min(a, b, c) * n
        
        while left < right:
            mid = left + (right - left) // 2
            if count(mid) < n:
                left = mid + 1
            else:
                right = mid
        
        return left
```

## 复杂度分析

### 方法一、二、三

- **时间复杂度**：O(log(2×10^9) × log(max(a,b,c)))
  - 二分查找的次数为 O(log(2×10^9)) ≈ 31 次
  - 每次计算 gcd 的时间复杂度为 O(log(max(a,b,c)))
  - 由于 gcd 可以预计算，实际上每次查询是 O(1)
  - 总体时间复杂度约为 O(31) = O(1)
  
- **空间复杂度**：O(1)
  - 只使用了常数个变量

## 关键点总结

1. **二分查找的应用**：虽然不能直接枚举丑数序列，但可以二分答案，利用单调性找到第 n 个丑数

2. **容斥原理**：计算被 a 或 b 或 c 整除的数时，要减去重复计算的部分（lcm），再加回被三次减去的部分

3. **最小公倍数计算**：lcm(a, b) = a × b / gcd(a, b)，这是数论中的基本公式

4. **预计算优化**：将所有需要的 lcm 提前计算好，避免在二分过程中重复计算

5. **边界设置**：右边界可以设为 min(a,b,c) × n，这是一个安全的上界

## 易错点

1. **整数溢出**：计算 lcm 时，a × b 可能会溢出，应该写成 `a * b // gcd(a, b)` 而不是 `a // gcd(a, b) * b`

2. **容斥原理遗漏**：容易忘记加上 `+ num // lcm(a,b,c)` 这一项，导致重复减去的部分没有加回来

3. **二分边界**：left 和 right 的更新要正确，确保不会陷入死循环
   - 当 count(mid) < n 时，mid 肯定不是答案，所以 left = mid + 1
   - 当 count(mid) >= n 时，mid 可能是答案，所以 right = mid

4. **gcd 的实现**：如果手写 gcd，注意递归终止条件和参数顺序

5. **右边界估计**：不能简单设为 a × n，因为 a 可能不是最小值
