## 题目描述

与 3256 相同，但数据范围更大：
- `3 <= m, n <= 500`

**提示：**
- `3 <= m, n <= 500`
- `-10^9 <= board[i][j] <= 10^9`

## 解题思路

与 3256 相同的算法，对每行保留前 3 大的值，然后枚举中间行和前后缀最优组合。

由于 m, n 最大 500，对每行保留 top3 需要 O(n)，前后缀计算 O(m)，枚举中间行 O(m * 9) 次，总时间 O(m * n + m * 27) = O(m * n)。

## Python 代码实现

### 方法一：枚举中间行 + 前后缀 top3（推荐）

```python
from typing import List

class Solution:
    def maximumValueSum(self, board: List[List[int]]) -> int:
        m, n = len(board), len(board[0])
        
        def get_top3(row_idx):
            # 返回第 row_idx 行中最大的 3 个 (value, col) 对
            vals = sorted(enumerate(board[row_idx]), key=lambda x: -x[1])
            return [(v, c) for c, v in vals[:3]]
        
        rows = [get_top3(r) for r in range(m)]
        
        def merge_top3(a, b):
            # 合并两个 top3 列表，取最大的 3 个
            combined = sorted(a + b, key=lambda x: -x[0])
            return combined[:3]
        
        # 前缀 top3：prefix[i] = 行 0..i 的合并 top3
        prefix = [None] * m
        prefix[0] = rows[0]
        for i in range(1, m):
            prefix[i] = merge_top3(prefix[i - 1], rows[i])
        
        # 后缀 top3：suffix[i] = 行 i..m-1 的合并 top3
        suffix = [None] * m
        suffix[m - 1] = rows[m - 1]
        for i in range(m - 2, -1, -1):
            suffix[i] = merge_top3(suffix[i + 1], rows[i])
        
        ans = float('-inf')
        
        for r2 in range(1, m - 1):
            for v2, c2 in rows[r2]:
                # 从前缀 prefix[r2-1] 选不同列的最大值
                for v1, c1 in prefix[r2 - 1]:
                    if c1 == c2:
                        continue
                    # 从后缀 suffix[r2+1] 选不同列的最大值
                    for v3, c3 in suffix[r2 + 1]:
                        if c3 != c1 and c3 != c2:
                            ans = max(ans, v1 + v2 + v3)
                            break
                    break  # 已找到最优 v1（prefix 是降序的）
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n + m * 27) = O(m * n)
- 空间复杂度：O(m * 3)

## 关键点总结

1. 每行只需 top3，枚举三行选三不同列，最多 3*3*3=27 种组合
2. 前后缀合并的 top3 保证了跨行选最优
3. 对每个中间行，找前缀和后缀的不冲突最大值

## 易错点

1. 前后缀 top3 的合并需要保留列信息
2. 枚举时三列必须两两不同
