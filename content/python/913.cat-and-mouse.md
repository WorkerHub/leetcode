## 题目描述

两位玩家分别扮演猫和老鼠，在一个 **无向** 图上进行游戏，两人轮流行动。

图的形式是：`graph[a]` 是一个列表，由满足 `ab` 是图中的一条边的所有节点 `b` 组成。

老鼠从节点 `1` 开始，第一个出发；猫从节点 `2` 开始，第二个出发。在节点 `0` 处有一个洞。

在每个玩家的行动中，他们 **必须** 沿着图中与所在当前位置连通的一条边移动。例如，如果老鼠在节点 `1`，那么它必须移动到 `graph[1]` 中的任一节点。

此外，猫无法移动到洞中（节点 `0`）。

然后，游戏在出现以下三种情形之一时结束：

- 如果猫和老鼠出现在同一个节点，猫获胜。
- 如果老鼠到达洞中，老鼠获胜。
- 如果某一位置重复出现（即，玩家的位置和移动顺序都与上一次行动相同），游戏平局。

给你一张图 `graph`，并假设两位玩家都都以最佳状态参与游戏：

- 如果老鼠获胜，则返回 `1`；
- 如果猫获胜，则返回 `2`；
- 如果平局，则返回 `0`。

**示例 1：**
```
输入：graph = [[2,5],[3],[0,4,5],[1,4,5],[2,3],[0,2,3]]
输出：0
```

**示例 2：**
```
输入：graph = [[1,3],[0],[3],[0,2]]
输出：1
```

**提示：**
- `3 <= graph.length <= 50`
- `1 <= graph[i].length < graph.length`
- `0 <= graph[i][j] < graph.length`
- `graph[i][j] != i`
- `graph[i]` 互不相同
- 猫不能进入洞（节点 0）

## 解题思路

这是一道博弈论问题，需要使用 **极小极大算法（Minimax）** 和 **拓扑排序**。

**状态定义：**
- 状态：`(mouse, cat, turn)`
  - `mouse`：老鼠的位置
  - `cat`：猫的位置
  - `turn`：轮到谁行动（1 表示老鼠，2 表示猫）

**游戏结果：**
- 老鼠胜利：`mouse == 0`
- 猫胜利：`mouse == cat`
- 平局：状态重复或无法判定

**算法思路：**
1. 从已知的胜负状态开始（老鼠在洞里，或猫抓到老鼠）
2. 使用逆向推理（拓扑排序），推导出所有状态的结果
3. 如果某个状态的所有后继状态都对对手有利，则当前状态对对手有利
4. 如果某个状态存在一个后继状态对自己有利，则当前状态对自己有利

## Python 代码实现

### 方法一：拓扑排序 + BFS（推荐 ⭐）

```python
from typing import List
from collections import deque

class Solution:
    def catMouseGame(self, graph: List[List[int]]) -> int:
        n = len(graph)
        DRAW, MOUSE, CAT = 0, 1, 2
        
        # result[mouse][cat][turn] = 游戏结果
        # turn: 1 表示老鼠回合，2 表示猫回合
        result = [[[0] * 3 for _ in range(n)] for _ in range(n)]
        
        # degree[mouse][cat][turn] = 该状态的出度
        degree = [[[0] * 3 for _ in range(n)] for _ in range(n)]
        
        # 计算每个状态的出度
        for m in range(n):
            for c in range(n):
                degree[m][c][MOUSE] = len(graph[m])
                degree[m][c][CAT] = len([node for node in graph[c] if node != 0])
        
        # 队列：存储已确定结果的状态
        queue = deque()
        
        # 初始化已知的状态
        for i in range(n):
            for t in range(1, 3):
                # 老鼠在洞里，老鼠胜
                result[0][i][t] = MOUSE
                queue.append((0, i, t, MOUSE))
                
                # 猫抓到老鼠，猫胜（老鼠不在洞里）
                if i > 0:
                    result[i][i][t] = CAT
                    queue.append((i, i, t, CAT))
        
        # BFS 反向推导
        while queue:
            mouse, cat, turn, res = queue.popleft()
            
            if mouse == 1 and cat == 2 and turn == MOUSE:
                return res
            
            # 找到所有可以到达当前状态的前驱状态
            if turn == MOUSE:
                # 当前是老鼠的回合，前一步是猫的回合
                for prev_cat in graph[cat]:
                    if prev_cat == 0:  # 猫不能进洞
                        continue
                    
                    if result[mouse][prev_cat][CAT] > 0:
                        continue
                    
                    # 如果对猫有利，直接设置
                    if res == CAT:
                        result[mouse][prev_cat][CAT] = CAT
                        queue.append((mouse, prev_cat, CAT, CAT))
                    else:
                        # 如果对老鼠有利，减少出度
                        degree[mouse][prev_cat][CAT] -= 1
                        if degree[mouse][prev_cat][CAT] == 0:
                            result[mouse][prev_cat][CAT] = MOUSE
                            queue.append((mouse, prev_cat, CAT, MOUSE))
            else:
                # 当前是猫的回合，前一步是老鼠的回合
                for prev_mouse in graph[mouse]:
                    if result[prev_mouse][cat][MOUSE] > 0:
                        continue
                    
                    # 如果对老鼠有利，直接设置
                    if res == MOUSE:
                        result[prev_mouse][cat][MOUSE] = MOUSE
                        queue.append((prev_mouse, cat, MOUSE, MOUSE))
                    else:
                        # 如果对猫有利，减少出度
                        degree[prev_mouse][cat][MOUSE] -= 1
                        if degree[prev_mouse][cat][MOUSE] == 0:
                            result[prev_mouse][cat][MOUSE] = CAT
                            queue.append((prev_mouse, cat, MOUSE, CAT))
        
        return result[1][2][MOUSE]
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def catMouseGame(self, graph: List[List[int]]) -> int:
        n = len(graph)
        DRAW, MOUSE, CAT = 0, 1, 2
        
        @lru_cache(None)
        def dfs(mouse, cat, turn):
            # 超过一定步数，判定为平局（避免无限循环）
            if turn > 2 * n:
                return DRAW
            
            # 老鼠在洞里，老鼠胜
            if mouse == 0:
                return MOUSE
            
            # 猫抓到老鼠，猫胜
            if mouse == cat:
                return CAT
            
            if turn % 2 == 1:  # 老鼠的回合
                mouse_win = False
                for next_mouse in graph[mouse]:
                    res = dfs(next_mouse, cat, turn + 1)
                    if res == MOUSE:
                        return MOUSE
                    if res == DRAW:
                        mouse_win = True
                
                return DRAW if mouse_win else CAT
            else:  # 猫的回合
                cat_win = False
                for next_cat in graph[cat]:
                    if next_cat == 0:  # 猫不能进洞
                        continue
                    res = dfs(mouse, next_cat, turn + 1)
                    if res == CAT:
                        return CAT
                    if res == DRAW:
                        cat_win = True
                
                return DRAW if cat_win else MOUSE
        
        return dfs(1, 2, 1)
```

## 复杂度分析

**方法一：拓扑排序**
- 时间复杂度：O(n^3)，状态数 O(n^2)，每个状态最多访问 O(n) 条边
- 空间复杂度：O(n^2)，存储状态结果

**方法二：记忆化搜索**
- 时间复杂度：O(n^3)
- 空间复杂度：O(n^2)

## 关键点总结

1. **博弈论问题**：需要考虑双方都以最优策略行动
2. **状态定义**：`(mouse, cat, turn)` 三维状态
3. **逆向推理**：从已知结果倒推
4. **出度优化**：如果所有后继状态都对对手有利，则当前状态对对手有利
5. **平局处理**：通过限制步数或检测循环判定平局

## 易错点

1. **猫不能进洞**：在遍历猫的移动时要排除节点 0
2. **状态初始化**：要正确初始化老鼠胜利和猫胜利的状态
3. **回合区分**：要区分是老鼠的回合还是猫的回合
4. **循环判断**：要防止无限循环，限制步数或使用拓扑排序
5. **出度计算**：猫的出度要排除节点 0
