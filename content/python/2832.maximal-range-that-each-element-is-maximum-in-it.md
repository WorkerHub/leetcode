## 题目描述

给你一个整数数组 `nums`，返回一个数组 `ans`，其中 `ans[i]` 是以 `nums[i]` 作为最大元素的最长子数组的长度。

**示例 1：**
```
输入：nums = [1,5,4,3,6]
输出：[1,4,2,1,5]
解释：
nums[0]=1: 最长子数组 [1]，长度 1
nums[1]=5: 最长子数组 [1,5,4,3]，长度 4
nums[2]=4: 最长子数组 [4,3]，长度 2
nums[3]=3: 最长子数组 [3]，长度 1
nums[4]=6: 最长子数组 [1,5,4,3,6]，长度 5
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：[1,1,1,1,5]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- nums 中元素**互不相同**

## 解题思路

对每个元素 `nums[i]`，找：
- `left[i]`：左边第一个比 `nums[i]` 大的元素的下标（不存在则 -1）
- `right[i]`：右边第一个比 `nums[i]` 大的元素的下标（不存在则 n）

则 `ans[i] = right[i] - left[i] - 1`

用**单调栈**求左右边界，时间 O(n)。

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def maximumLengthOfRanges(self, nums: List[int]) -> List[int]:
        n = len(nums)
        left = [-1] * n   # left[i] = 左边第一个比 nums[i] 大的下标
        right = [n] * n   # right[i] = 右边第一个比 nums[i] 大的下标

        # 单调递减栈，求左边界
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] < nums[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)

        # 单调递减栈，求右边界
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] < nums[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)

        return [right[i] - left[i] - 1 for i in range(n)]
```

### 方法二：一次扫描（两遍）

```python
from typing import List

class Solution:
    def maximumLengthOfRanges(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n

        # 左边界：维护一个单调递减栈
        left = [0] * n  # left[i] = 左边可延伸的距离
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] < nums[i]:
                stack.pop()
            left[i] = i - stack[-1] if stack else i + 1
            # 不对，这个思路不对，还是用左右边界法

        # 重新用正确方法
        left_bound = [-1] * n
        right_bound = [n] * n

        stk = []
        for i in range(n):
            while stk and nums[stk[-1]] < nums[i]:
                stk.pop()
            left_bound[i] = stk[-1] if stk else -1
            stk.append(i)

        stk = []
        for i in range(n - 1, -1, -1):
            while stk and nums[stk[-1]] < nums[i]:
                stk.pop()
            right_bound[i] = stk[-1] if stk else n
            stk.append(i)

        return [right_bound[i] - left_bound[i] - 1 for i in range(n)]
```

## 复杂度分析

- 时间复杂度：O(n)，两次单调栈扫描
- 空间复杂度：O(n)，辅助数组和栈

## 关键点总结

1. 每个元素 i 作为最大元素的最长子数组：左右扩展到第一个比它大的元素为止
2. 单调栈高效求左右边界（每个元素最多进出栈一次）
3. 答案 = `right[i] - left[i] - 1`

## 易错点

1. 由于元素各不相同，不需要处理相等情况（>而非>=）
2. 左边界默认 -1（左边没有比它大的），右边界默认 n（右边没有比它大的）
3. 栈存下标，不存元素值
