## 题目描述

给你一个正整数数组 `nums` 和一个正整数 `k`。

**分区** 是将数组分为两个非空子集，每个元素恰好属于一个子集（顺序无关）。若两种分区的分法不同（即至少一个元素属于不同子集），则视为不同分区。

若两个子集的和均 >= `k`，则称该分区为 **好分区**。

返回 **好分区** 的数目（结果对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：nums = [1,2,3,4], k = 4
输出：6
解释：好分区包括：[1,4],[2,3] 等
```

**示例 2：**

```
输入：nums = [3,3,3], k = 4
输出：0
```

**提示：**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

**容斥定理**：好分区数 = 总分区数 - 坏分区数（至少一个子集的和 < k）。

- 总分区数：n 个元素分两个非空子集 = 2^(n-1) - 1（因为同一种分法不算两次）。实际是 2^n / 2 = 2^(n-1)，再减去空集情况...

更准确：总分区数 = 2^n / 2 = 2^(n-1)（每种分法和其补集视为一种）。但这里每个元素分配给子集 1 或子集 2，共 2^n - 2 种（排除两个空集），再除以 2 = 2^(n-1) - 1。

**坏分区**：子集 1 的和 < k（即子集 2 和 >= k 自动满足但子集 1 不满足）。

用 DP 计算和 < k 的子集数量：`dp[j]` = 选若干元素使和恰好为 j 的方案数（0-1 背包）。坏分区数 = 2 * sum(dp[j] for j < k) - 2（排除空集和全集）。

实际更简单：坏分区数 = sum(dp[j] for 0 <= j < k)（选子集1和<k的方案数，子集2自动确定），再减去 1（空集）和 1（全集，当全部和 < k 时），然后再乘 2（子集1和子集2对称）。

## Python 代码实现

### 方法一：容斥 + 0-1 背包（推荐）

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = sum(nums)

        # 若总和 < 2k，则不可能有好分区
        if total < 2 * k:
            return 0

        # 总分区数（每种分法双向不重复）= 2^(n-1)
        total_partitions = pow(2, n - 1, MOD)

        # 坏分区：子集1的和 < k，用 0-1 背包计算
        # dp[j] = 选若干元素使和恰好为 j 的子集数量
        dp = [0] * k
        dp[0] = 1
        for num in nums:
            for j in range(k - 1, -1, -1):
                if j + num < k:
                    dp[j + num] = (dp[j + num] + dp[j]) % MOD

        # 坏分区数：子集1和 in [0, k-1] 的选法数
        # 去掉空集（j=0 有一种选法对应空子集，不算有效分区）
        bad = sum(dp) % MOD

        # 对称：子集2和 < k 的情况与子集1相同（但实际是互补的，不重复）
        # 由于子集1和 < k 时，子集2和 = total - 子集1和 >= 2k - (k-1) >= k（已排除total<2k情况）
        # 所以这里 bad 就是子集1和 < k 的分区数（含空集）
        # 减去空集（dp[0] = 1 但子集1为空不算有效分区）
        bad = (bad - 1 + MOD) % MOD  # 去掉空子集

        return (total_partitions - bad + MOD) % MOD
```

### 方法二：直接 DP 计算合法方案

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = sum(nums)
        if total < 2 * k:
            return 0

        # 计算和 < k 的子集数（不含空集和全集）
        dp = [0] * k
        dp[0] = 1
        for num in nums:
            for j in range(min(k - 1, k - 1), -1, -1):
                if j + num < k:
                    dp[j + num] = (dp[j + num] + dp[j]) % MOD

        bad_count = (sum(dp) - 1) % MOD  # -1 排除空集
        all_count = (pow(2, n - 1, MOD) - 1 + MOD) % MOD  # 排除全集在一侧的情况
        return (pow(2, n - 1, MOD) - bad_count + MOD) % MOD
```

## 复杂度分析

- 时间复杂度：O(n * k)，0-1 背包
- 空间复杂度：O(k)，DP 数组

## 关键点总结

1. 好分区数 = 总分区数 - 坏分区数（至少一个子集和 < k）
2. 总和 < 2k 时一定没有好分区，提前判断
3. 0-1 背包统计和严格小于 k 的子集数

## 易错点

1. 总分区数是 2^(n-1)（每种分法和补集视为同一种）
2. 排除空子集的情况（空集不是有效分区）
3. 当 total >= 2k 时，子集1和 < k 则子集2和 = total - 子集1和 >= k，是坏的
