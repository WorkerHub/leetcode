## 题目描述

给你一个字符串数组 words，只返回可以使用在美式键盘同一行的字母打印出来的单词。键盘如下图所示。

美式键盘中：
- 第一行由字符 "qwertyuiop" 组成
- 第二行由字符 "asdfghjkl" 组成
- 第三行由字符 "zxcvbnm" 组成

**示例 1：**
```
输入：words = ["Hello","Alaska","Dad","Peace"]
输出：["Alaska","Dad"]
```

**示例 2：**
```
输入：words = ["omk"]
输出：[]
```

**示例 3：**
```
输入：words = ["adsdf","sfd"]
输出：["adsdf","sfd"]
```

**提示：**
- 1 <= words.length <= 20
- 1 <= words[i].length <= 100
- words[i] 由英文字母（小写和大写字母）组成

## 解题思路

这是一道简单的字符串处理题，核心是判断单词的所有字母是否都在同一行。

### 核心思想

1. **字符分组**：
   - 将键盘字符分成三组
   - 建立字符到行号的映射

2. **判断方法**：
   - 获取单词第一个字符的行号
   - 检查其他字符是否都在同一行

3. **优化思路**：
   - 使用集合快速判断字符属于哪一行
   - 使用哈希表存储字符到行的映射

## Python 代码实现

### 方法一：哈希表映射（推荐）

```python
from typing import List

class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        """
        使用哈希表建立字符到行的映射
        
        时间复杂度：O(n * m)，n 是单词数，m 是平均长度
        空间复杂度：O(1)
        """
        # 建立字符到行号的映射
        row_map = {}
        rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"]
        
        for i, row in enumerate(rows):
            for char in row:
                row_map[char] = i
                row_map[char.upper()] = i  # 大写字母
        
        result = []
        
        for word in words:
            if not word:
                continue
            
            # 获取第一个字符的行号
            first_row = row_map[word[0]]
            
            # 检查所有字符是否在同一行
            if all(row_map[char] == first_row for char in word):
                result.append(word)
        
        return result
```

### 方法二：使用集合判断

```python
class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        """
        使用集合判断字符是否都在某一行
        
        时间复杂度：O(n * m)
        空间复杂度：O(1)
        """
        row1 = set("qwertyuiopQWERTYUIOP")
        row2 = set("asdfghjklASDFGHJKL")
        row3 = set("zxcvbnmZXCVBNM")
        
        result = []
        
        for word in words:
            word_set = set(word)
            # 检查单词的所有字符是否是某一行的子集
            if (word_set <= row1 or 
                word_set <= row2 or 
                word_set <= row3):
                result.append(word)
        
        return result
```

### 方法三：列表推导式（简洁版）

```python
class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        """
        使用列表推导式
        
        时间复杂度：O(n * m)
        空间复杂度：O(1)
        """
        rows = [
            set("qwertyuiopQWERTYUIOP"),
            set("asdfghjklASDFGHJKL"),
            set("zxcvbnmZXCVBNM")
        ]
        
        return [word for word in words 
                if any(set(word) <= row for row in rows)]
```

### 方法四：最简洁的实现

```python
class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        """
        最简洁的实现
        
        时间复杂度：O(n * m)
        空间复杂度：O(1)
        """
        rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"]
        
        result = []
        for word in words:
            lower_word = word.lower()
            for row in rows:
                if all(c in row for c in lower_word):
                    result.append(word)
                    break
        
        return result
```

### 方法五：正则表达式（炫技）

```python
import re

class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        """
        使用正则表达式
        
        时间复杂度：O(n * m)
        空间复杂度：O(1)
        """
        return [word for word in words
                if re.match(r'(?i)([qwertyuiop]*|[asdfghjkl]*|[zxcvbnm]*)$', word)]
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(n × m)
  - n 是单词数量
  - m 是单词的平均长度
  - 需要检查每个单词的每个字符

- **空间复杂度**：O(1)
  - 键盘行数固定
  - 字符集固定
  - 不随输入规模增长

## 关键点总结

1. **字符映射**：建立字符到行的映射关系
2. **集合操作**：使用子集判断 `set(word) <= row`
3. **大小写处理**：转换为小写或建立双向映射
4. **短路求值**：使用 `all()` 和 `any()` 提前终止
5. **多种实现**：哈希表、集合、推导式等

## 易错点

1. **大小写处理**
   - 单词包含大小写字母
   - 需要统一处理或建立双向映射

2. **空单词**
   - words[i] 长度至少为 1（题目保证）
   - 但代码中可以加判断更稳健

3. **集合操作符**
   - `<=` 表示子集
   - `<` 表示真子集
   - 本题用 `<=`

4. **all 和 any 的使用**
   - `all()`：所有元素都为 True
   - `any()`：至少一个元素为 True
   - 空序列：all 返回 True，any 返回 False

5. **break 的位置**
   - 找到匹配的行后要 break
   - 避免重复添加
