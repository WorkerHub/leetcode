## 题目描述

有一个整数数组 `nums`，以及若干 `requests`，每个请求是 `[starti, endi]`，表示取 `nums[starti..endi]` 的子数组之和。

你可以对 `nums` 进行任意排列，使得所有请求的子数组和之总和最大。

返回所有请求之和的最大值，对 `10^9 + 7` 取模。

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `requests.length <= 10^5`

## 解题思路

### 贪心 + 差分数组

**贪心思路：** 某个位置被更多次请求覆盖，就应该放更大的数。

**步骤：**
1. 用差分数组统计每个位置被请求覆盖的次数 `freq[i]`
2. 对 `freq` 和 `nums` 都降序排序
3. 将最大的数放到被覆盖最多的位置，依次匹配

## 代码实现

### 方法一：差分数组 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maxSumRangeQuery(self, nums: List[int], requests: List[List[int]]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        # 差分数组
        diff = [0] * (n + 1)
        for l, r in requests:
            diff[l] += 1
            diff[r + 1] -= 1

        # 还原频次数组
        freq = []
        cur = 0
        for i in range(n):
            cur += diff[i]
            freq.append(cur)

        # 降序排序
        freq.sort(reverse=True)
        nums.sort(reverse=True)

        # 贪心：最大频次配最大数
        ans = 0
        for f, x in zip(freq, nums):
            if f == 0:
                break
            ans = (ans + f * x) % MOD

        return ans
```

### 方法二：使用 numpy（非标准，展示思路）

```python
from typing import List

class Solution:
    def maxSumRangeQuery(self, nums: List[int], requests: List[List[int]]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        cnt = [0] * n
        # 差分思路
        for l, r in requests:
            cnt[l] += 1
            if r + 1 < n:
                cnt[r + 1] -= 1
        # 前缀和还原
        for i in range(1, n):
            cnt[i] += cnt[i-1]
        cnt.sort(reverse=True)
        nums.sort(reverse=True)
        return sum(c * x for c, x in zip(cnt, nums) if c > 0) % MOD
```

## 复杂度分析

- **时间复杂度**：O(N log N + R)，R 为请求数，N 为数组长度
- **空间复杂度**：O(N)

## 关键点总结

1. 差分数组统计每个位置被覆盖的次数
2. 贪心：高频率位置 × 大数字，最大化总和
3. 当 `freq[i] == 0` 时可以提前终止

## 易错点

- 差分数组还原后需要对频次排序（不是原始差分值）
- 只有 `freq[i] > 0` 的位置才有意义
