## 题目描述

给定一个二叉树的根节点 `root`，判断其是否是一个完全二叉树。

在一个完全二叉树中，除了最后一层外，所有层都是完全填充的，并且最后一层中的所有节点都尽可能地靠左。最后一层（第 h 层）包含 `1` 到 `2^h` 个节点。

**示例 1：**
```
输入：root = [1,2,3,4,5,6]
输出：true
```

**示例 2：**
```
输入：root = [1,2,3,4,5,null,7]
输出：false
```

**提示：**
- 树中节点数在范围 `[1, 100]` 内
- `1 <= Node.val <= 1000`

## 解题思路

完全二叉树的特点：层序遍历时，遇到第一个空节点后，不应该再有非空节点。

## Python 代码实现

### 方法一：层序遍历（推荐）⭐

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        """层序遍历检查完全性"""
        if not root:
            return True
        
        queue = deque([root])
        found_null = False
        
        while queue:
            node = queue.popleft()
            
            if node is None:
                found_null = True
            else:
                if found_null:
                    return False
                queue.append(node.left)
                queue.append(node.right)
        
        return True
```

### 方法二：编号法

```python
class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        """给节点编号，检查编号连续性"""
        if not root:
            return True
        
        queue = deque([(root, 1)])
        max_index = 0
        count = 0
        
        while queue:
            node, index = queue.popleft()
            max_index = max(max_index, index)
            count += 1
            
            if node.left:
                queue.append((node.left, 2 * index))
            if node.right:
                queue.append((node.right, 2 * index + 1))
        
        return max_index == count
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. 完全二叉树：遇到空节点后不能再有节点
2. 编号法：最大编号等于节点数

## 易错点

1. 要将None也入队
2. 注意空树的处理
