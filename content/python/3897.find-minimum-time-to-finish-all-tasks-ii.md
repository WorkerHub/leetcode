## 题目描述

给你一个任务列表 `tasks`，每个任务 `tasks[i] = [start, end, duration]`，表示任务必须在 `[start, end]` 时间段内完成，且需要持续时间 `duration`（不一定连续）。

你每次只能同时进行一个任务，返回完成所有任务所需的最少总时间（从 0 开始）。如果无法完成所有任务则返回 -1。

**示例 1：**

```
输入：tasks = [[2, 3, 1], [4, 5, 1], [1, 5, 2]]
输出：2
解释：时间 1-3 执行 tasks[2] 共 2 个单位，时间 2-3 执行 tasks[0] 1 个单位... 实际需要调度。
```

**提示：**
- `1 <= tasks.length <= 2000`
- `tasks[i].length == 3`
- `1 <= start_i <= end_i <= 2000`
- `1 <= duration_i <= end_i - start_i + 1`

## 解题思路

贪心策略（类似 CPU 调度）：
1. 按截止时间 `end` 升序排序任务。
2. 使用位集（bitarray）记录哪些时间段已被占用。
3. 对每个任务，贪心地在 `[start, end]` 范围内尽量选最晚的空闲时间段。

## Python 代码实现

### 方法一：贪心 + 位集（推荐）

```python
from typing import List

class Solution:
    def findMinimumTime(self, tasks: List[List[int]]) -> int:
        # 按截止时间排序
        tasks.sort(key=lambda x: x[1])
        max_time = max(end for _, end, _ in tasks)

        # 位集：run[t] = 1 表示时间 t 已被占用
        run = [0] * (max_time + 1)

        for start, end, duration in tasks:
            # 统计 [start, end] 内已占用的时间
            already = sum(run[start:end + 1])
            need = duration - already

            # 贪心：从后往前选空闲时间段
            for t in range(end, start - 1, -1):
                if need <= 0:
                    break
                if not run[t]:
                    run[t] = 1
                    need -= 1

            if need > 0:
                return -1  # 任务无法完成

        return sum(run)
```

### 方法二：前缀和优化

```python
from typing import List

class Solution:
    def findMinimumTime(self, tasks: List[List[int]]) -> int:
        tasks.sort(key=lambda x: x[1])
        max_time = max(t[1] for t in tasks)
        run = [0] * (max_time + 2)

        for start, end, duration in tasks:
            # 计算 [start, end] 内已占用的时间（前缀和）
            already = sum(run[start:end + 1])
            need = max(0, duration - already)

            # 从后往前填满 need 个时间段
            for t in range(end, start - 1, -1):
                if need <= 0:
                    break
                if not run[t]:
                    run[t] = 1
                    need -= 1

        return sum(run)
```

## 复杂度分析

- 时间复杂度：O(n * max_time)，每个任务最多扫描 max_time 个时间点
- 空间复杂度：O(max_time)

## 关键点总结

1. 按截止时间升序排序，优先处理最紧急的任务（贪心）。
2. 从截止时间往前贪心选空闲时间段（尽量晚执行，为早截止任务留出空间）。
3. 位集记录已占用时间，支持 O(1) 查询。

## 易错点

1. 已占用时间不算入 need（`need = duration - already`）。
2. 若 need > 0 任务无法完成时返回 -1。
3. 贪心方向是从后往前（最晚执行）。
