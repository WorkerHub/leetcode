## 题目描述

给定字符串数组 `words`，每次操作可以交换相邻两个字符串的位置。求将所有互为字母异位词（anagram）的字符串分组放在一起所需的最少操作次数（类似于将相同类别的元素排在一起）。

**示例 1：**
```
输入：words = ["bca","aaa","aaa","bca"]
输出：1
解释：交换 words[1] 和 words[2] 不需要（已经在一起），实际上只需要 1 次操作：
     将 "bca"(下标 3) 移到 "bca"(下标 0) 旁边需要 3 次；
     或将 "aaa"(下标 1) 和 "aaa"(下标 2) 视为已分组，"bca" 放两边需要 1 次交换。
```

**示例 2：**
```
输入：words = ["abc","cba","bca","abc"]
输出：1
```

**提示：**
- `1 <= words.length <= 50`
- `1 <= words[i].length <= 20`

## 解题思路

等价于：将数组按"字母异位词类别"排序，使相同类别相邻，求最少交换次数。

这等价于计算将数组按类别分组的最少相邻交换次数（类似于排序所需的最少冒泡交换次数）。

**方法：** 将每个字符串规范化（排序字母），相同规范化形式的归为一类。计算将数组变成"所有同类相邻"的最少交换次数。

这等价于计算当前排列的逆序对数目（针对类别标签序列）。

## Python 代码实现

### 方法一：贪心模拟（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minOperations(self, words: List[str]) -> int:
        # 将每个词规范化
        def normalize(w):
            return ''.join(sorted(w))

        n = len(words)
        # 分配类别标签
        label_map = {}
        labels = []
        for w in words:
            key = normalize(w)
            if key not in label_map:
                label_map[key] = len(label_map)
            labels.append(label_map[key])

        # 统计每个类别的目标位置（按首次出现顺序）
        # 计算最少相邻交换次数（等价于逆序对数）
        # 目标：相同标签的放在一起，保持类别内相对顺序
        target = sorted(range(n), key=lambda i: labels[i])
        # 逆序对：使用归并排序计数
        pos = [0] * n
        for i, t in enumerate(target):
            pos[t] = i  # 原下标 t 移到位置 i

        # 计算逆序对数
        def merge_sort(arr):
            if len(arr) <= 1:
                return arr, 0
            mid = len(arr) // 2
            left, l_inv = merge_sort(arr[:mid])
            right, r_inv = merge_sort(arr[mid:])
            merged = []
            inv = l_inv + r_inv
            i = j = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i])
                    i += 1
                else:
                    merged.append(right[j])
                    inv += len(left) - i
                    j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged, inv

        _, inversions = merge_sort(pos)
        return inversions
```

### 方法二：暴力模拟冒泡排序

```python
from typing import List

class Solution:
    def minOperations(self, words: List[str]) -> int:
        def normalize(w):
            return ''.join(sorted(w))

        words = list(words)
        ops = 0
        n = len(words)

        # 冒泡排序（按规范化形式）
        for i in range(n):
            for j in range(n - 1):
                if normalize(words[j]) > normalize(words[j+1]):
                    words[j], words[j+1] = words[j+1], words[j]
                    ops += 1

        return ops
```

## 复杂度分析

- 时间复杂度：方法一 O(n log n)（含归并排序逆序对）；方法二 O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 字母异位词规范化：对字母排序，相同规范化形式为同组
2. 分组相邻等价于求将类别序列排序的最少相邻交换次数（逆序对数）
3. 归并排序可以在 O(n log n) 内统计逆序对

## 易错点

1. 同组内元素的相对顺序不重要，只需最终同组相邻
2. 逆序对计数需要以组标签而非词本身排序
