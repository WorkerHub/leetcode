## 题目描述

有一根长度为 `n` 的木板，一些蚂蚁在木板上爬行。每只蚂蚁以 **1单位/秒** 的速度移动。当两只蚂蚁相遇时，它们会同时改变方向继续爬行，一旦到达木板端点，就会从木板上落下。

给你一个整数 `n` 和两个整数数组 `left`（向左爬的蚂蚁位置）和 `right`（向右爬的蚂蚁位置），返回所有蚂蚁落下之前的最后时刻。

**示例 1：**
```
输入：n = 4, left = [4,3], right = [0,1]
输出：4
```

**示例 2：**
```
输入：n = 7, left = [0,1,2,3,4,5,6,7], right = []
输出：7
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= left.length <= n + 1`
- `0 <= right.length <= n + 1`

## 解题思路

### 脑筋急转弯关键观察

两只蚂蚁相遇后各自掉头，等效于**两只蚂蚁穿过彼此继续前行**（因为蚂蚁是相同的，无法区分）。

因此：
- 向左爬的蚂蚁，落下时间 = 其当前位置（到左端点的距离）
- 向右爬的蚂蚁，落下时间 = `n - 其当前位置`（到右端点的距离）

最后一只蚂蚁落下的时刻 = 所有蚂蚁落下时间的最大值。

## 代码实现

### 方法一：脑筋急转弯（推荐）

```python
from typing import List

class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        ans = 0
        # 向左爬的蚂蚁，落下时间为其当前位置（到左端的距离）
        for pos in left:
            ans = max(ans, pos)
        # 向右爬的蚂蚁，落下时间为 n - 当前位置（到右端的距离）
        for pos in right:
            ans = max(ans, n - pos)
        return ans
```

### 方法二：使用内置函数简化

```python
from typing import List

class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        # 左向蚂蚁最大位置 vs 右向蚂蚁最大剩余距离
        max_left = max(left, default=0)
        max_right = max((n - pos for pos in right), default=0)
        return max(max_left, max_right)
```

### 方法三：合并处理

```python
from typing import List

class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        # 将两种情况统一计算后取最大值
        times = [pos for pos in left] + [n - pos for pos in right]
        return max(times) if times else 0
```

## 复杂度分析

- **时间复杂度**：O(L + R)，L 和 R 分别是 left、right 数组长度
- **空间复杂度**：O(1)，方法一只用常数额外空间

## 关键点总结

1. 核心洞察：两只蚂蚁碰撞相当于穿过对方，不改变全局蚂蚁分布
2. 向左蚂蚁落下时间 = 位置值；向右蚂蚁落下时间 = `n - 位置值`
3. 答案就是所有落下时间的最大值
4. 不需要真正模拟碰撞过程

## 易错点

- 错误地去模拟碰撞，复杂度变成 O(N^2)
- 忘记处理 left 或 right 为空的边界情况
- 混淆向左蚂蚁的落下时间（不是 `n - pos` 而是 `pos`）
