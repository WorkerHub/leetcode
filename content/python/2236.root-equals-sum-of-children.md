## 题目描述

给你一个二叉树的根节点 `root`，该二叉树恰好有两层，所有叶子节点都在第二层。

二叉树满足以下条件：
- 根节点（第一层）只有一个节点，其值为 `root.val`。
- 第二层每个节点的值都是正整数，且没有重复。

如果根节点的值等于其左子节点和右子节点值之和，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：root = [10,4,6]
输出：true
```

**示例 2：**
```
输入：root = [5,3,1]
输出：false
```

## 解题思路

直接检查：`root.val == root.left.val + root.right.val`。

## 代码实现

### 方法一：直接比较（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def checkTree(self, root: Optional[TreeNode]) -> bool:
        # 根节点值是否等于左右子节点值之和
        return root.val == root.left.val + root.right.val
```

### 方法二：通用树求和（可扩展到多层）

```python
from typing import Optional

class Solution:
    def checkTree(self, root: Optional[TreeNode]) -> bool:
        # 计算子节点之和（此题只有两层，左右子节点即叶子）
        children_sum = 0
        if root.left:
            children_sum += root.left.val
        if root.right:
            children_sum += root.right.val
        return root.val == children_sum
```

## 复杂度分析

- 时间复杂度：O(1)，只访问固定的 3 个节点。
- 空间复杂度：O(1)。

## 关键点总结

1. 题目保证恰好两层，根节点有且只有左右两个子节点。
2. 直接比较根值与左右子节点值之和即可。

## 易错点

- 题目保证树结构固定（两层），不需要递归遍历。
- 确认根节点一定有左右子节点，无需空指针检查（但方法二更鲁棒）。
