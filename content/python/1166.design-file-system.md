## 题目描述

设计一个文件系统，允许你创建新路径并将它们与不同的值相关联。

路径的格式是一个或多个连接的字符串，形式为：`/` 后跟一个或多个小写英文字母。例如，`/leetcode` 和 `/leetcode/problems` 是有效路径，而空字符串 `""` 和 `/` 不是有效路径。

实现 `FileSystem` 类：

- `FileSystem()` 初始化对象
- `bool createPath(string path, int value)` 创建一个新路径并将一个值与之关联，如果可能则返回 `true`。如果路径已经存在或其父路径不存在，则返回 `false`。
- `int get(string path)` 返回与路径关联的值，如果路径不存在则返回 `-1`。

示例：

```
输入：
["FileSystem","createPath","get"]
[[],["/a",1],["/a"]]
输出：
[null,true,1]

输入：
["FileSystem","createPath","createPath","get","createPath","get"]
[[],["/leet",1],["/leet/code",2],["/leet/code"],["/c/d",1],["/c"]]
输出：
[null,true,true,2,false,-1]
解释：
FileSystem fileSystem = new FileSystem();
fileSystem.createPath("/leet", 1); // 返回 true
fileSystem.createPath("/leet/code", 2); // 返回 true
fileSystem.get("/leet/code"); // 返回 2
fileSystem.createPath("/c/d", 1); // 返回 false，因为父路径 "/c" 不存在
fileSystem.get("/c"); // 返回 -1，因为路径不存在
```

提示：

- 对 `createPath` 和 `get` 的调用次数加起来最多 `10^4` 次
- `2 <= path.length <= 100`
- `1 <= value <= 10^9`

## 解题思路

这是一道设计类题目，需要实现一个类似文件系统的路径管理结构。

**核心考点：**

1. 路径的父子关系验证
2. 高效的路径存储和查询
3. 路径格式的解析

**两种主要方法：**

**方法一：哈希表**
- 使用哈希表直接存储路径和值的映射
- 创建路径时，检查父路径是否存在
- 时间复杂度：O(path长度)，需要解析路径找父路径

**方法二：字典树（Trie）**
- 使用树形结构存储路径层级关系
- 更符合文件系统的实际结构
- 空间开销略大，但扩展性更好

## Python 代码实现

### 方法一：哈希表（推荐）

```python
class FileSystem:
    def __init__(self):
        """初始化文件系统"""
        self.paths = {}  # 存储路径到值的映射
    
    def createPath(self, path: str, value: int) -> bool:
        """
        创建新路径
        
        时间复杂度：O(n)，n 是路径长度
        空间复杂度：O(1)
        """
        # 路径已存在
        if path in self.paths:
            return False
        
        # 根路径特殊处理
        if path == "/":
            return False
        
        # 查找父路径
        parent_path = path.rsplit('/', 1)[0]
        
        # 父路径为空字符串表示这是一级路径（如 "/a"）
        if parent_path == "":
            self.paths[path] = value
            return True
        
        # 检查父路径是否存在
        if parent_path not in self.paths:
            return False
        
        # 创建路径
        self.paths[path] = value
        return True
    
    def get(self, path: str) -> int:
        """
        获取路径对应的值
        
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        return self.paths.get(path, -1)
```

### 方法二：字典树（Trie）

```python
class TrieNode:
    def __init__(self):
        self.children = {}  # 子节点
        self.value = -1  # 路径对应的值，-1 表示不存在

class FileSystem:
    def __init__(self):
        """初始化 Trie 根节点"""
        self.root = TrieNode()
    
    def createPath(self, path: str, value: int) -> bool:
        """
        使用 Trie 创建路径
        
        时间复杂度：O(n)，n 是路径长度
        空间复杂度：O(n)
        """
        # 分割路径
        parts = path.split('/')[1:]  # 跳过第一个空字符串
        
        # 遍历到父节点
        node = self.root
        for i in range(len(parts) - 1):
            part = parts[i]
            if part not in node.children:
                return False  # 父路径不存在
            node = node.children[part]
        
        # 检查最后一个节点
        last_part = parts[-1]
        if last_part in node.children:
            return False  # 路径已存在
        
        # 创建新节点
        new_node = TrieNode()
        new_node.value = value
        node.children[last_part] = new_node
        return True
    
    def get(self, path: str) -> int:
        """
        获取路径对应的值
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        parts = path.split('/')[1:]
        node = self.root
        
        for part in parts:
            if part not in node.children:
                return -1
            node = node.children[part]
        
        return node.value
```

### 方法三：简化版哈希表

```python
class FileSystem:
    def __init__(self):
        self.paths = {}
    
    def createPath(self, path: str, value: int) -> bool:
        """简化代码，逻辑更清晰"""
        if path in self.paths or path == "/":
            return False
        
        # 找到最后一个 /
        last_slash = path.rfind('/')
        parent = path[:last_slash] if last_slash > 0 else ""
        
        # 一级路径（parent为空）或父路径存在
        if parent == "" or parent in self.paths:
            self.paths[path] = value
            return True
        
        return False
    
    def get(self, path: str) -> int:
        return self.paths.get(path, -1)
```

## 复杂度分析

**方法一（哈希表）：**
- createPath：
  - 时间复杂度：`O(n)`，n 是路径长度，需要查找最后一个 '/'
  - 空间复杂度：`O(1)`
- get：
  - 时间复杂度：`O(1)`，哈希表查询
  - 空间复杂度：`O(1)`

**方法二（Trie）：**
- createPath：
  - 时间复杂度：`O(n + d)`，n 是路径长度，d 是路径深度
  - 空间复杂度：`O(d)`，需要创建新节点
- get：
  - 时间复杂度：`O(d)`，d 是路径深度
  - 空间复杂度：`O(1)`

方法一更简洁高效，适合本题；方法二更符合文件系统结构，扩展性更好。

## 关键点总结

1. **父路径验证**：创建路径前必须验证父路径是否存在

2. **路径解析**：使用 `rsplit('/', 1)` 或 `rfind('/')` 查找父路径

3. **一级路径处理**：如 "/a"，其父路径是空字符串，需要特殊处理

4. **重复路径检查**：创建前检查路径是否已存在

5. **数据结构选择**：哈希表简单高效，Trie 更符合实际文件系统结构

## 易错点

1. **忘记检查父路径**：
   ```python
   # 错误：直接创建路径
   self.paths[path] = value
   
   # 正确：先检查父路径是否存在
   if parent in self.paths:
       self.paths[path] = value
   ```

2. **一级路径判断错误**：
   ```python
   # 错误：把一级路径当作无效路径
   if not parent:
       return False
   
   # 正确：一级路径的父路径是空字符串，应该允许
   if parent == "" or parent in self.paths:
   ```

3. **路径分割错误**：
   ```python
   # 错误：split 会产生空字符串
   parts = path.split('/')  # ['', 'a', 'b']
   
   # 正确：跳过第一个空字符串
   parts = path.split('/')[1:]  # ['a', 'b']
   ```

4. **根路径处理**：题目中 "/" 不是有效路径，要特殊处理

5. **返回值错误**：get 方法找不到路径时应返回 -1，不是 None
