## 题目描述

给定一个包含非负整数的数组 `nums`，返回其中可以组成三角形三条边的三元组个数。

**示例 1：**

```
输入：nums = [2,2,3,4]
输出：3
解释：有效的组合是：
2,3,4 (使用第一个 2)
2,3,4 (使用第二个 2)
2,2,3
```

**示例 2：**

```
输入：nums = [4,2,3,4]
输出：4
```

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

## 解题思路

三角形成立条件：三边 a、b、c（a ≤ b ≤ c）满足 `a + b > c`。

**核心思路：排序 + 双指针**

1. **排序**：将数组排序后，假设 `nums[i] ≤ nums[j] ≤ nums[k]`
2. **简化条件**：只需判断 `nums[i] + nums[j] > nums[k]`
3. **双指针**：固定最大边 k，用双指针找满足条件的 i, j

## Python 代码实现

### 方法一：排序 + 双指针（推荐）⭐

```python
from typing import List

class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        """
        排序 + 双指针
        
        时间复杂度：O(n^2)
        空间复杂度：O(1)
        """
        nums.sort()
        count = 0
        n = len(nums)
        
        # 固定最大边（从后往前）
        for k in range(n - 1, 1, -1):
            left, right = 0, k - 1
            
            # 双指针找两条较小的边
            while left < right:
                if nums[left] + nums[right] > nums[k]:
                    # [left, right-1] 都可以与 right, k 组成三角形
                    count += right - left
                    right -= 1
                else:
                    # 和太小，移动左指针
                    left += 1
        
        return count
```

### 方法二：二分查找

```python
class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        """
        排序 + 二分查找
        
        时间复杂度：O(n^2 log n)
        空间复杂度：O(1)
        """
        import bisect
        
        nums.sort()
        count = 0
        n = len(nums)
        
        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                # 找到最大的 k 使得 nums[i] + nums[j] > nums[k]
                target = nums[i] + nums[j]
                k = bisect.bisect_left(nums, target, j + 1)
                count += k - j - 1
        
        return count
```

### 方法三：暴力枚举（超时）

```python
class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        """
        三重循环暴力枚举
        
        时间复杂度：O(n^3)
        空间复杂度：O(1)
        """
        count = 0
        n = len(nums)
        
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    a, b, c = sorted([nums[i], nums[j], nums[k]])
                    if a + b > c:
                        count += 1
        
        return count
```

## 复杂度分析

### 方法一（双指针）
- **时间复杂度**：O(n²)，外层循环 O(n)，双指针 O(n)
- **空间复杂度**：O(1)，忽略排序空间

### 方法二（二分查找）
- **时间复杂度**：O(n² log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序优化**：排序后只需判断最小两边之和
2. **双指针技巧**：固定最大边，双指针找两小边
3. **计数技巧**：当 `nums[left] + nums[right] > nums[k]` 时，`[left, right-1]` 都满足
4. **去除无效值**：数组中的 0 不影响结果（0 不能组成三角形）
