## 题目描述

给你一个 `n x n` 矩阵 `matrix`，其中每行和每列元素均按升序排序，找到矩阵中第 `k` 小的元素。

请注意，它是排序后的第 `k` 小元素，而不是第 `k` 个不同的元素。

你必须找到一种内存复杂度优于 `O(n^2)` 的解决方案。

**示例 1：**

```
输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
输出：13
解释：矩阵中的元素为 [1,5,9,10,11,12,13,13,15]，第 8 小元素是 13
```

**示例 2：**

```
输入：matrix = [[-5]], k = 1
输出：-5
```

**提示：**
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 题目数据保证 `matrix` 中的所有行和列都按非递减顺序排列
- `1 <= k <= n^2`

**进阶：**
- 你能否用一个恒定的内存（即 `O(1)` 内存复杂度）来解决这个问题？
- 你能在 `O(n)` 的时间复杂度下解决这个问题吗？这个方法对于面试来说可能太超前了，但是你会发现阅读这篇文章很有趣。

## 解题思路

这道题有多种解法，从简单到高级：

### 方法一：最小堆（推荐，易理解）

利用矩阵每行有序的特性：
1. 将每行的第一个元素加入最小堆
2. 弹出 k-1 次最小元素
3. 每次弹出后，将该元素所在行的下一个元素加入堆
4. 第 k 次弹出的就是答案

### 方法二：二分查找（最优，O(1) 空间）

二分搜索值域：
1. 左边界：`matrix[0][0]`（最小值）
2. 右边界：`matrix[n-1][n-1]`（最大值）
3. 对于中间值 `mid`，统计矩阵中 `<= mid` 的元素个数
4. 根据个数调整搜索范围

### 方法三：暴力排序（不推荐）

将所有元素展平并排序，返回第 k 个。空间 O(n^2)，不符合要求。

## Python 代码实现

### 方法一：最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        """
        最小堆方法
        时间复杂度：O(k log n)
        空间复杂度：O(n)
        """
        n = len(matrix)
        # 最小堆：(值, 行索引, 列索引)
        min_heap = [(matrix[i][0], i, 0) for i in range(n)]
        heapq.heapify(min_heap)
        
        # 弹出 k-1 次
        for _ in range(k - 1):
            val, row, col = heapq.heappop(min_heap)
            
            # 将同一行的下一个元素加入堆
            if col + 1 < n:
                heapq.heappush(min_heap, (matrix[row][col + 1], row, col + 1))
        
        # 第 k 次弹出的是答案
        return heapq.heappop(min_heap)[0]
```

### 方法二：二分查找（最优，O(1) 空间）

```python
from typing import List

class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        """
        二分查找值域
        时间复杂度：O(n log(max - min))
        空间复杂度：O(1)
        """
        n = len(matrix)
        left, right = matrix[0][0], matrix[n - 1][n - 1]
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 统计 <= mid 的元素个数
            count = self.countLessEqual(matrix, mid)
            
            if count < k:
                # 第 k 小的元素在右半部分
                left = mid + 1
            else:
                # 第 k 小的元素 <= mid
                right = mid
        
        return left
    
    def countLessEqual(self, matrix: List[List[int]], target: int) -> int:
        """
        统计矩阵中 <= target 的元素个数
        利用每行每列都有序的特性
        """
        n = len(matrix)
        count = 0
        row, col = n - 1, 0  # 从左下角开始
        
        while row >= 0 and col < n:
            if matrix[row][col] <= target:
                # 当前列的前 row+1 个元素都 <= target
                count += row + 1
                col += 1
            else:
                # 当前元素太大，向上移动
                row -= 1
        
        return count
```

### 方法三：暴力排序（不推荐）

```python
from typing import List

class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        """
        暴力：展平并排序
        时间复杂度：O(n^2 log(n^2))
        空间复杂度：O(n^2)，不符合要求
        """
        # 展平矩阵
        flat = []
        for row in matrix:
            flat.extend(row)
        
        # 排序
        flat.sort()
        
        # 返回第 k 小的元素
        return flat[k - 1]
```

### 方法四：优化的堆（只初始化第一列）

```python
from typing import List
import heapq

class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        """
        优化：只初始化第一列，减少堆的初始大小
        """
        n = len(matrix)
        min_heap = [(matrix[i][0], i, 0) for i in range(min(k, n))]
        heapq.heapify(min_heap)
        
        result = 0
        for _ in range(k):
            result, row, col = heapq.heappop(min_heap)
            
            if col + 1 < n:
                heapq.heappush(min_heap, (matrix[row][col + 1], row, col + 1))
        
        return result
```

## 复杂度分析

### 方法一：最小堆
- 时间复杂度：O(k log n)
  - 初始化堆：O(n)
  - k 次堆操作：O(k log n)
- 空间复杂度：O(n)

### 方法二：二分查找
- 时间复杂度：O(n × log(max - min))
  - 二分：O(log(max - min))
  - 每次统计：O(n)
- 空间复杂度：O(1)

### 方法三：暴力排序
- 时间复杂度：O(n^2 log n)
- 空间复杂度：O(n^2)

## 关键点总结

1. **堆的使用**：利用每行有序的特性，只需维护 n 个元素的堆
2. **二分查找值域**：在值的范围内二分，而不是在索引范围内
3. **统计技巧**：从左下角或右上角开始统计 `<= mid` 的元素
4. **空间优化**：方法二达到 O(1) 空间
5. **有序性利用**：充分利用行和列都有序的性质

## 易错点

1. **统计方向**：从左下角开始，向右或向上移动
2. **二分边界**：`left < right` 而不是 `left <= right`
3. **返回值**：二分查找返回 `left`，不是 `mid`
4. **堆初始化**：只需要初始化每行的第一个元素
5. **重复元素**：矩阵中可能有重复元素，要正确处理

## 图解示例

### 示例：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8

**方法一：最小堆**

```
初始堆：[(1,0,0), (10,1,0), (12,2,0)]

第 1 次弹出：1，加入 (5,0,1)
堆：[(5,0,1), (10,1,0), (12,2,0)]

第 2 次弹出：5，加入 (9,0,2)
堆：[(9,0,2), (10,1,0), (12,2,0)]

...

第 8 次弹出：13
```

**方法二：二分查找**

```
left = 1, right = 15

mid = 8:
  <= 8 的元素：1, 5 (2 个) < 8，left = 9

mid = 12:
  <= 12 的元素：1, 5, 9, 10, 11, 12 (6 个) < 8，left = 13

mid = 13:
  <= 13 的元素：1, 5, 9, 10, 11, 12, 13, 13 (8 个) >= 8，right = 13

left == right = 13，返回 13
```
