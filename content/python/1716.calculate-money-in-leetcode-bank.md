## 题目描述

Hercy 想要为购买第一辆车存钱。他每天都往力扣银行里存钱。

最开始，第 `1` 天，他在银行账户里存入 `1` 块钱。从第 `2` 天起，他每天都比前一天多存入 `1` 块钱。

每过一个星期一，他都会比上周同一天多存 `1` 块钱。

给你 `n`，请你返回在第 `n` 天结束的时候他在银行总共存了多少块钱。

**示例 1：**
```
输入：n = 4
输出：10
第1天存1，第2天存2，第3天存3，第4天存4，总共 1+2+3+4=10
```

**示例 2：**
```
输入：n = 10
输出：37
第1周：1+2+3+4+5+6+7=28
第2周：2+3+4+5+6+7+8=35，共存 35-28+28=... 直接算：28+9=37
```

**提示：**
- `1 <= n <= 1000`

## 解题思路

每周的规律：
- 第 `k` 周的第 `d` 天（d = 1..7），存 `k + d - 1` 块钱
- 第 `k` 周：存钱 `k + k+1 + k+2 + ... + k+6` = `7k + 21`

整数周 `w = n // 7`，剩余天数 `r = n % 7`：
- 整数周总计：sum_{k=1}^{w} (7k + 21) = 7 * w*(w+1)/2 + 21*w
- 最后不完整周第 `w+1` 周的前 `r` 天：sum_{d=1}^{r} (w+1 + d - 1) = r*(w+1) + r*(r-1)/2

## 代码实现

### 方法一：数学公式直接计算（推荐）

```python
class Solution:
    def totalMoney(self, n: int) -> int:
        weeks = n // 7   # 完整的周数
        days = n % 7     # 剩余不完整周的天数
        
        # 完整 weeks 周的总金额
        # 第 k 周（k=1..weeks）的总金额 = 7k + 21
        # 总和 = sum(7k+21, k=1..weeks) = 7*weeks*(weeks+1)//2 + 21*weeks
        full_weeks_total = 7 * weeks * (weeks + 1) // 2 + 21 * weeks
        
        # 不完整周（第 weeks+1 周）前 days 天的总金额
        # 第 weeks+1 周第 d 天存：weeks + d 块（d=1..days）
        # 总和 = weeks*days + (1+2+...+days) = weeks*days + days*(days+1)//2
        partial_total = weeks * days + days * (days + 1) // 2
        
        return full_weeks_total + partial_total
```

### 方法二：逐天模拟（清晰直观）

```python
class Solution:
    def totalMoney(self, n: int) -> int:
        total = 0
        week_base = 1  # 本周一的存款基数
        
        for day in range(1, n + 1):
            # 计算今天是本周第几天（1-7）
            day_of_week = (day - 1) % 7 + 1
            
            # 周一开始新的一周，更新基数
            if day_of_week == 1 and day > 1:
                week_base += 1
            
            # 今天存入：本周基数 + 本周第几天 - 1
            today = week_base + day_of_week - 1
            total += today
        
        return total
```

## 复杂度分析

- **方法一**：O(1)，纯数学计算
- **方法二**：O(n)，逐天模拟

## 关键点总结

1. 规律清晰：每周第一天比上周第一天多 1
2. 用数学公式可以 O(1) 求解
3. 模拟方法也很直观，便于验证正确性

## 易错点

- 第 `k` 周第 `d` 天存 `k + d - 1`，注意 d 从 1 开始
- 数学公式中注意整除
