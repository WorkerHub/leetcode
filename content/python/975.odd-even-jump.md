## 题目描述

给定一个整数数组 `arr`，你从某个索引开始，可以进行奇数次跳跃和偶数次跳跃。

从索引 `i` 向右跳跃时：
- **奇数次跳跃**：跳到索引 `j`，使得 `arr[i] <= arr[j]` 且 `arr[j]` 是所有满足条件的值中最小的。如果有多个这样的索引，跳到最小的索引 `j`。
- **偶数次跳跃**：跳到索引 `j`，使得 `arr[i] >= arr[j]` 且 `arr[j]` 是所有满足条件的值中最大的。如果有多个这样的索引，跳到最小的索引 `j`。

如果从某个索引开始跳跃，最终能够跳到数组的最后一个索引（最后一跳可以是奇数跳或偶数跳），则认为从该索引可以到达终点。

返回可以到达数组最后一个索引的起始索引的数量。

**示例 1：**
```
输入：arr = [10,13,12,14,15]
输出：2
解释：
从起始索引 i = 0 出发，我们可以跳到 i = 2（因为 arr[2] 是大于等于 arr[0] 的最小值），
然后无法再跳了。
从起始索引 i = 1 和 i = 2 出发，我们可以跳到 i = 3，然后我们可以跳到 i = 4，这是最后一个索引。
从起始索引 i = 3 出发，我们可以跳到 i = 4。
从起始索引 i = 4 出发，我们已经在最后一个索引。
总共有 2 个索引（i = 3 和 i = 4）可以到达最后一个索引。
```

**示例 2：**
```
输入：arr = [2,3,1,1,4]
输出：3
解释：
从起始索引 i = 0 出发，我们进行如下跳跃：
- 奇数跳：i = 0 -> 2
- 偶数跳：i = 2 -> 3
- 奇数跳：i = 3 -> 4
从起始索引 i = 1 出发，我们进行如下跳跃：
- 奇数跳：i = 1 -> 4
从起始索引 i = 2, i = 3 和 i = 4 出发都可以到达最后一个索引。
```

**提示：**
- `1 <= arr.length <= 2 * 10^4`
- `0 <= arr[i] < 10^5`

## 解题思路

这是一道结合了动态规划和单调栈的困难题。核心思路如下：

1. **动态规划状态定义**：
   - `odd[i]`：从索引 `i` 开始，第一跳是奇数跳，能否到达终点
   - `even[i]`：从索引 `i` 开始，第一跳是偶数跳，能否到达终点

2. **状态转移**：
   - 如果从 `i` 进行奇数跳到达 `j`，则 `odd[i] = even[j]`（因为下一跳是偶数跳）
   - 如果从 `i` 进行偶数跳到达 `j`，则 `even[i] = odd[j]`（因为下一跳是奇数跳）

3. **关键难点**：如何快速找到每个位置的下一个奇数跳和偶数跳位置？
   - 使用单调栈：对索引按值排序后，使用单调栈找到下一个跳跃位置
   - 奇数跳：按值升序排序（值相同时按索引升序），找到每个位置右侧最近的更大值
   - 偶数跳：按值降序排序（值相同时按索引升序），找到每个位置右侧最近的更小值

4. **从后向前遍历**：
   - 最后一个位置显然可以到达（`odd[n-1] = even[n-1] = True`）
   - 从后向前计算每个位置的状态

## Python 代码实现

### 方法一：动态规划 + 单调栈（推荐）

```python
from typing import List

class Solution:
    def oddEvenJumps(self, arr: List[int]) -> int:
        n = len(arr)
        
        # 找到每个位置的下一个奇数跳和偶数跳的位置
        next_odd = self.makeGraph(arr, True)  # 奇数跳：找 >= arr[i] 的最小值
        next_even = self.makeGraph(arr, False)  # 偶数跳：找 <= arr[i] 的最大值
        
        # dp 数组
        odd = [False] * n
        even = [False] * n
        
        # 最后一个位置作为基础情况
        odd[n - 1] = even[n - 1] = True
        
        # 从后向前遍历
        for i in range(n - 2, -1, -1):
            # 如果可以进行奇数跳，检查跳到的位置能否通过偶数跳到达终点
            if next_odd[i] != -1:
                odd[i] = even[next_odd[i]]
            # 如果可以进行偶数跳，检查跳到的位置能否通过奇数跳到达终点
            if next_even[i] != -1:
                even[i] = odd[next_even[i]]
        
        # 统计从哪些位置开始（第一跳是奇数跳）可以到达终点
        return sum(odd)
    
    def makeGraph(self, arr: List[int], is_odd: bool) -> List[int]:
        """
        使用单调栈构建跳跃图
        is_odd = True: 找每个位置右侧大于等于当前值的最小值
        is_odd = False: 找每个位置右侧小于等于当前值的最大值
        """
        n = len(arr)
        result = [-1] * n
        
        # 创建索引数组并排序
        indices = list(range(n))
        if is_odd:
            # 奇数跳：按值升序，值相同时按索引升序
            indices.sort(key=lambda i: (arr[i], i))
        else:
            # 偶数跳：按值降序，值相同时按索引升序
            indices.sort(key=lambda i: (-arr[i], i))
        
        # 使用单调栈找到下一个跳跃位置
        stack = []
        for i in indices:
            # 当前索引 i 可以作为栈中索引的下一跳目标
            while stack and stack[-1] < i:
                result[stack.pop()] = i
            stack.append(i)
        
        return result
```

### 方法二：使用 TreeMap（有序字典）

```python
from typing import List
from sortedcontainers import SortedDict

class Solution:
    def oddEvenJumps(self, arr: List[int]) -> int:
        n = len(arr)
        odd = [False] * n
        even = [False] * n
        odd[n - 1] = even[n - 1] = True
        
        # 从后向前遍历，维护有序映射
        sorted_map = SortedDict({arr[n - 1]: n - 1})
        
        for i in range(n - 2, -1, -1):
            val = arr[i]
            
            # 奇数跳：找 >= val 的最小值
            idx = sorted_map.bisect_left(val)
            if idx < len(sorted_map):
                key = sorted_map.keys()[idx]
                odd[i] = even[sorted_map[key]]
            
            # 偶数跳：找 <= val 的最大值
            idx = sorted_map.bisect_right(val)
            if idx > 0:
                key = sorted_map.keys()[idx - 1]
                even[i] = odd[sorted_map[key]]
            
            # 更新映射（相同值保留索引较小的）
            sorted_map[val] = i
        
        return sum(odd)
```

## 复杂度分析

**方法一：单调栈**
- 时间复杂度：O(n log n)，排序的时间复杂度
- 空间复杂度：O(n)，存储 dp 数组和辅助数组

**方法二：有序字典**
- 时间复杂度：O(n log n)，每次插入和查找都是 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. **状态转移的理解**：奇数跳之后必定是偶数跳，反之亦然
2. **单调栈的应用**：通过排序+单调栈快速找到下一个跳跃位置
3. **从后向前遍历**：因为每个位置的状态依赖于后面位置的状态
4. **边界条件**：最后一个位置永远可以到达

## 易错点

1. **跳跃规则混淆**：注意奇数跳找最小的更大值，偶数跳找最大的更小值
2. **索引处理**：相同值时要选择索引最小的
3. **排序策略**：奇数跳和偶数跳的排序方式不同
4. **初始状态**：记得统计的是 `odd` 数组的和（第一跳是奇数跳）
