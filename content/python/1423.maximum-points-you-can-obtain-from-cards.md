## 题目描述

几张牌 **排成一行**，每张牌都有一个对应的点数。点数由整数数组 `cardPoints` 给出。

每次行动，你可以从行的开头或者末尾拿一张牌，最终你必须恰好拿 `k` 张牌。

你的点数就是你拿到手中的所有牌的点数之和。

给你一个整数数组 `cardPoints` 和整数 `k`，返回你可以获得的最大点数。

**示例 1：**

```
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
解释：第一次行动，不管从开头还是末尾拿，手上的牌点数 = 1，
     拿了 3 张后最大点数 = 1+6+5 = 12（从末尾拿3张）。
```

**示例 2：**

```
输入：cardPoints = [2,2,2], k = 2
输出：4
```

**示例 3：**

```
输入：cardPoints = [9,7,7,9,7,7,9], k = 7
输出：55
解释：必须拿所有牌。
```

**提示：**

- `1 <= cardPoints.length <= 10^5`
- `1 <= cardPoints[i] <= 10^4`
- `1 <= k <= cardPoints.length`

## 解题思路

### 逆向思维：求中间最小子数组和

从两端取 `k` 张牌，等价于**留下中间连续的 `n-k` 张牌**。

总和固定为 `sum(cardPoints)`，减去中间留下的那部分，剩余即为取到的点数。

因此，目标转化为：**求长度为 `n-k` 的连续子数组的最小和**，然后用总和减去它。

使用滑动窗口维护长度为 `n-k` 的窗口的最小和。

### 特殊情况

若 `k == n`，取所有牌，直接返回总和。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)
        total = sum(cardPoints)

        # 取所有牌
        if k == n:
            return total

        window_size = n - k  # 中间留下的牌的数量

        # 计算初始窗口（前 window_size 张牌）的和
        window_sum = sum(cardPoints[:window_size])
        min_window = window_sum

        # 滑动窗口：向右移动，每次加入右边一张，移出左边一张
        for i in range(window_size, n):
            window_sum += cardPoints[i]
            window_sum -= cardPoints[i - window_size]
            min_window = min(min_window, window_sum)

        return total - min_window
```

### 方法二：前缀和（等价思路）

```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)
        total = sum(cardPoints)

        # 取所有牌
        if k == n:
            return total

        window_size = n - k

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + cardPoints[i]

        # 长度为 window_size 的子数组最小和
        min_sum = float('inf')
        for i in range(window_size, n + 1):
            sub_sum = prefix[i] - prefix[i - window_size]
            min_sum = min(min_sum, sub_sum)

        return total - min_sum
```

### 方法三：正向枚举（直接枚举从两端取的方案）

```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)

        # 枚举从左端取 i 张，从右端取 k-i 张（i 从 0 到 k）
        # 前缀和方便计算
        prefix = [0] * (k + 1)  # prefix[i] = 前 i 张牌的点数和
        for i in range(k):
            prefix[i + 1] = prefix[i] + cardPoints[i]

        suffix = [0] * (k + 1)  # suffix[i] = 后 i 张牌的点数和
        for i in range(k):
            suffix[i + 1] = suffix[i] + cardPoints[n - 1 - i]

        max_score = 0
        for i in range(k + 1):
            # 从左取 i 张，从右取 k-i 张
            score = prefix[i] + suffix[k - i]
            max_score = max(max_score, score)

        return max_score
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 前缀和 | O(n) | O(n) |
| 枚举两端 | O(k) | O(k) |

方法三的时间复杂度最优（O(k)），因为只需要计算两端各 k 个元素的前缀/后缀和。

## 图解示例

以 `cardPoints = [1,2,3,4,5,6,1], k = 3` 为例（方法一）：

```
n = 7, total = 22, window_size = 7-3 = 4

初始窗口 [1,2,3,4]，window_sum = 10

i=4: 加入5，移出1，window_sum = 10+5-1 = 14
i=5: 加入6，移出2，window_sum = 14+6-2 = 18
i=6: 加入1，移出3，window_sum = 18+1-3 = 16

最小窗口和 = 10（初始窗口）
答案 = 22 - 10 = 12 ✓
```

## 关键点总结

1. 核心转化：从两端取 k 张 = 中间留 n-k 张，最大化取得的牌 = 最小化留下的牌
2. 滑动窗口维护固定长度子数组的最小和
3. 方法三更直接，枚举"从左取 i 张，从右取 k-i 张"的所有组合

## 易错点

1. 当 `k == n` 时，窗口大小为 0，特殊处理（或者统一处理也可，因为空窗口和为0）
2. 滑动窗口初始计算前 `window_size` 个元素的和，然后从索引 `window_size` 开始滑动
3. 方法三中 `prefix[i]` 是前 `i` 张，`suffix[k-i]` 是后 `k-i` 张，注意下标
