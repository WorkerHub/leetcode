## 题目描述

给你一个下标从 0 开始的二进制字符串 `floor`，表示地板上的瓷砖（`'1'` 表示白色，`'0'` 表示黑色）。同时给你 `numCarpets` 和 `carpetLen`，分别表示可铺的地毯数量和每块地毯的长度（每块相同）。

地毯可以铺在任何位置，可以互相重叠，每次覆盖一段连续的地板。

返回铺完所有地毯后，**最少**剩余可见白色瓷砖数量。

**示例 1：**
```
输入：floor = "10110101", numCarpets = 2, carpetLen = 2
输出：2
```

**示例 2：**
```
输入：floor = "11111", numCarpets = 2, carpetLen = 3
输出：0
```

**提示：**
- `1 <= carpetLen <= floor.length <= 1000`
- `floor[i]` 是 `'0'` 或 `'1'`
- `1 <= numCarpets <= 10^9`

## 解题思路

**动态规划 + 前缀和。**

设 `dp[i][j]` 为用 `j` 块地毯覆盖前 `i` 块瓷砖，剩余白色瓷砖的最少数量。

**转移方程：**
- 不覆盖第 `i` 块：`dp[i][j] = dp[i-1][j] + floor[i-1]=='1'`
- 用一块地毯覆盖以第 `i` 块结尾的 `carpetLen` 长度：`dp[i][j] = dp[max(0, i-carpetLen)][j-1]`

取两者最小值。

**前缀和**：`pre[i]` 表示前 `i` 块瓷砖中白色瓷砖的数量，用于快速计算区间白色数。

注意：`numCarpets` 可以很大，但最多铺 `n / carpetLen` 块有效，因此 `j` 上限取 `min(numCarpets, n // carpetLen + 1)`。

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def minimumWhiteTiles(self, floor: str, numCarpets: int, carpetLen: int) -> int:
        n = len(floor)

        # 前缀和：pre[i] 表示前 i 个字符中 '1' 的数量
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + (1 if floor[i] == '1' else 0)

        # 地毯超过 n 块时等效于全覆盖
        numCarpets = min(numCarpets, (n + carpetLen - 1) // carpetLen)

        # dp[i][j]：用 j 块地毯覆盖前 i 格，最少剩余白色数
        # 为节省空间，用滚动数组
        # dp[i] = 前 i 格用 j 块地毯的最少白色数
        INF = float('inf')
        prev = [pre[i] for i in range(n + 1)]  # j=0 时无地毯覆盖

        for j in range(1, numCarpets + 1):
            curr = [0] * (n + 1)
            for i in range(n + 1):
                # 不使用第 j 块地毯覆盖第 i 格
                option1 = prev[i] if j - 1 >= 0 else INF
                # 这里 option1 应从 curr[i-1] 得到（不覆盖当前格）
                # 实际需要从前一格的当前层转移
                curr[i] = prev[i]  # 用 j 块地毯，不覆盖到第 i 格结尾的收益
            # 重新正确推导
            curr[0] = 0
            for i in range(1, n + 1):
                # 选择1：不用地毯覆盖第 i 格（此格露出）
                opt1 = curr[i - 1] + (1 if floor[i - 1] == '1' else 0)
                # 选择2：用一块地毯覆盖 [i-carpetLen, i-1]
                opt2 = prev[max(0, i - carpetLen)]
                curr[i] = min(opt1, opt2)
            prev = curr

        return prev[n]
```

### 方法二：记忆化搜索

```python
from functools import lru_cache

class Solution:
    def minimumWhiteTiles(self, floor: str, numCarpets: int, carpetLen: int) -> int:
        n = len(floor)
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + int(floor[i])

        # 区间 [l, r] 内白色瓷砖数
        def whites(l, r):
            return pre[r + 1] - pre[l]

        @lru_cache(maxsize=None)
        def dp(i, j):
            """从位置 i 开始，用 j 块地毯，最少剩余白色数"""
            if i >= n:
                return 0
            if j == 0:
                return whites(i, n - 1)  # 无地毯，剩余全部白色
            # 不在位置 i 放地毯
            opt1 = int(floor[i]) + dp(i + 1, j)
            # 在位置 i 放地毯（覆盖 i 到 i+carpetLen-1）
            opt2 = dp(min(n, i + carpetLen), j - 1)
            return min(opt1, opt2)

        return dp(0, numCarpets)
```

## 复杂度分析

**方法一（DP）：**
- 时间复杂度：O(n * min(numCarpets, n/L))，L 为 carpetLen。
- 空间复杂度：O(n)，滚动数组。

**方法二（记忆化）：**
- 时间复杂度：O(n * numCarpets)（限制后）。
- 空间复杂度：O(n * numCarpets)，缓存空间。

## 关键点总结

1. `numCarpets` 很大时，超过 `ceil(n/carpetLen)` 块地毯等价于全覆盖，需截断。
2. DP 转移：对每格选择露出（白色加1）或用地毯覆盖。
3. 前缀和快速查询区间白色瓷砖数。

## 易错点

- `numCarpets` 可能极大，必须取 `min(numCarpets, ceil(n/carpetLen))` 避免 TLE。
- 地毯覆盖范围是 `[i-carpetLen, i-1]`（0-indexed 下标注意）。
