## 题目描述

给你一个整数数组 `nums`，返回满足以下条件的子数组数量：子数组中不同元素的个数等于整个数组中不同元素的个数。

**示例 1：**

```
输入：nums = [1,2,3,1,2]
输出：4
解释：整个数组有3种不同元素，子数组[1,2,3],[2,3,1],[3,1,2],[1,2,3,1,2]等都满足
```

**示例 2：**

```
输入：nums = [1,1,1]
输出：3
解释：整个数组只有1种元素，所有长度>=1的子数组均满足
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

目标：统计包含所有不同元素的子数组数量。

等价于：统计含恰好 `k` 种不同元素的子数组数（k = 整个数组不同元素数）。

**至多 k 种减至多 k-1 种**：含恰好 k 种 = 至多 k 种 - 至多 k-1 种。

但更直接的方法：滑动窗口找最短的包含所有元素的子数组，再利用前缀扩展。

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        total_distinct = len(set(nums))
        n = len(nums)
        count = 0
        freq = defaultdict(int)
        distinct = 0
        left = 0

        # 对每个右端点，找最小的left使子数组包含所有元素
        # min_left[right] = 最小的left使得nums[left..right]含所有元素
        # 那么有效左端点从0到min_left[right]

        min_left = [0] * n
        curr_left = 0
        freq = defaultdict(int)
        distinct = 0

        for right in range(n):
            freq[nums[right]] += 1
            if freq[nums[right]] == 1:
                distinct += 1
            while distinct == total_distinct:
                min_left[right] = curr_left
                freq[nums[curr_left]] -= 1
                if freq[nums[curr_left]] == 0:
                    distinct -= 1
                curr_left += 1

        # 修正：对每个right，valid左端点数量
        freq = defaultdict(int)
        distinct = 0
        left = 0
        ans = 0

        for right in range(n):
            freq[nums[right]] += 1
            if freq[nums[right]] == 1:
                distinct += 1
            while distinct == total_distinct and left <= right:
                ans += right - left + 1  # 不对，需要重新思考
                freq[nums[left]] -= 1
                if freq[nums[left]] == 0:
                    distinct -= 1
                left += 1

        return ans
```

### 方法二：正确滑动窗口

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        target = len(set(nums))
        n = len(nums)

        def at_most(k):
            freq = defaultdict(int)
            distinct = 0
            left = 0
            count = 0
            for right in range(n):
                freq[nums[right]] += 1
                if freq[nums[right]] == 1:
                    distinct += 1
                while distinct > k:
                    freq[nums[left]] -= 1
                    if freq[nums[left]] == 0:
                        distinct -= 1
                    left += 1
                count += right - left + 1
            return count

        return at_most(target) - at_most(target - 1)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 含恰好 k 种 = 至多 k 种 - 至多 k-1 种（标准技巧）
2. 至多 k 种的子数组数量用滑动窗口 O(n) 计算
3. k = 整个数组的不同元素数

## 易错点

1. `at_most(target) - at_most(target-1)` 是固定套路
2. 至多 k 种时，每次右端点右移，有效左端点到当前 left 的所有都合法
3. 注意 `count += right - left + 1` 统计的是以 right 结尾的合法子数组数
