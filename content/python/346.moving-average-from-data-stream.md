## 题目描述

给定一个整数数据流和一个窗口大小，根据该滑动窗口的大小，计算其所有整数的移动平均值。

实现 `MovingAverage` 类：

- `MovingAverage(int size)` 用窗口大小 `size` 初始化对象。
- `double next(int val)` 计算并返回数据流中最后 `size` 个值的移动平均值。

**示例：**
```
输入：
["MovingAverage", "next", "next", "next", "next"]
[[3], [1], [10], [3], [5]]
输出：
[null, 1.0, 5.5, 4.66667, 6.0]

解释：
MovingAverage movingAverage = new MovingAverage(3);
movingAverage.next(1);  // 返回 1.0 = 1 / 1
movingAverage.next(10); // 返回 5.5 = (1 + 10) / 2
movingAverage.next(3);  // 返回 4.66667 = (1 + 10 + 3) / 3
movingAverage.next(5);  // 返回 6.0 = (10 + 3 + 5) / 3
```

**提示：**
- `1 <= size <= 1000`
- `-10^5 <= val <= 10^5`
- 最多调用 `next` 方法 `10^4` 次

## 解题思路

这是一道设计题，核心是实现一个固定大小的滑动窗口。

**关键概念：**
- 滑动窗口：只保留最近的 `size` 个数据
- 移动平均：窗口内所有数的平均值

**实现方案：**

**方案1：队列实现**
- 使用队列（collections.deque）维护窗口
- 当队列满时，移除最旧的元素
- 维护窗口内元素的总和

**方案2：数组实现**
- 使用固定大小的数组和索引指针
- 循环使用数组空间
- 同样维护总和

## Python 代码实现

### 方法一：队列 + 总和（推荐）⭐

```python
from collections import deque

class MovingAverage:
    def __init__(self, size: int):
        """
        初始化固定大小的滑动窗口
        """
        self.size = size
        self.queue = deque()  # 存储窗口内的数据
        self.window_sum = 0   # 窗口内数据的总和
    
    def next(self, val: int) -> float:
        """
        添加新值并返回移动平均值
        """
        # 添加新值
        self.queue.append(val)
        self.window_sum += val
        
        # 如果窗口满了，移除最旧的值
        if len(self.queue) > self.size:
            removed = self.queue.popleft()
            self.window_sum -= removed
        
        # 返回平均值
        return self.window_sum / len(self.queue)
```

**时间复杂度：** O(1)，每次操作都是常数时间
**空间复杂度：** O(size)，存储窗口数据

### 方法二：循环数组（节省空间）

```python
class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.window = [0] * size  # 固定大小数组
        self.count = 0            # 当前窗口中的元素个数
        self.index = 0            # 当前插入位置
        self.window_sum = 0       # 窗口总和
    
    def next(self, val: int) -> float:
        # 如果窗口已满，减去将被替换的值
        if self.count == self.size:
            self.window_sum -= self.window[self.index]
        
        # 添加新值
        self.window[self.index] = val
        self.window_sum += val
        
        # 更新索引（循环）
        self.index = (self.index + 1) % self.size
        
        # 更新计数（最多为 size）
        if self.count < self.size:
            self.count += 1
        
        # 返回平均值
        return self.window_sum / self.count
```

**时间复杂度：** O(1)
**空间复杂度：** O(size)

### 方法三：简单列表（不推荐，效率低）

```python
class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.data = []
    
    def next(self, val: int) -> float:
        # 添加新值
        self.data.append(val)
        
        # 保持窗口大小
        if len(self.data) > self.size:
            self.data.pop(0)  # O(n) 操作！
        
        # 计算平均值
        return sum(self.data) / len(self.data)  # O(n) 操作！
```

**时间复杂度：** O(size)，每次都要计算总和
**空间复杂度：** O(size)

### 方法四：仅使用列表但维护总和

```python
class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.data = []
        self.window_sum = 0
    
    def next(self, val: int) -> float:
        self.data.append(val)
        self.window_sum += val
        
        # 如果超过窗口大小
        if len(self.data) > self.size:
            removed = self.data.pop(0)
            self.window_sum -= removed
        
        return self.window_sum / len(self.data)
```

**注意：** `list.pop(0)` 是 O(n) 操作，不如 deque 的 O(1)

## 复杂度分析

| 方法 | next() 时间 | 空间复杂度 | 优点 | 缺点 |
|------|------------|-----------|------|------|
| deque + sum | O(1) | O(size) | 简洁高效 | 需要导入 deque |
| 循环数组 | O(1) | O(size) | 不需导入 | 代码稍复杂 |
| 简单列表 | O(size) | O(size) | 代码简单 | 效率低 |
| 列表 + sum | O(size) | O(size) | 较简单 | pop(0) 慢 |

## 关键点总结

1. **数据结构选择**：deque 比 list 更适合频繁的头部删除
2. **维护总和**：避免每次重新计算，O(1) 更新
3. **循环数组**：通过取模实现循环使用空间
4. **计数器**：区分窗口未满和已满的情况
5. **边界处理**：窗口未满时使用实际元素个数

## 易错点

1. **每次重新计算总和**
   ```python
   # 错误：O(n) 的 sum 操作
   def next(self, val):
       self.queue.append(val)
       if len(self.queue) > self.size:
           self.queue.popleft()
       return sum(self.queue) / len(self.queue)
   
   # 正确：维护总和
   def next(self, val):
       self.window_sum += val
       self.queue.append(val)
       if len(self.queue) > self.size:
           self.window_sum -= self.queue.popleft()
       return self.window_sum / len(self.queue)
   ```

2. **使用 list.pop(0)**
   ```python
   # 不推荐：O(n) 操作
   if len(self.data) > self.size:
       self.data.pop(0)
   
   # 推荐：使用 deque
   if len(self.queue) > self.size:
       self.queue.popleft()  # O(1)
   ```

3. **循环数组索引错误**
   ```python
   # 错误：index 可能越界
   self.index += 1
   
   # 正确：使用取模
   self.index = (self.index + 1) % self.size
   ```

4. **count 计数错误**
   ```python
   # 错误：count 可能超过 size
   self.count += 1
   
   # 正确：限制最大值
   if self.count < self.size:
       self.count += 1
   ```

5. **平均值计算**
   ```python
   # 错误：使用 size 而不是实际元素数
   return self.window_sum / self.size
   
   # 正确：使用实际元素数
   return self.window_sum / len(self.queue)
   # 或
   return self.window_sum / self.count
   ```

```python
# 问题1：如何支持获取窗口中位数？
# 需要维护有序结构，可以用两个堆

# 问题2：如何支持加权移动平均？
# 每个元素乘以权重，维护加权总和

# 问题3：如何支持指数移动平均（EMA）？
# EMA = α * current + (1-α) * previous_EMA

class ExponentialMovingAverage:
    def __init__(self, alpha: float):
        self.alpha = alpha
        self.ema = None
    
    def next(self, val: float) -> float:
        if self.ema is None:
            self.ema = val
        else:
            self.ema = self.alpha * val + (1 - self.alpha) * self.ema
        return self.ema
```

```python
# deque vs list 性能测试

import time

dq = deque()

lst = []
start = time.time()

    lst.append(i)

# deque 会快得多！
```
