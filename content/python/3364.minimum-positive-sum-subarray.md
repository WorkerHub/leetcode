## 题目描述

给你一个整数数组 `nums` 和两个整数 `l` 和 `r`。

找出 `nums` 中长度在 `[l, r]` 之间，且元素和**最小的正数**（> 0）。

返回该最小正数和，若不存在返回 -1。

**示例：**
```
输入：nums = [3, -2, 1, 4], l = 2, r = 3
输出：1
解释：子数组 [3,-2] 和为 1（长度2），[−2,1] 和为 −1，[1,4] 和为 5，[3,−2,1] 和为 2，[−2,1,4] 和为 3
      最小正数和为 1
```

**提示：**
- `1 <= nums.length <= 100`
- `-1000 <= nums[i] <= 1000`
- `1 <= l <= r <= nums.length`

## 解题思路

数据范围小（n <= 100），直接暴力枚举所有长度在 `[l, r]` 之间的子数组，计算和，找最小正数。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        n = len(nums)
        min_positive = float('inf')
        
        for i in range(n):
            s = 0
            for j in range(i, n):
                s += nums[j]
                length = j - i + 1
                if l <= length <= r:
                    if s > 0:
                        min_positive = min(min_positive, s)
                elif length > r:
                    break
        
        return min_positive if min_positive != float('inf') else -1
```

### 方法二：前缀和枚举

```python
from typing import List

class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]
        
        min_positive = float('inf')
        for i in range(n):
            for length in range(l, r + 1):
                j = i + length
                if j > n:
                    break
                s = prefix[j] - prefix[i]
                if s > 0:
                    min_positive = min(min_positive, s)
        
        return min_positive if min_positive != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n * (r - l + 1))，枚举起始位置和长度
- 空间复杂度：O(1) 或 O(n)（前缀和）

## 关键点总结

1. 数据范围小，暴力枚举即可。
2. 只需找和 > 0 的最小值，边枚举边更新最小值。
3. 子数组长度在 `[l, r]` 范围内。

## 易错点

1. 子数组和严格 > 0（不包含 0）。
2. 长度超过 r 时提前 break，优化常数。
3. 若无满足条件的子数组，返回 -1。
