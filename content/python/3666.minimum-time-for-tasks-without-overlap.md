## 题目描述

给你一组任务 `tasks[i] = [start_i, end_i, duration_i]`，任务 i 必须在时间区间 `[start_i, end_i]` 内完成，需要 `duration_i` 个连续的时间单位，且任意两个任务不能同时进行。

返回完成所有任务的最短时间，若不可能则返回 -1。

**示例 1：**

```
输入：tasks = [[1,4,2],[2,5,3]]
输出：-1
解释：区间重叠且时间不够
```

**示例 2：**

```
输入：tasks = [[1,3,2],[4,6,2]]
输出：4
解释：任务1在[1,2]，任务2在[4,5]，总时间4
```

**提示：**

- `1 <= tasks.length <= 10^4`
- `tasks[i].length == 3`

## 解题思路

将任务按截止时间排序，用贪心安排。等价于区间调度 + 最短时间计算。

对不重叠的任务，按截止时间排序后，每个任务在尽量晚的时间安排（不超过截止时间）。

DP：`dp[i]` = 完成前 i 个任务的最小时间。

## Python 代码实现

### 方法一：贪心 + 排序（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, tasks: List[List[int]]) -> int:
        tasks.sort(key=lambda t: t[1])  # 按截止时间排序
        current_time = 0
        total = 0

        for start, end, duration in tasks:
            # 任务的可用时间窗口
            available = end - max(start, current_time) + 1
            if available < duration:
                return -1
            # 尽量晚安排：在 [max(start, current_time), end] 中安排 duration 时间
            # 贪心：尽量靠近截止时间安排，实际上只统计总时间
            total += duration
            current_time = max(current_time, start) + duration

        return total
```

### 方法二：DP（更精确）

```python
from typing import List

class Solution:
    def minimumTime(self, tasks: List[List[int]]) -> int:
        tasks.sort(key=lambda t: t[1])
        n = len(tasks)

        # dp[i] = 完成前 i 个任务后的最晚完成时间（最优安排）
        # 贪心：按截止时间排序，每个任务尽量靠后安排
        end_time = 0

        for start, end, duration in tasks:
            # 从 end 往前，尽量填入 duration 的时间
            start_actual = max(start, end_time)
            if start_actual + duration > end + 1:
                return -1
            # 贪心靠后：在 [end+1-duration, end] 执行
            end_time = end + 1  # 实际结束时间

        # 总时间 = 所有任务 duration 之和
        return sum(t[2] for t in tasks)
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 按截止时间排序，确保最早截止的任务先安排
2. 检验每个任务是否有足够的时间窗口
3. 任务不重叠：顺序安排，总时间 = 各任务时长之和

## 易错点

1. 任务可能有时间窗口约束，需检查是否有足够时间
2. 任务不能重叠，但可以紧密相连
3. 总时间是固定的（duration 之和），关键是检查可行性
