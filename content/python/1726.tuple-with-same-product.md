## 题目描述

给你一个由**不同**正整数组成的数组 `nums`，请你返回满足 `a * b = c * d` 的元组 `(a, b, c, d)` 的数量，其中 `a`、`b`、`c` 和 `d` 都是 `nums` 中的元素，且 `a != b`，`a != c`，`a != d`，`b != c`，`b != d`，`c != d`（四个元素两两不同）。

**示例：**
```
输入：nums = [2,3,4,6]
输出：8
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`

## 解题思路

枚举所有数对 `(i, j)`（i < j），计算乘积，用哈希表统计每个乘积对应的数对数量。

若某乘积有 `k` 个数对，则从中选 2 个数对能组成 `C(k, 2)` 个不同的元组，每个元组有 8 种排列（`a, b` 可互换，`c, d` 可互换，两对可互换，共 2 * 2 * 2 = 8）。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def tupleSameProduct(self, nums: List[int]) -> int:
        n = len(nums)
        # 统计每个乘积对应的数对数量
        product_count = defaultdict(int)
        
        for i in range(n):
            for j in range(i + 1, n):
                product = nums[i] * nums[j]
                product_count[product] += 1
        
        ans = 0
        # 对每个乘积，从中选 2 个数对，每组有 8 种排列
        for cnt in product_count.values():
            # C(cnt, 2) = cnt * (cnt - 1) / 2，每个组合有 8 种排列
            ans += cnt * (cnt - 1) // 2 * 8
        
        return ans
```

### 方法二：边统计边计算（优化常数）

```python
from typing import List
from collections import defaultdict

class Solution:
    def tupleSameProduct(self, nums: List[int]) -> int:
        n = len(nums)
        product_count = defaultdict(int)
        ans = 0
        
        for i in range(n):
            for j in range(i + 1, n):
                p = nums[i] * nums[j]
                # 在加入之前，已有 product_count[p] 个数对与当前数对乘积相同
                # 每个配对贡献 8 个元组
                ans += product_count[p] * 8
                product_count[p] += 1
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n^2)，枚举所有数对
- **空间复杂度**：O(n^2)，哈希表大小

## 关键点总结

1. 枚举所有数对的乘积，统计频率
2. 每对相同乘积的数对组合有 8 种排列（两个数对各自可以互换，两对之间也可以互换）
3. `C(k, 2) * 8` 计算贡献

## 易错点

- 注意 8 的来源：(a,b,c,d)、(b,a,c,d)、(a,b,d,c)、(b,a,d,c)、(c,d,a,b)、(d,c,a,b)、(c,d,b,a)、(d,c,b,a) 共 8 种
- 数组元素两两不同，不需要考虑重复
