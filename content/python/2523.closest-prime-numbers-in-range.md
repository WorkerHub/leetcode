## 题目描述

给你两个正整数 `left` 和 `right`，找出在 `[left, right]` 范围内最接近（差值最小）的两个质数 `num1` 和 `num2`，其中 `num1 < num2`。

返回 `[num1, num2]`。如果有多对质数差值相同，返回 `num1` 最小的那对。如果 `[left, right]` 内质数数量不足 2，返回 `[-1, -1]`。

**示例 1：**

```
输入：left = 10, right = 19
输出：[11, 13]
解释：范围内质数为 11, 13, 17, 19。最近的两个质数相差 2。
```

**示例 2：**

```
输入：left = 4, right = 6
输出：[-1, -1]
解释：范围内只有一个质数 5。
```

**提示：**

- `1 <= left <= right <= 10^6`

## 解题思路

枚举 `[left, right]` 中的质数，收集到列表中，然后找相邻质数差值最小的一对。

判断质数：用埃拉托色尼筛法预计算到 10^6 的所有质数，O(1) 查询。

## Python 代码实现

### 方法一：线性筛 + 枚举（推荐）

```python
from typing import List

class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        # 埃氏筛预计算质数
        sieve = [True] * (right + 1)
        sieve[0] = sieve[1] = False
        for i in range(2, int(right**0.5) + 1):
            if sieve[i]:
                for j in range(i*i, right + 1, i):
                    sieve[j] = False

        # 收集范围内的质数
        primes = [p for p in range(left, right + 1) if sieve[p]]

        if len(primes) < 2:
            return [-1, -1]

        # 找相邻质数中差值最小的
        ans = [primes[0], primes[1]]
        min_diff = primes[1] - primes[0]
        for i in range(2, len(primes)):
            diff = primes[i] - primes[i-1]
            if diff < min_diff:
                min_diff = diff
                ans = [primes[i-1], primes[i]]

        return ans
```

### 方法二：逐个检验质数

```python
from typing import List
import math

class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        def is_prime(n: int) -> bool:
            if n < 2:
                return False
            if n == 2:
                return True
            if n % 2 == 0:
                return False
            for i in range(3, int(math.sqrt(n)) + 1, 2):
                if n % i == 0:
                    return False
            return True

        prev = -1
        ans = [-1, -1]
        min_diff = float('inf')

        for num in range(left, right + 1):
            if is_prime(num):
                if prev != -1 and num - prev < min_diff:
                    min_diff = num - prev
                    ans = [prev, num]
                prev = num

        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(right * log log right)，埃氏筛
- 方法二时间复杂度：O((right - left) * √right)，逐个检验
- 空间复杂度：O(right)（方法一）

## 关键点总结

1. 埃氏筛对大范围质数预计算效率高
2. 相邻质数的差值在大多数情况下很小（孪生质数差值为 2）
3. 若范围内质数不足 2，直接返回 [-1, -1]

## 易错点

1. 差值最小的一对是相邻质数对，不需要检查非相邻的
2. 若有多对差值相同，返回 num1 最小的（即第一对）
3. left = 1 时，1 不是质数，从 2 开始
