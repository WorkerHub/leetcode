## 题目描述

给你一个整数 `n`，请你计算并返回该整数**各位数字之积**与**各位数字之和**的差。

**示例 1：**

```
输入：n = 234
输出：15
解释：
各位数字之积 = 2 * 3 * 4 = 24
各位数字之和 = 2 + 3 + 4 = 9
结果 = 24 - 9 = 15
```

**示例 2：**

```
输入：n = 4421
输出：21
解释：
各位数字之积 = 4 * 4 * 2 * 1 = 32
各位数字之和 = 4 + 4 + 2 + 1 = 11
结果 = 32 - 11 = 21
```

**提示：**

- `1 <= n <= 10^5`

---

## 解题思路

这道题的核心是**提取整数的每一位数字**，然后分别计算积和和，最后相减。

提取数字有两种思路：
1. **数学方法**：反复对 10 取余得到末位，再除以 10 去掉末位，直到 n 变为 0。
2. **字符串方法**：将整数转为字符串，遍历每个字符，转回整数进行运算。

两种方法都很直接，但理解数学方法更有助于掌握"取位"的基本操作。

---

## Python 代码实现

### 方法一：数学取位法（推荐）

```python
class Solution:
    def subtractProductAndSum(self, n: int) -> int:
        product = 1  # 各位之积，初始值为 1（乘法单位元）
        total = 0    # 各位之和，初始值为 0（加法单位元）

        while n > 0:
            digit = n % 10   # 取出 n 的最后一位数字
            product *= digit  # 累乘
            total += digit    # 累加
            n //= 10          # 去掉最后一位

        return product - total
```

**执行过程（以 n=234 为例）：**

| 循环 | n   | digit | product | total |
|------|-----|-------|---------|-------|
| 第1轮 | 234 | 4     | 4       | 4     |
| 第2轮 | 23  | 3     | 12      | 7     |
| 第3轮 | 2   | 2     | 24      | 9     |
| 结束  | 0   | -     | 24      | 9     |

结果：24 - 9 = 15

### 方法二：字符串转换法（简洁）

```python
class Solution:
    def subtractProductAndSum(self, n: int) -> int:
        # 将整数转为字符串，再将每个字符转为整数
        digits = [int(ch) for ch in str(n)]

        product = 1
        for d in digits:
            product *= d  # 计算乘积

        total = sum(digits)  # 计算总和

        return product - total
```

### 方法三：Python 函数式写法（最简洁）

```python
from functools import reduce
from operator import mul

class Solution:
    def subtractProductAndSum(self, n: int) -> int:
        digits = [int(ch) for ch in str(n)]
        # reduce 配合 mul 计算连乘
        product = reduce(mul, digits, 1)
        total = sum(digits)
        return product - total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学取位法 | O(log n) | O(1) |
| 字符串法 | O(log n) | O(log n) |

- **时间复杂度 O(log n)**：n 的位数约为 log₁₀(n)，循环次数等于位数。
- **空间复杂度**：数学法不需要额外空间；字符串法需要存储 digits 数组，大小等于位数。

## 关键点总结

1. `n % 10` 可以取出整数 n 的**最后一位**数字。
2. `n //= 10` 可以**去掉**整数 n 的最后一位数字（整除向下取整）。
3. 乘积的初始值设为 **1**，加和的初始值设为 **0**（对应各自的单位元）。
4. 字符串转换法更直观，适合 Python 初学者。
5. 两种方法在竞赛和面试中都可接受，数学法更考验基础功底。

---

## 易错点

1. **乘积初始值误设为 0**：如果 `product = 0` 初始值设错，任何数乘以 0 都得 0，结果必然错误。乘法初始值必须为 1。
2. **字符串方法忘记转 int**：`str(n)` 的每个字符是字符类型，必须用 `int(ch)` 转换后才能参与数学运算。
3. **循环条件**：用数学法时，循环条件为 `n > 0`，n 为正整数时不需要处理 n=0 的情况（题目保证 n >= 1）。
