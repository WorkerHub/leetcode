## 题目描述

给你一个**互不相同**的整数数组 `locations`，其中 `locations[i]` 表示第 `i` 个城市的位置。同时给你 `start`、`finish` 和 `fuel` 整数。

你从城市 `start` 出发，每次移动，你可以选择任意城市，从城市 `i` 到城市 `j` 消耗的燃油量为 `|locations[i] - locations[j]|`。

返回从 `start` 到 `finish` 的所有可能路径数（可以经过任意城市，可以多次到达 `finish`）。结果对 `10^9 + 7` 取模。

**提示：**
- `2 <= locations.length <= 100`
- `0 <= start, finish < locations.length`
- `1 <= fuel <= 200`

## 解题思路

### 记忆化搜索（DFS + 记忆化）

定义 `dp[cur][fuel]` = 在城市 `cur`、还有 `fuel` 燃油时，到达 `finish` 的路径数。

**状态转移：**
- 若 `cur == finish`，贡献 1（当前就在终点，算一条路径）
- 再枚举下一个城市 `next`（不等于 `cur`），若 `fuel >= cost`，则加上 `dp[next][fuel - cost]`

## 代码实现

### 方法一：记忆化递归（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def countRoutes(self, locations: List[int], start: int, finish: int, fuel: int) -> int:
        MOD = 10**9 + 7
        n = len(locations)

        @lru_cache(maxsize=None)
        def dp(cur: int, remaining: int) -> int:
            # 在 cur 城市、剩余 remaining 燃油，到达 finish 的路径数
            # 当前在 finish 算一条（即使 remaining=0 也算）
            result = 1 if cur == finish else 0
            # 枚举下一步去哪
            for nxt in range(n):
                if nxt == cur:
                    continue
                cost = abs(locations[cur] - locations[nxt])
                if remaining >= cost:
                    result = (result + dp(nxt, remaining - cost)) % MOD
            return result

        return dp(start, fuel)
```

### 方法二：迭代 DP

```python
from typing import List

class Solution:
    def countRoutes(self, locations: List[int], start: int, finish: int, fuel: int) -> int:
        MOD = 10**9 + 7
        n = len(locations)
        # dp[f][c] = 还有 f 燃油、在城市 c 时，到 finish 的路径数
        dp = [[0] * n for _ in range(fuel + 1)]

        # 初始化：当 fuel=0 时，只有在 finish 才有 1 条路径
        for f in range(fuel + 1):
            dp[f][finish] = 1

        # 从小 fuel 到大 fuel
        for f in range(fuel + 1):
            for cur in range(n):
                for nxt in range(n):
                    if nxt == cur:
                        continue
                    cost = abs(locations[cur] - locations[nxt])
                    if f >= cost:
                        dp[f][cur] = (dp[f][cur] + dp[f - cost][nxt]) % MOD

        return dp[fuel][start]
```

## 复杂度分析

- **时间复杂度**：O(N^2 * Fuel)，状态数 N * Fuel，每个状态枚举 N 个邻居
- **空间复杂度**：O(N * Fuel)

N=100, Fuel=200 时约 2 * 10^6，可以接受。

## 关键点总结

1. 状态：`(当前城市, 剩余燃油)`，共 N * Fuel 个状态
2. 每到 `finish` 就贡献 1（可多次经过）
3. 记忆化避免重复计算

## 易错点

- 到达 `finish` 不代表停止，可以继续走（只要有燃油）
- 每次到达 `finish` 都贡献 1 个路径，不是只在燃油耗尽时才算
