## 题目描述

给你两个字符串 `s1` 和 `s2`，它们的长度相等。

一次**字符串交换**操作的步骤如下：选出某个字符串中的两个下标（**不必不同**），并交换这两个下标所对应的字符。

如果对**其中一个字符串**执行**最多一次字符串交换**就可以使两个字符串相等，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s1 = "bank", s2 = "kanb"
输出：true
解释：交换 s1[0] 和 s1[3]，得到 "nanb" ... 不对，交换 s1[0]='b' 和 s1[3]='k'，得到 "kank"，不等于 "kanb"
实际：s1 = "bank", s2 = "kanb"，差异在位置 0 和 3（'b','k' vs 'k','b'），交换 s1[0] 和 s1[3] 得 "kanb" = s2
```

**示例 2：**
```
输入：s1 = "kelb", s2 = "kelb"
输出：true
解释：两个字符串已经相等，不需要交换（或交换同一位置两次）
```

**示例 3：**
```
输入：s1 = "abcd", s2 = "dcba"
输出：false
解释：有 4 个不同的位置，不能用一次交换解决
```

**提示：**
- `1 <= s1.length, s2.length <= 100`
- `s1.length == s2.length`
- `s1` 和 `s2` 只包含小写英文字母

## 解题思路

找出 `s1` 和 `s2` 在所有位置上的差异。设差异位置列表为 `diff`：
- `len(diff) == 0`：两字符串完全相同，直接返回 `true`
- `len(diff) == 2`：只有两个位置不同，检查这两个位置的字符能否通过一次交换使两个字符串相等，即 `s1[i] == s2[j]` 且 `s1[j] == s2[i]`
- 其他情况（diff 长度为 1 或 >= 3）：返回 `false`

## 代码实现

### 方法一：找差异位置（推荐）

```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        # 找出所有不相同的位置
        diff = [(c1, c2) for c1, c2 in zip(s1, s2) if c1 != c2]

        if len(diff) == 0:
            # 完全相同
            return True
        if len(diff) == 2:
            # 检查交换两个位置的字符后是否相等
            # diff[0] = (s1[i], s2[i]), diff[1] = (s1[j], s2[j])
            # 交换 s1[i] 和 s1[j] 后，需要 s1[j]==s2[i] 且 s1[i]==s2[j]
            (a, b), (c, d) = diff
            return a == d and b == c
        return False
```

### 方法二：计数比较

```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        from collections import Counter

        # 字符组成必须相同（一次交换不改变字符集合）
        if Counter(s1) != Counter(s2):
            return False

        # 差异位置必须 <= 2（一次交换最多影响两个位置）
        diff_count = sum(c1 != c2 for c1, c2 in zip(s1, s2))
        return diff_count <= 2
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，只存储差异位置列表（最多记录全部位置，但实际上超过 2 就可以提前退出）

## 关键点总结

1. 差异位置数量只能是 0 或 2（一次交换只能修复恰好 2 个位置的差异）
2. 差异数为 2 时，还需验证能通过交换修复：`s1[i]==s2[j]` 且 `s1[j]==s2[i]`
3. 差异数为 1 时，不可能通过一次交换解决（一次交换影响两个位置）

## 易错点

1. 差异数 == 1 时要返回 `false`，不要漏掉
2. 方法二中 `Counter` 不同时直接返回 `false`，但仍需检查差异位置 <= 2
3. 不要与 `s2` 上的交换混淆，只需对其中一个字符串执行操作
