## 题目描述

给你一个正整数数组 `arr`，可以进行以下两种操作任意次：
1. **减小**：将数组中的任意元素减小到任意正整数
2. **重排**：重新排列数组元素

目标：使数组满足：
- `arr[0] == 1`
- 任意两个相邻元素之差的绝对值不超过 1（`|arr[i] - arr[i-1]| <= 1`）

返回执行操作后，数组可能的**最大元素**。

**示例 1：**
```
输入：arr = [2,2,1,2,1]
输出：2
```

**示例 2：**
```
输入：arr = [100,1,1000]
输出：3
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^9`

## 解题思路

**贪心**：

1. 排序数组
2. 第一个元素设为 1
3. 对于之后每个元素 `arr[i]`，它的值最多能比前一个元素大 1，且不能超过它的原始值（可以减小但不能增大）
4. 所以 `arr[i] = min(arr[i], arr[i-1] + 1)`
5. 最后一个元素即为所求最大值

## 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: List[int]) -> int:
        arr.sort()
        arr[0] = 1  # 第一个元素必须为 1

        for i in range(1, len(arr)):
            # 当前元素最大值为 min(arr[i], arr[i-1] + 1)
            arr[i] = min(arr[i], arr[i - 1] + 1)

        return arr[-1]
```

### 方法二：计数排序优化

```python
from typing import List

class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: List[int]) -> int:
        n = len(arr)
        # 目标序列最大为 n（每步最多 +1，从 1 开始，n 个数最大为 n）
        # 用计数排序统计各值的个数
        count = [0] * (n + 2)
        for x in arr:
            count[min(x, n)] += 1

        result = 0
        for val in range(1, n + 1):
            # 当前值至少为 result + 1（但不超过 val）
            result = min(result + count[val], val)

        return result
```

## 复杂度分析

- **方法一（排序贪心）**：O(n log n) 时间，O(1) 空间
- **方法二（计数排序）**：O(n) 时间，O(n) 空间

## 关键点总结

1. 贪心：排序后贪心地让每个元素尽可能大（但不超过前一个 +1）
2. 目标序列最大值不超过 n（数组长度），因此可以用计数排序
3. 只能减小不能增大，所以排序后每个元素设为 `min(原值, 前一个+1)`

## 易错点

- 第一个元素固定为 1，而不是保持原值
- 操作只能减小，不能增大（因此设为 `min(arr[i], arr[i-1]+1)` 而非直接赋值为 `arr[i-1]+1`）
