## 题目描述

如果字符串 `s` 中**不存在**两个不同字符频率相同的情况，就称 `s` 是**优质字符串**。

给你一个字符串 `s`，返回使 `s` 成为**优质字符串**需要删除的**最少字符数**。

**示例：**
```
输入：s = "aab"
输出：0（a 出现 2 次，b 出现 1 次，不重复）

输入：s = "aaabbbcc"
输出：2（删除 2 个 b，b 频率从 3 变为 1，各频率唯一）
```

## 解题思路

**贪心策略：**
1. 统计每个字符的频率
2. 按频率从大到小排序
3. 对每个频率，若已被使用，则将其减少到**最大可用频率**（贪心：删除最少字符）

## 代码实现

### 方法一：贪心 + 集合（推荐）

```python
from collections import Counter

class Solution:
    def minDeletions(self, s: str) -> int:
        freq = sorted(Counter(s).values(), reverse=True)
        used = set()
        deletions = 0
        
        for f in freq:
            # 找到 <= f 的最大未使用频率
            while f > 0 and f in used:
                f -= 1
                deletions += 1
            
            if f > 0:
                used.add(f)
        
        return deletions
```

### 方法二：贪心排序（不用集合）

```python
from collections import Counter

class Solution:
    def minDeletions(self, s: str) -> int:
        freq = sorted(Counter(s).values(), reverse=True)
        deletions = 0
        
        for i in range(1, len(freq)):
            if freq[i] >= freq[i-1]:
                # 当前频率 >= 前一个，需要减小
                new_freq = max(0, freq[i-1] - 1)
                deletions += freq[i] - new_freq
                freq[i] = new_freq
        
        return deletions
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心+集合 | O(n + 26 log 26) = O(n) | O(26) = O(1) |
| 排序贪心 | O(n) | O(26) = O(1) |

## 关键点总结

1. 只有字符频率的唯一性有要求，不关心具体是哪个频率
2. 贪心：当频率冲突时，将其减少到最近可用值（最少删除）
3. 频率减为 0 时可以，表示该字符全部删除

## 易错点

- 频率可以减为 0（全部删除）
- 排序后从大到小处理：让大频率优先占用较大值
- 每个频率只能被一个字符使用
