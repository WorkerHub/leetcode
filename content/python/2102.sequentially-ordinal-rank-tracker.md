## 题目描述

一个观光景点由它的名字和景点评分组成，其中景点评分是一个整数。景点按如下规则排名：

- **评分更高**的景点排名更靠前。
- 若两个景点评分相同，**名字更小**（字典序更靠前）的景点排名更靠前。

实现 `SORTracker` 类：

- `SORTracker()` 初始化系统，不含任何景点。
- `void add(string name, int score)` 向系统中加入一个名字为 `name`，评分为 `score` 的景点。
- `string get()` 查询并返回第 `i` 次调用 `get()` 时系统中第 `i` 好的景点名称。

**示例：**
```
输入：
["SORTracker", "add", "add", "get", "add", "get", "add", "get", "add", "get", "add", "get", "get"]
[[], ["bradford", 2], ["branford", 3], [], ["alps", 2], [], ["orland", 2], [], ["orlando", 3], [], ["alpine", 2], [], []]
输出：
[null, null, null, "branford", null, "alps", null, "bradford", null, "bradford", null, "bradford", "orland"]
```

**提示：**
- `name` 由小写英文字母组成，长度在 `[1, 10]`。
- `1 <= score <= 10^5`
- `get` 与 `add` 的调用次数相同，且不超过 `4 * 10^4`。

## 解题思路

**双堆维护第 i 好的景点**

每次 `get()` 调用需要获取当前排名第 `i` 好的景点（i 依次递增）。

思路：维护两个堆
- `good`：最大堆，存放排名前 i 的景点，堆顶是第 i 好的。
- `bad`：最小堆，存放排名 i+1 之后的景点。

堆的排序规则：按 `(-score, name)` 作为比较键（Python 中用负号模拟最大堆）。

**操作：**
- `add`：先将新景点加入 `bad`（最小堆）。若 `bad` 堆顶比 `good` 堆顶更优，则将 `bad` 堆顶移至 `good`，同时将 `good` 堆顶移至 `bad`。
- `get`：将 `bad` 堆顶（当前第 i+1 好）移至 `good`（成为第 i 好），返回 `good` 堆顶。

## 代码实现

### 方法一：双堆（推荐）

```python
import heapq

class SORTracker:
    def __init__(self):
        # good 堆：最大堆，存放前 i 名，堆顶是第 i 名
        # 用 (score, name) 负号模拟，(score越大越好，name越小越好)
        # 存储 (-score, name) 使得 heapq 最小堆变最大堆
        self.good = []  # 最大堆（存负分）：堆顶是前i名中最差的（即第i名）
        self.bad = []   # 最小堆：存储第i名之后的景点
        self.i = 0      # 当前查询次数

    def _better(self, a, b) -> bool:
        # 判断 a 是否比 b 更好（分高或同分名字更小）
        # a, b 格式为 (-score, name)
        return a < b  # Python 元组比较：先比 -score（即分越高 -score 越小），再比 name

    def add(self, name: str, score: int) -> None:
        # 新景点加入 bad 堆
        heapq.heappush(self.bad, (-score, name))
        # 若 bad 堆顶比 good 堆顶更好，则交换
        if self.good and self._better(self.bad[0], self.good[0]):
            top_bad = heapq.heappop(self.bad)
            top_good = heapq.heappop(self.good)
            heapq.heappush(self.bad, top_good)
            heapq.heappush(self.good, top_bad)

    def get(self) -> str:
        # bad 堆顶（最优的那个）移入 good，成为第 i 名
        self.i += 1
        top = heapq.heappop(self.bad)
        heapq.heappush(self.good, top)
        # good 堆顶即第 i 名
        neg_score, name = self.good[0]
        return name
```

### 方法二：使用 sortedcontainers.SortedList

```python
from sortedcontainers import SortedList

class SORTracker:
    def __init__(self):
        # 按 (-score, name) 排序，索引 0 是最好的
        self.sl = SortedList(key=lambda x: (-x[1], x[0]))
        self.i = 0  # 当前应返回的排名

    def add(self, name: str, score: int) -> None:
        # 直接插入有序列表
        self.sl.add((name, score))

    def get(self) -> str:
        # 返回第 i 名（0-indexed）
        name, score = self.sl[self.i]
        self.i += 1
        return name
```

## 复杂度分析

| 方法 | add 时间复杂度 | get 时间复杂度 | 空间复杂度 |
|------|--------------|--------------|-----------|
| 双堆 | O(log n)     | O(log n)     | O(n)      |
| SortedList | O(log n) | O(1)     | O(n)      |

## 关键点总结

1. 双堆法核心：`good` 堆始终保持前 i 名，`get` 时将 `bad` 堆顶移入 `good`。
2. 排序规则：分高优先，同分则名字字典序小优先，用 `(-score, name)` 作为比较键。
3. `add` 操作后需检查是否需要调整两堆的边界元素。

## 易错点

- `good` 堆是最大堆，堆顶是前 i 名中最差的（即第 i 名），不是最好的。
- Python `heapq` 是最小堆，存 `(-score, name)` 来模拟按分数降序排列。
- 每次 `get` 前先将 `bad` 堆顶移入 `good`，使 `good` 中元素数量恰好等于 i。
