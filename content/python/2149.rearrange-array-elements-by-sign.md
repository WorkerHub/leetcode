## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，大小为 **偶数**，由**数量相等**的正整数和负整数组成。

对数组进行**重排**，使：
- 每个**连续**的两个整数符号**相反**。
- 重排后**正整数**出现在**偶数**下标处，**负整数**出现在**奇数**下标处。
- 相对顺序**保持不变**（正整数的相对顺序和负整数的相对顺序分别不变）。

返回重排后的数组。

**示例：**
```
输入：nums = [3,1,-2,-5,2,-4]
输出：[3,-2,1,-5,2,-4]
```

**提示：**
- `2 <= nums.length <= 2 * 10^5`
- `nums.length` 为偶数
- `1 <= |nums[i]| <= 10^5`
- 正负整数数量相等

## 解题思路

**双指针**

分别维护下一个正数的位置 `pos`（初始为 0，步长 2）和下一个负数的位置 `neg`（初始为 1，步长 2）。

遍历 `nums`，遇到正数填入 `result[pos]`，遇到负数填入 `result[neg]`。

## 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = [0] * n
        pos = 0  # 下一个正数放置的位置（偶数下标）
        neg = 1  # 下一个负数放置的位置（奇数下标）

        for x in nums:
            if x > 0:
                result[pos] = x
                pos += 2
            else:
                result[neg] = x
                neg += 2

        return result
```

### 方法二：分离正负数后合并

```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        positives = [x for x in nums if x > 0]
        negatives = [x for x in nums if x < 0]
        result = []
        for p, n in zip(positives, negatives):
            result.append(p)
            result.append(n)
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n) | O(n) |
| 分离合并 | O(n) | O(n) |

## 关键点总结

1. 正数放偶数位，负数放奇数位，各自保持相对顺序。
2. 双指针法：`pos` 和 `neg` 分别追踪下一个正/负数的放置位置。
3. 分离合并法：先提取正负数，再交错合并，代码更直观。

## 易错点

- 正数放偶数下标（0,2,4,...），负数放奇数下标（1,3,5,...）。
- 题目保证正负数数量相等，无需处理数量不等的情况。
