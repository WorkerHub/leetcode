## 题目描述

给你一个大小为 `n x 2` 的整数数组 `logs` 和一个整数 `k`，其中 `logs[i] = [IDi, timei]` 表示用户 `IDi` 在时间 `timei` 进行了一次操作。

**用户活跃分钟数（UAM）**定义为用户在唯一分钟数内进行操作的个数（同一分钟多次操作只算一次）。

请你统计每种 UAM 值（1 到 k）对应的用户数，返回大小为 k 的结果数组 `answer`，其中 `answer[j]` 是 UAM 等于 `j+1` 的用户数。

**示例：**
```
输入：logs = [[0,5],[1,2],[0,2],[0,5],[1,3]], k = 5
输出：[0,2,0,0,0]
解释：用户 0 的唯一活跃分钟数：{2,5} → UAM=2；用户 1 的唯一活跃分钟数：{2,3} → UAM=2
     answer[1] = 2，其余为 0
```

**提示：**
- `1 <= logs.length <= 10^4`
- `0 <= IDi <= 10^9`
- `1 <= timei <= 10^5`
- `1 <= k <= 10^5`

## 解题思路

用哈希表记录每个用户操作过的唯一时间（用集合去重）。然后统计每个用户的 UAM（集合大小），对每个 UAM 值累计计数。

## 代码实现

### 方法一：哈希表 + 集合去重（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def findingUsersActiveMinutes(self, logs: List[List[int]], k: int) -> List[int]:
        # 用字典记录每个用户操作的唯一时间集合
        user_minutes = defaultdict(set)
        for uid, t in logs:
            user_minutes[uid].add(t)

        answer = [0] * k
        for uid, times in user_minutes.items():
            uam = len(times)  # 用户活跃分钟数
            if 1 <= uam <= k:
                answer[uam - 1] += 1  # 下标从 0 开始，uam 对应 answer[uam-1]
        return answer
```

### 方法二：Counter 简化

```python
from collections import defaultdict, Counter
from typing import List

class Solution:
    def findingUsersActiveMinutes(self, logs: List[List[int]], k: int) -> List[int]:
        user_times = defaultdict(set)
        for uid, t in logs:
            user_times[uid].add(t)

        # 统计各 UAM 值的用户数
        uam_count = Counter(len(v) for v in user_times.values())

        return [uam_count.get(j + 1, 0) for j in range(k)]
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历 logs 一次，统计一次
- **空间复杂度**：O(n)，哈希表存储

## 关键点总结

1. 同一用户同一分钟多次操作只算一次，用集合自动去重
2. 结果数组下标从 0 开始，UAM=j+1 对应 answer[j]

## 易错点

- answer 数组索引是 UAM-1，不是 UAM
- 若 UAM > k，题目保证不会发生（但写代码时可以加 if 保护）
