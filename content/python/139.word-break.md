## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s`，则返回 `true`。

**注意：** 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**
```
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**
```
输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**
```
输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false
```

**提示：**
- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串互不相同

## 解题思路

这是一道经典的动态规划问题，也可以用带记忆化的回溯解决。

**核心思想：判断字符串能否被字典中的单词拼接**

### 方法一：动态规划（最优解）

**定义状态：**
- `dp[i]` 表示字符串 `s[0:i]`（前 i 个字符）能否被字典中的单词拼接

**状态转移方程：**
```
dp[i] = any(dp[j] and s[j:i] in wordDict) for j in range(i)
```
- 如果存在某个位置 `j`，使得 `s[0:j]` 可以被拼接（`dp[j] = True`）
- 并且 `s[j:i]` 在字典中
- 那么 `s[0:i]` 就可以被拼接（`dp[i] = True`）

**初始状态：**
- `dp[0] = True`（空字符串可以被拼接）

**算法流程：**
1. 初始化 dp 数组，`dp[0] = True`
2. 遍历字符串的每个位置 i（从 1 到 n）
3. 对于每个 i，检查所有可能的分割点 j（从 0 到 i-1）
4. 如果 `dp[j]` 为 True 且 `s[j:i]` 在字典中，则 `dp[i] = True`

### 方法二：回溯 + 记忆化

从字符串开头开始，尝试匹配字典中的每个单词，递归处理剩余部分，使用记忆化避免重复计算。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        # 将字典转为集合，加快查找速度
        word_set = set(wordDict)
        
        # dp[i] 表示 s[0:i] 能否被拼接
        dp = [False] * (n + 1)
        dp[0] = True  # 空字符串可以被拼接
        
        # 遍历字符串的每个位置
        for i in range(1, n + 1):
            # 检查所有可能的分割点
            for j in range(i):
                # 如果 s[0:j] 可以被拼接，且 s[j:i] 在字典中
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break  # 找到一种拼接方式即可
        
        return dp[n]
```

### 方法二：动态规划（优化版，从单词长度入手）

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        word_set = set(wordDict)
        # 获取字典中单词的最大长度，减少不必要的检查
        max_len = max(len(word) for word in wordDict)
        
        dp = [False] * (n + 1)
        dp[0] = True
        
        for i in range(1, n + 1):
            # 只检查长度不超过最大单词长度的子串
            for j in range(max(0, i - max_len), i):
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break
        
        return dp[n]
```

### 方法三：回溯 + 记忆化

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        memo = {}  # 记忆化：存储每个起始位置的结果
        
        def backtrack(start: int) -> bool:
            # 已经处理完整个字符串
            if start == len(s):
                return True
            
            # 如果已经计算过，直接返回结果
            if start in memo:
                return memo[start]
            
            # 尝试匹配字典中的每个单词
            for end in range(start + 1, len(s) + 1):
                word = s[start:end]
                if word in word_set:
                    # 如果当前单词匹配，递归处理剩余部分
                    if backtrack(end):
                        memo[start] = True
                        return True
            
            memo[start] = False
            return False
        
        return backtrack(0)
```

### 方法四：BFS（广度优先搜索）

```python
from typing import List
from collections import deque

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        visited = set()  # 记录已访问的位置，避免重复
        queue = deque([0])  # 队列存储当前位置
        
        while queue:
            start = queue.popleft()
            if start == n:
                return True
            
            # 尝试所有可能的下一个位置
            for end in range(start + 1, n + 1):
                if end in visited:
                    continue
                if s[start:end] in word_set:
                    queue.append(end)
                    visited.add(end)
        
        return False
```

## 复杂度分析

### 方法一、二：动态规划
- **时间复杂度**：O(n² × m)，其中 n 是字符串长度，m 是平均单词长度（字符串切片和哈希查找）
- **空间复杂度**：O(n)，dp 数组的空间

### 方法三：回溯 + 记忆化
- **时间复杂度**：O(n² × m)，最坏情况下需要检查所有子串
- **空间复杂度**：O(n)，记忆化数组和递归栈的空间

### 方法四：BFS
- **时间复杂度**：O(n² × m)
- **空间复杂度**：O(n)，队列和 visited 集合的空间

## 关键点总结

1. **动态规划的应用**：将问题分解为子问题，避免重复计算
2. **集合优化查找**：将列表转为集合，O(1) 时间查找
3. **状态定义**：`dp[i]` 表示前缀字符串能否被拼接
4. **优化技巧**：记录最大单词长度，减少不必要的检查
5. **多种解法**：DP、回溯、BFS 都可以解决，但 DP 最优

## 易错点

1. **索引问题**：`dp[i]` 对应字符串 `s[0:i]`，注意切片的左闭右开
2. **字典查找**：要将 `wordDict` 转为集合，提高查找效率
3. **初始状态**：`dp[0] = True` 不能忘记，表示空字符串可以被拼接
4. **重复使用**：字典中的单词可以重复使用，不需要标记是否使用过
5. **break 优化**：找到一种拼接方式后可以立即 break，不需要继续检查
