## 题目描述

给你两个字符串 `current` 和 `correct`，均表示 `"HH:MM"` 格式的 24 小时制时间（`00:00` 到 `23:59`）。

每次操作可以将 `current` 加 1 分钟、5 分钟、15 分钟或 60 分钟。

返回将 `current` 转换为 `correct` 所需的 **最少操作次数**（保证 `correct >= current`）。

**示例 1：**
```
输入：current = "02:30", correct = "04:35"
输出：3
解释：差125分钟，125 = 2*60 + 1*5 + 0*15 + 0 -> 2+1=3次，其实125=60+60+5，3次。
```

**示例 2：**
```
输入：current = "11:00", correct = "11:01"
输出：1
```

## 解题思路

**贪心：** 将时间差转换为分钟数 `diff`，每次尽量使用最大的操作（60 -> 15 -> 5 -> 1），类似找零钱问题。

操作集合：`[60, 15, 5, 1]`，贪心地优先使用大操作。

## 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def convertTime(self, current: str, correct: str) -> int:
        # 将时间字符串转换为分钟数
        def to_minutes(t: str) -> int:
            h, m = t.split(':')
            return int(h) * 60 + int(m)

        diff = to_minutes(correct) - to_minutes(current)

        ops = 0
        for step in [60, 15, 5, 1]:
            ops += diff // step  # 使用该步长的次数
            diff %= step         # 剩余差值

        return ops
```

### 方法二：显式处理每个步长

```python
class Solution:
    def convertTime(self, current: str, correct: str) -> int:
        # 解析时分
        ch, cm = int(current[:2]), int(current[3:])
        dh, dm = int(correct[:2]), int(correct[3:])

        # 计算分钟差
        diff = (dh * 60 + dm) - (ch * 60 + cm)

        count = 0
        # 贪心：先用60，再用15，再用5，最后用1
        count += diff // 60
        diff %= 60
        count += diff // 15
        diff %= 15
        count += diff // 5
        diff %= 5
        count += diff  # 剩余用1分钟操作

        return count
```

## 复杂度分析

- 时间复杂度：O(1)，操作数固定为 4。
- 空间复杂度：O(1)。

## 关键点总结

1. 将时间差转为分钟数，然后用贪心策略（类似找零）。
2. 操作从大到小：60 -> 15 -> 5 -> 1，每步取商和余数。
3. 保证 `correct >= current`，差值非负。

## 易错点

- 时间字符串解析：`HH:MM` 中小时是前两位，分钟是后两位，冒号在中间。
- 操作顺序必须从大到小才能保证最少操作次数。
