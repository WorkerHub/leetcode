## 题目描述

给定一棵有 `n` 个节点的加权树（边有权重），节点编号 1 到 n，根节点为 1。给定若干查询：
- 类型 1：更新某条边的权重
- 类型 2：查询从根节点 1 到节点 `v` 的最短路径长度

**示例：**

```
输入：n = 4, edges = [[1,2,3],[2,3,4],[2,4,1]], queries = [[2,3],[1,2,3,7],[2,3]]
输出：[7, 11]
解释：
初始：1->2->3 距离为 3+4=7
更新边 (2,3) 权重为 7 后：1->2->3 距离为 3+7=10...
```

**提示：**
- `2 <= n <= 10^5`
- 查询数 <= 10^5
- 边权 `1 <= weight <= 10^9`

## 解题思路

树上路径 + 边权更新：

1. **欧拉序（DFS 序）**：对树进行 DFS，记录每个节点的进入时间 `in[v]` 和离开时间 `out[v]`
2. **根到节点距离**：用数组 `dist[v]` 维护根到节点 v 的距离
3. **边权更新**：当更新边 `(u, v)`（u 是 v 的父节点）的权重时，v 的子树中所有节点的距离都需要加上差值 `delta = new_weight - old_weight`
4. **线段树区间更新**：利用 DFS 序，v 的子树对应连续区间 `[in[v], out[v]]`，使用线段树进行区间加法和单点查询

核心步骤：
- DFS 建立欧拉序和初始 dist 数组
- 线段树支持区间加、单点查
- 查询 `dist[v]` 等于线段树查询 `in[v]` 位置的值

## Python 代码实现

### 方法一：DFS 序 + 线段树（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def treeQueries(self, n: int, edges: List[List[int]], queries: List[List[int]]) -> List[int]:
        # 建树（无向图，有权重）
        graph = defaultdict(list)
        edge_weight = {}
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))
            edge_weight[(min(u,v), max(u,v))] = w

        # DFS 建立欧拉序
        in_time = [0] * (n + 1)
        out_time = [0] * (n + 1)
        dist = [0] * (n + 1)
        parent = [0] * (n + 1)
        parent_edge = {}  # 节点 -> 父边 key

        timer = [0]
        order = []

        def dfs(u, p, d):
            timer[0] += 1
            in_time[u] = timer[0]
            order.append(u)
            dist[u] = d
            for v, w in graph[u]:
                if v != p:
                    parent[v] = u
                    key = (min(u,v), max(u,v))
                    parent_edge[v] = key
                    dfs(v, u, d + w)
            out_time[u] = timer[0]

        dfs(1, 0, 0)

        # 线段树（支持区间加、单点查）
        size = n + 2
        tree = [0] * (4 * size)
        lazy = [0] * (4 * size)

        def push_down(node):
            if lazy[node]:
                tree[2*node] += lazy[node]
                lazy[2*node] += lazy[node]
                tree[2*node+1] += lazy[node]
                lazy[2*node+1] += lazy[node]
                lazy[node] = 0

        def update(node, start, end, l, r, val):
            if r < start or end < l:
                return
            if l <= start and end <= r:
                tree[node] += val
                lazy[node] += val
                return
            push_down(node)
            mid = (start + end) // 2
            update(2*node, start, mid, l, r, val)
            update(2*node+1, mid+1, end, l, r, val)

        def query(node, start, end, idx):
            if start == end:
                return tree[node]
            push_down(node)
            mid = (start + end) // 2
            if idx <= mid:
                return query(2*node, start, mid, idx)
            return query(2*node+1, mid+1, end, idx)

        # 初始化：将 dist 写入线段树
        for v in range(1, n+1):
            update(1, 1, n, in_time[v], in_time[v], dist[v])

        result = []
        for q in queries:
            if q[0] == 2:
                v = q[1]
                result.append(query(1, 1, n, in_time[v]))
            else:
                # 类型 1：更新边权重
                _, u, v, new_w = q
                key = (min(u,v), max(u,v))
                old_w = edge_weight[key]
                delta = new_w - old_w
                edge_weight[key] = new_w
                # 确定子节点
                child = v if parent[v] == u else u
                # 更新子树
                update(1, 1, n, in_time[child], out_time[child], delta)

        return result
```

### 方法二：树上差分（简化版）

```python
from typing import List
from collections import defaultdict

class Solution:
    def treeQueries(self, n: int, edges: List[List[int]], queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append([v, w])
            graph[v].append([u, w])

        dist = [0] * (n + 1)
        parent = [(-1, 0)] * (n + 1)  # (父节点, 边权)
        order = []
        visited = [False] * (n + 1)
        stack = [1]
        visited[1] = True

        while stack:
            u = stack.pop()
            order.append(u)
            for v, w in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    parent[v] = (u, w)
                    dist[v] = dist[u] + w
                    stack.append(v)

        result = []
        # 维护到根距离（暴力更新）
        for q in queries:
            if q[0] == 2:
                result.append(dist[q[1]])
            else:
                _, u, v, new_w = q
                child = v if parent[v][0] == u else u
                old_w = parent[child][1]
                delta = new_w - old_w
                parent[child] = (parent[child][0], new_w)
                # 更新子树所有节点
                sub_stack = [child]
                while sub_stack:
                    node = sub_stack.pop()
                    dist[node] += delta
                    for nb, _ in graph[node]:
                        if nb != parent[node][0]:
                            sub_stack.append(nb)

        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)（方法一线段树），O(n * q)（方法二暴力）
- 空间复杂度：O(n)

## 关键点总结

1. DFS 序将子树映射为连续区间，利于线段树区间操作
2. 更新边权时，只需对子树的所有节点加上差值
3. 线段树支持区间加（lazy 标记）和单点查询

## 易错点

1. 确定边的子节点方向（谁是父节点谁是子节点）
2. 更新时需要正确找到子节点（根据 parent 数组判断）
3. 线段树 lazy 标记的下推时机
