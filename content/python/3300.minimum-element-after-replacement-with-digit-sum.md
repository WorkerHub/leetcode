## 题目描述

给你一个整数数组 `nums`，执行以下操作**任意次**：

选择数组中的一个元素，将其替换为其所有数字的和。

返回可能得到的**最小元素**。

**示例 1：**
```
输入：nums = [10,12,13,14]
输出：1
解释：10 -> 1+0=1，选择1作为最小值。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：1
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`

## 解题思路

对每个元素，可以用其"数字和"替换。数字和一定 <= 原值（对正整数）。

可以反复替换，但对 1-9 的数字，其数字和等于自身，不再缩小。

所以实际上，对每个元素，一次替换就够了：将大于 9 的数替换为其数字和（可能还 > 9，但最多两次就降到个位数）。

最终每个元素的最小值就是其"最终数字和"（反复求数字和直到单位数）= 数字根（Digital root）。

数字根公式：若 n = 0，root = 0；否则 root = 1 + (n-1) % 9。

## Python 代码实现

### 方法一：计算数字和（推荐）

```python
from typing import List

class Solution:
    def minElement(self, nums: List[int]) -> int:
        def digit_sum(n):
            return sum(int(d) for d in str(n))
        
        # 每个元素最多操作一次（数字和小于原值）
        return min(min(nums), min(digit_sum(x) for x in nums))
```

### 方法二：数字根公式

```python
from typing import List

class Solution:
    def minElement(self, nums: List[int]) -> int:
        def digital_root(n):
            # 数字根：反复求数字和直到单位数
            while n >= 10:
                n = sum(int(d) for d in str(n))
            return n
        
        return min(digital_root(x) for x in nums)
```

### 方法三：一次数字和

```python
from typing import List

class Solution:
    def minElement(self, nums: List[int]) -> int:
        # 题目只说"任意次"，但对于最小值，一次就够了
        # 因为一次替换后值变小，而我们取全局最小
        candidates = nums + [sum(int(d) for d in str(x)) for x in nums]
        return min(candidates)
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))，log 因为数字位数
- 空间复杂度：O(1)

## 关键点总结

1. 对每个元素，求一次数字和（或反复求直到个位数）
2. 取所有元素（原值或数字和）的最小值
3. 数字和总是 <= 原值（对正整数）

## 易错点

1. 题目说任意次，但对于找最小值，每个元素只需求一次数字和即可
2. 多位数的数字和仍可能是多位数（如 99 -> 18 -> 9），可能需要多次
