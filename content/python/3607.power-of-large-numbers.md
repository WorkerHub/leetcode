## 题目描述

给你两个用字符串表示的大整数 `base` 和 `exp`，返回 `base^exp` 对 `10^9 + 7` 取模的结果。

`base` 和 `exp` 可能非常大（位数超过普通整型范围）。

**示例 1：**

```
输入：base = "2", exp = "10"
输出：1024
```

**示例 2：**

```
输入：base = "123456789", exp = "987654321"
输出：352239301
```

**提示：**

- `1 <= base.length, exp.length <= 10^4`
- `base` 和 `exp` 均为合法正整数字符串，不含前导零

## 解题思路

核心问题：大整数幂取模。

由于 `exp` 本身可能是大整数（字符串形式），需要：
1. 将字符串 `base` 转为整数（Python 原生支持大整数）
2. 将字符串 `exp` 转为整数
3. 使用快速幂 `pow(base, exp, MOD)` 计算

Python 内置 `pow(a, b, mod)` 直接支持大整数，三参数形式即为模幂运算，时间复杂度 O(log exp)。

## Python 代码实现

### 方法一：Python 内置大整数（推荐）

```python
class Solution:
    def powerOfLargeNumbers(self, base: str, exp: str) -> int:
        MOD = 10 ** 9 + 7
        # Python 原生支持任意大整数，直接转换后使用内置模幂
        b = int(base)
        e = int(exp)
        return pow(b, e, MOD)
```

### 方法二：手动快速幂（字符串转大整数后）

```python
class Solution:
    def powerOfLargeNumbers(self, base: str, exp: str) -> int:
        MOD = 10 ** 9 + 7

        b = int(base)
        e = int(exp)

        # 快速幂实现
        result = 1
        b %= MOD
        while e > 0:
            if e % 2 == 1:
                result = result * b % MOD
            b = b * b % MOD
            e //= 2

        return result
```

## 复杂度分析

- 时间复杂度：O(len(exp) + log(exp))，字符串转整数 O(len)，快速幂 O(log exp)
- 空间复杂度：O(len(base) + len(exp))，大整数存储

## 关键点总结

1. Python 内置 `pow(a, b, mod)` 三参数形式高效计算模幂
2. Python 原生支持大整数，无需特殊处理字符串转换
3. 快速幂将时间复杂度从 O(exp) 降低到 O(log exp)
4. 取模运算需在每步乘法后进行，防止中间结果溢出

## 易错点

1. 不要用 `(b ** e) % MOD`，当 exp 极大时效率极低
2. Python 的 `int` 虽然支持大整数，但指数运算不带模时极慢
3. 字符串转整数本身是 O(n) 的，n 为字符串长度
