## 题目描述

银行有 `m` 行 `n` 列，每个格子含 `'0'`（没有安全设备）或 `'1'`（有安全设备）。

**激光束**满足：连接**不同行**的两个安全设备，且两行之间的所有行均没有安全设备。

若第 `i` 行有 `a` 个设备，第 `j` 行有 `b` 个设备，且 `i < j` 且 `i+1` 到 `j-1` 行均没有设备，则这两行之间有 `a * b` 条激光束。

返回银行中激光束的**总数量**。

**示例：**
```
输入：bank = ["011001","000000","010100","001000"]
输出：8
解释：
- 第0行(2个设备)和第2行(2个设备)之间：2*2=4条（第1行全0）
- 第2行(2个设备)和第3行(1个设备)之间：2*1=2条
- 总共：4+2=6（不对，应为8，再检查...）
实际：第0行2，第2行2，第3行1，0和2之间4，2和3之间2，总计8错，需重算。
第0行: "011001" -> 3个1
第2行: "010100" -> 2个1  
第3行: "001000" -> 1个1
3*2 + 2*1 = 8
```

**提示：**
- `m == bank.length`
- `n == bank[i].length`
- `1 <= m, n <= 500`
- `bank[i][j]` 为 `'0'` 或 `'1'`

## 解题思路

**逐行统计 1 的个数**

过滤掉全为 0 的行，只保留有安全设备的行。相邻两个非空行之间的激光束数 = 两行 1 的数量之积。

## 代码实现

### 方法一：逐行统计（推荐）

```python
from typing import List

class Solution:
    def numberOfBeams(self, bank: List[str]) -> int:
        # 收集每行非零行的设备数量
        counts = [row.count('1') for row in bank if '1' in row]
        ans = 0
        for i in range(1, len(counts)):
            ans += counts[i - 1] * counts[i]
        return ans
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def numberOfBeams(self, bank: List[str]) -> int:
        ans = 0
        prev = 0  # 上一个非空行的设备数
        for row in bank:
            curr = row.count('1')
            if curr > 0:
                ans += prev * curr
                prev = curr
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 逐行统计 | O(m * n) | O(m) |
| 一次遍历 | O(m * n) | O(1) |

## 关键点总结

1. 只有相邻的非空行（之间没有其他非空行）之间才产生激光束。
2. 激光束数 = 相邻非空行 1 的个数之积。
3. 过滤全 0 行后，依次相乘累加即可。

## 易错点

- 中间有全 0 行时，不影响上下非空行的"相邻"关系，因为只考虑没有安全设备的行为间隔。
- 若某行全为 0，它不产生任何激光束，也不阻断前后非空行的连接（但实际上它确实阻断了！）。

等等，重新理解题意：**相邻的非空行**指中间的所有行均为全 0。所以过滤 0 行后，相邻元素确实就是题目中定义的"相邻"。
