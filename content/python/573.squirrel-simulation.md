## 题目描述

现在有一棵树，一只松鼠和一些坚果。位置由二维网格的单元格表示。你的目标是找到松鼠收集所有坚果并把它们放到树下的最小路程。松鼠一次最多只能携带一颗坚果。

松鼠可以直接从当前位置跳到树或坚果的位置。所有的距离都是曼哈顿距离。

给定五个参数：
- `height` 和 `width` 表示网格的高度和宽度
- `tree` 表示树的位置
- `squirrel` 表示松鼠的位置
- `nuts` 表示坚果的位置数组

**示例：**
```
输入：
height = 5, width = 7
tree = [2,2]
squirrel = [4,4]
nuts = [[3,0], [2,5]]
输出：12
```

## 解题思路

核心观察：
- 除了第一颗坚果，其他所有坚果都需要往返（nut -> tree -> nut -> tree）
- 第一颗坚果：squirrel -> nut -> tree
- 最优策略：选择能节省最多距离的坚果作为第一颗

## Python 代码实现

### 方法一：贪心（推荐）⭐

```python
from typing import List

class Solution:
    def minDistance(self, height: int, width: int, tree: List[int], squirrel: List[int], nuts: List[List[int]]) -> int:
        """
        贪心选择第一颗坚果
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        def manhattan_distance(p1, p2):
            return abs(p1[0] - p2[0]) + abs(p1[1] - p2[1])
        
        # 计算所有坚果往返树的总距离
        total_distance = sum(2 * manhattan_distance(nut, tree) for nut in nuts)
        
        # 找到最优的第一颗坚果（能节省最多距离的）
        # 第一颗坚果的距离：squirrel -> nut -> tree
        # 节省的距离：nut -> tree - (squirrel -> nut)
        max_saving = float('-inf')
        for nut in nuts:
            dist_nut_tree = manhattan_distance(nut, tree)
            dist_squirrel_nut = manhattan_distance(squirrel, nut)
            saving = dist_nut_tree - dist_squirrel_nut
            max_saving = max(max_saving, saving)
        
        return total_distance - max_saving
```

### 方法二：直接计算

```python
from typing import List

class Solution:
    def minDistance(self, height: int, width: int, tree: List[int], squirrel: List[int], nuts: List[List[int]]) -> int:
        """
        直接计算最小距离
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        def dist(p1, p2):
            return abs(p1[0] - p2[0]) + abs(p1[1] - p2[1])
        
        total = 0
        min_diff = float('inf')
        
        for nut in nuts:
            d = dist(nut, tree)
            total += 2 * d
            # 计算作为第一颗坚果的额外距离
            diff = dist(squirrel, nut) - d
            min_diff = min(min_diff, diff)
        
        return total + min_diff
```

## 复杂度分析

- **时间复杂度**：O(n)，n 是坚果数量
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心策略**：选择能节省最多距离的坚果作为第一颗
2. **曼哈顿距离**：|x1 - x2| + |y1 - y2|
3. **数学转化**：total - max_saving
