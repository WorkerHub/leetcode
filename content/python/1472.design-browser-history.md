## 题目描述

你有一个只支持单个标签页的**浏览器**，最开始你浏览的网页是 `homepage`，可以访问其他的网站 `url`，也可以在浏览历史中后退 `steps` 步或前进 `steps` 步。

请你实现 `BrowserHistory` 类：

- `BrowserHistory(string homepage)`：用 `homepage` 初始化浏览器类。
- `void visit(string url)`：从当前页跳转访问 `url` 对应的页面。执行此操作会把浏览历史前进部分全部删除。
- `string back(int steps)`：在浏览历史中后退 `steps` 步。如果你只能在历史中后退至多 `x` 步且 `steps > x`，那么你只后退 `x` 步。返回后退至多 `steps` 步以后的 `url`。
- `string forward(int steps)`：在浏览历史中前进 `steps` 步。如果你只能在历史中前进至多 `x` 步且 `steps > x`，那么你只前进 `x` 步。返回前进至多 `steps` 步以后的 `url`。

**示例：**

```
输入：
["BrowserHistory","visit","visit","visit","back","back","forward","visit","forward","back","back"]
[["leetcode.com"],["google.com"],["facebook.com"],["youtube.com"],[1],[1],[1],["linkedin.com"],[2],[2],[7]]
输出：
[null,null,null,null,"facebook.com","google.com","facebook.com",null,"linkedin.com","google.com","leetcode.com"]

解释：
BrowserHistory("leetcode.com")   // 初始页: leetcode.com
visit("google.com")               // history: [leetcode, google], cur=1
visit("facebook.com")             // history: [leetcode, google, facebook], cur=2
visit("youtube.com")              // history: [leetcode, google, facebook, youtube], cur=3
back(1)                           // cur=2, return "facebook.com"
back(1)                           // cur=1, return "google.com"
forward(1)                        // cur=2, return "facebook.com"
visit("linkedin.com")             // history: [leetcode, google, facebook, linkedin], cur=3
forward(2)                        // cur=3（到头了）, return "linkedin.com"
back(2)                           // cur=1, return "google.com"
back(7)                           // cur=0, return "leetcode.com"
```

**提示：**
- `1 <= homepage.length <= 20`
- `1 <= url.length <= 20`
- `1 <= steps <= 100`
- `homepage` 和 `url` 都只包含小写英文字母和 `.`
- 最多调用 `5000` 次 `visit`、`back` 和 `forward` 函数

---

## 解题思路

**核心思想：** 用一个列表（数组）存储历史记录，用一个指针 `cur` 记录当前位置。

- `visit(url)`：将 `url` 插入 `cur+1` 位置，清除之后的历史，更新 `cur = cur + 1`。
- `back(steps)`：`cur = max(0, cur - steps)`，返回 `history[cur]`。
- `forward(steps)`：`cur = min(len-1, cur + steps)`，返回 `history[cur]`。

---

## Python 代码实现

### 方法一：列表 + 指针（推荐）

```python
class BrowserHistory:

    def __init__(self, homepage: str):
        self.history = [homepage]  # 历史记录列表
        self.cur = 0               # 当前页面的指针

    def visit(self, url: str) -> None:
        # 截断当前位置之后的历史，插入新页面
        self.history = self.history[:self.cur + 1]
        self.history.append(url)
        self.cur += 1              # 指针前进一步

    def back(self, steps: int) -> str:
        # 后退 steps 步，但不能超过头部
        self.cur = max(0, self.cur - steps)
        return self.history[self.cur]

    def forward(self, steps: int) -> str:
        # 前进 steps 步，但不能超过尾部
        self.cur = min(len(self.history) - 1, self.cur + steps)
        return self.history[self.cur]
```

### 方法二：双栈模拟（后退栈 + 前进栈）

```python
class BrowserHistory:

    def __init__(self, homepage: str):
        self.back_stack = [homepage]  # 后退历史（当前页也在栈顶）
        self.forward_stack = []       # 前进历史

    def visit(self, url: str) -> None:
        self.back_stack.append(url)   # 访问新页面，压入后退栈
        self.forward_stack.clear()    # 清空前进历史

    def back(self, steps: int) -> str:
        # 将当前页移到前进栈，直到后退了 steps 步或只剩一页
        while steps > 0 and len(self.back_stack) > 1:
            self.forward_stack.append(self.back_stack.pop())
            steps -= 1
        return self.back_stack[-1]    # 返回后退后的当前页

    def forward(self, steps: int) -> str:
        # 将前进栈顶移到后退栈，直到前进了 steps 步或前进栈为空
        while steps > 0 and self.forward_stack:
            self.back_stack.append(self.forward_stack.pop())
            steps -= 1
        return self.back_stack[-1]    # 返回前进后的当前页
```

### 方法三：双端队列（Deque）优化

```python
from collections import deque

class BrowserHistory:

    def __init__(self, homepage: str):
        self.history = [homepage]  # 历史记录
        self.cur = 0               # 当前位置
        self.end = 0               # 有效历史的末尾

    def visit(self, url: str) -> None:
        self.cur += 1
        # 如果当前位置超出列表范围，追加；否则覆盖
        if self.cur < len(self.history):
            self.history[self.cur] = url
        else:
            self.history.append(url)
        self.end = self.cur  # 更新有效末尾

    def back(self, steps: int) -> str:
        self.cur = max(0, self.cur - steps)
        return self.history[self.cur]

    def forward(self, steps: int) -> str:
        self.cur = min(self.end, self.cur + steps)
        return self.history[self.cur]
```

## 复杂度分析

| 方法 | visit | back | forward | 空间 |
|------|-------|------|---------|------|
| 列表+指针 | O(n)（切片） | O(1) | O(1) | O(n) |
| 双栈 | O(1) | O(steps) | O(steps) | O(n) |
| 列表+端点指针 | O(1) | O(1) | O(1) | O(n) |

- 方法三（列表+端点指针）是最优方案，所有操作均为 O(1)。
- 方法一中 `visit` 的切片操作是 O(n)，在最坏情况下较慢。

---

## 关键点总结

1. 浏览器历史本质上是一个**带指针的线性结构**，`visit` 时截断后续历史。
2. 双栈模拟：后退栈保存历史，前进栈保存前进历史，`visit` 清空前进栈。
3. 最优方案（方法三）：用 `end` 指针标记有效历史末尾，`visit` 时原地覆盖，避免切片。
4. `back` 和 `forward` 要用 `max`/`min` 防止越界。

---

## 易错点

- **`visit` 时忘记清空前进历史**：访问新页面后，前进历史应该失效。
- **`back` 和 `forward` 越界**：要用 `max(0, ...)` 和 `min(len-1, ...)` 限制范围。
- **方法一切片复制**：`history[:cur+1]` 会创建新列表，频繁操作时性能较差。
