## 题目描述

给你两个字符串 `s` 和 `t`，可以从 `s` 中删除**最多一个字符**，使得 `s` 和 `t` 的**最长公共前缀**尽可能长。

返回最长公共前缀的长度。

**示例 1：**

```
输入：s = "madxa", t = "madam"
输出：4
解释：从 s 删除 'x'，得 "mada"，与 t 的公共前缀 "mada"，长度 4
```

**示例 2：**

```
输入：s = "abc", t = "abc"
输出：3
解释：不删除任何字符，公共前缀 "abc"
```

**提示：**
- `1 <= s.length, t.length <= 10^5`

## 解题思路

双指针：先找不删除时的公共前缀长度 `base`。然后在第一个不匹配位置，尝试删除 s[base]（跳过），继续比较 s[base+1..] 和 t[base..]。

## Python 代码实现

### 方法一：双指针

```python
class Solution:
    def longestCommonPrefix(self, s: str, t: str) -> int:
        n, m = len(s), len(t)

        # 找第一个不匹配位置
        i = 0
        while i < n and i < m and s[i] == t[i]:
            i += 1

        # i 是第一个不匹配位置
        # 不删除：公共前缀长度 = i
        # 删除 s[i]：继续比较 s[i+1..] 和 t[i..]
        if i == n or i == m:
            return i  # 其中一个已经耗尽，无需删除

        # 尝试删除 s[i]
        base = i
        si, ti = i + 1, i
        while si < n and ti < m and s[si] == t[ti]:
            si += 1
            ti += 1

        extra = ti - base  # 删除后额外匹配的长度

        return base + extra
```

### 方法二：考虑更多情况

```python
class Solution:
    def longestCommonPrefix(self, s: str, t: str) -> int:
        n, m = len(s), len(t)

        def match_len(si, ti):
            """从 s[si] 和 t[ti] 开始，匹配的长度"""
            count = 0
            while si < n and ti < m and s[si] == t[ti]:
                si += 1
                ti += 1
                count += 1
            return count

        # 不删除
        base = match_len(0, 0)

        if base == min(n, m):
            return base

        # 在第一个不匹配位置 base，删除 s[base]
        extra = match_len(base + 1, base)

        return base + extra
```

### 方法三：暴力枚举（适合小规模）

```python
class Solution:
    def longestCommonPrefix(self, s: str, t: str) -> int:
        def lcp(a, b):
            i = 0
            while i < len(a) and i < len(b) and a[i] == b[i]:
                i += 1
            return i

        # 不删除
        best = lcp(s, t)

        # 删除 s[i]（对每个 i）
        for i in range(len(s)):
            new_s = s[:i] + s[i+1:]
            val = lcp(new_s, t)
            best = max(best, val)

        return best
```

## 复杂度分析

- 方法一：O(n + m)
- 方法三（暴力）：O(n^2)

## 关键点总结

1. 先找不删除时的公共前缀长度
2. 在第一个不匹配位置，删除 s 中该字符，继续比较
3. 删除 t 中字符无意义（公共前缀是 s 和 t 的共同部分）

## 易错点

1. 只删除一个字符，且只在 s 中删除（不在 t 中）
2. 删除的字符要在第一个不匹配位置（其他位置删除不会增加公共前缀）
3. 删除后继续比较的起点是 (base+1, base)，而非从头开始
