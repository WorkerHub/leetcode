## 题目描述

给你一个字符串 `s`，字符串的**幂字符串**是指一个由某个字母重复至少一次而形成的非空字符串（即连续相同字符组成的子字符串）。

返回字符串 `s` 中最长的幂字符串的长度。

**示例 1：**
```
输入：s = "leetcode"
输出：2
解释：子字符串 "ee" 是最长的幂字符串。
```

**示例 2：**
```
输入：s = "abbcccddddeeeeedcba"
输出：5
解释：子字符串 "eeeee" 是最长的幂字符串。
```

**示例 3：**
```
输入：s = "triplepillooooow"
输出：5
```

**示例 4：**
```
输入：s = "hooraaaaaaaaaaay"
输出：11
```

**示例 5：**
```
输入：s = "tourist"
输出：1
```

**提示：**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 解题思路

**一次遍历计数：**

维护一个计数器 `count`，记录当前连续相同字符的长度：
1. 从第二个字符开始遍历。
2. 若当前字符与前一个字符相同，`count += 1`。
3. 若不同，重置 `count = 1`。
4. 每步都更新最大值。

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
class Solution:
    def maxPower(self, s: str) -> int:
        if not s:
            return 0

        max_len = 1
        count = 1

        for i in range(1, len(s)):
            if s[i] == s[i - 1]:
                count += 1          # 与前一字符相同，连续长度加 1
                max_len = max(max_len, count)
            else:
                count = 1           # 字符不同，重置计数

        return max_len
```

### 方法二：itertools.groupby（Python 内置）

```python
from itertools import groupby

class Solution:
    def maxPower(self, s: str) -> int:
        # groupby 将连续相同字符分组，返回 (字符, 迭代器)
        return max(sum(1 for _ in group) for _, group in groupby(s))
```

**注意：** `groupby` 非常简洁，但每次调用 `sum(1 for _ in group)` 等价于 `len(list(group))`。

### 方法三：正则表达式

```python
import re

class Solution:
    def maxPower(self, s: str) -> int:
        # 匹配所有连续相同字符的组，取最长的长度
        return max(len(m.group()) for m in re.finditer(r'(.)\1*', s))
```

**正则解释：** `(.)` 匹配任意字符并捕获，`\1*` 匹配零或更多个与捕获组相同的字符。`(.)\1*` 匹配一个或多个连续相同字符的子串。

### 方法四：双指针（滑动窗口）

```python
class Solution:
    def maxPower(self, s: str) -> int:
        max_len = 0
        left = 0

        for right in range(len(s)):
            if s[right] != s[left]:
                left = right  # 重置窗口起点

            max_len = max(max_len, right - left + 1)

        return max_len
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历字符串一次。
- **空间复杂度：** O(1)，仅用常数空间（方法二的 `groupby` 是惰性求值，也是 O(1)）。

## 关键点总结

1. 问题本质是"最长连续相同字符子串"，一次遍历即可解决。
2. Python 的 `itertools.groupby` 天然支持分组，非常适合此类问题。
3. 正则表达式 `(.)\1*` 用反向引用实现连续相同字符的匹配。
4. 双指针（方法四）也是处理"连续满足条件的子串"的通用框架。

## 易错点

- 初始化 `count = 0` 而非 `count = 1`，导致单字符的情况返回 0。
- 忘记更新 `max_len`，只返回最终的 `count`（会错过中间的最大值）。
- 方法二/三：如果 `s` 为空，`max()` 会报错，需要处理边界（题目保证 `len >= 1`）。
