## 题目描述

给你一个长度为 `n` 的整数数组 `receiver` 和一个整数 `k`。

有 `n` 名玩家，编号 0 到 n-1。`receiver[i]` 是玩家 `i` 将球传给的下一个玩家。玩家可以传球给自己（`receiver[i] = i`）。

传球游戏共进行 `k` 轮，从某个玩家 `x` 开始传球。**传球函数值** = 在 `k` 次传球中接球的玩家编号之和（包括初始持球者 x）。

返回所有 `x` 中传球函数值的最大值。

**示例 1：**
```
输入：receiver = [2,0,1], k = 4
输出：6
解释：从 x=2 开始：2->1->0->2->1，总和 = 2+1+0+2+1 = 6
```

**示例 2：**
```
输入：receiver = [1,1,0,2,3], k = 3
输出：10
解释：从 x=4 开始：4->3->2->0，总和 = 4+3+2+0 = 9？等等
实际上传球 k 轮，共 k+1 个数（包括自己）
k=3，接球次数含初始：4+3+2+0=9
还是 4+3+2+0+1=10（k+1次）
```

**提示：**
- `1 <= receiver.length <= 10^5`
- `0 <= receiver[i] <= n-1`
- `1 <= k <= 10^10`

## 解题思路

**二进制提升（Binary Lifting）：**

由于 k 可以很大（10^10），不能逐步模拟。

`jump[i][j]` = 从玩家 i 出发，传球 `2^j` 次后到达的玩家。
`sum[i][j]` = 从玩家 i 出发，传球 `2^j` 次过程中，接球玩家编号之和（不含 i 自身）。

通过二进制拆解 k：将 k 分解为若干 2^j 的和，逐步跳跃，累积玩家编号之和。

**初始化：**
- `jump[i][0] = receiver[i]`（一步后到达的玩家）
- `sum[i][0] = receiver[i]`（一步的接球玩家）

**转移：**
- `jump[i][j] = jump[jump[i][j-1]][j-1]`（分两半跳）
- `sum[i][j] = sum[i][j-1] + sum[jump[i][j-1]][j-1]`（两半之和）

**查询：** 从 x 出发传 k 次：
- 初始化 `cur = x`, `total = x`
- 对 k 的每一个二进制位 j（若该位为 1）：
  - `total += sum[cur][j]`（加上这 2^j 步的玩家之和）
  - `cur = jump[cur][j]`

## Python 代码实现

### 方法一：二进制提升（推荐）

```python
from typing import List

class Solution:
    def getMaxFunctionValue(self, receiver: List[int], k: int) -> int:
        n = len(receiver)
        LOG = k.bit_length()  # 最大需要的二进制位数

        # jump[j][i] = 从 i 出发，传球 2^j 次后的玩家
        # sum_val[j][i] = 从 i 出发，传球 2^j 次接球玩家编号之和（不含 i）
        jump = [[0] * n for _ in range(LOG + 1)]
        sum_val = [[0] * n for _ in range(LOG + 1)]

        # 初始化：2^0 = 1 次传球
        for i in range(n):
            jump[0][i] = receiver[i]
            sum_val[0][i] = receiver[i]

        # 倍增预处理
        for j in range(1, LOG + 1):
            for i in range(n):
                jump[j][i] = jump[j-1][jump[j-1][i]]
                sum_val[j][i] = sum_val[j-1][i] + sum_val[j-1][jump[j-1][i]]

        ans = 0
        # 枚举起始玩家 x
        for x in range(n):
            total = x  # 包含自身
            cur = x
            remaining = k
            j = 0
            while remaining > 0:
                if remaining & 1:
                    total += sum_val[j][cur]
                    cur = jump[j][cur]
                remaining >>= 1
                j += 1
            ans = max(ans, total)

        return ans
```

### 方法二：更清晰的实现

```python
from typing import List

class Solution:
    def getMaxFunctionValue(self, receiver: List[int], k: int) -> int:
        n = len(receiver)
        LOG = max(1, k.bit_length())

        # 二进制提升表
        anc = [list(receiver)]  # anc[0][i] = receiver[i]
        s = [list(receiver)]    # s[0][i] = receiver[i]

        for _ in range(1, LOG + 1):
            prev_anc = anc[-1]
            prev_s = s[-1]
            new_anc = [prev_anc[prev_anc[i]] for i in range(n)]
            new_s = [prev_s[i] + prev_s[prev_anc[i]] for i in range(n)]
            anc.append(new_anc)
            s.append(new_s)

        ans = 0
        for x in range(n):
            total = x
            cur = x
            bits = k
            j = 0
            while bits:
                if bits & 1:
                    total += s[j][cur]
                    cur = anc[j][cur]
                bits >>= 1
                j += 1
            ans = max(ans, total)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n × log k)，预处理和查询各 O(n log k)
- 空间复杂度：O(n × log k)，二进制提升表

## 关键点总结

1. 二进制提升：O(log k) 级别的跳跃，代替逐步模拟
2. 维护两个表：跳跃后的位置 + 路径上的玩家之和
3. 最终答案包含起始玩家 x 自身（total 初始化为 x）

## 易错点

1. total 要包含起始玩家 x（不只是传球过程中的玩家）
2. k 次传球意味着共有 k+1 个玩家（含初始）：x, receiver[x], ...，因此 sum_val 存的是 k 步中接球玩家的和，total = x + sum_val
3. LOG 的大小：`k.bit_length()` 即可
