## 题目描述

`n` 个球排成一行，用字符串 `s` 表示，`s[i] = '0'` 为白球，`s[i] = '1'` 为黑球。

每次操作：交换相邻两个球。

返回使所有黑球（`'1'`）都在白球（`'0'`）右边所需的最少操作次数。

**示例 1：**
```
输入：s = "101"
输出：1
解释：交换下标 1 和 2，得 "110"
```

**示例 2：**
```
输入：s = "100"
输出：2
```

**提示：**
- `1 <= n <= 10^5`
- `s[i] == '0'` 或 `s[i] == '1'`

## 解题思路

贪心：从左到右遍历，每遇到一个 '0'（白球），它需要移到已经处理的 '1' 的左边。

等价思路：统计每个 '0' 需要"越过"多少个 '1'。

从左到右遍历，维护已经见过的 '1' 的个数 `ones`。每遇到 '0'，它需要向左移动 `ones` 步（越过 ones 个黑球）。

## Python 代码实现

### 方法一：贪心统计（推荐）

```python
class Solution:
    def minimumSteps(self, s: str) -> int:
        ans = 0
        ones = 0  # 当前位置左边（包含当前）的 '1' 的数量
        for c in s:
            if c == '1':
                ones += 1
            else:
                # 当前 '0' 需要越过 ones 个 '1'
                ans += ones
        return ans
```

### 方法二：双指针

```python
class Solution:
    def minimumSteps(self, s: str) -> int:
        n = len(s)
        # 找每个 '0' 的目标位置
        # 所有 '0' 的目标位置是 0, 1, 2, ...（从左到右）
        # 第 k 个 '0' 需要从当前位置移到位置 k-1
        # 操作数 = 当前位置 - 目标位置 = 当前位置 - (k-1)
        # = (pos - target)，等于当前位置之前有多少个 '1'
        ans = 0
        zero_count = 0
        for i, c in enumerate(s):
            if c == '0':
                # 第 zero_count 个 '0'（从0编号），目标位置是 zero_count
                # 当前位置 i，越过 (i - zero_count) 个 '1'
                ans += i - zero_count
                zero_count += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每个 '0' 要移到所有 '1' 的左边，等价于越过其前面所有的 '1'
2. 维护 `ones` 计数器，每遇到 '0' 累加当前 ones 值
3. 不需要模拟实际交换过程，直接统计每个 '0' 的移动代价

## 易错点

1. 操作是相邻交换，每次交换等于一次操作
2. '0' 需要移过的 '1' 的个数等于其左侧已有的 '1' 的数量
3. 答案可能很大（long）
