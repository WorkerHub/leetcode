## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次旋转后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：

- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` 旋转一次的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`。

给你一个元素值互不相同的数组 `nums`，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的最小元素。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入: nums = [3,4,5,1,2]
输出: 1
解释: 原数组为 [1,2,3,4,5]，旋转 3 次得到输入数组。
```

**示例 2：**

```
输入: nums = [4,5,6,7,0,1,2]
输出: 0
解释: 原数组为 [0,1,2,4,5,6,7]，旋转 4 次得到输入数组。
```

**示例 3：**

```
输入: nums = [11,13,15,17]
输出: 11
解释: 原数组为 [11,13,15,17]，旋转 4 次（即不旋转）得到输入数组。
```

**提示：**

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数互不相同
- `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转

## 解题思路

旋转排序数组的特点：
- 数组被分为两个递增的部分
- 最小值是旋转点（两部分的分界点）
- 如果没有旋转，数组仍然有序

**二分查找思路：**

1. 如果 `nums[mid] > nums[right]`：
   - 说明最小值在右半部分（包括 mid 右边）
   - `left = mid + 1`

2. 如果 `nums[mid] < nums[right]`：
   - 说明右半部分是有序的，最小值在左半部分（包括 mid）
   - `right = mid`

3. 最终 `left == right`，指向最小值

**为什么和 nums[right] 比较？**

- 和 `nums[left]` 比较无法确定最小值位置
- 和 `nums[right]` 比较可以判断哪一半是旋转的

**图示理解：**

```
[3, 4, 5, 1, 2]
     mid
nums[mid]=5 > nums[right]=2 -> 最小值在右边

[1, 2, 3, 4, 5]
     mid
nums[mid]=3 < nums[right]=5 -> 最小值在左边（可能是mid）
```

## Python 代码实现

### 方法一：二分查找（标准解法，推荐）

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 中间值大于右边值，说明最小值在右半部分
            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                # 中间值小于等于右边值，最小值在左半部分（包括mid）
                right = mid
        
        return nums[left]
```

### 方法二：二分查找（另一种写法）

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        
        # 如果数组没有旋转，直接返回第一个元素
        if nums[left] < nums[right]:
            return nums[left]
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 和最右边元素比较
            if nums[mid] > nums[right]:
                # 最小值在右边
                left = mid + 1
            else:
                # 最小值在左边（包括mid）
                right = mid
        
        return nums[left]
```

### 方法三：二分查找（带详细注释）

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        """
        二分查找旋转数组的最小值
        
        核心思路：
        - 旋转数组分为两段递增序列
        - 最小值是两段的分界点
        - 通过比较 mid 和 right 判断最小值在哪一半
        """
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 情况1: [3,4,5,1,2] mid=5, right=2
            # nums[mid] > nums[right] -> 右半部分被旋转，最小值在右边
            if nums[mid] > nums[right]:
                left = mid + 1
            
            # 情况2: [5,1,2,3,4] mid=2, right=4
            # nums[mid] < nums[right] -> 右半部分有序，最小值在左边
            else:
                right = mid
        
        # 退出循环时 left == right，指向最小值
        return nums[left]
```

### 方法四：递归写法

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        return self.binary_search(nums, 0, len(nums) - 1)
    
    def binary_search(self, nums: List[int], left: int, right: int) -> int:
        # 只剩一个元素
        if left == right:
            return nums[left]
        
        # 数组有序，返回第一个
        if nums[left] < nums[right]:
            return nums[left]
        
        mid = left + (right - left) // 2
        
        if nums[mid] > nums[right]:
            # 最小值在右半部分
            return self.binary_search(nums, mid + 1, right)
        else:
            # 最小值在左半部分
            return self.binary_search(nums, left, mid)
```

### 方法五：暴力法（不满足时间要求，仅供对比）

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        # 直接遍历找最小值
        return min(nums)

# 时间复杂度: O(n)
# 不满足题目要求的 O(log n)
```

## 复杂度分析

**方法一、二、三、四：二分查找**

- 时间复杂度：O(log n)
  - 每次循环排除一半元素
- 空间复杂度：
  - 迭代：O(1)
  - 递归：O(log n) - 递归调用栈

**方法五：暴力法**

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **和右边界比较**：
   - `nums[mid]` 和 `nums[right]` 比较
   - 不要和 `nums[left]` 比较（无法判断）

2. **区间更新规则**：
   - `nums[mid] > nums[right]`：`left = mid + 1`（最小值不是 mid）
   - `nums[mid] < nums[right]`：`right = mid`（最小值可能是 mid）

3. **循环条件**：
   - `while left < right`，而不是 `left <= right`
   - 避免死循环

4. **返回值**：
   - 返回 `nums[left]` 或 `nums[right]`（此时相等）
   - 不要返回 `nums[mid]`

5. **特殊情况**：
   - 数组没有旋转（已经有序）：可以提前判断
   - 只有一个元素：while 循环不执行，直接返回

## 易错点

1. **比较对象错误**：
   - 不要和 `nums[left]` 比较
   - 例如 `[3,1,2]`，mid=1, left=0
   - `nums[mid]=1 < nums[left]=3`，但最小值是 mid

2. **区间更新错误**：
   - `nums[mid] > nums[right]` 时，应该 `left = mid + 1`
   - 不是 `left = mid`（会导致死循环）

3. **循环条件错误**：
   - 使用 `left <= right` 可能导致死循环
   - 正确条件：`left < right`

4. **返回值错误**：
   - 不要返回 `mid`
   - 退出时 `left == right`，返回 `nums[left]`

5. **边界情况未考虑**：
   - 数组长度为 1
   - 数组没有旋转（已经有序）
