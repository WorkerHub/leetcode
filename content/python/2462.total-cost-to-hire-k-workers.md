## 题目描述

给你一个下标从 **0** 开始的整数数组 `costs`，其中 `costs[i]` 是雇用第 `i` 位工人的代价。

同时给你两个整数 `k` 和 `candidates`。我们想根据以下规则恰好雇用 `k` 位工人：

- 总共进行 `k` 轮雇用，且每轮恰好雇用一位工人。
- 在每一轮雇用中，从 **最前面** `candidates` 和 **最后面** `candidates` 个工人中选代价最小的一位工人，如果有多位代价相同且最小的工人，选择下标更小的工人。
- 每次雇用后，已雇用工人不参与下一轮。

返回雇用恰好 `k` 位工人的总代价。

**提示：**
- `1 <= costs.length <= 10^5`
- `1 <= costs[i] <= 10^5`
- `1 <= k, candidates <= costs.length`

## 解题思路

**双指针 + 两个最小堆：**

维护两个最小堆：
- `left_heap`：前 `candidates` 个候选工人的代价（最小堆，含下标）
- `right_heap`：后 `candidates` 个候选工人的代价

用双指针 `l` 和 `r` 追踪当前候选范围的边界。

每次取两个堆中代价最小（相同则下标小）的工人，弹出后若 `l <= r`，从相应端补充一位新候选人。

## 代码实现

### 方法一：双堆 + 双指针（推荐）

```python
from typing import List
import heapq

class Solution:
    def totalCost(self, costs: List[int], k: int, candidates: int) -> int:
        n = len(costs)
        l, r = candidates - 1, n - candidates  # 当前候选范围边界

        # 初始化两个最小堆
        left_heap = [(costs[i], i) for i in range(min(candidates, n))]
        right_heap = []
        for i in range(max(n - candidates, candidates), n):
            if i > l:  # 避免与左堆重叠
                right_heap.append((costs[i], i))

        heapq.heapify(left_heap)
        heapq.heapify(right_heap)

        total = 0

        for _ in range(k):
            left_top = left_heap[0] if left_heap else (float('inf'), float('inf'))
            right_top = right_heap[0] if right_heap else (float('inf'), float('inf'))

            if left_top <= right_top:
                cost, idx = heapq.heappop(left_heap)
                total += cost
                l += 1
                if l <= r:
                    heapq.heappush(left_heap, (costs[l], l))
            else:
                cost, idx = heapq.heappop(right_heap)
                total += cost
                r -= 1
                if l <= r:
                    heapq.heappush(right_heap, (costs[r], r))

        return total
```

### 方法二：简化实现

```python
from typing import List
import heapq

class Solution:
    def totalCost(self, costs: List[int], k: int, candidates: int) -> int:
        n = len(costs)
        l, r = 0, n - 1
        left_heap, right_heap = [], []

        # 初始化左堆
        for _ in range(candidates):
            if l <= r:
                heapq.heappush(left_heap, (costs[l], l))
                l += 1

        # 初始化右堆（不与左堆重叠）
        for _ in range(candidates):
            if l <= r:
                heapq.heappush(right_heap, (costs[r], r))
                r -= 1

        total = 0

        for _ in range(k):
            l_top = left_heap[0] if left_heap else (float('inf'), float('inf'))
            r_top = right_heap[0] if right_heap else (float('inf'), float('inf'))

            if l_top <= r_top:
                cost, _ = heapq.heappop(left_heap)
                total += cost
                if l <= r:
                    heapq.heappush(left_heap, (costs[l], l))
                    l += 1
            else:
                cost, _ = heapq.heappop(right_heap)
                total += cost
                if l <= r:
                    heapq.heappush(right_heap, (costs[r], r))
                    r -= 1

        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双堆 + 双指针 | O((k + candidates) * log(candidates)) | O(candidates) |

## 关键点总结

1. 左右两个最小堆各维护 `candidates` 个候选工人
2. 每次从两堆中取最小（相同时取下标小的）
3. 弹出后需补充一个新候选工人（若范围未耗尽）

## 易错点

- 左右堆初始化时不能有重叠（`l <= r` 保证互不重叠）
- 元组比较 `(cost, idx)` 自然地实现了「代价相同取下标小」的逻辑
