## 题目描述

数对 `(a,b)` 由整数 `a` 和 `b` 组成，其数对距离定义为 `a` 和 `b` 的绝对差值。

给你一个整数数组 `nums` 和一个整数 `k`，数对由 `nums[i]` 和 `nums[j]` 组成且满足 `0 <= i < j < nums.length`。返回 **所有数对距离中** 第 `k` 小的数对距离。

**示例 1：**

```
输入：nums = [1,3,1], k = 1
输出：0
解释：数对和对应的距离如下：
(1,3) -> 2
(1,1) -> 0
(3,1) -> 2
距离第 1 小的数对是 (1,1) ，距离为 0 。
```

**示例 2：**

```
输入：nums = [1,1,1], k = 2
输出：0
```

**示例 3：**

```
输入：nums = [1,6,1], k = 3
输出：5
```

**提示：**
- `n == nums.length`
- `2 <= n <= 10^4`
- `0 <= nums[i] <= 10^6`
- `1 <= k <= n * (n - 1) / 2`

## 解题思路

**核心思想：二分查找 + 双指针**

直接枚举所有数对会超时，使用二分查找答案。

**算法流程：**
1. 对数组排序
2. 二分查找距离 `mid`
3. 统计距离小于等于 `mid` 的数对个数
4. 根据个数调整二分范围

## Python 代码实现

### 方法一：二分查找 + 双指针（推荐）⭐

```python
from typing import List

class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        
        def count_pairs(mid: int) -> int:
            """统计距离小于等于 mid 的数对个数"""
            count = 0
            left = 0
            
            for right in range(n):
                while nums[right] - nums[left] > mid:
                    left += 1
                count += right - left
            
            return count
        
        # 二分查找距离
        left, right = 0, nums[-1] - nums[0]
        
        while left < right:
            mid = (left + right) // 2
            if count_pairs(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        return left
```

### 方法二：带注释详细版

```python
class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        # 排序，方便计算距离
        nums.sort()
        n = len(nums)
        
        def count_pairs_with_distance_le(distance: int) -> int:
            """
            使用双指针统计距离 <= distance 的数对个数
            时间复杂度 O(n)
            """
            count = 0
            left = 0
            
            for right in range(n):
                # 移动左指针，直到 nums[right] - nums[left] <= distance
                while nums[right] - nums[left] > distance:
                    left += 1
                
                # [left, right) 之间的所有元素都满足条件
                count += right - left
            
            return count
        
        # 二分查找第 k 小的距离
        # 最小距离是 0，最大距离是 max - min
        min_dist = 0
        max_dist = nums[-1] - nums[0]
        
        while min_dist < max_dist:
            mid_dist = (min_dist + max_dist) // 2
            
            # 统计距离 <= mid_dist 的数对个数
            pairs_count = count_pairs_with_distance_le(mid_dist)
            
            if pairs_count < k:
                # 数对太少，距离要增大
                min_dist = mid_dist + 1
            else:
                # 数对足够，尝试更小的距离
                max_dist = mid_dist
        
        return min_dist
```

## 复杂度分析

- **时间复杂度：** O(n log n + n log D)
  - 排序：O(n log n)
  - 二分：O(log D)，D 是最大距离
  - 每次统计：O(n)
  
- **空间复杂度：** O(log n)，排序栈空间

## 关键点总结

1. **二分答案**：二分距离而不是枚举数对
2. **双指针统计**：O(n) 统计小于等于某距离的数对数
3. **排序优化**：排序后可以使用双指针
4. **边界确定**：最小 0，最大是数组最大差值

## 易错点

1. **二分边界**：是 `left < right` 不是 `left <= right`
2. **计数逻辑**：`right - left` 不是 `right - left + 1`
3. **排序遗漏**：必须先排序
4. **数对定义**：`i < j`，不要重复计数
