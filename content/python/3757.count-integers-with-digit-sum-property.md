## 题目描述

给定整数 `n`，统计 `[1, n]` 范围内，满足"数字之和等于某个完全平方数"的整数数量。

**示例 1：**
```
输入：n = 20
输出：14
解释：数字之和为完全平方数（1,4,9,16...）的整数：
     和=1：1,10
     和=4：4,13,22(>20),31(>20),40(>20)... -> 4,13
     和=9：9,18,27(>20)... -> 9,18
     和=16：7,16
     共 1+2+2+2+7=? 让我重新数：1,4,9,10,13,16,18... 继续。
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

数位 DP。对于 [1, n] 范围内，满足数字和为完全平方数的整数计数。

数字和范围：1 到 9*9 = 81（10^9 最多 9 位，每位最大 9，所以数字和最大为 81）。

完全平方数 <= 81：1, 4, 9, 16, 25, 36, 49, 64, 81。

对每个完全平方数 `t`，用数位 DP 统计 [1, n] 中数字和等于 t 的整数数量，累加即为答案。

## Python 代码实现

### 方法一：数位 DP（推荐）

```python
from functools import lru_cache

class Solution:
    def countIntegers(self, n: int) -> int:
        digits = str(n)
        length = len(digits)

        @lru_cache(maxsize=None)
        def dp(pos: int, digit_sum: int, tight: bool, started: bool) -> int:
            if pos == length:
                return 1 if started and is_perfect_square(digit_sum) else 0

            limit = int(digits[pos]) if tight else 9
            count = 0

            for d in range(0, limit + 1):
                if d == 0 and not started:
                    count += dp(pos + 1, 0, tight and d == limit, False)
                else:
                    count += dp(pos + 1, digit_sum + d, tight and d == limit, True)

            return count

        def is_perfect_square(x: int) -> bool:
            if x <= 0:
                return False
            r = int(x ** 0.5)
            return r * r == x or (r+1)*(r+1) == x

        return dp(0, 0, True, False)
```

### 方法二：枚举目标和

```python
import math

class Solution:
    def countIntegers(self, n: int) -> int:
        def count_with_sum(n: int, target: int) -> int:
            """统计 [1,n] 中数字和等于 target 的整数数"""
            digits = str(n)
            length = len(digits)
            from functools import lru_cache

            @lru_cache(maxsize=None)
            def dp(pos, rem, tight, started):
                if pos == length:
                    return 1 if started and rem == 0 else 0
                limit = int(digits[pos]) if tight else 9
                result = 0
                for d in range(min(limit, rem) + 1 if started else limit + 1):
                    if d == 0 and not started:
                        result += dp(pos+1, rem, tight and d == limit, False)
                    elif d <= rem:
                        result += dp(pos+1, rem - d, tight and d == limit, True)
                return result

            dp.cache_clear()
            return dp(0, target, True, False)

        # 完全平方数 <= 81
        total = 0
        r = 1
        while r * r <= 81:
            total += count_with_sum(n, r * r)
            r += 1
        return total
```

## 复杂度分析

- 时间复杂度：O(L * S * 10)，L 为位数，S 为最大数字和（81）
- 空间复杂度：O(L * S)

## 关键点总结

1. 数字和上界为 81（10^9 范围内），完全平方数不多
2. 数位 DP 的标准套路：pos（当前位）、digit_sum（累积数字和）、tight（是否紧贴上界）
3. 对每个目标完全平方数分别统计，再求和

## 易错点

1. 完全平方数判断要注意浮点误差，用整数平方根
2. "started" 标志处理前导零
