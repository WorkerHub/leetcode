## 题目描述

给你一个长度为偶数的二进制字符串 `s`。

如果字符串可以被分成一个或多个满足下列条件的子字符串，则认为该字符串是 **美丽** 的：
- 每个子字符串的长度为偶数
- 每个子字符串只含 `'1'` 或只含 `'0'`

返回使字符串 `s` 变为美丽字符串所需的 **最少字符修改次数**。

**示例 1：**
```
输入：s = "1001"
输出：2
解释：将 s 变为 "0000" 或 "1111" 均需 2 次修改
```

**示例 2：**
```
输入：s = "10"
输出：1
```

**示例 3：**
```
输入：s = "0000"
输出：0
```

**提示：**
- `2 <= s.length <= 10^5`
- `s.length` 是偶数
- `s` 只含 `'0'` 和 `'1'`

## 解题思路

将字符串按 2 个字符分组（(0,1), (2,3), (4,5), ...）。对于每一对字符：
- 若两个字符相同，无需修改
- 若两个字符不同，必须修改一个，代价为 1

因此只需统计相邻两两不同的对数。

## Python 代码实现

### 方法一：按对检查（推荐）

```python
class Solution:
    def minChanges(self, s: str) -> int:
        ans = 0
        # 每次看两个字符一对
        for i in range(0, len(s), 2):
            if s[i] != s[i + 1]:
                ans += 1
        return ans
```

### 方法二：利用异或运算

```python
class Solution:
    def minChanges(self, s: str) -> int:
        # s[i] != s[i+1] 等价于 s[i] XOR s[i+1] == 1
        return sum(s[i] != s[i + 1] for i in range(0, len(s), 2))
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有字符对
- 空间复杂度：O(1)，只用常数空间

## 关键点总结

1. 贪心思想：按位置 (0,1), (2,3), ... 分组，每组内两字符必须相同
2. 不需要考虑合并相邻组，每对独立处理
3. 每对不同则代价恰好为 1（改一个字符即可）

## 易错点

1. 字符串长度保证为偶数，不需要处理奇数长度情况
2. 不能跨对修改：修改第 1 对不影响第 2 对
