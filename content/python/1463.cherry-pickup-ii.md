## 题目描述

给你一个 `rows x cols` 的矩阵 `grid` 来表示一块樱桃地，`grid[i][j]` 表示在该位置的樱桃数量。

你有两台机器人，机器人 1 从左上角格子 `(0,0)` 出发，机器人 2 从右上角格子 `(0, cols-1)` 出发。

每台机器人在每一步移动都可以从当前格子向下一行走到三个可能的格子：正下方、左下方、右下方。

每台机器人都需要走到最底行，机器人收集当前位置的所有樱桃。**如果两台机器人停在同一位置，该位置的樱桃只能被收集一次**。

返回两台机器人能收集到的最多樱桃数量。

**示例 1：**
```
输入：grid = [[3,1,1],[2,5,1],[1,5,5],[2,1,1]]
输出：24
解释：路径如下：
机器人 1：(0,0) -> (1,0) -> (2,1) -> (3,0)，收集樱桃：3+2+5+2 = 12
机器人 2：(0,3) -> (1,3) -> (2,3) -> (3,3)，收集樱桃：1+1+5+1 = 8
但更优的路径是：
机器人 1：(0,0) -> (1,1) -> (2,2) -> (3,1)，收集 3+5+5+1 = 14
机器人 2：(0,3) -> (1,2) -> (2,3) -> (3,3)，收集 1+1+5+1 = 8
...实际答案 24 是另一种组合
```

**提示：**
- `rows == grid.length`
- `cols == grid[i].length`
- `2 <= rows, cols <= 70`
- `0 <= grid[i][j] <= 100`

## 解题思路

**同步 DP：两个机器人同时向下移动**

关键思路：两个机器人每一步都从第 `r` 行移动到第 `r+1` 行，可以同步模拟。

**状态定义：** `dp[r][c1][c2]` 表示到达第 r 行时，机器人 1 在列 c1、机器人 2 在列 c2，两者能收集的最大樱桃数。

**状态转移：**

每一步，两台机器人各自有 3 种移动方向（左下、正下、右下），共 9 种组合：

```
对于每种 (dc1, dc2) in {-1,0,1} × {-1,0,1}：
  new_c1 = c1 + dc1
  new_c2 = c2 + dc2
  若 new_c1, new_c2 都在有效范围内：
    樱桃数 = grid[r][new_c1] + grid[r][new_c2]
    若 new_c1 == new_c2：樱桃数减半（只算一次）
    dp[r][new_c1][new_c2] = max(..., dp[r-1][c1][c2] + 樱桃数)
```

**初始化：**

`dp[0][0][cols-1] = grid[0][0] + grid[0][cols-1]`（起始位置收集樱桃）

如果起始时两者在同一列（cols=1），则只收集一次。

## Python 代码实现

### 方法一：三维 DP（推荐）

```python
from typing import List

class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        NEG_INF = float('-inf')

        # dp[c1][c2] 表示当前行，机器人1在c1、机器人2在c2时的最大樱桃数
        # 用滚动数组节省空间
        dp = [[NEG_INF] * cols for _ in range(cols)]

        # 初始化第 0 行
        c1_start, c2_start = 0, cols - 1
        if c1_start == c2_start:
            dp[c1_start][c2_start] = grid[0][c1_start]
        else:
            dp[c1_start][c2_start] = grid[0][c1_start] + grid[0][c2_start]

        # 逐行向下推进
        for r in range(1, rows):
            new_dp = [[NEG_INF] * cols for _ in range(cols)]

            for c1 in range(cols):
                for c2 in range(cols):
                    if dp[c1][c2] == NEG_INF:
                        continue  # 不可达状态，跳过

                    # 枚举两个机器人的所有移动组合（各 3 种）
                    for dc1 in [-1, 0, 1]:
                        for dc2 in [-1, 0, 1]:
                            nc1, nc2 = c1 + dc1, c2 + dc2

                            # 检查新列是否在有效范围内
                            if 0 <= nc1 < cols and 0 <= nc2 < cols:
                                # 收集当前位置的樱桃
                                cherries = grid[r][nc1]
                                if nc1 != nc2:
                                    cherries += grid[r][nc2]

                                new_dp[nc1][nc2] = max(
                                    new_dp[nc1][nc2],
                                    dp[c1][c2] + cherries
                                )

            dp = new_dp

        # 返回最后一行所有状态中的最大值
        return max(dp[c1][c2] for c1 in range(cols) for c2 in range(cols)
                   if dp[c1][c2] != NEG_INF)
```

### 方法二：记忆化递归（自顶向下）

```python
from typing import List
from functools import lru_cache

class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        @lru_cache(maxsize=None)
        def dp(r: int, c1: int, c2: int) -> int:
            """
            从第 r 行开始，机器人1在c1、机器人2在c2，向下能收集的最大樱桃数
            """
            # 收集当前行的樱桃
            cherries = grid[r][c1] + (0 if c1 == c2 else grid[r][c2])

            # 到达最后一行，直接返回
            if r == rows - 1:
                return cherries

            # 尝试所有 9 种移动组合，取最大值
            best = float('-inf')
            for dc1 in [-1, 0, 1]:
                for dc2 in [-1, 0, 1]:
                    nc1, nc2 = c1 + dc1, c2 + dc2
                    if 0 <= nc1 < cols and 0 <= nc2 < cols:
                        best = max(best, dp(r + 1, nc1, nc2))

            return cherries + best

        # 从第 0 行开始，机器人1在列0，机器人2在列cols-1
        return dp(0, 0, cols - 1)
```

## 复杂度分析

- 时间复杂度：O(rows × cols^2 × 9) = O(rows × cols^2)，每个状态 9 种转移
- 空间复杂度：O(cols^2)（滚动数组）或 O(rows × cols^2)（完整 DP 表）

## 图解示例

以示例 1 `grid = [[3,1,1],[2,5,1],[1,5,5],[2,1,1]]` 为例（cols=4）：

```
初始状态（r=0）：
  dp[0][3] = grid[0][0] + grid[0][3] = 3 + 1 = 4
  
r=1 时，从 (c1=0, c2=3) 出发，枚举 9 种移动：
  (0->0, 3->2): 2 + 1 = 3，dp[0][2] = 4+3 = 7
  (0->0, 3->3): 2 + 1 = 3，dp[0][3] = 4+3 = 7
  (0->1, 3->2): 5 + 1 = 6，dp[1][2] = 4+6 = 10
  (0->1, 3->3): 5 + 1 = 6，dp[1][3] = 4+6 = 10
  ...
```

## 关键点总结

1. 两个机器人同步移动：状态用 (行, 列1, 列2) 表示，同行时联合转移
2. 同列时樱桃只计一次：`cherries = grid[r][c1] + (grid[r][c2] if c1 != c2 else 0)`
3. 每步有 9 种移动组合（3×3），都需要枚举
4. 滚动数组优化空间：只保留当前行的 DP 值

## 易错点

- 同格只算一次樱桃，不能简单相加
- 移动方向包括 3 种，不要漏掉"斜向"移动
- 初始化时，两机器人起始列可能相同（当 cols=1 时），需要特殊处理
