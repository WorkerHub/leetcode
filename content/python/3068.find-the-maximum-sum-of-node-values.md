## 题目描述

给你一棵 `n` 个节点的无向树，节点值存储在 `nums` 中，以及整数 `k`。

每次操作，你可以选择树上一条边 `(u, v)`，将 `nums[u]` 和 `nums[v]` 都异或 `k`。

你可以执行任意次操作（包括 0 次），目标是最大化所有节点值的总和。

**示例 1：**
```
输入：nums = [1,2,1], k = 3, edges = [[0,1],[0,2]]
输出：6
```

**提示：**
- `2 <= n <= 2 * 10^4`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`
- `edges.length == n - 1`

## 解题思路

**关键观察：**

每次操作对一条边的两个端点都异或 `k`。若对同一节点操作偶数次，效果抵消；奇数次等于异或一次 `k`。

注意：通过一系列操作，最终效果是某些节点被异或了 `k`，但树的连通性决定了这些节点的"奇偶性约束"——即被异或的节点数必须为**偶数**（因为每条边同时改变两个节点的奇偶性，总奇偶性守恒）。

所以问题转化为：**选择偶数个节点**（可以是 0 个），将其值异或 `k`，使总和最大化。

**贪心：**
1. 对每个节点，计算 `gain[i] = (nums[i] ^ k) - nums[i]`（异或后的增益）
2. 将所有正增益的节点异或（贪心选最优），若选择节点数为奇数，需要去掉增益最小的正增益节点，或加上增益最大的负增益节点

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        n = len(nums)
        # 计算每个节点异或 k 后的增益
        gains = [(nums[i] ^ k) - nums[i] for i in range(n)]

        # 按增益降序排序
        gains.sort(reverse=True)

        # 贪心选择正增益的节点
        total = sum(nums)
        selected = 0
        extra = 0

        for g in gains:
            if g > 0:
                extra += g
                selected += 1
            else:
                break

        # 若选择了偶数个，直接返回
        if selected % 2 == 0:
            return total + extra

        # 选择了奇数个，需要调整
        # 方案1：去掉最小正增益（gains[selected-1]）
        # 方案2：加上最大负增益（gains[selected]，若存在）
        opt1 = extra - gains[selected - 1] if selected > 0 else -float('inf')
        opt2 = extra + gains[selected] if selected < n else -float('inf')

        return total + max(opt1, opt2)
```

### 方法二：更简洁的实现

```python
from typing import List

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        total = sum(nums)
        # 计算所有增益
        gains = sorted([(x ^ k) - x for x in nums], reverse=True)

        extra = 0
        for i in range(0, len(gains) - 1, 2):
            # 每次选两个（保持偶数个约束）
            pair_gain = gains[i] + gains[i + 1]
            if pair_gain > 0:
                extra += pair_gain
            else:
                break

        return total + extra
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 树结构不影响最终结果，关键是**偶数个节点被异或**的约束
2. 贪心选正增益节点，若奇数个则需要调整
3. 两种调整方案取最优

## 易错点

1. 约束是**偶数个**节点被异或，不是任意个
2. 增益可以为负（不异或反而更好）
3. 方案2（加最大负增益）中 `gains[selected]` 可能越界
