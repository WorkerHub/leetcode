## 题目描述

给你一个整数数组 `arr` 和一个目标值 `target`。

请你返回一个整数 `value`，使得将数组中所有大于 `value` 的值变成 `value` 后，数组的和最接近 `target`（最接近意味着两者之差的绝对值最小）。

如果有多个使得和最接近 `target` 的方案，请你返回这些整数中的**最小值**。

请注意，答案不一定是 `arr` 数组中的数字。

**示例 1：**

```
输入：arr = [4,9,3], target = 10
输出：3
解释：当 value=3 时，数组变为 [3,3,3]，和为 9。
     当 value=4 时，数组变为 [4,4,3]，和为 11。
     9 和 11 距离 10 都是 1，但返回较小的 value=3。
```

**示例 2：**

```
输入：arr = [2,3,5], target = 10
输出：5
解释：当 value=5 时，数组变为 [2,3,5]，和为 10（完全等于 target）。
```

**示例 3：**

```
输入：arr = [60864,25176,27249,21296,20204], target = 56803
输出：11361
```

**提示：**

- `1 <= arr.length <= 10^4`
- `1 <= arr[i] <= 10^5`
- `1 <= target <= 10^9`

## 解题思路

### 问题抽象

定义"变换后的数组和"函数 `f(value)`：将 `arr` 中大于 `value` 的元素替换为 `value` 后，求数组之和。

我们需要找到 `value`，使得 `|f(value) - target|` 最小。

### 关键性质：f(value) 是单调递增函数

- `value` 越大，每个元素被截断得越少，因此数组和越大
- `value` 越小，每个元素被截断得越多，因此数组和越小
- 所以 `f(value)` 关于 `value` 单调不减

由于 `f(value)` 单调，可以用**二分查找**确定最优 `value`：
- 二分搜索范围：`[0, max(arr)]`
- 目标：找到使 `f(value)` 最接近 `target` 的 `value`

### 如何高效计算 f(value)？

朴素方法：遍历数组，每个元素取 `min(arr[i], value)`，求和，O(n)。

优化方法：排序后用前缀和 + 二分：
- 设数组已排序，前缀和为 `prefix`
- 找到第一个大于 `value` 的位置 `k`（二分查找）
- `f(value) = prefix[k]（前 k 个不变）+ value * (n - k)（后面的元素截断为 value）`

这样每次计算 `f(value)` 的时间从 O(n) 降为 O(log n)（排序后）。

### 二分策略

二分查找使 `f(value)` 最接近 `target` 的 `value`：

- 当 `f(mid) < target` 时，需要增大 `value`，向右搜索
- 当 `f(mid) > target` 时，需要减小 `value`，向左搜索
- 当 `f(mid) == target` 时，直接返回 `mid`

最终比较 `f(left)` 和 `f(right)` 哪个更接近 `target`（注意若相同距离取较小值）。

## Python 代码实现

### 方法一：排序 + 前缀和 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def findBestValue(self, arr: List[int], target: int) -> int:
        # 排序，方便二分 + 前缀和计算
        arr.sort()
        n = len(arr)

        # 构建前缀和，prefix[i] = arr[0] + arr[1] + ... + arr[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + arr[i]

        def calc_sum(value: int) -> int:
            """计算将所有大于 value 的元素替换为 value 后的数组和"""
            # 找到第一个严格大于 value 的位置
            k = bisect.bisect_right(arr, value)
            # 前 k 个元素不变，后 n-k 个元素变为 value
            return prefix[k] + value * (n - k)

        # 二分查找最优 value，范围 [0, max(arr)]
        lo, hi = 0, arr[-1]  # arr 已排序，arr[-1] 是最大值

        while lo < hi:
            mid = (lo + hi) // 2
            s = calc_sum(mid)
            if s < target:
                # 和太小，需要增大 value
                lo = mid + 1
            else:
                # 和 >= target，尝试减小 value
                hi = mid

        # lo 是使 f(value) >= target 的最小 value
        # 比较 lo 和 lo-1 哪个更接近 target
        # （lo-1 对应 f(value) < target，lo 对应 f(value) >= target）
        sum_lo = calc_sum(lo)
        sum_lo_minus_1 = calc_sum(lo - 1)

        # 若 lo-1 的和距离 target 不超过 lo 的和的距离，返回 lo-1（取较小值）
        if abs(sum_lo_minus_1 - target) <= abs(sum_lo - target):
            return lo - 1
        return lo
```

### 方法二：枚举候选值（简洁，适合面试快速实现）

**观察**：最优的 `value` 一定是 `arr` 中某个值或某两个相邻值之间的某个整数。但实际上，答案 `value` 的范围在 `[0, max(arr)]`，且 `f(value)` 在整数点的变化规律使得只需检查 `arr` 中的值（加上 0）即可找到候选区间。

更简单的做法：直接二分 `[0, max(arr)]` 范围内的所有整数（方法一已经是这样）。

以下是一个不依赖前缀和、直接暴力计算 `f(value)` 的二分版本：

```python
from typing import List

class Solution:
    def findBestValue(self, arr: List[int], target: int) -> int:
        def calc_sum(value: int) -> int:
            """暴力计算变换后数组和，O(n)"""
            return sum(min(x, value) for x in arr)

        # 二分 value 的范围
        lo, hi = 0, max(arr)

        while lo < hi:
            mid = (lo + hi) // 2
            if calc_sum(mid) < target:
                lo = mid + 1
            else:
                hi = mid

        # 比较 lo 和 lo-1
        if abs(calc_sum(lo - 1) - target) <= abs(calc_sum(lo) - target):
            return lo - 1
        return lo
```

**说明**：此版本每次 `calc_sum` 是 O(n)，整体 O(n log M)，其中 M = max(arr)。在 n=10^4, M=10^5 的数据规模下，约 10^4 * 17 ≈ 1.7 * 10^5 次操作，完全可以通过。

### 方法三：暴力枚举所有候选值

最优 `value` 一定在 `[0, max(arr)]` 内，且 `f(value)` 在每个 `arr[i]` 处会发生斜率变化。因此候选值只需检查 `arr` 中的元素：

```python
from typing import List

class Solution:
    def findBestValue(self, arr: List[int], target: int) -> int:
        # 候选 value 为 arr 中每个元素（含 0）
        candidates = sorted(set(arr))

        def calc_sum(value: int) -> int:
            return sum(min(x, value) for x in arr)

        best_value = 0
        best_diff = abs(calc_sum(0) - target)

        for v in candidates:
            diff = abs(calc_sum(v) - target)
            # 严格小于才更新（保证相同距离时取较小 value）
            if diff < best_diff:
                best_diff = diff
                best_value = v

        # 还需检查候选值之间的整数（因为最优值不一定是数组中的值）
        # 此方法不完整，仅作为思路参考，实际应使用二分

        return best_value
```

**注意**：方法三不完整，最优 `value` 不一定是 `arr` 中的元素（如示例 3 中答案是 11361，不一定在原数组中）。此方法仅用于展示思路，实际请使用方法一或二。

## 复杂度分析

### 方法一（前缀和 + 二分）

- **时间复杂度**：O(n log n)
  - 排序：O(n log n)
  - 构建前缀和：O(n)
  - 二分查找：O(log M)，其中 M = max(arr) <= 10^5
  - 每次 `calc_sum`：O(log n)（二分查找位置）
  - 总计：O(n log n)
- **空间复杂度**：O(n)，存储前缀和数组

### 方法二（暴力 calc_sum + 二分）

- **时间复杂度**：O(n log M)，其中 M = max(arr)
  - 二分 O(log M) 次，每次 O(n)
- **空间复杂度**：O(1)（不计输入）

## 图解示例

以 arr = [4, 9, 3], target = 10 为例，演示 f(value) 函数：

```
value=0:  [0,0,0]  sum=0
value=1:  [1,1,1]  sum=3
value=2:  [2,2,2]  sum=6
value=3:  [3,3,3]  sum=9   ← 距离 target=10 为 1
value=4:  [4,4,3]  sum=11  ← 距离 target=10 为 1
value=5:  [4,5,3]  sum=12
...
value=9:  [4,9,3]  sum=16

f(3)=9，f(4)=11，都与 target=10 距离为 1，取较小 value=3。

二分过程（lo=0, hi=9）：
  mid=4, calc_sum(4)=11 >= 10 → hi=4
  mid=2, calc_sum(2)=6 < 10  → lo=3
  mid=3, calc_sum(3)=9 < 10  → lo=4
  lo==hi=4，退出

比较：|calc_sum(3)-10| = |9-10| = 1
      |calc_sum(4)-10| = |11-10| = 1
1 <= 1，返回 lo-1 = 3
```

## 关键点总结

1. **单调性是二分的前提**：`f(value)` 关于 `value` 单调不减，因此可以二分
2. **二分的终止条件**：最终 `lo` 是使 `f(value) >= target` 的最小值，候选答案是 `lo` 或 `lo-1`
3. **相同距离取较小值**：比较时用 `<=`（而非 `<`），确保相同距离时优先选较小的 `value`
4. **前缀和加速**：结合排序和前缀和，将每次 `f(value)` 计算从 O(n) 降至 O(log n)
5. **`bisect_right` 的使用**：找"第一个严格大于 value 的位置"，正好对应截断边界

## 易错点

1. **比较时的 `<=` 和 `<`**：`abs(sum_lo_minus_1 - target) <= abs(sum_lo - target)` 中必须用 `<=`，否则相同距离时会返回较大的 `value`
2. **lo=0 时的边界**：当 `lo=0` 时，`lo-1 = -1`，但 `calc_sum(-1)` 实际上等于 `calc_sum(0)`（所有元素 min(x, -1) 会出错）。需要确认 `lo` 的取值范围。在方法二中，`calc_sum(lo-1)` 当 `lo=0` 时会计算 `calc_sum(-1)`，此时所有元素变为 0，结果为 0，不影响正确性（因为 `target >= 1`，`lo=0` 时 `|0-target| > |calc_sum(0)-target|` 不成立，所以实际不会返回 -1）
3. **二分边界**：`hi` 应取 `max(arr)` 而非 `max(arr) - 1`，因为答案可能就是最大值（f(max(arr)) = sum(arr)）
4. **不能只检查数组中的值**：最优 `value` 不一定是 `arr` 中的元素，必须在整数范围内二分
