## 题目描述

给你一个由小写字母组成的字符串 `s`，和一个整数 `k`。

请你按下面的要求分割字符串：
- 首先，你可以将 `s` 中的部分字符修改为其他小写英文字母
- 接着，你需要把 `s` 分割成 `k` 个非空且不相交的子字符串，并且每个子字符串都是回文串

请返回以这种方式分割字符串所需修改的最少字符数。

**示例 1：**
```
输入：s = "abc", k = 2
输出：1
解释：将 s 分成 "ab" 和 "c"，"c" 已经是回文串了，把 "ab" 中的 'b' 改成 'a'，使之变成回文串 "aa"
所以最少修改 1 次
```

**示例 2：**
```
输入：s = "aabbc", k = 3
输出：0
解释：将 s 分成 "aa"、"bb" 和 "c"，它们已经都是回文串了
```

**示例 3：**
```
输入：s = "leetcode", k = 8
输出：0
解释：将每个字母单独作为一个子串，每个字母都是回文串
```

**提示：**
- `1 <= k <= s.length <= 100`
- `s` 中只含有小写英文字母

## 解题思路

**整体思路：** 将问题分解为两步。

**第一步：预处理——计算将任意子串变为回文所需的最少修改次数**

对于子串 `s[i..j]`，将其变为回文串，只需从两端向中间配对：
- 如果 `s[i] == s[j]`，不需要修改
- 如果 `s[i] != s[j]`，需要修改其中一个字符，代价为 1

公式：`cost(i, j) = 将 s[i..j] 变为回文的最少修改次数`

```
cost(i, j):
    如果 i >= j: return 0  （空串或单字符已是回文）
    如果 s[i] == s[j]: return cost(i+1, j-1)
    else: return cost(i+1, j-1) + 1
```

化简后：`cost(i, j)` = 从两端向内不匹配的字符对数。

**第二步：动态规划——最优分割**

定义 `dp[i][k]` = 将 `s[0..i]`（前 i+1 个字符）分割成 `k` 个回文子串的最少修改次数。

**状态转移：**
```
dp[i][j] = min over all m < i of: dp[m-1][j-1] + cost(m, i)
```

含义：枚举最后一段子串的起点 `m`，即把 `s[m..i]` 作为最后一个回文子串。

**初始化：**
- `dp[i][1] = cost(0, i)`：只分成 1 段，整个前缀变为回文的代价

**图解示例（s = "abc", k = 2）：**
```
cost 矩阵（cost[i][j] = 将s[i..j]变为回文的代价）：
      j=0 j=1 j=2
i=0 [  0,  1,  1  ]   s[0..0]="a"->0, s[0..1]="ab"->1, s[0..2]="abc"->1
i=1 [  -,  0,  1  ]   s[1..1]="b"->0, s[1..2]="bc"->1
i=2 [  -,  -,  0  ]   s[2..2]="c"->0

dp 矩阵（dp[i][k] = 前i+1个字符分成k段的最少代价）：
       k=1  k=2
i=0 [   0,   0  ]   "a" 分 1 段：cost(0,0)=0；分 2 段不合法（k<=i+1）
i=1 [   1,   0  ]   "ab" 分 1 段：cost(0,1)=1；分 2 段：dp[0][1]+cost(1,1)=0+0=0
i=2 [   1,   1  ]   "abc" 分 1 段：cost(0,2)=1；分 2 段：min(dp[0][1]+cost(1,2), dp[1][1]+cost(2,2))=min(0+1, 1+0)=1

答案：dp[2][2] = 1 ✓
```

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def palindromePartition(self, s: str, k: int) -> int:
        n = len(s)

        # 预计算 cost[i][j]：将 s[i..j] 变为回文的最少修改次数
        cost = [[0] * n for _ in range(n)]
        for length in range(2, n + 1):          # 子串长度从 2 开始
            for i in range(n - length + 1):
                j = i + length - 1
                # 两端字符不同需要修改1次，加上内部子串的代价
                cost[i][j] = cost[i+1][j-1] + (0 if s[i] == s[j] else 1)

        # dp[i][j] = 将 s[0..i] 分割成 j 段的最少修改次数
        # 初始化为无穷大
        INF = float('inf')
        dp = [[INF] * (k + 1) for _ in range(n)]

        # 初始化：每个前缀分成 1 段（整个前缀变为回文）
        for i in range(n):
            dp[i][1] = cost[0][i]

        # 状态转移
        for i in range(1, n):           # 枚举前缀长度（s[0..i]）
            for j in range(2, min(i + 1, k) + 1):  # 枚举分段数（最多 i+1 段）
                # 枚举最后一段的起点 m（s[m..i]是最后一段）
                for m in range(j - 1, i + 1):  # m 至少为 j-1（前 j-1 段各1字符）
                    if dp[m-1][j-1] != INF:
                        dp[i][j] = min(dp[i][j], dp[m-1][j-1] + cost[m][i])

        return dp[n-1][k]
```

### 方法二：带记忆化的递归（自顶向下）

```python
from functools import lru_cache

class Solution:
    def palindromePartition(self, s: str, k: int) -> int:
        n = len(s)

        @lru_cache(maxsize=None)
        def cost(i: int, j: int) -> int:
            """计算将 s[i..j] 变为回文的最少修改次数"""
            if i >= j:
                return 0  # 空串或单字符已是回文
            # 两端相同则不需要改，不同则需要改1个
            return cost(i + 1, j - 1) + (0 if s[i] == s[j] else 1)

        @lru_cache(maxsize=None)
        def dp(i: int, parts: int) -> int:
            """
            将 s[0..i] 分割成 parts 段回文串的最少修改次数
            """
            # 基础情况：只分1段，直接计算代价
            if parts == 1:
                return cost(0, i)

            # 段数不能超过字符数
            if parts > i + 1:
                return float('inf')

            # 枚举最后一段的起点
            result = float('inf')
            for m in range(parts - 1, i + 1):
                prev = dp(m - 1, parts - 1)  # 前 parts-1 段的代价
                if prev != float('inf'):
                    result = min(result, prev + cost(m, i))
            return result

        return dp(n - 1, k)
```

### 方法三：优化版（简洁迭代）

```python
class Solution:
    def palindromePartition(self, s: str, k: int) -> int:
        n = len(s)

        # 预计算所有子串变为回文的代价（递推版本）
        cost = [[0] * n for _ in range(n)]
        for i in range(n - 2, -1, -1):    # 从右到左枚举左端点
            for j in range(i + 1, n):      # 枚举右端点
                cost[i][j] = cost[i+1][j-1] + (0 if s[i] == s[j] else 1)

        # dp[i][t] = 将 s[0..i] 分成 t 段的最少代价
        dp = [[float('inf')] * (k + 1) for _ in range(n)]
        for i in range(n):
            dp[i][1] = cost[0][i]

        for t in range(2, k + 1):
            for i in range(t - 1, n):      # 前 i+1 个字符，至少需要 t 个字符
                for m in range(t - 1, i + 1):  # 最后一段起点 m
                    dp[i][t] = min(dp[i][t], dp[m-1][t-1] + cost[m][i])

        return dp[n-1][k]
```

## 复杂度分析

- **时间复杂度：** O(n^2 * k)
  - 预计算 cost 矩阵：O(n^2)
  - DP 转移：O(n^2 * k)（三层循环）

- **空间复杂度：** O(n^2 + n*k)
  - cost 矩阵：O(n^2)
  - dp 矩阵：O(n*k)
  - 由于 k <= n，空间复杂度也可以写作 O(n^2)

## 关键点总结

1. **问题分解**：先预计算 cost 矩阵（将子串变为回文的代价），再做区间 DP
2. **cost 计算**：从两端向内配对，不匹配则代价 +1，时间 O(n^2) 预处理所有子串
3. **DP 转移**：枚举最后一段的起点，前缀分 k-1 段的最优解 + 最后一段变回文的代价
4. **分段限制**：分 k 段时，每段至少 1 字符，所以前缀长度至少为 k
5. **初始化**：分 1 段时，直接用 cost[0][i]；分 k=n 段时，每段 1 字符，代价为 0

## 易错点

1. **cost 下标**：cost[i][j] 中 i <= j，计算时注意不要越界（length >= 2 时才需要递推）
2. **dp 初始化**：INF 很重要，表示"不可能的状态"，转移时要检查前驱状态是否有效
3. **m 的范围**：最后一段起点 m 必须满足 `j-1 <= m <= i`（前 j-1 段各至少 1 个字符）
4. **dp[m-1]** 越界：当 m=0 时，dp[m-1] = dp[-1] 在 Python 中不会报错但语义错误，需要特殊处理（m 从 j-1 开始可以避免 m=0 的情况当 j>=2 时）
5. **k = n 的特殊情况**：每个字符单独成段，每段是长度1的回文，代价为0
