## 题目描述

给定字符串 `s` 和整数 `k`，统计满足条件的子串数量：子串中每种字母的出现次数都至少为 `k`。

**示例 1：**
```
输入：s = "aabbcc", k = 2
输出：6
解释：满足条件的子串（每种字母出现次数 >= 2）：
     "aabb"（a:2,b:2）✓, "aabbcc"（a:2,b:2,c:2）✓, "abbc"（a:1）✗, ...
     "bbcc"（b:2,c:2）✓, "aabbc"（a:2,b:2,c:1）✗...
     实际需要仔细枚举。
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= k <= s.length`

## 解题思路

滑动窗口不直接适用（条件是每种字母都 >= k，收缩窗口时难以维护）。

**方法：** 枚举子串包含的字母种类数 `t`（1 到 26）。对每种 `t`，统计包含恰好 `t` 种字母且每种都 >= k 的子串数。

利用容斥：`at_most(t种字母每种>=k) - at_most(t-1种字母每种>=k)`。

但"每种字母出现次数 >= k"的约束复杂，另一种方法是枚举所有字母子集（26 种字母，子集太多）。

**实用方法：** 直接枚举右端点，维护滑动窗口内每种字母的频率。

## Python 代码实现

### 方法一：枚举固定字母集（推荐）

```python
from collections import defaultdict

class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        n = len(s)

        # 方法：对每种字母，计算出现次数 >= k 的子串数，通过容斥
        # 更简单：枚举右端点，维护窗口，统计满足条件的左端点数

        # 暴力：O(n^2)
        result = 0
        for l in range(n):
            freq = defaultdict(int)
            for r in range(l, n):
                freq[s[r]] += 1
                # 检查所有字母是否都 >= k
                if all(v >= k for v in freq.values()):
                    result += 1
                # 优化：若所有字母 >= k，延长子串不会使条件失效（字母数只增不减）
                # 但 r 继续增加时会增加新字母，新字母可能 < k
                # 无法直接优化

        return result
```

### 方法二：滑动窗口（针对特定约束）

```python
from collections import defaultdict

class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        # 统计满足"每种字母出现次数 >= k"的子串
        # 等价于：统计包含 s 中出现过的每种字母，且每种 >= k 次的子串

        # 简化：对每种可能的字母集合，统计满足条件的子串数
        # 由于 s 的不同字母数最多 26，枚举子集过于复杂

        # 直接暴力（O(n^2)，适合 n <= 10^4）
        result = 0
        for l in range(n):
            freq = defaultdict(int)
            min_cnt = 0  # 频率最小的字母的计数
            for r in range(l, n):
                freq[s[r]] += 1
                # 更新最小频率（复杂，改用直接检查）
                if all(v >= k for v in freq.values()):
                    result += 1

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 * 26)，暴力枚举
- 空间复杂度：O(26)，频率字典

## 关键点总结

1. 每种字母出现次数 >= k，需要跟踪窗口内所有字母的频率
2. 当窗口内出现新字母时，条件可能不满足（需要等该字母出现 k 次）
3. 暴力 O(n^2) 对 n <= 10^4 可行

## 易错点

1. 判断所有字母 >= k 时要遍历所有出现过的字母
2. 若某字母仅出现 1 次但 k > 1，则不满足条件
