## 题目描述

给你一个整数数组 `nums`。

对 `nums` 执行若干次操作：每次选择相邻的两个元素，用它们的和替换这两个元素（变为一个元素）。

返回经过若干次操作后，能得到的最长非递减数组的长度。

**示例 1：**
```
输入：nums = [5,2,2]
输出：1
解释：合并后只能得到 [5,4] 或 [5,2,2]，但 5,4 是递减的，5,2,2 也不是非递减的
等等：[5,4] 长度 2 不行（5>4），原数组 [5,2,2] 也不行（5>2）
合并 2,2 得 [5,4]，5>4，不行
```

**示例 2：**
```
输入：nums = [4,3,2,6], k=?
输出：2
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 10^9`

## 解题思路

定义 `dp[i]` 为以 i 结尾的最长非递减合并数组的长度，同时记录该段合并后的总和为 `sum[i]`（若有多种长度相同的情况，尽量让 sum 最小）。

对于 dp[i]，枚举上一段的结尾 j（dp[i] = dp[j] + 1），要求 `partial_sum(j+1, i) >= last_val[j]`（本段合并后的和 >= 前段最后元素合并后的值）。

使用前缀和 + 单调栈优化二分查找。

## Python 代码实现

### 方法一：动态规划 + 单调栈 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def findMaximumLength(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # dp[i] = 最长非递减合并数组的长度（考虑 nums[0..i-1]）
        # last[i] = dp[i] 的情况下，最后一段合并后的最小值
        dp = [0] * (n + 1)
        last = [0] * (n + 1)  # 每段合并后的值（最大可行中最小）

        # 单调栈优化
        # 对于位置 i，找最大的 j 使得 prefix[i] - prefix[j] >= last[j]
        # 即 prefix[j] + last[j] <= prefix[i]
        # 在 prefix[j] + last[j] 递增的序列中，用二分找最左满足的 j

        # 维护 (prefix[j] + last[j]) 的单调递增栈
        mono = [(0, 0)]  # (prefix[j] + last[j], j)

        for i in range(1, n + 1):
            # 找最大的 j 满足 prefix[j] + last[j] <= prefix[i]
            lo, hi = 0, len(mono) - 1
            res = 0
            while lo <= hi:
                mid = (lo + hi) // 2
                if mono[mid][0] <= prefix[i]:
                    res = mono[mid][1]
                    lo = mid + 1
                else:
                    hi = mid - 1

            j = res
            dp[i] = dp[j] + 1
            last[i] = prefix[i] - prefix[j]  # 当前段的合并和

            # 将 (prefix[i] + last[i]) 加入单调栈（保持递增）
            val = prefix[i] + last[i]
            # 因为 prefix[i] + last[i] = prefix[i] + (prefix[i] - prefix[j]) = 2*prefix[i] - prefix[j]
            # 这是递增的（i 增大，prefix 递增）
            while mono and mono[-1][0] >= val:
                mono.pop()
            mono.append((val, i))

        return dp[n]
```

### 方法二：暴力 DP（小数据验证）

```python
from typing import List

class Solution:
    def findMaximumLength(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        dp = [0] * (n + 1)
        last = [0] * (n + 1)

        for i in range(1, n + 1):
            for j in range(i):
                seg_sum = prefix[i] - prefix[j]
                if seg_sum >= last[j]:
                    if dp[j] + 1 > dp[i] or (dp[j] + 1 == dp[i] and seg_sum < last[i]):
                        dp[i] = dp[j] + 1
                        last[i] = seg_sum

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n log n)，单调栈 + 二分查找
- 空间复杂度：O(n)

## 关键点总结

1. 合并操作：一段连续元素合并为其和，和具有单调性（右端延伸，和增大）
2. dp 转移：找最右的 j 使得 prefix[i]-prefix[j] >= last[j]，即 prefix[j]+last[j] <= prefix[i]
3. 单调栈维护 prefix[j]+last[j] 的递增序列，支持二分查找

## 易错点

1. 当 dp 值相同时，选 last 值最小的（贪心：给后续更多空间）
2. 单调栈维护的是 prefix[j]+last[j]，不是单纯的 prefix[j]
3. j=0 表示从头开始一段，last[0]=0（初始无限制）
