## 题目描述

给你一个整数 `n`，表示一个国家中城市的数量（编号 1 到 n）。另给你一个二维整数数组 `roads`，`roads[i] = [ai, bi]` 表示城市 `ai` 和 `bi` 之间有一条双向道路。

你需要给每座城市分配一个 1 到 n 之间的独特整数值，一条道路的**重要性**为其两端城市值之和。

返回在最优分配下，所有道路的**最大总重要性**之和。

**示例 1：**
```
输入：n = 5, roads = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]
输出：43
```

**示例 2：**
```
输入：n = 5, roads = [[0,3],[2,4]]
输出：20
```

## 解题思路

**贪心：** 度数越大的城市，其值出现次数越多（每条相邻道路都会用到它的值）。所以给度数最大的城市分配最大的值 `n`，次大度数分配 `n-1`，以此类推。

对道路总重要性 = `sum(degree[i] * value[i])`，为使其最大，按度数从小到大排序，依次分配值 1, 2, ..., n（贪心最优）。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def maximumImportance(self, n: int, roads: List[List[int]]) -> int:
        # 统计每个城市的度数
        degree = [0] * n
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1

        # 按度数排序，度数最小的分配值 1，最大的分配值 n
        degree.sort()

        ans = 0
        for i, d in enumerate(degree):
            ans += (i + 1) * d  # 分配值 i+1

        return ans
```

### 方法二：Counter + 排序（更直观）

```python
from typing import List
from collections import Counter

class Solution:
    def maximumImportance(self, n: int, roads: List[List[int]]) -> int:
        degree = Counter()
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1

        # 按度数升序排列各城市
        sorted_degrees = sorted(degree[i] for i in range(n))

        ans = 0
        for val, d in enumerate(sorted_degrees, 1):
            ans += val * d

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n + m)，排序 + 遍历边。
- 空间复杂度：O(n)，度数数组。

## 关键点总结

1. 最优策略：度数大的城市分配大的值，贪心证明：交换不等度数城市的值不会更优。
2. 总重要性 = `sum(degree[city] * value[city])`，排序对齐即可。
3. 不同城市的度数可以相同，排序后按序分配无需担心。

## 易错点

- 城市编号是 0 到 n-1，不是 1 到 n，初始化 `degree = [0] * n`。
- 分配的值是 1 到 n（`enumerate(sorted_degrees, 1)`）。
