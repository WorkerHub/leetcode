## 题目描述

给你一个 `m x n` 的矩阵 `seats`，矩阵的每个位置要么是 `'.'` 要么是 `'#'` 。

- `'.'` 表示可以坐人的空位；
- `'#'` 表示不可以坐人的损坏座位。

学生可以坐在可用的位置上，但需要遵守以下规则：**不允许两个学生相邻坐在一起（左右相邻、或斜上方相邻）**，具体来说，如果某位置 `(r, c)` 坐了学生，则以下位置不能坐人：
- `(r, c-1)`、`(r, c+1)` — 同行左右邻座
- `(r-1, c-1)`、`(r-1, c+1)` — 上一行的左上和右上座位

返回可以参加考试的最多学生数。

**示例 1：**
```
输入：seats = [
  ["#",".","#","#",".","#"],
  [".","#","#","#","#","."],
  ["#",".","#","#",".","#"]
]
输出：4
```

**示例 2：**
```
输入：seats = [
  [".","#"],
  ["#","#"],
  ["#","."],
  ["#","#"],
  [".","#"]
]
输出：3
```

**示例 3：**
```
输入：seats = [
  ["#",".",".",".","#"],
  [".","#",".","#","."],
  [".",".","#",".","."],
  [".","#",".","#","."],
  ["#",".",".",".","#"]
]
输出：10
```

**提示：**
- `seats` 只包含字符 `'.'` 和字符 `'#'`
- `m == seats.length`
- `n == seats[i].length`
- `1 <= m <= 8`
- `1 <= n <= 8`

## 解题思路

这道题是经典的**状态压缩动态规划**问题。由于每行最多 8 个座位，可以用一个二进制数表示该行的就座状态（第 i 位为 1 表示第 i 列坐了学生）。

**核心思想：**
1. 将每一行的座位状态压缩成一个二进制整数（最多 8 位，即 256 个状态）。
2. 逐行枚举合法的就座方案，并结合上一行的状态转移。

**状态定义：**
- `dp[i][mask]` = 处理完第 i 行、且第 i 行的就座状态为 `mask` 时，能坐下的最多学生总数。

**合法性检查：**
- 当前行状态 `mask` 合法：
  - `mask & (mask >> 1) == 0`：同行不相邻（没有两个相邻的 1）
  - `mask & (~row_valid) == 0`：只坐在没有损坏的座位上（`row_valid` 为该行可用位的掩码）
- 与上一行状态 `prev` 合法：
  - `mask & (prev >> 1) == 0`：当前行没有人坐在上一行人的右下方
  - `mask & (prev << 1) == 0`：当前行没有人坐在上一行人的左下方

**时间复杂度分析：** m 行，每行 2^n 个状态，转移也是 2^n，总体 O(m * 4^n)，n<=8 完全可行。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def maxStudents(self, seats: List[List[str]]) -> int:
        m, n = len(seats), len(seats[0])
        
        # 预处理每行的合法座位掩码（'.' 对应位为 1，'#' 对应位为 0）
        row_valid = []
        for i in range(m):
            mask = 0
            for j in range(n):
                if seats[i][j] == '.':
                    mask |= (1 << j)
            row_valid.append(mask)
        
        # 检查同行状态是否合法（没有相邻的学生）
        def row_ok(mask, valid):
            if mask & (~valid) & ((1 << n) - 1):
                return False  # 坐在了损坏座位上
            if mask & (mask >> 1):
                return False  # 同行有相邻学生
            return True
        
        # dp[mask] 表示当前行状态为 mask 时的最大学生数
        # 初始化为 -1 表示不合法
        INF = float('-inf')
        dp = [INF] * (1 << n)
        
        # 处理第 0 行
        for mask in range(1 << n):
            if row_ok(mask, row_valid[0]):
                dp[mask] = bin(mask).count('1')
        
        # 逐行转移
        for i in range(1, m):
            new_dp = [INF] * (1 << n)
            for mask in range(1 << n):
                # 当前行状态 mask 必须合法
                if not row_ok(mask, row_valid[i]):
                    continue
                for prev in range(1 << n):
                    # 上一行状态 prev 必须合法
                    if dp[prev] == INF:
                        continue
                    # 检查行间约束：
                    # 当前行不能有人坐在上一行左上/右上的位置
                    if mask & (prev << 1):
                        continue  # 当前有人在上一行某人的右下方（即上一行该人的右上有人）
                    if mask & (prev >> 1):
                        continue  # 当前有人在上一行某人的左下方
                    students = dp[prev] + bin(mask).count('1')
                    new_dp[mask] = max(new_dp[mask], students)
            dp = new_dp
        
        return max(x for x in dp if x != INF)
```

### 方法二：状态压缩 DP（空间优化版）

```python
from typing import List

class Solution:
    def maxStudents(self, seats: List[List[str]]) -> int:
        m, n = len(seats), len(seats[0])
        full = (1 << n) - 1  # n 位全 1 掩码
        
        # 预处理每行可用座位的掩码
        valid = []
        for row in seats:
            mask = 0
            for j, c in enumerate(row):
                if c == '.':
                    mask |= (1 << j)
            valid.append(mask)
        
        # dp[mask] = 第 i 行状态为 mask 时前 i+1 行最多学生数
        dp = [-1] * (1 << n)
        
        # 初始化第 0 行
        for s in range(1 << n):
            # s 必须是 valid[0] 的子集（只坐可用位）
            if (s & valid[0]) == s and (s & (s >> 1)) == 0:
                dp[s] = bin(s).count('1')
        
        for i in range(1, m):
            ndp = [-1] * (1 << n)
            for cur in range(1 << n):
                # cur 是 valid[i] 的子集且同行不相邻
                if (cur & valid[i]) != cur:
                    continue
                if cur & (cur >> 1):
                    continue
                for pre in range(1 << n):
                    if dp[pre] < 0:
                        continue
                    # 行间不冲突（cur 和 pre 无斜向相邻）
                    if (cur & (pre << 1)) or (cur & (pre >> 1)):
                        continue
                    val = dp[pre] + bin(cur).count('1')
                    if val > ndp[cur]:
                        ndp[cur] = val
            dp = ndp
        
        return max(x for x in dp if x >= 0)
```

### 方法三：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxStudents(self, seats: List[List[str]]) -> int:
        m, n = len(seats), len(seats[0])
        
        # 每行可用座位掩码
        valid = []
        for row in seats:
            mask = 0
            for j, c in enumerate(row):
                if c == '.':
                    mask |= (1 << j)
            valid.append(mask)
        
        @lru_cache(maxsize=None)
        def dfs(row, prev_mask):
            """返回从第 row 行开始，上一行状态为 prev_mask 时的最大学生数"""
            if row == m:
                return 0
            best = 0
            for cur in range(1 << n):
                # 只坐可用座位
                if (cur & valid[row]) != cur:
                    continue
                # 同行不相邻
                if cur & (cur >> 1):
                    continue
                # 与上一行不冲突
                if (cur & (prev_mask << 1)) or (cur & (prev_mask >> 1)):
                    continue
                cnt = bin(cur).count('1') + dfs(row + 1, cur)
                best = max(best, cnt)
            return best
        
        return dfs(0, 0)
```

## 复杂度分析

**方法一/二（状态压缩 DP）：**
- 时间复杂度：O(m * 4^n)。m 行，每行枚举当前状态 2^n，每个状态再枚举上一行状态 2^n。n<=8，4^8=65536，m<=8，总计约 52 万次运算。
- 空间复杂度：O(2^n)，只保留上一行 DP 数组。

**方法三（记忆化递归）：**
- 时间复杂度：O(m * 2^n * 2^n) = O(m * 4^n)，与方法一相同。
- 空间复杂度：O(m * 2^n)，记忆化缓存大小。

## 图解示例

以第一个示例为例，按行处理：

```
第 0 行：# . # # . #   valid = 010010 = 18
  合法状态（子集且不相邻）：000000, 000010, 010000, 010010

第 1 行：. # # # # .   valid = 100001 = 33
  合法状态：000000, 000001, 100000, 100001
  注意 100001 相邻？1 在位 0 和位 5，不相邻，合法

行间约束：当前行 cur 与上行 pre 不能有斜邻
  例：pre=010010（第 1、4 位有人），cur=100001
  cur & (pre << 1) = 100001 & 100100 = 100000 != 0，冲突
```

## 关键点总结

1. **状态压缩**：每行最多 8 位，用二进制整数表示就座状态，枚举 2^n 种可能。
2. **同行合法性**：`mask & (mask >> 1) == 0` 保证没有相邻学生。
3. **行间合法性**：用位移操作检查斜向冲突，`cur & (prev << 1)` 和 `cur & (prev >> 1)`。
4. **子集约束**：就座状态必须是可用座位掩码的子集，即 `(mask & valid) == mask`。
5. **转移顺序**：从第 0 行到第 m-1 行，每行仅依赖上一行，空间可优化为 O(2^n)。

## 易错点

- 位移方向容易搞混：`prev << 1` 表示 prev 的每个位向高位移动，等价于"上一行每个人都整体右移一列"，此时检查 `cur & (prev << 1)` 是在查当前行是否在上一行某人的左下方（从上往下看，左下方斜邻）。
- 损坏座位的掩码处理：一定要用 `(mask & valid[i]) == mask` 而不是 `mask & valid[i]`，否则只要有交集就通过，会包含损坏座位。
- 初始状态 dp 需要设为 -1（或负无穷）来区分"不可达"和"0人就座"两种情况。
