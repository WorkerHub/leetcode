## 题目描述

给你一个二进制字符串 `s`，你可以执行以下操作任意次：选择字符串中的 `"00"` 子串，将其替换为 `"10"`。

返回经过若干次操作后可以得到的字典序最大的二进制字符串。

**示例 1：**

```
输入：s = "000110"
输出："111011"
解释：
"000110" -> "100110" -> "110110" -> "111010" -> "111011"
```

**示例 2：**

```
输入：s = "01"
输出："01"
解释：没有 "00" 子串，无法操作。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 '0' 或 '1'

## 解题思路

关键观察：
1. 操作 `"00" -> "10"` 实际上是将 `0` 向右移动（左边的 `0` 变为 `1`）。
2. 字符串中 `1` 的个数不变，`0` 的总数不变。
3. 最终字符串的形式：所有 `1` 尽量靠左，最后只剩一个 `0`（如果有 `0` 的话）。

具体规律：
- 统计从第一个 `0` 开始到末尾的字符中 `0` 的个数（设为 `count0`），`1` 的个数（设为 `count1`）。
- 结果字符串：第一个 `0` 之前的部分不变 + `count0 + count1 - 1` 个 `1` + `"0"` + 剩余（如果有）。

## Python 代码实现

### 方法一：贪心构造（推荐）

```python
class Solution:
    def maximumBinaryString(self, s: str) -> str:
        # 找第一个 '0' 的位置
        first_zero = s.find('0')
        if first_zero == -1:
            return s  # 全是 '1'，无法操作

        # 统计从 first_zero 到末尾的 '0' 个数
        count_zeros = s.count('0', first_zero)

        # 结果：first_zero 个 '1' + (count_zeros - 1) 个 '1' + '0' + 剩余 '1'
        n = len(s)
        # 总 '1' 个数 = n - count_zeros（原来就有的 1）
        # 操作后：前 first_zero 个是原始 '1'，然后是 count_zeros - 1 个 '1'，然后是 '0'
        result_ones_before_zero = first_zero + (count_zeros - 1)
        result = '1' * result_ones_before_zero + '0' + '1' * (n - result_ones_before_zero - 1)

        return result
```

### 方法二：模拟操作（理解用）

```python
class Solution:
    def maximumBinaryString(self, s: str) -> str:
        arr = list(s)
        n = len(arr)
        changed = True

        while changed:
            changed = False
            for i in range(n - 1):
                if arr[i] == '0' and arr[i + 1] == '0':
                    arr[i] = '1'
                    # arr[i+1] 保持 '0'
                    changed = True
                    break  # 重新开始

        return ''.join(arr)
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n^2)（方法二模拟）
- 空间复杂度：O(n)，结果字符串

## 关键点总结

1. 每次操作消耗一个 `0`，将其变为 `1`，另一个 `0` 右移。
2. 最终只剩一个 `0`（当原来有 `0` 时），其他位置都是 `1`。
3. 第一个 `0` 之前的 `1` 不受影响（左边没有 `0` 可以帮助操作）。

## 易错点

1. 如果字符串全是 `1`，直接返回原字符串。
2. `0` 的最终位置是 `first_zero + count_zeros - 1`（即所有 `0` 合并后的最后位置）。
3. 方法二模拟效率低，仅用于理解。
