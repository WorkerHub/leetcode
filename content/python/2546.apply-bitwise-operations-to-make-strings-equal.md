## 题目描述

给你两个下标从 **0** 开始的 **二进制字符串** `s` 和 `target`，两个字符串长度相同，且只包含字符 '0' 和 '1'。

每次操作，可以选择 `s` 中两个不同的下标 `i` 和 `j`，同时执行：
- `s[i] = s[i] OR s[j]`
- `s[j] = s[i] XOR s[j]`

如果可以通过有限次操作使 `s == target`，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：s = "1010", target = "0110"
输出：true
```

**示例 2：**

```
输入：s = "11", target = "00"
输出：false
```

**提示：**

- `n == s.length == target.length`
- `2 <= n <= 10^5`
- `s` 和 `target` 只包含 '0' 和 '1'

## 解题思路

分析操作的效果：
- 若 s[i]=1, s[j]=0：s[i] = 1|0 = 1，s[j] = 1^0 = 1。效果：将 0 变成 1（需要一个 1 作为源）
- 若 s[i]=1, s[j]=1：s[i] = 1|1 = 1，s[j] = 1^1 = 0。效果：将 1 变成 0（需要另一个 1）
- 若 s[i]=0, s[j]=0 或 s[i]=0, s[j]=1：都不产生新的 1

关键结论：
1. 若 s 中没有 1，则无法产生任何 1，只能与 target 全为 0 时匹配
2. 若 s 中有 1，target 中也有 1：可以任意操作，只要 s 和 target 都有 1 就可以相互转化

## Python 代码实现

### 方法一：判断 1 的存在性（推荐）

```python
class Solution:
    def makeStringsEqual(self, s: str, target: str) -> bool:
        # 操作等效：有 1 可以复制和消除 1（只要有一个 1）
        # 没有 1 则永远无法产生 1
        s_has_one = '1' in s
        t_has_one = '1' in target

        # s 和 target 对于"是否存在 1"必须一致
        return s_has_one == t_has_one
```

### 方法二：详细分析

```python
class Solution:
    def makeStringsEqual(self, s: str, target: str) -> bool:
        # 若 s 全为 0：
        #   - target 全为 0 → true（已经相等）
        #   - target 含 1 → false（无法产生 1）
        # 若 s 含 1：
        #   - target 全为 0 → false（1 无法全部消除，操作会保留至少一个 1？）
        #     实际上：(1,1) → (1,0)，可以将所有 1 变为 0 除了一个
        #     再 (1,0)... 无法消除最后一个 1，所以 target 含 1 才行
        #   - target 含 1 → true（可以任意排列 1）
        # 结论：s_has_one == t_has_one
        return ('1' in s) == ('1' in target)
```

## 复杂度分析

- 时间复杂度：O(n)，扫描字符串判断是否含 '1'
- 空间复杂度：O(1)

## 关键点总结

1. 操作不能凭空创造 1，只能传播和消除
2. 若 s 全 0，无法产生任何 1
3. 若 s 有 1，可以复制到任意位置，也可以消除（但必须保留至少一个）
4. 结论：s 和 target 是否含 1 必须一致

## 易错点

1. 不是统计 1 的数量，而是判断是否"存在 1"
2. 操作可以传播 1 到任意位置，所以 1 的位置不重要，只有是否有 1 重要
3. 有 1 时可以任意操控 1 的分布，但不能完全消除所有 1
