## 题目描述

给你一个整数 `num`，请你找出同时满足下面全部要求的两个整数：

- 两数乘积等于 `num + 1` 或 `num + 2`
- 以绝对差进行度量，两数大小最接近

请你以两个整数的形式返回这两个整数，如果存在多组满足题意的答案，任选其中一组均可。

**示例 1：**
```
输入：num = 8
输出：[3,3]
解释：
对于 num + 1 = 9，最近的因子对是 (3, 3)，绝对差为 0。
对于 num + 2 = 10，最近的因子对是 (2, 5)，绝对差为 3。
选 (3, 3)。
```

**示例 2：**
```
输入：num = 123
输出：[5,25]
解释：
num+1=124，最近因子对：4*31（差27），2*62（差60），...
num+2=125，最近因子对：5*25（差20），更接近。
```

**示例 3：**
```
输入：num = 999**
输出：[40,25]
解释：999+1=1000，1000=40*25（差15），999+2=1001，...
```

**提示：**
- `1 <= num <= 10^9`

## 解题思路

对于一个正整数 `target`，找两个因子 `a` 和 `b` 使得 `a * b = target` 且 `|a - b|` 最小。

**关键观察：** 当 `a * b = target` 时，使 `|a - b|` 最小的 `a` 在 `sqrt(target)` 附近。

**算法：** 从 `a = floor(sqrt(target))` 开始向下枚举，找第一个能整除 `target` 的 `a`，对应 `b = target // a`，此时 `|a - b|` 最小。

对 `target = num+1` 和 `target = num+2` 分别找最优因子对，然后比较两组中哪组差更小。

**为什么从 sqrt 向下找？**

设 `a <= b`，则 `a <= sqrt(target) <= b`。当 `a` 越接近 `sqrt(target)` 时，`b = target/a` 也越接近 `sqrt(target)`，两者差越小。从 `floor(sqrt(target))` 开始向下，第一个整除 target 的 `a` 就是最优的 `a`。

## Python 代码实现

### 方法一：从 sqrt 向下枚举（推荐）

```python
from typing import List
import math

class Solution:
    def closestDivisors(self, num: int) -> List[int]:
        
        def best_pair(target: int) -> List[int]:
            """找乘积为 target 的最接近因子对"""
            # 从 sqrt(target) 开始向下找第一个因子
            a = int(math.isqrt(target))  # floor(sqrt(target))
            while a >= 1:
                if target % a == 0:
                    return [a, target // a]
                a -= 1
            return [1, target]  # 最坏情况（target 是质数）
        
        pair1 = best_pair(num + 1)
        pair2 = best_pair(num + 2)
        
        # 选差的绝对值更小的那一对
        if abs(pair1[0] - pair1[1]) <= abs(pair2[0] - pair2[1]):
            return pair1
        return pair2
```

### 方法二：暴力枚举所有因子（思路更直接）

```python
from typing import List
import math

class Solution:
    def closestDivisors(self, num: int) -> List[int]:
        
        def best_pair(target: int) -> List[int]:
            """枚举所有因子对，找差最小的"""
            best = [1, target]
            best_diff = target - 1
            
            # 枚举到 sqrt(target)
            for a in range(1, int(math.isqrt(target)) + 1):
                if target % a == 0:
                    b = target // a
                    if b - a < best_diff:
                        best_diff = b - a
                        best = [a, b]
            
            return best
        
        pair1 = best_pair(num + 1)
        pair2 = best_pair(num + 2)
        
        if abs(pair1[0] - pair1[1]) <= abs(pair2[0] - pair2[1]):
            return pair1
        return pair2
```

### 方法三：合并两个目标值统一处理

```python
from typing import List
import math

class Solution:
    def closestDivisors(self, num: int) -> List[int]:
        best = None
        best_diff = float('inf')
        
        # 对 num+1 和 num+2 分别处理
        for target in (num + 1, num + 2):
            # 从 sqrt 向下找第一个因子
            a = int(math.isqrt(target))
            while target % a != 0:
                a -= 1
            b = target // a
            diff = b - a  # 注意：由于 a <= sqrt <= b，b >= a，差为 b-a
            if diff < best_diff:
                best_diff = diff
                best = [a, b]
        
        return best
```

## 复杂度分析

- 时间复杂度：O(sqrt(num))。从 sqrt(num+2) 向下枚举，最坏情况（num+1 和 num+2 都是质数）需要遍历到 1，共 sqrt(num) 步。
- 空间复杂度：O(1)。

## 关键点总结

1. 使两个因子差最小的分割点在 `sqrt(target)` 处，从该处向下找第一个因子即可。
2. 需要对 `num+1` 和 `num+2` 分别找最优因子对，然后取差更小的那组。
3. Python `math.isqrt(n)` 返回 `floor(sqrt(n))`（整数平方根），比 `int(math.sqrt(n))` 更精确（避免浮点误差）。
4. 由于 `a <= sqrt(target) <= b = target//a`，所以 `b >= a`，`|a-b| = b-a`，差始终非负。

## 易错点

- 不能只考虑 `num+1`，必须同时考虑 `num+2`，选差更小的那对。
- 用 `math.sqrt` 可能有浮点精度问题，建议用 `math.isqrt`（Python 3.8+）或 `int(math.sqrt(n))`。
- 当 num+1 或 num+2 是完全平方数时，最优答案就是 `[sqrt, sqrt]`，差为 0，算法能正确处理（如 num=8 时 num+1=9=3*3）。
- 当 num+1 或 num+2 是质数时，最接近的因子对只有 `[1, target]`，此时只要对面的目标不是质数，对面的结果会更优。

## 示例手动推导

以 `num = 8` 为例：

```
target1 = 9:
  sqrt(9) = 3, 9 % 3 == 0 -> 因子对 (3, 3)，差 = 0

target2 = 10:
  sqrt(10) ≈ 3.16, isqrt = 3
  10 % 3 = 1，不整除，a=2
  10 % 2 == 0 -> 因子对 (2, 5)，差 = 3

比较：0 < 3，选 (3, 3)
```
