## 题目描述

给你两个只包含 1 到 9 之间数字的数组 `nums1` 和 `nums2`，每个数组中的元素互不相同，找出并返回能由 `nums1` 中的某个数字以及 `nums2` 中的某个数字组成的、且最小的两位数。

两位数中的每个数字必须来自对应的数组。

**示例 1：**
```
输入：nums1 = [4,1,3], nums2 = [5,7,9]
输出：15
解释：最小两位数：第一位来自 nums1，第二位来自 nums2
可以组成的两位数：45,47,49,15,17,19,35,37,39
最小为 15
```

**示例 2：**
```
输入：nums1 = [3,5,2,6], nums2 = [3,1,7]
输出：3
解释：数字 3 同时出现在两个数组中，所以可以直接返回 3
```

**数据范围：**
- 1 <= nums1.length, nums2.length <= 9
- 1 <= nums1[i], nums2[i] <= 9
- 所有 nums1 中的数字互不相同，nums2 中的数字也互不相同

## 解题思路

分两种情况讨论：

1. **存在公共元素**：若两个数组有公共数字，直接返回最小公共数字（即一位数）
2. **无公共元素**：从两个数组各取最小值 `a = min(nums1)`, `b = min(nums2)`, 组成两位数。较小的数放十位，即 `min(a*10+b, b*10+a)`

## Python 代码实现

### 方法一：集合求交集（推荐）

```python
from typing import List

class Solution:
    def minNumber(self, nums1: List[int], nums2: List[int]) -> int:
        # 求两个数组的公共元素
        common = set(nums1) & set(nums2)
        if common:
            # 返回最小公共元素（一位数比两位数小）
            return min(common)
        # 无公共元素，取各自最小值组成最小两位数
        a, b = min(nums1), min(nums2)
        return min(a * 10 + b, b * 10 + a)
```

### 方法二：枚举

```python
from typing import List

class Solution:
    def minNumber(self, nums1: List[int], nums2: List[int]) -> int:
        s1, s2 = set(nums1), set(nums2)
        # 检查公共元素
        for x in range(1, 10):
            if x in s1 and x in s2:
                return x  # 找到最小公共元素
        # 无公共元素
        a, b = min(nums1), min(nums2)
        return min(a * 10 + b, b * 10 + a)
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 和 m 为两数组长度
- 空间复杂度：O(n + m)，存储集合

## 关键点总结

1. 公共元素（一位数）比两位数更小，优先考虑
2. 无公共元素时，取各自最小值，较小的放十位

## 易错点

1. 若存在公共元素，返回最小公共元素而非最小的两位组合
2. 无公共元素时，组合方式有两种（a*10+b 和 b*10+a），取最小
