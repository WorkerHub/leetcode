## 题目描述

对于某些非负整数 k ，如果交换 s1 中两个字母的位置恰好 k 次，能够使结果字符串等于 s2 ，则认为字符串 s1 和 s2 的 相似度为 k 。

给你两个字母异位词 s1 和 s2 ，返回 s1 和 s2 的相似度 k 的最小值。

**示例 1：**
```
输入：s1 = "ab", s2 = "ba"
输出：1
```

**示例 2：**
```
输入：s1 = "abc", s2 = "bca"
输出：2
```

**提示：**
- 1 <= s1.length <= 20
- s2.length == s1.length
- s1 和 s2 只包含集合 {'a', 'b', 'c', 'd', 'e', 'f'} 中的小写字母
- s2 是 s1 的一个字母异位词

## 解题思路

这是一道**最短路径问题**，可以用 BFS（广度优先搜索）求解。

**核心观察：**
1. 每次交换看作一次状态转移
2. 我们要找从 s1 到 s2 的最短路径（最少交换次数）
3. BFS 能保证找到最短路径

**优化策略：**
1. **贪心选择**：每次只交换能使 s1[i] == s2[i] 的位置（有意义的交换）
2. **剪枝**：只考虑第一个不匹配位置的交换
3. **去重**：使用 set 记录访问过的状态

**算法流程：**
1. 使用 BFS，队列初始状态为 s1
2. 对于当前字符串，找到第一个不匹配的位置 i
3. 尝试将 i 与后面所有能使 s1[i] == s2[i] 的位置交换
4. 如果交换后的字符串等于 s2，返回步数
5. 否则将新状态加入队列

**为什么只考虑第一个不匹配位置？**
- 贪心思想：总可以通过某个最优解使得前面的位置先匹配
- 这样可以大大减少搜索空间

## Python 代码实现

### 方法一：BFS + 贪心剪枝（推荐）⭐

```python
class Solution:
    def kSimilarity(self, s1: str, s2: str) -> int:
        from collections import deque
        
        if s1 == s2:
            return 0
        
        # BFS
        queue = deque([(s1, 0)])  # (当前字符串, 交换次数)
        visited = {s1}
        
        while queue:
            curr, swaps = queue.popleft()
            
            # 找到第一个不匹配的位置
            i = 0
            while i < len(curr) and curr[i] == s2[i]:
                i += 1
            
            # 尝试交换 i 与后面的位置
            for j in range(i + 1, len(curr)):
                # 只考虑有意义的交换：curr[j] == s2[i]
                if curr[j] == s2[i]:
                    # 执行交换
                    curr_list = list(curr)
                    curr_list[i], curr_list[j] = curr_list[j], curr_list[i]
                    next_state = ''.join(curr_list)
                    
                    # 找到答案
                    if next_state == s2:
                        return swaps + 1
                    
                    # 加入队列
                    if next_state not in visited:
                        visited.add(next_state)
                        queue.append((next_state, swaps + 1))
        
        return -1
```

**代码说明：**
- 只交换能使 curr[i] == s2[i] 的位置
- 使用 visited 去重，避免重复搜索
- BFS 保证找到最短路径

### 方法二：优化的 BFS（双向 BFS）

```python
class Solution:
    def kSimilarity(self, s1: str, s2: str) -> int:
        if s1 == s2:
            return 0
        
        # 双向 BFS
        forward = {s1}
        backward = {s2}
        swaps = 0
        
        while forward:
            swaps += 1
            next_level = set()
            
            for curr in forward:
                # 找第一个不匹配位置
                i = 0
                while i < len(curr) and curr[i] == s2[i]:
                    i += 1
                
                # 尝试交换
                for j in range(i + 1, len(curr)):
                    if curr[j] == s2[i]:
                        curr_list = list(curr)
                        curr_list[i], curr_list[j] = curr_list[j], curr_list[i]
                        next_state = ''.join(curr_list)
                        
                        # 如果在另一端找到了
                        if next_state in backward:
                            return swaps
                        
                        next_level.add(next_state)
            
            forward = next_level
            
            # 优化：始终从小的那一端扩展
            if len(forward) > len(backward):
                forward, backward = backward, forward
        
        return -1
```

**代码说明：**
- 从两端同时搜索，提高效率
- 每次选择较小的集合扩展

### 方法三：A* 搜索（启发式搜索）

```python
class Solution:
    def kSimilarity(self, s1: str, s2: str) -> int:
        import heapq
        
        if s1 == s2:
            return 0
        
        def heuristic(s: str) -> int:
            """启发函数：估计还需要多少次交换"""
            return sum(s[i] != s2[i] for i in range(len(s))) // 2
        
        # 优先队列：(估计总代价, 实际代价, 当前字符串)
        heap = [(heuristic(s1), 0, s1)]
        visited = {s1: 0}
        
        while heap:
            _, swaps, curr = heapq.heappop(heap)
            
            if curr == s2:
                return swaps
            
            # 找第一个不匹配位置
            i = 0
            while i < len(curr) and curr[i] == s2[i]:
                i += 1
            
            # 尝试交换
            for j in range(i + 1, len(curr)):
                if curr[j] == s2[i]:
                    curr_list = list(curr)
                    curr_list[i], curr_list[j] = curr_list[j], curr_list[i]
                    next_state = ''.join(curr_list)
                    
                    if next_state not in visited or visited[next_state] > swaps + 1:
                        visited[next_state] = swaps + 1
                        priority = swaps + 1 + heuristic(next_state)
                        heapq.heappush(heap, (priority, swaps + 1, next_state))
        
        return -1
```

**代码说明：**
- 使用启发函数估计剩余代价
- 优先搜索更有希望的路径

## 复杂度分析

### 方法一：BFS
- **时间复杂度**：O(n! / (k! × (n-k)!))，最坏情况需要遍历很多状态，但剪枝后实际很小。
- **空间复杂度**：O(n!)，visited 集合的大小。

### 方法二：双向 BFS
- **时间复杂度**：O(√(状态数))，双向搜索能大幅减少搜索空间。
- **空间复杂度**：O(状态数)。

### 方法三：A*
- **时间复杂度**：取决于启发函数的质量，通常优于普通 BFS。
- **空间复杂度**：O(状态数)。

## 关键点总结

1. **BFS 应用**：最短路径问题的经典算法
2. **贪心剪枝**：只考虑第一个不匹配位置，大幅减少搜索空间
3. **有意义的交换**：只交换能让 curr[i] == s2[i] 的位置
4. **去重优化**：使用 visited 集合避免重复状态
5. **双向搜索**：从两端搜索能提高效率

## 易错点

1. **交换所有位置**：不应该尝试所有可能的交换，只交换有意义的
   ```python
   # ❌ 错误：搜索空间太大
   for j in range(i + 1, len(curr)):
       # 交换所有位置
   
   # ✅ 正确：只交换有意义的
   for j in range(i + 1, len(curr)):
       if curr[j] == s2[i]:  # 有意义的交换
   ```

2. **忘记去重**：会导致重复搜索，超时

3. **字符串不可变**：Python 字符串不可变，需要转为 list 再交换

4. **BFS 队列元素**：别忘了存储交换次数
