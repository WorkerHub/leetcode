## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

如果满足以下条件，则子数组 `nums[l..r]` 是一个 **漂亮子数组**：

- 对于数组中每个从 0 开始的位 `j`（`0 <= j <= 19`），`nums[l..r]` 中该位为 1 的元素数量是偶数。

返回 `nums` 中漂亮子数组的数目。

**示例 1：**

```
输入：nums = [4,3,1,2,4]
输出：2
解释：漂亮子数组为 [4,3,1,2] 和 [4]（单个 4）。
注意 [4] 每一位都是偶数个（0 个），所以是漂亮子数组。
```

**示例 2：**

```
输入：nums = [1,10,4]
输出：0
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`

## 解题思路

**前缀 XOR + 哈希表**：

子数组 `[l, r]` 每一位 1 的个数为偶数，等价于 `nums[l] XOR nums[l+1] XOR ... XOR nums[r] == 0`。

令 `prefix[i]` 为 `nums[0] XOR nums[1] XOR ... XOR nums[i-1]`，则子数组 `[l, r]` 的 XOR = `prefix[r+1] XOR prefix[l]`。

当 `prefix[r+1] == prefix[l]` 时，子数组 XOR 为 0，即为漂亮子数组。

用哈希表统计每个前缀 XOR 出现次数，每次遇到重复的前缀 XOR，就累加对应次数。

## Python 代码实现

### 方法一：前缀 XOR + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def beautifulSubarrays(self, nums: List[int]) -> int:
        count = defaultdict(int)
        count[0] = 1  # 前缀 XOR 为 0 初始一个（空前缀）

        prefix = 0
        ans = 0
        for x in nums:
            prefix ^= x
            # 找之前有多少个相同前缀 XOR
            ans += count[prefix]
            count[prefix] += 1

        return ans
```

### 方法二：排序前缀 XOR（不用哈希表）

```python
from typing import List

class Solution:
    def beautifulSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        # 计算所有前缀 XOR
        prefix = [0] * (n + 1)
        for i, x in enumerate(nums):
            prefix[i + 1] = prefix[i] ^ x

        # 排序后统计相邻相等的对数
        prefix.sort()
        ans = 0
        i = 0
        while i < len(prefix):
            j = i
            while j < len(prefix) and prefix[j] == prefix[i]:
                j += 1
            cnt = j - i
            ans += cnt * (cnt - 1) // 2  # C(cnt, 2)
            i = j
        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(n)，单次遍历
- 方法二时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. "每一位 1 的个数为偶数" 等价于 "XOR 为 0"
2. 子数组 XOR = 前缀 XOR 的差（异或意义下的"差" = 再异或一次）
3. 前缀 XOR 相等 ⟹ 子数组 XOR 为 0

## 易错点

1. 初始化 `count[0] = 1`，表示空前缀（下标 0 之前）
2. 先累加 `count[prefix]` 再更新 `count[prefix] += 1`，顺序不能反
3. 方法二用组合数 C(n, 2) = n*(n-1)/2 统计相等对数
