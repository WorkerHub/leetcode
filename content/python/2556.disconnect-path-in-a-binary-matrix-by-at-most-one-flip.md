## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。你最多可以将一个 `1` 修改为 `0`。

当矩阵 **不存在** 从左上角 `(0, 0)` 到右下角 `(m-1, n-1)` 的路径（每步只能向右或向下移动，且只能经过值为 1 的格子）时，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：grid = [[1,1,1],[1,0,0],[1,1,1]]
输出：false
解释：存在路径 (0,0)→(0,1)→(0,2)→(1,2)... 等，无论删除哪个 1 都无法断开。
```

**示例 2：**

```
输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：false
```

**提示：**

- `m == grid.length`, `n == grid[i].length`
- `1 <= m, n <= 1000`
- `grid[i][j]` 为 0 或 1
- `grid[0][0] == grid[m-1][n-1] == 1`

## 解题思路

**关键观察**：如果矩阵有两条不相交的路径（从左上到右下），则无论删除哪一个格子都无法同时断开两条路径，返回 false。

如果只有一条路径，删除路径上的某格即可断开，返回 true。

**算法**：进行两次 DFS/BFS：
1. 第一次 DFS：找到一条路径，并将路径上的格子（除起点和终点）标记为 0
2. 第二次 DFS：在修改后的图上检查是否还有路径

若第二次 DFS 仍有路径，说明存在两条不相交路径，返回 false；否则返回 true。

## Python 代码实现

### 方法一：两次 DFS（推荐）

```python
from typing import List

class Solution:
    def isPossibleToCutPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        def dfs(r, c):
            if r == m - 1 and c == n - 1:
                return True
            grid[r][c] = 0  # 标记已访问（走过的路设为 0）
            # 只能向右或向下
            for dr, dc in [(1, 0), (0, 1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                    if dfs(nr, nc):
                        return True
            return False

        # 第一次 DFS：找一条路径并标记
        # 恢复起点和终点
        if not dfs(0, 0):
            return True  # 原本就没有路径
        grid[0][0] = 1
        grid[m-1][n-1] = 1

        # 第二次 DFS：检查是否还有路径
        return not dfs(0, 0)
```

### 方法二：DP 判断是否存在路径

```python
from typing import List

class Solution:
    def isPossibleToCutPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        def has_path(g):
            # DP：dp[i][j] = 是否可达 (i,j)
            dp = [[False] * n for _ in range(m)]
            dp[0][0] = g[0][0] == 1
            for i in range(m):
                for j in range(n):
                    if i == 0 and j == 0:
                        continue
                    if g[i][j] == 0:
                        continue
                    from_up = dp[i-1][j] if i > 0 else False
                    from_left = dp[i][j-1] if j > 0 else False
                    dp[i][j] = from_up or from_left
            return dp[m-1][n-1]

        import copy

        def mark_path(g):
            # DFS 标记一条路径为 0（除起终点）
            def dfs(r, c):
                if r == m-1 and c == n-1:
                    return True
                g[r][c] = 0
                for dr, dc in [(1,0),(0,1)]:
                    nr, nc = r+dr, c+dc
                    if 0 <= nr < m and 0 <= nc < n and g[nr][nc] == 1:
                        if dfs(nr, nc):
                            return True
                return False
            return dfs(0, 0)

        g2 = [row[:] for row in grid]
        if not mark_path(g2):
            return True
        g2[0][0] = 1
        g2[m-1][n-1] = 1
        return not has_path(g2)
```

## 复杂度分析

- 时间复杂度：O(m * n)，两次 DFS
- 空间复杂度：O(m * n)，递归栈 + DP 数组

## 关键点总结

1. 两次 DFS：第一次标记路径，第二次检验是否还有路径
2. 若第一次 DFS 后恢复起终点，第二次无路径，则返回 true
3. 本质是判断是否只有一条路径（通过删除它可以断开）

## 易错点

1. 恢复起点 (0,0) 和终点 (m-1, n-1) 不能被标记为 0
2. 路径方向只能向右或向下（不能向左或向上）
3. 两次 DFS 共用同一个 grid，注意修改顺序
