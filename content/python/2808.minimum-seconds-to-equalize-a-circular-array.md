## 题目描述

给你一个下标从 0 开始长度为 `n` 的整数数组 `nums`。

每秒可以对数组执行以下操作（同时对所有元素）：
- 对于每个下标 `i`，`nums[i]` 可以替换为 `nums[i-1]`、`nums[i]` 或 `nums[i+1]` 中的任意一个（**数组是环形的**）。

返回使数组 `nums` 中所有元素相等所需的**最少秒数**。

**示例 1：**
```
输入：nums = [1,2,1,2]
输出：1
解释：1 秒后，下标 1 和 3 的值可以改为相邻的 1，所有元素变为 1
```

**示例 2：**
```
输入：nums = [2,1,3,3,2]
输出：2
解释：选择值 3，两个 3 可以在 2 秒内覆盖所有元素
```

**示例 3：**
```
输入：nums = [5,5,5,5]
输出：0
解释：已经相等
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键观察：** 若最终所有元素都变为值 `v`，那么只有 `v` 可以"扩散"。在 t 秒内，每个位置上的 `v` 可以向左右各扩展 t 步。

因此，对于值 `v` 来说，需要让所有位置都被某个 `v` 的位置覆盖。在环形数组中，两个相邻 `v` 之间的最大间距决定了扩散时间。

**算法：**
1. 用哈希表记录每个值出现的所有位置
2. 对每个值，计算相邻位置之间的最大间距（环形）
3. 答案 = `min(max_gap // 2)` over all values

为什么是 `max_gap // 2`：两个 `v` 之间距离为 d，中间点最多距离 `d // 2`（整除），所以需要 `d // 2` 秒。

## Python 代码实现

### 方法一：哈希表 + 最大间距（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def minimumSeconds(self, nums: List[int]) -> int:
        n = len(nums)
        # 记录每个值出现的所有下标
        positions = defaultdict(list)
        for i, v in enumerate(nums):
            positions[v].append(i)

        ans = n  # 初始化为最大可能值

        for v, pos in positions.items():
            # 计算相邻位置之间的最大间距（环形）
            max_gap = 0
            m = len(pos)
            for i in range(m):
                # 当前位置和下一个位置之间的间距
                next_i = (i + 1) % m
                if next_i == 0:
                    # 最后一个和第一个之间（环形）
                    gap = n - pos[-1] + pos[0]
                else:
                    gap = pos[next_i] - pos[i]
                max_gap = max(max_gap, gap)
            ans = min(ans, max_gap // 2)

        return ans
```

### 方法二：简洁写法（统一处理环形）

```python
from collections import defaultdict
from typing import List

class Solution:
    def minimumSeconds(self, nums: List[int]) -> int:
        n = len(nums)
        positions = defaultdict(list)
        for i, v in enumerate(nums):
            positions[v].append(i)

        ans = n
        for pos in positions.values():
            # 把第一个位置复制到末尾，模拟环形
            pos_with_wrap = pos + [pos[0] + n]
            # 计算所有相邻间距的最大值
            max_gap = max(
                pos_with_wrap[i + 1] - pos_with_wrap[i]
                for i in range(len(pos_with_wrap) - 1)
            )
            ans = min(ans, max_gap // 2)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表建立 O(n)，遍历所有位置之和也是 O(n)
- 空间复杂度：O(n)，存储所有位置的哈希表

## 图解示例

```
nums = [2,1,3,3,2], n = 5
值 2 的位置：[0, 4]
- 间距：4-0=4（0到4）, 5-4+0=1（环形从4回到0）
- max_gap = 4, max_gap//2 = 2

值 1 的位置：[1]
- 环形间距：5（绕一圈）
- max_gap = 5, max_gap//2 = 2

值 3 的位置：[2, 3]
- 间距：3-2=1, 5-3+2=4
- max_gap = 4, max_gap//2 = 2

答案 = min(2, 2, 2) = 2
```

## 关键点总结

1. 最优策略：选择某个值，让它从各自位置向外扩散
2. 对于值 v，扩散时间由相邻两个 v 之间的最大间距决定，时间 = max_gap // 2
3. 环形数组：最后一个位置和第一个位置也相邻，需特殊处理
4. 答案是所有值中扩散时间的最小值

## 易错点

1. 环形间距：最后一个位置到第一个位置的距离 = `n - pos[-1] + pos[0]`
2. 取整向下：`max_gap // 2` 而不是 `(max_gap + 1) // 2`
3. 注意只有一个位置的值：间距 = n（整个数组），需要 n//2 秒
