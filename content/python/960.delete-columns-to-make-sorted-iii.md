## 题目描述

给定由 `n` 个字符串组成的数组 `strs`，其中每个字符串长度相等。

选取一个删除索引序列，对于 `strs` 中的每个字符串，删除对应每个索引处的字符。

比如，有 `strs = ["abcdef", "uvwxyz"]`，删除索引序列 `{0, 2, 3}`，删除后 `strs` 为 `["bef", "vyz"]`。

假设，我们选择了一组删除索引 `answer`，那么在执行删除操作之后，最终得到的数组的元素是按**字典序**（`strs[0] <= strs[1] <= strs[2] ... <= strs[n - 1]`）排列的，然后请你返回 `answer.length` 的最小可能值。

**示例 1：**
```
输入：strs = ["babca","bbazb"]
输出：3
解释：
删除 0、1 和 4 这三列后，最终得到的数组是 strs = ["bc", "az"]。
这两行是分别按字典序排列的（即，strs[0][0] <= strs[0][1] 且 strs[1][0] <= strs[1][1]）。
注意，strs[0] > strs[1] —— 数组 strs 不一定是按字典序排列的。
```

**示例 2：**
```
输入：strs = ["edcba"]
输出：4
解释：如果删除的列少于 4 列，则剩下的行都不会按字典序排列。
```

**示例 3：**
```
输入：strs = ["ghi","def","abc"]
输出：0
解释：所有行都已按字典序排列。
```

**提示：**
- `n == strs.length`
- `1 <= n <= 100`
- `1 <= strs[i].length <= 100`
- `strs[i]` 由小写英文字母组成

## 解题思路

这道题要求保留最少的列，使得每一行都是字典序排列的。可以转化为：**求最长的列子序列，使得保留这些列后每行都是非递减的**。

**核心思想：**
1. 问题转化为求最长递增子序列（LIS）的变体
2. 使用动态规划，`dp[i]` 表示以第 `i` 列结尾的最长有效列序列的长度
3. 对于每一列 `j < i`，检查是否可以将第 `i` 列接在第 `j` 列后面
4. 判断条件：对于所有行，第 `j` 列的字符都 `<=` 第 `i` 列的字符

**算法流程：**
1. 初始化 `dp` 数组，每列单独存在时长度为 1
2. 对于每一列 `i`，检查之前的每一列 `j`
3. 如果所有行的 `strs[row][j] <= strs[row][i]`，则可以转移
4. 最终答案为总列数减去最长有效列序列的长度

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        n = len(strs)  # 行数
        m = len(strs[0])  # 列数
        
        # dp[i] 表示以第 i 列结尾的最长有效列序列长度
        dp = [1] * m
        
        # 枚举每一列作为结尾
        for i in range(1, m):
            # 检查之前的每一列
            for j in range(i):
                # 检查是否可以将第 i 列接在第 j 列后面
                valid = True
                for row in range(n):
                    # 所有行都必须满足非递减关系
                    if strs[row][j] > strs[row][i]:
                        valid = False
                        break
                
                if valid:
                    dp[i] = max(dp[i], dp[j] + 1)
        
        # 最少删除列数 = 总列数 - 最长有效列序列长度
        return m - max(dp)
```

### 方法二：动态规划（优化版）

```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        if not strs:
            return 0
        
        m = len(strs[0])  # 列数
        
        # dp[i] 表示保留第 i 列时，前面最多能保留多少列（包括第 i 列）
        dp = [1] * m
        
        for i in range(m):
            for j in range(i):
                # 检查第 j 列和第 i 列是否可以同时保留
                # 即：对所有行，第 j 列字符 <= 第 i 列字符
                if all(strs[k][j] <= strs[k][i] for k in range(len(strs))):
                    dp[i] = max(dp[i], dp[j] + 1)
        
        return m - max(dp)
```

### 方法三：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        n = len(strs)
        m = len(strs[0])
        
        def canFollow(j, i):
            """检查第 i 列能否跟在第 j 列后面"""
            for row in range(n):
                if strs[row][j] > strs[row][i]:
                    return False
            return True
        
        @lru_cache(None)
        def dfs(col):
            """从第 col 列开始，能保留的最多列数"""
            if col == m:
                return 0
            
            # 不保留当前列
            res = dfs(col + 1)
            
            # 尝试保留当前列
            # 找前面能接上的列
            max_prev = 0
            for prev in range(col):
                if canFollow(prev, col):
                    max_prev = max(max_prev, dfs(prev))
            
            # 也可以当前列是第一列
            res = max(res, max_prev + 1)
            
            return res
        
        max_kept = max(dfs(i) for i in range(m))
        return m - max_kept
```

### 方法四：暴力 + 优化（理解用）

```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        m = len(strs[0])
        max_keep = 0
        
        # 尝试所有可能的列组合（使用位掩码）
        for mask in range(1 << m):
            # 提取保留的列
            cols = [i for i in range(m) if mask & (1 << i)]
            
            if not cols:
                continue
            
            # 检查这些列是否有效
            valid = True
            for row in strs:
                for i in range(len(cols) - 1):
                    if row[cols[i]] > row[cols[i + 1]]:
                        valid = False
                        break
                if not valid:
                    break
            
            if valid:
                max_keep = max(max_keep, len(cols))
        
        return m - max_keep
```

## 复杂度分析

### 方法一/二：动态规划
- **时间复杂度**：O(m² × n)，其中 m 是列数，n 是行数。需要枚举所有列对，每次检查需要 O(n)
- **空间复杂度**：O(m)，dp 数组空间

### 方法三：记忆化搜索
- **时间复杂度**：O(m² × n)
- **空间复杂度**：O(m)，递归栈和缓存空间

### 方法四：暴力
- **时间复杂度**：O(2^m × m × n)，指数级别，仅适用于小数据
- **空间复杂度**：O(m)

## 关键点总结

1. **问题转化**：删除最少的列 = 保留最多的有效列 = 求最长递增子序列
2. **状态定义**：`dp[i]` 表示以第 i 列结尾的最长有效列序列
3. **转移条件**：检查所有行是否满足第 j 列 <= 第 i 列
4. **边界情况**：只有一列时，需要检查该列是否单调
5. **优化思路**：使用 `all()` 函数简化代码

## 易错点

1. **理解题意**：每一行要字典序排列，不是整个数组按行排序
2. **转移条件**：必须所有行都满足条件，不是部分行
3. **初始化**：每列单独存在时长度为 1，不是 0
4. **答案计算**：是总列数减去保留的列数，不是直接返回 dp 值
5. **边界处理**：空数组或只有一行的情况
