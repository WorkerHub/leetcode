## 题目描述

给你两个整数 `x` 和 `y`，表示你在笛卡尔坐标系中的位置 `(x, y)`。同时给你一个数组 `points`，其中 `points[i] = [a_i, b_i]`，表示在笛卡尔坐标系中有一个点 `(a_i, b_i)`。

如果一个点与你所在的位置共享相同的行或者列（即 `a_i == x` 或 `b_i == y`），我们称该点是**有效点**。

返回距你当前位置 **曼哈顿距离** 最近的**有效点**的下标（下标从 `0` 开始）。如果有多个最近的有效点，返回下标**最小**的一个。如果没有有效点，返回 `-1`。

**示例：**
```
输入：x = 3, y = 4, points = [[1,4],[-1,4],[2,2],[3,3],[3,4]]
输出：2
```

**提示：**
- `1 <= points.length <= 10^4`

## 解题思路

遍历所有点，找满足 `a_i == x` 或 `b_i == y` 的点，计算曼哈顿距离，取最小距离的最小下标。

## 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def nearestValidPoint(self, x: int, y: int, points: List[List[int]]) -> int:
        min_dist = float('inf')
        best_idx = -1
        
        for i, (a, b) in enumerate(points):
            # 判断是否为有效点
            if a == x or b == y:
                dist = abs(a - x) + abs(b - y)
                if dist < min_dist:
                    min_dist = dist
                    best_idx = i
        
        return best_idx
```

### 方法二：过滤后取最小

```python
from typing import List

class Solution:
    def nearestValidPoint(self, x: int, y: int, points: List[List[int]]) -> int:
        valid = [
            (abs(a - x) + abs(b - y), i)
            for i, (a, b) in enumerate(points)
            if a == x or b == y
        ]
        
        if not valid:
            return -1
        
        # 按距离升序，距离相同时按下标升序
        valid.sort()
        return valid[0][1]
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 有效点：共享 x 坐标或 y 坐标
2. 曼哈顿距离：`|a - x| + |b - y|`
3. 多个最小距离时取下标最小的（线性扫描天然满足）

## 易错点

- 要同时满足有效性（共享坐标）和最小距离
- 下标最小：线性从左到右扫，用严格小于 `<` 保证只在更小时更新
