## 题目描述

有一个长度为 n 的篱笆需要粉刷，你有 k 种颜色可以选择。你必须粉刷所有的篱笆柱子，并且要遵循以下规则：

- 每个柱子只能涂一种颜色
- 最多只能有两个相邻的柱子颜色相同

返回你可以粉刷篱笆的方案总数。

**示例 1：**
```
输入: n = 3, k = 2
输出: 6
解释: 
用 c1 表示颜色 1，c2 表示颜色 2
所有可能的涂色方案:
  柱 1  柱 2  柱 3
  -----  -----  -----
   c1     c1     c2
   c1     c2     c1
   c1     c2     c2
   c2     c1     c1
   c2     c1     c2
   c2     c2     c1
```

**示例 2：**
```
输入: n = 1, k = 1
输出: 1
```

**示例 3：**
```
输入: n = 7, k = 2
输出: 42
```

**提示：**
- 1 <= n <= 50
- 1 <= k <= 10^5

## 解题思路

这是一道经典的动态规划问题。关键是理解"最多两个相邻柱子颜色相同"这个约束。

### 状态定义

定义两种状态：
- `same[i]`：第 i 个柱子与第 i-1 个柱子颜色相同的方案数
- `diff[i]`：第 i 个柱子与第 i-1 个柱子颜色不同的方案数

总方案数：`total[i] = same[i] + diff[i]`

### 状态转移

**对于 same[i]：**
- 第 i 个柱子与第 i-1 个颜色相同
- 那么第 i-1 个必须与第 i-2 个颜色不同（否则三个连续相同）
- `same[i] = diff[i-1]`

**对于 diff[i]：**
- 第 i 个柱子与第 i-1 个颜色不同
- 可以从第 i-1 个的任何方案转移过来
- 有 k-1 种颜色选择（排除与 i-1 相同的颜色）
- `diff[i] = (same[i-1] + diff[i-1]) * (k-1) = total[i-1] * (k-1)`

### 初始状态

- `n = 1`：有 k 种方案
- `n = 2`：
  - 两个柱子相同：k 种
  - 两个柱子不同：k * (k-1) 种
  - 总计：k + k*(k-1) = k*k 种

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        """
        动态规划，维护 same 和 diff 两个状态
        """
        if n == 0 or k == 0:
            return 0
        if n == 1:
            return k
        
        # 初始状态（前两个柱子）
        same = k          # 前两个柱子颜色相同的方案数
        diff = k * (k - 1)  # 前两个柱子颜色不同的方案数
        
        # 从第 3 个柱子开始
        for i in range(3, n + 1):
            # 第 i 个与第 i-1 个相同：必须从 diff 转移
            new_same = diff
            # 第 i 个与第 i-1 个不同：从所有方案转移
            new_diff = (same + diff) * (k - 1)
            
            same, diff = new_same, new_diff
        
        return same + diff
```

### 方法二：优化的动态规划

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        """
        使用一个变量维护总方案数
        """
        if n == 0 or k == 0:
            return 0
        if n == 1:
            return k
        if n == 2:
            return k * k
        
        # prev2: i-2 的总方案数
        # prev1: i-1 的总方案数
        prev2 = k
        prev1 = k * k
        
        for i in range(3, n + 1):
            # 当前方案数 = 
            # 1. 与前一个不同（从 prev1 转移）：prev1 * (k-1)
            # 2. 与前一个相同（从 prev2 转移，中间必须不同）：prev2 * (k-1)
            current = prev1 * (k - 1) + prev2 * (k - 1)
            # 或者简化为：current = (prev1 + prev2) * (k - 1)
            
            prev2 = prev1
            prev1 = current
        
        return prev1
```

### 方法三：数学公式推导

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        """
        推导出的递推公式
        """
        if n == 0 or k == 0:
            return 0
        if n == 1:
            return k
        if n == 2:
            return k * k
        
        # f(n) = (k-1) * [f(n-1) + f(n-2)]
        # 这是一个递推关系
        dp = [0] * (n + 1)
        dp[1] = k
        dp[2] = k * k
        
        for i in range(3, n + 1):
            dp[i] = (k - 1) * (dp[i - 1] + dp[i - 2])
        
        return dp[n]
```

### 方法四：空间优化版

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        """
        空间优化到 O(1)
        """
        if n == 0 or k == 0:
            return 0
        if n == 1:
            return k
        if n == 2:
            return k * k
        
        # 只需要记录前两个状态
        two_back = k
        one_back = k * k
        
        for i in range(3, n + 1):
            current = (k - 1) * (one_back + two_back)
            two_back = one_back
            one_back = current
        
        return one_back
```

### 方法五：详细注释版（便于理解）

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        """
        详细解释每一步的动态规划
        """
        if n == 0 or k == 0:
            return 0
        
        if n == 1:
            # 只有一个柱子，k 种颜色
            return k
        
        # 定义状态：
        # same: 当前柱子与前一个柱子颜色相同的方案数
        # diff: 当前柱子与前一个柱子颜色不同的方案数
        
        # 第一个柱子：k 种选择
        # 第二个柱子：
        #   - 与第一个相同：k 种（每种颜色各有一种方案）
        #   - 与第一个不同：k * (k-1) 种
        same = k
        diff = k * (k - 1)
        
        # 从第三个柱子开始遍历
        for i in range(3, n + 1):
            # 当前柱子与前一个相同：
            # 前一个必须与再前一个不同（防止三连）
            # 所以只能从 diff 转移过来
            new_same = diff
            
            # 当前柱子与前一个不同：
            # 可以从前一个的任何状态转移（same 或 diff）
            # 有 k-1 种颜色选择
            new_diff = (same + diff) * (k - 1)
            
            same, diff = new_same, new_diff
        
        # 总方案数 = 相同的 + 不同的
        return same + diff
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历 n 个柱子

**空间复杂度：** O(1)
- 只使用常数个变量

**示例：** n = 3, k = 2

```
柱子 1 | 柱子 2 | 柱子 3 | 说明
-------|--------|--------|------
  c1   |   c1   |   c2   | 前两个相同，第三个必须不同
  c1   |   c2   |   c1   | 前两个不同，第三个可以是 c1
  c1   |   c2   |   c2   | 前两个不同，第三个可以是 c2
  c2   |   c1   |   c1   | 前两个不同，第三个可以是 c1
  c2   |   c1   |   c2   | 前两个不同，第三个可以是 c2
  c2   |   c2   |   c1   | 前两个相同，第三个必须不同

总计：6 种方案
```

**状态转移过程：**

```
i = 1: total = k = 2

i = 2: 
  same = k = 2
  diff = k*(k-1) = 2*1 = 2
  total = 2 + 2 = 4

i = 3:
  same = diff(上一轮) = 2
  diff = (same + diff)(上一轮) * (k-1) = 4 * 1 = 4
  total = 2 + 4 = 6
```

## 关键点总结

1. **状态分类**：将问题分解为"与前一个相同"和"与前一个不同"两种状态
2. **约束理解**：最多两个连续相同，意味着三个连续必须不同
3. **状态转移**：
   - `same[i] = diff[i-1]`（必须从不同状态转移）
   - `diff[i] = total[i-1] * (k-1)`（可以从任何状态转移）
4. **边界情况**：n = 1 和 n = 2 需要特殊处理
5. **空间优化**：只需要记录前两个状态，可以优化到 O(1) 空间

## 易错点

1. **初始状态设置错误**
   ```python
   # 错误：n=2 时 same 应该是 k，不是 1
   same = 1
   
   # 正确
   same = k
   ```

2. **状态转移条件混淆**
   ```python
   # 错误：same 应该只从 diff 转移
   new_same = same + diff
   
   # 正确：same 只能从 diff 转移（防止三连）
   new_same = diff
   ```

3. **边界情况遗漏**
   ```python
   # 要处理 n=0, n=1, n=2 的特殊情况
   if n == 0 or k == 0:
       return 0
   if n == 1:
       return k
   ```

4. **公式理解错误**
   ```python
   # 错误：忘记 (k-1) 这个因子
   new_diff = same + diff
   
   # 正确：有 k-1 种颜色选择
   new_diff = (same + diff) * (k - 1)
   ```
