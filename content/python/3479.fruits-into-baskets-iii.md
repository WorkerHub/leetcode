## 题目描述

给你一个整数数组 `fruits`，以及一个二维整数数组 `baskets`，其中 `baskets[i] = [capacity_i, type_i]`。

从左到右将每个水果放入第一个合适的篮子：
- 水果 `fruits[j]` 只能放入类型等于 `fruits[j]` 且还有剩余容量的篮子
- 如果没有合适的篮子，该水果无法放置

返回无法放置的水果数量。

**示例：**

```
输入：fruits = [1,2,1,3,2], baskets = [[2,1],[1,2],[1,3]]
输出：1
```

**提示：**
- `1 <= fruits.length <= 10^5`
- `1 <= baskets.length <= 10^5`
- `1 <= baskets[i][0], baskets[i][1] <= 10^9`

## 解题思路

对于每种水果类型，找到第一个有剩余容量且类型匹配的篮子。

维护有序数据结构（按下标排序），对每种类型的篮子用有序集合快速查找。

或者：线段树维护每个篮子的剩余容量，对每种类型的篮子列表用二分查找找第一个有容量的篮子。

## Python 代码实现

### 方法一：哈希表 + 有序集合

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def numUnplacedFruits(self, fruits: List[int], baskets: List[List[int]]) -> int:
        # 按类型分组篮子，记录 (下标) 的有序集合（下标越小越优先）
        from collections import defaultdict

        # type -> SortedList of (index) with remaining capacity
        type_baskets = defaultdict(SortedList)

        # 初始化：记录每个篮子的容量
        cap = {}
        for i, (c, t) in enumerate(baskets):
            cap[i] = c
            type_baskets[t].add(i)

        unplaced = 0
        for fruit in fruits:
            if fruit not in type_baskets or not type_baskets[fruit]:
                unplaced += 1
                continue

            # 找第一个（下标最小的）有剩余容量的篮子
            placed = False
            sl = type_baskets[fruit]

            # 在有序集合中找第一个可用篮子
            for idx in sl:
                if cap[idx] > 0:
                    cap[idx] -= 1
                    if cap[idx] == 0:
                        sl.remove(idx)
                    placed = True
                    break

            if not placed:
                unplaced += 1

        return unplaced
```

### 方法二：线段树（高效版）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numUnplacedFruits(self, fruits: List[int], baskets: List[List[int]]) -> int:
        m = len(baskets)
        cap = [b[0] for b in baskets]

        # 线段树：查询区间内第一个 cap > 0 的位置
        # 按类型分组，对每种类型维护其篮子下标列表

        type_indices = defaultdict(list)
        for i, (c, t) in enumerate(baskets):
            type_indices[t].append(i)

        # 对每种类型，维护其篮子剩余容量（按下标顺序）
        # 用 SortedList 存有剩余容量的篮子下标
        type_available = defaultdict(SortedList)
        for t, indices in type_indices.items():
            for idx in indices:
                if cap[idx] > 0:
                    type_available[t].add(idx)

        from sortedcontainers import SortedList

        type_avail = defaultdict(SortedList)
        for i, (c, t) in enumerate(baskets):
            if c > 0:
                type_avail[t].add(i)

        unplaced = 0
        for fruit in fruits:
            sl = type_avail[fruit]
            if not sl:
                unplaced += 1
            else:
                idx = sl[0]  # 最小下标（最左边）
                cap[idx] -= 1
                if cap[idx] == 0:
                    sl.remove(idx)

        return unplaced
```

### 方法三：简洁实现

```python
from typing import List
from collections import defaultdict
from sortedcontainers import SortedList

class Solution:
    def numUnplacedFruits(self, fruits: List[int], baskets: List[List[int]]) -> int:
        cap = {}
        avail = defaultdict(SortedList)

        for i, (c, t) in enumerate(baskets):
            cap[i] = c
            if c > 0:
                avail[t].add(i)

        ans = 0
        for f in fruits:
            sl = avail[f]
            if not sl:
                ans += 1
            else:
                idx = sl[0]
                cap[idx] -= 1
                if cap[idx] == 0:
                    sl.remove(idx)

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + m) log m)，n 为水果数，m 为篮子数
- 空间复杂度：O(m)

## 关键点总结

1. 按类型分组篮子，每种类型独立管理
2. SortedList 自动维护有序状态，快速获取最小下标（最左边）
3. 容量用完时从有序集合中移除

## 易错点

1. 找的是下标最小的篮子（最左边），不是容量最大的
2. 容量为 0 的篮子不能放水果，要从可用集合中移除
3. 水果类型不在篮子类型中时，直接算无法放置
