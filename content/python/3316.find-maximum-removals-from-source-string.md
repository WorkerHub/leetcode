## 题目描述

给你一个字符串 `source`，一个字符串 `pattern`，以及一个整数数组 `targetIndices`。

每次操作可以删除 `source` 中下标在 `targetIndices` 中的一个字符（每个下标最多用一次）。

返回在保证 `pattern` 仍是 `source` 的子序列的前提下，最多可以删除多少个字符。

**示例：**
```
输入：source = "abbaa", pattern = "aba", targetIndices = [0, 1, 2]
输出：1
解释：可以删除下标 0 的字符，剩余 "bbaa"，"aba" 仍是 "bbaa" 的子序列
```

**提示：**
- `1 <= pattern.length <= source.length <= 3000`
- `source` 和 `pattern` 只含小写字母
- `targetIndices` 是 `[0, source.length-1]` 的子集，且已排序

## 解题思路

**动态规划：**

定义 `dp[i][j]` = 使用 `source[0..i-1]` 匹配 `pattern[0..j-1]`（子序列），可以删除的最多目标下标数。

转移：
- 若 `i` 在 `targetIndices` 中（设 `is_target[i] = True`）：
  - 删除 `source[i]`：`dp[i+1][j] = max(dp[i+1][j], dp[i][j] + 1)`
  - 不删除，若 `source[i] == pattern[j]`：`dp[i+1][j+1] = max(dp[i+1][j+1], dp[i][j])`
  - 不删除，`source[i]` 不参与匹配：`dp[i+1][j] = max(dp[i+1][j], dp[i][j])`
- 若 `i` 不在 `targetIndices` 中：
  - 若 `source[i] == pattern[j]`：`dp[i+1][j+1] = max(dp[i+1][j+1], dp[i][j])`
  - 不参与匹配：`dp[i+1][j] = max(dp[i+1][j], dp[i][j])`

答案：`max(dp[n][m])` = `dp[n][m]`（匹配完整 pattern 时的最大删除数）。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxRemovals(self, source: str, pattern: str, targetIndices: List[int]) -> int:
        n, m = len(source), len(pattern)
        target_set = set(targetIndices)
        
        # dp[i][j] = 处理完 source 前 i 个字符，匹配了 pattern 前 j 个字符，最多删除多少个
        # 初始化为 -1（不可达）
        INF = float('-inf')
        dp = [[INF] * (m + 1) for _ in range(n + 1)]
        dp[0][0] = 0
        
        for i in range(n):
            for j in range(m + 1):
                if dp[i][j] == INF:
                    continue
                
                if i in target_set:
                    # 选择1：删除 source[i]（只有在 target 中才能删除）
                    dp[i + 1][j] = max(dp[i + 1][j], dp[i][j] + 1)
                
                # 选择2：不删除 source[i]，尝试匹配 pattern[j]
                if j < m and source[i] == pattern[j]:
                    dp[i + 1][j + 1] = max(dp[i + 1][j + 1], dp[i][j])
                
                # 选择3：不删除，不匹配（跳过）
                dp[i + 1][j] = max(dp[i + 1][j], dp[i][j])
        
        return dp[n][m] if dp[n][m] != INF else 0
```

### 方法二：空间优化（一维 DP）

```python
from typing import List

class Solution:
    def maxRemovals(self, source: str, pattern: str, targetIndices: List[int]) -> int:
        n, m = len(source), len(pattern)
        target_set = set(targetIndices)
        
        INF = float('-inf')
        dp = [INF] * (m + 1)
        dp[0] = 0
        
        for i in range(n):
            # 从后往前遍历，防止同行状态被覆盖
            new_dp = dp[:]
            for j in range(m + 1):
                if dp[j] == INF:
                    continue
                if i in target_set:
                    # 删除 source[i]
                    new_dp[j] = max(new_dp[j], dp[j] + 1)
                if j < m and source[i] == pattern[j]:
                    # 匹配
                    new_dp[j + 1] = max(new_dp[j + 1], dp[j])
                # 跳过（已在 new_dp = dp[:] 中处理）
            dp = new_dp
        
        return dp[m] if dp[m] != INF else 0
```

## 复杂度分析

- 时间复杂度：O(n * m)，二维 DP
- 空间复杂度：O(n * m) 或 O(m)（空间优化版）

## 关键点总结

1. DP 状态 `dp[i][j]` 表示处理到 `source[i]`、匹配了 `pattern[j]` 个字符时的最大删除数。
2. 对每个位置，选择"删除"（仅限目标下标）、"匹配"或"跳过"三种操作。
3. 初始状态不可达的 DP 格子用负无穷标记，防止无效传递。

## 易错点

1. 删除操作只对 `targetIndices` 中的下标有效。
2. DP 初始化时，只有 `dp[0][0] = 0`，其余为不可达（-inf）。
3. 空间优化时需要复制数组再更新，防止当行状态影响下一个转移。
