## 题目描述

给定一个整数数组 nums 和一个正整数 k，判断是否可能把这个数组分成 k 个非空子集，其总和都相等。

**示例：**
```
输入：nums = [4,3,2,3,5,2,1], k = 4
输出：true
解释：可以分为 [5], [1,4], [2,3], [2,3] 四个子集
```

## Python 代码实现

### 方法一：回溯

```python
from typing import List

class Solution:
    def canPartitionKSubsets(self, nums: List[int], k: int) -> bool:
        total = sum(nums)
        if total % k != 0:
            return False
        
        target = total // k
        nums.sort(reverse=True)
        
        if nums[0] > target:
            return False
        
        used = [False] * len(nums)
        
        def backtrack(k_left, cur_sum, start):
            if k_left == 0:
                return True
            
            if cur_sum == target:
                return backtrack(k_left - 1, 0, 0)
            
            for i in range(start, len(nums)):
                if used[i] or cur_sum + nums[i] > target:
                    continue
                
                used[i] = True
                if backtrack(k_left, cur_sum + nums[i], i + 1):
                    return True
                used[i] = False
            
            return False
        
        return backtrack(k, 0, 0)
```

## 复杂度分析

- 时间复杂度：O(k * 2^n)
- 空间复杂度：O(n)

## 关键点总结

1. 先判断总和能否整除 k
2. 使用回溯尝试所有可能
3. 剪枝优化提高效率
