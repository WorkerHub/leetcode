## 题目描述

给你一个数组 `start = [startX, startY]` 表示起点，`target = [targetX, targetY]` 表示终点。在二维网格中每步的代价是移动的曼哈顿距离。还有一些特殊道路 `specialRoads[i] = [x1, y1, x2, y2, cost]`，使用这条路可以以 `cost` 的代价从 `(x1,y1)` 到 `(x2,y2)`（覆盖原来的曼哈顿距离）。

返回从起点到终点的最小代价。

**示例：**
```
输入：start = [1,1], target = [4,5], specialRoads = [[1,2,3,3,2],[3,4,4,5,1]]
输出：5
解释：直走 |1-4|+|1-5|=7；使用特殊路可能更省
```

**数据范围：**
- 1 <= specialRoads.length <= 200
- start.length == target.length == 4
- 1 <= startX, startY, targetX, targetY, x1, y1, x2, y2 <= 10^5

## 解题思路

Dijkstra 最短路：将起点、终点和所有特殊路的端点视为图的节点，边权为：
- 两点之间的曼哈顿距离（普通移动）
- 特殊路的代价 `cost`（若特殊路代价 < 曼哈顿距离才有意义）

用 Dijkstra 从起点出发求到终点的最短路。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumCost(self, start: List[int], target: List[int],
                    specialRoads: List[List[int]]) -> int:
        # 将所有关键点加入图
        # 用 Dijkstra，节点为坐标点
        # 边：任意两点间的曼哈顿距离，以及特殊路

        sx, sy = start
        tx, ty = target

        def manhattan(x1, y1, x2, y2):
            return abs(x1 - x2) + abs(y1 - y2)

        # dist[(x,y)] = 从起点到 (x,y) 的最短代价
        dist = {(sx, sy): 0}
        # 最小堆：(代价, x, y)
        heap = [(0, sx, sy)]

        while heap:
            d, x, y = heapq.heappop(heap)

            if d > dist.get((x, y), float('inf')):
                continue

            # 直接走到终点
            new_d = d + manhattan(x, y, tx, ty)
            if new_d < dist.get((tx, ty), float('inf')):
                dist[(tx, ty)] = new_d
                heapq.heappush(heap, (new_d, tx, ty))

            # 使用特殊路
            for x1, y1, x2, y2, cost in specialRoads:
                # 先走到 (x1, y1)，再使用特殊路到 (x2, y2)
                to_entry = d + manhattan(x, y, x1, y1)
                total = to_entry + cost
                if total < dist.get((x2, y2), float('inf')):
                    dist[(x2, y2)] = total
                    heapq.heappush(heap, (total, x2, y2))

        return dist.get((tx, ty), manhattan(sx, sy, tx, ty))
```

## 复杂度分析

- 时间复杂度：O((n + 1) * n * log n)，n 为特殊路数量
- 空间复杂度：O(n)

## 关键点总结

1. Dijkstra：从每个已到达的点，尝试使用各条特殊路
2. 特殊路代价 cost 不一定比曼哈顿距离小，但 Dijkstra 会自动选优
3. 终点也可以直接从任意点走曼哈顿距离到达

## 易错点

1. 起点到特殊路入口 + 特殊路代价，不能只考虑直接到出口
2. 不同点的坐标可能相同（重叠），用坐标元组作为节点标识
