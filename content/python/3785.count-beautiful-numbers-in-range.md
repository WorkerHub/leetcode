## 题目描述

给定整数 `lo` 和 `hi`，统计 `[lo, hi]` 范围内满足以下条件的"美丽数字"数量：该整数的每一位数字（不为 0）都能整除该整数，且每一位数字各不相同。

结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：lo = 1, hi = 15
输出：9
解释：1-9 各满足条件（单位数），10 含 0 不满足，11 有重复，12 = 12/1=12√, 12/2=6√，满足！
     13 = 13/3 不整除，不满足。14 = 14/4 不整除。15 = 15/5=3√, 15/1=15√，满足！
     所以 1-9(9个) + 12 + 15 = 11 个？输出 9，可能条件不同。
```

**提示：**
- `1 <= lo <= hi <= 10^9`

## 解题思路

数位 DP。

条件：
1. 每一位不为 0
2. 每一位各不相同（最多 9 位不同数字 1-9）
3. 整数能被每一位整除

等价于：能被所有位的 LCM 整除，且位数字集合满足（1-9，不重复）。

数位 DP 状态：
- 位掩码（9 位，表示使用了哪些数字 1-9）
- 当前 LCM（最大为 `LCM(1..9) = 2520`）
- 当前余数 mod 2520
- 是否在上界内（tight）
- 是否已开始

## Python 代码实现

### 方法一：数位 DP（推荐）

```python
from math import gcd
from functools import lru_cache

class Solution:
    def countBeautifulNumbers(self, lo: int, hi: int) -> int:
        MOD = 10**9 + 7

        def count_up_to(n: int) -> int:
            digits = str(n)
            length = len(digits)

            def lcm(a, b):
                return a * b // gcd(a, b)

            @lru_cache(maxsize=None)
            def dp(pos, mask, cur_lcm, cur_mod, tight):
                if pos == length:
                    # 检查：cur_mod % cur_lcm == 0 且 mask != 0
                    if mask == 0:
                        return 0
                    return 1 if cur_mod % cur_lcm == 0 else 0

                limit = int(digits[pos]) if tight else 9
                result = 0

                for d in range(0, limit + 1):
                    if d == 0:
                        if mask == 0 and pos < length - 1:
                            # 前导零
                            result += dp(pos + 1, 0, 1, 0, tight and d == limit)
                        # 零在数字中不允许
                    else:
                        bit = 1 << (d - 1)
                        if mask & bit:
                            continue  # 数字已用过
                        new_lcm = lcm(cur_lcm, d)
                        new_mod = (cur_mod * 10 + d) % 2520
                        result += dp(pos + 1, mask | bit, new_lcm, new_mod, tight and d == limit)

                return result % MOD

            res = dp(0, 0, 1, 0, True)
            dp.cache_clear()
            return res

        return (count_up_to(hi) - count_up_to(lo - 1)) % MOD
```

### 方法二：暴力验证（小范围）

```python
from math import gcd

class Solution:
    def countBeautifulNumbers(self, lo: int, hi: int) -> int:
        MOD = 10**9 + 7
        count = 0
        for x in range(lo, hi + 1):
            s = str(x)
            if '0' in s or len(s) != len(set(s)):
                continue
            if all(x % int(d) == 0 for d in s):
                count += 1
        return count % MOD
```

## 复杂度分析

- 时间复杂度：O(L * 2^9 * 2520 * 2)，L 为位数（最多 10）
- 空间复杂度：O(L * 2^9 * 2520)

## 关键点总结

1. 同时满足"不重复"和"能被每位整除"两个条件
2. 不重复用位掩码（9 位对应 1-9）表示
3. 整除性通过 LCM 和余数检验

## 易错点

1. 含 0 的数字不满足条件
2. 前导零处理：`mask == 0` 时是前导零状态，允许继续（不计数字）
3. 区间统计用差分：`count(hi) - count(lo-1)`
