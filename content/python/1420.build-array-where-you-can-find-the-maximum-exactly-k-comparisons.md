## 题目描述

给你三个整数 `n`、`m` 和 `k`。下述算法用于找某个数组中的最大元素：

```
maximum_value = -1
maximum_index = -1
search_cost = 0
for i from 0 to n-1:
    if nums[i] > maximum_value:
        maximum_value = nums[i]
        maximum_index = i
        search_cost = search_cost + 1
return maximum_index
```

构造一个长度为 `n`、元素在 `[1, m]` 范围内的数组，使得上述算法的 `search_cost` 恰好等于 `k`。

返回满足条件的数组数目，答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 2, m = 3, k = 1
输出：6
解释：有 6 种数组满足条件：[1,1],[2,1],[2,2],[3,1],[3,2],[3,3]
```

**示例 2：**

```
输入：n = 5, m = 2, k = 3
输出：0
解释：没有满足条件的数组。
```

**示例 3：**

```
输入：n = 9, m = 1, k = 1
输出：1
```

**提示：**

- `1 <= n <= 50`
- `1 <= m <= 100`
- `0 <= k <= n`

## 解题思路

### 动态规划

**理解 search_cost：**

`search_cost` 等于数组的"前缀最大值改变的次数"，也就是从左到右遇到新的最大值的次数。

例如 `[1, 3, 2, 4]`：
- 位置0: 1 > -1，更新，cost=1
- 位置1: 3 > 1，更新，cost=2
- 位置2: 2 < 3，不更新
- 位置3: 4 > 3，更新，cost=3

**DP 状态定义：**

`dp[i][j][cost]` = 前 `i` 个元素，当前最大值为 `j`，搜索代价为 `cost` 的方案数。

**转移：**

对第 `i+1` 个元素，设其值为 `v`（`1 <= v <= m`）：

- 若 `v <= j`（不更新最大值）：`dp[i+1][j][cost] += dp[i][j][cost]`，共有 `j` 个选择（1 到 j）
- 若 `v > j`（更新最大值，cost+1）：`dp[i+1][v][cost+1] += dp[i][j][cost]`，对所有 `v > j` 有效

**初始状态：**
- `dp[0][0][0] = 1`（空数组，最大值为0，代价为0，1种方案）

**答案：**
- `sum(dp[n][j][k] for j in range(1, m+1))`

**优化：** 可以用滚动数组将空间从 O(n * m * k) 优化到 O(m * k)。

## Python 代码实现

### 方法一：三维 DP（直观版）

```python
class Solution:
    def numOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7

        # dp[i][j][cost]：前 i 个元素，当前最大值为 j，搜索代价为 cost 的方案数
        # 为简化，用滚动数组：只保留上一行 dp[j][cost]
        # 初始化：dp[0][0] = 1（空数组，最大值0，代价0）
        dp = [[0] * (k + 1) for _ in range(m + 1)]
        dp[0][0] = 1  # 最大值为 0，代价为 0，1 种

        for i in range(n):
            new_dp = [[0] * (k + 1) for _ in range(m + 1)]
            for j in range(m + 1):
                for cost in range(k + 1):
                    if dp[j][cost] == 0:
                        continue
                    # 选一个不超过 j 的值（不更新最大值）
                    # v 可以是 1 到 j，共 j 种选择
                    new_dp[j][cost] = (new_dp[j][cost] + dp[j][cost] * j) % MOD
                    # 选一个比 j 大的值 v（更新最大值，cost+1）
                    if cost + 1 <= k:
                        for v in range(j + 1, m + 1):
                            new_dp[v][cost + 1] = (new_dp[v][cost + 1] + dp[j][cost]) % MOD
            dp = new_dp

        return sum(dp[j][k] for j in range(1, m + 1)) % MOD
```

### 方法二：前缀和优化（推荐，减少内层循环）

```python
class Solution:
    def numOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7

        # dp[j][c] = 当前最大值为 j，搜索代价为 c 的方案数
        dp = [[0] * (k + 1) for _ in range(m + 1)]
        dp[0][0] = 1

        for i in range(n):
            new_dp = [[0] * (k + 1) for _ in range(m + 1)]

            # 维护前缀和：prefix[c][j] = sum(dp[1..j][c])
            # 这样"选比 j 大的值"的转移可以 O(1) 完成
            prefix = [[0] * (k + 1) for _ in range(m + 2)]
            for j in range(1, m + 1):
                for c in range(k + 1):
                    prefix[j][c] = (prefix[j - 1][c] + dp[j][c]) % MOD

            for j in range(1, m + 1):
                for c in range(k + 1):
                    # 情况1：选一个 <= j 的值（不更新最大值），j 种选择
                    new_dp[j][c] = (new_dp[j][c] + dp[j][c] * j) % MOD

                    # 情况2：从最大值 < j 的状态，选 j 作为新最大值（cost+1）
                    # sum(dp[0..j-1][c-1]) = prefix[j-1][c-1]
                    if c >= 1:
                        new_dp[j][c] = (new_dp[j][c] + prefix[j - 1][c - 1]) % MOD

            dp = new_dp

        return sum(dp[j][k] for j in range(1, m + 1)) % MOD
```

### 方法三：记忆化递归（自顶向下，更直观）

```python
from functools import lru_cache

class Solution:
    def numOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7

        @lru_cache(maxsize=None)
        def dp(i: int, max_val: int, cost: int) -> int:
            """
            从位置 i 开始，当前最大值为 max_val，剩余需要的搜索代价为 cost
            返回填满 [i, n-1] 的方案数
            """
            if i == n:
                # 已填完，检查代价是否恰好为 0
                return 1 if cost == 0 else 0

            result = 0

            # 选一个不超过 max_val 的值（不更新最大值）
            # 有 max_val 种选择（1 到 max_val）
            result += dp(i + 1, max_val, cost) * max_val

            # 选一个超过 max_val 的值 v（更新最大值，cost-1）
            if cost > 0:
                for v in range(max_val + 1, m + 1):
                    result += dp(i + 1, v, cost - 1)

            return result % MOD

        return dp(0, 0, k)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三维 DP | O(n * m^2 * k) | O(m * k) |
| 前缀和优化 | O(n * m * k) | O(m * k) |
| 记忆化递归 | O(n * m^2 * k) | O(n * m * k) |

方法二用前缀和将内层循环优化掉，时间复杂度最优。

## 关键点总结

1. `search_cost` 等于"从左到右，前缀最大值更新的次数"
2. DP 状态三维：（元素个数，当前最大值，当前代价）
3. 转移：选小于等于最大值的数（不增加代价）或选更大的数（代价+1）
4. 前缀和优化：避免对"所有比当前最大值大的 v"内层枚举

## 易错点

1. 初始最大值设为 0（表示还没有选任何元素），代价为 0
2. 选不超过 j 的值时，有 `j` 种选择（1 到 j，不是 0 到 j）
3. 最终答案只统计 `dp[n][j][k]`（j >= 1），不包含 j = 0
