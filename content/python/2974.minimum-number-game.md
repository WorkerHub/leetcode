## 题目描述

给你一个长度为偶数的整数数组 `nums`，你和你的朋友轮流进行操作：
- 你先从 `nums` 中取出最小值，放入空数组 `arr` 末尾
- 然后你的朋友从 `nums` 中取出最小值，放入 `arr` 末尾

重复直到 `nums` 为空，返回 `arr`。

**示例 1：**
```
输入：nums = [5,4,2,3]
输出：[3,2,5,4]
解释：
操作 1：你取 2，朋友取 3，arr=[3,2] (朋友先放)
操作 2：你取 4，朋友取 5，arr=[3,2,5,4]
等等... 实际根据题意是你先取放进 arr，朋友再取放进 arr
操作 1：你取 2 放入，arr=[2]；朋友取 3 放入，arr=[2,3]
操作 2：你取 4 放入，arr=[2,3,4]；朋友取 5 放入，arr=[2,3,4,5]
这不对，答案是 [3,2,5,4]...
重读题意：你取一个，朋友取一个，**朋友先放入 arr**
```

**实际题意：** 每轮你先取最小值，然后朋友再取最小值，但朋友的先放入 arr，然后你的放入 arr。

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`
- `nums.length` 是偶数

## 解题思路

排序后，每两个一组处理：
- 第一个（较小的）是你取的
- 第二个（较大的）是朋友取的
- 朋友先放，你后放：先放 nums[1]，再放 nums[0]

## Python 代码实现

### 方法一：排序后两两交换（推荐）

```python
from typing import List

class Solution:
    def numberGame(self, nums: List[int]) -> List[int]:
        nums.sort()
        arr = []
        for i in range(0, len(nums), 2):
            # 你取 nums[i]（较小），朋友取 nums[i+1]（较大）
            # 朋友先放，你后放
            arr.append(nums[i + 1])
            arr.append(nums[i])
        return arr
```

### 方法二：使用最小堆模拟

```python
from typing import List
import heapq

class Solution:
    def numberGame(self, nums: List[int]) -> List[int]:
        heap = list(nums)
        heapq.heapify(heap)
        arr = []

        while heap:
            mine = heapq.heappop(heap)      # 你取最小
            friends = heapq.heappop(heap)    # 朋友取下一个最小
            arr.append(friends)              # 朋友先放
            arr.append(mine)                 # 你后放

        return arr
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 你先取最小，朋友再取最小（第二小）
2. 朋友先放入 arr（第二小），你后放入 arr（最小）
3. 排序后每两个交换位置

## 易错点

1. 放入顺序：朋友的值先放，你的值后放（不是取的顺序）
2. 排序后连续两个 nums[i], nums[i+1]，先放 nums[i+1] 再放 nums[i]
