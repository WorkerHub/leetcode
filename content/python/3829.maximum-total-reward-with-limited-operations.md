## 题目描述

给你一个整数数组 `rewardValues`，表示若干奖励值。你可以按任意顺序获取奖励，规则是：若当前总奖励值 `x` 严格小于某个奖励值 `v`，则可以获取 `v`，总奖励增加 `v`。

但每个奖励最多只能获取 `k` 次（1 <= k <= 3）。

返回可以获得的最大总奖励值。

**示例 1：**

```
输入：rewardValues = [1, 1, 3, 3], k = 1
输出：4
解释：获取 1 后总奖励为 1，再获取 3（1 < 3），总奖励 4。
```

**示例 2：**

```
输入：rewardValues = [1, 6, 4, 3, 2], k = 2
输出：11
解释：可以多次获取某些奖励，最大总奖励 11。
```

**提示：**
- `1 <= rewardValues.length <= 2000`
- `1 <= rewardValues[i] <= 2000`
- `1 <= k <= 3`

## 解题思路

使用位运算 DP 优化背包：
1. 将 rewardValues 排序并去重（保留最多 k 个）。
2. `dp` 是一个大整数（bitset），`dp` 的第 i 位为 1 表示总奖励值 i 可达。
3. 对每个奖励值 `v`，若当前总奖励 `x < v`，则可以加上 `v`。
4. 转移：将 `dp` 中所有小于 `v` 的位左移 `v` 位，合并到 `dp` 中。

## Python 代码实现

### 方法一：位集 DP（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxReward(self, rewardValues: List[int], k: int) -> int:
        # 每个值最多使用 k 次
        cnt = Counter(rewardValues)
        # 构建新的 rewardValues 列表（每个值重复 min(cnt, k) 次）
        vals = []
        for v, c in cnt.items():
            vals.extend([v] * min(c, k))
        vals.sort()

        # 用大整数（Python int 作为 bitset）
        # dp 的第 i 位为 1 表示可以达到总奖励 i
        dp = 1  # 第 0 位为 1，表示初始总奖励 0 可达

        for v in vals:
            # 找所有可达的 x < v，加上 v 得到 x + v
            # 提取 dp 中第 0 到 v-1 位（小于 v 的可达值）
            # mask = (1 << v) - 1 提取低 v 位
            mask = (1 << v) - 1
            # 将这些位左移 v 位（加上奖励 v）
            dp |= (dp & mask) << v

        # 找 dp 中最高的 1 位
        return dp.bit_length() - 1
```

### 方法二：标准 DP（适用于小范围）

```python
from typing import List
from collections import Counter

class Solution:
    def maxReward(self, rewardValues: List[int], k: int) -> int:
        max_val = max(rewardValues) * 2
        cnt = Counter(rewardValues)

        # dp[x] = 总奖励为 x 是否可达
        dp = {0}
        vals = sorted(set(rewardValues))

        for v in vals:
            times = min(cnt[v], k)
            for _ in range(times):
                new_dp = set(dp)
                for x in dp:
                    if x < v:
                        new_dp.add(x + v)
                dp = new_dp

        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(n * max_val / 64)，位运算优化的背包
- 空间复杂度：O(max_val / 64)，大整数存储

## 关键点总结

1. Python 大整数可以作为高效的 bitset，进行位移和按位或操作。
2. 每次对奖励值 v，只有当前总奖励 x < v 时才能获取，用掩码 `(1 << v) - 1` 提取。
3. k 次限制通过重复添加奖励值到列表中处理。

## 易错点

1. Python 整数无上限，无需担心溢出，但 bit_length 可能超出预期范围。
2. k 次限制不是对所有值，而是对每个不同值各自限制。
3. 排序后按从小到大处理，保证 x < v 的条件成立。
