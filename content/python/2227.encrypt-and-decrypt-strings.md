## 题目描述

给你一个类 `Encrypter`，需要支持两个操作：

- **encrypt(word1)**：将 `word1` 的每个字母替换为其对应的加密字符串（一到多个字母），返回加密后的字符串。每个字母对应唯一的加密串。
- **decrypt(word2)**：对 `word2` 进行解密，计算有多少个 `dictionary` 中的单词可以加密成 `word2`。

初始化时给出：
- `keys`：要加密的原始字母列表。
- `values`：每个字母对应的加密串（可能有相同的加密串）。
- `dictionary`：合法单词列表。

**示例：**
```
输入：
["Encrypter", "encrypt", "decrypt"]
[[["a","b","c","d"], ["ei","zf","ei","am"], ["abcd","acbd","adbc","badc","dacb","cbda","abad","abab"]], ["abcd"], ["eizfeiam"]]
输出：[null, "eizfeiam", 2]
```

## 解题思路

**加密**：直接查映射表，每个字符对应加密串拼接。

**解密**：
- 暴力法：将 `dictionary` 中每个单词加密后比较是否等于 `word2`。
- 为避免解密时逐字符匹配（多对一），预处理：将所有字典单词加密后存入哈希表，解密时直接查频次。

由于 `values` 中不同字母可能对应相同加密串，解密时存在歧义，故只统计字典中能加密成 `word2` 的单词数。

## 代码实现

### 方法一：预处理字典（推荐）

```python
from typing import List
from collections import Counter

class Encrypter:
    def __init__(self, keys: List[str], values: List[str], dictionary: List[str]):
        # 构建字母到加密串的映射
        self.enc_map = {k: v for k, v in zip(keys, values)}
        # 预先将字典中所有单词加密，统计每个加密结果的频次
        self.dec_count = Counter()
        for word in dictionary:
            encrypted = self.encrypt(word)
            if encrypted:  # 只有完全可加密的才统计
                self.dec_count[encrypted] += 1

    def encrypt(self, word1: str) -> str:
        result = []
        for ch in word1:
            if ch not in self.enc_map:
                return ""  # 无法加密
            result.append(self.enc_map[ch])
        return "".join(result)

    def decrypt(self, word2: str) -> int:
        # 直接查预处理的频次表
        return self.dec_count.get(word2, 0)
```

### 方法二：暴力解密（对比理解）

```python
from typing import List

class Encrypter:
    def __init__(self, keys: List[str], values: List[str], dictionary: List[str]):
        self.enc_map = {k: v for k, v in zip(keys, values)}
        self.dictionary = dictionary

    def encrypt(self, word1: str) -> str:
        result = []
        for ch in word1:
            if ch not in self.enc_map:
                return ""
            result.append(self.enc_map[ch])
        return "".join(result)

    def decrypt(self, word2: str) -> int:
        # 对字典中每个单词，加密后检查是否等于 word2
        count = 0
        for word in self.dictionary:
            if self.encrypt(word) == word2:
                count += 1
        return count
```

## 复杂度分析

**方法一（预处理字典）：**
- 初始化：O(D * L)，D 为字典大小，L 为最长单词长度。
- encrypt：O(L)。
- decrypt：O(1)，直接查表。

**方法二（暴力）：**
- decrypt：O(D * L)，每次需检查所有字典单词。

## 关键点总结

1. 解密的难点在于不同字母可能对应相同加密串，导致一对多映射。
2. 预处理字典：将所有字典单词提前加密，解密时直接查频次，O(1) 回答查询。
3. 加密时若某字母不在 keys 中，返回空串（无法加密）。

## 易错点

- 初始化时预处理字典，而不是每次解密时遍历。
- 若字典单词包含不在 `keys` 中的字母，`encrypt` 返回空串，不应计入频次。
