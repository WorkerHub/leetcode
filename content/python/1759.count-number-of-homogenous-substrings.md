## 题目描述

给你一个字符串 `s`，返回 `s` 中同质子字符串的数目。由于答案可能很大，只需返回对 `10^9 + 7` 取余后的结果。

**同质字符串**：如果一个字符串中的所有字符都相同，则该字符串是同质的。

**示例 1：**
```
输入：s = "abbcccaa"
输出：13
解释：同质子字符串为：
"a" x 3, "b" x 2, "c" x 3, "aa" x 1, "bb" x 1, "cc" x 3, "ccc" x 1 = 3+2+3+1+1+3+1 = 13（不对，重新算）
实际上：a(1), bb(2+1=3子), ccc(3+2+1=6子), aa(2+1=3子) = 1+3+6+3=13
```

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

统计每段连续相同字符的长度 `k`，对每段贡献的同质子字符串数为 `k * (k + 1) / 2`（长度 1 到 k 的子串数量）。

所有段的贡献求和即为答案。

## 代码实现

### 方法一：统计连续段（推荐）

```python
class Solution:
    def countHomogenous(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        ans = 0
        i = 0
        n = len(s)
        
        while i < n:
            # 找当前字符的连续段
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            # 长度为 k = j - i 的连续段贡献 k*(k+1)//2 个同质子串
            k = j - i
            ans = (ans + k * (k + 1) // 2) % MOD
            i = j
        
        return ans
```

### 方法二：使用 itertools.groupby

```python
from itertools import groupby

class Solution:
    def countHomogenous(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        ans = 0
        
        for char, group in groupby(s):
            k = sum(1 for _ in group)
            ans = (ans + k * (k + 1) // 2) % MOD
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历
- **空间复杂度**：O(1)

## 关键点总结

1. 连续相同字符段长度为 k，贡献 `k*(k+1)/2` 个同质子串
2. 各段独立统计，相加取模

## 易错点

- 注意结果取模
- 整除 `//` 不会有精度问题
