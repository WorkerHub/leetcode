## 题目描述

给定一个整数数组 `nums`，将其分成 `k` 个非空子数组（连续），使得每个子数组的异或值的最大值最小化。返回该最小的最大异或值。

**示例 1：**

```
输入：nums = [1,2,3,4], k = 2
输出：3
解释：分法 [1,2,3] 和 [4]：异或 1^2^3=0, 4。最大=4。
     分法 [1,2] 和 [3,4]：异或 1^2=3, 3^4=7。最大=7。
     分法 [1] 和 [2,3,4]：异或 1, 2^3^4=5。最大=5。
     最小最大为 5。（示例仅供参考）
```

**提示：**
- `1 <= k <= nums.length <= 1000`
- `0 <= nums[i] <= 10^9`

## 解题思路

区间 DP 或前缀异或 + DP：

定义 `dp[i][j]` = 将 `nums[0..i-1]` 分成 `j` 组的最小最大异或值。

前缀异或 `prefix[i] = nums[0] ^ ... ^ nums[i-1]`，区间 [l, r] 的异或值 = `prefix[r+1] ^ prefix[l]`。

状态转移：
`dp[i][j] = min over all split points m (dp[m][j-1], xor(m, i))`

其中 `xor(m, i) = prefix[i] ^ prefix[m]`，最终最大值 = `max(dp[m][j-1], xor(m,i))`。

## Python 代码实现

### 方法一：前缀异或 + DP（推荐）

```python
from typing import List

class Solution:
    def minimizeXor(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 前缀异或
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] ^ nums[i]

        INF = float('inf')
        # dp[i][j] = nums[0..i-1] 分 j 段的最小最大异或值
        dp = [[INF] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        for i in range(1, n + 1):
            for j in range(1, min(i, k) + 1):
                for m in range(j - 1, i):
                    # 最后一段 [m, i-1]，异或值 = prefix[i] ^ prefix[m]
                    seg_xor = prefix[i] ^ prefix[m]
                    val = max(dp[m][j - 1], seg_xor)
                    dp[i][j] = min(dp[i][j], val)

        return dp[n][k]
```

### 方法二：二分答案 + 贪心验证

```python
from typing import List

class Solution:
    def minimizeXor(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] ^ nums[i]

        def feasible(mid: int) -> bool:
            # 贪心：从左到右，尽量合并，当异或值 <= mid 时分割
            count = 0
            cur_xor = 0
            for x in nums:
                cur_xor ^= x
                if cur_xor > mid:
                    # 当前段已超过 mid，必须在上一个位置分割
                    # 但若单个元素就超过 mid，则不可行
                    count += 1
                    cur_xor = x
                    if cur_xor > mid:
                        return False
            count += 1
            return count <= k

        # 二分答案
        # 所有可能的异或值在 0 到 所有元素的最大异或范围内
        lo, hi = 0, (1 << 30) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)（DP），O(n log MAX)（二分+贪心）
- 空间复杂度：O(n * k)（DP），O(1)（二分）

## 关键点总结

1. 前缀异或 `prefix[i]` 使区间异或查询 O(1)
2. DP 状态：`dp[i][j]` = 前 i 个元素分 j 段的最小最大异或值
3. 二分答案：验证给定上限时，贪心检查能否用 <= k 段覆盖

## 易错点

1. 前缀异或的区间计算：`[l, r]` = `prefix[r+1] ^ prefix[l]`
2. 二分验证中，单个元素超过 mid 则无解
3. 贪心时贪心方向：让每段异或值尽量不超过 mid
