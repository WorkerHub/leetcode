## 题目描述

给定一个数组 nums，如果 i < j 且 nums[i] > 2 * nums[j]，我们就将 (i, j) 称作一个重要翻转对。

你需要返回给定数组中的重要翻转对的数量。

**示例 1：**
```
输入：nums = [1,3,2,3,1]
输出：2
```

**示例 2：**
```
输入：nums = [2,4,3,5,1]
输出：3
```

**提示：**
- 0 <= nums.length <= 5 * 10^4
- -2^31 <= nums[i] <= 2^31 - 1

## 解题思路

这道题是经典的逆序对问题的变种，可以使用归并排序、树状数组或线段树解决。

### 核心思想

1. **暴力解法**（O(n²)）：
   - 双重循环枚举所有 (i, j) 对
   - 检查是否满足条件
   - 超时，不可行

2. **归并排序**（推荐）：
   - 在归并排序过程中统计翻转对
   - 左右两部分各自有序后，统计跨越的翻转对
   - 时间复杂度 O(n log n)

3. **关键观察**：
   - 对于已排序的左右两部分
   - 对于左边的每个元素，找右边有多少个元素满足条件
   - 利用有序性快速统计

## Python 代码实现

### 方法一：归并排序（推荐）

```python
from typing import List

class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        """
        归并排序统计翻转对
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        def merge_sort(arr, start, end):
            if start >= end:
                return 0
            
            mid = (start + end) // 2
            # 递归统计左右两部分的翻转对
            count = merge_sort(arr, start, mid) + merge_sort(arr, mid + 1, end)
            
            # 统计跨越中点的翻转对
            j = mid + 1
            for i in range(start, mid + 1):
                # 找到右边第一个不满足 nums[i] > 2 * nums[j] 的位置
                while j <= end and arr[i] > 2 * arr[j]:
                    j += 1
                count += j - (mid + 1)
            
            # 合并两个有序数组
            arr[start:end + 1] = sorted(arr[start:end + 1])
            
            return count
        
        return merge_sort(nums, 0, len(nums) - 1)
```

### 方法二：优化的归并排序（避免重复排序）

```python
class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        """
        优化的归并排序，手动合并数组
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        def merge_sort_and_count(start, end):
            if start >= end:
                return 0
            
            mid = (start + end) // 2
            count = merge_sort_and_count(start, mid) + merge_sort_and_count(mid + 1, end)
            
            # 统计翻转对
            j = mid + 1
            for i in range(start, mid + 1):
                while j <= end and nums[i] > 2 * nums[j]:
                    j += 1
                count += j - (mid + 1)
            
            # 手动合并
            temp = []
            i, j = start, mid + 1
            while i <= mid and j <= end:
                if nums[i] <= nums[j]:
                    temp.append(nums[i])
                    i += 1
                else:
                    temp.append(nums[j])
                    j += 1
            
            temp.extend(nums[i:mid + 1])
            temp.extend(nums[j:end + 1])
            nums[start:end + 1] = temp
            
            return count
        
        return merge_sort_and_count(0, len(nums) - 1)
```

### 方法三:使用树状数组（Binary Indexed Tree）

```python
class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        """
        使用树状数组统计
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # 离散化
        all_nums = sorted(set(nums + [num * 2 for num in nums]))
        rank = {num: i + 1 for i, num in enumerate(all_nums)}
        
        # 树状数组
        n = len(all_nums)
        bit = [0] * (n + 1)
        
        def update(idx):
            while idx <= n:
                bit[idx] += 1
                idx += idx & (-idx)
        
        def query(idx):
            res = 0
            while idx > 0:
                res += bit[idx]
                idx -= idx & (-idx)
            return res
        
        count = 0
        # 从右向左处理
        for num in reversed(nums):
            # 查询有多少个数 < num / 2
            count += query(rank[num * 2] - 1)
            # 插入当前数
            update(rank[num])
        
        return count
```

### 方法四：暴力解法（仅供理解）

```python
class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        """
        暴力解法，超时
        
        时间复杂度：O(n²)
        空间复杂度：O(1)
        """
        count = 0
        n = len(nums)
        
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] > 2 * nums[j]:
                    count += 1
        
        return count
```

## 复杂度分析

**方法一、二：归并排序**
- **时间复杂度**：O(n log n)
  - 归并排序：O(n log n)
  - 统计翻转对：每层 O(n)，总共 log n 层
  
- **空间复杂度**：O(n)
  - 临时数组：O(n)
  - 递归栈：O(log n)

**方法三：树状数组**
- **时间复杂度**：O(n log n)
  - 离散化：O(n log n)
  - 树状数组操作：每次 O(log n)，总共 n 次
  
- **空间复杂度**：O(n)
  - 树状数组：O(n)

**方法四：暴力**
- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **分治思想**：将问题分解为子问题
2. **归并排序应用**：在合并过程中统计
3. **有序性利用**：左右两部分有序后快速统计
4. **双指针技巧**：统计时使用双指针
5. **离散化技巧**：树状数组需要离散化

## 易错点

1. **条件判断**
   - 是 nums[i] > 2 * nums[j]，不是 nums[i] > nums[j]
   - 注意是严格大于

2. **统计时机**
   - 在归并之前统计翻转对
   - 不是在归并过程中统计

3. **指针初始化**
   - j 从 mid + 1 开始
   - 每次外层循环不需要重置 j（利用单调性）

4. **数组合并**
   - 统计和合并是两个独立的过程
   - 不要在统计时修改数组

5. **溢出问题**
   - 2 * nums[j] 可能溢出
   - 可以改写为 nums[i] / 2 > nums[j]
   - 但要注意除法的整数运算问题
