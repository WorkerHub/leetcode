## 题目描述

给定一个字符串 `queryIP`。如果是有效的 IPv4 地址，返回 `"IPv4"`；如果是有效的 IPv6 地址，返回 `"IPv6"`；如果不是上述类型的 IP 地址，返回 `"Neither"`。

**有效的 IPv4 地址** 是 `"x1.x2.x3.x4"` 形式的 IP 地址。其中 `0 <= xi <= 255` 且 `xi` 不能包含前导零。

- 例如: `"192.168.1.1"` 、`"192.168.1.0"` 为有效 IPv4 地址，`"192.168.01.1"` 为无效 IPv4 地址；`"192.168.1.00"` 、`"192.168@1.1"` 为无效 IPv4 地址。

**有效的 IPv6 地址** 是 `"x1:x2:x3:x4:x5:x6:x7:x8"` 形式的 IP 地址。其中：

- `1 <= xi.length <= 4`
- `xi` 是一个十六进制字符串，可以包含数字、小写英文字母 `'a'` 到 `'f'` 和大写英文字母 `'A'` 到 `'F'`。
- 在 `xi` 中允许前导零。

例如 `"2001:0db8:85a3:0000:0000:8a2e:0370:7334"` 和 `"2001:db8:85a3:0:0:8A2E:0370:7334"` 是有效的 IPv6 地址，而 `"2001:0db8:85a3::8A2E:037j:7334"` 和 `"02001:0db8:85a3:0000:0000:8a2e:0370:7334"` 是无效的 IPv6 地址。

**示例 1：**
```
输入：queryIP = "172.16.254.1"
输出："IPv4"
解释：有效的 IPv4 地址，返回 "IPv4"
```

**示例 2：**
```
输入：queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
输出："IPv6"
解释：有效的 IPv6 地址，返回 "IPv6"
```

**示例 3：**
```
输入：queryIP = "256.256.256.256"
输出："Neither"
解释：既不是 IPv4 地址，也不是 IPv6 地址
```

**提示：**
- `queryIP` 仅由英文字母，数字，字符 `'.'` 和 `':'` 组成。

## 解题思路

这是一道字符串验证题，需要仔细处理各种边界情况。

**解题步骤：**
1. 根据分隔符判断是 IPv4（`.`）还是 IPv6（`:`）
2. 分别验证 IPv4 和 IPv6 的规则

**IPv4 验证规则：**
- 恰好 4 个部分
- 每个部分是 0-255 的数字
- 不能有前导零（除了 "0" 本身）
- 不能有非数字字符

**IPv6 验证规则：**
- 恰好 8 个部分
- 每个部分是 1-4 位十六进制数
- 只能包含 0-9, a-f, A-F
- 允许前导零

## Python 代码实现

### 方法一：分情况验证（推荐）⭐

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        # 判断是 IPv4 还是 IPv6
        if '.' in queryIP:
            return self.validateIPv4(queryIP)
        elif ':' in queryIP:
            return self.validateIPv6(queryIP)
        else:
            return "Neither"
    
    def validateIPv4(self, ip: str) -> str:
        parts = ip.split('.')
        
        # 必须恰好 4 个部分
        if len(parts) != 4:
            return "Neither"
        
        for part in parts:
            # 不能为空
            if not part:
                return "Neither"
            
            # 不能有前导零（除了 "0" 本身）
            if len(part) > 1 and part[0] == '0':
                return "Neither"
            
            # 必须全是数字
            if not part.isdigit():
                return "Neither"
            
            # 范围检查 0-255
            if int(part) > 255:
                return "Neither"
        
        return "IPv4"
    
    def validateIPv6(self, ip: str) -> str:
        parts = ip.split(':')
        
        # 必须恰好 8 个部分
        if len(parts) != 8:
            return "Neither"
        
        for part in parts:
            # 长度必须是 1-4
            if not part or len(part) > 4:
                return "Neither"
            
            # 必须全是十六进制字符
            for char in part:
                if char not in '0123456789abcdefABCDEF':
                    return "Neither"
        
        return "IPv6"
```

### 方法二：使用正则表达式

```python
import re

class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        # IPv4 正则：4 个 0-255 的数字，用 . 分隔
        ipv4_pattern = r'^(([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\.){3}([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])$'
        
        # IPv6 正则：8 个 1-4 位十六进制数，用 : 分隔
        ipv6_pattern = r'^(([0-9a-fA-F]{1,4}):){7}([0-9a-fA-F]{1,4})$'
        
        if re.match(ipv4_pattern, queryIP):
            return "IPv4"
        elif re.match(ipv6_pattern, queryIP):
            return "IPv6"
        else:
            return "Neither"
```

**优点：** 代码简洁，但正则难以理解和调试

### 方法三：详细验证版

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        def is_valid_ipv4_part(s):
            """验证 IPv4 的一个部分"""
            # 空字符串无效
            if not s:
                return False
            
            # 长度不能超过 3
            if len(s) > 3:
                return False
            
            # 前导零检查
            if s[0] == '0' and len(s) > 1:
                return False
            
            # 必须全是数字
            if not s.isdigit():
                return False
            
            # 范围检查
            return 0 <= int(s) <= 255
        
        def is_valid_ipv6_part(s):
            """验证 IPv6 的一个部分"""
            # 空字符串或长度超过 4
            if not s or len(s) > 4:
                return False
            
            # 必须是十六进制字符
            for char in s:
                if not (char.isdigit() or 'a' <= char.lower() <= 'f'):
                    return False
            
            return True
        
        # IPv4 检查
        if '.' in queryIP and ':' not in queryIP:
            parts = queryIP.split('.')
            if len(parts) == 4 and all(is_valid_ipv4_part(p) for p in parts):
                return "IPv4"
        
        # IPv6 检查
        elif ':' in queryIP and '.' not in queryIP:
            parts = queryIP.split(':')
            if len(parts) == 8 and all(is_valid_ipv6_part(p) for p in parts):
                return "IPv6"
        
        return "Neither"
```

## 复杂度分析

**方法一（分情况验证）：**
- 时间复杂度：O(n)，n 是字符串长度
- 空间复杂度：O(1)

**方法二（正则表达式）：**
- 时间复杂度：O(n)，正则引擎的匹配
- 空间复杂度：O(1)

## 关键点总结

1. **分隔符判断：** 先根据 `.` 或 `:` 区分类型
2. **IPv4 前导零：** `"01"` 无效，但 `"0"` 有效
3. **IPv6 允许前导零：** `"0001"` 有效
4. **部分数量：** IPv4 恰好 4 个，IPv6 恰好 8 个
5. **边界情况：** 空部分、多余分隔符、混合分隔符

## 易错点

1. **前导零判断：** IPv4 不允许，IPv6 允许
   ```python
   # IPv4："01" 无效，"0" 有效
   if s[0] == '0' and len(s) > 1:
       return False
   
   # IPv6："0001" 有效
   ```

2. **混合分隔符：** 同时包含 `.` 和 `:`
   ```python
   # 错误：只检查是否包含
   if '.' in queryIP:
       return validateIPv4(queryIP)
   
   # 正确：确保不包含另一种分隔符
   if '.' in queryIP and ':' not in queryIP:
       return validateIPv4(queryIP)
   ```

3. **空部分：** `"192.168..1"` 或 `"2001::85a3"`
   ```python
   # split 会产生空字符串
   parts = "192.168..1".split('.')  # ['192', '168', '', '1']
   
   # 必须检查
   if not part:
       return "Neither"
   ```

4. **边界值：** IPv4 的 255 和 256
   ```python
   # "255" 有效，"256" 无效
   if int(part) > 255:
       return "Neither"
   ```

5. **字符验证：** IPv6 只能是十六进制
   ```python
   # 错误：允许所有字母
   if part.isalnum():
   
   # 正确：只允许 0-9, a-f, A-F
   if char not in '0123456789abcdefABCDEF':
       return "Neither"
   ```
