## 题目描述

给你一个数组 `rectangles`，其中 `rectangles[i] = [li, wi]` 表示第 `i` 个矩形的长度为 `li`、宽度为 `wi`。

如果存在 `k` 同时满足 `k <= li` 且 `k <= wi`，则可以将第 `i` 个矩形剪切成边长为 `k` 的正方形。

设 `maxLen` 为可以从矩形数组 `rectangles` 切割得到的**最大正方形**边长。

请你统计有多少个矩形能够切割出边长为 `maxLen` 的正方形，并返回矩形**数目**。

**示例 1：**
```
输入：rectangles = [[5,8],[3,9],[5,12],[16,5]]
输出：3
解释：最大正方形边长 = 5，有 3 个矩形能切出
```

**提示：**
- `1 <= rectangles.length <= 1000`
- `rectangles[i].length == 2`
- `1 <= li, wi <= 10^9`

## 解题思路

每个矩形能切割出的最大正方形边长为 `min(li, wi)`。
找到所有矩形中 `min(li, wi)` 的最大值，统计达到该最大值的矩形数量。

## 代码实现

### 方法一：两遍遍历（推荐）

```python
from typing import List

class Solution:
    def countGoodRectangles(self, rectangles: List[List[int]]) -> int:
        # 计算每个矩形能切割出的最大正方形边长
        max_squares = [min(l, w) for l, w in rectangles]
        
        # 找最大边长
        max_len = max(max_squares)
        
        # 统计达到最大边长的矩形数
        return sum(1 for s in max_squares if s == max_len)
```

### 方法二：一遍遍历

```python
from typing import List

class Solution:
    def countGoodRectangles(self, rectangles: List[List[int]]) -> int:
        max_len = 0
        count = 0
        
        for l, w in rectangles:
            side = min(l, w)
            if side > max_len:
                # 更新最大边长，重置计数
                max_len = side
                count = 1
            elif side == max_len:
                count += 1
        
        return count
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历数组
- **空间复杂度**：O(n)（方法一）或 O(1)（方法二）

## 关键点总结

1. 每个矩形能切出的最大正方形边长为 `min(长, 宽)`
2. 找到全局最大值，再统计个数

## 易错点

- 注意是最大正方形，不是任意正方形
