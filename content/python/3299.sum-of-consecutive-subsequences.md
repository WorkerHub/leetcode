## 题目描述

给你一个整数数组 `nums`，如果子序列中**相邻元素之差恰好为 1**（每个连续对差为 1 或 -1），则称为**连续子序列**。

返回所有**连续子序列**的元素之和的总和，答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3]
输出：20
```

**示例 2：**
```
输入：nums = [1,3,5,7]
输出：16
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

与 3284 类似，但这里是子**序列**（不要求连续位置），而连续子序列要求相邻元素差为 1。

等价于：子序列中每个相邻元素对差为 ±1，即子序列中包含连续整数值（按某种顺序排列）。

实际上：连续子序列 = 相邻元素值差恰好为 1 的子序列。

对每个元素 `nums[i]`，考虑其对总和的贡献：
- 在以 i 结尾的连续子序列中，nums[i] 出现的次数
- 用 DP：`dp[v]` = 以值为 v 结尾的连续子序列的总数

转移：当加入 nums[i] = v 时：
- `dp[v] = dp[v-1] + dp[v+1] + 1`（连接到值 v-1 结尾或值 v+1 结尾的子序列，或单独成一个）

贡献：每个以 v 结尾的连续子序列都贡献 v，共 dp[v] 次。

但这样会重复统计。需要仔细处理。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def getSum(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        
        # cnt[v] = 以值 v 结尾的连续子序列数量
        # sum_dp[v] = 以值 v 结尾的所有连续子序列的元素和之总和
        
        cnt = defaultdict(int)
        sum_dp = defaultdict(int)
        total = 0
        
        for v in nums:
            # 新子序列：[v]
            new_cnt = 1
            new_sum = v
            
            # 可以接在以 v-1 结尾的子序列后面
            new_cnt = (new_cnt + cnt[v - 1]) % MOD
            new_sum = (new_sum + sum_dp[v - 1] + v * cnt[v - 1]) % MOD
            
            # 可以接在以 v+1 结尾的子序列后面（差为-1）
            new_cnt = (new_cnt + cnt[v + 1]) % MOD
            new_sum = (new_sum + sum_dp[v + 1] + v * cnt[v + 1]) % MOD
            
            cnt[v] = (cnt[v] + new_cnt) % MOD
            sum_dp[v] = (sum_dp[v] + new_sum) % MOD
            
            total = (total + new_sum) % MOD
        
        return total
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(max_val)

## 关键点总结

1. DP：cnt[v] 统计以值 v 结尾的子序列数，sum_dp[v] 统计其总和
2. 每个新元素可以接在 v-1 或 v+1 结尾的子序列后面
3. 每个子序列末尾加上当前元素 v，总和增加 v * cnt

## 易错点

1. 子序列不要求连续位置（与 3284 的子数组不同）
2. 注意取模运算，避免溢出
