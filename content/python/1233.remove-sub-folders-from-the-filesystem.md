## 题目描述

你是一位系统管理员，手里有一份文件夹列表 `folder`，你的任务是要删除该列表中的所有子文件夹，并以任意顺序返回剩下的文件夹。

如果文件夹 `folder[i]` 位于另一个文件夹 `folder[j]` 下，那么 `folder[i]` 就是 `folder[j]` 的子文件夹。

文件夹的路径是由一个或多个按以下格式串联形成的字符串：'/' 后跟一个或者多个小写英文字母。

例如，"/leetcode" 和 "/leetcode/problems" 都是有效的路径，而空字符串和 "/" 不是。

示例 1：
```
输入：folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
输出：["/a","/c/d","/c/f"]
解释："/a/b" 是 "/a" 的子文件夹，"/c/d/e" 是 "/c/d" 的子文件夹。
```

示例 2：
```
输入：folder = ["/a","/a/b/c","/a/b/d"]
输出：["/a"]
解释：文件夹 "/a/b/c" 和 "/a/b/d" 都会被删除，因为它们都是 "/a" 的子文件夹。
```

示例 3：
```
输入：folder = ["/a/b/c","/a/b/ca","/a/b/d"]
输出：["/a/b/c","/a/b/ca","/a/b/d"]
```

提示：
- `1 <= folder.length <= 4 * 10^4`
- `2 <= folder[i].length <= 100`
- `folder[i]` 只包含小写字母和 '/'
- `folder[i]` 总是以字符 '/' 起始
- 每个文件夹名都是唯一的

## 解题思路

这道题有两种主要思路：

### 思路一：排序 + 前缀匹配

1. 对文件夹列表排序，这样父文件夹一定出现在子文件夹之前
2. 遍历排序后的列表，检查当前文件夹是否是已添加文件夹的子文件夹
3. 判断子文件夹的方法：检查是否以 "父文件夹/" 开头

关键点：排序后 "/a" 会在 "/a/b" 前面，所以只需要检查当前文件夹是否是上一个添加的文件夹的子文件夹。

### 思路二：字典树（Trie）

1. 构建字典树，每个节点代表一个目录
2. 插入时如果遇到已标记为文件夹的节点，说明是子文件夹
3. 遍历字典树，收集所有非子文件夹

## Python 代码实现

### 方法一：排序 + 前缀匹配（推荐）

```python
from typing import List

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        """
        排序后逐个检查是否是前一个的子文件夹
        
        Args:
            folder: 文件夹列表
            
        Returns:
            删除子文件夹后的列表
        """
        # 排序：父文件夹会在子文件夹前面
        folder.sort()
        
        result = []
        
        for f in folder:
            # 如果 result 为空，或者当前文件夹不是上一个的子文件夹
            if not result or not f.startswith(result[-1] + '/'):
                result.append(f)
        
        return result
```

### 方法二：使用集合

```python
from typing import List

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        """
        使用集合检查每个前缀是否存在
        """
        folder_set = set(folder)
        result = []
        
        for f in folder:
            is_subfolder = False
            
            # 检查所有可能的父文件夹
            path = f
            for i in range(len(f)):
                if f[i] == '/' and i > 0:
                    # 检查前缀是否在集合中
                    prefix = f[:i]
                    if prefix in folder_set:
                        is_subfolder = True
                        break
            
            if not is_subfolder:
                result.append(f)
        
        return result
```

### 方法三：字典树（Trie）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_folder = False

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        """
        使用字典树存储文件夹结构
        """
        root = TrieNode()
        
        # 构建字典树
        for f in folder:
            parts = f.split('/')[1:]  # 跳过第一个空字符串
            node = root
            
            for part in parts:
                if part not in node.children:
                    node.children[part] = TrieNode()
                node = node.children[part]
            
            node.is_folder = True
        
        # 遍历字典树，收集非子文件夹
        result = []
        
        def dfs(node: TrieNode, path: str):
            """深度优先搜索"""
            if node.is_folder:
                result.append(path)
                return  # 找到文件夹，不再向下搜索
            
            for name, child in node.children.items():
                dfs(child, path + '/' + name)
        
        dfs(root, '')
        
        return result
```

### 方法四：优化的排序方法

```python
from typing import List

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        """
        排序后使用更简洁的逻辑
        """
        folder.sort()
        result = [folder[0]]
        
        for i in range(1, len(folder)):
            # 获取上一个添加的文件夹
            last = result[-1]
            
            # 检查当前文件夹是否是上一个的子文件夹
            # 必须是 last + '/' 开头，而不仅仅是 last 开头
            # 例如 "/a/b" 不是 "/a/bc" 的前缀
            if not folder[i].startswith(last + '/'):
                result.append(folder[i])
        
        return result
```

## 复杂度分析

**方法一（推荐）：**
- 时间复杂度：O(n log n + L)，其中 n 是文件夹数量，L 是所有路径的总长度
  - 排序：O(n log n)
  - 遍历和前缀检查：O(L)
- 空间复杂度：O(log n)，排序的栈空间

**方法二：**
- 时间复杂度：O(n × m^2)，其中 m 是平均路径长度
- 空间复杂度：O(n)

**方法三：**
- 时间复杂度：O(L)，其中 L 是所有路径的总长度
- 空间复杂度：O(L)

## 关键点总结

1. 排序是关键：字典序排序保证父文件夹在子文件夹前面
2. 判断子文件夹：必须是 `parent + '/'` 的前缀，而不仅仅是 `parent`
3. 优化：排序后只需要和上一个添加的文件夹比较
4. 边界情况：注意 "/a" 和 "/ab" 的区别
5. 字符串的 startswith 方法非常高效

## 易错点

1. 忘记在父文件夹后面加 '/'，导致误判
   - 错误：`"/a/b".startswith("/a")`  → True（但 /ab 不是 /a 的子文件夹）
   - 正确：`"/a/b".startswith("/a/")`  → True
2. 排序前后的逻辑混乱
3. 字典树实现时忘记在找到文件夹后停止搜索
4. split('/') 后忘记跳过第一个空字符串
5. 没有考虑路径相同的情况（题目保证唯一）
