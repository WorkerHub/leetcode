## 题目描述

给你一棵有 `n` 个节点的树（根节点为 0），每个节点有一个小写字母 `s[i]`。

对每个节点 `i`，将以 `i` 为根的子树做 DFS（先访问编号小的子节点），将访问顺序记录的字符串记为 `dfs_str[i]`。

对于每个节点 `i`（`0 <= i < n`），判断 `dfs_str[i]` 是否是回文串。返回长度为 `n` 的布尔数组 `answer`，`answer[i]` 表示 `dfs_str[i]` 是否为回文串。

**提示：**
- `2 <= n <= 10^5`

## 解题思路

**字符串哈希（Rabin-Karp）：**

1. 先用 DFS（欧拉序）给每个节点的子树分配 DFS 入时间戳 `in[i]` 和出时间戳 `out[i]`。子树对应的 DFS 字符串就是 `s[in[i]:out[i]+1]`。

2. 对构造的 DFS 字符串，用多项式哈希同时计算正向哈希和反向哈希，快速判断 `s[in[i]:out[i]+1]` 是否为回文。

**具体步骤：**
1. DFS 记录欧拉序（每个节点在 DFS 中的进入和离开时间）。
2. 构造 `dfs_order` 字符串（按 DFS 顺序排列的字符）。
3. 预处理正向和反向多项式哈希。
4. 对每个节点，O(1) 比较 `[in[i], out[i]]` 区间的正反哈希。

## Python 代码实现

### 方法一：字符串哈希（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findAnswer(self, parent: List[int], s: str) -> List[bool]:
        n = len(s)
        
        # 构建树
        children = defaultdict(list)
        for i in range(1, n):
            children[parent[i]].append(i)
        # 子节点按编号排序
        for i in range(n):
            children[i].sort()
        
        # DFS 构建欧拉序
        order = []
        in_time = [0] * n
        out_time = [0] * n
        timer = [0]
        
        def dfs(node):
            in_time[node] = timer[0]
            order.append(s[node])
            timer[0] += 1
            for child in children[node]:
                dfs(child)
            out_time[node] = timer[0] - 1
        
        import sys
        sys.setrecursionlimit(200000)
        dfs(0)
        
        dfs_str = ''.join(order)
        m = len(dfs_str)  # = n
        
        # 多项式哈希：双哈希防碰撞
        MOD1, BASE1 = 10**9 + 7, 131
        MOD2, BASE2 = 10**9 + 9, 137
        
        # 正向哈希
        h1 = [0] * (m + 1)
        h2 = [0] * (m + 1)
        pw1 = [1] * (m + 1)
        pw2 = [1] * (m + 1)
        
        for i in range(m):
            h1[i+1] = (h1[i] * BASE1 + ord(dfs_str[i])) % MOD1
            h2[i+1] = (h2[i] * BASE2 + ord(dfs_str[i])) % MOD2
            pw1[i+1] = pw1[i] * BASE1 % MOD1
            pw2[i+1] = pw2[i] * BASE2 % MOD2
        
        # 反向哈希
        rev_str = dfs_str[::-1]
        rh1 = [0] * (m + 1)
        rh2 = [0] * (m + 1)
        for i in range(m):
            rh1[i+1] = (rh1[i] * BASE1 + ord(rev_str[i])) % MOD1
            rh2[i+1] = (rh2[i] * BASE2 + ord(rev_str[i])) % MOD2
        
        def get_hash(h, pw, l, r):
            """获取 [l, r] 的哈希值（0 索引）"""
            return (h[r+1] - h[l] * pw[r-l+1]) % (MOD1 if h is h1 else MOD2)
        
        def is_palindrome(l, r):
            # 正向 [l, r]
            fwd1 = (h1[r+1] - h1[l] * pw1[r-l+1]) % MOD1
            fwd2 = (h2[r+1] - h2[l] * pw2[r-l+1]) % MOD2
            # 反向对应：rev_str 中 [m-1-r, m-1-l]
            rl, rr = m - 1 - r, m - 1 - l
            bwd1 = (rh1[rr+1] - rh1[rl] * pw1[rr-rl+1]) % MOD1
            bwd2 = (rh2[rr+1] - rh2[rl] * pw2[rr-rl+1]) % MOD2
            return fwd1 == bwd1 and fwd2 == bwd2
        
        return [is_palindrome(in_time[i], out_time[i]) for i in range(n)]
```

## 复杂度分析

- 时间复杂度：O(n)，DFS + 哈希预处理 + n 次 O(1) 查询
- 空间复杂度：O(n)

## 关键点总结

1. DFS 欧拉序：每个节点 `i` 的子树对应 DFS 序的连续区间 `[in[i], out[i]]`。
2. 字符串哈希支持 O(1) 区间哈希查询，用于判断回文。
3. 双哈希（两组不同的模数和基数）降低碰撞概率。

## 易错点

1. 子节点需要按编号升序排序（题目要求先访问编号小的子节点）。
2. 反向哈希的区间转换：`[l, r]` 在反转字符串中对应 `[m-1-r, m-1-l]`。
3. 取模运算中可能出现负数，需要 `% MOD`（Python 中 `%` 自动为正）。
