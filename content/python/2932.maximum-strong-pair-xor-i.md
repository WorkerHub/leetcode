## 题目描述

给你一个整数数组 `nums`，选取两个下标 `i` 和 `j`（不要求 i != j）组成 **强对**，满足 `|nums[i] - nums[j]| <= min(nums[i], nums[j])`。

返回所有强对中 `nums[i] XOR nums[j]` 的最大值。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：7
解释：强对 (2,5)：|2-5|=3，min(2,5)=2，3>2 不满足？
实际：(3,5)：|3-5|=2，min(3,5)=3，2<=3 满足，3 XOR 5=6
(1,2)：|1-2|=1，min=1，满足，XOR=3
找最大：枚举
```

**示例 2：**
```
输入：nums = [10,100]
输出：0
解释：只有 (10,10) 和 (100,100) 满足强对条件（单个元素与自己），XOR=0
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 100`

## 解题思路

数据范围小，直接暴力枚举所有对 (i, j)，检查强对条件，维护最大 XOR 值。

条件 `|x - y| <= min(x, y)` 等价于：不失一般性设 x <= y，则 y - x <= x，即 y <= 2x，即 x >= y/2。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        ans = 0
        n = len(nums)
        for i in range(n):
            for j in range(n):
                x, y = nums[i], nums[j]
                if abs(x - y) <= min(x, y):
                    ans = max(ans, x ^ y)
        return ans
```

### 方法二：排序后检查（优化枚举）

```python
from typing import List

class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        nums.sort()
        ans = 0
        n = len(nums)
        for i in range(n):
            for j in range(i, n):
                x, y = nums[i], nums[j]
                # x <= y，条件变为 y - x <= x，即 y <= 2x
                if y <= 2 * x:
                    ans = max(ans, x ^ y)
                else:
                    break  # y 只会更大
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有对
- 空间复杂度：O(1)

## 关键点总结

1. 强对条件：`|x-y| <= min(x,y)` 等价于 `max(x,y) <= 2 * min(x,y)`
2. 排序后可以提前终止内层循环（y 超过 2x 后更大的 y 也不满足）
3. 允许 i == j（与自身配对，XOR 为 0）

## 易错点

1. 允许 i == j，即可以用同一个元素
2. 答案可能为 0（如 nums 全相同时）
