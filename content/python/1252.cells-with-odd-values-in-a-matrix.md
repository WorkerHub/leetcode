## 题目描述

给你一个 m x n 的矩阵，最开始的时候，每个单元格中的值都是 0。

另有一个二维索引数组 indices，indices[i] = [ri, ci] 指向矩阵中的某个位置，其中 ri 和 ci 分别表示指定的行和列（从 0 开始编号）。

对 indices[i] 所指向的每个位置，应同时执行下述增量操作：

1. ri 行上的所有单元格，加 1 。
2. ci 列上的所有单元格，加 1 。

给你 m、n 和 indices 。请你在执行完所有 indices 指定的增量操作后，返回矩阵中奇数值单元格的数目。

示例 1：

```
输入：m = 2, n = 3, indices = [[0,1],[1,1]]
输出：6
解释：最开始的矩阵是 [[0,0,0],[0,0,0]]。
第一次增量操作后得到 [[1,2,1],[0,1,0]]。
最后的矩阵是 [[1,3,1],[1,3,1]]，里面有 6 个奇数。
```

示例 2：

```
输入：m = 2, n = 2, indices = [[1,1],[0,0]]
输出：0
解释：最后的矩阵是 [[2,2],[2,2]]，里面没有奇数。
```

提示：

- 1 <= m, n <= 50
- 1 <= indices.length <= 100
- 0 <= ri < m
- 0 <= ci < n

## 解题思路

这道题有多种解法，从直接模拟到数学优化。

### 思路1：直接模拟

直接创建一个 m x n 的矩阵，按照 indices 中的指令逐一操作，最后统计奇数。

### 思路2：只记录增量次数（推荐）

观察发现，我们不需要真正创建矩阵，只需要：
1. 记录每一行被增加的次数 row_count
2. 记录每一列被增加的次数 col_count
3. 对于位置 (i, j)，它的值 = row_count[i] + col_count[j]
4. 统计有多少位置的值是奇数

### 思路3：数学优化

一个位置 (i, j) 的值是奇数，当且仅当 row_count[i] + col_count[j] 是奇数。
这发生在：
- row_count[i] 是奇数，col_count[j] 是偶数
- row_count[i] 是偶数，col_count[j] 是奇数

所以奇数单元格数 = 奇数行数 * 偶数列数 + 偶数行数 * 奇数列数

## Python 代码实现

### 方法一：只记录增量次数（推荐）

```python
from typing import List

class Solution:
    def oddCells(self, m: int, n: int, indices: List[List[int]]) -> int:
        # 记录每行和每列的增量次数
        row_count = [0] * m
        col_count = [0] * n
        
        # 统计每行每列被操作的次数
        for r, c in indices:
            row_count[r] += 1
            col_count[c] += 1
        
        # 统计奇数单元格数量
        count = 0
        for i in range(m):
            for j in range(n):
                # 位置 (i,j) 的值 = row_count[i] + col_count[j]
                if (row_count[i] + col_count[j]) % 2 == 1:
                    count += 1
        
        return count
```

### 方法二：数学优化

```python
from typing import List

class Solution:
    def oddCells(self, m: int, n: int, indices: List[List[int]]) -> int:
        # 记录每行和每列的增量次数
        row_count = [0] * m
        col_count = [0] * n
        
        # 统计每行每列被操作的次数
        for r, c in indices:
            row_count[r] += 1
            col_count[c] += 1
        
        # 统计奇数行和奇数列的数量
        odd_rows = sum(count % 2 for count in row_count)
        odd_cols = sum(count % 2 for count in col_count)
        
        # 奇数单元格 = 奇数行 * 偶数列 + 偶数行 * 奇数列
        return odd_rows * (n - odd_cols) + (m - odd_rows) * odd_cols
```

### 方法三：直接模拟（便于理解）

```python
from typing import List

class Solution:
    def oddCells(self, m: int, n: int, indices: List[List[int]]) -> int:
        # 创建 m x n 的矩阵
        matrix = [[0] * n for _ in range(m)]
        
        # 执行所有操作
        for r, c in indices:
            # 增加第 r 行的所有元素
            for j in range(n):
                matrix[r][j] += 1
            # 增加第 c 列的所有元素
            for i in range(m):
                matrix[i][c] += 1
        
        # 统计奇数
        count = 0
        for i in range(m):
            for j in range(n):
                if matrix[i][j] % 2 == 1:
                    count += 1
        
        return count
```

## 复杂度分析

### 方法一：只记录增量次数
- 时间复杂度：O(len(indices) + m * n)，遍历 indices 和遍历所有单元格
- 空间复杂度：O(m + n)，存储行列的增量次数

### 方法二：数学优化
- 时间复杂度：O(len(indices) + m + n)，最优解
- 空间复杂度：O(m + n)

### 方法三：直接模拟
- 时间复杂度：O(len(indices) * (m + n) + m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 不需要真正创建矩阵，只需记录每行每列的增量
2. 位置 (i,j) 的值 = 该行的增量 + 该列的增量
3. 数学优化：利用奇偶性规律减少计算
4. 奇数 + 奇数 = 偶数，奇数 + 偶数 = 奇数，偶数 + 偶数 = 偶数

## 易错点

1. 忘记同一位置可能被多次操作
2. 直接模拟时重复增加了同一位置的值
3. 没有利用空间优化，创建了不必要的矩阵
4. 数学优化时计算公式错误
