## 题目描述

给你一个长度为 `n` 的整数数组，其子数组的**交替子数组和**定义为从下标 `i` 开始，对每个元素按正负交替加减的结果：
`nums[i] - nums[i+1] + nums[i+2] - ...`

返回所有非空子数组中**交替子数组和的最大值**。

**示例 1：**
```
输入：nums = [3,-5,1.5,-2.5]
输出：10
解释：子数组 [3,-5] 的交替和为 3-(-5)=8；子数组 [3,-5,1.5] 为 3-(-5)+1.5=9.5；单独 [-5] 为 -5；最大为 10（[3] 或 [3,-5,1.5,-2.5] = 3-(-5)+1.5-(-2.5)=10）
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

**DP 定义：**
- `dp_odd[i]`：以 `nums[i]` 结尾（符号为正，即在子数组中奇数位）的最大交替和
- `dp_even[i]`：以 `nums[i]` 结尾（符号为负，即在子数组中偶数位）的最大交替和

**状态转移：**
- `dp_odd[i] = max(nums[i], dp_even[i-1] + nums[i])`（单独开始或接在负号之后）
- `dp_even[i] = dp_odd[i-1] - nums[i]`（必须接在正号之后）

答案为所有 `dp_odd[i]` 的最大值（子数组以正号开始更有利）。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maximumAlternatingSubarraySum(self, nums: List[int]) -> float:
        n = len(nums)
        # odd：当前元素符号为正时的最大交替和
        # even：当前元素符号为负时的最大交替和
        odd = nums[0]   # 以 nums[0] 为正号开始
        even = -nums[0] # 以 nums[0] 为负号开始
        ans = nums[0]

        for i in range(1, n):
            # 新的 odd：单独 nums[i]，或接在 even 之后
            new_odd = max(nums[i], even + nums[i])
            # 新的 even：必须接在 odd 之后
            new_even = odd - nums[i]

            ans = max(ans, new_odd)
            odd = new_odd
            even = new_even

        return ans
```

### 方法二：空间优化 DP

```python
from typing import List

class Solution:
    def maximumAlternatingSubarraySum(self, nums: List[int]) -> float:
        # dp[0]: 最后一个元素符号为+的最大交替和
        # dp[1]: 最后一个元素符号为-的最大交替和（用于扩展）
        dp = [nums[0], float('-inf')]
        ans = nums[0]

        for i in range(1, len(nums)):
            new_dp = [
                max(nums[i], dp[1] + nums[i]),  # 正号：新开始或接负号
                dp[0] - nums[i]                  # 负号：接正号
            ]
            ans = max(ans, new_dp[0])
            dp = new_dp

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 子数组的交替和总是从正号开始（第一个元素加，第二个减，...）
2. DP 跟踪两种状态：最后一个元素为正号和为负号的最大交替和
3. 答案是所有以正号结尾状态的最大值

## 易错点

- `even` 的初始值设为 `-inf` 或 `-nums[0]`（取决于定义）
- 注意 `dp[1]` 可能在初始时为 `-inf`，`dp[1] + nums[i]` 时不影响 max 的正确性
