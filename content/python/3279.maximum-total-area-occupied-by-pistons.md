## 题目描述

给你一些活塞（pistons），每个活塞有高度 `heights[i]` 和移动方向 `directions[i]`（'U' 上移或 'D' 下移）。每秒每个活塞移动 1 个单位，碰到边界（0 或 maxVal）时反弹。

返回所有活塞高度之和在**任意时刻**的**最大值**。

**提示：**
- `1 <= n <= 10^5`
- `0 <= heights[i] <= maxVal <= 10^6`

## 解题思路

关键观察：所有活塞的位置之和关于时间是一个周期为 `2 * maxVal` 的函数，每一秒的变化量取决于各活塞的方向。

每秒活塞总高度的变化量 = 上移活塞数量 - 下移活塞数量（在未碰到边界时）。

但活塞碰到边界时方向会反转，使得计算复杂。

模拟关键事件：找出所有活塞方向改变的时刻（碰到 0 或 maxVal），用有序集合维护各时刻的变化量，然后遍历找最大值。

## Python 代码实现

### 方法一：差分 + 模拟关键事件（推荐）

```python
from typing import List
from sortedcontainers import SortedDict

class Solution:
    def maximumTotalAreaOccupied(self, heights: List[int], directions: List[str], maxVal: int) -> int:
        n = len(heights)
        
        # 每秒总高度变化量的差分
        # 当活塞在时刻 t 碰到边界时，它的贡献从 +1 变为 -1 或反之
        
        # 差分字典：delta[t] = 在时刻 t 的变化量改变量
        # 初始 change = sum(1 if d=='U' else -1 for d in directions)
        
        from collections import defaultdict
        diff = defaultdict(int)
        
        init_change = 0
        for h, d in zip(heights, directions):
            if d == 'U':
                init_change += 1
                # 碰到 maxVal 的时刻：maxVal - h
                t = maxVal - h
                diff[t] -= 2  # 从 +1 变为 -1
                # 碰到 0 的时刻：maxVal - h + maxVal = 2*maxVal - h
                diff[2 * maxVal - h] += 2
            else:
                init_change -= 1
                # 碰到 0 的时刻：h
                t = h
                diff[t] += 2  # 从 -1 变为 +1
                # 碰到 maxVal 的时刻：h + maxVal
                diff[h + maxVal] -= 2
        
        # 所有事件在 [0, 2*maxVal-1] 内循环
        # 从 t=0 开始，计算每秒总高度
        init_sum = sum(heights)
        
        cur_sum = init_sum
        cur_change = init_change
        max_sum = cur_sum
        
        # 事件排序
        events = sorted(diff.keys())
        prev_t = 0
        
        for t in events:
            # [prev_t, t) 这段时间内 change 不变
            # 不需要逐秒计算，可以找最大值
            if cur_change > 0:
                max_sum = max(max_sum, cur_sum + cur_change * (t - prev_t - 1))
            elif cur_change == 0:
                max_sum = max(max_sum, cur_sum)
            # cur_change < 0 时最大值在最左边（prev_t 时刻）
            max_sum = max(max_sum, cur_sum)
            
            cur_sum += cur_change * (t - prev_t)
            cur_change += diff[t]
            prev_t = t
        
        max_sum = max(max_sum, cur_sum)
        
        return max_sum
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序事件
- 空间复杂度：O(n)

## 关键点总结

1. 活塞位置之和的变化率只在碰到边界时改变
2. 差分记录变化率改变的时刻，跳过无事件的时间段
3. 在每段等速变化期间，找出最大值（起点或终点）

## 易错点

1. 每个活塞的反弹时刻要正确计算
2. 周期为 2*maxVal，事件在一个周期内
