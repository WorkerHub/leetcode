## 题目描述

给你链表的头节点 `head` 和一个整数 `k`。

交换链表正数第 `k` 个节点和倒数第 `k` 个节点的**值**后，返回链表的头节点（链表从 1 开始索引）。

**示例 1：**
```
输入：head = [1,2,3,4,5], k = 2
输出：[1,4,3,2,5]
```

**提示：**
- 链表中节点的数目是 `n`
- `1 <= k <= n <= 10^5`
- `0 <= Node.val <= 100`

## 解题思路

用双指针找到正数第 `k` 个和倒数第 `k` 个节点：
1. 先找到正数第 `k` 个节点
2. 用快慢指针找倒数第 `k` 个：快指针继续到末尾，慢指针同步前进
3. 交换两个节点的值

## 代码实现

### 方法一：双指针一次遍历（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def swapNodes(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # 找正数第 k 个节点
        fast = head
        for _ in range(k - 1):
            fast = fast.next
        
        # first 指向正数第 k 个节点
        first = fast
        
        # slow 和 fast 同步前进，当 fast 到达末尾时，slow 指向倒数第 k 个
        slow = head
        while fast.next:
            fast = fast.next
            slow = slow.next
        
        # second 指向倒数第 k 个节点
        second = slow
        
        # 交换两节点的值
        first.val, second.val = second.val, first.val
        
        return head
```

### 方法二：先计算长度再定位

```python
from typing import Optional

class Solution:
    def swapNodes(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # 先统计链表长度
        n = 0
        node = head
        while node:
            n += 1
            node = node.next
        
        # 找正数第 k 个（下标 k-1）和倒数第 k 个（下标 n-k）
        idx_first = k - 1
        idx_second = n - k
        
        node = head
        first = second = None
        for i in range(n):
            if i == idx_first:
                first = node
            if i == idx_second:
                second = node
            node = node.next
        
        # 交换值
        first.val, second.val = second.val, first.val
        
        return head
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历链表
- **空间复杂度**：O(1)

## 关键点总结

1. 只交换值，不需要修改链表结构
2. 双指针找倒数第 k 个节点：快指针先走 k 步，然后快慢同步前进

## 易错点

- 交换的是**值**，不是节点指针
- 正数第 k 和倒数第 k 可能是同一节点（k 使链表长度的一半取整），此时交换无影响
