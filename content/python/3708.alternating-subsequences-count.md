## 题目描述

给定一个只包含字母 `'a'` 和 `'b'` 的字符串 `s`，统计其中**交替子序列**的数量（子序列中相邻字符不相同）。返回结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：s = "aab"
输出：6
解释：所有交替子序列：
     "a"（下标 0）, "a"（下标 1）, "b"（下标 2）,
     "ab"（下标 0,2）, "ab"（下标 1,2）, "aab"不是交替的。
     共 5 个，但单字符子序列也算。
```

**示例 2：**
```
输入：s = "abab"
输出：14
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由 `'a'` 和 `'b'` 组成

## 解题思路

动态规划。

设 `dp_a` 为以 `'a'` 结尾的交替子序列数量，`dp_b` 为以 `'b'` 结尾的交替子序列数量。

遍历字符串：
- 若 `s[i] == 'a'`：可以将当前 `'a'` 接在所有以 `'b'` 结尾的子序列后面，形成新的以 `'a'` 结尾的子序列；同时 `'a'` 本身也是长度为 1 的子序列。
  - `dp_a = dp_b + 1`（不累加，而是替换，因为所有以 `'a'` 结尾的旧子序列可以被新子序列覆盖）
  
  实际上应该累加：`dp_a = dp_a + dp_b + 1`

- 若 `s[i] == 'b'`：`dp_b = dp_b + dp_a + 1`

答案为 `(dp_a + dp_b) % MOD`。

但需要注意：对于连续相同字符，不能重复计算。更精确的做法是：
- 遇到 `'a'`：新增的以 `'a'` 结尾的子序列 = `dp_b + 1`（把这个新 `'a'` 接在所有以 `'b'` 结尾的后面，加上自身）
- `dp_a += dp_b + 1`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def countAlternatingSubsequences(self, s: str) -> int:
        MOD = 10**9 + 7
        # dp_a: 以 'a' 结尾的交替子序列数量
        # dp_b: 以 'b' 结尾的交替子序列数量
        dp_a, dp_b = 0, 0

        for c in s:
            if c == 'a':
                # 当前 'a' 可以接在所有以 'b' 结尾的子序列后，也可以单独成一个
                dp_a = (dp_a + dp_b + 1) % MOD
            else:
                # 当前 'b' 可以接在所有以 'a' 结尾的子序列后，也可以单独成一个
                dp_b = (dp_b + dp_a + 1) % MOD

        return (dp_a + dp_b) % MOD
```

### 方法二：分组统计（利用连续相同字符的特性）

```python
from itertools import groupby

class Solution:
    def countAlternatingSubsequences(self, s: str) -> int:
        MOD = 10**9 + 7
        # 将连续相同字符分组，每组大小为 cnt
        # 对于交替子序列，每组选 1 个字符，组合数为各组大小之积
        groups = [(key, sum(1 for _ in grp)) for key, grp in groupby(s)]

        # dp[i] = 从前 i 组中选出的交替子序列数（每组选 1 个）
        # dp[0] = groups[0][1]（第一组选一个字符的方案数）
        if not groups:
            return 0

        dp = [0] * len(groups)
        dp[0] = groups[0][1]  # 第一组可选 cnt0 个字符
        for i in range(1, len(groups)):
            # 当前组大小为 groups[i][1]，可以接在前 i-1 组的所有子序列后
            # 也可以单独成子序列（长度 1）
            dp[i] = (dp[i-1] * groups[i][1] + groups[i][1]) % MOD

        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n)，一次线性遍历
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 交替子序列的 DP 核心：以某字符结尾的子序列数 = 以另一字符结尾的子序列数 + 1
2. 不用记录完整 DP 数组，只需维护两个变量
3. 取模操作在每步更新后立即执行，防止溢出

## 易错点

1. 注意是子序列（不要求连续），而不是子串
2. 单个字符也算交替子序列
3. 连续相同字符不会互相"交替"，要正确处理
