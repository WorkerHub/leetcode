## 题目描述

给定一个整数数组 `nums`（元素均为正整数），判断是否可以将数组分成两个非空子集，使得两个子集的元素乘积相等。

**示例 1：**

```
输入：nums = [2, 3, 6]
输出：true
解释：{2,3} 乘积=6，{6} 乘积=6，两者相等。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：false
```

**提示：**
- `2 <= nums.length <= 30`
- `1 <= nums[i] <= 100`

## 解题思路

两个子集乘积相等，且并集为整个数组。设总乘积为 P = product(nums)，每个子集的乘积为 sqrt(P)（即 P 需为完全平方数）。

但子集的乘积必须是整数，所以需要 P 为完全平方数，且 sqrt(P) 可以由某些元素的乘积达到。

方法：
1. 计算总乘积 P，若 sqrt(P) 不是整数，返回 false
2. 枚举所有子集，检查是否存在乘积等于 sqrt(P) 的非空真子集

## Python 代码实现

### 方法一：枚举子集（推荐）

```python
from typing import List
from math import isqrt

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        total_prod = 1
        for x in nums:
            total_prod *= x

        # 总乘积必须是完全平方数
        sqrt_p = isqrt(total_prod)
        if sqrt_p * sqrt_p != total_prod:
            return False

        # 枚举所有非空真子集，检查乘积是否等于 sqrt_p
        target = sqrt_p
        for mask in range(1, (1 << n) - 1):
            prod = 1
            for i in range(n):
                if mask & (1 << i):
                    prod *= nums[i]
                    if prod > target:
                        break
            if prod == target:
                return True

        return False
```

### 方法二：动态规划

```python
from typing import List
from math import isqrt

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total_prod = 1
        for x in nums:
            total_prod *= x

        sqrt_p = isqrt(total_prod)
        if sqrt_p * sqrt_p != total_prod:
            return False

        target = sqrt_p
        # 类似子集和问题，但是乘积
        # 使用集合存储可达的乘积值
        reachable = {1}  # 空集乘积为 1

        for x in nums:
            new_reachable = set(reachable)
            for prod in reachable:
                new_prod = prod * x
                if new_prod <= target:
                    new_reachable.add(new_prod)
            reachable = new_reachable

        # 需要找到非空真子集（不能取全部元素）
        # target 需要在 reachable 中，且不能由全部元素组成
        all_prod = 1
        for x in nums:
            all_prod *= x

        return target in reachable and target != all_prod
```

## 复杂度分析

- 时间复杂度：O(2^n)（方法一），O(n * target)（方法二 DP）
- 空间复杂度：O(2^n)（方法一），O(target)（方法二）

## 关键点总结

1. 两个子集乘积相等等价于总乘积是完全平方数
2. 每个子集乘积 = sqrt(总乘积)
3. 枚举非空真子集检查乘积

## 易错点

1. 两个子集必须非空（不能一个为空集，一个为整个数组）
2. 总乘积可能非常大，Python 的大整数支持处理
3. 完全平方数检验：`isqrt(n)^2 == n`
