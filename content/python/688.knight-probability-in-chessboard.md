## 题目描述

在一个 n x n 的国际象棋棋盘上，一个骑士从单元格 (row, column) 开始，并尝试进行 k 次移动。

骑士有 8 种可能的走法，每次移动在基本方向上都是两个单元格，然后在正交方向上是一个单元格。

每次移动，骑士随机选择 8 个方向之一移动。即使移动会离开棋盘，骑士仍然会移动。

返回骑士在棋盘上停留的概率。

**示例：**
```
输入：n = 3, k = 2, row = 0, column = 0
输出：0.06250
```

## Python 代码实现

### 方法一：动态规划

```python
class Solution:
    def knightProbability(self, n: int, k: int, row: int, column: int) -> float:
        # 8个方向
        directions = [(-2,-1),(-2,1),(-1,-2),(-1,2),(1,-2),(1,2),(2,-1),(2,1)]
        
        # dp[step][i][j] 表示走 step 步后在 (i,j) 的概率
        dp = [[0] * n for _ in range(n)]
        dp[row][column] = 1
        
        for _ in range(k):
            new_dp = [[0] * n for _ in range(n)]
            for i in range(n):
                for j in range(n):
                    for dx, dy in directions:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < n and 0 <= nj < n:
                            new_dp[ni][nj] += dp[i][j] / 8
            dp = new_dp
        
        return sum(sum(row) for row in dp)
```

## 复杂度分析

- 时间复杂度：O(k * n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 使用动态规划计算概率
2. 每步移动概率均等
3. 累加所有位置的概率
