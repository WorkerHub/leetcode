## 题目描述

三枚石子放置在数轴上，位置分别为 `a`、`b`、`c`。

每一回合，你可以从两端之一拿起一枚石子（位置最小或最大），并将其放入两端之间的任一空闲位置。

形式上，假设这三枚石子当前分别位于位置 `x`、`y`、`z` 且 `x < y < z`。那么就可以从位置 `x` 或者 `z` 拿起一枚石子，并将该石子移动到某一整数位置 `k` 处，其中 `x < k < z` 且 `k != y`。

当你无法进行任何移动时，即这些石子的位置连续时，游戏结束。

要使游戏结束，你可以执行的最小和最大移动次数分别是多少？以数组形式返回答案：`[minimum_moves, maximum_moves]`。

**示例 1：**

```
输入: a = 1, b = 2, c = 5
输出: [1, 2]
解释: 
- 最小移动 1 次：将石子 c 从 5 移动到 3，得到 [1, 2, 3]
- 最大移动 2 次：
  第一次：将石子 c 从 5 移动到 4，得到 [1, 2, 4]
  第二次：将石子 c 从 4 移动到 3，得到 [1, 2, 3]
```

**示例 2：**

```
输入: a = 4, b = 3, c = 2
输出: [0, 0]
解释: 石子已经连续，无需移动
```

**示例 3：**

```
输入: a = 3, b = 5, c = 1
输出: [1, 2]
解释:
- 最小移动 1 次：将石子 a 从 3 移动到 4，得到 [1, 4, 5] 或者 [2, 4, 5]
- 最大移动 2 次
```

**提示：**

- `1 <= a, b, c <= 100`
- `a`、`b`、`c` 的值互不相同

## 解题思路

这是一道数学脑筋急转弯题目，关键是分析最小移动次数和最大移动次数的规律。

首先，将三个位置排序为 `x < y < z`。

### 最小移动次数分析

1. **已经连续**（`z - x == 2`）：不需要移动，返回 0
2. **相邻或间隔为 1**：
   - 如果 `y - x <= 2` 或 `z - y <= 2`，只需要移动 1 次
   - 例如 `[1, 2, 5]`：将 5 移动到 3
3. **其他情况**：需要移动 2 次

### 最大移动次数分析

最大移动次数是贪心策略：每次只移动一格，尽可能多地移动。

计算公式：`(z - x - 2)`，即总共的空位数量。

- 例如 `[1, 2, 5]`：空位有 3 和 4，共 2 个空位，最大移动 2 次
- 每次移动一格：`[1, 2, 5]` → `[1, 2, 4]` → `[1, 2, 3]`

## Python 代码实现

### 方法一：数学分析（推荐）

```python
from typing import List

class Solution:
    def numMovesStones(self, a: int, b: int, c: int) -> List[int]:
        """
        通过数学分析计算最小和最大移动次数
        
        时间复杂度: O(1)
        空间复杂度: O(1)
        """
        # 排序三个位置
        x, y, z = sorted([a, b, c])
        
        # 计算最大移动次数：总空位数
        max_moves = z - x - 2
        
        # 计算最小移动次数
        if z - x == 2:
            # 已经连续
            min_moves = 0
        elif y - x <= 2 or z - y <= 2:
            # 有相邻或间隔为 1 的情况
            min_moves = 1
        else:
            # 都不相邻，需要移动两次
            min_moves = 2
        
        return [min_moves, max_moves]
```

### 方法二：更直观的条件判断

```python
from typing import List

class Solution:
    def numMovesStones(self, a: int, b: int, c: int) -> List[int]:
        """
        使用更详细的条件判断，便于理解
        
        时间复杂度: O(1)
        空间复杂度: O(1)
        """
        # 排序
        stones = sorted([a, b, c])
        x, y, z = stones[0], stones[1], stones[2]
        
        # 计算间隔
        gap1 = y - x - 1  # 左侧间隔的空位数
        gap2 = z - y - 1  # 右侧间隔的空位数
        
        # 最大移动次数 = 所有空位
        max_moves = gap1 + gap2
        
        # 最小移动次数
        if gap1 == 0 and gap2 == 0:
            # 已经连续
            min_moves = 0
        elif gap1 <= 1 or gap2 <= 1:
            # 至少有一侧相邻或只有一个空位，只需移动一次
            min_moves = 1
        else:
            # 两侧都有间隔，需要移动两次
            min_moves = 2
        
        return [min_moves, max_moves]
```

### 方法三：使用 min 函数简化

```python
from typing import List

class Solution:
    def numMovesStones(self, a: int, b: int, c: int) -> List[int]:
        """
        使用 min 函数简化最小移动次数的计算
        
        时间复杂度: O(1)
        空间复杂度: O(1)
        """
        x, y, z = sorted([a, b, c])
        
        # 最大移动次数
        max_moves = z - x - 2
        
        # 最小移动次数
        if z - x == 2:
            min_moves = 0
        else:
            # 取两个间隔的最小值，如果最小间隔 <= 2，则只需 1 次
            # 否则需要 2 次
            min_gap = min(y - x, z - y)
            min_moves = 1 if min_gap <= 2 else 2
        
        return [min_moves, max_moves]
```

### 方法四：详细注释版（新手推荐）

```python
from typing import List

class Solution:
    def numMovesStones(self, a: int, b: int, c: int) -> List[int]:
        """
        详细版本，每一步都有清晰的注释
        
        时间复杂度: O(1)
        空间复杂度: O(1)
        """
        # 第一步：排序三个石子的位置
        positions = sorted([a, b, c])
        left, middle, right = positions
        
        # 第二步：计算两个间隔的距离
        left_gap = middle - left   # 左边两个石子的距离
        right_gap = right - middle  # 右边两个石子的距离
        
        # 第三步：计算最大移动次数
        # 最大移动 = 总距离 - 3（三个石子占据的位置）+ 1
        # 简化为：right - left - 2
        max_moves = right - left - 2
        
        # 第四步：计算最小移动次数
        # 情况 1：已经连续（例如 [1, 2, 3]）
        if left_gap == 1 and right_gap == 1:
            min_moves = 0
        # 情况 2：有一个间隔是 1 或 2（例如 [1, 2, 5] 或 [1, 3, 5]）
        elif left_gap <= 2 or right_gap <= 2:
            min_moves = 1
        # 情况 3：两个间隔都大于 2（例如 [1, 5, 10]）
        else:
            min_moves = 2
        
        return [min_moves, max_moves]
```

## 复杂度分析

所有方法的复杂度都相同：

- **时间复杂度**：O(1)，只需要排序 3 个元素和简单计算
- **空间复杂度**：O(1)，只使用常数额外空间

## 关键点总结

1. **排序是关键**：先将三个位置排序，便于分析
2. **最大移动次数**：等于总空位数 `z - x - 2`
3. **最小移动次数分三种情况**：
   - 已连续：0 次
   - 至少有一侧间隔 ≤ 2：1 次
   - 两侧间隔都 > 2：2 次
4. **脑筋急转弯**：这是一道数学题，需要找规律而不是暴力搜索
5. **间隔计算**：`y - x` 和 `z - y` 是关键的两个间隔

## 易错点

1. **忘记排序**：必须先将三个位置排序
2. **间隔计算错误**：间隔应该是位置差减去石子本身占据的位置
3. **边界条件**：注意 `z - x == 2` 的情况（已经连续）
4. **最小移动的判断**：要区分间隔为 1 和间隔为 2 的情况
5. **理解题意**：只能移动两端的石子，不能移动中间的石子

## 图解示例

以 `a = 1, b = 2, c = 5` 为例：

```
初始状态: [1, 2, _, _, 5]
          x  y        z

间隔: 
- 左侧间隔: y - x - 1 = 2 - 1 - 1 = 0
- 右侧间隔: z - y - 1 = 5 - 2 - 1 = 2

最大移动 (贪心，每次移动一格):
[1, 2, _, _, 5] → [1, 2, _, 4, _] → [1, 2, 3, _, _]
共 2 次

最小移动 (直接到位):
[1, 2, _, _, 5] → [1, 2, 3, _, _]
共 1 次（因为右侧间隔 = 2，可以一次移动到位）
```
