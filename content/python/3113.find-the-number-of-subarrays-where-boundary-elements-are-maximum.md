## 题目描述

给你一个整数数组 `nums`，统计满足如下条件的子数组数量：

子数组的 **第一个** 和 **最后一个** 元素都等于子数组中的 **最大值**。

**示例 1：**
```
输入：nums = [1,4,3,3,2]
输出：6
解释：满足条件的子数组有 [1],[4],[3],[3],[2],[3,3]（下标 2-3）。
```

**示例 2：**
```
输入：nums = [3,3,3]
输出：6
解释：所有子数组：[3],[3],[3],[3,3],[3,3],[3,3,3]，均满足。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对于以下标 `j` 结尾的子数组 `[i..j]`，需要 `nums[i] == nums[j]` 且 `nums[i]` 是子数组最大值。

使用单调栈维护"当前可以作为最大值的候选"。单调栈保持从底到顶单调不增。当处理 `nums[j]` 时：
- 弹出所有比 `nums[j]` 小的元素（它们不能是最大值了）
- 若栈顶等于 `nums[j]`，则以 `nums[j]` 为最大值且边界相等的子数组数量等于栈顶位置处相同值的计数

用栈存储 `(value, count)` 对。

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def numberOfSubarrays(self, nums: List[int]) -> int:
        ans = 0
        # 单调栈：存 (值, 该值在栈中的个数)
        stack = []  # 从底到顶单调不增

        for x in nums:
            # 弹出所有严格小于 x 的元素
            while stack and stack[-1][0] < x:
                stack.pop()

            if stack and stack[-1][0] == x:
                # 栈顶与 x 相同，当前 x 可与栈中所有该值配对
                cnt = stack[-1][1]
                ans += cnt  # cnt 个以不同位置开始、以 x 结尾且最大值为 x 的子数组
                stack[-1] = (x, cnt + 1)
            else:
                # 栈顶严格大于 x 或栈空
                stack.append((x, 1))

            ans += 1  # 长度为 1 的子数组 [x]

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈空间

## 关键点总结

1. 合法子数组要求首尾相等且等于子数组最大值
2. 单调不增栈：栈中元素从底到顶不增，保证栈中每个值都是当前未被更大值"截断"的候选
3. `(值, 计数)` 压缩相同连续值

## 易错点

1. 长度为 1 的子数组始终合法，需要先计数
2. 注意弹出条件是严格小于，等于时更新计数而不弹出
