## 题目描述

给你一个整数数组 `nums`，以及两个整数 `cost1` 和 `cost2`。

两种操作：
- 操作 1：将某个元素加 1，花费 cost1
- 操作 2：将任意两个不同下标的元素同时加 1，花费 cost2

返回使数组所有元素相等所需的 **最少** 花费，对 `10^9 + 7` 取模。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], cost1, cost2 <= 10^6`

## 解题思路

目标值至少为 max(nums)，枚举目标值（从 max(nums) 到 max(nums) + n）。

对于目标值 target，各元素需要增加的量 `diff[i] = target - nums[i]`，总需要加量 = sum(diff)，最大需加量 = max(diff)。

贪心：若 cost2 * 2 <= cost1，应尽量用操作 2。每次操作 2 消耗最大 diff 和其他任意 diff。
- 若 max_diff <= total / 2：所有操作都可以配对，用 total/2 次操作 2，总花费 = ceil(total/2) * cost2（若 total 奇数，额外一次操作 1）
- 若 max_diff > total / 2：最大 diff 必须配对 total - max_diff 次，剩余 max_diff - (total - max_diff) 次单独用操作 1

## Python 代码实现

### 方法一：枚举目标值（推荐）

```python
from typing import List

class Solution:
    def minCostToEqualizeArray(self, nums: List[int], cost1: int, cost2: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        max_val = max(nums)
        min_val = min(nums)

        # 计算目标值为 target 时的最小花费
        def calc(target: int) -> int:
            diffs = [target - x for x in nums]
            total = sum(diffs)
            mx = max(diffs)

            if cost2 * 2 >= cost1 or n == 1:
                # 操作 2 不划算，全用操作 1
                return total * cost1

            # 尽量用操作 2
            if mx <= total - mx:
                # 可以全部配对
                pairs = total // 2
                singles = total % 2
                return (pairs * cost2 + singles * cost1) % MOD
            else:
                # 最大 diff 配对后，剩余单独处理
                pairs = total - mx
                singles = mx - pairs
                return (pairs * cost2 + singles * cost1) % MOD

        # 枚举目标值：max_val 到 max_val + n（超过 n 后增加目标值不划算）
        ans = float('inf')
        for target in range(max_val, max_val + n + 1):
            ans = min(ans, calc(target))

        return ans % MOD
```

### 方法二：数学推导

```python
from typing import List
import math

class Solution:
    def minCostToEqualizeArray(self, nums: List[int], cost1: int, cost2: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        max_val = max(nums)

        if cost2 * 2 >= cost1 or n <= 2:
            total = sum(max_val - x for x in nums)
            return total * cost1 % MOD

        def cost(target: int) -> int:
            diffs = [target - x for x in nums]
            s = sum(diffs)
            mx = max(diffs)
            rest = s - mx
            if mx >= rest:
                return (rest * cost2 + (mx - rest) * cost1) % MOD
            else:
                return (s // 2 * cost2 + (s % 2) * cost1) % MOD

        ans = min(cost(t) for t in range(max_val, max_val + n + 1))
        return ans % MOD
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举 n 个目标值，每次计算 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 若 2*cost2 >= cost1，操作 2 不划算，全用操作 1
2. 否则，贪心配对：最大 diff 优先与其他配对
3. 枚举目标值：max_val 到 max_val + n 即可覆盖最优

## 易错点

1. n == 1 时只能用操作 1
2. 枚举目标值超过 max_val 是因为有时增大目标值反而总花费更少
