## 题目描述

与 3023 相同的流式匹配题，但 `pattern.length` 扩大到 `10^6`，需要更高效实现。

在无限二进制流中找 `pattern` 第一次出现的起始下标。

**提示：**
- `1 <= pattern.length <= 10^6`

## 解题思路

使用 KMP 算法，与 3023 相同思路，但需要注意 Python 中大数组的效率。

可以用**位运算优化**的滑动哈希替代 KMP：用一个整数的位来表示滑动窗口，每次移入一位并比较。

但对于 `pattern.length <= 10^6`，KMP 依然是最优选择。

## Python 代码实现

### 方法一：KMP（推荐）

```python
from typing import List

class InfiniteStream:
    def next(self) -> int:
        pass

class Solution:
    def findPattern(self, stream: 'InfiniteStream', pattern: List[int]) -> int:
        m = len(pattern)

        # 预处理 KMP 失配表
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and pattern[i] != pattern[j]:
                j = fail[j - 1]
            if pattern[i] == pattern[j]:
                j += 1
            fail[i] = j

        # 流式 KMP 匹配
        j = 0
        idx = 0
        while True:
            c = stream.next()
            while j > 0 and c != pattern[j]:
                j = fail[j - 1]
            if c == pattern[j]:
                j += 1
            if j == m:
                return idx - m + 1
            idx += 1
```

### 方法二：位运算滑动窗口（适合 pattern 较短时）

```python
from typing import List

class Solution:
    def findPattern(self, stream: 'InfiniteStream', pattern: List[int]) -> int:
        m = len(pattern)

        # 将 pattern 转为整数（位掩码）
        # 注意：仅适合 m <= 64 的情况
        if m > 64:
            # 退化为 KMP
            return self._kmp(stream, pattern)

        pat_val = 0
        for bit in pattern:
            pat_val = (pat_val << 1) | bit
        mask = (1 << m) - 1

        window = 0
        for i in range(m - 1):
            window = ((window << 1) | stream.next()) & mask

        idx = m - 1
        while True:
            window = ((window << 1) | stream.next()) & mask
            if window == pat_val:
                return idx - m + 1
            idx += 1

    def _kmp(self, stream, pattern):
        m = len(pattern)
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and pattern[i] != pattern[j]:
                j = fail[j-1]
            if pattern[i] == pattern[j]:
                j += 1
            fail[i] = j

        j = 0
        idx = 0
        while True:
            c = stream.next()
            while j > 0 and c != pattern[j]:
                j = fail[j-1]
            if c == pattern[j]:
                j += 1
            if j == m:
                return idx - m + 1
            idx += 1
```

## 复杂度分析

- KMP：O(n + m)，n 为找到匹配前读取的字符数
- 位运算（m <= 64）：O(n)，每步 O(1)
- 空间复杂度：O(m)

## 关键点总结

1. KMP 是流式匹配的标准解法，适合任意长度的 pattern
2. 位运算滑动窗口仅适合短 pattern（m <= 64）
3. 两种方法的匹配过程均为每字符 O(1) 均摊

## 易错点

1. 位运算方法中 mask 的计算：`(1 << m) - 1`
2. KMP 失配表中回退是 `j = fail[j-1]`，不是 `j--`
3. 初始时先读入前 m-1 个字符建立窗口，再开始逐字符判断
