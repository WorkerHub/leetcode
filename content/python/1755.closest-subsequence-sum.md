## 题目描述

给你一个整数数组 `nums` 和一个目标值 `goal`。

你需要从 `nums` 中选出一个子序列，使子序列元素总和最接近 `goal`。也就是说，如果子序列元素总和为 `sum`，你需要**最小化绝对差** `abs(sum - goal)`。

返回 `abs(sum - goal)` 可能的**最小值**。

**注意**，数组的每个元素都可以选取一次，选取的子序列不能为空。

**示例 1：**
```
输入：nums = [5,-7,3,5], goal = 6
输出：0
解释：选取子序列 [3,5]，和为 6
```

**提示：**
- `1 <= nums.length <= 40`
- `-10^7 <= nums[i] <= 10^7`
- `-10^9 <= goal <= 10^9`

## 解题思路

**折半枚举（Meet in the Middle）**：

1. 将数组分为两半，分别枚举所有子集的和（各 2^20 ≈ 10^6 个）
2. 对后半部分的和排序
3. 对前半部分的每个和 `s1`，在后半部分中二分查找最接近 `goal - s1` 的和

## 代码实现

### 方法一：折半枚举（Meet in the Middle）（推荐）

```python
from typing import List
import bisect

class Solution:
    def minAbsDifference(self, nums: List[int], goal: int) -> int:
        def get_all_sums(arr):
            """获取数组所有子集的和"""
            sums = [0]
            for x in arr:
                sums = sums + [s + x for s in sums]
            return sums
        
        n = len(nums)
        mid = n // 2
        
        # 前半部分和后半部分的所有子集和
        left_sums = get_all_sums(nums[:mid])
        right_sums = sorted(get_all_sums(nums[mid:]))
        
        ans = float('inf')
        
        for s1 in left_sums:
            target = goal - s1
            # 在 right_sums 中找最接近 target 的值
            pos = bisect.bisect_left(right_sums, target)
            
            # 检查 pos 和 pos-1 位置
            for p in [pos, pos - 1]:
                if 0 <= p < len(right_sums):
                    ans = min(ans, abs(s1 + right_sums[p] - goal))
        
        return ans
```

### 方法二：状态压缩枚举（适合理解）

```python
from typing import List
import bisect

class Solution:
    def minAbsDifference(self, nums: List[int], goal: int) -> int:
        n = len(nums)
        half = n // 2
        
        # 枚举前半部分所有 2^half 个子集的和
        left = []
        for mask in range(1 << half):
            s = sum(nums[i] for i in range(half) if (mask >> i) & 1)
            left.append(s)
        
        # 枚举后半部分所有 2^(n-half) 个子集的和
        right = []
        for mask in range(1 << (n - half)):
            s = sum(nums[half + i] for i in range(n - half) if (mask >> i) & 1)
            right.append(s)
        
        right.sort()
        ans = float('inf')
        
        for s1 in left:
            target = goal - s1
            pos = bisect.bisect_left(right, target)
            for p in [pos - 1, pos]:
                if 0 <= p < len(right):
                    ans = min(ans, abs(s1 + right[p] - goal))
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(2^(n/2) * n/2 + 2^(n/2) * log(2^(n/2))) = O(n * 2^(n/2))
- **空间复杂度**：O(2^(n/2))

## 关键点总结

1. 折半枚举（Meet in the Middle）将 O(2^n) 降为 O(2^(n/2))
2. 对一半的和排序，对另一半二分查找
3. 二分找最近时要检查前后两个位置

## 易错点

- 二分后要同时检查 `pos` 和 `pos-1`，因为最接近可能在两边
- 允许选空子集，但空子集和为 0，对结果有贡献
