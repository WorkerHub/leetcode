## 题目描述

给定一个字符串 `s`，移除其中所有的元音字母 `'a'`, `'e'`, `'i'`, `'o'`, `'u'`，并返回新字符串。

**示例 1:**

```
输入: s = "leetcodeisacommunityforcoders"
输出: "ltcdscmmntyfrcdrs"
```

**示例 2:**

```
输入: s = "aeiou"
输出: ""
```

**提示:**

- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

## 解题思路

这是一道简单的字符串处理题，主要考查字符串操作和过滤。

核心思路：
1. 遍历字符串中的每个字符
2. 判断字符是否为元音字母
3. 保留非元音字母，过滤掉元音字母

可以用多种方式实现：
- 字符串拼接
- 列表推导式
- filter 函数
- 正则表达式

## Python 代码实现

### 方法一：列表推导式（推荐）

```python
class Solution:
    def removeVowels(self, s: str) -> str:
        # 定义元音字母集合
        vowels = set('aeiou')
        
        # 使用列表推导式过滤，然后拼接
        return ''.join([ch for ch in s if ch not in vowels])
```

### 方法二：字符串拼接

```python
class Solution:
    def removeVowels(self, s: str) -> str:
        vowels = 'aeiou'
        result = ''
        
        # 遍历每个字符
        for ch in s:
            if ch not in vowels:
                result += ch
        
        return result
```

### 方法三：使用 filter 函数

```python
class Solution:
    def removeVowels(self, s: str) -> str:
        # 定义判断函数
        def is_not_vowel(ch):
            return ch not in 'aeiou'
        
        # 使用filter过滤
        return ''.join(filter(is_not_vowel, s))
```

### 方法四：正则表达式

```python
import re

class Solution:
    def removeVowels(self, s: str) -> str:
        # 使用正则表达式替换所有元音为空字符串
        return re.sub('[aeiou]', '', s)
```

### 方法五：使用 translate（最快）

```python
class Solution:
    def removeVowels(self, s: str) -> str:
        # 创建翻译表，将元音映射为None（删除）
        trans_table = str.maketrans('', '', 'aeiou')
        return s.translate(trans_table)
```

## 复杂度分析

**方法一（列表推导式）：**
- 时间复杂度：O(n)，其中 n 是字符串长度，需要遍历一次
- 空间复杂度：O(n)，存储结果列表

**方法二（字符串拼接）：**
- 时间复杂度：O(n²)，字符串拼接每次都会创建新字符串
- 空间复杂度：O(n)

**方法五（translate）：**
- 时间复杂度：O(n)，底层C实现，最快
- 空间复杂度：O(n)

## 关键点总结

1. **使用集合判断成员**：`vowels = set('aeiou')` 比字符串查找更快（O(1) vs O(5)）
2. **列表推导式**：简洁高效，是Python推荐的写法
3. **避免字符串直接拼接**：在循环中使用 `+=` 拼接字符串效率低
4. **translate 方法**：处理字符替换/删除的最快方法

## 易错点

1. **字符串拼接效率问题**：
   ```python
   # 不推荐：每次拼接都创建新字符串，O(n²)
   result = ''
   for ch in s:
       result += ch
   
   # 推荐：先用列表存储，最后join，O(n)
   result = []
   for ch in s:
       result.append(ch)
   return ''.join(result)
   ```

2. **忘记只处理小写**：题目保证只有小写字母，但如果有大写需求，要添加大写元音

3. **in 操作符的性能**：集合的 in 操作是 O(1)，字符串的 in 操作是 O(k)，k是元音数量
