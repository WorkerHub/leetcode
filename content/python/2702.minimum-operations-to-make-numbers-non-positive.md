## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和两个整数 `x` 和 `y`。每次操作中，你需要选择一个满足 `0 <= i < nums.length` 的下标 `i`，并同时执行：

- 将 `nums[i]` 减去 `x`
- 将所有其他 `nums[j]`（`j != i`）减去 `y`

返回使 `nums` 中所有元素都小于等于 0 的 **最少操作次数**。

**示例 1：**
```
输入：nums = [3,4,1,7,6], x = 4, y = 2
输出：3
解释：
- 操作 1：选 i=3，nums[3] -= 4, 其余 -= 2 → [1,2,-1,3,4]
- 操作 2：选 i=4，nums[4] -= 4, 其余 -= 2 → [-1,0,-3,1,0]
- 操作 3：选 i=3，nums[3] -= 4, 其余 -= 2 → [-3,-2,-5,-3,-2]
```

**示例 2：**
```
输入：nums = [1,2,3], x = 3, y = 1
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= y < x <= 10^9`

## 解题思路

**二分答案**：对操作次数 `mid` 进行二分。

对于给定操作次数 `k`，判断是否可行：
- 每个元素 `nums[i]` 至少被减了 `k * y`（所有操作都包含它）。
- 若某个元素被额外选中 `t` 次（作为"特殊元素"），则它额外被减了 `t * (x - y)`。
- 元素 `i` 被选中次数 `t_i` 需满足：`nums[i] - k*y - t_i*(x-y) <= 0`，即 `t_i >= ceil((nums[i] - k*y) / (x-y))`。
- 若 `nums[i] - k*y <= 0`，则不需要额外选中。
- 所有元素所需"被选次数"之和 <= `k`（总操作次数）。

## Python 代码实现

### 方法一：二分答案（推荐）

```python
import math
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int, y: int) -> int:
        def check(k: int) -> bool:
            # 判断 k 次操作是否可以使所有元素 <= 0
            total_needed = 0
            diff = x - y  # 被额外选中时多减的量
            for num in nums:
                # 经过 k 次操作后，元素至少减少了 k*y
                remaining = num - k * y
                if remaining > 0:
                    # 需要额外被选中的次数
                    t = math.ceil(remaining / diff)
                    total_needed += t
                    if total_needed > k:
                        return False
            return True

        # 二分操作次数的范围
        lo, hi = 0, max(nums)  # 最多 max(nums) 次操作
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：更紧凑的二分写法

```python
import math
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int, y: int) -> int:
        lo, hi = 0, max(nums)
        diff = x - y

        while lo < hi:
            mid = (lo + hi) // 2
            # 计算 mid 次操作所需的"特殊选择"总次数
            needed = sum(
                math.ceil((num - mid * y) / diff)
                for num in nums
                if num - mid * y > 0
            )
            if needed <= mid:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log(max(nums)))，二分 O(log(max)) 次，每次校验 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 二分操作次数，将"最优化问题"转化为"判定问题"
2. 每次操作每个元素都减 `y`，被选中的那个额外再减 `x - y`
3. 判定时累加各元素需要被额外选中的次数，与总次数 `k` 比较
4. 上界取 `max(nums)` 即可（最坏每次只减 1）

## 易错点

1. 注意 `x > y` 保证 `diff > 0`，除法无歧义
2. `ceil` 要用整数除法避免浮点误差：`(a + b - 1) // b`
3. 仅当 `remaining > 0` 才需要计算额外选中次数
