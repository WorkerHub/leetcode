## 题目描述

给定字符串 `word1` 和 `word2`。统计 `word1` 中有多少个子字符串，通过重排可以包含 `word2`（即该子串包含 `word2` 所有字符，考虑频次）。

**示例 1：**

```
输入：word1 = "bcca", word2 = "abc"
输出：1
解释：子串 "bcca" 包含 a,b,c,c，包含 word2 的 a,b,c，重排可得到包含 word2 的字符串。
     满足条件的子串：长度 >= 3 且包含 word2 所有字符（含频次）。
```

**示例 2：**

```
输入：word1 = "abbc", word2 = "bc"
输出：3
解释：满足的子串：[1,2]="bb"不满足，[1,3]="bbc"满足，...
```

**提示：**
- `1 <= word1.length <= 10^5`
- `1 <= word2.length <= 10^4`

## 解题思路

滑动窗口（两指针）。

统计 `word1` 的子串中，包含 `word2` 所有字符（频次）的子串数量。

滑动窗口标准方法：
1. 维护窗口内各字符频次
2. 当窗口满足条件（包含 word2 所有字符），所有以当前右端点结束的更长子串也满足
3. 用"缺失字符计数器"跟踪窗口是否满足条件

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def countSubstrings(self, word1: str, word2: str) -> int:
        n = len(word1)
        need = Counter(word2)
        window = Counter()
        missing = len(word2)  # 需要补充的字符总数
        left = 0
        result = 0

        for right in range(n):
            c = word1[right]
            window[c] += 1
            if c in need and window[c] <= need[c]:
                missing -= 1

            # 当窗口满足条件，缩小左端
            while missing == 0:
                # 以 right 为右端，left 为左端的子串满足条件
                # 以 right 为右端，0..left 为左端的所有子串也满足（更长的）
                result += 1
                # 移动左端
                lc = word1[left]
                window[lc] -= 1
                if lc in need and window[lc] < need[lc]:
                    missing += 1
                left += 1

        return result
```

### 方法二：二指针 + 统计所有满足条件的右端点

```python
from collections import Counter

class Solution:
    def countSubstrings(self, word1: str, word2: str) -> int:
        n = len(word1)
        m = len(word2)
        need = Counter(word2)
        total = 0

        # 对每个左端点，找最短满足条件的子串的右端点
        # 然后以左端点为起点的满足条件的子串数 = n - min_right
        # 这样做 O(n) 次，总 O(n^2)，需要更优化

        # 标准滑动窗口：统计所有满足条件的子串数
        window = Counter()
        satisfied = 0  # 窗口中已满足的字符种数
        need_count = sum(need.values())
        have = 0  # 当前窗口满足的字符总数
        left = 0

        for right in range(n):
            c = word1[right]
            window[c] += 1
            if c in need and window[c] <= need[c]:
                have += 1
            while have == need_count:
                total += n - right  # 以 left 为左端，right 到 n-1 为右端的子串都满足
                lc = word1[left]
                if lc in need and window[lc] <= need[lc]:
                    have -= 1
                window[lc] -= 1
                left += 1

        return total
```

## 复杂度分析

- 时间复杂度：O(n + m)，滑动窗口
- 空间复杂度：O(26) = O(1)，字符频次

## 关键点总结

1. 滑动窗口维护窗口内字符频次
2. 当满足条件时，以当前左端点为起点的所有更长子串也满足
3. 统计以左端点为起点的满足条件子串数 = n - (当前最短满足右端点)

## 易错点

1. 统计的是子串数量（有序），不是子集数量
2. 需要考虑字符频次（`word2` 中重复字符必须在子串中出现足够多次）
3. 一旦满足条件，继续缩小左端找更短满足条件的子串
