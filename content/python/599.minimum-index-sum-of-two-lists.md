## 题目描述

假设Andy和Doris想在晚餐时选择一家餐厅，并且他们都有一个表示最喜爱餐厅的列表，每个餐厅的名字用字符串表示。

你需要帮助他们用最少的索引和找出他们共同喜爱的餐厅。如果答案不止一个，则输出所有答案且不考虑顺序。你可以假设答案总是存在。

**示例：**
```
输入：list1 = ["Shogun","Tapioca Express","Burger King","KFC"], 
     list2 = ["Piatti","The Grill at Torrey Pines","Hungry Hunter Steakhouse","Shogun"]
输出：["Shogun"]
解释：唯一共同喜爱的餐厅是 "Shogun"
```

```
输入：list1 = ["Shogun","Tapioca Express","Burger King","KFC"], 
     list2 = ["KFC","Shogun","Burger King"]
输出：["Shogun"]
解释："Shogun" 的索引和最小 (0+1=1)
```

**提示：**
- `1 <= list1.length, list2.length <= 1000`
- `1 <= list1[i].length, list2[i].length <= 30`
- `list1[i]` 和 `list2[i]` 由空格 `' '` 和英文字母组成
- `list1` 的所有字符串都是唯一的
- `list2` 中的所有字符串都是唯一的

## Python 代码实现

```python
from typing import List

class Solution:
    def findRestaurant(self, list1: List[str], list2: List[str]) -> List[str]:
        """
        哈希表记录索引
        
        时间复杂度：O(m + n)
        空间复杂度：O(m)
        """
        # 记录 list1 中每个餐厅的索引
        index_map = {restaurant: i for i, restaurant in enumerate(list1)}
        
        min_sum = float('inf')
        result = []
        
        for j, restaurant in enumerate(list2):
            if restaurant in index_map:
                index_sum = index_map[restaurant] + j
                if index_sum < min_sum:
                    min_sum = index_sum
                    result = [restaurant]
                elif index_sum == min_sum:
                    result.append(restaurant)
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(m + n)，m和n分别是两个列表的长度
- **空间复杂度**：O(m)，哈希表存储list1

## 关键点总结

1. **哈希表**：用字典记录第一个列表的索引
2. **遍历比较**：遍历第二个列表，计算索引和
3. **更新结果**：维护最小索引和及其对应的餐厅
