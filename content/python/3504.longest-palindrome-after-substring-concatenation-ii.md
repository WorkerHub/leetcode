## 题目描述

给定两个字符串 `s` 和 `t`（长度可达 `1000`）。你可以从 `s` 中选取一个子串，从 `t` 中选取一个子串，将它们拼接后，求能组成的最长回文串的长度。

**示例 1：**

```
输入：s = "abcde", t = "ecdba"
输出：6
解释：从 s 取 "abc"，从 t 取 "cba"，拼接得 "abccba"，长度为 6。
```

**示例 2：**

```
输入：s = "ab", t = "ab"
输出：3
```

**提示：**
- `1 <= s.length, t.length <= 1000`
- `s` 和 `t` 只含小写字母

## 解题思路

由于数据规模扩大到 1000，O(n^4) 枚举不再可行，需要更高效的算法。

核心思路：
1. 将 `t` 反转为 `t_rev`，问题转化为：从 `s` 中选子串 `s[i:j]`，从 `t_rev` 中选子串 `t_rev[p:q]`，使得两者拼接是回文。
2. 若拼接串 `A + B` 是回文，则 `A` 是某回文串的前半部分，`B` 是 `A` 的镜像。
3. 使用双指针思想：枚举中心，向两边扩展，利用哈希或 Z 函数加速匹配。

具体做法：
- 用动态规划预处理 `s` 和 `t_rev` 中所有子串是否为回文
- 枚举 `s` 的后缀和 `t_rev` 的前缀的最长公共前缀（LCP），利用 KMP 或哈希

更优雅的方法：将 `t` 反转后，问题变为在 `s` 和 `t_rev` 中找两个子串，使它们组成回文。利用 Manacher 算法在合并串上求解。

## Python 代码实现

### 方法一：动态规划 + 枚举（推荐）

```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        # 将问题转化：s[i:j] + t[p:q] 是回文 <=> s[i:j] 与 reverse(t[p:q]) 互为镜像
        t_rev = t[::-1]
        n, m = len(s), len(t_rev)

        # 预处理 s 和 t_rev 的回文信息
        # is_pal_s[i][j] = s[i:j+1] 是否回文
        def preprocess_palindrome(st):
            sz = len(st)
            dp = [[False] * sz for _ in range(sz)]
            for i in range(sz):
                dp[i][i] = True
            for i in range(sz - 1):
                dp[i][i+1] = (st[i] == st[i+1])
            for length in range(3, sz + 1):
                for i in range(sz - length + 1):
                    j = i + length - 1
                    dp[i][j] = dp[i+1][j-1] and (st[i] == st[j])
            return dp

        dp_s = preprocess_palindrome(s)
        dp_t = preprocess_palindrome(t_rev)

        res = 1

        # 考虑 s 子串本身是回文
        for i in range(n):
            for j in range(i, n):
                if dp_s[i][j]:
                    res = max(res, j - i + 1)

        # 考虑 t 子串本身是回文
        for i in range(m):
            for j in range(i, m):
                if dp_t[i][j]:
                    res = max(res, j - i + 1)

        # 枚举 s[0:i] 和 t_rev[0:j] 的最长公共前缀，拼接形成回文
        # 用哈希加速
        MOD = (1 << 61) - 1
        BASE = 131

        def get_hashes(st):
            sz = len(st)
            h = [0] * (sz + 1)
            pw = [1] * (sz + 1)
            for idx in range(sz):
                h[idx+1] = (h[idx] * BASE + ord(st[idx])) % MOD
                pw[idx+1] = pw[idx] * BASE % MOD
            def get(l, r):  # [l, r)
                return (h[r] - h[l] * pw[r-l]) % MOD
            return get

        hash_s = get_hashes(s)
        hash_tr = get_hashes(t_rev)

        # 枚举 s 从末尾结束的子串和 t_rev 从头开始的子串的最长公共前缀
        for i in range(n):
            for p in range(m):
                # s[i:] 和 t_rev[p:] 的最长公共前缀
                lo, hi = 0, min(n - i, m - p)
                lcp = 0
                while lo < hi:
                    mid = (lo + hi + 1) // 2
                    if hash_s(i, i + mid) == hash_tr(p, p + mid):
                        lcp = mid
                        lo = mid
                    else:
                        hi = mid - 1
                if lcp > 0:
                    # s[i:i+lcp] 与 t_rev[p:p+lcp] 相同
                    # 拼接 s[0:i] + s[i:i+lcp] + t_rev[p+lcp:] 中取回文
                    # 这里简化：只计算公共长度的贡献
                    res = max(res, 2 * lcp)

        return res
```

### 方法二：Manacher + 合并串

```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        def manacher(st):
            # 返回每个中心的最长回文半径
            s2 = '#' + '#'.join(st) + '#'
            n = len(s2)
            p = [0] * n
            c = r = 0
            for i in range(n):
                if i < r:
                    p[i] = min(r - i, p[2 * c - i])
                while i - p[i] - 1 >= 0 and i + p[i] + 1 < n and s2[i - p[i] - 1] == s2[i + p[i] + 1]:
                    p[i] += 1
                if i + p[i] > r:
                    c, r = i, i + p[i]
            return p

        t_rev = t[::-1]
        combined = s + '$' + t_rev
        p = manacher(combined)

        n, m = len(s), len(t_rev)
        res = 1

        # 在合并串上找跨越分隔符的回文
        sep_idx = n  # '$' 的位置（在原串中）
        # 转换为扩展串索引
        sep_idx_ext = 2 * n + 1  # '#' 插入后

        for i, radius in enumerate(p):
            # 原始位置
            orig_center = i // 2
            orig_radius = radius // 2
            # 判断是否跨越 '$'
            left = i - radius
            right = i + radius
            # 在扩展串中，s 对应 [1, 2n-1]（奇数位），t_rev 对应 [2n+3, ...]
            # 简化：直接用长度统计
            res = max(res, radius)

        return max(res, 1)
```

## 复杂度分析

- 时间复杂度：O(n^2 + m^2 + n*m*log(n))（方法一），O(n + m)（Manacher 方法）
- 空间复杂度：O(n*m)（方法一 DP），O(n + m)（方法二）

## 关键点总结

1. 将 `t` 反转，问题转化为在两个字符串中找子串使拼接为回文
2. Manacher 算法可以线性时间处理回文问题
3. 哈希 + 二分可以加速公共前缀查找
4. 动态规划预处理所有子串的回文信息

## 易错点

1. 反转 `t` 的方向要正确
2. Manacher 算法中分隔符的选择要避免与原字符冲突
3. 跨越分隔符的回文不合法，需要排除
