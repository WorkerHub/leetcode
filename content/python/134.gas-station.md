## 题目描述

在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的汽车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 `gas` 和 `cost`，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 `-1`。如果存在解，则**保证**它是**唯一**的。

**示例 1：**
```
输入: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出: 3
解释:
从 3 号加油站(索引为 3 处)出发，可获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 4 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
开往 0 号加油站，此时油箱有 8 - 2 + 1 = 7 升汽油
开往 1 号加油站，此时油箱有 7 - 3 + 2 = 6 升汽油
开往 2 号加油站，此时油箱有 6 - 4 + 3 = 5 升汽油
开往 3 号加油站，你需要消耗 5 升汽油，正好足够你返回到 3 号加油站。
因此，3 可为起始索引。
```

**示例 2：**
```
输入: gas = [2,3,4], cost = [3,4,3]
输出: -1
解释:
你不能从 0 号或 1 号加油站出发，因为没有足够的汽油可以让你行驶到下一个加油站。
我们从 2 号加油站出发，可以获得 4 升汽油。 此时油箱有 = 0 + 4 = 4 升汽油
开往 0 号加油站，此时油箱有 4 - 3 + 2 = 3 升汽油
开往 1 号加油站，此时油箱有 3 - 3 + 3 = 3 升汽油
你无法返回 2 号加油站，因为返程需要消耗 4 升汽油，但是你的油箱只有 3 升汽油。
因此，无论怎样，你都不可能绕环路行驶一周。
```

**提示：**
- `gas.length == n`
- `cost.length == n`
- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`

## 解题思路

这道题是典型的**贪心算法**问题。

### 核心观察：

1. **必要条件**：如果 `sum(gas) < sum(cost)`，无论从哪里出发都无法完成一圈
2. **贪心策略**：如果从 A 出发无法到达 B，那么 A 和 B 之间的任何站点都无法到达 B
3. **唯一解性**：如果存在解，则解是唯一的（题目保证）

### 贪心思路：

1. 从第 0 个加油站开始尝试
2. 累计当前油量：`tank += gas[i] - cost[i]`
3. 如果油量小于 0，说明从当前起点无法到达下一站
4. 更新起点为下一个加油站，重置油量
5. 最后检查总油量是否 >= 0

### 为什么这样是对的？

- **跳过失败区间**：如果从 A 到 B 失败，那么 A 到 B 之间的任何点作为起点也会失败
  - 因为从 A 到中间某点 C 时，油量是累积的（>=0）
  - 从 C 开始，油量为 0，更不可能到达 B
- **总量判断**：如果总油量 >= 0，且前面的起点都失败，那么最后一个尝试的起点必定成功

## Python 代码实现

### 方法一：贪心算法（一次遍历）⭐

```python
from typing import List

class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        
        total_tank = 0  # 总油量
        current_tank = 0  # 当前油量
        start = 0  # 起始站点
        
        for i in range(n):
            # 计算在第 i 站的油量变化
            total_tank += gas[i] - cost[i]
            current_tank += gas[i] - cost[i]
            
            # 如果当前油量小于 0，无法从 start 到达 i+1
            if current_tank < 0:
                # 更新起点为下一个站点
                start = i + 1
                # 重置当前油量
                current_tank = 0
        
        # 如果总油量 >= 0，返回起点；否则返回 -1
        return start if total_tank >= 0 else -1
```

### 方法二：暴力解法（会超时）

```python
from typing import List

class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        
        # 尝试每个起点
        for start in range(n):
            tank = 0
            can_complete = True
            
            # 从 start 出发，走一圈
            for i in range(n):
                station = (start + i) % n
                tank += gas[station] - cost[station]
                
                # 油量不足
                if tank < 0:
                    can_complete = False
                    break
            
            if can_complete:
                return start
        
        return -1
```

### 方法三：优化暴力（提前剪枝）

```python
from typing import List

class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        
        # 总油量不足，直接返回
        if sum(gas) < sum(cost):
            return -1
        
        start = 0
        
        while start < n:
            tank = 0
            step = 0
            
            # 从 start 出发，尽可能走多远
            while step < n:
                station = (start + step) % n
                tank += gas[station] - cost[station]
                
                if tank < 0:
                    break
                
                step += 1
            
            # 成功走完一圈
            if step == n:
                return start
            
            # 跳过失败的区间
            start += step + 1
        
        return -1
```

### 方法四：两次遍历（容易理解）

```python
from typing import List

class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        
        # 第一次遍历：检查总油量
        total = sum(gas[i] - cost[i] for i in range(n))
        if total < 0:
            return -1
        
        # 第二次遍历：找起点
        tank = 0
        start = 0
        
        for i in range(n):
            tank += gas[i] - cost[i]
            
            if tank < 0:
                start = i + 1
                tank = 0
        
        return start
```

### 方法五：记录最小油量点

```python
from typing import List

class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        
        # 从 0 开始模拟一圈
        tank = 0
        min_tank = float('inf')
        min_index = 0
        
        for i in range(n):
            tank += gas[i] - cost[i]
            
            # 记录最低油量的位置
            if tank < min_tank:
                min_tank = tank
                min_index = i
        
        # 总油量不足
        if tank < 0:
            return -1
        
        # 从最低点的下一个位置出发
        return (min_index + 1) % n
```

## 复杂度分析

设加油站数量为 n。

### 方法一：贪心算法
- **时间复杂度**：O(n)，只需遍历一次
- **空间复杂度**：O(1)，只用了常数个变量

### 方法二：暴力解法
- **时间复杂度**：O(n^2)，每个起点尝试走一圈
- **空间复杂度**：O(1)

### 方法三：优化暴力
- **时间复杂度**：O(n)，虽然有两层循环，但每个站点最多访问两次
- **空间复杂度**：O(1)

## 关键点总结

1. **总量判断**：`sum(gas) >= sum(cost)` 是能完成的必要条件
2. **贪心策略**：从 A 无法到达 B，则 A~B 之间任何点都无法到达 B
3. **跳过失败区间**：失败后直接从下一个站点开始尝试
4. **唯一解性**：题目保证解唯一，简化了问题
5. **一次遍历**：贪心算法可以在 O(n) 时间内解决

## 易错点

1. **忘记检查总油量**
   ```python
   # 必须先检查总油量
   if sum(gas) < sum(cost):
       return -1
   ```

2. **油量计算错误**
   ```python
   # 错误：分开计算
   tank += gas[i]
   tank -= cost[i]
   
   # 正确：一次计算净增量
   tank += gas[i] - cost[i]
   ```

3. **起点更新错误**
   ```python
   # 错误：起点更新为 i
   start = i
   
   # 正确：起点更新为 i+1（下一个站点）
   start = i + 1
   ```

4. **重置油量**
   ```python
   # 更新起点时必须重置当前油量
   start = i + 1
   current_tank = 0  # 重要！
   ```

5. **环形处理**
   ```python
   # 处理环形数组
   station = (start + step) % n
   ```
