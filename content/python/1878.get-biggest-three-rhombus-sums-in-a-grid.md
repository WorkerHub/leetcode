## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，返回矩阵中**最大的三个菱形和**（不重复），按**降序**排列。

菱形以中心格 `(i, j)` 和半径 `k`（k >= 0）定义，包含：
- k=0 时：仅 `grid[i][j]` 本身
- k>0 时：菱形边界上的所有格子之和

若不足三个不同的菱形和，则返回所有不同的值。

**示例：**
```
输入：grid = [[3,4,5,1,3],[3,3,4,2,3],[20,30,200,40,10],[1,5,5,4,1],[4,3,2,2,3]]
输出：[228,216,211]
```

## 解题思路

**前缀和 + 枚举**：

对角线方向的前缀和：
- 右下对角线（`/` 方向）：`left[i][j]` = 从 `(i,0)` 到 `(i,j)` 的 `/` 对角线前缀和
- 左下对角线（`\` 方向）：`right[i][j]` = 从 `(i,j)` 到 `(i,n-1)` 的 `\` 对角线前缀和

实际上，菱形半径为 k 时，可以利用四条对角线的前缀和来快速计算菱形和。

维护一个最多3个元素的有序集合，枚举所有菱形（所有中心和所有半径），找最大的三个不同值。

## 代码实现

### 方法一：对角线前缀和 + 枚举（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])

        # 计算两个方向的对角线前缀和
        # left_diag[i][j] = 从 (i-j方向) 到 (i,j) 的累加（右下方向 '\'）
        # right_diag[i][j] = 从 (i,j) 到某处 的累加（左下方向 '/'）
        # 这里用直接的对角线前缀和

        # 简化版：直接枚举中心和半径，计算菱形和
        # 对角线前缀 dl[i][j] = 从该对角线起点到(i,j)的前缀和
        # 右下方向（↘）
        dl = [[0] * n for _ in range(m)]
        dr = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                dl[i][j] = grid[i][j]
                if i > 0 and j > 0:
                    dl[i][j] += dl[i-1][j-1]
                dr[i][j] = grid[i][j]
                if i > 0 and j < n-1:
                    dr[i][j] += dr[i-1][j+1]

        # 使用有序集合（最多保留3个不同值，保持降序）
        top3 = SortedList(key=lambda x: -x)

        def add_to_top3(val: int) -> None:
            if val not in top3:
                top3.add(val)
                if len(top3) > 3:
                    top3.pop(-1)

        def rhombus_sum(i: int, j: int, k: int) -> int:
            if k == 0:
                return grid[i][j]
            # 四条边的和（菱形边界）
            # 上顶点 (i-k, j)，下顶点 (i+k, j)，左顶点 (i, j-k)，右顶点 (i, j+k)
            top_i, bot_i = i - k, i + k
            if top_i < 0 or bot_i >= m or j - k < 0 or j + k >= n:
                return -1  # 超出边界

            # 上半部分右下边：从 (i-k, j) 到 (i, j+k)（'\'方向）
            s1 = dl[i][j+k] - (dl[i-k-1][j] if i-k > 0 else 0)
            # 上半部分左下边：从 (i-k, j) 到 (i, j-k)（'/'方向）
            s2 = dr[i][j-k] - (dr[i-k-1][j] if i-k > 0 else 0)
            # 下半部分右上边：从 (i, j+k) 到 (i+k, j)（'/'方向）
            s3 = dr[i+k][j] - (dr[i-1][j+k] if i > 0 else 0)
            # 下半部分左上边：从 (i, j-k) 到 (i+k, j)（'\'方向）
            s4 = dl[i+k][j] - (dl[i-1][j-k] if i > 0 else 0)
            # 注意：四个顶点被重复计算，需要减去
            return s1 + s2 + s3 + s4 - grid[i-k][j] - grid[i][j+k] - grid[i][j-k] - grid[i+k][j]

        for i in range(m):
            for j in range(n):
                add_to_top3(grid[i][j])  # k=0
                for k in range(1, min(i, m-1-i, j, n-1-j) + 1):
                    s = rhombus_sum(i, j, k)
                    if s >= 0:
                        add_to_top3(s)

        return list(top3)
```

### 方法二：暴力枚举（简单理解）

```python
from typing import List

class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        top3 = set()

        for i in range(m):
            for j in range(n):
                # k=0
                top3.add(grid[i][j])
                k = 1
                while i-k >= 0 and i+k < m and j-k >= 0 and j+k < n:
                    # 计算半径为 k 的菱形边界和
                    s = 0
                    for d in range(k):
                        s += grid[i-k+d][j+d]    # 上右边
                        s += grid[i+d][j+k-d]    # 右下边
                        s += grid[i+k-d][j-d]    # 下左边
                        s += grid[i-d][j-k+d]    # 左上边
                    top3.add(s)
                    k += 1

        return sorted(top3, reverse=True)[:3]
```

## 复杂度分析

- **方法一（对角线前缀和）**：O(m * n * min(m,n)) 时间，O(m*n) 空间
- **方法二（暴力）**：O(m * n * min(m,n)^2) 时间

## 关键点总结

1. 维护最多3个不同值的有序集合
2. 利用对角线前缀和将菱形和计算优化到 O(1)
3. 菱形边界的四条边对应两个对角线方向的前缀和段

## 易错点

- 菱形边界上的四个顶点被相邻两条边各计算一次，需要减去多余的计数
- 半径 k 的最大值受中心位置到边界距离的约束
