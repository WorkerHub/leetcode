## 题目描述

给定整数 `n` 和 `t`，找最小的正整数 `x`，使得 `x >= n` 且 `x` 的各位数字之和等于 `t`。

**示例 1：**
```
输入：n = 100, t = 1
输出：100
解释：100 的数字和为 1，满足条件。
```

**示例 2：**
```
输入：n = 1, t = 2
输出：2
解释：2 的数字和为 2，满足条件。
```

**示例 3：**
```
输入：n = 199, t = 10
输出：199
解释：1+9+9=19，不等于 10。下一个：200: 2，不等于 10。... 找到数字和为 10 的最小数 >= 199。
     19: 1+9=10，但 19 < 199。
     最小的 >= 199 且数字和为 10 的数是？ 280: 2+8=10 >= 199 ✓。
     217: 2+1+7=10, 217 >= 199 ✓。最小是 208? 2+0+8=10 ✓, 208 >= 199 ✓。最小是 208。
```

**提示：**
- `1 <= n <= 10^9`
- `1 <= t <= 100`

## 解题思路

从 `n` 开始，构造满足条件的最小整数。

**贪心方法：**
尝试直接修改 `n` 的各位来达到目标数字和 `t`：
1. 若 `n` 的数字和已经等于 `t`，直接返回 `n`。
2. 若数字和 < `t`：从最低位开始增加，使数字和增加到 `t`。
3. 若数字和 > `t`：需要进位，找合适的修改位置。

更稳妥的方法：二分或逐位贪心构造。

## Python 代码实现

### 方法一：贪心逐位构造（推荐）

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        def digit_sum(x):
            return sum(int(c) for c in str(x))

        # 从 n 开始向上搜索（如果范围小可以直接搜索）
        # 对于 n <= 10^9，位数最多 10，数字和最大 90
        # 若 t > 90，无法满足（但 t <= 100 时需要更多位）
        # 直接搜索可能太慢，使用贪心构造

        # 方法：枚举 x 的位数 L（L >= len(str(n))）
        # 在 L 位数中，找 >= n 且数字和为 t 的最小数

        for x in range(n, n + 1000000):  # 在一定范围内搜索
            if digit_sum(x) == t:
                return x

        # 若范围内找不到，构造更大的数
        # 长度为 L+1 的最小数字和为 t 的数
        L = len(str(n)) + 1
        if t <= 9 * L:
            # 构造 L 位数，数字和为 t
            digits = [0] * L
            rem = t
            digits[0] = 1
            rem -= 1
            for i in range(L - 1, 0, -1):
                digits[i] = min(9, rem)
                rem -= digits[i]
            return int(''.join(map(str, digits)))
        return -1
```

### 方法二：数位 DP 贪心

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        digits = list(str(n))
        L = len(digits)

        def build(digs, pos, rem, tight, started):
            """贪心构造：从 pos 位开始填充，剩余数字和为 rem"""
            if pos == L:
                return [] if rem == 0 else None
            lo = int(digs[pos]) if tight else 0
            # 从 lo 开始找满足条件的最小数字
            for d in range(lo if started else max(lo, 1 if pos == 0 else 0), 10):
                if rem - d < 0:
                    break
                if rem - d <= 9 * (L - pos - 1):  # 剩余位能凑出 rem-d
                    rest = build(digs, pos+1, rem-d, tight and d == lo, True)
                    if rest is not None:
                        return [d] + rest
            return None

        result = build(digits, 0, t, True, False)
        if result:
            return int(''.join(map(str, result)))

        # 需要更多位
        for extra in range(1, 5):
            new_L = L + extra
            if t <= 9 * new_L:
                r = [0] * new_L
                rem = t
                r[0] = 1 if t >= 1 else 0
                rem -= r[0]
                for i in range(new_L-1, 0, -1):
                    r[i] = min(9, rem)
                    rem -= r[i]
                if rem == 0:
                    return int(''.join(map(str, r)))
        return -1
```

## 复杂度分析

- 时间复杂度：O(10 * L) 贪心构造
- 空间复杂度：O(L)

## 关键点总结

1. 从 n 出发，尝试保持前缀不变，调整后缀使数字和等于 t
2. 若当前数字和不足，从最低位增加；若超出，进位处理
3. 贪心：每位尽量选小，同时确保后续能凑出剩余数字和

## 易错点

1. 当 t > 9 * 位数 时，当前位数无法满足，需要增加位数
2. 首位不能为 0
