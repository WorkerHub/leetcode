## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `k`。

请你返回满足下述条件的下标对 `(i, j)` 的数目：

- `0 <= i < j < nums.length`
- `nums[i] == nums[j]`
- `(i * j) % k == 0`

**示例：**
```
输入：nums = [3,1,2,2,2,1,3], k = 2
输出：4
解释：
- (0,6)：nums[0]=nums[6]=3，0*6=0，0%2=0
- (2,3)：nums[2]=nums[3]=2，2*3=6，6%2=0
- (2,4)：nums[2]=nums[4]=2，2*4=8，8%2=0
- (3,4)：nums[3]=nums[4]=2，3*4=12，12%2=0
共 4 对。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`

## 解题思路

**暴力枚举**

n <= 100，O(n^2) 枚举所有对，逐一检查三个条件。

## 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] == nums[j] and (i * j) % k == 0:
                    count += 1
        return count
```

### 方法二：哈希表优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        # 按值分组，同值的下标放一起
        groups = defaultdict(list)
        for i, v in enumerate(nums):
            groups[v].append(i)

        count = 0
        for indices in groups.values():
            m = len(indices)
            for a in range(m):
                for b in range(a + 1, m):
                    i, j = indices[a], indices[b]
                    if (i * j) % k == 0:
                        count += 1
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力 | O(n^2) | O(1) |
| 哈希 | O(n^2) 最坏 | O(n) |

## 关键点总结

1. n <= 100，O(n^2) 完全可行，直接暴力枚举。
2. 三个条件逐一检查：下标有序、值相等、乘积被 k 整除。
3. 哈希版本先分组，减少不必要的值比较，代码稍复杂但逻辑清晰。

## 易错点

- 条件是 `i < j`，不是 `i <= j`（不重复、不自配）。
- `(i * j) % k == 0` 表示 i * j 被 k 整除。
