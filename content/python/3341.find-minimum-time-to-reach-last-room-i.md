## 题目描述

给你一个 `n x m` 的地下城网格，从 `(0, 0)` 出发，目标是到达 `(n-1, m-1)`。

每个格子 `(i, j)` 有一个整数 `moveTime[i][j]`，表示在该时间点之后才能进入（即进入时间 >= moveTime[i][j]）。

从一个格子移动到相邻格子（上下左右）需要 **1 秒**。

初始时刻为 0，位于 `(0, 0)`。

返回到达 `(n-1, m-1)` 的最短时间。

**提示：**
- `2 <= n, m <= 750`
- `0 <= moveTime[i][j] <= 10^9`

## 解题思路

**Dijkstra 最短路：**

将每个格子 `(i, j)` 的到达时间定义为 `dist[i][j]`。

从 `(i, j)` 移动到 `(ni, nj)` 时，到达 `(ni, nj)` 的时间 = `max(dist[i][j], moveTime[ni][nj]) + 1`（等到开放时间再移动，移动需 1 秒）。

用 Dijkstra 算法（最小堆）求从 `(0, 0)` 到所有格子的最短时间。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minTimeToReach(self, moveTime: List[List[int]]) -> int:
        n, m = len(moveTime), len(moveTime[0])
        INF = float('inf')
        dist = [[INF] * m for _ in range(n)]
        dist[0][0] = 0
        
        # 最小堆：(当前时间, 行, 列)
        heap = [(0, 0, 0)]
        
        while heap:
            t, r, c = heapq.heappop(heap)
            
            if t > dist[r][c]:
                continue  # 已找到更短路径
            
            if r == n - 1 and c == m - 1:
                return t
            
            for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < m:
                    # 到达 (nr, nc) 的时间：等待 moveTime[nr][nc] 后再移动 1 秒
                    arrive = max(t, moveTime[nr][nc]) + 1
                    if arrive < dist[nr][nc]:
                        dist[nr][nc] = arrive
                        heapq.heappush(heap, (arrive, nr, nc))
        
        return dist[n-1][m-1]
```

## 复杂度分析

- 时间复杂度：O(n * m * log(n * m))，Dijkstra
- 空间复杂度：O(n * m)，距离数组和堆

## 关键点总结

1. 每步移动 1 秒，但到达目标格子需要等到 `moveTime` 指定的时间（两者取最大再 +1）。
2. Dijkstra 是处理带权最短路的标准算法。
3. `max(当前时间, moveTime[nr][nc]) + 1` 是关键转移公式。

## 易错点

1. 进入格子 `(0, 0)` 无需等待（初始就在此处）。
2. 到达时间 = `max(当前时间, moveTime[目标]) + 1`，不是简单相加。
3. Dijkstra 中需要检查 `t > dist[r][c]` 来跳过过时状态。
