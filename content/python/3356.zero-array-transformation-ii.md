## 题目描述

与 3355 类似，但每次查询 `[l, r, val]` 对区间 `[l, r]` 中的每个元素最多减 `val`（不能减到负数）。

返回使数组变为全 0 所需的**最少查询数** `k`（使用前 `k` 个查询），若不能变为全 0 则返回 -1。

**提示：**
- `1 <= nums.length <= 10^5`
- `queries[i] = [l, r, val]`
- `1 <= queries.length <= 10^5`

## 解题思路

**二分查找 + 差分数组：**

答案（最少查询数 k）具有单调性：若前 k 个查询能让数组变为全 0，则前 k+1 个也能。

因此，二分查找最小的 k，然后验证前 k 个查询是否足够。

**验证函数 `check(k)`：**
- 使用差分数组统计位置 i 被前 k 个查询覆盖的最大减少量。
- 但每次查询可以减的量是 `val`，不是 1，需要差分数组累加 `val`。
- 检验 `nums[i] <= cover[i]` 对所有 i 是否成立。

## Python 代码实现

### 方法一：二分 + 差分数组（推荐）

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        q = len(queries)
        
        def check(k):
            """前 k 个查询是否能使数组变为全 0"""
            diff = [0] * (n + 1)
            for i in range(k):
                l, r, val = queries[i]
                diff[l] += val
                diff[r + 1] -= val
            
            cover = 0
            for i in range(n):
                cover += diff[i]
                if nums[i] > cover:
                    return False
            return True
        
        # 先检查是否有解
        if not check(q):
            return -1
        
        # 二分查找最小的 k
        lo, hi = 0, q
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

## 复杂度分析

- 时间复杂度：O((n + q) * log q)，二分 * check 函数
- 空间复杂度：O(n)，差分数组

## 关键点总结

1. 二分答案的单调性：前 k 个查询足够，则前 k+1 个也足够。
2. 验证函数用差分数组 O(n + k) 计算每个位置的最大减少量。
3. 每个查询贡献 `val`（不是 1），差分数组中 `diff[l] += val, diff[r+1] -= val`。

## 易错点

1. 二分区间 `[0, q]`（包括 0，即不使用任何查询的情况）。
2. 差分数组中累加的是 `val`，不是 1。
3. 最终 `cover` 是区间内**最多可以减**的总量，需要 >= `nums[i]`。
