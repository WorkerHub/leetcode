## 题目描述

给定三个升序排列的整数数组 `arr1`、`arr2`、`arr3`，找出同时出现在这三个数组中的所有公共元素，以升序返回。

**示例 1：**
```
输入：arr1 = [1,2,3,4,5], arr2 = [1,2,5,7,9], arr3 = [1,3,4,5,8]
输出：[1,5]
解释：1 和 5 同时出现在三个数组中。
```

**示例 2：**
```
输入：arr1 = [1,2,3], arr2 = [4,5,6], arr3 = [7,8,9]
输出：[]
```

**提示：**
- `1 <= arr1.length, arr2.length, arr3.length <= 1000`
- `1 <= arr1[i], arr2[i], arr3[i] <= 2000`
- 每个数组内元素各不相同且升序排列

## 解题思路

**方法一：三指针**

分别用三个指针 `i`, `j`, `k` 遍历三个数组：
- 若三个指针指向的值相等，则该值是公共元素，三指针同时右移。
- 否则，找到三个值中最小的那个，对应指针右移（跳过较小的值）。

**方法二：哈希表**

用集合求交集：`set(arr1) & set(arr2) & set(arr3)`，排序后返回。

## Python 代码实现

### 方法一：三指针（推荐，O(n) 空间高效）

```python
from typing import List

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        i, j, k = 0, 0, 0
        result = []

        while i < len(arr1) and j < len(arr2) and k < len(arr3):
            a, b, c = arr1[i], arr2[j], arr3[k]
            if a == b == c:
                # 三个值相等，找到公共元素
                result.append(a)
                i += 1
                j += 1
                k += 1
            else:
                # 推进最小值对应的指针
                min_val = min(a, b, c)
                if a == min_val:
                    i += 1
                if b == min_val:
                    j += 1
                if c == min_val:
                    k += 1

        return result
```

### 方法二：集合求交集

```python
from typing import List

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        # Python 集合运算，简洁直观
        common = set(arr1) & set(arr2) & set(arr3)
        return sorted(common)
```

## 复杂度分析

- 时间复杂度：方法一 O(n1 + n2 + n3)；方法二 O((n1 + n2 + n3) log n)（含排序）
- 空间复杂度：方法一 O(1)（不计返回值）；方法二 O(n1 + n2 + n3)

## 关键点总结

1. 三指针是利用有序性的经典技巧，线性时间复杂度
2. 推进最小值的指针，快速跳过不可能是公共元素的值
3. 集合交集方法代码更简洁，适合快速实现

## 易错点

1. 三指针方法中，若有多个指针指向最小值，它们都需要右移
2. 返回结果需要升序，三指针方法自然有序，集合方法需要排序
