## 题目描述

给你一个 `n x n` 的整数矩阵 `matrix`，你可以进行以下操作**任意次**：选择矩阵中**相邻两个元素**，同时**乘以 -1**。

返回矩阵中所有元素的**最大可能总和**。

**示例 1：**
```
输入：matrix = [[1,-1],[-1,1]]
输出：4
```

**示例 2：**
```
输入：matrix = [[1,2,3],[-1,-2,-3],[1,2,3]]
输出：16
```

**提示：**
- `n == matrix.length == matrix[i].length`
- `2 <= n <= 250`
- `-10^5 <= matrix[i][j] <= 10^5`

---

## 解题思路

### 核心思想：贪心

操作可以将任意两个相邻元素的符号都取反。通过多次操作，**负号可以"移动"到任意位置**。

关键观察：
1. 每次操作将两个相邻元素同时取反，负号的总奇偶性不变（偶数个负号可以全部消除）
2. 若负号数量为**偶数**，可以两两消除，所有元素取绝对值之和最大
3. 若负号数量为**奇数**，最终必须剩一个负号，应放在绝对值最小的元素上

答案 = 所有元素绝对值之和 - 2 * 最小绝对值（若负数个数为奇数）

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxMatrixSum(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        total = 0
        neg_count = 0
        min_abs = float('inf')

        for row in matrix:
            for x in row:
                total += abs(x)
                if x < 0:
                    neg_count += 1
                min_abs = min(min_abs, abs(x))

        # 若负数个数为偶数，可以全部消除；否则最小绝对值元素保留负号
        if neg_count % 2 == 0:
            return total
        else:
            return total - 2 * min_abs
```

### 方法二：显式贪心（详细注释版）

```python
from typing import List

class Solution:
    def maxMatrixSum(self, matrix: List[List[int]]) -> int:
        total_abs = 0    # 所有元素绝对值之和
        neg_cnt = 0      # 负数个数
        min_abs_val = float('inf')  # 最小绝对值

        for row in matrix:
            for x in row:
                abs_x = abs(x)
                total_abs += abs_x
                if x < 0:
                    neg_cnt += 1
                if abs_x < min_abs_val:
                    min_abs_val = abs_x

        # 偶数个负号：可以全消，最大和 = 所有绝对值之和
        # 奇数个负号：最小绝对值元素取负，减去 2 倍
        if neg_cnt % 2 == 0:
            return total_abs
        return total_abs - 2 * min_abs_val
```

## 关键点总结

1. 负号可以通过相邻元素操作任意"移动"，偶数个负号可以全部消除
2. 奇数个负号：最终留一个负号在绝对值最小的元素上，损失最少
3. 有零时，最小绝对值为 0，奇数个负号也可以全部消除（答案等于所有绝对值之和）

---

## 易错点

- 若矩阵中有 0，则 `min_abs = 0`，`total - 2 * 0 = total`，即使奇数个负号也能消除
- 统计负数个数时，0 不算负数
