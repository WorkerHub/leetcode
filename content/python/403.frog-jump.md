## 题目描述

一只青蛙想要过河。假定河流被等分为若干个单元格，并且在每一个单元格内都有可能放有一块石子（也有可能没有）。青蛙可以跳上石子，但是不可以跳入水中。

给你石子的位置列表 stones（用单元格序号升序表示），请判定青蛙能否成功过河（即能否在最后一步跳至最后一块石子上）。

开始时，青蛙默认已站在第一块石子上，并可以假定它第一步只能跳跃 1 个单位（即只能从单元格 1 跳至单元格 2）。

如果青蛙上一步跳跃了 k 个单位，那么它接下来的跳跃距离只能选择为 k - 1、k 或 k + 1 个单位。另请注意，青蛙只能向前方跳跃。

**示例 1：**
```
输入：stones = [0,1,3,5,6,8,12,17]
输出：true
解释：青蛙可以成功过河，按照如下方案跳跃：跳 1 个单位到第 2 块石子, 然后跳 2 个单位到第 3 块石子, 接着跳 2 个单位到第 4 块石子, 然后跳 3 个单位到第 6 块石子, 跳 4 个单位到第 7 块石子, 最后，跳 5 个单位到第 8 个石子（即最后一块石子）。
```

**示例 2：**
```
输入：stones = [0,1,2,3,4,8,9,11]
输出：false
解释：这是因为第 5 和第 6 个石子之间的间距太大，没有可行的方案让青蛙跳过去。
```

**提示：**
- 2 <= stones.length <= 2000
- 0 <= stones[i] <= 2^31 - 1
- stones[0] == 0
- stones 按严格升序排列

## 解题思路

这是一道经典的动态规划问题，需要记录青蛙在每个位置可能的跳跃距离。

核心观察：
1. 青蛙从位置 0 开始，第一步只能跳 1 个单位
2. 如果上一步跳了 k 单位，这一步只能跳 k-1、k 或 k+1 单位
3. 需要判断能否跳到最后一块石子

解决方案：
- **方法一（推荐）**：记忆化搜索（DFS + 哈希表）
- **方法二**：动态规划（哈希表记录每个位置可达的跳跃距离）
- **方法三**：BFS 广度优先搜索

## Python 代码实现

### 方法一：记忆化搜索（推荐）

```python
from typing import List

class Solution:
    def canCross(self, stones: List[int]) -> bool:
        """
        DFS + 记忆化搜索
        状态：(当前位置索引, 上一步跳跃距离)
        """
        n = len(stones)
        # 将石子位置转换为集合，方便 O(1) 查找
        stone_set = set(stones)
        # 记忆化：(位置, 跳跃距离) -> 能否到达终点
        memo = {}
        
        def dfs(pos: int, k: int) -> bool:
            """
            pos: 当前位置
            k: 上一步的跳跃距离
            返回：能否从当前位置跳到最后一块石子
            """
            # 到达最后一块石子
            if pos == stones[-1]:
                return True
            
            # 已经计算过
            if (pos, k) in memo:
                return memo[(pos, k)]
            
            # 尝试三种跳跃距离：k-1, k, k+1
            for next_k in [k - 1, k, k + 1]:
                if next_k > 0:  # 跳跃距离必须为正数
                    next_pos = pos + next_k
                    # 下一个位置必须是石子
                    if next_pos in stone_set:
                        if dfs(next_pos, next_k):
                            memo[(pos, k)] = True
                            return True
            
            memo[(pos, k)] = False
            return False
        
        # 从位置 0 开始，第一步跳 1 个单位到位置 1
        # 如果第二块石子不在位置 1，直接返回 False
        if 1 not in stone_set:
            return False
        
        return dfs(1, 1)
```

### 方法二：动态规划（哈希表）

```python
from typing import List
from collections import defaultdict

class Solution:
    def canCross(self, stones: List[int]) -> bool:
        """
        动态规划：dp[i] 表示到达第 i 块石子时可能的跳跃距离集合
        """
        # dp[石子位置] = 到达该位置可能的跳跃距离集合
        dp = defaultdict(set)
        dp[0].add(0)  # 起点，跳跃距离为 0
        
        for stone in stones:
            # 遍历到达当前石子的所有可能跳跃距离
            for k in dp[stone]:
                # 尝试下一步的三种跳跃距离
                for next_k in [k - 1, k, k + 1]:
                    if next_k > 0:  # 跳跃距离必须为正
                        next_pos = stone + next_k
                        # 如果下一个位置是石子，记录跳跃距离
                        if next_pos in stones:
                            dp[next_pos].add(next_k)
        
        # 检查最后一块石子是否可达
        return len(dp[stones[-1]]) > 0
```

### 方法三：BFS 广度优先搜索

```python
from typing import List
from collections import deque

class Solution:
    def canCross(self, stones: List[int]) -> bool:
        """
        BFS：逐层搜索所有可能的跳跃方案
        """
        n = len(stones)
        stone_set = set(stones)
        target = stones[-1]
        
        # 队列：(当前位置, 上一步跳跃距离)
        queue = deque([(0, 0)])
        # 访问过的状态
        visited = {(0, 0)}
        
        while queue:
            pos, k = queue.popleft()
            
            # 尝试三种跳跃距离
            for next_k in [k - 1, k, k + 1]:
                if next_k > 0:
                    next_pos = pos + next_k
                    
                    # 到达终点
                    if next_pos == target:
                        return True
                    
                    # 下一个位置是石子且未访问过
                    if next_pos in stone_set and (next_pos, next_k) not in visited:
                        visited.add((next_pos, next_k))
                        queue.append((next_pos, next_k))
        
        return False
```

### 方法四：优化的动态规划（使用索引）

```python
from typing import List
from collections import defaultdict

class Solution:
    def canCross(self, stones: List[int]) -> bool:
        """
        优化版 DP：使用字典映射位置到索引
        """
        n = len(stones)
        # 位置 -> 索引的映射
        pos_to_idx = {stone: i for i, stone in enumerate(stones)}
        
        # dp[i] = 到达索引 i 处石子的所有可能跳跃距离
        dp = [set() for _ in range(n)]
        dp[0].add(0)
        
        for i in range(n):
            for k in dp[i]:
                # 尝试三种跳跃
                for next_k in [k - 1, k, k + 1]:
                    if next_k > 0:
                        next_pos = stones[i] + next_k
                        if next_pos in pos_to_idx:
                            dp[pos_to_idx[next_pos]].add(next_k)
        
        return len(dp[n - 1]) > 0
```

## 复杂度分析

### 方法一：记忆化搜索

- **时间复杂度**：O(n^2)
  - 最多有 O(n^2) 个不同的状态 (位置, 跳跃距离)
  - 每个状态最多计算一次
  
- **空间复杂度**：O(n^2)
  - 记忆化存储和递归栈的空间

### 方法二：动态规划

- **时间复杂度**：O(n^2)
  - 对每块石子，可能有 O(n) 种跳跃距离
  
- **空间复杂度**：O(n^2)
  - 存储每个位置的跳跃距离集合

## 关键点总结

1. **状态定义**：需要记录 (位置, 上一步跳跃距离) 的二维状态
2. **状态转移**：如果上一步跳了 k，这一步可以跳 k-1、k 或 k+1
3. **剪枝优化**：
   - 跳跃距离必须 > 0
   - 下一个位置必须有石子
   - 使用集合加速查找
4. **初始条件**：第一步必须从 0 跳到 1，跳跃距离为 1

## 易错点

1. **初始条件**：
   - 如果 `stones[1] != 1`，青蛙无法开始跳跃，应返回 False
   - 初始状态是 `(0, 0)` 或从 `(1, 1)` 开始

2. **跳跃距离限制**：
   - k - 1 可能为 0，但跳跃距离不能为 0 或负数
   - 要检查 `next_k > 0`

3. **重复计算**：
   - 必须使用记忆化或 DP，否则会超时
   - 相同的 (位置, 跳跃距离) 状态可能被多次访问

4. **集合查找**：
   - 将 stones 转换为集合，提高查找效率
   - 不要每次遍历数组查找

## 学习建议

1. **理解状态设计**：
   - 为什么需要二维状态？因为下一步的选择依赖于上一步的跳跃距离
   - 状态压缩：能否只用一维？不能，因为同一位置可能有多种到达方式

2. **记忆化 vs DP**：
   - 记忆化搜索：自顶向下，代码更直观
   - DP：自底向上，避免递归开销
   - 两种方法本质相同，复杂度一致

3. **优化技巧**：
   - 使用哈希表/集合加速查找
   - 剪枝：跳跃距离不可能超过石子数量
   - 提前终止：到达终点即可返回

4. **调试建议**：
   - 打印 dp 状态，观察每个位置可能的跳跃距离
   - 从小数据开始测试
   - 检查边界条件
