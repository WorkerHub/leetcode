## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和正整数 `k`。

定义子序列的"幂"：若子序列中所有元素之和等于 `k`，则幂为 `2^(n - 子序列长度)`，否则为 0。

返回 `nums` 所有非空子序列的幂之和，答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3], k = 3
输出：6
解释：子序列 [3] 幂=4，[1,2] 幂=2，[1,2,3]（若和=3）幂=1，但 1+2+3=6 != 3
实际：[3]→2^2=4，[1,2]→2^1=2，总和 6
```

**提示：**
- `1 <= n <= 15`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= 10^9`

## 解题思路

设 `f(S)` 为子序列 `S` 的幂，当且仅当 `sum(S) == k` 时 `f(S) = 2^(n - |S|)`。

等价转化：对每个和为 `k` 的子序列 `S`（长度 `m`），它的幂为 `2^(n-m)`。这等于：包含 `S` 的所有超集的数量（`S` 加上剩余 `n-m` 个元素中任意选择的子集），共 `2^(n-m)` 个超集。

所以 **总幂** = 所有和为 `k` 的子序列数 × 对应的超集数 = 对每个和为 `k` 的子序列 `S`，统计包含 `S` 的所有子集数（`2^(n - |S|)`）。

等价于：**所有子集 T 中，若 T 包含某个和为 k 的子序列，则 T 对答案贡献 1**，即统计"包含至少一个和为 k 的子序列"的子集 T 的数量。

进一步简化：DP 统计所有大小为 `j` 的和为 `k` 的子序列数 `dp[j]`，答案 = `sum(dp[j] * 2^(n-j))`。

`dp[j]` = 大小恰好为 `j` 且和为 `k` 的子序列数。

## Python 代码实现

### 方法一：DP 统计（推荐）

```python
from typing import List

class Solution:
    def sumOfPower(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # dp[j][s] = 选了 j 个元素，和为 s 的子序列数
        # 但 k 可能很大，用哈希表
        from collections import defaultdict

        # dp[j] = {sum: count}，选 j 个元素的各种和的方案数
        # 由于 n <= 15，j 最多 15，k <= 10^4 * 15 = 1.5*10^5
        # 可以用 dp[sum] = 方案数（按选择元素数分层）

        # 简化：dp[s] = 和为 s 的子序列数（不限大小，但需分层计 2^(n-size)）
        # 改为：dp_by_size[j][s] = 大小为 j、和为 s 的子序列数

        # n <= 15，dp_by_size 最多 16 * k 大小，k 可达 1.5*10^5
        # 总状态 O(n * k)，可行

        # dp[j] 表示大小为 j 的子序列的和的计数字典
        dp = [defaultdict(int) for _ in range(n + 1)]
        dp[0][0] = 1  # 大小为 0，和为 0，有 1 个（空子序列）

        for num in nums:
            # 倒序更新（避免重复选同一元素）
            for j in range(min(n, n), 0, -1):
                for s, cnt in dp[j - 1].items():
                    dp[j][s + num] = (dp[j][s + num] + cnt) % MOD

        ans = 0
        for j in range(1, n + 1):
            if k in dp[j]:
                ans = (ans + dp[j][k] * pow(2, n - j, MOD)) % MOD

        return ans
```

### 方法二：优化版

```python
from typing import List
from collections import defaultdict

class Solution:
    def sumOfPower(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # dp[(size, sum)] = 方案数
        dp = defaultdict(int)
        dp[(0, 0)] = 1

        for num in nums:
            new_dp = defaultdict(int)
            for (j, s), cnt in dp.items():
                new_dp[(j, s)] = (new_dp[(j, s)] + cnt) % MOD
                new_dp[(j + 1, s + num)] = (new_dp[(j + 1, s + num)] + cnt) % MOD
            dp = new_dp

        ans = 0
        for (j, s), cnt in dp.items():
            if s == k and j > 0:
                ans = (ans + cnt * pow(2, n - j, MOD)) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)，状态数 O(n * k)，转移 O(n)
- 空间复杂度：O(n * k)

## 关键点总结

1. 问题转化：幂之和 = 统计每种大小的和为 k 的子序列数，乘以 2^(n-j)
2. DP 统计按大小分层的和为 k 的子序列数
3. n <= 15 保证了状态数有限

## 易错点

1. 幂的定义是 `2^(n - 子序列长度)`，不是 `2^(子序列长度)`
2. 空子序列不算（幂为 0）
3. 注意取模操作
