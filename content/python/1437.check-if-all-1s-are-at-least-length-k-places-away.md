## 题目描述

给你一个由若干 `0` 和 `1` 组成的数组 `nums` 以及整数 `k`。

如果所有 `1` 都至少相距 `k` 个位置，则返回 `true`；否则，返回 `false`。

"至少相距 k 个位置"指：对任意两个 `1` 的下标 `i` 和 `j`（`i < j`），都满足 `j - i >= k`。

**示例 1：**
```
输入：nums = [1,0,0,0,1,0,0,1], k = 2
输出：true
解释：每对 1 之间都至少间隔了 2 个位置。
1 在下标 0, 4, 7，间距为 4 和 3，均 >= 2，返回 true。
```

**示例 2：**
```
输入：nums = [1,0,0,1,0,1], k = 2
输出：false
解释：下标 3 和 5 的 1 之间只有 1 个 0，间距为 2，但...
实际：5 - 3 = 2，若 k=2 则 2 >= 2 满足。
再看：下标 0 和 3：3-0=3>=2，3 和 5：5-3=2>=2，均满足，应返回 true。
（注意：若 k=2 则答案为 true，若 k=3 则 5-3=2 < 3，答案为 false。）
```

**示例 3：**
```
输入：nums = [1,0,0,0,1,0,0,1], k = 3
输出：false
解释：第二个 1 在下标 4，第三个在下标 7，7-4=3>=3；
但下标 0 到 4 的间距为 4>=3，满足。返回 true。
（若 nums=[1,0,0,1,0,1], k=2 则下标 3和5 差值为 2=k，满足。）
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= k <= nums.length`
- `nums[i]` 为 `0` 或 `1`

## 解题思路

**思路：记录上一个 1 的位置**

由于只需要检查相邻两个 `1` 之间的距离（非相邻的距离一定更大），因此：
1. 遍历数组，记录上一个 `1` 的下标 `last`（初始化为 `-k-1` 或 `-inf`）。
2. 遇到 `1` 时，检查 `当前下标 - last >= k`。
   - 若满足，更新 `last`。
   - 若不满足，直接返回 `False`。
3. 遍历完成后返回 `True`。

**为什么只检查相邻 1 之间的距离？**  
若相邻两个 1 的距离都 >= k，则所有 1 的距离自然 >= k（间距是单调不减的关系，相邻最小）。

## Python 代码实现

### 方法一：记录上一个 1 的位置（推荐）

```python
from typing import List

class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        last = -k - 1  # 初始值确保第一个 1 一定满足条件

        for i, num in enumerate(nums):
            if num == 1:
                if i - last < k:
                    return False  # 距离不足 k
                last = i  # 更新上一个 1 的位置

        return True
```

**注意：** 这里的距离是下标之差，`i - last >= k` 等价于"两个 1 之间至少有 k-1 个位置"（但题目的"相距 k 个位置"通常指下标差 >= k，需看题意）。

实际上题目中的例子：`nums=[1,0,0,0,1,0,0,1], k=2`，1 在下标 0、4、7，差值为 4 和 3，均 >= 2，返回 true。所以条件是 `i - last >= k`。

### 方法二：提取所有 1 的下标，逐一比较

```python
from typing import List

class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        # 找出所有 1 的下标
        ones = [i for i, num in enumerate(nums) if num == 1]

        # 检查相邻两个 1 的间距
        for i in range(1, len(ones)):
            if ones[i] - ones[i - 1] < k:
                return False

        return True
```

### 方法三：使用 zip 简化相邻比较

```python
from typing import List

class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        ones = [i for i, num in enumerate(nums) if num == 1]
        # zip(ones, ones[1:]) 生成相邻对 (ones[i], ones[i+1])
        return all(b - a >= k for a, b in zip(ones, ones[1:]))
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历数组一次。
- **空间复杂度：**
  - 方法一：O(1)，仅用常数空间。
  - 方法二/三：O(m)，m 为 1 的数量。

## 图解示例

```
nums = [1,0,0,0,1,0,0,1], k = 2

遍历：
  下标 0：num=1，last=-3（初始），0-(-3)=3 >= 2，更新 last=0
  下标 4：num=1，4-0=4 >= 2，更新 last=4
  下标 7：num=1，7-4=3 >= 2，更新 last=7

遍历完毕，返回 True
```

## 关键点总结

1. 只需检查相邻两个 `1` 的距离，因为相邻距离是所有 `1` 对距离中最小的。
2. 初始化 `last = -k - 1` 确保遇到第一个 `1` 时不会误判（`0 - (-k-1) = k+1 >= k`）。
3. 方法三的 `zip(ones, ones[1:])` 是 Python 中比较相邻元素的惯用写法，值得掌握。
4. 如果数组中没有 `1` 或只有一个 `1`，方法自然返回 `True`。

## 易错点

- 初始 `last` 设置不当（如设为 0），导致第一个 1 在下标 0 时误判。
- 检查条件写成 `i - last <= k`（方向反了），或用 `>` 而非 `>=`（边界错误）。
- 忘记在找到不满足条件的情况时立即返回，继续遍历浪费时间。
