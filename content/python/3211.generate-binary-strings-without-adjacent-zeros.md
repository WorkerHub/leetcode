## 题目描述

给你一个正整数 `n`，返回所有长度为 `n`、不含**相邻零**的二进制字符串。

你可以以**任意顺序**返回答案。

**示例 1：**
```
输入：n = 1
输出：["0","1"]
```

**示例 2：**
```
输入：n = 2
输出：["10","11","01"]
解释：不包含 "00"（含相邻零）
```

**示例 3：**
```
输入：n = 3
输出：["010","011","101","110","111","100","001"]
（不含 "000","001" 中含 "00" 的...）
```

**提示：**
- `1 <= n <= 18`

## 解题思路

**递归回溯**：逐位生成，每次选择 '0' 或 '1'，如果上一位是 '0'，则当前位只能是 '1'。

也可以用位运算枚举所有 n 位整数，过滤掉含相邻 0（即某位是 0 且下一位也是 0）的数。

## Python 代码实现

### 方法一：递归回溯（推荐）

```python
from typing import List

class Solution:
    def validStrings(self, n: int) -> List[str]:
        ans = []
        
        def backtrack(path: list, last_char: str):
            if len(path) == n:
                ans.append(''.join(path))
                return
            # 尝试放 '1'
            path.append('1')
            backtrack(path, '1')
            path.pop()
            # 只有上一位不是 '0' 时才能放 '0'
            if last_char != '0':
                path.append('0')
                backtrack(path, '0')
                path.pop()
        
        backtrack([], '1')  # 初始假设上一位是 '1'，允许第一位放 '0'
        return ans
```

### 方法二：位运算枚举

```python
from typing import List

class Solution:
    def validStrings(self, n: int) -> List[str]:
        ans = []
        for mask in range(1 << n):
            # 检查是否有相邻的 0
            # 相邻两位都是 0：(~mask) & (~mask >> 1) & ((1<<n)-1) != 0
            inv = (~mask) & ((1 << n) - 1)  # 取反，得到 0 的位置
            if inv & (inv >> 1) == 0:  # 没有相邻的 0
                ans.append(format(mask, f'0{n}b'))
        return ans
```

### 方法三：迭代生成

```python
from typing import List

class Solution:
    def validStrings(self, n: int) -> List[str]:
        # 从长度 1 开始，逐步扩展
        cur = ['0', '1']
        for _ in range(n - 1):
            nxt = []
            for s in cur:
                nxt.append(s + '1')  # 任何字符后都可以接 '1'
                if s[-1] != '0':     # 只有末尾不是 '0' 才能接 '0'
                    nxt.append(s + '0')
            cur = nxt
        return cur
```

## 复杂度分析

- 时间复杂度：O(2^n)，结果集大小约为 2^n
- 空间复杂度：O(n * 2^n)，存储所有结果

## 关键点总结

1. 核心约束：不允许相邻两位都是 '0'
2. 递归时，若上一位是 '0'，则当前位只能是 '1'
3. 位运算方法：检查 `inv & (inv >> 1) == 0` 是否成立

## 易错点

1. 回溯初始时，要允许第一位放 '0'（假设前一位不是 '0'）
2. 位运算中取反后需要用掩码截断到 n 位
