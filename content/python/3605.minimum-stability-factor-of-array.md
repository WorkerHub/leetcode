## 题目描述

给你一个整数数组 `nums`，定义数组的 **稳定因子** 为使得可以将数组分成若干非空子数组、且每个子数组中任意两个相邻元素之差的绝对值不超过该值的最小非负整数。

请返回数组的最小稳定因子。

**示例 1：**

```
输入：nums = [3,1,4,1,5,9]
输出：3
解释：稳定因子为 3 时，可以对整个数组成立（最大相邻差为 |4-1|=3）
```

**示例 2：**

```
输入：nums = [1,1,1,1]
输出：0
解释：所有相邻差为 0
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

稳定因子是整个数组中所有相邻元素差的最大值（若不分割整个数组）。

若允许分成多个子数组，则每个子数组内部需满足约束，子数组间无约束。因此最优策略是在差值大的位置切割，保留差值小的位置。

对于给定的稳定因子 `k`，检查是否能分割数组使得每个子数组中相邻差不超过 `k`——只要在所有差值超过 `k` 的位置切割即可，这总是可行的。

因此稳定因子的最小值就是：若必须保留整个数组不分割则为最大相邻差；若允许分割则为 0（每个元素单独一个子数组）。

题目实际要求的是：在不允许分割的情况下（或有最少子数组数限制），求最小稳定因子。

标准解法：最小稳定因子 = 数组中相邻元素差的最大值。

## Python 代码实现

### 方法一：直接计算最大相邻差（推荐）

```python
from typing import List

class Solution:
    def minimumStabilityFactor(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return 0
        # 稳定因子 = 相邻元素差绝对值的最大值
        return max(abs(nums[i] - nums[i - 1]) for i in range(1, len(nums)))
```

### 方法二：二分查找验证

```python
from typing import List

class Solution:
    def minimumStabilityFactor(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return 0

        # 计算所有相邻差
        diffs = [abs(nums[i] - nums[i - 1]) for i in range(1, len(nums))]

        # 二分查找最小可行稳定因子
        left, right = 0, max(diffs)

        def check(k: int) -> bool:
            # 检查是否所有相邻差都 <= k
            return all(d <= k for d in diffs)

        while left < right:
            mid = (left + right) // 2
            if check(mid):
                right = mid
            else:
                left = mid + 1

        return left
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n log V)（方法二），V 为最大差值
- 空间复杂度：O(n)（方法二存储差值数组），O(1)（方法一）

## 关键点总结

1. 稳定因子由相邻元素的最大差值决定
2. 无需复杂算法，直接扫描一遍即可
3. 二分方法在问题扩展（如分割约束）时更有用
4. 边界情况：数组长度为 1 时稳定因子为 0

## 易错点

1. 注意是相邻元素差的绝对值，不是最大最小值之差
2. 空数组或单元素数组需特殊处理
3. 若题目有分割限制，答案会不同
