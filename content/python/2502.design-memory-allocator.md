## 题目描述

给你一个整数 `n`，表示下标从 **0** 开始的内存数组的大小。所有内存单元开始都是空闲的。

请你设计一个具备以下功能的内存分配器：

- `Allocator(int n)` 用一个大小为 `n` 的内存数组初始化分配器对象。
- `int allocate(int size, int mID)` 找出大小为 `size` 个连续空闲内存单元且位于 **最左侧** 的块，分配并赋 id `mID`。返回块的第一个下标。如果不存在这样的块，返回 `-1`。
- `int free(int mID)` 释放 id 为 `mID` 的所有内存单元。返回释放的内存单元数目。

**示例：**

```
输入：
["Allocator", "allocate", "allocate", "allocate", "free", "allocate", "allocate", "free", "allocate"]
[[10], [1, 1], [1, 2], [1, 3], [2], [3, 4], [1, 1], [1], [10, 2]]
输出：
[null, 0, 1, 2, 1, 3, 1, 3, -1]
```

**提示：**

- `1 <= n, size, mID <= 1000`
- 最多调用 `allocate` 和 `free` 方法 1000 次

## 解题思路

由于数据规模较小（n, size, mID 均 <= 1000），可以使用数组直接模拟内存。

分配时：从左到右扫描，找到连续 size 个空闲（值为 0）的位置，将其标记为 mID。

释放时：遍历整个数组，将所有值为 mID 的位置清零，统计数量返回。

## Python 代码实现

### 方法一：数组模拟（推荐）

```python
class Allocator:
    def __init__(self, n: int):
        # 内存数组，0 表示空闲，非 0 表示被 mID 占用
        self.memory = [0] * n
        self.n = n

    def allocate(self, size: int, mID: int) -> int:
        # 从左到右找第一个长度为 size 的连续空闲块
        count = 0
        start = -1
        for i in range(self.n):
            if self.memory[i] == 0:
                if count == 0:
                    start = i
                count += 1
                if count == size:
                    # 找到了，标记并返回起始位置
                    for j in range(start, start + size):
                        self.memory[j] = mID
                    return start
            else:
                # 遇到占用单元，重置计数
                count = 0
                start = -1
        return -1

    def free(self, mID: int) -> int:
        # 释放所有 mID 标记的单元
        freed = 0
        for i in range(self.n):
            if self.memory[i] == mID:
                self.memory[i] = 0
                freed += 1
        return freed
```

### 方法二：使用区间列表维护空闲块

```python
class Allocator:
    def __init__(self, n: int):
        # 直接用列表存每个位置的 id
        self.mem = [0] * n
        self.n = n

    def allocate(self, size: int, mID: int) -> int:
        i = 0
        while i <= self.n - size:
            # 检查从 i 开始是否有 size 个连续空闲
            j = i
            while j < i + size and self.mem[j] == 0:
                j += 1
            if j == i + size:
                # 找到连续空闲块
                for k in range(i, i + size):
                    self.mem[k] = mID
                return i
            else:
                # 从下一个非空闲位置继续
                i = j + 1
        return -1

    def free(self, mID: int) -> int:
        count = sum(1 for x in self.mem if x == mID)
        self.mem = [0 if x == mID else x for x in self.mem]
        return count
```

## 复杂度分析

- `allocate` 时间复杂度：O(n)，最坏扫描整个数组
- `free` 时间复杂度：O(n)，遍历整个数组
- 空间复杂度：O(n)，存储内存数组

## 关键点总结

1. 数据规模小（n <= 1000，操作 <= 1000），暴力模拟完全可行
2. 分配时要找"最左侧"的连续空闲块，不能贪心跳跃
3. 释放时要释放所有相同 mID 的单元，不限于一块连续区域

## 易错点

1. 分配时要确保 size 个连续空闲，不能有任何间断
2. 释放时同一 mID 可能分布在多处（因为可以多次 allocate 相同 mID）
3. 返回的是连续块的起始下标，而不是结束下标
