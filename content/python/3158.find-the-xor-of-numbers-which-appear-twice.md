## 题目描述

给你一个数组 `nums`，其中每个数字要么只出现一次，要么恰好出现两次。

返回所有 **出现两次** 的数字的按位异或结果。如果不存在出现两次的数字，返回 0。

**示例 1：**
```
输入：nums = [1,2,1,3]
输出：1
解释：只有 1 出现了两次，返回 1。
```

**示例 2：**
```
输入：nums = [1,2,3]
输出：0
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`
- 每个数字最多出现两次

## 解题思路

用哈希表记录每个数字的出现次数，然后对所有出现两次的数字求异或。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def duplicateNumbersXOR(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        ans = 0
        for x, c in cnt.items():
            if c == 2:
                ans ^= x
        return ans
```

### 方法二：位运算技巧

```python
from typing import List

class Solution:
    def duplicateNumbersXOR(self, nums: List[int]) -> int:
        seen = set()
        ans = 0
        for x in nums:
            if x in seen:
                ans ^= x  # 第二次出现，加入异或
            else:
                seen.add(x)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 只对出现两次的数字做异或
2. 用集合标记已见过的数字

## 易错点

1. 出现一次的数字不参与异或
2. 没有重复数字时返回 0
