## 题目描述

给你一棵 **二叉树** 的根节点 `root`，树中有 `n` 个节点，每个节点都有一个 **不同** 的值，另给你一个长度为 `m` 的数组 `queries`。

你必须在树上执行 `m` 个 **独立** 的查询，其中第 `i` 个查询你需要执行以下操作：

- **删除** 以 `queries[i]` 为根节点的子树。题目所用测试用例保证 `queries[i]` **不等于** 根节点的值。

每次查询都是独立的，相当于每次查询前都恢复原树。

返回一个长度为 `m` 的数组 `answer`，其中 `answer[i]` 是执行第 `i` 个查询后，树的高度。

**提示：**
- 树中节点数目是 `n`。
- `2 <= n <= 10^5`

## 解题思路

**预处理 + DFS：**

对于删除以 `v` 为根的子树后，树的高度 = 不经过 `v` 的最大深度。

**关键观察：** 删除 `v` 的子树后，树的高度 = 从根到叶子的最大路径，且该路径不经过 `v`。

**预处理方法：**
1. 对每一层（深度），记录该层中最大的「本节点到最深叶子的深度」（节点高度）的前两名
2. 对查询节点 `v`（深度为 `d`，高度为 `h`）：
   - 若删除 `v`，同层其他节点贡献的最大高度 = 同层前两高度中不等于 `v` 高度的那个
   - 答案 = `depth[v] + other_height` 和 `depth[v] - 1` 中的最大值（`depth[v] - 1` 是仅保留从根到 v 的父节点的高度）

等等，更准确的处理方式：

答案 = max(「v 所在层的其他节点的高度 + 该节点深度」的最大值, `depth_of_v - 1`（v 的父节点到根的路径高度）)

更简洁：对同一层的节点，按高度排序维护前两名；删除某节点后，取该层其他节点的最大值，加上该层深度再取最大。

## 代码实现

### 方法一：DFS 预处理每层（推荐）

```python
from typing import Optional, List
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def treeQueries(self, root: Optional[TreeNode], queries: List[int]) -> List[int]:
        # 每层维护高度最大的前两个节点
        # node_depth[v] = v 的深度（根为 0）
        # node_height[v] = v 的高度（到最深叶子的距离）
        node_depth = {}
        node_height = {}
        # level_top2[d] = [(h, val), (h2, val2)] 该层高度前两名
        level_top2 = defaultdict(list)

        def dfs(node, depth):
            if not node:
                return -1
            node_depth[node.val] = depth
            left_h = dfs(node.left, depth + 1)
            right_h = dfs(node.right, depth + 1)
            h = 1 + max(left_h, right_h)
            node_height[node.val] = h

            # 维护该层前两大高度
            level = level_top2[depth]
            level.append((h, node.val))
            level.sort(reverse=True)
            if len(level) > 2:
                level.pop()

            return h

        dfs(root, 0)

        ans = []
        for q in queries:
            d = node_depth[q]
            h = node_height[q]
            top2 = level_top2[d]

            # 找同层其他节点的最大高度
            other_h = -1
            for hi, vi in top2:
                if vi != q:
                    other_h = hi
                    break

            # 删除 q 的子树后，树的高度
            # = max(d - 1, d + other_h)（注意 other_h 是相对于该层的，实际高度 d + other_h）
            if other_h == -1:
                result = d - 1
            else:
                result = max(d - 1, d + other_h)

            ans.append(result)

        return ans
```

### 方法二：两次 DFS 预计算

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def treeQueries(self, root: Optional[TreeNode], queries: List[int]) -> List[int]:
        cache = {}

        def height(node):
            if not node:
                return -1
            if node in cache:
                return cache[node]
            h = 1 + max(height(node.left), height(node.right))
            cache[node] = h
            return h

        # ans_map[v] = 删除 v 的子树后的树高度
        ans_map = {}

        def dfs(node, depth, max_without):
            if not node:
                return
            # 删除当前节点后的树高度 = max(已无此子树的最大高度)
            ans_map[node.val] = max_without
            left_h = height(node.left)
            right_h = height(node.right)
            # 递归左子树：右子树贡献 depth + 1 + right_h
            dfs(node.left, depth + 1, max(max_without, depth + 1 + right_h))
            # 递归右子树：左子树贡献 depth + 1 + left_h
            dfs(node.right, depth + 1, max(max_without, depth + 1 + left_h))

        dfs(root, 0, 0)
        return [ans_map[q] for q in queries]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 预处理 | O(n + m) | O(n) |

## 关键点总结

1. 预处理每个节点删除后的树高度，存入哈希表
2. 递归时传入「当前路径上已知的最大高度（不含当前子树）」
3. 利用兄弟子树高度更新传给子节点的参数

## 易错点

- 节点高度 = 到最深叶子的距离（叶子高度为 0）
- 深度从 0 开始（根节点深度为 0）
