## 题目描述

给你一个数组 `towers` 和一个整数 `radius`。

数组 `towers` 中包含一些网络信号发射塔，其中 `towers[i] = [xi, yi, qi]` 表示第 `i` 座塔坐标为 `(xi, yi)`，信号强度为 `qi`。

坐标 `(x, y)` 处的网络质量可由以下公式计算：
- 对于每座信号强度为 `qi`、距离为 `d` 的塔，若 `d <= radius`，则贡献 `floor(qi / (1 + d))`
- 其中 `d = sqrt((xi - x)^2 + (yi - y)^2)` 是欧氏距离

返回网络质量**最大**的整数坐标，如果有多个坐标的网络质量相同，返回**最小的坐标**（先比较 x，再比较 y）。

**提示：**
- `1 <= towers.length <= 50`
- `0 <= xi, yi, qi <= 50`
- `1 <= radius <= 50`

## 解题思路

由于坐标范围有限（0 到 50），可以**暴力枚举**所有整数坐标 `(x, y)`，计算每个坐标的网络质量，取最大值。

搜索空间范围：`x, y` 范围在 `[0, 50]` 以内即可（因为塔的坐标不超过 50，最优点一定在这个范围内）。

## 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List
import math

class Solution:
    def bestCoordinate(self, towers: List[List[int]], radius: int) -> List[int]:
        max_quality = 0
        best = [0, 0]
        
        # 枚举所有整数坐标
        for x in range(51):
            for y in range(51):
                quality = 0
                for tx, ty, tq in towers:
                    d = math.sqrt((tx - x) ** 2 + (ty - y) ** 2)
                    if d <= radius:
                        quality += int(tq / (1 + d))
                
                # 更新最优坐标（相同质量取更小坐标）
                if quality > max_quality:
                    max_quality = quality
                    best = [x, y]
        
        return best
```

### 方法二：限定搜索范围

```python
from typing import List
import math

class Solution:
    def bestCoordinate(self, towers: List[List[int]], radius: int) -> List[int]:
        # 搜索范围：塔坐标的边界
        min_x = min(t[0] for t in towers)
        max_x = max(t[0] for t in towers)
        min_y = min(t[1] for t in towers)
        max_y = max(t[1] for t in towers)
        
        max_quality = 0
        best = [min_x, min_y]
        
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                quality = 0
                for tx, ty, tq in towers:
                    d = math.sqrt((tx - x) ** 2 + (ty - y) ** 2)
                    if d <= radius:
                        quality += int(tq / (1 + d))
                
                if quality > max_quality:
                    max_quality = quality
                    best = [x, y]
        
        return best
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(51 * 51 * m) = O(m) | O(1) |
| 限定范围 | O((max_x-min_x) * (max_y-min_y) * m) | O(1) |

m 为塔的数量。坐标范围和塔数都不超过 50，总操作不超过 51*51*50 ≈ 130000。

## 关键点总结

1. 坐标范围小（0-50），可以暴力枚举所有整数坐标
2. 距离需要用欧氏距离（`math.sqrt`），且需 `<= radius`
3. 信号贡献 `floor(qi / (1 + d))`，用 `int()` 取整
4. 多个坐标质量相同时取最小坐标：按 x 升序外层循环，y 升序内层循环，严格 `>` 更新

## 易错点

- 信号公式中取整是向下取整：`int(tq / (1 + d))`
- 最优坐标更新条件是严格大于（`quality > max_quality`），相同不更新保证最小坐标
- 只有距离 `d <= radius` 的塔才有贡献，超出 radius 的不计入
