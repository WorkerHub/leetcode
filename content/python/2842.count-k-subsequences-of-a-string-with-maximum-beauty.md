## 题目描述

给你一个字符串 `s` 和一个整数 `k`。

**k-子序列**：从 `s` 中选 `k` 个下标 `i1 < i2 < ... < ik`，且 `s[i1], s[i2], ..., s[ik]` 各不相同。

**美丽度**：k-子序列中每个字符 `c` 的频率之和（`c` 在 `s` 中出现的次数，不是子序列中的次数）。

例如 `s = "aabcb"`, 子序列 `"acb"`（下标 0,2,3）的美丽度 = freq('a') + freq('c') + freq('b') = 2+1+2 = 5。

返回使美丽度最大的 k-子序列的数量，对 `10^9 + 7` 取模。

**提示：**
- `1 <= n <= 2 × 10^5`
- `1 <= k <= 26`（最多 26 种不同字符）

## 解题思路

**贪心 + 组合数学：**

1. 统计每个字符的频率，若不同字符数 < k，返回 0
2. 为最大化美丽度，贪心选频率最高的 k 个字符
3. 若恰好有 k 个不同字符，每种只有一种选法，答案乘以各频率（从每种字符选哪一个？每个下标只选一次）
4. 若频率相同的字符有多个，需要用**组合数**计算选法数

**详细：**
- 设频率从高到低排列，若第 k 个字符频率为 `f_k`，有 `cnt` 个字符都有此频率
- 需要从这 `cnt` 个频率为 `f_k` 的字符中选 `need` 个（其余频率更高的字符全选）
- 答案 = `C(cnt, need) × prod(freq[i]^1 for each selected char)`（每种字符有 freq[i] 种选法，选哪个下标）

等等，每种字符有 freq[i] 个位置可以选，选 1 个，有 freq[i] 种选法。

## Python 代码实现

### 方法一：贪心 + 组合数学（推荐）

```python
from collections import Counter
from math import comb
from typing import List

class Solution:
    def countKSubsequencesWithMaxBeauty(self, s: str, k: int) -> int:
        MOD = 10**9 + 7

        freq = Counter(s)
        distinct = len(freq)

        if distinct < k:
            return 0

        # 按频率降序排列
        freqs = sorted(freq.values(), reverse=True)

        # 前 k 个字符（频率最高）的频率乘积 × 组合数
        # 检查第 k 个频率和第 k+1 个频率是否相同
        ans = 1
        threshold = freqs[k - 1]  # 第 k 个的频率（0-indexed: k-1）

        # 统计频率 > threshold 的字符数
        higher_count = sum(1 for f in freqs if f > threshold)
        # 统计频率 == threshold 的字符数
        equal_count = sum(1 for f in freqs if f == threshold)
        # 需要从 equal_count 个中选 k - higher_count 个
        need = k - higher_count

        # 所有频率 > threshold 的字符：各有 freq 种选法
        for f in freqs:
            if f > threshold:
                ans = ans * f % MOD

        # 频率 == threshold 的字符：选 need 个，各有 threshold 种选法
        ans = ans * pow(threshold, need, MOD) % MOD
        # 组合数 C(equal_count, need)
        ans = ans * comb(equal_count, need) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26) = O(n)，统计频率和排序（字符数最多 26）
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 贪心：选频率最高的 k 种字符，最大化美丽度
2. 每种字符有 freq[i] 个位置可选（选哪个下标），选 1 个有 freq[i] 种方法
3. 当多个字符频率相同时，用 `C(equal_count, need)` 计算选法
4. 答案 = 组合数 × 各字符频率之积

## 易错点

1. 区分字符数 < k 的情况（返回 0）
2. 当第 k 个位置有多个频率相同的字符时，需要组合数
3. `comb(n, k)` 在 Python 3.8+ 中可直接使用（math.comb）
4. 答案要对 MOD 取模，但 `math.comb` 返回大整数，乘法后再取模
