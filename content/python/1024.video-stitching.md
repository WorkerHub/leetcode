## 题目描述

你将会获得一系列视频片段，这些片段来自于一项持续时长为 `time` 秒的体育赛事。这些片段可能有所重叠，也可能长度不一。

使用数组 `clips` 描述所有的视频片段，其中 `clips[i] = [starti, endi]` 表示第 `i` 个视频片段开始于 `starti` 并且结束于 `endi`。

返回所需视频片段的最小数目，使得这些片段能够覆盖整个赛事 `[0, time]`。如果无法覆盖整个赛事，则返回 `-1`。

**示例 1：**
```
输入：clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]], time = 10
输出：3
解释：
选中 [0,2], [8,10], [1,9] 这三个片段。
然后，按下面的方案重制比赛片段：
将 [1,9] 再剪辑为 [1,2] + [2,8] + [8,9]。
现在手上有 [0,2] + [2,8] + [8,10]，覆盖了整个比赛[0,10]。
```

**示例 2：**
```
输入：clips = [[0,1],[1,2]], time = 5
输出：-1
解释：无法只用 [0,1] 和 [1,2] 覆盖 [0,5] 的整个过程。
```

**示例 3：**
```
输入：clips = [[0,1],[6,8],[0,2],[5,6],[0,4],[0,3],[6,7],[1,3],[4,7],[1,4],[2,5],[2,6],[3,4],[4,5],[5,7],[6,9]], time = 9
输出：3
解释：可以选择 [0,4], [4,7] 和 [6,9] 这三个片段。
```

**提示：**
- `1 <= clips.length <= 100`
- `0 <= starti <= endi <= 100`
- `1 <= time <= 100`

## 解题思路

这是经典的区间覆盖问题，类似于跳跃游戏。

**贪心策略**：
1. 排序：按起始位置排序
2. 在当前能到达的范围内，选择能延伸最远的片段
3. 重复直到覆盖目标或无法继续

**核心思想**：
- 维护当前已覆盖的右边界
- 在所有起点在边界内的片段中，选择终点最远的

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def videoStitching(self, clips: List[List[int]], time: int) -> int:
        """
        贪心：每次选择能延伸最远的片段
        时间复杂度：O(nlogn)
        空间复杂度：O(1)
        """
        # 按起始位置排序
        clips.sort()
        
        count = 0
        current_end = 0  # 当前覆盖的右边界
        next_end = 0     # 下一次能到达的最远位置
        i = 0
        
        while current_end < time:
            # 在current_end范围内，找能延伸最远的片段
            while i < len(clips) and clips[i][0] <= current_end:
                next_end = max(next_end, clips[i][1])
                i += 1
            
            # 如果无法延伸，返回-1
            if next_end == current_end:
                return -1
            
            # 更新边界，片段数+1
            current_end = next_end
            count += 1
        
        return count
```

### 方法二：动态规划

```python
class Solution:
    def videoStitching(self, clips: List[List[int]], time: int) -> int:
        """
        DP：dp[i]表示覆盖[0,i]所需的最少片段数
        时间复杂度：O(n*time)
        空间复杂度：O(time)
        """
        # dp[i] = 覆盖[0,i]的最少片段数
        dp = [float('inf')] * (time + 1)
        dp[0] = 0
        
        for i in range(1, time + 1):
            # 尝试所有能覆盖到i的片段
            for start, end in clips:
                if start <= i <= end:
                    # 从[0, start]的基础上加一个片段
                    dp[i] = min(dp[i], dp[start] + 1)
        
        return dp[time] if dp[time] != float('inf') else -1
```

### 方法三：优化的贪心

```python
class Solution:
    def videoStitching(self, clips: List[List[int]], time: int) -> int:
        """
        预处理 + 贪心
        maxEnd[i] = 所有起点<=i的片段中，最大的终点
        """
        # 预处理：对每个起点，记录最大终点
        max_end = [0] * 101
        for start, end in clips:
            max_end[start] = max(max_end[start], end)
        
        count = 0
        current_end = 0
        next_end = 0
        
        for i in range(time + 1):
            # 更新next_end
            if i <= current_end:
                next_end = max(next_end, max_end[i])
            
            # 到达current_end，必须选择片段
            if i == current_end:
                if next_end == current_end:
                    return -1
                current_end = next_end
                count += 1
        
        return count
```

### 方法四：详细注释版

```python
class Solution:
    def videoStitching(self, clips: List[List[int]], time: int) -> int:
        """
        贪心算法详解
        
        思路：
        1. 排序后从左到右扫描
        2. 维护已覆盖区间[0, current_end]
        3. 在所有start <= current_end的片段中
           选择end最大的一个
        4. 重复直到覆盖[0, time]
        """
        # 按起始位置排序
        clips.sort(key=lambda x: (x[0], -x[1]))
        
        n = len(clips)
        result = 0
        current_end = 0
        next_end = 0
        i = 0
        
        while current_end < time:
            # 找所有能接上current_end的片段中
            # 延伸最远的一个
            while i < n and clips[i][0] <= current_end:
                next_end = max(next_end, clips[i][1])
                i += 1
            
            # 如果没有片段能接上，无解
            if next_end == current_end:
                return -1
            
            # 选择这个片段
            current_end = next_end
            result += 1
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（贪心） | O(n log n) | O(1) |
| 方法二（DP） | O(n × time) | O(time) |
| 方法三（优化贪心） | O(n + time) | O(1) |

## 图解示例

以 `clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]], time = 10` 为例：

```
排序后: [0,2], [1,5], [1,9], [4,6], [5,9], [8,10]

初始: current_end=0, next_end=0, count=0

第1轮: 找start<=0的片段
  [0,2]: next_end=2
  选择[0,2], current_end=2, count=1

第2轮: 找start<=2的片段
  [1,5]: next_end=5
  [1,9]: next_end=9
  选择[1,9], current_end=9, count=2

第3轮: 找start<=9的片段
  [4,6]: next_end不变(9)
  [5,9]: next_end不变(9)
  [8,10]: next_end=10
  选择[8,10], current_end=10, count=3

current_end >= time, 返回3
```

## 关键点总结

1. **贪心选择**：在能接上的片段中选延伸最远的
2. **排序预处理**：按起始位置排序简化处理
3. **双指针维护**：current_end和next_end
4. **无解判断**：next_end无法延伸时返回-1
5. **边界条件**：必须从0开始才能覆盖

## 易错点

1. **起点检查**：如果没有从0开始的片段，无解
2. **无法延伸**：next_end==current_end表示无法继续
3. **重复片段**：可能有多个片段起点相同
4. **排序依据**：按起点排序，起点相同按终点
5. **边界覆盖**：要覆盖到time，不是time-1
