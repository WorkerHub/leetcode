## 题目描述

多项式链表是一种特殊形式的链表，每个节点表示多项式的一项，节点包含两个属性：
- `coefficient`：该项的系数
- `power`：该项的指数

链表按指数**降序**排列，每个指数对应的系数非零。

给你两个多项式链表的头节点 `poly1` 和 `poly2`，返回它们的和，用链表表示。

**示例：**
```
输入：poly1 = [(1,1)], poly2 = [(1,0)]
输出：[(1,1),(1,0)]
解释：x + 1
```

## 解题思路

类似**归并两个有序链表**，但比较的是指数（降序）：
- 若两个指数相同，系数相加；若和为 0 则跳过（不加入结果）
- 若指数不同，取指数更大的节点加入结果

## 代码实现

### 方法一：双指针归并（推荐）

```python
class PolyNode:
    def __init__(self, x=0, y=0, next=None):
        self.coefficient = x
        self.power = y
        self.next = next

class Solution:
    def addPoly(self, poly1: PolyNode, poly2: PolyNode) -> PolyNode:
        dummy = PolyNode()  # 哑头节点
        curr = dummy
        
        p1, p2 = poly1, poly2
        
        while p1 and p2:
            if p1.power > p2.power:
                # p1 的指数更大，直接加入结果
                curr.next = PolyNode(p1.coefficient, p1.power)
                p1 = p1.next
            elif p1.power < p2.power:
                # p2 的指数更大
                curr.next = PolyNode(p2.coefficient, p2.power)
                p2 = p2.next
            else:
                # 指数相同，系数相加
                coeff_sum = p1.coefficient + p2.coefficient
                if coeff_sum != 0:
                    curr.next = PolyNode(coeff_sum, p1.power)
                    curr = curr.next
                p1 = p1.next
                p2 = p2.next
                continue  # 跳过 curr = curr.next，已在上面处理
            
            curr = curr.next
        
        # 处理剩余部分
        curr.next = p1 if p1 else p2
        
        return dummy.next
```

### 方法二：哈希表合并

```python
from collections import defaultdict

class Solution:
    def addPoly(self, poly1: PolyNode, poly2: PolyNode) -> PolyNode:
        coeffs = defaultdict(int)
        
        # 遍历两个链表，按指数合并系数
        node = poly1
        while node:
            coeffs[node.power] += node.coefficient
            node = node.next
        
        node = poly2
        while node:
            coeffs[node.power] += node.coefficient
            node = node.next
        
        # 按指数降序构建结果链表
        dummy = PolyNode()
        curr = dummy
        for power in sorted(coeffs.keys(), reverse=True):
            if coeffs[power] != 0:
                curr.next = PolyNode(coeffs[power], power)
                curr = curr.next
        
        return dummy.next
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(m + n) | O(1)（不含结果） |
| 哈希表 | O((m+n) log(m+n)) | O(m+n) |

## 关键点总结

1. 按指数降序归并，类似有序链表合并
2. 指数相同时系数相加，若和为 0 则不加入结果链表
3. 双指针方法空间效率更高
4. 哑头节点简化链表操作

## 易错点

- 系数相加为 0 时跳过，不加入结果链表
- 处理完相同指数后，p1 和 p2 都要前移
- 最后剩余的一个链表直接接到结果后面
