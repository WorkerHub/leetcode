## 题目描述

给你一个下标从 0 开始的字符串数组 `words` 和一个下标从 0 开始的二进制数组 `groups`，两个数组长度均为 `n`。

你需要从下标 `[0, 1, ..., n-1]` 中选出一个 **最长子序列**，使得对于子序列中相邻的两个下标 `i < j`，满足：
- `groups[i] != groups[j]`
- `words[i]` 和 `words[j]` 长度相同
- `words[i]` 和 `words[j]` 的汉明距离恰好为 1

返回满足条件的最长子序列对应的 `words` 数组（如果有多个答案，返回任意一个）。

**示例 1：**
```
输入：words = ["bab","dab","cab"], groups = [1,2,1]
输出：["bab","cab"]
```

**示例 2：**
```
输入：words = ["a","b","c","d"], groups = [1,2,3,4]
输出：["a","b","c","d"] 或其他长度4的答案
```

**提示：**
- `1 <= n <= 1000`
- `1 <= words[i].length <= 10`
- `1 <= groups[i] <= n`
- `words` 中所有字符串长度相同
- `words[i]` 只包含小写英文字母

## 解题思路

使用动态规划求解最长子序列。

定义 `dp[i]` 为以第 `i` 个单词结尾的满足条件的最长子序列长度，同时记录前驱下标以便回溯路径。

对于每对下标 `(j, i)`（j < i），若满足以下所有条件则可转移：
1. `groups[j] != groups[i]`
2. `len(words[j]) == len(words[i])`
3. `hamming_distance(words[j], words[i]) == 1`

最终从 `dp` 最大值对应位置回溯得到路径。

## Python 代码实现

### 方法一：动态规划 + 回溯路径（推荐）

```python
from typing import List

class Solution:
    def getWordsInLongestSubsequence(self, words: List[str], groups: List[int]) -> List[str]:
        n = len(words)

        def hamming_distance(s1: str, s2: str) -> int:
            # 计算两个等长字符串的汉明距离
            if len(s1) != len(s2):
                return float('inf')
            return sum(c1 != c2 for c1, c2 in zip(s1, s2))

        # dp[i] 表示以第 i 个单词结尾的最长子序列长度
        dp = [1] * n
        # prev[i] 记录第 i 个单词的前驱下标，-1 表示无前驱
        prev = [-1] * n

        for i in range(1, n):
            for j in range(i):
                # 检查三个条件
                if (groups[j] != groups[i] and
                        len(words[j]) == len(words[i]) and
                        hamming_distance(words[j], words[i]) == 1):
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
                        prev[i] = j

        # 找到最长子序列的末尾下标
        best_idx = max(range(n), key=lambda x: dp[x])

        # 回溯构建答案
        result = []
        idx = best_idx
        while idx != -1:
            result.append(words[idx])
            idx = prev[idx]

        result.reverse()
        return result
```

### 方法二：暴力枚举（便于理解）

```python
from typing import List

class Solution:
    def getWordsInLongestSubsequence(self, words: List[str], groups: List[int]) -> List[str]:
        n = len(words)

        def check(i: int, j: int) -> bool:
            # 检查 i, j 是否满足相邻条件
            if groups[i] == groups[j]:
                return False
            if len(words[i]) != len(words[j]):
                return False
            diff = 0
            for a, b in zip(words[i], words[j]):
                if a != b:
                    diff += 1
                if diff > 1:
                    return False
            return diff == 1

        dp = [1] * n
        prev = [-1] * n

        for i in range(n):
            for j in range(i):
                if check(j, i) and dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    prev[i] = j

        best = max(range(n), key=lambda x: dp[x])
        path = []
        while best != -1:
            path.append(words[best])
            best = prev[best]
        return path[::-1]
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为单词数，L 为单词长度，每对单词计算汉明距离需要 O(L)
- 空间复杂度：O(n)，存储 dp 和 prev 数组

## 关键点总结

1. 动态规划状态设计：`dp[i]` 表示以下标 i 结尾的最长合法子序列长度
2. 转移条件需同时满足三个约束：groups 不同、长度相同、汉明距离为 1
3. 使用 `prev` 数组记录路径，方便回溯还原具体方案
4. 汉明距离计算可以提前终止（diff > 1 时直接返回）

## 易错点

1. 汉明距离必须恰好为 1，不能是 0（相同）也不能大于 1
2. 两个字符串长度不同时汉明距离无意义，需先判断长度
3. 回溯路径后需要 reverse，因为是从末尾往前追踪
