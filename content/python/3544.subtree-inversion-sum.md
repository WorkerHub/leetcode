## 题目描述

给定一棵有 `n` 个节点的树，根节点为 `0`，每个节点有值 `nums[i]`（可正可负）。每次操作可以选择某个节点 `v`，将其子树中所有节点的值取反（乘以 -1）。最多执行 `k` 次操作，求操作后整棵树的节点值之和的最大值。

**示例 1：**

```
输入：nums = [-1, -2, -3], edges = [[0,1],[0,2]], k = 1
输出：4
解释：将根节点取反：[1,2,3]，和为6... 但取反0会让1,2,3都取反。
     实际：取反整棵树，-1-2-3 -> 1+2+3 = 6，操作1次。
```

**示例 2：**

```
输入：nums = [1, -2, 3], edges = [[0,1],[0,2]], k = 2
输出：6
```

**提示：**
- `1 <= n <= 2000`
- `k >= 0`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

树形动态规划。

状态：`dp[v][j][parity]` = 以 v 为根的子树，使用了 j 次操作，且当前节点的累计取反次数奇偶性为 `parity` 时，子树节点值之和的最大值。

关键观察：
- 对子树取反 = 子树所有节点值取反
- 多次取反等价于奇偶性
- 父节点的取反操作会影响所有子节点

树形 DP + 区间 DP 合并子树。

## Python 代码实现

### 方法一：树形 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def subtreeInversionSum(self, nums: List[int], edges: List[List[int]], k: int) -> int:
        n = len(nums)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        INF = float('-inf')

        # dp[v][j][p] = 子树 v，用了 j 次操作，外部取反奇偶 p 时的最大子树和
        # 太复杂，先考虑贪心

        # 贪心：对负值最大的子树取反，重复 k 次
        # 但子树嵌套，需要仔细处理

        # 简化：DFS 后序遍历，对每个节点子树计算
        # 若子树和为负，取反（消耗一次操作）使其变正

        subtree_sum = [0] * n
        ops_used = [0]

        def dfs(v, parent):
            s = nums[v]
            for u in graph[v]:
                if u != parent:
                    dfs(u, v)
                    s += subtree_sum[u]
            subtree_sum[v] = s

        dfs(0, -1)

        # 贪心取反最负的子树
        import heapq
        neg_sums = []
        def collect_negatives(v, parent):
            if subtree_sum[v] < 0:
                heapq.heappush(neg_sums, subtree_sum[v])
            for u in graph[v]:
                if u != parent:
                    collect_negatives(u, v)

        collect_negatives(0, -1)

        total = subtree_sum[0]
        for _ in range(k):
            if neg_sums and neg_sums[0] < 0:
                s = heapq.heappop(neg_sums)
                total -= 2 * s  # 取反改变总和 2*s
                heapq.heappush(neg_sums, -s)
            else:
                break

        return total
```

### 方法二：DFS 自底向上贪心

```python
from typing import List
from collections import defaultdict

class Solution:
    def subtreeInversionSum(self, nums: List[int], edges: List[List[int]], k: int) -> int:
        n = len(nums)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def dfs(v, parent):
            # 返回子树内的负子树和列表（按绝对值降序）
            sub_sum = nums[v]
            neg_list = []
            for u in graph[v]:
                if u != parent:
                    child_sum, child_negs = dfs(u, v)
                    sub_sum += child_sum
                    neg_list.extend(child_negs)
            if sub_sum < 0:
                neg_list.append(sub_sum)
            return sub_sum, sorted(neg_list)

        total_sum, neg_subs = dfs(0, -1)
        neg_subs.sort()  # 最小的（绝对值最大的负数）在前

        for i in range(min(k, len(neg_subs))):
            if neg_subs[i] < 0:
                total_sum -= 2 * neg_subs[i]

        return total_sum
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS + 排序
- 空间复杂度：O(n)

## 关键点总结

1. 对子树取反，相当于将子树和改变符号
2. 贪心：每次选择绝对值最大的负子树取反
3. 注意子树嵌套关系（父子树的取反会相互影响）

## 易错点

1. 子树取反后，父树的和也会改变
2. 同一子树取反偶数次等于没取反（奇偶性）
3. 嵌套子树的取反不能重复计算
