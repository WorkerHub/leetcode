## 题目描述

给你一个二维整数数组 `squares`，其中 `squares[i] = [xi, yi, li]` 表示一个正方形，左下角为 `(xi, yi)`，边长为 `li`。

找一条水平线 `y = h`，使得水平线上方和下方的正方形**总面积**相等。

返回满足条件的最小 `h`（可以是小数）。

**示例 1：**

```
输入：squares = [[0,0,1],[1,1,1]]
输出：1.00000
解释：y=1 时，上方面积 = 1（第二个正方形），下方面积 = 1（第一个正方形）
```

**示例 2：**

```
输入：squares = [[0,0,2],[1,1,1]]
输出：1.16667
```

**提示：**
- `1 <= squares.length <= 10^5`
- `squares[i].length == 3`
- `0 <= xi, yi <= 10^9`
- `1 <= li <= 10^9`

## 解题思路

二分答案 `h`：

对给定的水平线 `y = h`，计算：
- 上方面积 = 所有正方形中 y > h 的部分面积之和
- 下方面积 = 所有正方形中 y <= h 的部分面积之和

这是一个关于 h 的单调函数，可以二分。

计算每个正方形在 h 处的切割：
- 若 `yi >= h`：整个正方形在上方，上方面积 += l^2
- 若 `yi + li <= h`：整个正方形在下方，下方面积 += l^2
- 否则：正方形被切割，下方高度 = h - yi，下方面积 += l * (h - yi)

## Python 代码实现

### 方法一：二分浮点数（推荐）

```python
from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        # 计算总面积
        total_area = sum(l * l for _, _, l in squares)

        def below_area(h):
            """y <= h 的总面积"""
            area = 0.0
            for x, y, l in squares:
                if y + l <= h:
                    # 整个正方形在下方
                    area += l * l
                elif y < h:
                    # 部分在下方
                    area += l * (h - y)
            return area

        # 二分：找最小 h 使得下方面积 >= 总面积 / 2
        target = total_area / 2

        lo = min(y for _, y, _ in squares)
        hi = max(y + l for _, y, l in squares)

        for _ in range(100):  # 精度足够
            mid = (lo + hi) / 2
            if below_area(mid) >= target:
                hi = mid
            else:
                lo = mid

        return lo
```

### 方法二：解析精确二分（避免浮点误差）

```python
from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        total = sum(l * l for _, _, l in squares)
        half = total / 2

        # 收集所有关键 y 坐标（正方形的上下边界）
        events = sorted(set(y for _, y, _ in squares) | set(y + l for _, y, l in squares))

        # 对每个区间 [events[i], events[i+1]]，计算在该区间内的面积增量
        # 下方面积是 h 的分段线性函数

        # 从 lo 到 hi 二分
        lo = float(events[0])
        hi = float(events[-1])

        def below(h):
            a = 0.0
            for x, y, l in squares:
                top = y + l
                if top <= h:
                    a += l * l
                elif y < h:
                    a += l * (h - y)
            return a

        for _ in range(200):
            mid = (lo + hi) / 2
            if below(mid) < half:
                lo = mid
            else:
                hi = mid

        return (lo + hi) / 2
```

## 复杂度分析

- 时间复杂度：O(n * iterations)，iterations = 100 或 200
- 空间复杂度：O(1)

## 关键点总结

1. 二分水平线高度 h，函数 `below_area(h)` 关于 h 单调不减
2. 找最小 h 使得下方面积 >= 总面积 / 2
3. 二分精度足够时（100-200 次迭代），误差 < 10^-6

## 易错点

1. 总面积用整数计算避免精度问题，目标值为浮点数
2. 二分范围：最低边界到最高边界
3. `below_area` 是分段线性函数，连续且单调
