## 题目描述

在 RGB 颜色空间中，颜色由三个十六进制数字表示，每个数字从 00 到 FF，分别表示红色、绿色和蓝色。

例如，"#09af00" 表示红色为 09，绿色为 af，蓝色为 00。

类似颜色是指每个分量的十六进制数字都相同的颜色。例如，"#aabbcc" 是类似颜色，但 "#abcdef" 不是。

给你一个字符串 color 表示一个 RGB 颜色，请你找出与它最相似的类似颜色，并以字符串形式返回。

如果有多个最相似的类似颜色，返回任何一个即可。

**示例 1:**
```
输入: color = "#09f166"
输出: "#11ee66"
解释: 
红色: 09 -> 11
绿色: f1 -> ee
蓝色: 66 -> 66
```

**示例 2:**
```
输入: color = "#4e3fe1"
输出: "#5544dd"
解释:
红色: 4e -> 55
绿色: 3f -> 44
蓝色: e1 -> dd
```

**提示:**
- color.length == 7
- color[0] == '#'
- 对于 i > 0，color[i] 是 0 到 9 或者 a 到 f 中的一个十六进制数字

## 解题思路

这是一道数学和字符串处理问题。核心思想是：**对于每个颜色分量，在所有类似颜色值中找到最接近的那个**。

### 核心观察

1. **类似颜色的定义**：每个分量的两位十六进制数字相同，如 "00", "11", "22", ..., "ff"
2. **候选值**：对于任意十六进制分量，候选的类似颜色值只有 17 个："00", "11", "22", ..., "ee", "ff"
3. **距离计算**：需要找到与给定值差值最小的候选值

### 算法流程

1. 将输入颜色的三个分量分别提取出来（去掉 '#'）
2. 对于每个分量：
   - 将两位十六进制数转换为十进制数
   - 在所有类似颜色值（0x00, 0x11, 0x22, ..., 0xff）中找到最接近的
   - 转换回十六进制格式
3. 拼接三个分量，返回结果

### 关键技巧

对于一个十六进制数 xy，最接近的类似颜色是 xx 还是 yy？
- 将 xy 转换为十进制，除以 17（因为 0x11 = 17）
- 四舍五入后乘以 17，就得到最接近的值
- 例如：0x4e = 78，78 / 17 = 4.58，round(4.58) = 5，5 * 17 = 85 = 0x55

## Python 代码实现

### 方法一：数学计算（推荐）

```python
class Solution:
    def similarRGB(self, color: str) -> str:
        def find_similar(component: str) -> str:
            """找到最接近的类似颜色分量"""
            # 将十六进制字符串转换为十进制数
            value = int(component, 16)
            
            # 除以 17 并四舍五入，得到最接近的倍数
            # 0x11 = 17, 0x22 = 34, ..., 0xff = 255
            nearest = round(value / 17) * 17
            
            # 转换回两位十六进制字符串（小写）
            return f"{nearest:02x}"
        
        # 提取三个颜色分量
        r = color[1:3]  # 红色
        g = color[3:5]  # 绿色
        b = color[5:7]  # 蓝色
        
        # 分别找到最相似的类似颜色
        return f"#{find_similar(r)}{find_similar(g)}{find_similar(b)}"
```

### 方法二：枚举所有候选值

```python
class Solution:
    def similarRGB(self, color: str) -> str:
        def find_similar(component: str) -> str:
            """通过枚举找到最接近的类似颜色分量"""
            value = int(component, 16)
            min_diff = float('inf')
            result = "00"
            
            # 枚举所有类似颜色值：00, 11, 22, ..., ff
            for i in range(16):
                # 类似颜色的值：i * 17（因为 0x11 = 17）
                candidate = i * 17
                diff = abs(candidate - value)
                
                if diff < min_diff:
                    min_diff = diff
                    result = f"{candidate:02x}"
            
            return result
        
        r = color[1:3]
        g = color[3:5]
        b = color[5:7]
        
        return f"#{find_similar(r)}{find_similar(g)}{find_similar(b)}"
```

### 方法三：位运算优化

```python
class Solution:
    def similarRGB(self, color: str) -> str:
        def find_similar(component: str) -> str:
            """使用位运算找到最接近的类似颜色分量"""
            value = int(component, 16)
            
            # 计算商和余数
            q, r = divmod(value, 17)
            
            # 如果余数大于 8，向上取整；否则向下取整
            if r > 8:
                q += 1
            
            # 确保不超过 15（0xff）
            q = min(q, 15)
            
            return f"{q * 17:02x}"
        
        return f"#{find_similar(color[1:3])}{find_similar(color[3:5])}{find_similar(color[5:7])}"
```

### 方法四：Python 一行流

```python
class Solution:
    def similarRGB(self, color: str) -> str:
        return '#' + ''.join(
            f"{round(int(color[i:i+2], 16) / 17) * 17:02x}" 
            for i in range(1, 7, 2)
        )
```

## 复杂度分析

### 方法一、三、四：数学计算
- **时间复杂度**：O(1)，只需要处理 3 个颜色分量，每个分量的计算是常数时间
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法二：枚举候选值
- **时间复杂度**：O(1)，虽然有循环，但只循环 16 次（常数），总体仍是 O(1)
- **空间复杂度**：O(1)

## 图解示例

以 color = "#09f166" 为例：

```
输入：#09f166

分解：
  R: 09 (十进制 9)
  G: f1 (十进制 241)
  B: 66 (十进制 102)

计算最接近的类似颜色：
  R: 9 / 17 = 0.53 -> round(0.53) = 1 -> 1 * 17 = 17 = 0x11
  G: 241 / 17 = 14.18 -> round(14.18) = 14 -> 14 * 17 = 238 = 0xee
  B: 102 / 17 = 6.00 -> round(6.00) = 6 -> 6 * 17 = 102 = 0x66

输出：#11ee66

候选值对比（绿色分量 f1 = 241）：
  ...
  0xcc = 204, diff = 37
  0xdd = 221, diff = 20
  0xee = 238, diff = 3  ← 最小
  0xff = 255, diff = 14
```

## 关键点总结

1. **类似颜色的数学特征**：所有类似颜色值都是 17 的倍数（0x11 = 17）
2. **四舍五入技巧**：通过除以 17 再四舍五入，可以快速找到最接近的倍数
3. **十六进制转换**：熟练使用 `int(s, 16)` 和 `f"{n:02x}"` 进行进制转换
4. **字符串处理**：正确提取颜色分量 color[1:3], color[3:5], color[5:7]
5. **独立性**：三个颜色分量的计算是独立的，可以分别处理

## 易错点

1. **索引错误**：记得跳过第一个字符 '#'，从索引 1 开始提取颜色分量
2. **进制转换**：int(component, 16) 的第二个参数 16 不能忘记
3. **格式化输出**：使用 f"{n:02x}" 确保输出两位小写十六进制数，不足补 0
4. **四舍五入**：Python 的 round() 在 .5 时采用"银行家舍入"，但本题影响不大
5. **边界情况**：当值为 0xff 时，不能向上取整到 0x100，要限制在 15 * 17 = 255
