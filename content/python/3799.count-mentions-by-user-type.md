## 题目描述

社交网络中，用户可以有三种身份类型：`"ALL"`（所有人）、`"HERE"`（当前在线用户）和具体用户 ID。给定事件列表 `events`，每个事件格式为 `[timestamp, message_type, mentioned_users]`，其中 `message_type` 决定了该消息被谁看到：
- `"ALL"`：所有用户都被提及
- `"HERE"`：所有当前在线的用户被提及
- 具体 ID：只有该 ID 用户被提及

同时有另一类事件 `"OFFLINE"`，表示某用户下线，持续一段时间后重新上线。

返回每个用户被提及的次数。

**示例 1：**
```
输入：numberOfUsers = 2, events = [["MESSAGE","10","id0 id1"],["OFFLINE","11","0"],["MESSAGE","71","HERE"]]
输出：[2,1]
解释：时刻 10，id0 和 id1 各被提及 1 次；时刻 71，用户 0 还未上线（需等到 11+60=71 时刻重新上线，恰好还是不在），用户 1 被提及。
```

**提示：**
- `1 <= numberOfUsers <= 100`
- `1 <= events.length <= 100`
- 每个事件均有效

## 解题思路

**模拟 + 排序：**

1. 按时间戳排序事件
2. 维护每个用户的下线结束时间 `offline_until[user_id]`
3. 处理每个事件：
   - `MESSAGE ALL`：所有用户计数 +1
   - `MESSAGE HERE`：当前在线用户（`offline_until[i] <= current_time`）计数 +1
   - `MESSAGE id_list`：指定用户计数 +1
   - `OFFLINE user_id duration`：设置 `offline_until[user_id] = current_time + 60`

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def countMentions(self, numberOfUsers: int, events: List[List[str]]) -> List[int]:
        # 按时间戳排序，时间相同时 OFFLINE 事件先处理
        events.sort(key=lambda e: (int(e[1]), 0 if e[0] == "OFFLINE" else 1))

        mentions = [0] * numberOfUsers
        offline_until = [0] * numberOfUsers  # 用户下线结束时间（0 表示在线）

        for event in events:
            etype, timestamp, data = event[0], int(event[1]), event[2]

            if etype == "MESSAGE":
                if data == "ALL":
                    # 所有用户被提及
                    for i in range(numberOfUsers):
                        mentions[i] += 1
                elif data == "HERE":
                    # 当前在线用户被提及
                    for i in range(numberOfUsers):
                        if offline_until[i] <= timestamp:
                            mentions[i] += 1
                else:
                    # 具体用户列表："id0 id3 id5"
                    for uid_str in data.split():
                        uid = int(uid_str[2:])  # 去掉 "id" 前缀
                        if 0 <= uid < numberOfUsers:
                            mentions[uid] += 1

            elif etype == "OFFLINE":
                uid = int(data)
                if 0 <= uid < numberOfUsers:
                    offline_until[uid] = timestamp + 60

        return mentions
```

### 方法二：分类处理 + 集合

```python
from typing import List

class Solution:
    def countMentions(self, numberOfUsers: int, events: List[List[str]]) -> List[int]:
        # 按时间戳排序
        sorted_events = sorted(events, key=lambda e: (int(e[1]), e[0] != "OFFLINE"))

        mentions = [0] * numberOfUsers
        offline_until = {}  # user_id -> 重新上线时间

        for etype, ts_str, data in sorted_events:
            ts = int(ts_str)

            if etype == "OFFLINE":
                uid = int(data)
                offline_until[uid] = ts + 60

            elif etype == "MESSAGE":
                if data == "ALL":
                    for i in range(numberOfUsers):
                        mentions[i] += 1
                elif data == "HERE":
                    for i in range(numberOfUsers):
                        if offline_until.get(i, 0) <= ts:
                            mentions[i] += 1
                else:
                    for uid_str in data.split():
                        uid = int(uid_str[2:])
                        mentions[uid] += 1

        return mentions
```

## 复杂度分析

- 时间复杂度：O(E * N)，E 为事件数，N 为用户数
- 空间复杂度：O(N)，存储下线时间

## 关键点总结

1. 事件按时间戳排序，相同时间 OFFLINE 先处理
2. 维护每个用户的下线结束时间
3. `HERE` 消息只通知当前在线用户（`offline_until <= timestamp`）
4. 下线持续时间固定为 60 单位

## 易错点

1. 相同时间戳时，OFFLINE 事件应先于 MESSAGE 处理
2. 用户 ID 格式为 `"id0"`, `"id1"` 等，需解析数字部分
3. 下线 60 单位后重新上线，在恰好 60 单位时是否在线需根据题意确认
