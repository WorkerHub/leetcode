## 题目描述

给你两个**非负**整数 `num1` 和 `num2`。

每一步中，若 `num1 >= num2`，则 `num1 -= num2`；否则 `num2 -= num1`。

重复上述操作，直到其中一个数变为 0。

返回操作次数。

**示例 1：**
```
输入：num1 = 2, num2 = 3
输出：3
解释：
- num1 (2) < num2 (3)：num2 -= num1 -> num2 = 1（1次）
- num1 (2) > num2 (1)：num1 -= num2 -> num1 = 1（2次）
- num1 (1) == num2 (1)：num1 -= num2 -> num1 = 0（3次）
```

**提示：**
- `0 <= num1, num2 <= 10^6`

## 解题思路

**直接模拟**（或利用 GCD 优化）

直接按题意模拟，每步减法。

**优化：** 若 `num1 >= num2`，则连续减 `num1 // num2` 次，相当于 `num1 % num2`，操作次数增加 `num1 // num2`。这类似欧几里得算法，时间复杂度降至 O(log(min(num1, num2)))。

## 代码实现

### 方法一：直接模拟

```python
class Solution:
    def countOperations(self, num1: int, num2: int) -> int:
        ops = 0
        while num1 != 0 and num2 != 0:
            if num1 >= num2:
                num1 -= num2
            else:
                num2 -= num1
            ops += 1
        return ops
```

### 方法二：类 GCD 优化（推荐）

```python
class Solution:
    def countOperations(self, num1: int, num2: int) -> int:
        ops = 0
        while num1 != 0 and num2 != 0:
            if num1 >= num2:
                ops += num1 // num2  # 一次性减多次
                num1 %= num2
            else:
                ops += num2 // num1
                num2 %= num1
        return ops
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接模拟 | O(num1 + num2) | O(1) |
| GCD 优化 | O(log(min(num1, num2))) | O(1) |

## 关键点总结

1. 直接模拟逻辑简单，但在极端情况下（如 num1=1, num2=10^6）很慢。
2. 类 GCD 优化：批量减法，每次操作将两数中的较大值变为取模结果。
3. GCD 优化后，每两步至少将最大值减半，总步数 O(log)。

## 易错点

- 终止条件：其中一个为 0 时停止。
- GCD 优化时，`num1 %= num2` 后可能 `num1 = 0`，直接结束。
