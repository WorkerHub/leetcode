## 题目描述

给你一个整数数组 `nums`，选择四个**不同**下标 `w, x, y, z`，使乘积差 `(nums[w] * nums[x]) - (nums[y] * nums[z])` 最大化。

返回所能得到的最大乘积差。

**示例 1：**
```
输入：nums = [5, 6, 2, 7, 4]
输出：34
解释：选 w=1, x=3, y=2, z=4，乘积差 = (6*7) - (2*4) = 42 - 8 = 34
```

**示例 2：**
```
输入：nums = [4, 2, 5, 9, 7, 4, 8]
输出：64
解释：选最大两个数 9,8 和最小两个数 2,4，乘积差 = 72 - 8 = 64
```

**提示：**
- `4 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`

---

## 解题思路

### 核心思想：贪心 - 最大两数乘积减最小两数乘积

要使乘积差最大：
- `nums[w] * nums[x]` 应尽量大 → 选数组中**最大的两个数**
- `nums[y] * nums[z]` 应尽量小 → 选数组中**最小的两个数**

直接排序后取两端即可。

---

## 代码实现

### 方法一：排序（推荐）

```python
from typing import List

class Solution:
    def maxProductDifference(self, nums: List[int]) -> int:
        # 排序后最大两数在末尾，最小两数在开头
        nums.sort()
        n = len(nums)
        # 最大两数乘积 - 最小两数乘积
        return nums[n - 1] * nums[n - 2] - nums[0] * nums[1]
```

### 方法二：线性扫描找极值（O(n) 无需排序）

```python
from typing import List

class Solution:
    def maxProductDifference(self, nums: List[int]) -> int:
        # 用四个变量记录最大、第二大、最小、第二小
        max1 = max2 = 0          # 最大、第二大
        min1 = min2 = float('inf')  # 最小、第二小

        for x in nums:
            # 更新最大和第二大
            if x >= max1:
                max2 = max1
                max1 = x
            elif x > max2:
                max2 = x

            # 更新最小和第二小
            if x <= min1:
                min2 = min1
                min1 = x
            elif x < min2:
                min2 = x

        return max1 * max2 - min1 * min2
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（排序） | O(n log n) | O(1) |
| 方法二（线性） | O(n) | O(1) |

## 关键点总结

1. 贪心思路：最大乘积差 = 最大两数乘积 - 最小两数乘积
2. 四个下标必须不同，但找最大两数和最小两数时自然满足（数组长度 >= 4）
3. O(n) 线性扫描更优，但排序写法更简洁

---

## 易错点

- 注意是四个**不同下标**，但当数组中有重复值时，只要下标不同即可
- `nums[n-1] * nums[n-2]` 不是最大元素的平方，是最大和第二大
