## 题目描述

网站域名 `"discuss.leetcode.com"` 由多个子域名组成。顶级域名为 `"com"`，二级域名为 `"leetcode.com"`，最低一级为 `"discuss.leetcode.com"`。当访问域名 `"discuss.leetcode.com"` 时，同时也会隐式访问其父域名 `"leetcode.com"` 以及 `"com"`。

**计数配对域名** 是遵循 `"rep d1.d2.d3"` 或 `"rep d1.d2"` 格式的一个域名表示，其中 `rep` 表示访问域名的次数，`d1.d2.d3` 为域名本身。

给你一个 **计数配对域名** 组成的数组 `cpdomains`，解析得到输入中每个子域名对应的 **计数配对域名**，并以数组形式返回。可以按 **任意顺序** 返回答案。

**示例 1:**
```
输入: cpdomains = ["9001 discuss.leetcode.com"]
输出: ["9001 leetcode.com","9001 discuss.leetcode.com","9001 com"]
解释: 例子中仅包含一个网站域名："discuss.leetcode.com"。
按照前文描述，子域名 "leetcode.com" 和 "com" 都会被访问，所以它们都被访问了 9001 次。
```

**示例 2:**
```
输入: cpdomains = ["900 google.mail.com", "50 yahoo.com", "1 intel.mail.com", "5 wiki.org"]
输出: ["901 mail.com","50 yahoo.com","900 google.mail.com","5 wiki.org","5 org","1 intel.mail.com","951 com"]
解释: 按照前文描述，会访问 "google.mail.com" 900 次，"yahoo.com" 50 次，"intel.mail.com" 1 次，"wiki.org" 5 次。
而对于父域名，会访问 "mail.com" 900 + 1 = 901 次，"com" 900 + 50 + 1 = 951 次，和 "org" 5 次。
```

**提示:**
- `1 <= cpdomain.length <= 100`
- `1 <= cpdomain[i].length <= 100`
- `cpdomain[i]` 会遵循 `"repi d1i.d2i.d3i"` 或 `"repi d1i.d2i"` 格式
- `repi` 是范围 `[1, 10^4]` 内的整数
- `d1i`、`d2i` 和 `d3i` 由小写英文字母组成

## 解题思路

这是一道哈希表 + 字符串处理的题目。核心思路是：
1. 解析每个计数配对，提取访问次数和域名
2. 生成该域名的所有子域名（包括自己）
3. 使用哈希表累计每个子域名的访问次数
4. 格式化输出结果

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def subdomainVisits(self, cpdomains: List[str]) -> List[str]:
        count = defaultdict(int)
        
        for cpdomain in cpdomains:
            # 分离访问次数和域名
            times, domain = cpdomain.split()
            times = int(times)
            
            # 生成所有子域名并累计
            parts = domain.split('.')
            for i in range(len(parts)):
                subdomain = '.'.join(parts[i:])
                count[subdomain] += times
        
        # 格式化输出
        return [f"{cnt} {domain}" for domain, cnt in count.items()]
```

### 方法二：不使用 defaultdict

```python
from typing import List

class Solution:
    def subdomainVisits(self, cpdomains: List[str]) -> List[str]:
        count = {}
        
        for cpdomain in cpdomains:
            times, domain = cpdomain.split()
            times = int(times)
            
            # 逐级生成子域名
            parts = domain.split('.')
            for i in range(len(parts)):
                subdomain = '.'.join(parts[i:])
                count[subdomain] = count.get(subdomain, 0) + times
        
        return [f"{cnt} {domain}" for domain, cnt in count.items()]
```

### 方法三：使用 Counter

```python
from typing import List
from collections import Counter

class Solution:
    def subdomainVisits(self, cpdomains: List[str]) -> List[str]:
        count = Counter()
        
        for cpdomain in cpdomains:
            times, domain = cpdomain.split()
            times = int(times)
            
            parts = domain.split('.')
            for i in range(len(parts)):
                count['.'.join(parts[i:])] += times
        
        return [f"{cnt} {domain}" for domain, cnt in count.items()]
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 是数组长度，m 是域名的平均层数
- **空间复杂度**：O(n × m)，存储所有子域名

## 关键点总结

1. **字符串分割**：使用 `split()` 分离次数和域名
2. **子域名生成**：从右到左逐级生成
3. **哈希表累计**：使用 defaultdict 或 get 方法
4. **字符串拼接**：使用 `'.'.join()` 和 f-string

## 易错点

1. **访问次数转换**：记得转换为整数
2. **子域名顺序**：从当前位置到末尾，不是从开头
3. **输出格式**：次数和域名之间有空格
