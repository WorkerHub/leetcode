## 题目描述

原始字符串由小写字母组成，可以被编码为另一个字符串，编码规则是将若干连续字符替换为一个正整数（表示字符数）。

给你两个编码字符串 `s1` 和 `s2`，判断是否存在一个原始字符串，经过上述编码规则后，可以得到 `s1` 和 `s2`。

**示例 1：**
```
输入：s1 = "internationalization", s2 = "i18n"
输出：true
解释：原始字符串 "internationalization"，s2 = "i" + 18 + "n"
```

**示例 2：**
```
输入：s1 = "l123e", s2 = "44"
输出：true
解释：原始字符串长度为 124，s1 = "l" + 123 + "e"，s2 = 44 + 44
```

**提示：**
- `1 <= s1.length, s2.length <= 40`
- `s1` 和 `s2` 只含小写字母和数字

## 解题思路

**DP 状态：** `dp(i, j, diff)` = 在 `s1[i:]` 和 `s2[j:]` 处，`s1` 超前 `s2` `diff` 个字符的情况下，是否存在合法原始字符串（`diff > 0` 表示 s1 超前，`diff < 0` 表示 s2 超前）。

**状态转移：**
1. `diff == 0`：s1[i] 和 s2[j] 必须相同或都是数字（扩展数字）
2. `diff > 0`：s1 已经消耗了 diff 个字符，s2[j] 需要匹配这些字符
3. `diff < 0`：s2 已经消耗了 |diff| 个字符，s1[i] 需要匹配

## 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from functools import lru_cache

class Solution:
    def possiblyEquals(self, s1: str, s2: str) -> bool:
        m, n = len(s1), len(s2)

        @lru_cache(maxsize=None)
        def dp(i: int, j: int, diff: int) -> bool:
            # i: s1 的当前位置, j: s2 的当前位置
            # diff: s1 相对 s2 超前的字符数（正表示 s1 超前，负表示 s2 超前）

            if i == m and j == n:
                return diff == 0

            if diff > 0:
                # s1 已超前 diff 个字符，s2[j] 需要消耗
                if j < n and s2[j].isdigit():
                    # 扩展 s2 的数字
                    num = 0
                    jj = j
                    while jj < n and s2[jj].isdigit():
                        num = num * 10 + int(s2[jj])
                        jj += 1
                        if dp(i, jj, diff - num):
                            return True
                    return False
                elif j < n and s2[j].isalpha():
                    # s2 的字母匹配 s1 超前的字符
                    if diff > 0:
                        return dp(i, j + 1, diff - 1)
                else:
                    return False

            elif diff < 0:
                # s2 超前，s1[i] 需要消耗
                if i < m and s1[i].isdigit():
                    num = 0
                    ii = i
                    while ii < m and s1[ii].isdigit():
                        num = num * 10 + int(s1[ii])
                        ii += 1
                        if dp(ii, j, diff + num):
                            return True
                    return False
                elif i < m and s1[i].isalpha():
                    return dp(i + 1, j, diff + 1)
                else:
                    return False

            else:  # diff == 0
                # 两者同步
                if i == m or j == n:
                    return i == m and j == n

                if s1[i].isalpha() and s2[j].isalpha():
                    if s1[i] == s2[j]:
                        return dp(i + 1, j + 1, 0)
                    return False

                if s1[i].isalpha():
                    # s2[j] 是数字
                    num = 0
                    jj = j
                    while jj < n and s2[jj].isdigit():
                        num = num * 10 + int(s2[jj])
                        jj += 1
                        if dp(i, jj, -num):
                            return True
                    return False

                if s2[j].isalpha():
                    # s1[i] 是数字
                    num = 0
                    ii = i
                    while ii < m and s1[ii].isdigit():
                        num = num * 10 + int(s1[ii])
                        ii += 1
                        if dp(ii, j, num):
                            return True
                    return False

                # 两者都是数字
                num1 = 0
                ii = i
                while ii < m and s1[ii].isdigit():
                    num1 = num1 * 10 + int(s1[ii])
                    ii += 1
                    num2 = 0
                    jj = j
                    while jj < n and s2[jj].isdigit():
                        num2 = num2 * 10 + int(s2[jj])
                        jj += 1
                        if dp(ii, jj, num1 - num2):
                            return True
                return False

        return dp(0, 0, 0)
```

### 方法二：简化状态转移

```python
from functools import lru_cache

class Solution:
    def possiblyEquals(self, s1: str, s2: str) -> bool:
        m, n = len(s1), len(s2)

        # 预解析：将字符串分段为 (type, value) 的列表
        # type = 'char' 或 'num'

        @lru_cache(maxsize=None)
        def solve(i, j, diff):
            if i == m and j == n:
                return diff == 0
            # 如果 diff != 0，先尝试消耗领先的字符
            if diff != 0:
                leading = s1 if diff > 0 else s2
                pos = j if diff > 0 else i
                abs_diff = abs(diff)
                if pos < len(leading) and leading[pos].isalpha():
                    if diff > 0:
                        return solve(i, j + 1, diff - 1)
                    else:
                        return solve(i + 1, j, diff + 1)
                elif pos < len(leading) and leading[pos].isdigit():
                    num, p = 0, pos
                    while p < len(leading) and leading[p].isdigit():
                        num = num * 10 + int(leading[p])
                        p += 1
                        ndi = j if diff > 0 else i
                        ndj = p if diff > 0 else p
                        nd = (diff - num) if diff > 0 else (diff + num)
                        args = (i, ndj, nd) if diff > 0 else (ndj, j, nd)
                        if solve(*args):
                            return True
                return False
            # diff == 0
            if i >= m or j >= n:
                return False
            if s1[i].isalpha() and s2[j].isalpha():
                return s1[i] == s2[j] and solve(i+1, j+1, 0)
            # 有数字，枚举
            nums1 = get_nums(s1, i)
            nums2 = get_nums(s2, j)
            if not nums1 and not nums2:
                return False
            for n1, i2 in (nums1 or [(0, i)]):
                for n2, j2 in (nums2 or [(0, j)]):
                    if solve(i2, j2, n1 - n2):
                        return True
            return False

        def get_nums(s, start):
            if start >= len(s) or s[start].isalpha():
                return None
            result = []
            num, p = 0, start
            while p < len(s) and s[p].isdigit():
                num = num * 10 + int(s[p])
                p += 1
                result.append((num, p))
            return result

        return solve(0, 0, 0)
```

## 复杂度分析

- 时间复杂度：O(m * n * D)，D 为最大差值（约 10^4 * 40 = 40000）
- 空间复杂度：O(m * n * D)，记忆化缓存

## 关键点总结

1. 状态 `(i, j, diff)` 表示 s1 当前位置、s2 当前位置、超前字符数
2. 差值 `diff` 范围 [-998, 998]（数字最大 9^40 但实际受字符串长度限制）
3. 数字可以一位一位地读（枚举不同数字长度）

## 易错点

- 数字是可变位数（如 `123` 可以是 1 个数或 3 个独立字符数），需要枚举
- diff 的范围需要合理限制（过大则无法匹配）
- 状态转移边界：`i == m and j == n` 时 `diff` 必须为 0
