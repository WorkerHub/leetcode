## 题目描述

给你一个二维整数数组 `stockPrices`，`stockPrices[i] = [dayi, pricei]` 表示第 `dayi` 天的股价为 `pricei`。

折线图上每天对应一个点，用**最少数量的线段**来表示这个折线图（相邻点如果共线则可以合并成一条线段）。

返回表示折线图所需的**最少线段数量**。

**示例 1：**
```
输入：stockPrices = [[1,7],[2,6],[3,5],[4,4],[5,4],[6,3],[7,2],[8,1]]
输出：3
解释：[1,7]->[5,4] 是一条线段，[5,4]->[7,2] 是另一条，[7,2]->[8,1] 是第三条。
```

**示例 2：**
```
输入：stockPrices = [[3,4],[1,2],[7,8],[2,3]]
输出：1
```

## 解题思路

将点按日期排序，然后遍历相邻点判断是否共线。

**共线判断：** 三点 `A, B, C` 共线当且仅当斜率 `AB == BC`，即 `(yB-yA)/(xB-xA) == (yC-yB)/(xC-xB)`，整理为整数形式避免浮点误差：`(yB-yA) * (xC-xB) == (yC-yB) * (xB-xA)`。

若不共线，则需要新的一条线段，计数加 1。

## 代码实现

### 方法一：斜率整数判断（推荐）

```python
from typing import List

class Solution:
    def minimumLines(self, stockPrices: List[List[int]]) -> int:
        # 按日期排序
        stockPrices.sort()
        n = len(stockPrices)

        if n <= 1:
            return 0

        lines = 1  # 至少需要一条线段
        for i in range(2, n):
            x1, y1 = stockPrices[i - 2]
            x2, y2 = stockPrices[i - 1]
            x3, y3 = stockPrices[i]

            # 用交叉乘法判断共线（避免浮点）
            # 斜率 = (y2-y1)/(x2-x1) == (y3-y2)/(x3-x2)
            # 转为：(y2-y1)*(x3-x2) == (y3-y2)*(x2-x1)
            if (y2 - y1) * (x3 - x2) != (y3 - y2) * (x2 - x1):
                lines += 1

        return lines
```

### 方法二：记录前一条线段的斜率

```python
from typing import List
from math import gcd

class Solution:
    def minimumLines(self, stockPrices: List[List[int]]) -> int:
        stockPrices.sort()
        n = len(stockPrices)
        if n <= 1:
            return 0

        lines = 1
        # 记录前一段的斜率（约分后的分子分母）
        dx = stockPrices[1][0] - stockPrices[0][0]
        dy = stockPrices[1][1] - stockPrices[0][1]
        g = gcd(abs(dx), abs(dy))
        prev_slope = (dy // g, dx // g)

        for i in range(2, n):
            x1, y1 = stockPrices[i - 1]
            x2, y2 = stockPrices[i]
            dx = x2 - x1
            dy = y2 - y1
            g = gcd(abs(dx), abs(dy))
            cur_slope = (dy // g, dx // g)
            if cur_slope != prev_slope:
                lines += 1
                prev_slope = cur_slope

        return lines
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(1)。

## 关键点总结

1. 排序后，问题简化为判断相邻三点是否共线。
2. 用交叉乘法（整数运算）避免浮点精度问题。
3. 每次斜率变化时，需要新的一条线段。

## 易错点

- 斜率比较用整数叉积而非浮点除法，避免精度问题。
- 至少有两个点才需要线段（n=1 时返回 0）。
