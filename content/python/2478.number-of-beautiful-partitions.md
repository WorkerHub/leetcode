## 题目描述

给你一个字符串 `s`，它只包含数字字符，同时给你两个整数 `k` 和 `minLength`。

如果对 `s` 的分割满足以下条件，则认为是一个 **美丽分割**：

- `s` 被分成 `k` 个 **非空** 子字符串。
- 每个子字符串的长度 **至少** 为 `minLength`。
- 每个子字符串的第一个字符是 **素数**（`'2'`、`'3'`、`'5'`、`'7'`），最后一个字符 **不是** 素数（`'1'`、`'4'`、`'6'`、`'8'`、`'9'`）。

返回所有 **美丽分割** 的数目，因为答案可能很大，返回对 `10^9 + 7` 取余的结果。

**提示：**
- `1 <= k, minLength <= s.length <= 1000`

## 解题思路

**动态规划：**

`dp[i][j]` = 将 `s[0..i-1]` 分成 `j` 个满足条件的子字符串的方案数。

**转移条件：** 若 `s[l..i-1]`（长度 >= minLength，s[l] 是素数，s[i-1] 不是素数），则：
`dp[i][j] += dp[l][j-1]`

**优化：** 用前缀和加速内层循环。

## 代码实现

### 方法一：DP + 前缀和优化（推荐）

```python
class Solution:
    def beautifulPartitions(self, s: str, k: int, minLength: int) -> int:
        MOD = 10 ** 9 + 7
        primes = set('2357')
        n = len(s)

        # 检查初始条件
        if s[0] not in primes or s[-1] in primes:
            return 0

        # dp[i][j] = s[0..i-1] 分成 j 段的方案数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 1

        # prefix[i][j] = sum(dp[0..i][j])（前缀和加速）
        prefix = [[0] * (k + 1) for _ in range(n + 1)]
        prefix[0][0] = 1

        for i in range(1, n + 1):
            # 以位置 i-1 结尾的子字符串：结尾字符必须不是素数
            if s[i - 1] not in primes:  # 结尾不是素数
                for j in range(1, k + 1):
                    # 子字符串起点 l，长度 >= minLength，起点字符是素数
                    # l 的范围：l <= i - minLength
                    l_bound = i - minLength  # l 的最大值（0-indexed：l 对应 dp 中的 l）
                    if l_bound >= 0 and s[l_bound] in primes:
                        # 等等，起点 l 对应的字符是 s[l]（0-indexed），需要 s[l] in primes
                        # 前缀和：sum(dp[l'][j-1]) for all valid l'
                        pass

            # 更新前缀和（简化处理）
            for j in range(k + 1):
                prefix[i][j] = (prefix[i - 1][j] + dp[i][j]) % MOD

        # 重新实现正确的版本
        dp2 = [[0] * (k + 1) for _ in range(n + 1)]
        dp2[0][0] = 1

        for j in range(1, k + 1):
            # 构建前缀和（j-1 段的前缀和）
            psum = [0] * (n + 1)
            for i in range(n + 1):
                psum[i + 1] = (psum[i] + dp2[i][j - 1]) % MOD if i < n + 1 else 0

            for i in range(minLength, n + 1):
                # 以 i-1 结尾，s[i-1] 不是素数
                if s[i - 1] in primes:
                    continue
                # 起点 l 范围：[1, i-minLength+1]（1-indexed），且 s[l-1] 是素数
                # dp2[i][j] = sum over valid l of dp2[l-1][j-1]
                for l in range(1, i - minLength + 2):
                    if s[l - 1] in primes:
                        dp2[i][j] = (dp2[i][j] + dp2[l - 1][j - 1]) % MOD

        return dp2[n][k]
```

### 方法二：更清晰的 DP

```python
class Solution:
    def beautifulPartitions(self, s: str, k: int, minLength: int) -> int:
        MOD = 10 ** 9 + 7
        PRIMES = set('2357')
        n = len(s)

        if s[0] not in PRIMES or s[-1] in PRIMES:
            return 0

        # f[i][j] = s[0..i-1] 分成 j 段，最后一段结尾在 i-1 的方案数
        # 答案 = f[n][k]
        f = [[0] * (k + 1) for _ in range(n + 1)]
        f[0][0] = 1

        for j in range(1, k + 1):
            # 前缀和优化
            prefix = 0
            ptr = 0  # 控制有效的起点范围

            for i in range(minLength, n + 1):
                # 尝试在 i 处结束一段（s[i-1] 不是素数）
                if s[i - 1] in PRIMES:
                    continue

                # 更新前缀和：加入满足条件的起点
                while ptr <= i - minLength:
                    if s[ptr] in PRIMES:  # 起点字符是素数
                        prefix = (prefix + f[ptr][j - 1]) % MOD
                    ptr += 1

                f[i][j] = prefix

        return f[n][k]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP + 前缀和 | O(n * k) | O(n * k) |

## 关键点总结

1. 每段的起点是素数字符，终点是非素数字符
2. 前缀和优化：对每个终点 i，用滑动指针维护有效起点的方案数之和
3. 初始检查：若 `s[0]` 不是素数或 `s[n-1]` 是素数，直接返回 0

## 易错点

- 注意 1-indexed 与 0-indexed 的转换
- 前缀和的更新需要与当前终点配合
