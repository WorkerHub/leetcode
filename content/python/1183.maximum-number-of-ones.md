## 题目描述

[LeetCode 1183. Maximum Number Of Ones](https://leetcode.com/problems/maximum-number-of-ones/)

考虑一个 `width x height` 的矩阵，其中每个单元格的值为 `0` 或 `1`。

现在有一个约束条件：在矩阵中任意大小为 `sideLength x sideLength` 的子矩阵中，最多只能有 `maxOnes` 个 `1`。

请返回在满足上述约束条件下，整个矩阵中最多可以有多少个 `1`。

**示例 1:**

```
输入: width = 3, height = 3, sideLength = 2, maxOnes = 1
输出: 4
解释:
在一个 3x3 的矩阵中，每个 2x2 的子矩阵最多有 1 个 1。
最优方案如下：
[1, 0, 1]
[0, 0, 0]
[1, 0, 1]
总共有 4 个 1。
```

**示例 2:**

```
输入: width = 3, height = 3, sideLength = 2, maxOnes = 2
输出: 6
解释:
[1, 0, 1]
[1, 0, 1]
[1, 0, 1]
```

**提示:**

- `1 <= width, height <= 100`
- `1 <= sideLength <= width, height`
- `0 <= maxOnes <= sideLength * sideLength`

## 解题思路

这道题是一道非常巧妙的贪心问题，核心思想是**找到重复模式**。

**关键观察**：
1. 由于约束是针对 `sideLength x sideLength` 的子矩阵，整个矩阵会被这样的子矩阵"覆盖"
2. 矩阵可以看作由多个 `sideLength x sideLength` 的块平铺而成
3. 在每个这样的基础块中，我们需要选择最多 `maxOnes` 个位置放 `1`
4. 关键问题：在基础块的哪些位置放 `1` 可以使得总数最大？

**贪心策略**：
1. 将整个矩阵按照 `sideLength` 进行分块，每个位置 `(i, j)` 对应的块内位置是 `(i % sideLength, j % sideLength)`
2. 统计每个块内位置被"覆盖"的次数（即这个位置在整个矩阵中出现了多少次）
3. 贪心选择：优先在被覆盖次数最多的位置放 `1`
4. 选择 `maxOnes` 个覆盖次数最多的位置

**数学推导**：
- 对于位置 `(r, c)`（r < sideLength, c < sideLength），它在整个矩阵中出现的次数为：
  - 行方向：`(height - r + sideLength - 1) // sideLength`
  - 列方向：`(width - c + sideLength - 1) // sideLength`
  - 总次数：行方向 × 列方向

## Python 代码实现

### 方法一：贪心 + 排序（推荐）

```python
from typing import List

class Solution:
    def maximumNumberOfOnes(self, width: int, height: int, sideLength: int, maxOnes: int) -> int:
        """
        计算每个块内位置的覆盖次数，贪心选择覆盖次数最多的位置
        """
        # 统计每个块内位置的覆盖次数
        counts = []
        
        for r in range(sideLength):
            for c in range(sideLength):
                # 计算位置 (r, c) 在整个矩阵中出现的次数
                row_count = (height - r + sideLength - 1) // sideLength
                col_count = (width - c + sideLength - 1) // sideLength
                total_count = row_count * col_count
                counts.append(total_count)
        
        # 贪心：选择覆盖次数最多的 maxOnes 个位置
        counts.sort(reverse=True)
        
        return sum(counts[:maxOnes])
```

### 方法二：使用堆优化（适合 maxOnes 较小的情况）

```python
from typing import List
import heapq

class Solution:
    def maximumNumberOfOnes(self, width: int, height: int, sideLength: int, maxOnes: int) -> int:
        """
        使用最大堆来选择 top-k 个覆盖次数
        """
        counts = []
        
        for r in range(sideLength):
            for c in range(sideLength):
                # 计算覆盖次数
                row_count = (height - r + sideLength - 1) // sideLength
                col_count = (width - c + sideLength - 1) // sideLength
                counts.append(row_count * col_count)
        
        # 使用 nlargest 获取前 maxOnes 大的值
        top_k = heapq.nlargest(maxOnes, counts)
        
        return sum(top_k)
```

### 方法三：数学公式优化

```python
from typing import List

class Solution:
    def maximumNumberOfOnes(self, width: int, height: int, sideLength: int, maxOnes: int) -> int:
        """
        直接计算每个位置的覆盖次数，不使用列表存储
        """
        # 计算每个块内位置的覆盖次数
        def get_count(r: int, c: int) -> int:
            """计算位置 (r, c) 的覆盖次数"""
            row_count = (height - r - 1) // sideLength + 1
            col_count = (width - c - 1) // sideLength + 1
            return row_count * col_count
        
        # 生成所有位置的覆盖次数
        counts = [get_count(r, c) for r in range(sideLength) for c in range(sideLength)]
        
        # 排序后选择前 maxOnes 个
        counts.sort(reverse=True)
        
        return sum(counts[:maxOnes])
```

## 复杂度分析

### 方法一（贪心 + 排序）：
- 时间复杂度：O(s^2 * log(s^2))，其中 s = sideLength
  - 需要计算 s^2 个位置的覆盖次数：O(s^2)
  - 排序需要 O(s^2 * log(s^2))
- 空间复杂度：O(s^2)，存储所有覆盖次数

### 方法二（堆优化）：
- 时间复杂度：O(s^2 * log(maxOnes))
  - 计算覆盖次数：O(s^2)
  - nlargest 的时间复杂度为 O(s^2 * log(maxOnes))
- 空间复杂度：O(s^2)

### 方法三（数学优化）：
- 时间复杂度：O(s^2 * log(s^2))，与方法一相同
- 空间复杂度：O(s^2)

## 关键点总结

1. **分块思想**：将大矩阵分解为小块，找到重复模式
2. **贪心策略**：优先选择覆盖次数多的位置，使得总数最大
3. **覆盖次数计算**：理解如何计算一个块内位置在整个矩阵中出现的次数
4. **向上取整**：`(height - r + sideLength - 1) // sideLength` 等价于 `ceil((height - r) / sideLength)`
5. **模运算应用**：通过 `i % sideLength` 和 `j % sideLength` 将位置映射到块内坐标

## 易错点

1. **覆盖次数计算错误**：要考虑边界情况，不是简单的 `height // sideLength`
2. **向上取整公式**：`(a + b - 1) // b` 实现向上取整，不要写错
3. **理解题意**：约束是"任意子矩阵最多 maxOnes 个 1"，不是整个矩阵
4. **贪心的正确性**：要理解为什么选择覆盖次数多的位置是最优的
5. **索引范围**：块内位置的范围是 `[0, sideLength)`，不要越界
