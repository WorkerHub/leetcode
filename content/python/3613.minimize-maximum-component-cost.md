## 题目描述

给你一个 `n` 个节点的无向加权图，边集 `edges[i] = [u, v, w]`。将图中节点分成若干连通分量，每个连通分量的 **代价** 为其内部最大边权。

请返回所有分量中最大代价的最小可能值（即最小化所有分量中边权最大值）。

**示例 1：**

```
输入：n = 5, edges = [[0,1,4],[1,2,2],[2,3,1],[3,4,3]]
输出：2
解释：将 {0,1,2} 和 {2,3,4} 分开... 最优划分后最大边权为 2
```

**示例 2：**

```
输入：n = 3, edges = [[0,1,5],[1,2,5],[0,2,5]]
输出：5
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= edges.length <= 2 * 10^5`
- `0 <= u, v < n`
- `1 <= w <= 10^9`

## 解题思路

**二分答案 + 并查集验证**：

二分最大代价 `mid`：
- 只允许使用权重 `<= mid` 的边构建连通分量
- 检查是否所有节点都被覆盖（即每个节点至少在某个分量中）

由于可以任意分割，实际上只要权重 `<= mid` 的边构成的子图中每个连通分量合法即可。

等价于：找到最小的 `mid` 使得只用 `<= mid` 的边时，没有节点被孤立（或某些连通性要求满足）。

实际上，答案就是图的最小生成树的最大边权（如果图连通），即最小生成树的瓶颈权值。

## Python 代码实现

### 方法一：二分 + 并查集（推荐）

```python
from typing import List

class Solution:
    def minimizeMaxCost(self, n: int, edges: List[List[int]]) -> int:
        # 收集所有边权
        weights = sorted(set(e[2] for e in edges))

        def check(max_w: int) -> bool:
            # 只用权重 <= max_w 的边，检查图的连通性
            parent = list(range(n))

            def find(x):
                while parent[x] != x:
                    parent[x] = parent[parent[x]]
                    x = parent[x]
                return x

            def union(x, y):
                parent[find(x)] = find(y)

            for u, v, w in edges:
                if w <= max_w:
                    union(u, v)

            root = find(0)
            return all(find(i) == root for i in range(n))

        # 二分查找
        lo, hi = 0, len(weights) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if check(weights[mid]):
                hi = mid
            else:
                lo = mid + 1

        return weights[lo] if check(weights[lo]) else -1
```

### 方法二：Kruskal 最小生成树（等价）

```python
from typing import List

class Solution:
    def minimizeMaxCost(self, n: int, edges: List[List[int]]) -> int:
        edges.sort(key=lambda e: e[2])
        parent = list(range(n))

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            rx, ry = find(x), find(y)
            if rx == ry:
                return False
            parent[rx] = ry
            return True

        components = n
        max_w = 0
        for u, v, w in edges:
            if union(u, v):
                components -= 1
                max_w = w
                if components == 1:
                    return max_w

        return -1 if components > 1 else max_w
```

## 复杂度分析

- 时间复杂度：O(E log E)，排序为主要开销
- 空间复杂度：O(n)

## 关键点总结

1. 最小化最大代价 = 最小生成树的最大边权（瓶颈最小生成树）
2. Kruskal 算法天然给出瓶颈最小生成树
3. 二分方法更通用，适合加了额外约束的变体
4. 若图不连通，返回 -1

## 易错点

1. 若图不连通，无法满足所有节点互联，需返回 -1
2. 最小生成树最大边权就是答案，无需更复杂操作
3. 并查集路径压缩减少重复 `find` 调用开销
