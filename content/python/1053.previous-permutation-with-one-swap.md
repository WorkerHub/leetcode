## 题目描述

给你一个正整数数组 `arr`（可能存在重复的元素），请你返回可在一次交换（交换两数字 `arr[i]` 和 `arr[j]` 的位置）后得到的、按字典序排列小于 `arr` 的最大排列。

如果无法这么操作，就请返回原数组。

**示例 1：**
```
输入：arr = [3,2,1]
输出：[3,1,2]
解释：交换 2 和 1
```

**示例 2：**
```
输入：arr = [1,1,5]
输出：[1,1,5]
解释：已经是最小排列
```

**示例 3：**
```
输入：arr = [1,9,4,6,7]
输出：[1,7,4,6,9]
解释：交换 9 和 7
```

**提示：**
- `1 <= arr.length <= 10^4`
- `1 <= arr[i] <= 10^4`

## 解题思路

这道题要求找到比当前排列小的最大排列，核心是理解"字典序"和"贪心策略"。

**关键观察：**
1. 从右向左找第一个"下降点"（`arr[i] > arr[i+1]`），这是我们能够减小的最高位
2. 在下降点右侧找一个尽可能大的、但比 `arr[i]` 小的数进行交换
3. 如果有多个相同的候选数，选择最右边的（保证交换后左边部分尽可能大）

**算法流程：**
1. 从右向左找第一个 `arr[i] > arr[i+1]` 的位置 `i`
2. 如果不存在这样的 `i`，说明数组已经是最小排列，返回原数组
3. 在 `[i+1, n-1]` 范围内找到最大的、但小于 `arr[i]` 的数的位置 `j`
4. 如果有多个相同的数，选择最右边的位置
5. 交换 `arr[i]` 和 `arr[j]`

## Python 代码实现

### 方法一：贪心算法（推荐）

```python
from typing import List

class Solution:
    def prevPermOpt1(self, arr: List[int]) -> List[int]:
        """
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(arr)
        
        # 1. 从右向左找第一个下降点
        i = n - 2
        while i >= 0 and arr[i] <= arr[i + 1]:
            i -= 1
        
        # 如果没找到，说明数组非递增，已经是最小排列
        if i < 0:
            return arr
        
        # 2. 在 i 右侧找最大的、但小于 arr[i] 的数
        j = n - 1
        while j > i and arr[j] >= arr[i]:
            j -= 1
        
        # 3. 如果有重复的，找最右边的
        while j > i and arr[j] == arr[j - 1]:
            j -= 1
        
        # 4. 交换
        arr[i], arr[j] = arr[j], arr[i]
        
        return arr
```

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def prevPermOpt1(self, arr: List[int]) -> List[int]:
        """
        寻找上一个排列的贪心算法
        """
        n = len(arr)
        
        # 步骤1：从右向左找第一个 arr[i] > arr[i+1] 的位置
        # 这个位置是我们可以减小的最高位
        left = -1
        for i in range(n - 2, -1, -1):
            if arr[i] > arr[i + 1]:
                left = i
                break
        
        # 如果找不到，说明整个数组是非递减的，已经是最小排列
        if left == -1:
            return arr
        
        # 步骤2：在 left 右侧找到最大的、但小于 arr[left] 的数
        right = -1
        max_val = -1
        for i in range(left + 1, n):
            if arr[i] < arr[left] and arr[i] > max_val:
                max_val = arr[i]
                right = i
        
        # 步骤3：如果有多个相同的最大值，选最右边的
        for i in range(right + 1, n):
            if arr[i] == max_val:
                right = i
        
        # 步骤4：交换
        arr[left], arr[right] = arr[right], arr[left]
        
        return arr
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def prevPermOpt1(self, arr: List[int]) -> List[int]:
        """
        简化的贪心实现
        """
        n = len(arr)
        
        # 找下降点
        i = n - 2
        while i >= 0 and arr[i] <= arr[i + 1]:
            i -= 1
        
        if i < 0:
            return arr
        
        # 找交换位置：小于 arr[i] 的最大值的最右位置
        j = i + 1
        for k in range(i + 2, n):
            if arr[i] > arr[k] >= arr[j]:
                j = k
        
        arr[i], arr[j] = arr[j], arr[i]
        return arr
```

## 复杂度分析

**时间复杂度：** O(n)
- 找下降点：最坏 O(n)
- 找交换位置：最坏 O(n)
- 总体：O(n)

**空间复杂度：** O(1)
- 只使用常量级额外空间
- 原地修改数组

## 关键点总结

1. **下降点**：从右向左找第一个 `arr[i] > arr[i+1]`，这是能减小的最高位
2. **交换对象**：在下降点右侧找小于 `arr[i]` 的最大值
3. **去重处理**：如果有多个相同的最大值，必须选最右边的
4. **边界情况**：如果没有下降点，说明已是最小排列

## 易错点

1. **重复元素**：必须选择相同值的最右位置，否则得不到最大的上一个排列
   - 错误：`[3,1,1,3]` → `[1,3,1,3]`
   - 正确：`[3,1,1,3]` → `[1,1,3,3]`

2. **全递增序列**：如果数组是非递减的，直接返回原数组

3. **查找范围**：交换对象只能在下降点右侧查找

4. **理解题意**：只能交换一次，且要求的是"小于当前排列的最大排列"
