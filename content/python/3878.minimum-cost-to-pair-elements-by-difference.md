## 题目描述

给你一个整数数组 `nums`（偶数长度），你需要将所有元素分成 n/2 对，每对的代价为两元素之差的绝对值。

返回所有配对方案中总代价的最小值。

**示例 1：**

```
输入：nums = [1, 3, 2, 4]
输出：2
解释：配对 (1,2) 和 (3,4)，代价 |1-2| + |3-4| = 1 + 1 = 2。
```

**示例 2：**

```
输入：nums = [1, 5, 3, 4]
输出：2
解释：配对 (3,4) 和 (1,5)，代价 1 + 4 = 5；
配对 (3,5) 和 (1,4)，代价 2 + 3 = 5；
配对 (1,3) 和 (4,5)，代价 2 + 1 = 3；
最优配对 (1,3) 和 (4,5) 代价 3，或 (3,4) 和 (1,5) 代价 5... 哪个更优？
```

**提示：**
- `n == nums.length`（偶数）
- `2 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**排序后相邻配对**是最优策略：

证明：若将排序数组中非相邻元素配对（交叉配对），总代价不小于相邻配对。

例如：a <= b <= c <= d，`|a-c| + |b-d| >= |a-b| + |c-d|`（因为 c-a >= b-a 且 d-b >= d-c）。

## Python 代码实现

### 方法一：排序相邻配对（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        nums.sort()
        total = 0
        for i in range(0, len(nums), 2):
            total += nums[i + 1] - nums[i]  # 相邻元素差（排序后为非负）
        return total
```

### 方法二：枚举验证（小数据）

```python
from typing import List
from itertools import permutations

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        n = len(nums)
        nums.sort()
        # 排序后相邻配对
        return sum(nums[i + 1] - nums[i] for i in range(0, n, 2))
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)，原地排序

## 关键点总结

1. 排序后相邻配对总是最优解（数学可证）。
2. 排序后 `nums[i+1] - nums[i]` 总为非负，无需取绝对值。
3. 遍历步长为 2，取偶数下标和奇数下标的差。

## 易错点

1. 数组长度必须为偶数（题目保证），确认遍历不越界。
2. 不要用浮点数，全程整数运算。
