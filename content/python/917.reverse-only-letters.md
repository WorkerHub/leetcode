## 题目描述

给你一个字符串 `s`，根据下述规则反转字符串：

- 所有非英文字母保留在原有位置。
- 所有英文字母（小写或大写）位置反转。

返回反转后的 `s`。

**示例 1：**
```
输入：s = "ab-cd"
输出："dc-ba"
```

**示例 2：**
```
输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"
```

**示例 3：**
```
输入：s = "Test1ng-Leet=code-Q!"
输出："Qedo1ct-eeLg=ntse-T!"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 仅由 ASCII 值在范围 `[33, 122]` 的字符组成
- `s` 不含 `'\"'` 或 `'\\'`

## 解题思路

这道题要求只反转字母，非字母字符保持位置不变。典型的双指针问题。

**方法一：双指针**
1. 左指针从左往右，右指针从右往左
2. 遇到字母就交换，遇到非字母就跳过
3. 直到两个指针相遇

**方法二：提取 + 填充**
1. 提取所有字母并反转
2. 按原顺序填充回去，非字母位置不变

## Python 代码实现

### 方法一：双指针（推荐 ⭐）

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        # 转换为列表，方便修改
        chars = list(s)
        left, right = 0, len(s) - 1
        
        while left < right:
            # 左指针找到字母
            while left < right and not chars[left].isalpha():
                left += 1
            
            # 右指针找到字母
            while left < right and not chars[right].isalpha():
                right -= 1
            
            # 交换字母
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
        
        return ''.join(chars)
```

### 方法二:提取 + 填充

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        # 提取所有字母
        letters = [c for c in s if c.isalpha()]
        # 反转字母列表
        letters.reverse()
        
        # 重新构建字符串
        result = []
        letter_index = 0
        
        for c in s:
            if c.isalpha():
                result.append(letters[letter_index])
                letter_index += 1
            else:
                result.append(c)
        
        return ''.join(result)
```

### 方法三：栈

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        # 将所有字母入栈
        stack = [c for c in s if c.isalpha()]
        
        # 重新构建字符串
        result = []
        for c in s:
            if c.isalpha():
                result.append(stack.pop())
            else:
                result.append(c)
        
        return ''.join(result)
```

### 方法四：一行代码（Python 特色）

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()][::-1]
        return ''.join(letters.pop(0) if c.isalpha() else c for c in s)
```

## 复杂度分析

**方法一：双指针**
- 时间复杂度：O(n)，每个字符最多访问一次
- 空间复杂度：O(n)，需要转换为列表（Python 字符串不可变）

**方法二：提取 + 填充**
- 时间复杂度：O(n)，遍历两次
- 空间复杂度：O(n)，存储字母和结果

**方法三：栈**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **双指针技巧**：从两端向中间移动，跳过非字母
2. **字母判断**：使用 `isalpha()` 方法
3. **字符串不可变**：Python 字符串不可变，需要转为列表
4. **栈的应用**：栈可以方便地实现反转
5. **多种解法**：双指针、提取填充、栈都可以解决

## 易错点

1. **忘记跳过非字母**：必须同时检查左右指针的字符
2. **边界条件**：`left < right` 的判断
3. **字符串不可变**：Python 字符串不能直接修改，要转列表
4. **大小写**：题目要求保留大小写
5. **ASCII 范围**：题目给定了字符范围，但实际不影响解法

```
交换后：j - b C - d E f - g h I a

j - b C - d E f - g h I a
    ↑                 ↑
    左找字母 b        右找字母 I
交换后：j - I C - d E f - g h b a

j - I C - d E f - g h b a
      ↑             ↑
      左找字母 C    右找字母 h
交换后：j - I h - d E f - g C b a

... 继续直到 left >= right

最终：j - I h - g f E - d C b a
```
