## 题目描述

给你一个字符串 `s`，它由若干个单词组成，单词之间用空格分隔。

如果字符串 `t` 中每个单词都是 `s` 对应单词的一个字母异位词（anagram），则称字符串 `t` 是 `s` 的一个 **字母异位词**。

返回 `s` 的 **不同字母异位词** 的数目（结果对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：s = "too hot"
输出：18
解释："too" 有 3 种排列（too, oto, oot），"hot" 有 6 种排列（hot, hto, oht, oth, tho, toh）。总计 3 × 6 = 18。
```

**示例 2：**

```
输入：s = "aa"
输出：1
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母和空格
- 相邻单词间只有一个空格

## 解题思路

对每个单词，计算其不同排列的数量：若单词长度为 n，各字符出现次数为 c1, c2, ..., ck，则不同排列数 = n! / (c1! * c2! * ... * ck!)。

所有单词的排列数之积即为答案。计算时使用模逆元处理除法取模。

## Python 代码实现

### 方法一：预计算阶乘和模逆元（推荐）

```python
from collections import Counter

MOD = 10**9 + 7

class Solution:
    def countAnagrams(self, s: str) -> int:
        # 预计算阶乘
        max_len = len(s) + 1
        fact = [1] * max_len
        for i in range(1, max_len):
            fact[i] = fact[i-1] * i % MOD

        def mod_inv(x, mod=MOD):
            # 费马小定理：x^(mod-2) mod mod
            return pow(x, mod - 2, mod)

        result = 1
        for word in s.split():
            n = len(word)
            # 排列数 = n! / (c1! * c2! * ... * ck!)
            perm = fact[n]
            for cnt in Counter(word).values():
                perm = perm * mod_inv(fact[cnt]) % MOD
            result = result * perm % MOD

        return result
```

### 方法二：预计算逆元数组

```python
from collections import Counter

MOD = 10**9 + 7

class Solution:
    def countAnagrams(self, s: str) -> int:
        max_n = len(s) + 1
        fact = [1] * max_n
        inv_fact = [1] * max_n

        for i in range(1, max_n):
            fact[i] = fact[i-1] * i % MOD

        # 线性递推计算阶乘逆元
        inv_fact[max_n - 1] = pow(fact[max_n - 1], MOD - 2, MOD)
        for i in range(max_n - 2, -1, -1):
            inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

        result = 1
        for word in s.split():
            n = len(word)
            perm = fact[n]
            for cnt in Counter(word).values():
                perm = perm * inv_fact[cnt] % MOD
            result = result * perm % MOD

        return result
```

## 复杂度分析

- 时间复杂度：O(|s|)，预计算阶乘 O(|s|)，处理每个单词 O(L)
- 空间复杂度：O(|s|)，阶乘数组

## 关键点总结

1. 单词的不同排列数 = n! / (各字符频次的阶乘之积)
2. 整个字符串的答案 = 各单词排列数之积
3. 模运算中的除法要用模逆元代替，费马小定理：a^{-1} ≡ a^{p-2} (mod p)

## 易错点

1. 不要忘记对每个字符的重复次数求阶乘逆元
2. 中间结果要及时取模，防止大数溢出（Python 中不溢出但影响效率）
3. 预计算逆元数组比每次调用 pow(x, MOD-2, MOD) 更高效
