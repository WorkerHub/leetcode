## 题目描述

给你 `n` 个城市，编号为从 `1` 到 `n`，以及 `n-1` 条边，构成一棵树。

返回一个大小为 `n-1` 的数组 `ans`，其中 `ans[i]` 表示城市间**最大距离**恰好等于 `i+1` 的**子树**（城市子集）数目。

子树中的城市之间必须保持连通，且子树的最大距离是子树中任意两个城市间距离的最大值。

**提示：**
- `2 <= n <= 15`

## 解题思路

由于 `n <= 15`，可以**枚举所有子集**（2^15 = 32768 个），对每个子集：
1. 检查子集中的城市是否在原树中构成连通子树
2. 若连通，计算子集中的最大距离

**检查连通性：** 枚举子集中每个节点，统计入度为 0 的节点个数；也可以直接用 BFS/DFS 检验。

**计算最大距离：** 预处理任意两点间距离（BFS/DFS），然后枚举子集中所有点对。

## 代码实现

### 方法一：枚举子集 + 预处理距离（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def countSubgraphsForEachDiameter(self, n: int, edges: List[List[int]]) -> List[int]:
        # 建图（1-indexed）
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # BFS 预处理任意两点间距离
        dist = [[0] * (n + 1) for _ in range(n + 1)]
        for src in range(1, n + 1):
            visited = [-1] * (n + 1)
            visited[src] = 0
            queue = deque([src])
            while queue:
                node = queue.popleft()
                for nei in graph[node]:
                    if visited[nei] == -1:
                        visited[nei] = visited[node] + 1
                        queue.append(nei)
            for dst in range(1, n + 1):
                dist[src][dst] = visited[dst]
        
        ans = [0] * (n - 1)
        
        # 枚举所有非空子集
        for mask in range(1, 1 << n):
            # 获取子集中的城市列表（1-indexed）
            cities = [i + 1 for i in range(n) if mask >> i & 1]
            if len(cities) < 2:
                continue
            
            # 检查子集是否构成连通子树
            # 方法：子集中边的数量 = 城市数 - 1（树中连通等价条件）
            edge_count = 0
            for u in cities:
                for v in graph[u]:
                    if (mask >> (v - 1)) & 1:
                        edge_count += 1
            edge_count //= 2  # 每条边被计了两次
            
            if edge_count != len(cities) - 1:
                continue  # 不连通
            
            # 计算子集中的最大距离
            max_dist = 0
            for i in range(len(cities)):
                for j in range(i + 1, len(cities)):
                    max_dist = max(max_dist, dist[cities[i]][cities[j]])
            
            if max_dist > 0:
                ans[max_dist - 1] += 1
        
        return ans
```

### 方法二：树形 DP（状态压缩）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubgraphsForEachDiameter(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u - 1].append(v - 1)
            graph[v - 1].append(u - 1)
        
        ans = [0] * (n - 1)
        
        # 对每个子集，用 DFS 同时检查连通性和计算直径
        def dfs(node: int, parent: int, mask: int):
            """返回从 node 出发的最大深度"""
            depth = 0
            for nei in graph[node]:
                if nei != parent and (mask >> nei) & 1:
                    d = dfs(nei, node, mask) + 1
                    # 当前节点到子树的路径 + 之前的最大深度 = 经过当前节点的路径
                    self.diameter = max(self.diameter, depth + d)
                    depth = max(depth, d)
            return depth
        
        for mask in range(3, 1 << n):
            if bin(mask).count('1') < 2:
                continue
            
            # 找子集中的第一个节点
            root = (mask & -mask).bit_length() - 1
            
            self.diameter = 0
            node_count = bin(mask).count('1')
            
            # DFS 并统计访问节点数
            visited = [0]
            
            def dfs2(node: int, parent: int):
                visited[0] += 1
                depth = 0
                for nei in graph[node]:
                    if nei != parent and (mask >> nei) & 1:
                        d = dfs2(nei, node) + 1
                        self.diameter = max(self.diameter, depth + d)
                        depth = max(depth, d)
                return depth
            
            dfs2(root, -1)
            
            # 若 DFS 访问节点数等于子集大小，则连通
            if visited[0] == node_count and self.diameter > 0:
                ans[self.diameter - 1] += 1
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举子集 | O(2^n * n^2) | O(n^2) |
| 树形 DP | O(2^n * n) | O(n) |

n <= 15，均可接受。

## 关键点总结

1. n <= 15 允许枚举所有子集（2^15 = 32768）
2. 连通性判断：子集中边数 = 节点数 - 1
3. 预处理任意两点距离（BFS），O(n^2) 预处理，O(1) 查询
4. 最大距离即树的直径

## 易错点

- 子集中节点数要 >= 2，单节点没有最大距离
- 边数统计时每条边被计两次，需要除以 2
- 答案数组大小是 `n-1`，下标从 0 开始对应距离 1
