## 题目描述

给定一个字符串 `text` 和一个字符串数组 `words`，返回所有 `[i, j]` 使得子串 `text[i...j]` 在 `words` 数组中。

返回的结果需要按照以下规则排序：
- 首先按照 `i` 升序排序
- 如果 `i` 相同，按照 `j` 升序排序

**示例 1：**
```
输入：text = "thestoryofleetcodeandme", words = ["story","fleet","leetcode"]
输出：[[3,7],[9,13],[10,17]]
```

**示例 2：**
```
输入：text = "ababa", words = ["aba","ab"]
输出：[[0,1],[0,2],[2,3],[2,4]]
解释：
注意，匹配可以重叠，"aba" 匹配 [0,2] 和 [2,4]。
```

**提示：**
- `1 <= text.length <= 100`
- `1 <= words.length <= 20`
- `1 <= words[i].length <= 50`
- `text` 和 `words[i]` 都只包含小写英文字母
- 所有 `words` 中的字符串互不相同

## 解题思路

这道题有多种解法，核心是找到所有匹配的子串。

**方法对比：**
1. **暴力枚举**：对每个起始位置，检查是否有 word 匹配 - O(n × m × k)
2. **字典树（Trie）**：构建 Trie，然后在 text 中查找 - O(总字符数)
3. **Python 内置方法**：使用 `str.find()` 或 `str.startswith()` - 简洁高效

## Python 代码实现

### 方法一：暴力枚举（推荐，简单直接）

```python
from typing import List

class Solution:
    def indexPairs(self, text: str, words: List[str]) -> List[List[int]]:
        """
        时间复杂度：O(n × m × k)，n=len(text), m=len(words), k=平均word长度
        空间复杂度：O(结果数量)
        """
        result = []
        
        # 遍历每个起始位置
        for i in range(len(text)):
            # 检查每个 word 是否从位置 i 开始匹配
            for word in words:
                # 检查是否匹配
                if text[i:i+len(word)] == word:
                    result.append([i, i + len(word) - 1])
        
        # 排序（按题目要求）
        result.sort()
        return result
```

### 方法二：使用 startswith

```python
from typing import List

class Solution:
    def indexPairs(self, text: str, words: List[str]) -> List[List[int]]:
        """
        使用 startswith 方法
        """
        result = []
        
        for i in range(len(text)):
            for word in words:
                if text[i:].startswith(word):
                    result.append([i, i + len(word) - 1])
        
        result.sort()
        return result
```

### 方法三：字典树（Trie）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word: str):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_word = True
    
    def search_from(self, text: str, start: int) -> List[int]:
        """从 text[start] 开始查找所有匹配的结束位置"""
        result = []
        node = self.root
        
        for i in range(start, len(text)):
            char = text[i]
            if char not in node.children:
                break
            node = node.children[char]
            if node.is_word:
                result.append(i)
        
        return result

class Solution:
    def indexPairs(self, text: str, words: List[str]) -> List[List[int]]:
        """
        使用 Trie 优化查找
        时间复杂度：O(n × k + 总字符数)
        空间复杂度：O(总字符数)
        """
        # 构建 Trie
        trie = Trie()
        for word in words:
            trie.insert(word)
        
        # 查找所有匹配
        result = []
        for i in range(len(text)):
            end_positions = trie.search_from(text, i)
            for j in end_positions:
                result.append([i, j])
        
        result.sort()
        return result
```

### 方法四：使用集合优化

```python
from typing import List

class Solution:
    def indexPairs(self, text: str, words: List[str]) -> List[List[int]]:
        """
        将 words 转为集合，加速查找
        """
        word_set = set(words)
        result = []
        
        for i in range(len(text)):
            for j in range(i, len(text)):
                if text[i:j+1] in word_set:
                    result.append([i, j])
        
        result.sort()
        return result
```

## 复杂度分析

**方法一和方法二：暴力枚举**
- 时间复杂度：O(n × m × k + R log R)
  - n = len(text)
  - m = len(words)
  - k = 平均word长度
  - R = 结果数量
- 空间复杂度：O(R)

**方法三：字典树**
- 时间复杂度：O(W + n × L)
  - W = 所有 words 的总字符数
  - L = 最长word长度
- 空间复杂度：O(W)

**方法四：集合查找**
- 时间复杂度：O(n² × k)，k 是平均长度
- 空间复杂度：O(m × k)

      root

## 关键点总结

1. **匹配可重叠**：同一个位置可能有多个匹配
2. **排序要求**：先按起始位置，再按结束位置
3. **Trie 优化**：适用于 words 数量多或需要多次查询的场景
4. **Python 技巧**：利用切片和 `startswith` 简化代码

## 易错点

1. **结束索引**：注意是 `[i, j]` 而不是 `[i, len]`，j 是实际字符的索引
2. **重叠匹配**：不要遗漏重叠的匹配情况
3. **排序**：确保结果按要求排序
4. **边界检查**：切片时注意不要越界
