## 题目描述

给你一个下标从 0 开始的字符串 `s`，只包含小写英文字母，以及一个整数 `count`。

如果 `s` 的某个**子字符串**中，每种出现的字符恰好出现 `count` 次，则称该子字符串为**等计数**子字符串。

返回 `s` 中等计数子字符串的数目。

**示例 1：**
```
输入：s = "aaabcbbcc", count = 3
输出：3
解释：子串 "aaabcbbcc"[0:3]="aaa"（1种字符各出现3次），[3:9]="bcbbcc"（b,c各3次），[0:9]（a,b,c各3次）
```

**提示：**
- `1 <= s.length <= 3 * 10^4`
- `1 <= count <= 3 * 10^4`
- `s` 只含小写字母

## 解题思路

**枚举字符种数：** 等计数子字符串中恰好有 `k` 种字符，每种出现 `count` 次，则子串长度 = `k * count`。

枚举 `k` 从 1 到 26，对每个 `k`，找长度为 `k * count` 的子串中，恰好包含 `k` 种字符且每种出现 `count` 次的数量。

**滑动窗口：** 对固定窗口大小 `k * count`，检查窗口内字符分布。

## 代码实现

### 方法一：枚举字符种数 + 滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def equalCountSubstrings(self, s: str, count: int) -> int:
        n = len(s)
        total = 0

        for k in range(1, 27):  # k 种不同字符
            window_size = k * count
            if window_size > n:
                break

            # 滑动窗口检查
            freq = Counter(s[:window_size])
            if len(freq) == k and all(v == count for v in freq.values()):
                total += 1

            for i in range(window_size, n):
                # 加入新字符
                freq[s[i]] += 1
                # 移除旧字符
                freq[s[i - window_size]] -= 1
                if freq[s[i - window_size]] == 0:
                    del freq[s[i - window_size]]

                if len(freq) == k and all(v == count for v in freq.values()):
                    total += 1

        return total
```

### 方法二：前缀和优化（避免 all 检查）

```python
from collections import Counter

class Solution:
    def equalCountSubstrings(self, s: str, count: int) -> int:
        n = len(s)
        total = 0

        for k in range(1, 27):
            window_size = k * count
            if window_size > n:
                break

            freq = Counter()
            exact_count = 0  # 频次恰好为 count 的字符种数

            for i in range(n):
                c = s[i]
                if freq[c] == count:
                    exact_count -= 1
                freq[c] += 1
                if freq[c] == count:
                    exact_count += 1

                # 移出窗口左侧
                if i >= window_size:
                    out_c = s[i - window_size]
                    if freq[out_c] == count:
                        exact_count -= 1
                    freq[out_c] -= 1
                    if freq[out_c] == count:
                        exact_count += 1
                    if freq[out_c] == 0:
                        del freq[out_c]

                # 检查是否满足条件
                if i >= window_size - 1:
                    if len(freq) == k and exact_count == k:
                        total += 1

        return total
```

## 复杂度分析

- 时间复杂度：O(26 * n)，枚举 k 再滑动窗口
- 空间复杂度：O(26)，窗口内字符频次

## 关键点总结

1. 枚举字符种数 `k`（1 到 26），固定窗口大小 `k * count`
2. 滑动窗口维护频次和满足条件的字符数
3. 条件：窗口内恰好有 `k` 种字符，且每种出现 `count` 次

## 易错点

- 枚举的上限是 26（字符种类数）
- 窗口大小超过 n 时停止枚举（`break` 而非 `continue`）
- 维护 `exact_count` 时，需要在更新频次前后分别判断
