## 题目描述

给你一个整数数组 `nums`，返回数组中**最大元素**与**最小元素**的**最大公约数（GCD）**。

**示例 1：**
```
输入：nums = [2,5,6,9,10]
输出：2
解释：最大值 10，最小值 2，gcd(10, 2) = 2
```

**示例 2：**
```
输入：nums = [7,5,6,8,3]
输出：1
解释：最大值 8，最小值 3，gcd(8, 3) = 1
```

**提示：**
- `2 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`

---

## 解题思路

### 核心思想：直接求 max 和 min 的 GCD

找到数组最大值和最小值，调用辗转相除法（欧几里得算法）即可。

Python 3.5+ 的 `math.gcd` 直接可用。

---

## 代码实现

### 方法一：math.gcd（推荐）

```python
import math
from typing import List

class Solution:
    def findGCD(self, nums: List[int]) -> int:
        return math.gcd(max(nums), min(nums))
```

### 方法二：手写辗转相除法

```python
from typing import List

class Solution:
    def findGCD(self, nums: List[int]) -> int:
        def gcd(a: int, b: int) -> int:
            # 辗转相除法（欧几里得算法）
            while b:
                a, b = b, a % b
            return a

        return gcd(max(nums), min(nums))
```

### 方法三：一行代码

```python
import math
from typing import List

class Solution:
    def findGCD(self, nums: List[int]) -> int:
        # max 和 min 内置函数 + math.gcd
        a, b = min(nums), max(nums)
        return math.gcd(a, b)
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n + log(min(a,b))) | O(1) |
| 方法二 | O(n + log(min(a,b))) | O(1) |

---

## 关键点总结

1. 只需找最大值和最小值，无需对整个数组求 GCD
2. 欧几里得算法：`gcd(a, b) = gcd(b, a % b)`，时间 O(log min)
3. Python 提供 `math.gcd` 直接使用

---

## 易错点

- 审题：只需对最大和最小两个数求 GCD，不是全部元素
- `math.gcd` 在 Python 3.5+ 中可用，对负数取绝对值处理
