## 题目描述

给你两个整数数组 `power` 和 `damage`（长度均为 `n`），以及一个整数 `health`。

Bob 有 `health` 点生命值。有 `n` 个敌人，第 `i` 个敌人需要 `power[i]` 点攻击力才能消灭（每回合造成 1 点伤害），每回合对 Bob 造成 `damage[i]` 点伤害。

Bob 每回合只能攻击一个敌人，消灭后该敌人不再造成伤害。

在 Bob 生命值降至 0 之前，Bob 的目标是消灭所有敌人或尽可能减少伤害总量。

返回在**最优策略**下，Bob 受到的**最小总伤害**。

**示例：**
```
输入：power = [3,1,3], damage = [1,2,3], health = 3
输出：6
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= power[i], damage[i] <= 10^4`
- `1 <= health <= 10^8`

## 解题思路

贪心：决定消灭敌人的顺序以最小化总伤害。

设消灭第 i 个敌人需要 `t_i = ceil(power[i] / 1) = power[i]` 回合（每回合造成 1 伤害）。

在消灭敌人 i 之前，所有未被消灭的其他敌人 j 会造成 `t_i * damage[j]` 的额外伤害（实际是重叠时间）。

更精确：如果按顺序 `a, b` 消灭，总伤害为：
- 消灭 a：`t_a * damage_b`（消灭 a 时 b 还在）
- 消灭 b：0（a 已消灭）
- 总额外伤害 = `t_a * damage_b`

按顺序 `b, a` 消灭，总额外伤害 = `t_b * damage_a`

选择额外伤害小的顺序：若 `t_a * damage_b < t_b * damage_a`，则先消灭 a。

即按 `power[i] / damage[i]` 升序排列（或 `power[i] * damage[j] < power[j] * damage[i]`）。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List
import functools

class Solution:
    def minDamage(self, power: List[int], damage: List[int], health: int) -> int:
        n = len(power)
        
        # 按 power[i] / damage[i] 升序排列
        # 比较 i, j：若 power[i] * damage[j] < power[j] * damage[i]，先 i
        enemies = sorted(zip(power, damage), key=lambda x: x[0] / x[1])
        
        total_damage = 0
        time = 0  # 当前时刻
        
        for p, d in enemies:
            time += p  # 消灭该敌人需要 p 回合
            total_damage += d * time  # 该敌人在消灭前（包括消灭时）造成的总伤害
        
        # 但这里 total_damage 包含了消灭每个敌人后的伤害
        # 重新计算：每个敌人在 [0, time_killed] 时间内造成伤害
        # time_killed[i] = sum(power[0..i])（按排序后的顺序）
        # 总伤害 = sum(damage[i] * time_killed[i])
        
        # 上面的计算已经正确了
        
        # 但实际问题中 health 限制了 Bob 的生存，这里题目要求最小伤害
        # 重新理解：Bob 每回合攻击一个敌人（造成 1 点伤害），
        # 同时所有存活的敌人对 Bob 造成伤害
        # Bob 的生命不是约束，我们只需最小化总伤害
        
        # 重新计算总伤害
        total_damage = 0
        time = 0
        for p, d in enemies:
            time += p
            total_damage += d * time
        
        # 减去每个敌人自己消灭后的时间（它们在消灭后不再造成伤害）
        # 实际：总伤害 = sum(d_i * T_i)，其中 T_i 是消灭第 i 个敌人的时刻
        # T_i = sum(p_1 + ... + p_i)（按顺序）
        # 每个敌人在 T_i 时刻前一直造成伤害
        
        return total_damage
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 贪心排序：按 power[i]/damage[i] 升序
2. 总伤害 = sum(damage[i] * 消灭时刻[i])
3. 消灭时刻是按排序顺序的前缀和

## 易错点

1. 排序准则：`p_i / d_i` 升序（比率小的先打）
2. 每个敌人在被消灭的时刻及之前都会造成伤害
