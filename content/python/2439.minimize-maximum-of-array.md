## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，数组由 `n` 个非负整数组成。

每次操作中，你需要：
- 选择一个满足 `1 <= i < n` 的整数 `i`
- 将 `nums[i]` 减 `1`
- 将 `nums[i - 1]` 加 `1`

进行任意次操作后，返回 `nums` 中可能的 **最小** 最大值。

**示例 1：**
```
输入：nums = [3,7,1,6]
输出：5
解释：操作后可得 [5,5,1,6] -> [5,5,3,4] -> [5,5,4,3] 等，最大值最小为 5。
```

**示例 2：**
```
输入：nums = [10,1]
输出：6
```

**提示：**
- `n == nums.length`
- `2 <= n <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

**二分查找 + 贪心验证：**

二分答案 `mid`，验证是否能使所有元素都 <= `mid`：
- 对每个位置 `i`，若 `nums[i] > mid`，超出的部分必须向左传递（由 `i-1` 承担）
- 累积向左传递的值，若 `nums[i]` 加上累计传入的值 > `mid`，则再次溢出向左传
- 若 `nums[0]` 处累计量超限，说明 `mid` 不可行

**贪心公式（数学推导）：**
前 `i+1` 个元素的平均值向上取整就是所需最小最大值：`ceil(sum(nums[:i+1]) / (i+1))`

答案是所有前缀的 `ceil(sum / count)` 的最大值。

## 代码实现

### 方法一：贪心（前缀平均值，推荐）

```python
from typing import List
import math

class Solution:
    def minimizeArrayValue(self, nums: List[int]) -> int:
        # 答案 = max over all i of ceil(prefix_sum[i] / (i+1))
        ans = 0
        prefix_sum = 0
        for i, x in enumerate(nums):
            prefix_sum += x
            # 前 i+1 个元素的平均值向上取整
            ans = max(ans, math.ceil(prefix_sum / (i + 1)))
        return ans
```

### 方法二：二分查找 + 贪心验证

```python
from typing import List

class Solution:
    def minimizeArrayValue(self, nums: List[int]) -> int:
        def can_achieve(mid: int) -> bool:
            """检查是否能使所有元素 <= mid"""
            carry = 0  # 向左侧传递的超量
            for i in range(len(nums) - 1, 0, -1):
                # nums[i] 加上右边传来的...不对，应该从左往右
            # 正确方向：从右往左不行，从左往右
            overflow = 0  # 当前位置需要传给右边的超量
            # 实际上应该是从左往右，携带多余量向右传递是不行的
            # 只能把超量向左传。
            # 从右到左遍历：
            carry = 0
            for i in range(len(nums) - 1, -1, -1):
                total = nums[i] + carry
                if total > mid:
                    if i == 0:
                        return False
                    carry = total - mid  # 超出部分向左传
                else:
                    carry = 0
            return True

        lo, hi = max(nums), sum(nums)
        while lo < hi:
            mid = (lo + hi) // 2
            if can_achieve(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法三：二分（正确实现）

```python
from typing import List

class Solution:
    def minimizeArrayValue(self, nums: List[int]) -> int:
        def feasible(limit: int) -> bool:
            """从左到右，检查能否让每个元素 <= limit"""
            spare = 0  # 可以吸收的额外量（来自右边减下来）
            # 从右往左：每个位置多的可以往左传
            carry = 0
            for i in range(len(nums) - 1, 0, -1):
                val = nums[i] + carry
                if val > limit:
                    carry = val - limit  # 超出的往左传
                else:
                    carry = 0
            return nums[0] + carry <= limit

        lo, hi = 0, max(nums)
        # 注意：lo 应该是 nums[0]
        lo = nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 关键点总结

1. 核心观察：前 k 个元素的总和不能均摊到超过 `max_val * k`，故最大值 >= `ceil(prefix_sum / k)`
2. 答案 = 所有前缀 `ceil(sum/count)` 的最大值
3. 整数除法向上取整：`(a + b - 1) // b`

## 易错点

- 前缀平均值要向上取整
- 超出部分只能向左传（操作是将 i 位减去，i-1 加上），不能向右
