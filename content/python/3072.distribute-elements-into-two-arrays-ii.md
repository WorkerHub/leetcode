## 题目描述

与 3069 相同的分配规则，但规则改为：
- 若 `arr1` 中严格大于 `nums[i]` 的元素个数 > `arr2` 中严格大于 `nums[i]` 的元素个数，追加到 `arr1`
- 否则追加到 `arr2`

数据范围：`nums.length <= 10^5`，`nums[i] <= 10^9`。

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对每个新元素 `nums[i]`，需要快速查询两个数组中大于 `nums[i]` 的元素个数。

使用**树状数组（Fenwick Tree）+ 坐标压缩**：
- 对所有值进行离散化
- 维护两个 BIT（Binary Indexed Tree）分别记录 arr1 和 arr2 的元素分布
- 查询：大于 x 的元素数 = 总数 - 小于等于 x 的元素数

## Python 代码实现

### 方法一：树状数组 + 坐标压缩（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        # 坐标压缩
        sorted_unique = sorted(set(nums))
        rank = {v: i + 1 for i, v in enumerate(sorted_unique)}  # 1-indexed
        m = len(sorted_unique)

        # 树状数组
        class BIT:
            def __init__(self, n):
                self.n = n
                self.tree = [0] * (n + 1)

            def update(self, i, delta=1):
                while i <= self.n:
                    self.tree[i] += delta
                    i += i & (-i)

            def query(self, i) -> int:
                s = 0
                while i > 0:
                    s += self.tree[i]
                    i -= i & (-i)
                return s

            def query_range(self, l, r) -> int:
                if l > r: return 0
                return self.query(r) - self.query(l - 1)

        bit1 = BIT(m)
        bit2 = BIT(m)
        arr1 = [nums[0]]
        arr2 = [nums[1]]
        bit1.update(rank[nums[0]])
        bit2.update(rank[nums[1]])

        for i in range(2, len(nums)):
            v = nums[i]
            r = rank[v]
            # 大于 v 的元素数 = 总数 - 小于等于 v 的元素数
            cnt1 = len(arr1) - bit1.query(r)  # arr1 中大于 v 的个数
            cnt2 = len(arr2) - bit2.query(r)  # arr2 中大于 v 的个数

            if cnt1 > cnt2:
                arr1.append(v)
                bit1.update(r)
            else:
                arr2.append(v)
                bit2.update(r)

        return arr1 + arr2
```

### 方法二：SortedList（Python 内置有序列表）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        sl1 = SortedList([nums[0]])
        sl2 = SortedList([nums[1]])
        arr1 = [nums[0]]
        arr2 = [nums[1]]

        for i in range(2, len(nums)):
            v = nums[i]
            # 大于 v 的元素数 = 总数 - bisect_right(v) 的位置
            cnt1 = len(sl1) - sl1.bisect_right(v)
            cnt2 = len(sl2) - sl2.bisect_right(v)

            if cnt1 > cnt2:
                arr1.append(v)
                sl1.add(v)
            else:
                arr2.append(v)
                sl2.add(v)

        return arr1 + arr2
```

## 复杂度分析

- 时间复杂度：O(n log n)，树状数组每次操作 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 需要动态维护有序集合，支持快速查询大于某值的元素个数
2. 树状数组 + 离散化是经典组合
3. SortedList 的 `bisect_right` 可以快速找插入位置

## 易错点

1. 比较的是"严格大于"，用 `bisect_right` 而非 `bisect_left`
2. 若 `cnt1 == cnt2`，追加到 `arr2`（else 分支）
3. 坐标压缩时用 1-indexed，BIT 查询从 1 开始
