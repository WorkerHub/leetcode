## 题目描述

[LeetCode 1213. Intersection Of Three Sorted Arrays](https://leetcode.com/problems/intersection-of-three-sorted-arrays/)

给定三个严格递增的整数数组 `arr1`、`arr2` 和 `arr3`，返回一个严格递增的数组，该数组包含所有三个数组中共有的整数。

示例 1：
```
输入：arr1 = [1,2,3,4,5], arr2 = [1,2,5,7,9], arr3 = [1,3,4,5,8]
输出：[1,5]
解释：只有 1 和 5 同时出现在三个数组中。
```

示例 2：
```
输入：arr1 = [197,418,523,876,1356], arr2 = [501,880,1593,1710,1870], arr3 = [521,682,1337,1395,1764]
输出：[]
```

提示：
- 1 <= arr1.length, arr2.length, arr3.length <= 1000
- 1 <= arr1[i], arr2[i], arr3[i] <= 2000

## 解题思路

这道题要求找出三个有序数组的交集。由于数组已经排好序，我们可以利用这个特性来优化算法。

核心思路：
1. 利用哈希表统计每个元素在多少个数组中出现
2. 利用三指针同时遍历三个数组
3. 对较短的数组使用二分查找

关键观察：
- 三个数组都是严格递增的，可以利用单调性
- 只需要找出现 3 次的元素
- 交集中的元素必定同时存在于三个数组中

## Python 代码实现

### 方法一：哈希表计数（推荐新手）

```python
from typing import List
from collections import Counter

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        # 方法：使用哈希表统计每个数字出现的次数
        # 将三个数组合并后，统计出现 3 次的元素
        
        # 统计所有元素出现的次数
        count = Counter(arr1 + arr2 + arr3)
        
        # 筛选出现 3 次的元素
        result = [num for num in count if count[num] == 3]
        
        # 排序（由于原数组有序，交集也是有序的）
        return sorted(result)
```

### 方法二：三指针（推荐，空间最优）

```python
from typing import List

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        # 方法：使用三个指针分别遍历三个数组
        # 当三个指针指向的值相等时，说明找到了交集元素
        
        result = []
        i, j, k = 0, 0, 0
        
        while i < len(arr1) and j < len(arr2) and k < len(arr3):
            # 如果三个指针指向的值相等，加入结果
            if arr1[i] == arr2[j] == arr3[k]:
                result.append(arr1[i])
                i += 1
                j += 1
                k += 1
            else:
                # 找出三者中的最小值，移动对应指针
                min_val = min(arr1[i], arr2[j], arr3[k])
                if arr1[i] == min_val:
                    i += 1
                if arr2[j] == min_val:
                    j += 1
                if arr3[k] == min_val:
                    k += 1
        
        return result
```

### 方法三：集合交集（Python 特色）

```python
from typing import List

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        # 方法：利用 Python 集合的交集操作
        # 先求两个集合的交集，再与第三个集合求交集
        
        # 转换为集合并求交集
        intersection = set(arr1) & set(arr2) & set(arr3)
        
        # 转换为有序列表
        return sorted(list(intersection))
```

### 方法四：二分查找优化

```python
from typing import List
import bisect

class Solution:
    def arraysIntersection(self, arr1: List[int], arr2: List[int], arr3: List[int]) -> List[int]:
        # 方法：以最短的数组为基准，在其他两个数组中二分查找
        # 适合三个数组长度差异较大的情况
        
        # 找出最短的数组作为基准
        arrays = sorted([arr1, arr2, arr3], key=len)
        shortest = arrays[0]
        other1 = arrays[1]
        other2 = arrays[2]
        
        result = []
        
        for num in shortest:
            # 在另外两个数组中二分查找
            idx1 = bisect.bisect_left(other1, num)
            idx2 = bisect.bisect_left(other2, num)
            
            # 检查是否找到
            if (idx1 < len(other1) and other1[idx1] == num and
                idx2 < len(other2) and other2[idx2] == num):
                result.append(num)
        
        return result
```

## 复杂度分析

### 方法一：哈希表计数
- 时间复杂度：O(n1 + n2 + n3)，其中 n1、n2、n3 分别是三个数组的长度
- 空间复杂度：O(n1 + n2 + n3)，需要存储所有元素

### 方法二：三指针
- 时间复杂度：O(n1 + n2 + n3)，最坏情况下需要遍历所有元素
- 空间复杂度：O(1)，只使用常数额外空间（不计结果数组）

### 方法三：集合交集
- 时间复杂度：O(n1 + n2 + n3)，需要遍历所有元素
- 空间复杂度：O(n1 + n2 + n3)，需要创建三个集合

### 方法四：二分查找
- 时间复杂度：O(n × log m)，其中 n 是最短数组长度，m 是最长数组长度
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. 利用数组有序的特性，可以使用三指针线性扫描
2. 三指针法每次移动最小值对应的指针，确保不会遗漏元素
3. 当三个数组长度差异很大时，二分查找法更优
4. Python 的集合操作简洁但需要额外空间

## 易错点

1. 忘记数组是严格递增的，可能会写出复杂的去重逻辑
2. 三指针法中，移动指针时要注意可能有多个指针需要同时移动
3. 使用集合交集时要记得最后排序，因为集合是无序的
4. 二分查找后要检查找到的位置是否越界，以及值是否真的相等
