## 题目描述

颠倒给定的 32 位无符号整数的二进制位。

**提示：**
- 请注意，在某些语言（如 Java）中，没有无符号整数类型。在这种情况下，输入和输出都将被指定为有符号整数类型，并且不应影响您的实现，因为无论整数是有符号的还是无符号的，其内部的二进制表示形式都是相同的。
- 在 Java 中，编译器使用二进制补码记法来表示有符号整数。因此，在上面的示例 2 中，输入表示有符号整数 `-3`，输出表示有符号整数 `-1073741825`。

**示例 1：**
```
输入：n = 00000010100101000001111010011100
输出：964176192 (00111001011110000010100101000000)
解释：输入的二进制串 00000010100101000001111010011100 表示无符号整数 43261596，
     因此返回 964176192，其二进制表示形式为 00111001011110000010100101000000。
```

**示例 2：**
```
输入：n = 11111111111111111111111111111101
输出：3221225471 (10111111111111111111111111111111)
解释：输入的二进制串 11111111111111111111111111111101 表示无符号整数 4294967293，
     因此返回 3221225471 其二进制表示形式为 10111111111111111111111111111111 。
```

**提示：**
- 输入是一个长度为 `32` 的二进制字符串

**进阶：**
如果多次调用这个函数，你将如何优化你的算法？

## 解题思路

这道题要求反转 32 位整数的二进制位。核心是**位运算**。

### 方法一：逐位处理

最直观的方法：
1. 从右往左遍历每一位
2. 取出当前位的值（用 `n & 1`）
3. 将这一位放到结果的对应位置
4. 右移原数字，左移结果

### 方法二：分治法

将 32 位分成两部分，递归地交换：
- 将 32 位分为左 16 位和右 16 位，交换
- 每 16 位再分为 8 位，交换
- 每 8 位再分为 4 位，交换
- 依此类推...

### 方法三：查找表（进阶优化）

如果需要多次调用，可以预先计算 8 位（256 种）的反转结果，存入表中。
32 位可以分为 4 个 8 位，分别查表再组合。

## Python 代码实现

### 方法一：逐位反转（推荐新手）⭐

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        """
        逐位提取并反转
        时间复杂度：O(1)，固定 32 次循环
        空间复杂度：O(1)
        """
        result = 0
        
        # 处理 32 位
        for i in range(32):
            # 取出 n 的最低位
            bit = n & 1
            
            # 将这一位放到 result 的对应位置
            # result 先左移，然后加上当前位
            result = (result << 1) | bit
            
            # n 右移一位，处理下一位
            n >>= 1
        
        return result
```

### 方法二：不用循环的写法

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        """
        用位运算公式一次性计算
        更简洁但不易理解
        """
        result = 0
        for _ in range(32):
            result = (result << 1) + (n & 1)
            n >>= 1
        return result
```

### 方法三：分治法（进阶）⭐

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        """
        分治法：通过位掩码和移位操作实现
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        # 交换相邻的位
        n = ((n & 0xaaaaaaaa) >> 1) | ((n & 0x55555555) << 1)
        # 交换相邻的 2 位
        n = ((n & 0xcccccccc) >> 2) | ((n & 0x33333333) << 2)
        # 交换相邻的 4 位
        n = ((n & 0xf0f0f0f0) >> 4) | ((n & 0x0f0f0f0f) << 4)
        # 交换相邻的 8 位
        n = ((n & 0xff00ff00) >> 8) | ((n & 0x00ff00ff) << 8)
        # 交换相邻的 16 位
        n = (n >> 16) | ((n & 0x0000ffff) << 16)
        
        return n
```

### 方法四：Python 字符串处理（不推荐但简洁）

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        """
        转换为二进制字符串，反转后转回整数
        不符合位运算的练习目的，但代码简洁
        """
        # 转为 32 位二进制字符串
        binary = bin(n)[2:].zfill(32)
        
        # 反转
        reversed_binary = binary[::-1]
        
        # 转回整数
        return int(reversed_binary, 2)
```

### 方法五：查找表优化（多次调用时使用）

```python
class Solution:
    def __init__(self):
        # 预计算 8 位的所有反转结果（0-255）
        self.lookup = [0] * 256
        for i in range(256):
            result = 0
            for j in range(8):
                result = (result << 1) | (i & 1)
                i >>= 1
            self.lookup[i] = result
    
    def reverseBits(self, n: int) -> int:
        """
        使用查找表，将 32 位分为 4 个 8 位处理
        多次调用时效率更高
        """
        result = 0
        for i in range(4):
            # 取出 8 位
            byte = n & 0xff
            # 查表获取反转后的值
            result = (result << 8) | self.lookup[byte]
            # 处理下一个 8 位
            n >>= 8
        return result
```

## 复杂度分析

**方法一、二（逐位处理）：**
- **时间复杂度**：O(1)，固定循环 32 次
- **空间复杂度**：O(1)

**方法三（分治法）：**
- **时间复杂度**：O(1)，固定 5 次操作
- **空间复杂度**：O(1)

**方法五（查找表）：**
- **时间复杂度**：O(1)，每次查询 4 次表
- **空间复杂度**：O(1)，固定 256 个元素的表

## 关键点总结

1. **位运算基础**：
   - `n & 1`：取最低位
   - `n >> 1`：右移一位
   - `result << 1`：左移一位
   - `|`：按位或（合并结果）

2. **固定位数**：题目明确是 32 位，所以时间复杂度是 O(1)

3. **分治思想**：将大问题分解为小问题递归解决

4. **空间换时间**：查找表适合多次调用的场景

5. **Python 特性**：虽然可以用字符串，但不利于学习位运算

## 易错点

1. **循环次数错误**：必须是 32 次，不能是 31 次
   ```python
   for i in range(32):  # ✅ 32 位
   for i in range(31):  # ❌ 少了一位
   ```

2. **位移顺序错误**：先左移结果，再或上新位
   ```python
   result = (result << 1) | bit  # ✅
   result = result | (bit << 1)  # ❌ 错误
   ```

3. **忘记处理高位的 0**：即使高位是 0 也要处理
   ```python
   # 必须循环 32 次，即使 n 变为 0 也要继续
   for i in range(32):
       # ...
   ```

4. **Python 整数无限精度问题**：Python 的 int 没有位数限制
   ```python
   # 如果需要确保 32 位，可以：
   return result & 0xFFFFFFFF
   ```

5. **分治法的掩码错误**：掩码必须准确
   ```python
   0xaaaaaaaa  # ✅ 10101010... (32 位)
   0xaaa       # ❌ 只有 12 位
   ```
