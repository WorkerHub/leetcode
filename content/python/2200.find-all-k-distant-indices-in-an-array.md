## 题目描述

给你一个下标从 **0** 开始、长度为 `n` 的整数数组 `nums` 以及两个整数 `key` 和 `k`。

**k 距离下标**：若存在满足以下条件的下标 `j`，则称下标 `i` 为 k 距离下标：
- `|i - j| <= k`
- `nums[j] == key`

返回**升序**排列的所有 k 距离下标。

**示例 1：**
```
输入：nums = [3,4,9,1,3,9,5], key = 9, k = 1
输出：[1,2,3,4,5,6]
解释：9 出现在下标 2 和 5：
- 下标 2 周围 k=1 范围：[1,3]
- 下标 5 周围 k=1 范围：[4,6]
合并：[1,2,3,4,5,6]
```

**示例 2：**
```
输入：nums = [2,2,2,2,2], key = 2, k = 2
输出：[0,1,2,3,4]
```

**提示：**
- `1 <= n <= 1000`
- `1 <= nums[i] <= 1000`
- `key` 是 `nums` 中的一个数
- `1 <= k <= n`

## 解题思路

**方法一：枚举 key 的位置，标记范围**

找到所有 `nums[j] == key` 的下标 `j`，将 `[max(0, j-k), min(n-1, j+k)]` 范围内的下标加入结果集合。

**方法二：双指针**

先收集所有 `key` 的位置，然后用双指针从左到右扫描，维护当前有效的 key 下标范围。

## 代码实现

### 方法一：标记法（推荐）

```python
from typing import List

class Solution:
    def findKDistantIndices(self, nums: List[int], key: int, k: int) -> List[int]:
        n = len(nums)
        result = set()

        for j in range(n):
            if nums[j] == key:
                # 将 j 的 k 范围内所有下标加入结果
                for i in range(max(0, j - k), min(n - 1, j + k) + 1):
                    result.add(i)

        return sorted(result)
```

### 方法二：双指针（避免重复遍历）

```python
from typing import List

class Solution:
    def findKDistantIndices(self, nums: List[int], key: int, k: int) -> List[int]:
        n = len(nums)
        # 收集所有 key 的位置
        key_positions = [j for j in range(n) if nums[j] == key]

        result = []
        ptr = 0  # key_positions 的指针

        for i in range(n):
            # 更新指针：跳过 i - k > key_positions[ptr] 的 key
            while ptr < len(key_positions) and key_positions[ptr] < i - k:
                ptr += 1
            # 检查是否存在距离 <= k 的 key
            if ptr < len(key_positions) and key_positions[ptr] <= i + k:
                result.append(i)

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 标记法 | O(n * k) | O(n) |
| 双指针 | O(n) | O(n)（存储 key 位置） |

## 关键点总结

1. 找出所有 `key` 的位置，对每个位置扩展范围 `[j-k, j+k]`。
2. 双指针方法：对每个下标 `i`，维护满足 `|i-j| <= k` 的 key 下标集合，用滑动窗口优化。
3. 结果需要升序且无重复。

## 易错点

- 范围越界：`max(0, j-k)` 和 `min(n-1, j+k)` 处理边界。
- 用 `set` 去重或双指针直接避免重复。
