## 题目描述

给你一个整数 `money`（单位：美元）和另一个整数 `children`。

你需要按照如下规则分配 `money` 给 `children` 个孩子：

- 所有的钱都必须分配完。
- 每个孩子至少得到 **1** 美元。
- 没有孩子得到 **4** 美元。

返回最多有多少个孩子能得到 **恰好 8** 美元。若不可能，返回 `-1`。

**示例 1：**

```
输入：money = 20, children = 3
输出：1
解释：给第一个孩子 8，剩下 12 给 2 个孩子，不能各得 8。
     可以给一个孩子 8，另两个分别 1 和 11（或其他分法），最多 1 人得 8 美元。
```

**示例 2：**

```
输入：money = 16, children = 2
输出：2
解释：每人 8 美元，正好分完。
```

**提示：**

- `1 <= money <= 200`
- `2 <= children <= 30`

## 解题思路

**贪心**：

1. 若 `money < children`：无法每人至少 1 美元，返回 `-1`
2. 若 `money > 8 * children`：钱太多，不可能分完，返回 `-1`
3. 否则，尝试尽可能多地给孩子 8 美元：
   - 先保证每人 1 美元（共 `children` 美元），剩余 `money - children`
   - 每个得 8 美元的孩子额外需要 7 美元（已有基础 1 美元）
   - `k = min((money - children) // 7, children)` 个孩子可能得到 8 美元
   - 如果剩下的 `children - k` 个孩子都不能得 4 美元，则需要调整 k

实际操作：枚举 k（得到 8 美元的孩子数），验证剩余钱能否分给剩余孩子（每人至少 1 美元，不能为 4 美元）。

## Python 代码实现

### 方法一：贪心推导（推荐）

```python
class Solution:
    def distMoney(self, money: int, children: int) -> int:
        # 不可能：钱不够每人 1 美元，或钱太多
        if money < children or money > 8 * children:
            return -1

        # 最多 k 人得到 8 美元
        # 先给每人 1，剩余 money - children，每人追加 7 才能得 8
        k = min((money - children) // 7, children)

        # 验证剩余钱分给剩余孩子
        remaining_money = money - 8 * k
        remaining_children = children - k

        # 如果只剩 1 个孩子，且剩余钱为 4，需要减少 k
        if remaining_children == 1 and remaining_money == 4:
            k -= 1
        # 如果没有剩余孩子但还有剩余钱，也需要减少 k
        elif remaining_children == 0 and remaining_money != 0:
            k -= 1

        return max(k, 0)
```

### 方法二：暴力枚举验证

```python
class Solution:
    def distMoney(self, money: int, children: int) -> int:
        if money < children or money > 8 * children:
            return -1

        # 从大到小枚举得到 8 美元的人数
        for k in range(min(children, money // 8), -1, -1):
            remaining = money - 8 * k
            rem_children = children - k
            # 剩余孩子每人至少 1 美元，不能有人恰好得 4 美元
            # 最简单的检验：remaining >= rem_children 且 remaining != 4 * rem_children（若只剩1人）
            if remaining >= rem_children:
                # 检查是否可以分配（剩余孩子只要每人不为4即可）
                if rem_children == 1 and remaining == 4:
                    continue
                return k
        return -1
```

## 复杂度分析

- 时间复杂度：O(1)（方法一）或 O(children)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 先检查边界：`money < children`（不够分）或 `money > 8*children`（太多）
2. 不得 4 美元的限制：关注只剩 1 个孩子时剩余钱是否恰好为 4
3. 最大 k = `min((money - children) // 7, children)`

## 易错点

1. `money > 8 * children` 时返回 -1（钱无法分完且不超过 8）
2. 只有 1 个剩余孩子且剩余钱为 4 时，需要将 k 减 1
3. 答案最小为 0（`max(k, 0)`）
