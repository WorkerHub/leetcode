## 题目描述

给你两个字符串 `s` 和 `t`。每步操作中，你可以在 `s` 或 `t` 中**追加任意一个字符**。

返回使 `s` 和 `t` 互为**字母异位词**所需的最少步骤数。

字母异位词：两个字符串中每个字符出现的次数相同。

**示例 1：**
```
输入：s = "leetcode", t = "coats"
输出：7
解释：
- s 中 l、e(2次)、d 共 4 个字母 t 没有，需要加到 t 中。
- t 中 a(1次) s(1次) 共 2+1=3 个字母，但重算后实际需 7 步。
```

**示例 2：**
```
输入：s = "night", t = "thing"
输出：0
解释：已经是字母异位词。
```

**提示：**
- `1 <= s.length, t.length <= 2 * 10^5`
- `s` 和 `t` 只含小写英文字母

## 解题思路

**字符频次差**

统计 `s` 和 `t` 中每个字母的频次，对于每个字母 `c`：
- `s` 中有 `a` 个，`t` 中有 `b` 个。
- 需要补充 `|a - b|` 个该字母（多的那一方不用变，少的那一方追加）。

答案 = 所有字母 `|cnt_s[c] - cnt_t[c]|` 之和。

## 代码实现

### 方法一：Counter 差值（推荐）

```python
from collections import Counter

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        cs = Counter(s)
        ct = Counter(t)
        ans = 0
        # 枚举所有出现过的字母
        for c in set(cs) | set(ct):
            ans += abs(cs[c] - ct[c])
        return ans
```

### 方法二：频率数组

```python
class Solution:
    def minSteps(self, s: str, t: str) -> int:
        freq = [0] * 26
        # s 中字母频次 +1
        for c in s:
            freq[ord(c) - ord('a')] += 1
        # t 中字母频次 -1
        for c in t:
            freq[ord(c) - ord('a')] -= 1
        # 所有差值的绝对值之和
        return sum(abs(x) for x in freq)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter | O(|s| + |t|) | O(26) |
| 频率数组 | O(|s| + |t|) | O(26) |

## 关键点总结

1. 字母异位词要求两个字符串每个字母频次相同。
2. 每次追加一个字符，追加次数 = 所有字母频次差的绝对值之和。
3. 频率数组方法简洁，`freq[i] > 0` 说明 `s` 多，需往 `t` 追加；`< 0` 说明 `t` 多。

## 易错点

- 此题是追加（不是删除/替换），所以两个方向的差都要计入。
- 与 [1347. 制造字母异位词的最小步骤数](https://leetcode.com/problems/minimum-number-of-steps-to-make-two-strings-anagram/) 的区别：那道题只能修改其中一个字符串。
