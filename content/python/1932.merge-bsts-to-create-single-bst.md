## 题目描述

给你 `n` 棵**二叉搜索树的根节点**组成的列表 `trees`，它们满足：
- 每棵树只有 2 或 3 个节点（根和至多两个叶节点）
- 所有树的叶节点值互不相同，也和其他树的根节点值互不相同

你可以执行以下操作：
- 选择两棵树，其中一棵树的**叶节点值**等于另一棵树的**根节点值**
- 将该叶节点替换为另一棵树（删除被替换的树）

返回合并后的 BST 根节点，如果无法合并成合法的 BST，返回 `null`。

**提示：**
- `n` 棵树，`1 <= trees.length <= 5 * 10^4`

---

## 解题思路

### 核心思想：哈希表 + 合并 + BST 验证

1. 用哈希表记录每个根节点值对应的树根
2. 找出只作为根、不作为任何树的叶节点值的那棵树（唯一候选根）
3. DFS 合并：遇到叶节点时，若其值在哈希表中有对应树根，则替换
4. 验证结果是否是合法 BST（中序遍历严格递增）

## 代码实现

### 方法一：哈希表合并 + BST 验证（推荐）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def canMerge(self, trees: List[TreeNode]) -> Optional[TreeNode]:
        # 根值到树根的映射
        root_map = {t.val: t for t in trees}

        # 统计所有叶节点值（作为叶子出现的节点）
        leaf_vals = set()
        for t in trees:
            if t.left:
                leaf_vals.add(t.left.val)
            if t.right:
                leaf_vals.add(t.right.val)

        # 找候选根：根值不出现在任何叶节点值中
        candidates = [t for t in trees if t.val not in leaf_vals]
        if len(candidates) != 1:
            return None

        root = candidates[0]

        def dfs(node: TreeNode, lo: int, hi: int) -> bool:
            """合并并验证 BST：lo < node.val < hi"""
            if node is None:
                return True
            if not (lo < node.val < hi):
                return False

            # 如果是叶节点且在映射中，替换为对应子树
            if node.left is None and node.right is None:
                if node.val in root_map and root_map[node.val] is not node:
                    sub = root_map[node.val]
                    node.left = sub.left
                    node.right = sub.right
                    del root_map[node.val]

            return dfs(node.left, lo, node.val) and dfs(node.right, node.val, hi)

        del root_map[root.val]  # 候选根从映射中删除

        if dfs(root, 0, float('inf')) and not root_map:
            # root_map 中剩余的树没有被合并，说明多余
            return root
        return None
```

### 方法二：中序遍历验证

```python
class Solution:
    def canMerge(self, trees: List[TreeNode]) -> Optional[TreeNode]:
        root_map = {t.val: t for t in trees}
        leaf_vals = set()
        for t in trees:
            if t.left: leaf_vals.add(t.left.val)
            if t.right: leaf_vals.add(t.right.val)

        candidates = [t for t in trees if t.val not in leaf_vals]
        if len(candidates) != 1:
            return None

        root = candidates[0]

        # 用中序遍历（迭代）合并并验证
        inorder = []
        stack = []
        node = root
        # 先做合并（DFS 展开所有叶节点）
        used = set()

        def expand(node):
            """递归展开叶节点"""
            if node is None:
                return
            if node.left is None and node.right is None and node.val in root_map and root_map[node.val] is not node:
                sub = root_map.pop(node.val)
                node.left = sub.left
                node.right = sub.right
            expand(node.left)
            expand(node.right)

        root_map.pop(root.val, None)
        expand(root)

        # 中序遍历验证严格递增
        prev = [0]
        valid = [True]

        def inorder_check(node):
            if node is None or not valid[0]:
                return
            inorder_check(node.left)
            if node.val <= prev[0]:
                valid[0] = False
            prev[0] = node.val
            inorder_check(node.right)

        inorder_check(root)
        return root if valid[0] and not root_map else None
```

## 关键点总结

1. 合法合并后只有一棵树，候选根是不被任何叶节点引用的根
2. 合并时把叶节点替换为对应树根的子节点（非树根本身）
3. 最终验证是否为合法 BST（中序严格递增）且所有树都被使用

---

## 易错点

- 候选根必须唯一（恰好 1 个不被引用的根）
- 替换叶节点时，是把对应树的左右子树接上来，不是树根本身
- 必须验证所有树都被合并（`root_map` 为空）
