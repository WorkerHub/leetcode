## 题目描述

给定一个整数数组 `nums` 和整数 `k`。将数组分成若干个连续子数组（分区），使得每个子数组中最大值和最小值之差不超过 `k`。求满足条件的分区数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：nums = [1, 2, 3, 4], k = 1
输出：1
解释：唯一的合法分区是 [[1,2],[3,4]]，差为1。
     [[1],[2,3],[4]]：[2,3]差=1，合法；[[1],[2],[3],[4]]：每个差=0，合法...
     实际计算后答案为 4。
```

**示例 2：**

```
输入：nums = [2, 1, 3], k = 1
输出：2
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

动态规划 + 单调队列。

`dp[i]` = 将前 `i` 个元素分区的方案数。

转移：`dp[i] = sum(dp[j])` for all `j` 使得 `max(nums[j..i-1]) - min(nums[j..i-1]) <= k`。

即合法的最右起点 `j` 需要满足：`max(nums[j..i-1]) - min(nums[j..i-1]) <= k`。

关键：随着 `j` 从 `i-1` 向左移动，`max - min` 是单调不减的。用二分法或双端队列找左边界。

维护两个单调队列（分别追踪最大值和最小值），确定合法的 `j` 范围，然后用前缀和 O(1) 求 dp 之和。

## Python 代码实现

### 方法一：单调队列 + 前缀和（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        dp = [0] * (n + 1)
        dp[0] = 1
        prefix = [0] * (n + 2)
        prefix[1] = 1

        max_dq = deque()  # 单调递减（追踪最大值）
        min_dq = deque()  # 单调递增（追踪最小值）
        left = 0  # 合法的最左起点

        for right in range(n):
            # 更新单调队列
            while max_dq and nums[max_dq[-1]] <= nums[right]:
                max_dq.pop()
            max_dq.append(right)

            while min_dq and nums[min_dq[-1]] >= nums[right]:
                min_dq.pop()
            min_dq.append(right)

            # 维护 left：确保 [left, right] 的 max - min <= k
            while nums[max_dq[0]] - nums[min_dq[0]] > k:
                left += 1
                if max_dq[0] < left:
                    max_dq.popleft()
                if min_dq[0] < left:
                    min_dq.popleft()

            # dp[right+1] = sum(dp[left..right])
            # = prefix[right+1] - prefix[left]
            dp[right + 1] = (prefix[right + 1] - prefix[left] + MOD) % MOD
            prefix[right + 2] = (prefix[right + 1] + dp[right + 1]) % MOD

        return dp[n]
```

### 方法二：暴力 DP（适合小数据）

```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        dp = [0] * (n + 1)
        dp[0] = 1

        for i in range(1, n + 1):
            cur_max = cur_min = nums[i-1]
            for j in range(i - 1, -1, -1):
                cur_max = max(cur_max, nums[j])
                cur_min = min(cur_min, nums[j])
                if cur_max - cur_min > k:
                    break
                dp[i] = (dp[i] + dp[j]) % MOD

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)，DP 数组和前缀和

## 关键点总结

1. 单调队列维护滑动窗口的最大值和最小值
2. 双指针 `left` 确保窗口合法（max - min <= k）
3. 前缀和快速计算 dp 区间求和

## 易错点

1. 单调队列的弹出条件：`left` 移动后，队头过期需要弹出
2. 前缀和的初始化：`prefix[1] = dp[0] = 1`
3. 取模时注意负数：`(a - b + MOD) % MOD`
