## 题目描述

给你一个字符串数组 `words` 和一个字符串 `pref`。

返回 `words` 中以 `pref` 作为**前缀**的字符串数目。

字符串 `s` 的**前缀**就是 `s` 的任一前导连续子字符串。

**示例 1：**
```
输入：words = ["pay","attention","practice","attend"], pref = "at"
输出：2
解释：以 "at" 开头的单词有 "attention" 和 "attend"，共 2 个。
```

**示例 2：**
```
输入：words = ["leetcode","win","loops","success"], pref = "code"
输出：0
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length, pref.length <= 100`
- `words[i]` 和 `pref` 只含小写英文字母

## 解题思路

**直接判断前缀**

遍历 `words`，用 `str.startswith()` 或手动字符串切片判断是否以 `pref` 开头，统计数量。

## 代码实现

### 方法一：startswith（推荐）

```python
from typing import List

class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        # startswith 方法直接判断前缀
        return sum(1 for w in words if w.startswith(pref))
```

### 方法二：切片比较

```python
from typing import List

class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        n = len(pref)
        count = 0
        for w in words:
            # 取 w 的前 n 个字符与 pref 比较
            if w[:n] == pref:
                count += 1
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| startswith | O(n * m)，n 为单词数，m 为 pref 长度 | O(1) |
| 切片 | O(n * m) | O(m) |

## 关键点总结

1. `str.startswith(pref)` 是 Python 内置方法，直接使用最简洁。
2. 切片 `w[:len(pref)] == pref` 等价，但会额外创建子字符串。
3. 本题数据规模小，两种方法效率相同。

## 易错点

- 切片方法中要先计算 `len(pref)`，避免在循环内重复计算。
- 注意 pref 比 w 更长的情况：`w[:n]` 会比 `pref` 短，自然不等，无需特判。
