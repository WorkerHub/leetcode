## 题目描述

给你两个字符串列表 `positive_feedback` 和 `negative_feedback`，分别包含若干表示**正面**和**负面**反馈的词汇。

同一个词不会同时出现在正面和负面列表中。

还有 `n` 个学生的报告，表示为字符串列表 `report`，以及一个整数数组 `student_id` 和正整数 `k`。

每个学生的报告分数由以下规则计算：
- 出现一个正面词汇，得 3 分
- 出现一个负面词汇，扣 1 分

返回得分 **最高** 的前 `k` 名学生的 id 列表，按分数 **降序** 排列，若分数相同按学生 id **升序** 排列。

**示例：**

```
输入：positive_feedback = ["smart","brilliant","studious"]
      negative_feedback = ["not"]
      report = ["this student is not studious","the student is smart"]
      student_id = [1,2], k = 2
输出：[2, 1]
```

**提示：**

- `1 <= positive_feedback.length, negative_feedback.length <= 10^4`
- `1 <= report.length <= 10^4`
- `1 <= student_id.length == report.length <= 10^4`
- `k <= student_id.length`

## 解题思路

将正面词汇和负面词汇存入集合，对每个报告按空格分词后统计得分。最后按 (分数降序, id 升序) 排序取前 k 个。

## Python 代码实现

### 方法一：集合 + 排序（推荐）

```python
from typing import List

class Solution:
    def topStudents(self, positive_feedback: List[str], negative_feedback: List[str],
                    report: List[str], student_id: List[int], k: int) -> List[int]:
        pos_set = set(positive_feedback)
        neg_set = set(negative_feedback)

        scores = []
        for sid, rep in zip(student_id, report):
            score = 0
            for word in rep.split():
                if word in pos_set:
                    score += 3
                elif word in neg_set:
                    score -= 1
            scores.append((-score, sid))  # 负分数便于升序排列

        scores.sort()
        return [sid for _, sid in scores[:k]]
```

### 方法二：使用堆（适合 k 远小于 n 时）

```python
from typing import List
import heapq

class Solution:
    def topStudents(self, positive_feedback: List[str], negative_feedback: List[str],
                    report: List[str], student_id: List[int], k: int) -> List[int]:
        pos_set = set(positive_feedback)
        neg_set = set(negative_feedback)

        # 最小堆：(分数, -id)，保留分数最高的 k 个
        heap = []
        for sid, rep in zip(student_id, report):
            score = 0
            for word in rep.split():
                if word in pos_set:
                    score += 3
                elif word in neg_set:
                    score -= 1
            heapq.heappush(heap, (score, -sid))
            if len(heap) > k:
                heapq.heappop(heap)

        # 从堆中取出，按分数降序、id 升序
        result = sorted(heap, key=lambda x: (-x[0], x[1]))
        return [-sid for _, sid in result]
```

## 复杂度分析

- 时间复杂度：O(n * L + n log n)，L 为报告平均词数
- 空间复杂度：O(n + P + N)，P 和 N 为正/负反馈词汇数

## 关键点总结

1. 使用集合存储正/负词汇，单词查找 O(1)
2. 排序键：先按分数降序，再按学生 id 升序
3. 可用 `(-score, sid)` 作为排序元组，自然满足排序要求

## 易错点

1. 报告需要按空格分词，`report.split()` 处理多个空格时也正确
2. 同一报告中同一词可多次计分
3. 排序是降分数+升 id，不能只排一个维度
