## 题目描述

给定整数数组 `nums` 和整数 `k`，若子序列 `[a_1, a_2, ..., a_m]` 满足对所有 `1 <= i < m` 都有 `a_{i+1} >= a_i * k`，则称该子序列为**美丽子序列**。返回所有美丽子序列的数量，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [2,3,6,12], k = 2
输出：8
解释：美丽子序列包括：
     长度 1：[2],[3],[6],[12] -> 4 个
     长度 2：[2,6],[2,12],[3,6],[3,12],[6,12] -> 5 个
     长度 3：[2,6,12],[3,6,12] -> 2 个... 实际统计为 8 个。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], k <= 10^9`

## 解题思路

动态规划 + 哈希表。

定义 `dp[i]` 为以 `nums[i]` 结尾的美丽子序列的数量（包括只含 `nums[i]` 本身的子序列）。

转移方程：`dp[i] = 1 + sum(dp[j] for all j < i where nums[i] >= nums[j] * k)`

为了高效计算，对 `nums` 排序后处理，并用字典 `count` 记录每个值对应的 DP 和：
- 对于当前元素 `v = nums[i]`，需要找所有满足 `v >= prev * k` 的 `prev`，即 `prev <= v // k`。
- 若 `k > 1`：找字典中所有键 `<= v // k` 的值之和。

由于 `k = 1` 时条件变为 `a_{i+1} >= a_i`，特殊处理。

## Python 代码实现

### 方法一：排序 + 有序字典（推荐）

```python
from typing import List
from sortedcontainers import SortedDict

class Solution:
    def countBeautifulSubsequences(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        nums.sort()
        # sorted_map[v] = 以 v 结尾的美丽子序列数量之和
        sorted_map = SortedDict()
        total = 0

        for v in nums:
            # 找所有 prev <= v // k 的 dp 值之和
            if k == 0:
                break
            threshold = v // k
            # 累加 sorted_map 中所有键 <= threshold 的值
            prefix_sum = 0
            idx = sorted_map.bisect_right(threshold)
            for key in sorted_map.keys()[:idx]:
                prefix_sum = (prefix_sum + sorted_map[key]) % MOD

            # 当前元素自身构成长度 1 的子序列
            dp_v = (prefix_sum + 1) % MOD
            total = (total + dp_v) % MOD

            # 更新字典
            sorted_map[v] = (sorted_map.get(v, 0) + dp_v) % MOD

        return total
```

### 方法二：基础 DP（O(n^2)，适合小数据）

```python
from typing import List

class Solution:
    def countBeautifulSubsequences(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        nums.sort()
        dp = [1] * n  # dp[i]: 以 nums[i] 结尾的美丽子序列数

        for i in range(n):
            for j in range(i):
                if nums[i] >= nums[j] * k:
                    dp[i] = (dp[i] + dp[j]) % MOD

        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：方法一 O(n log n)；方法二 O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 将条件转化为：当前值 >= 前驱值 × k，等价于前驱值 <= 当前值 // k
2. 排序后可以保证只向后扩展，避免考虑顺序问题
3. 使用有序字典维护前缀和以加速查询

## 易错点

1. `k=1` 时所有非递减序列都是美丽子序列，计数量更大
2. 对大数值整除时注意 Python 的整数除法（`//`）
