## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，表示地图，`grid[i][j]` 为 0 表示墙，否则表示该格子的商品价格。

你从 `start = [row, col]` 出发，目标是购买 `k` 件最高排名的商品，商品排名规则：

1. 距离 start 更近。
2. 距离相同时，价格更低。
3. 价格也相同时，行下标更小。
4. 行下标也相同时，列下标更小。

价格在 `[low, high]` 范围内的商品才可购买（`0` 为墙，不计入）。

返回 `k` 件最高排名商品的坐标（按排名顺序）。

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 500`
- `0 <= grid[i][j] <= 10^6`
- `0 <= row < m`
- `0 <= col < n`
- `1 <= k <= m * n`
- `1 <= low <= high <= 10^6`

## 解题思路

**BFS + 排序**

从 start 出发做 BFS，记录可达且价格在 `[low, high]` 范围内的商品及其距离。按排名规则排序后取前 k 个。

## 代码实现

### 方法一：BFS + 排序（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def highestRankedKItems(self, grid: List[List[int]], pricing: List[int], start: List[int], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        low, high = pricing
        sr, sc = start
        
        # BFS
        visited = [[False] * n for _ in range(m)]
        visited[sr][sc] = True
        queue = deque([(sr, sc, 0)])  # (行, 列, 距离)
        items = []  # 可购买的商品列表：(距离, 价格, 行, 列)

        while queue:
            r, c, dist = queue.popleft()
            price = grid[r][c]
            # 若当前格子有商品且价格在范围内
            if low <= price <= high:
                items.append((dist, price, r, c))
            # 继续 BFS（即使当前格子是墙，也不会到达，因为墙被过滤）
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc] and grid[nr][nc] != 0:
                    visited[nr][nc] = True
                    queue.append((nr, nc, dist + 1))

        # 按 (距离, 价格, 行, 列) 排序
        items.sort()
        return [[r, c] for dist, price, r, c in items[:k]]
```

### 方法二：堆优化

```python
from typing import List
from collections import deque
import heapq

class Solution:
    def highestRankedKItems(self, grid: List[List[int]], pricing: List[int], start: List[int], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        low, high = pricing
        sr, sc = start

        visited = set([(sr, sc)])
        queue = deque([(sr, sc, 0)])
        items = []

        while queue:
            r, c, dist = queue.popleft()
            price = grid[r][c]
            if low <= price <= high:
                heapq.heappush(items, (dist, price, r, c))
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if (0 <= nr < m and 0 <= nc < n
                        and (nr, nc) not in visited
                        and grid[nr][nc] != 0):
                    visited.add((nr, nc))
                    queue.append((nr, nc, dist + 1))

        result = []
        while items and len(result) < k:
            dist, price, r, c = heapq.heappop(items)
            result.append([r, c])
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS + 排序 | O(m*n*log(m*n)) | O(m*n) |

## 关键点总结

1. BFS 保证按最短距离遍历，天然得到距离信息。
2. 排序关键字：(距离, 价格, 行, 列)，直接利用 Python 元组比较。
3. 墙（值为 0）不能通过，起点本身的价格也要检查。

## 易错点

- 起点 `start` 本身的价格也要检查（若在范围内则加入商品列表）。
- BFS 中，当前格子为墙时已经被过滤（加入 queue 前检查），但如果 start 是墙则需特殊处理（题目一般保证 start 不是墙）。
