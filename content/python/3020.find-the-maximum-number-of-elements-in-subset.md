## 题目描述

给你一个正整数数组 `nums`。

你需要从 `nums` 中选取一个子集，满足以下条件：

- 子集元素可以排列成 `[x, x^2, x^4, ..., x^(2^k), ..., x^(2^k), ..., x^4, x^2, x]` 这样的形式，即满足"回文"结构
- 子集中每个 `x^(2^i)` 出现的次数必须足够

返回满足条件的最长子集长度。

**详细说明：** 序列形如 `x, x^2, x^4, ..., x^k, ..., x^4, x^2, x`，其中中间元素 `x^k` 只出现一次（或者不出现，整个序列长度为奇数）。如果 `x = 1`，则序列中所有元素均为 1，长度为 1 的奇数个 1 也满足。

**示例 1：**
```
输入：nums = [5,4,1,2,2,4,1,5]
输出：7
```

**示例 2：**
```
输入：nums = [1,1,1]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对于每个数 `x` 作为序列起始，构建序列 `x, x^2, x^4, ...`，直到某个元素不在数组中或次数不够 2 次（最后一个中间元素可以只有 1 次）。

特殊情况：`x = 1`，序列全为 1，长度为 `count(1)`（奇数取最近的奇数）。

步骤：
1. 用哈希表统计每个数出现的次数
2. 枚举每个可能的起始值 `x`
3. 构建序列：`x, x^2, x^4, ...`，每级需要至少 2 个（两端各一个）
4. 找到第一个次数 < 2 的，可以作为中间值（+1）

## Python 代码实现

### 方法一：哈希表枚举（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        count = Counter(nums)
        ans = 1  # 至少能选 1 个元素

        for x in count:
            if x == 1:
                # 特殊情况：全为 1，取奇数个
                # 若 count[1] >= 1，至少选 1
                # 若 count[1] >= 3，选 3，以此类推
                v = count[1]
                # 最多选 v 个，且结果为奇数（回文中心只有一个）
                # 实际上全 1 序列，可以选 1, 3, 5, ... 个
                ans = max(ans, v if v % 2 == 1 else v - 1)
                continue

            # 构建序列 x, x^2, x^4, ...
            length = 0
            cur = x
            while cur in count:
                if count[cur] >= 2:
                    length += 2  # 两端各一个
                    # 检查是否溢出（cur * cur 可能超出范围）
                    if cur > 10 ** 9 // cur:  # cur * cur > 10^9
                        # 下一个已超出范围，不可能在数组中
                        length += 1  # 当前 cur 可作为中间值
                        break
                    cur = cur * cur
                else:
                    # count[cur] == 1，只能作为中间值
                    length += 1
                    break
            else:
                # while 正常结束（cur 不在 count 中）
                # 上一个 cur（还没乘方）可作为中间值吗？不，上面已处理
                pass

            ans = max(ans, length)

        return ans
```

### 方法二：修正版

```python
from typing import List
from collections import Counter

class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        count = Counter(nums)
        ans = 1

        for x in set(nums):
            if x == 1:
                # 1^(2^k) = 1，整个序列都是 1
                cnt = count[1]
                # 取最大奇数（回文长度必须是奇数）
                ans = max(ans, cnt - (cnt % 2 == 0))
                continue

            length = 0
            cur = x
            while cur in count:
                if count[cur] >= 2:
                    length += 2
                    next_val = cur * cur
                    if next_val > 10 ** 9:
                        # 下一步必然超出范围，cur 可作为中心
                        length += 1
                        break
                    cur = next_val
                else:
                    # count[cur] == 1，作为中心
                    length += 1
                    break

            ans = max(ans, length)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log log M)，M 为最大值，每次翻倍后序列长度不超过 log log M 级
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 序列形如 `x, x^2, x^4, ..., x^(2^k), ..., x^4, x^2, x`（回文）
2. 每个除中心外的元素需要出现至少 2 次
3. 序列长度 = 2 * (层数) + 1（有中心）或 2 * (层数)（无中心）
4. `x = 1` 是特殊情况，1 的任意次幂仍为 1

## 易错点

1. 翻方时要检查是否会整数溢出（超过 10^9）
2. `x = 1` 时长度不是无限的，受 `count[1]` 限制
3. 回文长度为奇数（有唯一中心），所以 `x=1` 时取奇数长度
