## 题目描述

[LeetCode 1180. Count Substrings With Only One Distinct Letter](https://leetcode.com/problems/count-substrings-with-only-one-distinct-letter/)

给定一个字符串 `s`，返回只含有一个不同字母的子字符串的个数。

**示例 1:**

```
输入: s = "aaaba"
输出: 8
解释: 只有一个不同字母的子字符串有 "a", "aa", "aaa", "aaab" (索引 0-2 的 "aaa"), "b" 共 8 个。
注意 "b" 只出现一次，所以答案不是 9。
```

**示例 2:**

```
输入: s = "aaaaaaaaaa"
输出: 55
```

**提示:**

- `1 <= s.length <= 1000`
- `s[i]` 只包含小写英文字母

## 解题思路

这道题的核心思想是：**对于连续出现的相同字符，计算其能组成的子串数量**。

**关键观察**：
1. 如果有 n 个连续相同的字符，它们可以组成的子串数量为：n + (n-1) + (n-2) + ... + 1 = n * (n + 1) / 2
   - 长度为 1 的子串有 n 个
   - 长度为 2 的子串有 n-1 个
   - ...
   - 长度为 n 的子串有 1 个

2. 我们只需要遍历字符串，统计每段连续相同字符的长度，然后用公式计算即可

**算法流程**：
1. 使用双指针或计数器统计连续相同字符的长度
2. 每当遇到不同字符或到达字符串末尾，计算当前连续段的贡献
3. 累加所有连续段的贡献

## Python 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def countLetters(self, s: str) -> int:
        """
        使用双指针统计连续相同字符段
        """
        if not s:
            return 0
        
        result = 0
        i = 0
        n = len(s)
        
        while i < n:
            j = i
            # 找到连续相同字符的结束位置
            while j < n and s[j] == s[i]:
                j += 1
            
            # 计算这段连续字符的贡献
            length = j - i
            result += length * (length + 1) // 2
            
            # 移动到下一段
            i = j
        
        return result
```

### 方法二：单次遍历计数

```python
class Solution:
    def countLetters(self, s: str) -> int:
        """
        单次遍历，使用计数器记录当前连续字符的长度
        """
        if not s:
            return 0
        
        result = 0
        count = 1  # 当前连续字符的个数
        
        for i in range(1, len(s)):
            if s[i] == s[i - 1]:
                # 字符相同，计数器加1
                count += 1
            else:
                # 字符不同，结算之前的连续段
                result += count * (count + 1) // 2
                count = 1  # 重置计数器
        
        # 处理最后一段
        result += count * (count + 1) // 2
        
        return result
```

### 方法三：使用 itertools.groupby

```python
from itertools import groupby

class Solution:
    def countLetters(self, s: str) -> int:
        """
        使用 Python 内置的 groupby 函数简化代码
        """
        result = 0
        
        # groupby 会将连续相同的字符分组
        for char, group in groupby(s):
            length = len(list(group))
            result += length * (length + 1) // 2
        
        return result
```

## 复杂度分析

**所有方法的复杂度相同：**

- 时间复杂度：O(n)，其中 n 是字符串的长度，需要遍历一次字符串
- 空间复杂度：O(1)，只使用常数额外空间（方法三使用 groupby 时会有 O(k) 的空间，k 为某个分组的长度）

## 关键点总结

1. **数学公式**：n 个连续相同字符可以组成 n * (n + 1) / 2 个子串
2. **分段计算**：将问题分解为多个连续相同字符段的子问题
3. **边界处理**：注意处理最后一段连续字符
4. **代码简洁性**：方法三展示了 Python 的优雅写法，但方法二更直观

## 易错点

1. **忘记处理最后一段**：遍历结束后，最后一段连续字符还没有被统计
2. **整数除法**：使用 `//` 而不是 `/`，确保结果是整数
3. **空字符串**：虽然题目保证 `s.length >= 1`，但最好还是加上空字符串检查
4. **计数器初始化**：方法二中 count 应该初始化为 1，而不是 0
