## 题目描述

给你一个下标从 0 开始的一维整数数组 `original` 和两个整数 `m` 和 `n`。请将 `original` 转换为一个 `m` 行 `n` 列的二维数组。

- `original` 中下标为 `0` 到 `n - 1`（含）的元素构成二维数组的第一行
- 下标为 `n` 到 `2 * n - 1`（含）的元素构成二维数组的第二行，以此类推

若无法构成合法的二维数组，返回空的二维数组。

**示例 1：**
```
输入：original = [1,2,3,4], m = 2, n = 2
输出：[[1,2],[3,4]]
```

**示例 2：**
```
输入：original = [1,2,3], m = 1, n = 3
输出：[[1,2,3]]
```

**示例 3：**
```
输入：original = [1,2], m = 1, n = 1
输出：[]
解释：original 有 2 个元素，但目标矩阵只有 1 个位置，无法转换
```

**提示：**
- `1 <= original.length <= 5 * 10^4`
- `1 <= original[i] <= 10^5`
- `1 <= m, n <= 4 * 10^4`

## 解题思路

首先检查 `original.length == m * n`，若不满足返回空数组。
然后按顺序将 `original` 分成 `m` 组，每组 `n` 个元素。

## 代码实现

### 方法一：切片（推荐）

```python
from typing import List

class Solution:
    def construct2DArray(self, original: List[int], m: int, n: int) -> List[List[int]]:
        # 检查长度是否合法
        if len(original) != m * n:
            return []

        # 按每行 n 个元素切分
        return [original[i * n:(i + 1) * n] for i in range(m)]
```

### 方法二：索引计算

```python
from typing import List

class Solution:
    def construct2DArray(self, original: List[int], m: int, n: int) -> List[List[int]]:
        if len(original) != m * n:
            return []

        result = [[0] * n for _ in range(m)]
        for k in range(len(original)):
            row = k // n  # 行索引
            col = k % n   # 列索引
            result[row][col] = original[k]

        return result
```

### 方法三：numpy 风格（简洁）

```python
from typing import List

class Solution:
    def construct2DArray(self, original: List[int], m: int, n: int) -> List[List[int]]:
        if len(original) != m * n:
            return []

        # 利用 Python 内置的列表推导式
        result = []
        for i in range(0, len(original), n):
            result.append(original[i:i + n])
        return result
```

## 复杂度分析

- 时间复杂度：O(m * n)，填充每个元素
- 空间复杂度：O(m * n)，结果数组

## 关键点总结

1. 必须先验证 `len(original) == m * n`
2. 第 `i` 行对应 `original[i*n : (i+1)*n]`
3. 一维下标 `k` 对应二维坐标：`row = k // n`，`col = k % n`

## 易错点

- 忘记检查长度合法性就尝试转换
- 切片时注意是 `(i+1)*n` 不是 `i*n + n - 1`（切片右侧是开区间）
