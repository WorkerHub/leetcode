## 题目描述

给定一个不为空的二叉搜索树和一个目标值 target，找到 BST 中最接近目标值的 k 个值。

**示例 1：**
```
输入: root = [4,2,5,1,3], target = 3.714286, k = 2
输出: [4,3]
```

**示例 2：**
```
输入: root = [1], target = 0.000000, k = 1
输出: [1]
```

**提示：**
- 树中节点数量在 [1, 10^4] 范围内
- 0 <= Node.val <= 10^9
- -10^9 <= target <= 10^9
- 1 <= k <= 树中节点总数

**注意：**
- 假设 BST 是平衡的
- 返回的结果顺序不重要

## 解题思路

这道题要求在 BST 中找到最接近目标值的 k 个值，有多种解法思路。

### 思路一：中序遍历 + 排序

1. BST 的中序遍历得到有序数组
2. 在有序数组中找到最接近 target 的 k 个值
3. 可以使用双指针或者堆来选择最近的 k 个值

### 思路二：最大堆

1. 维护一个大小为 k 的最大堆
2. 遍历 BST，将节点值与 target 的差值存入堆
3. 堆的大小超过 k 时，弹出差值最大的元素
4. 最后堆中剩余的就是最接近的 k 个值

### 思路三：双指针（中序遍历 + 滑动窗口）

1. 中序遍历得到有序数组
2. 找到最接近 target 的位置
3. 使用双指针从该位置向两边扩展，选择最接近的 k 个值

## Python 代码实现

### 方法一：中序遍历 + 双指针（推荐）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def closestKValues(self, root: Optional[TreeNode], target: float, k: int) -> List[int]:
        """
        中序遍历获取有序数组，然后使用双指针找最近的 k 个值
        """
        # 中序遍历获取有序数组
        def inorder(node):
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        nums = inorder(root)
        
        # 找到最接近 target 的位置
        # 使用二分查找找到插入位置
        left, right = 0, len(nums) - 1
        while left < right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid
        
        # left 指向第一个 >= target 的位置
        # 使用双指针从 left 位置向两边扩展
        result = []
        left = left - 1  # 左指针指向小于 target 的最大值
        right = left + 1  # 右指针指向大于等于 target 的最小值
        
        # 选择最接近的 k 个值
        for _ in range(k):
            # 左指针越界，只能选右边
            if left < 0:
                result.append(nums[right])
                right += 1
            # 右指针越界，只能选左边
            elif right >= len(nums):
                result.append(nums[left])
                left -= 1
            # 比较左右两边哪个更接近
            elif abs(nums[left] - target) <= abs(nums[right] - target):
                result.append(nums[left])
                left -= 1
            else:
                result.append(nums[right])
                right += 1
        
        return result
```

### 方法二：最大堆

```python
import heapq
from typing import List, Optional

class Solution:
    def closestKValues(self, root: Optional[TreeNode], target: float, k: int) -> List[int]:
        """
        使用最大堆维护最接近的 k 个值
        """
        # 最大堆，存储 (-差值, 节点值)
        max_heap = []
        
        def dfs(node):
            if not node:
                return
            
            # 计算当前节点与 target 的差值
            diff = abs(node.val - target)
            
            if len(max_heap) < k:
                # 堆未满，直接加入
                heapq.heappush(max_heap, (-diff, node.val))
            elif diff < -max_heap[0][0]:
                # 当前节点更接近，替换堆顶
                heapq.heapreplace(max_heap, (-diff, node.val))
            
            # 遍历左右子树
            dfs(node.left)
            dfs(node.right)
        
        dfs(root)
        
        # 提取堆中的值
        return [val for _, val in max_heap]
```

### 方法三：优化的中序遍历（一次遍历）

```python
from typing import List, Optional

class Solution:
    def closestKValues(self, root: Optional[TreeNode], target: float, k: int) -> List[int]:
        """
        使用滑动窗口，在中序遍历过程中维护最近的 k 个值
        """
        result = []
        
        def inorder(node):
            if not node:
                return
            
            inorder(node.left)
            
            # 处理当前节点
            if len(result) < k:
                result.append(node.val)
            else:
                # 窗口已满，判断是否需要替换
                # result[0] 是窗口中最左边（最小）的值
                # result[-1] 是窗口中最右边（最大）的值
                if abs(node.val - target) < abs(result[0] - target):
                    result.pop(0)
                    result.append(node.val)
                else:
                    # 由于是有序的，后面的值只会越来越远，可以提前终止
                    return
            
            inorder(node.right)
        
        inorder(root)
        return result
```

### 方法四：使用 Python 特性（简洁版）

```python
from typing import List, Optional

class Solution:
    def closestKValues(self, root: Optional[TreeNode], target: float, k: int) -> List[int]:
        """
        使用 Python 排序特性
        """
        # 中序遍历获取所有值
        def inorder(node):
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        nums = inorder(root)
        
        # 按照与 target 的距离排序，取前 k 个
        nums.sort(key=lambda x: abs(x - target))
        return nums[:k]
```

## 复杂度分析

### 方法一：中序遍历 + 双指针

**时间复杂度：** O(n)
- 中序遍历：O(n)
- 双指针选择：O(k)
- 总体：O(n)

**空间复杂度：** O(n)
- 存储中序遍历结果

### 方法二：最大堆

**时间复杂度：** O(n log k)
- 遍历所有节点：O(n)
- 每次堆操作：O(log k)

**空间复杂度：** O(k + h)
- 堆空间：O(k)
- 递归栈：O(h)，h 为树的高度

### 方法三：优化的中序遍历

**时间复杂度：** O(n)（最坏情况）
- 可能提前终止，平均情况更好

**空间复杂度：** O(k + h)

### 方法四：排序

**时间复杂度：** O(n log n)
- 中序遍历：O(n)
- 排序：O(n log n)

**空间复杂度：** O(n)

## 关键点总结

1. **利用 BST 性质**：中序遍历得到有序数组
2. **双指针技巧**：在有序数组中，从最接近位置向两边扩展
3. **堆的应用**：维护大小为 k 的最大堆，保存最小的 k 个差值
4. **剪枝优化**：利用有序性，可以提前终止遍历
5. **方法选择**：
   - 方法一最优：O(n) 时间，清晰易懂
   - 方法二适合流式数据：O(n log k)
   - 方法四最简洁：适合快速实现

## 易错点

1. **双指针初始化**：找到最接近 target 的位置后，正确设置左右指针
   ```python
   # 错误：直接使用二分结果
   left = mid
   right = mid + 1
   
   # 正确：根据二分结果调整
   left = left - 1  # 指向小于 target 的位置
   right = left + 1  # 指向大于等于 target 的位置
   ```

2. **边界判断**：双指针扩展时要检查越界
   ```python
   if left < 0:  # 左边界
       # 只能选右边
   elif right >= len(nums):  # 右边界
       # 只能选左边
   ```

3. **距离比较**：注意相等距离的处理
   ```python
   # 距离相等时，可以选左边或右边，题目不要求顺序
   if abs(nums[left] - target) <= abs(nums[right] - target):
       # 选左边
   ```

4. **堆的使用**：Python heapq 是最小堆，要实现最大堆需要取负值
   ```python
   heapq.heappush(max_heap, (-diff, node.val))  # 差值取负
   ```
