## 题目描述

给定长度为 `2n` 的整数数组 `nums`，通过若干次操作将相邻元素配对，使得每对元素相等。每次操作可以将某个元素移动一步（向左或向右）。求使所有元素配对（相邻且相等）的最少移动次数。

**示例 1：**
```
输入：nums = [1,1,2,2]
输出：0
解释：已经配对：(1,1) 和 (2,2)。
```

**示例 2：**
```
输入：nums = [1,2,1,2]
输出：2
解释：将 nums[1]=2 移到 nums[3]=2 旁边，或将 nums[2]=1 移到 nums[0]=1 旁边，最少 2 步。
```

**提示：**
- `1 <= n <= 10^5`
- `2 * n == nums.length`
- 每种值恰好出现偶数次

## 解题思路

贪心：对同一值的所有出现位置，按位置顺序两两配对（相邻的两个配对），然后计算移动代价。

对于同一个值的位置列表 `[p1, p2, p3, p4, ...]`（已排序），最优配对是 `(p1,p2), (p3,p4), ...`。

每对 `(pi, pi+1)` 的代价与将它们合并到相邻位置的移动数有关，但由于是整体移动，代价计算更复杂。

简化：每对相同值只需要计算"两个位置合并"的代价，不考虑与其他对的交互。最少操作 = 将 `p2 - p1 - 1`（中间元素数）步将它们合并到相邻。

## Python 代码实现

### 方法一：贪心配对（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minMoves(self, nums: List[int]) -> int:
        # 记录每种值的出现位置
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)

        total_moves = 0
        for positions in pos.values():
            positions.sort()
            # 两两配对：(p0,p1), (p2,p3), ...
            for i in range(0, len(positions), 2):
                # 将 positions[i] 和 positions[i+1] 合并到相邻
                # 最少移动数：它们之间的距离 - 1
                total_moves += positions[i+1] - positions[i] - 1

        return total_moves
```

### 方法二：排序后统计

```python
from typing import List
from collections import defaultdict

class Solution:
    def minMoves(self, nums: List[int]) -> int:
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)

        moves = 0
        for positions in pos.values():
            positions.sort()
            for i in range(0, len(positions), 2):
                a, b = positions[i], positions[i+1]
                # 要将 a 和 b 相邻，需要 b - a - 1 次移动（将 b 移到 a+1，或 a 移到 b-1）
                moves += b - a - 1

        return moves
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序各值的位置
- 空间复杂度：O(n)

## 关键点总结

1. 同一值的相邻两个位置配对最优（贪心）
2. 配对代价 = 两个位置之间的元素数（距离 - 1）
3. 不同值的配对相互独立，分别计算

## 易错点

1. 配对顺序：相邻的位置配对，而非任意配对
2. 代价 = `b - a - 1`（已经相邻时代价为 0）
