## 题目描述

微波炉面板有 10 个数字键（0-9）和一个开始键，可以显示最多 4 位的烹饪时间（形如 `mm:ss`，分钟和秒钟）。

给你整数 `startAt`、`moveCost`、`pushCost` 和 `targetSeconds`：
- 当前手指位于数字 `startAt` 上。
- 移动到相邻或非相邻的不同数字代价为 `moveCost`，按下当前数字代价为 `pushCost`。

返回设置 `targetSeconds` 的**最小代价**。注意时间格式：
- 若显示 `m:ss`、`mm:ss` 或 `s`，都可以表示有效的时间（不含前导零，除非分钟数为 0 则只显示秒）。

**提示：**
- `0 <= startAt <= 9`
- `1 <= moveCost, pushCost <= 10^5`
- `1 <= targetSeconds <= 6039`

## 解题思路

**枚举所有合法的 (分钟, 秒) 组合**

`targetSeconds` 可能对应多种 `(分钟, 秒)` 表示：
- `(0, targetSeconds)` 若 `targetSeconds <= 99`
- `(targetSeconds // 60, targetSeconds % 60)` 若 `targetSeconds % 60 <= 59` 且 `targetSeconds // 60 <= 99`
- 其他组合...

枚举所有可能的分钟数 `m`（0 到 99），计算对应秒数 `s = targetSeconds - m * 60`，若 `0 <= s <= 99`，则这是一个合法组合。

对每个合法组合，计算按键总代价（移动代价 + 按键代价）。

## 代码实现

### 方法一：枚举所有合法分钟数（推荐）

```python
class Solution:
    def minCostSetTime(self, startAt: int, moveCost: int, pushCost: int, targetSeconds: int) -> int:
        def cost(minute: int, second: int) -> int:
            # 计算按下显示 minute:second 的代价
            # 将 minute 和 second 拼成数字序列
            if minute == 0:
                digits = [second]  # 只显示秒
            else:
                digits = [minute, second]

            # 构造实际按键序列（分钟不含前导零，秒恰好两位）
            # 实际上显示的是 minute*100 + second 这个数
            num = minute * 100 + second
            if num == 0:
                keys = [0]
            else:
                keys = []
                while num > 0:
                    keys.append(num % 10)
                    num //= 10
                keys.reverse()

            total = 0
            cur = startAt
            for key in keys:
                if key != cur:
                    total += moveCost
                    cur = key
                total += pushCost
            return total

        ans = float('inf')
        for m in range(100):  # 分钟 0-99
            s = targetSeconds - m * 60
            if 0 <= s <= 99:
                ans = min(ans, cost(m, s))

        return ans
```

### 方法二：直接枚举数字序列

```python
class Solution:
    def minCostSetTime(self, startAt: int, moveCost: int, pushCost: int, targetSeconds: int) -> int:
        def calc(seq: str) -> int:
            # 计算按键序列的代价
            cur = startAt
            total = 0
            for ch in seq:
                digit = int(ch)
                if digit != cur:
                    total += moveCost
                    cur = digit
                total += pushCost
            return total

        ans = float('inf')
        for m in range(100):
            s = targetSeconds - m * 60
            if not (0 <= s <= 99):
                continue
            # 生成按键序列字符串（m:ss 格式）
            if m == 0:
                seq = str(s)  # 不显示分钟部分
            else:
                seq = str(m) + f"{s:02d}"  # 分钟无前导零，秒恰好两位
            ans = min(ans, calc(seq))

        return ans
```

## 关键点总结

1. targetSeconds 对应的 (分钟, 秒) 有多种合法表示（分钟 0-99，秒 0-99）。
2. 枚举所有合法表示，取最小代价。
3. 按键序列：分钟无前导零，秒数若在 0-9 之间需两位（如 `05`）。

## 易错点

- 秒数必须是两位字符串（即使 < 10 也要补零），除非分钟为 0 时只显示秒本身。
- 分钟为 0 时不在显示中（直接显示秒数）。
