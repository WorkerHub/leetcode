## 题目描述

给你一个整数数组 `nums`，其中部分位置是障碍物（值为 -1）。你从下标 0 出发，每次可以跳跃 1 步或 2 步（不能跳到障碍物位置），目标是到达下标 `n-1`。

返回到达终点所需的最少跳跃次数，如果无法到达则返回 -1。

**示例 1：**

```
输入：nums = [0, 0, -1, 0, 0]
输出：3
解释：0 -> 1 -> 3 -> 4，跳跃 3 次（跳过下标 2 的障碍）。
```

**示例 2：**

```
输入：nums = [0, -1, -1, 0]
输出：-1
解释：下标 1 和 2 都是障碍，无法到达终点。
```

**提示：**
- `2 <= nums.length <= 10^5`
- `nums[i]` 为 0 或 -1
- `nums[0]` 和 `nums[n-1]` 不是障碍物

## 解题思路

经典的最短路径问题，使用 BFS 保证最少跳跃次数：
1. 从下标 0 开始，使用队列进行 BFS。
2. 每次从队列取出当前位置，尝试跳 1 步或 2 步。
3. 如果目标位置不是障碍且未被访问，加入队列。
4. 第一次到达 n-1 时，返回当前跳跃次数。

动态规划同样可以解决：`dp[i]` = 到达位置 i 的最少跳跃次数。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumJumps(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return 0

        visited = [False] * n
        visited[0] = True
        queue = deque([(0, 0)])  # (当前位置, 跳跃次数)

        while queue:
            pos, steps = queue.popleft()

            # 尝试跳 1 步和 2 步
            for jump in [1, 2]:
                nxt = pos + jump
                if nxt == n - 1:
                    return steps + 1
                if 0 <= nxt < n and nums[nxt] != -1 and not visited[nxt]:
                    visited[nxt] = True
                    queue.append((nxt, steps + 1))

        return -1  # 无法到达终点
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def minimumJumps(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')
        dp = [INF] * n
        dp[0] = 0  # 起点无需跳跃

        for i in range(1, n):
            if nums[i] == -1:
                continue  # 障碍位置跳过
            # 从 i-1 跳 1 步到达 i
            if i >= 1 and dp[i - 1] != INF:
                dp[i] = min(dp[i], dp[i - 1] + 1)
            # 从 i-2 跳 2 步到达 i
            if i >= 2 and dp[i - 2] != INF:
                dp[i] = min(dp[i], dp[i - 2] + 1)

        return dp[n - 1] if dp[n - 1] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n)，每个位置最多访问一次
- 空间复杂度：O(n)，BFS 队列或 dp 数组

## 关键点总结

1. BFS 天然保证找到最短路径（最少跳跃次数）。
2. 动态规划也可以处理此问题，转移方程简单清晰。
3. 障碍物位置直接跳过，不更新 dp 值。

## 易错点

1. 起始位置和终点不是障碍，但中间位置需要检查。
2. dp 初始值设为无穷大，表示不可达，最后检查是否仍为无穷大。
3. BFS 中需要标记访问，避免重复入队。
