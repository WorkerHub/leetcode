## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，将数组中的元素分成若干组（每组至少两个元素），使得每组中所有元素之和不超过 `k`。返回可以形成的最多组数。

**示例 1：**
```
输入：nums = [1, 2, 3, 4, 5], k = 6
输出：2
解释：可以分成 [1,5] 和 [2,4]，每组和不超过 6，剩余 3 无法与任何元素配对。
```

**示例 2：**
```
输入：nums = [1, 1, 1, 1], k = 3
输出：2
解释：分成 [1,1] 和 [1,1]。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 2 * 10^9`

## 解题思路

贪心 + 排序 + 双指针。

将数组排序后，使用双指针从两端向中间扫描：
- 左指针指向当前最小值，右指针指向当前最大值。
- 若 `nums[left] + nums[right] <= k`，说明这两个元素可以配成一组，计数加一，两指针同时向中间移动。
- 若两者之和超过 `k`，说明最大值太大，无法与任何剩余元素配对（因为左边已经是最小值），右指针左移，放弃该元素。

这种策略保证了每次配对都"尽可能利用最大值"，从而最大化组数。

## Python 代码实现

### 方法一：贪心双指针（推荐）

```python
from typing import List

class Solution:
    def maximizeGroups(self, nums: List[int], k: int) -> int:
        # 先排序，方便使用双指针
        nums.sort()
        left, right = 0, len(nums) - 1
        count = 0

        while left < right:
            if nums[left] + nums[right] <= k:
                # 当前最小值与最大值可以配成一组
                count += 1
                left += 1
                right -= 1
            else:
                # 最大值太大，无法与任何人配对
                right -= 1

        return count
```

### 方法二：排序后二分查找

```python
from typing import List
import bisect

class Solution:
    def maximizeGroups(self, nums: List[int], k: int) -> int:
        nums.sort()
        count = 0
        right = len(nums) - 1

        for left in range(len(nums)):
            if left >= right:
                break
            # 对于 nums[left]，找最大的配对元素（不超过 k - nums[left]）
            target = k - nums[left]
            pos = bisect.bisect_right(nums, target, left + 1, right + 1) - 1
            if pos > left:
                # 找到了可配对的元素
                count += 1
                right = pos - 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)，只用了常数额外空间（排序原地）

## 关键点总结

1. 排序后双指针是解决"配对求和"类问题的经典模式
2. 贪心策略：用最小值去"消耗"最大值，保证尽可能多配对
3. 当最大值无法与最小值配对时，该最大值必然无法与任何元素配对

## 易错点

1. 注意循环终止条件 `left < right`，两指针不能指向同一元素（每组至少两个不同元素）
2. 右指针左移时不要忘记放弃当前最大值
