## 题目描述

给定一个整数数组 arr，返回所有子数组按位或结果的不同值的数量。

**提示：**
- 1 <= arr.length <= 5 * 10^4
- 0 <= arr[i] <= 10^9

## 解题思路

**关键观察：**
- 以 arr[i] 结尾的子数组，OR 值最多有 30 个不同值（整数最多 30 位）
- 使用集合存储以当前元素结尾的所有 OR 值

## Python 代码实现

```python
class Solution:
    def subarrayBitwiseORs(self, arr: List[int]) -> int:
        result = set()
        cur = {0}
        
        for num in arr:
            cur = {num | x for x in cur} | {num}
            result |= cur
        
        return len(result)
```

## 复杂度分析

- **时间复杂度**：O(n × log(max(arr)))
- **空间复杂度**：O(n × log(max(arr)))

## 关键点总结

1. **OR 单调性**：OR 只增不减
2. **状态数限制**：最多 30 个不同状态
3. **集合去重**：自动统计不同值
