## 题目描述

给定两个字符串 `order` 和 `s`。`order` 中的所有字符都是唯一的，并且之前按照某些自定义的顺序排序。

对 `s` 进行排序，使得 `s` 中的字符按照 `order` 中的顺序排列。具体来说，如果 `x` 在 `order` 中出现在 `y` 之前，那么在排序后的字符串中 `x` 也应该出现在 `y` 之前。

返回满足这个性质的 `s` 的任意一种排列。

**示例 1：**
```
输入: order = "cba", s = "abcd"
输出: "cbad"
解释: 
"a", "b", "c" 在 order 中，所以按照 "c", "b", "a" 的顺序排列。
"d" 不在 order 中，可以放在任意位置，"dcba", "cdba", "cbda" 都是有效答案。
```

**示例 2：**
```
输入: order = "bcafg", s = "abcd"
输出: "bcad"
解释: 
按照 order 的顺序，输出为 "bcad"。
"d" 不在 order 中，可以放在任意位置。
```

**提示：**
- `1 <= order.length <= 26`
- `1 <= s.length <= 200`
- `order` 和 `s` 都由小写英文字母组成
- `order` 中的所有字符都是唯一的

## 解题思路

这是一道自定义排序问题，核心是按照给定的顺序重新排列字符串。

**关键观察：**

1. **排序依据**：
   - 在 `order` 中的字符按照其在 `order` 中的顺序排列
   - 不在 `order` 中的字符可以放在任意位置

2. **解法思路**：
   
   **方法一：计数 + 按序构建**
   - 统计 `s` 中每个字符的出现次数
   - 按照 `order` 的顺序，依次取出对应数量的字符
   - 最后添加不在 `order` 中的字符

   **方法二：自定义排序**
   - 为每个字符定义一个优先级（在 `order` 中的位置）
   - 使用 Python 的 `sorted()` 函数和自定义 key
   
   **方法三：哈希表 + 拼接**
   - 用哈希表记录 `s` 中每个字符的数量
   - 按 `order` 的顺序拼接结果

## Python 代码实现

### 方法一：计数 + 按序构建（推荐）

```python
from collections import Counter

class Solution:
    def customSortString(self, order: str, s: str) -> str:
        """
        统计字符频率，按 order 顺序构建结果
        
        时间复杂度：O(n + m)
        空间复杂度：O(1)，最多 26 个字母
        """
        # 统计 s 中每个字符的出现次数
        count = Counter(s)
        
        result = []
        
        # 按 order 的顺序添加字符
        for char in order:
            if char in count:
                result.append(char * count[char])
                # 删除已处理的字符
                del count[char]
        
        # 添加不在 order 中的字符（顺序任意）
        for char, freq in count.items():
            result.append(char * freq)
        
        return ''.join(result)
```

### 方法二：自定义排序

```python
class Solution:
    def customSortString(self, order: str, s: str) -> str:
        """
        使用自定义排序函数
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # 创建字符到优先级的映射
        # 不在 order 中的字符优先级设为无穷大（放最后）
        priority = {char: i for i, char in enumerate(order)}
        
        # 按优先级排序
        sorted_s = sorted(s, key=lambda x: priority.get(x, float('inf')))
        
        return ''.join(sorted_s)
```

### 方法三：哈希表 + 字符串拼接

```python
from collections import defaultdict

class Solution:
    def customSortString(self, order: str, s: str) -> str:
        """
        使用哈希表记录字符频率，按顺序拼接
        
        时间复杂度：O(n + m)
        空间复杂度：O(1)
        """
        # 统计字符频率
        freq = defaultdict(int)
        for char in s:
            freq[char] += 1
        
        result = []
        
        # 按 order 顺序添加
        for char in order:
            if char in freq:
                result.append(char * freq[char])
                freq[char] = 0  # 标记已处理
        
        # 添加剩余字符
        for char in s:
            if freq[char] > 0:
                result.append(char)
                freq[char] -= 1
        
        return ''.join(result)
```

### 方法四：简化版（使用列表推导）

```python
from collections import Counter

class Solution:
    def customSortString(self, order: str, s: str) -> str:
        """
        使用列表推导简化代码
        
        时间复杂度：O(n + m)
        空间复杂度：O(1)
        """
        count = Counter(s)
        
        # 按 order 顺序的字符
        result = ''.join(char * count[char] for char in order if char in count)
        
        # 不在 order 中的字符
        remaining = ''.join(char * count[char] for char in count if char not in order)
        
        return result + remaining
```

## 复杂度分析

### 方法一、三、四：计数法
- **时间复杂度：** O(n + m)，其中 n 是 `s` 的长度，m 是 `order` 的长度
  - 统计字符频率：O(n)
  - 按 order 遍历：O(m)
- **空间复杂度：** O(1)，最多 26 个小写字母，常数空间

### 方法二：自定义排序
- **时间复杂度：** O(n log n)，排序的时间复杂度
- **空间复杂度：** O(n)，排序需要额外空间

## 关键点总结

1. **计数思想**：统计字符频率是处理字符串重排问题的常用技巧
2. **顺序控制**：按照 `order` 的顺序遍历，保证输出顺序正确
3. **剩余字符处理**：不在 `order` 中的字符可以放在任意位置（通常放最后）
4. **优化选择**：计数法比排序法更高效（O(n) vs O(n log n)）
5. **Python 技巧**：
   - `Counter` 统计频率
   - 字符串乘法：`'a' * 3 = 'aaa'`
   - `join()` 拼接字符串

## 易错点

1. **重复字符处理**：`s` 中可能有重复字符，需要正确计数
2. **不在 order 中的字符**：容易遗漏，需要单独处理
3. **字符顺序**：不在 `order` 中的字符可以任意顺序，但要确保都包含
4. **字符串不可变**：Python 中字符串不可变，使用列表拼接更高效
5. **边界情况**：
   - `order` 包含 `s` 中所有字符
   - `s` 中有 `order` 中没有的字符
   - `order` 中有 `s` 中没有的字符
