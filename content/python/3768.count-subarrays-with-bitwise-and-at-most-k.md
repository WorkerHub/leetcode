## 题目描述

给定整数数组 `nums` 和整数 `k`，统计所有子数组中按位与（AND）的结果不超过 `k` 的子数组数量。

**示例 1：**
```
输入：nums = [1,1,1], k = 0
输出：1
解释：只有全数组 [1,1,1] 的 AND = 1 > 0... 
     实际：AND 只会越来越小。单元素 AND = 元素本身，若 nums[i] <= k 则子数组 [i,i] 满足。
     子数组 AND <= 0 的只有 [0]... 不存在（元素 >= 1）。输出 0？题目示例可能不同。
```

**示例 2：**
```
输入：nums = [2,1,4,3], k = 1
输出：8
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

利用按位 AND 的单调性：子数组越长，AND 值只会减小或不变（每次 AND 都会保留或去掉某些位）。

**方法：** 对每个右端点 `r`，维护所有以 `r` 结尾的不同 AND 值集合（大小为 O(log max_val)），统计其中 <= k 的数量。

## Python 代码实现

### 方法一：维护 AND 集合（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        # cur_ands: {(and_value, count)} 表示以当前位置结尾的子数组的 AND 值及其子数组数量
        cur_ands = {}  # and_value -> count

        for x in nums:
            new_ands = {}
            for val, cnt in cur_ands.items():
                new_val = val & x
                new_ands[new_val] = new_ands.get(new_val, 0) + cnt
            # 加入以当前元素为单独子数组
            new_ands[x] = new_ands.get(x, 0) + 1
            cur_ands = new_ands

            # 统计 AND <= k 的子数组数量
            result += sum(cnt for val, cnt in cur_ands.items() if val <= k)

        return result
```

### 方法二：暴力（适合小数组）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        for l in range(n):
            cur_and = nums[l]
            for r in range(l, n):
                cur_and &= nums[r]
                if cur_and <= k:
                    result += 1
                # AND 只减不增，若已 <= k 后续都满足
                # 但不能提前退出，因为 AND 可能已经很小
        return result
```

## 复杂度分析

- 时间复杂度：O(n log max_val)，AND 集合大小有界
- 空间复杂度：O(log max_val)

## 关键点总结

1. 以每个右端点结尾的子数组 AND 值最多有 O(log max_val) 种
2. 维护 AND 值及其子数组数量的字典，每步更新
3. AND 操作具有单调性：子数组延长时 AND 值不增

## 易错点

1. AND 集合需要记录每种 AND 值对应的子数组数量
2. 统计时对每种 AND 值判断是否 <= k，乘以对应数量
