## 题目描述

你打算利用空闲时间来做兼职工作赚些零花钱。

这里有 n 份兼职工作，每份工作预计从 `startTime[i]` 开始到 `endTime[i]` 结束，报酬为 `profit[i]`。

给你一份兼职工作表，包含开始时间 `startTime`，结束时间 `endTime` 和预计报酬 `profit` 三个数组，请你计算并返回可以获得的最大报酬。

注意，时间上出现重叠的 2 份工作不能同时进行。

如果你选择的工作在时间 X 结束，那么你可以立刻进行在时间 X 开始的下一份工作。

示例 1：
```
输入：startTime = [1,2,3,3], endTime = [3,4,5,6], profit = [50,10,40,70]
输出：120
解释：
选择第 1 份和第 4 份工作，时间范围是 [1-3], [3-6]，我们可以获得 120 的最大报酬。
```

示例 2：
```
输入：startTime = [1,2,3,4,6], endTime = [3,5,10,6,9], profit = [20,20,100,70,60]
输出：150
解释：
选择第 1, 4, 5 份工作，最大报酬 150。
```

示例 3：
```
输入：startTime = [1,1,1], endTime = [2,3,4], profit = [5,6,4]
输出：6
```

提示：
- `1 <= startTime.length == endTime.length == profit.length <= 5 * 10^4`
- `1 <= startTime[i] < endTime[i] <= 10^9`
- `1 <= profit[i] <= 10^4`

## 解题思路

这是经典的加权区间调度问题，使用动态规划 + 二分查找解决。

核心思路：
1. 按结束时间对工作排序
2. `dp[i]` 表示考虑前 i 个工作能获得的最大报酬
3. 对于第 i 个工作，有两个选择：
   - 不做：`dp[i] = dp[i-1]`
   - 做：`dp[i] = profit[i] + dp[j]`，其中 j 是最后一个不与 i 冲突的工作
4. 使用二分查找快速找到 j

## Python 代码实现

### 方法一：DP + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        """
        动态规划 + 二分查找
        
        Args:
            startTime: 开始时间数组
            endTime: 结束时间数组
            profit: 报酬数组
            
        Returns:
            最大报酬
        """
        # 将工作按结束时间排序
        jobs = sorted(zip(endTime, startTime, profit))
        n = len(jobs)
        
        # dp[i] 表示考虑前 i 个工作的最大报酬
        dp = [0] * (n + 1)
        
        for i in range(n):
            end_time, start_time, pft = jobs[i]
            
            # 二分查找最后一个不冲突的工作
            # 找到结束时间 <= 当前工作开始时间的最后一个工作
            left, right = 0, i
            while left < right:
                mid = (left + right + 1) // 2
                if jobs[mid-1][0] <= start_time:
                    left = mid
                else:
                    right = mid - 1
            
            # 选择做或不做当前工作
            dp[i+1] = max(dp[i], dp[left] + pft)
        
        return dp[n]
```

### 方法二：使用 bisect 库

```python
from typing import List
import bisect

class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        """
        使用 Python 的 bisect 简化二分查找
        """
        # 按结束时间排序
        jobs = sorted(zip(endTime, startTime, profit))
        n = len(jobs)
        
        # 提取排序后的结束时间
        end_times = [job[0] for job in jobs]
        
        dp = [0] * (n + 1)
        
        for i in range(n):
            end_time, start_time, pft = jobs[i]
            
            # 找到最后一个结束时间 <= start_time 的位置
            j = bisect.bisect_right(end_times, start_time, 0, i)
            
            # 做或不做当前工作
            dp[i+1] = max(dp[i], dp[j] + pft)
        
        return dp[n]
```

### 方法三：递归 + 记忆化

```python
from typing import List
from functools import lru_cache
import bisect

class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        """
        递归 + 记忆化搜索
        """
        # 按结束时间排序
        jobs = sorted(zip(endTime, startTime, profit))
        n = len(jobs)
        end_times = [job[0] for job in jobs]
        
        @lru_cache(None)
        def dp(i: int) -> int:
            """返回从第 i 个工作开始的最大报酬"""
            if i >= n:
                return 0
            
            end_time, start_time, pft = jobs[i]
            
            # 找下一个不冲突的工作
            next_job = bisect.bisect_left(end_times, end_time, i+1)
            
            # 做当前工作 vs 不做
            take = pft + dp(next_job)
            skip = dp(i + 1)
            
            return max(take, skip)
        
        return dp(0)
```

### 方法四：优化的 DP

```python
from typing import List
import bisect

class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        """
        空间优化版本
        """
        jobs = sorted(zip(startTime, endTime, profit))
        n = len(jobs)
        
        # 按结束时间排序更方便
        jobs_by_end = sorted(zip(endTime, startTime, profit))
        
        # 存储 (结束时间, 最大收益) 对
        dp = [[0, 0]]  # [时间, 收益]
        
        for end, start, pft in jobs_by_end:
            # 二分查找找到最近的不冲突时间点
            idx = bisect.bisect_right(dp, [start, float('inf')]) - 1
            
            # 如果做当前工作能获得更多收益
            if dp[idx][1] + pft > dp[-1][1]:
                dp.append([end, dp[idx][1] + pft])
        
        return dp[-1][1]
```

## 复杂度分析

**方法一和方法二（推荐）：**
- 时间复杂度：O(n log n)，排序 O(n log n)，每个工作二分查找 O(log n)
- 空间复杂度：O(n)

**方法三：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)，递归栈和缓存

**方法四：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按结束时间排序是关键
2. 使用二分查找快速找到不冲突的工作
3. DP 状态定义：dp[i] 表示考虑前 i 个工作的最大收益
4. 状态转移：max(不做, 做 + 前面不冲突的最大收益)
5. bisect_right 和 bisect_left 的区别

## 易错点

1. 排序时忘记同时调整三个数组
2. 二分查找的边界条件错误
3. DP 初始化错误
4. 混淆开始时间和结束时间
5. 忘记考虑不做当前工作的情况
