## 题目描述

如果一个数列至少有三个元素，并且任意两个相邻元素之差相同，则称该数列为等差数列。

给你一个整数数组 nums，返回数组 nums 中所有等差子数组的个数。

子数组是数组中的一个连续序列。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：3
解释：nums 中有三个子等差数组：[1,2,3]、[2,3,4] 和 [1,2,3,4]
```

**示例 2：**
```
输入：nums = [1]
输出：0
```

## 解题思路

核心观察：
1. 如果 [a, b, c, d, e] 是等差数列，那么包含的等差子数组有：
   - 长度为 3：[a,b,c], [b,c,d], [c,d,e]
   - 长度为 4：[a,b,c,d], [b,c,d,e]
   - 长度为 5：[a,b,c,d,e]
2. 如果连续 k 个数是等差数列，包含的等差子数组数量为：(k-2) * (k-1) / 2

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def numberOfArithmeticSlices(self, nums: List[int]) -> int:
        """
        dp[i] 表示以 nums[i] 结尾的等差子数组个数
        """
        n = len(nums)
        if n < 3:
            return 0
        
        dp = 0  # 以当前元素结尾的等差子数组个数
        total = 0
        
        for i in range(2, n):
            if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
                # 可以形成等差数列
                dp += 1
                total += dp
            else:
                # 重新开始
                dp = 0
        
        return total
```

### 方法二：数学计算

```python
from typing import List

class Solution:
    def numberOfArithmeticSlices(self, nums: List[int]) -> int:
        """
        计算连续等差序列的长度，用公式计算
        """
        n = len(nums)
        if n < 3:
            return 0
        
        total = 0
        length = 2  # 当前等差序列长度
        
        for i in range(2, n):
            if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
                length += 1
            else:
                # 计算之前序列的等差子数组数量
                if length >= 3:
                    total += (length - 2) * (length - 1) // 2
                length = 2
        
        # 处理最后一段
        if length >= 3:
            total += (length - 2) * (length - 1) // 2
        
        return total
```

### 方法三：暴力枚举

```python
from typing import List

class Solution:
    def numberOfArithmeticSlices(self, nums: List[int]) -> int:
        """
        枚举所有子数组
        """
        n = len(nums)
        count = 0
        
        for i in range(n - 2):
            diff = nums[i + 1] - nums[i]
            for j in range(i + 2, n):
                if nums[j] - nums[j - 1] == diff:
                    count += 1
                else:
                    break
        
        return count
```

## 复杂度分析

### 方法一：动态规划
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

### 方法三：暴力
- **时间复杂度**：O(n^2)
- **空间复杂度**：O(1)

## 关键点总结

1. 等差数列的定义和性质
2. DP 状态：以当前元素结尾的等差子数组个数
3. 状态转移：如果能延续，dp += 1

2. 重置 dp 时机错误
