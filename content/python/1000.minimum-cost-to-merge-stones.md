## 题目描述

有 n 堆石头排成一排，第 i 堆中有 stones[i] 块石头。

每次移动需要将连续的 k 堆石头合并为一堆，而这次移动的成本为这 k 堆中石头的总数。

返回把所有石头合并成一堆的最低成本。如果无法合并成一堆，返回 -1。

**示例：**
```
输入：stones = [3,2,4,1], k = 2
输出：20
解释：
从 [3, 2, 4, 1] 开始
合并 [3, 2]，成本为 5，剩下 [5, 4, 1]
合并 [4, 1]，成本为 5，剩下 [5, 5]
合并 [5, 5]，成本为 10，剩下 [10]
总成本 20
```

## 解题思路

这是一道困难的区间DP问题。

**关键观察：**
1. 每次合并 k 堆变成 1 堆，相当于减少 k-1 堆
2. 要合并成 1 堆，必须满足：(n - 1) % (k - 1) == 0
3. 使用区间DP，定义 dp[i][j][p] 表示将 stones[i:j+1] 合并成 p 堆的最小成本

## Python 代码实现

```python
from typing import List

class Solution:
    def mergeStones(self, stones: List[int], k: int) -> int:
        n = len(stones)
        
        # 检查是否能合并成一堆
        if (n - 1) % (k - 1) != 0:
            return -1
        
        # 计算前缀和
        prefix = [0]
        for stone in stones:
            prefix.append(prefix[-1] + stone)
        
        # dp[i][j][p] 表示将 stones[i:j+1] 合并成 p 堆的最小成本
        dp = [[[float('inf')] * (k + 1) for _ in range(n)] for _ in range(n)]
        
        # 初始化：单堆的成本为 0
        for i in range(n):
            dp[i][i][1] = 0
        
        # 枚举区间长度
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                # 合并成 p 堆
                for p in range(2, k + 1):
                    for mid in range(i, j, k - 1):
                        dp[i][j][p] = min(dp[i][j][p], 
                                         dp[i][mid][1] + dp[mid + 1][j][p - 1])
                
                # 合并成 1 堆
                dp[i][j][1] = dp[i][j][k] + prefix[j + 1] - prefix[i]
        
        return dp[0][n - 1][1]
```

## 复杂度分析

- 时间复杂度：O(n^3 / k)
- 空间复杂度：O(n^2 * k)

## 关键点总结

1. 检查是否能合并成一堆的条件
2. 使用三维DP记录合并成不同堆数的成本
3. 中间节点的选择要满足 k-1 的倍数关系
4. 使用前缀和快速计算区间和

## 易错点

1. 忘记检查能否合并成一堆
2. 中间节点的步长应该是 k-1 而不是 1
3. 合并成 1 堆需要先合并成 k 堆
4. 初始化时忘记设置单堆的成本为 0
