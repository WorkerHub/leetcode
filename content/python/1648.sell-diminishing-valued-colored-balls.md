## 题目描述

你有一些彩色球，颜色标注为整数 `1` 到 `n`，每种颜色的球数量由整数数组 `inventory` 给出，`inventory[i]` 是第 `i` 种颜色球的数量。

客户想要购买 `orders` 个球。对于每种颜色的球，第 `i` 次购买该颜色的球将获得 `inventory[j] - i + 1` 的利润（从最多的开始卖）。

你想最大化总利润，返回**最大利润**（结果对 `10^9 + 7` 取余）。

**策略：** 每次卖出**当前最多**的颜色中的一个球。

## 解题思路

**贪心 + 二分：**

每次应该卖当前最多的颜色，但 orders 可能很大，不能逐个模拟。

**批量卖：** 找到一个阈值 t，将所有 > t 的颜色降至 t，计算这样能卖出多少球和获得多少利润，再处理剩余的 orders。

二分查找最优阈值 t。

## 代码实现

### 方法一：二分查找阈值（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxProfit(self, inventory: List[int], orders: int) -> int:
        MOD = 10 ** 9 + 7
        inventory.sort()
        n = len(inventory)
        
        # 二分找阈值 t：将所有 > t 的降至 t，累计能卖出的数量 >= orders
        # 使得我们确定批量卖出的层数
        
        lo, hi = 0, max(inventory)
        while lo < hi:
            mid = (lo + hi) // 2
            # 计算能卖出数量（所有 > mid 的部分）
            count = sum(max(0, x - mid) for x in inventory)
            if count >= orders:
                hi = mid
            else:
                lo = mid + 1
        
        # t = lo，将所有 > t 的降至 t
        t = lo
        
        # 计算利润：等差数列求和
        def sum_from_a_to_b(a: int, b: int) -> int:
            """求 a + (a+1) + ... + b 的和"""
            if a > b:
                return 0
            return (a + b) * (b - a + 1) // 2
        
        profit = 0
        remaining = orders
        
        for x in inventory:
            if x > t:
                # 将 x 降至 t，卖出 x - t 个球，利润为 (t+1) + (t+2) + ... + x
                balls_sold = x - t
                profit += sum_from_a_to_b(t + 1, x)
                profit %= MOD
                remaining -= balls_sold
        
        # 处理最后一层（剩余 remaining 个球，都以 t 的价格卖出）
        # 但有些列可能刚好降到 t，有些没有达到 t
        if remaining > 0:
            profit += remaining * t
            profit %= MOD
        
        return profit % MOD
```

### 方法二：最大堆模拟（理论正确但时间复杂度高）

```python
from typing import List
import heapq

class Solution:
    def maxProfit(self, inventory: List[int], orders: int) -> int:
        MOD = 10 ** 9 + 7
        # 使用负数实现最大堆
        heap = [-x for x in inventory]
        heapq.heapify(heap)
        
        profit = 0
        while orders > 0:
            top = -heapq.heappop(heap)
            second = -heap[0] if heap else 0
            # 可以将 top 降到 second（批量操作）
            batches = top - second
            if batches * len([x for x in heap if -x == second] + [1]) <= orders:
                # 批量卖
                count_at_top = sum(1 for x in heap if -x >= top - batches)
                # 简化为逐步
                pass
            profit = (profit + top) % MOD
            orders -= 1
            if top - 1 > 0:
                heapq.heappush(heap, -(top - 1))
        
        return profit
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(n log n + n log M) | O(1) |
| 堆模拟 | O(orders log n)（可能 TLE） | O(n) |

## 关键点总结

1. 贪心：每次卖最多的颜色的球（从高价到低价）
2. 批量处理：将所有超过阈值 t 的部分一起计算
3. 等差数列求和：`sum_from_a_to_b(t+1, x) = (t+1+x)*(x-t)/2`
4. 最后剩余的 orders 以价格 t 卖出

## 易错点

- 等差数列求和结果可能很大，每步都取模
- 剩余 orders 的处理：有些颜色降到 t，有些没有；剩余的以 t 价格卖
- 二分找的是能使"高于 t 的总球数 >= orders"的最大 t
