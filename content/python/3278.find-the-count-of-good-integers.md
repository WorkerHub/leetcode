## 题目描述

给你两个**正整数** `n` 和 `k`，如果一个 `n` 位整数满足：
1. 它能被 `k` 整除
2. 它能被重排（在不产生前导零的情况下）成一个**回文数**

则称其为**好整数**。

返回 `n` 位**好整数**的数量。

**注意：** 这道题与 3272 的区别是：3272 要求整数本身是回文数，而 3278 要求整数的某种排列是回文数。

**示例 1：**
```
输入：n = 1, k = 4
输出：2
解释：4 和 8 可以被 4 整除，单个数字本身就是回文数
```

**提示：**
- `1 <= n <= 10`
- `1 <= k <= 9`

## 解题思路

一个 n 位整数能重排成回文数的条件：
- n 为偶数：每种数字出现偶数次
- n 为奇数：恰好一种数字出现奇数次，其余出现偶数次

枚举所有满足回文条件的数字组合，然后统计其中能被 k 整除的 n 位整数的排列数。

步骤：
1. 枚举所有能构成 n 位回文数的数字多重集
2. 对每种多重集，生成最大的回文数检验能否被 k 整除，若能则统计所有 n 位排列数

## Python 代码实现

### 方法一：枚举回文数 + 统计排列（推荐）

```python
from math import factorial
from collections import Counter

class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        # 方法：枚举所有 n 位能被 k 整除的回文数，
        # 对每个回文数，统计其数字重排后满足条件的 n 位数的数量
        
        # 但实际上每个回文数的数字是固定的，重排后的 n 位数中
        # 满足能被 k 整除且是回文的只有原来那一个
        # 所以等价于 3272？
        
        # 重读："能被重排成回文数" ≠ "本身是回文数"
        # 一个数的某种排列是回文数，则该数是好整数
        # 好整数 = 数字组合满足回文条件，且能被 k 整除，且不含前导零
        
        # 所以枚举所有满足条件的数字多重集（Counter），
        # 统计 n 位（无前导零）整数的排列数
        
        seen = set()  # 避免重复统计同一种数字组合
        ans = 0
        
        half = (n + 1) // 2
        
        # 枚举 n 位回文数
        start = 10 ** (half - 1)
        end = 10 ** half
        
        for first_half in range(start, end):
            s = str(first_half)
            if n % 2 == 0:
                palindrome = s + s[::-1]
            else:
                palindrome = s + s[-2::-1]
            
            num = int(palindrome)
            if num % k != 0:
                continue
            
            # 用排序后的字符串作为标识
            key = ''.join(sorted(palindrome))
            if key in seen:
                continue
            seen.add(key)
            
            # 统计以 key 为数字组合，n 位无前导零的整数个数
            cnt = Counter(palindrome)
            total = factorial(n)
            for c in cnt.values():
                total //= factorial(c)
            
            # 减去首位为 0 的情况
            if cnt['0'] > 0:
                cnt['0'] -= 1
                zero_first = factorial(n - 1)
                for c in cnt.values():
                    zero_first //= factorial(c)
                cnt['0'] += 1
                total -= zero_first
            
            ans += total
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(10^(n/2))，枚举前半部分
- 空间复杂度：O(10^(n/2))（seen 集合）

## 关键点总结

1. 枚举所有 n 位回文数，找能被 k 整除的
2. 用数字多重集标识（去重）
3. 统计每种多重集的无前导零的 n 位排列数

## 易错点

1. 用排序后的字符串作为多重集的唯一标识，避免重复
2. 统计排列时要减去首位为 0 的情况
