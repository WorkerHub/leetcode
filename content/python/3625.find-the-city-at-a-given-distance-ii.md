## 题目描述

有 `n` 个城市，通过双向加权边相连，`edges[i] = [u, v, w]`。对于每个城市 `i`，找出距离不超过 `distanceThreshold` 的城市数量最少的城市。若多个城市满足，返回编号最大的那个。

**示例 1：**

```
输入：n = 4, edges = [[0,1,3],[1,2,1],[1,3,4],[2,3,1]], distanceThreshold = 4
输出：3
解释：城市3只能到达城市2（距离2），其余城市可到达更多
```

**示例 2：**

```
输入：n = 5, edges = [[0,1,2],[0,4,8],[1,2,3],[1,4,2],[2,3,1],[3,4,1]], distanceThreshold = 2
输出：0
```

**提示：**

- `2 <= n <= 100`
- `1 <= edges.length <= n * (n - 1) / 2`
- `1 <= distanceThreshold <= 10^4`

## 解题思路

Floyd-Warshall 全源最短路：

1. 计算所有节点对之间的最短距离
2. 对每个城市，统计距离 <= `distanceThreshold` 的城市数
3. 找出计数最少的城市（相同时取编号最大）

由于 n <= 100，Floyd 的 O(n^3) 完全可行。

## Python 代码实现

### 方法一：Floyd-Warshall（推荐）

```python
from typing import List

class Solution:
    def findTheCity(self, n: int, edges: List[List[int]], distanceThreshold: int) -> int:
        INF = float('inf')
        # 初始化距离矩阵
        dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            dist[i][i] = 0
        for u, v, w in edges:
            dist[u][v] = min(dist[u][v], w)
            dist[v][u] = min(dist[v][u], w)

        # Floyd-Warshall
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        # 找可达城市数最少的城市（编号最大优先）
        ans = -1
        min_count = n + 1
        for i in range(n):
            count = sum(1 for j in range(n) if i != j and dist[i][j] <= distanceThreshold)
            if count <= min_count:
                min_count = count
                ans = i  # 编号更大的覆盖

        return ans
```

### 方法二：Dijkstra（多次）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def findTheCity(self, n: int, edges: List[List[int]], distanceThreshold: int) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        def dijkstra(src):
            dist = [float('inf')] * n
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, node = heapq.heappop(heap)
                if d > dist[node]:
                    continue
                for nb, w in graph[node]:
                    if d + w < dist[nb]:
                        dist[nb] = d + w
                        heapq.heappush(heap, (d + w, nb))
            return dist

        ans, min_count = -1, n + 1
        for i in range(n):
            d = dijkstra(i)
            count = sum(1 for j in range(n) if i != j and d[j] <= distanceThreshold)
            if count <= min_count:
                min_count = count
                ans = i
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^3)（Floyd），O(n * (V + E) log V)（Dijkstra 多次）
- 空间复杂度：O(n^2)

## 关键点总结

1. n <= 100 时 Floyd-Warshall 最简单
2. 统计可达城市数时排除自身
3. 相同计数取编号最大，遍历时用 `<=` 覆盖

## 易错点

1. Floyd 初始化：`dist[i][i] = 0`，其余为无穷大
2. 多边取最小值初始化
3. 返回编号最大：遍历时用 `count <= min_count` 而不是 `<`
