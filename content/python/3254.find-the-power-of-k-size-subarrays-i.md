## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

如果长度为 `k` 的子数组中的元素是**连续的且递增的**（即 `nums[i], nums[i]+1, ..., nums[i]+k-1`），则该子数组的**幂**为其最大值（即 `nums[i+k-1]`）；否则幂为 `-1`。

返回长度为 `n - k + 1` 的数组，包含每个长度为 `k` 的子数组的幂。

**示例 1：**
```
输入：nums = [1,2,3,4,3,2,5], k = 3
输出：[3,4,-1,-1,-1]
```

**示例 2：**
```
输入：nums = [2,2,2,2,2], k = 4
输出：[-1,-1]
```

**提示：**
- `1 <= n <= 500`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= n`

## 解题思路

滑动窗口：维护以当前位置结尾的最长"连续递增"子数组的长度 `cnt`。

- 若 `nums[i] == nums[i-1] + 1`，则 `cnt += 1`，否则 `cnt = 1`
- 对位置 `i`（子数组结尾），若 `cnt >= k`，则子数组的幂为 `nums[i]`，否则为 `-1`

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        # cnt[i] = 以 i 结尾的最长连续递增子数组长度
        cnt = 1
        ans = []
        
        for i in range(n):
            if i > 0 and nums[i] == nums[i - 1] + 1:
                cnt += 1
            else:
                cnt = 1
            
            if i >= k - 1:
                if cnt >= k:
                    ans.append(nums[i])
                else:
                    ans.append(-1)
        
        return ans
```

### 方法二：暴力检查

```python
from typing import List

class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        ans = []
        for i in range(n - k + 1):
            # 检查 nums[i..i+k-1] 是否连续递增
            valid = all(nums[i + j] == nums[i] + j for j in range(k))
            ans.append(nums[i + k - 1] if valid else -1)
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n * k)，空间复杂度 O(1)

## 关键点总结

1. 维护以每个位置结尾的最长连续递增长度
2. 当前位置与前一位置差为 1 时，长度加 1；否则重置为 1
3. 若连续递增长度 >= k，则该子数组的幂为最后一个元素

## 易错点

1. 连续递增要求差恰好为 1，而不是任意递增
2. 注意下标起始：结果数组从 k-1 开始
