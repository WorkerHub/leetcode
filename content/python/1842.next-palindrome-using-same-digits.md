## 题目描述

给你一个数字字符串 `num`（长度为偶数），它是一个回文串。找到使用相同数字的最小回文串，且严格大于 `num`。若不存在，返回空字符串 `""`。

**示例 1：**
```
输入：num = "1221"
输出："2112"
```

**示例 2：**
```
输入：num = "5225"
输出："5520" -> 实际输出 "5520"
```

**提示：**
- `num.length` 为偶数
- `num` 只包含数字

## 解题思路

由于 num 是回文串，它由前半部分决定。问题转化为：

**在前半部分（长度 n/2）的数字上找下一个排列（Next Permutation）**，然后将其镜像作为整个回文串。

若前半部分已是最大排列（降序），则不存在更大的回文，返回空字符串。

**Next Permutation 算法**：
1. 从右向左找第一个下降的位置 i（`a[i] < a[i+1]`）
2. 从右向左找第一个比 `a[i]` 大的位置 j
3. 交换 `a[i]` 和 `a[j]`
4. 反转 `a[i+1:]`

## 代码实现

### 方法一：前半部分 Next Permutation（推荐）

```python
class Solution:
    def nextPalindrome(self, num: str) -> str:
        n = len(num)
        half = list(num[:n // 2])  # 取前半部分

        # 在前半部分上执行 Next Permutation
        # 步骤1：从右向左找第一个下降位置
        i = len(half) - 2
        while i >= 0 and half[i] >= half[i + 1]:
            i -= 1

        if i < 0:
            return ""  # 已是最大排列，不存在更大的回文

        # 步骤2：找右侧第一个比 half[i] 大的元素
        j = len(half) - 1
        while half[j] <= half[i]:
            j -= 1

        # 步骤3：交换
        half[i], half[j] = half[j], half[i]

        # 步骤4：反转 i+1 之后的部分
        half[i + 1:] = half[i + 1:][::-1]

        # 构建回文串
        front = ''.join(half)
        return front + front[::-1]
```

## 复杂度分析

- **时间复杂度**：O(n)，Next Permutation 是线性的
- **空间复杂度**：O(n)，存储前半部分

## 关键点总结

1. 回文串由前半部分完全决定，只需对前半部分求下一排列
2. Next Permutation 是标准算法：找下降点 -> 找交换点 -> 交换 -> 反转后缀
3. 若前半部分已降序（最大排列），返回空字符串

## 易错点

- Next Permutation 中反转后缀（步骤4），不是排序，直接反转即可（后缀是降序的，反转后变升序）
- 构造回文串：`front + front[::-1]`（偶数长度直接拼接）
