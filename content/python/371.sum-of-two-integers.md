## 题目描述

给你两个整数 `a` 和 `b`，不使用运算符 `+` 和 `-`，计算并返回两整数之和。

**示例 1：**

```
输入：a = 1, b = 2
输出：3
```

**示例 2：**

```
输入：a = 2, b = 3
输出：5
```

**提示：**
- `-1000 <= a, b <= 1000`

## 解题思路

这道题考察位运算的基础知识。关键是理解加法的本质：

### 加法的位运算实现

加法可以分解为两个步骤：
1. **不考虑进位的加法**：使用异或运算（XOR）`a ^ b`
2. **计算进位**：使用与运算（AND）再左移 `(a & b) << 1`

重复这两步，直到没有进位为止。

### 示例演示

```
a = 5 (101)
b = 3 (011)

第一轮：
  不进位加法：101 ^ 011 = 110 (6)
  进位：      (101 & 011) << 1 = 001 << 1 = 010 (2)

第二轮：
  a = 110, b = 010
  不进位加法：110 ^ 010 = 100 (4)
  进位：      (110 & 010) << 1 = 010 << 1 = 100 (4)

第三轮：
  a = 100, b = 100
  不进位加法：100 ^ 100 = 000 (0)
  进位：      (100 & 100) << 1 = 100 << 1 = 1000 (8)

第四轮：
  a = 000, b = 1000
  不进位加法：000 ^ 1000 = 1000 (8)
  进位：      (000 & 1000) << 1 = 0

结果：8 (5 + 3 = 8)
```

### 负数处理

Python 中整数是无限精度的，需要特殊处理负数：
- 使用掩码 `0xFFFFFFFF` 限制为 32 位
- 对于负数结果，需要转换回 Python 的负数表示

## Python 代码实现

### 方法一：位运算（Python 3 处理负数）

```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        """
        使用位运算实现加法
        处理 Python 中的负数
        
        时间复杂度：O(1)，最多循环 32 次
        空间复杂度：O(1)
        """
        # 32 位掩码
        mask = 0xFFFFFFFF
        
        while b != 0:
            # 不考虑进位的加法
            sum_without_carry = (a ^ b) & mask
            # 计算进位
            carry = ((a & b) << 1) & mask
            
            a = sum_without_carry
            b = carry
        
        # 处理负数：如果最高位是 1，则为负数
        # Python 中需要转换为负数表示
        if a > 0x7FFFFFFF:  # 最高位为 1
            return ~(a ^ mask)
        else:
            return a
```

### 方法二：递归实现

```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        """
        递归实现
        """
        mask = 0xFFFFFFFF
        
        # 递归终止条件
        if b == 0:
            # 处理负数
            return a if a <= 0x7FFFFFFF else ~(a ^ mask)
        
        # 不考虑进位的和
        sum_without_carry = (a ^ b) & mask
        # 进位
        carry = ((a & b) << 1) & mask
        
        return self.getSum(sum_without_carry, carry)
```

### 方法三：简化版（仅适用于非负数或特定语言）

```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        """
        简化版，不处理 Python 的负数问题
        仅在某些受限环境或其他语言中有效
        """
        while b != 0:
            # 不进位加法
            sum_val = a ^ b
            # 进位
            carry = (a & b) << 1
            
            a = sum_val
            b = carry
        
        return a
```

### 方法四：使用内置函数（作弊，仅供理解）

```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        """
        使用 Python 内置的 sum（仅用于理解题意）
        题目不允许使用 + 和 -
        """
        return sum([a, b])
```

## 复杂度分析

### 方法一/二/三：位运算
- 时间复杂度：O(1)，最多循环 32 次（32 位整数）
- 空间复杂度：O(1)

## 关键点总结

1. **异或（XOR）**：不考虑进位的加法
   - `1 ^ 1 = 0`
   - `1 ^ 0 = 1`
   - `0 ^ 0 = 0`
2. **与（AND）+ 左移**：计算进位
   - `(a & b) << 1`
3. **循环终止**：当没有进位时（`b == 0`）
4. **掩码**：`0xFFFFFFFF` 限制为 32 位
5. **负数处理**：Python 特有问题，需要转换

## 易错点

1. **负数处理**：Python 中整数是无限精度的，需要掩码
2. **死循环**：忘记使用掩码导致负数时死循环
3. **符号转换**：`~(a ^ mask)` 将补码转换为 Python 负数
4. **边界值**：`0x7FFFFFFF` 是 32 位有符号整数的最大正数
5. **语言差异**：这道题在不同语言中实现细节不同

## 图解示例

### 示例：a = 1, b = 2

```
a = 1 (001)
b = 2 (010)

第一轮：
  a ^ b = 001 ^ 010 = 011 (3)
  (a & b) << 1 = (001 & 010) << 1 = 000 << 1 = 000 (0)
  
  a = 3, b = 0

b == 0，返回 a = 3
```

### 示例：a = -1, b = 1

```
在 32 位补码表示中：
a = -1 = 0xFFFFFFFF (全 1)
b = 1  = 0x00000001

第一轮：
  a ^ b = 0xFFFFFFFE
  (a & b) << 1 = (0xFFFFFFFF & 0x00000001) << 1 = 0x00000002
  
  a = 0xFFFFFFFE, b = 0x00000002

第二轮：
  a ^ b = 0xFFFFFFFC
  (a & b) << 1 = (0xFFFFFFFE & 0x00000002) << 1 = 0x00000004
  
  ... (继续迭代直到 b = 0)

最终结果：0 (即 -1 + 1 = 0)
```

## 学习建议

1. **理解位运算**：
   - XOR（异或）：不同为 1，相同为 0
   - AND（与）：都为 1 才为 1
   - 左移：相当于乘以 2
2. **加法本质**：
   - 无进位加法 = XOR
   - 进位 = AND + 左移
3. **掌握补码**：负数在计算机中用补码表示
4. **Python 特性**：
   - 无限精度整数
   - 需要手动处理 32 位限制
5. **其他语言对比**：
   - Java/C++：有固定位数，更简单
   - Python：需要额外处理
6. **扩展思考**：
   - 如何用位运算实现减法？（a - b = a + (-b)）
   - 如何实现乘法？（累加或移位累加）
   - 如何实现除法？（减法 + 移位）
