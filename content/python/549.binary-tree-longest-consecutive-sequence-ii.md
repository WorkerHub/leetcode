## 题目描述

给定二叉树的根 root，返回树中最长连续序列路径的长度。

连续序列路径是指路径中相邻节点的值相差 1。该路径可以是递增的或递减的。

例如，[1,2,3,4] 和 [4,3,2,1] 都被认为是有效的，但路径 [1,2,4,3] 则不是有效的。

注意：路径可以从任何节点开始和结束。

**示例 1：**
```
输入：root = [1,2,3]
输出：2
解释：最长连续序列路径是 [1, 2] 或 [2, 1]
```

**示例 2：**
```
输入：root = [2,1,3]
输出：3
解释：最长连续序列路径是 [1, 2, 3] 或 [3, 2, 1]
```

**提示：**
- 树中节点数在范围 [1, 3 * 10^4] 内
- -3 * 10^4 <= Node.val <= 3 * 10^4

## 解题思路

这道题与普通的最长连续序列不同，路径可以是递增或递减，且可以从任意节点开始和结束。

**核心思想：**
1. 对每个节点，计算通过它的最长连续路径
2. 路径可能由递增段和递减段组成
3. 使用后序遍历，先计算子树信息再处理当前节点

**状态定义：**
- 对每个节点返回两个值：
  - `inc`：以该节点结尾的最长递增序列长度
  - `dec`：以该节点结尾的最长递减序列长度

**关键观察：**
- 最长路径可能是：递增段 + 当前节点 + 递减段

## Python 代码实现

### 方法一：后序遍历（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def longestConsecutive(self, root: Optional[TreeNode]) -> int:
        self.max_len = 0
        
        def dfs(node: Optional[TreeNode]) -> tuple:
            """
            返回 (递增长度, 递减长度)
            递增：子节点值 = 当前值 + 1
            递减：子节点值 = 当前值 - 1
            """
            if not node:
                return 0, 0
            
            # 初始化当前节点的递增和递减长度
            inc = dec = 1
            
            # 处理左子树
            if node.left:
                left_inc, left_dec = dfs(node.left)
                # 如果左孩子值 = 当前值 + 1，可以形成递增序列
                if node.left.val == node.val + 1:
                    inc = max(inc, left_inc + 1)
                # 如果左孩子值 = 当前值 - 1，可以形成递减序列
                elif node.left.val == node.val - 1:
                    dec = max(dec, left_dec + 1)
            
            # 处理右子树
            if node.right:
                right_inc, right_dec = dfs(node.right)
                # 如果右孩子值 = 当前值 + 1，可以形成递增序列
                if node.right.val == node.val + 1:
                    inc = max(inc, right_inc + 1)
                # 如果右孩子值 = 当前值 - 1，可以形成递减序列
                elif node.right.val == node.val - 1:
                    dec = max(dec, right_dec + 1)
            
            # 更新全局最大值：递增 + 递减 - 1（减去当前节点的重复计数）
            self.max_len = max(self.max_len, inc + dec - 1)
            
            return inc, dec
        
        dfs(root)
        return self.max_len
```

### 方法二：更清晰的实现

```python
class Solution:
    def longestConsecutive(self, root: Optional[TreeNode]) -> int:
        self.result = 0
        
        def helper(node: Optional[TreeNode]) -> tuple:
            if not node:
                return 0, 0
            
            # 递归处理左右子树
            left_inc, left_dec = helper(node.left)
            right_inc, right_dec = helper(node.right)
            
            # 当前节点的递增和递减长度初始化为1
            inc, dec = 1, 1
            
            # 检查左孩子
            if node.left:
                if node.left.val == node.val + 1:
                    inc = left_inc + 1
                elif node.left.val == node.val - 1:
                    dec = left_dec + 1
            
            # 检查右孩子
            if node.right:
                if node.right.val == node.val + 1:
                    inc = max(inc, right_inc + 1)
                elif node.right.val == node.val - 1:
                    dec = max(dec, right_dec + 1)
            
            # 更新结果：通过当前节点的最长路径
            self.result = max(self.result, inc + dec - 1)
            
            return inc, dec
        
        helper(root)
        return self.result
```

### 方法三：单遍历实现

```python
class Solution:
    def longestConsecutive(self, root: Optional[TreeNode]) -> int:
        def dfs(node):
            if not node:
                return 0, 0
            
            inc = dec = 1
            left_inc, left_dec = dfs(node.left)
            right_inc, right_dec = dfs(node.right)
            
            if node.left:
                if node.left.val - node.val == 1:
                    inc = max(inc, left_inc + 1)
                elif node.val - node.left.val == 1:
                    dec = max(dec, left_dec + 1)
            
            if node.right:
                if node.right.val - node.val == 1:
                    inc = max(inc, right_inc + 1)
                elif node.val - node.right.val == 1:
                    dec = max(dec, right_dec + 1)
            
            self.ans = max(self.ans, inc + dec - 1)
            return inc, dec
        
        self.ans = 0
        dfs(root)
        return self.ans
```

## 复杂度分析

- 时间复杂度：O(n)，其中 n 是树中节点的数量，每个节点访问一次
- 空间复杂度：O(h)，其中 h 是树的高度，递归调用栈的深度

## 图解示例

```
示例树：
      2
     / \
    1   3

分析：
1. 节点 1：inc=1, dec=1
2. 节点 3：inc=1, dec=1
3. 节点 2：
   - 左孩子 1 = 2-1，形成递减：dec=2
   - 右孩子 3 = 2+1，形成递增：inc=2
   - 路径长度：inc + dec - 1 = 2 + 2 - 1 = 3
   
最长路径：[1, 2, 3] 或 [3, 2, 1]，长度为 3
```

## 关键点总结

1. 使用后序遍历，先处理子树再处理当前节点
2. 每个节点维护递增和递减两个状态
3. 最长路径可能由递增段和递减段组成
4. 返回值包含两个信息：递增长度和递减长度
5. 全局变量记录最大值

## 易错点

1. 忘记路径可以是递增或递减
2. 计算路径长度时重复计算当前节点
3. 没有考虑路径可以从任意节点开始
4. 混淆递增和递减的判断条件
