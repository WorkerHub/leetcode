## 题目描述

给你两个非负整数 `low` 和 `high`，返回在区间 `[low, high]` 内奇数的数目。

**示例 1：**

```
输入：low = 3, high = 7
输出：3
解释：区间 [3, 7] 内的奇数为 3, 5, 7，共 3 个。
```

**示例 2：**

```
输入：low = 8, high = 10
输出：1
解释：区间 [8, 10] 内的奇数为 9，共 1 个。
```

**提示：**
- `0 <= low <= high <= 10^9`

## 解题思路

数学公式：区间 `[1, n]` 内奇数的个数为 `(n + 1) // 2`。

利用前缀奇数计数函数 `count_odds(n) = (n + 1) // 2`，区间 `[low, high]` 内的奇数数目 = `count_odds(high) - count_odds(low - 1)`。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # [1, n] 中奇数个数为 (n + 1) // 2
        def prefix_odd_count(n):
            return (n + 1) // 2

        return prefix_odd_count(high) - prefix_odd_count(low - 1)
```

### 方法二：直接计算

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # 区间长度
        length = high - low + 1
        # 若 low 为奇数，奇数个数为 (length + 1) // 2
        # 若 low 为偶数，奇数个数为 length // 2
        if low % 2 == 1:
            return (length + 1) // 2
        else:
            return length // 2
```

## 复杂度分析

- 时间复杂度：O(1)，纯数学计算
- 空间复杂度：O(1)

## 关键点总结

1. 使用前缀奇数计数函数 `(n+1)//2` 可以快速计算任意区间内的奇数个数。
2. 区间 `[low, high]` 的奇数数目 = `count(high) - count(low - 1)`。
3. 两种方法等价，方法一更通用。

## 易错点

1. `low = 0` 时 `low - 1 = -1`，`(-1 + 1) // 2 = 0`，处理正确。
2. 不要直接枚举，范围可达 10^9。
