## 题目描述

你正在参加一个多角色游戏，每个角色有两个属性 `attack` 和 `defense`。给你一个二维整数数组 `properties`，其中 `properties[i] = [attack_i, defense_i]`。

如果一个角色的 `attack` 和 `defense` **均严格小于**另一个角色，则这个角色是**弱角色**。

返回弱角色的数量。

**示例 1：**
```
输入：properties = [[5,5],[6,3],[3,6]]
输出：0
```

**示例 2：**
```
输入：properties = [[2,2],[3,3]]
输出：1
```

**提示：**
- `2 <= properties.length <= 10^5`
- `1 <= attack_i, defense_i <= 10^5`

---

## 解题思路

### 核心思想：排序 + 贪心（维护最大 defense）

关键排序策略：
- 按 `attack` **降序**排列
- 相同 `attack` 的按 `defense` **升序**排列（避免同 attack 互相影响）

排序后，从左到右扫描：维护已见的最大 `defense`（`max_def`），若当前角色的 `defense < max_def`，则它是弱角色（因为已经有 attack 更大的角色，defense 也更大）。

相同 attack 按 defense 升序排列是关键：保证同 attack 的不会误判为弱角色。

---

## 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def numberOfWeakCharacters(self, properties: List[List[int]]) -> int:
        # attack 降序，相同 attack 时 defense 升序
        properties.sort(key=lambda x: (-x[0], x[1]))

        max_def = 0
        count = 0

        for atk, df in properties:
            if df < max_def:
                count += 1
            else:
                max_def = max(max_def, df)

        return count
```

### 方法二：排序 + 单调栈（等价）

```python
from typing import List

class Solution:
    def numberOfWeakCharacters(self, properties: List[List[int]]) -> int:
        # 同方法一的排序，然后维护 defense 的最大值
        properties.sort(key=lambda x: (-x[0], x[1]))

        ans = 0
        max_defense = 0

        for _, defense in properties:
            if defense < max_defense:
                ans += 1
            max_defense = max(max_defense, defense)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 贪心 | O(n log n) | O(1) |

---

## 关键点总结

1. 按 attack 降序排序后，前面的 attack 都 >= 当前
2. 相同 attack 按 defense 升序，防止误判（同 attack 不算弱）
3. 维护 max_def：当前 defense < max_def 则为弱角色

---

## 易错点

- 相同 attack 时 defense 必须升序排列，否则同一组的会互相误判
- `max_def = max(max_def, df)` 不需要判断，每次更新即可
