## 题目描述

给你一个 **下标从 0 开始** 的整数数组 `nums`。你可以将 `nums` 中的元素按 **任意顺序** 重新排列。

令 `prefix` 为一个数组，其中 `prefix[i]` 是重排后数组中前 `i + 1` 个元素的前缀和。若 `prefix[i] > 0`，则 `prefix[i]` 对应的 **分数** 加 1。

返回你能够得到的 **最大分数**。

**示例 1：**

```
输入：nums = [2,-1,0,1,-3,3,-3]
输出：6
解释：将数组重排为 [3,2,1,-1,-3,-3,0]
前缀和：[3,5,6,5,2,-1,-1]，前 6 项 > 0，得分 6。
```

**示例 2：**

```
输入：nums = [-2,-3,0,2,-1,3,-3]
输出：4
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^6 <= nums[i] <= 10^6`

## 解题思路

**贪心**：将数组降序排序，使前缀和尽可能长时间保持正数。

降序排列后，计算前缀和，统计前缀和 > 0 的个数即为最大分数。

直觉：把大的数放前面，前缀和下降得最慢，可以让更多前缀和为正。

## Python 代码实现

### 方法一：降序排序 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        # 降序排列：大数在前，前缀和尽量保持正
        nums.sort(reverse=True)

        score = 0
        prefix = 0
        for x in nums:
            prefix += x
            if prefix > 0:
                score += 1
            else:
                break  # 后续元素更小，前缀和只会更小
        return score
```

### 方法二：不提前退出的完整版

```python
from typing import List
import itertools

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        nums.sort(reverse=True)
        # 计算前缀和列表
        prefix = list(itertools.accumulate(nums))
        # 统计正数个数
        return sum(1 for p in prefix if p > 0)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)（方法一原地排序）或 O(n)（方法二前缀和列表）

## 关键点总结

1. 降序排序是最优策略，保证前缀和下降最慢
2. 一旦前缀和 <= 0 可以提前终止（后续元素不大于当前元素）
3. 用 `itertools.accumulate` 可以优雅地计算前缀和

## 易错点

1. 前缀和严格大于 0 才得分（`prefix > 0`，不含等于 0）
2. 提前终止的条件正确性：降序后若当前前缀和 <= 0，后续加入更小的数只会更小
3. 不能使用升序排列，那样会让负数先进入导致得分低
