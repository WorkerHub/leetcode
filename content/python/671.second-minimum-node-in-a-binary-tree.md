## 题目描述

给定一个特殊的二叉树，其中每个节点都有 0 个或 2 个子节点。树中所有节点的值都不相同。

如果一个节点有两个子节点，那么该节点的值等于两个子节点中较小的值。

更正式地说，root.val = min(root.left.val, root.right.val) 总成立。

给定这样的二叉树，返回所有节点值中第二小的值。如果不存在第二小的值，返回 -1。

**示例 1：**
```
输入：root = [2,2,5,null,null,5,7]
输出：5
解释：最小值是2，第二小的值是5
```

**示例 2：**
```
输入：root = [2,2,2]
输出：-1
解释：最小值是2，但不存在第二小的值
```

**提示：**
- 树中节点数在 [1, 25] 范围内
- 1 <= Node.val <= 2^31 - 1
- root.val == min(root.left.val, root.right.val)

## 解题思路

利用题目给定的特殊性质：根节点的值一定是最小值。

**关键观察：**
1. 根节点的值就是最小值
2. 第二小的值一定在某个子节点中
3. 如果子节点值等于根节点值，需要继续向下找
4. 如果子节点值大于根节点值，它可能是第二小值的候选

**算法策略：**
- DFS 遍历树
- 跳过等于根节点值的节点
- 找到所有大于根节点值的节点中的最小值

## Python 代码实现

### 方法一：DFS（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        min_val = root.val
        self.second_min = float('inf')
        
        def dfs(node):
            if not node:
                return
            
            # 如果当前节点值大于最小值，更新第二小值
            if min_val < node.val < self.second_min:
                self.second_min = node.val
            
            # 只有当节点值等于最小值时，才需要继续搜索子树
            # 因为如果 node.val > min_val，子树的值一定 >= node.val
            if node.val == min_val:
                dfs(node.left)
                dfs(node.right)
        
        dfs(root)
        return self.second_min if self.second_min != float('inf') else -1
```

### 方法二：简化递归

```python
class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        def dfs(node, min_val):
            """返回子树中大于min_val的最小值"""
            if not node:
                return -1
            
            # 如果当前节点值大于最小值，它是候选值
            if node.val > min_val:
                return node.val
            
            # 当前节点值等于最小值，继续搜索子树
            left = dfs(node.left, min_val)
            right = dfs(node.right, min_val)
            
            # 合并左右子树的结果
            if left == -1:
                return right
            if right == -1:
                return left
            return min(left, right)
        
        return dfs(root, root.val)
```

### 方法三：BFS 遍历

```python
from collections import deque

class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        min_val = root.val
        second_min = float('inf')
        
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            
            if min_val < node.val < second_min:
                second_min = node.val
            
            # 只有值等于最小值的节点才需要继续搜索
            if node.val == min_val:
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return second_min if second_min != float('inf') else -1
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，最坏情况需要遍历所有节点
- 空间复杂度：O(h)，h 为树的高度，递归栈或队列空间

## 图解示例

以 root = [2,2,5,null,null,5,7] 为例：

```
树结构：
      2
     / \
    2   5
       / \
      5   7

DFS过程：
1. root(2): val=2=min_val, 继续搜索左右子树
2. left(2): val=2=min_val, 继续搜索左右子树（都是null）
3. right(5): val=5>min_val, second_min=5
   但还是检查子树（因为可能有更小的）
4. right.left(5): val=5=second_min, 不更新
5. right.right(7): val=7>second_min, 不更新

返回 second_min = 5
```

## 关键点总结

1. **根节点性质**：根节点值一定是最小值
2. **剪枝优化**：节点值 > min_val 时不需要搜索子树
3. **第二小定义**：严格大于最小值的最小值
4. **不存在情况**：所有节点值都相同时返回 -1
5. **递归返回**：返回子树中的候选值，在父节点合并

## 易错点

1. **忘记剪枝**：值大于最小值的节点无需继续搜索
2. **边界情况**：只有根节点、所有值相同等情况
3. **初始值设置**：second_min 初始化为 inf，便于更新
4. **相等处理**：值等于根节点的要继续搜索，不是候选值
5. **返回条件**：未找到时返回 -1，不是 inf
