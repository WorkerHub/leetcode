## 题目描述

给你一个整数数组 `nums`，将该数组分割成一个或多个连续子数组，使每个子数组的所有元素的 **最大公约数（GCD）严格大于 1**。

返回满足条件的 **最少** 子数组数目。

**示例 1：**
```
输入：nums = [12,6,3,14,8]
输出：2
解释：[12,6,3] 的 GCD 为 3，[14,8] 的 GCD 为 2。共 2 个子数组。
```

**示例 2：**
```
输入：nums = [4,12,6,14]
输出：1
解释：整个数组 GCD 为 2。
```

**提示：**
- `1 <= nums.length <= 2000`
- `2 <= nums[i] <= 10^9`

## 解题思路

**贪心：**

每次尽可能延长当前子数组：维护当前子数组的 GCD，只要 GCD > 1 就继续扩展；一旦加入新元素后 GCD 变为 1，就在前一个位置分割，开启新的子数组。

**注意：** 题目保证 `nums[i] >= 2`，所以单个元素的 GCD 就是元素本身（>= 2 > 1）。因此每个元素单独成一个子数组时也满足条件。

## 代码实现

### 方法一：贪心 + GCD（推荐）

```python
from typing import List
import math

class Solution:
    def minimumSplits(self, nums: List[int]) -> int:
        ans = 1
        cur_gcd = nums[0]  # 当前子数组的 GCD

        for i in range(1, len(nums)):
            new_gcd = math.gcd(cur_gcd, nums[i])
            if new_gcd == 1:
                # GCD 变为 1，必须在此处分割
                ans += 1
                cur_gcd = nums[i]  # 新子数组从当前元素开始
            else:
                cur_gcd = new_gcd  # 继续延伸当前子数组

        return ans
```

### 方法二：动态规划（验证贪心）

```python
from typing import List
import math

class Solution:
    def minimumSplits(self, nums: List[int]) -> int:
        n = len(nums)
        # dp[i] = 前 i 个元素分割成满足条件的最少子数组数
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            g = nums[i - 1]
            for j in range(i - 1, -1, -1):
                # 子数组 nums[j..i-1] 的 GCD 是 g
                if g == 1:
                    break  # 后续 GCD 只会更小，不需要继续
                dp[i] = min(dp[i], dp[j] + 1)
                if j > 0:
                    g = math.gcd(g, nums[j - 1])

            # 处理 j=0 时的情况（整个从 0 到 i-1 的子数组）
            if g > 1:
                dp[i] = min(dp[i], dp[0] + 1)

        return dp[n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n log(max_val)) | O(1) |
| 动态规划 | O(n^2 log(max_val)) | O(n) |

## 关键点总结

1. 贪心：当前 GCD 为 1 时必须分割，否则继续延伸
2. 单个元素（>= 2）满足 GCD > 1 的条件，保证可以分割
3. GCD 随子数组增长单调不增

## 易错点

- GCD 变为 1 时，新子数组从当前元素开始，不是下一个元素
- 题目保证 `nums[i] >= 2`，单独一个元素 GCD = nums[i] >= 2 > 1，合法
