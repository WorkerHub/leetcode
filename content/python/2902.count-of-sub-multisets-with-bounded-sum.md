## 题目描述

给你一个下标从 0 开始的非负整数数组 `nums` 和两个整数 `l` 和 `r`。

返回 `nums` 的 **子多重集** 的数目，子多重集的元素和在 `[l, r]` 范围内。

由于答案可能很大，返回答案对 `10^9 + 7` 取余的结果。

子多重集是从原数组中选取部分元素（可以选 0 个）组成的集合，其中相同值的元素视为不同元素，但选取时计数。

**示例 1：**
```
输入：nums = [1,2,2,3], l = 6, r = 6
输出：1
解释：只有子多重集 {1,2,3} 的和为 6
```

**示例 2：**
```
输入：nums = [2,1,4,2,7], l = 1, r = 5
输出：7
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `0 <= nums[i] <= 2 * 10^4`
- `nums` 的和不超过 `2 * 10^4`
- `0 <= l <= r <= 2 * 10^4`

## 解题思路

使用多重背包 + 滑动窗口优化的动态规划。

首先统计每个数字出现的次数，然后对每个数字做有界多重背包。

关键优化：对于每个数字 `v`，若其出现次数为 `c`，则在 `dp` 数组上做滑动窗口优化，将 O(S*c) 的转移优化为 O(S)。

特别处理：0 出现 `c0` 次时，所有有效子集数量乘以 `(c0 + 1)`，因为 0 不影响和但会产生 `c0 + 1` 种不同的选法。

## Python 代码实现

### 方法一：多重背包 + 滑动窗口（推荐）

```python
from typing import List
from collections import Counter
from collections import deque

class Solution:
    def countSubMultisets(self, nums: List[int], l: int, r: int) -> int:
        MOD = 10**9 + 7
        total = sum(nums)
        if l > total:
            return 0
        r = min(r, total)

        cnt = Counter(nums)
        # 单独处理 0：0 不影响和，有 cnt[0]+1 种选法
        zero_ways = cnt.pop(0, 0) + 1

        # dp[s] 表示和恰好为 s 的子多重集数目
        dp = [0] * (r + 1)
        dp[0] = 1

        for v, c in cnt.items():
            if v > r:
                continue
            # 滑动窗口优化多重背包
            # 对于 dp 数组中每个模 v 的余数分组单独处理
            new_dp = dp[:]
            for rem in range(v):
                # 收集同余类的下标
                window = deque()
                # window 存 (dp值的前缀和, 下标)
                prefix = 0
                q = deque()  # 存前缀和
                # 直接用前缀和滑动窗口
                indices = list(range(rem, r + 1, v))
                # 前缀和数组
                s = [0] * (len(indices) + 1)
                for i, idx in enumerate(indices):
                    s[i + 1] = (s[i] + dp[idx]) % MOD
                # 对每个位置 i，可以从 max(0, i-c) 到 i-1 转移
                for i in range(len(indices)):
                    lo = max(0, i - c)
                    new_dp[indices[i]] = (s[i + 1] - s[lo] + MOD) % MOD
            dp = new_dp

        ans = sum(dp[l:r + 1]) % MOD
        return ans * zero_ways % MOD
```

### 方法二：简化版动态规划（思路清晰）

```python
from typing import List
from collections import Counter

class Solution:
    def countSubMultisets(self, nums: List[int], l: int, r: int) -> int:
        MOD = 10**9 + 7
        total = sum(nums)
        r = min(r, total)
        if l > r:
            return 0

        cnt = Counter(nums)
        zero_factor = cnt.pop(0, 0) + 1

        # dp[s] = 和为 s 的方案数
        dp = [0] * (r + 1)
        dp[0] = 1

        for v, c in cnt.items():
            if v > r:
                continue
            # 从右向左更新（有界背包转无界前先处理）
            # 使用前缀和优化：对每个余数类做滑动窗口
            for j in range(r, -1, -1):
                if dp[j] == 0:
                    continue
                for k in range(1, c + 1):
                    if j + k * v > r:
                        break
                    dp[j + k * v] = (dp[j + k * v] + dp[j]) % MOD

        # 注意：上面简化版有重复计算问题，仅作思路说明
        # 实际使用方法一
        return sum(dp[l:r + 1]) % MOD * zero_factor % MOD
```

## 复杂度分析

- 时间复杂度：O(S * K)，S = sum(nums)，K 为不同数字种类数，滑动窗口后整体 O(S)
- 空间复杂度：O(S)，dp 数组大小

## 关键点总结

1. 将 0 单独处理，避免其干扰背包容量计算
2. 多重背包的滑动窗口优化：对每个余数类独立处理，用前缀和将复杂度从 O(S*c) 降到 O(S)
3. 答案是区间 `[l, r]` 内所有 dp 值之和，再乘以 0 的方案数

## 易错点

1. 0 的处理：选 0 个 0、1 个 0、...、c0 个 0 共 c0+1 种，独立于和
2. r 需要 clamp 到 total，防止数组越界
3. 取余操作要在每步做，防止溢出
