## 题目描述

有一些不规则的硬币。在这些硬币中，`prob[i]` 表示第 `i` 枚硬币正面朝上的概率。

请对每一枚硬币抛掷一次，然后返回正面朝上的硬币数等于 `target` 的概率。

示例 1：
```
输入：prob = [0.4], target = 1
输出：0.40000
```

示例 2：
```
输入：prob = [0.5,0.5,0.5,0.5,0.5], target = 0
输出：0.03125
```

提示：
- `1 <= prob.length <= 1000`
- `0 <= prob[i] <= 1`
- `0 <= target <= prob.length`
- 如果答案与标准答案的误差在 `10^-5` 内，则被视为正确答案。

## 解题思路

这是一道经典的概率型动态规划问题。

定义状态：
- `dp[i][j]` 表示抛掷前 i 枚硬币，恰好有 j 枚正面朝上的概率

状态转移：
- 对于第 i 枚硬币，它可能正面朝上（概率 prob[i-1]），也可能反面朝上（概率 1-prob[i-1]）
- `dp[i][j] = dp[i-1][j-1] * prob[i-1] + dp[i-1][j] * (1 - prob[i-1])`
  - 第一项：前 i-1 枚有 j-1 个正面，第 i 枚是正面
  - 第二项：前 i-1 枚有 j 个正面，第 i 枚是反面

初始状态：
- `dp[0][0] = 1.0`（没有硬币时，0 个正面的概率是 1）

## Python 代码实现

### 方法一：二维 DP（推荐）

```python
from typing import List

class Solution:
    def probabilityOfHeads(self, prob: List[float], target: int) -> float:
        """
        使用二维动态规划计算概率
        
        Args:
            prob: 每枚硬币正面朝上的概率
            target: 目标正面数量
            
        Returns:
            恰好有 target 枚正面朝上的概率
        """
        n = len(prob)
        # dp[i][j] 表示前 i 枚硬币恰好有 j 个正面的概率
        dp = [[0.0] * (target + 1) for _ in range(n + 1)]
        
        # 初始状态：0 枚硬币，0 个正面，概率为 1
        dp[0][0] = 1.0
        
        # 遍历每枚硬币
        for i in range(1, n + 1):
            # j 表示正面的数量
            for j in range(target + 1):
                # 第 i 枚硬币是反面，前 i-1 枚有 j 个正面
                dp[i][j] = dp[i-1][j] * (1 - prob[i-1])
                
                # 第 i 枚硬币是正面，前 i-1 枚有 j-1 个正面
                if j > 0:
                    dp[i][j] += dp[i-1][j-1] * prob[i-1]
        
        return dp[n][target]
```

### 方法二：一维 DP 空间优化（推荐）

```python
from typing import List

class Solution:
    def probabilityOfHeads(self, prob: List[float], target: int) -> float:
        """
        使用一维数组优化空间
        """
        n = len(prob)
        # dp[j] 表示恰好有 j 个正面的概率
        dp = [0.0] * (target + 1)
        dp[0] = 1.0  # 初始状态
        
        # 遍历每枚硬币
        for i in range(n):
            # 注意：必须从后往前遍历，避免覆盖还需要使用的值
            for j in range(target, -1, -1):
                if j == 0:
                    # j = 0 时，只有一种情况：所有硬币都是反面
                    dp[j] = dp[j] * (1 - prob[i])
                else:
                    # 第 i 枚是正面 + 第 i 枚是反面
                    dp[j] = dp[j-1] * prob[i] + dp[j] * (1 - prob[i])
        
        return dp[target]
```

### 方法三：优化的一维 DP

```python
from typing import List

class Solution:
    def probabilityOfHeads(self, prob: List[float], target: int) -> float:
        """
        更清晰的一维 DP 写法
        """
        # dp[j] 表示当前恰好有 j 个正面的概率
        dp = [1.0] + [0.0] * target
        
        for p in prob:
            # 从后往前更新
            for j in range(target, -1, -1):
                # 当前状态 = (之前 j-1 个正面 * 当前正面) + (之前 j 个正面 * 当前反面)
                dp[j] = (dp[j-1] * p if j > 0 else 0) + dp[j] * (1 - p)
        
        return dp[target]
```

### 方法四：递归 + 记忆化

```python
from typing import List
from functools import lru_cache

class Solution:
    def probabilityOfHeads(self, prob: List[float], target: int) -> float:
        """
        使用递归 + 记忆化搜索
        """
        n = len(prob)
        
        @lru_cache(None)
        def dp(i: int, j: int) -> float:
            """
            返回前 i 枚硬币恰好有 j 个正面的概率
            """
            # 基础情况
            if j < 0 or j > i:
                return 0.0
            if i == 0:
                return 1.0 if j == 0 else 0.0
            
            # 递归计算
            # 第 i 枚是正面 + 第 i 枚是反面
            return (dp(i-1, j-1) * prob[i-1] + 
                    dp(i-1, j) * (1 - prob[i-1]))
        
        return dp(n, target)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n × target)，需要计算 n × target 个状态
- 空间复杂度：O(n × target)

**方法二和方法三（推荐）：**
- 时间复杂度：O(n × target)
- 空间复杂度：O(target)

**方法四：**
- 时间复杂度：O(n × target)
- 空间复杂度：O(n × target)，递归调用栈和缓存

## 关键点总结

1. 这是概率型动态规划的典型应用
2. 状态转移考虑两种情况：当前硬币是正面/反面
3. 一维 DP 优化时必须从后往前遍历
4. 注意边界条件：j = 0 和 j > i 的情况
5. 浮点数精度问题：题目允许 10^-5 的误差

## 易错点

1. 一维 DP 时从前往后遍历会导致状态被提前覆盖
2. 忘记处理 j = 0 的边界情况
3. 概率值超过 1 或小于 0（逻辑错误）
4. 状态转移方程写错：混淆正面和反面的概率
5. 初始化错误：dp[0][0] 应该是 1.0
