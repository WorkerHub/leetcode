## 题目描述

给你一个 `n x n` 的矩阵，每行和每列的元素之和应相等（"美丽矩阵"）。每次操作可以将任意一个元素加 1。

返回使矩阵变为美丽矩阵所需的最少操作次数。

**示例 1：**

```
输入：grid = [[1, 2], [3, 4]]
输出：4
解释：目标每行每列和相等，当前行和：[3, 7]，列和：[4, 6]。
```

**示例 2：**

```
输入：grid = [[1, 1], [1, 1]]
输出：0
解释：已经是美丽矩阵。
```

**提示：**
- `1 <= n <= 100`
- `1 <= grid[i][j] <= 1000`

## 解题思路

目标：所有行和与列和相等，设为 `T`。

由于只能加 1，T 必须 >= max(各行和, 各列和)。

`T = max(max_row_sum, max_col_sum)`（取当前最大行和和列和的最大值）。

操作次数 = `n * T - sum(所有元素)`（每行需要达到 T，总和需要达到 n*T）。

## Python 代码实现

### 方法一：数学计算（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]]) -> int:
        n = len(grid)
        row_sums = [sum(row) for row in grid]
        col_sums = [sum(grid[i][j] for i in range(n)) for j in range(n)]

        target = max(max(row_sums), max(col_sums))
        total = sum(sum(row) for row in grid)

        return n * target - total
```

### 方法二：逐步补足

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]]) -> int:
        n = len(grid)

        # 行和和列和
        row_sums = [sum(grid[i]) for i in range(n)]
        col_sums = [sum(grid[i][j] for i in range(n)) for j in range(n)]

        # 目标和为当前最大行/列和
        T = max(max(row_sums), max(col_sums))

        # 操作数 = 所有行补足到 T 的总量 = n*T - total
        total = sum(row_sums)
        return n * T - total
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵
- 空间复杂度：O(n)，行和列和数组

## 关键点总结

1. 只能加 1，目标和 T 必须 >= 当前所有行和与列和。
2. T = max(所有行和, 所有列和)，这是最小可行的目标。
3. 总操作数 = n*T - 当前总和（每行补足到 T，共 n 行）。

## 易错点

1. 行和与列和都要参与比较，不能只看行。
2. T 是行/列和，不是单个元素；总操作数是总和的差。
