## 题目描述

一个国家由 `n` 座城市组成，编号 `0` 到 `n-1`。给你一个整数 `n` 和一个二维数组 `paths`，其中 `paths[i]` 是第 `i` 个朋友访问城市的路径。

所有路径中，某段路径的**公共子路径**是出现在**所有朋友路径**中的子路径。

返回最长公共子路径的长度，如果不存在则返回 `0`。

**示例 1：**
```
输入：n = 5, paths = [[0,1,2,3,4],[2,3,4],[4,0,1,2,3]]
输出：2
解释：最长公共子路径为 [2,3] 或 [3,4]，长度为 2
```

**提示：**
- `1 <= n <= 10^5`
- `m == paths.length`，`2 <= m <= 10^5`
- `sum(paths[i].length) <= 10^5`
- `0 <= paths[i][j] < n`

---

## 解题思路

### 核心思想：二分长度 + 滚动哈希

**二分答案**：二分最长公共子路径的长度 `mid`

**验证**：判断是否存在长度为 `mid` 的子路径在所有路径中都出现
- 对每条路径，用**滚动哈希**计算所有长度为 `mid` 的子路径的哈希值
- 求所有路径对应哈希集合的**交集**
- 若交集非空，则存在

为降低哈希碰撞概率，使用**双哈希**（两个不同的模数和基）。

## 代码实现

### 方法一：二分 + 双滚动哈希（推荐）

```python
from typing import List

class Solution:
    def longestCommonSubpath(self, n: int, paths: List[List[int]]) -> int:
        MOD1, BASE1 = 10**9 + 7, 100003
        MOD2, BASE2 = 10**9 + 9, 200003

        def get_hashes(path: List[int], length: int):
            """计算 path 中所有长度为 length 的子路径的双哈希集合"""
            if len(path) < length:
                return set()

            h1, h2 = 0, 0
            pw1, pw2 = 1, 1  # BASE^(length-1) % MOD

            # 初始化第一个窗口
            for i in range(length):
                h1 = (h1 * BASE1 + path[i]) % MOD1
                h2 = (h2 * BASE2 + path[i]) % MOD2
                if i < length - 1:
                    pw1 = pw1 * BASE1 % MOD1
                    pw2 = pw2 * BASE2 % MOD2

            result = {(h1, h2)}
            # 滑动窗口
            for i in range(length, len(path)):
                # 移除左端，加入右端
                h1 = (h1 - path[i - length] * pw1 % MOD1 + MOD1) % MOD1
                h1 = (h1 * BASE1 + path[i]) % MOD1
                h2 = (h2 - path[i - length] * pw2 % MOD2 + MOD2) % MOD2
                h2 = (h2 * BASE2 + path[i]) % MOD2
                result.add((h1, h2))
            return result

        def can_find(length: int) -> bool:
            """判断是否存在长度为 length 的公共子路径"""
            if length == 0:
                return True
            # 以最短路径开始，求交集
            common = get_hashes(paths[0], length)
            for i in range(1, len(paths)):
                common &= get_hashes(paths[i], length)
                if not common:
                    return False
            return bool(common)

        # 二分答案：最大长度不超过最短路径的长度
        lo, hi = 0, min(len(p) for p in paths)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_find(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：后缀数组（理论更优，实现复杂）

```python
# 后缀数组方法思路说明（实现复杂，面试中较少要求）
# 1. 将所有路径用分隔符连接成一个序列
# 2. 构建后缀数组和 LCP 数组
# 3. 二分 + 滑动窗口检查是否有覆盖所有路径的公共子路径
# 此处提供简化的二分 + 哈希方法作为主要解法

class Solution:
    def longestCommonSubpath(self, n: int, paths: List[List[int]]) -> int:
        # 复用方法一的实现
        return self._solve(n, paths)

    def _solve(self, n, paths):
        MOD1, BASE1 = (1 << 61) - 1, 131
        MOD2, BASE2 = 10**9 + 7, 137

        def get_hashes(path, L):
            if len(path) < L:
                return set()
            h1 = h2 = 0
            p1 = p2 = 1
            for i in range(L):
                h1 = (h1 * BASE1 + path[i] + 1) % MOD1
                h2 = (h2 * BASE2 + path[i] + 1) % MOD2
                if i < L - 1:
                    p1 = p1 * BASE1 % MOD1
                    p2 = p2 * BASE2 % MOD2
            res = {(h1, h2)}
            for i in range(L, len(path)):
                h1 = (h1 - (path[i-L]+1) * p1 % MOD1 + MOD1) % MOD1
                h1 = (h1 * BASE1 + path[i] + 1) % MOD1
                h2 = (h2 - (path[i-L]+1) * p2 % MOD2 + MOD2) % MOD2
                h2 = (h2 * BASE2 + path[i] + 1) % MOD2
                res.add((h1, h2))
            return res

        lo, hi = 0, min(len(p) for p in paths)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            common = get_hashes(paths[0], mid)
            for path in paths[1:]:
                common &= get_hashes(path, mid)
                if not common:
                    break
            if common:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分 + 滚动哈希 | O(S log S) | O(S) |
| 后缀数组 | O(S log S) | O(S) |

其中 S = 所有路径长度之和。

---

## 关键点总结

1. 二分长度 + 哈希验证是解决此类问题的通用框架
2. 双哈希（两个不同模数）大幅降低碰撞概率
3. 滚动哈希避免重复计算每个窗口的哈希值

---

## 易错点

- 哈希碰撞：单哈希可能产生误判，建议使用双哈希
- 路径中城市编号从 0 开始，哈希时可以加 1 避免 0 对哈希的干扰
