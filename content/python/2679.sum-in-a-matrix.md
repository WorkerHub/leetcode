## 题目描述

给你一个 `m x n` 整数矩阵 `nums`。每步操作：从每行中选取最大值，删除它，然后将这一步中所有选取的最大值中的最大值加入分数。重复这一过程直到矩阵为空。

返回最终得分。

**示例 1：**
```
输入：nums = [[7,2,1],[6,4,2],[6,5,3],[3,2,1]]
输出：15
解释：每轮取每行最大值后取全局最大：
第1轮：7,6,6,3 -> 全局最大7
第2轮：2,4,5,2 -> 全局最大5
第3轮：1,2,3,1 -> 全局最大3
得分 7+5+3=15
```

**数据范围：**
- m == nums.length, n == nums[0].length
- 1 <= m, n <= 100
- 1 <= nums[i][j] <= 100

## 解题思路

贪心：对每行排序，然后对每列取最大值（即每轮）：第 `j` 列对应第 `j` 轮，取各行第 `j` 大的元素中的最大值。

等价操作：对每行排序（升序），然后按列（每列对应一轮）取各行该列的最大值加入分数。

## Python 代码实现

### 方法一：排序后按列取最大值（推荐）

```python
from typing import List

class Solution:
    def matrixSum(self, nums: List[List[int]]) -> int:
        # 对每行排序（升序），最大值在最后
        for row in nums:
            row.sort()

        ans = 0
        n = len(nums[0])
        # 按列（从最大到最小）取每列各行的最大值
        for j in range(n - 1, -1, -1):
            ans += max(nums[i][j] for i in range(len(nums)))

        return ans
```

### 方法二：逐列处理

```python
from typing import List

class Solution:
    def matrixSum(self, nums: List[List[int]]) -> int:
        for row in nums:
            row.sort(reverse=True)  # 降序：第 j 轮取 nums[i][j]

        m, n = len(nums), len(nums[0])
        return sum(max(nums[i][j] for i in range(m)) for j in range(n))
```

## 复杂度分析

- 时间复杂度：O(m * n * log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 每轮从每行取最大值，等价于取每行排序后的第 j 大元素
2. 各行排序后，第 j 轮的分数 = 所有行第 j 大元素的最大值

## 易错点

1. 每轮取各行最大值后取全局最大，而不是累加所有行最大值
2. 对行排序后按列操作
