## 题目描述

给你二叉树的根节点 `root`，请你采用前序遍历的方式，将二叉树转化为一个由括号和整数组成的字符串，返回构造出的字符串。

空节点使用一对空括号对 `"()"` 表示，转化后需要省略所有不影响字符串与原始二叉树之间的一对一映射关系的空括号对。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/05/03/cons1-tree.jpg)

```
输入：root = [1,2,3,4]
输出："1(2(4))(3)"
解释：初步转化后得到 "1(2(4)())(3())"，
但省略所有不必要的空括号对后，得到 "1(2(4))(3)"
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/05/03/cons2-tree.jpg)

```
输入：root = [1,2,3,null,4]
输出："1(2()(4))(3)"
解释：和示例 1 类似，但不能省略第一个空括号对，否则会破坏输入与输出一一映射的关系
```

**提示：**

- 树中节点数目范围是 `[1, 10^4]`
- `-1000 <= Node.val <= 1000`

## 解题思路

这道题要求将二叉树转换为字符串，核心是**前序遍历 + 括号表示法**。

**规则总结：**

1. **根节点**：直接添加值
2. **左子树**：
   - 存在：添加 `(左子树字符串)`
   - 不存在但右子树存在：添加 `()`
   - 不存在且右子树也不存在：省略
3. **右子树**：
   - 存在：添加 `(右子树字符串)`
   - 不存在：省略

**省略规则：**
- 左右子树都为空：完全省略括号
- 只有右子树为空：省略右括号
- 只有左子树为空：**不能省略**左括号，必须用 `()` 占位

**递归思路：**
```
tree2str(root):
    if root is None: return ""
    
    result = str(root.val)
    
    if 左子树 or 右子树:
        result += "(" + tree2str(左子树) + ")"
    
    if 右子树:
        result += "(" + tree2str(右子树) + ")"
    
    return result
```

## Python 代码实现

### 方法一：递归（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        """
        递归前序遍历构建字符串
        
        时间复杂度：O(n)，访问每个节点一次
        空间复杂度：O(h)，递归栈深度，h为树高
        """
        if not root:
            return ""
        
        # 根节点值
        result = str(root.val)
        
        # 处理左子树
        if root.left or root.right:
            # 左子树存在或右子树存在时，都需要添加左括号
            result += "(" + self.tree2str(root.left) + ")"
        
        # 处理右子树
        if root.right:
            result += "(" + self.tree2str(root.right) + ")"
        
        return result
```

### 方法二：递归（详细注释版）

```python
class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        """
        详细版本，清晰展示各种情况
        """
        if not root:
            return ""
        
        # 当前节点值
        result = str(root.val)
        
        # 情况1：左右子树都不存在
        if not root.left and not root.right:
            return result
        
        # 情况2：只有左子树存在
        if root.left and not root.right:
            result += "(" + self.tree2str(root.left) + ")"
            return result
        
        # 情况3：只有右子树存在
        if not root.left and root.right:
            result += "()"  # 左子树用空括号占位
            result += "(" + self.tree2str(root.right) + ")"
            return result
        
        # 情况4：左右子树都存在
        result += "(" + self.tree2str(root.left) + ")"
        result += "(" + self.tree2str(root.right) + ")"
        return result
```

### 方法三：迭代（栈模拟递归）

```python
class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        """
        使用栈实现迭代版本
        
        时间复杂度：O(n)
        空间复杂度：O(n)，栈空间
        """
        if not root:
            return ""
        
        stack = [root]
        visited = set()
        result = []
        
        while stack:
            node = stack[-1]
            
            if node in visited:
                # 节点已访问，添加右括号
                stack.pop()
                result.append(")")
            else:
                # 第一次访问节点
                visited.add(node)
                result.append("(")
                result.append(str(node.val))
                
                # 特殊处理：只有右子树时，需要为左子树添加空括号
                if not node.left and node.right:
                    result.append("()")
                
                # 先右后左（因为栈是后进先出）
                if node.right:
                    stack.append(node.right)
                if node.left:
                    stack.append(node.left)
        
        # 去掉最外层的括号
        return "".join(result)[1:-1]
```

### 方法四：简洁版（一行流）

```python
class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        """
        极简版本
        """
        if not root:
            return ""
        
        left = f"({self.tree2str(root.left)})" if (root.left or root.right) else ""
        right = f"({self.tree2str(root.right)})" if root.right else ""
        
        return f"{root.val}{left}{right}"
```

## 复杂度分析

### 递归方法
- **时间复杂度**：O(n)，n 为节点数，每个节点访问一次
- **空间复杂度**：O(h)，h 为树高，递归栈深度
  - 最坏情况（链式树）：O(n)
  - 最好情况（平衡树）：O(log n)

### 迭代方法
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈和 visited 集合

## 关键点总结

1. **前序遍历**：根 -> 左 -> 右
2. **括号规则**：
   - 左子树空但右子树非空：必须用 `()` 占位
   - 左右都空：完全省略括号
   - 右子树空：省略右括号
3. **递归边界**：空节点返回空字符串
4. **字符串拼接**：使用 f-string 或 + 运算符
5. **省略优化**：根据子树情况决定是否添加括号

## 易错点

1. **忘记左子树占位**：
   ```python
   # ❌ 错误：只有右子树时忘记为左子树添加()
   if root.left:
       result += "(" + self.tree2str(root.left) + ")"
   if root.right:
       result += "(" + self.tree2str(root.right) + ")"
   # 当左子树为空右子树非空时，无法区分结构
   ```

2. **过度省略括号**：
   ```python
   # ❌ 错误：左右都空时也添加括号
   result += "(" + self.tree2str(root.left) + ")"
   result += "(" + self.tree2str(root.right) + ")"
   # [1] 会变成 "1()()" 而非 "1"
   ```

3. **条件判断顺序**：
   ```python
   # ❌ 错误：先判断 root.left
   if root.left:
       result += "(" + self.tree2str(root.left) + ")"
   # 应该是 if root.left or root.right
   ```

4. **负数处理**：
   ```python
   # ✅ 正确：str() 会自动处理负数
   result = str(root.val)  # -1 -> "-1"
   ```

## 学习建议

**新手学习路径：**

1. **理解前序遍历**：
   - 顺序：根 -> 左 -> 右
   - 递归实现最直观
   - 本题是前序遍历的应用

2. **掌握括号规则**：
   - 画出几个示例树，手动构建字符串
   - 总结什么情况需要括号，什么情况可以省略
   - 理解为什么左子树空时需要 `()` 占位

3. **循序渐进**：
   - 第一步：不考虑省略，所有子树都加括号
   - 第二步：添加省略规则
   - 第三步：优化代码简洁性

4. **推荐方法**：
   - 初学者：方法二（详细版），逻辑清晰
   - 进阶：方法一（推荐版），简洁高效
   - 追求极致：方法四（一行流）

5. **测试用例**：
   ```python
   # 单节点
   [1] -> "1"
   
   # 只有左子树
   [1,2] -> "1(2)"
   
   # 只有右子树
   [1,null,3] -> "1()(3)"
   
   # 完整二叉树
   [1,2,3] -> "1(2)(3)"
   
   # 复杂情况
   [1,2,3,null,4] -> "1(2()(4))(3)"
   ```

**实战技巧：**
- 递归是处理树问题的首选方法
- 注意边界条件：空节点、单节点、只有一侧子树
- 字符串拼接用 f-string 更简洁：`f"{val}({left})({right})"`
- 可以先写出完整版本，再根据规则优化省略逻辑
