## 题目描述

有两个水壶，容量分别为 `x` 升和 `y` 升。水的供应是无限的。

你可以执行以下操作：
- 装满任意一个水壶
- 清空任意一个水壶
- 将水从一个水壶倒入另一个水壶，直到接水壶装满或倒水壶为空

给你两个整数 `x`、`y` 和 `target`，如果可以通过以上操作得到恰好 `target` 升的水，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：x = 3, y = 5, target = 4
输出：true
解释：
按照以下步骤操作，以 '#' 表示装满，'@' 表示清空：
1. 装满 5 升的水壶：(0, 5)
2. 把 5 升的水壶倒到 3 升的水壶：(3, 2)
3. 清空 3 升的水壶：(0, 2)
4. 把 2 升水倒到 3 升的水壶：(2, 0)
5. 装满 5 升的水壶：(2, 5)
6. 把 5 升的水壶倒到 3 升的水壶：(3, 4)
```

**示例 2：**

```
输入：x = 2, y = 6, target = 5
输出：false
```

**示例 3：**

```
输入：x = 1, y = 2, target = 3
输出：true
解释：同时装满两个水壶，总容量为 3
```

**提示：**
- `1 <= x, y, target <= 10^3`

## 解题思路

这道题有两种解法：数学方法和搜索方法。

### 方法一：数学方法（推荐）

这是一个经典的**裴蜀定理**（贝祖定理）应用题。

**裴蜀定理**：对于任意整数 a、b 和它们的最大公约数 gcd(a, b)，存在整数 m、n 使得：
```
a * m + b * n = gcd(a, b) * k
```

其中 k 是任意整数。

**应用到本题**：
- 通过倒水操作，我们能得到的水量是 `x * m + y * n` 的形式
- 因此，能得到的水量必须是 `gcd(x, y)` 的倍数
- 同时，水量不能超过 `x + y`

**结论**：
```
target 可达 ⟺ target <= x + y 且 target % gcd(x, y) == 0
```

### 方法二：BFS/DFS 搜索

将问题建模为状态搜索：
- 状态：`(a, b)` 表示两个水壶的当前水量
- 每次可以执行 6 种操作
- 使用 BFS 或 DFS 搜索是否能到达 `target`

## Python 代码实现

### 方法一：数学方法（推荐）

```python
import math

class Solution:
    def canMeasureWater(self, x: int, y: int, target: int) -> bool:
        """
        使用裴蜀定理
        时间复杂度：O(log(min(x, y)))，计算 GCD 的时间
        空间复杂度：O(1)
        """
        # target 不能超过两个水壶的总容量
        if target > x + y:
            return False
        
        # 特殊情况：target 为 0
        if target == 0:
            return True
        
        # 计算最大公约数
        g = math.gcd(x, y)
        
        # target 必须是 gcd 的倍数
        return target % g == 0
```

### 方法二：BFS 搜索

```python
from typing import Tuple
from collections import deque

class Solution:
    def canMeasureWater(self, x: int, y: int, target: int) -> bool:
        """
        BFS 状态搜索
        时间复杂度：O(x * y)，最多有 x * y 个不同状态
        空间复杂度：O(x * y)
        """
        if target > x + y:
            return False
        
        if target == 0:
            return True
        
        # BFS
        queue = deque([(0, 0)])  # (壶1的水量, 壶2的水量)
        visited = {(0, 0)}
        
        while queue:
            a, b = queue.popleft()
            
            # 检查是否达到目标
            if a == target or b == target or a + b == target:
                return True
            
            # 6 种操作
            next_states = [
                (x, b),        # 装满壶1
                (a, y),        # 装满壶2
                (0, b),        # 清空壶1
                (a, 0),        # 清空壶2
                (max(0, a - (y - b)), min(y, b + a)),  # 壶1倒到壶2
                (min(x, a + b), max(0, b - (x - a)))   # 壶2倒到壶1
            ]
            
            for state in next_states:
                if state not in visited:
                    visited.add(state)
                    queue.append(state)
        
        return False
```

### 方法三：DFS 搜索

```python
class Solution:
    def canMeasureWater(self, x: int, y: int, target: int) -> bool:
        """
        DFS 状态搜索
        """
        if target > x + y:
            return False
        
        if target == 0:
            return True
        
        visited = set()
        
        def dfs(a: int, b: int) -> bool:
            # 检查是否达到目标
            if a == target or b == target or a + b == target:
                return True
            
            # 状态已访问
            if (a, b) in visited:
                return False
            
            visited.add((a, b))
            
            # 6 种操作
            # 装满壶1
            if dfs(x, b):
                return True
            # 装满壶2
            if dfs(a, y):
                return True
            # 清空壶1
            if dfs(0, b):
                return True
            # 清空壶2
            if dfs(a, 0):
                return True
            # 壶1倒到壶2
            if dfs(max(0, a - (y - b)), min(y, b + a)):
                return True
            # 壶2倒到壶1
            if dfs(min(x, a + b), max(0, b - (x - a))):
                return True
            
            return False
        
        return dfs(0, 0)
```

## 复杂度分析

### 方法一：数学方法
- 时间复杂度：O(log(min(x, y)))，欧几里得算法计算 GCD
- 空间复杂度：O(1)

### 方法二：BFS 搜索
- 时间复杂度：O(x × y)，最多有 (x+1) × (y+1) 个状态
- 空间复杂度：O(x × y)

### 方法三：DFS 搜索
- 时间复杂度：O(x × y)
- 空间复杂度：O(x × y)

## 关键点总结

1. **裴蜀定理**：这是解决此类问题的数学基础
2. **GCD 的意义**：最大公约数决定了能达到的最小单位
3. **状态空间**：两个水壶的状态可以用二元组表示
4. **数学优化**：数学方法远优于搜索方法
5. **边界条件**：target 为 0 或超过总容量的特殊情况

## 易错点

1. **总容量限制**：忘记检查 `target <= x + y`
2. **GCD 为 0**：当 x 或 y 为 0 时，`gcd(x, y)` 的处理
3. **状态重复**：搜索方法中必须用 visited 避免重复
4. **倒水操作**：计算倒水后的状态容易出错
   - 壶1倒到壶2：`(max(0, a-(y-b)), min(y, a+b))`
5. **特殊情况**：target == 0 时返回 true
