## 题目描述

给你一个数组 `routes`，表示一系列公交线路，其中每个 `routes[i]` 表示一条公交线路，第 `i` 辆公交车将会在上面循环行驶。

例如，路线 `routes[0] = [1, 5, 7]` 表示第 `0` 辆公交车会一直按序列 `1 -> 5 -> 7 -> 1 -> 5 -> 7 -> 1 -> ...` 这样的车站路线行驶。

现在从 `source` 车站出发（初始时不在公交车上），要前往 `target` 车站。期间仅可乘坐公交车。

求出 **最少乘坐的公交车数量**。如果不可能到达终点车站，返回 `-1`。

**示例 1:**
```
输入: routes = [[1,2,7],[3,6,7]], source = 1, target = 6
输出: 2
解释: 最优策略是先乘坐第一辆公交车到达车站 7, 然后乘坐第二辆公交车到车站 6。
```

**示例 2:**
```
输入: routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]], source = 15, target = 12
输出: -1
```

**提示:**
- `1 <= routes.length <= 500`
- `1 <= routes[i].length <= 10^5`
- `routes[i]` 中的所有值 **互不相同**
- `sum(routes[i].length) <= 10^5`
- `0 <= routes[i][j] < 10^6`
- `0 <= source, target < 10^6`

## 解题思路

这是一道图的BFS问题。关键是将问题转化为**公交车之间的转换**，而不是站点之间的转换。

**核心思想：**
1. 建立站点到公交车的映射
2. BFS 搜索公交车，而不是站点
3. 每次换乘公交车，步数加 1

## Python 代码实现

### 方法一：BFS（推荐）⭐

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def numBusesToDestination(self, routes: List[List[int]], source: int, target: int) -> int:
        if source == target:
            return 0
        
        # 建立站点到公交车的映射
        stop_to_buses = defaultdict(set)
        for bus, stops in enumerate(routes):
            for stop in stops:
                stop_to_buses[stop].add(bus)
        
        # BFS：搜索公交车
        visited_buses = set()
        visited_stops = {source}
        queue = deque([(source, 0)])  # (当前站点, 乘坐公交车数)
        
        while queue:
            stop, buses_taken = queue.popleft()
            
            # 遍历当前站点的所有公交车
            for bus in stop_to_buses[stop]:
                if bus in visited_buses:
                    continue
                
                visited_buses.add(bus)
                
                # 遍历这辆公交车的所有站点
                for next_stop in routes[bus]:
                    if next_stop == target:
                        return buses_taken + 1
                    
                    if next_stop not in visited_stops:
                        visited_stops.add(next_stop)
                        queue.append((next_stop, buses_taken + 1))
        
        return -1
```

### 方法二：优化版本

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def numBusesToDestination(self, routes: List[List[int]], source: int, target: int) -> int:
        if source == target:
            return 0
        
        # 建立映射
        stop_to_buses = defaultdict(list)
        for i, route in enumerate(routes):
            for stop in route:
                stop_to_buses[stop].append(i)
        
        # BFS
        queue = deque([source])
        visited_stops = {source}
        visited_buses = set()
        steps = 0
        
        while queue:
            steps += 1
            for _ in range(len(queue)):
                stop = queue.popleft()
                
                for bus in stop_to_buses[stop]:
                    if bus in visited_buses:
                        continue
                    visited_buses.add(bus)
                    
                    for next_stop in routes[bus]:
                        if next_stop == target:
                            return steps
                        if next_stop not in visited_stops:
                            visited_stops.add(next_stop)
                            queue.append(next_stop)
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(N × S)，N 是公交车数量，S 是站点总数
- **空间复杂度**：O(N × S)

## 关键点总结

1. **问题转化**：搜索公交车而非站点
2. **双向映射**：站点到公交车的映射很关键
3. **避免重复**：同时标记访问过的站点和公交车
4. **BFS层次**：每一层代表一次换乘

## 易错点

1. **起点终点相同**：需要特判
2. **重复访问**：必须标记访问过的公交车和站点
3. **步数计算**：每换一辆公交车才加 1
