## 题目描述

二叉树中有一个**无效节点**，其右子指针指向了同一深度的另一个节点（即向右而不是向下）。给你这棵树的根节点 `root`，找到并移除这个无效节点，返回修正后的二叉树根节点。

**注意：**
- 无效节点的**右指针**指向同层的另一个节点（不是子节点）
- 无效节点之外的节点是合法的

## 解题思路

**BFS（层序遍历）方法：**
- 从左到右逐层遍历
- 用集合记录已访问的节点（同层从左到右按 BFS 顺序访问）
- 若某节点的右子节点已被访问过，则该右指针是无效的，将其置为 None

**关键：** 同层按从左到右的 BFS 顺序处理，所以被错误指向的节点会先被访问，然后当遇到指向它的无效指针时，发现它已在 visited 中。

## 代码实现

### 方法一：BFS（推荐）

```python
from collections import deque
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def correctBinaryTree(self, root: TreeNode) -> TreeNode:
        queue = deque([root])
        
        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                
                # 检查右子节点是否已被访问（说明是无效指针）
                if node.right and node.right in {n for n in queue}:
                    node.right = None
                    return root
                
                if node.right:
                    queue.append(node.right)
                if node.left:
                    queue.append(node.left)
        
        return root
```

### 方法二：DFS（后序遍历，标记已访问节点）

```python
from typing import Optional

class Solution:
    def correctBinaryTree(self, root: TreeNode) -> TreeNode:
        visited = set()
        
        def dfs(node: TreeNode, parent: TreeNode, is_left: bool) -> bool:
            if not node:
                return False
            
            if node in visited:
                # 发现环：这条边是无效的，断开父节点的指针
                if is_left:
                    parent.left = None
                else:
                    parent.right = None
                return True
            
            visited.add(node)
            
            # 先检查右子树（无效节点的右指针指向同层右边的节点）
            if dfs(node.right, node, False):
                return True
            if dfs(node.left, node, True):
                return True
            
            return False
        
        # 创建虚拟父节点
        dummy = TreeNode()
        dummy.left = root
        dfs(root, dummy, True)
        return root
```

### 方法三：BFS 正确版（使用 visited 集合）

```python
from collections import deque
from typing import Optional

class Solution:
    def correctBinaryTree(self, root: TreeNode) -> TreeNode:
        # 在 BFS 时，从右到左处理（确保无效指针的目标节点先被访问）
        queue = deque([root])
        visited = set()
        
        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                
                # 检查右子节点
                if node.right:
                    if node.right in visited:
                        node.right = None
                        continue
                    visited.add(node.right)
                    queue.append(node.right)
                
                if node.left:
                    if node.left in visited:
                        node.left = None
                        continue
                    visited.add(node.left)
                    queue.append(node.left)
            
        return root
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n) | O(n) |
| DFS | O(n) | O(h) |

## 关键点总结

1. 无效节点的右指针指向同层的一个**已经在同层右边出现过**的节点
2. BFS 按层处理，同层中被"跨层"指向的节点会先于指向它的父节点被访问
3. 发现某节点已在访问集合中，说明该指针是无效指针，将其断开

## 易错点

- BFS 中同层顺序很关键：目标节点必须先被添加到 visited
- DFS 方法需要先遍历右子树（因为无效指针在右边，且指向右边）
