## 题目描述

设计一个王位继承系统，包含如下操作：

- `ThroneInheritance(kingName)` — 初始化，国王名为 `kingName`
- `birth(parentName, childName)` — 表示 `parentName` 有个新孩子 `childName`
- `death(name)` — 标记 `name` 死亡
- `getInheritanceOrder()` — 返回当前继承顺序（**不包含**死亡的人）

继承顺序基于**前序遍历**（DFS）家族树：国王 → 长子及其后代 → 次子及其后代 → ...

**提示：**
- `1 <= kingName.length, parentName.length, childName.length, name.length <= 15`
- 所有操作最多调用 `10^5` 次

## 解题思路

### 哈希表 + DFS

用哈希表存储：
- `children[name]`：每个人的有序孩子列表（按出生顺序）
- `dead`：死亡人员集合

`getInheritanceOrder()` 对家族树做前序 DFS，跳过死亡成员（但其后代仍要遍历！）

**关键：** 死亡的人不出现在继承顺序中，但其子女仍然有效。

## 代码实现

### 方法一：哈希表 + DFS（推荐）

```python
from collections import defaultdict
from typing import List

class ThroneInheritance:

    def __init__(self, kingName: str):
        self.king = kingName
        self.children = defaultdict(list)  # 父 -> 有序子列表
        self.dead = set()                  # 死亡集合

    def birth(self, parentName: str, childName: str) -> None:
        # 将孩子添加到父亲的子列表末尾（按出生顺序）
        self.children[parentName].append(childName)

    def death(self, name: str) -> None:
        # 标记为死亡（不从树中删除）
        self.dead.add(name)

    def getInheritanceOrder(self) -> List[str]:
        order = []

        def dfs(name: str):
            # 前序遍历：当前节点（若未死亡，加入结果）
            if name not in self.dead:
                order.append(name)
            # 遍历孩子（死亡的孩子不加入结果，但其后代仍遍历）
            for child in self.children[name]:
                dfs(child)

        dfs(self.king)
        return order
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from collections import defaultdict
from typing import List

class ThroneInheritance:

    def __init__(self, kingName: str):
        self.king = kingName
        self.children = defaultdict(list)
        self.dead = set()

    def birth(self, parentName: str, childName: str) -> None:
        self.children[parentName].append(childName)

    def death(self, name: str) -> None:
        self.dead.add(name)

    def getInheritanceOrder(self) -> List[str]:
        order = []
        # 迭代前序 DFS，用栈（注意要逆序压入，保证先访问长子）
        stack = [self.king]
        while stack:
            name = stack.pop()
            if name not in self.dead:
                order.append(name)
            # 逆序压入孩子，使最先出生的孩子最先弹出
            for child in reversed(self.children[name]):
                stack.append(child)
        return order
```

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| `birth` | O(1) | O(1) |
| `death` | O(1) | O(1) |
| `getInheritanceOrder` | O(N) | O(N) |

N 为当前家族人数。

## 关键点总结

1. 用有序列表存孩子（保证出生顺序 = 继承先后）
2. 死亡集合只标记不删除节点，DFS 时跳过死者但继续遍历其后代
3. 前序 DFS 恰好给出正确的继承顺序

## 易错点

- 死亡的人的**后代仍然继承**，不能剪枝跳过死者的子树
- `getInheritanceOrder` 每次都需重新 DFS（不能缓存）
- 迭代 DFS 压栈时需逆序，保证顺序正确
