## 题目描述

设计一个管理 `n` 个座位预约情况的系统，座位编号为 `1` 到 `n`：

- `SeatManager(n)` 初始化，所有座位可用
- `reserve()` 返回最小编号的可用座位，并标记为不可用
- `unreserve(seatNumber)` 释放 `seatNumber` 号座位，标记为可用

**示例：**
```
输入：["SeatManager","reserve","reserve","unreserve","reserve","reserve","unreserve","reserve","reserve"]
     [[5],[],[],[2],[],[],[5],[],[]]
输出：[null,1,2,null,2,3,null,3,5]
```

**提示：**
- `1 <= n <= 10^5`
- `reserve` 和 `unreserve` 调用次数之和不超过 `10^5`

## 解题思路

用**最小堆**维护所有可用座位：
- 初始化时将 1 到 n 全部加入堆
- `reserve()`：弹出堆顶（最小可用座位）
- `unreserve(seatNumber)`：将座位编号重新加入堆

## 代码实现

### 方法一：最小堆（推荐）

```python
import heapq

class SeatManager:
    def __init__(self, n: int):
        # 初始化，将 1 到 n 全部加入最小堆
        self.available = list(range(1, n + 1))
        heapq.heapify(self.available)

    def reserve(self) -> int:
        # 弹出最小编号的可用座位
        return heapq.heappop(self.available)

    def unreserve(self, seatNumber: int) -> None:
        # 将座位归还，加入堆
        heapq.heappush(self.available, seatNumber)
```

### 方法二：延迟初始化（节省内存）

```python
import heapq

class SeatManager:
    def __init__(self, n: int):
        self.n = n
        self.next_seat = 1      # 下一个待分配的座位（从未释放过的）
        self.returned = []      # 归还的座位（最小堆）

    def reserve(self) -> int:
        if self.returned and self.returned[0] < self.next_seat:
            # 优先从归还的座位中取最小的
            return heapq.heappop(self.returned)
        else:
            # 从未分配的座位中取
            seat = self.next_seat
            self.next_seat += 1
            return seat

    def unreserve(self, seatNumber: int) -> None:
        heapq.heappush(self.returned, seatNumber)
```

## 复杂度分析

- **方法一**：
  - 初始化：O(n)（heapify）
  - reserve/unreserve：O(log n)
- **方法二**：
  - 初始化：O(1)
  - reserve/unreserve：O(log n)

## 关键点总结

1. 最小堆天然支持 O(log n) 的最小元素提取和插入
2. 延迟初始化避免了 O(n) 的初始化开销，适合 n 很大但操作数少的情况
3. `heapq.heapify` 比逐一插入更高效，O(n) vs O(n log n)

## 易错点

- 方法一初始化时用 heapify，不要用循环 heappush
- 方法二中 reserve 需要比较归还堆的堆顶与 next_seat 的大小
