## 题目描述

给定一棵 `n` 个节点的无向树，边用 `edges` 表示。树的"直径"是最长路径的边数。

返回树中节点数最少的子树，使得该子树的直径等于整棵树的直径。（子树是连通的节点子集）

**示例 1：**
```
输入：n = 5, edges = [[0,1],[0,2],[1,3],[1,4]]
输出：3
解释：树的直径为 2（如 3-1-0-2 = 3 条边）。最小直径子树包含节点 {3,1,2} 或 {4,1,2} 或 {3,1,4}，共 3 个节点。
```

**提示：**
- `2 <= n <= 1000`
- `edges.length == n-1`

## 解题思路

先找树的直径（最长路径），然后找包含直径路径的最小子树。

包含直径路径的最小子树就是直径路径本身（直径两端点之间的路径），节点数 = 直径长度 + 1。

步骤：
1. BFS/DFS 找直径端点 `u`（从任意节点出发，最远的节点）
2. 再从 `u` 出发，找最远节点 `v`，路径 `u->v` 即为直径
3. 返回 `diameter + 1`（路径上的节点数）

## Python 代码实现

### 方法一：两次 BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minimumSubtreeDiameter(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def bfs(start: int):
            dist = [-1] * n
            dist[start] = 0
            queue = deque([start])
            farthest = start
            while queue:
                node = queue.popleft()
                for nb in graph[node]:
                    if dist[nb] == -1:
                        dist[nb] = dist[node] + 1
                        if dist[nb] > dist[farthest]:
                            farthest = nb
                        queue.append(nb)
            return farthest, dist[farthest]

        # 第一次 BFS：找直径端点 u
        u, _ = bfs(0)
        # 第二次 BFS：找直径长度
        v, diameter = bfs(u)

        # 最小直径子树 = 直径路径上的节点数 = diameter + 1
        return diameter + 1
```

### 方法二：DFS 求直径

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumSubtreeDiameter(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        diameter = [0]

        def dfs(node: int, parent: int) -> int:
            """返回从 node 出发的最长路径长度"""
            depths = [0]
            for nb in graph[node]:
                if nb != parent:
                    d = dfs(nb, node) + 1
                    depths.append(d)
            depths.sort(reverse=True)
            # 取最长的两条路径更新直径
            if len(depths) >= 2:
                diameter[0] = max(diameter[0], depths[0] + depths[1])
            else:
                diameter[0] = max(diameter[0], depths[0])
            return depths[0]

        dfs(0, -1)
        return diameter[0] + 1
```

## 复杂度分析

- 时间复杂度：O(n)，两次 BFS 或一次 DFS
- 空间复杂度：O(n)

## 关键点总结

1. 树的直径：从任意节点 BFS 到最远节点 u，再从 u BFS 到最远节点 v，`u-v` 的距离即为直径
2. 最小子树 = 直径路径本身，节点数 = 直径 + 1
3. DFS 方法通过比较路径两端的最长延伸来更新直径

## 易错点

1. 直径是边数（不是节点数），最终返回 `diameter + 1`（节点数）
2. DFS 中需要取当前节点的最长两个子路径之和
