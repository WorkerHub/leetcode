## 题目描述

我们有一些二维坐标，如 `"(1, 3)"` 或 `"(2, 0.5)"`，然后我们移除所有逗号，小数点和空格，得到一个字符串 `s`。

例如，`"(1, 3)"` 变成 `s = "(13)"` ，`"(2, 0.5)"` 变成 `s = "(205)"` 。

返回所有可能的原始坐标字符串的列表。

我们的答案可以按 **任意顺序** 返回。

**示例 1:**
```
输入: s = "(123)"
输出: ["(1, 2.3)","(1, 23)","(1.2, 3)","(12, 3)"]
```

**示例 2:**
```
输入: s = "(0123)"
输出: ["(0, 1.23)","(0, 12.3)","(0, 123)","(0.1, 2.3)","(0.1, 23)","(0.12, 3)"]
解释: 0.0, 00, 0001 或 00.01 是不被允许的。
```

**示例 3:**
```
输入: s = "(00011)"
输出: ["(0, 0.011)","(0.001, 1)"]
```

**提示:**
- `4 <= s.length <= 12`
- `s[0]` == `"("` 且 `s[s.length - 1]` == `")"`
- `s` 的其他字符都是数字

## 解题思路

1. 去掉括号，分割成两部分
2. 对每部分枚举所有合法的小数表示
3. 组合所有可能的坐标

## Python 代码实现

```python
from typing import List

class Solution:
    def ambiguousCoordinates(self, s: str) -> List[str]:
        def make_numbers(s):
            """生成字符串 s 的所有合法数字表示"""
            n = len(s)
            if n == 0 or (n > 1 and s[0] == '0' and s[-1] == '0'):
                return []
            
            result = []
            
            # 整数（无小数点）
            if n == 1 or s[0] != '0':
                result.append(s)
            
            # 带小数点
            for i in range(1, n):
                integer_part = s[:i]
                decimal_part = s[i:]
                
                # 整数部分不能有前导0（除非是 "0"）
                # 小数部分不能有后导0
                if (integer_part == '0' or integer_part[0] != '0') and decimal_part[-1] != '0':
                    result.append(f"{integer_part}.{decimal_part}")
            
            return result
        
        # 去掉括号
        s = s[1:-1]
        n = len(s)
        result = []
        
        # 分割成两部分
        for i in range(1, n):
            left = s[:i]
            right = s[i:]
            
            left_nums = make_numbers(left)
            right_nums = make_numbers(right)
            
            for l in left_nums:
                for r in right_nums:
                    result.append(f"({l}, {r})")
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n³)

## 关键点总结

1. **前导零**：整数部分只有 "0" 可以有前导零
2. **后导零**：小数部分不能有后导零
3. **枚举分割点**：尝试所有可能的分割位置

## 易错点

1. **特殊情况**："00" 不合法
2. **小数点位置**：不能在开头或结尾
3. **单独的0**："0" 是合法的
