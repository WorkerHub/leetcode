## 题目描述

给你一个字符串数组 `words`，找到 `words` 中最长的单词，使得该单词的**所有前缀**也都是 `words` 中的单词。

若有多个满足条件的单词，返回字典序最小的那个；若没有，返回空字符串 `""`。

**示例 1：**
```
输入：words = ["k","ki","kip","kipi","kipik"]
输出："kipik"
```

**示例 2：**
```
输入：words = ["a","banana","app","appl","ap","apply","apple"]
输出："apple"
```

## 解题思路

**字典树**：将所有单词插入字典树，在字典树节点上标记哪些节点是单词的结尾。

然后 DFS 遍历字典树，只沿着标记为单词结尾的节点前进，找到最长（字典序最小）的路径。

**等价方法**：将 words 放入集合，排序后逐一检查每个单词的所有前缀是否都在集合中。

## 代码实现

### 方法一：字典树 + DFS（推荐）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def longestWord(self, words: List[str]) -> str:
        root = TrieNode()

        # 将所有单词插入字典树
        for word in words:
            node = root
            for ch in word:
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]
            node.is_end = True

        # DFS 遍历字典树，只沿着单词结尾节点前进
        result = ""
        def dfs(node: TrieNode, path: str) -> None:
            nonlocal result
            if len(path) > len(result) or (len(path) == len(result) and path < result):
                result = path
            for ch in sorted(node.children.keys()):  # 按字母序遍历
                child = node.children[ch]
                if child.is_end:
                    dfs(child, path + ch)

        dfs(root, "")
        return result
```

### 方法二：集合 + 排序验证

```python
from typing import List

class Solution:
    def longestWord(self, words: List[str]) -> str:
        word_set = set(words)
        words.sort(key=lambda x: (-len(x), x))  # 按长度降序，长度相同则字典序升序

        for word in words:
            # 检查所有前缀是否在集合中
            if all(word[:i] in word_set for i in range(1, len(word))):
                return word
        return ""
```

## 复杂度分析

- **方法一（字典树）**：O(n * L) 时间和空间，L 为平均单词长度
- **方法二（集合）**：O(n * L^2) 时间（每个单词检查 L 个前缀，每次查找 O(L)）

## 关键点总结

1. 字典树方法：DFS 只沿标记为单词结尾的节点深入，保证所有前缀都是单词
2. 集合方法：先排序再验证，遇到第一个满足条件的直接返回
3. 排序策略：长度降序 + 字典序升序，第一个满足条件的就是答案

## 易错点

- 检查前缀时是 `range(1, len(word))`，不包含空字符串和单词本身（空字符串不在集合中，但空前缀是平凡满足的）
- 实际上 `range(1, len(word))` 对应前缀 `word[:1]` 到 `word[:len(word)-1]`
