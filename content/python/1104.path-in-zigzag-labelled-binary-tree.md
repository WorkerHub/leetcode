## 题目描述

在一棵无限的二叉树上,每个节点都有两个子节点,树中的节点按行从左到右进行编号。

在奇数行(即第一行、第三行、第五行...),编号从左到右进行。

在偶数行(即第二行、第四行、第六行...),编号从右到左进行。

给定树中一个节点的标号 `label`,请你返回从根节点到该节点的路径(该路径是很多节点标号的集合)。

**示例 1:**
```
输入: label = 14
输出: [1,3,4,14]
解释:
        1
      /   \
     3     2
   /  \   /  \
  4    5 6    7
 / \  / \
15 14 13 12 11 10 9  8
路径为: 1 -> 3 -> 4 -> 14
```

**示例 2:**
```
输入: label = 26
输出: [1,2,6,10,26]
```

**提示:**
- `1 <= label <= 10^6`

## 解题思路

这道题的关键在于理解 zigzag 标记方式下节点之间的父子关系。

**核心观察:**
1. 如果是普通的完全二叉树,节点 `x` 的父节点是 `x // 2`
2. 由于偶数行是反向编号,需要将反向的标号映射回正常位置
3. 对于第 `level` 层的节点 `label`:
   - 该层节点范围: `[2^(level-1), 2^level - 1]`
   - 如果是偶数层(反向),需要镜像映射

**算法流程:**
1. 找到 `label` 所在的层数
2. 从 `label` 开始,逐层向上找父节点
3. 如果当前层是反向的,先将 `label` 映射到正常位置
4. 计算父节点后,如果父节点所在层是反向的,再映射回反向位置
5. 重复直到根节点

**层数计算公式:**
- 第 `level` 层的节点范围: `[2^(level-1), 2^level - 1]`
- 给定 `label`,其层数为 `floor(log2(label)) + 1`

**镜像映射公式:**
- 第 `level` 层,正常位置 `pos` 的镜像位置: `2^(level-1) + 2^level - 1 - pos`

## Python 代码实现

### 方法一: 逐层向上查找(推荐) ⭐

```python
from typing import List

class Solution:
    def pathInZigZagTree(self, label: int) -> List[int]:
        # 计算label所在的层数(从1开始)
        level = 1
        while 2 ** level <= label:
            level += 1
        
        # 结果路径,从根到label
        path = []
        
        # 从label向上追溯到根节点
        while label >= 1:
            path.append(label)
            
            # 计算当前层的范围
            level_min = 2 ** (level - 1)
            level_max = 2 ** level - 1
            
            # 如果当前层是偶数层(zigzag反向),将label映射到正常位置
            if level % 2 == 0:
                # 镜像映射: 反向位置 -> 正向位置
                label = level_min + level_max - label
            
            # 计算父节点(在正常二叉树中)
            label = label // 2
            level -= 1
            
            # 如果父节点所在层是偶数层,需要再次镜像
            if level > 0:
                level_min = 2 ** (level - 1)
                level_max = 2 ** level - 1
                if level % 2 == 0:
                    # 正向位置 -> 反向位置
                    label = level_min + level_max - label
        
        # 反转路径(因为我们是从下往上追溯的)
        return path[::-1]
```

### 方法二: 简化版本

```python
from typing import List
import math

class Solution:
    def pathInZigZagTree(self, label: int) -> List[int]:
        # 计算层数
        level = int(math.log2(label)) + 1
        
        path = []
        
        while label > 0:
            path.append(label)
            
            # 当前层的范围
            level_start = 2 ** (level - 1)
            level_end = 2 ** level - 1
            
            # 计算父节点
            # 如果当前层是反向的,先映射到正向
            if level % 2 == 0:
                # 反向映射
                label = level_start + level_end - label
            
            # 找到父节点(正常位置)
            parent = label // 2
            
            # 如果父节点层是反向的,映射回反向
            level -= 1
            if level > 0 and level % 2 == 0:
                parent_start = 2 ** (level - 1)
                parent_end = 2 ** level - 1
                parent = parent_start + parent_end - parent
            
            label = parent
        
        return path[::-1]
```

### 方法三: 位运算优化

```python
from typing import List

class Solution:
    def pathInZigZagTree(self, label: int) -> List[int]:
        # 计算层数
        level = label.bit_length()
        
        path = []
        
        while label:
            path.append(label)
            
            # 当前层的最小和最大值
            level_min = 1 << (level - 1)  # 2^(level-1)
            level_max = (1 << level) - 1  # 2^level - 1
            
            # 偶数层需要镜像
            if level & 1 == 0:  # 偶数层
                label = level_min + level_max - label
            
            # 父节点
            label >>= 1  # label // 2
            level -= 1
            
            # 父节点层如果是偶数,再次镜像
            if label and level & 1 == 0:
                parent_min = 1 << (level - 1)
                parent_max = (1 << level) - 1
                label = parent_min + parent_max - label
        
        return path[::-1]
```

## 复杂度分析

### 所有方法:
- **时间复杂度**: O(log label),需要向上遍历 log(label) 层
- **空间复杂度**: O(log label),存储路径需要 O(log label) 空间

## 图解示例

以 `label = 14` 为例:

```
层1(奇):       1
层2(偶):     3   2
层3(奇):   4 5 6 7
层4(偶): 15 14 13 12 11 10 9 8
```

追溯过程:
1. `14` 在第4层(偶数层),映射到正常位置: `8 + 15 - 14 = 9`
2. `9` 的父节点: `9 // 2 = 4`
3. `4` 在第3层(奇数层),不需要映射,父节点: `4 // 2 = 2`
4. `2` 在第2层(偶数层),映射到正常位置: `2 + 3 - 2 = 3`,父节点: `3 // 2 = 1`
5. 实际路径应该是: `1 -> 3 -> 4 -> 14`

**注意**: 上述追溯中的映射逻辑需要根据具体实现调整。

## 关键点总结

1. **层数计算**: 使用 `log2(label)` 或 `bit_length()` 快速计算层数
2. **镜像映射**: 偶数层的反向编号需要映射到正常位置才能计算父节点
3. **映射公式**: `mirror = level_min + level_max - original`
4. **双向映射**: 当前节点映射 → 找父节点 → 父节点反映射
5. **位运算优化**: 使用位运算代替乘除法,提高效率

## 易错点

1. **层数判断**: 层数从1开始,注意奇偶层的判断
2. **映射时机**: 需要在计算父节点前后都考虑是否需要映射
3. **路径顺序**: 从下往上追溯,最后需要反转结果
4. **边界条件**: label = 1 时直接返回 [1]
