## 题目描述

给你两个非负整数数组 `rowSum` 和 `colSum`，其中 `rowSum[i]` 是二维矩阵第 `i` 行元素之和，`colSum[j]` 是第 `j` 列元素之和。换言之，你需要找一个非负整数矩阵，使得矩阵中每一行和每一列之和分别等于 `rowSum[i]` 和 `colSum[j]`。

请你返回任意一个满足条件的矩阵。

**示例 1：**
```
输入：rowSum = [3,8], colSum = [4,7]
输出：[[3,0],[1,7]]
```

**示例 2：**
```
输入：rowSum = [5,7,10], colSum = [8,6,8]
输出：[[0,5,0],[6,1,0],[2,0,8]]
```

**提示：**
- `1 <= rowSum.length, colSum.length <= 500`
- `0 <= rowSum[i], colSum[j] <= 10^8`
- `sum(rowSum) == sum(colSum)`

## 解题思路

**贪心策略：** 对于每个位置 `(i, j)`，尽可能填入大的值。

具体来说：
- `matrix[i][j] = min(rowSum[i], colSum[j])`
- 然后更新 `rowSum[i] -= matrix[i][j]`，`colSum[j] -= matrix[i][j]`
- 按行列顺序处理即可

**证明合法性：** 由于总和相等，每次用掉尽可能多的值，最终所有行列和都能恰好满足。

## 代码实现

### 方法一：贪心逐位填充（推荐）

```python
from typing import List

class Solution:
    def restoreMatrix(self, rowSum: List[int], colSum: List[int]) -> List[List[int]]:
        m, n = len(rowSum), len(colSum)
        matrix = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                # 当前位置尽量填大值
                val = min(rowSum[i], colSum[j])
                matrix[i][j] = val
                rowSum[i] -= val  # 更新剩余行和
                colSum[j] -= val  # 更新剩余列和
        
        return matrix
```

### 方法二：双指针贪心

```python
from typing import List

class Solution:
    def restoreMatrix(self, rowSum: List[int], colSum: List[int]) -> List[List[int]]:
        m, n = len(rowSum), len(colSum)
        matrix = [[0] * n for _ in range(m)]
        
        # 复制避免修改原数组
        row = rowSum[:]
        col = colSum[:]
        
        i, j = 0, 0
        while i < m and j < n:
            # 当前能填的最大值
            val = min(row[i], col[j])
            matrix[i][j] = val
            row[i] -= val
            col[j] -= val
            
            # 某行或某列满足后移动指针
            if row[i] == 0:
                i += 1
            if col[j] == 0:
                j += 1
        
        return matrix
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心逐位 | O(m * n) | O(m * n)（结果矩阵） |
| 双指针贪心 | O(m + n) | O(m * n)（结果矩阵） |

双指针贪心的时间复杂度更优，因为每步至少消除一行或一列。

## 关键点总结

1. 贪心策略：每个位置填入 `min(rowSum[i], colSum[j])`
2. 题目保证 `sum(rowSum) == sum(colSum)`，所以贪心一定能找到合法解
3. 双指针方法更高效，时间复杂度从 O(m*n) 降至 O(m+n)
4. 不需要回溯，贪心是最优的

## 易错点

- 修改 `rowSum` 和 `colSum` 时注意是否需要保留原数组
- 双指针方法中，只有当行/列和降为 0 时才移动对应指针
- 贪心填充后一定要更新剩余行/列和
