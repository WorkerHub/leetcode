## 题目描述

你有一个电影租赁公司，由 `n` 个商店组成，商店编号 `0` 到 `n-1`。每个商店有一份电影列表。

初始化时给你一个二维整数数组 `entries`，`entries[i] = [shop_i, movie_i, price_i]`，表示商店 `shop_i` 有电影 `movie_i`，租金为 `price_i`。

实现 `MovieRentingSystem` 类：
- `MovieRentingSystem(int n, int[][] entries)` 初始化系统
- `List<Integer> search(int movie)` 返回**未被租借**的该电影**租金最低**的 5 个商店编号，按租金升序，租金相同按商店编号升序
- `void rent(int shop, int movie)` 租借指定商店的指定电影
- `void drop(int shop, int movie)` 归还指定电影
- `List<Integer> report()` 返回**已被租借**的电影中**租金最低**的 5 个，以 `[shop, movie]` 格式返回，按租金升序，相同按 shop 升序，再按 movie 升序

**提示：**
- `1 <= n <= 3 * 10^5`
- `1 <= entries.length <= 10^5`
- 操作次数 `<= 10^5`

---

## 解题思路

### 核心思想：有序集合（SortedList）维护多个视图

需要维护三种有序集合：
1. `unrented[movie]`：每部电影未租借的商店，按 `(price, shop)` 排序
2. `rented`：所有已租借记录，按 `(price, shop, movie)` 排序
3. `price[shop][movie]`：记录每个商店每部电影的价格

使用 Python 的 `sortedcontainers.SortedList` 支持 O(log n) 的插入、删除和查找。

## 代码实现

### 方法一：SortedList（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class MovieRentingSystem:

    def __init__(self, n: int, entries: List[List[int]]):
        # 记录 (shop, movie) 对应的价格
        self.price = {}
        # 每部电影的未租借集合，元素为 (price, shop)
        self.unrented = {}
        # 已租借集合，元素为 (price, shop, movie)
        self.rented = SortedList()

        for shop, movie, p in entries:
            self.price[(shop, movie)] = p
            if movie not in self.unrented:
                self.unrented[movie] = SortedList()
            self.unrented[movie].add((p, shop))

    def search(self, movie: int) -> List[int]:
        # 返回 movie 未租借商店中租金最低的 5 个，返回商店编号
        if movie not in self.unrented:
            return []
        sl = self.unrented[movie]
        # 取前 5 个，返回商店编号
        return [shop for _, shop in sl[:5]]

    def rent(self, shop: int, movie: int) -> None:
        p = self.price[(shop, movie)]
        # 从未租借集合移除
        self.unrented[movie].remove((p, shop))
        # 加入已租借集合
        self.rented.add((p, shop, movie))

    def drop(self, shop: int, movie: int) -> None:
        p = self.price[(shop, movie)]
        # 从已租借集合移除
        self.rented.remove((p, shop, movie))
        # 加回未租借集合
        self.unrented[movie].add((p, shop))

    def report(self) -> List[List[int]]:
        # 返回已租借中租金最低的 5 个 [shop, movie]
        return [[shop, movie] for _, shop, movie in self.rented[:5]]
```

### 方法二：使用 heapq（备选，适合不能用 SortedList 时）

```python
from typing import List
import heapq

class MovieRentingSystem:
    """使用堆 + 延迟删除的方法（适合面试手写）"""

    def __init__(self, n: int, entries: List[List[int]]):
        self.price = {}
        # unrented_heap[movie] = 最小堆 [(price, shop), ...]
        self.unrented_heap = {}
        # rented_heap = 最小堆 [(price, shop, movie), ...]
        self.rented_heap = []
        # 延迟删除集合
        self.rented_set = set()
        self.unrented_removed = {}  # movie -> set of removed (price, shop)

        for shop, movie, p in entries:
            self.price[(shop, movie)] = p
            if movie not in self.unrented_heap:
                self.unrented_heap[movie] = []
                self.unrented_removed[movie] = set()
            heapq.heappush(self.unrented_heap[movie], (p, shop))

    def search(self, movie: int) -> List[int]:
        result = []
        if movie not in self.unrented_heap:
            return result
        heap = self.unrented_heap[movie]
        removed = self.unrented_removed[movie]
        # 延迟清理已租借的条目
        temp = []
        while heap and len(result) < 5:
            p, shop = heap[0]
            if (p, shop) in removed:
                heapq.heappop(heap)
                removed.discard((p, shop))
            else:
                result.append(shop)
                temp.append(heapq.heappop(heap))
        for item in temp:
            heapq.heappush(heap, item)
        return result

    def rent(self, shop: int, movie: int) -> None:
        p = self.price[(shop, movie)]
        self.unrented_removed[movie].add((p, shop))
        self.rented_set.add((p, shop, movie))
        heapq.heappush(self.rented_heap, (p, shop, movie))

    def drop(self, shop: int, movie: int) -> None:
        p = self.price[(shop, movie)]
        self.rented_set.discard((p, shop, movie))
        heapq.heappush(self.unrented_heap[movie], (p, shop))
        self.unrented_removed[movie].discard((p, shop))

    def report(self) -> List[List[int]]:
        result = []
        temp = []
        while self.rented_heap and len(result) < 5:
            item = self.rented_heap[0]
            if item not in self.rented_set:
                heapq.heappop(self.rented_heap)
            else:
                result.append([item[1], item[2]])
                temp.append(heapq.heappop(self.rented_heap))
        for item in temp:
            heapq.heappush(self.rented_heap, item)
        return result
```

## 复杂度分析

| 操作 | SortedList 方法 | 堆方法 |
|------|----------------|--------|
| search | O(log n) | O(k log n) |
| rent | O(log n) | O(log n) |
| drop | O(log n) | O(log n) |
| report | O(1) | O(k log n) |

---

## 关键点总结

1. 三种视图：每部电影的未租状态、全局已租状态、价格映射
2. 需要支持高效的插入、删除和有序查询，SortedList 最合适
3. 排序键为 `(price, shop)` 或 `(price, shop, movie)`，自然满足多条件排序

---

## 易错点

- search 和 report 只返回最多 5 个，不是强制 5 个（不足 5 则返回全部）
- 租借状态转换时必须同时更新 unrented 和 rented 两个集合
