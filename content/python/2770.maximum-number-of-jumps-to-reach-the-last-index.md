## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `target`。

从下标 0 出发，可以从 `i` 跳到任意 `j`（`i < j`），前提是 `|nums[i] - nums[j]| <= target`。

返回到达下标 `n-1` 的 **最大跳跃次数**，如果不可达则返回 -1。

**示例 1：**
```
输入：nums = [1,3,6,4,1,2], target = 2
输出：3
解释：0->1->3->5，跳跃 3 次
```

**示例 2：**
```
输入：nums = [1,3,6,4,1,2], target = 3
输出：5
```

**提示：**
- `2 <= nums.length <= 1000`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= target <= 2 * 10^9`

## 解题思路

**DP**：`dp[i]` = 从 0 到 i 的最大跳跃次数。

`dp[0] = 0`，对每个 `j`，若存在 `i < j` 且 `dp[i] >= 0` 且 `|nums[i] - nums[j]| <= target`，则 `dp[j] = max(dp[j], dp[i] + 1)`。

最终返回 `dp[n-1]`（若为 -1 则不可达）。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maximumJumps(self, nums: List[int], target: int) -> int:
        n = len(nums)
        dp = [-1] * n
        dp[0] = 0

        for j in range(1, n):
            for i in range(j):
                if dp[i] >= 0 and abs(nums[i] - nums[j]) <= target:
                    dp[j] = max(dp[j], dp[i] + 1)

        return dp[n - 1]
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. dp[i] = -1 表示不可达
2. 最大跳跃次数，所以取 max 而非 min
3. 转移条件：差值 <= target

## 易错点

1. 检查 dp[i] >= 0（可达）才能转移
2. 最终返回 dp[n-1]，可能为 -1
