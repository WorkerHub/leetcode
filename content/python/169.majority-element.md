## 题目描述

给定一个大小为 `n` 的数组 `nums`，返回其中的多数元素。多数元素是指在数组中出现次数**大于** `⌊n/2⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**
```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**
```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**
- n == nums.length
- 1 <= n <= 5 * 10^4
- -10^9 <= nums[i] <= 10^9

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 解题思路

这道题有多种解法，从简单到高效：

### 思路一：哈希表计数（直观）
统计每个元素出现的次数，返回次数大于 `n/2` 的元素。

### 思路二：排序（巧妙）
排序后，下标为 `n/2` 的元素一定是多数元素。
- 因为多数元素数量 > n/2，排序后必然占据中间位置

### 思路三：摩尔投票算法（最优）
**核心思想：** 不同元素互相抵消，最后剩下的一定是多数元素。

**算法流程：**
1. 维护一个候选元素和计数器
2. 遍历数组：
   - 计数为 0 时，更换候选元素
   - 遇到相同元素，计数 +1
   - 遇到不同元素，计数 -1
3. 最后的候选元素就是答案

**为什么可行？**
- 多数元素数量 > n/2，即使与所有其他元素抵消，也会剩余
- 抵消过程不会影响多数元素的"多数"属性

## Python 代码实现

### 方法一：摩尔投票算法（推荐，O(n) 时间，O(1) 空间）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        # 候选元素和计数器
        candidate = None
        count = 0
        
        for num in nums:
            if count == 0:
                # 计数为 0，更换候选元素
                candidate = num
            
            # 相同元素 +1，不同元素 -1
            count += 1 if num == candidate else -1
        
        return candidate
```

### 方法二：排序法（简洁，O(n log n) 时间）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        # 排序后中间元素一定是多数元素
        nums.sort()
        return nums[len(nums) // 2]
```

### 方法三：哈希表计数（直观，O(n) 空间）

```python
from typing import List
from collections import Counter

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        # 统计每个元素出现次数
        counts = Counter(nums)
        # 返回出现次数最多的元素
        return counts.most_common(1)[0][0]
```

### 方法四：哈希表优化版（提前返回）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        counts = {}
        threshold = len(nums) // 2
        
        for num in nums:
            counts[num] = counts.get(num, 0) + 1
            # 一旦超过半数，立即返回
            if counts[num] > threshold:
                return num
```

### 方法五：分治法（递归，O(n log n) 时间）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        def majority_element_rec(lo: int, hi: int) -> int:
            # 基本情况：只有一个元素
            if lo == hi:
                return nums[lo]
            
            # 分治
            mid = (lo + hi) // 2
            left_majority = majority_element_rec(lo, mid)
            right_majority = majority_element_rec(mid + 1, hi)
            
            # 如果左右多数元素相同，直接返回
            if left_majority == right_majority:
                return left_majority
            
            # 否则，统计两个候选元素在当前区间的出现次数
            left_count = sum(1 for i in range(lo, hi + 1) if nums[i] == left_majority)
            right_count = sum(1 for i in range(lo, hi + 1) if nums[i] == right_majority)
            
            return left_majority if left_count > right_count else right_majority
        
        return majority_element_rec(0, len(nums) - 1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 摩尔投票 | O(n) | O(1) |
| 排序 | O(n log n) | O(1) 或 O(n) |
| 哈希表 | O(n) | O(n) |
| 分治 | O(n log n) | O(log n) |

**最优解：** 摩尔投票算法

## 图解示例

以 `nums = [2,2,1,1,1,2,2]` 为例（摩尔投票）：

```
初始：candidate = None, count = 0

遍历过程：
num=2: count=0, candidate=2, count=1
num=2: count=2
num=1: count=1 (抵消)
num=1: count=0
num=1: count=0, candidate=1, count=1
num=2: count=0 (抵消)
num=2: count=0, candidate=2, count=1

最终：candidate = 2
```

```

排序后：[1,1,1,2,2,2,2]
中位数：       ↑ (index=3)
结果：2
```

## 关键点总结

1. **摩尔投票核心**：配对抵消，多数元素最后剩余
2. **排序法巧思**：多数元素必占据中间位置
3. **哈希表直观**：统计频次，但空间复杂度高
4. **提前返回优化**：超过半数即可返回
5. **题目保证**：一定存在多数元素（无需验证）

## 易错点

1. **摩尔投票边界**
   - 初始化：`count = 0` 而非 `count = 1`
   - 更新候选：`if count == 0` 而非 `if count < 0`

2. **排序法索引**
   - 中位数索引：`len(nums) // 2` 而非 `len(nums) / 2`

3. **哈希表阈值**
   - 条件：`> len(nums) // 2` 而非 `>= len(nums) // 2`
   - 示例：[1,1] 中 1 出现 2 次，2//2=1，需要 >1 才成立（但本题保证存在）

4. **忘记题目保证**
   - 本题保证一定有多数元素，无需验证候选元素
   - 如果不保证，需要第二次遍历验证

5. **空间复杂度要求**
   - 进阶要求 O(1) 空间，排除哈希表和分治
