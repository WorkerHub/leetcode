## 题目描述

给你一个字符串 `s`，请你判断它是否有效。

字符串 `s` 有效需要满足：假设开始有一个空字符串 `t = ""`，你可以执行任意次下述操作将 `t` 转换为 `s`：
- 将字符串 `"abc"` 插入到 `t` 中的任意位置。形式上，`t` 变为 `tleft + "abc" + tright`，其中 `t == tleft + tright`。注意，`tleft` 和 `tright` 可能为空。

如果字符串 `s` 有效，则返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。
```

**示例 2：**
```
输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。
```

**示例 3：**
```
输入：s = "abccba"
输出：false
```

**提示：**
- `1 <= s.length <= 2 * 10^4`
- `s` 由字母 `'a'`、`'b'` 和 `'c'` 组成

## 解题思路

这道题的本质是**括号匹配**的变形，只不过这里匹配的是 `"abc"` 这个序列。

**核心思想：**
1. 如果字符串有效，我们可以反向操作：不断删除 `"abc"` 子串
2. 如果最终字符串变为空，说明原字符串有效
3. 这个过程可以用**栈**来高效实现

**算法流程：**
1. 遍历字符串的每个字符
2. 将字符压入栈
3. 每次压栈后，检查栈顶是否形成 `"abc"` 序列
4. 如果形成 `"abc"`，则弹出这三个字符（相当于删除）
5. 最后检查栈是否为空

**为什么用栈？**
- 栈可以方便地检查最近添加的字符
- 栈可以高效地删除匹配的序列
- 时间复杂度 O(n)，空间复杂度 O(n)

## Python 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        
        for char in s:
            # 将字符压入栈
            stack.append(char)
            
            # 检查栈顶是否形成 "abc"
            # 需要至少有 3 个元素，且最后三个是 'a', 'b', 'c'
            if len(stack) >= 3 and stack[-3:] == ['a', 'b', 'c']:
                # 弹出这三个字符
                stack.pop()
                stack.pop()
                stack.pop()
        
        # 如果栈为空，说明所有字符都被成功匹配
        return len(stack) == 0
```

### 方法二：字符串替换（简单但效率较低）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 不断删除 "abc" 子串，直到无法删除
        while "abc" in s:
            s = s.replace("abc", "")
        
        # 如果最终字符串为空，说明有效
        return s == ""
```

### 方法三：栈优化（字符串切片）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        
        for char in s:
            stack.append(char)
            
            # 使用字符串拼接检查
            if len(stack) >= 3 and ''.join(stack[-3:]) == 'abc':
                # 删除最后三个元素
                del stack[-3:]
        
        return not stack
```

### 方法四：栈（只保留字符）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        
        for c in s:
            if c == 'c':
                # 如果当前是 'c'，检查前两个是否是 'a' 和 'b'
                if len(stack) >= 2 and stack[-2] == 'a' and stack[-1] == 'b':
                    stack.pop()  # 弹出 'b'
                    stack.pop()  # 弹出 'a'
                else:
                    stack.append(c)
            else:
                stack.append(c)
        
        return len(stack) == 0
```

## 复杂度分析

**方法一（栈）：**
- **时间复杂度：** O(n)，每个字符最多入栈和出栈一次
- **空间复杂度：** O(n)，最坏情况栈的大小

**方法二（字符串替换）：**
- **时间复杂度：** O(n^2)，每次 replace 操作都是 O(n)，可能需要执行多次
- **空间复杂度：** O(n)，字符串的临时副本

## 关键点总结

1. **问题转换**：插入操作的逆操作是删除，问题可以转换为不断删除 `"abc"`
2. **栈的应用**：栈适合处理"最近添加的元素"相关的问题
3. **匹配模式**：类似括号匹配，但这里匹配的是三字符序列
4. **优化技巧**：在遇到特定字符（如 'c'）时再检查，可以减少检查次数
5. **替换 vs 栈**：字符串替换简单但效率低，栈方法更优

## 易错点

1. **边界检查**：检查栈顶前要确保栈中至少有 3 个元素
2. **弹出顺序**：要连续弹出 3 个元素，不要只弹出一个
3. **列表切片**：`stack[-3:]` 创建新列表，用于比较，不会修改原栈
4. **空字符串**：空字符串应该返回 `true`（符合题意：从空字符串开始）
