## 题目描述

给你一棵 `n` 个节点的树（无向图，有向边），找到根节点 `r`（0 到 n-1），使得从 `r` 出发能到达所有其他节点时需要**反转的边数最少**。

返回一个数组，`answer[i]` = 以 i 为根时需要反转的最少边数。

**提示：**
- `2 <= n <= 10^5`
- `edges.length == n - 1`

## 解题思路

**换根 DP（Rerooting DP）：**

1. 先以节点 0 为根，DFS 计算 `dp[0]`（从 0 出发需要反转的边数）
2. 再 DFS 重新根：当父节点 `p` 切换到子节点 `c` 时：
   - 若原边方向为 `p -> c`：切换后不需要反转（c 到 p 是反向的），`dp[c] = dp[p] - 0 + 1`（原来不反，现在从 c 看 p 需要反转）
   - 若原边方向为 `c -> p`：切换后不需要反转 `p -> c` 这条（原来反，现在从 c 看顺方向），`dp[c] = dp[p] + 0 - 1`

更准确地：
- 若边方向 `u -> v`（有向），以 u 为根时，这条边顺方向（不需反转）；以 v 为根时，这条边反向（需反转），差值 +1
- 若边方向 `v -> u`（有向），以 u 为根时，这条边需反转；以 v 为根时，顺方向，差值 -1

**切根转移：** `dp[v] = dp[u] + (1 if 原边从 v 到 u else -1)`（当树中 u 是 v 的父亲时）

## Python 代码实现

### 方法一：换根 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minEdgeReversals(self, n: int, edges: List[List[int]]) -> List[int]:
        # 建邻接表：(neighbor, cost) cost=0 表示顺方向，1 表示需反转
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append((v, 0))  # u -> v 方向，不需反转
            graph[v].append((u, 1))  # v -> u 方向，反向时需反转

        dp = [0] * n

        # 第一次 DFS：以 0 为根，计算 dp[0]
        def dfs1(node: int, parent: int):
            for nei, cost in graph[node]:
                if nei != parent:
                    dp[0] += cost  # 从 0 出发，这条边的代价
                    dfs1(nei, node)

        dfs1(0, -1)

        # 第二次 DFS：换根
        def dfs2(node: int, parent: int):
            for nei, cost in graph[node]:
                if nei != parent:
                    # 从 node 换到 nei 为根时
                    # cost 是从 node -> nei 的代价（node 视角）
                    # 从 nei 视角，这条边的代价变为 1 - cost
                    dp[nei] = dp[node] + (1 - cost) - cost
                    # 等价于：dp[nei] = dp[node] + 1 - 2*cost
                    dfs2(nei, node)

        dfs2(0, -1)
        return dp
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minEdgeReversals(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append((v, 0))
            graph[v].append((u, 1))

        dp = [0] * n
        parent = [-1] * n

        # 第一次 DFS（迭代）
        order = []
        stack = [0]
        visited = [False] * n
        visited[0] = True
        while stack:
            node = stack.pop()
            order.append(node)
            for nei, cost in graph[node]:
                if not visited[nei]:
                    visited[nei] = True
                    parent[nei] = node
                    dp[0] += cost
                    stack.append(nei)

        # 第二次 DFS（按 BFS 顺序换根）
        from collections import deque
        queue = deque([0])
        visited = [False] * n
        visited[0] = True
        while queue:
            node = queue.popleft()
            for nei, cost in graph[node]:
                if not visited[nei]:
                    visited[nei] = True
                    dp[nei] = dp[node] + 1 - 2 * cost
                    queue.append(nei)

        return dp
```

## 复杂度分析

- 时间复杂度：O(n)，两次 DFS/BFS
- 空间复杂度：O(n)，图和辅助数组

## 关键点总结

1. 换根 DP：先从一个根计算答案，再通过父子关系的差值递推
2. 转移公式：`dp[child] = dp[parent] + 1 - 2 * cost`（cost 是从 parent 到 child 的代价）
3. 建图时记录每条边的方向（cost=0 顺方向，cost=1 需反转）

## 易错点

1. 建图时需要双向存储（无向图基础上保留原始方向）
2. 转移公式理解：cost=0 说明 parent->child 顺方向，换根后 child->parent 需反转（+1），parent->child 不需要了（+0 - 0 = +0，但对 dp[parent] 的贡献要去掉，所以是 +1 - 0 = +1）
