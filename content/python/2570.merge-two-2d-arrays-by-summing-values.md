## 题目描述

给你两个 **二维** 整数数组 `nums1` 和 `nums2`。

- `nums1[i] = [id_i, val_i]` 表示编号为 `id_i` 的数字，对应值为 `val_i`
- 两个数组均按 `id` 升序排列，且每个 `id` 在各自数组中只出现一次

合并两个数组：对相同 `id` 的项，将其值相加。返回按 `id` 升序排列的合并后数组（每个 `id` 只出现一次）。

**示例 1：**

```
输入：nums1 = [[1,2],[2,3],[4,5]], nums2 = [[1,4],[3,2],[4,1],[5,1]]
输出：[[1,6],[2,3],[3,2],[4,6],[5,1]]
```

**提示：**

- `1 <= nums1.length, nums2.length <= 200`
- 每个 `id` 为 1 到 1000，且在各自数组中唯一

## 解题思路

双指针合并（类似归并排序），或用哈希表合并后排序。

## Python 代码实现

### 方法一：双指针合并（推荐）

```python
from typing import List

class Solution:
    def mergeArrays(self, nums1: List[List[int]], nums2: List[List[int]]) -> List[List[int]]:
        i, j = 0, 0
        result = []

        while i < len(nums1) and j < len(nums2):
            id1, val1 = nums1[i]
            id2, val2 = nums2[j]
            if id1 < id2:
                result.append([id1, val1])
                i += 1
            elif id1 > id2:
                result.append([id2, val2])
                j += 1
            else:
                result.append([id1, val1 + val2])
                i += 1
                j += 1

        # 处理剩余元素
        result.extend(nums1[i:])
        result.extend(nums2[j:])
        return result
```

### 方法二：哈希表

```python
from typing import List
from collections import defaultdict

class Solution:
    def mergeArrays(self, nums1: List[List[int]], nums2: List[List[int]]) -> List[List[int]]:
        total = defaultdict(int)
        for id_, val in nums1:
            total[id_] += val
        for id_, val in nums2:
            total[id_] += val
        return sorted([id_, val] for id_, val in total.items())
```

## 复杂度分析

- 方法一时间复杂度：O(m + n)，双指针线性合并
- 方法二时间复杂度：O((m + n) log(m + n))，排序
- 空间复杂度：O(m + n)，输出数组

## 关键点总结

1. 双指针利用有序性，O(m+n) 合并
2. 相同 id 时，值相加
3. 合并后结果仍按 id 升序

## 易错点

1. 相同 id 时两个指针都要前进
2. 处理完循环后，剩余的部分直接追加
3. 哈希表方法最后需要排序（保证按 id 升序）
