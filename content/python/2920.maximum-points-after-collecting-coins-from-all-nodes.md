## 题目描述

给你一棵 n 个节点的无向树，节点编号为 0 到 n-1，根节点为 0。另给你整数数组 `coins`，其中 `coins[i]` 是节点 i 的金币数，以及一个整数 `k`。

从根节点出发，对每个节点可以选择以下操作之一：
- 操作 1：收集该节点所有金币（值为 `coins[i]`），再减去 `k`（总得分加 `coins[i] - k`）
- 操作 2：将该节点金币数减半（向下取整），该节点得 0 分，但其子树中所有节点的金币数也减半

求能获得的最大总得分。

**示例 1：**
```
输入：edges = [[0,1],[1,2],[2,3]], coins = [10,10,3,3], k = 5
输出：11
```

**示例 2：**
```
输入：edges = [[0,1],[0,2]], coins = [8,4,4], k = 5
输出：16
```

**提示：**
- `n == coins.length`
- `2 <= n <= 10^5`
- `0 <= coins[i] <= 10^4`
- `edges.length == n-1`
- `0 <= k <= 10^4`

## 解题思路

树形 DP + 位运算优化。

关键观察：coins[i] <= 10^4 < 2^14，对一个节点执行操作 2 会将其金币减半，连续减半 14 次后金币变为 0。因此每个节点最多减半 14 次。

定义 `dp[node][j]`：以 node 为根的子树，其金币数已被减半 j 次时的最大得分。

对于节点 node（金币数 `c = coins[node] >> j`）：
- 操作 1：得分 = `c - k + sum(dp[child][j] for child in children)`
- 操作 2：得分 = `sum(dp[child][j+1] for child in children)`（j+1 次减半传递给子树）

## Python 代码实现

### 方法一：树形 DP + 位运算（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumPoints(self, edges: List[List[int]], coins: List[int], k: int) -> int:
        n = len(coins)
        # 建邻接表
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        MAX_HALVE = 14  # coins[i] <= 10^4 < 2^14

        @lru_cache(maxsize=None)
        def dfs(node: int, parent: int, halved: int) -> int:
            # 当前节点的实际金币数（已减半 halved 次）
            c = coins[node] >> halved

            # 操作 1：收集金币
            res1 = c - k
            # 操作 2：不收集（金币继续减半传递给子节点）
            res2 = 0

            for child in graph[node]:
                if child == parent:
                    continue
                # 操作 1：子节点减半次数不变
                res1 += dfs(child, node, halved)
                # 操作 2：子节点再额外减半一次
                if halved < MAX_HALVE:
                    res2 += dfs(child, node, halved + 1)
                # halved >= MAX_HALVE 时金币为 0，操作2得0分

            return max(res1, res2)

        return dfs(0, -1, 0)
```

### 方法二：迭代 DFS（避免递归深度限制）

```python
from typing import List
import sys
sys.setrecursionlimit(200000)

class Solution:
    def maximumPoints(self, edges: List[List[int]], coins: List[int], k: int) -> int:
        n = len(coins)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        MAX_HALVE = 14
        # dp[node][j] = 节点 node 金币减半 j 次时的最大得分
        dp = [[-1] * MAX_HALVE for _ in range(n)]

        # 迭代后序遍历
        order = []
        parent = [-1] * n
        stack = [0]
        visited = [False] * n
        while stack:
            node = stack.pop()
            if visited[node]:
                order.append(node)
                continue
            visited[node] = True
            stack.append(node)
            for child in graph[node]:
                if child != parent[node]:
                    parent[child] = node
                    stack.append(child)

        for node in order:
            children = [c for c in graph[node] if c != parent[node]]
            for j in range(MAX_HALVE):
                c = coins[node] >> j
                res1 = c - k
                res2 = 0
                for child in children:
                    res1 += dp[child][j]
                    if j + 1 < MAX_HALVE:
                        res2 += dp[child][j + 1]
                dp[node][j] = max(res1, res2)

        return dp[0][0]
```

## 复杂度分析

- 时间复杂度：O(n * 14)，每个节点计算 14 个状态
- 空间复杂度：O(n * 14)，DP 数组

## 关键点总结

1. 关键观察：coins 最大值 10^4，连续减半 14 次后为 0，所以减半次数最多 14 次有意义
2. `coins[node] >> j` 等价于将金币减半 j 次（整数除以 2^j）
3. 操作 2 使子树额外减半一次，用 j+1 表示

## 易错点

1. 操作 2 的得分为 0（节点本身不得分），只影响子树的金币数
2. 递归深度可能很大（链状树），需要设置递归限制或改用迭代
3. j >= 14 时金币已为 0，操作 2 的子树得分为 0
