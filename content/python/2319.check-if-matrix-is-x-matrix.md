## 题目描述

如果一个正方形矩阵满足下述条件，则称其为一个 **X 矩阵**：
1. 矩阵对角线上的所有元素都**不是 0**。
2. 矩阵对角线以外的所有元素都是 **0**。

给你一个大小为 `n x n` 的矩阵 `grid`，请你判断 `grid` 是否为 X 矩阵。是则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：grid = [[2,0,0,1],[0,3,1,0],[0,5,2,0],[4,0,0,2]]
输出：true
```

**示例 2：**
```
输入：grid = [[5,7,0],[0,3,1],[0,5,0]]
输出：false
```

**提示：**
- `n == grid.length == grid[i].length`
- `1 <= n <= 100`
- `0 <= grid[i][j] <= 100`

## 解题思路

遍历矩阵每个元素，判断：
- 若在对角线上（`i == j` 或 `i + j == n - 1`），元素必须非零。
- 若不在对角线上，元素必须为零。

## 代码实现

### 方法一：枚举判断（推荐）

```python
from typing import List

class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        for i in range(n):
            for j in range(n):
                on_diagonal = (i == j) or (i + j == n - 1)
                if on_diagonal:
                    if grid[i][j] == 0:
                        return False  # 对角线上必须非零
                else:
                    if grid[i][j] != 0:
                        return False  # 非对角线上必须为零
        return True
```

### 方法二：all + 列表推导式（Pythonic 写法）

```python
from typing import List

class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        return all(
            (grid[i][j] != 0) if (i == j or i + j == n - 1) else (grid[i][j] == 0)
            for i in range(n)
            for j in range(n)
        )
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举判断 | O(n^2) | O(1) |

## 关键点总结

1. n×n 矩阵的两条对角线：主对角线 `i == j`，副对角线 `i + j == n - 1`。
2. 同时在两条对角线上的元素（即矩阵中心，当 n 为奇数时）也算在对角线上。

## 易错点

- 副对角线条件是 `i + j == n - 1`，而不是 `i + j == n`。
- 对角线上的值必须严格非零（> 0），为零则不是 X 矩阵。
