## 题目描述

给定一个字符串 `caption`（视频标题）。生成标签的规则：
1. 以 `'#'` 开头
2. 将标题中所有单词拼接，首个单词全小写，后续每个单词首字母大写（驼峰命名法）
3. 若总长度（含 `'#'`）超过 100，截断到 100 个字符

**示例 1：**

```
输入：caption = "Hello World"
输出："#helloWorld"
```

**示例 2：**

```
输入：caption = "The Quick Brown Fox"
输出："#theQuickBrownFox"
```

**示例 3：**

```
输入：caption = "very long title that might exceed the limit"
输出："#veryLongTitleThatMightExceedTheLimit"（截断到100字符）
```

**提示：**
- `1 <= caption.length <= 150`
- 只含小写字母和空格

## 解题思路

1. 按空格分割单词
2. 第一个单词全小写，其余单词首字母大写（其余小写）
3. 拼接后加 `'#'` 前缀
4. 截断到 100 字符

## Python 代码实现

### 方法一：字符串操作（推荐）

```python
class Solution:
    def generateTag(self, caption: str) -> str:
        words = caption.split()
        if not words:
            return '#'

        # 第一个单词全小写
        result = words[0].lower()

        # 后续单词首字母大写
        for word in words[1:]:
            result += word[0].upper() + word[1:].lower()

        # 加 '#' 前缀，截断到 100 字符
        tag = '#' + result
        return tag[:100]
```

### 方法二：使用 capitalize 方法

```python
class Solution:
    def generateTag(self, caption: str) -> str:
        words = caption.lower().split()
        if not words:
            return '#'

        camel = words[0] + ''.join(w.capitalize() for w in words[1:])
        return ('#' + camel)[:100]
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串
- 空间复杂度：O(n)，结果字符串

## 关键点总结

1. 驼峰命名：首词小写，后续词首字母大写
2. 加 `'#'` 前缀后截断到 100 字符（含 `'#'`）
3. Python 的 `capitalize()` 方法首字母大写，其余小写

## 易错点

1. 截断是在加 `'#'` 之后（所以标签最多 100 字符）
2. 若 caption 只有一个单词，结果是 `#word`（全小写）
3. 注意大写时只有首字母大写，其余保持小写（`capitalize()`）
