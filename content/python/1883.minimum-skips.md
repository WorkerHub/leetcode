## 题目描述

给你一个整数数组 `dist`，其中 `dist[i]` 是第 i 条路的距离，一个整数 `speed` 表示行驶速度，整数 `hoursBefore` 表示需要在 `hoursBefore` 小时内到达终点。

每条路行驶后，若不休息则必须等到下一个整点（向上取整）才能继续。可以在任意路后**跳过休息**（即不等整点直接继续）。

返回到达终点所需的**最少跳过次数**，若无法在 `hoursBefore` 内到达则返回 -1。

**示例：**
```
输入：dist = [1,3,2], speed = 4, hoursBefore = 2
输出：1
```

**提示：**
- `n == dist.length`
- `1 <= n <= 1000`

## 解题思路

**动态规划（浮点精度问题）**：

`dp[i][j]` = 通过前 i 条路，恰好跳过 j 次所需的**最短时间（乘以 speed 后是距离，避免浮点）**。

为避免浮点误差，用整数乘以 speed 计算（所有时间乘以 speed 变为距离单位）：

`dp[i][j]` = 通过前 i 条路，恰好跳过 j 次所需的最短距离（= 时间 * speed）

转移：
- 不跳过第 i 路后的休息：`dp[i][j] = ceil(dp[i-1][j] + dist[i-1])` 的上整 * speed
- 跳过第 i 路后的休息：`dp[i][j] = dp[i-1][j-1] + dist[i-1]`（直接累加）

向上取整用 `(x + speed - 1) // speed * speed`（整数运算）。

## 代码实现

### 方法一：DP + 整数运算（推荐）

```python
from typing import List
import math

class Solution:
    def minSkips(self, dist: List[int], speed: int, hoursBefore: int) -> int:
        n = len(dist)
        INF = float('inf')

        # dp[j] = 已经处理 i 条路，跳过了 j 次时的最小距离（*speed）
        # 用滚动数组
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            new_dp = [INF] * (n + 1)
            for j in range(i + 1):
                # 不跳过第 i 段后的休息
                if j <= i - 1 and dp[j] != INF:
                    # 向上取整到 speed 的倍数
                    val = dp[j] + dist[i - 1]
                    rounded = math.ceil(val / speed) * speed
                    new_dp[j] = min(new_dp[j], rounded)
                # 跳过第 i 段后的休息（j >= 1）
                if j >= 1 and dp[j - 1] != INF:
                    new_dp[j] = min(new_dp[j], dp[j - 1] + dist[i - 1])
            dp = new_dp

        for j in range(n + 1):
            if dp[j] <= hoursBefore * speed:
                return j
        return -1
```

### 方法二：使用 GCD 避免浮点误差

```python
from typing import List

class Solution:
    def minSkips(self, dist: List[int], speed: int, hoursBefore: int) -> int:
        n = len(dist)
        INF = float('inf')
        # 用整数表示距离（乘以 speed 消除分母）
        dp = [[INF] * (n + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        def ceil_mul(x: int) -> int:
            """将 x（距离单位）向上取整到 speed 的倍数"""
            return (x + speed - 1) // speed * speed

        for i in range(1, n + 1):
            for j in range(i + 1):
                # 不跳过
                if j < i:
                    prev = dp[i-1][j]
                    if prev != INF:
                        dp[i][j] = min(dp[i][j], ceil_mul(prev + dist[i-1]))
                # 跳过
                if j > 0:
                    prev = dp[i-1][j-1]
                    if prev != INF:
                        dp[i][j] = min(dp[i][j], prev + dist[i-1])

        for j in range(n + 1):
            if dp[n][j] <= hoursBefore * speed:
                return j
        return -1
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)（可用滚动数组优化为 O(n)）

## 关键点总结

1. 用整数避免浮点精度问题：所有时间 * speed = 距离（整数）
2. 整数向上取整到 speed 的倍数：`(x + speed - 1) // speed * speed`
3. 状态：`dp[i][j]` = 前 i 路，跳过 j 次的最短距离

## 易错点

- 最后一条路后不需要等待（也不需要跳过），j 状态范围上限为 n-1（跳过次数最多 n-1）
- 浮点运算会导致 `ceil` 函数精度问题，建议全程用整数
