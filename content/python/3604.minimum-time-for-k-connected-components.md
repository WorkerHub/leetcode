## 题目描述

给你一个 `n` 个节点的无向加权图，边集为 `edges`，其中 `edges[i] = [u, v, w]` 表示节点 `u` 和 `v` 之间有权重为 `w` 的边。初始时所有节点互相连通（完全连通分量数为 1）。

你可以按任意顺序删除边。请返回使图中连通分量数至少为 `k` 所需删除的边的最小总权重。

**示例 1：**

```
输入：n = 5, edges = [[0,1,5],[1,2,3],[2,3,2],[3,4,4]], k = 3
输出：5
解释：删除权重 2 和 3 的边，得到 3 个连通分量，总权重 5
```

**示例 2：**

```
输入：n = 4, edges = [[0,1,1],[1,2,2],[2,3,3]], k = 2
输出：1
解释：删除权重最小的边即可
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= edges.length <= 2 * 10^5`
- `0 <= u, v < n`
- `1 <= w <= 10^6`
- `1 <= k <= n`

## 解题思路

逆向思维：将问题转化为"从 n 个孤立节点出发，用最大权重边合并，使连通分量数恰好为 k"。

这等价于：在生成树的 `n-1` 条边中，保留权重最大的 `n-k` 条边（使分量数为 k），删除剩余的边总权重最小。

使用 Kruskal 算法（逆向）：
1. 将所有边按权重从大到小排序
2. 用并查集逐步合并，直到连通分量数等于 `k`
3. 被合并的边的权重之和即为需要删除的最小边权重之和

等价于：从最小生成树出发，保留最大的 `n-k` 条树边，其余树边需要删除，非树边全部删除。

实际最优答案 = 总边权 - 选出的最大 `n-k` 条生成树边之和。

## Python 代码实现

### 方法一：并查集 + 逆向 Kruskal（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], k: int) -> int:
        # 按权重从小到大排序，逆向考虑
        edges.sort(key=lambda e: e[2])

        parent = list(range(n))
        rank = [0] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x: int, y: int) -> bool:
            rx, ry = find(x), find(y)
            if rx == ry:
                return False
            if rank[rx] < rank[ry]:
                rx, ry = ry, rx
            parent[ry] = rx
            if rank[rx] == rank[ry]:
                rank[rx] += 1
            return True

        # 先构建最小生成树（或生成森林），记录树边
        tree_edges = []
        components = n
        for u, v, w in edges:
            if union(u, v):
                tree_edges.append(w)
                components -= 1

        # 需要将连通分量从当前状态分裂到 k 个
        # 即删除树中最小的 (components_after_kruskal - k + need_split) 条边
        # 等价于：tree_edges 已按权重升序，删除最小的若干条

        # 重置并查集，逆向：保留最大的 n-k 条树边
        need_to_delete = len(tree_edges) - (n - k)
        if need_to_delete <= 0:
            return 0

        return sum(tree_edges[:need_to_delete])
```

### 方法二：直接贪心删最小树边

```python
from typing import List

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], k: int) -> int:
        edges.sort(key=lambda e: e[2])
        parent = list(range(n))

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x: int, y: int) -> bool:
            rx, ry = find(x), find(y)
            if rx == ry:
                return False
            parent[rx] = ry
            return True

        # 构建最小生成树，收集树边权重
        mst_weights = []
        for u, v, w in edges:
            if union(u, v):
                mst_weights.append(w)

        # 树有 len(mst_weights) 条边，对应 len(mst_weights)+1 个节点（连通分量）
        # 若需要 k 个分量，需删除 k-1 条边（取最小的 k-1 条）
        mst_weights.sort()
        need = k - 1
        if need <= 0:
            return 0
        return sum(mst_weights[:need])
```

## 复杂度分析

- 时间复杂度：O(E log E)，主要是排序
- 空间复杂度：O(n + E)

## 关键点总结

1. 逆向思维：删边增加分量 等价于 选边合并分量
2. 最小代价删边 = 删除最小生成树中权重最小的 `k-1` 条边
3. 非树边不需要删除（它们不影响连通性分裂）
4. 并查集路径压缩 + 按秩合并保证效率

## 易错点

1. 若图已有多个连通分量（不连通），需调整初始分量数
2. `k > n` 是非法输入，不需要考虑
3. 删 `k-1` 条最小树边得到 `k` 个连通分量（而非 `k` 条）
