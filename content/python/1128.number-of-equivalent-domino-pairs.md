## 题目描述

给你一个由一些多米诺骨牌组成的列表 `dominoes`。

如果其中某一张多米诺骨牌可以通过旋转 `0` 度或 `180` 度得到另一张骨牌，我们就认为这两张牌是**等价的**。

形式上，`dominoes[i] = [a, b]` 和 `dominoes[j] = [c, d]` 等价的条件是 `a == c` 且 `b == d`，或是 `a == d` 且 `b == c`。

在 `0 <= i < j < dominoes.length` 的前提下，找出满足 `dominoes[i]` 和 `dominoes[j]` 等价的骨牌对 `(i, j)` 的数量。

**示例 1：**
```
输入：dominoes = [[1,2],[2,1],[3,4],[5,6]]
输出：1
```

**示例 2：**
```
输入：dominoes = [[1,2],[1,2],[1,1],[1,2],[2,2]]
输出：3
```

**提示：**
- `1 <= dominoes.length <= 40000`
- `1 <= dominoes[i][j] <= 9`

## 解题思路

这道题的核心是如何判断两张多米诺骨牌是否等价。关键观察：

1. `[a, b]` 和 `[c, d]` 等价 ⟺ `(a, b) == (c, d)` 或 `(a, b) == (d, c)`
2. 为了统一表示，可以将每张骨牌标准化为 `(min(a, b), max(a, b))`
3. 使用哈希表统计每种标准化骨牌出现的次数
4. 如果某种骨牌出现 n 次，则配对数为 C(n, 2) = n × (n - 1) / 2

### 核心思想

使用**哈希表计数**，将等价的骨牌映射到同一个键，统计每种骨牌的出现次数，然后计算组合数。

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List

class Solution:
    def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
        # 哈希表：存储标准化后的骨牌及其出现次数
        count = {}
        result = 0
        
        for a, b in dominoes:
            # 标准化：将较小的数放在前面
            key = (min(a, b), max(a, b))
            
            # 如果这种骨牌之前出现过，说明可以与之前的骨牌配对
            if key in count:
                result += count[key]
                count[key] += 1
            else:
                count[key] = 1
        
        return result
```

### 方法二：使用元组排序

```python
from typing import List

class Solution:
    def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
        count = {}
        result = 0
        
        for domino in dominoes:
            # 使用 tuple(sorted()) 标准化
            key = tuple(sorted(domino))
            
            # 累加之前相同的骨牌数量
            result += count.get(key, 0)
            # 更新计数
            count[key] = count.get(key, 0) + 1
        
        return result
```

### 方法三：数字编码（空间优化）

```python
from typing import List

class Solution:
    def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
        # 由于每个数字范围是 1-9，可以用两位数编码
        # 例如 [1,2] 编码为 12，[2,1] 也编码为 12
        count = [0] * 100  # 最大为 99
        result = 0
        
        for a, b in dominoes:
            # 确保较小的数在十位
            if a > b:
                a, b = b, a
            
            # 编码为两位数
            key = a * 10 + b
            
            # 累加之前相同的骨牌数量
            result += count[key]
            count[key] += 1
        
        return result
```

### 方法四：暴力解法（不推荐，用于理解）

```python
from typing import List

class Solution:
    def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
        count = 0
        n = len(dominoes)
        
        # 双重循环，检查每一对
        for i in range(n):
            for j in range(i + 1, n):
                a, b = dominoes[i]
                c, d = dominoes[j]
                
                # 判断是否等价
                if (a == c and b == d) or (a == d and b == c):
                    count += 1
        
        return count
```

## 复杂度分析

### 方法一、二、三（哈希表）

- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：
  - 方法一、二：O(k)，k 是不同骨牌的数量，最多 45 种（1-9 的组合）
  - 方法三：O(1)，使用固定大小的数组（100）

### 方法四（暴力解法）

- **时间复杂度**：O(n²)，双重循环
- **空间复杂度**：O(1)

## 关键点总结

1. **标准化表示**：将 `[a, b]` 和 `[b, a]` 统一为 `(min(a, b), max(a, b))`
2. **哈希表应用**：用字典统计每种标准化骨牌的出现次数
3. **组合计数**：n 个相同元素选 2 个的组合数是 n × (n - 1) / 2
4. **累加技巧**：每次遇到重复骨牌时，直接累加之前出现的次数，避免最后计算组合数
5. **空间优化**：利用数字范围小的特点，用数组代替哈希表

## 易错点

1. **配对计数方式**：
   - 错误：统计总数后用 `count[key] * (count[key] - 1) / 2`
   - 正确：每次遇到重复时累加 `count[key]`（已有的相同骨牌数量）
2. **标准化方向**：
   - 必须保证 `[1,2]` 和 `[2,1]` 映射到同一个键
   - 使用 `(min(a,b), max(a,b))` 或 `tuple(sorted([a,b]))`
3. **索引范围**：题目要求 `i < j`，所以是无序对，不需要考虑顺序
4. **数字范围**：题目限定 `1 <= dominoes[i][j] <= 9`，可以用数组优化
