## 题目描述

树可以看成是一个无向图，其中任何两个顶点只通过一条路径连接。

在本问题中，添加一条附加的边连接到树中的两个顶点，创建一个图。

给定一个包含 n 个节点（节点值为 1 到 n）的边数组 edges，找到一条可以删除的边，使得删除后的图恢复成一棵树。

如果有多个答案，返回最后出现在数组中的边。

**示例 1：**
```
输入：edges = [[1,2],[1,3],[2,3]]
输出：[2,3]
```

**示例 2：**
```
输入：edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]
输出：[1,4]
```

**提示：**
- n == edges.length
- 3 <= n <= 1000
- edges[i].length == 2
- 1 <= edges[i][0] < edges[i][1] <= n

## 解题思路

使用并查集来检测环的形成。

**核心思想：**
1. 遍历所有边
2. 如果两个节点已经在同一集合中，说明添加这条边会形成环
3. 返回第一条导致环的边

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        n = len(edges)
        parent = list(range(n + 1))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False
            parent[root_x] = root_y
            return True
        
        for u, v in edges:
            if not union(u, v):
                return [u, v]
        
        return []
```

### 方法二：DFS 检测环

```python
from typing import List
import collections

class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        graph = collections.defaultdict(set)
        
        def has_cycle(u, v):
            """检查添加边 (u,v) 是否会形成环"""
            visited = set()
            
            def dfs(node, target):
                if node == target:
                    return True
                visited.add(node)
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        if dfs(neighbor, target):
                            return True
                return False
            
            return dfs(u, v)
        
        for u, v in edges:
            if has_cycle(u, v):
                return [u, v]
            graph[u].add(v)
            graph[v].add(u)
        
        return []
```

## 复杂度分析

**并查集方法：**
- 时间复杂度：O(n * α(n))，α 是阿克曼函数的反函数，几乎为常数
- 空间复杂度：O(n)

**DFS方法：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 并查集用于检测无向图中的环
2. 如果两个节点已连通，添加边会形成环
3. 返回最后出现的导致环的边

## 易错点

1. 忘记路径压缩导致性能下降
2. 索引从1开始而不是0
3. 没有正确实现 find 和 union 操作
