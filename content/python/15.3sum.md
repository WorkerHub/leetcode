## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0
不同的三元组是 [-1,0,1] 和 [-1,-1,2]
注意，输出的顺序和三元组的顺序并不重要。
```

**示例 2：**
```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0
```

**示例 3：**
```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0
```

## 解题思路

### 核心思想：排序 + 双指针

这道题是「两数之和」的进阶版，关键点在于：
1. **排序**：先对数组排序，方便去重和使用双指针
2. **固定一个数**：将三数之和转化为两数之和问题
3. **双指针**：在剩余数组中用双指针查找两数之和
4. **去重**：避免重复的三元组

**算法流程：**
1. 对数组进行排序
2. 遍历数组，固定第一个数 `nums[i]`
3. 在 `[i+1, n-1]` 范围内用双指针查找两数之和为 `-nums[i]`
4. 如果找到，记录结果，并移动指针跳过重复元素
5. 如果和太小，左指针右移；如果和太大，右指针左移

## Python 代码实现

### 方法：排序 + 双指针

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()  # 排序
        result = []
        n = len(nums)
        
        # 固定第一个数
        for i in range(n - 2):
            # 跳过重复的第一个数
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            # 优化：如果最小的数都大于0，后面不可能有解
            if nums[i] > 0:
                break
            
            # 双指针查找剩余两个数
            left, right = i + 1, n - 1
            target = -nums[i]
            
            while left < right:
                current_sum = nums[left] + nums[right]
                
                if current_sum == target:
                    # 找到一组解
                    result.append([nums[i], nums[left], nums[right]])
                    
                    # 跳过重复的元素
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    
                    # 移动指针
                    left += 1
                    right -= 1
                    
                elif current_sum < target:
                    left += 1  # 和太小，左指针右移
                else:
                    right -= 1  # 和太大，右指针左移
        
        return result
```

### 优化版（更简洁）

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        result = []
        
        for i in range(len(nums) - 2):
            # 去重 + 剪枝
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            if nums[i] > 0:
                break
            
            left, right = i + 1, len(nums) - 1
            
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                
                if total == 0:
                    result.append([nums[i], nums[left], nums[right]])
                    # 去重
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif total < 0:
                    left += 1
                else:
                    right -= 1
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n²)
  - 排序：O(n log n)
  - 外层循环：O(n)
  - 内层双指针：O(n)
  - 总体：O(n²)

- **空间复杂度**：O(log n)，排序所需的栈空间（不计结果数组）

## 图解示例

以 `nums = [-1,0,1,2,-1,-4]` 为例：

```
排序后：[-4, -1, -1, 0, 1, 2]

i=0, nums[i]=-4:
  left=1, right=5: -4 + (-1) + 2 = -3 < 0, left++
  left=2, right=5: -4 + (-1) + 2 = -3 < 0, left++
  ...无解

i=1, nums[i]=-1:
  left=2, right=5: -1 + (-1) + 2 = 0 ✓ → [-1,-1,2]
  跳过重复，left=3, right=4
  left=3, right=4: -1 + 0 + 1 = 0 ✓ → [-1,0,1]

i=2, nums[i]=-1: 跳过（重复）

结果：[[-1,-1,2], [-1,0,1]]
```

## 关键点总结

1. **排序是前提**：排序后才能使用双指针，且方便去重
2. **三数转两数**：固定一个数，问题变成两数之和
3. **去重三个位置**：
   - 第一个数去重：`if i > 0 and nums[i] == nums[i-1]: continue`
   - 第二个数去重：找到解后跳过相同的 `left`
   - 第三个数去重：找到解后跳过相同的 `right`
4. **剪枝优化**：如果 `nums[i] > 0`，后面不可能有解
5. **双指针移动**：根据和的大小决定移动哪个指针

## 易错点

1. **去重位置**：
   - ❌ `if nums[i] == nums[i-1]` 会漏掉 `i=0` 的情况
   - ✅ `if i > 0 and nums[i] == nums[i-1]`

2. **去重时机**：
   - 找到解后要先跳过重复元素，再移动指针
   - 否则会漏掉一些解

3. **边界条件**：
   - `while left < right` 要有等号判断
   - 跳过重复时也要检查 `left < right`
