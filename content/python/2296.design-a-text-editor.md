## 题目描述

请设计一个带光标的文本编辑器，支持以下操作：

- `TextEditor()`：构造函数，初始化空文本。
- `addText(text)`：在光标处添加字符串，光标移到字符串末尾。
- `deleteText(k)`：删除光标左侧 k 个字符，返回实际删除的字符数（不足 k 时删除所有）。
- `cursorLeft(k)`：光标向左移动 k 次，不能超过文本开头，返回光标左侧最多 10 个字符。
- `cursorRight(k)`：光标向右移动 k 次，不能超过文本末尾，返回光标左侧最多 10 个字符。

## 解题思路

**双栈模拟光标：**

用两个栈：
- `left_stack`：光标左侧的字符（栈顶为光标紧左边的字符）。
- `right_stack`：光标右侧的字符（栈顶为光标紧右边的字符）。

操作实现：
- `addText(text)`：将字符逐一压入 `left_stack`。
- `deleteText(k)`：从 `left_stack` 弹出至多 k 个字符。
- `cursorLeft(k)`：从 `left_stack` 弹出至多 k 个字符，压入 `right_stack`。
- `cursorRight(k)`：从 `right_stack` 弹出至多 k 个字符，压入 `left_stack`。

返回光标左侧最多 10 个字符：取 `left_stack` 顶部 10 个字符。

## 代码实现

### 方法一：双栈（推荐）

```python
class TextEditor:
    def __init__(self):
        self.left = []   # 光标左侧字符，栈顶为紧靠光标的字符
        self.right = []  # 光标右侧字符，栈顶为紧靠光标的字符

    def addText(self, text: str) -> None:
        for ch in text:
            self.left.append(ch)

    def deleteText(self, k: int) -> int:
        deleted = min(k, len(self.left))
        for _ in range(deleted):
            self.left.pop()
        return deleted

    def cursorLeft(self, k: int) -> str:
        move = min(k, len(self.left))
        for _ in range(move):
            self.right.append(self.left.pop())
        # 返回光标左侧最多 10 个字符
        return ''.join(self.left[-10:])

    def cursorRight(self, k: int) -> str:
        move = min(k, len(self.right))
        for _ in range(move):
            self.left.append(self.right.pop())
        return ''.join(self.left[-10:])
```

### 方法二：用字符串切片（更简洁但效率较低）

```python
class TextEditor:
    def __init__(self):
        self.text = ""
        self.cursor = 0  # 光标位置（在 text 中的下标）

    def addText(self, text: str) -> None:
        self.text = self.text[:self.cursor] + text + self.text[self.cursor:]
        self.cursor += len(text)

    def deleteText(self, k: int) -> int:
        deleted = min(k, self.cursor)
        self.text = self.text[:self.cursor - deleted] + self.text[self.cursor:]
        self.cursor -= deleted
        return deleted

    def cursorLeft(self, k: int) -> str:
        self.cursor = max(0, self.cursor - k)
        return self.text[max(0, self.cursor - 10):self.cursor]

    def cursorRight(self, k: int) -> str:
        self.cursor = min(len(self.text), self.cursor + k)
        return self.text[max(0, self.cursor - 10):self.cursor]
```

## 复杂度分析

**方法一（双栈）：**
- `addText`：O(|text|)。
- `deleteText`：O(k)。
- `cursorLeft/Right`：O(k + 10)。
- 空间复杂度：O(n)，n 为总字符数。

**方法二（字符串）：**
- `addText`：O(n)，字符串拼接。
- 其他：O(n)。

## 关键点总结

1. 双栈是光标操作的经典数据结构：光标左右两侧各一个栈。
2. 光标移动 = 在两个栈之间转移元素。
3. 返回左侧最多 10 个字符：`''.join(left[-10:])`。

## 易错点

- 移动步数不能超过实际可移动范围：`min(k, len(left/right))`。
- `addText` 需要逐字符压栈（不能批量），或直接 `self.left.extend(text)`。
