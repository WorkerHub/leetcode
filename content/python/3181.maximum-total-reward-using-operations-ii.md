## 题目描述

与 3180 相同，但数据范围更大：
- `1 <= rewardValues.length <= 5 * 10^4`
- `1 <= rewardValues[i] <= 5 * 10^4`

需要高效的 bitset 方案。

## 解题思路

与 3180 方法二相同，使用 Python 大整数作为 bitset。

对每个奖励 r（排序后），可达集合更新为：`dp |= (dp & mask) << r`，其中 `mask = (1 << r) - 1`。

Python 的大整数支持任意精度位运算，直接使用即可。

## Python 代码实现

### 方法一：大整数 bitset（推荐）

```python
from typing import List

class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        rewardValues = sorted(set(rewardValues))
        dp = 1  # 初始 v=0 可达

        for r in rewardValues:
            # 取 dp 中 v < r 的位，左移 r 位后并入 dp
            mask = (1 << r) - 1
            dp |= (dp & mask) << r

        return dp.bit_length() - 1
```

### 方法二：显式说明

```python
from typing import List

class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        vals = sorted(set(rewardValues))
        # dp 第 v 位为 1 表示总奖励 v 可达
        dp = 1  # 第 0 位为 1

        for r in vals:
            # 所有 v < r 且可达的总奖励，加上 r 后也可达
            # 即：dp 的低 r 位代表当前可达的 v < r 的情况
            below = dp & ((1 << r) - 1)
            dp |= below << r

        # 找最高位
        return dp.bit_length() - 1
```

## 复杂度分析

- 时间复杂度：O(n * max_val / 64)，位运算并行化
- 空间复杂度：O(max_val / 64)

## 关键点总结

1. 利用 Python 大整数的位运算，相当于 bitset
2. 每次操作是 O(max_val / word_size) 的位操作
3. `(dp & mask) << r` 同时处理所有可达状态

## 易错点

1. 去重 rewardValues（相同的奖励只能用一次）
2. mask = (1 << r) - 1 只取 r 位以下的部分
