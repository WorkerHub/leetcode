## 题目描述

给定圆上的 `2n` 个点，编号为 `0` 到 `2n-1`（按圆周顺序排列）。用 `n` 条弦连接这些点（每个点恰好属于一条弦）。若两条弦 `(a,b)` 和 `(c,d)` 满足弦在圆内相交（即端点交叉分布），则称它们"相交"。

求连接 `2n` 个点的方案中，最大相交弦对数。

**示例 1：**
```
输入：n = 2
输出：1
解释：4 个点，2 条弦，最多 1 对相交。
```

**示例 2：**
```
输入：n = 3
输出：3
解释：6 个点，3 条弦，最多 3 对相交。
```

**提示：**
- `1 <= n <= 500`

## 解题思路

动态规划。

设 `dp[i]` 为用 `2i` 个连续圆周点连接 `i` 条弦的最大相交对数。

关键观察：若弦 `(0, k)` 连接最左点和第 `k` 点（`k` 为奇数，因为需要偶数个点在两侧）：
- 弦左侧 `k-1` 个点（`1` 到 `k-1`，偶数个），连 `(k-1)/2` 条弦
- 弦右侧 `2n-k-1` 个点，连剩余弦
- 每条左侧的弦与每条右侧的弦都与 `(0,k)` 相交一次

$dp[n] = \max_{k \text{ 奇数}} \left( dp[\frac{k-1}{2}] + dp[n - \frac{k+1}{2}] + \frac{k-1}{2} \cdot (n - \frac{k+1}{2}) \right)$

等价地，枚举第一个点（0）与哪个点相连，设连的是第 `2j+1` 个点（确保两侧各有偶数个点），则：
- 左边 `j` 条弦，右边 `n-j-1` 条弦
- 相交对数 = `j * (n-j-1) + dp[j] + dp[n-j-1]`

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def maxIntersections(self, n: int) -> int:
        # dp[i]: 2i 个点构成的 i 条弦的最大相交对数
        dp = [0] * (n + 1)

        for i in range(2, n + 1):
            # 固定点 0，枚举与其配对的点（必须使两侧点数为偶数）
            # 配对点 k，左侧有 k-1 个点（需为偶数），右侧有 2i-k-1 个点（需为偶数）
            # 因此 k 为奇数：k = 1, 3, 5, ..., 2i-1
            for k in range(1, 2 * i, 2):
                left = (k - 1) // 2      # 左侧弦数
                right = i - 1 - left      # 右侧弦数
                pairs = left * right       # 左侧弦与右侧弦的相交对数
                dp[i] = max(dp[i], dp[left] + dp[right] + pairs)

        return dp[n]
```

### 方法二：数学公式（最优为全交叉）

```python
class Solution:
    def maxIntersections(self, n: int) -> int:
        # 最优方案是使所有弦两两相交，对数为 C(n, 2) = n*(n-1)/2
        # 但不是所有 n 条弦都能两两相交
        # 实际上通过 DP 求解
        dp = [0] * (n + 1)
        for i in range(2, n + 1):
            for k in range(1, 2 * i, 2):
                left = (k - 1) // 2
                right = i - 1 - left
                dp[i] = max(dp[i], dp[left] + dp[right] + left * right)
        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^2)，双重循环
- 空间复杂度：O(n)

## 关键点总结

1. 固定一条弦，将问题分解为两个独立子问题（左侧和右侧）
2. 跨越该弦的弦与该弦相交，左侧弦 * 右侧弦 = 新增相交对数
3. 选择 k 使两侧各有偶数个点（k 为奇数）

## 易错点

1. 枚举 k 时必须保证 `(k-1)` 为偶数（即 k 为奇数）才能整除
2. 答案不一定是 `C(n,2)`，不是所有弦都能相互相交
