## 题目描述

给你一个长度为 `n` 的数组 `nums`（包含 1 到 n 的所有整数），以及一个整数 `k`。

子数组的 **中位数** 定义：若子数组长度为奇数，中位数是排序后中间的数；若为偶数，中位数是排序后两个中间数中较小的那个。

返回中位数为 `k` 的子数组数目。

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i], k <= n`
- `nums` 中的整数互不相同

## 解题思路

**哈希表 + 前缀和：**

找到 k 在数组中的位置 `pos`。对于包含 k 的子数组 `[l, r]`（`l <= pos <= r`）：

将每个元素转化为 +1（大于 k）或 -1（小于 k）或 0（等于 k，即 k 本身）。

中位数为 k 的条件：
- 奇数长度：`sum([l, r]) == 0`（小于 k 的个数 == 大于 k 的个数）
- 偶数长度：`sum([l, r]) == 1`（大于 k 的个数比小于 k 的个数多 1）

即 `sum([l, r]) == 0` 或 `sum([l, r]) == 1`。

用前缀和：设 `pre[i]` = 转化后前 i 个元素的前缀和，则 `sum([l, r]) = pre[r+1] - pre[l]`。

枚举右边界 r（`r >= pos`），查找左边界 l（`l <= pos`）满足 `pre[r+1] - pre[l] in {0, 1}`。

用哈希表记录 `[0, pos]` 的前缀和个数，每次枚举 r 时查询即可。

## 代码实现

### 方法一：哈希表 + 前缀和（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        pos = nums.index(k)  # k 在数组中的位置

        # 将数组转化：大于 k 为 +1，小于 k 为 -1，k 本身为 0
        transformed = [0 if x == k else (1 if x > k else -1) for x in nums]

        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + transformed[i]

        # 统计左半部分（[0, pos]）的前缀和频次
        left_count = defaultdict(int)
        for i in range(pos + 1):  # l 从 0 到 pos，前缀和为 prefix[l] = prefix[i]
            left_count[prefix[i]] += 1

        # 枚举右边界 r（从 pos 到 n-1）
        ans = 0
        for r in range(pos, n):
            # sum([l, r]) = prefix[r+1] - prefix[l]
            # 需要 prefix[r+1] - prefix[l] in {0, 1}
            # 即 prefix[l] in {prefix[r+1], prefix[r+1] - 1}
            target_sum = prefix[r + 1]
            ans += left_count[target_sum]       # sum = 0
            ans += left_count[target_sum - 1]   # sum = 1

        return ans
```

### 方法二：直接枚举

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        pos = nums.index(k)
        ans = 0

        for l in range(n):
            if l > pos:
                break
            balance = 0  # 大于k的个数 - 小于k的个数
            for r in range(l, n):
                if nums[r] > k:
                    balance += 1
                elif nums[r] < k:
                    balance -= 1
                if r >= pos and balance in (0, 1):
                    ans += 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(n) |
| 枚举 | O(n^2) | O(1) |

## 关键点总结

1. 含 k 的子数组中位数为 k ↔ balance（大于k数量 - 小于k数量）为 0 或 1
2. 前缀和 + 哈希表：固定右边界，查左边界
3. balance=0 对应奇数长度中位数恰好是 k，balance=1 对应偶数长度

## 易错点

- 子数组必须包含 k（所以左边界 <= pos <= 右边界）
- 偶数长度中位数取较小值，所以 balance=1 也算（k 比另一个中位数小）
