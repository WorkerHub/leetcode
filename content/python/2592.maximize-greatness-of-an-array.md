## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。你需要将 `nums` 重新排列成一个新数组 `perm`。

定义 `nums` 的 **伟大值** 为满足 `0 <= i < nums.length` 且 `perm[i] > nums[i]` 的下标数目。

返回重新排列 `nums` 能够得到的 **最大伟大值**。

**示例 1：**

```
输入：nums = [1,3,5,2,1,3,1]
输出：4
解释：一种最优排列是 [2,5,3,3,3,1,1]
perm[0]=2 > nums[0]=1，perm[1]=5 > nums[1]=3，perm[2]=3 < nums[2]=5（不满足），
perm[3]=3 > nums[3]=2，perm[4]=3 > nums[4]=1，满足 4 个。
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：3
解释：[2,3,4,1] 满足 perm[0]>1, perm[1]>2, perm[2]>3，共 3 个。
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

**排序 + 贪心双指针**：

经典的"田忌赛马"策略：

1. 对 `nums` 排序
2. 用双指针：`i` 指向待满足的位置，`j` 指向可用来覆盖的元素
3. 若 `nums[j] > nums[i]`，则配对成功，两指针各移一位，计数 +1
4. 否则，`j` 右移寻找更大的元素

等价地，`perm` 是 `nums` 的某个排列，使 `perm[i] > nums[i]` 尽可能多。

## Python 代码实现

### 方法一：排序双指针（推荐）

```python
from typing import List

class Solution:
    def maximizeGreatness(self, nums: List[int]) -> int:
        nums.sort()
        i = 0  # 待被超越的下标（nums 排好序的）
        ans = 0

        for j in range(len(nums)):
            # nums[j] 作为 perm[i] 来超越 nums[i]
            if nums[j] > nums[i]:
                ans += 1
                i += 1

        return ans
```

### 方法二：贪心计数（等价简洁写法）

```python
from typing import List

class Solution:
    def maximizeGreatness(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        # 双指针：ptr 指向需要被超越的元素
        ptr = 0
        for x in nums:
            if x > nums[ptr]:
                ptr += 1
        return ptr
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（原地排序）

## 关键点总结

1. 排序后用双指针贪心配对，类似"田忌赛马"
2. 对于 nums 中每个元素，尽量用刚好比它大的元素来超越它（充分利用资源）
3. 指针 `ptr` 前进的次数即为最终答案

## 易错点

1. 排序后两个指针都在同一个排好序的数组上操作（不是两个独立数组）
2. 只有严格大于才算（`>`，不含等于）
3. 不需要真正构造 perm，只需统计能配对成功的数量
