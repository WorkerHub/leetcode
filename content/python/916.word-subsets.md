## 题目描述

给你两个字符串数组 `words1` 和 `words2`。

现在，如果 `b` 中的每个字母都在 `a` 中出现（**包括重复字母**），那么称字符串 `b` 是字符串 `a` 的 **子集**。

- 例如，`"wrr"` 是 `"warrior"` 的子集，但不是 `"world"` 的子集。

如果对 `words2` 中的每一个单词 `b`，`b` 都是 `a` 的子集，那么我们称 `words1` 中的单词 `a` 是 **通用单词**。

以数组形式返回 `words1` 中所有的通用单词。你可以按 **任意顺序** 返回答案。

**示例 1：**
```
输入：words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["e","o"]
输出：["facebook","google","leetcode"]
```

**示例 2：**
```
输入：words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["l","e"]
输出：["apple","google","leetcode"]
```

**提示：**
- `1 <= words1.length, words2.length <= 10^4`
- `1 <= words1[i].length, words2[i].length <= 10`
- `words1[i]` 和 `words2[i]` 仅由小写英文字母组成
- 所有 `words1[i]` 互不相同

## 解题思路

这道题的关键是理解"通用单词"的定义：对于 `words1` 中的单词 `a`，如果 `words2` 中的每个单词都是 `a` 的子集，那么 `a` 是通用单词。

**朴素思路：**
- 对于 `words1` 中的每个单词，检查它是否包含 `words2` 中所有单词的字母
- 时间复杂度：O(n * m * k)，n 和 m 是两个数组长度，k 是单词长度

**优化思路：**
- 不需要检查每个 `words2` 的单词，可以合并它们的要求
- 对于每个字母，我们只需要知道它在 `words2` 中出现的 **最大次数**
- 例如：`words2 = ["eo", "eoo"]`，我们只需要检查 `a` 是否包含至少 1 个 'e' 和 2 个 'o'

**具体步骤：**
1. 统计 `words2` 中每个单词的字符频率
2. 合并这些频率，对于每个字符，取最大出现次数
3. 检查 `words1` 中每个单词是否满足这个合并后的要求

## Python 代码实现

### 方法一：字符频率统计（推荐 ⭐）

```python
from typing import List
from collections import Counter

class Solution:
    def wordSubsets(self, words1: List[str], words2: List[str]) -> List[str]:
        # 计算 words2 中每个字符的最大出现次数
        max_freq = Counter()
        for word in words2:
            freq = Counter(word)
            # 对每个字符，取最大值
            for char, count in freq.items():
                max_freq[char] = max(max_freq[char], count)
        
        # 检查 words1 中的每个单词
        result = []
        for word in words1:
            freq = Counter(word)
            # 检查是否满足所有字符的最大频率要求
            if all(freq[char] >= count for char, count in max_freq.items()):
                result.append(word)
        
        return result
```

### 方法二：使用数组代替 Counter

```python
from typing import List

class Solution:
    def wordSubsets(self, words1: List[str], words2: List[str]) -> List[str]:
        # 计算 words2 中每个字符的最大出现次数
        max_freq = [0] * 26  # 只有小写字母
        
        for word in words2:
            # 统计当前单词的字符频率
            freq = [0] * 26
            for char in word:
                freq[ord(char) - ord('a')] += 1
            
            # 更新最大频率
            for i in range(26):
                max_freq[i] = max(max_freq[i], freq[i])
        
        # 检查 words1 中的每个单词
        result = []
        for word in words1:
            # 统计当前单词的字符频率
            freq = [0] * 26
            for char in word:
                freq[ord(char) - ord('a')] += 1
            
            # 检查是否满足要求
            if all(freq[i] >= max_freq[i] for i in range(26)):
                result.append(word)
        
        return result
```

### 方法三：简化版

```python
from typing import List
from collections import Counter

class Solution:
    def wordSubsets(self, words1: List[str], words2: List[str]) -> List[str]:
        def count(word):
            """统计字符频率"""
            return Counter(word)
        
        def is_subset(counter1, counter2):
            """检查 counter2 是否是 counter1 的子集"""
            return all(counter1[char] >= count for char, count in counter2.items())
        
        # 合并 words2 的要求
        max_req = Counter()
        for word in words2:
            word_count = count(word)
            for char in word_count:
                max_req[char] = max(max_req[char], word_count[char])
        
        # 过滤 words1
        return [word for word in words1 if is_subset(count(word), max_req)]
```

## 复杂度分析

**时间复杂度：** O((n + m) * k)
- n 是 words1 的长度，m 是 words2 的长度，k 是平均单词长度
- 统计 words2 需要 O(m * k)
- 检查 words1 需要 O(n * k)

**空间复杂度：** O(1)
- 字符集大小固定（26 个字母），空间是常数级别

## 关键点总结

1. **问题转化**：将多个子集要求合并为一个要求
2. **最大频率**：对每个字符，取 words2 中的最大出现次数
3. **Counter 使用**：统计字符频率
4. **优化思路**：避免重复检查，预处理 words2
5. **数组优化**：可以用数组代替字典，空间更优

## 易错点

1. **理解子集**：子集要求包含所有字母及其出现次数
2. **重复字母**：要考虑字母的重复次数，不只是是否出现
3. **合并策略**：对每个字符取最大次数，不是累加
4. **边界情况**：words2 为空或 words1 为空
5. **字符范围**：题目保证只有小写字母
