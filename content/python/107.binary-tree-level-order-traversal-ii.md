## 题目描述

给你二叉树的根节点 `root`，返回其节点值自底向上的层序遍历。（即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：[[15,7],[9,20],[3]]
```

**示例 2：**

```
输入：root = [1]
输出：[[1]]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`

## 解题思路

这道题是二叉树层序遍历的变体，要求自底向上输出结果。核心思路有两种：

**方法一：正常层序遍历 + 反转结果**
1. 使用 BFS（广度优先搜索）进行正常的层序遍历
2. 将每一层的节点值收集到结果列表中
3. 最后将整个结果列表反转

**方法二：正常层序遍历 + 头部插入**
1. 使用 BFS 进行正常的层序遍历
2. 每遍历完一层，将该层结果插入到结果列表的开头
3. 这样就不需要最后反转

**BFS 层序遍历的标准模板**：
1. 使用队列存储节点
2. 每次处理当前队列中的所有节点（一层）
3. 将下一层的节点加入队列
4. 重复直到队列为空

## Python 代码实现

### 方法一：BFS + 反转结果（推荐）⭐

```python
from typing import List, Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        # 边界情况：空树
        if not root:
            return []
        
        result = []
        queue = deque([root])  # 使用双端队列
        
        # BFS 层序遍历
        while queue:
            level_size = len(queue)  # 当前层的节点数量
            level_values = []  # 存储当前层的节点值
            
            # 遍历当前层的所有节点
            for _ in range(level_size):
                node = queue.popleft()
                level_values.append(node.val)
                
                # 将下一层的节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 将当前层的结果加入到结果列表
            result.append(level_values)
        
        # 反转结果，实现自底向上
        return result[::-1]
```

### 方法二：BFS + 头部插入

```python
class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            level_values = []
            
            for _ in range(level_size):
                node = queue.popleft()
                level_values.append(node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 将当前层插入到结果列表的开头，实现自底向上
            result.insert(0, level_values)
        
        return result
```

### 方法三：DFS + 深度记录

```python
class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        
        def dfs(node: Optional[TreeNode], level: int) -> None:
            """深度优先搜索，记录每个节点所在的层级"""
            if not node:
                return
            
            # 如果当前层级还没有对应的列表，就创建一个
            if level >= len(result):
                result.append([])
            
            # 将当前节点的值加入到对应层级的列表中
            result[level].append(node.val)
            
            # 递归遍历左右子树
            dfs(node.left, level + 1)
            dfs(node.right, level + 1)
        
        # 从根节点开始，层级为 0
        dfs(root, 0)
        
        # 反转结果，实现自底向上
        return result[::-1]
```

### 方法四：使用 collections.deque（双端队列优化）

```python
class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = deque()  # 使用双端队列存储结果
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            level_values = []
            
            for _ in range(level_size):
                node = queue.popleft()
                level_values.append(node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 使用 appendleft 在头部插入，避免反转
            result.appendleft(level_values)
        
        return list(result)
```

## 复杂度分析

### 方法一、二、四（BFS）

- **时间复杂度**：O(n)，其中 n 是树中的节点数。每个节点都会被访问一次。
- **空间复杂度**：O(n)，队列中最多会存储一层的节点，最坏情况下（完全二叉树）最后一层有 n/2 个节点。

### 方法三（DFS）

- **时间复杂度**：O(n)，每个节点都会被访问一次。
- **空间复杂度**：O(h)，其中 h 是树的高度，递归调用栈的深度。最坏情况下 h = n（退化成链表）。

## 关键点总结

1. **BFS 模板掌握**：层序遍历是 BFS 的经典应用，要掌握标准模板
2. **层级分离**：使用 `level_size = len(queue)` 来分离每一层
3. **反转技巧**：
   - 方法一：最后统一反转 `[::-1]`
   - 方法二：使用 `insert(0, ...)`
   - 方法四：使用双端队列的 `appendleft`
4. **DFS 也可行**：虽然层序遍历通常用 BFS，但 DFS 记录层级也能实现
5. **队列选择**：使用 `collections.deque` 比列表效率更高

## 易错点

1. **层级分离错误**：忘记记录 `level_size`，导致无法正确分离每一层
2. **空树处理**：要检查 `root` 是否为 `None`
3. **反转时机**：要在所有层遍历完成后再反转，不能边遍历边反转
4. **插入位置**：方法二使用 `insert(0, ...)` 时，注意每次都是插入到开头
5. **队列操作**：要使用 `popleft()` 而不是 `pop()`，保证先进先出
