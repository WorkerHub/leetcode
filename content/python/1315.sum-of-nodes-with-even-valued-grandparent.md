## 题目描述

给你一棵二叉树，请你返回满足以下条件的所有节点的值之和：

- 该节点的祖父节点的值为偶数（祖父节点是当前节点的父节点的父节点）。

如果不存在祖父节点，那么该节点就不在上述要求的范围内。

**示例：**

```
        6
       / \
      7   8
     / \ / \
    2  7 1  3
   /  \  \
  9   1   4
```

```
输入：root = [6,7,8,2,7,1,3,9,null,1,null,null,null,null,4]
输出：18
解释：节点 2 的祖父是 6（偶数）：+2
     节点 7 的祖父是 6（偶数）：已在右子树，左子的祖父7（奇数）、右子的祖父也是7（奇数）
     节点 1 的祖父是 8（偶数）：+1
     节点 3 的祖父是 8（偶数）：+3
     节点 9 的祖父是 7（奇数）：不计入
     节点 1(右) 祖父是 7（奇数）：不计入
     节点 4 的祖父是 1（奇数）：不计入
     总和 = 2 + 7 + 1 + 3 + ... = 18
```

**提示：**

- 树中节点的数目在 `1` 到 `10^4` 之间
- 每个节点的值在 `1` 到 `100` 之间

## 解题思路

**思路一：DFS 传递父节点和祖父节点的值（推荐）**

在 DFS 遍历时，额外传递当前节点的父节点值和祖父节点值。当祖父节点值为偶数时，将当前节点值累加到结果中。

**思路二：BFS 层次遍历**

使用队列存储 `(节点, 父节点, 祖父节点)` 三元组，逐层扩展时传递祖先信息。

**思路三：反向思维（从父节点统计孙子）**

遍历每个偶数值节点，直接累加它的所有孙子节点值（跳过两层子节点）。

## Python 代码实现

### 方法一：DFS 传递父祖父值（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        self.total = 0
        
        def dfs(node, parent_val, grandparent_val):
            if not node:
                return
            # 祖父节点值为偶数，累加当前节点
            if grandparent_val % 2 == 0:
                self.total += node.val
            # 继续深入，更新父值和祖父值
            dfs(node.left, node.val, parent_val)
            dfs(node.right, node.val, parent_val)
        
        # 根节点无父节点和祖父节点，用奇数 1 初始化避免误判
        dfs(root, 1, 1)
        return self.total
```

### 方法二：DFS（无全局变量，返回累加值）

```python
from typing import Optional

class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        
        def dfs(node, parent_val, grandparent_val) -> int:
            if not node:
                return 0
            # 当前节点的贡献（祖父为偶数时）
            curr = node.val if grandparent_val % 2 == 0 else 0
            # 递归计算左右子树
            left = dfs(node.left, node.val, parent_val)
            right = dfs(node.right, node.val, parent_val)
            return curr + left + right
        
        return dfs(root, 1, 1)
```

### 方法三：BFS 层次遍历

```python
from typing import Optional
from collections import deque

class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        total = 0
        # 队列存储 (节点, 父节点值, 祖父节点值)
        queue = deque([(root, 1, 1)])
        
        while queue:
            node, parent_val, grandparent_val = queue.popleft()
            # 祖父为偶数时累加
            if grandparent_val % 2 == 0:
                total += node.val
            # 将子节点入队，更新父祖父信息
            if node.left:
                queue.append((node.left, node.val, parent_val))
            if node.right:
                queue.append((node.right, node.val, parent_val))
        
        return total
```

### 方法四：反向统计（从祖父节点遍历孙子）

```python
from typing import Optional

class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        
        def dfs(node) -> int:
            if not node:
                return 0
            total = 0
            # 当前节点值为偶数，统计孙子节点的值
            if node.val % 2 == 0:
                # 左子的左右孩子（左孙子）
                if node.left:
                    if node.left.left:
                        total += node.left.left.val
                    if node.left.right:
                        total += node.left.right.val
                # 右子的左右孩子（右孙子）
                if node.right:
                    if node.right.left:
                        total += node.right.left.val
                    if node.right.right:
                        total += node.right.right.val
            # 继续遍历整棵树
            return total + dfs(node.left) + dfs(node.right)
        
        return dfs(root)
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 为树的高度，递归栈深度；最坏 O(n)（链式树），平均 O(log n)

## 关键点总结

1. DFS 时额外传递父节点和祖父节点的值，是处理"祖先信息"问题的通用技巧
2. 根节点初始化时，父/祖父值用奇数（如 1）避免误判（若用 0 则根节点本身可能被错误累加）
3. 方法四（反向统计）逻辑更直观，但代码较冗长
4. BFS 与 DFS 对这道题都适用，选择更熟悉的即可

## 易错点

1. **初始化祖父值**：如果用 0 初始化祖父值，由于 0 是偶数，根节点会被错误地计入结果，应该用奇数初始化
2. **祖父不存在的情况**：根节点和根节点的子节点都没有祖父节点，不应该被统计
3. **方法四的层级**：祖父的孙子 = 儿子的儿子，要向下跳两层，别只跳一层
