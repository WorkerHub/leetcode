## 题目描述

给你一个大小为 `n × n` 的矩阵 `grid`，其中 `grid[i][j]` 为正整数或 -1（表示障碍物）。

单元格 `(i, j)` 的**远端距离**：如果从 `(i, j)` 出发（只能走非障碍物的上下左右相邻格），无法到达某些非障碍物格子，则远端距离 = 那些无法到达的非障碍物格子的值之和。

返回所有格子（非障碍物）的远端距离之和。

**示例 1：**
```
输入：grid = [[-1,1,-1],[5,-1,4],[-1,3,-1]]
输出：39
解释：
(0,1): 只能到达自身 {1}，无法到达 {5,4,3}，远端距离 = 5+4+3 = 12
(1,0): 只能到达自身 {5}，无法到达 {1,4,3}，远端距离 = 1+4+3 = 8
...
```

**提示：**
- `1 <= n <= 300`
- `grid[i][j]` 为 -1 或 1 到 10^6 的正整数

## 解题思路

每个非障碍物格子都属于某个**连通分量**。同一连通分量内的格子可以互相到达，所以它们的远端距离 = 总非障碍物格子之和 - 本连通分量之和。

**算法：**
1. 计算所有非障碍物格子的值之和 `total`
2. DFS/BFS 找到所有连通分量，计算每个分量的大小和值之和
3. 对每个分量，每个格子的远端距离 = `total - component_sum`
4. 总远端距离 = `sum(component_sum × (n² - comp_size) × ... )`

等等，更准确的：
- 若连通分量的值之和为 `cs`，格子数为 `sz`
- 每个格子的远端距离 = `total - cs`
- 该分量贡献 = `sz × (total - cs)`

## Python 代码实现

### 方法一：DFS 连通分量（推荐）

```python
from typing import List

class Solution:
    def sumRemoteness(self, grid: List[List[int]]) -> int:
        n = len(grid)
        total = sum(grid[i][j] for i in range(n) for j in range(n) if grid[i][j] != -1)

        visited = [[False] * n for _ in range(n)]
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        def bfs(sr: int, sc: int) -> tuple:
            """BFS 返回连通分量的格子数和值之和"""
            from collections import deque
            dq = deque([(sr, sc)])
            visited[sr][sc] = True
            comp_sum = grid[sr][sc]
            comp_size = 1
            while dq:
                r, c = dq.popleft()
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < n and 0 <= nc < n and not visited[nr][nc] and grid[nr][nc] != -1:
                        visited[nr][nc] = True
                        comp_sum += grid[nr][nc]
                        comp_size += 1
                        dq.append((nr, nc))
            return comp_sum, comp_size

        ans = 0
        for i in range(n):
            for j in range(n):
                if grid[i][j] != -1 and not visited[i][j]:
                    comp_sum, comp_size = bfs(i, j)
                    # 该分量中每个格子的远端距离 = total - comp_sum
                    ans += comp_size * (total - comp_sum)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，每个格子最多被访问一次
- 空间复杂度：O(n^2)，visited 数组和 BFS 队列

## 关键点总结

1. 同一连通分量内的格子互相可达，远端距离相同 = `total - comp_sum`
2. 整个分量的贡献 = `comp_size × (total - comp_sum)`
3. 先计算总值 total，再 BFS/DFS 找连通分量

## 易错点

1. 区分障碍物（-1）和非障碍物（正整数）
2. `total` 只统计非障碍物格子的值
3. 每个格子的远端距离是该连通分量**之外**的所有格子的值之和
