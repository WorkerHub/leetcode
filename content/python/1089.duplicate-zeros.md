## 题目描述

给定一个固定长度的整数数组 `arr`，请你将该数组中出现的每个零**复制一份**，并将原数组中的其余元素向右移动。

注意：不要在超过数组长度的位置写入元素。请在**原地**修改输入数组，不要从函数返回任何值。

**示例 1：**
```
输入：arr = [1,0,2,3,0,4,5,0]
输出：[1,0,0,2,3,0,0,4]
解释：调用函数后，输入数组被修改为 [1,0,0,2,3,0,0,4]
```

**示例 2：**
```
输入：arr = [1,2,3]
输出：[1,2,3]
解释：没有 0，数组保持不变
```

**提示：**
- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 9`

## 解题思路

这是一道**双指针 + 原地修改**问题。

### 核心思想

1. **问题挑战**：
   - 原地修改，空间复杂度 O(1)
   - 复制零会导致后面元素被覆盖
   - 需要从后往前处理

2. **两遍扫描法**：
   - **第一遍**：计算复制后的有效长度，确定最后一个要处理的元素
   - **第二遍**：从后往前，将元素复制到正确位置

3. **关键观察**：
   - 每个 0 会占用 2 个位置
   - 非零元素占用 1 个位置
   - 从右往左填充，避免覆盖未处理的元素

## Python 代码实现

### 方法一：两遍扫描（推荐）

```python
from typing import List

class Solution:
    def duplicateZeros(self, arr: List[int]) -> None:
        """
        Do not return anything, modify arr in-place instead.
        """
        n = len(arr)
        
        # 第一遍：计算需要处理的元素个数
        zeros = 0
        i = 0
        
        # 找到最后一个要处理的元素
        while i + zeros < n:
            if arr[i] == 0:
                zeros += 1
            i += 1
        
        # i 现在指向第一个不会被包含的元素
        i -= 1
        write = n - 1
        
        # 处理边界情况：最后一个元素是0且会被复制
        if i + zeros == n:
            arr[write] = 0
            write -= 1
            i -= 1
            zeros -= 1
        
        # 第二遍：从后往前填充
        while write >= 0:
            if arr[i] == 0:
                # 复制两个0
                arr[write] = 0
                write -= 1
                if write >= 0:
                    arr[write] = 0
                    write -= 1
            else:
                # 复制非零元素
                arr[write] = arr[i]
                write -= 1
            
            i -= 1
```

### 方法二：使用额外空间（易理解）

```python
from typing import List

class Solution:
    def duplicateZeros(self, arr: List[int]) -> None:
        """
        Do not return anything, modify arr in-place instead.
        """
        n = len(arr)
        # 创建临时数组
        temp = []
        
        for num in arr:
            temp.append(num)
            if num == 0:
                temp.append(0)
        
        # 将前 n 个元素复制回原数组
        for i in range(n):
            arr[i] = temp[i]
```

### 方法三：计数 + 从后填充（优化版）

```python
from typing import List

class Solution:
    def duplicateZeros(self, arr: List[int]) -> None:
        n = len(arr)
        # 计算0的数量
        zeros = arr.count(0)
        
        # 从后往前遍历
        i = n - 1
        write = n + zeros - 1
        
        while i >= 0 and write >= 0:
            # 如果写入位置在数组范围内
            if write < n:
                arr[write] = arr[i]
            
            # 如果当前元素是0，再写一次
            if arr[i] == 0:
                write -= 1
                if write < n:
                    arr[write] = 0
            
            i -= 1
            write -= 1
```

## 复杂度分析

**方法一（推荐）：**
- **时间复杂度**：O(n)
  - 两遍遍历，每遍 O(n)
- **空间复杂度**：O(1)
  - 原地修改

**方法二（额外空间）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)
  - 需要临时数组

**方法三：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 图解示例

以 `arr = [1,0,2,3,0,4,5,0]` 为例：

```
原数组：[1, 0, 2, 3, 0, 4, 5, 0]
索引：   0  1  2  3  4  5  6  7

第一遍：计算有效元素
- i=0: 1, zeros=0
- i=1: 0, zeros=1
- i=2: 2, zeros=1
- i=3: 3, zeros=1
- i=4: 0, zeros=2
- i=5: 4, zeros=2, i+zeros=7 < 8
- i=6: 5, zeros=2, i+zeros=8，停止
- 最后处理的元素是 i=5 (值=4)

第二遍：从后往前填充
write=7, i=5
- arr[5]=4 → arr[7]=4   [1,0,2,3,0,4,5,4]
- i=4, arr[4]=0 → arr[6]=0, arr[5]=0  [1,0,2,3,0,0,0,4]
- i=3, arr[3]=3 → arr[4]=3  [1,0,2,3,3,0,0,4]
- i=2, arr[2]=2 → arr[3]=2  [1,0,2,2,3,0,0,4]
- i=1, arr[1]=0 → arr[2]=0, arr[1]=0  [1,0,0,2,3,0,0,4]
- i=0, arr[0]=1 → arr[0]=1  [1,0,0,2,3,0,0,4]

结果：[1,0,0,2,3,0,0,4]
```

## 关键点总结

1. **从后往前**：避免覆盖未处理的元素
2. **两遍扫描**：第一遍确定范围，第二遍填充
3. **边界处理**：最后一个元素是 0 的特殊情况
4. **原地修改**：不使用额外数组，空间 O(1)
5. **写指针**：用 write 指针标记写入位置

## 易错点

1. **从前往后**：会覆盖未处理的元素
2. **边界情况**：最后一个元素是 0 且恰好被复制一半
3. **数组越界**：写指针可能超出数组范围，需要判断
4. **零的个数**：重复零会增加 zeros 计数
5. **指针初始化**：write 指针应该从 n-1 开始
