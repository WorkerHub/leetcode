## 题目描述

有一组物品，每个物品有一个值 `values[i]` 和一个标签 `labels[i]`。

同时给定两个整数 `numWanted` 和 `useLimit`。

你需要从这些物品中选择一个子集，使得：
- 子集中最多有 `numWanted` 个物品
- 每个标签最多使用 `useLimit` 次

返回子集的**最大值之和**。

**示例 1：**
```
输入：values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1
输出：9
解释：选择的子集是第一、第三、第五个物品（值分别为 5, 3, 1，标签为 1, 2, 3）
```

**示例 2：**
```
输入：values = [5,4,3,2,1], labels = [1,3,3,3,2], numWanted = 3, useLimit = 2
输出：12
解释：选择前三个物品（5, 4, 3），标签为 1, 3, 3，标签 3 使用了 2 次
```

**示例 3：**
```
输入：values = [9,8,8,7,6], labels = [0,0,0,1,1], numWanted = 3, useLimit = 1
输出：16
解释：选择第一、第二、第四个物品（9, 8, 7）
```

**提示：**
- `n == values.length == labels.length`
- `1 <= n <= 2 * 10^4`
- `0 <= values[i], labels[i] <= 2 * 10^4`
- `1 <= numWanted, useLimit <= n`

## 解题思路

这是一道**贪心 + 哈希表**问题。

### 核心思想

1. **贪心策略**：
   - 优先选择值最大的物品
   - 在满足标签限制的前提下，尽可能选择高价值物品

2. **约束条件**：
   - 最多选 `numWanted` 个物品
   - 每个标签最多使用 `useLimit` 次

3. **算法流程**：
   - 将物品按值降序排序
   - 从高到低遍历，尝试选择每个物品
   - 使用哈希表记录每个标签已使用次数
   - 如果当前物品的标签未超限且总数未达 `numWanted`，选择它

## Python 代码实现

### 方法一：贪心 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def largestValsFromLabels(self, values: List[int], labels: List[int], 
                               numWanted: int, useLimit: int) -> int:
        # 将值和标签配对，并按值降序排序
        items = sorted(zip(values, labels), key=lambda x: -x[0])
        
        # 记录每个标签已使用次数
        label_count = defaultdict(int)
        
        total_value = 0
        selected = 0
        
        for value, label in items:
            # 检查是否可以选择这个物品
            if label_count[label] < useLimit and selected < numWanted:
                total_value += value
                label_count[label] += 1
                selected += 1
                
                # 提前结束
                if selected == numWanted:
                    break
        
        return total_value
```

### 方法二：使用堆（优先队列）

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def largestValsFromLabels(self, values: List[int], labels: List[int], 
                               numWanted: int, useLimit: int) -> int:
        # 创建最大堆（使用负值）
        heap = [(-value, label) for value, label in zip(values, labels)]
        heapq.heapify(heap)
        
        label_count = defaultdict(int)
        total_value = 0
        selected = 0
        
        while heap and selected < numWanted:
            value, label = heapq.heappop(heap)
            value = -value  # 恢复正值
            
            if label_count[label] < useLimit:
                total_value += value
                label_count[label] += 1
                selected += 1
        
        return total_value
```

### 方法三：使用 Counter

```python
from typing import List
from collections import Counter

class Solution:
    def largestValsFromLabels(self, values: List[int], labels: List[int], 
                               numWanted: int, useLimit: int) -> int:
        # 配对并排序
        items = sorted(zip(values, labels), reverse=True)
        
        label_count = Counter()
        total_value = 0
        selected = 0
        
        for value, label in items:
            if label_count[label] < useLimit and selected < numWanted:
                total_value += value
                label_count[label] += 1
                selected += 1
        
        return total_value
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n log n)
  - 排序：O(n log n)
  - 遍历：O(n)
- **空间复杂度**：O(n)
  - items 数组：O(n)
  - 哈希表：O(k)，k 是不同标签数

## 图解示例

以 `values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1` 为例：

```
配对并排序：
[(5, 1), (4, 1), (3, 2), (2, 2), (1, 3)]

选择过程：
1. (5, 1): label_count[1]=0 < 1, selected=0 < 3
   选择，total=5, label_count[1]=1, selected=1

2. (4, 1): label_count[1]=1 >= 1
   跳过（标签1已用完）

3. (3, 2): label_count[2]=0 < 1, selected=1 < 3
   选择，total=8, label_count[2]=1, selected=2

4. (2, 2): label_count[2]=1 >= 1
   跳过（标签2已用完）

5. (1, 3): label_count[3]=0 < 1, selected=2 < 3
   选择，total=9, label_count[3]=1, selected=3

结果：9
```

## 关键点总结

1. **贪心正确性**：按值降序选择，在满足约束时总是最优
2. **排序技巧**：使用 `zip` 配对值和标签，一起排序
3. **哈希表计数**：记录每个标签的使用次数
4. **提前终止**：达到 `numWanted` 时可以立即返回
5. **负值堆**：Python heapq 是最小堆，用负值模拟最大堆

## 易错点

1. **排序方向**：应该降序（从大到小），而不是升序
2. **两个限制**：同时检查物品数和标签使用次数
3. **标签重复**：同一标签可能出现在多个物品上
4. **计数器初始化**：defaultdict 自动初始化为 0
5. **提前终止**：忘记在达到 numWanted 时 break
