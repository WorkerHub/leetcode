## 题目描述

给你两个字符串 `str1` 和 `str2`，返回同时以 `str1` 和 `str2` 作为子序列的最短字符串。如果答案不止一个，则可以返回满足条件的任意一个。

如果从字符串 `T` 中删除一些字符（也可能不删除），得到字符串 `S`，那么 `S` 就是 `T` 的子序列。

**示例 1：**

```
输入：str1 = "abac", str2 = "cab"
输出："cabac"
解释：
str1 = "abac" 是 "cabac" 的一个子串，因为我们可以删去 "cabac" 的第一个 "c"得到 "abac"。 
str2 = "cab" 是 "cabac" 的一个子串，因为我们可以删去 "cabac" 末尾的 "ac" 得到 "cab"。
最终我们返回的答案是满足上述属性的最短字符串。
```

**示例 2：**

```
输入：str1 = "aaaaaaaa", str2 = "aaaaaaaa"
输出："aaaaaaaa"
```

**提示：**

- `1 <= str1.length, str2.length <= 1000`
- `str1` 和 `str2` 都由小写英文字母组成

## 解题思路

这是一道经典的动态规划问题，与**最长公共子序列（LCS）**密切相关。

**核心思想：**
- 最短公共超序列 = str1 长度 + str2 长度 - 最长公共子序列长度
- 构造过程需要在找到 LCS 的基础上，交替插入两个字符串的非公共部分

**算法流程：**

1. **第一步：计算 LCS 的 DP 表**
   - `dp[i][j]` 表示 `str1[0:i]` 和 `str2[0:j]` 的最长公共子序列长度
   - 状态转移方程：
     - 如果 `str1[i-1] == str2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
     - 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

2. **第二步：从 DP 表回溯构造结果**
   - 从 `dp[m][n]` 开始（m、n 分别是两个字符串长度）
   - 如果 `str1[i-1] == str2[j-1]`：这是公共字符，加入结果，`i--`, `j--`
   - 如果 `dp[i][j] == dp[i-1][j]`：`str1[i-1]` 不在 LCS 中，加入结果，`i--`
   - 如果 `dp[i][j] == dp[i][j-1]`：`str2[j-1]` 不在 LCS 中，加入结果，`j--`
   - 最后把剩余的字符加入结果

**关键观察：**
- 公共字符只保留一份，非公共字符都要保留
- 回溯时要保持相对顺序，确保两个原字符串都是结果的子序列

## Python 代码实现

### 方法一：动态规划 + 回溯构造（推荐）

```python
class Solution:
    def shortestCommonSupersequence(self, str1: str, str2: str) -> str:
        """
        动态规划 + 回溯构造最短公共超序列
        时间复杂度：O(m * n)
        空间复杂度：O(m * n)
        """
        m, n = len(str1), len(str2)
        
        # 步骤1：构建LCS的DP表
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if str1[i - 1] == str2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        
        # 步骤2：从DP表回溯构造结果
        result = []
        i, j = m, n
        
        while i > 0 and j > 0:
            if str1[i - 1] == str2[j - 1]:
                # 公共字符，只加一次
                result.append(str1[i - 1])
                i -= 1
                j -= 1
            elif dp[i - 1][j] > dp[i][j - 1]:
                # str1[i-1] 不在LCS中
                result.append(str1[i - 1])
                i -= 1
            else:
                # str2[j-1] 不在LCS中
                result.append(str2[j - 1])
                j -= 1
        
        # 添加str1的剩余部分
        while i > 0:
            result.append(str1[i - 1])
            i -= 1
        
        # 添加str2的剩余部分
        while j > 0:
            result.append(str2[j - 1])
            j -= 1
        
        # 反转结果（因为是从后往前构造的）
        return ''.join(result[::-1])
```

### 方法二：记忆化递归

```python
from functools import lru_cache

class Solution:
    def shortestCommonSupersequence(self, str1: str, str2: str) -> str:
        """
        记忆化递归方法
        时间复杂度：O(m * n)
        空间复杂度：O(m * n)
        """
        @lru_cache(maxsize=None)
        def dp(i: int, j: int) -> str:
            """
            返回 str1[i:] 和 str2[j:] 的最短公共超序列
            """
            # 基础情况：一个字符串用完了
            if i == len(str1):
                return str2[j:]
            if j == len(str2):
                return str1[i:]
            
            # 如果当前字符相同
            if str1[i] == str2[j]:
                return str1[i] + dp(i + 1, j + 1)
            
            # 如果不同，尝试两种选择，取较短的
            choice1 = str1[i] + dp(i + 1, j)
            choice2 = str2[j] + dp(i, j + 1)
            
            return choice1 if len(choice1) <= len(choice2) else choice2
        
        return dp(0, 0)
```

class Solution:
    def shortestCommonSupersequence(self, str1: str, str2: str) -> str:
        """
        先用空间优化DP计算LCS长度，再构造结果
        """
        m, n = len(str1), len(str2)
        
        # 计算LCS长度（空间优化版本）
        def lcs_length() -> int:
            prev = [0] * (n + 1)
            
            for i in range(1, m + 1):
                curr = [0] * (n + 1)
                for j in range(1, n + 1):
                    if str1[i - 1] == str2[j - 1]:
                        curr[j] = prev[j - 1] + 1
                    else:
                        curr[j] = max(prev[j], curr[j - 1])
                prev = curr
            
            return prev[n]
        
        # 最短超序列长度 = m + n - LCS长度
        # 但我们需要完整DP表来构造，所以这个方法主要用于验证
        lcs_len = lcs_length()
        print(f"LCS长度: {lcs_len}, 超序列长度: {m + n - lcs_len}")

### 方法四：详细注释版

```python
class Solution:
    def shortestCommonSupersequence(self, str1: str, str2: str) -> str:
        """
        最短公共超序列详解
        
        关键思路：
        1. 利用LCS找到公共部分
        2. 公共字符只保留一次
        3. 非公共字符都要加入结果
        """
        m, n = len(str1), len(str2)
        
        # 构建DP表：dp[i][j] = str1[0:i]和str2[0:j]的LCS长度
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if str1[i - 1] == str2[j - 1]:
                    # 字符相同，LCS长度+1
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 字符不同，取较大的LCS长度
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        
        # 从DP表回溯构造最短超序列
        result = []
        i, j = m, n
        
        # 从后往前构造
        while i > 0 and j > 0:
            if str1[i - 1] == str2[j - 1]:
                # 情况1：当前字符相同（在LCS中）
                # 只添加一次这个字符
                result.append(str1[i - 1])
                i -= 1
                j -= 1
            elif dp[i - 1][j] > dp[i][j - 1]:
                # 情况2：str1[i-1]不在LCS中
                # LCS来自于上方（去掉str1[i-1]）
                result.append(str1[i - 1])
                i -= 1
            else:
                # 情况3：str2[j-1]不在LCS中
                # LCS来自于左方（去掉str2[j-1]）
                result.append(str2[j - 1])
                j -= 1
        
        # 处理剩余字符
        # 如果str1还有剩余
        while i > 0:
            result.append(str1[i - 1])
            i -= 1
        
        # 如果str2还有剩余
        while j > 0:
            result.append(str2[j - 1])
            j -= 1
        
        # 反转结果（因为是从后往前构造的）
        return ''.join(reversed(result))
```

## 复杂度分析

**方法一（动态规划 + 回溯）：**
- **时间复杂度**：O(m × n)，构建 DP 表需要 O(m × n)，回溯构造需要 O(m + n)
- **空间复杂度**：O(m × n)，DP 表的空间

**方法二（记忆化递归）：**
- **时间复杂度**：O(m × n)，每个状态计算一次
- **空间复杂度**：O(m × n)，递归栈和缓存空间，但结果字符串可能很长

## 图解示例

以示例 1 为例：`str1 = "abac"`, `str2 = "cab"`

**步骤 1：构建 DP 表（LCS 长度）**

```
    ""  c  a  b
""   0  0  0  0
a    0  0  1  1
b    0  0  1  2
a    0  0  1  2
c    0  1  1  2
```

LCS 长度 = 2（"ab" 或 "ca"）

**步骤 2：回溯构造**

```
从 dp[4][3] = 2 开始：
i=4, j=3: str1[3]='c', str2[2]='b' 不同
         dp[3][3]=2 > dp[4][2]=1，选择 str1[3]='c'
         result = ['c'], i=3

i=3, j=3: str1[2]='a', str2[2]='b' 不同
         dp[2][3]=2 > dp[3][2]=1，选择 str1[2]='a'
         result = ['c','a'], i=2

i=2, j=3: str1[1]='b', str2[2]='b' 相同
         result = ['c','a','b'], i=1, j=2

i=1, j=2: str1[0]='a', str2[1]='a' 相同
         result = ['c','a','b','a'], i=0, j=1

i=0, j=1: 添加 str2 剩余部分 'c'
         result = ['c','a','b','a','c']

反转：'cabac'
```

## 关键点总结

1. **LCS 是核心**：最短公共超序列长度 = len(str1) + len(str2) - len(LCS)
2. **回溯构造**：从 DP 表反向推导，决定每个字符的来源
3. **公共字符只保留一次**：当 `str1[i] == str2[j]` 时，只添加一次
4. **非公共字符都要保留**：确保两个字符串都是结果的子序列
5. **反转结果**：因为是从后往前构造的，最后需要反转

## 易错点

1. **DP 表索引问题**：`dp[i][j]` 对应 `str1[i-1]` 和 `str2[j-1]`，要小心偏移
2. **回溯时的选择**：当 `dp[i-1][j]` 和 `dp[i][j-1]` 相等时，选择哪个都行（但要保持一致性）
3. **忘记反转结果**：从后往前构造，最后必须反转
4. **剩余字符处理**：回溯结束后要检查是否有剩余字符
5. **字符相同时的处理**：只添加一次，同时 i 和 j 都要移动
6. **空字符串情况**：虽然题目保证长度 >= 1，但要注意边界
