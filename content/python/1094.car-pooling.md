## 题目描述

车上最初有 capacity 个空座位。车只能向一个方向行驶（不允许掉头或改变方向）

给定整数 capacity 和一个数组 trips，trips[i] = [numPassengers, from, to] 表示第 i 次行程有 numPassengers 个乘客，接他们的位置是 from，送他们的位置是 to。这些位置是从汽车的初始位置向东的距离。

当且仅当你可以在所有给定的行程中接送所有乘客时，返回 true，否则返回 false。

示例 1：

```
输入：trips = [[2,1,5],[3,3,7]], capacity = 4
输出：false
```

示例 2：

```
输入：trips = [[2,1,5],[3,3,7]], capacity = 5
输出：true
```

示例 3：

```
输入：trips = [[2,1,5],[3,5,7]], capacity = 3
输出：true
```

示例 4：

```
输入：trips = [[3,2,7],[3,7,9],[8,3,9]], capacity = 11
输出：true
```

提示：

- 1 <= trips.length <= 1000
- trips[i].length == 3
- 1 <= numPassengers <= 100
- 0 <= from < to <= 1000
- 1 <= capacity <= 10⁵

## 解题思路

这道题的核心是判断在所有行程中，车上的乘客数是否会超过容量限制。关键观察是：车辆只向东行驶，所以位置是单调递增的。

核心思想：
- 在每个位置，记录上车和下车的乘客数
- 按照位置顺序遍历，累计当前车上的人数
- 如果任何时刻车上人数超过 capacity，返回 false

常见解法：
1. 差分数组：在上车位置 +numPassengers，在下车位置 -numPassengers
2. 事件排序：将上车和下车作为事件排序处理
3. 堆/优先队列：动态维护当前在车上的行程

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        # 差分数组：记录每个位置的乘客变化量
        # 题目限制 to <= 1000，所以数组大小设为 1001
        diff = [0] * 1001
        
        # 构建差分数组
        for num_passengers, from_loc, to_loc in trips:
            # 在 from 位置上车，乘客数增加
            diff[from_loc] += num_passengers
            # 在 to 位置下车，乘客数减少
            diff[to_loc] -= num_passengers
        
        # 遍历差分数组，计算每个位置的实际乘客数
        current_passengers = 0
        for i in range(1001):
            current_passengers += diff[i]
            # 如果当前乘客数超过容量，返回 false
            if current_passengers > capacity:
                return False
        
        return True
```

### 方法二：事件排序

```python
from typing import List

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        # 创建事件列表：(位置, 乘客变化量)
        events = []
        for num_passengers, from_loc, to_loc in trips:
            # 上车事件：位置 from_loc，乘客增加
            events.append((from_loc, num_passengers))
            # 下车事件：位置 to_loc，乘客减少
            events.append((to_loc, -num_passengers))
        
        # 按位置排序
        # 关键：同一位置时，下车事件应该在上车事件之前处理
        # 因为题目中 from < to，所以下车位置的乘客不会立即上车
        events.sort(key=lambda x: (x[0], x[1]))
        
        # 遍历所有事件
        current_passengers = 0
        for location, change in events:
            current_passengers += change
            if current_passengers > capacity:
                return False
        
        return True
```

### 方法三：堆/优先队列

```python
from typing import List
import heapq

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        # 按照上车位置排序
        trips.sort(key=lambda x: x[1])
        
        # 最小堆：存储 (下车位置, 乘客数)
        min_heap = []
        current_passengers = 0
        
        for num_passengers, from_loc, to_loc in trips:
            # 处理所有在当前位置之前下车的乘客
            while min_heap and min_heap[0][0] <= from_loc:
                drop_location, passengers = heapq.heappop(min_heap)
                current_passengers -= passengers
            
            # 当前行程的乘客上车
            current_passengers += num_passengers
            if current_passengers > capacity:
                return False
            
            # 将当前行程加入堆（等待下车）
            heapq.heappush(min_heap, (to_loc, num_passengers))
        
        return True
```

### 方法四：优化的差分数组（空间优化）

```python
from typing import List

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        # 找到最远的位置，避免创建过大的数组
        max_location = max(to_loc for _, _, to_loc in trips)
        
        # 差分数组
        diff = [0] * (max_location + 1)
        
        # 构建差分数组
        for num_passengers, from_loc, to_loc in trips:
            diff[from_loc] += num_passengers
            diff[to_loc] -= num_passengers
        
        # 计算前缀和并检查容量
        current_passengers = 0
        for change in diff:
            current_passengers += change
            if current_passengers > capacity:
                return False
        
        return True
```

### 方法五：简化版（使用字典）

```python
from typing import List

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        # 使用字典存储每个位置的乘客变化
        passenger_changes = {}
        
        for num_passengers, from_loc, to_loc in trips:
            passenger_changes[from_loc] = passenger_changes.get(from_loc, 0) + num_passengers
            passenger_changes[to_loc] = passenger_changes.get(to_loc, 0) - num_passengers
        
        # 按位置排序处理
        current_passengers = 0
        for location in sorted(passenger_changes.keys()):
            current_passengers += passenger_changes[location]
            if current_passengers > capacity:
                return False
        
        return True
```

## 复杂度分析

### 方法一：差分数组

- 时间复杂度：O(n + m)，其中 n 是 trips 的长度，m 是最大位置（1000）。需要遍历所有行程构建差分数组，然后遍历差分数组。
- 空间复杂度：O(m)，需要一个长度为 1001 的差分数组。

### 方法二：事件排序

- 时间复杂度：O(n log n)，其中 n 是 trips 的长度。需要创建 2n 个事件并排序。
- 空间复杂度：O(n)，需要存储所有事件。

### 方法三：堆/优先队列

- 时间复杂度：O(n log n)，排序需要 O(n log n)，堆操作最多 O(n log n)。
- 空间复杂度：O(n)，堆中最多存储 n 个行程。

### 方法四：优化的差分数组

- 时间复杂度：O(n + m)，其中 m 是实际的最大位置。
- 空间复杂度：O(m)，动态分配数组大小。

### 方法五：字典

- 时间复杂度：O(n log k)，其中 k 是不同的位置数量（最多 2n）。
- 空间复杂度：O(k)。

## 关键点总结

1. 差分数组思想：在起点 +x，在终点 -x，前缀和即为每个位置的实际值
2. 下车位置不算在车上：乘客在 to 位置已经下车，所以在 to 位置减去人数
3. 选择合适的方法：
   - 位置范围小 → 差分数组（空间换时间）
   - 行程数量少 → 事件排序或堆
4. 注意排序的稳定性：同一位置时，下车应该在上车之前处理
5. 车辆单向行驶：位置是单调递增的，简化了问题

## 易错点

1. 差分数组边界
   - 题目说 to <= 1000，所以数组大小至少要 1001
   - 下车位置要减去乘客数，不是加

2. 事件排序的顺序
   - 同一位置时，下车事件应该先于上车事件
   - 使用 key=lambda x: (x[0], x[1]) 可以正确处理（负数在前）

3. 堆的使用
   - 堆中存储的是 (下车位置, 乘客数)
   - 要在处理新上车乘客前，先处理所有已下车的乘客

4. 容量判断时机
   - 应该在所有乘客变化后再判断
   - 不要在下车前判断（下车会减少人数）
