## 题目描述

给你一个 `n` 个服务器的网络，服务器编号从 0 到 `n-1`，主服务器是 0 号。

网络由数组 `edges` 给出（无向边），每条边权重为 1。

数组 `patience` 中，`patience[i]` 是数据服务器 `i`（`i >= 1`）的**耐心值**。

工作过程：
- 每秒，每个数据服务器向主服务器发送一条信息
- 如果数据服务器在 `patience[i]` 秒内没有收到回复，就**重新发送**
- 回复沿最短路径返回

求**网络恢复空闲**（所有服务器收到回复且没有新信息在传输）的**最早时刻**。

**示例：**
```
输入：edges = [[0,1],[1,2]], patience = [0,2,1]
输出：8
```

**提示：**
- `n == patience.length`
- `2 <= n <= 10^5`
- `1 <= edges.length <= min(10^5, n*(n-1)/2)`
- `0 <= patience[i] <= 10^5`

## 解题思路

**BFS 求最短距离：** 从 0 号服务器出发，BFS 求到每个节点的最短路径距离 `dist[i]`。

**计算每个服务器最后一条信息的回复时刻：**
- 每条信息的往返时间为 `2 * dist[i]`
- 服务器 `i` 会在第 `0, patience[i], 2*patience[i], ...` 秒发送信息
- 最后一次发送的时刻是 `t_last = ((2*dist[i] - 1) // patience[i]) * patience[i]`
- 最后一次发送的信息到达时刻：`t_last + 2*dist[i]`
- 该服务器最后回复到达时刻即为 `t_last + 2*dist[i]`

**答案** = `max(t_last + 2*dist[i] for i in 1..n-1) + 1`（再过1秒后网络空闲）

## 代码实现

### 方法一：BFS + 数学计算（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def networkBecomesIdle(self, edges: List[List[int]], patience: List[int]) -> int:
        n = len(patience)
        # 构建邻接表
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS 求从 0 到每个节点的最短距离
        dist = [-1] * n
        dist[0] = 0
        queue = deque([0])
        while queue:
            node = queue.popleft()
            for nei in graph[node]:
                if dist[nei] == -1:
                    dist[nei] = dist[node] + 1
                    queue.append(nei)

        ans = 0
        for i in range(1, n):
            d = dist[i]
            p = patience[i]
            round_trip = 2 * d  # 往返时间

            # 最后一次重发时刻：< round_trip 的最大 k*p 值
            # k_max = (round_trip - 1) // p
            last_send = ((round_trip - 1) // p) * p
            last_arrival = last_send + round_trip

            ans = max(ans, last_arrival)

        return ans + 1  # 最后一个信息到达后的下一秒
```

### 方法二：模拟（理解用）

```python
from typing import List
from collections import deque

class Solution:
    def networkBecomesIdle(self, edges: List[List[int]], patience: List[int]) -> int:
        n = len(patience)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        dist = [-1] * n
        dist[0] = 0
        q = deque([0])
        while q:
            node = q.popleft()
            for nb in graph[node]:
                if dist[nb] == -1:
                    dist[nb] = dist[node] + 1
                    q.append(nb)

        ans = 0
        for i in range(1, n):
            rtt = 2 * dist[i]        # 往返时间
            p = patience[i]
            # 服务器在 0, p, 2p, ... 发送信息
            # 最后一次发送（发送时刻 < rtt）
            last = (rtt - 1) // p * p
            ans = max(ans, last + rtt + 1)  # last 发送 + rtt 到达 + 1（下一秒）

        return ans
```

## 复杂度分析

- 时间复杂度：O(V + E)，BFS 遍历图
- 空间复杂度：O(V + E)，邻接表

## 关键点总结

1. BFS 求最短距离（无权图）
2. 计算每个服务器最后一次**重新发送**的时刻：`((2d-1) // p) * p`
3. 最后一条信息到达时刻 + 1 = 该服务器的贡献值
4. 答案取所有服务器贡献值的最大值

## 易错点

- 最后一次发送条件：发送时刻**严格小于**往返时间（发出去之前还没收到回复）
- 公式 `(rtt - 1) // p * p` 计算最后一次重发时刻
- 答案是 `last_arrival + 1`（+1 因为 last_arrival 时刻信息到达，下一秒才空闲）
