## 题目描述

设计一个支持以下操作的数据结构：
- `add(number)`：向数据结构中添加一个数字
- `deleteOne(number)`：删除一个数字（若存在）
- `hasFrequency(frequency)`：检查是否有数字恰好出现 `frequency` 次

**示例：**
```
add(3), add(3), hasFrequency(2) -> true
add(3), hasFrequency(3) -> true
deleteOne(3), hasFrequency(3) -> false
```

**数据范围：**
- 1 <= number <= 10^5
- 1 <= frequency <= 10^5

## 解题思路

维护两个哈希表：
- `count[x]`：数字 x 的出现次数
- `freq_count[f]`：恰好出现 f 次的数字个数

每次 add/delete 操作同时更新两个哈希表。

## Python 代码实现

### 方法一：双哈希表（推荐）

```python
from collections import defaultdict

class FrequencyTracker:
    def __init__(self):
        self.count = defaultdict(int)       # number -> 出现次数
        self.freq_count = defaultdict(int)  # 频率 -> 有多少个数字有此频率

    def add(self, number: int) -> None:
        old_freq = self.count[number]
        # 更新旧频率的统计
        if old_freq > 0:
            self.freq_count[old_freq] -= 1
        # 更新计数
        self.count[number] += 1
        new_freq = self.count[number]
        self.freq_count[new_freq] += 1

    def deleteOne(self, number: int) -> None:
        if self.count[number] == 0:
            return
        old_freq = self.count[number]
        self.freq_count[old_freq] -= 1
        self.count[number] -= 1
        new_freq = self.count[number]
        if new_freq > 0:
            self.freq_count[new_freq] += 1

    def hasFrequency(self, frequency: int) -> bool:
        return self.freq_count[frequency] > 0
```

## 复杂度分析

- 时间复杂度：add/delete/hasFrequency 均 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 双哈希表保持同步：`count` 记录每个数的频率，`freq_count` 记录有多少数有某个频率
2. 每次操作先更新旧频率统计，再更新新频率统计

## 易错点

1. `deleteOne` 时如果数字不存在，不做任何操作
2. 频率减为 0 时不能在 `freq_count` 中保留（虽然不影响正确性，但要清零旧频率）
3. 初始 `count[x] = 0` 时不应更新 `freq_count[0]`
