## 题目描述

给定一个正整数，检查它的二进制表示是否总是 0、1 交替出现。

**示例 1：**
```
输入：n = 5
输出：true
解释：5 的二进制表示是：101
```

**示例 2：**
```
输入：n = 7
输出：false
解释：7 的二进制表示是：111
```

## Python 代码实现

### 方法一：位运算

```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        # n ^ (n >> 1) 会将所有位变为 1（如果是交替的）
        # 例如：101 ^ 10 = 111
        xor = n ^ (n >> 1)
        
        # 检查 xor 是否所有位都是 1
        # 如果是，xor & (xor + 1) 应该为 0
        return (xor & (xor + 1)) == 0
```

### 方法二：逐位检查

```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        prev_bit = n & 1
        n >>= 1
        
        while n:
            curr_bit = n & 1
            if curr_bit == prev_bit:
                return False
            prev_bit = curr_bit
            n >>= 1
        
        return True
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)
