## 题目描述

设计一个支持下述操作的**食物评分系统**：

- `FoodRatings(foods, cuisines, ratings)`：初始化系统，`foods[i]`、`cuisines[i]`、`ratings[i]` 分别表示第 `i` 种食物的名字、烹饪方式和评分。
- `void changeRating(food, newRating)`：更新食物 `food` 的评分为 `newRating`。
- `String highestRated(cuisine)`：返回指定烹饪方式中评分最高的食物名称（若有相同评分，返回字典序最小的）。

**提示：**
- `1 <= n <= 2 * 10^4`
- 最多调用 `changeRating` 和 `highestRated` 各 `2 * 10^4` 次

## 解题思路

维护：
1. `food_info`：`food -> (cuisine, rating)`，快速查找食物信息。
2. `cuisine_foods`：`cuisine -> SortedList[(-rating, food)]`，按评分降序、字典序升序维护有序集合（用负评分表示降序）。

`changeRating`：从集合中删除旧记录，插入新记录。
`highestRated`：返回集合第一个元素的食物名。

## 代码实现

### 方法一：哈希表 + SortedList（推荐）

```python
from typing import List
from collections import defaultdict
from sortedcontainers import SortedList

class FoodRatings:
    def __init__(self, foods: List[str], cuisines: List[str], ratings: List[int]):
        self.food_info = {}  # food -> (cuisine, rating)
        self.cuisine_foods = defaultdict(SortedList)  # cuisine -> SortedList[(-rating, food)]
        
        for food, cuisine, rating in zip(foods, cuisines, ratings):
            self.food_info[food] = (cuisine, rating)
            self.cuisine_foods[cuisine].add((-rating, food))

    def changeRating(self, food: str, newRating: int) -> None:
        cuisine, old_rating = self.food_info[food]
        # 删除旧记录
        self.cuisine_foods[cuisine].remove((-old_rating, food))
        # 插入新记录
        self.food_info[food] = (cuisine, newRating)
        self.cuisine_foods[cuisine].add((-newRating, food))

    def highestRated(self, cuisine: str) -> str:
        # 第一个元素：最高评分（负值最小 -> 评分最大），字典序最小
        return self.cuisine_foods[cuisine][0][1]
```

### 方法二：懒删除堆

```python
from typing import List
from collections import defaultdict
import heapq

class FoodRatings:
    def __init__(self, foods: List[str], cuisines: List[str], ratings: List[int]):
        self.food_info = {}  # food -> (cuisine, rating)
        self.cuisine_heap = defaultdict(list)  # cuisine -> heap[(-rating, food)]
        
        for food, cuisine, rating in zip(foods, cuisines, ratings):
            self.food_info[food] = (cuisine, rating)
            heapq.heappush(self.cuisine_heap[cuisine], (-rating, food))

    def changeRating(self, food: str, newRating: int) -> None:
        cuisine, _ = self.food_info[food]
        self.food_info[food] = (cuisine, newRating)
        heapq.heappush(self.cuisine_heap[cuisine], (-newRating, food))
        # 旧记录不删除（懒删除）

    def highestRated(self, cuisine: str) -> str:
        heap = self.cuisine_heap[cuisine]
        # 弹出过期记录
        while True:
            neg_rating, food = heap[0]
            _, cur_rating = self.food_info[food]
            if -neg_rating == cur_rating:
                return food
            heapq.heappop(heap)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| SortedList | changeRating O(log n)，highestRated O(1) | O(n) |
| 懒删除堆 | changeRating O(log n)，highestRated 均摊 O(log n) | O(n) |

## 关键点总结

1. 用 `(-rating, food)` 作为排序键，负评分使高评分排前面，字典序自然升序。
2. SortedList 支持高效的有序插入、删除和随机访问。
3. 懒删除堆中，查询时跳过过期记录。

## 易错点

- SortedList 中同一食物的旧记录必须显式删除（不是懒删除）。
- 懒删除堆中，判断堆顶是否过期：`当前评分 != 堆中记录的评分`。
