## 题目描述

给你两个字符串 `word1` 和 `word2`，长度均为 `n`，如果两个字符串中每种字母出现频率之差的**绝对值**都不超过 3，则称这两个字符串**几乎等价**。

返回 `true` 或 `false`。

**示例 1：**
```
输入：word1 = "aaaa", word2 = "bccb"
输出：false
解释：a 在 word1 中出现 4 次，在 word2 中出现 0 次，差为 4 > 3
```

**示例 2：**
```
输入：word1 = "abcdeef", word2 = "abaaacc"
输出：true
```

**提示：**
- `n == word1.length == word2.length`
- `1 <= n <= 100`
- `word1` 和 `word2` 只含小写字母

## 解题思路

统计两个字符串中每种字母的出现次数，检查差值绝对值是否都 <= 3。

## 代码实现

### 方法一：Counter 差值（推荐）

```python
from collections import Counter

class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        c1 = Counter(word1)
        c2 = Counter(word2)

        # 检查所有字母的频率差
        for c in 'abcdefghijklmnopqrstuvwxyz':
            if abs(c1[c] - c2[c]) > 3:
                return False
        return True
```

### 方法二：差值统计

```python
from collections import defaultdict

class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        diff = defaultdict(int)
        for c in word1:
            diff[c] += 1
        for c in word2:
            diff[c] -= 1

        return all(abs(v) <= 3 for v in diff.values())
```

### 方法三：数组计数

```python
class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        freq = [0] * 26

        for c in word1:
            freq[ord(c) - ord('a')] += 1
        for c in word2:
            freq[ord(c) - ord('a')] -= 1

        return all(abs(f) <= 3 for f in freq)
```

## 复杂度分析

- 时间复杂度：O(n + 26)，线性
- 空间复杂度：O(26)，常数

## 关键点总结

1. 统计两字符串各字母频次差
2. 所有 26 个字母的差的绝对值都不超过 3
3. 未出现的字母频次为 0（`Counter` 默认返回 0）

## 易错点

- 需要遍历所有 26 个字母（不仅仅是出现过的字母）
- `Counter` 访问不存在的键返回 0，不会报 KeyError
