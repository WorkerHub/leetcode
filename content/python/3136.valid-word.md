## 题目描述

给你一个字符串 `word`。

如果 `word` 满足以下所有条件，则认为 `word` 是有效的：
- 长度至少为 3
- 只包含数字 (0-9) 和英文字母 (大小写)
- 至少包含一个元音字母 (`a, e, i, o, u`，大小写均可)
- 至少包含一个辅音字母

返回 `word` 是否有效。

**示例 1：**
```
输入：word = "234Adas"
输出：true
```

**示例 2：**
```
输入：word = "b3"
输出：false（长度不足 3）
```

**示例 3：**
```
输入：word = "a3$e"
输出：false（包含 '$'）
```

**提示：**
- `1 <= word.length <= 20`
- `word` 只包含英文字母、数字、特殊符号

## 解题思路

按照四个条件逐一检验：
1. 长度 >= 3
2. 所有字符为字母或数字
3. 至少一个元音字母
4. 至少一个辅音字母（字母中非元音的）

## Python 代码实现

### 方法一：逐条判断（推荐）

```python
class Solution:
    def isValid(self, word: str) -> bool:
        if len(word) < 3:
            return False

        vowels = set('aeiouAEIOU')
        has_vowel = False
        has_consonant = False

        for c in word:
            if not c.isalnum():
                return False  # 包含非字母非数字字符
            if c.isalpha():
                if c in vowels:
                    has_vowel = True
                else:
                    has_consonant = True

        return has_vowel and has_consonant
```

### 方法二：使用 any

```python
class Solution:
    def isValid(self, word: str) -> bool:
        if len(word) < 3:
            return False
        if not all(c.isalnum() for c in word):
            return False
        vowels = set('aeiouAEIOU')
        letters = [c for c in word if c.isalpha()]
        has_vowel = any(c in vowels for c in letters)
        has_consonant = any(c not in vowels for c in letters)
        return has_vowel and has_consonant
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 四个条件缺一不可
2. 辅音 = 字母中的非元音
3. 数字既不是元音也不是辅音

## 易错点

1. 数字不算辅音，只有字母才区分元音/辅音
2. 元音大小写都要考虑
