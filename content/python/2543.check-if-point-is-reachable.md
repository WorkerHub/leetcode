## 题目描述

给你一个整数 `targetX` 和 `targetY`，表示目标点坐标 `(targetX, targetY)`。

起始点为 `(1, 1)`，每次可以进行以下操作之一：
- `(x, y) → (x + y, y)`
- `(x, y) → (x, x + y)`

判断能否通过若干次操作从 `(1, 1)` 到达 `(targetX, targetY)`。

**示例 1：**

```
输入：targetX = 6, targetY = 9
输出：false
```

**示例 2：**

```
输入：targetX = 4, targetY = 7
输出：true
解释：(1,1)→(1,2)→(1,3)→(4,3)→(4,7)
```

**提示：**

- `1 <= targetX, targetY <= 10^9`

## 解题思路

**逆向思维**：从 `(targetX, targetY)` 反向操作到 `(1, 1)`。

逆操作：
- 若 x > y：`(x, y) → (x - y, y)`
- 若 y > x：`(x, y) → (x, y - x)`
- 若 x == y：只有 `(1, 1)` 合法

这本质上是辗转相减法（类似 GCD），效率上可以用取模加速：若 x > y，一次减法会得到 `(x % y, y)`（若 x % y == 0 则需特别处理）。

关键结论：`(targetX, targetY)` 可达当且仅当 `gcd(targetX, targetY)` 是 2 的幂次方（包括 2^0 = 1）。

## Python 代码实现

### 方法一：GCD 判断（推荐）

```python
import math

class Solution:
    def isReachable(self, targetX: int, targetY: int) -> bool:
        # 关键结论：可达当且仅当 gcd(targetX, targetY) 是 2 的幂
        g = math.gcd(targetX, targetY)
        # 检查 g 是否是 2 的幂：g > 0 且 g & (g-1) == 0
        return g & (g - 1) == 0
```

### 方法二：逆向模拟

```python
import math

class Solution:
    def isReachable(self, targetX: int, targetY: int) -> bool:
        x, y = targetX, targetY
        # 逆向操作：辗转相减，加速用取模
        while x != y:
            if x > y:
                if y == 0:
                    return False
                x %= y
                if x == 0:
                    # x 变成 0，只有 y 是 2 的幂时才能到达 (1,y)
                    return y & (y - 1) == 0
            else:
                if x == 0:
                    return False
                y %= x
                if y == 0:
                    return x & (x - 1) == 0

        # x == y：只有 (1,1) 合法，即 gcd 是 1（2 的 0 次方）
        return x == y and (x & (x-1)) == 0
```

## 复杂度分析

- 方法一时间复杂度：O(log(min(targetX, targetY)))，GCD 计算
- 方法二时间复杂度：O(log(max(targetX, targetY)))，辗转相除
- 空间复杂度：O(1)

## 关键点总结

1. 逆向操作等价于辗转相减法，本质是求 GCD
2. 关键结论：gcd(targetX, targetY) 必须是 2 的幂次方
3. 检验 n 是 2 的幂：`n > 0 and (n & (n-1)) == 0`

## 易错点

1. 起始点是 (1,1) 不是 (0,0)，逆向时不能减到 0（除非终止）
2. gcd = 1 也是合法的（2^0 = 1）
3. 模运算加速时要注意余数为 0 的边界情况
