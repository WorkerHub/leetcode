## 题目描述

句子是一个由空格分隔的单词序列，且没有前导或尾随空格，单词间只有一个空格。

给你一个句子 `s` 和一个整数 `k`，返回 `s` 的前 `k` 个单词组成的字符串。

**示例 1：**
```
输入：s = "Hello how are you Contestant", k = 4
输出："Hello how are you"
```

**示例 2：**
```
输入：s = "What is the solution to this problem", k = 4
输出："What is the"
```

**提示：**
- `1 <= s.length <= 500`
- `s` 只包含小写和大写英文字母以及空格
- `k` 满足 `1 <= k <= 单词数`

## 解题思路

直接将字符串按空格分割，取前 k 个单词，再用空格拼接即可。

或者手动扫描字符串，找到第 k 个单词结束的位置，截取子字符串。

## 代码实现

### 方法一：split + join（推荐）

```python
class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        # 分割后取前 k 个单词，再拼接
        return ' '.join(s.split()[:k])
```

### 方法二：手动扫描找第 k 个空格

```python
class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        count = 0
        for i, ch in enumerate(s):
            if ch == ' ':
                count += 1
                if count == k:
                    return s[:i]  # 返回第 k 个空格前的子字符串
        return s  # 不足 k 个空格，说明 k == 单词数，返回整个句子
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为字符串长度
- **空间复杂度**：O(n)，存储分割后的单词列表

## 关键点总结

1. Python 的 `split()` 不传参数会按任意空白字符分割，并自动去除多余空格
2. 方法二在遇到第 k 个空格时立即返回，不需要分割整个字符串

## 易错点

- 若 k 等于总单词数，不会有第 k 个空格，需要在循环结束后返回整个字符串
