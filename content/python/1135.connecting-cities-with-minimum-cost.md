## 题目描述

想象一下你是个城市基建规划者，地图上有 `n` 座城市，它们按从 `1` 到 `n` 编号。

给你整数 `n` 和一个数组 `connections`，其中 `connections[i] = [xi, yi, costi]` 表示将城市 `xi` 和城市 `yi` 连接所要的成本。返回连接所有城市的最低成本，每对城市之间至少有一条路径。如果无法连接所有城市，返回 `-1`。

该**最小成本**应该是所用全部连接成本的总和。

**示例 1：**
```
输入：n = 3, connections = [[1,2,5],[1,3,6],[2,3,1]]
输出：6
解释：选择任何 2 条边都可以连接所有城市，我们选择成本最小的 2 条。
```

**示例 2：**
```
输入：n = 4, connections = [[1,2,3],[3,4,4]]
输出：-1
解释：无法连接所有城市，因为城市 2 和城市 4 没有路径。
```

**提示：**
- `1 <= n <= 10^4`
- `1 <= connections.length <= 10^4`
- `connections[i].length == 3`
- `1 <= xi, yi <= n`
- `xi != yi`
- `0 <= costi <= 10^5`

## 解题思路

这是一道经典的**最小生成树（Minimum Spanning Tree, MST）**问题。

### 核心概念

- **生成树**：连接图中所有顶点的树（n 个顶点，n-1 条边，无环）
- **最小生成树**：权重和最小的生成树

### 两种经典算法

1. **Kruskal 算法**：边的角度，按边权排序，使用并查集
2. **Prim 算法**：点的角度，从一个点开始扩展，使用堆优化

## Python 代码实现

### 方法一：Kruskal 算法 + 并查集（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = n  # 连通分量数量
    
    def find(self, x: int) -> int:
        """查找根节点（路径压缩）"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        """合并两个集合（按秩合并）"""
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return False  # 已经在同一集合
        
        # 按秩合并
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
        
        self.count -= 1
        return True

class Solution:
    def minimumCost(self, n: int, connections: List[List[int]]) -> int:
        # Kruskal 算法
        # 1. 按边权排序
        connections.sort(key=lambda x: x[2])
        
        # 2. 初始化并查集
        uf = UnionFind(n)
        
        # 3. 遍历边，选择不形成环的最小边
        total_cost = 0
        edges_used = 0
        
        for x, y, cost in connections:
            # 注意：城市编号从 1 开始，并查集索引从 0 开始
            if uf.union(x - 1, y - 1):
                total_cost += cost
                edges_used += 1
                
                # 生成树有 n-1 条边
                if edges_used == n - 1:
                    return total_cost
        
        # 如果无法形成生成树
        return -1 if edges_used < n - 1 else total_cost
```

### 方法二：Prim 算法（堆优化）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, connections: List[List[int]]) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for x, y, cost in connections:
            graph[x].append((y, cost))
            graph[y].append((x, cost))
        
        # Prim 算法
        visited = set()
        min_heap = [(0, 1)]  # (cost, node)，从节点 1 开始
        total_cost = 0
        
        while min_heap and len(visited) < n:
            cost, node = heapq.heappop(min_heap)
            
            if node in visited:
                continue
            
            visited.add(node)
            total_cost += cost
            
            # 将邻居加入堆
            for neighbor, edge_cost in graph[node]:
                if neighbor not in visited:
                    heapq.heappush(min_heap, (edge_cost, neighbor))
        
        # 检查是否所有节点都被访问
        return total_cost if len(visited) == n else -1
```

### 方法三：简化的并查集实现

```python
from typing import List

class Solution:
    def minimumCost(self, n: int, connections: List[List[int]]) -> int:
        # 简化的并查集
        parent = list(range(n + 1))  # 索引 1 到 n
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False
            parent[root_x] = root_y
            return True
        
        # 按成本排序
        connections.sort(key=lambda x: x[2])
        
        total_cost = 0
        edges = 0
        
        for x, y, cost in connections:
            if union(x, y):
                total_cost += cost
                edges += 1
                if edges == n - 1:
                    return total_cost
        
        return -1
```

## 复杂度分析

### Kruskal 算法

- **时间复杂度**：O(E log E)，主要是排序的时间，E 是边数
- **空间复杂度**：O(n)，并查集的空间

### Prim 算法

- **时间复杂度**：O(E log n)，堆操作的时间
- **空间复杂度**：O(n + E)，邻接表和堆的空间

## 关键点总结

1. **最小生成树的性质**：
   - n 个节点，n-1 条边
   - 无环
   - 连通所有节点
   - 边权和最小
2. **Kruskal 算法流程**：
   - 按边权排序
   - 贪心选择最小边，使用并查集判断是否形成环
   - 选够 n-1 条边即可
3. **并查集作用**：高效判断两个节点是否连通，O(α(n)) ≈ O(1)
4. **路径压缩**：`find` 函数中将路径上的所有节点直接连到根
5. **按秩合并**：将矮树连到高树，保持树的平衡

## 易错点

1. **城市编号**：题目中城市编号从 1 开始，需要转换为 0 开始（或并查集大小为 n+1）
2. **边数判断**：生成树需要 n-1 条边，如果无法选够则返回 -1
3. **并查集初始化**：初始化大小应该是 n（或 n+1，取决于索引方式）
4. **连通性检查**：最后需要检查是否所有节点都连通
5. **排序稳定性**：按成本排序，相同成本的边顺序不影响结果

## 图解示例

对于 `n = 3, connections = [[1,2,5],[1,3,6],[2,3,1]]`：

```
排序后：[[2,3,1], [1,2,5], [1,3,6]]

步骤1：选择 [2,3,1]
  - union(2, 3) → 成功
  - cost = 1, edges = 1

步骤2：选择 [1,2,5]
  - union(1, 2) → 成功（连接了 1 和 {2,3}）
  - cost = 1 + 5 = 6, edges = 2

已有 2 条边（n-1 = 2），返回 6
```
