## 题目描述

给你一个 `n` 个节点的**有向图**（每个节点最多有一条出边），节点从 `0` 到 `n-1` 编号。`edges[i]` 表示节点 `i` 的出边指向 `edges[i]`（`-1` 表示无出边）。

返回图中**最长**环的长度，若不存在环则返回 `-1`。

**示例 1：**
```
输入：edges = [3,3,4,2,3]
输出：3
解释：存在环 2->4->3->2，长度为 3。
```

**提示：**
- `n == edges.length`
- `2 <= n <= 10^5`
- `-1 <= edges[i] < n`
- `edges[i] != i`

## 解题思路

**DFS + 时间戳（方法一）：**
对每个节点进行 DFS，记录进入时间。遇到已访问且在当前路径上的节点时，计算环长度。

**拓扑排序（方法二）：**
删除所有出度/入度为 0 的节点（无法在环中），剩余节点即构成环。找最大的连通分量。

## 代码实现

### 方法一：DFS + 时间戳（推荐）

```python
from typing import List

class Solution:
    def longestCycle(self, edges: List[int]) -> int:
        n = len(edges)
        visited = [0] * n  # 0: 未访问, 正数: 访问时间戳
        ans = -1
        timer = [1]

        for start in range(n):
            if visited[start] != 0:
                continue
            # 开始 DFS
            cur = start
            while cur != -1 and visited[cur] == 0:
                visited[cur] = timer[0]
                timer[0] += 1
                cur = edges[cur]
            
            if cur != -1 and visited[cur] >= visited[start]:
                # 找到环，环长度 = 当前时间戳 - visited[cur]
                cycle_len = timer[0] - visited[cur]
                ans = max(ans, cycle_len)
        
        return ans
```

### 方法二：拓扑排序（Kahn 算法）

```python
from typing import List
from collections import deque

class Solution:
    def longestCycle(self, edges: List[int]) -> int:
        n = len(edges)
        in_degree = [0] * n
        
        for u in range(n):
            if edges[u] != -1:
                in_degree[edges[u]] += 1
        
        # 将所有入度为 0 的节点加入队列（不在环中）
        q = deque(i for i in range(n) if in_degree[i] == 0)
        removed = [False] * n
        
        while q:
            u = q.popleft()
            removed[u] = True
            v = edges[u]
            if v != -1:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    q.append(v)
        
        # 剩余未被删除的节点构成环
        ans = -1
        for i in range(n):
            if not removed[i]:
                # 沿环遍历计算长度
                length = 0
                cur = i
                while not removed[cur]:
                    removed[cur] = True
                    length += 1
                    cur = edges[cur]
                ans = max(ans, length)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS + 时间戳 | O(n) | O(n) |
| 拓扑排序 | O(n) | O(n) |

## 关键点总结

1. 每个节点最多一条出边，图结构为"rho"形（一条链进入一个环）。
2. DFS 时间戳法：遇到当前路径上已访问的节点，计算环长。
3. 拓扑排序法：反复删除非环节点，剩余节点属于环。

## 易错点

- DFS 时间戳法中，回到的节点必须是**当前路径上**的节点（时间戳 >= 起点的时间戳）。
- 时间戳方法中，必须确保 `visited[cur] >= visited[start]`，避免将前一次 DFS 的路径错误地计入环。
