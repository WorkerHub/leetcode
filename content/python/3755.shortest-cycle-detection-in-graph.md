## 题目描述

给定一个有 `n` 个节点的无向图，边集为 `edges`。找出图中最短环的长度（最小环的边数）。若不存在环，返回 `-1`。

**示例 1：**
```
输入：n = 7, edges = [[0,1],[1,2],[2,0],[3,4],[4,5],[5,6],[6,3]]
输出：3
解释：最短环为 0-1-2-0，长度 3。
```

**示例 2：**
```
输入：n = 4, edges = [[0,1],[0,2]]
输出：-1
解释：无环。
```

**提示：**
- `2 <= n <= 1000`
- `1 <= edges.length <= 1000`

## 解题思路

对每个节点作为 BFS 起点，找从该节点出发回到该节点的最短路径（最短环长度）。

**方法：** 对每个节点 `u`，做 BFS，若在 BFS 中发现节点 `v` 已被访问（且 `v` 不是 `u` 的父节点），则找到了一个环，长度为 `dist[u] + dist[v] + 1`。

对所有节点取最小值。

## Python 代码实现

### 方法一：每个节点 BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def findShortestCycle(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = float('inf')

        for start in range(n):
            # BFS 从 start 出发，寻找最短环
            dist = [-1] * n
            dist[start] = 0
            parent = [-1] * n
            queue = deque([start])

            while queue:
                u = queue.popleft()
                for v in graph[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        parent[v] = u
                        queue.append(v)
                    elif parent[u] != v:
                        # 发现已访问且不是父节点，找到环
                        ans = min(ans, dist[u] + dist[v] + 1)

        return ans if ans != float('inf') else -1
```

### 方法二：DFS 检测环

```python
from typing import List
from collections import defaultdict

class Solution:
    def findShortestCycle(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = float('inf')
        depth = [-1] * n

        def dfs(u: int, par: int, d: int) -> None:
            nonlocal ans
            depth[u] = d
            for v in graph[u]:
                if v == par:
                    continue
                if depth[v] == -1:
                    dfs(v, u, d + 1)
                else:
                    ans = min(ans, d - depth[v] + 1)

        for i in range(n):
            if depth[i] == -1:
                dfs(i, -1, 0)

        return ans if ans != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n * (n + m))，每个节点做一次 BFS/DFS
- 空间复杂度：O(n + m)

## 关键点总结

1. 对每个节点做 BFS，发现已访问节点（非父节点）时即找到环
2. 环长度 = 两个节点到起点的距离之和 + 1
3. 取所有起点的最小值

## 易错点

1. 无向图 BFS 中，父节点方向不算回边（用 parent 数组排除）
2. 多重边情况：同一对节点有两条边时，长度为 2 的环
