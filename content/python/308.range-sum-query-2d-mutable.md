## 题目描述

给你一个 2D 矩阵 `matrix`，请计算出从左上角 `(row1, col1)` 到右下角 `(row2, col2)` 组成的矩形中所有元素的和。

你需要实现 `NumMatrix` 类：

- `NumMatrix(int[][] matrix)` 给定整数矩阵 `matrix` 进行初始化
- `void update(int row, int col, int val)` 更新 `matrix[row][col]` 的值到 `val`
- `int sumRegion(int row1, int col1, int row2, int col2)` 返回左上角 `(row1, col1)` 、右下角 `(row2, col2)` 所描述的子矩阵的元素**总和**

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/14/sum-grid.jpg)

```
输入
["NumMatrix", "sumRegion", "update", "sumRegion"]
[[[[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]], [2, 1, 4, 3], [3, 2, 2], [2, 1, 4, 3]]
输出
[null, 8, null, 10]

解释
NumMatrix numMatrix = new NumMatrix([[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]);
numMatrix.sumRegion(2, 1, 4, 3); // 返回 8（红色矩形框的元素总和）
numMatrix.update(3, 2, 2);       // 矩阵变为 [[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 2, 1, 7], [1, 0, 3, 0, 5]]
numMatrix.sumRegion(2, 1, 4, 3); // 返回 10（红色矩形框的元素总和）
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 200`
- `-10^5 <= matrix[i][j] <= 10^5`
- `0 <= row < m`
- `0 <= col < n`
- `-10^5 <= val <= 10^5`
- `0 <= row1 <= row2 < m`
- `0 <= col1 <= col2 < n`
- 最多调用 `10^4` 次 `sumRegion` 和 `update` 方法

## 解题思路

这是 304 题（二维不可变区间和）和 307 题（一维可变区间和）的结合版本。

### 方法对比

| 方法 | 更新时间 | 查询时间 | 空间 |
|------|---------|---------|------|
| 暴力 | O(1) | O(mn) | O(1) |
| 二维树状数组 | O(log m × log n) | O(log m × log n) | O(mn) |
| 线段树 | O(log m × log n) | O(log m × log n) | O(mn) |
| 逐行树状数组 | O(log n) | O(m × log n) | O(mn) |

### 二维树状数组（推荐）⭐

**核心思想**：将一维树状数组扩展到二维。

- `tree[i][j]` 维护的是一个二维区域的和
- 更新和查询都需要在两个维度上操作

## Python 代码实现

### 方法一：二维树状数组（推荐）⭐

```python
from typing import List

class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        if not matrix or not matrix[0]:
            return
        
        self.m = len(matrix)
        self.n = len(matrix[0])
        
        # 原始矩阵
        self.matrix = [[0] * self.n for _ in range(self.m)]
        
        # 二维树状数组（索引从 1 开始）
        self.tree = [[0] * (self.n + 1) for _ in range(self.m + 1)]
        
        # 初始化
        for i in range(self.m):
            for j in range(self.n):
                self.update(i, j, matrix[i][j])
    
    def update(self, row: int, col: int, val: int) -> None:
        """更新 matrix[row][col] 的值为 val"""
        # 计算差值
        delta = val - self.matrix[row][col]
        self.matrix[row][col] = val
        
        # 更新树状数组
        i = row + 1
        while i <= self.m:
            j = col + 1
            while j <= self.n:
                self.tree[i][j] += delta
                j += self._lowbit(j)
            i += self._lowbit(i)
    
    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        """返回子矩阵 (row1, col1) 到 (row2, col2) 的和"""
        return (
            self._prefix_sum(row2, col2) -
            self._prefix_sum(row1 - 1, col2) -
            self._prefix_sum(row2, col1 - 1) +
            self._prefix_sum(row1 - 1, col1 - 1)
        )
    
    def _prefix_sum(self, row: int, col: int) -> int:
        """计算从 (0, 0) 到 (row, col) 的矩形和"""
        if row < 0 or col < 0:
            return 0
        
        result = 0
        i = row + 1
        while i > 0:
            j = col + 1
            while j > 0:
                result += self.tree[i][j]
                j -= self._lowbit(j)
            i -= self._lowbit(i)
        
        return result
    
    def _lowbit(self, x: int) -> int:
        """计算 lowbit(x)"""
        return x & (-x)
```

### 方法二：逐行树状数组

```python
from typing import List

class BIT:
    """一维树状数组"""
    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (n + 1)
    
    def update(self, index: int, delta: int) -> None:
        """更新位置 index，增加 delta"""
        i = index + 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)
    
    def query(self, index: int) -> int:
        """查询前缀和 [0, index]"""
        if index < 0:
            return 0
        result = 0
        i = index + 1
        while i > 0:
            result += self.tree[i]
            i -= i & (-i)
        return result
    
    def range_sum(self, left: int, right: int) -> int:
        """查询区间和 [left, right]"""
        return self.query(right) - self.query(left - 1)

class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        if not matrix or not matrix[0]:
            return
        
        self.m = len(matrix)
        self.n = len(matrix[0])
        self.matrix = [row[:] for row in matrix]  # 复制矩阵
        
        # 每一行都有一个树状数组
        self.rows = [BIT(self.n) for _ in range(self.m)]
        
        # 初始化每一行的树状数组
        for i in range(self.m):
            for j in range(self.n):
                self.rows[i].update(j, matrix[i][j])
    
    def update(self, row: int, col: int, val: int) -> None:
        """更新 matrix[row][col] 的值为 val"""
        delta = val - self.matrix[row][col]
        self.matrix[row][col] = val
        self.rows[row].update(col, delta)
    
    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        """返回子矩阵的和"""
        result = 0
        for i in range(row1, row2 + 1):
            result += self.rows[i].range_sum(col1, col2)
        return result
```

### 方法四：带详细注释的二维树状数组

```python
from typing import List

class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        """
        初始化二维树状数组
        
        tree[i][j] 的含义：
        维护一个二维区域的和，具体范围由 lowbit 决定
        """
        if not matrix or not matrix[0]:
            self.m = 0
            self.n = 0
            return
        
        self.m = len(matrix)
        self.n = len(matrix[0])
        
        # 保存原始矩阵（用于计算差值）
        self.matrix = [[0] * self.n for _ in range(self.m)]
        
        # 二维树状数组，大小 (m+1) x (n+1)
        self.tree = [[0] * (self.n + 1) for _ in range(self.m + 1)]
        
        # 初始化所有元素
        for i in range(self.m):
            for j in range(self.n):
                self.update(i, j, matrix[i][j])
    
    def update(self, row: int, col: int, val: int) -> None:
        """
        更新 matrix[row][col] 的值为 val
        
        思路：
        1. 计算差值 delta
        2. 在两个维度上都向上传播更新
        """
        delta = val - self.matrix[row][col]
        self.matrix[row][col] = val
        
        # 树状数组索引从 1 开始
        i = row + 1
        while i <= self.m:
            j = col + 1
            while j <= self.n:
                self.tree[i][j] += delta
                j += j & (-j)  # lowbit(j)
            i += i & (-i)  # lowbit(i)
    
    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        """
        返回子矩阵的和
        
        公式（容斥原理）：
        sum = prefix(r2, c2) - prefix(r1-1, c2) 
            - prefix(r2, c1-1) + prefix(r1-1, c1-1)
        """
        return (
            self._prefix_sum(row2, col2) -
            self._prefix_sum(row1 - 1, col2) -
            self._prefix_sum(row2, col1 - 1) +
            self._prefix_sum(row1 - 1, col1 - 1)
        )
    
    def _prefix_sum(self, row: int, col: int) -> int:
        """
        计算从 (0, 0) 到 (row, col) 的矩形和
        
        思路：在两个维度上都向下累加
        """
        if row < 0 or col < 0:
            return 0
        
        result = 0
        i = row + 1
        while i > 0:
            j = col + 1
            while j > 0:
                result += self.tree[i][j]
                j -= j & (-j)  # lowbit(j)
            i -= i & (-i)  # lowbit(i)
        
        return result
```

## 复杂度分析

**二维树状数组：**
- 时间复杂度：
  - 初始化：O(mn log m log n)
  - 更新：O(log m × log n)
  - 查询：O(log m × log n)
- 空间复杂度：O(mn)

**逐行树状数组：**
- 时间复杂度：
  - 初始化：O(mn log n)
  - 更新：O(log n)
  - 查询：O(m log n)
- 空间复杂度：O(mn)

## 关键点总结

1. **二维树状数组的更新**：
   ```python
   i = row + 1
   while i <= m:
       j = col + 1
       while j <= n:
           tree[i][j] += delta
           j += lowbit(j)
       i += lowbit(i)
   ```

2. **二维树状数组的查询**：
   ```python
   i = row + 1
   while i > 0:
       j = col + 1
       while j > 0:
           result += tree[i][j]
           j -= lowbit(j)
       i -= lowbit(i)
   ```

3. **容斥原理**：查询时需要加加减减，与二维前缀和类似

4. **索引转换**：树状数组索引从 1 开始，需要 +1

5. **更新是差值**：`delta = val - matrix[row][col]`，而不是直接赋值

## 易错点

1. **双重循环顺序**：内外层循环不能颠倒
2. **索引偏移**：忘记 +1 转换
3. **容斥原理**：区间查询的四项公式容易记错
4. **lowbit 计算**：`x & (-x)` 不要写错
5. **边界处理**：`_prefix_sum(-1, x)` 应返回 0
