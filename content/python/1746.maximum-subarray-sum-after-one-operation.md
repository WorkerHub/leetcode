## 题目描述

给你一个整数数组 `nums`，你**必须**对其执行一次操作：选择数组中某个元素，将其替换为该元素的**平方**。

请你返回执行一次操作后可以得到的**最大子数组和**。

**示例 1：**
```
输入：nums = [2,-1,-4,-3]
输出：17
解释：将 -4 替换为 16，得到 [2,-1,16,-3]，最大子数组和为 2+(-1)+16=17
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

动态规划：

- `dp0[i]`：以 `nums[i]` 结尾，没有使用过平方操作的最大子数组和
- `dp1[i]`：以 `nums[i]` 结尾，恰好使用过一次平方操作的最大子数组和

转移：
- `dp0[i] = max(nums[i], dp0[i-1] + nums[i])`（标准 Kadane 算法）
- `dp1[i] = max(dp0[i-1] + nums[i]^2, nums[i]^2, dp1[i-1] + nums[i])`
  - 在 i 处使用平方：`max(dp0[i-1], 0) + nums[i]^2`（从之前的子数组延续或新开始）
  - 之前已用平方，延续到 i：`dp1[i-1] + nums[i]`

答案为所有 `dp1[i]` 的最大值。

## 代码实现

### 方法一：DP 两状态（推荐）

```python
from typing import List

class Solution:
    def maxSumAfterOperation(self, nums: List[int]) -> int:
        n = len(nums)
        
        # dp0: 以当前元素结尾，未使用平方操作的最大子数组和
        # dp1: 以当前元素结尾，已使用一次平方操作的最大子数组和
        dp0 = nums[0]
        dp1 = nums[0] ** 2  # 在第一个元素使用平方
        ans = dp1
        
        for i in range(1, n):
            x = nums[i]
            # 在当前位置使用平方：max(dp0 + x^2, x^2)
            new_dp1 = max(max(dp0, 0) + x * x, dp1 + x)
            # 不在当前位置使用平方
            new_dp0 = max(dp0 + x, x)
            
            dp0 = new_dp0
            dp1 = new_dp1
            ans = max(ans, dp1)
        
        return ans
```

### 方法二：显式状态更新

```python
from typing import List

class Solution:
    def maxSumAfterOperation(self, nums: List[int]) -> int:
        INF = float('-inf')
        # no_sq: 未使用平方的最大连续子数组和（以当前元素结尾）
        # with_sq: 已使用一次平方的最大连续子数组和（以当前元素结尾）
        no_sq = INF
        with_sq = INF
        ans = INF
        
        for x in nums:
            # 更新 with_sq：要么在此处平方，要么之前已平方
            new_with_sq = max(
                (no_sq if no_sq != INF else 0) + x * x,  # 在此处平方
                x * x,                                      # 从此处开始并平方
                (with_sq + x) if with_sq != INF else INF    # 之前已平方，延续
            )
            # 更新 no_sq
            new_no_sq = max(x, (no_sq + x) if no_sq != INF else x)
            
            no_sq = new_no_sq
            with_sq = new_with_sq
            ans = max(ans, with_sq)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历
- **空间复杂度**：O(1)，只用常数空间

## 关键点总结

1. 将问题分为"已使用平方"和"未使用平方"两个状态
2. 转移方程类似 Kadane 算法，在每个位置决定是否使用平方操作
3. 答案在所有 `with_sq[i]` 中取最大值

## 易错点

- 必须恰好使用一次平方操作（`dp1` 中必须有过一次平方）
- 初始化时 `dp1 = nums[0]^2`，`dp0 = nums[0]`
