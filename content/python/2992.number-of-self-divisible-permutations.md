## 题目描述

给你一个整数 `n`，返回 `[1, 2, ..., n]` 的排列数，满足对每个位置 `i`（1-indexed），`perm[i]` 能被 `i` 整除。

**示例 1：**
```
输入：n = 2
输出：2
解释：[1,2] 和 [2,2] - 等等，[1,2]: perm[1]=1 能被 1 整除，perm[2]=2 能被 2 整除，有效
[2,1]: perm[1]=2 能被 1 整除，perm[2]=1 不能被 2 整除，无效
输出 1? 还是 2?
```

**实际示例：**
```
输入：n = 2
输出：1
输入：n = 3
输出：3
```

**提示：**
- `1 <= n <= 12`

## 解题思路

使用**状态压缩 DP**（位运算）：用 `mask` 表示哪些数字已被使用。

`dp[pos][mask]`：当前填第 `pos` 位，已使用数字集合为 `mask`，的方案数。

对于位置 `pos`，枚举所有未使用的数字 `num`，若 `num % pos == 0`，则可以放在 pos。

n <= 12，mask 最多 2^12 = 4096 个状态。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from functools import lru_cache

class Solution:
    def selfDivisiblePermutationCount(self, n: int) -> int:
        @lru_cache(maxsize=None)
        def dp(pos: int, mask: int) -> int:
            if pos > n:
                return 1
            count = 0
            for num in range(1, n + 1):
                if (mask >> (num - 1)) & 1:
                    continue  # 已使用
                if num % pos == 0:
                    count += dp(pos + 1, mask | (1 << (num - 1)))
            return count

        return dp(1, 0)
```

### 方法二：迭代 DP

```python
class Solution:
    def selfDivisiblePermutationCount(self, n: int) -> int:
        # dp[mask] = 已使用数字集合为 mask 时，已填前 popcount(mask) 位的方案数
        dp = [0] * (1 << n)
        dp[0] = 1

        for mask in range(1 << n):
            pos = bin(mask).count('1') + 1  # 当前要填第 pos 位
            if pos > n:
                continue
            for num in range(1, n + 1):
                if (mask >> (num - 1)) & 1:
                    continue  # 已使用
                if num % pos == 0:
                    dp[mask | (1 << (num - 1))] += dp[mask]

        # 答案是 mask 为全满（所有位都用上）的方案数
        return dp[(1 << n) - 1]
```

## 复杂度分析

- 时间复杂度：O(n * 2^n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 状态压缩：mask 的第 i 位为 1 表示数字 i+1 已被使用
2. 位置 pos = mask 中 1 的个数 + 1（当前要填的位置）
3. 枚举未使用的数字，检查能否被 pos 整除

## 易错点

1. 位置从 1 开始（1-indexed）
2. 条件是 num % pos == 0（num 能被 pos 整除），不是 pos 能被 num 整除
3. 答案是 mask = (1<<n)-1 的计数
