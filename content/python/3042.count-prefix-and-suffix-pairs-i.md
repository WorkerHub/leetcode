## 题目描述

给你一个下标从 0 开始的字符串数组 `words`。

定义函数 `isPrefixAndSuffix(str1, str2)`：当 `str1` 同时是 `str2` 的前缀和后缀时返回 `true`，否则返回 `false`。

返回满足 `i < j` 且 `isPrefixAndSuffix(words[i], words[j])` 为 `true` 的下标对数量。

**示例 1：**
```
输入：words = ["a","aba","ababa","aa"]
输出：4
```

**示例 2：**
```
输入：words = ["pa","papa","mamama"]
输出：2
```

**提示：**
- `1 <= words.length <= 50`
- `1 <= words[i].length <= 10`

## 解题思路

数据范围小，直接枚举所有 `(i, j)` 对（i < j），判断 `words[i]` 是否同时是 `words[j]` 的前缀和后缀。

Python 内置 `str.startswith` 和 `str.endswith` 即可。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        count = 0
        n = len(words)
        for i in range(n):
            for j in range(i + 1, n):
                s1, s2 = words[i], words[j]
                if len(s1) <= len(s2) and s2.startswith(s1) and s2.endswith(s1):
                    count += 1
        return count
```

### 方法二：使用辅助函数

```python
from typing import List

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        def is_prefix_and_suffix(s1: str, s2: str) -> bool:
            return len(s1) <= len(s2) and s2[:len(s1)] == s1 and s2[-len(s1):] == s1

        return sum(
            1 for i in range(len(words))
            for j in range(i + 1, len(words))
            if is_prefix_and_suffix(words[i], words[j])
        )
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为字符串数，L 为最大字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 同时是前缀和后缀：`str2.startswith(str1)` 且 `str2.endswith(str1)`
2. 前提：`len(str1) <= len(str2)`
3. 数据范围小，暴力枚举即可

## 易错点

1. 需要检查长度：`str1` 不能比 `str2` 长
2. 当 `str1 == str2` 时，`str1` 既是 `str2` 的前缀又是后缀（合法）
