## 题目描述

有一个长度为 `arrLen` 的数组，下标从 `0` 到 `arrLen - 1`。

一个指针从位置 `0` 开始，每一步可以进行以下操作之一：
- 向左移动一步（位置减 1）
- 向右移动一步（位置减 1）
- 停在原地（位置不变）

请你返回恰好走 `steps` 步之后，指针仍然在位置 `0` 处的方案数。由于答案可能非常大，返回结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：steps = 3, arrLen = 2
输出：4
解释：有 4 种不同的方法可以在 3 步后停在位置 0：
  向右，向左，停在原地
  停在原地，向右，向左
  向右，停在原地，向左
  停在原地，停在原地，停在原地
```

**示例 2：**
```
输入：steps = 2, arrLen = 4
输出：2
解释：
  向右，向左
  停在原地，停在原地
```

**示例 3：**
```
输入：steps = 4, arrLen = 2
输出：8
```

**提示：**
- `1 <= steps <= 500`
- `1 <= arrLen <= 10^6`
- 答案对 `10^9 + 7` 取模

---

## 解题思路

**动态规划定义：**

设 `dp[i][j]` = 走了 `i` 步后，指针在位置 `j` 的方案数。

**状态转移：** 第 `i` 步可以来自第 `i-1` 步的三种操作：
- 从位置 `j-1` 向右走（如果 `j > 0`）
- 从位置 `j+1` 向左走（如果 `j+1 < arrLen`）
- 从位置 `j` 停在原地

因此：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j] + dp[i-1][j+1]`

**初始状态：** `dp[0][0] = 1`（走 0 步，在位置 0 的方案数为 1）

**关键优化——限制位置范围：**

位置最大只能到 `steps // 2`，原因：
- 我们需要在 `steps` 步后回到位置 0
- 假设向右走了 `r` 步，向左走了 `l` 步，停留 `s` 步
- 最终位置为 0：`r - l = 0`，即 `r = l`
- 总步数：`r + l + s = steps`，即 `2r + s = steps`
- 所以 `r <= steps // 2`，即最远只能到达位置 `steps // 2`

这样，实际需要考虑的位置数为 `min(arrLen, steps // 2 + 1)`，而不是 `arrLen`（可能高达 10^6）。

## Python 代码实现

### 方法一：二维 DP（标准解法）

```python
class Solution:
    def numWays(self, steps: int, arrLen: int) -> int:
        MOD = 10 ** 9 + 7

        # 关键优化：最远只能到达 steps//2 的位置
        # 因为向右走多少步就必须向左走多少步才能回到 0
        max_pos = min(arrLen - 1, steps // 2)

        # dp[j] = 当前步数下，指针在位置 j 的方案数
        # 使用滚动数组优化（只保留上一步的状态）
        dp = [0] * (max_pos + 1)
        dp[0] = 1  # 初始状态：0 步，在位置 0

        for i in range(steps):
            new_dp = [0] * (max_pos + 1)
            for j in range(max_pos + 1):
                if dp[j] == 0:
                    continue  # 跳过方案数为 0 的位置
                # 操作1：停在原地
                new_dp[j] = (new_dp[j] + dp[j]) % MOD
                # 操作2：向左走（j > 0 才能向左）
                if j > 0:
                    new_dp[j - 1] = (new_dp[j - 1] + dp[j]) % MOD
                # 操作3：向右走（j < max_pos 才能向右）
                if j < max_pos:
                    new_dp[j + 1] = (new_dp[j + 1] + dp[j]) % MOD
            dp = new_dp

        return dp[0]
```

**执行过程演示（steps=3, arrLen=2）：**
```
初始：dp = [1, 0]  (只有位置0有1种方案)

第1步：
  从位置0：停在0(+1), 向右到1(+1)
  new_dp = [1, 1]

第2步：
  从位置0：停在0(+1), 向右到1(+1)
  从位置1：停在1(+1), 向左到0(+1)
  new_dp = [2, 2]

第3步：
  从位置0：停在0(+2), 向右到1(+2)
  从位置1：停在1(+2), 向左到0(+2)
  new_dp = [4, 4]

答案：dp[0] = 4 ✓
```

### 方法二：记忆化递归（Top-Down DP）

```python
from functools import lru_cache

class Solution:
    def numWays(self, steps: int, arrLen: int) -> int:
        MOD = 10 ** 9 + 7
        # 关键优化：位置上界
        max_pos = min(arrLen - 1, steps // 2)

        @lru_cache(maxsize=None)
        def dfs(remaining_steps: int, pos: int) -> int:
            """
            remaining_steps: 还剩多少步可以走
            pos: 当前位置
            返回：从当前状态出发，最终回到位置 0 的方案数
            """
            # 剩余步数不够回到位置 0（即使每步都向左也回不去）
            if pos > remaining_steps:
                return 0
            # 已经没有步数了，检查是否在位置 0
            if remaining_steps == 0:
                return 1 if pos == 0 else 0

            total = 0
            # 三种操作
            total += dfs(remaining_steps - 1, pos)        # 停在原地
            if pos > 0:
                total += dfs(remaining_steps - 1, pos - 1)  # 向左走
            if pos < max_pos:
                total += dfs(remaining_steps - 1, pos + 1)  # 向右走
            return total % MOD

        return dfs(steps, 0)
```

### 方法三：完整二维 DP 展示（便于理解）

```python
class Solution:
    def numWays(self, steps: int, arrLen: int) -> int:
        MOD = 10 ** 9 + 7
        max_pos = min(arrLen - 1, steps // 2)

        # dp[i][j] = 走了 i 步后在位置 j 的方案数
        # 为了节省内存使用滚动数组，这里先展示完整版
        dp = [[0] * (max_pos + 1) for _ in range(steps + 1)]
        dp[0][0] = 1  # 初始：0 步，在位置 0

        for i in range(1, steps + 1):
            for j in range(max_pos + 1):
                # 来自停在原地
                dp[i][j] = dp[i-1][j]
                # 来自位置 j-1 向右走
                if j > 0:
                    dp[i][j] = (dp[i][j] + dp[i-1][j-1]) % MOD
                # 来自位置 j+1 向左走
                if j + 1 <= max_pos:
                    dp[i][j] = (dp[i][j] + dp[i-1][j+1]) % MOD

        return dp[steps][0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一（滚动数组） | O(steps × min(arrLen, steps)) | O(min(arrLen, steps)) | 最优空间 |
| 方法二（记忆化递归） | O(steps × min(arrLen, steps)) | O(steps × min(arrLen, steps)) | 缓存表 |
| 方法三（完整 2D DP） | O(steps × min(arrLen, steps)) | O(steps × min(arrLen, steps)) | 便于理解 |

关键：`min(arrLen, steps // 2 + 1)` 的上界使得即使 `arrLen = 10^6`，实际需要的位置数也只有 `steps // 2 + 1 <= 251`。

---

## 关键点总结

1. **位置上界优化是关键**：若没有这个优化，`arrLen` 可达 10^6，会导致 MLE（内存超限）或 TLE（超时）。必须将位置上界限制为 `min(arrLen - 1, steps // 2)`。
2. **滚动数组**：当 DP 只依赖上一行时，可以只保留上一行（滚动数组），将空间复杂度从 O(steps × pos) 降至 O(pos)。
3. **状态转移方向**：方法一是"推"的方式（从当前状态推导下一状态），方法三是"拉"的方式（当前状态从上一步拉取），两者等价。
4. **取模时机**：每次加法后立即对 `10^9 + 7` 取模，防止数值溢出（虽然 Python 没有整数溢出，但对保持良好习惯有意义）。
5. **剪枝条件** `pos > remaining_steps`：如果当前位置大于剩余步数，即使每步都向左也无法回到 0，可以直接返回 0。

---

## 易错点

1. **忘记位置上界优化**：直接用 `range(arrLen)` 会导致对 `arrLen = 10^6` 的输入超时或超内存。
2. **边界处理**：向左时需要 `j > 0`（不能超出数组左边界），向右时需要 `j < max_pos`（不能超出有效范围）。
3. **滚动数组更新顺序**：方法一创建了 `new_dp`，不是原地修改 `dp`。如果原地修改，会导致同一步的状态互相影响，结果错误。
4. **最终答案**：答案是 `dp[0]`（走完所有步后在位置 0 的方案数），不要返回其他位置的值。
5. **steps // 2 vs steps // 2 + 1**：`max_pos = min(arrLen - 1, steps // 2)` 中用的是 `steps // 2`（因为向右最多走 steps//2 步），循环时用 `range(max_pos + 1)` 包含 max_pos。

2. **滚动数组技巧**：这是 DP 优化中最常用的空间优化手段。每当 DP 转移只依赖"上一层"时，就可以用滚动数组将二维 DP 压缩为一维，建议重点掌握。
3. **剪枝的重要性**：`pos > remaining_steps` 这个剪枝条件在记忆化递归中非常有效，体现了"可行性剪枝"的思想——提前排除不可能回到目标的状态。
