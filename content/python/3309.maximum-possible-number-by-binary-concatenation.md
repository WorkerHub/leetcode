## 题目描述

给你一个长度为 3 的整数数组 `nums`。

将这 3 个数的**二进制表示**按某种顺序拼接，得到一个新的二进制数，返回所有排列中**最大**的那个十进制值。

**示例 1：**
```
输入：nums = [1, 2, 3]
输出：30
解释：排列 [2, 3, 1]：二进制为 "10" + "11" + "1" = "10111" = 23
      排列 [3, 2, 1]：二进制为 "11" + "10" + "1" = "11101" = 29
      排列 [3, 1, 2]：二进制为 "11" + "1" + "10" = "11110" = 30（最大）
```

**示例 2：**
```
输入：nums = [2, 8, 16]
输出：1296
解释：排列 [16, 2, 8]：二进制 "10000" + "10" + "1000" = "100001 01000" ...
```

**提示：**
- `nums.length == 3`
- `1 <= nums[i] <= 127`

## 解题思路

数组长度固定为 3，全排列只有 6 种，枚举所有排列，计算每种排列拼接后的二进制数的十进制值，取最大值即可。

**二进制拼接方式：**
将 `a` 和 `b` 拼接，等价于：`a * (2 ^ b的二进制位数) + b`，即 `(a << b.bit_length()) | b`。

## Python 代码实现

### 方法一：枚举全排列（推荐）

```python
from typing import List
from itertools import permutations

class Solution:
    def maximumNumber(self, nums: List[int]) -> int:
        max_val = 0
        
        for perm in permutations(nums):
            # 拼接三个数的二进制表示
            result = 0
            for num in perm:
                # 将 result 左移 num 的二进制位数，再加上 num
                result = (result << num.bit_length()) | num
            max_val = max(max_val, result)
        
        return max_val
```

### 方法二：直接比较字符串拼接（简洁）

```python
from typing import List
from itertools import permutations

class Solution:
    def maximumNumber(self, nums: List[int]) -> int:
        best = 0
        for perm in permutations(nums):
            # 拼接二进制字符串后转为整数
            binary_str = ''.join(bin(x)[2:] for x in perm)
            best = max(best, int(binary_str, 2))
        return best
```

## 复杂度分析

- 时间复杂度：O(1)，数组长度固定为 3，全排列数量固定为 6
- 空间复杂度：O(1)

## 关键点总结

1. 数组长度固定为 3，枚举全部 6 种排列即可。
2. 二进制拼接的核心：`(a << b.bit_length()) | b` 等价于把 `a` 的二进制放在 `b` 的前面。
3. `bin(x)[2:]` 去掉 Python `bin()` 函数返回的 `'0b'` 前缀。

## 易错点

1. `num.bit_length()` 是数字的二进制位数，`0` 的 `bit_length()` 为 0，但本题 `nums[i] >= 1`，不影响。
2. 拼接多个数时注意累积左移，不是固定位数。
3. 不要将"最大十进制值"误理解为每位都选最大，需要全局比较。
