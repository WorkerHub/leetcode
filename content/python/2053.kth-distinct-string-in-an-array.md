## 题目描述

**不同字符串**是指在数组中只出现**一次**的字符串。

给你一个字符串数组 `arr` 和一个整数 `k`，请你返回 `arr` 中第 `k` 个**不同字符串**。如果不同字符串少于 `k` 个，返回空字符串 `""`。

注意，按照字符串在原数组中出现的**顺序**对不同字符串进行编号。

**示例 1：**
```
输入：arr = ["d","b","c","b","c","a"], k = 2
输出："a"
解释：不同字符串（只出现一次）按顺序为 "d","a"，第2个是"a"
```

**示例 2：**
```
输入：arr = ["aaa","aa","a"], k = 1
输出："aaa"
```

**提示：**
- `1 <= k <= arr.length <= 1000`
- `1 <= arr[i].length <= 5`
- `arr[i]` 由小写英文字母组成

## 解题思路

两步法：先统计每个字符串的出现次数，然后按原数组顺序找第 k 个只出现一次的字符串。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        count = Counter(arr)  # 统计每个字符串出现次数

        cnt = 0  # 已发现的不同字符串数
        for s in arr:
            if count[s] == 1:  # 只出现一次
                cnt += 1
                if cnt == k:
                    return s

        return ""  # 不存在第 k 个不同字符串
```

### 方法二：两次遍历

```python
from typing import List

class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        freq = {}
        for s in arr:
            freq[s] = freq.get(s, 0) + 1

        for s in arr:
            if freq[s] == 1:
                k -= 1
                if k == 0:
                    return s

        return ""
```

### 方法三：集合过滤（简洁）

```python
from typing import List

class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        # 找出只出现一次的字符串集合
        seen = set()
        duplicates = set()
        for s in arr:
            if s in seen:
                duplicates.add(s)
            seen.add(s)

        # 按原顺序找第 k 个
        cnt = 0
        for s in arr:
            if s not in duplicates:
                cnt += 1
                if cnt == k:
                    return s
        return ""
```

## 复杂度分析

- 时间复杂度：O(n)，两次遍历
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 先用哈希表统计出现频次
2. 按原数组顺序遍历，找出现次数为 1 的字符串
3. 计数到第 k 个时返回

## 易错点

- 保持原顺序（不是字典序或任意顺序）
- 注意 k 可能超过不同字符串的总数，此时返回 `""`
