## 题目描述

给你一个二进制字符串 `s` 和一个二维整数数组 `queries`，其中 `queries[i] = [firsti, secondi]`。

对于第 `i` 个查询，找到 `s` 中满足以下条件的 **最短** 子字符串：
- 子字符串对应的值与 `firsti XOR secondi` 相等
- 子字符串中不含前导零（除非子字符串本身就是 "0"）

返回一个整数数组 `ans`，其中 `ans[i] = [lefti, righti]` 表示子字符串的左右下标（0 索引）。若不存在，返回 `[-1, -1]`。

**示例 1：**

```
输入：s = "101101", queries = [[0,5],[1,2]]
输出：[[0,2],[2,3]]
```

**提示：**

- `1 <= s.length <= 10^4`
- `1 <= queries.length <= 10^5`
- `0 <= firsti, secondi <= 10^9`

## 解题思路

**预计算**：对字符串 `s` 的每个起始位置 i，枚举从 i 开始的所有子字符串（不含前导零），将其值和对应的 [i, j] 存入哈希表。

由于值最多 32 位（最大 10^9 约 30 位），对每个起始位置最多扩展 30 位，共 O(30 * n) 次操作。

查询时，计算 first XOR second，直接查哈希表。

## Python 代码实现

### 方法一：预计算哈希表（推荐）

```python
from typing import List

class Solution:
    def substringXorQueries(self, s: str, queries: List[List[int]]) -> List[List[int]]:
        n = len(s)
        # val_to_pos[v] = [left, right]：s 中最短表示 v 的子串（不含前导零）
        val_to_pos = {}

        for i in range(n):
            if s[i] == '0':
                # 单个 '0' 表示值 0
                if 0 not in val_to_pos:
                    val_to_pos[0] = [i, i]
                continue  # 以 '0' 开头的多位子串有前导零，跳过

            val = 0
            for j in range(i, min(i + 30, n)):
                val = val * 2 + int(s[j])
                if val not in val_to_pos:
                    val_to_pos[val] = [i, j]

        ans = []
        for first, second in queries:
            target = first ^ second
            ans.append(val_to_pos.get(target, [-1, -1]))

        return ans
```

### 方法二：对每个查询单独二分

```python
from typing import List

class Solution:
    def substringXorQueries(self, s: str, queries: List[List[int]]) -> List[List[int]]:
        n = len(s)
        cache = {}

        for i in range(n):
            if s[i] == '0':
                if 0 not in cache:
                    cache[0] = [i, i]
                continue
            val = 0
            for j in range(i, min(i + 32, n)):
                val = (val << 1) | int(s[j])
                if val not in cache:
                    cache[val] = [i, j]

        return [cache.get(a ^ b, [-1, -1]) for a, b in queries]
```

## 复杂度分析

- 预处理时间复杂度：O(n * 30)，对每个位置扩展最多 30 步
- 查询时间复杂度：O(1)，哈希查找
- 空间复杂度：O(n * 30)，哈希表大小

## 关键点总结

1. 预处理所有合法子串（不含前导零，长度 <= 32 位）到哈希表
2. 查询时直接计算 first XOR second 查哈希表
3. 最短子串：对同一值，先出现的 i 对应的子串更短（从左到右枚举）

## 易错点

1. 含前导零的多位子串要跳过（除 "0" 本身）
2. 目标值最大 10^9 < 2^30，所以每个起点扩展最多 30 位
3. 哈希表中存最短（最先出现）的子串位置
