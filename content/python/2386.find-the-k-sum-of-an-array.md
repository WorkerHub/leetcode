## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。`nums` 的任一**子序列**的**和**定义为该子序列所有元素的和（空子序列的和为 0）。

返回 `nums` 中所有子序列的和中第 `k` 大的值。

**示例 1：**
```
输入：nums = [2,4,-2], k = 5
输出：2
解释：所有子序列和：6, 4, 2, 2, 0, 0, -2（排序后：6,4,2,2,0,0,-2）
```

**示例 2：**
```
输入：nums = [1,-2,3,4,-10,12], k = 16
输出：10
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `1 <= k <= min(2000, 2^n)`

## 解题思路

**核心思路：**

1. 所有正数全取的和为最大子序列和 `max_sum`。
2. 次大的子序列和 = `max_sum` 减去某个"代价"（代价 = 不取某正数的损失，或额外取某负数的代价）。
3. 将所有数取绝对值排序，用最小堆枚举第 k 大的"减少量"。

**算法：**
- 设 `S = sum(正数)`，将 `abs(nums)` 排序。
- 用最小堆，每次扩展：(当前损失, 当前下标)。
- 从堆中取出第 k-1 次（因为第 1 大就是 S），每次可以：
  - 替换当前元素（加上 `sorted_abs[i+1] - sorted_abs[i]`）
  - 添加下一个元素（加上 `sorted_abs[i+1]`）

## 代码实现

### 方法一：最小堆枚举（推荐）

```python
from typing import List
import heapq

class Solution:
    def kSum(self, nums: List[int], k: int) -> int:
        # 计算全正数之和（最大子序列和）
        max_sum = sum(x for x in nums if x > 0)
        
        # 将绝对值排序（每个数的"代价"）
        abs_nums = sorted(abs(x) for x in nums)
        n = len(abs_nums)
        
        # 最小堆：(损失量, 下一个元素下标)
        # 初始：选择损失量最小的（即 abs_nums[0]）
        heap = [(abs_nums[0], 0)]
        
        # 第 1 大是 max_sum，需要找第 k-1 次更小的损失
        for _ in range(k - 1):
            if not heap:
                break
            cost, i = heapq.heappop(heap)
            
            # 扩展：下一个元素
            if i + 1 < n:
                # 在当前基础上再减去 abs_nums[i+1]（累加损失）
                heapq.heappush(heap, (cost + abs_nums[i + 1], i + 1))
                # 用 abs_nums[i+1] 替换 abs_nums[i]（替换损失）
                heapq.heappush(heap, (cost - abs_nums[i] + abs_nums[i + 1], i + 1))
        
        if not heap:
            return max_sum - float('inf')
        
        return max_sum - heap[0][0]
```

### 方法二：更清晰的实现版

```python
from typing import List
import heapq

class Solution:
    def kSum(self, nums: List[int], k: int) -> int:
        total = 0
        for i, x in enumerate(nums):
            if x >= 0:
                total += x
            else:
                nums[i] = -x  # 取绝对值
        
        nums.sort()
        
        # 堆：(减少量, 当前指向的最大下标)
        h = [(nums[0], 0)]
        ans = total
        
        for _ in range(k - 1):
            d, i = heapq.heappop(h)
            ans = total - d  # 当前第 _ + 2 大的值
            
            if i + 1 < len(nums):
                # 再减一个
                heapq.heappush(h, (d + nums[i + 1], i + 1))
                # 替换当前
                heapq.heappush(h, (d - nums[i] + nums[i + 1], i + 1))
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最小堆 | O(n log n + k log k) | O(n + k) |

## 关键点总结

1. 最大子序列和 = 所有正数之和。
2. 每个更小的子序列和 = 最大和 - 某种"代价"（代价是排序后绝对值的组合）。
3. 堆中维护（代价，下标），每次弹出最小代价，生成两个新状态（继续加、替换）。

## 易错点

- 初始堆应包含 `(abs_nums[0], 0)` 而不是从空开始。
- 替换操作：`cost - abs_nums[i] + abs_nums[i+1]`，是用下一个替换当前。
- 第 1 大就是 `max_sum`，循环从第 2 大开始求。
