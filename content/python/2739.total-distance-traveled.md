## 题目描述

一辆卡车有两个油箱：主油箱容量为 `mainTank` 升，副油箱容量为 `additionalTank` 升。

每消耗 5 升主油箱燃料，从副油箱向主油箱注入 1 升燃料（如果副油箱有剩余）。

卡车每升燃料行驶 10 km，返回卡车能行驶的最大距离。

**示例 1：**
```
输入：mainTank = 5, additionalTank = 10
输出：60
解释：主油箱 5 升用完，中途补充 1 升（消耗 5 升时），总共 6 升，行驶 60 km
```

**示例 2：**
```
输入：mainTank = 1, additionalTank = 2
输出：10
解释：1 升行驶 10 km，不够 5 升不能补充
```

**提示：**
- `1 <= mainTank, additionalTank <= 100`

## 解题思路

每消耗 5 升可从副箱补 1 升。主油箱实际使用量 = mainTank + 补充量。补充次数 = `min(mainTank // 5, additionalTank)`（但补充后主箱增加，需要循环计算）。

实际上：设补充次数为 k，则 `k = min((mainTank + k) // 5, additionalTank)` 是循环依赖，但可以直接用 `k = min(mainTank // 5, additionalTank)`（因为每次补充最多用 5 升才得 1 升，精确计算）。

更简单：`total = mainTank + min(mainTank // 5, additionalTank)`。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def distanceTraveled(self, mainTank: int, additionalTank: int) -> int:
        # 补充次数：每消耗5升补1升，不超过副油箱容量
        refills = min(mainTank // 5, additionalTank)
        # 总燃料 = 主油箱 + 补充量，每升10km
        return (mainTank + refills) * 10
```

### 方法二：模拟

```python
class Solution:
    def distanceTraveled(self, mainTank: int, additionalTank: int) -> int:
        distance = 0
        used = 0  # 已消耗的燃料
        while mainTank > 0:
            mainTank -= 1
            used += 1
            distance += 10
            # 每消耗 5 升，补 1 升
            if used % 5 == 0 and additionalTank > 0:
                mainTank += 1
                additionalTank -= 1
        return distance
```

## 复杂度分析

- 方法一：时间复杂度 O(1)
- 方法二：时间复杂度 O(mainTank)，空间复杂度 O(1)

## 关键点总结

1. 补充次数上限是 `mainTank // 5`（消耗 5 升才补 1 升）
2. 不超过副油箱容量 `additionalTank`

## 易错点

1. 补充发生在消耗 5 升之后，不是一开始
2. 公式 `min(mainTank // 5, additionalTank)` 是精确的（补充的 1 升本身不触发新的补充条件）
