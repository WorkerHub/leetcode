## 题目描述

给定一个整数数组 `hours`，表示以小时计的工作时间。我们定义「表现良好的时间段」为：在这段时间内，「劳累的天数」严格大于「不劳累的天数」。

所谓「劳累的一天」，指工作时间大于 8 小时的一天。所谓「表现良好时间段」，指「劳累的天数」严格大于时间段内总天数的一半。

返回「表现良好时间段」的最大长度。

**示例 1:**

```
输入: hours = [9,9,6,0,6,6,9]
输出: 3
解释: 最长的表现良好时间段是 [9,9,6]，长度为3。
```

**示例 2:**

```
输入: hours = [6,6,6]
输出: 0
```

**提示:**

- `1 <= hours.length <= 10^4`
- `0 <= hours[i] <= 16`

## 解题思路

这道题的关键是将问题转化为**前缀和 + 哈希表**问题。

**转化思路**：
1. 将劳累天(>8小时)标记为+1，不劳累天标记为-1
2. 问题变为：找最长子数组，使得子数组和 > 0
3. 使用前缀和，问题进一步转化为：找最远的两个位置 i < j，使得 `prefix[j] > prefix[i]`

**核心技巧**：
- 如果 `prefix[j] > 0`，说明 `[0, j]` 是表现良好的
- 如果 `prefix[j] <= 0`，需要找最左边的 i 使得 `prefix[i] < prefix[j]`
- 使用哈希表记录每个前缀和第一次出现的位置

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def longestWPI(self, hours: List[int]) -> int:
        n = len(hours)
        prefix_sum = 0  # 当前前缀和
        max_length = 0
        # 哈希表：记录每个前缀和第一次出现的位置
        first_occurrence = {}
        
        for i in range(n):
            # 转化：>8为+1，<=8为-1
            if hours[i] > 8:
                prefix_sum += 1
            else:
                prefix_sum -= 1
            
            # 如果前缀和>0，说明从0到i都是表现良好的
            if prefix_sum > 0:
                max_length = i + 1
            else:
                # 需要找到最左边的位置j，使得prefix[j] = prefix_sum - 1
                # 这样[j+1, i]的和就是1（大于0）
                if prefix_sum - 1 in first_occurrence:
                    max_length = max(max_length, i - first_occurrence[prefix_sum - 1])
            
            # 记录当前前缀和第一次出现的位置
            if prefix_sum not in first_occurrence:
                first_occurrence[prefix_sum] = i
        
        return max_length
```

### 方法二：单调栈

```python
class Solution:
    def longestWPI(self, hours: List[int]) -> int:
        n = len(hours)
        # 转化数组
        scores = [1 if h > 8 else -1 for h in hours]
        
        # 计算前缀和
        prefix = [0]
        for score in scores:
            prefix.append(prefix[-1] + score)
        
        # 构建单调递减栈（存储索引）
        stack = []
        for i in range(len(prefix)):
            if not stack or prefix[i] < prefix[stack[-1]]:
                stack.append(i)
        
        max_length = 0
        # 从右向左遍历，寻找最长区间
        for j in range(len(prefix) - 1, -1, -1):
            while stack and prefix[j] > prefix[stack[-1]]:
                i = stack.pop()
                max_length = max(max_length, j - i)
        
        return max_length
```

### 方法三：暴力枚举（超时但易理解）

```python
class Solution:
    def longestWPI(self, hours: List[int]) -> int:
        n = len(hours)
        max_length = 0
        
        # 枚举所有子数组
        for i in range(n):
            tired_days = 0
            for j in range(i, n):
                if hours[j] > 8:
                    tired_days += 1
                
                # 计算当前子数组长度
                length = j - i + 1
                # 判断是否表现良好
                if tired_days > length - tired_days:  # tired > non_tired
                    max_length = max(max_length, length)
        
        return max_length
```

## 复杂度分析

**方法一（哈希表）：**
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，哈希表最多存n个元素

**方法二（单调栈）：**
- 时间复杂度：O(n)，两次遍历
- 空间复杂度：O(n)，栈和前缀数组

**方法三（暴力）：**
- 时间复杂度：O(n²)，会超时
- 空间复杂度：O(1)

## 关键点总结

1. **问题转化**：劳累天+1，不劳累天-1，找和>0的最长子数组
2. **前缀和技巧**：将子数组和问题转化为两个前缀和的差
3. **哈希表优化**：记录每个前缀和第一次出现的位置
4. **关键观察**：如果当前前缀和为s，需要找s-1的最左位置（因为s-(s-1)=1>0）

## 易错点

1. **转化后的条件**：
   ```python
   # 错误：寻找prefix[j] > prefix[i]的任意i
   # 正确：寻找prefix[j] - prefix[i] > 0，即prefix[i] < prefix[j]
   # 特别地，当prefix[j] <= 0时，找prefix[i] = prefix[j] - 1
   ```

2. **哈希表存储时机**：
   ```python
   # 要在使用之后再更新哈希表，避免i=j的情况
   if prefix_sum - 1 in first_occurrence:
       max_length = max(max_length, i - first_occurrence[prefix_sum - 1])
   
   if prefix_sum not in first_occurrence:
       first_occurrence[prefix_sum] = i
   ```

3. **边界条件**：
   - 所有天都劳累：prefix_sum一直>0
   - 所有天都不劳累：max_length=0

## 图解示例

**示例: hours = [9,9,6,0,6,6,9]**

```
转化：         [1, 1,-1,-1,-1,-1, 1]
前缀和：    0  1  2  1  0 -1 -2 -1

索引:       -1  0  1  2  3  4  5  6

分析：
i=0: prefix=1 > 0 → max_length = 1
i=1: prefix=2 > 0 → max_length = 2
i=2: prefix=1 > 0 → max_length = 3 ✓
i=3: prefix=0, 找prefix=-1的位置 → 无
i=4: prefix=-1, 找prefix=-2的位置 → 无
i=5: prefix=-2, 找prefix=-3的位置 → 无
i=6: prefix=-1, 找prefix=-2的位置 → 5 → max_length = 6-5 = 1

答案：3
```
