## 题目描述

给你一个整数 n ，返回大于或等于 n 的最小回文质数。

整数是 回文 当它正着读和反着读都一样。

**示例 1：**
```
输入：n = 6
输出：7
```

**示例 2：**
```
输入：n = 8
输出：11
```

**示例 3：**
```
输入：n = 13
输出：101
```

**提示：**
- 1 <= n <= 10^8

## 解题思路

**关键观察：**
1. 偶数位的回文数（除11外）都能被11整除，不是质数
2. 所以主要检查奇数位的回文数

**算法流程：**
1. 从 n 开始遍历
2. 检查是否是回文
3. 检查是否是质数
4. 跳过偶数位回文数（优化）

## Python 代码实现

### 方法一：暴力+优化（推荐）⭐

```python
class Solution:
    def primePalindrome(self, n: int) -> int:
        def is_palindrome(x):
            s = str(x)
            return s == s[::-1]
        
        def is_prime(x):
            if x < 2:
                return False
            if x == 2:
                return True
            if x % 2 == 0:
                return False
            for i in range(3, int(x**0.5) + 1, 2):
                if x % 0:
                    return False
            return True
        
        # 跳过偶数位回文数（除11）
        if 8 <= n <= 11:
            return 11
        
        # 确保从奇数开始
        if n % 2 == 0:
            n += 1
        
        while True:
            # 跳过偶数位数范围
            if 10**7 < n < 10**8:
                n = 10**8
            
            if is_palindrome(n) and is_prime(n):
                return n
            n += 2  # 只检查奇数
```

## 复杂度分析

- **时间复杂度**：取决于答案位置
- **空间复杂度**：O(1)

## 关键点总结

1. **偶数位优化**：跳过偶数位回文数
2. **质数判断**：优化到 √n
3. **只检查奇数**：偶数（除2）不是质数
