## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，找到长度恰好为 `k` 的子数组中，不同元素数量最多的那个，返回该最大不同元素数量。

**示例 1：**

```
输入：nums = [1, 2, 1, 2, 3], k = 3
输出：3
解释：子数组 [1,2,3] 有 3 个不同元素。
```

**示例 2：**

```
输入：nums = [1, 1, 1, 1], k = 2
输出：1
解释：所有长度为 2 的子数组都只有 1 个不同元素。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

与 3825 相同：使用**滑动窗口 + 哈希表**统计每个固定大小窗口内的不同元素数，取最大值。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        n = len(nums)
        freq = defaultdict(int)
        distinct = 0
        ans = 0

        for i in range(n):
            c = nums[i]
            if freq[c] == 0:
                distinct += 1
            freq[c] += 1

            if i >= k:
                lc = nums[i - k]
                freq[lc] -= 1
                if freq[lc] == 0:
                    distinct -= 1
                    del freq[lc]

            if i >= k - 1:
                ans = max(ans, distinct)

        return ans
```

### 方法二：数组计数

```python
from typing import List

class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        n = len(nums)
        cnt = [0] * (max(nums) + 1)
        distinct = 0
        ans = 0

        for i in range(n):
            v = nums[i]
            if cnt[v] == 0:
                distinct += 1
            cnt[v] += 1

            if i >= k:
                lv = nums[i - k]
                cnt[lv] -= 1
                if cnt[lv] == 0:
                    distinct -= 1

            if i >= k - 1:
                ans = max(ans, distinct)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(min(k, max_val))

## 关键点总结

1. 固定大小 k 的滑动窗口，维护不同元素计数。
2. 加入右端时若为新元素则计数加 1；移除左端时若频率降为 0 则计数减 1。
3. 数组计数比哈希表速度快，但空间依赖值域大小。

## 易错点

1. 窗口大小 k 的判断：`i >= k - 1` 时记录（0-indexed）。
2. 移除左端字符时需先减少频率，再检查是否为 0。
