## 题目描述

给定一个整数数组 `nums` 和两个整数 `firstLen` 和 `secondLen`。

请你找出并返回两个非重叠子数组中元素的最大和，长度分别为 `firstLen` 和 `secondLen`。

长度为 `firstLen` 的子数组可以出现在长度为 `secondLen` 的子数组之前或之后，但二者必须不重叠。

子数组是数组的一个连续部分。

**示例 1：**

```
输入: nums = [0,6,5,2,2,5,1,9,4], firstLen = 1, secondLen = 2
输出: 20
解释: 一种选择是 [9] 长度为 1，和 [6,5] 长度为 2
```

**示例 2：**

```
输入: nums = [3,8,1,3,2,1,8,9,0], firstLen = 3, secondLen = 2
输出: 29
解释: 一种选择是 [3,8,1] 长度为 3，和 [8,9] 长度为 2
```

**示例 3：**

```
输入: nums = [2,1,5,6,0,9,5,0,3,8], firstLen = 4, secondLen = 3
输出: 31
解释: 一种选择是 [5,6,0,9] 长度为 4，和 [0,3,8] 长度为 3
```

**提示：**

- `1 <= firstLen, secondLen <= 1000`
- `2 <= firstLen + secondLen <= 1000`
- `firstLen + secondLen <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

## 解题思路

这道题的核心是找到两个不重叠的子数组使得它们的和最大。关键点：

1. **子数组的相对位置**：长度为 `firstLen` 的子数组可以在 `secondLen` 的左边或右边
2. **使用前缀和优化**：避免重复计算子数组和
3. **动态维护最大值**：遍历时记录当前位置左侧的最大子数组和

核心思想：
- 分两种情况：firstLen 的子数组在左边，或 secondLen 的子数组在左边
- 使用滑动窗口计算子数组和
- 动态维护左侧已遍历部分的最大子数组和

算法流程：
1. 计算前缀和数组，便于 O(1) 计算子数组和
2. 分别考虑两种情况（firstLen 在左 / secondLen 在左）
3. 从左到右遍历，维护左侧最大子数组和，计算当前位置的总和
4. 返回两种情况的最大值

## Python 代码实现

### 方法一：前缀和 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxSumTwoNoOverlap(self, nums: List[int], firstLen: int, secondLen: int) -> int:
        """
        使用前缀和和滑动窗口，分两种情况计算
        
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        n = len(nums)
        
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        # 辅助函数：计算 L 长度子数组在左，M 长度子数组在右的最大和
        def helper(L: int, M: int) -> int:
            max_sum = 0
            max_L = 0  # 左侧 L 长度子数组的最大和
            
            # 从位置 L+M 开始遍历（保证有足够空间放两个子数组）
            for i in range(L + M, n + 1):
                # 更新左侧 L 长度子数组的最大和
                # 当前可以选择的 L 长度子数组结束位置为 i-M
                max_L = max(max_L, prefix[i - M] - prefix[i - M - L])
                
                # 当前位置的 M 长度子数组和
                current_M = prefix[i] - prefix[i - M]
                
                # 更新最大总和
                max_sum = max(max_sum, max_L + current_M)
            
            return max_sum
        
        # 两种情况：firstLen 在左或 secondLen 在左
        return max(helper(firstLen, secondLen), helper(secondLen, firstLen))
```

### 方法二：一次遍历优化

```python
from typing import List

class Solution:
    def maxSumTwoNoOverlap(self, nums: List[int], firstLen: int, secondLen: int) -> int:
        """
        一次遍历同时考虑两种情况
        
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        n = len(nums)
        
        # 计算前缀和
        for i in range(1, n):
            nums[i] += nums[i - 1]
        
        result = nums[firstLen + secondLen - 1]
        max_first = nums[firstLen - 1]  # firstLen 在左侧时的最大和
        max_second = nums[secondLen - 1]  # secondLen 在左侧时的最大和
        
        for i in range(firstLen + secondLen, n):
            # firstLen 在左侧，secondLen 在右侧
            max_first = max(max_first, nums[i - secondLen] - nums[i - secondLen - firstLen])
            # secondLen 在左侧，firstLen 在右侧
            max_second = max(max_second, nums[i - firstLen] - nums[i - firstLen - secondLen])
            
            # 更新结果
            result = max(result, 
                        max_first + nums[i] - nums[i - secondLen],  # firstLen 在左
                        max_second + nums[i] - nums[i - firstLen])  # secondLen 在左
        
        return result
```

### 方法三：暴力解法（便于理解）

```python
from typing import List

class Solution:
    def maxSumTwoNoOverlap(self, nums: List[int], firstLen: int, secondLen: int) -> int:
        """
        暴力枚举所有可能的子数组组合
        
        时间复杂度: O(n^2)
        空间复杂度: O(1)
        """
        n = len(nums)
        max_sum = 0
        
        # 枚举第一个子数组的起始位置
        for i in range(n - firstLen + 1):
            first_sum = sum(nums[i:i + firstLen])
            
            # 枚举第二个子数组的起始位置（在第一个之前）
            for j in range(max(0, i - secondLen + 1)):
                if j + secondLen <= i:  # 确保不重叠
                    second_sum = sum(nums[j:j + secondLen])
                    max_sum = max(max_sum, first_sum + second_sum)
            
            # 枚举第二个子数组的起始位置（在第一个之后）
            for j in range(i + firstLen, n - secondLen + 1):
                second_sum = sum(nums[j:j + secondLen])
                max_sum = max(max_sum, first_sum + second_sum)
        
        return max_sum
```

### 方法四：动态规划

```python
from typing import List

class Solution:
    def maxSumTwoNoOverlap(self, nums: List[int], firstLen: int, secondLen: int) -> int:
        """
        动态规划方法，分别记录左右两侧的最大子数组和
        
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        n = len(nums)
        
        # 计算所有长度为 firstLen 的子数组和
        first_sums = []
        current_sum = sum(nums[:firstLen])
        first_sums.append(current_sum)
        for i in range(firstLen, n):
            current_sum = current_sum - nums[i - firstLen] + nums[i]
            first_sums.append(current_sum)
        
        # 计算所有长度为 secondLen 的子数组和
        second_sums = []
        current_sum = sum(nums[:secondLen])
        second_sums.append(current_sum)
        for i in range(secondLen, n):
            current_sum = current_sum - nums[i - secondLen] + nums[i]
            second_sums.append(current_sum)
        
        max_result = 0
        
        # firstLen 在左，secondLen 在右
        max_left = 0
        for i in range(len(second_sums)):
            if i >= firstLen:
                max_left = max(max_left, first_sums[i - secondLen])
                max_result = max(max_result, max_left + second_sums[i])
        
        # secondLen 在左，firstLen 在右
        max_left = 0
        for i in range(len(first_sums)):
            if i >= secondLen:
                max_left = max(max_left, second_sums[i - firstLen])
                max_result = max(max_result, max_left + first_sums[i])
        
        return max_result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力解法 | O(n²) | O(1) | 枚举所有组合，易于理解 |
| 前缀和 + 滑动窗口 | O(n) | O(n) | 使用前缀和优化，推荐 |
| 一次遍历优化 | O(n) | O(1) | 空间最优，原地修改数组 |
| 动态规划 | O(n) | O(n) | 思路清晰，易于扩展 |

## 关键点总结

1. 两个子数组可以有两种相对位置（firstLen 在左或在右）
2. 使用前缀和可以 O(1) 计算任意子数组和
3. 滑动窗口维护固定长度子数组的和
4. 动态维护左侧最大子数组和，避免重复计算
5. 分治思想：将问题分解为两种情况分别求解

## 易错点

1. **边界条件**：确保 `firstLen + secondLen <= n`
2. **不重叠判断**：两个子数组的索引范围不能有交集
3. **前缀和索引**：`prefix[i]` 表示前 i 个元素的和，注意索引偏移
4. **两种情况都要考虑**：不能只考虑一种顺序
5. **滑动窗口更新**：正确维护窗口内元素和的变化
