## 题目描述

有一个自行车手打算进行一场公路骑行，这条路线总共由 `n + 1` 个不同海拔点组成。自行车手从海拔为 `0` 的点 `0` 出发，给你一个长度为 `n` 的整数数组 `gain`，其中 `gain[i]` 是第 `i` 个和第 `i + 1` 个海拔之间的**净海拔变化**。

请你找出并返回最高点的**海拔**。

**示例 1：**
```
输入：gain = [-5,1,5,0,-7]
输出：1
```

**示例 2：**
```
输入：gain = [-4,-3,-2,-1,4,3,2]
输出：0
```

**提示：**
- `n == gain.length`
- `1 <= n <= 100`
- `-100 <= gain[i] <= 100`

## 解题思路

计算前缀和即为各点的海拔，取最大值。初始海拔为 0，每个后续点的海拔为前一点加上 `gain[i]`。

## 代码实现

### 方法一：遍历求前缀和最大值（推荐）

```python
from typing import List

class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        # 从海拔0出发，累计海拔变化
        current = 0
        max_alt = 0  # 起点海拔为 0，也要考虑进去
        
        for g in gain:
            current += g
            max_alt = max(max_alt, current)
        
        return max_alt
```

### 方法二：itertools.accumulate

```python
from typing import List
from itertools import accumulate

class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        # 起始点海拔 0，计算各点海拔的最大值
        altitudes = list(accumulate([0] + gain))
        return max(altitudes)
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历一次
- **空间复杂度**：O(1)（方法一）或 O(n)（方法二）

## 关键点总结

1. 前缀和即为各点海拔
2. 初始海拔 0 也要包含在最大值的候选中

## 易错点

- 起始点海拔为 0，最高点可能是出发点，要初始化 `max_alt = 0`
