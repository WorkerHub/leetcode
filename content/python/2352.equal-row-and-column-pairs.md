## 题目描述

给你一个下标从 **0** 开始、大小为 `n x n` 的整数矩阵 `grid`，返回满足 `R_i == C_j` 的行列对 `(R_i, C_j)` 的数目。

其中，`R_i` 是第 `i` 行，`C_j` 是第 `j` 列。若一行 `R_i` 与一列 `C_j` 的元素完全相同（顺序也相同），则认为该行与该列相等。

**示例 1：**
```
输入：grid = [[3,2,1],[1,7,6],[2,7,7]]
输出：1
```

**示例 2：**
```
输入：grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]
输出：3
```

**提示：**
- `n == grid.length == grid[i].length`
- `1 <= n <= 200`

## 解题思路

**哈希表计数：**
1. 将每一行转为元组，用哈希表统计各行元组出现次数。
2. 遍历每一列，将列转为元组，查询哈希表中是否存在相同元组。
3. 累加匹配次数。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def equalPairs(self, grid: List[List[int]]) -> int:
        n = len(grid)
        
        # 统计每一行（作为元组）的出现次数
        row_count = Counter(tuple(row) for row in grid)
        
        ans = 0
        # 遍历每一列
        for j in range(n):
            col = tuple(grid[i][j] for i in range(n))
            ans += row_count[col]  # 查找有多少行与该列相同
        
        return ans
```

### 方法二：暴力对比

```python
from typing import List

class Solution:
    def equalPairs(self, grid: List[List[int]]) -> int:
        n = len(grid)
        ans = 0
        
        for i in range(n):    # 枚举行
            for j in range(n):  # 枚举列
                # 逐元素比较行 i 和列 j
                if all(grid[i][k] == grid[k][j] for k in range(n)):
                    ans += 1
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n^2) | O(n^2) |
| 暴力 | O(n^3) | O(1) |

## 关键点总结

1. 将行和列都转换为元组后，用哈希表匹配，避免逐一比较。
2. `Counter` 对行进行计数，查询列时直接返回匹配数。
3. n <= 200 时暴力 O(n^3) 也可接受，但哈希表更优。

## 易错点

- 列的提取：第 j 列是 `[grid[i][j] for i in range(n)]`，注意行列下标顺序。
- 元组比较是按元素顺序的，与列表比较规则相同。
