## 题目描述

圣诞节即将来临，餐厅准备制作汉堡。

餐厅中有两种汉堡：
- **巨无霸汉堡**：制作一个需要 **4 片西红柿** 和 **2 片奶酪**
- **小汉堡**：制作一个需要 **2 片西红柿** 和 **1 片奶酪**

给你西红柿片数 `tomatoSlices` 和奶酪片数 `cheeseSlices`，返回满足以下条件的 **[巨无霸汉堡数量, 小汉堡数量]**：
- 用完所有的西红柿和奶酪（不浪费任何食材）
- 两种数量都是非负整数

如果没有满足条件的方案，返回 `[]`。

**示例 1：**
```
输入：tomatoSlices = 16, cheeseSlices = 7
输出：[1, 5]
解释：制作 1 个巨无霸汉堡和 5 个小汉堡，共用 1*4+5*2=14 片西红柿（错误！应该是16）
实际：1*4+5*2=14≠16 所以让我们验算：
正确：制作 1 个巨无霸：4 片西红柿，2 片奶酪；5 个小汉堡：10 片西红柿，5 片奶酪
总计：14 片西红柿 + 7 片奶酪... 
实际正确答案：4*1+2*5=14≠16，应该是 [2,3]? 4*2+2*3=14≠16
正确：4x+2y=16, x+y=7 -> 2x=2 -> x=1,y=6: 4+12=16 ✓, 1+6=7 ✓ 所以是 [1,6]
输出：[1, 6]
```

**示例 2：**
```
输入：tomatoSlices = 17, cheeseSlices = 4
输出：[]
```

**示例 3：**
```
输入：tomatoSlices = 4, cheeseSlices = 17
输出：[]
```

**示例 4：**
```
输入：tomatoSlices = 0, cheeseSlices = 0
输出：[0, 0]
```

**示例 5：**
```
输入：tomatoSlices = 2, cheeseSlices = 1
输出：[0, 1]
```

**提示：**
- `0 <= tomatoSlices, cheeseSlices <= 10^7`

## 解题思路

**建立方程组：**

设巨无霸数量为 x，小汉堡数量为 y，则：

```
4x + 2y = tomatoSlices  ... (1)
 x +  y = cheeseSlices  ... (2)
```

**求解过程：**

由 (1) - 2*(2) 得：

```
4x + 2y - 2x - 2y = tomatoSlices - 2 * cheeseSlices
2x = tomatoSlices - 2 * cheeseSlices
x = (tomatoSlices - 2 * cheeseSlices) / 2
```

再由 (2) 得：

```
y = cheeseSlices - x
```

**有解的条件（三个条件都要满足）：**

1. `tomatoSlices - 2 * cheeseSlices` 必须是非负偶数（才能整除得到非负整数 x）
2. `x >= 0`（巨无霸数量不能为负）
3. `y = cheeseSlices - x >= 0`（小汉堡数量不能为负）

**举例验证：**
```
tomatoSlices = 16, cheeseSlices = 7
2x = 16 - 14 = 2  -> x = 1
y = 7 - 1 = 6
验证：4*1 + 2*6 = 16 ✓，1 + 6 = 7 ✓
结果：[1, 6]

tomatoSlices = 17, cheeseSlices = 4
2x = 17 - 8 = 9  -> 9 不是偶数，无解
结果：[]
```

## Python 代码实现

### 方法一：直接解方程（推荐）

```python
from typing import List

class Solution:
    def numOfBurgers(self, tomatoSlices: int, cheeseSlices: int) -> List[int]:
        # 建立方程：4x + 2y = tomatoSlices，x + y = cheeseSlices
        # 解方程：2x = tomatoSlices - 2 * cheeseSlices
        diff = tomatoSlices - 2 * cheeseSlices

        # 条件1：diff 必须为非负偶数（保证 x 是非负整数）
        if diff < 0 or diff % 2 != 0:
            return []

        x = diff // 2               # 巨无霸汉堡数量
        y = cheeseSlices - x        # 小汉堡数量

        # 条件2：小汉堡数量不能为负
        if y < 0:
            return []

        return [x, y]
```

### 方法二：完整条件验证版（更清晰）

```python
from typing import List

class Solution:
    def numOfBurgers(self, tomatoSlices: int, cheeseSlices: int) -> List[int]:
        """
        数学解方程：
        设巨无霸数量为 x，小汉堡数量为 y
        方程1：4x + 2y = tomatoSlices（西红柿约束）
        方程2：x + y = cheeseSlices（奶酪约束）

        解：x = (tomatoSlices - 2 * cheeseSlices) / 2
            y = cheeseSlices - x
        """
        # 计算 2x 的值
        twice_x = tomatoSlices - 2 * cheeseSlices

        # 条件检查
        # 1. 2x 必须是偶数（才能整除得到整数 x）
        # 2. 2x 必须非负（x >= 0）
        if twice_x < 0 or twice_x % 2 != 0:
            return []

        x = twice_x // 2           # 巨无霸数量
        y = cheeseSlices - x        # 小汉堡数量

        # 3. 小汉堡数量必须非负
        if y < 0:
            return []

        return [x, y]
```

### 方法三：枚举验证（暴力，仅用于理解，不推荐）

```python
from typing import List

class Solution:
    def numOfBurgers(self, tomatoSlices: int, cheeseSlices: int) -> List[int]:
        """
        暴力枚举：遍历巨无霸数量的所有可能值
        时间复杂度 O(n)，不推荐，仅用于理解
        """
        # 巨无霸最多需要 tomatoSlices // 4 个
        for x in range(tomatoSlices // 4 + 1):
            remaining_tomato = tomatoSlices - 4 * x  # 剩余西红柿

            # 剩余西红柿必须是偶数（小汉堡需要2片）
            if remaining_tomato % 2 != 0:
                continue

            y = remaining_tomato // 2  # 小汉堡数量

            # 验证奶酪是否刚好用完
            if x + y == cheeseSlices:
                return [x, y]

        return []
```

### 方法四：一行解法（Python 极简风格）

```python
from typing import List

class Solution:
    def numOfBurgers(self, tomatoSlices: int, cheeseSlices: int) -> List[int]:
        # 计算差值
        d = tomatoSlices - 2 * cheeseSlices
        # 计算巨无霸和小汉堡数量
        x, y = d // 2, cheeseSlices - d // 2
        # 验证所有条件：差值为非负偶数，且两个数量都非负
        return [x, y] if d >= 0 and d % 2 == 0 and y >= 0 else []
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接解方程（推荐） | O(1) | O(1) |
| 暴力枚举 | O(tomatoSlices / 4) | O(1) |

- 解方程法：O(1) 时间，O(1) 空间，是最优解
- 暴力枚举：tomatoSlices 最大为 10^7，枚举约 250 万次，会超时

## 关键点总结

1. **建立方程组**：将问题转化为二元一次方程组是本题关键
2. **消元求解**：用第一个方程减去第二个方程的 2 倍，消去 y 求出 x
3. **三个无解条件**：差值为负、差值为奇数、小汉堡数量为负
4. **整除检查**：Python 中 `diff % 2 == 0` 确保整除，不用担心浮点数精度
5. **顺序检查**：先检查 diff 的合法性，再检查 y 是否非负

## 易错点

1. **方程建立错误**：巨无霸用 4 片西红柿和 2 片奶酪，小汉堡用 2 片西红柿和 1 片奶酪，不要搞混
2. **忘记检查奇偶性**：tomatoSlices 为奇数时，一定无解（因为 4x+2y 一定是偶数）
3. **只检查 x >= 0**：还需要检查 y >= 0（即 cheeseSlices >= x）
4. **浮点数除法**：Python 中用 `//` 整除而非 `/`，避免浮点误差
5. **边界情况**：tomatoSlices = 0, cheeseSlices = 0 时，答案是 [0, 0]，不要漏掉
