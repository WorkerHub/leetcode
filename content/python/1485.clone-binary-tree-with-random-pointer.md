## 题目描述

给你一棵二叉树，树上每个节点都有一个附加的随机指针，该指针可以指向树中的**任意节点**，也可以指向 `null`。

请返回该树的**深克隆**（即，克隆一棵与原树完全相同的树，且克隆树中没有指针指向原树的节点）。

树中每个节点的数据结构如下：

```
class Node {
    int val;
    Node left;
    Node right;
    Node random;
}
```

你的函数返回克隆树的根节点 `cloned`，使得克隆树与原树结构完全相同。

**提示：**
- 期望时间复杂度为 O(n)
- 不能修改原树
- 可以用树的节点数作为哈希表的键

---

## 解题思路

**核心思想：** 使用哈希表建立"原节点 -> 克隆节点"的映射，分两步处理：

**步骤：**
1. **第一步（DFS/BFS）**：遍历原树，为每个节点创建克隆节点（只设置 val，不设置指针），并存入哈希表 `mapping[orig] = clone`。
2. **第二步**：再次遍历，通过哈希表设置每个克隆节点的 `left`、`right`、`random` 指针。

**也可以一次 DFS 完成（递归版）：**
- 遇到一个节点，先检查哈希表是否已经克隆。
- 若未克隆，创建克隆节点，加入哈希表，然后递归设置 left、right、random。

## Python 代码实现

### 方法一：哈希表 + 两次 BFS（推荐）

```python
from typing import Optional
from collections import deque

# 定义节点结构
class Node:
    def __init__(self, val=0, left=None, right=None, random=None):
        self.val = val
        self.left = left
        self.right = right
        self.random = random

class Solution:
    def copyRandomBinaryTree(self, root: Optional[Node]) -> Optional[Node]:
        if not root:
            return None

        # 哈希表：原节点 -> 克隆节点
        mapping = {}

        # 第一步：BFS 遍历，创建所有克隆节点（只设置 val）
        queue = deque([root])
        while queue:
            node = queue.popleft()
            mapping[node] = Node(node.val)  # 创建克隆节点

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        # 第二步：BFS 再次遍历，设置 left、right、random 指针
        queue = deque([root])
        visited = set()
        while queue:
            node = queue.popleft()
            if node in visited:
                continue
            visited.add(node)

            clone = mapping[node]  # 对应的克隆节点

            # 设置左子节点
            if node.left:
                clone.left = mapping[node.left]
                queue.append(node.left)

            # 设置右子节点
            if node.right:
                clone.right = mapping[node.right]
                queue.append(node.right)

            # 设置随机指针
            if node.random:
                clone.random = mapping[node.random]

        return mapping[root]
```

### 方法二：哈希表 + 递归 DFS（一次遍历）

```python
from typing import Optional

class Solution:
    def copyRandomBinaryTree(self, root: Optional[Node]) -> Optional[Node]:
        # 哈希表缓存已克隆的节点
        memo = {}

        def clone(node: Optional[Node]) -> Optional[Node]:
            if node is None:
                return None

            # 如果已经克隆过，直接返回（处理 random 指针的环）
            if node in memo:
                return memo[node]

            # 创建克隆节点
            cloned = Node(node.val)
            memo[node] = cloned  # 先加入哈希表，再递归（防止无限循环）

            # 递归克隆左右子节点和随机指针
            cloned.left = clone(node.left)
            cloned.right = clone(node.right)
            cloned.random = clone(node.random)

            return cloned

        return clone(root)
```

### 方法三：迭代 DFS（栈模拟）

```python
from typing import Optional

class Solution:
    def copyRandomBinaryTree(self, root: Optional[Node]) -> Optional[Node]:
        if not root:
            return None

        memo = {}

        def get_clone(node: Optional[Node]) -> Optional[Node]:
            """获取节点的克隆，若不存在则创建"""
            if node is None:
                return None
            if node not in memo:
                memo[node] = Node(node.val)
            return memo[node]

        stack = [root]
        get_clone(root)  # 创建根节点的克隆

        while stack:
            node = stack.pop()
            clone = memo[node]

            # 设置左子节点
            if node.left:
                clone.left = get_clone(node.left)
                stack.append(node.left)

            # 设置右子节点
            if node.right:
                clone.right = get_clone(node.right)
                stack.append(node.right)

            # 设置随机指针
            if node.random:
                clone.random = get_clone(node.random)

        return memo[root]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 两次 BFS | O(n) | O(n) |
| 递归 DFS（哈希表） | O(n) | O(n)（递归栈 + 哈希表） |
| 迭代 DFS | O(n) | O(n) |

- 所有方法遍历每个节点恰好一次，时间 O(n)。
- 哈希表存储 n 个映射关系，空间 O(n)。

## 关键点总结

1. **哈希表**是克隆带随机指针树的核心工具，建立"原节点 -> 克隆节点"的映射。
2. **先加入哈希表，再处理子节点和随机指针**：防止 random 指针形成环导致无限递归（在递归版本中尤为重要）。
3. 处理 `random` 指针和处理 `left`/`right` 的方式完全相同——通过哈希表查找对应的克隆节点。
4. 返回 `mapping[root]` 或 `memo[root]` 作为克隆树的根。

---

## 易错点

- **先加入哈希表再递归**：在方法二中，`memo[node] = cloned` 必须在递归之前执行，否则若 `random` 指向祖先节点，会导致无限递归。
- **None 处理**：`clone(None)` 返回 `None`，随机指针可能为 `None`。
- **不修改原树**：所有操作只在克隆节点上进行，不改变原节点的指针。
