## 题目描述

给出二叉树的根节点 `root`，树中每个节点都有一个不同的值。

如果节点值在 `to_delete` 中出现，我们就把该节点从树上删除，最后得到一个森林（一些不相交的树构成的集合）。

返回森林中的每棵树。你可以按任意顺序返回结果。

**示例 1：**

![](https://assets.leetcode.com/uploads/2019/07/01/screen-shot-2019-07-01-at-53836-pm.png)

```
输入：root = [1,2,3,4,5,6,7], to_delete = [3,5]
输出：[[1,2,null,4],[6],[7]]
解释：删除节点 3 和 5 后，形成三棵树
```

**示例 2：**
```
输入：root = [1,2,4,null,3], to_delete = [3]
输出：[[1,2,4]]
```

**提示：**
- 树中的节点数最大为 `1000`
- 每个节点都有一个在 `1` 到 `1000` 之间的值，且互不相同
- `to_delete.length <= 1000`
- `to_delete` 包含在 `1` 到 `1000` 之间的值，且互不相同

## 解题思路

这道题需要删除指定节点后，返回形成的森林。关键在于理解什么时候会产生新的树根。

**核心观察：**
1. **新树根的产生条件**：
   - 原来的根节点如果不被删除，它就是一棵树的根
   - 如果一个节点的父节点被删除了，且该节点本身不被删除，它会成为新树的根

2. **删除节点的影响**：
   - 删除一个节点后，它的左右子树会断开
   - 如果子节点不在删除列表中，它们会成为新的独立树

**解题步骤：**
1. 使用 DFS 遍历整棵树
2. 对于每个节点：
   - 如果需要删除，将其左右子树（如果不为空且不被删除）加入结果
   - 如果不删除，保持父子关系
3. 处理根节点：如果根节点不被删除，加入结果

## Python 代码实现

### 方法一：递归 DFS（推荐）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def delNodes(self, root: Optional[TreeNode], to_delete: List[int]) -> List[TreeNode]:
        # 将 to_delete 转换为集合，提高查找效率
        to_delete_set = set(to_delete)
        forest = []
        
        def dfs(node: Optional[TreeNode], is_root: bool) -> Optional[TreeNode]:
            """
            DFS 遍历树
            node: 当前节点
            is_root: 当前节点是否可能成为树根
            返回: 处理后的节点（如果被删除则返回 None）
            """
            if not node:
                return None
            
            # 判断当前节点是否需要删除
            deleted = node.val in to_delete_set
            
            # 如果当前节点是根且不被删除，加入森林
            if is_root and not deleted:
                forest.append(node)
            
            # 递归处理左右子树
            # 如果当前节点被删除，左右子节点可能成为新的根
            node.left = dfs(node.left, deleted)
            node.right = dfs(node.right, deleted)
            
            # 如果当前节点被删除，返回 None（断开与父节点的连接）
            return None if deleted else node
        
        dfs(root, True)
        return forest
```

### 方法二：递归（分离收集逻辑）

```python
from typing import List, Optional

class Solution:
    def delNodes(self, root: Optional[TreeNode], to_delete: List[int]) -> List[TreeNode]:
        to_delete_set = set(to_delete)
        forest = []
        
        def helper(node: Optional[TreeNode]) -> Optional[TreeNode]:
            """返回处理后的节点"""
            if not node:
                return None
            
            # 先递归处理子节点
            node.left = helper(node.left)
            node.right = helper(node.right)
            
            # 如果当前节点需要删除
            if node.val in to_delete_set:
                # 将不为空的子节点加入森林
                if node.left:
                    forest.append(node.left)
                if node.right:
                    forest.append(node.right)
                # 返回 None 表示删除当前节点
                return None
            
            # 不删除则返回节点本身
            return node
        
        # 处理根节点
        root = helper(root)
        if root:
            forest.append(root)
        
        return forest
```

### 方法三：迭代（使用栈）

```python
from typing import List, Optional

class Solution:
    def delNodes(self, root: Optional[TreeNode], to_delete: List[int]) -> List[TreeNode]:
        if not root:
            return []
        
        to_delete_set = set(to_delete)
        forest = []
        
        # 使用栈进行 DFS，存储 (节点, 父节点, 是否为左子节点)
        stack = [(root, None, False)]
        
        while stack:
            node, parent, is_left = stack.pop()
            
            if not node:
                continue
            
            # 判断是否删除当前节点
            if node.val in to_delete_set:
                # 如果删除，需要将子节点入栈，且它们可能成为新根
                if node.left:
                    stack.append((node.left, None, False))
                if node.right:
                    stack.append((node.right, None, False))
                
                # 断开父节点的连接
                if parent:
                    if is_left:
                        parent.left = None
                    else:
                        parent.right = None
            else:
                # 不删除
                # 如果没有父节点，说明是根节点
                if not parent:
                    forest.append(node)
                
                # 处理子节点
                if node.left:
                    stack.append((node.left, node, True))
                if node.right:
                    stack.append((node.right, node, False))
        
        return forest
```

### 方法四：后序遍历（清晰版）

```python
from typing import List, Optional

class Solution:
    def delNodes(self, root: Optional[TreeNode], to_delete: List[int]) -> List[TreeNode]:
        to_delete_set = set(to_delete)
        result = []
        
        def postorder(node: Optional[TreeNode], has_parent: bool) -> Optional[TreeNode]:
            """
            后序遍历
            has_parent: 当前节点是否有有效的父节点
            """
            if not node:
                return None
            
            # 后序遍历：先处理子节点
            node.left = postorder(node.left, node.val not in to_delete_set)
            node.right = postorder(node.right, node.val not in to_delete_set)
            
            # 如果当前节点要被删除
            if node.val in to_delete_set:
                # 子节点（如果存在）会成为新的根
                # 它们已经在递归中被添加到结果
                return None
            else:
                # 如果当前节点没有父节点，它是一个根
                if not has_parent:
                    result.append(node)
                return node
        
        postorder(root, False)
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是树中节点的数量，每个节点访问一次
- 空间复杂度：O(n + m)
  - O(n) 递归调用栈或显式栈的空间
  - O(m) to_delete_set 的空间，m 是 to_delete 的长度

## 图解示例

以 `root = [1,2,3,4,5,6,7], to_delete = [3,5]` 为例：

```
原始树：
        1
       / \
      2   3
     / \ / \
    4  5 6  7

删除节点 3 和 5：

步骤1：遍历到节点 5（值在 to_delete 中）
       - 节点 5 被删除，没有子节点

步骤2：遍历到节点 3（值在 to_delete 中）
       - 节点 3 被删除
       - 左子节点 6 成为新根（加入 forest）
       - 右子节点 7 成为新根（加入 forest）

步骤3：节点 2 保留
       - 左子节点 4 保留
       - 右子节点 5 已被删除（设为 None）

步骤4：节点 1 是原根，不被删除
       - 保留在 forest 中

最终森林：
    1          6        7
   /
  2
 /
4

结果：[[1,2,null,4], [6], [7]]
```

## 关键点总结

1. **后序遍历的重要性**：必须先处理子节点，再处理当前节点，这样才能正确断开连接
2. **新根的识别**：
   - 原根节点如果不被删除
   - 被删除节点的非空子节点
3. **使用集合优化查找**：将 `to_delete` 转为集合，查找时间从 O(m) 降到 O(1)
4. **返回值的意义**：递归函数返回 None 表示删除该节点，实现自动断开连接
5. **is_root 参数的作用**：标识当前节点是否可能成为树根

## 易错点

1. **遍历顺序错误**：使用前序遍历会导致无法正确处理子树
2. **忘记断开连接**：删除节点后没有将父节点的指针设为 None
3. **重复添加根节点**：同一个节点被添加多次到结果中
4. **边界情况**：
   - 根节点被删除
   - 所有节点都被删除
   - to_delete 为空
5. **集合转换**：忘记将 to_delete 转为集合，导致查找效率低下
