## 题目描述

Alice 和 Bob 玩字符串游戏。Alice 从 `word = "a"` 开始，Bob 给出一个操作数组 `operations`：
- `operations[i] = 0`：将 `word` 中每个字符不变地追加到末尾（复制）。
- `operations[i] = 1`：将 `word` 中每个字符替换为字母表中下一个字符（'z' -> 'a'）后追加到末尾。

每次操作后，`word` 的长度翻倍。给你整数 `k`，返回第 `k` 个字符（1 索引）。

**示例 1：**
```
输入：k = 5, operations = [0, 0, 0]
输出：'a'
解释：每次操作都是复制，所有字符都是 'a'
```

**示例 2：**
```
输入：k = 10, operations = [0, 1, 0, 1]
输出：'b'
```

**提示：**
- `1 <= k <= 10^14`
- `1 <= operations.length <= 100`
- `operations[i]` 为 0 或 1
- 操作次数保证 `2^len(operations) >= k`

## 解题思路

**递归向上追溯：**

由于每次操作字符串长度翻倍，第 `k` 个字符（1 索引，转为 0 索引为 `k-1`）来自于某次操作。

逆向思考：
1. 从第 `t` 次操作开始，当前字符串长度为 `2^t`。
2. 如果第 `k`（0 索引）个字符在后半段（`k >= 2^(t-1)`），则它由第 `t` 次操作从前半段位置 `k - 2^(t-1)` 产生：
   - 若 `operations[t-1] == 0`（复制），字符不变。
   - 若 `operations[t-1] == 1`（下移），字符偏移量加 1。
3. 如果在前半段，递归处理前半段。

最终，位置 0 的字符是 'a'，总偏移量对 26 取模得到最终字符。

## Python 代码实现

### 方法一：递归追溯（推荐）

```python
class Solution:
    def kthCharacter(self, k: int, operations: List[int]) -> str:
        # 计算偏移量（每次被"操作1"影响就加1）
        offset = 0
        k -= 1  # 转为 0 索引
        
        # 从最后一次操作往前追溯
        for i in range(len(operations) - 1, -1, -1):
            length = 1 << i  # 第 i 次操作后，前半段长度为 2^i
            if k >= length:
                # 第 k 个字符在后半段，来自前半段位置 k - length
                k -= length
                offset += operations[i]  # 若 op=1，则偏移+1
            # 若在前半段，继续往上追溯（k 不变）
        
        return chr(ord('a') + offset % 26)
```

### 方法二：位操作分析

```python
from typing import List

class Solution:
    def kthCharacter(self, k: int, operations: List[int]) -> str:
        k -= 1  # 0 索引
        offset = 0
        
        # 找到需要多少次操作才能覆盖 k+1 个字符
        t = 0
        while (1 << t) <= k:
            t += 1
        # t 是需要的操作次数
        
        for i in range(t - 1, -1, -1):
            if k >= (1 << i):
                k -= (1 << i)
                if i < len(operations):
                    offset += operations[i]
        
        return chr(ord('a') + offset % 26)
```

## 复杂度分析

- 时间复杂度：O(log k)，最多追溯 log k 次
- 空间复杂度：O(1)

## 关键点总结

1. 字符串每次翻倍，第 `k` 个字符如果在后半段，必定来自前半段某个字符经过一次操作变换而来。
2. 倒序追溯时，记录操作类型为 1 的累计次数即偏移量。
3. 最终字符 = `chr(ord('a') + offset % 26)`。

## 易错点

1. `k` 需要转为 0 索引再处理。
2. 追溯时 `length = 1 << i`，注意 `i` 从 `len(operations)-1` 开始而不是从 0。
3. `offset % 26` 处理 'z' 后循环的情况。
