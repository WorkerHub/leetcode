## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据保证数组 `nums` 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位整数范围内。

请不要使用除法，且在 O(n) 时间复杂度内完成此题。

**示例 1：**
```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
```

**示例 2：**
```
输入: nums = [-1,1,0,-3,3]
输出: [0,0,9,0,0]
```

**提示：**
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- 保证数组 `nums` 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位整数范围内

**进阶：** 你可以在 O(1) 的额外空间复杂度内完成这个题目吗？（出于对空间复杂度分析的目的，输出数组不被视为额外空间。）

## 解题思路

这道题的核心挑战是：**不能使用除法**，且时间复杂度要求 O(n)。

**朴素思路（使用除法）：**
- 计算所有元素的乘积 `total`
- 对于每个位置 i，`answer[i] = total / nums[i]`
- 但题目不允许使用除法，且当有 0 时会出错

**优化思路：前缀积 + 后缀积**

对于位置 i，`answer[i]` = 左边所有数的乘积 × 右边所有数的乘积

**方法：**
1. **左边乘积**：计算 i 左边所有元素的乘积
2. **右边乘积**：计算 i 右边所有元素的乘积
3. **结果**：`answer[i] = left[i] * right[i]`

**示例分析（nums = [1, 2, 3, 4]）：**

```
位置:     0   1   2   3
nums:     1   2   3   4

左边积:   1   1   2   6
         (无) (1) (1×2) (1×2×3)

右边积:  24  12   4   1
      (2×3×4)(3×4) (4) (无)

结果:    24  12   8   6
       (1×24)(1×12)(2×4)(6×1)
```

## Python 代码实现

### 方法一：两个数组（空间 O(n)）

```python
from typing import List

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        使用两个数组分别存储左边和右边的乘积
        """
        n = len(nums)
        
        # left[i] 表示 i 左边所有元素的乘积
        left = [1] * n
        # right[i] 表示 i 右边所有元素的乘积
        right = [1] * n
        
        # 计算左边的乘积
        for i in range(1, n):
            left[i] = left[i - 1] * nums[i - 1]
        
        # 计算右边的乘积
        for i in range(n - 2, -1, -1):
            right[i] = right[i + 1] * nums[i + 1]
        
        # 计算最终结果
        answer = [left[i] * right[i] for i in range(n)]
        
        return answer
```

### 方法二：一个数组 + 一个变量（空间 O(1)）⭐

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        优化空间：使用输出数组存储左边乘积，用变量存储右边乘积
        时间复杂度：O(n)
        空间复杂度：O(1)（不计输出数组）
        """
        n = len(nums)
        answer = [1] * n
        
        # 第一遍：计算左边的乘积，存储在 answer 中
        left = 1
        for i in range(n):
            answer[i] = left
            left *= nums[i]
        
        # 第二遍：计算右边的乘积，直接乘到 answer 上
        right = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= right
            right *= nums[i]
        
        return answer
```

### 方法三：使用除法（不符合题意，仅供理解）

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        使用除法的方法（题目不允许）
        需要处理 0 的特殊情况
        """
        n = len(nums)
        
        # 统计 0 的个数
        zero_count = nums.count(0)
        
        # 如果有 2 个或以上的 0，所有结果都是 0
        if zero_count > 1:
            return [0] * n
        
        # 如果有 1 个 0
        if zero_count == 1:
            # 计算非 0 元素的乘积
            product = 1
            for num in nums:
                if num != 0:
                    product *= num
            
            # 只有 0 的位置结果不为 0
            return [product if num == 0 else 0 for num in nums]
        
        # 没有 0，直接计算总乘积再除以当前元素
        total = 1
        for num in nums:
            total *= num
        
        return [total // num for num in nums]
```

### 方法四：详细注释版（推荐学习）

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        前缀积和后缀积的应用
        """
        n = len(nums)
        answer = [1] * n
        
        # 步骤 1：从左到右，计算每个位置左边所有数的乘积
        # answer[i] 存储 nums[0] * nums[1] * ... * nums[i-1]
        left_product = 1
        for i in range(n):
            answer[i] = left_product  # 先赋值左边的乘积
            left_product *= nums[i]    # 更新乘积，包含当前元素
        
        # 此时 answer = [1, 1, 2, 6]（对于 nums = [1,2,3,4]）
        
        # 步骤 2：从右到左，计算每个位置右边所有数的乘积
        # 并乘到 answer[i] 上
        right_product = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= right_product  # 乘上右边的乘积
            right_product *= nums[i]     # 更新乘积，包含当前元素
        
        # 此时 answer = [24, 12, 8, 6]
        
        return answer
```

## 复杂度分析

**方法一（两个数组）：**
- 时间复杂度：O(n)，遍历数组三次
- 空间复杂度：O(n)，需要两个额外数组

**方法二（一个数组 + 变量）：**
- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)，不计输出数组，只用了两个变量

## 图解示例

```
nums = [1, 2, 3, 4]

步骤 1：计算左边乘积（从左到右）
i=0: answer[0] = 1 (左边无元素)，left = 1 × 1 = 1
i=1: answer[1] = 1 (左边是 1)，left = 1 × 2 = 2
i=2: answer[2] = 2 (左边是 1×2)，left = 2 × 3 = 6
i=3: answer[3] = 6 (左边是 1×2×3)，left = 6 × 4 = 24

此时 answer = [1, 1, 2, 6]

步骤 2：计算右边乘积（从右到左）
i=3: answer[3] = 6 × 1 = 6 (右边无元素)，right = 1 × 4 = 4
i=2: answer[2] = 2 × 4 = 8 (右边是 4)，right = 4 × 3 = 12
i=1: answer[1] = 1 × 12 = 12 (右边是 3×4)，right = 12 × 2 = 24
i=0: answer[0] = 1 × 24 = 24 (右边是 2×3×4)，right = 24 × 1 = 24

最终 answer = [24, 12, 8, 6]
```

## 关键点总结

1. **前缀积思想**：类似前缀和，维护左边元素的乘积
2. **后缀积思想**：维护右边元素的乘积
3. **空间优化**：用输出数组存储中间结果，用变量代替数组
4. **两次遍历**：第一次从左到右，第二次从右到左
5. **初始值为 1**：乘法的单位元是 1

## 易错点

1. **循环边界**：
   ```python
   # 从右到左遍历时的边界
   for i in range(n - 1, -1, -1):  # 正确
   for i in range(n - 2, -1, -1):  # 错误，会漏掉第一个元素
   ```

2. **更新顺序**：
   ```python
   # 错误：先更新再赋值
   left *= nums[i]
   answer[i] = left  # 这样会包含 nums[i]
   
   # 正确：先赋值再更新
   answer[i] = left
   left *= nums[i]
   ```

3. **初始值**：
   ```python
   # left 和 right 的初始值应该是 1，不是 0
   left = 1  # 正确
   left = 0  # 错误，乘法会全变成 0
   ```

4. **理解题意**：
   - "除自身以外" 不是除法，而是左边乘积 × 右边乘积
   - 不要被 "除" 字误导

5. **处理 0**：
   - 前缀积方法自动处理了 0 的情况
   - 不需要特殊处理
