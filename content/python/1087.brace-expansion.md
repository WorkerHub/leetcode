## 题目描述

此题为 LeetCode Premium 题目。

给定一个表示单词列表的字符串 `s`，单词中的每个字母有一个或多个选项。

- 如果只有一个选项，则字母直接出现
- 如果有多个选项，则用花括号 `{a,b,c}` 分隔选项

例如，字符串 `"{a,b}c{d,e}f"` 表示单词列表 `["acdf","acef","bcdf","bcef"]`。

返回按**字典序**排列的所有可能单词。

**示例 1：**
```
输入：s = "{a,b}c{d,e}f"
输出：["acdf","acef","bcdf","bcef"]
```

**示例 2：**
```
输入：s = "abcd"
输出：["abcd"]
```

**提示：**
- `1 <= s.length <= 50`
- `s` 由字母、花括号 `{}`、逗号 `,` 组成
- 所有选项都是小写字母
- 结果按字典序返回

## 解题思路

这是一道**回溯 + 字符串处理**问题。

### 核心思路

1. **解析字符串**：
   - 识别普通字符（直接选择）
   - 识别花括号中的选项（多选一）

2. **构建选项列表**：
   - 将字符串解析为选项组：`[[a,b], [c], [d,e], [f]]`
   - 每个位置可能有一个或多个选项

3. **回溯生成**：
   - 对每个位置，遍历所有选项
   - 递归生成后续字符
   - 收集所有可能的单词

4. **排序输出**：
   - 如果每个花括号内的选项已按字典序排列，递归生成的结果自然有序
   - 否则需要最后排序

## Python 代码实现

### 方法一：解析 + 回溯（推荐）

```python
from typing import List

class Solution:
    def expand(self, s: str) -> List[str]:
        # 解析字符串，构建选项列表
        options = []
        i = 0
        
        while i < len(s):
            if s[i] == '{':
                # 找到匹配的 }
                j = i
                while s[j] != '}':
                    j += 1
                # 提取选项并排序
                choices = sorted(s[i+1:j].split(','))
                options.append(choices)
                i = j + 1
            else:
                # 单个字符
                options.append([s[i]])
                i += 1
        
        # 回溯生成所有单词
        result = []
        
        def backtrack(index: int, current: str):
            if index == len(options):
                result.append(current)
                return
            
            for char in options[index]:
                backtrack(index + 1, current + char)
        
        backtrack(0, "")
        return result
```

### 方法二：迭代生成（笛卡尔积）

```python
from typing import List
from itertools import product

class Solution:
    def expand(self, s: str) -> List[str]:
        # 解析选项
        options = []
        i = 0
        
        while i < len(s):
            if s[i] == '{':
                j = i
                while s[j] != '}':
                    j += 1
                choices = sorted(s[i+1:j].split(','))
                options.append(choices)
                i = j + 1
            else:
                options.append([s[i]])
                i += 1
        
        # 使用 itertools.product 生成笛卡尔积
        result = [''.join(combination) for combination in product(*options)]
        
        return result
```

### 方法三：BFS（广度优先）

```python
from typing import List
from collections import deque

class Solution:
    def expand(self, s: str) -> List[str]:
        # 解析选项
        options = []
        i = 0
        
        while i < len(s):
            if s[i] == '{':
                j = i
                while s[j] != '}':
                    j += 1
                choices = sorted(s[i+1:j].split(','))
                options.append(choices)
                i = j + 1
            else:
                options.append([s[i]])
                i += 1
        
        # BFS 生成
        queue = deque([''])
        
        for option_group in options:
            new_queue = deque()
            while queue:
                prefix = queue.popleft()
                for char in option_group:
                    new_queue.append(prefix + char)
            queue = new_queue
        
        return sorted(list(queue))
```

### 方法四：递归生成（简洁版）

```python
from typing import List

class Solution:
    def expand(self, s: str) -> List[str]:
        def parse_and_generate(s: str) -> List[str]:
            if not s:
                return ['']
            
            if s[0] == '{':
                # 找到匹配的 }
                end = s.index('}')
                choices = sorted(s[1:end].split(','))
                # 递归生成剩余部分
                suffixes = parse_and_generate(s[end+1:])
                return [c + suffix for c in choices for suffix in suffixes]
            else:
                # 单个字符
                suffixes = parse_and_generate(s[1:])
                return [s[0] + suffix for suffix in suffixes]
        
        return parse_and_generate(s)
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n × m^k)
  - n 是字符串长度
  - m 是每个选项组的平均选项数
  - k 是选项组的数量
  - 生成的单词数量为 m^k
- **空间复杂度**：O(m^k)
  - 存储所有生成的单词

## 关键点总结

1. **字符串解析**：正确识别花括号和普通字符
2. **选项排序**：对每个选项组内部排序，确保字典序
3. **回溯模板**：每个位置选择一个选项，递归后续
4. **笛卡尔积**：本质上是多个集合的笛卡尔积
5. **itertools.product**：Python 标准库提供的笛卡尔积工具

## 易错点

1. **花括号匹配**：简单题目中不会有嵌套，直接找 `}`
2. **选项分割**：使用逗号分割选项
3. **排序时机**：每个选项组内部排序，而不是最后排序所有结果
4. **空字符串**：递归基础情况要正确处理
5. **字符串拼接**：注意字符串不可变，拼接会创建新对象
