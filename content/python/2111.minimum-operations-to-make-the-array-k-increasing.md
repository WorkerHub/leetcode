## 题目描述

给你一个下标从 **0** 开始的数组 `arr`，以及一个正整数 `k`。

如果对于每个满足 `k <= i <= arr.length - 1` 的下标 `i`，都有 `arr[i-k] <= arr[i]`，那么我们称 `arr` 是 `k` 递增的。

每次操作中，你可以选择一个下标 `i` 并将 `arr[i]` 改为任意值。

返回使 `arr` 变成 **k 递增**所需的**最少操作次数**。

**示例 1：**
```
输入：arr = [5,4,3,2,1], k = 1
输出：4
解释：k=1 时要求整个数组不降序，最少修改 4 个元素。
```

**示例 2：**
```
输入：arr = [4,1,5,2,6,2], k = 2
输出：0
解释：arr[0]=4,arr[2]=5,arr[4]=6 递增；arr[1]=1,arr[3]=2,arr[5]=2 不严格递减但满足不降，已是 k 递增。
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i], k <= arr.length`

## 解题思路

**拆分子序列 + LIS（最长不递减子序列）**

将 `arr` 按步长 `k` 拆成 `k` 个子序列：
- 子序列 0：`arr[0], arr[k], arr[2k], ...`
- 子序列 1：`arr[1], arr[k+1], arr[2k+1], ...`
- ...
- 子序列 k-1：`arr[k-1], arr[2k-1], ...`

每个子序列需要满足**不递减**。最少操作次数 = 子序列长度 - 该子序列的**最长不递减子序列（LIS）**长度。

对每个子序列求 LIS，修改 = 子序列长度 - LIS 长度。

**LIS 算法（patience sorting）：** 用二分查找维护 `tails` 数组，时间 O(m log m)。

## 代码实现

### 方法一：分组求 LIS（推荐）

```python
from typing import List
import bisect

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        def lis_length(seq: List[int]) -> int:
            # 求最长不递减子序列（允许相等）
            tails = []
            for x in seq:
                # 找第一个 > x 的位置（允许相等，故用 bisect_right）
                pos = bisect.bisect_right(tails, x)
                if pos == len(tails):
                    tails.append(x)
                else:
                    tails[pos] = x
            return len(tails)

        total_ops = 0
        for start in range(k):
            # 提取第 start 个子序列
            subseq = arr[start::k]
            # 最少修改次数 = 子序列长度 - 最长不递减子序列长度
            total_ops += len(subseq) - lis_length(subseq)
        return total_ops
```

### 方法二：更清晰的 LIS 实现

```python
from typing import List
import bisect

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        def min_changes_to_non_decreasing(seq: List[int]) -> int:
            """
            计算使 seq 变成不递减序列所需的最少改动次数
            等于 len(seq) - 最长不递减子序列(LNDS)长度
            """
            # patience sort：tails[i] 是长度为 i+1 的不递减子序列的最小末尾
            tails = []
            for val in seq:
                # 找第一个严格大于 val 的位置
                idx = bisect.bisect_right(tails, val)
                if idx == len(tails):
                    tails.append(val)
                else:
                    tails[idx] = val
            return len(seq) - len(tails)

        ans = 0
        for i in range(k):
            ans += min_changes_to_non_decreasing(arr[i::k])
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| LIS + 二分 | O(n log n) | O(n) |

- 共 k 个子序列，每个长度约 n/k，LIS 复杂度 O((n/k) log(n/k))，共 O(n log n)。

## 关键点总结

1. 按步长 k 将数组拆成 k 个独立子序列，各子序列互不影响。
2. 每个子序列求**最长不递减子序列**（非严格递增），注意用 `bisect_right`。
3. 最少操作数 = 子序列长度 - LIS 长度（保留 LIS，其余全改）。

## 易错点

- 是**不递减**（允许相等），不是严格递增。因此 LIS 中查找时用 `bisect_right` 而非 `bisect_left`。
- Python 的 `arr[i::k]` 切片直接获取子序列，非常方便。
