## 题目描述

你正在安装一个广告牌，并希望它高度最大。这块广告牌将有两个钢制支架，两边各一个。每个钢支架的高度必须相等。

你有一堆可以焊接在一起的钢筋 `rods`。举个例子，如果钢筋的长度为 `1`、`2` 和 `3`，则可以将它们焊接在一起形成长度为 `6` 的支架。

返回广告牌的最大可能安装高度。如果没法安装广告牌，请返回 `0`。

**示例 1：**
```
输入：rods = [1,2,3,6]
输出：6
解释：我们有两个支架，长度分别为 1+2+3=6 和 6
```

**示例 2：**
```
输入：rods = [1,2,3,4,5,6]
输出：10
解释：我们有两个支架，长度分别为 1+2+3+4=10 和 5+6=11，但是我们只能得到长度 10，因为我们需要两个等长的支架
```

**示例 3：**
```
输入：rods = [1,2]
输出：0
解释：无法让两个支架等高
```

**提示：**
- `1 <= rods.length <= 20`
- `1 <= rods[i] <= 1000`
- `sum(rods[i]) <= 5000`

## 解题思路

这道题要求将钢筋分成两组，使得两组的和相等，并且最大化这个和。

**核心思想：**

1. **动态规划**：定义状态 `dp[i][diff]` 表示前 i 根钢筋，两组高度差为 diff 时，较矮组的最大高度
2. **差值转移**：每根钢筋有三种选择：
   - 放到较高组：差值增大
   - 放到较矮组：差值减小
   - 不使用：差值不变

3. **状态压缩**：只关心差值，不关心具体哪组更高

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def tallestBillboard(self, rods: List[int]) -> int:
        """
        动态规划：dp[diff] 表示两组高度差为 diff 时，较矮组的最大高度
        """
        # dp[diff] = 较矮组的最大高度
        dp = {0: 0}
        
        for rod in rods:
            # 必须使用新的字典，避免重复使用同一根钢筋
            new_dp = dp.copy()
            
            for diff, shorter in dp.items():
                # 选择1：放到较高组
                longer = shorter + diff
                new_diff = longer + rod - shorter
                new_dp[new_diff] = max(new_dp.get(new_diff, 0), shorter)
                
                # 选择2：放到较矮组
                new_shorter = shorter + rod
                new_diff = abs(new_shorter - longer)
                if new_shorter >= longer:
                    new_dp[new_diff] = max(new_dp.get(new_diff, 0), longer)
                else:
                    new_dp[new_diff] = max(new_dp.get(new_diff, 0), new_shorter)
            
            dp = new_dp
        
        return dp[0]
```

### 方法二：简化的DP

```python
class Solution:
    def tallestBillboard(self, rods: List[int]) -> int:
        """简化版DP"""
        dp = {0: 0}
        
        for r in rods:
            new_dp = dp.copy()
            for diff, y in dp.items():
                # 放到较高组
                new_dp[diff + r] = max(new_dp.get(diff + r, 0), y)
                # 放到较矮组
                new_diff = abs(diff - r)
                new_dp[new_diff] = max(new_dp.get(new_diff, 0), max(y, y + diff - r))
            dp = new_dp
        
        return dp[0]
```

## 复杂度分析

- **时间复杂度**：O(N × S)，N是钢筋数量，S是钢筋和的总和
- **空间复杂度**：O(S)

## 关键点总结

1. **状态定义**：用差值作为状态关键
2. **转移方程**：三种选择的状态转移
3. **字典优化**：使用字典而非数组节省空间

## 易错点

1. 必须复制字典避免重复使用
2. 差值可能为负，需要取绝对值
