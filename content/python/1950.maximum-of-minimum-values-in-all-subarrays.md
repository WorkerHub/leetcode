## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，对于所有长度为 `k`（`1 <= k <= n`）的子数组，求其最小值，再对所有长度相同的子数组取最大值，记为 `ans[k-1]`。

返回答案数组 `ans`，长度为 `n`。

**示例 1：**
```
输入：nums = [0, 1, 2, 4]
输出：[4, 2, 1, 0]
解释：
k=1：最小值最大为 4（子数组 [4]）
k=2：最小值最大为 2（子数组 [2,4]）
k=3：最小值最大为 1（子数组 [1,2,4]）
k=4：最小值最大为 0（整个数组）
```

**提示：**
- `n == nums.length`，`1 <= n <= 10^5`
- `0 <= nums[i] <= 10^9`

---

## 解题思路

### 核心思想：单调栈 + 反向填充

对每个元素 `nums[i]`，用单调栈找它作为**最小值**的最长子数组长度：

设 `left[i]` = 左侧第一个比 `nums[i]` 小的位置（不存在则为 -1）
设 `right[i]` = 右侧第一个比 `nums[i]` 小的位置（不存在则为 n）

那么 `nums[i]` 能成为最小值的最长子数组长度为 `right[i] - left[i] - 1`。

`ans[right[i]-left[i]-1-1] = max(ans[...], nums[i])`（即长度为该值的子数组，最大最小值可以是 nums[i]）

最后从大到小填充：`ans[k] = max(ans[k], ans[k+1])`（更短的子数组的答案不小于更长的）。

## 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def findMaximums(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n

        # 使用单调递增栈求每个元素作为最小值的最大子数组范围
        stack = []

        for i in range(n + 1):
            # i == n 时作为哨兵触发最后处理
            while stack and (i == n or nums[stack[-1]] >= nums[i]):
                idx = stack.pop()
                # left 是栈中上一个元素（比 nums[idx] 小的左侧位置）
                left = stack[-1] if stack else -1
                right = i
                # 以 nums[idx] 为最小值的最长子数组长度
                length = right - left - 1
                ans[length - 1] = max(ans[length - 1], nums[idx])
            stack.append(i)

        # 从大到小传播：更短的子数组答案 >= 更长的
        for k in range(n - 2, -1, -1):
            ans[k] = max(ans[k], ans[k + 1])

        return ans
```

### 方法二：暴力（对比学习，小数据）

```python
from typing import List

class Solution:
    def findMaximums(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n

        for k in range(1, n + 1):
            for i in range(n - k + 1):
                sub_min = min(nums[i:i + k])
                ans[k - 1] = max(ans[k - 1], sub_min)

        return ans
```

## 关键点总结

1. 每个元素能作为最小值的最长子数组长度由单调栈确定
2. 知道最长长度后，更短长度的答案从右向左传播（单调非增）
3. 最后 `ans[k] = max(ans[k], ans[k+1])` 填充所有长度的答案

---

## 易错点

- 使用哨兵（`i == n`）触发栈中剩余元素的处理
- 反向传播不能遗漏：`ans[k] = max(ans[k], ans[k+1])`（从 n-2 到 0）
