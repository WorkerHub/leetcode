## 题目描述

给你一个字符串 `s`，每次操作可以选择 `s` 中三个**连续**字符，将它们全部转换为 `'O'`。

返回将 `s` 中所有 `'X'` 字符转换为 `'O'` 字符所需的**最少操作次数**。

**示例 1：**
```
输入：s = "XXX"
输出：1
```

**示例 2：**
```
输入：s = "XXOX"
输出：2
解释：前两个 X（位置0,1）用一次操作转，最后一个 X（位置3）再用一次
```

**示例 3：**
```
输入：s = "OOOO"
输出：0
```

**提示：**
- `3 <= s.length <= 1000`
- `s[i]` 是 `'X'` 或 `'O'`

## 解题思路

**贪心策略：** 从左到右遍历，遇到第一个 `'X'` 时，执行一次操作覆盖当前位置及后续两个字符（跳过3个字符），然后继续向右搜索下一个 `'X'`。

这样每次操作都尽可能多地覆盖右侧的 `'X'`，操作次数最少。

## 代码实现

### 方法一：贪心跳跃（推荐）

```python
class Solution:
    def minimumMoves(self, s: str) -> int:
        count = 0
        i = 0
        n = len(s)

        while i < n:
            if s[i] == 'X':
                count += 1  # 执行一次操作，覆盖 i, i+1, i+2
                i += 3      # 跳过3个位置
            else:
                i += 1      # O 字符直接跳过

        return count
```

### 方法二：扫描统计

```python
class Solution:
    def minimumMoves(self, s: str) -> int:
        ops = 0
        skip = 0  # 需要跳过的剩余字符数

        for c in s:
            if skip > 0:
                skip -= 1
                continue
            if c == 'X':
                ops += 1
                skip = 2  # 跳过后续两个字符

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 贪心策略：遇到 `'X'` 立刻从当前位置开始覆盖3个字符
2. 这样做确保每次操作的覆盖范围不会"浪费"在已经是 `'O'` 的位置
3. 每次操作后跳过3个位置，因为这3个已被处理

## 易错点

- 贪心从左到右，每次从第一个未处理的 `'X'` 开始，向右覆盖
- 跳跃步长是 3（不是 2），因为操作影响3个连续字符
