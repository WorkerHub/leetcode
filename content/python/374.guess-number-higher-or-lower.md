## 题目描述

我们正在玩猜数字游戏。游戏规则如下：

我从 `1` 到 `n` 之间选择一个数字。你需要猜我选的是哪个数字。

每次你猜错了，我会告诉你这个数字是大了还是小了。

你调用一个预先定义好的接口 `int guess(int num)`，它会返回三个可能的结果：

- `-1`：你猜的数字比我选的数字大（即 `num > pick`）
- `1`：你猜的数字比我选的数字小（即 `num < pick`）
- `0`：你猜对了（即 `num == pick`）

返回我选的数字。

**示例 1：**

```
输入：n = 10, pick = 6
输出：6
```

**示例 2：**

```
输入：n = 1, pick = 1
输出：1
```

**示例 3：**

```
输入：n = 2, pick = 1
输出：1
```

**提示：**
- `1 <= n <= 2^31 - 1`
- `1 <= pick <= n`

## 解题思路

这是一道经典的**二分查找**问题。

### 核心思想

在 `[1, n]` 范围内使用二分查找：
1. 取中间值 `mid`
2. 调用 `guess(mid)` 获取反馈
3. 根据反馈缩小搜索范围：
   - 返回 `-1`：说明 `mid` 太大，搜索左半部分 `[left, mid-1]`
   - 返回 `1`：说明 `mid` 太小，搜索右半部分 `[mid+1, right]`
   - 返回 `0`：找到答案

### 时间复杂度

二分查找的时间复杂度为 O(log n)。

## Python 代码实现

### 方法一：标准二分查找（推荐）

```python
# The guess API is already defined for you.
# @param num, your guess
# @return -1 if num is higher than the picked number
#          1 if num is lower than the picked number
#          otherwise return 0
# def guess(num: int) -> int:

class Solution:
    def guessNumber(self, n: int) -> int:
        """
        标准二分查找
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        left, right = 1, n
        
        while left <= right:
            mid = left + (right - left) // 2  # 避免溢出
            result = guess(mid)
            
            if result == 0:
                return mid
            elif result == -1:
                # mid 太大，搜索左半部分
                right = mid - 1
            else:  # result == 1
                # mid 太小，搜索右半部分
                left = mid + 1
        
        # 理论上不会到这里
        return -1
```

### 方法二：使用 while True（简化版）

```python
class Solution:
    def guessNumber(self, n: int) -> int:
        """
        简化的二分查找
        """
        left, right = 1, n
        
        while True:
            mid = (left + right) // 2
            result = guess(mid)
            
            if result == 0:
                return mid
            elif result == -1:
                right = mid - 1
            else:
                left = mid + 1
```

### 方法三：三分查找（了解，不推荐）

```python
class Solution:
    def guessNumber(self, n: int) -> int:
        """
        三分查找（理论上调用次数可能更少，但不一定更快）
        时间复杂度：O(log3 n)
        
        注意：对于这道题，三分查找没有优势，因为 guess 调用次数相近
        """
        left, right = 1, n
        
        while left <= right:
            mid1 = left + (right - left) // 3
            mid2 = right - (right - left) // 3
            
            res1 = guess(mid1)
            res2 = guess(mid2)
            
            if res1 == 0:
                return mid1
            if res2 == 0:
                return mid2
            
            if res1 < 0:
                # mid1 太大，搜索左边
                right = mid1 - 1
            elif res2 > 0:
                # mid2 太小，搜索右边
                left = mid2 + 1
            else:
                # 在 mid1 和 mid2 之间
                left = mid1 + 1
                right = mid2 - 1
        
        return -1
```

### 方法四：递归实现

```python
class Solution:
    def guessNumber(self, n: int) -> int:
        """
        递归实现二分查找
        时间复杂度：O(log n)
        空间复杂度：O(log n)，递归栈
        """
        return self.binarySearch(1, n)
    
    def binarySearch(self, left: int, right: int) -> int:
        if left > right:
            return -1
        
        mid = left + (right - left) // 2
        result = guess(mid)
        
        if result == 0:
            return mid
        elif result == -1:
            return self.binarySearch(left, mid - 1)
        else:
            return self.binarySearch(mid + 1, right)
```

### 方法三：三分查找
- 时间复杂度：O(log3 n)，理论上更快，但实际差异不大
- 空间复杂度：O(1)

### 方法四：递归二分查找
- 时间复杂度：O(log n)
- 空间复杂度：O(log n)

## 关键点总结

1. **二分查找模板**：这是最经典的二分查找应用
2. **避免溢出**：使用 `left + (right - left) // 2` 而不是 `(left + right) // 2`
3. **边界条件**：`while left <= right`
4. **交互式题目**：需要调用预定义的 API
5. **返回值理解**：
   - `-1`：猜大了
   - `1`：猜小了
   - `0`：猜对了

## 易错点

1. **溢出问题**：在其他语言中 `(left + right)` 可能溢出，Python 无此问题但保持好习惯
2. **边界更新**：
   - 猜大了：`right = mid - 1`（不是 `mid`）
   - 猜小了：`left = mid + 1`（不是 `mid`）
3. **返回值含义**：注意 `-1` 和 `1` 的含义，容易弄反
4. **循环条件**：`while left <= right`，不要忘记等号
5. **初始范围**：是 `[1, n]`，不是 `[0, n-1]`
