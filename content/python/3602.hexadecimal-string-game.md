## 题目描述

给你一个十六进制字符串 `s`（只含字符 `0-9` 和 `a-f`），两位玩家轮流操作。每次操作可以将字符串中的一个字符替换为相邻的十六进制值（如 `'3'` 可替换为 `'2'` 或 `'4'`，`'a'` 可替换为 `'9'` 或 `'b'`，边界字符 `'0'` 只能增加，`'f'` 只能减少）。无法操作的玩家输。

先手玩家是否能赢？

**示例 1：**

```
输入：s = "abc"
输出：true
解释：先手有合法操作，可以赢得游戏
```

**示例 2：**

```
输入：s = "fff"
输出：false
解释：每个字符只能减少，先手总是输
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含字符 `0-9` 和 `a-f`

## 解题思路

这是一个博弈论问题，可以用 Sprague-Grundy 定理分析。每个字符独立，整体的 Grundy 值等于所有字符 Grundy 值的异或。

对于字符 `c`（值为 0-15），其合法操作数取决于它与边界的距离：
- 可以向 0 方向移动 `c` 步，向 15 方向移动 `15 - c` 步
- 总可移动步数为 `c + (15 - c) = 15`（非边界字符）

实际上每个字符的游戏等价于一个 Nim 堆，Grundy 值即为该字符的十六进制值本身（0-15 中的某个）。对所有字符的 Grundy 值求异或，不为 0 则先手赢。

## Python 代码实现

### 方法一：Sprague-Grundy 定理（推荐）

```python
class Solution:
    def canWin(self, s: str) -> bool:
        xor_sum = 0
        for c in s:
            # 将十六进制字符转为整数（0-15）
            val = int(c, 16)
            # 每个字符的 Grundy 值等于其值
            xor_sum ^= val
        # 异或不为 0 则先手赢
        return xor_sum != 0
```

### 方法二：逐字符分析

```python
class Solution:
    def canWin(self, s: str) -> bool:
        # 统计可移动总步数
        total_moves = 0
        for c in s:
            val = int(c, 16)
            # 向小方向可走 val 步，向大方向可走 15-val 步
            total_moves += val + (15 - val)

        # 若总移动步数为奇数，先手赢（简化分析）
        xor_val = 0
        for c in s:
            xor_val ^= int(c, 16)
        return xor_val != 0
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(1)

## 关键点总结

1. 每个字符的操作相互独立，可拆分为独立子游戏
2. 用 Sprague-Grundy 定理：整体 Grundy 值 = 各字符 Grundy 值的异或
3. 每个字符的 Grundy 值等于其十六进制整数值
4. 异或结果不为 0 则先手必赢

## 易错点

1. 十六进制字符转整数要用 `int(c, 16)` 而非直接用 `ord`
2. 边界字符 `'0'` 和 `'f'` 的移动方向受限
3. 不要把每个字符的总移动数（15）误认为 Grundy 值
