## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个 **非负整数** `k`。

每次操作可以选择任意 `nums[i]`，将其替换为 `[nums[i] - k, nums[i] + k]` 范围内的任意整数。

一个数组的 **美丽值** 等于 **最长非递减子序列** 的长度。返回执行任意次操作后数组的 **最大美丽值**。

**注意：** 每个操作可以改变任意元素，但每个元素只能操作一次。

**示例 1：**
```
输入：nums = [4,6,1,2], k = 2
输出：3
解释：可以使 [4,6,2,4] 或类似，最长非递减子序列长度 3
```

**示例 2：**
```
输入：nums = [1,1,1,1], k = 10
输出：4
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i], k <= 10^5`

## 解题思路

每个元素 `nums[i]` 可以变为 `[nums[i] - k, nums[i] + k]` 内的任意整数。

问题转化为：在这些区间中，选择最多的相互重叠（有公共点）的区间数量。

排序后，用滑动窗口找最多有多少个区间的左端 `nums[i] - k` <= 某个公共值（等价于右端 `nums[j] + k >= nums[i] - k`，即 `nums[j] >= nums[i] - 2k`）。

排序后，滑动窗口：`nums[right] - nums[left] <= 2k` 的最大窗口大小即为答案。

## Python 代码实现

### 方法一：排序 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        nums.sort()
        ans = 1
        left = 0

        for right in range(len(nums)):
            # 窗口内所有元素能有公共区间的条件：最大值 - 最小值 <= 2k
            while nums[right] - nums[left] > 2 * k:
                left += 1
            ans = max(ans, right - left + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个元素的可变范围是长度 2k 的区间
2. 若两个区间有公共点，则两个元素可以变为同一值（非递减成立）
3. 转化为：排序后，找最大的窗口使得首尾差 <= 2k

## 易错点

1. 条件是 `nums[right] - nums[left] <= 2 * k`（不是 k）
2. 非递减子序列，相等也合法
