## 题目描述

给你 `2n` 个球，每种颜色的球个数由数组 `balls` 给出，其中 `balls[i]` 是第 `i` 种颜色球的个数（编号从 0 开始）。

所有的球会被放入两个盒子里，**每个盒子接收 n 个球**。

给你一个整数数组 `balls`，其中 `balls.length` 等于颜色种数 k（`balls` 的长度），`sum(balls) = 2n`。

返回两个盒子**各自包含不同颜色数量相同**的概率。

**示例 1：**
```
输入：balls = [1,1]
输出：1.00000
解释：每种颜色各一个球，每盒各放一球，两盒颜色种数都是 1，概率为 1。
```

**示例 2：**
```
输入：balls = [2,1,1]
输出：0.66667
解释：4 个球共 4!/(2!1!1!) = 12 种不同排列。
     其中两盒颜色种数相同的情况为 8 种，概率 = 8/12 ≈ 0.66667。
```

**示例 3：**
```
输入：balls = [1,1,1,1,1,1]
输出：0.90000
解释：6 种颜色各一个球，放入两盒各 3 个，概率为 0.9。
```

**提示：**
- `1 <= balls.length <= 8`
- `1 <= balls[i] <= 6`
- `sum(balls)` 是偶数

## 解题思路

**概率 = 满足条件的方案数 / 总方案数**

**总方案数：** 将 `2n` 个有区别的球（同种颜色不同编号）放入两个盒子，每盒 n 个：
`C(2n, n)`（从 2n 个球中选 n 个放入盒子 1）

**满足条件的方案数：** 两盒颜色种数相同

**方法：回溯枚举**

逐种颜色处理，枚举该种颜色有多少个球放入盒子 1（0 到 `balls[i]`），追踪：
- 盒子 1 已放球数
- 盒子 1 已有颜色数
- 盒子 2 已有颜色数

当所有颜色处理完后，检查两盒球数是否都等于 n，且颜色种数相同。

**数学简化：**

不需要区分每个球，只需要统计颜色的分配方式，用组合数乘以排列数来计算概率。

## Python 代码实现

### 方法一：回溯 + 组合数（推荐）

```python
from typing import List
from math import comb
from functools import lru_cache

class Solution:
    def getProbability(self, balls: List[int]) -> float:
        k = len(balls)
        n = sum(balls) // 2  # 每盒球数

        # 分子：两盒颜色种数相同的方案数（加权）
        # 分母：总方案数 C(2n, n)

        # 用 DFS/回溯枚举每种颜色放入盒子1的个数
        total_ways = 0   # 总方案数（等于 C(2n, n)）
        valid_ways = 0   # 满足条件的方案数

        def dfs(idx: int, box1_count: int, box2_count: int,
                box1_colors: int, box2_colors: int, ways: int) -> None:
            nonlocal total_ways, valid_ways

            if idx == k:
                # 所有颜色处理完毕
                if box1_count == n and box2_count == n:
                    total_ways += ways
                    if box1_colors == box2_colors:
                        valid_ways += ways
                return

            # 当前颜色有 balls[idx] 个球，枚举放入盒子1的个数（0 到 balls[idx]）
            for put_in_box1 in range(balls[idx] + 1):
                put_in_box2 = balls[idx] - put_in_box1

                # 当前颜色分配的方案数（组合数）
                color_ways = comb(balls[idx], put_in_box1)

                # 当前颜色是否在盒子1/2中出现
                new_box1_colors = box1_colors + (1 if put_in_box1 > 0 else 0)
                new_box2_colors = box2_colors + (1 if put_in_box2 > 0 else 0)

                dfs(idx + 1, box1_count + put_in_box1, box2_count + put_in_box2,
                    new_box1_colors, new_box2_colors, ways * color_ways)

        dfs(0, 0, 0, 0, 0, 1)

        return valid_ways / total_ways
```

### 方法二：动态规划

```python
from typing import List
from math import comb

class Solution:
    def getProbability(self, balls: List[int]) -> float:
        k = len(balls)
        n = sum(balls) // 2

        # dp[(box1_count, box1_colors, box2_colors)] = 方案数
        # 逐种颜色更新
        from collections import defaultdict
        dp = defaultdict(float)
        dp[(0, 0, 0)] = 1.0  # 初始状态：0 个球，0 种颜色

        for i in range(k):
            new_dp = defaultdict(float)
            for (cnt1, col1, col2), ways in dp.items():
                for put1 in range(balls[i] + 1):
                    put2 = balls[i] - put1
                    # 当前颜色的分配方案数
                    c = comb(balls[i], put1)
                    new_col1 = col1 + (1 if put1 > 0 else 0)
                    new_col2 = col2 + (1 if put2 > 0 else 0)
                    new_dp[(cnt1 + put1, new_col1, new_col2)] += ways * c
            dp = new_dp

        # 计算满足条件的方案数和总方案数
        valid = sum(v for (cnt1, col1, col2), v in dp.items()
                    if cnt1 == n and col1 == col2)
        total = sum(v for (cnt1, col1, col2), v in dp.items()
                    if cnt1 == n)

        return valid / total if total > 0 else 0.0
```

### 方法三：简化版（直接计算概率）

```python
from typing import List
from math import comb

class Solution:
    def getProbability(self, balls: List[int]) -> float:
        k = len(balls)
        n = sum(balls) // 2
        total = comb(2 * n, n)  # 总分法数

        valid = 0.0

        def dfs(idx: int, cnt1: int, col1: int, col2: int, ways: float) -> None:
            nonlocal valid
            if idx == k:
                if cnt1 == n and col1 == col2:
                    valid += ways
                return
            cnt2 = sum(balls[:idx]) - cnt1  # 已分配的球中放入盒2的数量
            remaining = sum(balls[idx:])
            # 剪枝：盒子1还需要放 (n - cnt1) 个球，但剩余球数不足
            if n - cnt1 > remaining or n - cnt1 < 0:
                return

            for put1 in range(balls[idx] + 1):
                put2 = balls[idx] - put1
                c = comb(balls[idx], put1)
                new_col1 = col1 + (1 if put1 > 0 else 0)
                new_col2 = col2 + (1 if put2 > 0 else 0)
                dfs(idx + 1, cnt1 + put1, new_col1, new_col2, ways * c)

        dfs(0, 0, 0, 0, 1.0)
        return valid / total
```

## 复杂度分析

- 时间复杂度：O(∏(balls[i] + 1))，枚举每种颜色的分配方式，最坏 O(7^8)
- 空间复杂度：O(k)，递归深度

由于 k ≤ 8，balls[i] ≤ 6，枚举空间在可接受范围内。

## 关键点总结

1. 概率 = 满足条件的方案数 / 总方案数
2. 逐种颜色枚举分配方式，用组合数 `C(balls[i], put_in_box1)` 计算每种颜色的分法
3. 追踪状态：(已处理颜色数, 盒1球数, 盒1颜色数, 盒2颜色数)
4. 满足条件：两盒各有 n 个球，且颜色种数相同

## 易错点

- 每种颜色的球是**有区别的**（虽然颜色相同），分配方式用组合数计算
- 追踪的是"颜色种数"而非"球数"，所以 put_in_box1 > 0 才算一种颜色
- 浮点数精度：由于方案数可能很大，建议用整数计算方案数，最后做除法
