## 题目描述

实现一个 `MapSum` 类，支持两个方法：
- `insert(String key, int val)`：插入 key-val 键值对，如果 key 已经存在，用新的 val 替换原来的值
- `sum(String prefix)`：返回所有以 prefix 为前缀的键的值的总和

**示例：**
```
输入：
["MapSum", "insert", "sum", "insert", "sum"]
[[], ["apple", 3], ["ap"], ["app", 2], ["ap"]]
输出：
[null, null, 3, null, 5]

解释：
MapSum mapSum = new MapSum();
mapSum.insert("apple", 3);  
mapSum.sum("ap");           // 返回 3 (apple = 3)
mapSum.insert("app", 2);    
mapSum.sum("ap");           // 返回 5 (apple = 3 + app = 2)
```

**提示：**
- 1 <= key.length, prefix.length <= 50
- key 和 prefix 仅由小写英文字母组成
- 1 <= val <= 1000
- 最多调用 50 次 insert 和 sum

## 解题思路

这是一道经典的字典树(Trie)应用题。

**核心思想：**
使用 Trie 存储键值对，在每个节点存储以该节点为前缀的所有值的和。

**两种主要方法：**
1. **暴力哈希表**：简单但效率较低
2. **字典树**：优化的数据结构

**Trie方案的关键：**
- 每个节点存储经过该节点的所有键的值的和
- 插入时更新路径上所有节点的和
- 查询时直接返回前缀最后一个节点的和

## Python 代码实现

### 方法一：哈希表（简单）⭐

```python
class MapSum:
    def __init__(self):
        self.map = {}
    
    def insert(self, key: str, val: int) -> None:
        self.map[key] = val
    
    def sum(self, prefix: str) -> int:
        total = 0
        for key, val in self.map.items():
            if key.startswith(prefix):
                total += val
        return total
```

### 方法二：字典树 + 前缀和（推荐）⭐

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.value = 0  # 存储该前缀的值的总和

class MapSum:
    def __init__(self):
        self.root = TrieNode()
        self.map = {}  # 记录已插入的key和value
    
    def insert(self, key: str, val: int) -> None:
        # 计算增量（处理更新的情况）
        delta = val - self.map.get(key, 0)
        self.map[key] = val
        
        # 更新Trie树
        node = self.root
        for char in key:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
            node.value += delta  # 更新路径上所有节点的和
    
    def sum(self, prefix: str) -> int:
        node = self.root
        for char in prefix:
            if char not in node.children:
                return 0
            node = node.children[char]
        return node.value
```

### 方法三：简化的Trie（不处理更新）

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.sum_val = 0

class MapSum:
    def __init__(self):
        self.root = TrieNode()
        self.keys = {}
    
    def insert(self, key: str, val: int) -> None:
        # 先删除旧值的影响
        old_val = self.keys.get(key, 0)
        diff = val - old_val
        self.keys[key] = val
        
        # 从根节点开始更新
        curr = self.root
        for ch in key:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
            curr.sum_val += diff
    
    def sum(self, prefix: str) -> int:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return 0
            curr = curr.children[ch]
        return curr.sum_val
```

### 方法四：前缀哈希表

```python
class MapSum:
    def __init__(self):
        self.map = {}
        self.prefix_sum = {}
    
    def insert(self, key: str, val: int) -> None:
        # 如果是更新，先减去旧值
        old_val = self.map.get(key, 0)
        delta = val - old_val
        self.map[key] = val
        
        # 更新所有前缀的和
        for i in range(1, len(key) + 1):
            prefix = key[:i]
            self.prefix_sum[prefix] = self.prefix_sum.get(prefix, 0) + delta
    
    def sum(self, prefix: str) -> int:
        return self.prefix_sum.get(prefix, 0)
```

## 复杂度分析

**方法一：哈希表**
- insert: O(1)
- sum: O(n × m)，n为键的数量，m为键的平均长度
- 空间复杂度：O(n × m)

**方法二：字典树**
- insert: O(k)，k为key的长度
- sum: O(k)，k为prefix的长度
- 空间复杂度：O(总字符数)

**方法四：前缀哈希**
- insert: O(k²)，需要更新k个前缀
- sum: O(1)
- 空间复杂度：O(总前缀数)

## 关键点总结

1. **更新处理**：同一个key插入多次要用新值替换旧值
2. **增量更新**：计算delta而不是直接加val
3. **前缀和存储**：在Trie节点存储经过该节点的所有值的和
4. **空间换时间**：预处理前缀和，加速查询
5. **哈希表辅助**：记录已插入的key-val，便于计算增量

## 易错点

1. **忘记处理更新**：相同key插入两次，不是累加而是替换
2. **增量计算错误**：应该用 delta = new_val - old_val
3. **前缀不存在**：查询不存在的前缀要返回0
4. **节点初始化**：新节点的value要初始化为0
5. **路径更新**：插入时要更新路径上所有节点
