## 题目描述

给你两个正整数 `n` 和 `limit`。

将 `n` 颗糖果分给 3 个小朋友，每个小朋友至多获得 `limit` 颗糖果，求分配方案数。

**示例 1：**
```
输入：n = 5, limit = 2
输出：3
解释：(1,2,2),(2,1,2),(2,2,1)
```

**示例 2：**
```
输入：n = 3, limit = 3
输出：10
```

**提示：**
- `1 <= n <= 10^8`
- `1 <= limit <= 10^8`

## 解题思路

用容斥原理。

设 `f(n, k)` 为将 n 颗糖分给 k 个小朋友（无上限）的方案数 = C(n+k-1, k-1)（隔板法）。

设 `A_i` 为第 i 个小朋友获得超过 limit 颗的方案集合。

答案 = 无限制方案数 - |A_1 ∪ A_2 ∪ A_3|

由容斥原理：
- |A_i| = 令第 i 个小朋友至少获得 limit+1 颗，剩余 n-(limit+1) 颗分给 3 人 = C(n-limit+1, 2)（若 >= 0）
- |A_i ∩ A_j| = 令两人各至少 limit+1 颗，剩余 n-2*(limit+1) 分给 3 人
- |A_1 ∩ A_2 ∩ A_3| = 令三人各至少 limit+1 颗，剩余 n-3*(limit+1) 分给 3 人

答案 = C(n+2,2) - 3*C(n-limit+1, 2) + 3*C(n-2*limit, 2) - C(n-3*limit-1, 2)（当参数 >= 2 时）

## Python 代码实现

### 方法一：容斥原理（推荐）

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def C2(x: int) -> int:
            # C(x, 2) = x*(x-1)//2，若 x < 2 则为 0
            if x < 2:
                return 0
            return x * (x - 1) // 2

        # 无限制：C(n+2, 2)
        # 减去一人超限：3 * C(n - (limit+1) + 2, 2) = 3 * C(n-limit+1, 2)
        # 加上两人超限：3 * C(n - 2*(limit+1) + 2, 2) = 3 * C(n-2*limit, 2)
        # 减去三人超限：C(n - 3*(limit+1) + 2, 2) = C(n-3*limit-1, 2)
        ans = (C2(n + 2)
               - 3 * C2(n - limit + 1)
               + 3 * C2(n - 2 * limit)
               - C2(n - 3 * limit - 1))
        return ans
```

### 方法二：验证容斥（小数据暴力对比）

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        # 暴力（仅用于验证小数据）
        if n > 300:
            # 使用容斥
            def C2(x):
                return x * (x - 1) // 2 if x >= 2 else 0
            return (C2(n + 2) - 3 * C2(n - limit + 1)
                    + 3 * C2(n - 2 * limit) - C2(n - 3 * limit - 1))
        count = 0
        for a in range(min(n, limit) + 1):
            for b in range(min(n - a, limit) + 1):
                c = n - a - b
                if 0 <= c <= limit:
                    count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O(1)，纯数学计算
- 空间复杂度：O(1)

## 关键点总结

1. 无上限分配 n 给 k 人：C(n+k-1, k-1)，对本题 k=3 即 C(n+2, 2)
2. 容斥原理三步：减去单人超限，加回两人超限，减去三人超限
3. 超过 limit 等价于该人至少得到 limit+1，新问题变为无限制分配 n-(limit+1) 给 3 人

## 易错点

1. C2 函数对负数参数返回 0（无意义的分配数为 0）
2. 两人超限时剩余 n - 2*(limit+1)，需代入 C(n-2*limit, 2) = C((n-2*(limit+1))+2, 2)
3. n 可以很大（10^8），Python 整数无溢出问题
