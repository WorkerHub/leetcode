## 题目描述

给你一个整数数组 `nums`，数组中共有 `2 * n` 个整数。

需要将 `nums` 分成 `n` 对，使得每对数字中两个整数相等。

如果能做到，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：nums = [3,2,3,2,2,2]
输出：true
解释：分成 (3,3),(2,2),(2,2)，每对相等。
```

**示例 2：**
```
输入：nums = [1,2,3,4]
输出：false
```

**提示：**
- `nums.length == 2 * n`
- `1 <= n <= 500`
- `1 <= nums[i] <= 500`

## 解题思路

每种数字必须出现**偶数次**才能两两配对。只需统计每个数字的出现次数，若所有数字出现次数都是偶数则返回 true。

**方法：**
- 使用计数器（Counter 或字典），检查每个值的计数是否为偶数。
- 也可以用位运算：对每个元素异或，若最终结果为 0 则说明每个数出现了偶数次（适用于值较小的情况，需配合哈希）。

## 代码实现

### 方法一：计数器（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def divideArray(self, nums: List[int]) -> bool:
        # 统计每个数字出现的次数
        count = Counter(nums)
        # 所有数字的出现次数必须是偶数
        return all(v % 2 == 0 for v in count.values())
```

### 方法二：位运算（XOR）

```python
from typing import List

class Solution:
    def divideArray(self, nums: List[int]) -> bool:
        # 对每个数字异或计数（按位标记奇偶性）
        # 由于值范围是1-500，可用整数的不同位表示
        # 更简洁：直接用集合的对称差
        seen = set()
        for num in nums:
            if num in seen:
                seen.remove(num)  # 已出现过，配对移除
            else:
                seen.add(num)     # 第一次出现，加入集合
        # 所有数都配对了，集合应为空
        return len(seen) == 0
```

### 方法三：排序后相邻比较

```python
from typing import List

class Solution:
    def divideArray(self, nums: List[int]) -> bool:
        nums.sort()
        # 排序后，相邻的两个数必须相等才能配对
        for i in range(0, len(nums), 2):
            if nums[i] != nums[i + 1]:
                return False
        return True
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，一次遍历计数。
- 空间复杂度：O(n)，哈希表存储计数。

**方法二：**
- 时间复杂度：O(n)。
- 空间复杂度：O(n)，最坏情况存储所有元素。

**方法三：**
- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(1)（原地排序）。

## 关键点总结

1. 核心条件：每种数字出现次数为偶数。
2. Counter 是 Python 中最简洁的解法。
3. 排序后两两比较也是直观方法。

## 易错点

- 题目说 `2 * n` 个元素，不必额外判断长度为偶数。
- 方法二用集合模拟配对过程，逻辑简单直观。
