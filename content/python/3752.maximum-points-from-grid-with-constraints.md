## 题目描述

给定 `m × n` 的整数矩阵 `grid`，从任意单元格出发，每次可以移动到相邻单元格（上下左右），收集该单元格的点数。条件：移动时只能到达点数不小于当前单元格点数的格子，或者花费 1 点代价跳到任意相邻格子。

求在 `k` 次代价操作内能收集的最大点数之和（路径可以重复访问格子，但每个格子只计一次）。

**示例 1：**
```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]], k = 0
输出：9
解释：不花代价只能走递增路径，最优从 (0,0)=1 走到 (2,2)=9，路径上各格子值之和最大。
```

**提示：**
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 10^6`
- `0 <= k <= m + n`

## 解题思路

动态规划：`dp[i][j][c]` 表示以 `(i,j)` 为终点，使用了 `c` 次代价的最大点数之和。

转移：
- 来自相邻格子，若相邻格子值 >= 当前格子值：无代价移动
- 来自相邻格子，若相邻格子值 < 当前格子值：花费 1 代价

每个格子的点数只计一次（路径不重复计数），这使得问题更复杂。

简化版：每个格子可以重复访问，但每次进入时加分（实际上取格子值 - 之前是否计过分）。

## Python 代码实现

### 方法一：简化 DP（每格最多访问一次）

```python
from typing import List

class Solution:
    def maxPoints(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('-inf')
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        # dp[i][j][c]: 到达 (i,j)，使用 c 次代价，收集的最大点数
        dp = [[[INF] * (k + 1) for _ in range(n)] for _ in range(m)]

        # 初始化：从每个格子出发
        for si in range(m):
            for sj in range(n):
                dp[si][sj][0] = grid[si][sj]

        # 按格子值排序处理（确保从小到大处理，保证无代价转移的正确性）
        cells = sorted((grid[i][j], i, j) for i in range(m) for j in range(n))

        for val, i, j in cells:
            for c in range(k + 1):
                if dp[i][j][c] == INF:
                    continue
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n:
                        if grid[ni][nj] >= val:
                            # 无代价移动
                            new_val = dp[i][j][c] + grid[ni][nj]
                            dp[ni][nj][c] = max(dp[ni][nj][c], new_val)
                        elif c + 1 <= k:
                            # 花费 1 代价
                            new_val = dp[i][j][c] + grid[ni][nj]
                            dp[ni][nj][c+1] = max(dp[ni][nj][c+1], new_val)

        return max(dp[i][j][c] for i in range(m) for j in range(n) for c in range(k+1))
```

### 方法二：BFS + 优先队列

```python
from typing import List
import heapq

class Solution:
    def maxPoints(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        # 最大化点数：用负数转为最小化
        INF = float('-inf')
        best = [[[-INF] * (k+1) for _ in range(n)] for _ in range(m)]

        heap = []
        for i in range(m):
            for j in range(n):
                best[i][j][0] = grid[i][j]
                heapq.heappush(heap, (-grid[i][j], 0, i, j))

        dirs = [(0,1),(0,-1),(1,0),(-1,0)]
        ans = max(grid[i][j] for i in range(m) for j in range(n))

        while heap:
            neg_pts, cost, i, j = heapq.heappop(heap)
            pts = -neg_pts
            if pts < best[i][j][cost]:
                continue
            ans = max(ans, pts)
            for di, dj in dirs:
                ni, nj = i+di, j+dj
                if 0 <= ni < m and 0 <= nj < n:
                    new_cost = cost + (0 if grid[ni][nj] >= grid[i][j] else 1)
                    new_pts = pts + grid[ni][nj]
                    if new_cost <= k and new_pts > best[ni][nj][new_cost]:
                        best[ni][nj][new_cost] = new_pts
                        heapq.heappush(heap, (-new_pts, new_cost, ni, nj))

        return ans
```

## 复杂度分析

- 时间复杂度：O(mn * k * log(mn))
- 空间复杂度：O(mn * k)

## 关键点总结

1. 状态包含已使用代价次数 c，与经典最短路问题相比增加了一维
2. 无代价移动时目标格子值必须 >= 当前格子值
3. 最大化问题用优先队列（最大堆）处理

## 易错点

1. 每次花费代价时 c 增加 1，超过 k 时不能继续
2. 初始时每个格子都可以作为起点
