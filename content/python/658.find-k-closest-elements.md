## 题目描述

给定一个**排序好**的数组 `arr`，两个整数 `k` 和 `x`，从数组中找到最靠近 `x`（两数之差最小）的 `k` 个数。返回的结果必须要是按**升序**排好的。

整数 `a` 比整数 `b` 更接近 `x` 需要满足：

- `|a - x| < |b - x|` 或者
- `|a - x| == |b - x|` 且 `a < b`

**示例 1:**

```
输入：arr = [1,2,3,4,5], k = 4, x = 3
输出：[1,2,3,4]
```

**示例 2:**

```
输入：arr = [1,2,3,4,5], k = 4, x = -1
输出：[1,2,3,4]
```

**提示:**
- `1 <= k <= arr.length`
- `1 <= arr.length <= 10^4`
- `arr` 按**升序**排列
- `-10^4 <= arr[i], x <= 10^4`

## 解题思路

这道题有多种解法，从简单到优化：

### 思路一：排序法（最直观）

1. 按照与 x 的距离对数组排序
2. 取前 k 个元素
3. 对结果排序返回

### 思路二：双指针（滑动窗口）

利用数组有序的性质：

1. 使用双指针维护一个大小为 k 的窗口
2. 比较窗口两端与 x 的距离
3. 移除距离较远的一端

### 思路三：二分查找（最优）

关键观察：k 个最近元素在数组中是**连续**的。

问题转化为：找到这个长度为 k 的连续子数组的起始位置。

使用二分查找找到最优的左边界：
- 左边界的范围：`[0, n-k]`
- 比较 `arr[mid]` 和 `arr[mid+k]` 与 x 的距离

## Python 代码实现

### 方法一：排序法（新手推荐）⭐

```python
from typing import List

class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        """
        按距离排序，取前 k 个
        """
        # 按照距离排序，距离相同时按值排序
        sorted_arr = sorted(arr, key=lambda num: (abs(num - x), num))
        
        # 取前 k 个元素
        result = sorted_arr[:k]
        
        # 结果需要按升序排列
        return sorted(result)
```

### 方法二：双指针（滑动窗口）⭐

```python
class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        """
        双指针缩小范围，最终保留 k 个元素
        """
        left, right = 0, len(arr) - 1
        
        # 不断缩小窗口，直到只剩 k 个元素
        while right - left >= k:
            # 比较两端与 x 的距离
            if abs(arr[left] - x) <= abs(arr[right] - x):
                # 左端更近或相等（相等时保留较小的），移除右端
                right -= 1
            else:
                # 右端更近，移除左端
                left += 1
        
        return arr[left:right + 1]
```

### 方法三：二分查找（最优解）⭐

```python
class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        """
        二分查找最优的左边界
        """
        left, right = 0, len(arr) - k
        
        while left < right:
            mid = (left + right) // 2
            
            # 比较 arr[mid] 和 arr[mid+k] 谁离 x 更远
            # 如果 arr[mid] 离 x 更远，说明最优区间在右边
            if x - arr[mid] > arr[mid + k] - x:
                left = mid + 1
            else:
                right = mid
        
        return arr[left:left + k]
```

### 方法四：二分查找 + 扩展（另一种思路）

```python
class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        """
        先二分找到最接近 x 的位置，然后双指针扩展
        """
        # 二分查找最接近 x 的位置
        left, right = 0, len(arr) - 1
        
        while left < right:
            mid = (left + right) // 2
            if arr[mid] < x:
                left = mid + 1
            else:
                right = mid
        
        # left 是第一个 >= x 的位置
        # 设置双指针
        i = left - 1  # x 左边
        j = left      # x 右边
        
        # 扩展 k 个元素
        for _ in range(k):
            if i < 0:
                j += 1
            elif j >= len(arr):
                i -= 1
            elif abs(arr[i] - x) <= abs(arr[j] - x):
                i -= 1
            else:
                j += 1
        
        return arr[i + 1:j]
```

### 方法五：堆（不推荐，仅供学习）

```python
import heapq

class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        """
        使用最大堆维护 k 个最近的元素
        """
        # 最大堆：(-距离, -值, 值)
        heap = []
        
        for num in arr:
            dist = abs(num - x)
            
            if len(heap) < k:
                heapq.heappush(heap, (-dist, -num, num))
            else:
                if dist < -heap[0][0] or (dist == -heap[0][0] and num < heap[0][2]):
                    heapq.heappop(heap)
                    heapq.heappush(heap, (-dist, -num, num))
        
        result = [item[2] for item in heap]
        return sorted(result)
```

## 复杂度分析

### 方法一：排序法
- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)，排序需要额外空间

### 方法二：双指针
- **时间复杂度**：O(n)，最多遍历 n-k 次
- **空间复杂度**：O(1)，不算返回值

### 方法三：二分查找
- **时间复杂度**：O(log(n-k) + k)
  - 二分查找：O(log(n-k))
  - 复制结果：O(k)
- **空间复杂度**：O(1)，不算返回值

### 方法四：二分 + 扩展
- **时间复杂度**：O(log n + k)
- **空间复杂度**：O(1)

### 方法五：堆
- **时间复杂度**：O(n log k)
- **空间复杂度**：O(k)

## 图解示例

示例 1：`arr = [1,2,3,4,5], k = 4, x = 3`

**双指针法：**

```
初始：left=0, right=4
[1, 2, 3, 4, 5]
 ↑           ↑

比较：|1-3|=2, |5-3|=2
距离相等，保留较小的 1，移除 5
right = 3

[1, 2, 3, 4, 5]
 ↑        ↑

现在窗口大小 = 4，停止
结果：[1, 2, 3, 4]
```

**二分查找法：**

```
寻找左边界，范围 [0, 5-4] = [0, 1]

初始：left=0, right=1
mid = 0

比较 arr[0]=1 和 arr[4]=5：
x-arr[0] = 3-1 = 2
arr[4]-x = 5-3 = 2
2 不大于 2，right = mid = 0

left = right = 0，停止
结果：arr[0:4] = [1, 2, 3, 4]
```

示例 2：`arr = [1,2,3,4,5], k = 4, x = -1`

```
所有元素都在 x 右边，取最左边的 k 个
结果：[1, 2, 3, 4]

双指针过程：
比较：|-1-1|=2, |-1-5|=6
移除 5

比较：|-1-1|=2, |-1-4|=5
移除 4

比较：|-1-1|=2, |-1-3|=4
移除 3

最终：[1, 2, 3, 4]（实际是|-1-2|=3）

实际计算：
轮1：|1-(-1)|=2, |5-(-1)|=6 -> 移除5
轮2：|1-(-1)|=2, |4-(-1)|=5 -> 移除4
轮3：|1-(-1)|=2, |3-(-1)|=4 -> 移除3
结果：[1,2,3,4] 但是|2-(-1)|=3也比|1-(-1)|=2大
哦不对，题解是正确的
```

## 关键点总结

1. **数组有序**：利用有序性质，最近的 k 个元素一定是连续的
2. **距离定义**：距离相等时选择较小的值
3. **双指针技巧**：从两端向中间缩小，保留距离更近的一端
4. **二分查找**：找到最优左边界，直接截取子数组
5. **返回格式**：结果必须按升序排列

## 易错点

1. **距离相等时的处理**：
   ```python
   # 错误：距离相等时没有优先选择较小值
   if abs(arr[left] - x) < abs(arr[right] - x):
   
   # 正确：使用 <=
   if abs(arr[left] - x) <= abs(arr[right] - x):
   ```

2. **循环条件**：
   ```python
   # 双指针：要保留 k 个元素
   while right - left >= k:  # 不是 >
   ```

3. **二分边界**：
   ```python
   # 左边界范围是 [0, n-k]，不是 [0, n-1]
   left, right = 0, len(arr) - k
   ```

4. **二分比较条件**：
   ```python
   # 比较的是距离差
   if x - arr[mid] > arr[mid + k] - x:
   ```

5. **结果需要排序**：
   ```python
   # 方法一中，取出的元素需要重新排序
   return sorted(result)
   ```

**常见问题：**

Q: 为什么最近的 k 个元素一定连续？
A: 反证法，如果不连续，中间的元素一定比两端某个更近。

Q: 二分查找为什么比较 arr[mid] 和 arr[mid+k]？
A: 这两个元素决定了窗口的左右边界，比较它们可以判断窗口应该左移还是右移。

Q: 双指针为什么从两端开始？
A: 因为要缩小到 k 个元素，从两端移除更方便。
