## 题目描述

给你双向链表的**某个节点**（不一定是头节点），将整个链表转换为数组返回（按链表顺序）。

**注意：** 输入给定的是链表中的某一个节点，需要找到头节点再遍历。

**示例：**
```
输入：head = [1,2,3,4,5]（给定节点可能是中间某个）
输出：[1,2,3,4,5]
```

**提示：**
- 链表节点数在 `[1, 500]` 之间
- `-10^4 <= Node.val <= 10^4`

## 解题思路

1. 先通过 `prev` 指针找到头节点（`prev` 为 None 的节点）
2. 再从头节点沿 `next` 遍历整个链表

## Python 代码实现

### 方法一：先找头节点再遍历（推荐）

```python
from typing import Optional, List

class Node:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next

class Solution:
    def toArray(self, node: Optional[Node]) -> List[int]:
        # 找头节点
        while node.prev:
            node = node.prev
        
        # 从头遍历
        result = []
        while node:
            result.append(node.val)
            node = node.next
        
        return result
```

### 方法二：先收集再返回

```python
from typing import Optional, List

class Solution:
    def toArray(self, node: Optional[Node]) -> List[int]:
        # 向左找头
        head = node
        while head.prev:
            head = head.prev
        
        # 向右遍历
        return [n.val for n in iter(lambda: head, None) if (head := head.next) or True]
        # 简洁版
        result = []
        cur = head
        while cur:
            result.append(cur.val)
            cur = cur.next
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 双向链表可以通过 prev 指针向左找头节点
2. 找到头节点后正向遍历即可

## 易错点

1. 与 3263 不同，这里给的不是头节点
2. 需要先向左走到 prev 为 None 的节点
