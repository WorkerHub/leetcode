## 题目描述

给你一个字符串数组 `words`，定义一对 `(i, j)` 为"几乎有序对"当且仅当 `i < j` 且 `words[i]` 最多交换一对字符后能变成 `words[j]`（`words[i]` 和 `words[j]` 长度相同）。

返回这样的对的数量。

**示例 1：**

```
输入：words = ["ab","ba","abc"]
输出：1
解释：("ab","ba")：交换ab的两个字符得ba
```

**示例 2：**

```
输入：words = ["aa","aa"]
输出：1
解释：不交换（已相同）也是合法的（0次交换=最多1次）
```

**提示：**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`

## 解题思路

枚举所有对 `(i, j)`，对每对检查是否满足条件。

检验函数：两字符串长度不同则不满足。统计不同位置数：
- 0 个不同：已相同，满足
- 2 个不同：交换这两个位置后检查是否相同
- 其他数量：不满足

## Python 代码实现

### 方法一：枚举 + 差异位置检验（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, words: List[str]) -> int:
        def is_almost_sorted(w1: str, w2: str) -> bool:
            if len(w1) != len(w2):
                return False
            diffs = [(a, b) for a, b in zip(w1, w2) if a != b]
            if len(diffs) == 0:
                return True
            if len(diffs) == 2:
                return diffs[0] == diffs[1][::-1]
            return False

        count = 0
        n = len(words)
        for i in range(n):
            for j in range(i + 1, n):
                if is_almost_sorted(words[i], words[j]):
                    count += 1
        return count
```

### 方法二：排序变体

```python
from typing import List

class Solution:
    def countPairs(self, words: List[str]) -> int:
        def check(s, t):
            if len(s) != len(t):
                return False
            diff = [(a, b) for a, b in zip(s, t) if a != b]
            return len(diff) == 0 or (len(diff) == 2 and diff[0] == (diff[1][1], diff[1][0]))

        ans = 0
        for i in range(len(words)):
            for j in range(i + 1, len(words)):
                if check(words[i], words[j]):
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，L 为字符串长度
- 空间复杂度：O(L)

## 关键点总结

1. 不同位置数为 0（相同）或 2（可交换）才满足
2. 差异为 2 时：`(a,b)` 和 `(b,a)` 才能通过一次交换解决
3. 枚举所有对，O(n^2)

## 易错点

1. 长度不同时直接返回 False
2. 差异位置恰好 2 时，需检查 `diffs[0] == diffs[1][::-1]`（即 a=b',b=a'）
3. 字符相同但顺序不同的对（如 "aa" 和 "aa"）也满足
