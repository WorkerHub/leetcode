## 题目描述

给你一个非负整数数组 `nums` 和整数 `k`。

返回 `nums` 中满足以下条件的最短子数组长度：子数组中所有元素按位或 >= k。

若不存在，返回 -1。

**示例 1：**
```
输入：nums = [1,2,3], k = 2
输出：1
解释：[2] 的按位或为 2 >= 2，长度 1
```

**示例 2：**
```
输入：nums = [2,1,8], k = 10
输出：3
```

**提示：**
- `1 <= nums.length <= 50`
- `0 <= nums[i] <= 50`
- `0 <= k <= 50`

## 解题思路

数据范围小，暴力枚举所有子数组，计算按位或，找最短满足条件的。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def minimumSubarrayLength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = n + 1

        for i in range(n):
            cur_or = 0
            for j in range(i, n):
                cur_or |= nums[j]
                if cur_or >= k:
                    ans = min(ans, j - i + 1)
                    break  # 已找到以 i 开头的最短，无需继续

        return ans if ans <= n else -1
```

### 方法二：滑动窗口（适合大数据量）

```python
from typing import List

class Solution:
    def minimumSubarrayLength(self, nums: List[int], k: int) -> int:
        if k == 0:
            return 1  # 任意非空子数组的 OR >= 0

        n = len(nums)
        ans = float('inf')
        bit_count = [0] * 32  # 各位的 1 的个数
        cur_or = 0
        left = 0

        for right in range(n):
            # 加入 nums[right]
            for b in range(32):
                if nums[right] >> b & 1:
                    bit_count[b] += 1
            cur_or |= nums[right]

            # 收缩左边界
            while cur_or >= k and left <= right:
                ans = min(ans, right - left + 1)
                # 移出 nums[left]
                for b in range(32):
                    if nums[left] >> b & 1:
                        bit_count[b] -= 1
                        if bit_count[b] == 0:
                            cur_or &= ~(1 << b)
                left += 1

        return ans if ans != float('inf') else -1
```

## 复杂度分析

- 方法一：O(n^2)，n <= 50 完全可行
- 方法二：O(n * 32) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 按位或是单调的（子数组扩大，OR 只增不减），适合滑动窗口
2. 收缩窗口时需要重新计算 OR（用位计数数组）
3. 特殊情况：k = 0 时任意子数组满足

## 易错点

1. 收缩窗口时不能直接减去 `nums[left]` 的 OR（因为 OR 不可逆），需要用位计数数组
2. 最终 `ans = n+1` 或 `inf` 时返回 -1
