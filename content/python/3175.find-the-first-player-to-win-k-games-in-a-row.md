## 题目描述

有 `n` 名玩家参加比赛，编号 1 到 n，初始顺序由数组 `skills` 给出。

规则：技能更高的玩家赢得比赛，赢家与队列中下一名玩家继续比赛，输家排到队伍末尾。

返回第一个连续赢得 `k` 场比赛的玩家编号（1-indexed 的玩家号基于 skills 数组位置）。

实际题意：skills[i] 是玩家 i 的技能值，队列初始为 [0,1,...,n-1]（按索引）。返回第一个连续赢 k 场的玩家的 **索引**（0-indexed）。

**提示：**
- `2 <= n <= 10^5`
- `1 <= k <= 10^9`

## 解题思路

如果 k >= n-1，则技能最大的玩家一定能赢（经过至多 n-1 场后必然遇上）。

否则模拟：维护当前赢家和连续胜场数，遍历队列。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def findWinningPlayer(self, skills: List[int], k: int) -> int:
        n = len(skills)
        # 如果 k >= n-1，最大技能的玩家必定是答案
        if k >= n - 1:
            return skills.index(max(skills))

        # 模拟
        cur = 0  # 当前赢家的索引
        wins = 0  # 连续胜场数

        for i in range(1, n):
            if skills[cur] > skills[i]:
                wins += 1
            else:
                cur = i
                wins = 1
            if wins == k:
                return cur

        return cur
```

### 方法二：使用队列

```python
from typing import List
from collections import deque

class Solution:
    def findWinningPlayer(self, skills: List[int], k: int) -> int:
        n = len(skills)
        if k >= n - 1:
            return skills.index(max(skills))

        q = deque(range(n))
        wins = 0
        cur = q.popleft()

        while wins < k:
            challenger = q.popleft()
            if skills[cur] > skills[challenger]:
                wins += 1
                q.append(challenger)
            else:
                q.append(cur)
                cur = challenger
                wins = 1

        return cur
```

## 复杂度分析

- 时间复杂度：O(n)，最多遍历一遍
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. k >= n-1 时直接返回最大技能玩家
2. 线性扫描，维护当前赢家和连胜数
3. 遇到更强对手时更新赢家，连胜归 1

## 易错点

1. k 很大时不能真正模拟
2. 线性扫描中，当前赢家从 index 0 开始
