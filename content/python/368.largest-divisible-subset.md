## 题目描述

给你一个由无重复正整数组成的数组 `nums`，请你找出并返回其中最大的整除子集 `answer`，子集中每对元素 `(answer[i], answer[j])` 都应当满足：
- `answer[i] % answer[j] == 0`，或
- `answer[j] % answer[i] == 0`

如果存在多个有效解子集，返回其中任何一个均可。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[1,2]
解释：[1,3] 也是有效解
```

**示例 2：**

```
输入：nums = [1,2,4,8]
输出：[1,2,4,8]
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 2 * 10^9`
- `nums` 中的所有整数互不相同

## 解题思路

这道题是动态规划的经典应用，类似于"最长递增子序列"问题。

### 关键观察

1. **整除的传递性**：如果 `a % b == 0` 且 `b % c == 0`，则 `a % c == 0`
2. **排序后简化**：对数组排序后，对于 `i < j`，只需检查 `nums[j] % nums[i] == 0`
3. **动态规划状态**：`dp[i]` 表示以 `nums[i]` 结尾的最大整除子集的长度

### 算法流程

1. 将数组排序
2. 使用 DP 计算每个位置的最大整除子集长度
3. 回溯构造实际的子集

### 状态转移方程

```
dp[i] = max(dp[j] + 1)  其中 j < i 且 nums[i] % nums[j] == 0
```

## Python 代码实现

### 方法一：动态规划 + 回溯构造（推荐）

```python
from typing import List

class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        """
        动态规划 + 回溯构造结果
        时间复杂度：O(n^2)
        空间复杂度：O(n)
        """
        if not nums:
            return []
        
        # 排序是关键
        nums.sort()
        n = len(nums)
        
        # dp[i] 表示以 nums[i] 结尾的最大整除子集的长度
        dp = [1] * n
        # parent[i] 记录 nums[i] 的前驱索引，用于回溯
        parent = [-1] * n
        
        # 记录最大长度和对应的结束索引
        max_len = 1
        max_idx = 0
        
        # 动态规划
        for i in range(1, n):
            for j in range(i):
                # 如果 nums[i] 能被 nums[j] 整除
                if nums[i] % nums[j] == 0:
                    # 更新 dp[i]
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
                        parent[i] = j
            
            # 更新最大长度
            if dp[i] > max_len:
                max_len = dp[i]
                max_idx = i
        
        # 回溯构造结果
        result = []
        idx = max_idx
        while idx != -1:
            result.append(nums[idx])
            idx = parent[idx]
        
        return result[::-1]  # 反转得到正序
```

### 方法二：优化的动态规划

```python
from typing import List

class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        """
        使用字典存储每个位置的实际子集
        空间换时间，避免回溯
        """
        if not nums:
            return []
        
        nums.sort()
        n = len(nums)
        
        # subsets[i] 存储以 nums[i] 结尾的最大整除子集
        subsets = [[num] for num in nums]
        
        for i in range(1, n):
            for j in range(i):
                if nums[i] % nums[j] == 0:
                    # 如果通过 j 能得到更长的子集
                    if len(subsets[j]) + 1 > len(subsets[i]):
                        subsets[i] = subsets[j] + [nums[i]]
        
        # 返回最长的子集
        return max(subsets, key=len)
```

### 方法三：只记录长度（如果只需要长度）

```python
from typing import List

class Solution:
    def largestDivisibleSubsetLength(self, nums: List[int]) -> int:
        """
        如果只需要返回最大长度
        """
        if not nums:
            return 0
        
        nums.sort()
        n = len(nums)
        dp = [1] * n
        
        for i in range(1, n):
            for j in range(i):
                if nums[i] % nums[j] == 0:
                    dp[i] = max(dp[i], dp[j] + 1)
        
        return max(dp)
```

## 复杂度分析

### 方法一：DP + 回溯
- 时间复杂度：O(n^2)
  - 排序：O(n log n)
  - DP：O(n^2)
  - 回溯：O(n)
- 空间复杂度：O(n)

### 方法二：存储子集
- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)，最坏情况每个子集都很长

### 方法三：只计算长度
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. **排序的重要性**：排序后只需检查 `nums[i] % nums[j] == 0`（j < i）
2. **整除的传递性**：如果 a|b 且 b|c，则 a|c（关键性质）
3. **类比 LIS**：这道题本质上是"最长递增子序列"的变体
4. **回溯构造**：使用 parent 数组记录前驱，用于构造结果
5. **贪心不可行**：不能简单地每次选最大的可整除元素

## 易错点

1. **忘记排序**：必须先排序才能简化问题
2. **初始化**：dp 数组初始化为 1，不是 0
3. **parent 初始化**：初始化为 -1 表示没有前驱
4. **回溯方向**：构造的结果是倒序的，需要反转
5. **整除判断**：是 `nums[i] % nums[j] == 0`，不是相反
