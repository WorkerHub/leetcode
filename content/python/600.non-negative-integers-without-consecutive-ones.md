## 题目描述

给定一个正整数 `n`，返回范围在 `[0, n]` 内，二进制表示不包含连续的 1 的非负整数个数。

**示例：**
```
输入：n = 5
输出：5
解释：
0  -> 0
1  -> 1
2  -> 10
3  -> 11 (包含连续的1，不计入)
4  -> 100
5  -> 101
所以答案是 5
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

这是一道数位DP问题。

核心思想：
- 使用斐波那契数列计算不含连续1的数字个数
- 数位DP逐位判断

## Python 代码实现

### 方法一：数位DP（推荐）⭐

```python
class Solution:
    def findIntegers(self, n: int) -> int:
        """
        数位DP + 斐波那契
        
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        # 将n转为二进制
        binary = bin(n)[2:]
        k = len(binary)
        
        # fib[i] 表示 i 位二进制数中不含连续1的个数
        fib = [0] * (k + 1)
        fib[0] = 1
        fib[1] = 2
        for i in range(2, k + 1):
            fib[i] = fib[i-1] + fib[i-2]
        
        result = 0
        prev_bit = 0  # 前一位的值
        
        for i in range(k):
            if binary[i] == '1':
                # 当前位是1，加上所有当前位为0的情况
                result += fib[k - i - 1]
                
                # 如果前一位也是1，说明出现连续1，后面的都不合法
                if prev_bit == 1:
                    return result
                
                prev_bit = 1
            else:
                prev_bit = 0
        
        # n本身也需要计入（如果合法）
        return result + 1
```

### 方法二：记忆化搜索

```python
class Solution:
    def findIntegers(self, n: int) -> int:
        """
        记忆化DFS
        
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        binary = bin(n)[2:]
        memo = {}
        
        def dfs(pos, prev, tight):
            """
            pos: 当前位置
            prev: 前一位是否为1
            tight: 是否受n的限制
            """
            if pos == len(binary):
                return 1
            
            if (pos, prev, tight) in memo:
                return memo[(pos, prev, tight)]
            
            limit = int(binary[pos]) if tight else 1
            count = 0
            
            for digit in range(limit + 1):
                # 如果前一位是1且当前位也是1，跳过
                if prev == 1 and digit == 1:
                    continue
                count += dfs(pos + 1, digit, tight and digit == limit)
            
            memo[(pos, prev, tight)] = count
            return count
        
        return dfs(0, 0, True)
```

## 复杂度分析

- **时间复杂度**：O(log n)，二进制位数
- **空间复杂度**：O(log n)

## 关键点总结

1. **数位DP**：按位处理，考虑限制条件
2. **斐波那契**：不含连续1的数量符合斐波那契规律
3. **tight变量**：记录是否受n的限制
4. **prev变量**：记录前一位避免连续1

## 易错点

1. **边界处理**：n本身需要计入结果
2. **连续1检测**：一旦出现连续1，后面的都不合法
3. **斐波那契初始化**：fib[0]=1, fib[1]=2
