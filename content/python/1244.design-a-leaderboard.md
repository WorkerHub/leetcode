## 题目描述

设计一个排行榜类 `Leaderboard`，包含以下三个功能：

1. `addScore(playerId, score)`：更新玩家的得分。如果该玩家已存在于排行榜中，则将分数加到该玩家的当前分数上；否则，将该玩家添加到排行榜中并设置初始分数。
2. `top(K)`：返回前 K 名玩家的总分数之和。
3. `reset(playerId)`：将指定玩家的分数重置为 0。

初始时，排行榜为空。

**示例：**

```
输入：
["Leaderboard","addScore","addScore","addScore","addScore","addScore","top","reset","reset","addScore","top"]
[[],[1,73],[2,56],[3,39],[4,51],[5,4],[1],[1],[2],[2,51],[3]]

输出：
[null,null,null,null,null,null,73,null,null,null,141]

解释：
Leaderboard leaderboard = new Leaderboard ();
leaderboard.addScore(1,73);   // 排行榜 [[1,73]]
leaderboard.addScore(2,56);   // 排行榜 [[1,73],[2,56]]
leaderboard.addScore(3,39);   // 排行榜 [[1,73],[2,56],[3,39]]
leaderboard.addScore(4,51);   // 排行榜 [[1,73],[2,56],[3,39],[4,51]]
leaderboard.addScore(5,4);    // 排行榜 [[1,73],[2,56],[3,39],[4,51],[5,4]]
leaderboard.top(1);           // 返回 73；前 1 名玩家的分数和为 73
leaderboard.reset(1);         // 排行榜 [[2,56],[3,39],[4,51],[5,4]]
leaderboard.reset(2);         // 排行榜 [[3,39],[4,51],[5,4]]
leaderboard.addScore(2,51);   // 排行榜 [[2,51],[3,39],[4,51],[5,4]]
leaderboard.top(3);           // 返回 141 = 51 + 51 + 39；前 3 名玩家的分数和
```

**提示：**

- `1 <= playerId, K <= 10000`
- 题目数据保证 `K` 不会超过当前排行榜中玩家的数量
- `1 <= score <= 100`
- 最多调用 `1000` 次 `addScore`、`top` 和 `reset`

## 解题思路

这是一道设计题，核心在于如何高效地实现三个操作：

1. **addScore**：需要快速更新玩家分数 → 使用哈希表存储 `playerId -> score`
2. **top(K)**：需要找到前 K 高的分数并求和 → 可以对分数排序或使用堆
3. **reset**：需要快速重置玩家分数 → 哈希表支持 O(1) 更新

**关键观察：**
- 玩家 ID 和分数是独立的，使用哈希表（字典）存储映射关系
- `top(K)` 操作需要排序，可以每次调用时对所有分数排序
- 对于频繁的 `top(K)` 查询，可以考虑维护有序结构或使用堆优化

## Python 代码实现

### 方法一：哈希表 + 排序（推荐）⭐

每次 `top(K)` 时对所有分数进行排序，简单直接。

```python
class Leaderboard:
    def __init__(self):
        # 使用字典存储玩家 ID 和分数的映射
        self.scores = {}

    def addScore(self, playerId: int, score: int) -> None:
        # 如果玩家已存在，累加分数；否则初始化分数
        if playerId in self.scores:
            self.scores[playerId] += score
        else:
            self.scores[playerId] = score

    def top(self, K: int) -> int:
        # 获取所有分数，降序排序，取前 K 个求和
        all_scores = sorted(self.scores.values(), reverse=True)
        return sum(all_scores[:K])

    def reset(self, playerId: int) -> None:
        # 将玩家分数重置为 0（或直接删除）
        self.scores[playerId] = 0
```

### 方法二：哈希表 + 堆优化

使用最小堆维护前 K 个最大值，适合 K 较小的情况。

```python
import heapq

class Leaderboard:
    def __init__(self):
        self.scores = {}

    def addScore(self, playerId: int, score: int) -> None:
        if playerId in self.scores:
            self.scores[playerId] += score
        else:
            self.scores[playerId] = score

    def top(self, K: int) -> int:
        # 使用最小堆维护前 K 个最大值
        # 堆的大小为 K，堆顶是第 K 大的元素
        heap = []
        for score in self.scores.values():
            if score > 0:  # 只考虑正分数
                heapq.heappush(heap, score)
                if len(heap) > K:
                    heapq.heappop(heap)  # 移除最小值
        return sum(heap)

    def reset(self, playerId: int) -> None:
        self.scores[playerId] = 0
```

### 方法三：使用 nlargest 优化

利用 Python 的 `heapq.nlargest` 简化 `top(K)` 实现。

```python
import heapq

class Leaderboard:
    def __init__(self):
        self.scores = {}

    def addScore(self, playerId: int, score: int) -> None:
        self.scores[playerId] = self.scores.get(playerId, 0) + score

    def top(self, K: int) -> int:
        # 使用 heapq.nlargest 获取前 K 大的元素
        return sum(heapq.nlargest(K, self.scores.values()))

    def reset(self, playerId: int) -> None:
        self.scores[playerId] = 0
```

## 复杂度分析

### 方法一（哈希表 + 排序）

- **addScore**：O(1)，字典插入/更新
- **top**：O(n log n)，n 为玩家数量，需要排序
- **reset**：O(1)，字典更新
- **空间复杂度**：O(n)，存储 n 个玩家的分数

### 方法二（哈希表 + 堆）

- **addScore**：O(1)
- **top**：O(n log K)，遍历所有分数并维护大小为 K 的堆
- **reset**：O(1)
- **空间复杂度**：O(n)

### 方法三（nlargest）

- **addScore**：O(1)
- **top**：O(n log K)，`nlargest` 内部使用堆实现
- **reset**：O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. 使用**哈希表**存储玩家 ID 与分数的映射，支持 O(1) 查询和更新
2. `top(K)` 操作的核心是**找到前 K 大的元素**并求和
3. 当 K 较小时，**堆**比完全排序更高效（O(n log K) vs O(n log n)）
4. Python 的 `heapq.nlargest` 是最简洁的实现方式
5. `reset` 操作可以将分数设为 0，或从字典中删除（根据需求）

## 易错点

1. **累加分数**：`addScore` 是累加而不是覆盖，需要 `+=` 而非 `=`
2. **reset 后的处理**：重置为 0 后，该玩家仍在字典中，不影响后续操作
3. **K 的边界**：题目保证 K 不超过玩家数量，无需额外检查
4. **分数为 0 的玩家**：在 `top` 中是否包含分数为 0 的玩家（题目未明确，但通常包含）
