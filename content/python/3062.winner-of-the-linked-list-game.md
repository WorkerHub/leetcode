## 题目描述

给你一个链表，包含偶数个节点（节点值均为非负整数）。

两位玩家 Even 和 Odd 进行游戏：
- Even 玩家收集偶数位置的节点值（位置从 0 开始，0-indexed 的偶数位：0, 2, 4, ...）
- Odd 玩家收集奇数位置的节点值（1, 3, 5, ...）

比较两人收集的值之和：
- 若 Even 的总和 > Odd 的总和，返回 `"Even"`
- 若 Odd 的总和 > Even 的总和，返回 `"Odd"`
- 否则返回 `"Tie"`

**示例 1：**
```
输入：head = [2,1]
输出："Even"
```

**提示：**
- 链表节点数在 `[2, 100]` 范围内
- `0 <= Node.val <= 100`

## Python 代码实现

### 方法一：遍历统计（推荐）

```python
from typing import Optional

# 链表节点定义
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def gameResult(self, head: Optional[ListNode]) -> str:
        even_sum = 0
        odd_sum = 0
        pos = 0
        node = head

        while node:
            if pos % 2 == 0:
                even_sum += node.val
            else:
                odd_sum += node.val
            pos += 1
            node = node.next

        if even_sum > odd_sum:
            return "Even"
        elif odd_sum > even_sum:
            return "Odd"
        else:
            return "Tie"
```

### 方法二：每两个节点比较

```python
from typing import Optional

class Solution:
    def gameResult(self, head: Optional[ListNode]) -> str:
        even_sum = odd_sum = 0
        node = head
        while node and node.next:
            even_sum += node.val
            odd_sum += node.next.val
            node = node.next.next

        if even_sum > odd_sum:
            return "Even"
        elif odd_sum > even_sum:
            return "Odd"
        return "Tie"
```

## 复杂度分析

- 时间复杂度：O(n)，遍历链表一次
- 空间复杂度：O(1)

## 关键点总结

1. 偶数位（0-indexed）求和 vs 奇数位求和
2. 链表节点数为偶数，方法二每次取两个节点

## 易错点

1. 位置从 0 开始（0-indexed）
2. 题目保证节点数为偶数
