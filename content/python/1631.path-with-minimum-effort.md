## 题目描述

你准备参加一场远足活动。给你一个 `rows x columns` 的地图 `heights`，其中 `heights[row][col]` 表示格子 `(row, col)` 的高度。

一条路径的**费力程度**定义为路径上相邻格子**高度差绝对值的最大值**。

请返回从左上角到右下角的路径中，**费力程度最小**的路径的费力程度。

**示例：**
```
输入：heights = [[1,2,2],[3,8,2],[5,3,5]]
输出：2
解释：路径 [1,3,5,3,5]，最大高度差是 2（3-5 = 2）
```

**提示：**
- `rows == heights.length`
- `columns == heights[i].length`
- `1 <= rows, columns <= 100`
- `1 <= heights[i][j] <= 10^6`

## 解题思路

**方法一：Dijkstra 最短路**（将路径费力程度定义为到达某格的最小最大高度差）

**方法二：二分 + BFS/DFS**（二分答案 mid，检查是否存在只使用高度差 <= mid 的路径连接起点和终点）

**方法三：并查集**（将所有边按高度差排序，从小到大加入，直到左上和右下连通为止）

## 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        rows, cols = len(heights), len(heights[0])
        # dist[r][c] = 从左上角到 (r,c) 的最小费力程度
        dist = [[float('inf')] * cols for _ in range(rows)]
        dist[0][0] = 0
        
        # 最小堆：(当前费力程度, row, col)
        heap = [(0, 0, 0)]
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while heap:
            effort, r, c = heapq.heappop(heap)
            
            if r == rows - 1 and c == cols - 1:
                return effort
            
            if effort > dist[r][c]:
                continue  # 过时状态，跳过
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols:
                    diff = abs(heights[nr][nc] - heights[r][c])
                    new_effort = max(effort, diff)
                    if new_effort < dist[nr][nc]:
                        dist[nr][nc] = new_effort
                        heapq.heappush(heap, (new_effort, nr, nc))
        
        return dist[rows-1][cols-1]
```

### 方法二：二分 + BFS

```python
from typing import List
from collections import deque

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        rows, cols = len(heights), len(heights[0])
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        def can_reach(max_diff: int) -> bool:
            """检查仅使用高度差 <= max_diff 的边，能否从左上到右下"""
            visited = [[False] * cols for _ in range(rows)]
            visited[0][0] = True
            queue = deque([(0, 0)])
            while queue:
                r, c = queue.popleft()
                if r == rows - 1 and c == cols - 1:
                    return True
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if (0 <= nr < rows and 0 <= nc < cols
                            and not visited[nr][nc]
                            and abs(heights[nr][nc] - heights[r][c]) <= max_diff):
                        visited[nr][nc] = True
                        queue.append((nr, nc))
            return False
        
        lo, hi = 0, 10 ** 6
        while lo < hi:
            mid = (lo + hi) // 2
            if can_reach(mid):
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Dijkstra | O(m*n * log(m*n)) | O(m*n) |
| 二分+BFS | O(m*n * log(max_height)) | O(m*n) |

## 关键点总结

1. Dijkstra 中用最大高度差（不是累加）定义"距离"，用最小堆维护
2. 二分答案：答案具有单调性（max_diff 越大，越容易到达）
3. 二分的上界为 10^6（最大高度差），下界为 0

## 易错点

- Dijkstra 中松弛条件：`max(effort, diff) < dist[nr][nc]`（取最大值不是加法）
- 二分搜索时，`hi = mid`（不是 `mid - 1`），因为找左边界
- BFS 时要标记已访问防止重复
