## 题目描述

给你一个只包含数字的字符串 `s`，长度为 `n`。

每次操作：将相邻两个数字替换为它们的和对 10 取模（将两个字符替换为一个字符）。

连续进行操作直到字符串长度为 2，判断这两个数字是否相等。

**示例 1：**

```
输入：s = "3902"
输出：false
解释：
"3902" -> "292"（3+9=12%10=2, 9+0=9, 0+2=2）-> "12"（2+9=11%10=1, 9+2=11%10=1）? 
等等，每次操作只替换一对相邻数字...
实际：每次将所有相邻对都替换，相当于对整个字符串做杨辉三角卷积
```

**示例 2：**

```
输入：s = "34789"
输出：false
```

**提示：**
- `3 <= s.length <= 100`
- `s` 只包含数字字符

## 解题思路

每次操作将所有相邻对同时替换（类似杨辉三角）。经过 n-2 次操作后，字符串长度为 2。

最终两个数字的值可以用组合数表示：
- 位置 0 的值 = sum(C(n-2, i) * d[i]) mod 10，i 从 0 到 n-2
- 位置 1 的值 = sum(C(n-2, i) * d[i+1]) mod 10，i 从 0 到 n-2

其中 d[i] = int(s[i])。

由于 n <= 100，组合数 C(n-2, i) 较大，需要对 10 取模。

## Python 代码实现

### 方法一：模拟（推荐）

```python
class Solution:
    def hasSameDigits(self, s: str) -> bool:
        # 将字符串变为数字列表
        digits = [int(c) for c in s]

        while len(digits) > 2:
            new_digits = []
            for i in range(len(digits) - 1):
                new_digits.append((digits[i] + digits[i + 1]) % 10)
            digits = new_digits

        return digits[0] == digits[1]
```

### 方法二：组合数学（O(n)）

```python
class Solution:
    def hasSameDigits(self, s: str) -> bool:
        n = len(s)
        digits = [int(c) for c in s]

        # 经过 n-2 次操作后，最终 s[0] = sum(C(n-2,i) * d[i]) mod 10
        # s[1] = sum(C(n-2,i) * d[i+1]) mod 10

        def compute(start, length):
            """从 start 开始，取 length 个元素，经 length-1 次卷积的结果"""
            # 等于 sum(C(length-1, i) * d[start+i]) mod 10
            result = 0
            c = 1  # C(length-1, i)
            for i in range(length):
                result = (result + c * digits[start + i]) % 10
                # 更新组合数：C(length-1, i+1) = C(length-1, i) * (length-1-i) / (i+1)
                if i < length - 1:
                    c = c * (length - 1 - i) // (i + 1)
            return result

        val0 = compute(0, n - 1)
        val1 = compute(1, n - 1)
        return val0 == val1
```

## 复杂度分析

- 方法一（模拟）：O(n^2)
- 方法二（组合数）：O(n)

## 关键点总结

1. 每次操作对所有相邻对同时替换，等同于帕斯卡三角卷积
2. 模拟直接实现，n <= 100 时可接受
3. 数学方法：最终值是原始数字的二项式卷积

## 易错点

1. 每次操作同时处理所有相邻对（不是一次只处理一对）
2. 和对 10 取模，保持数字在 0-9 范围内
3. 组合数 C(n-2, i) 在整数域计算后才对 10 取模
