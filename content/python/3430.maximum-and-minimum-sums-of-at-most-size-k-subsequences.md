## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

返回所有长度**至多为 `k`** 的非空**子序列**的最大值和最小值的总和，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：nums = [1,2,3], k = 2
输出：36
解释：
长度 1 子序列：[1],[2],[3] -> (1+1)+(2+2)+(3+3) = 12
长度 2 子序列：[1,2],[1,3],[2,3] -> (1+2)+(1+3)+(2+3) = 12+12 = 24... 不对
实际：长度 2 子序列 max+min: [1,2]->2+1=3, [1,3]->3+1=4, [2,3]->3+2=5, 共12
总和 = 12+12 = 24... 需要确认答案
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= min(70, nums.length)`

## 解题思路

对于排序后的数组 `sorted_nums`，子序列的最大值和最小值等于所有长度 1 到 k 的子集的最大值和最小值。

**排序后的贡献**：
- 对排序后的 `a[0] <= a[1] <= ... <= a[n-1]`
- `a[i]` 作为某子序列的**最小值**，当子序列中不含 a[0..i-1] 的元素，且包含 a[i]，其余元素在 a[i+1..n-1] 中选
- `a[i]` 作为最小值且子序列长度为 t（1<=t<=k）的方案数 = C(n-1-i, t-1)
- 总贡献：sum over i, t: a[i] * C(n-1-i, t-1) for t=1..k

同理对最大值：
- `a[i]` 作为最大值且子序列长度为 t 的方案数 = C(i, t-1)
- 总贡献：sum over i, t: a[i] * C(i, t-1) for t=1..k

## Python 代码实现

### 方法一：排序 + 组合数（推荐）

```python
from typing import List

class Solution:
    def minMaxSums(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        nums.sort()

        # 预计算组合数 C(n, r)，r 最大为 k
        # C[i][j] = C(i, j)
        max_n = n + 1
        fact = [1] * max_n
        for i in range(1, max_n):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * max_n
        inv_fact[max_n - 1] = pow(fact[max_n - 1], MOD - 2, MOD)
        for i in range(max_n - 2, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        def C(n, r):
            if r < 0 or r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

        total = 0

        for i in range(n):
            # a[i] 作为最小值的贡献
            # 子序列其余 t-1 个元素从 a[i+1..n-1] 中选，t 从 1 到 k
            # 方案数 = sum_{t=1}^{k} C(n-1-i, t-1) = sum_{j=0}^{k-1} C(n-1-i, j)
            min_cnt = 0
            for j in range(k):
                min_cnt = (min_cnt + C(n - 1 - i, j)) % MOD
            total = (total + nums[i] * min_cnt) % MOD

            # a[i] 作为最大值的贡献
            # 子序列其余 t-1 个元素从 a[0..i-1] 中选，t 从 1 到 k
            # 方案数 = sum_{t=1}^{k} C(i, t-1) = sum_{j=0}^{k-1} C(i, j)
            max_cnt = 0
            for j in range(k):
                max_cnt = (max_cnt + C(i, j)) % MOD
            total = (total + nums[i] * max_cnt) % MOD

        return total
```

### 方法二：预计算前缀组合数和

```python
from typing import List

class Solution:
    def minMaxSums(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        nums.sort()

        # 预计算 C(i, 0) + C(i, 1) + ... + C(i, k-1) 对每个 i
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        def C(n, r):
            if r < 0 or r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

        # 预计算 sum_C[i] = sum_{j=0}^{k-1} C(i, j)
        sum_C = [0] * (n + 1)
        for i in range(n + 1):
            s = 0
            for j in range(min(k, i + 1)):
                s = (s + C(i, j)) % MOD
            sum_C[i] = s

        total = 0
        for i in range(n):
            # 作为最小值：从右边 n-1-i 个中选 0 到 k-1 个
            total = (total + nums[i] * sum_C[n - 1 - i]) % MOD
            # 作为最大值：从左边 i 个中选 0 到 k-1 个
            total = (total + nums[i] * sum_C[i]) % MOD

        return total
```

## 复杂度分析

- 时间复杂度：O(n * k + n log n)，排序和组合数计算
- 空间复杂度：O(n)

## 关键点总结

1. 排序后，子序列的最小值是其中最小的元素，最大值是最大的元素
2. 利用组合数计算每个元素作为最值的次数
3. a[i] 作为最小值：其余元素只能从右边选；作为最大值：只能从左边选

## 易错点

1. 注意对长度 1 到 k 的子序列都要考虑（t=1 时子序列只有 a[i] 本身）
2. a[i] 作为最小值且长度为 t：C(n-1-i, t-1)，而不是 C(n-i, t-1)（不能再选 a[i]）
3. 最大值和最小值的贡献要都计算（每个子序列有一个 max 和一个 min）
