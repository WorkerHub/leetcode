## 题目描述

给你一个字符串 `road`，其中每个字符为 `'x'`（坑洼）或 `'.'`（平整）。以及一个整数 `budget`，表示可用预算。

修复一段连续 `k` 个坑洼（全为 `'x'`）的路段需要花费 `k + 1` 的预算（k 个坑洼加 1 个边界费用）。

你可以选择多个不重叠的连续坑洼段来修复，使修复的坑洼总数最大，且不超出预算。

**示例 1：**
```
输入：road = ".......xxx...x", budget = 6
输出：3
```

**示例 2：**
```
输入：road = "x.......xxx", budget = 6
输出：3
```

**提示：**
- `1 <= road.length <= 3 * 10^5`
- `road[i]` 为 `'x'` 或 `'.'`
- `1 <= budget <= 3 * 10^5`

## 解题思路

首先找出所有连续坑洼段，记录每段的长度。修复长度为 k 的段需要 k+1 预算，修复数量为 k。

贪心策略：优先修复最长的连续段（性价比高，修复 k 个坑洼只需 k+1 费用，越长单位费用越低）。将所有段长度降序排列，依次选择修复直到预算不足。

## Python 代码实现

### 方法一：贪心 + 排序（推荐）

```python
class Solution:
    def maxPotholes(self, road: str, budget: int) -> int:
        # 统计每段连续 'x' 的长度
        segments = []
        count = 0
        for c in road:
            if c == 'x':
                count += 1
            else:
                if count > 0:
                    segments.append(count)
                    count = 0
        if count > 0:
            segments.append(count)

        # 降序排列，优先修最长的段
        segments.sort(reverse=True)

        ans = 0
        for seg in segments:
            cost = seg + 1  # 修复该段的费用
            if budget >= cost:
                budget -= cost
                ans += seg
            elif budget > 1:
                # 只能修复部分（取 budget-1 个坑洼）
                fixed = budget - 1
                ans += fixed
                break
            else:
                break

        return ans
```

### 方法二：考虑预算边界

```python
class Solution:
    def maxPotholes(self, road: str, budget: int) -> int:
        segments = []
        i = 0
        n = len(road)
        while i < n:
            if road[i] == 'x':
                j = i
                while j < n and road[j] == 'x':
                    j += 1
                segments.append(j - i)
                i = j
            else:
                i += 1

        segments.sort(reverse=True)
        ans = 0
        for seg in segments:
            if budget <= 1:
                break
            # 最多修 budget-1 个（还需要 1 个边界费用）
            fix = min(seg, budget - 1)
            ans += fix
            budget -= fix + 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，n 为字符串长度，主要是排序
- 空间复杂度：O(n)

## 关键点总结

1. 修复长度 k 的段需要 k+1 费用，性价比随 k 增大而提高
2. 贪心：优先修最长的连续坑洼段
3. 预算不足时部分修复当前段（取 budget-1 个）

## 易错点

1. 每段修复费用是段长+1，不是段长
2. 部分修复时只取 budget-1 个，不是 budget 个
