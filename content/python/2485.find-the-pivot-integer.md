## 题目描述

给你一个正整数 `n`，找出满足以下条件的 **支点整数** `x`：

- `1` 到 `x` 之间所有整数之和 = `x` 到 `n` 之间所有整数之和

返回支点整数 `x`，若不存在返回 `-1`（保证答案唯一或不存在）。

**示例：**
```
输入：n = 8
输出：6
解释：1+2+3+4+5+6 = 6+7+8 = 21
```

**提示：**
- `1 <= n <= 1000`

## 解题思路

**数学公式：**

`1 + 2 + ... + x = x * (x + 1) / 2`

`x + (x+1) + ... + n = n*(n+1)/2 - (x-1)*x/2`

令两者相等：
`x*(x+1)/2 = n*(n+1)/2 - x*(x-1)/2`

整理：`x^2 = n*(n+1)/2`

若 `n*(n+1)/2` 是完全平方数，则 `x = sqrt(n*(n+1)/2)`，否则返回 -1。

## 代码实现

### 方法一：数学公式（推荐）

```python
import math

class Solution:
    def pivotInteger(self, n: int) -> int:
        # 总和
        total = n * (n + 1) // 2
        # 若 total 是完全平方数，x = sqrt(total)
        x = int(math.isqrt(total))
        if x * x == total:
            return x
        return -1
```

### 方法二：枚举（暴力）

```python
class Solution:
    def pivotInteger(self, n: int) -> int:
        total = n * (n + 1) // 2
        prefix = 0

        for x in range(1, n + 1):
            prefix += x
            suffix = total - prefix + x  # x 到 n 之和（x 算一次）
            if prefix == suffix:
                return x

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学公式 | O(1) 或 O(sqrt(n)) | O(1) |
| 枚举 | O(n) | O(1) |

## 关键点总结

1. 支点整数满足 `x^2 = n*(n+1)/2`
2. 使用 `math.isqrt` 取整数平方根，再验证是否完全平方

## 易错点

- 注意 `1 到 x` 和 `x 到 n` 都包含 x，所以 x 被计算两次，等式中 x 出现在两侧是对的
- 浮点数 sqrt 可能有精度问题，使用 `math.isqrt` 更安全
