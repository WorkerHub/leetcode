## 题目描述

现在有一个特殊的排名系统，依据参赛团队在投票人心中的次序进行排名，每个投票者都需要按从高到低的顺序对参与排名的所有团队进行排位。

排名规则如下：

1. 参赛团队的排名次序依照其所获得的**第一位置票的多少**而定；
2. 如果存在多个团队并列的情况，将继续考虑他们的**第二位置票**；
3. 以此类推，直到决出胜负，如果所有位置的票数都相同，则按队伍字母名称的字典序排列。

给你一个字符串数组 `votes`，其中 `votes[i]` 是第 `i` 个投票者对所有参赛队的排位结果（从高到低）。

请你根据以上规则返回所有参赛队排名后的结果字符串。

**示例 1：**
```
输入：votes = ["ABC","ACB","ABC","ACB","ACB"]
输出："ACB"
解释：
A 第一：5票，B 第一：0票，C 第一：0票 -> A 第一
A 第二：0票，C 第二：3票，B 第二：2票 -> C 第二
B 第三：3票，C 第三：2票 -> B 第三
```

**示例 2：**
```
输入：votes = ["WXYZ","XYZW"]
输出："XWYZ"
解释：
第一位：W:1, X:1 并列 -> 看第二位
第二位：W: 在XYZW中第4位=0，X: 在WXYZ中第2位 -> X更多 -> X第一
```

**示例 3：**
```
输入：votes = ["ZMNAGUEDSJYLBOPHRQICWFXTVK"]
输出："ZMNAGUEDSJYLBOPHRQICWFXTVK"
解释：只有一个投票者，直接输出。
```

**提示：**
- `1 <= votes.length <= 1000`
- `1 <= votes[i].length <= 26`
- `votes[i].length == votes[0].length`
- `votes[i][j]` 是英文大写字母
- `votes[i]` 中的字母互不相同
- `votes[0]` 中出现的字母在 `votes[i]` 中也出现

## 解题思路

**核心思路：** 统计每个队伍在各位置的得票数，然后按规则排序。

**数据结构：** 用哈希表 `vote_count[team][pos]` 记录队伍 `team` 在第 `pos` 位置的票数。

**排序键：** 对每个队伍 `t`，排序键为：
`(-vote_count[t][0], -vote_count[t][1], ..., -vote_count[t][n-1], t)`

其中票数取负（降序），最后追加队名字符（用于字典序决胜）。

## Python 代码实现

### 方法一：哈希表 + 自定义排序（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def rankTeams(self, votes: List[str]) -> str:
        n = len(votes[0])  # 队伍数量（也是每票的长度）
        
        # vote_count[team] = [第1位票数, 第2位票数, ..., 第n位票数]
        vote_count = defaultdict(lambda: [0] * n)
        
        for vote in votes:
            for pos, team in enumerate(vote):
                vote_count[team][pos] += 1
        
        # 获取所有队伍
        teams = list(vote_count.keys())
        
        # 排序：按各位置票数降序，最后按队名字典序升序
        teams.sort(key=lambda t: ([-v for v in vote_count[t]], t))
        
        return ''.join(teams)
```

### 方法二：使用元组作为排序键（代码更清晰）

```python
from typing import List
from collections import defaultdict

class Solution:
    def rankTeams(self, votes: List[str]) -> str:
        # 统计各队在各位置的票数
        n = len(votes[0])
        count = defaultdict(lambda: [0] * n)
        
        for vote in votes:
            for rank, team in enumerate(vote):
                count[team][rank] += 1
        
        # 构造排序键：各位票数取负（实现降序），最后加队名（升序决胜）
        def sort_key(team: str):
            return tuple(-count[team][i] for i in range(n)) + (team,)
        
        teams = sorted(count.keys(), key=sort_key)
        return ''.join(teams)
```

### 方法三：使用 functools.cmp_to_key（显式比较函数）

```python
from typing import List
from collections import defaultdict
import functools

class Solution:
    def rankTeams(self, votes: List[str]) -> str:
        n = len(votes[0])
        count = defaultdict(lambda: [0] * n)
        
        for vote in votes:
            for pos, team in enumerate(vote):
                count[team][pos] += 1
        
        def compare(t1: str, t2: str) -> int:
            """
            自定义比较函数
            返回负数表示 t1 < t2（t1 排前），正数表示 t1 > t2，0 表示相等
            """
            for pos in range(n):
                c1, c2 = count[t1][pos], count[t2][pos]
                if c1 != c2:
                    # 票数多的排前（降序）
                    return c2 - c1  # c2 > c1 返回正，表示 t1 要排后
            # 所有位置票数相同，按字典序
            return (t1 > t2) - (t1 < t2)  # 相当于 (t1 > t2) ? 1 : (t1 < t2 ? -1 : 0)
        
        teams = sorted(count.keys(), key=functools.cmp_to_key(compare))
        return ''.join(teams)
```

### 方法四：简洁版（利用 Python 列表负号技巧）

```python
from typing import List
from collections import Counter

class Solution:
    def rankTeams(self, votes: List[str]) -> str:
        n = len(votes[0])
        # 用 Counter 统计各位置票数
        # count[pos][team] = 票数
        teams = set(votes[0])
        
        # 每个队伍的完整得票向量
        scores = {t: [0] * n for t in teams}
        for vote in votes:
            for i, t in enumerate(vote):
                scores[t][i] += 1
        
        # 排序
        return ''.join(
            sorted(teams, key=lambda t: ([-x for x in scores[t]], t))
        )
```

## 复杂度分析

- 时间复杂度：O(V * N + N^2 * log N)，其中 V 是投票数，N 是队伍数（最多 26）。统计票数 O(V*N)，排序 O(N log N)，每次比较 O(N)，故排序 O(N^2 log N)。由于 N <= 26，常数较小。
- 空间复杂度：O(N^2)，存储每个队伍的各位置票数。

## 示例推导

以 `votes = ["ABC","ACB","ABC","ACB","ACB"]` 为例：

```
统计票数：
  A: [5, 0, 0]  （A 在第1位 5次，第2位 0次，第3位 0次）
  B: [0, 2, 3]  （B 在第1位 0次，第2位 2次，第3位 3次）
  C: [0, 3, 2]  （C 在第1位 0次，第2位 3次，第3位 2次）

排序键（取负后）：
  A: ([-5, 0, 0], 'A')  -> (-5, 0, 0, 'A')
  B: ([0, -2, -3], 'B') -> (0, -2, -3, 'B')
  C: ([0, -3, -2], 'C') -> (0, -3, -2, 'C')

排序：
  -5 < 0，所以 A 排第一
  C: (0,-3,-2) < B: (0,-2,-3)，所以 C 排第二，B 排第三

结果："ACB"
```

## 关键点总结

1. 用嵌套列表 `count[team][pos]` 存储各队在各位置的票数，O(N^2) 空间（N最多26）。
2. 排序键是各位置票数的降序（取负）加上队名（升序决胜），可以用元组直接作为 Python 排序键。
3. Python 的 `sorted` 对元组是按字典序比较，正好满足"先比第1位，相同比第2位..."的要求。
4. 取负的技巧：`[-v for v in count[t]]` 将降序变为升序，让 Python 默认升序排序实现降序效果。

## 易错点

- 排序键中队名要放在**最后**（决胜条件），不能放在前面。
- 票数要取负（降序），如果忘记取负会变成票少的排前。
- 注意 `defaultdict(lambda: [0]*n)` 中的 `n` 是在 lambda 创建时捕获的，确保 `n` 已经被正确赋值。
- `sorted(count.keys(), ...)` 中 `count.keys()` 的顺序是插入顺序（Python 3.7+），不影响最终排序结果。
