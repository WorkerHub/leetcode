## 题目描述

存在一个由 `n` 个不同元素组成的整数数组 `nums`，但你已经记不清具体内容。好在你还记得 `nums` 中每对相邻元素。

给你一个二维整数数组 `adjacentPairs`，大小为 `n - 1`，其中每个 `adjacentPairs[i] = [u_i, v_i]` 表示元素 `u_i` 和 `v_i` 在 `nums` 中相邻。

题目数据保证所有由 `adjacentPairs` 表示的相邻关系都是**有效**的，并且存在唯一一个满足条件的 `nums` 数组。

请你返回**原始数组** `nums`。

**示例 1：**
```
输入：adjacentPairs = [[2,1],[3,4],[3,2]]
输出：[1,2,3,4]
```

**提示：**
- `nums.length == n`
- `adjacentPairs.length == n - 1`
- `0 <= ui, vi <= 10^5`

## 解题思路

将相邻关系看成无向图的边，度为 1 的节点是数组的首尾元素（链的端点）。

从任意一个端点开始，沿着图遍历（DFS/BFS），还原数组。

## 代码实现

### 方法一：建图 + 从端点 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def restoreArray(self, adjacentPairs: List[List[int]]) -> List[int]:
        # 建立邻接表
        graph = defaultdict(list)
        for u, v in adjacentPairs:
            graph[u].append(v)
            graph[v].append(u)
        
        # 找端点（度为 1 的节点）
        start = None
        for node, neighbors in graph.items():
            if len(neighbors) == 1:
                start = node
                break
        
        # 从端点 DFS 还原数组
        n = len(adjacentPairs) + 1
        result = []
        visited = set()
        
        def dfs(node):
            result.append(node)
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    dfs(neighbor)
        
        dfs(start)
        return result
```

### 方法二：迭代遍历（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def restoreArray(self, adjacentPairs: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in adjacentPairs:
            graph[u].append(v)
            graph[v].append(u)
        
        # 找端点
        start = next(node for node, nb in graph.items() if len(nb) == 1)
        
        n = len(adjacentPairs) + 1
        result = [start]
        prev = None
        cur = start
        
        for _ in range(n - 1):
            # 找下一个节点（不是前一个）
            for neighbor in graph[cur]:
                if neighbor != prev:
                    result.append(neighbor)
                    prev, cur = cur, neighbor
                    break
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，建图和遍历各 O(n)
- **空间复杂度**：O(n)，邻接表和结果数组

## 关键点总结

1. 数组对应一条链，度为 1 的节点是链的端点
2. 从端点出发，沿链还原数组
3. 迭代版本通过记录前一个节点来避免重复访问

## 易错点

- 元素值可以为 0，不能用 0 判断未访问
