## 题目描述

`n` 支队伍参加比赛，给你一个 `n x n` 的布尔矩阵 `grid`，其中 `grid[i][j] == 1` 表示队伍 `i` 比队伍 `j` 强（反之亦然）。

冠军队伍是满足：对所有其他队伍 `j`（j != i），都有 `grid[i][j] == 1` 的队伍。

返回冠军队伍的编号。

**示例 1：**
```
输入：grid = [[0,1],[0,0]]
输出：0
解释：grid[0][1]=1，队伍 0 比队伍 1 强，所以队伍 0 是冠军
```

**示例 2：**
```
输入：grid = [[0,0,1],[1,0,1],[0,0,0]]
输出：1
```

**提示：**
- `n == grid.length == grid[i].length`
- `2 <= n <= 100`
- `grid[i][j]` 是 0 或 1
- 对于所有 `i`，`grid[i][i] = 0`
- 若 `grid[i][j] = 1`，则 `grid[j][i] = 0`
- 保证存在唯一冠军

## 解题思路

冠军队伍必须在一行中对所有其他队伍的列都为 1（除自身外）。

等价地：在列方向上，没有其他队伍能击败冠军，即冠军所在列中没有 1（除对角线）。

利用入度：计算每列的入度（被其他队伍"击败"的次数），入度为 0 的就是冠军。

## Python 代码实现

### 方法一：统计行和（推荐）

```python
from typing import List

class Solution:
    def findChampion(self, grid: List[List[int]]) -> int:
        n = len(grid)
        for i in range(n):
            # 检查队伍 i 是否能击败所有其他队伍
            if sum(grid[i]) == n - 1:
                return i
        return -1
```

### 方法二：统计列入度

```python
from typing import List

class Solution:
    def findChampion(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # 入度：第 j 列有多少个 1，代表有多少支队伍比 j 强
        in_degree = [sum(grid[i][j] for i in range(n)) for j in range(n)]
        for j in range(n):
            if in_degree[j] == 0:
                return j
        return -1
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 冠军行之和等于 n-1（对所有其他队伍都能获胜）
2. 冠军列之和等于 0（没有队伍能击败冠军）
3. 题目保证唯一冠军，所以一定能找到

## 易错点

1. 对角线 grid[i][i] = 0，行和为 n-1 表示对其他所有 n-1 支队伍都获胜
2. 不需要检查 grid[i][j] + grid[j][i] = 1，题目已保证
