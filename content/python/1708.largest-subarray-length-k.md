## 题目描述

数组 `A` 是 `nums` 的子数组且 `A.length == k`。在对 `nums` 的元素重新排列后，数组 `A` 有可能成为最大数组吗？如果是的话，返回 `true`。

更具体地，如果可以选择一个长度为 `k` 的子数组，通过重新排列 `nums` 中的元素（不一定需要选取连续元素），使得此子数组变为字典序最大，则返回 `true`。

**注意：** 实际上，给定长度 `k` 的子数组若其第一个元素是 `nums` 中最大值，则一定是字典序最大子数组（因为可以重新排列剩余部分）。

**示例 1：**
```
输入：nums = [1,4,5,2,3], k = 3
输出：[5,2,3]
```

**示例 2：**
```
输入：nums = [1,4,5,2,3], k = 2
输出：[5,2]
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- 数组中所有元素均不相同

## 解题思路

由于所有元素均不相同，字典序最大的长度为 `k` 的子数组，必然从 `nums` 中最大元素开始。

找到最大元素的下标 `idx`，返回 `nums[idx:idx+k]` 即可。

这是因为：第一个元素越大，字典序越大。第一个元素相同时才比较第二个，但题目保证所有元素不同，所以第一个元素最大的子数组就是答案。

## 代码实现

### 方法一：找最大值位置（推荐）

```python
from typing import List

class Solution:
    def largestSubarray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        
        # 找最大值的下标
        max_idx = 0
        for i in range(1, n):
            if nums[i] > nums[max_idx]:
                max_idx = i
        
        # 返回从最大值开始的长度为 k 的子数组
        return nums[max_idx:max_idx + k]
```

### 方法二：使用内置函数

```python
from typing import List

class Solution:
    def largestSubarray(self, nums: List[int], k: int) -> List[int]:
        # 找最大值的下标（从左到右第一个）
        max_idx = nums.index(max(nums))
        return nums[max_idx:max_idx + k]
```

## 复杂度分析

- **时间复杂度**：O(n)，找最大值需要遍历数组
- **空间复杂度**：O(k)，返回长度为 k 的子数组（或 O(1) 若只返回视图）

## 关键点总结

1. 所有元素不同，字典序最大子数组的第一个元素必须是整个数组的最大值
2. 直接找最大值下标，取之后 k 个元素

## 易错点

- 确保 `max_idx + k <= n`，题目保证 `k <= n`，所以不会越界
- 如果有重复元素就要考虑更复杂的比较，但本题保证无重复
