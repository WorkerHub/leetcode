## 题目描述

给你一个 n * n 的网格 grid ，上面放置着一些 1 x 1 x 1 的正方体。每个值 v = grid[i][j] 表示 v 个正方体叠放在对应单元格 (i, j) 上。

放置好正方体后，任何直接相邻的正方体都会互相粘在一起，形成一些不规则的三维形体。

请你返回最终这些形体的总表面积。

**提示：**
- n == grid.length == grid[i].length
- 1 <= n <= 50
- 0 <= grid[i][j] <= 50

## 解题思路

计算表面积 = 总立方体数 × 6 - 被遮挡的面

**被遮挡的面：**
- 同一列叠加：每层遮挡2个面
- 相邻列：min(height1, height2) × 2

## Python 代码实现

```python
class Solution:
    def surfaceArea(self, grid: List[List[int]]) -> int:
        n = len(grid)
        area = 0
        
        for i in range(n):
            for j in range(n):
                if grid[i][j] > 0:
                    # 基础面积
                    area += grid[i][j] * 4 + 2
                    
                    # 减去内部遮挡（竖直方向）
                    if grid[i][j] > 1:
                        area -= (grid[i][j] - 1) * 2
                    
                    # 减去相邻遮挡
                    if i > 0:
                        area -= min(grid[i][j], grid[i-1][j]) * 2
                    if j > 0:
                        area -= min(grid[i][j], grid[i][j-1]) * 2
        
        return area
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **每个立方体贡献6个面**
2. **减去遮挡**：竖直 + 水平
3. **边界处理**：只减一次
