## 题目描述

给你一个字符串 `sentence`，由若干用空格分隔的单词组成。如果满足以下条件，则句子是 **循环的**：

- 相邻单词中，前一个单词的最后一个字母等于后一个单词的第一个字母
- 句子的最后一个单词的最后一个字母等于第一个单词的第一个字母

**示例：**
```
输入：sentence = "leetcode exercises sound delightful"
输出：true
解释：l->e, e->s, s->d, d->l，最后 l==l
```

**提示：**
- `1 <= sentence.length <= 500`
- `sentence` 仅由小写英文字母和空格组成

## 解题思路

**直接模拟：**

1. 按空格分割单词
2. 检查每对相邻单词（前一个末尾 == 后一个开头）
3. 检查首尾（最后一个单词末尾 == 第一个单词开头）

或者更简洁：在原字符串中，检查每个空格前后的字符是否相同，以及首尾字符是否相同。

## 代码实现

### 方法一：分割单词（推荐）

```python
class Solution:
    def isCircularSentence(self, sentence: str) -> bool:
        words = sentence.split()

        # 检查首尾
        if words[-1][-1] != words[0][0]:
            return False

        # 检查相邻单词
        for i in range(len(words) - 1):
            if words[i][-1] != words[i + 1][0]:
                return False

        return True
```

### 方法二：直接在原字符串中检查

```python
class Solution:
    def isCircularSentence(self, sentence: str) -> bool:
        n = len(sentence)

        # 首尾字符相同
        if sentence[0] != sentence[-1]:
            return False

        # 每个空格前后字符相同
        for i in range(n):
            if sentence[i] == ' ' and sentence[i - 1] != sentence[i + 1]:
                return False

        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分割单词 | O(n) | O(n) |
| 原字符串 | O(n) | O(1) |

## 关键点总结

1. 循环：每个单词的尾字母 = 下一个单词的首字母（循环，包括最后和第一）
2. 在原字符串中，空格处相邻字符即为前一单词末尾和后一单词开头

## 易错点

- 注意句子首尾的循环条件也需要检查
- 空格处检查 `sentence[i-1]` 和 `sentence[i+1]`，不需要先分割
