## 题目描述

给你一个 rows x cols 的屏幕和一个用非空的单词列表组成的句子，请你计算出给定句子可以在屏幕上完整显示的次数。

注意：
1. 一个单词不能拆分成两行
2. 单词在句子中的顺序必须保持不变
3. 在一行中的两个连续单词必须用一个空格符分隔
4. 句子中的单词总量不会超过 100
5. 每个单词的长度大于 0 且不会超过 10
6. 1 ≤ rows, cols ≤ 20,000

**示例：**
```
输入：rows = 2, cols = 8, sentence = ["hello", "world"]
输出：1
解释：
hello---
world---
字符 '-' 表示空白
```

## 解题思路

核心思路：
1. 将句子拼接成一个长字符串（单词之间加空格）
2. 模拟填充过程，记录每行的起始位置
3. 使用记忆化避免重复计算

## Python 代码实现

### 方法一：模拟 + 记忆化

```python
from typing import List

class Solution:
    def wordsTyping(self, sentence: List[str], rows: int, cols: int) -> int:
        """
        模拟填充过程
        """
        # 拼接句子
        s = ' '.join(sentence) + ' '
        length = len(s)
        
        # 记录每行起始位置在句子中的索引
        memo = {}
        count = 0
        pos = 0  # 当前在句子中的位置
        
        for _ in range(rows):
            if pos in memo:
                # 使用缓存
                count += memo[pos][0]
                pos = memo[pos][1]
            else:
                start = pos
                # 这一行能放 cols 个字符
                pos += cols
                
                # 如果当前字符是空格，跳过
                while pos < length and s[pos] != ' ':
                    pos -= 1
                
                # 跳过空格
                pos += 1
                
                # 计算完成了多少次句子
                times = pos // length
                count += times
                pos %= length
                
                # 缓存
                memo[start] = (times, pos)
        
        return count
```

### 方法二：优化版

```python
from typing import List

class Solution:
    def wordsTyping(self, sentence: List[str], rows: int, cols: int) -> int:
        """
        优化的模拟
        """
        s = ' '.join(sentence) + ' '
        length = len(s)
        pos = 0
        
        for _ in range(rows):
            pos += cols
            
            # 如果落在空格上，前进一位
            if s[pos % length] == ' ':
                pos += 1
            else:
                # 回退到上一个空格
                while pos > 0 and s[(pos - 1) % length] != ' ':
                    pos -= 1
        
        return pos // length
```

## 复杂度分析

- **时间复杂度**：O(rows)
- **空间复杂度**：O(length)

## 关键点总结

1. 拼接句子为字符串
2. 模拟填充过程
3. 使用取模处理循环
4. 记忆化优化
