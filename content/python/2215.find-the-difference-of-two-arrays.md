## 题目描述

给你两个下标从 0 开始的整数数组 `nums1` 和 `nums2`，请你返回一个大小为 2 的列表 `answer`，其中：

- `answer[0]` 是 `nums1` 中所有**不**存在于 `nums2` 中的**不同**整数组成的列表。
- `answer[1]` 是 `nums2` 中所有**不**存在于 `nums1` 中的**不同**整数组成的列表。

结果列表中的元素可以按**任意顺序**返回。

**示例 1：**
```
输入：nums1 = [1,2,3], nums2 = [2,4,6]
输出：[[1,3],[4,6]]
```

**示例 2：**
```
输入：nums1 = [1,2,3,3], nums2 = [1,1,2,2]
输出：[[3],[]]
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `-1000 <= nums1[i], nums2[i] <= 1000`

## 解题思路

将两个数组分别转为集合，利用集合的差运算直接求解。

- `nums1` 中不在 `nums2` 的元素：`set(nums1) - set(nums2)`
- `nums2` 中不在 `nums1` 的元素：`set(nums2) - set(nums1)`

## 代码实现

### 方法一：集合差运算（推荐）

```python
from typing import List

class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        # 转为集合，利用集合差操作
        s1 = set(nums1)
        s2 = set(nums2)
        # s1 - s2：在 nums1 但不在 nums2 的元素
        # s2 - s1：在 nums2 但不在 nums1 的元素
        return [list(s1 - s2), list(s2 - s1)]
```

### 方法二：手动遍历

```python
from typing import List

class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        s2 = set(nums2)
        s1 = set(nums1)

        diff1 = []
        seen1 = set()
        for x in nums1:
            if x not in s2 and x not in seen1:
                diff1.append(x)
                seen1.add(x)

        diff2 = []
        seen2 = set()
        for x in nums2:
            if x not in s1 and x not in seen2:
                diff2.append(x)
                seen2.add(x)

        return [diff1, diff2]
```

### 方法三：一行解法

```python
from typing import List

class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        # Python 最简洁写法
        return [list(set(nums1) - set(nums2)), list(set(nums2) - set(nums1))]
```

## 复杂度分析

- 时间复杂度：O(m + n)，将两个数组转为集合，再求差。
- 空间复杂度：O(m + n)，集合存储元素。

## 关键点总结

1. 集合天然去重，直接用 `-` 运算符求差集。
2. Python 的集合运算语义清晰，代码极简。
3. 结果顺序无所谓，集合转列表即可。

## 易错点

- 直接比较数组元素（不转集合）会有重复元素，需额外去重。
- 注意是"不同整数"，即结果中每个数只出现一次。
