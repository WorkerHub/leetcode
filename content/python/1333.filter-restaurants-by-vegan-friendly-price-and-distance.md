## 题目描述

给你一个餐馆信息数组 `restaurants`，其中 `restaurants[i] = [id_i, rating_i, veganFriendly_i, price_i, distance_i]`。你必须使用以下三个过滤器来过滤这些餐馆信息。

其中素食者友好过滤器 `veganFriendly` 的值可以为 `true` 或者 `false`，如果该过滤器设为 `true`，则只考虑 `veganFriendly_i` 为 `true` 的餐馆，本过滤器设为 `false` 时，可以考虑所有餐馆。此外，我们还有最大价格过滤器 `maxPrice` 和最大距离过滤器 `maxDistance`，分别用来过滤价格大于 `maxPrice` 或距离大于 `maxDistance` 的餐馆。

过滤后返回餐馆的 **id**，按照 `rating` 从高到低排序。如果 `rating` 相同，则按 `id` 从高到低排序。请返回过滤后餐馆的 `id` 数组。

**示例 1：**
```
输入：restaurants = [[1,4,1,40,10],[2,8,0,50,5],[3,8,1,30,4],[4,10,0,10,3],[5,1,1,15,1]],
     veganFriendly = 1, maxPrice = 50, maxDistance = 10
输出：[3,1,5]
解释：
餐馆 1：[1,4,1,40,10] 满足所有条件，id = 1
餐馆 2：[2,8,0,50,5] 不满足条件（veganFriendly 为 0，但 veganFriendly 过滤器为 1）
餐馆 3：[3,8,1,30,4] 满足所有条件，id = 3
餐馆 4：[4,10,0,10,3] 不满足条件（veganFriendly 为 0）
餐馆 5：[5,1,1,15,1] 满足所有条件，id = 5
按 rating 降序排序：3（rating=8）, 1（rating=4）, 5（rating=1）
```

**示例 2：**
```
输入：restaurants = [[1,4,1,40,10],[2,8,0,50,5],[3,8,1,30,4],[4,10,0,10,3],[5,1,1,15,1]],
     veganFriendly = 0, maxPrice = 50, maxDistance = 10
输出：[4,3,2,1,5]
```

**提示：**
- `1 <= restaurants.length <= 10^4`
- `restaurants[i].length == 5`
- `1 <= id_i, rating_i, price_i, distance_i <= 10^5`
- `veganFriendly_i` 为 `0` 或 `1`
- `veganFriendly` 为 `0` 或 `1`

## 解题思路

**算法步骤：**
1. 遍历餐馆列表，按三个条件过滤
2. 对满足条件的餐馆按 `(rating, id)` 降序排序
3. 返回排序后的 id 列表

**过滤条件：**
- 若 `veganFriendly == 1`，则 `veganFriendly_i` 必须为 1
- `price_i <= maxPrice`
- `distance_i <= maxDistance`

## Python 代码实现

### 方法一：列表推导 + 排序（推荐）

```python
from typing import List

class Solution:
    def filterRestaurants(self, restaurants: List[List[int]],
                          veganFriendly: int, maxPrice: int,
                          maxDistance: int) -> List[int]:
        # 过滤：素食友好 + 价格 + 距离
        filtered = [r for r in restaurants
                    if (not veganFriendly or r[2] == 1)  # 素食过滤
                    and r[3] <= maxPrice                   # 价格过滤
                    and r[4] <= maxDistance]               # 距离过滤
        
        # 按 rating 降序，rating 相同按 id 降序排序
        filtered.sort(key=lambda r: (r[1], r[0]), reverse=True)
        
        # 返回 id 列表
        return [r[0] for r in filtered]
```

### 方法二：逐步过滤 + 排序（步骤清晰版）

```python
from typing import List

class Solution:
    def filterRestaurants(self, restaurants: List[List[int]],
                          veganFriendly: int, maxPrice: int,
                          maxDistance: int) -> List[int]:
        result = []
        
        for r in restaurants:
            rid, rating, vegan, price, distance = r
            
            # 条件 1：素食过滤（veganFriendly=1 时只保留 vegan=1 的）
            if veganFriendly == 1 and vegan != 1:
                continue
            
            # 条件 2：价格过滤
            if price > maxPrice:
                continue
            
            # 条件 3：距离过滤
            if distance > maxDistance:
                continue
            
            result.append(r)
        
        # 按 rating 降序，rating 相同则 id 降序
        result.sort(key=lambda r: (r[1], r[0]), reverse=True)
        
        return [r[0] for r in result]
```

### 方法三：使用 filter 函数

```python
from typing import List

class Solution:
    def filterRestaurants(self, restaurants: List[List[int]],
                          veganFriendly: int, maxPrice: int,
                          maxDistance: int) -> List[int]:
        def is_valid(r):
            """判断餐馆是否满足所有过滤条件"""
            _, rating, vegan, price, distance = r
            # 若 veganFriendly=1 则要求 vegan=1，否则不限制
            vegan_ok = (not veganFriendly) or (vegan == 1)
            return vegan_ok and price <= maxPrice and distance <= maxDistance
        
        # 过滤 + 排序 + 提取 id
        filtered = list(filter(is_valid, restaurants))
        filtered.sort(key=lambda r: (r[1], r[0]), reverse=True)
        return [r[0] for r in filtered]
```

### 方法四：一行写法（展示 Python 表达力）

```python
from typing import List

class Solution:
    def filterRestaurants(self, restaurants: List[List[int]],
                          veganFriendly: int, maxPrice: int,
                          maxDistance: int) -> List[int]:
        return [
            r[0] for r in sorted(
                # 过滤
                (r for r in restaurants
                 if (not veganFriendly or r[2]) and r[3] <= maxPrice and r[4] <= maxDistance),
                # 排序键：(rating, id) 降序
                key=lambda r: (r[1], r[0]),
                reverse=True
            )
        ]
```

## 关键点总结

1. 三个过滤条件的逻辑：`veganFriendly` 为 0 时不限制素食，为 1 时只保留素食餐馆
2. 排序键是 `(rating, id)` 两级，均为降序
3. Python 的 `sort(key=..., reverse=True)` 可以处理多级排序

## 易错点

1. 素食过滤的条件：`veganFriendly=0` 时不过滤任何餐馆，`veganFriendly=1` 时只保留 `vegan=1`
   - 错误写法：`r[2] == veganFriendly`（当 `veganFriendly=0` 时会过滤掉 `vegan=1` 的餐馆）
   - 正确写法：`not veganFriendly or r[2] == 1`
2. 排序是降序，不要忘记 `reverse=True`
3. 注意返回的是 `id`，不是餐馆的完整信息
