## 题目描述

给你一个正整数数组 `nums`，返回 `nums` 的非空子序列的不同最大公约数（GCD）数目。

**示例 1：**
```
输入：nums = [6,10,3]
输出：5
解释：不同的 GCD 为 1,2,3,5,6
```

**示例 2：**
```
输入：nums = [5,15,40,5,6]
输出：7
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 2 * 10^5`

## 解题思路

**枚举 GCD + 数论**：

对于每个候选 GCD 值 `g`（从 1 到 max(nums)），判断是否存在一个子序列其 GCD 恰好等于 `g`。

子序列的 GCD 为 `g` 当且仅当：`nums` 中所有是 `g` 的倍数的元素，其 GCD 恰好为 `g`。

**算法**：
1. 用集合存储 nums 中的所有值，O(1) 查询
2. 对每个 g 从 1 到 max(nums)：
   - 枚举 g 的所有倍数 `g, 2g, 3g, ...`，若该倍数在 nums 中，则累计这些值的 GCD
   - 若最终 GCD 等于 g，则 g 是一个合法的子序列 GCD

## 代码实现

### 方法一：枚举 GCD（推荐）

```python
from math import gcd
from typing import List

class Solution:
    def countDifferentSubsequenceGCDs(self, nums: List[int]) -> int:
        max_val = max(nums)
        num_set = set(nums)  # 用集合加速查询
        result = 0

        for g in range(1, max_val + 1):
            # 枚举 g 的所有倍数，计算这些数的 GCD
            current_gcd = 0
            multiple = g
            while multiple <= max_val:
                if multiple in num_set:
                    current_gcd = gcd(current_gcd, multiple)
                    if current_gcd == g:
                        # 已经确认 g 是合法的子序列 GCD，提前退出
                        break
                multiple += g

            if current_gcd == g:
                result += 1

        return result
```

### 方法二：预处理倍数关系（优化版）

```python
from math import gcd
from typing import List

class Solution:
    def countDifferentSubsequenceGCDs(self, nums: List[int]) -> int:
        max_val = max(nums)
        present = [False] * (max_val + 1)
        for x in nums:
            present[x] = True

        result = 0
        for g in range(1, max_val + 1):
            current_gcd = 0
            for multiple in range(g, max_val + 1, g):
                if present[multiple]:
                    current_gcd = gcd(current_gcd, multiple)
                    if current_gcd == g:
                        break
            if current_gcd == g:
                result += 1
        return result
```

## 复杂度分析

- **时间复杂度**：O(max_val * log(max_val))，对每个 g 枚举其倍数，总数为调和级数 O(max_val * log(max_val))
- **空间复杂度**：O(max_val)，布尔数组

## 关键点总结

1. 子序列 GCD 为 g 等价于：所有 g 的倍数在 nums 中出现的元素的 GCD 等于 g
2. 枚举 g 时，只需枚举 g 的倍数，总时间复杂度由调和级数保证为 O(max_val * log(max_val))
3. 发现 current_gcd == g 时可提前退出内层循环

## 易错点

- `gcd(0, x) = x`，初始 `current_gcd = 0` 是正确的技巧
- 若 g 的倍数中没有在 nums 中出现，`current_gcd` 保持 0，不等于 g，正确跳过
