## 题目描述

给你一个整数数组 `arr`，只有可以将其划分为三个和相等的非空部分时才返回 `true`，否则返回 `false`。

形式上，如果可以找到索引 `i + 1 < j` 且满足 `(arr[0] + arr[1] + ... + arr[i] == arr[i + 1] + arr[i + 2] + ... + arr[j - 1] == arr[j] + arr[j + 1] + ... + arr[arr.length - 1])` 就可以将数组三等分。

**示例 1：**
```
输入：arr = [0,2,1,-6,6,-7,9,1,2,0,1]
输出：true
解释：0 + 2 + 1 = -6 + 6 - 7 + 9 + 1 = 2 + 0 + 1
```

**示例 2：**
```
输入：arr = [0,2,1,-6,6,7,9,-1,2,0,1]
输出：false
```

**示例 3：**
```
输入：arr = [3,3,6,5,-2,2,5,1,-9,4]
输出：true
解释：3 + 3 = 6 = 5 - 2 + 2 + 5 + 1 - 9 + 4
```

**提示：**
- `3 <= arr.length <= 5 * 10^4`
- `-10^4 <= arr[i] <= 10^4`

## 解题思路

**核心观察**：
1. 如果能三等分，每部分的和必须等于总和的1/3
2. 总和必须能被3整除
3. 贪心策略：找到第一个和为sum/3的部分，再找第二个

**算法步骤**：
1. 计算总和，如果不能被3整除，返回false
2. 贪心地从左往右找第一个和为target的部分
3. 继续找第二个和为target的部分
4. 如果找到两个，剩余部分自动满足

## Python 代码实现

### 方法一：贪心查找（推荐）⭐

```python
from typing import List

class Solution:
    def canThreePartsEqualSum(self, arr: List[int]) -> bool:
        """
        贪心策略：依次找到两个和为sum/3的部分
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        total = sum(arr)
        
        # 总和必须能被3整除
        if total % 3 != 0:
            return False
        
        target = total // 3
        current_sum = 0
        count = 0  # 找到的部分数量
        
        # 注意：不遍历最后一个元素，保证第三部分非空
        for i in range(len(arr) - 1):
            current_sum += arr[i]
            
            # 找到一个和为target的部分
            if current_sum == target:
                count += 1
                current_sum = 0
                
                # 找到两个部分即可，剩余自动是第三部分
                if count == 2:
                    return True
        
        return False
```

### 方法二：双指针

```python
class Solution:
    def canThreePartsEqualSum(self, arr: List[int]) -> bool:
        """
        双指针从两端向中间查找
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        total = sum(arr)
        
        if total % 3 != 0:
            return False
        
        target = total // 3
        n = len(arr)
        
        # 从左边找第一个部分
        left_sum = 0
        left = 0
        while left < n - 2:
            left_sum += arr[left]
            if left_sum == target:
                break
            left += 1
        
        # 从右边找第三个部分
        right_sum = 0
        right = n - 1
        while right > left + 1:
            right_sum += arr[right]
            if right_sum == target:
                break
            right -= 1
        
        # 检查是否找到有效的划分
        # left和right之间至少要有一个元素（第二部分）
        return left_sum == target and right_sum == target and left + 1 < right
```

### 方法三：详细注释版

```python
class Solution:
    def canThreePartsEqualSum(self, arr: List[int]) -> bool:
        """
        贪心策略详细版
        
        关键点：
        1. 总和必须能被3整除
        2. 找到两个和为target的部分即可
        3. 要保证每部分非空
        """
        total_sum = sum(arr)
        
        # 检查总和是否能被3整除
        if total_sum % 3 != 0:
            return False
        
        target = total_sum // 3
        current = 0
        parts_found = 0
        
        # 遍历数组（不包括最后一个元素）
        # 保证第三部分至少有一个元素
        for i in range(len(arr) - 1):
            current += arr[i]
            
            # 当前累加和等于目标值
            if current == target:
                parts_found += 1
                current = 0  # 重置累加和，开始下一部分
                
                # 已找到两个部分
                if parts_found == 2:
                    # 剩余元素自动构成第三部分，和也是target
                    return True
        
        return False
```

### 方法四：特殊情况优化

```python
class Solution:
    def canThreePartsEqualSum(self, arr: List[int]) -> bool:
        """
        优化：处理target为0的特殊情况
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        total = sum(arr)
        
        if total % 3 != 0:
            return False
        
        target = total // 3
        current_sum = 0
        count = 0
        
        for i in range(len(arr)):
            current_sum += arr[i]
            
            if current_sum == target:
                count += 1
                current_sum = 0
        
        # 特殊情况：target为0时，可能找到超过3个部分
        # 例如：[0,0,0,0] target=0，可以有多种划分
        if target == 0:
            return count >= 3
        else:
            return count == 3
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)，只使用常数额外空间

## 图解示例

以 `arr = [0,2,1,-6,6,-7,9,1,2,0,1]` 为例：

```
总和 = 0+2+1-6+6-7+9+1+2+0+1 = 9
目标 = 9 / 3 = 3

遍历过程：
i=0: sum=0
i=1: sum=2
i=2: sum=3 → 找到第1部分！count=1, sum=0
i=3: sum=-6
i=4: sum=0
i=5: sum=-7
i=6: sum=2
i=7: sum=3 → 找到第2部分！count=2, sum=0
返回 true

划分结果：
第1部分：[0,2,1] = 3
第2部分：[-6,6,-7,9,1] = 3
第3部分：[2,0,1] = 3
```

## 关键点总结

1. **必要条件**：总和能被3整除
2. **贪心策略**：找到两个部分即可，第三部分自动满足
3. **边界保证**：循环不包括最后一个元素，保证第三部分非空
4. **特殊情况**：target为0时可能有多个有效划分
5. **提前返回**：找到两个部分立即返回true

## 易错点

1. **忘记检查总和**：必须先判断总和是否能被3整除
2. **最后一个元素**：循环范围要保证第三部分非空
3. **重置累加和**：找到一个部分后要重置current_sum
4. **target为0**：要特殊处理，可能有超过3个0和部分
5. **部分数量**：只需找到2个部分，不是3个
