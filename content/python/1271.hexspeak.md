## 题目描述

将十进制整数 `num`（以字符串形式给出）转换为十六进制表示，然后进行以下替换：
- 将所有的 `0` 替换为 `O`（大写字母 O）
- 将所有的 `1` 替换为 `I`（大写字母 I）

如果最终结果**只包含**以下字符：`A, B, C, D, E, F, I, O`，则返回该结果字符串；否则返回 `"ERROR"`。

**示例 1：**
```
输入：num = "257"
输出："IOI"
解释：257 的十六进制是 101，替换后 1->I, 0->O, 1->I，得到 "IOI"，只含 I 和 O，合法。
```

**示例 2：**
```
输入：num = "3"
输出："ERROR"
解释：3 的十六进制是 3，替换后仍是 "3"，含有数字 3，不合法。
```

**示例 3：**
```
输入：num = "13"
输出："D"
解释：13 的十六进制是 D，替换后不需要改变，只含 D，合法。
```

**示例 4：**
```
输入：num = "16"
输出："IO"
解释：16 的十六进制是 10，替换后 1->I, 0->O，得到 "IO"，合法。
```

**示例 5：**
```
输入：num = "730"
输出："ERROR"
解释：730 的十六进制是 2DA，含有 2 和 A，2 不在合法字符集中，返回 "ERROR"。
```

**提示：**
- `1 <= num <= 10^12`
- `num` 不含前导零

---

## 解题思路

本题分为三步：
1. 将十进制字符串转为十进制整数
2. 将整数转为十六进制字符串（转为大写）
3. 检查每个字符：
   - `0` 替换为 `O`
   - `1` 替换为 `I`
   - `A-F` 保留
   - 其他字符（2-9）返回 `"ERROR"`

**十六进制的字符范围：** `0-9` 和 `A-F`（大写）。转换后，`2-9` 这 8 个数字字符是导致 "ERROR" 的原因。

## Python 代码实现

### 方法一：直接转换（推荐）

```python
class Solution:
    def toHexspeak(self, num: str) -> str:
        # 第一步：将字符串转为整数，再转为十六进制（大写）
        # hex() 返回如 "0x1a1"，需要去掉 "0x" 前缀并转大写
        hex_str = hex(int(num))[2:].upper()

        # 第二步：替换 0 -> O，1 -> I
        hex_str = hex_str.replace('0', 'O').replace('1', 'I')

        # 第三步：检查是否只含合法字符（A-F, I, O）
        valid_chars = set('ABCDEFIO')
        for ch in hex_str:
            if ch not in valid_chars:
                return "ERROR"

        return hex_str
```

**执行演示：**
```
num = "257"
int("257") = 257
hex(257) = "0x101"
[2:] = "101"
.upper() = "101"（本来就没有小写字母）
replace('0','O') = "1O1"
replace('1','I') = "IOI"
检查：I,O,I 都在合法字符集 ✓
返回 "IOI"
```

### 方法二：使用 translate 方法（简洁版）

Python 字符串的 `translate` 方法可以一次性完成字符替换：

```python
class Solution:
    def toHexspeak(self, num: str) -> str:
        # 构建翻译表：0->O, 1->I
        table = str.maketrans('01', 'OI')

        # 转十六进制并替换
        hex_str = hex(int(num))[2:].upper().translate(table)

        # 合法字符集
        valid_chars = set('ABCDEFIO')

        # 检查是否合法
        return hex_str if all(c in valid_chars for c in hex_str) else "ERROR"
```

---

### 方法三：逐位构建（手动进制转换，了解原理）

```python
class Solution:
    def toHexspeak(self, num: str) -> str:
        n = int(num)
        # 十六进制各位对应的字符（0-15 映射）
        hex_chars = {
            0: 'O',   # 0 替换为 O
            1: 'I',   # 1 替换为 I
            10: 'A',
            11: 'B',
            12: 'C',
            13: 'D',
            14: 'E',
            15: 'F',
        }

        result = []
        while n > 0:
            remainder = n % 16  # 取余得到当前最低位
            if remainder not in hex_chars:
                # 2-9 这些数字不在映射表中，直接返回 ERROR
                return "ERROR"
            result.append(hex_chars[remainder])
            n //= 16  # 去掉最低位

        # 结果是从低位到高位构建的，需要反转
        return ''.join(reversed(result))
```

**注意：** 方法三用于理解手动进制转换的原理，生产中直接用 `hex()` 更简洁。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一 | O(log n) | O(log n) | 十六进制位数约为 log16(n) |
| 方法二 | O(log n) | O(log n) | 同方法一，用 translate 更高效 |
| 方法三 | O(log n) | O(log n) | 手动除法，每次取余 |

其中 n 为输入整数的值（最大 10^12），十六进制位数约为 40 位以内。

## 关键点总结

1. **Python 内置的 hex() 函数**：`hex(n)` 返回 `"0x..."` 格式，需要 `[2:]` 去掉前缀，`.upper()` 转大写。
2. **合法字符集**：转换后只有 `A, B, C, D, E, F, I, O` 是合法的（即原来十六进制中的 `A-F` 以及 `0->O`, `1->I`）。导致 ERROR 的字符是 `2-9`。
3. **替换顺序**：先把 `0->O`，再把 `1->I`（两者独立，顺序无关）。
4. **输入是字符串**：`num` 是字符串形式，需要先 `int(num)` 转换为整数再处理。

---

## 易错点

1. **忘记 `.upper()`**：`hex()` 对于 A-F 会返回小写（如 `"0x1a"`），必须转大写才能与合法字符集对比。
2. **`hex()` 返回带前缀**：`hex(16)` 返回 `"0x10"`，需要 `[2:]` 去掉 `"0x"`，不要忘记。
3. **`num` 是字符串**：直接对字符串调用 `hex()` 会报错，必须先 `int(num)` 转整数。
4. **不要提前替换 0 和 1**：必须先转十六进制，再替换 0 和 1。如果直接在十进制时处理，逻辑错误。
5. **合法字符集包含 I 和 O**：替换后的结果中 `I` 和 `O` 是合法的，不要把它们误判为非法字符。

## 学习建议

1. **掌握 Python 进制转换**：`bin()` 转二进制、`oct()` 转八进制、`hex()` 转十六进制，结果都以 `"0b"/"0o"/"0x"` 开头，注意用 `[2:]` 去掉前缀。
2. **字符串替换方法**：`str.replace()` 用于简单替换，`str.translate(str.maketrans())` 用于批量字符映射，两种都要掌握。
3. **理解进制转换原理**：方法三展示了手动实现进制转换的过程——反复取余，这是所有进制转换的本质，有助于处理题目中不能用内置函数的情况。
