## 题目描述

给你一个整数数组 nums，每次操作会从中选择一个元素并将该元素的值减少 1。

如果符合下列情况之一，则数组 A 就是锯齿数组：
- 每个偶数索引对应的元素都大于相邻的元素，即 A[0] > A[1] < A[2] > A[3] < A[4] > ...
- 或者，每个奇数索引对应的元素都大于相邻的元素，即 A[0] < A[1] > A[2] < A[3] > A[4] < ...

返回将数组 nums 转换为锯齿数组所需的最小操作次数。

**示例 1：**
```
输入：nums = [1,2,3]
输出：2
解释：我们可以把 2 递减到 0，或把 3 递减到 1。
```

**示例 2：**
```
输入：nums = [9,6,1,6,2]
输出：4
```

**提示：**
- 1 <= nums.length <= 1000
- 1 <= nums[i] <= 1000

## 解题思路

锯齿数组有两种模式：
1. **偶数索引元素大**：nums[0] > nums[1] < nums[2] > nums[3] < ...
2. **奇数索引元素大**：nums[0] < nums[1] > nums[2] < nums[3] > ...

**核心观察：**

1. **只能减少，不能增加**：
   - 要让某个位置成为局部最小值/最大值
   - 如果要成为最大值，需要减少相邻元素
   - 如果要成为最小值，需要减少自己

2. **贪心策略**：
   - 分别尝试两种模式，取操作次数最小的
   - 对于每种模式，贪心地减少需要调整的元素

3. **两种模式的计算**：
   - **模式1**（偶数位置大）：让所有奇数位置元素比相邻元素小
   - **模式2**（奇数位置大）：让所有偶数位置元素比相邻元素小

4. **计算减少次数**：
   - 对于位置 i，如果需要它比相邻元素小
   - 需要减少到 min(左邻居, 右邻居) - 1
   - 操作次数 = max(0, nums[i] - min(neighbors) + 1)

## Python 代码实现

### 方法一：贪心 - 分别计算两种模式 ⭐

```python
from typing import List

class Solution:
    def movesToMakeZigzag(self, nums: List[int]) -> int:
        """
        分别计算两种锯齿模式需要的操作次数，取最小值
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(nums)
        if n <= 1:
            return 0
        
        # 计算两种模式的操作次数
        # 模式1：让奇数位置元素小（偶数位置是峰）
        moves_odd = self.calculate_moves(nums, 1)
        
        # 模式2：让偶数位置元素小（奇数位置是峰）
        moves_even = self.calculate_moves(nums, 0)
        
        return min(moves_odd, moves_even)
    
    def calculate_moves(self, nums: List[int], start: int) -> int:
        """
        计算让 start, start+2, start+4... 位置元素成为谷底所需的操作次数
        """
        moves = 0
        n = len(nums)
        
        # 遍历需要成为谷底的位置
        for i in range(start, n, 2):
            # 找到相邻元素的最小值
            min_neighbor = float('inf')
            
            # 左邻居
            if i > 0:
                min_neighbor = min(min_neighbor, nums[i - 1])
            
            # 右邻居
            if i < n - 1:
                min_neighbor = min(min_neighbor, nums[i + 1])
            
            # 如果当前元素不小于最小邻居，需要减少
            if min_neighbor != float('inf') and nums[i] >= min_neighbor:
                moves += nums[i] - min_neighbor + 1
        
        return moves
```

### 方法二：简化版（一次遍历计算两种模式）⭐ 推荐

```python
class Solution:
    def movesToMakeZigzag(self, nums: List[int]) -> int:
        """
        一次遍历同时计算两种模式
        """
        n = len(nums)
        moves = [0, 0]  # moves[0] 偶数位置小，moves[1] 奇数位置小
        
        for i in range(n):
            # 计算左右邻居的最小值
            left = nums[i - 1] if i > 0 else float('inf')
            right = nums[i + 1] if i < n - 1 else float('inf')
            min_neighbor = min(left, right)
            
            # 如果当前位置需要成为谷底（比相邻都小）
            # i % 2 == 0: 对应 moves[0]（偶数位置小）
            # i % 2 == 1: 对应 moves[1]（奇数位置小）
            if nums[i] >= min_neighbor:
                moves[i % 2] += nums[i] - min_neighbor + 1
        
        return min(moves)
```

### 方法三：列表推导式（更 Pythonic）

```python
class Solution:
    def movesToMakeZigzag(self, nums: List[int]) -> int:
        """
        使用列表推导式，代码更简洁
        """
        n = len(nums)
        
        def count_moves(start: int) -> int:
            """计算从 start 开始，每隔一个位置减少的总次数"""
            return sum(
                max(0, nums[i] - min(
                    nums[i - 1] if i > 0 else float('inf'),
                    nums[i + 1] if i < n - 1 else float('inf')
                ) + 1)
                for i in range(start, n, 2)
            )
        
        return min(count_moves(0), count_moves(1))
```

### 方法四：原地修改版本（仅用于理解）

```python
class Solution:
    def movesToMakeZigzag(self, nums: List[int]) -> int:
        """
        原地修改数组来计算（注意：会修改原数组的副本）
        不推荐，仅用于理解思路
        """
        def try_pattern(arr: List[int], positions: List[int]) -> int:
            """尝试让指定位置的元素变小"""
            moves = 0
            for i in positions:
                # 计算需要减少到多少
                target = float('inf')
                if i > 0:
                    target = min(target, arr[i - 1])
                if i < len(arr) - 1:
                    target = min(target, arr[i + 1])
                
                if target != float('inf') and arr[i] >= target:
                    decrease = arr[i] - target + 1
                    moves += decrease
            
            return moves
        
        # 尝试两种模式
        even_positions = list(range(0, len(nums), 2))
        odd_positions = list(range(1, len(nums), 2))
        
        return min(
            try_pattern(nums[:], even_positions),
            try_pattern(nums[:], odd_positions)
        )
```

## 复杂度分析

**时间复杂度**：O(n)
- 需要遍历数组一次或两次
- 每个元素只访问常数次

**空间复杂度**：O(1)
- 只使用常数额外空间
- 不需要额外数组

## 关键点总结

1. **两种模式**：偶数位大或奇数位大
2. **贪心思想**：只减少不增加，每次减到刚好满足条件
3. **局部最优**：每个位置独立计算，不影响其他位置
4. **边界处理**：数组两端只有一个邻居
5. **优化技巧**：一次遍历同时计算两种模式

## 易错点

1. **边界元素处理**：
   - 第一个和最后一个元素只有一个邻居
   - 使用 `float('inf')` 作为不存在邻居的标记

2. **减少量计算**：
   - 要减到比最小邻居小 1
   - 公式：`nums[i] - min_neighbor + 1`

3. **理解题意**：
   - 只能减少，不能增加
   - 两种模式选择操作数少的

4. **索引奇偶**：
   - 容易混淆哪种模式对应哪些位置
   - 奇数位置小 = 偶数位置大

5. **初始化**：
   - moves 数组初始化为 [0, 0]

## 图解示例

以 `nums = [9,6,1,6,2]` 为例：

**模式1：偶数位置大（0,2,4 大）= 奇数位置小（1,3 小）**
```
位置: 0  1  2  3  4
原值: 9  6  1  6  2
要求: >  <  >  <  >= (最后一个无右邻)

需要调整位置 1: min(9,1)=1, 6需要减到0, 操作6次
需要调整位置 3: min(1,2)=1, 6需要减到0, 操作6次
总操作：12次
```

**模式2：奇数位置大（1,3 大）= 偶数位置小（0,2,4 小）**
```
位置: 0  1  2  3  4
原值: 9  6  1  6  2
要求: <  >  <  >  <

需要调整位置 0: min(6)=6, 9需要减到5, 操作4次
需要调整位置 2: min(6,6)=6, 1本身就小，操作0次
需要调整位置 4: min(6)=6, 2本身就小，操作0次
总操作：4次
```

**答案：min(12, 4) = 4**
