## 题目描述

有 `n` 个朋友参加聚会，一排有编号 `0` 到 `n-1` 的椅子。给你一个 `times` 数组，`times[i] = [arrival_i, leaving_i]`，表示第 `i` 个朋友的到达和离开时间（时间唯一）。

每个朋友到达时坐**编号最小**的可用椅子，离开后该椅子变为可用。

给你 `targetFriend`，返回该朋友坐的椅子编号。

**示例 1：**
```
输入：times = [[1,4],[2,3],[4,6]], targetFriend = 1
输出：1
解释：
朋友 0 在时刻 1 到达，坐椅子 0
朋友 1 在时刻 2 到达，坐椅子 1
朋友 1 在时刻 3 离开，椅子 1 空出
朋友 2 在时刻 4 到达（同时朋友 0 离开），坐椅子 0
因此朋友 1 坐的是椅子 1
```

**提示：**
- `n == times.length`，`1 <= n <= 10^4`
- `times[i].length == 2`，`1 <= arrival_i < leaving_i <= 10^5`

---

## 解题思路

### 核心思想：双堆模拟

维护两个堆：
- `available`：最小堆，存放可用椅子编号（初始为 0 到 n-1）
- `occupied`：最小堆，存放 `(离开时间, 椅子编号)`

处理每个到达事件时：
1. 将所有在此时刻及之前离开的朋友释放椅子（放回 available）
2. 取 available 中最小编号的椅子
3. 将 `(离开时间, 椅子编号)` 加入 occupied

## 代码实现

### 方法一：双堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def smallestChair(self, times: List[List[int]], targetFriend: int) -> int:
        n = len(times)
        target_arrival = times[targetFriend][0]

        # 按到达时间排序（记录原始索引）
        events = sorted(range(n), key=lambda i: times[i][0])

        # 可用椅子：最小堆（初始 0..n-1）
        available = list(range(n))
        heapq.heapify(available)

        # 已占用：最小堆 [(离开时间, 椅子编号)]
        occupied = []

        for idx in events:
            arrival, leaving = times[idx]

            # 释放所有在当前时刻前离开的椅子
            while occupied and occupied[0][0] <= arrival:
                _, chair = heapq.heappop(occupied)
                heapq.heappush(available, chair)

            # 取最小可用椅子
            chair = heapq.heappop(available)

            if idx == targetFriend:
                return chair

            # 记录该朋友占用的椅子
            heapq.heappush(occupied, (leaving, chair))

        return -1
```

### 方法二：排序 + 模拟（O(n²) 暴力，小数据验证）

```python
from typing import List

class Solution:
    def smallestChair(self, times: List[List[int]], targetFriend: int) -> int:
        n = len(times)
        target_arrival = times[targetFriend][0]

        # 记录每把椅子空闲的时刻
        chair_free = [0] * n

        # 按到达时间排序
        order = sorted(range(n), key=lambda i: times[i][0])

        for idx in order:
            arrival, leaving = times[idx]
            # 找编号最小的在 arrival 时刻前已空闲的椅子
            for c in range(n):
                if chair_free[c] <= arrival:
                    chair_free[c] = leaving
                    if idx == targetFriend:
                        return c
                    break

        return -1
```

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双堆 | O(n log n) | O(n) |
| 暴力模拟 | O(n²) | O(n) |

## 关键点总结

1. 按到达时间排序处理事件
2. 双堆：available 维护最小可用椅子，occupied 维护最早离开时间
3. 处理到达时先释放已离开的椅子，再取最小可用椅子

---

## 易错点

- 释放椅子的条件是 `occupied[0][0] <= arrival`（到达时间 ≥ 离开时间，椅子已空）
- 注意题目说时间唯一，所以不会有精确等于的边界问题（实际到达时刻 = 某人离开时刻时，椅子应可用）
