## 题目描述

给你两个正整数数组 `nums` 和 `target`，两个数组长度相等。

每次操作中，你可以选择两个 **不同** 的下标 `i` 和 `j`，使 `nums[i]` 增加 `2`，`nums[j]` 减少 `2`。

如果两个数组中每个元素出现的频率相同，我们称两个数组是 **相似的**。

返回使 `nums` 与 `target` 相似所需的 **最少操作次数**。

**示例 1：**
```
输入：nums = [8,12,6], target = [2,14,10]
输出：2
解释：操作两次即可。
```

**示例 2：**
```
输入：nums = [1,2,5], target = [4,1,3]
输出：1
```

**提示：**
- `n == nums.length == target.length`
- `1 <= n <= 10^5`
- `1 <= nums[i], target[i] <= 10^6`
- 题目保证答案存在

## 解题思路

**关键观察：**
1. 每次操作不改变奇偶性（增加 2 或减少 2，奇偶不变）
2. 因此，奇数位置的元素只能匹配奇数，偶数只能匹配偶数

**贪心策略：**
- 将 `nums` 和 `target` 分别按奇偶分组
- 对每组，分别排序
- 将多余的（nums > target）与不足的（nums < target）配对
- 操作次数 = sum(nums[i] - target[i]) / 2（仅对 nums > target 的部分求和）

## 代码实现

### 方法一：奇偶分组 + 排序（推荐）

```python
from typing import List

class Solution:
    def makeSimilar(self, nums: List[int], target: List[int]) -> int:
        # 按奇偶分组并排序
        nums_odd = sorted(x for x in nums if x % 2 == 1)
        nums_even = sorted(x for x in nums if x % 2 == 0)
        target_odd = sorted(x for x in target if x % 2 == 1)
        target_even = sorted(x for x in target if x % 2 == 0)

        # 计算总差值（只算 nums > target 的部分，另一半通过另一个操作抵消）
        total = 0
        for a, b in zip(nums_odd, target_odd):
            total += max(0, a - b)
        for a, b in zip(nums_even, target_even):
            total += max(0, a - b)

        # 每次操作减少差值 2，所以操作次数 = total / 2
        return total // 2
```

### 方法二：统一排序处理

```python
from typing import List

class Solution:
    def makeSimilar(self, nums: List[int], target: List[int]) -> int:
        # 每个数映射到 (奇偶, 值)，奇偶相同的才能互相匹配
        def sort_by_parity(arr):
            odd = sorted(x for x in arr if x % 2 == 1)
            even = sorted(x for x in arr if x % 2 == 0)
            return odd + even

        nums_sorted = sort_by_parity(nums)
        target_sorted = sort_by_parity(target)

        ans = 0
        for a, b in zip(nums_sorted, target_sorted):
            ans += abs(a - b)

        return ans // 4  # 每次操作减少总差 4（一个+2，一个-2）
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 奇偶分组 + 排序 | O(n log n) | O(n) |

## 关键点总结

1. 奇偶分组：操作不改变奇偶性，奇数只能匹配奇数
2. 排序后一一对应是最优匹配（贪心）
3. 操作次数 = 总正差值 / 2（等于总绝对差 / 4）

## 易错点

- 必须按奇偶分组，不能将奇偶混搭
- 操作次数是总绝对差除以 4，不是除以 2（因为一次操作 +2 和 -2 共影响 4 的总差）
