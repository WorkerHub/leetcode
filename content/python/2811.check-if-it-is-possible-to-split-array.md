## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个整数 `m`。

一次操作中，你可以将 `nums` 分割成两个非空的连续子数组，条件是其中**至少一个**子数组的元素之和 >= `m`。

不断重复此操作，直到无法分割为止（即每个子数组长度为 1 时停止）。

如果可以将 `nums` 分割成 `n` 个单独的元素（即可以一直分割到底），返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：nums = [2, 2, 1], m = 4
输出：true
解释：
[2,2,1] -> 分割为 [2] 和 [2,1]（[2,2] 的和为 4 >= m，满足条件）
[2,1] -> 分割为 [2] 和 [1]（[2,1] 的和为 3 < 4，但 [2] 单个元素也不能提供 >= 4 的和）
等等，需要重新理解
```

**示例 2：**
```
输入：nums = [2, 1, 3], m = 5
输出：false
```

**提示：**
- `1 <= n <= 100`
- `1 <= nums[i] <= 100`
- `1 <= m <= 200`

## 解题思路

**关键观察：**
- 当 `n == 1` 时，不需要分割，直接返回 `true`
- 当 `n == 2` 时，两个元素必须有一个子数组（即原数组）之和 >= m，即 `sum(nums) >= m`
- 一个长度 >= 2 的子数组能被分割，当且仅当它包含某个长度为 2 的子数组（相邻两个元素）之和 >= m

**关键结论：** 如果存在相邻两个元素之和 >= m，那么整个数组可以一直分割。

**证明：**
- 若有 `nums[i] + nums[i+1] >= m`，可以将任意包含这两个元素的子数组分出这两个元素
- 当数组长度为 2 时，`[nums[i], nums[i+1]]` 的和 >= m，可以继续分割成两个单元素

因此，答案为：`n == 1` 或 存在相邻两元素之和 >= m。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def canSplitArray(self, nums: List[int], m: int) -> bool:
        n = len(nums)
        # 只有一个元素时，不需要分割
        if n == 1:
            return True
        # 检查是否存在相邻两元素之和 >= m
        for i in range(n - 1):
            if nums[i] + nums[i + 1] >= m:
                return True
        return False
```

### 方法二：动态规划（验证思路）

```python
from typing import List
from functools import lru_cache

class Solution:
    def canSplitArray(self, nums: List[int], m: int) -> bool:
        n = len(nums)
        # prefix[i] = nums[0] + ... + nums[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        def sub_sum(l: int, r: int) -> int:
            """区间 [l, r] 的和"""
            return prefix[r + 1] - prefix[l]

        @lru_cache(maxsize=None)
        def can_split(l: int, r: int) -> bool:
            """子数组 [l, r] 是否可以被完全分割"""
            if l == r:
                return True  # 单个元素，已分割完成
            # 尝试在 k 和 k+1 之间分割
            for k in range(l, r):
                left_sum = sub_sum(l, k)
                right_sum = sub_sum(k + 1, r)
                # 至少一个子数组之和 >= m
                if left_sum >= m or right_sum >= m:
                    if can_split(l, k) and can_split(k + 1, r):
                        return True
            return False

        return can_split(0, n - 1)
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n^3)，空间复杂度 O(n^2)

## 关键点总结

1. 核心结论：`n==1` 时直接返回 `true`；否则只需检查是否存在相邻两元素和 >= m
2. 任何长度 > 2 的子数组，只要包含一对相邻和 >= m 的元素，就可以一步一步分割出来
3. 贪心方法时间复杂度 O(n)，远优于暴力 DP

## 易错点

1. 当 n=1 时特殊处理，不需要任何分割
2. 检查的是相邻两个元素（连续），不是任意两个元素
3. n=2 时，只需检查 `nums[0] + nums[1] >= m`
