## 题目描述

给你一个整数 `n` 和一个长度为 `n` 的整数数组 `sick`，其中 `sick[i]` 表示第 i 天有学生生病（下标从 0 开始）。

若某天有学生生病，则感染天数加 1；若某天没有新学生生病（即前后都是健康天之间的某天），则这天计为间隔天。

更正式地：`sick` 是一个严格递增数组，`sick[i]` 表示第几天有学生感染。

将未被感染的时间段分组：在 sick[i] 到 sick[i+1] 之间的间隔为 `gap = sick[i+1] - sick[i] - 1` 天，对于每段间隔，其贡献为 `1 + 2 + ... + gap = gap*(gap+1)/2`（每一天感染前一天感染的学生的"可能性"组合）。

**示例 1：**
```
输入：n = 3, sick = [0,2]
输出：4
```

**示例 2：**
```
输入：n = 4, sick = [1]
输出：0
```

**提示：**
- `2 <= n <= 10^5`
- `0 <= sick.length <= n - 1`
- `0 <= sick[i] <= n - 1`
- `sick` 严格递增

## 解题思路

本题计算的是"感染可能性"的总数。

对于 sick 中相邻两个感染日之间的空隙（长度为 gap），其贡献为 `gap * (gap + 1) / 2`（类似于选 1 到 gap 的任意子集起点）。

特别地，sick 前面的空隙（0 到 sick[0]-1）和后面的空隙（sick[-1]+1 到 n-1）的贡献稍有不同（只有一侧有感染源）。

## Python 代码实现

### 方法一：计算各段贡献（推荐）

```python
from typing import List

class Solution:
    def countDaysBetweenDates(self, n: int, sick: List[int]) -> int:
        if not sick:
            return 0

        def contribution(gap: int, both_sides: bool) -> int:
            if gap <= 0:
                return 0
            if both_sides:
                # 两侧都有感染源，可能性 = 2^(gap-1) - 1（每天可以从左或右感染）
                # 实际：对长度为 gap 的空隙，两端各有一个感染源
                # 贡献 = 2^(gap-1)
                return (1 << (gap - 1))
            else:
                # 单侧感染源
                return gap

        total = 0
        # 前段空隙（单侧）
        total += contribution(sick[0], False)
        # 中间空隙（双侧）
        for i in range(len(sick) - 1):
            gap = sick[i + 1] - sick[i] - 1
            total += contribution(gap, True)
        # 后段空隙（单侧）
        total += contribution(n - 1 - sick[-1], False)

        return total
```

### 方法二：直接计算（验证公式）

```python
from typing import List

class Solution:
    def countDaysBetweenDates(self, n: int, sick: List[int]) -> int:
        # 注意：此题实际是计算 n 天中有多少天会被感染
        # 根据题意重新理解：sick 中的学生已感染，每天新增感染
        # 实际题意可能是计算"可能的感染天数组合"
        # 使用公式：2-sided gap 贡献 2^(gap-1)，1-sided gap 贡献 gap
        MOD = 10**9 + 7
        if not sick:
            return 0

        ans = 0
        # 左端空隙
        ans += sick[0]
        # 右端空隙
        ans += n - 1 - sick[-1]
        # 中间空隙
        for i in range(len(sick) - 1):
            gap = sick[i + 1] - sick[i] - 1
            if gap > 0:
                ans += pow(2, gap - 1, MOD)
        return ans % MOD
```

## 复杂度分析

- 时间复杂度：O(len(sick))
- 空间复杂度：O(1)

## 关键点总结

1. 边界空隙（单侧感染源）：贡献为空隙长度
2. 内部空隙（双侧感染源）：贡献为 2^(gap-1)
3. 空数组时（无感染）返回 0

## 易错点

1. 注意左右边界空隙是单侧（只有一端有感染源），而中间空隙是双侧
2. 中间空隙为 0 时不做贡献
3. 答案可能很大，需要取模
