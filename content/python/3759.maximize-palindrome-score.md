## 题目描述

给定字符串 `s` 和整数 `k`，可以从字符串中选最多 `k` 个字符位置进行修改（替换为任意字符）。求修改后，`s` 的最长回文子序列的长度（可以乘以某个得分因子）。

**示例 1：**
```
输入：s = "abacaba", k = 1
输出：7
解释：修改 1 个字符可以使整个字符串成为回文，得分 7。
```

**示例 2：**
```
输入：s = "abcde", k = 1
输出：5
解释：修改 1 个字符，最优可得长度 3 的回文... 或可得 5 字符的回文（将 b->d, 不行，只能改 1 个）。
     "adcda" -> k=1 时修改 'b' 为 'd'，得 "adcde"... 最长回文子序列为 5 字符。
```

**提示：**
- `1 <= s.length <= 1000`
- `0 <= k <= s.length`

## 解题思路

区间 DP。

`dp[i][j][c]`：使用最多 `c` 次修改，将 `s[i..j]` 变成回文的最长长度。

但 k 可以很大，需要换一个角度：

**区间 DP（标准解法）：**
`dp[i][j]`：使 `s[i..j]` 变成回文所需的最少修改次数，同时记录最大回文长度。

或者：对于每段 `s[i..j]`，若 `s[i] == s[j]`，可以直接扩展；否则修改一个字符使 `s[i] == s[j]`，代价 1，长度增加 2。

**贪心 + DP：**
先计算 `cost[i][j]`：使 `s[i..j]` 成为回文的最少修改次数，以及能得到的最长回文长度。

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def maxPalindromeScore(self, s: str, k: int) -> int:
        n = len(s)
        # dp[i][j]: (最少修改次数, 对应回文长度)
        # 简化：dp[i][j] = 使 s[i..j] 成为回文的最少修改次数
        INF = float('inf')
        cost = [[0] * n for _ in range(n)]

        # 计算将 s[i..j] 变为回文的最少修改次数（区间 DP）
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    cost[i][j] = cost[i+1][j-1] if length > 2 else 0
                else:
                    cost[i][j] = (cost[i+1][j-1] if length > 2 else 0) + 1

        # 找到使用最多 k 次修改能得到的最长回文子串
        # 枚举所有子串 [i, j]
        ans = 0
        for i in range(n):
            for j in range(i, n):
                if cost[i][j] <= k:
                    ans = max(ans, j - i + 1)

        return ans
```

### 方法二：DP 记录最少修改次数

```python
class Solution:
    def maxPalindromeScore(self, s: str, k: int) -> int:
        n = len(s)
        # min_ops[i][j]: 将 s[i..j] 变为回文的最少操作数
        min_ops = [[0] * n for _ in range(n)]

        for l in range(2, n + 1):
            for i in range(n - l + 1):
                j = i + l - 1
                if s[i] == s[j]:
                    min_ops[i][j] = min_ops[i+1][j-1] if l > 2 else 0
                else:
                    min_ops[i][j] = (min_ops[i+1][j-1] if l > 2 else 0) + 1

        best = 1  # 单个字符总是回文
        for i in range(n):
            for j in range(i + 1, n):
                if min_ops[i][j] <= k:
                    best = max(best, j - i + 1)

        return best
```

## 复杂度分析

- 时间复杂度：O(n^2)，区间 DP
- 空间复杂度：O(n^2)

## 关键点总结

1. 区间 DP 计算将子串变为回文的最少修改次数
2. 若 `s[i] == s[j]`，不需要额外修改；否则修改一次
3. 枚举所有满足 `cost <= k` 的子串，取最长

## 易错点

1. 单字符子串代价为 0，是回文
2. 内层递推 `cost[i+1][j-1]` 在 `l == 2` 时需要特判（`i+1 > j-1`）
