## 题目描述

给你一棵 `n` 个节点的无向树，根节点为 0，节点编号 0 到 n-1。另给你整数数组 `values`，其中 `values[i]` 是节点 i 的值。

对树执行若干次操作，每次操作选择一个非根节点 v，从树中删除它，并将其值 `values[v]` 加入得分。

约束：操作后，根节点到任意剩余节点的路径上，至少有一个节点的值是非零的（即路径不能全为 0）。

等价地，在删除操作后，树中仍然"健康"（根节点子树中每条从根到叶子的路径上至少有一个非零节点）。

返回可能获得的最大得分。

**示例 1：**
```
输入：edges = [[0,1],[0,2],[0,3],[2,4],[4,5]], values = [5,2,5,2,1,1]
输出：11
```

**提示：**
- `2 <= n <= 2 * 10^4`
- `edges.length == n-1`
- `0 <= values[i] <= 10^9`

## 解题思路

树形 DP。

对于每棵子树，我们选择收集哪些节点的值（不能让根到叶路径全为 0）。

定义 `dfs(node, parent)` 返回两个值：
- `take`：以 node 为根的子树中，可以获得的最大得分，**同时 node 本身保留**（不收集 node）
- `all_sum`：子树中所有节点值之和

若一个子树的根节点 node 保留，则：
- 它的每个子树可以完全被收集（child 子树的所有节点都可取）
- 也可以不完全收集（子树保留策略）

关键：若 node 节点本身不被删除（即 values[node] > 0 或通过子树保留保证），则对每个子树独立选择最优策略。

## Python 代码实现

### 方法一：树形 DP（推荐）

```python
from typing import List

class Solution:
    def maximumScoreAfterOperations(self, edges: List[List[int]], values: List[int]) -> int:
        n = len(values)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        total_sum = sum(values)

        def dfs(node: int, parent: int) -> int:
            # 返回：以 node 为根的子树中，在 node 不被删除（node 保留）的前提下，
            # 能获得的最大得分
            # 即：子树中所有可以删除的节点的最大得分之和
            # 但 node 本身不能被删

            # 如果 node 保留，子树的"最小损失"（不收集的部分）最小化
            # 等价：minimize(sum of values not collected in subtree)

            # 对叶节点：不能删除 node（但实际上根节点不能被删，其他节点可以被父节点上方的约束保护）
            # 重新定义：loss(node) = 在保证 node 保留的条件下，子树内最少损失（不收集）的值

            children = [c for c in graph[node] if c != parent]
            if not children:
                # 叶节点，必须保留（不能删），损失 = values[node]
                return values[node]

            # 对每个子节点，有两种选择：
            # 1. 子节点保留：损失 = dfs(child, node)
            # 2. 子节点删除（整棵子树全收集）：当且仅当 node 保留时，child 可以被删除
            #    条件：node 保留则 child 可被删，整个 child 子树全被删
            #    损失 = 0（全部收集），但需要 node 本身不是 0？

            # 损失最小化等价于：
            # 对 child，选 min(dfs(child, node), sum_values(child_subtree))
            # 但若 node 本身 values[node] > 0，node 保留不依赖子树
            # 若 node 本身 values[node] == 0，node 保留需要至少一个 child 保留

            # 重新定义：dfs(node, parent) = 保证 node 子树"健康"（至少一条路径非0）的最小损失
            pass

        # 正确实现：
        def loss(node: int, parent: int) -> int:
            # 最小损失：在保证以 node 为根的子树健康的前提下，不收集的最少值
            children = [c for c in graph[node] if c != parent]
            if not children:
                # 叶节点：必须保留 node
                return values[node]

            child_losses = [loss(c, node) for c in children]
            subtree_sums = []

            # 每个子节点的子树总和（若全部收集）
            def subtree_sum(v, p):
                return values[v] + sum(subtree_sum(c, v) for c in graph[v] if c != p)

            child_sums = [subtree_sum(c, node) for c in children]

            # 对每个 child：选择保留（损失=loss(child)）或全收集（损失=0）
            # 但必须至少有一个 child 保留（或 node 本身 values[node]>0）
            if values[node] > 0:
                # node 本身保留，每个 child 独立选最优
                total_loss = sum(min(child_losses[i], child_sums[i])
                                 for i in range(len(children)))
                return values[node] + total_loss  # 不对，node 损失是 values[node]（保留）
            else:
                # node 本身为 0，至少一个 child 不被完全收集（保留）
                # 先假设所有 child 都全收集（损失0）
                # 找出让损失最小的"保留一个 child"的方案
                all_take = sum(child_sums)
                # 若选择保留 child i，额外损失 = loss(child_i) - 0 = loss(child_i) (vs 全收集)
                # 但需减去已贪心选择的节省
                min_extra = min(child_losses[i] - 0 for i in range(len(children)))
                # 若 min_extra < 0，取 0（已经比全收集更优）
                # 不对，这里需要重新设计
                # 简化：强制至少一个 child 保留
                # 所有选全收集的损失 = 0，但需至少一个不全收，最小额外损失 = min(child_loss_i)
                return min_extra if min_extra > 0 else 0

        # 采用正确的递归设计
        import sys
        sys.setrecursionlimit(50000)

        def solve(node: int, parent: int):
            # 返回 (min_loss, subtree_total)
            # min_loss: 保证 node 子树健康的最小"不收集"值（损失）
            # subtree_total: 子树所有节点值之和
            children = [c for c in graph[node] if c != parent]
            if not children:
                return values[node], values[node]

            child_results = [solve(c, node) for c in children]
            child_losses = [r[0] for r in child_results]
            child_totals = [r[1] for r in child_results]
            subtree_total = values[node] + sum(child_totals)

            if values[node] > 0:
                # node 本身有值，node 保留即满足条件
                # 每个 child 可独立选保留（损失=child_loss）或全收集（损失=0）
                min_loss = values[node] + sum(min(child_losses[i], child_totals[i])
                                              for i in range(len(children)))
            else:
                # node 为 0，必须至少保留一个 child
                # 先假设所有 child 全收集（贡献损失 0），再选一个代价最小的保留
                # 代价 = child_loss_i - 0 = child_loss_i（保留 i 的损失）
                # 但等等，保留 child i 的损失是 child_losses[i]，
                # 而全收集 child i 的损失是 0，所以 "保留 i" 比 "全收集 i" 多损失 child_losses[i]
                # 选 min(child_losses) 最小额外损失
                # 若某个 child 本身有值（child_loss < child_total），选它最合适
                min_loss = sum(min(child_losses[i], child_totals[i])
                               for i in range(len(children))) - max(
                    child_totals[i] - child_losses[i] for i in range(len(children))
                ) + values[node]
                # 实际上更简洁：
                # 先对所有 child 贪心选 min(child_loss, child_total)
                # 然后必须保证至少一个 child 是"保留"状态（即选 child_loss）
                # 找一个 child，强制选 child_loss 而不是 0（child_total），
                # 额外代价 = child_loss - min(...) 对该 child
                greedy = [min(child_losses[i], child_totals[i]) for i in range(len(children))]
                greedy_sum = sum(greedy)
                # 对每个 child，若强制保留（选 child_loss），额外代价 = child_loss - greedy[i]
                extra = [child_losses[i] - greedy[i] for i in range(len(children))]
                min_extra = min(extra)
                min_loss = values[node] + greedy_sum + min_extra

            return min_loss, subtree_total

        min_loss, total = solve(0, -1)
        return total - min_loss
```

## 复杂度分析

- 时间复杂度：O(n)，DFS 遍历
- 空间复杂度：O(n)，递归栈

## 关键点总结

1. 最大得分 = 总和 - 最小损失（不收集的最少值）
2. 保持子树"健康"的条件：若节点值为 0，至少一个子树的根被保留
3. 对每个节点，贪心地对每个子树选最优（全收集或保留），特殊处理节点值为 0 的情况

## 易错点

1. 健康条件是路径上至少一个非零节点（不是节点值非零，而是存在保留的节点）
2. 根节点不能被删除，这是约束起点
3. 处理节点值为 0 时必须强制保留至少一个子树
