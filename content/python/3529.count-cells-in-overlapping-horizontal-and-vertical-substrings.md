## 题目描述

给定一个字符矩阵 `grid` 和一个字符串 `pattern`。统计矩阵中同时满足以下两个条件的单元格数量：
1. 该单元格是某个水平（行方向）出现的 `pattern` 的一部分
2. 该单元格是某个垂直（列方向）出现的 `pattern` 的一部分

**示例：**

```
输入：grid = [["a","b","c"],["b","b","b"],["c","b","a"]], pattern = "b"
输出：3
解释：pattern "b" 水平出现在第2行，垂直出现在第2列，
     同时满足的单元格为 (1,0),(1,1),(1,2),(0,1),(2,1)...
     实际统计在两个方向都有 pattern 覆盖的单元格。
```

**提示：**
- `1 <= grid.length, grid[0].length <= 50`
- `1 <= pattern.length <= 100`
- 字符为小写字母

## 解题思路

1. 对每行用字符串匹配找出 `pattern` 的所有出现位置，标记这些单元格
2. 对每列用字符串匹配找出 `pattern` 的所有出现位置，标记这些单元格
3. 统计同时被水平和垂直标记的单元格数量

使用 KMP 或 Python 内置字符串搜索。

## Python 代码实现

### 方法一：标记矩阵（推荐）

```python
from typing import List

class Solution:
    def countCells(self, grid: List[List[str]], pattern: str) -> int:
        rows = len(grid)
        cols = len(grid[0])
        p_len = len(pattern)

        # 水平标记
        h_mark = [[False] * cols for _ in range(rows)]
        for r in range(rows):
            row_str = ''.join(grid[r])
            # 找 pattern 在行中的所有出现位置
            start = 0
            while True:
                pos = row_str.find(pattern, start)
                if pos == -1:
                    break
                for c in range(pos, pos + p_len):
                    h_mark[r][c] = True
                start = pos + 1

        # 垂直标记
        v_mark = [[False] * cols for _ in range(rows)]
        for c in range(cols):
            col_str = ''.join(grid[r][c] for r in range(rows))
            start = 0
            while True:
                pos = col_str.find(pattern, start)
                if pos == -1:
                    break
                for r in range(pos, pos + p_len):
                    v_mark[r][c] = True
                start = pos + 1

        # 统计同时满足的单元格
        count = 0
        for r in range(rows):
            for c in range(cols):
                if h_mark[r][c] and v_mark[r][c]:
                    count += 1

        return count
```

### 方法二：集合操作

```python
from typing import List

class Solution:
    def countCells(self, grid: List[List[str]], pattern: str) -> int:
        rows = len(grid)
        cols = len(grid[0])
        p_len = len(pattern)

        h_cells = set()
        v_cells = set()

        # 水平搜索
        for r in range(rows):
            row_str = ''.join(grid[r])
            idx = 0
            while True:
                pos = row_str.find(pattern, idx)
                if pos == -1:
                    break
                for c in range(pos, pos + p_len):
                    h_cells.add((r, c))
                idx = pos + 1

        # 垂直搜索
        for c in range(cols):
            col_str = ''.join(grid[r][c] for r in range(rows))
            idx = 0
            while True:
                pos = col_str.find(pattern, idx)
                if pos == -1:
                    break
                for r in range(pos, pos + p_len):
                    v_cells.add((r, c))
                idx = pos + 1

        return len(h_cells & v_cells)
```

## 复杂度分析

- 时间复杂度：O(rows * cols * p_len)，字符串搜索
- 空间复杂度：O(rows * cols)，标记矩阵

## 关键点总结

1. 分别找水平和垂直方向 pattern 出现的所有单元格
2. 取交集得到同时满足的单元格
3. 使用集合操作简化代码

## 易错点

1. pattern 可以在同一行/列出现多次（重叠或非重叠）
2. 搜索时 `start = pos + 1` 而不是 `pos + p_len`（允许重叠匹配）
3. 标记的是 pattern 覆盖的所有单元格，不只是起始位置
