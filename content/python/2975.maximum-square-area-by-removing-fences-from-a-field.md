## 题目描述

给你一个 `m x n` 的田地（包含边界），有若干横向栅栏（水平线）和纵向栅栏（竖线）。

横向栅栏位于行 `hFences[i]`（1 到 m-1 之间，不含边界 0 和 m），纵向栅栏类似。

每次可以移除任意栅栏。返回能形成的最大正方形区域的面积，对 `10^9 + 7` 取余。若无法形成，返回 -1。

**示例 1：**
```
输入：m = 4, n = 3, hFences = [2,3], vFences = [2]
输出：4
```

**提示：**
- `3 <= m, n <= 10^9`
- `1 <= hFences.length <= min(m-1, 600)`
- `1 <= vFences.length <= min(n-1, 600)`

## 解题思路

枚举水平方向上两条线（包含边界 0 和 m），计算它们之间的距离 d。将所有可能的水平距离存入集合。

枚举垂直方向上两条线，同理。

若存在一个距离 d 同时出现在水平集合和垂直集合中，则可以形成 d x d 的正方形。取最大的 d，面积为 d^2。

## Python 代码实现

### 方法一：枚举所有行列对，取公共距离（推荐）

```python
from typing import List

class Solution:
    def maximizeSquareArea(self, m: int, n: int, hFences: List[int], vFences: List[int]) -> int:
        MOD = 10**9 + 7

        def get_gaps(fences: List[int], boundary: int) -> set:
            # 所有可能的距离（包含边界 0 和 boundary）
            lines = sorted([0] + fences + [boundary])
            gaps = set()
            for i in range(len(lines)):
                for j in range(i + 1, len(lines)):
                    gaps.add(lines[j] - lines[i])
            return gaps

        h_gaps = get_gaps(hFences, m)
        v_gaps = get_gaps(vFences, n)

        # 找公共距离
        common = h_gaps & v_gaps
        if not common:
            return -1

        side = max(common)
        return side * side % MOD
```

### 方法二：直接枚举

```python
from typing import List

class Solution:
    def maximizeSquareArea(self, m: int, n: int, hFences: List[int], vFences: List[int]) -> int:
        MOD = 10**9 + 7
        h_lines = sorted([0] + hFences + [m])
        v_lines = sorted([0] + vFences + [n])

        h_gaps = set()
        for i in range(len(h_lines)):
            for j in range(i + 1, len(h_lines)):
                h_gaps.add(h_lines[j] - h_lines[i])

        best = -1
        for i in range(len(v_lines)):
            for j in range(i + 1, len(v_lines)):
                d = v_lines[j] - v_lines[i]
                if d in h_gaps:
                    best = max(best, d)

        return best * best % MOD if best != -1 else -1
```

## 复杂度分析

- 时间复杂度：O(H^2 + V^2)，H 和 V 为栅栏数 + 边界，最大约 600
- 空间复杂度：O(H^2 + V^2)，存储所有可能距离

## 关键点总结

1. 边界（0 和 m/n）也算作线，必须加入
2. 枚举两条线之间的距离，用集合求交
3. H, V <= 600，H^2 = 3.6 * 10^5，完全可行

## 易错点

1. 边界 0 和 m（或 n）必须包含
2. 面积需要对 MOD 取余
3. 无公共距离时返回 -1
