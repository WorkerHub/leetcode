## 题目描述

给你一个下标从 **0** 开始的整数矩阵 `grid`，矩阵大小为 `m x n`，由从 `0` 到 `m * n - 1` 的不同整数组成。你可以在此矩阵中，从一个单元格移动到 **下一行** 的任何其他单元格。如果你在第 `(x, y)` 个单元格，且该单元格的值为 `v`，你可以移动到第 `(x + 1, j)` 个单元格，代价为 `moveCost[v][j]`，其中 `0 <= j < n`。

第一行的移动代价可以忽略（即从第一行任意位置出发代价为 0）。

一条路径的代价是：路径上所有值之和 + 路径上所有移动代价之和。

返回从第一行的任意单元格出发，到达最后一行的任意单元格，所有路径中的**最小代价**。

**示例：**
```
输入：grid = [[5,3],[4,0],[2,1]], moveCost = [[9,8],[1,5],[10,12],[18,6],[2,4],[14,3]]
输出：17
解释：路径 (0,0)->(1,0)->(2,0) 代价：5 + 3 + 9 + 4 + 1 + 2 = 17（去掉第一行移动cost）
实际：grid[0][0]=5, moveCost[5][0]=9, grid[1][0]=4, moveCost[4][0]=2, grid[2][0]=2，总代价=5+9+4+2+2=17（不含第一行出发cost，含所有格子值和移动代价）
```

**提示：**
- `m == grid.length`，`n == grid[i].length`
- `2 <= m, n <= 50`
- `grid` 由 0 到 m*n-1 的不同整数组成
- `moveCost.length == m * n`
- `moveCost[i].length == n`

## 解题思路

**动态规划：**
定义 `dp[i][j]` 为到达 `grid[i][j]` 的最小路径代价。

- 初始化：`dp[0][j] = grid[0][j]`（第一行无移动代价）
- 转移：`dp[i][j] = min(dp[i-1][k] + moveCost[grid[i-1][k]][j]) + grid[i][j]`
- 答案：`min(dp[m-1][j])`

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minPathCost(self, grid: List[List[int]], moveCost: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # dp[j] 表示到达当前行第 j 列的最小代价
        dp = grid[0][:]  # 初始化为第一行各格子的值

        for i in range(1, m):
            new_dp = [float('inf')] * n
            for k in range(n):
                # 从上一行第 k 列出发
                for j in range(n):
                    # 移动到当前行第 j 列的代价
                    cost = dp[k] + moveCost[grid[i - 1][k]][j] + grid[i][j]
                    new_dp[j] = min(new_dp[j], cost)
            dp = new_dp
        
        return min(dp)
```

### 方法二：完整 dp 矩阵（便于理解）

```python
from typing import List

class Solution:
    def minPathCost(self, grid: List[List[int]], moveCost: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # dp[i][j] 表示到达 grid[i][j] 的最小代价
        dp = [[float('inf')] * n for _ in range(m)]
        
        # 第一行初始化
        for j in range(n):
            dp[0][j] = grid[0][j]
        
        # 逐行转移
        for i in range(1, m):
            for k in range(n):
                v = grid[i - 1][k]  # 上一行第 k 列的格子值
                for j in range(n):
                    # 从 (i-1, k) 移动到 (i, j)
                    new_cost = dp[i - 1][k] + moveCost[v][j] + grid[i][j]
                    dp[i][j] = min(dp[i][j], new_cost)
        
        return min(dp[m - 1])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 空间优化 DP | O(m * n^2) | O(n) |
| 完整 DP | O(m * n^2) | O(m * n) |

## 关键点总结

1. DP 状态定义为到达每个格子的最小总代价（含格子自身值和移动代价）。
2. 第一行的移动代价不计，直接初始化为格子值。
3. `moveCost[v][j]` 表示从值为 `v` 的格子移动到下一行第 `j` 列的代价。

## 易错点

- `moveCost` 的索引是格子的**值**，不是格子的位置。
- 注意路径代价包含每个经过格子的**值**，以及每次移动的代价。
