## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`，以及两个整数 `indexDifference` 和 `valueDifference`。

找出满足下述条件的两个下标 `i` 和 `j`：
- `abs(i - j) >= indexDifference`
- `abs(nums[i] - nums[j]) >= valueDifference`

返回整数数组 `[i, j]`。若不存在，返回 `[-1, -1]`。

**示例 1：**
```
输入：nums = [5,1,4,1], indexDifference = 2, valueDifference = 4
输出：[0,3]
```

**示例 2：**
```
输入：nums = [2,1], indexDifference = 0, valueDifference = 0
输出：[0,0]
```

**提示：**
- `1 <= n <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= indexDifference <= 10^5`
- `0 <= valueDifference <= 10^9`

## 解题思路

本题数据范围大（n 达到 10^5），需要 O(n) 解法。

枚举 `j`，对于每个 `j`，满足 `abs(i - j) >= indexDifference` 的 `i` 范围是 `[0, j - indexDifference]`（取 j >= indexDifference 时）。

在遍历 j 的过程中，维护区间 `[0, j - indexDifference]` 中的最大值和最小值及其下标。每次 j 增大 1，区间右边界也增大 1，因此只需在窗口右边界处更新最大/最小值。

若 `nums[j] - min_val >= valueDifference`，则找到答案；
若 `max_val - nums[j] >= valueDifference`，则找到答案。

## Python 代码实现

### 方法一：维护前缀最大最小值（推荐）

```python
from typing import List

class Solution:
    def findIndices(self, nums: List[int], indexDifference: int, valueDifference: int) -> List[int]:
        n = len(nums)
        # min_idx: 区间 [0, j-indexDifference] 中最小值的下标
        # max_idx: 区间 [0, j-indexDifference] 中最大值的下标
        min_idx = 0
        max_idx = 0

        for j in range(indexDifference, n):
            # 区间右边界更新为 j - indexDifference
            i = j - indexDifference
            if nums[i] < nums[min_idx]:
                min_idx = i
            if nums[i] > nums[max_idx]:
                max_idx = i

            # 检查最小值配对
            if nums[j] - nums[min_idx] >= valueDifference:
                return [min_idx, j]
            # 检查最大值配对
            if nums[max_idx] - nums[j] >= valueDifference:
                return [max_idx, j]

        return [-1, -1]
```

### 方法二：暴力枚举（适合小数据验证）

```python
from typing import List

class Solution:
    def findIndices(self, nums: List[int], indexDifference: int, valueDifference: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + indexDifference, n):
                if abs(nums[i] - nums[j]) >= valueDifference:
                    return [i, j]
        return [-1, -1]
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历，每步 O(1) 更新最大/最小值
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. 关键观察：固定 j，候选 i 在 `[0, j - indexDifference]` 中；`abs(nums[i] - nums[j])` 最大化需要找区间最大值或最小值
2. 随着 j 递增，候选区间单调扩展，可以动态维护最大/最小值
3. 两种配对情况：nums[j] 大（用最小值 i）或 nums[j] 小（用最大值 i）

## 易错点

1. j 的起始值是 `indexDifference`，不是 0
2. 更新最大/最小值用的是 `i = j - indexDifference`，与 j 同步移动
3. 需要同时检查两种情况（最大和最小）
