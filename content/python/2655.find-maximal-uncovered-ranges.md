## 题目描述

给你一个整数 `n` 和一个二维整数数组 `ranges`，其中 `ranges[i] = [start, end]`。这些区间覆盖 `[0, n-1]` 中的部分整数。返回 `[0, n-1]` 中未被任何区间覆盖的整数组成的最大区间列表（按起始值升序排列）。

**示例 1：**
```
输入：n = 10, ranges = [[3,5],[7,8]]
输出：[[0,2],[6,6],[9,9]]
```

**示例 2：**
```
输入：n = 3, ranges = [[0,2]]
输出：[]
```

**数据范围：**
- 1 <= n <= 10^9
- 0 <= ranges.length <= 10^6
- 0 <= start <= end < n

## 解题思路

排序 + 区间合并：先对 ranges 按起始位置排序，然后扫描找未覆盖的间隙：
- 从 0 开始，找到第一个区间的左端 - 1 就是第一段未覆盖范围
- 合并重叠区间，找各区间之间的间隙
- 最后检查最后一个区间的右端到 n-1 的间隙

## Python 代码实现

### 方法一：排序 + 扫描（推荐）

```python
from typing import List

class Solution:
    def findMaximalUncoveredRanges(self, n: int, ranges: List[List[int]]) -> List[List[int]]:
        if not ranges:
            return [[0, n - 1]]

        # 按起始位置排序
        ranges.sort()

        ans = []
        prev_end = -1  # 上一个已处理区间的右端（初始为 -1）

        for start, end in ranges:
            # 当前区间与上一个区间之间的间隙
            if start > prev_end + 1:
                ans.append([prev_end + 1, start - 1])
            # 更新已覆盖的右端（合并重叠区间）
            prev_end = max(prev_end, end)

        # 检查最后一个区间到 n-1 的间隙
        if prev_end < n - 1:
            ans.append([prev_end + 1, n - 1])

        return ans
```

### 方法二：合并区间后求补集

```python
from typing import List

class Solution:
    def findMaximalUncoveredRanges(self, n: int, ranges: List[List[int]]) -> List[List[int]]:
        if not ranges:
            return [[0, n - 1]]

        # 先合并区间
        ranges.sort()
        merged = [ranges[0][:]]
        for start, end in ranges[1:]:
            if start <= merged[-1][1] + 1:
                merged[-1][1] = max(merged[-1][1], end)
            else:
                merged.append([start, end])

        # 求补集
        ans = []
        if merged[0][0] > 0:
            ans.append([0, merged[0][0] - 1])
        for i in range(1, len(merged)):
            ans.append([merged[i - 1][1] + 1, merged[i][0] - 1])
        if merged[-1][1] < n - 1:
            ans.append([merged[-1][1] + 1, n - 1])

        return ans
```

## 复杂度分析

- 时间复杂度：O(m log m)，m 为区间数量
- 空间复杂度：O(m)

## 关键点总结

1. 排序后线性扫描，维护当前已覆盖的右端
2. 间隙 = 上一区间右端 + 1 到当前区间左端 - 1
3. 注意首尾的特殊处理

## 易错点

1. 区间重叠时取最大右端
2. 注意 `n-1` 是最大下标（包含），检查最后一段到 `n-1`
