## 题目描述

字符串的**吸引力**定义为该字符串中**不同字母数量**。

给你一个字符串 `s`，返回 `s` 所有子字符串的**吸引力之和**。

**示例 1：**
```
输入：s = "abbca"
输出：28
```

**示例 2：**
```
输入：s = "code"
输出：20
```

## 解题思路

**动态规划（贡献法）：**

计算每个字符 `s[i]` 对所有子串的贡献：字符 `s[i]` 对子串 `s[l..r]`（`l <= i <= r`）的贡献为 1，当且仅当 `s[l..r]` 中 `s[i]` 是**第一次出现**（或该字符在 `s[l..i-1]` 中没有出现）。

即字符 `s[i]` 在子串 `s[l..r]` 中有贡献，当且仅当 `l > last[s[i]]`（`last[s[i]]` 是 `s[i]` 上一次出现的位置，初始为 -1）。

固定右端点 `i`，字符 `s[i]` 对以 `i` 结尾的子串的贡献次数 = `i - last[s[i]]`（从 `last[s[i]]+1` 到 `i` 共这么多个起点）。

`dp[i]` = 所有以 `i` 结尾的子串的吸引力之和 = `dp[i-1] + (i - last[s[i]])`。

答案 = `sum(dp)`。

## 代码实现

### 方法一：动态规划贡献法（推荐）

```python
class Solution:
    def appealSum(self, s: str) -> int:
        # last[c] = 字符 c 上次出现的位置（初始为 -1）
        last = {}
        dp = 0       # 以当前位置结尾的所有子串的吸引力之和
        total = 0

        for i, ch in enumerate(s):
            prev = last.get(ch, -1)
            # 以 i 结尾的子串中，新增吸引力来自 s[i]
            # 起点 l 满足：prev < l <= i（即 l 在 prev+1 到 i 之间）
            # 共 i - prev 个起点
            dp += i - prev
            total += dp
            last[ch] = i

        return total
```

### 方法二：直接统计每个字符贡献

```python
class Solution:
    def appealSum(self, s: str) -> int:
        n = len(s)
        total = 0
        last = {}

        for i, ch in enumerate(s):
            # 字符 ch 对以 i 结尾的子串的贡献
            # 可用的左端点 l: last[ch]+1 到 i
            # 可用的右端点 r: i 到 n-1
            prev = last.get(ch, -1)
            # 贡献 = (起点数) * (终点数) = (i - prev) * (n - i)
            total += (i - prev) * (n - i)
            last[ch] = i

        return total
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(26) = O(1)，只有 26 个小写字母的 last 数组。

## 关键点总结

1. 贡献法：统计每个字符对哪些子串的吸引力有贡献（即该字符是子串中第一次出现）。
2. 方法一：`dp[i]` = 以 i 结尾的所有子串的吸引力之和，通过 `i - last[ch]` 递推。
3. 方法二更直接：字符 `ch` 在 `[i, i]` 到 `[prev+1, n-1]` 范围内的所有子串中有贡献，计算组合数。

## 易错点

- `last` 初始值为 -1（字符从未出现），表示左端点可以从 0 开始。
- 方法一中 `dp` 表示累计到当前位置的递推值，每轮更新后加到 `total`。
