## 题目描述

街道上有 `n` 盏灯，每盏灯照亮其左右各 `range_i` 米内的位置（闭区间）。

给你一个整数数组 `lights`，`lights[i] = [position_i, range_i]` 表示第 `i` 盏灯位于 `position_i`，照亮范围是 `[position_i - range_i, position_i + range_i]`。

返回被照亮次数**最多**的位置。如果有多个位置亮度相同，返回**最小**的那个。

**示例 1：**
```
输入：lights = [[-3,2],[1,2],[3,3]]
输出：-1
解释：-1 被灯 0 和 灯 1 照亮，共 2 盏，是最亮的位置之一
```

**示例 2：**
```
输入：lights = [[1,0],[0,1]]
输出：1
```

**提示：**
- `1 <= lights.length <= 10^5`
- `-10^8 <= position_i <= 10^8`
- `0 <= range_i <= 10^8`

## 解题思路

**差分数组 + 扫描线思想：**
- 每盏灯覆盖 `[pos - range, pos + range]`
- 在 `pos - range` 处亮度 +1，在 `pos + range + 1` 处亮度 -1
- 排序事件点，扫描获取最大亮度位置

由于坐标范围很大（达 2 * 10^8），直接用数组无法存储，需要用**有序事件点**处理。

## 代码实现

### 方法一：差分 + 排序扫描（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def brightestPosition(self, lights: List[List[int]]) -> int:
        diff = defaultdict(int)  # 差分字典

        for pos, r in lights:
            diff[pos - r] += 1      # 进入区间
            diff[pos + r + 1] -= 1  # 离开区间

        max_bright = 0
        cur_bright = 0
        ans = 0

        # 按坐标排序扫描
        for coord in sorted(diff.keys()):
            cur_bright += diff[coord]
            if cur_bright > max_bright:
                max_bright = cur_bright
                ans = coord  # 更新最亮位置（取最小，第一次遇到最大值就记录）

        return ans
```

### 方法二：事件数组排序

```python
from typing import List

class Solution:
    def brightestPosition(self, lights: List[List[int]]) -> int:
        # 构建事件：(坐标, 类型)，+1 为进入，-1 为离开
        events = []
        for pos, r in lights:
            events.append((pos - r, 1))      # 区间左端
            events.append((pos + r + 1, -1)) # 区间右端后一位

        # 先按坐标排序，同坐标时先处理进入（+1）后处理离开（-1）
        events.sort(key=lambda x: (x[0], -x[1]))

        cur = 0
        max_bright = 0
        ans = 0

        for coord, delta in events:
            cur += delta
            if cur > max_bright:
                max_bright = cur
                ans = coord

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序事件点
- 空间复杂度：O(n)

## 关键点总结

1. 差分思想：在区间两端打标记，扫描时累加得到亮度
2. 坐标范围大，用哈希字典代替数组
3. 题目要求返回最小位置：第一次达到最大亮度时记录即可（因为我们从小到大遍历坐标）

## 易错点

- 区间是闭区间 `[pos - range, pos + range]`，差分在 `pos + range + 1` 处减 1
- 同坐标时排序需要确保 `+1` 事件在 `-1` 事件之前处理（若存在同坐标的进出）
- 取最小位置：升序扫描时第一次更新最大值就是最小坐标
