## 题目描述

`n` 个人（编号 0 到 `n-1`）参加了一系列会议。初始时，人 0 知道一个秘密，并在时间 `firstPerson` 时告知了人 `firstPerson`。

会议列表 `meetings[i] = [x, y, time]` 表示人 `x` 和人 `y` 在时间 `time` 开会。知道秘密的人会在会议中告诉对方。

返回最终知道秘密的**所有人的编号**。

**示例：**
```
输入：n = 6, meetings = [[1,2,5],[2,3,8],[1,5,10]], firstPerson = 1
输出：[0,1,2,3,5]
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= meetings.length <= 10^5`
- 按时间顺序处理，同一时刻的多个会议可以同时传播秘密

## 解题思路

**并查集（按时间分组处理）：**

1. 将所有会议按时间分组
2. 对同一时刻的会议，先将参与者合并（并查集），然后检查合并后的集合中是否有知道秘密的人
3. 若某集合不包含知道秘密的人，**撤销**这次合并（或重置该组的并查集关系）
4. 处理完所有时刻后，返回与人 0 在同一集合的所有人

**关键：** 同一时刻的会议必须一起处理（同时传播），不能逐个处理。

## 代码实现

### 方法一：并查集 + 按时间分组（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findAllPeople(self, n: int, meetings: List[List[int]], firstPerson: int) -> List[int]:
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        # 初始：0 和 firstPerson 知道秘密
        union(0, firstPerson)

        # 按时间分组
        time_groups = defaultdict(list)
        for x, y, t in meetings:
            time_groups[t].append((x, y))

        for t in sorted(time_groups):
            group = time_groups[t]
            people = set()

            # 先合并所有同时刻的会议
            for x, y in group:
                union(x, y)
                people.add(x)
                people.add(y)

            # 检查哪些人与 0 不连通，断开他们（重置）
            for p in people:
                if find(p) != find(0):
                    parent[p] = p  # 重置，只重置非秘密持有集合的人

        return [i for i in range(n) if find(i) == find(0)]
```

### 方法二：BFS 按时间层传播

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findAllPeople(self, n: int, meetings: List[List[int]], firstPerson: int) -> List[int]:
        # 按时间分组
        time_map = defaultdict(list)
        for x, y, t in meetings:
            time_map[t].append((x, y))

        knows = {0, firstPerson}

        for t in sorted(time_map):
            # 建立当前时刻的图
            graph = defaultdict(list)
            for x, y in time_map[t]:
                graph[x].append(y)
                graph[y].append(x)

            # BFS 从已知秘密的人出发
            queue = deque([p for p in graph if p in knows])
            visited = set(queue)
            while queue:
                cur = queue.popleft()
                for nb in graph[cur]:
                    if nb not in visited:
                        visited.add(nb)
                        knows.add(nb)
                        queue.append(nb)

        return list(knows)
```

## 复杂度分析

- 时间复杂度：O(M log M + M * alpha(n))，M 为会议数
- 空间复杂度：O(n + M)

## 关键点总结

1. 同一时刻的会议必须同时处理（可能形成链式传播）
2. 并查集方法：合并后重置与 0 不相连的节点
3. BFS 方法：在当前时刻的子图中从已知者出发 BFS

## 易错点

- 不能逐个处理会议：`A-B, B-C` 在同一时刻，若 A 知道秘密，则 C 也应该知道
- 并查集重置时，只重置非秘密持有集合的人（与 0 不连通的）
