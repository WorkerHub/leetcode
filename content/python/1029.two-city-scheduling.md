## 题目描述

公司计划面试 `2n` 人。给你一个数组 `costs`，其中 `costs[i] = [aCosti, bCosti]`，表示第 `i` 人飞往 `a` 市的费用为 `aCosti`，飞往 `b` 市的费用为 `bCosti`。

返回将每个人都飞到 `a`、`b` 中某座城市的最低费用，要求每个城市都有 `n` 人抵达。

**示例 1：**
```
输入：costs = [[10,20],[30,200],[400,50],[30,20]]
输出：110
解释：
第一个人去 a 市，费用为 10。
第二个人去 a 市，费用为 30。
第三个人去 b 市，费用为 50。
第四个人去 b 市，费用为 20。
最低总费用为 10 + 30 + 50 + 20 = 110。
```

**示例 2：**
```
输入：costs = [[259,770],[448,54],[926,667],[184,139],[840,118],[577,469]]
输出：1859
```

**提示：**
- `2 * n == costs.length`
- `2 <= costs.length <= 100`
- `costs.length` 为偶数
- `1 <= aCosti, bCosti <= 1000`

## 解题思路

**核心思想**：贪心算法

**关键观察**：
1. 假设所有人都去A市，总费用为 `sum(aCost)`
2. 现在需要选n个人改去B市
3. 改变的代价是 `bCost - aCost`
4. 选择代价最小（最负）的n个人改去B市

**算法步骤**：
1. 按 `bCost - aCost` 排序
2. 前n个人去B市，后n个去A市
3. 或者：先都去A市，然后选差值最小的n个改去B市

## Python 代码实现

### 方法一：排序贪心（推荐）⭐

```python
from typing import List

class Solution:
    def twoCitySchedCost(self, costs: List[List[int]]) -> int:
        """
        贪心：按去B市的相对优势排序
        时间复杂度：O(nlogn)
        空间复杂度：O(1) 或 O(n) 取决于排序实现
        """
        # 按去B市比去A市的节省程度排序
        # bCost - aCost越小，去B市越划算
        costs.sort(key=lambda x: x[1] - x[0])
        
        n = len(costs) // 2
        total = 0
        
        # 前n个人去B市（去B更划算）
        for i in range(n):
            total += costs[i][1]
        
        # 后n个人去A市
        for i in range(n, 2 * n):
            total += costs[i][0]
        
        return total
```

### 方法二：先都去A再调整

```python
class Solution:
    def twoCitySchedCost(self, costs: List[List[int]]) -> int:
        """
        贪心思路：
        1. 假设所有人都去A市
        2. 选n个人改去B市，选择refund最大的
        
        时间复杂度：O(nlogn)
        空间复杂度：O(n)
        """
        # 先计算所有人去A市的费用
        total = sum(cost[0] for cost in costs)
        
        # 计算每个人改去B市的退款（可能为负）
        # refund = aCost - bCost
        # refund越大，改去B市越划算
        refunds = [cost[0] - cost[1] for cost in costs]
        
        # 按退款排序，选退款最大的n个改去B市
        refunds.sort(reverse=True)
        
        n = len(costs) // 2
        total -= sum(refunds[:n])
        
        return total
```

### 方法三：详细注释版

```python
class Solution:
    def twoCitySchedCost(self, costs: List[List[int]]) -> int:
        """
        贪心算法详解
        
        思路：
        - 每个人去A或B的费用不同
        - 总共2n人，每个城市要n人
        - 关键：如何选择哪n个去A，哪n个去B？
        
        策略：
        - 计算每个人去B相对去A的优势：bCost - aCost
        - 优势为负（去B更便宜）的优先去B
        - 优势为正（去A更便宜）的优先去A
        """
        # 按去B的相对费用排序
        # diff = bCost - aCost
        # diff < 0: 去B更便宜
        # diff > 0: 去A更便宜
        costs.sort(key=lambda x: x[1] - x[0])
        
        n = len(costs) // 2
        min_cost = 0
        
        # 排序后，前n个人去B市最优
        for i in range(n):
            min_cost += costs[i][1]  # 去B市
        
        # 后n个人去A市最优
        for i in range(n, 2 * n):
            min_cost += costs[i][0]  # 去A市
        
        return min_cost
```

### 方法四：一行代码版

```python
class Solution:
    def twoCitySchedCost(self, costs: List[List[int]]) -> int:
        """
        简洁实现
        """
        costs.sort(key=lambda x: x[1] - x[0])
        n = len(costs) // 2
        return sum(costs[i][1] for i in range(n)) + \
               sum(costs[i][0] for i in range(n, 2*n))
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序的时间
- **空间复杂度**：O(1) 到 O(n)，取决于排序算法

## 图解示例

以 `costs = [[10,20],[30,200],[400,50],[30,20]]` 为例：

```
原始数据：
人员  A市  B市  diff(B-A)
0     10   20   +10
1     30   200  +170
2     400  50   -350
3     30   20   -10

按diff排序：
人员  A市  B市  diff(B-A)
2     400  50   -350  ← 去B市
3     30   20   -10   ← 去B市
0     10   20   +10   ← 去A市
1     30   200  +170  ← 去A市

费用计算：
去B: 50 + 20 = 70
去A: 10 + 30 = 40
总计: 110
```

## 关键点总结

1. **贪心策略**：按相对优势选择城市
2. **排序依据**：`bCost - aCost` 或 `aCost - bCost`
3. **问题转化**：选择问题转化为排序问题
4. **平衡约束**：每个城市恰好n人
5. **相对成本**：关注的是相对差异，不是绝对值

## 易错点

1. **排序方向**：要清楚是升序还是降序
2. **索引范围**：前n个和后n个的划分
3. **费用计算**：前半去B，后半去A（或相反）
4. **理解diff**：diff为负表示去B更划算
5. **边界情况**：n=1时也要正确处理
