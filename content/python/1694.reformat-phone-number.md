## 题目描述

给你一个字符串形式的电话号码 `number`。`number` 由数字、空格和破折号组成。

请你按下述规则整理电话号码的格式：
1. 首先，**删除**所有的空格和破折号
2. 其次，将数组**从左到右**每 3 个一组分块，**直到**剩下 4 个或更少数字。剩下的数字将按下述方式分块：
   - 2 个数字：单个含 2 个数字的块
   - 3 个数字：单个含 3 个数字的块
   - 4 个数字：两个分别含 2 个数字的块

用破折号连接这些块后，返回格式化后的电话号码。

保证输入的电话号码包含至少 2 位数字。

**示例 1：**
```
输入：number = "1-23-45 6"
输出："123-456"
```

**示例 2：**
```
输入：number = "123 4-5678"
输出："123-456-78"
```

**示例 3：**
```
输入：number = "12"
输出："12"
```

**提示：**
- `2 <= number.length <= 100`
- `number` 由数字和字符 `'-'`、`' '` 组成
- `number` 中至少含有 2 个数字

## 解题思路

1. 先过滤掉空格和破折号，只保留数字
2. 将纯数字字符串按规则分块：每 3 个一组，最后剩余按 2/3/4（拆成2+2）处理
3. 用 `-` 连接所有块

对于最后的处理，若剩余 4 个数字，则分成两个 2 位块；否则（2 或 3 个）作为一块。

## 代码实现

### 方法一：模拟（推荐）

```python
class Solution:
    def reformatNumber(self, number: str) -> str:
        # 步骤1：过滤非数字字符
        digits = [c for c in number if c.isdigit()]
        digits = ''.join(digits)

        n = len(digits)
        blocks = []
        i = 0

        # 步骤2：每次取 3 个，直到剩余不超过 4 个
        while n - i > 4:
            blocks.append(digits[i:i + 3])
            i += 3

        # 步骤3：处理剩余部分
        remaining = n - i
        if remaining == 4:
            # 4 个数字拆成 2+2
            blocks.append(digits[i:i + 2])
            blocks.append(digits[i + 2:i + 4])
        else:
            # 2 或 3 个数字直接作为一块
            blocks.append(digits[i:])

        return '-'.join(blocks)
```

### 方法二：利用切片和列表推导

```python
class Solution:
    def reformatNumber(self, number: str) -> str:
        # 过滤数字
        digits = number.replace('-', '').replace(' ', '')
        n = len(digits)
        blocks = []
        i = 0

        while i < n:
            # 剩余数量决定分法
            left = n - i
            if left > 4:
                blocks.append(digits[i:i + 3])
                i += 3
            elif left == 4:
                blocks.append(digits[i:i + 2])
                blocks.append(digits[i + 2:i + 4])
                i += 4
            else:
                # left == 2 或 3
                blocks.append(digits[i:])
                break

        return '-'.join(blocks)
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串常数次
- **空间复杂度**：O(n)，存储过滤后的数字和分块结果

## 关键点总结

1. 先清除所有非数字字符，再处理分块
2. 关键判断：剩余 4 个时拆成 2+2，而非 3+1（3+1 不合法）
3. 使用 `-`.join 连接各块

## 易错点

1. 剩余 4 个时不能作为一整块，必须拆成 2+2
2. 字符串过滤可以用 `str.replace()` 或 `filter(str.isdigit, number)`
3. 分块时的边界条件：`while n - i > 4` 确保循环退出时剩余不超过 4 个
