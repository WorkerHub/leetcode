## 题目描述

给定在 xy 平面上的一组点，确定由这些点组成的任何矩形的最小面积，其中矩形的边**不一定平行于** x 轴和 y 轴。

如果没有任何矩形，就返回 0。

**示例 1：**
```
输入：[[1,2],[2,1],[1,0],[0,1]]
输出：2.00000
解释：最小面积的矩形出现在 [1,2],[2,1],[1,0],[0,1] 时，面积为 2。
```

**示例 2：**
```
输入：[[0,1],[2,1],[1,1],[1,0],[2,0]]
输出：1.00000
解释：最小面积的矩形出现在 [1,0],[1,1],[2,1],[2,0] 时，面积为 1。
```

**示例 3：**
```
输入：[[0,3],[1,2],[3,1],[1,3],[2,1]]
输出：0
解释：没法从这些点中组成任何矩形。
```

**示例 4：**
```
输入：[[3,1],[1,1],[0,1],[2,1],[3,3],[3,2],[0,2],[2,3]]
输出：2.00000
解释：最小面积的矩形出现在 [2,1],[2,3],[3,3],[3,1] 时，面积为 2。
```

**提示：**
- `1 <= points.length <= 50`
- `points[i].length == 2`
- `0 <= points[i][0], points[i][1] <= 4 * 10^4`
- 所有的点都是不同的
- 答案误差不超过 `10^-5`

## 解题思路

这道题与 [939. 最小面积矩形](https://leetcode.com/problems/minimum-area-rectangle/) 的区别在于，矩形的边不一定平行于坐标轴。

**核心思想：**
1. 矩形的性质：对角线互相平分且相等（对于正方形）或对角线互相平分（对于一般矩形）
2. 枚举所有点对作为对角线，检查是否能构成矩形
3. 对于两个点作为对角线，需要满足：
   - 中点相同
   - 两条对角线长度相等（或判断四个点是否构成矩形）

**判断矩形的方法：**
- 枚举任意两个点作为可能的对角线端点
- 如果两个点对的中点相同且满足矩形性质，则构成矩形
- 计算面积并更新最小值

## Python 代码实现

### 方法一：枚举对角线（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def minAreaFreeRect(self, points: List[List[int]]) -> float:
        n = len(points)
        if n < 4:
            return 0
        
        # 使用字典存储所有对角线
        # key: (中点坐标, 对角线长度平方)
        # value: [(点1索引, 点2索引), ...]
        diagonals = defaultdict(list)
        
        # 枚举所有点对作为对角线
        for i in range(n):
            for j in range(i + 1, n):
                x1, y1 = points[i]
                x2, y2 = points[j]
                
                # 计算中点（使用2倍坐标避免浮点数）
                center = ((x1 + x2), (y1 + y2))
                
                # 计算对角线长度的平方
                dist_sq = (x1 - x2) ** 2 + (y1 - y2) ** 2
                
                diagonals[(center, dist_sq)].append((i, j))
        
        min_area = float('inf')
        
        # 遍历所有对角线组
        for (center, dist_sq), pairs in diagonals.items():
            # 如果只有一条对角线，无法构成矩形
            if len(pairs) < 2:
                continue
            
            # 枚举同一组中的两条对角线
            for i in range(len(pairs)):
                for j in range(i + 1, len(pairs)):
                    p1_idx, p2_idx = pairs[i]
                    p3_idx, p4_idx = pairs[j]
                    
                    # 获取四个点
                    p1 = points[p1_idx]
                    p2 = points[p2_idx]
                    p3 = points[p3_idx]
                    
                    # 计算矩形的两条边长
                    # 边1：p1 到 p3
                    side1 = ((p1[0] - p3[0]) ** 2 + (p1[1] - p3[1]) ** 2) ** 0.5
                    # 边2：p1 到 p4（使用 p2 和 p3 也可以）
                    p4 = points[p4_idx]
                    side2 = ((p1[0] - p4[0]) ** 2 + (p1[1] - p4[1]) ** 2) ** 0.5
                    
                    # 计算面积
                    area = side1 * side2
                    min_area = min(min_area, area)
        
        return min_area if min_area != float('inf') else 0
```

### 方法二：向量叉积判断

```python
from typing import List
from collections import defaultdict

class Solution:
    def minAreaFreeRect(self, points: List[List[int]]) -> float:
        n = len(points)
        if n < 4:
            return 0
        
        # 将点转为元组并存入集合，方便查找
        point_set = set(map(tuple, points))
        min_area = float('inf')
        
        # 枚举三个点
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    x1, y1 = points[i]
                    x2, y2 = points[j]
                    x3, y3 = points[k]
                    
                    # 尝试以 (i, j, k) 构成矩形的三个顶点
                    # 第四个点应该是 p4 = p2 + p3 - p1
                    # 即 (x2 + x3 - x1, y2 + y3 - y1)
                    x4 = x2 + x3 - x1
                    y4 = y2 + y3 - y1
                    
                    if (x4, y4) not in point_set:
                        continue
                    
                    # 检查是否为矩形（两条边垂直）
                    # 向量 p1->p2 和 p1->p3
                    v1 = (x2 - x1, y2 - y1)
                    v2 = (x3 - x1, y3 - y1)
                    
                    # 点积为 0 表示垂直
                    if v1[0] * v2[0] + v1[1] * v2[1] == 0:
                        # 计算边长
                        len1 = (v1[0] ** 2 + v1[1] ** 2) ** 0.5
                        len2 = (v2[0] ** 2 + v2[1] ** 2) ** 0.5
                        area = len1 * len2
                        min_area = min(min_area, area)
        
        return min_area if min_area != float('inf') else 0
```

### 方法三：优化的枚举

```python
from typing import List
import itertools

class Solution:
    def minAreaFreeRect(self, points: List[List[int]]) -> float:
        n = len(points)
        if n < 4:
            return 0
        
        point_set = set(map(tuple, points))
        min_area = float('inf')
        
        # 枚举所有四个点的组合
        for combo in itertools.combinations(range(n), 4):
            # 获取四个点
            pts = [points[i] for i in combo]
            
            # 检查这四个点是否能构成矩形
            # 枚举三种配对方式
            for indices in [((0, 1), (2, 3)), ((0, 2), (1, 3)), ((0, 3), (1, 2))]:
                (i1, i2), (i3, i4) = indices
                p1, p2, p3, p4 = pts[i1], pts[i2], pts[i3], pts[i4]
                
                # 检查对角线是否互相平分
                if (p1[0] + p2[0] == p3[0] + p4[0] and 
                    p1[1] + p2[1] == p3[1] + p4[1]):
                    
                    # 检查是否为矩形（两对角线长度相等）
                    d1 = (p1[0] - p2[0]) ** 2 + (p1[1] - p2[1]) ** 2
                    d2 = (p3[0] - p4[0]) ** 2 + (p3[1] - p4[1]) ** 2
                    
                    if d1 == d2:
                        # 计算面积
                        v1 = (pts[1][0] - pts[0][0], pts[1][1] - pts[0][1])
                        v2 = (pts[2][0] - pts[0][0], pts[2][1] - pts[0][1])
                        
                        # 使用叉积计算面积
                        area = abs(v1[0] * v2[1] - v1[1] * v2[0])
                        min_area = min(min_area, area)
        
        return min_area if min_area != float('inf') else 0
```

## 复杂度分析

### 方法一：枚举对角线
- **时间复杂度**：O(n² + m²)，其中 n 是点的个数，m 是对角线的个数（最多 O(n²)）
- **空间复杂度**：O(n²)，存储所有对角线

### 方法二：向量判断
- **时间复杂度**：O(n³)，枚举三个点
- **空间复杂度**：O(n)，点集合空间

### 方法三：枚举组合
- **时间复杂度**：O(n⁴)，枚举所有四点组合
- **空间复杂度**：O(n)

## 关键点总结

1. **矩形性质**：对角线互相平分且相等（平行四边形），加上任意两边垂直（矩形）
2. **中心点**：两条对角线的中点必须相同
3. **浮点精度**：使用平方值避免开方运算的精度损失
4. **哈希优化**：通过对角线中点和长度分组，减少枚举次数
5. **向量点积**：判断两边是否垂直

## 易错点

1. **浮点精度**：比较浮点数时要考虑精度问题
2. **中点计算**：使用 2 倍坐标避免浮点数中点
3. **面积计算**：使用叉积或边长乘积，注意公式正确性
4. **去重**：避免计算重复的矩形
5. **特殊情况**：点数少于 4 时返回 0
