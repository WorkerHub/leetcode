## 题目描述

给你一个整数 `n`，返回所有满足以下条件的下标对 `[x, y]`（`x <= y`）：
- `x + y == n`
- `x` 和 `y` 都是质数

按升序返回所有这样的下标对。

**示例 1：**
```
输入：n = 10
输出：[[3,7],[5,5]]
```

**示例 2：**
```
输入：n = 2
输出：[]
```

**提示：**
- `1 <= n <= 10^6`

## 解题思路

使用埃拉托斯特尼筛法预处理 n 以内的所有质数，然后枚举 `x` 从 2 到 `n//2`，检查 `x` 和 `n-x` 是否都是质数。

## Python 代码实现

### 方法一：埃氏筛 + 枚举（推荐）

```python
from typing import List

class Solution:
    def findPrimePairs(self, n: int) -> List[List[int]]:
        # 埃氏筛预处理质数
        is_prime = [True] * (n + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(n**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, n+1, i):
                    is_prime[j] = False

        ans = []
        for x in range(2, n // 2 + 1):
            y = n - x
            if is_prime[x] and is_prime[y]:
                ans.append([x, y])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log log n)（筛法） + O(n)（枚举）
- 空间复杂度：O(n)

## 关键点总结

1. 埃氏筛高效预处理质数
2. 枚举 x 到 n//2，避免重复对
3. 对 `[x, x]`（n 为偶数且 x = n/2）自然包含在 `x <= y` 中

## 易错点

1. 注意 1 不是质数
2. x 枚举到 `n//2` 确保 `x <= y`
