## 题目描述

给你一棵 `n` 个节点的无根带权树，节点编号为 0 到 n-1，每个节点有价格 `price[i]`。

路径的 **代价** 定义为路径上所有节点价格之和。

选择树上的一条路径（至少一个节点），路径的 **分数** = 路径最大价格节点的代价 - 路径最小价格节点的代价（即从较贵的端点到较便宜的端点的代价差）。

返回所有路径中最大分数的值。

**示例：**

```
输入：n = 6, edges = [[0,1],[1,2],[1,3],[3,4],[3,5]], price = [9,8,1,6,2,4]
输出：24
解释：路径 0→1→3 代价 23，路径 2→1→3→5 等，最优路径得分 24。
```

**提示：**

- `1 <= n <= 10^5`
- `edges.length == n - 1`
- `price.length == n`

## 解题思路

**换根 DP**。对每个节点，考虑以它为路径的一端（价格可选也可不选该端节点）：

分数 = (路径总和) - min(端点价格) = max(含端点的链和 - 端点价格, 含端点的链和 - 另一端点价格)

等价于：对每个节点，考虑以它为"去掉端点"的一端，找另一端的最大"非端节点链和"。

实现：DFS 计算每个节点向下的最大链和（端节点不计入）和最大链和（端节点计入），换根 DP 合并答案。

## Python 代码实现

### 方法一：两次 DFS（推荐）

```python
from typing import List
from collections import defaultdict
import sys
sys.setrecursionlimit(200000)

class Solution:
    def maxOutput(self, n: int, edges: List[List[int]], price: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 0

        # 对每个节点，返回 (以该节点为端点的最大链和（含自身）, 最大链和（不含自身）)
        # 递推关系用于合并两子树的路径
        # dp1[v] = 从 v 出发向下，包含 v 自身的最大链
        # dp2[v] = 从 v 出发向下，不含 v 自身的最大链（即取子节点的 dp1）
        dp1 = [0] * n  # 含端点（v 自身）的最大链和
        dp2 = [0] * n  # 不含端点的最大链和

        # 第一次 DFS：以 0 为根，计算向下的 dp1, dp2
        def dfs(v, parent):
            nonlocal ans
            dp1[v] = price[v]
            dp2[v] = 0
            for u in graph[v]:
                if u == parent:
                    continue
                dfs(u, v)
                # 尝试合并：一端含 v，另一端含 u（dp1[u]）或不含 u（dp2[u]）
                ans = max(ans,
                          dp1[v] + dp1[u] - price[v],  # 两端都是叶子端点，减去 v 的端点代价
                          dp1[v] + dp2[u],              # v 含，u 不含（u 侧去掉端点）
                          dp2[v] + dp1[u])              # v 不含（v 侧去掉端点），u 含
                # 更新 dp1[v] 和 dp2[v]
                dp2[v] = max(dp2[v], dp1[u] + price[v] - price[v], dp1[u])
                # 修正：dp2[v] = max(dp2[v], dp1[u]) -- 不含 v 的端点，从 u 的最大含端点链延伸到 v
                dp2[v] = max(dp2[v], dp1[u])
                dp1[v] = max(dp1[v], dp1[u] + price[v])

            ans = max(ans, dp1[v], dp2[v])

        dfs(0, -1)
        return ans
```

### 方法二：简化版 DFS（以每个节点为路径一个端点）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxOutput(self, n: int, edges: List[List[int]], price: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 返回 (含当前节点的最大链和, 不含当前节点的最大链和)
        # 分数 = 含端点链 + 不含端点链（两端不同）
        ans = 0

        def dfs(node, parent):
            nonlocal ans
            # 不含当前节点的最大链（从子节点出发的最大含端点链）
            max_with = price[node]    # 含 node 的最大链
            max_without = 0           # 不含 node 的最大链（即取 node 出发的 max_with 去掉 node）

            for child in graph[node]:
                if child == parent:
                    continue
                child_with, child_without = dfs(child, node)

                # 合并：node 为一端（不含）- child 为另一端（含）
                ans = max(ans, max_with - price[node] + child_with,
                               max_without + child_with,
                               max_with + child_without)

                # 更新
                max_without = max(max_without, child_with)
                max_with = max(max_with, child_with + price[node])

            return max_with, max_without

        dfs(0, -1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，DFS 遍历每个节点一次
- 空间复杂度：O(n)，递归栈和邻接表

## 关键点总结

1. 路径分数 = 路径总和 - 某端点价格（去掉代价最小的端点）
2. 等价于：含端点的链 + 不含端点的链（从另一节点出发）
3. DFS 维护两个状态：含当前节点的最大链和、不含当前节点的最大链和

## 易错点

1. 路径至少含一个节点，单节点路径分数为 0
2. "去掉端点"意味着路径分数不计入端点价格
3. 合并两子树时要考虑多种组合（都含/一含一不含）
