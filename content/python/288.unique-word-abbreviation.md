## 题目描述

单词的缩写需遵循以下格式：

1. 初始缩写由起始字母 + 省略字母的数量 + 结尾字母组成。
2. 若存在冲突，亦即多于一个单词有同样的缩写，则使用以下格式 `起始字母 + 省略字母的数量 + 结尾字母 + 重复数字`。

例如，`dog --> d1g` 因为存在一个字母被省略，`internationalization --> i18n` 因为中间有 18 个字母被省略。

假设你有一个字典和一个单词，请你判断该单词的缩写在这本字典中是否唯一。若单词的缩写在字典中唯一，则返回 `true`；否则，返回 `false`。

**示例 1:**

```
输入:
["ValidWordAbbr","isUnique","isUnique","isUnique","isUnique"]
[[["deer","door","cake","card"]],["dear"],["cart"],["cane"],["make"]]

输出:
[null,false,true,false,true]

解释:
ValidWordAbbr validWordAbbr = new ValidWordAbbr(["deer", "door", "cake", "card"]);
validWordAbbr.isUnique("dear"); // 返回 false，字典中的 "deer" 与 "door" 有相同的缩写 "d2r"，但这两个单词本身不同。
validWordAbbr.isUnique("cart"); // 返回 true，没有其他单词的缩写是 "c2t"。
validWordAbbr.isUnique("cane"); // 返回 false，字典中的 "cake" 有缩写 "c2e"。
validWordAbbr.isUnique("make"); // 返回 true，没有其他单词的缩写是 "m2e"。
```

**示例 2:**

```
输入:
["ValidWordAbbr","isUnique","isUnique","isUnique","isUnique","isUnique"]
[[["a","a"]],["a"],["a"],["a"],["a"],["a"]]

输出:
[null,true,true,true,true,true]

解释: 所有查询的单词都与字典中的单词相同，因此都返回 true。
```

**提示:**

- `1 <= dictionary.length <= 3 * 10^4`
- `1 <= dictionary[i].length <= 20`
- `dictionary[i]` 由小写英文字母组成
- `1 <= word.length <= 20`
- `word` 由小写英文字母组成
- 最多调用 `5000` 次 `isUnique`

## 解题思路

这道题的核心是判断一个单词的缩写在字典中是否唯一。需要注意"唯一"的定义。

**关键理解：**

一个单词的缩写唯一，当且仅当：
1. 字典中没有其他单词有相同的缩写，或
2. 字典中唯一有相同缩写的单词就是它本身

**易错点：**

很容易误解为"缩写在字典中不存在就返回 true"，但实际上：
- `["deer", "door"]` 对于查询 `"deer"`，应该返回 `false`
- 因为 `"door"` 也有缩写 `"d2r"`

**解题思路：**

方法一：哈希表存储缩写到单词集合的映射
- 缩写 -> 所有具有该缩写的单词集合
- 判断时检查该集合大小和是否包含查询单词

方法二：哈希表存储缩写计数
- 缩写 -> (单词, 计数)
- 需要处理好字典中有重复单词的情况

**算法流程：**

1. 预处理字典，构建缩写到单词集合的映射
2. 对于查询单词，计算其缩写
3. 检查该缩写对应的单词集合：
   - 集合为空：唯一
   - 集合只有一个单词且等于查询单词：唯一
   - 其他情况：不唯一

## Python 代码实现

### 方法一：哈希表存储单词集合（推荐）

```python
from typing import List
from collections import defaultdict

class ValidWordAbbr:
    def __init__(self, dictionary: List[str]):
        """
        初始化：构建缩写到单词集合的映射
        """
        self.abbr_map = defaultdict(set)
        
        for word in dictionary:
            abbr = self._get_abbr(word)
            self.abbr_map[abbr].add(word)
    
    def _get_abbr(self, word: str) -> str:
        """
        获取单词的缩写
        """
        if len(word) <= 2:
            return word
        return word[0] + str(len(word) - 2) + word[-1]
    
    def isUnique(self, word: str) -> bool:
        """
        判断单词的缩写是否唯一
        
        唯一的条件：
        1. 字典中没有该缩写，或
        2. 字典中该缩写只对应一个单词，且就是查询单词本身
        """
        abbr = self._get_abbr(word)
        words_with_same_abbr = self.abbr_map[abbr]
        
        # 没有相同缩写的单词，或只有查询单词本身
        return len(words_with_same_abbr) == 0 or \
               (len(words_with_same_abbr) == 1 and word in words_with_same_abbr)
```

### 方法二：更简洁的实现

```python
class ValidWordAbbr:
    def __init__(self, dictionary: List[str]):
        self.abbr_to_words = {}
        
        for word in dictionary:
            abbr = self._abbreviate(word)
            if abbr not in self.abbr_to_words:
                self.abbr_to_words[abbr] = set()
            self.abbr_to_words[abbr].add(word)
    
    def _abbreviate(self, word: str) -> str:
        n = len(word)
        if n <= 2:
            return word
        return f"{word[0]}{n - 2}{word[-1]}"
    
    def isUnique(self, word: str) -> bool:
        abbr = self._abbreviate(word)
        
        # 该缩写不存在
        if abbr not in self.abbr_to_words:
            return True
        
        # 只有查询单词本身有这个缩写
        words = self.abbr_to_words[abbr]
        return len(words) == 1 and word in words
```

### 方法三：详细注释版（新手友好）

```python
from collections import defaultdict

class ValidWordAbbr:
    """
    判断单词缩写是否唯一
    
    缩写规则：
    - 长度 <= 2: 不缩写
    - 长度 > 2: 首字母 + 中间字母数量 + 尾字母
    
    唯一性定义：
    - 字典中没有其他单词有相同缩写
    - 或字典中唯一有相同缩写的单词就是它本身
    
    示例：
    字典: ["deer", "door", "cake", "card"]
    缩写: d2r, d2r, c2e, c2d
    
    查询 "dear" (缩写 d2r):
    - 字典中 "deer" 和 "door" 都是 d2r
    - "dear" 不在字典中
    - 返回 false（不唯一）
    
    查询 "deer" (缩写 d2r):
    - 字典中 "deer" 和 "door" 都是 d2r
    - "deer" 在字典中，但 "door" 也有相同缩写
    - 返回 false（不唯一）
    
    查询 "cart" (缩写 c2t):
    - 字典中没有单词缩写为 c2t
    - 返回 true（唯一）
    """
    
    def __init__(self, dictionary: List[str]):
        # 缩写 -> 具有该缩写的所有单词的集合
        self.abbr_dict = defaultdict(set)
        
        # 预处理字典
        for word in dictionary:
            abbr = self.get_abbreviation(word)
            self.abbr_dict[abbr].add(word)
    
    def get_abbreviation(self, word: str) -> str:
        """
        计算单词的缩写
        
        word: 待缩写的单词
        return: 缩写字符串
        
        示例:
        "deer" -> "d2r"
        "door" -> "d2r"
        "cake" -> "c2e"
        "it" -> "it" (长度<=2 不缩写)
        """
        length = len(word)
        
        # 长度 <= 2 不需要缩写
        if length <= 2:
            return word
        
        # 首字母 + 中间字母数 + 尾字母
        return word[0] + str(length - 2) + word[-1]
    
    def isUnique(self, word: str) -> bool:
        """
        判断单词的缩写是否唯一
        
        word: 查询的单词
        return: 是否唯一
        """
        abbr = self.get_abbreviation(word)
        
        # 获取具有相同缩写的所有单词
        words_with_same_abbr = self.abbr_dict[abbr]
        
        # 情况 1：没有单词有这个缩写
        if len(words_with_same_abbr) == 0:
            return True
        
        # 情况 2：只有一个单词有这个缩写，且就是查询单词本身
        if len(words_with_same_abbr) == 1 and word in words_with_same_abbr:
            return True
        
        # 情况 3：有多个单词有相同缩写，或唯一的单词不是查询单词
        return False

# 使用示例
# dictionary = ["deer", "door", "cake", "card"]
# obj = ValidWordAbbr(dictionary)
# print(obj.isUnique("dear"))  # False
# print(obj.isUnique("cart"))  # True
# print(obj.isUnique("cane"))  # False
# print(obj.isUnique("make"))  # True
# print(obj.isUnique("deer"))  # False
```

### 方法四：使用字典存储计数

```python
class ValidWordAbbr:
    def __init__(self, dictionary: List[str]):
        """
        存储每个缩写对应的不同单词数量
        """
        from collections import Counter
        
        # 先去重
        unique_words = set(dictionary)
        
        # 统计每个缩写对应的单词
        self.abbr_map = {}
        for word in unique_words:
            abbr = self._abbr(word)
            if abbr not in self.abbr_map:
                self.abbr_map[abbr] = set()
            self.abbr_map[abbr].add(word)
    
    def _abbr(self, word: str) -> str:
        if len(word) <= 2:
            return word
        return word[0] + str(len(word) - 2) + word[-1]
    
    def isUnique(self, word: str) -> bool:
        abbr = self._abbr(word)
        
        if abbr not in self.abbr_map:
            return True
        
        # 只有一个单词且是查询单词
        return self.abbr_map[abbr] == {word}
```

## 复杂度分析

**初始化：**
- 时间复杂度：`O(n * k)` n 是字典大小，k 是单词平均长度
- 空间复杂度：`O(n * k)` 存储所有单词

**isUnique 查询：**
- 时间复杂度：`O(k)` 计算缩写
- 空间复杂度：`O(1)` 不使用额外空间

## 关键点总结

1. **唯一性定义**：理解"唯一"不是"不存在"，而是"没有其他不同单词有相同缩写"
2. **集合存储**：使用 set 存储具有相同缩写的单词，便于去重和判断
3. **边界处理**：长度 <= 2 的单词不缩写
4. **字典预处理**：需要处理字典中有重复单词的情况
5. **缩写计算**：首字母 + 中间字母数 + 尾字母

## 易错点

1. **唯一性理解错误**：误认为缩写不存在就返回 true
2. **重复单词处理**：字典中可能有重复单词，需要去重或使用 set
3. **查询单词在字典中**：查询 `"deer"` 时，`"deer"` 和 `"door"` 都在字典中，应返回 false
4. **边界情况**：长度为 1 或 2 的单词需要特殊处理
5. **空字典**：初始化时字典可能为空
