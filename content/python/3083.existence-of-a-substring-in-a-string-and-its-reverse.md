## 题目描述

给你一个字符串 `s`，如果 `s` 中存在长度为 2 的子字符串，同时也是 `s` 的**反转字符串**的子字符串，则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：s = "leetcode"
输出：true
解释：子字符串 "ee" 同时也在 "edocteel" 中（即反转后的 s）
```

**示例 2：**
```
输入：s = "abcba"
输出：true
```

**示例 3：**
```
输入：s = "abcd"
输出：false
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

枚举 `s` 中所有长度为 2 的子字符串，检查其是否在 `s` 的反转中出现（等价于 `s` 中是否有 `s[i+1] + s[i]` 这样的子字符串）。

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
class Solution:
    def isSubstringPresent(self, s: str) -> bool:
        # 收集 s 中所有长度为 2 的子字符串
        sub2 = set(s[i:i+2] for i in range(len(s) - 1))
        # 检查 s 的反转中是否有 sub2 中的子字符串
        # 等价于 s 中是否存在 sub2 中某个字符串的反转
        return any(sub[::-1] in sub2 for sub in sub2)
```

### 方法二：直接检查

```python
class Solution:
    def isSubstringPresent(self, s: str) -> bool:
        # 检查 s 中任意 s[i]s[i+1]，s 中是否有 s[i+1]s[i]
        pairs = set()
        for i in range(len(s) - 1):
            pairs.add((s[i], s[i+1]))

        for a, b in pairs:
            if (b, a) in pairs:
                return True
        return False
```

### 方法三：最简版

```python
class Solution:
    def isSubstringPresent(self, s: str) -> bool:
        rev = s[::-1]
        return any(s[i:i+2] in rev for i in range(len(s) - 1))
```

## 复杂度分析

- 时间复杂度：O(n)，n 个长度为 2 的子字符串，每次检查 O(1)（哈希集合）
- 空间复杂度：O(n)，存储子字符串集合

## 关键点总结

1. 长度为 2 的子字符串最多 26^2 = 676 种
2. `"ab"` 在反转字符串中 = `"ba"` 在原字符串中
3. 用集合存储所有长度为 2 的子串，O(1) 查询

## 易错点

1. 检查的是长度为 2 的子字符串，不是单字符
2. 反转字符串中包含子串等价于原字符串中包含该子串的反转
