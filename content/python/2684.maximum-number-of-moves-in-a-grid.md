## 题目描述

给你一个 `m x n` 的矩阵 `grid`，初始位置在第 0 列的任意一行。每步可以从当前单元格移动到右侧三个相邻格（右上、右、右下），但要求目标格的值**严格大于**当前格。

返回可以移动的最大次数。

**示例 1：**
```
输入：grid = [[2,4,3,5],[5,4,9,3],[3,4,2,11],[10,9,13,15]]
输出：3
```

**示例 2：**
```
输入：grid = [[3,2,4],[2,1,9],[1,1,7]]
输出：0
```

**数据范围：**
- m == grid.length, n == grid[0].length
- 2 <= m, n <= 1000
- 4 <= grid[i][j] <= 10^6

## 解题思路

动态规划：`dp[i][j]` = 从第 0 列出发，到达位置 `(i,j)` 的最大移动次数（-1 表示不可达）。

按列从左到右计算：第 0 列所有格可达（dp[i][0] = 0），每格可以向右上、右、右下移动。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxMoves(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # dp[i][j]: 到达 (i,j) 的最大步数，-1 表示不可达
        dp = [[-1] * n for _ in range(m)]

        # 第 0 列都可以作为起点
        for i in range(m):
            dp[i][0] = 0

        ans = 0
        for j in range(1, n):
            for i in range(m):
                # 三个可能的来源：(i-1,j-1), (i,j-1), (i+1,j-1)
                for di in [-1, 0, 1]:
                    pi = i + di
                    if 0 <= pi < m and dp[pi][j - 1] >= 0 and grid[i][j] > grid[pi][j - 1]:
                        dp[i][j] = max(dp[i][j], dp[pi][j - 1] + 1)
                ans = max(ans, dp[i][j])

        return ans
```

### 方法二：BFS

```python
from typing import List
from collections import deque

class Solution:
    def maxMoves(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        visited = [[False] * n for _ in range(m)]
        queue = deque()
        # 将第 0 列所有格加入队列
        for i in range(m):
            queue.append((i, 0, 0))  # (行, 列, 步数)
            visited[i][0] = True

        ans = 0
        while queue:
            r, c, steps = queue.popleft()
            ans = max(ans, steps)
            for dr in [-1, 0, 1]:
                nr, nc = r + dr, c + 1
                if 0 <= nr < m and nc < n and not visited[nr][nc] and grid[nr][nc] > grid[r][c]:
                    visited[nr][nc] = True
                    queue.append((nr, nc, steps + 1))

        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 每步只能向右移动（列递增），且值严格递增
2. DP 按列从左到右计算，每格从三个可能的前驱中取最大
3. BFS 也可以，用 visited 避免重复

## 易错点

1. 初始位置在第 0 列的任意行
2. 目标格值必须**严格大于**当前格（不能相等）
3. 边界检查：`0 <= nr < m` 且 `nc < n`
