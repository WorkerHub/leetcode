## 题目描述

给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **小于** 当前节点的数。
- 节点的右子树只包含 **大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

**示例 1：**

```
输入：root = [2,1,3]
输出：true
```

**示例 2：**

```
输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5，但是右子节点的值是 4。
```

**提示：**

- 树中节点数目范围在 `[1, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 解题思路

这道题是二叉搜索树（BST）的经典验证问题，关键在于理解 BST 的性质。

**核心观察：**

1. **错误理解：** 不能只检查每个节点是否满足「左子节点 < 当前节点 < 右子节点」，因为这只考虑了父子关系，没有考虑整棵子树。

2. **正确理解：** 对于每个节点，它的值必须在一个有效的范围内：
   - 左子树的所有节点值必须小于当前节点
   - 右子树的所有节点值必须大于当前节点

3. **BST 的关键性质：** 中序遍历（左-根-右）BST 会得到一个严格递增的序列。

**解法思路：**

- **方法一（中序遍历）：** 进行中序遍历，检查遍历结果是否严格递增
- **方法二（递归边界）：** 递归时传递每个节点的取值范围（下界和上界）
- **方法三（迭代中序）：** 用栈模拟中序遍历，空间优化

## Python 代码实现

### 方法一：中序遍历（推荐）

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        """
        中序遍历法：BST 的中序遍历结果应该是严格递增序列
        """
        self.prev = None  # 记录中序遍历的前一个节点值
        return self.inorder(root)
    
    def inorder(self, node: TreeNode) -> bool:
        if not node:
            return True
        
        # 递归遍历左子树
        if not self.inorder(node.left):
            return False
        
        # 检查当前节点：必须大于前一个节点
        if self.prev is not None and node.val <= self.prev:
            return False
        
        # 更新 prev 为当前节点值
        self.prev = node.val
        
        # 递归遍历右子树
        return self.inorder(node.right)
```

### 方法二：递归边界法

```python
class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        """
        递归边界法：为每个节点维护取值范围 (lower, upper)
        """
        def validate(node: TreeNode, lower: float, upper: float) -> bool:
            if not node:
                return True
            
            # 当前节点值必须在 (lower, upper) 范围内
            if node.val <= lower or node.val >= upper:
                return False
            
            # 递归检查左右子树
            # 左子树：上界是当前节点值
            # 右子树：下界是当前节点值
            return (validate(node.left, lower, node.val) and
                    validate(node.right, node.val, upper))
        
        # 初始范围是 (-∞, +∞)
        return validate(root, float('-inf'), float('inf'))
```

### 方法三：迭代中序遍历（空间优化）

```python
class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        """
        迭代中序遍历：使用栈模拟递归
        """
        stack = []
        prev = None
        current = root
        
        while stack or current:
            # 一直向左走，将路径上的节点入栈
            while current:
                stack.append(current)
                current = current.left
            
            # 弹出栈顶节点（当前最小节点）
            current = stack.pop()
            
            # 检查是否满足递增关系
            if prev is not None and current.val <= prev:
                return False
            
            prev = current.val
            
            # 转向右子树
            current = current.right
        
        return True
```

### 方法四：中序遍历数组法（最直观，适合初学者）

```python
class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        """
        最直观的方法：先中序遍历得到数组，再检查是否严格递增
        """
        def inorder(node: TreeNode) -> list:
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        # 获取中序遍历结果
        values = inorder(root)
        
        # 检查是否严格递增
        for i in range(1, len(values)):
            if values[i] <= values[i - 1]:
                return False
        
        return True
```

## 复杂度分析

**方法一、二、三：**

- **时间复杂度：** O(n)，其中 n 是树中节点的数量，每个节点访问一次
- **空间复杂度：** O(h)，其中 h 是树的高度（递归栈或迭代栈的空间）
  - 最好情况（平衡树）：O(log n)
  - 最坏情况（链状树）：O(n)

**方法四：**

- **时间复杂度：** O(n)
- **空间复杂度：** O(n)，需要额外的数组存储遍历结果

## 图解示例

以示例 2 为例：`[5,1,4,null,null,3,6]`

```
        5
       / \
      1   4
         / \
        3   6
```

**错误分析：**

- 局部检查：节点 4 满足 `3 < 4 < 6`，看似正确
- 全局检查：节点 4 在根节点 5 的右子树中，应该 `> 5`，但 `4 < 5`，不满足 BST 性质

**中序遍历结果：** `[1, 5, 3, 4, 6]`

- 发现 `5 > 3`，不是递增序列，返回 `false`

**正确的 BST 中序遍历示例：** `[2,1,3]`

```
    2
   / \
  1   3
```

中序遍历结果：`[1, 2, 3]`，严格递增，返回 `true`

## 关键点总结

1. **理解 BST 定义：** 不仅是父子关系，而是整个子树的范围约束
2. **中序遍历性质：** BST 的中序遍历结果是严格递增序列（核心性质）
3. **边界处理：** 使用 `float('-inf')` 和 `float('inf')` 作为初始边界
4. **严格递增：** 注意是 `<` 而不是 `<=`，相等的值也不符合 BST 定义
5. **空间优化：** 迭代法可以在某些情况下提前终止，节省时间

## 易错点

1. **只检查父子关系：**
   ```python
   # 错误示例
   def isValidBST(self, root):
       if not root:
           return True
       if root.left and root.left.val >= root.val:
           return False
       if root.right and root.right.val <= root.val:
           return False
       # 这样无法检测到跨层级的错误（如示例 2）
   ```

2. **忘记严格递增：**
   ```python
   # 错误：使用 < 而不是 <=
   if prev is not None and node.val < prev:  # 应该是 <=
       return False
   ```
   BST 不允许重复值，必须严格递增。

3. **边界值问题：**
   - 节点值可能是 `2^31 - 1` 或 `-2^31`
   - 使用 `float('inf')` 而不是 `2^31`，避免边界值判断错误

4. **prev 初始化：**
   - 使用 `None` 作为初始值，而不是 `float('-inf')`
   - 因为第一个节点（最小值）可能就是 `-2^31`
