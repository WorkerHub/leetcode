## 题目描述

给你一个 `m x n` 的矩阵 `grid`，其中：
- `'W'` 表示一堵墙
- `'E'` 表示一个敌人
- `'0'` (数字 0) 表示一个空位

返回你使用一枚炸弹可以击杀的最大敌人数。炸弹会杀死所有在同一行和同一列且没有墙阻隔的敌人。

注意：炸弹只能放在空位上。

**示例 1：**

```
输入: grid = [["0","E","0","0"],["E","0","W","E"],["0","E","0","0"]]
输出: 3
解释: 将炸弹放在 (1,1) 可以击杀 3 个敌人
```

**示例 2：**

```
输入: grid = [["W","W","W"],["0","0","0"],["E","E","E"]]
输出: 1
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 500`
- `grid[i][j]` 是 `'W'`、`'E'` 或 `'0'`

## 解题思路

这道题的核心是计算每个空位能击杀的敌人数。炸弹的攻击范围是：
1. 同一行中，左右两侧直到遇到墙为止的所有敌人
2. 同一列中，上下两侧直到遇到墙为止的所有敌人

### 方法一：暴力法（不推荐）

对于每个空位，分别向四个方向扫描统计敌人数。时间复杂度过高。

### 方法二：动态规划优化（推荐）

关键观察：
- 对于同一行中被墙分隔的区间，每个空位能击杀的行敌人数是相同的
- 对于同一列中被墙分隔的区间，每个空位能击杀的列敌人数是相同的

优化策略：
1. 使用 `rowHits` 记录当前行能击杀的敌人数（遇到墙时重新计算）
2. 使用 `colHits` 数组记录每列能击杀的敌人数（遇到墙时重新计算）
3. 只在遇到墙或新行时重新计算，避免重复扫描

## Python 代码实现

### 方法一：动态规划优化（推荐）

```python
from typing import List

class Solution:
    def maxKilledEnemies(self, grid: List[List[str]]) -> int:
        if not grid or not grid[0]:
            return 0
        
        m, n = len(grid), len(grid[0])
        max_enemies = 0
        row_hits = 0  # 当前行能击杀的敌人数
        col_hits = [0] * n  # 每列能击杀的敌人数
        
        for i in range(m):
            for j in range(n):
                # 遇到新行或墙时，重新计算当前行的敌人数
                if j == 0 or grid[i][j-1] == 'W':
                    row_hits = 0
                    # 向右扫描，统计到下一堵墙之前的敌人数
                    for k in range(j, n):
                        if grid[i][k] == 'W':
                            break
                        if grid[i][k] == 'E':
                            row_hits += 1
                
                # 遇到新列或墙时，重新计算当前列的敌人数
                if i == 0 or grid[i-1][j] == 'W':
                    col_hits[j] = 0
                    # 向下扫描，统计到下一堵墙之前的敌人数
                    for k in range(i, m):
                        if grid[k][j] == 'W':
                            break
                        if grid[k][j] == 'E':
                            col_hits[j] += 1
                
                # 如果是空位，计算能击杀的总敌人数
                if grid[i][j] == '0':
                    max_enemies = max(max_enemies, row_hits + col_hits[j])
        
        return max_enemies
```

### 方法二：四个方向的动态规划（更直观）

```python
from typing import List

class Solution:
    def maxKilledEnemies(self, grid: List[List[str]]) -> int:
        if not grid or not grid[0]:
            return 0
        
        m, n = len(grid), len(grid[0])
        
        # 分别记录从四个方向看能击杀的敌人数
        left = [[0] * n for _ in range(m)]
        right = [[0] * n for _ in range(m)]
        up = [[0] * n for _ in range(m)]
        down = [[0] * n for _ in range(m)]
        
        # 从左向右
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 'W':
                    left[i][j] = 0
                elif grid[i][j] == 'E':
                    left[i][j] = (left[i][j-1] if j > 0 else 0) + 1
                else:  # '0'
                    left[i][j] = left[i][j-1] if j > 0 else 0
        
        # 从右向左
        for i in range(m):
            for j in range(n-1, -1, -1):
                if grid[i][j] == 'W':
                    right[i][j] = 0
                elif grid[i][j] == 'E':
                    right[i][j] = (right[i][j+1] if j < n-1 else 0) + 1
                else:
                    right[i][j] = right[i][j+1] if j < n-1 else 0
        
        # 从上向下
        for j in range(n):
            for i in range(m):
                if grid[i][j] == 'W':
                    up[i][j] = 0
                elif grid[i][j] == 'E':
                    up[i][j] = (up[i-1][j] if i > 0 else 0) + 1
                else:
                    up[i][j] = up[i-1][j] if i > 0 else 0
        
        # 从下向上
        for j in range(n):
            for i in range(m-1, -1, -1):
                if grid[i][j] == 'W':
                    down[i][j] = 0
                elif grid[i][j] == 'E':
                    down[i][j] = (down[i+1][j] if i < m-1 else 0) + 1
                else:
                    down[i][j] = down[i+1][j] if i < m-1 else 0
        
        # 计算最大值
        max_enemies = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '0':
                    total = left[i][j] + right[i][j] + up[i][j] + down[i][j]
                    max_enemies = max(max_enemies, total)
        
        return max_enemies
```

## 复杂度分析

### 方法一：动态规划优化
- 时间复杂度：O(m × n)，虽然有嵌套循环，但每个格子的行和列统计只在遇到墙时进行，均摊后是 O(m × n)
- 空间复杂度：O(n)，只需要存储列的击杀数

### 方法二：四个方向的动态规划
- 时间复杂度：O(m × n)，需要扫描四次矩阵
- 空间复杂度：O(m × n)，需要四个辅助数组

## 关键点总结

1. **避免重复计算**：相同区间内的空位能击杀的敌人数是相同的，只需在遇到墙时重新计算
2. **方向分解**：将问题分解为行方向和列方向分别处理
3. **边界条件**：注意第一行、第一列以及墙的位置
4. **状态缓存**：使用变量缓存当前有效区间的敌人数
5. **空间优化**：方法一只需 O(n) 空间，优于方法二的 O(m × n)

## 易错点

1. **重复扫描**：每次都扫描整行/整列会导致超时，要利用墙的分隔特性
2. **墙的判断**：遇到墙时要清零计数器
3. **索引边界**：向右或向下扫描时注意不要越界
4. **条件判断顺序**：先判断是否需要重新计算，再使用缓存的值
5. **初始化**：新行的第一个元素要重新计算行击杀数
