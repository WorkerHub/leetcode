## 题目描述

给你一个整数数组 `nums` 和一个正整数 `threshold`。

你需要选择一个**正整数**作为除数，然后将数组里每个数都除以它，将除法结果**向上取整**后求和，使得结果小于等于 `threshold`。

请你找出**最小**的满足要求的除数。

**示例 1：**

```
输入：nums = [1,2,5,9], threshold = 6
输出：5
解释：
除数为 1: ceil(1/1)+ceil(2/1)+ceil(5/1)+ceil(9/1) = 1+2+5+9 = 17
除数为 4: ceil(1/4)+ceil(2/4)+ceil(5/4)+ceil(9/4) = 1+1+2+3 = 7
除数为 5: ceil(1/5)+ceil(2/5)+ceil(5/5)+ceil(9/5) = 1+1+1+2 = 5 <= 6
```

**示例 2：**

```
输入：nums = [2,3,5,7,11], threshold = 11
输出：3
```

**示例 3：**

```
输入：nums = [19], threshold = 5
输出：4
```

**提示：**

- `1 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 10^6`
- `nums.length <= threshold <= 10^6`

---

## 解题思路

### 关键观察：单调性

设 `f(d)` 为除数为 `d` 时各元素向上取整后的和：
- 当 `d` 增大时，`f(d)` **单调不增**（除数越大，各元素除以它的商越小或不变）。
- 当 `d=1` 时，`f(1)` 最大（等于 nums 之和）。
- 当 `d=max(nums)` 时，每个元素除以 d 的结果都是 1，`f(d) = len(nums)` 最小。

题目保证 `threshold >= len(nums)`，所以 `d=max(nums)` 时一定满足条件。

### 二分查找

由于 `f(d)` 具有单调性，可以在 `[1, max(nums)]` 的范围内进行二分查找，寻找最小的 `d` 使得 `f(d) <= threshold`。

**二分模板（寻找最左满足条件的值）：**
- 搜索范围：`left=1, right=max(nums)`
- 条件：`f(mid) <= threshold`
  - 满足：说明 mid 可能是答案，但也许更小的值也满足，缩小到左半段 `right = mid`
  - 不满足：mid 太小，必须增大，`left = mid + 1`
- 最终 `left == right` 就是答案

### 向上取整的技巧

`math.ceil(a / b)` 等价于 `(a + b - 1) // b`（整数运算，不引入浮点误差）。

```
ceil(7 / 3) = 3
(7 + 3 - 1) // 3 = 9 // 3 = 3  ✓

ceil(6 / 3) = 2
(6 + 3 - 1) // 3 = 8 // 3 = 2  ✓
```

## Python 代码实现

### 方法一：二分查找（推荐）

```python
import math
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:

        def compute_sum(divisor: int) -> int:
            """计算使用给定除数时，所有元素向上取整后的总和"""
            return sum(math.ceil(num / divisor) for num in nums)

        left, right = 1, max(nums)  # 除数的搜索范围

        while left < right:
            mid = (left + right) // 2

            if compute_sum(mid) <= threshold:
                # mid 满足条件，但可能存在更小的满足条件的除数
                # 缩小到左半段（包含 mid）
                right = mid
            else:
                # mid 不满足条件，除数需要更大
                left = mid + 1

        return left  # 循环结束时 left == right，即为最小满足条件的除数
```

### 方法二：二分查找 + 整数向上取整（避免浮点数）

```python
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:

        def compute_sum(divisor: int) -> int:
            """使用整数运算实现向上取整，避免浮点误差"""
            # ceil(a / b) = (a + b - 1) // b
            return sum((num + divisor - 1) // divisor for num in nums)

        left, right = 1, max(nums)

        while left < right:
            mid = (left + right) // 2

            if compute_sum(mid) <= threshold:
                right = mid
            else:
                left = mid + 1

        return left
```

### 方法三：线性搜索（暴力，用于理解）

```python
import math
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:
        # 从 1 开始逐一尝试每个除数
        for divisor in range(1, max(nums) + 1):
            total = sum(math.ceil(num / divisor) for num in nums)
            if total <= threshold:
                return divisor  # 找到第一个满足条件的除数
        return -1  # 不会到达这里
```

**注意：** 方法三时间复杂度为 O(n * max(nums))，当 max(nums)=10^6, n=5*10^4 时约 5*10^10 次操作，会超时，仅用于理解。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(n * log(max(nums))) | O(1) |
| 线性搜索 | O(n * max(nums)) | O(1) |

- **二分查找**：搜索范围为 [1, max(nums)]，每次二分；每次 compute_sum 需 O(n)，共 O(log(max(nums))) 次，总共 O(n * log(max(nums)))。
- 代入数据：n=5*10^4，log(10^6)≈20，约 10^6 次操作，完全可以接受。

## 图解示例

以 `nums = [1,2,5,9], threshold = 6` 为例：

```
搜索范围：[1, 9]

第1轮：left=1, right=9, mid=5
  f(5) = ceil(1/5)+ceil(2/5)+ceil(5/5)+ceil(9/5) = 1+1+1+2 = 5 <= 6
  满足条件，right = 5

第2轮：left=1, right=5, mid=3
  f(3) = ceil(1/3)+ceil(2/3)+ceil(5/3)+ceil(9/3) = 1+1+2+3 = 7 > 6
  不满足条件，left = 4

第3轮：left=4, right=5, mid=4
  f(4) = ceil(1/4)+ceil(2/4)+ceil(5/4)+ceil(9/4) = 1+1+2+3 = 7 > 6
  不满足条件，left = 5

left == right == 5，返回 5
```

## 关键点总结

1. **单调性是二分的前提**：除数越大，总和越小（单调不增），这是可以二分的根本原因。
2. **二分模板**：寻找"最小满足条件的值"时，用 `right = mid`（满足）和 `left = mid + 1`（不满足），循环结束时 `left == right` 即为答案。
3. **向上取整的整数实现**：`(a + b - 1) // b` 是 `ceil(a/b)` 的整数版本，在算法竞赛中常用，避免浮点精度问题。
4. **搜索范围的确定**：除数最小为 1（此时总和最大），最大为 max(nums)（此时每个 ceil 值都是 1，总和 = n <= threshold，一定满足）。

---

## 易错点

1. **二分边界**：寻找"最小满足条件的值"时，满足条件时应 `right = mid` 而非 `right = mid - 1`，否则会漏掉答案。
2. **ceil 函数的浮点问题**：`math.ceil(9 / 3)` 在某些浮点运算中可能出现问题（如 `math.ceil(2.9999999)` = 3 而非 2），使用整数公式 `(a + b - 1) // b` 更安全。
3. **搜索上界**：上界应为 `max(nums)` 而非 `sum(nums)` 或其他值，因为除数一旦等于最大元素，所有 ceil 值为 1，总和最小（等于 n）。
