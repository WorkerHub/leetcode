## 题目描述

给你三个整数 `start`、`finish` 和 `limit`，以及一个字符串 `s`。

如果一个正整数 `x` 满足以下条件，则称其为**强大整数**：
- `x` 的每一位数字都不超过 `limit`
- `x` 以字符串 `s` 结尾

返回区间 `[start, finish]` 内强大整数的个数。

**示例 1：**
```
输入：start = 1, finish = 6000, limit = 4, s = "124"
输出：5
解释：满足条件的强大整数：124, 1124, 2124, 3124, 4124
```

**示例 2：**
```
输入：start = 15, finish = 215, limit = 6, s = "10"
输出：2
解释：满足条件的强大整数：110, 210
```

**提示：**
- `1 <= start <= finish <= 10^15`
- `1 <= limit <= 9`
- `1 <= s.length <= floor(log10(finish)) + 1`
- `s` 中每位数字均不超过 `limit`

## 解题思路

数位 DP 经典模板：`count(n)` 计算 `[1, n]` 中满足条件的强大整数个数，答案 = `count(finish) - count(start - 1)`。

强大整数格式：前缀部分（每位 <= limit）+ 固定后缀 `s`。

设 `s` 的长度为 `ls`，对于长度为 `L` 的数 `x`（`L >= ls`），其后 `ls` 位固定为 `s`，前 `L - ls` 位每位在 `[0, limit]`。

数位 DP 步骤：
1. 将上界 `n` 转为字符串 `t`
2. 若 `t` 长度 < `ls`，直接返回 0
3. 枚举总长度 `L` 从 `ls` 到 `len(t)`
4. 对于每个 `L`，用 digit DP 统计满足条件的数

核心：逐位确定前缀，当前位 `< t[i]` 时后续自由选（每位 0~limit），当前位 `= t[i]` 时继续受约束。

## Python 代码实现

### 方法一：数位 DP（推荐）

```python
class Solution:
    def numberOfPowerfulInt(self, start: int, finish: int, limit: int, s: str) -> int:
        def count(n: int) -> int:
            t = str(n)
            lt, ls = len(t), len(s)
            if lt < ls:
                return 0
            # 检查后缀 s 本身是否合法（每位 <= limit）
            for c in s:
                if int(c) > limit:
                    return 0

            res = 0
            # 枚举前缀长度 pre_len = lt - ls（即总长度 = lt）
            # 也考虑总长度 < lt 的情况
            # 总长度 L 从 ls 到 lt
            for L in range(ls, lt):
                # 总长度为 L，前缀长度 pre = L - ls
                pre = L - ls
                if pre == 0:
                    # 没有前缀，数就是 s 本身（若 s 合法且 s 的值 <= n）
                    # 这里只统计长度严格小于 lt 的
                    # 长度 L < lt，一定 <= n（若无前导零问题）
                    # 但要注意 s 可能有前导零问题：s 本身作为数时
                    # 实际上 s 是整数后缀，这里数字 = s，需要 s 无前导零（第一位 != 0）
                    # 题目保证 s 是有效后缀，所以 s 本身是合法正整数
                    res += 1
                else:
                    # 前缀长度 pre，首位从 1~limit，其余从 0~limit
                    # 首位选择：1 ~ limit
                    first_choices = limit  # 1..limit，共 limit 种
                    # 其余 pre-1 位：每位 0..limit，共 (limit+1) 种
                    res += first_choices * (limit + 1) ** (pre - 1)

            # 处理总长度恰好为 lt 的情况（可能受到 t 的约束）
            pre_len = lt - ls
            suffix = t[pre_len:]  # t 的最后 ls 位

            # 先检查后缀部分是否 >= s（按字典序）
            # 若后缀 < s，则即使前缀满足约束也不算（因为整个数 < 某个值）
            # 实际上这里要精确：数的后缀固定为 s，前缀受约束
            # 数位 DP 处理前缀
            # tight 表示是否仍受 t 前 pre_len 位的约束
            if pre_len == 0:
                # 没有前缀，数就是 s，检查 s <= n
                if s <= t[lt - ls:]:  # 字典序比较（长度相同）
                    res += 1
            else:
                # 逐位处理前缀
                # 同时需要考虑后缀约束
                tight = True
                valid = True
                for i in range(pre_len):
                    lo = 1 if i == 0 else 0
                    hi = int(t[i]) if tight else limit
                    hi = min(hi, limit)

                    if lo > hi:
                        valid = False
                        break

                    # 自由选择 lo ~ hi-1 的位（后续全自由）
                    free_count = max(0, hi - lo)
                    res += free_count * (limit + 1) ** (pre_len - i - 1)

                    # 继续 tight：当前位取 t[i]
                    if int(t[i]) > limit:
                        # 当前位超过 limit，tight 路径断掉
                        valid = False
                        break
                    # 否则继续
                    tight = tight  # 保持 tight

                if valid:
                    # 前缀完全匹配 t[0..pre_len-1]，检查后缀
                    if s <= suffix:
                        res += 1

            return res

        return count(finish) - count(start - 1)
```

### 方法二：简洁数位 DP（记忆化）

```python
class Solution:
    def numberOfPowerfulInt(self, start: int, finish: int, limit: int, s: str) -> int:
        def count(n: int) -> int:
            t = str(n)
            lt, ls = len(t), len(s)
            if lt < ls:
                return 0
            # 检查后缀合法性
            if any(int(c) > limit for c in s):
                return 0

            # 数位 DP：枚举前缀
            # pre_len = lt - ls 位的前缀，受 t[0..pre_len-1] 约束
            pre_len = lt - ls

            # 统计长度 < lt 的所有满足条件的数
            res = 0
            # 长度为 ls（前缀为空）：数 = s，注意 s 要小于 n
            # 实际上长度 < lt 时，数一定 < 10^(lt-1) <= n（不严格，需具体判断）
            # 简化：枚举前缀长度 0 ~ pre_len-1
            for p in range(pre_len):
                if p == 0:
                    # 总长度 = ls，数 = int(s)，数字位数 = ls
                    # 注意 int(s) 的实际位数可能 < ls（前导零）
                    # 强大整数要求：整数本身，后缀为 s
                    # 若 p=0，则数就是 s 本身
                    # 只有当 ls < lt 时这个数才一定 < n
                    res += 1  # s 本身（若 ls < lt，则 s < 10^(lt-1) <= n/10 < n）
                else:
                    # 前缀长度为 p，首位 1~limit，其余 0~limit
                    res += limit * (limit + 1) ** (p - 1)

            # 统计总长度 = lt，前缀长度 = pre_len 的满足条件的数
            if pre_len == 0:
                # 数就是 s，检查 int(s) <= n
                if s <= str(n)[lt - ls:]:
                    res += 1
            else:
                # 逐位构建前缀，tight 约束
                tight = True
                for i in range(pre_len):
                    cur_digit = int(t[i])
                    lo = 1 if i == 0 else 0
                    upper = min(cur_digit, limit) if tight else limit

                    if lo > upper:
                        tight = False
                        break

                    # 选 lo ~ upper-1（自由部分）
                    res += max(0, upper - lo) * (limit + 1) ** (pre_len - i - 1)

                    # 继续选 cur_digit（tight）
                    if cur_digit > limit:
                        tight = False
                        break

                if tight:
                    # 后缀检查
                    suffix_in_t = t[pre_len:]
                    if s <= suffix_in_t:
                        res += 1

            return res

        return count(finish) - count(start - 1)
```

## 复杂度分析

- 时间复杂度：O(log(finish))，数位 DP 逐位处理
- 空间复杂度：O(log(finish))，存储数字字符串

## 关键点总结

1. 数位 DP：`count(n) = [1,n] 中满足条件的数个数`，答案 = `count(finish) - count(start-1)`
2. 强大整数 = 前缀（每位 <= limit）+ 固定后缀 `s`
3. 分两部分统计：总长度 < `len(str(n))` 的（完全自由）和等于 `len(str(n))` 的（受约束）
4. 后缀固定为 `s`，只需处理前缀的数位 DP
5. 注意后缀 `s` 本身每位也需 <= limit

## 易错点

1. `start - 1` 可能为 0，需确保 `count(0) = 0`
2. 后缀 `s` 本身若含有 > limit 的数字，则不存在满足条件的数
3. 前缀首位不能为 0（避免前导零）
4. 字典序比较后缀时需保证长度相同
