## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

对于数组 `nums` 的子数组 `nums[l..r]`，定义其 **不同元素计数** 为子数组中不同值的个数。

返回所有子数组的不同元素计数的 **平方和**。

**示例 1：**
```
输入：nums = [1,2,1]
输出：15
解释：
子数组 [1]: 不同元素数 1, 1^2=1
子数组 [2]: 不同元素数 1, 1^2=1
子数组 [1]: 不同元素数 1, 1^2=1
子数组 [1,2]: 不同元素数 2, 2^2=4
子数组 [2,1]: 不同元素数 2, 2^2=4
子数组 [1,2,1]: 不同元素数 2, 2^2=4
总和 = 1+1+1+4+4+4 = 15
```

**示例 2：**
```
输入：nums = [2,2]
输出：3
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

数据范围小（n <= 100），直接枚举所有子数组，对每个子数组用集合统计不同元素个数，累加平方值。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def sumCounts(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for l in range(n):
            seen = set()
            for r in range(l, n):
                seen.add(nums[r])  # 扩展子数组时增量更新
                distinct = len(seen)
                ans += distinct * distinct
        return ans
```

### 方法二：利用贡献法（进阶思路）

```python
from typing import List

class Solution:
    def sumCounts(self, nums: List[int]) -> int:
        # dist(l,r) 表示 nums[l..r] 的不同元素数
        # dist(l,r)^2 = dist(l,r) + 2 * sum_{i<j} [nums[i]!=nums[j] and i,j in [l,r] 且是首次出现对]
        # 此方法较复杂，小数据直接暴力更清晰
        n = len(nums)
        ans = 0
        for l in range(n):
            s = set()
            for r in range(l, n):
                s.add(nums[r])
                ans += len(s) ** 2
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子数组，每次 O(1) 增量更新集合
- 空间复杂度：O(n)，集合最多存 n 个不同元素

## 关键点总结

1. 增量维护集合：固定左端点 l，右端点 r 从 l 向右扩展，每次只加入一个新元素
2. `len(seen)` 即为当前子数组的不同元素个数
3. 平方和直接累加

## 易错点

1. 集合要在外层循环重置（每次固定 l 时重新初始化）
2. 包含单个元素的子数组也要统计（不同元素数为 1，贡献 1）
