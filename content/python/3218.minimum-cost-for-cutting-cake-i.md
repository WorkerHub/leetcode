## 题目描述

有一块 `m x n` 的矩形蛋糕，你需要将其切成 `1 x 1` 的小块。

每次你可以沿着一条水平线或垂直线切割当前的任意一块，成本如下：
- `horizontalCut[i]`：沿第 `i` 条水平线切割的成本（0 ≤ i < m-1）
- `verticalCut[j]`：沿第 `j` 条垂直线切割的成本（0 ≤ j < n-1）

**注意：** 多次切割同一条线的成本叠加。

返回将蛋糕切成 `1 x 1` 的**最小总成本**。

**示例 1：**
```
输入：m = 3, n = 2, horizontalCut = [1,3], verticalCut = [5]
输出：13
解释：先切 verticalCut[0]=5（成本5），再切两条水平线。
```

**示例 2：**
```
输入：m = 2, n = 2, horizontalCut = [7], verticalCut = [4]
输出：15
```

**提示：**
- `1 <= m, n <= 20`
- `horizontalCut.length == m - 1`
- `verticalCut.length == n - 1`
- `1 <= horizontalCut[i], verticalCut[j] <= 100`

## 解题思路

贪心策略：每次选择成本最高的切割先做。

当沿水平线切时，该切割会被 "当前垂直段数" 计入（因为每个垂直段都要切一次）。同理，垂直切割被 "当前水平段数" 计入。

贪心：优先做成本高的切割，此时所需乘数（段数）最小（等于1或初始段数），可以最小化总成本。

使用两个指针，分别指向水平和垂直切割列表（降序排序），每次选更大的切割执行。

## Python 代码实现

### 方法一：贪心合并排序（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, m: int, n: int, horizontalCut: List[int], verticalCut: List[int]) -> int:
        # 降序排序
        horizontalCut.sort(reverse=True)
        verticalCut.sort(reverse=True)
        
        h_segs = 1  # 当前水平段数
        v_segs = 1  # 当前垂直段数
        
        cost = 0
        i, j = 0, 0
        
        while i < len(horizontalCut) or j < len(verticalCut):
            # 选择成本更高的切割
            h_val = horizontalCut[i] if i < len(horizontalCut) else -1
            v_val = verticalCut[j] if j < len(verticalCut) else -1
            
            if h_val >= v_val:
                # 水平切割，成本乘以当前垂直段数
                cost += h_val * v_segs
                h_segs += 1
                i += 1
            else:
                # 垂直切割，成本乘以当前水平段数
                cost += v_val * h_segs
                v_segs += 1
                j += 1
        
        return cost
```

### 方法二：暴力 DP（适合小数据）

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumCost(self, m: int, n: int, horizontalCut: List[int], verticalCut: List[int]) -> int:
        @lru_cache(maxsize=None)
        def dp(r1, c1, r2, c2):
            # 切割 (r1,c1) 到 (r2,c2) 的最小成本
            if r2 - r1 == 1 and c2 - c1 == 1:
                return 0
            ans = float('inf')
            # 水平切割
            for r in range(r1 + 1, r2):
                cost = horizontalCut[r - 1] + dp(r1, c1, r, c2) + dp(r, c1, r2, c2)
                ans = min(ans, cost)
            # 垂直切割
            for c in range(c1 + 1, c2):
                cost = verticalCut[c - 1] + dp(r1, c1, r2, c) + dp(r1, c, r2, c2)
                ans = min(ans, cost)
            return ans
        
        return dp(0, 0, m, n)
```

## 复杂度分析

- 方法一（贪心）：时间复杂度 O((m + n) log(m + n))，空间复杂度 O(1)
- 方法二（DP）：时间复杂度 O(m^2 n^2 (m + n))，仅适合小数据

## 关键点总结

1. 贪心：优先做成本高的切割，此时乘数（已有的段数）还小
2. 每次水平切割的实际成本 = 切割值 * 当前垂直段数
3. 维护水平段数和垂直段数，每次切割后对应段数加 1

## 易错点

1. 切割成本要乘以当前另一个方向的段数
2. 当两个方向成本相同时，选哪个都可以（总成本相同）
