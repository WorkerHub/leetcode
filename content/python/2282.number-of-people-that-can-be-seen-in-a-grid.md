## 题目描述

给你一个 `m x n` 的整数矩阵 `heights`，每个格子代表一个人的身高。

一行/列中，位置 `j` 的人能看到位置 `k`（`j < k`）的人，当且仅当 `j` 和 `k` 之间没有任何人身高 **严格大于** `min(heights[j], heights[k])`。

返回一个 `m x n` 的矩阵 `answer`，`answer[i][j]` 是第 `i` 行第 `j` 列的人在其所在**行**和**列**中能看到的人数总和。

## 解题思路

**单调栈：**

对每一行和每一列分别处理。

对于一行从左到右，用单调递减栈：
- 当当前元素弹出栈顶时，栈顶能看到当前元素（被弹出者是当前元素左边第一个不被遮挡的）。
- 此外，若栈中还有元素（栈顶的前一个），则那个元素也能看到被弹出者（因为被弹出者没有被遮挡）。

具体：维护单调不增栈，对每对相邻可见的人，双向计数 +1。

## 代码实现

### 方法一：单调栈逐行逐列处理（推荐）

```python
from typing import List

class Solution:
    def seePeople(self, heights: List[List[int]]) -> List[List[int]]:
        m, n = len(heights), len(heights[0])
        ans = [[0] * n for _ in range(m)]

        def count_visible(arr):
            """对一维数组用单调栈统计每个位置能看到的人数"""
            result = [0] * len(arr)
            stack = []  # 单调递减栈（存高度）
            for i, h in enumerate(arr):
                # 弹出所有小于当前高度的元素
                while stack and stack[-1][1] <= h:
                    idx, val = stack.pop()
                    # idx 能看到 i，i 能看到 idx
                    result[idx] += 1
                    result[i] += 1
                    # 若弹出的两个相邻相等，只计一次
                    if stack and val == stack[-1][1]:
                        result[i] -= 1  # 不重复计
                # 若栈非空，当前高度能看到栈顶（不被挡）
                # 注意：上面已经对弹出的元素计数了
                stack.append((i, h))
            return result

        # 处理每一行
        for i in range(m):
            row_result = count_visible(heights[i])
            for j in range(n):
                ans[i][j] += row_result[j]

        # 处理每一列
        for j in range(n):
            col = [heights[i][j] for i in range(m)]
            col_result = count_visible(col)
            for i in range(m):
                ans[i][j] += col_result[i]

        return ans
```

### 方法二：标准单调栈（更清晰）

```python
from typing import List

class Solution:
    def seePeople(self, heights: List[List[int]]) -> List[List[int]]:
        m, n = len(heights), len(heights[0])
        ans = [[0] * n for _ in range(m)]

        def process(arr, out):
            """单调递减栈处理一维数组可见性"""
            stack = []  # (height, index)
            for i, h in enumerate(arr):
                while stack:
                    top_h, top_i = stack[-1]
                    if top_h <= h:
                        stack.pop()
                        out[top_i] += 1  # top_i 能看到 i
                        out[i] += 1      # i 能看到 top_i
                        # 若下一个栈顶与被弹出的等高，避免 i 重复计数
                        if stack and stack[-1][0] == top_h:
                            out[i] -= 1
                    else:
                        # 栈顶更高，i 能看到栈顶，但栈顶不能看到 i（被遮挡）
                        out[i] += 1
                        break
                stack.append((h, i))

        # 处理行
        for i in range(m):
            row_out = [0] * n
            process(heights[i], row_out)
            for j in range(n):
                ans[i][j] += row_out[j]

        # 处理列
        for j in range(n):
            col = [heights[i][j] for i in range(m)]
            col_out = [0] * m
            process(col, col_out)
            for i in range(m):
                ans[i][j] += col_out[i]

        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)，每行每列各遍历一次。
- 空间复杂度：O(max(m, n))，栈空间。

## 关键点总结

1. 行和列独立处理，结果相加。
2. 单调递减栈：弹出时说明左侧元素能看到当前元素。
3. 等高处理：两个相邻等高元素互相可见，但不应重复计数。

## 易错点

- 等高元素的处理：`a, b, c` 中若 `b == c`，a 只能看到 b（被 b 挡住看不到 c）。
- 单调栈需考虑弹出后栈顶与被弹出值相等的特殊情况。
