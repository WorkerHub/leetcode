## 题目描述

给你一个整数数组 `nums` 和两个整数 `start` 和 `target`，从 `start` 出发，每步可以：
1. 将当前值加上 `nums[i]`（i 可以是任意下标）
2. 将当前值减去 `nums[i]`

返回到达 `target` 所需的最少步数。

**示例 1：**

```
输入：nums = [1, 2, 3], start = 0, target = 4
输出：2
解释：0 -> 1 -> 4（加 1 再加 3），2 步。
```

**示例 2：**

```
输入：nums = [1, 5, 9], start = 3, target = -7
输出：2
解释：3 -> -2 -> -7（减 5 再减 5），2 步。
```

**提示：**
- `1 <= nums.length <= 1000`
- `-1000 <= nums[i] <= 1000`
- `-1000 <= start, target <= 1000`

## 解题思路

BFS 从 `start` 出发，每步可以加或减 `nums` 中任意元素，找到 `target` 的最短路径。

值域有限（约 [-2000, 2000]），用哈希集合记录访问过的值。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minSteps(self, nums: List[int], start: int, target: int) -> int:
        if start == target:
            return 0

        visited = {start}
        queue = deque([start])
        steps = 0

        while queue:
            steps += 1
            for _ in range(len(queue)):
                curr = queue.popleft()
                for v in nums:
                    for next_val in [curr + v, curr - v]:
                        if next_val == target:
                            return steps
                        if next_val not in visited:
                            visited.add(next_val)
                            queue.append(next_val)

        return -1  # 不可达
```

### 方法二：双向 BFS（优化）

```python
from typing import List

class Solution:
    def minSteps(self, nums: List[int], start: int, target: int) -> int:
        if start == target:
            return 0

        front = {start}
        back = {target}
        visited_front = {start}
        visited_back = {target}
        steps = 0

        while front and back:
            steps += 1
            # 扩展较小的集合
            if len(front) > len(back):
                front, back = back, front
                visited_front, visited_back = visited_back, visited_front

            new_front = set()
            for curr in front:
                for v in nums:
                    for nxt in [curr + v, curr - v]:
                        if nxt in back:
                            return steps
                        if nxt not in visited_front:
                            visited_front.add(nxt)
                            new_front.add(nxt)
            front = new_front

        return -1
```

## 复杂度分析

- 时间复杂度：O(R * n)，R 为值域大小，n 为 nums 长度
- 空间复杂度：O(R)，已访问集合

## 关键点总结

1. BFS 保证最少步数，每步可以选任意 nums[i] 加或减。
2. 值域有限，可以用哈希集合记录已访问避免重复。
3. 双向 BFS 可以将搜索空间从 O(b^d) 降到 O(b^(d/2))。

## 易错点

1. 每步可以重复使用同一个 nums[i]（若允许重复使用）。
2. 负值也可以到达，不要限制值域为正数。
