## 题目描述

设计一个路由器数据结构，支持以下操作：
- `Router(int memoryLimit)`：初始化路由器，内存限制为 `memoryLimit` 个数据包
- `bool addPacket(int source, int destination, int timestamp)`：添加数据包。若与已有重复（source, destination, timestamp 完全相同）则返回 `false`，否则添加并返回 `true`。若内存已满，移除最早的数据包
- `int[] forwardPacket()`：转发最早的数据包，返回 `[source, destination, timestamp]`；若无数据包返回空数组
- `int getCount(int destination, int startTime, int endTime)`：返回目的地为 `destination`、时间戳在 `[startTime, endTime]` 范围内的数据包数量

**示例：**

```
输入：["Router", "addPacket", "addPacket", "addPacket", "forwardPacket", "getCount"]
     [[3], [1,4,90], [2,5,90], [3,5,95], [], [5,89,99]]
输出：[null, true, true, true, [1,4,90], 2]
```

**提示：**
- `1 <= memoryLimit <= 10^5`
- 操作总次数 <= 10^5

## 解题思路

使用以下数据结构组合：
1. **双端队列（deque）**：维护数据包的插入顺序，支持 O(1) 的最早数据包查询和移除
2. **哈希集合**：记录所有已有数据包的 `(source, destination, timestamp)`，O(1) 判断重复
3. **哈希表 + 有序列表**：对每个 `destination` 维护时间戳的有序列表，支持 `getCount` 的二分查找

## Python 代码实现

### 方法一：deque + 哈希表 + 有序列表（推荐）

```python
from collections import deque, defaultdict
from bisect import bisect_left, bisect_right, insort

class Router:
    def __init__(self, memoryLimit: int):
        self.limit = memoryLimit
        self.queue = deque()  # 存储 (source, dest, ts) 按插入顺序
        self.seen = set()     # 去重集合
        self.dest_ts = defaultdict(list)  # destination -> 有序时间戳列表

    def addPacket(self, source: int, destination: int, timestamp: int) -> bool:
        key = (source, destination, timestamp)
        if key in self.seen:
            return False
        # 若内存已满，移除最早的数据包
        if len(self.queue) >= self.limit:
            old = self.queue.popleft()
            self.seen.discard(old)
            # 从 dest_ts 中移除
            old_dest, old_ts = old[1], old[2]
            idx = bisect_left(self.dest_ts[old_dest], old_ts)
            if idx < len(self.dest_ts[old_dest]) and self.dest_ts[old_dest][idx] == old_ts:
                self.dest_ts[old_dest].pop(idx)

        self.queue.append(key)
        self.seen.add(key)
        insort(self.dest_ts[destination], timestamp)
        return True

    def forwardPacket(self) -> list:
        if not self.queue:
            return []
        pkt = self.queue.popleft()
        self.seen.discard(pkt)
        # 从 dest_ts 中移除
        dest, ts = pkt[1], pkt[2]
        idx = bisect_left(self.dest_ts[dest], ts)
        if idx < len(self.dest_ts[dest]) and self.dest_ts[dest][idx] == ts:
            self.dest_ts[dest].pop(idx)
        return list(pkt)

    def getCount(self, destination: int, startTime: int, endTime: int) -> int:
        ts_list = self.dest_ts[destination]
        left = bisect_left(ts_list, startTime)
        right = bisect_right(ts_list, endTime)
        return right - left
```

### 方法二：简化版（适合小数据）

```python
from collections import deque

class Router:
    def __init__(self, memoryLimit: int):
        self.limit = memoryLimit
        self.packets = deque()
        self.seen = set()

    def addPacket(self, source: int, destination: int, timestamp: int) -> bool:
        key = (source, destination, timestamp)
        if key in self.seen:
            return False
        if len(self.packets) >= self.limit:
            removed = self.packets.popleft()
            self.seen.discard(removed)
        self.packets.append(key)
        self.seen.add(key)
        return True

    def forwardPacket(self) -> list:
        if not self.packets:
            return []
        pkt = self.packets.popleft()
        self.seen.discard(pkt)
        return list(pkt)

    def getCount(self, destination: int, startTime: int, endTime: int) -> int:
        # O(n) 线性扫描
        return sum(
            1 for s, d, t in self.packets
            if d == destination and startTime <= t <= endTime
        )
```

## 复杂度分析

- `addPacket`：O(log n)（方法一，有序插入），O(1)（方法二）
- `forwardPacket`：O(log n)（方法一），O(1)（方法二）
- `getCount`：O(log n)（方法一，二分），O(n)（方法二）
- 空间复杂度：O(memoryLimit)

## 关键点总结

1. 双端队列维护先进先出的顺序
2. 哈希集合实现 O(1) 去重
3. 对每个 destination 维护有序时间戳列表，实现高效区间计数
4. `bisect` 模块实现二分查找区间计数

## 易错点

1. 移除过期数据包时，要同时从 `seen`、`queue`、`dest_ts` 三处删除
2. `dest_ts` 中可能有重复时间戳（同一 destination 不同 source）
3. `forwardPacket` 也需要从 `dest_ts` 中移除对应时间戳
