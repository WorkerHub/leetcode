## 题目描述

给你一个下标从 0 开始的数组 `points`，它表示二维平面上一些点的整数坐标，其中 `points[i] = [xi, yi]`。

两点之间的距离定义为它们的曼哈顿距离。

返回点对中 **最大** 曼哈顿距离的 **最小** 可能值，需要从数组中恰好移除一个点。

**示例 1：**
```
输入：points = [[3,10],[5,15],[10,2],[4,4]]
输出：12
解释：移除点 [5,15] 后，最大曼哈顿距离为 12。
```

**示例 2：**
```
输入：points = [[1,1],[1,1],[1,1]]
输出：0
```

**提示：**
- `3 <= points.length <= 10^5`
- `1 <= points[i].length == 2`
- `1 <= xi, yi <= 10^8`

## 解题思路

曼哈顿距离 |x1-x2| + |y1-y2| 可以转化为切比雪夫距离：令 u = x+y，v = x-y，则曼哈顿距离 = max(|u1-u2|, |v1-v2|)。

最大曼哈顿距离 = max(max(u) - min(u), max(v) - min(v))。

因此，最大距离由 u 的最大最小值或 v 的最大最小值决定。只需枚举移除 u 最大/最小值点或 v 最大/最小值点，共 4 种情况，取最小结果。

## Python 代码实现

### 方法一：枚举边界点（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minimumDistance(self, points: List[List[int]]) -> int:
        # 转化为 u = x+y, v = x-y
        us = SortedList(x + y for x, y in points)
        vs = SortedList(x - y for x, y in points)

        ans = float('inf')
        for x, y in points:
            u = x + y
            v = x - y
            # 临时移除当前点
            us.remove(u)
            vs.remove(v)
            # 计算最大曼哈顿距离
            dist = max(us[-1] - us[0], vs[-1] - vs[0])
            ans = min(ans, dist)
            # 恢复
            us.add(u)
            vs.add(v)
        return ans
```

### 方法二：只枚举 4 个极值点

```python
from typing import List

class Solution:
    def minimumDistance(self, points: List[List[int]]) -> int:
        def max_dist_without(skip: int) -> int:
            # 计算去掉 skip 号点后的最大曼哈顿距离
            min_u = min_v = float('inf')
            max_u = max_v = float('-inf')
            for i, (x, y) in enumerate(points):
                if i == skip:
                    continue
                u, v = x + y, x - y
                min_u = min(min_u, u)
                max_u = max(max_u, u)
                min_v = min(min_v, v)
                max_v = max(max_v, v)
            return max(max_u - min_u, max_v - min_v)

        # 找出决定最大距离的 4 个极值点的索引
        min_u_i = min(range(len(points)), key=lambda i: points[i][0] + points[i][1])
        max_u_i = max(range(len(points)), key=lambda i: points[i][0] + points[i][1])
        min_v_i = min(range(len(points)), key=lambda i: points[i][0] - points[i][1])
        max_v_i = max(range(len(points)), key=lambda i: points[i][0] - points[i][1])

        return min(max_dist_without(i) for i in {min_u_i, max_u_i, min_v_i, max_v_i})
```

## 复杂度分析

- 时间复杂度：O(n)，只枚举 4 个候选点，每次计算最大距离 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 曼哈顿距离可通过坐标旋转 45 度转化为切比雪夫距离
2. 最大曼哈顿距离由 u=x+y 或 v=x-y 的极差决定
3. 只需枚举移除 4 个极值点的情况

## 易错点

1. 转化后的最大距离是 max(u极差, v极差) 而非 u极差 + v极差
2. 枚举时需要覆盖所有 4 个极值点
