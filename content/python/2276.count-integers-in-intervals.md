## 题目描述

实现 `CountIntervals` 类：

- `CountIntervals()`：初始化对象。
- `add(left, right)`：将区间 `[left, right]` 添加到集合中。
- `count()`：返回集合中所有区间**合并后**覆盖的整数总数。

**示例：**
```
输入：
["CountIntervals", "add", "add", "count", "add", "count"]
[[], [2, 3], [7, 10], [], [5, 8], []]
输出：[null, null, null, 6, null, 8]
```

## 解题思路

**有序集合维护不重叠区间：**

维护一个有序的区间集合（按左端点排序），每次 `add` 时：
1. 找到所有与新区间 `[l, r]` 重叠的已有区间。
2. 将它们合并为一个大区间。
3. 同时维护当前覆盖的总整数数。

用 Python 的 `SortedList`（sortedcontainers 库）或用有序字典模拟。

## 代码实现

### 方法一：有序列表维护区间（推荐）

```python
from sortedcontainers import SortedList

class CountIntervals:
    def __init__(self):
        # 存储 (left, right) 区间，按 left 排序
        self.intervals = SortedList(key=lambda x: x[0])
        self.total = 0  # 当前覆盖的总整数数

    def add(self, left: int, right: int) -> None:
        new_left, new_right = left, right

        # 找到所有与 [left, right] 重叠的区间
        # 重叠条件：existing.left <= new_right AND existing.right >= new_left
        to_remove = []

        # 用二分找可能重叠的区间
        pos = self.intervals.bisect_left((left,))
        # 往前检查一个（前一个区间可能右端延伸到当前左端）
        for i in range(max(0, pos - 1), len(self.intervals)):
            il, ir = self.intervals[i]
            if il > new_right:  # 后续区间都不重叠
                break
            if ir >= new_left:  # 重叠
                new_left = min(new_left, il)
                new_right = max(new_right, ir)
                to_remove.append((il, ir))

        for interval in to_remove:
            self.total -= interval[1] - interval[0] + 1
            self.intervals.remove(interval)

        self.intervals.add((new_left, new_right))
        self.total += new_right - new_left + 1

    def count(self) -> int:
        return self.total
```

### 方法二：使用内置有序字典（不依赖外部库）

```python
import bisect

class CountIntervals:
    def __init__(self):
        self.lefts = []   # 区间左端点列表（有序）
        self.rights = []  # 对应右端点
        self.total = 0

    def add(self, left: int, right: int) -> None:
        # 找与 [left, right] 重叠的区间
        # 右端点 >= left 的第一个区间
        lo = bisect.bisect_left(self.rights, left)
        # 左端点 <= right 的最后一个区间
        hi = bisect.bisect_right(self.lefts, right)

        if lo < hi:
            # 有重叠区间，合并
            left = min(left, self.lefts[lo])
            right = max(right, self.rights[hi - 1])
            # 减去被合并区间的计数
            for i in range(lo, hi):
                self.total -= self.rights[i] - self.lefts[i] + 1
            # 删除 [lo, hi) 的区间
            del self.lefts[lo:hi]
            del self.rights[lo:hi]

        # 插入新区间
        bisect.insort(self.lefts, left)
        idx = bisect.bisect_left(self.lefts, left)
        self.rights.insert(idx, right)
        self.total += right - left + 1

    def count(self) -> int:
        return self.total
```

## 复杂度分析

- add：O(k log n + k)，k 为被合并的区间数（均摊 O(log n)）。
- count：O(1)。

## 关键点总结

1. 维护不重叠区间集合，每次 `add` 合并重叠区间。
2. 用有序集合/有序列表高效查找重叠区间。
3. 实时维护总覆盖数 `total`，`count()` O(1) 返回。

## 易错点

- 合并时需考虑前一个区间（其右端可能与新区间左端重叠）。
- 及时更新 `total`：删除被合并区间的贡献，加上新合并区间的贡献。
