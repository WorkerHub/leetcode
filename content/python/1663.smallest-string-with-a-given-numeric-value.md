## 题目描述

**小写字母的数值**是指字母在字母表中的位置（`a -> 1`，`b -> 2`，...，`z -> 26`）。

**字符串的数值**是该字符串中字符数值之和。

给你两个整数 `n` 和 `k`，返回**长度为 `n`**、**数值等于 `k`** 的字典序最小的字符串。

**示例：**
```
输入：n = 3, k = 27
输出："aay"（1+1+25=27）

输入：n = 5, k = 73
输出："aaszz"
```

## 解题思路

**贪心（从后往前）：**
- 尽量让前面的字符小（字典序最小），让后面的字符大
- 从最后一个位置开始，尽量使用最大值（'z' = 26），直到满足总和要求

具体来说：从右往左确定每个字符：
- 当前字符值 = `min(26, k - (n - 1) * 1)`（至少留给前面每个字符值 1）
- 减去当前字符值后更新 k，n 减 1

## 代码实现

### 方法一：贪心从后往前（推荐）

```python
class Solution:
    def getSmallestString(self, n: int, k: int) -> str:
        result = []
        
        for i in range(n - 1, -1, -1):
            # 前 i 个位置各至少用 1（值为 'a'）
            # 当前位置的最大值 = min(26, k - i)
            val = min(26, k - i)
            result.append(chr(ord('a') + val - 1))
            k -= val
        
        return ''.join(reversed(result))
```

### 方法二：从前往后（逆向思维）

```python
class Solution:
    def getSmallestString(self, n: int, k: int) -> str:
        result = ['a'] * n
        k -= n  # 每个位置已经贡献了 'a'=1，k 减去 n
        
        # 从后往前，尽量用 'z'
        for i in range(n - 1, -1, -1):
            if k <= 0:
                break
            add = min(25, k)  # 最多加 25（从 'a'=1 到 'z'=26，加 25）
            result[i] = chr(ord('a') + add)
            k -= add
        
        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(n) |

## 关键点总结

1. 字典序最小：前面的字符尽量小（尽量是 'a'），后面的字符才大
2. 贪心：从后往前，每个位置取 `min(26, k - 前面位置数)`
3. 前面每个位置至少值为 1（'a'），所以当前位置最大 = `k - (剩余位置数)`

## 易错点

- 从后往前贪心，前面留的最小值是 1（每位至少 'a'）
- 字符值从 1 开始（a=1），不是从 0 开始
- 返回时反转结果数组（从后向前构建的）
