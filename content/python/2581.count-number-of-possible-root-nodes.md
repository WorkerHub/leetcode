## 题目描述

Alice 有一棵 `n` 个节点的无根树，节点编号 0 到 n-1。给你若干猜测，每个猜测 `guesses[i] = [u, v]` 表示"节点 u 是节点 v 的父节点"。

Alice 随机选择一个根节点。若对于某个根的选择，至少有 `k` 个猜测是正确的，则这个根是"可能的根节点"。

返回可能的根节点的数目。

**示例 1：**

```
输入：edges = [[0,1],[1,2],[1,3],[4,2]], guesses = [[1,3],[0,1],[1,0],[2,4]], k = 3
输出：3
```

**提示：**

- `n == edges.length + 1`
- `2 <= n <= 10^5`

## 解题思路

**换根 DP**：

1. 先以节点 0 为根，统计 guesses 中正确的猜测数 base
2. 将 guesses 存入集合，格式为 `(parent, child)`
3. 换根 DFS：当从父节点 p 换到子节点 c 时：
   - (p, c) 变为不合法（原来 p 是 c 的父，现在不是了），若 (p, c) 在 guesses 中，count -= 1
   - (c, p) 变为合法（现在 c 是 p 的父），若 (c, p) 在 guesses 中，count += 1

## Python 代码实现

### 方法一：换根 DP（推荐）

```python
from typing import List
from collections import defaultdict
import sys
sys.setrecursionlimit(200000)

class Solution:
    def rootCount(self, edges: List[List[int]], guesses: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        guess_set = set(map(tuple, guesses))

        # 第一次 DFS：以 0 为根，计算 base_count
        base_count = 0

        def dfs1(node, parent):
            nonlocal base_count
            for child in graph[node]:
                if child != parent:
                    if (node, child) in guess_set:
                        base_count += 1
                    dfs1(child, node)

        dfs1(0, -1)

        # 第二次 DFS：换根，统计以每个节点为根的正确猜测数
        ans = 0
        count = [0] * n
        count[0] = base_count

        def dfs2(node, parent, cur_count):
            nonlocal ans
            if cur_count >= k:
                ans += 1
            for child in graph[node]:
                if child != parent:
                    new_count = cur_count
                    if (node, child) in guess_set:
                        new_count -= 1
                    if (child, node) in guess_set:
                        new_count += 1
                    dfs2(child, node, new_count)

        dfs2(0, -1, base_count)
        return ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def rootCount(self, edges: List[List[int]], guesses: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        guess_set = set(map(tuple, guesses))

        # 迭代 DFS 计算以 0 为根的正确猜测数
        root = 0
        parent = [-1] * n
        order = []
        stack = [root]
        visited = [False] * n
        visited[root] = True

        while stack:
            node = stack.pop()
            order.append(node)
            for nb in graph[node]:
                if not visited[nb]:
                    visited[nb] = True
                    parent[nb] = node
                    stack.append(nb)

        # 计算 base_count（以 0 为根）
        base_count = sum(1 for node in order if parent[node] != -1 and (parent[node], node) in guess_set)

        # 换根
        cnt = [0] * n
        cnt[root] = base_count
        ans = 0

        for node in order:
            if cnt[node] >= k:
                ans += 1
            for child in graph[node]:
                if child != parent[node]:
                    new_cnt = cnt[node]
                    if (node, child) in guess_set:
                        new_cnt -= 1
                    if (child, node) in guess_set:
                        new_cnt += 1
                    cnt[child] = new_cnt

        return ans
```

## 复杂度分析

- 时间复杂度：O(n + |guesses|)，两次 DFS
- 空间复杂度：O(n + |guesses|)

## 关键点总结

1. 换根时，父子关系改变：原 (p, c) 变无效，新 (c, p) 可能有效
2. 用 guesses 集合实现 O(1) 查询
3. 两次 DFS：第一次计算基准，第二次换根统计

## 易错点

1. 换根时只影响直接父子关系的 guesses
2. 迭代 DFS 比递归更安全，避免大树时栈溢出
3. n 可以到 10^5，递归深度可能超限
