## 题目描述

给你一个整数数组 `arr`，请你检查是否存在两个整数 `N` 和 `M`，满足 `N` 是 `M` 的两倍（即，`N = 2 * M`）。

更正式地，检查是否存在两个下标 `i` 和 `j` 满足：
- `i != j`
- `0 <= i, j < arr.length`
- `arr[i] == 2 * arr[j]`

**示例 1：**
```
输入：arr = [10,2,5,3]
输出：true
解释：N = 10，M = 5（10 = 2 * 5）
```

**示例 2：**
```
输入：arr = [7,1,14,11]
输出：true
解释：N = 14，M = 7（14 = 2 * 7）
```

**示例 3：**
```
输入：arr = [3,1,7,11]
输出：false
解释：在该数组中不存在满足条件的两个元素。
```

**提示：**
- `2 <= arr.length <= 500`
- `-10^3 <= arr[i] <= 10^3`

## 解题思路

**方法一（哈希集合）：**

遍历数组，对每个元素 `x`：
- 检查 `2 * x` 是否在已见集合中（`x` 是 M，`2x` 是 N）
- 检查 `x / 2`（`x` 是偶数时）是否在已见集合中（`x` 是 N，`x/2` 是 M）

或者，可以先将所有元素放入集合，然后对每个元素 `x` 检查 `2*x` 是否也在集合中（注意 0 的特殊情况）。

**方法二（排序 + 双指针）：**

排序后用两个指针，一个指向可能的 M（小的），一个指向可能的 N（大的）。

**方法三（排序 + 二分查找）：**

排序后对每个元素 `x` 二分查找 `2*x`。

## Python 代码实现

### 方法一：哈希集合一次遍历（推荐）

```python
from typing import List

class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        seen = set()
        
        for x in arr:
            # 检查 2*x 是否在 seen 中（x 作为 M，2x 作为 N）
            # 检查 x/2 是否在 seen 中（x 作为 N，x/2 作为 M）
            if 2 * x in seen or (x % 2 == 0 and x // 2 in seen):
                return True
            seen.add(x)
        
        return False
```

### 方法二：哈希集合预处理（两次遍历）

```python
from typing import List

class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        seen = set(arr)
        
        for x in arr:
            # 检查 2*x 是否在数组中
            if 2 * x in seen:
                # 特殊处理 x=0：0*2=0，需要确保数组中有两个0
                if x == 0:
                    if arr.count(0) >= 2:
                        return True
                else:
                    return True
        
        return False
```

### 方法三：排序 + 双指针

```python
from typing import List

class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        arr.sort()
        n = len(arr)
        
        # 使用双指针：i 指向较小的元素（M），j 从 i+1 开始找 2*M
        for i in range(n):
            # 在 arr[i+1:] 中找 2 * arr[i]
            target = 2 * arr[i]
            lo, hi = i + 1, n - 1
            while lo <= hi:
                mid = (lo + hi) // 2
                if arr[mid] == target:
                    return True
                elif arr[mid] < target:
                    lo = mid + 1
                else:
                    hi = mid - 1
        
        return False
```

### 方法四：排序 + 二分查找（使用 bisect）

```python
from typing import List
import bisect

class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        arr.sort()
        n = len(arr)
        
        for i, x in enumerate(arr):
            target = 2 * x
            # 在整个数组中查找 target
            pos = bisect.bisect_left(arr, target)
            # 确认找到且不是自身
            if pos < n and arr[pos] == target and pos != i:
                return True
        
        return False
```

### 方法五：暴力双重循环（最直观）

```python
from typing import List

class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        n = len(arr)
        for i in range(n):
            for j in range(n):
                if i != j and arr[i] == 2 * arr[j]:
                    return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（哈希集合） | O(n) | O(n) |
| 方法二（哈希预处理） | O(n) | O(n) |
| 方法三/四（排序+二分） | O(n log n) | O(1)* |
| 方法五（暴力） | O(n^2) | O(1) |

*排序本身需要 O(n) 空间（Python 的 timsort），但通常认为是 O(log n) 辅助空间。

## 关键点总结

1. 方法一的哈希集合遍历最高效：一次遍历，每次检查 `2*x` 和 `x//2`
2. 特殊情况：`x = 0` 时，`2*0 = 0`，需要数组中有两个 0 才成立
3. 方法一的一次遍历天然避免了 `i == j` 的问题（`seen` 中只有比当前元素早的元素）

## 易错点

1. `x = 0` 的特殊情况：`2 * 0 = 0`，如果用集合预处理，`0` 在集合中只有一个，会错误返回 `True`
2. 方法一中使用一次遍历可以避免 `i == j` 的问题
3. 不能直接 `x % 2 == 0 and x / 2 in seen`，因为 Python 3 的 `/` 是浮点除法，应使用 `x // 2`

## 图解示例

seen = {}
