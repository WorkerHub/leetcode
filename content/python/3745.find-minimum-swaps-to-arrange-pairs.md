## 题目描述

给定 `2n` 个元素，这些元素构成 `n` 个配对（每对由两个值相同的元素组成）。将它们排成一排（偶数下标 0,2,4,...,2n-2 和对应的奇数下标 1,3,5,...,2n-1 分别为一对），求使每对相邻的最少交换次数。

**示例 1：**
```
输入：nums = [3,2,1,2,3,1]
输出：2
解释：目标：每个偶数位和下一个位置的元素相同。
     nums = [3,2,1,2,3,1] -> 交换 nums[1] 和 nums[4]：[3,3,1,2,2,1] -> 交换 nums[3] 和 nums[5]：[3,3,1,1,2,2]，共 2 次。
```

**示例 2：**
```
输入：nums = [1,2,1,2]
输出：1
```

**提示：**
- `1 <= n <= 10^5`
- `2 * n == nums.length`
- 每个值恰好出现两次

## 解题思路

图论 + 环分解。

将每对元素看作一条边，构建一个图：
- 节点 `i` 表示下标 `2i` 的元素
- 节点 `j` 表示下标 `2j` 的元素
- 若 `nums[2i]` 和 `nums[2j]` 应该配对（即值相同），但当前 `2i` 的配对是 `2i+1`（即 `nums[2i+1]`），则形成一条置换边。

置换的最少交换数 = n - 置换中的环数。

## Python 代码实现

### 方法一：置换环分解（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums) // 2

        # 找到每个值的两个位置
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)

        # 构建置换：当前位置 i（偶数），其配对应为 i+1（奇数）
        # 若 nums[i] != nums[i+1]，则需要交换
        # 利用 Union-Find 或环检测

        # 贪心：模拟交换过程
        nums = list(nums)
        swaps = 0
        for i in range(0, len(nums), 2):
            if nums[i] == nums[i + 1]:
                continue
            # 找到与 nums[i] 相同的另一个元素（在 i+1 之后）
            target = nums[i]
            for j in range(i + 2, len(nums)):
                if nums[j] == target:
                    # 将 nums[j] 移到 i+1 处
                    # 实际是将 nums[i+1] 与 nums[j] 交换
                    nums[i + 1], nums[j] = nums[j], nums[i + 1]
                    swaps += 1
                    break

        return swaps
```

### 方法二：更简洁的贪心

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        nums = list(nums)
        n = len(nums)
        swaps = 0

        for i in range(0, n, 2):
            if nums[i] != nums[i + 1]:
                # 在 i+2 之后找与 nums[i] 相同的元素
                j = i + 2
                while j < n and nums[j] != nums[i]:
                    j += 1
                # 检查是否在 j+1 找到配对更优
                # 将找到的元素换到 i+1
                nums[i + 1], nums[j] = nums[j], nums[i + 1]
                swaps += 1

        return swaps
```

## 复杂度分析

- 时间复杂度：O(n^2) 最坏情况（每次线性查找）；可用哈希表优化到 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：遍历每对位置，若当前对不匹配则找到配对元素换过来
2. 每次交换使当前位置正确匹配，不影响之前已处理的对
3. 换回最近的配对元素最优

## 易错点

1. 注意修改的是数组副本，不影响原数组
2. 查找配对元素时从 `i+2` 开始（跳过已处理的对）
