## 题目描述

给你一个整数 `n`（0 到 n-1 的节点）和一个有权无向图（边用 `roads` 给出，`roads[i] = [u, v, w]`），以及一个整数 `maxDistance`。

你需要选择一些节点关闭（其余节点为"开放"节点），使得所有开放节点之间的最短路距离都不超过 `maxDistance`。

返回满足条件的节点关闭选择方案数（即开放节点的子集数）。

**示例 1：**
```
输入：n = 3, maxDistance = 5, roads = [[0,1,2],[1,2,3],[2,0,4]]
输出：7
```

**提示：**
- `1 <= n <= 10`
- `1 <= roads.length <= 1000`
- `0 <= roads[i][0], roads[i][1] <= n-1`
- `0 <= roads[i][2] <= 1000`
- `1 <= maxDistance <= 10^5`

## 解题思路

n <= 10，枚举所有 2^n 个子集（表示开放节点集合）。

对每个子集，运行 Floyd-Warshall 或 Dijkstra 计算开放节点之间的最短路，检查是否所有开放节点对的最短路 <= maxDistance。

## Python 代码实现

### 方法一：枚举子集 + Floyd-Warshall（推荐）

```python
from typing import List

class Solution:
    def numberOfSets(self, n: int, maxDistance: int, roads: List[List[int]]) -> int:
        # 构建邻接矩阵
        INF = float('inf')
        dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            dist[i][i] = 0
        for u, v, w in roads:
            dist[u][v] = min(dist[u][v], w)
            dist[v][u] = min(dist[v][u], w)

        # Floyd-Warshall（全图最短路）
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        ans = 0
        # 枚举所有子集（开放节点集合）
        for mask in range(1 << n):
            nodes = [i for i in range(n) if (mask >> i) & 1]
            # 检查所有开放节点对之间的最短路
            valid = True
            for i in range(len(nodes)):
                for j in range(i + 1, len(nodes)):
                    if dist[nodes[i]][nodes[j]] > maxDistance:
                        valid = False
                        break
                if not valid:
                    break
            if valid:
                ans += 1

        return ans
```

### 方法二：针对每个子集重新运行 Floyd（精确处理关闭节点）

```python
from typing import List

class Solution:
    def numberOfSets(self, n: int, maxDistance: int, roads: List[List[int]]) -> int:
        INF = float('inf')
        # 对每个子集，只考虑子集内的节点和边
        ans = 0

        for mask in range(1 << n):
            nodes = [i for i in range(n) if (mask >> i) & 1]
            if not nodes:
                ans += 1  # 空集合也算
                continue

            # 构建子图的最短路
            d = {(i, j): INF for i in nodes for j in nodes}
            for i in nodes:
                d[(i, i)] = 0
            for u, v, w in roads:
                if (mask >> u) & 1 and (mask >> v) & 1:
                    d[(u, v)] = min(d[(u, v)], w)
                    d[(v, u)] = min(d[(v, u)], w)

            # Floyd
            for k in nodes:
                for i in nodes:
                    for j in nodes:
                        if d[(i, k)] + d[(k, j)] < d[(i, j)]:
                            d[(i, j)] = d[(i, k)] + d[(k, j)]

            valid = all(d[(i, j)] <= maxDistance
                        for i in nodes for j in nodes if i != j)
            if valid:
                ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(2^n * n^3)，枚举子集 + Floyd
- 空间复杂度：O(n^2)

## 关键点总结

1. n <= 10，2^10 = 1024 个子集，每个 Floyd O(n^3)，总计约 O(10^6)
2. 开放节点之间的最短路必须考虑通过关闭节点的路径（允许经过关闭节点）
3. 方法一预计算全图最短路（含关闭节点作为中间点），更高效

## 易错点

1. 空集合（所有节点都关闭）也是有效方案（没有开放节点对，条件空满足）
2. 最短路允许经过关闭节点作为中间节点（只要开放节点对之间的最终距离满足条件）
3. Floyd 中 k 需要遍历所有节点（不只是开放节点，若要精确则只用开放节点）
