## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，如果某个连续子数组中恰好有 `k` 个奇数，我们就认为这个子数组是**优美子数组**。

请返回这个数组中优美子数组的数目。

**示例 1：**

```
输入：nums = [1,1,2,1,1], k = 3
输出：2
解释：包含 3 个奇数的子数组为 [1,1,2,1] 和 [1,2,1,1]
```

**示例 2：**

```
输入：nums = [2,4,6], k = 1
输出：0
解释：数组中没有奇数，不存在优美子数组
```

**示例 3：**

```
输入：nums = [2,2,2,1,2,2,1,2,2,2], k = 2
输出：16
```

**提示：**

- `1 <= nums.length <= 50000`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

这道题的核心是**统计恰好包含 k 个奇数的连续子数组数量**。

**关键转化：**
- 将数组转换为 0/1 数组：奇数 → 1，偶数 → 0
- 问题变为：找到和为 k 的连续子数组数量
- 这是经典的**前缀和 + 哈希表**问题

**解法思路：**

1. **方法一：前缀和 + 哈希表**
   - 记录每个位置之前的奇数个数（前缀和）
   - 使用哈希表存储每个前缀和出现的次数
   - 如果当前前缀和为 `s`，则找前面前缀和为 `s - k` 的位置

2. **方法二：滑动窗口（at-most 技巧）**
   - `恰好 k 个` = `最多 k 个` - `最多 k-1 个`
   - 使用滑动窗口分别计算这两个值

3. **方法三：双指针**
   - 固定右端点，找左端点的可行区间

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）⭐

```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        from collections import defaultdict
        
        # 哈希表记录前缀和（奇数个数）出现的次数
        prefix_count = defaultdict(int)
        prefix_count[0] = 1  # 初始前缀和为 0，出现 1 次
        
        odd_count = 0  # 当前前缀和（奇数个数）
        result = 0
        
        for num in nums:
            # 如果是奇数，前缀和 +1
            if num % 2 == 1:
                odd_count += 1
            
            # 查找前面是否存在前缀和为 odd_count - k 的位置
            # 如果存在，说明从那个位置到当前位置恰好有 k 个奇数
            result += prefix_count[odd_count - k]
            
            # 更新当前前缀和的出现次数
            prefix_count[odd_count] += 1
        
        return result
```

### 方法二：at-most 技巧（滑动窗口）

使用 "恰好 k 个 = 最多 k 个 - 最多 k-1 个" 的技巧。

```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        def atMost(k: int) -> int:
            """计算最多包含 k 个奇数的子数组数量"""
            count = 0
            left = 0
            odd_count = 0
            
            for right in range(len(nums)):
                # 如果是奇数，计数 +1
                if nums[right] % 2 == 1:
                    odd_count += 1
                
                # 如果奇数超过 k 个，收缩左边界
                while odd_count > k:
                    if nums[left] % 2 == 1:
                        odd_count -= 1
                    left += 1
                
                # [left, right] 区间内所有子数组都满足条件
                count += right - left + 1
            
            return count
        
        # 恰好 k 个 = 最多 k 个 - 最多 k-1 个
        return atMost(k) - atMost(k - 1)
```

### 方法三：双指针（计算左边界区间）

```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        odd_count = 0
        left = 0
        
        # cnt 记录当前窗口左侧的偶数个数
        cnt = 0
        
        for right in range(n):
            # 右指针遇到奇数
            if nums[right] % 2 == 1:
                odd_count += 1
                cnt = 0  # 重置左侧偶数计数
            
            # 当奇数个数达到 k 时
            while odd_count == k:
                cnt += 1  # 每次左移都增加一个有效子数组
                
                # 左指针移动
                if nums[left] % 2 == 1:
                    odd_count -= 1
                left += 1
            
            result += cnt
        
        return result
```

### 方法四：Python 简洁写法

```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        # 将数组转为 0/1 数组（奇数为 1，偶数为 0）
        odd = [1 if x % 2 else 0 for x in nums]
        
        # 前缀和哈希表
        prefix = {0: 1}
        s = 0
        result = 0
        
        for x in odd:
            s += x
            result += prefix.get(s - k, 0)
            prefix[s] = prefix.get(s, 0) + 1
        
        return result
```

## 复杂度分析

### 方法一（前缀和 + 哈希表）

- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(n)，哈希表最多存储 n 个不同的前缀和

### 方法二（at-most 技巧）

- **时间复杂度**：O(n)，两次滑动窗口遍历
- **空间复杂度**：O(1)，只使用常数空间

### 方法三（双指针）

- **时间复杂度**：O(n)，双指针各遍历一次
- **空间复杂度**：O(1)

## 关键点总结

1. **问题转化**：恰好 k 个奇数 → 前缀和为 k 的连续子数组
2. **前缀和技巧**：使用哈希表记录前缀和出现次数
3. **at-most 技巧**：`恰好 k = 最多 k - 最多 (k-1)`
4. **初始化**：`prefix_count[0] = 1` 很重要，表示前缀和为 0 的情况
5. **奇偶判断**：`num % 2 == 1` 判断奇数

## 易错点

1. **初始化遗漏**：忘记设置 `prefix_count[0] = 1`
2. **前缀和理解**：前缀和 `s` 表示前 `i` 个数中奇数的个数
3. **区间计数**：从前缀和 `s - k` 到 `s` 的区间恰好有 k 个奇数
4. **at-most 边界**：注意是 `atMost(k) - atMost(k-1)`，而不是 `atMost(k+1)`
5. **奇偶数组转换**：可以不显式转换，直接判断 `num % 2`
