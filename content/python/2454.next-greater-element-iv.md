## 题目描述

给你一个下标从 **0** 开始的非负整数数组 `nums`。对于 `nums` 中每一个整数，你必须找到对应元素的 **第二大** 整数。

如果 `nums[i]` 右边存在两个严格大于 `nums[i]` 的整数，则 `nums[i]` 的第二大整数就是从左到右在 `nums[i]` 右边的第二个严格大于 `nums[i]` 的整数。如果不存在，则第二大整数为 `-1`。

**示例 1：**
```
输入：nums = [2,4,0,9,6]
输出：[9,6,6,-1,-1]
解释：
- 下标 0：右边有 4,9,6，第一大是 4，第二大是 9。
- 下标 1：右边有 9,6，第一大是 9，第二大不存在（只有一个 > 4 的），所以是... 等等 6 也 > 4，第二大是 6。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

**两个单调栈：**

维护两个栈：
- `stack1`：单调递减栈，存储尚未找到第一大值的元素下标
- `stack2`：已找到第一大值但还未找到第二大值的元素下标（也按值单调递减）

**处理流程：**
1. 遍历 `nums`，对当前元素 `nums[i]`：
   - 先处理 `stack2`：弹出所有 `nums[top] < nums[i]` 的元素，记录为第二大值
   - 再处理 `stack1`：弹出所有 `nums[top] < nums[i]` 的元素，转移到 `stack2`（已找到第一大值）
   - 将 `i` 压入 `stack1`

## 代码实现

### 方法一：双单调栈（推荐）

```python
from typing import List

class Solution:
    def secondGreaterElement(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [-1] * n
        stack1 = []  # 单调递减栈（等待第一大值）
        stack2 = []  # 已有第一大值，等待第二大值

        for i, x in enumerate(nums):
            # 处理 stack2：弹出所有值 < x 的元素（x 是它们的第二大值）
            while stack2 and nums[stack2[-1]] < x:
                ans[stack2.pop()] = x

            # 将 stack1 中值 < x 的元素转移到 stack2
            temp = []
            while stack1 and nums[stack1[-1]] < x:
                temp.append(stack1.pop())
            # temp 中的元素按值降序加入 stack2（保持 stack2 单调递减）
            stack2.extend(reversed(temp))

            stack1.append(i)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双单调栈 | O(n) | O(n) |

每个元素最多进出各栈一次，总体 O(n)。

## 关键点总结

1. 两个栈分阶段处理：第一阶段找第一大值，第二阶段找第二大值
2. 处理顺序：先处理 stack2，再处理 stack1（避免同一元素 x 在同一步骤中被计两次）
3. temp 数组存储从 stack1 中弹出的元素，逆序加入 stack2 保持单调性

## 易错点

- 先处理 `stack2` 再处理 `stack1`，不能颠倒
- `temp` 中的元素需要逆序（倒序）加入 `stack2`，保持 `stack2` 单调递减
