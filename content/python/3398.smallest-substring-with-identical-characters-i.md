## 题目描述

给你一个**二进制字符串** `s` 和一个整数 `numOps`，每次操作可以将 `s` 中的任意一个字符翻转（0 变 1 或 1 变 0）。

返回经过**最多 `numOps` 次操作**后，`s` 中**最长的全相同字符子字符串**的最小可能长度。

**示例：**
```
输入：s = "000001", numOps = 1
输出：2
解释：翻转 s[2]，得到 "001001"，最长全相同子串为 "00"，长度 2。
```

**提示：**
- `1 <= n <= 1000`（本题 I，数据范围较小）
- `0 <= numOps <= n`

## 解题思路

**二分答案 + 贪心验证：**

二分目标：最长全相同子串的最小长度 `mid`。

验证函数 `check(mid)`：能否通过最多 `numOps` 次操作，使所有的全相同子串长度不超过 `mid`？

对于给定的最大允许长度 `mid`：
- 找到所有长度超过 `mid` 的全相同字符段。
- 对每段长度为 `L` 的全相同段，至少需要 `L // (mid + 1)` 次操作将其打断（每 `mid+1` 个连续相同字符中插入一个不同字符）。

特殊情况：`mid = 1` 时，字符串应交替 01，验证代价为将 s 变为 "010101..." 或 "101010..." 的最小翻转数。

## Python 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
class Solution:
    def minLength(self, s: str, numOps: int) -> int:
        n = len(s)
        
        def cost(max_len):
            """计算将所有全相同子串长度限制在 max_len 内所需的最少操作数"""
            if max_len == 0:
                return float('inf')
            
            # 特殊处理 max_len == 1：
            # 需要变成交替字符串，计算变成 "010101..." 或 "101010..." 的代价
            if max_len == 1:
                cost0 = sum(1 for i in range(n) if s[i] != str(i % 2))      # 目标 "010101..."
                cost1 = sum(1 for i in range(n) if s[i] != str((i + 1) % 2))  # 目标 "101010..."
                return min(cost0, cost1)
            
            # max_len >= 2：找所有连续相同字符段，统计打断代价
            ops = 0
            i = 0
            while i < n:
                j = i
                while j < n and s[j] == s[i]:
                    j += 1
                length = j - i
                # 长度为 length 的段，需要 length // (max_len + 1) 次操作
                ops += length // (max_len + 1)
                i = j
            
            return ops
        
        # 二分：找最小的 mid 使得 cost(mid) <= numOps
        lo, hi = 1, n
        
        while lo < hi:
            mid = (lo + hi) // 2
            if cost(mid) <= numOps:
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

### 方法二：暴力枚举（适合 n <= 1000）

```python
class Solution:
    def minLength(self, s: str, numOps: int) -> int:
        n = len(s)
        
        def cost(max_len):
            if max_len == 1:
                c0 = sum(s[i] != '01'[i % 2] for i in range(n))
                c1 = sum(s[i] != '10'[i % 2] for i in range(n))
                return min(c0, c1)
            ops = 0
            i = 0
            while i < n:
                j = i + 1
                while j < n and s[j] == s[i]:
                    j += 1
                length = j - i
                ops += length // (max_len + 1)
                i = j
            return ops
        
        # 从小到大枚举答案
        for ans in range(1, n + 1):
            if cost(ans) <= numOps:
                return ans
        
        return n
```

## 复杂度分析

**方法一（二分）：**
- 时间复杂度：O(n log n)，二分 O(log n) 次，每次验证 O(n)
- 空间复杂度：O(1)

**方法二（枚举）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(1)

## 关键点总结

1. 二分目标长度，验证能否在 `numOps` 次内达成。
2. 对于长度为 `L` 的全相同段，限制最大长度为 `mid`，需要 `L // (mid+1)` 次操作。
3. 特殊处理 `mid = 1`：最优是变为交替字符串，计算两种交替模式的最小代价。

## 易错点

1. `mid = 1` 时不能直接用通用公式，需要特殊处理交替字符串。
2. 打断长度为 `L` 的段，每 `mid+1` 个元素中需翻转 1 个，代价是 `L // (mid+1)`。
3. 二分区间是 `[1, n]`，不是 `[0, n]`（最短长度至少为 1）。
