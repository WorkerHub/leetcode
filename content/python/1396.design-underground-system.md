## 题目描述

请你实现一个类 `UndergroundSystem`，用来记录地铁的每次行程，并计算从某个站到另一个站的平均行程时间。

**实现方法：**

- `void checkIn(int id, string stationName, int t)`：
  编号为 `id` 的乘客在时间 `t` 于车站 `stationName` 签到。
  一个乘客在时间 `t1` 签到，不会在时间 `t1` 之前再次签到（即每个乘客同时最多只有一次旅行）。

- `void checkOut(int id, string stationName, int t)`：
  编号为 `id` 的乘客在时间 `t` 于车站 `stationName` 签出。

- `double getAverageTime(string startStation, string endStation)`：
  返回从 `startStation` 出发到达 `endStation` 的平均行程时间。
  **平均时间**基于截至当前所有从 `startStation` 到 `endStation` 的行程时间计算，不包括其他任何路线的行程时间。
  从 `startStation` 到 `endStation` 的行程时间为 `tOut - tIn`。
  此方法被调用时，从 `startStation` 到 `endStation` 至少有一次行程。

**你可以假设**所有对 `checkIn` 和 `checkOut` 的调用都是一致的。即：如果一名乘客在时间 `t1` 于某站签到，那么他在时间 `t2 > t1` 才会在另一个站签出。

**示例：**

```
输入：
["UndergroundSystem","checkIn","checkIn","checkIn","checkOut","checkOut","checkOut","getAverageTime","getAverageTime","checkIn","getAverageTime","checkOut","getAverageTime"]
[[],[45,"Leyton",3],[32,"Paradise",8],[27,"Leyton",10],[45,"Waterloo",15],[27,"Waterloo",20],[32,"Cambridge",22],["Paradise","Cambridge"],["Leyton","Waterloo"],[10,"Leyton",24],["Leyton","Waterloo"],[10,"Waterloo",38],["Leyton","Waterloo"]]

输出：
[null,null,null,null,null,null,null,14.00000,11.00000,null,11.00000,null,12.00000]
```

**提示：**

- `1 <= id, t <= 10^6`
- `1 <= stationName.length, startStation.length, endStation.length <= 10 `
- 所有字符串由大小写英文字母与数字组成
- `checkIn` 和 `checkOut` 方法最多调用 `2 * 10^4` 次

## 解题思路

**双哈希表设计：**

1. **`check_in_data`**：记录每个乘客的签到信息
   - 键：乘客 id
   - 值：`(stationName, t)` 元组

2. **`trip_data`**：记录每条路线的统计信息
   - 键：`(startStation, endStation)` 元组
   - 值：`(total_time, trip_count)` 元组

**操作流程：**
- `checkIn`：将 `(stationName, t)` 存入 `check_in_data[id]`
- `checkOut`：从 `check_in_data[id]` 取出签到信息，计算本次行程时间，更新 `trip_data`
- `getAverageTime`：从 `trip_data` 取出累计时间和次数，返回平均值

## Python 代码实现

### 方法一：双哈希表（推荐）

```python
from collections import defaultdict

class UndergroundSystem:

    def __init__(self):
        # 存储当前在途乘客的签到信息：{id: (stationName, t)}
        self.check_in_data = {}
        # 存储路线的累计行程时间和次数：{(start, end): (total_time, count)}
        self.trip_data = defaultdict(lambda: (0, 0))

    def checkIn(self, id: int, stationName: str, t: int) -> None:
        # 记录乘客的签到站和时间
        self.check_in_data[id] = (stationName, t)

    def checkOut(self, id: int, stationName: str, t: int) -> None:
        # 取出签到信息
        start_station, start_time = self.check_in_data.pop(id)
        # 计算本次行程时间
        duration = t - start_time
        # 更新路线统计：累计时间 + 本次时长，次数 + 1
        total_time, count = self.trip_data[(start_station, stationName)]
        self.trip_data[(start_station, stationName)] = (total_time + duration, count + 1)

    def getAverageTime(self, startStation: str, endStation: str) -> float:
        total_time, count = self.trip_data[(startStation, endStation)]
        return total_time / count
```

### 方法二：显式字典（更直观）

```python
class UndergroundSystem:

    def __init__(self):
        # {乘客id: (签到站名, 签到时间)}
        self.on_trip = {}
        # {(起始站, 终点站): [总时间, 次数]}
        self.stats = {}

    def checkIn(self, id: int, stationName: str, t: int) -> None:
        self.on_trip[id] = (stationName, t)

    def checkOut(self, id: int, stationName: str, t: int) -> None:
        start, start_t = self.on_trip.pop(id)
        key = (start, stationName)
        if key not in self.stats:
            self.stats[key] = [0, 0]  # [总时间, 次数]
        self.stats[key][0] += t - start_t  # 累加行程时间
        self.stats[key][1] += 1             # 行程次数加1

    def getAverageTime(self, startStation: str, endStation: str) -> float:
        total, count = self.stats[(startStation, endStation)]
        return total / count
```

## 复杂度分析

- **checkIn**：O(1)，哈希表插入
- **checkOut**：O(1)，哈希表查询和更新
- **getAverageTime**：O(1)，哈希表查询和除法

- **空间复杂度**：O(P + R)，P 是在途乘客数，R 是不同路线数

## 图解示例

```
checkIn(45, "Leyton", 3):  on_trip = {45: ("Leyton", 3)}
checkOut(45, "Waterloo", 15): duration = 12, stats[("Leyton","Waterloo")] = (12, 1)
checkIn(10, "Leyton", 24):  on_trip = {10: ("Leyton", 24)}
checkOut(10, "Waterloo", 38): duration = 14, stats[("Leyton","Waterloo")] = (26, 2)
getAverageTime("Leyton", "Waterloo"): 26/2 = 13.0
```

## 关键点总结

1. 用两个哈希表分别记录"当前在途乘客"和"路线统计"
2. `checkOut` 时使用 `pop` 清除在途记录，节省空间
3. 路线的键用 `(startStation, endStation)` 元组，Python 元组可以直接作为字典键
4. `getAverageTime` 直接用累计时间除以次数

## 易错点

- `checkOut` 时要从 `check_in_data` 中**删除**该乘客（用 `pop`），否则乘客信息会残留
- `getAverageTime` 中除以的是**行程次数**，不是总时间
- 路线统计的键是有序的 `(start, end)`，`("A","B")` 和 `("B","A")` 是不同路线
