## 题目描述

给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。

**示例 1：**
```
输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。第一个匹配项的下标是 0
```

**示例 2：**
```
输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现
```

**提示：**
- `1 <= haystack.length, needle.length <= 10^4`
- `haystack` 和 `needle` 仅由小写英文字符组成

## 解题思路

这是经典的字符串匹配问题。

**方法对比：**
1. **内置函数**：直接使用 `str.find()`
2. **暴力法**：逐个位置尝试匹配
3. **KMP算法**：高效的字符串匹配算法

## Python 代码实现

### 方法一：内置函数（最简单）

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        return haystack.find(needle)
```

### 方法二：暴力法

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        
        # 遍历每个可能的起始位置
        for i in range(n - m + 1):
            # 检查从 i 开始是否匹配
            if haystack[i:i+m] == needle:
                return i
        
        return -1
```

### 方法三：KMP 算法

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        if m == 0:
            return 0
        
        # 构建 next 数组（部分匹配表）
        next_arr = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and needle[i] != needle[j]:
                j = next_arr[j - 1]
            if needle[i] == needle[j]:
                j += 1
            next_arr[i] = j
        
        # KMP 匹配
        j = 0
        for i in range(n):
            while j > 0 and haystack[i] != needle[j]:
                j = next_arr[j - 1]
            if haystack[i] == needle[j]:
                j += 1
            if j == m:
                return i - m + 1
        
        return -1
```

## 复杂度分析

**方法一和方法二：**
- 时间复杂度：O(n×m)
- 空间复杂度：O(1)

**方法三（KMP）：**
- 时间复杂度：O(n + m)
- 空间复杂度：O(m)

## 关键点总结

1. **内置函数**：实际工作中推荐使用
2. **暴力法**：简单直观，适合小数据
3. **KMP**：面试常考，需要理解 next 数组的构建

## 易错点

1. **边界情况**：needle 为空字符串
2. **索引越界**：暴力法要注意范围是 `range(n - m + 1)`
