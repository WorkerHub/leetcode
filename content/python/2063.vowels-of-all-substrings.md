## 题目描述

给你一个字符串 `word`，返回所有子字符串中**元音字母**的总数目。

**示例 1：**
```
输入：word = "aba"
输出：6
解释：子串 "a","b","a","ab","ba","aba"，其中含元音 1+0+1+1+1+2=6
```

**示例 2：**
```
输入：word = "abc"
输出：3
```

**提示：**
- `1 <= word.length <= 10^5`
- `word` 由小写英文字母组成

## 解题思路

**数学方法：** 对于每个元音字符 `word[i]`，统计它出现在多少个子串中。

位置 `i`（0-indexed）的字符：
- 左端点可以是 `0, 1, ..., i`，共 `i + 1` 种
- 右端点可以是 `i, i+1, ..., n-1`，共 `n - i` 种
- 包含位置 `i` 的子串数 = `(i + 1) * (n - i)`

对所有元音字符的位置累加即得答案。

## 代码实现

### 方法一：数学计算（推荐）

```python
class Solution:
    def countVowels(self, word: str) -> int:
        n = len(word)
        vowels = set('aeiou')
        total = 0

        for i, c in enumerate(word):
            if c in vowels:
                # 位置 i 的字符出现在 (i+1) * (n-i) 个子串中
                total += (i + 1) * (n - i)

        return total
```

### 方法二：动态规划辅助理解

```python
class Solution:
    def countVowels(self, word: str) -> int:
        # dp[i] = 所有以 word[i] 结尾的子串中的元音总数
        n = len(word)
        vowels = set('aeiou')
        dp = 0  # 以当前字符结尾的所有子串中的元音数
        total = 0

        # 以 word[i] 结尾的子串数为 i+1 个（word[0..i], word[1..i], ..., word[i..i]）
        # 加入 word[i] 后，新子串中的元音数 = dp + (i+1) * (word[i] 是元音 ? 1 : 0)
        # 实际上这个 DP 不直接，用数学方法更清晰

        for i, c in enumerate(word):
            total += (i + 1) * (n - i) if c in vowels else 0

        return total
```

### 方法三：暴力（用于理解）

```python
class Solution:
    def countVowels(self, word: str) -> int:
        n = len(word)
        vowels = set('aeiou')
        total = 0

        for i in range(n):
            for j in range(i, n):
                # 统计子串 word[i..j] 中的元音
                total += sum(1 for c in word[i:j+1] if c in vowels)

        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学计算 | O(n) | O(1) |
| 暴力 | O(n^3) | O(1) |

## 关键点总结

1. 贡献法：计算每个元音字符对所有子串的贡献
2. 位置 `i` 的字符在 `(i+1) * (n-i)` 个子串中出现
3. 只需累加所有元音位置的贡献

## 易错点

- 索引从 0 开始：左侧有 `i+1` 个选择（0 到 i），右侧有 `n-i` 个选择（i 到 n-1）
- 只统计元音字符的贡献，辅音字符贡献为 0
