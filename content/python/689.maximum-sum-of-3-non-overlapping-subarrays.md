## 题目描述

给你一个整数数组 nums 和一个整数 k，找出三个长度为 k 且不重叠的子数组，使得它们的和最大。

返回这三个子数组的起始索引。如果有多个答案，返回字典序最小的。

**示例：**
```
输入：nums = [1,2,1,2,6,7,5,1], k = 2
输出：[0,3,5]
解释：
子数组 [1,2], [2,6], [7,5] 的和为 20
```

## Python 代码实现

### 方法一：动态规划

```python
from typing import List

class Solution:
    def maxSumOfThreeSubarrays(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        
        # 计算所有长度为 k 的子数组的和
        sums = []
        window_sum = sum(nums[:k])
        sums.append(window_sum)
        for i in range(k, n):
            window_sum = window_sum - nums[i-k] + nums[i]
            sums.append(window_sum)
        
        # left[i] 表示 [0, i] 范围内最大和的起始索引
        left = [0] * len(sums)
        best = 0
        for i in range(len(sums)):
            if sums[i] > sums[best]:
                best = i
            left[i] = best
        
        # right[i] 表示 [i, n-1] 范围内最大和的起始索引
        right = [0] * len(sums)
        best = len(sums) - 1
        for i in range(len(sums) - 1, -1, -1):
            if sums[i] >= sums[best]:
                best = i
            right[i] = best
        
        # 找到最优的三个子数组
        result = [-1, -1, -1]
        max_sum = 0
        for j in range(k, len(sums) - k):
            i, l = left[j - k], right[j + k]
            total = sums[i] + sums[j] + sums[l]
            if total > max_sum:
                max_sum = total
                result = [i, j, l]
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 预计算所有子数组的和
2. 使用辅助数组记录左右最优位置
3. 枚举中间子数组的位置
