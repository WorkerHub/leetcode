## 题目描述

国际摩尔斯密码定义一种标准编码方式，将每个字母对应于一个由一系列点和短线组成的字符串，比如:
- `'a'` 对应 `".-"`
- `'b'` 对应 `"-..."`
- `'c'` 对应 `"-.-."`

等等。

为了方便，所有 26 个英文字母的摩尔斯密码表如下：

```
[".-","-...","-.-.","-..",".","..-.","--.","....","..",".---","-.-",".-..","--","-.","---",".--.","--.-",".-.","...","-","..-","...-",".--","-..-","-.--","--.."]
```

给你一个字符串数组 `words`，每个单词可以写成每个字母对应摩尔斯密码的组合。

例如，`"cab"` 可以写成 `"-.-..--..."`（即 `"-.-."` + `".-"` + `"-..."` 字符串的结合）。我们将这样一个连接过程称作 **单词翻译**。

返回 `words` 中所有单词进行单词翻译之后可以获得多少种不同的 **单词翻译**。

**示例 1:**
```
输入: words = ["gin","zen","gig","msg"]
输出: 2
解释: 各单词翻译如下:
"gin" -> "--...-."
"zen" -> "--...-."
"gig" -> "--...--."
"msg" -> "--...--."
共有 2 种不同翻译, "--...-." 和 "--...--.".
```

**示例 2:**
```
输入: words = ["a"]
输出: 1
```

**提示:**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 12`
- `words[i]` 由小写英文字母组成

## 解题思路

这是一道简单的哈希表题目。核心思路是：
1. 将每个单词转换成摩尔斯密码
2. 使用集合（set）存储所有不同的密码
3. 返回集合的大小

**步骤：**
1. 定义摩尔斯密码映射表
2. 遍历每个单词，将其转换为摩尔斯密码
3. 将密码加入集合
4. 返回集合大小

## Python 代码实现

### 方法一：哈希集合（推荐）⭐

```python
from typing import List

class Solution:
    def uniqueMorseRepresentations(self, words: List[str]) -> int:
        # 摩尔斯密码映射表
        morse = [".-","-...","-.-.","-..",".","..-.","--.","....","..",".---",
                 "-.-",".-..","--","-.","---",".--.","--.-",".-.","...","-",
                 "..-","...-",".--","-..-","-.--","--.."]
        
        # 存储所有不同的摩尔斯密码
        transformations = set()
        
        for word in words:
            # 将单词转换为摩尔斯密码
            code = ''.join(morse[ord(char) - ord('a')] for char in word)
            transformations.add(code)
        
        return len(transformations)
```

### 方法二：使用字典映射

```python
from typing import List

class Solution:
    def uniqueMorseRepresentations(self, words: List[str]) -> int:
        morse = [".-","-...","-.-.","-..",".","..-.","--.","....","..",".---",
                 "-.-",".-..","--","-.","---",".--.","--.-",".-.","...","-",
                 "..-","...-",".--","-..-","-.--","--.."]
        
        # 创建字母到摩尔斯密码的映射
        letter_to_morse = {chr(ord('a') + i): morse[i] for i in range(26)}
        
        # 存储转换结果
        seen = set()
        
        for word in words:
            code = ''.join(letter_to_morse[char] for char in word)
            seen.add(code)
        
        return len(seen)
```

### 方法三：一行流（Pythonic）

```python
from typing import List

class Solution:
    def uniqueMorseRepresentations(self, words: List[str]) -> int:
        morse = [".-","-...","-.-.","-..",".","..-.","--.","....","..",".---",
                 "-.-",".-..","--","-.","---",".--.","--.-",".-.","...","-",
                 "..-","...-",".--","-..-","-.--","--.."]
        
        return len({''.join(morse[ord(c) - ord('a')] for c in word) for word in words})
```

### 方法四：使用 map 函数

```python
from typing import List

class Solution:
    def uniqueMorseRepresentations(self, words: List[str]) -> int:
        morse = [".-","-...","-.-.","-..",".","..-.","--.","....","..",".---",
                 "-.-",".-..","--","-.","---",".--.","--.-",".-.","...","-",
                 "..-","...-",".--","-..-","-.--","--.."]
        
        def to_morse(word: str) -> str:
            """将单词转换为摩尔斯密码"""
            return ''.join(map(lambda c: morse[ord(c) - ord('a')], word))
        
        return len(set(map(to_morse, words)))
```

## 复杂度分析

- **时间复杂度**：O(n × m)，其中 n 是单词数量，m 是单词的平均长度
- **空间复杂度**：O(n × m)，最坏情况下每个单词的编码都不同

## 关键点总结

1. **集合去重**：利用 set 自动去重的特性
2. **字符映射**：通过 ASCII 码计算字符索引
3. **字符串拼接**：使用 `''.join()` 高效拼接
4. **Python 特性**：可以写成简洁的一行代码

## 易错点

1. **索引计算**：`ord(char) - ord('a')` 获取字母在字母表中的位置
2. **字符串拼接**：不要用 `+` 在循环中拼接，用 `join` 更高效
3. **大小写**：题目保证是小写字母，无需处理大写
