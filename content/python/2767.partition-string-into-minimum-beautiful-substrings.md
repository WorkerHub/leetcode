## 题目描述

给你一个仅包含字符 `'0'` 和 `'1'` 的字符串 `s`，如果一个字符串满足：
1. 不含前导零
2. 其二进制表示的十进制值是 5 的幂次

则称该字符串为 **美丽字符串**。

将 `s` 分割成若干 **美丽字符串** 的最小分割数，如果无法分割则返回 -1。

**示例 1：**
```
输入：s = "1011"
输出：2
解释："101"（5的1次方）+"1"（5的0次方）
```

**示例 2：**
```
输入：s = "111"
输出：3
解释："1"+"1"+"1"
```

**提示：**
- `1 <= s.length <= 15`

## 解题思路

预处理 5 的幂次的二进制表示集合，然后 DP：`dp[i]` = 分割 `s[0..i-1]` 的最小份数。

5 的幂次：1, 5, 25, 125, 625, 3125, 15625 ... 二进制长度最多 15。

## Python 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def minimumBeautifulSubstrings(self, s: str) -> int:
        n = len(s)
        # 预处理 5 的幂次的二进制字符串
        powers = set()
        p = 1
        while p <= 2**15:
            powers.add(bin(p)[2:])  # 去掉 '0b' 前缀
            p *= 5

        INF = float('inf')
        dp = [0] + [INF] * n  # dp[i] = 分割 s[0..i-1] 的最小份数

        for i in range(1, n + 1):
            for j in range(i):
                sub = s[j:i]
                if sub[0] == '0':  # 含前导零
                    continue
                if sub in powers:
                    if dp[j] < INF:
                        dp[i] = min(dp[i], dp[j] + 1)

        return dp[n] if dp[n] < INF else -1
```

### 方法二：回溯（适合小数据）

```python
class Solution:
    def minimumBeautifulSubstrings(self, s: str) -> int:
        n = len(s)
        powers = set()
        p = 1
        while p <= 2**15:
            powers.add(bin(p)[2:])
            p *= 5

        self.ans = float('inf')

        def dfs(start, cnt):
            if start == n:
                self.ans = min(self.ans, cnt)
                return
            if s[start] == '0':
                return
            for end in range(start + 1, n + 1):
                if s[start:end] in powers:
                    dfs(end, cnt + 1)

        dfs(0, 0)
        return self.ans if self.ans < float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，L 为 5 的幂次二进制长度（最多 15）
- 空间复杂度：O(n)

## 关键点总结

1. 5 的幂次在 15 位二进制内只有少数个（1,5,25,125,625,3125,15625）
2. DP 定义清晰：dp[i] 为前 i 个字符的最小分割数
3. 前导零直接跳过

## 易错点

1. 子串不能有前导零（`sub[0] == '0'` 需跳过）
2. 5 的幂次预处理要足够
