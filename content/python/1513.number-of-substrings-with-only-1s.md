## 题目描述

给你一个二进制字符串 `s`（只含 0 和 1），返回所有字符都是 1 的子字符串的数目。

由于答案可能很大，请你将它对 `10^9 + 7` 取模后返回。

**示例 1：**
```
输入：s = "0110111"
输出：9
解释：子字符串 "1" 出现5次，"11"出现2次，"111"出现1次，"1111"... 共9个
```

**示例 2：**
```
输入：s = "101"
输出：2
```

**示例 3：**
```
输入：s = "111111"
输出：21
解释：6*(6+1)/2 = 21
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 0 或 1

## 解题思路

### 数学规律

将字符串按 0 分割成连续 1 的片段，每个长度为 `L` 的连续 1 的片段，贡献的子字符串数量为 `L*(L+1)/2`。

例如 `"111"` 中：长度1的子串 3 个，长度2的子串 2 个，长度3的子串 1 个，共 `3+2+1 = 6 = 3*4/2`。

## 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def numSub(self, s: str) -> int:
        MOD = 10**9 + 7
        ans = 0
        count = 0  # 当前连续1的长度
        for c in s:
            if c == '1':
                count += 1
                # 每新增一个1，可以和前面所有连续的1组成新子串
                ans = (ans + count) % MOD
            else:
                count = 0  # 遇到0，重置计数
        return ans
```

### 方法二：分段统计

```python
class Solution:
    def numSub(self, s: str) -> int:
        MOD = 10**9 + 7
        ans = 0
        # 按 '0' 分割，统计每段连续1的长度
        for segment in s.split('0'):
            L = len(segment)
            # 长度为 L 的连续1贡献 L*(L+1)//2 个子串
            ans = (ans + L * (L + 1) // 2) % MOD
        return ans
```

### 方法三：逐字符遍历（更详细的写法）

```python
class Solution:
    def numSub(self, s: str) -> int:
        MOD = 10**9 + 7
        ans = 0
        i = 0
        n = len(s)
        while i < n:
            if s[i] == '1':
                # 找连续1的末尾
                j = i
                while j < n and s[j] == '1':
                    j += 1
                L = j - i  # 连续1的长度
                ans = (ans + L * (L + 1) // 2) % MOD
                i = j
            else:
                i += 1
        return ans
```

## 复杂度分析

- **时间复杂度**：O(N)，遍历字符串一次
- **空间复杂度**：O(1)（方法一、三）；O(N)（方法二，split 产生子串列表）

## 关键点总结

1. 连续 L 个 1 能组成 `L*(L+1)/2` 个全为 1 的子串
2. 方法一的技巧：每遇到一个 1，累加当前连续长度（等效于逐步累加）
3. 注意答案取模

## 易错点

- 空字符串的情况（题目保证长度 >= 1，但 split('0') 可能产生空段，空段 L=0，贡献为 0，不影响结果）
- 忘记取模（L*(L+1)/2 可能很大）
