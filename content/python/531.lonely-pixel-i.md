## 题目描述

给定一个由 `'B'`（黑色像素）和 `'W'`（白色像素）组成的二维数组 `picture`，找出所有"孤独的黑色像素"的数量。

"孤独的黑色像素"是指字符 `'B'`，它所在的行和列都只有这一个黑色像素。

**示例 1：**
```
输入: picture = [['W', 'W', 'B'],
                ['W', 'B', 'W'],
                ['B', 'W', 'W']]
输出: 3
解释: 所有三个 'B' 都是孤独的黑色像素。
- picture[0][2]: 第 0 行和第 2 列都只有这一个 'B'
- picture[1][1]: 第 1 行和第 1 列都只有这一个 'B'
- picture[2][0]: 第 2 行和第 0 列都只有这一个 'B'
```

**示例 2：**
```
输入: picture = [['B', 'B', 'B'],
                ['B', 'B', 'W'],
                ['B', 'W', 'W']]
输出: 0
解释: 没有孤独的黑色像素，因为每个 'B' 所在的行或列都有其他 'B'。
```

**提示：**
- `m == picture.length`
- `n == picture[i].length`
- `1 <= m, n <= 500`
- `picture[i][j]` 只能是 `'W'` 或 `'B'`

## 解题思路

这道题的核心思想是：一个黑色像素是"孤独的"，当且仅当它所在的行和列都只有这一个黑色像素。

**算法流程：**

1. **统计阶段**：遍历整个矩阵，统计每一行和每一列的黑色像素数量
2. **检查阶段**：再次遍历矩阵，对于每个黑色像素，检查其所在行和列的黑色像素数量是否都为 1
3. **计数结果**：满足条件的黑色像素数量即为答案

**关键观察：**
- 使用两个数组分别存储每行和每列的黑色像素数量
- 时间复杂度可以优化到 O(m*n)，只需两次遍历
- 空间复杂度 O(m+n)，用于存储行列统计信息

## Python 代码实现

### 方法一：两次遍历统计法（推荐）

```python
from typing import List

class Solution:
    def findLonelyPixel(self, picture: List[List[str]]) -> int:
        """
        使用两次遍历统计黑色像素
        第一次统计每行每列的黑色像素数量
        第二次检查每个黑色像素是否孤独
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        
        # 统计每行和每列的黑色像素数量
        row_count = [0] * m  # row_count[i] 表示第 i 行的黑色像素数量
        col_count = [0] * n  # col_count[j] 表示第 j 列的黑色像素数量
        
        # 第一次遍历：统计
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    row_count[i] += 1
                    col_count[j] += 1
        
        # 第二次遍历：检查孤独像素
        lonely_count = 0
        for i in range(m):
            for j in range(n):
                # 如果是黑色像素，且所在行和列都只有一个黑色像素
                if picture[i][j] == 'B' and row_count[i] == 1 and col_count[j] == 1:
                    lonely_count += 1
        
        return lonely_count
```

### 方法二：一次遍历优化（空间换时间）

```python
from typing import List

class Solution:
    def findLonelyPixel(self, picture: List[List[str]]) -> int:
        """
        使用哈希表存储每行每列的黑色像素位置
        可以在统计的同时记录位置信息
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        
        # 使用字典存储每行每列的黑色像素列表
        row_blacks = {i: [] for i in range(m)}  # 每行的黑色像素列索引
        col_blacks = {j: [] for j in range(n)}  # 每列的黑色像素行索引
        
        # 遍历矩阵，记录所有黑色像素的位置
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    row_blacks[i].append(j)
                    col_blacks[j].append(i)
        
        # 统计孤独像素
        lonely_count = 0
        for i in range(m):
            # 如果该行只有一个黑色像素
            if len(row_blacks[i]) == 1:
                j = row_blacks[i][0]  # 获取该黑色像素的列索引
                # 检查该列是否也只有一个黑色像素
                if len(col_blacks[j]) == 1:
                    lonely_count += 1
        
        return lonely_count
```

### 方法三：简化版（适合初学者）

```python
from typing import List

class Solution:
    def findLonelyPixel(self, picture: List[List[str]]) -> int:
        """
        最直观的方法：对每个黑色像素，检查其行列是否唯一
        """
        if not picture or not picture[0]:
            return 0
        
        m, n = len(picture), len(picture[0])
        lonely_count = 0
        
        for i in range(m):
            for j in range(n):
                if picture[i][j] == 'B':
                    # 检查该黑色像素是否孤独
                    if self.isLonely(picture, i, j, m, n):
                        lonely_count += 1
        
        return lonely_count
    
    def isLonely(self, picture: List[List[str]], row: int, col: int, m: int, n: int) -> bool:
        """检查位置 (row, col) 的黑色像素是否孤独"""
        # 检查该行是否只有一个黑色像素
        row_black_count = sum(1 for j in range(n) if picture[row][j] == 'B')
        if row_black_count != 1:
            return False
        
        # 检查该列是否只有一个黑色像素
        col_black_count = sum(1 for i in range(m) if picture[i][col] == 'B')
        if col_black_count != 1:
            return False
        
        return True
```

## 复杂度分析

### 方法一：两次遍历统计法
- **时间复杂度**：O(m × n)，其中 m 和 n 分别是矩阵的行数和列数
  - 第一次遍历统计：O(m × n)
  - 第二次遍历检查：O(m × n)
  - 总体：O(2 × m × n) = O(m × n)
- **空间复杂度**：O(m + n)，用于存储行列统计数组

### 方法二：一次遍历优化
- **时间复杂度**：O(m × n)，只需一次完整遍历矩阵
- **空间复杂度**：O(m × n)，最坏情况下所有像素都是黑色

### 方法三：简化版
- **时间复杂度**：O(m² × n²)，对每个像素都可能需要遍历整行整列
- **空间复杂度**：O(1)，只使用常数额外空间

**推荐使用方法一**，它在时间和空间上达到了最佳平衡。

## 关键点总结

1. **两次遍历策略**：第一次统计，第二次检查，避免重复计算
2. **空间换时间**：使用 O(m+n) 的额外空间存储统计信息，换取 O(m×n) 的时间复杂度
3. **条件判断**：孤独像素必须同时满足"行唯一"和"列唯一"两个条件
4. **边界处理**：注意空矩阵的边界情况
5. **数据结构选择**：使用数组存储计数比使用哈希表更高效

## 易错点

1. **忘记同时检查行和列**
   ```python
   # 错误：只检查了行
   if row_count[i] == 1:
       lonely_count += 1
   
   # 正确：必须同时检查行和列
   if picture[i][j] == 'B' and row_count[i] == 1 and col_count[j] == 1:
       lonely_count += 1
   ```

2. **重复计数问题**
   - 在第二次遍历时，每个孤独像素只应该被计数一次
   - 不要在统计行列时就开始计数，应该在检查阶段统一计数

3. **索引越界**
   ```python
   # 注意行列数组的索引范围
   row_count = [0] * m  # 索引范围 [0, m-1]
   col_count = [0] * n  # 索引范围 [0, n-1]
   ```

4. **空矩阵处理**
   ```python
   # 必须检查矩阵是否为空
   if not picture or not picture[0]:
       return 0
   ```

## 学习建议

1. **掌握矩阵遍历的基本模式**：
   - 行优先遍历：`for i in range(m): for j in range(n)`
   - 列优先遍历：`for j in range(n): for i in range(m)`
   - 理解何时需要两次遍历

2. **理解统计与检查的分离**：
   - 先统计全局信息（第一次遍历）
   - 再根据全局信息做决策（第二次遍历）
   - 这种模式在很多矩阵题目中都适用

3. **练习空间时间权衡**：
   - 方法一：用 O(m+n) 空间换 O(m×n) 时间
   - 方法三：用 O(1) 空间但需要 O(m²×n²) 时间
   - 根据实际场景选择合适的方案

4. **从简单到优化的学习路径**：
   - 第一步：实现方法三（暴力法），确保理解题意
   - 第二步：优化到方法一（两次遍历），学习统计思想
   - 第三步：尝试方法二（哈希表），理解不同数据结构的应用

5. **调试技巧**：
   - 打印中间结果：`print(row_count, col_count)` 查看统计是否正确
   - 使用小测试用例：从 2×2 矩阵开始测试
   - 检查边界：空矩阵、全黑、全白、只有一个元素等情况
