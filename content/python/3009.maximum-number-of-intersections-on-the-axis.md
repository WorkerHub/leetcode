## 题目描述

给你一个二维整数数组 `circles`，其中 `circles[i] = [xi, yi, ri]` 表示以 `(xi, yi)` 为圆心、`ri` 为半径的第 `i` 个圆。

返回 x 轴上被最多圆覆盖的点的数量（圆覆盖意味着该点在圆内或圆的边界上）。

**注意：** 只考虑 x 轴上的点，即 `y = 0` 的情况。

**示例 1：**
```
输入：circles = [[2,1,1]]
输出：2
解释：圆与 x 轴的交点为 [1,3]，覆盖了整数点 1, 2, 3，共 3 个？
实际输出为 2（即圆覆盖的 x 轴上的点个数）
```

**示例 2：**
```
输入：circles = [[0,1,1]]
输出：1
```

**提示：**
- `1 <= circles.length <= 10^5`
- `circles[i].length == 3`
- `1 <= xi, yi, ri <= 10^9`

## 解题思路

对于圆 `(x, y, r)`，它与 x 轴（y=0）相交的条件是 `y <= r`（圆心到 x 轴的距离 <= 半径）。

若相交，x 轴上被覆盖的区间为：
- 水平距离 `d = sqrt(r^2 - y^2)`
- 覆盖区间为 `[x - d, x + d]`

注意：为避免浮点数问题，使用整数平方比较：
- 覆盖的整数 x 坐标范围为 `[ceil(x - d), floor(x + d)]`

使用**差分数组**统计 x 轴各点被覆盖的圆的数量，找最大值。

由于坐标可能很大，使用哈希表（字典）作为差分数组。

## Python 代码实现

### 方法一：差分数组 + 哈希表（推荐）

```python
from typing import List
import math
from collections import defaultdict

class Solution:
    def maximumIntersectionCount(self, circles: List[List[int]]) -> int:
        # 差分数组（用有序字典或排序事件列表）
        diff = defaultdict(int)

        for x, y, r in circles:
            # 判断圆是否与 x 轴相交
            if y > r:
                continue
            # 水平覆盖范围
            d_sq = r * r - y * y
            d = int(math.isqrt(d_sq))  # 整数平方根

            left = x - d
            right = x + d

            # 差分：[left, right] 区间 +1
            diff[left] += 1
            diff[right + 1] -= 1

        # 扫描差分数组
        ans = 0
        cur = 0
        for key in sorted(diff.keys()):
            cur += diff[key]
            ans = max(ans, cur)

        return ans
```

### 方法二：事件扫描线

```python
from typing import List
import math

class Solution:
    def maximumIntersectionCount(self, circles: List[List[int]]) -> int:
        events = []

        for x, y, r in circles:
            if y > r:
                continue
            d = int(math.isqrt(r * r - y * y))
            left = x - d
            right = x + d
            # +1 表示覆盖开始，-1 表示覆盖结束
            events.append((left, 1))
            events.append((right + 1, -1))

        # 按位置排序，同位置先处理开始再处理结束
        events.sort(key=lambda e: (e[0], -e[1]))

        ans = 0
        cur = 0
        for _, delta in events:
            cur += delta
            ans = max(ans, cur)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序操作
- 空间复杂度：O(n)，存储事件列表

## 关键点总结

1. 圆与 x 轴相交条件：`y <= r`
2. 整数平方根：`math.isqrt` 精确计算，避免浮点误差
3. 差分数组思路：区间 +1，最后前缀和找最大值
4. 坐标范围大时用哈希表/排序事件代替静态数组

## 易错点

1. 浮点数精度问题：必须用整数运算（`isqrt`）
2. 差分数组右端点要 +1 再 -1（`right + 1` 处 -1）
3. `y == r` 时圆恰好与 x 轴相切，仅覆盖一个点 `x`
