## 题目描述

给定两个长度为 `n` 的整数数组 `arr1` 和 `arr2`，每次操作可以将 `arr1` 的某个元素加 1 或减 1（也可以对 `arr2` 操作，但代价相同）。求使两个数组相等的最少操作次数。

**示例 1：**
```
输入：arr1 = [1,2,3], arr2 = [2,3,4]
输出：3
解释：每个位置差值为 1，共 3 次操作。
```

**示例 2：**
```
输入：arr1 = [1,1,1,1], arr2 = [1,1,1,1]
输出：0
解释：已经相等，无需操作。
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= arr1[i], arr2[i] <= 10^6`

## 解题思路

**数学分析：**

使两数组相等的最简单方式是让每个对应位置上的元素相等，最少操作次数就是各位置差值绝对值之和：

`ans = sum(|arr1[i] - arr2[i]| for i in range(n))`

如果可以通过"交换操作"（将差值从一处转移到另一处）来减少总操作数，则需要更复杂分析。但通常最优策略是逐位处理。

## Python 代码实现

### 方法一：逐位差值之和（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, arr1: List[int], arr2: List[int]) -> int:
        # 每个位置独立处理，最少操作 = 差值绝对值
        return sum(abs(a - b) for a, b in zip(arr1, arr2))
```

### 方法二：哈希表统计差值分布

```python
from typing import List
from collections import Counter

class Solution:
    def minOperations(self, arr1: List[int], arr2: List[int]) -> int:
        # 统计差值分布，用于分析
        diffs = Counter()
        total = 0

        for a, b in zip(arr1, arr2):
            diff = abs(a - b)
            diffs[diff] += 1
            total += diff

        return total
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最少操作数等于各位置元素差值绝对值之和
2. 每个位置独立处理，贪心最优
3. 差值绝对值保证非负

## 易错点

1. 注意差值取绝对值
2. 若题目允许跨位置操作，需要重新分析
