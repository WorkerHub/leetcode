## 题目描述

给定字符串 `text` 和两个字符串 `first` 和 `second`，在 `text` 中找到所有形如 "first second third" 的出现，其中 `second` 紧跟在 `first` 后面，`third` 紧跟在 `second` 后面。

返回所有这些 "third" 的字符串数组。

**示例 1：**
```
输入：text = "alice is a good girl she is a good student", first = "a", second = "good"
输出：["girl","student"]
解释：
- "a good girl" → third = "girl"
- "a good student" → third = "student"
```

**示例 2：**
```
输入：text = "we will we will rock you", first = "we", second = "will"
输出：["we","rock"]
解释：
- "we will we" → third = "we"
- "we will rock" → third = "rock"
```

**提示：**
- `1 <= text.length <= 1000`
- `text` 由小写英文字母和空格组成
- `text` 中的所有单词之间都由**单个空格字符**分隔
- `1 <= first.length, second.length <= 10`
- `first` 和 `second` 由小写英文字母组成

## 解题思路

这是一道简单的**字符串处理**问题，核心思路是遍历单词序列，找到连续的 "first second third" 模式。

### 算法流程

1. **分割字符串**：将 `text` 按空格分割成单词数组
2. **遍历查找**：从索引 0 到 n-3 遍历（确保后面至少有两个单词）
3. **模式匹配**：检查当前位置是否满足 `words[i] == first` 且 `words[i+1] == second`
4. **收集结果**：如果匹配，将 `words[i+2]` 加入结果数组

### 边界情况

- 文本中单词少于 3 个：返回空数组
- 没有匹配的模式：返回空数组
- 多个匹配：返回所有 third

## Python 代码实现

### 方法一：遍历查找（推荐）

```python
from typing import List

class Solution:
    def findOcurrences(self, text: str, first: str, second: str) -> List[str]:
        # 分割文本为单词数组
        words = text.split()
        result = []
        
        # 遍历到倒数第三个单词（确保后面有 second 和 third）
        for i in range(len(words) - 2):
            # 检查是否匹配 "first second" 模式
            if words[i] == first and words[i + 1] == second:
                # 收集 third
                result.append(words[i + 2])
        
        return result
```

### 方法二：列表推导式（简洁版）

```python
from typing import List

class Solution:
    def findOcurrences(self, text: str, first: str, second: str) -> List[str]:
        words = text.split()
        
        return [
            words[i + 2]
            for i in range(len(words) - 2)
            if words[i] == first and words[i + 1] == second
        ]
```

### 方法三：使用 zip（Pythonic）

```python
from typing import List

class Solution:
    def findOcurrences(self, text: str, first: str, second: str) -> List[str]:
        words = text.split()
        result = []
        
        # zip 将三个相邻单词配对
        for w1, w2, w3 in zip(words, words[1:], words[2:]):
            if w1 == first and w2 == second:
                result.append(w3)
        
        return result
```

### 方法四：使用 zip + 列表推导式（最简洁）

```python
from typing import List

class Solution:
    def findOcurrences(self, text: str, first: str, second: str) -> List[str]:
        words = text.split()
        
        return [
            w3 
            for w1, w2, w3 in zip(words, words[1:], words[2:])
            if w1 == first and w2 == second
        ]
```

### 方法五：正则表达式

```python
import re
from typing import List

class Solution:
    def findOcurrences(self, text: str, first: str, second: str) -> List[str]:
        # 构建正则表达式：匹配 "first second (任意单词)"
        pattern = rf'\b{first}\s+{second}\s+(\w+)'
        
        # 找到所有匹配，返回捕获组（即 third）
        return re.findall(pattern, text)
```

## 复杂度分析

**方法一、二、三、四：**
- **时间复杂度**：O(n)，其中 n 是单词总数
  - 分割字符串：O(n)
  - 遍历单词：O(n)
- **空间复杂度**：O(n)
  - words 数组：O(n)
  - result 数组：最坏 O(n)

**方法五（正则表达式）：**
- **时间复杂度**：O(m)，m 是字符串长度（正则引擎内部处理）
- **空间复杂度**：O(n)

## 图解示例

以 `text = "we will we will rock you", first = "we", second = "will"` 为例：

```
分割后：words = ["we", "will", "we", "will", "rock", "you"]

遍历过程：
i=0: words[0]="we", words[1]="will", words[2]="we"
     "we" == first ✓, "will" == second ✓
     → result.append("we")

i=1: words[1]="will", words[2]="we", words[3]="will"
     "will" != first ✗

i=2: words[2]="we", words[3]="will", words[4]="rock"
     "we" == first ✓, "will" == second ✓
     → result.append("rock")

i=3: words[3]="will", words[4]="rock", words[5]="you"
     "will" != first ✗

结果：["we", "rock"]
```

## 关键点总结

1. **字符串分割**：`split()` 默认按空格分割，自动处理多个连续空格
2. **遍历边界**：`range(len(words) - 2)` 确保不越界
3. **zip 技巧**：`zip(words, words[1:], words[2:])` 优雅地遍历三元组
4. **列表推导式**：简洁地表达筛选逻辑
5. **正则表达式**：`\b` 表示单词边界，`\w+` 匹配单词字符

## 易错点

1. **数组越界**：遍历时忘记留出 2 个位置给 second 和 third
2. **空格处理**：题目保证单个空格，但要理解 `split()` 的行为
3. **大小写**：题目说明都是小写，但实际中可能需要考虑大小写敏感
4. **zip 切片**：`words[1:]` 和 `words[2:]` 创建新列表，注意空间开销
5. **正则转义**：如果 first/second 包含特殊字符，需要转义（本题都是字母）
