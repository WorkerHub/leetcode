## 题目描述

有一幅以 `m x n` 的二维整数数组表示的图画 `image`，其中 `image[i][j]` 表示该图画的像素值大小。

你也被给予三个整数 `sr`, `sc` 和 `color`。你应该从像素 `image[sr][sc]` 开始对图像进行上色填充。

为了完成 **上色工作**：

1. 从初始像素开始，将其颜色改为 `color`。
2. 对初始坐标的 **上下左右四个方向上** 相邻且与初始像素的原始颜色同色的像素点执行相同的上色操作。
3. 通过检查与初始像素颜色相同的相邻像素并修改它们的颜色来继续 **重复** 此过程。
4. 当 **没有** 其它原始颜色的相邻像素时 **停止** 操作。

最后返回经过上色渲染 **修改** 后的图像。

**示例 1：**

```
输入：image = [[1,1,1],[1,1,0],[1,0,1]]，sr = 1, sc = 1, color = 2
输出：[[2,2,2],[2,2,0],[2,0,1]]
```

**示例 2：**

```
输入：image = [[0,0,0],[0,0,0]], sr = 0, sc = 0, color = 0
输出：[[0,0,0],[0,0,0]]
```

## 解题思路

经典的 **洪水填充（Flood Fill）** 算法，可以用 DFS 或 BFS 实现。

**核心思想：**
- 从起点开始，递归/迭代地访问四个方向
- 只访问颜色与起点原始颜色相同的像素
- 将访问过的像素染成新颜色

## Python 代码实现

### 方法一：DFS（推荐）⭐

```python
from typing import List

class Solution:
    def floodFill(self, image: List[List[int]], sr: int, sc: int, color: int) -> List[List[int]]:
        original_color = image[sr][sc]
        
        # 特殊情况：颜色相同无需填充
        if original_color == color:
            return image
        
        m, n = len(image), len(image[0])
        
        def dfs(r: int, c: int):
            # 越界检查
            if r < 0 or r >= m or c < 0 or c >= n:
                return
            
            # 颜色不匹配
            if image[r][c] != original_color:
                return
            
            # 染色
            image[r][c] = color
            
            # 四个方向递归
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)
        
        dfs(sr, sc)
        return image
```

### 方法二：BFS

```python
from collections import deque

class Solution:
    def floodFill(self, image: List[List[int]], sr: int, sc: int, color: int) -> List[List[int]]:
        original_color = image[sr][sc]
        
        if original_color == color:
            return image
        
        m, n = len(image), len(image[0])
        queue = deque([(sr, sc)])
        image[sr][sc] = color
        
        directions = [(1,0), (-1,0), (0,1), (0,-1)]
        
        while queue:
            r, c = queue.popleft()
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                
                if 0 <= nr < m and 0 <= nc < n and image[nr][nc] == original_color:
                    image[nr][nc] = color
                    queue.append((nr, nc))
        
        return image
```

## 复杂度分析

- **时间复杂度：** O(m × n)
- **空间复杂度：** O(m × n)，递归栈或队列空间

## 关键点总结

1. **避免死循环**：先判断颜色是否相同
2. **四个方向**：上下左右遍历
3. **边界检查**：防止越界
