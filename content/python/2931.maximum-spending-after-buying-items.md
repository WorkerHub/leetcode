## 题目描述

给你一个下标从 0 开始的 `m x n` 整数矩阵 `values`，其中 `values[i][j]` 表示第 `i` 个商店里第 `j` 件物品的价值。

每个商店里的物品从左到右价值非递增。你必须按以下规则购买物品：
- 每次只能从**某个商店的最右边**还未被购买的物品开始购买（从右到左依次购买每个商店的物品）
- 第 `d` 天购买的物品，花费 = `values[i][j] * d`

求购买完所有 `m * n` 件物品后的最大总花费。

**示例 1：**
```
输入：values = [[8,5,2],[6,4,1],[9,7,3]]
输出：285
```

**提示：**
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^4`
- `1 <= values[i][j] <= 10^6`
- `values[i]` 是非递增的

## 解题思路

贪心：总花费 = sum(values[i][j] * d)，d 从 1 到 m*n 递增。

为了最大化花费，应该让**价值大的物品尽量在后面（d 大）的天购买**。

约束：每个商店必须从右到左购买（从最小价值到最大价值）。

贪心策略：每次选当前各商店"最右边可购买物品"中价值**最小**的来购买（分配给当前天 d，从小到大排列保证大价值后购买）。

使用最小堆维护各商店当前可购买的最右边物品。

## Python 代码实现

### 方法一：贪心 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxSpending(self, values: List[List[int]]) -> int:
        m, n = len(values), len(values[0])

        # 初始化堆：每个商店最右边的物品 (value, shop_idx, item_idx)
        heap = []
        for i in range(m):
            # 每个商店从右边（j = n-1）开始
            heapq.heappush(heap, (values[i][n - 1], i, n - 1))

        ans = 0
        day = 1

        while heap:
            val, shop, j = heapq.heappop(heap)
            ans += val * day
            day += 1
            # 若该商店还有更左边的物品，加入堆
            if j > 0:
                heapq.heappush(heap, (values[shop][j - 1], shop, j - 1))

        return ans
```

### 方法二：排序所有物品（简化版）

```python
from typing import List

class Solution:
    def maxSpending(self, values: List[List[int]]) -> int:
        # 每行从右到左的顺序被固定
        # 但不同行之间可以交叉
        # 贪心：将所有可用物品排序，从小到大依次购买（分配天数 1, 2, ...）
        # 关键：某物品"可用"当且仅当其右侧的所有物品已被购买
        # 但由于每行价值非递增，右边物品价值 <= 左边物品价值
        # 因此全局最小值一定来自某行的最右边可用物品

        # 将所有物品展平，按价值排序（需保证顺序约束）
        # 由于每行非递增，各行可以单独考虑顺序，用堆维护
        m, n = len(values), len(values[0])
        import heapq
        heap = [(values[i][n - 1], i, n - 1) for i in range(m)]
        heapq.heapify(heap)

        ans = 0
        for day in range(1, m * n + 1):
            val, i, j = heapq.heappop(heap)
            ans += val * day
            if j > 0:
                heapq.heappush(heap, (values[i][j - 1], i, j - 1))

        return ans
```

## 复杂度分析

- 时间复杂度：O(mn log m)，共 mn 次堆操作，堆大小最多 m
- 空间复杂度：O(m)，堆大小

## 关键点总结

1. 贪心：价值小的物品在早期（d 小）购买，价值大的在后期（d 大）购买，最大化总花费
2. 每次从堆中取出当前最小价值的可购买物品
3. 每行从右到左的约束自动被堆维护（购买后将左边的物品加入堆）

## 易错点

1. 物品购买顺序：每个商店从最右边（最小价值）开始，向左购买
2. 天数从 1 开始，最后一天购买最贵的物品
3. 最大化花费：贪心地让价值大的物品等到天数大时再买
