## 题目描述

给你一支股票价格的数据流。数据流包含时间戳和对应的股票价格。

需要设计一个算法，支持以下操作：
- `update(timestamp, price)`：更新时间戳对应的价格（同一时间戳可能多次更新，以最新的为准）
- `current()`：返回当前最新时间戳的价格
- `maximum()`：返回当前所有时间点的最高价格
- `minimum()`：返回当前所有时间点的最低价格

**示例：**
```
输入：
["StockPrice", "update", "update", "current", "maximum", "update", "maximum", "minimum"]
[[], [1,10], [2,5], [], [], [1,3], [], []]
输出：
[null, null, null, 5, 10, null, 5, 3]
```

**提示：**
- `1 <= timestamp, price <= 10^9`
- `update`、`current`、`maximum`、`minimum` 调用次数不超过 `10^5`

## 解题思路

- 用哈希表 `timestamp_price` 记录每个时间戳的最新价格
- 用变量 `latest_ts` 记录最新时间戳
- 用**有序容器**（如 Python 的 `SortedList`）维护所有价格，支持最大最小值查询

当同一时间戳更新时，需要从有序容器中删除旧价格，插入新价格。

## 代码实现

### 方法一：哈希表 + SortedList（推荐）

```python
from sortedcontainers import SortedList

class StockPrice:

    def __init__(self):
        self.timestamp_price = {}  # 时间戳 -> 最新价格
        self.prices = SortedList()  # 有序价格列表
        self.latest_ts = 0

    def update(self, timestamp: int, price: int) -> None:
        if timestamp in self.timestamp_price:
            # 删除旧价格
            old_price = self.timestamp_price[timestamp]
            self.prices.remove(old_price)

        # 更新价格
        self.timestamp_price[timestamp] = price
        self.prices.add(price)

        # 更新最新时间戳
        if timestamp >= self.latest_ts:
            self.latest_ts = timestamp

    def current(self) -> int:
        return self.timestamp_price[self.latest_ts]

    def maximum(self) -> int:
        return self.prices[-1]  # 有序列表的最后一个元素

    def minimum(self) -> int:
        return self.prices[0]   # 有序列表的第一个元素
```

### 方法二：哈希表 + 双堆（懒删除）

```python
import heapq

class StockPrice:

    def __init__(self):
        self.timestamp_price = {}
        self.max_heap = []  # 最大堆（取反模拟）
        self.min_heap = []  # 最小堆
        self.latest_ts = 0

    def update(self, timestamp: int, price: int) -> None:
        self.timestamp_price[timestamp] = price
        heapq.heappush(self.min_heap, price)
        heapq.heappush(self.max_heap, -price)
        if timestamp >= self.latest_ts:
            self.latest_ts = timestamp

    def current(self) -> int:
        return self.timestamp_price[self.latest_ts]

    def maximum(self) -> int:
        # 懒删除：堆顶如果不再是最新价格则弹出
        while True:
            price = -self.max_heap[0]
            # 检查是否有任意时间戳的价格等于 price（无法直接验证，需要维护计数）
            # 此方法需要额外计数，较复杂，使用 SortedList 更简洁
            break
        return price

    def minimum(self) -> int:
        return self.min_heap[0]
```

### 方法三：正确的懒删除双堆

```python
import heapq
from collections import defaultdict

class StockPrice:

    def __init__(self):
        self.prices = {}  # timestamp -> price
        self.max_heap = []  # (-price, timestamp)
        self.min_heap = []  # (price, timestamp)
        self.latest = 0

    def update(self, timestamp: int, price: int) -> None:
        self.prices[timestamp] = price
        heapq.heappush(self.max_heap, (-price, timestamp))
        heapq.heappush(self.min_heap, (price, timestamp))
        if timestamp >= self.latest:
            self.latest = timestamp

    def current(self) -> int:
        return self.prices[self.latest]

    def maximum(self) -> int:
        # 懒删除：检查堆顶是否与最新价格一致
        while -self.max_heap[0][0] != self.prices[self.max_heap[0][1]]:
            heapq.heappop(self.max_heap)
        return -self.max_heap[0][0]

    def minimum(self) -> int:
        while self.min_heap[0][0] != self.prices[self.min_heap[0][1]]:
            heapq.heappop(self.min_heap)
        return self.min_heap[0][0]
```

## 复杂度分析

| 操作 | SortedList | 双堆（懒删除） |
|------|-----------|-------------|
| update | O(log n) | O(log n) |
| current | O(1) | O(1) |
| maximum | O(1) | O(log n) |
| minimum | O(1) | O(log n) |

## 关键点总结

1. 同一时间戳可能多次更新，需要维护时间戳到最新价格的映射
2. `SortedList` 支持 O(log n) 插入/删除，是最简洁的方案
3. 双堆懒删除：更新时只插入，查询时检查堆顶是否过期

## 易错点

- 最新时间戳更新：只要新时间戳 >= 当前最新时间戳就更新（注意等号）
- 懒删除必须通过 `(price, timestamp)` 对检验，仅靠 price 不唯一
- `SortedList.remove` 删除的是值，若有重复会只删一个（正确行为）
