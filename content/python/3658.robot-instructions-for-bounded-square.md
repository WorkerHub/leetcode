## 题目描述

在一个无限大的二维平面上有一个机器人，初始位置为 `(0,0)`，面向北方。指令集合为 `G`（前进一步）、`L`（向左转 90 度）、`R`（向右转 90 度）。

执行指令字符串一次后，判断机器人是否在有界圆内（即无论重复执行多少次指令，机器人始终在以原点为中心的某个圆内）。

**示例 1：**

```
输入：instructions = "GGLLGG"
输出：true
解释：执行后：(0,2)，方向北。执行两次回到(0,0)。有界
```

**示例 2：**

```
输入：instructions = "GG"
输出：false
解释：每次执行后位置持续增加，无界
```

**示例 3：**

```
输入：instructions = "GL"
输出：true
解释：执行4次后回到原点
```

**提示：**

- `1 <= instructions.length <= 100`
- `instructions[i]` 为 `'G'`、`'L'` 或 `'R'`

## 解题思路

执行一次指令后，判断是否有界的充要条件：

1. 执行后机器人回到原点，或
2. 执行后机器人不朝北（面向其他方向则循环 2 次或 4 次会回到原点）

证明：
- 若回到原点，下次也从原点开始，有界
- 若面向东/西，两次循环后位移相消，有界
- 若面向南，一次正好抵消，有界
- 若面向北且不在原点，每次都同方向漂移，无界

## Python 代码实现

### 方法一：模拟一次（推荐）

```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        # 方向：0=北, 1=东, 2=南, 3=西
        x, y = 0, 0
        direction = 0  # 初始朝北
        dx = [0, 1, 0, -1]  # 北东南西 x 偏移
        dy = [1, 0, -1, 0]  # 北东南西 y 偏移

        for cmd in instructions:
            if cmd == 'G':
                x += dx[direction]
                y += dy[direction]
            elif cmd == 'L':
                direction = (direction - 1) % 4
            else:  # 'R'
                direction = (direction + 1) % 4

        # 有界条件：回到原点，或方向不朝北
        return (x == 0 and y == 0) or direction != 0
```

### 方法二：模拟四次验证

```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        def simulate(x, y, d):
            dx = [0, 1, 0, -1]
            dy = [1, 0, -1, 0]
            for cmd in instructions:
                if cmd == 'G':
                    x += dx[d]
                    y += dy[d]
                elif cmd == 'L':
                    d = (d - 1) % 4
                else:
                    d = (d + 1) % 4
            return x, y, d

        x, y, d = 0, 0, 0
        for _ in range(4):
            x, y, d = simulate(x, y, d)
        return x == 0 and y == 0
```

## 复杂度分析

- 时间复杂度：O(n)，n 为指令长度
- 空间复杂度：O(1)

## 关键点总结

1. 有界充要条件：执行一次后（1）回到原点，或（2）不朝北
2. 不朝北时最多执行 4 次指令即可回到原点
3. 只需模拟一次指令执行

## 易错点

1. 向左转：方向减 1（北→西→南→东→北）
2. 向右转：方向加 1（北→东→南→西→北）
3. 初始方向为北（index 0）
