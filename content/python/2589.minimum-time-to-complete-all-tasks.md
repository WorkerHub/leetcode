## 题目描述

有 `n` 台电脑需要执行一系列任务。给你一个二维整数数组 `tasks`，其中 `tasks[i] = [start_i, end_i, duration_i]`，表示第 `i` 个任务需要在 `[start_i, end_i]` 的时间段内运行恰好 `duration_i` 个单位时间。

你可以在每台电脑的任意时刻运行多个任务（但每个任务只由一台电脑执行），每个任务可以在其时间段内的任意时刻运行（不需要连续）。

返回完成所有任务所需的 **最少** 运行时间。

**示例 1：**

```
输入：tasks = [[2,3,1],[4,5,1],[1,5,2]]
输出：2
```

**示例 2：**

```
输入：tasks = [[1,3,2],[2,5,3],[5,6,2]]
输出：4
```

**提示：**

- `1 <= tasks.length <= 2000`
- `tasks[i].length == 3`
- `1 <= start_i <= end_i <= 2000`
- `1 <= duration_i <= end_i - start_i + 1`

## 解题思路

**贪心 + 排序**：

1. 按 `end` 升序排序（截止时间早的优先处理）
2. 用一个布尔数组 `run[1..2000]` 标记哪些时刻已经在运行
3. 对每个任务 `[start, end, duration]`：
   - 先统计 `[start, end]` 内已经标记运行的时刻数 `already`
   - 还需要额外运行 `need = duration - already` 个时刻
   - 从 `end` 向左贪心地选尚未标记的时刻（越靠右越好，与后面任务重叠概率更高）

这是一个经典的区间调度贪心问题。

## Python 代码实现

### 方法一：贪心 + 差分/标记数组（推荐）

```python
from typing import List

class Solution:
    def findMinimumTime(self, tasks: List[List[int]]) -> int:
        # 按截止时间升序排序
        tasks.sort(key=lambda x: x[1])

        MAX_T = 2001
        run = [False] * MAX_T  # run[t] 表示时刻 t 是否已安排运行

        for start, end, duration in tasks:
            # 统计 [start, end] 内已运行的时刻数
            already = sum(run[t] for t in range(start, end + 1))
            need = duration - already
            if need <= 0:
                continue
            # 从右向左贪心选取尚未运行的时刻
            t = end
            while need > 0:
                if not run[t]:
                    run[t] = True
                    need -= 1
                t -= 1

        return sum(run)
```

### 方法二：用前缀和加速计算 already

```python
from typing import List

class Solution:
    def findMinimumTime(self, tasks: List[List[int]]) -> int:
        tasks.sort(key=lambda x: x[1])

        MAX_T = 2001
        run = [0] * MAX_T  # 0 或 1

        for start, end, duration in tasks:
            # 用前缀和快速统计已运行时刻
            already = sum(run[start:end + 1])
            need = duration - already
            t = end
            while need > 0:
                if run[t] == 0:
                    run[t] = 1
                    need -= 1
                t -= 1

        return sum(run)
```

## 复杂度分析

- 时间复杂度：O(n * T)，T = 2000，n 为任务数
- 空间复杂度：O(T)，标记数组

## 关键点总结

1. 按截止时间排序，优先处理截止时间早的任务
2. 从右向左贪心填充：靠近截止时间的时刻与后续任务重叠概率更高，节省更多空间
3. 先利用已有的运行时刻，减少额外需求

## 易错点

1. `already` 要实时计算（之前处理其他任务可能已标记部分时刻）
2. 从右向左选（不是从左向右），这样贪心最优
3. 时间范围 1 到 2000，数组大小为 2001
