## 题目描述

给你两个长度相等的整数数组 `price` 和 `tastiness`，长度均为 `n`。同时给你两个整数 `maxAmount` 和 `maxCoupons`。

你打算用 **最多** `maxAmount` 钱买一些水果。另外，你还有 `maxCoupons` 张优惠券，可以将某个水果的价格减半。每种水果最多能购买 **一次**，每张优惠券只能在 **一种** 水果上使用，同一种水果只能使用 **一次** 优惠券。

返回购买任意数量水果所能获得的 **最大** 总美味值。

**提示：**
- `n == price.length == tastiness.length`
- `1 <= n <= 100`
- `0 <= price[i] <= 10^3`
- `0 <= tastiness[i] <= 10^3`
- `0 <= maxAmount <= 10^5`
- `0 <= maxCoupons <= 5`

## 解题思路

**背包动态规划：**

每个水果有三种选择：
1. 不买
2. 原价买（花费 `price[i]`）
3. 半价买（花费 `price[i] // 2`，使用一张优惠券）

这是一个二维背包问题：
- 状态：`dp[j][k]` = 花费 j 元、使用 k 张优惠券的最大美味值
- 维度：j ∈ [0, maxAmount]，k ∈ [0, maxCoupons]

**转移方程：**
- 不买：`dp[j][k]` 不变
- 原价买：`dp[j][k] = max(dp[j][k], dp[j - price[i]][k] + tastiness[i])`
- 半价买：`dp[j][k] = max(dp[j][k], dp[j - price[i]//2][k-1] + tastiness[i])`

## 代码实现

### 方法一：二维背包 DP（推荐）

```python
from typing import List

class Solution:
    def maxTastiness(self, price: List[int], tastiness: List[int], maxAmount: int, maxCoupons: int) -> int:
        n = len(price)
        # dp[j][k] = 花费 j 元，使用 k 张优惠券，能获得的最大美味值
        dp = [[0] * (maxCoupons + 1) for _ in range(maxAmount + 1)]

        for i in range(n):
            p, t = price[i], tastiness[i]
            # 逆序遍历（0/1 背包），防止同一水果重复选
            for j in range(maxAmount, -1, -1):
                for k in range(maxCoupons, -1, -1):
                    # 选择一：不买，dp[j][k] 不变
                    # 选择二：原价买
                    if j >= p:
                        dp[j][k] = max(dp[j][k], dp[j - p][k] + t)
                    # 选择三：用优惠券买（价格减半）
                    half = p // 2
                    if k >= 1 and j >= half:
                        dp[j][k] = max(dp[j][k], dp[j - half][k - 1] + t)

        return dp[maxAmount][maxCoupons]
```

### 方法二：三维 DP（更直观）

```python
from typing import List

class Solution:
    def maxTastiness(self, price: List[int], tastiness: List[int], maxAmount: int, maxCoupons: int) -> int:
        n = len(price)
        # 先初始化为 0
        INF = float('inf')
        # dp[i][j][k] = 考虑前 i 种水果，花 j 元用 k 张券的最大美味
        # 为节省内存，只保留上一行
        dp = [[0] * (maxCoupons + 1) for _ in range(maxAmount + 1)]

        for i in range(n):
            # 逆序遍历，0/1 背包
            for j in range(maxAmount, -1, -1):
                for k in range(maxCoupons, -1, -1):
                    # 原价买
                    if j >= price[i]:
                        dp[j][k] = max(dp[j][k], dp[j - price[i]][k] + tastiness[i])
                    # 半价买
                    half = price[i] // 2
                    if k >= 1 and j >= half:
                        dp[j][k] = max(dp[j][k], dp[j - half][k - 1] + tastiness[i])

        return dp[maxAmount][maxCoupons]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维背包 DP | O(n * maxAmount * maxCoupons) | O(maxAmount * maxCoupons) |

n=100，maxAmount=10^5，maxCoupons=5，共约 5*10^7 次操作，可以接受。

## 关键点总结

1. 每个水果三种选择：不买、原价、半价（用券）
2. 两个约束维度：总金额和优惠券数量
3. 0/1 背包逆序遍历，防止重复选择同一水果

## 易错点

- 逆序遍历两个维度（j 和 k），保证 0/1 背包的正确性
- 价格减半：`price[i] // 2`（整数除法，向下取整）
