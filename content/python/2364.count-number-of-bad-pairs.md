## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。如果 `i < j` 且 `j - i != nums[j] - nums[i]`，则称 `(i, j)` 是一个**坏数对**。

返回 `nums` 中坏数对的总数目。

**示例 1：**
```
输入：nums = [4,1,3,3]
输出：5
解释：总数对 C(4,2)=6 个，其中 (0,3) 是好数对（4-1=3-3 不对...），实际好数对只有 1 个，坏数对有 5 个。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**转化：**
`j - i == nums[j] - nums[i]` 等价于 `nums[j] - j == nums[i] - i`。

因此，**好数对**的特征是 `nums[i] - i` 值相同。

总数对数为 `n*(n-1)/2`，减去好数对数即为坏数对数。

用哈希表统计每个 `nums[i] - i` 的出现次数，若某值出现 k 次，则这 k 个下标互相构成 `C(k,2) = k*(k-1)/2` 个好数对。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countBadPairs(self, nums: List[int]) -> int:
        n = len(nums)
        total = n * (n - 1) // 2  # 总数对数
        
        # 统计 nums[i] - i 的频率
        diff_count = Counter(nums[i] - i for i in range(n))
        
        # 好数对数
        good = sum(c * (c - 1) // 2 for c in diff_count.values())
        
        return total - good
```

### 方法二：逐步累计

```python
from typing import List

class Solution:
    def countBadPairs(self, nums: List[int]) -> int:
        seen = {}
        ans = 0
        
        for i, x in enumerate(nums):
            key = x - i
            # 前面有 seen[key] 个相同 key 的元素，形成 seen[key] 个好数对
            # 因此坏数对 = i - seen[key]（与前面所有元素配对，减去好数对）
            ans += i - seen.get(key, 0)
            seen[key] = seen.get(key, 0) + 1
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(n) |

## 关键点总结

1. `j - i == nums[j] - nums[i]` 变形为 `nums[i] - i == nums[j] - j`。
2. 坏数对 = 总数对 - 好数对。
3. 好数对数为每组 `nums[i]-i` 相同的下标的组合数之和。

## 易错点

- 总数对是有序的 `(i, j)` 其中 `i < j`，共 `n*(n-1)/2` 个。
- 注意 `nums[i] - i` 可能为负数，但哈希表可以处理。
