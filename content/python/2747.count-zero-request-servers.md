## 题目描述

给你一个整数 `n`，表示服务器数目（编号 1 到 n），以及一个二维整数数组 `logs`（`logs[i] = [server_id, time]`）表示服务器请求日志，以及查询数组 `queries`（`queries[i] = [l, r]`）。

对每个查询 `[l, r]`，返回在时间范围 `[l, r]` 内 **没有收到任何请求** 的服务器数目。

**示例：**
```
输入：n = 3, logs = [[1,3],[2,6],[1,5]], queries = [[2,4],[6,6]]
输出：[1,2]
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= logs.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

**离线处理 + 滑动窗口**：

1. 将查询按右端 `r` 排序，用指针维护滑动窗口 `[l, r]`
2. 用哈希表统计窗口内出现的服务器及其计数
3. 窗口内活跃服务器数 = 哈希表大小，答案 = `n - 活跃数`

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countServers(self, n: int, logs: List[List[int]], x: int, queries: List[List[int]]) -> List[int]:
        # 日志按时间排序
        logs.sort(key=lambda a: a[1])
        # 查询按右端排序，记录原始下标
        sorted_queries = sorted(enumerate(queries), key=lambda a: a[1][1])

        ans = [0] * len(queries)
        cnt = defaultdict(int)  # 服务器出现次数
        active = 0  # 窗口内活跃服务器数
        left = 0    # 日志左指针
        right = 0   # 日志右指针

        for qi, (l, r) in sorted_queries:
            # 扩展右端：加入所有 time <= r 的日志
            while right < len(logs) and logs[right][1] <= r:
                sid = logs[right][0]
                if cnt[sid] == 0:
                    active += 1
                cnt[sid] += 1
                right += 1
            # 收缩左端：移除所有 time < l 的日志
            while left < right and logs[left][1] < l:
                sid = logs[left][0]
                cnt[sid] -= 1
                if cnt[sid] == 0:
                    active -= 1
                left += 1
            ans[qi] = n - active

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，排序
- 空间复杂度：O(n + q)

## 关键点总结

1. 离线按查询右端排序，配合双指针维护滑动窗口
2. 哈希表维护窗口内活跃服务器集合
3. 答案 = 总服务器数 - 活跃服务器数

## 易错点

1. 查询按右端排序，不是按左端
2. 日志的时间范围是 `[l, r]`，闭区间
