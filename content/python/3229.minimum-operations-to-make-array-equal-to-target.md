## 题目描述

给你两个长度相同的正整数数组 `nums` 和 `target`。

每次操作，你可以选择 `nums` 的一个**连续子数组**，将其所有元素加 1 或减 1。

返回使 `nums` 等于 `target` 所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [3,5,1,2], target = [4,6,2,4]
输出：2
```

**示例 2：**
```
输入：nums = [1,3,2], target = [2,1,4]
输出：5
```

**提示：**
- `1 <= nums.length == target.length <= 10^5`
- `1 <= nums[i], target[i] <= 10^8`

## 解题思路

将问题转化：令 `diff[i] = target[i] - nums[i]`，问题变为：用最少次数的区间加减 1 操作使 `diff` 全变 0。

这等价于计算 `diff` 数组的"变化量"：每次"增长段"需要一定次数的+1操作，每次"减少段"需要一定次数的-1操作。

最优次数 = 正差分之和（diff 从负到正的增量）+ 负差分的绝对值之和（diff 从正到负的增量）。

即：`sum(max(0, diff[i] - diff[i-1]) for i in range(n))` 加上 `sum(max(0, diff[i-1] - diff[i]) for i in range(n))`，但这两者加起来等于 `diff` 数组的"总变化量"，最终为 `sum(abs(d[i] - d[i-1]))` 的一半... 

实际正确公式：类比"最少操作使数组全为0的区间操作"，答案是差分数组的正部分之和：`diff[0]正部分 + sum(max(0, diff[i]-diff[i-1]))` 中的正部分。

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int], target: List[int]) -> int:
        n = len(nums)
        # d[i] = target[i] - nums[i]，需要对 d 做最少区间操作使其全为 0
        d = [target[i] - nums[i] for i in range(n)]
        
        # 最少区间操作次数 = 差分数组正值之和 + 差分数组负值绝对值之和
        # 等价于：abs(d[0]) + sum(max(0, abs(d[i]) - abs(d[i-1])) ...)
        # 实际：操作次数 = 正的"上升沿"之和 + 负的"下降沿"绝对值之和
        # 更简单的公式：max(0, d[0]) + sum(max(0, d[i]-d[i-1]) for i in 1..n-1)
        #             + max(0, -d[0]) + sum(max(0, d[i-1]-d[i]) for ...)
        # 这等于 sum(max(0, d[i]-d[i-1])) + max(0, d[0]) if d[0]>0
        # 不对，让我重推
        
        # 标准结论：对数组做最少区间加减1操作使其全为0
        # = 差分数组（包含边界 0）中正值之和
        # diff = d[0], d[1]-d[0], ..., d[n-1]-d[n-2], -d[n-1]
        # 正值之和 = max(0,d[0]) + sum(max(0,d[i]-d[i-1])) + max(0,-d[n-1])
        # 由于 sum(所有正变化) = sum(所有负变化的绝对值)（总和为0）
        # 所以 正值之和 = 负值绝对值之和 = 总操作次数
        
        ans = max(0, d[0]) + max(0, -d[-1])
        for i in range(1, n):
            delta = d[i] - d[i - 1]
            if delta > 0:
                ans += delta  # 上升需要额外的加法操作
        # 实际上只要统计上升部分即可
        # 等价于：ans = max(0, d[0]) + sum(max(0, d[i]-d[i-1]) for i in 1..n-1)
        
        return ans
```

### 方法二：正确公式

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int], target: List[int]) -> int:
        n = len(nums)
        d = [target[i] - nums[i] for i in range(n)]
        
        ans = abs(d[0])
        for i in range(1, n):
            # 如果方向相同且新值更大（绝对值增大），需要额外操作
            if d[i] > 0 and d[i] > d[i - 1]:
                ans += d[i] - max(0, d[i - 1])
            elif d[i] < 0 and d[i] < d[i - 1]:
                ans += abs(d[i]) - abs(min(0, d[i - 1]))
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 转化为差分数组 `d = target - nums`，问题变为最少操作使 d 全零
2. 操作次数 = diff(d) 中正值之和（即 d 上升的总量 + 初始正值）
3. 贪心：相邻上升段复用之前的操作

## 易错点

1. 差分数组中要考虑首尾边界
2. 正负方向的变化要分别处理
