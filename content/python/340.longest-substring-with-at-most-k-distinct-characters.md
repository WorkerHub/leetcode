## 题目描述

给定一个字符串 `s` 和一个整数 `k`，返回**至多包含 `k` 个不同字符**的最长子串的长度。

**示例 1:**

```
输入：s = "eceba", k = 2
输出：3
解释：满足条件的子串是 "ece"，长度为 3。
```

**示例 2:**

```
输入：s = "aa", k = 1
输出：2
解释：满足条件的子串是 "aa"，长度为 2。
```

**提示:**

- `1 <= s.length <= 5 * 10^4`
- `0 <= k <= 50`

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题是经典的**滑动窗口**问题。

### 核心思想

1. **滑动窗口维护**：
   - 使用哈希表记录窗口内每个字符的出现次数
   - 维护窗口内不同字符的数量

2. **窗口扩展**：
   - 右指针右移，将新字符加入窗口
   - 更新字符计数

3. **窗口收缩**：
   - 当不同字符数 > k 时，左指针右移
   - 移除左边界字符，更新计数
   - 如果某字符计数为 0，从哈希表删除

4. **更新最大长度**：
   - 每次窗口合法时（不同字符数 <= k），更新最大长度

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）⭐

```python
from collections import defaultdict

class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        """
        滑动窗口：维护至多 k 个不同字符
        """
        if k == 0:
            return 0
        
        char_count = defaultdict(int)  # 字符计数
        left = 0
        max_len = 0
        
        for right in range(len(s)):
            # 扩展窗口：加入右边界字符
            char_count[s[right]] += 1
            
            # 收缩窗口：保持不同字符数 <= k
            while len(char_count) > k:
                char_count[s[left]] -= 1
                if char_count[s[left]] == 0:
                    del char_count[s[left]]
                left += 1
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

### 方法三：使用普通字典

```python
class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        """
        使用普通字典
        """
        if k == 0:
            return 0
        
        char_count = {}
        left = 0
        max_len = 0
        
        for right in range(len(s)):
            # 加入右边界字符
            if s[right] in char_count:
                char_count[s[right]] += 1
            else:
                char_count[s[right]] = 1
            
            # 收缩窗口
            while len(char_count) > k:
                char_count[s[left]] -= 1
                if char_count[s[left]] == 0:
                    del char_count[s[left]]
                left += 1
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

### 方法四：优化的滑动窗口（记录字符位置）

```python
class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        """
        记录每个字符最右边的位置，优化收缩过程
        """
        if k == 0:
            return 0
        
        char_index = {}  # 记录每个字符最右边的位置
        left = 0
        max_len = 0
        
        for right in range(len(s)):
            # 更新字符位置
            char_index[s[right]] = right
            
            # 收缩窗口：删除最左边的字符
            if len(char_index) > k:
                # 找到最左边字符的位置
                leftmost_index = min(char_index.values())
                del char_index[s[leftmost_index]]
                left = leftmost_index + 1
            
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
        
        return max_len
```

### 方法五：暴力解法（会超时）

```python
class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        """
        暴力解法：枚举所有子串
        时间复杂度 O(n^2)
        """
        if k == 0:
            return 0
        
        max_len = 0
        n = len(s)
        
        for i in range(n):
            char_set = set()
            for j in range(i, n):
                char_set.add(s[j])
                
                if len(char_set) <= k:
                    max_len = max(max_len, j - i + 1)
                else:
                    break  # 不同字符数超过 k，停止扩展
        
        return max_len
```

## 复杂度分析

**方法一/二/三：滑动窗口**

- **时间复杂度**：O(n)
  - 左右指针各遍历一次数组
  - 哈希表操作 O(1)
  
- **空间复杂度**：O(k)
  - 哈希表最多存储 k+1 个字符

**方法四：优化的滑动窗口**

- **时间复杂度**：O(n * k)
  - 每次收缩需要 O(k) 找最小值
  
- **空间复杂度**：O(k)

**方法五：暴力解法**

- **时间复杂度**：O(n^2)
  - 双层循环
  
- **空间复杂度**：O(k)
  - 集合最多存储 k 个字符

## 关键点总结

1. **滑动窗口模板**：
   - 右指针扩展窗口
   - 左指针收缩窗口
   - 更新最大值

2. **哈希表维护**：
   - 记录窗口内每个字符的出现次数
   - 计数为 0 时删除，保持哈希表大小 = 不同字符数

3. **窗口收缩条件**：`len(char_count) > k`

4. **长度计算**：`right - left + 1`

5. **边界情况**：
   - `k = 0`：返回 0
   - `k >= len(set(s))`：返回 `len(s)`

## 易错点

1. **忘记删除计数为 0 的字符**：
   - 必须 `del char_count[s[left]]`
   - 否则 `len(char_count)` 不准确

2. **窗口收缩条件**：
   - 正确：`while len(char_count) > k`
   - 错误：`while len(char_count) >= k`

3. **最大长度更新时机**：
   - 应该在窗口合法时更新
   - 即收缩窗口之后

4. **k = 0 的处理**：
   - 特殊情况，需要单独处理

5. **字符计数递减**：
   - 要先递减再判断是否删除
   - 不能先删除再递减

## 图解示例

示例 1：`s = "eceba", k = 2`

```
初始: left = 0, char_count = {}, max_len = 0

right = 0, s[0] = 'e':
  char_count = {'e': 1}, len = 1
  max_len = 1

right = 1, s[1] = 'c':
  char_count = {'e': 1, 'c': 1}, len = 2
  max_len = 2

right = 2, s[2] = 'e':
  char_count = {'e': 2, 'c': 1}, len = 2
  max_len = 3

right = 3, s[3] = 'b':
  char_count = {'e': 2, 'c': 1, 'b': 1}, len = 3
  不同字符数 > 2，收缩窗口：
    移除 s[0] = 'e': char_count = {'e': 1, 'c': 1, 'b': 1}
    仍然 > 2，继续收缩：
    移除 s[1] = 'c': char_count = {'e': 1, 'b': 1}
    left = 2
  max_len = 3 (right - left + 1 = 3 - 2 + 1 = 2)

right = 4, s[4] = 'a':
  char_count = {'e': 1, 'b': 1, 'a': 1}, len = 3
  不同字符数 > 2，收缩窗口：
    移除 s[2] = 'e': char_count = {'b': 1, 'a': 1}
    left = 3
  max_len = 3

最终: max_len = 3
```
