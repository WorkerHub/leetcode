## 题目描述

在商店中，有 n 件商品，每件商品都有一个价格 price。

商店提供了一些大礼包 special，每个大礼包包含特定数量的商品和一个价格。

给定你需要购买的商品清单 needs，返回满足购买清单的最低价格。

**示例 1：**
```
输入：price = [2,5], special = [[3,0,5],[1,2,10]], needs = [3,2]
输出：14
解释：
有两种购买方式：
1. 直接购买：2*3 + 5*2 = 16
2. 使用大礼包：5 + 2*2 + 5 = 14（一个大礼包 + 单独购买）
```

**提示：**
- n == price.length
- n == needs.length
- 1 <= n <= 6
- 0 <= price[i] <= 10
- 0 <= needs[i] <= 10
- 1 <= special.length <= 100

## 解题思路

使用记忆化搜索（DFS + 缓存）来尝试所有可能的购买方案。

## Python 代码实现

### 方法一：记忆化搜索

```python
from typing import List

class Solution:
    def shoppingOffers(self, price: List[int], special: List[List[int]], needs: List[int]) -> int:
        memo = {}
        
        def dfs(cur_needs):
            # 转换为元组用于哈希
            key = tuple(cur_needs)
            if key in memo:
                return memo[key]
            
            # 不使用任何大礼包的价格
            res = sum(cur_needs[i] * price[i] for i in range(len(price)))
            
            # 尝试使用每个大礼包
            for offer in special:
                # 检查是否可以使用此大礼包
                new_needs = []
                valid = True
                for i in range(len(needs)):
                    if cur_needs[i] < offer[i]:
                        valid = False
                        break
                    new_needs.append(cur_needs[i] - offer[i])
                
                if valid:
                    # 使用此大礼包
                    res = min(res, offer[-1] + dfs(new_needs))
            
            memo[key] = res
            return res
        
        return dfs(needs)
```

## 复杂度分析

- 时间复杂度：O(m * k^n)，m 是大礼包数量，k 是商品数量上限，n 是商品种类
- 空间复杂度：O(k^n)

## 关键点总结

1. 使用记忆化避免重复计算
2. 检查大礼包是否可用
3. 比较使用和不使用大礼包的价格
