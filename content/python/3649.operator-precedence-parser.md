## 题目描述

给你一个数学表达式字符串，包含整数、运算符 `+`、`-`、`*`、`/` 和括号，按照标准运算符优先级（先乘除后加减，括号最高）计算并返回结果。

**示例 1：**

```
输入：s = "3+2*2"
输出：7
```

**示例 2：**

```
输入：s = " 3/2 "
输出：1
```

**示例 3：**

```
输入：s = " 3+5 / 2 "
输出：5
```

**提示：**

- `1 <= s.length <= 3 * 10^5`
- `s` 由整数、`+`、`-`、`*`、`/` 和空格组成
- 整数和运算符之间有至少一个空格分隔

## 解题思路

**双栈法**：使用操作数栈和运算符栈，按运算符优先级处理。

或者**递归下降解析器**：
- `expr → term (('+' | '-') term)*`
- `term → factor (('*' | '/') factor)*`
- `factor → number | '(' expr ')'`

## Python 代码实现

### 方法一：双栈（推荐）

```python
class Solution:
    def calculate(self, s: str) -> int:
        stack = []
        num = 0
        op = '+'
        s = s.strip()
        i = 0

        while i < len(s):
            c = s[i]
            if c.isdigit():
                num = num * 10 + int(c)
            if c == '(':
                # 找匹配的右括号，递归计算
                cnt = 1
                j = i + 1
                while cnt > 0:
                    if s[j] == '(':
                        cnt += 1
                    elif s[j] == ')':
                        cnt -= 1
                    j += 1
                num = self.calculate(s[i + 1:j - 1])
                i = j - 1

            if (c in '+-*/' or i == len(s) - 1) and c != ' ':
                if op == '+':
                    stack.append(num)
                elif op == '-':
                    stack.append(-num)
                elif op == '*':
                    stack.append(stack.pop() * num)
                elif op == '/':
                    stack.append(int(stack.pop() / num))  # 向零截断
                op = c
                num = 0
            i += 1

        return sum(stack)
```

### 方法二：递归下降解析器

```python
class Solution:
    def calculate(self, s: str) -> int:
        tokens = []
        i = 0
        while i < len(s):
            if s[i].isdigit():
                j = i
                while j < len(s) and s[j].isdigit():
                    j += 1
                tokens.append(int(s[i:j]))
                i = j
            elif s[i] in '+-*/()':
                tokens.append(s[i])
                i += 1
            else:
                i += 1

        pos = [0]

        def parse_expr():
            result = parse_term()
            while pos[0] < len(tokens) and tokens[pos[0]] in '+-':
                op = tokens[pos[0]]
                pos[0] += 1
                right = parse_term()
                result = result + right if op == '+' else result - right
            return result

        def parse_term():
            result = parse_factor()
            while pos[0] < len(tokens) and tokens[pos[0]] in '*/':
                op = tokens[pos[0]]
                pos[0] += 1
                right = parse_factor()
                result = result * right if op == '*' else int(result / right)
            return result

        def parse_factor():
            if tokens[pos[0]] == '(':
                pos[0] += 1
                result = parse_expr()
                pos[0] += 1  # ')'
                return result
            val = tokens[pos[0]]
            pos[0] += 1
            return val

        return parse_expr()
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈深度

## 关键点总结

1. 双栈法：遇到低优先级运算符时处理栈顶
2. 除法向零截断：`int(a / b)` 而非 `a // b`
3. 递归下降：按语法规则分层解析

## 易错点

1. 负数处理：`-` 开头的表达式需将 0 先入栈
2. 除法向零截断（负数时 `//` 与 `int(/)` 不同）
3. 括号匹配时需要递归处理嵌套
