## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。请你将 `nums` 中**偶数下标**的元素**升序**排序，将**奇数下标**的元素**降序**排序，然后返回重排后的数组。

**示例 1：**
```
输入：nums = [4,1,2,3]
输出：[2,3,4,1]
解释：偶数下标元素 [4,2] 升序 -> [2,4]；奇数下标元素 [1,3] 降序 -> [3,1]。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

分别提取偶数下标和奇数下标的元素，分别排序（偶数升序，奇数降序），再按位置合并。

## 代码实现

### 方法一：分离排序合并（推荐）

```python
from typing import List

class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        # 提取偶数下标和奇数下标元素
        evens = sorted(nums[::2])         # 升序
        odds = sorted(nums[1::2], reverse=True)  # 降序

        # 合并回结果
        result = []
        i, j = 0, 0
        idx = 0
        while idx < len(nums):
            if idx % 2 == 0:
                result.append(evens[i])
                i += 1
            else:
                result.append(odds[j])
                j += 1
            idx += 1
        return result
```

### 方法二：更简洁的合并

```python
from typing import List

class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        evens = sorted(nums[::2])           # 偶数下标升序
        odds = sorted(nums[1::2], reverse=True)  # 奇数下标降序
        nums[::2] = evens
        nums[1::2] = odds
        return nums
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分离排序 | O(n log n) | O(n) |

## 关键点总结

1. Python 切片 `nums[::2]` 获取偶数下标元素，`nums[1::2]` 获取奇数下标元素。
2. 排序后直接赋值回切片位置，`nums[::2] = evens` 就地更新。
3. 方法二最简洁，充分利用 Python 切片赋值。

## 易错点

- 偶数下标升序，奇数下标降序（注意方向不要弄反）。
- Python 中 `sorted(...)` 返回新列表，`reverse=True` 表示降序。
