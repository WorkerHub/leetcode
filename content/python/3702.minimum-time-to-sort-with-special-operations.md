## 题目描述

给定一个整数数组 `nums`，你可以对数组执行以下特殊操作：每次操作选择一个下标 `i`，将 `nums[i]` 移动到数组末尾，耗时为 `i + 1`（即该元素当前的位置加一）。求将数组变为非递减有序所需的最小总时间。

**示例 1：**
```
输入：nums = [3, 1, 2]
输出：2
解释：将 nums[0]=3 移到末尾，耗时 1，数组变为 [1, 2, 3]，已排好序。
```

**示例 2：**
```
输入：nums = [2, 4, 3, 1]
输出：5
解释：先移动 nums[3]=1（耗时 4），再移动 nums[1]=4（耗时 2），数组有序，总耗时 6。
     也可以先移动 nums[2]=3（耗时 3），再移动 nums[0]=2（耗时 1）... 选最优方案。
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^6`，元素各不相同

## 解题思路

关键观察：最终排好序的数组中，有一段连续的"原始前缀"不需要移动，其余元素都要被移动到末尾。

换个角度：找出原数组中最长的前缀，使得该前缀已经是有序的（即 `nums[0..j]` 是 `sorted_nums[0..j]` 的前缀），则这段前缀内的元素不需要操作，其余元素从右往左依次移动到末尾，每次移动的代价为当前位置加一。

动态规划：设 `dp[i]` 表示将 `nums[0..i]` 变为有序所需的最小时间。
- 若 `nums[i]` 已经在排序后的正确位置，则可以延续之前的最优解。
- 否则需要将 `nums[i]` 移走。

实际上更直接的贪心做法：计算有多少元素是"原地不动"的（它们构成原数组的一个前缀有序段），其余元素按从右到左的顺序移动，代价依次累加。

## Python 代码实现

### 方法一：贪心模拟（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, nums: List[int]) -> int:
        n = len(nums)
        sorted_nums = sorted(nums)

        # 找出最长的有序前缀长度 j，满足 nums[0..j-1] == sorted_nums[0..j-1]
        j = 0
        while j < n and nums[j] == sorted_nums[j]:
            j += 1

        # j 之后的元素需要被移动，从右到左依次移动
        # 每次移动代价是当前该元素所在位置（原位置）
        total = 0
        # 需要移动的元素是 nums[j:]，按照其原始位置从大到小移动
        # 将它们的代价（原始下标+1）累加
        for i in range(j, n):
            total += (i + 1)

        return total
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def minimumTime(self, nums: List[int]) -> int:
        n = len(nums)
        sorted_nums = sorted(nums)
        # pos[v] = v 在排序数组中的目标位置
        pos = {v: i for i, v in enumerate(sorted_nums)}

        # dp[i]: 处理完 nums[0..i] 所需最小代价
        # 若 nums[i] 位于其目标位置 pos[nums[i]]，且之前的顺序正确，则代价不增加
        INF = float('inf')
        # 直接枚举：保留哪些元素不动（它们必须构成有序前缀）
        min_cost = sum(range(1, n + 1))  # 全部移动的代价

        # 找最长可保留的前缀
        for keep in range(n + 1):
            if keep == 0 or nums[:keep] == sorted_nums[:keep]:
                # 移动剩余 n-keep 个元素，代价为这些元素原始下标+1 之和
                cost = sum(i + 1 for i in range(keep, n))
                min_cost = min(min_cost, cost)

        return min_cost
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序加线性扫描
- 空间复杂度：O(n)，存储排序后的数组

## 关键点总结

1. 核心思路：找到原数组中可以"原地保留"的最长有序前缀
2. 其余元素必须被移动，代价为各自当前位置之和
3. 贪心选择：尽量保留更多的前缀元素，减少总移动代价

## 易错点

1. 前缀必须是连续的，不能跳跃保留中间元素
2. 移动代价是"移动时的当前位置"，从右往左移动时位置不变（每次从末尾删除再插入）
