## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`。

每一步，你可以交换相邻两个元素，但仅当它们具有 **相同的置位数**（二进制表示中 1 的个数）时，才可以交换。

如果可以通过若干次操作将数组排序，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：nums = [8,4,2,30,15]
输出：true
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：false
```

**提示：**
- `1 <= n <= 100`
- `1 <= nums[i] <= 1000`

## 解题思路

关键观察：具有相同置位数的元素之间可以任意排序（因为相邻交换可以实现冒泡排序，从而达到任意排列）。

因此，将数组按置位数分组，每组内的元素可以自由排序。

**判断是否可以排序：**
将数组划分为若干连续的"块"，每个块内的元素置位数相同。对每个块单独排序后，验证整个数组是否有序。

等价于：**对于相邻两个块，前一个块的最大值必须 <= 后一个块的最小值**。

## Python 代码实现

### 方法一：分组排序验证（推荐）

```python
from typing import List

class Solution:
    def canSortArray(self, nums: List[int]) -> bool:
        n = len(nums)
        i = 0
        prev_max = 0  # 上一个块的最大值

        while i < n:
            j = i
            bit_count = bin(nums[i]).count('1')

            # 找到当前块的右边界
            while j < n and bin(nums[j]).count('1') == bit_count:
                j += 1

            # 当前块的最小值和最大值
            block_min = min(nums[i:j])
            block_max = max(nums[i:j])

            # 当前块的最小值必须大于上一个块的最大值
            if block_min < prev_max:
                return False

            prev_max = block_max
            i = j

        return True
```

### 方法二：排序后比较

```python
from typing import List

class Solution:
    def canSortArray(self, nums: List[int]) -> bool:
        # 将数组按置位数分组，组内排序
        from itertools import groupby

        sorted_parts = []
        for _, group in groupby(nums, key=lambda x: bin(x).count('1')):
            sorted_parts.extend(sorted(group))

        # 检查整体是否有序
        return sorted_parts == sorted(nums)
```

### 方法三：简洁版

```python
from typing import List

class Solution:
    def canSortArray(self, nums: List[int]) -> bool:
        n = len(nums)
        # 对数组进行"受限冒泡排序"的模拟
        arr = nums[:]
        for i in range(n):
            for j in range(n - 1):
                if arr[j] > arr[j + 1]:
                    # 只有置位数相同才能交换
                    if bin(arr[j]).count('1') == bin(arr[j + 1]).count('1'):
                        arr[j], arr[j + 1] = arr[j + 1], arr[j]
        return arr == sorted(nums)
```

## 复杂度分析

- 时间复杂度：O(n log n)，分组排序；方法三 O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 相同置位数的相邻元素可以交换，等价于该组可任意排序
2. 连续相同置位数的元素形成一个"块"，块内可自由排列
3. 只需验证相邻块之间前块最大值 <= 后块最小值

## 易错点

1. 块是**连续**的——不连续的相同置位数元素不能越过中间的不同置位数元素互换位置
2. 不是对整个相同置位数的元素排序，而是按连续区间分块
