## 题目描述

给你一个整数数组 `arr`，请你判断数组中是否存在**连续三个奇数**。

**示例 1：**
```
输入：arr = [2,6,4,1]
输出：false
```

**示例 2：**
```
输入：arr = [1,2,34,3,4,5,7,23,12]
输出：true
解释：[5,7,23] 是连续三个奇数
```

**提示：**
- `1 <= arr.length <= 1000`
- `1 <= arr[i] <= 1000`

## 解题思路

### 计数器法

遍历数组，维护当前连续奇数的数量：
- 遇到奇数，计数器加 1
- 遇到偶数，计数器重置为 0
- 若计数器达到 3，返回 True

## 代码实现

### 方法一：计数器（推荐）

```python
from typing import List

class Solution:
    def threeConsecutiveOdds(self, arr: List[int]) -> bool:
        count = 0
        for num in arr:
            if num % 2 == 1:
                count += 1
                if count == 3:
                    return True
            else:
                count = 0
        return False
```

### 方法二：滑动窗口（枚举三元组）

```python
from typing import List

class Solution:
    def threeConsecutiveOdds(self, arr: List[int]) -> bool:
        for i in range(len(arr) - 2):
            if arr[i] % 2 == 1 and arr[i+1] % 2 == 1 and arr[i+2] % 2 == 1:
                return True
        return False
```

### 方法三：使用 any + zip

```python
from typing import List

class Solution:
    def threeConsecutiveOdds(self, arr: List[int]) -> bool:
        return any(
            a % 2 == 1 and b % 2 == 1 and c % 2 == 1
            for a, b, c in zip(arr, arr[1:], arr[2:])
        )
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)（方法一/二）；O(N)（方法三，zip 产生临时对象）

## 关键点总结

1. 计数器法：遇奇加 1，遇偶重置
2. 三元组枚举也很直观：检查每个连续三元组是否全为奇数
3. `zip(arr, arr[1:], arr[2:])` 优雅地枚举所有连续三元组

## 易错点

- 数组长度可能小于 3，方法二中 `range(len(arr) - 2)` 在长度 < 3 时为空，不会越界
- 方法三 `zip` 在长度 < 3 时也自动为空
