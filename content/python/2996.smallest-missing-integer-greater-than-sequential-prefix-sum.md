## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

**顺序前缀和**：从 `nums[0]` 开始的最长连续递增前缀的和。具体地，找最大的 `i` 使得 `nums[0], nums[1], ..., nums[i]` 严格递增（逐个增大），前缀和为 `sum(nums[0..i])`。

若 `nums[0]` 就是最长严格递增前缀（即 nums[1] <= nums[0]），则前缀和 = nums[0]。

返回大于该前缀和且不在 `nums` 中出现的最小正整数。

**示例 1：**
```
输入：nums = [1,2,3,2,5]
输出：6
解释：顺序前缀：[1,2,3]（2 < 3 但 2 < 3 是递增，2 在 nums[3] 不递增），前缀和=1+2+3=6
6 不在 nums 中，返回 6
等等，答案是 6，不是 7。
```

**示例 2：**
```
输入：nums = [3,4,5,1,2]
输出：3? 前缀和=3+4+5=12，然后找 > 12 且不在 nums 中的最小整数
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

1. 找最长严格递增前缀，计算前缀和 `s`
2. 从 `s + 1` 开始找第一个不在 `nums` 中的整数

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def missingInteger(self, nums: List[int]) -> int:
        # 计算顺序前缀和
        prefix_sum = nums[0]
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1] + 1:
                prefix_sum += nums[i]
            else:
                break

        # 找大于 prefix_sum 且不在 nums 中的最小整数
        nums_set = set(nums)
        ans = prefix_sum + 1
        while ans in nums_set:
            ans += 1
        return ans
```

### 方法二：使用 itertools

```python
from typing import List
import itertools

class Solution:
    def missingInteger(self, nums: List[int]) -> int:
        # 计算前缀（连续递增，每个元素比前一个大 1）
        total = 0
        for i, x in enumerate(nums):
            if i == 0 or x == nums[i - 1] + 1:
                total += x
            else:
                break

        nums_set = set(nums)
        ans = total + 1
        while ans in nums_set:
            ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，n <= 50 很小
- 空间复杂度：O(n)，集合存储

## 关键点总结

1. 连续递增前缀：每个元素比前一个大 1（差值为 1）
2. 前缀和 s，找 s+1 开始第一个不在数组中的整数
3. nums 值有限（<=50），答案不会太大

## 易错点

1. 连续递增要求差值恰好为 1，不是 >= 1
2. 从 prefix_sum + 1 开始查找（大于前缀和）
3. 若 prefix_sum + 1 本身就不在 nums，直接返回
