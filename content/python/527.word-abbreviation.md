## 题目描述

给定一个由不同字符串组成的数组 `words`，返回每个单词的最小可能缩写。

字符串缩写的规则如下：

1. 每个单词的初始缩写是：第一个字符，然后是中间的字符数量，最后是最后一个字符
2. 如果多个单词共享相同的缩写，则执行以下操作：
   - 将它们每个缩写的前缀（第一部分的字符）增加 1
   - 例如，从单词 `["abcdef","abndef"]` 开始，两者最初缩写为 `"a4f"`。然后操作序列为 `["a4f","a4f"]` -> `["ab3f","ab3f"]` -> `["abc2f","abn2f"]`
   - 重复此操作，直到每个缩写都是唯一的
3. 最后，如果缩写没有使单词变短，则保留原始单词

**示例 1：**
```
输入: words = ["like","god","internal","me","internet","interval","intension","face","intrusion"]
输出: ["l2e","god","internal","me","i6t","interval","inte4n","f2e","intr4n"]
```

**示例 2：**
```
输入: words = ["aa","aaa"]
输出: ["aa","aaa"]
```

**提示：**
- `1 <= words.length <= 400`
- `2 <= words[i].length <= 400`
- `words[i]` 由小写英文字母组成
- `words` 的所有字符串都是唯一的

## 解题思路

这道题的关键是处理缩写冲突。如果两个单词有相同的缩写，它们必须：
1. 首字母相同
2. 尾字母相同
3. 长度相同

**解题策略：使用字典树（Trie）**

1. **分组**：按照（长度，尾字母）将单词分组
2. **构建 Trie**：每组单词构建一个 Trie
3. **统计前缀**：在 Trie 中记录每个节点被多少个单词经过（`cnt`）
4. **查找唯一前缀**：从根开始，找到第一个 `cnt == 1` 的节点
5. **生成缩写**：根据前缀长度生成缩写，如果不比原单词短则保留原单词

## Python 代码实现

### 方法一：分组 + 字典树（推荐）

```python
from typing import List
from collections import defaultdict

class Trie:
    """字典树节点"""
    def __init__(self):
        self.children = [None] * 26  # 26 个小写字母
        self.cnt = 0  # 经过此节点的单词数量
    
    def insert(self, word: str):
        """插入单词到 Trie"""
        node = self
        for char in word:
            idx = ord(char) - ord('a')
            if not node.children[idx]:
                node.children[idx] = Trie()
            node = node.children[idx]
            node.cnt += 1  # 增加计数
    
    def search(self, word: str) -> int:
        """
        查找单词的唯一前缀长度
        返回第一个 cnt == 1 的节点位置
        """
        node = self
        for i, char in enumerate(word, 1):
            idx = ord(char) - ord('a')
            node = node.children[idx]
            if node.cnt == 1:
                return i  # 返回前缀长度
        return len(word)  # 需要完整单词

class Solution:
    def wordsAbbreviation(self, words: List[str]) -> List[str]:
        """
        使用 Trie 生成最小缩写
        """
        n = len(words)
        # 按（长度，尾字母）分组
        groups = defaultdict(list)
        for i, word in enumerate(words):
            key = (len(word), word[-1])
            groups[key].append(i)
        
        # 为每组构建 Trie 并查找前缀长度
        prefix_lens = [0] * n
        for indices in groups.values():
            # 构建 Trie
            trie = Trie()
            for i in indices:
                trie.insert(words[i])
            
            # 查找每个单词的唯一前缀长度
            for i in indices:
                prefix_lens[i] = trie.search(words[i])
        
        # 生成缩写
        result = []
        for i, word in enumerate(words):
            prefix_len = prefix_lens[i]
            # 缩写格式：prefix + middle_count + last_char
            abbr_len = prefix_len + 1 + len(str(len(word) - prefix_len - 1))
            
            if abbr_len >= len(word):
                # 缩写不比原词短，保留原词
                result.append(word)
            else:
                # 生成缩写
                middle_count = len(word) - prefix_len - 1
                abbr = word[:prefix_len] + str(middle_count) + word[-1]
                result.append(abbr)
        
        return result
```

### 方法二：详细注释版（适合初学者）

```python
from typing import List
from collections import defaultdict

class Trie:
    """字典树实现"""
    def __init__(self):
        self.children = [None] * 26
        self.cnt = 0
    
    def insert(self, word: str):
        node = self
        for char in word:
            idx = ord(char) - ord('a')
            if not node.children[idx]:
                node.children[idx] = Trie()
            node = node.children[idx]
            node.cnt += 1
    
    def search(self, word: str) -> int:
        node = self
        for i, char in enumerate(word, 1):
            idx = ord(char) - ord('a')
            node = node.children[idx]
            if node.cnt == 1:
                return i
        return len(word)

class Solution:
    def wordsAbbreviation(self, words: List[str]) -> List[str]:
        """
        步骤：
        1. 按（长度，尾字母）分组
        2. 每组构建 Trie
        3. 查找唯一前缀
        4. 生成缩写
        """
        n = len(words)
        
        # 步骤 1: 分组
        groups = defaultdict(list)
        for i, word in enumerate(words):
            # 只有长度和尾字母相同的单词可能有相同缩写
            key = (len(word), word[-1])
            groups[key].append(i)
        
        # 步骤 2 & 3: 为每组查找唯一前缀
        prefix_lens = [0] * n
        for indices in groups.values():
            if len(indices) == 1:
                # 只有一个单词，前缀长度为 1
                prefix_lens[indices[0]] = 1
                continue
            
            # 构建 Trie
            trie = Trie()
            for i in indices:
                trie.insert(words[i])
            
            # 查找唯一前缀
            for i in indices:
                prefix_lens[i] = trie.search(words[i])
        
        # 步骤 4: 生成缩写
        result = []
        for i, word in enumerate(words):
            prefix_len = prefix_lens[i]
            
            # 计算缩写长度
            # 缩写 = 前缀 + 中间数字 + 尾字母
            middle_count = len(word) - prefix_len - 1
            if middle_count <= 0:
                # 前缀太长，使用原词
                result.append(word)
            else:
                # 计算缩写的总长度
                abbr = word[:prefix_len] + str(middle_count) + word[-1]
                if len(abbr) < len(word):
                    result.append(abbr)
                else:
                    result.append(word)
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(L)
  - L 是所有单词的总长度
  - 每个单词插入 Trie：O(L)
  - 查找前缀：O(L)
  
- **空间复杂度**：O(L)
  - Trie 存储所有单词：O(L)

## 关键点总结

1. **分组策略**：只有长度和尾字母相同的单词可能冲突
2. **Trie 计数**：`cnt` 记录经过每个节点的单词数
3. **唯一前缀**：第一个 `cnt == 1` 的节点
4. **缩写验证**：必须比原单词短才使用
5. **边界情况**：前缀长度 >= 单词长度时使用原词

## 易错点

1. **缩写长度计算**
   ```python
   # 错误：没有考虑数字的长度
   abbr_len = prefix_len + 1 + 1
   
   # 正确：数字可能是多位
   abbr_len = prefix_len + len(str(middle_count)) + 1
   ```

2. **Trie 计数**
   ```python
   # 必须在每个节点增加计数
   node = node.children[idx]
   node.cnt += 1  # 不能忘记
   ```

3. **分组键**
   ```python
   # 正确：使用元组作为键
   key = (len(word), word[-1])
   
   # 错误：只用长度不够
   key = len(word)
   ```
