## 题目描述

给定一个数组 `books`,其中 `books[i] = [thicknessi, heighti]` 表示第 `i` 本书的厚度和高度。同时给定一个整数 `shelfWidth`。

按顺序将这些书摆放到总宽度为 `shelfWidth` 的书架上。

先选择书架上的一些书,使这些书的厚度之和不超过 `shelfWidth`,然后将这些书竖着摆放在书架上。这一层书架的高度由这些书中最高的那本书决定。

重复这个过程,直到把所有的书都摆放完毕。

注意,在这个过程的任意时刻,摆放书的顺序与给定图书序列的顺序相同。

返回书架整体可能的最小高度。

**示例 1:**
```
输入: books = [[1,1],[2,3],[2,3],[1,1],[1,1],[1,1],[1,2]], shelfWidth = 4
输出: 6
解释:
第一层: [1,1], [2,3] -> 厚度和 = 1+2 = 3, 高度 = max(1,3) = 3
第二层: [2,3] -> 厚度 = 2, 高度 = 3
第三层: [1,1], [1,1], [1,1], [1,2] -> 厚度和 = 1+1+1+1 = 4, 高度 = max(1,1,1,2) = 2
总高度 = 3 + 3 + 2 = 8

更优方案:
第一层: [1,1] -> 厚度 = 1, 高度 = 1
第二层: [2,3], [2,3] -> 厚度和 = 4, 高度 = 3
第三层: [1,1], [1,1], [1,1] -> 厚度和 = 3, 高度 = 1
第四层: [1,2] -> 厚度 = 1, 高度 = 2
等等...实际最优是 6
```

**示例 2:**
```
输入: books = [[1,3],[2,4],[3,2]], shelfWidth = 6
输出: 4
```

**提示:**
- `1 <= books.length <= 1000`
- `1 <= thicknessi <= shelfWidth <= 1000`
- `1 <= heighti <= 1000`

## 解题思路

这是一道典型的动态规划问题,需要在保持书籍顺序的前提下,最优地分配每层书架。

**核心思想:**
1. 定义 `dp[i]` 表示放置前 `i` 本书所需的最小高度
2. 对于第 `i` 本书,可以选择:
   - 单独放在新的一层
   - 与前面的一本或多本书放在同一层(前提是宽度允许)
3. 状态转移:枚举第 `i` 本书所在层包含的书籍范围,选择最小高度

**状态定义:**
- `dp[i]` = 放置前 `i` 本书的最小总高度

**状态转移方程:**
- 枚举第 `i` 本书所在层从第 `j` 本书开始:
- `dp[i] = min(dp[j-1] + max_height[j...i])` (当 `sum_width[j...i] <= shelfWidth`)

**算法流程:**
1. 初始化 `dp[0] = 0`(没有书时高度为0)
2. 从前往后遍历每本书 `i`
3. 对于每本书 `i`,尝试将它与前面的书放在同一层
4. 从 `i` 向前枚举 `j`,只要宽度允许,就计算这种分层方案的总高度
5. 取所有方案中的最小值

## Python 代码实现

### 方法一: 动态规划(推荐) ⭐

```python
from typing import List

class Solution:
    def minHeightShelves(self, books: List[List[int]], shelfWidth: int) -> int:
        n = len(books)
        # dp[i] 表示放置前i本书的最小高度
        dp = [float('inf')] * (n + 1)
        dp[0] = 0  # 没有书时高度为0
        
        # 遍历每一本书
        for i in range(1, n + 1):
            # 当前书的厚度和高度
            width = 0
            height = 0
            
            # 尝试将第i本书与前面的书放在同一层
            # j 表示当前层的第一本书的索引
            for j in range(i, 0, -1):
                width += books[j-1][0]  # 累加厚度
                
                # 如果超过书架宽度,停止
                if width > shelfWidth:
                    break
                
                # 更新当前层的最大高度
                height = max(height, books[j-1][1])
                
                # 更新dp[i]: 前j-1本书的最小高度 + 当前层的高度
                dp[i] = min(dp[i], dp[j-1] + height)
        
        return dp[n]
```

### 方法二: 带注释的详细版本

```python
from typing import List

class Solution:
    def minHeightShelves(self, books: List[List[int]], shelfWidth: int) -> int:
        n = len(books)
        dp = [0] + [float('inf')] * n
        
        for i in range(1, n + 1):
            # 尝试将书籍 [j, i) 放在同一层
            current_width = 0
            current_max_height = 0
            
            for j in range(i, 0, -1):
                # books[j-1] 是第j本书(索引从0开始)
                book_width, book_height = books[j-1]
                current_width += book_width
                
                # 宽度超限,无法放在同一层
                if current_width > shelfWidth:
                    break
                
                # 更新当前层的最大高度
                current_max_height = max(current_max_height, book_height)
                
                # 状态转移:前j-1本书的高度 + 当前层高度
                dp[i] = min(dp[i], dp[j-1] + current_max_height)
        
        return dp[n]
```

### 方法三: 记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def minHeightShelves(self, books: List[List[int]], shelfWidth: int) -> int:
        n = len(books)
        
        @lru_cache(None)
        def dfs(index: int) -> int:
            """从第index本书开始,放置剩余书籍的最小高度"""
            if index == n:
                return 0
            
            min_height = float('inf')
            current_width = 0
            current_max_height = 0
            
            # 尝试将index及后续的书放在当前层
            for i in range(index, n):
                width, height = books[i]
                current_width += width
                
                if current_width > shelfWidth:
                    break
                
                current_max_height = max(current_max_height, height)
                # 当前层高度 + 剩余书籍的最小高度
                total = current_max_height + dfs(i + 1)
                min_height = min(min_height, total)
            
            return min_height
        
        return dfs(0)
```

## 复杂度分析

### 方法一和方法二(动态规划):
- **时间复杂度**: O(n²),外层循环 n 次,内层循环最多 n 次
- **空间复杂度**: O(n),dp 数组

### 方法三(记忆化搜索):
- **时间复杂度**: O(n²),每个状态最多计算一次
- **空间复杂度**: O(n),递归栈和缓存

## 关键点总结

1. **动态规划定义**: `dp[i]` 表示放置前 `i` 本书的最小高度
2. **状态转移**: 枚举最后一层包含的书籍范围,选择最小高度
3. **逆向枚举**: 从当前书向前枚举,累加宽度直到超限
4. **顺序限制**: 必须按照给定顺序放置书籍,不能调整顺序
5. **贪心误区**: 不能贪心地总是填满每一层,需要考虑高度的影响

## 易错点

1. **索引处理**: `dp[i]` 对应前 `i` 本书,而 `books[i-1]` 是第 `i` 本书
2. **宽度判断**: 累加宽度时要先加后判断,防止遗漏边界情况
3. **高度更新**: 每层的高度是该层所有书中的最大高度
4. **初始化**: `dp[0] = 0`,其余为 `inf`
