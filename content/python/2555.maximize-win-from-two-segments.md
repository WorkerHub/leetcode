## 题目描述

在 X 轴上有若干奖品，位置为整数数组 `prizePositions`（已排序）。

你有两条线段，每条长度为 `k`，可以放置在 X 轴的任意位置（`[x, x+k]`）。

两条线段内包含的奖品数之和的 **最大值** 是多少？（两线段可以重叠）

**示例 1：**

```
输入：prizePositions = [1,1,2,2,3,3,5], k = 2
输出：7
解释：线段 [1,3] 包含 6 个，线段 [5,7] 包含 1 个，但更优为 [1,3] 和 [3,5]，均包含 6+6=12... 最优为 7。
```

**提示：**

- `1 <= prizePositions.length <= 10^5`
- `0 <= prizePositions[i] <= 10^9`
- `0 <= k <= 10^9`
- prizePositions 有序

## 解题思路

**滑动窗口 + 前缀最优**。

对于每个右端点 r，求 [r-k, r] 内的奖品数（滑动窗口），记为 `right_count[r]`。

同时维护 `best[r]` = 在 r 位置之前最优的单段奖品数（使用第一条线段）。

对于第二条线段右端点 r，第一条线段的最佳位置在第二条线段左侧（prizePositions[r]-k-1 之前结束的最优值）。

## Python 代码实现

### 方法一：滑动窗口 + 前缀最优（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximizeWin(self, prizePositions: List[int], k: int) -> int:
        n = len(prizePositions)
        # dp[i] = 用一条长度为 k 的线段，覆盖 prizePositions[0..i] 中的最大奖品数
        dp = [0] * (n + 1)  # dp[i] 表示前 i 个位置的最优单段奖品数

        ans = 0
        left = 0

        for right in range(n):
            # 维护窗口：prizePositions[right] - prizePositions[left] <= k
            while prizePositions[right] - prizePositions[left] > k:
                left += 1
            # 当前线段覆盖 [left, right]，奖品数为 right - left + 1
            window_size = right - left + 1

            # dp[right+1] = max(dp[right], window_size)
            dp[right + 1] = max(dp[right], window_size)

            # 第二条线段右端点为 right，第一条线段最优（在 left-1 之前）
            # 第一条线段结束位置 <= prizePositions[right] - k - 1
            # 二分找最大的 j 使 prizePositions[j] <= prizePositions[right] - k - 1
            # 对应 dp[j+1] 或 dp[left]（line 1 结束在 left-1 之前）
            ans = max(ans, dp[left] + window_size)

        return ans
```

### 方法二：二分 + DP

```python
from typing import List
import bisect

class Solution:
    def maximizeWin(self, prizePositions: List[int], k: int) -> int:
        n = len(prizePositions)
        # best[i] = 用一条线段覆盖前 i 个奖品的最大数量
        best = [0] * (n + 1)
        ans = 0
        left = 0

        for right in range(n):
            while prizePositions[right] - prizePositions[left] > k:
                left += 1

            # 当前窗口大小
            cur = right - left + 1
            best[right + 1] = max(best[right], cur)

            # 找第一条线段的最佳位置（在当前线段左端之前结束）
            # 第一条线段右端 <= prizePositions[left] - 1
            # 用二分找满足 prizePositions[j] <= prizePositions[left] - k - 1 的最大 j
            p = bisect.bisect_right(prizePositions, prizePositions[left] - k - 1)
            ans = max(ans, best[p] + cur)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，滑动窗口 O(n) + 二分 O(log n) 每次
- 空间复杂度：O(n)，best 数组

## 关键点总结

1. 枚举第二条线段的位置，贪心地找第一条线段的最优位置
2. best[i] 记录使用一条线段在前 i 个奖品中能拿到的最多数量
3. 两条线段可以不重叠也可以重叠，最优时通常不重叠

## 易错点

1. 第一条线段可以在第二条线段的任意左侧，不必紧邻
2. best 数组下标偏移：best[i] 表示前 i 个元素的最优值
3. 二分找"在当前线段左端之前能选的最优单段"
