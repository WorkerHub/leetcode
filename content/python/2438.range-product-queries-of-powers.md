## 题目描述

给你一个正整数 `n`，`n` 可以表示为若干个不同的 2 的幂的和（即 `n` 的二进制表示）。

同时给你一个下标从 **0** 开始的整数数组 `queries`，其中 `queries[i] = [lefti, righti]`。

对于每个查询 `i`，计算 `powers[lefti], powers[lefti+1], ..., powers[righti]` 的乘积，其中 `powers` 是将 `n` 分解为若干不同的 2 的幂之后从小到大排列得到的数组。

返回一个数组，其中第 `i` 个元素是第 `i` 个查询的答案对 `10^9 + 7` 取余的结果。

**示例 1：**
```
输入：n = 15, queries = [[0,1],[2,2],[0,3]]
输出：[6,4,64]
解释：n = 15 = 1 + 2 + 4 + 8，powers = [1,2,4,8]。
- 查询 [0,1]：1 * 2 = 2（不对，1*2=2？题目输出 6？）
```

实际：powers = [1,2,4,8]，查询 [0,1] 的积是 1*2=2，但示例输出是 6？让我重新核对...

实际上 n=15 二进制 1111，powers=[1,2,4,8]
- [0,1]: 1*2=2，但示例说 6...

看来我误读了，重新理解：示例输出 [6,4,64] 对应 [[0,1],[2,2],[0,3]] ...

等等 powers=[1,2,4,8]，[0,1]=1*2=2，[2,2]=4，[0,3]=1*2*4*8=64。所以输出应该是 [2,4,64]，不是 [6,4,64]。

**提示：**
- `1 <= n <= 10^9`
- `1 <= queries.length <= 10^5`
- `0 <= lefti <= righti < popcount(n)`

## 解题思路

1. 提取 `n` 的所有 2 的幂（从小到大），构成 `powers` 数组
2. 对每个查询 `[l, r]`，计算 `powers[l] * powers[l+1] * ... * powers[r]`
3. 可以预计算前缀积（但由于有取模，需要费马小定理求逆元），或者直接遍历区间

由于 `n` 最多 30 个二进制位，`powers` 最长 30 个元素，直接遍历查询区间即可。

## 代码实现

### 方法一：直接枚举（推荐，因 powers 最多 30 个）

```python
from typing import List

class Solution:
    def productQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7

        # 提取 n 的二进制表示中所有的 2 的幂
        powers = []
        bit = 1
        while bit <= n:
            if n & bit:
                powers.append(bit)
            bit <<= 1

        ans = []
        for l, r in queries:
            # 计算 powers[l] 到 powers[r] 的乘积
            product = 1
            for i in range(l, r + 1):
                product = product * powers[i] % MOD
            ans.append(product)

        return ans
```

### 方法二：前缀积（2 的幂乘积可以用指数计算）

```python
from typing import List

class Solution:
    def productQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7

        # 提取每个 2 的幂的指数（即 bit 位位置）
        exponents = []
        for i in range(30):
            if n >> i & 1:
                exponents.append(i)

        # powers 乘积 = 2^(sum of exponents)
        # 前缀和
        prefix = [0] * (len(exponents) + 1)
        for i, e in enumerate(exponents):
            prefix[i + 1] = prefix[i] + e

        ans = []
        for l, r in queries:
            # powers[l..r] 的乘积 = 2^(prefix[r+1] - prefix[l])
            exp = prefix[r + 1] - prefix[l]
            ans.append(pow(2, exp, MOD))

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接枚举 | O(q * 30) | O(30) |
| 前缀积优化 | O(q * log(exp)) | O(30) |

q 为查询数量，powers 最多 30 个。

## 关键点总结

1. `powers` 由 `n` 的二进制中各个 1 对应的 2 的幂组成
2. 因为 `n <= 10^9 < 2^30`，`powers` 最多 30 个元素
3. 方法二利用 2 的幂的乘法可转化为指数相加

## 易错点

- 取模时每步乘法都要取模，防止溢出
- 方法二中查询区间是 `[l, r]`（包含两端）
