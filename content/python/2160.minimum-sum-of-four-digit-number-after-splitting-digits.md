## 题目描述

给你一个四位**正整数** `num`。请你使用 `num` 中的**数字**，将 `num` 拆成两个新整数 `new1` 和 `new2`，每个数字只使用一次，且 `new1` 和 `new2` 都不含**前导零**。

返回可以得到的 `new1 + new2` 的**最小值**。

**示例：**
```
输入：num = 2932
输出：52
解释：可以拆成 [29, 32] (29+32=61)，[23, 92] (115)，[22, 93] (115)，[29, 32] ...
最小的是：[23, 92] -> 不对，应为 [22, 39] -> 22+93=115？
实际最小：数字 2,9,3,2 排序为 [2,2,3,9]，拆为 23 和 29？不对...
最优：排序后将最小的两个作为十位，另两个作为个位：
2,2,3,9 -> new1=23, new2=29 -> 52? 
实际：new1 = 2*10+3 = 23，new2 = 2*10+9 = 29，和为 52。
```

**提示：**
- `1000 <= num <= 9999`

## 解题思路

**贪心：排序后最小的两个数作为十位**

设 4 个数字排序后为 `a <= b <= c <= d`，最优分配为：
- `new1 = a * 10 + c`
- `new2 = b * 10 + d`
- 和 = `(a + b) * 10 + (c + d)`

为了最小化和，应将最小的两个数放在十位（系数为 10），较大的两个放在个位（系数为 1）。

## 代码实现

### 方法一：贪心排序（推荐）

```python
class Solution:
    def minimumSum(self, num: int) -> int:
        # 提取四个数字并排序
        digits = sorted(int(d) for d in str(num))
        a, b, c, d = digits
        # 最小的两个作为十位
        return (a * 10 + c) + (b * 10 + d)
```

### 方法二：枚举所有拆分方式

```python
from itertools import permutations

class Solution:
    def minimumSum(self, num: int) -> int:
        digits = [int(d) for d in str(num)]
        min_sum = float('inf')
        # 枚举所有排列
        for perm in permutations(digits):
            # 将 4 个数字分成两个两位数
            new1 = perm[0] * 10 + perm[1]
            new2 = perm[2] * 10 + perm[3]
            if new1 > 0 and new2 > 0:  # 无前导零（题目保证数字 >= 1000，所以有非零数字）
                min_sum = min(min_sum, new1 + new2)
        return min_sum
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(1)（固定 4 个数字） | O(1) |
| 枚举 | O(4!) = O(24) | O(1) |

## 关键点总结

1. 贪心：最小的两个数作为十位，较大的两个作为个位，使总和最小。
2. 最优分配：`(a+b)*10 + (c+d)`，最小化方式是 a,b 为最小两个。
3. 不需要考虑前导零，因为 num >= 1000，至少有一个非零数字，可以确保十位非零（排序后 a 为最小，题目保证 4 位正整数，不含前导零）。

## 易错点

- 注意四位数 num 的数字提取：`str(num)` 或逐位取余。
- 贪心拆分是 `a*10+c` 和 `b*10+d`，不是 `a*10+b` 和 `c*10+d`。
