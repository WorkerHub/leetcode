## 题目描述

有 `n` 朵花，第 `i` 朵花的**美丽值**为 `flowers[i]`（可能为负）。园丁可以保留一个子序列（**不要求连续**），同一位置的花只能保留一次。

一个**有效子序列**是指子序列的第一个和最后一个元素相同。

返回一个**有效子序列**的最大**美丽值之和**。

子序列的美丽值 = 子序列中所有元素之和。

**示例 1：**
```
输入：flowers = [1,2,3,1,2]
输出：8
解释：选择子序列 [1,2,3,1]，美丽值之和为 7；或 [2,3,1,2] 和为 8
最优：选 [2,3,1,2]，和为 8
```

**示例 2：**
```
输入：flowers = [100,41,5,72,4,100]
输出：237
```

**提示：**
- `1 <= flowers.length <= 10^5`
- `-10^4 <= flowers[i] <= 10^4`

## 解题思路

有效子序列的首尾元素相同，设值为 `v`，子序列包含 `v` 在原数组中第一次和最后一次出现的位置，以及中间所有**正数**元素（负数包含会减小总和）。

贪心思路：
1. 对于值 `v`，找到它的第一次和最后一次出现位置 `first[v]` 和 `last[v]`
2. 子序列的和 = `flowers[first[v]]` + `flowers[last[v]]`（若 first != last）+ 区间 `(first[v], last[v])` 中所有正数之和
3. 若 `first[v] == last[v]`（只出现一次），则子序列只有这一个元素，和为 `flowers[first[v]]`

使用前缀正数和 `pos_prefix[i]` = `flowers[0..i-1]` 中正数之和，可快速计算区间正数和。

## 代码实现

### 方法一：贪心 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maximumBeauty(self, flowers: List[int]) -> int:
        n = len(flowers)

        # 记录每个值第一次和最后一次出现的位置
        first = {}
        last = {}
        for i, f in enumerate(flowers):
            if f not in first:
                first[f] = i
            last[f] = i

        # 构建前缀正数和
        # pos_prefix[i] = flowers[0..i-1] 中正数之和
        pos_prefix = [0] * (n + 1)
        for i in range(n):
            pos_prefix[i + 1] = pos_prefix[i] + (flowers[i] if flowers[i] > 0 else 0)

        ans = float('-inf')

        for v in first:
            l = first[v]
            r = last[v]
            if l == r:
                # 只出现一次，子序列只有这一个元素
                ans = max(ans, flowers[l])
            else:
                # 首尾两个 v，加上中间所有正数
                # 注意：如果 v 为正数，l 和 r 处的 v 会被计入前缀正数和
                # 要排除首尾已经在 pos_prefix 内的部分
                # 区间 (l, r) 的正数和 = pos_prefix[r] - pos_prefix[l+1]
                middle_pos = pos_prefix[r] - pos_prefix[l + 1]
                # 总和 = v（首）+ v（尾）+ 中间正数
                total = flowers[l] + flowers[r] + middle_pos
                ans = max(ans, total)

        return ans
```

### 方法二：扫描法

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumBeauty(self, flowers: List[int]) -> int:
        n = len(flowers)
        first = {}
        last = {}
        for i, f in enumerate(flowers):
            if f not in first:
                first[f] = i
            last[f] = i

        # 前缀正数和
        pos_sum = [0] * (n + 1)
        for i in range(n):
            pos_sum[i + 1] = pos_sum[i] + max(0, flowers[i])

        ans = max(flowers)  # 至少可以选单个元素
        for v in first:
            l, r = first[v], last[v]
            if l < r:
                # 首尾都是 v，但如果 v > 0 则首尾已在前缀和内，需要单独处理
                # 中间 (l+1, r-1) 的正数和
                mid = pos_sum[r] - pos_sum[l + 1]
                total = flowers[l] + mid + flowers[r]
                ans = max(ans, total)

        return ans
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历一遍数组
- **空间复杂度**：O(n)，前缀和数组和哈希表

## 关键点总结

1. 有效子序列首尾相同，中间取所有正数（贪心，负数只会减小总和）
2. 前缀正数和快速计算区间内正数之和
3. 注意处理单次出现的值：子序列只有一个元素
4. 中间区间是开区间 `(l, r)`，前缀和索引要正确

## 易错点

1. 计算中间正数时，不包括首尾位置 `l` 和 `r`（它们已经单独加）
2. 单个元素的情况需要单独处理（首尾相同位置）
3. `flowers[i]` 可以为负，要用 `max(0, flowers[i])` 构建前缀正数和
