## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

每次操作时，你需要从数组中选出和为 `k` 的两个整数并将它们移除（每次操作从数组中移除两个）。

返回你可以对数组执行的**最大操作数**。

**示例：**
```
输入：nums = [1,2,3,4], k = 5
输出：2（1+4, 2+3）

输入：nums = [3,1,3,4,3], k = 6
输出：1（3+3）
```

## 解题思路

**方法一：哈希表**：遍历数组，对每个 x 检查 `k-x` 是否已存在（类似两数之和）。

**方法二：双指针**：排序后，左右指针分别从两端向中间移动。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        count = Counter(nums)
        ops = 0
        
        for x in list(count.keys()):
            complement = k - x
            if complement in count:
                if x == complement:
                    ops += count[x] // 2
                    count[x] = 0
                elif x < complement:  # 避免重复计数
                    pairs = min(count[x], count[complement])
                    ops += pairs
                    count[x] -= pairs
                    count[complement] -= pairs
        
        return ops
```

### 方法二：双指针

```python
from typing import List

class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1
        ops = 0
        
        while left < right:
            s = nums[left] + nums[right]
            if s == k:
                ops += 1
                left += 1
                right -= 1
            elif s < k:
                left += 1
            else:
                right -= 1
        
        return ops
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(n) |
| 双指针 | O(n log n) | O(1) |

## 关键点总结

1. 哈希表：统计频率，逐个匹配配对，注意 `x == k-x` 的特殊情况
2. 双指针：排序后两端收缩，和等于 k 时配对
3. 双指针更简洁直观，推荐记忆

## 易错点

- 哈希表方法中，`x == k-x` 时对数为 `count[x] // 2`
- 双指针中，找到一对后两个指针都要移动
- 注意移除操作是"永久性的"（同一元素不能重复配对）
