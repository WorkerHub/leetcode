## 题目描述

给定一个长度为 `n` 的整数数组 `cost`，其中 `cost[i]` 表示从位置 `i` 出发到达位置 `i+1` 的费用。你从位置 `0` 出发，目标是到达每一个位置。从位置 `i` 到位置 `j`（`j > i`）的费用为 `cost[i] + cost[i+1] + ... + cost[j-1]`。

但你也可以选择从任意位置 `k` 免费"传送"到位置 `k`（即从某个位置 `0` 到 `k` 中费用最小的位置出发），求到达每个位置的最小费用。

**示例 1：**

```
输入：cost = [5, 3, 4, 1, 3, 2]
输出：[0, 5, 3, 3, 1, 1]
```

**示例 2：**

```
输入：cost = [1, 2, 3]
输出：[0, 1, 1]
```

**提示：**
- `1 <= n <= 100`
- `1 <= cost[i] <= 100`

## 解题思路

对于每个位置 `i`，到达它的最小费用等于 `cost[0..i-1]` 中的最小前缀和。实际上，由于可以从 `0` 到 `i` 中任意位置"免费出发"，到达位置 `i` 的代价就是 `min(cost[0], cost[1], ..., cost[i-1])`，因为选择费用最小的那个位置直接一步到 `i`。

关键观察：
1. 位置 `0` 的代价是 `0`（已经在那里）
2. 位置 `i` 的最小代价 = `min(cost[0], ..., cost[i-1])`

这是因为从位置 `k` 到位置 `i` 的代价是 `sum(cost[k:i])`，当只走一步（`k = i-1`）时代价为 `cost[i-1]`；我们选择使代价最小的出发点，但实际上前缀最小值就是答案。

## Python 代码实现

### 方法一：前缀最小值（推荐）

```python
from typing import List

class Solution:
    def minCostToReachEveryPosition(self, cost: List[int]) -> List[int]:
        n = len(cost)
        result = [0] * n
        # 位置 0 代价为 0
        # 位置 i 的代价 = min(cost[0], cost[1], ..., cost[i-1])
        min_cost = float('inf')
        for i in range(n):
            if i == 0:
                result[i] = 0
            else:
                min_cost = min(min_cost, cost[i - 1])
                result[i] = min_cost
        return result
```

### 方法二：逐步计算前缀最小值

```python
from typing import List

class Solution:
    def minCostToReachEveryPosition(self, cost: List[int]) -> List[int]:
        n = len(cost)
        result = [0] * n
        # 从位置 1 开始，result[i] 是到达 i 的最小代价
        for i in range(1, n):
            # 枚举从哪个位置出发，代价为 cost[k]（仅走一步到 i 时的简化）
            # 实际上最优解是前缀最小值
            result[i] = min(cost[:i])
        return result
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)，存储结果数组

## 关键点总结

1. 到达位置 `0` 的代价固定为 `0`
2. 到达位置 `i` 的最小代价等于 `cost[0..i-1]` 的最小值
3. 可以用一个变量维护前缀最小值，O(n) 解决

## 易错点

1. 位置 `0` 不需要花费，直接为 `0`
2. 注意 `cost` 数组的索引，`cost[i]` 是从 `i` 到 `i+1` 的费用
3. 不要把"到每个位置的最小代价"和"路径累加"搞混
