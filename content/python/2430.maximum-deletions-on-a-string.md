## 题目描述

给你一个仅由小写英文字母组成的字符串 `s`。在一步操作中，你可以：

- 删除 **整个字符串** `s`，或者
- 对于满足 `1 <= i <= s.length / 2` 的任意 `i`，如果 `s` 最开头的 `i` 个字符与接下来的 `i` 个字符相等，删除最开头的 `i` 个字符。

例如，`s = "ababc"`，那么在一步操作中，可以删除 `s` 最开头的 2 个字符，得到 `"abc"`，因为 `s` 的最开头 2 个字符 `"ab"` 与之后的 2 个字符 `"ab"` 相等。

返回删除 `s` 所需的 **最大** 操作数。

**示例 1：**
```
输入：s = "abcabcdabc"
输出：2
```

**示例 2：**
```
输入：s = "aabaab"
输出：4
```

**提示：**
- `1 <= s.length <= 4000`

## 解题思路

**动态规划 + Z 函数：**

设 `dp[i]` 为删除从位置 `i` 开始的子串 `s[i:]` 所需的最大操作数。

转移：对每个位置 `i`，若 `s[i:i+k] == s[i+k:i+2k]`（前 k 个字符等于后 k 个字符），则可以删除前 k 个字符，转移为 `dp[i] = max(dp[i], dp[i+k] + 1)`。

**如何快速判断 `s[i:i+k] == s[i+k:i+2k]`？**

使用 Z 函数：对于子串 `t = s[i:]`，Z[j] 表示 `t[j:]` 与 `t` 的最长公共前缀长度。
若 `Z[j] >= j`，则 `t[0:j] == t[j:2j]`，即可以删除前 j 个字符。

**算法：**
1. 从右到左计算 dp
2. 对每个位置 i，计算 `s[i:]` 的 Z 函数
3. 根据 Z 函数找所有可行的 k，更新 dp

## 代码实现

### 方法一：动态规划 + Z 函数（推荐）

```python
class Solution:
    def deleteString(self, s: str) -> int:
        n = len(s)

        def z_function(t: str):
            """计算字符串 t 的 Z 函数"""
            m = len(t)
            z = [0] * m
            z[0] = m
            l, r = 0, 0
            for i in range(1, m):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < m and t[z[i]] == t[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z

        # dp[i] = 删除 s[i:] 的最大操作数
        dp = [1] * n

        for i in range(n - 1, -1, -1):
            z = z_function(s[i:])
            for j in range(1, (n - i) // 2 + 1):
                # 如果 z[j] >= j，则 s[i:i+j] == s[i+j:i+2j]
                if z[j] >= j:
                    dp[i] = max(dp[i], dp[i + j] + 1)

        return dp[0]
```

### 方法二：动态规划 + 滚动哈希

```python
class Solution:
    def deleteString(self, s: str) -> int:
        n = len(s)
        MOD = (1 << 61) - 1  # 梅森素数
        BASE = 131

        # 预计算哈希值
        h = [0] * (n + 1)
        pw = [1] * (n + 1)
        for i in range(n):
            h[i + 1] = (h[i] * BASE + ord(s[i])) % MOD
            pw[i + 1] = pw[i] * BASE % MOD

        def get_hash(l: int, r: int) -> int:
            """获取 s[l:r+1] 的哈希值"""
            return (h[r + 1] - h[l] * pw[r - l + 1]) % MOD

        def equal(i: int, j: int, length: int) -> bool:
            """判断 s[i:i+length] == s[j:j+length]"""
            return get_hash(i, i + length - 1) == get_hash(j, j + length - 1)

        dp = [1] * n

        for i in range(n - 1, -1, -1):
            for k in range(1, (n - i) // 2 + 1):
                if equal(i, i + k, k):
                    dp[i] = max(dp[i], dp[i + k] + 1)

        return dp[0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP + Z 函数 | O(n^2) | O(n) |
| DP + 哈希 | O(n^2) | O(n) |

## 关键点总结

1. DP 从右到左：`dp[i]` 依赖 `dp[i+k]`（k > 0）
2. Z 函数快速判断前缀相等：`z[j] >= j` 说明 `s[i:i+j] == s[i+j:i+2j]`
3. 初始化 `dp[i] = 1`（至少需要一次删除整个字符串）

## 易错点

- 枚举 k 的范围：`1 <= k <= (n-i) // 2`（需要 2k 个字符）
- Z 函数中 `z[0]` 通常定义为字符串本身的长度
