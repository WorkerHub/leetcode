## 题目描述

给你一棵 `n` 个节点的无权无向树，节点编号为 `0` 到 `n - 1`，每个节点有一个值 `val[i]`。

你需要在树上找到两个 **不重叠** 的子树，使两个子树的节点值之和的 **异或** 值 **最大**。

返回这个最大异或值，如果找不到，返回 `0`。

**提示：**
- `2 <= n <= 5 * 10^4`
- `1 <= val.length == n`
- `1 <= val[i] <= 2^29 - 1`

## 解题思路

**字典树 + DFS：**

1. 通过 DFS 计算每棵以节点 v 为根的子树的节点值之和 `sub_sum[v]`
2. 然后再进行 DFS，对当前子树的根节点，在已处理过的不重叠子树中找到与当前子树 XOR 最大的值
3. 关键：利用字典树（Trie）在 O(30) 时间内查询与给定值 XOR 最大的已有值

**不重叠的保证：** 在 DFS 中，先处理子节点，再将子节点插入 Trie，确保当前节点 v 的子树不在 Trie 中。

实际上，一棵更简单的理解：枚举删除一条边，将树分成两个部分，找这两部分 XOR 的最大值。

## 代码实现

### 方法一：字典树 + DFS（推荐）

```python
from typing import List
from collections import defaultdict

class TrieNode:
    def __init__(self):
        self.children = [None, None]

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, num: int) -> None:
        node = self.root
        for i in range(29, -1, -1):
            bit = (num >> i) & 1
            if not node.children[bit]:
                node.children[bit] = TrieNode()
            node = node.children[bit]

    def max_xor(self, num: int) -> int:
        node = self.root
        if not node.children[0] and not node.children[1]:
            return 0  # Trie 为空
        result = 0
        for i in range(29, -1, -1):
            bit = (num >> i) & 1
            want = 1 - bit  # 希望找与 bit 不同的位
            if node.children[want]:
                result |= (1 << i)
                node = node.children[want]
            elif node.children[bit]:
                node = node.children[bit]
            else:
                break
        return result

class Solution:
    def maxXor(self, n: int, edges: List[List[int]], values: List[int]) -> int:
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 计算每个子树的值之和
        sub_sum = values[:]

        def calc_sum(node, parent):
            for child in adj[node]:
                if child != parent:
                    calc_sum(child, node)
                    sub_sum[node] += sub_sum[child]

        calc_sum(0, -1)

        trie = Trie()
        ans = 0

        def dfs(node, parent):
            nonlocal ans
            # 先处理子节点
            for child in adj[node]:
                if child != parent:
                    dfs(child, node)
                    # 子树 child 已处理完，插入 trie
                    trie.insert(sub_sum[child])
                    # 查询当前节点的子树与已有子树的最大 XOR
                    ans = max(ans, trie.max_xor(sub_sum[node]))

        dfs(0, -1)
        return ans
```

### 方法二：枚举删边（暴力）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxXor(self, n: int, edges: List[List[int]], values: List[int]) -> int:
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        sub_sum = values[:]

        def calc_sum(node, parent):
            for child in adj[node]:
                if child != parent:
                    calc_sum(child, node)
                    sub_sum[node] += sub_sum[child]

        calc_sum(0, -1)
        total = sub_sum[0]

        # 枚举每条边，删除后两部分异或最大
        ans = 0
        for u, v in edges:
            # 删除边 (u, v)，较小子树的和 = min(sub_sum[u], sub_sum[v])
            # 注意：子树方向需要确定
            if sub_sum[u] < sub_sum[v]:
                sub_val = sub_sum[u]
            else:
                sub_val = sub_sum[v]
            other_val = total - sub_val
            ans = max(ans, sub_val ^ other_val)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 字典树 | O(n log(max_val)) | O(n log(max_val)) |
| 枚举删边 | O(n) | O(n) |

## 关键点总结

1. 删除一条边 = 分成两个不重叠子树，XOR 两部分的节点值之和
2. 枚举删边时，较小子树的 sum 就是父节点方向上子树的 sum
3. 字典树适用于不需要枚举所有边的情况（如有更复杂的不重叠条件）

## 易错点

- 删边后两部分的和：`sub_sum[child]` 和 `total - sub_sum[child]`
- 字典树查询时 Trie 为空要特殊处理
