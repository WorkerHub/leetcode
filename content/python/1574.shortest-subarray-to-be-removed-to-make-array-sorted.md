## 题目描述

给你一个整数数组 `arr`，请你删除一个子数组（可以为空），使得剩下的元素构成**非递减数组**。

返回满足题意的最短子数组的长度。

**示例 1：**
```
输入：arr = [1,2,3,10,4,2,3,5]
输出：3
解释：删除子数组 [10,4,2] 得到 [1,2,3,3,5]
```

**提示：**
- `1 <= arr.length <= 10^5`

## 解题思路

### 双指针

1. 找最长的**前缀非递减段** `arr[0..left]`
2. 找最长的**后缀非递减段** `arr[right..n-1]`
3. 候选删除方案：
   - 删去 `arr[left+1..n-1]`（只保留前缀）
   - 删去 `arr[0..right-1]`（只保留后缀）
   - 枚举前缀 `arr[0..i]` 和后缀 `arr[j..n-1]` 的拼接（`i` 从 0 到 left，二分找最小的 `j >= right` 使 `arr[j] >= arr[i]`）

## 代码实现

### 方法一：双指针 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def findLengthOfShortestSubarray(self, arr: List[int]) -> int:
        n = len(arr)
        # 找前缀非递减段的右端点
        left = 0
        while left < n - 1 and arr[left] <= arr[left + 1]:
            left += 1
        # 已经整体非递减
        if left == n - 1:
            return 0
        # 找后缀非递减段的左端点
        right = n - 1
        while right > 0 and arr[right - 1] <= arr[right]:
            right -= 1

        # 候选1：删去 left+1 到 n-1（保留前缀）
        # 候选2：删去 0 到 right-1（保留后缀）
        ans = min(n - left - 1, right)

        # 候选3：保留前缀 arr[0..i] 和后缀 arr[j..n-1] 的拼接
        # 枚举 i（前缀），二分找最小 j 使 arr[j] >= arr[i]
        i = 0
        j = right
        while i <= left and j < n:
            if arr[i] <= arr[j]:
                ans = min(ans, j - i - 1)
                i += 1
            else:
                j += 1

        return ans
```

### 方法二：枚举 + 二分

```python
from typing import List
import bisect

class Solution:
    def findLengthOfShortestSubarray(self, arr: List[int]) -> int:
        n = len(arr)
        # 前缀非递减段
        left = 0
        while left < n - 1 and arr[left] <= arr[left + 1]:
            left += 1
        if left == n - 1:
            return 0
        # 后缀非递减段
        right = n - 1
        while right > 0 and arr[right - 1] <= arr[right]:
            right -= 1

        ans = min(n - left - 1, right)

        # 枚举前缀长度 i+1，二分在后缀中找合适的 j
        suffix = arr[right:]
        for i in range(left + 1):
            # 找 suffix 中第一个 >= arr[i] 的位置
            pos = bisect.bisect_left(suffix, arr[i])
            # 删去 arr[i+1..right+pos-1]，长度 = right + pos - i - 1
            ans = min(ans, right + pos - i - 1)

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N log N)（方法二）；O(N)（方法一）
- **空间复杂度**：O(1)

## 关键点总结

1. 保留前缀 + 后缀，中间删去的子数组最短
2. 双指针：左右同向扩展，`arr[i] <= arr[j]` 时前缀可以延伸
3. 特殊情况：删去前缀（只保留后缀）或删去后缀（只保留前缀）

## 易错点

- 方法一中枚举时 `j` 从 `right` 开始（不是 0），因为后缀起点已知
- 删去的子数组长度 = `j - i - 1`（保留 `arr[0..i]` 和 `arr[j..n-1]`）
