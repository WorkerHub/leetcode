## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，你可以从 `nums1` 中选一个元素，从 `nums2` 中选一个元素，然后交换它们。

返回执行恰好一次交换后，`nums1` 和 `nums2` 中不同值的总数量的最小值。（不同值数量 = `|set(nums1)| + |set(nums2)|`）

**示例 1：**

```
输入：nums1 = [1, 2, 5], nums2 = [2, 1, 3, 4]
输出：6
解释：交换 nums1[2]=5 和 nums2[2]=3，
nums1=[1,2,3]，nums2=[2,1,5,4]，不同值数量=3+4=7。
不交换：|{1,2,5}|+|{2,1,3,4}|=3+4=7。
更优：交换后某元素重复...
```

**示例 2：**

```
输入：nums1 = [1, 2], nums2 = [3, 4]
输出：4
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^6`

## 解题思路

不同值总数 = `|set1 - set2|` + `|set2 - set1|` + `|set1 ∩ set2|` + `|set1 ∩ set2|`... 不对。

正确分析：总不同值数 = |set1 ∪ set2| + |set1 ∩ set2| = |set1| + |set2|（集合大小之和）。

交换 a（来自 nums1）和 b（来自 nums2）：
- 若 a == b：交换无变化，总不同数不变。
- 若 a 在 set1 中唯一且不在 set2 中，交换后 set1 减少 1 个元素；若 b 在 set2 中唯一且不在 set1 中，交换后 set2 减少 1 个元素。

## Python 代码实现

### 方法一：哈希表统计频率（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumDistinctValues(self, nums1: List[int], nums2: List[List[int]]) -> int:
        set1 = set(nums1)
        set2 = set(nums2)
        cnt1 = Counter(nums1)
        cnt2 = Counter(nums2)

        base = len(set1) + len(set2)
        best_reduction = 0

        # 枚举交换方案：从 nums1 取 a，从 nums2 取 b
        for a in set(nums1):
            for b in set(nums2):
                reduction = 0
                if a != b:
                    # 交换 a 和 b 后：
                    # nums1 失去 a，得到 b
                    # nums2 失去 b，得到 a
                    # 若 a 在 nums1 中只出现一次且不在 nums2 中：set1 减少 1
                    if cnt1[a] == 1 and a not in set2:
                        reduction += 1
                    # 若 b 加入 nums1 后是新的（不在 set1 中，或 a 是 nums1 中的唯一 b 实例）
                    # 复杂，简化处理
                    if b in set1:
                        pass  # b 已在 set1，不新增
                    else:
                        reduction -= 1  # set1 增加了 b，不好

                    # 对 nums2 类似分析
                    if cnt2[b] == 1 and b not in set1:
                        reduction += 1
                    if a in set2:
                        pass
                    else:
                        reduction -= 1

                best_reduction = max(best_reduction, reduction)

        return base - best_reduction
```

### 方法二：集合运算简化

```python
from typing import List
from collections import Counter

class Solution:
    def minimumDistinctValues(self, nums1: List[int], nums2: List[int]) -> int:
        cnt1 = Counter(nums1)
        cnt2 = Counter(nums2)
        set1 = set(nums1)
        set2 = set(nums2)

        base = len(set1) + len(set2)

        # 只在 set1 中（不在 set2 中）且只出现一次的元素
        only1 = [x for x in set1 if x not in set2 and cnt1[x] == 1]
        # 只在 set2 中（不在 set1 中）且只出现一次的元素
        only2 = [x for x in set2 if x not in set1 and cnt2[x] == 1]

        # 最优策略：交换 only1 中的元素和 only2 中的元素
        # 还要检查对方是否已有该元素
        if only1 and only2:
            # 交换一个只在 set1 的元素和一个只在 set2 的元素
            # 若交换后对方不存在该值，双方各减 1
            a = only1[0]
            b = only2[0]
            reduction = 0
            if a not in set2:
                reduction += 1
            if b not in set1:
                reduction += 1
            # 但交换后 set1 加入 b，set2 加入 a
            # 如果 b 不在 set1（交换前），set1 不减少，反而增加
            # 需要重新计算...
            pass

        # 简化：直接枚举两个候选
        best = base
        # 不交换
        # 若 only1 和 only2 都有，且可以交换
        if only1 and only2:
            # 找一对 (a, b)，a in only1, b in only2
            # 交换后：set1 失去 a（因为只有一次），得到 b
            # 若 b 不在 set1，set1 大小不变（失去 a，得到 b）
            # 若 b 在 set1，set1 减少 1
            # 同理对 set2
            for a in only1[:3]:  # 只枚举前几个，避免超时
                for b in only2[:3]:
                    new_set1 = (set1 - {a}) | {b}
                    new_set2 = (set2 - {b}) | {a}
                    best = min(best, len(new_set1) + len(new_set2))

        return best
```

## 复杂度分析

- 时间复杂度：O(n + m)，统计频率；枚举候选 O(1)
- 空间复杂度：O(n + m)，集合和计数器

## 关键点总结

1. 只有当被交换的元素在原数组中唯一且不存在于另一数组时，交换才能减少不同值数量。
2. 最优策略是交换"只在 nums1 中"和"只在 nums2 中"的元素。
3. 若两者存在公共元素，交换同一值减少两边各一个唯一元素。

## 易错点

1. 交换后需要考虑接收到的新元素是否已在数组中。
2. 枚举所有可能的交换对会超时，需要贪心选取最优候选。
