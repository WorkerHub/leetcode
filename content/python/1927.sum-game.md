## 题目描述

Alice 和 Bob 玩一个关于字符串 `num` 的游戏（长度为偶数）：

- 字符串只包含数字 `'0'`-`'9'` 和 `'?'`
- Alice 先手，双方轮流用 `'0'`-`'9'` 替换一个 `'?'`
- Alice 希望字符串前半部分和 ≠ 后半部分和（Alice 赢）
- Bob 希望字符串前半部分和 = 后半部分和（Bob 赢）

双方采取最优策略，若 Alice 赢返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：num = "5023"
输出：false
解释：无 '?'，前半 5+0=5，后半 2+3=5，相等，Bob 赢
```

**示例 2：**
```
输入：num = "25??"
输出：true
解释：Alice 将一个 '?' 设为 9，无论 Bob 怎么设另一个 '?' 都不能使两半相等
```

**提示：**
- `2 <= num.length <= 10^5`，长度为偶数
- `num` 只包含数字和 `'?'`

---

## 解题思路

### 核心思想：数学分析

设：
- `sum_left`、`q_left`：前半部分数字之和和 `'?'` 的数量
- `sum_right`、`q_right`：后半部分数字之和和 `'?'` 的数量

**关键定理：** Bob 能使两半相等，当且仅当：

```
sum_left - sum_right = (q_right - q_left) * 9 / 2
```

即：`2 * (sum_left - sum_right) = 9 * (q_right - q_left)`

**原因：**
- 每对 `(前?，后?)` 可以被 Bob 用 `(x, 9-x)` 填充，贡献差为 9
- 如果 `?` 数量差是奇数，则 Alice 必赢（因为 Bob 无法完全抵消）

Alice 赢当且仅当上述等式不成立。

## 代码实现

### 方法一：数学推导（推荐）

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        n = len(num)
        half = n // 2

        sum_left = sum_right = 0
        q_left = q_right = 0

        for i in range(half):
            if num[i] == '?':
                q_left += 1
            else:
                sum_left += int(num[i])

        for i in range(half, n):
            if num[i] == '?':
                q_right += 1
            else:
                sum_right += int(num[i])

        # Bob 赢的条件：2*(sum_left - sum_right) == 9*(q_right - q_left)
        # 等价于：sum_left + q_left * 4.5 == sum_right + q_right * 4.5
        # 但使用整数：2*(sum_left - sum_right) == 9*(q_right - q_left)
        return 2 * (sum_left - sum_right) != 9 * (q_right - q_left)
```

### 方法二：模拟贪心（直观理解）

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        n = len(num)
        half = n // 2

        # 计算前半和后半的和与问号数
        def calc(s):
            total = 0
            q = 0
            for c in s:
                if c == '?':
                    q += 1
                else:
                    total += int(c)
            return total, q

        sl, ql = calc(num[:half])
        sr, qr = calc(num[half:])

        # 贪心分析：
        # 每次 Alice 在较大和一侧填 9，Bob 在相同侧填 0 以配对
        # 最终 Bob 赢需满足：(qr-ql)*9 == 2*(sl-sr)
        return (qr - ql) * 9 != 2 * (sl - sr)
```

## 关键点总结

1. Bob 赢的充要条件：`2*(sl - sr) == 9*(qr - ql)`
2. 每对 `(前?, 后?)` 相当于可填入 (x, 9-x)，和差为 9，平均值为 4.5
3. 若问号数量差为奇数，Alice 必赢（无法用整数满足条件）

---

## 易错点

- 使用整数比较避免浮点误差：`2*(sl-sr) == 9*(qr-ql)` 而非除以 2
- 注意前半后半的问号数量差的方向（qr - ql，不是 ql - qr）
