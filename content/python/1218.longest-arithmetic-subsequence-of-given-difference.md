## 题目描述

给定一个整数数组 `arr` 和一个整数 `difference`，请你返回 `arr` 中最长等差子序列的长度，该子序列中相邻元素之间的差等于 `difference`。

子序列是指在不改变其余元素顺序的情况下，通过删除一些元素或不删除任何元素而从 `arr` 派生出来的序列。

**示例 1：**

```
输入：arr = [1,2,3,4], difference = 1
输出：4
解释：最长的等差子序列是 [1,2,3,4]。
```

**示例 2：**

```
输入：arr = [1,3,5,7], difference = 1
输出：1
解释：最长的等差子序列是任意单个元素。
```

**示例 3：**

```
输入：arr = [1,5,7,8,5,3,4,2,1], difference = -2
输出：4
解释：最长的等差子序列是 [7,5,3,1]。
```

**提示：**

- `1 <= arr.length <= 10^5`
- `-10^4 <= arr[i], difference <= 10^4`

## 解题思路

这是一道动态规划问题，关键在于如何高效地找到以每个元素结尾的最长等差子序列。

**核心思想：**

1. 使用哈希表 `dp` 存储以某个数字结尾的最长等差子序列的长度
2. 对于当前元素 `num`，如果 `num - difference` 存在于哈希表中，说明可以将 `num` 接到以 `num - difference` 结尾的序列后面
3. 状态转移方程：`dp[num] = dp[num - difference] + 1`（如果存在），否则 `dp[num] = 1`

**为什么这样做？**

- 等差数列的特点是相邻元素差值固定
- 如果 `num` 要加入某个等差序列，那么前一个元素必定是 `num - difference`
- 通过哈希表可以 O(1) 时间查找前驱元素，避免遍历

## Python 代码实现

### 方法一：哈希表 + 动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        """
        使用哈希表记录以每个数字结尾的最长等差子序列长度
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # dp[num] 表示以 num 结尾的最长等差子序列的长度
        dp = {}
        max_length = 1
        
        for num in arr:
            # 查找前驱元素
            prev = num - difference
            
            if prev in dp:
                # 可以接在以 prev 结尾的序列后面
                dp[num] = dp[prev] + 1
            else:
                # 以 num 为起点，长度为 1
                dp[num] = 1
            
            # 更新最大长度
            max_length = max(max_length, dp[num])
        
        return max_length
```

### 方法二：空间优化版本

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        """
        使用 defaultdict 简化代码
        """
        # 使用 defaultdict 避免判断键是否存在
        dp = defaultdict(int)
        
        for num in arr:
            # 直接更新，如果 num - difference 不存在，返回 0
            dp[num] = dp[num - difference] + 1
        
        # 返回所有长度中的最大值
        return max(dp.values())
```

### 方法三：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        """
        详细解释版本：展示完整思考过程
        """
        # 哈希表：键是数字，值是以该数字结尾的最长等差子序列长度
        dp = {}
        result = 0
        
        # 遍历数组中的每个元素
        for num in arr:
            # 计算当前元素的前驱（等差数列中的前一个元素）
            previous_num = num - difference
            
            # 初始化当前元素的长度为 1（至少包含它自己）
            current_length = 1
            
            # 如果前驱存在，说明可以接在前驱后面
            if previous_num in dp:
                current_length = dp[previous_num] + 1
            
            # 更新哈希表
            dp[num] = current_length
            
            # 更新全局最大长度
            result = max(result, current_length)
        
        return result
```

## 复杂度分析

**方法一和方法二：**

- **时间复杂度**：O(n)，其中 n 是数组长度，只需遍历一次数组
- **空间复杂度**：O(n)，哈希表最多存储 n 个元素

## 图解示例

以 `arr = [1,5,7,8,5,3,4,2,1], difference = -2` 为例：

```
遍历过程：

num = 1:  dp[1] = 1  (没有前驱 -1)
num = 5:  dp[5] = 1  (没有前驱 3)
num = 7:  dp[7] = 1  (没有前驱 5)  等等，5 已经在了！
          dp[7] = dp[5] + 1 = 2  序列：[5,7]
num = 8:  dp[8] = 1  (没有前驱 6)
num = 5:  dp[5] = 1  (前驱 3 不存在，重新计算)
num = 3:  dp[3] = dp[5] + 1 = 2  序列：[5,3]
num = 4:  dp[4] = 1  (没有前驱 2)
num = 2:  dp[2] = 1  (没有前驱 0)
num = 1:  dp[1] = dp[3] + 1 = 3  序列：[7,5,3,1]

等等，重新理解：
num = 7:  前驱是 7-(-2)=9, 不存在, dp[7] = 1
num = 5:  前驱是 5-(-2)=7, 存在! dp[5] = dp[7] + 1 = 2  [7,5]
num = 3:  前驱是 3-(-2)=5, 存在! dp[3] = dp[5] + 1 = 3  [7,5,3]
num = 1:  前驱是 1-(-2)=3, 存在! dp[1] = dp[3] + 1 = 4  [7,5,3,1]

最终答案：4
```

## 关键点总结

1. **状态定义**：`dp[num]` 表示以 `num` 结尾的最长等差子序列长度
2. **状态转移**：通过查找 `num - difference` 来确定前驱
3. **哈希表优化**：O(1) 时间查找前驱，避免暴力枚举
4. **注意重复元素**：同一个数字可能出现多次，dp 值会被覆盖更新
5. **difference 可以为负数**：题目中 difference 可以是负数，需要注意计算方向

## 易错点

1. **混淆子序列和子数组**：
   - 子序列不要求连续，只需保持相对顺序
   - 错误做法：寻找连续的等差数列

2. **忘记处理重复元素**：
   - 同一个数字可能多次出现
   - 正确做法：每次都更新 `dp[num]`，保留最新的值

3. **difference 为负数**：
   - `difference = -2` 时，前驱是 `num - (-2) = num + 2`
   - 示例：1 的前驱是 3（3 → 1，差值 -2）

4. **初始化问题**：
   - 每个元素至少可以自成一个长度为 1 的序列
   - 不要忘记处理没有前驱的情况
