## 题目描述

一个下标从 **0** 开始的数组的**交替子序列和**定义为：该子序列**偶数下标**元素之和减去**奇数下标**元素之和。

给你一个数组 `nums`，请你返回 `nums` 任意子序列的**最大交替子序列和**。

**示例 1：**
```
输入：nums = [4, 2, 5, 3]
输出：7
解释：选取子序列 [4, 2, 5]，交替和 = 4 - 2 + 5 = 7
```

**示例 2：**
```
输入：nums = [5, 6, 7, 8]
输出：8
解释：只选 [8]，交替和 = 8
```

**示例 3：**
```
输入：nums = [6, 2, 1, 2, 4, 5]
输出：10
解释：选取 [6, 1, 5]，交替和 = 6 - 1 + 5 = 10
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

---

## 解题思路

### 动态规划

定义两个状态：
- `even`：当前选取子序列长度为偶数（或 0）时的最大交替和
- `odd`：当前选取子序列长度为奇数时的最大交替和

对每个 `nums[i]`：
- 若选为新元素且放在偶数位：`even_new = max(even, odd + nums[i])`（在奇数状态后加一个偶数位元素）
- 若选为新元素且放在奇数位：`odd_new = max(odd, even - nums[i])`

初始：`even = 0`（空子序列），`odd = -inf`

### 贪心解释

实际上，最优策略是：
- 每次"上坡"时加上峰值，"下坡"时减去谷值
- 等价于选出所有局部最大值作为偶数位，局部最小值作为奇数位

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        # even: 当前已选子序列偶数长度时的最大交替和
        # odd: 当前已选子序列奇数长度时的最大交替和
        even, odd = 0, float('-inf')

        for x in nums:
            # 选 x 作为偶数位（在 odd 基础上添加）
            even_new = max(even, odd + x)
            # 选 x 作为奇数位（在 even 基础上减去）
            odd_new = max(odd, even - x)
            even, odd = even_new, odd_new

        # 答案是偶数长度的最大值（也包含空子序列）
        return even
```

### 方法二：贪心

```python
from typing import List

class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        # 贪心：累积正向收益（上坡时加差值）
        result = 0
        prev = 0  # 上一个元素值
        for x in nums:
            # 若当前值比上一个大，可以获得正向收益
            result += max(0, x - prev)
            prev = x
        return result
```

### 方法三：显式 DP 数组（对比学习）

```python
from typing import List

class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        n = len(nums)
        # dp[i][0]: 子序列末尾元素在偶数位时的最大值
        # dp[i][1]: 子序列末尾元素在奇数位时的最大值
        dp = [[0, float('-inf')] for _ in range(n + 1)]

        for i in range(1, n + 1):
            x = nums[i - 1]
            # 偶数位：在奇数位后加 x 或保持偶数状态
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + x)
            # 奇数位：在偶数位后减 x 或保持奇数状态
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - x)

        return dp[n][0]
```

## 关键点总结

1. 子序列可以不连续，因此可以选任意组合
2. 偶数位加、奇数位减，最优策略是尽量大的值在偶数位、尽量小的值在奇数位
3. DP 状态只需两个变量（当前子序列末尾处于偶数/奇数位的最优值）

---

## 易错点

- 注意"偶数位"从 0 开始（位置 0, 2, 4...），子序列第一个元素在偶数位
- `even` 初始化为 0（对应空子序列），`odd` 初始化为 `-inf`
