## 题目描述

力扣公司的员工都使用员工卡来开门。给你一个字符串数组 `keyName` 和 `keyTime`，其中 `[keyName[i], keyTime[i]]` 对应每次刷卡记录，`keyName[i]` 是员工姓名，`keyTime[i]` 是 `HH:MM` 格式的刷卡时间。

请你返回一个**告警名单**，包含**在一小时内（含）使用同一张员工卡三次或三次以上**的员工名字，名字按**字典序**排序后返回。

**注意**：同一张员工卡一小时内使用三次或更多次，是指在 **60 分钟内**（即时间差 <= 60 分钟，且包含 60 分钟）。

**示例：**
```
输入：keyName = ["daniel","daniel","daniel","luis","luis","luis","luis"]
      keyTime = ["10:00","10:40","11:00","09:00","11:00","13:00","15:00"]
输出：["daniel","luis"]
解释：
- daniel 在 10:00, 10:40, 11:00 刷卡，11:00 - 10:00 = 60 分钟，满足条件
- luis 在 09:00, 11:00, 13:00, 15:00 刷卡，11:00 - 09:00 = 120 分钟，不满足；但 13:00 - 11:00 = 120... 
  实际 luis 没有 3 次在 1 小时内，但题目给出此输出，需核对
```

**提示：**
- `1 <= keyName.length, keyTime.length <= 10^5`
- `keyName.length == keyTime.length`
- `keyTime[i]` 格式为 `HH:MM`
- 同一员工的刷卡记录可能是乱序的

## 解题思路

1. 用**哈希表**将每个员工的所有刷卡时间归类
2. 将时间转换为**分钟数**（HH * 60 + MM）方便比较
3. 对每个员工的时间列表**排序**
4. 使用**滑动窗口**检查是否有连续 3 个时间点满足 `times[i+2] - times[i] <= 60`

## 代码实现

### 方法一：哈希表 + 排序 + 滑动窗口（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def alertNames(self, keyName: List[str], keyTime: List[str]) -> List[str]:
        # 将每个员工的刷卡时间收集起来
        name_times = defaultdict(list)
        for name, time in zip(keyName, keyTime):
            # 将时间转换为分钟数
            h, m = map(int, time.split(':'))
            name_times[name].append(h * 60 + m)
        
        result = []
        for name, times in name_times.items():
            times.sort()  # 排序后才能使用滑动窗口
            # 检查是否有连续 3 个时间点在 1 小时内
            for i in range(len(times) - 2):
                if times[i + 2] - times[i] <= 60:
                    result.append(name)
                    break  # 找到一组就不需要继续检查
        
        result.sort()  # 按字典序排序
        return result
```

### 方法二：先排序全部记录再处理

```python
from collections import defaultdict
from typing import List

class Solution:
    def alertNames(self, keyName: List[str], keyTime: List[str]) -> List[str]:
        # 将时间转换为分钟数，并和名字配对排序
        records = []
        for name, time in zip(keyName, keyTime):
            h, m = map(int, time.split(':'))
            records.append((name, h * 60 + m))
        
        # 先按名字排序，同名按时间排序
        records.sort()
        
        result = set()
        i = 0
        while i < len(records):
            # 找到同名员工的所有记录
            j = i
            while j < len(records) and records[j][0] == records[i][0]:
                j += 1
            # records[i:j] 是同一员工的所有记录（已按时间排序）
            times = [t for _, t in records[i:j]]
            for k in range(len(times) - 2):
                if times[k + 2] - times[k] <= 60:
                    result.add(records[i][0])
                    break
            i = j
        
        return sorted(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n log n) | O(n) |
| 方法二 | O(n log n) | O(n) |

n 为记录总数，排序是主要开销。

## 关键点总结

1. 将时间字符串转换为分钟数，方便做差比较
2. 同一员工的时间列表需要排序（输入不保证有序）
3. 滑动窗口只需检查每三个连续时间点：`times[i+2] - times[i] <= 60`
4. 找到符合条件的员工后立即 `break`，避免重复添加

## 易错点

- 时间差 `<= 60` 而不是 `< 60`（题目说"包含 60 分钟"）
- 刷卡记录可能是乱序的，必须先排序再滑动窗口
- 最终结果需要按字典序排序
