## 题目描述

给你一个整数数组 `nums`，从中选出三个互不相邻的元素（任意两个选出的元素下标之差绝对值 >= 2），使其总和最大。

返回该最大和，如果无法选出三个这样的元素则返回 -1。

**示例 1：**

```
输入：nums = [2, 1, 6, 3, 8, 5]
输出：16
解释：选 nums[0]=2, nums[2]=6, nums[4]=8，互不相邻，和 16。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：-1
解释：长度为 3，无法选出三个互不相邻的元素（最少需要 5 个元素）。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

动态规划，类似打家劫舍但需要选恰好 3 个：
- `dp[i][k]` = 从 `nums[0..i]` 中选了 k 个互不相邻元素的最大和（k = 0, 1, 2, 3）。
- 转移：
  - 不选 nums[i]：`dp[i][k] = dp[i-1][k]`
  - 选 nums[i]：`dp[i][k] = dp[i-2][k-1] + nums[i]`（不能选 i-1）

## Python 代码实现

### 方法一：DP 选 3 个不相邻（推荐）

```python
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)
        if n < 5:  # 至少需要 5 个元素（如 [1,x,2,x,3]）
            return -1

        # dp[k][i] = 从 nums[0..i] 中选 k 个不相邻元素的最大和
        # 简化为滚动数组
        NEG_INF = float('-inf')
        # dp[k] = 前 i 个元素中选了 k 个不相邻的最大和
        # 使用三个变量：prev_prev（i-2）, prev（i-1），curr（i）

        dp = [[NEG_INF] * 4 for _ in range(n + 1)]
        dp[0][0] = 0  # 0 个元素，选 0 个，和为 0

        for i in range(1, n + 1):
            v = nums[i - 1]
            for k in range(4):
                # 不选 nums[i-1]
                dp[i][k] = dp[i - 1][k]
                # 选 nums[i-1]
                if k >= 1 and i >= 2 and dp[i - 2][k - 1] != NEG_INF:
                    dp[i][k] = max(dp[i][k], dp[i - 2][k - 1] + v)
                elif k >= 1 and i == 1 and k == 1:
                    dp[i][k] = max(dp[i][k], v)

        return dp[n][3] if dp[n][3] != NEG_INF else -1
```

### 方法二：前缀最大值贪心

```python
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)
        if n < 5:
            return -1

        # 方法：枚举中间元素的位置（至少在 2..n-3 之间）
        # 左边选一个 nums[l]，l <= mid - 2
        # 右边选一个 nums[r]，r >= mid + 2

        # 预计算 left_max[i] = max(nums[0..i]) 中满足间隔条件的值
        # 简化：直接用 DP

        # dp1[i] = nums[0..i] 中的最大值
        dp1 = [float('-inf')] * n
        dp1[0] = nums[0]
        for i in range(1, n):
            dp1[i] = max(dp1[i - 1], nums[i])

        # dp2[i] = 在 nums[0..i] 中选 2 个不相邻的最大和，第二个在 i 或之前
        dp2 = [float('-inf')] * n
        if n >= 2:
            dp2[1] = nums[0] + nums[1]  # 这两个相邻！
        # 修正：dp2[i] = 在 0..i 中选 2 个不相邻的最大和（两者差 >= 2）

        # 前缀最大值（选第一个）
        prev_max1 = float('-inf')  # 到 i-2 的最大值
        best_pair = float('-inf')  # 选了 2 个不相邻的最大和，第二个在 i-2 之前

        ans = float('-inf')

        # 枚举第三个元素的位置
        for i in range(4, n):  # 第三个至少在下标 4
            # 第二个在 i-2，第一个在 i-4 之前
            # 更新 best_pair：以 i-2 结尾的最优 2 个不相邻对
            pass

        # 完整 DP 方法
        INF = float('-inf')
        # dp[k] = 选了 k 个不相邻元素的最大和（当前可能选最后一个或不选）
        prev2 = [0, INF, INF, INF]  # dp[i-2]
        prev1 = [0, INF, INF, INF]  # dp[i-1]

        for v in nums:
            curr = [0, INF, INF, INF]
            for k in range(4):
                # 不选 v
                curr[k] = prev1[k]
                # 选 v（从 i-2 的状态转移）
                if k >= 1 and prev2[k - 1] != INF:
                    curr[k] = max(curr[k], prev2[k - 1] + v)
            prev2 = prev1
            prev1 = curr

        return prev1[3] if prev1[3] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，滚动数组

## 关键点总结

1. 选 k 个不相邻元素的 DP：`dp[k] = max(dp[k], dp_prev2[k-1] + v)`。
2. "不相邻"要求：选 nums[i] 时，前一个选的最晚在 nums[i-2]。
3. 用两个滚动变量 prev2 和 prev1 代替二维 DP，降低空间。

## 易错点

1. 至少需要 5 个元素才能选 3 个不相邻（间距 >= 2：indices 0, 2, 4）。
2. 初始化时 `prev2[0] = 0`（选 0 个的和为 0），其余为 -inf。
3. 不要混淆"选了 k 个"和"恰好选第 k 个"。
