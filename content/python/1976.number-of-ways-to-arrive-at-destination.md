## 题目描述

你在一个城市里，城市由 `n` 个路口组成，编号 `0` 到 `n-1`，以及 `roads` 数组，`roads[i] = [ui, vi, timei]` 表示 `ui` 和 `vi` 之间有一条双向道路，通行时间为 `timei` 分钟。

你想从 0 号路口出发，以**最短时间**到达 `n-1` 号路口，返回所有**最短时间路径**的数量，对 `10^9+7` 取余。

**提示：**
- `1 <= n <= 200`，`n-1 <= roads.length <= n*(n-1)/2`

---

## 解题思路

### 核心思想：Dijkstra + 路径计数

1. 用 Dijkstra 算法求从 0 到每个节点的最短距离 `dist[v]`
2. 同时维护 `ways[v]`：到达 `v` 的最短路径数
3. 当松弛 `dist[v]` 时更新 `ways[v] = ways[u]`；若发现等长路径，则 `ways[v] += ways[u]`

---

## 代码实现

### 方法一：Dijkstra + 计数（推荐）

```python
from typing import List
import heapq

class Solution:
    def countPaths(self, n: int, roads: List[List[int]]) -> int:
        MOD = 10**9 + 7

        # 构建邻接表
        graph = [[] for _ in range(n)]
        for u, v, t in roads:
            graph[u].append((v, t))
            graph[v].append((u, t))

        # Dijkstra
        INF = float('inf')
        dist = [INF] * n
        ways = [0] * n
        dist[0] = 0
        ways[0] = 1

        heap = [(0, 0)]  # (距离, 节点)

        while heap:
            d, u = heapq.heappop(heap)

            if d > dist[u]:
                continue  # 过时的状态

            for v, t in graph[u]:
                new_dist = d + t
                if new_dist < dist[v]:
                    # 发现更短路径
                    dist[v] = new_dist
                    ways[v] = ways[u]
                    heapq.heappush(heap, (new_dist, v))
                elif new_dist == dist[v]:
                    # 发现等长路径
                    ways[v] = (ways[v] + ways[u]) % MOD

        return ways[n - 1]
```

### 方法二：Dijkstra + 拓扑 DP

```python
from typing import List
import heapq

class Solution:
    def countPaths(self, n: int, roads: List[List[int]]) -> int:
        MOD = 10**9 + 7

        graph = [[] for _ in range(n)]
        for u, v, t in roads:
            graph[u].append((v, t))
            graph[v].append((u, t))

        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0
        heap = [(0, 0)]

        # 第一步：求最短距离
        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, t in graph[u]:
                if d + t < dist[v]:
                    dist[v] = d + t
                    heapq.heappush(heap, (dist[v], v))

        # 第二步：在最短路径 DAG 上 DP 计数
        ways = [0] * n
        ways[0] = 1

        # 按距离排序，拓扑顺序 DP
        order = sorted(range(n), key=lambda x: dist[x])
        for u in order:
            for v, t in graph[u]:
                if dist[u] + t == dist[v]:
                    ways[v] = (ways[v] + ways[u]) % MOD

        return ways[n - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O((n + e) log n) | O(n + e) |
| 方法二 | O((n + e) log n) | O(n + e) |

## 关键点总结

1. Dijkstra 求最短路同时维护路径数
2. 发现更短路：更新 `ways[v] = ways[u]`；发现等长路：`ways[v] += ways[u]`
3. 方法二先求距离再在 DAG 上 DP，逻辑更清晰

---

## 易错点

- 注意 `ways` 取模时机：`ways[v] = (ways[v] + ways[u]) % MOD`
- Dijkstra 中需要跳过过时状态（`d > dist[u]`）
