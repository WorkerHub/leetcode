## 题目描述

你正在探访一家农场，农场从左到右种植了一排果树。这些树用一个整数数组 `fruits` 表示，其中 `fruits[i]` 是第 `i` 棵树上的水果种类。

你想要尽可能多地收集水果。然而，农场的主人设定了一些严格的规矩，你必须按照要求采摘水果：
- 你只有两个篮子，并且每个篮子只能装单一类型的水果。每个篮子能装的水果总量没有限制。
- 你可以选择任意一棵树开始采摘，你必须从每棵树（包括开始采摘的树）上恰好摘一个水果。采摘的水果应当符合篮子的要求。
- 一旦你到达一棵树，但水果不符合篮子的要求，那么你必须停止采摘。

给你一个整数数组 `fruits`，返回你可以收集的水果的最大数目。

**示例 1：**
```
输入：fruits = [1,2,1]
输出：3
解释：可以采摘全部 3 棵树。
```

**示例 2：**
```
输入：fruits = [0,1,2,2]
输出：3
解释：可以采摘 [1,2,2]。
如果从第一棵树开始采摘，则只能采摘 [0,1] 这两棵树。
```

**示例 3：**
```
输入：fruits = [1,2,3,2,2]
输出：4
解释：可以采摘 [2,3,2,2]。
如果从第一棵树开始采摘，则只能采摘 [1,2]。
```

**示例 4：**
```
输入：fruits = [3,3,3,1,2,1,1,2,3,3,4]
输出：5
解释：可以采摘 [1,2,1,1,2]。
```

**提示：**
- 1 <= fruits.length <= 10^5
- 0 <= fruits[i] < fruits.length

## 解题思路

这道题本质上是求：**最长连续子数组，使得子数组中最多包含两种不同的元素**。

这是一个经典的滑动窗口问题。

**算法流程：**
1. 使用滑动窗口 [left, right]
2. 使用哈希表记录窗口内每种水果的数量
3. 右指针不断扩展窗口
4. 当窗口内水果种类超过 2 种时，左指针收缩窗口
5. 记录过程中的最大窗口大小

**关键观察：**
- 问题转化为：找最长子数组，最多包含 2 种不同数字
- 滑动窗口维护一个满足条件的区间
- 窗口右移时增加元素，左移时删除元素

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        # 记录窗口内每种水果的数量
        basket = defaultdict(int)
        left = 0
        max_fruits = 0
        
        for right in range(len(fruits)):
            # 右指针的水果放入篮子
            basket[fruits[right]] += 1
            
            # 如果水果种类超过 2 种，收缩左边界
            while len(basket) > 2:
                basket[fruits[left]] -= 1
                if basket[fruits[left]] == 0:
                    del basket[fruits[left]]
                left += 1
            
            # 更新最大值
            max_fruits = max(max_fruits, right - left + 1)
        
        return max_fruits
```

### 方法二：优化的滑动窗口

```python
from typing import List

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        basket = {}
        left = 0
        
        for right in range(len(fruits)):
            # 记录水果及其最后出现位置
            basket[fruits[right]] = right
            
            # 如果种类超过 2，移除最早的水果
            if len(basket) > 2:
                # 找到最小的位置（最早加入的水果）
                min_pos = min(basket.values())
                # 删除该水果
                del basket[fruits[min_pos]]
                # 左指针移到该水果的下一个位置
                left = min_pos + 1
        
        return len(fruits) - left
```

### 方法三：滑动窗口（不使用 defaultdict）

```python
from typing import List

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        basket = {}
        left = 0
        max_fruits = 0
        
        for right in range(len(fruits)):
            # 加入右边的水果
            if fruits[right] in basket:
                basket[fruits[right]] += 1
            else:
                basket[fruits[right]] = 1
            
            # 收缩窗口直到满足条件
            while len(basket) > 2:
                basket[fruits[left]] -= 1
                if basket[fruits[left]] == 0:
                    del basket[fruits[left]]
                left += 1
            
            max_fruits = max(max_fruits, right - left + 1)
        
        return max_fruits
```

### 方法四：记录上一个水果的位置（最优）

```python
from typing import List

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        n = len(fruits)
        if n <= 2:
            return n
        
        # 记录两种水果
        fruit1, fruit2 = fruits[0], None
        # 记录第二种水果开始的位置
        fruit2_start = 0
        # 记录连续相同水果的起始位置
        last_change = 0
        max_fruits = 0
        
        for i in range(n):
            if fruits[i] == fruit1:
                pass
            elif fruit2 is None or fruits[i] == fruit2:
                if fruit2 is None:
                    fruit2 = fruits[i]
                    fruit2_start = i
            else:
                # 遇到第三种水果
                max_fruits = max(max_fruits, i - fruit2_start)
                fruit2_start = last_change
                fruit1, fruit2 = fruits[i - 1], fruits[i]
            
            # 更新连续相同水果的位置
            if i > 0 and fruits[i] != fruits[i - 1]:
                last_change = i
        
        return max(max_fruits, n - fruit2_start)
```

## 复杂度分析

**方法一、三（滑动窗口）：**
- 时间复杂度：O(n)，每个元素最多被访问两次（一次加入，一次删除）
- 空间复杂度：O(1)，哈希表最多存储 3 个元素

**方法二（优化滑动窗口）：**
- 时间复杂度：O(n)，但每次找最小位置需要 O(2) = O(1)
- 空间复杂度：O(1)

## 关键点总结

1. **问题转化**：将实际问题转化为"最长子数组包含最多 k 种元素"（k=2）
2. **滑动窗口模板**：右指针扩展，条件不满足时左指针收缩
3. **哈希表用途**：记录窗口内元素的计数或位置
4. **窗口维护**：
   - 加入元素：直接加到哈希表
   - 删除元素：计数减到 0 时从哈希表删除
5. **最大值更新**：每次扩展窗口后更新答案

## 易错点

1. **边界条件**：数组长度 <= 2 时可以直接返回长度
2. **哈希表删除**：计数为 0 时要从哈希表中删除键
3. **窗口长度计算**：是 `right - left + 1`，不是 `right - left`
4. **while vs if**：收缩窗口用 while，不是 if
5. **答案初始化**：max_fruits 初始化为 0，不是 1
