## 题目描述

给你两个长度相同的整数数组 `target` 和 `arr`。

每一步中，你可以选择 `arr` 的任意**非空子数组**并将它逆序。你可以执行此过程任意次。

如果你能让 `arr` 变得与 `target` 相同，返回 `True`；否则，返回 `False`。

**示例 1：**
```
输入：target = [1,2,3,4], arr = [2,4,1,3]
输出：true
解释：按照如下步骤可以将 arr 转变为 target：
     1. 逆序子数组 [2,4,1] ，arr 变成 [1,4,2,3]
     2. 逆序子数组 [4,2] ，arr 变成 [1,2,4,3]
     3. 逆序子数组 [4,3] ，arr 变成 [1,2,3,4]
```

**示例 2：**
```
输入：target = [7], arr = [7]
输出：true
解释：arr 等于 target 无需任何操作。
```

**示例 3：**
```
输入：target = [3,7,9], arr = [3,7,11]
输出：false
解释：arr 不包含值为 9 的元素，所以无论如何操作都不能变成 target。
```

**提示：**
- `target.length == arr.length`
- `1 <= target.length <= 1000`
- `1 <= target[i] <= 1000`
- `1 <= arr[i] <= 1000`

## 解题思路

**关键洞察：** 通过若干次子数组翻转，可以实现数组的**任意排列**（类似冒泡排序的原理）。

因此，`arr` 能变成 `target` 的充要条件是：**两个数组包含完全相同的元素（包括重复元素的个数）**。

验证方法：
1. **排序比较**：将两个数组排序后逐元素比较
2. **哈希表计数**：统计每个元素的出现次数，比较两个频率表

## Python 代码实现

### 方法一：排序比较（推荐，最简洁）

```python
from typing import List

class Solution:
    def canBeEqual(self, target: List[int], arr: List[int]) -> bool:
        # 排序后比较，若相等则包含相同元素
        return sorted(target) == sorted(arr)
```

### 方法二：哈希表计数

```python
from typing import List
from collections import Counter

class Solution:
    def canBeEqual(self, target: List[int], arr: List[int]) -> bool:
        # Counter 统计每个元素的出现次数
        # 如果两个频率字典相等，则两数组包含完全相同的元素
        return Counter(target) == Counter(arr)
```

### 方法三：手动计数（不用库函数，帮助理解）

```python
from typing import List

class Solution:
    def canBeEqual(self, target: List[int], arr: List[int]) -> bool:
        if len(target) != len(arr):
            return False

        # 手动统计频率
        count = {}
        for num in target:
            count[num] = count.get(num, 0) + 1
        for num in arr:
            count[num] = count.get(num, 0) - 1

        # 如果所有元素的计数都归零，则两数组元素相同
        return all(v == 0 for v in count.values())
```

## 复杂度分析

**方法一（排序）：**
- 时间复杂度：O(n log n)，排序的时间
- 空间复杂度：O(n)，排序需要额外空间（Python 中 sorted 返回新列表）

**方法二（Counter）：**
- 时间复杂度：O(n)，遍历两个数组
- 空间复杂度：O(n)，哈希表存储频率

## 关键点总结

1. 子数组翻转可以实现任意排列（这是核心数学洞察）
2. 因此问题转化为：两数组是否包含完全相同的元素（频率也相同）
3. Python 的 `sorted()` 和 `Counter` 都可以一行解决

## 易错点

- 不要忘记考虑重复元素：`[1,1,2]` 和 `[1,2,2]` 排序后不同，正确返回 False
- 不要仅比较元素种类（集合相等），还要比较每个元素的出现次数
