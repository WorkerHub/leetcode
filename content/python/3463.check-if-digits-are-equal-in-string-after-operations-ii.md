## 题目描述

与 3461 题相同，但字符串长度最大为 10^5，需要高效计算组合数 C(n-2, i) mod 10。

**提示：**
- `3 <= s.length <= 10^5`

## 解题思路

最终结果 = sum(C(n-2, i) * d[i]) mod 10（i 从 0 到 n-2）。

由于 10 = 2 * 5，用中国剩余定理（CRT）分别对 2 和 5 求模，然后合并。

C(n, k) mod 2 和 C(n, k) mod 5 用卢卡斯定理计算。

**卢卡斯定理**：对质数 p，C(n, k) mod p = product(C(n_i, k_i)) mod p，其中 n_i 和 k_i 是 n 和 k 在 p 进制下的各位。

## Python 代码实现

### 方法一：卢卡斯定理 + CRT

```python
class Solution:
    def hasSameDigits(self, s: str) -> bool:
        n = len(s)
        digits = [int(c) for c in s]

        def lucas(n, k, p):
            """C(n, k) mod p，使用卢卡斯定理"""
            if k == 0:
                return 1
            if k > n:
                return 0
            # 在 p 进制下取各位
            ni, ki = n % p, k % p
            if ki > ni:
                return 0
            # C(ni, ki) mod p（直接计算，ni < p）
            c = 1
            for i in range(ki):
                c = c * (ni - i) % p
            for i in range(1, ki + 1):
                c = c * pow(i, p - 2, p) % p
            return c * lucas(n // p, k // p, p) % p

        def compute_mod(start, length, mod):
            """sum(C(length-1, i) * d[start+i]) mod mod"""
            result = 0
            for i in range(length):
                c = lucas(length - 1, i, mod)
                result = (result + c * digits[start + i]) % mod
            return result

        # 对 mod=2 和 mod=5 分别计算
        def compute(start, length):
            r2 = compute_mod(start, length, 2)
            r5 = compute_mod(start, length, 5)
            # CRT: x ≡ r2 (mod 2), x ≡ r5 (mod 5) -> x mod 10
            # 穷举 x in 0..9
            for x in range(10):
                if x % 2 == r2 and x % 5 == r5:
                    return x
            return 0

        return compute(0, n - 1) == compute(1, n - 1)
```

class Solution:
    def hasSameDigits(self, s: str) -> bool:
        digits = list(map(int, s))

        while len(digits) > 2:
            digits = [(digits[i] + digits[i+1]) % 10 for i in range(len(digits)-1)]

        return digits[0] == digits[1]

### 方法三：优化卢卡斯计算

```python
class Solution:
    def hasSameDigits(self, s: str) -> bool:
        n = len(s)
        d = list(map(int, s))
        N = n - 2  # 最终 C(N, i) for i in 0..N+1

        # 利用卢卡斯定理对 p=2 和 p=5 分别计算 C(N, i) mod p

        def bincoef_mod_p(N, p):
            """返回 C(N, 0), C(N, 1), ..., C(N, N) mod p 的列表"""
            # 使用卢卡斯定理：将 N 写成 p 进制
            # C(N, i) mod p = product of C(N_j, i_j) mod p，N_j 和 i_j 是各位

            # 对小的 p，可以直接用 DP
            # dp[i] = C(N, i) mod p
            result = [0] * (N + 2)
            result[0] = 1
            for j in range(N):
                # 从右向左更新，避免覆盖
                new_result = [0] * (N + 2)
                for i in range(N + 2):
                    if result[i]:
                        new_result[i] = (new_result[i] + result[i]) % p
                        if i + 1 <= N + 1:
                            new_result[i + 1] = (new_result[i + 1] + result[i]) % p
                result = new_result
            return result

        # 这个方法对 N 很大时不适用，改用卢卡斯定理的递推
        # 直接使用卢卡斯
        def lucas(n, k, p):
            if k > n:
                return 0
            if k == 0 or k == n:
                return 1
            return lucas(n // p, k // p, p) * lucas(n % p, k % p, p) % p

        def small_c(n, k, p):
            """C(n, k) mod p，n < p"""
            if k > n:
                return 0
            c = 1
            for i in range(k):
                c = c * (n - i) % p
            for i in range(1, k + 1):
                c = c * pow(i, p - 2, p) % p
            return c

        def sum_d(start, p):
            """sum(C(n-2, i) * d[start+i]) mod p"""
            s = 0
            for i in range(n - 1):
                c = lucas(n - 2, i, p) if n - 2 >= i else 0
                s = (s + c * d[start + i]) % p
            return s

        # 分别对 2 和 5 计算
        a2 = sum_d(0, 2)
        b2 = sum_d(1, 2)
        a5 = sum_d(0, 5)
        b5 = sum_d(1, 5)

        # 合并 CRT
        def crt(r2, r5):
            for x in range(10):
                if x % 2 == r2 and x % 5 == r5:
                    return x
            return 0

        return crt(a2, a5) == crt(b2, b5)
```

## 复杂度分析

- 方法一：O(n * log_p(n)) 使用卢卡斯定理
- 空间复杂度：O(n)

## 关键点总结

1. 最终结果 = 二项式卷积对 10 取模
2. 对 10 取模 = 对 2 取模 + 对 5 取模（中国剩余定理）
3. 卢卡斯定理高效计算大组合数对质数取模

## 易错点

1. 卢卡斯定理只适用于质数模
2. CRT 合并时，找 0-9 中满足 x≡r2(mod 2) 且 x≡r5(mod 5) 的值
3. C(N, i) 其中 N 可能很大（10^5 量级）
