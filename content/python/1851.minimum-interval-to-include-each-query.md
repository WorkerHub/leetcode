## 题目描述

给你一个二维整数数组 `intervals`，其中 `intervals[i] = [lefti, righti]` 表示第 i 个区间。

另给你一个整数数组 `queries`，对于每个 `queries[j]`，返回包含 `queries[j]` 的**最小区间的大小**，若不存在包含 `queries[j]` 的区间，则返回 -1。

区间大小 = `right - left + 1`。

**示例：**
```
输入：intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]
输出：[3,3,1,4]
```

## 解题思路

**离线查询 + 排序 + 最小堆**：

1. 将 queries 按值排序（记录原始下标）
2. 将 intervals 按左端点排序
3. 用指针扫描 queries（从小到大），对于每个 query q：
   - 将所有左端点 <= q 的区间加入最小堆（按区间大小）
   - 从堆中移除所有右端点 < q 的区间（不再包含 q）
   - 堆顶即为最小的包含 q 的区间

## 代码实现

### 方法一：排序 + 最小堆（推荐）

```python
import heapq
from typing import List

class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        # intervals 按左端点排序
        intervals.sort()
        # queries 按值排序，保留原始下标
        sorted_queries = sorted(enumerate(queries), key=lambda x: x[1])

        result = [-1] * len(queries)
        heap = []   # (区间大小, 右端点)
        ptr = 0     # intervals 的指针
        n = len(intervals)

        for orig_idx, q in sorted_queries:
            # 将所有左端点 <= q 的区间加入堆
            while ptr < n and intervals[ptr][0] <= q:
                left, right = intervals[ptr]
                size = right - left + 1
                heapq.heappush(heap, (size, right))
                ptr += 1

            # 移除不包含 q 的区间（右端点 < q）
            while heap and heap[0][1] < q:
                heapq.heappop(heap)

            if heap:
                result[orig_idx] = heap[0][0]

        return result
```

### 方法二：二分查找（每个 query 独立查询）

```python
import bisect
from typing import List

class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        # 对每个 query，找包含它且最小的区间（暴力，仅作理解）
        result = []
        for q in queries:
            min_size = float('inf')
            for l, r in intervals:
                if l <= q <= r:
                    min_size = min(min_size, r - l + 1)
            result.append(min_size if min_size != float('inf') else -1)
        return result
        # O(n * m)，大数据会 TLE
```

## 复杂度分析

- **方法一（排序 + 堆）**：
  - 时间复杂度：O((n + m) log n)，n 为区间数，m 为查询数
  - 空间复杂度：O(n + m)
- **方法二（暴力）**：
  - 时间复杂度：O(n * m)

## 关键点总结

1. 离线处理：将 queries 排序后顺序扫描，利用单调性批量加入区间
2. 堆按区间大小排序，快速找最小区间
3. 懒删除：移除右端点 < 当前 query 的区间（这些区间不再有用）

## 易错点

- 原始下标要保留，用于填充结果数组
- 移除过期区间（right < q）用 while 循环，不是 if
