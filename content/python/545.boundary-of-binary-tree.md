## 题目描述

给定一棵二叉树，以逆时针顺序从根开始返回其边界。边界按顺序包括左边界、叶子节点和右边界，不包含重复的节点。

**定义：**
- 左边界：从根到最左侧节点的路径（不包括叶子节点）
- 右边界：从根到最右侧节点的路径（不包括叶子节点）
- 叶子节点：没有子节点的节点

**示例 1：**
```
输入：
    1
     \
      2
     / \
    3   4

输出：[1, 3, 4, 2]

解释：
左边界为空，因为没有左子树
叶子节点：[3, 4]
右边界：[2]（从下到上）
最终结果：[1] + [] + [3,4] + [2] = [1,3,4,2]
```

**示例 2：**
```
输入：
      1
     / \
    2   3
   / \
  4   5

输出：[1, 2, 4, 5, 3]

解释：
左边界：[2]
叶子节点：[4, 5]
右边界：[3]
最终结果：[1] + [2] + [4,5] + [3] = [1,2,4,5,3]
```

**提示：**
- 树中节点数在范围 [1, 10^4] 内
- -1000 <= Node.val <= 1000

## 解题思路

这道题需要分别处理三个部分：左边界、叶子节点、右边界。

**核心思想：**
1. 左边界：沿着左子树向下，优先选择左孩子，无左孩子则选右孩子
2. 叶子节点：中序遍历收集所有叶子节点
3. 右边界：沿着右子树向下，优先选择右孩子，无右孩子则选左孩子

**注意事项：**
- 根节点总是包含在边界中
- 如果根节点是叶子节点，不要重复添加
- 右边界需要从下到上，所以要反转

## Python 代码实现

### 方法一：分别处理三部分（推荐）

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def boundaryOfBinaryTree(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        # 如果根节点是叶子节点，直接返回
        if not root.left and not root.right:
            return [root.val]
        
        result = [root.val]
        
        # 1. 添加左边界（不包括叶子节点）
        self.addLeftBoundary(root.left, result)
        
        # 2. 添加所有叶子节点
        self.addLeaves(root, result)
        
        # 3. 添加右边界（不包括叶子节点，从下到上）
        self.addRightBoundary(root.right, result)
        
        return result
    
    def addLeftBoundary(self, node: Optional[TreeNode], result: List[int]) -> None:
        """添加左边界（不包括叶子节点）"""
        while node:
            # 不是叶子节点才添加
            if node.left or node.right:
                result.append(node.val)
            
            # 优先选择左孩子，无左孩子则选右孩子
            if node.left:
                node = node.left
            else:
                node = node.right
    
    def addRightBoundary(self, node: Optional[TreeNode], result: List[int]) -> None:
        """添加右边界（不包括叶子节点，从下到上）"""
        temp = []
        while node:
            # 不是叶子节点才添加
            if node.left or node.right:
                temp.append(node.val)
            
            # 优先选择右孩子，无右孩子则选左孩子
            if node.right:
                node = node.right
            else:
                node = node.left
        
        # 反转后添加到结果（从下到上）
        result.extend(temp[::-1])
    
    def addLeaves(self, node: Optional[TreeNode], result: List[int]) -> None:
        """添加所有叶子节点（从左到右）"""
        if not node:
            return
        
        # 如果是叶子节点，添加到结果
        if not node.left and not node.right:
            result.append(node.val)
            return
        
        # 递归处理左右子树
        self.addLeaves(node.left, result)
        self.addLeaves(node.right, result)
```

### 方法二：统一递归处理

```python
class Solution:
    def boundaryOfBinaryTree(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        if not root.left and not root.right:
            return [root.val]
        
        result = []
        
        # 处理根节点
        result.append(root.val)
        
        # 获取左边界
        def getLeftBoundary(node: Optional[TreeNode]) -> List[int]:
            if not node or (not node.left and not node.right):
                return []
            
            boundary = [node.val]
            if node.left:
                boundary.extend(getLeftBoundary(node.left))
            else:
                boundary.extend(getLeftBoundary(node.right))
            
            return boundary
        
        # 获取叶子节点
        def getLeaves(node: Optional[TreeNode]) -> List[int]:
            if not node:
                return []
            
            if not node.left and not node.right:
                return [node.val]
            
            return getLeaves(node.left) + getLeaves(node.right)
        
        # 获取右边界
        def getRightBoundary(node: Optional[TreeNode]) -> List[int]:
            if not node or (not node.left and not node.right):
                return []
            
            boundary = []
            if node.right:
                boundary.extend(getRightBoundary(node.right))
            else:
                boundary.extend(getRightBoundary(node.left))
            
            boundary.append(node.val)
            return boundary
        
        # 组合结果
        if root.left:
            result.extend(getLeftBoundary(root.left))
        
        result.extend(getLeaves(root))
        
        if root.right:
            result.extend(getRightBoundary(root.right))
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n)，其中 n 是树中节点的数量，每个节点最多访问一次
- 空间复杂度：O(h)，其中 h 是树的高度，递归调用栈的深度

## 图解示例

```
示例树：
        1
       / \
      2   3
     / \
    4   5

处理过程：
1. 根节点：[1]
2. 左边界：[2]（不包括叶子4）
3. 叶子节点：[4, 5]（从左到右）
4. 右边界：[3]（从下到上）

最终结果：[1, 2, 4, 5, 3]
```

## 关键点总结

1. 分别处理左边界、叶子节点、右边界三个部分
2. 左边界优先选择左孩子，右边界优先选择右孩子
3. 叶子节点不应该在边界中重复出现
4. 右边界需要反转（从下到上）
5. 特殊处理根节点是叶子节点的情况

## 易错点

1. 忘记排除叶子节点导致重复添加
2. 右边界没有反转，顺序错误
3. 没有处理根节点是叶子节点的特殊情况
4. 左边界和右边界的遍历方向错误
