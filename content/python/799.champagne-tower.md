## 题目描述

我们把玻璃杯摆成金字塔的形状，其中第一层有 1 个玻璃杯，第二层有 2 个，依次类推到第 100 层，每个玻璃杯 (250ml) 将盛有香槟。

从顶层的第一个玻璃杯开始倾倒一些香槟，当顶层的杯子满了，任何溢出的香槟都会立刻等流量的流向左右两侧的玻璃杯。当那两个玻璃杯又满了，就会等流量的流向它们左右两侧的玻璃杯，依次类推。（当最底层的玻璃杯满了，香槟会流到地板上）

例如，在倾倒一杯香槟后，最顶层的玻璃杯满了。倾倒了两杯香槟后，第二层的两个玻璃杯各自盛放一半的香槟。在倒三杯香槟后，第二层的香槟满了 - 此时总共有三个满的玻璃杯。

给定倾倒了非负整数杯香槟后，返回第 query_row 行、第 query_glass 列的玻璃杯所盛放的香槟占玻璃杯容积的比例（query_row 和 query_glass 都从 0 开始）。

**示例 1:**
```
输入: poured = 1, query_row = 1, query_glass = 1
输出: 0.00000
解释: 在倾倒 1 杯香槟后，顶层的杯子满了，但第二层的两个杯子是空的。
```

**示例 2:**
```
输入: poured = 2, query_row = 1, query_glass = 1
输出: 0.50000
解释: 在倾倒 2 杯香槟后，第二层的两个杯子各自盛放一半的香槟。
```

**示例 3:**
```
输入: poured = 100000009, query_row = 33, query_glass = 17
输出: 1.00000
```

**提示:**
- 0 <= poured <= 10^9
- 0 <= query_glass <= query_row < 100

## 解题思路

这是一道模拟流体分配的动态规划问题。核心思想是：**从上到下逐层模拟香槟的流动过程**。

### 核心观察

1. **流动规则**：每个杯子最多装 1 单位的香槟，多余的香槟会均分给左下和右下两个杯子
2. **金字塔结构**：第 i 层有 i+1 个杯子，每个杯子（除了边界）会接收来自上方两个杯子的香槟
3. **状态转移**：如果第 i 层第 j 个杯子的香槟量为 x，那么流向下层的香槟量为 max(0, x-1)，左右各分 (x-1)/2

### 算法流程

1. 创建一个二维数组 `tower[i][j]` 表示第 i 层第 j 个杯子接收到的香槟总量
2. 初始化：`tower[0][0] = poured`（所有香槟倒入顶层杯子）
3. 逐层模拟：
   - 对于每个杯子，如果香槟量大于 1，计算溢出量
   - 将溢出的香槟平均分配给左下和右下的杯子
4. 返回目标杯子的香槟量（最大为 1）

### 优化思路

由于只需要计算到第 query_row 层，不需要计算所有 100 层，可以提前终止。另外，可以使用滚动数组优化空间复杂度。

## Python 代码实现

### 方法一：二维数组模拟（推荐）

```python
class Solution:
    def champagneTower(self, poured: int, query_row: int, query_glass: int) -> float:
        # 创建二维数组存储每个杯子接收到的香槟总量
        # tower[i][j] 表示第 i 层第 j 个杯子的香槟量
        tower = [[0.0] * (i + 1) for i in range(query_row + 1)]
        
        # 所有香槟倒入顶层杯子
        tower[0][0] = poured
        
        # 逐层模拟香槟流动
        for i in range(query_row):
            for j in range(i + 1):
                # 计算当前杯子的溢出量
                overflow = (tower[i][j] - 1.0) / 2.0
                
                # 如果有溢出，分配给下层的两个杯子
                if overflow > 0:
                    tower[i + 1][j] += overflow      # 左下杯子
                    tower[i + 1][j + 1] += overflow  # 右下杯子
        
        # 返回目标杯子的香槟量，最多为 1
        return min(1.0, tower[query_row][query_glass])
```

### 方法二：滚动数组优化空间

```python
class Solution:
    def champagneTower(self, poured: int, query_row: int, query_glass: int) -> float:
        # 使用两个一维数组交替存储当前层和下一层
        curr = [0.0] * (query_row + 2)
        curr[0] = poured
        
        # 逐层计算
        for i in range(query_row):
            next_row = [0.0] * (query_row + 2)
            
            for j in range(i + 1):
                # 计算溢出量
                overflow = (curr[j] - 1.0) / 2.0
                
                if overflow > 0:
                    next_row[j] += overflow
                    next_row[j + 1] += overflow
            
            curr = next_row
        
        return min(1.0, curr[query_glass])
```

### 方法三：原地修改优化

```python
class Solution:
    def champagneTower(self, poured: int, query_row: int, query_glass: int) -> float:
        # 使用一个足够大的二维数组
        tower = [[0.0] * 102 for _ in range(102)]
        tower[0][0] = poured
        
        # 模拟流动过程
        for i in range(query_row + 1):
            for j in range(i + 1):
                if tower[i][j] > 1:
                    # 计算溢出量并分配
                    overflow = (tower[i][j] - 1) / 2
                    tower[i + 1][j] += overflow
                    tower[i + 1][j + 1] += overflow
                    # 当前杯子保留 1 单位
                    tower[i][j] = 1
        
        return tower[query_row][query_glass]
```

## 复杂度分析

### 方法一：二维数组模拟
- **时间复杂度**：O(R^2)，其中 R 是 query_row。需要计算从第 0 层到第 R 层的所有杯子，总共约 R^2 个杯子
- **空间复杂度**：O(R^2)，存储二维数组

### 方法二：滚动数组
- **时间复杂度**：O(R^2)
- **空间复杂度**：O(R)，只需要存储当前层和下一层

### 方法三：原地修改
- **时间复杂度**：O(R^2)
- **空间复杂度**：O(R^2)

## 图解示例

以 poured = 2 为例：

```
层 0:        [2.0]
            /     \
           /       \
层 1:   [0.5]     [0.5]
         |  \     /  |
         |   \   /   |
层 2: [0.0] [0.0] [0.0]

计算过程：
1. tower[0][0] = 2.0，溢出 (2.0 - 1.0) / 2 = 0.5
2. tower[1][0] += 0.5，tower[1][1] += 0.5
3. tower[1][0] = 0.5 < 1，无溢出
4. tower[1][1] = 0.5 < 1，无溢出
```

## 关键点总结

1. **模拟思想**：这是一道典型的模拟题，关键是理解香槟的流动规则
2. **状态定义**：用 tower[i][j] 表示第 i 层第 j 个杯子接收到的香槟总量（不是最终装的量）
3. **溢出计算**：只有当杯子的香槟量大于 1 时才会溢出，溢出量为 (amount - 1) / 2
4. **边界处理**：最终返回时要确保结果不超过 1.0
5. **优化策略**：只需要计算到目标层，不需要计算所有 100 层

## 易错点

1. **状态含义混淆**：tower[i][j] 存储的是接收到的总香槟量，而不是最终装的量。一个杯子可能接收 2 单位但只装 1 单位
2. **溢出计算错误**：溢出量是 (amount - 1) / 2，不要忘记除以 2（因为要分给两个杯子）
3. **数组越界**：注意第 i 层有 i+1 个杯子，索引从 0 到 i
4. **浮点数精度**：使用 float 而不是 int，初始化时用 0.0
5. **返回值限制**：最后要返回 min(1.0, tower[query_row][query_glass])，不能直接返回原始值
