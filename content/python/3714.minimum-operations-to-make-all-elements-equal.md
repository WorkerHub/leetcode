## 题目描述

给定一个整数数组 `nums`，每次操作可以选择数组中任意两个元素，将它们都替换为它们的平均值（向下取整）。求使数组所有元素相等所需的最少操作次数。

若无法使所有元素相等，返回 `-1`。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：2
解释：
操作 1：选 1 和 3，变为 [2,2,3,4]（平均为 2）
操作 2：选 2 和 4，变为 [2,3,3,3]（不对）...
实际最优：操作 [2,4]，变为 [3,3,3,3] -> 但 1 没变。
需要重新分析。
```

**示例 2：**
```
输入：nums = [5,5,5]
输出：0
解释：已经相等。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

观察：若数组中所有元素之和不能被 `n` 整除（n 为元素个数），则无法使所有元素相等（因为每次操作不改变总和，而目标是所有元素等于 `sum/n`）。

若可以达成目标（设目标值为 `target = sum(nums) // n`）：
- 统计当前不等于 `target` 的元素数量。
- 每次操作最多消除 2 个不等元素（若两个不等元素平均值 = target，则一次操作搞定）。
- 贪心配对：将需要增大的元素与需要减小的元素配对。

最少操作次数 = `ceil(不等元素数量 / 2)`（若每次都能配对成功）。

## Python 代码实现

### 方法一：贪心统计（推荐）

```python
from typing import List
import math

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)

        # 若总和不能整除 n，无法使所有元素相等
        if total % n != 0:
            return -1

        target = total // n

        # 统计不等于 target 的元素数量
        not_equal = sum(1 for x in nums if x != target)

        # 每次操作可以修正 2 个元素（将一个太大和一个太小的配对）
        # 最少操作次数为 ceil(not_equal / 2)
        return math.ceil(not_equal / 2)
```

### 方法二：排序后双指针

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)

        if total % n != 0:
            return -1

        target = total // n
        ops = 0

        # 将大于 target 的和小于 target 的分开
        larger = [x for x in nums if x > target]
        smaller = [x for x in nums if x < target]

        # 每次从两组各取一个配对操作
        i, j = 0, 0
        while i < len(larger) and j < len(smaller):
            ops += 1
            # 简化：假设每次能正好消除一对
            i += 1
            j += 1

        # 剩余未配对的（不会有，因为总和守恒）
        ops += (len(larger) - i) + (len(smaller) - j)

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 平均值操作不改变总和，因此目标值唯一：`sum/n`
2. 若总和不能整除 n，永远无法达成
3. 每次配对一个偏大和一个偏小的元素，最少操作 = `ceil(异常元素数 / 2)`

## 易错点

1. 整数平均值向下取整可能导致某些情况无解（需要验证 `total % n == 0`）
2. 单数个不等元素需要向上取整
