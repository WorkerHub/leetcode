## 题目描述

给你一个字符串 `s` 和整数 `k`，执行以下操作 `k` 次：将 `s` 的所有字符依次插入到原字符串相应字符之间（即将 `s` 与其自身交错插入）。

返回 `k` 次操作后字符串的总长度，结果对 `10^9 + 7` 取模。

**示例 1：**

```
输入：s = "a", k = 3
输出：8
解释：
初始："a"（长度1）
操作1后："a"插入"a"中→"aa"（长度2）？
实际规则：长度变化为 len * 2 - 1 每次？
```

**提示：**

- `1 <= s.length <= 10^5`
- `0 <= k <= 10^9`

## 解题思路

分析长度变化规律：

设初始长度为 `n`，每次操作后长度如何变化：
- 操作后长度 = `2 * 当前长度 - 1`（在每两个相邻字符间插入一个字符）

递推：`L_0 = n`，`L_i = 2 * L_{i-1} - 1`

解递推：`L_k = (n - 1) * 2^k + 1`

用快速幂计算 `2^k mod (10^9 + 7)`。

## Python 代码实现

### 方法一：数学公式 + 快速幂（推荐）

```python
class Solution:
    def lengthAfterTransformations(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        if k == 0:
            return n
        # L_k = (n - 1) * 2^k + 1
        ans = ((n - 1) * pow(2, k, MOD) + 1) % MOD
        return ans
```

### 方法二：迭代验证（小 k）

```python
class Solution:
    def lengthAfterTransformations(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        length = len(s)
        for _ in range(min(k, 60)):  # 超过 60 次数值极大
            length = (2 * length - 1) % MOD
        if k > 60:
            # 用公式补充
            pass
        return length
```

## 复杂度分析

- 时间复杂度：O(log k)，快速幂
- 空间复杂度：O(1)

## 关键点总结

1. 递推关系：`L_{i+1} = 2 * L_i - 1`
2. 通项公式：`L_k = (n-1) * 2^k + 1`
3. 大数取模使用 Python 内置 `pow(a, b, mod)`

## 易错点

1. k=0 时直接返回原始长度
2. 递推关系推导：每两个相邻字符间插入一个字符，n 个字符有 n-1 个间隔，长度变为 n + (n-1) = 2n-1
3. 取模时结果可能为 0
