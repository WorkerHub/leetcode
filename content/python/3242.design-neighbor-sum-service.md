## 题目描述

给你一个 `n x n` 的二维整数矩阵 `grid`（包含 0 到 n^2-1 的不重复整数）。

实现 `neighborSum` 类：
- `neighborSum(int[][] grid)`：构造函数
- `int adjacentSum(int value)`：返回 `value` 在矩阵中**上下左右**四个相邻元素之和
- `int diagonalSum(int value)`：返回 `value` 在矩阵中**四个对角**相邻元素之和

**示例：**
```
输入：
grid = [[0,1,2],[3,4,5],[6,7,8]]
查询：adjacentSum(1) -> 1+0+2+4 = 1+0+2+4...
adjacentSum(4) -> 1+3+7+5 = 16
diagonalSum(4) -> 0+2+6+8 = 16
```

**提示：**
- `3 <= n <= 10`
- `0 <= grid[i][j] <= n^2 - 1`
- 所有值互不相同

## 解题思路

预处理：用哈希表记录每个值的位置 `(i, j)`，然后对每次查询直接计算周围四个方向的和。

## Python 代码实现

### 方法一：哈希表 + 模拟（推荐）

```python
from typing import List

class neighborSum:
    def __init__(self, grid: List[List[int]]):
        self.grid = grid
        self.n = len(grid)
        # 记录每个值的位置
        self.pos = {}
        for i in range(self.n):
            for j in range(self.n):
                self.pos[grid[i][j]] = (i, j)
    
    def adjacentSum(self, value: int) -> int:
        r, c = self.pos[value]
        n = self.n
        total = 0
        for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < n:
                total += self.grid[nr][nc]
        return total
    
    def diagonalSum(self, value: int) -> int:
        r, c = self.pos[value]
        n = self.n
        total = 0
        for dr, dc in [(-1, -1), (-1, 1), (1, -1), (1, 1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < n:
                total += self.grid[nr][nc]
        return total
```

### 方法二：直接遍历

```python
from typing import List

class neighborSum:
    def __init__(self, grid: List[List[int]]):
        self.grid = grid
        self.n = len(grid)
    
    def _find(self, value):
        for i in range(self.n):
            for j in range(self.n):
                if self.grid[i][j] == value:
                    return i, j
        return -1, -1
    
    def adjacentSum(self, value: int) -> int:
        r, c = self._find(value)
        n, g = self.n, self.grid
        total = 0
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < n and 0 <= nc < n:
                total += g[nr][nc]
        return total
    
    def diagonalSum(self, value: int) -> int:
        r, c = self._find(value)
        n, g = self.n, self.grid
        total = 0
        for dr, dc in [(-1,-1),(-1,1),(1,-1),(1,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < n and 0 <= nc < n:
                total += g[nr][nc]
        return total
```

## 复杂度分析

- 构造：O(n^2)
- 查询：O(1)（方法一）或 O(n^2)（方法二，不推荐）
- 空间：O(n^2)

## 关键点总结

1. 预处理哈希表，O(1) 定位值的位置
2. 上下左右和对角分别用方向数组遍历
3. 注意边界检查（矩阵边缘的格子）

## 易错点

1. 对角方向是四个斜方向，不是上下左右
2. 边界检查防止越界
