## 题目描述

给你一个整数数组 `nums`（长度 `n`）和整数 `k`。

将 `nums` 分割为 `k` 个不相交的非空子数组，第 `i` 个子数组（1-indexed）的强度为 `(-1)^(i+1) * i * sum`（奇数位置正，偶数位置负，权重依次为 1, -2, 3, -4, ...）。

返回所有可能分割的最大强度总和。

**示例：**
```
输入：nums = [1,2,3,-1,2], k = 3
输出：22
```

**提示：**
- `1 <= n <= 10^4`
- `1 <= k <= n`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

DP：`dp[i][j]` = 前 `j` 个元素划分为 `i` 个子数组的最大强度。

子数组 `i` 的权重系数为 `(-1)^(i+1) * i`，奇数子数组正权重，偶数子数组负权重。

等价于：当 `i` 为奇数时，该子数组的元素希望和最大（贡献 `i * sum`）；当 `i` 为偶数时，希望和最小（贡献 `-i * sum`）。

`dp[i][j] = max over j' < j (dp[i-1][j'] + w_i * sum(nums[j'+1..j]))`

利用前缀和优化：`sum(nums[j'+1..j]) = prefix[j] - prefix[j']`

`dp[i][j] = max(dp[i-1][j'] + w_i * (prefix[j] - prefix[j'])) = w_i * prefix[j] + max(dp[i-1][j'] - w_i * prefix[j'])`

## Python 代码实现

### 方法一：DP + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maximumStrength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # dp[j] = 当前使用 i 个子数组，前 j 个元素的最大强度
        INF = float('-inf')
        # 初始化 dp[-1][0] = 0（0 个子数组，0 个元素）
        prev = [INF] * (n + 1)
        prev[0] = 0

        for i in range(1, k + 1):
            w = i if i % 2 == 1 else -i  # 权重系数
            curr = [INF] * (n + 1)
            best = INF  # max(prev[j'] - w * prefix[j'])

            for j in range(i, n - k + i + 1):  # 保证后面还有 k-i 个元素
                # 更新 best：使用 j-1 个元素结束的最优前驱
                val = prev[j - 1]
                if val != INF:
                    cand = val - w * prefix[j - 1]
                    best = max(best, cand)
                # 更新 curr[j]
                if best != INF:
                    curr[j] = w * prefix[j] + best

            prev = curr

        return max(v for v in prev if v != INF)
```

### 方法二：简化实现

```python
from typing import List

class Solution:
    def maximumStrength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        NEG_INF = float('-inf')
        # dp[i][j] = 使用 i 个子数组，到第 j 个元素为止的最大强度
        dp = [[NEG_INF] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0

        for i in range(1, k + 1):
            w = i if i % 2 == 1 else -i
            best = NEG_INF
            for j in range(i, n + 1):
                # best = max over j' in [i-1, j-1] of (dp[i-1][j'] - w*prefix[j'])
                if dp[i-1][j-1] != NEG_INF:
                    best = max(best, dp[i-1][j-1] - w * prefix[j-1])
                if best != NEG_INF:
                    dp[i][j] = max(dp[i][j], w * prefix[j] + best)

        return max(dp[k][k:])
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(n * k) 或 O(n)（滚动数组）

## 关键点总结

1. 奇数子数组权重为正，希望和最大；偶数子数组权重为负，希望和最小（绝对值最大）
2. DP 利用前缀和将子数组和转化为前缀差，用"维护最优前驱"优化到 O(1) 转移
3. 权重系数随子数组编号变化

## 易错点

1. 子数组编号从 1 开始（1-indexed），奇偶性据此判断
2. 维护 `best = max(dp[i-1][j'] - w * prefix[j'])` 时，`j'` 的范围要正确
3. 每个子数组至少 1 个元素，k 个子数组需要至少 k 个元素
