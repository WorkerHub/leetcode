## 题目描述

给定一个二叉树的根节点 `root`。设根节点位于二叉树的第 `1` 层，而根节点的子节点位于第 `2` 层，依此类推。

返回层内元素之和最大的那几层中的最小层号。

示例 1：

```
输入：root = [1,7,0,7,-8,null,null]
输出：2
解释：
第 1 层各元素之和为 1，
第 2 层各元素之和为 7 + 0 = 7，
第 3 层各元素之和为 7 + (-8) = -1，
所以我们返回层内元素之和最大的层的层号，即第 2 层。
```

示例 2：

```
输入：root = [989,null,10250,98693,-89388,null,null,null,-32127]
输出：2
```

提示：

- 树中的节点数在 `[1, 10^4]` 范围内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这是一道典型的二叉树层序遍历问题，核心是使用 BFS（广度优先搜索）逐层遍历树，计算每层的和，找出最大和对应的最小层号。

**关键观察：**

1. 需要区分树的每一层，BFS 天然适合这个需求
2. 节点值可能为负数，所以不能假设深层的和一定更大
3. 如果多层有相同的最大和，返回层号最小的那一层
4. 层号从 1 开始计数

**算法步骤：**

1. 使用队列进行 BFS 遍历
2. 在处理每一层时，先记录当前层的节点数
3. 计算该层所有节点值的和
4. 比较并更新最大和及对应的层号
5. 返回最大和对应的层号

## Python 代码实现

### 方法一：BFS + 队列（推荐）

```python
from typing import Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        """
        使用 BFS 逐层遍历树，计算每层的和
        
        时间复杂度：O(n)，n 为节点数
        空间复杂度：O(w)，w 为树的最大宽度
        """
        if not root:
            return 0
        
        queue = deque([root])
        max_sum = float('-inf')  # 最大层和
        max_level = 1  # 最大和对应的层号
        current_level = 1  # 当前层号
        
        while queue:
            # 当前层的节点数
            level_size = len(queue)
            level_sum = 0  # 当前层的和
            
            # 遍历当前层的所有节点
            for _ in range(level_size):
                node = queue.popleft()
                level_sum += node.val
                
                # 将下一层节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 更新最大和及对应层号
            if level_sum > max_sum:
                max_sum = level_sum
                max_level = current_level
            
            current_level += 1
        
        return max_level
```

### 方法二：DFS + 哈希表

```python
from typing import Optional
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        """
        使用 DFS 遍历树，用哈希表记录每层的和
        
        时间复杂度：O(n)
        空间复杂度：O(h)，h 为树的高度（递归栈）
        """
        # 哈希表存储每层的和
        level_sums = defaultdict(int)
        
        def dfs(node: Optional[TreeNode], level: int) -> None:
            """DFS 遍历，记录每层节点值之和"""
            if not node:
                return
            
            level_sums[level] += node.val
            dfs(node.left, level + 1)
            dfs(node.right, level + 1)
        
        # 从根节点开始，层号为 1
        dfs(root, 1)
        
        # 找出和最大的最小层号
        max_sum = float('-inf')
        max_level = 1
        
        for level in sorted(level_sums.keys()):
            if level_sums[level] > max_sum:
                max_sum = level_sums[level]
                max_level = level
        
        return max_level
```

### 方法三：BFS 一次遍历优化

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        """
        BFS 遍历，使用变量直接记录结果
        代码更简洁
        """
        if not root:
            return 0
        
        queue = deque([root])
        max_sum, max_level, level = float('-inf'), 0, 0
        
        while queue:
            level += 1
            level_sum = sum(node.val for node in queue)
            
            if level_sum > max_sum:
                max_sum = level_sum
                max_level = level
            
            # 构建下一层
            queue = deque(
                child 
                for node in queue 
                for child in (node.left, node.right) 
                if child
            )
        
        return max_level
```

### 方法四：BFS + 列表推导（Python 风格）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        """
        利用 Python 特性，代码更简洁
        """
        queue = deque([root])
        level_sums = []  # 存储每层的和
        
        while queue:
            level_size = len(queue)
            # 计算当前层的和
            level_sum = sum(node.val for node in queue)
            level_sums.append(level_sum)
            
            # 构建下一层队列
            for _ in range(level_size):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        # 找到最大和的索引，层号 = 索引 + 1
        max_sum = max(level_sums)
        return level_sums.index(max_sum) + 1
```

## 复杂度分析

**方法一（BFS）：**
- 时间复杂度：`O(n)`，每个节点访问一次
- 空间复杂度：`O(w)`，w 为树的最大宽度（队列中最多存储一层的节点）

**方法二（DFS）：**
- 时间复杂度：`O(n)`，每个节点访问一次
- 空间复杂度：`O(h)`，h 为树的高度（递归调用栈）

对于平衡树，两种方法空间复杂度都是 `O(log n)`；对于极不平衡的树，BFS 可能更省空间。

## 关键点总结

1. **BFS 适用场景**：需要按层处理树的问题，BFS 是最自然的选择

2. **层的划分**：使用 `level_size = len(queue)` 记录当前层节点数，保证只处理当前层

3. **负数处理**：初始化 `max_sum = float('-inf')` 而不是 0，因为所有节点值可能都是负数

4. **层号从 1 开始**：不要忘记层号是从 1 开始计数的

5. **最小层号**：题目要求相同最大和时返回层号最小的，所以用 `>` 而不是 `>=` 比较

## 易错点

1. **层号起始错误**：忘记层号从 1 开始，导致返回结果偏差

2. **队列处理错误**：
   ```python
   # 错误：没有记录层大小，无法区分不同层
   while queue:
       node = queue.popleft()  # 会把所有层混在一起
   ```

3. **max_sum 初始化**：
   ```python
   # 错误：如果所有层和都是负数，会返回错误结果
   max_sum = 0
   
   # 正确：使用负无穷
   max_sum = float('-inf')
   ```

4. **比较符号错误**：
   ```python
   # 错误：使用 >= 会在和相同时更新为更大的层号
   if level_sum >= max_sum:
   
   # 正确：使用 > 保证返回最小层号
   if level_sum > max_sum:
   ```

5. **空树处理**：虽然题目说明节点数至少为 1，但实际代码中最好加上空树判断
