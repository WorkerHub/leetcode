## 题目描述

给定一个整数数组 `arr`，找到 `min(b)` 的总和，其中 `b` 的范围为 `arr` 的每个（连续）子数组。

由于答案可能很大，因此 **返回答案模 `10^9 + 7`**。

**示例 1：**
```
输入：arr = [3,1,2,4]
输出：17
解释：
子数组为 [3], [1], [2], [4], [3,1], [1,2], [2,4], [3,1,2], [1,2,4], [3,1,2,4]。
最小值为 3, 1, 2, 4, 1, 1, 2, 1, 1, 1。
总和为 17。
```

**示例 2：**
```
输入：arr = [11,81,94,43,3]
输出：444
```

**提示：**
- `1 <= arr.length <= 3 * 10^4`
- `1 <= arr[i] <= 3 * 10^4`

## 解题思路

这道题要求计算所有子数组的最小值之和。暴力解法是 O(n^2) 或 O(n^3)，需要优化。

**关键观察：**
- 对于每个元素 `arr[i]`，计算它作为最小值时，能贡献多少次
- 如果 `arr[i]` 是某个子数组的最小值，那么这个子数组必须：
  - 包含 `arr[i]`
  - 左边界在 `arr[i]` 左侧第一个比它小的元素之后
  - 右边界在 `arr[i]` 右侧第一个比它小的元素之前

**单调栈解法：**
1. 使用单调栈找到每个元素左边第一个比它小的位置（left）
2. 使用单调栈找到每个元素右边第一个比它小的位置（right）
3. 对于位置 `i`，它作为最小值的子数组数量 = `(i - left) * (right - i)`
4. 贡献值 = `arr[i] * (i - left) * (right - i)`

**为什么用单调栈：**
- 单调栈可以在 O(n) 时间内找到每个元素左/右边第一个更小的元素
- 这是解决区间最值问题的经典技巧

## Python 代码实现

### 方法一：单调栈（推荐 ⭐）

```python
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        
        # left[i]: 左边第一个小于 arr[i] 的位置
        # right[i]: 右边第一个小于 arr[i] 的位置
        left = [-1] * n
        right = [n] * n
        
        # 使用单调栈找左边界
        stack = []
        for i in range(n):
            while stack and arr[stack[-1]] > arr[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)
        
        # 使用单调栈找右边界
        stack = []
        for i in range(n - 1, -1, -1):
            # 注意：这里使用 >= 而不是 >，避免重复计数
            while stack and arr[stack[-1]] >= arr[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)
        
        # 计算结果
        result = 0
        for i in range(n):
            # arr[i] 作为最小值的子数组数量
            count = (i - left[i]) * (right[i] - i)
            result = (result + arr[i] * count) % MOD
        
        return result
```

### 方法二：一次遍历优化

```python
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        result = 0
        stack = []  # 单调递增栈，存储 (index, 贡献值)
        
        for i in range(n + 1):
            # 处理到数组末尾时，使用一个很小的值触发所有元素出栈
            current = 0 if i == n else arr[i]
            
            while stack and arr[stack[-1]] > current:
                mid = stack.pop()
                # left 是栈顶元素（如果栈为空，则为 -1）
                left = stack[-1] if stack else -1
                right = i
                
                # arr[mid] 作为最小值的子数组数量
                count = (mid - left) * (right - mid)
                result = (result + arr[mid] * count) % MOD
            
            stack.append(i)
        
        return result
```

### 方法三：动态规划

```python
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        
        # dp[i] 表示以 arr[i] 结尾的所有子数组的最小值之和
        dp = [0] * n
        result = 0
        
        for i in range(n):
            # 找到左边第一个小于等于 arr[i] 的位置
            j = i - 1
            while j >= 0 and arr[j] > arr[i]:
                j -= 1
            
            # arr[i] 作为最小值的子数组数量
            # 从 j+1 到 i 的所有位置都可以作为左端点
            if j == -1:
                # 左边所有元素都大于 arr[i]
                dp[i] = arr[i] * (i + 1)
            else:
                # 左边有更小的元素
                dp[i] = arr[i] * (i - j) + dp[j]
            
            result = (result + dp[i]) % MOD
        
        return result
```

### 方法四：暴力解法（超时，仅供理解）

```python
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        result = 0
        
        # 枚举所有子数组
        for i in range(n):
            min_val = arr[i]
            for j in range(i, n):
                min_val = min(min_val, arr[j])
                result = (result + min_val) % MOD
        
        return result
```

## 复杂度分析

**方法一/二：单调栈**
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈的空间

**方法三：动态规划**
- 时间复杂度：O(n^2)，最坏情况下每个位置都需要向左遍历
- 空间复杂度：O(n)，DP 数组

**方法四：暴力解法**
- 时间复杂度：O(n^2)，枚举所有子数组
- 空间复杂度：O(1)

## 关键点总结

1. **单调栈的应用**：找每个元素左右两边第一个更小的元素
2. **贡献法**：计算每个元素作为最小值能贡献多少次
3. **避免重复**：右边界使用 `>=` 而不是 `>`，防止相同元素重复计数
4. **取模运算**：结果很大，需要取模 10^9 + 7
5. **边界处理**：左边界为 -1，右边界为 n

## 易错点

1. **重复计数**：相同元素可能导致重复计数，需要在左/右边界处理时注意
2. **取模时机**：每次累加时都要取模，避免溢出
3. **单调栈方向**：左边界从左到右，右边界从右到左
4. **边界初始化**：left 初始化为 -1，right 初始化为 n
5. **栈空判断**：弹栈后要检查栈是否为空
