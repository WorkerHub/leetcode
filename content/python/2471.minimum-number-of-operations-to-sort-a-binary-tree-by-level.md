## 题目描述

给你一棵 **二叉树** 的根节点 `root`。

操作次数定义为：选择同一层的 **两个** 节点，交换这两个节点的值。

返回每一层节点值排好序所需的 **最少操作次数**。

**示例 1：**
```
输入：root = [1,4,3,7,6,8,5,null,null,null,null,9,null,10]
输出：3
```

**提示：**
- 树中节点数目在范围 `[1, 10^5]` 内
- `1 <= Node.val <= 10^5`
- 树中所有值 **互不相同**

## 解题思路

**BFS 层序遍历 + 置换环：**

对每一层的节点值，计算将其排成升序所需的最少交换次数。

**最少交换次数 = n - 置换环数**，其中 n 为该层节点数。

**求置换环数的方法：**
1. 将当前层值排序，得到目标数组
2. 计算从当前排列到目标排列的置换（用哈希表或坐标压缩）
3. 统计置换环的数量

## 代码实现

### 方法一：BFS + 置换环（推荐）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minimumOperations(self, root: Optional[TreeNode]) -> int:
        def min_swaps(arr):
            """计算将 arr 排成有序所需的最少交换次数（置换环法）"""
            n = len(arr)
            sorted_arr = sorted(arr)
            # 将值映射到目标位置
            pos = {v: i for i, v in enumerate(sorted_arr)}
            # 将当前值映射到目标位置的置换
            perm = [pos[v] for v in arr]

            visited = [False] * n
            cycles = 0
            for i in range(n):
                if not visited[i]:
                    cycles += 1
                    j = i
                    while not visited[j]:
                        visited[j] = True
                        j = perm[j]
            return n - cycles

        ans = 0
        queue = deque([root])

        while queue:
            level_vals = []
            for _ in range(len(queue)):
                node = queue.popleft()
                level_vals.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            ans += min_swaps(level_vals)

        return ans
```

### 方法二：BFS + 贪心交换

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minimumOperations(self, root: Optional[TreeNode]) -> int:
        def count_swaps(arr):
            """贪心计算最少交换次数"""
            n = len(arr)
            indexed = sorted(enumerate(arr), key=lambda x: x[1])
            pos = [0] * n
            for new_i, (orig_i, _) in enumerate(indexed):
                pos[orig_i] = new_i

            swaps = 0
            visited = [False] * n
            for i in range(n):
                if visited[i] or pos[i] == i:
                    visited[i] = True
                    continue
                cycle_len = 0
                j = i
                while not visited[j]:
                    visited[j] = True
                    j = pos[j]
                    cycle_len += 1
                swaps += cycle_len - 1
            return swaps

        ans = 0
        queue = deque([root])
        while queue:
            size = len(queue)
            vals = []
            for _ in range(size):
                node = queue.popleft()
                vals.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            ans += count_swaps(vals)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS + 置换环 | O(n log n) | O(n) |

## 关键点总结

1. 最少交换次数 = 元素总数 - 置换环数
2. BFS 逐层处理，对每层独立计算最少交换次数
3. 置换环：从当前排列映射到排序后排列的循环结构

## 易错点

- 置换环算法中，已访问节点不重复计算
- 单元素的「环」贡献 0 次交换，长度 k 的环贡献 k-1 次交换
