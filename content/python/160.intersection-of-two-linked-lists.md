## 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

图示两个链表在节点 `c1` 开始相交：

```
a1 → a2 ↘
          c1 → c2 → c3
b1 → b2 → b3 ↗
```

题目数据保证整个链式结构中不存在环。

注意，函数返回结果后，链表必须保持其原始结构。

**自定义评测：**

评测系统的输入如下（你的程序不适用此输入）：
- `intersectVal` - 相交的起始节点的值。如果不存在相交节点，这一值为 0
- `listA` - 第一个链表
- `listB` - 第二个链表
- `skipA` - 在 listA 中（从头节点开始）跳到交叉节点的节点数
- `skipB` - 在 listB 中（从头节点开始）跳到交叉节点的节点数

评测系统将根据这些输入创建链式数据结构，并将两个头节点 `headA` 和 `headB` 传递给你的程序。如果程序能够正确返回相交节点，那么你的解决方案将被视作正确答案。

**示例 1：**
```
输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：相交节点的引用（值为 8 的节点）
解释：相交节点的值为 8（注意，如果两个链表相交则不能为 0）。
从各自的表头开始算起，链表 A 为 [4,1,8,4,5]，链表 B 为 [5,6,1,8,4,5]。
在 A 中，相交节点前有 2 个节点；在 B 中，相交节点前有 3 个节点。
```

**示例 2：**
```
输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
输出：相交节点的引用（值为 2 的节点）
```

**示例 3：**
```
输入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
输出：null
解释：两个链表不相交，返回 null。
```

**提示：**
- listA 中节点数目为 m
- listB 中节点数目为 n
- 1 <= m, n <= 3 * 10^4
- 1 <= Node.val <= 10^5
- 0 <= skipA < m
- 0 <= skipB < n
- 如果 listA 和 listB 没有交点，intersectVal 为 0
- 如果 listA 和 listB 有交点，intersectVal == listA[skipA] == listB[skipB]

**进阶：**你能否设计一个时间复杂度 O(m + n)、仅用 O(1) 内存的解决方案？

## 解题思路

这道题有多种解法，从简单到优雅逐步讲解。

### 思路一：哈希表（直观）

1. 遍历链表 A，将所有节点存入哈希集合
2. 遍历链表 B，检查每个节点是否在集合中
3. 第一个在集合中的节点就是相交节点

### 思路二：双指针（巧妙）⭐

这是最优雅的解法，核心思想是**消除长度差**。

**关键观察：**
- 假设链表 A 长度为 m，链表 B 长度为 n
- 相交部分长度为 c
- 那么 A 的非相交部分长度为 a = m - c，B 的非相交部分长度为 b = n - c

**巧妙之处：**
- 指针 pA 遍历完 A 后，继续遍历 B
- 指针 pB 遍历完 B 后，继续遍历 A
- 第一次相遇时，pA 和 pB 走过的距离相同：a + c + b = b + c + a

**三种情况：**
1. 有相交：pA 和 pB 会在相交节点相遇
2. 无相交但长度相同：pA 和 pB 会同时到达末尾（null）
3. 无相交且长度不同：pA 和 pB 会在第二轮同时到达末尾（null）

### 思路三：计算长度差

1. 先遍历两个链表，计算长度差 diff
2. 让长链表先走 diff 步
3. 然后两个指针同步前进，相遇点即为交点

## Python 代码实现

### 方法一：双指针（推荐）⭐

```python
from typing import Optional

class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        双指针法：两个指针走过相同的路径长度后必定相遇
        时间复杂度：O(m + n)
        空间复杂度：O(1)
        """
        if not headA or not headB:
            return None
        
        # 两个指针分别从两个链表头部开始
        pA, pB = headA, headB
        
        # 当两个指针相遇时停止
        # 如果有交点，会在交点相遇
        # 如果无交点，会在 None 处相遇
        while pA != pB:
            # pA 走完 A 链表后，继续走 B 链表
            pA = pA.next if pA else headB
            # pB 走完 B 链表后，继续走 A 链表
            pB = pB.next if pB else headA
        
        # 返回相交节点（或 None）
        return pA
```

### 方法二：哈希表（直观易懂）

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        哈希表法：先记录 A 的所有节点，再查找 B 的节点
        时间复杂度：O(m + n)
        空间复杂度：O(m)，需要存储 A 链表的所有节点
        """
        if not headA or not headB:
            return None
        
        # 用集合存储链表 A 的所有节点
        visited = set()
        curr = headA
        while curr:
            visited.add(curr)
            curr = curr.next
        
        # 遍历链表 B，查找第一个在集合中的节点
        curr = headB
        while curr:
            if curr in visited:
                return curr
            curr = curr.next
        
        return None
```

### 方法三：计算长度差

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        计算长度差法：让长链表先走差值步数，然后同步前进
        时间复杂度：O(m + n)
        空间复杂度：O(1)
        """
        if not headA or not headB:
            return None
        
        # 辅助函数：计算链表长度
        def get_length(head: ListNode) -> int:
            length = 0
            curr = head
            while curr:
                length += 1
                curr = curr.next
            return length
        
        # 计算两个链表的长度
        lenA = get_length(headA)
        lenB = get_length(headB)
        
        # 让长链表先走差值步数
        pA, pB = headA, headB
        if lenA > lenB:
            for _ in range(lenA - lenB):
                pA = pA.next
        else:
            for _ in range(lenB - lenA):
                pB = pB.next
        
        # 同步前进，直到相遇
        while pA != pB:
            pA = pA.next
            pB = pB.next
        
        return pA
```

### 方法四：双指针（详细注释版）

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        双指针详细版：帮助理解原理
        """
        if not headA or not headB:
            return None
        
        pA, pB = headA, headB
        
        # 最多遍历两轮链表就能找到答案
        # 第一轮：pA 走 A + B 的公共前缀，pB 走 B + A 的公共前缀
        # 第二轮：如果有交点会相遇，无交点会同时为 None
        while pA != pB:
            # pA 到达 A 链表末尾后，跳到 B 链表头部
            if pA is None:
                pA = headB
            else:
                pA = pA.next
            
            # pB 到达 B 链表末尾后，跳到 A 链表头部
            if pB is None:
                pB = headA
            else:
                pB = pB.next
        
        # 相交：返回交点
        # 不相交：返回 None（两个指针都为 None）
        return pA
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：O(m + n)，每个指针最多遍历两个链表一次
- 空间复杂度：O(1)，只使用两个指针

**方法二（哈希表）：**
- 时间复杂度：O(m + n)
- 空间复杂度：O(m)，需要存储链表 A 的所有节点

**方法三（长度差）：**
- 时间复杂度：O(m + n)，需要遍历三次
- 空间复杂度：O(1)

## 图解示例

示例 1：listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]

```
链表结构：
A: 4 → 1 → 8 → 4 → 5
B: 5 → 6 → 1 ↗

双指针走法：
pA: 4 → 1 → 8 → 4 → 5 → 5 → 6 → 1 → 8 (相遇)
pB: 5 → 6 → 1 → 8 → 4 → 5 → 4 → 1 → 8 (相遇)

pA 走过：2 + 5 + 3 = 10 步（到达 8）
pB 走过：3 + 5 + 2 = 10 步（到达 8）
```

无相交示例：
```
A: 2 → 6 → 4
B: 1 → 5

pA: 2 → 6 → 4 → None → 1 → 5 → None (相遇)
pB: 1 → 5 → None → 2 → 6 → 4 → None (相遇)

两者都在 None 处相遇，返回 None
```

## 关键点总结

1. **双指针巧妙之处**：通过交换路径消除长度差，无需计算长度
2. **相等判断**：比较的是节点引用（对象），不是节点值
3. **终止条件**：pA == pB 时停止（可能是交点，也可能是 None）
4. **路径切换**：到达末尾后切换到另一个链表的头部
5. **无交点情况**：两个指针最终都会变成 None 并相等

## 易错点

1. **节点比较方式**：应该用 `pA == pB`（引用比较），不是 `pA.val == pB.val`（值比较）
2. **终止条件**：是 `while pA != pB`，不是 `while pA and pB`
3. **路径切换时机**：应该在 `pA is None` 时切换，不是 `pA.next is None`
4. **边界处理**：空链表需要提前判断
5. **修改链表**：不能修改链表结构，只能通过指针遍历
