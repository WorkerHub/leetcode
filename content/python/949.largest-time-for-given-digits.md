## 题目描述

给定一个由 4 位数字组成的数组 arr，找到可以设置的符合 24 小时制的最大时间。

24 小时格式为 "HH:MM"，其中 HH 在 00 到 23 之间，MM 在 00 到 59 之间。最小的 24 小时制时间是 00:00，而最大的是 23:59。从 00:00 开始算，过一分钟是 00:01。

以长度为 5 的字符串，按 "HH:MM" 格式返回最大时间。如果不能确定有效时间，则返回空字符串。

## Python 代码实现

```python
from typing import List
from itertools import permutations

class Solution:
    def largestTimeFromDigits(self, arr: List[int]) -> str:
        max_time = -1
        
        for h1, h2, m1, m2 in permutations(arr):
            hour = h1 * 10 + h2
            minute = m1 * 10 + m2
            
            if 0 <= hour <= 23 and 0 <= minute <= 59:
                time_value = hour * 60 + minute
                max_time = max(max_time, time_value)
        
        if max_time == -1:
            return ""
        
        return f"{max_time // 60:02d}:{max_time % 60:02d}"
```

## 复杂度分析

- 时间复杂度：O(1)，固定24种排列
- 空间复杂度：O(1)
