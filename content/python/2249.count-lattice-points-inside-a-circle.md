## 题目描述

给你一个二维整数数组 `circles`，其中 `circles[i] = [xi, yi, ri]` 表示第 `i` 个圆的圆心坐标 `(xi, yi)` 和半径 `ri`。

返回**包含在至少一个圆内**的**格点数量**（即坐标为整数的点）。

**注意：** 圆上的点也算在圆内。

**示例 1：**
```
输入：circles = [[2,2,1]]
输出：5
解释：在圆内的格点：(1,2),(2,1),(2,2),(2,3),(3,2)。
```

## 解题思路

**枚举格点：** 对每个格点 `(x, y)`，检查是否在某个圆内（`(x-cx)^2 + (y-cy)^2 <= r^2`）。

格点的范围：`x` 在 `[min(cx-r), max(cx+r)]`，`y` 同理。

由于 `0 <= xi, yi, ri <= 100`，格点 x 和 y 的范围都在 `[0, 200]` 内，枚举次数至多 `201 * 201 ≈ 40000`，完全可行。

## 代码实现

### 方法一：枚举格点（推荐）

```python
from typing import List

class Solution:
    def countLatticePoints(self, circles: List[List[int]]) -> int:
        # 确定枚举范围
        min_x = min(cx - r for cx, cy, r in circles)
        max_x = max(cx + r for cx, cy, r in circles)
        min_y = min(cy - r for cx, cy, r in circles)
        max_y = max(cy + r for cx, cy, r in circles)

        count = 0
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                # 检查 (x,y) 是否在至少一个圆内
                for cx, cy, r in circles:
                    if (x - cx) ** 2 + (y - cy) ** 2 <= r ** 2:
                        count += 1
                        break  # 在一个圆内就够了

        return count
```

### 方法二：用集合去重

```python
from typing import List

class Solution:
    def countLatticePoints(self, circles: List[List[int]]) -> int:
        points = set()

        for cx, cy, r in circles:
            # 枚举圆内所有格点
            for dx in range(-r, r + 1):
                # 对于每个 dx，计算 y 的范围
                dy_max = int((r * r - dx * dx) ** 0.5)
                for dy in range(-dy_max, dy_max + 1):
                    points.add((cx + dx, cy + dy))

        return len(points)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(N * m)，N 为格点数量，m 为圆的数量。
- 空间复杂度：O(1)。

**方法二：**
- 时间复杂度：O(m * r^2)，每个圆枚举其内部格点。
- 空间复杂度：O(total_points)，集合存储去重格点。

## 关键点总结

1. 格点检查：用距离平方 `(x-cx)^2 + (y-cy)^2 <= r^2` 避免开平方。
2. 方法二枚举每个圆内的格点，用集合去重，避免重复计数。
3. 枚举 `dy_max = floor(sqrt(r^2 - dx^2))`，确定每行的 y 范围。

## 易错点

- `dy_max` 用整数 `int((r*r - dx*dx)**0.5)` 可能因浮点误差少 1，建议检查 `dy_max+1`。
- 圆上的点（`<=`）也要包含。
