## 题目描述

给你一个整数数组 `gifts`，表示每堆礼物的数量。每秒钟，你需要执行以下操作：
- 选择礼物数量最多的那堆
- 将该堆礼物减少为其平方根（向下取整）

经过 `k` 秒后，返回所有堆礼物的 **总数量**。

**示例 1：**

```
输入：gifts = [25,64,9,4,100], k = 4
输出：29
解释：100→10→4→2→1... 25→5→2... 64→8... 9→3... 
```

**示例 2：**

```
输入：gifts = [1,1,1,1], k = 4
输出：4
```

**提示：**

- `1 <= gifts.length <= 10^3`
- `1 <= gifts[i] <= 10^9`
- `1 <= k <= 10^3`

## 解题思路

使用最大堆，每次取出最大值，替换为其平方根（向下取整），重复 k 次。

## Python 代码实现

### 方法一：最大堆（推荐）

```python
from typing import List
import heapq
import math

class Solution:
    def pickGifts(self, gifts: List[int], k: int) -> int:
        # Python 用负值实现最大堆
        heap = [-g for g in gifts]
        heapq.heapify(heap)

        for _ in range(k):
            max_val = -heapq.heappop(heap)
            new_val = math.isqrt(max_val)  # 向下取整平方根
            heapq.heappush(heap, -new_val)

        return -sum(heap)
```

### 方法二：暴力排序（适合小规模）

```python
from typing import List
import math

class Solution:
    def pickGifts(self, gifts: List[int], k: int) -> int:
        gifts = gifts[:]
        for _ in range(k):
            max_idx = gifts.index(max(gifts))
            gifts[max_idx] = math.isqrt(gifts[max_idx])
        return sum(gifts)
```

## 复杂度分析

- 方法一时间复杂度：O(k log n)，堆操作
- 方法二时间复杂度：O(k * n)，暴力找最大值
- 空间复杂度：O(n)，堆

## 关键点总结

1. 最大堆每次 O(log n) 取最大并更新
2. 整数平方根用 `math.isqrt` 准确向下取整
3. Python 最大堆：将元素取负放入 heapq

## 易错点

1. 平方根要向下取整，用 `math.isqrt` 而不是 `int(x**0.5)`（后者有精度问题）
2. 每次操作选的是当前最大的那堆，不是固定某堆
3. 返回所有堆的总数，不是被操作的那堆
