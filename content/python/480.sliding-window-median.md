## 题目描述

中位数是有序序列最中间的那个数。如果序列的长度是偶数，则没有最中间的数；此时中位数是最中间的两个数的平均数。

例如：
- `[2,3,4]`，中位数是 `3`
- `[2,3]`，中位数是 `(2 + 3) / 2 = 2.5`

给你一个数组 `nums`，有一个长度为 `k` 的窗口从最左端滑动到最右端。窗口中有 `k` 个数，每次窗口向右移动 `1` 位。你的任务是找出每次窗口移动后得到的新窗口中元素的中位数，并输出由它们组成的数组。

**示例：**
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[1.00000,-1.00000,-1.00000,3.00000,5.00000,6.00000]
解释：
窗口位置                      中位数
---------------               -----
[1  3  -1] -3  5  3  6  7       1
 1 [3  -1  -3] 5  3  6  7      -1
 1  3 [-1  -3  5] 3  6  7      -1
 1  3  -1 [-3  5  3] 6  7       3
 1  3  -1  -3 [5  3  6] 7       5
 1  3  -1  -3  5 [3  6  7]      6
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 解题思路

**核心思想：** 使用两个堆维护窗口的有序状态。

- **大顶堆（小的一半）：** 存储较小的 k/2 个元素
- **小顶堆（大的一半）：** 存储较大的 k/2 个元素
- 中位数就在两个堆顶

**难点：** 滑动窗口需要删除元素，堆不支持高效删除。

**解决方案：** 延迟删除（懒删除）
- 用哈希表记录待删除的元素
- 在访问堆顶时清理

## Python 代码实现

### 方法一：双堆 + 延迟删除（推荐）⭐

```python
from typing import List
from heapq import heappush, heappop
from collections import defaultdict

class Solution:
    def medianSlidingWindow(self, nums: List[int], k: int) -> List[float]:
        # 大顶堆（存储较小的一半，取负实现）
        small = []
        # 小顶堆（存储较大的一半）
        large = []
        # 延迟删除的哈希表
        delayed = defaultdict(int)
        
        # 初始化前 k 个元素
        for i in range(k):
            heappush(small, -nums[i])
        
        # 平衡两个堆
        for _ in range(k // 2):
            heappush(large, -heappop(small))
        
        result = [self.getMedian(small, large, k)]
        
        # 滑动窗口
        for i in range(k, len(nums)):
            # 移出的元素
            out_num = nums[i - k]
            # 移入的元素
            in_num = nums[i]
            
            # 记录延迟删除
            delayed[out_num] += 1
            
            # 决定新元素放入哪个堆
            balance = 0
            if out_num <= -small[0]:
                balance -= 1
            else:
                balance += 1
            
            if in_num <= -small[0]:
                heappush(small, -in_num)
                balance += 1
            else:
                heappush(large, in_num)
                balance -= 1
            
            # 平衡堆
            if balance < 0:
                heappush(small, -heappop(large))
            elif balance > 0:
                heappush(large, -heappop(small))
            
            # 清理堆顶的延迟删除元素
            while small and delayed[-small[0]] > 0:
                delayed[-small[0]] -= 1
                heappop(small)
            
            while large and delayed[large[0]] > 0:
                delayed[large[0]] -= 1
                heappop(large)
            
            result.append(self.getMedian(small, large, k))
        
        return result
    
    def getMedian(self, small, large, k):
        if k % 2 == 1:
            return float(-small[0])
        else:
            return (-small[0] + large[0]) / 2.0
```

### 方法二：简化版（使用 SortedList）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def medianSlidingWindow(self, nums: List[int], k: int) -> List[float]:
        window = SortedList(nums[:k])
        result = []
        
        for i in range(len(nums) - k + 1):
            # 计算中位数
            if k % 2 == 1:
                result.append(float(window[k // 2]))
            else:
                result.append((window[k // 2 - 1] + window[k // 2]) / 2.0)
            
            # 滑动窗口
            if i + k < len(nums):
                window.remove(nums[i])
                window.add(nums[i + k])
        
        return result
```

**注意：** 需要安装 `sortedcontainers` 库

## 复杂度分析

**方法一（双堆）：**
- 时间复杂度：O(n log k)
- 空间复杂度：O(k)

**方法二（SortedList）：**
- 时间复杂度：O(n log k)
- 空间复杂度：O(k)

## 关键点总结

1. **双堆维护：** 小的一半和大的一半
2. **延迟删除：** 哈希表记录，堆顶清理
3. **平衡策略：** 保持两个堆大小差不超过 1
4. **中位数计算：** 根据 k 的奇偶性

## 易错点

1. **堆的平衡：** 必须保持大小关系
2. **延迟删除的清理：** 访问堆顶前清理
3. **边界情况：** k = 1 或 k = n
