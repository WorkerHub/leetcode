## 题目描述

键盘上一排有 26 个键，但是有些键损坏了。给你一个字符串 `text` 和一个字符串 `brokenLetters`，其中 `brokenLetters` 包含所有损坏的键。

返回使用此键盘能够打出的 `text` 中单词数量（以空格分隔单词，单词不含损坏的键中的字母即可打出）。

**示例 1：**
```
输入：text = "hello world", brokenLetters = "ad"
输出：1
解释："world" 可以打出，"hello" 含 'h' 不在 brokenLetters，均可打出...
实际两个词都不含 a 或 d，都能打出，答案是 2
```

**示例 2：**
```
输入：text = "leet code", brokenLetters = "lt"
输出：1
解释："leet" 含 'l' 和 't'，不能打；"code" 不含损坏键，可以打
```

**提示：**
- `1 <= text.length <= 10^4`
- `0 <= brokenLetters.length <= 26`
- `text` 和 `brokenLetters` 只含小写字母，不含重复字母

---

## 解题思路

### 核心思想：集合判断

将 `brokenLetters` 转换为集合，对每个单词检查是否包含损坏字母。

---

## 代码实现

### 方法一：集合 + 遍历（推荐）

```python
class Solution:
    def canBeTypedWords(self, text: str, brokenLetters: str) -> int:
        broken = set(brokenLetters)
        count = 0

        for word in text.split():
            # 检查单词中是否有损坏字母
            if not any(c in broken for c in word):
                count += 1

        return count
```

### 方法二：列表推导（Python 风格）

```python
class Solution:
    def canBeTypedWords(self, text: str, brokenLetters: str) -> int:
        broken = set(brokenLetters)
        # 统计所有不含损坏字母的单词数
        return sum(
            1 for word in text.split()
            if not set(word) & broken  # 单词字符集与损坏集无交集
        )
```

### 方法三：正则表达式（另一种思路）

```python
import re

class Solution:
    def canBeTypedWords(self, text: str, brokenLetters: str) -> int:
        if not brokenLetters:
            return len(text.split())
        # 统计包含损坏字母的单词数，从总数中减去
        pattern = f'[{re.escape(brokenLetters)}]'
        words = text.split()
        broken_count = sum(1 for w in words if re.search(pattern, w))
        return len(words) - broken_count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(k) |
| 方法二 | O(n) | O(k) |
| 方法三 | O(n) | O(k) |

n 为 text 长度，k 为 brokenLetters 长度。

---

## 关键点总结

1. 用集合存储损坏字母，O(1) 查找
2. `any(c in broken for c in word)` 短路求值，效率高
3. `set(word) & broken` 集合交集为空则单词可以打出

---

## 易错点

- `brokenLetters` 为空字符串时所有单词都能打出，注意处理
- 单词以空格分隔，使用 `split()` 自动处理多个空格
