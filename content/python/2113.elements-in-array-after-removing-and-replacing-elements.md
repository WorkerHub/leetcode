## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums` 和 `queries`。

有一个初始为空的数组 `arr`，依次处理以下两类操作（按 `queries` 中的顺序）：

- 如果 `queries[i]` 的值 `v >= 0`，则在 `arr` 的**末尾**插入 `nums[v]`。
- 如果 `queries[i]` 的值 `v < 0`，则**删除** `arr` 末尾的元素。

返回每次操作后 `arr[0]` 的值（如果 `arr` 为空，则为 `-1`）。

**示例：**
```
输入：nums = [1,2,3,4,5], queries = [0,1,2,-3,3,4,-1]
输出：[1,1,1,1,1,1,1]
解释：
- queries[0]=0: arr=[nums[0]]=>[1]，arr[0]=1
- queries[1]=1: arr=[1,2]，arr[0]=1
- queries[2]=2: arr=[1,2,3]，arr[0]=1
- queries[3]=-3: arr=[1,2]，arr[0]=1
- queries[4]=3: arr=[1,2,nums[3]]=[1,2,4]，arr[0]=1
- queries[5]=4: arr=[1,2,4,5]，arr[0]=1
- queries[6]=-1: arr=[1,2,4]，arr[0]=1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `0 <= queries[i] <= nums.length - 1` 或 `-nums.length <= queries[i] <= -1`

## 解题思路

**模拟栈操作**

用一个列表（栈）模拟 `arr`：
- `v >= 0`：将 `nums[v]` 推入栈。
- `v < 0`：弹出栈顶元素。

每步记录 `arr[0]`（栈底元素）或 -1（栈为空）。

**优化：** 不需要真正维护栈，只需记录当前栈的大小。栈第一个元素就是最初入栈的 `nums[queries[0]]`（若 queries[0] >= 0）。但由于后续操作可能把第一个元素也删掉，还是需要维护栈的全部内容。

## 代码实现

### 方法一：模拟栈（推荐）

```python
from typing import List

class Solution:
    def elementInNums(self, nums: List[int], queries: List[int]) -> List[int]:
        arr = []    # 模拟动态数组
        result = []
        for v in queries:
            if v >= 0:
                # 插入 nums[v] 到末尾
                arr.append(nums[v])
            else:
                # 删除末尾元素
                if arr:
                    arr.pop()
            # 记录 arr[0]，若为空则 -1
            result.append(arr[0] if arr else -1)
        return result
```

### 方法二：使用 deque（适用于频繁操作两端）

```python
from typing import List
from collections import deque

class Solution:
    def elementInNums(self, nums: List[int], queries: List[int]) -> List[int]:
        arr = deque()
        result = []
        for v in queries:
            if v >= 0:
                arr.append(nums[v])
            else:
                if arr:
                    arr.pop()
            result.append(arr[0] if arr else -1)
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟栈 | O(n + q) | O(n) |

## 关键点总结

1. 直接模拟，`v >= 0` 插入，`v < 0` 弹出。
2. 每步查询 `arr[0]`，为空返回 -1。
3. Python 列表的 `append` 和 `pop` 都是 O(1)，效率够用。

## 易错点

- 删除操作前需检查 `arr` 是否为空，避免越界。
- 记录的是 `arr[0]` 而非栈顶 `arr[-1]`。
