## 题目描述

给你一个长度为 `n` 的整数数组 `target`，初始数组 `initial` 是一个和 `target` 等长的全 0 数组。

每次操作，可以选择一个子数组，将其中每个元素加 1。

请你返回使 `initial` 变成 `target` 所需的最少操作次数。

**示例 1：**
```
输入：target = [1,2,3,2,1]
输出：3
```

**示例 2：**
```
输入：target = [3,1,1,2]
输出：4
```

**提示：**
- `1 <= target.length <= 10^5`
- `1 <= target[i] <= 10^5`

## 解题思路

### 贪心：差分数组分析

**关键观察：**

考虑相邻元素的差：
- 若 `target[i] > target[i-1]`，则第 `i` 个位置需要额外 `target[i] - target[i-1]` 次操作来"抬高"
- 若 `target[i] <= target[i-1]`，则可以继续使用之前的操作（无需新增）

所以最少操作次数 = `target[0] + sum(max(0, target[i] - target[i-1]) for i in range(1, n))`

**直觉解释：** 把 target 看成一个"山脉"，每次操作是一条"水平线段"，问覆盖所有山脉需要多少条水平线段。答案就是所有"上升台阶"的总高度。

## 代码实现

### 方法一：差分贪心（推荐）

```python
from typing import List

class Solution:
    def minNumberOperations(self, target: List[int]) -> int:
        # 第一个元素需要 target[0] 次操作
        ans = target[0]
        for i in range(1, len(target)):
            # 只有上升时才需要额外操作
            if target[i] > target[i-1]:
                ans += target[i] - target[i-1]
        return ans
```

### 方法二：使用 zip 简化

```python
from typing import List

class Solution:
    def minNumberOperations(self, target: List[int]) -> int:
        # target[0] + 所有正差值之和
        ans = target[0]
        ans += sum(max(0, b - a) for a, b in zip(target, target[1:]))
        return ans
```

### 方法三：完整分析版（含动态规划视角）

```python
from typing import List

class Solution:
    def minNumberOperations(self, target: List[int]) -> int:
        n = len(target)
        # dp[i] = 使 initial[0..i] 变成 target[0..i] 的最小操作数
        # dp[i] = dp[i-1] + max(0, target[i] - target[i-1])
        # dp[0] = target[0]
        # 直接滚动计算
        ops = target[0]
        for i in range(1, n):
            diff = target[i] - target[i-1]
            if diff > 0:
                ops += diff
        return ops
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. 答案等于 `target[0]` 加上所有"上升台阶"的高度
2. 本质是：操作次数 = 差分数组中正值的总和
3. 下降不需要新增操作（可以复用之前的操作，提前结束）

## 易错点

- 只累加正差值（下降时不减），不是累加所有差值的绝对值
