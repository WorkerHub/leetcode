## 题目描述

给你一个整数数组 `original` 和一个二维整数数组 `bounds`，其中 `bounds[i] = [li, ri]`。

一个"复制数组" `copy` 满足：
- `copy.length == original.length`
- 对所有 i，`copy[i] - copy[i-1] == original[i] - original[i-1]`（相邻差相同）
- 对所有 i，`li <= copy[i] <= ri`

返回满足条件的**不同**复制数组的数量。

**示例 1：**

```
输入：original = [1,2,3], bounds = [[1,3],[3,5],[5,7]]
输出：3
解释：copy 与 original 差值序列相同，即 copy[i] = original[i] + k（常数偏移 k）
找满足所有约束的 k 的范围
```

**提示：**
- `2 <= original.length == bounds.length <= 10^5`
- `1 <= li <= ri <= 10^9`
- `1 <= original[i] <= 10^9`

## 解题思路

`copy` 与 `original` 的差值序列相同，意味着 `copy[i] = original[i] + k`，其中 k 是常数偏移。

约束：`li <= original[i] + k <= ri`，即 `li - original[i] <= k <= ri - original[i]`。

所有约束的交集：
- `k >= max(li - original[i])` 对所有 i
- `k <= min(ri - original[i])` 对所有 i

满足条件的 k 的整数个数 = max(0, min_upper - max_lower + 1)。

## Python 代码实现

### 方法一：计算 k 的范围（推荐）

```python
from typing import List

class Solution:
    def countArrays(self, original: List[int], bounds: List[List[int]]) -> int:
        n = len(original)

        # k 的范围：max(lower_bounds) <= k <= min(upper_bounds)
        max_lower = float('-inf')
        min_upper = float('inf')

        for i in range(n):
            li, ri = bounds[i]
            # copy[i] = original[i] + k
            lower_k = li - original[i]
            upper_k = ri - original[i]

            max_lower = max(max_lower, lower_k)
            min_upper = min(min_upper, upper_k)

        if max_lower > min_upper:
            return 0

        return min_upper - max_lower + 1
```

### 方法二：更清晰的写法

```python
from typing import List

class Solution:
    def countArrays(self, original: List[int], bounds: List[List[int]]) -> int:
        # 计算允许的偏移 k 的范围
        lo = max(bounds[i][0] - original[i] for i in range(len(original)))
        hi = min(bounds[i][1] - original[i] for i in range(len(original)))

        return max(0, hi - lo + 1)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 复制数组是原数组加上一个常数偏移 k
2. 找所有约束允许的 k 的整数范围
3. 答案 = 范围内整数个数

## 图解示例

```
original = [1,2,3], bounds = [[1,3],[3,5],[5,7]]
copy[i] = original[i] + k

i=0: 1 <= 1+k <= 3 -> 0 <= k <= 2
i=1: 3 <= 2+k <= 5 -> 1 <= k <= 3
i=2: 5 <= 3+k <= 7 -> 2 <= k <= 4

交集：k in [2, 2]，共 1 个整数
```

## 易错点

1. 不同 copy 只是 k 值不同（整数 k）
2. k 必须是整数（copy[i] 是整数）
3. max_lower > min_upper 时无解，返回 0
