## 题目描述

给你一个长度为 `n` 的整数数组 `maxHeights`，表示每个位置的最大高度。

你要建一组塔，规则：
- 第 i 座塔的高度 `heights[i]` 在 [1, maxHeights[i]] 之间
- 高度序列必须是**山形**：存在下标 `i`（峰顶），使得 heights 在 i 之前非递减，在 i 之后非递增

返回 heights 之和的最大值。

**示例 1：**
```
输入：maxHeights = [5,3,4,1,1]
输出：13
解释：heights = [5,3,4,1,1]... 不对，需要先升后降
heights = [3,3,3,1,1]，sum=11
或 heights = [5,3,3,1,1] 不是山形（5>3 然后 3=3 可以，但 3>1 OK）
heights = [3,3,4,1,1]，4 是峰顶，sum=13 ✓
```

**提示：**
- `1 <= n <= 10^3`（简单版本，小数据）
- `1 <= maxHeights[i] <= 10^9`

## 解题思路

**枚举峰顶：** 对每个下标 i 作为峰顶，计算最优的 heights 数组：
- 峰顶高度 = `maxHeights[i]`
- 往左：每个位置高度 = `min(maxHeights[j], heights[j+1])`（非递减约束）
- 往右：每个位置高度 = `min(maxHeights[j], heights[j-1])`（非递增约束）

枚举所有峰顶，取最大和。

数据量小（n <= 10^3），O(n^2) 可行。

## Python 代码实现

### 方法一：枚举峰顶（推荐，简单版）

```python
from typing import List

class Solution:
    def maximumSumOfHeights(self, maxHeights: List[int]) -> int:
        n = len(maxHeights)
        ans = 0

        for peak in range(n):
            heights = [0] * n
            heights[peak] = maxHeights[peak]

            # 往左：非递减（heights[peak-1] <= heights[peak]）
            for j in range(peak - 1, -1, -1):
                heights[j] = min(maxHeights[j], heights[j + 1])

            # 往右：非递增（heights[peak+1] <= heights[peak]）
            for j in range(peak + 1, n):
                heights[j] = min(maxHeights[j], heights[j - 1])

            total = sum(heights)
            ans = max(ans, total)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举 n 个峰顶，每次 O(n)
- 空间复杂度：O(n)，heights 数组

## 关键点总结

1. 枚举每个位置作为峰顶，往两侧递推高度
2. 左侧高度 = `min(maxHeights[j], 右邻高度)`
3. 右侧高度 = `min(maxHeights[j], 左邻高度)`
4. 峰顶取最大允许高度 `maxHeights[peak]`

## 易错点

1. 山形要求单调，不是严格单调（相等可以）
2. 往左是非递增，往右也是非递增（从峰顶向两侧都是非递增）

## 学习建议

本题数据量小（n <= 10^3），O(n^2) 暴力解已足够。更大数据量的同类问题（2866）需要单调栈优化为 O(n)。
