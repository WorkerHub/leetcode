## 题目描述

给你一个图，包含 `n` 个节点，编号从 `0` 到 `n-1`。有若干条无向边，每条边有权重 `dis`。

实现类 `DistanceLimitedPathsExist`：
- `DistanceLimitedPathsExist(int n, int[][] edgeList)`：初始化数据结构，`edgeList[i] = [u, v, dis]`
- `boolean query(int p, int q, int limit)`：如果存在从 `p` 到 `q` 的路径，且路径上每条边的权重都**严格小于** `limit`，则返回 `true`

**提示：**
- `2 <= n <= 10^4`
- `0 <= edgeList.length <= 10^4`
- `0 <= queries.length <= 10^4`
- 每次查询需要在线处理

## 解题思路

使用**Kruskal 重构树**（克鲁斯卡尔重构树）支持在线查询：

1. 按边权升序排序，用并查集维护
2. 建立重构树：每次合并两个连通分量时，新建一个虚拟节点，权值为当前边权，作为两个分量根节点的父亲
3. 查询 `(p, q, limit)`：在重构树上找 `p` 和 `q` 的 LCA，若 LCA 的权值 < limit，则路径存在
4. 用倍增法求 LCA

## 代码实现

### 方法一：Kruskal 重构树 + 倍增 LCA

```python
class DistanceLimitedPathsExist:
    def __init__(self, n: int, edgeList):
        # 按边权排序
        edgeList.sort(key=lambda x: x[2])
        
        # 重构树节点：原始节点 0..n-1，虚拟节点从 n 开始
        MAX_NODES = 2 * n
        LOG = 15  # 2^15 > 2*n
        
        self.node_val = [0] * MAX_NODES  # 虚拟节点的边权值
        self.parent = list(range(MAX_NODES))  # 并查集
        self.tree_parent = [[0] * LOG for _ in range(MAX_NODES)]  # 倍增表
        self.depth = [0] * MAX_NODES
        self.LOG = LOG
        
        node_cnt = n  # 下一个虚拟节点的编号
        
        def find(x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x
        
        # Kruskal 重构树构建
        for u, v, w in edgeList:
            ru, rv = find(u), find(v)
            if ru == rv:
                continue
            # 新建虚拟节点
            self.node_val[node_cnt] = w
            self.parent[node_cnt] = node_cnt  # 虚拟节点自身
            # 连接两个分量的根
            self.parent[ru] = node_cnt
            self.parent[rv] = node_cnt
            # 设置深度和倍增表
            self.tree_parent[ru][0] = node_cnt
            self.tree_parent[rv][0] = node_cnt
            self.depth[ru] = self.depth[node_cnt] + 1
            self.depth[rv] = self.depth[node_cnt] + 1
            node_cnt += 1
        
        self.total_nodes = node_cnt
        
        # 构建倍增表
        for k in range(1, LOG):
            for v in range(self.total_nodes):
                self.tree_parent[v][k] = self.tree_parent[self.tree_parent[v][k-1]][k-1]
    
    def query(self, p: int, q: int, limit: int) -> bool:
        # 在重构树上求 LCA，判断 LCA 的 node_val 是否 < limit
        # 先将 p、q 提升到同一深度
        # 找重构树根（深度更浅的公共祖先）
        
        # 将 p 提升到和 q 同深度
        if self.depth[p] < self.depth[q]:
            p, q = q, p
        
        diff = self.depth[p] - self.depth[q]
        for k in range(self.LOG):
            if (diff >> k) & 1:
                p = self.tree_parent[p][k]
        
        if p == q:
            return self.node_val[p] < limit
        
        for k in range(self.LOG - 1, -1, -1):
            if self.tree_parent[p][k] != self.tree_parent[q][k]:
                p = self.tree_parent[p][k]
                q = self.tree_parent[q][k]
        
        lca = self.tree_parent[p][0]
        return self.node_val[lca] < limit
```

### 方法二：离线处理（简化版，不支持在线但逻辑清晰）

```python
from typing import List

def offline_query(n: int, edgeList: List[List[int]], queries: List[List[int]]) -> List[bool]:
    """离线处理版本，供理解算法用"""
    parent = list(range(n))
    
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    def union(x, y):
        px, py = find(x), find(y)
        if px != py:
            parent[px] = py
    
    # 边按权重排序
    edges = sorted(edgeList, key=lambda x: x[2])
    # 查询按 limit 排序
    indexed_queries = sorted(enumerate(queries), key=lambda x: x[1][2])
    
    ans = [False] * len(queries)
    j = 0
    
    for orig_idx, (p, q, limit) in indexed_queries:
        while j < len(edges) and edges[j][2] < limit:
            union(edges[j][0], edges[j][1])
            j += 1
        ans[orig_idx] = find(p) == find(q)
    
    return ans
```

## 复杂度分析

- **在线方法一**：预处理 O(E log E + N log N)，每次查询 O(log N)
- **离线方法二**：O((E + Q) log(E + Q))

## 关键点总结

1. Kruskal 重构树将最大边权转化为 LCA 问题
2. 倍增法求 LCA，支持 O(log n) 在线查询
3. 重构树的 LCA 的权值就是路径上的最大边权

## 易错点

- 虚拟节点编号从 n 开始，注意数组大小
- 深度关系：虚拟节点的深度比其子节点浅
