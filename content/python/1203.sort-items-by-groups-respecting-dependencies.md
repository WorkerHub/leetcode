## 题目描述

[LeetCode 1203. Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/)

公司共有 `n` 个项目和 `m` 个小组，每个项目都属于某一个小组，`group[i]` 表示第 `i` 个项目所属的小组，如果第 `i` 个项目不属于任何小组，则 `group[i]` 等于 `-1`。

现在需要在所有项目之间施加一些约束条件，这些约束条件可能会导致项目之间的依赖关系。

`beforeItems[i]` 是一个列表，表示在开始第 `i` 个项目前必须完成的所有项目。

你的任务是为这些项目进行排序，要求：
1. 同一小组的项目必须排在一起
2. 存在依赖关系的项目，被依赖的项目必须排在前面

如果存在多个答案，返回其中任何一个。如果没有合法的项目顺序，返回一个空数组。

**示例 1:**
```
输入：n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3,6],[],[],[]]
输出：[6,3,4,1,5,2,0,7]
```

**示例 2:**
```
输入：n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3],[],[4],[]]
输出：[]
解释：与示例 1 大致相同，但是在排序后的列表中，4 必须放在 6 的前面，但 6 属于小组 0，4 属于小组 0，而小组的顺序是确定的，这是一个矛盾。
```

**提示:**
- 1 <= m <= n <= 3 * 10^4
- group.length == beforeItems.length == n
- -1 <= group[i] <= m - 1
- 0 <= beforeItems[i].length <= n - 1
- 0 <= beforeItems[i][j] <= n - 1
- i != beforeItems[i][j]
- beforeItems[i] 不含重复元素

## 解题思路

这是一道复杂的拓扑排序问题，需要同时处理**项目之间的依赖**和**组之间的依赖**。

### 问题分解

这道题实际上需要做**两次拓扑排序**：

1. **组间拓扑排序**：确定小组的顺序
2. **组内拓扑排序**：确定每个小组内项目的顺序

### 核心思路

1. **处理无组项目**：将 group[i] = -1 的项目分配到独立的组（每个项目一个组）
2. **构建依赖图**：
   - 项目级别的依赖图：记录项目之间的依赖关系
   - 组级别的依赖图：记录组之间的依赖关系
3. **拓扑排序**：
   - 先对组进行拓扑排序，得到组的顺序
   - 对每个组内的项目进行拓扑排序
   - 按组的顺序拼接各组的项目

### 拓扑排序原理

拓扑排序用于有向无环图（DAG），算法步骤：
1. 计算每个节点的入度（有多少条边指向它）
2. 将入度为 0 的节点加入队列
3. 从队列中取出节点，将其邻居的入度减 1
4. 如果邻居的入度变为 0，加入队列
5. 重复直到队列为空

如果处理的节点数小于总节点数，说明存在环，无法完成拓扑排序。

## Python 代码实现

### 方法一：双层拓扑排序（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def sortItems(self, n: int, m: int, group: List[int], beforeItems: List[List[int]]) -> List[int]:
        # 为无组项目分配独立的组
        group_id = m
        for i in range(n):
            if group[i] == -1:
                group[i] = group_id
                group_id += 1
        
        # 构建图和入度数组
        # 项目级别
        item_graph = defaultdict(list)
        item_indegree = [0] * n
        
        # 组级别
        group_graph = defaultdict(list)
        group_indegree = [0] * group_id
        
        # 记录每个组包含哪些项目
        group_items = defaultdict(list)
        for i in range(n):
            group_items[group[i]].append(i)
        
        # 构建依赖关系
        for i in range(n):
            for before in beforeItems[i]:
                # 项目依赖
                item_graph[before].append(i)
                item_indegree[i] += 1
                
                # 组依赖（只有当项目属于不同组时才添加）
                if group[before] != group[i]:
                    group_graph[group[before]].append(group[i])
                    group_indegree[group[i]] += 1
        
        # 拓扑排序函数
        def topological_sort(graph, indegree, nodes):
            queue = deque([node for node in nodes if indegree[node] == 0])
            result = []
            
            while queue:
                node = queue.popleft()
                result.append(node)
                
                for neighbor in graph[node]:
                    indegree[neighbor] -= 1
                    if indegree[neighbor] == 0:
                        queue.append(neighbor)
            
            # 如果结果数量不等于节点数量，说明存在环
            return result if len(result) == len(nodes) else []
        
        # 对组进行拓扑排序
        group_order = topological_sort(group_graph, group_indegree, range(group_id))
        if not group_order:
            return []
        
        # 对每个组内的项目进行拓扑排序
        result = []
        for gid in group_order:
            items = group_items[gid]
            if not items:
                continue
            
            # 对当前组的项目进行拓扑排序
            item_order = topological_sort(item_graph, item_indegree, items)
            if not item_order:
                return []
            
            result.extend(item_order)
        
        return result
```

### 方法二：去重优化的拓扑排序

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def sortItems(self, n: int, m: int, group: List[int], beforeItems: List[List[int]]) -> List[int]:
        # 为无组项目分配组号
        group_id = m
        for i in range(n):
            if group[i] == -1:
                group[i] = group_id
                group_id += 1
        
        # 初始化图和入度
        item_graph = [[] for _ in range(n)]
        item_indegree = [0] * n
        group_graph = [[] for _ in range(group_id)]
        group_indegree = [0] * group_id
        
        # 记录每个组的项目
        group_items = [[] for _ in range(group_id)]
        for i in range(n):
            group_items[group[i]].append(i)
        
        # 用集合去重组之间的边
        group_edges_set = set()
        
        # 构建依赖关系
        for i in range(n):
            for before in beforeItems[i]:
                # 项目依赖
                item_graph[before].append(i)
                item_indegree[i] += 1
                
                # 组依赖（去重）
                if group[before] != group[i]:
                    edge = (group[before], group[i])
                    if edge not in group_edges_set:
                        group_edges_set.add(edge)
                        group_graph[group[before]].append(group[i])
                        group_indegree[group[i]] += 1
        
        # 拓扑排序
        def topo_sort(graph, indegree):
            queue = deque([i for i in range(len(indegree)) if indegree[i] == 0])
            result = []
            
            while queue:
                node = queue.popleft()
                result.append(node)
                
                for neighbor in graph[node]:
                    indegree[neighbor] -= 1
                    if indegree[neighbor] == 0:
                        queue.append(neighbor)
            
            return result if len(result) == len(indegree) else []
        
        # 组拓扑排序
        group_order = topo_sort(group_graph, group_indegree)
        if not group_order:
            return []
        
        # 项目拓扑排序（全局）
        item_order = topo_sort(item_graph, item_indegree)
        if not item_order:
            return []
        
        # 按组顺序组织项目
        result = []
        for gid in group_order:
            for item in item_order:
                if group[item] == gid:
                    result.append(item)
        
        return result
```

### 方法三：DFS 拓扑排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def sortItems(self, n: int, m: int, group: List[int], beforeItems: List[List[int]]) -> List[int]:
        # 分配组号
        group_id = m
        for i in range(n):
            if group[i] == -1:
                group[i] = group_id
                group_id += 1
        
        # 构建图
        item_graph = defaultdict(list)
        group_graph = defaultdict(list)
        group_items = defaultdict(list)
        
        for i in range(n):
            group_items[group[i]].append(i)
        
        group_edges = set()
        for i in range(n):
            for before in beforeItems[i]:
                item_graph[before].append(i)
                if group[before] != group[i]:
                    edge = (group[before], group[i])
                    if edge not in group_edges:
                        group_edges.add(edge)
                        group_graph[group[before]].append(group[i])
        
        # DFS 拓扑排序
        def dfs_topo(graph, nodes):
            WHITE, GRAY, BLACK = 0, 1, 2
            color = {node: WHITE for node in nodes}
            result = []
            
            def dfs(node):
                if color[node] == GRAY:  # 检测到环
                    return False
                if color[node] == BLACK:  # 已访问
                    return True
                
                color[node] = GRAY
                for neighbor in graph.get(node, []):
                    if not dfs(neighbor):
                        return False
                color[node] = BLACK
                result.append(node)
                return True
            
            for node in nodes:
                if color[node] == WHITE:
                    if not dfs(node):
                        return []
            
            return result[::-1]  # 反转得到拓扑序
        
        # 组拓扑排序
        group_order = dfs_topo(group_graph, range(group_id))
        if not group_order:
            return []
        
        # 构建结果
        result = []
        for gid in group_order:
            items = group_items[gid]
            item_order = dfs_topo(item_graph, items)
            if not item_order:
                return []
            result.extend(item_order)
        
        return result
```

## 复杂度分析

### 方法一、二

- **时间复杂度**：O(n + m + E)
  - n 是项目数，m 是组数，E 是依赖边数
  - 分配组号：O(n)
  - 构建图：O(E)
  - 组拓扑排序：O(m + 组间边数)
  - 项目拓扑排序：O(n + E)
  
- **空间复杂度**：O(n + m + E)
  - 图的存储：O(E)
  - 入度数组：O(n + m)
  - 队列：O(n + m)

### 方法三：DFS

- **时间复杂度**：O(n + m + E)
- **空间复杂度**：O(n + m + E)，递归栈额外 O(n)

## 关键点总结

1. **双层拓扑排序**：这是解决此题的核心，需要分别对组和项目进行拓扑排序

2. **无组项目处理**：group[i] = -1 的项目需要分配到独立的组，避免与其他项目混淆

3. **组依赖的构建**：只有当两个项目属于不同组时，才会产生组之间的依赖

4. **去重的重要性**：同一组之间可能有多条边，需要去重避免重复增加入度

5. **环检测**：拓扑排序天然能检测环，如果排序后的节点数少于总节点数，说明有环

## 易错点

1. **忘记处理无组项目**：group[i] = -1 时必须分配新的组号

2. **组依赖判断错误**：
   - 只有 `group[before] != group[i]` 时才添加组依赖
   - 同组内的项目依赖不影响组的顺序

3. **重复边导致入度错误**：
   - 同一组之间可能有多个项目依赖，产生重复的组依赖边
   - 必须用集合去重

4. **拓扑排序函数通用性**：
   - 需要能够对任意节点集合进行排序
   - 不能假设节点从 0 开始连续编号

5. **结果拼接顺序**：
   - 必须先确定组的顺序，再按组顺序拼接项目
   - 不能直接使用全局项目拓扑排序的结果
