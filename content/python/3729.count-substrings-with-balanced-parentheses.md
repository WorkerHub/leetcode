## 题目描述

给定一个只包含 `'('` 和 `')'` 的字符串 `s`，统计其中**有效括号子串**的数量（每个子串本身是合法的括号序列）。

**示例 1：**
```
输入：s = "(())"
输出：3
解释：有效子串：s[0..1]="()"，s[1..2]="()"，s[0..3]="(())"，共 3 个。
```

**示例 2：**
```
输入：s = ")()())"
输出：2
解释：有效子串：s[1..2]="()" 和 s[3..4]="()"，共 2 个... 以及 s[1..4]="()()"，共 3 个。
```

**提示：**
- `1 <= s.length <= 3 * 10^4`

## 解题思路

经典的有效括号子串计数问题，使用栈。

**思路：**
使用栈记录未匹配的左括号的位置，以及当前有效段的左边界。

维护栈：
- 初始压入 `-1` 作为哨兵（上一个有效段的左边界-1）
- 遇到 `'('`：将下标压栈
- 遇到 `')'`：
  - 若栈非空且栈顶不是哨兵（是 `'('`），弹出匹配的 `'('`，当前有效长度 = `i - stack[-1]`，累加所有以 i 结尾的有效子串数 = 有效长度 / 2
  - 若栈空或找不到匹配，压入当前下标作为新边界

## Python 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def countBalancedSubstrings(self, s: str) -> int:
        stack = [-1]  # 哨兵：记录最近一个无效括号的位置
        count = 0

        for i, c in enumerate(s):
            if c == '(':
                stack.append(i)
            else:
                stack.pop()
                if not stack:
                    # 栈变空，压入当前下标作为新边界
                    stack.append(i)
                else:
                    # 当前有效段长度
                    valid_len = i - stack[-1]
                    # 以 i 结尾的有效子串数 = valid_len // 2
                    count += valid_len // 2

        return count
```

### 方法二：动态规划

```python
class Solution:
    def countBalancedSubstrings(self, s: str) -> int:
        n = len(s)
        # dp[i]: 以 s[i] 结尾的有效括号子串数
        dp = [0] * n
        count = 0

        for i in range(1, n, 2):  # 有效括号长度为偶数，只在偶数位置
            if s[i] == ')':
                # 往左找匹配
                j = i - 1
                depth = 1
                while j >= 0 and depth > 0:
                    if s[j] == ')':
                        depth += 1
                    else:
                        depth -= 1
                    j -= 1
                if depth == 0:
                    # [j+1, i] 是有效括号子串
                    dp[i] = 1 + (dp[j] if j >= 0 else 0)
                    count += dp[i]

        return count
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，栈空间

## 关键点总结

1. 栈中初始压入 -1 作为哨兵，标记有效段的起始边界
2. 遇到 ')' 时，若栈顶是 '(' 的下标，则弹出并累计有效子串数
3. 有效长度除以 2 等于以当前位置结尾的有效子串数

## 易错点

1. 遇到 ')' 时，若栈为空（弹出哨兵后），需要重新压入当前下标
2. 有效子串长度一定是偶数
