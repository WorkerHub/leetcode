## 题目描述

给你一个 **不包含** 任何零的整数数组 `nums`，找出自身与对应的负整数都在数组中存在的 **最大正整数** `k`。

换句话讲，就是找最大正整数 `k`，使得 `-k` 也在数组中存在。

返回最大正整数 `k`，如果不存在，返回 `-1`。

**示例 1：**
```
输入：nums = [-1,2,-3,3]
输出：3
解释：3 和 -3 都在数组中，是满足条件的最大正整数。
```

**示例 2：**
```
输入：nums = [-1,10,6,7,-7,1]
输出：7
```

**示例 3：**
```
输入：nums = [-10,8,6,7,-2,-3]
输出：-1
```

**提示：**
- `1 <= nums.length <= 1000`
- `-1000 <= nums[i] <= 1000`
- `nums[i] != 0`

## 解题思路

使用哈希集合存储所有元素，然后遍历正整数，找到最大的既有 `k` 又有 `-k` 的值。

## 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def findMaxK(self, nums: List[int]) -> int:
        num_set = set(nums)
        ans = -1

        for x in nums:
            if x > 0 and -x in num_set:
                ans = max(ans, x)

        return ans
```

### 方法二：排序 + 双指针

```python
from typing import List

class Solution:
    def findMaxK(self, nums: List[int]) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1

        while left < right:
            s = nums[left] + nums[right]
            if s == 0:
                return nums[right]  # 找到最大的正负对
            elif s < 0:
                left += 1
            else:
                right -= 1

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希集合 | O(n) | O(n) |
| 排序 + 双指针 | O(n log n) | O(1) |

## 关键点总结

1. 哈希集合 O(1) 查找，高效检查 `-k` 是否存在
2. 双指针从两端向中间，有序数组下找最大的正负对

## 易错点

- 只找正整数，跳过负数
- 找最大值，不是第一个找到的
