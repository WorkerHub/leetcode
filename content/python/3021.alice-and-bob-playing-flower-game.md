## 题目描述

Alice 和 Bob 玩花朵游戏。游戏场中有一朵花，花朵有 `n` 片花瓣（朝北方向）和 `m` 片花瓣（朝南方向）。

Alice 和 Bob 轮流拿花瓣，Alice 先手。每次操作，当前玩家可以从任意方向（北或南）摘取一片花瓣。

摘取最后一片花瓣的人获胜。

返回 Alice 获胜的 `(n, m)` 对数，其中 `1 <= n <= x`，`1 <= m <= y`。

**示例 1：**
```
输入：n = 3, m = 2
输出：3
```

**示例 2：**
```
输入：n = 1, m = 1
输出：1
```

**提示：**
- `1 <= n, m <= 10^9`

## 解题思路

总花瓣数为 `n + m`。

- 若 `n + m` 为奇数：Alice 先手，总共奇数步，Alice 走第 1, 3, 5, ... 步，最终 Alice 走最后一步，Alice 必胜
- 若 `n + m` 为偶数：Bob 必胜

所以 Alice 获胜当且仅当 `n + m` 为奇数，即 `n` 和 `m` 一奇一偶。

满足条件的对数：
- `n` 为奇数且 `m` 为偶数：`ceil(x/2) * floor(y/2)`
- `n` 为偶数且 `m` 为奇数：`floor(x/2) * ceil(y/2)`

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def flowerGame(self, n: int, m: int) -> int:
        # Alice 获胜条件：n + m 为奇数（一奇一偶）
        # n 在 [1, n] 中奇数个数：ceil(n/2) = (n+1)//2
        # n 在 [1, n] 中偶数个数：floor(n/2) = n//2

        odd_n = (n + 1) // 2   # [1, n] 中奇数个数
        even_n = n // 2         # [1, n] 中偶数个数
        odd_m = (m + 1) // 2   # [1, m] 中奇数个数
        even_m = m // 2         # [1, m] 中偶数个数

        # n 奇 m 偶 的对数
        case1 = odd_n * even_m
        # n 偶 m 奇 的对数
        case2 = even_n * odd_m

        return case1 + case2
```

### 方法二：简化写法

```python
class Solution:
    def flowerGame(self, n: int, m: int) -> int:
        # Alice 胜：(n+m) 为奇数
        # 等价于 n 和 m 一奇一偶
        return (n + 1) // 2 * (m // 2) + (n // 2) * ((m + 1) // 2)
```

## 复杂度分析

- 时间复杂度：O(1)，直接数学计算
- 空间复杂度：O(1)

## 关键点总结

1. 总花瓣奇数 → Alice 胜（先手优势）；总花瓣偶数 → Bob 胜
2. Alice 胜的充要条件：`n + m` 为奇数，即 n 和 m 一奇一偶
3. 利用奇偶计数公式快速求答案

## 易错点

1. 区间 `[1, n]` 中奇数个数为 `(n+1)//2`，而非 `n//2`
2. 注意是有序对 `(n, m)`，两种情况都要统计
