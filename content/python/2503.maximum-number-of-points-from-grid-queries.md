## 题目描述

给你一个 `m x n` 整数矩阵 `grid` 和一个大小为 `k` 的数组 `queries`。

对每个查询 `queries[i]`，从 `grid[0][0]` 出发，每次只能移动到上、下、左、右四个方向的相邻单元格，但只能进入值 **严格小于** `queries[i]` 的单元格。返回可以访问的单元格数目（包含起点，若起点满足条件）。

返回长度为 `k` 的数组 `ans`，其中 `ans[i]` 是第 `i` 个查询的答案。

**示例 1：**

```
输入：grid = [[1,2,3],[2,5,7],[3,5,1]], queries = [5,6,2]
输出：[5,8,1]
```

**提示：**

- `m == grid.length`, `n == grid[i].length`
- `2 <= m, n <= 1000`
- `4 <= grid[i][j] <= 10^5`
- `1 <= queries.length <= 10^4`
- `1 <= queries[i] <= 10^6`

## 解题思路

**离线处理 + BFS + 最小堆**

将查询从小到大排序后依次处理。维护一个最小堆，初始放入起点。

每次处理查询 q：从堆中弹出所有值 < q 的单元格，将它们的邻居加入堆（未访问的），计数访问的格子数。

由于查询是递增处理，前一个查询的结果可以叠加，无需重复 BFS。

## Python 代码实现

### 方法一：离线排序 + 最小堆 BFS（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxPoints(self, grid: List[List[int]], queries: List[int]) -> List[int]:
        m, n = len(grid), len(grid[0])
        # 将查询附带原始下标，排序处理
        sorted_queries = sorted(enumerate(queries), key=lambda x: x[1])
        ans = [0] * len(queries)

        # 最小堆：(格子值, 行, 列)
        heap = [(grid[0][0], 0, 0)]
        visited = [[False] * n for _ in range(m)]
        visited[0][0] = True
        count = 0
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        for idx, q in sorted_queries:
            # 弹出所有值 < q 的格子，扩展邻居
            while heap and heap[0][0] < q:
                val, r, c = heapq.heappop(heap)
                count += 1
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc]:
                        visited[nr][nc] = True
                        heapq.heappush(heap, (grid[nr][nc], nr, nc))
            ans[idx] = count

        return ans
```

### 方法二：暴力 BFS（每次查询独立）

```python
from typing import List
from collections import deque

class Solution:
    def maxPoints(self, grid: List[List[int]], queries: List[int]) -> List[int]:
        m, n = len(grid), len(grid[0])
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        def bfs(q):
            # 若起点不满足条件，直接返回 0
            if grid[0][0] >= q:
                return 0
            visited = [[False] * n for _ in range(m)]
            visited[0][0] = True
            dq = deque([(0, 0)])
            count = 0
            while dq:
                r, c = dq.popleft()
                count += 1
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc] and grid[nr][nc] < q:
                        visited[nr][nc] = True
                        dq.append((nr, nc))
            return count

        return [bfs(q) for q in queries]
```

## 复杂度分析

- 方法一时间复杂度：O((mn + k) log(mn))，离线排序 O(k log k)，堆操作 O(mn log(mn))
- 方法二时间复杂度：O(k * m * n)，每次查询独立 BFS
- 空间复杂度：O(mn)

## 关键点总结

1. 离线处理：将查询排序后按顺序处理，结果可以复用
2. 最小堆保证每次处理时弹出的格子值最小，自然满足 < q 的条件
3. 已访问标记在整个过程中共享，不需要重置

## 易错点

1. 起点 `grid[0][0]` 也需要满足 < q 条件才能被计入
2. 离线处理后要按原始下标存结果
3. 邻居入堆时就标记已访问，防止重复入堆
