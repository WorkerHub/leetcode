## 题目描述

给定一个字符串 `text`,你可以交换其中两个字符。

返回交换后,字符串中最长的由重复字符组成的子串的长度。

**示例 1:**

```
输入: text = "ababa"
输出: 3
解释: 我们可以交换第一个 'b' 和最后一个 'a',或者交换最后一个 'b' 和第一个 'a'
这样得到的最长重复字符子串是 "aaa",长度为 3
```

**示例 2:**

```
输入: text = "aaabaaa"
输出: 6
解释: 交换 'b' 和最后一个 'a'(或第一个 'a'),得到最长重复子串 "aaaaaa",长度为 6
```

**示例 3:**

```
输入: text = "aaaa"
输出: 4
解释: 不需要交换,最长重复字符子串已经是 "aaaa",长度为 4
```

**示例 4:**

```
输入: text = "aaabaaa"
输出: 6
```

**示例 5:**

```
输入: text = "aaaaa"
输出: 5
解释: 不需要交换,最长重复字符子串是 "aaaaa",长度为 5
```

**提示:**
- `1 <= text.length <= 20000`
- `text` 仅由小写英文字母组成

## 解题思路

这道题需要考虑几种情况:

**情况 1: 连续的相同字符块**
- 找到所有连续相同字符的块
- 如果某个字符在其他位置还有剩余,可以交换过来延长

**情况 2: 中间只隔一个不同字符的两块**
- 例如 "aaabaa",中间的 'b' 可以和其他位置的 'a' 交换
- 这样可以合并两个块

**核心思路:**
1. 先统计每个字符的总数
2. 遍历字符串,对于每个连续块:
   - 如果该字符总数 > 当前块长度,可以 +1(从其他地方交换一个过来)
   - 如果当前块和下下个块是同一字符(中间隔一个字符),可以合并
3. 返回最大值

## Python 代码实现

### 方法一: 分组 + 统计(推荐)

```python
from collections import Counter

class Solution:
    def maxRepOpt1(self, text: str) -> int:
        """
        先统计每个字符总数,然后考虑交换的最优情况
        """
        # 统计每个字符的总数
        char_count = Counter(text)
        
        # 将字符串分组,记录每个连续块的字符和长度
        groups = []
        i = 0
        while i < len(text):
            j = i
            while j < len(text) and text[j] == text[i]:
                j += 1
            groups.append((text[i], j - i))
            i = j
        
        # 计算最大长度
        max_len = 0
        
        for i in range(len(groups)):
            char, length = groups[i]
            # 情况1: 当前连续块,如果该字符在其他地方还有,可以交换一个过来
            # 限制是不能超过该字符的总数
            max_len = max(max_len, min(length + 1, char_count[char]))
            
            # 情况2: 如果和下下个块是同一字符,可以考虑合并
            if i + 2 < len(groups) and groups[i + 2][0] == char:
                next_char, next_len = groups[i + 1]
                # 中间只隔了一个字符
                if next_len == 1:
                    # 合并三个块,但总长度不能超过该字符的总数
                    combined_len = length + groups[i + 2][1]
                    # 如果该字符总数 > 合并后的长度,说明还可以交换中间的字符
                    if char_count[char] > combined_len:
                        max_len = max(max_len, combined_len + 1)
                    else:
                        max_len = max(max_len, combined_len)
        
        return max_len
```

### 方法二: 滑动窗口思想

```python
from collections import Counter

class Solution:
    def maxRepOpt1(self, text: str) -> int:
        """
        使用滑动窗口和分组思想
        """
        count = Counter(text)
        n = len(text)
        max_len = 0
        
        # 对每个字符尝试
        for target_char in count:
            # 找到所有 target_char 的连续段
            groups = []
            i = 0
            while i < n:
                if text[i] == target_char:
                    j = i
                    while j < n and text[j] == target_char:
                        j += 1
                    groups.append((i, j - 1, j - i))  # (start, end, length)
                    i = j
                else:
                    i += 1
            
            # 对于每个连续段
            for idx, (start, end, length) in enumerate(groups):
                # 情况1: 单独的段,可以从其他地方交换一个字符过来
                if count[target_char] > length:
                    max_len = max(max_len, length + 1)
                else:
                    max_len = max(max_len, length)
                
                # 情况2: 和下一个段合并
                if idx + 1 < len(groups):
                    next_start, next_end, next_length = groups[idx + 1]
                    # 检查两个段是否只隔一个字符
                    if next_start - end == 2:
                        combined = length + next_length
                        # 如果该字符总数大于合并后的长度,可以替换中间的字符
                        if count[target_char] > combined:
                            max_len = max(max_len, combined + 1)
                        else:
                            max_len = max(max_len, combined)
        
        return max_len
```

### 方法三: 更简洁的实现

```python
from collections import Counter

class Solution:
    def maxRepOpt1(self, text: str) -> int:
        # 统计字符频率
        count = Counter(text)
        
        # 将相同字符分组
        groups = [(char, len(list(group))) for char, group in 
                  __import__('itertools').groupby(text)]
        
        max_len = 0
        
        for i, (char, length) in enumerate(groups):
            # 情况1: 单个块,从其他位置交换一个字符过来
            max_len = max(max_len, min(length + 1, count[char]))
            
            # 情况2: 合并两个被单个字符隔开的块
            if i + 2 < len(groups) and groups[i + 2][0] == char and groups[i + 1][1] == 1:
                # 两块长度 + 是否还有额外字符可交换
                combined = length + groups[i + 2][1]
                max_len = max(max_len, min(combined + 1, count[char]))
        
        return max_len
```

## 复杂度分析

**时间复杂度**: O(n)
- n 为字符串长度
- 需要遍历字符串进行分组: O(n)
- 遍历所有分组: O(n)

**空间复杂度**: O(n)
- 最坏情况下,字符串交替出现不同字符,分组数为 O(n)
- 字符计数器: O(26) = O(1)

groups = [('a', 3), ('b', 1), ('a', 3)]

  - 单块: min(3+1, 6) = 4

## 关键点总结

1. 需要统计每个字符的总出现次数
2. 分组记录连续相同字符的块
3. 考虑两种情况: 单块延长 和 两块合并
4. 合并时要检查中间是否只隔一个字符
5. 结果不能超过该字符的总数

## 易错点

1. 忘记考虑字符总数的限制
2. 合并时没有检查中间是否只隔一个字符
3. 边界情况: 字符串长度为1
4. 没有考虑所有字符都相同的情况
5. 合并后忘记 +1(交换中间的字符)
