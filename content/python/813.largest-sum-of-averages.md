## 题目描述

给定数组 `nums` 和一个整数 `k`。我们将给定的数组 `nums` 分成 **最多** `k` 个非空子数组，使得它们的每个子数组的平均值之和最大。

返回这个最大的平均值之和。误差在 `10^-6` 内的答案将被视为正确答案。

**示例 1:**
```
输入: nums = [9,1,2,3,9], k = 3
输出: 20.00000
解释: 最优分割是 [9], [1, 2, 3], [9]。平均值和为 9 + 2 + 9 = 20。
```

**示例 2:**
```
输入: nums = [1,2,3,4,5,6,7], k = 4
输出: 20.50000
```

**提示:**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

使用动态规划。`dp[i][k]` 表示前 `i` 个数分成 `k` 组的最大平均值和。

**状态转移：**
```python
dp[i][k] = max(dp[j][k-1] + avg(j+1, i)) for all j < i
```

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def largestSumOfAverages(self, nums: List[int], k: int) -> float:
        n = len(nums)
        
        # 前缀和，方便计算子数组平均值
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        def avg(i, j):
            """计算 nums[i:j+1] 的平均值"""
            return (prefix[j + 1] - prefix[i]) / (j - i + 1)
        
        # dp[i][groups] 表示前 i 个数分成 groups 组的最大平均值和
        dp = [[0.0] * (k + 1) for _ in range(n)]
        
        # 初始化：每个数自成一组
        for i in range(n):
            dp[i][1] = avg(0, i)
        
        # 状态转移
        for groups in range(2, k + 1):
            for i in range(groups - 1, n):
                for j in range(groups - 2, i):
                    dp[i][groups] = max(dp[i][groups], 
                                       dp[j][groups - 1] + avg(j + 1, i))
        
        return dp[n - 1][k]
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def largestSumOfAverages(self, nums: List[int], k: int) -> float:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        @lru_cache(maxsize=None)
        def dp(i, groups):
            """前 i 个数分成 groups 组的最大平均值和"""
            if groups == 1:
                return (prefix[i] - prefix[0]) / i
            
            max_sum = 0
            for j in range(groups - 1, i):
                avg = (prefix[i] - prefix[j]) / (i - j)
                max_sum = max(max_sum, dp(j, groups - 1) + avg)
            
            return max_sum
        
        return dp(n, k)
```

## 复杂度分析

- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n × k)

## 关键点总结

1. **前缀和优化**：快速计算子数组和
2. **DP状态设计**：二维状态表示位置和组数
3. **枚举分割点**：最后一组从哪里开始

## 易错点

1. **平均值计算**：使用前缀和
2. **初始化**：第一组的情况要单独处理
3. **循环范围**：注意边界条件
