## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `target`。

定义 `infinite_nums` 为 `nums` 的无限拼接（即 nums + nums + nums + ...）。

返回 `infinite_nums` 中满足元素之和等于 `target` 的**最短子数组**的长度。如果不存在，返回 -1。

**示例 1：**
```
输入：nums = [1,2,3], target = 5
输出：2
解释：target=5，子数组 [2,3] 长度 2，[1,2,3,... 可以找到更短的 [2,3] 长度 2]
```

**示例 2：**
```
输入：nums = [1,1,1,2,3], target = 4
输出：2
解释：子数组 [1,3] 长度 2（跨越一个循环边界：[3,1]（即 nums[4]+nums[0]=3+1=4））
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= target <= 10^9`

## 解题思路

**分析：** 设 `total = sum(nums)`，`target = q * total + r`（其中 `0 <= r < total`）。

- 完整的 q 个 nums 总和 = `q * total`
- 还需要一个子数组（可能跨边界）其和 = r
  - 若 r == 0，直接用 q 个完整 nums，但最短的是找 nums 中最短和为 total 的子数组（即整个 nums 本身，如果找不到更短）
  - 若 r > 0，在 nums + nums 中找最短子数组和 = r

**关键：**
1. 若 `target % total == 0`：需要恰好 `target / total` 个完整 nums，但也可能在 nums + nums 中找到更短的（目标 r = total）。这种情况下，在 nums + nums 中找最短和 = total 的子数组（就是找在 2 倍 nums 中的最短和等于 total 的子数组）
   
   其实更简单：设 `r = target % total`：
   - 若 r == 0：r 实际上 = total（子数组必须包含完整的 total），所以在 `2 * nums` 中找和 = total 的最短子数组
   - 否则：在 `2 * nums` 中找和 = r 的最短子数组
2. 最终长度 = `(q - (r == 0)) * n + len_short`

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minSizeSubarray(self, nums: List[int], target: int) -> int:
        n = len(nums)
        total = sum(nums)

        # q 个完整数组 + r 的余数
        q, r = divmod(target, total)

        # 若 r == 0，在 2*nums 中找和 = total 的最短子数组
        # 若 r > 0，在 2*nums 中找和 = r 的最短子数组
        need = r if r > 0 else total

        # 在 nums + nums 中找最短子数组和 = need（滑动窗口）
        doubled = nums + nums
        cur_sum = 0
        left = 0
        best = float('inf')

        for right in range(2 * n):
            cur_sum += doubled[right]
            while cur_sum > need:
                cur_sum -= doubled[left]
                left += 1
            if cur_sum == need:
                best = min(best, right - left + 1)

        if best == float('inf'):
            return -1

        # 总长度：若 r > 0，用 q 个完整 nums + best 长的子数组
        # 若 r == 0，用 (q-1) 个完整 nums + best 长的子数组（因为找的是 total 的子数组）
        extra_complete = q if r > 0 else q - 1
        return extra_complete * n + best
```

## 复杂度分析

- 时间复杂度：O(n)，滑动窗口扫描 2n 个元素
- 空间复杂度：O(n)，存储 doubled 数组

## 关键点总结

1. 将 target 分解为 q 个完整 nums + 余数 r 的最短子数组
2. 在 nums + nums 中用滑动窗口找最短和 = r 的子数组
3. r = 0 特殊处理：等价于找 total 的子数组，然后总完整数减 1

## 易错点

1. `r = 0` 时需要特殊处理（在 2*nums 中找 sum = total，而不是 sum = 0）
2. 完整数组个数：r > 0 时用 q 个，r = 0 时用 q-1 个
3. 若 `best = inf`（在 2*nums 中找不到满足条件的子数组），返回 -1
