## 题目描述

设计并实现一个最不经常使用（LFU）缓存。

实现 `LFUCache` 类：

- `LFUCache(int capacity)` - 用数据结构的容量 `capacity` 初始化对象
- `int get(int key)` - 如果键 `key` 存在于缓存中，则获取键的值，否则返回 `-1`
- `void put(int key, int value)` - 如果键已存在，则变更其值；如果键不存在，则插入键值对。当缓存达到其容量 `capacity` 时，应该在插入新项之前，移除最不经常使用的项。在此问题中，当存在平局（即两个或更多个键具有相同使用频率）时，应该去除最近最久未使用的键

为了确定最不常使用的键，可以为缓存中的每个键维护一个使用计数器。使用计数最小的键是最不经常使用的键。

当一个键首次插入到缓存中时，它的使用计数器被设置为 `1`（由于 `put` 操作）。对缓存中的键执行 `get` 或 `put` 操作时，使用计数器的值将会递增。

函数 `get` 和 `put` 必须以 O(1) 的平均时间复杂度运行。

**示例：**
```
输入:
["LFUCache", "put", "put", "get", "put", "get", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [3], [4, 4], [1], [3], [4]]
输出:
[null, null, null, 1, null, -1, 3, null, -1, 3, 4]

解释:
// cnt(x) = 键 x 的使用计数
// cache=[] 将显示最后使用的顺序（最左边的元素是最近的）
LFUCache lfu = new LFUCache(2);
lfu.put(1, 1);   // cache=[1,_], cnt(1)=1
lfu.put(2, 2);   // cache=[2,1], cnt(2)=1, cnt(1)=1
lfu.get(1);      // 返回 1
                 // cache=[1,2], cnt(2)=1, cnt(1)=2
lfu.put(3, 3);   // 2 是 LFU 键因为 cnt(2)=1 最小，移除键 2
                 // cache=[3,1], cnt(3)=1, cnt(1)=2
lfu.get(2);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,1], cnt(3)=2, cnt(1)=2
lfu.put(4, 4);   // 1 和 3 的 cnt 相同，但 1 最久未使用，移除键 1
                 // cache=[4,3], cnt(4)=1, cnt(3)=2
lfu.get(1);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,4], cnt(4)=1, cnt(3)=3
lfu.get(4);      // 返回 4
                 // cache=[4,3], cnt(4)=2, cnt(3)=3
```

**提示：**
- `1 <= capacity <= 10^4`
- `0 <= key <= 10^5`
- `0 <= value <= 10^9`
- 最多调用 `2 * 10^5` 次 `get` 和 `put` 方法

## 解题思路

LFU 缓存需要满足两个条件：
1. 移除访问频率最低的键
2. 频率相同时，移除最久未使用的键（LRU）

**数据结构设计：**

1. **哈希表** `key_map`: `{key: Node}` - 快速查找节点
2. **频率哈希表** `freq_map`: `{freq: DoublyLinkedList}` - 管理每个频率的节点链表
3. **最小频率** `min_freq`: 记录当前最小访问频率
4. **双向链表**: 每个频率对应一个双向链表，维护 LRU 顺序

**核心操作：**

### get(key):
1. 如果 key 不存在，返回 -1
2. 获取节点值
3. 增加节点频率（从旧频率链表移除，加入新频率链表）
4. 返回值

### put(key, value):
1. 如果 key 已存在，更新值并增加频率
2. 如果 key 不存在：
   - 如果缓存已满，移除 `min_freq` 链表的最后一个节点
   - 创建新节点，频率为 1
   - 加入频率 1 的链表
   - 更新 `min_freq` 为 1

### 增加频率:
1. 从当前频率链表移除节点
2. 如果链表为空且该频率是 `min_freq`，则 `min_freq++`
3. 节点频率 +1
4. 加入新频率链表的头部（最近使用）

## Python 代码实现

### 方法一：哈希表 + 双向链表（推荐）

```python
from collections import defaultdict

class Node:
    """双向链表节点"""
    def __init__(self, key: int, value: int):
        self.key = key
        self.value = value
        self.freq = 1  # 初始频率为 1
        self.prev = None
        self.next = None

class DoublyLinkedList:
    """双向链表，维护 LRU 顺序"""
    def __init__(self):
        self.head = Node(-1, -1)  # 哨兵节点
        self.tail = Node(-1, -1)
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def add_first(self, node: Node) -> None:
        """在链表头部添加节点（最近使用）"""
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node
    
    def remove(self, node: Node) -> Node:
        """移除指定节点"""
        node.next.prev = node.prev
        node.prev.next = node.next
        node.next, node.prev = None, None
        return node
    
    def remove_last(self) -> Node:
        """移除最后一个节点（最久未使用）"""
        return self.remove(self.tail.prev)
    
    def is_empty(self) -> bool:
        """检查链表是否为空"""
        return self.head.next == self.tail

class LFUCache:
    """LFU 缓存实现"""
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.min_freq = 0  # 最小访问频率
        self.key_map = {}  # key -> Node
        self.freq_map = defaultdict(DoublyLinkedList)  # freq -> DoublyLinkedList
    
    def get(self, key: int) -> int:
        """获取键的值"""
        if self.capacity == 0 or key not in self.key_map:
            return -1
        
        node = self.key_map[key]
        self._incr_freq(node)  # 增加频率
        return node.value
    
    def put(self, key: int, value: int) -> None:
        """插入或更新键值对"""
        if self.capacity == 0:
            return
        
        # 键已存在，更新值和频率
        if key in self.key_map:
            node = self.key_map[key]
            node.value = value
            self._incr_freq(node)
            return
        
        # 键不存在，需要插入
        # 如果缓存已满，移除最不常用的键
        if len(self.key_map) == self.capacity:
            # 从最小频率链表移除最后一个节点
            ls = self.freq_map[self.min_freq]
            removed = ls.remove_last()
            del self.key_map[removed.key]
        
        # 创建新节点并添加
        node = Node(key, value)
        self._add_node(node)
        self.key_map[key] = node
        self.min_freq = 1  # 新节点频率为 1
    
    def _incr_freq(self, node: Node) -> None:
        """增加节点的访问频率"""
        freq = node.freq
        ls = self.freq_map[freq]
        ls.remove(node)  # 从当前频率链表移除
        
        # 如果当前频率链表为空，更新 min_freq
        if ls.is_empty():
            del self.freq_map[freq]
            if freq == self.min_freq:
                self.min_freq += 1
        
        # 增加频率并添加到新链表
        node.freq += 1
        self._add_node(node)
    
    def _add_node(self, node: Node) -> None:
        """将节点添加到对应频率的链表头部"""
        freq = node.freq
        ls = self.freq_map[freq]
        ls.add_first(node)

# Your LFUCache object will be instantiated and called as such:
# obj = LFUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)
```

## 复杂度分析

- **时间复杂度**：
  - `get`: O(1) - 哈希表查找 + 链表操作
  - `put`: O(1) - 哈希表操作 + 链表操作
  
- **空间复杂度**：O(capacity)
  - 存储最多 `capacity` 个节点
  - 频率链表数量最多为 `capacity`

## 关键点总结

1. **双向链表维护 LRU 顺序**：同频率的节点按访问时间排序
2. **频率分组**：每个频率对应一个链表
3. **最小频率跟踪**：用 `min_freq` 快速定位要移除的节点
4. **节点移动**：访问时从旧频率链表移到新频率链表
5. **哨兵节点**：简化链表操作，避免空指针判断

## 易错点

1. **忘记更新 min_freq**
   ```python
   # 错误：移除后没有更新 min_freq
   if ls.is_empty():
       del self.freq_map[freq]
   
   # 正确：检查并更新
   if ls.is_empty():
       del self.freq_map[freq]
       if freq == self.min_freq:
           self.min_freq += 1
   ```

2. **节点频率更新顺序**
   ```python
   # 正确顺序：先移除，再增加频率，最后添加
   ls.remove(node)
   node.freq += 1
   self._add_node(node)
   ```

3. **put 时更新现有键**
   ```python
   # 必须检查键是否已存在
   if key in self.key_map:
       # 更新值和频率
       return
   # 否则插入新键
   ```
