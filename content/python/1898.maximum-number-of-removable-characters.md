## 题目描述

给你两个字符串 `s` 和 `p`，其中 `p` 是 `s` 的**子序列**。同时给你一个元素各不相同的整数数组 `removable`，其中 `removable[i]` 是 `s` 中某个字符的下标。

每步操作中，你可以将 `s[removable[0]], s[removable[1]], ...` 依次标记为"已删除"（但实际不删除），判断删除前 k 个后 `p` 是否仍是 `s` 的子序列。

返回可以删除的最大元素数 `k`（`0 <= k <= removable.length`）。

**示例 1：**
```
输入：s = "abcacb", p = "ab", removable = [3,1,0]
输出：2
解释：删除下标 3, 1 后 s = "a_c_cb"（下划线表示删除），p="ab" 仍是子序列
删除 3 个则 s = "__c_cb"，p="ab" 不是子序列
```

**示例 2：**
```
输入：s = "abcbddddd", p = "abcd", removable = [3,2,1,4,5,6]
输出：1
```

**提示：**
- `1 <= p.length <= s.length <= 10^5`
- `0 <= removable.length < s.length`
- `removable[i]` 各不相同

## 解题思路

**二分查找**：

删除数量 k 具有单调性：若删除前 k 个后 p 仍是子序列，则删除前 k-1 个也成立（单调递减，即答案是满足条件的最大 k）。

因此，对 k 进行二分查找：
- 验证函数：将 `removable[0..k-1]` 对应的下标标记为删除，检查 p 是否仍是 s 的子序列

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def maximumRemovals(self, s: str, p: str, removable: List[int]) -> int:
        def is_subseq(k: int) -> bool:
            """删除前 k 个元素后，p 是否仍是 s 的子序列"""
            # 标记删除的下标
            removed = set(removable[:k])
            j = 0  # p 的指针
            for i in range(len(s)):
                if i in removed:
                    continue
                if j < len(p) and s[i] == p[j]:
                    j += 1
            return j == len(p)

        # 二分查找最大 k
        lo, hi = 0, len(removable)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if is_subseq(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：二分 + 数组标记（更快）

```python
from typing import List

class Solution:
    def maximumRemovals(self, s: str, p: str, removable: List[int]) -> int:
        n = len(s)

        def check(k: int) -> bool:
            # 用布尔数组代替集合，访问更快
            deleted = [False] * n
            for i in range(k):
                deleted[removable[i]] = True

            j = 0
            for i in range(n):
                if not deleted[i] and j < len(p) and s[i] == p[j]:
                    j += 1

            return j == len(p)

        lo, hi = 0, len(removable)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法三：直接线性枚举（超时但理解用）

```python
from typing import List

class Solution:
    def maximumRemovals(self, s: str, p: str, removable: List[int]) -> int:
        def is_subseq(removed_set):
            j = 0
            for i, ch in enumerate(s):
                if i not in removed_set and j < len(p) and ch == p[j]:
                    j += 1
            return j == len(p)

        # 从最大 k 往小枚举（暴力）
        for k in range(len(removable), -1, -1):
            if is_subseq(set(removable[:k])):
                return k
        return 0
```

## 复杂度分析

- **时间复杂度**：O((n + m) * log(len(removable)))，二分 O(log r) 次，每次验证 O(n + m)
- **空间复杂度**：O(n)，删除标记数组

## 关键点总结

1. 单调性：删除越少越容易保持子序列关系，适合二分查找
2. 二分的模板：求满足条件的**最大 k**，使用 `lo = mid`，`hi = mid - 1`
3. 验证子序列：用双指针，跳过已删除的字符

## 易错点

- 二分时上界为 `len(removable)`，不是 `len(s)`
- 使用数组标记比集合查找更快（O(1) vs 哈希）
- 验证是「删除前 k 个」，不是随意选 k 个
