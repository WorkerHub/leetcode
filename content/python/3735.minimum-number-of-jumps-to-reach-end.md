## 题目描述

给定整数数组 `nums`，从下标 `0` 出发，每次可以从当前位置 `i` 跳跃到 `i + nums[i]` 或 `i - nums[i]`（若目标下标合法）。求到达最后一个下标 `n-1` 所需的最少跳跃次数，若不可达返回 `-1`。

**示例 1：**
```
输入：nums = [2,3,1,1,4]
输出：2
解释：从 0 跳 2 步到达 2，再跳 1 步到达 3，再跳 1 步到达 4（终点）... 或 0->1->4，共 2 步。
```

**示例 2：**
```
输入：nums = [1,2,3]
输出：2
解释：0->1->（1+2=3，但 n-1=2）->... 0->(0+1=1)->(1+2=3 越界，或 1-2 越界)... 
     0->2（0+nums[0]=0+1=1，哦不对）... 
     nums[0]=1: 0->1; nums[1]=2: 1->3(越界) 或 1->-1(越界); 不行。
     nums[0]=1: 0->1; nums[1]=2: 1+2=3>2, 1-2=-1<0; 死路？
     重新：nums = [1,2,3]: 0->0+1=1, 1->1+2=3(越界)或1->1-2=-1; 所以到不了 2？返回 -1。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^5`

## 解题思路

BFS（广度优先搜索），最少跳跃次数等价于 BFS 最短层数。

从节点 0 出发，每次可以到达 `i + nums[i]` 和 `i - nums[i]`，BFS 找到终点 `n-1` 的最短步数。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minJumps(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return 0

        visited = [False] * n
        visited[0] = True
        queue = deque([0])
        steps = 0

        while queue:
            steps += 1
            for _ in range(len(queue)):
                i = queue.popleft()
                for nxt in [i + nums[i], i - nums[i]]:
                    if nxt == n - 1:
                        return steps
                    if 0 <= nxt < n and not visited[nxt]:
                        visited[nxt] = True
                        queue.append(nxt)

        return -1
```

### 方法二：动态规划（适合有向图结构）

```python
from typing import List

class Solution:
    def minJumps(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')
        dp = [INF] * n
        dp[0] = 0

        # 按步数 BFS 等价于 DP（但需要多轮迭代）
        changed = True
        while changed:
            changed = False
            for i in range(n):
                if dp[i] == INF:
                    continue
                for nxt in [i + nums[i], i - nums[i]]:
                    if 0 <= nxt < n and dp[i] + 1 < dp[nxt]:
                        dp[nxt] = dp[i] + 1
                        changed = True

        return dp[n-1] if dp[n-1] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n)，BFS 每个节点访问一次
- 空间复杂度：O(n)，visited 数组和队列

## 关键点总结

1. BFS 自然求最短路，适合无权图（等步数）
2. 每个节点最多访问一次，用 visited 数组防止重复
3. 每步可以跳正负两个方向

## 易错点

1. 注意 `i - nums[i]` 可能为负数，需要边界检查
2. 起点和终点相同（n=1）时直接返回 0
