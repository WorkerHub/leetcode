## 题目描述

给你一个下标从 0 开始的 `p x q` 整数矩阵 `grid`，你需要构建一个新的矩阵 `ans`，其中 `ans[i][j]` 等于除 `grid[i][j]` 以外的所有元素之积，结果对 `12345` 取余。

**示例 1：**
```
输入：grid = [[1,2],[3,4]]
输出：[[24,12],[8,6]]
```

**示例 2：**
```
输入：grid = [[2,2],[2,2],[2,2]]
输出：[[64,64],[64,64],[64,64]]
```

**提示：**
- `1 <= p, q <= 10^4`
- `1 <= p * q <= 10^5`
- `1 <= grid[i][j] <= 4000`

## 解题思路

将二维矩阵展开为一维数组处理。这是经典的"除自身以外所有元素之积"问题。

使用前缀积和后缀积：
- `prefix[k]`：第 0 到 k-1 个元素的乘积（不含 k）
- `suffix[k]`：第 k+1 到末尾元素的乘积（不含 k）
- `ans[k] = prefix[k] * suffix[k]`

所有运算在模 12345 下进行。

## Python 代码实现

### 方法一：前缀积 × 后缀积（推荐）

```python
from typing import List

class Solution:
    def constructProductMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        MOD = 12345
        p, q = len(grid), len(grid[0])
        n = p * q

        # 将二维矩阵展平为一维
        flat = [grid[i][j] for i in range(p) for j in range(q)]

        # 计算前缀积（不含当前元素）
        prefix = [1] * n
        for k in range(1, n):
            prefix[k] = prefix[k - 1] * flat[k - 1] % MOD

        # 计算后缀积（不含当前元素）
        suffix = [1] * n
        for k in range(n - 2, -1, -1):
            suffix[k] = suffix[k + 1] * flat[k + 1] % MOD

        # 构建答案矩阵
        ans = [[0] * q for _ in range(p)]
        for k in range(n):
            i, j = divmod(k, q)
            ans[i][j] = prefix[k] * suffix[k] % MOD

        return ans
```

### 方法二：原地前缀积（空间优化）

```python
from typing import List

class Solution:
    def constructProductMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        MOD = 12345
        p, q = len(grid), len(grid[0])
        n = p * q

        # ans 先存前缀积
        ans = [[0] * q for _ in range(p)]
        prod = 1
        for k in range(n):
            i, j = divmod(k, q)
            ans[i][j] = prod
            prod = prod * grid[i][j] % MOD

        # 再乘后缀积
        suffix = 1
        for k in range(n - 1, -1, -1):
            i, j = divmod(k, q)
            ans[i][j] = ans[i][j] * suffix % MOD
            suffix = suffix * grid[i][j] % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(p*q)，线性遍历两次
- 空间复杂度：O(1)（方法二），输出矩阵不算额外空间

## 关键点总结

1. 二维矩阵可以用 `divmod(k, q)` 在一维下标和二维坐标间转换
2. 前缀积和后缀积的经典技巧：`ans[k] = prefix[k] * suffix[k]`
3. 所有乘法需要对 12345 取余，注意是 12345 而非常见的 10^9+7

## 易错点

1. 模数是 12345，不是质数，但不影响算法正确性
2. 前缀积不含当前元素：`prefix[k]` 是前 k 个元素之积（下标 0..k-1）
3. 二维展平时按行展开：`k = i * q + j`
