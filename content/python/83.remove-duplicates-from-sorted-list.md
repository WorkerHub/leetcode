## 题目描述

给定一个已排序的链表的头 `head`，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

**示例 1：**
```
输入：head = [1,1,2]
输出：[1,2]
```

**示例 2：**
```
输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

**提示：**
- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序排列

## 解题思路

**核心思想：** 遍历链表，如果当前节点与下一个节点值相同，就跳过下一个节点。

**关键观察：**
1. 链表已排序，重复元素必定相邻
2. 保留第一个重复节点，删除后续重复节点
3. 不需要虚拟头节点，因为头节点必定保留

**算法流程：**
1. 从头节点开始遍历
2. 如果 `curr.val == curr.next.val`，说明有重复
3. 跳过下一个节点：`curr.next = curr.next.next`
4. 否则，移动到下一个节点

## Python 代码实现

### 方法一：迭代（推荐）

```python
from typing import Optional

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 空链表直接返回
        if not head:
            return head
        
        curr = head
        
        while curr and curr.next:
            if curr.val == curr.next.val:
                # 删除下一个节点（跳过）
                curr.next = curr.next.next
            else:
                # 移动到下一个节点
                curr = curr.next
        
        return head
```

### 方法二：递归

```python
from typing import Optional

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 递归终止条件
        if not head or not head.next:
            return head
        
        # 递归处理后续节点
        head.next = self.deleteDuplicates(head.next)
        
        # 如果当前节点与下一个节点值相同，返回下一个节点
        if head.val == head.next.val:
            return head.next
        
        return head
```

### 方法三：while 循环跳过所有重复

```python
from typing import Optional

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return head
        
        curr = head
        
        while curr:
            # 跳过所有与当前节点值相同的节点
            while curr.next and curr.val == curr.next.val:
                curr.next = curr.next.next
            
            # 移动到下一个不同值的节点
            curr = curr.next
        
        return head
```

## 复杂度分析

**方法一（迭代）：**
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(1)

**方法二（递归）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归调用栈

## 关键点总结

1. **保留策略**：保留第一个，删除后续重复节点
2. **不需要虚拟头节点**：头节点必定保留
3. **移动时机**：只有确定下一个节点值不同时才移动
4. **链表已排序**：重复元素必定相邻

## 易错点

1. **空指针判断**：`curr.next` 判断要在前面，防止空指针异常
2. **移动时机**：发现重复时不要移动 curr，只修改 curr.next
3. **边界条件**：空链表或单节点链表要特殊处理
