## 题目描述

考虑一个对**无序数组** `nums` 进行二分查找的过程：

在 `[left, right]` 范围内，每次取中间元素 `nums[mid]` 与目标值比较：
- 如果 `nums[mid] == target`，返回 mid
- 如果 `nums[mid] < target`，在 `[mid+1, right]` 中继续找
- 如果 `nums[mid] > target`，在 `[left, mid-1]` 中继续找

给你一个整数数组 `nums`（所有元素不同），返回**可二分搜索**的元素数量——即对于这些元素作为搜索目标，无论以哪种方式选取中间点，都能被二分查找找到。

一个元素 `x` 可以被二分搜索找到，当且仅当：在 `x` 左侧的所有元素都小于 `x`，且在 `x` 右侧的所有元素都大于 `x`（即 `x` 是局部可搜索的）。

**示例 1：**
```
输入：nums = [-1, 5, 2]
输出：1
解释：只有 5 的左边只有比它小的（-1），右边只有比它大的（不存在），5 可二分搜索
```

**提示：**
- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^4`，所有元素不同

---

## 解题思路

### 核心思想：前缀最大值和后缀最小值

元素 `nums[i]` 可以被二分搜索找到当且仅当：
- `nums[i]` 大于其左侧所有元素（即 `nums[i] > max(nums[0..i-1])`）
- `nums[i]` 小于其右侧所有元素（即 `nums[i] < min(nums[i+1..n-1])`）

用前缀最大值数组和后缀最小值数组快速判断。

---

## 代码实现

### 方法一：前缀最大值 + 后缀最小值（推荐）

```python
from typing import List

class Solution:
    def binarySearchableNumbers(self, nums: List[int]) -> int:
        n = len(nums)

        # prefix_max[i] = nums[0..i-1] 的最大值（i=0 时为 -inf）
        prefix_max = [float('-inf')] * n
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i - 1])

        # suffix_min[i] = nums[i+1..n-1] 的最小值（i=n-1 时为 inf）
        suffix_min = [float('inf')] * n
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i + 1])

        count = 0
        for i in range(n):
            # nums[i] 必须大于左侧所有元素且小于右侧所有元素
            if nums[i] > prefix_max[i] and nums[i] < suffix_min[i]:
                count += 1

        return count
```

### 方法二：O(n) 单次扫描

```python
from typing import List

class Solution:
    def binarySearchableNumbers(self, nums: List[int]) -> int:
        n = len(nums)

        # 计算后缀最小值
        suffix_min = [float('inf')] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_min[i] = min(nums[i], suffix_min[i + 1])

        count = 0
        cur_max = float('-inf')  # 当前遍历到的最大值

        for i in range(n):
            # nums[i] 可二分搜索：大于左侧所有 且 小于右侧所有
            if nums[i] > cur_max and nums[i] < suffix_min[i + 1]:
                count += 1
            cur_max = max(cur_max, nums[i])

        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(n) |
| 方法二 | O(n) | O(n) |

---

## 关键点总结

1. 可二分搜索的元素 = 满足"前缀最大值 < x < 后缀最小值"的元素
2. 等价于：x 比左侧所有元素大，且比右侧所有元素小
3. 用前缀/后缀预处理可在 O(n) 时间完成

---

## 易错点

- 前缀最大值 `prefix_max[i]` 是 `i` 左侧（不含 `i`）的最大值
- 后缀最小值 `suffix_min[i]` 是 `i` 右侧（不含 `i`）的最小值
