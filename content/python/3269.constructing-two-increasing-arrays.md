## 题目描述

给你两个 `0` 索引的整数数组 `nums1` 和 `nums2`，每个数组只包含 `0` 和 `1`，长度均为 `n`。

在一次操作中，你可以选择两个下标 `i`（0 ≤ i < n），交换 `nums1[i]` 和 `nums2[i]`。

你的目标是让 `nums1` 和 `nums2` 都变为**严格递增**的数组。

返回所需的**最少操作次数**，若无法实现返回 `-1`。

**提示：**
- `1 <= n <= 1000`
- `nums1[i], nums2[i]` 只包含 0 或 1

## 解题思路

DP：对每个位置 i，状态为是否交换（0/1），转移时保证严格递增。

`dp[i][s]` = 前 i 个位置，第 i 个位置状态为 s（0 不换，1 换）时的最少操作次数。

转移条件：第 i 个位置选择 s 后，第 i-1 个位置选择 s_prev，需满足：
- `nums1_i > nums1_{i-1}`（nums1 严格递增）
- `nums2_i > nums2_{i-1}`（nums2 严格递增）

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        INF = float('inf')
        
        # dp[s] = 当前位置状态为 s 的最少操作次数
        # s=0: 不换，s=1: 换
        dp = [0, 1]  # 第 0 个位置
        
        for i in range(1, n):
            new_dp = [INF, INF]
            
            for s in range(2):  # 当前状态
                # 当前位置的值
                a_cur = nums1[i] if s == 0 else nums2[i]
                b_cur = nums2[i] if s == 0 else nums1[i]
                
                for s_prev in range(2):  # 前一位置状态
                    if dp[s_prev] == INF:
                        continue
                    a_prev = nums1[i-1] if s_prev == 0 else nums2[i-1]
                    b_prev = nums2[i-1] if s_prev == 0 else nums1[i-1]
                    
                    # 检查严格递增
                    if a_cur > a_prev and b_cur > b_prev:
                        cost = dp[s_prev] + s  # s=1 表示换，代价为1
                        new_dp[s] = min(new_dp[s], cost)
            
            dp = new_dp
        
        ans = min(dp)
        return ans if ans != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n * 4) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个位置只有两个状态（换/不换）
2. DP 转移时检查严格递增约束
3. 由于只有 0 和 1，严格递增要求相邻位置不同

## 易错点

1. 严格递增（`>`），不是非递减（`>=`）
2. 注意对于 0/1 数组，严格递增意味着 [0, 1] 模式
