## 题目描述

给你一个整数数组 `arr`，返回元素总和为 **奇数** 的子数组数目。

由于答案可能很大，请你将结果对 `10^9 + 7` 取模后再返回。

**示例 1：**
```
输入：arr = [1,3,5]
输出：4
解释：子数组为 [1],[1,3],[1,3,5],[3],[3,5],[5]，和为奇数的有 [1],[1,3,5],[3],[3,5]
```

**示例 2：**
```
输入：arr = [2,4,6]
输出：0
```

**示例 3：**
```
输入：arr = [1,2,3,4,5,6,7]
输出：16
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 100`

## 解题思路

### 前缀和奇偶性

子数组 `[l, r]` 的和 = `prefix[r] - prefix[l-1]`。

要使子数组和为奇数，需要 `prefix[r]` 和 `prefix[l-1]` 的奇偶性不同（一奇一偶）。

所以，维护前缀和中奇数和偶数的数量：
- `prefix[0] = 0`（偶数），初始 `even = 1, odd = 0`
- 遍历每个元素，更新前缀和的奇偶性
- 若当前前缀和为奇数，则与前面所有偶数前缀和配对，贡献 `even` 个子数组
- 若当前前缀和为偶数，则与前面所有奇数前缀和配对，贡献 `odd` 个子数组

## 代码实现

### 方法一：前缀和奇偶统计（推荐）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        ans = 0
        prefix = 0
        even = 1  # prefix[0] = 0 是偶数
        odd = 0

        for num in arr:
            prefix += num
            if prefix % 2 == 1:
                # 当前前缀和为奇数，与前面所有偶数前缀和配对
                ans = (ans + even) % MOD
                odd += 1
            else:
                # 当前前缀和为偶数，与前面所有奇数前缀和配对
                ans = (ans + odd) % MOD
                even += 1

        return ans
```

### 方法二：只记录奇偶性（不记录实际值）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        ans = 0
        # count[0] = 偶数前缀和数量，count[1] = 奇数前缀和数量
        count = [1, 0]  # 初始 prefix[0] = 0 为偶数
        prefix_parity = 0  # 当前前缀和的奇偶性

        for num in arr:
            prefix_parity = (prefix_parity + num) % 2
            # 与前面奇偶性不同的前缀和配对
            ans = (ans + count[1 - prefix_parity]) % MOD
            count[prefix_parity] += 1

        return ans
```

### 方法三：暴力（仅供参考）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + arr[i]
        ans = 0
        for i in range(n):
            for j in range(i+1, n+1):
                if (prefix[j] - prefix[i]) % 2 == 1:
                    ans = (ans + 1) % MOD
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一/二 | O(N) | O(1) |
| 方法三（暴力） | O(N^2) | O(N) |

## 关键点总结

1. 子数组和的奇偶性由两端前缀和的奇偶性决定：一奇一偶则为奇
2. 只需记录前缀和奇偶性的出现次数，不需要实际值
3. 初始时 `count[0] = 1`（空前缀和为 0，是偶数）

## 易错点

- 初始化 `count[0] = 1` 表示 `prefix[0] = 0`（偶数）
- 当前前缀和为奇，配对前面的偶（不是奇），关系要搞清楚
