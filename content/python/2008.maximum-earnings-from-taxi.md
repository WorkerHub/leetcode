## 题目描述

n 个地点沿一条路排列，位置编号从 1 到 n，司机从位置 1 出发。

给你一个整数 `n` 和一个二维整数数组 `rides`，其中 `rides[i] = [start_i, end_i, tip_i]` 表示第 `i` 位乘客在位置 `start_i` 上车，在位置 `end_i` 下车，并给司机 `tip_i` 美元小费。

每次接单，司机获得 `end_i - start_i + tip_i` 美元收入。

返回司机接单的**最大总收入**（司机可以选择接或不接任何乘客，但同一时间只能接一位乘客）。

**示例 1：**
```
输入：n = 5, rides = [[2,5,4],[1,5,1]]
输出：7
解释：接单 0：收入 5-2+4=7；接单 1：收入 5-1+1=5；选接单0收入最大
```

**示例 2：**
```
输入：n = 20, rides = [[1,6,1],[3,10,2],[10,12,3],[11,12,2],[12,15,2],[13,18,1]]
输出：20
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= rides.length <= 3 * 10^4`
- `rides[i].length == 3`
- `1 <= start_i < end_i <= n`
- `0 <= tip_i <= 10^5`

## 解题思路

这是经典的**加权区间调度**问题，用动态规划求解。

**dp 定义：** `dp[i]` 表示司机到达位置 `i` 时的最大收入。

**状态转移：**
- `dp[i] = dp[i-1]`（不在位置 `i` 接乘客，保持前一个位置的最大收入）
- 对于所有在位置 `i` 下车的乘客 `(start, i, tip)`：
  `dp[i] = max(dp[i], dp[start] + (i - start + tip))`

**优化：** 用哈希表将乘客按下车位置分组，便于快速查找。

## 代码实现

### 方法一：动态规划 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxTaxiEarnings(self, n: int, rides: List[List[int]]) -> int:
        # 按下车位置分组
        end_map = defaultdict(list)
        for start, end, tip in rides:
            end_map[end].append((start, tip))

        dp = [0] * (n + 1)  # dp[i] 表示到达位置 i 的最大收入

        for i in range(1, n + 1):
            dp[i] = dp[i - 1]  # 不在位置 i 接单
            for start, tip in end_map[i]:
                # 接从 start 到 i 的乘客
                earn = i - start + tip
                dp[i] = max(dp[i], dp[start] + earn)

        return dp[n]
```

### 方法二：排序 + 二分查找 DP

```python
from typing import List
import bisect

class Solution:
    def maxTaxiEarnings(self, n: int, rides: List[List[int]]) -> int:
        # 按下车位置排序
        rides.sort(key=lambda x: x[1])

        m = len(rides)
        # dp[i] 表示考虑前 i 个 ride 的最大收入（1-indexed）
        dp = [0] * (m + 1)

        ends = [ride[1] for ride in rides]  # 所有下车位置

        for i in range(1, m + 1):
            start, end, tip = rides[i - 1]
            earn = end - start + tip

            # 二分查找：找最后一个下车位置 <= start 的 ride
            j = bisect.bisect_right(ends, start, 0, i - 1)
            # rides[j-1] 是不与当前 ride 冲突的最后一个 ride
            dp[i] = max(dp[i - 1], dp[j] + earn)

        return dp[m]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（哈希表DP） | O(n + m)，m 为 rides 数量 | O(n + m) |
| 方法二（排序+二分DP） | O(m log m) | O(m) |

## 关键点总结

1. 定义 `dp[i]` 为到达位置 `i` 的最大收入，关键在按下车位置转移
2. 每趟行程收入为 `end - start + tip`，从 `dp[start]` 转移过来
3. 哈希表按下车位置分组，使状态转移更高效
4. 方法二类似"带权最多不相交区间"问题

## 易错点

- `dp[i] = dp[i-1]` 不能漏掉（司机可以选择不接任何乘客直接到位置 `i`）
- 收入公式是 `end - start + tip`，不是 `tip` 本身
- 二分查找时要找下车位置 `<= start`（不是 `< start`），因为接完乘客刚好到 `start`，可以立即接下一位
