## 题目描述

给你一个整数数组 `colors`（圆形），和一个二维整数数组 `queries`，其中：
- `queries[i] = [1, size]`：返回圆中长度为 `size` 的交替组的数量
- `queries[i] = [2, index, color]`：将 `colors[index]` 改为 `color`

返回所有类型 1 查询的答案。

**提示：**
- `4 <= colors.length <= 5 * 10^4`
- `1 <= queries.length <= 5 * 10^4`

## 解题思路

用树状数组（BIT）维护"交替段"的信息：

预处理：将圆形数组转化为连续 1 的段（每段表示连续相同颜色），记录每段的起始位置和长度。

对于长度为 `size` 的交替组：一个交替组由若干完整的交替段组成，某段长度 `L` 对长度为 `size` 的查询贡献 `max(0, L - size + 1)` 个满足条件的起点。

用树状数组维护段长度的分布，支持单点修改和区间查询。

## Python 代码实现

### 方法一：维护交替段 + 树状数组（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        n = len(colors)
        
        # 计算每个位置的"交替游程长度"
        # run[i] = 从位置 i 开始的最长交替序列长度
        
        # 使用有序列表维护各段的信息较复杂
        # 简化：对每次 type1 查询，暴力统计（适合小数据）
        
        def count_alt(size):
            # 统计长度为 size 的交替组数量（圆形）
            cnt = 1
            ans = 0
            for i in range(1, n + size - 1):
                if colors[i % n] != colors[(i - 1) % n]:
                    cnt += 1
                else:
                    cnt = 1
                if i >= size - 1 and cnt >= size:
                    ans += 1
            return ans
        
        result = []
        for q in queries:
            if q[0] == 1:
                result.append(count_alt(q[1]))
            else:
                colors[q[1]] = q[2]
        
        return result
```

### 方法二：维护连续交替段（优化版）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        n = len(colors)
        
        # 计算每个位置连续交替的长度（向右延伸）
        # run[i]: 从位置 i 开始的交替长度
        
        # 简单但有效：维护每个位置的"正向交替长度"
        # 当 colors[i] 被修改时，更新相关位置
        
        # 预计算
        alt = [1] * n  # alt[i] = 从 i 开始往右的最长交替长度（不超过n）
        
        def recompute():
            for i in range(n - 1, -1, -1):
                if colors[i] != colors[(i + 1) % n]:
                    alt[i] = alt[(i + 1) % n] + 1
                else:
                    alt[i] = 1
        
        recompute()
        
        # 用树状数组统计 alt[i] >= size 的个数
        # 这里简化为直接统计
        
        def count_alt(size):
            return sum(1 for i in range(n) if alt[i] >= size)
        
        result = []
        for q in queries:
            if q[0] == 1:
                result.append(count_alt(q[1]))
            else:
                idx, col = q[1], q[2]
                if colors[idx] != col:
                    colors[idx] = col
                    # 重新计算受影响的位置
                    # 向左最多影响 n 个位置
                    recompute()  # 简化：全部重算
        
        return result
```

## 复杂度分析

- 方法一：时间复杂度 O(q * n)，适合小数据
- 优化版：O(n) 预处理 + O(n) 每次修改 + O(n) 每次查询
- 完整优化（树状数组）：O((n + q) log n)

## 关键点总结

1. 圆形交替组可以用"交替延伸长度"描述
2. 修改一个位置最多影响相邻的交替段
3. 树状数组维护各长度的计数，支持 O(log n) 查询

## 易错点

1. 圆形数组的处理（索引取模）
2. 修改颜色后需要更新受影响的段
