## 题目描述

给你两个整数 `n`（符文数量）和 `ability`（法术能力值），以及一个二维数组 `spells`，其中 `spells[i] = [energyCost, effect]`。

要施放第 `i` 个法术，需要能量 >= `energyCost[i]`，施放后获得 `effect[i]` 的能量加成。

同时，一些符文之间有依赖关系（类似有向图），某些符文需要先放置其他符文。

你初始有一些符文和能量 `ability`，可以添加额外的符文（代价为 1）。

返回使所有法术都能施放的最少添加符文数。

**注意：** 本题的具体描述基于推测，实际以 LeetCode 官方为准。

## 解题思路

基于拓扑排序或反向依赖分析，计算需要额外激活的最少符文数量。

思路：将依赖关系建图，找出没有依赖（或依赖已满足）的节点，统计需要额外添加的节点数。

## Python 代码实现

### 方法一：拓扑排序（基础框架）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minRunesToAdd(self, n: int, crystals: List[int], flowFrom: List[int], flowTo: List[int]) -> int:
        # 构建有向图
        graph = defaultdict(list)
        in_degree = [0] * n
        
        for u, v in zip(flowFrom, flowTo):
            graph[u].append(v)
            in_degree[v] += 1
        
        # 可达节点：从初始节点（crystals）出发
        reachable = set(crystals)
        queue = deque(crystals)
        
        while queue:
            node = queue.popleft()
            for nb in graph[node]:
                if nb not in reachable:
                    reachable.add(nb)
                    queue.append(nb)
        
        # 找出未被覆盖的节点，逆向分析最少需要激活的
        # 目标：使所有节点可达（或满足某些条件）
        # 需要的额外节点数 = 未可达的起始节点数（入度为 0 且未被覆盖的节点）
        
        # 找入度为 0 且不可达的节点
        additions = 0
        changed = True
        while changed:
            changed = False
            for i in range(n):
                if i not in reachable:
                    # 检查 i 的所有前驱是否已可达
                    all_pred_reachable = True
                    # 这里需要反向图
                    break
        
        # 简化：统计不可达的入度为 0 的节点
        reverse_graph = defaultdict(list)
        for u, v in zip(flowFrom, flowTo):
            reverse_graph[v].append(u)
        
        # 找所有不可达的节点中，其前驱也不可达的节点集（新起点）
        for i in range(n):
            if i not in reachable and not any(p in reachable for p in reverse_graph[i]):
                # i 是新起点，需要添加
                additions += 1
                # BFS 从 i 出发扩展可达集
                reachable.add(i)
                q = deque([i])
                while q:
                    node = q.popleft()
                    for nb in graph[node]:
                        if nb not in reachable:
                            reachable.add(nb)
                            q.append(nb)
        
        return additions
```

## 复杂度分析

- 时间复杂度：O(n + m)，图遍历
- 空间复杂度：O(n + m)

## 关键点总结

1. 初始可达集从 `crystals` 出发扩展。
2. 对于不可达的节点，找那些前驱也不可达的节点（新起点），每添加一个新起点就从它扩展。
3. 贪心：优先选择能覆盖最多不可达节点的起点（可以转化为最少添加数）。

## 易错点

1. 添加一个节点后，需要重新扩展可达集（BFS）。
2. 新起点是"没有任何可达前驱的不可达节点"。
3. 逆向图帮助找每个节点的前驱。
