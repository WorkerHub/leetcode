## 题目描述

给你一个由正整数组成的数组 `nums` 和一个 **正** 整数 `k`。

如果 `nums` 的子集中，任意两个整数的绝对差 **不等于** `k`，则认为该子集是 **漂亮** 子集。

返回 `nums` 的 **非空漂亮** 子集的数目。

注意：子集是指从数组中选出若干元素组成的集合（不考虑顺序），相同的数视为不同元素（下标不同）。

**示例 1：**

```
输入：nums = [2,4,6], k = 2
输出：4
解释：漂亮子集：[2], [4], [6], [2,6]。
[2,4] 和 [4,6] 中各有两元素差为 2，不漂亮。
```

**示例 2：**

```
输入：nums = [1], k = 1
输出：1
```

**提示：**

- `1 <= nums.length <= 20`
- `1 <= nums[i], k <= 1000`

## 解题思路

**回溯 + 哈希计数**：

数组长度最多 20，枚举所有非空子集共 2^20 ≈ 100 万个，用回溯剪枝。

维护一个计数字典 `cnt`，每次加入元素 `x` 时，检查 `x-k` 和 `x+k` 是否已在集合中。

**优化 DP（按余数分组）**：

将 `nums` 按 `% k` 分组，同组内才可能出现差为 `k` 的对。每组独立用 DP 计算，组间答案相乘。

## Python 代码实现

### 方法一：回溯（推荐，简单直接）

```python
from typing import List
from collections import defaultdict

class Solution:
    def beautifulSubsets(self, nums: List[int], k: int) -> int:
        nums.sort()
        cnt = defaultdict(int)
        self.ans = 0

        def backtrack(start):
            for i in range(start, len(nums)):
                x = nums[i]
                # 若 x - k 在当前子集中，不能加入 x
                if cnt[x - k] > 0:
                    continue
                cnt[x] += 1
                self.ans += 1  # 每加入一个元素，子集数 +1
                backtrack(i + 1)
                cnt[x] -= 1

        backtrack(0)
        return self.ans
```

### 方法二：分组 DP（高效）

```python
from typing import List
from collections import defaultdict

class Solution:
    def beautifulSubsets(self, nums: List[int], k: int) -> int:
        # 按 x % k 分组
        groups = defaultdict(list)
        cnt = defaultdict(int)
        for x in nums:
            cnt[x] += 1

        for x in cnt:
            groups[x % k].append(x)

        # 对每组排序后，用 DP 计算该组的漂亮子集数（含空集）
        total = 1
        visited = set()
        for x in sorted(cnt):
            if x in visited:
                continue
            # 提取以 x 为起点的链：x, x+k, x+2k, ...
            chain = []
            cur = x
            while cur in cnt:
                chain.append((cur, cnt[cur]))
                visited.add(cur)
                cur += k

            # 链上 DP：dp[i] 表示考虑链前 i 个元素的漂亮子集数（含空集）
            # 对链上每个元素，可以选 0 到 cnt 个（但要保证相邻差不为 k 的约束）
            # 每个链节点的 cnt 个相同元素：选 t 个有 C(cnt, t) 种
            # 状态：不选当前节点 / 选当前节点（则不能选前一个）
            prev_skip = 1   # 前一个链节点不选的方案数
            prev_take = 0   # 前一个链节点选的方案数（选了 >= 1 个）

            for val, c in chain:
                # 选 1 到 c 个 val（有 2^c - 1 种）
                ways = (1 << c) - 1  # 2^c - 1（非空子集数）
                curr_skip = prev_skip + prev_take  # 不选当前节点
                curr_take = prev_skip * ways        # 选当前节点（前一个必须不选）
                prev_skip, prev_take = curr_skip, curr_take

            total *= (prev_skip + prev_take)

        return total - 1  # 减去全空集
```

## 复杂度分析

- 方法一时间复杂度：O(2^n)，回溯枚举
- 方法二时间复杂度：O(n log n)，排序 + 线性 DP
- 空间复杂度：O(n)

## 关键点总结

1. 方法一：回溯时检查 `x - k` 是否在集合中（排序后只需检查一侧）
2. 方法二：按 `% k` 分组，组间互不影响，组内形成链，用 DP
3. 链上 DP 类似打家劫舍：相邻节点不能同时选

## 易错点

1. 方法一中排序后只需检查 `x - k`（因为按升序添加，`x + k` 还未加入）
2. 方法二中相同值的元素有 `cnt` 个，可以选 1 到 cnt 个，共 `2^cnt - 1` 种非空选法
3. 方法二最后要减 1（全空集不算）
