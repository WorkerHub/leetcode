## 题目描述

给定一个 `m x n` 的整数矩阵 `grid` 和整数 `k`。对每个 `k x k` 的子矩阵，计算其中任意两个不同元素之差的绝对值的最小值（若子矩阵所有元素相同，则最小差为 0）。返回所有 `k x k` 子矩阵的最小差的列表（按行优先顺序）。

**示例 1：**

```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出：[[1,1],[1,1]]
解释：左上 2x2 子矩阵 [[1,2],[4,5]]，排序后 [1,2,4,5]，最小差=1。
```

**提示：**
- `1 <= m, n <= 30`
- `1 <= k <= min(m, n)`
- `-100 <= grid[i][j] <= 100`

## 解题思路

枚举所有 k×k 子矩阵，对每个子矩阵排序后找相邻元素的最小差。

子矩阵数量：`(m-k+1) * (n-k+1)`，每个子矩阵包含 `k^2` 个元素，排序为 `O(k^2 log k)`。

总时间复杂度：O(m * n * k^2 * log k)，对于 m, n <= 30, k <= 30，可接受。

## Python 代码实现

### 方法一：枚举子矩阵 + 排序（推荐）

```python
from typing import List

class Solution:
    def minAbsDiff(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        rows_out = m - k + 1
        cols_out = n - k + 1
        result = []

        for r in range(rows_out):
            row_result = []
            for c in range(cols_out):
                # 提取 k x k 子矩阵的所有元素
                elements = []
                for dr in range(k):
                    for dc in range(k):
                        elements.append(grid[r+dr][c+dc])

                # 排序后找最小差
                elements.sort()
                min_diff = float('inf')
                for i in range(1, len(elements)):
                    if elements[i] != elements[i-1]:
                        min_diff = min(min_diff, elements[i] - elements[i-1])

                row_result.append(0 if min_diff == float('inf') else min_diff)
            result.append(row_result)

        return result
```

### 方法二：使用集合去重后排序

```python
from typing import List

class Solution:
    def minAbsDiff(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        result = []

        for r in range(m - k + 1):
            row_result = []
            for c in range(n - k + 1):
                vals = sorted(set(
                    grid[r+dr][c+dc]
                    for dr in range(k)
                    for dc in range(k)
                ))
                if len(vals) <= 1:
                    row_result.append(0)
                else:
                    min_diff = min(vals[i+1] - vals[i] for i in range(len(vals)-1))
                    row_result.append(min_diff)
            result.append(row_result)

        return result
```

## 复杂度分析

- 时间复杂度：O(m * n * k^2 * log k)
- 空间复杂度：O(k^2)，每个子矩阵的元素

## 关键点总结

1. 枚举所有 `(m-k+1) * (n-k+1)` 个子矩阵
2. 对每个子矩阵排序，相邻元素之差的最小值就是答案
3. 所有元素相同时，最小差为 0

## 易错点

1. 返回的是二维结果（每个子矩阵的最小差排列成矩阵形式）
2. 若子矩阵所有元素相同（去重后只有1个），最小差为 0
3. 注意子矩阵的行列索引范围
