## 题目描述

设计一个算法，接收一个字符流，并检查这些字符的后缀是否是字符串数组 `words` 中的一个字符串。

例如，`words = ["abc", "xyz"]`，字符流依次添加四个字符 `'a'`、`'x'`、`'y'` 和 `'z'`，你的算法应当可以检测到 `"axyz"` 的后缀 `"xyz"` 与 `words` 中的字符串 `"xyz"` 匹配。

实现 `StreamChecker` 类：

- `StreamChecker(String[] words)`：使用给定的字符串数组 `words` 初始化对象
- `boolean query(char letter)`：从字符流中接收一个新字符，如果字符流的任意后缀与 `words` 中的某个字符串匹配，则返回 `true`；否则返回 `false`

**示例：**

```
输入:
["StreamChecker", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query"]
[[["cd", "f", "kl"]], ["a"], ["b"], ["c"], ["d"], ["e"], ["f"], ["g"], ["h"], ["i"], ["j"], ["k"], ["l"]]

输出:
[null, false, false, false, true, false, true, false, false, false, false, false, true]

解释:
StreamChecker streamChecker = new StreamChecker(["cd", "f", "kl"]);
streamChecker.query("a"); // 返回 False
streamChecker.query("b"); // 返回 False
streamChecker.query("c"); // 返回 False
streamChecker.query("d"); // 返回 True，因为 'cd' 在 words 中
streamChecker.query("e"); // 返回 False
streamChecker.query("f"); // 返回 True，因为 'f' 在 words 中
streamChecker.query("g"); // 返回 False
streamChecker.query("h"); // 返回 False
streamChecker.query("i"); // 返回 False
streamChecker.query("j"); // 返回 False
streamChecker.query("k"); // 返回 False
streamChecker.query("l"); // 返回 True，因为 'kl' 在 words 中
```

**提示：**

- `1 <= words.length <= 2000`
- `1 <= words[i].length <= 200`
- `words[i]` 由小写英文字母组成
- `letter` 是小写英文字母
- 最多调用 `query` 方法 `4 * 10^4` 次

## 解题思路

这道题的核心是**后缀匹配**，需要高效地检查字符流的后缀是否匹配给定的单词。

关键观察：
1. 我们需要检查的是**后缀**，而不是前缀
2. 字符流是持续增长的，需要高效的查询
3. 使用 Trie（字典树）可以高效地存储和查询字符串

核心思路：
1. **反向 Trie**：将所有单词反向插入 Trie，这样后缀匹配就变成了前缀匹配
2. **维护字符流**：保存接收到的字符（反向存储）
3. **查询优化**：每次查询时，从最新字符开始在 Trie 中查找

算法流程：
1. 初始化时，将所有单词反向插入 Trie
2. 每次 query 时，将新字符加入流的开头（反向存储）
3. 从流的开头开始在 Trie 中查找，看是否能匹配到完整单词
4. 为了避免超时，限制搜索深度为最长单词的长度

## Python 代码实现

### 方法一：反向 Trie（推荐）

```python
from typing import List

class TrieNode:
    """Trie 树的节点"""
    def __init__(self):
        self.children = {}  # 子节点
        self.is_end = False  # 是否是单词结尾

class StreamChecker:
    """
    使用反向 Trie 实现字符流后缀匹配
    
    时间复杂度:
    - 初始化: O(N*L)，N 是单词数量，L 是平均长度
    - query: O(L)，L 是最长单词的长度
    
    空间复杂度: O(N*L)
    """
    
    def __init__(self, words: List[str]):
        self.root = TrieNode()
        self.stream = []  # 存储字符流（反向）
        self.max_len = 0  # 最长单词的长度
        
        # 将所有单词反向插入 Trie
        for word in words:
            self.max_len = max(self.max_len, len(word))
            self._insert(word[::-1])  # 反向插入
    
    def _insert(self, word: str) -> None:
        """将单词插入 Trie"""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def query(self, letter: str) -> bool:
        """
        查询字符流的后缀是否匹配任何单词
        """
        # 将新字符添加到流的开头（反向存储）
        self.stream.insert(0, letter)
        
        # 在 Trie 中查找，从最新字符开始
        node = self.root
        # 只需要搜索最长单词的长度
        for i in range(min(len(self.stream), self.max_len)):
            char = self.stream[i]
            if char not in node.children:
                return False
            node = node.children[char]
            if node.is_end:
                return True
        
        return False
```

### 方法二：使用 collections.deque 优化

```python
from typing import List
from collections import deque

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class StreamChecker:
    """
    使用 deque 优化字符流存储
    
    时间复杂度:
    - 初始化: O(N*L)
    - query: O(L)
    
    空间复杂度: O(N*L + M)，M 是 query 调用次数
    """
    
    def __init__(self, words: List[str]):
        self.root = TrieNode()
        self.stream = deque()
        self.max_len = 0
        
        for word in words:
            self.max_len = max(self.max_len, len(word))
            node = self.root
            # 反向插入
            for char in reversed(word):
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
            node.is_end = True
    
    def query(self, letter: str) -> bool:
        # 添加到队列开头
        self.stream.appendleft(letter)
        
        # 保持队列长度不超过最长单词
        if len(self.stream) > self.max_len:
            self.stream.pop()
        
        # 在 Trie 中查找
        node = self.root
        for char in self.stream:
            if char not in node.children:
                return False
            node = node.children[char]
            if node.is_end:
                return True
        
        return False
```

### 方法三：使用字典简化 Trie

```python
from typing import List

class StreamChecker:
    """
    使用嵌套字典实现 Trie，代码更简洁
    
    时间复杂度:
    - 初始化: O(N*L)
    - query: O(L)
    
    空间复杂度: O(N*L)
    """
    
    def __init__(self, words: List[str]):
        self.trie = {}
        self.stream = []
        self.max_len = max(len(word) for word in words)
        
        # 构建反向 Trie
        for word in words:
            node = self.trie
            for char in reversed(word):
                if char not in node:
                    node[char] = {}
                node = node[char]
            node['#'] = True  # 使用 '#' 标记单词结尾
    
    def query(self, letter: str) -> bool:
        self.stream.insert(0, letter)
        
        # 限制搜索长度
        if len(self.stream) > self.max_len:
            self.stream.pop()
        
        node = self.trie
        for char in self.stream:
            if char not in node:
                return False
            node = node[char]
            if '#' in node:
                return True
        
        return False
```

### 方法四：暴力解法（不推荐，会超时）

```python
from typing import List

class StreamChecker:
    """
    暴力方法：每次查询都检查所有单词
    
    时间复杂度:
    - 初始化: O(N)
    - query: O(N*L)，会超时
    
    空间复杂度: O(M)，M 是 query 调用次数
    """
    
    def __init__(self, words: List[str]):
        self.words = words
        self.stream = ""
    
    def query(self, letter: str) -> bool:
        self.stream += letter
        
        # 检查是否有单词是当前流的后缀
        for word in self.words:
            if self.stream.endswith(word):
                return True
        
        return False
```

## 复杂度分析

| 方法 | 初始化 | Query | 空间 | 说明 |
|------|--------|-------|------|------|
| 反向 Trie | O(N*L) | O(L) | O(N*L) | 最优解，推荐 |
| Deque 优化 | O(N*L) | O(L) | O(N*L) | 限制流的长度 |
| 字典 Trie | O(N*L) | O(L) | O(N*L) | 代码简洁 |
| 暴力解法 | O(N) | O(N*L) | O(M) | 会超时，不推荐 |

其中 N 是单词数量，L 是最长单词的长度，M 是 query 调用次数。

## 关键点总结

1. **反向思维**：将单词反向插入 Trie，后缀匹配转化为前缀匹配
2. **Trie 数据结构**：高效存储和查询字符串集合
3. **搜索深度限制**：只需搜索最长单词的长度，避免不必要的计算
4. **空间优化**：可以限制字符流的长度为最长单词长度
5. **is_end 标记**：在 Trie 节点中标记单词结尾，便于判断匹配

## 易错点

1. **忘记反向**：必须将单词反向插入，否则无法匹配后缀
2. **流的存储方式**：新字符应该插入到流的开头（反向存储）
3. **搜索提前终止**：找到匹配就应该返回 True，不需要继续搜索
4. **内存溢出**：如果不限制流的长度，可能导致内存问题
5. **Trie 结构**：确保正确实现 Trie 的插入和查询逻辑
