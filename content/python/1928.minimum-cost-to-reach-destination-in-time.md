## 题目描述

一个国家有 `n` 个城市，编号 `0` 到 `n-1`，给你一个整数 `maxTime` 和一个数组 `edges`，其中 `edges[i] = [xi, yi, timei]` 表示城市 `xi` 和 `yi` 之间有一条双向道路，通行时间为 `timei` 分钟。

每个城市有一个通行费 `passingFees[i]`。你从城市 `0` 出发，需要在**不超过 `maxTime` 分钟**的情况下到达城市 `n-1`。

路径总费用 = 经过每个城市的通行费之和（含起点和终点，同一城市多次经过只收一次……实际上每次经过都收费）。

返回从城市 `0` 到城市 `n-1` 的**最低总费用**，如果无法在时间限制内到达，返回 `-1`。

**示例 1：**
```
输入：maxTime = 30, edges = [[0,1,10],[1,2,10],[2,5,10],[0,3,1],[3,4,10],[4,5,15]], passingFees = [5,1,2,20,20,3]
输出：11
```

**提示：**
- `1 <= maxTime <= 1000`
- `n == passingFees.length`，`1 <= n <= 1000`

---

## 解题思路

### 核心思想：二维 DP

定义 `dp[t][v]` = 恰好用时 `t` 分钟到达城市 `v` 的最低费用。

转移：对每条边 `(u, v, time)`：
- `dp[t][v] = min(dp[t][v], dp[t-time][u] + passingFees[v])`
- `dp[t][u] = min(dp[t][u], dp[t-time][v] + passingFees[u])`

答案：`min(dp[t][n-1] for t in range(1, maxTime+1))`

## 代码实现

### 方法一：二维 DP（推荐）

```python
from typing import List

class Solution:
    def minCost(self, maxTime: int, edges: List[List[int]], passingFees: List[int]) -> int:
        n = len(passingFees)
        INF = float('inf')

        # dp[t][v] = 恰好用时 t 到达 v 的最低费用
        dp = [[INF] * n for _ in range(maxTime + 1)]
        dp[0][0] = passingFees[0]  # 从城市 0 出发，费用为 passingFees[0]

        for t in range(1, maxTime + 1):
            for u, v, time in edges:
                if time <= t:
                    # 从 u 到 v（使用时间 time）
                    if dp[t - time][u] < INF:
                        dp[t][v] = min(dp[t][v], dp[t - time][u] + passingFees[v])
                    # 从 v 到 u（双向边）
                    if dp[t - time][v] < INF:
                        dp[t][u] = min(dp[t][u], dp[t - time][v] + passingFees[u])

        # 取所有时刻到达 n-1 的最低费用
        ans = min(dp[t][n - 1] for t in range(1, maxTime + 1))
        return ans if ans < INF else -1
```

### 方法二：Dijkstra 变体（状态 = (城市, 已用时间)）

```python
from typing import List
import heapq

class Solution:
    def minCost(self, maxTime: int, edges: List[List[int]], passingFees: List[int]) -> int:
        n = len(passingFees)
        INF = float('inf')

        # 构建邻接表
        graph = [[] for _ in range(n)]
        for u, v, t in edges:
            graph[u].append((v, t))
            graph[v].append((u, t))

        # 状态：(费用, 城市, 已用时间)
        heap = [(passingFees[0], 0, 0)]
        # best[v][t] = 用时 t 到达 v 的最低费用
        best = [[INF] * (maxTime + 1) for _ in range(n)]
        best[0][0] = passingFees[0]

        while heap:
            cost, u, used = heapq.heappop(heap)

            if u == n - 1:
                return cost
            if cost > best[u][used]:
                continue

            for v, t in graph[u]:
                new_time = used + t
                if new_time > maxTime:
                    continue
                new_cost = cost + passingFees[v]
                if new_cost < best[v][new_time]:
                    best[v][new_time] = new_cost
                    heapq.heappush(heap, (new_cost, v, new_time))

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(maxTime * E) | O(maxTime * n) |
| Dijkstra | O(maxTime * E * log(n*maxTime)) | O(n * maxTime) |

---

## 关键点总结

1. 二维状态：城市 + 已用时间，才能正确限制总时间
2. DP 按时间层次递推，避免图中环路问题
3. 答案取所有合法时间到达终点的最小费用

---

## 易错点

- 初始化：`dp[0][0] = passingFees[0]`（从城市 0 出发就要付费）
- 边是双向的，需要同时处理两个方向的转移
