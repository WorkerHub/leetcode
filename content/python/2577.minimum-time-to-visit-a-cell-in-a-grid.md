## 题目描述

给你一个 `m x n` 矩阵 `grid`，其中 `grid[i][j]` 表示到达 `(i, j)` 格子所需的 **最早时间**（必须在 grid[i][j] 时刻或之后才能进入该格子）。

从格子 `(0, 0)` 出发，时刻 `0` 开始，每步花费 1 单位时间，可以向上下左右移动。

返回到达格子 `(m-1, n-1)` 的 **最少时间**；若无法到达，返回 `-1`。

**示例 1：**

```
输入：grid = [[0,1,3,2],[5,1,2,5],[4,3,8,6]]
输出：7
```

**提示：**

- `m == grid.length`, `n == grid[i].length`
- `2 <= m, n <= 1000`
- `0 <= grid[i][j] <= 10^5`
- `grid[0][0] == 0`

## 解题思路

**Dijkstra 算法**：使用最小堆，`(时间, 行, 列)` 作为状态。

到达 `(nr, nc)` 的最早时间：
- 若当前时间 `t + 1 >= grid[nr][nc]`，直接进入，时间 = `t + 1`
- 否则需要等待，但可以通过在两格之间来回移动等待时间。若 `grid[nr][nc] - t` 是奇数，时间 = `grid[nr][nc]`；若是偶数，时间 = `grid[nr][nc] + 1`

**无法到达的条件**：若 `grid[0][1] > 1` 且 `grid[1][0] > 1`（初始无法移动出 (0,0)）。

## Python 代码实现

### 方法一：Dijkstra + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 若无法从 (0,0) 出发
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]  # (时间, 行, 列)
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        while heap:
            t, r, c = heapq.heappop(heap)
            if r == m - 1 and c == n - 1:
                return t
            if t > dist[r][c]:
                continue

            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 到达 (nr, nc) 的时间
                    if t + 1 >= grid[nr][nc]:
                        nt = t + 1
                    else:
                        # 需要等待，可以来回移动
                        wait = grid[nr][nc] - (t + 1)
                        # 若 wait 是奇数，再走 1 步，时间 = grid[nr][nc]
                        # 若 wait 是偶数，再走 1 步，时间 = grid[nr][nc] + 1
                        if wait % 2 == 0:
                            nt = grid[nr][nc] + 1
                        else:
                            nt = grid[nr][nc]
                    if nt < dist[nr][nc]:
                        dist[nr][nc] = nt
                        heapq.heappush(heap, (nt, nr, nc))

        return -1
```

### 方法二：BFS + 等待时间计算

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        INF = float('inf')
        time = [[INF] * n for _ in range(m)]
        time[0][0] = 0
        pq = [(0, 0, 0)]

        while pq:
            t, r, c = heapq.heappop(pq)
            if t > time[r][c]:
                continue
            if r == m-1 and c == n-1:
                return t
            for dr, dc in [(0,1),(1,0),(0,-1),(-1,0)]:
                nr, nc = r+dr, c+dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                diff = grid[nr][nc] - (t + 1)
                if diff <= 0:
                    nt = t + 1
                elif diff % 2 == 0:
                    nt = grid[nr][nc] + 1
                else:
                    nt = grid[nr][nc]
                if nt < time[nr][nc]:
                    time[nr][nc] = nt
                    heapq.heappush(pq, (nt, nr, nc))
        return -1
```

## 复杂度分析

- 时间复杂度：O(m * n * log(m * n))，Dijkstra
- 空间复杂度：O(m * n)

## 关键点总结

1. 等待策略：若 grid[nr][nc] > t+1，可以通过来回移动等待，根据奇偶性计算实际到达时间
2. 无法到达的特殊情况：起点的两个邻居均不可达（grid[0][1] > 1 且 grid[1][0] > 1）
3. Dijkstra 适合有权最短路，确保每个格子只被最优时间更新

## 易错点

1. 等待时间的奇偶判断：`grid[nr][nc] - (t+1)` 是奇数还是偶数
2. 起点特殊情况需要单独处理
3. 弹出时要检查是否过期（t > dist[r][c]）
