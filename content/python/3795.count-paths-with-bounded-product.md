## 题目描述

给定整数数组 `nums` 和整数 `k`，统计乘积不超过 `k` 的连续子数组的数量。

**示例 1：**
```
输入：nums = [10,5,2,6], k = 100
输出：8
解释：乘积 <= 100 的子数组：[10],[5],[2],[6],[10,5],[5,2],[2,6],[5,2,6]，共 8 个。
```

**示例 2：**
```
输入：nums = [1,2,3], k = 0
输出：0
解释：k=0，任何子数组乘积均大于 0（元素均正），故 0 个。
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 10^6`

## 解题思路

**滑动窗口：**

由于所有元素均为正整数，乘积具有单调性：扩大窗口乘积增大，缩小窗口乘积减小。

用双指针维护窗口 `[left, right]`，保持 `product <= k`：
- 每次右移 `right`，乘以 `nums[right]`
- 若乘积 > k，左移 `left` 直到乘积 <= k
- 以 `right` 为右端点的合法子数组数量为 `right - left + 1`

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0

        product = 1
        ans = 0
        left = 0

        for right in range(len(nums)):
            product *= nums[right]
            # 收缩左边界直到乘积 < k
            while product >= k and left <= right:
                product //= nums[left]
                left += 1
            # 以 right 为右端点的合法子数组数：right - left + 1
            ans += right - left + 1

        return ans
```

### 方法二：对数转化 + 前缀和 + 二分

```python
from typing import List
import math
import bisect

class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0

        log_k = math.log(k)
        n = len(nums)

        # 前缀对数和
        prefix = [0.0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + math.log(nums[i])

        ans = 0
        for right in range(1, n + 1):
            # 找最小的 left 使 prefix[right] - prefix[left] < log_k
            # 即 prefix[left] > prefix[right] - log_k
            target = prefix[right] - log_k + 1e-9
            lo = bisect.bisect_left(prefix, target, 0, right)
            ans += right - lo

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n log n)（方法二）
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 所有元素为正整数，乘积具有单调性，适合滑动窗口
2. 以 `right` 为右端点的合法子数组数为 `right - left + 1`
3. `k <= 1` 时直接返回 0（无法满足乘积 < 1）

## 易错点

1. `k = 0` 或 `k = 1` 时需要特判
2. 注意乘积是"小于 k"还是"不超过 k"，题目要求 `<= k`
