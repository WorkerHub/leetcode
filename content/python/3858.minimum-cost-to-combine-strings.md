## 题目描述

给你一个字符串数组 `strs`，你需要通过拼接操作将所有字符串合并为一个字符串。每次操作可以将任意两个字符串拼接，代价为两个字符串长度之和。

返回合并所有字符串的最小总代价。

**示例 1：**

```
输入：strs = ["a", "bc", "def"]
输出：9
解释：
- 拼接 "a" 和 "bc"，代价 3，得 "abc"
- 拼接 "abc" 和 "def"，代价 6，总代价 9
```

**示例 2：**

```
输入：strs = ["ab", "c"]
输出：3
解释：拼接代价 3。
```

**提示：**
- `2 <= strs.length <= 10^5`
- `1 <= strs[i].length <= 10^4`
- 总长度 <= 10^6

## 解题思路

本题等价于**哈夫曼编码**问题：将 n 个字符串合并为一个，每次合并代价为当前两者长度之和，最小总代价。

使用贪心的**最小堆**：每次取最短的两个字符串合并，这样短字符串被合并的次数最多，总代价最小。

## Python 代码实现

### 方法一：最小堆（哈夫曼贪心，推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumCost(self, strs: List[str]) -> int:
        # 将所有字符串的长度加入最小堆
        lengths = [len(s) for s in strs]
        heapq.heapify(lengths)

        total_cost = 0

        while len(lengths) > 1:
            # 取最短的两个
            a = heapq.heappop(lengths)
            b = heapq.heappop(lengths)
            cost = a + b
            total_cost += cost
            heapq.heappush(lengths, cost)

        return total_cost
```

### 方法二：排序模拟（用于理解）

```python
from typing import List

class Solution:
    def minimumCost(self, strs: List[str]) -> int:
        # 模拟哈夫曼编码过程（效率低于堆）
        lengths = sorted(len(s) for s in strs)
        total = 0

        while len(lengths) > 1:
            a, b = lengths[0], lengths[1]
            cost = a + b
            total += cost
            # 将新长度插入有序位置
            import bisect
            lengths = lengths[2:]
            bisect.insort(lengths, cost)

        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作
- 空间复杂度：O(n)，堆

## 关键点总结

1. 最小代价合并问题 = 哈夫曼编码问题。
2. 贪心：每次合并两个最短的字符串，保证短字符串参与合并次数多，长字符串参与次数少。
3. 最小堆可以在 O(log n) 内取出最小值并插入新值。

## 易错点

1. 只需要记录长度，不需要实际拼接字符串。
2. 合并后的长度（a + b）也要加入堆，等待后续合并。
3. 至少有 2 个字符串时才需要合并，否则代价为 0。
