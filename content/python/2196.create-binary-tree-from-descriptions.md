## 题目描述

给你一个二维整数数组 `descriptions`，其中 `descriptions[i] = [parenti, childi, isLefti]` 表示：
- `parenti` 是 `childi` 在**二叉树**中的父节点。
- 如果 `isLefti == 1`，则 `childi` 是 `parenti` 的**左**孩子；否则是**右**孩子。

请你根据描述构造并返回二叉树的根节点。

**示例 1：**
```
输入：descriptions = [[20,15,1],[20,17,0],[50,20,1],[50,80,0],[80,19,1]]
输出：[50,20,80,15,17,19]
```

**提示：**
- `1 <= descriptions.length <= 10^4`
- `descriptions[i].length == 3`
- `1 <= parenti, childi <= 10^5`
- `0 <= isLefti <= 1`
- 生成的二叉树是有效的

## 解题思路

**哈希表建树**

用哈希表存储所有节点（按值索引），遍历描述数组建立父子关系。根节点是所有节点中从未作为"孩子"出现的那一个。

## 代码实现

### 方法一：哈希表建树（推荐）

```python
from typing import Optional, List
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def createBinaryTree(self, descriptions: List[List[int]]) -> Optional[TreeNode]:
        # 节点哈希表
        nodes = {}

        def get_node(val):
            if val not in nodes:
                nodes[val] = TreeNode(val)
            return nodes[val]

        children = set()  # 所有出现过的孩子节点值

        for parent, child, is_left in descriptions:
            p_node = get_node(parent)
            c_node = get_node(child)
            if is_left:
                p_node.left = c_node
            else:
                p_node.right = c_node
            children.add(child)

        # 根节点：出现在 descriptions 中但从未作为孩子
        for parent, child, _ in descriptions:
            if parent not in children:
                return nodes[parent]

        return None
```

### 方法二：集合运算找根

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def createBinaryTree(self, descriptions: List[List[int]]) -> Optional[TreeNode]:
        nodes = {}
        all_children = set()

        for parent, child, is_left in descriptions:
            if parent not in nodes:
                nodes[parent] = TreeNode(parent)
            if child not in nodes:
                nodes[child] = TreeNode(child)
            if is_left:
                nodes[parent].left = nodes[child]
            else:
                nodes[parent].right = nodes[child]
            all_children.add(child)

        # 根节点是所有父节点中，不是任何人孩子的那一个
        all_parents = {p for p, c, _ in descriptions}
        root_val = (all_parents - all_children).pop()
        return nodes[root_val]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(n) |

## 关键点总结

1. 用哈希表按值索引节点，避免重复创建。
2. 根节点是"出现在父节点列表中、但从未作为孩子"的节点。
3. 遍历一遍描述数组即可完成建树。

## 易错点

- 同一个节点可能在多条描述中作为父节点出现，哈希表确保不重复创建。
- 根节点判断：需要找从未出现在 `child` 集合中的父节点。
