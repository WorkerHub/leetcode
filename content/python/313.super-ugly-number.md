## 题目描述

**超级丑数**是一个正整数，其所有质因数都在给定的质数数组 `primes` 中。

给你一个整数 `n` 和一个整数数组 `primes`，返回第 `n` 个**超级丑数**。

题目数据保证第 `n` 个超级丑数在**32-bit**带符号整数范围内。

**示例 1：**
```
输入：n = 12, primes = [2,7,13,19]
输出：32 
解释：给定长度为 4 的质数数组 primes = [2,7,13,19]，前 12 个超级丑数序列为：[1,2,4,7,8,13,14,16,19,26,28,32] 。
```

**示例 2：**
```
输入：n = 1, primes = [2,3,5]
输出：1
解释：1 不含质因数，因此它的所有质因数都在质数数组 primes = [2,3,5] 中。
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= primes.length <= 100`
- `2 <= primes[i] <= 1000`
- 题目数据保证 `primes[i]` 是一个质数
- `primes` 中的所有值互不相同，且按**升序**排列

## 解题思路

这是 264 题（Ugly Number II）的扩展版，质因数从 [2,3,5] 扩展到任意质数数组。

### 核心思想：多路归并

类似于合并 K 个有序链表，我们需要从 K 个"生成序列"中选择最小值。

**K 个生成序列**：
- 第 1 个序列：1×primes[0], 2×primes[0], 4×primes[0], ...
- 第 2 个序列：1×primes[1], 2×primes[1], 4×primes[1], ...
- ...
- 第 K 个序列：1×primes[K-1], 2×primes[K-1], ...

**方法**：
1. **动态规划 + 多指针**：维护 K 个指针，每次选最小值
2. **最小堆**：用堆维护候选值

## Python 代码实现

### 方法一：动态规划 + 多指针（推荐）⭐

```python
from typing import List

class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        # dp[i] 表示第 i 个超级丑数
        dp = [0] * n
        dp[0] = 1
        
        # 为每个质数维护一个指针
        k = len(primes)
        pointers = [0] * k
        
        for i in range(1, n):
            # 计算每个质数对应的候选值
            candidates = [dp[pointers[j]] * primes[j] for j in range(k)]
            
            # 选择最小值作为下一个丑数
            dp[i] = min(candidates)
            
            # 更新指针（可能有多个指针需要前进）
            for j in range(k):
                if candidates[j] == dp[i]:
                    pointers[j] += 1
        
        return dp[n - 1]
```

### 方法二：最小堆

```python
from typing import List
import heapq

class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        # 使用堆维护候选值
        heap = [1]
        seen = {1}
        ugly = 1
        
        for _ in range(n):
            # 取出最小值
            ugly = heapq.heappop(heap)
            
            # 生成新的候选值
            for prime in primes:
                new_ugly = ugly * prime
                if new_ugly not in seen:
                    seen.add(new_ugly)
                    heapq.heappush(heap, new_ugly)
        
        return ugly
```

### 方法三:优化的多指针

```python
from typing import List

class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        dp = [1] * n
        pointers = [0] * len(primes)
        
        for i in range(1, n):
            # 计算候选值
            candidates = [dp[pointers[j]] * primes[j] for j in range(len(primes))]
            
            # 找到最小值
            min_val = min(candidates)
            dp[i] = min_val
            
            # 更新所有等于最小值的指针
            for j in range(len(primes)):
                if candidates[j] == min_val:
                    pointers[j] += 1
        
        return dp[-1]
```

### 方法四：带详细注释的版本

```python
from typing import List

class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        """
        动态规划 + 多指针
        
        思路：
        1. dp[i] 表示第 i 个超级丑数
        2. 每个质数 primes[j] 都有一个指针 pointers[j]
        3. 候选值：dp[pointers[j]] * primes[j]
        4. 选择最小的候选值作为下一个丑数
        5. 更新对应的指针
        """
        # 初始化
        dp = [0] * n
        dp[0] = 1  # 第 1 个丑数是 1
        
        k = len(primes)
        pointers = [0] * k  # 每个质数的指针
        
        # 生成第 2 到第 n 个丑数
        for i in range(1, n):
            # 计算每个质数的候选值
            # candidates[j] = dp[pointers[j]] * primes[j]
            candidates = []
            for j in range(k):
                candidates.append(dp[pointers[j]] * primes[j])
            
            # 选择最小值
            min_val = min(candidates)
            dp[i] = min_val
            
            # 更新指针
            # 注意：可能有多个候选值等于最小值，都要更新
            for j in range(k):
                if candidates[j] == min_val:
                    pointers[j] += 1
        
        return dp[n - 1]
```

## 复杂度分析

**方法一（多指针）：**
- 时间复杂度：O(n × k)，其中 k 是 primes 的长度
- 空间复杂度：O(n + k)

**方法二（最小堆）：**
- 时间复杂度：O(n × k × log(n×k))
- 空间复杂度：O(n × k)

## 关键点总结

1. **多路归并**：类似合并 K 个有序链表
2. **多指针**：为每个质数维护一个指针
3. **去重**：可能有多个质数生成相同的丑数，都要更新指针
4. **初始值**：第 1 个丑数是 1
5. **选择最小值**：每次从 K 个候选值中选最小的

## 易错点

1. **指针更新**：所有等于最小值的指针都要更新，不是只更新一个
2. **初始化**：`dp[0] = 1`，`pointers` 全为 0
3. **边界情况**：`n = 1` 时直接返回 1
4. **溢出**：虽然题目保证不溢出，但实际计算时要注意
