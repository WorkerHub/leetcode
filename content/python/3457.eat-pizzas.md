## 题目描述

给你一个整数数组 `pizzas`，表示每块披萨的重量（克）。你每天吃一块披萨，共 n 天。

规则：
- 奇数天（1, 3, 5, ...）吃的披萨**完整计入**体重
- 偶数天（2, 4, 6, ...）吃的披萨**只计入一半**体重

你可以任意安排吃披萨的顺序，求最大总体重增加量。

**示例 1：**

```
输入：pizzas = [9,8,3,5,5]
输出：28
解释：一种最优方案：奇数天吃 9,8,5，偶数天吃 5,3
体重增加 = 9 + 8 + 5 + 5/2 + 3/2 = 22 + 4 = 26... 重新计算
实际：5 天，奇数天 1,3,5（3天），偶数天 2,4（2天）
最优：奇数天吃最重的 3 块：9,8,5；偶数天吃最重的 2 块各取一半：5+3
= 9+8+5 + ceil(5/2) + ceil(3/2) = 22 + 3 + 2 = 27... 
```

**提示：**
- `1 <= pizzas.length <= 10^5`
- `1 <= pizzas[i] <= 10^5`
- `pizzas.length` 为偶数（每 4 天一个循环）

## 解题思路

贪心：要最大化总体重增加，奇数天应吃最重的披萨，偶数天吃次重的（只计一半）。

设 n = len(pizzas)，奇数天 = ceil(n/2)，偶数天 = floor(n/2)。

对排序后的 pizzas（降序）：
- 前 ceil(n/2) 块完整计入（奇数天）
- 后 floor(n/2) 块只计一半（偶数天，取最重的一半）

等等，偶数天的披萨要选哪些？贪心：偶数天选最重的剩余披萨，这样一半也是最大的。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List
import math

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort(reverse=True)

        # 奇数天的天数（计入完整重量）
        odd_days = math.ceil(n / 2)
        # 偶数天的天数（计入一半重量）
        even_days = n // 2

        # 贪心：奇数天吃最重的 odd_days 块
        # 偶数天吃接下来最重的 even_days 块（各取一半）
        total = 0

        for i in range(odd_days):
            total += pizzas[i]

        for i in range(odd_days, odd_days + even_days):
            total += pizzas[i] // 2

        return total
```

### 方法二：考虑偶数天只计一半的最优策略

```python
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort()

        # n 天：奇数天 ceil(n/2)，偶数天 floor(n/2)
        # 奇数天选最大的 ceil(n/2) 块
        # 偶数天从剩余中选最大的 floor(n/2) 块（各取一半）

        odd_days = (n + 1) // 2
        even_days = n // 2

        total = 0

        # 奇数天：从大到小选 odd_days 块
        # 偶数天：从剩余的大到小选 even_days 块，取一半

        # 所有块从大到小排列：pizzas[n-1], pizzas[n-2], ...
        # 奇数天：pizzas[n-1..n-odd_days]（完整）
        # 偶数天：pizzas[n-odd_days-1..n-odd_days-even_days]（取一半）

        for i in range(n - 1, n - 1 - odd_days, -1):
            total += pizzas[i]

        for i in range(n - 1 - odd_days, n - 1 - odd_days - even_days, -1):
            total += pizzas[i] // 2

        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 奇数天完整计入，偶数天只计一半——奇数天应吃最重的
2. n 天：奇数天 ceil(n/2)，偶数天 floor(n/2)
3. 贪心：先分配最重的给奇数天，剩余给偶数天

## 易错点

1. 奇数天和偶数天的划分：n 天中奇数天 ceil(n/2)，偶数天 floor(n/2)
2. 整数除以 2 用 `//`（向下取整），不是四舍五入
3. 偶数天的披萨也应选剩余中最重的（而不是最轻的）
