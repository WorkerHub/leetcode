## 题目描述

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

**示例 1：**
```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

**示例 2：**
```
输入：lists = []
输出：[]
```

**示例 3：**
```
输入：lists = [[]]
输出：[]
```

**提示：**
- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按升序排列
- `lists[i].length` 的总和不超过 `10^4`

## 解题思路

这道题是合并两个有序链表的升级版，有多种解法：

**方法对比：**
1. **暴力法**：收集所有节点，排序后重建链表
2. **逐一合并**：依次合并两个链表
3. **分治法**：类似归并排序（推荐）
4. **优先队列（堆）**：每次取最小的节点

## Python 代码实现

### 方法一：分治法（推荐）

```python
from typing import List, Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        if not lists:
            return None
        
        # 分治合并
        return self.merge(lists, 0, len(lists) - 1)
    
    def merge(self, lists: List[Optional[ListNode]], left: int, right: int) -> Optional[ListNode]:
        # 只有一个链表
        if left == right:
            return lists[left]
        
        # 分治
        mid = (left + right) // 2
        l1 = self.merge(lists, left, mid)
        l2 = self.merge(lists, mid + 1, right)
        
        # 合并两个有序链表
        return self.mergeTwoLists(l1, l2)
    
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        current = dummy
        
        while l1 and l2:
            if l1.val < l2.val:
                current.next = l1
                l1 = l1.next
            else:
                current.next = l2
                l2 = l2.next
            current = current.next
        
        current.next = l1 if l1 else l2
        return dummy.next
```

### 方法二：优先队列（堆）

```python
import heapq
from typing import List, Optional

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        # Python 的 heapq 不能直接比较 ListNode
        # 需要使用元组 (val, index, node)
        heap = []
        
        # 将所有链表的头节点加入堆
        for i, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, i, node))
        
        dummy = ListNode(0)
        current = dummy
        
        while heap:
            # 取出最小的节点
            val, i, node = heapq.heappop(heap)
            current.next = node
            current = current.next
            
            # 如果该链表还有下一个节点，加入堆
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        
        return dummy.next
```

### 方法三：逐一合并

```python
from typing import List, Optional

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        if not lists:
            return None
        
        result = None
        for lst in lists:
            result = self.mergeTwoLists(result, lst)
        
        return result
    
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        current = dummy
        
        while l1 and l2:
            if l1.val < l2.val:
                current.next = l1
                l1 = l1.next
            else:
                current.next = l2
                l2 = l2.next
            current = current.next
        
        current.next = l1 if l1 else l2
        return dummy.next
```

## 复杂度分析

设 k 为链表数量，n 为所有节点总数。

**方法一（分治法）：**
- 时间复杂度：O(n log k)
  - 分治的深度为 log k
  - 每层合并的总节点数为 n
- 空间复杂度：O(log k)，递归调用栈

**方法二（堆）：**
- 时间复杂度：O(n log k)
  - 每个节点进出堆一次，堆操作为 O(log k)
- 空间复杂度：O(k)，堆的大小

**方法三（逐一合并）：**
- 时间复杂度：O(kn)
  - 第一次合并：n1 + n2
  - 第二次合并：(n1 + n2) + n3
  - ...
  - 总计约 O(kn)
- 空间复杂度：O(1)

## 关键点总结

1. **分治思想**：将 k 个链表分成两半，递归合并
2. **堆的应用**：维护 k 个链表的当前最小值
3. **合并两链表**：基础操作，需要熟练掌握
4. **索引技巧**：堆中使用索引避免节点比较问题

## 易错点

1. **空链表处理**：
   - 空数组 `lists = []`
   - 包含空链表 `lists = [[]]`
2. **堆的比较问题**：Python 的 ListNode 无法直接比较，需要用元组
3. **分治边界**：`left == right` 时返回单个链表
4. **索引越界**：处理边界条件时要小心
