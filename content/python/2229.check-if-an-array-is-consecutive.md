## 题目描述

给你一个整数数组 `nums`，如果 `nums` 是**连续数组**则返回 `true`，否则返回 `false`。

**连续数组**：包含从 `min(nums)` 到 `max(nums)` 的所有整数，且每个整数恰好出现一次。

**示例 1：**
```
输入：nums = [1,3,4,2,5]
输出：true
```

**示例 2：**
```
输入：nums = [1,3,4,2,6]
输出：false
```

**示例 3：**
```
输入：nums = [1,1,1,1,1]
输出：false
```

## 解题思路

连续数组的条件：
1. 无重复元素（用集合判断）。
2. `max - min == n - 1`（范围恰好覆盖 n 个整数）。

两个条件同时满足即为连续数组。

## 代码实现

### 方法一：集合 + 范围检查（推荐）

```python
from typing import List

class Solution:
    def isConsecutive(self, nums: List[int]) -> bool:
        n = len(nums)
        # 条件1：无重复（集合大小等于数组大小）
        # 条件2：最大值 - 最小值 == n - 1
        return len(set(nums)) == n and max(nums) - min(nums) == n - 1
```

### 方法二：排序后比较

```python
from typing import List

class Solution:
    def isConsecutive(self, nums: List[int]) -> bool:
        nums.sort()
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1] + 1:
                return False
        return True
```

### 方法三：使用 Counter 检查

```python
from typing import List
from collections import Counter

class Solution:
    def isConsecutive(self, nums: List[int]) -> bool:
        cnt = Counter(nums)
        # 所有值出现次数为1，且范围连续
        if any(v > 1 for v in cnt.values()):
            return False
        return max(nums) - min(nums) == len(nums) - 1
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，创建集合和求最大最小值。
- 空间复杂度：O(n)，集合存储。

**方法二：**
- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(1)（原地排序）。

## 关键点总结

1. 连续数组的两个等价条件：无重复 且 max - min = n - 1。
2. 方法一最简洁高效，一行解决。
3. 方法二排序后逐一比较，适合初学者理解。

## 易错点

- 必须同时满足两个条件：仅 `max - min == n - 1` 还不够（可能有重复）。
- 仅无重复也不够（元素不连续）。
