## 题目描述

实验室有两个传感器 `sensor1` 和 `sensor2`，通常情况下它们产生相同的读数。但其中一个传感器在某一时刻出现故障，故障的表现为：跳过一个数据点，导致之后的数据向前移动了一位。

给你两个长度为 `n` 的整数数组 `sensor1` 和 `sensor2`，判断哪个传感器有故障（返回 1 或 2），若无法确定（即两个传感器的数据可以都对），则返回 -1。

**示例 1：**
```
输入：sensor1 = [2,3,4,5], sensor2 = [2,1,3,4]
输出：1
解释：传感器1跳过了第一个1，导致后面数据前移
```

**示例 2：**
```
输入：sensor1 = [2,2,2,2,2], sensor2 = [2,2,2,2,5]
输出：-1
```

## 解题思路

用双指针扫描：找到第一个不同的位置 `i`，此后：
- 若 `sensor1[i:]` 与 `sensor2[i+1:]` 相等，说明 sensor1 出错（多了一个错误值）
- 若 `sensor2[i:]` 与 `sensor1[i+1:]` 相等，说明 sensor2 出错
- 若两者都满足（或都不满足），返回 -1

## 代码实现

### 方法一：找第一个差异点 + 比较（推荐）

```python
from typing import List

class Solution:
    def badSensor(self, sensor1: List[int], sensor2: List[int]) -> int:
        n = len(sensor1)
        # 找到第一个不同的位置
        i = 0
        while i < n and sensor1[i] == sensor2[i]:
            i += 1

        if i == n:
            return -1  # 完全相同，无法判断

        # 检查从 i 开始，哪个传感器后续匹配
        # 若 sensor1 跳过了一个值：sensor1[i+1:] == sensor2[i:]
        s1_fault = sensor1[i+1:] == sensor2[i:n-1]
        # 若 sensor2 跳过了一个值：sensor2[i+1:] == sensor1[i:]
        s2_fault = sensor2[i+1:] == sensor1[i:n-1]

        if s1_fault and not s2_fault:
            return 1
        if s2_fault and not s1_fault:
            return 2
        return -1
```

### 方法二：双指针逐步比较

```python
from typing import List

class Solution:
    def badSensor(self, sensor1: List[int], sensor2: List[int]) -> int:
        n = len(sensor1)
        i = 0
        # 找到第一个不同位置
        while i < n - 1 and sensor1[i] == sensor2[i]:
            i += 1

        if sensor1[i] == sensor2[i]:
            return -1

        # 偏移一位比较
        j = i + 1
        s1_ok = True  # sensor1 跳过一个，后续是否匹配
        s2_ok = True  # sensor2 跳过一个，后续是否匹配
        while j < n:
            if sensor1[j] != sensor2[j - 1]:
                s1_ok = False
            if sensor2[j] != sensor1[j - 1]:
                s2_ok = False
            j += 1

        if s1_ok and not s2_ok:
            return 1
        if s2_ok and not s1_ok:
            return 2
        return -1
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)（切片），方法二为 O(1)

## 关键点总结

1. 找到第一个差异点，之后比较偏移一位的后缀是否匹配
2. 若两种情况都满足（全相同尾部），返回 -1

## 易错点

- 切片比较简洁但创建了额外空间；双指针版本更节省空间
- 当 i 为最后一个位置时，偏移比较为空数组，视为匹配
