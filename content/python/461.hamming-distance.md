## 题目描述

两个整数之间的汉明距离指的是这两个数字对应二进制位不同的位置的数目。

给你两个整数 `x` 和 `y`，计算并返回它们之间的汉明距离。

**示例 1：**
```
输入：x = 1, y = 4
输出：2
解释：
1   (0 0 0 1)
4   (0 1 0 0)
       ↑   ↑
上面的箭头指出了对应二进制位不同的位置。
```

**示例 2：**
```
输入：x = 3, y = 1
输出：1
```

**提示：**
- `0 <= x, y <= 2^31 - 1`

## 解题思路

汉明距离的核心思想是统计两个数二进制表示中不同位的个数。

**核心观察：**
1. 两个数异或（XOR）运算后，结果中为 1 的位就是不同的位
2. 问题转化为统计异或结果中 1 的个数

**算法流程：**
1. 对 x 和 y 进行异或运算：`xor_result = x ^ y`
2. 统计 xor_result 中 1 的个数

**为什么异或可以找出不同的位？**
- `0 ^ 0 = 0`（相同）
- `1 ^ 1 = 0`（相同）
- `0 ^ 1 = 1`（不同）
- `1 ^ 0 = 1`（不同）

## Python 代码实现

### 方法一：内置函数 bin().count() （推荐）⭐

```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        # 异或运算找出不同的位
        xor_result = x ^ y
        
        # 转为二进制字符串，统计 '1' 的个数
        return bin(xor_result).count('1')
```

**优点：** 代码简洁，Python 特色解法

### 方法二：Brian Kernighan 算法

```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        xor_result = x ^ y
        count = 0
        
        # Brian Kernighan 算法：每次消除最右边的 1
        while xor_result:
            xor_result &= xor_result - 1  # 清除最右边的 1
            count += 1
        
        return count
```

**核心技巧：** `n & (n - 1)` 可以消除 n 最右边的 1
- 例如：`n = 12 (1100)`，`n - 1 = 11 (1011)`，`n & (n - 1) = 8 (1000)`

### 方法三：逐位比较

```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        count = 0
        
        # 逐位比较，直到两个数都为 0
        while x or y:
            # 比较最低位
            if (x & 1) != (y & 1):
                count += 1
            # 右移一位
            x >>= 1
            y >>= 1
        
        return count
```

### 方法四：使用 bit_count() (Python 3.10+)

```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        # Python 3.10+ 提供的内置方法
        return (x ^ y).bit_count()
```

**最简洁：** Python 3.10+ 推荐使用此方法

## 复杂度分析

**方法一（bin().count()）：**
- 时间复杂度：O(log n)，n 是较大的数，需要转换为二进制字符串
- 空间复杂度：O(log n)，存储二进制字符串

**方法二（Brian Kernighan）：**
- 时间复杂度：O(k)，k 是二进制中 1 的个数（最优）
- 空间复杂度：O(1)

**方法三（逐位比较）：**
- 时间复杂度：O(log n)，n 是较大的数
- 空间复杂度：O(1)

**方法四（bit_count()）：**
- 时间复杂度：O(1)，底层硬件优化
- 空间复杂度：O(1)

## 关键点总结

1. **异或运算是核心：** `x ^ y` 直接标记出不同的位
2. **多种统计方法：** 
   - Python 特色：`bin().count('1')` 或 `bit_count()`
   - 算法优化：Brian Kernighan 算法
3. **位运算技巧：** `n & (n - 1)` 消除最右边的 1
4. **时间优化：** Brian Kernighan 算法复杂度与 1 的个数相关，而非总位数
5. **Python 版本：** 3.10+ 可用 `bit_count()`，性能最佳

## 易错点

1. **忘记异或运算：** 直接比较两个数而不是异或结果
   ```python
   # 错误
   bin(x).count('1') + bin(y).count('1')
   
   # 正确
   bin(x ^ y).count('1')
   ```

2. **误用 bin() 的返回格式：** `bin(5)` 返回 `'0b101'`（带前缀）
   ```python
   # 正确：count('1') 只统计 '1' 字符，不受 '0b' 影响
   bin(x ^ y).count('1')
   ```

3. **位运算优先级：** 比较运算符优先级高于位运算
   ```python
   # 错误（需要加括号）
   if x & 1 != y & 1:  # 等价于 x & (1 != y) & 1
   
   # 正确
   if (x & 1) != (y & 1):
   ```

4. **边界情况：** x 或 y 为 0 时也要正确处理
   ```python
   # x = 0, y = 0 时，汉明距离为 0
   # x = 0, y = 5 时，汉明距离等于 5 的二进制中 1 的个数
   ```
