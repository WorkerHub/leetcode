## 题目描述

存在一个无向图，图中有 `n` 个节点。其中每个节点都有一个介于 `0` 到 `n - 1` 之间的唯一编号。

给定一个二维数组 `graph`，表示图，其中 `graph[u]` 是一个节点数组，由节点 `u` 的邻接节点组成。

如果图是二分图，返回 `true`；否则，返回 `false`。

**二分图定义**：如果能将一个图的节点集合分割成两个独立的子集 A 和 B，并使图中的每一条边的两个节点一个来自 A 集合，一个来自 B 集合，则称该图为二分图。

**示例 1：**
```
输入：graph = [[1,2,3],[0,2],[0,1,3],[0,2]]
输出：false
解释：不能将节点分割成两个独立的子集，以使每条边都连接一个来自 A 的节点和一个来自 B 的节点。
```

**示例 2：**
```
输入：graph = [[1,3],[0,2],[1,3],[0,2]]
输出：true
解释：可以将节点分割成两个子集：{0, 2} 和 {1, 3}。
```

**提示：**
- graph.length == n
- 1 <= n <= 100
- 0 <= graph[u].length < n
- 0 <= graph[u][i] <= n - 1
- graph[u] 不会包含 u
- graph[u] 的所有值互不相同
- 如果 graph[u] 包含 v，那么 graph[v] 也会包含 u

## 解题思路

二分图的本质是**图染色问题**：能否用两种颜色给所有节点染色，使得相邻节点颜色不同？

**核心观察：**
1. 二分图等价于**没有奇数环**的图
2. 可以用**0和1**（或两种颜色）标记两个子集
3. 如果能成功染色，就是二分图

**解题步骤：**
1. 遍历所有节点（图可能不连通）
2. 对每个未染色的节点，用DFS/BFS进行染色
3. 给当前节点染色color，给所有邻居染色1-color
4. 如果发现冲突（相邻节点同色），返回false

**三种方法：**
- **DFS染色法**：递归染色
- **BFS染色法**：队列染色
- **并查集**：将"应该在同一组"的节点合并

## Python 代码实现

### 方法一：DFS 染色法（推荐）

```python
from typing import List

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        # 用0表示未染色，1和-1表示两种颜色
        color = [0] * n
        
        def dfs(node: int, c: int) -> bool:
            color[node] = c
            # 遍历所有邻居
            for neighbor in graph[node]:
                if color[neighbor] == c:
                    # 邻居已经是相同颜色，冲突
                    return False
                if color[neighbor] == 0:
                    # 邻居未染色，染成相反颜色
                    if not dfs(neighbor, -c):
                        return False
            return True
        
        # 遍历所有节点（图可能不连通）
        for i in range(n):
            if color[i] == 0:  # 未染色
                if not dfs(i, 1):
                    return False
        
        return True
```

### 方法二：BFS 染色法

```python
from typing import List
from collections import deque

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        color = [0] * n
        
        for start in range(n):
            if color[start] != 0:
                continue
            
            # BFS染色
            queue = deque([start])
            color[start] = 1
            
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if color[neighbor] == 0:
                        # 未染色，染成相反颜色
                        color[neighbor] = -color[node]
                        queue.append(neighbor)
                    elif color[neighbor] == color[node]:
                        # 冲突
                        return False
        
        return True
```

### 方法三：并查集（进阶）

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        root_x, root_y = self.find(x), self.find(y)
        if root_x != root_y:
            self.parent[root_x] = root_y
    
    def is_connected(self, x, y):
        return self.find(x) == self.find(y)

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        uf = UnionFind(n)
        
        for node in range(n):
            neighbors = graph[node]
            if not neighbors:
                continue
            
            # 检查node和第一个邻居是否在同一集合
            if uf.is_connected(node, neighbors[0]):
                return False
            
            # 将所有邻居合并到一个集合（因为它们应该同色）
            for i in range(1, len(neighbors)):
                if uf.is_connected(node, neighbors[i]):
                    return False
                uf.union(neighbors[0], neighbors[i])
        
        return True
```

## 复杂度分析

设节点数为 n，边数为 m。

**DFS/BFS方法：**
- **时间复杂度：** O(n + m)，每个节点和边各访问一次
- **空间复杂度：** O(n)，存储颜色数组和递归栈/队列

**并查集方法：**
- **时间复杂度：** O(n + m × α(n))，α为阿克曼函数的反函数，近似O(1)
- **空间复杂度：** O(n)

## 关键点总结

1. **二分图 = 无奇数环**：可以用两种颜色染色且相邻不同色
2. **染色策略**：给节点染色color，邻居染色-color（或1-color）
3. **处理不连通图**：必须遍历所有节点，不能只从0开始
4. **冲突检测**：如果邻居已染色且颜色相同，立即返回false
5. **并查集思路**：一个节点的所有邻居应该在同一个集合（同色）

## 易错点

1. **忘记处理不连通图**：图可能有多个连通分量，需要遍历所有节点
2. **颜色初始化**：用0表示未染色，1和-1表示两种颜色
3. **DFS返回值**：要正确传递false，不能忽略递归返回值
4. **并查集逻辑**：邻居之间要合并（同色），而不是节点和邻居合并
