## 题目描述

给你一个字符串数组 `message` 和一个字符串数组 `bannedWords`。

如果一条消息中包含**至少两个** bannedWords 中的单词，则该消息被视为垃圾邮件（spam）。

如果消息是垃圾邮件，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：message = ["hello","world","leetcode"], bannedWords = ["world","hello"]
输出：true
解释：message 中包含 "hello" 和 "world"，均在 bannedWords 中，共 2 个，返回 true
```

**示例 2：**
```
输入：message = ["hello","programming","fun"], bannedWords = ["world","programming"]
输出：false
解释：只有 "programming" 在 bannedWords 中，不足 2 个
```

**提示：**
- `1 <= message.length <= 10^3`
- `1 <= bannedWords.length <= 10^3`
- `1 <= message[i].length, bannedWords[i].length <= 15`
- `message[i]` 和 `bannedWords[i]` 只含小写字母

## 解题思路

将 bannedWords 转为集合，遍历 message 中的每个单词，统计在 bannedWords 中出现的数量，若 >= 2 返回 true。

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def reportSpam(self, message: List[str], bannedWords: List[str]) -> bool:
        banned_set = set(bannedWords)
        count = sum(1 for word in message if word in banned_set)
        return count >= 2
```

### 方法二：早退优化

```python
from typing import List

class Solution:
    def reportSpam(self, message: List[str], bannedWords: List[str]) -> bool:
        banned_set = set(bannedWords)
        count = 0
        for word in message:
            if word in banned_set:
                count += 1
                if count >= 2:
                    return True
        return False
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为 message 长度，m 为 bannedWords 长度
- 空间复杂度：O(m)，哈希集合

## 关键点总结

1. 将 bannedWords 转为 set，查询 O(1)
2. 统计 message 中被封禁单词的数量，>= 2 即为垃圾邮件
3. 方法二提前退出，遇到第 2 个就返回

## 易错点

1. 条件是"至少 2 个"，不是恰好 2 个
2. bannedWords 可能有重复，但 message 中统计时不需要去重
