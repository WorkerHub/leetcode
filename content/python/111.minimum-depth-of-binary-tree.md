## 题目描述

给定一个二叉树，找出其最小深度。

最小深度是从根节点到最近叶子节点的最短路径上的节点数量。

**说明**：叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：2
```

**示例 2：**

```
输入：root = [2,null,3,null,4,null,5,null,6]
输出：5
```

**提示：**

- 树中节点数的范围在 `[0, 10^5]` 内
- `-1000 <= Node.val <= 1000`

## 解题思路

这道题容易和求最大深度混淆，关键区别在于**必须是叶子节点**。

### 核心要点

**叶子节点的定义**：左右子节点都为空的节点

**陷阱案例**：
```
    1
   /
  2
```
最小深度是 2，而不是 1！因为节点 1 不是叶子节点。

### 解题方法

**方法一：BFS（广度优先搜索）- 推荐**
- 层序遍历，遇到第一个叶子节点即可返回
- 因为是层序遍历，第一个叶子节点一定在最浅的层
- 时间复杂度：O(n)，但通常会提前结束

**方法二：DFS（深度优先搜索）**
- 递归计算左右子树的最小深度
- 注意处理只有左子树或只有右子树的情况
- 时间复杂度：O(n)，必须遍历所有节点

## Python 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```python
from typing import Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        # 边界情况：空树
        if not root:
            return 0
        
        # BFS 层序遍历
        queue = deque([(root, 1)])  # (节点, 深度)
        
        while queue:
            node, depth = queue.popleft()
            
            # 找到第一个叶子节点，立即返回
            if not node.left and not node.right:
                return depth
            
            # 将子节点加入队列
            if node.left:
                queue.append((node.left, depth + 1))
            if node.right:
                queue.append((node.right, depth + 1))
        
        return 0  # 理论上不会到达这里
```

### 方法二：BFS 层序遍历（标准模板）

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        queue = deque([root])
        depth = 1
        
        while queue:
            # 遍历当前层的所有节点
            level_size = len(queue)
            
            for _ in range(level_size):
                node = queue.popleft()
                
                # 找到叶子节点，返回当前深度
                if not node.left and not node.right:
                    return depth
                
                # 将下一层节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 当前层遍历完，深度 +1
            depth += 1
        
        return depth
```

### 方法三：DFS 递归（需要注意边界）⭐

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        # 边界情况：空树
        if not root:
            return 0
        
        # 情况 1：叶子节点
        if not root.left and not root.right:
            return 1
        
        # 情况 2：只有左子树
        if not root.right:
            return self.minDepth(root.left) + 1
        
        # 情况 3：只有右子树
        if not root.left:
            return self.minDepth(root.right) + 1
        
        # 情况 4：左右子树都存在
        return min(self.minDepth(root.left), self.minDepth(root.right)) + 1
```

### 方法四：DFS 递归（简化版）

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        # 计算左右子树的最小深度
        left_depth = self.minDepth(root.left)
        right_depth = self.minDepth(root.right)
        
        # 如果左右子树有一个为空，返回非空子树的深度 + 1
        # 如果都不为空，返回较小的深度 + 1
        if not root.left or not root.right:
            return left_depth + right_depth + 1
        
        return min(left_depth, right_depth) + 1
```

### 方法五：DFS 迭代（使用栈）

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        stack = [(root, 1)]
        min_depth = float('inf')
        
        while stack:
            node, depth = stack.pop()
            
            # 叶子节点，更新最小深度
            if not node.left and not node.right:
                min_depth = min(min_depth, depth)
                continue
            
            # 将子节点入栈
            if node.left:
                stack.append((node.left, depth + 1))
            if node.right:
                stack.append((node.right, depth + 1))
        
        return min_depth
```

## 复杂度分析

### 方法一、二（BFS）

- **时间复杂度**：O(n)，最坏情况下需要遍历所有节点，但通常会提前结束
- **空间复杂度**：O(w)，其中 w 是树的最大宽度（队列中最多的节点数）

### 方法三、四（DFS 递归）

- **时间复杂度**：O(n)，需要遍历所有节点
- **空间复杂度**：O(h)，其中 h 是树的高度（递归调用栈）

### 方法五（DFS 迭代）

- **时间复杂度**：O(n)，需要遍历所有节点
- **空间复杂度**：O(h)，栈的空间

## 图解示例

### 示例 1：

```
      3
     / \
    9   20
       /  \
      15   7

BFS 层序遍历：
第 1 层：3 （不是叶子）
第 2 层：9, 20 （9 是叶子！返回 2）

DFS 递归：
minDepth(3):
  minDepth(9) = 1 （叶子节点）
  minDepth(20):
    minDepth(15) = 1
    minDepth(7) = 1
    return min(1, 1) + 1 = 2
  return min(1, 2) + 1 = 2
```

### 示例 2（陷阱）：

```
    2
     \
      3
       \
        4
         \
          5
           \
            6

错误思路：min(0, minDepth(3)) + 1 = 1 ✗
正确思路：只有右子树，返回 minDepth(3) + 1

层层递归：
minDepth(2) = minDepth(3) + 1
            = (minDepth(4) + 1) + 1
            = ((minDepth(5) + 1) + 1) + 1
            = (((minDepth(6) + 1) + 1) + 1) + 1
            = ((((1) + 1) + 1) + 1) + 1
            = 5
```

## 关键点总结

1. **叶子节点定义**：左右子节点都为空，这是关键
2. **BFS 优势**：可以在遇到第一个叶子节点时立即返回，不需要遍历整棵树
3. **DFS 陷阱**：不能简单地取 min(左深度, 右深度)，要处理单子树的情况
4. **边界处理**：
   - 空树返回 0
   - 叶子节点返回 1
   - 只有一个子树时，不能取 min(0, 子树深度)
5. **性能对比**：BFS 通常更快，因为可能提前结束

## 易错点

1. **忘记叶子节点定义**：
   ```python
   # 错误：直接取 min
   return min(left_depth, right_depth) + 1
   
   # 正确：要处理单子树的情况
   if not root.left or not root.right:
       return left_depth + right_depth + 1
   ```

2. **空节点深度**：空节点深度为 0，但不是叶子节点

3. **单子树情况**：
   ```
       1
      /
     2
   ```
   最小深度是 2，不是 1（因为 1 不是叶子）

4. **BFS 判断条件**：要判断 `not node.left and not node.right`，不能只判断一个

5. **与最大深度混淆**：
   - 最大深度：可以直接 `max(left, right) + 1`
   - 最小深度：要考虑叶子节点的定义
