## 题目描述

给你一个产品数组 `products` 和一个搜索词 `searchWord`。

设计一个搜索推荐系统，在依次输入 `searchWord` 的每个字符后，推荐 `products` 中最多三个产品名称。推荐的产品必须满足：
- 是 `searchWord` 当前输入前缀的**完整匹配**（即产品名包含当前输入字符串作为前缀）
- 如果匹配的产品超过三个，返回**字典序最小**的三个

**示例 1：**
```
输入：products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"
输出：
[
  ["mobile","moneypot","monitor"],
  ["mobile","moneypot","monitor"],
  ["mouse","mousepad"],
  ["mouse","mousepad"],
  ["mouse","mousepad"]
]
解释：
  输入 "m"：所有产品都以 "m" 开头 → 取字典序前三
  输入 "mo"：同上
  输入 "mou"：只有 "mouse", "mousepad" 匹配
  输入 "mous"：同上
  输入 "mouse"：同上
```

**示例 2：**
```
输入：products = ["havana"], searchWord = "havana"
输出：[["havana"],["havana"],["havana"],["havana"],["havana"],["havana"]]
```

**示例 3：**
```
输入：products = ["bags","baggage","banner","box","cloths"], searchWord = "bags"
输出：[["baggage","bags","banner"],["baggage","bags","banner"],["baggage","bags"],["bags"]]
```

**提示：**
- `1 <= products.length <= 1000`
- `1 <= products[i].length <= 3 * 10^4`
- `products[i]` 只含小写英文字母
- `products` 中没有重复元素
- `1 <= searchWord.length <= 1000`

---

## 解题思路

本题要求在每次输入前缀后，找到所有匹配该前缀的产品中字典序最小的三个。

**三种主要思路：**

1. **排序 + 二分查找**：先对 products 排序，再对每个前缀用二分查找定位起始位置，取接下来最多 3 个匹配的产品。
2. **排序 + 逐步过滤**：先排序，然后对每次新增字符逐步过滤掉不匹配的产品。
3. **字典树（Trie）**：构建字典树，每个节点存储经过该节点的产品（按字典序的前三个），实现高效的前缀查询。

## Python 代码实现

### 方法一：排序 + 二分查找（推荐）

**思路：**
- 先将 products 排序
- 对于前缀 prefix，在排序后的数组中，用 `bisect_left` 找到第一个 `>= prefix` 的位置
- 从该位置起，取最多 3 个有该前缀的产品

```python
from typing import List
import bisect

class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        # 先对产品列表排序，使字典序最小的排在前面
        products.sort()
        result = []

        for i in range(1, len(searchWord) + 1):
            prefix = searchWord[:i]  # 当前输入的前缀
            suggestions = []

            # 用二分查找找到第一个 >= prefix 的位置
            pos = bisect.bisect_left(products, prefix)

            # 从 pos 开始，取最多 3 个有该前缀的产品
            for j in range(pos, min(pos + 3, len(products))):
                # 检查该产品是否以 prefix 开头
                if products[j].startswith(prefix):
                    suggestions.append(products[j])
                else:
                    # 由于已排序，不匹配后面也不会匹配，直接停止
                    break

            result.append(suggestions)

        return result
```

**二分查找的作用：**
```
排序后：["mobile","moneypot","monitor","mouse","mousepad"]
prefix = "mo"
bisect_left 找到第一个 >= "mo" 的位置 = 0（"mobile" >= "mo"）
从 0 开始取：mobile, moneypot, monitor（都以 "mo" 开头）
```

### 方法二：排序 + 逐步过滤（简洁版）

**思路：** 每次在上一轮结果的基础上，过滤掉不含新前缀的产品。

```python
from typing import List

class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        # 先对产品列表排序
        products.sort()
        result = []
        prefix = ""

        for char in searchWord:
            prefix += char  # 逐字符扩展前缀
            # 过滤出以当前前缀开头的产品
            products = [p for p in products if p.startswith(prefix)]
            # 取前三个
            result.append(products[:3])

        return result
```

**注意：** 这种方法每次过滤会更新 `products`，实际上是逐渐缩小候选集，效率较高。
但对于极端情况（每次过滤后只剩 3 个），总体时间复杂度仍然是 O(n * L)，其中 L 是 searchWord 长度。

### 方法三：字典树（Trie）

**思路：** 构建一个字典树，每个节点存储经过该节点的产品名称（字典序最小的前三个）。

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}       # 子节点字典：字符 -> TrieNode
        self.suggestions = []    # 经过此节点的产品（最多保存前三个，按字典序）

class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        root = TrieNode()

        # 先对产品排序，这样插入时天然按字典序
        products.sort()

        # 构建字典树
        for product in products:
            node = root
            for char in product:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
                # 每个节点最多保存字典序最小的三个产品
                if len(node.suggestions) < 3:
                    node.suggestions.append(product)

        # 查询：依次走到每个前缀对应的节点
        result = []
        node = root
        dead_end = False  # 标记是否已经找不到匹配的节点

        for char in searchWord:
            if dead_end or char not in node.children:
                # 前缀已不存在于字典树中
                result.append([])
                dead_end = True
            else:
                node = node.children[char]
                result.append(node.suggestions[:])

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一：二分查找 | O(n log n + L log n) | O(n) | n=产品数，L=searchWord长度 |
| 方法二：逐步过滤 | O(n log n + n×L) | O(n) | 每次过滤最坏 O(n)，共 L 次 |
| 方法三：字典树 | O(n×W + L) | O(n×W) | W=产品平均长度，构建树代价高 |

---

## 关键点总结

1. **排序是基础**：排序后字典序最小的三个就是前三个满足前缀条件的产品，无需额外排序。
2. **二分查找加速**：`bisect_left` 快速定位第一个满足前缀的产品位置，避免全量扫描。
3. **startswith 检查**：二分找到位置后，需用 `startswith` 验证（排序后，不满足则后面也不满足，可提前退出）。
4. **字典树的优势**：当有大量查询时，字典树的查询时间 O(L) 优于二分的 O(L log n)，但构建代价高。
5. **前三个限制**：每个前缀只需要最多 3 个结果，可以提前截止，不需要找所有匹配。

---

## 易错点

1. **排序必须在最前面**：无论哪种方法，都需要先排序产品，才能保证取字典序最小的三个。
2. **二分查找的边界**：`bisect_left` 返回的位置可能等于 `len(products)`（所有产品都小于 prefix），需要处理这种边界情况。
3. **方法二修改了 products 引用**：`products = [...]` 会创建新列表，不是原地修改，实际上每次循环 products 变小，要注意这与"原始 products 不变"的写法区别。
4. **字典树节点的 suggestions 最多 3 个**：插入时要检查 `len(node.suggestions) < 3`，避免存储过多。
5. **dead_end 标志**：一旦某个字符在字典树中找不到，后续所有前缀都返回空列表，用 `dead_end` 标志避免重复判断。
