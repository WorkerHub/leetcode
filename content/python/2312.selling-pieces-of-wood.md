## 题目描述

给你两个整数 `m` 和 `n`，分别表示一块木头的高和宽。同时给你一个二维整数数组 `prices`，其中 `prices[i] = [h_i, w_i, price_i]` 表示你可以以 `price_i` 元出售一块高为 `h_i` 宽为 `w_i` 的木头。

每次操作中，你可以将当前的木块沿**水平**或**垂直**方向切割成两块，并且每块木头的高和宽都是**正整数**。

在完成所有切割之后，你可以以**任意顺序**出售这些木块。返回你切割木块后可以获得的**最多钱数**。

注意：你可以出售完全切割后的木块，也可以直接出售原始木块。

**示例 1：**
```
输入：m = 3, n = 5, prices = [[1,4,2],[2,2,7],[2,1,3]]
输出：19
解释：沿水平方向切一刀，得到 [1,5] 和 [2,5]，[2,5] 再切成两个 [2,2] 和 [2,1]。
总价：[1,5]不卖，但可以切成 [1,4]+[1,1]...最优方案卖得 19 元。
```

**提示：**
- `1 <= m, n <= 200`
- `1 <= prices.length <= 2 * 10^4`
- `prices[i].length == 3`

## 解题思路

**区间 DP / 记忆化搜索：**
定义 `dp[h][w]` 为高 `h` 宽 `w` 的木块能获得的最大价值。

转移方程：
- 直接出售：若 `(h, w)` 在 prices 中，则可获得对应价格。
- 水平切割：枚举切割位置 `i`（1 <= i < h），`dp[h][w] = max(dp[i][w] + dp[h-i][w])`。
- 垂直切割：枚举切割位置 `j`（1 <= j < w），`dp[h][w] = max(dp[h][j] + dp[h][w-j])`。

## 代码实现

### 方法一：记忆化搜索（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def sellingWood(self, m: int, n: int, prices: List[List[int]]) -> int:
        # 将价格存入字典便于查找
        price_map = {}
        for h, w, p in prices:
            price_map[(h, w)] = p

        @lru_cache(maxsize=None)
        def dp(h: int, w: int) -> int:
            # 直接出售当前木块的价格
            best = price_map.get((h, w), 0)
            # 尝试水平切割
            for i in range(1, h):
                best = max(best, dp(i, w) + dp(h - i, w))
            # 尝试垂直切割
            for j in range(1, w):
                best = max(best, dp(h, j) + dp(h, w - j))
            return best

        return dp(m, n)
```

### 方法二：自底向上 DP

```python
from typing import List

class Solution:
    def sellingWood(self, m: int, n: int, prices: List[List[int]]) -> int:
        # dp[i][j] 表示高 i 宽 j 的木块最大价值
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 初始化直接出售的价格
        for h, w, p in prices:
            dp[h][w] = max(dp[h][w], p)

        # 自底向上递推（从小到大）
        for h in range(1, m + 1):
            for w in range(1, n + 1):
                # 水平切割
                for i in range(1, h):
                    dp[h][w] = max(dp[h][w], dp[i][w] + dp[h - i][w])
                # 垂直切割
                for j in range(1, w):
                    dp[h][w] = max(dp[h][w], dp[h][j] + dp[h][w - j])

        return dp[m][n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 记忆化搜索 | O(m * n * (m + n)) | O(m * n) |
| 自底向上 DP | O(m * n * (m + n)) | O(m * n) |

## 关键点总结

1. DP 状态为木块尺寸，转移包含直接出售、水平切割、垂直切割三种选择。
2. 利用问题的最优子结构：大木块的最优值由子问题的最优值组合而来。
3. 由于 m, n <= 200，O(m * n * (m + n)) = O(200 * 200 * 400) = O(1.6 * 10^7)，可以接受。

## 易错点

- 初始化 `dp[h][w]` 时要取最大值，因为同一尺寸可能有多个价格。
- 切割位置 `i` 的范围是 `[1, h-1]`（不含 0 和 h），确保两块都是正整数高度。
