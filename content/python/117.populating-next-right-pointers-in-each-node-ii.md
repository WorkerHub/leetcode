## 题目描述

给定一个二叉树：

```cpp
struct Node {
  int val;
  Node *left;
  Node *right;
  Node *next;
}
```

填充它的每个 `next` 指针，让这个指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 `next` 指针设置为 `NULL`。

初始状态下，所有 `next` 指针都被设置为 `NULL`。

**示例 1：**

```
输入：root = [1,2,3,4,5,null,7]
输出：[1,#,2,3,#,4,5,7,#]
解释：
给定二叉树如上图所示，你的函数应该填充它的每个 next 指针，以指向其下一个右侧节点。
序列化输出按层序遍历顺序（由 next 指针连接），'#' 表示每层的末尾。
```

**示例 2：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中的节点数在范围 `[0, 6000]` 内
- `-100 <= Node.val <= 100`

**进阶：**

- 你只能使用常量级额外空间。
- 使用递归解题也符合要求，本题中递归程序占用的栈空间不算做额外的空间复杂度。

## 解题思路

这道题是 [116. 填充每个节点的下一个右侧节点指针](https://leetcode.com/problems/populating-next-right-pointers-in-each-node/) 的进阶版本，区别在于这里的二叉树不是完美二叉树，可能存在节点只有一个子节点或没有子节点的情况。

**核心思想：**

1. **层序遍历**：使用队列，将同一层的节点连接起来
2. **利用 next 指针遍历**：使用虚拟头节点，连接下一层的节点
3. **关键难点**：处理不完整的层，需要找到下一层的第一个节点

**与 116 题的区别：**
- 116 题是完美二叉树，每个节点都有两个子节点或没有子节点
- 117 题是普通二叉树，节点可能只有左子节点或只有右子节点

## Python 代码实现

### 方法一：层序遍历（BFS）

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next
"""

class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        from collections import deque
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            
            # 遍历当前层的所有节点
            for i in range(level_size):
                node = queue.popleft()
                
                # 如果不是当前层的最后一个节点，连接到下一个节点
                if i < level_size - 1:
                    node.next = queue[0]
                
                # 将子节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return root
```

### 方法二：利用 next 指针 + 虚拟头节点（推荐，O(1) 空间）

```python
class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        # 当前层的起始节点
        leftmost = root
        
        while leftmost:
            # 使用虚拟头节点来构建下一层的链接
            dummy = Node(0)  # 虚拟头节点
            prev = dummy     # 用于连接下一层节点的指针
            
            # 遍历当前层的所有节点
            curr = leftmost
            while curr:
                # 处理左子节点
                if curr.left:
                    prev.next = curr.left
                    prev = prev.next
                
                # 处理右子节点
                if curr.right:
                    prev.next = curr.right
                    prev = prev.next
                
                # 移动到当前层的下一个节点
                curr = curr.next
            
            # 移动到下一层的第一个节点
            leftmost = dummy.next
        
        return root
```

### 方法三：优化的层序遍历

```python
class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        from collections import deque
        queue = deque([root])
        
        while queue:
            prev = None
            
            # 处理当前层的所有节点
            for _ in range(len(queue)):
                node = queue.popleft()
                
                # 连接到前一个节点
                if prev:
                    prev.next = node
                prev = node
                
                # 添加子节点到队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return root
```

### 方法四：递归辅助函数

```python
class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return None
        
        # 处理当前节点的子节点连接
        if root.left and root.right:
            root.left.next = root.right
        
        # 找到下一层的第一个节点
        if root.left or root.right:
            # 获取当前节点的子节点（优先右节点）
            child = root.right if root.right else root.left
            
            # 找到当前节点的 next 节点的第一个子节点
            next_node = root.next
            while next_node:
                if next_node.left:
                    child.next = next_node.left
                    break
                if next_node.right:
                    child.next = next_node.right
                    break
                next_node = next_node.next
        
        # 注意：先递归右子树，再递归左子树
        # 因为我们依赖 next 指针，右子树需要先建立连接
        self.connect(root.right)
        self.connect(root.left)
        
        return root
```

## 复杂度分析

**方法一、三：层序遍历**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，队列最多存储一层的节点

**方法二：利用 next 指针（推荐）**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(1)，只使用常量额外空间

**方法四：递归**
- 时间复杂度：O(n)
- 空间复杂度：O(h)，递归栈深度为树的高度

## 关键点总结

1. **虚拟头节点技巧**：用 dummy 节点简化下一层的连接操作
2. **遍历顺序**：使用当前层的 next 指针遍历，同时构建下一层的连接
3. **处理不完整层**：节点可能只有左子节点或右子节点，需要分别处理
4. **找下一个节点**：需要在 next 链中寻找第一个有子节点的节点
5. **递归顺序**：先递归右子树，因为左子树的连接依赖右子树的 next

## 易错点

1. **只考虑完美二叉树**：假设每个节点都有两个子节点，导致出错
2. **虚拟节点忘记初始化**：每层都要重新创建 dummy 节点
3. **递归顺序错误**：先递归左子树会导致连接不完整
4. **next 链遍历**：找下一个子节点时，要遍历整个 next 链
5. **空指针判断**：要判断 `curr.left` 和 `curr.right` 是否存在
