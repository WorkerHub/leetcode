## 题目描述

给你一个正整数 `n`，表示一个无向图的节点数，以及一个二维整数数组 `edges`，其中 `edges[i] = [a_i, b_i]` 表示节点 a 和节点 b 之间有一条边。

将节点分成若干组，满足以下条件：
- 每个节点属于且仅属于一组
- 若 `(a, b)` 之间有边，则 a 和 b 属于相邻的组（即 `|group(a) - group(b)| == 1`）

返回最多可以分成的组数，若无法满足条件返回 `-1`（比如图中有奇数环）。

**提示：**
- `1 <= n <= 500`
- `1 <= edges.length <= 10^4`

## 解题思路

**二分图判断 + BFS 最长路径：**

1. **必要条件：** 若图中有奇数环（无法二分图染色），则返回 -1
2. **对每个连通分量：** 分组数 = 该连通分量的 BFS 层数最大值（即直径 + 1）
   - 对连通分量中的每个节点作为 BFS 起始点，求最大层数
   - 连通分量的最优分组数 = 最大 BFS 深度
3. 答案 = 所有连通分量的最优分组数之和

## 代码实现

### 方法一：并查集 + 二分图检验 + BFS（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        adj = defaultdict(list)
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)

        # 二分图检验（染色法）
        color = [-1] * (n + 1)

        def bfs_color(start):
            queue = deque([start])
            color[start] = 0
            while queue:
                node = queue.popleft()
                for nei in adj[node]:
                    if color[nei] == -1:
                        color[nei] = 1 - color[node]
                        queue.append(nei)
                    elif color[nei] == color[node]:
                        return False  # 奇数环，不是二分图
            return True

        # 并查集找连通分量
        parent = list(range(n + 1))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        for a, b in edges:
            union(a, b)

        # 检查是否是二分图，同时找连通分量
        for i in range(1, n + 1):
            if color[i] == -1:
                if not bfs_color(i):
                    return -1

        # BFS 求从某节点出发的最大深度
        def bfs_depth(start):
            dist = [-1] * (n + 1)
            dist[start] = 0
            queue = deque([start])
            max_d = 0
            while queue:
                node = queue.popleft()
                for nei in adj[node]:
                    if dist[nei] == -1:
                        dist[nei] = dist[node] + 1
                        max_d = max(max_d, dist[nei])
                        queue.append(nei)
            return max_d + 1  # 层数

        # 对每个连通分量，找最大 BFS 深度
        from collections import defaultdict
        components = defaultdict(list)
        for i in range(1, n + 1):
            components[find(i)].append(i)

        ans = 0
        for root, nodes in components.items():
            max_groups = 0
            for node in nodes:
                max_groups = max(max_groups, bfs_depth(node))
            ans += max_groups

        return ans
```

### 方法二：简化版（BFS 染色 + BFS 深度合并）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        adj = [[] for _ in range(n + 1)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)

        def bfs(src, component):
            dist = {src: 0}
            q = deque([src])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if v in component:
                        if v not in dist:
                            dist[v] = dist[u] + 1
                            q.append(v)
                        elif abs(dist[v] - dist[u]) != 1:
                            return -1  # 奇数环（同层有边）
            return max(dist.values()) + 1

        visited = [False] * (n + 1)
        ans = 0

        for i in range(1, n + 1):
            if visited[i]:
                continue
            # BFS 找连通分量
            comp = set()
            q = deque([i])
            visited[i] = True
            comp.add(i)
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        comp.add(v)
                        q.append(v)

            # 对连通分量中每个节点做 BFS，取最大深度
            best = 0
            for node in comp:
                d = bfs(node, comp)
                if d == -1:
                    return -1
                best = max(best, d)
            ans += best

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n * (n + m)) | O(n + m) |

## 关键点总结

1. 非二分图（有奇数环）直接返回 -1
2. 对每个连通分量，最优分组数 = 对连通分量内每个节点做 BFS 所得的最大层数
3. 各连通分量的最优分组数相加即为总答案

## 易错点

- 二分图检验：BFS 时相邻节点颜色相同即存在奇数环
- BFS 深度从 1 开始（第一层就有 1 组）
