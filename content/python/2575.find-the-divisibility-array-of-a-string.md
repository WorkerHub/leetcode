## 题目描述

给你一个下标从 **0** 开始的字符串 `word`（只包含数字），和一个正整数 `m`。

`word` 的 **可整除性数组** `div` 定义为：若 `word[0..i]` 所表示的数能被 `m` 整除，则 `div[i] = 1`，否则 `div[i] = 0`。

返回 `word` 的可整除性数组。

**示例 1：**

```
输入：word = "998244353", m = 3
输出：[1,1,0,0,0,1,1,0,0]
解释：
"9" % 3 == 0 → 1
"99" % 3 == 0 → 1
"998" % 3 != 0 → 0
...
```

**提示：**

- `1 <= word.length <= 10^5`
- `1 <= m <= 10^9`
- `word` 只包含数字

## 解题思路

逐位计算前缀数的余数：`remainder = (remainder * 10 + digit) % m`。

这样避免了处理大数，每步只需取模运算。

## Python 代码实现

### 方法一：逐位取模（推荐）

```python
from typing import List

class Solution:
    def divisibilityArray(self, word: str, m: int) -> List[int]:
        remainder = 0
        result = []

        for ch in word:
            remainder = (remainder * 10 + int(ch)) % m
            result.append(1 if remainder == 0 else 0)

        return result
```

### 方法二：Python 列表推导（简洁）

```python
from typing import List

class Solution:
    def divisibilityArray(self, word: str, m: int) -> List[int]:
        ans = []
        r = 0
        for c in word:
            r = (r * 10 + int(c)) % m
            ans.append(int(r == 0))
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 逐位取模：`(r * 10 + d) % m` 等价于前缀数字模 m
2. 避免大数运算，每步结果都在 [0, m-1] 范围内
3. 当余数为 0 时，该前缀能被 m 整除

## 易错点

1. 不能直接将整个前缀转为整数（可能非常大）
2. 余数计算：每次乘 10 并加新数字后取模
3. 注意 `int(ch)` 将字符转为整数
