## 题目描述

给你一个正整数 `n`，表示一个 `n` 个节点（下标 0 到 n-1）的 **连通无向图**，另有一个二维整数数组 `edges`，其中 `edges[i] = [ui, vi]` 表示节点 `ui` 和 `vi` 之间有一条边。

返回一个长度为 `n` 的整数数组 `answer`，其中 `answer[i]` 是第 `i` 个节点与图中任意环上节点的最短距离。

**示例 1：**
```
输入：n = 7, edges = [[1,2],[2,4],[4,3],[3,1],[0,1],[0,5],[5,6]]
输出：[1,0,0,0,0,1,2]
解释：环是1-2-4-3-1，节点0距离节点1最近，距离为1。
```

**提示：**
- `3 <= n <= 10^5`
- `edges.length == n`（连通图恰好有一个环）
- 图是连通的，且恰好含一个环

## 解题思路

由于图连通且有 n 条边、n 个节点，恰好含一个环。

**步骤：**
1. **拓扑排序剥树叶**：不断删除度为 1 的节点（叶子），剩余节点就是环上的节点。
2. **多源 BFS**：以环上所有节点为起点，向外进行 BFS，计算每个节点到环的最短距离。

这利用了"树叶剥离"（类似拓扑排序求最小环）的思想。

## 代码实现

### 方法一：拓扑排序 + 多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def distanceToCycle(self, n: int, edges: List[List[int]]) -> List[int]:
        # 建图
        graph = [[] for _ in range(n)]
        degree = [0] * n
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
            degree[u] += 1
            degree[v] += 1

        # 拓扑排序：剥离所有叶子，剩下的是环
        queue = deque()
        for i in range(n):
            if degree[i] == 1:
                queue.append(i)

        in_cycle = [True] * n  # 初始假设所有点在环上
        while queue:
            u = queue.popleft()
            in_cycle[u] = False  # 叶子节点不在环上
            for v in graph[u]:
                degree[v] -= 1
                if degree[v] == 1:
                    queue.append(v)

        # 多源 BFS：从环上节点向外扩展
        ans = [-1] * n
        bfs_queue = deque()
        for i in range(n):
            if in_cycle[i]:
                ans[i] = 0
                bfs_queue.append(i)

        while bfs_queue:
            u = bfs_queue.popleft()
            for v in graph[u]:
                if ans[v] == -1:  # 未访问过的节点
                    ans[v] = ans[u] + 1
                    bfs_queue.append(v)

        return ans
```

### 方法二：并查集找环 + BFS

```python
from typing import List
from collections import deque

class Solution:
    def distanceToCycle(self, n: int, edges: List[List[int]]) -> List[int]:
        # 并查集
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return False
            parent[px] = py
            return True

        # 找到环上的一条边
        graph = [[] for _ in range(n)]
        cycle_edge = None
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
            if not union(u, v):
                cycle_edge = (u, v)

        # DFS 找环上所有节点
        # 从 cycle_edge 的端点出发找路径
        u, v = cycle_edge
        # BFS 找从 v 到 u 不经过直接边的路径（即环）
        in_cycle = set()
        # 用 DFS 标记从 u 到 v 经过的节点（环的路径）
        visited = {u}
        path = [u]

        def dfs(node, target):
            if node == target:
                return True
            for nb in graph[node]:
                if nb not in visited and not (node == u and nb == v):
                    visited.add(nb)
                    path.append(nb)
                    if dfs(nb, target):
                        return True
                    path.pop()
            return False

        dfs(u, v)
        in_cycle = set(path)

        # 多源 BFS
        ans = [-1] * n
        queue = deque()
        for node in in_cycle:
            ans[node] = 0
            queue.append(node)

        while queue:
            cur = queue.popleft()
            for nb in graph[cur]:
                if ans[nb] == -1:
                    ans[nb] = ans[cur] + 1
                    queue.append(nb)

        return ans
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，拓扑排序和 BFS 各 O(n)。
- 空间复杂度：O(n)，图和队列。

**方法二：**
- 时间复杂度：O(n alpha(n))，并查集操作。
- 空间复杂度：O(n)。

## 关键点总结

1. 连通图 n 个节点 n 条边，恰好含一个环。
2. 拓扑排序剥叶是识别环节点的经典技巧。
3. 多源 BFS 同时计算所有节点到环的最短距离，比单源 BFS 更高效。

## 易错点

- 拓扑排序时初始度为 1 的才入队，度减为 1 后才入队（而非减为 0）。
- 多源 BFS 初始化时把所有环节点都加入队列，距离设为 0。
