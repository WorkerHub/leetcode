## 题目描述

在二维平面上，有一个机器人从原点 `(0, 0)` 开始。给出它的移动顺序，判断这个机器人在完成移动后是否在 `(0, 0)` 处结束。

移动顺序由字符串 `moves` 表示。字符 `move[i]` 表示其第 `i` 次移动。机器人的有效动作有 `R`（右），`L`（左），`U`（上）和 `D`（下）。

如果机器人在完成所有动作后返回原点，则返回 `true`。否则，返回 `false`。

**注意：**机器人"面朝"的方向无关紧要。`R` 将始终使机器人向右移动一次，`L` 将始终向左移动等。此外，假设每次移动机器人的移动幅度相同。

**示例 1:**

```
输入: moves = "UD"
输出: true
解释：机器人向上移动一次，然后向下移动一次。所有动作都具有相同的幅度，因此它最终回到它开始的原点。因此，返回 true。
```

**示例 2:**

```
输入: moves = "LL"
输出: false
解释：机器人向左移动两次。它最终位于原点的左侧，距原点有两次"移动"的距离。返回 false。
```

**提示:**
- `1 <= moves.length <= 2 * 10^4`
- `moves` 只包含字符 `'U'`, `'D'`, `'L'` 和 `'R'`

## 解题思路

这是一道非常简单的模拟题。机器人能回到原点的充要条件是：

**核心观察：**

1. **水平方向**：向左移动的次数 = 向右移动的次数
2. **垂直方向**：向上移动的次数 = 向下移动的次数

### 解法思路

**方法一：计数法**
- 统计 `L` 和 `R` 的数量是否相等
- 统计 `U` 和 `D` 的数量是否相等

**方法二：坐标模拟**
- 维护 `(x, y)` 坐标
- 根据移动方向更新坐标
- 最后判断是否回到 `(0, 0)`

**方法三：一次遍历**
- 用两个变量记录水平和垂直方向的偏移
- 最后判断偏移是否为 0

## Python 代码实现

### 方法一：计数法（最简洁）⭐

```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        """
        统计四个方向的移动次数
        """
        return moves.count('L') == moves.count('R') and moves.count('U') == moves.count('D')
```

### 方法二：坐标模拟

```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        """
        模拟机器人移动，维护坐标
        """
        x, y = 0, 0
        
        for move in moves:
            if move == 'U':
                y += 1
            elif move == 'D':
                y -= 1
            elif move == 'L':
                x -= 1
            elif move == 'R':
                x += 1
        
        return x == 0 and y == 0
```

### 方法三：字典映射

```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        """
        使用字典存储方向映射
        """
        x, y = 0, 0
        
        # 方向映射
        directions = {
            'U': (0, 1),
            'D': (0, -1),
            'L': (-1, 0),
            'R': (1, 0)
        }
        
        for move in moves:
            dx, dy = directions[move]
            x += dx
            y += dy
        
        return x == 0 and y == 0
```

### 方法四：Counter 统计

```python
from collections import Counter

class Solution:
    def judgeCircle(self, moves: str) -> bool:
        """
        使用 Counter 统计每个方向的次数
        """
        count = Counter(moves)
        return count['L'] == count['R'] and count['U'] == count['D']
```

### 方法五：一行代码

```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        """
        超简洁版本
        """
        return moves.count('L') == moves.count('R') and moves.count('U') == moves.count('D')
```

## 复杂度分析

### 方法一：计数法
- **时间复杂度**：O(n)，count 方法遍历字符串 4 次
- **空间复杂度**：O(1)，只使用常量空间

### 方法二：坐标模拟
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，只使用两个变量

### 方法三：字典映射
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，字典大小固定

### 方法四：Counter 统计
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，Counter 最多存储 4 个键

```
移动 'D'：(0, 1) -> (0, 0)

结果：true
```

示例 2：`moves = "LL"`

```
起点：(0, 0)

移动 'L'：(0, 0) -> (-1, 0)
(-1,0) <- (0,0)

移动 'L'：(-1, 0) -> (-2, 0)
(-2,0) <- (-1,0) <- (0,0)

结果：false（在 (-2, 0)，未回到原点）
```

**计数法分析：**

```
moves = "UD"
L: 0, R: 0 -> L == R ✓
U: 1, D: 1 -> U == D ✓
结果：true

moves = "LL"
L: 2, R: 0 -> L != R ✗
结果：false
```

## 关键点总结

1. **问题本质**：判断水平和垂直方向的移动是否平衡
2. **等价条件**：`count(L) == count(R)` 且 `count(U) == count(D)`
3. **多种实现**：计数、坐标模拟、字典映射都可以
4. **代码简洁性**：Python 的 count 方法使代码非常简洁
5. **无需考虑顺序**：移动的顺序不影响最终位置

## 易错点

1. **忘记检查垂直方向**：
   ```python
   # 错误：只检查水平
   return moves.count('L') == moves.count('R')
   
   # 正确：同时检查水平和垂直
   return moves.count('L') == moves.count('R') and moves.count('U') == moves.count('D')
   ```

2. **坐标更新方向错误**：
   ```python
   # 注意 y 轴方向：U 是 +1，D 是 -1
   if move == 'U':
       y += 1  # 向上
   elif move == 'D':
       y -= 1  # 向下
   ```

3. **使用 == 而不是 =**：
   ```python
   # 错误：赋值
   if x = 0 and y = 0:
   
   # 正确：比较
   if x == 0 and y == 0:
   ```

4. **字典键不存在**：
   ```python
   # 如果输入保证有效，不需要检查
   # 但在实际中可以添加默认值
   directions.get(move, (0, 0))
   ```

5. **Counter 默认值**：
   ```python
   # Counter 对不存在的键返回 0，所以安全
   count['L'] == count['R']  # 即使没有 L 或 R 也正确
   ```
