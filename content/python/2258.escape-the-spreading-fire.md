## 题目描述

给你一个下标从 0 开始的二维整数数组 `grid`，大小为 `m x n`：
- `0`：草地，可以移动，也会被火蔓延。
- `1`：火源，火已在此蔓延。
- `2`：墙，不可移动，火也无法蔓延。

你的初始位置是 `(0, 0)`，目标是到达 `(m-1, n-1)`。每轮：先蔓延火（向上下左右扩展到草地），再你移动（向上下左右移动到草地，或停留）。

你需要在**到达目标时恰好在火到达之前或同时到达**（你到达时火还没到，或与你同时到达目标也算成功）。

返回你可以在初始位置最多**等待**多少分钟后再开始移动。若无法到达，返回 -1；若可以无限等待，返回 10^9。

## 解题思路

**二分答案 + BFS：**
- 二分等待时间 `t`。
- 对给定 `t`，先让火蔓延 `t` 轮（多源 BFS），得到火的到达时间 `fire_time[i][j]`。
- 然后用 BFS 模拟你从 `(0,0)` 出发，检查是否能到达 `(m-1,n-1)` 时不被火追上。

**关键条件：** 你在某步到达 `(i,j)` 时，你的到达时间 <= `fire_time[i][j]`（对于终点，允许同时到达）。

## 代码实现

### 方法一：二分 + 多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maximumMinutes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')

        # 预计算火到达每个格子的时间
        fire_time = [[INF] * n for _ in range(m)]
        fq = deque()
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    fire_time[i][j] = 0
                    fq.append((i, j))

        # 多源 BFS 计算火的扩散时间
        while fq:
            r, c = fq.popleft()
            for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 0 and fire_time[nr][nc] == INF:
                    fire_time[nr][nc] = fire_time[r][c] + 1
                    fq.append((nr, nc))

        def can_escape(wait: int) -> bool:
            """等待 wait 分钟后能否到达终点"""
            if fire_time[0][0] <= wait:
                return False  # 起点在等待期间被火烧

            visited = [[False] * n for _ in range(m)]
            visited[0][0] = True
            q = deque([(0, 0, wait)])  # (行, 列, 当前时间)

            while q:
                r, c, t = q.popleft()
                for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nr, nc = r + dr, c + dc
                    if not (0 <= nr < m and 0 <= nc < n):
                        continue
                    if grid[nr][nc] == 2 or visited[nr][nc]:
                        continue
                    nt = t + 1
                    # 到达终点：允许与火同时到达
                    if nr == m-1 and nc == n-1:
                        if nt <= fire_time[nr][nc]:
                            return True
                        continue
                    # 非终点：必须在火之前到达
                    if nt < fire_time[nr][nc]:
                        visited[nr][nc] = True
                        q.append((nr, nc, nt))

            return False

        # 二分等待时间
        lo, hi = 0, m * n
        if not can_escape(0):
            return -1
        if can_escape(hi):
            return 10 ** 9

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_escape(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：二分优化（预计算人的到达时间）

```python
from typing import List
from collections import deque

class Solution:
    def maximumMinutes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')

        def bfs_time(starts):
            """从多个起点出发，计算到达每个格子的最短时间"""
            dist = [[INF] * n for _ in range(m)]
            q = deque()
            for r, c in starts:
                dist[r][c] = 0
                q.append((r, c))
            while q:
                r, c = q.popleft()
                for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 0 and dist[nr][nc] == INF:
                        dist[nr][nc] = dist[r][c] + 1
                        q.append((nr, nc))
            return dist

        fire_starts = [(i,j) for i in range(m) for j in range(n) if grid[i][j] == 1]
        fire = bfs_time(fire_starts)
        person = bfs_time([(0, 0)])

        if person[m-1][n-1] == INF:
            return -1  # 人无法到达终点

        # 等待时间 t 可行当且仅当：
        # 对所有路径上的格子，person_time + t <= fire_time
        # 最大等待 = min over all cells on optimal path (fire - person)
        # 使用二分
        def feasible(t):
            if fire[0][0] <= t:
                return False
            q = deque([(0, 0)])
            vis = [[False]*n for _ in range(m)]
            vis[0][0] = True
            step = t
            while q:
                for _ in range(len(q)):
                    r, c = q.popleft()
                    for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                        nr, nc = r+dr, c+dc
                        if not (0 <= nr < m and 0 <= nc < n) or grid[nr][nc]==2 or vis[nr][nc]:
                            continue
                        ns = step + 1
                        if nr==m-1 and nc==n-1:
                            if ns <= fire[nr][nc]: return True
                            continue
                        if ns < fire[nr][nc]:
                            vis[nr][nc] = True
                            q.append((nr, nc))
                step += 1
            return False

        lo, hi = 0, m*n
        if not feasible(0): return -1
        if feasible(hi): return 10**9
        while lo < hi:
            mid = (lo+hi+1)//2
            if feasible(mid): lo = mid
            else: hi = mid-1
        return lo
```

## 复杂度分析

- 时间复杂度：O(m*n*log(m*n))，二分 O(log(mn))，每次 BFS O(mn)。
- 空间复杂度：O(m*n)。

## 关键点总结

1. 二分等待时间，验证是否可行。
2. 多源 BFS 预计算火的到达时间。
3. 到达终点时允许与火同时到达（`<=`），其他格子必须早于火（`<`）。

## 易错点

- 到达终点的条件比其他格子宽松（允许同时到达）。
- 二分上界设为 `m*n`（最大步数），若等待 `m*n` 还能到达，返回 `10^9`。
