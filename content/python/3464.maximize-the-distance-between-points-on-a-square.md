## 题目描述

给你一个整数 `side` 表示正方形的边长（坐标从 0 到 side），以及一个二维整数数组 `points`，每个点在正方形的边上。

从 points 中选 `k` 个点，使得相邻点（按顺序沿正方形边移动）之间的最小距离最大化。

返回这个最大化的最小距离。

**提示：**
- `4 <= side <= 10^9`
- `4 <= points.length <= 10^5`
- `k == 4`（选 4 个点）

## 解题思路

二分答案：二分最小距离 d，检查是否能在正方形边上选 k 个点使相邻距离都 >= d。

正方形周长 = 4 * side，将每个点映射为沿正方形边的弧长坐标（0 到 4*side）。

检查时：从第一个点出发，贪心地选距离 >= d 的下一个点，共选 k 个，看能否回到起点（即第 k 个点与第 1 个点的距离也 >= d）。

## Python 代码实现

### 方法一：二分 + 贪心

```python
from typing import List
import bisect

class Solution:
    def maxDistance(self, side: int, points: List[List[int]], k: int) -> int:
        # 将点映射到正方形边上的弧长坐标
        def to_arc(x, y):
            if y == 0:
                return x              # 下边
            elif x == side:
                return side + y       # 右边
            elif y == side:
                return 2 * side + (side - x)  # 上边
            else:
                return 3 * side + (side - y)  # 左边

        arcs = sorted(to_arc(x, y) for x, y in points)
        n = len(arcs)
        total = 4 * side

        def can_place(d):
            """是否能选 k 个点使相邻弧长距离 >= d"""
            # 枚举第一个点的位置
            for start_idx in range(n):
                # 从 start_idx 出发，贪心选 k 个点
                count = 1
                cur = arcs[start_idx]
                cur_idx = start_idx

                for _ in range(k - 1):
                    # 找下一个距当前点弧长 >= d 的点
                    target = cur + d
                    # 在 arcs 中找 >= target 的最小位置
                    # 需要考虑循环：target 可能超过 total
                    if target <= total:
                        j = bisect.bisect_left(arcs, target % total if target > total else target)
                        # 找到了
                        if j < n:
                            cur = arcs[j]
                            cur_idx = j
                            count += 1
                        else:
                            # 绕回来
                            j = bisect.bisect_left(arcs, target % total)
                            if j < n:
                                cur = arcs[j] + total
                                cur_idx = j
                                count += 1
                            else:
                                break
                    else:
                        j = bisect.bisect_left(arcs, target % total)
                        if j < n and j != start_idx:
                            cur = arcs[j] + total
                            count += 1
                        else:
                            break

                if count == k:
                    # 检查最后一个点与第一个点的距离
                    first = arcs[start_idx]
                    last = cur
                    # 绕回到第一个点的距离
                    gap = first + total - last
                    if gap >= d:
                        return True

            return False

        lo, hi = 1, total // k
        ans = 0

        while lo <= hi:
            mid = (lo + hi) // 2
            if can_place(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1

        return ans
```

### 方法二：简化贪心检查

```python
from typing import List
import bisect

class Solution:
    def maxDistance(self, side: int, points: List[List[int]], k: int) -> int:
        def to_arc(x, y):
            if y == 0:
                return x
            elif x == side:
                return side + y
            elif y == side:
                return 2 * side + (side - x)
            else:
                return 3 * side + (side - y)

        arcs = sorted(set(to_arc(x, y) for x, y in points))
        n = len(arcs)
        P = 4 * side

        def check(d):
            for i in range(n):
                cnt = 1
                cur = arcs[i]
                while cnt < k:
                    nxt = cur + d
                    if nxt > arcs[i] + P:
                        break
                    j = bisect.bisect_left(arcs, nxt % P)
                    if j < n:
                        cur = arcs[j] if arcs[j] >= nxt % P else arcs[j] + P
                    else:
                        cur = arcs[0] + P
                    cnt += 1
                if cnt == k and arcs[i] + P - cur >= d:
                    return True
            return False

        lo, hi = 1, P // k
        ans = 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n * log(P/k))
- 空间复杂度：O(n)

## 关键点总结

1. 将二维点映射为沿正方形边的一维弧长
2. 二分最小距离，贪心验证
3. 注意正方形的循环性（最后一个点与第一个点也要满足距离约束）

## 易错点

1. 弧长映射要正确（四条边连接顺序）
2. 循环问题：最后一个点到第一个点的距离也要 >= d
3. 二分上界：P // k（均分情况下的最大间距）
