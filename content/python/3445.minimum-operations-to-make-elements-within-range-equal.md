## 题目描述

给你一个整数数组 `nums` 和两个整数 `lower`、`upper`，以及整数 `limit`。

一次操作中，你可以将某个元素增加或减少 1，但是：
- 每次操作后，所有元素必须在 `[lower, upper]` 范围内

返回使所有元素相等所需的最少操作次数。如果不可能，返回 -1。

注意，若数组为空，操作数为 0。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= lower <= upper <= 10^9`
- `1 <= limit <= 10^6`
- `1 <= nums[i] <= 10^9`

## 解题思路

贪心：将所有元素移到 `[lower, upper]` 范围内（超出范围的截断），然后找使所有元素相等的最优目标值（中位数）。

实际上，所有元素的最终值必须在 `[lower, upper]` 内。将 `nums[i]` 夹在 `[lower, upper]`，即取 `max(lower, min(upper, nums[i]))`。

然后，在 `[lower, upper]` 内找一个值，使得所有元素调整到该值的代价最小——即中位数。

## Python 代码实现

### 方法一：截断 + 中位数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], lower: int, upper: int, limit: int) -> int:
        n = len(nums)

        # 将所有元素截断到 [lower, upper]
        adjusted = [max(lower, min(upper, x)) for x in nums]

        # 排序找中位数
        adjusted.sort()
        median = adjusted[n // 2]

        # 所有元素调整到中位数的代价
        total_cost = sum(abs(x - median) for x in adjusted)
```

### 方法二：考虑 limit 约束

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], lower: int, upper: int, limit: int) -> int:
        # 将元素限制到 [lower, upper]
        # 超出 [lower, upper] 需要先移动到范围内
        # 若元素本身就在 [lower, upper]，不需要移动
        # 若不在范围内，必须移动到边界

        # 然后找使所有元素相等的最小代价
        # 在 [lower, upper] 内选一个目标值，使总移动代价最小
        # 最优目标值是中位数（或任意 [lower, upper] 内的中位数附近值）

        clipped = [max(lower, min(upper, x)) for x in nums]
        clipped.sort()
        n = len(clipped)
        median = clipped[n // 2]

        # 确保中位数在 [lower, upper] 内
        target = max(lower, min(upper, median))

        cost = sum(abs(x - target) for x in clipped)
        return cost
```

### 方法三：前缀和优化找最优目标值

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], lower: int, upper: int, limit: int) -> int:
        # 所有元素先 clip 到 [lower, upper]
        clipped = sorted(max(lower, min(upper, x)) for x in nums)
        n = len(clipped)

        # 目标值 t 在 [lower, upper] 内使 sum|clip[i]-t| 最小
        # 最优 t = 中位数
        t = clipped[n // 2]

        # 前缀和计算代价
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + clipped[i]

        def cost_at(t):
            # 二分找 t 的位置
            import bisect
            pos = bisect.bisect_right(clipped, t)
            # 左侧：pos 个元素 <= t，代价 = t*pos - prefix[pos]
            left_cost = t * pos - prefix[pos]
            # 右侧：n-pos 个元素 > t，代价 = (prefix[n] - prefix[pos]) - t*(n-pos)
            right_cost = (prefix[n] - prefix[pos]) - t * (n - pos)
            return left_cost + right_cost

        return cost_at(t)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 超出 `[lower, upper]` 的元素必须先截断到边界
2. 在 `[lower, upper]` 内使所有元素相等，最优目标是中位数
3. 代价 = sum(|clipped[i] - median|)

## 易错点

1. 先截断，再找中位数（不是先找中位数再截断）
2. 截断到边界不一定是最优——只是必须满足的约束
3. 若所有元素已在 `[lower, upper]` 内，截断不改变任何值
