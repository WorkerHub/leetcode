## 题目描述

给你一个由小写英文字母组成的回文字符串 `palindrome`，请你将其中**一个**字符用任意小写英文字母替换，使得结果字符串的字典序**最小**，且**不是**回文串。

请你返回结果字符串。如果无法做到，则返回一个**空字符串**。

**示例 1：**

```
输入：palindrome = "abccba"
输出："aaccba"
解释：存在多种方法可以使 "abccba" 不是回文，例如 "zbccba", "aaccba", "abacba", "abcaba", "abccva", "abccbz" 等。
在所有方法中，"aaccba" 的字典序最小。
```

**示例 2：**

```
输入：palindrome = "a"
输出：""
解释：不存在替换一个字符使 "a" 变成非回文且有意义的字符串。
```

**提示：**

- `1 <= palindrome.length <= 1000`
- `palindrome` 仅由小写英文字母组成

## 解题思路

**贪心策略**

要让结果字典序最小，优先修改**前半部分**（高位权重大，改小影响更大）。

**分两种情况：**

**情况 1：前半部分存在非 'a' 字符**

将前半部分第一个非 'a' 的字符改为 'a'。这样：
- 字典序变小（'a' 是最小字母）
- 打破了回文对称性（该位置原本是非 'a'，改为 'a'，其镜像位置仍是原字符）

特别注意：如果要改的位置是**中间字符**（奇数长度字符串的正中间），改了仍然是回文！因为中间字符对称于自身。所以要跳过中间字符。

**情况 2：前半部分全是 'a'（字符串形如 "aaa...aaa" 或 "aaa...a...aaa"）**

此时所有字符都是 'a'（中间可能有 'a'），将**最后一个字符**改为 'b'。这样：
- 字典序尽量小（只改最低位）
- 打破回文性质

**为什么不能改后半部分？**

改前半部分对应位置的字符，会让字典序更小（前缀相同时，越高位的字符影响越大）。而改后半部分同等效果下字典序更大或相同。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        
        # 长度为 1 时，无法修改成非回文
        if n == 1:
            return ""
        
        s = list(palindrome)
        
        # 遍历前半部分，找第一个非 'a' 且不是中间字符的位置
        for i in range(n // 2):
            if s[i] != 'a':
                s[i] = 'a'
                return ''.join(s)
        
        # 前半部分全是 'a'（字符串全由 'a' 组成，中间可能有其他字符）
        # 将最后一个字符改为 'b'（字典序最小的非 'a' 字母）
        s[-1] = 'b'
        return ''.join(s)
```

### 方法二：字符串切片（等价写法）

```python
class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        if n == 1:
            return ""
        
        # 寻找前半部分第一个非 'a' 字符（排除中间字符）
        for i in range(n):
            # 跳过 'a' 和正中间字符（奇数长度时，中间下标为 n//2）
            if palindrome[i] != 'a' and not (n % 2 == 1 and i == n // 2):
                # 将该字符改为 'a'
                return palindrome[:i] + 'a' + palindrome[i + 1:]
        
        # 所有可修改位置都是 'a'，改最后一个为 'b'
        return palindrome[:-1] + 'b'
```

### 方法三：详细注释版（教学用）

```python
class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        
        # 特殊情况：长度为 1，无法不改成非回文
        if n == 1:
            return ""
        
        s = list(palindrome)
        
        # 策略 1：在前半部分找第一个非 'a' 字符，改为 'a'
        # 只需遍历前半段（下标 0 到 n//2 - 1）
        # 对于奇数长度，中间字符（n//2）不在范围内，不会被选中
        for i in range(n // 2):
            if s[i] != 'a':
                # 找到了！将其改为 'a'，打破对称性且字典序最小
                s[i] = 'a'
                return ''.join(s)
        
        # 策略 2：前半部分全是 'a'
        # 此时字符串形如 "aaa" 或 "aaXaa"（X 是中间字符）
        # 改最后一个字符为 'b' 是代价最小的破坏回文的方式
        s[n - 1] = 'b'
        return ''.join(s)
```

## 复杂度分析

- **时间复杂度**：O(n)，最多遍历字符串一次
- **空间复杂度**：O(n)，转换为列表或使用字符串切片

## 图解示例

```
palindrome = "abccba"，n=6

遍历前半部分（下标 0, 1, 2）：
  i=0: s[0]='a' == 'a'，跳过
  i=1: s[1]='b' != 'a'，改为 'a'
  返回 "aaccba"

palindrome = "aaaa"，n=4

遍历前半部分（下标 0, 1）：
  i=0: 'a' == 'a'，跳过
  i=1: 'a' == 'a'，跳过
策略 2：改最后一个为 'b'
返回 "aaab"

palindrome = "aba"，n=3（奇数长度）

遍历前半部分（下标 0, 只有 n//2=1 个）：
  i=0: 'a' == 'a'，跳过
策略 2：改最后一个为 'b'
返回 "abb"
```

## 关键点总结

1. 只遍历前半部分（`range(n//2)`），奇数长度时中间字符自然被排除
2. 找到第一个非 'a' 字符改为 'a'，字典序最优
3. 前半部分全为 'a' 时，改最后一个字符为 'b'
4. 长度为 1 时无解，返回空字符串

## 易错点

1. **中间字符的处理**：改中间字符不会打破回文（中间字符对称于自身），遍历 `range(n//2)` 自然跳过中间字符
2. **长度为 1 的特殊处理**：单字符无论改成什么都是回文，返回 ""
3. **后半部分不需遍历**：由于回文对称，前半部分的操作已经覆盖了所有情况
