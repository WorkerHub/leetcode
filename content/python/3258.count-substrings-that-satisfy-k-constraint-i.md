## 题目描述

给你一个**二进制字符串** `s` 和一个正整数 `k`。

如果字符串中 `'0'` 的数量**至多为 k**，或 `'1'` 的数量**至多为 k**，则称该字符串满足 **k 约束**。

返回满足 k 约束的 `s` 的子字符串数量。

**示例 1：**
```
输入：s = "10101", k = 1
输出：12
```

**示例 2：**
```
输入：s = "1010101", k = 2
输出：25
```

**提示：**
- `1 <= s.length <= 50`
- `0 <= k <= s.length`
- `s[i]` 为 `'0'` 或 `'1'`

## 解题思路

由于数据范围小（n <= 50），暴力枚举所有子字符串即可。

对每个子字符串，统计 '0' 和 '1' 的数量，判断是否满足 k 约束。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def countKConstraintSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        ans = 0
        for i in range(n):
            cnt0 = cnt1 = 0
            for j in range(i, n):
                if s[j] == '0':
                    cnt0 += 1
                else:
                    cnt1 += 1
                if cnt0 <= k or cnt1 <= k:
                    ans += 1
        return ans
```

### 方法二：滑动窗口

```python
class Solution:
    def countKConstraintSubstrings(self, s: str, k: int) -> int:
        # 对于每个右端点 j，找最小的左端点 l 使得 [l, j] 满足 k 约束
        # 满足条件的子字符串数 = j - l + 1
        n = len(s)
        cnt = [0, 0]  # cnt[0]=0的数量, cnt[1]=1的数量
        left = 0
        ans = 0
        
        for right in range(n):
            cnt[int(s[right])] += 1
            # 收缩左端：只有当两个计数都超过 k 时才不满足
            while cnt[0] > k and cnt[1] > k:
                cnt[int(s[left])] -= 1
                left += 1
            ans += right - left + 1
        
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n^2)
- 方法二：时间复杂度 O(n)，空间复杂度 O(1)

## 关键点总结

1. k 约束：0 的数量 <= k 或 1 的数量 <= k（满足其一即可）
2. 滑动窗口：当两个计数都超过 k 时，窗口不满足条件，需要收缩
3. 每个右端点对应的满足条件的子字符串数 = right - left + 1

## 易错点

1. 条件是"或"关系（至多 k 个 0 **或** 至多 k 个 1）
2. 不能贪心地认为长串不满足条件就不计入
