## 题目描述

给你一个整数数组 `jobs`（长度 n <= 12）和一个整数 `k`（工人数），返回分配所有任务给 k 名工人后，最大工作时间的最小值。

**示例 1：**

```
输入：jobs = [3, 2, 3], k = 3
输出：3
解释：每人分配一个任务，最大时间为 3。
```

**示例 2：**

```
输入：jobs = [1, 2, 4, 7, 8], k = 2
输出：11
解释：最优分配使最大时间最小为 11。
```

**提示：**
- `1 <= k <= jobs.length <= 12`
- `1 <= jobs[i] <= 10^7`

## 解题思路

与 3826 相同的状态压缩 DP 问题（1723. 完成所有工作的最短时间）。

使用**二分 + 回溯**或**状态压缩 DP**：
1. 预计算每个子集的和 `sum[mask]`。
2. `dp[j][mask]` = 前 j 名工人完成 mask 中任务的最小最大时间。
3. 答案为 `dp[k][(1<<n)-1]`。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        n = len(jobs)
        full = (1 << n) - 1

        # 预计算子集和
        subset_sum = [0] * (full + 1)
        for mask in range(1, full + 1):
            lsb = mask & (-mask)
            bit = lsb.bit_length() - 1
            subset_sum[mask] = subset_sum[mask ^ lsb] + jobs[bit]

        # dp[mask] = 用最少工人完成 mask 中任务的最小最大时间
        # 初始：1 名工人时，dp[mask] = subset_sum[mask]
        dp = subset_sum[:]

        for _ in range(1, k):
            new_dp = [0] * (full + 1)
            for mask in range(full + 1):
                new_dp[mask] = dp[mask]  # 不给第 j 个工人任何任务
                sub = mask
                while sub > 0:
                    # 给第 j 个工人分配 sub 中的任务
                    new_dp[mask] = min(new_dp[mask],
                                       max(dp[mask ^ sub], subset_sum[sub]))
                    sub = (sub - 1) & mask
            dp = new_dp

        return dp[full]
```

### 方法二：二分 + 回溯

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        jobs.sort(reverse=True)
        n = len(jobs)

        def feasible(limit):
            workers = [0] * k

            def dfs(i):
                if i == n:
                    return True
                seen = set()
                for j in range(k):
                    if workers[j] in seen:
                        continue
                    if workers[j] + jobs[i] <= limit:
                        seen.add(workers[j])
                        workers[j] += jobs[i]
                        if dfs(i + 1):
                            return True
                        workers[j] -= jobs[i]
                return False

            return dfs(0)

        lo, hi = max(jobs), sum(jobs)
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(k * 3^n)，枚举子集的子集
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 12 是状态压缩 DP 的标志，`2^12 = 4096`，三次幂 `3^12` 约 53 万，可接受。
2. 子集枚举 `sub = (sub - 1) & mask` 是经典技巧。
3. 二分 + 回溯带剪枝也是常用方法。

## 易错点

1. 初始化：1 名工人时所有任务都给他，`dp[mask] = subset_sum[mask]`。
2. DP 外层是工人数，内层是任务子集，不要颠倒。
3. 子集枚举时 sub = 0 的情况（不给当前工人任何任务）等价于 `new_dp[mask] = dp[mask]`，需单独处理。
