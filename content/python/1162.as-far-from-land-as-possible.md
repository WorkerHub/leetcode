## 题目描述

给定一个 `n x n` 的二维网格，其中每个单元格的值为 `0` 或 `1`，其中 `0` 代表海洋，`1` 代表陆地。

找到海洋中距离陆地最远的海洋单元格，返回该距离。如果网格上没有海洋或者没有陆地，返回 `-1`。

我们这里说的距离是曼哈顿距离：`(x0, y0)` 和 `(x1, y1)` 这两个单元格之间的距离是 `|x0 - x1| + |y0 - y1|`。

示例 1：

```
输入：grid = [[1,0,1],[0,0,0],[1,0,1]]
输出：2
解释： 
海洋单元格 (1, 1) 距离所有陆地单元格的距离都达到最大，为 2。
```

示例 2：

```
输入：grid = [[1,0,0],[0,0,0],[0,0,0]]
输出：4
解释： 
海洋单元格 (2, 2) 距离所有陆地单元格的距离都达到最大，为 4。
```

提示：

- `n == grid.length`
- `n == grid[i].length`
- `1 <= n <= 100`
- `grid[i][j]` 不是 `0` 就是 `1`

## 解题思路

这是一道多源 BFS（广度优先搜索）的经典问题。核心思想是从所有陆地单元格同时开始进行 BFS，逐层向外扩散到海洋，最后到达的海洋单元格就是距离陆地最远的。

**关键观察：**

1. 如果从每个海洋单元格分别计算到最近陆地的距离，时间复杂度为 O(n^4)，会超时
2. 反向思考：从所有陆地同时开始 BFS，第一次到达某个海洋单元格的距离就是最短距离
3. 多源 BFS：将所有陆地单元格同时加入初始队列
4. BFS 的层数就是距离

**算法步骤：**

1. 遍历网格，将所有陆地单元格 (i, j) 加入队列
2. 从队列开始 BFS，向四个方向扩散
3. 每次扩散到一个新的海洋单元格，记录距离
4. 返回最后访问到的海洋单元格的距离

**边界情况：**
- 全是陆地或全是海洋：返回 -1

## Python 代码实现

### 方法一：多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        """
        多源 BFS 求最大距离
        
        时间复杂度：O(n^2)
        空间复杂度：O(n^2)
        """
        n = len(grid)
        queue = deque()
        
        # 将所有陆地单元格加入队列，作为多源 BFS 的起点
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    queue.append((i, j, 0))  # (行, 列, 距离)
        
        # 边界情况：全是陆地或全是海洋
        if len(queue) == 0 or len(queue) == n * n:
            return -1
        
        # BFS 四个方向
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        max_distance = 0
        
        while queue:
            x, y, dist = queue.popleft()
            
            # 向四个方向扩散
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                # 检查边界和是否为海洋
                if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] == 0:
                    # 标记为已访问（改为陆地，避免重复访问）
                    grid[nx][ny] = 1
                    new_dist = dist + 1
                    max_distance = max(max_distance, new_dist)
                    queue.append((nx, ny, new_dist))
        
        return max_distance
```

### 方法二：BFS + visited 数组

```python
from typing import List
from collections import deque

class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        """
        使用 visited 数组避免修改原数组
        """
        n = len(grid)
        queue = deque()
        visited = [[False] * n for _ in range(n)]
        
        # 初始化：所有陆地加入队列
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    queue.append((i, j))
                    visited[i][j] = True
        
        # 边界情况
        if len(queue) == 0 or len(queue) == n * n:
            return -1
        
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        distance = -1  # 距离从 0 开始，最终返回 distance
        
        # BFS 层序遍历
        while queue:
            # 处理当前层
            size = len(queue)
            distance += 1
            
            for _ in range(size):
                x, y = queue.popleft()
                
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    
                    if (0 <= nx < n and 0 <= ny < n and 
                        not visited[nx][ny] and grid[nx][ny] == 0):
                        visited[nx][ny] = True
                        queue.append((nx, ny))
        
        return distance
```

### 方法三：动态规划（两次遍历）

```python
from typing import List

class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        """
        使用动态规划求解
        
        dp[i][j] 表示 (i,j) 到最近陆地的距离
        需要两次遍历：从左上到右下，从右下到左上
        
        时间复杂度：O(n^2)
        空间复杂度：O(n^2)
        """
        n = len(grid)
        INF = n * n  # 设置一个足够大的值
        
        # 初始化 dp 数组
        dp = [[INF] * n for _ in range(n)]
        
        # 第一次遍历：从左上到右下
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    dp[i][j] = 0
                else:
                    # 从上方来
                    if i > 0:
                        dp[i][j] = min(dp[i][j], dp[i-1][j] + 1)
                    # 从左方来
                    if j > 0:
                        dp[i][j] = min(dp[i][j], dp[i][j-1] + 1)
        
        # 第二次遍历：从右下到左上
        max_dist = -1
        for i in range(n-1, -1, -1):
            for j in range(n-1, -1, -1):
                if grid[i][j] == 0:
                    # 从下方来
                    if i < n - 1:
                        dp[i][j] = min(dp[i][j], dp[i+1][j] + 1)
                    # 从右方来
                    if j < n - 1:
                        dp[i][j] = min(dp[i][j], dp[i][j+1] + 1)
                    
                    # 更新最大距离
                    if dp[i][j] < INF:
                        max_dist = max(max_dist, dp[i][j])
        
        return max_dist
```

### 方法四：简化版 BFS

```python
from typing import List
from collections import deque

class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        """
        简化代码，直接在原数组上标记
        """
        n = len(grid)
        queue = deque((i, j) for i in range(n) for j in range(n) if grid[i][j] == 1)
        
        if len(queue) == 0 or len(queue) == n * n:
            return -1
        
        dist = -1
        while queue:
            dist += 1
            for _ in range(len(queue)):
                x, y = queue.popleft()
                for dx, dy in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] == 0:
                        grid[nx][ny] = 1
                        queue.append((nx, ny))
        
        return dist
```

## 复杂度分析

**BFS 方法：**
- 时间复杂度：`O(n^2)`，每个单元格最多访问一次
- 空间复杂度：`O(n^2)`，队列最多存储所有单元格

**动态规划方法：**
- 时间复杂度：`O(n^2)`，需要两次遍历
- 空间复杂度：`O(n^2)`，dp 数组

## 关键点总结

1. **多源 BFS 思想**：将多个起点同时加入队列，一起扩散，是处理"到多个点的最短距离"问题的标准方法

2. **BFS 的层次性**：BFS 天然按距离层次扩散，第一次到达的距离就是最短距离

3. **空间优化**：可以直接在原数组上标记已访问，避免额外的 visited 数组

4. **边界情况处理**：注意全是陆地或全是海洋的情况

5. **动态规划思路**：曼哈顿距离可以分解为水平和垂直方向，通过两次遍历更新

## 易错点

1. **单源 BFS 错误**：
   ```python
   # 错误：从每个海洋单元格分别 BFS，复杂度过高
   for each ocean cell:
       bfs to find nearest land
   ```

2. **距离计算错误**：
   ```python
   # 错误：忘记 BFS 的第一层是起点本身，距离为 0
   distance = 0  # 应该初始化为 -1 或在循环中处理
   ```

3. **边界条件遗漏**：忘记检查全是陆地或全是海洋的情况

4. **重复访问**：没有标记已访问的单元格，导致重复加入队列

5. **方向数组错误**：四个方向的 dx, dy 要配对正确
