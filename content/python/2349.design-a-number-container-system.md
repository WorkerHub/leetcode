## 题目描述

设计一个**数字容器系统**，可以在系统中插入数字并返回系统中给定数字的最小索引。

实现 `NumberContainers` 类：

- `NumberContainers()`：初始化数字容器系统。
- `void change(int index, int number)`：在索引 `index` 处填入 `number`。如果该索引已有数字，则替换为新数字。
- `int find(int number)`：返回系统中 `number` 的最小索引，若不存在则返回 `-1`。

**示例：**
```
["NumberContainers", "find", "change", "change", "change", "change", "find", "change", "find"]
[[], [10], [2, 10], [1, 10], [3, 10], [5, 10], [10], [1, 20], [10]]
输出：[null, -1, null, null, null, null, 1, null, 2]
```

**提示：**
- `1 <= index, number <= 10^9`
- 最多调用 `find` 和 `change` 各 `10^5` 次

## 解题思路

维护两个映射：
1. `idx_to_num`：`index -> number`，记录每个索引当前存放的数字。
2. `num_to_indices`：`number -> 有序索引集合`，记录每个数字对应的所有索引。

`change(index, number)`：
- 若 index 已有旧数字，从旧数字的索引集合中移除 index。
- 将 index 加入新数字的索引集合。

`find(number)`：返回 `num_to_indices[number]` 的最小值（集合为空则 -1）。

## 代码实现

### 方法一：哈希表 + 有序集合（推荐，使用 SortedList）

```python
from sortedcontainers import SortedList
from collections import defaultdict

class NumberContainers:
    def __init__(self):
        self.idx_to_num = {}                  # index -> number
        self.num_to_idx = defaultdict(SortedList)  # number -> sorted indices

    def change(self, index: int, number: int) -> None:
        if index in self.idx_to_num:
            old_num = self.idx_to_num[index]
            if old_num == number:
                return  # 没有变化
            # 从旧数字的集合中移除
            self.num_to_idx[old_num].remove(index)
        self.idx_to_num[index] = number
        self.num_to_idx[number].add(index)

    def find(self, number: int) -> int:
        sl = self.num_to_idx.get(number)
        if sl:
            return sl[0]
        return -1
```

### 方法二：哈希表 + 最小堆（懒删除）

```python
import heapq
from collections import defaultdict

class NumberContainers:
    def __init__(self):
        self.idx_to_num = {}         # index -> number
        self.num_to_heap = defaultdict(list)  # number -> min-heap of indices

    def change(self, index: int, number: int) -> None:
        self.idx_to_num[index] = number
        heapq.heappush(self.num_to_heap[number], index)
        # 旧值不从堆中删除（懒删除）

    def find(self, number: int) -> int:
        heap = self.num_to_heap.get(number, [])
        # 弹出无效的堆顶（该索引的当前数字不是 number）
        while heap and self.idx_to_num.get(heap[0]) != number:
            heapq.heappop(heap)
        return heap[0] if heap else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 有序集合 | change O(log n)，find O(1) | O(n) |
| 懒删除堆 | change O(log n)，find 均摊 O(log n) | O(n) |

## 关键点总结

1. `change` 需要更新两个映射：删除旧关联、建立新关联。
2. 懒删除堆：堆中可能有过时的索引，`find` 时弹出不合法的堆顶。
3. SortedList 的 `add` 和 `remove` 都是 O(log n)，`[0]` 取最小值 O(1)。

## 易错点

- 懒删除堆中，判断有效性用 `idx_to_num.get(heap[0]) != number`。
- `change` 中若 index 原来就存 number，则无需做任何修改（SortedList 会重复添加，需提前检查）。
