## 题目描述

给你一个字符串 `word` 和整数 `k`。`word` 的长度是 `k` 的倍数。

每次操作可以将 `word[i * k .. (i+1)*k - 1]` 这一段（长度为 k 的块）替换为任意字符串。

返回使 `word` 变为 **k 周期字符串**（即所有长度为 k 的块都相同）所需的 **最少** 操作次数。

**示例 1：**
```
输入：word = "leetcodeleet", k = 4
输出：1
解释：块为 "leet", "code", "leet"，将 "code" 替换为 "leet" 只需 1 次。
```

**提示：**
- `1 <= k <= word.length <= 10^6`
- `k` 整除 `word.length`

## 解题思路

将 word 切分为 n/k 个长度为 k 的块，统计每种块出现的频率，频率最高的块出现了 max_count 次，其余的块都需要替换，操作次数 = (n/k) - max_count。

## Python 代码实现

### 方法一：哈希计数（推荐）

```python
from collections import Counter

class Solution:
    def minimumOperationsToMakeKPeriodic(self, word: str, k: int) -> int:
        n = len(word)
        blocks = [word[i:i+k] for i in range(0, n, k)]
        # 出现次数最多的块不需要替换
        max_count = max(Counter(blocks).values())
        return len(blocks) - max_count
```

### 方法二：直接 Counter

```python
from collections import Counter

class Solution:
    def minimumOperationsToMakeKPeriodic(self, word: str, k: int) -> int:
        cnt = Counter(word[i:i+k] for i in range(0, len(word), k))
        return len(word) // k - max(cnt.values())
```

## 复杂度分析

- 时间复杂度：O(n)，切分和统计
- 空间复杂度：O(n)，存储所有块

## 关键点总结

1. 将字符串切分为等长块，找出现最多的块
2. 最少操作数 = 总块数 - 最大频率
3. 贪心：保留出现最多的块，其余全替换成它

## 易错点

1. 字符串切片 `word[i:i+k]` 要注意步长
2. 答案是总块数减最大频率，不是最大频率本身
