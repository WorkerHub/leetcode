## 题目描述

给你一个字符串 `num`，仅含数字字符。你需要把 `num` 分割成若干个**非空子字符串**，使得这些子字符串表示的数字形成一个**非递减序列**，且不含前导零（除非本身是 "0"）。

返回合法分割方案的数量，对 `10^9+7` 取余。

**示例 1：**
```
输入：num = "327"
输出：2
解释："3","2","7" 不合法（非递减），合法的有 "327", "3","27"
```

**示例 2：**
```
输入：num = "094"
输出：0
解释：所有分割都含前导零
```

**示例 3：**
```
输入：num = "0"
输出：1
```

**提示：**
- `1 <= num.length <= 3500`

---

## 解题思路

### 核心思想：区间 DP + LCP（最长公共前缀）

设 `dp[i][j]` = 把 `num[0..j-1]` 分割，最后一段为 `num[i..j-1]` 时的方案数。

转移：枚举倒数第二段的起始 `k`，最后一段 `[i,j)` 必须 >= 倒数第二段 `[k,i)`。

比较两段数字大小：
1. 长度不同 → 长的更大
2. 长度相同 → 需要逐字符比较（用 LCP 加速）

**LCP（最长公共前缀）**：`lcp[i][j]` = `num[i:]` 和 `num[j:]` 的最长公共前缀长度，O(n²) 预处理。

比较 `num[k..i-1]` 和 `num[i..j-1]`（同长 `L=i-k`）：从公共前缀 `lcp[k][i]` 处开始，若 `lcp[k][i] >= L` 则相等，否则比较 `num[k+lcp[k][i]]` 与 `num[i+lcp[k][i]]`。

## 代码实现

### 方法一：区间 DP + LCP（推荐）

```python
class Solution:
    def numberOfCombinations(self, num: str) -> int:
        MOD = 10**9 + 7
        n = len(num)

        # 预处理：lcp[i][j] = num[i:] 和 num[j:] 的最长公共前缀
        lcp = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if num[i] == num[j]:
                    lcp[i][j] = lcp[i + 1][j + 1] + 1
                else:
                    lcp[i][j] = 0

        def compare(i, j, length) -> bool:
            """判断 num[i:i+length] <= num[j:j+length]"""
            common = lcp[i][j]
            if common >= length:
                return True  # 完全相等
            return num[i + common] < num[j + common]

        # dp[i][j] = 最后一段起点为 i、终点为 j（不含）的方案数
        # 前缀和 prefix[i][j] = sum(dp[k][i] for k 合法)
        # 直接用前缀和优化转移
        # dp[i][j]: num[0..j-1] 的分割，最后一段为 num[i..j-1]
        dp = [[0] * (n + 1) for _ in range(n)]
        prefix = [[0] * (n + 1) for _ in range(n)]

        for j in range(1, n + 1):
            for i in range(j - 1, -1, -1):
                # 最后一段 num[i..j-1]，长度 L = j - i
                L = j - i
                if num[i] == '0':
                    # 前导零不合法（仅单个 '0' 允许）
                    dp[i][j] = 0
                    continue
                if i == 0:
                    # 整个 num[0..j-1] 作为一段，方案数 = 1
                    dp[i][j] = 1
                else:
                    # 枚举倒数第二段终点在 i，起点在 k
                    # 即 num[k..i-1] <= num[i..j-1]
                    # 相同长度 L: k = i - L，需 num[k..i-1] <= num[i..j-1]
                    # 较短长度（< L）的段均满足，前缀和处理
                    # 前缀和 prefix[i][j] = sum(dp[k][i] for k in [j-len_last, i])

                    # 同长段 k = i - L
                    k = i - L
                    same_len_ways = 0
                    if k >= 0 and num[k] != '0':
                        if compare(k, i, L):
                            same_len_ways = dp[k][i]

                    # 较短段：起点 k in [i - L + 1, i - 1]，即长度 < L
                    # 这些段都满足（数字更短则更小），sum dp[k][i] for k in [i-L+1, i]
                    # 用前缀和 prefix[i][j] = sum(dp[0][i]+...+dp[j-1][i])
                    # 较短段的 k 范围：[max(0, i-L+1), i-1]（长度 1 到 L-1）
                    shorter_ways = prefix[i][i] - (prefix[i][max(0, i - L)] if i - L >= 0 else 0)
                    # prefix[i][r] - prefix[i][l] = sum(dp[l..r-1][i])

                    dp[i][j] = (same_len_ways + shorter_ways) % MOD

            # 更新前缀和 prefix[?][j]（存 dp[0..j-1][j] 的前缀和）
            # 实际上 prefix[i][j] 表示 dp[0][i]+...+dp[j-1][i]
            # 这里重新理解：prefix[col][row]
            # prefix[i][r] = dp[0][i] + dp[1][i] + ... + dp[r-1][i]
            for i in range(n):
                prefix[i][j] = (prefix[i][j - 1] + dp[j - 1][i]) % MOD

        # 答案：所有合法的最后一段起点 i
        return sum(dp[i][n] for i in range(n)) % MOD
```

### 方法二：简化版（小数据范围暴力）

```python
class Solution:
    def numberOfCombinations(self, num: str) -> int:
        MOD = 10**9 + 7
        n = len(num)
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(start, prev_start, prev_end):
            """从 start 开始分割，前一段为 num[prev_start:prev_end]"""
            if start == n:
                return 1
            total = 0
            for end in range(start + 1, n + 1):
                seg = num[start:end]
                prev = num[prev_start:prev_end]
                # 无前导零
                if len(seg) > 1 and seg[0] == '0':
                    break
                # 比较大小
                if len(seg) > len(prev) or (len(seg) == len(prev) and seg >= prev):
                    total += dp(end, start, end)
            return total % MOD

        total = 0
        for end in range(1, n + 1):
            seg = num[:end]
            if len(seg) > 1 and seg[0] == '0':
                break
            total += dp(end, 0, end)
        return total % MOD
```

| 方法一 | O(n²) | O(n²) |
| 方法二（暴力） | O(n³) | O(n²) |

## 关键点总结

1. `dp[i][j]` 定义最后一段起点 + 终点，前缀和优化同长度比较
2. LCP 数组使得字符串比较 O(1)
3. 含前导零的段必须跳过（除非长度为 1 且为 "0"）

---

## 易错点

- 前导零检查：`num[i] == '0'` 时 `dp[i][j] = 0`
- LCP 比较需注意边界（`common >= length` 说明完全相等）
- 前缀和下标方向容易混淆
