## 题目描述

给你一个仅由 `'['` 和 `']'` 组成的字符串 `s`，且长度为偶数。

每次操作可以交换字符串中**任意两个字符**。

返回使 `s` **平衡**所需的**最少交换次数**。

**示例 1：**
```
输入：s = "]["
输出：1
解释：交换位置 0 和 1，得到 "[]"
```

**示例 2：**
```
输入：s = "]]][[["
输出：2
解释：交换 (0,3) 和 (1,4)，得到 "[[]][]"... 共 2 次
```

**提示：**
- `n == s.length`，`2 <= n <= 10^6`，n 为偶数
- `'['` 和 `']'` 各占一半

---

## 解题思路

### 核心思想：统计不匹配的括号对

用栈匹配括号，最终栈中剩下的是形如 `]]...[[` 的不匹配括号（设有 2k 个）。

对于 k 对不匹配的 `][`，每次交换可以修复一对（交换一个 `]` 和一个 `[`），因此需要 `ceil(k/2)` 次交换。

---

## 代码实现

### 方法一：栈统计不匹配数（推荐）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        # 用栈匹配，统计最终未匹配的 ']' 数
        unmatched = 0  # 多余的 ']' 数

        for c in s:
            if c == '[':
                unmatched -= 1  # '[' 可以消除一个待匹配的 ']'
            else:
                unmatched += 1  # 多了一个 ']'
            unmatched = max(0, unmatched)

        # unmatched 是多余的 ']' 数，成对的 ']...[' 需要 ceil(k/2) 次交换
        return (unmatched + 1) // 2
```

### 方法二：双指针（贪心）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        # 双指针：左指针找多余的 ']'，右指针找对应的 '['
        n = len(s)
        left, right = 0, n - 1
        swaps = 0

        while left < right:
            # 找左侧多余的 ']'
            while left < right and s[left] == '[':
                left += 1
            # 找右侧多余的 '['
            while left < right and s[right] == ']':
                right -= 1
            if left < right:
                swaps += 1
                left += 1
                right -= 1

        return swaps
```

### 方法三：数学公式（最简洁）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        # 扫描统计最大未匹配 ']' 数
        bal = 0
        unmatched = 0
        for c in s:
            bal += 1 if c == '[' else -1
            unmatched = max(unmatched, -bal)
        # 每次交换修复 2 个不匹配，所以 ceil(unmatched / 2)
        return (unmatched + 1) // 2
```

|------|-----------|-----------|
| 方法一 | O(n) | O(1) |
| 方法二 | O(n) | O(1) |
| 方法三 | O(n) | O(1) |

---

## 关键点总结

1. 统计扫描过程中最大的"未匹配 ]"数量 k
2. 每次交换可以修复 2 个不匹配，需要 `ceil(k/2)` 次
3. `(k + 1) // 2` 实现向上取整

---

## 易错点

- 最终需要的交换次数不是不匹配对数，而是 `ceil(不匹配对数 / 2)`
- 字符串中 `[` 和 `]` 各占一半，保证有解
