## 题目描述

给定一个不为空的二叉搜索树和一个目标值 `target`，请在该二叉搜索树中找到最接近目标值的节点值。

**注意：**
- 给定的目标值 `target` 是一个浮点数
- 题目保证在该二叉搜索树中只会存在一个最接近目标值的数

**示例 1：**
```
输入: root = [4,2,5,1,3], target = 3.714286
输出: 4

    4
   / \
  2   5
 / \
1   3
```

**示例 2：**
```
输入: root = [1], target = 4.428571
输出: 1
```

**提示：**
- 树中节点数在范围 `[1, 10^4]` 内
- `0 <= Node.val <= 10^9`
- `-10^9 <= target <= 10^9`

## 解题思路

利用**二叉搜索树（BST）的性质**可以高效求解。

**BST 性质：**
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点

**核心思路：**

1. **二分搜索**：
   - 如果 target < root.val，向左子树搜索
   - 如果 target > root.val，向右子树搜索
   - 每次比较当前节点是否更接近 target

2. **中序遍历**：
   - BST 的中序遍历是升序序列
   - 找到第一个大于等于 target 的节点
   - 比较该节点和前一个节点哪个更接近

3. **递归/迭代**：
   - 递归：自顶向下比较
   - 迭代：使用栈或直接遍历

## Python 代码实现

### 方法一：递归 + 二分搜索（推荐）⭐

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        # 记录最接近的值
        self.closest = root.val
        
        def dfs(node: TreeNode):
            if not node:
                return
            
            # 更新最接近的值
            if abs(node.val - target) < abs(self.closest - target):
                self.closest = node.val
            
            # 利用 BST 性质进行二分搜索
            if target < node.val:
                dfs(node.left)
            else:
                dfs(node.right)
        
        dfs(root)
        return self.closest
```

### 方法二：迭代二分搜索

```python
class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        closest = root.val
        
        while root:
            # 更新最接近的值
            if abs(root.val - target) < abs(closest - target):
                closest = root.val
            
            # 二分搜索
            if target < root.val:
                root = root.left
            else:
                root = root.right
        
        return closest
```

### 方法三：简化的迭代

```python
class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        closest = root.val
        
        while root:
            # 比较并更新
            closest = min(root.val, closest, key=lambda x: abs(x - target))
            
            # 移动到下一个节点
            root = root.left if target < root.val else root.right
        
        return closest
```

### 方法四：中序遍历

```python
class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        """
        中序遍历 BST 得到升序序列
        找到第一个 >= target 的节点
        """
        stack = []
        prev = float('-inf')
        
        while stack or root:
            # 一直向左
            while root:
                stack.append(root)
                root = root.left
            
            # 处理当前节点
            root = stack.pop()
            
            # 如果当前值 >= target，比较前后两个值
            if root.val >= target:
                return min(prev, root.val, key=lambda x: abs(x - target))
            
            prev = root.val
            root = root.right
        
        # 所有值都 < target，返回最后一个
        return prev
```

### 方法五：递归（返回值方式）

```python
class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        def dfs(node: TreeNode) -> int:
            if not node:
                return float('inf')  # 返回一个不可能的值
            
            # 递归搜索左或右子树
            if target < node.val:
                left_closest = dfs(node.left)
                return min(node.val, left_closest, key=lambda x: abs(x - target))
            else:
                right_closest = dfs(node.right)
                return min(node.val, right_closest, key=lambda x: abs(x - target))
        
        result = dfs(root)
        return result if result != float('inf') else root.val
```

### 方法六：暴力遍历（不推荐）

```python
class Solution:
    def closestValue(self, root: TreeNode, target: float) -> int:
        """
        遍历所有节点，找最接近的
        没有利用 BST 性质，效率低
        """
        self.closest = root.val
        
        def traverse(node: TreeNode):
            if not node:
                return
            
            if abs(node.val - target) < abs(self.closest - target):
                self.closest = node.val
            
            traverse(node.left)
            traverse(node.right)
        
        traverse(root)
        return self.closest
```

## 复杂度分析

### 方法一、二、三、五（二分搜索）
- **时间复杂度**：O(h)
  - h 是树的高度
  - 平衡树：O(log n)
  - 最坏情况（链状树）：O(n)
  
- **空间复杂度**：
  - 递归：O(h)，递归栈
  - 迭代：O(1)

### 方法四（中序遍历）
- **时间复杂度**：O(n)，最坏需要遍历所有节点
- **空间复杂度**：O(h)，栈空间

### 方法六（暴力遍历）
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **利用 BST 性质**：
   - target < node.val → 向左搜索
   - target > node.val → 向右搜索
   - 时间复杂度从 O(n) 降到 O(h)

2. **比较标准**：
   - 使用 `abs(node.val - target)` 计算距离
   - 选择距离更小的节点

3. **迭代 vs 递归**：
   - 迭代空间复杂度更优（O(1)）
   - 递归代码更简洁

4. **中序遍历技巧**：
   - BST 中序遍历是升序
   - 找到第一个 >= target 的位置
   - 比较前后两个值

5. **边界处理**：
   - 空节点判断
   - 只有一个节点的情况

## 易错点

1. **忘记利用 BST 性质**：
   ```python
   # 错误：遍历所有节点
   traverse(node.left)
   traverse(node.right)
   
   # 正确：二分搜索
   if target < node.val:
       dfs(node.left)
   else:
       dfs(node.right)
   ```

2. **距离计算错误**：
   ```python
   # 正确：要取绝对值
   abs(node.val - target)
   
   # 错误：可能为负数
   node.val - target
   ```

3. **相等情况处理**：
   ```python
   # target == node.val 时，可以向左或向右
   # 通常向右（或直接返回）
   if target < node.val:
       root = root.left
   else:  # 包括等于的情况
       root = root.right
   ```

4. **初始值设置**：
   ```python
   # 正确：初始化为根节点值
   closest = root.val
   
   # 错误：初始化为 0 或 float('inf')
   # 可能导致根节点本身就是答案时被忽略
   ```

5. **中序遍历边界**：
   - 所有值都小于 target
   - 所有值都大于 target
