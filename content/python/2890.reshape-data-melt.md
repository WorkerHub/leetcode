## 题目描述

给定一个 DataFrame `report`（宽格式，每列是一个季度），将其转换为长格式（每行一个季度记录）。

**示例：**
```
输入（宽格式）：
| product | Q1 | Q2 | Q3 | Q4 |
|---------|----|----|----|----|
| ...     |    |    |    |    |

输出（长格式）：
| product | quarter | sales |
|---------|---------|-------|
| ...     | Q1      | ...   |
| ...     | Q2      | ...   |
```

## Python 代码实现

### 方法一：pd.melt（推荐）

```python
import pandas as pd

def meltTable(report: pd.DataFrame) -> pd.DataFrame:
    # 宽格式转长格式
    # id_vars: 保持不动的列
    # var_name: 列名的变量名
    # value_name: 值的列名
    return pd.melt(
        report,
        id_vars='product',
        var_name='quarter',
        value_name='sales'
    )
```

### 方法二：stack 方法

```python
import pandas as pd

def meltTable(report: pd.DataFrame) -> pd.DataFrame:
    return (report
            .set_index('product')
            .stack()
            .reset_index()
            .rename(columns={'level_1': 'quarter', 0: 'sales'}))
```

## 复杂度分析

- 时间复杂度：O(n × m)，n 行 m 列
- 空间复杂度：O(n × m)

## 关键点总结

1. `pd.melt()` 将宽格式转为长格式（与 pivot 相反）
2. `id_vars`：不参与转换的列（保留为 ID）
3. `var_name`：列名转换后的新列名；`value_name`：值的新列名
