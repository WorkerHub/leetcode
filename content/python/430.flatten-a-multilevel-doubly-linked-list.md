## 题目描述

你会得到一个双向链表，除了 next 和 prev 指针之外，它还有一个子链表指针，可能指向单独的双向链表。这些子列表可能有一个或多个自己的子列表，依此类推，以生成如下面示例所示的多层数据结构。

给定位于列表第一级的头节点，请扁平化列表，即将这样的多级双向链表展平成一个单层双向链表。使得所有节点都出现在单层双链表中。

**示例 1：**
```
输入：head = [1,2,3,4,5,6,null,null,null,7,8,9,10,null,null,11,12]
输出：[1,2,3,7,8,11,12,9,10,4,5,6]
解释：
输入的多级列表如下图所示：

 1---2---3---4---5---6--NULL
         |
         7---8---9---10--NULL
             |
             11--12--NULL

扁平化后的链表如下：
1-2-3-7-8-11-12-9-10-4-5-6-NULL
```

**示例 2：**
```
输入：head = [1,2,null,3]
输出：[1,3,2]
解释：
输入的多级列表如下：

  1---2---NULL
  |
  3---NULL
```

**示例 3：**
```
输入：head = []
输出：[]
```

**提示：**
- 节点数目不超过 1000
- `1 <= Node.val <= 10^5`

**扁平化规则：**
如果节点 p 有子链表，则子链表应该出现在 p 和 p.next 之间。p.next 的节点应该在子链表之后。

## 解题思路

这道题要求将多层双向链表扁平化。核心思想是使用深度优先搜索（DFS）。

**关键观察：**
1. 遇到有 child 的节点时，应该先展开 child 链表
2. child 链表展开后，再连接原来的 next 节点
3. 展开过程类似于前序遍历

**算法流程（递归）：**
1. 从头节点开始遍历
2. 如果当前节点有 child：
   - 记录 next 节点（可能为空）
   - 递归展开 child 链表，得到 child 链表的尾节点
   - 连接：当前节点 -> child 链表
   - 连接：child 链表尾节点 -> 原 next 节点
   - 将 child 指针置空
3. 继续处理下一个节点

## Python 代码实现

### 方法一：递归 DFS ⭐ 推荐

```python
class Node:
    def __init__(self, val, prev=None, next=None, child=None):
        self.val = val
        self.prev = prev
        self.next = next
        self.child = child

class Solution:
    def flatten(self, head: 'Node') -> 'Node':
        if not head:
            return None
        
        def flatten_and_get_tail(node):
            """展开链表并返回尾节点"""
            current = node
            tail = None
            
            while current:
                next_node = current.next
                
                # 如果有子链表
                if current.child:
                    # 递归展开子链表，获取子链表的尾节点
                    child_tail = flatten_and_get_tail(current.child)
                    
                    # 连接当前节点和子链表
                    current.next = current.child
                    current.child.prev = current
                    
                    # 连接子链表尾节点和原 next 节点
                    if next_node:
                        child_tail.next = next_node
                        next_node.prev = child_tail
                    
                    # 清空 child 指针
                    current.child = None
                    
                    # 更新尾节点
                    tail = child_tail
                else:
                    tail = current
                
                current = next_node
            
            return tail
        
        flatten_and_get_tail(head)
        return head
```

### 方法二：迭代 + 栈

```python
class Solution:
    def flatten(self, head: 'Node') -> 'Node':
        if not head:
            return None
        
        stack = [head]
        prev = None
        
        while stack:
            current = stack.pop()
            
            # 建立与前一个节点的连接
            if prev:
                prev.next = current
                current.prev = prev
            
            # 如果有 next，先入栈（后处理）
            if current.next:
                stack.append(current.next)
            
            # 如果有 child，后入栈（先处理）
            if current.child:
                stack.append(current.child)
                current.child = None  # 清空 child 指针
            
            prev = current
        
        return head
```

### 方法三：简洁递归版

```python
class Solution:
    def flatten(self, head: 'Node') -> 'Node':
        def dfs(node):
            """返回链表的尾节点"""
            if not node:
                return None
            
            tail = node
            
            while node:
                next_node = node.next
                
                if node.child:
                    # 展开子链表
                    child_tail = dfs(node.child)
                    
                    # 插入子链表
                    node.next = node.child
                    node.child.prev = node
                    node.child = None
                    
                    # 连接尾部
                    if next_node:
                        child_tail.next = next_node
                        next_node.prev = child_tail
                    
                    tail = child_tail
                else:
                    tail = node
                
                node = next_node
            
            return tail
        
        dfs(head)
        return head
```

### 方法四：迭代简化版

```python
class Solution:
    def flatten(self, head: 'Node') -> 'Node':
        if not head:
            return None
        
        current = head
        
        while current:
            # 如果没有子链表，继续
            if not current.child:
                current = current.next
                continue
            
            # 找到子链表的尾节点
            child_tail = current.child
            while child_tail.next:
                child_tail = child_tail.next
            
            # 连接子链表
            child_tail.next = current.next
            if current.next:
                current.next.prev = child_tail
            
            current.next = current.child
            current.child.prev = current
            current.child = None
            
            current = current.next
        
        return head
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是链表中的节点总数
  - 每个节点访问一次
- 空间复杂度：
  - 方法一、三（递归）：O(h)，h 是链表的层数（递归栈）
  - 方法二（栈）：O(h)
  - 方法四（迭代）：O(1)

## 关键点总结

1. **DFS 思想**：优先处理子链表，类似前序遍历
2. **指针操作**：需要同时维护 prev 和 next 指针
3. **child 处理**：插入子链表后要清空 child 指针
4. **尾节点追踪**：需要找到子链表的尾节点以连接后续部分
5. **双向连接**：不要忘记同时设置 prev 和 next

## 易错点

1. **忘记清空 child**：插入子链表后必须将 child 置为 None
2. **prev 指针遗漏**：双向链表要同时设置 prev 和 next
3. **尾节点连接**：子链表的尾节点要连接到原 next 节点
4. **空指针检查**：next 节点可能为空，需要检查
5. **迭代顺序**：使用栈时，要先压 next 再压 child
