## 题目描述

给你一个 `n * n` 矩阵 `grid`，矩阵由若干 `0` 和 `1` 组成。请你用四叉树表示该矩阵。

你需要返回能表示矩阵的四叉树的根节点。

四叉树数据结构中，每个内部节点只有四个子节点。此外，每个节点都有两个属性：
- `val`：储存叶子节点所代表的区域的值。1 对应 True，0 对应 False
- `isLeaf`：当这个节点是一个叶子节点时为 True，如果它有 4 个子节点则为 False

```
class Node {
    public boolean val;
    public boolean isLeaf;
    public Node topLeft;
    public Node topRight;
    public Node bottomLeft;
    public Node bottomRight;
}
```

我们可以按以下步骤为二维区域构建四叉树：
1. 如果当前网格的值相同（即，全为 `0` 或者全为 `1`），将 `isLeaf` 设为 True，将 `val` 设为网格相应的值，并将四个子节点都设为 Null 然后停止。
2. 如果当前网格的值不同，将 `isLeaf` 设为 False，将 `val` 设为任意值，然后如下图所示，将当前网格划分为四个子网格。
3. 使用适当的子网格递归每个子节点。


**提示：**
- `n == grid.length == grid[i].length`
- `n == 2^x` 其中 `0 <= x <= 6`

## 解题思路

这道题要求构建四叉树来表示二维矩阵。核心思想是分治递归。

**关键观察：**
1. 如果区域内所有值相同，创建叶子节点
2. 如果区域内值不同，将区域四等分，递归构建四个子节点
3. 四个子区域分别是：左上、右上、左下、右下

**算法流程：**
1. 检查当前区域是否所有值相同
2. 如果相同，创建叶子节点
3. 如果不同，将区域分成四个子区域
4. 递归构建四个子节点
5. 创建非叶子节点，连接四个子节点

## Python 代码实现

### 方法一：分治递归 ⭐ 推荐

```python
from typing import List

class Node:
    def __init__(self, val, isLeaf, topLeft, topRight, bottomLeft, bottomRight):
        self.val = val
        self.isLeaf = isLeaf
        self.topLeft = topLeft
        self.topRight = topRight
        self.bottomLeft = bottomLeft
        self.bottomRight = bottomRight

class Solution:
    def construct(self, grid: List[List[int]]) -> 'Node':
        def is_all_same(x, y, length):
            """检查区域内是否所有值相同"""
            val = grid[x][y]
            for i in range(x, x + length):
                for j in range(y, y + length):
                    if grid[i][j] != val:
                        return False
            return True
        
        def build(x, y, length):
            """递归构建四叉树"""
            # 如果区域内所有值相同，创建叶子节点
            if is_all_same(x, y, length):
                return Node(
                    val=grid[x][y] == 1,
                    isLeaf=True,
                    topLeft=None,
                    topRight=None,
                    bottomLeft=None,
                    bottomRight=None
                )
            
            # 值不同，分成四个子区域
            half = length // 2
            
            # 递归构建四个子节点
            top_left = build(x, y, half)
            top_right = build(x, y + half, half)
            bottom_left = build(x + half, y, half)
            bottom_right = build(x + half, y + half, half)
            
            # 创建非叶子节点
            return Node(
                val=True,  # 非叶子节点的值可以是任意值
                isLeaf=False,
                topLeft=top_left,
                topRight=top_right,
                bottomLeft=bottom_left,
                bottomRight=bottom_right
            )
        
        n = len(grid)
        return build(0, 0, n)
```

### 方法二：优化版（使用前缀和检查）

```python
from typing import List

class Solution:
    def construct(self, grid: List[List[int]]) -> 'Node':
        n = len(grid)
        
        # 构建前缀和数组，用于快速判断区域是否全0或全1
        prefix = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                prefix[i][j] = (grid[i-1][j-1] + 
                               prefix[i-1][j] + 
                               prefix[i][j-1] - 
                               prefix[i-1][j-1])
        
        def get_sum(x, y, length):
            """获取区域的和"""
            x2, y2 = x + length, y + length
            return (prefix[x2][y2] - 
                   prefix[x][y2] - 
                   prefix[x2][y] + 
                   prefix[x][y])
        
        def build(x, y, length):
            total = get_sum(x, y, length)
            area = length * length
            
            # 全1或全0
            if total == 0 or total == area:
                return Node(
                    val=total == area,
                    isLeaf=True,
                    topLeft=None,
                    topRight=None,
                    bottomLeft=None,
                    bottomRight=None
                )
            
            # 分成四个子区域
            half = length // 2
            return Node(
                val=True,
                isLeaf=False,
                topLeft=build(x, y, half),
                topRight=build(x, y + half, half),
                bottomLeft=build(x + half, y, half),
                bottomRight=build(x + half, y + half, half)
            )
        
        return build(0, 0, n)
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def construct(self, grid: List[List[int]]) -> 'Node':
        def dfs(x, y, n):
            # 检查是否全部相同
            val = grid[x][y]
            all_same = True
            
            for i in range(x, x + n):
                for j in range(y, y + n):
                    if grid[i][j] != val:
                        all_same = False
                        break
                if not all_same:
                    break
            
            # 叶子节点
            if all_same:
                return Node(val == 1, True, None, None, None, None)
            
            # 非叶子节点
            half = n // 2
            return Node(
                True,
                False,
                dfs(x, y, half),
                dfs(x, y + half, half),
                dfs(x + half, y, half),
                dfs(x + half, y + half, half)
            )
        
        return dfs(0, 0, len(grid))
```

## 复杂度分析

**方法一：基础分治**
- 时间复杂度：O(n² × log n)
  - 每层递归需要 O(n²) 检查是否相同
  - 递归深度为 O(log n)
- 空间复杂度：O(log n)，递归栈空间

**方法二：前缀和优化**
- 时间复杂度：O(n²)
  - 构建前缀和：O(n²)
  - 递归构建：每次判断 O(1)，共 O(n²) 个节点
- 空间复杂度：O(n²)，前缀和数组

## 关键点总结

1. **分治思想**：将大问题分解为四个相同的小问题
2. **递归终止条件**：区域内所有值相同时创建叶子节点
3. **区域划分**：每次将区域四等分（左上、右上、左下、右下）
4. **前缀和优化**：使用前缀和快速判断区域是否全0或全1
5. **节点属性**：叶子节点的 isLeaf=True，非叶子节点的 isLeaf=False

## 易错点

1. **边界计算**：划分子区域时，起始坐标和长度要计算正确
2. **叶子节点判断**：只有所有值相同才是叶子节点
3. **坐标系统**：要注意行列索引，避免混淆 x 和 y
4. **非叶子节点的 val**：非叶子节点的 val 可以是任意值
5. **递归顺序**：四个子节点的顺序是固定的（左上、右上、左下、右下）
