## 题目描述

给你一个字符串 `s`，字符串只包含小写英文字母。

对于字符串中每个下标 `i`，定义**镜像字符**为与 `s[i]` 在字母表中距离相同的字符（即 `'a'` 和 `'z'` 互为镜像，`'b'` 和 `'y'` 互为镜像，...，`'m'` 和 `'n'` 互为镜像）。

**得分**的计算方式：对于每个 `i`，若在 `[0, i-1]` 范围内存在某个最近的下标 `j`，使得 `s[j]` 是 `s[i]` 的镜像字符，且 `j` 到 `i` 之间没有被"使用"过，则得 `i - j` 分，同时将 `j` 和 `i` 标记为已使用。

返回总得分。

**示例 1：**

```
输入：s = "aczzx"
输出：5
解释：
- i=0，'a' 的镜像是 'z'，前面没有 'z'，不得分
- i=1，'c' 的镜像是 'x'，前面没有 'x'，不得分
- i=2，'z' 的镜像是 'a'，前面有 'a'（j=0），得分 2-0=2，标记 0 和 2
- i=3，'z' 的镜像是 'a'，前面无未使用的 'a'，不得分
- i=4，'x' 的镜像是 'c'，前面有 'c'（j=1），得分 4-1=3，标记 1 和 4
总分 = 2+3=5
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

对每个字符维护一个栈，存储尚未被匹配的该字符的下标。

处理到位置 `i`：
1. 计算 `s[i]` 的镜像字符 `mirror`
2. 若 `stacks[mirror]` 非空，取出栈顶（最近的未匹配镜像字符位置 `j`），得分 += `i - j`
3. 若 `stacks[mirror]` 为空，将 `i` 压入 `stacks[s[i]]`

## Python 代码实现

### 方法一：26 个栈模拟（推荐）

```python
class Solution:
    def calculateScore(self, s: str) -> int:
        # 每个字母维护一个栈，存未匹配的下标
        stacks = [[] for _ in range(26)]
        score = 0

        for i, ch in enumerate(s):
            c = ord(ch) - ord('a')
            # 镜像字符：'a'<->'z', 'b'<->'y', ..., 即 25-c
            mirror = 25 - c

            if stacks[mirror]:
                # 找到最近的镜像字符，得分并标记已使用
                j = stacks[mirror].pop()
                score += i - j
            else:
                # 没有镜像字符，将自己入栈等待匹配
                stacks[c].append(i)

        return score
```

### 方法二：哈希表版本

```python
from collections import defaultdict

class Solution:
    def calculateScore(self, s: str) -> int:
        # 用字典存储每个字符的未匹配下标栈
        stacks = defaultdict(list)
        score = 0

        for i, ch in enumerate(s):
            # 镜像字符
            mirror = chr(ord('a') + 25 - (ord(ch) - ord('a')))

            if stacks[mirror]:
                j = stacks[mirror].pop()
                score += i - j
            else:
                stacks[ch].append(i)

        return score
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符最多入栈出栈各一次
- 空间复杂度：O(n)，栈的总大小

## 关键点总结

1. 镜像字符关系：第 k 个字母（0-indexed）的镜像是第 (25-k) 个字母
2. 用栈匹配"最近的"未使用镜像字符
3. 每次匹配时，栈顶是最近的镜像字符下标

## 图解示例

```
s = "aczzx"
stacks 初始全为空

i=0, 'a', mirror='z', stacks['z'] 空 -> 'a' 入栈: stacks['a']=[0]
i=1, 'c', mirror='x', stacks['x'] 空 -> 'c' 入栈: stacks['c']=[1]
i=2, 'z', mirror='a', stacks['a']=[0] 非空 -> j=0, 得分 2, stacks['a']=[]
i=3, 'z', mirror='a', stacks['a'] 空 -> 'z' 入栈: stacks['z']=[3]
i=4, 'x', mirror='c', stacks['c']=[1] 非空 -> j=1, 得分 3, stacks['c']=[]

总分 = 5
```

## 易错点

1. 镜像公式：`mirror_index = 25 - char_index`，不是 `26 - char_index`
2. 取的是"最近的"镜像字符（栈顶），而不是最远的
3. 栈存的是下标，不是字符本身
