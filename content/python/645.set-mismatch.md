## 题目描述

集合 `s` 包含从 `1` 到 `n` 的整数。不幸的是，因为数据错误，导致集合里面某一个数字复制了成了集合里面的另外一个数字的值，导致集合**丢失了一个数字**并且**有一个数字重复**。

给定一个数组 `nums` 代表了集合 `S` 发生错误后的结果。

请你找出重复出现的整数，再找到丢失的整数，将它们以数组的形式返回。

**示例 1：**

```
输入：nums = [1,2,2,4]
输出：[2,3]
```

**示例 2：**

```
输入：nums = [1,1]
输出：[1,2]
```

**提示：**

- `2 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`

## 解题思路

找出重复的数和缺失的数。

**方法对比：**
1. 哈希表：O(n) 时间，O(n) 空间
2. 排序：O(n log n) 时间
3. 数学：期望和 vs 实际和
4. 标记法：原地修改

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List
from collections import Counter

class Solution:
    def findErrorNums(self, nums: List[int]) -> List[int]:
        """
        使用计数器找重复和缺失
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        count = Counter(nums)
        
        duplicate = missing = 0
        
        for i in range(1, n + 1):
            if count[i] == 2:
                duplicate = i
            elif count[i] == 0:
                missing = i
        
        return [duplicate, missing]
```

### 方法二：数学方法

```python
class Solution:
    def findErrorNums(self, nums: List[int]) -> List[int]:
        """
        利用数学公式
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(nums)
        
        # 期望和
        expected_sum = n * (n + 1) // 2
        # 实际和
        actual_sum = sum(nums)
        # 去重和
        unique_sum = sum(set(nums))
        
        # 重复数 = 实际和 - 去重和
        duplicate = actual_sum - unique_sum
        # 缺失数 = 期望和 - 去重和
        missing = expected_sum - unique_sum
        
        return [duplicate, missing]
```

### 方法三：标记法（空间最优）

```python
class Solution:
    def findErrorNums(self, nums: List[int]) -> List[int]:
        """
        原地标记
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        duplicate = missing = 0
        
        for num in nums:
            index = abs(num) - 1
            if nums[index] < 0:
                duplicate = abs(num)
            else:
                nums[index] = -nums[index]
        
        for i, num in enumerate(nums):
            if num > 0:
                missing = i + 1
        
        return [duplicate, missing]
```

## 关键点总结

1. **哈希表**：最直观
2. **数学公式**：巧妙利用和的关系
3. **标记法**：空间 O(1)
