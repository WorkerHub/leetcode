## 题目描述

给定一个整数数组 `nums`，返回非空连续子数组的数量，使得子数组中最左侧的元素不大于子数组中的其他元素。

**示例 1：**
```
输入：nums = [1,4,2,5,3]
输出：11
解释：有 11 个有效子数组：[1],[4],[2],[5],[3],[1,4],[1,4,2],[1,4,2,5],[1,4,2,5,3],[4,2],[5,3]。
```

**示例 2：**
```
输入：nums = [3,2,1]
输出：3
解释：有 3 个有效子数组：[3],[2],[1]。
```

**示例 3：**
```
输入：nums = [2,2,2]
输出：6
解释：有 6 个有效子数组：[2],[2],[2],[2,2],[2,2],[2,2,2]。
```

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 10^5`

## 解题思路

这道题的关键是理解"最左侧元素不大于其他元素"的含义：
- 对于以 `nums[i]` 开头的子数组，所有元素都必须 ≥ `nums[i]`

**关键观察：**
- 对于每个位置 `i`，我们需要找到从 `i` 开始，能延伸到的最远位置
- 最远位置就是第一个小于 `nums[i]` 的位置
- 这正是**单调栈**的应用场景

**算法思路：**

**方法一：单调栈**
- 对于每个位置 `i`，找到其右侧第一个小于 `nums[i]` 的位置 `j`
- 以 `i` 开头的有效子数组有 `j - i` 个
- 使用单调递增栈可以在 O(n) 时间内完成

**方法二：暴力**
- 对于每个起始位置 `i`，向右扩展找到所有有效子数组
- 时间复杂度 O(n²)

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        """
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        # next_smaller[i] 表示 nums[i] 右侧第一个小于它的位置
        next_smaller = [n] * n
        stack = []  # 单调递增栈（存储索引）
        
        # 从右向左遍历，找每个位置右侧第一个更小的元素
        for i in range(n - 1, -1, -1):
            # 弹出所有 >= nums[i] 的元素
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            
            # 栈顶元素就是右侧第一个更小的
            if stack:
                next_smaller[i] = stack[-1]
            
            stack.append(i)
        
        # 统计有效子数组数量
        result = 0
        for i in range(n):
            # 以 i 开头的有效子数组数量
            result += next_smaller[i] - i
        
        return result
```

### 方法二：单调栈（从左向右）

```python
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        """
        从左向右使用单调栈
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        result = 0
        stack = []  # 单调递增栈
        
        for i in range(n):
            # 当前元素小于栈顶元素，说明栈顶元素的右边界找到了
            while stack and nums[stack[-1]] > nums[i]:
                idx = stack.pop()
                result += i - idx
            
            stack.append(i)
        
        # 处理栈中剩余元素（它们的右边界是数组末尾）
        while stack:
            idx = stack.pop()
            result += n - idx
        
        return result
```

### 方法三：暴力解法（理解用）

```python
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        """
        暴力解法，用于理解题意
        时间复杂度：O(n²)
        空间复杂度：O(1)
        """
        n = len(nums)
        count = 0
        
        for i in range(n):
            # 从 i 开始，找到所有有效子数组
            for j in range(i, n):
                # 检查 nums[i] 是否是最小的
                if nums[j] < nums[i]:
                    break
                count += 1
        
        return count
```

### 方法四：优化的单调栈（一次遍历）

```python
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        """
        一次遍历，边处理边计数
        """
        result = 0
        stack = []
        nums.append(-1)  # 哨兵，确保所有元素都被处理
        
        for i, num in enumerate(nums):
            while stack and nums[stack[-1]] > num:
                idx = stack.pop()
                result += i - idx
            stack.append(i)
        
        return result
```

## 复杂度分析

**方法一和方法二：单调栈**
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈的空间

**方法三：暴力**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 关键点总结

1. **问题转化**：以 `i` 开头的有效子数组数量 = 右侧第一个更小元素的位置 - i
2. **单调栈应用**：找"下一个更小元素"的经典问题
3. **栈的性质**：维护单调递增栈，可以快速找到边界
4. **两种方向**：从左向右或从右向左遍历都可以

## 易错点

1. **边界处理**：数组末尾的元素，其右边界是 `n`
2. **栈的维护**：要维护的是递增栈还是递减栈
3. **等于的情况**：`nums[i]` 等于右侧元素时，子数组仍然有效
4. **计数方式**：每个位置的贡献是 `right - left`，不要重复计数
