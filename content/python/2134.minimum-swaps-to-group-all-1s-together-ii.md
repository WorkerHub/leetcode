## 题目描述

**循环**数组中，`swap` 操作将相邻两个元素交换。给你一个二进制循环数组 `nums`，返回将数组中**所有 1 聚集在一起**所需的**最少交换次数**。

在循环数组中，最后一个元素和第一个元素相邻。

**示例 1：**
```
输入：nums = [0,1,0,1,1,0,0]
输出：1
解释：将 nums[3] 和 nums[2] 交换，得到 [0,1,1,1,0,0,0]。
```

**示例 2：**
```
输入：nums = [0,1,1,1,0,0,1,1,0]
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i] = 0 or 1`

## 解题思路

**滑动窗口**

设 1 的总个数为 `k`，最终需要将 k 个 1 集中到一个长度为 k 的窗口中。

最少交换次数 = 最少需要将多少个 0 移出长度为 k 的窗口 = k - 窗口内 1 的最大个数。

由于是循环数组，可以将数组复制一份（`nums + nums`），在长度 `2n` 的数组上做滑动窗口，窗口大小为 k。

## 代码实现

### 方法一：滑动窗口（循环展开）（推荐）

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        k = sum(nums)  # 1 的总个数
        if k == 0 or k == n:
            return 0

        # 展开为 2n 长度的数组
        doubled = nums + nums
        # 初始化窗口
        window_ones = sum(doubled[:k])
        max_ones = window_ones

        for i in range(k, 2 * n):
            window_ones += doubled[i] - doubled[i - k]
            max_ones = max(max_ones, window_ones)

        return k - max_ones
```

### 方法二：取模处理循环（原地）

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        k = sum(nums)
        if k == 0 or k == n:
            return 0

        # 初始窗口 [0, k-1]
        ones_in_window = sum(nums[:k])
        max_ones = ones_in_window

        for i in range(1, n):
            # 右移窗口：加入 nums[(i+k-1) % n]，移出 nums[i-1]
            ones_in_window += nums[(i + k - 1) % n] - nums[i - 1]
            max_ones = max(max_ones, ones_in_window)

        return k - max_ones
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(n)（展开）或 O(1)（取模） |

## 关键点总结

1. 问题转化：将 k 个 1 放入一个大小为 k 的窗口，使窗口内 1 最多（移动最少）。
2. 循环数组处理：展开数组为两倍长度，或用取模操作。
3. 答案 = k - 窗口内 1 的最大数量。

## 易错点

- `k == 0` 或 `k == n` 时已经满足条件，直接返回 0。
- 取模方法中窗口右端为 `(i + k - 1) % n`（0-indexed），需仔细计算。
