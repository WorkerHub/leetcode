## 题目描述

整数的 数组形式 `num` 是按照从左到右的顺序表示其数字的数组。

- 例如，对于 `num = 1321`，数组形式是 `[1,3,2,1]`

给定 `num`，整数的 数组形式 ，和整数 `k`，返回 整数 `num + k` 的 数组形式 。

**示例 1：**

```
输入：num = [1,2,0,0], k = 34
输出：[1,2,3,4]
解释：1200 + 34 = 1234
```

**示例 2：**

```
输入：num = [2,7,4], k = 181
输出：[4,5,5]
解释：274 + 181 = 455
```

**示例 3：**

```
输入：num = [2,1,5], k = 806
输出：[1,0,2,1]
解释：215 + 806 = 1021
```

**提示：**

- `1 <= num.length <= 10^4`
- `0 <= num[i] <= 9`
- `num` 不包含任何前导零，除了零本身
- `1 <= k <= 10^4`

## 解题思路

这道题本质上是实现大数加法，类似于我们手工计算加法的过程。

**核心思路：**

1. **逐位相加**：从个位（数组末尾）开始，逐位相加
2. **处理进位**：每次相加后，需要处理进位
3. **处理长度差异**：num 和 k 的长度可能不同

**算法流程：**

1. 从 num 的最后一位开始，依次与 k 的对应位相加
2. 维护一个进位值 carry
3. 将 k 当作一个整数处理，每次取个位（k % 10）参与计算
4. 计算完后 k 除以 10，继续下一位
5. 如果 num 遍历完但 k 还有剩余或还有进位，继续处理

## Python 代码实现

### 方法一：模拟加法过程（推荐）⭐

```python
from typing import List

class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        """
        从右向左逐位相加，模拟手工加法
        时间复杂度：O(max(n, log k))，n 是 num 的长度
        空间复杂度：O(1)，不计结果数组
        """
        result = []
        i = len(num) - 1  # 从 num 的最后一位开始
        
        # 当还有 num 的数字、k 不为 0 时继续
        while i >= 0 or k > 0:
            # 获取当前位的值
            if i >= 0:
                k += num[i]  # 将 num[i] 加到 k 上
                i -= 1
            
            # k 的个位就是当前位的结果
            result.append(k % 10)
            # k 除以 10 准备下一位（相当于进位）
            k //= 10
        
        # 因为是从后往前计算，需要反转结果
        return result[::-1]
```

### 方法二：使用进位变量

```python
class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        """
        显式使用进位变量
        """
        result = []
        carry = k  # 初始进位为 k
        i = len(num) - 1
        
        while i >= 0 or carry > 0:
            # 如果还有 num 的数字，加上它
            if i >= 0:
                carry += num[i]
                i -= 1
            
            # 当前位的值
            result.append(carry % 10)
            # 计算进位
            carry //= 10
        
        return result[::-1]
```

### 方法三：先转换再计算（简单但可能溢出）

```python
class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        """
        将数组转为整数，相加后再转回数组
        注意：对于超大数字可能溢出（Python 不会溢出，但其他语言可能）
        """
        # 将数组转为整数
        num_int = 0
        for digit in num:
            num_int = num_int * 10 + digit
        
        # 相加
        sum_result = num_int + k
        
        # 转回数组
        if sum_result == 0:
            return [0]
        
        result = []
        while sum_result > 0:
            result.append(sum_result % 10)
            sum_result //= 10
        
        return result[::-1]
```

### 方法四：Python 特色解法（最简洁）

```python
class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        """
        利用 Python 的大数支持和列表推导
        """
        # 将数组转为整数（使用 join 和 int）
        num_int = int(''.join(map(str, num)))
        
        # 相加后转回列表
        return [int(d) for d in str(num_int + k)]
```

## 复杂度分析

**方法一（推荐）：**
- 时间复杂度：O(max(n, log k))，其中 n 是 num 的长度，log k 是 k 的位数
- 空间复杂度：O(1)，不计结果数组

**方法二：**
- 时间复杂度：O(max(n, log k))
- 空间复杂度：O(1)

**方法三和方法四：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 注意：在其他语言中可能有整数溢出风险

## 关键点总结

1. **从右向左处理**：加法从个位开始，对应数组的末尾
2. **进位处理**：使用 `k //= 10` 自动处理进位
3. **长度不同**：通过 `while i >= 0 or k > 0` 处理
4. **结果反转**：因为从后往前计算，最后需要反转
5. **边界情况**：k = 0 或 num = [0] 等特殊情况

## 易错点

1. **忘记反转结果**：result 是从后往前构建的，最后必须反转
2. **边界条件**：循环条件应该是 `i >= 0 or k > 0`，不能用 `and`
3. **进位遗漏**：最后可能还有进位，需要继续处理
4. **数组为空**：题目保证 num.length >= 1，但要注意健壮性
