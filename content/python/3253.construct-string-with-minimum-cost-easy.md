## 题目描述

给你一个字符串 `target`、一个字符串数组 `words` 和一个整数数组 `costs`，其中 `costs[i]` 表示 `words[i]` 的花费。

每次操作可以选择 `words[i]`，将其附加到当前字符串末尾，花费 `costs[i]`。

目标是构造字符串 `target`，返回最小总花费。若无法构造返回 `-1`。

**注意：** 与 3213 类似，但本题为 easy，数据范围较小。

**提示：**
- `1 <= target.length <= 2000`
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`

## 解题思路

由于数据范围小，可以直接用哈希表 + 动态规划：

`dp[i]` = 构造 `target[0..i-1]` 的最小花费。

对每个位置 i，枚举所有 words，检查是否匹配 target 的某个前缀结尾。

## Python 代码实现

### 方法一：DP + 字典（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumCost(self, target: str, words: List[str], costs: List[int]) -> int:
        # 构建 word -> min_cost 映射
        word_cost = defaultdict(lambda: float('inf'))
        for w, c in zip(words, costs):
            word_cost[w] = min(word_cost[w], c)
        
        n = len(target)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(n):
            if dp[i] == INF:
                continue
            for j in range(i + 1, n + 1):
                sub = target[i:j]
                if sub in word_cost:
                    dp[j] = min(dp[j], dp[i] + word_cost[sub])
        
        return dp[n] if dp[n] != INF else -1
```

### 方法二：字典树 + DP

```python
from typing import List

class Solution:
    def minimumCost(self, target: str, words: List[str], costs: List[int]) -> int:
        # 构建字典树
        trie = [{}]
        min_cost = [0]
        
        for word, cost in zip(words, costs):
            node = 0
            for c in word:
                if c not in trie[node]:
                    trie.append({})
                    min_cost.append(float('inf'))
                    trie[node][c] = len(trie) - 1
                node = trie[node][c]
            min_cost[node] = min(min_cost[node], cost)
        
        n = len(target)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(n):
            if dp[i] == INF:
                continue
            node = 0
            for j in range(i, n):
                c = target[j]
                if c not in trie[node]:
                    break
                node = trie[node][c]
                if min_cost[node] < INF:
                    dp[j + 1] = min(dp[j + 1], dp[i] + min_cost[node])
        
        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 方法一：时间复杂度 O(n^2 * L)，L 为单词最大长度
- 方法二：时间复杂度 O(n^2 + sum(|words|))
- 空间复杂度：O(sum(|words|))

## 关键点总结

1. 基础 DP：dp[i] 表示构造前 i 个字符的最小花费
2. 字典树从每个起点向右匹配，效率更高
3. 同一单词保留最小花费

## 易错点

1. 无法构造时返回 -1
2. 同一单词可能有多个 cost，只保留最小值
