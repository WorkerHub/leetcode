## 题目描述

给你一棵以节点 `0` 为根的无权树，有 `n` 个节点，以及节点值数组 `nums`。

边权为 1（每条边权重相同），或者题目给了具体边权。

一条**特殊路径**是从根节点到某个节点的路径，满足路径上没有两个节点的值相同（即路径上所有节点值各不相同）。

返回最长特殊路径的长度（边数）。如果有多条最长特殊路径，返回节点数最少的那条的节点数。

**示例：**

```
输入：edges = [[0,1,1],[1,2,2],[1,3,1],[2,4,3]], nums = [1,1,0,0,0]
输出：[3,2]
解释：最长特殊路径是 0->1->2->4（但 nums[0]=nums[1]=1，有重复），不合法
实际：0->2->4，长度 3，节点 3...
```

**提示：**
- `2 <= n <= 5 * 10^4`
- 边权 `1 <= w <= 10^5`

## 解题思路

DFS 从根节点出发，维护当前路径上每个值最近出现的深度（用哈希表记录）。

对于每个节点，路径上不能有两个相同值的节点。用哈希表 `last_seen[v]` 记录值 `v` 最后出现在路径中的位置（按深度/距离）。

当 DFS 进入节点 u 时：
- 若 `nums[u]` 已在路径中出现，必须将路径起点移到该位置之后（相当于截断路径）
- 用双指针或记录最近重复位置

维护当前路径的起点（最近的限制点），使路径上所有节点值唯一。

## Python 代码实现

### 方法一：DFS + 哈希表记录最后出现深度

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestSpecialPath(self, edges: List[List[int]], nums: List[int]) -> List[int]:
        n = len(nums)
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # ans[0] = 最长路径长度（边权和），ans[1] = 对应的最少节点数
        ans = [0, 1]

        # 记录值 -> 路径上该值最近出现时的累积距离（从根到该节点）
        last_dist = {}  # value -> dist when last seen
        # dist_stack: 路径上各节点到根的距离
        dist_stack = [0]  # dist_stack[-1] 是当前节点到根的距离

        def dfs(node, parent, cur_dist, path_start_dist, depth):
            """
            node: 当前节点
            parent: 父节点（避免回头）
            cur_dist: 当前节点到根的距离（边权和）
            path_start_dist: 当前有效路径的起始距离
            depth: 当前路径中的节点数（包括当前节点）
            """
            nonlocal ans

            v = nums[node]
            # 若 v 已在路径中出现，且出现位置 >= 路径起点
            new_start_dist = path_start_dist
            if v in last_dist and last_dist[v] >= path_start_dist:
                # 新路径起点要在 last_dist[v] 之后
                new_start_dist = last_dist[v]

            # 当前路径长度 = cur_dist - new_start_dist
            path_len = cur_dist - new_start_dist
            # 当前路径节点数 = depth（从路径起点到当前）
            # 需要计算从 new_start_dist 到 cur_dist 的节点数
            # 这需要额外的信息...

            # 更新答案
            # 路径长度 = cur_dist - new_start_dist
            if path_len > ans[0] or (path_len == ans[0] and depth < ans[1]):
                ans = [path_len, depth]

            # 记录旧值，进入子节点
            old_last = last_dist.get(v)
            last_dist[v] = cur_dist

            for child, w in graph[node]:
                if child != parent:
                    dfs(child, node, cur_dist + w, new_start_dist, depth + 1)

            # 恢复
            if old_last is None:
                last_dist.pop(v, None)
            else:
                last_dist[v] = old_last

        dfs(0, -1, 0, 0, 1)
        return ans
```

### 方法二：简化版（只统计边权和）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestSpecialPath(self, edges: List[List[int]], nums: List[int]) -> List[int]:
        n = len(nums)
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        ans_len = 0
        ans_nodes = 1

        # value -> 最近在路径上出现时的路径深度（节点序号）
        last_seen_depth = {}
        # 路径上每个节点到根的距离
        dist_prefix = [0]  # dist_prefix[i] = 路径第 i 个节点到根的距离
        # 路径起始深度（包含当前路径的最早节点深度）
        path_start_depth = [0]

        def dfs(node, parent, cur_dist, depth):
            nonlocal ans_len, ans_nodes

            dist_prefix.append(cur_dist)
            v = nums[node]

            # 更新路径起始深度
            old_start = path_start_depth[0]
            if v in last_seen_depth:
                # 必须从 last_seen_depth[v]+1 开始
                path_start_depth[0] = max(path_start_depth[0], last_seen_depth[v] + 1)

            start_d = path_start_depth[0]
            path_len = cur_dist - dist_prefix[start_d]
            num_nodes = depth - start_d + 1  # 当前路径节点数

            if path_len > ans_len or (path_len == ans_len and num_nodes < ans_nodes):
                ans_len = path_len
                ans_nodes = num_nodes

            old_depth = last_seen_depth.get(v)
            last_seen_depth[v] = depth

            for child, w in graph[node]:
                if child != parent:
                    dfs(child, node, cur_dist + w, depth + 1)

            # 恢复状态
            path_start_depth[0] = old_start
            dist_prefix.pop()
            if old_depth is None:
                last_seen_depth.pop(v, None)
            else:
                last_seen_depth[v] = old_depth

        dfs(0, -1, 0, 0)
        return [ans_len, ans_nodes]
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，哈希表和递归栈

## 关键点总结

1. DFS 时维护"当前路径中每个值最后出现的深度"
2. 遇到重复值时，路径起始深度要推进到重复位置之后
3. 使用前缀距离数组快速计算路径长度

## 易错点

1. 恢复状态时要恢复路径起始深度（`path_start_depth`）
2. 路径节点数 = 当前深度 - 起始深度 + 1
3. 当路径长度相同时，要比较节点数，取节点数更少的
