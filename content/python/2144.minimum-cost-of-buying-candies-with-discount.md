## 题目描述

超市里有 `n` 块糖，价格为 `cost[i]`。超市有个优惠活动：**每购买两块糖，可以免费获得一块价格不超过这两块中较便宜那块的糖**。

你可以多次享受此优惠。

返回购买所有 `n` 块糖的**最低花费**。

**示例 1：**
```
输入：cost = [1,2,3]
输出：5
解释：买 3 和 2（花费 5），免费获得 1。总花费 5。
```

**示例 2：**
```
输入：cost = [6,5,7,9,2,2]
输出：23
解释：买 9 和 7（花费 16），免费获得 6；买 5 和 2（花费 7），免费获得 2。总花费 16+7=23。
```

**提示：**
- `1 <= cost.length <= 100`
- `1 <= cost[i] <= 100`

## 解题思路

**贪心：从贵到便宜排序，每三块糖中第三块免费**

为了最大化免费糖的价值，应该让免费的糖尽量贵。

排序后，从贵到便宜排列，按 `[0,1,2,3,4,5,...]` 分组，每组三个中第三块（下标 2,5,8,...）免费。

**证明：** 买前两块（最贵的两块），免费最多一块不超过较便宜那块价格的糖，贪心地选第三贵的糖免费，使免费价值最大。

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        cost.sort(reverse=True)  # 从贵到便宜排序
        total = 0
        for i, c in enumerate(cost):
            # 每三块中，第三块（下标 2,5,8,...）免费
            if (i + 1) % 3 != 0:
                total += c
        return total
```

### 方法二：跳过免费项

```python
from typing import List

class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        cost.sort(reverse=True)
        return sum(c for i, c in enumerate(cost) if i % 3 != 2)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(n log n) | O(1) |

## 关键点总结

1. 排序后，下标 2, 5, 8, ...（即每三个一组的第三个）对应的糖免费。
2. 贪心思想：将最贵的糖免费，才能最大化折扣。
3. Python 的 `enumerate` 配合取模判断非常简洁。

## 易错点

- 免费的是下标为 2, 5, 8, ...（`i % 3 == 2` 或 `(i+1) % 3 == 0`），不是 0, 3, 6,...。
- 排序方向：从大到小（`reverse=True`）。
