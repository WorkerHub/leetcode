## 题目描述

给你一份 `n` 位朋友的亲密度列表，其中 `n` 总是**偶数**。

对每位朋友 `i`，`preferences[i]` 是按亲密程度**由高到低**排序的朋友列表。

`pairs` 给出了配对方案，每人恰好配对一位朋友。

如果存在朋友 `x` 在 `y` 的喜好列表中排名比 `u`（`y` 的配对对象）更高，且 `y` 在 `x` 的喜好列表中排名比 `v`（`x` 的配对对象）更高，则 `x` 是**不开心的**。

返回不开心的朋友的数目。

## 解题思路

### 模拟 + 预处理排名

1. 预处理每个人对其他人的**排名**（亲密程度，值越小越亲密）
2. 对每个人 `x`，找其配对对象 `v`
3. 在 `x` 的偏好列表中，找排名比 `v` 更高的人（即 `pref_rank[x][y] < pref_rank[x][v]`）
4. 对这些更偏好的人 `y`，检查 `y` 是否也更偏好 `x`（即 `pref_rank[y][x] < pref_rank[y][u]`，`u` 是 `y` 的配对对象）

## 代码实现

### 方法一：预处理排名 + 模拟（推荐）

```python
from typing import List

class Solution:
    def unhappyFriends(self, n: int, preferences: List[List[int]], pairs: List[List[int]]) -> int:
        # 预处理：rank[x][y] 表示 y 在 x 的偏好列表中的排名（越小越高）
        rank = [[0] * n for _ in range(n)]
        for i in range(n):
            for j, friend in enumerate(preferences[i]):
                rank[i][friend] = j

        # 建立配对关系
        partner = {}
        for x, y in pairs:
            partner[x] = y
            partner[y] = x

        # 统计不开心的朋友
        ans = 0
        for x in range(n):
            v = partner[x]
            # 找 x 比 v 更偏好的人
            for y in preferences[x]:
                if y == v:
                    break  # v 及之后的都不比 v 更高
                # y 在 x 的偏好列表中排名比 v 更高
                u = partner[y]
                # 检查 y 是否也更偏好 x
                if rank[y][x] < rank[y][u]:
                    ans += 1
                    break  # x 已经是不开心的，不需要继续检查

        return ans
```

### 方法二：完整模拟（更直观）

```python
from typing import List

class Solution:
    def unhappyFriends(self, n: int, preferences: List[List[int]], pairs: List[List[int]]) -> int:
        # 预处理排名
        rank = {}
        for i, prefs in enumerate(preferences):
            for j, p in enumerate(prefs):
                rank[(i, p)] = j

        # 配对
        partner = {}
        for a, b in pairs:
            partner[a] = b
            partner[b] = a

        ans = 0
        for x in range(n):
            v = partner[x]
            is_unhappy = False
            for y in preferences[x]:
                if y == v:
                    break
                # x 更偏好 y，检查 y 是否也更偏好 x
                u = partner[y]
                if rank[(y, x)] < rank[(y, u)]:
                    is_unhappy = True
                    break
            if is_unhappy:
                ans += 1

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N^2)，预处理 O(N^2)，模拟 O(N^2) 最坏
- **空间复杂度**：O(N^2)

## 关键点总结

1. 预处理每个人的偏好排名，O(1) 比较
2. 对每个人，只需检查其偏好列表中排名比配对对象更高的人
3. 一旦找到一个符合条件的 y，就确定 x 不开心，可提前终止

## 易错点

- 偏好列表中越靠前排名越高，`rank` 值越小表示越亲密
- 找比配对对象更偏好的人，只需遍历到配对对象为止
