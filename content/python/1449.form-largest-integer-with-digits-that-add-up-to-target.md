## 题目描述

给你一个整数数组 `cost`，其中 `cost[i]` 是用数字 `i + 1`（即数字 1 到 9）的代价。另外给你一个整数 `target`，请你返回使用恰好 `target` 代价能够组成的最大整数（以字符串形式返回）。

如果无法满足要求，返回 `"0"`。

由于答案可能很大，请以字符串形式返回。

**示例 1：**
```
输入：cost = [4,3,2,5,6,7,2,5,5], target = 9
输出："7772"
解释：数字 7 的代价为 cost[6] = 2，数字 3 的代价为 cost[2] = 2。
     所以 "7772" 的代价是 2+2+2+3 = 9，等于 target。
     "977" 的代价是 5+2+2 = 9，等于 target，但 "7772" 更大。
```

**示例 2：**
```
输入：cost = [7,6,5,5,5,6,8,7,8], target = 12
输出："85"
解释："85" 的代价是 8+5 = 13，不等于 target。
     所以答案是 "85"。
```

**示例 3：**
```
输入：cost = [2,4,6,2,4,6,4,4,4], target = 5
输出："0"
```

**提示：**
- `cost.length == 9`
- `1 <= cost[i] <= 5000`
- `1 <= target <= 5000`

## 解题思路

这道题的核心思想分两步：

**第一步：确定最大位数**

要让整数最大，首先要让位数尽可能多（位数多的整数更大）。我们用动态规划求在恰好花费 `target` 代价时，最多能组成几位数字。

定义 `dp[j]` 为恰好花费代价 `j` 时，最多能组成的数字位数。这是一个完全背包问题（每个数字可以重复使用）。

- 初始化：`dp[0] = 0`，其余为 `-infinity`（表示不可达）
- 转移方程：`dp[j] = max(dp[j], dp[j - cost[i]] + 1)`（对每个数字 i 遍历）

**第二步：贪心构造最大整数**

确定了最大位数之后，从高位到低位，贪心地选择能放置的最大数字（数字 9 到 1 依次尝试）：
- 若当前数字 d 的代价为 c，且 `dp[remaining_target - c] == dp[remaining_target] - 1`，则选择数字 d，更新剩余代价。

## Python 代码实现

### 方法一：动态规划 + 贪心（推荐）

```python
from typing import List

class Solution:
    def largestNumber(self, cost: List[int], target: int) -> str:
        # dp[j] 表示恰好花费代价 j 时，最多能组成的数字位数
        # 用 float('-inf') 表示不可达状态
        dp = [float('-inf')] * (target + 1)
        dp[0] = 0  # 代价为 0 时，组成 0 位数字

        # 完全背包：每个数字可以重复使用
        for j in range(1, target + 1):
            for i in range(9):  # 遍历数字 1~9
                c = cost[i]
                if j >= c and dp[j - c] != float('-inf'):
                    dp[j] = max(dp[j], dp[j - c] + 1)

        # 如果 dp[target] 仍为 -inf，说明无法恰好达到 target
        if dp[target] == float('-inf'):
            return "0"

        # 贪心构造：从高位到低位，尽量选最大的数字
        result = []
        remaining = target
        for _ in range(dp[target]):  # 总共 dp[target] 位
            # 从 9 到 1 尝试，选能放置的最大数字
            for d in range(9, 0, -1):
                c = cost[d - 1]
                # 检查选了数字 d 之后，剩余代价是否还能恰好填满剩余位数
                if remaining >= c and dp[remaining - c] == dp[remaining] - 1:
                    result.append(str(d))
                    remaining -= c
                    break

        return "".join(result)
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def largestNumber(self, cost: List[int], target: int) -> str:
        @lru_cache(maxsize=None)
        def max_digits(t: int) -> int:
            """返回恰好花费代价 t 时的最大位数，不可达返回 -inf"""
            if t == 0:
                return 0
            if t < 0:
                return float('-inf')
            best = float('-inf')
            for c in cost:
                sub = max_digits(t - c)
                if sub != float('-inf'):
                    best = max(best, sub + 1)
            return best

        total_digits = max_digits(target)
        if total_digits == float('-inf'):
            return "0"

        result = []
        remaining = target
        for _ in range(total_digits):
            # 贪心：选最大的可行数字
            for d in range(9, 0, -1):
                c = cost[d - 1]
                if remaining >= c and max_digits(remaining - c) == max_digits(remaining) - 1:
                    result.append(str(d))
                    remaining -= c
                    break

        return "".join(result)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(target × 9) = O(target)，DP 填表加贪心构造
- 空间复杂度：O(target)，DP 数组的空间

**方法二：**
- 时间复杂度：O(target × 9)，记忆化后每个状态只计算一次
- 空间复杂度：O(target)，递归栈和缓存空间

## 关键点总结

1. 最大整数 = 位数最多（贪心）+ 每一位尽量大（贪心）
2. 完全背包求最大位数：`dp[j] = max(dp[j], dp[j - cost[i]] + 1)`
3. 不可达状态用 `-inf` 标记，与 `0` 区分开
4. 贪心构造时，利用 DP 值做"可行性验证"

## 易错点

- **`dp` 初始化**：不可达应设为 `-inf`，不能设为 `0`，否则无法区分"恰好达到"和"无法达到"的情况
- **贪心校验条件**：选数字 d 后，需要验证 `dp[remaining - c] == dp[remaining] - 1`，即剩余代价恰好够填满剩余位数
- **数字 9 到 1 枚举**：必须从大到小，保证每位选最大值
