## 题目描述

你正在运行一个程序，`nums[i]` 是第 `i` 步需要的内存量。你需要在整个运行过程中维护一个固定大小的内存块。每次**调整内存大小**为 `s` 时，之后所有步骤中多余的空间（`s - nums[i]`）都会被浪费，直到下次调整。

你最多可以**调整 `k` 次**（初始分配不算次数）。

返回整个运行过程中**最少浪费的内存量**。

**示例：**
```
输入：nums = [10, 20, 15, 30, 20], k = 2
输出：15
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 10^6`
- `0 <= k <= nums.length - 1`

---

## 解题思路

### 核心思想：DP

定义 `dp[i][j]` = 处理完前 `i+1` 个元素，已经调整了 `j` 次的最小浪费量（包含初始分配）。

对于区间 `[l, r]`，固定大小为 `max(nums[l..r])` 时的浪费量：
`waste(l, r) = max(nums[l..r]) * (r - l + 1) - sum(nums[l..r])`

初始化：`dp[r][0] = waste(0, r)` 对所有 r

转移：`dp[r][j] = min(dp[l-1][j-1] + waste(l, r))` for all l

## 代码实现

### 方法一：二维 DP（推荐）

```python
from typing import List

class Solution:
    def minSpaceWastedKResizing(self, nums: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        # 预计算区间 [l, r] 的浪费量
        waste = [[0] * n for _ in range(n)]
        for l in range(n):
            max_val = 0
            total = 0
            for r in range(l, n):
                max_val = max(max_val, nums[r])
                total += nums[r]
                waste[l][r] = max_val * (r - l + 1) - total

        # dp[i][j] = 处理完 nums[0..i]，进行了 j 次额外分配的最小浪费
        dp = [[INF] * (k + 1) for _ in range(n)]

        # 初始化：一次分配覆盖整个前缀
        for r in range(n):
            dp[r][0] = waste[0][r]

        for j in range(1, k + 1):
            for r in range(j, n):  # 至少 j 步才能进行 j 次额外分配
                for l in range(j, r + 1):
                    if dp[l - 1][j - 1] < INF:
                        dp[r][j] = min(dp[r][j], dp[l - 1][j - 1] + waste[l][r])

        return min(dp[n - 1])
```

### 方法二：一维 DP 滚动优化

```python
from typing import List

class Solution:
    def minSpaceWastedKResizing(self, nums: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        # 预计算前缀和和区间最大值（用于快速计算 waste）
        prefix_sum = [0] * (n + 1)
        for i, x in enumerate(nums):
            prefix_sum[i + 1] = prefix_sum[i] + x

        def get_waste(l, r):
            """区间 [l, r] 的浪费量"""
            max_val = max(nums[l:r + 1])
            return max_val * (r - l + 1) - (prefix_sum[r + 1] - prefix_sum[l])

        # prev_dp[i] = 在第 i 个位置，上一轮分配数的最小浪费
        prev_dp = [get_waste(0, r) for r in range(n)]

        for j in range(k):
            curr_dp = [INF] * n
            for r in range(n):
                max_val = 0
                total = 0
                for l in range(r, -1, -1):
                    max_val = max(max_val, nums[l])
                    total += nums[l]
                    w = max_val * (r - l + 1) - total
                    if l == 0:
                        curr_dp[r] = min(curr_dp[r], w)
                    else:
                        if prev_dp[l - 1] < INF:
                            curr_dp[r] = min(curr_dp[r], prev_dp[l - 1] + w)
            prev_dp = curr_dp

        return prev_dp[n - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n² * k) | O(n * k) |
| 方法二 | O(n² * k) | O(n) |

---

## 关键点总结

1. DP 思路：将数组分成 `k+1` 段，每段固定一个大小
2. 每段的浪费量 = 最大值 * 段长 - 段内总和
3. 预计算区间浪费量可减少重复计算

---

## 易错点

- 第 0 次调整覆盖初始分配，DP 从调整次数 0 开始
- 注意初始化：dp[r][0] = waste(0, r)（初始只有一次分配）
