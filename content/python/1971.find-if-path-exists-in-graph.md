## 题目描述

有一个具有 `n` 个顶点的**双向图**，顶点编号 `0` 到 `n-1`。给你一个整数 `n` 和边数组 `edges`，`edges[i] = [ui, vi]` 表示 `ui` 和 `vi` 之间有一条双向边。

给你两个整数 `source` 和 `destination`，判断图中是否存在一条从 `source` 到 `destination` 的**有效路径**。

**示例 1：**
```
输入：n = 3, edges = [[0,1],[1,2],[2,0]], source = 0, destination = 2
输出：true
```

**提示：**
- `1 <= n <= 2 * 10^5`
- `0 <= edges.length <= 2 * 10^5`

---

## 解题思路

### 方法一：BFS/DFS 图遍历

从 `source` 出发，BFS 或 DFS 判断是否能到达 `destination`。

### 方法二：并查集

将所有边连通，判断 `source` 和 `destination` 是否在同一连通分量。

---

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        if source == destination:
            return True

        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS
        visited = {source}
        queue = deque([source])

        while queue:
            node = queue.popleft()
            if node == destination:
                return True
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)

        return False
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py

        for u, v in edges:
            union(u, v)

        return find(source) == find(destination)
```

### 方法三：DFS

```python
from typing import List
from collections import defaultdict

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        visited = set()

        def dfs(node: int) -> bool:
            if node == destination:
                return True
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    if dfs(neighbor):
                        return True
            return False

        return dfs(source)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS/DFS | O(n + e) | O(n + e) |
| 并查集 | O((n + e) * alpha) | O(n) |

---

## 关键点总结

1. 图连通性问题，BFS/DFS/并查集均可
2. 并查集最简洁，且对多次查询高效
3. 注意 `source == destination` 时直接返回 `true`

---

## 易错点

- BFS 需要在入队时标记已访问，否则重复入队
- 并查集路径压缩避免退化
