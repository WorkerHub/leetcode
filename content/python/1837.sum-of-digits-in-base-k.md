## 题目描述

给你一个整数 `n`（十进制）和一个基数 `k`，返回 `n` 用 `k` 进制表示后，各位数字之和（十进制）。

**示例 1：**
```
输入：n = 34, k = 6
输出：9
解释：34 的六进制为 54，各位之和 5+4=9
```

**示例 2：**
```
输入：n = 10, k = 10
输出：1
解释：10 的十进制各位之和 1+0=1
```

**提示：**
- `1 <= n <= 100`
- `2 <= k <= 10`

## 解题思路

将 `n` 转换为 `k` 进制，然后累加各位数字。转换方法：反复用 `n % k` 取余，然后 `n //= k`，直到 `n == 0`。

## 代码实现

### 方法一：手动进制转换（推荐）

```python
class Solution:
    def sumBase(self, n: int, k: int) -> int:
        digit_sum = 0
        while n > 0:
            digit_sum += n % k  # 取最低位
            n //= k             # 去掉最低位
        return digit_sum
```

### 方法二：转字符串后求和

```python
class Solution:
    def sumBase(self, n: int, k: int) -> int:
        # 利用自定义进制转换
        digits = []
        while n > 0:
            digits.append(n % k)
            n //= k
        return sum(digits)
```

## 复杂度分析

- **时间复杂度**：O(log_k(n))，即 n 在 k 进制下的位数
- **空间复杂度**：O(1)

## 关键点总结

1. 进制转换的标准方法：反复取余和整除
2. 只需要各位之和，不需要存储完整的进制表示

## 易错点

- n=0 时循环不执行，返回 0（但题目 n >= 1，不会出现这种情况）
- 不要混淆：是将 n 转为 k 进制求各位和，不是将 n 的某种表示转换
