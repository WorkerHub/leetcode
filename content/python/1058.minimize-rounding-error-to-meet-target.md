## 题目描述

给定一个表示价格的字符串数组 `prices`，其中 `prices[i]` 表示第 `i` 件商品的价格，以及一个整数 `target`，表示你有的总金额。

`prices` 中的每个价格都是一个字符串，表示为一个浮点数。

你需要将每个价格 `prices[i]` 舍入为 `prices[i]` 的向上取整（`ceil`）或向下取整（`floor`），使得舍入后的价格之和等于 `target`。

如果可以实现目标，返回**最小的总舍入误差**。如果无法实现目标，返回 `"-1"`。

舍入误差是每个价格舍入前后差值的绝对值之和。

**示例 1：**
```
输入：prices = ["0.700","2.800","4.900"], target = 8
输出："1.000"
解释：
使用向下取整，向上取整，向上取整。
总和 = 0 + 3 + 5 = 8。
舍入误差 = |-0.700| + |0.200| + |0.100| = 1.000。
```

**示例 2：**
```
输入：prices = ["1.500","2.500","3.500"], target = 10
输出："-1"
解释：
无法达到目标。
向下取整总和 = 1 + 2 + 3 = 6
向上取整总和 = 2 + 3 + 4 = 9
无法得到 10。
```

**提示：**
- `1 <= prices.length <= 500`
- 每个 `prices[i]` 表示一个介于 `0.000` 和 `1000.000` 之间的价格，最多包含 3 位小数
- `0 <= target <= 10^6`

## 解题思路

这道题的核心是**贪心策略**：
1. 计算所有价格向下取整的和（最小可能和）
2. 计算所有价格向上取整的和（最大可能和）
3. 如果 `target` 不在这个范围内，返回 `-1`
4. 否则，需要将一部分向下取整改为向上取整，使和等于 `target`

**关键观察：**
- 每个价格只有两种选择：向下取整或向上取整
- 向上取整会使和增加 `ceil(price) - floor(price)`
- 要使总误差最小，应该选择小数部分接近 1 的价格向上取整

**算法流程：**
1. 分离整数部分和小数部分
2. 计算向下取整的总和 `floor_sum`
3. 需要向上取整的数量 `k = target - floor_sum`
4. 如果 `k < 0` 或 `k > 非整数价格数量`，返回 `-1`
5. 选择小数部分最大的 `k` 个价格向上取整
6. 计算总误差

## Python 代码实现

### 方法一：贪心 + 排序（推荐）

```python
from typing import List
import math

class Solution:
    def minimizeError(self, prices: List[str], target: int) -> str:
        """
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # 分离整数价格和小数部分
        fractions = []  # 存储小数部分
        floor_sum = 0   # 所有价格向下取整的和
        
        for price_str in prices:
            price = float(price_str)
            floor_price = math.floor(price)
            floor_sum += floor_price
            
            fraction = price - floor_price
            if fraction > 0:  # 只记录有小数部分的价格
                fractions.append(fraction)
        
        # 需要向上取整的数量
        need_ceil = target - floor_sum
        
        # 检查是否可行
        if need_ceil < 0 or need_ceil > len(fractions):
            return "-1"
        
        # 贪心：选择小数部分最大的 need_ceil 个向上取整
        # 这样可以最小化误差
        fractions.sort(reverse=True)
        
        # 计算总误差
        error = 0.0
        
        # 前 need_ceil 个向上取整，误差为 1 - fraction
        for i in range(need_ceil):
            error += 1 - fractions[i]
        
        # 剩余的向下取整，误差为 fraction
        for i in range(need_ceil, len(fractions)):
            error += fractions[i]
        
        # 格式化为 3 位小数
        return f"{error:.3f}"
```

### 方法二：详细注释版

```python
from typing import List
import math

class Solution:
    def minimizeError(self, prices: List[str], target: int) -> str:
        """
        贪心算法详细版
        """
        fractions = []
        floor_sum = 0
        
        # 步骤1：计算所有价格的向下取整和，并记录小数部分
        for price_str in prices:
            price = float(price_str)
            floor_val = int(price)  # 向下取整
            floor_sum += floor_val
            
            frac = price - floor_val
            if frac > 1e-9:  # 避免浮点数精度问题，判断是否有小数
                fractions.append(frac)
        
        # 步骤2：计算需要向上取整的数量
        need_ceil = target - floor_sum
        
        # 步骤3：可行性检查
        # 向下取整和 <= target <= 向上取整和
        if need_ceil < 0 or need_ceil > len(fractions):
            return "-1"
        
        # 步骤4：贪心选择
        # 要使误差最小，应该选择小数部分最大的向上取整
        # 因为向上取整的误差是 1-frac，frac 越大，误差越小
        fractions.sort(reverse=True)
        
        # 步骤5：计算最小误差
        total_error = 0.0
        
        # 选择的 need_ceil 个向上取整
        for i in range(need_ceil):
            total_error += 1 - fractions[i]
        
        # 其余的向下取整
        for i in range(need_ceil, len(fractions)):
            total_error += fractions[i]
        
        return f"{total_error:.3f}"
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def minimizeError(self, prices: List[str], target: int) -> str:
        """
        简化的贪心实现
        """
        # 提取小数部分
        fracs = []
        total_floor = 0
        
        for p in prices:
            val = float(p)
            floor_val = int(val)
            total_floor += floor_val
            frac = val - floor_val
            if frac > 0:
                fracs.append(frac)
        
        # 需要向上取整的数量
        k = target - total_floor
        
        if k < 0 or k > len(fracs):
            return "-1"
        
        # 排序，选择最大的 k 个向上取整
        fracs.sort(reverse=True)
        
        # 计算误差
        error = sum(1 - f for f in fracs[:k]) + sum(fracs[k:])
        
        return f"{error:.3f}"
```

## 图解示例

**示例：prices = ["0.700","2.800","4.900"], target = 8**

```
步骤1：分离整数和小数
0.700 → floor=0, frac=0.700
2.800 → floor=2, frac=0.800
4.900 → floor=4, frac=0.900

floor_sum = 0 + 2 + 4 = 6
fractions = [0.700, 0.800, 0.900]

步骤2：计算需要向上取整的数量
need_ceil = 8 - 6 = 2

步骤3：检查可行性
0 <= 2 <= 3 ✓

步骤4：贪心选择（按小数部分降序）
fractions 排序后：[0.900, 0.800, 0.700]
选择前 2 个向上取整：0.900, 0.800

步骤5：计算误差
向上取整：
  0.900 → 5，误差 = 1 - 0.900 = 0.100
  2.800 → 3，误差 = 1 - 0.800 = 0.200

向下取整：
  0.700 → 0，误差 = 0.700

总误差 = 0.100 + 0.200 + 0.700 = 1.000

方案：[0, 3, 5]，和 = 8 ✓
```

## 关键点总结

1. **贪心策略**：选择小数部分最大的向上取整，可以最小化误差
2. **可行性检查**：`floor_sum <= target <= floor_sum + 非整数价格数量`
3. **误差计算**：
   - 向上取整误差：`1 - fraction`
   - 向下取整误差：`fraction`
4. **整数价格**：整数价格没有选择余地，不影响优化

## 易错点

1. **整数价格**：如果价格本身是整数，不应该计入可选择的范围
2. **浮点精度**：判断小数部分时注意浮点数精度问题
3. **格式化输出**：结果需要保留 3 位小数
4. **可行性判断**：
   - `need_ceil < 0`：目标太小
   - `need_ceil > len(fractions)`：目标太大
