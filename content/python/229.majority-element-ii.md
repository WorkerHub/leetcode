## 题目描述

给定一个大小为 `n` 的整数数组，找出其中所有出现超过 `⌊ n/3 ⌋` 次的元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：[3]
```

**示例 2：**

```
输入：nums = [1]
输出：[1]
```

**示例 3：**

```
输入：nums = [1,2]
输出：[1,2]
```

**提示：**

- `1 <= nums.length <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 解题思路

这道题是经典的摩尔投票算法的扩展版。

### 核心观察

**重要结论：出现次数超过 ⌊n/3⌋ 的元素最多有 2 个。**

证明：假设有 3 个元素都出现超过 n/3 次，那么总次数 > 3 × (n/3) = n，矛盾！

### 摩尔投票算法（Boyer-Moore）

基本思想：**对拼消耗**
1. 维护两个候选者和它们的计数
2. 遍历数组，更新候选者和计数
3. 第二次遍历验证候选者是否真的超过 n/3

### 算法流程

**第一轮投票：找候选者**
1. 初始化两个候选者 `cand1`, `cand2` 和计数 `count1`, `count2`
2. 遍历数组：
   - 如果当前数等于某个候选者，对应计数 +1
   - 否则，如果某个计数为 0，更新该候选者
   - 否则，两个计数都 -1（对拼消耗）

**第二轮验证：确认候选者**
1. 统计两个候选者的实际出现次数
2. 如果超过 n/3，加入结果

## Python 代码实现

### 方法一：摩尔投票算法（推荐）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        # 第一轮投票：找出两个候选者
        cand1, cand2 = None, None
        count1, count2 = 0, 0
        
        for num in nums:
            if num == cand1:
                count1 += 1
            elif num == cand2:
                count2 += 1
            elif count1 == 0:
                cand1 = num
                count1 = 1
            elif count2 == 0:
                cand2 = num
                count2 = 1
            else:
                # 对拼消耗
                count1 -= 1
                count2 -= 1
        
        # 第二轮验证：统计候选者的实际次数
        count1 = count2 = 0
        for num in nums:
            if num == cand1:
                count1 += 1
            elif num == cand2:
                count2 += 1
        
        result = []
        n = len(nums)
        if count1 > n // 3:
            result.append(cand1)
        if count2 > n // 3:
            result.append(cand2)
        
        return result
```

### 方法二：哈希表（简单直接）

```python
from typing import List
from collections import Counter

class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        # 统计每个元素的出现次数
        counter = Counter(nums)
        n = len(nums)
        result = []
        
        # 找出出现次数超过 n/3 的元素
        for num, count in counter.items():
            if count > n // 3:
                result.append(num)
        
        return result
```

### 方法三：哈希表（不使用 Counter）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        # 手动统计
        count_map = {}
        for num in nums:
            count_map[num] = count_map.get(num, 0) + 1
        
        # 找出超过 n/3 的元素
        result = []
        threshold = len(nums) // 3
        for num, count in count_map.items():
            if count > threshold:
                result.append(num)
        
        return result
```

### 方法四：详细注释版（摩尔投票）

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        """
        找出出现次数超过 n/3 的所有元素
        
        核心思想：摩尔投票算法
        1. 最多有 2 个元素满足条件
        2. 第一轮投票找候选者
        3. 第二轮验证候选者
        """
        # 第一轮：投票阶段
        cand1, cand2 = None, None  # 两个候选者
        count1, count2 = 0, 0      # 对应的计数
        
        for num in nums:
            # 如果当前数字等于候选者1，计数+1
            if num == cand1:
                count1 += 1
            # 如果当前数字等于候选者2，计数+1
            elif num == cand2:
                count2 += 1
            # 如果候选者1的计数为0，更新候选者1
            elif count1 == 0:
                cand1 = num
                count1 = 1
            # 如果候选者2的计数为0，更新候选者2
            elif count2 == 0:
                cand2 = num
                count2 = 1
            # 否则，对拼消耗（三个不同的数字互相抵消）
            else:
                count1 -= 1
                count2 -= 1
        
        # 第二轮：验证阶段
        # 重新统计两个候选者的实际出现次数
        count1 = count2 = 0
        for num in nums:
            if num == cand1:
                count1 += 1
            elif num == cand2:
                count2 += 1
        
        # 检查候选者是否真的超过 n/3
        result = []
        n = len(nums)
        if count1 > n // 3:
            result.append(cand1)
        if count2 > n // 3:
            result.append(cand2)
        
        return result
```

## 复杂度分析

**方法一：摩尔投票算法**
- 时间复杂度：O(n)，两次遍历数组
- 空间复杂度：O(1)，只使用常数个变量

**方法二、三：哈希表**
- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(n)，哈希表最多存储 n 个元素

## 图解示例

以 `nums = [1,1,1,3,3,2,2,2]` 为例（n=8, n/3=2.67）：

```
第一轮投票：

num | cand1 | count1 | cand2 | count2 | 操作
----|-------|--------|-------|--------|-----
1   | 1     | 1      | None  | 0      | count1=0，设为cand1
1   | 1     | 2      | None  | 0      | num==cand1
1   | 1     | 3      | None  | 0      | num==cand1
3   | 1     | 3      | 3     | 1      | count2=0，设为cand2
3   | 1     | 3      | 3     | 2      | num==cand2
2   | 1     | 2      | 3     | 1      | 对拼消耗
2   | 1     | 1      | 3     | 0      | 对拼消耗
2   | 1     | 1      | 2     | 1      | count2=0，设为cand2

候选者：cand1=1, cand2=2

第二轮验证：
1 出现 3 次 > 8/3 (2.67)，加入结果
2 出现 3 次 > 8/3 (2.67)，加入结果

结果：[1, 2]
```

## 关键点总结

1. **数学证明**：最多有 2 个元素满足条件
2. **对拼消耗**：三个不同的数字互相抵消
3. **两轮处理**：第一轮找候选者，第二轮验证
4. **elif 顺序**：先判断是否等于候选者，再判断计数是否为0
5. **验证必要性**：第一轮只是找候选者，不保证一定满足条件

## 易错点

1. **忘记验证**：第一轮只是找候选者，必须第二轮验证
2. **elif 顺序错误**：要先判断 `num == cand`，再判断 `count == 0`
3. **重复添加**：验证时要用 `elif`，避免 cand1 和 cand2 相同时重复添加
4. **边界条件**：空数组、只有一个元素的情况
5. **候选者初始化**：初始化为 None 或任意值都可以，但要注意判断条件
