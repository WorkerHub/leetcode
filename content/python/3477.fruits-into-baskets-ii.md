## 题目描述

给你一个整数数组 `fruits`，其中 `fruits[i]` 是第 i 个水果的种类，以及一个整数 `k`。

你有无限个篮子，每个篮子最多装 `k` 个水果，但每个篮子只能装同一种水果。

从左到右将水果放入篮子：每次遇到一种水果，将它放入第一个（最左边）可以容纳该种水果的篮子。如果没有合适的篮子，就开一个新篮子。

返回装完所有水果所需的最少篮子数。

**示例：**

```
输入：fruits = [1,2,1,2,3], k = 2
输出：4
解释：篮子1: [1,1], 篮子2: [2,2], 篮子3: [3]
```

**提示：**
- `1 <= fruits.length <= 10^5`
- `1 <= fruits[i] <= 10^5`
- `1 <= k <= 10^3`

## 解题思路

模拟放置过程：用字典记录每种水果当前所在篮子的剩余容量，若满了就开新篮子。

关键：每个篮子容量 k，同一种水果优先使用现有篮子（最左边未满的那个）。

## Python 代码实现

### 方法一：哈希表模拟

```python
from typing import List
from collections import defaultdict

class Solution:
    def numBaskets(self, fruits: List[int], k: int) -> int:
        # basket_rem[fruit_type] = 当前该种水果篮子的剩余容量
        basket_rem = {}
        baskets = 0

        for f in fruits:
            if f not in basket_rem or basket_rem[f] == 0:
                # 开新篮子
                baskets += 1
                basket_rem[f] = k - 1
            else:
                basket_rem[f] -= 1

        return baskets
```

### 方法二：详细模拟（多篮子同种水果）

```python
from typing import List
from collections import deque

class Solution:
    def numBaskets(self, fruits: List[int], k: int) -> int:
        # 每种水果可能有多个篮子，用队列记录每个篮子剩余容量
        baskets = {}  # fruit -> deque of remaining capacities
        total = 0

        for f in fruits:
            if f not in baskets:
                baskets[f] = deque()

            q = baskets[f]
            if q and q[0] > 0:
                # 使用最左边未满的篮子
                q[0] -= 1
                if q[0] == 0:
                    q.popleft()  # 满了移除
            else:
                # 开新篮子
                total += 1
                remaining = k - 1
                if remaining > 0:
                    q.append(remaining)

        return total
```

### 方法三：计数优化

```python
from typing import List

class Solution:
    def numBaskets(self, fruits: List[int], k: int) -> int:
        from collections import defaultdict

        # 记录每种水果已用篮子数和当前篮子剩余容量
        basket_count = defaultdict(int)
        current_rem = defaultdict(int)
        total = 0

        for f in fruits:
            if current_rem[f] > 0:
                current_rem[f] -= 1
            else:
                # 开新篮子
                total += 1
                current_rem[f] = k - 1

        return total
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(m)，m 为不同水果种类数

## 关键点总结

1. 每种水果独立管理篮子，不同种类不互相干扰
2. 优先使用现有未满篮子（实际上只需记录当前篮子剩余容量）
3. 每种水果当前只有一个"活跃"篮子（最左边未满的）

## 易错点

1. 篮子满了（剩余0）需要开新篮子
2. 同一种水果的篮子是连续放的，不会跳过
3. 初始化时 `current_rem[f] = 0` 表示没有活跃篮子
