## 题目描述

给你一个整数 `eventTime`（表示事件的总时长），以及两个整数数组 `startTime` 和 `endTime`，各有 `n` 个元素（已按时间排序），表示 n 个会议的开始和结束时间。

你可以**移动最多 k 个**会议（每次移动可以将会议移到任意时间，但不能改变会议时长）。

返回移动后能获得的最大**连续空闲时间**。

**示例 1：**

```
输入：eventTime = 5, k = 1, startTime = [1,3], endTime = [2,5]
输出：2
解释：移动会议 [3,5] 到 [0,2]，得空闲时间 [2,5]，长度 3... 
或不移动，空闲时间 [0,1] 和 (空) ...
```

**示例 2：**

```
输入：eventTime = 10, k = 1, startTime = [0,2,9], endTime = [1,4,10]
输出：6
```

**提示：**
- `1 <= eventTime <= 10^9`
- `1 <= k <= n <= 500`
- `0 <= startTime[i] < endTime[i] <= eventTime`
- 会议之间不重叠

## 解题思路

会议之间的空隙构成了空闲时间段。设空隙数组为 `gaps`（包括 [0, start[0]] 和 [end[-1], eventTime] 以及相邻会议间的空隙）。

移动 k 个会议等效于"消除" k 个会议占用的时间块，合并相邻的 k+1 个空隙。

使用**滑动窗口**：枚举消除哪 k 个连续的会议（滑动窗口大小 k），每次窗口内的 k 个会议被移走后，窗口边界的 k+1 个空隙合并，总空闲时间 = 这 k+1 个空隙之和 + 各会议时长之和（因为会议被移走，它们占的时间变成空闲）。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)

        # 构建空隙数组
        # gaps[0] = 第一个会议前的空隙
        # gaps[i] = 第 i-1 个会议结束到第 i 个会议开始的空隙（i >= 1）
        # gaps[n] = 最后一个会议结束后的空隙
        gaps = []
        gaps.append(startTime[0])  # [0, startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])  # [endTime[-1], eventTime]

        # 会议时长
        durations = [endTime[i] - startTime[i] for i in range(n)]

        # 滑动窗口：选 k 个连续会议（下标 l 到 l+k-1），移走它们
        # 合并的空闲时间 = gaps[l] + sum(durations[l..l+k-1]) + gaps[l+1] + ... + gaps[l+k]
        # = sum(gaps[l..l+k]) + sum(durations[l..l+k-1])

        # 初始化窗口
        window_gaps = sum(gaps[:k + 1])  # gaps[0..k]
        window_dur = sum(durations[:k])   # durations[0..k-1]

        ans = window_gaps + window_dur

        for l in range(1, n - k + 1):
            # 移除左边：gaps[l-1] 和 durations[l-1]
            window_gaps -= gaps[l - 1]
            window_dur -= durations[l - 1]
            # 加入右边：gaps[l+k] 和 durations[l+k-1]
            window_gaps += gaps[l + k]
            window_dur += durations[l + k - 1]
            ans = max(ans, window_gaps + window_dur)

        return ans
```

### 方法二：枚举所有连续 k 个会议

```python
from typing import List

class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)

        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])

        durations = [endTime[i] - startTime[i] for i in range(n)]

        ans = 0
        for l in range(n - k + 1):
            # 移走会议 l 到 l+k-1
            free = sum(gaps[l: l + k + 1]) + sum(durations[l: l + k])
            ans = max(ans, free)

        return ans
```

## 复杂度分析

- 方法一（滑动窗口）：
  - 时间复杂度：O(n)
  - 空间复杂度：O(n)

- 方法二（朴素）：
  - 时间复杂度：O(n * k)
  - 空间复杂度：O(n)

## 关键点总结

1. 移动 k 个连续会议等效于合并 k+1 个相邻空隙
2. 合并后的空闲时间 = k+1 个空隙之和 + k 个被移走会议的时长之和
3. 用滑动窗口枚举所有可能的 k 个连续会议

## 易错点

1. 空隙数组比会议数组多 1 个（首尾各一个空隙）
2. 滑动窗口的范围：l 从 0 到 n-k（共 n-k+1 个起点）
3. 移走的会议时长也变成空闲时间（要加上）
