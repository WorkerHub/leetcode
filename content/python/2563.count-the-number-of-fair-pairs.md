## 题目描述

给你一个整数数组 `nums` 和两个整数 `lower` 和 `upper`，返回满足 `lower <= nums[i] + nums[j] <= upper` 的下标对 `(i, j)` 的数量，其中 `0 <= i < j < n`。

**示例 1：**

```
输入：nums = [0,1,7,4,4,5], lower = 3, upper = 6
输出：6
```

**示例 2：**

```
输入：nums = [1,7,9,2,5], lower = 11, upper = 11
输出：1
```

**提示：**

- `1 <= nums.length <= 10^5`
- `nums[i]`, `lower`, `upper` 为整数，范围 [-10^9, 10^9]

## 解题思路

排序后，对每个 nums[i]，用二分查找找满足条件的 nums[j]（j > i）的数量：
- `nums[j] >= lower - nums[i]` 且 `nums[j] <= upper - nums[i]`
- 两次二分查找确定合法 j 的范围

## Python 代码实现

### 方法一：排序 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def countFairPairs(self, nums: List[int], lower: int, upper: int) -> int:
        nums.sort()
        n = len(nums)
        ans = 0

        for i in range(n - 1):
            # 找 j > i 使得 lower <= nums[i] + nums[j] <= upper
            lo = bisect.bisect_left(nums, lower - nums[i], i + 1, n)
            hi = bisect.bisect_right(nums, upper - nums[i], i + 1, n)
            ans += hi - lo

        return ans
```

### 方法二：双指针

```python
from typing import List

class Solution:
    def countFairPairs(self, nums: List[int], lower: int, upper: int) -> int:
        nums.sort()
        n = len(nums)

        def count_pairs_less_than(limit):
            # 统计满足 nums[i] + nums[j] <= limit，i < j 的对数
            count = 0
            left, right = 0, n - 1
            while left < right:
                if nums[left] + nums[right] <= limit:
                    count += right - left
                    left += 1
                else:
                    right -= 1
            return count

        # 满足 lower <= sum <= upper = 满足 sum <= upper - 满足 sum <= lower-1
        return count_pairs_less_than(upper) - count_pairs_less_than(lower - 1)
```

## 复杂度分析

- 方法一时间复杂度：O(n log n)，排序 + 每次二分
- 方法二时间复杂度：O(n log n)，排序 + 两次双指针 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后利用单调性，二分或双指针高效统计
2. 对每个 i，用二分在 [i+1, n) 中找满足和在 [lower, upper] 内的 j
3. 双指针方法：统计和 <= limit 的对数，两次相减

## 易错点

1. 二分查找的范围是 `[i+1, n)`，不包含 i 本身（要求 i < j）
2. `bisect_left` 找左边界，`bisect_right` 找右边界，注意 off-by-one
3. 双指针统计时 `count += right - left`，不是 `right - left + 1`
