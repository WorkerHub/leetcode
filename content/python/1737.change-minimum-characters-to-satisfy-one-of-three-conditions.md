## 题目描述

给你两个字符串 `a` 和 `b`，二者均由小写字母组成。一次操作中，你可以将 `a` 或 `b` 中的**任一**字符改成**任一**小写字母。

你的目标是满足下列三个条件之一：
1. `a` 中每个字符都**严格小于** `b` 中的每个字符（字典序）
2. `b` 中每个字符都**严格小于** `a` 中的每个字符
3. `a` 和 `b` 都由**同一个**字符组成

请返回达成目标所需的**最少**操作数。

**示例 1：**
```
输入：a = "aba", b = "caa"
输出：2
```

**提示：**
- `1 <= a.length, b.length <= 10^5`

## 解题思路

分三种条件分别计算最小操作数，取最小值：

**条件1/2**：枚举分割点 `c`（a-z，共25个）：
- 条件1：a 全变为 <= c 的字符，b 全变为 > c 的字符
  - 代价 = a 中 > c 的字符数 + b 中 <= c 的字符数
- 条件2同理

**条件3**：枚举最终字符 `c`（a-z，共26个）：
- 代价 = a 中不等于 c 的字符数 + b 中不等于 c 的字符数
- = len(a) - count_a[c] + len(b) - count_b[c]
- 取 count_a[c] + count_b[c] 最大的

## 代码实现

### 方法一：前缀和优化（推荐）

```python
class Solution:
    def minCharacters(self, a: str, b: str) -> int:
        # 统计字母频率
        count_a = [0] * 26
        count_b = [0] * 26
        for c in a:
            count_a[ord(c) - ord('a')] += 1
        for c in b:
            count_b[ord(c) - ord('a')] += 1
        
        la, lb = len(a), len(b)
        ans = la + lb  # 最坏情况
        
        # 计算前缀和（a 中字母 <= c 的数量）
        prefix_a = [0] * 27
        prefix_b = [0] * 27
        for i in range(26):
            prefix_a[i + 1] = prefix_a[i] + count_a[i]
            prefix_b[i + 1] = prefix_b[i] + count_b[i]
        
        # 条件1：枚举分割点，a 的字符都 <= c，b 的字符都 > c（c 范围 a-y 即 0-24）
        for c in range(25):
            # a 中 > c 的数量：需要改变
            cost_a = la - prefix_a[c + 1]
            # b 中 <= c 的数量：需要改变
            cost_b = prefix_b[c + 1]
            ans = min(ans, cost_a + cost_b)
        
        # 条件2：b 的字符都 <= c，a 的字符都 > c
        for c in range(25):
            cost_b = lb - prefix_b[c + 1]
            cost_a = prefix_a[c + 1]
            ans = min(ans, cost_a + cost_b)
        
        # 条件3：a 和 b 都由同一字符组成
        for c in range(26):
            cost = (la - count_a[c]) + (lb - count_b[c])
            ans = min(ans, cost)
        
        return ans
```

### 方法二：直接枚举

```python
class Solution:
    def minCharacters(self, a: str, b: str) -> int:
        from collections import Counter
        ca = Counter(a)
        cb = Counter(b)
        la, lb = len(a), len(b)
        ans = la + lb
        
        alphabet = 'abcdefghijklmnopqrstuvwxyz'
        
        # 条件1/2：枚举分割点
        for i in range(25):
            # a 全在 [a..alphabet[i]]，b 全在 [alphabet[i+1]..z]
            cost1 = sum(ca.get(alphabet[j], 0) for j in range(i + 1, 26))  # a 中需要改的
            cost1 += sum(cb.get(alphabet[j], 0) for j in range(i + 1))    # b 中需要改的
            
            cost2 = sum(cb.get(alphabet[j], 0) for j in range(i + 1, 26))
            cost2 += sum(ca.get(alphabet[j], 0) for j in range(i + 1))
            
            ans = min(ans, cost1, cost2)
        
        # 条件3：枚举最终字符
        for c in alphabet:
            cost = (la - ca.get(c, 0)) + (lb - cb.get(c, 0))
            ans = min(ans, cost)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n + 26)，频率统计 O(n)，枚举 O(26)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 三个条件分别枚举，取最小
2. 前缀和优化条件1/2的枚举
3. 条件3只需取两个字符串中同一字母出现次数之和最大的

## 易错点

- 条件1/2的分割点范围是 0-24（不包含 25，即最后一个字母），因为严格小于
- 注意枚举方向（条件1和条件2的代价计算对称）
