## 题目描述

有 `n` 个人，每人要么是好人（说真话）、坏人（说假话）。

给你一个 `n x n` 的二维数组 `statements`，`statements[i][j]` 表示第 `i` 人对第 `j` 人的评价：
- `0`：i 说 j 是坏人。
- `1`：i 说 j 是好人。
- `2`：i 没有评论 j。

好人的每条声明都是真实的，坏人的声明可以是真的也可以是假的（不可靠）。

返回满足条件的**最多好人数**（即能找到一个一致的分配方案，使得好人数最多）。

**提示：**
- `n == statements.length == statements[i].length`
- `2 <= n <= 15`
- `statements[i][j]` 为 0、1、2 之一
- `statements[i][i] = 2`（不对自己评论）

## 解题思路

**位枚举**

n <= 15，枚举所有 `2^n` 种"好人/坏人"分配方案（每种方案用一个 n 位的二进制数表示，位为 1 表示好人）。

对每种方案，验证其合法性：所有好人的每条声明都必须与方案一致：
- 若 `statements[i][j] == 1`，则 j 必须是好人。
- 若 `statements[i][j] == 0`，则 j 必须是坏人。

## 代码实现

### 方法一：位枚举验证（推荐）

```python
from typing import List

class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        ans = 0

        for mask in range(1 << n):
            # mask 中第 i 位为 1 表示第 i 个人是好人
            if self.is_valid(statements, mask, n):
                ans = max(ans, bin(mask).count('1'))

        return ans

    def is_valid(self, statements, mask, n):
        for i in range(n):
            if not (mask >> i & 1):
                continue  # i 是坏人，声明不可靠
            # i 是好人，验证其所有声明
            for j in range(n):
                if statements[i][j] == 1 and not (mask >> j & 1):
                    return False  # i 说 j 是好人，但方案中 j 是坏人
                if statements[i][j] == 0 and (mask >> j & 1):
                    return False  # i 说 j 是坏人，但方案中 j 是好人
        return True
```

### 方法二：简洁版

```python
from typing import List

class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        ans = 0
        for mask in range(1 << n):
            valid = True
            for i in range(n):
                if not (mask >> i & 1):
                    continue
                for j in range(n):
                    if statements[i][j] == 2:
                        continue
                    good = (mask >> j & 1) == 1
                    if statements[i][j] == 1 and not good:
                        valid = False
                        break
                    if statements[i][j] == 0 and good:
                        valid = False
                        break
                if not valid:
                    break
            if valid:
                ans = max(ans, bin(mask).count('1'))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 位枚举 | O(2^n * n^2) | O(1) |

n <= 15，2^15 * 15^2 ≈ 7.4 * 10^6，可接受。

## 关键点总结

1. n <= 15，可以枚举所有 2^n 个分配方案。
2. 只有好人（mask 中对应位为 1）的声明需要验证。
3. 好人的每条 0/1 声明必须与方案一致，声明 2 无需验证。

## 易错点

- 坏人的声明不可靠，不需要验证。
- `mask >> i & 1` 的括号优先级：`>>`  < `&`，实际上 Python 中 `>>` 优先于 `&`，可以写 `(mask >> i) & 1`。
