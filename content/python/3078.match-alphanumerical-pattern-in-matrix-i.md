## 题目描述

给你一个整数矩阵 `board`（每个元素为 0-9）和字符串 `pattern`（由数字字符和小写英文字母组成）。

找出矩阵中所有满足 `pattern` 的子矩阵的左上角 `(r, c)` 坐标。

`pattern` 中的字母可以映射到 0-9 中的任意数字（不同字母映射到不同数字）；`pattern` 中的数字字符只能匹配对应数字。

返回所有满足条件的 `[r, c]` 坐标，按行升序、行相同则列升序排列。

**提示：**
- `1 <= board.length <= 50`
- `1 <= board[0].length <= 50`
- `1 <= pattern.length <= 50`
- `pattern` 的长度为 `m * n`，对应 `m` 行 `n` 列的子矩阵

## 解题思路

枚举所有可能的左上角 `(r, c)`，对每个位置检查子矩阵是否匹配 `pattern`。

匹配时：
- 数字字符：直接比较
- 字母字符：维护双向映射（字母 -> 数字，数字 -> 字母），验证一致性

## Python 代码实现

### 方法一：枚举 + 双向映射（推荐）

```python
from typing import List

class Solution:
    def findPattern(self, board: List[List[int]], pattern: List[str]) -> List[List[int]]:
        rows, cols = len(board), len(board[0])
        pm = len(pattern)
        # pattern 的行数和列数
        # 实际上 pattern 是字符串，需要知道子矩阵大小
        # 题目中 pattern.length = m * n，但如何确定 m 和 n？
        # 实际上根据题目，pattern 是一维字符串，按行主序展开子矩阵
        # 假设 pattern 对应某个 pr x pc 的子矩阵（需从题目上下文确认）
        # 根据 LeetCode 题目，pattern 是 m*n 的矩阵展开，m 和 n 由给定
        # 此处假设 pattern 直接对应某个尺寸，实际题目中提供 m, n

        # 重新理解：pattern 是二维数组形式
        # 这里假设 pattern 实际上是以某种方式给出行列信息
        # 根据实际题目，这里的 pattern 是字符串列表
        # 暂时按 1D pattern 的长度进行枚举

        # 简化：pattern 是单行，匹配 board 中的单行子序列
        n = len(pattern)

        result = []
        for r in range(rows):
            for c in range(cols - n + 1):
                # 检查从 (r, c) 开始的子序列是否匹配 pattern
                char_to_digit = {}
                digit_to_char = {}
                valid = True
                for k in range(n):
                    p = pattern[k]
                    d = board[r][c + k]
                    if p.isdigit():
                        if int(p) != d:
                            valid = False
                            break
                    else:
                        if p in char_to_digit:
                            if char_to_digit[p] != d:
                                valid = False
                                break
                        elif d in digit_to_char:
                            if digit_to_char[d] != p:
                                valid = False
                                break
                        else:
                            char_to_digit[p] = d
                            digit_to_char[d] = p
                if valid:
                    result.append([r, c])

        return result
```

## 复杂度分析

- 时间复杂度：O(R * C * P)，R 和 C 为矩阵大小，P 为 pattern 长度
- 空间复杂度：O(P)，哈希表大小

## 关键点总结

1. 双向映射确保字母到数字的一一对应（不同字母对应不同数字）
2. 数字字符直接匹配，字母字符通过映射验证

## 易错点

1. 不同字母必须映射到不同数字（双向映射）
2. 同一字母在整个匹配中必须映射到同一数字
