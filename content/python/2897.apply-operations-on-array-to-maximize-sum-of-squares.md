## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个**正整数** `k`。

你可以对数组执行以下操作**任意次**：
- 选择两个不同下标 `i` 和 `j`，同时将 `nums[i]` 替换为 `nums[i] OR nums[j]`，将 `nums[j]` 替换为 `nums[i] AND nums[j]`

你需要选出 `k` 个元素，使得它们的**平方和最大**。返回这个最大平方和对 `10^9 + 7` 取模的结果。

**示例 1：**
```
输入：nums = [2, 6, 5, 8], k = 2
输出：261
解释：
对 i=0, j=3：nums = [10, 6, 5, 0]
对 i=0, j=1：nums = [14, 2, 5, 0]
选 nums[0]=14, nums[2]=5，平方和 = 196+25=221... 
实际最优：选 14 和 5，261?
```

**示例 2：**
```
输入：nums = [4, 5, 4, 7], k = 3
输出：90
解释：选出 7, 5, 4，平方和 = 49+25+16=90
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键观察：** OR + AND 操作的本质

对于 `(a, b) -> (a OR b, a AND b)`：
- 每个二进制位上的 1 的总数保持不变（OR 集中 1，AND 保留公共 1）
- 这个操作等价于：将两个数的每一位重新分配，但每一位上 1 的总数不变

**贪心策略：**

对于每一个二进制位（0 到 29 位），统计所有数字在该位上 1 的个数 `cnt[bit]`。

要使 k 个数的平方和最大，应该尽量让少数几个数"集中"更多的 1（高位优先）。

具体地：从高位到低位，每一位有 `cnt[bit]` 个 1，将它们尽量分配给"靠前"的 k 个数（即优先让第 1 个数取满，再给第 2 个数，以此类推）。

然后取前 k 个数（平方和最大）。

**实现：**

统计每个二进制位上 1 的总数，然后对每个数（共 k 个），贪心地为它取尽量多的高位 1。

## Python 代码实现

### 方法一：位统计 + 贪心分配（推荐）

```python
from typing import List

class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7

        # 统计每个二进制位上 1 的总数
        cnt = [0] * 30
        for num in nums:
            for bit in range(30):
                if num >> bit & 1:
                    cnt[bit] += 1

        # 构造 k 个最优数
        ans = 0
        for _ in range(k):
            # 贪心为当前数取尽量高位的 1
            x = 0
            for bit in range(29, -1, -1):
                if cnt[bit] > 0:
                    x |= (1 << bit)
                    cnt[bit] -= 1
            ans = (ans + x * x) % MOD

        return ans
```

### 方法二：Counter 写法

```python
from typing import List
from collections import Counter

class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7

        # 统计每个位上 1 的数量
        bit_cnt = Counter()
        for num in nums:
            for bit in range(30):
                if num >> bit & 1:
                    bit_cnt[bit] += 1

        ans = 0
        for _ in range(k):
            x = 0
            for bit in range(29, -1, -1):
                if bit_cnt[bit] > 0:
                    x |= 1 << bit
                    bit_cnt[bit] -= 1
            ans = (ans + x * x) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 30 + k * 30) = O((n + k) * 30)，即 O(n)
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. OR + AND 操作保持每个二进制位上 1 的总数不变
2. 要最大化平方和，应将 1 集中到尽量少的数上（平方凸性：集中优于分散）
3. 贪心：每次取一个数，从高位到低位贪心取 1
4. 取前 k 个数即为最优解

## 易错点

1. 注意取模操作（结果需 mod 10^9+7）
2. 每个数最多 30 位（nums[i] <= 10^9 < 2^30）
3. 每次取 1 之后要将该位计数减 1
