## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

在一次操作中，你可以选择 `nums` 的一个连续子数组，并将其中所有值等于某个整数 `x` 的元素改为 `k`。

返回一次操作后，`nums` 中值为 `k` 的元素的**最大频率**。

**示例 1：**

```
输入：nums = [1,2,3,3,2,2], k = 3
输出：4
解释：选择子数组 [1,2,3,3]，将 2 改为 3，得 [1,3,3,3,2,2]，k=3 出现 3 次；
或选择 [3,3,2,2]，将 2 改为 3，得 [1,2,3,3,3,3]，k=3 出现 4 次
```

**示例 2：**

```
输入：nums = [1,2,3,4], k = 2
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^5`

## 解题思路

枚举要替换的目标值 x（x != k）。对于每个 x，在子数组中将所有 x 替换为 k。

等效于：选一段子数组 [l, r]，将其中的 x 全部变为 k。
- 区间外的 k 仍然保留
- 区间内的 x 变成 k
- 净增加 = 区间内 x 的数量 - 区间内 k 的数量（区间内 k 已经是 k，不需要算；但把 x 变成 k 后 k 数量增加了区间内 x 的数量）

等价于：最大化 `(区间内 x 的数量) - (区间内 k 的数量) + 总 k 数量`

即最大化 `区间内(x 出现数 - k 出现数) + count(k in nums)`

将数组中每个元素：若为 x，赋值 +1；若为 k，赋值 -1；否则赋值 0。
问题转化为求这个新数组的**最大子数组和**（Kadane）。

## Python 代码实现

### 方法一：枚举 x + Kadane（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        total_k = nums.count(k)
        n = len(nums)

        if total_k == n:
            return n

        # 枚举替换目标值 x（x != k）
        distinct_vals = set(nums) - {k}

        best_extra = 0  # 最大增量

        for x in distinct_vals:
            # 构造辅助数组：x -> +1, k -> -1, 其他 -> 0
            # 求最大子数组和（Kadane 算法）
            max_gain = 0
            cur = 0
            for v in nums:
                if v == x:
                    cur += 1
                elif v == k:
                    cur -= 1
                # 只统计正增益的子数组
                cur = max(0, cur)  # 允许空子数组（不操作）
                max_gain = max(max_gain, cur)

            best_extra = max(best_extra, max_gain)

        return total_k + best_extra
```

### 方法二：利用计数优化枚举顺序

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        total_k = nums.count(k)
        n = len(nums)

        # 只有在 nums 中出现的值才需要枚举
        val_set = set(nums)
        val_set.discard(k)

        best = 0

        for x in val_set:
            cur = 0
            max_gain = 0
            for v in nums:
                delta = 1 if v == x else (-1 if v == k else 0)
                cur += delta
                if cur < 0:
                    cur = 0
                if cur > max_gain:
                    max_gain = cur

            if max_gain > best:
                best = max_gain

        return total_k + best
```

### 方法三：不操作时的基准

```python
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        total_k = nums.count(k)
        best_gain = 0

        distinct = set(nums)
        distinct.discard(k)

        for x in distinct:
            cur = max_g = 0
            for v in nums:
                if v == x:
                    cur += 1
                elif v == k:
                    cur -= 1
                if cur < 0:
                    cur = 0
                max_g = max(max_g, cur)
            best_gain = max(best_gain, max_g)

        return total_k + best_gain
```

## 复杂度分析

- 时间复杂度：O(n * D)，D 为不同值的数量，最坏 O(n^2)
- 空间复杂度：O(D)

## 关键点总结

1. 枚举替换目标值 x，将问题转化为最大子数组和
2. Kadane 算法：`cur = max(0, cur + delta)`
3. 最终答案 = 原有的 k 数量 + 最大可增加量

## 易错点

1. 当 cur 为负时重置为 0（允许空子数组，即不进行操作）
2. 若 x 不在 nums 中，枚举它没有意义
3. 当 nums 全为 k 时直接返回 n
