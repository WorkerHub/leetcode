## 题目描述

给你一个字符串数组 `tokens`，表示一个根据逆波兰表示法表示的算术表达式。

请你计算该表达式。返回表示表达式值的整数。

**注意：**

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'`
- 每个操作数（运算对象）都可以是一个整数或另一个表达式
- 两个整数之间的除法总是向零截断
- 表达式中不含除零运算
- 输入是一个根据逆波兰表示法表示的算术表达式
- 答案及所有中间计算结果可以用 32 位整数表示

**示例 1：**

```
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为: ((2 + 1) * 3) = 9
```

**示例 2：**

```
输入: tokens = ["4","13","5","/","+"]
输出: 6
解释: 该算式转化为常见的中缀算术表达式为: (4 + (13 / 5)) = 6
```

**示例 3：**

```
输入: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
输出: 22
解释: 该算式转化为常见的中缀算术表达式为:
  ((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 22
```

**提示：**

- `1 <= tokens.length <= 10^4`
- `tokens[i]` 是一个算符（`"+"`、`"-"`、`"*"` 或 `"/"`），或是在范围 `[-200, 200]` 内的一个整数

## 解题思路

**逆波兰表达式（后缀表达式）**：运算符位于操作数之后。

例如：
- 中缀表达式：`(2 + 1) * 3`
- 后缀表达式：`2 1 + 3 *`

**求值规则：**

从左到右扫描表达式：
1. 遇到数字：压入栈
2. 遇到运算符：从栈中弹出两个数，计算结果，再压入栈
3. 最终栈中只剩一个数，即为结果

**为什么使用栈？**

- 后缀表达式的求值天然符合栈的后进先出特性
- 遇到运算符时，最近的两个操作数就是栈顶的两个元素

**算法流程：**

```
创建栈 stack
for token in tokens:
    if token 是数字:
        stack.push(token)
    else:  # 是运算符
        num2 = stack.pop()
        num1 = stack.pop()
        result = num1 operator num2
        stack.push(result)
return stack.top()
```

## Python 代码实现

### 方法一：栈（标准解法，推荐）

```python
from typing import List

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        operators = {'+', '-', '*', '/'}
        
        for token in tokens:
            if token not in operators:
                # 是数字，压入栈
                stack.append(int(token))
            else:
                # 是运算符，弹出两个数计算
                num2 = stack.pop()
                num1 = stack.pop()
                
                if token == '+':
                    result = num1 + num2
                elif token == '-':
                    result = num1 - num2
                elif token == '*':
                    result = num1 * num2
                else:  # token == '/'
                    # Python 的除法向下取整，题目要求向零截断
                    result = int(num1 / num2)
                
                stack.append(result)
        
        return stack[0]
```

### 方法二：使用字典优化运算符判断

```python
from typing import List
import operator

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        
        # 使用 operator 模块的函数
        ops = {
            '+': operator.add,
            '-': operator.sub,
            '*': operator.mul,
            '/': lambda x, y: int(x / y)  # 向零截断
        }
        
        for token in tokens:
            if token in ops:
                num2 = stack.pop()
                num1 = stack.pop()
                stack.append(ops[token](num1, num2))
            else:
                stack.append(int(token))
        
        return stack[0]
```

### 方法三：简化版（使用 eval，不推荐）

```python
from typing import List

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        
        for token in tokens:
            if token in {'+', '-', '*', '/'}:
                num2 = stack.pop()
                num1 = stack.pop()
                # 使用 eval 计算（不安全，仅供理解）
                stack.append(int(eval(f'{num1} {token} {num2}')))
            else:
                stack.append(int(token))
        
        return stack[0]

# 注意：eval 有安全风险，生产环境不推荐
```

### 方法四：递归解法（理解后缀表达式的另一种方式）

```python
from typing import List

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        def helper():
            token = tokens.pop()
            
            if token in {'+', '-', '*', '/'}:
                # 注意：后缀表达式从右到左处理时，顺序相反
                right = helper()
                left = helper()
                
                if token == '+':
                    return left + right
                elif token == '-':
                    return left - right
                elif token == '*':
                    return left * right
                else:
                    return int(left / right)
            else:
                return int(token)
        
        # 从后往前处理
        tokens.reverse()
        return helper()
```

## 复杂度分析

**方法一、二、三：**

- 时间复杂度：O(n)
  - 遍历 tokens 数组一次
  - 每个元素的入栈、出栈操作都是 O(1)
- 空间复杂度：O(n)
  - 栈最多存储 n/2 个数字（最坏情况：所有数字在前，运算符在后）

**方法四：递归**

- 时间复杂度：O(n)
- 空间复杂度：O(n) - 递归调用栈

## 关键点总结

1. **栈的完美应用场景**：
   - 后缀表达式求值是栈的经典应用
   - 运算符总是作用于最近的两个操作数

2. **弹出顺序**：
   - 先弹出的是右操作数（num2）
   - 后弹出的是左操作数（num1）
   - 对于减法和除法，顺序很重要：`num1 - num2`

3. **除法的特殊处理**：
   - Python 的 `//` 是向下取整（floor）
   - 题目要求向零截断（truncate towards zero）
   - 使用 `int(a / b)` 而不是 `a // b`

4. **数字识别**：
   - 负数也是数字，例如 `"-11"`
   - 可以用 `token not in operators` 或 `token.lstrip('-').isdigit()`

5. **最终结果**：
   - 有效的后缀表达式求值后栈中只剩一个元素
   - 即为最终结果

## 易错点

1. **除法的方向**：
   - Python: `5 // 2 = 2`, `-5 // 2 = -3` (向下取整)
   - 题目要求: `-5 / 2 = -2` (向零截断)
   - 正确做法: `int(a / b)`

2. **操作数顺序**：
   - 减法: `num1 - num2`，不是 `num2 - num1`
   - 除法: `num1 / num2`，不是 `num2 / num1`
   - 先弹出的是 num2，后弹出的是 num1

3. **负数的处理**：
   - `"-11"` 是一个负数，不是运算符
   - 判断运算符时要用集合 `{'+', '-', '*', '/'}`

4. **栈空判断**：
   - 题目保证表达式有效，不需要检查栈空
   - 如果需要检查，应在弹出前判断

5. **数据类型**：
   - 从栈中弹出的是整数，可以直接运算
   - 压入栈前确保是整数类型
