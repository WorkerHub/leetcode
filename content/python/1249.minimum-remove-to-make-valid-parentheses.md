## 题目描述

给你一个由 `'('`、`')'` 和小写字母组成的字符串 `s`。

你需要从字符串中删除最少数目的 `'('` 或者 `')'` （可以删除任意位置的括号），使得剩下的「括号字符串」有效。

请返回任意一个合法字符串。

有效「括号字符串」应当符合以下任意一条：
- 空字符串或只包含小写字母的字符串
- 可以被写作 `AB`（`A` 连接 `B`）的字符串，其中 `A` 和 `B` 都是有效「括号字符串」
- 可以被写作 `(A)` 的字符串，其中 `A` 是一个有效的「括号字符串」

**示例 1：**
```
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。
```

**示例 2：**
```
输入：s = "a)b(c)d"
输出："ab(c)d"
```

**示例 3：**
```
输入：s = "))(("
输出：""
解释：空字符串也是有效的
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 可能是 `'('`、`')'` 或英文小写字母

## 解题思路

这道题的核心思想是找出所有无效的括号并删除它们。无效的括号包括：
1. 没有对应左括号的右括号
2. 没有对应右括号的左括号

**关键观察：**
- 从左到右遍历时，可以找出多余的右括号（没有左括号匹配的右括号）
- 从右到左遍历时，可以找出多余的左括号（没有右括号匹配的左括号）

**算法流程：**
1. 使用栈记录左括号的位置
2. 遍历字符串，遇到左括号压栈，遇到右括号时：
   - 如果栈不为空，说明有匹配的左括号，弹出栈
   - 如果栈为空，说明这是多余的右括号，需要删除
3. 遍历结束后，栈中剩余的都是多余的左括号
4. 根据需要删除的位置重建字符串

## Python 代码实现

### 方法一：栈 + 集合标记（推荐）

```python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        # 使用集合记录需要删除的索引
        to_remove = set()
        stack = []
        
        # 第一次遍历：找出所有无效的括号位置
        for i, char in enumerate(s):
            if char == '(':
                # 左括号入栈，记录其索引
                stack.append(i)
            elif char == ')':
                if stack:
                    # 有匹配的左括号，弹出
                    stack.pop()
                else:
                    # 没有匹配的左括号，标记为需要删除
                    to_remove.add(i)
        
        # 栈中剩余的是多余的左括号
        to_remove.update(stack)
        
        # 构建结果字符串
        return ''.join(char for i, char in enumerate(s) if i not in to_remove)
```

**时间复杂度：** O(n)，其中 n 是字符串长度，需要遍历两次字符串  
**空间复杂度：** O(n)，栈和集合最坏情况下存储 O(n) 个元素

### 方法二：两次遍历法

```python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        # 第一步：从左到右删除多余的右括号
        result = []
        open_count = 0
        
        for char in s:
            if char == '(':
                open_count += 1
                result.append(char)
            elif char == ')':
                if open_count > 0:
                    # 有匹配的左括号
                    open_count -= 1
                    result.append(char)
                # else: 跳过这个多余的右括号
            else:
                # 普通字符直接添加
                result.append(char)
        
        # 第二步：从右到左删除多余的左括号
        # 此时 open_count 表示多余的左括号数量
        final_result = []
        for i in range(len(result) - 1, -1, -1):
            if result[i] == '(' and open_count > 0:
                # 这是多余的左括号，跳过
                open_count -= 1
            else:
                final_result.append(result[i])
        
        # 反转得到最终结果
        return ''.join(reversed(final_result))
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)

### 方法三：计数法（空间优化）

```python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        # 转换为列表以便修改
        s_list = list(s)
        
        # 第一次遍历：标记多余的右括号
        open_count = 0
        for i in range(len(s_list)):
            if s_list[i] == '(':
                open_count += 1
            elif s_list[i] == ')':
                if open_count > 0:
                    open_count -= 1
                else:
                    # 多余的右括号，标记为删除
                    s_list[i] = ''
        
        # 第二次遍历：从右往左标记多余的左括号
        close_count = 0
        for i in range(len(s_list) - 1, -1, -1):
            if s_list[i] == ')':
                close_count += 1
            elif s_list[i] == '(':
                if close_count > 0:
                    close_count -= 1
                else:
                    # 多余的左括号，标记为删除
                    s_list[i] = ''
        
        return ''.join(s_list)
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)，只需要字符列表

## 复杂度分析

所有方法的时间复杂度都是 O(n)，空间复杂度也都是 O(n)。

**方法对比：**
- 方法一最直观，易于理解和实现
- 方法二逻辑清晰，分两步处理
- 方法三在原字符串上修改，代码更简洁

实际应用中推荐使用方法一，因为代码最清晰，便于维护。

## 关键点总结

1. **栈的应用**：使用栈来匹配括号是经典技巧，左括号入栈，右括号出栈
2. **位置标记**：使用集合记录需要删除的位置，避免多次遍历
3. **两类无效括号**：多余的右括号（没有左括号匹配）和多余的左括号（没有右括号匹配）
4. **字符串重建**：使用列表拼接或生成器表达式高效构建结果

## 易错点

1. **只处理一个方向**：容易忽略从右到左的多余左括号，必须处理两个方向
2. **索引处理**：使用集合记录索引时，要注意索引的准确性
3. **边界情况**：
   - 全是左括号：`"(((("` → `""`
   - 全是右括号：`"))))"` → `""`
   - 没有括号：`"abc"` → `"abc"`
4. **字符串不可变**：Python 字符串不可变，需要转换为列表或使用拼接
