## 题目描述

你正在进行一个游戏，共有 `n` 个关卡，顺序挑战。给你一个整数数组 `damage`，`damage[i]` 是第 `i` 关的伤害值，另给你一个整数 `armor`，表示你拥有一件护甲，可以在**某一关**使用，使该关伤害减少 `min(armor, damage[i])`（即护甲吸收最多 `armor` 点伤害）。

返回能通关所需的**最少初始血量**（通关时血量必须 > 0）。

**示例 1：**
```
输入：damage = [2,7,4,3], armor = 4
输出：13
解释：血量至少 13：13-2=11，11-min(4,7)=11-4=7，7-4=3，3-3=0+1=1... 其实护甲用在第2关(7伤害)，减4得3，总血量=2+3+4+3+1=13。
```

**示例 2：**
```
输入：damage = [3,3,3], armor = 0
输出：10
```

**提示：**
- `n == damage.length`
- `1 <= n <= 10^5`
- `0 <= damage[i] <= 10^5`
- `0 <= armor <= 10^5`

## 解题思路

**贪心：** 护甲用在伤害最大的关卡，效果最好（减少最多伤害，等价于节省最多血量）。

所需最少初始血量 = 总伤害 - 护甲减少量 + 1（通关时血量 > 0）。

护甲减少量 = `min(armor, max(damage))`。

**正确性：** 护甲使用一次，用在最大伤害处可以减少最多伤害，贪心最优。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minimumHealth(self, damage: List[int], armor: int) -> int:
        total = sum(damage)
        # 护甲用在伤害最大的关卡，减少量最大
        max_damage = max(damage)
        armor_effect = min(armor, max_damage)
        # 最少初始血量：总伤害 - 护甲减少量 + 1
        return total - armor_effect + 1
```

### 方法二：显式计算（同逻辑，更易理解）

```python
from typing import List

class Solution:
    def minimumHealth(self, damage: List[int], armor: int) -> int:
        # 如果不使用护甲，需要的血量
        base = sum(damage) + 1

        # 护甲最多能帮你减少多少伤害（用在伤害最大的关卡）
        # 减少量不超过 armor，也不超过该关的实际伤害
        max_reduction = min(armor, max(damage))

        # 使用护甲后的最低血量
        return base - max_reduction
```

## 复杂度分析

- 时间复杂度：O(n)，求和与最大值各遍历一次。
- 空间复杂度：O(1)，常数额外空间。

## 关键点总结

1. 护甲使用一次，贪心地用在伤害最大的关卡，效果最优。
2. 最终血量 = 总伤害 - min(armor, max_damage) + 1。
3. "+1" 是因为通关时血量必须严格大于 0（即 > 0）。

## 易错点

- 通关条件是血量 > 0，不是 >= 0，所以最终要 +1。
- 护甲减少量不超过该关的实际伤害：`min(armor, damage[i])`。
