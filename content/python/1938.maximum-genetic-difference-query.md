## 题目描述

给你一棵有 `n` 个节点的有根树（根节点为 0），节点编号 `0` 到 `n-1`，以及查询数组 `queries`，每个查询 `[node_i, val_i]`，要求找到从 `node_i` 到根的路径上，与 `val_i` 异或值**最大**的节点值，返回该最大异或值。

**示例 1：**
```
输入：parents = [-1,0,1,1], queries = [[0,2],[3,2],[2,5]]
输出：[2,3,7]
```

**提示：**
- `n == parents.length`，`2 <= n <= 10^5`
- `queries.length <= 3 * 10^4`

---

## 解题思路

### 核心思想：DFS + 动态字典树

对树进行 DFS 遍历，维护一个**动态字典树**：
- 进入节点时，将节点值**插入**字典树
- 离开节点时，将节点值**从字典树中删除**

对每个查询 `[node, val]`，在 DFS 到达 `node` 时，字典树中恰好包含 `node` 到根的所有节点值，此时查询最大异或值。

## 代码实现

### 方法一：DFS + 动态 Trie（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxGeneticDifference(self, parents: List[int], queries: List[List[int]]) -> List[int]:
        n = len(parents)

        # 构建树
        children = defaultdict(list)
        root = -1
        for i, p in enumerate(parents):
            if p == -1:
                root = i
            else:
                children[p].append(i)

        # 将查询按节点分组
        query_map = defaultdict(list)
        for i, (node, val) in enumerate(queries):
            query_map[node].append((val, i))

        ans = [0] * len(queries)

        # 动态 Trie：cnt[bit_path] = 出现次数
        trie = defaultdict(int)
        BITS = 18  # 节点值最大 10^5 < 2^17

        def insert(x, delta=1):
            """插入或删除值 x（delta=1 插入，delta=-1 删除）"""
            cur = 0
            for bit in range(BITS, -1, -1):
                b = (x >> bit) & 1
                cur = cur * 2 + b + 1  # Trie 节点编号
                trie[cur] += delta

        def query(x):
            """在 Trie 中找与 x 异或最大的值"""
            cur = 0
            res = 0
            for bit in range(BITS, -1, -1):
                b = (x >> bit) & 1
                want = 1 - b  # 希望走与 b 不同的方向
                nxt = cur * 2 + want + 1
                if trie[nxt] > 0:
                    res |= (1 << bit)
                    cur = nxt
                else:
                    cur = cur * 2 + b + 1
            return res

        # DFS（迭代，避免栈溢出）
        stack = [(root, False)]
        while stack:
            node, leaving = stack.pop()
            if leaving:
                # 离开节点，从 Trie 中删除
                insert(node, -1)
            else:
                # 进入节点，插入 Trie
                insert(node, 1)
                stack.append((node, True))  # 标记离开
                # 处理当前节点的查询
                for val, idx in query_map[node]:
                    ans[idx] = query(val)
                # 压入子节点
                for child in children[node]:
                    stack.append((child, False))

        return ans
```

### 方法二：递归 DFS（逻辑相同，n 小时使用）

```python
from typing import List
from collections import defaultdict
import sys
sys.setrecursionlimit(200000)

class Solution:
    def maxGeneticDifference(self, parents: List[int], queries: List[List[int]]) -> List[int]:
        n = len(parents)
        children = defaultdict(list)
        root = -1
        for i, p in enumerate(parents):
            if p == -1:
                root = i
            else:
                children[p].append(i)

        query_map = defaultdict(list)
        for i, (node, val) in enumerate(queries):
            query_map[node].append((val, i))

        ans = [0] * len(queries)
        # Trie 使用字典：{(node, bit): count}
        trie = defaultdict(int)
        BITS = 18

        def insert(x, d):
            cur = 0
            for bit in range(BITS, -1, -1):
                b = (x >> bit) & 1
                cur = cur * 2 + b + 1
                trie[cur] += d

        def query(x):
            cur = 0
            res = 0
            for bit in range(BITS, -1, -1):
                b = (x >> bit) & 1
                want = 1 - b
                nxt = cur * 2 + want + 1
                if trie[nxt] > 0:
                    res |= (1 << bit)
                    cur = nxt
                else:
                    cur = cur * 2 + b + 1
            return res

        def dfs(node):
            insert(node, 1)
            for val, idx in query_map[node]:
                ans[idx] = query(val)
            for child in children[node]:
                dfs(child)
            insert(node, -1)

        dfs(root)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态 Trie + DFS | O((n + q) * BITS) | O(n * BITS) |

---

## 关键点总结

1. 动态 Trie 在 DFS 进入/离开时插入/删除，保证查询时 Trie 恰好包含路径上的节点
2. 节点值编号最大约 10^5，用 18 位二进制表示
3. 迭代 DFS 避免递归栈溢出

---

## 易错点

- 进入节点先插入，处理查询，再递归子节点，离开时删除
- Trie 节点编号设计：`cur * 2 + bit + 1`（避免 0 号节点混淆）
