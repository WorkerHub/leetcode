## 题目描述

给你一个包含若干星号 `*` 的字符串 `s`。

在一步操作中，你可以选中 `s` 中的一个星号。然后移除该星号**左侧**最近的那个**非星号**字符，并移除该星号自身。

返回移除所有星号之后的字符串。

**注意：** 生成的输入保证总是可以执行所有操作。

**示例 1：**
```
输入：s = "leet**cod*e"
输出："lecoe"
解释："leet**" -> 删除 t 和第一个 * -> "lee*cod*e" -> 再删 e -> "lecod*e" -> 删 d -> "lecoe"
```

**示例 2：**
```
输入：s = "erase*****"
输出：""
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 由小写英文字母和星号 `*` 组成
- `s` 中每个星号都有对应的可以删除的字符

## 解题思路

**栈模拟：**

遍历字符串：
- 若当前字符是字母，压入栈。
- 若当前字符是 `*`，弹出栈顶（删除最近的非星号字符）。

最后栈中剩余的字符从底到顶拼接即为答案。

## 代码实现

### 方法一：栈模拟（推荐）

```python
class Solution:
    def removeStars(self, s: str) -> str:
        stack = []
        
        for c in s:
            if c == '*':
                stack.pop()  # 删除最近的非星号字符
            else:
                stack.append(c)  # 普通字符入栈
        
        return ''.join(stack)
```

### 方法二：双指针（原地模拟）

```python
class Solution:
    def removeStars(self, s: str) -> str:
        # 用列表模拟，直接在列表上操作
        result = []
        for c in s:
            if c != '*':
                result.append(c)
            elif result:
                result.pop()
        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 栈模拟 | O(n) | O(n) |

## 关键点总结

1. 栈天然支持"后进先出"，完美对应"删除最近的字符"操作。
2. 遇到 `*` 就 `pop()`，遇到字母就 `append()`，最后 `join()`。
3. 题目保证每个 `*` 都有对应可删除的字符，所以无需检查栈是否为空。

## 易错点

- 注意是删除最近的**非星号**字符（`*` 已被移除，栈中不会有 `*`）。
- 最终结果是栈从底到顶拼接，`''.join(stack)` 直接给出正确顺序。
