## 题目描述

给定一个字符串 s 和一个整数 k 。你可以从 s 的前 k 个字符中选择一个，并把它加到字符串的末尾。

返回 在应用上述步骤的任意数量的移动后，字典序最小的字符串 。

**提示：**
- 1 <= k <= s.length <= 1000
- s 只由小写字母组成

## 解题思路

**数学结论：**
- k = 1：只能旋转，找最小的旋转
- k >= 2：可以排序，返回排序后的字符串

**为什么 k >= 2 可以排序？**
- 可以通过操作实现任意两个相邻字符的交换

## Python 代码实现

```python
class Solution:
    def orderlyQueue(self, s: str, k: int) -> str:
        if k == 1:
            # 只能旋转，找最小的旋转
            return min(s[i:] + s[:i] for i in range(len(s)))
        else:
            # 可以排序
            return ''.join(sorted(s))
```

## 复杂度分析

- **时间复杂度**：O(n² ) for k=1, O(n log n) for k>=2
- **空间复杂度**：O(n)

## 关键点总结

1. **k=1 特殊**：只能旋转
2. **k>=2 通用**：可以完全排序
3. **数学证明**：k>=2 时可实现冒泡排序
