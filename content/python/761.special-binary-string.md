## 题目描述

特殊的二进制序列是具有以下两个性质的二进制序列：

1. `0` 的数量与 `1` 的数量相等
2. 任意前缀中 `1` 的数量都不少于 `0` 的数量

给定一个特殊的二进制序列 `S`，对其进行任意次移动操作，使得它变得字典序最大。

移动操作定义如下：选择两个连续的、非空的、特殊的子串 `T1` 和 `T2`（可能重叠），交换它们的位置。

返回字典序最大的结果字符串。

**示例 1:**
```
输入: S = "11011000"
输出: "11100100"
解释:
以下是一些移动操作：
"11011000" -> "11100100" (交换 "10" 和 "1100")
"11011000" -> "11011000" (交换 "011" 和 "1000")
字符串 "11100100" 是字典序最大的。
```

**提示:**
- `1 <= S.length <= 50`
- `S` 是一个特殊的二进制序列

## 解题思路

这道题需要深入理解特殊二进制序列的性质。

**核心观察：**

1. **特殊序列的结构：** 特殊序列类似于合法的括号序列（1 对应 `(`，0 对应 `)`）
2. **子序列分解：** 一个特殊序列可以分解为多个不可分割的特殊子序列
3. **递归处理：** 对每个子序列递归地进行最大化处理
4. **贪心排序：** 将所有子序列按字典序降序排列

**算法流程：**
1. 找出所有顶层的特殊子序列（不被其他特殊子序列包含的）
2. 对每个子序列递归处理
3. 将所有子序列按字典序降序排序
4. 拼接结果

## Python 代码实现

### 方法一：递归 + 分治（推荐）⭐

```python
class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        # 基本情况：空字符串或 "10"
        if len(s) <= 2:
            return s
        
        # 找出所有顶层的特殊子序列
        substrings = []
        count = 0
        start = 0
        
        for i, char in enumerate(s):
            # 1 表示左括号，0 表示右括号
            count += 1 if char == '1' else -1
            
            # 当 count 回到 0 时，找到一个完整的特殊序列
            if count == 0:
                # 递归处理内部（去掉首尾的 1 和 0）
                inner = s[start + 1:i]
                processed = self.makeLargestSpecial(inner)
                # 加上首尾的 1 和 0
                substrings.append('1' + processed + '0')
                start = i + 1
        
        # 按字典序降序排序
        substrings.sort(reverse=True)
        
        return ''.join(substrings)
```

### 方法二：详细注释版（易理解）

```python
class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        """
        使特殊二进制序列字典序最大
        
        思路：
        1. 特殊序列类似于括号匹配（1='(', 0=')'）
        2. 一个特殊序列可以分解为多个子序列
        3. 递归地处理每个子序列
        4. 将子序列按字典序降序排列
        """
        # 空字符串或最小单元 "10"
        if len(s) <= 2:
            return s
        
        # 找出所有顶层的特殊子序列
        special_substrings = []
        
        # 使用计数器追踪括号平衡
        balance = 0
        substring_start = 0
        
        for i in range(len(s)):
            # '1' 增加计数（左括号）
            if s[i] == '1':
                balance += 1
            # '0' 减少计数（右括号）
            else:
                balance -= 1
            
            # 当计数回到 0 时，找到一个完整的顶层特殊序列
            if balance == 0:
                # 提取这个子序列
                substring = s[substring_start:i + 1]
                
                # 递归处理内部部分（去掉外层的 '1' 和 '0'）
                # 例如 "1100" 的内部是 "10"
                inner = substring[1:-1]
                
                if inner:
                    # 递归处理内部
                    max_inner = self.makeLargestSpecial(inner)
                    # 加上外层的 '1' 和 '0'
                    max_substring = '1' + max_inner + '0'
                else:
                    max_substring = substring
                
                special_substrings.append(max_substring)
                
                # 更新下一个子序列的起始位置
                substring_start = i + 1
        
        # 将所有子序列按字典序降序排序
        # 这样可以保证最终结果是字典序最大的
        special_substrings.sort(reverse=True)
        
        # 拼接所有子序列
        return ''.join(special_substrings)
```

### 方法三：使用栈

```python
class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        def helper(s):
            if not s:
                return s
            
            subs = []
            cnt = 0
            i = 0
            
            for j in range(len(s)):
                cnt += 1 if s[j] == '1' else -1
                if cnt == 0:
                    # 找到一个特殊子序列 s[i:j+1]
                    inner = helper(s[i+1:j])
                    subs.append('1' + inner + '0')
                    i = j + 1
            
            # 降序排序
            subs.sort(reverse=True)
            return ''.join(subs)
        
        return helper(s)
```

### 方法四：迭代版本

```python
class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        # 使用栈来处理嵌套结构
        stack = [[]]
        
        for char in s:
            if char == '1':
                stack.append([])
            else:  # char == '0'
                top = stack.pop()
                # 递归处理
                processed = self.makeLargestSpecial(''.join(top))
                stack[-1].append('1' + processed + '0')
        
        # 排序并拼接
        result = sorted(stack[0], reverse=True)
        return ''.join(result)
```

## 复杂度分析

- **时间复杂度：** O(n^2 log n)，其中 n 是字符串长度。递归深度为 O(n)，每层需要 O(n log n) 时间排序。
- **空间复杂度：** O(n^2)，递归栈和子字符串存储。

## 关键点总结

1. **括号匹配类比：** 将问题类比为括号匹配
2. **分治思想：** 将大问题分解为子问题
3. **递归处理：** 对每个子序列递归地求最优解
4. **贪心排序：** 排序保证字典序最大
5. **结构理解：** 理解特殊序列的嵌套结构

## 易错点

1. **子序列识别：** 正确识别顶层的特殊子序列
2. **递归边界：** 处理内部为空的情况
3. **排序方向：** 要降序排序，不是升序
4. **内外层处理：** 正确处理内层的递归和外层的 '1'、'0'
5. **拼接顺序：** 排序后的拼接顺序影响结果
