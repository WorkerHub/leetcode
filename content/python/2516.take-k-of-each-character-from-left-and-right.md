## 题目描述

给你一个由字符 `'a'`、`'b'`、`'c'` 组成的字符串 `s` 和一个非负整数 `k`。

每分钟，你可以从字符串左端或右端取一个字符。

你的任务是使三个字符 `'a'`、`'b'`、`'c'` 的取走数量均至少为 `k`。

返回完成任务所需的 **最少分钟数**，若无法完成，返回 `-1`。

**示例 1：**

```
输入：s = "aabaaaacaabc", k = 2
输出：8
解释：从左取 3 个，从右取 5 个，共 8 分钟。
```

**示例 2：**

```
输入：s = "a", k = 1
输出：-1
```

**提示：**

- `1 <= s.length <= 10^5`
- `0 <= k <= s.length`
- `s` 只由 `'a'`、`'b'`、`'c'` 组成

## 解题思路

**逆向思维 + 滑动窗口**：从两端取字符等价于保留中间一段不取的字符。

目标：找最长的"不取"中间窗口，使得窗口外的字符中 a, b, c 各至少 k 个。

滑动窗口维护中间不取的段，若窗口内某字符过多（使窗口外该字符不足 k），则缩小窗口。

最少取走数 = n - 最长合法窗口长度。

## Python 代码实现

### 方法一：逆向滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def takeCharacters(self, s: str, k: int) -> int:
        n = len(s)
        total = Counter(s)

        # 若总量不够，直接返回 -1
        if any(total[c] < k for c in 'abc'):
            return -1

        # 滑动窗口：窗口外各字符数量 >= k
        # 等价于：窗口内各字符数量 <= total[c] - k
        max_window = 0
        window = Counter()
        left = 0

        for right in range(n):
            window[s[right]] += 1
            # 若窗口内某字符超出允许量，移动左指针
            while window[s[right]] > total[s[right]] - k:
                window[s[left]] -= 1
                left += 1
            max_window = max(max_window, right - left + 1)

        return n - max_window
```

### 方法二：枚举左端取的数量

```python
from collections import Counter

class Solution:
    def takeCharacters(self, s: str, k: int) -> int:
        n = len(s)
        total = Counter(s)

        if any(total[c] < k for c in 'abc'):
            return -1

        # 前缀计数
        prefix = [Counter()]
        for c in s:
            prefix.append(prefix[-1].copy())
            prefix[-1][c] += 1

        ans = n
        # 从左取 l 个，判断右侧能否满足剩余需求
        for l in range(n + 1):
            left_cnt = prefix[l]
            needed = {c: max(0, k - left_cnt[c]) for c in 'abc'}
            # 从右取最少字符满足 needed
            r = 0
            right_cnt = Counter()
            while any(right_cnt[c] < needed[c] for c in 'abc') and l + r < n:
                r += 1
                right_cnt[s[n - r]] += 1
            if all(right_cnt[c] >= needed[c] for c in 'abc'):
                ans = min(ans, l + r)

        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(n)，滑动窗口单次遍历
- 方法二时间复杂度：O(n^2)，枚举左端长度
- 空间复杂度：O(1)（仅 3 个字符）

## 关键点总结

1. 取走两端等价于保留中间，转化为求最长保留窗口
2. 窗口内允许的最多 c 字符数 = `total[c] - k`
3. 滑动窗口只需检查刚加入右端的字符是否超出限制

## 易错点

1. 总量不足时提前返回 -1（任一字符总数 < k）
2. 窗口条件：每种字符窗口内数量 <= total[c] - k，不是 < k
3. 答案是 n 减去最大合法窗口，不是直接的操作次数
