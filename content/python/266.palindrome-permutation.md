## 题目描述

给定一个字符串，判断该字符串中的字符是否可以通过重新排列组成一个回文串。

**示例 1：**
```
输入: s = "code"
输出: false
```

**示例 2：**
```
输入: s = "aab"
输出: true
解释: "aab" 可以排列成 "aba"
```

**示例 3：**
```
输入: s = "carerac"
输出: true
解释: "carerac" 可以排列成 "racecar"
```

**提示：**
- `1 <= s.length <= 5000`
- `s` 只包含小写英文字母

## 解题思路

判断一个字符串能否重排为回文串，关键是理解**回文串的特性**。

**回文串的字符特点：**
1. 字符串长度为偶数：所有字符出现次数都是偶数
2. 字符串长度为奇数：只有一个字符出现次数为奇数，其他都是偶数

**核心思路：**
- 统计每个字符的出现次数
- 检查出现奇数次的字符数量
- 如果出现奇数次的字符数量 ≤ 1，返回 true

**举例说明：**
- `"aab"` → a:2, b:1 → 1 个奇数次 → 可以组成 "aba" ✓
- `"code"` → c:1, o:1, d:1, e:1 → 4 个奇数次 → 不能组成回文 ✗
- `"carerac"` → c:2, a:2, r:2, e:1 → 1 个奇数次 → 可以组成 "racecar" ✓

## Python 代码实现

### 方法一：哈希表计数（推荐）⭐

```python
from collections import Counter

class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        # 统计每个字符的出现次数
        count = Counter(s)
        
        # 统计出现奇数次的字符个数
        odd_count = sum(1 for freq in count.values() if freq % 2 == 1)
        
        # 最多只能有一个字符出现奇数次
        return odd_count <= 1
```

### 方法二：字典计数

```python
class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        # 手动构建字符计数字典
        count = {}
        for char in s:
            count[char] = count.get(char, 0) + 1
        
        # 统计奇数次字符
        odd_count = 0
        for freq in count.values():
            if freq % 2 == 1:
                odd_count += 1
                if odd_count > 1:  # 提前退出优化
                    return False
        
        return True
```

### 方法三：集合方法（巧妙）

```python
class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        """
        利用集合的性质：
        - 如果字符出现偶数次，加入再删除，集合不变
        - 如果字符出现奇数次，最终会留在集合中
        """
        char_set = set()
        
        for char in s:
            if char in char_set:
                char_set.remove(char)
            else:
                char_set.add(char)
        
        # 最多只能剩下一个字符（奇数次）
        return len(char_set) <= 1
```

### 方法四：位运算（高级）

```python
class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        """
        使用位运算优化空间
        适用于字符集较小的情况（如 26 个小写字母）
        """
        # 使用一个整数的每一位表示某个字符出现次数的奇偶性
        bitmap = 0
        
        for char in s:
            # 计算字符对应的位
            bit = 1 << (ord(char) - ord('a'))
            # 异或操作：出现偶数次变 0，奇数次变 1
            bitmap ^= bit
        
        # 检查 bitmap 是否最多只有 1 位为 1
        # bitmap & (bitmap - 1) 可以消除最右边的 1
        return bitmap == 0 or (bitmap & (bitmap - 1)) == 0
```

### 方法五：一行代码

```python
from collections import Counter

class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        return sum(v % 2 for v in Counter(s).values()) <= 1
```

## 复杂度分析

### 方法一、二、五
- **时间复杂度**：O(n)，遍历字符串一次统计，再遍历字典一次检查
- **空间复杂度**：O(k)，k 是字符集大小（小写字母最多 26）

### 方法三（集合）
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(k)，集合最多存储 k 个字符

### 方法四（位运算）
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，只用一个整数

## 关键点总结

1. **回文串特性**：字符出现次数必须满足最多一个奇数
2. **计数方法**：
   - Counter（最简洁）
   - 字典（基础方法）
   - 集合（巧妙）
   - 位运算（空间最优）
3. **优化技巧**：在统计过程中发现奇数次字符超过 1 个可提前返回
4. **集合方法原理**：利用配对消除的思想
5. **位运算技巧**：`bitmap & (bitmap - 1) == 0` 判断是否只有一位为 1

## 易错点

1. **边界条件**：空字符串可以组成回文（奇数次字符为 0 个）
2. **奇偶判断**：要统计出现**奇数次**的字符个数，不是偶数次
3. **判断条件**：是 `<= 1` 而不是 `== 1`（偶数长度字符串时为 0）
4. **字符集假设**：不要假设只有小写字母，除非题目明确说明
5. **集合方法**：要用 `remove` 而不是 `discard`（确保字符存在）

1. **理解回文的性质**：
   - 偶数长度：所有字符偶数次
   - 奇数长度：一个字符奇数次，其他偶数次

2. **掌握多种实现**：
   - 方法一（Counter）最常用
   - 方法三（集合）最巧妙
   - 方法四（位运算）面试亮点

3. **位运算技巧**：
   - `bitmap ^= bit`：异或实现奇偶切换
   - `bitmap & (bitmap - 1)`：消除最右边的 1
   - 这两个技巧在很多位运算题中都会用到

4. **举一反三**：

   - 理解本题是下一题的基础

5. **优化思考**：
   - 能否提前退出？（统计到第 2 个奇数次字符时）
   - 能否用更少的空间？（位运算 O(1)）
   - 能否用更简洁的代码？（一行代码）
