## 题目描述

给你一个字符串数组 `words` 和一个字符串 `target`。

你可以从 `words` 中任意选取字符串的**前缀**，将它们拼接起来形成 `target`。

返回形成 `target` 所需的**最少字符串（前缀）数量**，若无法形成返回 -1。

**示例 1：**
```
输入：words = ["abc","aaaaa","bcdef"], target = "aaaabc"
输出：3
解释："a" + "a" + "aabc"... 不对，需要用前缀
"aaaaa"的前缀"aa" + "abc"的前缀"abc" + ... = "aaabc"
最少3个？
```

**示例 2：**
```
输入：words = ["abcd","bcd"], target = "abcd"
输出：1
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 5 * 10^4`
- `1 <= target.length <= 5 * 10^4`

## 解题思路

BFS/DP 最短路：

`dp[i]` = 构造 `target[0..i-1]` 所需的最少前缀数。

对每个位置 i，找所有能从 i 开始匹配的 words 前缀，取最小转移。

用字典树存储所有 words，从每个位置 i 开始匹配字典树，找到所有可达位置。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minValidStrings(self, words: List[str], target: str) -> int:
        n = len(target)
        
        # 构建字典树
        trie = [{}]
        for word in words:
            node = 0
            for c in word:
                if c not in trie[node]:
                    trie.append({})
                    trie[node][c] = len(trie) - 1
                node = trie[node][c]
        
        # BFS：最少步数到达 target 末尾
        dist = [-1] * (n + 1)
        dist[0] = 0
        q = deque([0])
        
        while q:
            i = q.popleft()
            # 从位置 i 开始，沿字典树匹配
            node = 0
            for j in range(i, n):
                c = target[j]
                if c not in trie[node]:
                    break
                node = trie[node][c]
                # 可以跳到 j+1
                if dist[j + 1] == -1:
                    dist[j + 1] = dist[i] + 1
                    q.append(j + 1)
        
        return dist[n]
```

### 方法二：DP

```python
from typing import List

class Solution:
    def minValidStrings(self, words: List[str], target: str) -> int:
        n = len(target)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        # 字典树
        trie = [{}]
        for word in words:
            node = 0
            for c in word:
                if c not in trie[node]:
                    trie.append({})
                    trie[node][c] = len(trie) - 1
                node = trie[node][c]
        
        for i in range(n):
            if dp[i] == INF:
                continue
            node = 0
            for j in range(i, n):
                c = target[j]
                if c not in trie[node]:
                    break
                node = trie[node][c]
                dp[j + 1] = min(dp[j + 1], dp[i] + 1)
        
        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n^2 + sum(|words|))
- 空间复杂度：O(sum(|words|) + n)

## 关键点总结

1. 字典树从每个位置匹配所有可达的前缀
2. BFS 求最少步数
3. 与 Word Break 问题类似，但可以用前缀

## 易错点

1. 是 words 的前缀，不是完整单词
2. 注意无法形成时返回 -1
