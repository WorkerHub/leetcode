## 题目描述

给定两个人的空闲时间表 `slots1` 和 `slots2`，以及会议持续时间 `duration`，请你为他们安排合适的会议时间。

你需要返回他们都有空的最早的时间段，这个时间段需要大于等于 `duration`。

如果没有满足要求的会议时间，就返回一个空数组。

「空闲时间段」的格式是 `[start, end]`，由开始时间 `start` 和结束时间 `end` 组成，表示从 `start` 开始，到 `end` 结束。

题目保证同一个人的空闲时间不会重叠，也就是说，对于同一个人的任意两个空闲时间 `[start1, end1]` 和 `[start2, end2]`，要么 `start1 > end2`，要么 `start2 > end1`。

示例 1：
```
输入：slots1 = [[10,50],[60,120],[140,210]], slots2 = [[0,15],[60,70]], duration = 8
输出：[60,68]
```

示例 2：
```
输入：slots1 = [[10,50],[60,120],[140,210]], slots2 = [[0,15],[60,70]], duration = 12
输出：[]
```

提示：
- `1 <= slots1.length, slots2.length <= 10^4`
- `slots1[i].length, slots2[i].length == 2`
- `slots1[i][0] < slots1[i][1]`
- `slots2[i][0] < slots2[i][1]`
- `0 <= slots1[i][j], slots2[i][j] <= 10^9`
- `1 <= duration <= 10^6`

## 解题思路

这是一个经典的区间交集问题。我们需要找到两个时间表的重叠部分，并判断重叠部分是否足够长。

核心思路：
1. 先对两个时间表分别按开始时间排序
2. 使用双指针遍历两个时间表
3. 对于当前指向的两个时间段，计算它们的交集
4. 如果交集长度 >= duration，返回结果
5. 移动结束时间更早的指针

交集的计算：
- 交集开始时间 = max(start1, start2)
- 交集结束时间 = min(end1, end2)
- 如果开始时间 < 结束时间，说明有交集

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def minAvailableDuration(self, slots1: List[List[int]], slots2: List[List[int]], duration: int) -> List[int]:
        """
        使用双指针找到最早的可用时间段
        
        Args:
            slots1: 第一个人的空闲时间段
            slots2: 第二个人的空闲时间段
            duration: 会议持续时间
            
        Returns:
            最早的可用时间段 [start, end]
        """
        # 按开始时间排序
        slots1.sort()
        slots2.sort()
        
        i, j = 0, 0
        
        while i < len(slots1) and j < len(slots2):
            # 计算当前两个时间段的交集
            start = max(slots1[i][0], slots2[j][0])
            end = min(slots1[i][1], slots2[j][1])
            
            # 如果交集长度足够
            if end - start >= duration:
                return [start, start + duration]
            
            # 移动结束时间更早的指针
            if slots1[i][1] < slots2[j][1]:
                i += 1
            else:
                j += 1
        
        return []
```

### 方法二：优化版（提前过滤）

```python
from typing import List

class Solution:
    def minAvailableDuration(self, slots1: List[List[int]], slots2: List[List[int]], duration: int) -> List[int]:
        """
        优化：提前过滤掉不够长的时间段
        """
        # 只保留长度 >= duration 的时间段
        slots1 = [slot for slot in slots1 if slot[1] - slot[0] >= duration]
        slots2 = [slot for slot in slots2 if slot[1] - slot[0] >= duration]
        
        # 排序
        slots1.sort()
        slots2.sort()
        
        i, j = 0, 0
        
        while i < len(slots1) and j < len(slots2):
            # 计算交集
            start = max(slots1[i][0], slots2[j][0])
            end = min(slots1[i][1], slots2[j][1])
            
            # 因为已经过滤，只要有交集就一定满足条件
            if start < end:
                return [start, start + duration]
            
            # 移动指针
            if slots1[i][1] < slots2[j][1]:
                i += 1
            else:
                j += 1
        
        return []
```

### 方法三：使用堆（适用于多人场景）

```python
from typing import List
import heapq

class Solution:
    def minAvailableDuration(self, slots1: List[List[int]], slots2: List[List[int]], duration: int) -> List[int]:
        """
        使用最小堆，更容易扩展到多人场景
        """
        # 合并所有时间段，并标记来源
        heap = []
        for slot in slots1:
            if slot[1] - slot[0] >= duration:
                heapq.heappush(heap, (slot[0], slot[1], 1))
        
        for slot in slots2:
            if slot[1] - slot[0] >= duration:
                heapq.heappush(heap, (slot[0], slot[1], 2))
        
        # 记录每个来源的最新区间
        latest = {1: None, 2: None}
        
        while heap:
            start, end, source = heapq.heappop(heap)
            latest[source] = (start, end)
            
            # 如果两个来源都有区间
            if latest[1] and latest[2]:
                s1, e1 = latest[1]
                s2, e2 = latest[2]
                
                # 计算交集
                inter_start = max(s1, s2)
                inter_end = min(e1, e2)
                
                if inter_end - inter_start >= duration:
                    return [inter_start, inter_start + duration]
        
        return []
```

### 方法四：暴力解法（不推荐，仅用于理解）

```python
from typing import List

class Solution:
    def minAvailableDuration(self, slots1: List[List[int]], slots2: List[List[int]], duration: int) -> List[int]:
        """
        暴力解法：检查所有组合
        时间复杂度 O(n*m)，不推荐
        """
        min_start = float('inf')
        result = []
        
        for s1 in slots1:
            for s2 in slots2:
                # 计算交集
                start = max(s1[0], s2[0])
                end = min(s1[1], s2[1])
                
                # 如果交集足够长且开始时间更早
                if end - start >= duration and start < min_start:
                    min_start = start
                    result = [start, start + duration]
        
        return result
```

## 复杂度分析

**方法一（推荐）：**
- 时间复杂度：O(n log n + m log m)，其中 n 和 m 分别是两个数组的长度，主要是排序的开销
- 空间复杂度：O(log n + log m)，排序的空间复杂度

**方法二：**
- 时间复杂度：O(n log n + m log m)
- 空间复杂度：O(n + m)，过滤后可能需要新的数组

**方法三：**
- 时间复杂度：O((n + m) log(n + m))
- 空间复杂度：O(n + m)

**方法四：**
- 时间复杂度：O(n × m)
- 空间复杂度：O(1)

## 关键点总结

1. 区间交集的计算：`start = max(s1, s2)`, `end = min(e1, e2)`
2. 双指针移动策略：总是移动结束时间更早的指针
3. 可以提前过滤不满足长度要求的时间段，提高效率
4. 排序是关键步骤，确保我们找到的是最早的时间段
5. 注意边界条件：空数组、所有时间段都不够长等

## 易错点

1. 忘记排序就直接使用双指针
2. 指针移动逻辑错误，可能导致漏掉某些交集
3. 交集计算错误：混淆 max 和 min
4. 返回值错误：应该返回 [start, start + duration]，而不是 [start, end]
5. 没有处理没有交集的情况（返回空数组）
