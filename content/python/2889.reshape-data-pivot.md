## 题目描述

给定一个 DataFrame `weather`，将其从长格式（每行一个月份+城市）转换为宽格式（每行一个城市，每列一个月份）。

**示例：**
```
输入（长格式）：
| month | city     | temperature |
|-------|----------|-------------|
| Jan   | London   | 25          |
| Jan   | Dubai    | 32          |
| Feb   | London   | 22          |
| Feb   | Dubai    | 35          |

输出（宽格式）：
| city   | Jan | Feb |
|--------|-----|-----|
| Dubai  | 32  | 35  |
| London | 25  | 22  |
```

## Python 代码实现

### 方法一：pivot（推荐）

```python
import pandas as pd

def pivotTable(weather: pd.DataFrame) -> pd.DataFrame:
    # 行：city，列：month，值：temperature
    return weather.pivot(index='city', columns='month', values='temperature')
```

### 方法二：pivot_table（允许聚合）

```python
import pandas as pd

def pivotTable(weather: pd.DataFrame) -> pd.DataFrame:
    return weather.pivot_table(index='city', columns='month', values='temperature', aggfunc='first')
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `df.pivot(index, columns, values)` 长格式转宽格式
2. 若有重复的 (index, columns) 组合，用 `pivot_table` 指定聚合函数
3. 宽格式转长格式用 `pd.melt()`（见 2890）
