## 题目描述

给定一个整数 `n` 和一个整数数组 `blacklist`。设计一个算法从 `[0, n)` 中随机选择一个数字，但该数字不在 `blacklist` 中。任何在 `[0, n)` 且不在 `blacklist` 中的数字被选中的概率应该相等。

优化你的算法，使其最小化调用系统方法 `Math.random()` 的次数。

实现 `Solution` 类：
- `Solution(int n, int[] blacklist)` 初始化整数 `n` 和被加入黑名单 `blacklist` 的整数。
- `int pick()` 返回一个随机的整数，该整数在 `[0, n)` 中且不在 `blacklist` 中。

**示例 1：**

```
输入：
["Solution", "pick", "pick", "pick", "pick", "pick", "pick", "pick"]
[[7, [2, 3, 5]], [], [], [], [], [], [], []]
输出：
[null, 0, 4, 1, 6, 1, 0, 4]

解释：
Solution solution = new Solution(7, [2, 3, 5]);
solution.pick(); // 返回 0，在范围 [0, 1, 4, 6] 中随机选择一个数字。
solution.pick(); // 返回 4
solution.pick(); // 返回 1
solution.pick(); // 返回 6
solution.pick(); // 返回 1
solution.pick(); // 返回 0
solution.pick(); // 返回 4
```

**提示：**
- `1 <= n <= 10^9`
- `0 <= blacklist.length <= min(10^5, n - 1)`
- `0 <= blacklist[i] < n`
- `blacklist` 中所有值都不同
- `pick` 最多被调用 `2 * 10^4` 次

## 解题思路

这道题的关键是如何高效地从 `[0, n)` 中排除黑名单后随机选择。

**核心思想：映射法**

将 `[0, n)` 分为两部分：
1. **白名单区域** `[0, m)`：其中 `m = n - len(blacklist)`
2. **映射区域** `[m, n)`

**算法流程：**
1. 计算白名单大小 `m = n - len(blacklist)`
2. 将 `[0, m)` 中的黑名单数字映射到 `[m, n)` 中的白名单数字
3. 随机生成 `[0, m)` 中的数字
4. 如果该数字在映射表中，返回映射值；否则直接返回

**关键点：**
- `[0, m)` 区域最多有 `len(blacklist)` 个黑名单数字
- `[m, n)` 区域至少有 `len(blacklist)` 个白名单数字
- 通过映射将前半部分的黑名单数字指向后半部分的白名单数字

## Python 代码实现

### 方法一：映射法（推荐）⭐

```python
import random
from typing import List

class Solution:
    def __init__(self, n: int, blacklist: List[int]):
        """
        使用映射法：将 [0, m) 中的黑名单数字映射到 [m, n) 中的白名单数字
        m = n - len(blacklist) 是白名单的大小
        """
        self.m = n - len(blacklist)  # 白名单大小
        self.mapping = {}  # 映射表
        
        # 将黑名单转为集合，方便查找
        blacklist_set = set(blacklist)
        
        # 找到 [m, n) 中的白名单数字
        last = n - 1
        
        # 遍历 [0, m) 中的黑名单数字
        for b in blacklist:
            if b < self.m:  # 只处理前半部分的黑名单
                # 找到 [m, n) 中的白名单数字进行映射
                while last in blacklist_set:
                    last -= 1
                
                # 建立映射关系
                self.mapping[b] = last
                last -= 1

    def pick(self) -> int:
        """
        随机选择 [0, m) 中的数字
        如果在映射表中，返回映射值；否则直接返回
        """
        index = random.randint(0, self.m - 1)
        
        # 如果 index 在映射表中，返回映射后的值
        return self.mapping.get(index, index)
```

### 方法二：详细注释版

```python
import random
from typing import List

class Solution:
    def __init__(self, n: int, blacklist: List[int]):
        # 白名单大小 = 总数 - 黑名单数量
        self.m = n - len(blacklist)
        self.mapping = {}
        
        # 将黑名单转为集合，O(1) 查找
        blacklist_set = set(blacklist)
        
        # last 指针从 n-1 开始，向前寻找白名单数字
        last = n - 1
        
        # 只需要处理 [0, m) 中的黑名单数字
        # [m, n) 中的黑名单数字可以直接忽略
        for b in blacklist:
            if b < self.m:
                # 从后往前找到第一个白名单数字
                while last in blacklist_set:
                    last -= 1
                
                # 将黑名单数字 b 映射到白名单数字 last
                self.mapping[b] = last
                
                # 继续寻找下一个可用的白名单数字
                last -= 1

    def pick(self) -> int:
        # 在 [0, m) 范围内随机选择
        index = random.randint(0, self.m - 1)
        
        # 如果随机到的是黑名单数字，返回映射后的值
        # 否则直接返回该数字
        return self.mapping.get(index, index)
```

### 方法三：使用列表（不推荐，空间复杂度高）

```python
import random
from typing import List

class Solution:
    def __init__(self, n: int, blacklist: List[int]):
        """
        直接构建白名单列表
        当 n 很大时，空间复杂度过高
        """
        blacklist_set = set(blacklist)
        self.whitelist = [i for i in range(n) if i not in blacklist_set]

    def pick(self) -> int:
        # 从白名单中随机选择
        return random.choice(self.whitelist)
```

## 复杂度分析

### 方法一（映射法）：
- **初始化时间复杂度：** O(B)，其中 B 是黑名单长度
- **初始化空间复杂度：** O(B)，映射表最多存储 B 个元素
- **pick 时间复杂度：** O(1)
- **pick 空间复杂度：** O(1)

### 方法三（白名单列表）：
- **初始化时间复杂度：** O(n)
- **初始化空间复杂度：** O(n - B)，需要存储所有白名单数字
- **pick 时间复杂度：** O(1)
- **pick 空间复杂度：** O(1)

**对比：** 当 n 很大（如 10^9）时，方法一的空间优势明显。

## 图解示例

以 `n = 7, blacklist = [2, 3, 5]` 为例：

```
原始范围: [0, 1, 2, 3, 4, 5, 6]
黑名单:        ✗  ✗     ✗
白名单:   [0, 1,       4,    6]

m = 7 - 3 = 4（白名单大小）

分区：
[0, m) = [0, 1, 2, 3]  <- 前半部分，可能含有黑名单
[m, n) = [4, 5, 6]     <- 后半部分，可能含有白名单

前半部分黑名单: [2, 3]
后半部分白名单: [4, 6]（5 是黑名单，跳过）

映射关系：
2 -> 6
3 -> 4

随机过程：
random(0, 3) = 0 -> 0 (不在映射表) -> 返回 0 ✓
random(0, 3) = 1 -> 1 (不在映射表) -> 返回 1 ✓
random(0, 3) = 2 -> 2 (在映射表) -> 返回 6 ✓
random(0, 3) = 3 -> 3 (在映射表) -> 返回 4 ✓
```

## 关键点总结

1. **空间优化**：通过映射法将空间复杂度从 O(n) 降到 O(B)
2. **分区思想**：将范围分为前后两部分，只映射前半部分的黑名单
3. **映射策略**：前半部分黑名单 -> 后半部分白名单
4. **随机均匀性**：每个白名单数字被选中的概率相等（1/m）
5. **哈希表应用**：使用字典实现快速映射查找

## 易错点

1. **忘记过滤后半部分黑名单**：只需要映射 `[0, m)` 中的黑名单，`[m, n)` 中的黑名单直接忽略
2. **映射数字冲突**：从后往前找白名单时，要确保 `last` 不在黑名单中
3. **随机范围错误**：应该在 `[0, m)` 中随机，而不是 `[0, n)`
4. **边界条件**：黑名单为空时，直接随机 `[0, n)` 即可
5. **空间浪费**：不要尝试构建完整的白名单列表，当 n 很大时会 MLE
