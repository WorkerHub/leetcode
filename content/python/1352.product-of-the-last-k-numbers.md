## 题目描述

请你实现一个「数字乘积」类 `ProductOfNumbers`，要求支持下述两种方法：

1. `add(int num)` — 将数字 `num` 添加到当前数字列表的最后面。
2. `getProduct(int k)` — 返回当前数字列表中，最后 `k` 个数字的乘积。你可以假设当前列表中始终 **至少** 存在 `k` 个数字。

**题目保证：** `getProduct` 的输入 `k` 总是合法的，即最近一次 `add` 操作后，列表中至少有 `k` 个数字。另外，答案保证在 32 位整数范围内。

**示例：**
```
输入：
["ProductOfNumbers","add","add","add","add","add","getProduct","getProduct","getProduct","add","getProduct"]
[[],[3],[0],[2],[5],[4],[2],[3],[4],[8],[2]]

输出：
[null,null,null,null,null,null,20,40,0,null,32]

解释：
ProductOfNumbers productOfNumbers = new ProductOfNumbers();
productOfNumbers.add(3);        // [3]
productOfNumbers.add(0);        // [3,0]
productOfNumbers.add(2);        // [3,0,2]
productOfNumbers.add(5);        // [3,0,2,5]
productOfNumbers.add(4);        // [3,0,2,5,4]
productOfNumbers.getProduct(2); // 最后 2 个数 5*4=20
productOfNumbers.getProduct(3); // 最后 3 个数 2*5*4=40
productOfNumbers.getProduct(4); // 最后 4 个数含 0，结果=0
productOfNumbers.add(8);        // [3,0,2,5,4,8]
productOfNumbers.getProduct(2); // 最后 2 个数 4*8=32
```

**提示：**
- `add` 和 `getProduct` 最多各被调用 40000 次
- `0 <= num <= 100`
- `1 <= k <= 40000`

## 解题思路

**朴素想法（超时）：** 直接维护列表，`getProduct(k)` 时遍历最后 k 个数相乘，时间 O(k)，频繁查询时很慢。

**前缀积优化（推荐）：**

维护一个前缀积数组 `prefix`，`prefix[i]` 表示从位置 0 到位置 i-1 的所有数字的乘积。

`getProduct(k)` = `prefix[-1] / prefix[-(k+1)]`，即利用除法在 O(1) 时间内得到最后 k 个数的乘积。

**关键挑战：遇到 0 怎么办？**

0 的存在导致无法直接相除（除以 0 无意义）。解决方案：**遇到 0 时重置前缀积数组**。因为 0 之前的数字对后续任何查询都没有贡献（只要 k 覆盖到 0，结果必为 0）。

**重置后的 0 判断：** 如果查询的最后 k 个数包含了 0（即 k >= 当前前缀积数组长度），直接返回 0。

## Python 代码实现

### 方法一：前缀积 + 遇 0 重置（推荐）

```python
class ProductOfNumbers:

    def __init__(self):
        # prefix[i] 表示当前窗口从第 0 个数到第 i-1 个数的乘积
        # 初始化为 [1]，方便后续相除
        self.prefix = [1]

    def add(self, num: int) -> None:
        if num == 0:
            # 遇到 0，重置前缀积（0 之前的元素对后续查询无贡献）
            self.prefix = [1]
        else:
            # 新的前缀积 = 上一个前缀积 * num
            self.prefix.append(self.prefix[-1] * num)

    def getProduct(self, k: int) -> int:
        # 如果 k >= 前缀积数组长度（不含初始的 1），说明范围内包含了 0
        if k >= len(self.prefix):
            return 0
        # 最后 k 个数的乘积 = 全部乘积 / 前 (len-k-1) 个数的乘积
        return self.prefix[-1] // self.prefix[-k - 1]
```

### 方法二：朴素列表（简单但较慢）

```python
class ProductOfNumbers:

    def __init__(self):
        self.nums = []

    def add(self, num: int) -> None:
        self.nums.append(num)

    def getProduct(self, k: int) -> int:
        product = 1
        # 遍历最后 k 个数
        for i in range(len(self.nums) - k, len(self.nums)):
            product *= self.nums[i]
        return product
```

### 方法三：前缀积（保留 0，使用哈希记录 0 的位置）

```python
class ProductOfNumbers:
    """
    另一种思路：维护完整前缀积，同时记录 0 的位置。
    getProduct(k) 时，若区间内有 0，返回 0；否则相除。
    """

    def __init__(self):
        self.prefix = [1]
        # 记录所有 0 的位置（在 prefix 中的下标，等于添加时 prefix 的当前长度）
        self.zero_positions = []

    def add(self, num: int) -> None:
        if num == 0:
            # 记录 0 出现的位置（当前 prefix 长度即下一个数的位置）
            self.zero_positions.append(len(self.prefix))
            # 前缀积照常添加（0 * anything = 0）
            self.prefix.append(0)
        else:
            self.prefix.append(self.prefix[-1] * num if self.prefix[-1] != 0 else 0)

    def getProduct(self, k: int) -> int:
        n = len(self.prefix) - 1  # 当前数字总数
        start = n - k             # 最后 k 个数的起始下标（0-indexed）
        # 检查 [start, n-1] 内是否有 0
        # zero_positions 存储的是添加位置（1-indexed 对应 prefix 下标）
        # 如果最后一个 0 的下标 > start，则范围内含 0
        import bisect
        idx = bisect.bisect_right(self.zero_positions, start)
        if idx < len(self.zero_positions):
            return 0
        # 无 0，使用前缀积相除
        return self.prefix[n] // self.prefix[start]
```

## 复杂度分析

| 方法 | add 时间 | getProduct 时间 | 空间复杂度 |
|------|----------|-----------------|------------|
| 方法一（推荐） | O(1) | O(1) | O(n) |
| 方法二（朴素） | O(1) | O(k) | O(n) |
| 方法三 | O(1) | O(log n) | O(n) |

方法一最优，add 和 getProduct 均为 O(1)。

## 关键点总结

1. **前缀积思想**：`product(last k)` = `prefix[n] / prefix[n-k]`，O(1) 查询。
2. **0 的特殊处理**：遇到 0 直接重置数组，因为 0 之前的数对后续查询无用。
3. **0 判断**：`k >= len(prefix)` 说明查询范围覆盖了上次重置点（即包含了 0），返回 0。
4. **除法有效性**：由于重置了包含 0 的前缀，剩余前缀积全是正数，整除结果正确。
5. **初始化 [1]**：前缀积数组初始含 1，使得 `prefix[-1] / prefix[-(k+1)]` 写法统一。

## 易错点

- `getProduct(k)` 时边界判断：当 `k == len(prefix) - 1` 时，`prefix[-k-1]` 访问的是 `prefix[0] = 1`，结果正确；当 `k >= len(prefix)` 时包含了 0，需返回 0。
- 遇到 0 重置时，新数组初始化为 `[1]` 而不是 `[]`，确保后续 add 操作能正常运行。
- 整除 `//` 只在所有数都是整数时正确，本题保证数字都是非负整数，可以放心使用。
