## 题目描述

**游程编码（Run-Length Encoding, RLE）**将数组压缩为 `[val, freq]` 的形式，表示连续 `freq` 个 `val`。

给你两个以 RLE 格式表示的数组 `encoded1` 和 `encoded2`，返回两个数组按元素相乘后的 RLE 结果。

**示例：**
```
输入：encoded1 = [[1,3],[2,3]], encoded2 = [[6,3],[3,3]]
输出：[[6,6]]
解释：encoded1 = [1,1,1,2,2,2], encoded2 = [6,6,6,3,3,3]
     乘积 = [6,6,6,6,6,6] -> [[6,6]]
```

**提示：**
- `1 <= encoded1.length, encoded2.length <= 10^5`

## 解题思路

**双指针模拟**：

用两个指针分别指向 encoded1 和 encoded2 的当前段。每次取两段中较短的重叠部分，计算乘积，然后移除已处理的频率。

注意合并相邻值相同的段（将相同乘积的连续段合并）。

## 代码实现

### 方法一：双指针模拟（推荐）

```python
from typing import List

class Solution:
    def findRLEArray(self, encoded1: List[List[int]], encoded2: List[List[int]]) -> List[List[int]]:
        result = []
        i, j = 0, 0
        freq1 = freq2 = 0  # 当前段已处理的频率

        while i < len(encoded1) and j < len(encoded2):
            val1, f1 = encoded1[i]
            val2, f2 = encoded2[j]

            # 剩余未处理的频率
            remain1 = f1 - freq1
            remain2 = f2 - freq2

            # 取两段中重叠的部分（取最小值）
            overlap = min(remain1, remain2)
            product = val1 * val2

            # 加入结果（若与上一段相同则合并）
            if result and result[-1][0] == product:
                result[-1][1] += overlap
            else:
                result.append([product, overlap])

            # 更新已处理频率
            freq1 += overlap
            freq2 += overlap

            # 移动指针（若当前段已处理完）
            if freq1 == f1:
                i += 1
                freq1 = 0
            if freq2 == f2:
                j += 1
                freq2 = 0

        return result
```

### 方法二：简化版（直接修改剩余频率）

```python
from typing import List

class Solution:
    def findRLEArray(self, encoded1: List[List[int]], encoded2: List[List[int]]) -> List[List[int]]:
        res = []
        i = j = 0

        while i < len(encoded1):
            v1, f1 = encoded1[i]
            v2, f2 = encoded2[j]
            prod = v1 * v2
            overlap = min(f1, f2)

            if res and res[-1][0] == prod:
                res[-1][1] += overlap
            else:
                res.append([prod, overlap])

            encoded1[i][1] -= overlap
            encoded2[j][1] -= overlap

            if encoded1[i][1] == 0:
                i += 1
            if encoded2[j][1] == 0:
                j += 1

        return res
```

## 复杂度分析

- **时间复杂度**：O(m + n)，m 和 n 为两个编码数组的长度
- **空间复杂度**：O(m + n)，结果数组

## 关键点总结

1. 双指针同步处理，每次处理重叠部分（取两段频率的最小值）
2. 相邻相同乘积的段需要合并，避免结果冗余
3. 用剩余频率来追踪每段的处理进度

## 易错点

- 不能直接逐元素展开再乘再编码（会 TLE 且 MLE）
- 处理完一段后，只有该段频率降为 0 才移动对应指针
