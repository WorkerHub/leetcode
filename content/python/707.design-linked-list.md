## 题目描述

设计链表的实现。您可以选择使用单链表或双链表。单链表中的节点应该具有两个属性：`val` 和 `next`。`val` 是当前节点的值，`next` 是指向下一个节点的指针/引用。如果要使用双向链表，则还需要一个属性 `prev` 以指示链表中的上一个节点。假设链表中的所有节点都是 0-index 的。

在链表类中实现这些功能：

- `get(index)`：获取链表中第 `index` 个节点的值。如果索引无效，则返回 `-1`。
- `addAtHead(val)`：在链表的第一个元素之前添加一个值为 `val` 的节点。插入后，新节点将成为链表的第一个节点。
- `addAtTail(val)`：将值为 `val` 的节点追加到链表的最后一个元素。
- `addAtIndex(index, val)`：在链表中的第 `index` 个节点之前添加值为 `val` 的节点。如果 `index` 等于链表的长度，则该节点将附加到链表的末尾。如果 `index` 大于链表长度，则不会插入节点。如果 `index` 小于 0，则在头部插入节点。
- `deleteAtIndex(index)`：如果索引 `index` 有效，则删除链表中的第 `index` 个节点。

**示例：**

```
MyLinkedList linkedList = new MyLinkedList();
linkedList.addAtHead(1);
linkedList.addAtTail(3);
linkedList.addAtIndex(1,2);   // 链表变为1->2->3
linkedList.get(1);            // 返回2
linkedList.deleteAtIndex(1);  // 现在链表是1->3
linkedList.get(1);            // 返回3
```

**提示：**
- `0 <= index, val <= 1000`
- 请不要使用内置的 LinkedList 库。
- `get`、`addAtHead`、`addAtTail`、`addAtIndex` 和 `deleteAtIndex` 的调用次数不超过 `2000`。

## 解题思路

这是一道链表设计题，需要实现一个完整的链表数据结构。可以选择单链表或双链表实现。

**核心思想：**
1. 使用虚拟头节点（dummy head）简化边界处理
2. 维护链表长度，方便快速判断索引有效性
3. 实现基本的链表操作：查找、插入、删除

**关键点：**
- 使用 dummy 节点避免处理头节点的特殊情况
- 正确维护链表长度
- 注意边界条件的处理（index 的合法性）

## Python 代码实现

### 方法一：单链表实现（推荐）⭐

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class MyLinkedList:
    def __init__(self):
        # 使用虚拟头节点，简化边界处理
        self.dummy = ListNode(0)
        self.size = 0

    def get(self, index: int) -> int:
        """获取第 index 个节点的值"""
        # 索引无效
        if index < 0 or index >= self.size:
            return -1
        
        # 从 dummy.next 开始遍历
        current = self.dummy.next
        for _ in range(index):
            current = current.next
        
        return current.val

    def addAtHead(self, val: int) -> None:
        """在头部添加节点"""
        self.addAtIndex(0, val)

    def addAtTail(self, val: int) -> None:
        """在尾部添加节点"""
        self.addAtIndex(self.size, val)

    def addAtIndex(self, index: int, val: int) -> None:
        """在第 index 个位置插入节点"""
        # index 大于链表长度，不插入
        if index > self.size:
            return
        
        # index 小于 0，在头部插入
        if index < 0:
            index = 0
        
        # 找到插入位置的前一个节点
        pred = self.dummy
        for _ in range(index):
            pred = pred.next
        
        # 创建新节点并插入
        new_node = ListNode(val)
        new_node.next = pred.next
        pred.next = new_node
        
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        """删除第 index 个节点"""
        # 索引无效
        if index < 0 or index >= self.size:
            return
        
        # 找到删除位置的前一个节点
        pred = self.dummy
        for _ in range(index):
            pred = pred.next
        
        # 删除节点
        pred.next = pred.next.next
        
        self.size -= 1
```

### 方法二：双链表实现（更优化）

```python
class ListNode:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next

class MyLinkedList:
    def __init__(self):
        # 使用虚拟头尾节点
        self.head = ListNode(0)
        self.tail = ListNode(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def get(self, index: int) -> int:
        """获取第 index 个节点的值"""
        if index < 0 or index >= self.size:
            return -1
        
        # 优化：从较近的一端开始遍历
        if index < self.size // 2:
            # 从头开始
            current = self.head.next
            for _ in range(index):
                current = current.next
        else:
            # 从尾开始
            current = self.tail.prev
            for _ in range(self.size - 1 - index):
                current = current.prev
        
        return current.val

    def addAtHead(self, val: int) -> None:
        """在头部添加节点"""
        pred = self.head
        succ = self.head.next
        
        new_node = ListNode(val, pred, succ)
        pred.next = new_node
        succ.prev = new_node
        
        self.size += 1

    def addAtTail(self, val: int) -> None:
        """在尾部添加节点"""
        succ = self.tail
        pred = self.tail.prev
        
        new_node = ListNode(val, pred, succ)
        pred.next = new_node
        succ.prev = new_node
        
        self.size += 1

    def addAtIndex(self, index: int, val: int) -> None:
        """在第 index 个位置插入节点"""
        if index > self.size:
            return
        
        if index < 0:
            index = 0
        
        # 找到插入位置的后继节点
        if index < self.size // 2:
            succ = self.head.next
            for _ in range(index):
                succ = succ.next
        else:
            succ = self.tail
            for _ in range(self.size - index):
                succ = succ.prev
        
        pred = succ.prev
        
        # 插入新节点
        new_node = ListNode(val, pred, succ)
        pred.next = new_node
        succ.prev = new_node
        
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        """删除第 index 个节点"""
        if index < 0 or index >= self.size:
            return
        
        # 找到要删除的节点
        if index < self.size // 2:
            node = self.head.next
            for _ in range(index):
                node = node.next
        else:
            node = self.tail.prev
            for _ in range(self.size - 1 - index):
                node = node.prev
        
        # 删除节点
        pred = node.prev
        succ = node.next
        pred.next = succ
        succ.prev = pred
        
        self.size -= 1
```

## 复杂度分析

### 单链表实现：
- **时间复杂度：**
  - `get(index)`：O(index)，需要遍历到指定位置
  - `addAtHead(val)`：O(1)
  - `addAtTail(val)`：O(n)，需要遍历到尾部
  - `addAtIndex(index, val)`：O(index)
  - `deleteAtIndex(index)`：O(index)
- **空间复杂度：** O(1)，不考虑存储链表本身的空间

### 双链表实现：
- **时间复杂度：**
  - `get(index)`：O(min(index, n-index))，可以从两端遍历
  - `addAtHead(val)`：O(1)
  - `addAtTail(val)`：O(1)
  - `addAtIndex(index, val)`：O(min(index, n-index))
  - `deleteAtIndex(index)`：O(min(index, n-index))
- **空间复杂度：** O(1)，不考虑存储链表本身的空间

## 关键点总结

1. **虚拟节点的使用**：使用 dummy head 可以避免处理头节点的特殊情况，统一所有操作的逻辑
2. **维护链表长度**：通过 size 变量可以快速判断索引有效性，避免不必要的遍历
3. **双链表优化**：双链表可以从两端遍历，对于接近尾部的操作更高效
4. **边界条件处理**：注意 index 的合法性判断（负数、超出范围等）
5. **指针操作顺序**：插入和删除时要注意修改指针的顺序，避免链表断裂

## 易错点

1. **忘记更新 size**：每次插入或删除后要更新链表长度
2. **index 边界处理不当**：
   - `addAtIndex` 中 index == size 是合法的（尾部插入）
   - index < 0 时应在头部插入，而不是返回
3. **指针操作顺序错误**：
   - 插入时要先设置新节点的 next，再修改前驱节点的 next
   - 删除时要保存后继节点的引用
4. **双链表的 prev 和 next 不匹配**：修改链表时要同时更新双向指针
5. **虚拟节点的处理**：遍历时要从 dummy.next 开始，而不是 dummy
