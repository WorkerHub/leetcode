## 题目描述

给定一个 `m × n` 的整数矩阵 `grid`，从左上角 `(0,0)` 出发，到达右下角 `(m-1,n-1)`，路径必须经过中间单元格 `(m/2, n/2)`（向下取整）。每次只能向右或向下移动。求满足条件的最小路径代价（路径上所有单元格值之和）。

**示例 1：**
```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：25
解释：路径 (0,0)->(1,0)->(1,1)->(1,2)->(2,2)：1+4+5+6+9=25，经过中间格 (1,1)。
     路径 (0,0)->(0,1)->(1,1)->(2,1)->(2,2)：1+2+5+8+9=25，也经过 (1,1)。
```

**示例 2：**
```
输入：grid = [[5,1,2],[3,4,6],[8,7,9]]
输出：22
```

**提示：**
- `1 <= m, n <= 1000`，且 `m`, `n` 均为奇数
- `0 <= grid[i][j] <= 10^5`

## 解题思路

由于路径必须经过中间单元格 `mid = (m//2, n//2)`，可以将问题拆分为两段：

1. 从 `(0,0)` 到 `(mid_r, mid_c)` 的最小路径代价
2. 从 `(mid_r, mid_c)` 到 `(m-1, n-1)` 的最小路径代价

两段都是经典的"只能向右或向下"的 DP 问题。

- `dp1[i][j]`：从 `(0,0)` 到 `(i,j)` 的最小代价
- `dp2[i][j]`：从 `(i,j)` 到 `(m-1,n-1)` 的最小代价

答案 = `dp1[mid_r][mid_c] + dp2[mid_r][mid_c] - grid[mid_r][mid_c]`（中间格只计一次）

## Python 代码实现

### 方法一：分段 DP（推荐）

```python
from typing import List

class Solution:
    def minCostPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        mid_r, mid_c = m // 2, n // 2
        INF = float('inf')

        # 第一段 DP：从 (0,0) 到各点的最小代价
        dp1 = [[INF] * n for _ in range(m)]
        dp1[0][0] = grid[0][0]
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                top = dp1[i-1][j] if i > 0 else INF
                left = dp1[i][j-1] if j > 0 else INF
                dp1[i][j] = min(top, left) + grid[i][j]

        # 第二段 DP：从各点到 (m-1,n-1) 的最小代价（逆向 DP）
        dp2 = [[INF] * n for _ in range(m)]
        dp2[m-1][n-1] = grid[m-1][n-1]
        for i in range(m-1, -1, -1):
            for j in range(n-1, -1, -1):
                if i == m-1 and j == n-1:
                    continue
                bot = dp2[i+1][j] if i < m-1 else INF
                right = dp2[i][j+1] if j < n-1 else INF
                dp2[i][j] = min(bot, right) + grid[i][j]

        # 答案：两段之和减去中间格（被计算了两次）
        return dp1[mid_r][mid_c] + dp2[mid_r][mid_c] - grid[mid_r][mid_c]
```

### 方法二：两次正向 DP

```python
from typing import List

class Solution:
    def minCostPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        mid_r, mid_c = m // 2, n // 2

        def dp_from_start(sr, sc, er, ec):
            """从 (sr,sc) 到 (er,ec) 的最小路径代价"""
            rows = er - sr + 1
            cols = ec - sc + 1
            INF = float('inf')
            dp = [[INF] * cols for _ in range(rows)]
            dp[0][0] = grid[sr][sc]
            for i in range(rows):
                for j in range(cols):
                    if i == 0 and j == 0:
                        continue
                    top = dp[i-1][j] if i > 0 else INF
                    left = dp[i][j-1] if j > 0 else INF
                    dp[i][j] = min(top, left) + grid[sr+i][sc+j]
            return dp[rows-1][cols-1]

        cost1 = dp_from_start(0, 0, mid_r, mid_c)
        cost2 = dp_from_start(mid_r, mid_c, m-1, n-1)
        return cost1 + cost2 - grid[mid_r][mid_c]
```

## 复杂度分析

- 时间复杂度：O(mn)，两次 DP 各遍历全矩阵
- 空间复杂度：O(mn)，DP 数组

## 关键点总结

1. 强制经过某中间点时，将路径分为两段分别求最短路
2. 中间点被两段都计算了一次，最终需要减去一次
3. 第二段 DP 可以逆向（从终点往回）求解

## 易错点

1. 中间格的值被计算两次，答案需减去一次
2. 逆向 DP 的转移方向与正向相反（从右下取 min）
