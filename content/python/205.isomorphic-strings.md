## 题目描述

给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

**示例 1：**
```
输入：s = "egg", t = "add"
输出：true
解释：'e' -> 'a', 'g' -> 'd'
```

**示例 2：**
```
输入：s = "foo", t = "bar"
输出：false
解释：'o' 不能同时映射到 'a' 和 'r'
```

**示例 3：**
```
输入：s = "paper", t = "title"
输出：true
解释：'p' -> 't', 'a' -> 'i', 'e' -> 'l', 'r' -> 'e'
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `t.length == s.length`
- `s` 和 `t` 由任意有效的 ASCII 字符组成

## 解题思路

这道题的核心是理解**同构**的含义：

### 同构的定义

两个字符串同构，必须满足：
1. **一对一映射**：s 中的每个字符映射到 t 中的唯一字符
2. **双向映射**：不仅 s → t 要唯一，t → s 也要唯一
3. **位置对应**：相同位置的字符要满足映射关系

### 核心思想

需要建立**双向映射**：
- s → t 的映射
- t → s 的映射（防止多个字符映射到同一个字符）

### 解决方案

1. **双哈希表**：分别记录 s → t 和 t → s 的映射
2. **单哈希表 + 集合**：哈希表记录 s → t，集合记录 t 中已映射的字符
3. **模式编码**：将两个字符串编码成相同的模式

## Python 代码实现

### 方法一：双哈希表（推荐）⭐

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 建立双向映射
        s_to_t = {}  # s 到 t 的映射
        t_to_s = {}  # t 到 s 的映射
        
        for char_s, char_t in zip(s, t):
            # 检查 s -> t 的映射
            if char_s in s_to_t:
                if s_to_t[char_s] != char_t:
                    return False
            else:
                s_to_t[char_s] = char_t
            
            # 检查 t -> s 的映射
            if char_t in t_to_s:
                if t_to_s[char_t] != char_s:
                    return False
            else:
                t_to_s[char_t] = char_s
        
        return True
```

**代码说明**：
- 使用两个字典分别记录双向映射
- 遍历时同时检查两个方向的映射是否一致
- 如果发现冲突（一个字符映射到多个不同字符），返回 False

### 方法二：单哈希表 + 集合

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s_to_t = {}  # s 到 t 的映射
        used_t = set()  # t 中已经被映射的字符
        
        for char_s, char_t in zip(s, t):
            if char_s in s_to_t:
                # 如果已有映射，检查是否一致
                if s_to_t[char_s] != char_t:
                    return False
            else:
                # 如果 char_t 已经被其他字符映射，返回 False
                if char_t in used_t:
                    return False
                s_to_t[char_s] = char_t
                used_t.add(char_t)
        
        return True
```

**代码说明**：
- 用集合 `used_t` 记录 t 中已被映射的字符
- 确保 t 中的每个字符只被映射一次

### 方法三：模式编码⭐

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 将字符串编码成模式
        def encode(string: str) -> list:
            char_to_index = {}
            pattern = []
            for i, char in enumerate(string):
                if char not in char_to_index:
                    char_to_index[char] = i
                pattern.append(char_to_index[char])
            return pattern
        
        return encode(s) == encode(t)
```

**代码说明**：
- 将每个字符映射为它第一次出现的位置
- 两个字符串同构，当且仅当它们的编码模式相同
- 例如："egg" → [0, 1, 1]，"add" → [0, 1, 1]

### 方法四：简洁版（利用 Python 特性）

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 利用 map 和 set 的性质
        return len(set(s)) == len(set(t)) == len(set(zip(s, t)))
```

**代码说明**：
- `set(s)`：s 中不同字符的数量
- `set(t)`：t 中不同字符的数量
- `set(zip(s, t))`：不同映射对的数量
- 如果是同构的，三者应该相等

**示例**：
- s = "egg", t = "add"
- set(s) = {'e', 'g'}，长度 2
- set(t) = {'a', 'd'}，长度 2
- set(zip(s, t)) = {('e','a'), ('g','d')}，长度 2
- 三者相等，返回 True

### 方法五：使用 index 方法

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 每个位置字符第一次出现的位置应该相同
        for i in range(len(s)):
            if s.index(s[i]) != t.index(t[i]):
                return False
        return True
```

**代码说明**：
- `s.index(s[i])`：字符 s[i] 第一次出现的位置
- 同构字符串中，对应位置的字符第一次出现的位置应该相同

## 复杂度分析

### 方法一：双哈希表
- **时间复杂度**：O(n)，遍历一次字符串
- **空间复杂度**：O(n)，最坏情况下存储所有字符的映射

### 方法二：单哈希表 + 集合
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

### 方法三：模式编码
- **时间复杂度**：O(n)，需要遍历两次
- **空间复杂度**：O(n)，存储编码结果

### 方法四：简洁版
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

### 方法五：index 方法
- **时间复杂度**：O(n²)，每次 index 都是 O(n)
- **空间复杂度**：O(1)

映射关系：

```
位置：  0   1   2
s:     f   o   o
t:     b   a   r

映射关系：
f -> b
o -> a (第一次)
o -> r (第二次) ← 冲突！

o 不能同时映射到 a 和 r
返回 False
```

### 示例 3：s = "badc", t = "baba"

```
位置：  0   1   2   3
s:     b   a   d   c
t:     b   a   b   a

映射关系：
b -> b
a -> a
d -> b ← 冲突！

虽然 d -> b 本身没问题，
但 b 已经被 b 映射了（t -> s 方向）
返回 False
```

## 关键点总结

1. **双向映射**：必须同时检查 s → t 和 t → s 的映射
2. **一对一关系**：每个字符只能映射到唯一的字符
3. **位置对应**：相同位置的字符要满足映射关系
4. **多种实现**：哈希表、集合、模式编码都可以解决
5. **Python 技巧**：利用集合和 zip 可以简化代码

## 易错点

1. **忘记双向检查**：只检查 s → t，忘记检查 t → s
   - 错误案例：s = "ab", t = "aa"，如果只检查 s → t 会误判为 True
   
2. **边界情况**：
   - 空字符串（题目保证长度 >= 1）
   - 单字符字符串
   - 所有字符相同的字符串

3. **映射冲突**：没有检查一个字符是否映射到多个不同字符

4. **性能问题**：使用 index 方法会导致时间复杂度变为 O(n²)
