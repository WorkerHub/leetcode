## 题目描述

给你一个整数数组 `nums`，返回按位或（OR）等于整个数组按位或的非空子集数量。

**示例 1：**

```
输入：nums = [3,1]
输出：2
解释：总OR=3，子集[3]和[3,1]的OR均为3
```

**示例 2：**

```
输入：nums = [2,2,2]
输出：7
解释：所有非空子集OR均为2，共7个
```

**提示：**

- `1 <= nums.length <= 16`
- `1 <= nums[i] <= 10^5`

## 解题思路

先计算整个数组的 OR 值 `target`，然后统计 OR 等于 `target` 的非空子集数量。

由于 n <= 16，可以用状态压缩枚举所有 `2^n - 1` 个非空子集。

或者用 DP：`dp[v]` = OR 结果为 `v` 的子集数量。

## Python 代码实现

### 方法一：状态压缩枚举（推荐）

```python
from typing import List

class Solution:
    def countSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        target = 0
        for x in nums:
            target |= x

        count = 0
        for mask in range(1, 1 << n):
            or_val = 0
            for i in range(n):
                if mask >> i & 1:
                    or_val |= nums[i]
            if or_val == target:
                count += 1

        return count
```

### 方法二：动态规划

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubsets(self, nums: List[int]) -> int:
        target = 0
        for x in nums:
            target |= x

        # dp[v] = OR 为 v 的子集数（包含空集）
        dp = defaultdict(int)
        dp[0] = 1  # 空集

        for x in nums:
            new_dp = defaultdict(int)
            for v, cnt in dp.items():
                new_dp[v] += cnt         # 不选 x
                new_dp[v | x] += cnt     # 选 x
            dp = new_dp

        return dp[target]
```

## 复杂度分析

- 时间复杂度：O(2^n * n)（方法一），O(2^max_bit * n)（方法二）
- 空间复杂度：O(2^n)

## 关键点总结

1. 目标 OR 值一定是整个数组的 OR（OR 是单调的）
2. n <= 16 时状态压缩可行
3. DP 方式更通用

## 易错点

1. 只统计非空子集（`mask` 从 1 开始）
2. DP 中空集贡献需排除
3. OR 只能增加或不变，不能减少
