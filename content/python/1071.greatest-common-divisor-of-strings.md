## 题目描述

给定两个字符串 `str1` 和 `str2`，返回最长的字符串 `X`，使得 `X` 能够同时整除 `str1` 和 `str2`。

如果字符串 `T` 重复若干次可以得到字符串 `S`，那么我们称字符串 `T` 整除字符串 `S`。

**示例 1：**
```
输入：str1 = "ABCABC", str2 = "ABC"
输出："ABC"
```

**示例 2：**
```
输入：str1 = "ABABAB", str2 = "ABAB"
输出："AB"
```

**示例 3：**
```
输入：str1 = "LEET", str2 = "CODE"
输出：""
```

**提示：**
- `1 <= str1.length, str2.length <= 1000`
- `str1` 和 `str2` 由大写英文字母组成

## 解题思路

这道题的核心思想是利用**最大公约数（GCD）**的性质：

1. **关键观察**：如果存在公共整除字符串，那么 `str1 + str2` 应该等于 `str2 + str1`
   - 例如：`str1 = "ABCABC"`, `str2 = "ABC"`
   - `str1 + str2 = "ABCABCABC"`
   - `str2 + str1 = "ABCABCABC"`
   - 两者相等，说明存在公共整除字符串

2. **长度关系**：如果存在公共整除字符串，其长度必定是 `str1` 和 `str2` 长度的最大公约数
   - `str1` 的长度是公共字符串长度的倍数
   - `str2` 的长度也是公共字符串长度的倍数
   - 因此公共字符串的长度是两者长度的公约数，最长的就是最大公约数

3. **算法流程**：
   - 先判断 `str1 + str2` 是否等于 `str2 + str1`
   - 如果不等，返回空字符串
   - 如果相等，返回 `str1` 的前 `gcd(len(str1), len(str2))` 个字符

## Python 代码实现

### 方法一：GCD + 字符串拼接验证（推荐）

```python
from math import gcd
from typing import Optional

class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        # 如果 str1 + str2 != str2 + str1，说明不存在公共整除字符串
        if str1 + str2 != str2 + str1:
            return ""
        
        # 计算两个字符串长度的最大公约数
        gcd_len = gcd(len(str1), len(str2))
        
        # 返回长度为 gcd_len 的前缀
        return str1[:gcd_len]
```

### 方法二：枚举所有可能的长度

```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        # 辅助函数：判断 s 是否能整除 t
        def is_divisible(s: str, t: str) -> bool:
            if len(s) % len(t) != 0:
                return False
            # 检查 t 重复 n 次是否等于 s
            return t * (len(s) // len(t)) == s
        
        # 从最长的可能长度开始枚举
        min_len = min(len(str1), len(str2))
        
        for length in range(min_len, 0, -1):
            # 候选字符串的长度必须能同时整除两个字符串的长度
            if len(str1) % length == 0 and len(str2) % length == 0:
                candidate = str1[:length]
                if is_divisible(str1, candidate) and is_divisible(str2, candidate):
                    return candidate
        
        return ""
```

### 方法三：递归实现 GCD

```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        # 递归求最大公约数
        def gcd(a: int, b: int) -> int:
            return a if b == 0 else gcd(b, a % b)
        
        # 验证是否存在公共整除字符串
        if str1 + str2 != str2 + str1:
            return ""
        
        # 返回长度为 gcd 的前缀
        return str1[:gcd(len(str1), len(str2))]
```

## 复杂度分析

**方法一（推荐）：**
- **时间复杂度**：O(m + n)，其中 m 和 n 分别是两个字符串的长度
  - 字符串拼接和比较：O(m + n)
  - 计算 GCD：O(log(min(m, n)))
  - 总体：O(m + n)
- **空间复杂度**：O(m + n)，用于存储拼接后的字符串

**方法二：**
- **时间复杂度**：O(min(m, n) × (m + n))，最坏情况下需要枚举所有可能的长度
- **空间复杂度**：O(m) 或 O(n)，用于存储重复的字符串

```
- "ABC" × 1 = "ABC" ✓

```

## 关键点总结

1. **GCD 的数学性质**：公共整除字符串的长度必定是两个字符串长度的最大公约数
2. **快速验证技巧**：通过 `str1 + str2 == str2 + str1` 快速判断是否存在公共整除字符串
3. **Python 内置函数**：使用 `math.gcd()` 计算最大公约数
4. **字符串切片**：使用 `str[:n]` 获取前 n 个字符

## 易错点

1. **忘记验证存在性**：直接计算 GCD 可能导致错误，必须先验证 `str1 + str2 == str2 + str1`
2. **边界情况**：当两个字符串完全不同时（如 "LEET" 和 "CODE"），应返回空字符串
3. **长度关系**：不是所有的公共前缀都是整除字符串，必须满足长度是 GCD 的关系
4. **字符串不可变性**：Python 中字符串是不可变的，拼接会创建新对象，注意空间开销
