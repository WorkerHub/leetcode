## 题目描述

[LeetCode 1181. Before And After Puzzle](https://leetcode.com/problems/before-and-after-puzzle/)

给定一个短语列表 `phrases`，请返回所有能够通过连接两个短语形成的不同字符串的列表，要求第一个短语的最后一个单词等于第二个短语的第一个单词。

返回的答案需要按字典序排列，并且去重。

**示例 1:**

```
输入: phrases = ["writing code","code rocks"]
输出: ["writing code rocks"]
解释: "writing code" 的最后一个单词 "code" 等于 "code rocks" 的第一个单词 "code"，
      所以我们可以连接它们形成 "writing code rocks"。
```

**示例 2:**

```
输入: phrases = ["mission statement",
                "a quick bite to eat",
                "a chip off the old block",
                "chocolate bar",
                "mission impossible",
                "a man on a mission",
                "block party",
                "eat my words",
                "bar of soap"]
输出: ["a chip off the old block party",
      "a man on a mission impossible",
      "a man on a mission statement",
      "a quick bite to eat my words",
      "chocolate bar of soap"]
```

**示例 3:**

```
输入: phrases = ["a","b","a"]
输出: ["a"]
```

**提示:**

- `1 <= phrases.length <= 100`
- `1 <= phrases[i].length <= 100`
- 所有的 `phrases[i]` 都是小写字母和空格

## 解题思路

这道题的核心是：**找到所有可以拼接的短语对，并按要求处理结果**。

**关键观察**：
1. 对于每个短语，我们需要提取它的第一个单词和最后一个单词
2. 如果短语 A 的最后一个单词等于短语 B 的第一个单词，就可以连接（去掉重复的单词）
3. 需要避免自己和自己连接（虽然题目允许，但要注意索引不同的相同短语）
4. 最后要去重并排序

**算法流程**：
1. 预处理每个短语，提取首尾单词
2. 建立哈希表，将首单词相同的短语分组
3. 遍历每个短语，查找以其尾单词开头的其他短语
4. 拼接并去重，最后排序返回

## Python 代码实现

### 方法一：哈希表 + 字符串处理（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def beforeAndAfterPuzzles(self, phrases: List[str]) -> List[str]:
        """
        使用哈希表存储每个首单词对应的短语索引
        """
        # 预处理：提取每个短语的首尾单词和所有单词
        first_words = []  # 每个短语的首单词
        last_words = []   # 每个短语的尾单词
        words_list = []   # 每个短语的单词列表
        
        for phrase in phrases:
            words = phrase.split()
            words_list.append(words)
            first_words.append(words[0])
            last_words.append(words[-1])
        
        # 建立哈希表：首单词 -> 短语索引列表
        first_word_map = defaultdict(list)
        for i, word in enumerate(first_words):
            first_word_map[word].append(i)
        
        result_set = set()
        
        # 遍历每个短语作为前半部分
        for i in range(len(phrases)):
            last_word = last_words[i]
            
            # 查找所有以这个尾单词开头的短语
            if last_word in first_word_map:
                for j in first_word_map[last_word]:
                    # 不能是同一个短语（除非有重复的短语）
                    if i != j:
                        # 拼接：前半部分的所有单词 + 后半部分除了第一个单词的所有单词
                        combined = words_list[i] + words_list[j][1:]
                        result_set.add(' '.join(combined))
        
        # 去重后排序
        return sorted(result_set)
```

### 方法二：暴力枚举（简化版）

```python
from typing import List

class Solution:
    def beforeAndAfterPuzzles(self, phrases: List[str]) -> List[str]:
        """
        直接枚举所有短语对，检查是否可以连接
        """
        result_set = set()
        n = len(phrases)
        
        # 枚举所有短语对
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                
                # 提取短语 i 的尾单词和短语 j 的首单词
                words_i = phrases[i].split()
                words_j = phrases[j].split()
                
                # 检查是否可以连接
                if words_i[-1] == words_j[0]:
                    # 拼接并加入结果集
                    combined = words_i + words_j[1:]
                    result_set.add(' '.join(combined))
        
        # 去重后排序
        return sorted(result_set)
```

### 方法三：优化的哈希表（同时存储首尾）

```python
from typing import List
from collections import defaultdict

class Solution:
    def beforeAndAfterPuzzles(self, phrases: List[str]) -> List[str]:
        """
        优化：同时记录首尾单词和完整单词列表
        """
        # 预处理所有短语
        phrase_info = []
        first_map = defaultdict(list)
        
        for i, phrase in enumerate(phrases):
            words = phrase.split()
            first_word = words[0]
            last_word = words[-1]
            
            phrase_info.append((first_word, last_word, words))
            first_map[first_word].append(i)
        
        result_set = set()
        
        # 对每个短语，查找可以连接的后续短语
        for i, (first, last, words) in enumerate(phrase_info):
            # 查找所有以 last 开头的短语
            for j in first_map[last]:
                if i != j:
                    # 拼接
                    combined = words + phrase_info[j][2][1:]
                    result_set.add(' '.join(combined))
        
        return sorted(result_set)
```

## 复杂度分析

### 方法一和方法三（哈希表）：
- 时间复杂度：O(n^2 * m + k * log k)
  - n 为短语数量，m 为平均短语长度
  - 最坏情况下每个短语都可能与其他所有短语连接
  - k 为结果数量，需要排序
- 空间复杂度：O(n * m + k)，存储预处理信息和结果集

### 方法二（暴力枚举）：
- 时间复杂度：O(n^2 * m + k * log k)
  - 枚举所有短语对需要 O(n^2)
  - 每次处理需要 O(m)
- 空间复杂度：O(k)，只存储结果集

## 关键点总结

1. **字符串分割**：使用 `split()` 方法将短语分割成单词列表
2. **哈希表优化**：将首单词作为键，可以快速找到候选短语
3. **去重**：使用 `set` 自动去重，避免手动判断
4. **拼接技巧**：前半部分所有单词 + 后半部分除了第一个单词
5. **索引判断**：使用 `i != j` 避免自己和自己连接

## 易错点

1. **相同短语的处理**：即使有两个相同的短语，它们的索引不同，可以相互连接
2. **单词拼接**：连接时要去掉重复的单词（后半部分的第一个单词）
3. **空格处理**：使用 `' '.join()` 重新拼接时要注意空格
4. **排序要求**：题目要求字典序排序，不要忘记
5. **边界情况**：单个单词的短语，首尾单词是同一个
