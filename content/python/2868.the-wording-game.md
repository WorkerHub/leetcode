## 题目描述

Alice 和 Bob 进行单词游戏。给你两个字符串数组 `a`（Alice 的卡片）和 `b`（Bob 的卡片）。

游戏规则：
1. Alice 先出一张卡片
2. 之后轮流出牌
3. 每张新出的卡片必须满足其第一个字母 > 上一张出的最后一个字母（字典序严格大于）

无法出牌时输。Alice 赢当且仅当她能按规则先出牌并最终让 Bob 无法出牌。

返回 Alice 是否能赢。

**提示：**
- Alice 和 Bob 都使用最优策略

## 解题思路

**贪心：** 每次出牌应该选择首字母满足条件且最后一个字母尽量小的卡片（让对方尽量难以接）。

**Alice 先出：** Alice 选首字母最小的卡片（没有限制），然后 Bob 必须出首字母 > Alice 末尾字母的卡片。

**模拟最优策略：**
1. 将 `a` 和 `b` 都按首字母排序
2. Alice 每次出首字母满足条件且尾字母最小的牌（让对方接牌困难）
3. Bob 类似

实际上，贪心排序后按顺序遍历即可：
- 对 a 和 b 各自排序
- 模拟每一轮：当前玩家选满足条件的所有卡片中首字母最小的（或其他贪心准则）

## Python 代码实现

### 方法一：排序 + 贪心模拟（推荐）

```python
from typing import List

class Solution:
    def canAliceWin(self, a: List[str], b: List[str]) -> bool:
        # 按首字母排序，首字母相同时按末字母排序
        a.sort()
        b.sort()

        # 模拟游戏
        # Alice 先出：选首字母最小的（没有限制）
        # 然后 Bob 出：首字母 > Alice 最后出的末字母

        ia, ib = 0, 0  # 指针
        last_char = 'a' - chr(0 - 1)  # 初始无限制，设为比 'a' 小的字符

        # Alice 先出（初始 last_char 无限制）
        # 简化：Alice 出首字母 >= 'a' 的最小满足条件的牌
        turn = True  # True=Alice, False=Bob

        # 初始化：Alice 可以出任何牌
        while True:
            if turn:
                # Alice 找第一张满足条件的牌
                while ia < len(a) and a[ia][0] <= last_char:
                    ia += 1
                if ia >= len(a):
                    return False  # Alice 无牌可出，Alice 输
                last_char = a[ia][-1]
                ia += 1
            else:
                while ib < len(b) and b[ib][0] <= last_char:
                    ib += 1
                if ib >= len(b):
                    return True  # Bob 无牌可出，Alice 赢
                last_char = b[ib][-1]
                ib += 1
            turn = not turn
```

### 方法二：注意初始条件

```python
from typing import List

class Solution:
    def canAliceWin(self, a: List[str], b: List[str]) -> bool:
        a.sort()
        b.sort()
        ia = ib = 0
        # Alice 先出，初始无限制（相当于上一张末尾字母比 'a' 小）
        prev_last = chr(ord('a') - 1)  # 字符比 'a' 小
        turn = 0  # 0=Alice, 1=Bob

        while True:
            if turn == 0:
                # Alice 出牌
                while ia < len(a) and a[ia][0] <= prev_last:
                    ia += 1
                if ia == len(a):
                    return False
                prev_last = a[ia][-1]
                ia += 1
                turn = 1
            else:
                # Bob 出牌
                while ib < len(b) and b[ib][0] <= prev_last:
                    ib += 1
                if ib == len(b):
                    return True
                prev_last = b[ib][-1]
                ib += 1
                turn = 0
```

## 复杂度分析

- 时间复杂度：O((|a| + |b|) × log)，排序 + 线性遍历
- 空间复杂度：O(1)

## 关键点总结

1. 排序后贪心：每次选满足首字母条件的最小牌（首字母字典序最小）
2. 出牌让末尾字母最小（题目中首字母最小 = 末尾也相对小，因为排序了）
3. Alice 无牌时输，Bob 无牌时 Alice 赢

## 易错点

1. 初始条件：Alice 第一张牌没有限制，用比 'a' 更小的字符初始化
2. 条件是严格大于：首字母必须 > 上一张的末尾字母
3. 指针不回头（sorted 后直接用双指针）
