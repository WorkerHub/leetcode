## 题目描述

给你一个正整数 `s`，构造长度尽可能大的数组 `nums`，满足：
- `nums` 包含从 `1` 到某个正整数的所有正整数。
- 对于 `nums` 中所有的 `i < j`，有 `i * j <= s`。

返回满足条件的最大数组长度 `n`。

等价于：找最大的 `n` 使得对所有 `1 <= i < j <= n`，`i * j <= s`。

最大约束：所有 `i < j` 中最大的乘积是 `(n-1) * n`，所以条件等价于 `(n-1) * n <= s`。

**提示：**
- `1 <= s <= 10^12`

## 解题思路

条件"所有 `i < j` 的 `i * j <= s`"中，最大乘积是 `(n-1) * n`（最大的两个相邻整数），因此只需：

`(n-1) * n <= s`

找最大的 n 满足此条件，即求 `n^2 - n - s <= 0` 的最大整数解。

用二分查找：在 `[1, sqrt(s)+1]` 范围内二分找最大满足 `n*(n-1) <= s` 的 `n`。

或者直接用数学公式：`n ≈ (1 + sqrt(1 + 4s)) / 2`，然后向下取整验证。

## Python 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def maximumLength(self, s: int) -> int:
        # 找最大 n 使得 n * (n-1) <= s
        lo, hi = 1, int(s**0.5) + 2
        
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if mid * (mid - 1) <= s:
                lo = mid
            else:
                hi = mid - 1
        
        return lo
```

### 方法二：数学公式直接计算

```python
import math

class Solution:
    def maximumLength(self, s: int) -> int:
        # n*(n-1) <= s => n^2 - n - s <= 0
        # n <= (1 + sqrt(1 + 4s)) / 2
        n = int((1 + math.sqrt(1 + 4 * s)) / 2)
        # 验证并调整
        while n * (n - 1) > s:
            n -= 1
        while (n + 1) * n <= s:
            n += 1
        return n
```

## 复杂度分析

- 时间复杂度：O(log s)，二分查找
- 空间复杂度：O(1)

## 关键点总结

1. 所有 `i < j <= n` 对中，最大乘积是 `(n-1) * n`（最大的两个相邻数）。
2. 条件化简为 `n * (n-1) <= s`，求最大满足的 n。
3. 二分或数学公式均可，注意浮点精度问题。

## 易错点

1. 数学公式中 `sqrt` 存在浮点误差，需要在结果附近验证。
2. 二分的上界设为 `sqrt(s) + 2` 即可，避免整数溢出（Python 无溢出问题）。
3. 当 `s = 1` 时，`n = 1`（只有一个元素，没有 `i < j` 的对）。
