## 题目描述

给你一个嵌套的整数列表 `nestedList`。每个元素要么是一个整数，要么是一个列表（其元素也可能是整数或者是其他列表）。

整数的深度取决于它位于多少个列表内部。例如，嵌套列表 `[1,[2,2],[[3],2],1]` 中每个整数的值就是其深度。令 `maxDepth` 为最大深度。

返回该嵌套列表按深度加权求和的结果。规则如下：
- 深度为 `maxDepth` 的整数，其权重为 1
- 深度为 `maxDepth - 1` 的整数，其权重为 2
- 深度为 `maxDepth - d` 的整数，其权重为 `d + 1`

**示例 1：**

```
输入：nestedList = [[1,1],2,[1,1]]
输出：8
解释：
- 四个深度为 2 的 1，权重为 1，总和为 4
- 一个深度为 1 的 2，权重为 2，总和为 4
- 结果：4 + 4 = 8
```

**示例 2：**

```
输入：nestedList = [1,[4,[6]]]
输出：17
解释：
- 一个深度为 1 的 1，权重为 3，总和为 3
- 一个深度为 2 的 4，权重为 2，总和为 8
- 一个深度为 3 的 6，权重为 1，总和为 6
- 结果：3 + 8 + 6 = 17
```

**提示：**
- `1 <= nestedList.length <= 50`
- 嵌套列表中整数的值在 `[-100, 100]` 范围内
- 任何整数的最大深度小于或等于 50

## 解题思路

这道题是 [339. Nested List Weight Sum](https://leetcode.com/problems/nested-list-weight-sum/) 的变体。

关键区别：
- 339 题：深度越深，权重越大（深度为 d，权重为 d）
- 本题：深度越浅，权重越大（深度为 d，权重为 maxDepth - d + 1）

### 解法思路

**方法一：两次遍历**
1. 第一次遍历：找到最大深度 `maxDepth`
2. 第二次遍历：按照 `maxDepth - depth + 1` 计算加权和

**方法二：巧妙的一次遍历（推荐）**
核心观察：
- 如果直接计算，需要知道 `maxDepth`
- 反向思考：每层的数字被累加的次数不同
- 使用 BFS 层序遍历，每次将当前层的数字累加到结果中
- 下一层继承上一层的未加权和，实现反向加权效果

## Python 代码实现

### 方法一：两次遍历（直观）

```python
from typing import List

# """
# This is the interface that allows for creating nested lists.
# You should not implement it, or speculate about its implementation
# """
class NestedInteger:
    def isInteger(self) -> bool:
        """
        @return True if this NestedInteger holds a single integer, rather than a nested list.
        """
        pass

    def getInteger(self) -> int:
        """
        @return the single integer that this NestedInteger holds, if it holds a single integer
        Return None if this NestedInteger holds a nested list
        """
        pass

    def getList(self) -> List['NestedInteger']:
        """
        @return the nested list that this NestedInteger holds, if it holds a nested list
        Return None if this NestedInteger holds a single integer
        """
        pass

class Solution:
    def depthSumInverse(self, nestedList: List[NestedInteger]) -> int:
        """
        两次遍历：先找最大深度，再计算加权和
        """
        # 第一次遍历：找最大深度
        max_depth = self.getMaxDepth(nestedList)
        
        # 第二次遍历：计算加权和
        return self.getWeightedSum(nestedList, max_depth, 1)
    
    def getMaxDepth(self, nestedList: List[NestedInteger]) -> int:
        """
        DFS 计算最大深度
        """
        max_depth = 1
        for item in nestedList:
            if not item.isInteger():
                max_depth = max(max_depth, 1 + self.getMaxDepth(item.getList()))
        return max_depth
    
    def getWeightedSum(self, nestedList: List[NestedInteger], 
                       max_depth: int, current_depth: int) -> int:
        """
        DFS 计算加权和
        权重 = max_depth - current_depth + 1
        """
        total = 0
        weight = max_depth - current_depth + 1
        
        for item in nestedList:
            if item.isInteger():
                total += item.getInteger() * weight
            else:
                total += self.getWeightedSum(item.getList(), max_depth, current_depth + 1)
        
        return total
```

### 方法二：BFS 一次遍历（推荐，巧妙）

```python
from typing import List
from collections import deque

class Solution:
    def depthSumInverse(self, nestedList: List[NestedInteger]) -> int:
        """
        BFS 层序遍历，巧妙计算加权和
        关键思想：每层的数字会被累加多次
        """
        queue = deque(nestedList)
        total_sum = 0  # 最终结果
        level_sum = 0  # 当前层及之前所有层的数字和
        
        while queue:
            size = len(queue)
            
            for _ in range(size):
                item = queue.popleft()
                
                if item.isInteger():
                    # 将当前数字加到层和中
                    level_sum += item.getInteger()
                else:
                    # 将嵌套列表的元素加入队列
                    queue.extend(item.getList())
            
            # 每处理完一层，将当前的 level_sum 加到总和
            # 这样深度浅的数字会被累加更多次
            total_sum += level_sum
        
        return total_sum
```

### 方法三：DFS + 记录每层和

```python
from typing import List

class Solution:
    def depthSumInverse(self, nestedList: List[NestedInteger]) -> int:
        """
        DFS 记录每层的数字和，然后反向加权
        """
        level_sums = []  # level_sums[i] 表示深度为 i+1 的所有数字之和
        
        # DFS 收集每层的和
        self.dfs(nestedList, 0, level_sums)
        
        # 反向加权求和
        total = 0
        max_depth = len(level_sums)
        for depth in range(max_depth):
            weight = max_depth - depth
            total += level_sums[depth] * weight
        
        return total
    
    def dfs(self, nestedList: List[NestedInteger], 
            depth: int, level_sums: List[int]) -> None:
        """
        DFS 遍历，记录每层的数字和
        """
        # 确保 level_sums 有足够的空间
        if depth >= len(level_sums):
            level_sums.append(0)
        
        for item in nestedList:
            if item.isInteger():
                level_sums[depth] += item.getInteger()
            else:
                self.dfs(item.getList(), depth + 1, level_sums)
```

## 复杂度分析

设 N 为所有整数的总数，D 为最大深度。

### 方法一：两次遍历
- 时间复杂度：O(N)，遍历两次
- 空间复杂度：O(D)，递归栈深度

### 方法二：BFS 一次遍历
- 时间复杂度：O(N)，每个元素访问一次
- 空间复杂度：O(N)，队列最多存储所有元素

### 方法三：DFS + 记录每层和
- 时间复杂度：O(N)
- 空间复杂度：O(D)

## 关键点总结

1. **反向加权**：深度越浅，权重越大，这是与 339 题的关键区别
2. **BFS 技巧**：通过累加层和，巧妙实现反向加权
3. **层序遍历**：BFS 天然按层处理，适合这类问题
4. **数学转换**：`weight = maxDepth - depth + 1`
5. **一次遍历优化**：方法二避免了两次遍历，更优雅

## 易错点

1. **权重计算**：注意是 `maxDepth - depth + 1`，不是简单的 `depth`
2. **深度定义**：第一层深度为 1，不是 0
3. **BFS 队列**：要用 `extend` 而不是 `append`
4. **空嵌套列表**：要处理空列表的情况
5. **负数处理**：整数可以是负数，要正确累加
