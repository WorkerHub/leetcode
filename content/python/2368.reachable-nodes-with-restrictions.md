## 题目描述

给你一棵 `n` 个节点的无向树，节点编号从 `0` 到 `n-1`，`0` 为根节点。`edges[i] = [a_i, b_i]` 表示 a_i 和 b_i 之间有一条边。另给你一个整数数组 `restricted`，表示**受限节点**。

**不能**访问受限节点或经过受限节点到达其他节点（但可以从根节点 0 出发，根节点 0 不在 restricted 中）。

返回从根节点 `0` 出发**不受限**可以访问的最多节点数。

**示例 1：**
```
输入：n = 7, edges = [[0,1],[1,2],[3,1],[4,0],[0,5],[5,6]], restricted = [4,5]
输出：4
解释：从节点 0 可访问 0, 1, 2, 3，共 4 个。
```

**提示：**
- `2 <= n <= 10^5`
- `restricted.length < n - 1`

## 解题思路

将受限节点放入集合，从根节点 0 开始 DFS/BFS，跳过受限节点，统计可访问的节点数。

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def reachableNodes(self, n: int, edges: List[List[int]], restricted: List[int]) -> int:
        restricted_set = set(restricted)
        
        # 构建邻接表
        graph = defaultdict(list)
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        
        # BFS 从 0 出发
        visited = {0}
        queue = deque([0])
        count = 0
        
        while queue:
            node = queue.popleft()
            count += 1
            for nb in graph[node]:
                if nb not in visited and nb not in restricted_set:
                    visited.add(nb)
                    queue.append(nb)
        
        return count
```

### 方法二：DFS 递归

```python
from typing import List
from collections import defaultdict

class Solution:
    def reachableNodes(self, n: int, edges: List[List[int]], restricted: List[int]) -> int:
        restricted_set = set(restricted)
        graph = defaultdict(list)
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        
        count = [0]
        visited = set()
        
        def dfs(node):
            visited.add(node)
            count[0] += 1
            for nb in graph[node]:
                if nb not in visited and nb not in restricted_set:
                    dfs(nb)
        
        dfs(0)
        return count[0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n + m) | O(n + m) |
| DFS | O(n + m) | O(n + m) |

其中 m 为边数。

## 关键点总结

1. 受限节点不能访问，也不能经过，相当于删除这些节点后 BFS。
2. 将受限节点放入哈希集合，O(1) 判断。
3. 记录已访问节点避免重复（树结构中一般不需要，但有向图中需要）。

## 易错点

- 根节点 0 保证不在 restricted 中，无需特殊处理。
- 树中边是无向的，邻接表两端都要添加。
