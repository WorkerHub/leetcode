## 题目描述

给你一个由小写字母组成的字符串 `s`，和一个整数 `k`。如果一个字符串满足下述条件，则称其为**理想**字符串：
- 字符串是 `s` 的**子序列**。
- 字符串中相邻两个字母在字母表中位次差值**不超过** `k`（|ord(a) - ord(b)| <= k）。

返回**最长**理想字符串的长度。

**示例 1：**
```
输入：s = "acfgbd", k = 2
输出：4
解释：最长理想字符串为 "acbd"（a,c 差 2，c,b 差 1，b,d 差 2），长度为 4。
```

**提示：**
- `1 <= s.length <= 10^5`
- `0 <= k <= 25`
- `s` 只包含小写英文字母

## 解题思路

**动态规划：**
定义 `dp[c]` 为以字母 `c` 结尾的最长理想子序列长度。

对每个字符 `s[i]`（设为字符 `c`）：
- 枚举所有满足 `|ord(c') - ord(c)| <= k` 的前缀字母 `c'`。
- `dp[c] = max(dp[c'], ...) + 1`

只有 26 个字母，每次枚举最多 2*k+1 个字母（最多 51 个）。

## 代码实现

### 方法一：DP + 枚举邻近字母（推荐）

```python
class Solution:
    def longestIdealString(self, s: str, k: int) -> int:
        # dp[c] 表示以字母 c 结尾的最长理想子序列长度
        dp = [0] * 26
        
        for c in s:
            idx = ord(c) - ord('a')
            # 枚举差值 <= k 的字母
            best = 0
            for prev in range(max(0, idx - k), min(25, idx + k) + 1):
                best = max(best, dp[prev])
            dp[idx] = best + 1
        
        return max(dp)
```

### 方法二：哈希表版本（更易理解）

```python
class Solution:
    def longestIdealString(self, s: str, k: int) -> int:
        best = {}  # 字母 -> 以该字母结尾的最长理想子序列长度
        ans = 0
        
        for c in s:
            cur_best = 0
            for prev_ord in range(ord(c) - k, ord(c) + k + 1):
                prev_c = chr(prev_ord)
                if 'a' <= prev_c <= 'z' and prev_c in best:
                    cur_best = max(cur_best, best[prev_c])
            best[c] = max(best.get(c, 0), cur_best + 1)
            ans = max(ans, best[c])
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n * k) | O(26) |

其中 k <= 25，故每次枚举最多 51 个字母，接近 O(n)。

## 关键点总结

1. `dp[c]` 表示以字母 `c` 结尾的最长理想子序列长度，更新时枚举差值 <= k 的前驱字母。
2. 只有 26 个字母，状态空间固定。
3. 每次遇到字符 `c` 时，更新 `dp[c]`。

## 易错点

- 枚举范围 `[idx - k, idx + k]`，需要与 `[0, 25]` 取交集，避免越界。
- `dp[c]` 在一次遍历中可能被更新多次（同一字母出现多次），每次取最大值。
