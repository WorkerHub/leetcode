## 题目描述

给你一个四舍五入到两位小数的非负浮点数 `celsius` 来表示温度，以 **摄氏度**（**Celsius**）为单位。

你需要将摄氏度转换为 **开氏度**（**Kelvin**）和 **华氏度**（**Fahrenheit**），并以数组 `[kelvin, fahrenheit]` 的形式返回结果。

转换公式如下所示：
- `Kelvin = Celsius + 273.15`
- `Fahrenheit = Celsius * 1.80 + 32.00`

**示例 1：**
```
输入：celsius = 36.50
输出：[309.65000, 97.70000]
```

**示例 2：**
```
输入：celsius = 122.11
输出：[395.26000, 251.79800]
```

**提示：**
- `0 <= celsius <= 1000`

## 解题思路

直接套用公式计算，返回 `[celsius + 273.15, celsius * 1.80 + 32.00]`。

## 代码实现

### 方法一：直接套公式（推荐）

```python
from typing import List

class Solution:
    def convertTemperature(self, celsius: float) -> List[float]:
        kelvin = celsius + 273.15
        fahrenheit = celsius * 1.80 + 32.00
        return [kelvin, fahrenheit]
```

### 方法二：常量定义（增加可读性）

```python
from typing import List

class Solution:
    def convertTemperature(self, celsius: float) -> List[float]:
        KELVIN_OFFSET = 273.15
        FAHRENHEIT_RATIO = 1.80
        FAHRENHEIT_OFFSET = 32.00

        return [
            celsius + KELVIN_OFFSET,
            celsius * FAHRENHEIT_RATIO + FAHRENHEIT_OFFSET
        ]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接套公式 | O(1) | O(1) |

## 关键点总结

1. 开氏度 = 摄氏度 + 273.15
2. 华氏度 = 摄氏度 × 1.80 + 32.00
3. 返回浮点数数组

## 易错点

- 华氏度公式中是 1.80，不是 1.8（题目要求精确）
- 返回顺序：先 kelvin 后 fahrenheit
