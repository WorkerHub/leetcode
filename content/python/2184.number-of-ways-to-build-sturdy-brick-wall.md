## 题目描述

给你两个整数 `height` 和 `width`，以及一个整数数组 `bricks`，其中 `bricks[i]` 表示第 `i` 种砖块的宽度。每种砖块可以**无限次**使用。

用这些砖块构造一面宽为 `width`、高为 `height` 的墙，要求：
- 每行砖块总宽度恰好为 `width`
- 相邻两行之间，**砖块接缝**（分割点）不能在同一位置（即每行接缝集合不能有公共元素）

返回建造这面墙的方案数，结果对 `10^9 + 7` 取模。

**提示：**
- `1 <= height <= 100`
- `1 <= width <= 10`
- `1 <= bricks.length <= 10`
- `1 <= bricks[i] <= 10`

## 解题思路

**预处理行方案 + DP**

由于 `width <= 10`，每行接缝位置可以用一个 bitmask（最多 9 个可能的接缝位置）表示。

步骤：
1. DFS/回溯生成所有合法的行排列，将每行接缝集合编码为整数 `mask`。
2. 预计算哪些行对 `(mask_a, mask_b)` 的接缝不冲突（`mask_a & mask_b == 0`）。
3. DP：`dp[i][mask]` = 前 `i` 行，第 `i` 行接缝为 `mask` 的方案数。

## 代码实现

### 方法一：预处理 + DP（推荐）

```python
from typing import List

class Solution:
    def buildWall(self, height: int, width: int, bricks: List[int]) -> int:
        MOD = 10 ** 9 + 7

        # 步骤1：生成所有合法行的接缝 mask
        valid_masks = []

        def dfs(remaining, mask):
            if remaining == 0:
                valid_masks.append(mask)
                return
            for b in bricks:
                if b <= remaining:
                    # 在位置 (width - remaining) 处有接缝（若不是最右端）
                    pos = width - remaining  # 当前已填充位置
                    new_mask = mask
                    if pos > 0:
                        new_mask |= (1 << (pos - 1))
                    dfs(remaining - b, new_mask)

        dfs(width, 0)

        # 步骤2：去重
        valid_masks = list(set(valid_masks))
        m = len(valid_masks)

        # 步骤3：预计算相容矩阵
        compatible = [[] for _ in range(m)]
        for i in range(m):
            for j in range(m):
                if valid_masks[i] & valid_masks[j] == 0:
                    compatible[i].append(j)

        # 步骤4：DP
        dp = [1] * m  # 第1行，每种合法行各1种方案
        for _ in range(height - 1):
            new_dp = [0] * m
            for i in range(m):
                for j in compatible[i]:
                    new_dp[j] = (new_dp[j] + dp[i]) % MOD
            dp = new_dp

        return sum(dp) % MOD
```

### 方法二：矩阵快速幂（height 很大时适用）

```python
from typing import List

class Solution:
    def buildWall(self, height: int, width: int, bricks: List[int]) -> int:
        MOD = 10 ** 9 + 7

        # 生成所有合法行
        valid_masks = set()

        def dfs(remaining, mask):
            if remaining == 0:
                valid_masks.add(mask)
                return
            for b in bricks:
                if b <= remaining:
                    pos = width - remaining
                    new_mask = mask | ((1 << (pos - 1)) if pos > 0 else 0)
                    dfs(remaining - b, new_mask)

        dfs(width, 0)
        masks = list(valid_masks)
        m = len(masks)

        # 转移矩阵
        A = [[0] * m for _ in range(m)]
        for i in range(m):
            for j in range(m):
                if masks[i] & masks[j] == 0:
                    A[i][j] = 1

        # 矩阵快速幂（height-1 次）
        def mat_mul(X, Y):
            n = len(X)
            res = [[0] * n for _ in range(n)]
            for a in range(n):
                for b in range(n):
                    if X[a][b] == 0:
                        continue
                    for c in range(n):
                        res[a][c] = (res[a][c] + X[a][b] * Y[b][c]) % MOD
            return res

        def mat_pow(M, p):
            n = len(M)
            result = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
            while p:
                if p & 1:
                    result = mat_mul(result, M)
                M = mat_mul(M, M)
                p >>= 1
            return result

        R = mat_pow(A, height - 1)
        ans = 0
        for i in range(m):
            for j in range(m):
                ans = (ans + R[i][j]) % MOD
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(height * m^2) | O(m^2) |
| 矩阵快速幂 | O(m^3 * log(height)) | O(m^2) |

其中 `m` 为合法行数，`width <= 10` 时 `m` 很小。

## 关键点总结

1. 用 bitmask 编码每行的"接缝"位置（除最右端外）。
2. 两行相容当且仅当接缝 mask 的按位与为 0（没有公共接缝）。
3. 先枚举合法行，再做 height 层 DP。

## 易错点

- 最右端不算接缝（砖块恰好填满宽度，最右边没有接缝）。
- DFS 时要正确记录中间接缝位置。
