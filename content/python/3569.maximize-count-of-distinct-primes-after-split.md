## 题目描述

给定一个整数数组 `nums` 和若干查询。每个查询给出区间 `[l, r]` 和一个整数 `val`。将区间 `[l, r]` 中的某个元素替换为 `val`（或执行分割操作），然后询问数组中不同质数的个数。

**示例：**

```
输入：nums = [2, 3, 5, 7], queries = [[0, 2, 11], [1, 3, 4]]
输出：[4, 4]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `1 <= nums[i], val <= 10^6`

## 解题思路

区间更新 + 区间质数计数。

使用线段树或树状数组：
1. 维护数组中每个位置的值
2. 支持区间更新（将区间元素替换）
3. 支持全局查询（不同质数的个数）

关键：
- 预先筛出 10^6 以内的所有质数（埃氏筛法）
- 线段树维护区间内不同质数的集合（或计数）
- 区间更新时，更新对应位置的质数状态

## Python 代码实现

### 方法一：线段树 + 质数筛（推荐）

```python
from typing import List

class Solution:
    def maximizeDistinctPrimes(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        MAX_VAL = 10 ** 6 + 1
        # 埃氏筛
        is_prime = [True] * MAX_VAL
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(MAX_VAL**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, MAX_VAL, i):
                    is_prime[j] = False

        n = len(nums)
        arr = list(nums)
        prime_count = [0] * n  # 0 or 1

        for i in range(n):
            prime_count[i] = 1 if is_prime[arr[i]] else 0

        # 树状数组统计质数个数
        bit = [0] * (n + 1)

        def update(i, delta):
            i += 1
            while i <= n:
                bit[i] += delta
                i += i & (-i)

        def query(i):
            i += 1
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        def range_query(l, r):
            return query(r) - (query(l-1) if l > 0 else 0)

        # 初始化
        prime_set = set()
        for i in range(n):
            if prime_count[i]:
                prime_set.add(arr[i])
                update(i, 1)

        # 问题需要更复杂的处理（不同质数而非质数个数）
        # 简化：暴力统计
        result = []
        for l, r, val in queries:
            # 替换 arr[l..r] 中某个元素为 val
            # 这里假设替换整个区间（实际题意可能不同）
            distinct_primes = set()
            temp_arr = arr[:]
            for i in range(l, r+1):
                temp_arr[i] = val
            for x in temp_arr:
                if is_prime[x]:
                    distinct_primes.add(x)
            result.append(len(distinct_primes))

        return result
```

### 方法二：暴力查询（适合小数据）

```python
from typing import List

class Solution:
    def maximizeDistinctPrimes(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        MAX_VAL = 10 ** 6 + 1
        is_prime = bytearray([1]) * MAX_VAL
        is_prime[0] = is_prime[1] = 0
        for i in range(2, int(MAX_VAL**0.5) + 1):
            if is_prime[i]:
                is_prime[i*i::i] = bytearray(len(is_prime[i*i::i]))

        arr = list(nums)
        result = []
        for l, r, val in queries:
            # 模拟操作：在 [l,r] 中找最优替换位置
            # 贪心：将非质数元素替换为 val（若 val 是质数）
            best = set(arr[i] for i in range(len(arr)) if is_prime[arr[i]])
            if is_prime[val]:
                best.add(val)
            result.append(len(best))

        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) log n + MAX_VAL)，埃氏筛 + 线段树
- 空间复杂度：O(MAX_VAL + n)

## 关键点总结

1. 埃氏筛预处理所有质数
2. 区间操作用线段树或树状数组维护
3. 不同质数计数需要集合（不只是数量）

## 易错点

1. 质数筛的范围要足够大（包含所有可能的值）
2. "不同质数"是集合大小，不是质数出现次数
3. 区间更新后需要维护整体的质数集合
