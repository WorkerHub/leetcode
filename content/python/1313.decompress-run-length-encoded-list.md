## 题目描述

给你一个以游程编码压缩的整数列表 `nums`。

考虑每对相邻两元素 `nums[2i]` 和 `nums[2i+1]`（以 0 开始索引），每一对都代表解压后子列表中的 `nums[2i]` 个值为 `nums[2i+1]` 的元素。

请你返回解压后的列表。

**示例 1：**

```
输入：nums = [1,2,3,4]
输出：[2,4,4,4]
解释：
第一对 [1,2] 代表 1 个值为 2 的元素，即 [2]
第二对 [3,4] 代表 3 个值为 4 的元素，即 [4,4,4]
合并得 [2,4,4,4]
```

**示例 2：**

```
输入：nums = [1,1,2,3]
输出：[1,3,3]
```

**提示：**

- `2 <= nums.length <= 100`
- `nums.length % 2 == 0`
- `1 <= nums[2i] <= 100`
- `0 <= nums[2i+1] <= 100`

## 解题思路

直接模拟游程编码的解压过程：

- 每次取一对数 `(freq, val)`，即 `nums[2i]` 和 `nums[2i+1]`
- 将 `val` 重复 `freq` 次，追加到结果列表

**游程编码（Run-Length Encoding）简介：**

游程编码是一种简单的无损压缩方式，连续重复的值用"次数+值"来表示。
例如 `[4,4,4,2]` 可压缩为 `[3,4,1,2]`。

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def decompressRLElist(self, nums: List[int]) -> List[int]:
        result = []
        # 每次步进 2，取一对 (频率, 值)
        for i in range(0, len(nums), 2):
            freq = nums[i]      # 出现次数
            val = nums[i + 1]   # 对应的值
            result.extend([val] * freq)  # 将 val 重复 freq 次加入结果
        return result
```

### 方法二：列表推导式（Pythonic）

```python
from typing import List

class Solution:
    def decompressRLElist(self, nums: List[int]) -> List[int]:
        # zip(nums[::2], nums[1::2]) 将偶数位和奇数位配对
        return [val for freq, val in zip(nums[::2], nums[1::2]) for _ in range(freq)]
```

### 方法三：使用 itertools.chain（函数式风格）

```python
from typing import List
from itertools import chain

class Solution:
    def decompressRLElist(self, nums: List[int]) -> List[int]:
        # 每对生成一个重复列表，再用 chain 展平
        return list(chain.from_iterable(
            [nums[i + 1]] * nums[i] for i in range(0, len(nums), 2)
        ))
```

## 复杂度分析

- **时间复杂度**：O(n * max_freq)，n 为 nums 的长度，max_freq 为最大频率值
- **空间复杂度**：O(n * max_freq)，即输出列表的大小

由于 `nums.length <= 100` 且 `freq <= 100`，输出最多 5000 个元素，开销很小。

## 关键点总结

1. 输入数组长度一定是偶数，每两个元素为一组
2. 偶数下标（0,2,4,...）是频率，奇数下标（1,3,5,...）是值
3. `[val] * freq` 是 Python 中快速创建重复列表的惯用方式
4. `nums[::2]` 取步长为 2 的切片，配合 `zip` 可以优雅配对

## 易错点

1. **下标搞反**：`nums[2i]` 是频率，`nums[2i+1]` 是值，别弄反了
2. **步进为 1**：循环时步进应为 2（`range(0, len(nums), 2)`），否则会越界或重复处理
3. **extend vs append**：`extend([val] * freq)` 将多个元素加入列表；如果用 `append`，会把整个子列表作为一个元素加入
