## 题目描述

给你一个由 `n` 个 **不同** 整数组成的数组 `perm`，其中 `perm` 是 `[1, 2, ..., n]` 的一个排列。

返回 `perm` 在所有排列中的 **字典序** 排名（从 1 开始）。答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：perm = [1,2]
输出：1
```

**示例 2：**
```
输入：perm = [3,1,2]
输出：5
```

**提示：**
- `1 <= n <= 10^5`

## 解题思路

对于排列 `perm`，其字典序排名等于：对每个位置 `i`，统计比 `perm[i]` 小的且还未使用的数的个数，乘以 `(n - i - 1)!`，然后累加。

需要高效地查询"当前还有多少个小于 x 的数未使用"，使用树状数组（BIT）维护每个数是否已使用，支持前缀和查询。

## Python 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List
import math

class BIT:
    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i: int, delta: int = 1):
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)

    def query(self, i: int) -> int:
        # 前缀和 [1, i]
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

class Solution:
    def getPermutationIndex(self, perm: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(perm)
        bit = BIT(n)
        # 初始化：所有数都在
        for i in range(1, n + 1):
            bit.update(i)

        # 预计算阶乘
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        ans = 0
        for i, x in enumerate(perm):
            # 统计比 x 小的未使用数的个数
            smaller = bit.query(x - 1)
            ans = (ans + smaller * fact[n - i - 1]) % MOD
            bit.update(x, -1)  # 标记 x 已使用

        return (ans + 1) % MOD  # 排名从 1 开始
```

### 方法二：使用 SortedList

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def getPermutationIndex(self, perm: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(perm)
        sl = SortedList(range(1, n + 1))

        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        ans = 0
        for i, x in enumerate(perm):
            idx = sl.index(x)  # 比 x 小的未使用数个数
            ans = (ans + idx * fact[n - i - 1]) % MOD
            sl.remove(x)

        return (ans + 1) % MOD
```

## 复杂度分析

- 时间复杂度：O(n log n)，树状数组每次操作 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 字典序排名通过 Lehmer 码计算：每位乘以对应的阶乘
2. 用树状数组高效查询"未使用数中小于 x 的个数"
3. 结果需要 +1（排名从 1 开始）

## 易错点

1. 排名从 1 开始，最后需要 +1
2. 注意对 MOD 取模
3. 阶乘从第 `n-i-1` 项开始（最后一位贡献 0!）
