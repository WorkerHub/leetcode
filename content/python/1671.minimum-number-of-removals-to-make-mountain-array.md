## 题目描述

给你一个整数数组 `nums`，返回使 `nums` 成为**山形数组**所需删除的最少元素个数。

**山形数组：** 数组长度 >= 3，存在下标 `i`（0-indexed，且 `0 < i < n-1`），使得：
- `nums[0] < nums[1] < ... < nums[i]`（严格递增到峰值）
- `nums[i] > nums[i+1] > ... > nums[n-1]`（峰值后严格递减）

## 解题思路

**DP：**
- `lis[i]`：以 `nums[i]` 结尾的最长严格递增子序列长度（从左向右）
- `lds[i]`：以 `nums[i]` 开头的最长严格递减子序列长度（从右向左）

则以 `i` 为峰值的山形数组长度 = `lis[i] + lds[i] - 1`（去掉重复计算的峰值）

需要峰值不在首尾（`lis[i] > 1` 且 `lds[i] > 1`）。

最少删除数 = `n - max(lis[i] + lds[i] - 1)`（对所有有效峰值 i）。

## 代码实现

### 方法一：DP + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def minimumMountainRemovals(self, nums: List[int]) -> int:
        n = len(nums)
        
        def lis_lengths(arr):
            """计算每个位置的 LIS 长度（O(n log n)）"""
            dp = []  # 维护递增序列的最小末尾元素
            result = []
            for x in arr:
                pos = bisect.bisect_left(dp, x)
                if pos == len(dp):
                    dp.append(x)
                else:
                    dp[pos] = x
                result.append(pos + 1)
            return result
        
        # 从左到右的 LIS 长度
        lis = lis_lengths(nums)
        # 从右到左的 LIS 长度（即 LDS）
        lds = lis_lengths(nums[::-1])[::-1]
        
        max_mountain = 0
        for i in range(1, n - 1):
            if lis[i] > 1 and lds[i] > 1:
                max_mountain = max(max_mountain, lis[i] + lds[i] - 1)
        
        return n - max_mountain
```

### 方法二：朴素 DP（O(n^2)）

```python
from typing import List

class Solution:
    def minimumMountainRemovals(self, nums: List[int]) -> int:
        n = len(nums)
        
        # lis[i]：以 i 结尾的 LIS 长度
        lis = [1] * n
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    lis[i] = max(lis[i], lis[j] + 1)
        
        # lds[i]：以 i 开头的 LDS 长度（等于从右到左 LIS）
        lds = [1] * n
        for i in range(n - 2, -1, -1):
            for j in range(i + 1, n):
                if nums[j] < nums[i]:
                    lds[i] = max(lds[i], lds[j] + 1)
        
        max_mountain = 0
        for i in range(1, n - 1):
            if lis[i] > 1 and lds[i] > 1:
                max_mountain = max(max_mountain, lis[i] + lds[i] - 1)
        
        return n - max_mountain
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分优化 | O(n log n) | O(n) |
| 朴素 DP | O(n^2) | O(n) |

## 关键点总结

1. 问题转化：找最长山形子序列，最少删除 = n - 最长山形子序列长度
2. 山形 = 递增序列 + 递减序列，共享峰值
3. `lis[i] + lds[i] - 1` 计算以 i 为峰值的最长山形长度
4. 峰值必须不在首尾（`lis[i] > 1` 且 `lds[i] > 1`）

## 易错点

- 峰值不能是数组的第一个或最后一个元素
- `lds` 等于反转数组后的 LIS（再反转回来）
- 山形需要严格递增递减（使用 `bisect_left` 而不是 `bisect_right`）
