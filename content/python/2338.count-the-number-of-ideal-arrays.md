## 题目描述

给你两个整数 `n` 和 `maxValue`，用于描述一个**理想数组**。

对于下标从 **0** 开始、长度为 `n` 的整数数组 `arr`，如果满足以下条件，该数组就是一个**理想数组**：

- 每个 `arr[i]` 都是从 `1` 到 `maxValue` 范围内的一个值，其中 `0 <= i < n`。
- 每个 `arr[i]` 都可以被 `arr[i - 1]` **整除**，其中 `0 < i < n`。

返回长度为 `n` 的**不同**理想数组的数目。由于答案可能很大，返回对 `10^9 + 7` 取模的结果。

**示例 1：**
```
输入：n = 2, maxValue = 5
输出：10
```

**提示：**
- `2 <= n <= 10^4`
- `1 <= maxValue <= 10^4`

## 解题思路

**组合数学 + 枚举递增因子链：**

每个理想数组对应一条因子链 `v_0 | v_1 | ... | v_{k-1}`（v_i 整除 v_{i+1}），长度为 k（不同值的个数），然后将这 k 个不同值分配到 n 个位置中（允许连续重复，用隔板法）。

对于因子链长度为 k 的方案数，相当于将 k 个元素插入到 n 长度数组中（允许同一元素连续出现），即 C(n-1, k-1) 种分配方式。

**算法：**
1. 预处理 `dp[v][k]` = 以 v 结尾、长度为 k 的严格递增因子链数量（v_{i+1} 是 v_i 的倍数且 > v_i）。
2. 答案 = `sum over v, k: dp[v][k] * C(n-1, k-1)`。

## 代码实现

### 方法一：DP + 组合数（推荐）

```python
from math import comb

class Solution:
    def idealArrays(self, n: int, maxValue: int) -> int:
        MOD = 10 ** 9 + 7
        
        # dp[v] = 以 v 结尾的因子链中，各长度的数量
        # dp[v][k]：以 v 结尾、长度为 k 的严格递增因子链数
        
        # 由于 maxValue 最大为 10^4，因子链长度最大为 log2(10^4) ≈ 14
        MAX_K = 14
        
        # dp[v][k]：初始化，长度为 1 的链只有 v 自身
        dp = [[0] * (MAX_K + 1) for _ in range(maxValue + 1)]
        for v in range(1, maxValue + 1):
            dp[v][1] = 1
        
        # 枚举每个值作为链末尾，扩展到其倍数
        for v in range(1, maxValue + 1):
            for mul in range(2 * v, maxValue + 1, v):
                for k in range(1, MAX_K):
                    if dp[v][k] > 0:
                        dp[mul][k + 1] = (dp[mul][k + 1] + dp[v][k]) % MOD
        
        # 计算答案
        ans = 0
        for v in range(1, maxValue + 1):
            for k in range(1, MAX_K + 1):
                if dp[v][k] == 0:
                    continue
                # 将 k 个不同值分配到 n 个位置：C(n-1, k-1) 种方式
                ans = (ans + dp[v][k] * comb(n - 1, k - 1)) % MOD
        
        return ans
```

### 方法二：简化版（直接枚举因子链）

```python
from math import comb

class Solution:
    def idealArrays(self, n: int, maxValue: int) -> int:
        MOD = 10 ** 9 + 7
        
        # f[v][k]: 以 v 结尾长度为 k 的严格递增整除链的数量
        f = [[0] * 15 for _ in range(maxValue + 1)]
        for v in range(1, maxValue + 1):
            f[v][1] = 1
        
        for k in range(1, 14):
            for v in range(1, maxValue + 1):
                if f[v][k] == 0:
                    continue
                m = 2 * v
                while m <= maxValue:
                    f[m][k + 1] = (f[m][k + 1] + f[v][k]) % MOD
                    m += v
        
        ans = 0
        for v in range(1, maxValue + 1):
            for k in range(1, 15):
                ans = (ans + f[v][k] * comb(n - 1, k - 1)) % MOD
        return ans % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP + 组合数 | O(maxValue * log(maxValue) * MAX_K) | O(maxValue * MAX_K) |

## 关键点总结

1. 理想数组等价于因子链 + 将链中元素分配到 n 个位置的组合数。
2. 因子链最大长度为 `log2(maxValue)` ≈ 14（每次至少乘以 2）。
3. 分配方案数用隔板法：C(n-1, k-1)。

## 易错点

- 因子链是严格递增的（倍数关系要求严格大于），从 `2*v` 开始枚举。
- 组合数 `comb(n-1, k-1)` 当 k-1 > n-1 时为 0，Python 的 `comb` 自动处理。
