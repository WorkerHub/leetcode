## 题目描述

定义 `str = [s, n]` 表示 `str` 由 n 个字符串 s 拼接构成。

- 例如，`str == ["abc", 3] =="abcabcabc"`。

如果可以从 `s2` 中删除某些字符使其变为 `s1`，则称字符串 `s1` 可以从字符串 `s2` 获得。

- 例如，根据定义，`s1 = "abc"` 可以从 `s2 = "abdbec"` 获得，仅需要删除加粗且用斜体标识的字符。

现在给你两个字符串 `s1` 和 `s2` 和两个整数 `n1` 和 `n2`。由此构造得到两个字符串，其中 `str1 = [s1, n1]`、`str2 = [s2, n2]`。

请你找出一个最大整数 `m`，以满足 `str = [str2, m]` 可以从 `str1` 获得。

**示例 1：**
```
输入：s1 = "acb", n1 = 4, s2 = "ab", n2 = 2
输出：2
```

**示例 2：**
```
输入：s1 = "acb", n1 = 1, s2 = "acb", n2 = 1
输出：1
```

**提示：**
- `1 <= s1.length, s2.length <= 100`
- `s1` 和 `s2` 由小写英文字母组成
- `1 <= n1, n2 <= 10^6`

## 解题思路

这是一道**字符串匹配 + 循环节优化**的困难题。

**问题理解：**
- `str1 = s1 * n1`（s1 重复 n1 次）
- `str2 = s2 * n2`（s2 重复 n2 次）
- 求最大的 m，使得 `str2 * m` 是 `str1` 的子序列

**暴力思路：**
1. 在 `str1` 中不断匹配 `s2`
2. 每匹配完一个 `s2`，计数器加 1
3. 匹配完 `str1` 后，看能匹配多少个完整的 `str2`
4. 最后除以 n2 得到 m

**关键问题：** n1 和 n2 可达 10^6，直接暴力会超时

**优化策略：找循环节**
- 由于 s1 和 s2 都是有限字符串，在匹配过程中必然会出现循环
- 关键观察：从 s1 的某个位置开始匹配 s2，经过一轮 s1 后，会回到 s1 的某个固定位置
- 记录这个循环节，可以跳过重复计算

**循环节定义：**
- 记录每次遍历完一个 s1 后：
  - 在 s2 中的位置
  - 已经匹配了多少个完整的 s2
- 如果某次状态重复，说明找到了循环节

## Python 代码实现

### 方法一：找循环节优化（推荐）⭐

```python
class Solution:
    def getMaxRepetitions(self, s1: str, n1: int, s2: str, n2: int) -> int:
        if n1 == 0:
            return 0
        
        # 记录每遍历完一轮 s1 后的状态
        # recall[i] = (已匹配的 s2 个数, s2 中的位置)
        recall = {}
        s2_count = 0  # 已匹配的完整 s2 个数
        s2_idx = 0    # 当前在 s2 中的位置
        
        # 遍历 s1 的每一轮
        for i in range(1, n1 + 1):
            # 在当前轮 s1 中匹配 s2
            for char in s1:
                if char == s2[s2_idx]:
                    s2_idx += 1
                    if s2_idx == len(s2):
                        # 匹配完一个完整的 s2
                        s2_count += 1
                        s2_idx = 0
            
            # 检查是否出现循环节
            if s2_idx in recall:
                # 找到循环节
                prev_s1_count, prev_s2_count = recall[s2_idx]
                
                # 循环节的长度（s1 的轮数）
                cycle_len = i - prev_s1_count
                # 循环节内匹配的 s2 个数
                cycle_s2_count = s2_count - prev_s2_count
                
                # 剩余的 s1 轮数
                remaining_s1 = n1 - i
                # 可以完整重复多少个循环节
                repeat_cycles = remaining_s1 // cycle_len
                
                # 跳过循环节
                s2_count += repeat_cycles * cycle_s2_count
                
                # 处理剩余的不完整循环
                remaining_after_cycles = remaining_s1 % cycle_len
                for _ in range(remaining_after_cycles):
                    for char in s1:
                        if char == s2[s2_idx]:
                            s2_idx += 1
                            if s2_idx == len(s2):
                                s2_count += 1
                                s2_idx = 0
                
                break  # 找到循环节后跳出
            
            # 记录当前状态
            recall[s2_idx] = (i, s2_count)
        
        # 返回能匹配的 str2 个数
        return s2_count // n2
```

**核心思想：**
- 记录每轮 s1 结束后在 s2 中的位置
- 一旦位置重复，说明找到循环节
- 利用循环节跳过大量重复计算

### 方法二：预计算状态转移（更高效）

```python
class Solution:
    def getMaxRepetitions(self, s1: str, n1: int, s2: str, n2: int) -> int:
        if n1 == 0:
            return 0
        
        len1, len2 = len(s1), len(s2)
        
        # next_idx[i] 表示从 s2 的位置 i 开始，遍历一遍 s1 后到达 s2 的哪个位置
        # cnt[i] 表示这个过程中匹配了多少个完整的 s2
        next_idx = [0] * len2
        cnt = [0] * len2
        
        # 预计算状态转移
        for start_idx in range(len2):
            pos = start_idx
            count = 0
            for char in s1:
                if char == s2[pos]:
                    pos += 1
                    if pos == len2:
                        pos = 0
                        count += 1
            next_idx[start_idx] = pos
            cnt[start_idx] = count
        
        # 模拟 n1 轮 s1
        total_count = 0
        cur_idx = 0
        for _ in range(n1):
            total_count += cnt[cur_idx]
            cur_idx = next_idx[cur_idx]
        
        return total_count // n2
```

**优点：** 预计算所有可能的状态转移，避免重复计算

### 方法三：直接模拟（会超时，仅供理解）

```python
class Solution:
    def getMaxRepetitions(self, s1: str, n1: int, s2: str, n2: int) -> int:
        # 构造 str1
        str1 = s1 * n1
        
        # 在 str1 中匹配 s2
        s2_count = 0
        s2_idx = 0
        
        for char in str1:
            if char == s2[s2_idx]:
                s2_idx += 1
                if s2_idx == len(s2):
                    s2_count += 1
                    s2_idx = 0
        
        return s2_count // n2
```

**注意：** 当 n1 很大时会超时和内存溢出

## 复杂度分析

**方法一（循环节优化）：**
- 时间复杂度：O(|s1| × |s2|)
  - 最多遍历 |s2| 轮 s1（找到循环节）
  - 每轮遍历 s1 需要 O(|s1|)
- 空间复杂度：O(|s2|)，recall 字典

**方法二（预计算）：**
- 时间复杂度：O(|s1| × |s2| + n1)
  - 预计算：O(|s1| × |s2|)
  - 模拟：O(n1)
- 空间复杂度：O(|s2|)

**实际优化：** 方法一在找到循环节后可以直接跳过，通常更快

## 图解示例

以 `s1 = "acb", n1 = 4, s2 = "ab", n2 = 2` 为例：

```
str1 = "acbacbacbacb" (s1 重复 4 次)
str2 = "ab" * 2 = "abab"

在 str1 中匹配 s2 = "ab"：
a c b | a c b | a c b | a c b
↑       ↑       ↑       ↑
匹配 a   匹配 b   匹配 a   匹配 b
     完成 1 个 s2    完成 2 个 s2

总共匹配了 2 个完整的 s2
m = 2 // 2 = 1... 不对，应该是 2

重新分析：
在 "acbacbacbacb" 中匹配 "ab"：
- 第 1 个 a（位置 0）
- 第 1 个 b（位置 2）→ 完成第 1 个 "ab"
- 第 2 个 a（位置 3）
- 第 2 个 b（位置 5）→ 完成第 2 个 "ab"
- 第 3 个 a（位置 6）
- 第 3 个 b（位置 8）→ 完成第 3 个 "ab"
- 第 4 个 a（位置 9）
- 第 4 个 b（位置 11）→ 完成第 4 个 "ab"

总共匹配 4 个 "ab"
m = 4 // 2 = 2
```

## 关键点总结

1. **循环节优化：** 利用状态重复跳过计算
2. **状态定义：** 每轮 s1 结束后在 s2 中的位置
3. **子序列匹配：** 使用双指针，不是子串匹配
4. **最终计算：** 匹配的 s2 个数 / n2
5. **边界处理：** n1 或 n2 为 0 的情况

## 易错点

1. **理解题意：** 是子序列匹配，不是子串匹配
   ```python
   # s1 = "abc" 可以匹配 s2 = "ac"（删除 b）
   # 不是要求连续匹配
   ```

2. **循环节判断：** 用 s2 中的位置作为状态，不是 s1 的位置
   ```python
   # 正确：s2_idx 重复表示循环
   if s2_idx in recall:
   
   # 错误：用 s1 的轮数判断
   if i in recall:
   ```

3. **计数错误：** 匹配的是 s2 的个数，最后要除以 n2
   ```python
   # 正确
   return s2_count // n2
   
   # 错误：忘记除以 n2
   return s2_count
   ```

4. **边界情况：** n1 = 0 或未找到循环节时的处理
   ```python
   if n1 == 0:
       return 0
   ```
