## 题目描述

给你一个 **0** 下标的整数二维数组 `nodes`，其中 `nodes[i] = [id, parentId]`（`parentId` 为 -1 时表示根节点）。

给你一个整数数组 `order`，判断 `order` 是否是该二叉树的某种 **前序遍历** 结果（合法的前序序列）。

**示例 1：**
```
输入：nodes = [[2,-1],[3,2],[4,2],[1,3],[6,4]], order = [2,3,1,6,4]
输出：false
```

**示例 2：**
```
输入：nodes = [[1,-1],[2,1],[3,2],[4,3],[7,3]], order = [1,2,3,4,7]
输出：true
```

**提示：**
- `1 <= nodes.length <= 10^5`

## 解题思路

构建树，然后验证 `order` 数组是否与 DFS 前序遍历结果一致。

前序遍历使用栈模拟 DFS，维护当前期望的下一个访问节点指针，按序检查。

## Python 代码实现

### 方法一：构建树 + 迭代 DFS 验证（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def isPreorder(self, nodes: List[List[int]], order: List[int]) -> bool:
        # 构建邻接表（子节点列表）
        children = defaultdict(list)
        root = -1
        for node_id, parent_id in nodes:
            if parent_id == -1:
                root = node_id
            else:
                children[parent_id].append(node_id)

        # 迭代前序 DFS，验证 order
        idx = 0  # order 的指针
        stack = [root]

        while stack:
            node = stack.pop()
            if idx >= len(order) or order[idx] != node:
                return False
            idx += 1
            # 注意：子节点入栈顺序需要保证前序正确
            # 二叉树前序：根-左-右，栈中先入右再入左
            # 但这里可能有多种合法顺序，题目要求"某种前序"
            for child in reversed(children[node]):
                stack.append(child)

        return idx == len(order)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 构建树的邻接表，找到根节点
2. 迭代 DFS 前序遍历，逐一比对 order 数组
3. 子节点的遍历顺序需要根据 order 动态决定

## 易错点

1. 栈中子节点入栈顺序影响遍历结果，需要按 order 决定
2. 遍历结束后检查 idx == len(order)，确保 order 被完全消耗
