## 题目描述

如果一个数字字符串满足以下条件，则认为它是**好数字**：

- 下标从 0 开始，偶数位上的数字必须是偶数（0, 2, 4, 6, 8），有 5 种选择
- 奇数位上的数字必须是素数（2, 3, 5, 7），有 4 种选择

给你一个整数 `n`，返回长度为 `n` 的好数字字符串的数目，结果对 `10^9 + 7` 取余。

**示例 1：**
```
输入：n = 1
输出：5
解释：长度 1 的好数字：0,2,4,6,8
```

**示例 2：**
```
输入：n = 4
输出：400
解释：5 * 4 * 5 * 4 = 400
```

**提示：**
- `1 <= n <= 10^15`

---

## 解题思路

### 核心思想：快速幂

长度为 `n` 的字符串中：
- 偶数位有 `ceil(n/2) = (n+1)//2` 个，每个有 5 种选择
- 奇数位有 `floor(n/2) = n//2` 个，每个有 4 种选择

总数 = `5^((n+1)//2) * 4^(n//2)` mod `10^9+7`

由于 `n` 最大为 `10^15`，需要用**快速幂**（Python 内置 `pow(base, exp, mod)` 支持）。

---

## 代码实现

### 方法一：快速幂（推荐）

```python
class Solution:
    def countGoodNumbers(self, n: int) -> int:
        MOD = 10**9 + 7
        # 偶数位个数（0,2,4,...）= ceil(n/2)
        even_count = (n + 1) // 2
        # 奇数位个数（1,3,5,...）= floor(n/2)
        odd_count = n // 2
        # 使用 Python 内置快速幂（第三参数为模数）
        return pow(5, even_count, MOD) * pow(4, odd_count, MOD) % MOD
```

### 方法二：手写快速幂（对比学习）

```python
class Solution:
    def countGoodNumbers(self, n: int) -> int:
        MOD = 10**9 + 7

        def fast_pow(base: int, exp: int, mod: int) -> int:
            """快速幂：计算 base^exp % mod"""
            result = 1
            base %= mod
            while exp > 0:
                if exp % 2 == 1:
                    # 当前位为 1，乘入结果
                    result = result * base % mod
                # 底数平方，指数减半
                base = base * base % mod
                exp //= 2
            return result

        even_count = (n + 1) // 2
        odd_count = n // 2
        return fast_pow(5, even_count, MOD) * fast_pow(4, odd_count, MOD) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(log n) | O(1) |
| 方法二 | O(log n) | O(1) |

---

## 关键点总结

1. 统计偶数位和奇数位的个数，分别计算选择方案数
2. 两个幂次相乘即为答案
3. `n` 最大 `10^15`，必须使用快速幂（普通循环会超时）

---

## 易错点

- 偶数位个数是 `(n+1)//2`（包含第 0 位），不是 `n//2`
- 两个快速幂结果相乘后还需要 `% MOD`
