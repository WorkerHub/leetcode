## 题目描述

我们将整数 `x` 的**权重**定义为按照下述规则将 `x` 变成 `1` 所需要的步数：
- 如果 `x` 是偶数，那么 `x = x / 2`
- 如果 `x` 是奇数，那么 `x = 3 * x + 1`

比方说，`x = 3` 的权重为 7（3 → 10 → 5 → 16 → 8 → 4 → 2 → 1，共7步）。

给你三个整数 `lo`、`hi` 和 `k`，你的任务是将区间 `[lo, hi]` 之间的整数按照它们的权重**升序排序**，如果权重相同，请按照**数字本身升序**排序。

请你返回区间 `[lo, hi]` 之间的整数按权重排序后的第 `k` 个数（**从1开始**）。

**注意：** 对于任意满足 `lo <= x <= hi` 的整数 `x`，它的权重保证不会超过 `10^6`。且在排序过程中，区间 `[lo, hi]` 中的数不需要完整排序（只需找第k个）。

**示例 1：**
```
输入：lo = 12, hi = 15, k = 2
输出：13
解释：
12 的权重：12 → 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1，共9步。
13 的权重：13 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1，共9步。
14 的权重：14 → 7 → 22 → 11 → 34 → 17 → 52 → 26 → 13 → ..., 共17步。
15 的权重：15 → 46 → 23 → 70 → 35 → 106 → 53 → 160 → ..., 共17步。
按权重排序：[12(9), 13(9), 14(17), 15(17)] → 权重相同按数值升序
第2个是 13。
```

**示例 2：**
```
输入：lo = 7, hi = 11, k = 4
输出：7
```

**提示：**
- `1 <= lo <= hi <= 1000`
- `1 <= k <= hi - lo + 1`

## 解题思路

### 核心思想：记忆化递归 + 排序

**Collatz 猜想（3n+1 问题）：** 从任何正整数出发，不断执行：奇数→3n+1，偶数→n/2，最终会到达1。权重即所需步数。

**算法流程：**
1. **计算权重**：用递归 + 记忆化（缓存已计算的权重），避免重复计算。
2. **排序**：对 `[lo, hi]` 中所有整数按（权重, 数值）排序。
3. **返回第 k 个**：排序后返回下标 `k-1` 的元素。

## Python 代码实现

### 方法一：记忆化递归 + 排序（推荐）

```python
from typing import Dict
from functools import lru_cache

class Solution:
    def getKth(self, lo: int, hi: int, k: int) -> int:

        @lru_cache(maxsize=None)
        def power(x: int) -> int:
            """
            计算 x 的权重（到达1的步数）
            使用 lru_cache 缓存已计算的结果，避免重复计算
            """
            if x == 1:
                return 0
            if x % 2 == 0:
                return 1 + power(x // 2)
            else:
                return 1 + power(3 * x + 1)

        # 对 [lo, hi] 中所有整数按 (权重, 数值) 排序
        nums = sorted(range(lo, hi + 1), key=lambda x: (power(x), x))

        return nums[k - 1]  # k 从1开始，下标是 k-1
```

### 方法二：迭代计算权重（避免递归栈溢出）

```python
from typing import List

class Solution:
    def getKth(self, lo: int, hi: int, k: int) -> int:
        # 使用字典缓存已计算的权重
        cache: dict = {1: 0}

        def power(x: int) -> int:
            if x in cache:
                return cache[x]

            # 迭代版：记录路径，反向填充缓存
            path = []
            cur = x
            while cur not in cache:
                path.append(cur)
                if cur % 2 == 0:
                    cur = cur // 2
                else:
                    cur = 3 * cur + 1

            # cur 的权重已知，反向计算路径上所有节点的权重
            steps = cache[cur]
            for node in reversed(path):
                steps += 1
                cache[node] = steps

            return cache[x]

        # 按 (权重, 数值) 排序
        nums = sorted(range(lo, hi + 1), key=lambda x: (power(x), x))
        return nums[k - 1]
```

### 方法三：直接排序（不缓存，简洁但可能重复计算）

```python
class Solution:
    def getKth(self, lo: int, hi: int, k: int) -> int:

        def power(x: int) -> int:
            steps = 0
            while x != 1:
                if x % 2 == 0:
                    x //= 2
                else:
                    x = 3 * x + 1
                steps += 1
            return steps

        return sorted(range(lo, hi + 1), key=lambda x: (power(x), x))[k - 1]
```

### 方法四：只找第 k 个（不完全排序，使用 heapq.nsmallest）

```python
from typing import List
import heapq
from functools import lru_cache

class Solution:
    def getKth(self, lo: int, hi: int, k: int) -> int:

        @lru_cache(maxsize=None)
        def power(x: int) -> int:
            if x == 1:
                return 0
            return 1 + power(x // 2 if x % 2 == 0 else 3 * x + 1)

        # 只求第 k 小，无需完全排序
        # heapq.nsmallest 在 k 较小时比全排序更快
        return heapq.nsmallest(k, range(lo, hi + 1), key=lambda x: (power(x), x))[-1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| lru_cache 递归 | O(m × W) amortized, 排序 O(m log m) | O(W) 缓存 |
| 迭代缓存 | O(m × W) amortized, 排序 O(m log m) | O(W) 缓存 |
| 无缓存 | O(m × W), 排序 O(m log m) | O(1) |

- m = hi - lo + 1（区间大小，最大 1000）
- W = 最大权重（题目保证 ≤ 10^6，但实际对 1000 以内的数很小）
- 有缓存时，相同的中间值只计算一次

## 关键点总结

1. **Collatz 序列会经过很大的数**：即使 x ≤ 1000，序列中可能出现远大于 1000 的数（如 27 的序列峰值为9232），记忆化缓存这些中间值很重要。
2. **lru_cache**：Python 内置的装饰器，自动为递归函数添加缓存，使用方便，推荐。
3. **排序的 key 函数**：`key=lambda x: (power(x), x)` 同时按权重和数值排序，Python 的 tuple 比较是按字典序（先比第一元素，相等再比第二元素）。
4. **k 从1开始**：返回 `nums[k-1]`，注意下标从0开始。
5. **只需第 k 个可用 heapq.nsmallest**：对 k 很小时更高效，但本题数据规模小，差别不大。

## 易错点

1. **递归深度**：Python 默认递归深度限制（通常 1000），对 Collatz 序列可能超出，应使用 `@lru_cache` 减少深度，或用迭代版本。
2. **权重相同时按数值升序**：排序 key 中必须包含数值 `x`，否则相同权重的数顺序不确定。
3. **k 是1-based**：返回 `sorted_nums[k-1]`，不是 `sorted_nums[k]`。

## 学习建议

1. **Collatz 猜想**：虽未被证明，但数学界猜测所有正整数最终都会到达1，本题假设这是成立的。
2. **`@lru_cache`**：是 Python 记忆化的最简洁写法，适合单参数纯函数（无副作用、输出只依赖输入）。
3. **排序 + 索引**：在数据量不大时，排序后取第 k 个是最直接的方法，Python 的 `sorted` + `lambda` 用法是必备技能。
4. 本题也可以用动态规划的角度理解：`power(x) = 1 + power(next(x))`，边界是 `power(1) = 0`。
