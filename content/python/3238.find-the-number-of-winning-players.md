## 题目描述

给你一个整数 `n`（玩家数量，编号 0 到 n-1）和一个二维整数数组 `pick`，其中 `pick[i] = [xi, yi]` 表示玩家 `xi` 拾取了颜色为 `yi` 的球。

如果玩家 `i` 拾取的**某种颜色**的球的数量**严格大于** `i`，则玩家 `i` 获胜。

返回**获胜玩家**的数量。

**示例 1：**
```
输入：n = 4, pick = [[0,0],[1,0],[1,0],[2,1],[2,1],[2,0]]
输出：2
解释：
- 玩家0: 颜色0有1个，1>0，获胜
- 玩家1: 颜色0有2个，2>1，获胜
- 玩家2: 颜色1有2个，2>2不满足；颜色0有1个，1>2不满足，不获胜
- 玩家3: 没有球，不获胜
```

**示例 2：**
```
输入：n = 5, pick = [[1,1],[1,2],[1,3],[1,4]]
输出：0
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= pick.length <= 10^5`
- `0 <= xi <= n - 1`
- `0 <= yi <= 10`

## 解题思路

统计每个玩家每种颜色的球数，检查是否有某种颜色的数量 > 玩家编号。

由于颜色数量 yi <= 10，可以用嵌套字典或数组快速统计。

## Python 代码实现

### 方法一：哈希表统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def winningPlayerCount(self, n: int, pick: List[List[int]]) -> int:
        # cnt[player][color] = 数量
        cnt = [[0] * 11 for _ in range(n)]
        
        for x, y in pick:
            cnt[x][y] += 1
        
        ans = 0
        for i in range(n):
            # 检查是否有某种颜色数量 > i
            if max(cnt[i]) > i:
                ans += 1
        
        return ans
```

### 方法二：Counter 写法

```python
from typing import List
from collections import defaultdict, Counter

class Solution:
    def winningPlayerCount(self, n: int, pick: List[List[int]]) -> int:
        # 按玩家分组统计
        player_cnt = defaultdict(Counter)
        for x, y in pick:
            player_cnt[x][y] += 1
        
        ans = 0
        for i in range(n):
            if player_cnt[i] and max(player_cnt[i].values()) > i:
                ans += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为 pick 长度
- 空间复杂度：O(n * 11)

## 关键点总结

1. 颜色 yi 范围小（0-10），可以用数组快速统计
2. 获胜条件：某种颜色数量**严格大于**玩家编号 i
3. 玩家 0 只需某种颜色数量 > 0（即至少有 1 个）

## 易错点

1. 条件是严格大于（`>`），不是大于等于
2. 玩家编号从 0 开始，玩家 0 要求颜色数量 > 0
