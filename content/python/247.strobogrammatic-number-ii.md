## 题目描述

给你一个整数 `n`，返回所有长度为 `n` 的中心对称数。你可以按任何顺序返回答案。

中心对称数是指一个数字在旋转了 180 度之后看起来依旧相同的数字（或者上下颠倒地看）。

**示例 1：**
```
输入: n = 2
输出: ["11","69","88","96"]
```

**示例 2：**
```
输入: n = 1
输出: ["0","1","8"]
```

**提示：**
- 1 <= n <= 14

## 解题思路

这道题是 [LeetCode 246](https://leetcode.com/problems/strobogrammatic-number/) 的扩展，从判断变成生成所有可能的中心对称数。

**核心思想：**
- 使用递归或迭代，从中间向两边构建中心对称数
- 每次在两端添加一对对称的数字
- 注意特殊情况：不能有前导零（除了 "0" 本身）

**关键观察：**
1. **对称对**：可以添加的数字对有：('0','0'), ('1','1'), ('6','9'), ('8','8'), ('9','6')
2. **递归结构**：
   - n = 1: ["0", "1", "8"]
   - n = 2: 在 n=0 的基础上两端加对称对
   - n = 3: 在 n=1 的基础上两端加对称对
3. **前导零问题**：最外层不能是 '0'（除非 n=1 且结果是 "0"）

**递归思路：**
- base case: n = 0 返回 [""]，n = 1 返回 ["0", "1", "8"]
- recursive case: 在 n-2 的结果两端添加对称对
- 特殊处理：最外层过滤掉前导零的情况

## Python 代码实现

### 方法一：递归 + 回溯（推荐）⭐

```python
from typing import List

class Solution:
    def findStrobogrammatic(self, n: int) -> List[str]:
        """
        递归生成中心对称数
        时间复杂度：O(5^(n/2))，每层最多5种选择
        空间复杂度：O(5^(n/2))，存储所有结果
        """
        return self.helper(n, n)
    
    def helper(self, n: int, length: int) -> List[str]:
        """
        n: 当前需要生成的长度
        length: 最终目标长度（用于判断是否是最外层）
        """
        # 递归终止条件
        if n == 0:
            return [""]
        if n == 1:
            return ["0", "1", "8"]
        
        # 递归获取 n-2 长度的所有中心对称数
        middles = self.helper(n - 2, length)
        result = []
        
        # 在每个中间结果两端添加对称对
        for middle in middles:
            for pair in [('0', '0'), ('1', '1'), ('6', '9'), ('8', '8'), ('9', '6')]:
                # 最外层不能有前导零
                if n != length or pair[0] != '0':
                    result.append(pair[0] + middle + pair[1])
        
        return result
```

### 方法二：迭代法（自底向上）

```python
from typing import List

class Solution:
    def findStrobogrammatic(self, n: int) -> List[str]:
        """
        迭代方法，从小到大构建
        时间复杂度：O(5^(n/2))
        空间复杂度：O(5^(n/2))
        """
        # 初始化
        if n % 2 == 0:
            result = [""]
        else:
            result = ["0", "1", "8"]
        
        # 从中间向两边扩展
        pairs = [('0', '0'), ('1', '1'), ('6', '9'), ('8', '8'), ('9', '6')]
        
        # 每次循环增加2个字符（两端各1个）
        for _ in range(n // 2):
            new_result = []
            for num in result:
                for pair in pairs:
                    new_result.append(pair[0] + num + pair[1])
            result = new_result
        
        # 过滤掉前导零（除了 "0"）
        if n > 1:
            result = [num for num in result if num[0] != '0']
        
        return result
```

### 方法三：优化的递归（减少参数）

```python
from typing import List

class Solution:
    def findStrobogrammatic(self, n: int) -> List[str]:
        """
        简化的递归实现
        """
        def helper(current_len: int, is_outer: bool) -> List[str]:
            # 基础情况
            if current_len == 0:
                return [""]
            if current_len == 1:
                return ["0", "1", "8"]
            
            # 递归获取内层结果
            inner = helper(current_len - 2, False)
            result = []
            
            # 添加对称对
            pairs = [('0', '0'), ('1', '1'), ('6', '9'), ('8', '8'), ('9', '6')]
            for mid in inner:
                for left, right in pairs:
                    # 最外层不能有前导零
                    if not is_outer or left != '0':
                        result.append(left + mid + right)
            
            return result
        
        return helper(n, True)
```

### 方法四：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def findStrobogrammatic(self, n: int) -> List[str]:
        """
        使用记忆化避免重复计算
        """
        @lru_cache(None)
        def helper(length: int) -> List[str]:
            if length == 0:
                return [""]
            if length == 1:
                return ["0", "1", "8"]
            
            middles = helper(length - 2)
            result = []
            
            for middle in middles:
                for pair in [('0', '0'), ('1', '1'), ('6', '9'), ('8', '8'), ('9', '6')]:
                    result.append(pair[0] + middle + pair[1])
            
            return result
        
        # 获取所有结果
        all_nums = helper(n)
        
        # 过滤前导零
        if n > 1:
            return [num for num in all_nums if num[0] != '0']
        return all_nums
```

### 方法五：生成器版本（节省空间）

```python
from typing import List

class Solution:
    def findStrobogrammatic(self, n: int) -> List[str]:
        """
        使用生成器节省空间
        """
        def generate(current_len: int, target_len: int):
            if current_len == 0:
                yield ""
                return
            if current_len == 1:
                yield from ["0", "1", "8"]
                return
            
            # 递归生成内层
            for middle in generate(current_len - 2, target_len):
                for left, right in [('0', '0'), ('1', '1'), ('6', '9'), ('8', '8'), ('9', '6')]:
                    # 最外层不能有前导零
                    if current_len != target_len or left != '0':
                        yield left + middle + right
        
        return list(generate(n, n))
```

## 复杂度分析

所有方法的复杂度类似：
- **时间复杂度**：O(5^(n/2))，每一层最多有 5 种选择
- **空间复杂度**：O(5^(n/2))，存储所有结果

对于 n=14（最大值），结果数量约为 5^7 ≈ 78,125，是可以接受的。

## 关键点总结

1. **递归结构**：n 长度的问题可以拆解成 n-2 长度的子问题
2. **对称对**：5 对对称数字：(0,0), (1,1), (6,9), (8,8), (9,6)
3. **前导零处理**：最外层不能是 0，但中间层可以
4. **奇偶处理**：奇数长度有中间字符，偶数长度没有
5. **base case**：n=0 返回 [""]，n=1 返回 ["0","1","8"]

## 易错点

1. **前导零**：忘记过滤前导零，导致 "00"、"010" 等错误结果
2. **递归终止**：n=0 和 n=1 的 base case 要正确处理
3. **参数传递**：需要知道是否是最外层，才能判断是否允许 '0'
4. **奇偶性**：n 为奇数和偶数的初始状态不同
5. **结果顺序**：题目说可以任意顺序，不需要排序
