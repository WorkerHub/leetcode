## 题目描述

给定一个整数数组 `counts`，其中 `counts[i]` 表示使用面值组合恰好凑成金额 `i+1` 的方案数。给出使这些 `counts` 成立的最小硬币面值集合（每个面值唯一）。若不存在这样的面值集合，返回空数组。

换句话说：给定完全背包问题的结果数组，逆推硬币面值。

**示例 1：**

```
输入：counts = [1, 2, 3, 4, 5]
输出：[1, 2]
解释：面值 {1,2}：dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=4, dp[5]=5。
```

**示例 2：**

```
输入：counts = [1, 1, 2, 2, 3]
输出：[1, 3]
```

**提示：**
- `1 <= counts.length <= 50`
- `0 <= counts[i] <= 10^9`

## 解题思路

逆推完全背包：
- dp[i] = 使用面值集合凑成金额 i 的方案数（dp[0] = 1）
- dp[i] = sum(dp[i - c] for c in coins if c <= i)
- 逆推：对每个 i，dp[i] - sum(dp[i-c] for c in coins, c < i) 的余量
  - 若余量 > 0，则面值 i 是一个硬币（余量即为 dp[0] = 1，所以余量应为 1）
  - 若余量 = 0，则面值 i 不是硬币
  - 若余量 < 0 或余量 > 1，则无解返回 []

从 i=1 逐步确定：若当前位置满足加入 coin=i 能凑成 dp[i]，则加入。

## Python 代码实现

### 方法一：逐步逆推（推荐）

```python
from typing import List

class Solution:
    def findCoins(self, counts: List[int]) -> List[int]:
        n = len(counts)
        # dp[0] = 1（空方案），dp[i] = counts[i-1]
        dp = [0] * (n + 1)
        dp[0] = 1
        for i in range(1, n + 1):
            dp[i] = counts[i - 1]

        coins = []
        # 逐个确定 i 是否是面值
        for i in range(1, n + 1):
            # 已知 coins 中面值，从 dp 倒推是否需要面值 i
            # dp[i] = sum(dp[i-c] for c in coins+[i?])
            # 当前已知 coins 贡献：
            current = sum(dp[i - c] for c in coins if c <= i)
            remainder = dp[i] - current
            if remainder == 0:
                pass  # i 不是面值
            elif remainder == 1:
                coins.append(i)  # i 是面值
            else:
                return []  # 无法构成，无解

        # 验证：用推出的 coins 重新计算 dp，是否与输入一致
        verify = [0] * (n + 1)
        verify[0] = 1
        for i in range(1, n + 1):
            for c in coins:
                if c <= i:
                    verify[i] += verify[i - c]
            if verify[i] != dp[i]:
                return []

        return coins
```

### 方法二：动态规划验证

```python
from typing import List

class Solution:
    def findCoins(self, counts: List[int]) -> List[int]:
        n = len(counts)
        target = [0] + counts  # target[i] = counts[i-1]

        coins = []
        dp = [0] * (n + 1)
        dp[0] = 1

        for i in range(1, n + 1):
            # 已有 coins 对 dp[i] 的贡献
            contrib = sum(dp[i - c] for c in coins if c <= i)
            diff = target[i] - contrib
            if diff < 0:
                return []
            elif diff == 1:
                # 加入面值 i
                coins.append(i)
                dp[i] = target[i]
            elif diff == 0:
                dp[i] = target[i]
            else:
                return []

        return coins
```

## 复杂度分析

- 时间复杂度：O(n^2)，对每个位置枚举已知硬币
- 空间复杂度：O(n)，dp 数组

## 关键点总结

1. 利用完全背包 dp[i] = sum(dp[i-c]) 逆推
2. 对每个 i，计算已有硬币贡献后余量
3. 余量 = 0：i 不是硬币；= 1：i 是硬币；其他：无解

## 易错点

1. dp[0] = 1 是完全背包初始值，不要遗漏
2. 逆推时需按照从小到大顺序确定硬币
3. 余量可能因浮点或整数溢出引起问题，全程使用整数
