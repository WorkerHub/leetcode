## 题目描述

给你两个整数 `lo` 和 `hi`，统计满足以下条件的整数数目：该整数的各位数字之和被 3 整除（即数字和 % 3 == 0）。

**示例 1：**

```
输入：lo = 1, hi = 20
输出：7
解释：1到20中数字和被3整除的：3, 6, 9, 12, 15, 18, 20（20: 2+0=2，不对）
实际：3,6,9,12(1+2=3),15(1+5=6),18(1+8=9)，共6个。
```

**示例 2：**

```
输入：lo = 100, hi = 200
输出：34
```

**提示：**
- `1 <= lo <= hi <= 10^9`

## 解题思路

**数位 DP**：统计 `[1, n]` 中各位数字和被 3 整除的整数数目。

状态：`dp(pos, remainder, tight)`
- `pos`：当前处理的位
- `remainder`：当前数字和 mod 3
- `tight`：是否受上界约束

终止条件：处理完所有位，检查 `remainder == 0`。

## Python 代码实现

### 方法一：数位 DP（推荐）

```python
from functools import lru_cache

class Solution:
    def countIntegers(self, lo: int, hi: int) -> int:
        def count_up_to(n):
            digits = list(map(int, str(n)))
            length = len(digits)

            @lru_cache(maxsize=None)
            def dp(pos, remainder, tight, started):
                if pos == length:
                    return 1 if started and remainder == 0 else 0

                limit = digits[pos] if tight else 9
                result = 0

                for d in range(0, limit + 1):
                    new_tight = tight and (d == limit)
                    if not started and d == 0:
                        result += dp(pos + 1, 0, new_tight, False)
                    else:
                        new_rem = (remainder + d) % 3
                        result += dp(pos + 1, new_rem, new_tight, True)

                return result

            return dp(0, 0, True, False)

        return count_up_to(hi) - count_up_to(lo - 1)
```

### 方法二：数学公式（近似）

```python
class Solution:
    def countIntegers(self, lo: int, hi: int) -> int:
        # 1 到 n 中，大约 1/3 的整数数字和能被 3 整除
        # 精确计算用数位 DP
        def count_up_to(n):
            # 直接计算：1到n中各位和被3整除的数
            # 利用等差性质：大约是 n/3
            cnt = 0
            for x in range(1, n + 1):
                if sum(int(d) for d in str(x)) % 3 == 0:
                    cnt += 1
            return cnt

        # 暴力法，大范围不适用
        if hi <= 10**5:
            return count_up_to(hi) - count_up_to(lo - 1)

        # 用数位 DP
        from functools import lru_cache
        def count_dp(n):
            s = str(n)
            L = len(s)
            @lru_cache(maxsize=None)
            def dp(i, rem, tight, started):
                if i == L:
                    return 1 if started and rem == 0 else 0
                hi_d = int(s[i]) if tight else 9
                res = 0
                for d in range(hi_d + 1):
                    nt = tight and d == hi_d
                    if not started and d == 0:
                        res += dp(i + 1, 0, nt, False)
                    else:
                        res += dp(i + 1, (rem + d) % 3, nt, True)
                return res
            return dp(0, 0, True, False)

        return count_dp(hi) - count_dp(lo - 1)
```

## 复杂度分析

- 时间复杂度：O(10 * L * 3)，L 为数字位数（最多 10 位），3 为余数状态数
- 空间复杂度：O(L * 3)，记忆化

## 关键点总结

1. 数位 DP 的状态：位置、当前数字和的余数、是否受上界约束、是否已有前导非零数字。
2. `count(lo, hi) = count_up_to(hi) - count_up_to(lo - 1)`。
3. 余数只有 0, 1, 2 三种状态，状态空间极小。

## 易错点

1. 前导零不计入数字（`started = False` 时跳过）。
2. `lru_cache` 在每次调用 `count_up_to` 时需要清除（不同 n 共用缓存会出错），可以将 digits 作为参数传入或每次新建。
