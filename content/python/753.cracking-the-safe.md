## 题目描述

有一个需要密码才能打开的保险箱。密码是 `n` 位数，密码的每一位都是范围 `[0, k-1]` 中的一个数字。

你可以输入任意长度的密码序列，保险箱会自动记住最后 `n` 位输入。

例如，假设密码是 `"345"`，我可以输入 `"012345"` 来打开它，因为保险箱只记得最后 `3` 位数字 `"345"`。

请返回一个能打开保险箱的最短字符串。

**示例 1:**
```
输入：n = 1, k = 2
输出："01" 或 "10"
解释：只有两种可能的密码：
"0" 和 "1"
"01" 和 "10" 都可以打开保险箱。
```

**示例 2:**
```
输入：n = 2, k = 2
输出："00110"
解释：
4 种可能的密码：
"00", "01", "10", "11"
"00110" 可以打开保险箱，因为它包含了所有可能的密码：
"00" (位置 0-1)
"01" (位置 1-2)
"11" (位置 2-3)
"10" (位置 3-4，循环到位置 0)
```

**提示：**
- `1 <= n <= 4`
- `1 <= k <= 10`
- `1 <= k^n <= 4096`

## 解题思路

这道题实际上是要找到一个包含所有可能的 n 位密码的最短字符串，这是一个经典的 **欧拉回路（Eulerian Circuit）** 问题。

**核心思想：**
1. 将问题转化为图论问题
2. 每个 (n-1) 位的数字序列是一个节点
3. 如果在节点 A 后面添加一个数字可以得到节点 B，则 A 到 B 有一条边
4. 遍历所有边恰好一次，就能得到包含所有 n 位密码的序列

**图的构建：**
- 节点：所有可能的 (n-1) 位数字序列，共 k^(n-1) 个
- 边：从节点 A 到节点 B，表示在 A 的末尾添加一个数字后，删除第一位，得到 B
- 每个节点有 k 条出边，k 条入边
- 这是一个欧拉图（所有节点的入度等于出度）

**算法流程（Hierholzer 算法）：**
1. 从起点（通常是全 0）开始
2. 使用 DFS 遍历所有边
3. 将访问的边（代表添加的数字）记录下来
4. 逆序输出结果

## Python 代码实现

### 方法一：欧拉回路（Hierholzer 算法）⭐

```python
class Solution:
    def crackSafe(self, n: int, k: int) -> str:
        if n == 1:
            return ''.join(map(str, range(k)))
        
        # 起始节点（n-1 个 0）
        start = "0" * (n - 1)
        
        # 记录已访问的边
        visited = set()
        result = []
        
        def dfs(node):
            # 尝试所有可能的下一个数字
            for digit in range(k):
                # 构造边（节点 + 数字）
                edge = node + str(digit)
                
                if edge not in visited:
                    visited.add(edge)
                    # 下一个节点是当前边的后 n-1 位
                    next_node = edge[1:]
                    dfs(next_node)
                    # 记录添加的数字
                    result.append(str(digit))
        
        dfs(start)
        
        # 添加起始节点
        return "".join(result[::-1]) + start
```

### 方法二：迭代版本（使用栈）

```python
class Solution:
    def crackSafe(self, n: int, k: int) -> str:
        if n == 1:
            return ''.join(map(str, range(k)))
        
        start = "0" * (n - 1)
        visited = set()
        stack = [start]
        result = []
        
        while stack:
            node = stack[-1]
            found = False
            
            # 查找未访问的边
            for digit in range(k):
                edge = node + str(digit)
                if edge not in visited:
                    visited.add(edge)
                    next_node = edge[1:]
                    stack.append(next_node)
                    found = True
                    break
            
            if not found:
                # 所有边都已访问，回溯
                if len(stack) > 1:
                    # 记录从上一个节点到当前节点的数字
                    prev_node = stack[-2]
                    current_node = stack[-1]
                    # 找到对应的数字
                    for digit in range(k):
                        if prev_node + str(digit) == prev_node[:-1] + current_node:
                            result.append(str(digit))
                            break
                    else:
                        # 如果 prev_node 和 current_node 不直接相连
                        # 找到 edge 对应的最后一位
                        for digit in range(k):
                            if (prev_node + str(digit))[1:] == current_node:
                                result.append(str(digit))
                                break
                stack.pop()
        
        return start + "".join(result[::-1])
```

### 方法三：优化的递归版本

```python
class Solution:
    def crackSafe(self, n: int, k: int) -> str:
        if n == 1:
            return ''.join(map(str, range(k)))
        
        visited = set()
        result = []
        
        def dfs(node):
            for digit in map(str, range(k)):
                edge = node + digit
                if edge not in visited:
                    visited.add(edge)
                    dfs(edge[1:])  # 下一个节点
                    result.append(digit)
        
        start = "0" * (n - 1)
        dfs(start)
        
        return "".join(result[::-1]) + start
```

### 方法四：贪心 + DFS（易理解版本）

```python
class Solution:
    def crackSafe(self, n: int, k: int) -> str:
        # 特殊情况
        if n == 1:
            return ''.join(str(i) for i in range(k))
        
        # 总共有 k^n 个不同的密码
        total = k ** n
        visited = set()
        result = ["0"] * n  # 从全 0 开始
        
        def dfs():
            if len(visited) == total:
                return True
            
            # 获取当前的后 n-1 位
            prev = "".join(result[-(n-1):])
            
            # 尝试添加每个数字
            for digit in range(k):
                new_password = prev + str(digit)
                
                if new_password not in visited:
                    visited.add(new_password)
                    result.append(str(digit))
                    
                    if dfs():
                        return True
                    
                    # 回溯
                    visited.remove(new_password)
                    result.pop()
            
            return False
        
        # 添加初始密码
        visited.add("".join(result))
        dfs()
        
        return "".join(result)
```

## 复杂度分析

- **时间复杂度：** O(k^n)，需要访问所有 k^n 个密码
- **空间复杂度：** O(k^n)，需要存储所有访问过的边和递归栈

## 关键点总结

1. **问题转化：** 将问题转化为寻找欧拉回路
2. **图的性质：** 这是一个欧拉图，所有节点的入度等于出度
3. **Hierholzer 算法：** 用于寻找欧拉回路的经典算法
4. **DFS 顺序：** 后序遍历的逆序就是欧拉回路
5. **边的表示：** 边由节点加一个数字组成

## 易错点

1. **特殊情况：** n=1 时需要特殊处理
2. **节点定义：** 节点是 (n-1) 位序列，不是 n 位
3. **边的构造：** 边由当前节点加一个数字组成
4. **结果顺序：** DFS 的结果需要逆序
5. **起始节点：** 不要忘记在结果末尾添加起始节点

## 图解示例

以 n=2, k=2 为例：

```
节点（1位）：0, 1
边（2位）：00, 01, 10, 11

图的结构：
0 --0--> 0  (边 "00")
0 --1--> 1  (边 "01")
1 --0--> 0  (边 "10")
1 --1--> 1  (边 "11")

DFS 遍历顺序（从节点 0 开始）：
0 -> (边00) -> 0 -> (边01) -> 1 -> (边11) -> 1 -> (边10) -> 0

边的顺序：00, 01, 11, 10
逆序：10, 11, 01, 00
添加起始节点 "0"：0 + 10110 的后面部分

实际构造：
- 访问边 00：结果为 "0"
- 访问边 01：结果为 "00" + "1" = "001"
- 访问边 11：结果为 "001" + "1" = "0011"
- 访问边 10：结果为 "0011" + "0" = "00110"
```
