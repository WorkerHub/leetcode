## 题目描述

给你一棵二叉树的根节点 `root` 和两个整数值 `p` 和 `q`，计算二叉树中节点 `p` 和节点 `q` 之间的**距离**（两节点之间边的数目）。

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 0
输出：3
```

**提示：**
- 树中节点个数的范围在 `[1, 10^4]` 之间
- 每个节点的值都在 `[0, 10^4]` 之间
- 所有节点值都是唯一的
- `p` 和 `q` 是有效节点值

## 解题思路

两种方法：

**方法一（LCA 法）**：
- 找到节点 p 和 q 的最近公共祖先（LCA）
- 距离 = LCA 到 p 的距离 + LCA 到 q 的距离

**方法二（BFS）**：
- 建立无向图（父子关系）
- BFS 求 p 到 q 的最短路

## 代码实现

### 方法一：LCA + 深度（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findDistance(self, root: Optional[TreeNode], p: int, q: int) -> int:
        def find_lca(node, p, q):
            """找到 p 和 q 的最近公共祖先"""
            if not node:
                return None
            if node.val == p or node.val == q:
                return node
            left = find_lca(node.left, p, q)
            right = find_lca(node.right, p, q)
            if left and right:
                return node  # 当前节点是 LCA
            return left or right
        
        def find_depth(node, target, depth):
            """找到目标节点的深度（从当前节点计）"""
            if not node:
                return -1
            if node.val == target:
                return depth
            left = find_depth(node.left, target, depth + 1)
            if left != -1:
                return left
            return find_depth(node.right, target, depth + 1)
        
        lca = find_lca(root, p, q)
        return find_depth(lca, p, 0) + find_depth(lca, q, 0)
```

### 方法二：BFS 求最短路

```python
from typing import Optional
from collections import defaultdict, deque

class Solution:
    def findDistance(self, root: Optional[TreeNode], p: int, q: int) -> int:
        # 建立无向图
        graph = defaultdict(list)
        
        def build_graph(node):
            if not node:
                return
            if node.left:
                graph[node.val].append(node.left.val)
                graph[node.left.val].append(node.val)
                build_graph(node.left)
            if node.right:
                graph[node.val].append(node.right.val)
                graph[node.right.val].append(node.val)
                build_graph(node.right)
        
        build_graph(root)
        
        # BFS 从 p 到 q
        queue = deque([(p, 0)])
        visited = {p}
        while queue:
            node, dist = queue.popleft()
            if node == q:
                return dist
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append((neighbor, dist + 1))
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(n)，树的节点数
- **空间复杂度**：O(n)，递归栈/队列

## 关键点总结

1. LCA 方法：距离 = LCA 到 p 的距离 + LCA 到 q 的距离
2. BFS 方法：将树转为无向图后求最短路

## 易错点

- p 或 q 可能是另一个的祖先，LCA 即为较深的那个
