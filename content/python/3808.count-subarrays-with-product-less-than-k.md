## 题目描述

给你一个正整数数组 `nums` 和一个正整数 `k`，返回乘积严格小于 `k` 的子数组数目。

**示例 1：**

```
输入：nums = [10, 5, 2, 6], k = 100
输出：8
解释：乘积小于 100 的子数组为：
[10], [5], [2], [6], [10, 5], [5, 2], [2, 6], [5, 2, 6]，共 8 个。
注意 [10, 5, 2] 乘积为 100，不严格小于 100。
```

**示例 2：**

```
输入：nums = [1, 2, 3], k = 0
输出：0
解释：k = 0，任何正整数乘积都不小于 0。
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 10^6`

## 解题思路

使用**滑动窗口**（双指针）：
1. 维护一个乘积严格小于 k 的窗口 `[left, right]`。
2. 每次将 `right` 右移，将 `nums[right]` 乘入乘积。
3. 若乘积 >= k，则将 `left` 右移并除以 `nums[left]`，直到乘积 < k 或窗口为空。
4. 以 `right` 为右端点的合法子数组数目为 `right - left + 1`（所有以 right 结尾的子数组）。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0  # 所有元素 >= 1，乘积不可能 < 1 或 < 0

        count = 0
        product = 1
        left = 0

        for right in range(len(nums)):
            product *= nums[right]
            # 收缩左边界，直到乘积 < k
            while product >= k:
                product //= nums[left]
                left += 1
            # 以 right 为右端点的合法子数组数目
            count += right - left + 1

        return count
```

### 方法二：前缀积 + 二分查找

```python
from typing import List
import bisect
import math

class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k == 0:
            return 0

        # 取对数转化为前缀和，乘积 < k 等价于对数之和 < log(k)
        log_k = math.log(k)
        prefix = [0.0]
        for num in nums:
            prefix.append(prefix[-1] + math.log(num))

        count = 0
        for right in range(1, len(prefix)):
            # 找满足 prefix[right] - prefix[left] < log_k 的最小 left
            target = prefix[right] - log_k + 1e-9  # 浮点误差补偿
            left = bisect.bisect_left(prefix, target)
            count += right - left

        return count
```

## 复杂度分析

- 时间复杂度：
  - 方法一：O(n)，双指针各最多移动 n 次
  - 方法二：O(n log n)，二分查找
- 空间复杂度：O(1)（方法一）；O(n)（方法二，前缀数组）

## 关键点总结

1. 滑动窗口适用于乘积/和的连续子数组计数问题。
2. 以 right 为右端点、left 为左边界的合法子数组数 = `right - left + 1`。
3. k <= 1 时直接返回 0（元素均为正整数）。

## 易错点

1. 乘积是整除还是浮点除法？由于元素都是整数，`//` 可能有误差，建议先乘再判断后再除，或使用浮点。
2. k = 0 或 k = 1 需要特殊处理。
