## 题目描述

给定一个无向图（n 个节点，m 条边），需要为每个节点分配一个 `1` 到 `n` 的唯一整数值（排列）。边的价值等于其两端节点值的乘积，图的总价值是所有边的价值之和。求最大化图的总价值所能得到的最大值。

**示例 1：**

```
输入：n = 3, edges = [[0,1],[1,2]]
输出：8
解释：分配 [1,3,2]：边(0,1)=1*3=3，边(1,2)=3*2=6，总价值=9；
     分配 [2,3,1]：边(0,1)=6，边(1,2)=3，总价值=9；
     分配 [1,2,3]：边(0,1)=2，边(1,2)=6，总价值=8；
     最大值为 9（或更大）。
```

**提示：**
- `2 <= n <= 5 * 10^4`
- `m <= min(n*(n-1)/2, 10^5)`

## 解题思路

贪心策略：度数越大的节点应该分配越大的值，因为它参与更多的边乘积。

按节点度数降序排列，分配从 n 到 1 的值（度数最大的节点分配最大值）。

关键：若两个节点都分配了最大的值，它们连接的边收益最大。

## Python 代码实现

### 方法一：按度数排序分配（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumValueSum(self, n: int, edges: List[List[int]]) -> int:
        # 计算每个节点的度数
        degree = [0] * n
        for u, v in edges:
            degree[u] += 1
            degree[v] += 1

        # 按度数降序排列节点
        nodes_by_degree = sorted(range(n), key=lambda x: degree[x], reverse=True)

        # 分配值：度数最大的节点分配最大值 n
        node_val = [0] * n
        for rank, node in enumerate(nodes_by_degree):
            node_val[node] = n - rank

        # 计算总价值
        total = 0
        for u, v in edges:
            total += node_val[u] * node_val[v]

        return total
```

### 方法二：连通分量优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumValueSum(self, n: int, edges: List[List[int]]) -> int:
        # 贪心：对每个连通分量，将最大的值分配给度数最大的节点
        degree = defaultdict(int)
        for u, v in edges:
            degree[u] += 1
            degree[v] += 1

        # 找所有连通分量
        graph = defaultdict(set)
        for u, v in edges:
            graph[u].add(v)
            graph[v].add(u)

        visited = set()
        components = []

        def bfs(start):
            comp = []
            queue = [start]
            visited.add(start)
            while queue:
                node = queue.pop()
                comp.append(node)
                for nb in graph[node]:
                    if nb not in visited:
                        visited.add(nb)
                        queue.append(nb)
            return comp

        for i in range(n):
            if i not in visited:
                comp = bfs(i)
                components.append(comp)

        # 对每个连通分量，按度数分配最大值
        node_val = [0] * n
        available = list(range(n, 0, -1))  # n, n-1, ..., 1
        val_idx = 0

        # 所有有边的节点按度数降序排列
        active_nodes = sorted([node for node in range(n) if degree[node] > 0],
                               key=lambda x: degree[x], reverse=True)
        inactive_nodes = [node for node in range(n) if degree[node] == 0]

        for node in active_nodes:
            node_val[node] = available[val_idx]
            val_idx += 1

        total = 0
        for u, v in edges:
            total += node_val[u] * node_val[v]

        return total
```

## 复杂度分析

- 时间复杂度：O(n log n + m)，排序 + 计算
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：度数大的节点分配大的值，最大化参与多边的节点贡献
2. 孤立节点（无边）分配小值不影响结果
3. 排序后按序分配即可

## 易错点

1. 孤立节点不参与任何边，可以分配任意小的值
2. 若图不连通，各连通分量独立考虑
3. 证明贪心正确性：交换参数论证（两个节点交换值，若度数较大的节点原本分配较小值，交换后总和更大）
