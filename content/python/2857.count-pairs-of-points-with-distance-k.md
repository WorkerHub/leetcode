## 题目描述

给你一个下标从 0 开始的二维整数数组 `coordinates` 和一个整数 `k`。

**距离**定义为：`(x1 XOR x2) + (y1 XOR y2)`。

返回满足距离等于 `k` 的点对数。

**示例 1：**
```
输入：coordinates = [[1,2],[4,2],[1,3],[5,2]], k = 5
输出：2
解释：
(0,2): (1 XOR 1) + (2 XOR 3) = 0 + 1 = 1 ≠ 5
(0,1): (1 XOR 4) + (2 XOR 2) = 5 + 0 = 5 ✓
(1,2): (4 XOR 1) + (2 XOR 3) = 5 + 1 = 6 ≠ 5
(1,3): (4 XOR 5) + (2 XOR 2) = 1 + 0 = 1 ≠ 5
(2,3): (1 XOR 5) + (3 XOR 2) = 4 + 1 = 5 ✓
共 2 对
```

**提示：**
- `2 <= coordinates.length <= 50000`
- `0 <= xi, yi <= 10^6`
- `0 <= k <= 100`（k 很小）

## 解题思路

**关键：** k 很小（<= 100），可以枚举 `x1 XOR x2` 的所有可能值 t（0 到 k），则 `y1 XOR y2 = k - t`。

**哈希表：** 用哈希表存储之前出现过的 (x, y) 对的计数。

对每个点 (x2, y2)，枚举 t 从 0 到 k：
- `target_x = t XOR x2`... 不对，需要 `x1 = t XOR x2`（使 `x1 XOR x2 = t`）
  - 即 `x1 = x2 XOR t`
- `target_y = (k - t) XOR y2`
  - 即 `y1 = y2 XOR (k - t)`
- 查找哈希表中 `(x1, y1)` 的出现次数

## Python 代码实现

### 方法一：哈希表 + 枚举（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def countPairs(self, coordinates: List[List[int]], k: int) -> int:
        cnt = defaultdict(int)
        ans = 0

        for x, y in coordinates:
            # 枚举 x1 XOR x2 的值 t（0 到 k）
            for t in range(k + 1):
                # x1 = x XOR t，y1 = y XOR (k - t)
                need_x = x ^ t
                need_y = y ^ (k - t)
                ans += cnt[(need_x, need_y)]
            # 将当前点加入哈希表
            cnt[(x, y)] += 1

        return ans
```

### 方法二：更清晰的注释版

```python
from collections import defaultdict
from typing import List

class Solution:
    def countPairs(self, coordinates: List[List[int]], k: int) -> int:
        # prev 存储已处理的点
        prev = defaultdict(int)
        ans = 0

        for x2, y2 in coordinates:
            # 枚举 x1 XOR x2 的所有可能值
            for a in range(k + 1):
                b = k - a  # y1 XOR y2 = k - a
                # x1 = x2 XOR a，y1 = y2 XOR b
                x1 = x2 ^ a
                y1 = y2 ^ b
                ans += prev[(x1, y1)]

            prev[(x2, y2)] += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n × k)，n 为点的数量，k 最大 100
- 空间复杂度：O(n)，哈希表存储所有点

## 关键点总结

1. k 很小，可以枚举 XOR 分解：`a + b = k`，`x1 XOR x2 = a`，`y1 XOR y2 = b`
2. 对每种分解，用 `x1 = x2 XOR a` 推导需要的 x1，查哈希表
3. 先查哈希表，再加入当前点（避免自配对）

## 易错点

1. 先查询再插入（保证是不同点的配对，且不重复计数）
2. `a` 从 0 到 k（包含两端点）
3. `(x1, y1) = (x2 ^ a, y2 ^ (k-a))`，注意 XOR 与 (k-t) 的关系
