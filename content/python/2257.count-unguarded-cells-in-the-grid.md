## 题目描述

给你两个整数 `m` 和 `n`，分别表示行数和列数。另有两个二维整数数组：
- `guards`：`guards[i] = [rowi, coli]` 是守卫所在位置。
- `walls`：`walls[j] = [rowj, colj]` 是墙的位置。

守卫可以向**上、下、左、右**四个方向无限远处警戒，但被墙（或其他守卫）遮挡时停止。

返回网格中**未被任何守卫警戒**的**空单元格**的数量。

**示例 1：**
```
输入：m = 4, n = 6, guards = [[0,0],[1,1],[2,3]], walls = [[0,1],[2,2],[1,4]]
输出：7
```

## 解题思路

**模拟：** 标记每个单元格的状态（守卫、墙、被守卫、未被守卫）。

对每个守卫，向四个方向延伸，遇到墙或守卫停止，将经过的单元格标记为"被守卫"。

最后统计空单元格（非墙、非守卫、未被守卫）的数量。

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def countUnguarded(self, m: int, n: int, guards: List[List[int]], walls: List[List[int]]) -> int:
        # 状态：0=未访问, 1=被守卫, 2=守卫/墙
        grid = [[0] * n for _ in range(m)]

        # 标记守卫和墙
        for r, c in guards:
            grid[r][c] = 2
        for r, c in walls:
            grid[r][c] = 2

        # 守卫向四个方向延伸
        for r, c in guards:
            # 向上
            i = r - 1
            while i >= 0 and grid[i][c] != 2:
                grid[i][c] = 1
                i -= 1
            # 向下
            i = r + 1
            while i < m and grid[i][c] != 2:
                grid[i][c] = 1
                i += 1
            # 向左
            j = c - 1
            while j >= 0 and grid[r][j] != 2:
                grid[r][j] = 1
                j -= 1
            # 向右
            j = c + 1
            while j < n and grid[r][j] != 2:
                grid[r][j] = 1
                j += 1

        # 统计状态为 0 的单元格（空且未被守卫）
        return sum(grid[i][j] == 0 for i in range(m) for j in range(n))
```

### 方法二：位掩码优化（理解用）

```python
from typing import List

class Solution:
    def countUnguarded(self, m: int, n: int, guards: List[List[int]], walls: List[List[int]]) -> int:
        # 用不同状态值区分
        EMPTY = 0
        GUARDED = 1
        BLOCKER = 2  # 守卫或墙

        grid = [[EMPTY] * n for _ in range(m)]
        for r, c in guards + walls:
            grid[r][c] = BLOCKER

        def mark(r, c, dr, dc):
            r += dr
            c += dc
            while 0 <= r < m and 0 <= c < n and grid[r][c] != BLOCKER:
                if grid[r][c] == EMPTY:
                    grid[r][c] = GUARDED
                r += dr
                c += dc

        for r, c in guards:
            for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                mark(r, c, dr, dc)

        return sum(grid[i][j] == EMPTY for i in range(m) for j in range(n))
```

## 复杂度分析

- 时间复杂度：O(m*n + g*(m+n))，g 为守卫数量，每个守卫最多覆盖 m+n 个格子。
- 空间复杂度：O(m*n)，网格状态数组。

## 关键点总结

1. 守卫和墙都作为"遮挡物"，用同一状态值（2）。
2. 向四个方向延伸，遇到 2（守卫/墙）停止。
3. 最后统计状态为 0 的单元格。

## 易错点

- 被其他守卫遮挡时也要停止（守卫也是遮挡物）。
- 守卫和墙的初始标记要先完成，再做方向延伸，否则顺序会影响结果。
