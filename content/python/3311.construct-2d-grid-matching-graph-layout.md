## 题目描述

给你两个整数 `n` 和 `m`，以及一个二维整数数组 `edges`，其中 `edges[i] = [u, v]` 表示节点 `u` 和节点 `v` 之间有一条无向边。

构造一个 `n x m` 的二维网格，使得：
- 网格中每个格子填入 `0` 到 `n*m - 1` 中不同的数。
- 两个数相邻（上下左右）当且仅当它们之间在 `edges` 中有连接。

若存在这样的网格，返回该网格；否则返回空数组。

**提示：**
- `2 <= n, m <= 4`
- `2 <= n * m <= 12`

## 解题思路

由于 `n * m <= 12`，节点数量很小，可以用以下方法：

1. **找到角节点**：角节点度数为 2，边节点（非角）度数为 3，中心节点度数为 4。
2. **构造首行**：首行第一个元素是角节点，之后根据邻接关系逐步确定每一行。
3. **逐行填充**：首行确定后，每行的首元素由上一行首元素的邻居（非已使用）确定，同行后续元素由前一个的邻居且与上方格子也相邻来确定。

由于网格尺寸最大 4x4，且约束严格，可以用 DFS + 回溯构造，或利用度数约束直接构造。

## Python 代码实现

### 方法一：基于度数约束构造

```python
from typing import List
from collections import defaultdict

class Solution:
    def constructGridLayout(self, n: int, edges: List[List[int]]) -> List[List[int]]:
        # 构建邻接表和度数
        adj = defaultdict(set)
        for u, v in edges:
            adj[u].add(v)
            adj[v].add(u)
        
        degree = {i: len(adj[i]) for i in range(n)}
        total = len(degree)  # n * m
        
        # 找角节点（度数为2），若 n==1 或 m==1 找度数为1的
        # 这里 n, m 是行列数，total = n * m
        # 简化：直接 DFS 尝试构造
        
        rows, cols = n, total // n
        # 确保 rows <= cols
        # 根据度数确定格子类型：角(2), 边(3), 中心(4)
        # 在1行网格中度数可以是1或2
        
        def try_build(grid, used, r, c):
            if r == rows:
                return True
            if c == cols:
                return try_build(grid, used, r + 1, 0)
            
            # 确定候选节点
            if r == 0 and c == 0:
                # 角节点
                candidates = [v for v in range(total) if degree[v] == min(2, cols - 1 + rows - 1)]
            elif r == 0:
                # 第一行：必须与左边节点相邻
                left = grid[0][c - 1]
                candidates = [v for v in adj[left] if v not in used]
            else:
                # 必须与上方节点相邻
                up = grid[r - 1][c]
                candidates = [v for v in adj[up] if v not in used]
                if c > 0:
                    # 还必须与左边节点相邻
                    left = grid[r][c - 1]
                    candidates = [v for v in candidates if v in adj[left]]
            
            for v in candidates:
                grid[r][c] = v
                used.add(v)
                if try_build(grid, used, r, c + 1):
                    return True
                used.remove(v)
                grid[r][c] = -1
            
            return False
        
        # 尝试每个可能的起始角节点
        for start in range(total):
            grid = [[-1] * cols for _ in range(rows)]
            used = {start}
            grid[0][0] = start
            if try_build(grid, used, 0, 1):
                return grid
        
        return []
```

## 复杂度分析

- 时间复杂度：O((n*m)! / ((n*m - n*m)!))，最坏情况下的回溯，但由于约束严格，实际运行很快
- 空间复杂度：O(n*m)

## 关键点总结

1. 网格中相邻位置当且仅当存在边，利用此约束剪枝。
2. 回溯时从左上角开始，逐格填入满足与上方和左方都相邻的节点。
3. 由于 n*m <= 12，即使有回溯也不会太慢。

## 易错点

1. 行列方向的约束：同行相邻、同列相邻，两个方向都要满足。
2. 起始角节点的选择影响整体构造结果，需要尝试所有可能的起始点。
3. 交换 rows 和 cols 得到的转置矩阵也是合法答案。
