## 题目描述

给你一个整数 `n`，以及一个包含 `2^n` 个整数的数组 `sums`，它是某个长度为 `n` 的未知数组 `original` 的**所有子集和**（包括空子集，其和为 0）。

请你还原并返回原数组 `original`（可能含负数）。如果有多个答案，返回任意一个。

**提示：**
- `1 <= n <= 15`
- `sums.length == 2^n`
- `-10^4 <= sums[i] <= 10^4`

---

## 解题思路

### 核心思想：分治 + 差集还原

**关键观察**：
- 将 `sums` 排序
- 最小值和次小值之差为某个元素（设为 `d = sums[1] - sums[0]`），但不知道 `d` 还是 `-d` 是原数组元素
- 对 `sums` 按 `d` 分组：若含 `d` 则从 `sums` 中删去对应的 `sums[i] - d` 组（递归）；否则从 `sums` 中删去 `sums[i] - 0` 的部分（递归）

**分治步骤**：
1. 排序
2. `d = sums[1] - sums[0]`（候选元素为 `d` 或 `-d + sum_offset`）
3. 将 `sums` 分成两半：一半包含 `d`，一半不包含
4. 递归处理其中一半，最终确定 `d` 或 `d - sums[0]`

## 代码实现

### 方法一：分治递归（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, n: int, sums: List[int]) -> List[int]:

        def solve(arr: List[int]) -> List[int]:
            if len(arr) == 1:
                # arr = [0]，对应空集，返回空
                return []

            arr.sort()
            # 候选元素 d = arr[1] - arr[0]
            d = arr[1] - arr[0]

            # 将 arr 分为两组：包含 d 的和不包含 d 的
            # 尝试不选 d（对应 arr[0] 不含 d）
            cnt = Counter(arr)
            group0 = []
            group1 = []
            ok = True
            tmp = Counter(arr)
            for v in arr:
                if tmp[v] == 0:
                    continue
                tmp[v] -= 1
                if tmp[v + d] == 0:
                    ok = False
                    break
                tmp[v + d] -= 1
                group0.append(v)      # 不含 d 的组
                group1.append(v + d)  # 含 d 的组

            if ok:
                # 两种方案：d 在原数组，或 -d 在原数组
                # group0 包含 arr[0]，不含 d
                # 如果 arr[0] 在 group0 中（即选 0 不含 d），则原元素为 d
                # 否则原元素为 -d（取 group1 继续）
                # 检验：group0 必须包含 arr[0]
                res = solve(group0)
                # d 对应加入 group0 时元素是 d，否则元素是 0（不是 d）
                # arr[0] 一定在 group0 里（因为 arr[0] 是最小值，不含 d）
                return res + [d]
            else:
                # d = 0 且必须重新分
                # 当 d=0 时所有元素相同，直接取一半
                group0 = arr[:len(arr) // 2]
                return solve(group0) + [0]

        sums.sort()
        return solve(sums)
```

### 方法二：标准分治（处理 d=0 的边界）

```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, n: int, sums: List[int]) -> List[int]:

        def solve(sums: list) -> list:
            if len(sums) == 1:
                return []
            sums.sort()
            d = sums[1] - sums[0]  # 候选差值

            # 分组：将 sums 分成两个大小相等的子集
            # group_a 不含 d（对应不选该元素），group_b = group_a + d（对应选该元素）
            cnt = Counter(sums)
            group_a, group_b = [], []
            used = Counter()
            for v in sums:
                if used[v] > 0:
                    used[v] -= 1
                    continue
                group_a.append(v)
                group_b.append(v + d)
                used[v + d] += 1

            # group_a 包含 sums[0]（最小值不含 d）
            # 递归还原 group_a，原数组元素之一为 d（或 0 若 d=0）
            # 若 d=0：无法区分，选 group_a 的任意一半
            res = solve(group_a)
            return res + [d]

        return solve(sums)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分治 | O(2^n * n) | O(2^n) |

---

## 关键点总结

1. 每次取最小的差值 `d` 作为候选元素，将 `sums` 分为含 `d` 和不含 `d` 两半
2. 最小值 `sums[0]` 一定在不含 `d` 的组（因为它最小）
3. 递归处理一半，直到剩余 1 个元素（即 0，空集）

---

## 易错点

- `d = 0` 时两组相同，直接取前一半
- 注意分组后必须通过 Counter 去重匹配
