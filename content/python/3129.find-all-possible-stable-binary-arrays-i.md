## 题目描述

给你 3 个正整数 `zero`、`one` 和 `limit`。

**稳定** 的二进制数组定义：
- 数组中 0 的个数恰好为 `zero`，1 的个数恰好为 `one`
- 数组中不存在长度超过 `limit` 的全 0 或全 1 子数组

返回稳定二进制数组的数量，对 `10^9 + 7` 取模。

**示例 1：**
```
输入：zero = 1, one = 1, limit = 2
输出：2
解释：[0,1] 和 [1,0] 都是稳定的。
```

**示例 2：**
```
输入：zero = 1, one = 2, limit = 1
输出：1
解释：[1,0,1] 是唯一满足的（[0,1,1] 末尾有两个 1，超过 limit=1）。
```

**提示：**
- `1 <= zero, one, limit <= 200`

## 解题思路

动态规划：`dp[i][j][v]` 表示已放 i 个 0、j 个 1，且末位为 v 的稳定数组数量。

转移时，若末位为 v，则从末位为 v 的连续段长度 1 到 limit 的状态转移过来。使用前缀和优化。

## Python 代码实现

### 方法一：DP + 前缀和（推荐）

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7

        # dp[i][j][v]: 用了 i 个 0, j 个 1，末位为 v 的方案数
        # 初始化
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(i: int, j: int, last: int) -> int:
            # i 个 0 剩余，j 个 1 剩余，上一个放的是 last
            if i == 0 and j == 0:
                return 1
            res = 0
            if last == 0:
                # 本次放 1，下一个可以放 0 或 1
                for cnt in range(1, limit + 1):
                    if j >= cnt:
                        res += dp(i, j - cnt, 1) if cnt < limit else ...
                # 重新思考递归定义
            return res

        # 换一种 DP 定义
        # dp[i][j][v]: 放了 i 个 0, j 个 1，最后一位是 v 的方案数
        dp2 = [[[0, 0] for _ in range(one + 1)] for _ in range(zero + 1)]
        # 初始化：只放一个 0 或一个 1
        if zero >= 1:
            dp2[1][0][0] = 1
        if one >= 1:
            dp2[0][1][1] = 1

        # 前缀和
        # prefix0[i][j] = sum(dp2[i][j][0]) 用于快速计算
        for i in range(zero + 1):
            for j in range(one + 1):
                if i == 0 and j == 0:
                    continue
                if i > 0:
                    # 末位放 0，来自末位为 1 的状态（最后一段 0 长度 1~limit）
                    # 简化：dp2[i][j][0] = sum(dp2[i-k][j][1] for k in 1..limit)
                    for k in range(1, min(i, limit) + 1):
                        dp2[i][j][0] = (dp2[i][j][0] + dp2[i-k][j][1]) % MOD
                    # 初始情况：j==0 时全为 0 的数组
                    if j == 0 and i <= limit:
                        dp2[i][j][0] = (dp2[i][j][0] + 1) % MOD
                if j > 0:
                    for k in range(1, min(j, limit) + 1):
                        dp2[i][j][1] = (dp2[i][j][1] + dp2[i][j-k][0]) % MOD
                    if i == 0 and j <= limit:
                        dp2[i][j][1] = (dp2[i][j][1] + 1) % MOD

        return (dp2[zero][one][0] + dp2[zero][one][1]) % MOD
```

### 方法二：记忆化搜索

```python
from functools import lru_cache

class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7

        @lru_cache(maxsize=None)
        def solve(z: int, o: int, last: int) -> int:
            # 还需要放 z 个 0 和 o 个 1，上一段末位是 last
            if z == 0 and o == 0:
                return 1
            res = 0
            nxt = 1 - last  # 下一段放的值
            need = z if nxt == 0 else o
            for cnt in range(1, min(need, limit) + 1):
                nz = z - cnt if nxt == 0 else z
                no = o - cnt if nxt == 1 else o
                res = (res + solve(nz, no, nxt)) % MOD
            return res

        ans = 0
        for cnt in range(1, min(zero, limit) + 1):
            ans = (ans + solve(zero - cnt, one, 0)) % MOD
        for cnt in range(1, min(one, limit) + 1):
            ans = (ans + solve(zero, one - cnt, 1)) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(zero * one * limit)
- 空间复杂度：O(zero * one)

## 关键点总结

1. 关键约束：任意连续相同元素段长度不超过 limit
2. DP 状态记录已用 0 和 1 的数量及末位值
3. 转移时枚举末段长度（1 到 limit）

## 易错点

1. 初始状态（全 0 或全 1 的前缀）需要特别处理
2. 末段长度最多 limit，不是 zero 或 one
