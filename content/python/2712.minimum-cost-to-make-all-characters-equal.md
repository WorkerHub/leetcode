## 题目描述

给你一个下标从 **0** 开始、长度为 `n` 的二进制字符串 `s`，你可以对其执行以下操作 **任意次**：

- 选择下标 `i` 并翻转 **前缀** `s[0..i]` 或 **后缀** `s[i..n-1]`
- 翻转的代价为 `i + 1`（翻转前缀）或 `n - i`（翻转后缀）

返回使 `s` 中所有字符相等的 **最小代价**。

**示例 1：**
```
输入：s = "0011"
输出：2
解释：翻转 s[0..1]（前缀），代价 2，得到 "1111"
```

**示例 2：**
```
输入：s = "010101"
输出：9
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 是 `'0'` 或 `'1'`

## 解题思路

**贪心**：观察相邻两个字符之间的关系：

若 `s[i] != s[i-1]`，则需要翻转 `s[0..i-1]`（代价 `i`）或翻转 `s[i..n-1]`（代价 `n - i`），取最小代价 `min(i, n - i)`。

为什么？每次翻转操作实际上是统一某段的字符。最优策略：在每对相邻不同字符之间，选择翻转代价较小的一侧。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def minimumCost(self, s: str) -> int:
        n = len(s)
        cost = 0
        for i in range(1, n):
            if s[i] != s[i - 1]:
                # 翻转前缀 [0..i-1] 代价 i
                # 翻转后缀 [i..n-1] 代价 n-i
                cost += min(i, n - i)
        return cost
```

### 方法二：动态规划验证

```python
class Solution:
    def minimumCost(self, s: str) -> int:
        n = len(s)
        # dp[i] 表示使 s[0..i] 全部相等的最小代价
        # 此方法更直观地说明贪心的正确性
        ans = 0
        for i in range(1, n):
            if s[i] != s[i - 1]:
                ans += min(i, n - i)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 翻转前缀/后缀不改变相邻字符的相对关系
2. 每对相邻不同字符对应一个"分割点"，需要代价来消除
3. 贪心选择代价较小的翻转方向

## 易错点

1. 注意前缀翻转 `[0..i]` 代价是 `i+1`，但两个相邻字符 `s[i-1]` 和 `s[i]` 的分界处，翻转 `s[0..i-1]` 代价是 `i`
2. 翻转操作会改变字符串，但贪心分析时只需考虑相邻差异点
