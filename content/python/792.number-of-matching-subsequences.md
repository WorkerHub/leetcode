## 题目描述

给定字符串 `s` 和字符串数组 `words`，返回 `words` 中是 `s` 的子序列的单词个数。

字符串的**子序列**是从原字符串中删除一些（也可以不删除）字符后，剩余字符保持原有顺序得到的新字符串。

**示例 1：**
```
输入: s = "abcde", words = ["a","bb","acd","ace"]
输出: 3
解释: 有三个是 s 的子序列的单词: "a", "acd", "ace"
```

**示例 2：**
```
输入: s = "dsahjpjauf", words = ["ahjpjau","ja","ahbwzgqnuk","tnmlanowax"]
输出: 2
解释: "ahjpjau" 和 "ja" 是 s 的子序列
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `1 <= words.length <= 5000`
- `1 <= words[i].length <= 50`
- `s` 和 `words[i]` 都只包含小写英文字母

## 解题思路

这道题的朴素做法是对每个单词检查是否是 `s` 的子序列，但数据量较大时会超时。需要优化。

**关键观察：**

1. **朴素解法（会超时）**：
   - 对每个单词，用双指针检查是否是 `s` 的子序列
   - 时间复杂度：O(s.length × words.length)，当两者都很大时会超时

2. **优化思路一：预处理 + 二分查找**：
   - 预处理 `s`，记录每个字符出现的所有位置
   - 对每个单词，用二分查找快速定位下一个字符的位置
   - 时间复杂度：O(s.length + words 总长度 × log(s.length))

3. **优化思路二：分桶 + 迭代器**：
   - 将所有单词按照"下一个待匹配字符"分组
   - 遍历 `s` 的每个字符，推进对应桶中的所有单词
   - 避免重复遍历 `s`

4. **优化思路三：字典树（Trie）**：
   - 将所有单词构建成字典树
   - 遍历 `s`，在字典树中推进所有可能的路径
   - 适合单词有公共前缀的情况

## Python 代码实现

### 方法一：预处理 + 二分查找（推荐）

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def numMatchingSubseq(self, s: str, words: List[str]) -> int:
        """
        预处理 s 中每个字符的位置，使用二分查找匹配
        
        时间复杂度：O(n + m * L * log n)
        空间复杂度：O(n)
        """
        # 预处理：记录每个字符在 s 中的所有位置
        char_positions = defaultdict(list)
        for i, char in enumerate(s):
            char_positions[char].append(i)
        
        def is_subsequence(word: str) -> bool:
            """判断 word 是否是 s 的子序列"""
            pos = -1  # 当前在 s 中的位置
            
            for char in word:
                # 如果字符不在 s 中，直接返回 False
                if char not in char_positions:
                    return False
                
                # 使用二分查找找到下一个字符的位置
                positions = char_positions[char]
                idx = bisect.bisect_right(positions, pos)
                
                # 如果没有找到合适的位置，返回 False
                if idx == len(positions):
                    return False
                
                # 更新当前位置
                pos = positions[idx]
            
            return True
        
        # 统计有多少个单词是 s 的子序列
        return sum(is_subsequence(word) for word in words)
```

### 方法二：分桶 + 迭代器（效率最高）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numMatchingSubseq(self, s: str, words: List[str]) -> int:
        """
        将单词按"下一个待匹配字符"分组，一次遍历 s
        
        时间复杂度：O(n + m * L)
        空间复杂度：O(m * L)
        """
        # 将单词转为迭代器，并按第一个字符分组
        waiting = defaultdict(list)
        for word in words:
            it = iter(word)
            waiting[next(it)].append(it)
        
        count = 0
        
        # 遍历 s 的每个字符
        for char in s:
            # 取出所有等待当前字符的迭代器
            current_waiting = waiting[char]
            waiting[char] = []
            
            for it in current_waiting:
                # 尝试获取下一个字符
                next_char = next(it, None)
                
                if next_char is None:
                    # 单词已经匹配完成
                    count += 1
                else:
                    # 将迭代器放到下一个字符的桶中
                    waiting[next_char].append(it)
        
        return count
```

### 方法三：朴素双指针（简单但可能超时）

```python
from typing import List

class Solution:
    def numMatchingSubseq(self, s: str, words: List[str]) -> int:
        """
        对每个单词用双指针检查是否是子序列
        
        时间复杂度：O(n * m)，可能超时
        空间复杂度：O(1)
        """
        def is_subsequence(word: str) -> bool:
            """检查 word 是否是 s 的子序列"""
            i = 0  # s 的指针
            j = 0  # word 的指针
            
            while i < len(s) and j < len(word):
                if s[i] == word[j]:
                    j += 1
                i += 1
            
            return j == len(word)
        
        return sum(is_subsequence(word) for word in words)
```

### 方法四：使用缓存优化

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def numMatchingSubseq(self, s: str, words: List[str]) -> int:
        """
        使用缓存避免重复计算相同的单词
        
        时间复杂度：O(n + unique_words * L * log n)
        空间复杂度：O(n + unique_words)
        """
        # 预处理字符位置
        char_positions = defaultdict(list)
        for i, char in enumerate(s):
            char_positions[char].append(i)
        
        # 使用字典缓存结果
        cache = {}
        
        def is_subsequence(word: str) -> bool:
            if word in cache:
                return cache[word]
            
            pos = -1
            for char in word:
                if char not in char_positions:
                    cache[word] = False
                    return False
                
                positions = char_positions[char]
                idx = bisect.bisect_right(positions, pos)
                
                if idx == len(positions):
                    cache[word] = False
                    return False
                
                pos = positions[idx]
            
            cache[word] = True
            return True
        
        return sum(is_subsequence(word) for word in words)
```

## 复杂度分析

### 方法一：预处理 + 二分查找
- **时间复杂度：** O(n + m × L × log n)
  - n 是 `s` 的长度，m 是 `words` 的数量，L 是单词平均长度
  - 预处理：O(n)
  - 每个单词：O(L × log n)（L 次二分查找）
- **空间复杂度：** O(n)，存储字符位置

### 方法二：分桶 + 迭代器
- **时间复杂度：** O(n + total)，total 是所有单词的总长度
  - 遍历 s：O(n)
  - 处理所有单词：O(total)
- **空间复杂度：** O(total)，存储迭代器

### 方法三：朴素双指针
- **时间复杂度：** O(n × m)，每个单词都要遍历 s
- **空间复杂度：** O(1)

## 关键点总结

1. **子序列判断**：双指针是基础方法，但对多个单词效率低
2. **预处理优化**：记录字符位置，用二分查找加速
3. **批量处理**：分桶方法一次遍历 s，同时推进所有单词的匹配
4. **迭代器技巧**：方法二使用迭代器优雅地记录每个单词的匹配进度
5. **缓存优化**：如果有重复单词，可以用缓存避免重复计算

## 易错点

1. **二分查找边界**：使用 `bisect_right` 找到严格大于当前位置的下一个位置
2. **迭代器耗尽**：`next(it, None)` 返回 `None` 表示单词匹配完成
3. **字符不存在**：如果单词中有 `s` 中不存在的字符，直接返回 `False`
4. **位置更新**：二分查找后要更新 `pos` 为找到的位置
5. **空单词处理**：空单词是任何字符串的子序列
