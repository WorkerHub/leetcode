## 题目描述

给你一个整数数组 `strength`（每个锁的强度）和整数 `K`。

你有一把钥匙，初始能量 `X = 1`。

破开第 `i` 把锁需要你的能量 `X` 满足：`X % strength[i] == 0`（即 X 是 strength[i] 的倍数）。

破开第 `i` 把锁后，你的能量 `X` 变为 `X + K`。

你可以选择任意顺序破开所有锁。返回破开所有锁的**最短时间**，其中破开每把锁的时间等于你当前能量变成第 i 把锁的最小倍数的等待时间...

**重新理解：** 破开第 `i` 把锁需要你的 X 是 strength[i] 的倍数，而 X 可以通过等待（X += 1 每秒）增加，或者破开锁后 X 增加 K。

实际上：每次操作选一把锁，等到 X 满足条件，然后破开（X 不增加，而是下一把锁时 X += K）。

返回总等待时间。

**提示：**
- `1 <= n <= 8`（锁的数量很少，可以状压 DP）

## 解题思路

**状态压缩 DP：**

由于锁的数量 n <= 8，可以用状态压缩 DP 枚举所有排列顺序。

`dp[mask]` = 破开 `mask` 中的所有锁所需的最短时间（等待时间），同时记录当前的 X 值。

但 X 值依赖于已破开的锁的数量，`X = 1 + popcount(mask) * K`。

破开第 `i` 把锁：当前 `X`，需要等到 `X' = lcm(X, strength[i])`... 

实际上：X 需要是 strength[i] 的倍数。当前 X，需要增加最小步数使 X 变为 strength[i] 的最小倍数 >= X。等待步数 = `ceil(X / strength[i]) * strength[i] - X`。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
import math

class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        INF = float('inf')
        
        # dp[mask] = 破开 mask 中所有锁的最短等待时间
        dp = [INF] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            # 已破开的锁数量
            num_opened = bin(mask).count('1')
            X = 1 + num_opened * K  # 当前能量
            
            for i in range(n):
                if mask & (1 << i):
                    continue  # 已破开
                # 破开第 i 把锁需要等的时间
                # X 需要变成 strength[i] 的最小倍数
                s = strength[i]
                need = math.ceil(X / s) * s  # X 变成 s 的倍数，最小的 >= X
                wait = need - X
                new_mask = mask | (1 << i)
                dp[new_mask] = min(dp[new_mask], dp[mask] + wait)
        
        return dp[(1 << n) - 1]
```

## 复杂度分析

- 时间复杂度：O(2^n * n)，状压 DP
- 空间复杂度：O(2^n)

## 关键点总结

1. 已破开 `k` 把锁后，当前能量 `X = 1 + k * K`。
2. 破开第 `i` 把锁的等待时间 = `ceil(X / strength[i]) * strength[i] - X`。
3. 状压 DP 枚举所有破锁顺序，找最小总等待时间。

## 易错点

1. `ceil(X / s) * s` 是不小于 X 的 s 的最小倍数，可以用 `((X + s - 1) // s) * s` 计算。
2. 破开一把锁后 X 增加 K（在下一步体现，不是立即）。
3. `X = 1 + num_opened * K`，初始 X = 1，每破一把锁 X += K。
