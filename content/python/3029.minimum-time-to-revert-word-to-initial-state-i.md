## 题目描述

给你一个字符串 `word` 和整数 `k`。

每次操作：
1. 删除 `word` 的前 `k` 个字符
2. 在 `word` 末尾添加 `k` 个**任意**字符

你需要让 `word` 恢复到初始状态。

返回最少需要的操作次数。

**示例 1：**
```
输入：word = "abacaba", k = 3
输出：2
```

**示例 2：**
```
输入：word = "abacaba", k = 4
输出：1
```

**提示：**
- `1 <= word.length <= 50`
- `1 <= k <= word.length`
- `word` 只包含小写英文字母

## 解题思路

经过 `t` 次操作后，`word` 的前 `n - t*k` 个字符（若为正）等于原 `word` 的前 `n - t*k` 个字符，后面 `t*k` 个字符可以任意填充。

因此，`word` 能恢复到初始状态当且仅当：`word[t*k:]` 是 `word` 的一个前缀（即 `word` 的前缀 `word[0..n-t*k-1]` 等于 `word[t*k..n-1]`）。

也就是检查 `word` 是否有长度为 `n - t*k` 的前缀后缀匹配。

利用 KMP 失配函数（Z 函数）快速检查。

## Python 代码实现

### 方法一：Z 函数检查（推荐）

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)

        def z_function(s: str):
            """计算 Z 数组"""
            n = len(s)
            z = [0] * n
            z[0] = n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and s[z[i]] == s[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z

        z = z_function(word)

        for t in range(1, n // k + 2):
            start = t * k
            if start >= n:
                return t  # 所有字符都被替换，可以构造任意字符串
            # 检查 word[start:] 是否是 word 的前缀
            # 即 z[start] >= n - start
            if z[start] >= n - start:
                return t

        return (n + k - 1) // k
```

### 方法二：KMP 前缀函数

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)

        # 构建 KMP 失配表
        fail = [0] * n
        j = 0
        for i in range(1, n):
            while j > 0 and word[i] != word[j]:
                j = fail[j - 1]
            if word[i] == word[j]:
                j += 1
            fail[i] = j

        # 检查操作次数 t
        for t in range(1, n // k + 2):
            start = t * k
            if start >= n:
                return t
            # 利用失配函数：检查 word[start:] 是否是 word 的前缀
            # 即 word 中长度为 n - start 的后缀是否等于前缀
            # 用 Z 函数更直接，这里用暴力验证
            if word[start:] == word[:n - start]:
                return t

        return (n + k - 1) // k
```

### 方法三：直接字符串比较（n <= 50 时）

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)
        for t in range(1, n // k + 2):
            start = t * k
            if start >= n:
                return t
            # word[start:] 是 word 的前缀子串
            if word.startswith(word[start:]):
                return t
        return (n + k - 1) // k
```

## 复杂度分析

- 时间复杂度：O(n)，Z 函数 O(n)，检查 O(n/k) 次
- 空间复杂度：O(n)，Z 数组

## 关键点总结

1. 操作 t 次后，只有后 t*k 个字符可以自由设置
2. 恢复条件：`word[t*k:]` 等于 `word` 的前缀（长度 `n - t*k`）
3. Z 函数能快速判断：`z[i] >= n - i` 说明 `word[i:]` 是 `word` 的前缀

## 易错点

1. `start >= n` 时，原始字符串全部被替换，可以构造任意字符串
2. Z 函数中 `z[0] = n`（整个字符串是自身的前缀）
3. 注意循环上界：最多 `ceil(n/k)` 次操作
