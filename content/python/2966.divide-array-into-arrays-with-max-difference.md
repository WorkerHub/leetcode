## 题目描述

给你一个长度为 `n`（n 为 3 的倍数）的整数数组 `nums` 和一个正整数 `k`。

将 `nums` 分成 `n/3` 个大小为 3 的数组，满足每个子数组中最大元素与最小元素之差不超过 `k`。

若存在合法分法则返回它，否则返回空数组。

**示例 1：**
```
输入：nums = [1,3,4,8,7,9,3,5,1], k = 2
输出：[[1,1,3],[3,4,5],[7,8,9]]
```

**示例 2：**
```
输入：nums = [1,3,3,2,7,3], k = 3
输出：[[1,2,3],[3,3,7]] -- 实际：[[1,2,3],[3,3,7]] 7-3=4>3，不合法
返回：[]
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `n % 3 == 0`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^5`

## 解题思路

排序后，贪心地将每三个连续元素分为一组。

若排序后的数组中，任意 `sorted_nums[3i+2] - sorted_nums[3i] > k`（每组第一和第三个元素差超过 k），则不可行。

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def divideArray(self, nums: List[int], k: int) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        result = []

        for i in range(0, n, 3):
            # 每组三个相邻元素
            if nums[i + 2] - nums[i] > k:
                return []  # 不可行
            result.append([nums[i], nums[i + 1], nums[i + 2]])

        return result
```

### 方法二：验证分组

```python
from typing import List

class Solution:
    def divideArray(self, nums: List[int], k: int) -> List[List[int]]:
        nums.sort()
        groups = [[nums[i], nums[i+1], nums[i+2]] for i in range(0, len(nums), 3)]
        for g in groups:
            if g[2] - g[0] > k:
                return []
        return groups
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，存储结果

## 关键点总结

1. 贪心：排序后相邻三个一组，是使组内差最小的最优策略
2. 检查每组首尾差是否 <= k
3. 若任意一组不满足，整体无解

## 易错点

1. 分组是连续三个，不是间隔
2. 每组的最大最小差 = sorted_nums[3i+2] - sorted_nums[3i]（已排序，首尾差最大）
3. 返回分组本身而不只是 true/false
