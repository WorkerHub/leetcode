## 题目描述

如果数组中每对相邻元素都具有不同的奇偶性，则数组是 **特殊** 的（即奇偶性交替出现）。

给你一个整数数组 `nums`，如果 `nums` 是特殊数组，则返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：nums = [1]
输出：true
```

**示例 2：**
```
输入：nums = [2,1,4]
输出：false（2 偶，1 奇，4 偶 -> 2 和 1 相邻奇偶不同，但 1 和 4 相邻奇偶不同，所以 true？等等 2,1,4: 2%2=0,1%2=1,4%2=0，相邻对 (2,1) 不同，(1,4) 不同，所以 true）
实际示例：[2,1,4] 应该返回 true，[4,3,1,6] 返回 false（3 和 1 都是奇数）
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

遍历数组，检查每对相邻元素的奇偶性是否不同。

## Python 代码实现

### 方法一：遍历检查（推荐）

```python
from typing import List

class Solution:
    def isArraySpecial(self, nums: List[int]) -> bool:
        for i in range(1, len(nums)):
            if nums[i] % 2 == nums[i - 1] % 2:
                return False  # 相邻元素奇偶性相同
        return True
```

### 方法二：使用 all

```python
from typing import List

class Solution:
    def isArraySpecial(self, nums: List[int]) -> bool:
        return all(
            nums[i] % 2 != nums[i - 1] % 2
            for i in range(1, len(nums))
        )
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 奇偶性用 `x % 2` 判断
2. 相邻元素奇偶性不同：`nums[i] % 2 != nums[i-1] % 2`
3. 等价于 `nums[i] % 2 + nums[i-1] % 2 == 1`（一奇一偶）

## 易错点

1. 长度为 1 的数组视为特殊数组（没有相邻对）
2. 奇偶性不同 = 两者 XOR 为 1
