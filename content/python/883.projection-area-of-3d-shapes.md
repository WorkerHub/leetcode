## 题目描述

在 n x n 的网格 grid 中，我们放置了一些与 x，y，z 三轴对齐的 1 x 1 x 1 立方体。

每个值 v = grid[i][j] 表示 v 个正方体叠放在对应单元格 (i, j) 上。

返回结果形状在 xy 、yz 和 zx 平面上的投影的总面积。

**提示：**
- n == grid.length == grid[i].length
- 1 <= n <= 50
- 0 <= grid[i][j] <= 50

## 解题思路

分别计算三个方向的投影面积：
- **xy 平面**：从上往下看，grid[i][j] > 0 的格子数
- **yz 平面**：从前往后看，每行的最大值之和
- **zx 平面**：从左往右看，每列的最大值之和

## Python 代码实现

```python
class Solution:
    def projectionArea(self, grid: List[List[int]]) -> int:
        n = len(grid)
        
        # xy 平面：非零格子数
        xy = sum(1 for i in range(n) for j in range(n) if grid[i][j] > 0)
        
        # yz 平面：每行最大值
        yz = sum(max(row) for row in grid)
        
        # zx 平面：每列最大值
        zx = sum(max(grid[i][j] for i in range(n)) for j in range(n))
        
        return xy + yz + zx
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **三个投影**：分别计算
2. **xy平面**：计数非零
3. **yz/zx平面**：行列最大值
