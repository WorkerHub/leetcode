## 题目描述

给你一个整数数组 `digits`，返回所有满足以下条件且**升序排列**的三位整数：
1. 使用 `digits` 中的三个元素（每个下标最多使用一次）
2. 不含前导零（百位不为 0）
3. 是偶数（个位为偶数）

**示例：**
```
输入：digits = [2,1,3,0]
输出：[102,120,130,132,210,230,302,310,312,320]
```

**提示：**
- `3 <= digits.length <= 100`
- `0 <= digits[i] <= 9`

## 解题思路

**枚举三位数 + 验证可行性：**

枚举所有三位偶数（100 到 998，步长 2），对每个数验证其各位数字是否可以从 `digits` 中选出。

用 `Counter(digits)` 与三位数各位的 `Counter` 比较（是否可以组成）。

**另一种思路：** 枚举三个位置的数字（百位 1-9，十位 0-9，个位 0,2,4,6,8），检查计数是否够用。

## 代码实现

### 方法一：枚举三位偶数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findEvenNumbers(self, digits: List[int]) -> List[int]:
        cnt = Counter(digits)
        result = []

        for num in range(100, 999, 2):  # 三位偶数
            # 检查 num 的每一位是否在 digits 中有足够数量
            num_cnt = Counter([num // 100, (num // 10) % 10, num % 10])
            # 判断 num_cnt 是否是 cnt 的子集（计数）
            if all(num_cnt[d] <= cnt[d] for d in num_cnt):
                result.append(num)

        return result
```

### 方法二：枚举三个数字

```python
from typing import List
from collections import Counter

class Solution:
    def findEvenNumbers(self, digits: List[int]) -> List[int]:
        cnt = Counter(digits)
        result = set()

        for a in range(1, 10):       # 百位
            for b in range(0, 10):   # 十位
                for c in range(0, 10, 2):  # 个位（偶数）
                    need = Counter([a, b, c])
                    if all(need[d] <= cnt[d] for d in need):
                        result.add(a * 100 + b * 10 + c)

        return sorted(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举三位偶数 | O(450) ≈ O(1) | O(1) |
| 枚举三数字 | O(9 * 10 * 5) = O(450) | O(1) |

实际上两种方法都是 O(1)，因为枚举范围固定（不超过 500 个数）。

## 关键点总结

1. 三位偶数范围：100 到 998，共约 450 个
2. 用 Counter 判断 digits 中是否有足够的数字
3. 枚举范围固定，不受 digits 长度影响

## 易错点

- 百位不能为 0（三位数限制）
- 个位必须是偶数（0, 2, 4, 6, 8）
- 同一个 digits 下标最多使用一次（用 Counter 计数控制）
