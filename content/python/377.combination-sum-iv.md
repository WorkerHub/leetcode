## 题目描述

给你一个由不同整数组成的数组 `nums`，和一个目标整数 `target`。请你从 `nums` 中找出并返回总和为 `target` 的元素组合的个数。

题目数据保证答案符合 32 位整数范围。

注意：顺序不同的序列被视为不同的组合。

**示例 1：**

```
输入：nums = [1,2,3], target = 4
输出：7
解释：
所有可能的组合为：
(1, 1, 1, 1)
(1, 1, 2)
(1, 2, 1)
(1, 3)
(2, 1, 1)
(2, 2)
(3, 1)
请注意，顺序不同的序列被视为不同的组合
```

**示例 2：**

```
输入：nums = [9], target = 3
输出：0
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 1000`
- `nums` 中的所有元素互不相同
- `1 <= target <= 1000`

**进阶：**
如果给定的数组中含有负数会发生什么？问题会产生何种变化？如果允许负数出现，需要向题目中添加哪些限制条件？

## 解题思路

这道题乍一看像"组合总和"系列，但关键区别是：**顺序不同算不同的组合**。

因此，这实际上是一个**排列**问题，而不是组合问题。

### 核心思想

这是一个经典的**完全背包**问题的变体。

**状态定义**：
- `dp[i]` 表示和为 `i` 的组合数

**状态转移**：
对于每个和 `i`，遍历 `nums` 中的每个数 `num`：
- 如果 `i >= num`，则可以选择 `num`
- `dp[i] += dp[i - num]`

**初始化**：
- `dp[0] = 1`（和为 0 的方法数是 1，即不选任何数）

**遍历顺序**：
- 外层循环：目标和 `i`
- 内层循环：数组 `nums`
- 这样保证了排列（顺序敏感）

### 与组合的区别

如果是组合（顺序无关），遍历顺序应该是：
- 外层循环：`nums`
- 内层循环：目标和 `i`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        """
        动态规划（完全背包 + 排列）
        时间复杂度：O(target * n)
        空间复杂度：O(target)
        """
        # dp[i] 表示和为 i 的组合数
        dp = [0] * (target + 1)
        dp[0] = 1  # 和为 0 的方法数是 1
        
        # 外层循环：目标和（保证顺序敏感，即排列）
        for i in range(1, target + 1):
            # 内层循环：遍历每个数字
            for num in nums:
                if i >= num:
                    dp[i] += dp[i - num]
        
        return dp[target]
```

### 方法二：记忆化搜索（递归）

```python
from typing import List

class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        """
        记忆化搜索（自顶向下）
        时间复杂度：O(target * n)
        空间复杂度：O(target)
        """
        memo = {}
        
        def dfs(remain: int) -> int:
            """
            返回和为 remain 的组合数
            """
            if remain == 0:
                return 1
            
            if remain < 0:
                return 0
            
            if remain in memo:
                return memo[remain]
            
            count = 0
            for num in nums:
                count += dfs(remain - num)
            
            memo[remain] = count
            return count
        
        return dfs(target)
```

### 方法三：带剪枝的记忆化搜索

```python
from typing import List

class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        """
        优化：先排序，提前剪枝
        """
        nums.sort()
        memo = {}
        
        def dfs(remain: int) -> int:
            if remain == 0:
                return 1
            
            if remain in memo:
                return memo[remain]
            
            count = 0
            for num in nums:
                if num > remain:
                    break  # 剪枝：后面的数更大，无需继续
                count += dfs(remain - num)
            
            memo[remain] = count
            return count
        
        return dfs(target)
```

## 复杂度分析

### 方法一：动态规划
- 时间复杂度：O(target × n)，n 为数组长度
- 空间复杂度：O(target)

### 方法二：记忆化搜索
- 时间复杂度：O(target × n)
- 空间复杂度：O(target)，递归栈 + 缓存

## 关键点总结

1. **排列 vs 组合**：
   - 排列（本题）：外层循环目标和，内层循环数组
   - 组合：外层循环数组，内层循环目标和
2. **完全背包**：每个数字可以使用无限次
3. **状态转移**：`dp[i] += dp[i - num]`
4. **初始化**：`dp[0] = 1`
5. **遍历顺序**：决定了是排列还是组合

## 易错点

1. **遍历顺序错误**：如果外层循环 `nums`，内层循环 `target`，会得到组合数而不是排列数
2. **初始化**：忘记 `dp[0] = 1`
3. **边界检查**：`i >= num` 才能转移
4. **整数溢出**：题目说答案在 32 位范围内，Python 无此问题
5. **负数问题**：进阶问题中，如果有负数会导致无限循环

dp[0] = 1

dp[1]:

  选 2: dp[3] += dp[1] = 1

  选 1: dp[4] += dp[3] = 4
  选 2: dp[4] += dp[2] = 2
  选 3: dp[4] += dp[1] = 1
  dp[4] = 7  # 方案：(1,1,1,1), (1,1,2), (1,2,1), (1,3), (2,1,1), (2,2), (3,1)

## 学习建议

1. **理解排列和组合的区别**：
   - 排列：[1,2] 和 [2,1] 不同
   - 组合：[1,2] 和 [2,1] 相同
2. **掌握遍历顺序**：
   ```python
   # 排列（顺序敏感）
   for i in range(target + 1):
       for num in nums:
           dp[i] += dp[i - num]
   
   # 组合（顺序无关）
   for num in nums:
       for i in range(num, target + 1):
           dp[i] += dp[i - num]
   ```
3. **对比相关题目**：
   - 377（本题）：排列，可重复
   - 39：组合，可重复
   - 518：组合，硬币问题
4. **进阶思考（负数问题）**：
   - 如果有负数，可能形成无限循环
   - 需要限制组合的长度
   - 或者限制每个数使用的次数
5. **背包问题总结**：
   - 0-1 背包：每个物品只能用一次
   - 完全背包：每个物品可以用无限次
   - 本题：完全背包 + 排列
