## 题目描述

复数可以用字符串表示，形式为 `"实部+虚部i"`，其中：

- `实部` 是一个整数，范围为 `[-100, 100]`
- `虚部` 是一个整数，范围为 `[-100, 100]`
- `i² = -1`

给定两个字符串形式的复数 `num1` 和 `num2`，返回它们相乘的结果（字符串形式）。

**示例 1：**
```
输入: num1 = "1+1i", num2 = "1+1i"
输出: "0+2i"
解释: (1 + i) * (1 + i) = 1 + i² + 2i = 1 - 1 + 2i = 0 + 2i
```

**示例 2：**
```
输入: num1 = "1+-1i", num2 = "1+-1i"
输出: "0+-2i"
解释: (1 - i) * (1 - i) = 1 + i² - 2i = 1 - 1 - 2i = 0 - 2i
      需要返回 "0+-2i" 格式
```

**提示：**
- `num1` 和 `num2` 都是有效的复数

## 解题思路

这道题考察复数乘法的基本运算和字符串解析。

**复数乘法公式：**

对于两个复数 `(a₁ + b₁i)` 和 `(a₂ + b₂i)`，它们的乘积为：

```
(a₁ + b₁i) × (a₂ + b₂i)
= a₁a₂ + a₁b₂i + b₁a₂i + b₁b₂i²
= a₁a₂ + (a₁b₂ + b₁a₂)i + b₁b₂(-1)    (因为 i² = -1)
= (a₁a₂ - b₁b₂) + (a₁b₂ + b₁a₂)i
```

**关键公式：**
- **实部** = `a₁ × a₂ - b₁ × b₂`
- **虚部** = `a₁ × b₂ + a₂ × b₁`

**算法流程：**

1. 解析第一个复数字符串，提取实部 `a₁` 和虚部 `b₁`
2. 解析第二个复数字符串，提取实部 `a₂` 和虚部 `b₂`
3. 使用复数乘法公式计算结果的实部和虚部
4. 格式化为字符串 `"实部+虚部i"` 返回

**字符串解析技巧：**

对于字符串 `"1+1i"`：
- 去掉末尾的 `'i'`：`"1+1"`
- 按 `'+'` 分割：`["1", "1"]`
- 转换为整数：`1` 和 `1`

注意处理负数情况，如 `"1+-1i"` 分割后是 `["1", "-1"]`。

## Python 代码实现

### 方法一：字符串解析 + 公式计算（推荐）

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        """
        解析复数字符串并使用数学公式计算乘积
        时间复杂度 O(1)，空间复杂度 O(1)
        """
        # 解析第一个复数：去掉末尾的 'i'，然后按 '+' 分割
        a1, b1 = map(int, num1[:-1].split('+'))
        
        # 解析第二个复数
        a2, b2 = map(int, num2[:-1].split('+'))
        
        # 复数乘法公式
        # 实部 = a1 * a2 - b1 * b2
        # 虚部 = a1 * b2 + a2 * b1
        real = a1 * a2 - b1 * b2
        imag = a1 * b2 + a2 * b1
        
        # 格式化返回
        return f"{real}+{imag}i"
```

### 方法二：一行式写法（Python 特色）

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        """
        使用 Python f-string 和列表推导式简化代码
        """
        a1, b1 = map(int, num1[:-1].split('+'))
        a2, b2 = map(int, num2[:-1].split('+'))
        return f"{a1 * a2 - b1 * b2}+{a1 * b2 + a2 * b1}i"
```

### 方法三：使用正则表达式解析

```python
import re

class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        """
        使用正则表达式解析复数
        更健壮，可以处理各种格式
        """
        # 正则表达式匹配 "a+bi" 格式
        pattern = r'([+-]?\d+)\+([+-]?\d+)i'
        
        # 解析第一个复数
        match1 = re.match(pattern, num1)
        a1, b1 = int(match1.group(1)), int(match1.group(2))
        
        # 解析第二个复数
        match2 = re.match(pattern, num2)
        a2, b2 = int(match2.group(1)), int(match2.group(2))
        
        # 计算乘积
        real = a1 * a2 - b1 * b2
        imag = a1 * b2 + a2 * b1
        
        return f"{real}+{imag}i"
```

### 方法四：详细注释版（适合初学者）

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        """
        最详细的实现，包含每个步骤的解释
        """
        # 步骤 1: 解析第一个复数字符串
        # 示例: "1+1i" -> 去掉 'i' -> "1+1" -> 分割 -> ["1", "1"]
        num1_without_i = num1[:-1]  # 去掉末尾的 'i'
        parts1 = num1_without_i.split('+')  # 按 '+' 分割
        a1 = int(parts1[0])  # 实部
        b1 = int(parts1[1])  # 虚部
        
        # 步骤 2: 解析第二个复数字符串
        num2_without_i = num2[:-1]
        parts2 = num2_without_i.split('+')
        a2 = int(parts2[0])
        b2 = int(parts2[1])
        
        # 步骤 3: 使用复数乘法公式计算
        # (a1 + b1i) * (a2 + b2i) = (a1*a2 - b1*b2) + (a1*b2 + a2*b1)i
        
        # 计算实部
        real_part = a1 * a2 - b1 * b2
        
        # 计算虚部
        imaginary_part = a1 * b2 + a2 * b1
        
        # 步骤 4: 格式化为字符串返回
        # 使用 f-string 格式化
        result = f"{real_part}+{imaginary_part}i"
        
        return result
```

### 方法五：使用 Python 复数类型

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        """
        利用 Python 内置的复数类型
        将字符串转换为复数，计算后再转回字符串
        """
        # 将 "a+bi" 转换为 Python 复数 (a+bj)
        # 注意：Python 使用 'j' 表示虚数单位
        c1 = complex(num1.replace('i', 'j'))
        c2 = complex(num2.replace('i', 'j'))
        
        # 复数乘法
        result = c1 * c2
        
        # 转换回字符串格式
        # 提取实部和虚部（转为整数）
        real = int(result.real)
        imag = int(result.imag)
        
        return f"{real}+{imag}i"
```

## 关键点总结

1. **复数乘法公式记忆**：实部 = `a₁a₂ - b₁b₂`，虚部 = `a₁b₂ + a₂b₁`
2. **字符串解析技巧**：先去掉 `'i'`，再按 `'+'` 分割
3. **处理负数**：`"1+-1i"` 分割后自动得到 `["1", "-1"]`，无需特殊处理
4. **格式化输出**：使用 f-string 简化字符串拼接
5. **i² = -1 的应用**：这是虚数单位的定义，乘法公式的核心

## 易错点

1. **忘记去掉末尾的 'i'**
   ```python
   # 错误：直接分割包含 'i' 的字符串
   parts = num1.split('+')  # ["1", "1i"] - 错误
   
   # 正确：先去掉 'i'
   parts = num1[:-1].split('+')  # ["1", "1"] - 正确
   ```

2. **复数乘法公式错误**
   ```python
   # 错误：忘记 i² = -1
   real = a1 * a2  # 错误
   
   # 正确：应用 i² = -1
   real = a1 * a2 - b1 * b2  # 正确
   ```

3. **负数处理**
   ```python
   # 示例: "1+-1i"
   # 正确的分割结果是 ["1", "-1"]
   a, b = map(int, "1+-1i"[:-1].split('+'))  # a=1, b=-1
   
   # 不需要特殊处理负号，split('+') 已经正确处理
   ```

4. **输出格式错误**
   ```python
   # 错误：缺少 'i'
   return f"{real}+{imag}"  # 错误
   
   # 正确：包含 'i'
   return f"{real}+{imag}i"  # 正确
   
   # 注意：即使虚部是负数也要保持 '+' 号
   # "0+-2i" 是正确格式，不是 "0-2i"
   ```

5. **整数类型转换**
   ```python
   # 使用 Python 复数类型时，记得转换为整数
   result = c1 * c2
   # 错误：直接使用浮点数
   return f"{result.real}+{result.imag}i"  # 可能输出 "0.0+2.0i"
   
   # 正确：转换为整数
   return f"{int(result.real)}+{int(result.imag)}i"  # "0+2i"
   ```

1. **复习复数基础知识**：
   - 复数的定义：`z = a + bi`
   - 虚数单位：`i² = -1`
   - 复数加法：`(a₁ + b₁i) + (a₂ + b₂i) = (a₁ + a₂) + (b₁ + b₂)i`
   - 复数乘法：使用本题的公式

2. **掌握字符串解析技巧**：
   ```python
   # 技巧 1: 去掉特定字符
   s = "1+1i"
   s_without_i = s[:-1]  # "1+1"
   
   # 技巧 2: 分割字符串
   parts = s_without_i.split('+')  # ["1", "1"]
   
   # 技巧 3: 批量转换类型
   a, b = map(int, parts)  # a=1, b=1
   
   # 组合技巧：一行完成
   a, b = map(int, "1+1i"[:-1].split('+'))
   ```

3. **理解数学公式的推导**：
   ```
   (a₁ + b₁i) × (a₂ + b₂i)
   = a₁a₂ + a₁b₂i + b₁a₂i + b₁b₂i²  (展开)
   = a₁a₂ + a₁b₂i + b₁a₂i - b₁b₂    (i² = -1)
   = (a₁a₂ - b₁b₂) + (a₁b₂ + b₁a₂)i (合并同类项)
   ```

4. **练习 Python f-string 格式化**：
   ```python
   real, imag = 0, 2

   # 处理负数
   real, imag = 0, -2
   result = f"{real}+{imag}i"  # "0+-2i" (正确)
   ```
