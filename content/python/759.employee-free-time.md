## 题目描述

给定一个员工的工作时间表列表 `schedule`，表示每个员工的工作时间。

每个员工都有一个非重叠的时间段列表 `Intervals`，这些时间段已经排好序。

返回所有员工的共同空闲时间的有限区间列表，同样需要排好序。

**示例 1:**
```
输入: schedule = [[[1,2],[5,6]],[[1,3]],[[4,10]]]
输出: [[3,4]]
解释:
共有三个员工，他们各自的工作时间是:
员工 1: [1,2], [5,6]
员工 2: [1,3]
员工 3: [4,10]
共同的空闲时间是 [3,4]
```

**示例 2:**
```
输入: schedule = [[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]
输出: [[5,6],[7,9]]
```

**提示:**
- `1 <= schedule.length <= 50`
- `1 <= schedule[i].length <= 50`
- `0 <= schedule[i][j].start < schedule[i][j].end <= 10^8`

## 解题思路

这道题的关键是找到所有员工都空闲的时间段，也就是所有工作时间段之间的间隙。

**核心思想：**
1. 将所有员工的工作时间段合并到一起
2. 按开始时间排序
3. 合并重叠的时间段
4. 找出合并后相邻时间段之间的间隙

**算法流程：**
1. 收集所有时间段并排序
2. 合并重叠的时间段
3. 输出相邻时间段之间的空隙

## Python 代码实现

### 方法一：扁平化 + 区间合并（推荐）⭐

```python
from typing import List

# Definition for an Interval.
class Interval:
    def __init__(self, start: int = None, end: int = None):
        self.start = start
        self.end = end

class Solution:
    def employeeFreeTime(self, schedule: List[List[Interval]]) -> List[Interval]:
        # 将所有时间段扁平化
        intervals = []
        for employee in schedule:
            for interval in employee:
                intervals.append(interval)
        
        # 按开始时间排序
        intervals.sort(key=lambda x: x.start)
        
        # 合并重叠的时间段
        merged = [intervals[0]]
        for interval in intervals[1:]:
            if interval.start <= merged[-1].end:
                # 重叠，合并
                merged[-1].end = max(merged[-1].end, interval.end)
            else:
                # 不重叠，添加新区间
                merged.append(interval)
        
        # 找出空闲时间（相邻区间之间的间隙）
        result = []
        for i in range(len(merged) - 1):
            result.append(Interval(merged[i].end, merged[i + 1].start))
        
        return result
```

### 方法二：使用堆（优先队列）

```python
import heapq

class Solution:
    def employeeFreeTime(self, schedule: List[List[Interval]]) -> List[Interval]:
        # 使用最小堆，存储 (开始时间, 结束时间)
        heap = []
        for employee in schedule:
            for interval in employee:
                heapq.heappush(heap, (interval.start, interval.end))
        
        result = []
        _, prev_end = heapq.heappop(heap)
        
        while heap:
            start, end = heapq.heappop(heap)
            if start > prev_end:
                # 发现空闲时间
                result.append(Interval(prev_end, start))
                prev_end = end
            else:
                # 重叠，更新结束时间
                prev_end = max(prev_end, end)
        
        return result
```

### 方法三：事件扫描线

```python
class Solution:
    def employeeFreeTime(self, schedule: List[List[Interval]]) -> List[Interval]:
        # 创建事件列表：(时间, 类型) 
        # 类型：1 表示开始，-1 表示结束
        events = []
        for employee in schedule:
            for interval in employee:
                events.append((interval.start, 1))
                events.append((interval.end, -1))
        
        # 排序：时间相同时，结束事件在开始事件之前
        events.sort(key=lambda x: (x[0], x[1]))
        
        result = []
        count = 0
        prev_time = -1
        
        for time, event_type in events:
            if count == 0 and prev_time != -1 and prev_time < time:
                # 所有人都空闲
                result.append(Interval(prev_time, time))
            
            count += event_type
            if count == 0:
                prev_time = time
        
        return result
```

### 方法四：详细注释版（易理解）

```python
class Solution:
    def employeeFreeTime(self, schedule: List[List[Interval]]) -> List[Interval]:
        """
        找出所有员工的共同空闲时间
        
        思路：
        1. 收集所有工作时间段
        2. 合并重叠的时间段
        3. 空闲时间就是合并后相邻时间段之间的间隙
        """
        # 步骤 1: 收集所有工作时间段
        all_intervals = []
        for employee_schedule in schedule:
            for work_interval in employee_schedule:
                all_intervals.append(work_interval)
        
        # 步骤 2: 按开始时间排序
        all_intervals.sort(key=lambda interval: interval.start)
        
        # 步骤 3: 合并重叠的时间段
        # 初始化合并列表，放入第一个时间段
        merged_intervals = [all_intervals[0]]
        
        for current_interval in all_intervals[1:]:
            last_merged = merged_intervals[-1]
            
            # 检查当前时间段是否与最后一个合并的时间段重叠
            if current_interval.start <= last_merged.end:
                # 重叠，合并它们
                # 更新结束时间为两者中较大的
                last_merged.end = max(last_merged.end, current_interval.end)
            else:
                # 不重叠，添加为新的时间段
                merged_intervals.append(current_interval)
        
        # 步骤 4: 找出空闲时间
        # 空闲时间是相邻工作时间段之间的间隙
        free_time = []
        
        for i in range(len(merged_intervals) - 1):
            # 当前工作时间段的结束时间
            free_start = merged_intervals[i].end
            # 下一个工作时间段的开始时间
            free_end = merged_intervals[i + 1].start
            
            # 如果有间隙，就是空闲时间
            free_time.append(Interval(free_start, free_end))
        
        return free_time
```

### 方法五：一次遍历版本

```python
class Solution:
    def employeeFreeTime(self, schedule: List[List[Interval]]) -> List[Interval]:
        # 收集并排序所有区间
        times = sorted([interval for employee in schedule for interval in employee], 
                      key=lambda x: x.start)
        
        result = []
        end = times[0].end
        
        for interval in times[1:]:
            if interval.start > end:
                # 找到空闲时间
                result.append(Interval(end, interval.start))
                end = interval.end
            else:
                # 更新结束时间
                end = max(end, interval.end)
        
        return result
```

## 复杂度分析

**方法一：扁平化 + 区间合并**
- **时间复杂度：** O(N log N)，其中 N 是所有时间段的总数，主要是排序的时间
- **空间复杂度：** O(N)，存储所有时间段

**方法二：堆**
- **时间复杂度：** O(N log N)，堆操作
- **空间复杂度：** O(N)

**方法三：扫描线**
- **时间复杂度：** O(N log N)，排序事件
- **空间复杂度：** O(N)，存储事件

## 关键点总结

1. **问题转化：** 将问题转化为区间合并问题
2. **扁平化：** 将所有员工的时间段合并到一起处理
3. **排序：** 按开始时间排序是关键
4. **区间合并：** 合并重叠的工作时间段
5. **空隙查找：** 合并后的相邻时间段之间的间隙就是空闲时间

## 易错点

1. **排序遗漏：** 忘记排序会导致结果错误
2. **合并逻辑：** 合并条件是 `start <= prev_end`，不是 `<`
3. **更新结束时间：** 合并时要取较大的结束时间
4. **边界情况：** 只有一个合并区间时，没有空闲时间
5. **数据结构：** 注意 Interval 类的定义和使用
