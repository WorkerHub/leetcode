## 题目描述

给你一个整数数组 `nums` 和整数 `maximumBit`，对每个查询（共 `n` 个），你需要找到最优的非负整数 `k`（满足 `k < 2^maximumBit`），使得 `nums` 中所有元素与 `k` 的异或最大，然后移除 `nums` 的最后一个元素。

返回每次查询的最优 `k` 值列表。

**示例 1：**

```
输入：nums = [0,1,1,3], maximumBit = 2
输出：[0,3,2,3]
解释：
查询1：nums=[0,1,1,3], XOR=3, k=0（3^0=3最大）
查询2：nums=[0,1,1], XOR=0, k=3（0^3=3最大）
...
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= maximumBit <= 20`
- `0 <= nums[i] < 2^maximumBit`

## 解题思路

维护前缀异或值：`xor_all = nums[0] ^ nums[1] ^ ... ^ nums[i]`。

对每次查询，最优 `k = xor_all ^ ((1 << maximumBit) - 1)`（与全 1 异或，最大化结果）。

每次查询后移除最后一个元素，等价于 `xor_all ^= nums[-1]`。

## Python 代码实现

### 方法一：前缀异或（推荐）

```python
from typing import List

class Solution:
    def getMaximumXor(self, nums: List[int], maximumBit: int) -> List[int]:
        mask = (1 << maximumBit) - 1  # 全 1 掩码
        xor_all = 0
        for x in nums:
            xor_all ^= x

        result = []
        for i in range(len(nums) - 1, -1, -1):
            # 最优 k 使得 xor_all ^ k 最大，即 k = xor_all ^ mask
            result.append(xor_all ^ mask)
            xor_all ^= nums[i]  # 移除 nums[i]

        return result
```

### 方法二：前向计算再反转

```python
from typing import List

class Solution:
    def getMaximumXor(self, nums: List[int], maximumBit: int) -> List[int]:
        mask = (1 << maximumBit) - 1
        prefix_xor = [0]
        for x in nums:
            prefix_xor.append(prefix_xor[-1] ^ x)

        result = []
        for i in range(len(nums), 0, -1):
            result.append(prefix_xor[i] ^ mask)

        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 维护运行异或值，移除元素时再次异或（异或的逆操作是自身）
2. 最优 k = 当前总异或 ^ 全 1 掩码
3. 逆序输出：从后往前处理

## 易错点

1. 移除元素时 `xor_all ^= nums[i]`（异或自身抵消）
2. 掩码 `(1 << maximumBit) - 1` 确保 k 在范围内
3. 返回结果顺序：第一个元素对应最多元素时的查询
