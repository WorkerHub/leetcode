## 题目描述

给你一个长度为 `n` 的二维整数数组 `groups`，同时给你一个整数数组 `nums`。

你是否可以从 `nums` 中选出 `n` 个**不相交**的子数组，使得第 `i` 个子数组与 `groups[i]`（从左到右）完全相同，且如果 `i > 0`，第 `i` 个子数组在 `nums` 中出现的**位置在第 `i - 1` 个子数组后面**？

如果可以，返回 `true`；否则，返回 `false`。

**示例：**
```
输入：groups = [[1,-1,-1],[3,-2,0]], nums = [1,-1,0,1,-1,-1,3,-2,0]
输出：true
```

**提示：**
- `groups.length == n`
- `1 <= n <= 10^3`
- `1 <= groups[i].length, sum(groups[i].length) <= 10^3`
- `1 <= nums.length <= 10^3`

## 解题思路

贪心：对每个 `group`，在 `nums` 中从当前位置开始找第一个匹配的子数组，找到后更新起始位置继续下一个 `group`。

## 代码实现

### 方法一：贪心 + 线性匹配（推荐）

```python
from typing import List

class Solution:
    def canChoose(self, groups: List[List[int]], nums: List[int]) -> bool:
        start = 0  # 当前搜索起始位置
        
        for group in groups:
            g_len = len(group)
            found = False
            
            # 从 start 开始在 nums 中查找 group
            for i in range(start, len(nums) - g_len + 1):
                if nums[i:i + g_len] == group:
                    start = i + g_len  # 下一个 group 从此位置后开始
                    found = True
                    break
            
            if not found:
                return False
        
        return True
```

### 方法二：使用 KMP 加速匹配

```python
from typing import List

class Solution:
    def canChoose(self, groups: List[List[int]], nums: List[int]) -> bool:
        def kmp_search(text, pattern):
            """返回 pattern 在 text 中第一次出现的起始下标，未找到返回 -1"""
            n, m = len(text), len(pattern)
            if m == 0:
                return 0
            
            # 构建失败函数
            fail = [0] * m
            j = 0
            for i in range(1, m):
                while j > 0 and pattern[i] != pattern[j]:
                    j = fail[j - 1]
                if pattern[i] == pattern[j]:
                    j += 1
                fail[i] = j
            
            # KMP 搜索
            j = 0
            for i in range(n):
                while j > 0 and text[i] != pattern[j]:
                    j = fail[j - 1]
                if text[i] == pattern[j]:
                    j += 1
                if j == m:
                    return i - m + 1
            
            return -1
        
        start = 0
        for group in groups:
            idx = kmp_search(nums[start:], group)
            if idx == -1:
                return False
            start += idx + len(group)
        
        return True
```

## 复杂度分析

- **方法一**：时间 O(n * m)（n 是 nums 长度，m 是 groups 总长度），本题约束内足够
- **方法二**：时间 O(n + m)，KMP 线性

## 关键点总结

1. 贪心：每个 group 尽量找最左边的匹配（使后续有更多空间）
2. 找到匹配后，下一个搜索从匹配结束位置之后开始
3. 子数组不相交且有序

## 易错点

- 子数组不能重叠，所以下一次从 `i + len(group)` 开始
- 贪心选最左边的匹配是最优的
