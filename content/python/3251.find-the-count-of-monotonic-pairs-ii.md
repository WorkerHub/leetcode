## 题目描述

与 3250 相同的问题，但数据范围更大：
- `1 <= n <= 2000`
- `1 <= nums[i] <= 1000`

## 解题思路

与 3250 解法相同，只是 max_val 更大（1000）。

使用 DP + 前缀和：`dp[y]` 表示 `arr1[i] = y` 的方案数，通过前缀和 O(1) 计算每次转移。

总时间复杂度 O(n * max_val)，其中 max_val = 1000，n = 2000，共 2 * 10^6 操作，可以接受。

## Python 代码实现

### 方法一：DP + 前缀和（推荐）

```python
from typing import List

class Solution:
    def countOfPairs(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        max_val = max(nums)
        
        # dp[y] = arr1[i] = y 的方案数
        dp = [0] * (max_val + 1)
        for y in range(nums[0] + 1):
            dp[y] = 1
        
        for i in range(1, n):
            diff = nums[i] - nums[i - 1]
            
            # 前缀和
            prefix = [0] * (max_val + 2)
            for x in range(max_val + 1):
                prefix[x + 1] = (prefix[x] + dp[x]) % MOD
            
            new_dp = [0] * (max_val + 1)
            for y in range(nums[i] + 1):
                # x 的有效范围：max(0, y - diff) <= x <= min(y, nums[i-1])
                lo = max(0, y - diff)
                hi = min(y, nums[i - 1])
                if lo > hi:
                    new_dp[y] = 0
                else:
                    new_dp[y] = (prefix[hi + 1] - prefix[lo] + MOD) % MOD
            
            dp = new_dp
        
        return sum(dp) % MOD
```

### 方法二：组合数学优化

```python
from typing import List

class Solution:
    def countOfPairs(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        
        # 关键公式推导：
        # 差值 d[i] = arr1[i] - arr1[i-1] >= 0
        # 约束：d[i] <= nums[i] - nums[i-1]（当差 >= 0）
        # 若 nums[i] < nums[i-1]，则需要 d[i] <= nums[i] - nums[i-1] < 0，无法满足非负性
        
        # 等价转化：令 b[i] = arr1[i] - sum(max(0, nums[j]-nums[j-1]) for j<=i)
        # 变换后可以用插板法计算...
        
        # 实际上，最终答案等于 C(sum(max(0, d_i)) + n, n) 的某种变体
        # 但需要仔细推导，这里使用 DP 方法
        
        max_val = max(nums)
        dp = [0] * (max_val + 1)
        for y in range(nums[0] + 1):
            dp[y] = 1
        
        for i in range(1, n):
            diff = nums[i] - nums[i - 1]
            prefix = [0] * (max_val + 2)
            for x in range(max_val + 1):
                prefix[x + 1] = (prefix[x] + dp[x]) % MOD
            
            new_dp = [0] * (max_val + 1)
            for y in range(nums[i] + 1):
                lo = max(0, y - diff)
                hi = min(y, nums[i - 1])
                if lo <= hi:
                    new_dp[y] = (prefix[hi + 1] - prefix[lo] + MOD) % MOD
            
            dp = new_dp
        
        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n * max_val)，其中 max_val = 1000
- 空间复杂度：O(max_val)

## 关键点总结

1. 与 3250 完全相同的 DP 思路，只是数据范围更大
2. 前缀和将每步的内层循环优化为 O(1)
3. 取模运算防止溢出，注意相减时加 MOD

## 易错点

1. 前缀和相减时可能为负，需要加 MOD
2. diff 可以为负，此时约束变得更紧
