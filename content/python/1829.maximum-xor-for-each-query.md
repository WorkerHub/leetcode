## 题目描述

给你一个**有序**数组 `nums`（升序），和一个非负整数 `maximumBit`。

对数组执行 `n` 次查询，第 `i` 次查询（从 1 开始）中：
- 从当前数组（首次为完整数组，之后每次删除最后一个元素）找一个非负整数 `k < 2^maximumBit`，使得当前所有元素与 `k` 的异或和最大

返回 `n` 次查询得到的 `k` 值数组（按查询顺序）。

**示例 1：**
```
输入：nums = [0,1,1,3], maximumBit = 2
输出：[0,3,2,3]
```

**示例 2：**
```
输入：nums = [2,3,4,7], maximumBit = 3
输出：[5,2,6,5]
```

## 解题思路

**前缀异或 + 贪心**：

1. 计算整个数组的异或值 `xor_all`
2. 每次查询的目标：找 `k` 使得 `xor_all XOR k` 最大，且 `k < 2^maximumBit`
3. 最大化 XOR 的贪心策略：`k = xor_all XOR (2^maximumBit - 1)`，即将 `xor_all` 的低 `maximumBit` 位取反

每次移除最后一个元素时，`xor_all ^= nums[n-1-i]` 即可（i 从 0 开始）。

## 代码实现

### 方法一：前缀异或 + 取反（推荐）

```python
from typing import List

class Solution:
    def getMaximumXor(self, nums: List[int], maximumBit: int) -> List[int]:
        n = len(nums)
        mask = (1 << maximumBit) - 1  # maximumBit 位全 1，如 maximumBit=2 时 mask=3

        # 计算整个数组的异或值
        xor_all = 0
        for x in nums:
            xor_all ^= x

        result = []
        for i in range(n):
            # 最优 k = xor_all 的低 maximumBit 位取反
            k = xor_all ^ mask
            result.append(k)
            # 移除最后一个元素（等价于从后往前处理）
            xor_all ^= nums[n - 1 - i]

        return result
```

### 方法二：后缀异或（从后往前计算）

```python
from typing import List

class Solution:
    def getMaximumXor(self, nums: List[int], maximumBit: int) -> List[int]:
        mask = (1 << maximumBit) - 1
        n = len(nums)
        result = [0] * n

        # 从后往前，逐步计算后缀异或
        xor_suffix = 0
        for i in range(n - 1, -1, -1):
            xor_suffix ^= nums[i]
            result[n - 1 - i] = xor_suffix ^ mask
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. 异或有自反性：`a XOR a = 0`，删除一个元素只需再异或一次该元素
2. 最大化 `xor_all XOR k` 的最优 k：将 xor_all 的低 maximumBit 位全部取反，即 `xor_all XOR mask`
3. mask = `2^maximumBit - 1` = 低 maximumBit 位全为 1 的数

## 易错点

- 结果是按查询顺序（从整个数组到逐步删除末尾），而非从前往后删除
- 每次结果添加后立即更新 xor_all（删除当前末尾元素）
