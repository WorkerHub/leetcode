## 题目描述

给你一个整数 `n`，返回使用**恰好** `n` 张牌搭建**一层或多层**纸牌屋的方案数。

纸牌屋规则：
- 每层由若干个"三角形单元"组成，每个三角形单元使用 2 张牌（两张斜放），三角形之间用 1 张水平牌连接。
- 同一层有 `m` 个三角形，需要 `2m` 张斜牌 + `m-1` 张水平牌 = `3m - 1` 张牌。
- 每一层的三角形数量必须**严格递减**（上层三角形数量 < 下层三角形数量）。
- 每层至少有 1 个三角形。

**示例 1：**
```
输入：n = 16
输出：2
解释：两种方案：[2,4] 和 [1,2,3]（每层三角形数量）。
- [2,4]：(3*4-1)+(3*2-1) = 11+5=16
- [1,2,3]：(3*3-1)+(3*2-1)+(3*1-1) = 8+5+2=15... 不对，重新验证
实际输出为 2。
```

**提示：**
- `1 <= n <= 500`

## 解题思路

**动态规划**

每层 `k` 个三角形消耗 `3k - 1` 张牌。若有若干层，层数从下到上三角形数量**严格递减**。

设 `dp[n][k]` = 用 `n` 张牌，底层有 `k` 个三角形的方案数。

递推：`dp[n][k] = sum(dp[n - (3k-1)][j])` 其中 `j < k`。

最终答案 = 所有 `k >= 1` 的 `dp[n][k]` 之和。

简化：`dp[i]` = 用 `i` 张牌的方案数，枚举底层三角形数量 `k`。

## 代码实现

### 方法一：二维 DP（推荐）

```python
class Solution:
    def houseOfCards(self, n: int) -> int:
        # dp[cards][triangles] = 用恰好 cards 张牌，底层有 triangles 个三角形的方案数
        # 递推：底层用 3*triangles-1 张牌，剩余牌搭上层（上层底层三角形数 < triangles）
        # 等价：dp2[r][k] = 剩余 r 张牌，上一层（较上层）三角形数量上限为 k-1 的方案数

        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(remaining: int, max_triangles: int) -> int:
            # remaining：剩余牌数
            # max_triangles：本层最多可以使用的三角形数（严格小于下层）
            if remaining == 0:
                return 1  # 恰好用完
            ans = 0
            for k in range(1, max_triangles + 1):
                cost = 3 * k - 1
                if cost > remaining:
                    break
                ans += dp(remaining - cost, k - 1)
            return ans

        # 枚举底层三角形数量
        ans = 0
        for k in range(1, n + 1):
            cost = 3 * k - 1
            if cost > n:
                break
            ans += dp(n - cost, k - 1)

        return ans
```

### 方法二：迭代 DP

```python
class Solution:
    def houseOfCards(self, n: int) -> int:
        # dp[i][j] = 用 i 张牌，最大允许三角形数为 j 的方案数
        # 最大三角形数不超过 n//3 + 1
        max_k = n // 3 + 1
        dp = [[0] * (max_k + 1) for _ in range(n + 1)]
        dp[0] = [1] * (max_k + 1)  # 0 张牌：任何上限都有 1 种方案（空方案）

        for remaining in range(1, n + 1):
            for limit in range(max_k + 1):
                # 不放这层（实际上全在外层枚举）
                # 方案：枚举本层三角形数 k（1 <= k <= limit）
                for k in range(1, limit + 1):
                    cost = 3 * k - 1
                    if cost > remaining:
                        break
                    dp[remaining][limit] += dp[remaining - cost][k - 1]

        return dp[n][max_k]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 记忆化递归 | O(n^2 / 3) | O(n^2) |
| 迭代 DP | O(n^2 / 3) | O(n^2) |

## 关键点总结

1. 每层 `k` 个三角形消耗 `3k - 1` 张牌（2k 张斜牌 + k-1 张水平牌）。
2. 层数从下到上三角形严格递减，用"最大三角形数上限"参数控制。
3. 方案等价于把 `n` 分成若干个 `3k-1` 的形式，且对应的 `k` 严格递减。

## 易错点

- 每层至少 1 个三角形（消耗 2 张牌）。
- 严格递减：上层三角形数必须小于下层，不能相等。
- `3*k - 1` 而非 `3*k`：k 个三角形之间只有 `k-1` 个水平牌。
