## 题目描述

给你一个整数数组 `possible`（长度 `n`），其中 `possible[i]` 为 0 或 1。Alice 和 Bob 玩一个关卡游戏：

- 共 `n` 个关卡，`possible[i] = 1` 表示通过第 `i` 关得 1 分，`possible[i] = 0` 表示失去 1 分
- Alice 先选连续的前 `k` 个关卡（k 从 1 到 n-1），Bob 选剩余的关卡
- 返回使 Alice 得分**严格大于** Bob 得分的最小 k

如果不存在，返回 -1。

**示例 1：**
```
输入：possible = [1,0,1,0]
输出：1
```

**示例 2：**
```
输入：possible = [1,1,1,1,1]
输出：3
```

**提示：**
- `2 <= possible.length <= 10^5`
- `possible[i] in {0, 1}`

## 解题思路

预计算前缀和（将 0 转为 -1 计算得分）：
- `alice_score = sum(possible[0..k-1])`（0 计 -1，1 计 +1）
- `bob_score = sum(possible[k..n-1])`
- 条件：`alice_score > bob_score`

用前缀和快速计算两部分的得分，遍历 k 从 1 到 n-1。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def minimumLevels(self, possible: List[int]) -> int:
        n = len(possible)
        # 将 0 转为 -1，计算得分
        scores = [1 if x == 1 else -1 for x in possible]

        total = sum(scores)
        alice = 0

        for k in range(1, n):
            alice += scores[k - 1]
            bob = total - alice
            if alice > bob:
                return k

        return -1
```

### 方法二：直接计算

```python
from typing import List

class Solution:
    def minimumLevels(self, possible: List[int]) -> int:
        n = len(possible)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if possible[i] else -1)

        total = prefix[n]
        for k in range(1, n):
            alice = prefix[k]
            bob = total - alice
            if alice > bob:
                return k

        return -1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一）或 O(n)（方法二）

## 关键点总结

1. 将二值数组转为 (+1/-1) 的得分
2. 枚举分割点 k，用前缀和 O(1) 计算两部分得分
3. 找最小的 k 使 Alice 严格大于 Bob

## 易错点

1. k 的范围是 1 到 n-1（Alice 至少选 1 个，Bob 至少选 1 个）
2. 条件是严格大于（`>`），不是大于等于
