## 题目描述

给定一个单链表的头节点 `head`，其中的元素按升序排序，将其转换为高度平衡的二叉搜索树。

本题中，一个高度平衡二叉树是指一个二叉树每个节点的左右两个子树的高度差不超过 1。

**示例 1：**

```
输入：head = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：一个可能的答案是 [0,-3,9,-10,null,5]，它表示所示的高度平衡二叉搜索树。
```

**示例 2：**

```
输入：head = []
输出：[]
```

**提示：**

- `head` 中的节点数在 `[0, 2 * 10^4]` 范围内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这道题是第 108 题的进阶版，区别在于数据结构从数组换成了链表。链表不支持随机访问，所以不能直接使用索引，需要调整策略。

### 核心思路

**方法一：转换为数组**
- 先遍历链表，将所有值存入数组
- 然后使用第 108 题的方法构建平衡 BST
- 时间 O(n)，空间 O(n)

**方法二：快慢指针找中点**
- 使用快慢指针找到链表的中间节点作为根节点
- 递归地处理左右两半链表
- 时间 O(n log n)，空间 O(log n)

**方法三：中序遍历模拟（最优）**
- 利用 BST 的中序遍历等于有序序列的性质
- 先计算链表长度，确定树的结构
- 按中序遍历的顺序构建树，同时遍历链表
- 时间 O(n)，空间 O(log n)

## Python 代码实现

### 方法一：转换为数组（最简单）⭐

```python
from typing import Optional

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedListToBST(self, head: Optional[ListNode]) -> Optional[TreeNode]:
        # 步骤 1：将链表转换为数组
        values = []
        current = head
        while current:
            values.append(current.val)
            current = current.next
        
        # 步骤 2：使用数组构建平衡 BST
        def buildTree(left: int, right: int) -> Optional[TreeNode]:
            if left > right:
                return None
            
            # 选择中间元素作为根节点
            mid = (left + right) // 2
            root = TreeNode(values[mid])
            
            # 递归构建左右子树
            root.left = buildTree(left, mid - 1)
            root.right = buildTree(mid + 1, right)
            
            return root
        
        return buildTree(0, len(values) - 1)
```

### 方法二：快慢指针找中点

```python
class Solution:
    def sortedListToBST(self, head: Optional[ListNode]) -> Optional[TreeNode]:
        # 边界情况
        if not head:
            return None
        if not head.next:
            return TreeNode(head.val)
        
        # 使用快慢指针找到链表中点
        def findMiddle(left: Optional[ListNode], right: Optional[ListNode]) -> Optional[ListNode]:
            """
            找到链表中点，返回中点节点
            left: 起始节点（包含）
            right: 结束节点（不包含）
            """
            slow = fast = left
            while fast != right and fast.next != right:
                slow = slow.next
                fast = fast.next.next
            return slow
        
        def build(left: Optional[ListNode], right: Optional[ListNode]) -> Optional[TreeNode]:
            """
            构建平衡 BST
            left: 起始节点（包含）
            right: 结束节点（不包含）
            """
            if left == right:
                return None
            
            # 找到中间节点
            mid = findMiddle(left, right)
            
            # 创建根节点
            root = TreeNode(mid.val)
            
            # 递归构建左右子树
            root.left = build(left, mid)
            root.right = build(mid.next, right)
            
            return root
        
        return build(head, None)
```

### 方法三：中序遍历模拟（最优）⭐⭐

```python
class Solution:
    def sortedListToBST(self, head: Optional[ListNode]) -> Optional[TreeNode]:
        # 边界情况
        if not head:
            return None
        
        # 步骤 1：计算链表长度
        length = 0
        current = head
        while current:
            length += 1
            current = current.next
        
        # 使用 nonlocal 变量来维护当前遍历到的链表节点
        self.current = head
        
        def buildTree(left: int, right: int) -> Optional[TreeNode]:
            """
            按中序遍历的顺序构建 BST
            left, right: 当前子树的节点数量范围
            """
            if left > right:
                return None
            
            # 计算中间位置
            mid = (left + right) // 2
            
            # 按照中序遍历的顺序：先构建左子树
            left_child = buildTree(left, mid - 1)
            
            # 创建根节点，并移动链表指针
            root = TreeNode(self.current.val)
            root.left = left_child
            self.current = self.current.next
            
            # 构建右子树
            root.right = buildTree(mid + 1, right)
            
            return root
        
        return buildTree(0, length - 1)
```

### 方法四：递归 + 断链

```python
class Solution:
    def sortedListToBST(self, head: Optional[ListNode]) -> Optional[TreeNode]:
        if not head:
            return None
        
        # 使用快慢指针找中点，同时断开左半部分
        def getMid(head: Optional[ListNode]) -> Optional[ListNode]:
            prev = None
            slow = fast = head
            
            while fast and fast.next:
                prev = slow
                slow = slow.next
                fast = fast.next.next
            
            # 断开左半部分和中间节点
            if prev:
                prev.next = None
            
            return slow
        
        # 找到中间节点
        mid = getMid(head)
        root = TreeNode(mid.val)
        
        # 如果只有一个节点
        if head == mid:
            return root
        
        # 递归构建左右子树
        root.left = self.sortedListToBST(head)
        root.right = self.sortedListToBST(mid.next)
        
        return root
```

## 复杂度分析

### 方法一：转换为数组

- **时间复杂度**：O(n)，遍历链表一次 + 构建树一次
- **空间复杂度**：O(n)，需要额外数组存储所有值

### 方法二：快慢指针

- **时间复杂度**：O(n log n)
  - 每层递归需要 O(n) 时间找中点
  - 递归深度为 O(log n)
- **空间复杂度**：O(log n)，递归调用栈

### 方法三：中序遍历模拟

- **时间复杂度**：O(n)，计算长度 O(n) + 遍历链表一次 O(n)
- **空间复杂度**：O(log n)，递归调用栈

### 方法四：递归 + 断链

- **时间复杂度**：O(n log n)，同方法二
- **空间复杂度**：O(log n)，递归调用栈

## 关键点总结

1. **方法选择**：
   - 简单实现：方法一（转数组）
   - 空间优化：方法二或方法三
   - 时间最优：方法三
2. **快慢指针技巧**：快指针走两步，慢指针走一步，可以找到链表中点
3. **中序遍历妙用**：方法三巧妙利用了 BST 中序遍历的性质
4. **链表特点**：不支持随机访问，需要顺序遍历
5. **空间时间权衡**：方法一用空间换时间，方法三时空都优

## 易错点

1. **快慢指针初始化**：要注意快慢指针的起始位置
2. **边界条件**：空链表、单节点链表要特殊处理
3. **链表断开**：方法四要注意断开链表时不要丢失节点
4. **中序遍历顺序**：方法三要严格按照 左-根-右 的顺序
5. **链表指针移动**：方法三中要确保每个节点恰好被访问一次
