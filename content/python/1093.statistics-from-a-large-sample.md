## 题目描述

给定一个大样本的整数数组，范围在 [0, 255] 内。数组 count 表示样本中每个数字出现的次数，其中 count[k] 是数字 k 在样本中出现的次数。

计算样本的以下统计信息：

- minimum：样本中的最小元素
- maximum：样本中的最大元素
- mean：样本的平均值，计算为所有元素的总和除以元素总数
- median：中位数
  - 如果样本元素个数为奇数，中位数是排序后中间的元素
  - 如果样本元素个数为偶数，中位数是排序后中间两个元素的平均值
- mode：众数，样本中出现次数最多的数字（保证唯一）

返回样本的统计信息 [minimum, maximum, mean, median, mode]。答案与真实答案误差在 10⁻⁵ 以内即可。

- count.length == 256
- 0 <= count[i] <= 10⁹
- 1 <= sum(count) <= 10⁹
- count 的众数是唯一的

## 解题思路

这道题的核心是理解 count 数组的含义：count[i] 表示数字 i 出现的次数。我们需要根据这个频次数组计算统计信息，而不需要展开整个样本数组。

关键观察：
1. 最小值和最大值：找到第一个和最后一个 count[i] > 0 的索引 i
2. 均值：总和除以总数量
3. 中位数：需要找到排序后的中间位置，通过累计频次定位
4. 众数：找到 count 数组中最大值对应的索引

算法流程：
1. 遍历 count 数组，计算总数量 total、总和 sum_val
2. 同时记录最小值、最大值、众数
3. 计算均值 = sum_val / total
4. 通过累计频次找到中位数位置对应的值

中位数计算：
- 如果 total 是奇数，找第 (total + 1) / 2 个元素
- 如果 total 是偶数，找第 total / 2 和 total / 2 + 1 个元素的平均值

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def sampleStats(self, count: List[int]) -> List[float]:
        # 初始化变量
        minimum = -1  # 最小值
        maximum = -1  # 最大值
        total = 0     # 总数量
        sum_val = 0   # 总和
        mode = 0      # 众数
        max_count = 0 # 众数的频次
        
        # 第一次遍历：计算基本统计量
        for i in range(256):
            if count[i] > 0:
                # 更新最小值（第一个非零位置）
                if minimum == -1:
                    minimum = i
                # 更新最大值（最后一个非零位置）
                maximum = i
                # 累加总数量和总和
                total += count[i]
                sum_val += i * count[i]
                # 更新众数
                if count[i] > max_count:
                    max_count = count[i]
                    mode = i
        
        # 计算均值
        mean = sum_val / total
        
        # 计算中位数
        median = 0.0
        if total % 2 == 1:
            # 奇数个元素，找第 (total + 1) / 2 个
            target = (total + 1) // 2
            cumulative = 0
            for i in range(256):
                cumulative += count[i]
                if cumulative >= target:
                    median = float(i)
                    break
        else:
            # 偶数个元素，找第 total / 2 和 total / 2 + 1 个
            mid1 = total // 2
            mid2 = total // 2 + 1
            cumulative = 0
            first = -1
            second = -1
            for i in range(256):
                cumulative += count[i]
                # 找到第一个中间元素
                if first == -1 and cumulative >= mid1:
                    first = i
                # 找到第二个中间元素
                if cumulative >= mid2:
                    second = i
                    break
            median = (first + second) / 2.0
        
        return [float(minimum), float(maximum), mean, median, float(mode)]
```

### 方法二：两次遍历优化版

```python
from typing import List

class Solution:
    def sampleStats(self, count: List[int]) -> List[float]:
        # 第一次遍历：计算所有基本统计量（除了中位数）
        minimum, maximum = -1, -1
        total, sum_val = 0, 0
        mode, max_count = 0, 0
        
        for i in range(256):
            if count[i] > 0:
                if minimum == -1:
                    minimum = i
                maximum = i
                total += count[i]
                sum_val += i * count[i]
                if count[i] > max_count:
                    max_count = count[i]
                    mode = i
        
        mean = sum_val / total
        
        # 第二次遍历：计算中位数
        median = self._find_median(count, total)
        
        return [float(minimum), float(maximum), mean, median, float(mode)]
    
    def _find_median(self, count: List[int], total: int) -> float:
        """计算中位数的辅助函数"""
        if total % 2 == 1:
            # 奇数：找第 (total + 1) / 2 个元素
            target = (total + 1) // 2
            cumulative = 0
            for i in range(256):
                cumulative += count[i]
                if cumulative >= target:
                    return float(i)
        else:
            # 偶数：找第 total / 2 和 total / 2 + 1 个元素
            mid1, mid2 = total // 2, total // 2 + 1
            cumulative = 0
            first = second = -1
            for i in range(256):
                prev_cumulative = cumulative
                cumulative += count[i]
                if first == -1 and cumulative >= mid1:
                    first = i
                if cumulative >= mid2:
                    second = i
                    break
            return (first + second) / 2.0
        
        return 0.0
```

### 方法三：简化版（使用双指针思想）

```python
from typing import List

class Solution:
    def sampleStats(self, count: List[int]) -> List[float]:
        # 计算基本统计量
        minimum = next(i for i in range(256) if count[i] > 0)
        maximum = next(i for i in range(255, -1, -1) if count[i] > 0)
        
        total = sum(count)
        sum_val = sum(i * count[i] for i in range(256))
        mean = sum_val / total
        
        mode = max(range(256), key=lambda i: count[i])
        
        # 计算中位数
        median = self._calculate_median(count, total)
        
        return [float(minimum), float(maximum), mean, median, float(mode)]
    
    def _calculate_median(self, count: List[int], total: int) -> float:
        """计算中位数"""
        mid = total // 2
        cumulative = 0
        
        for i in range(256):
            cumulative += count[i]
            if total % 2 == 1:
                # 奇数情况
                if cumulative > mid:
                    return float(i)
            else:
                # 偶数情况
                if cumulative == mid:
                    # 恰好在边界，下一个非零位置是第二个中间值
                    next_val = next(j for j in range(i + 1, 256) if count[j] > 0)
                    return (i + next_val) / 2.0
                elif cumulative > mid:
                    return float(i)
        
        return 0.0
```

## 复杂度分析

### 方法一和方法二

- 时间复杂度：O(n)，其中 n = 256，固定大小。需要遍历 count 数组常数次。
- 空间复杂度：O(1)，只使用常数额外空间。

### 方法三

- 时间复杂度：O(n)，其中 n = 256。虽然使用了 Python 内置函数，但本质上还是遍历。
- 空间复杂度：O(1)。

## 关键点总结

1. 理解题意：count[i] 表示数字 i 的频次，不需要展开数组
2. 最小值最大值：找第一个和最后一个非零位置
3. 均值计算：总和 = Σ(i × count[i])，均值 = 总和 / 总数量
4. 中位数计算：通过累计频次定位中间位置，需要区分奇偶情况
5. 众数：找 count 数组中的最大值对应的索引

## 易错点

1. 中位数计算边界情况
   - 偶数个元素时，要找两个中间值的平均值
   - 注意累计频次恰好等于 mid 的情况
   
2. 数据类型转换
   - 返回值需要是 float 类型
   - 注意整数除法和浮点除法的区别

3. 初始值设置
   - minimum 初始值设为 -1 而不是 0，因为 0 也是有效值
   - 或者使用 None 作为初始值

4. 累计频次的更新时机
   - 在判断是否达到中位数位置时，要注意累计顺序
