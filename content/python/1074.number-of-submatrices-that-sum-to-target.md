## 题目描述

给定一个 `m x n` 的整数矩阵 `matrix` 和一个整数 `target`。

找出并返回矩阵中，元素总和等于目标值 `target` 的**非空子矩阵**的数量。

**示例 1：**
```
输入：matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0
输出：4
解释：四个 1x1 的子矩阵，它们的值都是 0
```

**示例 2：**
```
输入：matrix = [[1,-1],[-1,1]], target = 0
输出：5
解释：
1x1: (0,0), (0,1), (1,0), (1,1) 没有和为0的
1x2: (0,0)到(0,1) = 0 ✓
2x1: (0,0)到(1,0) = 0 ✓
     (0,1)到(1,1) = 0 ✓
2x2: 整个矩阵 = 0 ✓
加上 (1,1) 的值是 1，不对，让我重新数...
实际上正确答案需要仔细枚举
```

**示例 3：**
```
输入：matrix = [[904]], target = 0
输出：0
```

**提示：**
- `1 <= matrix.length <= 100`
- `1 <= matrix[0].length <= 100`
- `-1000 <= matrix[i][j] <= 1000`
- `-10^8 <= target <= 10^8`

## 解题思路

这道题是经典的**二维前缀和 + 哈希表**问题，可以看作是 [560. 和为 K 的子数组](https://leetcode.com/problems/subarray-sum-equals-k/) 的二维扩展。

### 核心思想

1. **降维思路**：
   - 将二维问题转化为多个一维问题
   - 枚举上下边界，将中间的多行压缩成一行
   - 在压缩后的一维数组中，使用哈希表找和为 target 的子数组

2. **一维子问题**：
   - 对于固定的上下边界，每列的和构成一个一维数组
   - 问题转化为：找一维数组中和为 target 的连续子数组个数
   - 使用前缀和 + 哈希表，时间复杂度 O(n)

3. **二维前缀和**：
   - `presum[i][j]` 表示从 `matrix[0][0]` 到 `matrix[i-1][j-1]` 的矩形和
   - 子矩阵 `(r1, c1)` 到 `(r2, c2)` 的和 = `presum[r2+1][c2+1] - presum[r1][c2+1] - presum[r2+1][c1] + presum[r1][c1]`

4. **算法流程**：
   - 预处理二维前缀和（可选，也可以在线计算）
   - 枚举上边界 `row1`
   - 枚举下边界 `row2`（`row2 >= row1`）
   - 计算每列在 `[row1, row2]` 区间的和，得到一维数组
   - 使用哈希表统计和为 target 的连续子数组

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numSubmatrixSumTarget(self, matrix: List[List[int]], target: int) -> int:
        m, n = len(matrix), len(matrix[0])
        count = 0
        
        # 枚举上边界
        for row1 in range(m):
            # col_sum[j] 表示第 j 列从 row1 到当前行的和
            col_sum = [0] * n
            
            # 枚举下边界
            for row2 in range(row1, m):
                # 更新每列的和
                for col in range(n):
                    col_sum[col] += matrix[row2][col]
                
                # 现在 col_sum 是一个一维数组
                # 问题转化为：找和为 target 的连续子数组个数
                count += self.subarraySum(col_sum, target)
        
        return count
    
    def subarraySum(self, nums: List[int], target: int) -> int:
        """找数组中和为 target 的连续子数组个数"""
        prefix_sum_count = defaultdict(int)
        prefix_sum_count[0] = 1  # 前缀和为 0 的情况有 1 种（空数组）
        
        current_sum = 0
        count = 0
        
        for num in nums:
            current_sum += num
            # 如果 current_sum - target 存在，说明存在子数组和为 target
            count += prefix_sum_count[current_sum - target]
            prefix_sum_count[current_sum] += 1
        
        return count
```

### 方法二：二维前缀和预处理

```python
from typing import List
from collections import defaultdict

class Solution:
    def numSubmatrixSumTarget(self, matrix: List[List[int]], target: int) -> int:
        m, n = len(matrix), len(matrix[0])
        
        # 构建二维前缀和
        # presum[i][j] 表示从 (0,0) 到 (i-1,j-1) 的矩形和
        presum = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                presum[i][j] = (matrix[i-1][j-1] + 
                               presum[i-1][j] + 
                               presum[i][j-1] - 
                               presum[i-1][j-1])
        
        count = 0
        
        # 枚举上下边界
        for row1 in range(m):
            for row2 in range(row1, m):
                # 对于固定的上下边界，计算每个右边界对应的列和
                prefix_count = defaultdict(int)
                prefix_count[0] = 1
                
                for col in range(n):
                    # 计算从 (row1, 0) 到 (row2, col) 的矩形和
                    current_sum = (presum[row2+1][col+1] - 
                                  presum[row1][col+1])
                    
                    # 找是否存在前缀和，使得当前和 - 前缀和 = target
                    count += prefix_count[current_sum - target]
                    prefix_count[current_sum] += 1
        
        return count
```

### 方法三：优化的一维压缩（内联实现）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numSubmatrixSumTarget(self, matrix: List[List[int]], target: int) -> int:
        m, n = len(matrix), len(matrix[0])
        count = 0
        
        for row1 in range(m):
            col_sum = [0] * n
            
            for row2 in range(row1, m):
                # 更新列和并同时统计
                prefix_count = defaultdict(int)
                prefix_count[0] = 1
                current_sum = 0
                
                for col in range(n):
                    col_sum[col] += matrix[row2][col]
                    current_sum += col_sum[col]
                    
                    count += prefix_count[current_sum - target]
                    prefix_count[current_sum] += 1
        
        return count
```

## 复杂度分析

**方法一、二、三：**
- **时间复杂度**：O(m² × n)
  - 枚举上下边界：O(m²)
  - 对每对边界，遍历 n 列：O(n)
  - 哈希表操作：O(1)
- **空间复杂度**：O(n)
  - col_sum 数组：O(n)
  - 哈希表最多 O(n) 个键

**如果使用暴力枚举所有子矩阵：**
- **时间复杂度**：O(m² × n² × m × n) = O(m³ × n³)

## 图解示例

以 `matrix = [[1,-1],[-1,1]], target = 0` 为例：

```
原始矩阵：
  0  1
0 1 -1
1 -1  1

枚举过程：
1. row1=0, row2=0: col_sum = [1, -1]
   找和为0的子数组：[1,-1] ✓ → count = 1

2. row1=0, row2=1: col_sum = [0, 0]
   找和为0的子数组：[0], [0, 0], [0] (第二个) ✓ → count += 3

3. row1=1, row2=1: col_sum = [-1, 1]
   找和为0的子数组：[-1,1] ✓ → count += 1

总计：5 个子矩阵
```

## 关键点总结

1. **降维思想**：将二维问题转化为多个一维问题
2. **前缀和技巧**：快速计算区间和
3. **哈希表优化**：用空间换时间，O(1) 查找目标前缀和
4. **遍历顺序**：枚举上下边界，动态维护列和
5. **复用一维算法**：和为 K 的子数组问题的直接应用

## 易错点

1. **前缀和初始化**：`prefix_count[0] = 1` 很重要，表示前缀和为 0 的情况
2. **边界处理**：二维前缀和数组要多开一行一列，避免边界判断
3. **列和更新**：每次更新下边界时，要累加到 col_sum 上，不是重置
4. **哈希表作用**：不是统计和为 target 的次数，而是统计 `current_sum - target` 的次数
5. **空间优化**：不需要完整的二维前缀和数组，在线计算即可
