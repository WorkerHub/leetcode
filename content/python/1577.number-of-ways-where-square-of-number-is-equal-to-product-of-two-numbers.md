## 题目描述

给你两个整数数组 `nums1` 和 `nums2`。

**类型1：** 满足 `nums1[i]^2 == nums2[j] * nums2[k]` 的三元组 `(i, j, k)` 数量（`j < k`）。

**类型2：** 满足 `nums2[i]^2 == nums1[j] * nums1[k]` 的三元组 `(i, j, k)` 数量（`j < k`）。

返回类型1和类型2的三元组总数。

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `1 <= nums1[i], nums2[i] <= 10^5`

## 解题思路

### 哈希表计数

对类型1：枚举 `nums1` 中的每个 `x`，在 `nums2` 中找两个数之积等于 `x^2`。

用哈希表统计 `nums2` 中每个值的出现次数，枚举 `nums2` 的每对 `(j, k)`，若其积等于 `x^2`，贡献 `cnt[j] * cnt[k]`（j != k 时）或 `C(cnt[j], 2)`（j == k 时）。

**更高效：** 对每个 `x^2`，枚举 `nums2` 中所有可能的 `nums2[j]`，若 `x^2 % nums2[j] == 0` 且 `x^2 // nums2[j]` 在 `nums2` 中存在：
- 若两因子不等：贡献 `cnt[a] * cnt[b]`
- 若两因子相等（即 `a == b`）：贡献 `C(cnt[a], 2) = cnt[a]*(cnt[a]-1)//2`

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def numTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        def count_type(a: List[int], b: List[int]) -> int:
            """统计 a[i]^2 == b[j]*b[k] (j<k) 的三元组数"""
            cnt = Counter(b)
            result = 0
            for x in a:
                target = x * x
                seen = set()
                for val in cnt:
                    if target % val == 0:
                        other = target // val
                        if other in cnt and other not in seen:
                            seen.add(val)
                            if val == other:
                                result += cnt[val] * (cnt[val] - 1) // 2
                            else:
                                result += cnt[val] * cnt[other]
            return result

        return count_type(nums1, nums2) + count_type(nums2, nums1)
```

### 方法二：暴力枚举（N <= 1000 时可接受）

```python
from typing import List

class Solution:
    def numTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        def count(a, b):
            cnt = 0
            n = len(b)
            for x in a:
                sq = x * x
                for j in range(n):
                    for k in range(j + 1, n):
                        if b[j] * b[k] == sq:
                            cnt += 1
            return cnt

        return count(nums1, nums2) + count(nums2, nums1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（哈希） | O(N1 * sqrt(max)) 最坏 O(N1 * N2) | O(N2) |
| 方法二（暴力） | O(N1 * N2^2) | O(1) |

N <= 1000 时方法二约 10^9 可能超时，方法一更快。

## 关键点总结

1. 对每个 `a[i]^2`，枚举 `b` 中的一个因子，计算另一个因子是否存在
2. 两因子相等时用组合数（`C(cnt, 2)`）避免重复计数
3. 两种类型对称，可以复用同一函数

## 易错点

- `j < k` 要求两因子的下标有序，用 `seen` 集合避免重复枚举同一对
- 两因子相等时用组合数，不同时直接乘积
