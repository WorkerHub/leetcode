## 题目描述

**花式字符串**是指不含有**三个连续**相同字符的字符串。

给你一个字符串 `s`，请你从 `s` 中删除**最少**的字符，使其变成花式字符串，返回最终结果。

**示例 1：**
```
输入：s = "leeetcode"
输出："leetcode"
解释：删除一个 'e'，使连续的 'e' 不超过 2 个
```

**示例 2：**
```
输入：s = "aaabaaaa"
输出："aabaa"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

---

## 解题思路

### 核心思想：贪心 - 跳过使连续相同字符超过 2 个的字符

遍历字符串，维护结果列表。若当前字符与结果列表末尾两个字符相同，则跳过（不加入）。

---

## 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def makeFancyString(self, s: str) -> str:
        result = []
        for c in s:
            # 若结果末尾两个字符与 c 相同，则跳过
            if len(result) >= 2 and result[-1] == c and result[-2] == c:
                continue
            result.append(c)
        return ''.join(result)
```

### 方法二：双指针写法

```python
class Solution:
    def makeFancyString(self, s: str) -> str:
        n = len(s)
        if n <= 2:
            return s

        result = [s[0], s[1]]
        for i in range(2, n):
            if s[i] != result[-1] or s[i] != result[-2]:
                result.append(s[i])
        return ''.join(result)
```

### 方法三：正则表达式替换

```python
import re

class Solution:
    def makeFancyString(self, s: str) -> str:
        # 将三个及以上连续相同字符替换为两个
        # 使用正则的反向引用
        return re.sub(r'(.)\1\1+', r'\1\1', s)
```

## 关键点总结

1. 只需确保任意连续相同字符不超过 2 个
2. 贪心策略：遇到第三个连续相同字符时跳过
3. 正则 `(.)\1\1+` 匹配 3 个及以上连续相同字符，替换为 2 个

---

## 易错点

- 检查末尾两个字符（不是一个），因为允许两个连续相同
- 字符串长度 ≤ 2 时直接返回（不可能有三连）
