## 题目描述

给定一个二叉树（具有根结点 root）， 一个目标结点 target ，和一个整数值 k 。

返回到目标结点 target 距离为 k 的所有结点的值的列表。 答案可以以 任何顺序 返回。

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2
输出：[7,4,1]
解释：所求结点为与目标结点（值为 5）距离为 2 的结点，值分别为 7，4，以及 1
```

**提示：**
- 节点数在 [1, 500] 范围内
- 0 <= Node.val <= 500
- Node.val 中所有值 不同
- 目标结点 target 是树上的结点
- 0 <= k <= 1000

## 解题思路

这道题的难点是二叉树中**没有父指针**，无法直接向上查找。

**解法思路：**
1. **建立父指针映射**：DFS 遍历树，记录每个节点的父节点
2. **BFS 从目标节点扩散**：把树看作无向图，从 target 开始 BFS
3. **距离为 k 的节点**：BFS 第 k 层的所有节点

**关键步骤：**
1. 先遍历树，建立 `parent` 字典
2. 从 target 开始 BFS，访问子节点和父节点
3. 使用 visited 避免重复访问
4. BFS 到第 k 层时返回结果

## Python 代码实现

### 方法一：父指针 + BFS（推荐）⭐

```python
class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        from collections import deque, defaultdict
        
        # 步骤1：建立父指针映射
        parent = {}
        
        def build_parent(node, par=None):
            if not node:
                return
            parent[node] = par
            build_parent(node.left, node)
            build_parent(node.right, node)
        
        build_parent(root)
        
        # 步骤2：从 target 开始 BFS
        queue = deque([target])
        visited = {target}
        distance = 0
        
        while queue:
            if distance == k:
                return [node.val for node in queue]
            
            for _ in range(len(queue)):
                node = queue.popleft()
                
                # 访问左子节点
                if node.left and node.left not in visited:
                    visited.add(node.left)
                    queue.append(node.left)
                
                # 访问右子节点
                if node.right and node.right not in visited:
                    visited.add(node.right)
                    queue.append(node.right)
                
                # 访问父节点
                if parent[node] and parent[node] not in visited:
                    visited.add(parent[node])
                    queue.append(parent[node])
            
            distance += 1
        
        return []
```

### 方法二：图 + BFS

```python
class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        from collections import deque, defaultdict
        
        # 建立图（邻接表）
        graph = defaultdict(list)
        
        def build_graph(node):
            if not node:
                return
            if node.left:
                graph[node.val].append(node.left.val)
                graph[node.left.val].append(node.val)
                build_graph(node.left)
            if node.right:
                graph[node.val].append(node.right.val)
                graph[node.right.val].append(node.val)
                build_graph(node.right)
        
        build_graph(root)
        
        # BFS
        queue = deque([target.val])
        visited = {target.val}
        distance = 0
        
        while queue:
            if distance == k:
                return list(queue)
            
            for _ in range(len(queue)):
                node_val = queue.popleft()
                for neighbor in graph[node_val]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
            
            distance += 1
        
        return []
```

### 方法三：DFS 记录距离

```python
class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        result = []
        
        def find_distance(node, target):
            """返回 target 在 node 子树中的深度，-1 表示不存在"""
            if not node:
                return -1
            if node == target:
                # 找到 target，向下搜索距离为 k 的节点
                collect_at_distance(node, k)
                return 0
            
            # 在左子树中查找
            left_dist = find_distance(node.left, target)
            if left_dist != -1:
                # target 在左子树中
                if left_dist + 1 == k:
                    result.append(node.val)
                else:
                    # 在右子树中找距离为 k - left_dist - 2 的节点
                    collect_at_distance(node.right, k - left_dist - 2)
                return left_dist + 1
            
            # 在右子树中查找
            right_dist = find_distance(node.right, target)
            if right_dist != -1:
                if right_dist + 1 == k:
                    result.append(node.val)
                else:
                    collect_at_distance(node.left, k - right_dist - 2)
                return right_dist + 1
            
            return -1
        
        def collect_at_distance(node, dist):
            """收集距离 node 为 dist 的所有节点"""
            if not node:
                return
            if dist == 0:
                result.append(node.val)
                return
            collect_at_distance(node.left, dist - 1)
            collect_at_distance(node.right, dist - 1)
        
        find_distance(root, target)
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有节点。
- **空间复杂度**：O(n)，parent 映射或图。

## 关键点总结

1. **父指针映射**：DFS 建立父子关系
2. **转化为无向图**：可以向上也可以向下
3. **BFS 层次遍历**：距离等于层数
4. **visited 去重**：避免重复访问
5. **多种解法**：父指针、图、纯 DFS

## 易错点

1. **忘记检查 parent[node]**：根节点的父节点是 None
2. **visited 时机**：加入队列时就标记，不是出队列时
3. **距离计数**：是边的数量，不是节点数量
