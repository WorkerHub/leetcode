## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。

返回所有满足**下标 i 的二进制表示中恰好有 k 个置位（为 1 的位）**的 `nums[i]` 之和。

**示例 1：**
```
输入：nums = [5,10,1,5,2], k = 1
输出：13
解释：下标 1（01），2（10）有 1 个置位，nums[1]+nums[2]=10+1=... 等等
下标 0（000）：0 个置位
下标 1（001）：1 个置位，nums[1]=10
下标 2（010）：1 个置位，nums[2]=1
下标 3（011）：2 个置位
下标 4（100）：1 个置位，nums[4]=2
总和 = 10+1+2=13
```

**示例 2：**
```
输入：nums = [4,3,2,1], k = 2
输出：1
解释：只有下标 3（11）有 2 个置位，nums[3]=1
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^6`
- `0 <= k <= 10`

## 解题思路

遍历所有下标 `i`，用 `bin(i).count('1')` 或 Python 的 `bit_count()` 方法计算置位数，若等于 k 则累加 `nums[i]`。

## Python 代码实现

### 方法一：bin().count('1')（推荐）

```python
from typing import List

class Solution:
    def sumIndicesWithKSetBits(self, nums: List[int], k: int) -> int:
        return sum(nums[i] for i in range(len(nums)) if bin(i).count('1') == k)
```

### 方法二：bit_count()（Python 3.10+）

```python
from typing import List

class Solution:
    def sumIndicesWithKSetBits(self, nums: List[int], k: int) -> int:
        total = 0
        for i in range(len(nums)):
            if i.bit_count() == k:  # Python 3.10+ 内置方法
                total += nums[i]
        return total
```

### 方法三：手动计算置位数

```python
from typing import List

class Solution:
    def sumIndicesWithKSetBits(self, nums: List[int], k: int) -> int:
        def count_bits(x: int) -> int:
            """计算整数 x 的二进制表示中 1 的个数"""
            count = 0
            while x:
                count += x & 1
                x >>= 1
            return count

        return sum(nums[i] for i in range(len(nums)) if count_bits(i) == k)
```

## 复杂度分析

- 时间复杂度：O(n × log n)，遍历所有下标，每次计算置位数 O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. `bin(i)` 返回二进制字符串（如 `'0b101'`），`.count('1')` 统计 1 的个数
2. Python 3.10+ 有 `int.bit_count()` 方法，更简洁
3. 也可用 `bin(i).count('1')` 或手动位运算

## 易错点

1. `bin(i)` 的结果包含前缀 `'0b'`，但 `count('1')` 不受影响（'0b' 中没有 '1'）
2. 下标从 0 开始，下标 0 的二进制是 0（没有置位）
