## 题目描述

有 `n` 个人要过一扇门。第 `i` 个人在时刻 `arrival[i]` 到达，希望移动方向为 `state[i]`（0 表示从右到左，1 表示从左到右）。

门的规则：
- 同一时刻只能有一人通过
- 若某时刻没有人等待，下一个人可以立即进入
- 若有多人在同一时刻等待，优先让与上一个通过方向相同的人通过
- 若与上一个方向相同的人不存在，优先让从右到左（方向 0）的人通过

返回一个数组，表示每个人过门的时刻。

**示例：**

```
输入：arrival = [0,1,1,2,4], state = [0,1,0,0,1]
输出：[0,3,1,2,4]
```

**提示：**

- `n == arrival.length == state.length`
- `1 <= n <= 10^5`
- `0 <= arrival[i] <= 10^9`（非递减）
- `state[i]` 为 0 或 1

## 解题思路

**模拟 + 两个队列**：

维护两个等待队列（方向 0 和方向 1），以及当前时刻和上一个通过方向。

在每个时刻：
1. 将已到达的人加入对应等待队列
2. 根据优先规则决定谁过门
3. 若两个队列都为空，时间跳跃到下一个人到达时刻

## Python 代码实现

### 方法一：双队列模拟（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def timeTaken(self, arrival: List[int], state: List[int]) -> List[int]:
        n = len(arrival)
        ans = [0] * n
        queue = [deque(), deque()]  # queue[0]: 想往左（方向0），queue[1]: 想往右（方向1）

        cur_time = 0
        last_dir = 1  # 上次通过方向（初始为 1，遇到空闲时优先方向 0）
        ptr = 0        # 下一个未入队的人

        while ptr < n or queue[0] or queue[1]:
            # 将当前时刻到达的人加入队列
            while ptr < n and arrival[ptr] <= cur_time:
                queue[state[ptr]].append(ptr)
                ptr += 1

            if not queue[0] and not queue[1]:
                # 队列为空，时间跳跃到下一个人到达
                if ptr < n:
                    cur_time = arrival[ptr]
                    last_dir = 1  # 空闲后重置，优先方向 0
                continue

            # 决定谁过门
            if queue[0] and queue[1]:
                # 两个方向都有人，优先上次方向
                chosen_dir = last_dir
            elif queue[0]:
                chosen_dir = 0
            else:
                chosen_dir = 1

            person = queue[chosen_dir].popleft()
            ans[person] = cur_time
            last_dir = chosen_dir
            cur_time += 1

        return ans
```

### 方法二：优先队列版本

```python
from typing import List
from collections import deque

class Solution:
    def timeTaken(self, arrival: List[int], state: List[int]) -> List[int]:
        n = len(arrival)
        ans = [0] * n
        # 按到达时间分组
        groups = [[] for _ in range(max(arrival) + 2)]
        for i in range(n):
            groups[arrival[i]].append(i)

        q = [deque(), deque()]
        last_dir = 1
        ptr = 0

        for t in range(max(arrival) + n + 1):
            if ptr < n and t >= arrival[ptr]:
                while ptr < n and arrival[ptr] <= t:
                    q[state[ptr]].append(ptr)
                    ptr += 1

            if not q[0] and not q[1]:
                last_dir = 1  # 重置为优先方向 0
                continue

            if q[0] and q[1]:
                d = last_dir
            elif q[0]:
                d = 0
            else:
                d = 1

            person = q[d].popleft()
            ans[person] = t
            last_dir = d

            if ptr >= n and not q[0] and not q[1]:
                break

        return ans
```

## 复杂度分析

- 时间复杂度：O(n + T)，T 为最大时间戳，实际约为 O(n * max_arrival)
- 空间复杂度：O(n)

## 关键点总结

1. 两个队列分别维护方向 0 和方向 1 的等待人员
2. 空闲时重置优先方向为 0（向左）
3. 有等待人员时，优先同方向的，否则优先方向 0

## 易错点

1. 门空闲（无人等待）后再有人到来时，优先方向重置
2. arrival 数组是非递减的，利用这点简化入队逻辑
3. 当 cur_time 跳跃时，新到达的人应立即加入队列
