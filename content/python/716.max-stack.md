## 题目描述

设计一个最大栈数据结构，既支持栈操作，又支持查找栈中最大元素。

实现 `MaxStack` 类：

- `MaxStack()` 初始化栈对象
- `void push(int x)` 将元素 x 压入栈中
- `int pop()` 移除栈顶元素并返回这个元素
- `int top()` 返回栈顶元素，无需移除
- `int peekMax()` 返回栈中最大元素，无需移除
- `int popMax()` 返回栈中最大元素，并将其删除。如果有多个最大元素，只删除最靠近栈顶的那个

**示例：**

```
输入
["MaxStack", "push", "push", "push", "top", "popMax", "top", "peekMax", "pop", "top"]
[[], [5], [1], [5], [], [], [], [], [], []]
输出
[null, null, null, null, 5, 5, 1, 5, 1, 5]

解释
MaxStack stk = new MaxStack();
stk.push(5);   // [5]
stk.push(1);   // [5, 1]
stk.push(5);   // [5, 1, 5]
stk.top();     // 返回 5
stk.popMax();  // 返回 5，栈变为 [5, 1]
stk.top();     // 返回 1
stk.peekMax(); // 返回 5
stk.pop();     // 返回 1，栈变为 [5]
stk.top();     // 返回 5
```

**提示：**
- `-10^7 <= x <= 10^7`
- 最多调用 `10^4` 次 `push`、`pop`、`top`、`peekMax` 和 `popMax`
- 调用 `pop`、`top`、`peekMax` 或 `popMax` 时，栈中至少存在一个元素

## 解题思路

这道题的难点在于 `popMax()` 操作，需要删除栈中间的元素。

**核心思想：**
- 使用双栈：一个普通栈 + 一个最大值栈
- 但这样无法高效实现 `popMax()`
- 需要使用双向链表 + TreeMap（有序字典）

**方法对比：**
1. **双栈方法**：适合 push/pop/top/peekMax，但 popMax 需要 O(n)
2. **链表 + TreeMap**：所有操作都是 O(log n)

## Python 代码实现

### 方法一：双栈（简单但 popMax 较慢）

```python
class MaxStack:
    def __init__(self):
        """
        stack: 普通栈
        max_stack: 最大值栈
        """
        self.stack = []
        self.max_stack = []
    
    def push(self, x: int) -> None:
        """压入元素"""
        self.stack.append(x)
        
        # 更新最大值栈
        if not self.max_stack:
            self.max_stack.append(x)
        else:
            self.max_stack.append(max(x, self.max_stack[-1]))
    
    def pop(self) -> int:
        """弹出栈顶元素"""
        self.max_stack.pop()
        return self.stack.pop()
    
    def top(self) -> int:
        """返回栈顶元素"""
        return self.stack[-1]
    
    def peekMax(self) -> int:
        """返回最大元素"""
        return self.max_stack[-1]
    
    def popMax(self) -> int:
        """
        删除并返回最大元素
        时间复杂度 O(n)
        """
        max_val = self.max_stack[-1]
        temp = []
        
        # 将最大值上面的元素暂存
        while self.stack[-1] != max_val:
            temp.append(self.pop())
        
        # 删除最大值
        self.pop()
        
        # 恢复暂存的元素
        while temp:
            self.push(temp.pop())
        
        return max_val
```

### 方法二：双向链表 + 有序字典（推荐）⭐

```python
from sortedcontainers import SortedDict

class Node:
    def __init__(self, val):
        self.val = val
        self.prev = None
        self.next = None

class MaxStack:
    def __init__(self):
        """
        使用双向链表维护栈结构
        使用 SortedDict 维护值到节点的映射
        """
        # 双向链表的虚拟头尾节点
        self.head = Node(0)
        self.tail = Node(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        
        # SortedDict: {value: [nodes]}
        self.sorted_dict = SortedDict()
    
    def push(self, x: int) -> None:
        """在链表尾部添加节点"""
        node = Node(x)
        
        # 插入到链表尾部
        node.prev = self.tail.prev
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node
        
        # 更新 SortedDict
        if x not in self.sorted_dict:
            self.sorted_dict[x] = []
        self.sorted_dict[x].append(node)
    
    def pop(self) -> int:
        """删除链表尾部节点"""
        node = self.tail.prev
        val = node.val
        
        # 从链表中删除
        node.prev.next = node.next
        node.next.prev = node.prev
        
        # 从 SortedDict 中删除
        self.sorted_dict[val].pop()
        if not self.sorted_dict[val]:
            del self.sorted_dict[val]
        
        return val
    
    def top(self) -> int:
        """返回链表尾部节点的值"""
        return self.tail.prev.val
    
    def peekMax(self) -> int:
        """返回 SortedDict 中的最大键"""
        return self.sorted_dict.peekitem(-1)[0]
    
    def popMax(self) -> int:
        """删除并返回最大值节点"""
        max_val, nodes = self.sorted_dict.peekitem(-1)
        node = nodes.pop()
        
        if not nodes:
            del self.sorted_dict[max_val]
        
        # 从链表中删除节点
        node.prev.next = node.next
        node.next.prev = node.prev
        
        return max_val
```

### 方法三：不使用外部库（手动实现）

```python
class MaxStack:
    def __init__(self):
        self.stack = []
        self.max_stack = []
    
    def push(self, x: int) -> None:
        self.stack.append(x)
        if not self.max_stack or x >= self.max_stack[-1]:
            self.max_stack.append(x)
        else:
            self.max_stack.append(self.max_stack[-1])
    
    def pop(self) -> int:
        self.max_stack.pop()
        return self.stack.pop()
    
    def top(self) -> int:
        return self.stack[-1]
    
    def peekMax(self) -> int:
        return self.max_stack[-1]
    
    def popMax(self) -> int:
        max_val = self.peekMax()
        buffer = []
        
        while self.top() != max_val:
            buffer.append(self.pop())
        
        self.pop()
        
        for x in reversed(buffer):
            self.push(x)
        
        return max_val
```

## 复杂度分析

### 方法一（双栈）：
- **push:** O(1)
- **pop:** O(1)
- **top:** O(1)
- **peekMax:** O(1)
- **popMax:** O(n)
- **空间复杂度：** O(n)

### 方法二（链表 + SortedDict）：
- **所有操作:** O(log n)
- **空间复杂度：** O(n)

## 关键点总结

1. **双栈思想**：维护普通栈和最大值栈
2. **popMax 优化**：使用链表可以 O(1) 删除任意节点
3. **有序字典**：快速找到最大值和对应节点
4. **双向链表**：方便删除中间节点
5. **Python 库**：`sortedcontainers` 提供高效的有序容器

## 易错点

1. **popMax 实现**：要找最靠近栈顶的最大值
2. **链表删除**：要正确更新前后节点的指针
3. **字典维护**：删除元素后要检查列表是否为空
4. **多个最大值**：要删除最靠近栈顶的那个
5. **空栈判断**：题目保证调用时栈非空，但实现时要注意
