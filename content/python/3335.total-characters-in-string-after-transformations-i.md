## 题目描述

给你一个字符串 `s` 和一个整数 `t`，表示转换次数。

每次转换：将字符串中每个字符替换为其在字母表中的**下一个字符**（'z' 被替换为 "ab" 两个字符）。

返回 `t` 次转换后字符串的**长度**（对 `10^9 + 7` 取模）。

**示例：**
```
输入：s = "abcyz", t = 2
输出：7
解释：
第1次：a->b, b->c, c->d, y->z, z->ab => "bcdz" + "ab" 长5... 
实际：abcyz -> bcdzab (每个字符变下一个，z变ab)，长度6
第2次：bcdzab -> cdea + bc = "cdeabc"... 
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= t <= 10^5`

## 解题思路

**动态规划（字符计数）：**

只需跟踪每个字母的数量，不需要实际存储字符串。

`cnt[c]` = 当前字符 `c` 的数量。

每次转换：
- 字符 'a' 到 'y' 变为下一个字符（'a' -> 'b'，..., 'y' -> 'z'）。
- 字符 'z' 变为 'a' 和 'b' 两个字符。

转移：
- `new_cnt['b'] += cnt['a']`，`new_cnt['c'] += cnt['b']`，...，`new_cnt['z'] += cnt['y']`
- `new_cnt['a'] += cnt['z']`，`new_cnt['b'] += cnt['z']`（'z' 同时贡献给 'a' 和 'b'）

实际上：
- 新的 `cnt[i] = cnt[i-1]`（对 i > 0）
- 新的 `cnt[0] = cnt[25]`（'z' -> 'a'）
- 新的 `cnt[1] += cnt[25]`（'z' -> 'b'，额外加）

等价于循环移位加特殊处理。

## Python 代码实现

### 方法一：模拟字符计数（推荐）

```python
class Solution:
    def lengthAfterTransformations(self, s: str, t: int) -> int:
        MOD = 10**9 + 7
        
        # 初始化字符计数
        cnt = [0] * 26
        for c in s:
            cnt[ord(c) - ord('a')] += 1
        
        for _ in range(t):
            new_cnt = [0] * 26
            for i in range(26):
                if cnt[i] == 0:
                    continue
                if i == 25:  # 'z' -> 'a' + 'b'
                    new_cnt[0] = (new_cnt[0] + cnt[25]) % MOD
                    new_cnt[1] = (new_cnt[1] + cnt[25]) % MOD
                else:
                    new_cnt[i + 1] = (new_cnt[i + 1] + cnt[i]) % MOD
            cnt = new_cnt
        
        return sum(cnt) % MOD
```

### 方法二：矩阵快速幂（适用于更大的 t）

```python
class Solution:
    def lengthAfterTransformations(self, s: str, t: int) -> int:
        MOD = 10**9 + 7
        
        # 构建转移矩阵 26x26
        # M[j][i] = 1 表示字符 i 转换后贡献给字符 j
        # 'a'(0) -> 'b'(1): M[1][0] = 1
        # 'z'(25) -> 'a'(0) 和 'b'(1): M[0][25] = 1, M[1][25] = 1
        M = [[0] * 26 for _ in range(26)]
        for i in range(25):
            M[i + 1][i] = 1
        M[0][25] = 1
        M[1][25] = 1
        
        def mat_mul(A, B):
            n = len(A)
            C = [[0] * n for _ in range(n)]
            for i in range(n):
                for k in range(n):
                    if A[i][k] == 0:
                        continue
                    for j in range(n):
                        C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
            return C
        
        def mat_pow(M, p):
            n = len(M)
            result = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
            while p:
                if p & 1:
                    result = mat_mul(result, M)
                M = mat_mul(M, M)
                p >>= 1
            return result
        
        cnt = [0] * 26
        for c in s:
            cnt[ord(c) - ord('a')] += 1
        
        Mt = mat_pow(M, t)
        
        result = 0
        for j in range(26):
            val = sum(Mt[j][i] * cnt[i] for i in range(26)) % MOD
            result = (result + val) % MOD
        
        return result
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(t * 26)，每次转换 O(26)
- 空间复杂度：O(26) = O(1)

**方法二：**
- 时间复杂度：O(26^3 * log t)，矩阵快速幂
- 空间复杂度：O(26^2)

## 关键点总结

1. 只需统计各字母数量，不需要实际构造字符串。
2. 每次转换是线性变换：字符 `i`（0 索引）的数量变为下一个字符的数量（'z' 贡献给 'a' 和 'b'）。
3. t <= 10^5 时方法一 O(26t) 足够；更大 t 用矩阵快速幂。

## 易错点

1. 'z'（index 25）转换时，同时贡献给 'a'（index 0）和 'b'（index 1）。
2. 每次转换需要用新数组，不能原地修改（否则会影响后续计算）。
3. 取模运算在每步都需要，防止溢出。
