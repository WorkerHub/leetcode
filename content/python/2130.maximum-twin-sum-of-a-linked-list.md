## 题目描述

在一个大小为 `n`（`n` 为偶数）的链表中，第 `i` 个节点（从 **0** 开始）的**孪生节点**为第 `(n-1-i)` 个节点。

**孪生和**定义为一个节点和它孪生节点的值之和。

请你返回最大孪生和。

**示例 1：**
```
输入：head = [5,4,2,1]
输出：6
解释：节点0和3是孪生（5+1=6），节点1和2是孪生（4+2=6），最大为6。
```

**示例 2：**
```
输入：head = [4,2,2,3]
输出：7
解释：孪生和：4+3=7, 2+2=4，最大为7。
```

**提示：**
- 链表节点数为偶数 `n`，`2 <= n <= 10^5`
- `1 <= Node.val <= 10^5`

## 解题思路

**方法一（栈）：** 将前半部分入栈，遍历后半部分时依次与栈顶配对求和，取最大值。

**方法二（反转链表）：** 找到链表中点，将后半部分反转，双指针同时从两端遍历。

## 代码实现

### 方法一：栈（推荐新手）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def pairSum(self, head: Optional[ListNode]) -> int:
        # 将所有节点值存入数组，再从两端配对
        vals = []
        cur = head
        while cur:
            vals.append(cur.val)
            cur = cur.next
        n = len(vals)
        return max(vals[i] + vals[n - 1 - i] for i in range(n // 2))
```

### 方法二：反转链表（O(1) 空间）

```python
from typing import Optional

class Solution:
    def pairSum(self, head: Optional[ListNode]) -> int:
        # 快慢指针找中点
        slow, fast = head, head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 反转后半部分
        prev = None
        cur = slow
        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        # prev 指向后半部分的头，head 指向前半部分的头
        ans = 0
        p1, p2 = head, prev
        while p2:
            ans = max(ans, p1.val + p2.val)
            p1 = p1.next
            p2 = p2.next

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数组存储 | O(n) | O(n) |
| 反转链表 | O(n) | O(1) |

## 关键点总结

1. 简单方法：将链表值存入数组，两端配对即可，O(n) 空间。
2. 进阶方法：找中点、反转后半、双指针配对，O(1) 额外空间。
3. 快慢指针找中点时，fast 到达末尾时 slow 恰好在中间。

## 易错点

- n 为偶数，中点后面恰好是后半部分的开头。
- 反转后半部分后，原链表中半部分的 `next` 指向后半部分反转后的尾部，但本题只需读值，不需要恢复。
