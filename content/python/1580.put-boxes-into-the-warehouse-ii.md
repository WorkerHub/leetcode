## 题目描述

与题 1564 类似，区别在于：可以从**左边或右边**将箱子推入仓库。

每个房间只能放一个箱子，箱子必须满足高度 <= 路过的所有房间高度。

返回最多能放入仓库的箱子数量。

**提示：**
- `1 <= boxes.length, warehouse.length <= 10^5`
- `1 <= boxes[i], warehouse[i] <= 10^9`

## 解题思路

### 预处理 + 贪心

**预处理：** 同时计算从左的前缀最小值 `left_min[i]` 和从右的后缀最小值 `right_min[i]`，每个位置的有效高度 = `max(left_min[i], right_min[i])`（箱子可以从两侧进入，取较大的）。

然后对有效高度排序，对箱子从大到小贪心分配。

## 代码实现

### 方法一：双向预处理 + 排序贪心（推荐）

```python
from typing import List

class Solution:
    def maxBoxesInWarehouse(self, boxes: List[int], warehouse: List[int]) -> int:
        n = len(warehouse)
        # 从左的前缀最小值
        left_min = warehouse[:]
        for i in range(1, n):
            left_min[i] = min(left_min[i], left_min[i-1])
        # 从右的后缀最小值
        right_min = warehouse[:]
        for i in range(n - 2, -1, -1):
            right_min[i] = min(right_min[i], right_min[i+1])
        # 每个位置的实际可用高度（从两侧进入取较大者）
        effective = [max(left_min[i], right_min[i]) for i in range(n)]
        # 排序后贪心
        effective.sort()
        boxes.sort()
        ans = 0
        bi = 0
        for h in effective:
            if bi < len(boxes) and boxes[bi] <= h:
                ans += 1
                bi += 1
        return ans
```

### 方法二：反向预处理（另一种思路）

```python
from typing import List

class Solution:
    def maxBoxesInWarehouse(self, boxes: List[int], warehouse: List[int]) -> int:
        n = len(warehouse)
        # 左进：前缀最小值
        left = [0] * n
        left[0] = warehouse[0]
        for i in range(1, n):
            left[i] = min(left[i-1], warehouse[i])
        # 右进：后缀最小值
        right = [0] * n
        right[n-1] = warehouse[n-1]
        for i in range(n-2, -1, -1):
            right[i] = min(right[i+1], warehouse[i])
        # 合并：取每个位置从两侧的较大有效高度
        heights = sorted(max(left[i], right[i]) for i in range(n))
        boxes.sort()
        j = 0
        for h in heights:
            if j < len(boxes) and boxes[j] <= h:
                j += 1
        return j
```

## 复杂度分析

- **时间复杂度**：O(N log N + M log M)，排序主导
- **空间复杂度**：O(N)

## 关键点总结

1. 从两侧都能进入，每个位置的有效高度 = `max(左前缀最小, 右后缀最小)`
2. 贪心：排序后小箱子放小格子
3. 与题 1564 的区别只在于有效高度的计算方式

## 易错点

- 双向进入时有效高度取 `max`（不是 min），因为可以选择从更好的方向进入
