## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个二维整数数组 `queries`，其中 `queries[i] = [l, r]`。对于每个查询 `[l, r]`，可以将 `nums[l..r]` 中的任意元素减 1（至多各减 1 次）。

请返回使 `nums` 全部变为 0 所需的最少查询次数。若无法实现，返回 -1。

**示例 1：**

```
输入：nums = [2,0,2], queries = [[0,2],[0,2],[1,1]]
输出：2
解释：用前两个查询（[0,2]两次），nums=[0,0,0]
```

**示例 2：**

```
输入：nums = [1,2,3,4], queries = [[0,3]]
输出：-1
解释：单次查询无法使所有元素归零
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `1 <= queries.length <= 10^5`

## 解题思路

**二分查找**：二分答案（使用前 k 个查询），检验是否可行。

**检验可行性（贪心 + 差分数组）**：
给定前 k 个查询，对每个位置 i，它被这些查询覆盖的次数就是可以减少的最大量。若所有位置可减量 >= nums[i]，则可行。

用差分数组计算每个位置被覆盖的次数，前缀和还原。

但本题查询中每次可以选择最多减 1，所以位置 i 被覆盖 c 次时可以减少 min(c, nums[i])。需要每个位置被覆盖次数 >= nums[i]。

## Python 代码实现

### 方法一：二分 + 差分数组（推荐）

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)

        def check(k: int) -> bool:
            # 使用前 k 个查询，检验能否使所有 nums[i] 变为 0
            diff = [0] * (n + 1)
            for l, r in queries[:k]:
                diff[l] += 1
                diff[r + 1] -= 1
            cover = 0
            for i in range(n):
                cover += diff[i]
                if cover < nums[i]:
                    return False
            return True

        if check(0):
            return 0

        lo, hi = 1, len(queries)
        if not check(hi):
            return -1

        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：前向扫描（无需二分）

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        diff = [0] * (n + 1)
        cover = 0
        qi = 0  # 查询指针

        for i in range(n):
            cover += diff[i]
            while cover < nums[i]:
                if qi >= len(queries):
                    return -1
                l, r = queries[qi]
                qi += 1
                if r >= i:
                    diff[max(l, i)] += 1
                    diff[r + 1] -= 1
                    if max(l, i) == i:
                        cover += 1
            # nums[i] 已满足

        return qi
```

## 复杂度分析

- 时间复杂度：O((n + q) log q)（方法一），O(n + q)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组快速计算区间覆盖次数
2. 二分查找最小查询数
3. 贪心：从左到右，优先使用覆盖当前位置的查询

## 易错点

1. 差分数组更新范围：`[l, r]` 对应 `diff[l]++, diff[r+1]--`
2. 需要检查 `check(0)` 特殊情况（所有 nums 已为 0）
3. 方法二中贪心选查询时，跳过右端点不覆盖当前位置的查询
