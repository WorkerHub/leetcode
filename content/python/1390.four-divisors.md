## 题目描述

给你一个整数数组 `nums`，请你返回该数组中恰好拥有四个因数的元素的各因数之和。如果数组中不存在满足题意的元素，则返回 `0`。

**示例 1：**

```
输入：nums = [21,4,7]
输出：32
解释：
21 有 4 个因数：1, 3, 7, 21
4 有 3 个因数：1, 2, 4
7 有 2 个因数：1, 7
答案是 21 的四个因数之和，即 1 + 3 + 7 + 21 = 32
```

**示例 2：**

```
输入：nums = [1,2,3,4,5]
输出：0
```

**提示：**

- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^5`

## 解题思路

**核心问题：** 找出一个数恰好有 4 个因数，并返回这些因数之和。

**关键观察：** 枚举因数时只需枚举到 `sqrt(n)`：
- 若 `i` 是 `n` 的因数，则 `n // i` 也是因数
- 若 `i == n // i`（即 `i^2 == n`），则只计一个因数
- 否则计两个因数

**恰好4个因数的情况：**

1. `n = p^3`（p 是素数）：因数为 1, p, p^2, p^3
2. `n = p * q`（p, q 是不同的素数）：因数为 1, p, q, p*q

**算法：**

1. 对每个数 `num`，从 1 枚举到 `sqrt(num)`
2. 找到所有因数对，记录因数个数和因数之和
3. 若最终恰好有 4 个因数，将因数之和累加到结果中

## Python 代码实现

### 方法一：枚举因数（推荐）

```python
from typing import List
import math

class Solution:
    def sumFourDivisors(self, nums: List[int]) -> int:
        result = 0

        for num in nums:
            divisors = []  # 存储找到的因数
            i = 1
            # 只枚举到 sqrt(num)，利用因数对称性
            while i * i <= num:
                if num % i == 0:
                    divisors.append(i)
                    if i != num // i:
                        # i 和 num//i 是两个不同的因数
                        divisors.append(num // i)
                # 剪枝：因数超过4个就提前退出
                if len(divisors) > 4:
                    break
                i += 1

            # 恰好有4个因数时，累加因数之和
            if len(divisors) == 4:
                result += sum(divisors)

        return result
```

### 方法二：辅助函数拆分（更清晰）

```python
from typing import List

class Solution:
    def sumFourDivisors(self, nums: List[int]) -> int:

        def get_divisor_sum(n: int) -> int:
            """
            如果 n 恰好有 4 个因数，返回因数之和；否则返回 0
            """
            divisors = []
            i = 1
            while i * i <= n:
                if n % i == 0:
                    divisors.append(i)
                    if i != n // i:
                        divisors.append(n // i)
                    # 因数已超过4个，提前退出
                    if len(divisors) > 4:
                        return 0
                i += 1
            # 恰好4个因数
            if len(divisors) == 4:
                return sum(divisors)
            return 0

        return sum(get_divisor_sum(num) for num in nums)
```

## 复杂度分析

- **时间复杂度 O(n * sqrt(M))**：n 是数组长度，M 是数组中最大值（最大为 10^5），sqrt(10^5) ≈ 316。总体约 O(n * 316)。
- **空间复杂度 O(1)**：除了结果外只用常数空间（`divisors` 列表最多存 4+1 个元素）。

## 图解示例

以 `num = 21` 为例，枚举过程：

```
i=1: 21%1==0, 因数: [1, 21]
i=2: 21%2!=0
i=3: 21%3==0, 3 != 7, 因数: [1, 21, 3, 7]
i=4: 4*4=16 <= 21, 21%4!=0
i=5: 5*5=25 > 21, 结束
因数列表: [1, 21, 3, 7]，长度=4，返回 1+21+3+7=32
```

## 关键点总结

1. 枚举因数只需到 `sqrt(n)`，利用因数的对称性（`i` 和 `n//i` 成对出现）
2. 特别注意 `i == n//i` 的情况（完全平方数），此时只计一个因数
3. 剪枝优化：一旦因数个数超过 4，立即退出循环返回 0
4. 恰好 4 个因数的整数形式：`p^3` 或 `p*q`（p, q 是不同素数）

## 易错点

- 忘记判断 `i == n // i` 的情况，导致完全平方数的因数被重复计数
  - 例如 `n=4`，`i=2` 时 `2 == 4//2`，只算一个因数，所以 4 有 3 个因数（1, 2, 4）
- 剪枝条件要用 `> 4` 而不是 `>= 4`，因为在某次迭代中可能一次加入两个因数
- 不要对每个 `num` 都枚举到 `num`，而要枚举到 `sqrt(num)`
