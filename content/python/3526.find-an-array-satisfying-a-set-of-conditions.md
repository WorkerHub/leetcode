## 题目描述

给定整数 `n` 和 `m`，构造一个长度为 `n` 的数组，其中元素为 `1` 到 `m` 之间的整数，满足：对所有 `1 <= i < j <= n`，`(j - i) % nums[i] != 0`（即 `nums[i]` 不能整除 `j - i`）。若无法构造，返回空数组。

**示例 1：**

```
输入：n = 3, m = 3
输出：[2, 3, 1]（或其他合法答案）
```

**示例 2：**

```
输入：n = 3, m = 1
输出：[]
解释：若 nums[i] = 1，则 (j-i) % 1 = 0，任意 i < j 都违反条件。
```

**提示：**
- `1 <= n <= 200`
- `1 <= m <= 200`

## 解题思路

构造题，使用回溯法逐位填充数组，对每个位置枚举 1 到 m 的值，检查是否满足约束条件。

约束检查：对于位置 `i`（0-indexed），已填位置 `j`（`j < i`）中，需要满足 `(i - j) % nums[j] != 0`（即 `nums[j]` 不整除 `i - j`）。

同时，对当前位置 `i` 选择的值 `v`，也需要验证：已填的 `j > i` 位置（回溯时不存在，忽略）的约束，以及 `j < i` 时 `nums[j]` 不整除 `i - j`。

## Python 代码实现

### 方法一：回溯构造（推荐）

```python
from typing import List

class Solution:
    def findArray(self, n: int, m: int) -> List[int]:
        result = [0] * n

        def is_valid(pos, val):
            # 检查 result[pos] = val 是否与已填的前面元素冲突
            for j in range(pos):
                diff = pos - j
                if diff % result[j] == 0:
                    return False
            # 检查 val 本身不会让后面的位置无解（剪枝）
            # val 不能整除 1（因为 nums[pos] = val 要求 diff % val != 0 for all diff > 0）
            # 即 val > 1 才不会有问题（val=1 整除任何数）
            return True

        def backtrack(pos):
            if pos == n:
                return True
            for v in range(1, m + 1):
                result[pos] = v
                if is_valid(pos, v):
                    if backtrack(pos + 1):
                        return True
            result[pos] = 0
            return False

        if backtrack(0):
            return result
        return []
```

### 方法二：贪心构造（若 m >= 2）

```python
from typing import List

class Solution:
    def findArray(self, n: int, m: int) -> List[int]:
        # 简单观察：若 m >= n，可以使用值 > n-1 的元素
        # 若 nums[i] > n-1，则对任意 j > i，j - i <= n-1 < nums[i]，条件自动满足
        if m >= n:
            # 所有位置填 m（或任意大于 n-1 的值）
            # 还需检查前面位置对后面的约束
            # 实际上用 [m, m, ..., m] 不行，因为 nums[0]=m, diff=1,2,...,n-1 是否整除 m?
            pass

        # 回溯是通用解法
        result = [0] * n

        def check(pos, val):
            for j in range(pos):
                if (pos - j) % result[j] == 0:
                    return False
            return True

        def bt(pos):
            if pos == n:
                return True
            for v in range(2, m + 1):  # v=1 不可用（1 整除所有差值）
                result[pos] = v
                if check(pos, v):
                    if bt(pos + 1):
                        return True
            result[pos] = 0
            return False

        if m < 2:
            return []
        if bt(0):
            return result
        return []
```

## 复杂度分析

- 时间复杂度：O(m^n * n)（最坏情况），实际上回溯剪枝后效率较高
- 空间复杂度：O(n)

## 关键点总结

1. `nums[i] = 1` 时，所有后续位置都违反条件，所以必须 `m >= 2`
2. 回溯法逐位选择值，对每个选择验证约束
3. 值越大越不容易整除差值，优先选大值

## 易错点

1. 约束是单向的：`nums[i]` 不整除 `j - i`（只有前面的元素约束后面的位置）
2. `m = 1` 时必然无解（1 整除任何正整数）
3. 回溯时需要正确重置已填的值
