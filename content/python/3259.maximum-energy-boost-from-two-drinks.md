## 题目描述

给你两个整数数组 `energyDrinkA` 和 `energyDrinkB`，长度均为 `n`。

每小时你可以喝一种饮料。如果切换饮料（从 A 到 B 或从 B 到 A），需要等**一小时**（该小时不喝任何饮料）。

返回 `n` 小时内能量的**最大提升**。

**示例 1：**
```
输入：energyDrinkA = [1,3,1], energyDrinkB = [3,1,3]
输出：5
解释：第 1 小时喝 B(3)，第 2 小时切换（0），第 3 小时喝 A(1)？不对
最优：第 1 小时喝 B(3)，第 2 小时喝 B(1)，第 3 小时喝 B(3)=7？
或：喝 A(1)，喝 A(3)，喝 A(1)=5
```

**提示：**
- `n == energyDrinkA.length == energyDrinkB.length`
- `3 <= n <= 10^5`
- `1 <= energyDrinkA[i], energyDrinkB[i] <= 10^5`

## 解题思路

动态规划：

`dp_a[i]` = 第 i 小时喝 A 的最大能量
`dp_b[i]` = 第 i 小时喝 B 的最大能量

转移：
- `dp_a[i] = max(dp_a[i-1] + energyDrinkA[i], dp_b[i-2] + energyDrinkA[i])`
  （从上小时喝 A 继续，或从两小时前喝 B 切换过来）
- `dp_b[i] = max(dp_b[i-1] + energyDrinkB[i], dp_a[i-2] + energyDrinkB[i])`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxEnergyBoost(self, energyDrinkA: List[int], energyDrinkB: List[int]) -> int:
        n = len(energyDrinkA)
        
        # dp[i][0] = 第 i 小时喝 A 的最大能量
        # dp[i][1] = 第 i 小时喝 B 的最大能量
        # dp[i][2] = 第 i 小时不喝（切换间隔）
        
        # 简化：
        # da = dp[i][0], db = dp[i][1]
        # da[i] = max(da[i-1], db[i-1] - db[i-1] + 0) + A[i]... 
        # 不对，切换需要跳过一小时
        
        # 重新定义：
        # dp_a[i] = 最后一次操作是在第 i 小时喝 A 的最大能量
        # dp_b[i] = 最后一次操作是在第 i 小时喝 B 的最大能量
        
        dp_a = [0] * n
        dp_b = [0] * n
        dp_a[0] = energyDrinkA[0]
        dp_b[0] = energyDrinkB[0]
        
        for i in range(1, n):
            # 喝 A：可以从上一时刻喝 A 继续，或从切换而来（上一时刻不喝，再上时刻喝 B）
            if i >= 2:
                dp_a[i] = max(dp_a[i-1] + energyDrinkA[i],
                              dp_b[i-2] + energyDrinkA[i])
                dp_b[i] = max(dp_b[i-1] + energyDrinkB[i],
                              dp_a[i-2] + energyDrinkB[i])
            else:  # i == 1
                # 只能从第 0 时刻同饮料继续
                dp_a[i] = dp_a[i-1] + energyDrinkA[i]  # 继续喝 A
                dp_b[i] = dp_b[i-1] + energyDrinkB[i]  # 继续喝 B
                # 也可以第 0 喝 A，第 1 切换（不喝），这样 dp 不计
                # 或者第 0 切换（不能，第0可以直接选）
                # 实际：可以第 0 不喝（切换前的空档），但初始直接选最优
        
        return max(dp_a[-1], dp_b[-1])
```

### 方法二：简洁 DP

```python
from typing import List

class Solution:
    def maxEnergyBoost(self, energyDrinkA: List[int], energyDrinkB: List[int]) -> int:
        n = len(energyDrinkA)
        # a, b = 当前时刻选 A 或 B 的最大值
        # pa, pb = 两时刻前的最大值
        
        prev_a = prev_b = 0
        cur_a = energyDrinkA[0]
        cur_b = energyDrinkB[0]
        
        for i in range(1, n):
            new_a = max(cur_a + energyDrinkA[i], prev_b + energyDrinkA[i])
            new_b = max(cur_b + energyDrinkB[i], prev_a + energyDrinkB[i])
            prev_a, prev_b = cur_a, cur_b
            cur_a, cur_b = new_a, new_b
        
        return max(cur_a, cur_b)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 切换饮料需要跳过一小时，所以从 i-2 时刻切换
2. DP 状态：当前时刻喝 A 的最大值和喝 B 的最大值
3. 转移：继续同种饮料 or 两步前切换过来

## 易错点

1. 切换需要间隔一小时（不是立即切换）
2. 初始两个时刻的转移要特殊处理
