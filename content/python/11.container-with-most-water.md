## 题目描述

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂直线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：** 你不能倾斜容器。

**示例 1：**

![示例图](https://aliyun-lc-upload.oss-cn-hangzhou.aliyuncs.com/aliyun-lc-upload/uploads/2018/07/25/question_11.jpg)

```
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
```

**示例 2：**
```
输入：height = [1,1]
输出：1
```

## 解题思路

### 方法一：暴力法（不推荐）
- 枚举所有可能的两条线的组合
- 时间复杂度 O(n²)，会超时

### 方法二：双指针（推荐）⭐

**核心思想：**
- 容器的面积 = 两条线之间的距离 × 较短线的高度
- 公式：`area = (right - left) × min(height[left], height[right])`

**双指针策略：**
1. 初始化：左指针在最左边，右指针在最右边
2. 此时宽度最大
3. 每次移动较矮的那一边的指针：
   - 如果移动较高的边，面积一定会减小（宽度减小，高度不会增加）
   - 如果移动较矮的边，面积有可能增加（高度可能增加）
4. 在移动过程中记录最大面积

**为什么这个策略是正确的？**
- 假设左边较矮，移动左指针
- 移动右指针不会得到更大面积（宽度变小，高度仍受左边限制）
- 所以可以安全地排除"左指针不动，右指针向左移动"的所有情况

## Python 代码实现

### 方法一：双指针（最优解）

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        # 初始化左右指针
        left, right = 0, len(height) - 1
        max_area = 0
        
        while left < right:
            # 计算当前面积
            width = right - left
            current_height = min(height[left], height[right])
            current_area = width * current_height
            
            # 更新最大面积
            max_area = max(max_area, current_area)
            
            # 移动较矮的那一边
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        
        return max_area
```

### 优化版（更简洁）

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_area = 0
        
        while left < right:
            # 计算面积并更新最大值
            max_area = max(max_area, 
                          (right - left) * min(height[left], height[right]))
            
            # 移动较矮的指针
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        
        return max_area
```

### 方法二：暴力法（仅供理解）

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        max_area = 0
        n = len(height)
        
        for i in range(n):
            for j in range(i + 1, n):
                width = j - i
                current_height = min(height[i], height[j])
                area = width * current_height
                max_area = max(max_area, area)
        
        return max_area
```

## 复杂度分析

### 双指针方法
- **时间复杂度**：O(n)，只需遍历一次数组
- **空间复杂度**：O(1)，只使用常量额外空间

### 暴力法
- **时间复杂度**：O(n²)，双重循环
- **空间复杂度**：O(1)

## 图解示例

以 `height = [1,8,6,2,5,4,8,3,7]` 为例：

```
初始状态：
left = 0, right = 8
area = 8 × min(1, 7) = 8 × 1 = 8

第一次移动（移动left，因为height[0]=1 < height[8]=7）：
left = 1, right = 8
area = 7 × min(8, 7) = 7 × 7 = 49  ← 最大值

第二次移动（移动right，因为height[1]=8 > height[8]=7）：
left = 1, right = 7
area = 6 × min(8, 3) = 6 × 3 = 18

...继续移动直到 left >= right
```

## 关键点总结

1. **面积公式**：`面积 = 宽度 × min(左高度, 右高度)`
2. **双指针策略**：始终移动较矮的那一边
3. **贪心思想**：从最大宽度开始，寻找可能更高的高度
4. **正确性证明**：移动较高的边不可能得到更大面积
5. **一次遍历**：时间复杂度 O(n)，非常高效

## 易错点

1. **移动哪个指针**：应该移动较矮的指针，不是较高的
2. **高度计算**：要取两边高度的最小值（木桶效应）
3. **边界条件**：`left < right` 而不是 `left <= right`
