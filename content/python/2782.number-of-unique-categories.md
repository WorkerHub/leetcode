## 题目描述

给你一个整数 `n`，表示有 `n` 个元素（编号 1 到 n）。你可以使用 API `haveSameCategory(a, b)` 查询两个元素是否属于同一类别。

在最多 `4 * n` 次查询内，找出不同类别的数量。

## 解题思路

**并查集 + 贪心**：对每个元素，与元素 1 比较：
- 若 `haveSameCategory(1, i)` 为 true，将 i 合并到 1 的组
- 否则，依次与已知不同类别的代表元素比较

优化策略：维护各类别的代表元素列表，对每个新元素，依次询问它与各代表是否同类，找到则合并，否则作为新代表。

总查询次数不超过 `n - 1 + (k-1) * (k-1)` 次，k 为类别数，通常在 4n 内。

## Python 代码实现

### 方法一：并查集 + 逐一比较（推荐）

```python
# 假设 API
# def haveSameCategory(a: int, b: int) -> bool: ...

class Solution:
    def numberOfCategories(self, n: int, haveSameCategory) -> int:
        parent = list(range(n + 1))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        # 对每个元素与前面的代表元素比较
        representatives = [1]  # 各类别的代表

        for i in range(2, n + 1):
            found = False
            for rep in representatives:
                if haveSameCategory(i, rep):
                    union(i, rep)
                    found = True
                    break
            if not found:
                representatives.append(i)

        return len(representatives)
```

## 复杂度分析

- 时间复杂度：O(n * k)，k 为类别数
- 查询次数：最坏 O(n * k)，但题目保证在 4n 内

## 关键点总结

1. 维护各类别代表，每个新元素与所有代表比较
2. 若与某代表同类则合并，否则加入新代表列表
3. 使用并查集跟踪类别

## 易错点

1. 查询次数需控制，不能超过限制
2. 代表元素随合并而变化，需使用 find 操作
