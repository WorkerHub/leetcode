## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

**示例 1：**
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2：**
```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

这道题要求在滑动窗口中快速找到最大值，关键是如何高效维护窗口最大值。

**朴素方法：**
- 每次窗口移动，遍历窗口内所有元素找最大值
- 时间复杂度：O(n * k)，会超时

**优化思路：单调队列**

使用双端队列（deque）维护一个单调递减的序列：
- 队首始终是当前窗口的最大值
- 队列中存储的是元素的**索引**（不是值）

**单调队列的维护规则：**

1. **入队**：新元素从队尾入队前，移除所有比它小的元素
2. **出队**：如果队首元素已经不在窗口内，移除队首
3. **查询**：队首元素就是当前窗口的最大值

**为什么存储索引？**
- 需要判断元素是否还在窗口内
- 通过索引可以快速判断

**为什么单调递减？**
- 如果新元素大于队尾元素，队尾元素永远不可能是最大值
- 可以直接移除，保持队列单调性

## Python 代码实现

### 方法一：单调队列（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        """
        使用单调递减队列
        时间复杂度：O(n)
        空间复杂度：O(k)
        """
        if not nums or k == 0:
            return []
        
        # 双端队列，存储元素索引
        dq = deque()
        result = []
        
        for i in range(len(nums)):
            # 1. 移除队首过期的元素（不在窗口内）
            if dq and dq[0] < i - k + 1:
                dq.popleft()
            
            # 2. 移除队尾所有小于当前元素的元素
            # 保持队列单调递减
            while dq and nums[dq[-1]] < nums[i]:
                dq.pop()
            
            # 3. 当前元素索引入队
            dq.append(i)
            
            # 4. 如果窗口已经形成（i >= k-1），记录最大值
            if i >= k - 1:
                result.append(nums[dq[0]])
        
        return result
```

### 方法二：单调队列（详细注释版）

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        """
        单调队列详解版本
        """
        n = len(nums)
        dq = deque()  # 存储索引
        result = []
        
        for i in range(n):
            # 维护窗口大小：移除队首不在窗口内的元素
            # 窗口范围：[i - k + 1, i]
            while dq and dq[0] < i - k + 1:
                dq.popleft()
            
            # 维护单调性：移除队尾小于当前值的元素
            # 因为它们不可能成为最大值
            while dq and nums[dq[-1]] < nums[i]:
                dq.pop()
            
            # 当前元素入队
            dq.append(i)
            
            # 窗口形成后，记录结果
            # 队首元素就是当前窗口最大值的索引
            if i >= k - 1:
                result.append(nums[dq[0]])
        
        return result
```

### 方法三：大顶堆

```python
import heapq

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        """
        使用大顶堆（优先队列）
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # Python 的 heapq 是小顶堆，用负数模拟大顶堆
        heap = []
        result = []
        
        for i in range(len(nums)):
            # 元素入堆，存储 (-值, 索引)
            heapq.heappush(heap, (-nums[i], i))
            
            # 如果窗口已经形成
            if i >= k - 1:
                # 移除不在窗口内的元素
                while heap[0][1] < i - k + 1:
                    heapq.heappop(heap)
                
                # 堆顶元素就是最大值
                result.append(-heap[0][0])
        
        return result
```

### 方法四：暴力法（仅用于理解，会超时）

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        """
        暴力方法：每次遍历窗口找最大值
        时间复杂度：O(n * k)
        """
        result = []
        
        for i in range(len(nums) - k + 1):
            # 找到窗口 [i, i+k) 的最大值
            window_max = max(nums[i:i+k])
            result.append(window_max)
        
        return result
```

### 方法五：分块 + 预处理（优化思路）

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        """
        分块预处理：
        - 从左到右记录每个位置到块尾的最大值
        - 从右到左记录每个位置到块首的最大值
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        if n * k == 0:
            return []
        if k == 1:
            return nums
        
        # left[i]: 从块起始到 i 的最大值
        left = [0] * n
        left[0] = nums[0]
        
        # right[i]: 从 i 到块结束的最大值
        right = [0] * n
        right[n - 1] = nums[n - 1]
        
        for i in range(1, n):
            # 每 k 个元素一块，块的起始位置重置
            if i % k == 0:
                left[i] = nums[i]
            else:
                left[i] = max(left[i - 1], nums[i])
            
            # 从右往左
            j = n - i - 1
            if (j + 1) % k == 0:
                right[j] = nums[j]
            else:
                right[j] = max(right[j + 1], nums[j])
        
        result = []
        for i in range(n - k + 1):
            # 窗口 [i, i+k-1] 的最大值
            # = max(right[i], left[i+k-1])
            result.append(max(right[i], left[i + k - 1]))
        
        return result
```

## 复杂度分析

**方法一（单调队列）：**
- 时间复杂度：O(n)，每个元素最多入队、出队一次
- 空间复杂度：O(k)，队列最多存储 k 个元素

**方法三（大顶堆）：**
- 时间复杂度：O(n log n)，每次入堆、出堆操作是 O(log n)
- 空间复杂度：O(n)，堆可能存储所有元素

**方法四（暴力法）：**
- 时间复杂度：O(n * k)
- 空间复杂度：O(1)

## 关键点总结

1. **单调队列**：维护单调递减序列，队首是最大值
2. **存储索引**：通过索引判断元素是否在窗口内
3. **双端操作**：队首出队（过期元素），队尾出队（维护单调性）
4. **O(n) 时间**：每个元素最多入队、出队一次
5. **deque 使用**：`popleft()` 和 `pop()` 都是 O(1)

## 易错点

1. **窗口边界判断**：
   ```python
   # 窗口范围是 [i - k + 1, i]
   if dq and dq[0] < i - k + 1:  # 正确
   if dq and dq[0] <= i - k:      # 也正确
   if dq and dq[0] < i - k:       # 错误
   ```

2. **结果记录时机**：
   ```python
   # 只有窗口形成后才记录
   if i >= k - 1:  # 正确
   if i >= k:      # 错误，会少记录一个
   ```

3. **队列存储的是索引**：
   ```python
   dq.append(i)              # 正确
   dq.append(nums[i])        # 错误
   result.append(nums[dq[0]]) # 正确
   result.append(dq[0])       # 错误
   ```

4. **比较时用值，判断时用索引**：
   ```python
   # 比较值
   while dq and nums[dq[-1]] < nums[i]:
   # 判断索引
   if dq[0] < i - k + 1:
   ```

5. **单调递减 vs 递增**：
   - 求最大值用单调递减队列
   - 求最小值用单调递增队列
