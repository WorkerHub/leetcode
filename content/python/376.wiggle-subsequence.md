## 题目描述

如果连续数字之间的差严格地在正数和负数之间交替，则数字序列称为摆动序列。第一个差（如果存在的话）可能是正数或负数。仅有一个元素或者含两个不等元素的序列也视作摆动序列。

例如：
- `[1, 7, 4, 9, 2, 5]` 是一个摆动序列，因为差值 `(6, -3, 5, -7, 3)` 是正负交替出现的
- 相反，`[1, 4, 7, 2, 5]` 和 `[1, 7, 4, 5, 5]` 不是摆动序列
  - 第一个序列是因为它的前两个差值都是正数
  - 第二个序列是因为它的最后一个差值为零

子序列可以通过从原始序列中删除一些（也可以不删除）元素来获得，剩下的元素保持其原始顺序。

给你一个整数数组 `nums`，返回 `nums` 中作为摆动序列的最长子序列的长度。

**示例 1：**

```
输入：nums = [1,7,4,9,2,5]
输出：6
解释：整个序列就是摆动序列，差值为 (6,-3,5,-7,3)
```

**示例 2：**

```
输入：nums = [1,17,5,10,13,15,10,5,16,8]
输出：7
解释：有几个子序列的长度为 7，其中一个是 [1,17,10,13,10,16,8]，差值为 (16,-7,3,-3,6,-8)
```

**示例 3：**

```
输入：nums = [1,2,3,4,5,6,7,8,9]
输出：2
```

**提示：**
- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

**进阶：**
你能否用 O(n) 时间复杂度完成此题？

## 解题思路

这道题有两种主要解法：动态规划和贪心。

### 方法一：动态规划（O(n) 空间）

**状态定义**：
- `up[i]`：以 `nums[i]` 结尾且最后一次是上升的最长摆动序列长度
- `down[i]`：以 `nums[i]` 结尾且最后一次是下降的最长摆动序列长度

**状态转移**：
```python
if nums[i] > nums[i-1]:  # 上升
    up[i] = down[i-1] + 1
    down[i] = down[i-1]
elif nums[i] < nums[i-1]:  # 下降
    down[i] = up[i-1] + 1
    up[i] = up[i-1]
else:  # 相等
    up[i] = up[i-1]
    down[i] = down[i-1]
```

### 方法二：贪心（O(1) 空间，推荐）

**核心思想**：只关心峰值和谷值。

遍历数组，统计趋势的变化次数：
- 记录上一个非零差值的符号
- 当差值符号改变时，计数加一

## Python 代码实现

### 方法一：动态规划（O(n) 空间）

```python
from typing import List

class Solution:
    def wiggleMaxLength(self, nums: List[int]) -> int:
        """
        动态规划
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if len(nums) < 2:
            return len(nums)
        
        n = len(nums)
        # up[i]: 以 nums[i] 结尾且最后是上升的最长摆动序列
        # down[i]: 以 nums[i] 结尾且最后是下降的最长摆动序列
        up = [1] * n
        down = [1] * n
        
        for i in range(1, n):
            if nums[i] > nums[i - 1]:
                # 上升：可以接在之前下降的后面
                up[i] = down[i - 1] + 1
                down[i] = down[i - 1]
            elif nums[i] < nums[i - 1]:
                # 下降：可以接在之前上升的后面
                down[i] = up[i - 1] + 1
                up[i] = up[i - 1]
            else:
                # 相等：保持不变
                up[i] = up[i - 1]
                down[i] = down[i - 1]
        
        return max(up[-1], down[-1])
```

### 方法二：优化的动态规划（O(1) 空间）

```python
from typing import List

class Solution:
    def wiggleMaxLength(self, nums: List[int]) -> int:
        """
        空间优化的动态规划
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if len(nums) < 2:
            return len(nums)
        
        up = 1  # 当前最后是上升的最长摆动序列
        down = 1  # 当前最后是下降的最长摆动序列
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                up = down + 1
            elif nums[i] < nums[i - 1]:
                down = up + 1
        
        return max(up, down)
```

### 方法三：贪心（推荐，最优）

```python
from typing import List

class Solution:
    def wiggleMaxLength(self, nums: List[int]) -> int:
        """
        贪心：统计峰值和谷值的数量
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if len(nums) < 2:
            return len(nums)
        
        # 去掉开头相等的元素
        prev_diff = nums[1] - nums[0]
        count = 2 if prev_diff != 0 else 1
        
        for i in range(2, len(nums)):
            diff = nums[i] - nums[i - 1]
            
            # 趋势改变（峰值或谷值）
            if (diff > 0 and prev_diff <= 0) or (diff < 0 and prev_diff >= 0):
                count += 1
                prev_diff = diff
        
        return count
```

### 方法四：更简洁的贪心

```python
from typing import List

class Solution:
    def wiggleMaxLength(self, nums: List[int]) -> int:
        """
        简洁版贪心
        """
        if len(nums) < 2:
            return len(nums)
        
        up = down = 1
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                up = down + 1
            elif nums[i] < nums[i - 1]:
                down = up + 1
        
        return max(up, down)
```

## 关键点总结

1. **摆动序列定义**：差值正负交替
2. **动态规划思路**：维护两种状态（上升结尾/下降结尾）
3. **贪心思路**：统计峰值和谷值
4. **状态转移**：
   - 上升时，`up` 可以从 `down` 转移
   - 下降时，`down` 可以从 `up` 转移
5. **空间优化**：只需要两个变量，不需要数组

## 易错点

1. **单个元素**：长度为 1 的数组返回 1
2. **两个元素**：长度为 2 且不相等返回 2
3. **连续相等**：`[1,1,1,2]` 的摆动序列长度是 2
4. **初始化**：`up` 和 `down` 初始化为 1
5. **贪心条件**：注意是 `<=` 和 `>=`，而不是 `<` 和 `>`

## 图解示例

### 示例：nums = [1,17,5,10,13,15,10,5,16,8]

```
原数组：1, 17, 5, 10, 13, 15, 10, 5, 16, 8
差值：  +16,-12,+5,+3,+2,-5,-5,+11,-8

峰值和谷值：
1 -> 17 (峰) -> 5 (谷) -> 15 (峰) -> 5 (谷) -> 16 (峰) -> 8 (谷)

摆动序列：[1, 17, 5, 15, 5, 16, 8]
长度：7

或者：[1, 17, 10, 13, 10, 16, 8]
```

### 动态规划过程：

```
i=0: up=1, down=1
i=1: 17>1  -> up=down+1=2, down=1
i=2: 5<17  -> down=up+1=3, up=2
i=3: 10>5  -> up=down+1=4, down=3
i=4: 13>10 -> up=4, down=3 (连续上升，不更新)
i=5: 15>13 -> up=4, down=3
i=6: 10<15 -> down=up+1=5, up=4
i=7: 5<10  -> down=5, up=4 (连续下降，不更新)
i=8: 16>5  -> up=down+1=6, down=5
i=9: 8<16  -> down=up+1=7, up=6

答案：max(6, 7) = 7
```
