## 题目描述

给你两个整数数组 `startTime`（开始时间）和 `endTime`（结束时间），以及整数 `queryTime`（查询时间）。

第 `i` 名学生在 `startTime[i]` 时开始做作业，并于 `endTime[i]` 时完成。

返回在时间 `queryTime` 时正在做作业的学生人数。形式上，返回能够使 `startTime[i] <= queryTime <= endTime[i]` 成立的学生人数。

**示例 1：**
```
输入：startTime = [1,2,3], endTime = [3,2,7], queryTime = 4
输出：1
解释：一共有 3 名学生。
第一名学生在时间 1 开始做作业，并于时间 3 完成。
第二名学生在时间 2 开始做作业，并于时间 2 完成。
第三名学生在时间 3 开始做作业，并于时间 7 完成。
在时间 4，只有第三名学生在做作业。
```

**示例 2：**
```
输入：startTime = [4], endTime = [4], queryTime = 4
输出：1
解释：在查询时间 4，唯一一名学生在做作业。
```

**提示：**
- `startTime.length == endTime.length`
- `1 <= startTime.length <= 100`
- `1 <= startTime[i] <= endTime[i] <= 1000`
- `1 <= queryTime <= 1000`

## 解题思路

这道题非常直接：遍历每名学生，检查查询时间是否在该学生的作业时间段内（即 `startTime[i] <= queryTime <= endTime[i]`），满足条件则计数加一。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def busyStudent(self, startTime: List[int], endTime: List[int], queryTime: int) -> int:
        count = 0
        for i in range(len(startTime)):
            # 判断 queryTime 是否在学生的作业时间区间内
            if startTime[i] <= queryTime <= endTime[i]:
                count += 1
        return count
```

### 方法二：Python 简洁写法（sum + 生成器）

```python
from typing import List

class Solution:
    def busyStudent(self, startTime: List[int], endTime: List[int], queryTime: int) -> int:
        # 利用 sum 和生成器表达式，一行解决
        return sum(
            1 for s, e in zip(startTime, endTime)
            if s <= queryTime <= e
        )
```

### 方法三：差分数组（了解思路，适合大量查询场景）

```python
from typing import List

class Solution:
    def busyStudent(self, startTime: List[int], endTime: List[int], queryTime: int) -> int:
        # 差分数组方法：适合多次查询的场景
        max_time = max(endTime) + 2
        diff = [0] * (max_time + 1)

        for s, e in zip(startTime, endTime):
            diff[s] += 1    # 在 s 时刻开始一个学生
            diff[e + 1] -= 1  # 在 e+1 时刻结束

        # 前缀和还原每个时刻的在读人数
        current = 0
        for t in range(max_time):
            current += diff[t]
            if t == queryTime:
                return current

        return 0
```

## 复杂度分析

**方法一 / 方法二：**
- 时间复杂度：O(n)，n 为学生数量
- 空间复杂度：O(1)

**方法三（差分数组）：**
- 时间复杂度：O(n + max_time)
- 空间复杂度：O(max_time)
- 适用场景：有大量查询时，预处理后每次查询 O(1)

## 关键点总结

1. 核心条件：`startTime[i] <= queryTime <= endTime[i]` 同时成立
2. Python 支持连续比较 `a <= b <= c`，代码更简洁
3. 对于单次查询，直接遍历即可；多次查询可考虑差分数组

## 易错点

- 注意区间是**闭区间**，两端均包含（`<=` 而非 `<`）
- 不要误写成 `startTime[i] < queryTime < endTime[i]`（漏掉等号情况）
