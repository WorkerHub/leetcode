## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

找到 `nums` 中满足以下要求且 **最长** 的子序列：

- 子序列 **严格递增**
- 子序列中相邻元素的差值 **不超过 `k`**

返回满足要求的最长子序列的长度。

**子序列** 是从一个数组中删除某些元素（也可以不删除）而不改变剩余元素的顺序所获得的序列。

**示例 1：**
```
输入：nums = [4,2,1,4,3,4,5,8,15], k = 3
输出：5
解释：满足要求的最长子序列为 [1,3,4,5,8]（差值均不超过 3）。
```

**示例 2：**
```
输入：nums = [7,4,5,1,8,12,4,7], k = 5
输出：4
解释：满足要求的最长子序列为 [4,5,8,12]。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], k <= 10^5`

## 解题思路

**标准 LIS 的扩展问题。**

设 `dp[v]` 表示以值 `v` 结尾的满足条件的最长子序列长度。

对于 `nums[i] = v`，转移方程为：
`dp[v] = max(dp[v-k], dp[v-k+1], ..., dp[v-1]) + 1`

这是一个**区间最大值查询 + 单点更新**的问题，用**线段树**维护，每次操作 O(log n)。

**算法步骤：**
1. 建立一棵线段树，维护区间最大值
2. 遍历 `nums` 中每个值 `v`：
   - 查询区间 `[v-k, v-1]` 的最大值 `best`
   - 更新 `dp[v] = max(dp[v], best + 1)`（取 max 防止同值重复）
   - 在线段树中更新位置 `v` 的值为 `dp[v]`
3. 查询整个线段树的最大值即为答案

## 代码实现

### 方法一：线段树（推荐）

```python
from typing import List

class SegTree:
    """线段树，支持区间最大值查询和单点更新"""
    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (4 * n)

    def update(self, pos: int, val: int, node: int = 1, lo: int = 1, hi: int = -1):
        """更新位置 pos 的值为 val"""
        if hi == -1:
            hi = self.n
        if lo == hi:
            self.tree[node] = max(self.tree[node], val)
            return
        mid = (lo + hi) // 2
        if pos <= mid:
            self.update(pos, val, 2 * node, lo, mid)
        else:
            self.update(pos, val, 2 * node + 1, mid + 1, hi)
        self.tree[node] = max(self.tree[2 * node], self.tree[2 * node + 1])

    def query(self, l: int, r: int, node: int = 1, lo: int = 1, hi: int = -1) -> int:
        """查询区间 [l, r] 的最大值"""
        if hi == -1:
            hi = self.n
        if l > r:
            return 0
        if l <= lo and hi <= r:
            return self.tree[node]
        mid = (lo + hi) // 2
        res = 0
        if l <= mid:
            res = max(res, self.query(l, r, 2 * node, lo, mid))
        if r > mid:
            res = max(res, self.query(l, r, 2 * node + 1, mid + 1, hi))
        return res


class Solution:
    def lengthOfLIS(self, nums: List[int], k: int) -> int:
        max_val = max(nums)
        seg = SegTree(max_val)

        for v in nums:
            # 查询 [v-k, v-1] 的最大 dp 值
            best = seg.query(max(1, v - k), v - 1)
            # 更新 dp[v]
            seg.update(v, best + 1)

        # 答案是整个线段树的最大值
        return seg.query(1, max_val)
```

### 方法二：暴力 DP（超时，仅供理解）

```python
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [1] * n
        ans = 1

        for i in range(1, n):
            for j in range(i):
                # 严格递增且差值不超过 k
                if nums[j] < nums[i] <= nums[j] + k:
                    dp[i] = max(dp[i], dp[j] + 1)
            ans = max(ans, dp[i])

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 线段树 | O(n log M) | O(M) |
| 暴力 DP | O(n^2) | O(n) |

其中 M 为 nums 中的最大值（最大 10^5）。

## 关键点总结

1. 核心转移：`dp[v] = max(dp[v-k..v-1]) + 1`，需要区间最大值查询
2. 线段树维护值域上的 DP，而不是下标上的 DP
3. 同值处理：更新时取 `max(dp[v], best+1)` 防止同值影响

## 易错点

- 查询区间左端点是 `max(1, v-k)` 防止越界
- 线段树的下标范围是值域 `[1, max_val]`，不是数组下标
