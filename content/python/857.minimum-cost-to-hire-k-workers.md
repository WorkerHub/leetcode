## 题目描述

有 n 名工人。给定两个数组 quality 和 wage ，其中，quality[i] 表示第 i 名工人的工作质量，其最低期望工资为 wage[i] 。

现在我们想雇佣 k 名工人组成一个工资组。在雇佣一组 k 名工人时，我们必须按照下述规则向他们支付工资：

1. 对工资组中的每名工人，应当按其工作质量与同组其他工人的工作质量的比例来支付工资。
2. 工资组中的每名工人至少应当得到他们的最低期望工资。

给定整数 k ，返回组成满足上述条件的付费群体所需的最小金额。答案与实际值误差在 10^-5 以内视为正确。

**示例 1：**
```
输入：quality = [10,20,5], wage = [70,50,30], k = 2
输出：105.00000
解释：我们向 0 号工人支付 70，向 2 号工人支付 35。
```

**示例 2：**
```
输入：quality = [3,1,10,10,1], wage = [4,8,2,2,7], k = 3
输出：30.66667
解释：我们向 0 号工人支付 4，向 2 号和 3 号各支付 13.33333。
```

**提示：**
- n == quality.length == wage.length
- 1 <= k <= n <= 10^4
- 1 <= quality[i], wage[i] <= 10^4

## 解题思路

这是一道**贪心 + 堆**的经典题目。

**核心理解：**
1. 工资按质量比例分配：如果比例是 r，工人 i 的工资是 `r * quality[i]`
2. 每个工人有最低期望：`r * quality[i] >= wage[i]`，即 `r >= wage[i] / quality[i]`
3. 要满足所有人，r 必须取最大的 `wage[i] / quality[i]`

**关键观察：**
- 定义每个工人的"性价比"：`ratio[i] = wage[i] / quality[i]`
- 如果选择了一组工人，比例 r = max(ratio)（组内最大的比例）
- 总工资 = r × sum(quality)
- 要最小化总工资，应该：
  1. 固定一个工人的 ratio 作为 r
  2. 选择 ratio ≤ r 的工人中，quality 最小的 k-1 个

**算法流程：**
1. 计算每个工人的 ratio，并按 ratio 排序
2. 枚举每个工人作为 ratio 最大的那个（队长）
3. 从前面的工人中选择 quality 最小的 k-1 个
4. 使用最大堆维护前 k-1 个 quality 最小的工人
5. 计算总工资并更新最小值

## Python 代码实现

### 方法一：贪心 + 最大堆（推荐）⭐

```python
class Solution:
    def mincostToHireWorkers(self, quality: List[int], wage: List[int], k: int) -> float:
        import heapq
        
        n = len(quality)
        # 计算每个工人的性价比，并按性价比排序
        workers = sorted([(wage[i] / quality[i], quality[i], i) 
                         for i in range(n)])
        
        result = float('inf')
        quality_sum = 0  # 当前选中工人的质量总和
        max_heap = []  # 最大堆，存储 quality（取负数实现最大堆）
        
        for ratio, q, i in workers:
            # 将当前工人加入堆
            heapq.heappush(max_heap, -q)
            quality_sum += q
            
            # 如果人数超过 k，移除 quality 最大的
            if len(max_heap) > k:
                quality_sum += heapq.heappop(max_heap)  # 注意是负数
            
            # 如果刚好 k 个人，计算总工资
            if len(max_heap) == k:
                result = min(result, ratio * quality_sum)
        
        return result
```

**代码说明：**
- 按 ratio 排序，枚举每个工人作为"队长"（ratio 最大的）
- 用最大堆维护 quality，保留最小的 k 个
- 队长确定后，总工资 = ratio × quality_sum

### 方法三：详细注释版（便于理解）

```python
class Solution:
    def mincostToHireWorkers(self, quality: List[int], wage: List[int], k: int) -> float:
        import heapq
        
        n = len(quality)
        
        # 计算每个工人的最低工资比例（性价比）
        # ratio[i] = wage[i] / quality[i]
        workers = []
        for i in range(n):
            ratio = wage[i] / quality[i]
            workers.append((ratio, quality[i]))
        
        # 按性价比从小到大排序
        workers.sort()
        
        min_cost = float('inf')
        quality_sum = 0
        max_heap = []  # 存储负的 quality，实现最大堆
        
        for ratio, q in workers:
            # 将当前工人加入候选
            heapq.heappush(max_heap, -q)
            quality_sum += q
            
            # 如果候选人数超过 k，移除 quality 最大的
            if len(max_heap) > k:
                max_quality = -heapq.heappop(max_heap)
                quality_sum -= max_quality
            
            # 如果刚好有 k 个人，计算成本
            if len(max_heap) == k:
                # 当前 ratio 是这 k 个人中最大的
                # 所以所有人的工资都能满足最低期望
                cost = ratio * quality_sum
                min_cost = min(min_cost, cost)
        
        return min_cost
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序 O(n log n) + 堆操作 O(n log k)。
- **空间复杂度**：O(n)，存储工人信息和堆。

## 图解示例

**示例 1**：`quality = [10,20,5], wage = [70,50,30], k = 2`

```
工人信息：
工人 0: quality=10, wage=70, ratio=7.0
工人 1: quality=20, wage=50, ratio=2.5
工人 2: quality=5,  wage=30, ratio=6.0

按 ratio 排序：
工人 1: ratio=2.5, quality=20
工人 2: ratio=6.0, quality=5
工人 0: ratio=7.0, quality=10

枚举过程：
1. 工人 1: ratio=2.5, quality=20
   堆=[20], quality_sum=20, 人数=1 < k

2. 工人 2: ratio=6.0, quality=5
   堆=[20, 5], quality_sum=25, 人数=2 = k
   成本 = 6.0 × 25 = 150

3. 工人 0: ratio=7.0, quality=10
   堆=[20, 5] → 移除20 → [10, 5]
   quality_sum=15, 人数=2 = k
   成本 = 7.0 × 15 = 105 ← 最小

答案：105.0
```

## 关键点总结

1. **性价比排序**：ratio = wage / quality，按从小到大排序
2. **贪心策略**：固定一个工人作为 ratio 最大的，选择前面 quality 最小的
3. **最大堆维护**：保留 quality 最小的 k 个工人
4. **工资计算**：总工资 = ratio × quality_sum
5. **枚举所有可能**：每个工人都可能是"队长"

## 易错点

1. **ratio 的理解**：不是越小越好，而是要枚举所有可能

2. **堆的使用**：Python 的 heapq 是最小堆，需要取负数实现最大堆
   ```python
   # ✅ 正确：取负数
   heapq.heappush(max_heap, -q)
   
   # ❌ 错误：直接用最小堆
   heapq.heappush(min_heap, q)
   ```

3. **quality_sum 更新**：
   ```python
   # ✅ 正确：弹出的是负数
   quality_sum += heapq.heappop(max_heap)
   
   # ❌ 错误：忘记是负数
   quality_sum -= heapq.heappop(max_heap)
   ```

4. **边界条件**：只有凑够 k 个人才计算成本
