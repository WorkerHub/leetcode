## 题目描述

给你一个字符串列表 `words` 和一个目标字符串 `target`。`words` 中所有字符串的长度相同。

你需要从 `words` 中每个字符串中选取一个字符（可以选不同字符串的字符），构成 `target` 字符串，规则如下：
- 选取的字符下标必须严格递增
- 从 `words[j]` 中选取第 `k` 个字符后，第 `k` 列的字符就不能被选取了
- 目标串的每个字符都必须被选取

返回构成 `target` 的方案数，结果对 `10^9 + 7` 取余。

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 1000`
- `words[i].length == words[j].length`
- `1 <= target.length <= 1000`
- `target.length <= words[i].length`

## 解题思路

**DP 定义：** `dp[i][j]` = 使用 words 中第 `j` 列（0-indexed）及之前的列，构成 `target[0..i-1]` 的方案数。

**关键预处理：** `freq[k][c]` = 第 `k` 列中字符 `c` 出现的次数。

**状态转移：**
- 不使用第 `j` 列：`dp[i][j] = dp[i][j-1]`
- 使用第 `j` 列来匹配 `target[i-1]`：`dp[i][j] += dp[i-1][j-1] * freq[j][target[i-1]]`

## 代码实现

### 方法一：二维 DP（推荐）

```python
from typing import List

class Solution:
    def numWays(self, words: List[str], target: str) -> int:
        MOD = 10 ** 9 + 7
        m = len(words[0])  # 每个单词的长度
        n = len(target)
        
        # 预处理：freq[k][c] = 第 k 列中字符 c 的出现次数
        freq = [[0] * 26 for _ in range(m)]
        for word in words:
            for k, c in enumerate(word):
                freq[k][ord(c) - ord('a')] += 1
        
        # dp[i][j] = 使用前 j+1 列，构成 target[0..i-1] 的方案数
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        dp[0][0] = 1  # 空目标串，方案数为 1
        
        for j in range(1, m + 1):
            dp[0][j] = 1  # 构成空目标串，方案数始终为 1
            for i in range(1, n + 1):
                # 不使用第 j 列
                dp[i][j] = dp[i][j-1]
                # 使用第 j 列匹配 target[i-1]
                c_idx = ord(target[i-1]) - ord('a')
                dp[i][j] += dp[i-1][j-1] * freq[j-1][c_idx]
                dp[i][j] %= MOD
        
        return dp[n][m]
```

### 方法二：一维 DP（空间优化）

```python
from typing import List

class Solution:
    def numWays(self, words: List[str], target: str) -> int:
        MOD = 10 ** 9 + 7
        m = len(words[0])
        n = len(target)
        
        freq = [[0] * 26 for _ in range(m)]
        for word in words:
            for k, c in enumerate(word):
                freq[k][ord(c) - ord('a')] += 1
        
        # dp[i] = 构成 target[0..i-1] 的方案数
        dp = [0] * (n + 1)
        dp[0] = 1  # 空目标串
        
        for j in range(m):  # 枚举列
            # 逆序遍历，避免同一列被多次使用
            for i in range(min(j + 1, n), 0, -1):
                c_idx = ord(target[i-1]) - ord('a')
                dp[i] = (dp[i] + dp[i-1] * freq[j][c_idx]) % MOD
        
        return dp[n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维 DP | O(L*W + m*n) | O(m*n) |
| 一维 DP | O(L*W + m*n) | O(n) |

L 为 words 中字符总数（L = |words| * m），W = m，n = |target|。

## 关键点总结

1. 预处理频率数组，避免重复统计
2. 两层 DP：外层枚举列 j，内层枚举目标串长度 i
3. 逆序遍历确保同一列只用一次
4. `dp[0] = 1` 是边界条件（空目标串只有一种构成方式）

## 易错点

- 逆序遍历 i（从 min(j+1, n) 到 1）避免一列被重复利用
- 预处理频率时用的是 words 的第 k 列（`freq[k][ord(c)-ord('a')]`）
- 注意 `target.length <= words[i].length`，否则无法构成目标
