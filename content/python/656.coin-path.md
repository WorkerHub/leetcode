## 题目描述

给定一个数组 `coins`，表示在从位置 1 到位置 n 的路径上每个位置的花费。你需要从位置 1 开始，到达位置 n。

你每次可以向前跳 1 到 `maxJump` 步。你的目标是找到**花费最小**的路径。如果有多条花费相同的路径，返回**字典序最小**的那一条。

如果无法到达位置 n，返回空数组。

**示例 1:**

```
输入: coins = [1,2,4,-1,2], maxJump = 2
输出: [1,3,5]
解释:
路径 1 -> 3 -> 5 的花费是 1 + 4 + 2 = 7
```

**示例 2:**

```
输入: coins = [1,2,4,-1,2], maxJump = 1
输出: []
解释:
无法跳过位置 4（花费为 -1 表示不可达）
```

**提示:**
- `coins.length == n`
- `1 <= n <= 1000`
- `-1 <= coins[i] <= 100`
- `1 <= maxJump <= 100`
- `coins[0]` 不会是 -1

## 解题思路

这是一道**动态规划 + 路径记录**的问题。

### 核心思路

1. **动态规划求最小花费**：
   - `dp[i]` 表示到达位置 i 的最小花费
   - 状态转移：`dp[i] = min(dp[j] + coins[i])` for j in range(max(0, i-maxJump), i)

2. **路径记录**：
   - 记录每个位置的前驱节点
   - 为了字典序最小，从最远的前驱开始考虑

3. **字典序最小**：
   - 在花费相同的情况下，选择编号最小的前驱
   - 这样构造的路径字典序最小

### 关键观察

- 花费为 -1 的位置不可达
- 需要同时记录最小花费和路径
- 字典序最小意味着路径中的数字尽可能小

## Python 代码实现

### 方法一：动态规划 + 路径记录（推荐）⭐

```python
from typing import List

class Solution:
    def cheapestJump(self, coins: List[int], maxJump: int) -> List[int]:
        """
        动态规划求最小花费路径
        """
        n = len(coins)
        
        # 特殊情况
        if coins[-1] == -1:
            return []
        
        # dp[i] 表示到达位置 i 的最小花费
        dp = [float('inf')] * n
        # next[i] 表示从位置 i 到达终点的下一步位置
        next_pos = [-1] * n
        
        # 起点
        dp[0] = coins[0]
        
        # 从后往前填表（为了方便记录路径）
        for i in range(n - 1, -1, -1):
            if coins[i] == -1:
                continue
            
            # 尝试从当前位置跳到后面的位置
            for j in range(i + 1, min(i + maxJump + 1, n)):
                if coins[j] == -1:
                    continue
                
                cost = dp[i] + coins[j]
                
                # 更新条件：花费更小，或花费相同但路径字典序更小
                if cost < dp[j] or (cost == dp[j] and next_pos[i] < next_pos[j]):
                    dp[j] = cost
                    next_pos[i] = j
        
        # 无法到达终点
        if dp[n - 1] == float('inf'):
            return []
        
        # 构造路径
        path = []
        pos = 0
        while pos != -1:
            path.append(pos + 1)  # 位置从 1 开始
            if pos == n - 1:
                break
            pos = next_pos[pos]
        
        return path
```

### 方法二：正向 DP + 回溯路径

```python
class Solution:
    def cheapestJump(self, coins: List[int], maxJump: int) -> List[int]:
        """
        正向动态规划 + 回溯构造路径
        """
        n = len(coins)
        
        if coins[-1] == -1:
            return []
        
        # dp[i] 表示到达位置 i 的最小花费
        dp = [float('inf')] * n
        # parent[i] 表示到达位置 i 的前驱位置
        parent = [-1] * n
        
        dp[0] = coins[0]
        
        # 正向 DP
        for i in range(n):
            if coins[i] == -1 or dp[i] == float('inf'):
                continue
            
            # 从位置 i 跳到后面的位置
            for j in range(i + 1, min(i + maxJump + 1, n)):
                if coins[j] == -1:
                    continue
                
                cost = dp[i] + coins[j]
                
                # 更新条件
                # 1. 花费更小
                # 2. 花费相同但前驱编号更小（字典序）
                if cost < dp[j]:
                    dp[j] = cost
                    parent[j] = i
                elif cost == dp[j] and i < parent[j]:
                    parent[j] = i
        
        # 无法到达终点
        if dp[n - 1] == float('inf'):
            return []
        
        # 回溯构造路径
        path = []
        pos = n - 1
        while pos != -1:
            path.append(pos + 1)
            pos = parent[pos]
        
        path.reverse()
        return path
```

### 方法三：优化版本（带路径长度）

```python
class Solution:
    def cheapestJump(self, coins: List[int], maxJump: int) -> List[int]:
        """
        同时记录路径长度，确保字典序最小
        """
        n = len(coins)
        
        if coins[-1] == -1:
            return []
        
        # dp[i] = (最小花费, 路径长度, 前驱位置)
        dp = [(float('inf'), 0, -1) for _ in range(n)]
        dp[0] = (coins[0], 1, -1)
        
        for i in range(n):
            if coins[i] == -1 or dp[i][0] == float('inf'):
                continue
            
            for j in range(i + 1, min(i + maxJump + 1, n)):
                if coins[j] == -1:
                    continue
                
                cost = dp[i][0] + coins[j]
                length = dp[i][1] + 1
                
                # 更新条件：
                # 1. 花费更小
                # 2. 花费相同但路径更长（字典序更小）
                # 3. 花费相同且路径长度相同但前驱更小
                if (cost < dp[j][0] or 
                    (cost == dp[j][0] and length > dp[j][1]) or
                    (cost == dp[j][0] and length == dp[j][1] and i < dp[j][2])):
                    dp[j] = (cost, length, i)
        
        if dp[n - 1][0] == float('inf'):
            return []
        
        # 回溯路径
        path = []
        pos = n - 1
        while pos != -1:
            path.append(pos + 1)
            pos = dp[pos][2]
        
        path.reverse()
        return path
```

## 复杂度分析

### 方法一/二：动态规划
- **时间复杂度**：O(n × maxJump)
  - 外层循环 n 次
  - 内层循环最多 maxJump 次
- **空间复杂度**：O(n)，dp 数组和 parent 数组

### 方法三：优化版本
- **时间复杂度**：O(n × maxJump)
- **空间复杂度**：O(n)

示例 1：`coins = [1,2,4,-1,2], maxJump = 2`

```
位置：  0   1   2   3   4
花费：  1   2   4  -1   2
索引：  1   2   3   4   5

DP 过程（正向）：

初始：dp = [1, inf, inf, inf, inf]
      parent = [-1, -1, -1, -1, -1]

从位置0出发：
  到位置1：cost = 1+2=3, dp[1]=3, parent[1]=0
  到位置2：cost = 1+4=5, dp[2]=5, parent[2]=0

dp = [1, 3, 5, inf, inf]

从位置1出发：
  到位置2：cost = 3+4=7 > 5，不更新
  到位置3：-1，跳过

从位置2出发：
  到位置3：-1，跳过
  到位置4：cost = 5+2=7, dp[4]=7, parent[4]=2

dp = [1, 3, 5, inf, 7]

回溯路径：
4 -> 2 -> 0
反转：[0, 2, 4]
转换为1-based：[1, 3, 5]
```

## 关键点总结

1. **动态规划**：`dp[i]` 表示到达位置 i 的最小花费
2. **路径记录**：使用 parent 数组记录前驱节点
3. **字典序最小**：花费相同时选择编号最小的前驱
4. **不可达位置**：花费为 -1 的位置需要跳过
5. **边界处理**：终点不可达时返回空数组

## 易错点

1. **位置索引**：
   ```python
   # 题目位置从1开始，数组索引从0开始
   path.append(pos + 1)  # 转换为1-based
   ```

2. **字典序条件**：
   ```python
   # 花费相同时，选择编号更小的前驱
   if cost < dp[j]:
       update()
   elif cost == dp[j] and i < parent[j]:  # 注意这个条件
       update()
   ```

3. **不可达判断**：
   ```python
   # 终点不可达
   if coins[-1] == -1:
       return []
   
   # 某个位置不可达
   if coins[i] == -1:
       continue
   ```

4. **跳跃范围**：
   ```python
   # 注意边界：min(i + maxJump + 1, n)
   for j in range(i + 1, min(i + maxJump + 1, n)):
   ```

5. **路径构造**：
   ```python
   # 回溯时需要反转
   path.reverse()
   ```

**常见问题：**

Q: 为什么花费相同时选择最小的前驱？
A: 因为路径中较早的位置编号越小，字典序越小。

Q: 正向 DP 和反向 DP 有什么区别？
A: 正向更直观，反向可以更方便地记录路径（不需要反转）。

Q: 如何确保字典序最小？
A: 在更新 DP 时，花费相同的情况下选择编号最小的前驱。
