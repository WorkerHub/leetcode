## 题目描述

给定整数数组 `nums` 和整数 `k`，统计有多少个子数组中的**不同元素之和**（即先去重再求和）恰好等于 `k`。

**示例 1：**
```
输入：nums = [1,2,1,3], k = 4
输出：2
解释：
- [1,2,1]: 不同元素 {1,2}，和 3 ≠ 4
- [2,1,3]: 不同元素 {1,2,3}，和 6 ≠ 4
- [1,2]: 不同元素 {1,2}，和 3 ≠ 4
- [2,1]: 同上，3 ≠ 4
- [1,3]: 不同元素 {1,3}，和 4 = 4 ✓
- [1,2,1,3]: 不同元素 {1,2,3}，和 6 ≠ 4
- ... 找出所有满足条件的子数组。
答案应为 2。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= 10^8`

## 解题思路

暴力枚举 + 哈希集合去重。

对每个左端点 `l`，向右扩展，维护窗口内不同元素的集合及其和，统计和等于 `k` 的子数组数量。

由于不同元素之和不单调（添加已有元素不增加和），无法用简单双指针。

## Python 代码实现

### 方法一：枚举左端点（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0

        for l in range(n):
            seen = set()
            distinct_sum = 0
            for r in range(l, n):
                if nums[r] not in seen:
                    seen.add(nums[r])
                    distinct_sum += nums[r]
                if distinct_sum == k:
                    result += 1
                elif distinct_sum > k:
                    break  # 不同元素和只增不减，可以提前退出

        return result
```

### 方法二：哈希表优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0

        for l in range(n):
            freq = defaultdict(int)
            distinct_sum = 0
            for r in range(l, n):
                if freq[nums[r]] == 0:
                    distinct_sum += nums[r]
                freq[nums[r]] += 1
                if distinct_sum == k:
                    result += 1
                if distinct_sum > k:
                    break

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2) 最坏，但由于不同元素和单调递增（正数情况），实际快很多
- 空间复杂度：O(n)

## 关键点总结

1. 不同元素之和：每个元素只计一次，需用集合追踪
2. 正整数情况下，不同元素之和随子数组扩展单调不减，可以提前终止
3. 由于窗口不满足滑动窗口的单调性（收缩时无法高效更新和），暴力枚举更合适

## 易错点

1. 元素重复时不累加到不同元素之和中
2. 提前退出条件：当不同元素和 > k 时停止（正整数情况）
