## 题目描述

你是一位室内设计师，你需要用 n × m 的地砖铺盖一个 n × m 的地板。

你手上有无限数量的正方形地砖，你想用最少的正方形地砖铺盖整个地板。

返回使用的正方形地砖的最少数量。

示例 1：
```
输入：n = 2, m = 3
输出：3
解释：3 块地砖就可以铺满卧室。
     2 块 1x1 地砖
     1 块 2x2 地砖
```

示例 2：
```
输入：n = 5, m = 8
输出：5
```

示例 3：
```
输入：n = 11, m = 13
输出：6
```

提示：
- `1 <= n <= 13`
- `1 <= m <= 13`

## 解题思路

这是一个经典的NP难问题，需要使用回溯 + 剪枝。

核心思路：
1. 从左上角开始填充，每次找到最左下角的未填充位置
2. 尝试不同大小的正方形填充
3. 使用高度数组记录每列的填充高度（类似天际线）
4. 剪枝优化

## Python 代码实现

```python
class Solution:
    def tilingRectangle(self, n: int, m: int) -> int:
        """
        使用回溯 + 剪枝求解
        """
        # 如果是正方形直接返回
        if n == m:
            return 1
        
        # 确保 n <= m
        if n > m:
            n, m = m, n
        
        self.result = n * m  # 最坏情况：全用 1x1
        
        def backtrack(heights: list, count: int):
            """
            heights: 每列的当前高度
            count: 已使用的正方形数量
            """
            # 剪枝
            if count >= self.result:
                return
            
            # 找到最低的列
            min_h = min(heights)
            
            # 所有列都填满了
            if min_h == n:
                self.result = count
                return
            
            # 找到最左边的最低列
            idx = heights.index(min_h)
            
            # 尝试不同大小的正方形
            # 最大边长受限于宽度和剩余高度
            max_size = min(n - min_h, m - idx)
            
            for size in range(max_size, 0, -1):
                # 检查是否能放置 size x size 的正方形
                can_place = all(heights[idx + i] == min_h for i in range(size))
                
                if can_place:
                    # 放置正方形
                    for i in range(size):
                        heights[idx + i] += size
                    
                    backtrack(heights, count + 1)
                    
                    # 回溯
                    for i in range(size):
                        heights[idx + i] -= size
        
        backtrack([0] * m, 0)
        return self.result
```

## 复杂度分析

- 时间复杂度：O(n×m×min(n,m)!)，指数级
- 空间复杂度：O(m)

## 关键点总结

1. 使用高度数组表示填充状态
2. 贪心选择：从左到右、从下到上填充
3. 剪枝：超过已知最优解时提前返回
4. 特判：正方形情况直接返回1

## 易错点

1. 没有正确处理高度数组
2. 剪枝条件不足导致超时
3. 边界条件处理错误
