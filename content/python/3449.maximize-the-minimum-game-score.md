## 题目描述

给你一个整数数组 `points` 和一个整数 `m`，数组长度为 n。

游戏规则：你有 m 次操作。每次操作选择一个下标 i，得到 `points[i]` 分，同时将 `points[i]` 减少 1。但 `points[i]` 不能降为负数。

你想要最大化**最少得分的操作**的分数（即所有 m 次操作中，得分最低的那次操作的分数最大化）。

返回这个最大化的最小操作得分。

**示例：**

```
输入：points = [2,4], m = 3
输出：2
解释：操作3次，可以得 [2,2,4] -> 最小值为 2
```

**提示：**
- `1 <= points.length <= 10^5`
- `1 <= points[i] <= 10^9`
- `1 <= m <= 10^9`

## 解题思路

二分答案：二分最小操作得分 `T`，检查是否能在 m 次操作中保证每次得分 >= T。

检查 `T` 是否可行：
- 每个 `points[i]` 最多可以贡献 `points[i]` 次得分 >= T（当 points[i] 从 points[i] 减到 T，共 points[i]-T+1 次，但每次减 1 还要继续操作直到 < T）
- 对每个 `points[i]`，可以取的操作次数 = floor(points[i] / T)（当得分 >= T 时取），取 T, T-1..., 但等等，减少后的值也需要 >= T 才行
- 实际上每个 points[i] 可以操作 floor(points[i] / T) 次（每次操作不低于 T 分）... 需要仔细分析

贪心：对每个 `points[i]`，在得分 >= T 时可以操作 `floor(points[i] / T)` 次（points[i], points[i]-1, ..., T），共 `points[i]-T+1` 次，但每次操作会减 1。

实际：对 points[i]，可以操作 `ceil(points[i] / T)` 次得分都 >= T？不对。

若 points[i] = 5, T = 2：5,4,3,2,1，前 4 次操作得分 >= 2（5,4,3,2），第 5 次 < 2 不可取。
可以操作 4 = floor(5/2) + (5%2 > 0 ? 1 : 0) = 2+1=3？

实际：从 points[i] 减到 1，中间 >= T 的值有 [T, points[i]]，共 points[i]-T+1 = points[i]-T+1 个。

每操作一次消耗一个值，所以可操作 min(points[i], ...) = points[i]-T+1 次（若 T <= points[i]，否则 0）。

## Python 代码实现

### 方法一：二分答案

```python
from typing import List
import math

class Solution:
    def maxScore(self, points: List[int], m: int) -> int:
        n = len(points)

        def can_achieve(T):
            """是否能在 m 次操作内保证每次得分 >= T"""
            if T == 0:
                return True
            total_ops = 0
            for p in points:
                if p >= T:
                    # 从 p 开始操作，得分 >= T 的次数
                    # p, p-1, ..., T 共 p-T+1 次
                    total_ops += p - T + 1
                    if total_ops >= m:
                        return True
            return total_ops >= m

        lo, hi = 0, max(points)

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_achieve(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：考虑操作顺序的贪心

```python
from typing import List

class Solution:
    def maxScore(self, points: List[int], m: int) -> int:
        n = len(points)

        def feasible(T):
            if T == 0:
                return True
            ops = 0
            for p in points:
                if p >= T:
                    ops += (p - T + 1)
                # 一旦够了就返回
            return ops >= m

        lo, hi = 0, max(points)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

## 复杂度分析

- 时间复杂度：O(n log(max_p))，二分 * 线性检查
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案：最小操作得分 T 具有单调性（T 越大，越难满足 m 次）
2. 检查函数：对每个 points[i]，计算能提供多少次 >= T 的操作
3. points[i] 能提供 max(0, points[i] - T + 1) 次 >= T 的操作

## 易错点

1. `points[i]` 能提供 `points[i] - T + 1` 次（而不是 `points[i] // T` 次）
2. 二分上界是 `max(points)`（每次操作最多得 max(points) 分）
3. T=0 时总是可行（特判）
