## 题目描述

Bob 站在单元格 `(0, 0)`，想要前往目标单元格 `(row, column)`，只能向右（`H`）或向下（`V`）移动。

给你一个数组 `destination = [row, column]` 和一个整数 `k`，找出 Bob 到达目标单元格所有可能路径中**字典序第 k 小**的路径（路径由 `H` 和 `V` 组成）。

**示例：**
```
输入：destination = [2,3], k = 1
输出："HHHVV"
（H=3次，V=2次，字典序最小的先全放 H）
```

## 解题思路

路径由 `column` 个 `H` 和 `row` 个 `V` 组成，总长度 `m = row + column`。

**字典序思考：** 在每个位置决定放 `H` 还是 `V`（`H < V`）：
- 假设当前放 `H`：后续还有 `v` 个 V 和 `h-1` 个 H，方案数 = `C(h-1+v, v)`
- 如果 `k <= 方案数`，则此位置放 `H`（方案数足够）
- 否则放 `V`，`k -= 方案数`

## 代码实现

### 方法一：组合数逐位确定（推荐）

```python
from typing import List
import math

class Solution:
    def kthSmallestPath(self, destination: List[int], k: int) -> str:
        row, col = destination
        # 共需 col 个 H 和 row 个 V
        h, v = col, row
        result = []
        
        for _ in range(h + v):
            if h == 0:
                result.append('V')
                v -= 1
                continue
            if v == 0:
                result.append('H')
                h -= 1
                continue
            
            # 放 H 时，剩余 (h-1) 个 H 和 v 个 V 的方案数
            cnt = math.comb(h - 1 + v, v)
            
            if k <= cnt:
                # 此位置放 H
                result.append('H')
                h -= 1
            else:
                # 此位置放 V
                result.append('V')
                v -= 1
                k -= cnt
        
        return ''.join(result)
```

### 方法二：预计算组合数（DP 方式）

```python
from typing import List

class Solution:
    def kthSmallestPath(self, destination: List[int], k: int) -> str:
        row, col = destination
        h, v = col, row
        total = h + v
        
        # 预计算组合数（使用 Pascal 三角）
        C = [[0] * (total + 1) for _ in range(total + 1)]
        for i in range(total + 1):
            C[i][0] = 1
            for j in range(1, i + 1):
                C[i][j] = C[i-1][j-1] + C[i-1][j]
        
        result = []
        for _ in range(total):
            if h == 0:
                result.append('V')
                v -= 1
            elif v == 0:
                result.append('H')
                h -= 1
            else:
                cnt = C[h - 1 + v][v]
                if k <= cnt:
                    result.append('H')
                    h -= 1
                else:
                    result.append('V')
                    v -= 1
                    k -= cnt
        
        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 组合数逐位 | O((h+v) * log(h+v)) | O(h+v) |
| 预计算 DP | O((h+v)^2) | O((h+v)^2) |

## 关键点总结

1. 字典序：`H < V`，所以在每个位置优先尝试 `H`
2. 放 `H` 的方案数 = `C(h-1+v, v)`（剩余 h-1 个 H 和 v 个 V 的全排列）
3. 若 `k <= cnt`，放 `H`；否则放 `V`，`k -= cnt`
4. H 或 V 用完时直接添加另一种字符

## 易错点

- `C(h-1+v, v)` 是**放 H 后**的方案数，不是放 V 后的
- `k -= cnt` 只在放 V 时执行
- H 或 V 为 0 时必须先处理（无需计算组合数）
