## 题目描述

已知函数 `signFunc(x)` 将会根据 `x` 的正负返回特定值：
- 如果 `x` 是正数，返回 `1`
- 如果 `x` 是负数，返回 `-1`
- 如果 `x` 是等于 `0`，返回 `0`

给你一个整数数组 `nums`，令 `product` 为数组 `nums` 中所有元素值的乘积。

返回 `signFunc(product)`。

**示例 1：**
```
输入：nums = [-1,-2,-3,-4,3,2,1]
输出：1
```

**示例 2：**
```
输入：nums = [1,5,0,2,-3]
输出：0
```

**提示：**
- `1 <= nums.length <= 1000`
- `-100 <= nums[i] <= 100`

## 解题思路

不需要计算实际乘积（可能溢出），只需关注：
1. 若任何元素为 0，乘积为 0，返回 0
2. 统计负数个数，偶数个负数乘积为正（返回 1），奇数个负数乘积为负（返回 -1）

## 代码实现

### 方法一：统计负数个数（推荐）

```python
from typing import List

class Solution:
    def arraySign(self, nums: List[int]) -> int:
        if 0 in nums:
            return 0
        # 统计负数个数，奇数返回 -1，偶数返回 1
        neg_count = sum(1 for x in nums if x < 0)
        return -1 if neg_count % 2 == 1 else 1
```

### 方法二：逐步更新符号

```python
from typing import List

class Solution:
    def arraySign(self, nums: List[int]) -> int:
        sign = 1
        for x in nums:
            if x == 0:
                return 0
            elif x < 0:
                sign = -sign  # 遇到负数翻转符号
        return sign
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 遇到 0 直接返回 0
2. 负数个数的奇偶决定最终符号
3. 不需要真正计算乘积，避免数值溢出

## 易错点

- 不要真正计算所有数的乘积，数组长度 1000 且每个元素最大 100，乘积会极大溢出（虽然 Python 支持大整数）
- 方法二更直观且早退出更快
