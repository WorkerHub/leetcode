## 题目描述

给你一个整数数组 `nums` 和两个正整数 `m` 和 `k`。

返回长度为 `k` 的子数组中，**包含至少 m 个不同值**的子数组的最大元素之和。如果不存在，返回 0。

**示例 1：**
```
输入：nums = [2,6,7,3,1,7], m = 3, k = 4
输出：18
解释：子数组 [6,7,3,1] 有 4 个不同值（>=3），和 = 17；[2,6,7,3] 有 4 个不同值，和 = 18
答案 = 18
```

**示例 2：**
```
输入：nums = [5,9,9,2,4,5,4], m = 1, k = 3
输出：23
解释：找最大和的长度为 k 的子数组（m=1，任意子数组都至少有 1 个不同值）
最大和子数组 [9,9,5] = 23？或 [5,9,9] = 23
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= m <= k <= nums.length`

## 解题思路

**滑动窗口（固定大小 k）+ 哈希表：**

维护大小为 k 的滑动窗口，同时用 Counter 记录窗口内各元素出现次数，以及窗口元素之和。

滑动时：
- 加入右端 `nums[right]`：更新 Counter 和窗口和
- 移出左端 `nums[right - k]`：更新 Counter 和窗口和（当窗口达到 k 时）
- 若 Counter 中不同元素个数 >= m，更新答案

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import Counter
from typing import List

class Solution:
    def maxSum(self, nums: List[int], m: int, k: int) -> int:
        n = len(nums)
        cnt = Counter()
        window_sum = 0
        ans = 0

        for right in range(n):
            # 加入右端元素
            cnt[nums[right]] += 1
            window_sum += nums[right]

            # 窗口大小超过 k，移出左端
            if right >= k:
                left_val = nums[right - k]
                cnt[left_val] -= 1
                if cnt[left_val] == 0:
                    del cnt[left_val]
                window_sum -= left_val

            # 窗口大小为 k 时检查
            if right >= k - 1:
                if len(cnt) >= m:  # 不同值数量 >= m
                    ans = max(ans, window_sum)

        return ans
```

### 方法二：更简洁的写法

```python
from collections import defaultdict
from typing import List

class Solution:
    def maxSum(self, nums: List[int], m: int, k: int) -> int:
        freq = defaultdict(int)
        total = 0
        ans = 0

        for i, x in enumerate(nums):
            freq[x] += 1
            total += x
            if i >= k:
                y = nums[i - k]
                freq[y] -= 1
                if freq[y] == 0:
                    del freq[y]
                total -= y
            if i >= k - 1 and len(freq) >= m:
                ans = max(ans, total)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素进出窗口一次
- 空间复杂度：O(k)，窗口内最多 k 个不同元素

## 关键点总结

1. 固定大小 k 的滑动窗口
2. 用 Counter/dict 记录窗口内各值的频次，`len(cnt)` 即为不同值的数量
3. 删除频次为 0 的键，以保持 len(cnt) 的准确性

## 易错点

1. 元素移出时，若频次降为 0 必须从 Counter 中删除（否则 len(cnt) 不准确）
2. 只有窗口大小达到 k 时才检查并更新答案（`if right >= k - 1`）
3. 滑动窗口的左端移出时机：当 `right >= k` 时（右端下标 >= k 说明窗口已满 k+1 个）
