## 题目描述

给你 `n` 个任务和 `m` 个工人，`tasks[i]` 是任务 `i` 的强度要求，`workers[j]` 是工人 `j` 的强度值。

每个工人最多完成一个任务，强度 >= 任务强度要求的工人才能完成任务。你有 `pills` 颗魔法药丸，每颗可使工人强度 +`strength`（一个工人只能吃一颗）。

返回能完成的**最多任务数**。

**提示：**
- `n, m <= 5 * 10^4`
- `0 <= pills <= m`
- `0 <= strength <= 10^9`
- `1 <= tasks[i], workers[j] <= 10^9`

## 解题思路

**二分答案：** 二分能完成的最多任务数 `k`，检验是否能完成前 `k` 个最简单任务（取最小 k 个任务）。

**检验 `k` 个任务是否可行（贪心）：**
- 选最强的 `k` 个工人（任务难度从小到大排序，取最强工人）
- 对任务从难到易分配（贪心：先处理最难任务）：
  - 若最强工人能完成（不用药）：分配最强工人
  - 否则：最强工人吃药，若能完成：分配能完成的最弱工人（节省强工人）
  - 否则：无法完成这个任务，返回 `false`

## 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
from typing import List
from collections import deque
import sortedcontainers

class Solution:
    def maxTaskAssign(self, tasks: List[int], workers: List[int],
                      pills: int, strength: int) -> int:
        tasks.sort()
        workers.sort()

        def can_do(k: int) -> bool:
            # 检验是否能完成最简单的 k 个任务
            # 使用最强的 k 个工人
            avail = sortedcontainers.SortedList(workers[-k:])
            p = pills

            # 从最难的任务开始分配（倒序）
            for i in range(k - 1, -1, -1):
                task = tasks[i]
                # 最强工人能完成（不用药）
                if avail[-1] >= task:
                    avail.pop(-1)
                else:
                    # 需要吃药：找能吃药后完成此任务的最弱工人
                    if p == 0:
                        return False
                    # 找 workers 中最小的满足 w + strength >= task 的工人
                    idx = avail.bisect_left(task - strength)
                    if idx == len(avail):
                        return False  # 没有工人吃药后能完成
                    avail.pop(idx)
                    p -= 1

            return True

        lo, hi = 0, min(len(tasks), len(workers))
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_do(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：使用 deque 优化

```python
from typing import List
from collections import deque

class Solution:
    def maxTaskAssign(self, tasks: List[int], workers: List[int],
                      pills: int, strength: int) -> int:
        tasks.sort()
        workers.sort()
        m = len(workers)

        def check(k: int) -> bool:
            p = pills
            # 用 k 个最强工人
            worker_q = deque(workers[m - k:])  # 已排序的工人队列

            # 从最难任务开始
            for i in range(k - 1, -1, -1):
                task = tasks[i]
                if worker_q[-1] >= task:
                    # 最强工人能完成，无需药丸
                    worker_q.pop()
                elif p > 0:
                    # 找最弱的能吃药完成的工人
                    # 二分找 worker_q 中 >= task - strength 的最小值
                    lo2, hi2 = 0, len(worker_q) - 1
                    pos = len(worker_q)
                    while lo2 <= hi2:
                        mid2 = (lo2 + hi2) // 2
                        if worker_q[mid2] >= task - strength:
                            pos = mid2
                            hi2 = mid2 - 1
                        else:
                            lo2 = mid2 + 1
                    if pos == len(worker_q):
                        return False
                    del worker_q[pos]
                    p -= 1
                else:
                    return False
            return True

        lo, hi = 0, min(len(tasks), m)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log^2 n)，外层二分 O(log n)，内层验证 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 二分答案，验证是否能完成 k 个任务
2. 贪心：选最简单的 k 个任务，用最强的 k 个工人
3. 从最难任务开始分配：最强工人不能完成时，找最弱的能吃药完成的工人（节省强工人用于更难任务）

## 易错点

- 贪心方向：从最难任务到最简单任务（倒序）
- 吃药时找"最弱的能完成"工人（而不是最强），保留强工人
- 二分取上界写法：`lo = mid + 1` 之后条件是 `can_do(mid)`
