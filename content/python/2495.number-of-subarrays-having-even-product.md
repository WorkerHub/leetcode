## 题目描述

给你一个整数数组 `nums`，返回乘积为 **偶数** 的子数组的数量。

子数组的乘积为偶数 ↔ 子数组中至少含有一个偶数。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**互补计数：**

总子数组数 = `n*(n+1)/2`

乘积为奇数的子数组 = 所有元素均为奇数的子数组（连续奇数段的组合数）

设连续奇数的段长度依次为 `l1, l2, ...`，则奇数乘积子数组数 = `sum(li*(li+1)/2)`。

答案 = 总数 - 奇数乘积子数组数。

或者：**动态规划**，设 `dp[i]` = 以 `nums[i]` 结尾的偶数乘积子数组数：
- 若 `nums[i]` 是偶数：所有以 i 结尾的子数组乘积都是偶数，贡献 `i+1` 个
- 若 `nums[i]` 是奇数：以 i 结尾的子数组，只有包含 i 左侧最近偶数才是偶数乘积

## 代码实现

### 方法一：互补计数（推荐）

```python
from typing import List

class Solution:
    def numberOfSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        total = n * (n + 1) // 2

        # 计算乘积为奇数的子数组数（全奇数连续段）
        odd_count = 0
        consecutive_odd = 0

        for x in nums:
            if x % 2 == 1:
                consecutive_odd += 1
            else:
                # 结算当前奇数段
                odd_count += consecutive_odd * (consecutive_odd + 1) // 2
                consecutive_odd = 0

        # 结算最后一段奇数
        odd_count += consecutive_odd * (consecutive_odd + 1) // 2

        return total - odd_count
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def numberOfSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        last_even = -1  # 最近一个偶数的下标

        for i in range(n):
            if nums[i] % 2 == 0:
                last_even = i
            # 以 i 结尾的偶数乘积子数组：需要包含 last_even
            # 若 last_even == -1，以 i 结尾的所有子数组乘积均为奇数（贡献 0）
            # 否则，以 i 结尾的偶数乘积子数组的左端点 l 满足 0 <= l <= last_even
            # 即 last_even + 1 个
            if last_even >= 0:
                ans += last_even + 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 互补计数 | O(n) | O(1) |
| 动态规划 | O(n) | O(1) |

## 关键点总结

1. 偶数乘积 ↔ 至少含一个偶数 ↔ 用互补（总数 - 全奇数子数组数）
2. DP 方法：以 i 结尾的偶数乘积子数组数 = 左端点可以是 0 到 last_even 的任意位置

## 易错点

- 互补法中连续奇数段要在末尾再结算一次
- DP 法中 `last_even == -1` 时贡献 0
