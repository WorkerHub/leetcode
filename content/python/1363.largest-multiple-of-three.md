## 题目描述

给你一个整数数组 `digits`，你可以通过按任意顺序连接其中某些数字来形成 **3 的倍数**，请你返回所能得到的**最大的 3 的倍数**。

由于答案可能不在整数范围内，请以字符串形式返回答案。如果无法得到答案，请返回一个空字符串 `""`。返回的结果不应包含不必要的前导零。

**示例 1：**
```
输入：digits = [8,1,9]
输出："981"
解释：981 = 9 * 109，是 3 的倍数，且是最大值。
```

**示例 2：**
```
输入：digits = [8,6,7,1,0]
输出："8760"
```

**示例 3：**
```
输入：digits = [1]
输出：""
```

**示例 4：**
```
输入：digits = [0,0,0,0,0,0]
输出："0"
```

**提示：**
- `1 <= digits.length <= 10^4`
- `0 <= digits[i] <= 9`

## 解题思路

一个数是 3 的倍数，当且仅当它的**各位数字之和是 3 的倍数**。

**贪心策略：**

设所有数字之和为 `S`，`r = S % 3`：

- **r == 0**：直接用所有数字组成最大数（降序排列）。
- **r == 1**：需要去掉"余数贡献为 1 的最小代价"：
  - 方案 A：去掉 1 个余数为 1 的最小数字（如 1, 4, 7 中最小的那个）
  - 方案 B：去掉 2 个余数为 2 的最小数字（如最小的两个属于 {2,5,8} 的数）
  - 选代价最小（去掉的数字价值最低）的方案，即去掉后剩余数字最多且最大。
- **r == 2**：类似地：
  - 方案 A：去掉 1 个余数为 2 的最小数字
  - 方案 B：去掉 2 个余数为 1 的最小数字

**"代价最小"的判断：** 比较两个方案去掉的数字总数（方案A去1个 vs 方案B去2个），优先选数字数目少的方案（保留更多位数）；若数字数目相同，则选去掉数字总和更小的。

**最后组合：** 用剩余数字降序排列组成最大数。注意处理全为 0 的情况（返回 "0" 而非 "000"）。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def largestMultipleOfThree(self, digits: List[int]) -> str:
        total = sum(digits)
        r = total % 3
        
        if r == 0:
            # 所有数字直接用
            digits.sort(reverse=True)
            result = ''.join(map(str, digits))
            # 处理全 0 情况
            return '0' if result and result[0] == '0' else result
        
        # 按余数分类
        # rem1[i] 表示余数为 1 的数字按升序排列
        rem = [[] for _ in range(3)]
        for d in sorted(digits):  # 升序，方便后面取最小的
            rem[d % 3].append(d)
        
        def remove_digits(to_remove: List[int]) -> List[int]:
            """从 digits 中移除 to_remove 中的数字（每个只移除一次）"""
            remaining = list(digits)
            for d in to_remove:
                remaining.remove(d)
            return remaining
        
        def try_remove(candidates: List[int], count: int) -> List[int]:
            """
            从 candidates 中取 count 个最小的数字（候选移除列表）
            如果 candidates 数量不足，返回 None
            """
            if len(candidates) < count:
                return None
            return candidates[:count]  # candidates 已升序，前 count 个最小
        
        best = []
        best_str = ""
        
        if r == 1:
            # 方案 A：去掉 1 个余数为 1 的最小数字
            option_a = try_remove(rem[1], 1)
            # 方案 B：去掉 2 个余数为 2 的最小数字
            option_b = try_remove(rem[2], 2)
        else:  # r == 2
            # 方案 A：去掉 1 个余数为 2 的最小数字
            option_a = try_remove(rem[2], 1)
            # 方案 B：去掉 2 个余数为 1 的最小数字
            option_b = try_remove(rem[1], 2)
        
        def build(removed: List[int]) -> str:
            if removed is None:
                return ""
            remaining = list(digits)
            for d in removed:
                remaining.remove(d)
            if not remaining:
                return ""
            remaining.sort(reverse=True)
            res = ''.join(map(str, remaining))
            # 去除前导零（如果全是 0，返回 "0"）
            return '0' if res[0] == '0' else res
        
        s_a = build(option_a)
        s_b = build(option_b)
        
        # 选更大的结果
        # 比较规则：位数多的更大；位数相同时字典序大的更大
        def is_better(a: str, b: str) -> bool:
            if not a:
                return False
            if not b:
                return True
            if len(a) != len(b):
                return len(a) > len(b)
            return a > b
        
        return s_a if is_better(s_a, s_b) else s_b
```

### 方法二：贪心（更简洁的实现）

```python
from typing import List

class Solution:
    def largestMultipleOfThree(self, digits: List[int]) -> str:
        digits.sort(reverse=True)  # 降序排列，方便后面组合
        total = sum(digits)
        r = total % 3
        
        if r == 0:
            res = ''.join(map(str, digits))
            return '0' if res and res[0] == '0' else res
        
        # 找出各余数类型的数字索引（从末尾找，因为降序，末尾的数最小）
        # 要移除最小的数，就在降序数组中从右往左找
        
        def remove_one(lst: List[int], mod: int) -> bool:
            """从降序列表 lst 中从右往左找第一个 %3==mod 的数并移除，返回是否成功"""
            for i in range(len(lst) - 1, -1, -1):
                if lst[i] % 3 == mod:
                    lst.pop(i)
                    return True
            return False
        
        # 尝试两种方案，取结果更大的
        import copy
        
        results = []
        
        if r == 1:
            # 方案 A：移除 1 个 mod==1 的最小数
            d_a = copy.copy(digits)
            if remove_one(d_a, 1):
                results.append(d_a)
            # 方案 B：移除 2 个 mod==2 的最小数
            d_b = copy.copy(digits)
            if remove_one(d_b, 2) and remove_one(d_b, 2):
                results.append(d_b)
        else:  # r == 2
            # 方案 A：移除 1 个 mod==2 的最小数
            d_a = copy.copy(digits)
            if remove_one(d_a, 2):
                results.append(d_a)
            # 方案 B：移除 2 个 mod==1 的最小数
            d_b = copy.copy(digits)
            if remove_one(d_b, 1) and remove_one(d_b, 1):
                results.append(d_b)
        
        if not results:
            return ""
        
        # 选剩余数字最多（或相同时数值最大）的结果
        best = max(results, key=lambda x: (len(x), x))
        if not best:
            return ""
        res = ''.join(map(str, best))
        return '0' if res[0] == '0' else res
```

### 方法三：动态规划（理解用）

```python
from typing import List

class Solution:
    def largestMultipleOfThree(self, digits: List[int]) -> str:
        """
        DP 思路：
        dp[r] = 使用某些数字能构成的最大数，且这些数字之和 % 3 == r
        初始 dp = ["", "", ""]（空字符串表示没有选任何数字）
        对每个数字 d，更新 dp
        最终返回 dp[0]
        """
        digits.sort(reverse=True)  # 降序，保证数字从大到小放入
        
        # dp[r] 是一个字符串，表示数字之和余数为 r 时能组成的最大数
        # 用特殊标记区分"没有选任何数字"和"选了数字但结果为空字符串"
        INF = None  # None 表示不可达
        dp = [None, None, None]
        dp[0] = ""  # 初始：不选任何数字，和为 0，余数 0
        
        def is_better(a, b):
            """a 比 b 更大（数字字符串比较）"""
            if a is None:
                return False
            if b is None:
                return True
            if len(a) != len(b):
                return len(a) > len(b)
            return a > b
        
        for d in digits:
            new_dp = list(dp)
            for r in range(3):
                if dp[r] is not None:
                    new_r = (r + d) % 3
                    candidate = dp[r] + str(d)
                    if is_better(candidate, new_dp[new_r]):
                        new_dp[new_r] = candidate
            dp = new_dp
        
        if dp[0] is None or dp[0] == "":
            return ""
        # 处理前导零
        return '0' if dp[0][0] == '0' else dp[0]
```

## 关键点总结

1. **核心定理**：数是 3 的倍数当且仅当各位数字之和是 3 的倍数。
2. **贪心策略**：根据总和的余数 r，决定去掉哪些数字使余数归零。r==1 时去 1 个余 1 或 2 个余 2；r==2 时去 1 个余 2 或 2 个余 1。
3. **最大化结果**：优先保留更多数字（位数更多），同等位数时保留数值更大的。
4. **前导零处理**：如果所有数字都是 0，结果为 "0"，而不是 "" 或 "000"。
5. **两方案比较**：不能贪心只选一种方案，要把两种方案都算出来，选更优的。

## 易错点

- 去掉"最小代价"的数字：应该去掉满足余数条件的**最小数字**（值最小），而不是位置最靠前的。
- 前导零情况：如果结果字符串第一个字符是 '0'，说明剩余数字全为 0，返回 "0"。
- 两种方案都可能为空（无法实施），需要检查并跳过。
- 方案 B（去两个）在 rem[target_mod] 数量不足 2 个时不可行，必须判断。
