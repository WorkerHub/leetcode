## 题目描述

给定一个字符矩阵 `classroom`，`'S'` 是起点，`'.'` 是空地，`'L'` 是垃圾（litter），`'X'` 是障碍物。从起点出发，每次可以向上下左右移动一步（不能进入 `'X'`）。经过 `'L'` 格时自动清除垃圾。求清除所有垃圾所需的最少步数，若无法清除则返回 `-1`。

**示例：**

```
输入：classroom = ["S...", "...L", "...."]
输出：4
```

**提示：**
- `1 <= m, n <= 20`
- 垃圾数量 <= 10（可以用位运算表示状态）

## 解题思路

BFS + 状态压缩。

状态：`(行, 列, 已清除垃圾的掩码)`。

由于垃圾数量 <= 10，用二进制掩码表示已清除的垃圾集合（最多 2^10 = 1024 种状态）。

BFS 遍历：
- 初始状态：起点位置，掩码为 0
- 转移：向四个方向移动，若进入 `'L'` 格则对应位设 1
- 目标：所有垃圾都被清除（掩码全为 1）

## Python 代码实现

### 方法一：BFS + 位掩码（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minMoves(self, classroom: List[str]) -> int:
        m, n = len(classroom), len(classroom[0])

        # 收集垃圾位置
        litters = []
        litter_id = {}
        start = None

        for r in range(m):
            for c in range(n):
                if classroom[r][c] == 'S':
                    start = (r, c)
                elif classroom[r][c] == 'L':
                    litter_id[(r, c)] = len(litters)
                    litters.append((r, c))

        if not litters:
            return 0

        k = len(litters)
        full_mask = (1 << k) - 1
        start_mask = litter_id.get(start, -1)
        init_mask = (1 << start_mask) if start_mask != -1 else 0

        # BFS
        dist = {}
        queue = deque()
        sr, sc = start
        queue.append((sr, sc, init_mask, 0))
        dist[(sr, sc, init_mask)] = 0

        while queue:
            r, c, mask, steps = queue.popleft()

            if mask == full_mask:
                return steps

            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r+dr, c+dc
                if 0 <= nr < m and 0 <= nc < n and classroom[nr][nc] != 'X':
                    new_mask = mask
                    if (nr, nc) in litter_id:
                        new_mask |= (1 << litter_id[(nr, nc)])
                    state = (nr, nc, new_mask)
                    if state not in dist:
                        dist[state] = steps + 1
                        queue.append((nr, nc, new_mask, steps + 1))

        return -1
```

### 方法二：优先队列（Dijkstra）

```python
from typing import List
import heapq

class Solution:
    def minMoves(self, classroom: List[str]) -> int:
        m, n = len(classroom), len(classroom[0])
        litter_id = {}
        start = None

        for r in range(m):
            for c in range(n):
                if classroom[r][c] == 'S':
                    start = (r, c)
                elif classroom[r][c] == 'L':
                    litter_id[(r, c)] = len(litter_id)

        if not litter_id:
            return 0

        k = len(litter_id)
        full_mask = (1 << k) - 1
        sr, sc = start
        init_mask = (1 << litter_id[(sr, sc)]) if (sr, sc) in litter_id else 0

        heap = [(0, sr, sc, init_mask)]
        visited = set()

        while heap:
            steps, r, c, mask = heapq.heappop(heap)
            if (r, c, mask) in visited:
                continue
            visited.add((r, c, mask))
            if mask == full_mask:
                return steps
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r+dr, c+dc
                if 0 <= nr < m and 0 <= nc < n and classroom[nr][nc] != 'X':
                    new_mask = mask | (1 << litter_id[(nr, nc)]) if (nr, nc) in litter_id else mask
                    if (nr, nc, new_mask) not in visited:
                        heapq.heappush(heap, (steps+1, nr, nc, new_mask))

        return -1
```

## 复杂度分析

- 时间复杂度：O(m * n * 2^k)，k 为垃圾数量
- 空间复杂度：O(m * n * 2^k)

## 关键点总结

1. 状态压缩 BFS：状态为 (位置, 已清除垃圾掩码)
2. 垃圾数量 <= 10，掩码最多 2^10 = 1024 种
3. BFS 保证找到最短路径

## 易错点

1. 起点可能也在垃圾位置（初始化掩码时需要考虑）
2. 障碍物 `'X'` 不可进入
3. 状态中需要同时记录位置和掩码
