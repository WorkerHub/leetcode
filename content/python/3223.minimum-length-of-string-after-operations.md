## 题目描述

给你一个字符串 `s`，你可以执行以下操作**任意次**：

选择字符串中的某个字符 `c`，删除 `c` 左侧**最近**的相同字符以及 `c` 右侧**最近**的相同字符（如果存在的话）。

返回执行操作后字符串的**最小长度**。

**示例 1：**
```
输入：s = "abaacbcbb"
输出：5
```

**示例 2：**
```
输入：s = "aa"
输出：2
```

**提示：**
- `1 <= s.length <= 2 * 10^5`
- `s` 只包含小写英文字母

## 解题思路

关键观察：对于每个字母，它的出现次数决定了最终保留多少个：
- 如果某字母出现 `k` 次，每次操作可以删掉 2 个（左右各一），保留中间的
- 奇数次出现：最终保留 1 个
- 偶数次出现：最终保留 2 个

所以结果是：对每个字母，保留 `1 if count % 2 == 1 else 2`，然后求和。

## Python 代码实现

### 方法一：统计每个字母出现次数（推荐）

```python
from collections import Counter

class Solution:
    def minimumLength(self, s: str) -> int:
        count = Counter(s)
        ans = 0
        for c, cnt in count.items():
            if cnt % 2 == 1:
                ans += 1   # 奇数次保留1个
            else:
                ans += 2   # 偶数次保留2个
        return ans
```

### 方法二：简洁写法

```python
from collections import Counter

class Solution:
    def minimumLength(self, s: str) -> int:
        count = Counter(s)
        # 奇数保留1，偶数保留2
        return sum(1 if v % 2 == 1 else 2 for v in count.values())
```

## 复杂度分析

- 时间复杂度：O(n)，统计字符频率
- 空间复杂度：O(1)，最多 26 个字母

## 关键点总结

1. 每次操作消耗相同字符 3 个，保留 1 个（删左右各最近的，保留自己）
2. 实际上等价于：每个字母奇数次保留 1 个，偶数次保留 2 个
3. 不同字母之间互不影响

## 易错点

1. 偶数次保留 2 个，不是 0 个（至少保留 2 个）
2. 操作可以任意次，不是只能操作一次
