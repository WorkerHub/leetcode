## 题目描述

LeetCode 设计了一款新型键盘，正在测试其新功能。一个测试人员将会使用该键盘来输入一个字符序列，但每次**按下某个键**都需要一定的时间（以毫秒为单位）。

给你一个字符串 `keysPressed`，其中 `keysPressed[i]` 表示测试人员在时刻 `releaseTimes[i]` 时释放的键，`releaseTimes` 数组是升序排列的，且初始时间为 0（即第一个键在时刻 `releaseTimes[0]` 释放）。

按键持续时间：
- 第一个键持续 `releaseTimes[0]`
- 第 i 个键（i > 0）持续 `releaseTimes[i] - releaseTimes[i-1]`

返回持续时间**最长**的键。如果有多个持续时间相同且最长的键，则返回**字典序最大**的那个键。

**示例：**
```
输入：releaseTimes = [9,29,49,50], keysPressed = "cbcd"
输出："c"
解释：持续时间：c=9, b=20, c=20, d=1。最长是 20，b 和 c 都是，c > b，返回 c
```

## 解题思路

遍历所有按键，计算每个键的持续时间，维护最长持续时间和对应的字典序最大键。

## 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def slowestKey(self, releaseTimes: List[int], keysPressed: str) -> str:
        # 记录最长持续时间和对应的键
        max_duration = releaseTimes[0]
        ans = keysPressed[0]
        
        for i in range(1, len(releaseTimes)):
            duration = releaseTimes[i] - releaseTimes[i - 1]
            key = keysPressed[i]
            
            # 更新条件：持续时间更长，或持续时间相同且字典序更大
            if duration > max_duration or (duration == max_duration and key > ans):
                max_duration = duration
                ans = key
        
        return ans
```

### 方法二：排序取最优

```python
from typing import List

class Solution:
    def slowestKey(self, releaseTimes: List[int], keysPressed: str) -> str:
        n = len(releaseTimes)
        # 计算每个键的持续时间
        durations = [releaseTimes[0]] + [
            releaseTimes[i] - releaseTimes[i - 1]
            for i in range(1, n)
        ]
        
        # 找最大持续时间
        max_dur = max(durations)
        
        # 在所有最大持续时间对应的键中，取字典序最大
        candidates = [keysPressed[i] for i in range(n) if durations[i] == max_dur]
        return max(candidates)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(n) | O(1) |
| 排序取最优 | O(n) | O(n) |

## 关键点总结

1. 第一个键持续时间为 `releaseTimes[0]`，其余键为相邻时间差
2. 更新条件：`duration > max` 或 `duration == max AND key > ans`
3. 方法一只需 O(1) 空间，更高效

## 易错点

- 第一个键的持续时间特殊处理（从时刻 0 开始）
- 相同持续时间取字典序**最大**（不是最小）
- `key > ans` 比较字符的字典序
