## 题目描述

在无限的平面上，机器人最初位于 `(0, 0)` 处，面朝北方。注意：

- 北方向是y轴的正方向
- 南方向是y轴的负方向
- 东方向是x轴的正方向
- 西方向是x轴的负方向

机器人可以接收以下三种类型的指令：

- `"G"`：直走 1 个单位
- `"L"`：左转 90 度
- `"R"`：右转 90 度

机器人按顺序执行指令 `instructions`，并一直重复它们。

只有在平面中存在环使得机器人永远无法离开时，返回 `true`。否则，返回 `false`。

**示例 1：**
```
输入：instructions = "GGLLGG"
输出：true
解释：机器人最初在 (0, 0) 处，面向北方。
"G"：移动到 (0, 1)
"G"：移动到 (0, 2)
"L"：左转，面向西方
"L"：左转，面向南方
"G"：移动到 (0, 1)
"G"：移动到 (0, 0)
重复指令，机器人进入循环：(0, 0) --> (0, 2) --> (0, 0) --> ...
```

**示例 2：**
```
输入：instructions = "GG"
输出：false
解释：机器人最初在 (0, 0) 处，面向北方。
"G"：移动到 (0, 1)
"G"：移动到 (0, 2)
重复指令，机器人不断向北移动，不会进入循环。
```

**示例 3：**
```
输入：instructions = "GL"
输出：true
解释：机器人最初在 (0, 0) 处，面向北方。
"G"：移动到 (0, 1)
"L"：左转，面向西方
重复指令后，机器人会形成一个正方形轨迹。
```

**提示：**
- `1 <= instructions.length <= 100`
- `instructions[i]` 仅包含 `'G'`、`'L'`、`'R'`

## 解题思路

这道题的关键是理解什么情况下机器人会被困在一个循环中。

### 核心观察

执行一次指令序列后，机器人的状态由两个因素决定：
1. **位置**：`(x, y)`
2. **方向**：北、东、南、西

机器人会被困在循环中的充要条件是：

**条件1：回到原点**
- 如果执行一次指令后回到 `(0, 0)`，显然会循环

**条件2：方向改变**
- 如果执行一次指令后，方向不再是北方，则最多执行 4 次指令序列后必定回到原点
- 原因：
  - 如果最终方向是东（右转90度），执行4次后转360度，回到原点
  - 如果最终方向是南（转180度），执行2次后回到原点
  - 如果最终方向是西（左转90度），执行4次后回到原点

### 数学证明

设执行一次指令后：
- 位移向量为 `(dx, dy)`
- 方向改变角度为 `θ`

如果 `θ != 0`（方向改变），则：
- 第1次：位移 `(dx, dy)`，旋转 `θ`
- 第2次：位移 `R(θ) * (dx, dy)`，旋转 `2θ`
- 第3次：位移 `R(2θ) * (dx, dy)`，旋转 `3θ`
- 第4次：位移 `R(3θ) * (dx, dy)`，旋转 `4θ = 360°`

其中 `R(α)` 是旋转矩阵。最终总位移为零。

## Python 代码实现

### 方法一：模拟 + 方向判断（推荐）

```python
from typing import List

class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        # 初始位置和方向
        x, y = 0, 0
        # 方向：0=北, 1=东, 2=南, 3=西
        direction = 0
        
        # 四个方向的移动向量：北、东、南、西
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        
        # 执行一次指令序列
        for instruction in instructions:
            if instruction == 'G':
                # 前进一步
                dx, dy = directions[direction]
                x += dx
                y += dy
            elif instruction == 'L':
                # 左转：direction - 1
                direction = (direction - 1) % 4
            else:  # instruction == 'R'
                # 右转：direction + 1
                direction = (direction + 1) % 4
        
        # 判断是否被困在循环中
        # 条件1：回到原点
        # 条件2：方向改变（不再朝北）
        return (x == 0 and y == 0) or direction != 0
```

### 方法二：使用方向向量

```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        # 初始位置
        x, y = 0, 0
        # 初始方向向量（朝北）
        dx, dy = 0, 1
        
        for instruction in instructions:
            if instruction == 'G':
                # 沿当前方向前进
                x += dx
                y += dy
            elif instruction == 'L':
                # 左转90度：(dx, dy) -> (-dy, dx)
                dx, dy = -dy, dx
            else:  # instruction == 'R'
                # 右转90度：(dx, dy) -> (dy, -dx)
                dx, dy = dy, -dx
        
        # 回到原点 或 方向改变（不是 (0, 1) 即朝北）
        return (x == 0 and y == 0) or (dx, dy) != (0, 1)
```

### 方法三：执行4次验证

```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        # 初始位置和方向
        x, y = 0, 0
        direction = 0  # 0=北, 1=东, 2=南, 3=西
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        
        # 执行4次指令序列
        for _ in range(4):
            for instruction in instructions:
                if instruction == 'G':
                    dx, dy = directions[direction]
                    x += dx
                    y += dy
                elif instruction == 'L':
                    direction = (direction - 1) % 4
                else:  # 'R'
                    direction = (direction + 1) % 4
        
        # 4次后如果回到原点，则被困在循环中
        return x == 0 and y == 0
```

### 方法四：详细注释版（便于理解）

```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        """
        判断机器人是否被困在循环中
        
        核心思想：
        1. 如果执行一次指令后回到原点 -> 循环
        2. 如果执行一次指令后方向改变 -> 最多4次后必定循环
        """
        # 位置坐标
        x, y = 0, 0
        
        # 方向索引：0=北, 1=东, 2=南, 3=西
        dir_idx = 0
        
        # 方向向量：北(0,1), 东(1,0), 南(0,-1), 西(-1,0)
        dir_vectors = [
            (0, 1),   # 北：y+1
            (1, 0),   # 东：x+1
            (0, -1),  # 南：y-1
            (-1, 0)   # 西：x-1
        ]
        
        # 执行一轮指令
        for cmd in instructions:
            if cmd == 'G':
                # 沿当前方向前进
                dx, dy = dir_vectors[dir_idx]
                x += dx
                y += dy
            elif cmd == 'L':
                # 左转：北->西->南->东->北
                # 索引减1，用模运算处理负数
                dir_idx = (dir_idx - 1) % 4
            elif cmd == 'R':
                # 右转：北->东->南->西->北
                # 索引加1
                dir_idx = (dir_idx + 1) % 4
        
        # 判断条件：
        # 1. 回到原点 (x==0 and y==0)
        # 2. 方向改变 (dir_idx != 0，即不朝北)
        # 满足任一条件即被困在循环中
        return (x == 0 and y == 0) or (dir_idx != 0)
```

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 是指令字符串的长度，只需遍历一次
- **空间复杂度**：O(1)，只使用常数额外空间

## 关键点总结

1. **方向是关键**：不仅要关注位置，更要关注方向的改变
2. **充要条件**：回到原点或方向改变，二者满足其一即可
3. **旋转对称性**：方向改变意味着多次执行后会形成对称轨迹
4. **只需执行一次**：不需要真的执行4次，判断一次即可
5. **方向表示**：可以用索引(0-3)或向量表示方向

## 易错点

1. **只判断位置**：容易只判断是否回到原点，忽略方向改变的情况
2. **方向索引计算**：左转时 `(dir - 1) % 4` 要注意负数模运算
3. **方向向量旋转**：
   - 左转90度：`(dx, dy) -> (-dy, dx)`
   - 右转90度：`(dx, dy) -> (dy, -dx)`
4. **理解错误**：误认为需要执行多次才能判断
5. **边界情况**：单个指令 `"G"` 或 `"L"` 的情况
