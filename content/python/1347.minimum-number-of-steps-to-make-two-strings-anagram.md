## 题目描述

给你两个长度相等的字符串 `s` 和 `t`。每一步中，你可以选择将 `t` 中的**任一字符**替换为**其他任意字符**。

返回使 `t` 成为 `s` 的异位词的最少步骤数。

**异位词** 是指字母相同，但排列不同（或相同）的字符串。

**示例 1：**
```
输入：s = "bab", t = "aba"
输出：1
解释：把 t 中第一个 'a' 替换为 'b'，t = "bba"，t 是 s 的异位词。
```

**示例 2：**
```
输入：s = "leetcode", t = "practice"
输出：5
解释：把 t 替换5个字符，使 t 成为 s 的异位词。
```

**示例 3：**
```
输入：s = "anagram", t = "mangaar"
输出：0
解释：s 和 t 已经是异位词了。
```

**提示：**
- `1 <= s.length <= 50000`
- `s.length == t.length`
- `s` 和 `t` 只包含小写英文字母

## 解题思路

**核心思路：统计字符频率差**

异位词要求两个字符串每个字母出现次数相同。

**分析：**
- 统计 `s` 中每个字符出现的次数 `freq_s`
- 统计 `t` 中每个字符出现的次数 `freq_t`
- 对于每个字符 `c`：
  - 若 `freq_s[c] > freq_t[c]`：`t` 中需要增加 `freq_s[c] - freq_t[c]` 个 `c`
  - 若 `freq_s[c] < freq_t[c]`：`t` 中需要减少 `freq_t[c] - freq_s[c]` 个 `c`

每次替换可以将多余的字符换成缺少的字符，因此步骤数 = 需要增加的字符总数（等于需要减少的字符总数）。

**结论：** 答案 = `sum(max(0, freq_s[c] - freq_t[c]) for c in 'abcdefghijklmnopqrstuvwxyz')`

等价于：`sum((freq_s - freq_t).values() for 正差值)`

## Python 代码实现

### 方法一：Counter 统计频率差（推荐）

```python
from collections import Counter

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        # 统计两个字符串的字符频率
        freq_s = Counter(s)
        freq_t = Counter(t)
        
        # 需要补充的字符数 = s 中比 t 多的字符数之和
        steps = 0
        for c in freq_s:
            if freq_s[c] > freq_t[c]:
                steps += freq_s[c] - freq_t[c]
        
        return steps
```

### 方法二：Counter 相减（Python 特色写法）

```python
from collections import Counter

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        # Counter 相减：只保留正差值（s 中比 t 多的部分）
        diff = Counter(s) - Counter(t)
        return sum(diff.values())
```

### 方法三：手动频率数组（不用 Counter）

```python
class Solution:
    def minSteps(self, s: str, t: str) -> int:
        # 使用数组代替字典，26个字母
        freq = [0] * 26
        
        # s 的字符计数 +1
        for c in s:
            freq[ord(c) - ord('a')] += 1
        
        # t 的字符计数 -1
        for c in t:
            freq[ord(c) - ord('a')] -= 1
        
        # 正值之和 = 需要替换的步数
        return sum(max(0, f) for f in freq)
```

### 方法四：排序后统计（适合理解）

```python
class Solution:
    def minSteps(self, s: str, t: str) -> int:
        # 排序后，异位词的排序结果相同
        # 统计 s 排序后与 t 排序后不同位置的字符数，除以2... 不对
        # 实际上排序法不如计数法直观，这里展示计数法的另一种实现
        
        from collections import Counter
        count = Counter(s)
        
        # 从 t 的字符中消耗 count
        for c in t:
            if count[c] > 0:
                count[c] -= 1
        
        # 剩余未被消耗的是需要额外补充的
        return sum(v for v in count.values() if v > 0)
```

### 方法五：数学方法（利用总差值为零）

```python
from collections import Counter

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        # 由于 s 和 t 长度相同，所以 freq_s 和 freq_t 的总和相等
        # 因此「s 中比 t 多的总量」= 「t 中比 s 多的总量」
        # 每次替换可以把 t 中多余的字符换成缺少的字符
        
        diff = Counter(s) - Counter(t)
        return sum(diff.values())
        
        # 等价写法：
        # return sum(max(0, Counter(s)[c] - Counter(t)[c]) for c in set(s + t))
```

## 图解示例

以 `s = "leetcode", t = "practice"` 为例：

```
s 的字符频率：{l:1, e:3, t:1, c:1, o:1, d:1}
t 的字符频率：{p:1, r:1, a:1, c:2, t:1, i:1, e:1}

差值（s - t）：
l: 1-0 = +1（需要增加）
e: 3-1 = +2（需要增加）
t: 1-1 = 0
c: 1-2 = -1（t 中有多余的 c）
o: 1-0 = +1（需要增加）
d: 1-0 = +1（需要增加）
p: 0-1 = -1（t 中有多余的 p）
r: 0-1 = -1（t 中有多余的 r）
a: 0-1 = -1（t 中有多余的 a）
i: 0-1 = -1（t 中有多余的 i）

需要增加的总量 = 1 + 2 + 1 + 1 = 5
（恰好等于需要减少的总量 = 1 + 1 + 1 + 1 + 1 = 5）

答案：5
```

## 关键点总结

1. 异位词要求每个字符出现次数相同
2. 每次替换可以同时减少一个多余字符并增加一个缺少字符
3. 步骤数 = s 中比 t 多的字符总数（等于 t 中比 s 多的字符总数）
4. Python 的 `Counter(s) - Counter(t)` 直接得到正差值字典

## 易错点

1. `Counter` 相减时，Python 自动忽略负值（只保留正差），这正是我们需要的
2. `sum(Counter(s) - Counter(t)).values()` 不对（sum 对字典 key 求和），应该是 `.values()`
3. 注意理解"步骤数 = 正差之和"：因为每步替换同时处理一个多余的和一个缺少的
