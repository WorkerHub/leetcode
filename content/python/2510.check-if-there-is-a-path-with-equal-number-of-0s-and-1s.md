## 题目描述

给你一个大小为 `m x n` 的二进制矩阵 `grid`，其中每个元素为 0 或 1。

请你判断矩阵中是否存在一条从左上角 `(0, 0)` 到右下角 `(m-1, n-1)` 的路径，使得路径上 0 的数目等于 1 的数目。

路径每一步只能向右或向下移动。

如果不存在这样的路径，返回 `false`；否则返回 `true`。

**示例 1：**

```
输入：grid = [[0,1,0,0],[0,1,0,0],[1,0,1,1]]
输出：true
```

**示例 2：**

```
输入：grid = [[1,1,0],[0,0,1],[1,0,0]]
输出：false
```

**提示：**

- `m == grid.length`, `n == grid[i].length`
- `2 <= m, n <= 100`
- `grid[i][j]` 为 0 或 1

## 解题思路

路径长度固定为 `m + n - 1` 步（含起点），若 `m + n - 1` 为偶数，则不可能有等量的 0 和 1。

设差值 d = (1的个数) - (0的个数)，则需要 d = 0，等价于路径上 0 和 1 各占一半。

**DP**：`dp[i][j]` 存储到达 `(i, j)` 时所有可能的 (1个数 - 0个数) 的集合。

- `dp[0][0] = {grid[0][0] == 1 ? 1 : -1}`
- 转移：从上方或左方到达，差值相应加 1 或减 1
- 答案：0 是否在 `dp[m-1][n-1]` 中

## Python 代码实现

### 方法一：DP + 集合（推荐）

```python
from typing import List

class Solution:
    def isThereAPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        # 路径长度为 m+n-1，若为偶数则不可能等量
        if (m + n - 1) % 2 == 0:
            return False

        # dp[i][j] = 到达 (i,j) 时所有可能的差值集合（1的数-0的数）
        INF = float('inf')
        dp = [None] * n
        for row in range(m):
            new_dp = [None] * n
            for col in range(n):
                # 当前格子的贡献：1 → +1，0 → -1
                delta = 1 if grid[row][col] == 1 else -1
                candidates = set()
                if row == 0 and col == 0:
                    candidates.add(delta)
                else:
                    if row > 0 and dp[col] is not None:
                        for v in dp[col]:
                            candidates.add(v + delta)
                    if col > 0 and new_dp[col - 1] is not None:
                        for v in new_dp[col - 1]:
                            candidates.add(v + delta)
                new_dp[col] = candidates
            dp = new_dp

        return 0 in dp[n - 1]
```

### 方法二：DP + 范围剪枝

```python
from typing import List

class Solution:
    def isThereAPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = m + n - 1
        if total % 2 == 0:
            return False

        # 用 (lo, hi) 表示可达差值的范围（连续整数区间）
        # 差值步长为 2（每次 +1 或 -1，奇偶性固定）
        # 简化：直接用集合
        dp = [[set() for _ in range(n)] for _ in range(m)]
        dp[0][0].add(1 if grid[0][0] == 1 else -1)

        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                delta = 1 if grid[i][j] == 1 else -1
                if i > 0:
                    for v in dp[i-1][j]:
                        dp[i][j].add(v + delta)
                if j > 0:
                    for v in dp[i][j-1]:
                        dp[i][j].add(v + delta)

        return 0 in dp[m-1][n-1]
```

## 复杂度分析

- 时间复杂度：O(m * n * path_len)，最坏情况集合大小为 O(m+n)
- 空间复杂度：O(m * n * (m+n))
- 优化后（用范围代替集合）：O(m * n)

## 关键点总结

1. 路径长度固定为 m+n-1，奇偶性预判可快速排除
2. DP 状态为"可达差值集合"，避免枚举所有路径
3. 差值的奇偶性在同一格是固定的，可用范围 [lo, hi] 替代集合优化

## 易错点

1. 路径长度为 m+n-1（含起点），不是 m+n
2. 要求路径恰好 0 和 1 各一半，目标差值为 0
3. 集合去重很重要，否则状态数会指数级增长
