## 题目描述

给你一个无向图，`n` 个节点（编号 0 到 n-1），每个节点有一个值 `vals[i]`。

`edges[i] = [a_i, b_i]` 表示节点 a 和节点 b 之间有一条**无权**边。

**星形图**：以节点 v 为中心，选择 0 条或多条相邻边，形成的图。

星形图的和 = 中心节点的值 + 所有被选中邻居节点的值（只有正值才选）。

返回所有星形图的 **最大和**。

**提示：**
- `n == vals.length`
- `1 <= n <= 10^5`
- `1 <= edges.length <= 10^5`
- `0 <= k <= n - 1`（隐含：选不超过 k 个邻居？题目中无 k 限制）

注：实际题目有参数 k，限制选至多 k 个邻居节点。

## 解题思路

**贪心：**

对每个节点 v，作为星形图中心：
1. 中心的值 = `vals[v]`
2. 从所有邻居中选至多 k 个正值最大的加入

使用贪心：对每个节点，将邻居值排序（降序），取前 k 个正值求和，加上中心值，就是以 v 为中心的最优星形图和。

答案 = 所有节点的最优星形图和的最大值。

## 代码实现

### 方法一：排序邻居（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxStarSum(self, vals: List[int], edges: List[List[int]], k: int) -> int:
        n = len(vals)
        adj = defaultdict(list)

        # 收集每个节点的邻居值（只保留正值）
        for a, b in edges:
            if vals[b] > 0:
                adj[a].append(vals[b])
            if vals[a] > 0:
                adj[b].append(vals[a])

        ans = max(vals)  # 至少可以选单个节点（0 条边）

        for v in range(n):
            # 对邻居值降序排序，取前 k 个
            neighbors = sorted(adj[v], reverse=True)
            star_sum = vals[v] + sum(neighbors[:k])
            ans = max(ans, star_sum)

        return ans
```

### 方法二：使用堆（仅保留最大 k 个）

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def maxStarSum(self, vals: List[int], edges: List[List[int]], k: int) -> int:
        n = len(vals)
        # top_k[v] = 节点 v 的前 k 大正邻居值之和
        adj = [[] for _ in range(n)]

        for a, b in edges:
            if vals[b] > 0:
                adj[a].append(vals[b])
            if vals[a] > 0:
                adj[b].append(vals[a])

        ans = max(vals)

        for v in range(n):
            # 取前 k 个最大正邻居值
            top_k_sum = sum(heapq.nlargest(k, adj[v]))
            ans = max(ans, vals[v] + top_k_sum)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序邻居 | O(m log m + n) | O(n + m) |
| 堆 | O(m log k + n) | O(n + m) |

## 关键点总结

1. 只选正值邻居（加负值只会减少总和）
2. 对每个中心节点，贪心地选最大的 k 个正邻居
3. 最终取所有星形图中的最大和

## 易错点

- k = 0 时星形图只有中心节点，答案可能是负数中最大的
- 初始答案应为 `max(vals)`（而不是 0），因为节点值可能为负数
