## 题目描述

给你一个二维整数数组 `intervals`，其中 `intervals[i] = [start_i, end_i]`（所有区间已按起始点升序排序且无重叠），以及一个整数 `size`。

你可以插入**一个长度为 `size` 的新区间** `[a, a + size - 1]`（`a` 可以是任意正整数）。

插入后，若干区间可能合并成**连通组**（相邻或重叠的区间合并为一组）。

返回插入新区间后，连通组的**最小数量**。

**示例：**
```
输入：intervals = [[1,2],[3,4],[6,7],[8,9],[11,12]], size = 3
输出：3
解释：插入 [4,6]，合并后变为 [1,2],[3,7],[8,9],[11,12]（等）
```

**提示：**
- `1 <= intervals.length <= 10^5`
- `1 <= start_i <= end_i <= 10^9`
- `1 <= size <= 10^9`

## 解题思路

**滑动窗口（双指针）：**

先统计不插入新区间时的连通组数量 `base`（已排好序的连续区间合并）。

然后，枚举新区间能覆盖哪些原有区间（从左到右的窗口），找最多能"额外合并"多少个连通组，用窗口内被覆盖的区间数来判断。

**关键观察：**
- 新区间 `[a, a+size-1]` 能覆盖所有 `start_i <= a+size-1` 且 `end_i >= a` 的区间。
- 滑动窗口：右端点 `r` 向右移动，保持 `intervals[l..r]` 都能被长度为 `size` 的新区间覆盖（即 `intervals[r][1] - intervals[l][0] + 1 <= size`）。

每个窗口 `[l, r]`，包含 `r - l + 1` 个区间，这些区间在连通组中占据若干组，合并后加上新区间变成 1 组。

实际上：合并前，这些原有区间已经形成若干连通组，插入新区间后这些组合并成 1 组（新区间把它们全连起来）。

最终答案 = `base - max_saved + 1`，其中 `max_saved` 是新区间最多能合并的额外连通组数。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minConnectedGroups(self, intervals: List[List[int]], size: int) -> int:
        n = len(intervals)
        
        # 计算原始连通组数量
        # 由于区间已排序无重叠，每个区间自成一组（但相邻区间可能连通）
        # 题目说"无重叠"，所以每个区间已经是独立的
        # 连通组：若 intervals[i][1] + 1 >= intervals[i+1][0]，则合并
        # 但题目说无重叠，所以相邻但不重叠的不合并？
        # 重新理解：区间的"连通"是指区间之间没有间隙（紧邻或重叠）
        # 原始区间无重叠，计算连通组数
        groups = 1
        for i in range(1, n):
            if intervals[i][0] > intervals[i-1][1] + 1:
                groups += 1
        
        # 枚举新区间覆盖的范围（右端点固定，左端点用二分或双指针）
        # 新区间长度为 size，能覆盖 [a, a+size-1]
        # 覆盖的原有区间 [l, r]：intervals[l][0] >= a 且 intervals[r][1] <= a+size-1
        # 即 intervals[r][1] - intervals[l][0] <= size - 1
        
        max_merge = 0  # 最多能合并的"额外组数"
        l = 0
        for r in range(n):
            # 保持窗口内的区间跨度不超过 size
            while intervals[r][1] - intervals[l][0] + 1 > size:
                l += 1
            # 窗口 [l, r] 内的连通组数
            window_groups = 1
            for i in range(l + 1, r + 1):
                if intervals[i][0] > intervals[i-1][1] + 1:
                    window_groups += 1
            # 插入新区间后，这些组合并为 1，额外节省 window_groups - 1 组
            # 但新区间本身加入（+1），净效果：减少 window_groups - 1 组
            max_merge = max(max_merge, window_groups - 1)
        
        return groups - max_merge + 1
```

### 方法二：优化滑动窗口（预处理组数）

```python
from typing import List

class Solution:
    def minConnectedGroups(self, intervals: List[List[int]], size: int) -> int:
        n = len(intervals)
        
        # 原始连通组数
        base = 1
        for i in range(1, n):
            if intervals[i][0] > intervals[i-1][1] + 1:
                base += 1
        
        # 预处理：prefix_groups[i] = intervals[0..i-1] 中的连通组数
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + (1 if i == 0 or intervals[i][0] > intervals[i-1][1] + 1 else 0)
        
        max_save = 0
        l = 0
        for r in range(n):
            while intervals[r][1] - intervals[l][0] + 1 > size:
                l += 1
            # 窗口 [l, r] 的组数 = prefix[r+1] - prefix[l]
            window_groups = prefix[r+1] - prefix[l]
            max_save = max(max_save, window_groups - 1)
        
        return base - max_save + 1
```

## 复杂度分析

- 时间复杂度：O(n)，滑动窗口一次遍历（方法二）
- 空间复杂度：O(n)，前缀组数数组

## 关键点总结

1. 新区间能覆盖的原区间范围用滑动窗口枚举：保持 `intervals[r][1] - intervals[l][0] + 1 <= size`。
2. 窗口内的连通组数用前缀和 O(1) 查询。
3. 答案 = 原组数 - 最大节省组数 + 1（新区间本身占 1 组）。

## 易错点

1. 窗口条件是区间端点跨度（`end_r - start_l + 1 <= size`），不是区间数量。
2. 连通性判断：`intervals[i][0] > intervals[i-1][1] + 1` 才是新组。
3. 答案减去 `max_save` 再加 1（新区间贡献 1 个组）。
