## 题目描述

给定一个序列 nums，检查是否能唯一地由子序列数组 sequences 重建。子序列数组 sequences 是一个二维数组，其中每个内部数组都是 nums 的一个子序列。

请你判断是否 nums 是唯一可以从 sequences 重建的序列。如果可以重建则返回 true，否则返回 false。

子序列的定义：从原序列中删除一些（可以是零个）元素，不改变剩余元素的相对顺序得到的序列。

**示例 1:**

```
输入: nums = [1,2,3], sequences = [[1,2],[1,3]]
输出: false
解释: 有两种可能的重建序列：[1,2,3] 和 [1,3,2]，因此返回 false。
```

**示例 2:**

```
输入: nums = [1,2,3], sequences = [[1,2]]
输出: false
解释: 序列 [1,2] 无法唯一确定 nums。
```

**示例 3:**

```
输入: nums = [1,2,3], sequences = [[1,2],[1,3],[2,3]]
输出: true
解释: 序列 [1,2]、[1,3] 和 [2,3] 可以唯一确定原序列 [1,2,3]。
```

**示例 4:**

```
输入: nums = [4,1,5,2,6,3], sequences = [[5,2,6,3],[4,1,5,2]]
输出: true
```

**提示:**

- 1 <= nums.length <= 10^4
- nums 仅包含不同的整数
- sequences[i] 是 nums 的子序列
- 1 <= sequences.length <= 10^4
- 1 <= sequences[i].length <= 10^4
- sequences 中的所有元素总数最多为 10^5

## 解题思路

这道题的核心是**拓扑排序**的唯一性判断。

**问题转化：**
1. 将 sequences 中的相邻关系转化为有向图
2. 判断这个有向图的拓扑排序是否唯一，且等于 nums

**唯一性的条件：**
1. 每一步拓扑排序中，入度为 0 的节点只能有 1 个（保证唯一性）
2. 拓扑排序的结果必须等于 nums
3. 所有 nums 中的数字都必须在 sequences 中出现

**拓扑排序步骤：**
1. 构建图：记录每个数字的后继节点和入度
2. 找到入度为 0 的节点作为起点
3. 每次只能有一个入度为 0 的节点（保证唯一性）
4. 按照 nums 的顺序验证拓扑排序结果

## Python 代码实现

### 方法一：拓扑排序（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def sequenceReconstruction(self, nums: List[int], sequences: List[List[int]]) -> bool:
        """
        拓扑排序验证唯一性
        时间复杂度: O(n + m)，n 是 nums 长度，m 是所有 sequences 的总长度
        空间复杂度: O(n + m)
        """
        # 构建图和入度表
        graph = defaultdict(set)  # 邻接表
        indegree = {num: 0 for num in nums}  # 入度
        
        # 检查 sequences 中是否包含 nums 中的所有数字
        all_nums = set()
        for seq in sequences:
            for num in seq:
                all_nums.add(num)
                if num not in indegree:
                    return False  # 出现了不在 nums 中的数字
        
        # 检查 nums 中的所有数字是否都在 sequences 中
        if len(all_nums) != len(nums):
            return False
        
        # 构建图的边
        for seq in sequences:
            for i in range(len(seq) - 1):
                u, v = seq[i], seq[i + 1]
                # 避免重复边
                if v not in graph[u]:
                    graph[u].add(v)
                    indegree[v] += 1
        
        # 拓扑排序
        queue = deque([num for num in nums if indegree[num] == 0])
        result = []
        
        while queue:
            # 关键：每次只能有一个入度为 0 的节点（唯一性）
            if len(queue) != 1:
                return False
            
            node = queue.popleft()
            result.append(node)
            
            # 更新后继节点的入度
            for neighbor in graph[node]:
                indegree[neighbor] -= 1
                if indegree[neighbor] == 0:
                    queue.append(neighbor)
        
        # 验证拓扑排序结果是否等于 nums
        return result == nums
```

### 方法二：简化的拓扑排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def sequenceReconstruction(self, nums: List[int], sequences: List[List[int]]) -> bool:
        """
        简化版拓扑排序
        """
        n = len(nums)
        graph = defaultdict(set)
        indegree = {num: 0 for num in nums}
        
        # 验证所有数字是否有效
        for seq in sequences:
            for num in seq:
                if num < 1 or num > n or num not in indegree:
                    return False
        
        # 构建图
        for seq in sequences:
            for i in range(len(seq) - 1):
                if seq[i + 1] not in graph[seq[i]]:
                    graph[seq[i]].add(seq[i + 1])
                    indegree[seq[i + 1]] += 1
        
        # 找到所有入度为 0 的节点
        idx = 0
        for i in range(n):
            # 每一步只能有一个选择
            count = sum(1 for num in nums if indegree[num] == 0)
            if count != 1:
                return False
            
            # 找到当前唯一的入度为 0 的节点
            current = None
            for num in nums:
                if indegree[num] == 0:
                    current = num
                    break
            
            # 验证是否与 nums[idx] 匹配
            if current != nums[idx]:
                return False
            
            # 标记为已访问（入度设为 -1）
            indegree[current] = -1
            
            # 更新后继节点的入度
            for neighbor in graph[current]:
                indegree[neighbor] -= 1
            
            idx += 1
        
        return True
```

### 方法三：相邻元素验证法

```python
from typing import List

class Solution:
    def sequenceReconstruction(self, nums: List[int], sequences: List[List[int]]) -> bool:
        """
        验证 nums 中每对相邻元素是否都出现在某个 sequence 中
        时间复杂度: O(n + m)
        空间复杂度: O(n)
        """
        n = len(nums)
        # 记录 nums 中每个数字的位置
        pos = {num: i for i, num in enumerate(nums)}
        
        # 检查每个 sequence 是否有效
        all_nums = set()
        pairs = set()  # 记录所有相邻对
        
        for seq in sequences:
            for i, num in enumerate(seq):
                # 检查数字是否在 nums 中
                if num not in pos:
                    return False
                all_nums.add(num)
                
                # 记录相邻对
                if i > 0:
                    # 检查顺序是否与 nums 一致
                    if pos[seq[i - 1]] >= pos[num]:
                        return False
                    pairs.add((seq[i - 1], num))
        
        # 检查是否所有数字都出现了
        if len(all_nums) != n:
            return False
        
        # 检查 nums 中的每对相邻元素是否都在 pairs 中
        for i in range(n - 1):
            if (nums[i], nums[i + 1]) not in pairs:
                return False
        
        return True
```

## 复杂度分析

**方法一和方法二（拓扑排序）：**
- 时间复杂度：O(n + m)，n 是 nums 长度，m 是所有 sequences 的总长度
- 空间复杂度：O(n + m)，存储图和入度信息

**方法三（相邻元素验证）：**
- 时间复杂度：O(n + m)
- 空间复杂度：O(n)

## 图解示例

以 nums = [1,2,3], sequences = [[1,2],[1,3],[2,3]] 为例：

```
Step 1: 构建图
sequences:
  [1,2]: 1 -> 2
  [1,3]: 1 -> 3
  [2,3]: 2 -> 3

图结构:
    1
   / \
  v   v
  2 -> 3

入度:
  1: 0 (起点)
  2: 1
  3: 2

Step 2: 拓扑排序
初始: queue = [1], result = []

第 1 步:
  queue 长度 = 1 ✓ (唯一)
  取出 1, result = [1]
  更新入度: 2的入度=0, 3的入度=1
  queue = [2]

第 2 步:
  queue 长度 = 1 ✓ (唯一)
  取出 2, result = [1, 2]
  更新入度: 3的入度=0
  queue = [3]

第 3 步:
  queue 长度 = 1 ✓ (唯一)
  取出 3, result = [1, 2, 3]
  queue = []

验证: result == nums ✓
返回: true
```

**反例：nums = [1,2,3], sequences = [[1,2],[1,3]]**

```
图结构:
    1
   / \
  v   v
  2   3

入度:
  1: 0
  2: 1
  3: 1

拓扑排序:
  第 1 步: queue = [1] ✓
  第 2 步: queue = [2, 3] ✗ (不唯一！)
  
返回: false
```

## 关键点总结

1. **拓扑排序的唯一性**：每一步只能有一个入度为 0 的节点
2. **图的构建**：从相邻元素关系构建有向图
3. **完整性检查**：确保所有数字都出现，且没有额外数字
4. **顺序验证**：拓扑排序结果必须与 nums 完全一致
5. **重复边处理**：使用 set 避免重复计算入度

## 易错点

1. **忘记检查数字范围**：
   - sequences 中可能出现不在 nums 中的数字
   - 需要验证所有数字的有效性

2. **忘记检查完整性**：
   - 所有 nums 中的数字必须在 sequences 中出现
   - 使用 set 统计所有出现过的数字

3. **重复边问题**：
   ```python
   # 错误：可能重复增加入度
   indegree[v] += 1
   
   # 正确：使用 set 避免重复
   if v not in graph[u]:
       graph[u].add(v)
       indegree[v] += 1
   ```

4. **唯一性判断**：
   - 必须每一步都只有一个选择
   - 而不是整体上有唯一解
