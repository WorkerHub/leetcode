## 题目描述

有一个特殊打字机，有 26 个字母排成一个圆圈，指针初始指向 `'a'`。每次可以顺时针或逆时针移动一格（1 秒），或者打印当前字母（1 秒）。

给你一个字符串 `word`，返回打印完整个 `word` 所需的**最短时间**。

**示例 1：**
```
输入：word = "abc"
输出：5
解释：a (1秒打印) → b (1秒移动+1秒打印) → c (1秒移动+1秒打印) = 5秒
```

**示例 2：**
```
输入：word = "bza"
输出：7
```

**提示：**
- `1 <= word.length <= 100`

---

## 解题思路

### 核心思想：贪心 - 每次选较短的移动方向

对每对相邻字母（前一个字母到当前字母），计算顺时针和逆时针的最短距离，取较小值加1（打印时间）。

初始时指针在 `'a'`，每步打印加 1 秒。

---

## 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def minTimeToType(self, word: str) -> int:
        total = 0
        prev = 'a'  # 初始位置

        for c in word:
            # 字母表上的距离（正方向）
            diff = abs(ord(c) - ord(prev))
            # 顺时针或逆时针，取较短路径，加 1 秒打印
            total += min(diff, 26 - diff) + 1
            prev = c

        return total
```

### 方法二：使用 zip（另一种写法）

```python
class Solution:
    def minTimeToType(self, word: str) -> int:
        prev_ord = ord('a')
        total = 0

        for c in word:
            cur_ord = ord(c)
            diff = abs(cur_ord - prev_ord)
            total += min(diff, 26 - diff) + 1
            prev_ord = cur_ord

        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(1) |
| 方法二 | O(n) | O(1) |

---

## 关键点总结

1. 两字母之间的最短圆形距离 = `min(diff, 26 - diff)`
2. 每个字母需要移动时间 + 1 秒打印
3. 初始位置 `'a'`，从第一个字母开始计算移动距离

---

## 易错点

- 圆形距离：最大正方向距离为 25，最短距离 = `min(diff, 26-diff)`
- 每个字母打印都需要额外 +1 秒
