## 题目描述

给你一个长度为 `n` 的整数数组 `prices`（巧克力价格），以及 `m` 次查询 `queries[i] = [ki, mi]`。

对于第 i 次查询，你要购买 `ki` 块巧克力：
- 你有会员卡，如果某块巧克力价格 <= `mi`，则免费（loss = 0）
- 否则，支付 `price - mi`（loss = price - mi）
- 选择最小化你的**相对损失**（总 loss）

返回一个数组，`answers[i]` = 第 i 次查询的最小相对损失。

**提示：**
- `1 <= prices.length <= 10^5`
- `1 <= prices[i] <= 10^9`
- `1 <= queries.length <= 10^5`
- `1 <= queries[i][0] <= prices.length`
- `1 <= queries[i][1] <= 10^9`

## 解题思路

**关键观察：**
- 排序后，价格 <= m 的从右侧便宜的选（免费）；价格 > m 的从左侧便宜的选（loss 最小）
- 排序 prices，前缀和加速区间求和

**对查询 (k, m)：**
- 设 pos = 最后一个 <= m 的位置（二分查找）
- 可以从左边（小于等于 m 的便宜价）取一些，从右边（大于 m）取一些
- 枚举从右边（>m）取 j 个，从左边取 k-j 个，最小化总 loss

## Python 代码实现

### 方法一：排序 + 前缀和 + 二分查找（推荐）

```python
import bisect
from typing import List

class Solution:
    def minimumRelativeLosses(self, prices: List[int], queries: List[List[int]]) -> List[int]:
        prices.sort()
        n = len(prices)

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + prices[i]

        def query(k: int, m: int) -> int:
            # 找最后一个 <= m 的位置
            # pos = 满足 prices[pos] <= m 的个数（0-indexed 之后）
            pos = bisect.bisect_right(prices, m)  # pos = 左侧 <=m 的数量

            ans = float('inf')
            # j = 从右边（>m）取的个数，范围 [max(0, k-pos), min(k, n-pos)]
            for j in range(max(0, k - pos), min(k, n - pos) + 1):
                left_count = k - j  # 从左边取的个数
                # 左边取最右（最贵的）前 left_count 个：loss=0（<=m 免费）
                # 实际取最右 left_count 个：下标 [pos-left_count, pos-1]
                # 右边取最左 j 个：下标 [pos, pos+j-1]，loss = sum - j*m
                left_loss = 0  # 价格 <=m，全免费

                # 右边 j 个的 loss
                right_sum = prefix[pos + j] - prefix[pos]
                right_loss = right_sum - j * m

                total = left_loss + right_loss
                ans = min(ans, total)

            return ans

        return [query(k, m) for k, m in queries]
```

### 方法二：优化（只考虑端点）

```python
import bisect
from typing import List

class Solution:
    def minimumRelativeLosses(self, prices: List[int], queries: List[List[int]]) -> List[int]:
        prices.sort()
        n = len(prices)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + prices[i]

        def calc(k: int, m: int) -> int:
            pos = bisect.bisect_right(prices, m)  # 左侧 <=m 的数量

            # j 从右（>m）取的数量
            j_lo = max(0, k - pos)   # 左边不够时必须从右取
            j_hi = min(k, n - pos)   # 右边最多只有 n-pos 个

            ans = float('inf')
            for j in range(j_lo, j_hi + 1):
                left_count = k - j
                # 左边取最右的 left_count 个（loss=0）
                # 右边取最左的 j 个（loss = sum(prices[pos:pos+j]) - j*m）
                right_loss = prefix[pos + j] - prefix[pos] - j * m
                ans = min(ans, right_loss)  # left_loss = 0

            return ans

        return [calc(k, m) for k, m in queries]
```

## 复杂度分析

- 时间复杂度：O(n log n + q × k)，排序 O(n log n)，每次查询最多 O(k) 枚举
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 排序后，价格 <= m 的选择 loss = 0（免费）；价格 > m 的 loss = price - m
2. 最优策略：从右边（>m）取最便宜的（最左边），从左边（<=m）取（全免费）
3. 前缀和快速求区间 sum，二分快速找 m 的位置

## 易错点

1. 二分找位置用 `bisect_right(prices, m)` 返回的是 <=m 的个数
2. j 的范围由左右两侧可用数量约束
3. 左侧 loss 为 0 是因为 <= m 全免费
