## 题目描述

给你一棵以节点 0 为根的树，共 n 个节点，边权为正整数。节点 i 的值为 `nums[i]`。

路径是从根到某个节点的路径。如果路径上所有节点的值都不同，则称该路径为"特殊路径"。

返回最长特殊路径的长度（边权之和），以及该长度下最少节点数。

**提示：**
- `2 <= n <= 5 * 10^4`
- `1 <= nums[i] <= 5 * 10^4`

## 解题思路

DFS + 双指针（滑动窗口）：

维护从根到当前节点的路径，用哈希表记录每个值最近出现的位置（深度）。

当添加节点 v 时，若 `nums[v]` 已在路径上出现，则路径左端必须推进到该重复位置之后。

用"路径起始深度"来裁剪，维护当前有效路径的起始位置。

## Python 代码实现

### 方法一：DFS + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestSpecialPath(self, edges: List[List[int]], nums: List[int]) -> List[int]:
        n = len(nums)
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # 维护路径信息
        # path_dist[d] = 从根到深度 d 的节点的路径长度（前缀和）
        prefix_dist = [0] * (n + 1)
        # last_seen[val] = 路径上值为 val 的最近节点的深度
        last_seen = {}
        # 当前路径起始深度（有效路径从这里开始）
        # 用栈维护每层的 last_seen 信息，便于回溯

        ans_len = 0
        ans_nodes = 1

        def dfs(u, parent, depth, start_depth):
            nonlocal ans_len, ans_nodes

            # 检查 nums[u] 是否在路径上出现过
            val = nums[u]
            prev_depth = last_seen.get(val, -1)
            new_start = max(start_depth, prev_depth + 1)

            # 当前路径长度（从 new_start 深度的节点到 u）
            cur_len = prefix_dist[depth] - prefix_dist[new_start]
            cur_nodes = depth - new_start + 1

            if cur_len > ans_len or (cur_len == ans_len and cur_nodes < ans_nodes):
                ans_len = cur_len
                ans_nodes = cur_nodes

            # 记录当前值
            last_seen[val] = depth

            for v, w in graph[u]:
                if v != parent:
                    prefix_dist[depth + 1] = prefix_dist[depth] + w
                    dfs(v, u, depth + 1, new_start)

            # 恢复 last_seen
            if prev_depth == -1:
                del last_seen[val]
            else:
                last_seen[val] = prev_depth

        prefix_dist[0] = 0
        dfs(0, -1, 0, 0)
        return [ans_len, ans_nodes]
```

### 方法二：DFS + 路径栈

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestSpecialPath(self, edges: List[List[int]], nums: List[int]) -> List[int]:
        n = len(nums)
        adj = defaultdict(list)
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))

        best = [0, 1]  # [max_length, min_nodes]
        path_vals = {}  # val -> depth in current path
        path_dist = [0]  # prefix distances

        def dfs(u, par, depth, start):
            val = nums[u]
            prev = path_vals.get(val, -1)
            new_start = max(start, prev + 1)

            cur_len = path_dist[depth] - path_dist[new_start]
            cur_nodes = depth - new_start + 1

            if (cur_len > best[0] or
                    (cur_len == best[0] and cur_nodes < best[1])):
                best[0] = cur_len
                best[1] = cur_nodes

            path_vals[val] = depth
            for v, w in adj[u]:
                if v != par:
                    path_dist.append(path_dist[depth] + w)
                    dfs(v, u, depth + 1, new_start)
                    path_dist.pop()

            if prev == -1:
                del path_vals[val]
            else:
                path_vals[val] = prev

        dfs(0, -1, 0, 0)
        return best
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点只访问一次
- 空间复杂度：O(n)，递归栈和路径信息

## 关键点总结

1. DFS 维护从根到当前节点的路径
2. 哈希表记录路径上每个值的最近深度
3. 双指针思想：有效路径起点 = max(当前起点, 重复值位置 + 1)
4. 回溯时恢复哈希表状态

## 易错点

1. 路径起始深度单调不减（只能向右移动）
2. 答案要求节点数最少，不是路径最短（在长度相同时选节点少的）
3. 前缀距离数组用于 O(1) 计算任意路径段的长度
