## 题目描述

有效 IP 地址正好由四个整数（每个整数位于 `0` 到 `255` 之间组成，且不能含有前导 `0`），整数之间用 `'.'` 分隔。

例如：`"0.1.2.201"` 和 `"192.168.1.1"` 是有效 IP 地址，但是 `"0.011.255.245"`、`"192.168.1.312"` 和 `"192.168@1.1"` 是无效 IP 地址。

给定一个只包含数字的字符串 `s`，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在 `s` 中插入 `'.'` 来形成。你不能重新排序或删除 `s` 中的任何数字。你可以按任何顺序返回答案。

**示例 1：**
```
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

**示例 2：**
```
输入：s = "0000"
输出：["0.0.0.0"]
```

**示例 3：**
```
输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
```

**提示：**
- `1 <= s.length <= 20`
- `s` 仅由数字组成

## 解题思路

**核心思想：回溯 + 剪枝**

IP 地址的约束条件：
1. 必须恰好有 4 段
2. 每段的值在 `[0, 255]` 之间
3. 每段不能有前导零（除了单独的 "0"）
4. 必须用完所有字符

**回溯框架：**
1. 选择：在当前位置后插入 `'.'`，分割出一段
2. 约束：每段长度 1-3，值在 0-255，无前导零
3. 目标：分成 4 段且用完所有字符

**剪枝优化：**
- 如果剩余字符太多或太少，无法组成剩余的段，提前返回
- 每段长度最多 3 位，最少 1 位

## Python 代码实现

### 方法一：回溯法（推荐）

```python
from typing import List

class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        result = []
        n = len(s)
        
        # 长度检查：IP 地址最少 4 位（如 0.0.0.0），最多 12 位（如 255.255.255.255）
        if n < 4 or n > 12:
            return result
        
        def is_valid(segment: str) -> bool:
            """检查一段是否合法"""
            # 检查前导零
            if len(segment) > 1 and segment[0] == '0':
                return False
            # 检查范围
            return 0 <= int(segment) <= 255
        
        def backtrack(start: int, path: List[str]):
            """
            start: 当前处理的起始位置
            path: 当前已分割的段
            """
            # 递归终止条件
            if len(path) == 4:
                # 必须恰好用完所有字符
                if start == n:
                    result.append('.'.join(path))
                return
            
            # 剪枝：剩余字符数量检查
            remain_segments = 4 - len(path)  # 还需要几段
            remain_chars = n - start  # 还剩几个字符
            
            # 剩余字符太少或太多都不行
            if remain_chars < remain_segments or remain_chars > remain_segments * 3:
                return
            
            # 尝试分割 1-3 位
            for length in range(1, 4):
                # 不能超出边界
                if start + length > n:
                    break
                
                # 获取当前段
                segment = s[start:start + length]
                
                # 检查是否合法
                if is_valid(segment):
                    # 选择当前段
                    path.append(segment)
                    # 递归处理剩余部分
                    backtrack(start + length, path)
                    # 撤销选择
                    path.pop()
        
        backtrack(0, [])
        return result
```

### 方法二：迭代法（三层循环）

```python
from typing import List

class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        result = []
        n = len(s)
        
        if n < 4 or n > 12:
            return result
        
        # 尝试所有可能的分割点
        # i, j, k 分别是第一、二、三个点的位置
        for i in range(1, min(4, n - 2)):  # 第一段：[0, i)
            for j in range(i + 1, min(i + 4, n - 1)):  # 第二段：[i, j)
                for k in range(j + 1, min(j + 4, n)):  # 第三段：[j, k)
                    # 第四段：[k, n)
                    
                    # 分割出四段
                    seg1 = s[0:i]
                    seg2 = s[i:j]
                    seg3 = s[j:k]
                    seg4 = s[k:n]
                    
                    # 检查每段是否合法
                    if (self.is_valid(seg1) and 
                        self.is_valid(seg2) and 
                        self.is_valid(seg3) and 
                        self.is_valid(seg4)):
                        result.append(f"{seg1}.{seg2}.{seg3}.{seg4}")
        
        return result
    
    def is_valid(self, segment: str) -> bool:
        """检查一段是否合法"""
        if not segment or len(segment) > 3:
            return False
        if len(segment) > 1 and segment[0] == '0':
            return False
        return 0 <= int(segment) <= 255
```

### 方法三：回溯法（字符串拼接版）

```python
from typing import List

class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        result = []
        n = len(s)
        
        if n < 4 or n > 12:
            return result
        
        def backtrack(start: int, segment_count: int, current: str):
            """
            start: 当前起始位置
            segment_count: 已有段数
            current: 当前构建的 IP 地址
            """
            # 已经有 4 段且用完所有字符
            if segment_count == 4 and start == n:
                result.append(current[:-1])  # 去掉最后一个点
                return
            
            # 段数已满但字符没用完，或字符用完但段数不足
            if segment_count == 4 or start == n:
                return
            
            # 尝试 1-3 位
            for length in range(1, 4):
                if start + length > n:
                    break
                
                segment = s[start:start + length]
                
                # 检查合法性
                if len(segment) > 1 and segment[0] == '0':
                    continue
                if int(segment) > 255:
                    continue
                
                # 递归
                backtrack(start + length, segment_count + 1, current + segment + '.')
        
        backtrack(0, 0, '')
        return result
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(3^4 × n) = O(n)，最多尝试 3^4 = 81 种分割方式，每次验证 O(1)
- 空间复杂度：O(n)，递归栈深度为 4，存储结果需要 O(n)

**方法二：**
- 时间复杂度：O(1)，三层循环固定次数（最多 3 × 3 × 3 = 27）
- 空间复杂度：O(1)，不考虑结果存储

## 关键点总结

1. **IP 地址规则**：4 段、每段 0-255、无前导零（除了 "0"）
2. **回溯三要素**：选择（分割 1-3 位）、约束（合法性检查）、目标（4 段且用完）
3. **剪枝优化**：检查剩余字符是否能组成剩余段数
4. **边界处理**：字符串长度必须在 [4, 12] 之间
5. **前导零判断**：长度 > 1 且首字符为 '0' 时非法

## 易错点

1. **前导零处理**：
   - "01" 是非法的（有前导零）
   - "0" 是合法的（单独的零）
   - "10" 是合法的（零不在开头）

2. **边界情况**：
   - 字符串长度不足 4 或超过 12，直接返回空
   - 每段最多 3 位数字

3. **剪枝条件**：
   - 剩余字符太少：`remain_chars < remain_segments`
   - 剩余字符太多：`remain_chars > remain_segments * 3`

4. **回溯撤销**：使用列表需要 pop，使用字符串拼接无需显式撤销

5. **结果格式**：用 `'.'` 连接四段，注意不要多余的点

这道题是回溯算法的经典应用：

1. **理解约束**：
   - 先明确 IP 地址的所有规则
   - 理解什么情况下可以剪枝

2. **回溯模板**：
   ```python
   def backtrack(start, path):
       if 满足条件:
           记录结果
           return
       
       if 剪枝条件:
           return
       
       for 选择 in 选择列表:
           if 合法:
               做选择
               backtrack(...)
               撤销选择
   ```

3. **调试技巧**：
   - 打印每次分割的结果
   - 检查剪枝条件是否正确
   - 验证边界情况

- 忘记检查前导零
