## 题目描述

给你一个字符串 `s`，它仅由字母 `'a'` 和 `'b'` 组成。每一次删除操作都可以从 `s` 中删除一个回文子序列。

返回删除给定字符串中所有字符（清空字符串）所需的最少删除次数。

「子序列」定义：如果一个字符串可以通过删除原字符串某些字符而不改变原字符顺序得到，那么这个字符串就是原字符串的一个子序列。

「回文」定义：如果一个字符串向前和向后读是一致的，那么这个字符串就是一个回文。

**示例 1：**
```
输入：s = "ababa"
输出：1
解释：字符串本身就是回文序列，只需删除一次。
```

**示例 2：**
```
输入：s = "abb"
输出：2
解释：
"abb" -> "bb" -> ""。
先删除回文子序列 "a"，再删除 "bb"。
```

**示例 3：**
```
输入：s = "baabb"
输出：2
解释：
先删除回文子序列 "bab"，再删除 "ab"... 不对，"ab" 不是回文。
应该先删除所有 'a'（"aaa" 是回文），再删除所有 'b'（"bb" 是回文）。
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 只包含字母 `'a'` 和 `'b'`

## 解题思路

**核心洞察：字符串只含 'a' 和 'b'，这是关键！**

由于只有两种字符，最多只需要 **2 步**就能清空字符串：
- 第一步：删除所有 'a'（"aaaa...a" 是回文子序列）
- 第二步：删除所有 'b'（"bbbb...b" 是回文子序列）

因此答案只有三种可能：
1. **0 步**：字符串为空（特殊情况）
2. **1 步**：字符串本身是回文，一次就能删完
3. **2 步**：字符串不是回文，两步删完（先删所有 'a'，再删所有 'b'）

**判断是否是回文**：使用双指针从两端向中间比较。

## Python 代码实现

### 方法一：判断回文（推荐）

```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        # 字符串为空，返回 0
        if not s:
            return 0
        
        # 判断 s 是否是回文
        # 双指针法
        left, right = 0, len(s) - 1
        is_palindrome = True
        while left < right:
            if s[left] != s[right]:
                is_palindrome = False
                break
            left += 1
            right -= 1
        
        # 是回文返回 1，否则返回 2
        return 1 if is_palindrome else 2
```

### 方法二：Python 切片判断回文（简洁版）

```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        if not s:
            return 0
        # s[::-1] 是 s 的反转，若与原字符串相等则为回文
        return 1 if s == s[::-1] else 2
```

### 方法三：一行写法

```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        # 利用 Python 的三元表达式和切片操作
        return 0 if not s else (1 if s == s[::-1] else 2)
```

### 方法四：分情况讨论（详细注释版，适合新手）

```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        # 情况 1：空字符串，0 步
        if len(s) == 0:
            return 0
        
        # 情况 2：检查 s 是否为回文
        # 回文的定义：正读和反读相同
        def is_palindrome(string: str) -> bool:
            return string == string[::-1]
        
        # 如果 s 本身是回文，1 步删完
        if is_palindrome(s):
            return 1
        
        # 否则 2 步删完：
        # 第 1 步：删除所有 'a'（所有 'a' 组成的子序列是回文）
        # 第 2 步：删除所有 'b'（所有 'b' 组成的子序列是回文）
        return 2
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（双指针） | O(n) | O(1) |
| 方法二/三（切片） | O(n) | O(n) |

- **时间复杂度**：判断回文需要 O(n)，其他操作 O(1)
- **空间复杂度**：双指针只需常数空间；切片方式需要 O(n) 额外空间存储反转字符串

## 关键点总结

1. 字符串只含 'a' 和 'b'，所以最多 2 步就能清空（分别删所有 'a' 和 'b'）
2. 如果字符串本身是回文，1 步即可删完
3. 空字符串是边界情况，返回 0
4. 答案只有 0、1、2 三种可能，无需复杂算法

## 易错点

1. 忽略空字符串的情况，题目说 `1 <= s.length`，但有时也需要考虑
2. 对"子序列"和"子串"的混淆：子序列不要求连续，因此所有 'a' 可以作为一个回文子序列一次删除
3. 题目只有 'a' 和 'b' 两种字符，这是关键约束，不能推广到任意字符集

## 图解示例

```
s = "baabb"

不是回文（b ≠ b 的最后一位... b-a-a-b-b，反转是 b-b-a-a-b，不相等）

步骤 1：删除所有 'a' 的子序列 "aa"（回文）→ 剩余 "bbb"
步骤 2：删除所有 'b' 的子序列 "bbb"（回文）→ 空字符串

共 2 步
```
