## 题目描述

给你一个整数数组 `nums`，和一个表示限制的整数 `limit`，请你返回最长连续子数组的长度，该子数组中的任意两个元素之间的绝对差必须小于或等于 `limit`。

如果不存在满足条件的子数组，则返回 `0`。

**示例 1：**
```
输入：nums = [8,2,4,7], limit = 4
输出：2
解释：
所有子数组如下：
[8] 最大绝对差 0 <= 4，长度 1
[8,2] 最大绝对差 6 > 4，不满足
[8,2,4] 最大绝对差 6 > 4，不满足
[8,2,4,7] 不满足
[2] 长度 1
[2,4] 最大绝对差 2 <= 4，长度 2
[2,4,7] 最大绝对差 5 > 4，不满足
[4] 长度 1
[4,7] 最大绝对差 3 <= 4，长度 2
[7] 长度 1
最长满足条件的子数组长度为 2。
```

**示例 2：**
```
输入：nums = [10,1,2,4,7,2], limit = 5
输出：4
解释：满足条件的最长子数组是 [2,4,7,2]，其最大绝对差为 5。
```

**示例 3：**
```
输入：nums = [4,2,2,2,4,4,2,2], limit = 0
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= limit <= 10^9`

## 解题思路

**子数组中最大绝对差 = 最大值 - 最小值**（因为最大差一定在最大值和最小值之间取得）。

因此问题转化为：找最长的窗口 `[left, right]`，使得窗口内的 `max - min <= limit`。

**关键：如何高效维护滑动窗口的最大值和最小值？**

**方法：双单调双端队列**
- 用一个单调递减队列 `max_dq` 维护窗口最大值（队头为最大值）。
- 用一个单调递增队列 `min_dq` 维护窗口最小值（队头为最小值）。
- 滑动窗口右移时，维护两个队列；若 `max - min > limit`，左移窗口并更新队列。

## Python 代码实现

### 方法一：双单调双端队列（推荐，O(n)）

```python
from typing import List
from collections import deque

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        # max_dq: 单调递减队列，存下标，队头为窗口内最大值的下标
        max_dq = deque()
        # min_dq: 单调递增队列，存下标，队头为窗口内最小值的下标
        min_dq = deque()

        left = 0
        result = 0

        for right, num in enumerate(nums):
            # 维护 max_dq：保持递减，弹出所有比当前值小的
            while max_dq and nums[max_dq[-1]] <= num:
                max_dq.pop()
            max_dq.append(right)

            # 维护 min_dq：保持递增，弹出所有比当前值大的
            while min_dq and nums[min_dq[-1]] >= num:
                min_dq.pop()
            min_dq.append(right)

            # 如果当前窗口不满足条件，收缩左边界
            while nums[max_dq[0]] - nums[min_dq[0]] > limit:
                left += 1
                # 弹出已不在窗口内的队头
                if max_dq[0] < left:
                    max_dq.popleft()
                if min_dq[0] < left:
                    min_dq.popleft()

            # 更新最长长度
            result = max(result, right - left + 1)

        return result
```

### 方法二：有序容器（SortedList）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        sl = SortedList()  # 有序列表，支持 O(log n) 插入和删除
        left = 0
        result = 0

        for right, num in enumerate(nums):
            sl.add(num)  # 加入当前元素

            # 若窗口不满足条件，收缩左边界
            while sl[-1] - sl[0] > limit:
                sl.remove(nums[left])
                left += 1

            result = max(result, right - left + 1)

        return result
```

### 方法三：堆（不常见，效率较低）

```python
from typing import List
import heapq

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        # 使用两个堆（最大堆和最小堆）维护窗口最值
        # 注意：堆删除任意元素不是 O(1)，效率低于双端队列方法
        # 此处使用懒删除
        max_heap = []  # 最大堆（存负数）
        min_heap = []  # 最小堆
        left = 0
        result = 0

        for right, num in enumerate(nums):
            heapq.heappush(max_heap, (-num, right))
            heapq.heappush(min_heap, (num, right))

            # 检查最大值和最小值
            # 懒删除：弹出已不在窗口的元素
            while max_heap[0][1] < left:
                heapq.heappop(max_heap)
            while min_heap[0][1] < left:
                heapq.heappop(min_heap)

            # 若不满足条件，收缩
            while -max_heap[0][0] - min_heap[0][0] > limit:
                left += 1
                while max_heap[0][1] < left:
                    heapq.heappop(max_heap)
                while min_heap[0][1] < left:
                    heapq.heappop(min_heap)

            result = max(result, right - left + 1)

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（双单调队列） | O(n) | O(n) |
| 方法二（SortedList） | O(n log n) | O(n) |
| 方法三（堆） | O(n log n) | O(n) |

- 方法一最优，每个元素最多进出队列各一次，均摊 O(1)。

## 图解示例

```
nums = [8,2,4,7], limit = 4

right=0, num=8:
  max_dq=[0], min_dq=[0]
  max=8, min=8, 差=0 <= 4
  窗口 [0,0]，长度 1

right=1, num=2:
  max_dq=[0,1]（8>2，直接加），min_dq=[1]（2<8，弹出0再加）
  max=8, min=2, 差=6 > 4
  left=1，max_dq[0]=0 < 1，弹出 -> max_dq=[1]
  min_dq[0]=1 >= 1，不弹
  差=2-2=0 <= 4，窗口 [1,1]，长度 1

right=2, num=4:
  max_dq=[1,2]（4>2，弹出1再加，但等等：nums[1]=2 <= 4，弹出）
  实际：max_dq 弹出 nums[dq[-1]]=2 <= 4，弹出下标1，加下标2 -> max_dq=[2]
  min_dq=[1,2]（4>2，直接加）
  max=4, min=2, 差=2 <= 4
  窗口 [1,2]，长度 2，result=2

right=3, num=7:
  max_dq：7 > 4，弹出2，加3 -> max_dq=[3]
  min_dq：7 > 4，直接加 -> min_dq=[1,2,3]
  max=7, min=2, 差=5 > 4
  left=2, min_dq[0]=1 < 2，弹出 -> min_dq=[2,3]
  max=7, min=4, 差=3 <= 4
  窗口 [2,3]，长度 2

最终 result = 2
```

## 关键点总结

1. 子数组最大差 = 最大值 - 最小值，因此问题等价于控制窗口内的最大值和最小值之差。
2. 双单调双端队列是维护滑动窗口最值的经典技巧，时间复杂度 O(n)。
3. `max_dq` 单调递减（队头最大），`min_dq` 单调递增（队头最小），均存下标。
4. 收缩窗口时需同时检查两个队列的队头是否已离开窗口。

## 易错点

- 弹出条件写反：`max_dq` 应在新元素 `>=` 队尾时弹出（保持递减）。
- 收缩左边界时，忘记检查队头下标是否已小于 `left`，导致使用了过期的最大/最小值。
- `SortedList` 需要安装 `sortedcontainers` 库（LeetCode 上可用，本地需 `pip install sortedcontainers`）。
