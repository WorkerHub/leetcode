## 题目描述

每次操作会改变文件系统的当前文件夹位置：
- `"../"` — 移动到父文件夹（若已在主文件夹则停留）
- `"./"` — 停留在当前文件夹
- `"x/"` — 移动到子文件夹 `x`

给你一个字符串列表 `logs`，表示操作序列，初始位于主文件夹。

返回执行完所有操作后，回到主文件夹所需的**最少操作数**（即当前深度）。

**示例 1：**
```
输入：logs = ["d1/","d2/","../","d21/","./"]
输出：2
解释：最终在 d1/d21/，需要 2 步回主文件夹。
```

**示例 2：**
```
输入：logs = ["d1/","d2/","./","d3/","../","d31/"]
输出：3
```

**提示：**
- `1 <= logs.length <= 10^3`

## 解题思路

### 计数器模拟

只需追踪当前目录的**深度**，不需要真正维护路径：
- `"../"` → 深度减 1（最小为 0）
- `"./"` → 深度不变
- `"x/"` → 深度加 1

## 代码实现

### 方法一：计数器（推荐，最简洁）

```python
from typing import List

class Solution:
    def minOperations(self, logs: List[str]) -> int:
        depth = 0
        for log in logs:
            if log == '../':
                depth = max(0, depth - 1)  # 不低于主文件夹
            elif log == './':
                pass  # 不变
            else:
                depth += 1  # 进入子文件夹
        return depth
```

### 方法二：栈模拟（更直观）

```python
from typing import List

class Solution:
    def minOperations(self, logs: List[str]) -> int:
        stack = []  # 用栈模拟路径
        for log in logs:
            if log == '../':
                if stack:
                    stack.pop()  # 返回上一层
            elif log == './':
                pass  # 原地不动
            else:
                stack.append(log)  # 进入子文件夹
        return len(stack)  # 栈深度即为距主文件夹的步数
```

## 复杂度分析

- **时间复杂度**：O(N)，N 为操作数
- **空间复杂度**：方法一 O(1)，方法二 O(N)

## 关键点总结

1. 只需追踪深度，不需要存储实际路径
2. `"../"` 深度减 1，最小为 0（不能超过主文件夹）
3. `"./"` 不变，其他均为进入子文件夹加 1

## 易错点

- `"../"` 在主文件夹时不能让深度变成负数
- 注意字符串完全匹配（`"../"` 不是 `".."`）
