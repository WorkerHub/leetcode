## 题目描述

有 `n` 个学生和 `k` 个组，将 `n` 个学生分配到 `k` 个组中，每组至少有 1 名学生。求分配方式的总数，结果对 `10^9 + 7` 取模。

（组内学生无顺序，组之间有区别）

这等价于计算第二类 Stirling 数 `S(n, k)` × `k!`（有序划分 = 满射数），或直接用容斥原理计算将 n 个不同球放入 k 个不同有区别的盒子（每盒至少一个）的方案数。

**示例 1：**
```
输入：n = 3, k = 2
输出：6
解释：将 3 个学生 {1,2,3} 分成 2 组，共 6 种方式。
```

**示例 2：**
```
输入：n = 4, k = 2
输出：14
解释：第二类 Stirling 数 S(4,2) = 7，乘以 2! = 2，得 14。
```

**提示：**
- `1 <= k <= n <= 500`

## 解题思路

经典组合数学问题：n 个不同元素分到 k 个不同的、非空的盒子中。

**容斥原理：**

$$f(n, k) = \sum_{i=0}^{k} (-1)^i \binom{k}{i} (k-i)^n$$

或者等价地，用第二类 Stirling 数：
$$S(n, k) = \frac{1}{k!} \sum_{i=0}^{k} (-1)^{k-i} \binom{k}{i} i^n$$

答案为 $k! \cdot S(n, k)$，展开后即容斥公式。

**DP 方法：**

$dp[i][j]$ = 将前 i 个学生分配到 j 个非空组的方案数。

$$dp[i][j] = j \cdot dp[i-1][j] + dp[i-1][j-1]$$

- 第 i 个学生加入已有的 j 个组中的某一组：$j \cdot dp[i-1][j]$
- 第 i 个学生单独开一个新组：$dp[i-1][j-1]$

## Python 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def countWays(self, n: int, k: int) -> int:
        MOD = 10**9 + 7

        if k > n:
            return 0

        # dp[i][j]: 将 i 个学生分到 j 个非空组的方案数
        # 这里组有区别（有序分组）
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 1  # 0 个学生放入 0 个组，1 种方式

        for i in range(1, n + 1):
            for j in range(1, min(i, k) + 1):
                # 第 i 个学生加入已有组之一
                dp[i][j] = (j * dp[i-1][j]) % MOD
                # 第 i 个学生单独开新组
                dp[i][j] = (dp[i][j] + dp[i-1][j-1]) % MOD

        return dp[n][k]
```

### 方法二：容斥原理

```python
from math import comb

class Solution:
    def countWays(self, n: int, k: int) -> int:
        MOD = 10**9 + 7

        # f(n,k) = sum_{i=0}^{k} (-1)^i * C(k,i) * (k-i)^n
        result = 0
        for i in range(k + 1):
            term = comb(k, i) * pow(k - i, n, MOD)
            if i % 2 == 0:
                result = (result + term) % MOD
            else:
                result = (result - term + MOD) % MOD

        return result
```

## 复杂度分析

- 时间复杂度：方法一 O(nk)；方法二 O(k log n)（用快速幂）
- 空间复杂度：方法一 O(nk)；方法二 O(1)

## 关键点总结

1. 本质是第二类 Stirling 数乘以 k!（若组有区别），或纯第二类 Stirling 数（若组无区别）
2. DP 转移式体现了"每个新元素要么进已有组，要么开新组"
3. 容斥公式是计算满射方案数的标准方法

## 易错点

1. k > n 时无法每组至少一人，直接返回 0
2. 区分"组有区别"和"组无区别"两种情况
