## 题目描述

给你一个整数数组 `nums`，其中恰好有两个元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。你可以按任意顺序返回答案。

**进阶：** 你的算法应该具有线性时间复杂度。你能否仅使用常数空间复杂度来实现？

**示例 1：**

```
输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5,3] 也是有效的答案
```

**示例 2：**

```
输入：nums = [-1,0]
输出：[-1,0]
```

**示例 3：**

```
输入：nums = [0,1]
输出：[1,0]
```

**提示：**
- `2 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 除两个数字只出现一次外，其余所有数字均出现两次

## 解题思路

这道题是"只出现一次的数字"系列的进阶版，需要用到位运算的技巧。

核心思想：
1. 利用异或运算的性质：`a ^ a = 0`，`a ^ 0 = a`
2. 将所有数字异或，得到两个只出现一次的数字的异或结果
3. 找到这个结果中任意一个为 1 的位（说明两个数在这一位不同）
4. 根据这一位将数组分成两组，每组包含一个只出现一次的数字
5. 分别对两组进行异或，得到最终结果

关键技巧：
- 异或运算：相同为 0，不同为 1
- 分组依据：选择任意一个为 1 的位进行分组
- 获取最低位的 1：`x & (-x)` 或 `x & ~(x-1)`

## Python 代码实现

### 方法一：位运算（推荐）⭐

```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        """
        位运算：异或 + 分组
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 第一步：将所有数字异或，得到两个只出现一次的数字的异或结果
        xor_result = 0
        for num in nums:
            xor_result ^= num
        
        # 第二步：找到 xor_result 中任意一个为 1 的位
        # 使用 x & (-x) 获取最低位的 1
        # 例如：xor_result = 6 (0110), -xor_result = -6 (1010)
        #       xor_result & (-xor_result) = 0010 (即第 2 位)
        diff_bit = xor_result & (-xor_result)
        
        # 第三步：根据这一位将数组分成两组
        num1, num2 = 0, 0
        for num in nums:
            if num & diff_bit:
                # 这一位为 1 的分到第一组
                num1 ^= num
            else:
                # 这一位为 0 的分到第二组
                num2 ^= num
        
        return [num1, num2]
```

### 方法二：位运算详细注释版

```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        """
        位运算的详细解释版本
        """
        # 步骤1：获取两个唯一数字的异或结果
        # 假设两个唯一数字是 a 和 b
        # 其他数字都出现两次，异或后为 0
        # 所以最终结果是 a ^ b
        xor_all = 0
        for num in nums:
            xor_all ^= num
        
        # 步骤2：找到 a 和 b 不同的某一位
        # 因为 a ≠ b，所以 a ^ b 至少有一位是 1
        # 我们找到最右边的 1（也可以找其他任意一个 1）
        
        # 获取最右边的 1 的方法：
        # x & (-x) 或 x & ~(x-1)
        # 
        # 原理（以 x & (-x) 为例）：
        # 假设 x = 0110 (二进制)
        # -x 在补码表示中，先取反再加1
        # ~x = 1001
        # -x = 1010
        # x & (-x) = 0010（只保留最右边的 1）
        rightmost_one = xor_all & (-xor_all)
        
        # 步骤3：根据这一位将数字分成两组
        # 一组在这一位是 1，一组在这一位是 0
        # a 和 b 必然在不同的组
        # 其他成对出现的数字会在同一组，异或后为 0
        a, b = 0, 0
        
        for num in nums:
            if num & rightmost_one:
                # 这一位是 1 的分到 a 组
                a ^= num
            else:
                # 这一位是 0 的分到 b 组
                b ^= num
        
        return [a, b]
```

### 方法三：哈希表（直观但不满足进阶要求）

```python
from typing import List
from collections import Counter

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        """
        使用哈希表统计
        时间复杂度：O(n)
        空间复杂度：O(n)
        不满足进阶要求（常数空间）
        """
        count = Counter(nums)
        return [num for num, freq in count.items() if freq == 1]
```

### 方法四：集合（简洁但不满足进阶要求）

```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        """
        使用集合
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        seen = set()
        for num in nums:
            if num in seen:
                seen.remove(num)
            else:
                seen.add(num)
        return list(seen)
```

### 方法五：数学方法（另一种思路）

```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        """
        数学方法：2 * sum(unique) - sum(all)
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        unique_nums = set(nums)
        # 设两个唯一的数为 a 和 b
        # sum(all) = a + b + 2 * (其他数字之和)
        # sum(unique) = a + b + (其他数字之和)
        # 2 * sum(unique) - sum(all) = a + b
        total_unique = sum(unique_nums)
        total_all = sum(nums)
        
        sum_ab = 2 * total_unique - total_all
        
        # 通过异或找到一个分组位
        xor_all = 0
        for num in nums:
            xor_all ^= num
        
        diff_bit = xor_all & (-xor_all)
        
        a = 0
        for num in nums:
            if num & diff_bit:
                a ^= num
        
        b = sum_ab - a
        return [a, b]
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)，只使用常数额外空间

**方法三、四（哈希表/集合）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 图解示例

以 `nums = [1,2,1,3,2,5]` 为例：

### 步骤1：全部异或

```
1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5
= (1 ^ 1) ^ (2 ^ 2) ^ 3 ^ 5
= 0 ^ 0 ^ 3 ^ 5
= 3 ^ 5
= 0011 ^ 0101
= 0110
= 6
```

### 步骤2：找到不同的位

```
xor_result = 6 = 0110 (二进制)

获取最低位的 1：
6 的二进制：  0110
-6 的补码：   1010
6 & (-6)：    0010 = 2

所以用第 2 位（从右往左，从 1 开始）来分组
```

### 步骤3：分组异或

```
diff_bit = 2 = 0010

检查每个数字的第 2 位：
1 = 0001，第2位=0 → 分到第二组
2 = 0010，第2位=1 → 分到第一组
1 = 0001，第2位=0 → 分到第二组
3 = 0011，第2位=1 → 分到第一组
2 = 0010，第2位=1 → 分到第一组
5 = 0101，第2位=0 → 分到第二组

第一组：2, 3, 2 → 2 ^ 3 ^ 2 = 3
第二组：1, 1, 5 → 1 ^ 1 ^ 5 = 5

结果：[3, 5]
```

## 位运算技巧详解

### 获取最低位的 1

```python
# 方法1：x & (-x)
x = 6    # 0110
-x = -6  # 补码：1010
x & (-x) # 0010

# 方法2：x & ~(x-1)
x = 6      # 0110
x-1 = 5    # 0101
~(x-1) = ~5 # 1010
x & ~(x-1)  # 0010

# 方法3：使用 lowbit 函数
def lowbit(x):
    return x & (-x)
```

### 为什么 `x & (-x)` 能获取最低位的 1？

```
以 x = 12 (1100) 为例：

x = 1100
在补码中，-x = ~x + 1
~x = 0011
~x + 1 = 0100

x & (-x) = 1100 & 0100 = 0100

观察：
- x 的最低位 1 右边的部分都是 0
- -x 会将这些 0 变成 1，最低位的 1 变成 1（因为要进位）
- x 和 -x 按位与，只有最低位的 1 保留
```

## 关键点总结

1. **异或性质**：`a ^ a = 0`, `a ^ 0 = a`，成对的数字异或后为 0
2. **分组思想**：找到区分两个数字的位，进行分组
3. **lowbit 技巧**：`x & (-x)` 获取最低位的 1
4. **位运算优势**：O(1) 空间复杂度，满足进阶要求
5. **分组保证**：成对出现的数字一定在同一组

## 易错点

1. **负数的处理**
   ```python
   # Python 中负数的位运算是正确的
   # 但在某些语言中需要注意符号位
   diff_bit = xor_result & (-xor_result)
   ```

2. **分组条件**
   ```python
   # 错误：使用 == 判断
   if num & diff_bit == diff_bit:
   
   # 正确：判断是否非零
   if num & diff_bit:
   ```

3. **理解异或的顺序无关性**
   ```python
   # 异或满足交换律和结合律
   a ^ b ^ c = (a ^ b) ^ c = a ^ (b ^ c)
   ```

4. **忘记处理边界情况**
   ```python
   # 题目保证至少有两个不同的数字
   # 但实现时要理解算法的前提
   ```
