## 题目描述

给你一个字符串 `sequence` 和一个字符串 `word`，返回 `word` 在 `sequence` 中可以重复 `word` 的**最多次数** `k`，使得 `word` 重复 `k` 次（即 `word * k`）是 `sequence` 的**子字符串**。

**示例：**
```
输入：sequence = "ababc", word = "ab"
输出：2（"abab" 是 "ababc" 的子字符串）

输入：sequence = "ababc", word = "ba"
输出：1（"ba" 是 "ababc" 的子字符串，但 "baba" 不是）
```

## 解题思路

**方法一：暴力枚举**：从 `k=1` 开始，检查 `word*k` 是否是 `sequence` 的子串，找最大 k。

**方法二：动态规划**：`dp[i]` = 以 `sequence[i]` 结尾，`word` 可以连续重复的最大次数。

## 代码实现

### 方法一：暴力枚举（推荐，适合小数据）

```python
class Solution:
    def maxRepeating(self, sequence: str, word: str) -> int:
        k = 0
        # 最多能重复的次数上界：len(sequence) // len(word)
        while word * (k + 1) in sequence:
            k += 1
        return k
```

### 方法二：动态规划

```python
class Solution:
    def maxRepeating(self, sequence: str, word: str) -> int:
        n = len(sequence)
        m = len(word)
        
        if n < m:
            return 0
        
        # dp[i] = 以 i 结尾时，word 可以连续重复的最大次数
        dp = [0] * n
        
        for i in range(m - 1, n):
            # 检查 sequence[i-m+1..i] 是否等于 word
            if sequence[i - m + 1: i + 1] == word:
                dp[i] = (dp[i - m] + 1) if i >= m else 1
        
        return max(dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n * n/m) | O(n) |
| 动态规划 | O(n * m)（字符串比较） | O(n) |

## 关键点总结

1. 方法一：Python 的 `in` 操作符直接检查子串，代码极简
2. DP 方法：`dp[i]` 记录以位置 i 为末尾的连续重复次数
3. DP 转移：若 `seq[i-m+1:i+1] == word`，则 `dp[i] = dp[i-m] + 1`

## 易错点

- 方法一中注意 `word * 0 = ""`，空串是任何字符串的子串，所以初始 k=0 正确
- DP 中 `dp[i-m]` 当 `i < m` 时需特殊处理（直接赋 1）
