## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

返回所有长度**至多为 `k`** 的非空子数组的最大值和最小值的总和。

即，对每个长度为 1 到 k 的子数组，计算其 `max + min`，将所有子数组的结果累加。

**示例 1：**

```
输入：nums = [1,2,3], k = 2
输出：20
解释：
子数组 [1]: max+min = 2
子数组 [2]: max+min = 4
子数组 [3]: max+min = 6
子数组 [1,2]: max+min = 2+1 = 3
子数组 [2,3]: max+min = 3+2 = 5
总和 = 2+4+6+3+5 = 20
```

**示例 2：**

```
输入：nums = [1,-3,1], k = 2
输出：-6
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- `1 <= k <= nums.length`

## 解题思路

对于每个元素 `nums[i]`，计算它作为**最大值**贡献了多少次，以及作为**最小值**贡献了多少次。

**nums[i] 作为最大值的贡献**：
对于以 `nums[i]` 为最大值的所有长度 <= k 的子数组，每个子数组贡献一次 `nums[i]`。

使用单调栈找 `nums[i]` 作为最大值的范围：
- 左边界 `L`：向左第一个比 `nums[i]` 大的位置
- 右边界 `R`：向右第一个比 `nums[i]` 大或等于的位置（处理重复）

nums[i] 作为最大值的子数组数 = 以 i 为最大值且长度 <= k 的子数组数。

这道题可以分别计算所有子数组的最大值之和与最小值之和。

## Python 代码实现

### 方法一：单调栈计算每个元素的贡献

```python
from typing import List

class Solution:
    def minMaxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)

        def contribution_as_max():
            """计算每个元素作为最大值的贡献之和"""
            total = 0
            # 单调递减栈（存下标）
            stack = []
            for i in range(n + 1):
                while stack and (i == n or nums[stack[-1]] <= nums[i]):
                    mid = stack.pop()
                    left = stack[-1] if stack else -1
                    right = i

                    # nums[mid] 是最大值的子数组：左端点 l 在 (left, mid]，右端点 r 在 [mid, right)
                    # 且子数组长度 <= k：r - l + 1 <= k，即 r - l <= k - 1

                    # 计数：l in [left+1, mid], r in [mid, right-1]
                    # 且 r - l <= k - 1
                    # 对每个 r，l 的范围：[max(left+1, r-k+1), mid]
                    for r in range(mid, right):
                        l_lo = max(left + 1, r - k + 1)
                        l_hi = mid
                        if l_lo <= l_hi:
                            count = l_hi - l_lo + 1
                            total += nums[mid] * count

                stack.append(i)
            return total

        def contribution_as_min():
            """计算每个元素作为最小值的贡献之和"""
            total = 0
            stack = []
            for i in range(n + 1):
                while stack and (i == n or nums[stack[-1]] >= nums[i]):
                    mid = stack.pop()
                    left = stack[-1] if stack else -1
                    right = i

                    for r in range(mid, right):
                        l_lo = max(left + 1, r - k + 1)
                        l_hi = mid
                        if l_lo <= l_hi:
                            count = l_hi - l_lo + 1
                            total += nums[mid] * count

                stack.append(i)
            return total

        return contribution_as_max() + contribution_as_min()
```

### 方法二：暴力解法（适合理解，n <= 10^3）

```python
from typing import List

class Solution:
    def minMaxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = 0

        for i in range(n):
            cur_max = nums[i]
            cur_min = nums[i]
            for j in range(i, min(i + k, n)):
                cur_max = max(cur_max, nums[j])
                cur_min = min(cur_min, nums[j])
                total += cur_max + cur_min

        return total
```

### 方法三：单调栈优化（O(n)）

```python
from typing import List

class Solution:
    def minMaxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)

        def sum_of_extremes(is_max: bool) -> int:
            """计算所有子数组的最大值（或最小值）之和"""
            total = 0
            stack = []  # 单调栈，存 (值, 计数)
            # 当前累积到位置 i，stack 代表向右看的候选极值

            # 使用"贡献法"：对每个元素，计算它是多少个子数组的极值
            # 利用单调栈找左右边界

            left_bound = [-1] * n  # 左边第一个比它大（max）或小（min）的位置
            right_bound = [n] * n  # 右边第一个不小于（max）或不大于（min）的位置

            stk = []
            for i in range(n):
                while stk and (nums[stk[-1]] <= nums[i] if is_max else nums[stk[-1]] >= nums[i]):
                    right_bound[stk.pop()] = i
                stk.append(i)

            stk = []
            for i in range(n - 1, -1, -1):
                while stk and (nums[stk[-1]] < nums[i] if is_max else nums[stk[-1]] > nums[i]):
                    left_bound[stk.pop()] = i
                stk.append(i)

            for i in range(n):
                l = left_bound[i]
                r = right_bound[i]
                # 子数组左端点在 [l+1, i]，右端点在 [i, r-1]，且长度 <= k
                # 贡献 = nums[i] * (子数组数量)
                # 子数组数量 = sum_{lend=max(l+1, i-k+1)}^{i} (min(r-1, lend+k-1) - i + 1)
                for lend in range(max(l + 1, i - k + 1), i + 1):
                    rend_max = min(r - 1, lend + k - 1)
                    cnt = rend_max - i + 1
                    if cnt > 0:
                        total += nums[i] * cnt

            return total

        return sum_of_extremes(True) + sum_of_extremes(False)
```

## 复杂度分析

- 方法二（暴力）：
  - 时间复杂度：O(n * k)
  - 空间复杂度：O(1)

- 方法一（单调栈）：
  - 时间复杂度：O(n * k) 最坏，O(n) 均摊
  - 空间复杂度：O(n)

## 关键点总结

1. 将问题分解为"所有子数组最大值之和"与"所有子数组最小值之和"
2. 对每个元素，用单调栈找它作为极值的范围，计算贡献次数
3. 长度限制 k 需要在计算贡献次数时额外考虑

## 易错点

1. 处理相等元素时，左右边界的严格/非严格判断要一致（避免重复计数）
2. 长度限制 <= k 的条件要同时约束左端点和右端点
3. 最大值和最小值的贡献要分别计算后相加
