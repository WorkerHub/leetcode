## 题目描述

一个数组的 **XOR 总和** 定义为数组中所有元素按位 XOR 的结果；若数组为空则为 0。

给你一个数组 `nums`，返回 `nums` 所有**非空子集**的 XOR 总和之和。

**示例 1：**
```
输入：nums = [1,3]
输出：6
解释：[1]=1, [3]=3, [1,3]=2，总和 1+3+2=6
```

**示例 2：**
```
输入：nums = [5,1,6]
输出：28
```

**提示：**
- `1 <= nums.length <= 12`

## 解题思路

**数学公式**：

每一位独立分析。对于某一位 b，考虑它在所有子集 XOR 总和中的贡献：
- 若 nums 中**至少有一个元素**的第 b 位为 1，则恰好有 `2^(n-1)` 个子集的 XOR 总和第 b 位为 1（任意选取其余 n-1 个元素的奇偶性使第 b 位为 1 的子集恰好占一半）
- 若 nums 中**没有元素**的第 b 位为 1，则所有子集的 XOR 在第 b 位为 0

因此，答案 = `(nums[0] OR nums[1] OR ... OR nums[n-1]) * 2^(n-1)`

## 代码实现

### 方法一：数学公式（推荐，O(n) 时间）

```python
from typing import List
from functools import reduce
from operator import or_

class Solution:
    def subsetXORSum(self, nums: List[int]) -> int:
        # 所有元素按位或
        or_all = 0
        for x in nums:
            or_all |= x
        # 结果 = or_all * 2^(n-1)
        return or_all * (1 << (len(nums) - 1))
```

### 方法二：回溯枚举（直观理解）

```python
from typing import List

class Solution:
    def subsetXORSum(self, nums: List[int]) -> int:
        result = [0]

        def backtrack(index: int, current_xor: int) -> None:
            if index == len(nums):
                result[0] += current_xor
                return
            # 不选 nums[index]
            backtrack(index + 1, current_xor)
            # 选 nums[index]
            backtrack(index + 1, current_xor ^ nums[index])

        backtrack(0, 0)
        return result[0]
        # 注意：回溯也包含了空集（current_xor=0），但空集贡献为 0，不影响结果
```

## 复杂度分析

- **方法一（公式）**：O(n) 时间，O(1) 空间
- **方法二（回溯）**：O(2^n) 时间，O(n) 空间（递归栈）

## 关键点总结

1. 数学推导：每个位独立计算贡献，结果 = 所有元素 OR 之积 * 2^(n-1)
2. 回溯方法适合 n <= 12 的小规模数据，每个元素选或不选
3. 空集 XOR 为 0，可以包含也可以不包含（贡献为 0）

## 易错点

- 公式中是按位 OR，不是 XOR
- `1 << (n-1)` 而不是 `2**(n-1)`（两者等价但前者在一些语言中更高效）
