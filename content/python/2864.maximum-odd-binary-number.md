## 题目描述

给你一个**非空**的二进制字符串 `s`，里面包含**至少一个** `'1'`。

重排 `s` 中的字符，使得得到的二进制数是**奇数**中的**最大值**（二进制末位为 1）。

返回结果字符串，不含前导零。

**示例 1：**
```
输入：s = "010"
输出："001"
解释：只有两种重排："001"（奇数 1）和 "100"（偶数 4）。最大奇数是 1（"001"）
```

**示例 2：**
```
输入：s = "0101"
输出："1001"
解释：重排后最大奇数：1001（9），比 1010（10，偶数）小，比 0101 等小
最大奇数是 "1001"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 包含 `'0'` 和 `'1'`
- `s` 中至少有一个 `'1'`

## 解题思路

**贪心：**
- 要让二进制数最大且为奇数：末位必须是 `'1'`，其余位越大越好
- 将剩余的 `'1'`（共 count_1 - 1 个）放到最高位，然后是 `'0'`，最后一个 `'1'` 放末位

**结果：** `(count_1 - 1) 个 '1'` + `count_0 个 '0'` + `'1'`

## Python 代码实现

### 方法一：计数（推荐）

```python
class Solution:
    def maximumOddBinaryNumber(self, s: str) -> str:
        count_1 = s.count('1')
        count_0 = s.count('0')
        # (count_1 - 1) 个 1 + count_0 个 0 + 末尾一个 1
        return '1' * (count_1 - 1) + '0' * count_0 + '1'
```

### 方法二：字符串操作

```python
class Solution:
    def maximumOddBinaryNumber(self, s: str) -> str:
        ones = s.count('1')
        zeros = len(s) - ones
        return '1' * (ones - 1) + '0' * zeros + '1'
```

## 复杂度分析

- 时间复杂度：O(n)，计数和构造字符串
- 空间复杂度：O(n)，结果字符串

## 关键点总结

1. 奇数 ⟺ 最后一位为 1
2. 最大值：尽量让高位为 1，所以将所有额外的 1 放在最前面
3. 公式：`'1' * (ones - 1) + '0' * zeros + '1'`

## 易错点

1. 保留 1 个 '1' 在末尾，其他 (ones-1) 个 '1' 在最前
2. 题目保证至少有一个 '1'，所以 ones >= 1，不会越界
3. 结果是二进制字符串，不含前导零（所有 '1' 在前，不影响）
