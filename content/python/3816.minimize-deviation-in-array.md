## 题目描述

给你一个正整数数组 `nums`，你可以对每个元素执行若干次以下操作之一：
- 若元素是**偶数**，将其除以 2
- 若元素是**奇数**，将其乘以 2

返回数组中最大值与最小值之差（偏差）的最小可能值。

**示例 1：**

```
输入：nums = [1, 2, 3, 4]
输出：1
解释：
将 1 乘以 2 得 [2, 2, 3, 4]，再将 4 除以 2 得 [2, 2, 3, 2]，
偏差 = 3 - 2 = 1。
```

**示例 2：**

```
输入：nums = [4, 1, 5, 20, 3]
输出：3
解释：将 20 不断除以 2 得到最优解，偏差 = 5 - 2 = 3。
```

**提示：**
- `2 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 10^9`

## 解题思路

关键观察：
1. 奇数只能乘以 2（变为偶数），偶数只能除以 2（变小）。
2. 先将所有奇数乘以 2，使它们有机会变小。
3. 之后只有偶数操作（不断除以 2），目标是缩小最大值。
4. 使用**最大堆**：每次取最大值除以 2（若为偶数），更新最小值，记录偏差。

## Python 代码实现

### 方法一：最大堆贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        # 将所有奇数乘以 2，统一处理
        # 使用最大堆（Python 用负数模拟）
        heap = []
        for num in nums:
            if num % 2 == 1:
                num *= 2
            heapq.heappush(heap, -num)  # 负数表示最大堆

        min_val = -max(heap)  # 所有转换后的最小值
        result = float('inf')

        while True:
            max_val = -heapq.heappop(heap)
            result = min(result, max_val - min_val)

            # 若最大值为奇数（无法继续缩小），结束
            if max_val % 2 == 1:
                break

            # 将最大值除以 2，加回堆中
            new_val = max_val // 2
            min_val = min(min_val, new_val)
            heapq.heappush(heap, -new_val)

        return result
```

### 方法二：排序 + 贪心（暴力枚举每种状态）

```python
from typing import List
import heapq

class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        # 同方法一，使用 SortedList 维护有序集合
        from sortedcontainers import SortedList

        sl = SortedList()
        for num in nums:
            # 将奇数乘以 2，使其可以被不断缩小
            if num % 2 == 1:
                num *= 2
            sl.add(num)

        result = sl[-1] - sl[0]

        # 不断缩小最大值（只有偶数才能除以 2）
        while sl[-1] % 2 == 0:
            max_val = sl[-1]
            sl.remove(max_val)
            sl.add(max_val // 2)
            result = min(result, sl[-1] - sl[0])

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n * log(max_val))，每次操作使最大值至少减半
- 空间复杂度：O(n)，堆或有序集合

## 关键点总结

1. 奇数乘以 2 后，数组中所有元素都是偶数，后续只需不断缩小最大值。
2. 贪心策略：每次减小当前最大值，同时追踪最小值，记录偏差。
3. 停止条件：最大值为奇数时（无法继续缩小），结束。

## 易错点

1. 奇数只能乘以 2 变为偶数后才能继续缩小，因此先统一乘以 2。
2. min_val 在每次更新时都要同步更新。
3. 最大值为奇数时必须停止，否则死循环。
