## 题目描述

给你一个整数数组 `nums`，构造新数组 `result`：

对于每个下标 `i`：
- 若 `nums[i] > 0`：从 `nums[i]` 出发，向右跳 `nums[i]` 步（循环，超出末尾从头开始），`result[i]` = 到达位置的 `nums` 值。
- 若 `nums[i] < 0`：从 `nums[i]` 出发，向左跳 `|nums[i]|` 步（循环），`result[i]` = 到达位置的 `nums` 值。
- 若 `nums[i] == 0`：`result[i] = nums[i]`（即 0）。

**示例：**
```
输入：nums = [3, -2, 1, 1, -2]
输出：[1, -2, 1, -2, 3]
解释：result[0] = nums[(0+3) % 5] = nums[3] = 1
     result[1] = nums[(1-2+5) % 5] = nums[4] = -2
```

**提示：**
- `1 <= nums.length <= 100`

## 解题思路

直接模拟：对每个位置 `i`，根据 `nums[i]` 的值计算目标位置，取目标位置的 `nums` 值。

目标位置 = `(i + nums[i]) % n`（Python 的 `%` 对负数也正确处理）。

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def constructTransformedArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = []
        
        for i in range(n):
            if nums[i] == 0:
                result.append(0)
            else:
                target = (i + nums[i]) % n
                result.append(nums[target])
        
        return result
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def constructTransformedArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        return [0 if nums[i] == 0 else nums[(i + nums[i]) % n] for i in range(n)]
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. 目标位置 = `(i + nums[i]) % n`，Python 的 `%` 对负数自动处理（结果非负）。
2. `nums[i] == 0` 时，结果为 0（自身）。
3. 模运算循环处理边界。

## 易错点

1. Python 的 `%` 运算对负数取模结果为正（`-2 % 5 = 3`），可以直接使用。
2. 不要修改原数组（`nums`），因为后续位置可能引用前面的值。
3. `nums[i] == 0` 时结果固定为 0，不是 `nums[i]` 本身... 等等，题目说 result[i] = nums[i] = 0，是一样的。
