## 题目描述

给你一个字符串 `s`，其中包含若干 `'?'` 字符。

请你将每个 `'?'` 替换为某个小写字母，使替换后的字符串中**不包含**任何连续重复字符，即 `s[i] != s[i+1]`。

返回结果字符串。若存在多种答案，返回任意一种。

**示例 1：**
```
输入：s = "?zs"
输出："azs"
```

**示例 2：**
```
输入：s = "ubv?w"
输出："ubvaw"
```

## 解题思路

### 贪心逐一替换

对每个 `'?'`，从 `'a'` 开始尝试，找第一个与前后字符都不同的字母。

由于只需避开前一个和后一个字符，最多尝试 3 个字母即可找到合适的（26个字母中至少有 24 个可用）。

## 代码实现

### 方法一：贪心尝试（推荐）

```python
class Solution:
    def modifyString(self, s: str) -> str:
        s = list(s)
        n = len(s)
        for i in range(n):
            if s[i] == '?':
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    # 检查与前后字符不同
                    if (i == 0 or s[i-1] != c) and (i == n-1 or s[i+1] != c):
                        s[i] = c
                        break
        return ''.join(s)
```

### 方法二：只尝试 a, b, c（因为最多需要避开2个字符）

```python
class Solution:
    def modifyString(self, s: str) -> str:
        s = list(s)
        n = len(s)
        for i in range(n):
            if s[i] == '?':
                # 只需尝试 'a', 'b', 'c'，总能找到合适的
                for c in 'abc':
                    prev = s[i-1] if i > 0 else None
                    nxt = s[i+1] if i < n-1 else None
                    if c != prev and c != nxt:
                        s[i] = c
                        break
        return ''.join(s)
```

### 方法三：使用 ord 计算

```python
class Solution:
    def modifyString(self, s: str) -> str:
        s = list(s)
        n = len(s)
        for i in range(n):
            if s[i] == '?':
                # 从 'a' 开始，跳过与前后相同的字符
                prev = ord(s[i-1]) - ord('a') if i > 0 and s[i-1] != '?' else -1
                nxt = ord(s[i+1]) - ord('a') if i < n-1 and s[i+1] != '?' else -1
                for j in range(26):
                    if j != prev and j != nxt:
                        s[i] = chr(ord('a') + j)
                        break
        return ''.join(s)
```

## 复杂度分析

- **时间复杂度**：O(N)（每个 `?` 最多尝试 3 个字符）
- **空间复杂度**：O(N)（转为列表）

## 关键点总结

1. 每个 `?` 只需避开前一个和后一个字符（最多 2 个）
2. 从 `'a'` 开始尝试，第三个字母必然可用
3. 注意边界：`i=0` 没有前字符，`i=n-1` 没有后字符

## 易错点

- 后续的 `?` 可能被之前替换的字符影响，要用已替换的值做比较（所以要修改原列表）
- 边界处理：数组首尾的 `?` 只需避免一侧
