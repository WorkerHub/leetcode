## 题目描述

一个城市有 `n` 个交叉口和 `m` 条双向道路，道路连接由 `edges` 给出。

交通信号灯每 `change` 分钟改变一次（绿灯 -> 红灯 -> 绿灯）。在红灯期间（所有 `[change, 2*change)`、`[3*change, 4*change)` 等时间段），你必须等待。

从 1 出发，求到达 `n` 的**第二最短时间**（严格大于最短时间的最小时间）。

**每次移动花费 `time` 分钟**（道路通行时间相同），但在红灯时必须等待。

**示例：**
```
输入：n = 5, edges = [[1,2],[1,3],[1,4],[3,4],[4,5]], time = 3, change = 5
输出：13
```

**提示：**
- `2 <= n <= 10^4`
- `n - 1 <= edges.length <= min(2*10^4, n*(n-1)/2)`
- `1 <= time, change <= 10^3`

## 解题思路

**BFS 变体：** 第二最短路需要记录每个节点的前两个到达时间（最短和次短）。

**关键点：**
1. 可以重复经过同一节点（因为要找次短路，可能需要"绕路"）
2. 每个节点最多到达 2 次（第一次和第二次）
3. 第二最短路时间 = 最短路时间或最短路时间 + 1 步（因为图中每条边权重相同）

**时间计算（等红灯）：**
- 当前时间 `t`，当前所在区间 `t // change` 为奇数时正在等待红灯
- 等待至下一个绿灯：`t = (t // change + 1) * change`
- 然后出发，花费 `time` 分钟

## 代码实现

### 方法一：BFS（记录前两次到达时间）

```python
from typing import List
from collections import deque

class Solution:
    def secondMinimum(self, n: int, edges: List[List[int]], time: int, change: int) -> int:
        # 构建邻接表
        graph = [[] for _ in range(n + 1)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # dist1[v]：最短到达时间，dist2[v]：次短到达时间
        INF = float('inf')
        dist1 = [INF] * (n + 1)
        dist2 = [INF] * (n + 1)
        dist1[1] = 0

        queue = deque([(1, 0)])  # (节点, 当前时间)

        while queue:
            node, cur_time = queue.popleft()

            # 等待信号灯
            # 当前时间在红灯区间（odd * change <= t < (odd+1)*change）
            interval = cur_time // change
            if interval % 2 == 1:
                # 等待到下一个绿灯
                wait_time = (interval + 1) * change - cur_time
            else:
                wait_time = 0

            next_time = cur_time + wait_time + time  # 移动到邻居的时间

            for nei in graph[node]:
                if dist1[nei] == INF:
                    dist1[nei] = next_time
                    queue.append((nei, next_time))
                elif dist2[nei] == INF and next_time > dist1[nei]:
                    dist2[nei] = next_time
                    if nei == n:
                        return dist2[n]
                    queue.append((nei, next_time))

        return dist2[n]
```

### 方法二：BFS 优化版

```python
from typing import List
from collections import deque

class Solution:
    def secondMinimum(self, n: int, edges: List[List[int]], time: int, change: int) -> int:
        graph = [[] for _ in range(n + 1)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # freq[v] = 到达 v 的次数（最多2次）
        freq = [0] * (n + 1)
        dist = [float('inf')] * (n + 1)

        def next_time(t):
            # 计算从时间 t 出发（考虑等红灯）后到达邻居的时间
            if (t // change) % 2 == 1:
                t = (t // change + 1) * change
            return t + time

        queue = deque([(0, 1)])  # (time, node)
        freq[1] = 1

        while queue:
            cur_time, node = queue.popleft()
            nt = next_time(cur_time)

            for nei in graph[node]:
                if freq[nei] < 2:
                    freq[nei] += 1
                    if freq[nei] == 2 and nei == n:
                        return nt
                    queue.append((nt, nei))

        return -1
```

## 复杂度分析

- 时间复杂度：O((V + E) * log V)，BFS 每个节点最多2次
- 空间复杂度：O(V + E)

## 关键点总结

1. BFS 允许每个节点被访问两次（记录最短和次短时间）
2. 等待信号灯的计算：当 `t // change` 为奇数时，等待到下一个 `change` 倍数
3. 次短路时间只需比最短路时间大即可（不需要完整 Dijkstra）

## 易错点

- 信号灯判断：`t // change` 为奇数时是红灯，需等待
- 等待时间：`(t // change + 1) * change - t`
- 次短路可能等于最短路 + time（绕一步再回来）
