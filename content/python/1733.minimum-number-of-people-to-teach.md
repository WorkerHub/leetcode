## 题目描述

在一个由 `m` 种语言和 `n` 个用户组成的世界里，每个用户都能说一种或多种语言。

给你一个整数 `n`，一个语言数组 `languages`，其中 `languages[i]` 是第 `i` 位用户能说的语言集合，还有一个关系数组 `friendships`，其中 `friendships[i] = [u_i, v_i]` 代表用户 `u_i` 和 `v_i` 是好友关系。

如果两个用户有**共同语言**，则他们可以互相沟通。你只能选择**一种语言**教授给任意数量的用户，使得所有好友之间都能沟通。

找到需要教授的**最少用户数**。注意，教授已经会该语言的用户，人数不计入结果。

**示例 1：**
```
输入：n = 2, languages = [["1"],["2"],["1","2"]], friendships = [[1,2],[1,3],[2,3]]
输出：1
```

**提示：**
- `2 <= n <= 500`
- `languages.length == m`（用户数）
- `1 <= languages[i].length <= n`

## 解题思路

对每种语言，统计需要教授多少用户：
1. 找出所有存在"不能沟通"的好友对（没有共同语言）
2. 对这些用户中，统计每种语言需要教授多少人（即不会该语言的人数）
3. 取最小值

优化：只需关注那些"不能沟通"的好友对中涉及的用户。

## 代码实现

### 方法一：枚举语言 + 计数（推荐）

```python
from typing import List

class Solution:
    def minimumTeachings(self, n: int, languages: List[List[int]], friendships: List[List[int]]) -> int:
        # 将每个用户的语言集合转为集合类型
        lang_sets = [set(l) for l in languages]
        
        # 找出所有不能沟通的好友对涉及的用户
        # 不能沟通 = 没有共同语言
        need_teach_users = set()
        bad_pairs = []
        
        for u, v in friendships:
            u -= 1
            v -= 1
            # 检查是否有共同语言
            if not lang_sets[u] & lang_sets[v]:
                need_teach_users.add(u)
                need_teach_users.add(v)
        
        if not need_teach_users:
            return 0
        
        # 对每种语言，统计在 need_teach_users 中不会该语言的用户数
        best = len(need_teach_users)  # 最坏情况教所有人
        
        for lang in range(1, n + 1):
            # 统计 need_teach_users 中不会 lang 的人数
            count = sum(1 for u in need_teach_users if lang not in lang_sets[u])
            best = min(best, count)
        
        return best
```

### 方法二：预先统计语言频率

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumTeachings(self, n: int, languages: List[List[int]], friendships: List[List[int]]) -> int:
        lang_sets = [set(l) for l in languages]
        
        # 找出不能沟通的好友对中的用户
        bad_users = set()
        for u, v in friendships:
            u -= 1
            v -= 1
            if not lang_sets[u] & lang_sets[v]:
                bad_users.add(u)
                bad_users.add(v)
        
        if not bad_users:
            return 0
        
        # 统计每种语言在 bad_users 中的会说人数
        lang_count = defaultdict(int)
        for u in bad_users:
            for lang in lang_sets[u]:
                lang_count[lang] += 1
        
        # 最少教授人数 = 总人数 - 会说该语言最多的人数
        max_already_know = max(lang_count.values()) if lang_count else 0
        return len(bad_users) - max_already_know
```

## 复杂度分析

- **时间复杂度**：O(m * n + f * max_lang)，m 用户数，f 好友对数
- **空间复杂度**：O(m * max_lang)，存储语言集合

## 关键点总结

1. 只需关注"不能沟通"的好友对中涉及的用户
2. 对每种语言，统计这些用户中已会该语言的人数，取最多的那种语言
3. 教授人数 = 不能沟通的用户总数 - 已会最优语言的人数

## 易错点

- 用户编号从 1 开始，注意转换
- 如果所有好友都能沟通，直接返回 0
