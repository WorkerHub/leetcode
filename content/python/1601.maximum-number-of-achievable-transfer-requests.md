## 题目描述

我们有 `n` 栋楼，编号从 `0` 到 `n-1`。每栋楼里住了一些员工。由于现在疫情，我们可以安排员工转移。给你一个数组 `requests`，其中 `requests[i] = [fromi, toi]` 表示一个员工请求从编号为 `fromi` 的楼转移到 `toi` 号楼。

在考虑转移请求时，每栋楼的净变化必须为零（即每栋楼的转入员工数等于转出员工数）。这样可以保证每栋楼的员工数不变。

请你返回满足条件的最多可完成的转移请求数目。

**示例 1：**
```
输入：n = 5, requests = [[0,1],[1,0],[0,1],[1,2],[2,0],[3,4]]
输出：5
```

**示例 2：**
```
输入：n = 3, requests = [[0,0],[1,2],[2,1]]
输出：3
```

**提示：**
- `1 <= n <= 20`
- `1 <= requests.length <= 16`
- `requests[i].length == 2`
- `0 <= fromi, toi < n`

## 解题思路

由于 `requests` 最多 16 个，可以用**枚举子集**的方式，枚举所有可能的请求组合（共 2^16 种），检查该组合中每栋楼的净变化是否都为零。

**核心思想：**
1. 枚举所有 2^m 个子集（m 为请求数量）
2. 对每个子集，统计每栋楼的净变化（离开 -1，到达 +1）
3. 若净变化全为 0，则该子集合法，更新最大请求数

**关键观察：** 同一个员工请求中 `from == to` 的情况也合法（净变化为 0）。

## 代码实现

### 方法一：枚举子集（位运算）（推荐）

```python
from typing import List

class Solution:
    def maximumRequests(self, n: int, requests: List[List[int]]) -> int:
        m = len(requests)
        ans = 0
        
        # 枚举所有 2^m 个子集
        for mask in range(1 << m):
            # 统计每栋楼的净变化
            delta = [0] * n
            for i in range(m):
                if mask >> i & 1:  # 第 i 个请求被选中
                    delta[requests[i][0]] -= 1  # 离开楼 from
                    delta[requests[i][1]] += 1  # 到达楼 to
            
            # 检查是否所有楼净变化为 0
            if all(d == 0 for d in delta):
                ans = max(ans, bin(mask).count('1'))
        
        return ans
```

### 方法二：回溯枚举

```python
from typing import List

class Solution:
    def maximumRequests(self, n: int, requests: List[List[int]]) -> int:
        m = len(requests)
        self.ans = 0
        delta = [0] * n
        
        def backtrack(idx: int, count: int):
            if idx == m:
                # 检查所有楼净变化是否为 0
                if all(d == 0 for d in delta):
                    self.ans = max(self.ans, count)
                return
            
            # 不选第 idx 个请求
            backtrack(idx + 1, count)
            
            # 选第 idx 个请求
            f, t = requests[idx]
            delta[f] -= 1
            delta[t] += 1
            backtrack(idx + 1, count + 1)
            # 回溯还原
            delta[f] += 1
            delta[t] -= 1
        
        backtrack(0, 0)
        return self.ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举子集 | O(2^m * (m + n)) | O(n) |
| 回溯 | O(2^m * n) | O(m + n) |

其中 m 为请求数量（最多 16），n 为楼数（最多 20）。

## 关键点总结

1. 请求数最多 16，可以枚举所有子集（2^16 = 65536，完全可行）
2. 净变化为 0 是合法的充要条件
3. 位运算 `mask >> i & 1` 用于判断第 i 位是否选中
4. `bin(mask).count('1')` 统计选中的请求数量
5. 回溯时必须还原 delta 数组

## 易错点

- 忘记回溯时恢复 delta 数组的状态
- 枚举子集时注意 `mask` 范围是 `[0, 1 << m)`，不含 `1 << m`
- `from == to` 的请求也是合法的，净变化仍为 0
