## 题目描述

给你一个包含若干 **互不相同** 正整数的数组 `nums`，你需要通过若干步操作将数组变空：每步操作检查数组首元素是否为当前最小值，若是则删除，否则将其移到数组末尾。返回操作次数。

**示例 1：**
```
输入：nums = [3,4,-1]
输出：5
解释：
[-1] 在尾部，需要 3->4->-1 移动 2 次，删除 -1；
然后 3->4 移动 1 次，删除 3；最后直接删除 4，共 5 次
```

**示例 2：**
```
输入：nums = [1,2,4,3]
输出：5
```

**数据范围：**
- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
- 所有元素互不相同

## 解题思路

将元素按值从小到大排序，按删除顺序处理。对于每次删除：

需要知道从当前位置（上一个被删元素的位置）到目标元素的移动次数。若目标在当前位置之后（顺序访问），直接走到目标；若目标在前面，需要绕一圈（经过当前数组的剩余元素）。

用树状数组（BIT）维护每个位置是否还有元素，快速计算区间内剩余元素个数，从而计算移动次数。

## Python 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List

class Solution:
    def countOperationsToEmptyArray(self, nums: List[int]) -> int:
        n = len(nums)

        # 树状数组：统计已删除元素数
        bit = [0] * (n + 1)

        def update(i, val=1):
            while i <= n:
                bit[i] += val
                i += i & (-i)

        def query(i):
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        def count_deleted_in_range(l, r):
            """[l, r] 中已删除的元素数（1-indexed）"""
            if l > r:
                return 0
            return query(r) - query(l - 1)

        # 按值排序，得到删除顺序
        order = sorted(range(n), key=lambda i: nums[i])

        ans = 0
        cur_pos = 0  # 当前处理位置（在原始数组中的位置，0-indexed）

        for rank, idx in enumerate(order):
            # 当前要删除的元素在原始数组中的位置（1-indexed）
            target = idx + 1
            remaining = n - rank  # 当前剩余元素数

            # 从 cur_pos 到 target 的存活元素数
            if target > cur_pos:
                # 目标在当前位置之后
                steps = target - cur_pos - count_deleted_in_range(cur_pos + 1, target)
            else:
                # 目标在当前位置之前，需要绕一圈
                steps = (n - cur_pos - count_deleted_in_range(cur_pos + 1, n)) + \
                        (target - count_deleted_in_range(1, target))

            ans += steps
            cur_pos = target
            update(target)  # 标记为已删除

        return ans
```

### 方法二：使用 SortedList

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def countOperationsToEmptyArray(self, nums: List[int]) -> int:
        n = len(nums)
        order = sorted(range(n), key=lambda i: nums[i])
        # positions: 仍在数组中的位置（有序）
        positions = SortedList(range(n))

        ans = 0
        cur = 0  # 当前处理的位置

        for idx in order:
            remaining = len(positions)
            pos_rank = positions.index(idx)  # idx 在当前有序位置中的排名

            # 计算从 cur 到 idx 需要多少步
            cur_rank = positions.bisect_left(cur)
            if pos_rank >= cur_rank:
                steps = pos_rank - cur_rank + 1
            else:
                steps = (remaining - cur_rank) + pos_rank + 1

            ans += steps
            positions.remove(idx)
            cur = idx

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)
- 方法二：时间复杂度 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按值从小到大依次删除
2. 计算从当前位置到目标位置的步数（考虑是否需要绕一圈）
3. 用树状数组或有序集合维护已删除元素，快速计算剩余元素数

## 易错点

1. 绕圈时的步数 = 从当前位置到末尾的剩余元素数 + 从头到目标的剩余元素数
2. 注意 1-indexed 和 0-indexed 的转换
