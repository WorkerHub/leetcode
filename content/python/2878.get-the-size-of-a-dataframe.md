## 题目描述

给定一个 DataFrame `players`，编写一个解决方案，获取 DataFrame 的行数和列数，以数组 `[number of rows, number of columns]` 形式返回。

**示例 1：**
```
输入：
players DataFrame 有 5 行 4 列

输出：[5, 4]
```

## Python 代码实现

### 方法一：shape 属性（推荐）

```python
import pandas as pd
from typing import List

def getDataframeSize(players: pd.DataFrame) -> List[int]:
    # df.shape 返回 (行数, 列数) 的元组
    return list(players.shape)
```

### 方法二：len 和 columns

```python
import pandas as pd
from typing import List

def getDataframeSize(players: pd.DataFrame) -> List[int]:
    return [len(players), len(players.columns)]
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `df.shape` 返回 `(rows, columns)` 元组
2. `len(df)` 返回行数，`len(df.columns)` 返回列数
3. 需要返回列表 `[rows, cols]`，注意 `list(df.shape)` 转换类型
