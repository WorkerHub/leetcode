## 题目描述

给你一个二进制字符串 `s`（只含 '0' 和 '1'），将字符串分割成三个**非空**子字符串，使每个子字符串中 `1` 的数量相同。

返回满足条件的分割方案数，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：s = "10101"
输出：4
```

**示例 2：**
```
输入：s = "1001"
输出：0
```

**提示：**
- `3 <= s.length <= 10^5`
- `s[i]` 只含 '0' 和 '1'

## 解题思路

### 数学 + 前缀和

1. 统计 `s` 中 `1` 的总数 `total`
2. 若 `total % 3 != 0`，返回 0
3. 若 `total == 0`，所有分割都合法：第一刀有 `n-2` 种，第二刀有 `n-1` 种... 答案 = `C(n-1, 2) = (n-1)*(n-2)//2`
4. 每段需要 `target = total // 3` 个 1
5. 找第一段第 `target` 个 `1` 和第 `target+1` 个 `1` 之间的间隔（第一刀可以插的位置数）
6. 找第二段第 `2*target` 个 `1` 和第 `2*target+1` 个 `1` 之间的间隔（第二刀可以插的位置数）
7. 答案 = 两个间隔数之积

## 代码实现

### 方法一：数学计数（推荐）

```python
class Solution:
    def numWays(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        ones = s.count('1')

        if ones % 3 != 0:
            return 0

        if ones == 0:
            # 任意分割都合法，两刀各有 C(n-1, 2) 种
            return (n - 1) * (n - 2) // 2 % MOD

        target = ones // 3
        # 找所有 1 的位置
        pos = [i for i, c in enumerate(s) if c == '1']

        # 第一刀：在第 target 个 1 和 第 target+1 个 1 之间
        # 可以插的位置数 = pos[target] - pos[target-1]
        gap1 = pos[target] - pos[target - 1]
        # 第二刀：在第 2*target 个 1 和 第 2*target+1 个 1 之间
        gap2 = pos[2 * target] - pos[2 * target - 1]

        return gap1 * gap2 % MOD
```

### 方法二：逐步计算间隔

```python
class Solution:
    def numWays(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        ones = s.count('1')

        if ones % 3 != 0:
            return 0
        if ones == 0:
            return (n - 1) * (n - 2) // 2 % MOD

        t = ones // 3
        # 收集所有 1 的位置
        positions = [i for i, c in enumerate(s) if c == '1']

        # 第一刀在 positions[t-1] 之后、positions[t] 之前
        ways1 = positions[t] - positions[t - 1]  # 间隔内 '0' 的数量，即可插入位置数
        # 第二刀在 positions[2t-1] 之后、positions[2t] 之前
        ways2 = positions[2 * t] - positions[2 * t - 1]

        return ways1 * ways2 % MOD
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)（存储 1 的位置）；O(1) 若直接扫描

## 关键点总结

1. 每段需要 `total//3` 个 1
2. 两刀的可选位置独立，答案是两者的乘积
3. `ones == 0` 是特殊情况，任何分割都合法

## 易错点

- `ones == 0` 时答案是 `C(n-1, 2)`（两刀都在 n-1 个间隔中独立选择）
- 下标：第 t 个 1（1-indexed）对应 `pos[t-1]`（0-indexed）
