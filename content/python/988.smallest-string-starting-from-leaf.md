## 题目描述

给定一棵根结点为 `root` 的二叉树，树中的每一个结点都有一个 `[0, 25]` 范围内的值，分别代表字母 `'a'` 到 `'z'`。

返回按字典序最小的字符串，该字符串从这棵树的一个叶结点开始，到根结点结束。

**注意**：字符串中任何较短的前缀在字典序上都是较大的，例如，在字典序上 `"ab"` 比 `"aba"` 要大。叶结点是指没有子结点的结点。

**示例 1：**

```
输入：root = [0,1,2,3,4,3,4]
输出："dba"
```

**示例 2：**

```
输入：root = [25,1,3,1,3,0,2]
输出："adz"
```

**示例 3：**

```
输入：root = [2,2,1,null,1,0,null,0]
输出："abc"
```

**提示：**

- 给定树的结点数在 `[1, 8500]` 范围内
- `0 <= Node.val <= 25`

## 解题思路

这道题的关键点：

1. **从叶子到根**：需要注意题目要求是从叶子结点到根结点的路径，所以在构建字符串时要反向
2. **DFS 遍历**：使用深度优先搜索遍历所有从根到叶子的路径
3. **字典序比较**：在所有路径中找到字典序最小的

**算法流程：**

1. 使用 DFS 遍历二叉树，从根到叶子记录路径
2. 到达叶子节点时，将路径反转（因为是从叶子到根）
3. 比较所有路径，保留字典序最小的
4. 将数字转换为对应的字母（0->'a', 1->'b', ...）

**注意事项：**

- 空节点需要特殊处理
- 只有叶子节点才是有效路径的终点
- 路径要反转后再比较

## Python 代码实现

### 方法一：DFS + 路径收集（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def smallestFromLeaf(self, root: Optional[TreeNode]) -> str:
        """
        使用 DFS 遍历所有从根到叶子的路径
        时间复杂度：O(n)，其中 n 是节点数
        空间复杂度：O(h)，其中 h 是树的高度
        """
        self.result = None
        
        def dfs(node: Optional[TreeNode], path: str) -> None:
            if not node:
                return
            
            # 将当前节点的值转换为字母并添加到路径开头（反向构建）
            current_path = chr(ord('a') + node.val) + path
            
            # 如果是叶子节点，更新结果
            if not node.left and not node.right:
                if self.result is None or current_path < self.result:
                    self.result = current_path
                return
            
            # 递归遍历左右子树
            if node.left:
                dfs(node.left, current_path)
            if node.right:
                dfs(node.right, current_path)
        
        dfs(root, "")
        return self.result
```

### 方法二：DFS + 列表路径

```python
class Solution:
    def smallestFromLeaf(self, root: Optional[TreeNode]) -> str:
        """
        使用列表收集路径，最后转换为字符串
        """
        self.min_string = None
        
        def dfs(node: Optional[TreeNode], path: list) -> None:
            if not node:
                return
            
            # 将当前节点值添加到路径
            path.append(node.val)
            
            # 如果是叶子节点
            if not node.left and not node.right:
                # 反转路径并转换为字符串
                current_string = ''.join(chr(ord('a') + val) for val in reversed(path))
                
                # 更新最小字符串
                if self.min_string is None or current_string < self.min_string:
                    self.min_string = current_string
            else:
                # 继续遍历子树
                dfs(node.left, path)
                dfs(node.right, path)
            
            # 回溯：移除当前节点
            path.pop()
        
        dfs(root, [])
        return self.min_string
```

### 方法三：简化版（使用 min 函数）

```python
class Solution:
    def smallestFromLeaf(self, root: Optional[TreeNode]) -> str:
        """
        收集所有路径后使用 min 函数
        """
        def dfs(node: Optional[TreeNode], path: str) -> list:
            if not node:
                return []
            
            # 当前路径（从叶子到根的顺序）
            current_path = chr(ord('a') + node.val) + path
            
            # 如果是叶子节点，返回当前路径
            if not node.left and not node.right:
                return [current_path]
            
            # 收集所有子树的路径
            paths = []
            if node.left:
                paths.extend(dfs(node.left, current_path))
            if node.right:
                paths.extend(dfs(node.right, current_path))
            
            return paths
        
        # 获取所有路径并返回最小的
        all_paths = dfs(root, "")
        return min(all_paths) if all_paths else ""
```

## 复杂度分析

**方法一（推荐）：**
- 时间复杂度：O(n)，其中 n 是节点数，需要遍历所有节点
- 空间复杂度：O(h)，其中 h 是树的高度，递归栈的深度

**方法二：**
- 时间复杂度：O(n)
- 空间复杂度：O(h)，路径列表和递归栈

**方法三：**
- 时间复杂度：O(n * m)，其中 m 是平均路径长度（因为字符串比较）
- 空间复杂度：O(n)，需要存储所有路径

## 关键点总结

1. **路径方向**：题目要求从叶子到根，所以构建字符串时要反向添加
2. **叶子节点判断**：只有 `left` 和 `right` 都为空才是叶子节点
3. **字符串比较**：Python 的字符串比较自动按字典序
4. **边界处理**：需要处理只有根节点的情况
5. **优化技巧**：在 DFS 过程中直接构建反向字符串，避免最后反转

## 易错点

1. **忘记反转路径**：容易写成从根到叶子的路径
2. **非叶子节点也参与比较**：必须确保只在叶子节点时才比较
3. **空树处理**：虽然题目保证至少有一个节点，但代码应该健壮
4. **字符串拼接方向**：`chr(ord('a') + node.val) + path` 是正确的反向构建方式
