## 题目描述

你的初始能量为 power，初始分数为 0，你有一个由整数组成的袋子 tokens。

你可以用两种方式来使用这些令牌：

- 如果你当前 至少 有 tokens[i] 点能量，可以打出令牌 i，失去 tokens[i] 点能量，并得到 1 分
- 如果你当前至少有 1 分，可以重新打出令牌 i，获得 tokens[i] 点能量，并失去 1 分

每个令牌 最多 只能使用一次。返回使用任意数量的令牌后可以得到的最大分数。

## Python 代码实现

```python
from typing import List

class Solution:
    def bagOfTokensScore(self, tokens: List[int], power: int) -> int:
        tokens.sort()
        left, right = 0, len(tokens) - 1
        score = 0
        max_score = 0
        
        while left <= right:
            if power >= tokens[left]:
                # 花费能量获得分数
                power -= tokens[left]
                score += 1
                left += 1
                max_score = max(max_score, score)
            elif score > 0:
                # 花费分数获得能量
                power += tokens[right]
                score -= 1
                right -= 1
            else:
                break
        
        return max_score
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)
