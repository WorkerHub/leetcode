## 题目描述

给你一棵二叉树的根节点 `root`，返回其节点值的**后序遍历**。

**示例 1：**
```
输入：root = [1,null,2,3]
输出：[3,2,1]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [1]
输出：[1]
```

**提示：**
- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

## 解题思路

后序遍历的访问顺序是：**左子树 -> 右子树 -> 根节点**。

核心思想有两种：
1. **递归法**：利用系统栈，自然实现深度优先搜索
2. **迭代法**：手动维护栈，模拟递归过程

**关键观察：**
- 后序遍历是前序遍历的"镜像逆序"
- 前序遍历：根 -> 左 -> 右
- 调整为：根 -> 右 -> 左，然后反转结果即可得到后序遍历

## Python 代码实现

### 方法一：递归法（推荐-最简洁）

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        递归实现后序遍历
        时间复杂度：O(n)
        空间复杂度：O(n) - 递归栈深度
        """
        result = []
        
        def postorder(node):
            if not node:
                return
            # 后序遍历顺序：左 -> 右 -> 根
            postorder(node.left)   # 遍历左子树
            postorder(node.right)  # 遍历右子树
            result.append(node.val)  # 访问根节点
        
        postorder(root)
        return result
```

### 方法二：迭代法（使用栈）⭐

```python
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        迭代实现后序遍历（推荐掌握）
        核心思路：前序遍历变体 + 反转
        - 前序遍历：根 -> 左 -> 右
        - 调整为：根 -> 右 -> 左
        - 反转结果：左 -> 右 -> 根（后序遍历）
        """
        if not root:
            return []
        
        stack = [root]
        result = []
        
        while stack:
            node = stack.pop()
            result.append(node.val)
            
            # 注意：先压左子节点，后压右子节点
            # 这样弹出时先处理右子树
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        
        # 反转结果得到后序遍历
        return result[::-1]
```

### 方法三：迭代法（标准实现）

```python
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        标准迭代后序遍历
        使用 prev 指针记录上次访问的节点
        """
        if not root:
            return []
        
        stack = []
        result = []
        prev = None  # 记录上次访问的节点
        curr = root
        
        while curr or stack:
            # 一直向左走到底
            while curr:
                stack.append(curr)
                curr = curr.left
            
            # 查看栈顶节点
            curr = stack[-1]
            
            # 如果右子树不存在或已被访问，则访问当前节点
            if not curr.right or curr.right == prev:
                result.append(curr.val)
                stack.pop()
                prev = curr  # 记录为已访问
                curr = None  # 避免重复访问
            else:
                # 否则访问右子树
                curr = curr.right
        
        return result
```

## 复杂度分析

**方法一（递归）：**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈深度，最坏情况下为 n（链式树）

**方法二（迭代变体）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈的大小

**方法三（标准迭代）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**后序遍历过程：**
```

   - 访问根节点 2

```

## 关键点总结

1. **后序遍历顺序**：左 -> 右 -> 根
2. **递归实现**：最简洁，注意递归顺序
3. **迭代实现**：可以用"前序变体+反转"技巧，更容易理解
4. **标准迭代**：需要记录 prev 节点，判断右子树是否已访问
5. **应用场景**：删除树、计算树的高度等需要先处理子节点的问题

## 易错点

1. **递归顺序错误**：必须先递归左右子树，最后访问根节点
2. **迭代法栈操作**：方法二中要先压左节点再压右节点
3. **标准迭代中的判断**：需要判断右子树是否为空或已访问，防止重复访问
4. **空树处理**：记得处理 root 为 None 的情况
