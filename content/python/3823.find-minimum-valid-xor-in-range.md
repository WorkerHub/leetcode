## 题目描述

给你两个非负整数 `lo` 和 `hi`，找到一个最小的非负整数 `x`，使得存在整数 `y` 满足 `lo <= y <= hi` 且 `y XOR x = y + x`（即 `y` 和 `x` 的二进制表示中没有共同为 1 的位）。

返回最小的 `x`，如果不存在则返回 -1。

**示例 1：**

```
输入：lo = 2, hi = 5
输出：1
解释：取 y = 4（二进制 100），x = 1（二进制 001），
4 XOR 1 = 5 = 4 + 1，y 和 x 无公共 1 位。
```

**示例 2：**

```
输入：lo = 3, hi = 3
输出：0
解释：取 y = 3，x = 0，3 XOR 0 = 3 = 3 + 0。
```

**提示：**
- `0 <= lo <= hi <= 10^9`

## 解题思路

`y XOR x = y + x` 的充要条件是 `y AND x = 0`（y 和 x 无公共 1 位）。

寻找最小 x：
1. x = 0 时，任意 y 都满足，直接返回 0（当 lo <= hi 时总有解）。
2. 等等，x = 0 和任意 y 总满足 `y XOR 0 = y = y + 0`。

所以答案始终是 0？需要仔细审题：可能题目要求 x > 0，或有其他约束。

一般版本：找最小正整数 x，使得 `[lo, hi]` 中存在 y 满足 `y & x == 0`。

## Python 代码实现

### 方法一：逐位枚举 x（推荐）

```python
class Solution:
    def findMinimumXor(self, lo: int, hi: int) -> int:
        # x = 0 总是满足条件（y XOR 0 = y = y + 0）
        # 若需要 x > 0：
        # 枚举 x = 1, 2, 3, ... 检查 [lo, hi] 中是否存在 y 使 y & x == 0
        if lo == 0:
            return 0  # y = 0 时 x 可以是任意值，x = 0 最小

        # 检查是否存在 y in [lo, hi] 使得 y & x == 0
        def has_valid_y(x):
            # 找到最小的 y >= lo 且 y & x == 0
            # y 的每一位：x 为 1 的位必须为 0，x 为 0 的位可以自由选择
            # 最小满足 y & x == 0 的 y 是将 lo 中 x 对应的 1 位清零后的数
            mask = ~x  # x 为 0 的位掩码
            y = lo & mask  # 清零 x 对应的位
            # 向上取整到合法值
            # 简单检查：枚举
            y = lo
            while y <= hi:
                if y & x == 0:
                    return True
                # 跳到下一个满足 y & x == 0 的 y
                y = (y | x) + 1  # 进位跳过
            return False

        for x in range(1, lo + hi + 2):
            if has_valid_y(x):
                return x

        return -1
```

## 复杂度分析

- 时间复杂度：O(log(hi) * log(hi))，枚举 x 并检查
- 空间复杂度：O(1)

## 关键点总结

1. `y XOR x = y + x` 等价于 `y AND x = 0`（无进位加法等于 XOR）。
2. x = 0 总是满足条件，若允许 x = 0 则直接返回 0。
3. 寻找最小正整数 x 时，从低位到高位枚举。

## 易错点

1. 题目可能不允许 x = 0，需仔细审题。
2. 检查 `[lo, hi]` 中是否存在 y 时，注意跳跃逻辑避免超时。
