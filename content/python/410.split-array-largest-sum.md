## 题目描述

给定一个非负整数数组 nums 和一个整数 k，你需要将这个数组分成 k 个非空的连续子数组。

设计一个算法使得这 k 个子数组各自和的最大值最小。

**示例 1：**
```
输入：nums = [7,2,5,10,8], k = 2
输出：18
解释：一共有四种方法将 nums 分割为 2 个子数组。
其中最好的方式是将其分为 [7,2,5] 和 [10,8]，因为此时这两个子数组各自的和的最大值为18，在所有情况中最小。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5], k = 2
输出：9
```

**示例 3：**
```
输入：nums = [1,4,4], k = 3
输出：4
```

**提示：**
- 1 <= nums.length <= 1000
- 0 <= nums[i] <= 10^6
- 1 <= k <= min(50, nums.length)

## 解题思路

这道题可以用二分查找或动态规划解决。

### 二分查找思路（推荐）

核心观察：
1. 答案的范围：[max(nums), sum(nums)]
   - 最小值：至少要包含最大的单个元素
   - 最大值：所有元素在一个子数组中
2. 如果能在限制为 mid 的情况下分成 <= k 个子数组，说明答案 <= mid
3. 二分查找答案，验证可行性

验证函数：
- 给定一个限制 limit，判断能否将数组分成 <= k 个子数组，每个子数组和 <= limit

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        """
        二分查找最小的最大子数组和
        """
        def can_split(max_sum: int) -> bool:
            """
            判断是否能将数组分成 <= k 个子数组，每个和 <= max_sum
            """
            count = 1  # 至少需要一个子数组
            current_sum = 0
            
            for num in nums:
                if current_sum + num <= max_sum:
                    current_sum += num
                else:
                    # 需要新的子数组
                    count += 1
                    current_sum = num
            
            return count <= k
        
        # 二分查找范围
        left = max(nums)  # 最小可能：包含最大元素
        right = sum(nums)  # 最大可能：所有元素
        
        while left < right:
            mid = (left + right) // 2
            
            if can_split(mid):
                # 可以分成 <= k 个，尝试更小的 max_sum
                right = mid
            else:
                # 不能分成 <= k 个，需要更大的 max_sum
                left = mid + 1
        
        return left
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        """
        动态规划
        dp[i][j] = 将前 i 个数分成 j 个子数组的最小的最大子数组和
        """
        n = len(nums)
        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        # dp[i][j] = 前 i 个数分成 j 个子数组的结果
        dp = [[float('inf')] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0
        
        for i in range(1, n + 1):
            for j in range(1, min(i, k) + 1):
                # 枚举第 j 个子数组的起始位置
                for p in range(j - 1, i):
                    # 第 j 个子数组是 [p+1, i]
                    sub_sum = prefix[i] - prefix[p]
                    dp[i][j] = min(dp[i][j], max(dp[p][j - 1], sub_sum))
        
        return dp[n][k]
```

### 方法三：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        """
        记忆化搜索
        """
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        @lru_cache(None)
        def dfs(index: int, remaining: int) -> int:
            """
            从 index 开始，分成 remaining 个子数组
            """
            if remaining == 1:
                # 剩余所有元素作为一个子数组
                return prefix[n] - prefix[index]
            
            if index == n:
                return float('inf')
            
            result = float('inf')
            # 枚举当前子数组的结束位置
            for i in range(index, n - remaining + 1):
                # 当前子数组 [index, i]
                current_sum = prefix[i + 1] - prefix[index]
                # 剩余部分的最优解
                rest = dfs(i + 1, remaining - 1)
                # 更新答案
                result = min(result, max(current_sum, rest))
            
            return result
        
        return dfs(0, k)
```

## 复杂度分析

### 方法一：二分查找

- **时间复杂度**：O(n * log(sum - max))
  - 二分查找次数：O(log(sum - max))
  - 每次验证：O(n)
  
- **空间复杂度**：O(1)

### 方法二：动态规划

- **时间复杂度**：O(n^2 * k)
  
- **空间复杂度**：O(n * k)
