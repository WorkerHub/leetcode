## 题目描述

给定一个长度为 `n` 的整数数组 `nums`，其中每个元素均在 `[1, n]` 范围内，但某些元素出现了两次，某些元素缺失。

要求：在 **O(n) 时间** 和 **O(1) 额外空间**（不计返回值）内，找出所有在 `[1, n]` 内但未出现在 `nums` 中的整数。

**示例 1：**
```
输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]
解释：5 和 6 未出现在数组中。
```

**示例 2：**
```
输入：nums = [1,1]
输出：[2]
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`
- 本题与第 448 题类似，但要求额外处理某些重复出现三次或更多的情况

## 解题思路

原地标记法：利用数组下标与值的对应关系。

遍历数组，对于每个值 `v = abs(nums[i])`，将下标 `v-1` 对应的元素取反（标记为负数）表示值 `v` 已出现。
- 最后扫描一遍，下标 `i` 对应元素仍为正数说明值 `i+1` 未出现。

由于同一位置可能被多次取反，需要用绝对值访问原始值。

## Python 代码实现

### 方法一：原地标记（推荐，O(1) 额外空间）

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 第一遍：将出现过的数字对应下标位置的值取反
        for i in range(n):
            idx = abs(nums[i]) - 1  # 值 v 对应下标 v-1
            if nums[idx] > 0:
                nums[idx] = -nums[idx]
            # 若已经是负数，说明已被标记过（重复元素），不用再取反

        # 第二遍：仍为正数的下标对应的值就是消失的数字
        result = []
        for i in range(n):
            if nums[i] > 0:
                result.append(i + 1)

        # 恢复原数组（可选）
        for i in range(n):
            nums[i] = abs(nums[i])

        return result
```

### 方法二：哈希表（O(n) 额外空间，代码更简洁）

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        seen = set(nums)
        return [i for i in range(1, len(nums) + 1) if i not in seen]
```

## 复杂度分析

- 时间复杂度：O(n)，两次线性扫描
- 空间复杂度：方法一 O(1) 额外空间；方法二 O(n)

## 关键点总结

1. 原地标记：将出现过的数字映射到对应下标，用符号标记是否出现
2. 取反操作不影响后续读取（用 `abs()` 获取原始值）
3. 对于重复出现的元素，只需确保对应位置被标记一次（避免双重取反）

## 易错点

1. 重复元素可能导致同一位置被取反两次，需要先判断是否已经为负
2. 恢复原数组时别忘了取绝对值
