## 题目描述

给你一个由若干 0 和 1 组成的二维网格 grid，请你找出边界全部由 1 组成的最大正方形子网格，并返回该子网格的面积。如果不存在，则返回 0。

**示例 1：**
```
输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：9
解释：最大的正方形边长为 3
```

**示例 2：**
```
输入：grid = [[1,1,0,0]]
输出：1
```

**提示：**
- 1 <= grid.length <= 100
- 1 <= grid[0].length <= 100
- grid[i][j] 为 0 或 1

## 解题思路

这道题要找边界全部由 1 组成的最大正方形，内部可以是任意值。

**核心思路：**

1. **枚举 + 验证**：
   - 枚举所有可能的正方形左上角位置
   - 从大到小枚举正方形边长
   - 验证该正方形的四条边是否全为 1

2. **前缀和优化**：
   - 预处理每个位置向右和向下连续 1 的个数
   - 使用这些信息快速判断边界是否全为 1

3. **验证正方形边界的方法**：
   - 对于边长为 len 的正方形，左上角为 (r, c)
   - 需要检查：
     - 上边：(r, c) 到 (r, c+len-1)
     - 下边：(r+len-1, c) 到 (r+len-1, c+len-1)
     - 左边：(r, c) 到 (r+len-1, c)
     - 右边：(r, c+len-1) 到 (r+len-1, c+len-1)

4. **优化策略**：
   - 使用前缀和数组记录：
     - right[i][j]：从 (i,j) 向右连续 1 的个数
     - down[i][j]：从 (i,j) 向下连续 1 的个数
   - 验证时只需检查四个角点的前缀和值

## Python 代码实现

### 方法一：前缀和优化 ⭐

```python
from typing import List

class Solution:
    def largest1BorderedSquare(self, grid: List[List[int]]) -> int:
        """
        使用前缀和预处理，快速验证边界
        时间复杂度：O(m*n*min(m,n))
        空间复杂度：O(m*n)
        """
        if not grid or not grid[0]:
            return 0
        
        m, n = len(grid), len(grid[0])
        
        # 预处理：计算每个位置向右和向下连续 1 的个数
        right = [[0] * n for _ in range(m)]  # 向右连续 1 的个数
        down = [[0] * n for _ in range(m)]   # 向下连续 1 的个数
        
        # 从右下角开始逆向计算
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if grid[i][j] == 1:
                    right[i][j] = 1 if j == n - 1 else right[i][j + 1] + 1
                    down[i][j] = 1 if i == m - 1 else down[i + 1][j] + 1
        
        # 从大到小枚举正方形边长
        max_len = min(m, n)
        for length in range(max_len, 0, -1):
            # 枚举左上角位置
            for i in range(m - length + 1):
                for j in range(n - length + 1):
                    # 检查四个角点的前缀和值
                    # 左上角 (i, j) 向右和向下至少有 length 个 1
                    # 右上角 (i, j+length-1) 向下至少有 length 个 1
                    # 左下角 (i+length-1, j) 向右至少有 length 个 1
                    if (right[i][j] >= length and 
                        down[i][j] >= length and
                        right[i + length - 1][j] >= length and
                        down[i][j + length - 1] >= length):
                        return length * length
        
        return 0
```

### 方法二：直接验证边界

```python
class Solution:
    def largest1BorderedSquare(self, grid: List[List[int]]) -> int:
        """
        直接验证每条边是否全为 1
        时间复杂度：O(m*n*min(m,n)^2)
        空间复杂度：O(1)
        """
        m, n = len(grid), len(grid[0])
        max_side = 0
        
        # 枚举左上角
        for i in range(m):
            for j in range(n):
                # 从大到小枚举边长
                max_possible = min(m - i, n - j)
                for length in range(max_possible, 0, -1):
                    if self.is_valid_square(grid, i, j, length):
                        max_side = max(max_side, length)
                        break  # 找到当前位置最大边长，无需继续
        
        return max_side * max_side
    
    def is_valid_square(self, grid: List[List[int]], r: int, c: int, length: int) -> bool:
        """
        检查以 (r, c) 为左上角，边长为 length 的正方形边界是否全为 1
        """
        # 检查上边和下边
        for j in range(c, c + length):
            if grid[r][j] != 1 or grid[r + length - 1][j] != 1:
                return False
        
        # 检查左边和右边
        for i in range(r, r + length):
            if grid[i][c] != 1 or grid[i][c + length - 1] != 1:
                return False
        
        return True
```

### 方法三：动态规划（另一种前缀和形式）

```python
class Solution:
    def largest1BorderedSquare(self, grid: List[List[int]]) -> int:
        """
        使用二维前缀和的另一种形式
        """
        m, n = len(grid), len(grid[0])
        
        # horizontal[i][j]: 从 (i,0) 到 (i,j) 的 1 的个数（同行）
        # vertical[i][j]: 从 (0,j) 到 (i,j) 的 1 的个数（同列）
        horizontal = [[0] * n for _ in range(m)]
        vertical = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    horizontal[i][j] = 1 if j == 0 else horizontal[i][j - 1] + 1
                    vertical[i][j] = 1 if i == 0 else vertical[i - 1][j] + 1
        
        max_side = 0
        
        # 枚举右下角
        for i in range(m):
            for j in range(n):
                # 可能的最大边长
                max_len = min(horizontal[i][j], vertical[i][j])
                
                # 从大到小尝试
                for length in range(max_len, 0, -1):
                    # 检查上边和左边
                    top_row = i - length + 1
                    left_col = j - length + 1
                    
                    if (horizontal[top_row][j] >= length and 
                        vertical[i][left_col] >= length):
                        max_side = max(max_side, length)
                        break
        
        return max_side * max_side
```

## 复杂度分析

**方法一（前缀和优化）：**
- 时间复杂度：O(m × n × min(m,n))
  - 预处理：O(m × n)
  - 枚举边长和位置：O(min(m,n) × m × n)
  - 验证边界：O(1)
- 空间复杂度：O(m × n)，存储 right 和 down 数组

**方法二（直接验证）：**
- 时间复杂度：O(m × n × min(m,n)²)
  - 枚举：O(m × n × min(m,n))
  - 每次验证：O(min(m,n))
- 空间复杂度：O(1)

**方法三（另一种前缀和）：**
- 时间复杂度：O(m × n × min(m,n))
- 空间复杂度：O(m × n)

## 关键点总结

1. **前缀和预处理**：记录每个位置向右/向下连续 1 的个数
2. **从大到小枚举**：找到第一个有效正方形即可返回
3. **边界验证技巧**：只需检查四个角点的前缀和值
4. **优化剪枝**：对每个左上角位置，找到最大边长后可以 break
5. **边界条件**：注意边长为 1 的特殊情况

## 易错点

1. **前缀和方向**：注意是从右下向左上计算还是从左上向右下
2. **边界检查不完整**：必须检查四条边，不能只检查两条
3. **索引越界**：枚举左上角时要保证 i + length <= m
4. **返回值**：返回的是面积（length²），不是边长
5. **空矩阵处理**：需要处理空输入的情况
