## 题目描述

给你一个日志数组 logs。每条日志都是以空格分隔的字串，其第一个字为字母与数字混合的标识符。

有两种不同类型的日志：

- 字母日志：除标识符之外，所有字均由小写字母组成
- 数字日志：除标识符之外，所有字均由数字组成

请按下述规则将日志重新排序：

- 所有 字母日志 都排在 数字日志 之前
- 字母日志 在内容不同时，按内容字母顺序排序；在内容相同时，按标识符排序
- 数字日志 应该保留原来的相对顺序

## Python 代码实现

```python
from typing import List

class Solution:
    def reorderLogFiles(self, logs: List[str]) -> List[str]:
        def get_key(log):
            identifier, rest = log.split(' ', 1)
            if rest[0].isalpha():
                # 字母日志：先按内容排序，再按标识符排序
                return (0, rest, identifier)
            else:
                # 数字日志：保持原顺序
                return (1,)
        
        return sorted(logs, key=get_key)
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)
