## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。

每次操作可以选择矩阵中任意一个 `1`，**同时将该行和该列的所有元素置为 0**（包括该元素本身）。

返回将矩阵变为全 0 所需的**最少操作次数**。

**提示：**
- `1 <= m, n <= 15`

## 解题思路

**状态压缩 BFS/DP**

将每行用一个二进制数表示（行掩码），整个矩阵状态用行掩码的元组表示。

BFS：从初始状态开始，每次操作选择一个 1 并将其所在行和列清零，找到达到全 0 状态的最少步数。

由于 m, n <= 15，矩阵可以用 n 个 m 位的掩码（按行存储）或 m 个 n 位的掩码来表示。使用 BFS + 状态哈希。

## 代码实现

### 方法一：BFS 状态搜索（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def removeOnes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 将矩阵编码为状态（tuple of rows as ints）
        def encode(g):
            return tuple(
                sum(g[i][j] << j for j in range(n))
                for i in range(m)
            )

        start = encode(grid)
        if all(r == 0 for r in start):
            return 0

        visited = {start}
        queue = deque([(start, 0)])

        while queue:
            state, ops = queue.popleft()
            # 枚举所有 1 的位置
            for i in range(m):
                for j in range(n):
                    if (state[i] >> j) & 1:
                        # 清除第 i 行和第 j 列
                        new_state = list(state)
                        new_state[i] = 0  # 第 i 行全部清零
                        for r in range(m):
                            new_state[r] &= ~(1 << j)  # 第 j 列清零
                        new_state = tuple(new_state)
                        if all(r == 0 for r in new_state):
                            return ops + 1
                        if new_state not in visited:
                            visited.add(new_state)
                            queue.append((new_state, ops + 1))

        return -1
```

### 方法二：迭代加深 DFS

```python
from typing import List

class Solution:
    def removeOnes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        def get_ones(g):
            return [(i, j) for i in range(m) for j in range(n) if g[i][j]]

        def apply_op(g, r, c):
            new_g = [row[:] for row in g]
            for j in range(n):
                new_g[r][j] = 0
            for i in range(m):
                new_g[i][c] = 0
            return new_g

        def dfs(g, depth):
            ones = get_ones(g)
            if not ones:
                return 0
            if depth == 0:
                return float('inf')
            # 选第一个 1 的位置
            r, c = ones[0]
            new_g = apply_op(g, r, c)
            return 1 + dfs(new_g, depth - 1)

        for ans in range(len(get_ones(grid)) + 1):
            if dfs(grid, ans) <= ans:
                return ans
        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(states * m * n) | O(states) |

## 关键点总结

1. 每次操作清零一行和一列，可能同时消除多个 1。
2. BFS 从初始状态出发，每步枚举所有可能的操作，找最短路径。
3. 状态编码：每行用一个整数表示（第 j 位 = 第 j 列的值）。

## 易错点

- 操作时将整行清零（不只是该行中选中的元素）和整列清零。
- 状态需要可哈希（用 tuple）。
