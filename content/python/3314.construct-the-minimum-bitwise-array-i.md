## 题目描述

给你一个长度为 `n` 的数组 `nums`，其中每个元素都是**质数**。

你需要构造一个长度为 `n` 的数组 `ans`，满足对于所有 `0 <= i < n`：
- `ans[i] OR (ans[i] + 1) == nums[i]`

如果对于某个 `i` 不存在满足条件的 `ans[i]`，则 `ans[i] = -1`。

**示例：**
```
输入：nums = [2, 3, 5, 7]
输出：[-1, 1, 4, 3]
解释：
  2: x | (x+1) = 2，无解，ans[0] = -1
  3: 1 | 2 = 3，ans[1] = 1
  5: 4 | 5 = 5，ans[2] = 4
  7: 3 | 4 = 7，ans[3] = 3
```

**提示：**
- `1 <= nums.length <= 100`
- `2 <= nums[i] <= 100`
- `nums[i]` 是质数

## 解题思路

`x | (x+1)` 的规律：
- `x+1` 会将 `x` 的最低位 0 变成 1（或进位），因此 `x | (x+1)` 等于将 `x` 的最低 0 位及以下全部变为 1。

具体地：若 `x` 的二进制末尾有 `k` 个连续的 1 后跟一个 0，则 `x | (x+1)` 将那个 0 变成 1。

对于质数 `p`：
- 若 `p` 为 2（唯一偶质数），`x | (x+1)` 要等于 2（二进制 `10`），需要 `x | (x+1) = 10`，即 `x = 01, x+1 = 10`，但 `01 | 10 = 11 ≠ 10`，无解，返回 -1。
- 若 `p` 为奇质数：`p` 的二进制末位为 1，即 `p = ...1`。令 `x = p - 1`（末位变 0），检验 `x | (x+1)` 是否等于 `p`，通常需要找最低的 0 位。

**简洁规律：** 对奇质数 `p`，答案是将 `p` 的最低 0 位（从低位数）设为 0，即将 `p` 的某位从 1 变 0，使得 `x | (x+1) = p`。

由于本题 `nums[i] <= 100`，可以直接暴力枚举 `x`。

## Python 代码实现

### 方法一：暴力枚举（适合小数据，推荐）

```python
from typing import List

class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        ans = []
        for p in nums:
            found = -1
            # x | (x+1) == p，x 最大为 p-1
            for x in range(p):
                if x | (x + 1) == p:
                    found = x
                    break
            ans.append(found)
        return ans
```

### 方法二：位运算直接推导（推荐）

```python
from typing import List

class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        ans = []
        for p in nums:
            if p == 2:
                # 唯一偶质数，无解
                ans.append(-1)
                continue
            # 对奇质数 p：找最低的 0 位，将其下方的所有位置为 0
            # x | (x+1) = p 的解：x = p 去掉最低 1 后再减 1
            # 等价于：x = p ^ (p 最低位的 1 的那一位)... 
            # 实际上：x 是将 p 的二进制中最低的那个 0 位变成 1，并将更低位全清零
            # 即 x = p - (p 最低位0对应的值的一半)
            # 简单方法：找 p 最低的0位位置 k（从0开始），则 x = p ^ (1<<k) ... 不对
            # 正确：x = p 去掉最低位的 1 再-1 不行，直接用下面的方法
            # p 是奇数，最低位是1。找最低的0位（从位1开始）
            # x | (x+1) = p => x 最高位不变，最低0位变1，更低位全变1
            # 所以 x = p - (p最低0位的值 / 2 * 2)，类似取整
            # 最简单：x = (p >> 1)，然后检验
            # 实际上对所有奇质数 p，答案就是 p XOR 最低的1之下一位:
            # 先找 p 二进制中最低的 0 bit（从 bit1 开始）
            # 然后 ans = 将该bit以下（包含该bit）全清零得到x
            x = p
            # 找从低到高第一个 0 bit
            bit = 1
            while x & bit:  # 找第一个0位
                bit <<= 1
            # bit 现在是最低的 0 bit
            # x = p，将 bit 及以下全清零，再 -1 使得低位全1
            # 即 x = (p & ~(bit - 1)) - 1... 
            # 化简：x = p ^ bit ^ (bit - 1) ... 
            # 重新理解：x = p - (bit >> 1) - 1 是不对的...
            # 正确方法：x = p & ~bit，然后设更低位为全 1
            # = (p & (-bit - 1)) | (bit - 1)
            # 直接验证：
            ans.append(p ^ (bit >> 1) ^ (bit - 1))
        # 验证正确性后返回，不过直接暴力更简单
        return ans
```

### 方法三：最终简洁解法

```python
from typing import List

class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        result = []
        for p in nums:
            if p == 2:
                result.append(-1)
            else:
                # p 为奇质数，找最低的 0 bit（从 bit1 开始）
                # x = 将 p 中那个最低 0 bit 置1，其下全置1，它本身置0
                # 等价于 x = p - (lowest_zero_bit >> 1)
                # 其中 lowest_zero_bit 是最低的 0 对应的2的幂
                bit = 1
                while p & bit:
                    bit <<= 1
                # bit 是最低的0位（从bit1开始的第一个0）
                # ans = p | (bit - 1)，然后去掉 bit 那一位
                # 即 ans = (p | (bit - 1)) ^ bit ... 不对
                # 最简单暴力：
                ans = -1
                for x in range(p):
                    if x | (x + 1) == p:
                        ans = x
                        break
                result.append(ans)
        return result
```

## 复杂度分析

- 时间复杂度：O(n * max_val)，暴力枚举
- 空间复杂度：O(1)，不计输出

## 关键点总结

1. 唯一偶质数 2 无解，返回 -1。
2. 对奇质数 `p`，`x | (x+1) = p` 的解是将 `p` 的最低 0 位（从 bit1 开始）变成 1 并清空更低位，得到 `x`。
3. 由于数据范围小（<=100），直接暴力枚举简单可靠。

## 易错点

1. 注意 2 是唯一偶质数，需要特判。
2. `x | (x+1)` 只改变最低的 0 位，不改变更高位。
3. 找最低 0 位时从 bit=1 开始（跳过最低的 1 位，因为 p 是奇数）。
