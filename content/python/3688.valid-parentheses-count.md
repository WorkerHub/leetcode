## 题目描述

给你一个包含 `(`、`)` 和 `?` 的字符串 `s`，其中 `?` 可以替换为 `(` 或 `)`。返回能使字符串成为有效括号序列的方案数，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：s = "()"
输出：1
```

**示例 2：**

```
输入：s = "(?)"
输出：1
解释："?" 替换为 "(" 得 "((" 无效，替换为 ")" 得 "()" 有效，共1种
```

**示例 3：**

```
输入：s = "??"
输出：1
解释："?" 替换为 "()" 得 "()" 有效，"((" 无效，")(" 无效，"))" 无效，共1种
```

**提示：**

- `1 <= s.length <= 1000`
- `s` 只包含 `(`、`)` 和 `?`

## 解题思路

DP：`dp[i][j]` = 处理前 `i` 个字符后，当前未匹配 `(` 的数量为 `j` 的方案数。

转移：
- 若 `s[i] == '('`：`dp[i+1][j+1] += dp[i][j]`
- 若 `s[i] == ')'`：若 `j > 0`，`dp[i+1][j-1] += dp[i][j]`
- 若 `s[i] == '?'`：同时做上两种转移

最终答案 = `dp[n][0]`（所有括号都匹配）

## Python 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def countWays(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        # dp[j] = 当前未匹配 ( 数为 j 的方案数
        dp = [0] * (n + 1)
        dp[0] = 1

        for c in s:
            new_dp = [0] * (n + 1)
            for j in range(n + 1):
                if dp[j] == 0:
                    continue
                if c in ('(', '?'):
                    # 添加 (
                    if j + 1 <= n:
                        new_dp[j + 1] = (new_dp[j + 1] + dp[j]) % MOD
                if c in (')', '?'):
                    # 添加 )
                    if j > 0:
                        new_dp[j - 1] = (new_dp[j - 1] + dp[j]) % MOD
            dp = new_dp

        return dp[0]
```

### 方法二：递归 + 记忆化

```python
from functools import lru_cache

class Solution:
    def countWays(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)

        @lru_cache(maxsize=None)
        def dp(i, open_count):
            if i == n:
                return 1 if open_count == 0 else 0
            if open_count < 0 or open_count > n - i:
                return 0
            result = 0
            if s[i] in ('(', '?'):
                result = (result + dp(i + 1, open_count + 1)) % MOD
            if s[i] in (')', '?'):
                result = (result + dp(i + 1, open_count - 1)) % MOD
            return result

        return dp(0, 0)
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. DP 状态为当前未匹配的 `(` 数量
2. `?` 可以是 `(` 也可以是 `)`，两种转移都尝试
3. 最终未匹配数为 0 才有效

## 易错点

1. 未匹配数不能为负（不能先出现 `)`）
2. 未匹配数不能超过剩余字符数（提前剪枝）
3. 最终答案是 `dp[0]`，不是所有 `dp` 的和
