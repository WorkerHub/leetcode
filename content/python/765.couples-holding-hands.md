## 题目描述

`n` 对情侣坐在连续排列的 `2n` 个座位上，想要牵到对方的手。

人和座位用 `0` 到 `2n - 1` 的整数表示，情侣们按顺序编号，第一对是 `(0, 1)`，第二对是 `(2, 3)`，以此类推，最后一对是 `(2n - 2, 2n - 1)`。

给定数组 `row` 表示 `2n` 个人的座位安排，返回最少交换次数以便每对情侣可以并肩坐在一起。每次交换可以选择任意两个人让他们交换座位。

**示例 1:**
```
输入: row = [0,2,1,3]
输出: 1
解释: 只需要交换 row[1] 和 row[2] 的位置即可。
```

**示例 2:**
```
输入: row = [3,2,0,1]
输出: 0
解释: 已经排好了。
```

**提示:**
- `2n == row.length`
- `2 <= n <= 30`
- `n` 是偶数
- `0 <= row[i] < 2n`
- `row` 中所有元素均不重复

## 解题思路

### 贪心算法
对于每一对座位，如果左边的人和右边的人不是情侣，就找到左边的人的伴侣，将右边的人和伴侣交换。

### 并查集
将每对座位看作一个节点，如果两对座位上坐的不是两对情侣，就连一条边。最后需要的交换次数等于 `总节点数 - 连通分量数`。

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def minSwapsCouples(self, row: List[int]) -> int:
        n = len(row)
        swaps = 0
        
        # 记录每个人的位置
        pos = {person: i for i, person in enumerate(row)}
        
        def partner(x):
            """返回 x 的伴侣编号"""
            return x + 1 if x % 2 == 0 else x - 1
        
        for i in range(0, n, 2):
            # 左边座位的人
            first = row[i]
            # 左边的人的伴侣
            second = partner(first)
            
            # 如果右边座位不是伴侣
            if row[i + 1] != second:
                # 找到伴侣的位置
                j = pos[second]
                # 交换
                row[i + 1], row[j] = row[j], row[i + 1]
                # 更新位置
                pos[row[j]] = j
                pos[row[i + 1]] = i + 1
                swaps += 1
        
        return swaps
```

### 方法二：并查集

```python
class Solution:
    def minSwapsCouples(self, row: List[int]) -> int:
        n = len(row) // 2
        
        # 并查集
        parent = list(range(n))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py
        
        # 将每对座位上的两个人所属的情侣对连接起来
        for i in range(0, len(row), 2):
            couple1 = row[i] // 2
            couple2 = row[i + 1] // 2
            union(couple1, couple2)
        
        # 计算连通分量数
        return n - sum(find(i) == i for i in range(n))
```

### 方法三：图论（环检测）

```python
class Solution:
    def minSwapsCouples(self, row: List[int]) -> int:
        n = len(row) // 2
        couples = [[] for _ in range(n)]
        
        # 构建图
        for i in range(0, len(row), 2):
            couple1 = row[i] // 2
            couple2 = row[i + 1] // 2
            couples[couple1].append(couple2)
            couples[couple2].append(couple1)
        
        # 计算环的数量
        visited = [False] * n
        swaps = 0
        
        for i in range(n):
            if not visited[i]:
                # BFS 找环
                cycle_size = 0
                queue = [i]
                visited[i] = True
                
                while queue:
                    node = queue.pop(0)
                    cycle_size += 1
                    
                    for neighbor in couples[node]:
                        if not visited[neighbor]:
                            visited[neighbor] = True
                            queue.append(neighbor)
                
                # 每个大小为 k 的环需要 k-1 次交换
                swaps += cycle_size - 1
        
        return swaps
```

## 复杂度分析

**方法一：贪心**
- **时间复杂度：** O(n)
- **空间复杂度：** O(n)

**方法二：并查集**
- **时间复杂度：** O(n α(n))
- **空间复杂度：** O(n)

## 关键点总结

1. **贪心策略：** 逐对处理，每次找到伴侣交换
2. **伴侣计算：** `x` 的伴侣是 `x^1`（异或1）
3. **并查集应用：** 将问题转化为连通分量
4. **环的性质：** 大小为 k 的环需要 k-1 次交换

## 易错点

1. **伴侣计算：** 0和1是一对，2和3是一对
2. **位置更新：** 交换后要更新位置映射
3. **步进：** 每次处理两个座位，步进为2
