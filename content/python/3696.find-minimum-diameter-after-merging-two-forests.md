## 题目描述

给你两棵树（无向连通图），边集分别为 `edges1` 和 `edges2`，节点数分别为 `n` 和 `m`。将两棵树通过一条新边连接（新边连接两棵树各一个节点），返回合并后图的最小可能直径。

树的直径是树中任意两节点间最长路径的长度。

**示例 1：**

```
输入：n = 4, edges1 = [[0,1],[1,2],[2,3]], m = 4, edges2 = [[0,1],[1,2],[2,3]]
输出：3
```

**提示：**

- `1 <= n, m <= 10^5`
- `edges1.length == n - 1`，`edges2.length == m - 1`

## 解题思路

合并两棵树后，新直径为以下三种情况的最大值：
1. 树 1 原有直径
2. 树 2 原有直径
3. 从树 1 某节点到连接边，再到树 2 某节点的路径

对情况 3，最优连接点是使距离最远点尽量近的节点，即树的"中心"节点（距离最远节点的距离最小）。

最优连接代价 = `ceil(d1/2) + 1 + ceil(d2/2)`，其中 d1、d2 分别是两棵树的直径。

最终答案 = `max(d1, d2, ceil(d1/2) + 1 + ceil(d2/2))`。

## Python 代码实现

### 方法一：两次 BFS 求直径（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minimumDiameterAfterMerge(self, n: int, edges1: List[List[int]],
                                   m: int, edges2: List[List[int]]) -> int:
        def tree_diameter(num_nodes, edges):
            if num_nodes == 1:
                return 0
            graph = defaultdict(list)
            for u, v in edges:
                graph[u].append(v)
                graph[v].append(u)

            def bfs(start):
                dist = [-1] * num_nodes
                dist[start] = 0
                queue = deque([start])
                farthest = start
                while queue:
                    node = queue.popleft()
                    for nb in graph[node]:
                        if dist[nb] == -1:
                            dist[nb] = dist[node] + 1
                            if dist[nb] > dist[farthest]:
                                farthest = nb
                            queue.append(nb)
                return farthest, dist[farthest]

            # 两次 BFS 求直径
            far1, _ = bfs(0)
            far2, diameter = bfs(far1)
            return diameter

        d1 = tree_diameter(n, edges1)
        d2 = tree_diameter(m, edges2)

        # 最优连接
        combined = (d1 + 1) // 2 + 1 + (d2 + 1) // 2

        return max(d1, d2, combined)
```

### 方法二：DFS 求直径

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumDiameterAfterMerge(self, n: int, edges1: List[List[int]],
                                   m: int, edges2: List[List[int]]) -> int:
        def get_diameter(num_nodes, edges):
            graph = defaultdict(list)
            for u, v in edges:
                graph[u].append(v)
                graph[v].append(u)

            diameter = [0]

            def dfs(node, parent):
                max1 = max2 = 0
                for nb in graph[node]:
                    if nb == parent:
                        continue
                    depth = dfs(nb, node) + 1
                    if depth > max1:
                        max2 = max1
                        max1 = depth
                    elif depth > max2:
                        max2 = depth
                diameter[0] = max(diameter[0], max1 + max2)
                return max1

            dfs(0, -1)
            return diameter[0]

        d1 = get_diameter(n, edges1)
        d2 = get_diameter(m, edges2)
        combined = (d1 + 1) // 2 + 1 + (d2 + 1) // 2

        return max(d1, d2, combined)
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. 合并后直径取三种情况最大值
2. 最优连接点是树的"中心"（直径的中点）
3. 连接代价 = `ceil(d1/2) + 1 + ceil(d2/2)`

## 易错点

1. `ceil(d/2) = (d+1)//2`（整数上取整）
2. 连接边本身贡献 1
3. 情况 3 不一定大于情况 1 或 2
