## 题目描述

给你一个二维整数数组 `envelopes`，其中 `envelopes[i] = [wi, hi]`，表示第 `i` 个信封的宽度和高度。

当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里，如同俄罗斯套娃一样。

请计算最多能有多少个信封能组成一组"俄罗斯套娃"信封（即可以把一个信封放到另一个信封里面）。

注意：不允许旋转信封。

**示例 1：**
```
输入：envelopes = [[5,4],[6,4],[6,7],[2,3]]
输出：3
解释：最多信封的个数为 3, 组合为: [2,3] => [5,4] => [6,7]。
```

**示例 2：**
```
输入：envelopes = [[1,1],[1,1],[1,1]]
输出：1
```

**提示：**
- `1 <= envelopes.length <= 10^5`
- `envelopes[i].length == 2`
- `1 <= wi, hi <= 10^5`

## 解题思路

这道题是 [300. 最长递增子序列](https://leetcode.com/problems/longest-increasing-subsequence/) 的二维版本。

**核心思想：**
1. 按宽度升序排序，宽度相同时按高度降序排序
2. 在高度上求最长递增子序列（LIS）

**为什么宽度相同时高度降序？**
- 避免宽度相同的信封被同时选中
- 例如 `[[3,3], [3,4]]`，如果都按升序，会错误地认为可以嵌套

## Python 代码实现

### 方法一：排序 + DP（O(n²)）

```python
from typing import List

class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        # 按宽度升序，宽度相同时高度降序
        envelopes.sort(key=lambda x: (x[0], -x[1]))
        
        # 提取高度数组
        heights = [h for w, h in envelopes]
        
        # 求最长递增子序列
        n = len(heights)
        dp = [1] * n
        
        for i in range(1, n):
            for j in range(i):
                if heights[j] < heights[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        
        return max(dp)
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

### 方法二：排序 + 二分（O(n log n)）⭐

```python
import bisect

class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        # 排序
        envelopes.sort(key=lambda x: (x[0], -x[1]))
        
        # 提取高度
        heights = [h for w, h in envelopes]
        
        # 二分法求 LIS
        tails = []
        
        for h in heights:
            # 找到第一个 >= h 的位置
            pos = bisect.bisect_left(tails, h)
            
            if pos == len(tails):
                tails.append(h)
            else:
                tails[pos] = h
        
        return len(tails)
```

**时间复杂度：** O(n log n)
**空间复杂度：** O(n)

```
tails = []

```

## 关键点总结

1. **排序策略**：宽度升序，高度降序
2. **降维**：转化为一维 LIS 问题
3. **二分优化**：O(n log n) 求 LIS
4. **避免重复**：高度降序防止宽度相同的信封被选中

## 易错点

1. **排序方式**
   ```python
   # 错误：都升序
   envelopes.sort()
   
   # 正确：宽度升序，高度降序
   envelopes.sort(key=lambda x: (x[0], -x[1]))
   ```

2. **LIS 判断条件**
   ```python
   # 要严格递增
   if heights[j] < heights[i]:  # 不能有等号
   ```
