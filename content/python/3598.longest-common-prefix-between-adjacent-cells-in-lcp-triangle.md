## 题目描述

给定一个字符串数组 `words`。构建 LCP 三角形：三角形第 `i` 行第 `j` 个元素（0-indexed）定义为 `lcp(words[i], words[j])`（即 `words[i]` 和 `words[j]` 的最长公共前缀长度）。

对三角形中相邻的单元格（同行相邻或上下相邻），求相邻单元格之差的绝对值之和的最大值。返回该最大值。

**示例：**

```
输入：words = ["ab","bc","cd"]
输出：2
解释：lcp[0][1]=0, lcp[0][2]=0, lcp[1][2]=0（无公共前缀）。
     若 words=["aa","ab","aa"]：lcp[0][1]=1, lcp[0][2]=2, lcp[1][2]=1。
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 20`

## 解题思路

首先预计算所有 lcp[i][j]（最长公共前缀长度）：O(n^2 * L)。

然后在三角形中，枚举所有相邻对（同行相邻：(i,j)和(i,j+1)；行间相邻：(i,j)和(i+1,j)，(i,j)和(i+1,j+1)），求差绝对值，取最大。

LCP 三角形中 (i,j) 对应 lcp(words[i], words[j])，i < j。

相邻关系：
- 同行：(i,j) 和 (i, j+1)，0 <= i < j < j+1
- 斜边：(i,j) 和 (i+1, j)，以及 (i,j) 和 (i+1, j+1)

## Python 代码实现

### 方法一：预计算 LCP + 枚举相邻（推荐）

```python
from typing import List

class Solution:
    def maxDifference(self, words: List[str]) -> int:
        n = len(words)

        # 计算两个字符串的 LCP 长度
        def lcp(a: str, b: str) -> int:
            i = 0
            while i < len(a) and i < len(b) and a[i] == b[i]:
                i += 1
            return i

        # 预计算 lcp 矩阵（只需 i < j 的部分）
        lcp_mat = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                lcp_mat[i][j] = lcp(words[i], words[j])

        ans = 0

        # 三角形行 i 包含 (i, i+1), (i, i+2), ..., (i, n-1)
        # 枚举同行相邻：(i, j) 和 (i, j+1)
        for i in range(n):
            for j in range(i + 1, n - 1):
                diff = abs(lcp_mat[i][j] - lcp_mat[i][j + 1])
                ans = max(ans, diff)

        # 枚举行间相邻：三角形的"行"是按第一个下标分组
        # 实际上 LCP 三角形通常指 (row, col) = (i, j) 对应 lcp[i][j]
        # i 从 0 到 n-2，j 从 i+1 到 n-1
        # 行间相邻：(i, j) 和 (i+1, j)（若 i+1 < j）
        for i in range(n - 1):
            for j in range(i + 2, n):  # j >= i+2 才有 (i+1, j)
                diff = abs(lcp_mat[i][j] - lcp_mat[i + 1][j])
                ans = max(ans, diff)

        # 斜向相邻：(i, j) 和 (i+1, j+1)（若 i+1 < j+1）
        for i in range(n - 1):
            for j in range(i + 1, n - 1):
                diff = abs(lcp_mat[i][j] - lcp_mat[i + 1][j + 1])
                ans = max(ans, diff)

        return ans
```

### 方法二：动态规划预计算 LCP

```python
from typing import List

class Solution:
    def maxDifference(self, words: List[str]) -> int:
        n = len(words)
        max_len = max(len(w) for w in words)

        # 用 DP 计算 LCP：lcp[i][j] = 若 words[i][0..] == words[j][0..]
        # 直接用字符比较
        lcp_mat = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i, n):
                k = 0
                while k < len(words[i]) and k < len(words[j]) and words[i][k] == words[j][k]:
                    k += 1
                lcp_mat[i][j] = lcp_mat[j][i] = k

        ans = 0
        # 枚举所有相邻对
        for i in range(n):
            for j in range(i + 1, n):
                # 同行相邻（j 和 j+1）
                if j + 1 < n:
                    ans = max(ans, abs(lcp_mat[i][j] - lcp_mat[i][j + 1]))
                # 列相邻（i 和 i+1）
                if i + 1 < j:
                    ans = max(ans, abs(lcp_mat[i][j] - lcp_mat[i + 1][j]))
                # 对角线
                if i + 1 < n and j + 1 < n:
                    ans = max(ans, abs(lcp_mat[i][j] - lcp_mat[i + 1][j + 1]))

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为单词数，L 为最长单词长度
- 空间复杂度：O(n^2)，存储 LCP 矩阵

## 关键点总结

1. 预计算所有 lcp[i][j]，避免重复计算
2. 三角形中的相邻关系有三种：同行、列向、对角线
3. 枚举所有相邻对取差的最大值

## 易错点

1. LCP 计算时注意越界（单词长度不同）
2. 三角形相邻关系要覆盖全面，不遗漏对角线相邻
3. i < j 是 LCP 三角形下标约束
