## 题目描述

给你一个 2 行 n 列的二进制数组：

- 矩阵是一个二进制矩阵，这意味着矩阵中的每个元素不是 0 就是 1。
- 第 0 行的元素之和为 upper。
- 第 1 行的元素之和为 lower。
- 第 i 列（从 0 开始编号）的元素之和为 colsum[i]，colsum 是一个长度为 n 的整数数组。

你需要利用 upper，lower 和 colsum 来重构这个矩阵，并以二维整数数组的形式返回它。

如果有多个不同的答案，那么任意一个都可以通过本题。

如果不存在符合要求的答案，就请返回一个空的二维数组。

示例 1：

```
输入：upper = 2, lower = 1, colsum = [1,1,1]
输出：[[1,1,0],[0,0,1]]
解释：[[1,0,1],[0,1,0]] 和 [[0,1,1],[1,0,0]] 也是正确答案。
```

示例 2：

```
输入：upper = 2, lower = 3, colsum = [2,2,1,1]
输出：[]
```

示例 3：

```
输入：upper = 5, lower = 5, colsum = [2,1,2,0,1,0,1,2,0,1]
输出：[[1,1,1,0,1,0,0,1,0,0],[1,0,1,0,0,0,1,1,0,1]]
```

提示：

- 1 <= colsum.length <= 10^5
- 0 <= upper, lower <= colsum.length
- 0 <= colsum[i] <= 2

## 解题思路

这是一道贪心算法题目。核心思路：

1. 先进行可行性检查：
   - 如果 sum(colsum) != upper + lower，无解
   - 如果某列 colsum[i] = 2，那么该列必须是 [1, 1]
   - 如果某列 colsum[i] = 0，那么该列必须是 [0, 0]

2. 贪心策略：
   - 对于 colsum[i] = 2，两行都放 1
   - 对于 colsum[i] = 0，两行都放 0
   - 对于 colsum[i] = 1，优先分配给还有余额的行

3. 具体实现：
   - 遍历 colsum，对于值为 2 的列，upper 和 lower 都减 1
   - 对于值为 1 的列，优先分配给 upper（也可以用其他策略）
   - 最后检查 upper 和 lower 是否都为 0

## Python 代码实现

### 方法一：贪心算法（推荐）

```python
from typing import List

class Solution:
    def reconstructMatrix(self, upper: int, lower: int, colsum: List[int]) -> List[List[int]]:
        n = len(colsum)
        result = [[0] * n for _ in range(2)]
        
        # 先处理 colsum = 2 的列
        for i in range(n):
            if colsum[i] == 2:
                result[0][i] = 1
                result[1][i] = 1
                upper -= 1
                lower -= 1
        
        # 处理 colsum = 1 的列
        for i in range(n):
            if colsum[i] == 1:
                if upper > 0:
                    # 优先分配给第一行
                    result[0][i] = 1
                    upper -= 1
                elif lower > 0:
                    # 否则分配给第二行
                    result[1][i] = 1
                    lower -= 1
                else:
                    # 无法分配，返回空
                    return []
        
        # 检查是否所有的 upper 和 lower 都用完
        if upper == 0 and lower == 0:
            return result
        else:
            return []
```

### 方法二：先检查可行性

```python
from typing import List

class Solution:
    def reconstructMatrix(self, upper: int, lower: int, colsum: List[int]) -> List[List[int]]:
        n = len(colsum)
        
        # 检查总和是否匹配
        if sum(colsum) != upper + lower:
            return []
        
        # 统计 colsum = 2 的个数
        two_count = colsum.count(2)
        
        # colsum = 2 的列，upper 和 lower 都必须贡献 1
        if two_count > upper or two_count > lower:
            return []
        
        # 剩余需要分配的 1
        upper -= two_count
        lower -= two_count
        
        # 初始化结果
        result = [[0] * n for _ in range(2)]
        
        # 填充矩阵
        for i in range(n):
            if colsum[i] == 2:
                result[0][i] = 1
                result[1][i] = 1
            elif colsum[i] == 1:
                if upper > 0:
                    result[0][i] = 1
                    upper -= 1
                else:
                    result[1][i] = 1
                    lower -= 1
        
        return result
```

## 复杂度分析

时间复杂度：O(n)，遍历 colsum 数组两次
空间复杂度：O(n)，存储结果矩阵

## 关键点总结

1. 贪心策略：优先处理确定的情况（colsum = 2 和 0）
2. 对于 colsum = 1 的列，优先分配给剩余额度较大的行
3. 需要先检查可行性：sum(colsum) = upper + lower
4. 时刻维护 upper 和 lower 的余额

## 易错点

1. 忘记检查总和是否等于 upper + lower
2. 没有优先处理 colsum = 2 的情况
3. 分配 colsum = 1 时没有检查余额是否足够
4. 最后忘记验证 upper 和 lower 是否都为 0
