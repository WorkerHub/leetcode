## 题目描述

给你一个整数数组 `nums`。

返回数组 `nums` 中 **严格递增** 或 **严格递减** 的最长子数组的长度。

**示例 1：**
```
输入：nums = [1,4,3,3,2]
输出：2
解释：严格递增子数组：[1,4]，长度为 2；严格递减子数组：[4,3],[3,2]，长度为 2。
```

**示例 2：**
```
输入：nums = [3,3,3,3]
输出：1
解释：最长严格递增或递减子数组长度为 1。
```

**示例 3：**
```
输入：nums = [3,2,1]
输出：3
解释：[3,2,1] 是严格递减子数组，长度为 3。
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

一次线性扫描，同时维护以当前位置结尾的最长严格递增长度 `inc` 和最长严格递减长度 `dec`。根据相邻元素大小关系更新两个变量，并实时更新答案。

## Python 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def longestMonotonicSubarray(self, nums: List[int]) -> int:
        ans = 1
        inc = 1  # 以当前位置结尾的最长严格递增长度
        dec = 1  # 以当前位置结尾的最长严格递减长度
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                inc += 1
                dec = 1  # 递增，重置递减长度
            elif nums[i] < nums[i - 1]:
                dec += 1
                inc = 1  # 递减，重置递增长度
            else:
                inc = 1  # 相等，两者都重置
                dec = 1
            ans = max(ans, inc, dec)
        return ans
```

### 方法二：分开计算

```python
from typing import List

class Solution:
    def longestMonotonicSubarray(self, nums: List[int]) -> int:
        def longest(is_inc: bool) -> int:
            ans = cur = 1
            for i in range(1, len(nums)):
                if (is_inc and nums[i] > nums[i - 1]) or \
                   (not is_inc and nums[i] < nums[i - 1]):
                    cur += 1
                    ans = max(ans, cur)
                else:
                    cur = 1
            return ans

        return max(longest(True), longest(False))
```

## 复杂度分析

- 时间复杂度：O(n)，一次线性扫描
- 空间复杂度：O(1)

## 关键点总结

1. 同时维护递增和递减两个连续长度变量
2. 相邻相等时，两者都重置为 1
3. 子数组长度最小为 1

## 易错点

1. 严格递增/递减，相等时需重置
2. 答案初始值应为 1，不是 0
