## 题目描述

给你一个二进制数组 `nums`。

如果一个子数组中任意两个相邻元素的值不同，则该子数组被称为 **交替子数组**。

返回数组 `nums` 中交替子数组的数量。

**示例 1：**
```
输入：nums = [0,1,1,1]
输出：5
解释：交替子数组有 [0],[1],[1],[1],[0,1]
```

**示例 2：**
```
输入：nums = [1,0,1,0]
输出：10
解释：每个长度为 1、2、3、4 的子数组都是交替子数组。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i]` 非 0 即 1

## 解题思路

对于以每个位置结尾的交替子数组，维护一个连续交替长度 `cur`。若 `nums[i] != nums[i-1]`，则 `cur` 加 1；否则 `cur` 重置为 1。每个位置贡献 `cur` 个交替子数组（长度从 1 到 cur 的所有子数组）。

将所有位置的 `cur` 累加即为答案。

## Python 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def countAlternatingSubarrays(self, nums: List[int]) -> int:
        ans = 0
        cur = 1  # 以当前位置结尾的最长交替子数组长度
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                cur += 1  # 交替，长度加 1
            else:
                cur = 1   # 不交替，重置为 1
            ans += cur
        return ans + 1  # 加上第一个元素本身（长度为 1 的子数组）
```

### 方法二：直接累加

```python
from typing import List

class Solution:
    def countAlternatingSubarrays(self, nums: List[int]) -> int:
        ans = 0
        cur = 0
        for i, x in enumerate(nums):
            # 判断是否与前一个元素不同
            if i > 0 and x != nums[i - 1]:
                cur += 1
            else:
                cur = 1
            ans += cur  # 以 i 结尾，有 cur 个交替子数组
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，只需一次线性扫描
- 空间复杂度：O(1)，只用了常数个变量

## 关键点总结

1. 以当前位置结尾的交替子数组数量等于以该位置结尾的最长交替连续段长度
2. 每次相邻元素不同时，长度加 1；相同时，重置为 1
3. 累加所有位置的贡献即可

## 易错点

1. 注意第一个元素本身贡献 1 个子数组
2. 重置时应设为 1，不是 0
