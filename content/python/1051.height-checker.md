## 题目描述

学校打算为全体学生拍一张年度纪念照。根据要求，学生需要按照非递减的高度顺序排列。

排序后的高度情况用数组 `expected` 表示，其中 `expected[i]` 是预期排在这一位置的学生的高度。

给你一个整数数组 `heights`，表示当前学生站位的高度情况。`heights[i]` 是这一位置上学生的高度。

返回满足 `heights[i] != expected[i]` 的下标数量。

**示例 1：**
```
输入：heights = [1,1,4,2,1,3]
输出：3
解释：
heights:  [1,1,4,2,1,3]
expected: [1,1,1,2,3,4]
下标 2、4、5 处的学生高度不匹配。
```

**示例 2：**
```
输入：heights = [5,1,2,3,4]
输出：5
解释：
heights:  [5,1,2,3,4]
expected: [1,2,3,4,5]
所有下标的对应学生高度都不匹配。
```

**示例 3：**
```
输入：heights = [1,2,3,4,5]
输出：0
解释：
heights:  [1,2,3,4,5]
expected: [1,2,3,4,5]
所有下标的对应学生高度都匹配。
```

**提示：**
- `1 <= heights.length <= 100`
- `1 <= heights[i] <= 100`

## 解题思路

这道题的核心思想非常简单：
1. 将原数组排序得到期望的顺序
2. 比较原数组和排序后的数组，统计不同位置的个数

由于题目限制了高度范围在 1-100 之间，我们可以使用计数排序来优化性能。

**算法流程：**
1. 复制原数组并排序，得到 `expected`
2. 遍历数组，比较 `heights[i]` 和 `expected[i]`
3. 统计不相等的位置数量

## Python 代码实现

### 方法一：排序比较（推荐）

```python
from typing import List

class Solution:
    def heightChecker(self, heights: List[int]) -> int:
        """
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # 获取排序后的期望顺序
        expected = sorted(heights)
        
        # 统计不匹配的位置数
        count = 0
        for i in range(len(heights)):
            if heights[i] != expected[i]:
                count += 1
        
        return count
```

### 方法二：一行代码（Python 特色）

```python
from typing import List

class Solution:
    def heightChecker(self, heights: List[int]) -> int:
        """
        使用 zip 和 sum 简化代码
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        return sum(h1 != h2 for h1, h2 in zip(heights, sorted(heights)))
```

### 方法三：计数排序优化（⭐ 最优解）

```python
from typing import List

class Solution:
    def heightChecker(self, heights: List[int]) -> int:
        """
        利用高度范围有限的特点，使用计数排序
        时间复杂度：O(n + k)，其中 k = 100
        空间复杂度：O(k)
        """
        # 统计每个高度出现的次数
        count = [0] * 101  # 高度范围 1-100
        for h in heights:
            count[h] += 1
        
        # 生成排序后的期望数组（不实际创建数组，直接比较）
        result = 0
        j = 1  # 当前期望高度
        for i in range(len(heights)):
            # 找到下一个存在的高度
            while count[j] == 0:
                j += 1
            
            # 比较当前位置
            if heights[i] != j:
                result += 1
            
            # 消耗一个高度为 j 的学生
            count[j] -= 1
        
        return result
```

## 复杂度分析

**方法一和方法二：排序比较**
- 时间复杂度：O(n log n)，主要是排序的时间
- 空间复杂度：O(n)，需要额外的数组存储排序结果

**方法三：计数排序**
- 时间复杂度：O(n + k)，其中 n 是数组长度，k = 100 是高度范围
- 空间复杂度：O(k) = O(100) = O(1)，常量级空间

## 关键点总结

1. **问题本质**：比较原数组和排序后数组的差异
2. **优化思路**：利用数据范围有限的特点使用计数排序
3. **Python 技巧**：使用 `zip` 和生成器表达式简化代码
4. **常量优化**：在小数据范围场景下，计数排序优于通用排序算法

## 易错点

1. **理解错误**：注意不是统计需要移动的学生数，而是统计位置不匹配的数量
2. **边界条件**：已经排好序的数组应该返回 0
3. **高度范围**：计数排序时注意数组下标从 1 到 100
