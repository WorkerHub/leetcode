## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，找出最小下标 `i`（0 <= i < n-1），使得 `nums[0..i]` 的乘积和 `nums[i+1..n-1]` 的乘积互质（GCD 为 1）。

若不存在这样的下标，返回 `-1`。

**示例 1：**

```
输入：nums = [4,7,8,15,3,5]
输出：2
解释：nums[0..2] = [4,7,8]，乘积 = 224；nums[3..5] = [15,3,5]，乘积 = 225；gcd(224,225) = 1。
```

**提示：**

- `1 <= nums.length <= 10^4`
- `nums[i]` 为整数（1 <= nums[i] <= 10^6）

## 解题思路

对每个质因数，记录它出现在 nums 中的最后一个位置。若某质因数 p 在 nums[0..i] 中出现，也在 nums[i+1..n-1] 中出现（即最后出现位置 > i），则分割点 i 不合法。

对每个分割点 i，检查所有质因数的最后位置是否都 <= i（即所有质因数都已"结束"在左侧）。

## Python 代码实现

### 方法一：质因数最后位置（推荐）

```python
from typing import List

class Solution:
    def findValidSplit(self, nums: List[int]) -> int:
        n = len(nums)
        # last[p] = 质因数 p 在 nums 中最后出现的位置
        last = {}

        for i, num in enumerate(nums):
            # 分解 num 的质因数
            d = 2
            while d * d <= num:
                if num % d == 0:
                    last[d] = i
                    while num % d == 0:
                        num //= d
                d += 1
            if num > 1:
                last[num] = i

        # 从左到右，维护当前位置 i 左侧所有质因数的最后位置的最大值
        max_last = 0
        for i in range(n - 1):
            # 更新当前元素的质因数最后位置
            num = nums[i]
            d = 2
            while d * d <= num:
                if num % d == 0:
                    max_last = max(max_last, last[d])
                    while num % d == 0:
                        num //= d
                d += 1
            if num > 1:
                max_last = max(max_last, last[num])

            # 若所有在 [0..i] 中出现的质因数的最后位置均 <= i
            if max_last <= i:
                return i

        return -1
```

### 方法二：预处理质因数

```python
from typing import List
from collections import defaultdict

class Solution:
    def findValidSplit(self, nums: List[int]) -> int:
        n = len(nums)
        last_pos = {}

        # 记录每个质因数最后出现位置
        for i in range(n - 1, -1, -1):
            x = nums[i]
            d = 2
            while d * d <= x:
                if x % d == 0:
                    if d not in last_pos:
                        last_pos[d] = i
                    while x % d == 0:
                        x //= d
                d += 1
            if x > 1 and x not in last_pos:
                last_pos[x] = i

        # 正向扫描，维护必须延伸到的最远位置
        required = 0
        for i in range(n - 1):
            x = nums[i]
            d = 2
            while d * d <= x:
                if x % d == 0:
                    required = max(required, last_pos[d])
                    while x % d == 0:
                        x //= d
                d += 1
            if x > 1:
                required = max(required, last_pos[x])
            if required <= i:
                return i
        return -1
```

## 复杂度分析

- 时间复杂度：O(n * √M)，M 为最大元素值（10^6），√M ≈ 1000
- 空间复杂度：O(P)，P 为不同质因数数量

## 关键点总结

1. 分割点合法 ⟺ 左侧所有质因数不出现在右侧
2. 对每个质因数记录最后位置，遍历时维护当前最大"必须延伸位置"
3. 当 `max_last <= i` 时，i 是合法分割点

## 易错点

1. 对每个 nums[i] 进行质因数分解（不是枚举所有质数）
2. 扫描时 max_last 要取所有遇到的质因数最后位置的最大值
3. 最后一个位置（n-1）不能作为分割点（右侧需非空）
