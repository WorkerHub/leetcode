## 题目描述

给你一个整数数组 `nums` 和一个非负整数 `k`。

一次操作中，你可以将 `nums` 中的任意元素加 1 或减 1。

返回使 `nums` 的 **中位数** 等于 `k` 所需的 **最少** 操作数。

数组的中位数是将数组升序排列后处于中间位置的元素。若数组长度为偶数，中位数为中间两个元素中较小的那个。

**示例 1：**
```
输入：nums = [2,5,6,8,5], k = 4
输出：2
解释：将 nums[1] 从 5 减到 4，操作 1 次，中位数变为 4。或将 nums[0] 从 2 加到 4，操作 2 次。
```

**示例 2：**
```
输入：nums = [2,5,6,8,5], k = 7
输出：3
解释：将中位数位置的元素改为 7，需要 2 步；将中位数右边大于 7 的不变。
```

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

排序后，中位数位于下标 `m = n // 2` 处。

- 若 `nums[m] == k`，无需操作。
- 若 `nums[m] > k`：需要将中位数降到 k，即要让下标 m 处的元素 <= k。对排序后 `nums[0..m]` 中大于 k 的元素，每个都需要减到 k，操作数之和即为答案。
- 若 `nums[m] < k`：需要将中位数升到 k，即要让下标 m 处的元素 >= k。对排序后 `nums[m..n-1]` 中小于 k 的元素，每个都需要加到 k，操作数之和即为答案。

## Python 代码实现

### 方法一：排序后贪心（推荐）

```python
from typing import List

class Solution:
    def minOperationsToMakeMedianK(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        m = n // 2  # 中位数下标
        ans = 0

        if nums[m] > k:
            # 中位数大于 k，将 [0..m] 中大于 k 的都减到 k
            for i in range(m + 1):
                if nums[i] > k:
                    ans += nums[i] - k
        elif nums[m] < k:
            # 中位数小于 k，将 [m..n-1] 中小于 k 的都加到 k
            for i in range(m, n):
                if nums[i] < k:
                    ans += k - nums[i]

        return ans
```

### 方法二：简洁写法

```python
from typing import List

class Solution:
    def minOperationsToMakeMedianK(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        m = n // 2
        ans = 0
        for i, x in enumerate(nums):
            if i <= m and x > k:
                ans += x - k  # 左半部分大于 k 的需要减小
            elif i >= m and x < k:
                ans += k - x  # 右半部分小于 k 的需要增大
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(1)（不计排序的栈空间）

## 关键点总结

1. 中位数下标为 `n // 2`（奇偶数组都适用）
2. 若中位数大于 k，只需操作左半部分（含中位数）中大于 k 的元素
3. 若中位数小于 k，只需操作右半部分（含中位数）中小于 k 的元素

## 易错点

1. 中位数下标计算：`n // 2` 而非 `(n-1) // 2`
2. 无需操作整个数组，只需操作影响中位数的那一侧
