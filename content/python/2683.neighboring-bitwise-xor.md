## 题目描述

给你一个长度为 `n` 的二进制数组 `derived`，`derived` 是由长度为 `n` 的二进制数组 `original` 生成的（`derived[i] = original[i] XOR original[(i+1) % n]`）。

判断是否存在有效的 `original` 数组。

**示例 1：**
```
输入：derived = [1,1,0]
输出：true
解释：original = [0,1,0] 可以生成 derived
```

**示例 2：**
```
输入：derived = [1,1]
输出：false
```

**数据范围：**
- n == derived.length
- 1 <= n <= 10^5
- derived[i] 为 0 或 1

## 解题思路

数学推导：将 `derived[0] XOR derived[1] XOR ... XOR derived[n-1]` 展开：

`derived[i] = original[i] XOR original[i+1]`

因此 `XOR(derived) = XOR(original[i] XOR original[i+1])` = 每个 `original[i]` 出现两次（循环中每个元素恰好出现两次）= 0。

所以 **当且仅当 `derived` 所有元素的 XOR 为 0 时**，存在有效的 `original`。

## Python 代码实现

### 方法一：全局 XOR（推荐）

```python
from typing import List

class Solution:
    def doesValidArrayExist(self, derived: List[int]) -> bool:
        # 所有元素的 XOR 为 0 时才有合法的 original
        result = 0
        for x in derived:
            result ^= x
        return result == 0
```

### 方法二：使用 functools.reduce

```python
from typing import List
import functools
import operator

class Solution:
    def doesValidArrayExist(self, derived: List[int]) -> bool:
        return functools.reduce(operator.xor, derived) == 0
```

### 方法三：尝试构造验证

```python
from typing import List

class Solution:
    def doesValidArrayExist(self, derived: List[int]) -> bool:
        n = len(derived)
        # 尝试 original[0] = 0
        for start in [0, 1]:
            original = [0] * n
            original[0] = start
            for i in range(n - 1):
                original[i + 1] = original[i] ^ derived[i]
            # 检查循环闭合：original[n-1] ^ original[0] == derived[n-1]
            if (original[n - 1] ^ original[0]) == derived[n - 1]:
                return True
        return False
```

## 复杂度分析

- 方法一/二：时间复杂度 O(n)，空间复杂度 O(1)
- 方法三：时间复杂度 O(n)，空间复杂度 O(n)

## 关键点总结

1. 循环 XOR 中每个元素出现两次，总 XOR 为 0
2. 因此 `derived` 所有元素 XOR = 0 是必要且充分条件

## 易错点

1. 这是充要条件，不只是必要条件
2. 方法三：只需尝试 `original[0] = 0` 和 `original[0] = 1` 两种情况
