## 题目描述

给定一个非负整数 `num`，反复将各个位上的数字相加，直到结果为一位数。返回这个结果。

**示例 1：**

```
输入：num = 38
输出：2
解释：各位相加的过程为：
38 --> 3 + 8 --> 11
11 --> 1 + 1 --> 2
由于 2 是一位数，所以返回 2
```

**示例 2：**

```
输入：num = 0
输出：0
```

**提示：**
- `0 <= num <= 2^31 - 1`

**进阶：** 你可以不使用循环或者递归，在 O(1) 时间复杂度内解决这个问题吗？

## 解题思路

这道题有两种思路：模拟过程和数学规律。

### 思路一：模拟（直观）
按照题目要求，循环计算各位数字之和，直到结果是一位数。

### 思路二：数学规律（进阶）⭐
这个过程实际上是在求**数根（Digital Root）**，有一个数学规律：

对于正整数 n：
- 如果 n = 0，数根为 0
- 如果 n % 9 = 0 且 n ≠ 0，数根为 9
- 否则，数根为 n % 9

数学证明：
```
假设 num = a * 10^n + b * 10^(n-1) + ... + z * 10^0

因为 10 ≡ 1 (mod 9)，所以：
10^k ≡ 1 (mod 9)

因此：
num ≡ a + b + ... + z (mod 9)

也就是说，num 和它各位数字之和关于 9 同余
反复相加直到一位数，结果就是 num % 9
特殊情况：num % 9 = 0 时，如果 num ≠ 0，结果应该是 9
```

## Python 代码实现

### 方法一：O(1) 数学公式（推荐）⭐

```python
class Solution:
    def addDigits(self, num: int) -> int:
        """
        数学公式：数根规律
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        if num == 0:
            return 0
        return (num - 1) % 9 + 1
```

### 方法二：数学公式（另一种写法）

```python
class Solution:
    def addDigits(self, num: int) -> int:
        """
        数学公式的另一种表达
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        if num == 0:
            return 0
        if num % 9 == 0:
            return 9
        return num % 9
```

### 方法三：循环模拟

```python
class Solution:
    def addDigits(self, num: int) -> int:
        """
        模拟各位相加的过程
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        while num >= 10:
            total = 0
            # 计算各位数字之和
            while num > 0:
                total += num % 10
                num //= 10
            num = total
        
        return num
```

### 方法四：递归

```python
class Solution:
    def addDigits(self, num: int) -> int:
        """
        递归实现
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        # 如果是一位数，直接返回
        if num < 10:
            return num
        
        # 计算各位数字之和
        total = 0
        while num > 0:
            total += num % 10
            num //= 10
        
        # 递归处理结果
        return self.addDigits(total)
```

### 方法五：Python 技巧（字符串）

```python
class Solution:
    def addDigits(self, num: int) -> int:
        """
        使用字符串操作（不推荐，仅展示 Python 技巧）
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        while num >= 10:
            num = sum(int(digit) for digit in str(num))
        return num
```

## 图解示例

以 `num = 38` 为例：

### 模拟过程：
```
38 → 3 + 8 = 11

2 是一位数，返回 2
```

### 数学公式：
```
38 % 9 = 2
验证：(38 - 1) % 9 + 1 = 37 % 9 + 1 = 1 + 1 = 2 ✓
```

更多例子：
```
num = 0  → 返回 0
num = 9  → 9 % 9 = 0，但 num ≠ 0，返回 9
num = 18 → 18 % 9 = 0，但 num ≠ 0，返回 9
         验证：1 + 8 = 9 ✓
num = 19 → 19 % 9 = 1，返回 1
         验证：1 + 9 = 10 → 1 + 0 = 1 ✓
num = 99 → 99 % 9 = 0，但 num ≠ 0，返回 9
         验证：9 + 9 = 18 → 1 + 8 = 9 ✓
```

## 数学原理详解

为什么 `(num - 1) % 9 + 1` 有效？

```
情况1: num % 9 = 1, 2, 3, ..., 8
  直接返回 num % 9

情况2: num % 9 = 0 且 num ≠ 0
  应该返回 9
  
使用 (num - 1) % 9 + 1：
- 当 num % 9 = 1 时：(num - 1) % 9 = 0，0 + 1 = 1 ✓
- 当 num % 9 = 2 时：(num - 1) % 9 = 1，1 + 1 = 2 ✓
- ...
- 当 num % 9 = 0 时：(num - 1) % 9 = 8，8 + 1 = 9 ✓
- 当 num = 0 时：需要特殊处理返回 0
```

## 关键点总结

1. **数根概念**：反复将各位数字相加，最终得到的一位数
2. **模 9 规律**：数根等价于对 9 取模（特殊处理 0 和 9 的倍数）
3. **O(1) 解法**：使用 `(num - 1) % 9 + 1` 公式
4. **边界情况**：num = 0 需要特殊处理
5. **数学原理**：基于模运算的性质

## 易错点

1. **忘记处理 0 的情况**
   ```python
   # 错误：0 会返回 1
   return (num - 1) % 9 + 1
   
   # 正确：先判断 0
   if num == 0:
       return 0
   return (num - 1) % 9 + 1
   ```

2. **忘记处理 9 的倍数**
   ```python
   # 错误：9 会返回 0
   return num % 9
   
   # 正确：9 的倍数返回 9
   if num == 0:
       return 0
   if num % 9 == 0:
       return 9
   return num % 9
   ```

3. **模拟时的循环条件**
   ```python
   # 错误：应该是 >= 10
   while num > 10:
   
   # 正确：包含 10
   while num >= 10:
   ```

4. **理解题意**：是要求最终结果为一位数，不是只计算一次
