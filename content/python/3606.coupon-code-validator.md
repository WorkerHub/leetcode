## 题目描述

给你一个字符串 `code`，表示一个优惠券码。有效的优惠券码需满足以下条件：

1. 长度在 `[6, 20]` 之间
2. 只包含大写字母、小写字母和数字
3. 至少包含一个大写字母、一个小写字母和一个数字
4. 不包含空格或特殊字符

如果 `code` 是有效的优惠券码，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：code = "Hello123"
输出：true
解释：长度 8，包含大写 H、小写 ello、数字 123，合法
```

**示例 2：**

```
输入：code = "abc"
输出：false
解释：长度不足 6
```

**示例 3：**

```
输入：code = "ALLUPPERCASE1"
输出：false
解释：缺少小写字母
```

**提示：**

- `1 <= code.length <= 100`
- `code` 由可打印 ASCII 字符组成

## 解题思路

逐一检验所有条件：
1. 检查长度是否在 `[6, 20]`
2. 检查是否只含字母数字（`isalnum()`）
3. 检查是否含大写字母（`any(c.isupper())`）
4. 检查是否含小写字母（`any(c.islower())`）
5. 检查是否含数字（`any(c.isdigit())`）

## Python 代码实现

### 方法一：逐条件验证（推荐）

```python
class Solution:
    def isValid(self, code: str) -> bool:
        # 条件1：长度检查
        if not (6 <= len(code) <= 20):
            return False
        # 条件2：只含字母和数字
        if not code.isalnum():
            return False
        # 条件3：至少一个大写字母
        if not any(c.isupper() for c in code):
            return False
        # 条件4：至少一个小写字母
        if not any(c.islower() for c in code):
            return False
        # 条件5：至少一个数字
        if not any(c.isdigit() for c in code):
            return False
        return True
```

### 方法二：正则表达式

```python
import re

class Solution:
    def isValid(self, code: str) -> bool:
        # 正则匹配：长度6-20，只含字母数字，且含大写、小写、数字各至少一个
        if not (6 <= len(code) <= 20):
            return False
        pattern = r'^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)[A-Za-z\d]+$'
        return bool(re.match(pattern, code))
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 条件逐一拆开验证，代码清晰
2. `isalnum()` 可快速检查只含字母和数字
3. `any()` + 生成器是 Python 惯用写法
4. 正则方式更简洁但可读性稍差

## 易错点

1. 长度上限 20 容易忽略
2. `isalnum()` 会对非 ASCII 字符返回 True，需注意题目约束
3. 正则中前向断言 `(?=...)` 的写法不熟悉可能出错
