## 题目描述

一个整数数组 `original` 可以通过以下步骤得到 `changed` 数组：
- 将 `original` 中每个元素 `x` 追加到 `changed`
- 将 `original` 中每个元素 `x` 的两倍（`2*x`）也追加到 `changed`
- 随机打乱 `changed`

给你一个数组 `changed`，如果它是某个原始数组转变而来的，返回原始数组 `original`；否则，返回空数组。注意 `original` 中可能有重复元素。

**示例 1：**
```
输入：changed = [1,3,4,2,6,8]
输出：[1,3,4]
解释：original = [1,3,4]，doubled 后得 [1,3,4,2,6,8]
```

**示例 2：**
```
输入：changed = [6,3,0,1]
输出：[]
解释：不存在合法的原始数组
```

**提示：**
- `1 <= changed.length <= 10^5`
- `0 <= changed[i] <= 10^5`

## 解题思路

**贪心策略：** 对 `changed` 排序后，从最小元素开始匹配：
- 每次取最小未使用的元素 `x`，尝试在剩余元素中找 `2*x`
- 若找到，则 `x` 是原始数组的元素，将 `x` 和 `2x` 标记为已用
- 若找不到，则不合法，返回 `[]`

**特殊情况：** `x = 0` 时 `2*x = 0`，需要成对出现。

## 代码实现

### 方法一：排序 + 哈希计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        # 长度必须是偶数
        if len(changed) % 2 != 0:
            return []

        changed.sort()  # 从小到大排序，保证先处理小值
        count = Counter(changed)  # 统计每个元素出现次数
        result = []

        for x in changed:
            if count[x] == 0:
                continue  # 该元素已被使用
            if count[2 * x] == 0:
                return []  # 找不到 2x，不合法

            # x 是原始数组的元素
            result.append(x)
            count[x] -= 1
            count[2 * x] -= 1

        return result
```

### 方法二：有序字典（更清晰）

```python
from typing import List
from collections import Counter

class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2 != 0:
            return []

        count = Counter(changed)
        result = []

        # 对所有唯一元素排序处理
        for x in sorted(count.keys()):
            # 处理当前元素 x 剩余的数量
            while count[x] > 0:
                # 检查 2x 是否足够
                if count[2 * x] < count[x] and x != 0:
                    # 先用完 2x，再看能配对多少
                    pass
                if count[2 * x] == 0:
                    return []
                result.append(x)
                count[x] -= 1
                count[2 * x] -= 1

        return result
```

### 方法三：排序贪心（直接匹配）

```python
from typing import List
from collections import Counter

class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2 != 0:
            return []

        changed.sort()
        count = Counter(changed)
        result = []

        for x in sorted(count):
            # 一次性处理 x 与 2x 的配对
            if x == 0:
                # 0 需要偶数个
                if count[0] % 2 != 0:
                    return []
                result.extend([0] * (count[0] // 2))
                count[0] = 0
            else:
                # x 的所有个数都需要在 2x 中找到对应
                while count[x] > 0:
                    if count[2 * x] <= 0:
                        return []
                    result.append(x)
                    count[x] -= 1
                    count[2 * x] -= 1

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(n)，哈希表存储

## 关键点总结

1. 排序后从小到大贪心匹配，小数优先作为原始元素
2. 每个原始元素 `x` 需要找到 `2x`，用哈希计数表跟踪剩余数量
3. 处理 `x = 0` 的特殊情况（`2*0 = 0`，需要成对出现）
4. 最终 `original` 长度为 `changed.length / 2`

## 易错点

- `x = 0` 是特殊情况，`2 * 0 = 0`，需要 `0` 的数量是偶数
- 排序后从小到大处理才能保证贪心正确（先用小值做原始元素）
- `changed.length` 必须是偶数，否则直接返回 `[]`
