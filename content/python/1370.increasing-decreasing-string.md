## 题目描述

给你一个字符串 `s`，请你根据下面的算法重新构造字符串：

1. 从 `s` 中选出**最小**的字符，将它**接在**结果字符串的后面。
2. 从 `s` 剩余字符中选出**最小**的字符，且该字符比上次选出的字符**大**，将它接在结果字符串的后面。
3. 重复步骤 2 ，直到你没法从 `s` 中选择字符。
4. 从 `s` 中选出**最大**的字符，将它**接在**结果字符串的后面。
5. 从 `s` 剩余字符中选出**最大**的字符，且该字符比上次选出的字符**小**，将它接在结果字符串的后面。
6. 重复步骤 5 ，直到你没法从 `s` 中选择字符。
7. 重复步骤 1 到 6，直到 `s` 中所有字符都已经被选过。

在任何一步中，如果最小或者最大字符不止一个，你可以选择其中任意一个，并将其从 `s` 中删除。

请你返回令 `s` 中所有字符都已经被选过之后构造的字符串。

**示例 1：**
```
输入：s = "aaaabbbbcccc"
输出："abccbaabccba"
解释：第一轮选出 a, b, c；第二轮从大到小选出 c, b, a；重复共2轮。
```

**示例 2：**
```
输入：s = "rat"
输出："art"
解释：步骤1选 a，步骤2选 r，步骤3选 t（已是最大），步骤4-6选出 t 再无更小的了，再次步骤1选出... 
实际：从小到大：a,r,t → 从大到小：无（已用完）→ 结果"art"
```

**提示：**
- `1 <= s.length <= 500`
- `s` 只包含小写英文字母

## 解题思路

### 核心思想

本题的过程等价于：
- **一轮中的"从小到大"阶段**：遍历 `a` 到 `z`，每个字母若还有剩余就取一个。
- **一轮中的"从大到小"阶段**：遍历 `z` 到 `a`，每个字母若还有剩余就取一个。
- 重复以上两步，直到所有字母用完。

为什么？因为每一步只要求"比上一个更大/更小"，而我们按字母顺序遍历，就天然满足了这个条件。

### 方法一：Counter 模拟（推荐）

**算法流程：**
1. 用 `Counter` 统计每个字符的频次。
2. 外层循环：当还有字符未被选完时。
3. 内层先正序遍历 `a-z`，有则取1个加入结果，频次减1。
4. 再逆序遍历 `z-a`，有则取1个加入结果，频次减1。

### 方法二：桶排序数组

用长度26的数组代替 Counter，效果相同但更底层。

## Python 代码实现

### 方法一：Counter 模拟（推荐）

```python
from collections import Counter
from typing import List

class Solution:
    def sortString(self, s: str) -> str:
        # 统计每个字符出现的次数
        count = Counter(s)
        result = []

        # 只要还有字符未被选完，就继续循环
        while len(result) < len(s):
            # 从小到大：遍历 a 到 z
            for c in 'abcdefghijklmnopqrstuvwxyz':
                if count[c] > 0:
                    result.append(c)
                    count[c] -= 1

            # 从大到小：遍历 z 到 a
            for c in 'zyxwvutsrqponmlkjihgfedcba':
                if count[c] > 0:
                    result.append(c)
                    count[c] -= 1

        return ''.join(result)
```

### 方法二：桶计数数组

```python
class Solution:
    def sortString(self, s: str) -> str:
        # 用长度26的数组统计每个字母的频次
        # index 0 对应 'a'，index 25 对应 'z'
        freq = [0] * 26
        for c in s:
            freq[ord(c) - ord('a')] += 1

        result = []
        total = len(s)

        while len(result) < total:
            # 从小到大：index 0 到 25
            for i in range(26):
                if freq[i] > 0:
                    result.append(chr(i + ord('a')))
                    freq[i] -= 1

            # 从大到小：index 25 到 0
            for i in range(25, -1, -1):
                if freq[i] > 0:
                    result.append(chr(i + ord('a')))
                    freq[i] -= 1

        return ''.join(result)
```

### 方法三：Python 特色写法（简洁版）

```python
from collections import Counter

class Solution:
    def sortString(self, s: str) -> str:
        count = Counter(s)
        result = []
        letters = sorted(count.keys())  # 所有出现的字母，已排序

        while sum(count.values()) > 0:
            # 从小到大取一遍
            for c in letters:
                if count[c] > 0:
                    result.append(c)
                    count[c] -= 1

            # 从大到小取一遍
            for c in reversed(letters):
                if count[c] > 0:
                    result.append(c)
                    count[c] -= 1

        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter 模拟 | O(n × 26) = O(n) | O(26) = O(1) |
| 桶计数数组 | O(n × 26) = O(n) | O(26) = O(1) |

**说明：**
- 外层循环最多执行 `n / 26 + 1` 次（每轮每个字母最多取一个，最多取26个）。
- 每轮内层遍历26个字母，故总操作数约为 `n / 26 × 2 × 26 ≈ 2n`，即 O(n)。
- 空间上只用了常数大小的计数数组，O(1)。

## 图解示例

以 `s = "aaaabbbbcccc"` 为例：

```
初始频次：a=4, b=4, c=4

第一轮：
  从小到大：取 a(3), b(3), c(3) → result = "abc"
  从大到小：取 c(2), b(2), a(2) → result = "abccba"

第二轮：
  从小到大：取 a(1), b(1), c(1) → result = "abccbabc"   // 不对，应为"abccbaabc"
  等等，a从2取到1，b从2取到1，c从2取到1
  → result = "abccba" + "abc" = "abccbaabc"
  从大到小：取 c(0), b(0), a(0)
  → result = "abccbaabc" + "cba" = "abccbaabccba"

最终输出："abccbaabccba" ✓
```

## 关键点总结

1. 按字母顺序正向/逆向遍历，天然满足"比上一个更大/更小"的条件。
2. 每轮每个字母最多取一个，需要循环直到所有字母用完。
3. `Counter` 是 Python 处理字符频次统计的利器，自带 `__missing__` 返回0，无需判断键是否存在。
4. 结果用列表累积再 `join`，比字符串直接拼接效率更高（避免反复创建新字符串）。
5. 字母表只有26个，固定大小，内层循环为 O(26) = O(1)。

## 易错点

1. **用字符串拼接而不是列表**：`result += c` 每次都创建新字符串，时间复杂度退化为 O(n²)，应使用列表 `append` 后再 `join`。
2. **每轮只选有剩余的字母**：必须检查 `count[c] > 0`，跳过已用完的字母。
3. **循环终止条件**：应用 `len(result) < len(s)` 或 `sum(count.values()) > 0`，而不是随意设置次数。
