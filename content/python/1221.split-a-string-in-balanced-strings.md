## 题目描述

平衡字符串是指 `'L'` 和 `'R'` 字符的数量相等的字符串。

给定一个平衡字符串 `s`，请将它分割成尽可能多的平衡字符串。

注意：分割得到的每个字符串都必须是平衡字符串。

返回可以通过分割得到的平衡字符串的**最大数量**。

**示例 1：**

```
输入：s = "RLRRLLRLRL"
输出：4
解释：s 可以分割为 "RL", "RRLL", "RL", "RL"，每个子字符串中都包含相同数量的 'L' 和 'R'。
```

**示例 2：**

```
输入：s = "RLRRRLLRLL"
输出：2
解释：s 可以分割为 "RL", "RRRLLRLL"，每个子字符串中都包含相同数量的 'L' 和 'R'。
注意，s 无法分割为 "RL", "RR", "RL", "LR", "LL"，因为第 2 个和第 5 个子字符串不是平衡字符串。
```

**示例 3：**

```
输入：s = "LLLLRRRR"
输出：1
解释：s 只能保持原样 "LLLLRRRR"。
```

**提示：**

- `2 <= s.length <= 1000`
- `s[i] = 'L' 或 'R'`
- `s` 是一个平衡字符串

## 解题思路

这是一道经典的**贪心**问题，关键在于理解"最多"的含义。

**核心思想：**

贪心策略：尽可能早地进行分割，即一旦遇到平衡子串就立即分割。

**为什么贪心是正确的？**

- 如果一个字符串在位置 i 处平衡（L 和 R 数量相等），那么：
  - 方案1：在位置 i 分割成两个平衡串
  - 方案2：继续往后，等到位置 j (j > i) 再分割
- 方案1 的分割数量 ≥ 方案2，所以尽早分割总是最优的

**算法步骤：**

1. 使用一个计数器 `balance`
2. 遇到 'L' 则 +1，遇到 'R' 则 -1（或相反）
3. 当 `balance == 0` 时，说明当前位置形成了一个平衡子串
4. 分割数量 +1，继续处理剩余部分

## Python 代码实现

### 方法一：贪心 + 计数器（推荐）⭐

```python
class Solution:
    def balancedStringSplit(self, s: str) -> int:
        """
        贪心算法：尽可能早地分割
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        balance = 0  # 平衡计数器
        count = 0    # 平衡子串的数量
        
        for char in s:
            # 更新平衡计数器
            if char == 'L':
                balance += 1
            else:  # char == 'R'
                balance -= 1
            
            # 当平衡时，找到一个平衡子串
            if balance == 0:
                count += 1
        
        return count
```

### 方法二：更简洁的写法

```python
class Solution:
    def balancedStringSplit(self, s: str) -> int:
        """
        使用三元表达式简化代码
        """
        balance = 0
        count = 0
        
        for char in s:
            balance += 1 if char == 'L' else -1
            if balance == 0:
                count += 1
        
        return count
```

### 方法三：一行代码（Pythonic）

```python
class Solution:
    def balancedStringSplit(self, s: str) -> int:
        """
        Python 特色解法：使用生成器表达式
        """
        balance = 0
        return sum(not (balance := balance + (1 if c == 'L' else -1)) for c in s)
```

### 方法四：详细注释版（新手友好）

```python
class Solution:
    def balancedStringSplit(self, s: str) -> int:
        """
        详细解释贪心算法的思路
        """
        # 平衡计数器：用于追踪 L 和 R 的数量差
        # 当 balance = 0 时，表示 L 和 R 数量相等
        balance = 0
        
        # 记录找到的平衡子串数量
        result = 0
        
        # 遍历字符串的每个字符
        for i, char in enumerate(s):
            # 方案1：L 记为 +1，R 记为 -1
            if char == 'L':
                balance += 1
            else:  # char == 'R'
                balance -= 1
            
            # 检查是否达到平衡
            if balance == 0:
                # 找到一个平衡子串
                result += 1
                
                # 调试输出（可选）
                # print(f"找到平衡子串：s[0:{i+1}] = {s[:i+1]}")
        
        return result
```

## 复杂度分析

所有方法：

- **时间复杂度**：O(n)，只需要遍历字符串一次
- **空间复杂度**：O(1)，只使用了常数个变量

## 关键点总结

1. **贪心策略正确性**：尽早分割总是最优的
2. **平衡判断**：使用一个计数器，L 和 R 分别 +1 和 -1
3. **无需记录分割位置**：只需要统计数量
4. **保证解的存在性**：题目保证输入是平衡字符串
5. **简单高效**：一次遍历，O(n) 时间，O(1) 空间

## 易错点

1. **误解题意**：
   - 错误：以为需要找出所有可能的分割方案
   - 正确：只需要找最多能分割成多少个平衡子串

2. **贪心策略错误**：
   - 错误：尝试等待更长的平衡子串
   - 正确：一旦平衡就立即分割

3. **计数方向**：
   - L 和 R 的 +1/-1 可以互换，但要保持一致
   - 只要能区分即可

4. **忘记题目保证**：
   - 题目已经保证 s 是平衡字符串
   - 不需要担心最终 balance 不为 0
