## 题目描述

给你一个正整数数组 `arr`，请你找出一个长度为 `m` 且在数组中至少重复 `k` 次的模式。

**模式** 是由一个或多个值组成的子数组，在原数组中 **连续** 重复 `k` 次（中间没有间隔）。

若这样的模式存在，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：arr = [1,2,4,4,4,4], m = 1, k = 3
输出：true
解释：模式 [4] 连续重复 4 次
```

**示例 2：**
```
输入：arr = [1,2,1,2,1,1,1,3], m = 2, k = 2
输出：true
解释：模式 [1,2] 连续重复 2 次（arr[0..1] 和 arr[2..3]）
```

## 解题思路

### 枚举起始位置

对每个起始位置 `i`，检查从 `i` 开始的长度 `m` 的模式是否连续重复至少 `k` 次。

**检验方法：** 检查 `arr[i..i+m-1] == arr[i+m..i+2m-1] == ... == arr[i+(k-1)*m..i+k*m-1]`。

等价于：检查 `arr[j] == arr[j+m]` 对 `j in [i, i+m*(k-1))` 都成立。

## 代码实现

### 方法一：枚举 + 逐元素比较（推荐）

```python
from typing import List

class Solution:
    def containsPattern(self, arr: List[int], m: int, k: int) -> bool:
        n = len(arr)
        # 对每个起始位置
        for i in range(n - m * k + 1):
            # 检查从 i 开始的模式是否重复 k 次
            valid = True
            for j in range(m * (k - 1)):
                if arr[i + j] != arr[i + j + m]:
                    valid = False
                    break
            if valid:
                return True
        return False
```

### 方法二：连续匹配计数（更高效）

```python
from typing import List

class Solution:
    def containsPattern(self, arr: List[int], m: int, k: int) -> bool:
        n = len(arr)
        count = 0  # 当前连续匹配的长度（以 m 为单位）

        for i in range(n - m):
            if arr[i] == arr[i + m]:
                count += 1
            else:
                count = 0
            # count 达到 m*(k-1) 说明找到了 k 次重复
            if count == m * (k - 1):
                return True

        return False
```

### 方法三：使用切片比较

```python
from typing import List

class Solution:
    def containsPattern(self, arr: List[int], m: int, k: int) -> bool:
        n = len(arr)
        for i in range(n - m * k + 1):
            pattern = arr[i:i+m]
            # 检查后续 k-1 次重复
            if all(arr[i+j*m:i+(j+1)*m] == pattern for j in range(1, k)):
                return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N * M * K) | O(1) |
| 方法二 | O(N) | O(1) |
| 方法三 | O(N * M * K) | O(M) |

## 关键点总结

1. 方法二最高效：连续 `m*(k-1)` 个相邻（间隔 m）的匹配 → 找到 k 次重复
2. `arr[i] == arr[i+m]` 表示位置 i 和 i+m 的元素相同（模式可以在这里继续重复）
3. 当计数达到 `m*(k-1)` 时，说明从某位置开始有 k 次重复

## 易错点

- 方法二中，连续匹配数为 `m*(k-1)` 而不是 `m*k`（共 k 份，两两之间的匹配有 k-1 对，每对验证 m 个）
