## 题目描述

给定一个二叉搜索树 `root` 和一个目标结果 `k`，如果二叉搜索树中存在两个元素且它们的和等于给定的目标结果，则返回 `true`。

**示例 1:**

```
输入: root = [5,3,6,2,4,null,7], k = 9
输出: true
```

**示例 2:**

```
输入: root = [5,3,6,2,4,null,7], k = 28
输出: false
```

**提示:**
- 树中节点数目在范围 `[1, 10⁴]` 内
- `-10⁴ <= Node.val <= 10⁴`
- 题目数据保证，输入的 `root` 是一棵**有效**的二叉搜索树
- `-10⁵ <= k <= 10⁵`

## 解题思路

这道题是经典的 Two Sum 问题在二叉搜索树上的变种。有多种解法：

### 思路一：哈希表法（最直观）

像普通数组的 Two Sum 一样，用哈希表记录遍历过的值，查找 `k - node.val` 是否存在。

**步骤：**
1. 遍历二叉树（任何遍历方式都可以）
2. 对于每个节点值 `val`，检查 `k - val` 是否在哈希表中
3. 如果存在，返回 True
4. 否则将 `val` 加入哈希表

### 思路二：中序遍历 + 双指针（利用 BST 性质）

BST 的中序遍历结果是有序数组，可以使用双指针法。

**步骤：**
1. 中序遍历得到有序数组
2. 使用双指针在有序数组中找 Two Sum

### 思路三：BST 迭代器（空间优化）

不需要存储整个数组，使用两个迭代器（一个正向，一个反向）。

## Python 代码实现

### 方法一：哈希表（推荐新手）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        """
        使用哈希表记录已访问的值
        """
        # 记录访问过的节点值
        seen = set()
        
        def dfs(node: Optional[TreeNode]) -> bool:
            """深度优先搜索"""
            if not node:
                return False
            
            # 检查 k - node.val 是否存在
            if k - node.val in seen:
                return True
            
            # 将当前值加入哈希表
            seen.add(node.val)
            
            # 递归搜索左右子树
            return dfs(node.left) or dfs(node.right)
        
        return dfs(root)
```

### 方法二：中序遍历 + 双指针

```python
class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        """
        利用 BST 性质：中序遍历得到有序数组
        """
        # 中序遍历得到有序数组
        def inorder(node: Optional[TreeNode]) -> list:
            if not node:
                return []
            return inorder(node.left) + [node.val] + inorder(node.right)
        
        # 获取有序数组
        nums = inorder(root)
        
        # 双指针查找
        left, right = 0, len(nums) - 1
        while left < right:
            current_sum = nums[left] + nums[right]
            if current_sum == k:
                return True
            elif current_sum < k:
                left += 1
            else:
                right -= 1
        
        return False
```

### 方法三：BFS + 哈希表

```python
from collections import deque

class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        """
        使用广度优先搜索 + 哈希表
        """
        if not root:
            return False
        
        seen = set()
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            
            # 检查是否存在配对值
            if k - node.val in seen:
                return True
            
            seen.add(node.val)
            
            # 将子节点加入队列
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        return False
```

### 方法四：BST 迭代器（空间优化）⭐

```python
class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        """
        使用两个迭代器：正向和反向
        不需要存储整个数组，空间优化
        """
        if not root:
            return False
        
        # 正向迭代器（从小到大）
        forward_stack = []
        # 反向迭代器（从大到小）
        backward_stack = []
        
        # 初始化正向栈（最左路径）
        node = root
        while node:
            forward_stack.append(node)
            node = node.left
        
        # 初始化反向栈（最右路径）
        node = root
        while node:
            backward_stack.append(node)
            node = node.right
        
        # 双指针
        left = forward_stack[-1].val
        right = backward_stack[-1].val
        
        while left < right:
            current_sum = left + right
            
            if current_sum == k:
                return True
            elif current_sum < k:
                # 移动左指针
                left = self._next_forward(forward_stack)
            else:
                # 移动右指针
                right = self._next_backward(backward_stack)
        
        return False
    
    def _next_forward(self, stack: list) -> int:
        """获取下一个较大的值（中序遍历的下一个）"""
        node = stack.pop()
        
        # 如果有右子树，找右子树的最左节点
        if node.right:
            node = node.right
            while node:
                stack.append(node)
                node = node.left
        
        return stack[-1].val if stack else float('inf')
    
    def _next_backward(self, stack: list) -> int:
        """获取下一个较小的值（反向中序遍历的下一个）"""
        node = stack.pop()
        
        # 如果有左子树，找左子树的最右节点
        if node.left:
            node = node.left
            while node:
                stack.append(node)
                node = node.right
        
        return stack[-1].val if stack else float('-inf')
```

## 复杂度分析

### 方法一：哈希表
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，哈希表和递归栈

### 方法二：中序遍历 + 双指针
- **时间复杂度**：O(n)，中序遍历 + 双指针遍历
- **空间复杂度**：O(n)，存储中序遍历结果

### 方法三：BFS + 哈希表
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，队列和哈希表

### 方法四：BST 迭代器
- **时间复杂度**：O(n)，最坏情况遍历所有节点
- **空间复杂度**：O(h)，h 为树高，只存储路径上的节点

## 关键点总结

1. **利用 BST 性质**：中序遍历是有序的，可以使用双指针
2. **哈希表通用性强**：不需要利用 BST 特性，适用于普通二叉树
3. **空间优化**：BST 迭代器只需 O(h) 空间
4. **遍历方式灵活**：DFS、BFS 都可以，根据场景选择
5. **提前终止**：找到答案后立即返回，不需要遍历完所有节点

## 易错点

1. **忘记检查同一节点**：
   ```python
   # 错误：先加入再检查，可能导致同一节点配对自己
   seen.add(node.val)
   if k - node.val in seen:
       return True
   
   # 正确：先检查再加入
   if k - node.val in seen:
       return True
   seen.add(node.val)
   ```

2. **双指针边界条件**：
   ```python
   # 确保 left < right，避免同一元素使用两次
   while left < right:  # 不是 left <= right
   ```

3. **空树处理**：
   ```python
   if not root:
       return False
   ```

4. **BST 性质假设**：虽然是 BST，但要确保代码对普通二叉树也正确

5. **整数溢出**：在其他语言中需要注意，Python 自动处理大整数
