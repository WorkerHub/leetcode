## 题目描述

给你一个下标从 **0** 开始的字符串数组 `nums`，其中每个字符串**长度相等**且只包含数字。

同时给你一个下标从 **0** 开始的二维整数数组 `queries`，其中 `queries[i] = [k_i, trim_i]`。对于每个查询 `i`，你需要：
1. 将 `nums` 中每个数字**裁剪**到后 `trim_i` 位。
2. 在裁剪后的数字中找第 `k_i` 小的数（1 索引）。
3. 返回裁剪前该数字在原数组中的下标（若有多个相同，返回最小下标）。

**示例 1：**
```
输入：nums = ["102","473","251","814"], queries = [[1,1],[2,3],[4,2],[1,2]]
输出：[2,2,1,0]
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i].length <= 100`
- `nums[i]` 只包含数字
- `1 <= queries.length <= 100`
- `queries[i].length == 2`

## 解题思路

**直接模拟（暴力法）：**
对每个查询，截取所有数字的后 `trim` 位，排序后找第 k 小的数字，返回其原始下标。

由于数据规模小（n, q <= 100），直接模拟可以通过。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def smallestTrimmedNumbers(self, nums: List[str], queries: List[List[int]]) -> List[int]:
        result = []
        
        for k, trim in queries:
            # 裁剪每个数字，保留后 trim 位，同时记录原始下标
            trimmed = [(num[-trim:], i) for i, num in enumerate(nums)]
            # 按裁剪后的字符串排序（字典序即数值序，因为长度相同）
            trimmed.sort()
            # 找第 k 小（1 索引）
            result.append(trimmed[k - 1][1])
        
        return result
```

### 方法二：使用 heapq 选取第 k 小

```python
from typing import List
import heapq

class Solution:
    def smallestTrimmedNumbers(self, nums: List[str], queries: List[List[int]]) -> List[int]:
        result = []
        
        for k, trim in queries:
            # 构建 (裁剪字符串, 原始下标) 列表
            trimmed = [(num[-trim:], i) for i, num in enumerate(nums)]
            # 获取第 k 小
            kth = heapq.nsmallest(k, trimmed)[-1]
            result.append(kth[1])
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力排序 | O(q * n * log(n) * L) | O(n) |
| 堆选取 | O(q * n * log(k)) | O(n) |

其中 q 为查询数，n 为数组大小，L 为字符串长度。

## 关键点总结

1. 所有数字长度相同，裁剪后字典序即等价于数值大小（因为长度相等）。
2. 同值时取原始下标最小的，`sort` 的稳定性保证了这一点（元组排序先比字符串再比下标）。
3. 由于数据规模小，暴力解法完全可行。

## 易错点

- Python 的 `sort` 是稳定排序，元组 `(裁剪串, 原始下标)` 按字典序排列时，相同裁剪串的情况下按下标升序排，满足"取最小下标"的要求。
- 裁剪用 `num[-trim:]`（取后 trim 位）。
