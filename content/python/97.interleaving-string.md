## 题目描述

给定三个字符串 `s1`、`s2`、`s3`，请你判断 `s3` 是否由 `s1` 和 `s2` 交错组成。

两个字符串 `s` 和 `t` 交错的定义与过程如下，其中每个字符串都会被分割成若干非空子字符串：

- `s = s1 + s2 + ... + sn`
- `t = t1 + t2 + ... + tm`
- `|n - m| <= 1`
- 交错是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`

**注意**：`a + b` 意味着字符串 `a` 和 `b` 连接。

**示例 1：**
```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出：true
解释：一种可能的交错方式是：
s1: aa  bc    c
s2:   db  bca
s3: aadbbcbcac
```

**示例 2：**
```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出：false
```

**示例 3：**
```
输入：s1 = "", s2 = "", s3 = ""
输出：true
```

**提示：**
- `0 <= s1.length, s2.length <= 100`
- `0 <= s3.length <= 200`
- `s1`、`s2` 和 `s3` 由小写英文字母组成

## 解题思路

这是一道经典的二维动态规划问题。

### 核心思想

**问题分析：**

1. **长度检查**：如果 `len(s1) + len(s2) != len(s3)`，直接返回 False

2. **交错的本质**：s3 的每个字符必须来自 s1 或 s2，且保持各自的相对顺序不变

3. **动态规划思路**：
   - 状态定义：`dp[i][j]` 表示 s1 的前 i 个字符和 s2 的前 j 个字符能否交错组成 s3 的前 i+j 个字符
   - 决策：s3[i+j-1] 可能来自 s1[i-1] 或 s2[j-1]

4. **状态转移方程**：
   ```
   dp[i][j] = (dp[i-1][j] and s1[i-1] == s3[i+j-1]) or 
              (dp[i][j-1] and s2[j-1] == s3[i+j-1])
   ```

5. **初始状态**：
   - `dp[0][0] = True`（空字符串可以组成空字符串）
   - `dp[i][0]`：只用 s1 的前 i 个字符组成 s3 的前 i 个字符
   - `dp[0][j]`：只用 s2 的前 j 个字符组成 s3 的前 j 个字符

### 图解思路

可以将问题看作在一个二维网格中寻找路径：
- 从左上角 (0, 0) 到右下角 (len(s1), len(s2))
- 每次只能向右或向下移动
- 移动时必须匹配 s3 中对应的字符

## Python 代码实现

### 方法一：二维动态规划（推荐）

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        """
        二维动态规划判断字符串交错
        
        Args:
            s1: 第一个字符串
            s2: 第二个字符串
            s3: 目标字符串
            
        Returns:
            s3 是否由 s1 和 s2 交错组成
        """
        m, n = len(s1), len(s2)
        
        # 长度不匹配，直接返回 False
        if m + n != len(s3):
            return False
        
        # dp[i][j] 表示 s1[:i] 和 s2[:j] 能否交错组成 s3[:i+j]
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        
        # 初始状态：空字符串
        dp[0][0] = True
        
        # 初始化第一列：只使用 s1
        for i in range(1, m + 1):
            dp[i][0] = dp[i - 1][0] and s1[i - 1] == s3[i - 1]
        
        # 初始化第一行：只使用 s2
        for j in range(1, n + 1):
            dp[0][j] = dp[0][j - 1] and s2[j - 1] == s3[j - 1]
        
        # 填充 dp 表
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # s3 的当前位置
                k = i + j - 1
                # 情况1：s3[k] 来自 s1[i-1]
                if s1[i - 1] == s3[k]:
                    dp[i][j] = dp[i][j] or dp[i - 1][j]
                # 情况2：s3[k] 来自 s2[j-1]
                if s2[j - 1] == s3[k]:
                    dp[i][j] = dp[i][j] or dp[i][j - 1]
        
        return dp[m][n]
```

### 方法二：一维动态规划（空间优化）

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        """
        一维动态规划，优化空间复杂度
        
        Args:
            s1: 第一个字符串
            s2: 第二个字符串
            s3: 目标字符串
            
        Returns:
            s3 是否由 s1 和 s2 交错组成
        """
        m, n = len(s1), len(s2)
        
        if m + n != len(s3):
            return False
        
        # 只使用一维数组，dp[j] 表示 s2[:j] 的状态
        dp = [False] * (n + 1)
        dp[0] = True
        
        # 初始化第一行
        for j in range(1, n + 1):
            dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]
        
        # 逐行更新
        for i in range(1, m + 1):
            # 更新当前行的第一个元素（j=0）
            dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
            
            for j in range(1, n + 1):
                k = i + j - 1
                # dp[j] 当前表示上一行的值（i-1, j）
                # dp[j-1] 表示当前行的前一个值（i, j-1）
                dp[j] = (dp[j] and s1[i - 1] == s3[k]) or \
                        (dp[j - 1] and s2[j - 1] == s3[k])
        
        return dp[n]
```

### 方法三：递归 + 记忆化（便于理解）

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        """
        递归 + 记忆化搜索
        
        Args:
            s1: 第一个字符串
            s2: 第二个字符串
            s3: 目标字符串
            
        Returns:
            s3 是否由 s1 和 s2 交错组成
        """
        m, n = len(s1), len(s2)
        
        if m + n != len(s3):
            return False
        
        # 记忆化字典
        memo = {}
        
        def dfs(i: int, j: int) -> bool:
            """
            判断 s1[i:] 和 s2[j:] 能否交错组成 s3[i+j:]
            
            Args:
                i: s1 的起始位置
                j: s2 的起始位置
                
            Returns:
                是否能组成
            """
            # 基本情况：都处理完了
            if i == m and j == n:
                return True
            
            # 查询缓存
            if (i, j) in memo:
                return memo[(i, j)]
            
            k = i + j  # s3 的当前位置
            result = False
            
            # 尝试从 s1 取字符
            if i < m and s1[i] == s3[k]:
                result = dfs(i + 1, j)
            
            # 尝试从 s2 取字符
            if not result and j < n and s2[j] == s3[k]:
                result = dfs(i, j + 1)
            
            # 缓存结果
            memo[(i, j)] = result
            return result
        
        return dfs(0, 0)
```

### 方法四：BFS 搜索（另一种思路）

```python
from collections import deque

class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        """
        BFS 搜索所有可能的路径
        
        Args:
            s1: 第一个字符串
            s2: 第二个字符串
            s3: 目标字符串
            
        Returns:
            s3 是否由 s1 和 s2 交错组成
        """
        m, n = len(s1), len(s2)
        
        if m + n != len(s3):
            return False
        
        # 使用队列进行 BFS
        queue = deque([(0, 0)])  # (i, j) 表示 s1 和 s2 的当前位置
        visited = {(0, 0)}  # 记录访问过的状态，避免重复
        
        while queue:
            i, j = queue.popleft()
            k = i + j
            
            # 找到解
            if i == m and j == n:
                return True
            
            # 尝试从 s1 取字符
            if i < m and s1[i] == s3[k] and (i + 1, j) not in visited:
                queue.append((i + 1, j))
                visited.add((i + 1, j))
            
            # 尝试从 s2 取字符
            if j < n and s2[j] == s3[k] and (i, j + 1) not in visited:
                queue.append((i, j + 1))
                visited.add((i, j + 1))
        
        return False
```

## 复杂度分析

### 方法一：二维动态规划
- **时间复杂度**：O(m * n)
  - 需要填充 m * n 的二维表
- **空间复杂度**：O(m * n)
  - 需要 dp 二维数组

### 方法二：一维动态规划
- **时间复杂度**：O(m * n)
  - 同样需要遍历所有状态
- **空间复杂度**：O(n)
  - 只使用一维数组，空间优化

### 方法三：递归 + 记忆化
- **时间复杂度**：O(m * n)
  - 最多有 m * n 个不同的子问题
- **空间复杂度**：O(m * n)
  - 递归栈和哈希表的空间

### 方法四：BFS
- **时间复杂度**：O(m * n)
  - 最坏情况访问所有状态
- **空间复杂度**：O(m * n)
  - 队列和访问集合的空间

```
解释：
- dp[0][0] = True（空字符串匹配）
- dp[2][3] = True 表示 "aa" 和 "dbb" 可以交错组成 "aadbb"
- dp[5][5] = True 表示整个 s1 和 s2 可以交错组成 s3
```

路径示例（一种可能的交错方式）：
```
(0,0) -> (1,0) -> (2,0) -> (2,1) -> (2,2) -> (3,2) -> (4,2) -> (4,3) -> (5,3) -> (5,4) -> (5,5)
对应：  a  ->  a  ->  d  ->  b  ->  b  ->  c  ->  b  ->  c  ->  a  ->  c
```

## 关键点总结

1. **长度检查**：最基本的剪枝，len(s1) + len(s2) 必须等于 len(s3)
2. **二维 DP**：状态定义为两个字符串的前缀能否组成目标前缀
3. **状态转移**：当前字符可能来自 s1 或 s2，两种情况取或
4. **空间优化**：可以用一维数组优化空间，降到 O(n)
5. **多种解法**：DP、记忆化递归、BFS 都可以解决，各有优劣

## 易错点

1. **索引混淆**
   - dp[i][j] 对应 s3 的索引是 i+j-1，不是 i+j
   - 字符串索引从 0 开始，但 dp 数组索引从 1 开始表示前缀

2. **初始化错误**
   - 必须正确初始化第一行和第一列
   - dp[0][0] = True 是基础

3. **状态转移逻辑**
   - 是"或"关系，不是"且"关系
   - 只要有一种方式能组成就返回 True

4. **空间优化时的更新顺序**
   - 使用一维数组时，要注意更新顺序
   - dp[0] 需要特殊处理

5. **边界条件**
   - 空字符串的情况要特殊处理
   - s1 或 s2 为空时，问题退化为字符串相等判断
