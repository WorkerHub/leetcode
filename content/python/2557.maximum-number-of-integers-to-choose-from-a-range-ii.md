## 题目描述

给你一个整数数组 `banned`（已排序，无重复）和两个整数 `n` 和 `maxSum`。

从 `[1, n]` 中选取不在 `banned` 中的整数，每个最多选一次，要求选出整数之和 <= `maxSum`。

返回最多能选出的整数数目。

**示例 1：**

```
输入：banned = [1,4,6], n = 6, maxSum = 4
输出：1
解释：可以选 2 或 3，最大选 1 个（选 2+3=5 > 4）。实际 2 <= 4，选 {2}，数目 1。
```

**提示：**

- `1 <= banned.length <= 10^5`
- `1 <= banned[i] <= n <= 10^9`
- `1 <= maxSum <= 10^15`（大范围，需要二分）

## 解题思路

由于 n 可以到 10^9，不能逐个枚举。

**二分答案**：二分选取的整数数目 cnt，判断选前 cnt 个合法整数之和是否 <= maxSum。

合法整数（不在 banned 中）的前 cnt 个之和：利用前缀和和二分查找快速计算第 cnt 个合法整数的值，以及其前缀和。

## Python 代码实现

### 方法一：二分答案（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        # banned 已排序且无重复
        banned_set = set(banned)
        # 合法整数数量 = n - len(banned中 <= n 的数)
        valid_count = n - bisect.bisect_right(banned, n)

        def sum_of_first_k_valid(k):
            # 求前 k 个合法整数之和（1 到 n 中不在 banned 中的最小 k 个）
            # 用二分找第 k 个合法整数的值
            if k <= 0:
                return 0
            # 二分：在 [1, n] 中，前 x 个整数中有多少个合法整数
            # valid_up_to(x) = x - (banned 中 <= x 的数量)
            lo, hi = 1, n
            while lo < hi:
                mid = (lo + hi) // 2
                # 1..mid 中合法整数数量
                valid = mid - bisect.bisect_right(banned, mid)
                if valid >= k:
                    hi = mid
                else:
                    lo = mid + 1
            # lo = 第 k 个合法整数
            kth = lo
            # 前 kth 个整数之和（1+2+...+kth）减去 banned 中 <= kth 的数之和
            total = kth * (kth + 1) // 2
            # 减去 banned 中 <= kth 的数
            banned_count = bisect.bisect_right(banned, kth)
            banned_sum = sum(banned[:banned_count])
            return total - banned_sum

        # 二分答案
        lo, hi = 0, valid_count
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if sum_of_first_k_valid(mid) <= maxSum:
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：前缀和优化

```python
from typing import List
import bisect

class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        # 前缀和
        banned = [x for x in banned if x <= n]
        banned_prefix = [0] * (len(banned) + 1)
        for i, x in enumerate(banned):
            banned_prefix[i+1] = banned_prefix[i] + x

        def banned_sum_up_to(x):
            # banned 中 <= x 的数之和
            idx = bisect.bisect_right(banned, x)
            return banned_prefix[idx]

        def valid_sum(k):
            # 前 k 个合法整数之和
            if k <= 0:
                return 0
            lo, hi = 1, n
            while lo < hi:
                mid = (lo + hi) // 2
                if mid - bisect.bisect_right(banned, mid) >= k:
                    hi = mid
                else:
                    lo = mid + 1
            kth = lo
            return kth * (kth+1)//2 - banned_sum_up_to(kth)

        lo, hi = 0, n - len(banned)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if valid_sum(mid) <= maxSum:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(len(banned) * log n)，外层二分 + 内层二分 + 前缀和
- 空间复杂度：O(len(banned))

## 关键点总结

1. n 很大，不能枚举，用二分答案
2. 快速计算"前 k 个合法整数之和"：二分找第 k 个合法整数，利用等差数列前缀和
3. 在计算中减去 banned 中的数之和

## 易错点

1. banned 中可能有大于 n 的数，需先过滤
2. banned_sum 要用前缀和提前计算，避免每次求和 O(n)
3. 二分上界是合法整数的总数，不是 n
