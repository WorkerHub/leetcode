## 题目描述

给你一个下标从 0 开始的二维整数数组 `flowers`，其中 `flowers[i] = [starti, endi]` 表示第 `i` 朵花的**开放时间段**（闭区间）。

另给你一个下标从 0 开始的整数数组 `people`，`people[i]` 是第 `i` 个人到达的时间。

返回一个整数数组 `answer`，其中 `answer[i]` 是第 `i` 个人到达时**正在开放**的花朵数量。

**示例 1：**
```
输入：flowers = [[1,6],[3,7],[9,12],[4,13]], people = [2,3,7,11]
输出：[1,2,2,2]
```

## 解题思路

**方法一：差分数组/扫描线**（时间范围大时不适用）

**方法二：排序 + 二分（推荐）**

对每个查询时间 `t`：
- 在 `t` 时刻已开放的花：`start <= t` 的花数量（用 `starts` 排序后二分）。
- 在 `t` 时刻已凋谢的花：`end < t` 的花数量（用 `ends` 排序后二分）。
- 答案 = 已开放 - 已凋谢。

**方法三：扫描线事件**：将开放和关闭事件排序，用指针扫描。

## 代码实现

### 方法一：排序 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        # 分别提取开始时间和结束时间，排序
        starts = sorted(f[0] for f in flowers)
        ends = sorted(f[1] for f in flowers)

        ans = []
        for t in people:
            # 开始时间 <= t 的花数量（已开放）
            opened = bisect.bisect_right(starts, t)
            # 结束时间 < t 的花数量（已凋谢）
            closed = bisect.bisect_left(ends, t)
            ans.append(opened - closed)

        return ans
```

### 方法二：扫描线（离线查询）

```python
from typing import List

class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        events = []
        for s, e in flowers:
            events.append((s, 1))   # 开花
            events.append((e + 1, -1))  # 凋谢

        events.sort()

        # 离线处理：将 people 按时间排序，扫描
        indexed_people = sorted(enumerate(people), key=lambda x: x[1])

        ans = [0] * len(people)
        bloom = 0  # 当前开放数量
        ei = 0     # 事件指针

        for idx, t in indexed_people:
            # 处理所有 time <= t 的事件
            while ei < len(events) and events[ei][0] <= t:
                bloom += events[ei][1]
                ei += 1
            ans[idx] = bloom

        return ans
```

## 复杂度分析

**方法一：**
- 时间复杂度：O((m + n) log m)，m 为花数，n 为查询数。
- 空间复杂度：O(m)。

**方法二：**
- 时间复杂度：O((m + n) log(m + n))。
- 空间复杂度：O(m + n)。

## 关键点总结

1. 方法一核心：在 t 时刻开放的花 = `(start <= t 的数量)` - `(end < t 的数量)`。
2. 用 `bisect_right(starts, t)` 统计开始 <= t 的花，`bisect_left(ends, t)` 统计结束 < t 的花。
3. 方法二扫描线适合在线查询顺序不固定的情况。

## 易错点

- `bisect_right(starts, t)` 而非 `bisect_left`（包含等于 t 的情况）。
- `bisect_left(ends, t)` 统计结束时间 < t（严格小于，即已凋谢）。
