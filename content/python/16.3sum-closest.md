## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个目标值 `target`。请你从 `nums` 中选出三个整数，使它们的和与 `target` 最接近。

返回这三个数的和。

假定每组输入只存在恰好一个解。

**示例 1：**
```
输入：nums = [-1,2,1,-4], target = 1
输出：2
解释：与 target 最接近的和是 2 (-1 + 2 + 1 = 2)
```

**示例 2：**
```
输入：nums = [0,0,0], target = 1
输出：0
解释：与 target 最接近的和是 0 (0 + 0 + 0 = 0)
```

## 解题思路

### 核心思想：排序 + 双指针

这道题与「三数之和」非常类似，但不是找和为 0 的三元组，而是找最接近 target 的三数之和。

**算法流程：**
1. 对数组进行排序
2. 遍历数组，固定第一个数 `nums[i]`
3. 用双指针在剩余数组中查找两数之和，使三数之和最接近 target
4. 记录当前最接近的和
5. 根据当前和与 target 的关系移动指针

**关键优化：**
- 如果当前和等于 target，直接返回（不可能更接近了）
- 排序后可以根据和的大小决定指针移动方向

## Python 代码实现

### 方法：排序 + 双指针

```python
class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()  # 排序
        n = len(nums)
        closest_sum = float('inf')  # 初始化为无穷大
        
        # 固定第一个数
        for i in range(n - 2):
            # 双指针
            left, right = i + 1, n - 1
            
            while left < right:
                current_sum = nums[i] + nums[left] + nums[right]
                
                # 如果正好等于target，直接返回
                if current_sum == target:
                    return target
                
                # 更新最接近的和
                if abs(current_sum - target) < abs(closest_sum - target):
                    closest_sum = current_sum
                
                # 移动指针
                if current_sum < target:
                    left += 1  # 和太小，左指针右移
                else:
                    right -= 1  # 和太大，右指针左移
        
        return closest_sum
```

### 优化版（添加剪枝）

```python
class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        closest_sum = nums[0] + nums[1] + nums[2]  # 初始化为前三个数的和
        
        for i in range(n - 2):
            # 剪枝：跳过重复的第一个数（可选优化）
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            left, right = i + 1, n - 1
            
            while left < right:
                current_sum = nums[i] + nums[left] + nums[right]
                
                # 如果正好等于target，直接返回
                if current_sum == target:
                    return target
                
                # 更新最接近的和
                if abs(current_sum - target) < abs(closest_sum - target):
                    closest_sum = current_sum
                
                # 移动指针
                if current_sum < target:
                    left += 1
                else:
                    right -= 1
        
        return closest_sum
```

## 复杂度分析

- **时间复杂度**：O(n²)
  - 排序：O(n log n)
  - 外层循环：O(n)
  - 内层双指针：O(n)
  - 总体：O(n²)

- **空间复杂度**：O(log n)，排序所需的栈空间

## 图解示例

以 `nums = [-1,2,1,-4], target = 1` 为例：

```
排序后：[-4, -1, 1, 2]

i=0, nums[i]=-4:
  left=1, right=3: -4 + (-1) + 2 = -3
    |-3 - 1| = 4, closest_sum = -3
    -3 < 1, left++
  left=2, right=3: -4 + 1 + 2 = -1
    |-1 - 1| = 2 < 4, closest_sum = -1
    -1 < 1, left++
  left > right，结束

i=1, nums[i]=-1:
  left=2, right=3: -1 + 1 + 2 = 2
    |2 - 1| = 1 < 2, closest_sum = 2 ✓
    2 > 1, right--
  left > right，结束

i=2: 结束

结果：2
```

## 关键点总结

1. **与三数之和的区别**：
   - 三数之和：找所有和为 0 的三元组
   - 三数之和最接近：找一个最接近 target 的和

2. **提前返回**：如果 `current_sum == target`，直接返回，不可能更接近

3. **更新条件**：比较的是 `abs(current_sum - target)` 的大小

4. **初始化**：`closest_sum` 可以初始化为前三个数的和或无穷大

5. **不需要去重**：因为只返回一个和，不需要像三数之和那样去重

## 易错点

1. **初始值设置**：
   - ❌ `closest_sum = 0` 可能不合适
   - ✅ `closest_sum = nums[0] + nums[1] + nums[2]` 或 `float('inf')`

2. **比较方式**：
   - 要用 `abs(current_sum - target)` 而不是直接比较大小

3. **提前返回**：
   - 当 `current_sum == target` 时应该立即返回
