## 题目描述

给你一个字符串 `word`，其中 `word` 仅包含 **不同** 的小写英文字母。

电话键盘上有 8 个按键（2-9），每个按键可以映射多个字母。你需要重新分配字母到按键，每个字母只能分配到一个按键。

输入某个字母的代价等于它在对应按键上的位置（从 1 开始）。

返回输入 `word` 中所有字母的最小总代价。

**示例 1：**
```
输入：word = "abcde"
输出：5
解释：每个按键分配一个字母，每个字母代价为 1，总代价 = 5
```

**示例 2：**
```
输入：word = "xycdefghij"
输出：12
解释：8 个按键，前 8 个字母各代价 1，后 2 个字母代价 2，总代价 = 8 + 2*2 = 12
```

**提示：**
- `1 <= word.length <= 26`
- `word` 中字母各不相同

## 解题思路

因为 `word` 中所有字母各不相同，每个字母只出现一次。

8 个按键，将字母分配：
- 前 8 个字母各代价 1（每个按键放第一位）
- 第 9-16 个字母代价 2（每个按键放第二位）
- 第 17-24 个字母代价 3
- 以此类推

总代价 = `sum((i // 8 + 1) for i in range(len(word)))`

## Python 代码实现

### 方法一：直接计算（推荐）

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        n = len(word)
        total = 0
        for i in range(n):
            total += i // 8 + 1
        return total
```

### 方法二：数学公式

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        n = len(word)
        # n 个字母，第 i 个（0-indexed）字母代价为 i // 8 + 1
        # 0-7: 代价 1，8-15: 代价 2，16-23: 代价 3，24-25: 代价 4
        q, r = divmod(n, 8)
        # 完整的 8 组：q 组，每组代价从 1 到 q，每组 8 个字母
        total = 8 * (1 + q) * q // 2 + (q + 1) * r
        return total
```

### 方法三：列表推导

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        return sum(i // 8 + 1 for i in range(len(word)))
```

## 复杂度分析

- 时间复杂度：O(n)，n <= 26 实际为 O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 所有字母各不相同，只需考虑字母个数，不需要考虑频率
2. 8 个按键，第 i 个字母（0-indexed）代价为 `i // 8 + 1`
3. 贪心思想：把字母按任意顺序排，前 8 个代价最小

## 易错点

1. 本题字母各不相同，不需要按频率贪心（与 3016 不同）
2. 键盘有 8 个键（2-9），不是 9 个或 10 个
