## 题目描述

给你一个整数数组 `nums`，请你返回其中位数为**偶数**的数字的个数。

**示例 1：**

```
输入：nums = [12,345,2,6,7896]
输出：2
解释：
12 是 2 位数字（位数为偶数）
345 是 3 位数字（位数为奇数）
2 是 1 位数字（位数为奇数）
6 是 1 位数字（位数为奇数）
7896 是 4 位数字（位数为偶数）
因此只有 12 和 7896 是位数为偶数的数字
```

**示例 2：**

```
输入：nums = [555,901,482,1771]
输出：1
解释：
只有 1771 是位数为偶数的数字。
```

**提示：**

- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^5`

## 解题思路

### 方法一：转字符串计算长度

将数字转为字符串，字符串长度即为数字的位数，判断长度是否为偶数。

### 方法二：数学方法（取对数）

位数 = `int(log10(num)) + 1`，但需要注意浮点精度问题，不推荐。

### 方法三：循环除以 10 计数

不断将数字除以 10，计数直到商为 0，得到位数。

### 方法四：范围判断

利用题目约束 `1 <= nums[i] <= 10^5`：
- 偶数位：2 位（10-99），4 位（1000-9999），6 位（100000-999999，但最大 10^5 = 100000 是 6 位）
- 在 `[10, 99]` 或 `[1000, 9999]` 或 `num == 100000` 时为偶数位

## Python 代码实现

### 方法一：字符串转换（推荐，最简洁）

```python
from typing import List

class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        count = 0
        for num in nums:
            # 转为字符串，判断长度是否为偶数
            if len(str(num)) % 2 == 0:
                count += 1
        return count
```

### 方法一变体：列表推导式（一行解法）

```python
from typing import List

class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        # 使用列表推导式统计偶数位数字的个数
        return sum(1 for num in nums if len(str(num)) % 2 == 0)
```

### 方法二：循环除 10 计算位数

```python
from typing import List

class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        def count_digits(n: int) -> int:
            """计算整数 n 的位数"""
            digits = 0
            while n > 0:
                digits += 1
                n //= 10  # 去掉最低位
            return digits

        count = 0
        for num in nums:
            if count_digits(num) % 2 == 0:
                count += 1
        return count
```

### 方法三：范围判断（利用题目约束）

```python
from typing import List

class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        count = 0
        for num in nums:
            # 根据题目约束 1 <= num <= 10^5，偶数位的范围：
            # 2位：[10, 99]
            # 4位：[1000, 9999]
            # 6位：num == 100000（10^5 恰好是 6 位）
            if (10 <= num <= 99 or
                1000 <= num <= 9999 or
                num == 100000):
                count += 1
        return count
```

### 方法四：使用 math.log10（了解即可，有精度风险）

```python
from typing import List
import math

class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        count = 0
        for num in nums:
            # 位数 = floor(log10(num)) + 1
            # 注意：此方法有浮点精度问题，不推荐
            digits = int(math.log10(num)) + 1
            if digits % 2 == 0:
                count += 1
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（字符串） | O(n * d) | O(d) |
| 方法二（循环除10） | O(n * d) | O(1) |
| 方法三（范围判断） | O(n) | O(1) |
| 方法四（log10） | O(n) | O(1) |

其中 `n` 为数组长度，`d` 为数字的最大位数（本题 `d <= 6`）。

实际上由于 `d` 是常数，所有方法的时间复杂度都是 O(n)。

## 关键点总结

1. **最简方法**：`len(str(num)) % 2 == 0`，直观且不易出错
2. **位数判断**：偶数位 `% 2 == 0`，奇数位 `% 2 == 1`
3. **题目约束利用**：`nums[i] <= 10^5`，偶数位只可能是 2 位、4 位或 6 位（仅 100000）
4. **Python 特性**：`sum(条件)` 可以直接统计满足条件的个数（`True` 计 1，`False` 计 0）
5. **负数处理**：本题保证正整数，不需要处理负数；若有负数，`str()` 会包含 `-` 号，需要特殊处理

## 易错点

- **log10 方法有精度问题**：某些整数经过浮点运算后结果会有微小误差，例如 `math.log10(100)` 理论上是 2，但浮点实现可能是 `1.9999999...`，`int()` 取整后变成 1，导致结果错误
- **字符串方法对负数不适用**：`str(-12)` 长度为 3（含负号），需额外处理，但本题不涉及负数
- **范围判断方法依赖题目约束**：如果输入范围改变（如有 10^6 以上的数），方法三需要更新
