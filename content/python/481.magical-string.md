## 题目描述

神奇字符串 s 仅由 '1' 和 '2' 组成，并需要遵守下面的规则：

- 神奇字符串 s 的神奇之处在于，串联字符串中 '1' 和 '2' 的连续出现次数可以生成该字符串。

s 的前几个元素是 s = "1221121221221121122……" 。如果将 s 中连续的若干 1 和 2 进行分组，可以得到 "1 22 11 2 1 22 1 22 11 2 11 22 ......" 。每组中 1 或者 2 的出现次数分别是 "1 2 2 1 1 2 1 2 2 1 2 2 ......" 。上面的出现次数正是 s 自身。

给你一个整数 n ，返回在神奇字符串 s 的前 n 个数字中 1 的数目。

**示例 1：**
```
输入：n = 6
输出：3
解释：神奇字符串 s 的前 6 个元素是 "122112"，它包含三个 1，因此返回 3。
```

**示例 2：**
```
输入：n = 1
输出：1
```

**提示：**
- 1 <= n <= 10^5

## 解题思路

这道题的关键是理解"神奇字符串"的生成规则：

1. **自引用性质**：字符串本身描述了自己的构成方式
   - 字符串由若干组连续的 1 或 2 组成
   - 每组的长度序列恰好是字符串本身

2. **构造过程**：
   - 初始字符串为 "122"
   - 使用两个指针：
     - `i`：指向当前要生成的组的长度（读取指针）
     - `j`：指向当前要填充的位置（写入指针）
   - 当前要填充的数字在 1 和 2 之间交替
   - 每次根据 s[i] 的值，决定要填充多少个相同的数字

3. **核心观察**：
   - s[0] = '1'，表示第一组有 1 个数字
   - s[1] = '2'，表示第二组有 2 个数字
   - s[2] = '2'，表示第三组有 2 个数字
   - 以此类推...

## Python 代码实现

### 方法一：双指针模拟（推荐）

```python
from typing import List

class Solution:
    def magicalString(self, n: int) -> int:
        """
        使用双指针模拟字符串的生成过程
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if n <= 0:
            return 0
        if n <= 3:
            return 1
        
        # 初始化字符串为 "122"
        s = [1, 2, 2]
        
        # i: 指向当前组的长度值
        # num: 当前要填充的数字（1 或 2）
        i = 2  # 从索引 2 开始读取长度
        num = 1  # 下一组要填充 1
        
        # 继续生成直到长度达到 n
        while len(s) < n:
            # s[i] 表示当前组的长度
            count = s[i]
            
            # 填充 count 个 num
            for _ in range(count):
                s.append(num)
                if len(s) >= n:
                    break
            
            # 切换到下一个数字（1 和 2 交替）
            num = 3 - num  # 1 变 2，2 变 1
            
            # 移动到下一个长度指示位置
            i += 1
        
        # 统计前 n 个数字中 1 的个数
        return s[:n].count(1)
```

### 方法二：优化空间（边生成边计数）

```python
class Solution:
    def magicalString(self, n: int) -> int:
        """
        边生成边计数，避免存储整个字符串
        
        时间复杂度：O(n)
        空间复杂度：O(n) - 仍需要存储字符串用于读取长度
        """
        if n <= 0:
            return 0
        if n <= 3:
            return 1
        
        s = [1, 2, 2]
        ones = 1  # 前 3 个元素中有 1 个 1
        i = 2
        num = 1
        
        while len(s) < n:
            count = s[i]
            
            for _ in range(count):
                s.append(num)
                # 如果添加的是 1，增加计数
                if num == 1 and len(s) <= n:
                    ones += 1
                if len(s) >= n:
                    break
            
            num = 3 - num
            i += 1
        
        return ones
```

### 方法三：使用字符串（更直观）

```python
class Solution:
    def magicalString(self, n: int) -> int:
        """
        使用字符串而不是列表
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if n <= 0:
            return 0
        if n <= 3:
            return 1
        
        s = "122"
        i = 2
        
        while len(s) < n:
            # 当前要填充的数字
            num = '1' if s[-1] == '2' else '2'
            # 填充次数
            count = int(s[i])
            # 追加字符
            s += num * count
            i += 1
        
        # 统计前 n 个字符中 '1' 的个数
        return s[:n].count('1')
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度**：O(n)
  - 需要生成 n 个字符
  - 每个字符只生成一次
  
- **空间复杂度**：O(n)
  - 需要存储生成的字符串
  - 虽然方法二尝试优化，但仍需完整字符串用于读取长度

**方法三：**
- **时间复杂度**：O(n)
  - 字符串拼接在 Python 中可能导致额外开销
  - 但总体仍是线性复杂度
  
- **空间复杂度**：O(n)
  - 存储字符串

## 关键点总结

1. **理解自引用性质**：字符串本身既是数据又是描述
2. **双指针技巧**：一个指针读取长度，一个指针写入数据
3. **数字交替**：使用 `num = 3 - num` 在 1 和 2 之间切换
4. **边界处理**：前 3 个字符需要特殊处理
5. **及时终止**：生成到 n 个字符就可以停止

## 易错点

1. **初始状态错误**
   - 必须初始化为 "122"，不能是 "12" 或其他
   - 读取指针 i 从索引 2 开始

2. **数字交替逻辑**
   - 容易搞混当前应该填充 1 还是 2
   - 注意是根据上一组的数字来决定下一组

3. **计数边界**
   - 当长度超过 n 时要及时停止计数
   - 避免统计多余的字符

4. **特殊情况处理**
   - n = 1, 2, 3 时需要特殊处理或确保逻辑正确
