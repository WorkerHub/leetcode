## 题目描述

在第 1 天，有一个人知道一个秘密。

从第 `delay` 天开始，每个知道秘密的人每天可以将秘密告诉另一个新人。每个知道秘密的人在第 `forget` 天（从他知道秘密当天算起的第 `forget` 天）会忘记秘密。

**注意：**一个人在忘记秘密的那天仍然可以传播秘密（就是说在忘记之前还能传播）。

给你整数 `n`、`delay` 和 `forget`，返回在第 `n` 天末知道秘密的人数（模 `10^9 + 7`）。

**示例 1：**
```
输入：n = 6, delay = 2, forget = 4
输出：5
```

**示例 2：**
```
输入：n = 4, delay = 1, forget = 3
输出：6
```

**提示：**
- `2 <= n <= 1000`
- `1 <= delay < forget <= n`

## 解题思路

**DP 差分：**
设 `dp[i]` 为第 `i` 天**新增**知道秘密的人数。

- 第 1 天：`dp[1] = 1`。
- 第 `i` 天新增人数 = 第 `i-1` 天能传播秘密的人数（即第 `i-delay` 到 `i-forget` 天新知道秘密且尚未忘记的人的累计数）。

用前缀和优化：维护一个当前**活跃**（可传播且未忘记）的人数之和。

## 代码实现

### 方法一：动态规划 + 前缀和（推荐）

```python
class Solution:
    def peopleAwareOfSecret(self, n: int, delay: int, forget: int) -> int:
        MOD = 10 ** 9 + 7
        
        # dp[i]: 第 i 天新增知道秘密的人数
        dp = [0] * (n + 1)
        dp[1] = 1
        
        # active[i]: 第 i 天开始传播的人中，在第 j 天（j >= i+delay，j < i+forget）可传播
        # 维护当前可传播的人数前缀和
        spread = 0  # 当前可传播的人数总和
        
        for i in range(2, n + 1):
            # 第 i-delay 天新知道的人今天开始可以传播
            if i - delay >= 1:
                spread = (spread + dp[i - delay]) % MOD
            # 第 i-forget 天新知道的人今天忘记了
            if i - forget >= 1:
                spread = (spread - dp[i - forget]) % MOD
            dp[i] = spread
        
        # 第 n 天末，仍知道秘密的人：第 n-forget+1 到 n 天新知道的人
        ans = 0
        for i in range(max(1, n - forget + 1), n + 1):
            ans = (ans + dp[i]) % MOD
        
        return ans
```

### 方法二：模拟（队列）

```python
from collections import deque

class Solution:
    def peopleAwareOfSecret(self, n: int, delay: int, forget: int) -> int:
        MOD = 10 ** 9 + 7
        
        # 队列中每个元素表示 (知道秘密的天, 人数)
        # 用数组 dp[day] 代替
        dp = [0] * (n + 1)
        dp[1] = 1
        
        for day in range(2, n + 1):
            # 今天新学秘密的人：来自 day-delay 到 day-1 仍未忘记的人
            for prev in range(max(1, day - forget + 1), day - delay + 1):
                if prev >= 1 and day - prev < forget:
                    dp[day] = (dp[day] + dp[prev]) % MOD
        
        # 统计第 n 天末仍知道秘密的人
        ans = sum(dp[max(1, n - forget + 1):n + 1]) % MOD
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP + 前缀和 | O(n) | O(n) |
| 模拟 | O(n * forget) | O(n) |

## 关键点总结

1. 第 `i` 天开始传播的条件：知道秘密已 `delay` 天，且未忘记（< `forget` 天）。
2. 用滑动窗口维护当前可传播的人数，避免每次重新求和。
3. 最终答案为第 `[n-forget+1, n]` 天新增知道秘密的人总数之和。

## 易错点

- 忘记的那天仍可传播，因此范围包含 `i - forget + 1`。
- 对 `spread` 取模后可能为负数（Python 取模不会，但要注意）。
