## 题目描述

给你一个二维整数数组 `bottomLeft` 和 `topRight`，分别表示 `n` 个矩形的左下角和右上角坐标。

找出所有两个矩形交集中，能放置的最大正方形的边长。

返回最大正方形的面积，若无交集返回 0。

**示例 1：**
```
输入：bottomLeft = [[1,1],[2,2],[3,1]], topRight = [[3,3],[4,4],[6,6]]
输出：1
```

**提示：**
- `n == bottomLeft.length == topRight.length`
- `1 <= n <= 10^3`
- `bottomLeft[i].length == topRight[i].length == 2`

## 解题思路

枚举所有 `(i, j)` 对，计算两个矩形的交集：
- 交集左下角：`(max(bl_i[0], bl_j[0]), max(bl_i[1], bl_j[1]))`
- 交集右上角：`(min(tr_i[0], tr_j[0]), min(tr_i[1], tr_j[1]))`

若交集合法（左下角坐标 <= 右上角坐标），交集内最大正方形边长 = `min(宽, 高)`。

## Python 代码实现

### 方法一：枚举所有矩形对（推荐）

```python
from typing import List

class Solution:
    def largestSquareInsideTwoRectangles(self, bottomLeft: List[List[int]], topRight: List[List[int]]) -> int:
        n = len(bottomLeft)
        ans = 0

        for i in range(n):
            for j in range(i + 1, n):
                # 计算两矩形的交集
                ix1 = max(bottomLeft[i][0], bottomLeft[j][0])
                iy1 = max(bottomLeft[i][1], bottomLeft[j][1])
                ix2 = min(topRight[i][0], topRight[j][0])
                iy2 = min(topRight[i][1], topRight[j][1])

                # 检查交集是否有效
                if ix1 < ix2 and iy1 < iy2:
                    # 交集内最大正方形边长
                    side = min(ix2 - ix1, iy2 - iy1)
                    ans = max(ans, side * side)

        return ans
```

### 方法二：使用辅助函数

```python
from typing import List

class Solution:
    def largestSquareInsideTwoRectangles(self, bottomLeft: List[List[int]], topRight: List[List[int]]) -> int:
        def intersect_square(bl1, tr1, bl2, tr2):
            # 计算两矩形交集中最大正方形边长
            ix1 = max(bl1[0], bl2[0])
            iy1 = max(bl1[1], bl2[1])
            ix2 = min(tr1[0], tr2[0])
            iy2 = min(tr1[1], tr2[1])
            if ix1 >= ix2 or iy1 >= iy2:
                return 0
            return min(ix2 - ix1, iy2 - iy1)

        n = len(bottomLeft)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                side = intersect_square(bottomLeft[i], topRight[i], bottomLeft[j], topRight[j])
                ans = max(ans, side * side)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有矩形对
- 空间复杂度：O(1)

## 关键点总结

1. 两矩形交集 = 坐标分量取 max（左下）和 min（右上）
2. 交集有效条件：`ix1 < ix2` 且 `iy1 < iy2`
3. 交集内最大正方形边长 = `min(宽, 高)`

## 易错点

1. 严格小于（不含等号）：交集有效需要严格 `<`，否则退化为线段或点
2. 返回面积（边长的平方），不是边长
