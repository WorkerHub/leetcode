## 题目描述

给定 `m × n` 的整数矩阵 `grid`，每个格子有一个代价值。从左上角 `(0,0)` 出发，只能向右或向下移动，到达右下角 `(m-1,n-1)`。求路径上所有格子代价之和的最小值（包含起点和终点）。

**示例 1：**
```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：路径 (0,0)->(0,1)->(0,2)->(1,2)->(2,2)：1+3+1+1+1=7
     路径 (0,0)->(1,0)->(2,0)->(2,1)->(2,2)：1+1+4+2+1=9
     最优路径代价 7。
```

**示例 2：**
```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

**提示：**
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 100`

## 解题思路

经典的动态规划问题。

`dp[i][j]`：从 `(0,0)` 到 `(i,j)` 的最小代价路径和。

转移方程：
- `dp[0][0] = grid[0][0]`
- 第一行：`dp[0][j] = dp[0][j-1] + grid[0][j]`
- 第一列：`dp[i][0] = dp[i-1][0] + grid[i][0]`
- 其他：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = grid[0][0]

        # 初始化第一行
        for j in range(1, n):
            dp[0][j] = dp[0][j-1] + grid[0][j]

        # 初始化第一列
        for i in range(1, m):
            dp[i][0] = dp[i-1][0] + grid[i][0]

        # 填表
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]

        return dp[m-1][n-1]
```

### 方法二：空间优化（滚动数组）

```python
from typing import List

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 只用一行 DP 数组
        dp = [0] * n
        dp[0] = grid[0][0]
        for j in range(1, n):
            dp[j] = dp[j-1] + grid[0][j]

        for i in range(1, m):
            dp[0] += grid[i][0]
            for j in range(1, n):
                dp[j] = min(dp[j], dp[j-1]) + grid[i][j]

        return dp[n-1]
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：方法一 O(mn)；方法二 O(n)

## 关键点总结

1. 只能向右或向下移动，使得问题具有无后效性，适合 DP
2. 滚动数组将空间从 O(mn) 优化到 O(n)
3. 正确初始化第一行和第一列

## 易错点

1. 第一行只能从左转移（只能向右），第一列只能从上转移（只能向下）
2. `dp[0][0] = grid[0][0]`，不是 0
