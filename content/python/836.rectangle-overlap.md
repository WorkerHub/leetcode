## 题目描述

矩形以列表 `[x1, y1, x2, y2]` 的形式表示，其中 `(x1, y1)` 为左下角的坐标，`(x2, y2)` 是右上角的坐标。矩形的上下边平行于 x 轴，左右边平行于 y 轴。

如果相交的面积为 **正**，则称两矩形重叠。需要明确的是，只有一条边重叠的两个矩形不认为是重叠的。

给出两个矩形 `rec1` 和 `rec2`。如果它们重叠，返回 `true`；否则，返回 `false`。

**示例 1:**
```
输入: rec1 = [0,0,2,2], rec2 = [1,1,3,3]
输出: true
```

**示例 2:**
```
输入: rec1 = [0,0,1,1], rec2 = [1,0,2,1]
输出: false
```

**示例 3:**
```
输入: rec1 = [0,0,1,1], rec2 = [2,2,3,3]
输出: false
```

**提示:**
- `rect1.length == 4`
- `rect2.length == 4`
- `-10^9 <= rec1[i], rec2[i] <= 10^9`
- `rec1` 和 `rec2` 表示有效的矩形

## Python 代码实现

```python
from typing import List

class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        # 不重叠的情况：
        # rec1 在 rec2 左边：rec1[2] <= rec2[0]
        # rec1 在 rec2 右边：rec1[0] >= rec2[2]
        # rec1 在 rec2 下边：rec1[3] <= rec2[1]
        # rec1 在 rec2 上边：rec1[1] >= rec2[3]
        
        # 重叠 = 不满足所有不重叠条件
        return not (rec1[2] <= rec2[0] or  # rec1 在左
                    rec1[0] >= rec2[2] or  # rec1 在右
                    rec1[3] <= rec2[1] or  # rec1 在下
                    rec1[1] >= rec2[3])    # rec1 在上
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向思维**：判断不重叠更简单
2. **四个条件**：左、右、上、下
3. **边界情况**：边重叠不算重叠（<=）

## 易错点

1. **等号**：<= 而不是 <
2. **坐标理解**：(x1,y1) 是左下，(x2,y2) 是右上
3. **逻辑运算**：not (A or B or C or D)

## 学习建议

1. **几何问题**：逆向思维往往更简单
2. **边界条件**：等号的位置很重要
