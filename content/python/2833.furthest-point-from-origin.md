## 题目描述

给你一个字符串 `moves`，其中每个字符为 `'L'`、`'R'` 或 `'_'`。

- `'L'`：向左移动 1 步（-1）
- `'R'`：向右移动 1 步（+1）
- `'_'`：可以向左或向右移动 1 步（你来选）

从坐标轴的原点（0）出发，执行所有动作后，返回**距原点最远**的可能距离。

**示例 1：**
```
输入：moves = "L_RL__R"
输出：3
解释：将 '_' 都选为 'L'，总位移 = -1+(-1)+1+(-1)+(-1)+(-1)+1 = -3，距离 = 3
```

**示例 2：**
```
输入：moves = "_______"
输出：7
解释：将所有 '_' 选为同一方向，距离 = 7
```

**提示：**
- `1 <= moves.length <= 50`
- `moves` 只包含 `'L'`、`'R'`、`'_'`

## 解题思路

**贪心：** 所有 `'_'` 都选择与 `L` 和 `R` 中多的一方相同的方向，可以最大化距离。

- 计算 `L` 的个数 `nl`，`R` 的个数 `nr`，`_` 的个数 `nu`
- 最终距离 = `|nl - nr| + nu`（所有 `_` 都分配给多的那方）

**数学分析：** 
- 若 `nl > nr`：选所有 `_` 为 L，距离 = `(nl + nu) - nr = |nl - nr| + nu`
- 若 `nr > nl`：选所有 `_` 为 R，距离 = `nr + nu - nl = |nl - nr| + nu`
- 若相等：选所有 `_` 为任意方向，距离 = `nu`

三种情况都满足 `|nl - nr| + nu`。

## Python 代码实现

### 方法一：计数（推荐）

```python
class Solution:
    def furthestDistanceFromOrigin(self, moves: str) -> int:
        nl = moves.count('L')
        nr = moves.count('R')
        nu = moves.count('_')
        return abs(nl - nr) + nu
```

### 方法二：逐步模拟理解

```python
class Solution:
    def furthestDistanceFromOrigin(self, moves: str) -> int:
        # 统计各种字符数量
        counts = {'L': 0, 'R': 0, '_': 0}
        for ch in moves:
            counts[ch] += 1

        # 固定 L 和 R 的净位移，'_' 全给多的那方
        net = counts['R'] - counts['L']
        wildcards = counts['_']
        # 最大距离 = |net| + wildcards（全部分配给净位移方向）
        return abs(net) + wildcards
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(1)

## 关键点总结

1. `'_'` 应该全部分配给 L 和 R 中较多的一方，最大化净位移
2. 答案 = `|count_L - count_R| + count_underscore`
3. 无论净位移方向如何，`'_'` 都能使距离增加

## 易错点

1. `'_'` 增加的距离是其数量，与净位移方向无关
2. 若 nl == nr，所有 `'_'` 选同一方向，距离 = `count_underscore`
