## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`。

如果下标 `i` 满足：`nums[0] + nums[1] + ... + nums[i] >= nums[i+1] + nums[i+2] + ... + nums[n-1]`，则称 `i` 是一个**合法分割**。

返回合法分割的**数量**（注意 `i` 不能是最后一个下标，即 `0 <= i < n-1`）。

**示例 1：**
```
输入：nums = [10,4,-8,7]
输出：2
解释：i=0: 10 >= 4-8+7=3，合法。i=1: 10+4=14 >= -8+7=-1，合法。i=2: 10+4-8=6 >= 7，不合法。共2个。
```

**示例 2：**
```
输入：nums = [2,3,1,0]
输出：2
```

## 解题思路

计算前缀和 `prefix`，总和 `total`。对每个合法的分割点 `i`（`0 <= i < n-1`）：
- 左侧和 = `prefix[i+1]`
- 右侧和 = `total - prefix[i+1]`
- 条件：`prefix[i+1] >= total - prefix[i+1]`，即 `2 * prefix[i+1] >= total`。

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def waysToSplitArray(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)
        prefix = 0
        count = 0

        for i in range(n - 1):  # i 不能是最后一个下标
            prefix += nums[i]
            # 左侧和 >= 右侧和
            if prefix >= total - prefix:
                count += 1

        return count
```

### 方法二：预计算前缀和数组

```python
from typing import List
from itertools import accumulate

class Solution:
    def waysToSplitArray(self, nums: List[int]) -> int:
        prefix = list(accumulate(nums))
        total = prefix[-1]
        # 检查每个分割点（不包括最后一个）
        return sum(1 for i in range(len(nums) - 1) if prefix[i] * 2 >= total)
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)（方法一），O(n)（方法二）。

## 关键点总结

1. 前缀和快速计算左侧和，右侧和 = 总和 - 左侧和。
2. 条件等价：`2 * left_sum >= total`，避免额外计算右侧和。
3. 分割点 `i` 的范围是 `0` 到 `n-2`（必须保留最右边至少一个元素在右侧）。

## 易错点

- 分割点不能是最后一个下标（`i < n-1`），即右侧至少有一个元素。
- 注意 `nums` 中有负数，总和可能为负，条件判断不能简化为纯正数逻辑。
