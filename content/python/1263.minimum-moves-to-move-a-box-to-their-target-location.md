## 题目描述

这是一个推箱子游戏，玩家需要在仓库中将箱子推到目标位置。

游戏用一个 `m x n` 的网格表示，每个格子可能是：

- `'S'`：玩家（Storekeeper）的起始位置，只有一个
- `'B'`：箱子（Box）的起始位置，只有一个
- `'T'`：目标位置（Target），只有一个
- `'.'`：空地板，可以自由移动
- `'#'`：墙壁，不能通过

玩家可以在空地板上向上、下、左、右移动。

**推箱子规则：**
- 玩家必须站在箱子的相邻位置
- 玩家移动方向要与推箱子的方向一致
- 箱子被推动后，玩家会移动到箱子原来的位置
- 箱子只能被推到空地板上，不能推到墙壁或越界

请返回将箱子推到目标位置所需的**最少推动次数**。如果无法完成，返回 `-1`。

**示例 1：**

```
输入：grid = [["#","#","#","#","#","#"],
             ["#","T","#","#","#","#"],
             ["#",".",".","B",".","#"],
             ["#",".","#","#",".","#"],
             ["#",".",".",".","S","#"],
             ["#","#","#","#","#","#"]]
输出：3
解释：玩家从 S 推箱子 3 次到 T
```

**示例 2：**

```
输入：grid = [["#","#","#","#","#","#"],
             ["#","T","#","#","#","#"],
             ["#",".",".","B",".","#"],
             ["#",".",".","#",".","#"],
             ["#",".",".",".","S","#"],
             ["#","#","#","#","#","#"]]
输出：-1
解释：无法将箱子推到目标位置
```

**示例 3：**

```
输入：grid = [["#","#","#","#","#","#"],
             ["#","T",".",".","#","#"],
             ["#",".","#","B",".","#"],
             ["#",".",".",".",".","#"],
             ["#",".",".",".","S","#"],
             ["#","#","#","#","#","#"]]
输出：5
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 20`
- `grid` 包含且只包含一个 `'S'`、`'B'` 和 `'T'`

## 解题思路

这是一道经典的**推箱子问题**，需要使用**双层 BFS**。

**核心难点：**

1. **状态表示**：不仅要记录箱子的位置，还要记录玩家的位置
   - 状态：`(box_row, box_col, player_row, player_col)`
   - 推箱子的次数作为 BFS 的层数

2. **推箱子的条件**：
   - 玩家必须能够到达箱子的反方向位置
   - 箱子的新位置必须是空地板

3. **BFS 策略**：
   - 外层 BFS：枚举箱子的可能移动方向（推动）
   - 内层 BFS：检查玩家是否能到达推箱子所需的位置

**算法步骤：**

1. 找到 S、B、T 的初始位置
2. 使用 BFS，状态为 `(箱子位置, 玩家位置)`
3. 对于每个状态，枚举箱子的 4 个移动方向
4. 对于每个方向，检查：
   - 箱子的新位置是否合法（不是墙，不越界）
   - 玩家能否到达推箱子所需的位置
5. 如果箱子到达目标位置，返回推动次数

## Python 代码实现

### 方法一：BFS + 状态检查（推荐）⭐

```python
class Solution:
    def minPushBox(self, grid: List[List[str]]) -> int:
        from collections import deque
        
        m, n = len(grid), len(grid[0])
        
        # 找到 S、B、T 的位置
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 'S':
                    start = (i, j)
                elif grid[i][j] == 'B':
                    box = (i, j)
                elif grid[i][j] == 'T':
                    target = (i, j)
        
        # 检查位置是否合法
        def is_valid(x, y):
            return 0 <= x < m and 0 <= y < n and grid[x][y] != '#'
        
        # 检查玩家能否从 player 到达 dest，同时避开箱子 box
        def can_reach(player, dest, box):
            if player == dest:
                return True
            
            visited = set([player])
            queue = deque([player])
            
            while queue:
                x, y = queue.popleft()
                
                for dx, dy in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                    nx, ny = x + dx, y + dy
                    
                    if (nx, ny) == dest:
                        return True
                    
                    # 不能走到箱子位置，不能走墙
                    if (nx, ny) != box and is_valid(nx, ny) and (nx, ny) not in visited:
                        visited.add((nx, ny))
                        queue.append((nx, ny))
            
            return False
        
        # BFS 推箱子
        # 状态：(箱子位置, 玩家位置, 推动次数)
        queue = deque([(box, start, 0)])
        visited = set([(box, start)])
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while queue:
            (bx, by), (px, py), pushes = queue.popleft()
            
            # 箱子到达目标
            if (bx, by) == target:
                return pushes
            
            # 尝试向 4 个方向推箱子
            for dx, dy in directions:
                # 箱子的新位置
                nbx, nby = bx + dx, by + dy
                
                # 玩家需要站在箱子的反方向位置
                req_px, req_py = bx - dx, by - dy
                
                # 检查箱子新位置是否合法
                if not is_valid(nbx, nby):
                    continue
                
                # 检查玩家需要站的位置是否合法
                if not is_valid(req_px, req_py):
                    continue
                
                # 检查玩家能否到达所需位置
                if not can_reach((px, py), (req_px, req_py), (bx, by)):
                    continue
                
                # 新状态
                new_state = ((nbx, nby), (bx, by))
                
                if new_state not in visited:
                    visited.add(new_state)
                    queue.append(((nbx, nby), (bx, by), pushes + 1))
        
        return -1
```

### 方法二：优化版本（使用 A* 启发式搜索）

使用曼哈顿距离作为启发函数优化搜索。

```python
class Solution:
    def minPushBox(self, grid: List[List[str]]) -> int:
        from collections import deque
        import heapq
        
        m, n = len(grid), len(grid[0])
        
        # 找到起始位置
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 'S':
                    player = (i, j)
                elif grid[i][j] == 'B':
                    box = (i, j)
                elif grid[i][j] == 'T':
                    target = (i, j)
        
        def is_valid(x, y):
            return 0 <= x < m and 0 <= y < n and grid[x][y] != '#'
        
        def can_reach(player, dest, box):
            if player == dest:
                return True
            visited = {player}
            queue = deque([player])
            while queue:
                x, y = queue.popleft()
                for dx, dy in [(0,1), (0,-1), (1,0), (-1,0)]:
                    nx, ny = x + dx, y + dy
                    if (nx, ny) == dest:
                        return True
                    if (nx, ny) != box and is_valid(nx, ny) and (nx, ny) not in visited:
                        visited.add((nx, ny))
                        queue.append((nx, ny))
            return False
        
        # 曼哈顿距离作为启发函数
        def heuristic(box):
            return abs(box[0] - target[0]) + abs(box[1] - target[1])
        
        # 优先队列：(优先级, 推动次数, 箱子位置, 玩家位置)
        heap = [(heuristic(box), 0, box, player)]
        visited = {(box, player)}
        
        while heap:
            _, pushes, (bx, by), (px, py) = heapq.heappop(heap)
            
            if (bx, by) == target:
                return pushes
            
            for dx, dy in [(0,1), (0,-1), (1,0), (-1,0)]:
                nbx, nby = bx + dx, by + dy
                req_px, req_py = bx - dx, by - dy
                
                if not is_valid(nbx, nby) or not is_valid(req_px, req_py):
                    continue
                
                if not can_reach((px, py), (req_px, req_py), (bx, by)):
                    continue
                
                new_state = ((nbx, nby), (bx, by))
                if new_state not in visited:
                    visited.add(new_state)
                    priority = pushes + 1 + heuristic((nbx, nby))
                    heapq.heappush(heap, (priority, pushes + 1, (nbx, nby), (bx, by)))
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(m² × n² × m × n) = O((mn)³)
  - 状态数：O((mn)²)（箱子和玩家的位置组合）
  - 每个状态检查玩家可达性：O(mn)
  - 最坏情况遍历所有状态

- **空间复杂度**：O((mn)²)
  - visited 集合存储状态
  - BFS 队列最多存储 O((mn)²) 个状态

## 关键点总结

1. **双重 BFS**：外层推箱子，内层检查玩家可达性
2. **状态表示**：`(箱子位置, 玩家位置)` 二元组
3. **推箱子条件**：玩家必须在箱子反方向，且箱子新位置合法
4. **玩家可达性检查**：单独的 BFS，避开箱子位置
5. **优化**：使用 A* 启发式搜索（曼哈顿距离）

## 易错点

1. **玩家位置遗漏**：状态中必须包含玩家位置，否则无法判断可达性
2. **反方向位置**：玩家需要站在箱子的反方向 `(bx - dx, by - dy)`
3. **避开箱子**：玩家移动时不能经过箱子的当前位置
4. **推动后玩家位置**：推箱子后，玩家移动到箱子原来的位置
5. **初始化**：正确找到 S、B、T 的位置
