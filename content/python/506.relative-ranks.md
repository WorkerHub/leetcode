## 题目描述

给你一个长度为 `n` 的整数数组 `score`，其中 `score[i]` 是第 `i` 位运动员在比赛中的得分。所有得分都互不相同。

运动员将根据得分决定名次，其中名次第 `1` 的运动员得分最高，名次第 `2` 的运动员得分第二高，依此类推。运动员的名次决定了他们的获奖情况：

- 名次第 `1` 的运动员获金牌 `"Gold Medal"`
- 名次第 `2` 的运动员获银牌 `"Silver Medal"`
- 名次第 `3` 的运动员获铜牌 `"Bronze Medal"`
- 从名次第 `4` 到第 `n` 的运动员，只能获得他们的名次编号（即，名次第 `x` 的运动员获得编号 `"x"`）

使用长度为 `n` 的数组 `answer` 返回获奖情况，其中 `answer[i]` 是第 `i` 位运动员的获奖情况。

**示例 1：**
```
输入：score = [5,4,3,2,1]
输出：["Gold Medal","Silver Medal","Bronze Medal","4","5"]
解释：名次为 [1st, 2nd, 3rd, 4th, 5th]。
```

**示例 2：**
```
输入：score = [10,3,8,9,4]
输出：["Gold Medal","5","Bronze Medal","Silver Medal","4"]
解释：名次为 [1st, 5th, 3rd, 2nd, 4th]。
```

**提示：**
- `n == score.length`
- `1 <= n <= 10^4`
- `0 <= score[i] <= 10^6`
- `score` 中的所有值互不相同

## 解题思路

这道题的核心是**排序 + 映射**。需要根据分数排名，然后将排名映射回原始索引位置。

### 核心思想：
1. 对分数排序，得到排名
2. 建立分数到排名的映射
3. 遍历原数组，根据分数查找对应的奖牌/排名

### 算法流程：
1. 对分数降序排序，得到排名顺序
2. 创建分数到名次的哈希表
3. 前三名映射为奖牌，其余为数字排名
4. 遍历原数组，根据分数查表得到结果

## Python 代码实现

### 方法一：排序 + 哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def findRelativeRanks(self, score: List[int]) -> List[str]:
        """
        排序 + 哈希表映射
        时间复杂度：O(n log n)，空间复杂度：O(n)
        """
        n = len(score)
        
        # 对分数降序排序
        sorted_scores = sorted(score, reverse=True)
        
        # 建立分数到名次的映射
        rank_map = {}
        medals = ["Gold Medal", "Silver Medal", "Bronze Medal"]
        
        for i, s in enumerate(sorted_scores):
            if i < 3:
                rank_map[s] = medals[i]
            else:
                rank_map[s] = str(i + 1)
        
        # 根据原数组的分数查找对应的名次
        return [rank_map[s] for s in score]
```

### 方法二：索引排序（更优雅）

```python
class Solution:
    def findRelativeRanks(self, score: List[int]) -> List[str]:
        """
        对索引进行排序，避免建立哈希表
        时间复杂度：O(n log n)，空间复杂度：O(n)
        """
        n = len(score)
        
        # 创建索引数组，按分数降序排序
        indices = sorted(range(n), key=lambda i: score[i], reverse=True)
        
        # 准备结果数组
        result = [""] * n
        medals = ["Gold Medal", "Silver Medal", "Bronze Medal"]
        
        # 根据排序后的索引顺序分配名次
        for rank, idx in enumerate(indices):
            if rank < 3:
                result[idx] = medals[rank]
            else:
                result[idx] = str(rank + 1)
        
        return result
```

### 方法三：使用元组排序

```python
class Solution:
    def findRelativeRanks(self, score: List[int]) -> List[str]:
        """
        使用 (分数, 索引) 元组排序
        时间复杂度：O(n log n)，空间复杂度：O(n)
        """
        n = len(score)
        
        # 创建 (分数, 原始索引) 元组列表
        score_with_index = [(s, i) for i, s in enumerate(score)]
        
        # 按分数降序排序
        score_with_index.sort(reverse=True)
        
        # 准备结果
        result = [""] * n
        medals = ["Gold Medal", "Silver Medal", "Bronze Medal"]
        
        for rank, (s, idx) in enumerate(score_with_index):
            if rank < 3:
                result[idx] = medals[rank]
            else:
                result[idx] = str(rank + 1)
        
        return result
```

### 方法四：一行流（Python 特色）

```python
class Solution:
    def findRelativeRanks(self, score: List[int]) -> List[str]:
        """
        利用字典推导式和排序的组合
        简洁但可读性稍差
        """
        sorted_scores = sorted(score, reverse=True)
        rank_map = {s: (["Gold Medal", "Silver Medal", "Bronze Medal"] + 
                        [str(i) for i in range(4, len(score) + 1)])[i] 
                    for i, s in enumerate(sorted_scores)}
        return [rank_map[s] for s in score]
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(n log n)
  - 排序：O(n log n)
  - 建立映射和查询：O(n)
- **空间复杂度**：O(n)
  - 排序后的数组或索引数组：O(n)
  - 哈希表或结果数组：O(n)

## 关键点总结

1. **排序策略**：降序排序，分数最高的排第一
2. **映射关系**：分数 → 排名，或索引 → 排名
3. **前三名特殊处理**：使用奖牌名称而非数字
4. **保持原顺序**：结果数组要与输入数组索引对应
5. **索引排序技巧**：排序索引而非值，直接得到结果位置

## 易错点

1. **排序方向**：应该是降序（reverse=True），不是升序
2. **排名从 1 开始**：第 4 名是 "4"，不是 "3"
3. **字符串类型**：数字排名要转为字符串
4. **索引对应**：result[i] 对应 score[i] 的名次，不要搞混
5. **边界情况**：n < 3 时，可能没有铜牌
