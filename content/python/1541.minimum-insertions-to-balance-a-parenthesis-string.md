## 题目描述

给你一个括号字符串 `s`，它只包含字符 `'('` 和 `')'`。

一个括号字符串被称为**平衡的**当它满足：
- 任何左括号 `'('` 必须对应**两个连续**的右括号 `'))'`
- 左括号 `'('` 必须在对应的右括号之前

每次操作，可以在字符串中**任意位置插入**一个括号字符。

返回使 `s` 平衡所需的最少插入次数。

**示例 1：**
```
输入：s = "(()))"
输出：1
解释：只需插入一个 ')' 变成 "(()))" -> "(())))"... 不对，应该插入 '(' 或 ')'
实际：s = "(()))" 已经是"(())" + ")"，插入一个 ')' 变成 "(()))" 还是不平衡，需要详细分析。
```

## 解题思路

### 贪心扫描

用变量 `open_cnt` 记录未匹配的左括号数，`ans` 记录插入次数。

**遍历字符串：**
- 遇到 `'('`：`open_cnt += 1`
- 遇到 `')'`：检查后面是否还有 `')'`
  - 如果后面有 `')'`（即连续两个右括号），消耗一个 `open_cnt`，若 `open_cnt == 0` 则需插入一个 `'('`
  - 如果后面没有 `')'`（单个右括号），消耗一个 `open_cnt` 并插入一个 `')'`，若 `open_cnt == 0` 则需插入 `'()'`

## 代码实现

### 方法一：贪心遍历（推荐）

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        ans = 0          # 需要插入的字符数
        open_cnt = 0     # 未匹配的 '(' 数量
        i = 0
        n = len(s)

        while i < n:
            if s[i] == '(':
                open_cnt += 1
                i += 1
            else:
                # 遇到右括号，需要两个连续 '))'
                if i + 1 < n and s[i + 1] == ')':
                    # 有两个连续右括号，匹配一个 '('
                    i += 2
                else:
                    # 只有一个右括号，需要插入一个 ')'
                    ans += 1
                    i += 1
                # 消耗一个 '('
                if open_cnt > 0:
                    open_cnt -= 1
                else:
                    # 没有 '(' 可以匹配，需要插入一个 '('
                    ans += 1

        # 剩余未匹配的 '('，每个需要插入两个 ')'
        ans += open_cnt * 2
        return ans
```

### 方法二：逐字符处理（更清晰）

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        ans = 0
        need_right = 0  # 还需要多少个 ')' 才能平衡

        for c in s:
            if c == '(':
                # 需要两个右括号
                need_right += 2
                # 如果 need_right 是奇数（前面有落单的')'），需要先补一个 ')'
                if need_right % 2 == 1:
                    ans += 1
                    need_right -= 1
            else:
                # 消耗一个右括号
                need_right -= 1
                if need_right < 0:
                    # 多余的右括号，需要插入一个 '('
                    ans += 1
                    need_right = 1  # 重置：刚插入的 '(' 还需要一个 ')'

        return ans + need_right
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. 每个 `(` 对应两个 `))`（而不是标准的一个 `)`）
2. 遇到单个 `)`（后面不是 `)`）时需要插入一个 `)`
3. 遍历结束后，剩余的未匹配 `(` 每个需要插入两个 `)`

## 易错点

- 标准括号题是 1:1，本题是 1:2（一个左对应两个右）
- 遇到 `')'` 时要贪心地消耗两个右括号（如果可以）
