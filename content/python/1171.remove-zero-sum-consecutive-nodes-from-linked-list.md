## 题目描述

给定链表头节点 `head`，重复删除所有和为 `0` 的连续节点序列，直到不存在这样的序列。

返回最终链表的头节点。

示例 1：

```
输入：head = [1,2,-3,3,1]
输出：[3,1]
解释：可以有多种答案，[1,2,1] 也是正确的
```

示例 2：

```
输入：head = [1,2,3,-3,4]
输出：[1,2,4]
```

示例 3：

```
输入：head = [1,2,3,-3,-2]
输出：[1]
```

## 解题思路

**核心思想：** 使用前缀和 + 哈希表

如果两个位置的前缀和相同，说明中间节点的和为 0。

## Python 代码实现

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeZeroSumSublists(self, head: ListNode) -> ListNode:
        """
        前缀和 + 哈希表
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        dummy = ListNode(0)
        dummy.next = head
        
        prefix_sum = 0
        prefix_map = {0: dummy}
        
        # 第一次遍历：记录前缀和
        node = dummy.next
        while node:
            prefix_sum += node.val
            prefix_map[prefix_sum] = node
            node = node.next
        
        # 第二次遍历：删除和为 0 的节点
        prefix_sum = 0
        node = dummy
        while node:
            prefix_sum += node.val
            node.next = prefix_map[prefix_sum].next
            node = node.next
        
        return dummy.next
```

## 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 关键点总结

1. 前缀和相同表示中间和为 0
2. 两次遍历：第一次记录，第二次删除
3. 使用 dummy 节点简化边界处理
