## 题目描述

一款游戏的每一轮时长恰好是 **15 分钟**。游戏开始时间为 `00:00`，轮次开始时间为 `00:00`、`00:15`、`00:30`、`00:45`、`01:00`……

给你两个字符串 `loginTime` 和 `logoutTime`，格式均为 `"HH:MM"`，分别表示某玩家的**登录时间**和**登出时间**。

请你返回玩家完整参与的**完整轮次数**（即登录时间 ≤ 轮次开始时间 且 轮次结束时间 ≤ 登出时间）。

**注意：** 如果 `logoutTime` 早于 `loginTime`，则表示跨越了午夜（第二天）。

**示例 1：**
```
输入：loginTime = "09:31", logoutTime = "10:14"
输出：1
解释：玩家只能完整参与 09:45 到 10:00 这一轮
```

**示例 2：**
```
输入：loginTime = "21:30", logoutTime = "03:00"
输出：22
解释：跨越午夜，从 21:30 到次日 03:00 共 22 轮
```

**提示：**
- `loginTime` 和 `logoutTime` 格式为 `"HH:MM"`
- `00 <= HH <= 23`
- `00 <= MM <= 59`

---

## 解题思路

### 核心思想：时间转分钟 + 处理跨午夜

1. 将时间字符串转换为分钟数（0 到 1439）
2. 如果 `logout < login`，说明跨越了午夜，令 `logout += 24 * 60`
3. 计算登录后第一个完整轮次开始时间：`ceil(login / 15) * 15`
4. 计算登出前最后一个完整轮次结束时间：`floor(logout / 15) * 15`
5. 完整轮次数 = `max(0, (end - start) / 15)`

---

## 代码实现

### 方法一：时间转分钟计算（推荐）

```python
class Solution:
    def numberOfRounds(self, loginTime: str, logoutTime: str) -> int:
        def to_minutes(t: str) -> int:
            # 将 "HH:MM" 转换为分钟数
            h, m = map(int, t.split(':'))
            return h * 60 + m

        login = to_minutes(loginTime)
        logout = to_minutes(logoutTime)

        # 处理跨午夜的情况
        if login > logout:
            logout += 24 * 60  # 加上一天的分钟数

        # 登录后第一个可参与轮次的开始时间（向上取整到15的倍数）
        first_round_start = (login + 14) // 15 * 15
        # 登出前最后一个完整轮次的结束时间（向下取整到15的倍数）
        last_round_end = logout // 15 * 15

        # 完整轮次数
        return max(0, (last_round_end - first_round_start) // 15)
```

### 方法二：使用 math 模块

```python
import math

class Solution:
    def numberOfRounds(self, loginTime: str, logoutTime: str) -> int:
        def to_minutes(t: str) -> int:
            h, m = map(int, t.split(':'))
            return h * 60 + m

        login = to_minutes(loginTime)
        logout = to_minutes(logoutTime)

        # 跨午夜处理
        if login > logout:
            logout += 1440  # 24 * 60 = 1440

        # 第一个满足条件的轮次开始（向上取整）
        start = math.ceil(login / 15) * 15
        # 最后一个满足条件的轮次结束（向下取整）
        end = math.floor(logout / 15) * 15

        return max(0, (end - start) // 15)
```

## 关键点总结

1. 时间统一转换为分钟数便于计算
2. 跨午夜时只需将 logout 加 1440 分钟（一天）
3. 登录时间向上取整到 15 的倍数，登出时间向下取整
4. `(login + 14) // 15 * 15` 等价于向上取整到最近 15 的倍数

---

## 易错点

- 当玩家登录和登出时间之间不足 15 分钟时，答案为 0，不要忘记 `max(0, ...)`
- 跨午夜判断：`logout < login` 时才加 1440，不要每次都加
- `(login + 14) // 15` 是向上取整的整数运算技巧
