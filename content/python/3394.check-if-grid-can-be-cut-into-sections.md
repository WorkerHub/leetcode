## 题目描述

给你一个整数 `n`，表示 `n x n` 的网格，以及一个二维数组 `rectangles`，其中 `rectangles[i] = [startx, starty, endx, endy]` 表示一个矩形区域。

判断能否用两条**水平**或两条**垂直**切割线将网格切成三列或三行，使得每一列（或行）中恰好包含一个矩形，且每个矩形完整地落在某一列（或行）中。

**提示：**
- `3 <= n <= 10^9`
- `3 <= rectangles.length <= 10^5`
- 矩形区域不重叠

## 解题思路

**区间合并：判断两个分割点是否存在**

将每个矩形在 x 轴的投影 `[startx, endx]` 看作区间，检查这些区间是否能被合并成恰好 3 个不相交的区间组（即存在两个"间隙"可以切割）。

同样对 y 轴的投影 `[starty, endy]` 做相同检查。

**具体方法：**
1. 对 x 轴投影（`[startx, endx]`）按左端点排序，合并重叠区间，统计合并后区间数量。若 >= 3，则存在两个垂直切割线。
2. 对 y 轴投影同理。
3. 若任一方向满足，返回 True。

## Python 代码实现

### 方法一：区间合并（推荐）

```python
from typing import List

class Solution:
    def checkValidCuts(self, n: int, rectangles: List[List[int]]) -> bool:
        
        def can_split(intervals):
            """判断区间是否可以合并后得到 >= 3 个不重叠区间"""
            intervals.sort()
            groups = 0
            max_end = 0
            
            for start, end in intervals:
                if start >= max_end:
                    # 新的不重叠区间组
                    groups += 1
                    if groups >= 3:
                        return True
                max_end = max(max_end, end)
            
            return groups >= 3
        
        # 提取 x 投影 [startx, endx]
        x_intervals = [(r[0], r[2]) for r in rectangles]
        # 提取 y 投影 [starty, endy]
        y_intervals = [(r[1], r[3]) for r in rectangles]
        
        return can_split(x_intervals) or can_split(y_intervals)
```

### 方法二：显式合并区间

```python
from typing import List

class Solution:
    def checkValidCuts(self, n: int, rectangles: List[List[int]]) -> bool:
        
        def merge_and_count(intervals):
            """合并区间后统计区间数量"""
            intervals.sort()
            merged = []
            for start, end in intervals:
                if merged and start < merged[-1][1]:
                    # 与上一区间重叠，扩展右端点
                    merged[-1] = (merged[-1][0], max(merged[-1][1], end))
                else:
                    merged.append((start, end))
            return len(merged)
        
        x_intervals = [(r[0], r[2]) for r in rectangles]
        y_intervals = [(r[1], r[3]) for r in rectangles]
        
        return merge_and_count(x_intervals) >= 3 or merge_and_count(y_intervals) >= 3
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导（n 为矩形数量）
- 空间复杂度：O(n)，存储区间列表

## 关键点总结

1. 问题转化为：矩形在某一轴的投影是否能合并成 3 个或更多不重叠区间。
2. 合并区间后，区间数 >= 3 意味着存在至少 2 个分割点。
3. 对 x 轴和 y 轴分别检查，任一满足即可。

## 易错点

1. 区间合并时注意使用 `start >= max_end` 而不是 `>`（区间允许端点相连，即 `[0,2]` 和 `[2,4]` 是相邻但不重叠的）。
2. 矩形坐标 `[startx, starty, endx, endy]`，注意索引对应关系。
3. 题目要恰好 3 段（每段含一个矩形），所以需要区间数 >= 3，不是恰好 3。
