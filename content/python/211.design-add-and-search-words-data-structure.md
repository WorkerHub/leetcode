## 题目描述

请你设计一个数据结构，支持 添加新单词 和 查找字符串是否与任何先前添加的字符串匹配。

实现词典类 `WordDictionary`：

- `WordDictionary()` 初始化词典对象
- `void addWord(word)` 将 `word` 添加到数据结构中，之后可以对它进行匹配
- `bool search(word)` 如果数据结构中存在字符串与 `word` 匹配，则返回 `true`；否则，返回 `false`。`word` 中可能包含一些 `'.'`，每个 `.` 都可以表示任何一个字母。

**示例 1：**

```
输入：
["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
输出：
[null,null,null,null,false,true,true,true]

解释：
WordDictionary wordDictionary = new WordDictionary();
wordDictionary.addWord("bad");
wordDictionary.addWord("dad");
wordDictionary.addWord("mad");
wordDictionary.search("pad"); // 返回 False
wordDictionary.search("bad"); // 返回 True
wordDictionary.search(".ad"); // 返回 True
wordDictionary.search("b.."); // 返回 True
```

**提示：**

- `1 <= word.length <= 25`
- `addWord` 中的 `word` 由小写英文字母组成
- `search` 中的 `word` 由 `'.'` 或小写英文字母组成
- 最多调用 `10^4` 次 `addWord` 和 `search`

## 解题思路

这道题是经典的字典树（Trie）应用题，核心挑战在于如何处理通配符 `.`。

**核心思想：**

1. **字典树结构**：使用 Trie 存储所有添加的单词，每个节点包含：
   - 一个字典（children）存储子节点
   - 一个布尔值（is_end）标记是否是单词结尾

2. **添加单词**：按字符逐层插入 Trie

3. **搜索单词**：
   - 遇到普通字符：直接在对应子节点查找
   - 遇到通配符 `.`：需要尝试所有可能的子节点（DFS）

**算法流程：**

1. 添加单词时，从根节点开始，逐字符创建/访问节点
2. 搜索时，使用 DFS 递归：
   - 如果当前字符是 `.`，遍历所有子节点递归搜索
   - 如果是普通字符，只在对应子节点继续搜索
   - 到达字符串末尾时，检查当前节点是否为单词结尾

## Python 代码实现

### 方法一：字典树 + DFS（推荐）⭐

```python
class TrieNode:
    def __init__(self):
        self.children = {}  # 存储子节点
        self.is_end = False  # 标记是否为单词结尾

class WordDictionary:
    def __init__(self):
        self.root = TrieNode()

    def addWord(self, word: str) -> None:
        """添加单词到字典树"""
        node = self.root
        for char in word:
            # 如果字符不存在，创建新节点
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True  # 标记单词结束

    def search(self, word: str) -> bool:
        """搜索单词，支持通配符 '.'"""
        return self._dfs_search(word, 0, self.root)
    
    def _dfs_search(self, word: str, index: int, node: TrieNode) -> bool:
        """DFS 递归搜索"""
        # 已经遍历完整个单词
        if index == len(word):
            return node.is_end
        
        char = word[index]
        
        if char == '.':
            # 通配符：尝试所有子节点
            for child in node.children.values():
                if self._dfs_search(word, index + 1, child):
                    return True
            return False
        else:
            # 普通字符：直接查找对应子节点
            if char not in node.children:
                return False
            return self._dfs_search(word, index + 1, node.children[char])
```

### 方法二：字典树 + 迭代优化

```python
class WordDictionary:
    def __init__(self):
        self.root = {}

    def addWord(self, word: str) -> None:
        """使用嵌套字典实现 Trie"""
        node = self.root
        for char in word:
            node = node.setdefault(char, {})
        node['#'] = True  # '#' 标记单词结束

    def search(self, word: str) -> bool:
        """迭代搜索，使用队列处理通配符"""
        from collections import deque
        queue = deque([(self.root, 0)])  # (当前节点, 字符索引)
        
        while queue:
            node, i = queue.popleft()
            
            # 已遍历完整个单词
            if i == len(word):
                if '#' in node:
                    return True
                continue
            
            char = word[i]
            if char == '.':
                # 通配符：将所有子节点加入队列
                for key in node:
                    if key != '#':
                        queue.append((node[key], i + 1))
            else:
                # 普通字符：只加入对应子节点
                if char in node:
                    queue.append((node[char], i + 1))
        
        return False
```

### 方法三：简化版（适合初学者）

```python
class WordDictionary:
    def __init__(self):
        self.words = set()  # 存储所有单词
    
    def addWord(self, word: str) -> None:
        self.words.add(word)
    
    def search(self, word: str) -> bool:
        """暴力匹配，适合数据量小的情况"""
        if '.' not in word:
            return word in self.words
        
        # 正则表达式匹配
        import re
        pattern = word.replace('.', '[a-z]')
        for w in self.words:
            if len(w) == len(word) and re.fullmatch(pattern, w):
                return True
        return False
```

## 复杂度分析

**方法一（字典树 + DFS）：**

- **时间复杂度：**
  - `addWord`：O(L)，L 为单词长度
  - `search`：
    - 最坏情况（全是通配符）：O(26^L)
    - 平均情况：O(L)
- **空间复杂度：** O(N × L)，N 为单词数量

**方法二（迭代）：**

- **时间复杂度：** 与方法一相同
- **空间复杂度：** O(N × L + K)，K 为队列大小

**方法三（暴力）：**

- **时间复杂度：** 
  - `addWord`：O(1)
  - `search`：O(N × L)
- **空间复杂度：** O(N × L)

## 关键点总结

1. **字典树是处理字符串前缀的高效数据结构**，适合词典类问题
2. **通配符处理需要 DFS**，遍历所有可能的分支
3. **节点设计**：使用字典存储子节点，布尔值标记单词结尾
4. **递归思路**：每次处理一个字符，剩余字符递归处理
5. **性能优化**：字典树避免了重复存储公共前缀

## 易错点

1. **忘记标记单词结尾**：只添加节点不标记 `is_end`，导致前缀被当作完整单词
   ```python
   # 错误示例
   node = node.children[char]  # 忘记设置 is_end
   ```

2. **通配符处理不完整**：只检查第一个匹配的子节点，应该检查所有
   ```python
   # 错误：遇到第一个匹配就返回
   for child in node.children.values():
       return self._dfs_search(word, index + 1, child)
   # 正确：必须遍历所有可能
   for child in node.children.values():
       if self._dfs_search(word, index + 1, child):
           return True
   ```

3. **索引越界**：递归前未检查 `index` 是否超出范围

4. **空字符串处理**：题目保证 `word.length >= 1`，但自测时需注意
