## 题目描述

一个法师有 `n` 个法术，每个法术造成 `power[i]` 点伤害。

如果你使用一个伤害值为 `x` 的法术，则所有伤害值为 `x-2`、`x-1`、`x+1`、`x+2` 的法术都不能使用。

返回最大总伤害。

**示例：**
```
输入：power = [1,1,3,4]
输出：6
解释：使用伤害值为 1 的法术两次（总伤害 2），使用 4（总伤害 4），不能使用 3（因为 4-1=3）。总计 6。
```

**提示：**
- `1 <= power.length <= 10^5`
- `1 <= power[i] <= 10^9`

## 解题思路

统计每个伤害值出现的次数，设唯一值排序后为 `vals`，对应总伤害为 `sums`（值 * 出现次数）。

然后对 `vals` 做 DP：`dp[i]` = 只考虑前 i 个唯一值时的最大总伤害。

转移：选择使用 vals[i]，需要排除 vals[i]-1 和 vals[i]-2，用二分查找找到最大的可选前驱下标。

## Python 代码实现

### 方法一：DP + 二分（推荐）

```python
from typing import List
from collections import Counter
import bisect

class Solution:
    def maximumTotalDamage(self, power: List[int]) -> int:
        cnt = Counter(power)
        vals = sorted(cnt)
        n = len(vals)
        # sums[i] = vals[i] * cnt[vals[i]]
        sums = [vals[i] * cnt[vals[i]] for i in range(n)]

        # dp[i] = 考虑 vals[0..i] 的最大总伤害
        dp = [0] * n
        dp[0] = sums[0]

        for i in range(1, n):
            # 不使用 vals[i]
            dp[i] = dp[i - 1]
            # 使用 vals[i]，找最大的 j 使 vals[j] < vals[i] - 2
            target = vals[i] - 2
            j = bisect.bisect_left(vals, target) - 1  # 最大的 j 使 vals[j] <= target - 1
            # 更精确：vals[j] <= vals[i] - 3（排除 -2, -1）
            j = bisect.bisect_left(vals, vals[i] - 2) - 1
            prev = dp[j] if j >= 0 else 0
            dp[i] = max(dp[i], prev + sums[i])

        return dp[-1]
```

### 方法二：更简洁

```python
from typing import List
from collections import Counter
import bisect

class Solution:
    def maximumTotalDamage(self, power: List[int]) -> int:
        cnt = Counter(power)
        vals = sorted(cnt.keys())
        n = len(vals)

        dp = [0] * (n + 1)
        for i in range(n):
            v = vals[i]
            # 不选 v
            dp[i + 1] = dp[i]
            # 选 v，排除 v-1 和 v-2
            # 找最大的 j 使 vals[j] <= v - 3（即 vals[j] < v - 2）
            j = bisect.bisect_left(vals, v - 2)  # 第一个 >= v-2 的位置
            dp[i + 1] = max(dp[i + 1], dp[j] + v * cnt[v])

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 二分
- 空间复杂度：O(n)

## 关键点总结

1. 统计每个唯一伤害值的总伤害
2. 类似打家劫舍，但不是 ±1 而是 ±2 范围内的限制
3. 二分查找合法的前驱状态

## 易错点

1. 排除的是 x-1 和 x-2（以及 x+1, x+2），所以选 x 后，前一个可选值的上界是 x-3
2. 注意：bisect_left(vals, v-2) 找的是第一个 >= v-2 的位置
