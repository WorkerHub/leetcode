## 题目描述

与 3095 相同题意，但 `nums.length` 扩大到 `2 * 10^5`，`nums[i]` 扩大到 `10^9`，需要更高效算法。

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

滑动窗口 + 位计数数组：

由于按位或 OR 不可逆（加入元素后 OR 只增不减，移出元素后需要重新计算），使用**位计数数组**维护窗口内每一位的 1 的个数：
- `bit_count[b]`：窗口内第 `b` 位为 1 的元素个数
- 当前窗口的 OR = 所有 `bit_count[b] > 0` 的位的或值

移出元素时：更新 `bit_count`，若某位计数变为 0，则 OR 中该位变为 0。

## Python 代码实现

### 方法一：滑动窗口 + 位计数（推荐）

```python
from typing import List

class Solution:
    def minimumSubarrayLength(self, nums: List[int], k: int) -> int:
        if k == 0:
            return 1

        n = len(nums)
        ans = float('inf')
        bit_count = [0] * 30  # 0 <= nums[i] <= 10^9，最多 30 位
        cur_or = 0
        left = 0

        for right in range(n):
            # 加入 nums[right]
            for b in range(30):
                if nums[right] >> b & 1:
                    bit_count[b] += 1
                    if bit_count[b] == 1:  # 该位从 0 变为 1
                        cur_or |= (1 << b)

            # 收缩：当 OR >= k 时，尝试缩短窗口
            while cur_or >= k and left <= right:
                ans = min(ans, right - left + 1)
                # 移出 nums[left]
                for b in range(30):
                    if nums[left] >> b & 1:
                        bit_count[b] -= 1
                        if bit_count[b] == 0:  # 该位从 1 变为 0
                            cur_or &= ~(1 << b)
                left += 1

        return ans if ans != float('inf') else -1
```

### 方法二：每个左端点二分（O(n log^2 n)）

```python
from typing import List

class Solution:
    def minimumSubarrayLength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        if k == 0:
            return 1

        # 利用 OR 的单调性：固定左端点，右端点越大 OR 越大
        # 对每个左端点二分右端点（但 OR 计算需要 O(n)，整体 O(n^2 log n)）
        # 实际上滑动窗口是最优的

        # 直接使用滑动窗口（同方法一）
        bit_count = [0] * 30
        cur_or = 0
        left = 0
        ans = float('inf')

        for right in range(n):
            for b in range(30):
                if (nums[right] >> b) & 1:
                    bit_count[b] += 1
                    cur_or |= (1 << b)

            while cur_or >= k:
                ans = min(ans, right - left + 1)
                for b in range(30):
                    if (nums[left] >> b) & 1:
                        bit_count[b] -= 1
                        if bit_count[b] == 0:
                            cur_or ^= (1 << b)
                left += 1

        return -1 if ans == float('inf') else ans
```

## 复杂度分析

- 时间复杂度：O(n * 30) = O(n)
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. 按位或 OR 不可逆，需要位计数数组辅助
2. 滑动窗口：当 OR >= k 时收缩左边界
3. 位计数数组：每位的 1 的个数，降为 0 时清除 OR 对应位

## 易错点

1. 移出元素时用 `cur_or ^= (1 << b)` 而非 `cur_or &= ~(1 << b)`（效果相同，但注意使用 `^=` 时需确保该位原本为 1）
2. 使用 `&= ~(1 << b)` 更安全（不依赖原值）
3. k = 0 的特殊情况（任意非空子数组满足）
