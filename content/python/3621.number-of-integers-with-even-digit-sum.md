## 题目描述

给你一个正整数 `num`，请返回 `[1, num]` 中各位数字之和为偶数的整数数量。

**示例 1：**

```
输入：num = 4
输出：2
解释：1(1), 2(2偶), 3(3), 4(4偶)，满足的是2和4，共2个
```

**示例 2：**

```
输入：num = 30
输出：14
```

**提示：**

- `1 <= num <= 1000`

## 解题思路

直接枚举 `[1, num]` 中每个整数，计算其各位数字之和是否为偶数。

数字和的奇偶性有规律：在连续正整数中，奇数和偶数交替出现（位数不变时），因此约一半满足条件。但进位（如 9→10）会打破规律，直接枚举更简单。

## Python 代码实现

### 方法一：直接枚举（推荐）

```python
class Solution:
    def countEven(self, num: int) -> int:
        count = 0
        for i in range(1, num + 1):
            # 计算各位数字之和
            if sum(int(d) for d in str(i)) % 2 == 0:
                count += 1
        return count
```

### 方法二：数学规律

```python
class Solution:
    def countEven(self, num: int) -> int:
        # num 的各位之和
        digit_sum = sum(int(d) for d in str(num))
        # 若 num 的各位之和为偶数，则 [1, num] 中有 num // 2 个偶数位和数
        # 若为奇数，有 (num - 1) // 2 个
        if digit_sum % 2 == 0:
            return num // 2
        else:
            return (num - 1) // 2
```

## 复杂度分析

- 时间复杂度：O(n log n)（方法一），O(log n)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 各位之和的奇偶性：`sum(digits) % 2`
2. 数学规律：`num` 内偶数字和数约为 `num // 2`
3. 精确计算需考虑 `num` 本身的数字和奇偶性

## 易错点

1. 方法二的规律推导：`num` 字和为偶则 `num//2`，否则 `(num-1)//2`
2. 注意从 1 开始计数（不包含 0）
