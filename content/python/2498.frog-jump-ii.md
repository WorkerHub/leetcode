## 题目描述

给你一个下标从 **0** 开始的整数数组 `stones`（严格递增），代表河中石头的位置。

有一只青蛙从石头 0 出发，要到达最后一块石头，且能返回出发点。要求：
- 去程：从 stones[0] 跳到 stones[n-1]，每次只能**向前**跳
- 返程：从 stones[n-1] 返回 stones[0]，每次只能**向后**跳
- 每块石头**最多**可以踩一次（除起点和终点可以踩两次）

定义路径的代价 = 所有跳跃长度的最大值。

返回所有可行的往返路径中，**最小代价**。

**提示：**
- `2 <= stones.length <= 10^5`
- `0 <= stones[0] < stones[1] < ... < stones[n-1] <= 10^9`

## 解题思路

**贪心：**

等价于两条不重叠的从 stones[0] 到 stones[n-1] 的路径（除首尾可共享），最小化最大跳跃距离。

**关键观察：** 最优策略是让两条路径交替使用石头，即一条路径用奇数位置的石头，另一条用偶数位置的石头。

这样，答案 = 相邻石头间隔一跳的最大值，即 `max(stones[i] - stones[i-2])` 对所有 i >= 2。

更简单：答案 = `max(stones[i+1] - stones[i-1])` 对所有中间石头，即隔一个石头的最大差值。

等价于：`max(stones[i] - stones[i-2] for i in range(2, n))`。

## 代码实现

### 方法一：贪心（隔一跳最大值）

```python
from typing import List

class Solution:
    def maxJump(self, stones: List[int]) -> int:
        n = len(stones)
        ans = stones[1] - stones[0]  # 第一步，两条路径都从 stones[0] 出发

        # 交替使用石头，跳两格的最大距离
        for i in range(2, n):
            ans = max(ans, stones[i] - stones[i - 2])

        return ans
```

## 关键点总结

1. 两条路径交替使用石头是最优策略
2. 答案 = 相邻两条路径中跳跃的最大值
3. 等价于：`max(stones[i] - stones[i-2])`（每条路径隔一个石头跳一次）

## 易错点

- 首尾石头两条路径共享，答案中需要考虑 `stones[1] - stones[0]`
- 注意 n=2 时，直接返回 `stones[1] - stones[0]`
