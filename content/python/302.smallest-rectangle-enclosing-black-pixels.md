## 题目描述

给你一个由 `'0'` 和 `'1'` 组成的二维矩阵 `image`，其中 `'1'` 表示黑色像素，`'0'` 表示白色像素。

黑色像素是连通的，即只有一块黑色区域。像素是水平或竖直连接的。

给你黑色像素的位置 `(x, y)`，返回包含所有黑色像素的最小矩形的面积。

**示例 1：**
```
输入：image = [
  ["0","0","1","0"],
  ["0","1","1","0"],
  ["0","1","0","0"]
], x = 0, y = 2
输出：6
解释：最小矩形的左上角是 (0, 1)，右下角是 (2, 2)，面积为 6
```

**示例 2：**
```
输入：image = [["1"]], x = 0, y = 0
输出：1
```

**提示：**
- `m == image.length`
- `n == image[i].length`
- `1 <= m, n <= 100`
- `image[i][j]` 为 `'0'` 或 `'1'`
- `0 <= x < m`
- `0 <= y < n`
- `image[x][y] == '1'`
- `image` 中的黑色像素仅形成一个连通块

## 解题思路

题目要求找到包含所有黑色像素的最小矩形。有两种主要思路：

### 思路一：DFS/BFS 遍历所有黑色像素

从给定的黑色像素 `(x, y)` 出发，使用 DFS 或 BFS 遍历所有连通的黑色像素，记录最小和最大的行列坐标。

- 最小行：`min_row`
- 最大行：`max_row`
- 最小列：`min_col`
- 最大列：`max_col`

矩形面积 = `(max_row - min_row + 1) * (max_col - min_col + 1)`

### 思路二：二分查找边界（最优）⭐

利用题目的关键信息：**黑色像素是连通的**。这意味着：
- 在某一行，黑色像素一定是连续的
- 在某一列，黑色像素一定是连续的

我们可以使用二分查找找到矩形的四条边界：
1. **左边界**：最小的列，该列存在黑色像素
2. **右边界**：最大的列，该列存在黑色像素
3. **上边界**：最小的行，该行存在黑色像素
4. **下边界**：最大的行，该行存在黑色像素

## Python 代码实现

### 方法一：DFS 遍历

```python
from typing import List

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        if not image or not image[0]:
            return 0
        
        m, n = len(image), len(image[0])
        
        # 初始化边界
        min_row, max_row = x, x
        min_col, max_col = y, y
        
        visited = set()
        
        def dfs(i: int, j: int):
            nonlocal min_row, max_row, min_col, max_col
            
            # 边界检查
            if i < 0 or i >= m or j < 0 or j >= n:
                return
            if image[i][j] == '0' or (i, j) in visited:
                return
            
            # 标记访问
            visited.add((i, j))
            
            # 更新边界
            min_row = min(min_row, i)
            max_row = max(max_row, i)
            min_col = min(min_col, j)
            max_col = max(max_col, j)
            
            # 四个方向递归
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)
        
        dfs(x, y)
        
        # 计算面积
        return (max_row - min_row + 1) * (max_col - min_col + 1)
```

### 方法二：BFS 遍历

```python
from typing import List
from collections import deque

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        if not image or not image[0]:
            return 0
        
        m, n = len(image), len(image[0])
        
        # 初始化边界
        min_row, max_row = x, x
        min_col, max_col = y, y
        
        visited = {(x, y)}
        queue = deque([(x, y)])
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while queue:
            i, j = queue.popleft()
            
            # 更新边界
            min_row = min(min_row, i)
            max_row = max(max_row, i)
            min_col = min(min_col, j)
            max_col = max(max_col, j)
            
            # 四个方向扩展
            for di, dj in directions:
                ni, nj = i + di, j + dj
                
                if 0 <= ni < m and 0 <= nj < n and \
                   image[ni][nj] == '1' and (ni, nj) not in visited:
                    visited.add((ni, nj))
                    queue.append((ni, nj))
        
        # 计算面积
        return (max_row - min_row + 1) * (max_col - min_col + 1)
```

### 方法三：二分查找（最优）⭐⭐

```python
from typing import List

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        m, n = len(image), len(image[0])
        
        def has_black_in_col(col: int) -> bool:
            """检查某一列是否有黑色像素"""
            for i in range(m):
                if image[i][col] == '1':
                    return True
            return False
        
        def has_black_in_row(row: int) -> bool:
            """检查某一行是否有黑色像素"""
            for j in range(n):
                if image[row][j] == '1':
                    return True
            return False
        
        # 二分查找左边界（最小列）
        left, right = 0, y
        while left < right:
            mid = (left + right) // 2
            if has_black_in_col(mid):
                right = mid
            else:
                left = mid + 1
        min_col = left
        
        # 二分查找右边界（最大列）
        left, right = y, n - 1
        while left < right:
            mid = (left + right + 1) // 2
            if has_black_in_col(mid):
                left = mid
            else:
                right = mid - 1
        max_col = left
        
        # 二分查找上边界（最小行）
        left, right = 0, x
        while left < right:
            mid = (left + right) // 2
            if has_black_in_row(mid):
                right = mid
            else:
                left = mid + 1
        min_row = left
        
        # 二分查找下边界（最大行）
        left, right = x, m - 1
        while left < right:
            mid = (left + right + 1) // 2
            if has_black_in_row(mid):
                left = mid
            else:
                right = mid - 1
        max_row = left
        
        return (max_row - min_row + 1) * (max_col - min_col + 1)
```

### 方法四：二分查找优化版

```python
from typing import List

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        m, n = len(image), len(image[0])
        
        def search_rows(top: int, bottom: int, find_min: bool) -> int:
            """在 [top, bottom] 范围内二分查找行边界"""
            while top < bottom:
                mid = (top + bottom) // 2 if find_min else (top + bottom + 1) // 2
                # 检查第 mid 行是否有黑色像素
                has_black = any(image[mid][j] == '1' for j in range(n))
                
                if has_black == find_min:
                    bottom = mid
                else:
                    top = mid + 1 if find_min else mid - 1
            
            return top if find_min else bottom
        
        def search_cols(left: int, right: int, find_min: bool) -> int:
            """在 [left, right] 范围内二分查找列边界"""
            while left < right:
                mid = (left + right) // 2 if find_min else (left + right + 1) // 2
                # 检查第 mid 列是否有黑色像素
                has_black = any(image[i][mid] == '1' for i in range(m))
                
                if has_black == find_min:
                    right = mid
                else:
                    left = mid + 1 if find_min else mid - 1
            
            return left if find_min else right
        
        # 找四条边界
        min_row = search_rows(0, x, True)
        max_row = search_rows(x, m - 1, False)
        min_col = search_cols(0, y, True)
        max_col = search_cols(y, n - 1, False)
        
        return (max_row - min_row + 1) * (max_col - min_col + 1)
```

## 复杂度分析

**方法一、二（DFS/BFS）：**
- 时间复杂度：O(m × n)，最坏情况下遍历所有像素
- 空间复杂度：O(m × n)，visited 集合或递归栈

**方法三、四（二分查找）：**
- 时间复杂度：O(m log n + n log m)
  - 查找左右边界：O(m × log n)
  - 查找上下边界：O(n × log m)
- 空间复杂度：O(1)

## 关键点总结

1. **利用连通性**：黑色像素是连通的，可以用 DFS/BFS 遍历所有像素
2. **二分查找优化**：连通性保证了行列的连续性，可以用二分查找边界
3. **二分查找技巧**：
   - 找最小值：`mid = (left + right) // 2`
   - 找最大值：`mid = (left + right + 1) // 2`
4. **边界更新**：注意二分查找时的边界更新逻辑
5. **面积计算**：`(max_row - min_row + 1) * (max_col - min_col + 1)`

## 易错点

1. **二分查找边界错误**：找最小值和最大值的逻辑不同
2. **面积计算错误**：忘记 +1（索引从 0 开始）
3. **DFS 栈溢出**：大数据量时递归深度过大
4. **边界检查遗漏**：数组越界
