## 题目描述

给你一个 `events` 数组，其中 `events[i] = [startDay_i, endDay_i, value_i]`，表示第 `i` 个活动在 `startDay_i` 到 `endDay_i` 举行，价值为 `value_i`。

同时给你整数 `k`，表示你能参加的最多活动数目。

你同一时间只能参加一个活动。如果你选择参加某个活动，那么你**必须完整地**参加此活动。活动结束日期是**包含的**，也就是说，你不能同时参加在 `[1,2]` 和 `[2,3]` 举办的两个活动。

请你返回能得到的**最大价值**。

**示例 1：**
```
输入：events = [[1,2,4],[3,4,3],[2,3,1]], k = 2
输出：7
```

**提示：**
- `1 <= k <= events.length`
- `1 <= k * events.length <= 10^6`

## 解题思路

**动态规划 + 二分查找**：

将 `events` 按开始日期排序，定义：
`dp[i][j]` = 前 `j` 个活动中，最多参加 `i` 个活动的最大价值

排序后，对第 `j` 个活动，可以选择：
1. 不参加：`dp[i][j] = dp[i][j-1]`
2. 参加：找到最后一个结束日期 < 当前活动开始日期的活动（二分），`dp[i][j] = dp[i-1][p] + value_j`

## 代码实现

### 方法一：DP + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxValue(self, events: List[List[int]], k: int) -> int:
        # 按结束日期排序
        events.sort(key=lambda x: x[1])
        n = len(events)
        
        # 提取结束日期，用于二分查找
        end_days = [e[1] for e in events]
        
        # dp[j][i] = 前 i 个活动（排序后），参加至多 j 个的最大价值
        # 用滚动数组优化
        prev = [0] * (n + 1)  # 上一轮的 dp
        
        for j in range(1, k + 1):
            curr = [0] * (n + 1)
            for i in range(1, n + 1):
                start, end, val = events[i - 1]
                
                # 不参加第 i 个活动
                curr[i] = curr[i - 1]
                
                # 参加第 i 个活动：找最后一个结束日期 < start 的活动
                # 在 end_days[0..i-2] 中找 < start 的最大索引（1-indexed，所以找 < start-1 的）
                p = bisect.bisect_left(end_days, start, 0, i - 1)
                # p 是第一个 >= start 的位置，所以 p-1 是最后一个 < start 的
                curr[i] = max(curr[i], prev[p] + val)
            
            prev = curr
        
        return prev[n]
```

### 方法二：记忆化搜索

```python
from typing import List
import bisect
from functools import lru_cache

class Solution:
    def maxValue(self, events: List[List[int]], k: int) -> int:
        events.sort()  # 按开始日期排序
        n = len(events)
        starts = [e[0] for e in events]
        
        @lru_cache(maxsize=None)
        def dp(idx, rem):
            """从 idx 开始，还能参加 rem 个活动的最大价值"""
            if idx >= n or rem == 0:
                return 0
            
            # 不参加当前活动
            res = dp(idx + 1, rem)
            
            # 参加当前活动
            end = events[idx][1]
            val = events[idx][2]
            # 找第一个开始时间 > end 的活动
            next_idx = bisect.bisect_right(starts, end, idx + 1)
            res = max(res, val + dp(next_idx, rem - 1))
            
            return res
        
        return dp(0, k)
```

## 复杂度分析

- **时间复杂度**：O(n * k * log n)，二分 O(log n)
- **空间复杂度**：O(n * k)

## 关键点总结

1. 排序后用 DP + 二分查找找不重叠的最优前缀
2. 类似于加权区间调度问题

## 易错点

- 活动结束日期包含在内，所以下一个活动的开始日期必须 > 当前结束日期
- 二分查找的边界
