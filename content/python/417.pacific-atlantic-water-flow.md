## 题目描述

有一个 m × n 的矩形岛屿，与太平洋和大西洋相邻。太平洋处于岛屿的左边界和上边界，而大西洋处于岛屿的右边界和下边界。

岛屿被分割成一个个方格网格。给定一个 m x n 的整数矩阵 heights，heights[r][c] 表示坐标 (r, c) 上单元格高于海平面的高度。

岛屿的雨水较多，水可以向相邻单元格流动，前提是相邻单元格的高度小于或等于当前单元格的高度。

请找出那些水流既可以流动到太平洋，也可以流动到大西洋的陆地单元的坐标。

**示例 1：**
```
输入：heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
输出：[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

## 解题思路

逆向思维：从海洋出发，找能到达的陆地。

核心思路：
1. 从太平洋边界开始 DFS/BFS，标记能到达的格子
2. 从大西洋边界开始 DFS/BFS，标记能到达的格子
3. 同时被两个海洋标记的格子就是答案

## Python 代码实现

### 方法一：DFS（推荐）

```python
from typing import List

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        """
        从两个海洋边界出发进行 DFS
        """
        if not heights or not heights[0]:
            return []
        
        m, n = len(heights), len(heights[0])
        
        # 标记能到达的格子
        pacific = [[False] * n for _ in range(m)]
        atlantic = [[False] * n for _ in range(m)]
        
        def dfs(r: int, c: int, visited: List[List[bool]]):
            """从 (r, c) 开始 DFS"""
            visited[r][c] = True
            
            for dr, dc in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                nr, nc = r + dr, c + dc
                # 边界检查，未访问，且高度不降
                if (0 <= nr < m and 0 <= nc < n and 
                    not visited[nr][nc] and 
                    heights[nr][nc] >= heights[r][c]):
                    dfs(nr, nc, visited)
        
        # 从太平洋边界（上边和左边）开始
        for i in range(m):
            dfs(i, 0, pacific)
        for j in range(n):
            dfs(0, j, pacific)
        
        # 从大西洋边界（下边和右边）开始
        for i in range(m):
            dfs(i, n - 1, atlantic)
        for j in range(n):
            dfs(m - 1, j, atlantic)
        
        # 找出同时能到达两个海洋的格子
        result = []
        for i in range(m):
            for j in range(n):
                if pacific[i][j] and atlantic[i][j]:
                    result.append([i, j])
        
        return result
```

### 方法二：BFS

```python
from typing import List
from collections import deque

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        """
        使用 BFS
        """
        if not heights or not heights[0]:
            return []
        
        m, n = len(heights), len(heights[0])
        pacific = [[False] * n for _ in range(m)]
        atlantic = [[False] * n for _ in range(m)]
        
        def bfs(queue: deque, visited: List[List[bool]]):
            """BFS 遍历"""
            while queue:
                r, c = queue.popleft()
                visited[r][c] = True
                
                for dr, dc in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                    nr, nc = r + dr, c + dc
                    if (0 <= nr < m and 0 <= nc < n and 
                        not visited[nr][nc] and 
                        heights[nr][nc] >= heights[r][c]):
                        queue.append((nr, nc))
                        visited[nr][nc] = True
        
        # 初始化队列
        pacific_queue = deque()
        atlantic_queue = deque()
        
        for i in range(m):
            pacific_queue.append((i, 0))
            atlantic_queue.append((i, n - 1))
        
        for j in range(n):
            pacific_queue.append((0, j))
            atlantic_queue.append((m - 1, j))
        
        bfs(pacific_queue, pacific)
        bfs(atlantic_queue, atlantic)
        
        result = []
        for i in range(m):
            for j in range(n):
                if pacific[i][j] and atlantic[i][j]:
                    result.append([i, j])
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. 逆向思维：从海洋到陆地
2. 两次 DFS/BFS 分别标记
3. 找交集

## 易错点

1. 水流方向理解错误（应该是高度不降）
2. 忘记处理边界重叠的情况
