## 题目描述

如果字符串满足以下条件之一，则可以称之为**有效括号字符串（VPS）**：
- 空字符串
- 由单个字符 `c`（其中 `c != '('` 且 `c != ')'`）组成的字符串
- 字符串 `AB`（`A` 与 `B` 连接），其中 `A` 和 `B` 都是 VPS
- 字符串 `(A)`，其中 `A` 是 VPS

给你一个 VPS 字符串 `s`，返回该字符串的**嵌套深度**。

**示例：**
```
输入：s = "(1+(2*3)+((8)/4))+1"
输出：3
解释：数字 8 被 3 层括号包围
```

**提示：**
- `1 <= s.length <= 100`
- `s` 由数字 `0-9`、运算符 `+`、`-`、`*`、`/`、左括号 `(`、右括号 `)` 组成
- 保证 `s` 是有效括号字符串

## 解题思路

遍历字符串，用一个计数器记录当前嵌套深度：
- 遇到 `(` 深度加 1，更新最大深度
- 遇到 `)` 深度减 1
- 其他字符忽略

## 代码实现

### 方法一：计数器（推荐）

```python
class Solution:
    def maxDepth(self, s: str) -> int:
        depth = 0    # 当前嵌套深度
        max_depth = 0  # 最大嵌套深度
        
        for c in s:
            if c == '(':
                depth += 1
                max_depth = max(max_depth, depth)
            elif c == ')':
                depth -= 1
        
        return max_depth
```

### 方法二：使用栈模拟

```python
class Solution:
    def maxDepth(self, s: str) -> int:
        stack = []
        max_depth = 0
        
        for c in s:
            if c == '(':
                stack.append('(')
                max_depth = max(max_depth, len(stack))
            elif c == ')':
                stack.pop()
        
        return max_depth
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 计数器 | O(n) | O(1) |
| 栈模拟 | O(n) | O(n) |

计数器方法更简洁，推荐使用。

## 关键点总结

1. 遇到 `(` 深度加 1，遇到 `)` 深度减 1
2. 在遇到 `(` 后立即更新最大深度（此时深度最大）
3. 因为是 VPS，不需要处理括号不匹配的情况
4. 计数器方法只需 O(1) 空间，优于栈方法

## 易错点

- 必须在遇到 `(` 之后立即更新最大深度，而不是在遇到 `)` 之前
- 其他字符（数字、运算符）不影响深度，直接跳过
