## 题目描述

给定两个 DataFrame `df1` 和 `df2`，有相同的列结构，将它们垂直拼接（按行堆叠）。

**示例：**
```
输入：
df1 有行 A，df2 有行 B

输出：先 A 后 B 的拼接结果
```

## Python 代码实现

### 方法一：pd.concat（推荐）

```python
import pandas as pd

def concatenateTables(df1: pd.DataFrame, df2: pd.DataFrame) -> pd.DataFrame:
    # 垂直拼接（按行堆叠），重置索引
    return pd.concat([df1, df2], ignore_index=True)
```

### 方法二：append（旧版 pandas）

```python
import pandas as pd

def concatenateTables(df1: pd.DataFrame, df2: pd.DataFrame) -> pd.DataFrame:
    # pandas 1.3 以后 append 已弃用，推荐用 concat
    return pd.concat([df1, df2]).reset_index(drop=True)
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 和 m 分别为两个 DataFrame 的行数
- 空间复杂度：O(n + m)

## 关键点总结

1. `pd.concat([df1, df2], ignore_index=True)` 垂直拼接两个 DataFrame
2. `ignore_index=True` 重置行索引（避免重复索引）
3. 水平拼接（按列）用 `pd.concat([df1, df2], axis=1)`
