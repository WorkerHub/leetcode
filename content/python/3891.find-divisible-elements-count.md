## 题目描述

给你一个整数数组 `nums` 和两个整数 `p` 和 `q`，统计 `nums` 中能被 `p` 整除且能被 `q` 整除的元素数目。

**示例 1：**

```
输入：nums = [2, 6, 12, 3, 10], p = 2, q = 3
输出：2
解释：6 和 12 能同时被 2 和 3 整除，共 2 个。
```

**示例 2：**

```
输入：nums = [1, 2, 3, 4], p = 2, q = 4
输出：1
解释：4 能被 2 且被 4 整除，共 1 个。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= p, q <= 100`

## 解题思路

能被 p 和 q 同时整除等价于能被 `lcm(p, q)` 整除，直接遍历统计即可。

## Python 代码实现

### 方法一：LCM 简化（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def findDivisibleCount(self, nums: List[int], p: int, q: int) -> int:
        # 能被 p 和 q 整除等价于能被 lcm(p, q) 整除
        lcm_pq = p * q // gcd(p, q)
        return sum(1 for v in nums if v % lcm_pq == 0)
```

### 方法二：直接双条件

```python
from typing import List

class Solution:
    def findDivisibleCount(self, nums: List[int], p: int, q: int) -> int:
        return sum(1 for v in nums if v % p == 0 and v % q == 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 同时被 p 和 q 整除等价于被 `lcm(p, q)` 整除。
2. `lcm(p, q) = p * q // gcd(p, q)`。
3. 方法二直接双条件，更直观。

## 易错点

1. `lcm` 计算不要用浮点数，用整数除法 `//`。
2. 两种方法结果相同，但方法一少一次取模运算。
