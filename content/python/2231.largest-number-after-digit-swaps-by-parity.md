## 题目描述

给你一个正整数 `num`，你可以 **多次** 交换其十进制表示中的任意两个 **奇偶性相同** 的相邻数字。

返回交换操作后 `num` 可以取到的**最大值**。

**示例 1：**
```
输入：num = 1234
输出：3412
解释：奇数位：1,3 -> 排成最大 3,1；偶数位：2,4 -> 排成最大 4,2。
```

**示例 2：**
```
输入：num = 65875
输出：87655
```

## 解题思路

由于可以多次交换**同奇偶性**的相邻数字，等价于可以**对奇数位上的数字任意排列**，对**偶数位上的数字任意排列**（气泡排序可以实现任意排列）。

因此：
1. 分别提取奇数位的数字和偶数位的数字（按值大小降序排列）。
2. 按原来的奇偶位置重新填入（大数优先放高位）。

## 代码实现

### 方法一：分组排序（推荐）

```python
class Solution:
    def largestInteger(self, num: int) -> int:
        digits = list(str(num))
        n = len(digits)

        # 分别收集奇数位和偶数位的数字，降序排列
        odds = sorted([d for d in digits if int(d) % 2 == 1], reverse=True)
        evens = sorted([d for d in digits if int(d) % 2 == 0], reverse=True)

        io = ie = 0  # 奇偶指针
        result = []
        for d in digits:
            if int(d) % 2 == 1:
                result.append(odds[io])
                io += 1
            else:
                result.append(evens[ie])
                ie += 1

        return int("".join(result))
```

### 方法二：优先队列（堆）

```python
import heapq

class Solution:
    def largestInteger(self, num: int) -> int:
        digits = list(str(num))
        # 奇数和偶数各用最大堆（负数模拟）
        odd_heap = []
        even_heap = []
        for d in digits:
            x = int(d)
            if x % 2 == 1:
                heapq.heappush(odd_heap, -x)
            else:
                heapq.heappush(even_heap, -x)

        result = []
        for d in digits:
            x = int(d)
            if x % 2 == 1:
                result.append(str(-heapq.heappop(odd_heap)))
            else:
                result.append(str(-heapq.heappop(even_heap)))

        return int("".join(result))
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序操作，n 为数字位数。
- 空间复杂度：O(n)，存储数字列表。

## 关键点总结

1. 多次相邻交换等价于全排列，只要奇偶性相同即可任意排列。
2. 分别对奇数位和偶数位的数字降序排列，再按原位置填回。
3. 不能跨奇偶交换。

## 易错点

- 注意是数字的奇偶性（1,3,5,7,9 为奇数；0,2,4,6,8 为偶数），而不是位置的奇偶性。
- 排序后按照原始数字的奇偶性决定使用哪个列表的下一个值。
