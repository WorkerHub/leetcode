## 题目描述

给你一个偶数长度的字符串 `s`。将其分成长度相同的两半，前一半为 `a`，后一半为 `b`。
两个字符串**相似**的条件：拥有相同数量的元音（`'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U'`）。
如果 `a` 和 `b` 相似，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：s = "book"
输出：true
解释：a = "bo"，b = "ok"，各含 1 个元音
```

**示例 2：**
```
输入：s = "textbook"
输出：false
解释：a = "text"，b = "book"，a 含 1 个元音，b 含 2 个元音
```

**提示：**
- `2 <= s.length <= 1000`
- `s.length` 是偶数
- `s` 由**大小写**字母组成

## 解题思路

直接分割字符串为前后两半，分别统计元音数量，比较是否相等。
使用集合存储元音字母，可以快速判断一个字符是否是元音。

## 代码实现

### 方法一：分割统计（推荐）

```python
class Solution:
    def halvesAreAlike(self, s: str) -> bool:
        # 元音字母集合（大小写均包含）
        vowels = set('aeiouAEIOU')
        n = len(s)
        mid = n // 2
        
        # 统计前半部分的元音数量
        count_a = sum(1 for c in s[:mid] if c in vowels)
        # 统计后半部分的元音数量
        count_b = sum(1 for c in s[mid:] if c in vowels)
        
        return count_a == count_b
```

### 方法二：双指针一次遍历

```python
class Solution:
    def halvesAreAlike(self, s: str) -> bool:
        vowels = set('aeiouAEIOU')
        n = len(s)
        
        # 用差值来判断，左指针从头，右指针从中间
        left, right = 0, n // 2
        diff = 0  # 前半元音数 - 后半元音数
        
        while left < n // 2:
            if s[left] in vowels:
                diff += 1
            if s[right] in vowels:
                diff -= 1
            left += 1
            right += 1
        
        return diff == 0
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，元音集合大小固定为常数

## 关键点总结

1. 注意元音包含大写和小写，共 10 个字符
2. 字符串长度保证为偶数，直接对半分即可
3. 用集合存储元音，查找效率为 O(1)

## 易错点

- 忘记包含大写元音 `A, E, I, O, U`
- 分割位置要用整除 `n // 2`
