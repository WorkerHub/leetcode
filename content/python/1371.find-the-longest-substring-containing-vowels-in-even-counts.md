## 题目描述

给你一个字符串 `s`，请你返回满足以下条件的最长子字符串的长度：每个元音字母（`'a'`、`'e'`、`'i'`、`'o'`、`'u'`）在子字符串中都恰好出现了**偶数次**（包括0次）。

**示例 1：**
```
输入：s = "eleetminicoworoep"
输出：13
解释：最长子字符串是 "leetminicowor"，其中：
- 'e' 出现 2 次
- 'i' 出现 2 次
- 'o' 出现 2 次
- 'a','u' 出现 0 次（偶数）
```

**示例 2：**
```
输入：s = "leetcodeisgreat"
输出：5
解释：最长子字符串是 "leetc"，其中 e 出现 2 次。
```

**示例 3：**
```
输入：s = "bcbcbc"
输出：6
解释：整个字符串 "bcbcbc" 中没有元音，所有元音出现0次（偶数），返回6。
```

**提示：**
- `1 <= s.length <= 5 * 10^5`
- `s` 只包含小写英文字母

## 解题思路

### 核心思想：状态压缩 + 前缀异或哈希

本题关键在于：如何高效判断子串中每个元音出现次数的奇偶性？

**奇偶性 → 位掩码：**
- 5个元音 `a, e, i, o, u` 各对应一位（共5位）
- 某位为 `1` 表示对应元音在当前前缀中出现了**奇数次**
- 某位为 `0` 表示对应元音在当前前缀中出现了**偶数次**

**前缀异或的妙用：**
- 设 `state[i]` 为前 `i` 个字符的状态掩码
- 子串 `s[l..r]` 的状态 = `state[r] XOR state[l-1]`
- 若该状态为 `0`，说明子串中所有元音均出现偶数次

**目标：** 找最长的 `r - (l-1)` 使得 `state[r] == state[l-1]`。

等价于：找前缀状态中**相同状态的最远距离**。

用哈希表记录每个状态**首次出现的位置**，若当前状态之前出现过，则更新最大长度。

### 方法一：状态压缩 + 前缀异或（推荐，O(n)）

### 方法二：暴力枚举（O(n²)，仅作对比）

## Python 代码实现

### 方法一：状态压缩 + 前缀异或哈希（推荐）

```python
class Solution:
    def findTheLongestSubstring(self, s: str) -> int:
        # 5个元音对应的位掩码位置
        # a→第0位, e→第1位, i→第2位, o→第3位, u→第4位
        vowel_to_bit = {'a': 1, 'e': 2, 'i': 4, 'o': 8, 'u': 16}

        # 记录每个状态首次出现的位置（下标 -1 表示"空前缀"位置）
        # 初始状态为 0（所有元音出现0次，均为偶数），位置为 -1
        first_seen = {0: -1}

        state = 0     # 当前前缀的状态掩码
        max_len = 0

        for i, c in enumerate(s):
            # 如果当前字符是元音，翻转对应位
            if c in vowel_to_bit:
                state ^= vowel_to_bit[c]

            if state in first_seen:
                # 相同状态之前出现过，子串长度为 i - first_seen[state]
                max_len = max(max_len, i - first_seen[state])
            else:
                # 记录该状态首次出现的位置
                first_seen[state] = i

        return max_len
```

### 方法二：状态压缩（用数组代替哈希表，速度更快）

```python
class Solution:
    def findTheLongestSubstring(self, s: str) -> int:
        # 状态只有 2^5 = 32 种，用数组代替字典
        # first_seen[state] = 该状态首次出现时的索引，初始化为 None
        first_seen = [-2] * 32   # -2 表示未见过
        first_seen[0] = -1       # 空前缀状态0在位置-1

        # 元音对应的位
        vowel_bit = [0] * 128   # ASCII 索引
        vowel_bit[ord('a')] = 1
        vowel_bit[ord('e')] = 2
        vowel_bit[ord('i')] = 4
        vowel_bit[ord('o')] = 8
        vowel_bit[ord('u')] = 16

        state = 0
        max_len = 0

        for i, c in enumerate(s):
            # 翻转对应元音的位（非元音的 vowel_bit 为0，异或不变）
            state ^= vowel_bit[ord(c)]

            if first_seen[state] != -2:
                # 该状态之前出现过，计算子串长度
                max_len = max(max_len, i - first_seen[state])
            else:
                # 首次见到该状态，记录位置
                first_seen[state] = i

        return max_len
```

### 方法三：暴力枚举（O(n²)，仅作理解对照）

```python
from collections import Counter

class Solution:
    def findTheLongestSubstring(self, s: str) -> int:
        # 暴力枚举所有子串，检查元音是否都是偶数次
        # 时间复杂度 O(n²)，仅用于理解，会超时
        n = len(s)
        vowels = set('aeiou')
        max_len = 0

        for left in range(n):
            count = Counter()
            for right in range(left, n):
                c = s[right]
                if c in vowels:
                    count[c] += 1
                # 检查所有元音是否都是偶数次
                if all(count[v] % 2 == 0 for v in vowels):
                    max_len = max(max_len, right - left + 1)

        return max_len
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 状态压缩+哈希表 | O(n) | O(2^5) = O(1) |
| 状态压缩+数组 | O(n) | O(2^5) = O(1) |
| 暴力枚举 | O(n²) | O(1) |

状态总数为 2^5 = 32（每个元音只有奇/偶两种状态），所以哈希表/数组大小固定，空间 O(1)。

## 关键点总结

1. **奇偶性用位表示**：用1位存储一个元音的奇偶计数，异或操作实现翻转，非常高效。
2. **前缀状态思想**：`子串[l..r]的状态 = 前缀状态[r] XOR 前缀状态[l-1]`，状态为0时满足条件。
3. **哈希表记录首次出现位置**：为了求最长子串，同一状态只记录**最早**出现的位置。
4. **初始化 `first_seen[0] = -1`**：空前缀的状态为0，位于位置-1（下标前一位），不要遗漏。
5. 状态数固定为 32（2^5），时间和空间均非常高效。

## 易错点

1. **初始状态忘记初始化**：`first_seen = {0: -1}` 中的 `{0: -1}` 不能省略，否则从头开始的满足条件的子串会被漏掉。
2. **只记录首次出现位置**：哈希表中同一状态只存**第一次出现**的位置，若已存在则不更新（否则会漏掉更长的子串）。
3. **XOR 操作的理解**：连续两次 XOR 同一个值等于原值，完美模拟了奇偶计数的翻转。
4. **非元音字符**：不需要修改状态，直接跳过或 XOR 0（不变）。
