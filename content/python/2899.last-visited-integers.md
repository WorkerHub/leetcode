## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

从左到右遍历数组，维护一个**最近访问整数**的有序列表（按访问顺序，最新在最后）。

当遇到正整数 `x` 时，将其加入列表。
当遇到 `-1` 时，找到列表中**倒数第 k 个**整数（k 为当前连续 -1 的个数），若不存在则记录 -1。

返回所有 -1 对应的结果数组。

**示例 1：**
```
输入：nums = [1, 2, -1, -1, -1]
输出：[2, 1, -1]
解释：
第一个 -1（k=1）：倒数第1个整数 = 2
第二个 -1（k=2）：倒数第2个整数 = 1
第三个 -1（k=3）：只有2个整数，返回 -1
```

**示例 2：**
```
输入：nums = [3, -1, -1, -1, -1, -1, -1, 1, -1]
输出：[3, -1, -1, -1, -1, -1, 1]
```

**提示：**
- `1 <= nums.length <= 100`
- `nums[i] == -1` 或 `1 <= nums[i] <= 100`

## 解题思路

**模拟：**

- 维护一个整数列表 `seen`（按访问顺序）
- 维护计数器 `k`，记录当前连续 -1 的个数
- 遇到正整数：加入列表，重置 k=0
- 遇到 -1：k+=1，若 `len(seen) >= k`，则结果加入 `seen[-k]`，否则加入 -1

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def lastVisitedIntegers(self, nums: List[int]) -> List[int]:
        seen = []   # 已访问的整数列表
        ans = []
        k = 0       # 连续 -1 计数

        for x in nums:
            if x != -1:
                seen.append(x)
                k = 0  # 重置连续 -1 计数
            else:
                k += 1
                # 倒数第 k 个：seen[-k]
                if k <= len(seen):
                    ans.append(seen[-k])
                else:
                    ans.append(-1)

        return ans
```

### 方法二：等价写法

```python
from typing import List

class Solution:
    def lastVisitedIntegers(self, nums: List[int]) -> List[int]:
        seen = []
        ans = []
        consecutive = 0  # 当前连续 -1 个数

        for num in nums:
            if num == -1:
                consecutive += 1
                idx = len(seen) - consecutive
                ans.append(seen[idx] if idx >= 0 else -1)
            else:
                seen.append(num)
                consecutive = 0

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，存储已访问整数

## 关键点总结

1. 遇到非 -1 数字时，重置连续 -1 计数器
2. 第 k 个连续 -1 对应 `seen[-k]`（倒数第 k 个）
3. 若列表长度不足 k，结果为 -1

## 易错点

1. k 是**连续** -1 的个数，遇到非 -1 时必须重置
2. Python 负下标：`seen[-k]` 等于 `seen[len(seen)-k]`，需确保 k <= len(seen)
