## 题目描述

给你一个字符串数组 `words`，数组中的每个字符串都是一个**两字母**的单词。返回从 `words` 中选择某些单词拼接在一起能够得到的**最长回文串**的**长度**。

**注意：** 不需要使用 `words` 中的所有单词，且 `words` 中每个单词只能使用一次。

**示例 1：**
```
输入：words = ["lc","cl","gg"]
输出：6
解释：一个最长的回文串是 "lc" + "gg" + "cl" = "lcggcl"，长度为 6
```

**示例 2：**
```
输入：words = ["ab","ty","yt","lc","cl","ab"]
输出：8
解释：一个最长的回文串是 "ty" + "lc" + "cl" + "yt" = "tylcclyt"，长度为 8
```

**示例 3：**
```
输入：words = ["cc","ll","xx"]
输出：2
解释：一个最长的回文串是 "cc"，长度为 2
```

**提示：**
- `1 <= words.length <= 10^5`
- `words[i].length == 2`
- `words[i]` 仅由小写英文字母组成

## 解题思路

将单词分为两类：
1. **自身是回文的**（如 "gg", "cc"）：两两配对可放在左右两侧，若有奇数个，可以放一个在中间
2. **非回文的**（如 "lc" 和 "cl"）：必须找到其翻转对，一左一右配对使用

具体贪心策略：
- 用哈希表统计每个单词的出现次数
- 对于非回文词 `w`，找其翻转 `rev`，取 `min(count[w], count[rev])` 对，每对贡献 4 个字符
- 对于回文词 `w`，每两个贡献 4 个字符，若最后剩余奇数个，可放一个在正中间（贡献 2 个字符，但只能放一次）

## 代码实现

### 方法一：哈希表贪心（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        count = Counter(words)
        result = 0
        center_used = False  # 是否已经在中间放了一个回文词

        for word, cnt in count.items():
            rev = word[::-1]
            if word == rev:
                # 自身是回文词（如 "gg"）
                # 每两个放在两侧，贡献 4 个字符
                result += (cnt // 2) * 4
                # 如果有剩余奇数个，可以放一个在中间
                if cnt % 2 == 1 and not center_used:
                    result += 2
                    center_used = True
            elif word < rev:
                # 非回文词，只处理 word < rev 的情况，避免重复统计
                # 每对 (word, rev) 贡献 4 个字符
                pairs = min(cnt, count.get(rev, 0))
                result += pairs * 4

        return result
```

### 方法二：逐个单词处理

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        # 用字典记录还未配对的单词
        unpaired = defaultdict(int)
        result = 0

        for word in words:
            rev = word[::-1]
            if unpaired[rev] > 0:
                # 找到配对，贡献 4 个字符
                result += 4
                unpaired[rev] -= 1
            else:
                unpaired[word] += 1

        # 检查是否有可以放在中间的回文词
        for word, cnt in unpaired.items():
            if word == word[::-1] and cnt > 0:
                result += 2
                break

        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有单词一次，哈希表操作为 O(1)
- **空间复杂度**：O(n)，哈希表存储单词计数

## 关键点总结

1. 将单词分为自身是回文（如 "aa"）和非回文（如 "ab"）两类分别处理
2. 非回文词必须与其翻转词配对使用
3. 自身是回文的词两两配对后，最多一个可以放在正中间
4. 方法二的"逐个消消乐"思路更直观

## 易错点

1. 方法一中用 `word < rev` 避免对同一对 `(word, rev)` 重复统计
2. 中间位置的回文词只能放一个，要用 `center_used` 标志位控制
3. `words` 中每个单词只能使用一次，需要正确处理计数
