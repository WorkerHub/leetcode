## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，数组中的元素均为 **正整数**。

每次操作，你可以选择两个 **不同** 的下标 `i` 和 `j`，满足 `nums[i] > 0` 且 `nums[j] > 0`，将 `nums[i]` 更新为 `nums[i] % nums[j]`。

返回执行若干次操作后，`nums` 的最小可能长度。

**注意：** 如果某个元素变为 0，它并不从数组中删除；但是"长度"实际上指最终非零元素的个数。

等等，重新审题：实际上本题的意思是，`nums[i] % nums[j]` 如果等于 0，则可以删除 `nums[i]`，数组长度减小。

**示例 1：**
```
输入：nums = [1,4,3,1]
输出：1
```

**示例 2：**
```
输入：nums = [5,5,5,10,5]
输出：2
```

**示例 3：**
```
输入：nums = [2,3,4]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键数学性质：**

1. 如果数组中存在两个不同的数 `a` 和 `b`（`a != b`），则 `a % b < b`，可以产生更小的数。
   - 若 `a % b != 0`，得到一个比 `b` 小的正整数，可以进一步削减其他元素
   - 若 `a % b == 0`，`a` 变为 0，相当于被删除（可以让 `a` 用 `b` 取模，若整除则删除 `a`）

2. 如果所有元素都相同（都等于 `x`），则没有办法减少任何元素（`x % x = 0`，但需要两个不同下标，都变 0 也不对）。
   - 实际上 `x % x = 0` 让一个变为 0，等于删除一个，最终剩 1 个 `x`。

3. 如果数组中存在最小值 `m`，且 `m` 不能整除所有其他元素，则会产生一个比 `m` 更小的数（即余数），最终可以得到所有元素的 GCD。

**结论：**
- 如果数组最小值能整除所有其他元素（即所有元素的 GCD 等于最小值），则无法进一步减少，答案为所有最小值的个数（因为非最小值都能被删除，最小值不能被删除）。
- 否则，最终 GCD 会比最小值还小，理论上可以把所有元素都缩到 GCD，最终答案为 1。

等价于：**如果最小值有多个或者最小值不能整除所有元素，答案为 1；否则答案为最小值的出现次数。**

## Python 代码实现

### 方法一：数论分析（推荐）

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def minimumArrayLength(self, nums: List[int]) -> int:
        # 计算所有元素的 GCD
        g = reduce(gcd, nums)
        min_val = min(nums)

        if g < min_val:
            # 最终 GCD 比最小值还小，可以把所有元素都变成 GCD 或更小
            # 最终数组长度为 1
            return 1

        # g == min_val：最小值就是 GCD，所有元素是最小值的倍数
        # 非最小值元素可以被删除（通过 x % min_val = 0 变为 0）
        # 最小值不能被删除（min_val % min_val = 0，但也可以互相抵消）
        # 实际上：两个相同的 min_val 互相取模得 0，可以删掉一个
        # 奇数个 min_val 最终剩 1 个，偶数个最终剩 0 个？不对
        # 两个 min_val 取模：min_val % min_val = 0，删掉一个，留一个
        # 所以：count(min_val) 个最小值，最终都能缩到 1 个（两两取模，每次删一个）
        # 答案 = ceil(count(min_val) / 2) ? 
        # 重新想：count=1 → 1，count=2 → 第一个 % 第二个 = 0，删第一个，剩 1
        # 所以答案永远是 1
        # 不对，还要看非最小值元素能否被删除
        # 非最小值 v = k * min_val（k > 1），v % min_val = 0，可以删除 v
        # 所以最终所有非最小值都被删除，剩下 count(min_val) 个最小值
        # count(min_val) 个最小值互相取模，每次减少 1 个，最终剩 1 个
        # 所以答案 = ceil(count(min_val) / 2)

        count = nums.count(min_val)
        return (count + 1) // 2
```

### 方法二：简化逻辑

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def minimumArrayLength(self, nums: List[int]) -> int:
        overall_gcd = reduce(gcd, nums)
        min_val = min(nums)

        # 如果 GCD < 最小值，说明可以产生比最小值更小的数，最终可以缩减到 1
        if overall_gcd < min_val:
            return 1

        # GCD == 最小值，只有最小值的倍数存在
        # 非最小值都可以被删除，最小值之间两两取模消去一个
        # 最终剩 ceil(count / 2)
        count = nums.count(min_val)
        return (count + 1) // 2
```

## 复杂度分析

- 时间复杂度：O(n log M)，M 为最大值，计算 GCD
- 空间复杂度：O(1)

## 关键点总结

1. 关键在于所有元素的 GCD：若 GCD < 最小值，答案为 1
2. 若 GCD = 最小值，只有最小值本身无法被完全消除
3. n 个相同值互相取模，每次消去一个，最终剩 `ceil(n/2)`

## 易错点

1. 注意 GCD 与最小值的关系，不是所有情况都能缩到 1
2. 最小值之间取模也可以消去，不要遗漏这个操作
