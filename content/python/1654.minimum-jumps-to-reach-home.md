## 题目描述

有一只跳蚤的家在数轴上的位置 `x = 0`，它想前往位置 `x = target`。

跳蚤可以：
- **向前跳** `a` 个单位
- **向后跳** `b` 个单位（不能连续向后跳两次）

另外，数组 `forbidden` 中的位置是**禁止停留**的。

求跳蚤到达 `target` 的最少跳数，若无法到达则返回 `-1`。

**提示：**
- `1 <= forbidden.length <= 1000`
- `1 <= a, b, forbidden[i] <= 2000`
- `0 <= target <= 2000`

## 解题思路

**BFS 最短路：**

状态为 `(position, last_direction)`，其中方向 0 表示向前跳，1 表示向后跳。

**搜索边界：** 位置最大值不超过 `max(forbidden) + a + b`（更大的位置没有意义，因为即使一直向前再向后也会循环）。

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumJumps(self, forbidden: List[int], a: int, b: int, x: int) -> int:
        forbidden_set = set(forbidden)
        # 位置上界：所有 forbidden 中的最大值 + a + b（保守估计）
        upper = max(max(forbidden), x) + a + b
        
        # 状态：(position, came_from_back)
        # came_from_back=True 表示上一跳是向后跳
        visited = set()
        visited.add((0, False))
        
        queue = deque([(0, False, 0)])  # (位置, 上一跳是否向后, 步数)
        
        while queue:
            pos, back, steps = queue.popleft()
            
            if pos == x:
                return steps
            
            # 向前跳
            new_pos = pos + a
            if new_pos <= upper and new_pos not in forbidden_set and (new_pos, False) not in visited:
                visited.add((new_pos, False))
                queue.append((new_pos, False, steps + 1))
            
            # 向后跳（上一跳不能是向后跳）
            if not back:
                new_pos = pos - b
                if new_pos > 0 and new_pos not in forbidden_set and (new_pos, True) not in visited:
                    visited.add((new_pos, True))
                    queue.append((new_pos, True, steps + 1))
        
        return -1
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def minimumJumps(self, forbidden: List[int], a: int, b: int, x: int) -> int:
        forbidden_set = set(forbidden)
        upper = max(max(forbidden), x) + a + b
        
        # dp[pos][0] = 正向到达 pos 的最少步数
        # dp[pos][1] = 反向到达 pos 的最少步数
        INF = float('inf')
        dp = [[INF, INF] for _ in range(upper + 1)]
        dp[0][0] = 0
        
        # 从 0 开始，按步数广度优先（BFS = 按层 DP）
        for pos in range(upper + 1):
            for back in range(2):
                if dp[pos][back] == INF:
                    continue
                # 向前
                nxt = pos + a
                if nxt <= upper and nxt not in forbidden_set:
                    dp[nxt][0] = min(dp[nxt][0], dp[pos][back] + 1)
                # 向后（不能连续向后）
                if back == 0:
                    nxt = pos - b
                    if nxt > 0 and nxt not in forbidden_set:
                        dp[nxt][1] = min(dp[nxt][1], dp[pos][back] + 1)
        
        result = min(dp[x])
        return result if result != INF else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(upper) | O(upper) |
| DP | O(upper) | O(upper) |

upper = max(forbidden) + a + b，约为 O(4000) = O(1)。

## 关键点总结

1. 状态需要记录"上一跳是否向后"，因为不能连续向后跳
2. 搜索上界：`max(forbidden) + a + b`（经验公式，确保不会无限向前）
3. BFS 保证找到最短路

## 易错点

- 不能停在 forbidden 集合中的位置
- 不能停在 x=0 之前（负数位置）
- 注意 `x=0` 时跳蚤已在家，应返回 0（但 x >= 1，所以无需特判）
