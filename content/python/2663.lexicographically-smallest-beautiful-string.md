## 题目描述

给你一个长度为 `n` 的字符串 `s` 和一个整数 `k`，字符串只含前 `k` 个小写字母（a 到 k 中的字母）。**美丽字符串**是不含长度为 2 或 3 的回文子串的字符串。

返回字典序最小且大于 `s` 的美丽字符串，若不存在则返回空字符串。

**示例 1：**
```
输入：s = "abcz", k = 26
输出："abda"
```

**示例 2：**
```
输入：s = "dc", k = 4
输出：""
解释：k=4 意味着只用 a,b,c,d，大于 "dc" 的美丽字符串不存在
```

**数据范围：**
- 1 <= n <= 10^5
- 4 <= k <= 26
- s 是长度为 n 的美丽字符串

## 解题思路

从最后一位开始，尝试递增该位：
1. 将最后一位递增（若超出 k 范围，退位再递增）
2. 每次递增后，检查当前位是否与前一位或前两位形成回文
   - 长度 2 的回文：`s[i] == s[i-1]`
   - 长度 3 的回文：`s[i] == s[i-2]`
3. 若当前位不满足，继续递增
4. 找到满足条件的当前位后，将后续位从 'a' 开始补充（也需要满足美丽条件）

## Python 代码实现

### 方法一：贪心递增（推荐）

```python
class Solution:
    def smallestBeautifulString(self, s: str, k: int) -> str:
        n = len(s)
        arr = list(s)

        def is_valid_at(i):
            """检查位置 i 是否与前面形成回文"""
            if i >= 1 and arr[i] == arr[i - 1]:
                return False
            if i >= 2 and arr[i] == arr[i - 2]:
                return False
            return True

        def next_valid_char(i, start_char):
            """从 start_char 开始，找第一个在位置 i 不形成回文的字符"""
            for c in range(ord(start_char), ord('a') + k):
                arr[i] = chr(c)
                if is_valid_at(i):
                    return True
            return False  # 没有合法字符

        # 从最后一位开始，尝试递增
        i = n - 1
        while i >= 0:
            # 尝试将 arr[i] 递增到下一个合法字符
            next_c = chr(ord(arr[i]) + 1)
            if next_valid_char(i, next_c):
                # 成功递增，将后续位填最小合法字符
                for j in range(i + 1, n):
                    if not next_valid_char(j, 'a'):
                        return ""  # 不应该发生
                return ''.join(arr)
            else:
                # 当前位无法递增，退到前一位
                i -= 1

        return ""  # 无法找到更大的美丽字符串
```

## 复杂度分析

- 时间复杂度：O(n * k)，最坏情况每位尝试 k 个字符
- 空间复杂度：O(n)

## 关键点总结

1. 不含长度 2 或 3 的回文等价于：任意相邻两字符不同，且间隔一个位置的字符不同
2. 从末位往前找第一个可以递增的位，然后将后续位从最小合法字符填充
3. 递增后每次只需检查当前位与前 1 和前 2 位

## 易错点

1. 长度 3 的回文：`s[i] == s[i-2]`，不是 `s[i] == s[i-1]`
2. 后续位填充也需要满足美丽条件
3. k 限制了可用字符范围
