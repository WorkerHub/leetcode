## 题目描述

给你一个字符串 `s`（由若干小写英文字母组成）和一个整数数组 `shift`，其中 `shift[i] = [direction, amount]`：

- `direction` 为 `0` 表示左移，`1` 表示右移
- `amount` 表示移动的字符个数

左移 1 位的意思：将字符串的第一个字符移动到最后。  
右移 1 位的意思：将字符串的最后一个字符移动到第一位。

请你按照 `shift` 数组依次对 `s` 进行移位操作，然后返回最终结果。

**示例 1：**

```
输入：s = "abc", shift = [[0,1],[1,2]]
输出："cab"
解释：
[0,1] 左移 1 位，"abc" → "bca"
[1,2] 右移 2 位，"bca" → "cab"
```

**示例 2：**

```
输入：s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]
输出："efgabcd"
解释：
[1,1] 右移 1 位，"abcdefg" → "gabcdef"
[1,1] 右移 1 位，"gabcdef" → "fgabcde"
[0,2] 左移 2 位，"fgabcde" → "abcdefg"
[1,3] 右移 3 位，"abcdefg" → "efgabcd"
```

**提示：**

- `1 <= s.length <= 100`
- `1 <= shift.length <= 100`
- `shift[i].length == 2`
- `0 <= shift[i][0] <= 1`
- `0 <= shift[i][1] <= 100`

注：本题为会员题。

## 解题思路

### 关键观察：合并所有移位

多次移位操作可以合并为一次：

- 左移 amount 等价于右移 -amount（负数表示左移）
- 将所有移位求代数和：正数表示右移，负数表示左移
- 对字符串长度取模，得到等效的单次移位

**合并规则：**
```
total = sum(amount if direction==1 else -amount for direction, amount in shift)
total = total % n  # n = len(s)，消除冗余移位
```

若 `total > 0`，右移 total 位：`s = s[-total:] + s[:-total]`  
若 `total < 0`，左移 |total| 位：`s = s[-total:] + s[:-total]`（同样的切片公式！）  
若 `total == 0`，不移位

实际上，`s[-total:] + s[:-total]` 对正负 `total` 都适用（当 total=0 时需单独处理）。

## Python 代码实现

### 方法一：合并移位（推荐）

```python
from typing import List

class Solution:
    def stringShift(self, s: str, shift: List[List[int]]) -> str:
        n = len(s)
        if n == 0:
            return s

        # 合并所有移位：右移为正，左移为负
        total = 0
        for direction, amount in shift:
            if direction == 1:
                total += amount   # 右移
            else:
                total -= amount   # 左移

        # 取模，得到等效的净右移量（0 <= total < n）
        total = total % n

        # 右移 total 位：最后 total 个字符移到前面
        if total == 0:
            return s
        return s[-total:] + s[:-total]
```

### 方法二：逐步模拟（理解用）

```python
from typing import List

class Solution:
    def stringShift(self, s: str, shift: List[List[int]]) -> str:
        n = len(s)

        for direction, amount in shift:
            amount = amount % n  # 防止 amount >= n 的冗余移位
            if direction == 0:
                # 左移 amount 位：前 amount 个字符移到末尾
                s = s[amount:] + s[:amount]
            else:
                # 右移 amount 位：后 amount 个字符移到前面
                s = s[-amount:] + s[:-amount] if amount > 0 else s

        return s
```

### 方法三：使用 collections.deque（高效旋转）

```python
from typing import List
from collections import deque

class Solution:
    def stringShift(self, s: str, shift: List[List[int]]) -> str:
        dq = deque(s)

        # 合并移位
        total = sum(amount if direction == 1 else -amount
                    for direction, amount in shift)
        total = total % len(s)

        # deque.rotate(k)：正数右旋，负数左旋
        dq.rotate(total)

        return "".join(dq)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 合并移位 | O(len(shift) + n) | O(n) |
| 逐步模拟 | O(len(shift) * n) | O(n) |
| deque | O(len(shift) + n) | O(n) |

合并移位是最优解，先合并再执行一次移位，避免了多次字符串切片。

## 图解示例

以 `s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]` 为例：

```
合并：total = +1 + 1 - 2 + 3 = 3（净右移 3 位）
total % 7 = 3

右移 3 位：s[-3:] + s[:-3] = "efg" + "abcd" = "efgabcd" ✓
```

## 关键点总结

1. 多次移位可以合并：右移为正，左移为负，求代数和
2. 对字符串长度取模，消除冗余移位（移位 n 次等于不移）
3. 右移 k 位的切片公式：`s[-k:] + s[:-k]`（k > 0）
4. `deque.rotate(k)` 是 Python 内置的旋转方法，正数右旋

## 易错点

1. `amount` 可以超过字符串长度，需要取模（`amount % n`）
2. `total = 0` 时，`s[-0:] + s[:-0]` = `s + ""` = `s`，但 `s[:-0]` 在 Python 中等于 `s[:0] = ""`，需要特殊处理！

   `s[:-0]` 相当于 `s[:0]`，结果是空字符串，所以 `total=0` 时必须特判。

3. 左移 k 位的切片：`s[k:] + s[:k]`；右移 k 位的切片：`s[-k:] + s[:-k]`，两者方向相反
