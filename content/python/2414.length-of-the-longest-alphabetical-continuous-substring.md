## 题目描述

**字母连续字符串** 是由字母表中连续字母组成的字符串，大小写不作区分。例如，`"abc"`、`"aab"` 均不是字母连续字符串，而 `"abc"` 和 `"wxyz"` 是字母连续字符串。

给你一个仅由小写英文字母组成的字符串 `s`，返回其 **最长** 的字母连续子字符串的长度。

**示例 1：**
```
输入：s = "abacaba"
输出：2
解释：s 中最长的字母连续子字符串为 "ab"，长度为 2。
```

**示例 2：**
```
输入：s = "abcde"
输出：5
解释：s 中最长的字母连续子字符串为 "abcde"，长度为 5。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成

## 解题思路

从左到右遍历字符串，维护当前连续子串的长度：
- 若当前字符比前一字符大 1（字母连续），当前长度加 1
- 否则重置当前长度为 1
- 实时更新最大长度

## 代码实现

### 方法一：一次遍历（推荐）

```python
class Solution:
    def longestContinuousSubstring(self, s: str) -> int:
        ans = 1
        cur = 1  # 当前连续子串长度

        for i in range(1, len(s)):
            if ord(s[i]) - ord(s[i - 1]) == 1:
                # 当前字符是前一字符的下一个字母
                cur += 1
                ans = max(ans, cur)
            else:
                # 断开，重置
                cur = 1

        return ans
```

### 方法二：双指针

```python
class Solution:
    def longestContinuousSubstring(self, s: str) -> int:
        ans = 0
        left = 0

        for right in range(len(s)):
            if right > 0 and ord(s[right]) - ord(s[right - 1]) != 1:
                left = right  # 重置起点
            ans = max(ans, right - left + 1)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(n) | O(1) |
| 双指针 | O(n) | O(1) |

## 关键点总结

1. 连续字母的条件：`ord(s[i]) - ord(s[i-1]) == 1`
2. 维护当前连续长度，遇到不连续时重置
3. 初始答案为 1（单个字符也是连续子串）

## 易错点

- 题目要求连续且递增，不是仅连续（`"ba"` 不算连续字母子串）
- 空字符串边界（但题目保证 `s.length >= 1`）
