## 题目描述

给你一个正整数数组 `nums`，对 `nums` 中的所有元素求乘积。

返回 **乘积** 中 **不同质因数** 的数目。

**注意：** 如果某个质因数在乘积中出现多次，在答案中仍只计 1 次。

**示例 1：**

```
输入：nums = [2,4,3,7,10,6]
输出：4
解释：
2 = 2
4 = 2²
3 = 3
7 = 7
10 = 2 × 5
6 = 2 × 3
乘积的质因数为 {2, 3, 5, 7}，共 4 个。
```

**示例 2：**

```
输入：nums = [2,4,8,16]
输出：1
解释：乘积的质因数只有 2。
```

**提示：**

- `1 <= nums.length <= 10^4`
- `2 <= nums[i] <= 1000`

## 解题思路

对每个数分别进行质因数分解，将所有质因数收集到一个集合中（自动去重），最后返回集合大小。

无需求乘积，因为乘积的质因数 = 所有元素质因数的并集。

## Python 代码实现

### 方法一：逐元素分解 + 集合（推荐）

```python
from typing import List

class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        primes = set()

        for num in nums:
            # 对每个数进行质因数分解
            d = 2
            while d * d <= num:
                if num % d == 0:
                    primes.add(d)
                    while num % d == 0:
                        num //= d
                d += 1
            if num > 1:
                primes.add(num)

        return len(primes)
```

### 方法二：预计算质数表（埃拉托色尼筛）

```python
from typing import List

class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        # 由于 nums[i] <= 1000，可以预计算所有 <= 1000 的质数
        max_val = 1000
        is_prime = [True] * (max_val + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(max_val**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, max_val + 1, i):
                    is_prime[j] = False
        primes = [i for i in range(2, max_val + 1) if is_prime[i]]

        prime_set = set()
        for num in nums:
            for p in primes:
                if p * p > num:
                    break
                if num % p == 0:
                    prime_set.add(p)
                    while num % p == 0:
                        num //= p
            if num > 1:
                prime_set.add(num)

        return len(prime_set)
```

## 复杂度分析

- 时间复杂度：O(n * √M)，n 为数组长度，M 为最大元素值（1000）
- 空间复杂度：O(P)，P 为不同质因数数目（最多约 170 个质数 <= 1000）

## 关键点总结

1. 乘积的质因数 = 各元素质因数的并集，不需要实际求乘积
2. 质因数分解标准方法：从 2 到 √n 试除
3. 分解后若剩余 > 1，则该剩余数本身是质因数

## 易错点

1. 不需要对乘积分解（乘积可能极大），只需对每个元素分解
2. 同一质因数出现在多个元素中，集合自动去重
3. 试除后记得检查剩余的 `num > 1` 情况
