## 题目描述

给你一个字符串 `s` 和一个整数 `repeatLimit`。用 `s` 中的字符构造一个新字符串 `repeatLimitedString`，使得任何字母**连续出现的次数**不超过 `repeatLimit`。你不必使用 `s` 中所有的字符。

返回**字典序最大**的 `repeatLimitedString`。

**示例 1：**
```
输入：s = "cczazcc", repeatLimit = 3
输出："zzcccac"
解释：最多连续用 3 个 c，然后插入 a，再接 c，...
```

**示例 2：**
```
输入：s = "aababab", repeatLimit = 2
输出："bbabaa"
```

**提示：**
- `1 <= repeatLimit <= s.length <= 10^5`
- `s` 只含小写英文字母

## 解题思路

**贪心 + 最大堆**

贪心策略：每次尽量选当前频率最高的字母，最多连续使用 `repeatLimit` 次；若还有剩余，则用次大的字母"打断"一次，然后继续。

使用最大堆（Python 用负数模拟）存储 `(-freq, char)`，每次弹出最大字母，最多放 `repeatLimit` 个；若堆中还有次大字母，弹出一个次大字母插入结果，再把剩余最大字母压回堆。

## 代码实现

### 方法一：最大堆（推荐）

```python
import heapq
from collections import Counter

class Solution:
    def repeatLimitedString(self, s: str, repeatLimit: int) -> str:
        # 统计频率，构建最大堆 (-freq, char)
        freq = Counter(s)
        heap = [(-cnt, ch) for ch, cnt in freq.items()]
        heapq.heapify(heap)

        result = []

        while heap:
            neg_cnt, ch = heapq.heappop(heap)
            cnt = -neg_cnt

            # 最多放 repeatLimit 个
            use = min(cnt, repeatLimit)
            result.append(ch * use)
            cnt -= use

            if cnt > 0:
                # 当前字母还有剩余，需要插入次大字母打断
                if not heap:
                    break  # 没有次大字母，无法继续
                neg_cnt2, ch2 = heapq.heappop(heap)
                cnt2 = -neg_cnt2
                result.append(ch2)  # 插入一个次大字母
                cnt2 -= 1
                # 把剩余次大字母压回
                if cnt2 > 0:
                    heapq.heappush(heap, (-cnt2, ch2))
                # 把剩余最大字母压回
                heapq.heappush(heap, (-cnt, ch))

        return ''.join(result)
```

### 方法二：从大到小枚举字母（26 字母有限）

```python
from collections import Counter

class Solution:
    def repeatLimitedString(self, s: str, repeatLimit: int) -> str:
        freq = [0] * 26
        for c in s:
            freq[ord(c) - ord('a')] += 1

        result = []
        i = 25  # 从字典序最大的字母开始

        while i >= 0:
            if freq[i] == 0:
                i -= 1
                continue
            # 放最多 repeatLimit 个字母 i
            use = min(freq[i], repeatLimit)
            result.append(chr(ord('a') + i) * use)
            freq[i] -= use

            if freq[i] > 0:
                # 还有剩余，找次大字母打断
                j = i - 1
                while j >= 0 and freq[j] == 0:
                    j -= 1
                if j < 0:
                    break  # 没有次大字母
                result.append(chr(ord('a') + j))
                freq[j] -= 1
                # 继续，i 不变

        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最大堆 | O(n log 26) = O(n) | O(26) |
| 枚举字母 | O(n * 26) | O(26) |

## 关键点总结

1. 每次优先放字典序最大的字母，不超过 `repeatLimit` 次。
2. 若该字母仍有剩余，必须插入一个次大字母"打断"，然后继续。
3. 若无次大字母，则直接结束。

## 易错点

- 打断时只插入**一个**次大字母，不是多个。
- 打断后记得把次大字母的剩余和最大字母的剩余都压回堆。
