## 题目描述

给你两个正整数数组 `spells` 和 `potions`，`spells[i]` 表示第 `i` 个咒语的能量，`potions[j]` 表示第 `j` 个魔药的能量。另给一个整数 `success`。

一对咒语和魔药若它们能量的**乘积**不小于 `success`，则配对**成功**。

返回一个长度与 `spells` 相同的数组 `pairs`，`pairs[i]` 为第 `i` 个咒语与多少个魔药配对成功。

**示例 1：**
```
输入：spells = [5,1,3], potions = [1,2,3,4,5], success = 7
输出：[4,0,3]
解释：5*2=10>=7, 5*3=15>=7, 5*4=20>=7, 5*5=25>=7，共4个；1*x<7所有；3*3=9>=7, 3*4, 3*5，共3个。
```

**示例 2：**
```
输入：spells = [3,1,2], potions = [8,5,8], success = 16
输出：[2,0,2]
```

## 解题思路

**二分查找：**

将 `potions` 排序，对每个 `spells[i]`，需要找满足 `spells[i] * potion >= success` 的 `potion` 数量。

即 `potion >= ceil(success / spells[i]) = (success + spells[i] - 1) // spells[i]`。

在排序后的 `potions` 中用 `bisect_left` 找到第一个 `>= threshold` 的位置，后面的所有魔药都满足条件。

## 代码实现

### 方法一：排序 + 二分查找（推荐）

```python
from typing import List
import bisect
import math

class Solution:
    def successfulPairs(self, spells: List[int], potions: List[int], success: int) -> List[int]:
        potions.sort()
        n = len(potions)
        result = []

        for spell in spells:
            # 需要 spell * potion >= success
            # 即 potion >= ceil(success / spell)
            threshold = math.ceil(success / spell)
            # 在排序 potions 中找第一个 >= threshold 的位置
            idx = bisect.bisect_left(potions, threshold)
            result.append(n - idx)

        return result
```

### 方法二：整数除法避免浮点

```python
from typing import List
import bisect

class Solution:
    def successfulPairs(self, spells: List[int], potions: List[int], success: int) -> List[int]:
        potions.sort()
        n = len(potions)
        ans = []

        for spell in spells:
            # threshold = ceil(success / spell) = (success + spell - 1) // spell
            threshold = (success + spell - 1) // spell
            idx = bisect.bisect_left(potions, threshold)
            ans.append(n - idx)

        return ans
```

### 方法三：双指针（对 spells 也排序）

```python
from typing import List

class Solution:
    def successfulPairs(self, spells: List[int], potions: List[int], success: int) -> List[int]:
        potions.sort()
        n, m = len(spells), len(potions)

        # 将 spells 按值排序，同时记录原始下标
        indexed_spells = sorted(enumerate(spells), key=lambda x: x[1])

        ans = [0] * n
        j = m - 1  # 魔药指针（从大到小）

        for orig_idx, spell in indexed_spells:
            # spell 从小到大，对应的 threshold 从大到小
            # j 指向最后一个不满足的魔药（从右往左找满足的边界）
            while j >= 0 and spell * potions[j] >= success:
                j -= 1
            ans[orig_idx] = m - (j + 1)

        return ans
```

## 复杂度分析

**方法一/二（二分查找）：**
- 时间复杂度：O((m + n) log m)，排序 + n 次二分。
- 空间复杂度：O(1)（不计输出）。

**方法三（双指针）：**
- 时间复杂度：O(m log m + n log n)，两个数组都排序。
- 空间复杂度：O(n)，存储排序后的下标。

## 关键点总结

1. 对 `potions` 排序后可以用二分快速定位。
2. `threshold = ceil(success / spell)`，整数计算用 `(success + spell - 1) // spell`。
3. `bisect_left(potions, threshold)` 返回第一个 `>= threshold` 的位置，`n - idx` 即满足条件的个数。

## 易错点

- `math.ceil(success / spell)` 可能有浮点精度问题，推荐用整数除法 `(success + spell - 1) // spell`。
- 双指针方法需要记录 spells 的原始下标，以便将结果放回正确位置。
