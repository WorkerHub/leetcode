## 题目描述

给你一个整数数组 `nums` 和一个链表的头节点 `head`，从链表中删除所有**值存在于 `nums` 中**的节点，返回修改后链表的头节点。

**示例 1：**
```
输入：nums = [1,2,3], head = [1,2,3,4,5]
输出：[4,5]
```

**示例 2：**
```
输入：nums = [1], head = [1,2,1,2,1,2]
输出：[2,2,2]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= 节点数 <= 10^5`
- `1 <= Node.val <= 10^5`
- `nums` 中的元素互不相同

## 解题思路

用哈希集合存储 `nums` 中的值，然后遍历链表，跳过值在集合中的节点。

使用虚拟头节点（dummy node）简化边界处理。

## Python 代码实现

### 方法一：哈希集合 + 虚拟头节点（推荐）

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def modifiedList(self, nums: List[int], head: Optional[ListNode]) -> Optional[ListNode]:
        # 将 nums 转为集合，O(1) 查询
        num_set = set(nums)
        
        # 虚拟头节点，方便处理头节点被删除的情况
        dummy = ListNode(0)
        dummy.next = head
        
        prev = dummy
        curr = head
        
        while curr:
            if curr.val in num_set:
                # 跳过该节点
                prev.next = curr.next
            else:
                prev = curr
            curr = curr.next
        
        return dummy.next
```

### 方法二：递归写法

```python
from typing import Optional, List

class Solution:
    def modifiedList(self, nums: List[int], head: Optional[ListNode]) -> Optional[ListNode]:
        num_set = set(nums)
        
        def remove(node):
            if not node:
                return None
            node.next = remove(node.next)
            if node.val in num_set:
                return node.next
            return node
        
        return remove(head)
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为链表长度，m 为 nums 长度
- 空间复杂度：O(m)，哈希集合

## 关键点总结

1. 先将 nums 转为 set，查询时间 O(1)
2. 虚拟头节点处理头节点被删除的情况
3. 维护前驱节点 prev，跳过需要删除的节点

## 易错点

1. 注意链表头节点可能也需要被删除
2. 删除节点时 prev 不要移动，只有保留节点时才移动 prev
