## 题目描述

给定一个字符串数组 `wordsDict` 和两个字符串 `word1` 和 `word2`，返回列表中这两个单词之间的最短距离。

**注意：** `word1` 和 `word2` 可能相同，此时你需要找到数组中这个单词相邻出现位置的最短距离。

**示例 1：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "makes", word2 = "coding"
输出: 1
```

**示例 2：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "makes", word2 = "makes"
输出: 3
解释: "makes" 出现在索引 1 和 4，最短距离是 3
```

**提示：**
- 1 <= wordsDict.length <= 10^5
- 1 <= wordsDict[i].length <= 10
- wordsDict[i] 由小写英文字母组成
- word1 和 word2 在 wordsDict 中

## 解题思路

这道题是 [LeetCode 243](https://leetcode.com/problems/shortest-word-distance/) 的扩展，关键区别是**word1 和 word2 可能相同**。

**核心思想：**
- 当 word1 != word2 时，使用 243 题的双指针方法
- 当 word1 == word2 时，找该单词相邻出现的最小距离

**关键观察：**
1. **相同单词的情况**：需要找到同一个单词的两个不同位置，且距离最小
2. **不同单词的情况**：和 243 题完全一样
3. **统一处理**：可以用一个算法同时处理两种情况

**算法设计：**
- 使用两个指针 pos1 和 pos2
- 当单词相同时，每次更新时 pos1 = pos2，pos2 = 当前位置
- 当单词不同时，分别更新对应的指针

## Python 代码实现

### 方法一：分情况讨论（易理解）

```python
from typing import List

class Solution:
    def shortestWordDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        分两种情况处理
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if word1 == word2:
            # 情况1：相同单词，找相邻出现的最小距离
            return self.shortestSameWord(wordsDict, word1)
        else:
            # 情况2：不同单词，使用 243 题的方法
            return self.shortestDiffWord(wordsDict, word1, word2)
    
    def shortestSameWord(self, wordsDict: List[str], word: str) -> int:
        """找同一个单词相邻出现的最小距离"""
        min_distance = float('inf')
        prev_pos = -1
        
        for i, w in enumerate(wordsDict):
            if w == word:
                if prev_pos != -1:
                    min_distance = min(min_distance, i - prev_pos)
                prev_pos = i
        
        return min_distance
    
    def shortestDiffWord(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """找两个不同单词的最小距离（243 题的方法）"""
        min_distance = float('inf')
        pos1, pos2 = -1, -1
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                pos1 = i
                if pos2 != -1:
                    min_distance = min(min_distance, pos1 - pos2)
            elif word == word2:
                pos2 = i
                if pos1 != -1:
                    min_distance = min(min_distance, pos2 - pos1)
        
        return min_distance
```

### 方法二：统一处理（推荐）⭐

```python
from typing import List

class Solution:
    def shortestWordDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        统一算法处理两种情况
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = float('inf')
        pos1, pos2 = -1, -1
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                # 如果 word1 == word2，pos1 保存上一个位置
                if word1 == word2:
                    pos1 = pos2
                else:
                    pos1 = i
            
            if word == word2:
                pos2 = i
            
            # 计算距离
            if pos1 != -1 and pos2 != -1 and pos1 != pos2:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法三：更简洁的统一处理⭐

```python
from typing import List

class Solution:
    def shortestWordDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        最简洁的实现
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = float('inf')
        pos1 = pos2 = -1
        
        for i, word in enumerate(wordsDict):
            # 先保存 pos2 的旧值（用于 word1 == word2 的情况）
            if word == word1:
                pos1 = pos2 if word1 == word2 else i
            
            # 更新 pos2
            if word == word2:
                pos2 = i
            
            # 两个位置都有效且不同，计算距离
            if pos1 != -1 and pos2 != -1 and pos1 != pos2:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法四：最优化版本（单次判断）

```python
from typing import List

class Solution:
    def shortestWordDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        优化版：减少判断次数
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = len(wordsDict)
        pos1 = pos2 = -1
        same = (word1 == word2)
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                if same:
                    # 相同单词：pos1 指向上一个位置，pos2 指向当前位置
                    pos1 = pos2
                    pos2 = i
                else:
                    pos1 = i
            elif word == word2:
                pos2 = i
            
            # 计算距离
            if pos1 != -1 and pos2 != -1:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法五：单指针法（最简洁）

```python
from typing import List

class Solution:
    def shortestWordDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        单指针方法
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = float('inf')
        prev_pos = -1
        
        for i, word in enumerate(wordsDict):
            if word == word1 or word == word2:
                # 如果上一个位置有效，且满足条件，计算距离
                if prev_pos != -1:
                    # word1 == word2: 总是计算距离
                    # word1 != word2: 只有当前单词与上一个不同时才计算
                    if word1 == word2 or wordsDict[prev_pos] != word:
                        min_distance = min(min_distance, i - prev_pos)
                
                prev_pos = i
        
        return min_distance
```

## 复杂度分析

所有方法的复杂度都相同：
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(1)，只使用常量额外空间

## 关键点总结

1. **区分两种情况**：word1 == word2 需要特殊处理
2. **相邻位置更新**：相同单词时，要保存上一个位置
3. **统一算法**：可以用一个算法同时处理两种情况
4. **位置判断**：计算距离前要确保 pos1 != pos2（避免同一位置）
5. **提前优化**：使用 `len(wordsDict)` 而不是 `float('inf')` 作为初始值

## 易错点

1. **相同单词处理**：忘记 word1 == word2 的情况，导致结果错误
2. **位置更新顺序**：相同单词时，要先保存 pos2 到 pos1，再更新 pos2
3. **距离判断条件**：要确保 pos1 != pos2，否则距离为 0
4. **边界情况**：只出现一次的单词（相同单词情况下）
5. **初始化**：pos1 和 pos2 初始化为 -1 而不是 0
