## 题目描述

给你一个整数数组 `nums`，每次操作可以删除数组的前 3 个元素（若不足 3 个则删除所有剩余元素）。

返回使数组中所有元素**互不相同**所需的最少操作次数。

**示例：**
```
输入：nums = [1,2,3,1,2,3]
输出：2
解释：操作 2 次后数组为空，所有元素自然互不相同。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

**从后向前检查：**

每次操作删除前 3 个元素，等价于找到最小的 `k`，使得 `nums[3k:]`（删除前 `3k` 个元素后的数组）中所有元素互不相同。

从后向前扫描：找到最后一个出现重复的位置 `i`，则需要删除到 `i+1` 之前的所有元素，需要 `ceil((i+1) / 3)` 次操作。

**等价方法：** 逆序遍历，记录已见过的元素集合，遇到重复元素时，该元素的下标 `i` 就是"第一个需要删除的元素"的最晚位置，答案为 `(i // 3) + 1`。

## Python 代码实现

### 方法一：从后向前检查（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        seen = set()
        n = len(nums)
        
        # 从后向前找第一个重复元素
        for i in range(n - 1, -1, -1):
            if nums[i] in seen:
                # 需要删除 nums[0..i]（共 i+1 个元素），即 ceil((i+1)/3) 次
                return i // 3 + 1
            seen.add(nums[i])
        
        # 数组本身无重复
        return 0
```

### 方法二：枚举操作次数（正向验证）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        
        for ops in range((n + 2) // 3 + 1):
            # 删除前 3*ops 个元素后检查
            remaining = nums[3 * ops:]
            if len(remaining) == len(set(remaining)):
                return ops
        
        return (n + 2) // 3
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希集合

**方法二：**
- 时间复杂度：O(n^2 / 3)，每次检查 O(n)，最多 O(n/3) 次
- 空间复杂度：O(n)

## 关键点总结

1. 每次删前 3 个，相当于找最小 k 使 `nums[3k:]` 无重复。
2. 从后向前扫描，找到第一个重复位置 `i`，答案为 `i // 3 + 1`。
3. 若无重复，返回 0。

## 易错点

1. `ceil((i+1) / 3)` 等于 `i // 3 + 1`（整数计算）。
2. 从后向前找到的第一个重复元素下标 `i`，表示 `nums[i]` 这个元素在更后面已经出现过，所以 `nums[0..i]` 都必须被删除。
3. 若整个数组无重复，返回 0（不需要操作）。
