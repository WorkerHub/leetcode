## 题目描述

图像平滑器是大小为 `3 x 3` 的过滤器，用于对图像的每个单元格平滑处理。平滑处理计算该单元格自身和其周围八个单元格的平均值（向下取整）。如果一个单元格周围存在的单元格少于九个，则取所有存在的单元格的平均值。

给你一个表示图像灰度的 `m x n` 整数矩阵 `img`，返回对图像的每个单元格平滑处理后的图像。

**示例 1:**

```
输入：img = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[0,0,0],[0,0,0],[0,0,0]]
解释：
对于点 (0,0)：周围有 4 个单元格，平均值 = (1+1+1+0)/4 = 0.75 = 0
对于点 (0,1)：周围有 6 个单元格，平均值 = (1+1+1+1+0+1)/6 = 0.833 = 0
对于点 (1,1)：周围有 9 个单元格，平均值 = (1+1+1+1+0+1+1+1+1)/9 = 0.888 = 0
```

**示例 2:**

```
输入：img = [[100,200,100],[200,50,200],[100,200,100]]
输出：[[137,141,137],[141,138,141],[137,141,137]]
解释：
对于点 (0,0)：(100+200+200+50)/4 = 137.5 = 137
对于点 (0,1)：(100+200+100+200+50+200)/6 = 141.666 = 141
对于点 (1,1)：(100+200+100+200+50+200+100+200+100)/9 = 138.888 = 138
```

**提示:**
- `m == img.length`
- `n == img[i].length`
- `1 <= m, n <= 200`
- `0 <= img[i][j] <= 255`

## 解题思路

这是一道简单的矩阵遍历题，关键是正确处理边界。

### 核心思路

1. **遍历每个单元格**
2. **计算周围 3x3 区域的和与数量**
3. **取平均值（向下取整）**

### 边界处理

对于位置 `(i, j)`，周围的 8 个邻居是：
- `(i-1, j-1)`, `(i-1, j)`, `(i-1, j+1)`
- `(i, j-1)`, `(i, j+1)`
- `(i+1, j-1)`, `(i+1, j)`, `(i+1, j+1)`

需要检查每个邻居是否在矩阵范围内。

## Python 代码实现

### 方法一：直接模拟（推荐）⭐

```python
from typing import List

class Solution:
    def imageSmoother(self, img: List[List[int]]) -> List[List[int]]:
        """
        遍历每个单元格，计算周围的平均值
        """
        m, n = len(img), len(img[0])
        result = [[0] * n for _ in range(m)]
        
        # 8个方向 + 自己
        directions = [(-1,-1), (-1,0), (-1,1), (0,-1), (0,0), (0,1), (1,-1), (1,0), (1,1)]
        
        for i in range(m):
            for j in range(n):
                total_sum = 0
                count = 0
                
                # 遍历周围的单元格
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    # 检查边界
                    if 0 <= ni < m and 0 <= nj < n:
                        total_sum += img[ni][nj]
                        count += 1
                
                # 计算平均值（向下取整）
                result[i][j] = total_sum // count
        
        return result
```

### 方法二：简化版本

```python
class Solution:
    def imageSmoother(self, img: List[List[int]]) -> List[List[int]]:
        """
        使用 range 简化边界判断
        """
        m, n = len(img), len(img[0])
        result = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                total_sum = 0
                count = 0
                
                # 遍历 3x3 区域
                for x in range(max(0, i-1), min(m, i+2)):
                    for y in range(max(0, j-1), min(n, j+2)):
                        total_sum += img[x][y]
                        count += 1
                
                result[i][j] = total_sum // count
        
        return result
```

### 方法三：列表推导式

```python
class Solution:
    def imageSmoother(self, img: List[List[int]]) -> List[List[int]]:
        """
        使用列表推导式，代码更简洁
        """
        m, n = len(img), len(img[0])
        
        def get_average(i, j):
            """计算 (i, j) 位置的平均值"""
            neighbors = [
                img[x][y]
                for x in range(max(0, i-1), min(m, i+2))
                for y in range(max(0, j-1), min(n, j+2))
            ]
            return sum(neighbors) // len(neighbors)
        
        return [[get_average(i, j) for j in range(n)] for i in range(m)]
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(m × n)，遍历每个单元格，每个单元格最多检查 9 个邻居
- **空间复杂度**：O(m × n)，存储结果矩阵（不算输出）则为 O(1)

## 关键点总结

1. **边界处理**：使用 `max(0, i-1)` 和 `min(m, i+2)` 处理边界
2. **向下取整**：使用整数除法 `//`
3. **3x3 区域**：包括自己和周围 8 个邻居
4. **遍历技巧**：可以用方向数组或嵌套循环
5. **结果矩阵**：需要新建矩阵，不能原地修改

## 易错点

1. **边界范围**：
   ```python
   # 错误：range(i-1, i+2) 可能越界
   for x in range(i-1, i+2):
   
   # 正确：限制范围
   for x in range(max(0, i-1), min(m, i+2)):
   ```

2. **包含自己**：
   ```python
   # 记得包含 (i, j) 自己
   # 8个邻居 + 自己 = 9个
   ```

3. **整数除法**：
   ```python
   # 正确：向下取整
   result[i][j] = total_sum // count
   
   # 错误：普通除法会得到浮点数
   result[i][j] = total_sum / count
   ```

4. **原地修改**：
   ```python
   # 不能直接修改原矩阵
   # 需要创建新矩阵存储结果
   result = [[0] * n for _ in range(m)]
   ```

5. **range 的上界**：
   ```python
   # range(a, b) 不包含 b
   # 所以是 i+2 而不是 i+1
   range(max(0, i-1), min(m, i+2))
   ```
