## 题目描述

给你一个整数数组 `nums` 和整数 `d`，找到最长的子序列使得相邻元素之差的绝对值等于 `d`（等差子序列，公差为 ±d）。

返回该子序列的最大长度。

**示例 1：**

```
输入：nums = [1,2,3,4], d = 1
输出：4
解释：[1,2,3,4]，相邻差均为1
```

**示例 2：**

```
输入：nums = [1,3,5,7], d = 2
输出：4
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= d <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

DP + 哈希表：

`dp[v]` = 以值 `v` 结尾的最长等差子序列长度（公差 d）。

对每个 `nums[i] = v`，`dp[v] = max(dp[v - d], dp[v + d]) + 1`（接在 `v-d` 或 `v+d` 之后）。

注意：子序列保持顺序，所以应该从左到右处理。由于只考虑公差 d，不考虑 -d 与 +d 的混合。

实际上公差固定为 d（正方向），只看 `v - d`：`dp[v] = dp[v - d] + 1`（若 `v - d` 存在）。

## Python 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List

class Solution:
    def maxPeriodicLength(self, nums: List[int], d: int) -> int:
        dp = {}  # dp[v] = 以 v 结尾的最长等差子序列长度
        ans = 1

        for v in nums:
            # 接在 v-d 后面
            if v - d in dp:
                dp[v] = max(dp.get(v, 1), dp[v - d] + 1)
            else:
                dp[v] = max(dp.get(v, 1), 1)
            ans = max(ans, dp[v])

        return ans
```

### 方法二：考虑双向公差

```python
from typing import List

class Solution:
    def maxPeriodicLength(self, nums: List[int], d: int) -> int:
        # 考虑公差为 +d 和 -d 的两个方向
        # 从左到右，dp[v] = 以 v 结尾，上一个元素为 v-d 的最长子序列
        dp_pos = {}  # 公差 +d：dp[v] = 以 v 结尾的最长子序列
        dp_neg = {}  # 公差 -d：dp[v] = 以 v 结尾的最长子序列
        ans = 1

        for v in nums:
            dp_pos[v] = dp_pos.get(v - d, 0) + 1
            dp_neg[v] = dp_neg.get(v + d, 0) + 1
            ans = max(ans, dp_pos[v], dp_neg[v])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（哈希表）

## 关键点总结

1. 公差为 d（正方向）时，`dp[v] = dp[v-d] + 1`
2. 考虑双向时，分别维护两个 dp 哈希表
3. 从左到右遍历，保证子序列顺序

## 易错点

1. 子序列需保持数组顺序，不是排序后的序列
2. 相同值的元素可以多次使用（不同位置）
3. `dp.get(v-d, 0)` 当 v-d 不存在时返回 0
