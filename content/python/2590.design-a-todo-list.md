## 题目描述

设计一个 **待办事项清单**，支持以下操作：

- `TodoList()` 初始化对象。
- `int addTask(int userId, String taskDescription, int dueDate, List<String> tags)` 为用户 `userId` 添加任务，返回任务 ID（从 1 递增）。
- `List<String> getAllTasks(int userId)` 返回用户 `userId` 未完成的所有任务描述，按截止日期升序排序，截止日期相同则按添加顺序排序。
- `List<String> getTasksForTag(int userId, String tag)` 返回用户 `userId` 未完成的含有标签 `tag` 的任务描述，排序同上。
- `void completeTask(int userId, int taskId)` 标记用户 `userId` 的任务 `taskId` 为已完成（若不存在则不操作）。

**提示：**

- `1 <= userId, taskId <= 100`
- `0 <= tags.length <= 100`
- 所有操作调用总数 `<= 100`

## 解题思路

**哈希表 + 列表模拟**：

用字典存储每个用户的任务列表，每个任务包含 id、描述、截止日期、标签集合、是否完成。

查询时过滤已完成任务，按 (截止日期, 任务 id) 排序。

## Python 代码实现

### 方法一：哈希表 + 列表（推荐）

```python
from typing import List
from collections import defaultdict

class TodoList:

    def __init__(self):
        self.next_id = 1
        # user_id -> list of (task_id, description, due_date, tags_set, completed)
        self.tasks = defaultdict(list)

    def addTask(self, userId: int, taskDescription: str, dueDate: int, tags: List[str]) -> int:
        task_id = self.next_id
        self.next_id += 1
        self.tasks[userId].append({
            'id': task_id,
            'desc': taskDescription,
            'due': dueDate,
            'tags': set(tags),
            'done': False
        })
        return task_id

    def getAllTasks(self, userId: int) -> List[str]:
        # 过滤未完成，按 (due_date, task_id) 排序
        pending = [t for t in self.tasks[userId] if not t['done']]
        pending.sort(key=lambda t: (t['due'], t['id']))
        return [t['desc'] for t in pending]

    def getTasksForTag(self, userId: int, tag: str) -> List[str]:
        # 过滤未完成且含有该标签
        pending = [t for t in self.tasks[userId] if not t['done'] and tag in t['tags']]
        pending.sort(key=lambda t: (t['due'], t['id']))
        return [t['desc'] for t in pending]

    def completeTask(self, userId: int, taskId: int) -> None:
        for t in self.tasks[userId]:
            if t['id'] == taskId:
                t['done'] = True
                return
```

### 方法二：全局任务表 + 用户索引

```python
from typing import List
from collections import defaultdict

class TodoList:

    def __init__(self):
        self.next_id = 1
        # task_id -> task info
        self.all_tasks = {}
        # user_id -> list of task_ids
        self.user_tasks = defaultdict(list)

    def addTask(self, userId: int, taskDescription: str, dueDate: int, tags: List[str]) -> int:
        tid = self.next_id
        self.next_id += 1
        self.all_tasks[tid] = {
            'user': userId,
            'desc': taskDescription,
            'due': dueDate,
            'tags': set(tags),
            'done': False
        }
        self.user_tasks[userId].append(tid)
        return tid

    def _get_pending(self, userId, tag=None):
        result = []
        for tid in self.user_tasks[userId]:
            t = self.all_tasks[tid]
            if t['done']:
                continue
            if tag and tag not in t['tags']:
                continue
            result.append((t['due'], tid, t['desc']))
        result.sort()
        return [desc for _, _, desc in result]

    def getAllTasks(self, userId: int) -> List[str]:
        return self._get_pending(userId)

    def getTasksForTag(self, userId: int, tag: str) -> List[str]:
        return self._get_pending(userId, tag)

    def completeTask(self, userId: int, taskId: int) -> None:
        if taskId in self.all_tasks and self.all_tasks[taskId]['user'] == userId:
            self.all_tasks[taskId]['done'] = True
```

## 复杂度分析

- `addTask`：O(1)
- `getAllTasks` / `getTasksForTag`：O(m log m)，m 为该用户的任务数
- `completeTask`：O(m)
- 空间复杂度：O(总任务数)

## 关键点总结

1. 每个任务需要存储：id、描述、截止日期、标签集合、完成状态
2. 排序键为 `(due_date, task_id)`，保证截止日期相同时按添加顺序
3. `tags` 存为集合，O(1) 查询是否含某标签

## 易错点

1. 任务 ID 从 1 开始全局递增，不是每个用户单独计数
2. `completeTask` 时需要验证 userId 和 taskId 是否匹配（方法二）
3. 排序时不能只按截止日期，相同截止日期需要按 task_id（添加顺序）
