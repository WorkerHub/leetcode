## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

每次操作可以将数组中所有**大于某个值 `h`** 的元素全部替换为 `h`（`h` 必须满足：不存在 `nums` 中的元素落在 `(h, min_greater)` 之间，即 h 可以是 nums 中比目标大的那个值减 1... 更准确：每次操作选一个值 h，将所有严格大于 h 的元素设为 h）。

返回使所有元素等于 `k` 的最少操作次数。若无法实现（如有元素 < k），返回 -1。

**示例：**
```
输入：nums = [5, 2, 5, 4, 5], k = 2
输出：2
解释：操作1：h=4，所有>4的变成4：[4,2,4,4,4]
     操作2：h=2，所有>2的变成2：[2,2,2,2,2]
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`

## 解题思路

若有任意 `nums[i] < k`，则无法通过操作使其等于 k（操作只能减小元素，不能增大），返回 -1。

每次操作可以将所有 > h 的元素降到 h。要将所有元素变成 k，需要依次"消灭"比 k 大的各个不同值，每个不同值（> k）需要一次操作。

因此，操作次数 = `nums` 中严格大于 `k` 的不同值的个数。

## Python 代码实现

### 方法一：集合计数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        # 若有 nums[i] < k，无解
        if any(x < k for x in nums):
            return -1
        
        # 统计严格大于 k 的不同值的个数
        return len(set(x for x in nums if x > k))
```

### 方法二：排序后计数

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        if min(nums) < k:
            return -1
        
        # 大于 k 的不同值的数量
        greater_values = set()
        for x in nums:
            if x > k:
                greater_values.add(x)
        
        return len(greater_values)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组
- 空间复杂度：O(n)，集合

## 关键点总结

1. 若有 `nums[i] < k`，无法通过减小操作达到 k，返回 -1。
2. 每次操作消灭一个"层级"（将最大值降到某个水平），操作次数 = 大于 k 的不同值个数。
3. 值等于 k 的元素无需操作。

## 易错点

1. `nums[i] == k` 的元素已经满足条件，不需要操作。
2. 若 `nums[i] < k`，立即返回 -1（操作无法增大元素）。
3. 计数的是不同值（用集合），不是元素总数。
