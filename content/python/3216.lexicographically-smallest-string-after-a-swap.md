## 题目描述

给你一个仅由**数字**组成的字符串 `s`，在一次操作中，你可以将字符串中**相邻**的两个数字交换，但前提是它们的**奇偶性相同**（即同为奇数或同为偶数）。

返回经过**至多一次**操作后，`s` 能变成的**字典序最小**字符串。

**示例 1：**
```
输入：s = "45320"
输出："43520"
解释：交换 s[1]='5' 和 s[2]='3'（都是奇数），得到 "43520"。
```

**示例 2：**
```
输入：s = "001"
输出："001"
解释：不存在有益的交换。
```

**提示：**
- `2 <= s.length <= 100`
- `s` 只包含数字

## 解题思路

贪心：从左往右找第一个可以通过交换使字符串变小的位置。

对于位置 `i`，如果 `s[i]` 和 `s[i+1]` 奇偶性相同，且 `s[i] > s[i+1]`，则交换后字典序更小，立即执行并返回。

## Python 代码实现

### 方法一：贪心遍历（推荐）

```python
class Solution:
    def getSmallestString(self, s: str) -> str:
        s = list(s)
        n = len(s)
        for i in range(n - 1):
            # 检查相邻两位奇偶性相同且前者大于后者
            if int(s[i]) % 2 == int(s[i + 1]) % 2 and s[i] > s[i + 1]:
                # 交换后字典序更小，直接返回
                s[i], s[i + 1] = s[i + 1], s[i]
                return ''.join(s)
        return ''.join(s)
```

### 方法二：一行写法

```python
class Solution:
    def getSmallestString(self, s: str) -> str:
        lst = list(s)
        for i in range(len(lst) - 1):
            a, b = int(lst[i]), int(lst[i + 1])
            if a % 2 == b % 2 and a > b:
                lst[i], lst[i + 1] = lst[i + 1], lst[i]
                break
        return ''.join(lst)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，转换为列表

## 关键点总结

1. 贪心：找到最左边能让字典序变小的交换
2. 条件：相邻两位奇偶性相同，且前者 > 后者
3. 只需执行一次操作，找到就立即返回

## 易错点

1. 只能操作一次，找到第一个满足条件的位置后立即交换并返回
2. 奇偶性是相同就可以交换，不是要求两者差为偶数
