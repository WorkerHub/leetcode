## 题目描述

X 轴上有一些机器人和工厂。给你一个整数数组 `robot`，其中 `robot[i]` 是第 `i` 个机器人的位置。再给你一个二维整数数组 `factory`，其中 `factory[j] = [positionj, limitj]`，表示第 `j` 个工厂在位置 `positionj`，且最多可以修理 `limitj` 个机器人。

每个机器人所在的位置 **各不相同**。每个工厂所在的位置也 **各不相同**。机器人和工厂的位置可能相同。

所有机器人都需要被修理。每个机器人移动一个距离的开销是 `1`。

请你返回修理所有机器人的 **最小总距离** 。测试数据保证所有机器人都可以被修理。

**提示：**
- `1 <= robot.length, factory.length <= 100`
- `1 <= robot[i], factory[j][0] <= 10^9`
- `0 <= factory[j][1] <= robot.length`

## 解题思路

**贪心 + 动态规划：**

**关键优化：** 将每个工厂按容量展开成多个「位置相同」的单容量工厂，简化问题。

排序后，最优解中机器人和工厂的相对顺序不会交叉（证明：若交叉，交换分配后总距离不增）。

**DP 状态：** `dp[i][j]` = 前 `i` 个机器人和前 `j` 个工厂的最小总距离。

**转移方程：**
- 将最后 `k` 个机器人（`robot[i-k+1..i]`）分配给第 `j` 个工厂
- `dp[i][j] = min over k of (dp[i-k][j-1] + sum(|robot[i-m] - fac[j]|) for m in 0..k-1)`

## 代码实现

### 方法一：DP + 展开工厂（推荐）

```python
from typing import List

class Solution:
    def minimumTotalDistance(self, robot: List[int], factory: List[List[int]]) -> int:
        robot.sort()
        factory.sort()

        # 展开工厂：每个工厂展开为 limit 个单元
        fac = []
        for pos, limit in factory:
            fac.extend([pos] * limit)

        m = len(robot)
        n = len(fac)
        INF = float('inf')

        # dp[i][j] = 前 i 个机器人由前 j 个工厂单元修理的最小距离
        dp = [[INF] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = 0
        for j in range(1, n + 1):
            dp[0][j] = 0  # 没有机器人时，任意工厂数都可以

        for j in range(1, n + 1):
            for i in range(1, m + 1):
                # 第 j 个工厂不修机器人 i
                dp[i][j] = dp[i][j - 1]
                # 第 j 个工厂修前 k 个（1 <= k <= i）
                dist = 0
                for k in range(1, i + 1):
                    dist += abs(robot[i - k] - fac[j - 1])
                    if dp[i - k][j - 1] != INF:
                        dp[i][j] = min(dp[i][j], dp[i - k][j - 1] + dist)

        return dp[m][n]
```

### 方法二：空间优化（滚动数组）

```python
from typing import List

class Solution:
    def minimumTotalDistance(self, robot: List[int], factory: List[List[int]]) -> int:
        robot.sort()
        factory.sort()

        fac = []
        for pos, limit in factory:
            fac.extend([pos] * limit)

        m = len(robot)
        n = len(fac)
        INF = float('inf')

        # 只保留前一列
        dp = [0] + [INF] * m

        for j in range(n):
            new_dp = dp[:]
            for i in range(1, m + 1):
                dist = 0
                for k in range(1, i + 1):
                    dist += abs(robot[i - k] - fac[j])
                    if dp[i - k] != INF:
                        new_dp[i] = min(new_dp[i], dp[i - k] + dist)
            dp = new_dp

        return dp[m]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 展开 DP | O(m^2 * sum(limits)) | O(m * sum(limits)) |
| 空间优化 | O(m^2 * sum(limits)) | O(m) |

## 关键点总结

1. 排序后不交叉原则：最优分配中相邻分配不会交叉
2. 展开工厂为单容量工厂，简化 DP 状态定义
3. 每个工厂可修理相邻的一段机器人

## 易错点

- `dp[0][j] = 0` 初始化（0 个机器人时距离为 0）
- 展开工厂后，DP 维度为机器人数 × 工厂单元总数
