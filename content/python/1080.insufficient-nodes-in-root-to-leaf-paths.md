## 题目描述

给定一棵二叉树的根 `root`，请你考虑它所有**从根到叶的路径**：从根到任何叶的路径。

如果通过节点 `node` 的每一条根到叶路径的值总和都**小于**给定的 `limit`，则该节点被称为**不足节点**。

请删除所有不足节点，并返回生成的二叉树的根。

**注意**：
- **叶子节点**是指没有子节点的节点。
- 删除操作是同时删除所有不足节点。

**示例 1：**
```
输入：root = [1,2,3,4,-99,-99,7,8,9,-99,-99,12,13,-99,14], limit = 1

       1
      / \
     2   3
    / \   \
   4  -99  7
  / \     / \
 8  9   12  13
           \
           14

输出：[1,2,3,4,null,null,7,8,9,null,14]

解释：
路径和：
- 1→2→4→8 = 15 ≥ 1 ✓
- 1→2→4→9 = 16 ≥ 1 ✓
- 1→3→7→12 = 23 ≥ 1 ✓
- 1→3→7→13→14 = 36 ≥ 1 ✓

移除 -99 及其子树后的树仍然满足条件
```

**示例 2：**
```
输入：root = [5,4,8,11,null,17,4,7,1,null,null,5,3], limit = 22
输出：[5,4,8,11,null,17,4,7,null,null,null,5]
```

**示例 3：**
```
输入：root = [1,2,-3,-5,null,4,null], limit = -1
输出：[1,null,-3,4]
```

**提示：**
- 树中节点数目在范围 `[1, 5000]` 内
- `-10^5 <= Node.val <= 10^5`
- `-10^9 <= limit <= 10^9`

## 解题思路

这是一道**后序遍历 + 剪枝**的问题。

### 核心思想

1. **什么是不足节点**：
   - 通过该节点的**所有**根到叶路径的和都 < limit
   - 注意是"所有"，而不是"存在某条"
   - 如果某节点至少有一条路径和 ≥ limit，它就不是不足节点

2. **后序遍历**：
   - 必须先处理子节点，再决定当前节点是否删除
   - 自底向上：先删除叶子，再删除上层节点

3. **递归定义**：
   - 函数返回：以当前节点为根的子树，删除不足节点后的新根
   - 如果当前节点应该被删除，返回 None
   - 否则返回当前节点（可能已修改子树）

4. **判断条件**：
   - **叶子节点**：路径和 = 当前路径和 + node.val，判断是否 >= limit
   - **非叶子节点**：递归处理后，如果左右子树都被删除，说明所有路径都不足，删除当前节点

## Python 代码实现

### 方法一：后序遍历 + 返回最大路径和（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode], current_sum: int) -> Optional[TreeNode]:
            """
            返回删除不足节点后的子树根
            current_sum: 从根到当前节点父节点的路径和
            """
            if not node:
                return None
            
            # 更新路径和
            current_sum += node.val
            
            # 如果是叶子节点，判断路径和是否足够
            if not node.left and not node.right:
                # 如果路径和 < limit，删除该叶子（返回 None）
                return None if current_sum < limit else node
            
            # 递归处理左右子树
            node.left = dfs(node.left, current_sum)
            node.right = dfs(node.right, current_sum)
            
            # 如果左右子树都被删除，说明所有路径都不足，删除当前节点
            if not node.left and not node.right:
                return None
            
            # 否则保留当前节点
            return node
        
        return dfs(root, 0)
```

### 方法二：显式跟踪路径（理解用）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode], path_sum: int) -> tuple[Optional[TreeNode], int]:
            """
            返回：(删除后的子树根, 通过该节点的最大路径和)
            """
            if not node:
                return None, float('-inf')
            
            # 当前路径和
            path_sum += node.val
            
            # 叶子节点
            if not node.left and not node.right:
                if path_sum < limit:
                    return None, path_sum  # 删除
                else:
                    return node, path_sum  # 保留
            
            # 递归处理子树
            new_left, max_left = dfs(node.left, path_sum)
            new_right, max_right = dfs(node.right, path_sum)
            
            # 更新子树
            node.left = new_left
            node.right = new_right
            
            # 计算通过当前节点的最大路径和
            max_path_sum = max(max_left, max_right)
            
            # 如果最大路径和都 < limit，删除当前节点
            if max_path_sum < limit:
                return None, max_path_sum
            
            return node, max_path_sum
        
        result, _ = dfs(root, 0)
        return result
```

### 方法三：布尔返回值（简洁版）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        def has_sufficient_path(node: Optional[TreeNode], current_sum: int) -> bool:
            """
            返回：以 node 为根的子树是否有至少一条路径和 >= limit
            """
            if not node:
                return False
            
            current_sum += node.val
            
            # 叶子节点
            if not node.left and not node.right:
                return current_sum >= limit
            
            # 递归检查左右子树
            left_sufficient = has_sufficient_path(node.left, current_sum)
            right_sufficient = has_sufficient_path(node.right, current_sum)
            
            # 删除不足的子树
            if not left_sufficient:
                node.left = None
            if not right_sufficient:
                node.right = None
            
            # 如果至少有一条路径足够，保留当前节点
            return left_sufficient or right_sufficient
        
        # 如果根节点都没有足够的路径，返回 None
        return root if has_sufficient_path(root, 0) else None
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，n 是树中节点数
  - 每个节点访问一次
- **空间复杂度**：O(h)，h 是树的高度
  - 递归调用栈的深度
  - 最坏情况（链式树）：O(n)
  - 平衡树：O(log n)

## 图解示例

以 `root = [1,2,-3,-5,null,4,null], limit = -1` 为例：

```
原始树：
      1
     / \
    2  -3
   /     \
  -5      4

路径分析：
- 1→2→-5 = -2 < -1 ✗（不足）
- 1→-3→4 = 2 ≥ -1 ✓（足够）

删除过程（后序遍历）：
1. 访问 -5（叶子）：-2 < -1，删除
2. 访问 2：左子树被删，右子树空，两个子树都空，删除
3. 访问 4（叶子）：2 ≥ -1，保留
4. 访问 -3：右子树有 4，保留
5. 访问 1：右子树有 -3→4，保留

结果树：
      1
       \
       -3
         \
          4
```

## 关键点总结

1. **后序遍历**：必须先知道子树的情况，才能决定当前节点
2. **不足节点定义**：所有路径都 < limit，而不是存在某条路径 < limit
3. **删除条件**：叶子节点判断路径和，非叶子节点判断子树是否全空
4. **路径和传递**：从根累加到当前节点
5. **原地修改**：直接修改 node.left 和 node.right，不需要重建树

## 易错点

1. **理解错题意**：误以为删除"存在不足路径"的节点，实际是"所有路径都不足"
2. **遍历顺序**：使用前序遍历无法判断是否删除，必须后序
3. **叶子判断**：删除子树后，非叶子节点可能变成叶子，需要再次判断
4. **路径和计算**：忘记累加当前节点的值
5. **返回值**：忘记处理根节点被删除的情况（返回 None）
