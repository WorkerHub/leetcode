## 题目描述

给你一个由 `0` 和 `1` 组成的矩阵 `matrix`。你可以将 `matrix` 中任意数量的列从原来的位置移走，并将它们依次插入到其他位置。

请你返回最优方案下将 `matrix` 中包含 `1` 的最大子矩阵面积。

**示例 1：**
```
输入：matrix = [[0,0,1],[1,1,1],[1,0,1]]
输出：4
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^5`

## 解题思路

对每一行，计算每个单元格向上连续 `1` 的个数（柱状图高度）。

对每一行的高度数组**降序排序**，枚举子矩阵的宽度：
- 宽度为 `j+1`（选前 `j+1` 列）
- 最小高度为 `heights[j]`（排序后取第 `j` 个）
- 面积 = `(j + 1) * heights[j]`

因为列可以自由移动，所以可以把高的列排在一起，贪心取最大面积。

## 代码实现

### 方法一：逐行排序贪心（推荐）

```python
from typing import List

class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        
        # 计算每列的向上连续 1 的个数（复用 matrix 节省空间）
        for i in range(1, m):
            for j in range(n):
                if matrix[i][j] == 1:
                    matrix[i][j] += matrix[i - 1][j]
        
        ans = 0
        
        for i in range(m):
            # 对当前行的高度降序排序
            heights = sorted(matrix[i], reverse=True)
            for j, h in enumerate(heights):
                if h == 0:
                    break
                # 宽度 j+1，高度 h，面积 = (j+1) * h
                ans = max(ans, (j + 1) * h)
        
        return ans
```

### 方法二：不修改原矩阵

```python
from typing import List

class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        
        # 另建高度数组
        heights = [row[:] for row in matrix]
        for i in range(1, m):
            for j in range(n):
                if heights[i][j] == 1:
                    heights[i][j] += heights[i - 1][j]
        
        ans = 0
        for i in range(m):
            row_h = sorted(heights[i], reverse=True)
            for j, h in enumerate(row_h):
                if h == 0:
                    break
                ans = max(ans, (j + 1) * h)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(m * n log n)，每行排序 O(n log n)
- **空间复杂度**：O(n)（方法一复用原矩阵）或 O(mn)

## 关键点总结

1. 向上连续 1 的个数是经典的矩形面积问题前处理
2. 列可以自由排列，所以可以降序排列后贪心取最优
3. 枚举宽度时，面积 = 宽度 * 当前最小高度

## 易错点

- 遇到高度为 0 的列可以提前 break（因为已排序，后面高度更小）
- 注意修改原矩阵的问题
