## 题目描述

给你一个二进制字符串 `s`，可以进行两种操作（任意次）：
1. **旋转**：将 `s[0]` 移到末尾（等价于循环移位）
2. **翻转**：将某个字符 0 变 1 或 1 变 0

最少需要多少次**翻转**操作，使得字符串变为交替字符串（不含相邻相同字符）。

**示例 1：**
```
输入：s = "111000"
输出：2
```

**示例 2：**
```
输入：s = "010"
输出：0
```

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

**滑动窗口（循环展开）**：

旋转操作等价于在所有循环移位中选最优的。

将字符串 `s` 扩展为 `s + s`（长度 2n），在其中用长度为 n 的滑动窗口计算最少翻转次数。

对于目标字符串（"010101..." 或 "101010..."），计算窗口内与目标不匹配的字符数。

## 代码实现

### 方法一：滑动窗口 + 双目标（推荐）

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        ss = s + s  # 循环展开

        # 目标1: "010101..." 从0开始
        # 目标2: "101010..." 从1开始
        # 对 ss 的每个位置，预计算与两个目标的不匹配情况
        diff1 = [0] * (2 * n)  # ss[i] 与 目标1 的差异
        diff2 = [0] * (2 * n)  # ss[i] 与 目标2 的差异
        for i in range(2 * n):
            t1 = str(i % 2)        # 目标1：偶数位0，奇数位1
            t2 = str(1 - i % 2)    # 目标2：偶数位1，奇数位0
            diff1[i] = 0 if ss[i] == t1 else 1
            diff2[i] = 0 if ss[i] == t2 else 1

        # 滑动窗口，窗口大小为 n
        result = n  # 初始化为最坏情况
        cur1 = sum(diff1[:n])
        cur2 = sum(diff2[:n])
        result = min(result, cur1, cur2)

        for i in range(n, 2 * n):
            cur1 += diff1[i] - diff1[i - n]
            cur2 += diff2[i] - diff2[i - n]
            result = min(result, cur1, cur2)

        return result
```

### 方法二：简洁版

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        # 扩展字符串，处理循环移位
        t = s + s
        # 预计算两种目标的差异数组
        a = sum(1 for i in range(n) if s[i] != str(i % 2))
        b = sum(1 for i in range(n) if s[i] != str(1 - i % 2))

        ans = min(a, b)
        for i in range(n, 2 * n):
            # 滑动：加入新位 i，去掉旧位 i-n
            c = int(t[i])
            e1 = 1 if t[i] != str(i % 2) else 0
            e2 = 1 if t[i] != str(1 - i % 2) else 0
            r1 = 1 if t[i - n] != str((i - n) % 2) else 0
            r2 = 1 if t[i - n] != str(1 - (i - n) % 2) else 0
            a = a + e1 - r1
            b = b + e2 - r2
            ans = min(ans, a, b)
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，扩展字符串

## 关键点总结

1. 循环移位等价于在 `s+s` 中选长度为 n 的窗口
2. 对两种目标字符串（0开头和1开头）分别用滑动窗口统计不匹配数
3. 取两种情况的最小值

## 易错点

- 目标字符串有两种（以 0 开头或以 1 开头），需要都考虑
- 滑动窗口中，新位 i 的目标值基于全局位置 `i % 2`，不是窗口内的相对位置
