## 题目描述

与 2873 相同，但数据量更大（n 最大 10^5），需要 O(n) 或 O(n log n) 解法。

给你下标从 0 开始的整数数组 `nums`，返回所有 `(i, j, k)` 满足 `i < j < k` 的 `(nums[i] - nums[j]) * nums[k]` 最大值，若全为负则返回 0。

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**O(n) 一次遍历：**

维护三个变量：
- `max_i`：目前最大的 nums[i]
- `max_ij`：目前最大的 nums[i] - nums[j]（固定 j 时）
- `ans`：最终答案

遍历每个 k（从 0 到 n-1）：
1. 更新答案：`ans = max(ans, max_ij * nums[k])`
2. 更新 max_ij：`max_ij = max(max_ij, max_i - nums[k])`（当前 k 作为 j 时）
3. 更新 max_i：`max_i = max(max_i, nums[k])`（当前 k 作为 i 时）

注意更新顺序：先用 max_ij 更新 ans（此时 nums[k] 是 k），再用 max_i 更新 max_ij（此时 nums[k] 是 j），最后更新 max_i（此时 nums[k] 是 i）。

## Python 代码实现

### 方法一：一次遍历 O(n)（推荐）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        max_i = 0     # 最大的 nums[i]（用于计算 nums[i] - nums[j]）
        max_ij = 0    # 最大的 nums[i] - nums[j]（用于计算最终乘积）

        for k in range(n):
            # 当前 nums[k] 作为 k，更新答案
            ans = max(ans, max_ij * nums[k])
            # 当前 nums[k] 作为 j，更新 max_ij
            max_ij = max(max_ij, max_i - nums[k])
            # 当前 nums[k] 作为 i，更新 max_i
            max_i = max(max_i, nums[k])

        return ans
```

### 方法二：前缀最大值 + 后缀最大值（O(n)）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        # 前缀最大值：prefix[i] = nums[0..i] 的最大值
        prefix = [0] * n
        prefix[0] = nums[0]
        for i in range(1, n):
            prefix[i] = max(prefix[i - 1], nums[i])

        # 后缀最大值：suffix[i] = nums[i..n-1] 的最大值
        suffix = [0] * n
        suffix[-1] = nums[-1]
        for i in range(n - 2, -1, -1):
            suffix[i] = max(suffix[i + 1], nums[i])

        ans = 0
        for j in range(1, n - 1):
            val = (prefix[j - 1] - nums[j]) * suffix[j + 1]
            ans = max(ans, val)

        return ans
```

## 复杂度分析

- 方法一：时间 O(n)，空间 O(1)
- 方法二：时间 O(n)，空间 O(n)

## 关键点总结

1. 方法一：维护 max_i 和 max_ij，一次遍历，更新顺序非常关键
2. 方法二：分别预处理前缀最大值和后缀最大值，枚举 j
3. 两种方法时间复杂度相同，方法一空间更优

## 易错点

1. 方法一的更新顺序：先用 ans，再更新 max_ij，最后更新 max_i（不能颠倒）
2. 结果可能为负（当 max_ij < 0 时），但最终返回 max(ans, 0)
3. 方法二中 j 的范围是 [1, n-2]（两侧各至少有一个元素）
