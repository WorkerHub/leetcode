## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。

定义数组的 **K-or** 为满足以下条件的非负整数：
- 对于每一位 `i`（0 <= i <= 31），若 `nums` 中**至少 k 个元素**在第 `i` 位上为 1，则 K-or 在第 `i` 位上为 1。

返回数组的 K-or 值。

**示例 1：**
```
输入：nums = [7,12,9,8,9,15], k = 4
输出：9
解释：
第 0 位：7,9,9,15 共 4 个，>=4，K-or 第 0 位为 1
第 1 位：7,15 共 2 个，<4，K-or 第 1 位为 0
第 2 位：7,12,15 共 3 个，<4，K-or 第 2 位为 0
第 3 位：12,8,9,15 共 4 个，>=4，K-or 第 3 位为 1
K-or = 1001 = 9
```

**示例 2：**
```
输入：nums = [2,12,1,11,4,5], k = 6
输出：0
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= nums.length`

## 解题思路

对每一个二进制位（0 到 31），统计 `nums` 中有多少个数在该位上为 1，若个数 >= k，则答案的该位为 1。

## Python 代码实现

### 方法一：逐位统计（推荐）

```python
from typing import List

class Solution:
    def findKOr(self, nums: List[int], k: int) -> int:
        ans = 0
        for bit in range(32):
            # 统计第 bit 位为 1 的元素个数
            count = sum(1 for x in nums if (x >> bit) & 1)
            if count >= k:
                ans |= (1 << bit)
        return ans
```

### 方法二：利用 bin 字符串

```python
from typing import List

class Solution:
    def findKOr(self, nums: List[int], k: int) -> int:
        ans = 0
        for bit in range(32):
            if sum((x >> bit) & 1 for x in nums) >= k:
                ans += 1 << bit
        return ans
```

## 复杂度分析

- 时间复杂度：O(32 * n) = O(n)，对每一位遍历数组
- 空间复杂度：O(1)

## 关键点总结

1. 按位独立处理：每一位的结果只取决于该位上有多少个 1
2. 整数最多 32 位（题目中 nums[i] <= 10^9 < 2^30，但保险起见检查 32 位）
3. 按位或构建答案：`ans |= (1 << bit)`

## 易错点

1. 注意位数范围：nums[i] <= 10^9，约 30 位，但检查 32 位更安全
2. 统计的是"至少 k 个"，不是"恰好 k 个"
