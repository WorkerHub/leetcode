## 题目描述

给你一条个人信息字符串 `s`，可能表示一个 **邮箱地址**，也可能表示一串 **电话号码**。返回按如下规则 **隐藏** 个人信息后的结果：

**电子邮箱：**
- 名字和域名的首字母和末字母需保留不变
- 中间部分用 5 个 "*" 代替

**电话号码：**
- 保留最后 4 位数字
- 其余数字用 "***-***-" 代替
- 如果有国家代码，保留国家代码并用 "+" 和 "-" 连接

## Python 代码实现

```python
class Solution:
    def maskPII(self, s: str) -> str:
        if '@' in s:
            # 邮箱
            name, domain = s.lower().split('@')
            return f"{name[0]}*****{name[-1]}@{domain}"
        else:
            # 电话
            digits = ''.join(c for c in s if c.isdigit())
            local = f"***-***-{digits[-4:]}"
            
            if len(digits) == 10:
                return local
            else:
                country = len(digits) - 10
                return f"+{'*' * country}-{local}"
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **类型判断**：通过 '@' 区分邮箱和电话
2. **字符串处理**：提取数字、大小写转换
3. **格式化**：f-string 拼接
