## 题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

**示例 1：**
```
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

**示例 2：**
```
输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 都是 ASCII 码表中的可打印字符

## 解题思路

这是一道经典的双指针问题，也是学习原地算法的入门题。

**核心思想：**
使用两个指针，一个指向开头，一个指向末尾，不断交换并向中间移动，直到两指针相遇。

**算法流程：**
1. 左指针 left 从 0 开始，右指针 right 从 len(s)-1 开始
2. 交换 s[left] 和 s[right]
3. left 向右移动，right 向左移动
4. 重复 2-3 直到 left >= right

**时间复杂度：** O(n)，遍历半个数组
**空间复杂度：** O(1)，只使用常数额外空间

## Python 代码实现

### 方法一：双指针（标准解法）⭐

```python
from typing import List

class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left, right = 0, len(s) - 1
        
        while left < right:
            # 交换左右指针的字符
            s[left], s[right] = s[right], s[left]
            
            # 移动指针
            left += 1
            right -= 1
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

### 方法二：Python 切片（简洁但不符合要求）

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        # Python 切片反转
        s[:] = s[::-1]
```

**注意：** 虽然代码简洁，但切片操作 `s[::-1]` 会创建新列表，不符合 O(1) 空间要求。

### 方法三：递归实现

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        def helper(left, right):
            if left >= right:
                return
            
            # 交换
            s[left], s[right] = s[right], s[left]
            
            # 递归处理子问题
            helper(left + 1, right - 1)
        
        helper(0, len(s) - 1)
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)，递归调用栈的深度

**注意：** 递归方法不符合 O(1) 空间要求。

### 方法四：for 循环版本

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        n = len(s)
        
        # 只需遍历前半部分
        for i in range(n // 2):
            # 交换对称位置的字符
            s[i], s[n - 1 - i] = s[n - 1 - i], s[i]
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

### 方法五：使用内置 reverse 方法

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        s.reverse()
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 是否原地 | 备注 |
|------|-----------|-----------|---------|------|
| 双指针 while | O(n) | O(1) | 是 | 标准解法 |
| 双指针 for | O(n) | O(1) | 是 | 更简洁 |
| 切片 | O(n) | O(n) | 否 | 不符合要求 |
| 递归 | O(n) | O(n) | 是 | 调用栈开销 |
| reverse() | O(n) | O(1) | 是 | 最简洁 |

## 图解示例

```
输入：s = ["h","e","l","l","o"]

初始状态：
 left              right
  ↓                 ↓
["h", "e", "l", "l", "o"]

第一次交换：
     left      right
      ↓         ↓
["o", "e", "l", "l", "h"]

第二次交换：
         left right
          ↓   ↓
["o", "l", "l", "e", "h"]

left >= right，停止
```

## 关键点总结

1. **双指针技巧**：从两端向中间移动是处理对称问题的常用技巧
2. **原地操作**：通过交换实现，不使用额外数组
3. **循环条件**：left < right（不是 left <= right，因为中间元素不需要交换）
4. **Python 特性**：可以用 `s.reverse()` 或切片，但要理解底层原理
5. **边界情况**：空数组和单字符数组都能正确处理

## 易错点

1. **循环条件错误**
   ```python
   # 错误：使用 <=，会导致中间元素被交换两次
   while left <= right:
       s[left], s[right] = s[right], s[left]
   
   # 正确：
   while left < right:
       s[left], s[right] = s[right], s[left]
   ```

2. **切片赋值错误**
   ```python
   # 错误：这只是修改了局部变量
   s = s[::-1]
   
   # 正确：必须用切片赋值来修改原数组
   s[:] = s[::-1]
   ```

3. **忘记移动指针**
   ```python
   # 错误：死循环
   while left < right:
       s[left], s[right] = s[right], s[left]
       # 忘记移动指针
   
   # 正确：
   while left < right:
       s[left], s[right] = s[right], s[left]
       left += 1
       right -= 1
   ```

4. **range 范围错误**
   ```python
   # 错误：遍历整个数组，导致反转两次
   for i in range(len(s)):
       s[i], s[n - 1 - i] = s[n - 1 - i], s[i]
   
   # 正确：只遍历前半部分
   for i in range(len(s) // 2):
       s[i], s[n - 1 - i] = s[n - 1 - i], s[i]
   ```

def reverseString(s: str) -> str:
