## 题目描述

给你一个字符串 `s`，请你反转字符串中单词的顺序。

**单词**是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的单词分隔开。

返回单词顺序颠倒且单词之间用单个空格隔开的结果字符串。

**注意：** 输入字符串 `s` 中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**示例 1：**

```
输入: s = "the sky is blue"
输出: "blue is sky the"
```

**示例 2：**

```
输入: s = "  hello world  "
输出: "world hello"
解释: 反转后的字符串中不能存在前导空格和尾随空格。
```

**示例 3：**

```
输入: s = "a good   example"
输出: "example good a"
解释: 如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。
```

**提示：**

- `1 <= s.length <= 10^4`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中至少存在一个单词

**进阶：** 如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 O(1) 额外空间复杂度的原地解法。

## 解题思路

这道题的核心有两个任务：
1. 反转单词顺序
2. 处理多余的空格

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 实现难度 |
|------|-----------|-----------|---------|
| split + reverse | O(n) | O(n) | 简单 |
| 双指针 | O(n) | O(n) | 中等 |
| 原地反转 | O(n) | O(1) | 困难 |

**思路一：使用库函数（最简单）**

1. 使用 `split()` 分割单词（自动处理多余空格）
2. 反转单词列表
3. 用 `' '.join()` 连接

**思路二：双指针**

1. 从后往前遍历字符串
2. 用双指针找到每个单词
3. 依次添加到结果中

**思路三：原地反转（符合进阶要求）**

1. 反转整个字符串
2. 反转每个单词
3. 清理空格

## Python 代码实现

### 方法一：使用 split 和 reverse（最简洁，推荐）

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # split() 会自动去除首尾空格，并按空格分割（多个空格视为一个）
        words = s.split()
        # 反转单词列表
        words.reverse()
        # 用单个空格连接
        return ' '.join(words)
```

### 方法二：一行代码（Python 特色）

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        return ' '.join(s.split()[::-1])
```

### 方法三：双指针（自己实现分割）

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        s = s.strip()  # 去除首尾空格
        result = []
        right = len(s) - 1
        
        while right >= 0:
            # 跳过空格
            while right >= 0 and s[right] == ' ':
                right -= 1
            
            if right < 0:
                break
            
            # 找到单词的左边界
            left = right
            while left >= 0 and s[left] != ' ':
                left -= 1
            
            # 提取单词
            result.append(s[left + 1:right + 1])
            right = left
        
        return ' '.join(result)
```

### 方法四：原地反转（模拟 C++ 的做法）

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # Python 字符串不可变，转换为列表
        chars = list(s.strip())
        n = len(chars)
        
        # 1. 反转整个字符串
        self.reverse(chars, 0, n - 1)
        
        # 2. 反转每个单词
        start = 0
        for i in range(n + 1):
            if i == n or chars[i] == ' ':
                # 找到一个单词，反转它
                self.reverse(chars, start, i - 1)
                start = i + 1
        
        # 3. 清理多余空格
        return self.clean_spaces(chars)
    
    def reverse(self, chars, left, right):
        """反转 chars[left:right+1]"""
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
    
    def clean_spaces(self, chars):
        """去除多余空格"""
        result = []
        i = 0
        n = len(chars)
        
        while i < n:
            # 跳过空格
            while i < n and chars[i] == ' ':
                i += 1
            
            # 收集单词
            word = []
            while i < n and chars[i] != ' ':
                word.append(chars[i])
                i += 1
            
            if word:
                result.extend(word)
                if i < n:  # 不是最后一个单词
                    result.append(' ')
        
        return ''.join(result).rstrip()
```

### 方法五：使用栈

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        stack = []
        word = []
        
        for char in s:
            if char != ' ':
                word.append(char)
            elif word:
                # 遇到空格且 word 不为空，说明一个单词结束
                stack.append(''.join(word))
                word = []
        
        # 处理最后一个单词
        if word:
            stack.append(''.join(word))
        
        # 栈是 LIFO，弹出时自然是反序
        result = []
        while stack:
            result.append(stack.pop())
        
        return ' '.join(result)
```

## 复杂度分析

**方法一、二：split + join**

- 时间复杂度：O(n)
  - split: O(n)
  - reverse: O(m)，m 为单词数
  - join: O(n)
- 空间复杂度：O(n)
  - 存储分割后的单词列表

**方法三：双指针**

- 时间复杂度：O(n)
  - 遍历字符串一次
- 空间复杂度：O(n)
  - 存储结果列表

**方法四：原地反转**

- 时间复杂度：O(n)
  - 反转整个字符串：O(n)
  - 反转每个单词：O(n)
  - 清理空格：O(n)
- 空间复杂度：O(n)
  - Python 字符串不可变，需要转为列表
  - 如果是 C++ 等可变字符串，可以做到 O(1)

## 图解示例

以 `s = "  hello world  "` 为例：

**方法一（split + reverse）：**

```
原始: "  hello world  "

split(): ["hello", "world"]

reverse(): ["world", "hello"]

join(): "world hello"
```

**方法四（原地反转）：**

```
1. 去除首尾空格: "hello world"

2. 反转整个字符串: "dlrow olleh"

3. 反转每个单词:
   "dlrow" -> "world"
   "olleh" -> "hello"
   结果: "world hello"
```

更复杂的例子：`s = "a good   example"`

```
1. split(): ["a", "good", "example"]

2. reverse(): ["example", "good", "a"]

3. join(): "example good a"

多个空格被自动处理为一个
```

## 关键点总结

1. **Python 的 split() 方法**：
   - 不带参数时，自动处理多个空格
   - 去除首尾空格
   - 是最简单的解决方案

2. **双指针技巧**：
   - 从后往前遍历，避免反转列表
   - 一个指针找单词边界，一个指针提取单词

3. **原地反转的思想**：
   - 两次反转等价于单词顺序反转
   - `"abc def"` -> `"fed cba"` -> `"def abc"`

4. **空格处理**：
   - 前导空格、尾随空格
   - 单词间多个空格
   - 结果中只保留单个空格

5. **Python 字符串不可变**：
   - 无法真正实现 O(1) 空间的原地修改
   - 可以转为列表操作，再转回字符串

## 易错点

1. **split() 的参数**：
   - `s.split()` 和 `s.split(' ')` 不同
   - 前者处理多个空格，后者把每个空格都作为分隔符

2. **空字符串的处理**：
   - `"   ".split()` 返回 `[]`，需要判断

3. **最后一个单词**：
   - 遍历时不要遗漏最后一个单词
   - 可以在字符串末尾添加哨兵空格

4. **结果末尾的空格**：
   - join 后不会有尾随空格
   - 手动拼接时注意最后一个单词后不加空格

5. **边界情况**：
   - 只有一个单词
   - 全是空格
   - 没有空格
