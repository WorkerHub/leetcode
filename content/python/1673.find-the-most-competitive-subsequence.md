## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，返回最具**竞争力**的 `k` 个元素组成的子序列。

数组的**竞争力**：在第一个不同的位置，字典序较小的子序列更具竞争力。

**示例：**
```
输入：nums = [3,5,2,6], k = 2
输出：[2,6]
解释：[2,6] 比 [3,5]、[3,6]、[5,6] 都更小
```

## 解题思路

**单调栈（贪心）：**

维护一个单调递增栈（长度不超过 k）：
- 若当前元素 < 栈顶元素，且**还能保证栈中有足够元素**（`len(stack) + remaining > k`），则弹出栈顶
- 若栈长度 < k，将当前元素压栈

## 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def mostCompetitive(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        stack = []
        
        for i, num in enumerate(nums):
            # 可以弹出的条件：栈不空 + 当前元素更小 + 后面还有足够元素
            while stack and num < stack[-1] and len(stack) + (n - i) > k:
                stack.pop()
            
            if len(stack) < k:
                stack.append(num)
        
        return stack
```

### 方法二：最小堆方法（理解用）

```python
from typing import List
import heapq

class Solution:
    def mostCompetitive(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        # 在所有 k 大小子序列中找最具竞争力的
        # 等价于：贪心选取最小可能值，保证后续有足够元素
        
        result = []
        heap = [(nums[i], i) for i in range(n)]
        heapq.heapify(heap)
        
        last_idx = -1
        for _ in range(k):
            # 找最小的、下标大于 last_idx 且后续还有足够元素的
            temp = []
            while heap:
                val, idx = heapq.heappop(heap)
                # 需要后面还有 k - len(result) - 1 个元素
                remaining_needed = k - len(result) - 1
                if idx > last_idx and (n - idx - 1) >= remaining_needed:
                    result.append(val)
                    last_idx = idx
                    # 将 temp 中的元素放回
                    for item in temp:
                        heapq.heappush(heap, item)
                    break
                else:
                    temp.append((val, idx))
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单调栈 | O(n) | O(k) |
| 最小堆 | O(n log n) | O(n) |

## 关键点总结

1. 单调递增栈：维护当前最具竞争力的子序列候选
2. 弹出条件：当前元素更小 + 剩余元素足够凑成 k 个
3. `len(stack) + (n - i) > k` 确保弹出后还能凑够 k 个

## 易错点

- 弹出条件必须确保后面有足够元素：`len(stack) + (n - i) > k`（此时 n-i 是从当前位置 i 到末尾的元素数，含当前元素）
- 压栈条件：`len(stack) < k`（不能超过 k 个）
- 最终栈就是答案（已是有序的 k 个元素）
