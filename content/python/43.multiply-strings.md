## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积，它们的乘积也表示为字符串形式。

**注意：** 不能使用任何内置的大数库或直接将输入转换为整数。

**示例 1：**
```
输入：num1 = "2", num2 = "3"
输出："6"
```

**示例 2：**
```
输入：num1 = "123", num2 = "456"
输出："56088"
```

**提示：**
- `1 <= num1.length, num2.length <= 200`
- `num1` 和 `num2` 只能由数字组成
- `num1` 和 `num2` 都不包含任何前导零，除了数字0本身

## 解题思路

核心思想：模拟竖式乘法

关键观察：
- num1[i] × num2[j] 的结果位于 result[i+j] 和 result[i+j+1]
- 长度为 m 和 n 的数相乘，结果最多 m+n 位

## Python 代码实现

```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"
        
        m, n = len(num1), len(num2)
        result = [0] * (m + n)
        
        # 从右向左遍历
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                # 两位数字相乘
                mul = int(num1[i]) * int(num2[j])
                # 结果位置
                p1, p2 = i + j, i + j + 1
                # 加上之前的进位
                total = mul + result[p2]
                
                result[p2] = total % 10
                result[p1] += total // 10
        
        # 转换为字符串，跳过前导零
        result_str = ''.join(map(str, result))
        return result_str.lstrip('0') or '0'
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m + n)

## 关键点总结

1. **位置关系**：i × j 的结果在 i+j 和 i+j+1 位置
2. **进位处理**：每次计算要加上之前的进位
3. **前导零**：最后去除前导零

## 易错点

1. **特殊情况**：任一为 "0" 直接返回 "0"
2. **索引计算**：注意 p1 和 p2 的位置关系
