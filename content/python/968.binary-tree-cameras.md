## 题目描述

给定一个二叉树，我们在树的节点上安装摄像头。

节点上的每个摄像头都可以监视**其父对象、自身及其直接子对象**。

计算监控树的所有节点所需的最小摄像头数量。

**示例 1：**
```
输入：[0,0,null,0,0]
输出：1
解释：如图所示，一台摄像头足以监控所有节点。
```

**示例 2：**
```
输入：[0,0,null,0,null,0,null,null,0]
输出：2
解释：需要至少两个摄像头。
```

**提示：**
- 给定树的节点数的范围是 `[1, 1000]`
- 每个节点的值都是 `0`

## 解题思路

这是一道经典的树形 DP + 贪心问题。

**核心思想：**
1. 贪心策略：优先在叶子节点的父节点放置摄像头
2. 状态定义：每个节点有三种状态
   - 状态 0：该节点未被监控（需要父节点或子节点的摄像头覆盖）
   - 状态 1：该节点有摄像头
   - 状态 2：该节点被监控（但自己没有摄像头）
3. 自底向上遍历，根据子节点状态决定当前节点状态

**状态转移：**
- 如果子节点有"未被监控"的，当前节点必须放摄像头
- 如果子节点有"有摄像头"的，当前节点被监控
- 如果子节点都是"被监控"的，当前节点不放摄像头（让父节点决定）

## Python 代码实现

### 方法一：贪心 + DFS（推荐）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minCameraCover(self, root: Optional[TreeNode]) -> int:
        self.cameras = 0
        
        # 状态定义
        # 0: 该节点未被监控
        # 1: 该节点有摄像头
        # 2: 该节点被监控（但没有摄像头）
        
        def dfs(node):
            """返回节点的状态"""
            if not node:
                # 空节点视为已被监控（不需要摄像头）
                return 2
            
            # 递归处理左右子树
            left = dfs(node.left)
            right = dfs(node.right)
            
            # 如果左右子节点有任意一个未被监控，当前节点必须放摄像头
            if left == 0 or right == 0:
                self.cameras += 1
                return 1
            
            # 如果左右子节点至少有一个有摄像头，当前节点被监控
            if left == 1 or right == 1:
                return 2
            
            # 如果左右子节点都被监控，当前节点不放摄像头
            # 返回 0，让父节点决定
            return 0
        
        # 处理根节点
        if dfs(root) == 0:
            # 如果根节点未被监控，必须在根节点放摄像头
            self.cameras += 1
        
        return self.cameras
```

### 方法二：树形 DP

```python
class Solution:
    def minCameraCover(self, root: Optional[TreeNode]) -> int:
        def dfs(node):
            """
            返回三元组 (a, b, c)
            a: 以 node 为根的子树被完全覆盖，且 node 没有摄像头的最少摄像头数
            b: 以 node 为根的子树被完全覆盖，且 node 有摄像头的最少摄像头数
            c: 以 node 为根的子树不一定被完全覆盖的最少摄像头数
            """
            if not node:
                # 空节点不需要摄像头，且被覆盖
                return (0, float('inf'), 0)
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            # node 没有摄像头：左右子树都必须被覆盖，且至少一个有摄像头
            a = min(left[1] + right[1], 
                    left[1] + right[0], 
                    left[0] + right[1])
            
            # node 有摄像头：左右子树选择最优情况
            b = 1 + min(left[0], left[1], left[2]) + min(right[0], right[1], right[2])
            
            # 不一定完全覆盖：左右子树都没有摄像头
            c = left[0] + right[0]
            
            return (a, b, c)
        
        result = dfs(root)
        # 根节点必须被覆盖，选择 a 和 b 的最小值
        return min(result[0], result[1])
```

### 方法三：后序遍历 + 状态机

```python
class Solution:
    def minCameraCover(self, root: Optional[TreeNode]) -> int:
        NOT_MONITORED = 0
        HAS_CAMERA = 1
        MONITORED = 2
        
        self.count = 0
        
        def postorder(node):
            if not node:
                return MONITORED
            
            left_state = postorder(node.left)
            right_state = postorder(node.right)
            
            # 如果有子节点未被监控，当前节点必须放摄像头
            if left_state == NOT_MONITORED or right_state == NOT_MONITORED:
                self.count += 1
                return HAS_CAMERA
            
            # 如果有子节点有摄像头，当前节点被监控
            if left_state == HAS_CAMERA or right_state == HAS_CAMERA:
                return MONITORED
            
            # 如果子节点都被监控，当前节点暂不放摄像头
            return NOT_MONITORED
        
        # 如果根节点未被监控，需要加一个摄像头
        if postorder(root) == NOT_MONITORED:
            self.count += 1
        
        return self.count
```

### 方法四：优化的贪心

```python
class Solution:
    def minCameraCover(self, root: Optional[TreeNode]) -> int:
        self.res = 0
        
        def dfs(node):
            # 返回值：0-未覆盖，1-有摄像头，2-已覆盖
            if not node:
                return 2
            
            l, r = dfs(node.left), dfs(node.right)
            
            # 如果子节点未覆盖，当前节点必须放摄像头
            if l == 0 or r == 0:
                self.res += 1
                return 1
            
            # 如果子节点有摄像头，当前节点被覆盖
            if l == 1 or r == 1:
                return 2
            
            # 子节点都已覆盖，当前节点未覆盖
            return 0
        
        # 根节点特殊处理
        return self.res + (dfs(root) == 0)
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，递归栈深度，h 是树的高度

## 关键点总结

1. **贪心策略**：从叶子节点往上，优先在叶子的父节点放摄像头
2. **状态设计**：三种状态清晰表示节点的监控情况
3. **自底向上**：后序遍历，根据子节点状态决定当前节点
4. **根节点处理**：最后要检查根节点是否被监控
5. **空节点定义**：空节点视为已被监控，简化逻辑

## 易错点

1. **空节点状态**：应该返回"已监控"，不是"未监控"
2. **根节点检查**：递归结束后要检查根节点状态
3. **状态转移**：子节点状态和当前节点状态的对应关系
4. **初始化**：摄像头计数器要初始化为 0
5. **叶子节点**：叶子节点返回"未监控"，由父节点放摄像头
