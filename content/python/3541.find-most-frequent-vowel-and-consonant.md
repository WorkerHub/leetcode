## 题目描述

给定一个只含小写字母的字符串 `s`，找出出现频率最高的元音字母和出现频率最高的辅音字母，返回它们的频率之和。如果有多个频率相同的元音或辅音，取其中任意一个即可。

**示例 1：**

```
输入：s = "aeioubc"
输出：2
解释：频率最高的元音是 a/e/i/o/u（各出现1次），最高辅音是 b/c（各1次）。
     1 + 1 = 2。
```

**示例 2：**

```
输入：s = "aabbcc"
输出：4
解释：最高频元音是 a（2次），最高频辅音是 b 或 c（2次）。2+2=4。
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只含小写字母

## 解题思路

统计每个字母的频率，分别找元音和辅音中的最大频率，相加返回。

元音集合：`{'a', 'e', 'i', 'o', 'u'}`

## Python 代码实现

### 方法一：Counter 统计（推荐）

```python
from collections import Counter

class Solution:
    def maxFreqVowelConsonant(self, s: str) -> int:
        vowels = set('aeiou')
        cnt = Counter(s)

        max_vowel = max((freq for c, freq in cnt.items() if c in vowels), default=0)
        max_consonant = max((freq for c, freq in cnt.items() if c not in vowels), default=0)

        return max_vowel + max_consonant
```

### 方法二：分别统计

```python
class Solution:
    def maxFreqVowelConsonant(self, s: str) -> int:
        vowels = set('aeiou')
        vowel_freq = {}
        consonant_freq = {}

        for c in s:
            if c in vowels:
                vowel_freq[c] = vowel_freq.get(c, 0) + 1
            else:
                consonant_freq[c] = consonant_freq.get(c, 0) + 1

        max_v = max(vowel_freq.values()) if vowel_freq else 0
        max_c = max(consonant_freq.values()) if consonant_freq else 0

        return max_v + max_c
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(1)，字符集大小固定为 26

## 关键点总结

1. 元音集合：a, e, i, o, u
2. 其余字母为辅音
3. 分别找两类中的最大频率，相加

## 易错点

1. 字符串中可能不含元音或不含辅音，用 `default=0` 处理
2. 只需要频率，不需要具体是哪个字母
3. 多个并列最大值时取任意一个（题目允许）
