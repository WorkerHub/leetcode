## 题目描述

给你一棵 **二叉搜索树** 的根节点 `root`，和一个由正整数组成的数组 `queries`。

对于每个查询 `queries[i]`，你需要找出两个值 `mini` 和 `maxi`：

- `mini`：树中 **小于等于** `queries[i]` 的 **最大值**。如果不存在，则使用 `-1` 代替。
- `maxi`：树中 **大于等于** `queries[i]` 的 **最小值**。如果不存在，则使用 `-1` 代替。

返回一个大小为 `queries.length` 的二维整数数组 `answer`，其中 `answer[i] = [mini, maxi]`。

**提示：**
- 树中节点数目在范围 `[2, 10^5]` 内
- `1 <= Node.val, queries[i] <= 10^6`

## 解题思路

**中序遍历 + 二分查找：**

BST 的中序遍历结果是有序数组。

1. 中序遍历 BST，得到有序数组 `sorted_vals`
2. 对每个查询 `q`：
   - 用 `bisect_right(sorted_vals, q) - 1` 找 `<= q` 的最大值
   - 用 `bisect_left(sorted_vals, q)` 找 `>= q` 的最小值

## 代码实现

### 方法一：中序遍历 + 二分查找（推荐）

```python
from typing import Optional, List
import bisect

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def closestNodes(self, root: Optional[TreeNode], queries: List[int]) -> List[List[int]]:
        # 中序遍历得到有序数组
        sorted_vals = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)
            sorted_vals.append(node.val)
            inorder(node.right)

        inorder(root)

        ans = []
        for q in queries:
            # 找 <= q 的最大值
            idx = bisect.bisect_right(sorted_vals, q) - 1
            mini = sorted_vals[idx] if idx >= 0 else -1

            # 找 >= q 的最小值
            idx2 = bisect.bisect_left(sorted_vals, q)
            maxi = sorted_vals[idx2] if idx2 < len(sorted_vals) else -1

            ans.append([mini, maxi])

        return ans
```

### 方法二：直接 BST 搜索（不依赖中序遍历）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def closestNodes(self, root: Optional[TreeNode], queries: List[int]) -> List[List[int]]:
        def search(root, q):
            mini, maxi = -1, -1
            node = root
            while node:
                if node.val == q:
                    return [q, q]
                elif node.val < q:
                    mini = node.val
                    node = node.right
                else:
                    maxi = node.val
                    node = node.left
            return [mini, maxi]

        return [search(root, q) for q in queries]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 中序 + 二分 | O(n + q log n) | O(n) |
| BST 搜索 | O(q * h)（h 为树高）| O(h) |

注意：BST 可能不平衡，高度可能为 O(n)，而中序+二分保证 O(log n) 查询。

## 关键点总结

1. BST 中序遍历结果有序，可以直接二分查找
2. `bisect_right(arr, q) - 1` 找最大的 `<= q` 的元素
3. `bisect_left(arr, q)` 找最小的 `>= q` 的元素

## 易错点

- 索引越界时（idx < 0 或 idx >= len）返回 -1
- 若直接 BST 搜索，树可能退化为链表，需要用中序遍历方法
