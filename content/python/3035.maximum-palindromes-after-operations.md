## 题目描述

给你一个字符串数组 `words`。

每次操作，你可以交换任意两个字符串中同一或不同位置的字符（即可以任意重新分配所有字符）。

返回最多能构成多少个回文字符串（从 `words` 数组中）。

**示例 1：**
```
输入：words = ["abbb","ba","aa"]
输出：3
```

**示例 2：**
```
输入：words = ["abc","ab"]
输出：2
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 100`
- `words[i]` 只包含小写英文字母

## 解题思路

字符可以自由重新分配给任意字符串，但每个字符串的**长度不变**。

1. 统计所有字符的总频率
2. 能配对的字符（频率 >= 2 的部分）可以放在回文的两侧
3. 剩余的奇数字符可以放在回文的中间（每个回文只能有一个中间字符）

贪心策略：
1. 统计所有字符的频率，计算"配对数"（每种字符 `freq // 2`）
2. 将字符串按长度排序
3. 对每个字符串，需要 `len // 2` 对字符填充两侧，可能还需要 1 个奇数字符（当 `len` 为奇数时）
4. 贪心地满足最短字符串的需求（因为短字符串需要的配对数少，更容易满足）

## Python 代码实现

### 方法一：贪心分配（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxPalindromesAfterOperations(self, words: List[int]) -> int:
        # 统计所有字符频率
        freq = Counter()
        for word in words:
            freq.update(word)

        # 总配对数（每种字符 freq // 2）
        pairs = sum(v // 2 for v in freq.values())
        # 总单字符数（奇数频率的字符）
        singles = sum(v % 2 for v in freq.values())

        # 按长度从小到大排序（贪心地先满足短字符串）
        lengths = sorted(len(w) for w in words)

        ans = 0
        for length in lengths:
            need_pairs = length // 2     # 需要的配对数
            need_single = length % 2     # 需要奇数中间字符（0 或 1）

            if pairs >= need_pairs:
                pairs -= need_pairs
                ans += 1
                # 若需要中间字符
                if need_single:
                    if singles > 0:
                        singles -= 1
                    else:
                        # 拆一对来当中间字符
                        pairs -= 1
                        singles += 1
                        if pairs < 0:
                            # 无法构成回文
                            ans -= 1
                            # 恢复
                            pairs += 1
                            break
            else:
                break  # 配对数不足，后面更长的字符串也无法满足

        return ans
```

### 方法二：更简洁版

```python
from typing import List
from collections import Counter

class Solution:
    def maxPalindromesAfterOperations(self, words: List[int]) -> int:
        freq = Counter(c for w in words for c in w)
        pairs = sum(v // 2 for v in freq.values())
        odds = sum(v % 2 for v in freq.values())

        lengths = sorted(len(w) for w in words)
        ans = 0

        for length in lengths:
            half = length // 2
            need_mid = length % 2

            if pairs < half:
                break

            pairs -= half
            ans += 1

            if need_mid:
                if odds > 0:
                    odds -= 1
                else:
                    # 从配对中拆出一个
                    pairs -= 1
                    odds += 1  # 多出一个单字符，但不需要了

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * L + n log n)，n 为字符串数，L 为平均长度
- 空间复杂度：O(1)（字符集大小 26）

## 关键点总结

1. 字符可以自由移动，只有总字符频率限制
2. 回文需要：`length//2` 对字符 + 可能的 1 个中间字符（奇数长度）
3. 贪心：按长度从小到大排序，优先满足短字符串

## 易错点

1. 奇数长度的字符串需要一个中间字符，但这个字符可以从任何奇数频率字符中取
2. 若没有奇数频率字符，可以拆一个配对来当中间字符（配对数减 1）
3. 排序后若配对数不够，后续更长的字符串必然也不够
