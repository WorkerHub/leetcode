## 题目描述

给你三个整数 `n`、`k` 和 `x`，返回满足以下条件的长度为 `n` 的数组数量（每个元素在 0 到 k 之间）：所有元素的 XOR 等于 x。结果对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 2, k = 3, x = 2
输出：2
解释：[0,2] 和 [2,0] 满足 XOR=2
实际：[0,2],[2,0],[1,3],[3,1]，共4个？需确认k约束
```

**示例 2：**

```
输入：n = 3, k = 2, x = 1
输出：6
```

**提示：**

- `1 <= n <= 10^5`
- `0 <= k <= 10^9`
- `0 <= x <= k`

## 解题思路

用 DP：`dp[i][v]` = 前 `i` 个元素的 XOR 为 `v` 的方案数。

但 v 的范围可能很大（最大为 k），需要逐位分析。

**逐位分析**：对每一位，独立计算满足条件的方案数，再乘起来。

对第 `b` 位，`x` 的第 `b` 位为 `xb`：
- 每个元素该位可以是 0 或 1（若 k 允许）
- `n` 个元素中该位 XOR 为 `xb`：即 1 的个数为奇偶性与 `xb` 相同
- 方案数 = `sum(C(n, j) for j 满足 j % 2 == xb % 2) * (按位可选方案)`

## Python 代码实现

### 方法一：按位 DP（推荐）

```python
class Solution:
    def countArrays(self, n: int, k: int, x: int) -> int:
        MOD = 10 ** 9 + 7
        ans = 1

        for bit in range(30):
            kb = (k >> bit) & 1  # k 在第 bit 位的值
            xb = (x >> bit) & 1  # x 在第 bit 位的值

            if kb == 0:
                # 所有元素此位只能为 0
                if xb != 0:
                    return 0  # XOR 要求该位为 1，但所有元素只能为 0
                # 方案数：1（只有全0一种选择）
            else:
                # 每个元素此位可以是 0 或 1
                # 统计 n 个 0/1 中有奇数个 1 的方案数
                from math import comb
                if xb == 1:
                    ways = sum(comb(n, j) for j in range(1, n + 1, 2)) % MOD
                else:
                    ways = sum(comb(n, j) for j in range(0, n + 1, 2)) % MOD
                ans = ans * ways % MOD

        return ans
```

### 方法二：数学公式

```python
class Solution:
    def countArrays(self, n: int, k: int, x: int) -> int:
        MOD = 10 ** 9 + 7
        # 奇数个1的总数 = 2^(n-1)，偶数个1的总数也 = 2^(n-1)
        half = pow(2, n - 1, MOD)
        ans = 1

        for bit in range(30):
            kb = (k >> bit) & 1
            xb = (x >> bit) & 1
            if kb == 0:
                if xb != 0:
                    return 0
            else:
                ans = ans * half % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(30)
- 空间复杂度：O(1)

## 关键点总结

1. 每位独立处理，总方案数为各位方案数之积
2. 若 k 的第 b 位为 0，所有元素该位只能是 0
3. 若 k 的第 b 位为 1，每个元素该位可独立选 0 或 1
4. 奇数个 1 和偶数个 1 各有 `2^(n-1)` 种方案

## 易错点

1. k 约束作用于每一位，不是简单的 <= k（更复杂情况需数位 DP）
2. `2^(n-1)` 的公式适用于每位可任选 0/1 的情况
3. x 的每一位必须与数组 XOR 对应位匹配
