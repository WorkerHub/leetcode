## 题目描述

给你一个整数数组 `jobs`，其中 `jobs[i]` 是完成第 `i` 项工作的时间。

现有 `k` 名工人可以同时做工，帮你完成这些工作。每名工人**最多**只能做两项工作，且工人之间的工作量相互独立。

请你设计一套最佳的工作分配方案，使工人的最大工作时间最短，并返回最大工作时间的**最小值**。

**示例 1：**
```
输入：jobs = [3,2,3], k = 3
输出：3
```

**示例 2：**
```
输入：jobs = [1,2,4,7,8], k = 2
输出：11
```

**提示：**
- `1 <= k <= jobs.length <= 12`
- `1 <= jobs[i] <= 10^7`

## 解题思路

**状态压缩 DP**：
- 用位掩码 `mask` 表示已分配的工作子集
- `dp[mask]` = 用尽量少的工人完成 mask 对应工作时，所有工人的工作时间之和中，分配了 `ceil(popcount(mask)/?)` 个工人...

更好的方式：
- `sum[mask]` = mask 中工作的总时间
- `dp[j][mask]` = 用 j 个工人完成 mask 中所有工作时，最大工作时间的最小值
- 枚举 mask 的子集 sub，分配给第 j 个工人

也可以用二分 + 回溯解决。

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        n = len(jobs)
        total_masks = 1 << n
        
        # 预计算每个子集的工作时间总和
        subset_sum = [0] * total_masks
        for mask in range(1, total_masks):
            # 找最低位的 1
            lsb = mask & (-mask)
            bit = lsb.bit_length() - 1
            subset_sum[mask] = subset_sum[mask ^ lsb] + jobs[bit]
        
        # dp[mask] = 将 mask 中工作分配给若干工人时，最大工作时间的最小值
        # 用 k 个工人的滚动 DP
        INF = float('inf')
        dp = [INF] * total_masks
        dp[0] = 0
        
        for j in range(k):
            # 每次迭代代表多一个工人
            new_dp = dp[:]
            for mask in range(total_masks):
                if dp[mask] == INF:
                    continue
                # 枚举 mask 的补集（剩余未分配的工作）的子集
                remaining = (total_masks - 1) ^ mask
                sub = remaining
                while sub > 0:
                    new_mask = mask | sub
                    new_dp[new_mask] = min(new_dp[new_mask],
                                          max(dp[mask], subset_sum[sub]))
                    sub = (sub - 1) & remaining
            dp = new_dp
        
        return dp[total_masks - 1]
```

### 方法二：回溯 + 剪枝

```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        jobs.sort(reverse=True)  # 降序排列，优先分配大任务（剪枝更有效）
        n = len(jobs)
        worker_time = [0] * k
        self.ans = sum(jobs)
        
        def backtrack(idx):
            if idx == n:
                self.ans = min(self.ans, max(worker_time))
                return
            
            seen = set()
            for i in range(k):
                if worker_time[i] in seen:
                    continue  # 跳过相同工作量的工人（避免重复搜索）
                if worker_time[i] + jobs[idx] >= self.ans:
                    continue  # 剪枝
                seen.add(worker_time[i])
                worker_time[i] += jobs[idx]
                backtrack(idx + 1)
                worker_time[i] -= jobs[idx]
        
        backtrack(0)
        return self.ans
```

## 复杂度分析

- **方法一**：时间 O(k * 3^n)（枚举子集），空间 O(2^n)
- **方法二**：最坏 O(k^n)，剪枝后实际较快

## 关键点总结

1. 状态压缩 DP 适合 n <= 20 的情况
2. 枚举子集时用 `sub = (sub - 1) & mask` 遍历所有子集
3. 回溯中降序排列和跳过相同工作量的工人是关键剪枝

## 易错点

- 子集枚举的边界（空集 sub=0 通常单独处理）
- 状态压缩 DP 中 dp 数组需要用滚动数组更新，防止同一轮重复使用
