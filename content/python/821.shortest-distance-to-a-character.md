## 题目描述

给你一个字符串 `s` 和一个字符 `c`，且 `c` 是 `s` 中出现过的字符。

返回一个整数数组 `answer`，其中 `answer.length == s.length` 且 `answer[i]` 是 `s` 中从下标 `i` 到离它 **最近** 的字符 `c` 的 **距离**。

两个下标 `i` 和 `j` 之间的 **距离** 为 `abs(i - j)`，其中 `abs` 是绝对值函数。

**示例 1:**
```
输入: s = "loveleetcode", c = "e"
输出: [3,2,1,0,1,0,0,1,2,2,1,0]
解释: 字符 'e' 出现在下标 3、5、6 和 11 处（下标从 0 开始计数）。
距下标 0 最近的 'e' 出现在下标 3 ，所以距离为 abs(0 - 3) = 3 。
距下标 1 最近的 'e' 出现在下标 3 ，所以距离为 abs(1 - 3) = 2 。
对于下标 4 ，出现在下标 3 和下标 5 处的 'e' 都离它最近，但距离是一样的 abs(4 - 3) == abs(4 - 5) = 1 。
距下标 8 最近的 'e' 出现在下标 6 ，所以距离为 abs(8 - 6) = 2 。
```

**示例 2:**
```
输入: s = "aaab", c = "b"
输出: [3,2,1,0]
```

**提示:**
- `1 <= s.length <= 10^4`
- `s[i]` 和 `c` 均为小写英文字母
- 题目数据保证 `c` 在 `s` 中至少出现一次

## 解题思路

**两次遍历法：**
1. 从左到右遍历，记录每个位置到左边最近 `c` 的距离
2. 从右到左遍历，更新为到两边最近 `c` 的最小距离

## Python 代码实现

### 方法一：两次遍历（推荐）⭐

```python
from typing import List

class Solution:
    def shortestToChar(self, s: str, c: str) -> List[int]:
        n = len(s)
        result = [float('inf')] * n
        
        # 从左到右：记录到左边最近 c 的距离
        prev = float('-inf')
        for i in range(n):
            if s[i] == c:
                prev = i
            result[i] = abs(i - prev)
        
        # 从右到左：更新到右边最近 c 的距离
        prev = float('inf')
        for i in range(n - 1, -1, -1):
            if s[i] == c:
                prev = i
            result[i] = min(result[i], abs(i - prev))
        
        return result
```

### 方法二：记录所有位置

```python
from typing import List
import bisect

class Solution:
    def shortestToChar(self, s: str, c: str) -> List[int]:
        # 找到所有 c 的位置
        positions = [i for i, char in enumerate(s) if char == c]
        
        result = []
        for i in range(len(s)):
            # 二分查找最近的 c 位置
            idx = bisect.bisect_left(positions, i)
            
            min_dist = float('inf')
            if idx < len(positions):
                min_dist = min(min_dist, abs(i - positions[idx]))
            if idx > 0:
                min_dist = min(min_dist, abs(i - positions[idx - 1]))
            
            result.append(min_dist)
        
        return result
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n)，两次遍历
- **空间复杂度**：O(n)，结果数组

### 方法二：
- **时间复杂度**：O(n log m)，m 是 c 出现次数
- **空间复杂度**：O(m + n)

## 关键点总结

1. **两次遍历**：分别处理左右方向
2. **距离更新**：取两个方向的最小值
3. **边界处理**：使用无穷大作为初始值

## 易错点

1. **初始值**：prev 应该是正/负无穷
2. **绝对值**：距离是绝对值
3. **最小值更新**：需要比较左右两个方向
