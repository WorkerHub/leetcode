## 题目描述

给你一个二维整数数组 `items`，`items[i] = [price_i, beauty_i]` 描述第 `i` 件物品的价格和美丽值。

另给你一个整数数组 `queries`，对于每个查询 `queries[j]`，找出价格**不超过** `queries[j]` 的最大美丽值，若无则为 0。

每个查询独立，不相互影响。

**示例 1：**
```
输入：items = [[1,2],[3,2],[2,4],[5,6],[3,5]], queries = [1,2,3,4,5,6]
输出：[2,4,5,5,6,6]
```

**提示：**
- `1 <= items.length, queries.length <= 10^5`
- `items[i].length == 2`
- `1 <= price_i, beauty_i <= 10^9`
- `1 <= queries[j] <= 10^9`

## 解题思路

1. 对 `items` 按价格排序
2. 构建"单调递增的最大美丽值"数组：遍历排序后的物品，维护前缀最大美丽值
3. 对每个查询，二分查找最大价格 <= query 的位置，返回该位置的最大美丽值

## 代码实现

### 方法一：排序 + 前缀最大 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumBeauty(self, items: List[List[int]], queries: List[int]) -> List[int]:
        # 按价格排序
        items.sort(key=lambda x: x[0])

        # 构建前缀最大美丽值数组
        prices = []
        max_beauties = []
        cur_max = 0
        for price, beauty in items:
            cur_max = max(cur_max, beauty)
            prices.append(price)
            max_beauties.append(cur_max)

        # 对每个查询二分查找
        result = []
        for q in queries:
            pos = bisect.bisect_right(prices, q) - 1
            result.append(max_beauties[pos] if pos >= 0 else 0)

        return result
```

### 方法二：离线排序查询

```python
from typing import List

class Solution:
    def maximumBeauty(self, items: List[List[int]], queries: List[int]) -> List[int]:
        items.sort(key=lambda x: x[0])
        n = len(queries)
        result = [0] * n

        # 将查询与原始下标一起排序
        sorted_queries = sorted(enumerate(queries), key=lambda x: x[1])

        j = 0
        cur_max = 0
        for idx, q in sorted_queries:
            # 加入所有价格 <= q 的物品
            while j < len(items) and items[j][0] <= q:
                cur_max = max(cur_max, items[j][1])
                j += 1
            result[idx] = cur_max

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+二分 | O((n+q) log n) | O(n) |
| 离线排序 | O((n+q) log(n+q)) | O(q) |

## 关键点总结

1. 排序后构建前缀最大美丽值，使每个位置存储"到此价格的最大美丽值"
2. 二分查找找到价格 <= q 的最后一个位置
3. 离线方法：将查询排序后，用双指针同步遍历

## 易错点

- 注意前缀最大值要在 items 排序后构建（不是原始顺序）
- 若 `pos < 0`（所有价格都超过 q），返回 0
- 多个相同价格的物品，前缀最大值会选最大美丽
