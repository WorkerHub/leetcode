## 题目描述

给你一个字符串 `word`，该字符串由数字和小写英文字母组成。

请你用空格替换每个不是数字的字符，然后将所有 **不同** 的数字组成一个集合，返回集合的大小。

**注意：** 数字前面可能有前导零，不同的数字指的是数值上不同。

**示例 1：**
```
输入：word = "a123bc34d8ef34"
输出：3
解释：不同的数字有 123、34、8
```

**示例 2：**
```
输入：word = "leet1234code234"
输出：2
```

**示例 3：**
```
输入：word = "a1b01c001"
输出：1
解释：数字 1、01、001 的值相同，只有一个不同的整数
```

**提示：**
- `1 <= word.length <= 1000`
- `word` 只包含小写英文字母和数字

## 解题思路

将字符串中的非数字字符视为分隔符，提取出所有数字片段，去除前导零后加入集合，最终返回集合大小。

关键点：数值相等（前导零不影响值），可以用字符串去除前导零后比较，或转为整数比较。由于数字可能很长（超过 int 范围），建议用字符串去除前导零后存入集合。

## 代码实现

### 方法一：正则提取 + 集合去重（推荐）

```python
import re

class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        # 用非数字字符分割，提取所有数字字符串
        nums = re.findall(r'\d+', word)
        # 去除前导零后加入集合（用 lstrip 去掉前导零）
        unique = set()
        for num in nums:
            # lstrip('0') 去掉前导零；若全为 0，结果为空字符串，用 or '0' 补充
            unique.add(num.lstrip('0'))
        return len(unique)
```

### 方法二：手动扫描字符串

```python
class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        unique = set()
        i = 0
        n = len(word)
        while i < n:
            if word[i].isdigit():
                # 找到数字段的起始位置，跳过前导零
                while i < n and word[i] == '0':
                    i += 1
                # 收集后续数字
                start = i
                while i < n and word[i].isdigit():
                    i += 1
                unique.add(word[start:i])  # 已去除前导零
            else:
                i += 1
        return len(unique)
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(n)，集合中存储数字字符串

## 关键点总结

1. 前导零不影响数值，需要在去重前统一去除前导零
2. 用 `lstrip('0')` 去除前导零时，若字符串全为 0，结果为空字符串（代表数值 0）
3. 正则 `\d+` 可以快速提取所有数字片段

## 易错点

- 忘记处理前导零，导致 "01" 和 "1" 被视为不同的数
- 全为 0 的字符串（如 "000"）去除前导零后为空字符串，需注意集合中空字符串的语义
