## 题目描述

给你两个整数数组 `hens` 和 `grains`，分别表示母鸡的位置和谷粒的位置。所有母鸡同时开始移动，每秒钟每只母鸡可以移动一步。母鸡吃掉谷粒时需要在同一位置。每只母鸡最多吃一粒谷粒，且谷粒一旦被吃就消失。

返回所有谷粒被吃完所需的最短时间。

**示例 1：**
```
输入：hens = [3,6,7], grains = [2,4,7,9]
输出：2
解释：母鸡 3 吃谷粒 2（1步），母鸡 6 吃谷粒 4（2步），母鸡 7 吃谷粒 7（0步）和 9（2步）
最大时间为 2
```

**示例 2：**
```
输入：hens = [4,6,109,111,213,215], grains = [5,110,214]
输出：1
```

**数据范围：**
- 1 <= hens.length, grains.length <= 2 * 10^4
- 0 <= hens[i], grains[i] <= 10^9

## 解题思路

二分答案 + 贪心验证：

二分时间 `t`，验证在时间 `t` 内是否能吃完所有谷粒：
- 对 `hens` 和 `grains` 排序
- 贪心匹配：用双指针，每只母鸡尽量多吃靠近自己的谷粒
- 对于母鸡 `h` 在时间 `t` 内，可以吃到的谷粒区间为 `[h - t, h + t]`（但走两端需要额外距离）
- 若向左走再向右走，最远右边界为 `h + t - 2 * max(0, h - grain_left)`
- 若向右走再向左走，最远右边界为 `h + t`（不需要回头）

## Python 代码实现

### 方法一：二分 + 贪心双指针（推荐）

```python
from typing import List
import bisect

class Solution:
    def minimumTime(self, hens: List[int], grains: List[int]) -> int:
        hens.sort()
        grains.sort()
        n_h, n_g = len(hens), len(grains)

        def can_eat_all(t: int) -> bool:
            # j 指向当前待吃的谷粒
            j = 0
            for h in hens:
                if j >= n_g:
                    break
                # 当前谷粒已在母鸡可达范围之前，跳过不能吃的
                if grains[j] < h - t:
                    return False
                # 母鸡 h 在时间 t 内最远能吃到右边哪粒谷粒？
                # 情况1：只向右走，最远到 h + t
                # 情况2：先向左走到 grains[j]（距离 h - grains[j]），再向右走
                #        剩余时间 t - (h - grains[j])，还可往右走到
                #        h + (t - 2*(h - grains[j]))
                # 取两种情况的最大右边界
                if grains[j] <= h:
                    left_dist = h - grains[j]
                    # 先左后右 or 先右后左
                    right_bound = max(h + t - 2 * left_dist, h + t // 2 if False else h + t - left_dist)
                    # 正确推导：先左再右 => h + (t - 2*left_dist)
                    #           先右再左 => 只到 h（不合理，因为谷粒在左）
                    # 实际最远右边界：
                    right_bound = max(h + t - 2 * left_dist, h + t - left_dist)
                    # 简化：right = h + t - left_dist（先右再回来吃左边的）
                    # 最优策略：right_bound = h + max(t - 2*left_dist, t - left_dist) 取不到
                    # 重新推导：
                    # 方案A：先吃左边所有，再向右走 => right = h + t - 2*left_dist（若 t >= 2*left_dist）
                    # 方案B：先向右走，再回来吃左边 => right = h + (t - left_dist) - left_dist = h + t - 2*left_dist（同）
                    # 方案C：只向右走 => 吃不到左边的谷粒（j仍指向左边谷粒，此方案无效）
                    right_bound = h + t - 2 * left_dist if t >= 2 * left_dist else h - (2 * left_dist - t)
                    if right_bound < 0:
                        right_bound = -(10**18)  # 无法到达
                else:
                    # 谷粒在右边，直接向右走
                    right_bound = h + t

                # 找到所有 <= right_bound 的谷粒（从 j 开始）
                j = bisect.bisect_right(grains, right_bound, j)

            return j >= n_g

        # 二分答案
        lo, hi = 0, max(abs(hens[i] - grains[j])
                        for i in [0, -1] for j in [0, -1]) + max(grains) + 1
        # 更简单的上界
        lo, hi = 0, 2 * 10**9

        while lo < hi:
            mid = (lo + hi) // 2
            if can_eat_all(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：简洁版贪心验证

```python
from typing import List
import bisect

class Solution:
    def minimumTime(self, hens: List[int], grains: List[int]) -> int:
        hens.sort()
        grains.sort()
        ng = len(grains)

        def check(t):
            j = 0
            for h in hens:
                if j == ng:
                    return True
                # 当前最左边待吃谷粒不可达
                if grains[j] < h - t:
                    return False
                # 计算该母鸡能覆盖的最右谷粒位置
                if grains[j] >= h:
                    # 谷粒在右边，直接走
                    right = h + t
                else:
                    # 谷粒在左边，需要绕路
                    left_extra = h - grains[j]
                    # 先左后右 or 先右后左
                    right = h + max(t - 2 * left_extra, t - left_extra)
                j = bisect.bisect_right(grains, right, j)
            return j == ng

        lo, hi = 0, 2 * 10**9
        while lo < hi:
            mid = (lo + hi) >> 1
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O((n + m) log(max_val))，n 和 m 为母鸡和谷粒数量，max_val 为坐标范围
- 空间复杂度：O(1)（排序 O(log n) 额外空间）

## 关键点总结

1. 二分答案，验证给定时间是否可行
2. 贪心：每只母鸡尽量吃最左边的谷粒，向右延伸
3. 绕路计算：若需要先走左再走右，右边界减少 2 倍左侧距离

## 易错点

1. 绕路的代价计算：先向一侧走再折回，距离翻倍
2. 母鸡和谷粒都需要排序
3. 注意谷粒在母鸡左侧和右侧两种情况的边界计算
