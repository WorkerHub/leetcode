## 题目描述

有 `n` 个球排成一行，每个球有颜色 `colors[i]`（整数）。你需要将这些球分成 `k` 组，每组是连续的，且每组中没有重复颜色。

将一组球"分开"的代价是：去掉组内所有重复颜色球的最小操作数（每次操作移除一个球）。

请返回最优分组方案的最小总代价。

**示例 1：**

```
输入：colors = [1,2,1,3,2], k = 2
输出：1
解释：分成 [1,2,1] 和 [3,2]，第一组有重复1，代价1；第二组无重复，代价0；总1
```

**提示：**

- `1 <= k <= colors.length <= 10^4`
- `1 <= colors[i] <= 10^4`

## 解题思路

DP + 贪心：

`dp[i]` = 前 `i` 个球分成若干有效组的最小代价。

对每个右端点 `j`，枚举上一个分割点 `i`，区间 `[i+1, j]` 的代价 = 每种颜色出现次数 - 1 的总和（即重复次数）。

用哈希表维护当前区间的颜色频率，实现 O(n) 的内层遍历。

## Python 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumCost(self, colors: List[int], k: int) -> int:
        n = len(colors)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        for j in range(1, n + 1):
            freq = defaultdict(int)
            cost = 0
            for i in range(j - 1, -1, -1):
                c = colors[i]
                freq[c] += 1
                if freq[c] > 1:
                    cost += 1  # 新增一个重复
                if dp[i] != INF:
                    dp[j] = min(dp[j], dp[i] + cost)

        return dp[n]
```

### 方法二：分段 DP（k 约束）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumCost(self, colors: List[int], k: int) -> int:
        n = len(colors)
        # 预计算每个区间的代价
        cost = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(n):
            freq = defaultdict(int)
            dup = 0
            for j in range(i, n):
                freq[colors[j]] += 1
                if freq[colors[j]] > 1:
                    dup += 1
                cost[i][j] = dup

        # dp[t][i] = 前 i 个球分成 t 组的最小代价
        INF = float('inf')
        dp = [[INF] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0

        for t in range(1, k + 1):
            for j in range(t, n + 1):
                for i in range(t - 1, j):
                    if dp[t - 1][i] != INF:
                        dp[t][j] = min(dp[t][j], dp[t - 1][i] + cost[i][j - 1])

        return dp[k][n]
```

## 复杂度分析

- 时间复杂度：O(n^2)，两层循环
- 空间复杂度：O(n^2)（方法二），O(n)（方法一）

## 关键点总结

1. 每组代价 = 该组中颜色出现次数超过 1 的总数
2. DP 枚举分割点，哈希表维护区间颜色频率
3. 分成 k 组等价于做 k 次分割

## 易错点

1. 代价是重复数（`freq[c] - 1` 之和），不是唯一颜色数
2. 不要重新计算区间代价，利用增量更新
3. 注意 k 可以等于 n（每组一个球），代价为 0
