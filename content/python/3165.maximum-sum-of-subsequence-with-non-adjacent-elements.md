## 题目描述

给你一个整数数组 `nums` 和一个二维数组 `queries`，`queries[i] = [posi, xi]`。

对每个查询，先将 `nums[posi]` 修改为 `xi`，然后计算 `nums` 的 **不相邻子序列** 的最大和。

返回所有查询的答案之和，对 `10^9 + 7` 取模。

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `1 <= queries.length <= 5 * 10^4`

## 解题思路

线段树维护区间的 4 个状态（不相邻子序列最大和），支持点更新和区间合并。

每个节点维护：
- `f00`：不选首尾的最大值
- `f01`：不选首、选尾的最大值
- `f10`：选首、不选尾的最大值
- `f11`：选首尾的最大值

合并规则类似矩阵乘法（取最大）。

## Python 代码实现

### 方法一：线段树（推荐）

```python
from typing import List

class Solution:
    def maximumSumSubsequence(self, nums: List[int], queries: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # 节点存 (f00, f01, f10, f11)
        # f[i][j] = 首端选/不选=i，尾端选/不选=j 的最大和
        INF = float('-inf')

        def make_leaf(v):
            return (0, INF, INF, v)  # 单个元素：f00=0, f01=不选=INF, f10=INF, f11=v

        def combine(l, r):
            l00, l01, l10, l11 = l
            r00, r01, r10, r11 = r
            # 不选首（用 l00,l01），选首（用 l10,l11）
            # 不选尾（用 r00,r10），选尾（用 r01,r11）
            f00 = max(l00 + r00, l00 + r10, l01 + r00)
            f01 = max(l00 + r01, l00 + r11, l01 + r01)
            f10 = max(l10 + r00, l10 + r10, l11 + r00)
            f11 = max(l10 + r01, l10 + r11, l11 + r01)
            return (f00, f01, f10, f11)

        # 建立线段树
        tree = [None] * (4 * n)

        def build(node, l, r):
            if l == r:
                tree[node] = make_leaf(nums[l])
                return
            mid = (l + r) // 2
            build(2*node, l, mid)
            build(2*node+1, mid+1, r)
            tree[node] = combine(tree[2*node], tree[2*node+1])

        def update(node, l, r, pos, val):
            if l == r:
                tree[node] = make_leaf(val)
                return
            mid = (l + r) // 2
            if pos <= mid:
                update(2*node, l, mid, pos, val)
            else:
                update(2*node+1, mid+1, r, pos, val)
            tree[node] = combine(tree[2*node], tree[2*node+1])

        build(1, 0, n-1)

        ans = 0
        for pos, x in queries:
            update(1, 0, n-1, pos, x)
            root = tree[1]
            ans = (ans + max(root)) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 线段树区间维护 4 种端点选择状态
2. 合并时枚举中间连接方式（类似矩阵乘法）
3. 不相邻限制体现在合并时左端选了则右端不能选相邻

## 易错点

1. 单个叶节点的初始化：f01=f10 应为 `-inf`（不能同时选首尾，只有一个元素）
2. 合并时注意不相邻条件
