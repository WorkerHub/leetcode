## 题目描述

给你一个整数数组 citations，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数。

根据维基百科上 h 指数的定义：h 代表"高引用次数"，一名科研人员的 h 指数是指他（她）的（n 篇论文中）总共有 h 篇论文分别被引用了至少 h 次。且其余的 n - h 篇论文每篇被引用次数不超过 h 次。

如果 h 有多种可能的值，h 指数是其中最大的那个。

**示例 1：**
```
输入: citations = [3,0,6,1,5]
输出: 3
解释: 给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 3, 0, 6, 1, 5 次。
     由于研究者有 3 篇论文每篇至少被引用了 3 次，其余 2 篇论文每篇被引用不多于 3 次，
     所以她的 h 指数是 3。
```

**示例 2：**
```
输入: citations = [1,3,1]
输出: 1
```

**提示：**
- n == citations.length
- 1 <= n <= 5000
- 0 <= citations[i] <= 1000

## 解题思路

### 理解 h 指数

h 指数的定义：
- 至少有 h 篇论文被引用了至少 h 次
- 其余论文被引用次数不超过 h 次

换句话说：
- 如果我们按引用次数从高到低排序
- h 指数是满足"至少有 h 篇论文引用次数 >= h"的最大值

### 思路一：排序后查找

1. 将引用次数降序排序
2. 从前往后遍历，找到满足条件的最大 h
3. 第 i 篇论文（从 0 开始），如果 citations[i] >= i+1，说明至少有 i+1 篇论文被引用了至少 i+1 次

### 思路二：计数排序

1. 统计每个引用次数的论文数量
2. 从高引用次数向低遍历，累计论文数
3. 当累计论文数 >= 当前引用次数时，就找到了 h 指数

## Python 代码实现

### 方法一：排序法（推荐，易理解）

```python
from typing import List

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        """
        排序后查找 h 指数
        """
        # 降序排序
        citations.sort(reverse=True)
        
        h = 0
        # 遍历每篇论文
        for i, citation in enumerate(citations):
            # 如果当前论文的引用次数 >= 当前位置（从 1 开始）
            # 说明至少有 i+1 篇论文被引用了至少 i+1 次
            if citation >= i + 1:
                h = i + 1
            else:
                # 由于是降序排序，后面的论文引用次数更少，可以退出
                break
        
        return h
```

### 方法二：排序优化版

```python
from typing import List

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        """
        排序后直接找 h 指数
        """
        citations.sort(reverse=True)
        
        # 从后往前找第一个满足 citations[i] >= i+1 的位置
        h = 0
        for i in range(len(citations)):
            # 至少有 i+1 篇论文被引用了至少 citations[i] 次
            # h 指数是 min(i+1, citations[i]) 的最大值
            if citations[i] >= i + 1:
                h = i + 1
        
        return h
```

### 方法三：计数排序（O(n) 时间）

```python
from typing import List

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        """
        计数排序，时间复杂度 O(n)
        """
        n = len(citations)
        
        # 计数数组，count[i] 表示引用次数为 i 的论文数量
        # 引用次数大于 n 的都归为 count[n]
        count = [0] * (n + 1)
        
        for c in citations:
            if c >= n:
                count[n] += 1
            else:
                count[c] += 1
        
        # 从高引用次数向低遍历
        total = 0  # 引用次数 >= i 的论文总数
        for i in range(n, -1, -1):
            total += count[i]
            # 如果有至少 i 篇论文被引用了至少 i 次
            if total >= i:
                return i
        
        return 0
```

### 方法四：Python 简洁版

```python
from typing import List

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        """
        使用 Python 特性的简洁实现
        """
        citations.sort(reverse=True)
        
        # 找到最大的 h，使得至少有 h 篇论文被引用了至少 h 次
        return sum(c >= i + 1 for i, c in enumerate(citations))
```

### 方法五：不使用排序（二分查找思想）

```python
from typing import List

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        """
        二分查找 h 指数
        """
        n = len(citations)
        left, right = 0, n
        
        while left <= right:
            h = (left + right) // 2
            # 计算引用次数 >= h 的论文数量
            count = sum(c >= h for c in citations)
            
            if count >= h:
                # 可能还有更大的 h
                left = h + 1
            else:
                right = h - 1
        
        return right
```

## 复杂度分析

### 方法一、二：排序法

**时间复杂度：** O(n log n)
- 排序：O(n log n)
- 遍历：O(n)

**空间复杂度：** O(log n)
- 排序的栈空间

### 方法三：计数排序

**时间复杂度：** O(n)
- 统计：O(n)
- 遍历计数数组：O(n)

**空间复杂度：** O(n)
- 计数数组

### 方法五：二分查找

**时间复杂度：** O(n log n)
- 二分查找：O(log n)
- 每次计算 count：O(n)
- 总体：O(n log n)

**空间复杂度：** O(1)

## 关键点总结

1. **理解 h 指数定义**：至少有 h 篇论文被引用至少 h 次
2. **排序思路**：降序排序后，第 i 篇论文如果 citations[i] >= i+1，则 h >= i+1
3. **计数排序优化**：可以将时间复杂度降到 O(n)
4. **边界情况**：
   - 所有论文引用次数都很高：h = n
   - 所有论文引用次数都为 0：h = 0
5. **方法选择**：
   - 排序法最直观，推荐新手使用
   - 计数排序最优，适合追求性能

## 易错点

1. **h 指数的理解**：注意是"至少 h 篇"，不是"恰好 h 篇"
   ```python
   # 错误理解：恰好 h 篇引用次数 >= h
   # 正确理解：至少 h 篇引用次数 >= h
   ```

2. **索引与数量的对应**：排序后第 i 个元素代表第 i+1 篇论文
   ```python
   # i 从 0 开始，但论文数从 1 开始
   if citations[i] >= i + 1:
       h = i + 1
   ```

3. **计数数组的范围**：引用次数可能超过 n，需要归并处理
   ```python
   # 引用次数 > n 的都记录在 count[n]
   if c >= n:
       count[n] += 1
   ```

4. **边界情况**：空数组、所有元素为 0 等
   ```python
   if not citations:
       return 0
   ```
