## 题目描述

给你 `n` 个长方体 `cuboids`，其中第 `i` 个长方体的尺寸是 `cuboids[i] = [widthi, lengthi, heighti]`（**下标从 0 开始**）。

请从 `cuboids` 中选出一个**子集**，并将它们堆叠起来。

如果将长方体 `i` 放在长方体 `j` 的上面，需要满足：
- `widthi <= widthj`
- `lengthi <= lengthj`
- `heighti <= heightj`

在此前提下，你可以通过**旋转**某一长方体，将某条边作为高度。

请你返回**堆叠长方体**的**最大高度**。

**示例 1：**
```
输入：cuboids = [[50,45,20],[95,37,53],[45,23,12]]
输出：190
解释：将第 0 个长方体（旋转后尺寸 20x45x50）放底部，第 2 个（12x23x45）放上面
总高度 50 + 45 + 12 = ... 最优结果为 190
```

**提示：**
- `n == cuboids.length`
- `1 <= n <= 100`
- `1 <= widthi, lengthi, heighti <= 100`

## 解题思路

关键观察：对于任意可以堆叠的长方体组合，始终存在一种旋转方式，使得每个长方体都按照"最长边为高"的方式摆放，仍然满足堆叠条件，且高度之和更大。

因此，可以将每个长方体的三条边排序，让最大值作为高度，中间值作为长，最小值作为宽。

然后对所有长方体按 `[width, length, height]` 排序，转化为类似"最长递增子序列"的 DP 问题。

`dp[i]` = 以第 `i` 个长方体为最顶端的最大高度。

状态转移：`dp[i] = max(dp[j] + cuboids[i][2])` 对所有 `j < i` 且满足 `cuboids[j][0] <= cuboids[i][0], cuboids[j][1] <= cuboids[i][1], cuboids[j][2] <= cuboids[i][2]`。

## 代码实现

### 方法一：排序 + 动态规划（推荐）

```python
from typing import List

class Solution:
    def maxHeight(self, cuboids: List[List[int]]) -> int:
        # 对每个长方体的三条边排序（使最大边成为高度）
        for c in cuboids:
            c.sort()

        # 对所有长方体按三维升序排序
        cuboids.sort()

        n = len(cuboids)
        # dp[i] 表示以第 i 个长方体为最顶端的最大高度
        dp = [c[2] for c in cuboids]  # 初始化为自身高度

        for i in range(n):
            for j in range(i):
                # 检查 j 能否放在 i 下面（j 的三维都 <= i 的三维）
                if (cuboids[j][0] <= cuboids[i][0] and
                    cuboids[j][1] <= cuboids[i][1] and
                    cuboids[j][2] <= cuboids[i][2]):
                    dp[i] = max(dp[i], dp[j] + cuboids[i][2])

        return max(dp)
```

### 方法二：带详细注释的实现

```python
from typing import List

class Solution:
    def maxHeight(self, cuboids: List[List[int]]) -> int:
        n = len(cuboids)

        # 步骤1：将每个长方体三条边排序
        # 最优旋转方式：最大边作为高度
        for c in cuboids:
            c.sort()  # 排序后 c[0] <= c[1] <= c[2]

        # 步骤2：按照三维升序排序所有长方体
        # 排序保证：若 j < i，则 j 有可能放在 i 下面
        cuboids.sort()

        # 步骤3：DP，类似最长递增子序列
        dp = [0] * n
        ans = 0

        for i in range(n):
            # 第 i 个长方体单独摆放时，高度为 cuboids[i][2]
            dp[i] = cuboids[i][2]
            for j in range(i):
                # 判断第 j 个能否在第 i 个下面
                if (cuboids[j][0] <= cuboids[i][0] and
                    cuboids[j][1] <= cuboids[i][1] and
                    cuboids[j][2] <= cuboids[i][2]):
                    # 在 j 的基础上再叠 i
                    dp[i] = max(dp[i], dp[j] + cuboids[i][2])
            ans = max(ans, dp[i])

        return ans
```

## 复杂度分析

- **时间复杂度**：O(n^2)，双重循环
- **空间复杂度**：O(n)，存储 dp 数组

## 关键点总结

1. 贪心预处理：每个长方体三条边排序后，最大边始终可以作为高度，且不会减小最优解
2. 全局排序后，满足堆叠条件的对必然是 `j < i` 的对
3. 问题转化为三维的"最长递增子序列"变种
4. `dp[i]` 初始化为 `cuboids[i][2]`（仅放当前长方体）

## 易错点

1. 贪心的合法性证明：若 A 能放在 B 上，旋转 A 让最大边为高后，A 仍然能放在 B 上
2. 全局排序后，仍需在 DP 时检查三维条件（排序不能保证所有 j < i 都满足堆叠）
3. 初始化 `dp[i]` 为 `cuboids[i][2]` 而非 0，否则答案会偏小
