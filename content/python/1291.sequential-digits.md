## 题目描述

我们定义「连续整数」为：每一位上的数字都比前一位大 1 的整数。

返回在范围 `[low, high]` 内，所有满足上述描述的整数，**按升序排列**。

**示例 1：**

```
输入：low = 100, high = 300
输出：[123, 234]
```

**示例 2：**

```
输入：low = 1000, high = 13000
输出：[1234, 2345, 3456, 4567, 5678, 6789, 12345]
```

**提示：**

- `10 <= low <= high <= 10^9`

## 解题思路

### 核心观察

所有可能的连续整数都是字符串 `"123456789"` 的某个**连续子串**对应的整数。

为什么？因为连续整数的每一位都比前一位大 1，所以：
- 1 位：1, 2, 3, ..., 9
- 2 位：12, 23, 34, 45, 56, 67, 78, 89
- 3 位：123, 234, 345, 456, 567, 678, 789
- ...
- 9 位：123456789

一共只有 `9 + 8 + 7 + ... + 1 = 45` 个连续整数！

**方法一：枚举所有连续整数**

直接从 `"123456789"` 中枚举所有子串，过滤在 `[low, high]` 范围内的。

**方法二：BFS/队列**

从每个起始数字（1-9）出发，每次在末尾加上下一个数字，直到超出 high 为止。

**方法三：数学枚举**

按位数从小到大枚举，每种位数枚举所有起始数字。

## Python 代码实现

### 方法一：字符串子串枚举（推荐，最简洁）

```python
from typing import List

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        sample = "123456789"  # 所有连续整数都是这个字符串的子串
        result = []

        # 枚举所有可能的子串长度
        for length in range(len(str(low)), len(str(high)) + 1):
            # 枚举该长度下所有的起始位置
            for start in range(9 - length + 1):
                num = int(sample[start:start + length])
                if low <= num <= high:
                    result.append(num)

        # 由于我们按长度从小到大、每种长度按起始位置从小到大枚举
        # 结果天然有序，不需要排序
        return result
```

### 方法二：BFS（队列扩展）

```python
from typing import List
from collections import deque

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        result = []
        # 初始化队列，从 1-9 的单位数开始
        queue = deque(range(1, 10))

        while queue:
            num = queue.popleft()

            if num > high:
                # 当前数已超出范围，无需继续
                continue

            if num >= low:
                result.append(num)

            # 在末尾追加下一个数字（当前末尾数字 + 1）
            last_digit = num % 10
            if last_digit < 9:
                # 末尾数字不是 9，可以继续扩展
                queue.append(num * 10 + last_digit + 1)

        return result
```

### 方法三：完整枚举后排序

```python
from typing import List

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        result = []

        # 枚举起始数字（1 到 9）
        for start in range(1, 10):
            num = start
            next_digit = start + 1

            # 不断在末尾追加下一个连续数字
            while num <= high and next_digit <= 9:
                if num >= low:
                    result.append(num)
                # 追加 next_digit 到 num 末尾
                num = num * 10 + next_digit
                next_digit += 1

            # 处理最后一个 num（已退出循环但可能在范围内）
            if low <= num <= high:
                result.append(num)

        # 不同起始数字生成的数可能交叉，需要排序
        result.sort()
        return result
```

### 方法四：预生成所有连续整数（暴力穷举）

```python
from typing import List

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        # 预先生成所有 45 个连续整数
        all_sequential = []
        for start in range(1, 10):
            num = 0
            for digit in range(start, 10):
                num = num * 10 + digit
                all_sequential.append(num)

        # 过滤在 [low, high] 范围内的（all_sequential 已有序）
        return [x for x in sorted(all_sequential) if low <= x <= high]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（子串枚举） | O(1) | O(1) |
| 方法二（BFS） | O(1) | O(1) |
| 方法三（枚举+排序） | O(1) | O(1) |
| 方法四（预生成） | O(1) | O(1) |

由于连续整数总数只有 45 个，所有方法的复杂度本质上都是 O(1)（常数时间）。

## 关键点总结

1. **关键观察**：所有连续整数都是 `"123456789"` 的连续子串，总数仅 45 个
2. **结果有序**：按长度从小到大、同长度按起始位置从小到大枚举，结果天然有序
3. **枚举范围**：长度从 `len(str(low))` 到 `len(str(high))` 即可，无需枚举全部
4. **末位判断**：BFS 方法中，只有末位数字不是 9 才能继续扩展
5. **枚举起点**：起始数字从 1 开始（不含 0），因为连续整数从正数开始

## 易错点

- **方法三需要排序**：不同起始数字生成的连续整数顺序可能交叉（如 123, 234, 1234, 2345...），不排序结果不正确；方法一按长度枚举则天然有序
- **length 的枚举范围**：方法一中 `start` 最大为 `9 - length`（而不是 `9 - length + 1` 个可以从 0 到 `9 - length`），要注意索引边界
- **题目约束 low >= 10**：不需要处理个位数（但如果 low 为 1，则需要包含个位数）
