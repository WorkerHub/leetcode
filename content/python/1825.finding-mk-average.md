## 题目描述

给你两个整数 `m` 和 `k`，以及一个流数据源，实现 `MKAverage` 类：
- `MKAverage(int m, int k)` 初始化
- `addElement(int num)` 向流中插入新元素
- `calculateMKAverage()` 若当前流中元素少于 `m` 个，返回 `-1`；否则对最后 `m` 个元素，去掉最小的 `k` 个和最大的 `k` 个，返回剩余元素的平均值（取整）

**示例：**
```
输入：["MKAverage","addElement","addElement","calculateMKAverage","addElement","calculateMKAverage","addElement","addElement","addElement","calculateMKAverage"]
     [[3,1],[3],[1],[],[10],[],[5],[5],[5],[]]
输出：[null,null,null,-1,null,3,null,null,null,5]
```

**提示：**
- `3 <= m <= 10^5`
- `1 <= k * 2 < m`
- `1 <= num <= 10^5`
- 最多调用 `addElement` 和 `calculateMKAverage` 各 `10^5` 次

## 解题思路

使用三个有序集合（SortedList）维护滑动窗口中的三个部分：
- `low`：最小的 k 个元素
- `mid`：中间的 m-2k 个元素（用于计算平均值）
- `high`：最大的 k 个元素

维护 `mid_sum`（中间部分的总和）便于快速计算均值。

每次 `addElement` 时，更新三个集合，保持各集合大小不变。

## 代码实现

### 方法一：三个 SortedList（推荐）

```python
from sortedcontainers import SortedList
from collections import deque

class MKAverage:
    def __init__(self, m: int, k: int):
        self.m = m
        self.k = k
        self.window = deque()   # 维护最近 m 个元素
        self.low = SortedList()   # 最小 k 个
        self.mid = SortedList()   # 中间 m-2k 个
        self.high = SortedList()  # 最大 k 个
        self.mid_sum = 0

    def _rebalance(self) -> None:
        """调整三个集合大小"""
        # low 不够：从 mid 移入
        while len(self.low) < self.k:
            val = self.mid.pop(0)
            self.mid_sum -= val
            self.low.add(val)
        # low 太多：移入 mid
        while len(self.low) > self.k:
            val = self.low.pop(-1)
            self.mid.add(val)
            self.mid_sum += val
        # high 不够：从 mid 移入
        while len(self.high) < self.k:
            val = self.mid.pop(-1)
            self.mid_sum -= val
            self.high.add(val)
        # high 太多：移入 mid
        while len(self.high) > self.k:
            val = self.high.pop(0)
            self.mid.add(val)
            self.mid_sum += val

    def addElement(self, num: int) -> None:
        self.window.append(num)

        # 将新元素插入合适的集合
        if not self.low or num <= self.low[-1]:
            self.low.add(num)
        elif not self.high or num >= self.high[0]:
            self.high.add(num)
        else:
            self.mid.add(num)
            self.mid_sum += num

        # 若窗口超过 m 个，移除最旧的元素
        if len(self.window) > self.m:
            old = self.window.popleft()
            if old in self.low:
                self.low.remove(old)
            elif old in self.high:
                self.high.remove(old)
            else:
                self.mid.remove(old)
                self.mid_sum -= old

        # 重新平衡三个集合
        if len(self.window) >= self.m:
            self._rebalance()

    def calculateMKAverage(self) -> int:
        if len(self.window) < self.m:
            return -1
        return self.mid_sum // (self.m - 2 * self.k)
```

### 方法二：仅用 SortedList（简化版）

```python
from sortedcontainers import SortedList
from collections import deque

class MKAverage:
    def __init__(self, m: int, k: int):
        self.m = m
        self.k = k
        self.q = deque()
        self.sl = SortedList()
        self.total = 0

    def addElement(self, num: int) -> None:
        self.q.append(num)
        self.sl.add(num)
        self.total += num
        if len(self.q) > self.m:
            old = self.q.popleft()
            self.sl.remove(old)
            self.total -= old

    def calculateMKAverage(self) -> int:
        if len(self.q) < self.m:
            return -1
        # 去掉最小 k 个和最大 k 个
        low_sum = sum(self.sl[:self.k])
        high_sum = sum(self.sl[-self.k:])
        return (self.total - low_sum - high_sum) // (self.m - 2 * self.k)
        # 注意：此方法 calculateMKAverage 是 O(k)，适合 k 较小时
```

## 复杂度分析

- **方法一**：
  - `addElement`：O(log m)
  - `calculateMKAverage`：O(1)
- **方法二**：
  - `addElement`：O(log m)
  - `calculateMKAverage`：O(k)

## 关键点总结

1. 用三个有序集合维护低、中、高三部分，中间部分维护累加和
2. 每次添加/删除元素后需要重新平衡三个集合，保持各自大小固定
3. 维护 mid_sum 使得查询均值为 O(1)

## 易错点

- 重新平衡时可能需要多次调整，用 while 而非 if
- 删除旧元素时，需要先确定它在哪个集合中
