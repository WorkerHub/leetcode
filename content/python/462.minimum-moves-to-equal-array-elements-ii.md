## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，返回使所有数组元素相等需要的最少移动数。

在一次操作中，你可以使数组中的一个元素加 1 或者减 1。

**示例 1：**
```
输入：nums = [1,2,3]
输出：2
解释：
只需要两次操作（每次操作指将一个元素加 1 或减 1）：
[1,2,3]  =>  [2,2,3]  =>  [2,2,2]
```

**示例 2：**
```
输入：nums = [1,10,2,9]
输出：16
```

**提示：**
- `n == nums.length`
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这是一个经典的数学问题，核心在于找到一个"目标值"，使得所有数字移动到这个目标值的总距离最小。

**核心观察：**
1. 问题等价于：在数轴上找一个点，使得所有点到这个点的距离之和最小
2. 这个点就是**中位数**（数学上可以证明）

**为什么是中位数？**
- 对于一组数，中位数是使得所有数到它的距离之和最小的点
- 直观理解：中位数左右两侧的元素数量相等，移动距离最平衡

**算法流程：**
1. 对数组排序
2. 找到中位数（对于偶数长度，任意中间值都可以）
3. 计算所有元素到中位数的距离之和

## Python 代码实现

### 方法一：排序 + 中位数（推荐）⭐

```python
from typing import List

class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        # 排序数组
        nums.sort()
        
        # 找到中位数
        n = len(nums)
        median = nums[n // 2]
        
        # 计算所有元素到中位数的距离之和
        return sum(abs(num - median) for num in nums)
```

**优点：** 思路清晰，易于理解

### 方法二：排序 + 双指针（优化）⭐

```python
from typing import List

class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        # 排序数组
        nums.sort()
        
        # 双指针计算距离
        left, right = 0, len(nums) - 1
        moves = 0
        
        while left < right:
            # 最大值和最小值的差就是两者移动到中间的总距离
            moves += nums[right] - nums[left]
            left += 1
            right -= 1
        
        return moves
```

**优点：** 
- 一次遍历，避免重复计算
- 不需要显式找中位数

**原理：** 
- 最外层的两个数必然移动到它们之间的某个位置
- `nums[right] - nums[left]` 就是它们的总移动距离

### 方法三：使用 statistics 库

```python
from typing import List
import statistics

class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        # 直接使用库函数找中位数
        median = statistics.median(nums)
        
        # 计算距离之和
        return sum(abs(num - median) for num in nums)
```

**注意：** `statistics.median()` 对偶数长度返回平均值，但不影响结果

### 方法四：快速选择（无需完全排序）

```python
from typing import List
import random

class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        # 使用快速选择找第 n//2 小的元素
        def quickSelect(arr, k):
            pivot = random.choice(arr)
            left = [x for x in arr if x < pivot]
            mid = [x for x in arr if x == pivot]
            right = [x for x in arr if x > pivot]
            
            if k < len(left):
                return quickSelect(left, k)
            elif k < len(left) + len(mid):
                return mid[0]
            else:
                return quickSelect(right, k - len(left) - len(mid))
        
        n = len(nums)
        median = quickSelect(nums, n // 2)
        
        return sum(abs(num - median) for num in nums)
```

**优点：** 平均 O(n) 时间复杂度，但实际不如排序简洁

## 复杂度分析

**方法一、二（排序）：**
- 时间复杂度：O(n log n)，排序的时间
- 空间复杂度：O(log n)，排序的栈空间（Python Timsort）

**方法四（快速选择）：**
- 时间复杂度：O(n) 平均，O(n^2) 最坏
- 空间复杂度：O(n)，递归栈 + 列表创建

**实际应用：** 对于本题规模，排序方法最佳（代码简洁且高效）

## 图解示例

以 `nums = [1, 10, 2, 9]` 为例：

```
步骤 1：排序
[1, 2, 9, 10]

步骤 2：找中位数
       ↓
[1, 2, 9, 10]
中位数 = nums[2] = 9 或 nums[1] = 2（都可以）

取 median = 2：
移动距离 = |1-2| + |2-2| + |9-2| + |10-2|
         = 1 + 0 + 7 + 8
         = 16

双指针方法：
left = 0, right = 3: moves += (10 - 1) = 9
left = 1, right = 2: moves += (9 - 2) = 7
总计：9 + 7 = 16
```

## 关键点总结

1. **中位数是最优解：** 数学上可以证明，中位数使得距离之和最小
2. **排序是关键：** 排序后才能快速找到中位数
3. **双指针优化：** 从两端向中间计算，避免重复遍历
4. **偶数长度：** 中位数取中间任意一个都可以（不影响结果）
5. **不需要实际移动：** 只计算距离，不需要真的修改数组

## 易错点

1. **误用平均数：** 最优目标不是平均数，而是中位数
   ```python
   # 错误
   target = sum(nums) // len(nums)  # 平均数不是最优解
   
   # 正确
   nums.sort()
   target = nums[len(nums) // 2]  # 中位数
   ```

2. **偶数长度的中位数处理：** 
   ```python
   # 对于 [1, 2, 9, 10]
   # nums[1] = 2 或 nums[2] = 9 都是正确的中位数
   # 结果相同，无需取平均
   ```

3. **忘记排序：** 直接取 `nums[n//2]` 而不排序
   ```python
   # 错误
   median = nums[len(nums) // 2]  # 未排序
   
   # 正确
   nums.sort()
   median = nums[len(nums) // 2]
   ```

4. **距离计算错误：** 忘记取绝对值
   ```python
   # 错误
   moves = sum(num - median for num in nums)
   
   # 正确
   moves = sum(abs(num - median) for num in nums)
   ```
