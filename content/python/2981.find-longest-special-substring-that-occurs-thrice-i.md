## 题目描述

给你一个字符串 `s`，找到**最长的特殊子字符串**，该子字符串至少出现三次。

**特殊子字符串**：只由**单一字母**重复组成的子字符串（如 "aaa"，"bb"）。

若不存在，返回 -1。

**示例 1：**
```
输入：s = "aaaa"
输出：2
解释："aa" 出现 3 次（位置 0-1, 1-2, 2-3）
```

**示例 2：**
```
输入：s = "abcde"
输出：-1
```

**提示：**
- `3 <= s.length <= 50`
- `s` 只含小写英文字母

## 解题思路

枚举所有特殊子字符串（连续相同字符组成的子串），统计每个的出现次数，找出现 >= 3 次的最长子串。

## Python 代码实现

### 方法一：枚举 + 哈希表（推荐）

```python
from collections import Counter

class Solution:
    def maximumLength(self, s: str) -> int:
        n = len(s)
        cnt = Counter()

        # 枚举所有特殊子串
        for i in range(n):
            for j in range(i + 1, n + 1):
                sub = s[i:j]
                # 检查是否是特殊子串（只含单一字母）
                if len(set(sub)) == 1:
                    cnt[sub] += 1

        ans = -1
        for sub, count in cnt.items():
            if count >= 3:
                ans = max(ans, len(sub))
        return ans
```

### 方法二：统计连续段

```python
from collections import defaultdict

class Solution:
    def maximumLength(self, s: str) -> int:
        # 统计每个字符的连续段长度
        # 对于长度为 L 的连续段，包含长度为 k (1<=k<=L) 的特殊子串 L-k+1 个
        groups = []
        i = 0
        while i < len(s):
            j = i
            while j < len(s) and s[j] == s[i]:
                j += 1
            groups.append((s[i], j - i))
            i = j

        # 对每个字符，统计各长度的出现次数
        freq = defaultdict(Counter)  # char -> {length: count}
        for ch, L in groups:
            for k in range(1, L + 1):
                freq[ch][k] += L - k + 1

        ans = -1
        for ch, length_cnt in freq.items():
            for k, cnt in length_cnt.items():
                if cnt >= 3:
                    ans = max(ans, k)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子串
- 空间复杂度：O(n^2)，哈希表

## 关键点总结

1. 特殊子串 = 单一字母重复，即 "aa", "aaa", "bbb" 等
2. 统计每个特殊子串的出现次数，找出现 >= 3 次的最长子串
3. 连续段方法：长度为 L 的连续段包含长度 k 的子串 L-k+1 次

## 易错点

1. 不同字符位置的相同特殊子串各自计数（"aaa" 从不同位置开始算不同）
2. 出现次数 >= 3（不是 > 3）
3. 若没有出现 >= 3 次的特殊子串，返回 -1
