## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`，以及一个整数 `k`。

你可以对 `nums` 执行如下操作任意次：
- 将 `nums` 中**任意**元素增加 1（注意只能增加，不能减少）

若数组满足"每个长度为 3 或 3 以上的子数组中，最大元素 >= k"，则称该数组为 **美丽** 数组。

返回将数组变为美丽数组所需的最少操作次数。

**示例 1：**
```
输入：nums = [2,3,0,0,2], k = 4
输出：3
```

**示例 2：**
```
输入：nums = [0,1,3,3], k = 5
输出：2
```

**提示：**
- `3 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

条件等价为：**不存在连续 3 个元素都 < k**，即对任意 i，`nums[i], nums[i+1], nums[i+2]` 中至少一个 >= k。

使用动态规划，定义：
- `dp[i]` = 使 `nums[0..i]` 满足条件且 `nums[i]` 被调整为 >= k 时的最少操作数
- `dp_skip[i]` = 使 `nums[0..i]` 满足条件且 `nums[i]` **不被**特殊处理（可能 < k）时的最少操作数

更简洁：`dp[i]` 为 `nums[i]` 达到 k 的最少总操作，`dp2[i]` 为不要求 `nums[i]` 达到 k。

等价的 dp：`f[i]` = 前 i 个元素合法且第 i 个"最后一个 >= k 的位置"的最少操作。

实际上最简洁：设 `dp[i]` = 将 nums[0..i] 处理好且第 i 个元素被提升到 >= k 的最少代价。
答案 = min(dp[n-1], dp[n-2], dp[n-3])（最后三个中至少有一个被提升）。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def minIncrementOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # cost[i] = 将 nums[i] 提升到 k 的代价
        def cost(i):
            return max(0, k - nums[i])

        # dp[i] = 将 nums[0..i] 全部合法，且 nums[i] >= k 时的最少操作数
        # 初始条件：dp[0], dp[1], dp[2] 独立计算
        # 转移：dp[i] = cost[i] + min(dp[i-1], dp[i-2], dp[i-3])
        # 其中 min(dp[i-1], dp[i-2], dp[i-3]) 代表前三个位置中至少有一个 >= k

        INF = float('inf')
        dp = [INF] * n
        dp[0] = cost(0)
        if n > 1:
            dp[1] = cost(1)
        if n > 2:
            dp[2] = cost(2)

        for i in range(3, n):
            dp[i] = cost(i) + min(dp[i - 1], dp[i - 2], dp[i - 3])

        # 答案：最后三个中有一个被提升（任意一个 >= k 即满足最后的 3 元素窗口）
        return min(dp[n - 1], dp[n - 2] if n >= 2 else INF, dp[n - 3] if n >= 3 else INF)
```

### 方法二：空间优化版

```python
from typing import List

class Solution:
    def minIncrementOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 只需保留最近三个 dp 值
        a = max(0, k - nums[0])
        b = max(0, k - nums[1]) if n > 1 else float('inf')
        c = max(0, k - nums[2]) if n > 2 else float('inf')

        for i in range(3, n):
            cost_i = max(0, k - nums[i])
            a, b, c = b, c, cost_i + min(a, b, c)

        return min(a, b, c)
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)，只保留最近三个状态

## 关键点总结

1. 问题等价：任意连续 3 个元素中至少有一个 >= k
2. dp[i] 表示以 i 为"最后一个 >= k 的位置"的最少代价
3. 转移：dp[i] = cost(i) + min(dp[i-1], dp[i-2], dp[i-3])，保证前三个中至少有一个

## 易错点

1. 只能增加元素，不能减少，所以 cost = max(0, k - nums[i])
2. 答案要取 dp[n-1], dp[n-2], dp[n-3] 的最小值，不只是 dp[n-1]
3. 初始三个 dp 值独立：不依赖更早的状态
