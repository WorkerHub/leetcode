## 题目描述

给定一个字符串数组 `strs`，你可以选择任意一个字符串作为起点，然后按照**任意顺序**连接其他字符串。对于每个字符串，你可以选择使用它本身或者它的**反转**。

你的目标是找到所有可能的连接方式中，**字典序最大**的字符串。

**示例 1：**
```
输入：strs = ["abc","xyz"]
输出："zyxcba"
解释：你可以得到 "zyxcba"，通过反转 "xyz" 为 "zyx"，然后反转 "abc" 为 "cba"，最后连接它们。
```

**示例 2：**
```
输入：strs = ["abc"]
输出："cba"
```

**提示：**
- `1 <= strs.length <= 1000`
- `1 <= strs[i].length <= 1000`
- `1 <= sum(strs[i].length) <= 1000`
- `strs[i]` 只包含小写字母

## 解题思路

这道题需要在所有可能的连接方式中找到字典序最大的字符串。

核心思想：
1. 对于每个字符串，选择它本身或反转后的版本中字典序较大的
2. 枚举每个位置作为起点
3. 其他字符串按最优方式（本身或反转）连接

贪心策略：
- 对于非起点字符串：直接选择它和反转中字典序较大的
- 对于起点字符串：需要枚举所有可能的切分位置

算法流程：
1. 预处理：对每个字符串，保存它和反转后较大的版本
2. 枚举起点：遍历每个字符串作为起点
3. 枚举切分位置：在起点字符串的每个位置切分（可以使用原字符串或反转）
4. 拼接其他字符串：使用预处理的最大版本
5. 更新全局最大值

## Python 代码实现

### 方法一：贪心 + 枚举（推荐）⭐

```python
from typing import List

class Solution:
    def splitLoopedString(self, strs: List[str]) -> str:
        """
        贪心 + 枚举所有可能的起点和切分位置
        
        时间复杂度：O(n * m^2)，n 是字符串数量，m 是平均长度
        空间复杂度：O(n * m)
        """
        # 预处理：对每个字符串，选择它和反转中较大的
        strs = [max(s, s[::-1]) for s in strs]
        
        result = ""
        
        # 枚举每个字符串作为起点
        for i in range(len(strs)):
            # 对于起点字符串，需要考虑原始和反转两种情况
            for s in (strs[i], strs[i][::-1]):
                # 枚举起点字符串的每个切分位置
                for j in range(len(s)):
                    # 从位置 j 切分：s[j:] + 其他字符串 + s[:j]
                    # 前半部分
                    current = s[j:]
                    # 后面的字符串（i+1 到末尾，再从头到 i-1）
                    current += "".join(strs[i+1:])
                    current += "".join(strs[:i])
                    # 后半部分
                    current += s[:j]
                    
                    # 更新最大值
                    result = max(result, current)
        
        return result
```

### 方法二：优化版本

```python
from typing import List

class Solution:
    def splitLoopedString(self, strs: List[str]) -> str:
        """
        优化：提前计算其他字符串的拼接结果
        
        时间复杂度：O(n * m^2)
        空间复杂度：O(n * m)
        """
        # 预处理：选择每个字符串和其反转中较大的
        strs = [max(s, s[::-1]) for s in strs]
        
        result = ""
        
        for i in range(len(strs)):
            # 其他字符串的拼接（按循环顺序）
            rest = "".join(strs[i+1:]) + "".join(strs[:i])
            
            # 枚举起点字符串的两种形式
            for s in (strs[i], strs[i][::-1]):
                # 枚举切分位置
                for j in range(len(s)):
                    # 构造候选字符串
                    candidate = s[j:] + rest + s[:j]
                    # 更新最大值
                    if candidate > result:
                        result = candidate
        
        return result
```

### 方法三：剪枝优化

```python
from typing import List

class Solution:
    def splitLoopedString(self, strs: List[str]) -> str:
        """
        剪枝优化：只考虑以最大字符开头的情况
        
        时间复杂度：O(n * m^2)
        空间复杂度：O(n * m)
        """
        # 预处理
        strs = [max(s, s[::-1]) for s in strs]
        
        # 找出所有字符串中的最大字符
        max_char = max(max(s) for s in strs)
        
        result = ""
        
        for i in range(len(strs)):
            rest = "".join(strs[i+1:]) + "".join(strs[:i])
            
            for s in (strs[i], strs[i][::-1]):
                for j in range(len(s)):
                    # 剪枝：只考虑以最大字符开头的情况
                    if s[j] != max_char:
                        continue
                    
                    candidate = s[j:] + rest + s[:j]
                    result = max(result, candidate)
        
        return result
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n × m²)，其中 n 是字符串数量，m 是平均长度
  - 外层循环：O(n)，枚举起点
  - 中层循环：O(1)，最多 2 种形式
  - 内层循环：O(m)，枚举切分位置
  - 字符串比较/拼接：O(m)
- **空间复杂度**：O(n × m)，存储预处理后的字符串和结果

## 关键点总结

1. **贪心策略**：对于非起点字符串，直接选择它和反转中较大的
2. **枚举起点**：每个字符串都可能作为起点
3. **枚举形式**：起点字符串需要考虑原始和反转两种形式
4. **枚举切分**：在起点字符串的每个位置切分
5. **剪枝优化**：只考虑以全局最大字符开头的情况

## 易错点

1. **起点处理**：
   - 起点字符串需要考虑原始和反转两种形式
   - 非起点字符串只需要选择较大的版本
2. **循环拼接**：
   - 注意拼接顺序：`s[j:] + rest + s[:j]`
   - `rest` 是其他字符串按循环顺序拼接
3. **字符串比较**：
   - Python 中字符串比较是字典序比较
   - 使用 `max()` 直接比较即可
4. **预处理**：
   - 先对所有字符串进行预处理，选择较大版本
   - 这样可以简化后续的处理
5. **边界情况**：
   - 只有一个字符串时
   - 字符串长度为 1 时
