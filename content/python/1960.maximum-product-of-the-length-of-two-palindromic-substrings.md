## 题目描述

给你一个下标从 **0** 开始的字符串 `s`，长度为**偶数** `n`。返回两段不相交且覆盖中间分割线的**奇数长度回文子字符串**的最大长度乘积。

具体要求：找 `j`（`0 <= j < n`），在 `s[0..j]` 中找最长奇数长度回文子字符串的长度 `left[j]`，在 `s[j+1..n-1]` 中找最长奇数长度回文子字符串的长度 `right[j]`，最大化 `left[j] * right[j]`。

**提示：**
- `2 <= n <= 10^5`，n 为偶数

---

## 解题思路

### 核心思想：Manacher 算法 + 前缀最大回文长度

1. 用 **Manacher 算法**求每个位置为中心的最长奇数长度回文半径 `p[i]`
2. 计算 `left[j]`：`s[0..j]` 中最长奇数回文长度（以 j 或之前为中心）
3. 计算 `right[j]`：`s[j+1..n-1]` 中最长奇数回文长度

**关键：** `left[j]` 不只是以 j 为中心的回文，而是所有 `s[0..j]` 内可以完整放置的最长奇数回文的长度。

需要正向和反向各做一次前缀最大值传播。

## 代码实现

### 方法一：Manacher + 前缀传播（推荐）

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)

        def manacher(t: str):
            """Manacher 算法，返回以每个位置为中心的最长奇数回文半径"""
            m = len(t)
            p = [0] * m
            c = r = 0  # 最右回文的中心和右边界
            for i in range(m):
                mirror = 2 * c - i
                if i < r:
                    p[i] = min(r - i, p[mirror])
                # 尝试扩展
                while i + p[i] + 1 < m and i - p[i] - 1 >= 0 and t[i + p[i] + 1] == t[i - p[i] - 1]:
                    p[i] += 1
                # 更新最右回文
                if i + p[i] > r:
                    c, r = i, i + p[i]
            return p

        p = manacher(s)
        # p[i] = 以 i 为中心的回文半径（回文长度 = 2*p[i]+1）

        # left[j] = s[0..j] 中最大奇数回文长度
        # 条件：以 c 为中心，半径 r，需要 c - r >= 0 且 c + r <= j
        # 即 j >= c + r，对每个中心 c，可覆盖 j >= c + p[c] 的位置

        left = [1] * n  # 至少有长度为 1 的回文
        for c in range(n):
            # 该中心的最长奇数回文长度 = 2*p[c]+1
            reach = c + p[c]  # 最右到达的位置
            # 在位置 j = reach 处，left[j] 可以更新为 2*p[c]+1
            if left[reach] < 2 * p[c] + 1:
                left[reach] = 2 * p[c] + 1

        # 前向传播：left[j] = max(left[j], left[j-1]-2)... 不，直接取最大
        # 正确：left[j] = max(left[j-1], 如果以 j 为中心的覆盖到 j 的回文)
        # 需要：j 从左到右，left[j] = max(以某c为中心且c+p[c]<=j的最长回文)
        # 重新计算：
        max_left = [1] * n
        for c in range(n):
            end = c + p[c]
            if end < n:
                max_left[end] = max(max_left[end], 2 * p[c] + 1)
        for j in range(1, n):
            # 从 j-1 传播，但长度减 2（缩短一圈）
            max_left[j] = max(max_left[j], max_left[j-1])

        # right[j] = s[j..n-1] 中最大奇数回文长度（从右向左传播）
        max_right = [1] * n
        for c in range(n):
            start = c - p[c]
            if start >= 0:
                max_right[start] = max(max_right[start], 2 * p[c] + 1)
        for j in range(n - 2, -1, -1):
            max_right[j] = max(max_right[j], max_right[j + 1])

        # 枚举分割点
        ans = 0
        for j in range(n - 1):
            ans = max(ans, max_left[j] * max_right[j + 1])

        return ans
```

### 方法二：简化版（不使用严格的覆盖判断）

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)

        def manacher_odd(t):
            m = len(t)
            p = [0] * m
            l = r = -1
            for i in range(m):
                k = 1 if i > r else min(p[l + r - i], r - i + 1)
                while i - k >= 0 and i + k < m and t[i - k] == t[i + k]:
                    k += 1
                p[i] = k - 1
                if i + k - 1 > r:
                    l, r = i - k + 1, i + k - 1
            return p

        p = manacher_odd(s)

        # 计算 left[j]：s[0..j] 内能完整放置的最长奇数回文长度
        left = [1] * n
        for c in range(n):
            end = c + p[c]
            if end < n:
                left[end] = max(left[end], 2 * p[c] + 1)
        for j in range(1, n):
            left[j] = max(left[j], left[j - 1])

        # 计算 right[j]：s[j..n-1] 内能完整放置的最长奇数回文长度
        right = [1] * n
        for c in range(n):
            start = c - p[c]
            if start >= 0:
                right[start] = max(right[start], 2 * p[c] + 1)
        for j in range(n - 2, -1, -1):
            right[j] = max(right[j], right[j + 1])

        ans = 0
        for j in range(n - 1):
            ans = max(ans, left[j] * right[j + 1])
        return ans
```

## 关键点总结

1. Manacher 算法 O(n) 计算所有回文半径
2. 通过前向/后向传播得到每个位置对应的最大回文长度
3. 枚举分割点取最大乘积

---

## 易错点

- `max_left[j]` 表示 `s[0..j]` 中能完整放置（右端点 ≤ j）的最长奇数回文
- 需要传播：`left[j] = max(left[j], left[j-1])`（更短前缀的最大回文也是有效的）
