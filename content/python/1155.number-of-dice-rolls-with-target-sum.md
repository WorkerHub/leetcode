## 题目描述

这里有 n 个一样的骰子，每个骰子上都有 k 个面，分别标号为 1 到 k。

给定三个整数 n、k 和 target，返回可能的方式数(出现的总和为 target)。

答案可能很大，你需要对 10^9 + 7 取模。

**示例 1：**
```
输入：n = 1, k = 6, target = 3
输出：1
解释：你扔一个有6个面的骰子。
得到3的和只有一种方法。
```

**示例 2：**
```
输入：n = 2, k = 6, target = 7
输出：6
解释：你扔两个骰子，每个骰子有6个面。
有6种方法得到7的和：1+6, 2+5, 3+4, 4+3, 5+2, 6+1。
```

**示例 3：**
```
输入：n = 30, k = 30, target = 500
输出：222616187
```

**提示：**
- 1 <= n, k <= 30
- 1 <= target <= 1000

## 解题思路

这是一个典型的动态规划问题，类似于"组合总和"。

**状态定义：**
- `dp[i][j]` 表示使用 i 个骰子，得到总和为 j 的方法数

**状态转移：**
- 对于第 i 个骰子，可以投出 1 到 k 的任意点数
- 如果第 i 个骰子投出 face（1 <= face <= k）
- 那么前 i-1 个骰子需要得到 j - face 的总和
- 状态转移方程：
  ```
  dp[i][j] = sum(dp[i-1][j-face]) for face in 1..k
  ```

**初始状态：**
- `dp[0][0] = 1`：0个骰子得到和0有1种方法
- 其他 `dp[0][j] = 0`

**边界条件：**
- 如果 target < n 或 target > n*k，返回 0
- 因为最小和是 n（每个骰子1），最大和是 n*k（每个骰子k）

## Python 代码实现

### 方法一：二维 DP ⭐

```python
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        """
        二维动态规划
        时间复杂度：O(n * target * k)
        空间复杂度：O(n * target)
        """
        MOD = 10**9 + 7
        
        # 边界检查
        if target < n or target > n * k:
            return 0
        
        # dp[i][j]: 使用i个骰子，得到和为j的方法数
        dp = [[0] * (target + 1) for _ in range(n + 1)]
        dp[0][0] = 1
        
        # 遍历骰子数量
        for i in range(1, n + 1):
            # 遍历可能的总和
            for j in range(i, min(target + 1, i * k + 1)):
                # 遍历当前骰子的点数
                for face in range(1, k + 1):
                    if j >= face:
                        dp[i][j] = (dp[i][j] + dp[i - 1][j - face]) % MOD
        
        return dp[n][target]
```

### 方法二：空间优化（滚动数组）⭐ 推荐

```python
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        """
        使用一维数组优化空间
        时间复杂度：O(n * target * k)
        空间复杂度：O(target)
        """
        MOD = 10**9 + 7
        
        if target < n or target > n * k:
            return 0
        
        # 只需要保存上一轮的结果
        dp = [0] * (target + 1)
        dp[0] = 1
        
        # 每加一个骰子
        for i in range(n):
            # 从后往前更新，避免覆盖
            new_dp = [0] * (target + 1)
            for j in range(target + 1):
                if dp[j] > 0:
                    # 当前骰子可以投1到k
                    for face in range(1, k + 1):
                        if j + face <= target:
                            new_dp[j + face] = (new_dp[j + face] + dp[j]) % MOD
            dp = new_dp
        
        return dp[target]
```

### 方法三：记忆化递归

```python
from functools import lru_cache

class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        """
        记忆化递归（自顶向下）
        """
        MOD = 10**9 + 7
        
        @lru_cache(maxsize=None)
        def dfs(dice_left: int, current_sum: int) -> int:
            # 基础情况
            if dice_left == 0:
                return 1 if current_sum == 0 else 0
            
            # 剪枝：剩余和不可能达到
            if current_sum < dice_left or current_sum > dice_left * k:
                return 0
            
            # 尝试当前骰子的所有点数
            count = 0
            for face in range(1, k + 1):
                if current_sum >= face:
                    count = (count + dfs(dice_left - 1, current_sum - face)) % MOD
            
            return count
        
        return dfs(n, target)
```

### 方法四：优化的DP（内层循环优化）

```python
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        """
        优化内层循环，使用前缀和
        时间复杂度：O(n * target)
        """
        MOD = 10**9 + 7
        
        if target < n or target > n * k:
            return 0
        
        dp = [0] * (target + 1)
        dp[0] = 1
        
        for i in range(1, n + 1):
            new_dp = [0] * (target + 1)
            # 使用滑动窗口优化
            window_sum = 0
            
            for j in range(i, min(target + 1, i * k + 1)):
                # 添加右边界
                if j <= k:
                    window_sum = (window_sum + dp[j - 1]) % MOD
                else:
                    window_sum = (window_sum + dp[j - 1] - dp[j - k - 1]) % MOD
                
                new_dp[j] = window_sum
            
            dp = new_dp
        
        return dp[target]
```

## 复杂度分析

**方法一（二维DP）：**
- 时间复杂度：O(n × target × k)
- 空间复杂度：O(n × target)

**方法二（一维DP）：**
- 时间复杂度：O(n × target × k)
- 空间复杂度：O(target)

**方法三（记忆化递归）：**
- 时间复杂度：O(n × target × k)
- 空间复杂度：O(n × target)

## 关键点总结

1. **状态定义**：`dp[i][j]` = 用i个骰子得到和j的方法数
2. **状态转移**：枚举当前骰子的点数，累加前一状态
3. **取模运算**：每次加法后取模，防止溢出
4. **空间优化**：只需要保存上一层结果
5. **边界优化**：提前判断不可能的情况

## 易错点

1. **取模时机**：
   ```python
   # 错误：最后才取模，可能溢出
   dp[i][j] = (sum(...)) % MOD
   
   # 正确：每次加法都取模
   dp[i][j] = (dp[i][j] + dp[i-1][j-face]) % MOD
   ```

2. **滚动数组更新顺序**：
   ```python
   # 错误：从前往后会覆盖未使用的数据
   for j in range(target + 1):
       dp[j] = ...
   
   # 正确：使用新数组
   new_dp = [0] * (target + 1)
   ```

3. **边界条件**：
   - 忘记检查 target < n 或 target > n*k

4. **初始状态**：
   - `dp[0][0] = 1` 而不是 `dp[1][0] = 1`

5. **循环范围**：
   - j 的范围应该从 i 开始（至少i个骰子点数为i）
