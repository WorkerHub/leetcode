## 题目描述

给定一个 `m × n` 的整数矩阵 `grid`，从左上角 `(0,0)` 出发，每次可以移动到相邻的上、下、左、右四个单元格。移动到单元格 `(i,j)` 的代价为 `grid[i][j]`，起点不计入代价。

求从起点出发，访问矩阵中所有单元格所需的最小总代价。

**示例 1：**
```
输入：grid = [[0,1,1],[1,1,1],[1,1,1]]
输出：8
解释：以最短路径访问所有单元格，每次移动代价为目标单元格的值。
```

**示例 2：**
```
输入：grid = [[1,2,3],[4,5,6]]
输出：21
```

**提示：**
- `1 <= m, n <= 50`
- `0 <= grid[i][j] <= 100`

## 解题思路

Dijkstra 最短路算法。

将每个单元格看作图的一个节点，从 `(0,0)` 出发，边权为目标节点的格子值。求到达每个节点的最短路径，再累加所有节点的最短路径之和。

用优先队列（最小堆）实现 Dijkstra，`dist[i][j]` 表示从起点到 `(i,j)` 的最小代价。

最终答案为 `sum(dist[i][j] for all i, j)`。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0  # 起点代价为 0

        # 最小堆：(当前代价, 行, 列)
        heap = [(0, 0, 0)]
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while heap:
            cost, i, j = heapq.heappop(heap)
            if cost > dist[i][j]:
                continue  # 已有更优路径，跳过
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    new_cost = cost + grid[ni][nj]
                    if new_cost < dist[ni][nj]:
                        dist[ni][nj] = new_cost
                        heapq.heappush(heap, (new_cost, ni, nj))

        # 累加所有单元格的最短路径代价
        return sum(dist[i][j] for i in range(m) for j in range(n))
```

### 方法二：BFS（仅适用于格子值相同时）

```python
from typing import List
from collections import deque

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0
        queue = deque([(0, 0, 0)])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while queue:
            cost, i, j = queue.popleft()
            if cost > dist[i][j]:
                continue
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    new_cost = cost + grid[ni][nj]
                    if new_cost < dist[ni][nj]:
                        dist[ni][nj] = new_cost
                        queue.append((new_cost, ni, nj))

        return sum(dist[i][j] for i in range(m) for j in range(n))
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))，Dijkstra 的时间复杂度
- 空间复杂度：O(mn)，存储距离矩阵和堆

## 关键点总结

1. 格子带权移动问题的经典解法是 Dijkstra
2. 起点代价为 0，移动到某格的代价是该格的值
3. 最终统计所有格子的最短路径之和

## 易错点

1. 起点 `(0,0)` 的代价为 0（不计入 `grid[0][0]`）
2. 非均匀权重必须用 Dijkstra 而非 BFS
