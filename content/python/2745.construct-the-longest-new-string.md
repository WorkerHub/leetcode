## 题目描述

给你三个整数 `x`、`y`、`z`，分别表示字符串 `"aa"`、`"bb"`、`"ab"` 的数量。

将这些字符串拼接在一起（每个字符串最多使用一次），使得最终字符串不含 `"aaa"` 或 `"bbb"` 子字符串，且最长。

返回能构造的最长字符串的长度。

**示例 1：**
```
输入：x = 2, y = 3, z = 1
输出：8
解释：可以拼成 "bbbbaabb" 等，长度 8
```

**示例 2：**
```
输入：x = 3, y = 2, z = 2
输出：14
```

**提示：**
- `1 <= x, y, z <= 50`

## 解题思路

分析各类型的搭配规则：
- `"ab"` 不含 `aa` 或 `bb`，随意添加
- `"aa"` 后面必须跟 `"bb"`，`"bb"` 后面必须跟 `"aa"`（避免 `"aaa"` 或 `"bbb"`）
- `"aa"` 和 `"bb"` 的数量需要平衡：`min(x, y)` 对可以交替使用

若 `x == y`：可用 `x` 个 `"aa"` 和 `x` 个 `"bb"` 交替，加上 `z` 个 `"ab"`，总长 = `(2x + z) * 2`
若 `x > y`：可用 `y+1` 个 `"aa"` 和 `y` 个 `"bb"`（末尾多一个 `"aa"`），加上 z 个 `"ab"`
若 `x < y`：对称同理

更简洁：答案 = `(2 * min(x, y) + z + (x != y)) * 2`

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def longestString(self, x: int, y: int, z: int) -> int:
        # min(x, y) 对 "aa" 和 "bb" 可以交替使用
        # 若 x != y，可以多放一个（多的那种）
        pairs = min(x, y)
        extra = 1 if x != y else 0  # 数量不等时，多的种类可多放一个
        # 总拼接块数：2*pairs + extra + z
        # 每块长度 2，总长度乘以 2
        return (2 * pairs + extra + z) * 2
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `"aa"` 和 `"bb"` 必须交替，最多用 `min(x, y)` 对
2. 若 `x != y`，多的那种可以再放一个（放在开头或结尾）
3. `"ab"` 不引入新的 `aa` 或 `bb`，全部可用

## 易错点

1. `extra` 条件是 `x != y`（而不是 `x > y` 或 `x < y`）
2. 每个字符串块长度为 2，最终长度需乘以 2
