## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`。

下标 `i` 的**平均差**定义为：`|前 i+1 个元素的平均值 - 后 n-i-1 个元素的平均值|`（整数除法向下取整）。

若后半部分为空，则平均差为前半部分的平均值（不减 0）。

返回**平均差最小**的下标，若有多个，返回最小的那个。

**示例 1：**
```
输入：nums = [2,5,3,9,5,3]
输出：3
解释：
下标3：前4个平均=[2+5+3+9]/4=19/4=4，后2个平均=[5+3]/2=4，|4-4|=0，最小。
```

## 解题思路

预计算总和 `total`，用前缀和 `prefix` 递推。

对每个下标 `i`：
- 前缀和：`prefix_sum = prefix_sum + nums[i]`。
- 后缀和：`suffix_sum = total - prefix_sum`。
- 前半均值：`prefix_sum // (i + 1)`。
- 后半均值：`suffix_sum // (n - i - 1)` 若后半非空，否则 0。

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def minimumAverageDifference(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)
        prefix = 0
        min_diff = float('inf')
        ans = 0

        for i in range(n):
            prefix += nums[i]
            suffix = total - prefix

            # 计算平均差
            left_avg = prefix // (i + 1)
            right_avg = suffix // (n - i - 1) if i < n - 1 else 0

            diff = abs(left_avg - right_avg)
            if diff < min_diff:
                min_diff = diff
                ans = i

        return ans
```

### 方法二：使用 accumulate

```python
from typing import List
from itertools import accumulate

class Solution:
    def minimumAverageDifference(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)
        prefix_sums = list(accumulate(nums))

        min_diff = float('inf')
        ans = 0

        for i in range(n):
            left_sum = prefix_sums[i]
            right_sum = total - left_sum

            left_avg = left_sum // (i + 1)
            right_avg = right_sum // (n - i - 1) if i < n - 1 else 0

            diff = abs(left_avg - right_avg)
            if diff < min_diff:
                min_diff = diff
                ans = i

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)（方法一），O(n)（方法二）。

## 关键点总结

1. 前缀和维护左半部分总和，后缀和 = 总和 - 前缀和。
2. 整数除法（`//`）向下取整。
3. 最后一个元素（i = n-1）后半为空，右均值视为 0。

## 易错点

- 当 `i == n-1` 时后半为空，右均值为 0（不是做除零运算）。
- 要找最小下标，所以用严格小于 `<` 来更新，相等时不更新（保留较小的下标）。
