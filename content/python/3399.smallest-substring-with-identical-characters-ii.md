## 题目描述

给你一个**二进制字符串** `s` 和一个整数 `numOps`，每次操作可以将 `s` 中的任意一个字符翻转（0 变 1 或 1 变 0）。

返回经过**最多 `numOps` 次操作**后，`s` 中**最长的全相同字符子字符串**的最小可能长度。

**提示：**
- `1 <= n <= 10^5`（本题 II，大数据范围）
- `0 <= numOps <= n`

## 解题思路

**二分答案 + O(n) 验证：**

与 3398 题（数据规模较小）完全相同的思路，但由于 n 最大 10^5，需要 O(n) 或 O(n log n) 的高效验证。

二分 `mid`（最大允许的全相同子串长度），验证 `cost(mid) <= numOps`：

1. 若 `mid == 1`：目标是交替字符串，计算变为 "010101..." 或 "101010..." 的最小代价（两种模式取最小）。
2. 若 `mid >= 2`：遍历所有连续相同字符段，每段长度 `L`，代价为 `L // (mid + 1)`。

O(n) 验证 + O(log n) 二分 = O(n log n) 总复杂度。

## Python 代码实现

### 方法一：二分 + O(n) 验证（推荐）

```python
class Solution:
    def minLength(self, s: str, numOps: int) -> int:
        n = len(s)
        
        # 预计算所有连续段的长度（加速验证）
        runs = []
        i = 0
        while i < n:
            j = i + 1
            while j < n and s[j] == s[i]:
                j += 1
            runs.append(j - i)
            i = j
        
        def cost(max_len):
            """计算将所有全相同子串长度限制在 max_len 内所需的最少操作数"""
            if max_len == 1:
                # 变为 "010101..." 或 "101010..." 的代价
                c0 = sum(1 for k in range(n) if s[k] != '01'[k % 2])
                c1 = sum(1 for k in range(n) if s[k] != '10'[k % 2])
                return min(c0, c1)
            
            # 每段长度 L，需要 L // (max_len + 1) 次操作
            return sum(length // (max_len + 1) for length in runs)
        
        # 二分最小化最长全相同子串长度
        lo, hi = 1, n
        
        while lo < hi:
            mid = (lo + hi) // 2
            if cost(mid) <= numOps:
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

### 方法二：两端二分优化（分别处理 mid=1 和 mid>=2）

```python
class Solution:
    def minLength(self, s: str, numOps: int) -> int:
        n = len(s)
        
        # 预计算连续段
        runs = []
        i = 0
        while i < n:
            j = i + 1
            while j < n and s[j] == s[i]:
                j += 1
            runs.append(j - i)
            i = j
        
        # 特判 mid=1
        c0 = sum(s[k] != '01'[k % 2] for k in range(n))
        c1 = sum(s[k] != '10'[k % 2] for k in range(n))
        if min(c0, c1) <= numOps:
            return 1
        
        # 二分 [2, n]
        lo, hi = 2, n
        while lo < hi:
            mid = (lo + hi) // 2
            # cost(mid) = sum(L // (mid+1) for L in runs)
            ops = sum(L // (mid + 1) for L in runs)
            if ops <= numOps:
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log n)，二分 O(log n) 次，每次验证 O(n)
- 空间复杂度：O(n)，存储连续段长度数组

## 图解示例

```
s = "000001", numOps = 1
连续段: [5, 1]（五个 '0' 和一个 '1'）

cost(1): 变为 "010101" 需要翻转 3 次，变为 "101010" 需要翻转 4 次
         cost(1) = min(3, 4) = 3 > 1，mid=1 不可行

cost(2): runs=[5,1], cost = 5//(2+1) + 1//(2+1) = 1 + 0 = 1 <= 1 ✓

二分: lo=1, hi=6
  mid=3: cost = 5//4 + 0 = 1 <= 1 ✓ -> hi=3
  mid=2: cost = 5//3 + 0 = 1 <= 1 ✓ -> hi=2
  mid=1: cost=3 > 1 -> lo=2
lo=hi=2，答案为 2
```

## 关键点总结

1. 预计算连续段长度，加速每次验证。
2. `mid = 1` 特殊处理：变为交替字符串，枚举两种模式取最小。
3. `mid >= 2`：每段长度 `L` 的代价为 `L // (mid+1)`（每 `mid+1` 个插入一个翻转）。

## 易错点

1. `mid = 1` 必须单独处理，用通用公式会得到错误结果。
2. 打断代价是 `L // (mid + 1)`，不是 `(L - 1) // mid`（虽然有时结果相同，但语义不同）。
3. 二分的 `lo` 从 1 开始，因为答案最小为 1。
