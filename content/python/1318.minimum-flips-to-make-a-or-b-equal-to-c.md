## 题目描述

给你三个正整数 `a`、`b` 和 `c`。

你可以对 `a` 和 `b` 的二进制表示进行位翻转操作，返回能够使按位或运算 `a OR b == c` 成立的**最小翻转次数**。

「位翻转操作」是指将一个数的二进制位中的 `0` 变成 `1` 或者将 `1` 变成 `0`。

**示例 1：**

```
输入：a = 2, b = 6, c = 5
输出：3
解释：
a = 010, b = 110, c = 101
翻转后：a = 011, b = 100, c = 101
a OR b = 011 OR 100 = 111 != 101，再翻转...
实际最优：a = 001, b = 100, c = 101 (翻转3次)
```

**示例 2：**

```
输入：a = 4, b = 2, c = 7
输出：1
```

**示例 3：**

```
输入：a = 1, b = 2, c = 3
输出：0
```

**提示：**

- `1 <= a <= 10^9`
- `1 <= b <= 10^9`
- `1 <= c <= 10^9`

## 解题思路

**逐位分析**

对于每一位，独立分析 `a`、`b`、`c` 对应的比特位，分三种情况：

**情况 1：c 的该位为 1**
- 需要 `a OR b = 1`，即 a 或 b 中至少有一个为 1
- 若 `a=0, b=0`：需要翻转 1 次（将 a 或 b 任意一个翻成 1）
- 若 `a=1, b=0` 或 `a=0, b=1` 或 `a=1, b=1`：不需要翻转

**情况 2：c 的该位为 0**
- 需要 `a OR b = 0`，即 a 和 b 都必须为 0
- 若 `a=0, b=0`：不需要翻转
- 若 `a=1, b=0` 或 `a=0, b=1`：需要翻转 1 次
- 若 `a=1, b=1`：需要翻转 2 次

**总结：**

```
c位=1: 翻转次数 = 1 if (a位=0 AND b位=0) else 0
c位=0: 翻转次数 = a位 + b位（a和b中有几个1就翻几次）
```

## Python 代码实现

### 方法一：逐位枚举（推荐）

```python
class Solution:
    def minFlips(self, a: int, b: int, c: int) -> int:
        flips = 0
        
        # 枚举每一位（最多30位，因为 a,b,c <= 10^9 < 2^30）
        for _ in range(30):
            bit_a = a & 1   # a 的当前最低位
            bit_b = b & 1   # b 的当前最低位
            bit_c = c & 1   # c 的当前最低位
            
            if bit_c == 1:
                # c 该位为 1，a OR b 需为 1
                # 只有当 a=0 且 b=0 时才需要翻转 1 次
                if bit_a == 0 and bit_b == 0:
                    flips += 1
            else:
                # c 该位为 0，a OR b 需为 0，即 a 和 b 都需为 0
                # a 有几个 1，b 有几个 1，就需要翻转几次
                flips += bit_a + bit_b
            
            # 右移一位，处理下一位
            a >>= 1
            b >>= 1
            c >>= 1
        
        return flips
```

### 方法二：位运算一次性计算（高效）

```python
class Solution:
    def minFlips(self, a: int, b: int, c: int) -> int:
        # 分析每种情况：
        # c=1, a=0, b=0 的位：需要翻1次
        #   这些位满足：~(a|b) & c
        #   即 a OR b 为 0 但 c 为 1 的位
        need_one = ~(a | b) & c  # 这些位需要翻 1 次
        
        # c=0, a=1, b=0 或 c=0, a=0, b=1 的位：需要翻1次
        # c=0, a=1, b=1 的位：需要翻2次
        #   c=0 时需要将 a 和 b 的 1 全部翻成 0
        #   ~c & a 表示 c=0 且 a=1 的位（需要翻 a）
        #   ~c & b 表示 c=0 且 b=1 的位（需要翻 b）
        flip_a = ~c & a  # c=0 但 a=1，需翻 a
        flip_b = ~c & b  # c=0 但 b=1，需翻 b
        
        # 统计各自的 1 的个数
        return bin(need_one).count('1') + bin(flip_a).count('1') + bin(flip_b).count('1')
```

### 方法三：位运算（最简洁版）

```python
class Solution:
    def minFlips(self, a: int, b: int, c: int) -> int:
        # 利用按位与直接计算
        # 当 c 位为 1 时：若 (a|b) 的该位为 0，翻 1 次
        # 当 c 位为 0 时：a 的该位为 1 翻 1 次，b 的该位为 1 翻 1 次
        # 即：
        # 翻转数 = popcount(~(a|b) & c) + popcount(~c & a) + popcount(~c & b)
        
        # 注意 Python 整数是无限精度，需要掩码限制位数
        MASK = (1 << 30) - 1
        return (bin((~(a | b)) & c & MASK).count('1')
                + bin((~c) & a & MASK).count('1')
                + bin((~c) & b & MASK).count('1'))
```

## 复杂度分析

- **时间复杂度**：O(log max(a, b, c))，即最多处理 30 位
- **空间复杂度**：O(1)

## 图解示例

以 `a=2, b=6, c=5` 为例：

```
位编号: 2  1  0
a    : 0  1  0
b    : 1  1  0
c    : 1  0  1

位0: c=1, a=0, b=0 -> 需翻1次（a或b翻成1）
位1: c=0, a=1, b=1 -> 需翻2次（a翻成0，b翻成0）
位2: c=1, a=0, b=1 -> 不需翻（b=1已满足OR=1）

总计: 1 + 2 + 0 = 3
```

## 关键点总结

1. 对每一位独立分析，各位互不影响
2. `c=1` 时：a 和 b 同时为 0 才需要翻 1 次
3. `c=0` 时：a 有多少个 1 翻多少次，b 有多少个 1 翻多少次
4. `bin(x).count('1')` 是统计二进制位中 1 的个数的 Python 惯用方式

## 易错点

1. **c=0 时 a=1, b=1 需要翻 2 次**：两个都要翻，不能只翻一个
2. **Python 负数的位运算**：`~x` 在 Python 中是无限精度的负数，需要用掩码 `& MASK` 限制位数
3. **枚举位数要足够**：a, b, c 最大 10^9 < 2^30，枚举 30 位即可
