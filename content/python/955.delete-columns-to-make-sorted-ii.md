## 题目描述

给定由 `n` 个字符串组成的数组 `strs`，其中每个字符串长度相等。

选取一个删除索引序列，对于 `strs` 中的每个字符串，删除对应索引处的字符。

比如，有 `strs = ["abcdef", "uvwxyz"]`，删除索引序列 `{0, 2, 3}`，删除后 `strs` 为 `["bef", "vyz"]`。

假设我们选择了一组删除索引 D，那么在执行删除操作之后，`strs` 中剩余的每一行都是按字典序排列的（即 `strs[0] <= strs[1] <= strs[2] ... <= strs[n-1]`）。

请返回 D 的最小可能大小。

**示例 1：**
```
输入：strs = ["ca","bb","ac"]
输出：1
解释：
删除第 0 列后，strs = ["a", "b", "c"]
此时 strs 中元素是按字典序排列的（即，strs[0] <= strs[1] <= strs[2]）
我们至少需要进行 1 次删除，因为最初 strs 不是按字典序排列的
```

**示例 2：**
```
输入：strs = ["xc","yb","za"]
输出：0
解释：strs 的列已经是按字典序排列了，所以我们不需要删除任何东西
```

**示例 3：**
```
输入：strs = ["zyx","wvu","tsr"]
输出：3
解释：我们必须删掉所有 3 列
```

**提示：**
- `n == strs.length`
- `1 <= n <= 100`
- `1 <= strs[i].length <= 100`
- `strs[i]` 由小写英文字母组成

## 解题思路

这道题是要找出最少删除多少列，使得剩余的字符串数组按字典序排列。

**核心思想：**

1. **贪心策略**：从左到右遍历每一列
   - 如果保留这一列后，字符串仍然有序，就保留
   - 否则删除这一列

2. **有序性判断**：维护一个"已确定有序"的行对集合
   - 如果 `strs[i]` 已经确定小于 `strs[i+1]`（前面某列已经确定），则后续列不再需要检查这对
   - 只需要检查尚未确定顺序的相邻行对

3. **算法流程**：
   - 遍历每一列
   - 检查这一列是否会破坏顺序
   - 如果保留这列不破坏顺序，更新已确定有序的行对
   - 如果破坏顺序，删除计数加 1

## Python 代码实现

### 方法一：贪心 + 集合维护（推荐）⭐

```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        """
        贪心算法：逐列检查，维护已确定有序的行对
        
        思路：
        1. 遍历每一列
        2. 检查保留这列是否会破坏未确定的行对
        3. 如果不破坏，更新已确定的行对集合
        """
        n = len(strs)
        m = len(strs[0])
        
        # 已确定有序的行对：如果 sorted[i] = True，表示 strs[i] < strs[i+1] 已确定
        sorted_pairs = [False] * (n - 1)
        delete_count = 0
        
        # 遍历每一列
        for col in range(m):
            # 检查保留这一列是否会破坏顺序
            # 只检查尚未确定有序的相邻行对
            if self.is_valid_column(strs, col, sorted_pairs):
                # 保留这一列，更新已确定的行对
                self.update_sorted_pairs(strs, col, sorted_pairs)
            else:
                # 删除这一列
                delete_count += 1
        
        return delete_count
    
    def is_valid_column(self, strs: List[str], col: int, sorted_pairs: List[bool]) -> bool:
        """检查保留第 col 列是否会破坏顺序"""
        n = len(strs)
        for i in range(n - 1):
            # 如果这对已经确定有序，跳过
            if sorted_pairs[i]:
                continue
            # 如果当前列出现逆序，不能保留
            if strs[i][col] > strs[i + 1][col]:
                return False
        return True
    
    def update_sorted_pairs(self, strs: List[str], col: int, sorted_pairs: List[bool]):
        """更新已确定有序的行对"""
        n = len(strs)
        for i in range(n - 1):
            # 如果已经确定，跳过
            if sorted_pairs[i]:
                continue
            # 如果当前列确定了顺序，标记为已确定
            if strs[i][col] < strs[i + 1][col]:
                sorted_pairs[i] = True
```

### 方法二：简化版贪心

```python
class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        """
        简化版实现
        """
        n, m = len(strs), len(strs[0])
        
        # sorted[i] 表示前 i 和 i+1 行已确定有序
        sorted_pairs = [False] * (n - 1)
        delete_count = 0
        
        for col in range(m):
            # 检查这一列是否会产生逆序
            temp_sorted = sorted_pairs[:]  # 复制当前状态
            
            valid = True
            for i in range(n - 1):
                if sorted_pairs[i]:
                    continue
                
                if strs[i][col] > strs[i + 1][col]:
                    # 产生逆序，必须删除这一列
                    valid = False
                    break
                elif strs[i][col] < strs[i + 1][col]:
                    # 确定了顺序
                    temp_sorted[i] = True
            
            if valid:
                sorted_pairs = temp_sorted
            else:
                delete_count += 1
        
        return delete_count
```

### 方法三：一次遍历优化

```python
class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        """
        优化版：减少不必要的复制
        """
        n, m = len(strs), len(strs[0])
        sorted_pairs = [False] * (n - 1)
        delete_count = 0
        
        for col in range(m):
            # 检查是否需要删除当前列
            need_delete = False
            
            for i in range(n - 1):
                # 已确定有序的行对，跳过
                if sorted_pairs[i]:
                    continue
                # 出现逆序，标记删除
                if strs[i][col] > strs[i + 1][col]:
                    need_delete = True
                    break
            
            if need_delete:
                delete_count += 1
            else:
                # 更新已确定的行对
                for i in range(n - 1):
                    if not sorted_pairs[i] and strs[i][col] < strs[i + 1][col]:
                        sorted_pairs[i] = True
        
        return delete_count
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(N × M)
  - N 是字符串数量，M 是字符串长度
  - 需要遍历每一列，每列最多检查 N-1 对相邻行
- **空间复杂度**：O(N)，存储已确定有序的行对

## 关键点总结

1. **贪心思想**：逐列处理，尽可能保留每一列
2. **状态维护**：用布尔数组记录哪些行对已确定有序
3. **提前剪枝**：已确定有序的行对不需要再检查
4. **顺序判断**：只有严格小于才能确定顺序，等于不能确定
5. **逆序检测**：发现逆序立即删除该列

## 易错点

1. **等于的处理**：`strs[i][col] == strs[i+1][col]` 时不能确定顺序
2. **状态更新时机**：必须在确定不删除列后才更新 sorted_pairs
3. **边界条件**：只有一个字符串时，不需要删除任何列
4. **提前终止**：一旦所有行对都确定有序，可以提前结束
5. **复制 vs 原地修改**：要注意何时需要复制状态
