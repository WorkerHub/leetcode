## 题目描述

给你两个二维整数数组 `items1` 和 `items2`，表示两个背包中的物品。每个数组中第 `i` 个元素表示一个物品，包含两个整数 `[value_i, weight_i]`（价值和重量）。

两个数组中，`value_i` 各不相同（在同一个数组中）。

将两个数组合并：若两个物品价值相同，则合并为一个物品，重量相加；否则保留原物品。

返回合并后的物品数组，按**价值**升序排列。

**示例 1：**
```
输入：items1 = [[1,1],[4,5],[3,8]], items2 = [[3,1],[1,5]]
输出：[[1,6],[3,9],[4,5]]
```

**提示：**
- `1 <= items1.length, items2.length <= 1000`
- `items1[i].length == items2[i].length == 2`

## 解题思路

用哈希表统计每个价值对应的总重量，然后按价值排序输出。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def mergeSimilarItems(self, items1: List[List[int]], items2: List[List[int]]) -> List[List[int]]:
        weight = defaultdict(int)
        
        for v, w in items1:
            weight[v] += w
        for v, w in items2:
            weight[v] += w
        
        # 按价值排序输出
        return sorted([v, w] for v, w in weight.items())
```

### 方法二：排序合并

```python
from typing import List

class Solution:
    def mergeSimilarItems(self, items1: List[List[int]], items2: List[List[int]]) -> List[List[int]]:
        combined = sorted(items1 + items2)  # 合并后按价值排序
        result = []
        
        for v, w in combined:
            if result and result[-1][0] == v:
                result[-1][1] += w  # 合并同价值物品
            else:
                result.append([v, w])
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O((n+m) log(n+m)) | O(n+m) |
| 排序合并 | O((n+m) log(n+m)) | O(n+m) |

## 关键点总结

1. 用哈希表按价值分组累加重量，再排序输出。
2. 排序合并方法：合并两个数组后统一排序，遍历时合并相邻同价值项。

## 易错点

- 排序时是按价值升序，`sorted()` 默认按列表第一个元素升序，符合要求。
