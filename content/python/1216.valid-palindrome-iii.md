## 题目描述

[LeetCode 1216. Valid Palindrome Iii](https://leetcode.com/problems/valid-palindrome-iii/)

给定一个字符串 `s` 和一个整数 `k`，判断 `s` 是否是 `k` 回文串。

如果可以通过从字符串中删除最多 `k` 个字符将其转换为回文串，则字符串是 `k` 回文串。

示例 1：
```
输入：s = "abcdeca", k = 2
输出：true
解释：删除 "b" 和 "e" 可以得到回文串 "acdca"
```

示例 2：
```
输入：s = "abbababa", k = 1
输出：true
解释：删除 "b" 可以得到回文串 "abaaba"
```

提示：
- 1 <= s.length <= 1000
- s 仅由小写英文字母组成
- 1 <= k <= s.length

## 解题思路

这道题是经典回文问题的变种，核心是判断最少需要删除多少个字符才能使字符串成为回文串。

核心思路：
1. 将问题转化为：最少需要删除多少个字符使其成为回文
2. 如果最少删除数 <= k，则返回 true
3. 可以用动态规划求解最长回文子序列，删除数 = 总长度 - 最长回文子序列长度

关键观察：
- 最少删除字符数 = 字符串长度 - 最长回文子序列长度
- 最长回文子序列可以用 DP 求解
- 也可以直接用区间 DP 计算最少需要删除的字符数

两种思路：
1. 求最长回文子序列（LCS 问题的变种）
2. 区间 DP 直接计算最少删除数

## Python 代码实现

### 方法一：最长回文子序列（推荐）

```python
class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        # 方法：计算最长回文子序列的长度
        # 如果 len(s) - 最长回文子序列长度 <= k，则可以构成 k 回文
        
        n = len(s)
        
        # dp[i][j] 表示 s[i:j+1] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]
        
        # 单个字符的回文长度为 1
        for i in range(n):
            dp[i][i] = 1
        
        # 按子串长度递增的顺序填表
        for length in range(2, n + 1):  # 子串长度从 2 到 n
            for i in range(n - length + 1):
                j = i + length - 1
                
                if s[i] == s[j]:
                    # 两端字符相同，可以都包含在回文子序列中
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    # 两端字符不同，取较大的一个
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        
        # 最长回文子序列长度
        longest_palindrome = dp[0][n - 1]
        
        # 需要删除的字符数
        deletions_needed = n - longest_palindrome
        
        return deletions_needed <= k
```

### 方法二：递归 + 记忆化搜索

```python
from functools import lru_cache

class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        # 方法：使用递归 + 记忆化计算最长回文子序列
        
        @lru_cache(None)
        def longest_palindrome_subseq(i: int, j: int) -> int:
            """计算 s[i:j+1] 的最长回文子序列长度"""
            if i > j:
                return 0
            if i == j:
                return 1
            
            if s[i] == s[j]:
                return longest_palindrome_subseq(i + 1, j - 1) + 2
            else:
                return max(longest_palindrome_subseq(i + 1, j),
                          longest_palindrome_subseq(i, j - 1))
        
        n = len(s)
        longest = longest_palindrome_subseq(0, n - 1)
        
        return n - longest <= k
```

### 方法三：区间 DP（直接计算删除数）

```python
class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        # 方法：直接用 DP 计算最少需要删除多少个字符
        # dp[i][j] 表示使 s[i:j+1] 成为回文需要删除的最少字符数
        
        n = len(s)
        
        # dp[i][j] 表示 s[i:j+1] 变成回文需要删除的最少字符数
        dp = [[0] * n for _ in range(n)]
        
        # 按子串长度递增的顺序填表
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                if s[i] == s[j]:
                    # 两端字符相同，不需要删除
                    dp[i][j] = dp[i + 1][j - 1]
                else:
                    # 两端字符不同，删除其中一个
                    dp[i][j] = min(dp[i + 1][j], dp[i][j - 1]) + 1
        
        return dp[0][n - 1] <= k
```

### 方法四：空间优化的 DP

```python
class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        # 方法：空间优化，使用一维数组
        
        n = len(s)
        
        # 使用滚动数组优化空间
        prev = [0] * n
        
        for i in range(n - 1, -1, -1):
            curr = [0] * n
            curr[i] = 1  # 单个字符的回文长度为 1
            
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    curr[j] = prev[j - 1] + 2
                else:
                    curr[j] = max(curr[j - 1], prev[j])
            
            prev = curr
        
        longest_palindrome = prev[n - 1]
        return n - longest_palindrome <= k
```

## 复杂度分析

### 方法一/二/三：标准 DP
- 时间复杂度：O(n^2)，需要填充 n×n 的 DP 表
- 空间复杂度：O(n^2)，DP 表的大小

### 方法四：空间优化
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)，只使用一维数组

## 关键点总结

1. 问题本质是求最长回文子序列，转化为经典 DP 问题
2. DP 状态定义：dp[i][j] 表示子串 s[i:j+1] 的最长回文子序列长度
3. 状态转移：如果 s[i] == s[j]，则 dp[i][j] = dp[i+1][j-1] + 2；否则取 max
4. 最少删除数 = 总长度 - 最长回文子序列长度
5. 可以用记忆化搜索或自底向上的 DP 求解

## 易错点

1. 混淆子序列和子串：子序列不要求连续，可以删除中间字符
2. DP 的填表顺序：需要按照子串长度递增或者从右下到左上填表
3. 边界条件：单个字符时回文长度为 1，空字符串时为 0
4. 状态转移时的边界：当 i+1 > j-1 时，dp[i+1][j-1] 应该为 0
5. 比较时要用 <=，因为允许删除最多 k 个字符
