## 题目描述

给定一个整数数组 `nums`。每次操作可以选择相邻两个元素，将它们替换为它们的和（即删除一个，另一个变为两者之和）。求使数组变为非递减有序所需的最少操作次数。

**示例 1：**

```
输入：nums = [5, 2, 3, 1]
输出：2
解释：
操作1：合并 [5,2] -> [7, 3, 1]
操作2：合并 [7,3] -> [10, 1] ... 不对
更好：合并 [2,3] -> [5, 5, 1]，再合并 [5,1] -> [5, 6]，非递减，操作2次。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：0
解释：数组已经非递减，无需操作。
```

**提示：**
- `1 <= nums.length <= 50`
- `-1000 <= nums[i] <= 1000`

## 解题思路

由于数据规模很小（n <= 50），可以直接模拟。

贪心策略：
1. 找到数组中相邻的"逆序对"（即 `nums[i] > nums[i+1]`）
2. 合并这对相邻元素（取和），继续检查
3. 重复直到数组非递减

每次操作后，合并的结果可能与前面的元素形成新的逆序对，需要继续处理。

模拟过程：每轮扫描找到第一个逆序对并合并，统计操作次数。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        ops = 0
        nums = nums[:]  # 不修改原数组
        while True:
            # 检查是否已非递减
            is_sorted = all(nums[i] <= nums[i+1] for i in range(len(nums)-1))
            if is_sorted or len(nums) <= 1:
                break
            # 找第一个逆序对并合并
            for i in range(len(nums) - 1):
                if nums[i] > nums[i+1]:
                    # 合并 nums[i] 和 nums[i+1]
                    nums[i] = nums[i] + nums[i+1]
                    nums.pop(i+1)
                    ops += 1
                    break
        return ops
```

### 方法二：每轮合并所有逆序对（贪心优化）

```python
from typing import List

class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        ops = 0
        arr = list(nums)

        while len(arr) > 1:
            # 找所有逆序对中"代价最小"的合并
            # 由于规模小，直接找第一个逆序对
            found = False
            for i in range(len(arr) - 1):
                if arr[i] > arr[i+1]:
                    arr[i] += arr[i+1]
                    arr.pop(i+1)
                    ops += 1
                    found = True
                    break
            if not found:
                break

        return ops
```

## 复杂度分析

- 时间复杂度：O(n^2)，每次操作减少一个元素，共 n-1 次，每次扫描 O(n)
- 空间复杂度：O(n)，复制数组

## 关键点总结

1. 每次合并相邻的逆序对（较大元素在前）
2. 合并后可能产生新的逆序对，需要继续处理
3. 贪心：每次处理第一个逆序对

## 易错点

1. 合并后数组长度减 1，索引需要重新计算
2. 合并结果可能与更前面的元素形成新逆序对（需要重新从头扫描）
3. 单元素数组直接返回 0
