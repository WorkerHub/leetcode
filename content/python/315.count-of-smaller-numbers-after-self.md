## 题目描述

给你一个整数数组 `nums`，按要求返回一个新数组 `counts`。数组 `counts` 有该性质： `counts[i]` 的值是  `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

**示例 1：**
```
输入：nums = [5,2,6,1]
输出：[2,1,1,0] 
解释：
5 的右侧有 2 个更小的元素 (2 和 1)
2 的右侧仅有 1 个更小的元素 (1)
6 的右侧有 1 个更小的元素 (1)
1 的右侧有 0 个更小的元素
```

**示例 2：**
```
输入：nums = [-1]
输出：[0]
```

**示例 3：**
```
输入：nums = [-1,-1]
输出：[0,0]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

这是一道经典的**逆序对**问题的变体。

### 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 |
|------|-----------|-----------|------|
| 暴力 | O(n²) | O(1) | 简单 |
| 归并排序 | O(n log n) | O(n) | 中等 |
| 树状数组 | O(n log n) | O(n) | 中等 |
| 线段树 | O(n log n) | O(n) | 较难 |

### 核心思想

**从右往左遍历**，维护一个有序结构，统计当前元素在结构中的位置。

## Python 代码实现

### 方法一：归并排序（推荐）⭐

```python
from typing import List

class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 索引数组，用于归并排序时保持原始索引
        indices = list(range(n))
        # 结果数组
        counts = [0] * n
        
        def merge_sort(left: int, right: int):
            if left >= right:
                return
            
            mid = (left + right) // 2
            merge_sort(left, mid)
            merge_sort(mid + 1, right)
            merge(left, mid, right)
        
        def merge(left: int, mid: int, right: int):
            # 临时数组
            temp = []
            i, j = left, mid + 1
            
            while i <= mid and j <= right:
                if nums[indices[i]] <= nums[indices[j]]:
                    # 统计右侧小于当前元素的数量
                    counts[indices[i]] += j - (mid + 1)
                    temp.append(indices[i])
                    i += 1
                else:
                    temp.append(indices[j])
                    j += 1
            
            # 处理剩余元素
            while i <= mid:
                counts[indices[i]] += j - (mid + 1)
                temp.append(indices[i])
                i += 1
            
            while j <= right:
                temp.append(indices[j])
                j += 1
            
            # 更新索引数组
            for i in range(len(temp)):
                indices[left + i] = temp[i]
        
        merge_sort(0, n - 1)
        return counts
```

### 方法二：树状数组

```python
from typing import List

class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        # 离散化：将数值映射到 [1, n] 范围
        sorted_nums = sorted(set(nums))
        rank = {v: i + 1 for i, v in enumerate(sorted_nums)}
        
        n = len(sorted_nums)
        tree = [0] * (n + 1)
        
        def lowbit(x):
            return x & (-x)
        
        def update(i: int, delta: int):
            while i <= n:
                tree[i] += delta
                i += lowbit(i)
        
        def query(i: int) -> int:
            result = 0
            while i > 0:
                result += tree[i]
                i -= lowbit(i)
            return result
        
        result = []
        # 从右往左遍历
        for num in reversed(nums):
            r = rank[num]
            # 查询比当前元素小的数量
            result.append(query(r - 1))
            # 将当前元素加入树状数组
            update(r, 1)
        
        return result[::-1]
```

### 方法三：暴力方法（会超时）

```python
from typing import List

class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        result = []
        n = len(nums)
        
        for i in range(n):
            count = 0
            for j in range(i + 1, n):
                if nums[j] < nums[i]:
                    count += 1
            result.append(count)
        
        return result
```

### 方法四：二分查找 + 有序列表

```python
from typing import List
import bisect

class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        result = []
        sorted_list = []
        
        # 从右往左遍历
        for num in reversed(nums):
            # 二分查找插入位置
            pos = bisect.bisect_left(sorted_list, num)
            result.append(pos)
            # 插入元素
            sorted_list.insert(pos, num)
        
        return result[::-1]
```

## 复杂度分析

**归并排序：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

**树状数组：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

**二分查找 + 插入：**
- 时间复杂度：O(n²)，插入操作是 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **归并排序**：在合并时统计逆序对
2. **树状数组**：离散化 + 从右往左插入
3. **索引数组**：归并排序时需要保持原始索引
4. **从右往左**：维护已遍历元素的有序结构
5. **离散化**：树状数组需要将值映射到 [1, n] 范围

## 易错点

1. **归并排序的统计时机**：在左边元素归并时统计
2. **离散化**：树状数组的索引从 1 开始
3. **结果反转**：从右往左遍历，最后要反转结果
4. **等于的情况**：`<=` 时才统计右侧元素
5. **索引数组**：归并排序时要维护原始索引
