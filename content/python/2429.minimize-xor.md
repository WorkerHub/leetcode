## 题目描述

给你两个正整数 `num1` 和 `num2`，找出满足下述条件的整数 `x`：

- `x` 的置位数和 `num2` 的置位数相同。
- `x XOR num1` 的值 **最小化**。

返回整数 `x`。题目保证，对于给定的输入，满足条件的 `x` 是 **唯一** 的。

**置位数** 是一个数的二进制表示中 `1` 的个数。

**示例 1：**
```
输入：num1 = 3, num2 = 5
输出：3
解释：num1 = 3（二进制 011），num2 = 5（二进制 101，2 个置位）。x = 3（置位数 2，XOR = 0）。
```

**示例 2：**
```
输入：num1 = 1, num2 = 12
输出：3
解释：num1 = 1（001），num2 = 12（1100，3 个置位）。x = 3（011，置位数 3，1 XOR 3 = 2）。
```

## 解题思路

设 `k = popcount(num2)`（num2 的置位数），需要构造一个恰好有 `k` 个 1 的整数 x，使得 `x XOR num1` 最小。

**贪心策略：**
- 为使 `x XOR num1` 最小，x 的 1 应尽量与 num1 的 1 对齐（相同位置）
- 若 `k <= popcount(num1)`：从 num1 最高位开始，保留高位的 k 个 1，其余置 0
- 若 `k > popcount(num1)`：先保留 num1 的所有 1，再从低位开始补充额外的 1

## 代码实现

### 方法一：贪心位操作（推荐）

```python
class Solution:
    def minimizeXor(self, num1: int, num2: int) -> int:
        k = bin(num2).count('1')  # 需要的置位数
        p = bin(num1).count('1')  # num1 的置位数

        x = num1

        if k == p:
            return num1
        elif k < p:
            # 需要去掉 (p - k) 个 1，从低位开始去
            remove = p - k
            for i in range(30):
                if remove == 0:
                    break
                if x >> i & 1:  # 第 i 位是 1
                    x ^= (1 << i)  # 清除第 i 位
                    remove -= 1
        else:
            # 需要额外增加 (k - p) 个 1，从低位开始补
            add = k - p
            for i in range(30):
                if add == 0:
                    break
                if not (x >> i & 1):  # 第 i 位是 0
                    x |= (1 << i)  # 设置第 i 位为 1
                    add -= 1

        return x
```

### 方法二：逐位构造

```python
class Solution:
    def minimizeXor(self, num1: int, num2: int) -> int:
        k = bin(num2).count('1')
        x = 0
        used = 0  # 已使用的 1 的个数

        # 先从 num1 的高位 1 中取，优先和 num1 对齐
        for i in range(29, -1, -1):
            if used == k:
                break
            if num1 >> i & 1:
                x |= (1 << i)
                used += 1

        # 若还不够，从低位补充 0 位
        for i in range(30):
            if used == k:
                break
            if not (x >> i & 1):
                x |= (1 << i)
                used += 1

        return x
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心位操作 | O(30) = O(1) | O(1) |

## 关键点总结

1. 保留高位的 1：`x XOR num1` 最小，因为高位对应更大值
2. `k < p`：从低位开始移除多余的 1
3. `k > p`：先保留所有 1，再从低位补充 1（低位置 1 影响最小）

## 易错点

- `k < p` 时从低位移除（保留高位），而不是从高位移除
- `k > p` 时从低位补充（在 num1 的 0 位中从低位开始补）
