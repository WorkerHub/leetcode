## 题目描述

病毒扩散得很快，现在你的任务是尽可能地通过安装防火墙来隔离病毒。

假设世界由 m x n 的二维矩阵 isInfected 组成。isInfected[i][j] == 0 表示该区域未感染病毒，isInfected[i][j] == 1 表示该区域已感染病毒。

每天晚上，病毒会从被感染区域向相邻的未感染区域扩散。

你需要在每天早上选择一个区域建立防火墙，隔离该区域的病毒，使其无法扩散。

返回需要使用的防火墙个数。

## Python 代码实现

```python
from typing import List

class Solution:
    def containVirus(self, isInfected: List[List[int]]) -> int:
        m, n = len(isInfected), len(isInfected[0])
        total_walls = 0
        
        def dfs(i, j, region, frontier, perimeter):
            if i < 0 or i >= m or j < 0 or j >= n or (i, j) in region:
                return
            
            if isInfected[i][j] == 1:
                region.add((i, j))
                for di, dj in [(0,1),(0,-1),(1,0),(-1,0)]:
                    dfs(i+di, j+dj, region, frontier, perimeter)
            elif isInfected[i][j] == 0:
                frontier.add((i, j))
                perimeter[0] += 1
        
        while True:
            # 找到所有感染区域
            regions = []
            visited = set()
            
            for i in range(m):
                for j in range(n):
                    if isInfected[i][j] == 1 and (i, j) not in visited:
                        region = set()
                        frontier = set()
                        perimeter = [0]
                        dfs(i, j, region, frontier, perimeter)
                        visited |= region
                        regions.append((region, frontier, perimeter[0]))
            
            if not regions:
                break
            
            # 选择威胁最大的区域
            regions.sort(key=lambda x: len(x[1]), reverse=True)
            region, frontier, walls = regions[0]
            total_walls += walls
            
            # 隔离该区域
            for i, j in region:
                isInfected[i][j] = 2
            
            # 其他区域扩散
            for region, frontier, _ in regions[1:]:
                for i, j in frontier:
                    isInfected[i][j] = 1
        
        return total_walls
```

## 复杂度分析

- 时间复杂度：O((m*n)^2)
- 空间复杂度：O(m*n)

## 关键点总结

1. 使用 DFS 找到所有感染区域
2. 计算每个区域的威胁程度
3. 隔离威胁最大的区域
4. 模拟其他区域的扩散
