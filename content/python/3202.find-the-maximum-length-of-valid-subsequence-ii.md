## 题目描述

给你一个整数数组 `nums` 和一个**正整数** `k`。`nums` 的子序列 `sub` 的长度为 `x`，如果其满足以下条件，则称其为**有效子序列**：

- `(sub[0] + sub[1]) % k == (sub[1] + sub[2]) % k == ... == (sub[x - 2] + sub[x - 1]) % k`

返回 `nums` 的**最长有效子序列**的长度。

**示例 1：**
```
输入：nums = [1,2,3,4,5], k = 2
输出：5
解释：最长有效子序列是 [1,2,3,4,5]。
```

**示例 2：**
```
输入：nums = [1,4,2,3,1,4], k = 3
输出：4
解释：最长有效子序列是 [1,4,1,4]。
```

**提示：**
- `2 <= nums.length <= 10^3`
- `1 <= nums[i] <= 10^7`
- `1 <= k <= 10^3`

## 解题思路

枚举每种目标余数 `r`（0 到 k-1），对于每个固定的余数 `r`，用动态规划计算最长有效子序列：

- 定义 `dp[j]` 为末尾元素模 k 等于 `j` 的最长有效子序列长度
- 对于当前元素 `x`，其模 k 的值为 `cur = x % k`
- 与之配对的前一个元素模 k 应为 `prev = (r - cur % k + k) % k`
- 转移：`dp[cur] = dp[prev] + 1`

## Python 代码实现

### 方法一：枚举余数 + 动态规划（推荐）

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        ans = 0
        # 枚举目标相邻和余数
        for r in range(k):
            # dp[j] 表示末尾元素 mod k == j 的最长有效子序列
            dp = [0] * k
            for x in nums:
                cur = x % k
                # 前一个元素的余数
                prev = (r - cur + k) % k
                dp[cur] = dp[prev] + 1
            ans = max(ans, max(dp))
        return ans
```

### 方法二：优化写法

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        ans = 0
        mods = [x % k for x in nums]  # 预处理余数
        for r in range(k):
            dp = [0] * k
            for cur in mods:
                prev = (r - cur + k) % k
                dp[cur] = dp[prev] + 1
            ans = max(ans, max(dp))
        return ans
```

## 复杂度分析

- 时间复杂度：O(k * n)，枚举 k 种余数，每次遍历数组
- 空间复杂度：O(k)，dp 数组大小为 k

## 关键点总结

1. 固定目标余数 `r`，问题转化为简单的一维 DP
2. 末尾为 `cur` 时，前一元素余数必须是 `(r - cur + k) % k`
3. 由于 n 和 k 都不超过 1000，O(nk) 完全可以接受

## 易错点

1. 计算 `prev` 时需要加 `k` 再取模，防止负数
2. 本题与 3201 的区别在于 k 不一定是 2，不能简单用奇偶判断
