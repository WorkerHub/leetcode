## 题目描述

请你编写一个程序来计算两个日期之间隔了多少天。

日期以字符串形式给出，格式为 `YYYY-MM-DD`，如下面的例子所示。

**示例 1：**
```
输入：date1 = "2019-06-29", date2 = "2019-06-30"
输出：1
```

**示例 2：**
```
输入：date1 = "2020-01-15", date2 = "2019-12-31"
输出：15
```

**提示：**
- 给定的日期是 `1971` 年到 `2100` 年之间的有效日期。

## 解题思路

计算两个日期之间的天数差，有两种主要思路：

1. **Python datetime 库**：直接解析日期字符串，利用 `datetime.date` 对象相减得到 `timedelta`，取绝对值即可。非常简洁，是实际工程中的首选。

2. **手动计算**：将每个日期转换为从某个基准日（如 1971-01-01）起的天数，两者之差的绝对值即为答案。需要自己处理：
   - 每月的天数（28/29/30/31）
   - 闰年判断（能被 4 整除且不能被 100 整除，或能被 400 整除）
   - 累计到某年某月某日的总天数

## Python 代码实现

### 方法一：使用 datetime 库（推荐，最简洁）

```python
from datetime import date

class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        # 将字符串解析为 date 对象
        # date.fromisoformat() 接受 "YYYY-MM-DD" 格式（Python 3.7+）
        d1 = date.fromisoformat(date1)
        d2 = date.fromisoformat(date2)
        
        # 两个 date 对象相减得到 timedelta，取天数的绝对值
        return abs((d1 - d2).days)
```

**Python 3.6 及以下的写法：**

```python
from datetime import datetime

class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        fmt = "%Y-%m-%d"  # 日期格式模板
        d1 = datetime.strptime(date1, fmt)
        d2 = datetime.strptime(date2, fmt)
        return abs((d1 - d2).days)
```

### 方法二：手动计算（不使用 datetime 库）

```python
class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        
        def is_leap(year: int) -> bool:
            """判断是否为闰年"""
            # 能被 400 整除，或能被 4 整除但不能被 100 整除
            return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
        
        def days_in_month(year: int, month: int) -> int:
            """返回某年某月的天数"""
            if month in (1, 3, 5, 7, 8, 10, 12):
                return 31
            elif month in (4, 6, 9, 11):
                return 30
            else:  # 2月
                return 29 if is_leap(year) else 28
        
        def date_to_days(date_str: str) -> int:
            """
            将日期字符串转换为从 1971-01-01 起的天数
            （基准日可以任意选，只要两个日期用同一基准即可）
            """
            year, month, day = map(int, date_str.split('-'))
            
            total = 0
            
            # 累加 1971 年到 year-1 年的天数
            for y in range(1971, year):
                total += 366 if is_leap(y) else 365
            
            # 累加 year 年 1 月到 month-1 月的天数
            for m in range(1, month):
                total += days_in_month(year, m)
            
            # 加上当月的天数（第 day 天，从 1 开始，加 day-1 天后到达该日）
            total += day - 1
            
            return total
        
        return abs(date_to_days(date1) - date_to_days(date2))
```

### 方法三：手动计算（优化版，不用循环年份）

```python
class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        
        def is_leap(y: int) -> bool:
            return y % 400 == 0 or (y % 4 == 0 and y % 100 != 0)
        
        # 每月天数（平年）
        MONTHS = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        def date_to_days(s: str) -> int:
            y, m, d = map(int, s.split('-'))
            
            # 从公元 1 年 1 月 1 日起计算天数（格里高利历公式）
            # 完整年的天数：365*y + y//4 - y//100 + y//400
            y -= 1  # 计算前 y 年（不含当年）
            total = 365 * y + y // 4 - y // 100 + y // 400
            y += 1  # 恢复
            
            # 当年前 m-1 个月的天数
            for i in range(1, m):
                total += MONTHS[i]
                if i == 2 and is_leap(y):
                    total += 1  # 闰年 2 月加 1 天
            
            total += d  # 当月天数
            
            return total
        
        return abs(date_to_days(date1) - date_to_days(date2))
```

### 方法四：Zeller 公式（直接计算日序数）

```python
class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        
        def to_julian_day(s: str) -> int:
            """
            计算 Julian Day Number（儒略日数）
            这是天文学中常用的日期序数，从公元前 4713 年 1 月 1 日起
            """
            y, m, d = map(int, s.split('-'))
            # 将 1月、2月视为上一年的13月、14月，方便计算
            if m <= 2:
                y -= 1
                m += 12
            a = y // 100
            b = 2 - a + a // 4  # 格里高利历修正
            return int(365.25 * (y + 4716)) + int(30.6001 * (m + 1)) + d + b - 1524
        
        return abs(to_julian_day(date1) - to_julian_day(date2))
```

## 闰年规则详解

```
闰年判断规则：
1. 能被 400 整除 -> 闰年（如 2000, 1600）
2. 能被 100 整除但不能被 400 整除 -> 平年（如 1900, 2100）
3. 能被 4 整除但不能被 100 整除 -> 闰年（如 2004, 2024）
4. 其他 -> 平年（如 2019, 2021）

代码：year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
```

## 关键点总结

1. Python `datetime` 库是处理日期计算的标准工具，面试/竞赛中推荐使用。
2. 两个 `date` 对象相减得到 `timedelta` 对象，`.days` 属性是天数差（有正负），用 `abs()` 取绝对值。
3. 手动计算时，先写 `is_leap()` 辅助函数，再统计年、月、日各部分的天数。
4. 基准日可以任意选（如 1971-01-01 或公元 1 年 1 月 1 日），两个日期用同一基准相减即可。
5. 月份天数记忆口诀："一三五七八十腊，三十一天永不差，四六九冬三十天，只有二月二十八（闰年二十九）"。

## 易错点

- 闰年判断不能只用 `year % 4 == 0`，还要排除能被 100 整除但不能被 400 整除的年份。
- `timedelta.days` 可以是负数，必须用 `abs()` 取绝对值。
- `date.fromisoformat()` 需要 Python 3.7+，更兼容的写法是 `datetime.strptime()`。
- 手动计算月份天数时，2 月需要根据当年是否为闰年来决定是 28 还是 29 天。
