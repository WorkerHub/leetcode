## 题目描述

我们将只包含数字 4 和 7 的整数称为**幸运数**。

给你一个整数 `k`，返回第 `k` 个幸运数，以字符串表示。

**幸运数从小到大排列：**
- 1 位：4, 7
- 2 位：44, 47, 74, 77
- 3 位：444, 447, 474, 477, 744, 747, 774, 777
- ...

**示例 1：**
```
输入：k = 4
输出："47"
解释：第 4 个幸运数是 47
```

**示例 2：**
```
输入：k = 10
输出："744"
解释：第 10 个幸运数是 744
```

**示例 3：**
```
输入：k = 1000
输出："777747447"
```

**提示：**
- `1 <= k <= 10^9`

## 解题思路

幸运数构成一棵完全二叉树：
- 第 1 层（1 位数）：4, 7，共 2 个
- 第 2 层（2 位数）：44, 47, 74, 77，共 4 个
- 第 n 层共 2^n 个幸运数

**核心技巧**：将 `k+1` 转为二进制，去掉最高位的 1，然后将剩余位中的 0 替换为 '4'，1 替换为 '7'。

验证：
- k=1: k+1=2=`10`(二进制)，去掉最高位 -> `0` -> "4" ✓
- k=2: k+1=3=`11`(二进制)，去掉最高位 -> `1` -> "7" ✓
- k=3: k+1=4=`100`(二进制)，去掉最高位 -> `00` -> "44" ✓
- k=4: k+1=5=`101`(二进制)，去掉最高位 -> `01` -> "47" ✓

## Python 代码实现

### 方法一：二进制位运算（推荐）

```python
class Solution:
    def kthLuckyNumber(self, k: int) -> str:
        # k+1 转二进制，去掉最高位的 1
        # 每一位 0 对应 '4'，1 对应 '7'
        binary = bin(k + 1)[2:]  # bin() 返回 '0b...' 格式，[2:] 去掉前缀
        # 去掉最高位（第一个字符）
        binary = binary[1:]
        # 替换 0 -> '4'，1 -> '7'
        result = binary.replace('0', '4').replace('1', '7')
        return result
```

### 方法二：逐层定位（直观版）

```python
class Solution:
    def kthLuckyNumber(self, k: int) -> str:
        result = []
        # 找到 k 所在的层数
        # 前缀和：1层有2个，1+2层有6个，1+2+4层有14个
        # 也可以直接用二进制方法
        
        # 等价于方法一，这里展示另一种理解方式
        # 从最高位向最低位确定每一位是4还是7
        
        # 先确定位数 n
        count = 2  # 当前层的幸运数个数
        n = 1      # 位数
        while k > count:
            k -= count
            count *= 2
            n += 1
        
        # 现在 k 是第 n 位幸运数中的第 k 个
        # 类似二进制：第 k 个 n 位幸运数
        for _ in range(n):
            # 每层左半部分是前缀 4，右半部分是前缀 7
            count //= 2
            if k <= count:
                result.append('4')
            else:
                result.append('7')
                k -= count
        
        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O(log k)，因为幸运数的位数为 O(log k)
- 空间复杂度：O(log k)，存储结果字符串

## 关键点总结

1. 幸运数可以看作二叉树的节点，按层序排列
2. 将 k+1 转为二进制后，去掉最高位，剩余位 0 -> 4，1 -> 7
3. Python 的 `bin()` 函数返回 `'0b...'` 格式，需要用 `[2:]` 截取
4. 方法二的逐层定位更直观，每次将范围缩小一半

## 易错点

1. 注意是 `k+1` 不是 `k`，因为第 1 个对应 `10`(二进制) 而不是 `1`
2. 去掉二进制最高位后，空字符串对应位数为 0，不会出现（k >= 1 保证）
3. 方法二在初始化 count 时要对应当前层的数量
