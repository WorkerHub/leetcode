## 题目描述

给你一个下标从 0 开始的二维整数数组 `nums`，每个元素 `nums[i] = [start_i, end_i]` 表示数轴上区间 `[start_i, end_i]`。

返回数轴上被至少一辆汽车覆盖的**整数点**的数量。

**示例 1：**
```
输入：nums = [[3,6],[1,5],[4,7]]
输出：7
解释：整数点 1,2,3,4,5,6,7 都被覆盖
```

**示例 2：**
```
输入：nums = [[1,3],[5,8]]
输出：7
解释：整数点 1,2,3,5,6,7,8 都被覆盖（4 未被覆盖）
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= start_i <= end_i <= 100`

## 解题思路

数据范围小（坐标最大 100），直接用集合记录所有被覆盖的点。

**方法二（差分数组）：** 对每个区间 `[l, r]`，`diff[l] += 1`，`diff[r+1] -= 1`，求前缀和后统计正值的个数。

## Python 代码实现

### 方法一：集合（推荐，最简洁）

```python
from typing import List

class Solution:
    def numberOfPoints(self, nums: List[List[int]]) -> int:
        covered = set()
        for start, end in nums:
            for point in range(start, end + 1):
                covered.add(point)
        return len(covered)
```

### 方法二：差分数组

```python
from typing import List

class Solution:
    def numberOfPoints(self, nums: List[List[int]]) -> int:
        # 差分数组，范围 [1, 101]
        diff = [0] * 102

        for start, end in nums:
            diff[start] += 1
            diff[end + 1] -= 1

        # 前缀和，统计被覆盖的点
        count = 0
        prefix = 0
        for i in range(1, 102):
            prefix += diff[i]
            if prefix > 0:
                count += 1

        return count
```

### 方法三：位运算（简洁）

```python
from typing import List

class Solution:
    def numberOfPoints(self, nums: List[List[int]]) -> int:
        covered = 0  # 用整数位掩码
        for start, end in nums:
            for i in range(start, end + 1):
                covered |= (1 << i)
        return bin(covered).count('1')
```

## 复杂度分析

- 方法一：时间 O(n × max_range)，空间 O(max_range)
- 方法二：时间 O(n + max_range)，空间 O(max_range)
- 方法三：时间 O(n × max_range)，空间 O(1)（整数）

## 关键点总结

1. 数据范围小，直接枚举所有覆盖点
2. 集合自动去重，len(set) 就是覆盖点数
3. 差分数组更高效，适合大范围情况

## 易错点

1. 区间是闭区间 `[start, end]`，包含两端点
2. 差分数组中 `diff[end+1] -= 1`，注意数组大小需要 `end + 2`
