## 题目描述

给定一个二进制字符串 `s` 和一个正整数 `n`，如果对于 `[1, n]` 范围内的每个整数，其二进制表示都是 `s` 的子串，就返回 `true`，否则返回 `false`。

子串是字符串中连续的字符序列。

**示例 1：**
```
输入：s = "0110", n = 3
输出：true
解释：
1 的二进制表示是 "1"，在 s 中
2 的二进制表示是 "10"，在 s 中
3 的二进制表示是 "11"，在 s 中
```

**示例 2：**
```
输入：s = "0110", n = 4
输出：false
解释：
4 的二进制表示是 "100"，不在 s 中
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 不是 `'0'` 就是 `'1'`
- `1 <= n <= 10^9`

## 解题思路

这道题的核心是判断字符串 `s` 是否包含从 1 到 n 的所有整数的二进制表示作为子串。

**关键观察：**

1. **从大到小检查更高效**：如果一个较大的数的二进制表示不在 `s` 中，那么可以立即返回 `false`。从 n 开始向下检查，能更早发现不满足条件的情况。

2. **二进制位数的限制**：对于长度为 `len(s)` 的字符串，它最多能包含不同的 k 位二进制数是有限的。例如，k 位二进制数有 2^k 个，但是字符串 s 中长度为 k 的子串最多只有 `len(s) - k + 1` 个。

3. **剪枝优化**：当 n 足够大时（比如 n > 2^(len(s))），肯定无法满足条件。实际上，当 `len(s) < 32` 时，如果 `n > 2^(len(s)/2)` 左右，基本不可能满足。

4. **高位数字优先**：位数多的数字（大数）的二进制表示更难被包含，如果所有高位数都被包含了，低位数更容易被包含（因为它们是高位数的后缀或部分）。

**算法流程：**

1. 遍历从 n 到 1 的所有整数
2. 将每个整数转换为二进制字符串（去掉 '0b' 前缀）
3. 检查该二进制字符串是否是 s 的子串
4. 如果有任何一个不是子串，返回 `false`
5. 如果全部都是子串，返回 `true`

**优化策略：**

- 可以只检查较大的数（位数较多的），因为如果大数都包含了，小数更可能被包含
- 实际上，只需要检查位数最多的那一半数字即可

## Python 代码实现

### 方法一：暴力检查（基础解法）

```python
class Solution:
    def queryString(self, s: str, n: int) -> bool:
        """
        暴力检查从 1 到 n 的每个数的二进制表示是否都在 s 中
        
        时间复杂度：O(n * len(s))
        空间复杂度：O(log n) - 存储二进制字符串
        """
        # 遍历 1 到 n 的所有整数
        for i in range(1, n + 1):
            # 将整数转换为二进制字符串（去掉 '0b' 前缀）
            binary = bin(i)[2:]
            # 检查是否是 s 的子串
            if binary not in s:
                return False
        return True
```

### 方法二：从大到小检查（优化解法 ⭐ 推荐）

```python
class Solution:
    def queryString(self, s: str, n: int) -> bool:
        """
        从大到小检查，因为大数更难被包含
        如果大数都包含了，小数更可能被包含
        
        时间复杂度：O(n * len(s))
        空间复杂度：O(log n)
        """
        # 从 n 开始向下检查到 1
        for i in range(n, 0, -1):
            binary = bin(i)[2:]
            if binary not in s:
                return False
        return True
```

### 方法三：剪枝优化（最优解法 ⭐⭐）

```python
class Solution:
    def queryString(self, s: str, n: int) -> bool:
        """
        基于数学剪枝的优化方案
        
        关键观察：
        - k 位二进制数有 2^k 个
        - 字符串 s 中长度为 k 的不同子串最多有 len(s) 个
        - 因此如果 n 太大，不可能所有数都被包含
        
        时间复杂度：O(len(s)^2) - 最坏情况下检查所有子串
        空间复杂度：O(len(s))
        """
        # 如果 n 太大，直接返回 False
        # 长度为 len(s) 的字符串最多包含 len(s) 个不同的 k 位子串
        # 而 k 位二进制数有 2^k 个
        # 当 n > len(s) 时，大概率不可能满足
        if n > 2 * len(s):
            return False
        
        # 只需要检查较大的数（位数多的）
        # 如果所有大数都被包含，小数通常也会被包含
        # 检查范围：从 max(1, n//2) 到 n
        start = max(1, n // 2)
        
        # 从大到小检查
        for i in range(n, start - 1, -1):
            binary = bin(i)[2:]
            if binary not in s:
                return False
        
        # 还需要检查小的数，但可以用集合优化
        # 收集字符串中所有可能的二进制子串
        seen = set()
        for i in range(len(s)):
            for j in range(i + 1, min(i + 32, len(s) + 1)):  # 最多 31 位，因为 n <= 10^9 < 2^30
                substr = s[i:j]
                if substr[0] != '0':  # 二进制数不以 0 开头
                    num = int(substr, 2)
                    if num <= n:
                        seen.add(num)
        
        # 检查 1 到 start-1 是否都在集合中
        for i in range(1, start):
            if i not in seen:
                return False
        
        return True
```

### 方法四：哈希集合法（Python 特色解法 ⭐）

```python
class Solution:
    def queryString(self, s: str, n: int) -> bool:
        """
        使用哈希集合存储所有子串对应的数值
        然后检查 1 到 n 是否都在集合中
        
        时间复杂度：O(len(s)^2)
        空间复杂度：O(len(s))
        """
        # 早期剪枝：如果 n 过大，直接返回 False
        if n >= 2 * len(s):
            return False
        
        # 用集合存储所有有效的二进制子串对应的数值
        binary_nums = set()
        
        # 遍历所有子串
        for i in range(len(s)):
            # 二进制数不能以 0 开头（除了 0 本身，但题目范围从 1 开始）
            if s[i] == '0':
                continue
            
            # 枚举以 i 开头的所有子串
            for j in range(i + 1, min(i + 32, len(s) + 1)):  # 限制长度为 31 位
                substr = s[i:j]
                num = int(substr, 2)  # 将二进制字符串转换为整数
                
                # 只记录范围内的数
                if num <= n:
                    binary_nums.add(num)
                else:
                    break  # 如果已经超过 n，后面的更长子串也会超过
        
        # 检查是否包含 1 到 n 的所有数
        return len(binary_nums) == n and binary_nums == set(range(1, n + 1))
```

## 复杂度分析

**方法一和方法二（暴力检查）：**
- 时间复杂度：O(n × len(s))，需要检查 n 个数，每次检查是 O(len(s))
- 空间复杂度：O(log n)，存储二进制字符串的空间

**方法三和方法四（哈希集合法）：**
- 时间复杂度：O(len(s)^2)，遍历所有子串，子串数量是 O(len(s)^2)
- 空间复杂度：O(len(s))，哈希集合存储子串对应的数值

当 n 较小时，方法一、二更快；当 n 很大时，方法三、四更优。

## 关键点总结

1. **二进制转换**：使用 `bin(n)[2:]` 将整数转换为二进制字符串
2. **子串判断**：Python 中使用 `in` 操作符可以高效判断子串
3. **优化策略**：从大到小检查，因为大数的二进制表示更难被包含
4. **数学剪枝**：当 n 超过一定范围时（如 n > 2 × len(s)），可以直接返回 False
5. **位数限制**：由于 n <= 10^9 < 2^30，二进制字符串最多 30 位

## 易错点

1. **忘记去掉二进制前缀**：`bin()` 函数返回的字符串包含 `'0b'` 前缀，需要使用 `[2:]` 切片去掉
2. **边界条件**：n = 1 时，只需检查字符串是否包含 "1"
3. **过早优化**：盲目优化可能导致代码复杂且难以调试，先保证正确性
4. **二进制数不以 0 开头**：在提取子串时，需要排除以 '0' 开头的子串（除了 0 本身）
5. **数值范围**：n 最大可达 10^9，需要考虑性能优化
