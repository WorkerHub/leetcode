## 题目描述

给你一个正整数数组 `price`，其中 `price[i]` 表示第 `i` 类糖果的价格，以及一个正整数 `k`。

商店正在打折，你需要选择 `k` 类不同的糖果，放入购物篮中。篮子中糖果的**甜蜜度**等于篮子中任意两种糖果价格之差的 **绝对值** 的最小值。

返回篮子中糖果的 **最大甜蜜度**。

**示例 1：**

```
输入：price = [13,5,1,8,21,2], k = 3
输出：8
解释：选择价格为 [1, 8, 21] 的糖果，甜蜜度 = min(|1-8|, |8-21|, |1-21|) = min(7, 13, 20) = 7。
      选择价格为 [1, 8, 21]... 最优选择使得最小差为 8。
```

**示例 2：**

```
输入：price = [1,3,1], k = 2
输出：2
```

**提示：**

- `1 <= price.length <= 10^5`
- `1 <= price[i] <= 10^9`
- `2 <= k <= price.length`

## 解题思路

**二分答案**：二分最小差值 d，判断能否从 price 中选出 k 个数，使得任意两数之差 >= d。

贪心判断：排序后，贪心地选取尽可能多的数（每次选下一个满足差值 >= d 的数），统计最多能选多少个。

## Python 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
from typing import List

class Solution:
    def maximumTastiness(self, price: List[int], k: int) -> int:
        price.sort()
        n = len(price)

        def can_select(min_diff: int) -> bool:
            # 贪心：从最小价格开始，每次选满足差值 >= min_diff 的下一个
            count = 1
            last = price[0]
            for i in range(1, n):
                if price[i] - last >= min_diff:
                    count += 1
                    last = price[i]
                    if count == k:
                        return True
            return count >= k

        lo, hi = 0, price[-1] - price[0]
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_select(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：同样二分，边界处理更清晰

```python
from typing import List

class Solution:
    def maximumTastiness(self, price: List[int], k: int) -> int:
        price.sort()

        def check(d: int) -> bool:
            # 检查能否在差值 >= d 的约束下选 k 个
            cnt, prev = 1, price[0]
            for p in price[1:]:
                if p - prev >= d:
                    cnt += 1
                    prev = p
            return cnt >= k

        lo, hi = 0, (price[-1] - price[0])
        # 找最大满足 check 的 d
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log n + n log(maxDiff))，排序 O(n log n)，二分 O(log maxDiff) 次贪心各 O(n)
- 空间复杂度：O(1)（排序可原地）

## 关键点总结

1. 最小差值的最大化 → 典型"最大化最小值"二分题
2. 排序后贪心验证：从左到右依次选，每次选满足差值条件的最小元素
3. 二分时要注意上取整：`(lo + hi + 1) // 2`，避免死循环

## 易错点

1. 二分边界：lo = 0（可能差值为 0），hi = max - min
2. 验证函数中贪心选取：排序后从小到大，每次选满足 diff >= d 的最近元素
3. 查找"最大满足条件的值"时，mid 要上取整
