## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，以及整数 `k`，统计满足以下条件的元素对 `(i, j)` 的数量：
- `nums1[i] == nums2[j]`
- `|i - j| <= k`（下标差的绝对值不超过 k）

**示例 1：**
```
输入：nums1 = [1,2,3], nums2 = [1,3,2], k = 1
输出：2
解释：(0,0) 处 nums1[0]=nums2[0]=1，|0-0|=0<=1；
     (1,2) 处 nums1[1]=nums2[2]=2，|1-2|=1<=1；
     (2,1) 处 nums1[2]=nums2[1]=3，|2-1|=1<=1；共 3 对。
```

**示例 2：**
```
输入：nums1 = [1,2,1], nums2 = [1,1,1], k = 1
输出：3
解释：满足 nums1[i]==nums2[j] 且 |i-j|<=1 的对。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `1 <= nums1[i], nums2[j] <= 10^5`
- `0 <= k <= min(nums1.length, nums2.length)`

## 解题思路

**哈希表 + 滑动窗口：**

对于 `nums2` 中每个位置 `j`，找 `nums1` 中值相同且下标在 `[j-k, j+k]` 内的元素数量。

**方法：**
1. 构建哈希表：`val_to_indices`，记录 `nums1` 中每个值对应的下标列表
2. 对 `nums2` 中每个位置 `j`，查找 `nums1` 中值为 `nums2[j]` 的下标列表，用二分统计在 `[j-k, j+k]` 内的下标数

## Python 代码实现

### 方法一：哈希表 + 二分（推荐）

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def countCommonElements(self, nums1: List[int], nums2: List[int], k: int) -> int:
        # 构建 nums1 的值 -> 下标列表映射（有序）
        val_to_idx = defaultdict(list)
        for i, v in enumerate(nums1):
            val_to_idx[v].append(i)

        ans = 0
        for j, v in enumerate(nums2):
            if v in val_to_idx:
                indices = val_to_idx[v]
                # 统计 indices 中在 [j-k, j+k] 范围内的数量
                lo = bisect.bisect_left(indices, j - k)
                hi = bisect.bisect_right(indices, j + k)
                ans += hi - lo

        return ans
```

### 方法二：排序 + 双指针

```python
from typing import List

class Solution:
    def countCommonElements(self, nums1: List[int], nums2: List[int], k: int) -> int:
        # 将匹配对收集后，按下标差排序
        from collections import defaultdict

        val_to_idx1 = defaultdict(list)
        for i, v in enumerate(nums1):
            val_to_idx1[v].append(i)

        ans = 0
        for j in range(len(nums2)):
            v = nums2[j]
            for i in val_to_idx1.get(v, []):
                if abs(i - j) <= k:
                    ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，n 为 nums1 长度，m 为 nums2 长度
- 空间复杂度：O(n)，哈希表存储 nums1 的下标

## 关键点总结

1. 哈希表预处理 nums1 的值到有序下标列表的映射
2. 二分查找在 O(log n) 内统计合法下标数量
3. 双重约束：值相等 且 下标差 <= k

## 易错点

1. 下标差是绝对值：`|i - j| <= k`，即 `j - k <= i <= j + k`
2. `bisect_right` 查找右边界时用 `j + k`（包含）
3. 两数组长度可以不同
