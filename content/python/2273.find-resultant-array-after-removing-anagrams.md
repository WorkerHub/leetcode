## 题目描述

给你一个字符串数组 `words`，在一步操作中，你可以删除 `words` 中任意一个字符串（当它和它前面的字符串互为**变位词**时）。

重复执行，直到不能删除为止，返回最终的字符串数组。

两个字符串 `s` 和 `t` 互为变位词：若它们包含的字母及每种字母的数量完全相同（不考虑顺序）。

**示例 1：**
```
输入：words = ["ba","ab","cd","cd","efg"]
输出：["ba","cd","efg"]
解释："ab" 是 "ba" 的变位词，删除；第二个 "cd" 是第一个的变位词，删除。
```

**示例 2：**
```
输入：words = ["a","b","c","d","e"]
输出：["a","b","c","d","e"]
```

## 解题思路

模拟：用栈维护结果数组，若当前字符串与栈顶字符串互为变位词，则跳过（不加入栈），否则加入栈。

判断变位词：排序后是否相等（或用 Counter 比较）。

## 代码实现

### 方法一：栈模拟（推荐）

```python
from typing import List

class Solution:
    def removeAnagrams(self, words: List[str]) -> List[str]:
        result = [words[0]]  # 第一个词一定保留

        for i in range(1, len(words)):
            # 若与前一个不互为变位词，则保留
            if sorted(words[i]) != sorted(result[-1]):
                result.append(words[i])

        return result
```

### 方法二：Counter 比较

```python
from typing import List
from collections import Counter

class Solution:
    def removeAnagrams(self, words: List[str]) -> List[str]:
        result = [words[0]]

        for word in words[1:]:
            if Counter(word) != Counter(result[-1]):
                result.append(word)

        return result
```

### 方法三：一行式

```python
from typing import List

class Solution:
    def removeAnagrams(self, words: List[str]) -> List[str]:
        # 保留 words[0] 和与前一词不是变位词的词
        ans = [words[0]]
        [ans.append(w) for w in words[1:] if sorted(w) != sorted(ans[-1])]
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * L log L)，n 为单词数，L 为最长单词长度（排序）。
- 空间复杂度：O(n * L)，存储结果。

## 关键点总结

1. 题目说删除变位词直到不能删为止，等价于：相邻变位词中保留最前面的那个。
2. 用栈/结果数组维护，与前一个比较（`result[-1]`）。
3. 排序后比较或用 Counter 判断变位词。

## 易错点

- 比较的是与前一个保留词的关系（`result[-1]`），不是与原数组前一个的关系。
- 删除是针对与前一个词的关系，不是任意位置。
