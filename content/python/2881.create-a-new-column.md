## 题目描述

给定一个 DataFrame `employees`，创建一个新列 `bonus`，值为每个员工 `salary` 的两倍。

**示例：**
```
输入：
+-----------+---------+--------+
| emp_id    | name    | salary |
+-----------+---------+--------+
| 3         | Bob     | 48675  |
| 90        | Alice   | 11096  |
...

输出：
+-----------+---------+--------+--------+
| emp_id    | name    | salary | bonus  |
+-----------+---------+--------+--------+
| 3         | Bob     | 48675  | 97350  |
| 90        | Alice   | 11096  | 22192  |
...
```

## Python 代码实现

### 方法一：直接列运算（推荐）

```python
import pandas as pd

def createBonusColumn(employees: pd.DataFrame) -> pd.DataFrame:
    # 创建新列：salary 的两倍
    employees['bonus'] = employees['salary'] * 2
    return employees
```

### 方法二：assign 方法（不修改原 DataFrame）

```python
import pandas as pd

def createBonusColumn(employees: pd.DataFrame) -> pd.DataFrame:
    return employees.assign(bonus=employees['salary'] * 2)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（新列）

## 关键点总结

1. `df['new_col'] = expression` 直接添加新列
2. `df.assign(col=expr)` 返回新 DataFrame（不修改原 df）
3. 列运算是向量化的，不需要循环
