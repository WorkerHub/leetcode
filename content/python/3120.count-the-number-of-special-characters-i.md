## 题目描述

给你一个字符串 `word`。如果某个字母的大写和小写形式都出现在 `word` 中，则称该字母为 **特殊字母**。

返回 `word` 中 **特殊字母** 的数量。

**示例 1：**
```
输入：word = "aaAbcBC"
输出：3
解释：特殊字母为 'a'、'b'、'c'（它们的大小写形式都出现了）。
```

**示例 2：**
```
输入：word = "abc"
输出：0
```

**提示：**
- `1 <= word.length <= 50`
- `word` 只包含英文字母

## 解题思路

使用集合存储字符串中出现的所有字符，然后遍历 26 个字母，检查每个字母的大写和小写是否都在集合中。

## Python 代码实现

### 方法一：集合查询（推荐）

```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        chars = set(word)
        ans = 0
        for c in 'abcdefghijklmnopqrstuvwxyz':
            if c in chars and c.upper() in chars:
                ans += 1
        return ans
```

### 方法二：集合交集

```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        chars = set(word)
        # 找出所有小写字母，其大写也在集合中
        return sum(
            1 for c in 'abcdefghijklmnopqrstuvwxyz'
            if c in chars and c.upper() in chars
        )
```

## 复杂度分析

- 时间复杂度：O(n + 26)，n 为字符串长度，构建集合 O(n)，查询 26 次
- 空间复杂度：O(n)，集合大小

## 关键点总结

1. 用集合存储所有出现的字符，O(1) 查询
2. 遍历 26 个字母，检查大小写都出现

## 易错点

1. 只统计字母数量（26 个），不是字符个数
2. 'a' 和 'A' 算同一个特殊字母
