## 题目描述

中心对称数是指一个数字在旋转了 180 度之后看起来依旧相同的数字（或者上下颠倒地看）。

编写一个函数来判断该数字是否是中心对称数，其输入将会以一个字符串的形式来表达数字。

**示例 1：**
```
输入: num = "69"
输出: true
```

**示例 2：**
```
输入: num = "88"
输出: true
```

**示例 3：**
```
输入: num = "962"
输出: false
```

**示例 4：**
```
输入: num = "1"
输出: true
```

**提示：**
- 1 <= num.length <= 50
- num 只包含数字

## 解题思路

中心对称数的核心是：数字旋转 180 度后与原数字相同。

**关键观察：**
1. 只有 0、1、6、8、9 这 5 个数字旋转 180 度后还是数字
2. 旋转后的映射关系：
   - 0 → 0
   - 1 → 1
   - 6 → 9
   - 8 → 8
   - 9 → 6
3. 其他数字（2、3、4、5、7）旋转后不是有效数字

**算法思路：**
- 使用双指针从两端向中间检查
- 左指针的数字旋转后应该等于右指针的数字
- 如果某个位置的数字不能旋转（2、3、4、5、7），直接返回 False

## Python 代码实现

### 方法一：双指针 + 哈希表（推荐）⭐

```python
class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        """
        双指针检查对称性
        时间复杂度：O(n)，n 是字符串长度
        空间复杂度：O(1)，哈希表大小固定
        """
        # 旋转映射关系
        rotation_map = {
            '0': '0',
            '1': '1',
            '6': '9',
            '8': '8',
            '9': '6'
        }
        
        left, right = 0, len(num) - 1
        
        while left <= right:
            # 检查左边字符是否能旋转
            if num[left] not in rotation_map:
                return False
            
            # 检查旋转后是否等于右边字符
            if rotation_map[num[left]] != num[right]:
                return False
            
            left += 1
            right -= 1
        
        return True
```

### 方法二：创建旋转字符串比较

```python
class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        """
        构造旋转后的字符串，然后比较
        时间复杂度：O(n)
        空间复杂度：O(n)，需要存储旋转后的字符串
        """
        rotation_map = {
            '0': '0', '1': '1', '6': '9',
            '8': '8', '9': '6'
        }
        
        # 构造旋转后的字符串（逆序）
        rotated = []
        for char in reversed(num):
            if char not in rotation_map:
                return False
            rotated.append(rotation_map[char])
        
        # 比较原字符串和旋转后的字符串
        return ''.join(rotated) == num
```

### 方法三：Pythonic 写法

```python
class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        """
        使用 Python 特性简化代码
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        pairs = {'0': '0', '1': '1', '6': '9', '8': '8', '9': '6'}
        
        # 检查每对字符
        return all(
            num[i] in pairs and pairs[num[i]] == num[~i]
            for i in range(len(num) // 2 + 1)
        )
```

### 方法四：使用对称性检查

```python
class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        """
        利用对称性直接检查
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        valid_pairs = {
            ('0', '0'), ('1', '1'), ('6', '9'),
            ('8', '8'), ('9', '6')
        }
        
        n = len(num)
        for i in range((n + 1) // 2):  # 遍历到中间位置（包括中间）
            pair = (num[i], num[n - 1 - i])
            if pair not in valid_pairs:
                return False
        
        return True
```

### 方法五：单次遍历优化

```python
class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        """
        单次遍历，提前返回优化
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 使用列表存储映射，避免字典查找
        # rotation[digit] = 旋转后的数字，-1 表示无效
        rotation = [-1] * 10
        rotation[0] = 0
        rotation[1] = 1
        rotation[6] = 9
        rotation[8] = 8
        rotation[9] = 6
        
        left, right = 0, len(num) - 1
        
        while left <= right:
            left_digit = int(num[left])
            right_digit = int(num[right])
            
            # 检查是否有效
            if rotation[left_digit] == -1 or rotation[left_digit] != right_digit:
                return False
            
            left += 1
            right -= 1
        
        return True
```

| Pythonic 写法 | O(n) | O(n) | 简洁但可读性稍差 |
| 对称性检查 | O(n) | O(1) | 使用元组集合 |

## 关键点总结

1. **有效数字**：只有 0、1、6、8、9 这 5 个数字可以旋转
2. **映射关系**：6 ↔ 9 互换，0、1、8 保持不变
3. **双指针技巧**：从两端向中间检查，对称性问题的常用方法
4. **中间字符**：当长度为奇数时，中间字符必须是 0、1、8（自对称）
5. **提前返回**：发现不匹配立即返回 False

## 易错点

1. **中间字符**：长度为奇数时，中间字符必须是 0、1、8，不能是 6 或 9
2. **映射方向**：6 旋转后是 9，9 旋转后是 6，不要弄反
3. **无效数字**：2、3、4、5、7 不能出现，出现即返回 False
4. **边界条件**：单个字符也要检查是否能自对称
5. **双指针边界**：left <= right 要包含等号（奇数长度需检查中间）
