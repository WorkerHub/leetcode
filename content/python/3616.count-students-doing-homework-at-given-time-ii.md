## 题目描述

给你两个整数数组 `startTime` 和 `endTime`，以及整数 `queryTime`。

第 `i` 个学生在时间区间 `[startTime[i], endTime[i]]` 内做作业（包含端点）。返回在时间点 `queryTime` 时正在做作业的学生数量。

**示例 1：**

```
输入：startTime = [1,2,3], endTime = [3,2,7], queryTime = 4
输出：1
解释：只有第3个学生（[3,7]）在时间4做作业
```

**示例 2：**

```
输入：startTime = [4], endTime = [4], queryTime = 4
输出：1
```

**提示：**

- `startTime.length == endTime.length`
- `1 <= startTime.length <= 100`
- `1 <= startTime[i] <= endTime[i] <= 1000`
- `1 <= queryTime <= 1000`

## 解题思路

直接遍历每个学生，检查 `queryTime` 是否在其作业时间段内。

条件：`startTime[i] <= queryTime <= endTime[i]`

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def busyStudent(self, startTime: List[int], endTime: List[int], queryTime: int) -> int:
        count = 0
        for s, e in zip(startTime, endTime):
            if s <= queryTime <= e:
                count += 1
        return count
```

### 方法二：函数式写法

```python
from typing import List

class Solution:
    def busyStudent(self, startTime: List[int], endTime: List[int], queryTime: int) -> int:
        return sum(s <= queryTime <= e for s, e in zip(startTime, endTime))
```

## 复杂度分析

- 时间复杂度：O(n)，n 为学生数量
- 空间复杂度：O(1)

## 关键点总结

1. 区间判断：左闭右闭区间 `[s, e]`
2. Python 链式比较 `s <= queryTime <= e` 简洁易读
3. `zip` 同步遍历两个数组

## 易错点

1. 端点包含：`<=` 而非 `<`
2. 两个数组长度相同，可以用 `zip`
