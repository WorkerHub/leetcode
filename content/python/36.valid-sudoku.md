## 题目描述

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可。

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3 x 3` 宫内只能出现一次。

**注意：**
- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

**示例 1：**
```
输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

**示例 2：**
```
输入：board = 
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与示例1相同。但由于位于左上角的 3x3 宫内有两个 8 存在, 因此这个数独是无效的。
```

## 解题思路

### 核心思想：哈希表记录

需要检查三个条件：
1. 每行没有重复数字
2. 每列没有重复数字
3. 每个 3×3 宫格没有重复数字

**算法流程：**
1. 遍历数独的每个格子
2. 对于每个非空格子 `board[i][j]`：
   - 检查该数字是否在第 `i` 行出现过
   - 检查该数字是否在第 `j` 列出现过
   - 检查该数字是否在所在的 3×3 宫格出现过
3. 用哈希表记录已出现的数字

**关键：如何确定 3×3 宫格？**
- 宫格索引 = `(i // 3, j // 3)`
- 例如 `(4, 5)` 在第 `(1, 1)` 个宫格

## Python 代码实现

### 方法一：哈希表（使用集合）

```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        # 记录每行、每列、每个宫格出现的数字
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        
        for i in range(9):
            for j in range(9):
                num = board[i][j]
                
                # 跳过空格
                if num == '.':
                    continue
                
                # 计算宫格索引
                box_index = (i // 3) * 3 + j // 3
                
                # 检查是否重复
                if num in rows[i] or num in cols[j] or num in boxes[box_index]:
                    return False
                
                # 记录该数字
                rows[i].add(num)
                cols[j].add(num)
                boxes[box_index].add(num)
        
        return True
```

### 方法二：一次遍历（使用字典）

```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        seen = set()
        
        for i in range(9):
            for j in range(9):
                num = board[i][j]
                
                if num == '.':
                    continue
                
                # 用字符串标记数字在行、列、宫格中的出现
                row_key = f'{num} in row {i}'
                col_key = f'{num} in col {j}'
                box_key = f'{num} in box {i//3}-{j//3}'
                
                # 检查是否已存在
                if row_key in seen or col_key in seen or box_key in seen:
                    return False
                
                # 添加到集合
                seen.add(row_key)
                seen.add(col_key)
                seen.add(box_key)
        
        return True
```

### 方法三：使用位运算（空间优化）

```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        # 用位掩码记录，每一位表示数字1-9是否出现
        rows = [0] * 9
        cols = [0] * 9
        boxes = [0] * 9
        
        for i in range(9):
            for j in range(9):
                if board[i][j] == '.':
                    continue
                
                num = int(board[i][j])
                box_index = (i // 3) * 3 + j // 3
                
                # 检查该数字对应的位是否已设置
                bit = 1 << num
                if (rows[i] & bit) or (cols[j] & bit) or (boxes[box_index] & bit):
                    return False
                
                # 设置该位
                rows[i] |= bit
                cols[j] |= bit
                boxes[box_index] |= bit
        
        return True
```

- **时间复杂度**：O(1)，固定遍历 81 个格子
- **空间复杂度**：O(1)，固定使用 9 个集合/数组

## 图解示例

### 宫格索引计算：

```
数独被分成 9 个 3×3 宫格，编号 0-8：

+-------+-------+-------+
| 0 0 0 | 1 1 1 | 2 2 2 |
| 0 0 0 | 1 1 1 | 2 2 2 |
| 0 0 0 | 1 1 1 | 2 2 2 |
+-------+-------+-------+
| 3 3 3 | 4 4 4 | 5 5 5 |
| 3 3 3 | 4 4 4 | 5 5 5 |
| 3 3 3 | 4 4 4 | 5 5 5 |
+-------+-------+-------+
| 6 6 6 | 7 7 7 | 8 8 8 |
| 6 6 6 | 7 7 7 | 8 8 8 |
| 6 6 6 | 7 7 7 | 8 8 8 |
+-------+-------+-------+

宫格索引公式：(i // 3) * 3 + j // 3

例如：
(0, 0) → (0//3)*3 + 0//3 = 0
(2, 4) → (2//3)*3 + 4//3 = 0*3 + 1 = 1
(5, 7) → (5//3)*3 + 7//3 = 1*3 + 2 = 5
```

## 关键点总结

1. **宫格索引计算**：
   - `box_index = (i // 3) * 3 + j // 3`
   - 这是本题的核心技巧

2. **三重检查**：
   - 行：`rows[i]`
   - 列：`cols[j]`
   - 宫格：`boxes[box_index]`

3. **数据结构选择**：
   - 集合（set）：简单直观
   - 字典（dict）：可以用字符串作为key
   - 位运算：空间最优

4. **边界条件**：
   - 空格用 `'.'` 表示，需要跳过

## 易错点

1. **宫格索引计算**：
   - 容易写错公式
   - 记住：`(i // 3) * 3 + j // 3`

2. **字符和整数**：
   - `board[i][j]` 是字符串
   - 位运算版本需要转换为整数

3. **空格判断**：
   - 要先判断是否为 `'.'`，再处理
