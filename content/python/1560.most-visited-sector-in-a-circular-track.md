## 题目描述

给你一个整数 `n` 和一个整数数组 `rounds`，表示在一个有 `n` 个扇区（1 到 n）的环形赛道上进行若干圈的比赛。

`rounds[i]` 表示第 i 圈结束时停在哪个扇区。赛道按 1, 2, ..., n, 1, 2, ... 的顺序循环。

返回访问次数最多的扇区列表（升序）。

**示例 1：**
```
输入：n = 4, rounds = [1,3,1,2]
输出：[1,2]
解释：1->2->3->1->2->3->4->1->2，各扇区访问次数 1:3, 2:3, 3:2, 4:1，1和2最多。
```

## 解题思路

### 关键观察

完整地走了多圈后，每个扇区被访问的次数大致相同（差距最多1）。

最终答案就是从起点的下一个扇区到终点（沿循环顺序）的所有扇区，这些扇区比其他扇区多访问了 1 次。

- 起点：`rounds[0]`
- 终点：`rounds[-1]`

若终点 >= 起点，则答案是 `[rounds[0], rounds[-1]]` 之间的扇区。
若终点 < 起点，则答案是 `[rounds[0], n] + [1, rounds[-1]]` 的扇区。

## 代码实现

### 方法一：数学分析（推荐）

```python
from typing import List

class Solution:
    def mostVisited(self, n: int, rounds: List[int]) -> List[int]:
        start = rounds[0]
        end = rounds[-1]
        if start <= end:
            # 终点在起点右侧或相同
            return list(range(start, end + 1))
        else:
            # 终点在起点左侧，绕过了 n
            return list(range(1, end + 1)) + list(range(start, n + 1))
```

### 方法二：模拟统计（直观）

```python
from typing import List

class Solution:
    def mostVisited(self, n: int, rounds: List[int]) -> List[int]:
        # 统计每个扇区的访问次数
        count = [0] * (n + 1)

        # 第一圈从 1 开始，结束在 rounds[0]
        for s in range(1, rounds[0] + 1):
            count[s] += 1

        # 后续各圈
        for i in range(1, len(rounds)):
            start = rounds[i-1]
            end = rounds[i]
            if end >= start:
                for s in range(start + 1, end + 1):
                    count[s] += 1
            else:
                for s in range(start + 1, n + 1):
                    count[s] += 1
                for s in range(1, end + 1):
                    count[s] += 1

        max_cnt = max(count)
        return [i for i in range(1, n + 1) if count[i] == max_cnt]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N) | O(N) |
| 方法二 | O(N * rounds) 最坏 | O(N) |

## 关键点总结

1. 访问最多的扇区 = 从起点（含）到终点（含）沿顺序的扇区
2. 若终点 >= 起点：`[start, end]`；否则：`[start, n] + [1, end]`
3. 只需看第一圈起点和最后圈终点，中间的完整圈每个扇区访问次数相同

## 易错点

- 起点是 `rounds[0]`（第一圈结束位置，也是第一圈经过的最后一个扇区）
- 注意从位置 1 出发到 `rounds[0]`（第一圈）
