## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。你可以执行 **恰好一次** 操作：选择某个元素将其乘以 `2^k`（即左移 k 位）。

返回操作后所有元素按位或（OR）运算的最大值。

**示例 1：**
```
输入：nums = [12,9], k = 1
输出：30
解释：选 nums[1]=9，乘以2变18，12|18 = 28... 
或者 nums[0]=12，乘以2变24，24|9 = 25
实际最优：选 9*2=18，12|18 = 28；选 12*2=24，24|9 = 25
答案是30？让我重算：12=1100, 9=1001, k=1
9<<1=18=10010, 12|18=11110=30
12<<1=24=11000, 24|9=11001=25
所以答案是30
```

**示例 2：**
```
输入：nums = [8,1,2], k = 2
输出：35
```

**数据范围：**
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^9
- 1 <= k <= 15

## 解题思路

贪心：对每个位置 `i`，若选择将 `nums[i]` 左移 k 位，结果为 `(prefix_or[i-1] | (nums[i] << k) | suffix_or[i+1])`。其中前缀 OR 和后缀 OR 可以预计算。

枚举所有可能的选择，取最大值。

## Python 代码实现

### 方法一：前缀 OR + 后缀 OR（推荐）

```python
from typing import List

class Solution:
    def maximumOr(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # 计算前缀 OR（prefix[i] = nums[0] | nums[1] | ... | nums[i-1]）
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] | nums[i]

        # 计算后缀 OR（suffix[i] = nums[i+1] | ... | nums[n-1]）
        suffix = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix[i] = suffix[i + 1] | nums[i]

        ans = 0
        for i in range(n):
            # 选择将 nums[i] 左移 k 位
            result = prefix[i] | (nums[i] << k) | suffix[i + 1]
            ans = max(ans, result)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 预计算前缀 OR 和后缀 OR，枚举每个选择
2. 选择 `i` 的结果 = 前缀 OR | (nums[i] << k) | 后缀 OR

## 易错点

1. 注意前缀 OR 不包括当前元素，后缀 OR 不包括当前元素
2. 乘以 `2^k` 等价于左移 k 位 `<< k`
