## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，从中选出若干个格子，满足：
- 每行最多选 1 个格子
- 所有选中的格子中，值互不相同

返回所有选中格子的值的**最大总和**。

**示例 1：**
```
输入：grid = [[1,2,3],[4,3,2],[1,1,1]]
输出：8
解释：选 (0,2)=3, (1,0)=4, 共和为7；或 (0,0)=1, (1,1)=3, (2,0)=1... 不行（重复1）
最优：选 (0,2)=3（第0行），(1,0)=4（第1行），共7；或 (0,1)=2, (1,0)=4, 共6；
最大应是 3+4=7？还是 3+4+1=8 选第3行的某个不重复的值...
```

**提示：**
- `1 <= m, n <= 10`
- `1 <= grid[i][j] <= 100`

## 解题思路

由于 m, n <= 10，格子值 <= 100，用**状态压缩 DP**：

`dp[mask]` = 选了 mask 中的行（二进制表示），且已选值的集合满足约束时的最大总和。

但值的集合可能很多种，需要换个角度。

**正确做法**：

将所有 (value, row) 按 value 降序排列，用状态压缩 DP：

`dp[mask]` = 已使用 mask 中的行（各行选了一个值且值互不相同），能获得的最大总和。

按值从大到小遍历，对每个值选择是否添加（选某一行中包含此值的格子）。

由于每行最多选 1 个，行状态用 bitmask（m <= 10，2^10 = 1024）。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 对每个值，找出它出现在哪些行（行的掩码）
        from collections import defaultdict
        val_rows = defaultdict(int)  # val -> row bitmask
        for i in range(m):
            for j in range(n):
                val = grid[i][j]
                val_rows[val] |= (1 << i)
        
        # 按值从大到小处理，状态压缩 DP
        # dp[mask] = 已使用 mask 中的行，选了若干互不相同值的最大总和
        dp = [0] * (1 << m)
        
        # 对每个值，枚举其出现的行，决定是否用该行、该值
        for val in sorted(val_rows.keys(), reverse=True):
            row_mask = val_rows[val]
            new_dp = dp[:]
            
            # 枚举 row_mask 的子集（可以选哪行的该值）
            for mask in range((1 << m) - 1, -1, -1):
                if dp[mask] == 0 and mask != 0:
                    continue  # 剪枝
                # 从 row_mask 中选一个未在 mask 中的行
                available = row_mask & ~mask
                row = available
                while row:
                    lsb = row & (-row)  # 最低位
                    new_mask = mask | lsb
                    new_dp[new_mask] = max(new_dp[new_mask], dp[mask] + val)
                    row &= row - 1
            
            dp = new_dp
        
        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(V * 2^m)，V 为不同值的数量（最多 100），2^m 最多 1024
- 空间复杂度：O(2^m)

## 关键点总结

1. 对每个值，找出含该值的所有行
2. 状态压缩：mask 表示已使用的行集合
3. 按值从大到小处理，保证每个值只被选一次

## 易错点

1. 同一行同一值可能出现多次，只需记录行的掩码（不重复）
2. 状态转移时不能选已用行（mask & lsb == 0）
