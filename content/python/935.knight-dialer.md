## 题目描述

国际象棋中的骑士可以按下图所示进行移动。这一次，我们将 "骑士" 放在电话拨号盘的任意数字键（0-9）上，接下来，骑士将会跳 n-1 步。每一步可以是沿着下图中的一个方向移动。

返回我们可以拨出的不同电话号码的数量。答案需要对 10^9 + 7 取模。

## Python 代码实现

```python
class Solution:
    def knightDialer(self, n: int) -> int:
        MOD = 10**9 + 7
        
        # 每个数字可以移动到的位置
        moves = {
            0: [4, 6],
            1: [6, 8],
            2: [7, 9],
            3: [4, 8],
            4: [0, 3, 9],
            5: [],
            6: [0, 1, 7],
            7: [2, 6],
            8: [1, 3],
            9: [2, 4]
        }
        
        # dp[i] 表示在位置 i 结束的电话号码数量
        dp = [1] * 10
        
        for _ in range(n - 1):
            new_dp = [0] * 10
            for i in range(10):
                for j in moves[i]:
                    new_dp[j] = (new_dp[j] + dp[i]) % MOD
            dp = new_dp
        
        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
