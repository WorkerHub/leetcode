## 题目描述

给你两个数组 `nums1` 和 `nums2`。

存在整数 `x`，使得 `nums1` 的每个元素加上 `x` 后，`nums1` 和 `nums2` 相同（不计顺序）。

返回整数 `x`。

**示例 1：**
```
输入：nums1 = [2,6,4], nums2 = [9,7,5]
输出：3
解释：nums1 中每个元素加 3，得到 [5,7,9]，与 nums2 相同。
```

**示例 2：**
```
输入：nums1 = [10], nums2 = [5]
输出：-5
```

**提示：**
- `1 <= nums1.length == nums2.length <= 100`
- `0 <= nums1[i], nums2[i] <= 1000`

## 解题思路

x 等于 min(nums2) - min(nums1)。因为加上 x 后两数组相同，最小值的差就是 x。

## Python 代码实现

### 方法一：最小值差（推荐）

```python
from typing import List

class Solution:
    def addedInteger(self, nums1: List[int], nums2: List[int]) -> int:
        return min(nums2) - min(nums1)
```

### 方法二：排序后比较

```python
from typing import List

class Solution:
    def addedInteger(self, nums1: List[int], nums2: List[int]) -> int:
        # 排序后第一个元素的差就是 x
        return sorted(nums2)[0] - sorted(nums1)[0]
```

## 复杂度分析

- 时间复杂度：O(n)，求最小值
- 空间复杂度：O(1)

## 关键点总结

1. 整体加 x 不改变相对大小，故最小值之差即为 x
2. 一行代码即可解决

## 易错点

1. x 可能为负数
2. 不需要排序，只需最小值
