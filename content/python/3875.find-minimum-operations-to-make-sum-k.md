## 题目描述

给你一个正整数 `n` 和一个正整数 `k`，每次操作可以将 `n` 乘以 2 或除以 2（向下取整）。

返回使 `n` 等于 `k` 所需的最少操作次数，如果不可能则返回 -1。

注意：此题实际描述可能不同，以下基于题目名称"找到使总和等于k的最少操作次数"解释。

给你整数数组 `nums` 和目标值 `k`，每次操作可以从数组中选任意元素加 1 或减 1，使数组总和等于 k，返回最少操作次数。

**示例 1：**

```
输入：nums = [1, 2, 3], k = 5
输出：1
解释：总和 1+2+3=6，减少 1 次（减 1）变为 5。
```

**示例 2：**

```
输入：nums = [1, 1, 1], k = 6
输出：3
解释：每个元素加 1，3 次操作。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

最少操作次数 = `|sum(nums) - k|`，因为每次操作改变总和 1，需要 `|diff|` 次。

## Python 代码实现

### 方法一：直接计算（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        return abs(sum(nums) - k)
```

### 方法二：分情况处理

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        total = sum(nums)
        if total > k:
            return total - k  # 需要减少
        elif total < k:
            return k - total  # 需要增加
        else:
            return 0
```

## 复杂度分析

- 时间复杂度：O(n)，求和
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作改变总和 1（加 1 或减 1），最少操作次数 = 差的绝对值。
2. `abs(sum - k)` 是最简洁的表达。
3. 可以对任意元素操作，不限制特定元素。

## 易错点

1. 确认操作是"对某元素加/减 1"，不是"对所有元素加/减 1"。
2. 如果操作有其他限制（如只能操作特定元素），答案可能不同。
