## 题目描述

给定一个整数数组 `nums`，定义排序规则：首先按各位数字之和升序排列，各位数字之和相同时按数值本身升序排列。求将 `nums` 按此规则排序所需的最少交换次数（只允许交换相邻或任意两个元素）。

**示例 1：**

```
输入：nums = [37, 100]
输出：1
解释：37的数字和=10，100的数字和=1，按数字和升序：[100,37]，需要1次交换。
```

**示例 2：**

```
输入：nums = [22, 14, 33]
输出：0
解释：22的和=4，14的和=5，33的和=6，已经有序，0次交换。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

1. 按目标排序规则对 `nums` 排序，得到目标数组
2. 求将原数组转换为目标数组所需的最少交换次数
3. 最少交换次数等于原数组的排列中"逆序对"的数量（对应于循环置换的分解）

实际上，最少交换次数 = n - (循环置换的个数)，或者用计算逆序对的方法。

用哈希表记录目标数组中每个元素的位置，再计算原数组到目标数组的置换中循环的个数。

## Python 代码实现

### 方法一：置换循环法（推荐）

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)

        def digit_sum(x):
            return sum(int(d) for d in str(x))

        # 按目标规则排序
        sorted_nums = sorted(nums, key=lambda x: (digit_sum(x), x))

        # 建立原数组元素到其在 sorted 中位置的映射
        # 注意：可能有重复元素
        pos_map = {}  # value -> [list of positions in sorted_nums]
        from collections import defaultdict
        positions = defaultdict(list)
        for i, x in enumerate(sorted_nums):
            positions[x].append(i)

        # 建立原数组每个位置到目标位置的映射
        target = [0] * n
        used_positions = defaultdict(int)
        for i, x in enumerate(nums):
            idx = used_positions[x]
            target[i] = positions[x][idx]
            used_positions[x] += 1

        # 计算置换中循环的个数
        visited = [False] * n
        cycles = 0
        for i in range(n):
            if not visited[i]:
                cycles += 1
                j = i
                while not visited[j]:
                    visited[j] = True
                    j = target[j]

        return n - cycles
```

### 方法二：记录目标位置后计算逆序

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)

        def digit_sum(x):
            s = 0
            while x > 0:
                s += x % 10
                x //= 10
            return s

        indexed = sorted(range(n), key=lambda i: (digit_sum(nums[i]), nums[i]))

        # indexed[i] 是原数组中第 i 个应该放到的目标位置的元素的原始索引
        # 转化为：把数组 indexed 变为 [0,1,...,n-1] 的最少交换次数
        visited = [False] * n
        swaps = 0
        for i in range(n):
            if visited[i] or indexed[i] == i:
                continue
            cycle = 0
            j = i
            while not visited[j]:
                visited[j] = True
                j = indexed[j]
                cycle += 1
            swaps += cycle - 1

        return swaps
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 自定义排序键：(数字之和, 数值本身)
2. 最少交换次数 = n - 置换中循环数 = sum(cycle_length - 1 for each cycle)
3. 置换分析：原位置到目标位置的映射

## 易错点

1. 有重复元素时，需要注意一一对应关系（同值元素按原顺序匹配）
2. 循环中，已访问的节点不重复计算
3. 目标是将原数组变为排序后的数组，映射方向要正确
