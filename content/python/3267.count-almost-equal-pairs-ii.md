## 题目描述

与 3265 相同，但允许**最多两次**数字交换（每次交换一对数字）。

**提示：**
- `2 <= nums.length <= 10^3`
- `0 <= nums[i] <= 10^7`

## 解题思路

生成每个数经过最多两次交换后的所有可能变体，然后统计对数。

两次交换：先枚举第一次交换，再枚举第二次交换，收集所有变体。

由于数字最多 8 位，两次交换的枚举量为 O(D^4)（D 为位数），可以接受。

## Python 代码实现

### 方法一：枚举两次交换变体（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, nums: List[int]) -> int:
        def get_variants(x):
            s0 = list(str(x))
            n = len(s0)
            variants = set()
            variants.add(x)
            
            # 一次交换
            for i in range(n):
                for j in range(i + 1, n):
                    s0[i], s0[j] = s0[j], s0[i]
                    if s0[0] != '0':
                        v1 = int(''.join(s0))
                        variants.add(v1)
                        # 二次交换
                        s1 = s0[:]
                        for p in range(n):
                            for q in range(p + 1, n):
                                s1[p], s1[q] = s1[q], s1[p]
                                if s1[0] != '0':
                                    variants.add(int(''.join(s1)))
                                s1[p], s1[q] = s1[q], s1[p]
                    s0[i], s0[j] = s0[j], s0[i]
            
            return variants
        
        cnt = defaultdict(int)
        ans = 0
        
        for x in nums:
            variants = get_variants(x)
            for v in variants:
                ans += cnt[v]
            cnt[x] += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * D^4)，D 为数字位数（最多 8）
- 空间复杂度：O(D^4) 每个数字的变体数

## 关键点总结

1. 最多两次交换，枚举第一次和第二次的所有可能
2. 用集合去重，避免重复计数
3. 先统计后查询，只统计 i < j 的对

## 易错点

1. 两次交换可以交换相同的一对（等于不交换），需要包含在变体中
2. 前导零检查需要在每次生成变体时进行
