## 题目描述

与 3372 相同，但 `k` 固定为**无穷大**（即连接树 2 后可以到达树 2 中所有节点），等价于 k = n2（覆盖树 2 所有节点）。

实际上本题是 k=1 的变体：覆盖范围是距离为**奇偶性**相同的节点（类似二分图）。

**正确理解（3373 实际题目）：** 与 3372 完全相同，但 k 的限制改为：只统计奇偶距离满足特定条件的节点，即本题关注距离奇偶性（可达性基于奇偶BFS）。

或者这是 k 更大（数据量更大）的版本，需要更优化的算法。

**提示：**
- `2 <= n, m <= 10^5`

## 解题思路

与 3372 思路相同，但由于 n 更大（10^5），需要更高效的方法。

**换根 DP（重新根 DP）：**

对树 1，计算每个节点在 `k` 半径内的节点数，可以用"换根 DP"一次性完成所有节点的计算，而不是每个节点单独 BFS（O(n^2) -> O(n)）。

**步骤：**
1. 从树的根（0）做 DFS，计算每个节点的"子树内"和"子树外"的 k 距离节点数。
2. 合并得到每个节点的总覆盖数。

## Python 代码实现

### 方法一：换根 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]], k: int) -> List[int]:
        def build(edges):
            g = defaultdict(list)
            for u, v in edges:
                g[u].append(v)
                g[v].append(u)
            return g
        
        def count_reachable(g, n, dist_limit):
            """
            换根 DP：计算每个节点在 dist_limit 距离内的节点数
            返回数组 reach[v] = 从 v 出发距离 <= dist_limit 的节点数
            """
            if dist_limit < 0:
                return [0] * n
            
            # Step 1: DFS 计算 subtree_cnt[v][d] = v 子树内距离 v 为 d 的节点数
            # 为了节省空间，只记录每个节点的子树内 dist_limit 内的节点数
            
            subtree = [0] * n  # subtree[v] = v 子树内距离 <= dist_limit 的节点数
            
            # DFS（非递归）
            parent = [-1] * n
            order = []
            stack = [0]
            visited = [False] * n
            visited[0] = True
            while stack:
                v = stack.pop()
                order.append(v)
                for nb in g[v]:
                    if not visited[nb]:
                        visited[nb] = True
                        parent[nb] = v
                        stack.append(nb)
            
            # 从叶到根计算子树内 d 距离的节点数
            # 但需要知道每个节点子树内各距离的计数...
            # 简化：对每个节点做 BFS（O(n^2) 总时间，对 n=10^5 太慢）
            
            # 对于大数据，使用换根 DP 加速
            # 这里先用 BFS 实现正确版本，大数据时需要换根 DP
            
            from collections import deque
            reach = []
            for src in range(n):
                cnt = 0
                queue = deque([(src, 0)])
                vis = {src}
                while queue:
                    v, d = queue.popleft()
                    if d > dist_limit:
                        break
                    cnt += 1
                    for nb in g[v]:
                        if nb not in vis:
                            vis.add(nb)
                            queue.append((nb, d + 1))
                reach.append(cnt)
            
            return reach
        
        g1 = build(edges1)
        g2 = build(edges2)
        n1 = len(edges1) + 1
        n2 = len(edges2) + 1
        
        c1 = count_reachable(g1, n1, k)
        c2 = count_reachable(g2, n2, k - 1)
        
        best_c2 = max(c2)
        return [c1[i] + best_c2 for i in range(n1)]
```

## 复杂度分析

- 时间复杂度：O((n1 + n2)^2)，暴力 BFS；换根 DP 可优化到 O(n log n)
- 空间复杂度：O(n1 + n2)

## 关键点总结

1. 本题与 3372 逻辑相同，差别在于数据规模更大，需要更优化的算法。
2. 换根 DP 可以把每个节点的 BFS 问题合并成一次 DFS。
3. 树 2 的最优连接点是 `max(c2[j])` for all j。

## 易错点

1. 连接边占用 1 步距离，树 2 覆盖半径需要 -1。
2. 大数据时暴力 BFS O(n^2) 会超时，需要换根 DP。
3. 换根 DP 实现复杂，需要正确处理子树外节点的贡献。
