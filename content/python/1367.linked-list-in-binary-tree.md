## 题目描述

给你一棵以 `root` 为根的二叉树和一个 `head` 为第一个节点的链表。

如果在二叉树中，存在一条一直向下的路径，且每个点的数值恰好一一对应以 `head` 为首的链表中每个节点的值，那么请你返回 `True`，否则返回 `False`。

一直向下的路径的意思是：从树中某个节点开始，一直连续向下（可以往左孩子或右孩子走）到达某个节点的路径。

**示例 1：**
```
输入：head = [4,2,8], root = [1,4,4,null,2,2,null,1,null,6,8,null,null,null,null,1,3]
输出：true
解释：树中蓝色的节点构成了与链表对应的子路径。
```

**示例 2：**
```
输入：head = [1,4,2,6], root = [1,4,4,null,2,2,null,1,null,6,8,null,null,null,null,1,3]
输出：true
```

**示例 3：**
```
输入：head = [1,4,2,6,8], root = [1,4,4,null,2,2,null,1,null,6,8,null,null,null,null,1,3]
输出：false
```

**提示：**
- 二叉树和链表中的每个节点的值在 `[1, 100]` 范围内。
- 链表将会含有 `1` 到 `100` 个节点。
- 二叉树将会含有 `1` 到 `2500` 个节点。

## 解题思路

本题需要判断链表是否对应二叉树中的某条向下路径。

**双重 DFS 思路：**

1. **外层 DFS（`isSubPath`）**：遍历二叉树的每个节点，尝试以该节点为起点，匹配链表。
2. **内层 DFS（`match`）**：从二叉树的某个节点和链表的某个节点开始，同步向下匹配。

`match(head, root)` 的逻辑：
- 如果 `head` 为 None，说明链表已全部匹配，返回 True。
- 如果 `root` 为 None 或 `root.val != head.val`，匹配失败，返回 False。
- 否则，递归检查左子树或右子树是否能继续匹配。

**KMP 优化思路（进阶）：** 将链表当作"模式串"，二叉树路径当作"文本串"，用 KMP 的失配函数优化回退，避免重复匹配。

## Python 代码实现

### 方法一：双重 DFS（推荐）

```python
from typing import Optional

# 节点定义
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSubPath(self, head: Optional[ListNode], root: Optional[TreeNode]) -> bool:
        
        def match(list_node: Optional[ListNode], tree_node: Optional[TreeNode]) -> bool:
            """
            从 tree_node 开始，尝试匹配以 list_node 为首的链表
            """
            if list_node is None:
                return True  # 链表已全部匹配成功
            if tree_node is None:
                return False  # 树节点不足，匹配失败
            if list_node.val != tree_node.val:
                return False  # 当前节点值不匹配
            # 继续向左或向右匹配下一个链表节点
            return match(list_node.next, tree_node.left) or \
                   match(list_node.next, tree_node.right)
        
        if root is None:
            return False
        
        # 外层：尝试以每个树节点为起点匹配链表
        # 以当前节点为起点匹配，或在左子树找，或在右子树找
        return match(head, root) or \
               self.isSubPath(head, root.left) or \
               self.isSubPath(head, root.right)
```

### 方法二：BFS 遍历树节点 + DFS 匹配（迭代外层）

```python
from typing import Optional
from collections import deque

class Solution:
    def isSubPath(self, head: Optional[ListNode], root: Optional[TreeNode]) -> bool:
        
        def match(list_node, tree_node) -> bool:
            """从 tree_node 开始匹配链表（递归）"""
            if not list_node:
                return True
            if not tree_node or tree_node.val != list_node.val:
                return False
            return match(list_node.next, tree_node.left) or \
                   match(list_node.next, tree_node.right)
        
        # BFS 遍历所有树节点，对每个节点尝试匹配
        queue = deque([root])
        while queue:
            node = queue.popleft()
            if node is None:
                continue
            if match(head, node):
                return True
            queue.append(node.left)
            queue.append(node.right)
        
        return False
```

### 方法三：KMP 优化（进阶）

```python
from typing import Optional

class Solution:
    def isSubPath(self, head: Optional[ListNode], root: Optional[TreeNode]) -> bool:
        """
        KMP 优化：构建链表的失配函数，在 DFS 过程中利用失配函数回退
        避免匹配失败后从头开始，优化最坏情况时间复杂度
        """
        # 将链表转为数组
        pattern = []
        node = head
        while node:
            pattern.append(node.val)
            node = node.next
        m = len(pattern)
        
        # 构建 KMP 失配函数 fail[i]
        # fail[i] 表示 pattern[0:i+1] 的最长真前后缀长度
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and pattern[i] != pattern[j]:
                j = fail[j - 1]
            if pattern[i] == pattern[j]:
                j += 1
            fail[i] = j
        
        def dfs(tree_node, matched: int) -> bool:
            """
            tree_node：当前树节点
            matched：已匹配的链表前缀长度
            """
            if tree_node is None:
                return False
            
            # KMP 匹配：更新已匹配长度
            while matched > 0 and tree_node.val != pattern[matched]:
                matched = fail[matched - 1]
            if tree_node.val == pattern[matched]:
                matched += 1
            
            if matched == m:
                return True  # 完全匹配
            
            return dfs(tree_node.left, matched) or dfs(tree_node.right, matched)
        
        return dfs(root, 0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 双重 DFS | O(N * M) | O(N + M)（递归栈） |
| BFS + DFS | O(N * M) | O(N + M) |
| KMP 优化 | O(N + M) | O(N + M) |

- N = 树节点数（最多 2500），M = 链表长度（最多 100）。
- 双重 DFS 最坏情况下每个树节点都要匹配整个链表，O(N*M)，对本题数据范围完全可行。

## 关键点总结

1. **双重 DFS 框架**：外层遍历每个树节点作为候选起点，内层从起点沿树向下匹配链表。
2. **match 函数的终止条件**：链表为空则匹配成功（`head is None`），树为空或值不匹配则失败。
3. **向左或向右**：内层 DFS 只需要链表节点的下一个和树节点的左/右子节点同步匹配，用 `or` 连接。
4. **KMP 优化**：将失配时的回退逻辑复用，避免从头重匹配，时间复杂度降为 O(N+M)。

## 易错点

- 内层 `match` 函数中，`head is None` 时返回 `True`（链表匹配完成），而不是继续检查 `root`。
- 外层遍历必须对每个树节点尝试（不仅仅是根节点），因为路径可以从任意节点开始。
- 路径只能"向下"（左子或右子），不能横跨左右子树，这由 `match` 函数的递归结构保证。
