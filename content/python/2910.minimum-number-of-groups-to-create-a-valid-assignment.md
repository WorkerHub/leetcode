## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，你需要将下标 `[0, n-1]` 分成若干组，满足：
- 每个下标恰好属于一个组
- 对于任意两个组，其大小之差不超过 1

设 `freq[v]` 为值 `v` 在 `nums` 中出现的次数，记 `min_freq` 为最小频率。

你需要找到满足以下条件的最少分组数：将同一个值的所有下标分到同一组（或分成大小差不超过 1 的若干组）。

更具体地：给定 `nums`，将数组下标分配给若干组，使得：
1. 同一组内不能有值相同的两个下标（即同一组内所有值都不同）
2. 最小化组数

**示例 1：**
```
输入：nums = [3,2,3,2,3]
输出：3
```

**示例 2：**
```
输入：nums = [10,10,10,3,1,1]
输出：4
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

统计每个值的出现频率。设各频率为 `cnt_1, cnt_2, ...`。

要将所有元素分成若干组，每组大小为 `k` 或 `k+1`（相差不超过 1），且同组内同值最多出现一次（实际上：每个值分配到 `k` 或 `k+1` 个组中）。

对于给定的每组大小 `k`：
- 频率为 `f` 的值，需要分配到 `ceil(f / k)` 个组，且每组放 `k` 或 `k+1` 个该值（实际每组只放一个，所以每个值需要恰好 `ceil(f/k)` 组……）

**正确分析**：每个值最多在每个组内出现一次，设分组数为 `m`，每组大小为 `k` 或 `k+1`，则每个频率 `f` 满足 `f <= m`（每组最多放一个）。最小 `m` 为所有频率的最大值。

实际上这道题要求：枚举每组大小 `k`（从最小频率开始降到 1），检查所有频率是否都能被 `k` 或 `k+1` 分割，取最小组数。

## Python 代码实现

### 方法一：贪心枚举每组大小（推荐）

```python
from typing import List
from collections import Counter
import math

class Solution:
    def minGroupsForValidAssignment(self, nums: List[int]) -> int:
        freq = Counter(nums)
        counts = list(freq.values())
        min_freq = min(counts)

        # 枚举每组大小 k，从 min_freq 到 1
        for k in range(min_freq, 0, -1):
            # 检查是否所有 cnt 都能用 k 或 k+1 分组
            total_groups = 0
            valid = True
            for cnt in counts:
                # cnt 个元素，每组 k 个，余数 r = cnt % k
                # 若 r == 0，需要 cnt // k 组
                # 若 r != 0，需要从 cnt//k 组中抽出 r 组各增加 1 个
                # 等价于检查 r <= cnt // k
                q, r = divmod(cnt, k)
                if r == 0:
                    total_groups += q
                elif r <= q:
                    # r 组变成 k+1 大小，其余 q-r 组保持 k 大小
                    total_groups += q + 1
                else:
                    valid = False
                    break
            if valid:
                return total_groups

        return len(nums)  # 极端情况：每组 1 个
```

### 方法二：直接计算（等价简化）

```python
from typing import List
from collections import Counter
import math

class Solution:
    def minGroupsForValidAssignment(self, nums: List[int]) -> int:
        freq = Counter(nums)
        counts = list(freq.values())
        min_cnt = min(counts)

        def calc_groups(k: int) -> int:
            # 计算每组大小为 k（允许 k+1）时的最少组数
            total = 0
            for cnt in counts:
                q, r = divmod(cnt, k)
                if r == 0:
                    total += q
                elif r <= q:
                    total += q + 1
                else:
                    return float('inf')  # 不可行
            return total

        return min(calc_groups(k) for k in range(1, min_cnt + 1))
```

## 复杂度分析

- 时间复杂度：O(n + D * K)，D 为不同值数量，K 为最小频率
- 空间复杂度：O(D)，存储频率表

## 关键点总结

1. 关键观察：每组大小必须为某个固定值 k 或 k+1
2. 从最小频率开始枚举 k，第一个可行的 k 给出最少组数（贪心：k 大则组少）
3. 对于频率 cnt 和组大小 k：若 cnt % k <= cnt // k，则可行

## 易错点

1. k 从大到小枚举（优先选大 k），第一个可行解即为答案
2. `r <= q` 的条件：r 个组需要从 k 扩到 k+1，需要有足够多的 k 大小的组来"贡献"多余 1 个位置
