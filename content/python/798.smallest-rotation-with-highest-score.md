## 题目描述

给你一个数组 `nums`，我们可以将它按一个非负整数 `k` 进行轮调，这样可以使数组变为 `[nums[k], nums[k + 1], ... nums[nums.length - 1], nums[0], nums[1], ..., nums[k-1]]` 的形式。此后，任何值小于或等于其索引的项都可以记作一分。

例如，数组为 `nums = [2,4,1,3,0]`，我们按 `k = 2` 进行轮调后，它将变成 `[1,3,0,2,4]`。这将记为 3 分，因为 1 <= 0, 3 <= 2, 0 <= 3。

返回我们所能得到的最高分数对应的轮调索引 `k`。如果有多个答案，返回满足条件的最小的 `k`。

**示例 1：**
```
输入：nums = [2,3,1,4,0]
输出：3
解释：
k = 0, [2,3,1,4,0]    分数 2（索引 2 和 4 满足）
k = 1, [3,1,4,0,2]    分数 3
k = 2, [1,4,0,2,3]    分数 3
k = 3, [4,0,2,3,1]    分数 4
k = 4, [0,2,3,1,4]    分数 3

所以最高分数是 4，对应的 k = 3
```

**示例 2：**
```
输入：nums = [1,3,0,2,4]
输出：0
解释：nums 无论怎么变化总是有 3 分
由于最小的 k 是 0，所以返回 0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] < nums.length`

## 解题思路

这道题的暴力解法是枚举所有 k 值（0 到 n-1），对每个 k 计算得分，时间复杂度 O(n²)，会超时。

**优化思路：差分数组 + 区间更新**

关键观察：对于数组中的每个元素 `nums[i]`，我们需要找出在哪些旋转 k 下，这个元素能贡献 1 分。

**何时 `nums[i]` 能贡献分数？**

设旋转 k 次后，`nums[i]` 移动到位置 `j`，则：
- 原位置 `i`，旋转 k 次后的新位置 `j = (i - k + n) % n`
- 要得分：`nums[i] <= j`，即 `nums[i] <= (i - k + n) % n`

我们需要找出所有满足条件的 k 值范围。

**数学推导：**

对于位置 i 的元素 `nums[i]`，在旋转 k 次后：
- 新位置 `j = (i - k + n) % n`
- 得分条件：`nums[i] <= j`

分两种情况讨论：

**情况 1：k 在正常范围内**
- 当 `k <= i` 时，新位置 `j = i - k`
- 要满足 `nums[i] <= i - k`，即 `k <= i - nums[i]`
- 所以 k 的范围是 `[0, i - nums[i]]`（当 `i >= nums[i]` 时）

**情况 2：k 使元素绕回数组开头**
- 当 `k > i` 时，新位置 `j = n + i - k`
- 要满足 `nums[i] <= n + i - k`，即 `k <= n + i - nums[i]`
- 同时 `k > i`
- 所以 k 的范围是 `[i + 1, n + i - nums[i]]`（当这个范围有效时）

**综合分析：**

对于每个元素 `nums[i]`，能贡献分数的 k 值是一个连续区间（或两个区间）。我们使用**差分数组**来高效处理区间加法。

**差分数组技巧：**
- 在区间 `[l, r]` 上加 1，等价于 `diff[l] += 1, diff[r+1] -= 1`
- 最后对差分数组求前缀和，得到每个位置的实际值

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def bestRotation(self, nums: List[int]) -> int:
        """
        使用差分数组找出最高分数对应的旋转次数
        
        思路：对每个元素分析其能贡献分数的 k 值区间
        
        参数：
            nums: 输入数组
            
        返回：
            最高分数对应的最小 k 值
        """
        n = len(nums)
        diff = [0] * (n + 1)  # 差分数组
        
        for i in range(n):
            # 对于 nums[i]，分析在哪些 k 下能得分
            
            # 元素在位置 i，旋转 k 次后到位置 (i - k + n) % n
            # 要得分：nums[i] <= (i - k + n) % n
            
            # 计算不能得分的区间，然后取反
            # 不能得分的条件：nums[i] > (i - k + n) % n
            
            # 换个思路：计算能得分的区间
            # 当 nums[i] > i 时，无论如何旋转都不能在 k=0 时得分
            
            # 失分区间：从 k = (i - nums[i] + 1 + n) % n 到 k = i
            left = (i - nums[i] + 1 + n) % n
            right = i
            
            # 使用差分数组标记失分区间
            if left <= right:
                diff[left] -= 1
                diff[right + 1] += 1
            else:
                # 跨越边界的情况
                diff[0] -= 1
                diff[right + 1] += 1
                diff[left] -= 1
                diff[n] += 1
        
        # 计算每个 k 的得分
        max_score = 0
        current_score = n  # 初始假设所有元素都得分
        result = 0
        
        for k in range(n):
            current_score += diff[k]
            if current_score > max_score:
                max_score = current_score
                result = k
        
        return result
```

### 方法二：直接计算贡献区间

```python
from typing import List

class Solution:
    def bestRotation(self, nums: List[int]) -> int:
        """
        直接计算每个元素的贡献区间
        
        思路：对每个元素，计算它在哪些 k 下能得分
        """
        n = len(nums)
        change = [0] * n  # change[k] 表示从 k-1 到 k 分数的变化
        
        for i in range(n):
            # nums[i] 在位置 i
            # 旋转 k 次后，位置变为 (i - k + n) % n
            # 得分条件：nums[i] <= (i - k + n) % n
            
            # 计算在哪个 k 开始失分
            # 失分开始于：nums[i] > (i - k + n) % n
            # 即 k > i - nums[i]（在模 n 意义下）
            
            change[(i - nums[i] + 1 + n) % n] -= 1
            change[(i + 1) % n] += 1
        
        # 计算每个 k 的得分
        max_score = 0
        score = sum(change)
        result = 0
        
        for k in range(n):
            score += change[k]
            if score > max_score:
                max_score = score
                result = k
        
        return result
```

### 方法三：暴力解法（用于对比）

```python
from typing import List

class Solution:
    def bestRotation(self, nums: List[int]) -> int:
        """
        暴力解法：枚举所有 k，计算得分
        
        思路：对每个 k 实际旋转数组并计算分数
        注意：此方法会超时，仅用于理解题意
        """
        n = len(nums)
        max_score = -1
        result = 0
        
        for k in range(n):
            # 旋转 k 次
            rotated = nums[k:] + nums[:k]
            
            # 计算得分
            score = sum(1 for i in range(n) if rotated[i] <= i)
            
            if score > max_score:
                max_score = score
                result = k
        
        return result
```

## 复杂度分析

### 方法一、二：差分数组
- **时间复杂度：** O(n)，遍历数组两次
- **空间复杂度：** O(n)，差分数组

### 方法三：暴力解法
- **时间复杂度：** O(n²)，n 个 k 值，每个 k 需要 O(n) 计算
- **空间复杂度：** O(n)，旋转后的数组

## 图解示例

以 `nums = [2,3,1,4,0]` 为例：

```
原数组：   [2,3,1,4,0]
索引：      0 1 2 3 4

k=0: [2,3,1,4,0]  得分：索引 2(1<=2), 4(0<=4) → 2 分
k=1: [3,1,4,0,2]  得分：索引 1(1<=1), 2(4>2)✗, 3(0<=3), 4(2<=4) → 3 分
k=2: [1,4,0,2,3]  得分：索引 0(1>0)✗, 1(4>1)✗, 2(0<=2), 3(2<=3), 4(3<=4) → 3 分
k=3: [4,0,2,3,1]  得分：索引 0(4>0)✗, 1(0<=1), 2(2<=2), 3(3<=3), 4(1<=4) → 4 分

```

最高分 4 分出现在 k=3。

**分析每个元素的贡献：**
- `nums[0]=2`：在 k=0 时不得分，在 k=1,2,3,4 时是否得分需要计算
- `nums[1]=3`：分析在哪些 k 下满足 `3 <= 新位置`
- 以此类推...

## 关键点总结

1. **差分数组**：区间更新的经典技巧，将 O(n) 的区间加法优化为 O(1)
2. **数学分析**：需要推导出每个元素在哪些 k 下能贡献分数
3. **模运算**：处理循环数组，注意 `(i - k + n) % n` 的使用
4. **边界情况**：差分区间可能跨越数组边界，需要分情况处理
5. **优化思维**：从 O(n²) 暴力优化到 O(n) 是本题的核心

## 易错点

1. **差分数组越界**：差分数组大小应为 n+1，防止 `diff[n]` 越界
2. **模运算**：计算新位置时要加 n 再取模，防止负数
3. **区间跨界**：当失分区间跨越数组边界时，需要拆分成两个区间
4. **初始分数**：要正确设置初始分数（通常假设所有元素都得分）
5. **最小 k**：题目要求返回最小的 k，所以用 `>` 而不是 `>=`
