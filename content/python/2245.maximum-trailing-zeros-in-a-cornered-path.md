## 题目描述

给你一个 `m x n` 的二维整数数组 `grid`。

**拐角路径**：选择一个单元格，向右或向下走一段，然后再向下或向右走一段（只能转弯一次，也可以不转弯），到达网格边界。路径必须从任意位置出发，沿某两个方向行走。

具体地，拐角路径是如下三种情况之一：
1. 只向右走一段。
2. 只向下走一段。
3. 先向右，再向下（或先向下再向右），共经过一个拐角。

返回经过路径上所有元素之积的**尾随零**的最大数量。

**提示：** 尾随零 = 乘积中因子 2 和因子 5 的最小数量。

## 解题思路

路径上的乘积的尾随零 = `min(路径上因子2的总数, 路径上因子5的总数)`。

预处理：对每个单元格 `(i,j)`，计算其值含有的因子 2 的个数 `f2[i][j]` 和因子 5 的个数 `f5[i][j]`。

前缀和：
- `row2[i][j]`：第 i 行前 j 个单元格的因子 2 之和。
- `col2[i][j]`：第 j 列前 i 个单元格的因子 2 之和。
- 同理 `row5`, `col5`。

枚举拐角位置 `(i,j)` 和路径方向，计算路径上的因子 2 和因子 5 总数。

## 代码实现

### 方法一：前缀和枚举拐角（推荐）

```python
from typing import List

class Solution:
    def maxTrailingZeros(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        def count_factor(x, p):
            """计算 x 中因子 p 的个数"""
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            return cnt

        # 预计算每格的因子2和因子5
        f2 = [[count_factor(grid[i][j], 2) for j in range(n)] for i in range(m)]
        f5 = [[count_factor(grid[i][j], 5) for j in range(n)] for i in range(m)]

        # 行前缀和：row_pre[f][i][j] = 第i行前j+1个元素的因子f总和
        row2 = [[0] * (n + 1) for _ in range(m)]
        row5 = [[0] * (n + 1) for _ in range(m)]
        for i in range(m):
            for j in range(n):
                row2[i][j + 1] = row2[i][j] + f2[i][j]
                row5[i][j + 1] = row5[i][j] + f5[i][j]

        # 列前缀和：col_pre[f][i][j] = 第j列前i+1个元素的因子f总和
        col2 = [[0] * n for _ in range(m + 1)]
        col5 = [[0] * n for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                col2[i + 1][j] = col2[i][j] + f2[i][j]
                col5[i + 1][j] = col5[i][j] + f5[i][j]

        ans = 0

        # 枚举拐角位置 (i, j)，4种路径方向组合（左上、右上、左下、右下）
        for i in range(m):
            for j in range(n):
                # 当前格的值
                c2, c5 = f2[i][j], f5[i][j]

                # 4种拐角方向：
                # 1. 从 (i, 0..j) 向右到 j，再从 (i..m-1, j) 向下（上方向右+下方向下）
                # 路径 = 第i行[0..j] + 第j列[i+1..m-1]（不重复计(i,j)）
                for (row_part2, row_part5, col_part2, col_part5) in [
                    # 右到j再下：行[0..j]向右到(i,j)，列(i,j)向下到底
                    (row2[i][j + 1], row5[i][j + 1], col2[m][j] - col2[i + 1][j], col5[m][j] - col5[i + 1][j]),
                    # 右到j再上（向左行进，取右到j加上col上方）
                    (row2[i][n] - row2[i][j], row5[i][n] - row5[i][j], col2[i][j], col5[i][j]),
                    # 下到i再右
                    (col2[i + 1][j], col5[i + 1][j], row2[i][n] - row2[i][j + 1], row5[i][n] - row5[i][j + 1]),
                    # 下到i再左
                    (col2[m][j] - col2[i][j], col5[m][j] - col5[i][j], row2[i][j], row5[i][j]),
                ]:
                    t2 = row_part2 + col_part2 - c2  # 减去重复计的 (i,j)
                    t5 = row_part5 + col_part5 - c5
                    ans = max(ans, min(t2, t5))

        return ans
```

### 方法二：简化版（正确枚举四方向）

```python
from typing import List

class Solution:
    def maxTrailingZeros(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        def cnt(x, p):
            c = 0
            while x % p == 0:
                x //= p
                c += 1
            return c

        two = [[cnt(grid[i][j], 2) for j in range(n)] for i in range(m)]
        five = [[cnt(grid[i][j], 5) for j in range(n)] for i in range(m)]

        # 前缀和
        pre_r2 = [[0]*(n+1) for _ in range(m)]
        pre_r5 = [[0]*(n+1) for _ in range(m)]
        pre_c2 = [[0]*n for _ in range(m+1)]
        pre_c5 = [[0]*n for _ in range(m+1)]

        for i in range(m):
            for j in range(n):
                pre_r2[i][j+1] = pre_r2[i][j] + two[i][j]
                pre_r5[i][j+1] = pre_r5[i][j] + five[i][j]
                pre_c2[i+1][j] = pre_c2[i][j] + two[i][j]
                pre_c5[i+1][j] = pre_c5[i][j] + five[i][j]

        ans = 0
        for i in range(m):
            for j in range(n):
                v2, v5 = two[i][j], five[i][j]
                # 四种组合：(水平左/右) + (垂直上/下)，减去重复的(i,j)
                for h2, h5, d2, d5 in [
                    (pre_r2[i][j+1], pre_r5[i][j+1], pre_c2[m][j]-pre_c2[i+1][j], pre_c5[m][j]-pre_c5[i+1][j]),
                    (pre_r2[i][j+1], pre_r5[i][j+1], pre_c2[i][j], pre_c5[i][j]),
                    (pre_r2[i][n]-pre_r2[i][j], pre_r5[i][n]-pre_r5[i][j], pre_c2[m][j]-pre_c2[i+1][j], pre_c5[m][j]-pre_c5[i+1][j]),
                    (pre_r2[i][n]-pre_r2[i][j], pre_r5[i][n]-pre_r5[i][j], pre_c2[i][j], pre_c5[i][j]),
                ]:
                    ans = max(ans, min(h2+d2-v2, h5+d5-v5))
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n * log(max_val))，预处理因子 + 枚举。
- 空间复杂度：O(m * n)，前缀和数组。

## 关键点总结

1. 尾随零 = `min(因子2总数, 因子5总数)`。
2. 前缀和快速计算路径上的因子总数。
3. 枚举拐角点 (i,j) 的四种方向组合（水平左/右 + 垂直上/下）。
4. 注意拐角点 (i,j) 被行和列各计算一次，需减去一次。

## 易错点

- 拐角点 (i,j) 在行前缀和和列前缀和中都被统计，需减去一次避免重复。
- 因子分解时，`grid[i][j]` 可能很大，分解因子 2 和 5 的时间复杂度为 O(log val)。
