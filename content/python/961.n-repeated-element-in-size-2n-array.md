## 题目描述

给你一个整数数组 `nums`，该数组具有以下属性：
- `nums.length == 2 * n`
- `nums` 包含 `n + 1` 个不同的元素
- `nums` 中恰有一个元素重复 `n` 次

找出并返回重复了 `n` 次的那个元素。

**示例 1：**
```
输入：nums = [1,2,3,3]
输出：3
```

**示例 2：**
```
输入：nums = [2,1,2,5,3,2]
输出：2
```

**示例 3：**
```
输入：nums = [5,1,5,2,5,3,5,4]
输出：5
```

**提示：**
- `2 <= n <= 5000`
- `nums.length == 2 * n`
- `0 <= nums[i] <= 10^4`
- `nums` 由 `n + 1` 个不同的元素组成，且其中一个元素恰好重复 `n` 次

## 解题思路

由于数组长度为 `2n`，包含 `n + 1` 个不同元素，其中一个元素重复 `n` 次，这意味着：
- 重复元素出现 `n` 次
- 其他 `n` 个元素各出现 1 次
- 重复元素占据了数组的一半位置

**核心观察：**
1. 重复元素出现频率最高（n 次）
2. 在任意 3 个连续的元素中，至少有一个是重复元素（当 n >= 2）
3. 可以用哈希表、计数等多种方法解决

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        # 使用集合记录已经出现过的元素
        seen = set()
        
        for num in nums:
            # 如果已经出现过，说明是重复元素
            if num in seen:
                return num
            seen.add(num)
        
        return -1  # 理论上不会执行到这里
```

### 方法二：计数器

```python
from typing import List
from collections import Counter

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        # 统计每个元素的出现次数
        count = Counter(nums)
        
        # 找出出现次数最多的元素
        n = len(nums) // 2
        for num, freq in count.items():
            if freq == n:
                return num
        
        return -1
```

### 方法三：随机采样（巧妙解法）

```python
from typing import List
import random

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        # 由于重复元素占一半，随机选两个元素，有很大概率至少一个是重复元素
        while True:
            # 随机选择两个不同的索引
            i, j = random.sample(range(len(nums)), 2)
            # 如果相等，就是重复元素
            if nums[i] == nums[j]:
                return nums[i]
```

### 方法四：检查相邻和间隔元素（最优解）

```python
from typing import List

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 检查相邻元素
        for i in range(n - 1):
            if nums[i] == nums[i + 1]:
                return nums[i]
        
        # 检查间隔一个位置的元素
        for i in range(n - 2):
            if nums[i] == nums[i + 2]:
                return nums[i]
        
        # 检查间隔两个位置的元素（仅需检查第一个和倒数第二个）
        if nums[0] == nums[n - 2]:
            return nums[0]
        
        return -1
```

### 方法五：数学方法（一行解法）

```python
from typing import List
from collections import Counter

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        # 找出出现次数超过 1 次的元素
        return Counter(nums).most_common(1)[0][0]
```

### 方法六：排序法

```python
from typing import List

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        # 排序后，重复元素必定相邻
        nums.sort()
        
        for i in range(len(nums) - 1):
            if nums[i] == nums[i + 1]:
                return nums[i]
        
        return -1
```

## 复杂度分析

### 方法一：哈希表
- **时间复杂度**：O(n)，最坏情况遍历整个数组
- **空间复杂度**：O(n)，哈希集合空间

### 方法二：计数器
- **时间复杂度**：O(n)，需要遍历数组统计
- **空间复杂度**：O(n)，Counter 空间

### 方法三：随机采样
- **时间复杂度**：O(1) 期望，但最坏情况 O(∞)（理论上）
- **空间复杂度**：O(1)

### 方法四：检查相邻
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

### 方法六：排序
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1) 或 O(n)，取决于排序算法

## 关键点总结

1. **数学性质**：重复元素占据数组一半位置，是解题的关键
2. **鸽巢原理**：在连续 3 个元素中，必有至少一个重复元素
3. **多种解法**：可以用哈希、计数、随机、检查相邻等多种方法
4. **空间优化**：方法四只需 O(1) 空间
5. **随机算法**：方法三展示了概率算法的应用

## 易错点

1. **边界情况**：n = 1 时，数组只有 [x, x]，需要特殊处理
2. **范围检查**：检查相邻元素时注意索引不越界
3. **理解题意**：是找重复 n 次的元素，不是找第一个重复元素
4. **空间限制**：如果要求 O(1) 空间，不能用哈希表
5. **随机方法**：理论上可能无限循环（虽然概率极低）
