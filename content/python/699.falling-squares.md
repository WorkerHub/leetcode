## 题目描述

在二维平面上有若干正方形从空中落下，每个正方形用 `positions[i] = [left, sideLength]` 表示，其中 `left` 是正方形左边缘的 X 坐标，`sideLength` 是正方形的边长。

每个正方形从很高的高度落下，按顺序一个接一个地落下。当正方形落下时：
- 它会向下移动，直到着陆在另一个正方形的顶部或者着陆在 X 轴上
- 一旦着陆，它就会冻结在该位置，不再移动
- 正方形只有当它的底边与另一个正方形的顶边相接触时，才算是着陆在该正方形上
- 仅仅擦过左侧或右侧不算着陆

在每个正方形落下后，你需要返回当前所有正方形堆叠的最大高度。返回一个整数数组 `ans`，其中 `ans[i]` 表示在第 `i` 个正方形落下后的最大高度。

**示例 1：**
```
输入: positions = [[1,2],[2,3],[6,1]]
输出: [2,5,5]
解释:
- 第 1 个正方形落下后，高度为 2
- 第 2 个正方形落在第 1 个正方形上，高度为 2 + 3 = 5
- 第 3 个正方形落在 X 轴上，最大高度仍为 5
```

**示例 2：**
```
输入: positions = [[100,100],[200,100]]
输出: [100,100]
解释:
- 第 1 个正方形落下后，高度为 100
- 第 2 个正方形只擦过第 1 个正方形的右侧，落在 X 轴上，最大高度仍为 100
```

**提示：**
- `1 <= positions.length <= 1000`
- `1 <= left <= 10^8`
- `1 <= sideLength <= 10^6`

## 解题思路

这道题的核心是要维护每个区间的最大高度。每当一个新正方形落下时，我们需要：

1. 找出与新正方形水平重叠的所有已落下正方形的最大高度
2. 新正方形的底部会落在这个最大高度之上
3. 更新该区间的高度
4. 记录全局最大高度

**关键观察：**
- 正方形 A 的区间是 `[left, left + sideLength)`（左闭右开）
- 两个正方形重叠的条件是区间有交集
- 区间 `[a, b)` 和 `[c, d)` 有交集的条件是 `a < d and c < b`

**方法对比：**
- 暴力模拟：每次遍历所有已落下的正方形，时间复杂度 O(n²)
- 线段树：可以优化区间查询和更新，但实现复杂
- 坐标压缩 + 暴力：对于本题数据规模，暴力模拟已足够

## Python 代码实现

### 方法一：暴力模拟（推荐）

```python
from typing import List

class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        # 记录每个正方形的区间和高度
        # intervals[i] = (left, right, height)
        intervals = []
        result = []
        max_height = 0
        
        for left, side_length in positions:
            # 计算当前正方形的右边界
            right = left + side_length
            
            # 找出所有与当前正方形重叠的区间的最大高度
            base_height = 0
            for l, r, h in intervals:
                # 判断区间是否重叠：left < r and l < right
                if left < r and l < right:
                    base_height = max(base_height, h)
            
            # 当前正方形的高度 = 基础高度 + 边长
            current_height = base_height + side_length
            
            # 保存当前正方形的信息
            intervals.append((left, right, current_height))
            
            # 更新全局最大高度
            max_height = max(max_height, current_height)
            result.append(max_height)
        
        return result
```

### 方法二：离散化 + 线段树（进阶）

```python
from typing import List

class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        # 收集所有坐标点进行离散化
        coords = set()
        for left, side_length in positions:
            coords.add(left)
            coords.add(left + side_length)
        
        # 坐标排序并建立映射
        sorted_coords = sorted(coords)
        coord_map = {c: i for i, c in enumerate(sorted_coords)}
        
        # heights[i] 表示离散化后区间 i 的高度
        n = len(sorted_coords)
        heights = [0] * n
        
        result = []
        max_height = 0
        
        for left, side_length in positions:
            right = left + side_length
            
            # 映射到离散化坐标
            l_idx = coord_map[left]
            r_idx = coord_map[right]
            
            # 查询区间 [l_idx, r_idx) 的最大高度
            base_height = 0
            for i in range(l_idx, r_idx):
                base_height = max(base_height, heights[i])
            
            # 当前高度
            current_height = base_height + side_length
            
            # 更新区间高度
            for i in range(l_idx, r_idx):
                heights[i] = current_height
            
            # 更新全局最大高度
            max_height = max(max_height, current_height)
            result.append(max_height)
        
        return result
```

### 方法三：简化的字典记录法

```python
from typing import List

class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        # 使用字典记录每个位置的高度
        height_map = {}
        result = []
        max_height = 0
        
        for left, side_length in positions:
            right = left + side_length
            
            # 查找当前正方形落点的最大高度
            base_height = 0
            for pos, h in height_map.items():
                # 检查是否有重叠
                if pos < right and left < pos + 1:
                    base_height = max(base_height, h)
            
            # 更新当前位置的高度
            current_height = base_height + side_length
            height_map[left] = current_height
            
            max_height = max(max_height, current_height)
            result.append(max_height)
        
        return result
```

## 复杂度分析

**方法一：暴力模拟**
- 时间复杂度：O(n²)，其中 n 是正方形的数量。每个正方形需要检查之前所有的正方形。
- 空间复杂度：O(n)，需要存储所有正方形的信息。

**方法二：离散化**
- 时间复杂度：O(n² + m log m)，其中 m 是不同坐标的数量。离散化需要 O(m log m)，每个正方形的查询和更新需要 O(m)。
- 空间复杂度：O(m)，存储离散化后的高度数组。

**方法三：字典记录**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 关键点总结

1. **区间重叠判断**：两个区间 `[a, b)` 和 `[c, d)` 重叠的条件是 `a < d and c < b`
2. **高度计算**：新正方形的高度 = 与之重叠的所有正方形的最大高度 + 自身边长
3. **全局最大值维护**：每次落下后都要更新并记录全局最大高度
4. **坐标系统**：使用左闭右开区间 `[left, left + sideLength)` 更方便判断
5. **边界情况**：正方形仅仅擦过左右边界不算重叠

## 易错点

1. **区间重叠判断错误**
   - 错误：使用 `left <= r and l <= right`（包含边界接触）
   - 正确：使用 `left < r and l < right`（边界接触不算重叠）

2. **高度更新顺序**
   - 必须先找出基础高度，再计算当前高度，最后更新全局最大值

3. **初始高度设置**
   - 基础高度初始化为 0（表示落在 X 轴上）

4. **结果数组长度**
   - 结果数组长度应该等于 positions 的长度，每个位置记录当时的最大高度
