## 题目描述

Alice 有一个正整数数组 `original`（长度为 n）。她将 `original` 中每个元素分别减去 `k` 得到 `lower`，加上 `k` 得到 `higher`。然后将 `lower` 和 `higher` 打乱后合并成一个长度为 `2n` 的数组 `changed`。

给你 `changed`，请恢复 `original` 数组。若存在多个合法 `original`，返回其中**任意一个**；若不存在，返回**空数组**。

**示例：**
```
输入：changed = [3,1,3,4,1,9,6,19,8,6]
输出：[3,4,6,8]  (之一)
```

**提示：**
- `2n == changed.length`
- `1 <= n <= 10^5`
- `1 <= changed[i] <= 10^5`

## 解题思路

**排序 + 枚举 k**

`k = (higher[i] - lower[i]) / 2`。

由于 `original[i] - k = lower[i]` 且 `original[i] + k = higher[i]`，所以 `k = (higher - lower) / 2`。

**枚举 k：**
- 排序 `changed`。
- 最小值 `changed[0]` 必定属于 lower 部分（因为它是所有值中最小的）。
- 枚举 `changed[0]` 的配对元素（可能是任意一个比它大的、满足差为偶数的元素）。
- 对每个候选 k，验证整个数组是否能被合法拆分。

**验证：** 排序后，用哈希表贪心匹配，每次取最小未匹配的元素 x，找 x+2k，若存在则匹配。

## 代码实现

### 方法一：排序 + 枚举 k + 验证（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, changed: List[int]) -> List[int]:
        changed.sort()
        n = len(changed) // 2
        cnt = Counter(changed)

        def try_k(k: int) -> List[int]:
            # 尝试用步长 k 恢复原数组
            temp = cnt.copy()
            result = []
            for x in changed:
                if temp[x] == 0:
                    continue  # 已被匹配
                if temp[x + 2 * k] == 0:
                    return []  # 无法匹配
                # 匹配 x 和 x + 2k，原始值为 x + k
                result.append(x + k)
                temp[x] -= 1
                temp[x + 2 * k] -= 1
            return result

        # changed[0] 必须是某个 lower 值
        # 枚举 changed[0] 的配对 higher 值
        min_val = changed[0]
        for i in range(1, len(changed)):
            if changed[i] == min_val:
                continue  # k=0 时 lower==higher，同样值需特殊处理
            diff = changed[i] - min_val
            if diff % 2 == 1:
                continue  # k 必须为整数
            k = diff // 2
            res = try_k(k)
            if res:
                return res

        # 处理 k=0 的情况（changed 中每个值出现偶数次）
        if all(v % 2 == 0 for v in cnt.values()):
            return [x for x in changed[:n]]

        return []
```

### 方法二：整合 k=0 的情况

```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, changed: List[int]) -> List[int]:
        changed.sort()
        cnt = Counter(changed)

        def check(k: int) -> List[int]:
            used = Counter()
            result = []
            for x in sorted(cnt):
                available = cnt[x] - used[x]
                if available < 0:
                    return []
                if available == 0:
                    continue
                # x 作为 lower，需要 x + 2k 作为 higher
                need = x + 2 * k
                if cnt[need] - used[need] < available:
                    return []
                # 取 available 个 x 匹配
                result.extend([x + k] * available)
                used[x] += available
                used[need] += available
            return result if len(result) == len(changed) // 2 else []

        # 枚举所有可能的 2k 值
        min_val = changed[0]
        seen_2k = set()
        for v in changed[1:]:
            two_k = v - min_val
            if two_k % 2 == 0 and two_k not in seen_2k:
                seen_2k.add(two_k)
                res = check(two_k // 2)
                if res:
                    return res

        return []
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+枚举 | O(n^2) 最差 | O(n) |

实际中枚举 k 的候选数量有限，平均表现好得多。

## 关键点总结

1. 排序后最小值一定是 lower 部分的元素。
2. 枚举最小值的配对，得到候选 k，再验证整个数组。
3. 验证时用 Counter 贪心从小到大匹配。

## 易错点

- 差必须为偶数（k 为整数）。
- k=0 时 lower=higher，需特殊判断（每个值出现偶数次）。
- 匹配时不能重复使用已匹配的元素。
