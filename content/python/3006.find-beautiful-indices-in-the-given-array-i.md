## 题目描述

给你一个字符串 `s`、字符串 `a`、字符串 `b` 和整数 `k`。

如果下标 `i` 满足以下条件，则认为该下标是 **美丽下标**：
- `0 <= i <= len(s) - len(a)`
- `s[i..i+len(a)-1] == a`
- 存在下标 `j` 使得 `s[j..j+len(b)-1] == b`，且 `|i - j| <= k`

以升序方式返回所有美丽下标。

**示例 1：**
```
输入：s = "isawsquirrelnearmysquirrelhouseohmy", a = "my", b = "squirrel", k = 15
输出：[16,33]
```

**示例 2：**
```
输入：s = "abcd", a = "a", b = "a", k = 4
输出：[0]
```

**提示：**
- `1 <= k <= s.length <= 10^5`
- `1 <= a.length, b.length <= 10^5`
- `s`、`a`、`b` 只包含小写英文字母

## 解题思路

1. 用 KMP 算法（或 Python 的 `str.find` / 正则）找出所有 `a` 在 `s` 中出现的位置列表 `posA`
2. 用同样方法找出所有 `b` 在 `s` 中出现的位置列表 `posB`
3. 对 `posA` 中的每个位置 `i`，用二分查找在 `posB` 中找是否存在位置 `j` 满足 `|i - j| <= k`

## Python 代码实现

### 方法一：KMP + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        def kmp_search(text: str, pattern: str) -> List[int]:
            # 构建 KMP 失配表
            m = len(pattern)
            fail = [0] * m
            j = 0
            for i in range(1, m):
                while j > 0 and pattern[i] != pattern[j]:
                    j = fail[j - 1]
                if pattern[i] == pattern[j]:
                    j += 1
                fail[i] = j

            # 在 text 中搜索 pattern
            positions = []
            j = 0
            for i in range(len(text)):
                while j > 0 and text[i] != pattern[j]:
                    j = fail[j - 1]
                if text[i] == pattern[j]:
                    j += 1
                if j == m:
                    positions.append(i - m + 1)
                    j = fail[j - 1]
            return positions

        posA = kmp_search(s, a)
        posB = kmp_search(s, b)

        result = []
        for i in posA:
            # 在 posB 中二分查找最近的 j，使 |i - j| <= k
            # 找第一个 >= i - k 的位置
            lo = bisect.bisect_left(posB, i - k)
            if lo < len(posB) and posB[lo] <= i + k:
                result.append(i)

        return result
```

### 方法二：双指针法

```python
from typing import List

class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        def find_all(text: str, pattern: str) -> List[int]:
            positions = []
            start = 0
            while True:
                idx = text.find(pattern, start)
                if idx == -1:
                    break
                positions.append(idx)
                start = idx + 1
            return positions

        posA = find_all(s, a)
        posB = find_all(s, b)

        result = []
        j = 0
        for i in posA:
            # 双指针：移动 j 直到 posB[j] >= i - k
            while j < len(posB) and posB[j] < i - k:
                j += 1
            # 检查 posB[j] 是否 <= i + k
            if j < len(posB) and posB[j] <= i + k:
                result.append(i)

        return result
```

## 复杂度分析

- 时间复杂度：O(n + m1 + m2 + p * log(q))，n 为 s 长度，m1/m2 为 a/b 长度，p/q 为 posA/posB 大小
- 双指针版本：O(n + m1 + m2)
- 空间复杂度：O(n)，存储匹配位置列表

## 关键点总结

1. KMP 算法线性时间找所有匹配位置
2. 二分查找或双指针在有序列表中快速判断范围内是否存在元素
3. 条件 `|i - j| <= k` 等价于 `i - k <= j <= i + k`

## 易错点

1. `bisect_left` 找第一个 >= `i-k` 的位置，还需验证该位置 <= `i+k`
2. 双指针中 `j` 指针只向右移，利用两个列表均有序的性质
3. Python 内置 `str.find` 比 KMP 简单，但对重叠匹配需注意 `start = idx + 1` 而非 `idx + len(pattern)`
