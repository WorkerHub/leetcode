## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。你需要将这个数组划分到 `k` 个相同大小的子集中，使得同一个子集里面没有两个相同的元素。

一个子集的**不兼容性**是该子集里面最大值和最小值的差。

返回将数组分成 `k` 个子集后，各子集**不兼容性**的**和**的**最小值**，如果无法分成 `k` 个子集，返回 `-1`。

子集中的元素不需要排序。

**示例 1：**
```
输入：nums = [1,2,1,4], k = 2
输出：4
解释：最优分配方式为 [1,2] 和 [1,4]
不兼容性为 (2-1) + (4-1) = 4
注意 [1,1] 和 [2,4] 可以得到更小的和，但是第一个子集包含 2 个相同的元素
```

**示例 2：**
```
输入：nums = [6,3,8,1,3,1,2,2], k = 4
输出：6
解释：最优的分配方式为 [1,2],[2,3],[6,8],[1,3]
不兼容性为 (2-1),(3-2),(8-6),(3-1) = 1,1,2,2
最小不兼容性和为 6
```

**提示：**
- `1 <= k <= nums.length <= 16`
- `1 <= nums[i] <= nums.length`
- `nums.length` 能被 `k` 整除

## 解题思路

本题使用**状态压缩动态规划**。

核心思路：
1. 用一个二进制数表示哪些元素已经被分配
2. 预计算每个大小为 `n/k` 的合法子集（无重复元素）的不兼容性
3. `dp[mask]` 表示已分配状态为 `mask` 时，最小不兼容性之和
4. 枚举当前状态下可以新增的合法子集进行转移

预处理：枚举所有大小恰好为 `n/k` 的子集，检查是否有重复元素，记录其不兼容性（max - min）。

状态转移：`dp[mask | sub] = min(dp[mask | sub], dp[mask] + cost[sub])`

## 代码实现

### 方法一：状态压缩动态规划（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumIncompatibility(self, nums: List[int], k: int) -> int:
        n = len(nums)
        size = n // k  # 每个子集的大小

        # 预处理：计算每个合法子集的不兼容性
        # 合法子集：大小为 size，且没有重复元素
        cost = {}
        for mask in range(1, 1 << n):
            # 统计 mask 中 1 的个数
            if bin(mask).count('1') != size:
                continue
            # 提取子集中的元素
            subset = [nums[i] for i in range(n) if mask >> i & 1]
            # 检查是否有重复元素
            if len(set(subset)) == size:
                cost[mask] = max(subset) - min(subset)

        # 如果某个元素出现次数超过 k 次，直接返回 -1
        from collections import Counter
        cnt = Counter(nums)
        if max(cnt.values()) > k:
            return -1

        INF = float('inf')
        dp = [INF] * (1 << n)
        dp[0] = 0

        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            # 找到当前状态中最低位的未选元素（贪心加速）
            # 找 mask 的补集中最小的未被选的下标
            rest = ((1 << n) - 1) ^ mask  # 未选元素的集合
            if rest == 0:
                continue
            # 找 rest 中第一个 1 的位置
            # 枚举包含 rest 中最小未选元素的所有合法子集
            # 找最低位
            low_bit = rest & (-rest)
            low_idx = low_bit.bit_length() - 1

            # 枚举 rest 的子集，找包含 low_idx 的合法子集
            sub = rest
            while sub:
                if (sub & low_bit) and sub in cost:
                    if dp[mask | sub] > dp[mask] + cost[sub]:
                        dp[mask | sub] = dp[mask] + cost[sub]
                # 枚举子集的子集
                sub = (sub - 1) & rest

        result = dp[(1 << n) - 1]
        return result if result != INF else -1
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumIncompatibility(self, nums: List[int], k: int) -> int:
        n = len(nums)
        size = n // k
        INF = float('inf')

        from collections import Counter
        if max(Counter(nums).values()) > k:
            return -1

        # 预计算合法子集的不兼容性
        cost = {}
        for mask in range(1, 1 << n):
            if bin(mask).count('1') != size:
                continue
            subset = [nums[i] for i in range(n) if mask >> i & 1]
            if len(set(subset)) == size:
                cost[mask] = max(subset) - min(subset)

        @lru_cache(maxsize=None)
        def dp(mask):
            # mask 表示已经分配的元素
            if mask == (1 << n) - 1:
                return 0
            rest = ((1 << n) - 1) ^ mask
            # 固定最低未选位，减少重复枚举
            low_bit = rest & (-rest)
            result = INF
            sub = rest
            while sub:
                if (sub & low_bit) and sub in cost:
                    val = dp(mask | sub)
                    if val != INF:
                        result = min(result, cost[sub] + val)
                sub = (sub - 1) & rest
            return result

        ans = dp(0)
        return ans if ans != INF else -1
```

## 复杂度分析

- **时间复杂度**：O(3^n)，枚举所有子集的子集，总量为 3^n
- **空间复杂度**：O(2^n)，存储 dp 数组和 cost 字典

## 关键点总结

1. 状态压缩：用二进制位 `mask` 表示已选元素的集合
2. 枚举子集：`sub = (sub-1) & rest` 是枚举 rest 所有子集的标准写法
3. 固定最低位：每次固定最低未选位所在的子集，避免重复分组
4. 预计算合法子集：提前计算每个合法子集（大小=size，无重复）的代价

## 易错点

1. 需要先检查某个元素出现次数是否超过 `k`，超过则直接返回 -1
2. 枚举子集时要注意 `sub = 0` 的情况，while 循环会在 sub=0 时退出
3. 子集大小必须恰好等于 `n/k`，不能多不能少
