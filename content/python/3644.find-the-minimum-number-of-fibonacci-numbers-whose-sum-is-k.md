## 题目描述

给你一个整数 `k`，找到最少数量的斐波那契数，使得这些数的和等于 `k`。每个斐波那契数可以使用多次。

斐波那契数列：1, 1, 2, 3, 5, 8, 13, 21, ...

**示例 1：**

```
输入：k = 7
输出：2
解释：7 = 5 + 2
```

**示例 2：**

```
输入：k = 10
输出：2
解释：10 = 8 + 2
```

**示例 3：**

```
输入：k = 19
输出：3
解释：19 = 13 + 5 + 1
```

**提示：**

- `1 <= k <= 10^9`

## 解题思路

**贪心：Zeckendorf 定理**

每次选取不超过 `k` 的最大斐波那契数，减去它，重复直到 `k = 0`。

Zeckendorf 定理保证贪心给出最优解：每个正整数都有唯一的不含相邻斐波那契数的分解。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        # 生成所有不超过 k 的斐波那契数
        fibs = [1, 1]
        while fibs[-1] < k:
            fibs.append(fibs[-1] + fibs[-2])

        count = 0
        while k > 0:
            # 找不超过 k 的最大斐波那契数
            while fibs[-1] > k:
                fibs.pop()
            k -= fibs[-1]
            count += 1

        return count
```

### 方法二：二分查找优化

```python
import bisect

class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        fibs = [1, 1]
        while fibs[-1] < k:
            fibs.append(fibs[-1] + fibs[-2])

        count = 0
        while k > 0:
            # 二分找最大不超过 k 的斐波那契数
            idx = bisect.bisect_right(fibs, k) - 1
            k -= fibs[idx]
            count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(log^2 k)，斐波那契数量为 O(log k)，每次查找 O(log log k)
- 空间复杂度：O(log k)

## 关键点总结

1. Zeckendorf 定理：贪心每次取最大斐波那契数是最优的
2. 斐波那契数的数量：1 到 10^9 内约 43 个
3. 使用二分查找快速找到最大斐波那契数

## 易错点

1. 斐波那契数可以重复使用（`5+5=10`，但 `8+2=10` 更少）
2. 贪心每次取最大而非重复取同一个
3. 注意 fibs 列表的生成上界
