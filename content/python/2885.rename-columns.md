## 题目描述

给定一个 DataFrame `students`，按如下规则重命名列名：
- `id` -> `student_id`
- `first` -> `first_name`
- `last` -> `last_name`
- `age` -> `age_in_years`

**示例：**
```
输入：id, first, last, age 列

输出：student_id, first_name, last_name, age_in_years 列
```

## Python 代码实现

### 方法一：rename 方法（推荐）

```python
import pandas as pd

def renameColumns(students: pd.DataFrame) -> pd.DataFrame:
    return students.rename(columns={
        'id': 'student_id',
        'first': 'first_name',
        'last': 'last_name',
        'age': 'age_in_years'
    })
```

### 方法二：直接修改 columns 属性

```python
import pandas as pd

def renameColumns(students: pd.DataFrame) -> pd.DataFrame:
    students.columns = ['student_id', 'first_name', 'last_name', 'age_in_years']
    return students
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `df.rename(columns={'old': 'new'})` 通过字典映射重命名
2. 未在字典中的列名不变
3. 方法二直接赋值需要提供所有列名，顺序必须正确
