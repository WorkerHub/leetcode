## 题目描述

初始时有 `n` 个灯泡处于关闭状态。第一轮，你打开所有的灯泡。第二轮，每两个灯泡你关闭一次。第三轮，每三个灯泡切换一次开关（如果关闭则开启，如果开启则关闭）。

第 `i` 轮，每 `i` 个灯泡切换一次开关。对于第 `n` 轮，你只切换最后一个灯泡的开关。

返回 `n` 轮后有多少个灯泡是亮着的。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/05/bulb.jpg)

```
输入：n = 3
输出：1 
解释：
初始时, 灯泡状态 [关闭, 关闭, 关闭].
第一轮后, 灯泡状态 [开启, 开启, 开启].
第二轮后, 灯泡状态 [开启, 关闭, 开启].
第三轮后, 灯泡状态 [开启, 关闭, 关闭]. 

所以有 1 个灯泡是亮着的。
```

**示例 2：**
```
输入：n = 0
输出：0
```

**示例 3：**
```
输入：n = 1
输出：1
```

**提示：**
- `0 <= n <= 10^9`

## 解题思路

### 暴力模拟（超时）

模拟整个过程，时间复杂度 O(n²)，对于 n=10^9 会超时。

### 数学规律⭐

**关键观察**：
- 灯泡 i 被切换的次数 = i 的因数个数
- 最终亮着 ⟺ 被切换奇数次 ⟺ 因数个数为奇数

**什么数的因数个数是奇数？**
- 只有完全平方数！
- 例如：16 = 1×16 = 2×8 = 4×4
- 除了4以外，其他因数都成对出现

**结论**：
- 最终亮着的灯泡数量 = [1, n] 中完全平方数的个数
- 答案 = floor(√n)

### 证明

对于灯泡 k：
- 在第 i 轮被切换 ⟺ i 是 k 的因数
- k 的因数个数为奇数 ⟺ k 是完全平方数

例如 n = 10：
- 完全平方数：1, 4, 9
- 答案：3 = floor(√10)

## Python 代码实现

### 方法一：数学公式（推荐）⭐

```python
import math

class Solution:
    def bulbSwitch(self, n: int) -> int:
        return int(math.sqrt(n))
```

### 方法二：不用库函数

```python
class Solution:
    def bulbSwitch(self, n: int) -> int:
        # 二分查找 √n 的整数部分
        if n == 0:
            return 0
        
        left, right = 1, n
        while left <= right:
            mid = (left + right) // 2
            if mid * mid <= n:
                left = mid + 1
            else:
                right = mid - 1
        
        return right
```

### 方法三：暴力模拟（仅供理解，会超时）

```python
class Solution:
    def bulbSwitch(self, n: int) -> int:
        # 初始化：所有灯泡关闭
        bulbs = [False] * (n + 1)
        
        # 进行 n 轮操作
        for i in range(1, n + 1):
            # 第 i 轮：每 i 个灯泡切换一次
            for j in range(i, n + 1, i):
                bulbs[j] = not bulbs[j]
        
        # 统计亮着的灯泡
        return sum(bulbs)
```

### 方法四：带详细注释

```python
import math

class Solution:
    def bulbSwitch(self, n: int) -> int:
        """
        数学规律解法
        
        核心观察：
        1. 灯泡 k 被切换的次数 = k 的因数个数
        2. 最终亮着 ⟺ 因数个数为奇数
        3. 因数个数为奇数 ⟺ 完全平方数
        
        例子：
        - 灯泡 6: 因数 [1,2,3,6]，被切换4次，最终关闭
        - 灯泡 9: 因数 [1,3,9]，被切换3次，最终开启
        
        结论：
        - 答案 = [1, n] 中完全平方数的个数
        - = floor(√n)
        """
        return int(math.sqrt(n))
```

## 复杂度分析

**数学方法：**
- 时间复杂度：O(1)
- 空间复杂度：O(1)

**暴力模拟：**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 关键点总结

1. **因数规律**：完全平方数的因数个数是奇数
2. **数学转化**：模拟 → 因数 → 完全平方数
3. **公式**：答案 = floor(√n)
4. **直接计算**：O(1) 时间复杂度

## 易错点

1. **直接模拟**：会超时，必须找规律
2. **理解题意**：第i轮切换第i, 2i, 3i, ... 个灯泡
3. **完全平方数**：1, 4, 9, 16, 25, ...
4. **取整**：使用floor而不是round

1. **从小案例开始**：
   - n=1: 1个灯泡亮
   - n=4: 2个灯泡亮 (1和4)
   - n=9: 3个灯泡亮 (1,4,9)

2. **找规律**：
   - 观察哪些灯泡最终是亮的
   - 分析这些灯泡的特点
   - 发现都是完全平方数

3. **理解因数**：
   - 为什么完全平方数的因数是奇数个？
   - 因为有一个因数会"自己配对"（如4×4）

4. **脑筋急转弯**：
   - 这类题不能硬做
   - 要找数学规律
   - 追求 O(1) 解法
