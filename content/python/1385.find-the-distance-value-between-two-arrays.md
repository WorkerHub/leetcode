## 题目描述

给你两个整数数组 `arr1` 和 `arr2`，以及一个整数 `d`。

请你返回两个数组之间的**距离值**。

`arr1` 中满足条件的元素 `x` 需满足：对于 `arr2` 中的**每个**元素 `y`，都有 `|x - y| > d`。

**距离值**是 `arr1` 中满足上述条件的元素的数量。

**示例 1：**
```
输入：arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
输出：2
解释：
- x=4：|4-10|=6>2，|4-9|=5>2，|4-1|=3>2，|4-8|=4>2 → 满足
- x=5：|5-10|=5>2，|5-9|=4>2，|5-1|=4>2，|5-8|=3>2 → 满足
- x=8：|8-10|=2，不满足（需要严格大于d）
结果：2
```

**示例 2：**
```
输入：arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3
输出：2
```

**示例 3：**
```
输入：arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6
输出：1
```

**提示：**
- `1 <= arr1.length, arr2.length <= 500`
- `-10^3 <= arr1[i], arr2[j] <= 10^3`
- `0 <= d <= 100`

## 解题思路

### 方法一：暴力枚举（O(m×n)，适合小数据）

对 `arr1` 中的每个元素，检查它与 `arr2` 中所有元素的绝对差，若都大于 d 则计数+1。

### 方法二：排序 + 二分查找（O((m+n) log n)，推荐）

**核心思想：**

对 `x ∈ arr1`，若 `arr2` 中存在某个 `y` 满足 `|x - y| <= d`，则等价于 `arr2` 中存在满足 `x - d <= y <= x + d` 的元素。

**算法：**
1. 对 `arr2` 排序。
2. 对每个 `x ∈ arr1`，在排序后的 `arr2` 中：
   - 用二分查找找第一个 `>= x - d` 的位置（lower bound）。
   - 若该位置的元素 `<= x + d`，说明存在 `y ∈ [x-d, x+d]`，即不满足条件。
   - 否则满足条件，计数+1。

### 方法三：双指针（O((m+n) log(m+n))）

## Python 代码实现

### 方法一：暴力枚举（推荐新手理解）

```python
from typing import List

class Solution:
    def findTheDistanceValue(self, arr1: List[int], arr2: List[int], d: int) -> int:
        count = 0

        for x in arr1:
            # 检查 arr2 中是否有元素与 x 的绝对差 <= d
            valid = True
            for y in arr2:
                if abs(x - y) <= d:
                    valid = False
                    break
            if valid:
                count += 1

        return count
```

### 方法二：排序 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def findTheDistanceValue(self, arr1: List[int], arr2: List[int], d: int) -> int:
        arr2.sort()  # 先对 arr2 排序，方便二分查找
        count = 0

        for x in arr1:
            # 寻找 arr2 中第一个 >= x-d 的位置
            lo = x - d
            hi = x + d

            # bisect_left 返回第一个 >= lo 的下标
            pos = bisect.bisect_left(arr2, lo)

            # 判断该位置的值是否 <= hi（即 arr2 中存在属于 [lo, hi] 的元素）
            if pos < len(arr2) and arr2[pos] <= hi:
                # arr2 中有元素与 x 的绝对差 <= d，不满足条件
                continue

            # arr2 中没有元素落在 [x-d, x+d] 范围内，满足条件
            count += 1

        return count
```

### 方法三：双指针

```python
from typing import List

class Solution:
    def findTheDistanceValue(self, arr1: List[int], arr2: List[int], d: int) -> int:
        # 两数组都排序
        arr1_sorted = sorted(arr1)
        arr2_sorted = sorted(arr2)
        count = 0
        j = 0  # arr2 的指针

        for x in arr1_sorted:
            lo, hi = x - d, x + d

            # 移动 j 使得 arr2[j] >= lo（j 不回退）
            while j < len(arr2_sorted) and arr2_sorted[j] < lo:
                j += 1

            # 若 arr2[j] <= hi，说明有元素在 [lo, hi] 中，不满足条件
            if j < len(arr2_sorted) and arr2_sorted[j] <= hi:
                continue  # 不满足，跳过

            count += 1

        return count
        # 注意：双指针方法需要 arr1 有序，且 j 不能回退
        # 若 arr1 未排序，此方法不适用（需要每次重置 j）
```

### 方法四：Python 函数式写法

```python
from typing import List
import bisect

class Solution:
    def findTheDistanceValue(self, arr1: List[int], arr2: List[int], d: int) -> int:
        arr2.sort()

        def is_valid(x):
            """判断 arr1 中元素 x 是否满足条件"""
            pos = bisect.bisect_left(arr2, x - d)
            return pos == len(arr2) or arr2[pos] > x + d

        return sum(1 for x in arr1 if is_valid(x))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(m × n) | O(1) |
| 排序 + 二分 | O((m+n) log n) | O(1) |
| 双指针 | O((m+n) log(m+n)) | O(m+n) |

- m = len(arr1)，n = len(arr2)。
- 方法二：排序 O(n log n)，每次二分 O(log n)，共 m 次，总 O(m log n + n log n)。

## 关键点总结

1. **绝对差条件转化**：`|x - y| > d` 等价于 `y < x-d 或 y > x+d`，即 `y 不在 [x-d, x+d]` 内。
2. **二分查找**：排序后，用 `bisect_left(arr2, x-d)` 找第一个 `>= x-d` 的位置，再判断是否 `<= x+d`。
3. **`bisect` 模块**：Python 内置，`bisect_left` 返回插入位置（左侧插入），即第一个 `>= target` 的下标。
4. 暴力解在数据量小（≤500）时完全足够，无需过度优化。
5. **严格大于**：条件是 `> d`（不是 `>= d`），等于 d 时不满足，需要注意等号。

## 图解示例

以 `arr2 = [1, 8, 9, 10]`（排序后），`x=4`，`d=2` 为例：

```
lo = 4-2 = 2,  hi = 4+2 = 6

bisect_left(arr2, 2) → 查找第一个 >= 2 的位置
arr2 = [1, 8, 9, 10]
         ^  ↑
         0  1
第一个 >= 2 是 arr2[1] = 8

检查 arr2[1] = 8 是否 <= hi = 6？
8 > 6，不在 [2, 6] 内 → arr2 中没有落在 [2,6] 的元素 → x=4 满足条件 ✓
```

## 易错点

1. **严格大于 d**：`|x - y| > d` 是严格不等式，等于 d 时不满足，所以检查的是 `arr2[pos] > x+d`（严格大于）。
2. **二分查找边界**：`pos < len(arr2)` 的判断不能省略，若 `pos == len(arr2)` 说明 `arr2` 中没有 `>= lo` 的元素，全都 `< lo`，满足条件。
3. **双指针的适用条件**：双指针方法要求 `arr1` 有序，且指针 j 只向右移动（不回退）。若 `arr1` 未排序，需先排序。
