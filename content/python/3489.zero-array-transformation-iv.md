## 题目描述

给你一个整数数组 `nums` 和一个二维整数数组 `queries`，其中 `queries[i] = [l, r]`。

每次操作选择一个查询 [l, r]，可以将 nums 中 [l, r] 范围内的某一个元素减少 1。

返回使 nums 所有元素变为 0 所需的最少操作次数。如果无法实现，返回 -1。

**提示：**
- `1 <= nums.length <= 10^3`
- `0 <= nums[i] <= 10^3`
- `1 <= queries.length <= 10^3`

## 解题思路

对每个位置 i，需要将 nums[i] 减到 0，即需要恰好 nums[i] 次操作作用于位置 i。

二分答案 k（使用前 k 个查询）：用 DP 判断前 k 个查询能否将所有元素减到 0。

DP：`dp[j]` = 使用前 k 个查询，将 nums[0..i] 都减到 0 所需的最少查询数（或是否可行）。

实际上：对每个位置 i，覆盖 i 的查询集合是固定的，需要选择 nums[i] 个这样的查询。

## Python 代码实现

### 方法一：二分 + DP 判断

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        m = len(queries)

        def can_zero(k):
            """判断使用前 k 个查询能否将所有 nums[i] 减到 0"""
            # 对每个位置 i，统计前 k 个查询中覆盖 i 的查询集合
            # 需要选 nums[i] 个覆盖 i 的查询（不同查询，每个查询只用一次在位置 i）
            # 但每个查询在一次操作中只能选一个位置
            # 这是一个匹配问题，等价于：
            # 是否存在分配方案，使得每个查询最多用一次，每个位置 i 被覆盖 nums[i] 次

            # 贪心：用差分数组，前 k 个查询按右端点贪心分配
            # dp[i] = 使 nums[0..i-1] 都满足所需的最少查询次数已使用
            # 使用差分 + 贪心

            # 差分数组统计每个位置被覆盖的最大次数
            diff = [0] * (n + 1)
            for i in range(k):
                l, r = queries[i]
                diff[l] += 1
                diff[r + 1] -= 1

            coverage = 0
            for i in range(n):
                coverage += diff[i]
                if coverage < nums[i]:
                    return False
            return True

        if can_zero(m):
            # 二分找最小 k
            lo, hi = 0, m
            while lo < hi:
                mid = (lo + hi) // 2
                if can_zero(mid):
                    hi = mid
                else:
                    lo = mid + 1
            return lo
        return -1
```

### 方法三：DP 判断（精确版）

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        m = len(queries)

        # 对每个位置 i，找覆盖它的查询集合
        # 判断能否选择足够多的查询将所有位置减到 0
        # 差分贪心：前 k 个查询，若每个位置覆盖次数 >= nums[i]，则可行

        def feasible(k):
            diff = [0] * (n + 1)
            for i in range(k):
                l, r = queries[i]
                diff[l] += 1
                diff[r + 1] -= 1
            cur = 0
            for i in range(n):
                cur += diff[i]
                if cur < nums[i]:
                    return False
            return True

        if not feasible(m):
            return -1

        lo, hi = 0, m
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(m log m * n)，二分 * 差分检查
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组：快速计算每个位置被前 k 个查询覆盖的总次数
2. 可行性判断：每个位置覆盖次数 >= nums[i]
3. 二分答案：找最小的 k 使得前 k 个查询可行

## 易错点

1. 差分数组范围要到 n+1（避免越界）
2. 二分左边界可以从 0 开始（使用 0 个查询，全为 0 时可行）
3. 若所有查询都不够，返回 -1
