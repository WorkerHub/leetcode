## 题目描述

你有无限多个栈排成一排，从左到右编号从 `0` 开始，每个栈的最大容量 `capacity` 都相同。

实现 `DinnerPlates` 类：

- `DinnerPlates(int capacity)` 初始化，栈最大容量为 `capacity`
- `void push(int val)` 将 `val` 推入最左边未满的栈
- `int pop()` 返回最右边非空栈顶部元素并移除，若所有栈为空返回 `-1`
- `int popAtStack(int index)` 返回编号 `index` 的栈顶部元素并移除，若栈为空返回 `-1`

## 解题思路

**数据结构：**

1. 使用列表存储所有栈
2. 使用最小堆记录未满栈的索引
3. 使用变量记录最右边非空栈的索引

## Python 代码实现

```python
import heapq

class DinnerPlates:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.stacks = []
        self.available = []  # 最小堆：记录未满栈的索引
        self.rightmost = -1  # 最右边非空栈的索引
    
    def push(self, val: int) -> None:
        # 清理已满的栈索引
        while self.available and self.available[0] < len(self.stacks) and len(self.stacks[self.available[0]]) == self.capacity:
            heapq.heappop(self.available)
        
        # 如果没有可用栈，创建新栈
        if not self.available:
            self.stacks.append([val])
            if len(self.stacks) - 1 > self.rightmost:
                self.rightmost = len(self.stacks) - 1
            if len(self.stacks[-1]) < self.capacity:
                heapq.heappush(self.available, len(self.stacks) - 1)
        else:
            # 推入最左边未满的栈
            idx = self.available[0]
            self.stacks[idx].append(val)
            if len(self.stacks[idx]) == self.capacity:
                heapq.heappop(self.available)
            if idx > self.rightmost:
                self.rightmost = idx
    
    def pop(self) -> int:
        # 找到最右边非空栈
        while self.rightmost >= 0 and not self.stacks[self.rightmost]:
            self.rightmost -= 1
        
        if self.rightmost < 0:
            return -1
        
        val = self.stacks[self.rightmost].pop()
        if len(self.stacks[self.rightmost]) < self.capacity:
            heapq.heappush(self.available, self.rightmost)
        return val
    
    def popAtStack(self, index: int) -> int:
        if index >= len(self.stacks) or not self.stacks[index]:
            return -1
        
        val = self.stacks[index].pop()
        if len(self.stacks[index]) < self.capacity:
            heapq.heappush(self.available, index)
        return val
```

## 复杂度分析

- push：`O(log n)`
- pop：`O(log n)`
- popAtStack：`O(log n)`

## 关键点总结

1. 使用最小堆维护未满栈索引
2. 维护最右边非空栈索引
3. 及时清理无效索引
