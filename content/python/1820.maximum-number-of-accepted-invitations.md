## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，其中 `grid[i][j]` 等于 `0` 或 `1`。如果 `grid[i][j] == 1`，表示第 `i` 个男生可以邀请第 `j` 个女生参加舞会。

返回接受邀请的最多对数（每个男生最多邀请一个女生，每个女生最多被一个男生邀请）。

**示例：**
```
输入：grid = [[1,1,1],[1,0,1],[0,0,1]]
输出：3
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `grid[i][j]` 为 `0` 或 `1`

## 解题思路

这是经典的**二分图最大匹配**问题，使用**匈牙利算法**求解。

男生为左节点集，女生为右节点集，`grid[i][j] == 1` 表示存在边。求最大匹配数。

**匈牙利算法**：对每个男生尝试找到一个女生匹配，若当前目标女生已被匹配，则递归尝试将该女生的匹配对象换到其他女生（增广路）。

## 代码实现

### 方法一：匈牙利算法（推荐）

```python
from typing import List

class Solution:
    def maximumInvitations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # match_girl[j] = 与第 j 个女生匹配的男生编号，-1 表示未匹配
        match_girl = [-1] * n

        def dfs(boy: int, visited: List[bool]) -> bool:
            """尝试为 boy 找到一个匹配，返回是否成功"""
            for girl in range(n):
                if grid[boy][girl] == 1 and not visited[girl]:
                    visited[girl] = True
                    # 若该女生未被匹配，或可以为其当前匹配的男生重新安排
                    if match_girl[girl] == -1 or dfs(match_girl[girl], visited):
                        match_girl[girl] = boy
                        return True
            return False

        result = 0
        for boy in range(m):
            visited = [False] * n  # 记录本轮 DFS 中已访问的女生
            if dfs(boy, visited):
                result += 1
        return result
```

### 方法二：BFS 增广路（Hopcroft-Karp 简化版）

```python
from typing import List
from collections import deque

class Solution:
    def maximumInvitations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        match_boy = [-1] * m   # match_boy[i] = i 号男生匹配的女生编号
        match_girl = [-1] * n  # match_girl[j] = j 号女生匹配的男生编号

        def dfs(boy: int, visited: set) -> bool:
            for girl in range(n):
                if grid[boy][girl] == 1 and girl not in visited:
                    visited.add(girl)
                    if match_girl[girl] == -1 or dfs(match_girl[girl], visited):
                        match_boy[boy] = girl
                        match_girl[girl] = boy
                        return True
            return False

        result = 0
        for boy in range(m):
            if dfs(boy, set()):
                result += 1
        return result
```

## 复杂度分析

- **时间复杂度**：O(m * (m + n))，每个男生 DFS 一次，每次最多访问所有节点
- **空间复杂度**：O(m + n)，匹配数组和访问标记

## 关键点总结

1. 二分图最大匹配的标准解法是匈牙利算法
2. 每次为新男生寻找匹配时，重置 visited 数组，避免影响其他路径
3. 关键操作：若目标女生已匹配，尝试让其原来的匹配对象换到其他女生（增广路思想）

## 易错点

- visited 数组必须每次 DFS（每个男生）重置，而不是全局共享
- match_girl 记录的是当前女生的匹配男生编号，初始为 -1
