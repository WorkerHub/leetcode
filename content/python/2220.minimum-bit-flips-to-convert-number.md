## 题目描述

一次 **位翻转** 定义为将数字 `x` 二进制表示下的某位翻转（0 变 1，1 变 0）。

给你两个整数 `start` 和 `goal`，返回将 `start` 转变成 `goal` 所需的 **最少位翻转** 次数。

**示例 1：**
```
输入：start = 10, goal = 7
输出：3
解释：10 = 1010，7 = 0111，异或后 = 1101，有3个1，故需要翻转3位。
```

**示例 2：**
```
输入：start = 3, goal = 4
输出：3
```

## 解题思路

两个数需要翻转的位，正好是它们异或结果中为 1 的位数（即 XOR 的汉明重量）。

`start XOR goal` 的结果中，为 1 的位表示两数在该位不同，需要翻转。

**统计二进制中 1 的个数**：用 `bin(x).count('1')` 或 `bin(x & -x).bit_count()`，Python 中最简洁是 `bin(x).count('1')`。

## 代码实现

### 方法一：XOR + 统计 1（推荐）

```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        # 异或后统计1的个数（即汉明距离）
        return bin(start ^ goal).count('1')
```

### 方法二：逐位检查

```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        xor = start ^ goal
        count = 0
        # 逐位检查 xor 中是否有 1
        while xor:
            count += xor & 1  # 检查最低位
            xor >>= 1         # 右移一位
        return count
```

### 方法三：Brian Kernighan 算法（快速计算 popcount）

```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        xor = start ^ goal
        count = 0
        # 每次清除最低位的1
        while xor:
            xor &= xor - 1  # 清除最低位的1
            count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O(log(max(start, goal)))，即处理的位数。
- 空间复杂度：O(1)。

## 关键点总结

1. 两数不同的位数等于异或结果中 1 的个数（汉明距离）。
2. Python 的 `bin(x).count('1')` 是最简洁的写法。
3. Brian Kernighan 算法每次清除最低位的 1，循环次数等于 1 的个数。

## 易错点

- 不是求最大值或最小值，而是统计不同位的数量。
- Python 整数可以任意大，但此题输入范围在 int 范围内，无需特殊处理。
