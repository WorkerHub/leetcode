## 题目描述

给你一个整数数组 `colors`，表示一个由红色和蓝色瓷砖组成的圆形，其中 `colors[i] == 0` 表示第 `i` 块瓷砖为红色，`colors[i] == 1` 表示第 `i` 块瓷砖为蓝色。

圆形中任意长度为 3 的连续子序列如果是**交替**的（红蓝红或蓝红蓝），则称为**交替组**。

返回**交替组**的数量。

**注意：**圆形中，第一块和最后一块瓷砖相邻。

**示例 1：**
```
输入：colors = [1,1,1]
输出：0
```

**示例 2：**
```
输入：colors = [0,1,0,0,1]
输出：3
```

**提示：**
- `3 <= colors.length <= 100`
- `0 <= colors[i] <= 1`

## 解题思路

枚举每个长度为 3 的窗口，检查中间元素是否与两侧不同。由于是圆形数组，需要用取模处理边界。

## Python 代码实现

### 方法一：枚举（推荐）

```python
from typing import List

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int]) -> int:
        n = len(colors)
        ans = 0
        for i in range(n):
            # 检查长度为3的窗口 [i-1, i, i+1]（圆形）
            prev = colors[(i - 1) % n]
            curr = colors[i]
            nxt = colors[(i + 1) % n]
            # 交替条件：中间与两侧都不同
            if curr != prev and curr != nxt:
                ans += 1
        return ans
```

### 方法二：扩展数组处理圆形

```python
from typing import List

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int]) -> int:
        n = len(colors)
        # 将数组复制一段处理圆形
        extended = colors + colors[:2]
        ans = 0
        for i in range(1, n + 1):
            if extended[i] != extended[i - 1] and extended[i] != extended[i + 1]:
                ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一）或 O(n)（方法二）

## 关键点总结

1. 圆形数组用取模 `% n` 处理边界
2. 交替组的判断：中间元素与两端均不相同

## 易错点

1. 注意是圆形数组，最后一个元素和第一个元素相邻
2. 长度为 3 的交替组条件是三个元素交替，不是相邻两个不同
