## 题目描述

给定一个有 `n` 个节点的有向无环图（DAG），边集为 `edges`，其中 `edges[i] = [u, v]` 表示从 `u` 到 `v` 有一条有向边。

计算从节点 `0` 出发，能到达节点 `n-1` 的路径总数，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：n = 3, edges = [[0,1],[0,2],[1,2]]
输出：2
解释：路径 0->2 和 0->1->2，共 2 条。
```

**示例 2：**
```
输入：n = 4, edges = [[0,1],[0,2],[1,3],[2,3]]
输出：2
解释：路径 0->1->3 和 0->2->3，共 2 条。
```

**提示：**
- `2 <= n <= 2 * 10^4`
- `0 <= edges.length <= 4 * 10^4`
- 图是有向无环图（DAG）

## 解题思路

记忆化 DFS 或拓扑排序 DP。

**记忆化 DFS：**
- 定义 `dfs(u)`：从节点 `u` 出发到达节点 `n-1` 的路径数。
- 若 `u == n-1`：返回 1（找到终点）
- 否则：`dfs(u) = sum(dfs(v) for (u,v) in edges)`
- 用 `@lru_cache` 避免重复计算。

**拓扑排序 DP：**
- 按拓扑序处理每个节点，`dp[u]` 表示从 `u` 到终点的路径数。

## Python 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from typing import List
from functools import lru_cache
from collections import defaultdict

class Solution:
    def countPaths(self, n: int, edges: List[List[int]]) -> int:
        MOD = 10**9 + 7
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)

        @lru_cache(maxsize=None)
        def dfs(u: int) -> int:
            if u == n - 1:
                return 1  # 到达终点
            total = 0
            for v in graph[u]:
                total = (total + dfs(v)) % MOD
            return total

        return dfs(0)
```

### 方法二：拓扑排序 DP

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def countPaths(self, n: int, edges: List[List[int]]) -> int:
        MOD = 10**9 + 7
        graph = defaultdict(list)
        rev_graph = defaultdict(list)
        in_degree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            rev_graph[v].append(u)
            in_degree[v] += 1

        # 拓扑排序
        topo = []
        queue = deque([i for i in range(n) if in_degree[i] == 0])
        while queue:
            u = queue.popleft()
            topo.append(u)
            for v in graph[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)

        # 逆拓扑序 DP
        dp = [0] * n
        dp[n - 1] = 1  # 终点
        for u in reversed(topo):
            for v in graph[u]:
                dp[u] = (dp[u] + dp[v]) % MOD

        return dp[0]
```

## 复杂度分析

- 时间复杂度：O(n + m)，DFS 或拓扑排序各线性
- 空间复杂度：O(n + m)

## 关键点总结

1. DAG 上的路径计数是经典动态规划问题
2. 记忆化 DFS 简洁，自然利用 DAG 无环性保证收敛
3. 拓扑排序保证处理每个节点时，其所有后继节点已处理完毕

## 易错点

1. 在有环图上不能使用此方法（题目保证 DAG）
2. 递归深度可能较大，Python 需要注意 `sys.setrecursionlimit`
