## 题目描述

给你一个整数数组 `nums`，返回 `nums[i] XOR nums[j]` 的最大运算结果，其中 `0 ≤ i ≤ j < n`。

**示例 1：**
```
输入：nums = [3,10,5,25,2,8]
输出：28
解释：最大运算结果是 5 XOR 25 = 28。
```

**示例 2：**
```
输入：nums = [14,70,53,83,49,91,36,80,92,51,66,70]
输出：127
```

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `0 <= nums[i] <= 2^31 - 1`

## 解题思路

这道题要求找出数组中两个数的最大异或值。核心思想是利用异或运算的性质和贪心策略。

**关键观察：**
1. 异或运算的性质：`a XOR b = c` 等价于 `a XOR c = b`
2. 要让异或结果最大，应该从高位到低位尽可能让每一位都是 1
3. 可以使用字典树（Trie）存储数字的二进制表示，然后贪心地选择每一位

**算法流程：**

**方法一：字典树（Trie）+ 贪心**
1. 构建字典树，将所有数字的二进制表示插入
2. 对每个数字，在字典树中贪心地选择与当前位相反的路径
3. 从高位到低位，尽可能选择能让当前位为 1 的路径

**方法二：哈希表 + 逐位构造**
1. 从高位到低位逐位确定最大异或值
2. 使用哈希表存储已处理位的前缀
3. 利用异或性质验证是否能构造出当前位为 1 的结果

## Python 代码实现

### 方法一：字典树（Trie）⭐ 推荐

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}  # 0 或 1

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        # 构建字典树
        root = TrieNode()
        
        # 将所有数字插入字典树（从高位到低位）
        for num in nums:
            node = root
            for i in range(31, -1, -1):  # 32位整数
                bit = (num >> i) & 1  # 获取第i位
                if bit not in node.children:
                    node.children[bit] = TrieNode()
                node = node.children[bit]
        
        # 对每个数字，在字典树中找最大异或值
        max_xor = 0
        for num in nums:
            node = root
            current_xor = 0
            
            # 从高位到低位贪心选择
            for i in range(31, -1, -1):
                bit = (num >> i) & 1
                # 贪心：尽量选择与当前位相反的路径
                toggle_bit = 1 - bit
                
                if toggle_bit in node.children:
                    current_xor |= (1 << i)  # 当前位可以是1
                    node = node.children[toggle_bit]
                else:
                    node = node.children[bit]  # 只能选择相同的位
            
            max_xor = max(max_xor, current_xor)
        
        return max_xor
```

### 方法二：哈希表 + 逐位构造

```python
from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        max_xor = 0
        mask = 0
        
        # 从高位到低位逐位确定最大异或值
        for i in range(31, -1, -1):
            mask |= (1 << i)  # 更新掩码，保留高位
            prefixes = {num & mask for num in nums}  # 当前位的所有前缀
            
            # 尝试让当前位为1
            temp = max_xor | (1 << i)
            
            # 验证是否存在两个前缀异或能得到temp
            # 利用性质：a XOR b = temp => a XOR temp = b
            for prefix in prefixes:
                if (prefix ^ temp) in prefixes:
                    max_xor = temp
                    break
        
        return max_xor
```

### 方法三：暴力解法（超时，仅用于理解）

```python
from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        max_xor = 0
        n = len(nums)
        
        # 枚举所有数对
        for i in range(n):
            for j in range(i, n):
                max_xor = max(max_xor, nums[i] ^ nums[j])
        
        return max_xor
```

## 复杂度分析

**方法一：字典树**
- 时间复杂度：O(n × L)，其中 n 是数组长度，L = 32 是整数位数
  - 构建字典树：O(n × L)
  - 查询最大异或值：O(n × L)
- 空间复杂度：O(n × L)，字典树最多存储 n × L 个节点

**方法二：哈希表**
- 时间复杂度：O(n × L)，L = 32
  - 外层循环 L 次，内层遍历 n 个元素
- 空间复杂度：O(n)，哈希表存储前缀

**方法三：暴力**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 关键点总结

1. **异或性质**：利用 `a XOR b = c` 等价于 `a XOR c = b` 的性质
2. **贪心策略**：从高位到低位，尽可能让每一位都是 1
3. **字典树应用**：适合处理二进制位的问题，支持高效的前缀匹配
4. **逐位构造**：哈希表方法通过逐位验证来构造最大值
5. **位运算技巧**：熟练使用位移、与、或等位运算操作

## 易错点

1. **位数处理**：整数是 32 位，循环要从 31 到 0
2. **掩码更新**：哈希表方法中，mask 要逐步累加高位
3. **字典树路径选择**：优先选择相反的位，只有不存在时才选择相同的位
4. **边界情况**：数组只有一个元素时，结果是 0（自己与自己异或）
5. **溢出问题**：Python 整数不会溢出，但其他语言需注意
