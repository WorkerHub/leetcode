## 题目描述

给你一个整数数组 `workers` 和两个二维整数数组 `tasks` 和 `profits`。

每个任务 `tasks[i]` 需要技能等级至少为 `tasks[i][0]` 的工人完成，完成后获得利润 `tasks[i][1]`（即 `profits[i]`）。

每个工人 `workers[j]` 有技能等级 `workers[j]`，最多完成一个任务。

返回最大总利润。

**示例：**

```
输入：workers = [3,5,2], tasks = [[2,50],[4,30],[5,20]]
输出：80
解释：工人0（技能3）完成任务0（利润50），工人1（技能5）完成任务1（利润30），最大80
```

**提示：**
- `1 <= workers.length, tasks.length <= 10^5`
- `1 <= workers[i], tasks[i][0] <= 10^9`
- `1 <= tasks[i][1] <= 10^9`

## 解题思路

贪心排序：将工人和任务按技能/需求排序，用最大堆保存当前工人能完成的所有任务利润，贪心选最大利润。

具体步骤：
1. 对工人按技能从小到大排序
2. 对任务按需求技能从小到大排序
3. 遍历工人，将当前工人能完成的任务加入最大堆
4. 每次从堆中取出利润最大的任务分配给当前工人

## Python 代码实现

### 方法一：排序 + 最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxProfit(self, workers: List[int], tasks: List[List[int]], profits: List[int]) -> int:
        # 合并任务信息，按需求技能排序
        task_list = sorted(zip([t[0] for t in tasks], profits))
        workers_sorted = sorted(workers)

        heap = []  # 最大堆（用负数模拟）
        j = 0
        total = 0
        n_tasks = len(task_list)

        for w in workers_sorted:
            # 将当前工人能完成的所有任务加入堆
            while j < n_tasks and task_list[j][0] <= w:
                heapq.heappush(heap, -task_list[j][1])
                j += 1
            # 选利润最大的任务
            if heap:
                total += -heapq.heappop(heap)

        return total
```

        for w in workers_sorted:

### 方法三：排序 + 贪心（最优）

```python
from typing import List
import heapq

class Solution:
    def maxProfit(self, workers: List[int], tasks: List[List[int]], profits: List[int]) -> int:
        task_profit = sorted(zip([t[0] for t in tasks], profits))
        workers_sorted = sorted(workers)

        max_heap = []
        j = 0
        ans = 0

        for skill in workers_sorted:
            # 所有需求 <= skill 的任务都可以做
            while j < len(task_profit) and task_profit[j][0] <= skill:
                heapq.heappush(max_heap, -task_profit[j][1])
                j += 1
            if max_heap:
                ans += -heapq.heappop(max_heap)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n + m log m)，n 为工人数，m 为任务数，排序和堆操作
- 空间复杂度：O(m)，堆的大小

## 关键点总结

1. 贪心：将工人和任务一起排序，逐步扩大可选任务集合
2. 最大堆：始终从当前可选任务中选利润最大的
3. 每个工人只选一个任务，每个任务只被选一次

## 易错点

1. 堆中任务被选走后不能再用，heappop 自然保证
2. 工人从小到大遍历，j 指针单调递增，不用重置
3. 技能等级相同的工人可以选同一批任务
