## 题目描述

给你 `nums`，一个正整数数组，其中有 `2 * n` 个数字，你需要执行 `n` 次操作。

第 `i` 次操作（从 1 开始编号）：
- 选择两个元素 `x` 和 `y`
- 获得 `i * gcd(x, y)` 分
- 将 `x` 和 `y` 从 `nums` 中移除

请你返回 `n` 次操作后你能获得的**最大分数**。

**示例 1：**
```
输入：nums = [1,2]
输出：1
解释：第 1 次操作选择 nums[0] 和 nums[1]，得 1 * gcd(1,2) = 1
```

**示例 2：**
```
输入：nums = [3,4,6,8]
输出：11
解释：第 1 次操作选 nums[1] 和 nums[2]：gcd(4,6)=2，得 1*2=2；第 2 次选 nums[0] 和 nums[3]：gcd(3,8)=1，得 2*1=2；总计 2+... 不对，11 是最优
最优：操作1选 (3,6) gcd=3，得 3；操作2选 (4,8) gcd=4，得 8；总计 11
```

**提示：**
- `1 <= n <= 7`
- `nums.length == 2 * n`
- `1 <= nums[i] <= 10^6`

## 解题思路

`2n` 个元素，需要配对 n 次，共有 `(2n-1)!! = (2n-1) * (2n-3) * ... * 1` 种配对方式。使用**状态压缩 DP**。

- `dp[mask]`：已使用元素集合为 `mask` 时的最大得分
- 当前操作次数 = `popcount(mask) / 2`（因为每次操作用掉 2 个元素）
- 枚举 `mask` 中选择哪两个元素 `i` 和 `j`，从 `dp[mask ^ (1<<i) ^ (1<<j)]` 转移

预处理所有对 `(i, j)` 的 gcd 值，加速计算。

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)  # 2 * (操作次数)
        ops = n // 2   # 操作次数

        # 预计算所有对的 gcd
        g = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                g[i][j] = gcd(nums[i], nums[j])

        # dp[mask]：已使用元素集合为 mask 时的最大得分
        dp = [0] * (1 << n)

        for mask in range(1, 1 << n):
            # 当前已使用的元素数量
            used = bin(mask).count('1')
            if used % 2 != 0:
                continue  # 使用的元素数必须是偶数
            op = used // 2  # 已经执行了 op 次操作（即当前是第 op+1 次操作）

            # 找 mask 中最小的未使用... 不对，找 mask 中已选的元素
            # 枚举 mask 中的所有有效对 (i, j)，i < j，都在 mask 中
            # 固定最低位，减少重复枚举
            low_bit = mask & (-mask)
            i = low_bit.bit_length() - 1  # mask 中最小的下标

            rest = mask ^ low_bit  # 去掉 i 后剩余的集合
            j_mask = rest
            while j_mask:
                j_bit = j_mask & (-j_mask)
                j = j_bit.bit_length() - 1
                # 从 dp[mask ^ (1<<i) ^ (1<<j)] 转移
                prev_mask = mask ^ low_bit ^ j_bit
                score = op * g[i][j] + dp[prev_mask]
                if score > dp[mask]:
                    dp[mask] = score
                j_mask ^= j_bit

        return dp[(1 << n) - 1]
```

### 方法二：记忆化搜索

```python
from typing import List
from math import gcd
from functools import lru_cache

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)

        # 预计算 gcd
        gcd_table = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                gcd_table[i][j] = gcd(nums[i], nums[j])

        @lru_cache(maxsize=None)
        def dp(mask):
            # mask 是剩余未使用的元素集合
            used = n - bin(mask).count('1')  # 已使用数量
            op = used // 2 + 1              # 当前是第几次操作

            if mask == 0:
                return 0

            # 枚举选取 mask 中最小下标的元素 i，和另一个元素 j
            low_bit = mask & (-mask)
            i = low_bit.bit_length() - 1
            rest = mask ^ low_bit

            best = 0
            tmp = rest
            while tmp:
                j_bit = tmp & (-tmp)
                j = j_bit.bit_length() - 1
                score = op * gcd_table[min(i,j)][max(i,j)] + dp(mask ^ low_bit ^ j_bit)
                if score > best:
                    best = score
                tmp ^= j_bit

            return best

        return dp((1 << n) - 1)
```

## 复杂度分析

- **时间复杂度**：O(4^n * n) 或 O(3^n * n)，状态数 * 枚举
- **空间复杂度**：O(2^n)，dp 数组

## 关键点总结

1. 状态压缩：用二进制 mask 表示已使用的元素集合
2. 固定最低位优化：每次固定 mask 中最低位的元素，减少重复枚举配对
3. 操作次序 = `popcount(mask) / 2`，决定每次操作的系数
4. 预计算 gcd 避免重复计算

## 易错点

1. mask 中 `'1'` 的个数必须是偶数才是有效状态
2. 操作次数的计算：已用 `2k` 个元素时，刚执行完第 `k` 次操作，下一次是第 `k+1` 次
3. 最低位优化中，i 是固定的（最小下标），只枚举 j（其他下标）
