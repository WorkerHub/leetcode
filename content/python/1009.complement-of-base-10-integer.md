## 题目描述

每个非负整数 `n` 都有其二进制表示。例如，`5` 可以被表示为二进制的 `"101"`。

我们可以将二进制的每一位翻转（0 变成 1，1 变成 0），得到这个数的补数。例如，`5` 的二进制补数是 `"010"`，也就是十进制的 `2`。

给你一个整数 `n`，返回其二进制表示的补数（十进制）。

**示例 1：**
```
输入：n = 5
输出：2
解释：5 的二进制表示为 "101"，其补数为 "010"，也就是十进制的 2。
```

**示例 2：**
```
输入：n = 7
输出：0
解释：7 的二进制表示为 "111"，其补数为 "000"，也就是十进制的 0。
```

**示例 3：**
```
输入：n = 10
输出：5
解释：10 的二进制表示为 "1010"，其补数为 "0101"，也就是十进制的 5。
```

**提示：**
- `0 <= n < 10^9`

**注意**：本题与 [476. 数字的补数](https://leetcode.com/problems/number-complement/) 相同

## 解题思路

**核心思想**：找到一个全1的掩码，与n异或即可得到补数

例如：
- n = 5 = 101
- mask = 111 (3位全1)
- 补数 = n ^ mask = 101 ^ 111 = 010 = 2

**关键步骤**：
1. 找到n的最高位1的位置
2. 构造相同位数的全1掩码
3. n与掩码异或得到结果

**特殊情况**：n = 0 时，补数为 1

## Python 代码实现

### 方法一：位运算构造掩码（推荐）⭐

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        """
        构造全1掩码后异或
        时间复杂度：O(logn)
        空间复杂度：O(1)
        """
        # 特殊情况：0的补数是1
        if n == 0:
            return 1
        
        # 找到最高位1的位置，构造掩码
        mask = 1
        temp = n
        
        # 将mask左移到与n相同的位数
        while temp > 0:
            mask <<= 1
            temp >>= 1
        
        # mask现在是比n大的最小的2的幂
        # 减1得到全1掩码
        mask -= 1
        
        # 异或得到补数
        return n ^ mask
```

### 方法二：直接计算掩码⭐⭐

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        """
        利用位运算技巧快速计算掩码
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        # 特殊情况
        if n == 0:
            return 1
        
        # 计算n的位数
        bit_length = n.bit_length()
        
        # 构造全1掩码：2^bit_length - 1
        mask = (1 << bit_length) - 1
        
        # 异或得到补数
        return n ^ mask
```

### 方法三：字符串转换

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        """
        转换为二进制字符串处理
        时间复杂度：O(logn)
        空间复杂度：O(logn)
        """
        # 转换为二进制字符串（去掉'0b'前缀）
        binary = bin(n)[2:]
        
        # 翻转每一位
        complement = ''.join('1' if bit == '0' else '0' for bit in binary)
        
        # 转换为十进制
        return int(complement, 2)
```

### 方法四：逐位处理

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        """
        从右往左逐位翻转
        时间复杂度：O(logn)
        空间复杂度：O(1)
        """
        if n == 0:
            return 1
        
        result = 0
        power = 0  # 2的幂次
        
        while n > 0:
            # 取最后一位并翻转
            bit = n & 1
            flipped_bit = 1 - bit
            
            # 添加到结果中
            result += flipped_bit * (1 << power)
            
            # 移到下一位
            n >>= 1
            power += 1
        
        return result
```

### 方法五：数学公式（最简洁）⭐⭐⭐

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        """
        数学公式：补数 = 2^位数 - 1 - n
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        if n == 0:
            return 1
        
        # 找到大于n的最小2的幂，减1得到全1掩码
        # 然后用掩码减去n即可
        power_of_2 = 1
        while power_of_2 <= n:
            power_of_2 <<= 1
        
        return power_of_2 - 1 - n
```

## 图解示例

以 n = 5 为例：

```
n = 5
二进制：101

步骤1：找到位数 = 3
步骤2：构造掩码 = 111 (二进制) = 7 (十进制)
步骤3：异或 = 101 ^ 111 = 010 = 2

或者用公式：
2^3 - 1 - 5 = 8 - 1 - 5 = 2
```

## 关键点总结

1. **异或性质**：a ^ 1 = ~a（位翻转）
2. **掩码构造**：2^位数 - 1 得到全1掩码
3. **Python技巧**：`bit_length()` 方法获取位数
4. **特殊情况**：0的补数是1（不是0）
5. **等价公式**：n ^ mask = mask - n

## 易错点

1. **忘记处理 n=0**：0的补数是1，不是0
2. **掩码位数错误**：要确保掩码与n位数相同
3. **溢出问题**：虽然Python不会溢出，但要理解掩码范围
4. **异或理解**：1^1=0, 0^1=1, 即与1异或等于翻转
5. **公式理解**：mask - n 等价于 n ^ mask
