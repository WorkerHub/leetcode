## 题目描述

给你两个整数数组 `original` 和 `changed`，以及整数数组 `cost`，其中 `original[i]` 可以用 `cost[i]` 的代价转换为 `changed[i]`。

另给你一个整数数组 `source` 和 `target`，请返回将 `source` 数组转换为 `target` 数组的最小总代价。若无法转换，返回 -1。

每次转换可以选择应用任意多次，多步转换可以组合。

**示例 1：**

```
输入：source = [0,3,3,1], target = [3,1,1,0],
     original = [0,1,2,3], changed = [1,2,3,0], cost = [5,2,2,3]
输出：9
```

**提示：**

- `1 <= source.length == target.length <= 10^5`
- `0 <= source[i], target[i] <= 10^9`
- `1 <= original.length == changed.length == cost.length <= 10^5`

## 解题思路

建图 + 最短路（Floyd 或 Dijkstra）：

1. 将所有转换规则视为有向加权图的边
2. 用 Floyd-Warshall（若值域小）或 Dijkstra（多源）计算每对值之间的最小转换代价
3. 对每对 `(source[i], target[i])`，查询最短路代价

由于值可达 10^9，需要离散化处理。

## Python 代码实现

### 方法一：Dijkstra + 离散化（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, source: List[int], target: List[int],
                    original: List[int], changed: List[int], cost: List[int]) -> int:
        # 离散化：收集所有出现的值
        all_vals = set(source) | set(target) | set(original) | set(changed)
        rank = {v: i for i, v in enumerate(sorted(all_vals))}
        n = len(rank)

        # 建图
        graph = defaultdict(list)
        for o, c, w in zip(original, changed, cost):
            graph[rank[o]].append((rank[c], w))

        # 对每个唯一源值，运行 Dijkstra
        unique_sources = set(rank[s] for s in source if s in rank)
        dist = {}  # dist[src][dst] = 最短代价

        def dijkstra(src):
            d = [float('inf')] * n
            d[src] = 0
            heap = [(0, src)]
            while heap:
                dd, u = heapq.heappop(heap)
                if dd > d[u]:
                    continue
                for v, w in graph[u]:
                    if d[u] + w < d[v]:
                        d[v] = d[u] + w
                        heapq.heappush(heap, (d[v], v))
            return d

        ans = 0
        memo = {}
        for s, t in zip(source, target):
            if s == t:
                continue
            rs, rt = rank.get(s), rank.get(t)
            if rs is None or rt is None:
                return -1
            if rs not in memo:
                memo[rs] = dijkstra(rs)
            d = memo[rs][rt]
            if d == float('inf'):
                return -1
            ans += d

        return ans
```

### 方法二：Floyd-Warshall（值域小时）

```python
from typing import List

class Solution:
    def minimumCost(self, source: List[int], target: List[int],
                    original: List[int], changed: List[int], cost: List[int]) -> int:
        INF = float('inf')
        all_vals = sorted(set(source + target + original + changed))
        rank = {v: i for i, v in enumerate(all_vals)}
        n = len(all_vals)

        dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            dist[i][i] = 0

        for o, c, w in zip(original, changed, cost):
            ro, rc = rank[o], rank[c]
            dist[ro][rc] = min(dist[ro][rc], w)

        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        ans = 0
        for s, t in zip(source, target):
            if s == t:
                continue
            d = dist[rank[s]][rank[t]]
            if d == INF:
                return -1
            ans += d
        return ans
```

## 复杂度分析

- 时间复杂度：O((V + E) log V * V + n)，Dijkstra 多源
- 空间复杂度：O(V^2)（Floyd）或 O(V + E)（Dijkstra）

## 关键点总结

1. 多步转换通过最短路解决（转换可传递）
2. 值域大时需要离散化
3. 对每个不同的源值只运行一次 Dijkstra

## 易错点

1. 同一边可能多次出现，取最小代价
2. 若 source[i] == target[i] 则代价为 0
3. 任何一对无法转换则返回 -1
