## 题目描述

给你一个下标从 **0** 开始的字符串数组 `words` 和两个整数 `left` 和 `right`。

如果字符串的 **第一个** 字符和 **最后一个** 字符都是元音字母（`a`、`e`、`i`、`o`、`u`），则认为该字符串是一个 **元音字符串**。

返回 `words[left]` 到 `words[right]`（含 `words[left]` 和 `words[right]`）中元音字符串的数目。

**示例 1：**

```
输入：words = ["are","amy","u"], left = 0, right = 2
输出：2
解释：- "are" 首字符 'a' 和尾字符 'e' 都是元音 → 计数
     - "amy" 尾字符 'y' 不是元音 → 不计
     - "u" 首尾都是 'u' → 计数
共 2 个。
```

**示例 2：**

```
输入：words = ["hey","aeo","mu","ooo","artro"], left = 1, right = 4
输出：3
```

**提示：**

- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 10`
- `words[i]` 仅由小写英文字母组成
- `0 <= left <= right < words.length`

## 解题思路

遍历 `words[left..right]`，对每个字符串判断首尾字符是否都在元音集合 `{'a','e','i','o','u'}` 中，统计满足条件的数目。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], left: int, right: int) -> int:
        vowels = set('aeiou')
        count = 0
        for i in range(left, right + 1):
            w = words[i]
            # 首字符和尾字符都是元音
            if w[0] in vowels and w[-1] in vowels:
                count += 1
        return count
```

### 方法二：切片 + sum

```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], left: int, right: int) -> int:
        vowels = set('aeiou')
        # 用生成器表达式统计
        return sum(
            1 for w in words[left:right + 1]
            if w[0] in vowels and w[-1] in vowels
        )
```

## 复杂度分析

- 时间复杂度：O(right - left + 1)，线性遍历子数组
- 空间复杂度：O(1)，仅用常数额外空间

## 关键点总结

1. 元音集合：`{'a', 'e', 'i', 'o', 'u'}`，共 5 个
2. 只需检查首字符 `w[0]` 和尾字符 `w[-1]`
3. 范围是闭区间 `[left, right]`，切片写法是 `words[left:right+1]`

## 易错点

1. 右边界是 `right + 1`（Python 切片不含右端点）
2. 单字符字符串 `"u"` 的首尾是同一个字符，仍然合法
3. 不要误用 `w[len(w)-1]`，直接用 `w[-1]` 更简洁
