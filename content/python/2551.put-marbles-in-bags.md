## 题目描述

你有 `n` 个弹珠和 `k` 个袋子。第 `i` 个弹珠的重量为 `weights[i]`。

将 **所有** 弹珠放入 `k` 个袋子，每个袋子至少有一个弹珠，袋子装的是连续弹珠。

一个袋子的得分 = 袋子中第一个和最后一个弹珠的重量之和。分配方案的总得分 = 所有袋子得分之和。

返回 **最大总得分** 和 **最小总得分** 的差值。

**示例 1：**

```
输入：weights = [1,3,5,1], k = 2
输出：4
解释：最大得分方案为 [1][3,5,1]，得分 = (1+1)+(3+1) = 6；最小得分方案为 [1,3][5,1]，得分 = (1+3)+(5+1) = 10... 差值为 4。
```

**提示：**

- `1 <= k <= weights.length <= 10^5`
- `1 <= weights[i] <= 10^9`

## 解题思路

关键观察：
- 无论如何分配，`weights[0]` 和 `weights[n-1]` 始终在得分中（第一袋的首 + 最后一袋的尾）
- 每次分割在位置 i 和 i+1 之间，会额外贡献 `weights[i] + weights[i+1]` 到总得分
- 分成 k 袋需要 k-1 个分割点

所以问题转化为：从 `adj[i] = weights[i] + weights[i+1]`（i = 0..n-2）中选 k-1 个，选最大 k-1 个之和减最小 k-1 个之和即为答案。

## Python 代码实现

### 方法一：排序选最大最小（推荐）

```python
from typing import List

class Solution:
    def putMarbles(self, weights: List[int], k: int) -> int:
        if k == 1:
            return 0  # 只有一种分法

        n = len(weights)
        # 相邻对的和
        adj = sorted(weights[i] + weights[i+1] for i in range(n-1))

        # 选 k-1 个分割点：最大 k-1 个之和 - 最小 k-1 个之和
        return sum(adj[-(k-1):]) - sum(adj[:k-1])
```

### 方法二：用堆选最大最小

```python
from typing import List
import heapq

class Solution:
    def putMarbles(self, weights: List[int], k: int) -> int:
        if k == 1 or k == len(weights):
            return 0

        n = len(weights)
        adj = [weights[i] + weights[i+1] for i in range(n-1)]

        # 最大 k-1 个
        largest = heapq.nlargest(k-1, adj)
        # 最小 k-1 个
        smallest = heapq.nsmallest(k-1, adj)

        return sum(largest) - sum(smallest)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 adj 数组
- 空间复杂度：O(n)，adj 数组

## 关键点总结

1. 首尾弹珠固定贡献，重点是 k-1 个分割点的选择
2. 每个分割点在 i 和 i+1 之间，贡献 weights[i] + weights[i+1]
3. 最大分数 - 最小分数 = 最大 k-1 个 adj 之和 - 最小 k-1 个 adj 之和

## 易错点

1. k = 1 时只有一种分法，差值为 0
2. adj 数组大小为 n-1，选 k-1 个分割点
3. 注意 adj 的计算范围 [0, n-2]
