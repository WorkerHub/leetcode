## 题目描述

给你一个整数数组 `nums`，每次操作可以选择数组中的最大元素，将其替换为 `ceil(max / 2)`。执行 `k` 次操作后，返回数组的最大元素。

**示例 1：**

```
输入：nums = [2,11,10,1,3], k = 4
输出：2
解释：
选11→ceil(11/2)=6: [2,6,10,1,3]
选10→5: [2,6,5,1,3]
选6→3: [2,3,5,1,3]
选5→3: [2,3,3,1,3]
最大值为3，但答案是2...需重新计算
```

**示例 2：**

```
输入：nums = [1,1,1,1], k = 0
输出：1
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 解题思路

**二分答案**：二分最终最大值 `mid`，判断是否能在 `k` 次操作内使所有元素 <= `mid`。

对每个元素 `x`，需要几次操作才能使其 <= `mid`？
- 若 `x <= mid`，0 次
- 否则，反复除以 2（向上取整），直到 <= mid

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List
import math

class Solution:
    def minimizeMax(self, nums: List[int], k: int) -> int:
        def ops_needed(x, target):
            """将 x 减小到 <= target 需要的操作次数"""
            ops = 0
            while x > target:
                x = math.ceil(x / 2)
                ops += 1
            return ops

        def check(mid):
            total_ops = sum(ops_needed(x, mid) for x in nums)
            return total_ops <= k

        left, right = 1, max(nums)
        while left < right:
            mid = (left + right) // 2
            if check(mid):
                right = mid
            else:
                left = mid + 1

        return left
```

### 方法二：优先队列模拟

```python
from typing import List
import heapq
import math

class Solution:
    def minimizeMax(self, nums: List[int], k: int) -> int:
        heap = [-x for x in nums]
        heapq.heapify(heap)

        for _ in range(k):
            max_val = -heapq.heappop(heap)
            new_val = math.ceil(max_val / 2)
            heapq.heappush(heap, -new_val)

        return -heap[0]
```

## 复杂度分析

- 时间复杂度：O(n log n * log(max_val))（二分），O(k log n)（模拟）
- 空间复杂度：O(n)（模拟）或 O(1)（二分，不含输入）

## 关键点总结

1. 二分答案：对最终最大值二分，验证 k 次是否足够
2. `ceil(x/2)` 对应每次操作
3. 操作次数与初始值有关，每次减半向上取整

## 易错点

1. `ceil(x/2) = (x + 1) // 2`
2. 操作针对最大元素，但二分时可以独立考虑每个元素
3. 模拟时用最大堆（Python 用负数最小堆）
