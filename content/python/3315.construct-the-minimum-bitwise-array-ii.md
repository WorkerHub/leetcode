## 题目描述

与 3314 相同，但数据范围更大：`2 <= nums[i] <= 10^9`，需要 O(log n) 的解法。

给你一个长度为 `n` 的数组 `nums`，其中每个元素都是**质数**。构造数组 `ans` 满足 `ans[i] OR (ans[i] + 1) == nums[i]`，无解时为 -1。

**提示：**
- `1 <= nums.length <= 10^5`
- `2 <= nums[i] <= 10^9`
- `nums[i]` 是质数

## 解题思路

**位运算分析：**

设 `x | (x+1) = p`。

`x+1` 是将 `x` 的最低 0 位变成 1（可能有进位）。`x | (x+1)` 的效果是将 `x` 的最低 0 位变成 1。

因此，`p = x | (x+1)` 意味着 `p` 与 `x` 只在 `x` 的最低 0 位处不同，且 `p` 那一位为 1。

也就是说：
- `p` 的某一位为 1，其下方所有位也为 1（因为 `x` 在那一位及以下全为 1，`x+1` 进位后那一位变 1，OR 后也是 1）。

等价条件：**`p` 的二进制表示中，存在某个位 `k`（`k >= 1`），使得 `p` 从第 `k` 位到第 0 位全部为 1。**

即：`(p & ((1 << (k+1)) - 1)) == (1 << (k+1)) - 1`，意味着 p 的末 `k+1` 位全是 1。

最小的 `x`：将 `p` 的第 `k` 位（那个 0 变 1 的位）和更低位清零，得到 `x = p ^ ((1 << (k+1)) - 1) ^ (1 << k)` ...

## Python 代码实现

### 方法一：位运算（推荐）

```python
from typing import List

class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        result = []
        for p in nums:
            if p == 2:
                result.append(-1)
            else:
                # 计算 p 的末尾连续 1 的个数 t
                # 答案是 p ^ (1 << (t-1))
                t = 0
                tmp = p
                while tmp & 1:
                    t += 1
                    tmp >>= 1
                # t 是末尾连续 1 的个数，t >= 1（因为 p 是奇质数）
                result.append(p ^ (1 << (t - 1)))
        return result
```

### 方法二：利用位运算简化

```python
from typing import List

class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        result = []
        for p in nums:
            if p == 2:
                result.append(-1)
            else:
                # (p+1) 会将末尾连续1翻转为0并进位
                # (p+1) & p = p 去掉末尾连续1和进位位（即清除末尾的1块）
                # 末尾1块的最低位是 bit 0，最高位是 bit t-1
                # 我们要的是 p ^ (1 << (t-1))
                # = p & ~(1 << (t-1)) | (0)
                # 等价于：p - (1 << (t-1))
                # (1 << (t-1)) = ((p+1) >> 1) & ~(p >> 1)... 复杂
                # 直接用循环计算 t 就好
                t = (p ^ (p + 1)).bit_length() - 1
                # p ^ (p+1) = 1的个数是 t+1 个（从bit0到bit t）
                # .bit_length() = t+1，所以 t = .bit_length() - 1... 
                # Hmm: p = 5 = 101, p+1 = 110, p^(p+1) = 011, bit_length = 2, t = 2-1 = 1. Correct!
                # p = 7 = 111, p+1 = 1000, p^(p+1) = 1111, bit_length = 4, t = 3. Correct!
                # p = 3 = 11, p+1 = 100, p^(p+1) = 111, bit_length = 3, t = 2. Correct!
                result.append(p ^ (1 << (t - 1)))
        return result
```

## 复杂度分析

- 时间复杂度：O(n log max_val)，对每个数计算末尾 1 的个数
- 空间复杂度：O(1)，不计输出

## 关键点总结

1. 质数 p = 2 时无解（偶数，唯一偶质数）。
2. 奇质数 p，答案是 `p ^ (1 << (t-1))`，其中 t 是 p 二进制末尾连续 1 的个数。
3. `p ^ (p+1)` 的位长度 - 1 可以快速计算 t。

## 易错点

1. 只有 2 是偶质数，其余质数均为奇数（末尾连续 1 数量 >= 1）。
2. `t` 是末尾连续 1 的个数，不是最高位的位置。
3. `p ^ (p+1)` 包含 t+1 个连续的 1（从 bit0 到 bit t），其 bit_length = t+1。
