## 题目描述

给定两个稀疏矩阵 `mat1`（`m x k`）和 `mat2`（`k x n`），计算它们的矩阵乘积 `mat1 x mat2`，返回 `m x n` 的结果矩阵。利用稀疏性优化计算（避免对零元素进行乘法操作）。

**示例：**

```
输入：mat1 = [[1,0,0],[-1,0,3]], mat2 = [[7,0,0],[0,0,0],[0,0,1]]
输出：[[7,0,0],[-7,0,3]]
```

**提示：**
- `1 <= m, k, n <= 100`
- `mat1[i][j], mat2[i][j]` 为整数
- 矩阵是稀疏的（大多数元素为 0）

## 解题思路

标准矩阵乘法 `result[i][j] = sum(mat1[i][k] * mat2[k][j] for k in range(K))`。

利用稀疏性优化：
1. 预先存储 `mat1` 的非零元素 `(i, k, val)`
2. 对每个非零的 `mat1[i][k]`，遍历 `mat2[k][:]` 中的非零元素

## Python 代码实现

### 方法一：哈希表存储稀疏元素（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m = len(mat1)
        k = len(mat1[0])
        n = len(mat2[0])

        result = [[0] * n for _ in range(m)]

        # 存储 mat1 的非零元素
        sparse1 = defaultdict(list)
        for i in range(m):
            for j in range(k):
                if mat1[i][j] != 0:
                    sparse1[i].append((j, mat1[i][j]))

        # 存储 mat2 的非零元素
        sparse2 = defaultdict(list)
        for i in range(k):
            for j in range(n):
                if mat2[i][j] != 0:
                    sparse2[i].append((j, mat2[i][j]))

        # 计算乘积
        for i in range(m):
            for col_idx, val1 in sparse1[i]:
                for j, val2 in sparse2[col_idx]:
                    result[i][j] += val1 * val2

        return result
```

### 方法二：直接矩阵乘法（简洁版）

```python
from typing import List

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        result = [[0] * n for _ in range(m)]

        for i in range(m):
            for p in range(k):
                if mat1[i][p] == 0:
                    continue  # 跳过零元素
                for j in range(n):
                    if mat2[p][j] != 0:
                        result[i][j] += mat1[i][p] * mat2[p][j]

        return result
```

## 复杂度分析

- 时间复杂度：O(m * k * n)（最坏），O(非零元素数量）（稀疏情况）
- 空间复杂度：O(非零元素数量)，存储稀疏表示

## 关键点总结

1. 稀疏矩阵优化：跳过零元素的乘法
2. 两层稀疏存储：对 mat1 按行、mat2 按列存储非零元素
3. 结果矩阵初始化为全零，累加非零乘积

## 易错点

1. 中间维度 `k` 是 mat1 的列数 = mat2 的行数
2. 结果矩阵大小是 `m x n`，不是 `k x k`
3. 稀疏矩阵中，可能同一位置有多个贡献（来自不同中间值 k），需要累加
