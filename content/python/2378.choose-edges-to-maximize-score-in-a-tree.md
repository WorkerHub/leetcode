## 题目描述

给你一棵 `n` 个节点的无向树，节点编号从 `0` 到 `n-1`，`0` 为根节点。`edges[i] = [parent_i, child_i, weight_i]` 表示从 parent_i 到 child_i 的有向边，权重为 weight_i。

从每个节点的子边中**最多**选取**一条**，选取的边集合需满足：每条路径上最多包含一条选中的边。

返回选中边权重之和的**最大值**。

**注意：** 每个非根节点有且仅有一个父节点，根节点没有父节点。

**提示：**
- `n == edges.length + 1`
- `2 <= n <= 10^5`
- `edges[i].length == 3`
- `0 <= parent_i < n`
- `0 <= weight_i <= 10^6`

## 解题思路

**树形 DP：**

对每个节点 `v`，定义：
- `dp[v][0]`：以 v 为根的子树中，不选 v 与其父节点之间的边时的最大分数。
- `dp[v][1]`：以 v 为根的子树中，选 v 与其父节点之间的边时的最大分数（此时 v 的所有子边都不能选）。

对 v 的每个子节点 `u`（边权为 w）：
- 不选 `(v, u)` 边：子树贡献为 `max(dp[u][0], dp[u][1])`（u 可以选与其父的边也可以不选，但那是 u 与它的子的关系，这里 v 是 u 的父）。

等等，让我重新分析：

实际上选取的边集合要满足"每条路径上最多包含一条选中的边"，等价于不能选父子都在同一条路径上的两条边。

更准确地说：对每个节点，**最多**选**一条**它的某条子边，且选了某条子边后，该子节点就不能再选它的子边（否则形成了路径上两条边）。

重新定义：
- `dp[v]`：以 v 为根的子树中，如果不选 v 与其父的边，最大分数。

对每个子节点 `u`（边权 w）：
- 选 `(v, u)`：贡献 w + `pure_dp[u]`（u 的子树中 u 不能再选其子边）。
- 不选 `(v, u)`：贡献 `dp[u]`。

## 代码实现

### 方法一：树形 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxScore(self, edges: List[List[int]]) -> int:
        n = len(edges) + 1
        children = defaultdict(list)  # parent -> [(child, weight)]
        
        for parent, child, weight in edges:
            children[parent].append((child, weight))
        
        # dp(v) 返回 (不选(父,v)的最大分数, 选(父,v)时v子树内的最大分数)
        # 但选(父,v)意味着v不能选任何子边
        def dfs(v):
            # 不选 v 连接父节点的情况：v 可以选一条子边
            # 返回 (不选父边时的最优, 选父边时v子树的最优)
            
            # 选父边：v 不能选子边，贡献 = sum(dp(u)[0] for u in children(v))
            # 但 dp(u)[0] 表示 u 不被父边选中时 u 子树的最优
            
            # 不选父边：v 可以从子边中选一条最优的
            # 额外增益 = max over (child u, weight w): w + dp(u)[no_parent] - dp(u)[no_parent] + dp(u)[with_parent]
            # = max(w + dp(u)[1] for (u,w) in children)
            
            base = 0  # 不选任何子边，所有子树的最优和
            best_gain = 0  # 额外选一条子边的最大收益
            
            for u, w in children[v]:
                no_sel, with_sel = dfs(u)
                base += no_sel
                gain = w + with_sel - no_sel  # 选 (v,u) 边的额外收益
                best_gain = max(best_gain, gain)
            
            # 不选父边：可以选一条子边
            not_selected = base + best_gain
            # 选父边：v 不选任何子边，贡献为 base（每个子树选其最优）
            selected = base
            
            return (not_selected, selected)
        
        result, _ = dfs(0)
        return result
```

### 方法二：迭代 DFS（防止递归深度问题）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxScore(self, edges: List[List[int]]) -> int:
        n = len(edges) + 1
        children = defaultdict(list)
        for parent, child, weight in edges:
            children[parent].append((child, weight))
        
        # 用 BFS 得到遍历顺序，然后逆序处理（从叶子到根）
        order = []
        stack = [0]
        parent_of = [-1] * n
        while stack:
            v = stack.pop()
            order.append(v)
            for u, w in children[v]:
                stack.append(u)
        
        dp = [[0, 0] for _ in range(n)]  # [不选父边, 选父边]
        
        for v in reversed(order):
            base = 0
            best_gain = 0
            for u, w in children[v]:
                base += dp[u][0]
                gain = w + dp[u][1] - dp[u][0]
                best_gain = max(best_gain, gain)
            dp[v][0] = base + best_gain
            dp[v][1] = base
        
        return dp[0][0]
```

## 关键点总结

1. 每个节点最多选一条连向子节点的边（不是父节点方向）。
2. 选了某条子边后，该子节点不能再选连向其子节点的边。
3. DP 状态区分"是否被父边选中"，分别计算最优分数。

## 易错点

- 区分"不选父边"和"选父边"：选父边时该节点无法选子边。
- `gain = w + dp[u][1] - dp[u][0]`：选 (v,u) 边比不选多出的收益（需 > 0 才值得选）。
