## 题目描述

本题是交互题。

给定一个整数数组 `nums`（只能通过 API 访问），其中相同值的元素聚集在一起（即数组分成若干块，每块内元素相同）。你需要返回这样的块（连续相同元素的段）的数量。

你可以访问的 API：
- `nums.length`：数组长度
- `nums[i]`：访问第 i 个元素

目标：用尽量少的访问次数（O(n) 最坏，但期望 O(k log n)，k 为块数）。

**示例：**
```
nums = [3,3,3,3,1,1,1,2,2]
输出：3（有三块：[3,3,3,3], [1,1,1], [2,2]）
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`
- 相同值的元素相邻（同一块内所有元素相同）

## 解题思路

利用二分查找跳过整个块：
- 从当前块的起始位置 start，读取 nums[start]
- 用二分查找找到该块的结束位置（最后一个等于 nums[start] 的位置）
- 跳到下一块，块数 +1

二分查找：在 [start, n-1] 中找最后一个等于 nums[start] 的位置。

## Python 代码实现

### 方法一：二分查找跳块（推荐）

```python
from typing import List

class Solution:
    def countBlocks(self, nums: List[int]) -> int:
        n = len(nums)
        count = 0
        start = 0

        while start < n:
            count += 1
            target = nums[start]
            # 二分查找该块的结束位置
            lo, hi = start, n - 1
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if nums[mid] == target:
                    lo = mid
                else:
                    hi = mid - 1
            # lo 是该块最后一个位置
            start = lo + 1

        return count
```

### 方法二：线性扫描（简单版）

```python
from typing import List

class Solution:
    def countBlocks(self, nums: List[int]) -> int:
        if not nums:
            return 0
        count = 1
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O(k log n)，k 为块数，每块二分查找
- 空间复杂度：O(1)

## 关键点总结

1. 每个块内所有元素相同，可以用二分查找快速跳过整块
2. 二分找"最右等于 target"：用 `lo = mid` 的写法（上取整防死循环）
3. 交互题中用二分减少 API 访问次数是关键优化

## 易错点

1. 二分查找找最右位置时，mid 要上取整：`mid = (lo + hi + 1) // 2`，否则 lo == hi-1 时死循环
2. 每次 start 移动到 `lo + 1`（下一块起始）
3. 线性扫描方法 O(n) 但 API 访问多，交互题中更推荐二分
