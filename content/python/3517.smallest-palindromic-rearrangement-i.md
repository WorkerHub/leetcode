## 题目描述

给定一个回文字符串 `s`，通过重排其字符使其仍为回文，且字典序最小。返回这个最小字典序的回文串。

**示例 1：**

```
输入：s = "eggegg"
输出："eggge"... 实际上返回最小字典序回文
```

**示例 2：**

```
输入：s = "letelt"
输出："lettel"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 是回文字符串
- `s` 只含小写字母

## 解题思路

由于输入保证是回文串，重排时需要保持回文性质并使字典序最小。

步骤：
1. 统计每个字符的出现次数
2. 对于回文串，每个字符（除中间字符外）成对出现
3. 将出现次数为偶数的字符对按字典序排列放在前半部分
4. 奇数个的字符放在中间（最多一个）
5. 前半部分按字典序排序，后半部分是前半部分的镜像

## Python 代码实现

### 方法一：字符计数 + 排序构建（推荐）

```python
from collections import Counter

class Solution:
    def smallestPalindrome(self, s: str) -> str:
        cnt = Counter(s)

        # 前半部分字符
        half = []
        middle = ''

        for c in sorted(cnt.keys()):
            # 每对字符放一个在前半
            pairs = cnt[c] // 2
            half.extend([c] * pairs)
            if cnt[c] % 2 == 1:
                middle = c  # 奇数个，中间字符

        # 构建回文：前半 + 中间 + 后半（前半的反转）
        half_str = ''.join(half)
        return half_str + middle + half_str[::-1]
```

### 方法二：排序后直接构建

```python
from collections import Counter

class Solution:
    def smallestPalindrome(self, s: str) -> str:
        n = len(s)
        cnt = Counter(s)

        # 构建前半部分字符列表（按字典序）
        chars = []
        odd_char = ''
        for c in 'abcdefghijklmnopqrstuvwxyz':
            if c in cnt:
                pairs = cnt[c] // 2
                chars.extend([c] * pairs)
                if cnt[c] % 2 == 1:
                    odd_char = c

        half = ''.join(chars)
        return half + odd_char + half[::-1]
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26) = O(n)，统计字符 + 排序（字符集大小固定为 26）
- 空间复杂度：O(n)，存储结果

## 关键点总结

1. 回文串中每个字符出现次数：偶数个字符对称放置，至多一个奇数个字符放中间
2. 字典序最小：前半部分按字典序排列（a < b < ... < z）
3. 直接从字母 a 到 z 遍历，保证字典序最小

## 易错点

1. 只有一个字符可以放在中间（回文串最多一个奇数频率字符）
2. 后半部分是前半部分的精确镜像
3. 长度为奇数时必有中间字符，长度为偶数时中间字符为空
