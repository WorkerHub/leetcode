## 题目描述

Alice 和 Bob 轮流从石子堆中取石子，Alice 先手。每次可以从**任意一个**非空石子堆中取**至少一颗**石子（取多少不限）。取走**最后一颗**石子的人**获胜**。

给你一个整数数组 `piles`，其中 `piles[i]` 表示第 `i` 堆石子的数量。

若 Alice 在双方都采取**最优策略**的情况下能赢，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：piles = [1]
输出：true
解释：Alice 取走唯一一堆，获胜
```

**示例 2：**
```
输入：piles = [1, 1]
输出：false
解释：Alice 取一堆，Bob 取另一堆，Bob 获胜
```

**示例 3：**
```
输入：piles = [1, 2, 3]
输出：false
解释：1 XOR 2 XOR 3 = 0，Alice 必败
```

**提示：**
- `1 <= piles.length <= 7`
- `1 <= piles[i] <= 7`

---

## 解题思路

### 核心思想：Nim 游戏定理（Sprague-Grundy 定理）

这是经典的 **Nim 游戏**问题。结论如下：

- 若所有堆的石子数**异或（XOR）和为 0**，先手**必败**
- 若所有堆的石子数**异或和不为 0**，先手**必胜**

**证明思路：**
1. 终态（所有堆为 0）异或和为 0，此时先手无法行动（刚才取了最后一颗的人是赢家），即异或和为 0 的状态是必败态
2. 从异或和不为 0 的状态出发，**总能**一步转移到异或和为 0 的状态（先手有必胜策略）
3. 从异或和为 0 的状态出发，**任意**一步都会转移到异或和不为 0 的状态（先手无法保持异或和为 0）

## 代码实现

### 方法一：异或运算（推荐）

```python
from typing import List
from functools import reduce
import operator

class Solution:
    def nimGame(self, piles: List[int]) -> bool:
        # 计算所有堆的异或和
        xor_sum = 0
        for p in piles:
            xor_sum ^= p
        # 异或和不为 0 则先手必胜
        return xor_sum != 0
```

### 方法二：使用 functools.reduce（Python 风格）

```python
from typing import List
from functools import reduce
import operator

class Solution:
    def nimGame(self, piles: List[int]) -> bool:
        # 使用 reduce 和 XOR 运算符计算所有元素的异或
        return reduce(operator.xor, piles) != 0
```

### 方法三：记忆化搜索（验证定理，对比学习）

```python
from typing import List, Tuple

class Solution:
    def nimGame(self, piles: List[int]) -> bool:
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def can_win(state: Tuple[int, ...]) -> bool:
            # 若所有堆为空，当前玩家无法行动，已经输了
            if all(x == 0 for x in state):
                return False
            lst = list(state)
            # 尝试所有可能的取法
            for i in range(len(lst)):
                if lst[i] > 0:
                    for take in range(1, lst[i] + 1):
                        lst[i] -= take
                        new_state = tuple(sorted(lst))
                        if not can_win(new_state):
                            lst[i] += take
                            return True
                        lst[i] += take
            return False

        return can_win(tuple(sorted(piles)))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（异或） | O(n) | O(1) |
| 方法二（reduce） | O(n) | O(1) |
| 方法三（搜索，对比） | 指数级 | 指数级 |

## 关键点总结

1. Nim 游戏的胜负由所有堆异或和决定
2. 异或和 ≠ 0 → 先手必胜；异或和 = 0 → 先手必败
3. 这是 Sprague-Grundy 定理的基础应用
4. Python 中可用 `reduce(operator.xor, piles)` 一行实现

---

## 易错点

- 注意题目说的是"取走最后一颗石子的人获胜"（不是 Misère Nim）
- Misère Nim（取最后一颗输）的策略与普通 Nim 不同
- 本题中 piles 规模较小，暴力搜索也可以通过，但 O(n) 解法更优雅
