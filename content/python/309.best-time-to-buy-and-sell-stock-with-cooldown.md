## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

- 卖出股票后，你无法在第二天买入股票 (即冷冻期为 1 天)。

**注意：**你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**
```
输入: prices = [1,2,3,0,2]
输出: 3 
解释: 对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]
```

**示例 2：**
```
输入: prices = [1]
输出: 0
```

**提示：**
- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`

## 解题思路

这是经典的**股票买卖系列**问题，加入了**冷冻期**的限制。

### 状态定义

定义三种状态：
1. **持有股票**（`hold`）：手上有股票
2. **不持有股票且不在冷冻期**（`sold`）：可以买入
3. **冷冻期**（`rest`）：刚卖出股票，不能买入

### 状态转移

对于第 `i` 天：

**持有股票**：
- 前一天就持有：`hold[i-1]`
- 今天买入：`sold[i-1] - prices[i]`（只能从非冷冻期买入）
- `hold[i] = max(hold[i-1], sold[i-1] - prices[i])`

**冷冻期**：
- 今天卖出：`hold[i-1] + prices[i]`
- `rest[i] = hold[i-1] + prices[i]`

**不持有且不在冷冻期**：
- 前一天就是这个状态：`sold[i-1]`
- 前一天是冷冻期：`rest[i-1]`
- `sold[i] = max(sold[i-1], rest[i-1])`

### 简化版本

实际上可以简化为两个状态：
- `dp[i][0]`：第 `i` 天不持有股票的最大利润
- `dp[i][1]`：第 `i` 天持有股票的最大利润

## Python 代码实现

### 方法一：三状态 DP（推荐）⭐

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
        
        n = len(prices)
        
        # 三种状态
        # hold: 持有股票
        # sold: 不持有股票且不在冷冻期
        # rest: 冷冻期
        hold = [0] * n
        sold = [0] * n
        rest = [0] * n
        
        # 初始状态
        hold[0] = -prices[0]  # 第 0 天买入
        sold[0] = 0           # 第 0 天不操作
        rest[0] = 0           # 第 0 天不可能在冷冻期
        
        for i in range(1, n):
            # 持有股票 = max(继续持有, 从非冷冻期买入)
            hold[i] = max(hold[i-1], sold[i-1] - prices[i])
            
            # 冷冻期 = 今天卖出
            rest[i] = hold[i-1] + prices[i]
            
            # 不持有且不在冷冻期 = max(继续不持有, 冷冻期结束)
            sold[i] = max(sold[i-1], rest[i-1])
        
        # 最后一天不持有股票的最大利润
        return max(sold[n-1], rest[n-1])
```

### 方法二：二状态 DP

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
        
        n = len(prices)
        
        # dp[i][0]: 第 i 天不持有股票的最大利润
        # dp[i][1]: 第 i 天持有股票的最大利润
        dp = [[0, 0] for _ in range(n)]
        
        # 初始状态
        dp[0][0] = 0
        dp[0][1] = -prices[0]
        
        for i in range(1, n):
            # 不持有股票 = max(前一天就不持有, 今天卖出)
            # 注意：卖出后要从 i-2 天转移（因为有冷冻期）
            if i >= 2:
                dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            else:
                dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            
            # 持有股票 = max(前一天就持有, 今天买入)
            # 注意：买入要从 i-2 天转移（因为 i-1 天可能是冷冻期）
            if i >= 2:
                dp[i][1] = max(dp[i-1][1], dp[i-2][0] - prices[i])
            else:
                dp[i][1] = max(dp[i-1][1], -prices[i])
        
        return dp[n-1][0]
```

### 方法三：空间优化

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
        
        # 三个变量表示三种状态
        hold = -prices[0]  # 持有股票
        sold = 0           # 不持有且不在冷冻期
        rest = 0           # 冷冻期
        
        for i in range(1, len(prices)):
            # 注意：更新顺序很重要，要用临时变量保存
            prev_hold = hold
            prev_sold = sold
            prev_rest = rest
            
            hold = max(prev_hold, prev_sold - prices[i])
            rest = prev_hold + prices[i]
            sold = max(prev_sold, prev_rest)
        
        # 最后一天不持有股票
        return max(sold, rest)
```

### 方法四：带详细注释的版本

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        """
        动态规划 + 状态机
        
        状态转移图：
        
        sold (不持有，非冷冻期)
          ↓ 买入
        hold (持有股票)
          ↓ 卖出
        rest (冷冻期)
          ↓ 一天后
        sold (不持有，非冷冻期)
        """
        if not prices:
            return 0
        
        n = len(prices)
        
        # 定义三种状态
        hold = -prices[0]  # 持有股票的最大利润
        sold = 0           # 不持有且不在冷冻期的最大利润
        rest = 0           # 冷冻期的最大利润
        
        for i in range(1, n):
            # 保存前一天的状态（因为要同时更新）
            prev_hold = hold
            prev_sold = sold
            
            # 更新三种状态
            
            # 1. 持有股票的最大利润
            #    要么前一天就持有，要么今天从非冷冻期买入
            hold = max(prev_hold, prev_sold - prices[i])
            
            # 2. 冷冻期的最大利润
            #    必须是今天卖出
            rest = prev_hold + prices[i]
            
            # 3. 不持有且不在冷冻期的最大利润
            #    要么前一天就是这个状态，要么前一天是冷冻期
            sold = max(prev_sold, rest)
        
        # 最后一天肯定是不持有股票的状态更优
        # 可能在冷冻期，也可能不在
        return max(sold, rest)
```

### 方法五：通用模板

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        """
        通用的股票问题 DP 模板
        """
        if not prices:
            return 0
        
        n = len(prices)
        
        # dp[i][0]: 第 i 天不持有股票
        # dp[i][1]: 第 i 天持有股票
        dp = [[0, 0] for _ in range(n)]
        
        dp[0][0] = 0
        dp[0][1] = -prices[0]
        
        for i in range(1, n):
            # 不持有 = max(前一天不持有, 今天卖出)
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            
            # 持有 = max(前一天持有, 今天买入)
            # 关键：买入时要考虑冷冻期，从 i-2 天转移
            if i >= 2:
                dp[i][1] = max(dp[i-1][1], dp[i-2][0] - prices[i])
            else:
                dp[i][1] = max(dp[i-1][1], dp[0][0] - prices[i])
        
        return dp[n-1][0]
```

## 复杂度分析

- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(1)，只用常数个变量（优化后）

## 关键点总结

1. **状态定义**：区分持有、不持有、冷冻期三种状态
2. **状态转移**：
   - 买入：只能从非冷冻期买入
   - 卖出：进入冷冻期
   - 冷冻期：一天后变为非冷冻期
3. **初始化**：第 0 天只有买入或不操作两种选择
4. **最终答案**：`max(sold, rest)`，最后一天不持有股票
5. **空间优化**：只需要前一天的状态，可以用变量代替数组

## 易错点

1. **状态转移顺序**：更新状态时要用临时变量保存前一天的值
2. **买入时机**：只能从非冷冻期买入，不能从冷冻期买入
3. **初始化**：`hold[0] = -prices[0]`，不是 0
4. **最终答案**：可能在冷冻期，也可能不在，取最大值
5. **边界处理**：`i >= 2` 时才能从 `dp[i-2]` 转移
