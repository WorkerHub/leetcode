## 题目描述

给定一个字符串数组 `queries` 和一个字符串 `pattern`，返回一个布尔数组 `answer`，其中 `answer[i]` 表示 `queries[i]` 是否与 `pattern` 匹配。

一个查询词 `queries[i]` 与 `pattern` 匹配，当且仅当你可以在 `pattern` 中插入小写英文字母，使其等于 `queries[i]`。你可以在 `pattern` 的任意位置插入字符，也可以选择不插入任何字符。

**示例 1：**

```
输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FB"
输出：[true,false,true,true,false]
解释：
"FooBar" 可以这样生成："F" + "oo" + "B" + "ar"。
"FootBall" 可以这样生成："F" + "oot" + "B" + "all"。
"FrameBuffer" 可以这样生成："F" + "rame" + "B" + "uffer"。
```

**示例 2：**

```
输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FoBa"
输出：[true,false,true,false,false]
解释：
"FooBar" 可以这样生成："Fo" + "o" + "Ba" + "r"。
"FootBall" 可以这样生成："Fo" + "ot" + "Ba" + "ll"。
```

**示例 3：**

```
输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FoBaT"
输出：[false,true,false,false,false]
解释：
"FooBarTest" 可以这样生成："Fo" + "o" + "Ba" + "r" + "T" + "est"。
```

**提示：**

- `1 <= pattern.length, queries.length <= 100`
- `1 <= queries[i].length <= 100`
- `queries[i]` 和 `pattern` 由英文字母组成

## 解题思路

这道题的核心是理解匹配规则：

1. **关键约束**：
   - `pattern` 中的所有字符必须按顺序出现在 `query` 中
   - `pattern` 中的大写字母在 `query` 中对应位置必须是大写字母
   - `query` 中可以有额外的小写字母（这些是"插入"的字母）
   - `query` 中不能有 `pattern` 中不存在的大写字母

2. **双指针思路**：
   - 使用两个指针 `i` 和 `j` 分别遍历 `query` 和 `pattern`
   - 如果当前字符匹配，两个指针都前进
   - 如果不匹配：
     - 若 `query[i]` 是小写字母，说明是插入的字符，`i` 前进
     - 若 `query[i]` 是大写字母，说明出现了多余的大写字母，匹配失败
   - 最后检查 `pattern` 是否完全匹配（`j` 到达末尾）且 `query` 剩余部分没有大写字母

3. **算法流程**：
   - 对于每个 `query`，使用双指针进行匹配
   - 遍历 `query` 的每个字符：
     - 如果与 `pattern` 当前字符相同，`pattern` 指针前进
     - 如果是大写字母但不匹配，返回 `False`
     - 如果是小写字母但不匹配，继续（这是允许的插入字符）
   - 检查 `pattern` 是否完全匹配完

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def camelMatch(self, queries: List[str], pattern: str) -> List[bool]:
        """
        使用双指针匹配每个查询字符串
        时间复杂度：O(n * m)，n 为 queries 长度，m 为单个 query 平均长度
        空间复杂度：O(1)，不计结果数组
        """
        def is_match(query: str, pattern: str) -> bool:
            """判断单个查询字符串是否匹配模式"""
            j = 0  # pattern 的指针
            
            for i in range(len(query)):
                # 如果当前字符与 pattern 匹配
                if j < len(pattern) and query[i] == pattern[j]:
                    j += 1
                # 如果是大写字母但不匹配，直接失败
                elif query[i].isupper():
                    return False
                # 如果是小写字母但不匹配，继续（允许插入的小写字母）
            
            # 检查 pattern 是否完全匹配
            return j == len(pattern)
        
        # 对每个查询字符串进行匹配
        return [is_match(query, pattern) for query in queries]
```

### 方法二：双指针优化版（更清晰的逻辑）

```python
from typing import List

class Solution:
    def camelMatch(self, queries: List[str], pattern: str) -> List[bool]:
        """
        优化版双指针，逻辑更清晰
        """
        def is_match(query: str, pattern: str) -> bool:
            i, j = 0, 0  # query 和 pattern 的指针
            
            while i < len(query):
                # 情况1：字符匹配
                if j < len(pattern) and query[i] == pattern[j]:
                    i += 1
                    j += 1
                # 情况2：query 中的小写字母（允许的插入）
                elif query[i].islower():
                    i += 1
                # 情况3：query 中的大写字母但不匹配（不允许）
                else:
                    return False
            
            # pattern 必须完全匹配
            return j == len(pattern)
        
        return [is_match(q, pattern) for q in queries]
```

### 方法三：正则表达式（Python 特色）

```python
from typing import List
import re

class Solution:
    def camelMatch(self, queries: List[str], pattern: str) -> List[bool]:
        """
        使用正则表达式进行匹配
        将 pattern 转换为正则表达式：在每个字符之间插入 [a-z]*
        """
        # 构建正则表达式
        # 例如：pattern = "FB" -> regex = "^[a-z]*F[a-z]*B[a-z]*$"
        regex = "^[a-z]*" + "[a-z]*".join(pattern) + "[a-z]*$"
        compiled = re.compile(regex)
        
        return [bool(compiled.match(query)) for query in queries]
```

### 方法四：递归解法

```python
from typing import List

class Solution:
    def camelMatch(self, queries: List[str], pattern: str) -> List[bool]:
        """
        递归方法：尝试匹配每个字符
        """
        def match(query: str, pattern: str, i: int, j: int) -> bool:
            """
            递归匹配函数
            i: query 当前位置
            j: pattern 当前位置
            """
            # 基础情况：pattern 匹配完成
            if j == len(pattern):
                # 检查 query 剩余部分是否只有小写字母
                return all(c.islower() for c in query[i:])
            
            # query 已结束但 pattern 未匹配完
            if i == len(query):
                return False
            
            # 字符匹配
            if query[i] == pattern[j]:
                return match(query, pattern, i + 1, j + 1)
            # query 当前是小写字母（可跳过）
            elif query[i].islower():
                return match(query, pattern, i + 1, j)
            # query 当前是不匹配的大写字母
            else:
                return False
        
        return [match(q, pattern, 0, 0) for q in queries]
```

## 复杂度分析

**方法一/二（双指针）：**
- 时间复杂度：O(n × m)，其中 n 是 `queries` 的长度，m 是单个 `query` 的平均长度。需要遍历每个查询字符串。
- 空间复杂度：O(1)，只使用常数额外空间（不计结果数组）。

**方法三（正则表达式）：**
- 时间复杂度：O(p + n × m)，其中 p 是构建正则表达式的时间，n 是 `queries` 长度，m 是匹配时间。
- 空间复杂度：O(p)，存储编译后的正则表达式。

**方法四（递归）：**
- 时间复杂度：O(n × m)，每个查询字符串最多递归 m 次。
- 空间复杂度：O(m)，递归调用栈的深度最多为查询字符串的长度。

## 关键点总结

1. **匹配规则理解**：允许插入小写字母，但不允许额外的大写字母。
2. **双指针技巧**：一个指针遍历 `query`，另一个指针跟踪 `pattern` 的匹配进度。
3. **大小写判断**：遇到不匹配的大写字母直接返回失败，小写字母可以跳过。
4. **完整性检查**：确保 `pattern` 完全匹配，且 `query` 剩余部分无多余大写字母。
5. **Python 特性**：可以使用正则表达式简化代码，但双指针更高效。

## 易错点

1. **忘记检查 pattern 是否完全匹配**：
   ```python
   # 错误：只检查了 query 遍历完，没检查 pattern
   return True  # 应该是 return j == len(pattern)
   ```

2. **处理剩余字符**：
   ```python
   # query 遍历完后，pattern 也必须遍历完
   # 错误示例：pattern = "FB", query = "F" 应返回 False
   ```

3. **大小写判断错误**：
   ```python
   # 错误：没有区分大小写
   if query[i] != pattern[j]:  # 应该进一步判断是否为大写
   ```

4. **正则表达式边界**：
   ```python
   # 必须使用 ^ 和 $ 确保完整匹配
   regex = "^[a-z]*" + "[a-z]*".join(pattern) + "[a-z]*$"
   ```

5. **空字符串处理**：
   ```python
   # pattern 为空时，query 只能包含小写字母
   if not pattern:
       return all(c.islower() for c in query)
   ```
