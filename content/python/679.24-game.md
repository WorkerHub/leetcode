## 题目描述

你有 4 张写有 1 到 9 数字的牌。你需要判断是否能通过 *，/，+，-，(，) 的运算得到 24。

**规则：**
- 除法运算符 / 表示实数除法，而不是整数除法
- 每个运算符对两个数进行运算，每张牌只能使用一次
- 你不必使用所有的牌，但你必须使用至少一张牌
- 你不能把数字连起来使用，例如把 2 和 3 连成 23

**示例 1：**
```
输入：cards = [4, 1, 8, 7]
输出：true
解释：(8-4) * (7-1) = 24
```

**示例 2：**
```
输入：cards = [1, 2, 1, 2]
输出：false
```

**提示：**
- cards.length == 4
- 1 <= cards[i] <= 9

## 解题思路

这是一道经典的回溯搜索题。

**核心思想：**
每次从剩余数字中选择两个，进行四则运算，得到新的数字，然后递归求解。

**搜索空间：**
- 第一次：从4个数中选2个，有C(4,2) = 6种选择，4种运算，共24种
- 第二次：从3个数中选2个，有C(3,2) = 3种选择，4种运算，共12种
- 第三次：从2个数中选2个，有C(2,2) = 1种选择，4种运算，共4种
- 总共：24 × 12 × 4 = 1152 种组合

**算法流程：**
1. 从数组中选择两个数
2. 对这两个数进行四则运算
3. 将结果放回数组，递归求解
4. 如果数组只剩一个数，判断是否等于24

**优化：**
- 加法和乘法满足交换律，可以减少重复计算
- 使用浮点数精度判断

## Python 代码实现

### 方法一：回溯 + 递归（推荐）⭐

```python
from typing import List
from itertools import permutations

class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        TARGET = 24
        EPSILON = 1e-6
        
        def backtrack(nums):
            """判断nums中的数字能否通过运算得到24"""
            n = len(nums)
            
            # 只剩一个数，判断是否为24
            if n == 1:
                return abs(nums[0] - TARGET) < EPSILON
            
            # 选择两个数进行运算
            for i in range(n):
                for j in range(n):
                    if i == j:
                        continue
                    
                    # 剩余的数字
                    remaining = [nums[k] for k in range(n) if k != i and k != j]
                    
                    # 尝试四种运算
                    # 加法
                    if backtrack(remaining + [nums[i] + nums[j]]):
                        return True
                    
                    # 减法（注意顺序）
                    if backtrack(remaining + [nums[i] - nums[j]]):
                        return True
                    
                    # 乘法
                    if backtrack(remaining + [nums[i] * nums[j]]):
                        return True
                    
                    # 除法（避免除以0）
                    if abs(nums[j]) > EPSILON:
                        if backtrack(remaining + [nums[i] / nums[j]]):
                            return True
            
            return False
        
        return backtrack(list(map(float, cards)))
```

### 方法二：优化的回溯

```python
class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        def solve(nums):
            if not nums:
                return False
            
            if len(nums) == 1:
                return abs(nums[0] - 24) < 1e-6
            
            n = len(nums)
            for i in range(n):
                for j in range(n):
                    if i == j:
                        continue
                    
                    a, b = nums[i], nums[j]
                    remaining = [nums[k] for k in range(n) if k != i and k != j]
                    
                    # 加法和乘法有交换律，只计算一次
                    # 但减法和除法没有，需要两个方向都试
                    
                    # 四种运算
                    for result in [a + b, a - b, a * b, a / b if b != 0 else float('inf')]:
                        if solve(remaining + [result]):
                            return True
            
            return False
        
        return solve(list(map(float, cards)))
```

### 方法三：带剪枝的优化

```python
class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        def dfs(nums):
            if len(nums) == 1:
                return abs(nums[0] - 24) < 1e-6
            
            n = len(nums)
            for i in range(n):
                for j in range(i + 1, n):  # 优化：j从i+1开始
                    a, b = nums[i], nums[j]
                    remaining = [nums[k] for k in range(n) if k != i and k != j]
                    
                    # 加法和乘法：交换律
                    for val in [a + b, a * b]:
                        if dfs(remaining + [val]):
                            return True
                    
                    # 减法：两个方向
                    for val in [a - b, b - a]:
                        if dfs(remaining + [val]):
                            return True
                    
                    # 除法：两个方向，避免除0
                    if abs(b) > 1e-6:
                        if dfs(remaining + [a / b]):
                            return True
                    if abs(a) > 1e-6:
                        if dfs(remaining + [b / a]):
                            return True
            
            return False
        
        return dfs(list(map(float, cards)))
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(1)，虽然看起来复杂，但输入固定为4个数，搜索空间有限
- 空间复杂度：O(1)，递归深度固定为3

实际计算量约为 9216 次操作（考虑所有可能）。

## 关键点总结

1. **回溯思想**：每次选两个数运算，递归处理剩余数字
2. **浮点精度**：使用epsilon判断是否等于24
3. **除法处理**：要检查除数是否为0
4. **交换律优化**：加法和乘法可以减少重复
5. **终止条件**：只剩一个数时判断是否为24

## 易错点

1. **浮点比较**：不能直接用 ==，要用精度判断
2. **除以0**：除法前要检查除数
3. **顺序问题**：减法和除法要考虑两个方向
4. **精度设置**：epsilon不能太大也不能太小
5. **类型转换**：输入要转为float
