## 题目描述

设计并实现一个迭代器来压缩一个字符串，其中重复的字符将被表示为字符后跟重复的次数。

实现 `StringIterator` 类：
- `StringIterator(String compressedString)` 用压缩字符串初始化对象
- `char next()` 返回下一个字符
- `boolean hasNext()` 如果仍有字符返回 true

**示例：**

```
StringIterator iterator = new StringIterator("L1e2t1C1o1d1e1");
iterator.next(); // 返回 'L'
iterator.next(); // 返回 'e'
iterator.next(); // 返回 'e'
iterator.next(); // 返回 't'
iterator.next(); // 返回 'C'
iterator.next(); // 返回 'o'
iterator.next(); // 返回 'd'
iterator.hasNext(); // 返回 true
iterator.next(); // 返回 'e'
iterator.hasNext(); // 返回 false
iterator.next(); // 返回 ' '
```

## Python 代码实现

```python
class StringIterator:
    def __init__(self, compressedString: str):
        self.s = compressedString
        self.ptr = 0
        self.char = ''
        self.count = 0

    def next(self) -> str:
        if not self.hasNext():
            return ' '
        
        if self.count == 0:
            self.char = self.s[self.ptr]
            self.ptr += 1
            num_str = ''
            while self.ptr < len(self.s) and self.s[self.ptr].isdigit():
                num_str += self.s[self.ptr]
                self.ptr += 1
            self.count = int(num_str)
        
        self.count -= 1
        return self.char

    def hasNext(self) -> bool:
        return self.ptr < len(self.s) or self.count > 0
```
