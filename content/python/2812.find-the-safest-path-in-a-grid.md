## 题目描述

给你一个下标从 0 开始、大小为 `n x n` 的二进制矩阵 `grid`，`grid[i][j]` 为 `0` 表示空格，为 `1` 表示有贼。

你要从左上角 `(0, 0)` 走到右下角 `(n-1, n-1)`，只能上下左右移动，不能走到贼的位置。

**安全系数** = 路径上每个格子到最近贼位置的曼哈顿距离的**最小值**。

返回所有路径中安全系数的**最大值**。

**示例 1：**
```
输入：grid = [[1,0,0],[0,0,0],[0,0,1]]
输出：0
解释：(0,0) 和 (n-1,n-1) 处都有贼，安全系数为 0
```

**示例 2：**
```
输入：grid = [[0,0,1],[0,0,0],[0,1,0]]
输出：2
```

**提示：**
- `1 <= n <= 400`
- `grid[i][j]` 为 0 或 1
- `grid` 中至少有一个贼

## 解题思路

**两步策略：**

1. **多源 BFS：** 以所有贼的位置为源点，BFS 计算每个格子到最近贼的距离 `dist[i][j]`

2. **二分答案 + BFS/DFS 验证：**
   - 二分安全系数 `mid`，检查是否存在从 `(0,0)` 到 `(n-1,n-1)` 只经过 `dist >= mid` 的格子的路径
   - 验证用 BFS 或 DFS

**或者使用 Dijkstra / 最大最小路径（类似最大瓶颈路）：**
- 将问题转化为：找从起点到终点的路径，使路径最小安全系数最大
- 用类 Dijkstra 的方法（优先队列，贪心选安全系数最大的方向）

## Python 代码实现

### 方法一：多源 BFS + 二分查找（推荐）

```python
from collections import deque
from typing import List

class Solution:
    def maximumSafenessFactor(self, grid: List[List[int]]) -> int:
        n = len(grid)

        # 多源 BFS：计算每个格子到最近贼的距离
        dist = [[-1] * n for _ in range(n)]
        dq = deque()
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    dist[i][j] = 0
                    dq.append((i, j))

        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        while dq:
            x, y = dq.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    dq.append((nx, ny))

        # 二分查找最大安全系数
        def can_reach(min_safe: int) -> bool:
            """检查是否能以最小安全系数 min_safe 从 (0,0) 到 (n-1,n-1)"""
            if dist[0][0] < min_safe or dist[n-1][n-1] < min_safe:
                return False
            visited = [[False] * n for _ in range(n)]
            dq = deque([(0, 0)])
            visited[0][0] = True
            while dq:
                x, y = dq.popleft()
                if x == n - 1 and y == n - 1:
                    return True
                for dx, dy in dirs:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < n and not visited[nx][ny] and dist[nx][ny] >= min_safe:
                        visited[nx][ny] = True
                        dq.append((nx, ny))
            return False

        lo, hi = 0, max(dist[i][j] for i in range(n) for j in range(n))
        ans = 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_reach(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1

        return ans
```

### 方法二：Dijkstra 最大最小路（类堆贪心）

```python
import heapq
from collections import deque
from typing import List

class Solution:
    def maximumSafenessFactor(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        # 多源 BFS 计算距离
        dist = [[-1] * n for _ in range(n)]
        dq = deque()
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    dist[i][j] = 0
                    dq.append((i, j))

        while dq:
            x, y = dq.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    dq.append((nx, ny))

        # 最大化最小安全系数（类 Dijkstra，最大堆）
        # heap 存 (-safe, x, y)
        heap = [(-dist[0][0], 0, 0)]
        visited = [[False] * n for _ in range(n)]
        visited[0][0] = True

        while heap:
            neg_safe, x, y = heapq.heappop(heap)
            cur_safe = -neg_safe
            if x == n - 1 and y == n - 1:
                return cur_safe
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n and not visited[nx][ny]:
                    visited[nx][ny] = True
                    new_safe = min(cur_safe, dist[nx][ny])
                    heapq.heappush(heap, (-new_safe, nx, ny))

        return -1
```

## 复杂度分析

- 时间复杂度：O(n^2 × log n)，BFS O(n^2)，二分 O(log n)，每次验证 O(n^2)
- 空间复杂度：O(n^2)，距离矩阵和访问数组

## 关键点总结

1. 多源 BFS 是高效计算各格子到贼最近距离的关键
2. 二分答案 + BFS 验证是解决"最大化最小值"问题的经典范式
3. 方法二用最大堆 Dijkstra 直接求最大最小路径

## 易错点

1. 起点或终点本身有贼时安全系数为 0，需处理
2. 二分上界应该是所有距离的最大值，不是 n
3. BFS 验证时要检查起点和终点的距离是否满足条件
