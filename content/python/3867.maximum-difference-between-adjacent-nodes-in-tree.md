## 题目描述

给你一棵有 `n` 个节点的树（以邻接表或边列表形式给出），每个节点有一个值。

返回树中任意一条边两端节点值之差的绝对值的最大值。

**示例 1：**

```
输入：n = 4, edges = [[0,1],[1,2],[2,3]], values = [5, 3, 7, 1]
输出：4
解释：边 (1,2) 两端值为 3 和 7，差为 4，是最大的。
```

**示例 2：**

```
输入：n = 3, edges = [[0,1],[1,2]], values = [1, 10, 2]
输出：9
解释：边 (0,1) 差为 9。
```

**提示：**
- `2 <= n <= 10^5`
- 值在 1 到 10^9 之间

## 解题思路

直接遍历所有边，计算两端节点值之差的绝对值，取最大值。

## Python 代码实现

### 方法一：直接枚举边（推荐）

```python
from typing import List

class Solution:
    def maxDifference(self, n: int, edges: List[List[int]], values: List[int]) -> int:
        ans = 0
        for u, v in edges:
            diff = abs(values[u] - values[v])
            ans = max(ans, diff)
        return ans
```

### 方法二：BFS/DFS（适用于需要遍历树结构的情况）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maxDifference(self, n: int, edges: List[List[int]], values: List[int]) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS 遍历所有边
        visited = [False] * n
        queue = deque([0])
        visited[0] = True
        ans = 0

        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    diff = abs(values[u] - values[v])
                    ans = max(ans, diff)
                    queue.append(v)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有边（树有 n-1 条边）
- 空间复杂度：O(1)（方法一）；O(n)（方法二，BFS 队列）

## 关键点总结

1. 树有 n-1 条边，遍历所有边计算差值即可。
2. 方法一最简洁，直接枚举边列表。
3. 方法二适合只有邻接表没有边列表的情况。

## 易错点

1. 树的边是无向的，每条边计算一次即可（不需要双向计算，因为取绝对值）。
2. 注意节点编号从 0 开始，`values` 数组对应节点编号。
