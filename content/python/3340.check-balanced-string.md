## 题目描述

给你一个由 `0` 到 `9` 组成的数字字符串 `num`。

如果字符串**奇数位置**（1 索引）的数字之和等于**偶数位置**的数字之和，则称该字符串是**平衡的**。

返回 `true` 若字符串是平衡的，否则返回 `false`。

**示例 1：**
```
输入：num = "1234"
输出：false
解释：奇数位（1,3）: 1+3=4，偶数位（2,4）: 2+4=6，不平衡
```

**示例 2：**
```
输入：num = "24123"
输出：true
解释：奇数位（1,3,5）: 2+1+3=6，偶数位（2,4）: 4+2=6，平衡
```

**提示：**
- `2 <= num.length <= 100`
- `num` 只含 '0' 到 '9'

## 解题思路

直接遍历字符串，根据下标奇偶性分别累加，比较两个和是否相等。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
class Solution:
    def isBalanced(self, num: str) -> bool:
        odd_sum = 0   # 奇数位（1 索引）的数字和
        even_sum = 0  # 偶数位（1 索引）的数字和
        
        for i, c in enumerate(num):
            if i % 2 == 0:  # 0 索引的偶数 = 1 索引的奇数
                odd_sum += int(c)
            else:
                even_sum += int(c)
        
        return odd_sum == even_sum
```

### 方法二：切片求和（Python 简洁风格）

```python
class Solution:
    def isBalanced(self, num: str) -> bool:
        # 奇数位（1 索引，0 索引为 0, 2, 4, ...）
        odd_pos_sum = sum(int(c) for c in num[::2])
        # 偶数位（1 索引，0 索引为 1, 3, 5, ...）
        even_pos_sum = sum(int(c) for c in num[1::2])
        return odd_pos_sum == even_pos_sum
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 注意题目中"奇数位"和"偶数位"是 1 索引，对应 Python 0 索引的偶数位和奇数位。
2. 切片 `num[::2]` 取 0, 2, 4, ... 位的字符（1 索引的 1, 3, 5, ... 奇数位）。
3. 两个子集数字和相等则平衡。

## 易错点

1. 1 索引和 0 索引的奇偶对应关系：0 索引的 0, 2, 4 对应 1 索引的奇数位。
2. 字符需要转为整数 `int(c)` 才能求和。
