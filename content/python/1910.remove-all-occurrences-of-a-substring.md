## 题目描述

给你两个字符串 `s` 和 `part`，请你对 `s` 反复执行以下操作直到 `s` 中**不再出现** `part` 子字符串：

- 找到 `s` 中**最左边**的 `part` 子字符串并将其删除

返回删除所有 `part` 子字符串之后的 `s`。

**示例 1：**
```
输入：s = "daabcbaabcbc", part = "abc"
输出："dab"
过程：
"daabcbaabcbc" → 删除 "abc" → "dabaabcbc"
"dabaabcbc" → 删除 "abc" → "dababc"    （注意这里不是删除 dabc）
"dababc" → 删除 "abc" → "dab"
```

**示例 2：**
```
输入：s = "axxxxyyyyb", part = "xy"
输出："ab"
```

**提示：**
- `1 <= s.length <= 1000`
- `1 <= part.length <= 1000`
- `s` 和 `part` 仅由小写英文字母组成

---

## 解题思路

### 方法一：直接字符串操作

反复查找并删除 `part`，直到 `part` 不再出现。

### 方法二：栈模拟（高效）

维护一个栈，逐字符压入。每次压入后，检查栈顶是否以 `part` 结尾：
- 若是，则弹出 `len(part)` 个字符
- 最终栈中的内容就是答案

这样只需一次遍历，时间复杂度 O(n * k)，其中 k 为 `part` 的长度。

---

## 代码实现

### 方法一：字符串循环替换（直观）

```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        # 反复删除最左边的 part，直到不存在
        while part in s:
            # str.replace 默认只替换第一个（count=1）
            s = s.replace(part, '', 1)
        return s
```

### 方法二：栈模拟（推荐，效率更好）

```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        stack = []
        k = len(part)

        for ch in s:
            # 将当前字符压入栈
            stack.append(ch)
            # 检查栈顶 k 个字符是否等于 part
            if len(stack) >= k and ''.join(stack[-k:]) == part:
                # 删除栈顶 k 个字符
                del stack[-k:]

        return ''.join(stack)
```

### 方法三：find 方法 + 切片（对比学习）

```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        # 用 find 找到位置后用切片拼接删除
        idx = s.find(part)
        while idx != -1:
            s = s[:idx] + s[idx + len(part):]
            idx = s.find(part)
        return s
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（replace） | O(n²/k * k) 最坏 O(n²) | O(n) |
| 方法二（栈） | O(n * k) | O(n) |
| 方法三（find+切片） | O(n² / k * k) | O(n) |

n 为 s 长度，k 为 part 长度。

---

## 关键点总结

1. 每次删除后，新的 `part` 可能在删除位置附近出现（由原本不相邻的部分组合而成）
2. 栈方法天然处理这种"拼接后再次出现"的情况
3. 字符串切片/replace 方法简洁，适合 s 长度不大时使用

---

## 易错点

- 使用 `str.replace(part, '')` 时不加 count 参数会替换所有出现，但每次应只删最左边一个（加 `count=1`）
- 栈方法中检查栈顶 k 个字符时，注意先判断栈的长度是否 >= k
