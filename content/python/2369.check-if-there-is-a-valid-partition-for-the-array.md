## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，你需要将其分割成一个或多个连续子数组，每个子数组满足以下条件之一：
1. 子数组**恰好**包含 **2** 个相等元素。
2. 子数组**恰好**包含 **3** 个相等元素。
3. 子数组**恰好**包含 **3** 个连续递增元素（差值为 1）。

若能分割，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：nums = [4,4,4,5,6]
输出：true
解释：分割为 [4,4] 和 [4,5,6]，均满足条件。
```

**示例 2：**
```
输入：nums = [1,1,1,2]
输出：false
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**动态规划：**
定义 `dp[i]` 表示前 `i` 个元素（`nums[0..i-1]`）是否可以被有效分割。

- `dp[0] = True`（空数组）
- 转移：
  - 若 `i >= 2` 且 `nums[i-1] == nums[i-2]`：`dp[i] |= dp[i-2]`（取 2 个相等元素）
  - 若 `i >= 3` 且 `nums[i-1] == nums[i-2] == nums[i-3]`：`dp[i] |= dp[i-3]`（取 3 个相等元素）
  - 若 `i >= 3` 且 `nums[i-1] == nums[i-2] + 1 == nums[i-3] + 2`：`dp[i] |= dp[i-3]`（取 3 个递增元素）

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def validPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        dp = [False] * (n + 1)
        dp[0] = True
        
        for i in range(2, n + 1):
            # 条件 1：最后 2 个元素相等
            if dp[i - 2] and nums[i - 1] == nums[i - 2]:
                dp[i] = True
            
            if i >= 3:
                # 条件 2：最后 3 个元素相等
                if dp[i - 3] and nums[i - 1] == nums[i - 2] == nums[i - 3]:
                    dp[i] = True
                # 条件 3：最后 3 个元素连续递增
                if dp[i - 3] and nums[i - 1] == nums[i - 2] + 1 == nums[i - 3] + 2:
                    dp[i] = True
        
        return dp[n]
```

### 方法二：空间优化（只保留最近 3 个状态）

```python
from typing import List

class Solution:
    def validPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        # dp 只需要最近 3 个状态
        dp = [True, False, False]  # dp[-3], dp[-2], dp[-1] 对应 dp[0], dp[1], dp[2]
        
        # 实际 dp[0] = True，dp[1] = False, dp[2] = ...
        # 用滚动数组：dp[i % 3] 代表 dp[i]
        full_dp = [False] * (n + 1)
        full_dp[0] = True
        
        for i in range(2, n + 1):
            if full_dp[i - 2] and nums[i - 1] == nums[i - 2]:
                full_dp[i] = True
            if i >= 3:
                if full_dp[i - 3] and nums[i - 1] == nums[i - 2] == nums[i - 3]:
                    full_dp[i] = True
                if full_dp[i - 3] and nums[i - 1] - nums[i - 2] == 1 and nums[i - 2] - nums[i - 3] == 1:
                    full_dp[i] = True
        
        return full_dp[n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n) | O(n) |

## 关键点总结

1. DP 状态：前 i 个元素是否可以有效分割。
2. 三种分割方式对应三种状态转移。
3. 连续递增条件：`a+1 == b` 且 `b+1 == c`，即 `c - b == 1` 且 `b - a == 1`。

## 易错点

- 注意 `dp` 数组下标与 `nums` 数组下标的对应关系：`dp[i]` 表示 `nums[0..i-1]`，`nums[i-1]` 是最后一个元素。
- 三种条件可能同时满足，任意一个满足即可（用 `|=`）。
