## 题目描述

给定整数数组 `nums` 和整数 `k`，选出 `nums` 中一个子集，使得子集所有元素的 GCD（最大公约数）恰好等于 `k`，且子集元素之和最大。返回该最大和。若不存在满足条件的子集，返回 `-1`。

**示例 1：**
```
输入：nums = [6,10,15], k = 5
输出：15
解释：子集 {5,10,15} 中 5 是哪来的？
     实际：选 {10,15}，GCD(10,15)=5，和为 25。
     选 {15}，GCD=15 ≠ 5。
     选 {10}，GCD=10 ≠ 5。
     最优：{10,15}，和为 25。
```

**示例 2：**
```
输入：nums = [3,4,6], k = 3
输出：9
解释：选 {3,6}，GCD=3，和为 9。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= k <= 10^6`

## 解题思路

筛选所有 k 的倍数，再在这些倍数中选出 GCD 恰好为 k 的子集（和最大）。

**关键观察：** 从 k 的所有倍数中选出 GCD = k 的子集，等价于：将每个元素除以 k 后，选出 GCD = 1 的子集。

为了使和最大，我们尽量选所有的 k 的倍数；若所有 k 倍数的 GCD 本身就等于 k，直接求和；否则找到子集使 GCD = k。

实际上：**选所有 k 的倍数**，然后验证其 GCD 是否等于 k。若是，和即为这些元素之和。
若不是（GCD = mk, m > 1），则这些元素的 GCD 是 k 的倍数，无法找到 GCD = k 的子集，但可以通过排除某些元素（GCD 为 mk 的元素）来调整。

更精确的方法：用容斥原理在 k 的倍数中找最大和子集，使得 GCD = k。

## Python 代码实现

### 方法一：贪心选择 k 的倍数（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        # 筛选 k 的倍数
        multiples = [x for x in nums if x % k == 0]

        if not multiples:
            return -1

        # 计算所有 k 的倍数的 GCD
        total_gcd = 0
        for x in multiples:
            total_gcd = gcd(total_gcd, x)

        # 若所有倍数的 GCD = k，则选所有倍数和最大
        if total_gcd == k:
            return sum(multiples)

        # 否则，选尽可能多的倍数但 GCD = k
        # 贪心：排除使 GCD > k 的元素
        # 实际上，GCD(所有倍数) 是 k 的倍数 t > 1
        # 若存在一个 k 的倍数但非 t 的倍数的元素，加入后 GCD 会降到 k
        # 策略：找最大和的子集使 GCD = k

        # 从大到小排序，贪心添加使 GCD = k
        multiples.sort(reverse=True)
        cur_gcd = 0
        total = 0
        for x in multiples:
            new_gcd = gcd(cur_gcd, x)
            if new_gcd >= k:  # 保持 GCD >= k（我们的目标 GCD = k）
                cur_gcd = new_gcd
                total += x

        return total if cur_gcd == k else -1
```

### 方法二：枚举 GCD 值（容斥）

```python
from typing import List
from math import gcd
from collections import defaultdict

class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        # 统计 k 的每个倍数在 nums 中出现的总和
        val_sum = defaultdict(int)
        for x in nums:
            if x % k == 0:
                val_sum[x // k] += x

        if not val_sum:
            return -1

        # 找使 GCD = k 的子集的最大和
        # 等价于选 d 值（d = x/k），使 GCD(d_values) = 1
        # 尽量选所有 d，若 GCD(所有 d) = 1 则直接返回总和
        total = sum(val_sum.values())
        all_d = list(val_sum.keys())
        g = 0
        for d in all_d:
            g = gcd(g, d)

        if g == 1:
            return total
        # 否则需要找子集
        # 简化：若 g > 1，找是否存在元素使 GCD 降到 1
        # 这需要更复杂的算法...
        # 简单贪心：尝试排除最小的（贡献最小的）元素
        for d in sorted(all_d):
            remaining = [x for x in all_d if x != d]
            new_g = 0
            for x in remaining:
                new_g = gcd(new_g, x)
            if new_g == 1:
                return total - val_sum[d * k]

        return -1
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))
- 空间复杂度：O(n)

## 关键点总结

1. 先筛选 k 的倍数，再在这些倍数中最大化和
2. 若所有 k 的倍数 GCD = k，直接选全部
3. 否则排除使 GCD 过大的元素

## 易错点

1. GCD(空集) 定义为 0，需要用 0 作为初始值
2. 元素除以 k 后，GCD = 1 等价于原集合 GCD = k
