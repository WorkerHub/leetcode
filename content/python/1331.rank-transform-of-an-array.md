## 题目描述

给你一个整数数组 `arr`，请你将数组中的每个元素替换为它们排序后的序号。

序号代表了一个元素有多大。序号编号规则如下：

- 序号从 1 开始编号。
- 一个元素越大，那么序号越大。如果两个元素相等，那么它们的序号相同。
- 每个数字的序号都应该尽可能地小。

**示例 1：**
```
输入：arr = [40,10,20,30]
输出：[4,1,2,3]
解释：40 是最大的元素，所以序号为 4；10 是最小的元素，序号为 1；以此类推。
```

**示例 2：**
```
输入：arr = [100,100,100]
输出：[1,1,1]
解释：所有元素相等，所以序号都为 1。
```

**示例 3：**
```
输入：arr = [37,12,28,9,100,56,80,5,12]
输出：[5,3,4,2,8,6,7,1,3]
```

**提示：**
- `0 <= arr.length <= 10^5`
- `-10^9 <= arr[i] <= 10^9`

## 解题思路

**算法步骤：**
1. 对数组元素去重并排序，得到从小到大的唯一值列表
2. 建立哈希映射：每个唯一值 -> 其排名（从 1 开始）
3. 遍历原数组，用哈希映射替换每个元素

**关键点：** 相同元素对应相同排名，排名连续（不跳号）。

## Python 代码实现

### 方法一：排序 + 哈希映射（推荐）

```python
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        # 对去重后的元素排序，建立值到排名的映射
        # enumerate 从 1 开始可以直接生成 (rank, value) 对
        rank = {val: i + 1 for i, val in enumerate(sorted(set(arr)))}
        
        # 用映射替换原数组
        return [rank[x] for x in arr]
```

### 方法二：用 bisect 二分查找确定排名

```python
from typing import List
import bisect

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        if not arr:
            return []
        
        # 排好序的唯一值列表
        sorted_unique = sorted(set(arr))
        
        # 二分查找每个元素在排序列表中的位置，即排名
        # bisect_left 返回第一个 >= val 的索引，加 1 转为从 1 开始的排名
        return [bisect.bisect_left(sorted_unique, x) + 1 for x in arr]
```

### 方法三：直接用 sorted + enumerate

```python
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        # 用 sorted 对（值, 原始索引）对进行排序
        # 然后按顺序分配排名
        n = len(arr)
        result = [0] * n
        
        # 按值排序，保留原始索引
        sorted_idx = sorted(range(n), key=lambda i: arr[i])
        
        rank = 1
        for k, idx in enumerate(sorted_idx):
            # 如果与前一个值相同，使用相同排名
            if k > 0 and arr[idx] == arr[sorted_idx[k - 1]]:
                result[idx] = result[sorted_idx[k - 1]]
            else:
                result[idx] = rank
            rank += 1  # 无论是否相同，rank 都递增（但填入的值只有不同时才更新）
        
        # 修正：rank 在相同元素时不应递增
        rank = 1
        for k, idx in enumerate(sorted_idx):
            if k > 0 and arr[idx] == arr[sorted_idx[k - 1]]:
                result[idx] = result[sorted_idx[k - 1]]
            else:
                result[idx] = rank
                rank += 1  # 只有遇到新值时才增加排名
        
        return result
```

### 方法四：简洁 Python 写法（推荐新手理解）

```python
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        # 分步骤写，更易理解
        
        # 第一步：对所有不重复的元素排序
        unique_sorted = sorted(set(arr))
        
        # 第二步：建立值到排名的字典
        rank_map = {}
        for rank, val in enumerate(unique_sorted, start=1):
            rank_map[val] = rank
        
        # 第三步：替换原数组的每个元素
        return [rank_map[x] for x in arr]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/四 | O(n log n) | O(n) |
| 方法二 | O(n log n) | O(n) |
| 方法三 | O(n log n) | O(n) |

- **时间复杂度**：排序 `O(n log n)` 是瓶颈
- **空间复杂度**：哈希映射和结果数组各 `O(n)`

## 关键点总结

1. 核心思路：排序去重 + 建立哈希映射，一次遍历替换
2. `set(arr)` 去重，`sorted()` 排序，`enumerate(start=1)` 从 1 开始编号
3. 相同元素映射到同一排名，排名连续不跳号
4. 方法一是最 Pythonic 的写法，一行字典推导完成映射

## 易错点

1. 忘记去重：直接对 `arr` 排序建映射时，相同元素会被赋予不同排名
2. 排名从 0 还是从 1 开始：题目要求从 1 开始，注意 `enumerate(start=1)` 或 `i + 1`
3. 排名是否连续：去重后再映射可以保证排名连续
