## 题目描述

给你一个正整数数组 `arr`，考虑所有满足以下条件的二叉树：

- 每个节点都有 0 个或 2 个子节点。
- 数组 `arr` 中的值与树的中序遍历中每个叶节点的值一一对应。（知识回顾：如果一个节点有 0 个子节点，那么该节点为叶节点。）
- 每个非叶节点的值等于其左子树和右子树中叶节点的最大值的乘积。

在所有这样的二叉树中，返回每个非叶节点的值的最小可能总和。这个和的值是一个 32 位整数。

**示例 1：**
```
输入：arr = [6,2,4]
输出：32
解释：有两种可能的树，第一种的非叶节点之和为 36，第二种非叶节点之和为 32。

    24            24
   /  \          /  \
  12   4        6    8
 /  \               / \
6    2             2   4
```

**示例 2：**
```
输入：arr = [4,11]
输出：44
```

**提示：**
- `2 <= arr.length <= 40`
- `1 <= arr[i] <= 15`
- 答案保证是一个 32 位有符号整数，即答案 `<= 2^31 - 1`

## 解题思路

这道题看似复杂，但可以简化理解：

### 核心观察

1. **中序遍历性质**：叶子节点的顺序必须与 `arr` 一致
2. **非叶节点的值**：等于左右子树叶子节点的最大值的乘积
3. **最优策略**：每次合并时，应该让较小的数尽快"消失"（被乘掉）

### 贪心思想

为了让总和最小，我们应该：
- 让较小的数尽早与其相邻的较小数相乘
- 避免大数之间相乘

这等价于：每次选择相邻的两个元素，使得它们与各自邻居中较小者的乘积最小。

### 三种解法思路

1. **动态规划**：`dp[i][j]` 表示 `arr[i:j+1]` 构成的最小代价
2. **单调栈**：维护一个单调递减栈，每次弹出时计算代价
3. **贪心**：每次合并最小的相邻对（需要特殊处理）

## Python 代码实现

### 方法一：单调栈（推荐，最优解）

```python
from typing import List

class Solution:
    def mctFromLeafValues(self, arr: List[int]) -> int:
        result = 0
        stack = [float('inf')]  # 哨兵，避免栈空判断
        
        for num in arr:
            # 当栈顶元素小于当前元素时，弹出栈顶
            while stack[-1] <= num:
                mid = stack.pop()
                # mid 会与 stack[-1] 和 num 中较小的那个合并
                result += mid * min(stack[-1], num)
            
            stack.append(num)
        
        # 处理栈中剩余元素
        while len(stack) > 2:
            result += stack.pop() * stack[-1]
        
        return result
```

**解释：**
- 维护一个单调递减栈（从栈底到栈顶递减）
- 当遇到比栈顶大的元素时，栈顶元素必须被合并
- 合并时选择与左右邻居中较小的那个相乘，代价最小

### 方法二：动态规划

```python
from typing import List

class Solution:
    def mctFromLeafValues(self, arr: List[int]) -> int:
        n = len(arr)
        
        # dp[i][j] 表示 arr[i:j+1] 构成树的最小代价
        dp = [[0] * n for _ in range(n)]
        
        # max_val[i][j] 表示 arr[i:j+1] 中的最大值
        max_val = [[0] * n for _ in range(n)]
        
        # 预处理最大值
        for i in range(n):
            max_val[i][i] = arr[i]
            for j in range(i + 1, n):
                max_val[i][j] = max(max_val[i][j-1], arr[j])
        
        # 枚举区间长度
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = float('inf')
                
                # 枚举分割点
                for k in range(i, j):
                    # 左子树：arr[i:k+1]，右子树：arr[k+1:j+1]
                    # 根节点值 = max(左子树) * max(右子树)
                    left_max = max_val[i][k]
                    right_max = max_val[k+1][j]
                    cost = dp[i][k] + dp[k+1][j] + left_max * right_max
                    dp[i][j] = min(dp[i][j], cost)
        
        return dp[0][n-1]
```

### 方法三：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def mctFromLeafValues(self, arr: List[int]) -> int:
        n = len(arr)
        
        @lru_cache(None)
        def dp(i: int, j: int) -> tuple:
            """
            返回 (最小代价, 区间最大值)
            """
            # 只有一个元素，代价为 0
            if i == j:
                return (0, arr[i])
            
            min_cost = float('inf')
            max_leaf = 0
            
            # 枚举分割点
            for k in range(i, j):
                left_cost, left_max = dp(i, k)
                right_cost, right_max = dp(k + 1, j)
                
                # 当前分割的代价
                cost = left_cost + right_cost + left_max * right_max
                min_cost = min(min_cost, cost)
                max_leaf = max(max_leaf, left_max, right_max)
            
            return (min_cost, max_leaf)
        
        return dp(0, n - 1)[0]
```

### 方法四：贪心（易于理解）

```python
from typing import List

class Solution:
    def mctFromLeafValues(self, arr: List[int]) -> int:
        result = 0
        
        # 每次移除最小的叶子节点
        while len(arr) > 1:
            # 找到最小值的索引
            min_idx = arr.index(min(arr))
            
            # 计算与左右邻居的乘积，选择较小的
            if min_idx == 0:
                result += arr[min_idx] * arr[min_idx + 1]
            elif min_idx == len(arr) - 1:
                result += arr[min_idx] * arr[min_idx - 1]
            else:
                result += arr[min_idx] * min(arr[min_idx - 1], arr[min_idx + 1])
            
            # 移除最小值
            arr.pop(min_idx)
        
        return result
```

## 复杂度分析

### 方法一：单调栈

- **时间复杂度**：O(n)，每个元素最多入栈出栈一次
- **空间复杂度**：O(n)，栈的空间

### 方法二、三：动态规划

- **时间复杂度**：O(n³)，三重循环
- **空间复杂度**：O(n²)，DP 数组

### 方法四：贪心

- **时间复杂度**：O(n²)，外层循环 n 次，每次查找最小值 O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **单调栈应用**：维护单调递减栈，当遇到更大元素时弹出并计算代价
2. **贪心策略**：每次让最小的数与其相邻的较小数合并
3. **DP 状态设计**：`dp[i][j]` 表示子数组的最小代价
4. **区间 DP 技巧**：枚举区间长度，再枚举起点和分割点
5. **优化思路**：从 O(n³) 的 DP 优化到 O(n) 的单调栈

## 易错点

1. **单调栈方向**：应该维护递减栈，而非递增栈
2. **哨兵设置**：栈底放 `float('inf')` 避免特殊判断
3. **合并选择**：弹出元素时，应该与左右邻居中较小的那个合并
4. **剩余元素处理**：栈中剩余元素需要按顺序合并
5. **DP 边界**：单个元素时代价为 0，而非叶子节点值

## 图解示例

对于 `arr = [6, 2, 4]`：

**单调栈过程：**
```
初始：stack = [inf]
处理 6：stack = [inf, 6]
处理 2：2 < 6，不弹出，stack = [inf, 6, 2]
处理 4：4 > 2，弹出 2
  - 2 与 min(6, 4) = 4 合并，代价 = 2 * 4 = 8
  - stack = [inf, 6, 4]
剩余：弹出 4，4 * 6 = 24
     弹出 6，6 * inf 不计算
总代价 = 8 + 24 = 32
```
