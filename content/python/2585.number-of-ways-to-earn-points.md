## 题目描述

有一场考试，共 `n` 种题型，第 `i` 种题型有 `count_i` 道题，每道题 `mark_i` 分。你的目标是恰好得 `target` 分。

每种题型的任意数量的题都可以做（最多做 `count_i` 道，分别得 `0, mark_i, 2*mark_i, ..., count_i * mark_i` 分）。

返回恰好得 `target` 分的方案数（对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：types = [[6,1],[3,2],[2,3]], target = 6
输出：7
```

**提示：**

- `1 <= types.length <= 50`
- `1 <= count_i, mark_i <= 50`
- `1 <= target <= 1000`

## 解题思路

**分组背包 DP**：`dp[j]` = 恰好得 j 分的方案数。

对每种题型 (count, mark)，做最多 count 道（多重背包）：
- 内层枚举做 0, 1, 2, ..., count 道该题型的方案

用前缀和优化多重背包：`dp[j] = sum(dp[j - t*mark] for t in range(min(j//mark, count) + 1))`。

## Python 代码实现

### 方法一：分组背包 DP（推荐）

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def waysToReachTarget(self, target: int, types: List[List[int]]) -> int:
        dp = [0] * (target + 1)
        dp[0] = 1  # 0 分有 1 种方案（不做任何题）

        for count, mark in types:
            # 逆序更新（避免重复使用当前题型）
            for j in range(target, -1, -1):
                # 原地累加：做 t 道该题型（t = 1 to min(count, j//mark)）
                # 等价于：new_dp[j] = sum(dp[j - t*mark] for t in range(count+1) if j >= t*mark)
                pass

            # 使用临时数组更新
            new_dp = [0] * (target + 1)
            for j in range(target + 1):
                for t in range(min(count, j // mark) + 1):
                    new_dp[j] = (new_dp[j] + dp[j - t * mark]) % MOD
            dp = new_dp

        return dp[target]
```

### 方法二：前缀和优化

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def waysToReachTarget(self, target: int, types: List[List[int]]) -> int:
        dp = [0] * (target + 1)
        dp[0] = 1

        for count, mark in types:
            new_dp = [0] * (target + 1)
            # 前缀和加速
            prefix = [0] * (target + 2)
            for j in range(target + 1):
                prefix[j + 1] = (prefix[j] + dp[j]) % MOD

            for j in range(target + 1):
                # new_dp[j] = sum(dp[j - t*mark]) for t in [0, min(count, j//mark)]
                # = 间隔为 mark 的前缀和差值
                max_t = min(count, j // mark)
                lo = j - max_t * mark
                # 等差下标的求和需要特殊前缀和，直接枚举
                val = 0
                for t in range(max_t + 1):
                    val = (val + dp[j - t * mark]) % MOD
                new_dp[j] = val

            dp = new_dp

        return dp[target]
```

## 复杂度分析

- 时间复杂度：O(n * target * count_max)，三层循环
- 空间复杂度：O(target)

## 关键点总结

1. 每种题型是独立的"多重背包"（做 0 到 count 道）
2. 对每种题型从头更新 dp 数组（不能原地逆序，因为同一题型不同数量相互独立）
3. 用新数组 new_dp 保证每种题型只用一次

## 易错点

1. 分组背包需要新数组（不能原地更新），否则同种题型会被重复计算
2. `j - t * mark` 必须 >= 0，条件 `t <= j // mark`
3. dp[0] = 1 表示恰好得 0 分有 1 种方案
