## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，它们已经按 **非递减** 顺序排列，请你返回两个数组的 **最小公共整数**。如果不存在公共整数，返回 `-1`。

如果某个整数在两个数组中都至少出现一次，则称为公共整数。

**示例 1：**

```
输入：nums1 = [1,2,3], nums2 = [2,4]
输出：2
```

**示例 2：**

```
输入：nums1 = [1,2,3,6], nums2 = [2,3,4,5]
输出：2
```

**提示：**

- `1 <= nums1.length, nums2.length <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^9`
- 数组按非递减顺序排列

## 解题思路

方法一：利用有序性，用双指针分别扫描两个数组，找到第一个相同的值。

方法二：集合求交集，取最小值。

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def getCommon(self, nums1: List[int], nums2: List[int]) -> int:
        i, j = 0, 0
        while i < len(nums1) and j < len(nums2):
            if nums1[i] == nums2[j]:
                return nums1[i]
            elif nums1[i] < nums2[j]:
                i += 1
            else:
                j += 1
        return -1
```

### 方法二：集合交集

```python
from typing import List

class Solution:
    def getCommon(self, nums1: List[int], nums2: List[int]) -> int:
        common = set(nums1) & set(nums2)
        return min(common) if common else -1
```

## 复杂度分析

- 方法一时间复杂度：O(m + n)，双指针线性扫描
- 方法二时间复杂度：O(m + n)，集合构建和交集
- 空间复杂度：O(1)（方法一），O(m + n)（方法二）

## 关键点总结

1. 双指针利用有序性，每次移动较小值的指针
2. 集合方法代码简洁，但额外空间较多
3. 数组有序，双指针找到的第一个公共值就是最小公共值

## 易错点

1. 注意两指针都要在各自数组范围内，防止越界
2. 找到相等时立即返回，因为数组有序第一个就是最小值
3. 两数组可能有重复元素，但找公共值时只需关注相等的情况
