## 题目描述

给你两个整数数组 `source` 和 `target`，长度都是 `n`。还有一个数组 `allowedSwaps`，其中每个 `allowedSwaps[i] = [ai, bi]` 表示你可以交换数组 `source` 中下标为 `ai` 和 `bi`（下标从 0 开始）的两个元素。注意，你可以**按任意顺序**多次交换一对特定下标指向的元素。

对于每个下标 `i`（从 0 到 n - 1），如果 `source[i]` 不等于 `target[i]`，则该下标处的数组 `source` 与 `target` 之间的**汉明距离**为 1。计算并返回 `source` 和 `target` 之间的**最小汉明距离**。

**示例 1：**
```
输入：source = [1,2,3,4], target = [2,1,4,5], allowedSwaps = [[0,1],[2,3]]
输出：1
```

**提示：**
- `n == source.length == target.length`
- `1 <= n <= 10^5`

## 解题思路

使用并查集将 `allowedSwaps` 中连通的下标合并为同一连通分量。在同一分量内，`source` 的元素可以任意排列。

对每个连通分量，统计 `source` 中元素的出现频率，与 `target` 中对应位置匹配，能匹配的就不产生汉明距离。

## 代码实现

### 方法一：并查集（推荐）

```python
from typing import List
from collections import defaultdict, Counter

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px != py:
            self.parent[px] = py

class Solution:
    def minimumHammingDistance(self, source: List[int], target: List[int],
                                allowedSwaps: List[List[int]]) -> int:
        n = len(source)
        uf = UnionFind(n)
        
        # 合并可交换的下标
        for a, b in allowedSwaps:
            uf.union(a, b)
        
        # 按连通分量分组
        groups = defaultdict(list)
        for i in range(n):
            groups[uf.find(i)].append(i)
        
        hamming = 0
        
        for root, indices in groups.items():
            # 统计该分量中 source 的元素频率
            src_count = Counter(source[i] for i in indices)
            
            # 对 target 中对应位置，尝试匹配
            for i in indices:
                t = target[i]
                if src_count[t] > 0:
                    src_count[t] -= 1
                    # 匹配成功，汉明距离 +0
                else:
                    hamming += 1  # 无法匹配，汉明距离 +1
        
        return hamming
```

### 方法二：DFS 版本

```python
from typing import List
from collections import defaultdict, Counter

class Solution:
    def minimumHammingDistance(self, source: List[int], target: List[int],
                                allowedSwaps: List[List[int]]) -> int:
        n = len(source)
        
        # 建立邻接表
        graph = defaultdict(list)
        for a, b in allowedSwaps:
            graph[a].append(b)
            graph[b].append(a)
        
        visited = [False] * n
        hamming = 0
        
        def dfs(node, component):
            visited[node] = True
            component.append(node)
            for neighbor in graph[node]:
                if not visited[neighbor]:
                    dfs(neighbor, component)
        
        for i in range(n):
            if not visited[i]:
                component = []
                dfs(i, component)
                
                # 统计该连通分量中 source 的元素
                src_count = Counter(source[j] for j in component)
                
                for j in component:
                    t = target[j]
                    if src_count[t] > 0:
                        src_count[t] -= 1
                    else:
                        hamming += 1
        
        return hamming
```

## 复杂度分析

- **时间复杂度**：O(n * alpha(n))，并查集近似线性
- **空间复杂度**：O(n)

## 关键点总结

1. 并查集合并可交换的下标，找出所有连通分量
2. 同一分量内 source 可任意排列，用计数匹配来最小化汉明距离
3. 贪心匹配：每个 target 元素先从分量的 source 中找，找到就消耗一个

## 易错点

- 并查集路径压缩避免超时
- 匹配时要消耗 source 中的元素（不能一个 source 元素匹配多个 target）
