## 题目描述

给定两个有序整数数组 `nums1` 和 `nums2`（可能含负数），以及整数 `k`。从 `nums1` 中选一个元素，从 `nums2` 中选一个元素，形成乘积。所有可能的乘积中，返回第 `k` 小的乘积（1-indexed）。

**示例 1：**

```
输入：nums1 = [2,5], nums2 = [3,4], k = 2
输出：8
解释：乘积有 [6,8,15,20]，第 2 小为 8。
```

**示例 2：**

```
输入：nums1 = [-4,-2,0,3], nums2 = [2,4], k = 6
输出：0
解释：乘积排序后第 6 小为 0。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 5 * 10^4`
- `-10^5 <= nums1[i], nums2[i] <= 10^5`
- `1 <= k <= nums1.length * nums2.length`

## 解题思路

二分答案：二分乘积值 `mid`，计算乘积 <= mid 的对数，找到最小的满足 count(<=mid) >= k 的 mid。

对于固定的 `a = nums1[i]`，计算 `a * b <= mid` 中满足条件的 `b` 数量：
- 若 `a > 0`：`b <= mid / a`，用二分找 nums2 中 <= mid/a 的个数
- 若 `a < 0`：`b >= mid / a`（不等号翻转），用二分找 nums2 中 >= mid/a 的个数
- 若 `a == 0`：乘积为 0，若 mid >= 0，贡献 len(nums2)；否则贡献 0

时间复杂度：O((m+n) log(m+n) log(max_val))

## Python 代码实现

### 方法一：二分答案（推荐）

```python
from typing import List
import bisect

class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        def count(mid):
            # 计算乘积 <= mid 的对数
            total = 0
            for a in nums1:
                if a > 0:
                    # a * b <= mid => b <= mid / a
                    threshold = mid / a
                    total += bisect.bisect_right(nums2, threshold)
                elif a < 0:
                    # a * b <= mid => b >= mid / a （注意取上界）
                    threshold = mid / a
                    total += len(nums2) - bisect.bisect_left(nums2, threshold)
                    # 注意浮点精度，用整数除法更安全
                else:
                    # a == 0，乘积为 0
                    if mid >= 0:
                        total += len(nums2)
            return total

        # 二分范围
        lo, hi = -10**10, 10**10
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= k:
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：精确整数二分（避免浮点误差）

```python
from typing import List
import bisect

class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        n2 = len(nums2)

        def count_leq(mid: int) -> int:
            # 统计 nums1[i] * nums2[j] <= mid 的对数
            res = 0
            for a in nums1:
                if a == 0:
                    if mid >= 0:
                        res += n2
                elif a > 0:
                    # b <= mid // a（整数，但要处理向下取整）
                    # 实际上要找 b 使 a*b <= mid，即 b <= mid/a
                    # 用 bisect 在 nums2 中二分
                    # 最大 b 满足 a*b <= mid
                    lo2, hi2 = 0, n2
                    while lo2 < hi2:
                        m2 = (lo2 + hi2) // 2
                        if a * nums2[m2] <= mid:
                            lo2 = m2 + 1
                        else:
                            hi2 = m2
                    res += lo2
                else:
                    # a < 0，a*b <= mid => b >= mid/a（翻转）
                    lo2, hi2 = 0, n2
                    while lo2 < hi2:
                        m2 = (lo2 + hi2) // 2
                        if a * nums2[m2] <= mid:
                            hi2 = m2
                        else:
                            lo2 = m2 + 1
                    res += n2 - lo2
            return res

        lo, hi = -10**10, 10**10
        while lo < hi:
            mid = (lo + hi) // 2
            if count_leq(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(m * log(n) * log(MAX))，m 为 nums1 长度，n 为 nums2 长度
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案，对每个候选值统计乘积 <= 该值的对数
2. 固定 nums1 的元素，在 nums2 中二分寻找满足条件的范围
3. 注意 a 的正负影响不等式方向，a=0 单独处理
4. 二分边界取 [-10^10, 10^10]

## 易错点

1. 浮点除法精度问题，推荐用整数比较避免
2. a < 0 时不等号翻转，二分方向改变
3. a = 0 时乘积始终为 0，根据 mid >= 0 决定是否计入
4. 答案二分用 lo < hi，返回 lo
