## 题目描述

给你一个正整数 `n`。

如果一个整数 `k` 满足以下条件，我们称它是一个 **公平整数**：

- `k` 的数字中，奇数数字的个数等于偶数数字的个数。

返回 **大于等于** `n` 且满足条件的 **最小公平整数**。

**示例 1：**
```
输入：n = 2
输出：10
解释：2 是不公平的（1 个偶数，0 个奇数）。最小的大于等于 2 的公平整数是 10（1 个偶数，1 个奇数）。
```

**示例 2：**
```
输入：n = 403
输出：1100
解释：最小的大于等于 403 的公平整数是 1100（2 个偶数，2 个奇数）。
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

公平整数的位数必须为偶数（因为奇数位数 = 偶数位数，所以总位数必须是偶数）。

**策略：**
1. 如果 n 的位数是偶数，从 n 开始向上搜索公平整数（但可能搜索范围很大）
2. 更优：对于每种偶数位数（2, 4, 6, 8, 10），找该位数下最小的大于等于 n 的公平整数
3. 如果 n 的位数本身是奇数，直接找下一个偶数位数长度的最小公平整数（就是 10^(len)，如 10、1000 等）

**具体思路：**
- 奇数位数：直接向上取到下一个偶数位数（如 n=5位，答案开头用 6 位的最小公平整数）
- 偶数位数：从 n 开始枚举（由于 10^9 最多 10 位，每个偶数位数最多要枚举到下一个偶数位数，可接受）

实际上因为 n 最大 10^9（10 位），直接从 n 开始逐一枚举也很快。

## 代码实现

### 方法一：逐一枚举（简单直接）

```python
class Solution:
    def closestFair(self, n: int) -> int:
        def is_fair(x: int) -> bool:
            """判断 x 是否是公平整数"""
            odd_count = 0
            even_count = 0
            while x > 0:
                digit = x % 10
                if digit % 2 == 0:
                    even_count += 1
                else:
                    odd_count += 1
                x //= 10
            return odd_count == even_count

        # 从 n 开始向上找第一个公平整数
        while not is_fair(n):
            n += 1
        return n
```

### 方法二：数学构造（更高效）

```python
class Solution:
    def closestFair(self, n: int) -> int:
        def count_digits(x: int):
            """统计 x 中奇数位和偶数位的个数"""
            odd, even = 0, 0
            while x:
                d = x % 10
                if d % 2 == 0:
                    even += 1
                else:
                    odd += 1
                x //= 10
            return odd, even

        # 计算 n 的位数
        digits = len(str(n))

        if digits % 2 == 1:
            # 奇数位数，直接返回下一个偶数位数的最小公平整数
            # 如 3 位 -> 4 位最小公平整数 1100（1 奇 1 偶不对）
            # 实际上最小公平整数如 10, 1001, ...
            # 最小偶数位数的公平整数：一半奇一半偶的最小排列
            target_digits = digits + 1
            # target_digits 位的最小公平整数
            # 前 target_digits//2 位放奇数(1开头)，后 target_digits//2 位放偶数(0)
            half = target_digits // 2
            return int('1' * half + '0' * half)
        else:
            # 偶数位数，从 n 开始枚举
            while True:
                odd, even = count_digits(n)
                if odd == even:
                    return n
                n += 1
                # 如果位数增加，跳到下一个偶数位数的最小公平整数
                if len(str(n)) > digits:
                    digits += 2
                    half = digits // 2
                    n = int('1' * half + '0' * half)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 逐一枚举 | O(枚举次数 * log n) | O(1) |
| 数学构造 | O(枚举次数 * log n) | O(1) |

对于 n <= 10^9，枚举次数有限，实际运行很快。

## 关键点总结

1. 公平整数的总位数必须为偶数
2. 若 n 为奇数位数，直接跳到下一个偶数位数的最小公平整数
3. 偶数位数时从 n 开始枚举，直到找到奇偶位数相等的数

## 易错点

- 位数为奇数的数（如 100-999）没有公平整数，需要直接跳到偶数位数
- 注意 0 算偶数
