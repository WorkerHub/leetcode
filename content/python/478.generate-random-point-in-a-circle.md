## 题目描述

给定圆的半径和圆心的位置，实现函数 `randPoint`，在圆中产生均匀随机点。

实现 `Solution` 类：
- `Solution(double radius, double x_center, double y_center)` 用圆的半径 `radius` 和圆心的位置 `(x_center, y_center)` 初始化对象
- `randPoint()` 返回圆内的一个随机点。圆周上的一点被认为在圆内。答案作为数组返回 `[x, y]`。

**示例 1：**
```
输入:
["Solution","randPoint","randPoint","randPoint"]
[[1.0, 0.0, 0.0], [], [], []]
输出: [null, [-0.02493, -0.38077], [0.82314, 0.38945], [0.36572, 0.17248]]
```

**提示：**
- `0 < radius <= 10^8`
- `-10^7 <= x_center, y_center <= 10^7`
- `randPoint` 最多被调用 `3 * 10^4` 次

## 解题思路

**错误方法：** 均匀随机半径和角度
- 这会导致中心点密度更大（极坐标面积不均）

**正确方法：** 拒绝采样或面积加权

### 方法一：拒绝采样
在正方形中随机生成点，拒绝圆外的点。

### 方法二：面积加权
- 半径按 `sqrt(random())` 分布
- 角度均匀分布

## Python 代码实现

### 方法一：拒绝采样（推荐）⭐

```python
import random

class Solution:
    def __init__(self, radius: float, x_center: float, y_center: float):
        self.radius = radius
        self.x_center = x_center
        self.y_center = y_center

    def randPoint(self):
        while True:
            # 在 [-radius, radius] 的正方形中随机生成点
            x = random.uniform(-self.radius, self.radius)
            y = random.uniform(-self.radius, self.radius)
            
            # 检查是否在圆内
            if x * x + y * y <= self.radius * self.radius:
                return [self.x_center + x, self.y_center + y]
```

### 方法二：面积加权（更高效）

```python
import random
import math

class Solution:
    def __init__(self, radius: float, x_center: float, y_center: float):
        self.radius = radius
        self.x_center = x_center
        self.y_center = y_center

    def randPoint(self):
        # 半径按面积加权
        r = self.radius * math.sqrt(random.random())
        
        # 角度均匀分布
        theta = random.uniform(0, 2 * math.pi)
        
        # 转换为笛卡尔坐标
        x = r * math.cos(theta)
        y = r * math.sin(theta)
        
        return [self.x_center + x, self.y_center + y]
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(1) 期望，拒绝概率 ≈ 21%
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. **拒绝采样：** 简单但有拒绝开销
2. **面积加权：** `r = R * sqrt(random())`
3. **角度均匀：** `theta = 2π * random()`

## 易错点

1. **半径均匀：** 错误，应该是 `sqrt(random())`
