## 题目描述

给你一个长度为**偶数** `n` 的整数数组 `nums` 和一个整数 `limit`。每次操作可以将 `nums` 中的**任何整数**替换为 `1` 到 `limit` 之间的另一个整数。

如果对于所有下标 `i`（`0 <= i < n/2`），`nums[i] + nums[n-1-i]` 的值都相同，则数组**互补**。

返回使数组**互补**所需的**最少操作数**。

## 解题思路

对每对 `(a, b) = (nums[i], nums[n-1-i])`（假设 `a <= b`）：

- 目标和 `T` 的范围：`[2, 2*limit]`
- 无需操作：`T = a + b`（0 次）
- 需要一次操作（调整 `a` 或 `b`）：`T ∈ [b+1, a+limit]`（a + limit >= b + 1）
- 需要两次操作（同时调整）：其余情况

**差分数组技巧：** 对每对数，在差分数组中记录操作次数的变化：
- `[2, a+1)` 区间：需要 2 次操作（用于超小目标和）
- `[a+1, a+b]` 区间：需要 1 次操作（只需调小 b 或用特殊值替换 a）
- `[a+b, a+b]` 区间：需要 0 次操作
- `(a+b, b+limit]` 区间：需要 1 次操作
- `(b+limit, 2*limit]` 区间：需要 2 次操作

## 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def minMoves(self, nums: List[int], limit: int) -> int:
        n = len(nums)
        # 差分数组，下标 0 对应目标和 0，..., 下标 2*limit 对应 2*limit
        diff = [0] * (2 * limit + 2)
        
        for i in range(n // 2):
            a, b = nums[i], nums[n - 1 - i]
            if a > b:
                a, b = b, a  # 确保 a <= b
            
            lo = a + 1   # 使用 1 次操作的左边界（改小 b 使目标更大）
            hi = b + limit  # 使用 1 次操作的右边界（改大 a）
            mid = a + b  # 不需要操作的唯一目标和
            
            # 整个范围 [2, 2*limit] 默认需要 2 次操作
            diff[2] += 2
            diff[2 * limit + 1] -= 2
            
            # [lo, 2*limit] 区间减 1 次（1 次操作即可）
            diff[lo] -= 1
            diff[2 * limit + 1] += 1
            
            # [mid, mid] 区间减 1 次（0 次操作）
            diff[mid] -= 1
            diff[mid + 1] += 1
            
            # [lo, hi] 重新：整体只需 1 次
            # 实际是：[2, lo-1] 需 2 次；[lo, hi] 需 1 次；[hi+1, 2*limit] 需 2 次
            # 上面的处理等价，但需要正确叠加
        
        # 计算前缀和，取 [2, 2*limit] 中最小值
        # 重新计算（上面的差分逻辑需要修正）
        
        # 正确做法：
        diff2 = [0] * (2 * limit + 2)
        for i in range(n // 2):
            a, b = nums[i], nums[n - 1 - i]
            if a > b:
                a, b = b, a
            lo = a + 1
            hi = b + limit
            mid = a + b
            
            diff2[2] += 2
            diff2[lo] -= 1
            diff2[mid] -= 1
            diff2[mid + 1] += 1
            diff2[hi + 1] += 1
        
        ans = float('inf')
        curr = 0
        for t in range(2, 2 * limit + 1):
            curr += diff2[t]
            ans = min(ans, curr)
        
        return ans
```

### 方法二：暴力枚举（适合小数据，理解用）

```python
from typing import List

class Solution:
    def minMoves(self, nums: List[int], limit: int) -> int:
        n = len(nums)
        ans = float('inf')
        
        for target in range(2, 2 * limit + 1):
            ops = 0
            for i in range(n // 2):
                a, b = nums[i], nums[n - 1 - i]
                if a + b == target:
                    pass  # 0 ops
                elif (1 <= target - b <= limit) or (1 <= target - a <= limit):
                    ops += 1  # 1 op
                else:
                    ops += 2  # 2 ops
            ans = min(ans, ops)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 差分数组 | O(n + limit) | O(limit) |
| 暴力枚举 | O(n * limit) | O(1) |

## 关键点总结

1. 差分数组技巧：O(1) 时间对区间统一加/减
2. 对每对 (a,b)，根据目标和 T 分析需要几次操作
3. 前缀和恢复差分数组，取最小值

## 易错点

- 差分数组边界处理：注意下标范围 `[2, 2*limit]`
- 一次操作可以将 a 或 b 替换为任意 `[1, limit]` 中的值
