## 题目描述

给你两种颜色的球：红色和蓝色，数量分别为 `red` 和 `blue`。

你需要用这些球排列成一个三角形，第 `i` 行（从 1 开始）有 `i` 个球，且相邻行颜色交替（奇数行一种颜色，偶数行另一种颜色）。

返回可以排列成的三角形的 **最大高度**。

**示例 1：**
```
输入：red = 2, blue = 4
输出：3
解释：第1行1个红，第2行2个蓝，第3行3个红，用了4红2蓝... 不对
实际：高度3时奇数行用2红(1+？)... 让我重新计算
行 1: 1 球，行 2: 2 球，行 3: 3 球，共 1+2+3=6 球。奇数行(1,3)用红色：1+3=4 红，偶数行(2)用蓝色：2 蓝。
red=2,blue=4 不够。
height=3,从蓝开始：奇数行用蓝 1+3=4 蓝，偶数行用红 2 红，2<=2, 4<=4，OK！输出 3。
```

**提示：**
- `1 <= red, blue <= 100`

## 解题思路

枚举高度 h（从大到小），对两种颜色分配方式（奇数行/偶数行用哪种颜色）各检查一次，找最大满足条件的 h。

高度 h 时，奇数行总数 = 1+3+5+... = ceil(h/2)^2，偶数行总数 = 2+4+6+... = floor(h/2) * (floor(h/2)+1)。

## Python 代码实现

### 方法一：枚举高度（推荐）

```python
class Solution:
    def maxHeightOfTriangle(self, red: int, blue: int) -> int:
        def check(h: int, c1: int, c2: int) -> bool:
            # 奇数行用 c1，偶数行用 c2
            odd_sum = sum(i for i in range(1, h + 1, 2))   # 1+3+5+...
            even_sum = sum(i for i in range(2, h + 1, 2))  # 2+4+6+...
            return odd_sum <= c1 and even_sum <= c2

        for h in range(200, 0, -1):
            if check(h, red, blue) or check(h, blue, red):
                return h
        return 0
```

### 方法二：数学公式

```python
class Solution:
    def maxHeightOfTriangle(self, red: int, blue: int) -> int:
        def can_do(h: int, c1: int, c2: int) -> bool:
            # 奇数行数：ceil(h/2)，偶数行数：floor(h/2)
            odd_rows = (h + 1) // 2
            even_rows = h // 2
            # 奇数行总数：1+3+...+(2k-1) = k^2
            odd_sum = odd_rows ** 2
            # 偶数行总数：2+4+...+2k = k*(k+1)
            even_sum = even_rows * (even_rows + 1)
            return odd_sum <= c1 and even_sum <= c2

        ans = 0
        for h in range(1, 201):
            if can_do(h, red, blue) or can_do(h, blue, red):
                ans = h
        return ans
```

## 复杂度分析

- 时间复杂度：O(1)，h 最大约 sqrt(red + blue)，而 red, blue <= 100，h <= 20
- 空间复杂度：O(1)

## 关键点总结

1. 枚举两种颜色分配方式（谁负责奇数行）
2. 奇数行总球数 = ceil(h/2)^2，偶数行总球数 = floor(h/2) * (floor(h/2)+1)
3. 找最大满足条件的高度

## 易错点

1. 两种分配方式都需要检查
2. 注意奇偶行的球数计算
