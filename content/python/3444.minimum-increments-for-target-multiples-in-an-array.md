## 题目描述

给你两个整数数组 `nums` 和 `target`。

在一次操作中，你可以选择 `nums` 中任意一个元素，并将其增加 1。

返回使 `nums` 中的某些元素成为 `target` 中**每个元素**的倍数所需的**最少操作次数**。即，对 target 中每个元素 t，nums 中至少有一个元素是 t 的倍数。

**示例 1：**

```
输入：nums = [1,2,3], target = [4]
输出：1
解释：将 3 增加到 4，代价 1，4 是 4 的倍数
```

**示例 2：**

```
输入：nums = [4,5,6], target = [6,4]
输出：0
解释：4 是 4 的倍数，6 是 6 的倍数，无需操作
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= target.length <= 4`
- `1 <= nums[i] <= 10^4`
- `1 <= target[i] <= 10^4`

## 解题思路

target 最多 4 个元素，用位掩码 DP。

设 `dp[mask]` = 使 mask 中对应的所有 target 元素都有 nums 中某个倍数对应时的最少操作数。

对每个 `nums[i]`，考虑它可以变成哪些 target 元素的倍数（通过增加操作）。

对于 `nums[i]` 和 target 子集 `mask`，计算将 `nums[i]` 增加到同时是所有 mask 中 target 元素倍数的最近数，代价 = 增加量。

同时是多个 target 元素倍数，等于是 LCM(target[mask]) 的倍数。

## Python 代码实现

### 方法一：枚举每个 nums 元素对每个 target 子集的贡献

```python
from typing import List
from math import lcm, gcd
from functools import reduce

class Solution:
    def minimumIncrements(self, nums: List[int], target: List[int]) -> int:
        m = len(target)  # <= 4
        full = (1 << m) - 1
        INF = float('inf')

        # 预计算每个非空子集的 LCM
        lcm_of = [0] * (1 << m)
        for mask in range(1, 1 << m):
            vals = [target[i] for i in range(m) if mask & (1 << i)]
            lcm_of[mask] = reduce(lcm, vals)

        # dp[mask]: 覆盖 target 中 mask 对应元素所需最少操作
        dp = [INF] * (1 << m)
        dp[0] = 0

        # 对每个 nums[i]，枚举它负责覆盖的 target 子集
        # 贪心：对每个 nums[i]，找其最优的"贡献子集"

        # 实际上这是一个集合覆盖 DP
        # dp[mask] = min over all ways to cover mask

        # 转移：枚举最后一个负责的 nums 元素和它覆盖的子集
        # 这个方法复杂度较高，需要优化

        # 简化：对每个 nums[i]，计算它覆盖每个 target 子集的最小代价
        # cost[i][mask] = 将 nums[i] 变为 lcm_of[mask] 的最近倍数的代价

        n = len(nums)
        # dp[mask]: 覆盖 mask 的最少代价
        dp = [INF] * (1 << m)
        dp[0] = 0

        for v in nums:
            # 计算 v 覆盖每个子集的代价
            # cost[mask] = 将 v 增加到 lcm 的倍数的最小代价
            costs = [INF] * (1 << m)
            costs[0] = 0  # 不用 v
            for mask in range(1, 1 << m):
                L = lcm_of[mask]
                # 最近的 >= v 的 L 的倍数
                remainder = v % L
                inc = 0 if remainder == 0 else L - remainder
                costs[mask] = inc

            # 更新 dp：dp[mask | sub] = min(dp[mask] + costs[sub])
            # 枚举当前 v 覆盖的子集 sub
            new_dp = dp[:]
            for covered in range(full + 1):  # 已覆盖的集合
                if dp[covered] == INF:
                    continue
                for sub in range(1, 1 << m):
                    new_mask = covered | sub
                    val = dp[covered] + costs[sub]
                    if val < new_dp[new_mask]:
                        new_dp[new_mask] = val
            dp = new_dp

        return dp[full] if dp[full] < INF else -1
```

### 方法二：更高效的 DP

```python
from typing import List
from math import lcm
from functools import reduce

class Solution:
    def minimumIncrements(self, nums: List[int], target: List[int]) -> int:
        m = len(target)
        full = (1 << m) - 1

        # 预计算子集 LCM
        lcm_mask = [1] * (1 << m)
        for mask in range(1, 1 << m):
            low = mask & (-mask)  # 最低位
            idx = low.bit_length() - 1
            lcm_mask[mask] = lcm(lcm_mask[mask ^ low], target[idx])

        INF = float('inf')
        dp = [INF] * (1 << m)
        dp[0] = 0

        for v in nums:
            # 对当前 v，计算覆盖每个子集的代价
            sub_cost = {}
            for mask in range(1, 1 << m):
                L = lcm_mask[mask]
                rem = v % L
                sub_cost[mask] = 0 if rem == 0 else L - rem

            # 更新 dp（枚举每个已覆盖集合，加上 v 覆盖新子集）
            new_dp = dp[:]
            for state in range(full + 1):
                if dp[state] == INF:
                    continue
                # 枚举 v 额外覆盖的子集（state 的补集的子集）
                complement = full ^ state
                sub = complement
                while sub > 0:
                    new_state = state | sub
                    val = dp[state] + sub_cost[sub]
                    if val < new_dp[new_state]:
                        new_dp[new_state] = val
                    sub = (sub - 1) & complement

            dp = new_dp

        return dp[full]
```

## 复杂度分析

- 时间复杂度：O(n * 3^m)，枚举子集
- 空间复杂度：O(2^m)

## 关键点总结

1. target 最多 4 个元素，用位掩码表示覆盖状态
2. 覆盖多个 target 元素时，需要是这些元素 LCM 的倍数
3. 集合覆盖 DP：枚举每个 nums 元素覆盖的 target 子集

## 易错点

1. 子集的 LCM 可能很大，需要正确计算
2. 将 v 增加到 L 的倍数：代价 = `L - v%L`（若 `v%L != 0`），否则为 0
3. 枚举子集时要遍历所有非空子集
