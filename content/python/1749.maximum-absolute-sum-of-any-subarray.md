## 题目描述

给你一个整数数组 `nums`。一个子数组 `[numsl, numsl+1, ..., numsr-1, numsr]` 的**和的绝对值**为 `abs(numsl + numsl+1 + ... + numsr-1 + numsr)`。

请你找出 `nums` 中和的绝对值最大的任意子数组，并返回该**最大值**。

**示例 1：**
```
输入：nums = [1,-3,2,3,-4]
输出：5
解释：子数组 [2,3] 和为 5，绝对值最大
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

和的绝对值最大，等价于：
- 和最大的子数组（正方向最大）
- 和最小的子数组（负方向最小）

两者绝对值取最大即为答案。

用 Kadane 算法分别求最大子数组和和最小子数组和。

## 代码实现

### 方法一：Kadane 算法（推荐）

```python
from typing import List

class Solution:
    def maxAbsoluteSum(self, nums: List[int]) -> int:
        # 求最大子数组和
        max_sum = cur_max = 0
        # 求最小子数组和
        min_sum = cur_min = 0
        
        for x in nums:
            cur_max = max(cur_max + x, x)
            max_sum = max(max_sum, cur_max)
            
            cur_min = min(cur_min + x, x)
            min_sum = min(min_sum, cur_min)
        
        return max(abs(max_sum), abs(min_sum))
```

### 方法二：前缀和法

```python
from typing import List

class Solution:
    def maxAbsoluteSum(self, nums: List[int]) -> int:
        # |sum(l..r)| = |prefix[r+1] - prefix[l]|
        # 最大化这个值 = 最大前缀和 - 最小前缀和
        prefix = 0
        max_prefix = 0
        min_prefix = 0
        
        for x in nums:
            prefix += x
            max_prefix = max(max_prefix, prefix)
            min_prefix = min(min_prefix, prefix)
        
        return max_prefix - min_prefix
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 最大绝对值子数组和 = max(最大子数组和, |最小子数组和|)
2. 前缀和方法更简洁：最大绝对值 = 最大前缀和 - 最小前缀和

## 易错点

- 初始化 `max_prefix = 0` 和 `min_prefix = 0`，因为空子数组的和为 0（但题目要非空子数组，不过前缀和包含了空子数组的情况，实际求的是最大前缀和减最小前缀和，覆盖所有非空子数组）
