## 题目描述

给你两个整数 `num` 和 `t`。每步操作可以将 `num` 增加或减少 1，同时将某个 **可达数字** 减少或增加 1。

在最多 `t` 步操作内，返回可以使某个数字等于 `num` 的最大可达数字。

换句话说，找到最大的 `x`，满足在 `t` 步内 `x` 可以变为 `num`（双向操作：每步 x 和 num 可以各变化 ±1，总共接近彼此）。

**示例 1：**
```
输入：num = 4, t = 1
输出：6
解释：x = 6 时，x - 1 = 5，num + 1 = 5，1 步内可以相等
```

**示例 2：**
```
输入：num = 3, t = 2
输出：7
```

**提示：**
- `1 <= num, t <= 50`

## 解题思路

每步操作 num 加 1，x 减 1（或反向），两者相互接近，每步缩小差距 2。经过 t 步，可以使 x 和 num 差距减少 2t，所以最大 x = `num + 2 * t`。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def theMaximumAchievableX(self, num: int, t: int) -> int:
        # 每步操作使 x 和 num 差距减 2，t 步最多减 2t
        return num + 2 * t
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 每步 x 减 1，num 加 1，差距减少 2
2. t 步后最大差距 2t，所以最大 x = num + 2t

## 易错点

1. 不要想复杂，核心就是每步缩近 2
