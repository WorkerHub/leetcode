## 题目描述

与 3346 相同，但数据范围更大：`nums.length <= 10^5`，`nums[i] <= 10^9`。

本质上与 3346 相同的解法，只是需要更高效的实现。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`（k 可以更大）
- `0 <= numOperations <= nums.length`

## 解题思路

与 3346 完全相同的排序 + 滑动窗口 + 前缀和方法，O(n log n) 时间复杂度在此范围内可以通过。

目标值不仅仅是数组中已有的值，也可能是两个相邻元素之间的某个中间值。

**扩展分析：** 目标值 v 可以是任意整数，但最优情况下 v 是数组中某个元素，或者两个相邻元素的中点（向上/向下取整）。

**简化：** 若对所有可能的目标值枚举代价太高，直接以排序后的数组元素为候选目标值（或加 numOperations 后的值）。

## Python 代码实现

### 方法一：排序 + 双指针滑动窗口（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxFrequency(self, nums: List[int], k: int, numOperations: int) -> int:
        nums.sort()
        n = len(nums)
        
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        def count(target):
            """计算以 target 为目标值，最多可以凑到的频率"""
            # 可以改变的元素：nums[i] 在 [target - numOperations, target + numOperations] 内
            lo = bisect.bisect_left(nums, target - numOperations)
            hi = bisect.bisect_right(nums, target + numOperations) - 1
            if lo > hi:
                return 0
            
            # 在 [lo, hi] 的所有元素中，总操作次数 <= k
            # 对 nums[i] <= target：操作次数 = target - nums[i]
            # 对 nums[i] > target：操作次数 = nums[i] - target
            # 选最多元素使总操作 <= k
            
            # 先找 <= target 的元素（只需付 target-nums[i]）
            # 用双指针找最大窗口
            # 以 target 为中心，向两侧扩展
            # 贪心：优先选距离近的
            
            # 简化：枚举窗口 [l, r] 使总操作 <= k
            # 由于排序，在 [lo, hi] 内用两指针
            # 但目标值 target 不一定是数组中的值
            
            # 对 [lo, r] 全取 target（从下往上，target >= nums[i]）
            # 加上从 [r+1, hi] 全取 target（需要 nums[i] - target 操作）
            # 分两部分找
            
            # 找 target 在排序数组中的位置
            mid = bisect.bisect_right(nums, target)  # nums[mid-1] <= target < nums[mid]
            
            # 左侧（<= target）：从 lo 到 mid-1，总操作 = target*(mid-lo) - sum(nums[lo..mid-1])
            # 右侧（> target）：从 mid 到 hi，总操作 = sum(nums[mid..hi]) - target*(hi-mid+1)
            
            # 最大左侧元素数（使操作 <= k）
            # 左指针 l1，使 target*(mid-l1) - (prefix[mid]-prefix[l1]) <= k
            l1 = bisect.bisect_left(
                range(lo, mid),
                True,
                key=lambda l: target * (mid - l) - (prefix[mid] - prefix[l]) <= k
            )
            # 简单实现：直接枚举或二分
            
            # 两侧都从 mid 扩展，二分找各自能包含的最多元素
            # 左侧 l in [lo, mid]：操作 = target*(mid-l) - prefix-sum，随 l 减小而增加
            l_left = lo
            while l_left < mid and (target * (mid - l_left) - (prefix[mid] - prefix[l_left])) > k:
                l_left += 1
            left_count = mid - l_left
            
            l_right = hi
            while l_right >= mid and (prefix[l_right+1] - prefix[mid] - target * (l_right - mid + 1)) > k:
                l_right -= 1
            right_count = l_right - mid + 1 if l_right >= mid else 0
            
            return left_count + right_count
        
        # 候选目标值：数组中每个值，以及 nums[i] + numOperations 和 nums[i] - numOperations
        candidates = set()
        for x in nums:
            candidates.add(x)
            candidates.add(x + numOperations)
            candidates.add(x - numOperations)
        
        return max(count(v) for v in candidates)
```

### 方法二：简化排序滑动窗口

```python
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int, numOperations: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]
        
        ans = 1
        # 枚举以 nums[r] 为目标值的最大频率
        l = 0
        for r in range(n):
            t = nums[r]
            while t - nums[l] > numOperations:
                l += 1
            # 窗口 [l, r] 内所有元素都可以改到 t（per-element 约束）
            # 找最大子窗口使总操作 <= k
            # 二分找左边界
            import bisect
            # sum(t - nums[i] for i in [ll, r]) = t*(r-ll+1) - (prefix[r+1]-prefix[ll])
            # 找最小 ll >= l 使上式 <= k
            lo2, hi2 = l, r
            while lo2 < hi2:
                mid2 = (lo2 + hi2) // 2
                ops = t * (r - mid2 + 1) - (prefix[r+1] - prefix[mid2])
                if ops <= k:
                    hi2 = mid2
                else:
                    lo2 = mid2 + 1
            ans = max(ans, r - lo2 + 1)
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后以每个元素为目标值，用二分找满足 k 约束的最大窗口。
2. per-element 约束（numOperations）先用滑动窗口缩小范围，再用 k 约束精确二分。
3. 总操作数 = 目标值 * 窗口大小 - 窗口元素之和（前缀和）。

## 易错点

1. per-element 约束和 total 约束是相互独立的两个限制。
2. 目标值可能是区间内任意值，取数组元素作为候选即可（最优解一定在某个元素值处取到）。
3. 前缀和计算要注意下标。
