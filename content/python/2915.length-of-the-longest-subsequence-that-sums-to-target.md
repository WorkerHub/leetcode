## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `target`。

返回 `nums` 中和等于 `target` 的 **最长子序列** 的长度。如果不存在这样的子序列，返回 `-1`。

**示例 1：**
```
输入：nums = [1,2,3,4,5], target = 9
输出：3
解释：子序列 [2,3,4] 的和为 9，长度为 3
```

**示例 2：**
```
输入：nums = [4,1,3,2,1,5], target = 7
输出：4
解释：子序列 [4,1,1] 的和为 6，[1,3,2,1] 的和为 7，长度 4
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`
- `1 <= target <= 1000`

## 解题思路

0-1 背包变种：`dp[j]` 表示和恰好为 `j` 时能选取的最多元素个数。

- 初始化：`dp[0] = 0`，其余为 `-inf`（表示不可达）
- 对每个元素 `num`，从右到左更新：`dp[j] = max(dp[j], dp[j - num] + 1)`（若 `dp[j - num]` 可达）
- 答案为 `dp[target]`，若为 `-inf` 则返回 `-1`

## Python 代码实现

### 方法一：0-1 背包（推荐）

```python
from typing import List

class Solution:
    def lengthOfLongestSubsequence(self, nums: List[int], target: int) -> int:
        # dp[j] = 和为 j 的子序列的最大长度，不可达则为 -inf
        dp = [-float('inf')] * (target + 1)
        dp[0] = 0

        for num in nums:
            # 0-1 背包：从右向左遍历，避免重复选取
            for j in range(target, num - 1, -1):
                if dp[j - num] != -float('inf'):
                    dp[j] = max(dp[j], dp[j - num] + 1)

        return dp[target] if dp[target] != -float('inf') else -1
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def lengthOfLongestSubsequence(self, nums: List[int], target: int) -> int:
        n = len(nums)

        @lru_cache(maxsize=None)
        def dfs(i: int, remain: int) -> int:
            # 从 nums[i..] 中选，使和恰好为 remain 的最多元素数
            if remain == 0:
                return 0
            if i == n or remain < 0:
                return -float('inf')
            # 不选 nums[i]
            skip = dfs(i + 1, remain)
            # 选 nums[i]
            take = dfs(i + 1, remain - nums[i])
            if take != -float('inf'):
                take += 1
            return max(skip, take)

        ans = dfs(0, target)
        return ans if ans != -float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n * target)，背包状态数
- 空间复杂度：O(target)，一维 DP 数组

## 关键点总结

1. 与普通背包不同，这里求的是元素个数最多（而非最大价值）
2. 初始值设为 -inf 而非 0，区分"可达且长度为 0"和"不可达"
3. 0-1 背包须从右向左遍历，防止同一元素被选多次

## 易错点

1. `dp[0] = 0` 而不是 `-inf`：空子序列和为 0 且合法
2. 更新条件：只有 `dp[j - num]` 可达时才更新 `dp[j]`
3. 最终答案为 `-1` 而非 `0` 当不可达时
