## 题目描述

给定一个单链表 `L` 的头节点 `head`，单链表 `L` 表示为：

```
L0 → L1 → … → Ln-1 → Ln
```

请将其重新排列后变为：

```
L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …
```

不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

**示例 1：**
```
输入：head = [1,2,3,4]
输出：[1,4,2,3]
```

**示例 2：**
```
输入：head = [1,2,3,4,5]
输出：[1,5,2,4,3]
```

**提示：**
- 链表的长度范围为 `[1, 5 * 10^4]`
- `1 <= node.val <= 1000`

## 解题思路

这道题需要将链表按照"头尾交替"的方式重新排列，可以分解为三个子问题：

**核心思想：找中点 + 反转 + 合并**

### 算法步骤：

1. **找到链表中点**：使用快慢指针找到链表的中间节点
2. **反转后半部分**：将中点之后的链表反转
3. **合并两部分**：交替合并前半部分和反转后的后半部分

### 详细说明：

**步骤1：找中点**
- 使用快慢指针，快指针每次走 2 步，慢指针每次走 1 步
- 当快指针到达末尾时，慢指针在中点

**步骤2：反转后半部分**
- 从中点开始反转链表
- 使用标准的链表反转算法

**步骤3：合并**
- 交替从前半部分和后半部分取节点
- 重新连接指针

## Python 代码实现

### 方法一：找中点 + 反转 + 合并（推荐）

```python
from typing import Optional

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        """
        Do not return anything, modify head in-place instead.
        """
        if not head or not head.next:
            return
        
        # 步骤1: 找到链表中点
        slow, fast = head, head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        
        # slow 现在指向中点（或中点偏左）
        # 将链表分为两部分
        second_half = slow.next
        slow.next = None  # 断开前后两部分
        
        # 步骤2: 反转后半部分
        second_half = self.reverseList(second_half)
        
        # 步骤3: 合并两部分
        first_half = head
        while second_half:
            # 保存下一个节点
            temp1 = first_half.next
            temp2 = second_half.next
            
            # 交替连接
            first_half.next = second_half
            second_half.next = temp1
            
            # 移动指针
            first_half = temp1
            second_half = temp2
    
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """反转链表"""
        prev = None
        curr = head
        while curr:
            next_node = curr.next
            curr.next = prev
            prev = curr
            curr = next_node
        return prev
```

### 方法二：一体化版本（所有逻辑在一个函数中）

```python
from typing import Optional

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        if not head or not head.next:
            return
        
        # 步骤1: 找中点
        slow = fast = head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        
        # 步骤2: 反转后半部分
        prev = None
        curr = slow.next
        slow.next = None  # 断开
        
        while curr:
            next_node = curr.next
            curr.next = prev
            prev = curr
            curr = next_node
        
        # 步骤3: 合并
        first = head
        second = prev
        
        while second:
            temp1 = first.next
            temp2 = second.next
            first.next = second
            second.next = temp1
            first = temp1
            second = temp2
```

### 方法三：使用列表存储（不满足空间要求，但直观）

```python
from typing import Optional

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        if not head or not head.next:
            return
        
        # 将链表节点存入列表
        nodes = []
        curr = head
        while curr:
            nodes.append(curr)
            curr = curr.next
        
        # 使用双指针重新连接
        left, right = 0, len(nodes) - 1
        
        while left < right:
            nodes[left].next = nodes[right]
            left += 1
            if left == right:
                break
            nodes[right].next = nodes[left]
            right -= 1
        
        # 最后一个节点的 next 置为 None
        nodes[left].next = None
```

### 方法四：递归（优雅但空间复杂度高）

```python
from typing import Optional

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        if not head or not head.next:
            return
        
        # 计算链表长度
        length = 0
        curr = head
        while curr:
            length += 1
            curr = curr.next
        
        self.reorder(head, length)
    
    def reorder(self, head: Optional[ListNode], length: int) -> Optional[ListNode]:
        """递归重排，返回处理后的尾节点"""
        if length == 1:
            tail = head.next
            head.next = None
            return tail
        if length == 2:
            tail = head.next.next
            head.next.next = None
            return tail
        
        # 递归处理中间部分
        tail = self.reorder(head.next, length - 2)
        
        # 重新连接
        temp = head.next
        head.next = tail
        next_tail = tail.next
        tail.next = temp
        
        return next_tail
```

## 复杂度分析

### 方法一、二：找中点 + 反转 + 合并
- **时间复杂度**：O(n)
  - 找中点：O(n)
  - 反转：O(n/2)
  - 合并：O(n/2)
- **空间复杂度**：O(1)，只使用常数个指针

### 方法三：列表存储
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，需要存储所有节点

### 方法四：递归
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，递归栈深度

## 图解示例

以 `head = [1,2,3,4,5]` 为例：

```
原始链表：
1 → 2 → 3 → 4 → 5

步骤1：找中点（slow 指针）
        slow
         ↓
1 → 2 → 3 → 4 → 5
            ↑
           fast

分割为两部分：
前半部分: 1 → 2 → 3
后半部分: 4 → 5

步骤2：反转后半部分
后半部分: 5 → 4

步骤3：交替合并
first:  1 → 2 → 3
second: 5 → 4

合并过程：
第1次: 1 → 5 → 2 → 3
              4
第2次: 1 → 5 → 2 → 4 → 3

最终结果：
1 → 5 → 2 → 4 → 3
```

**偶数节点的例子 `[1,2,3,4]`：**

```
原始: 1 → 2 → 3 → 4

找中点: slow 在 2
前半部分: 1 → 2
后半部分: 3 → 4

反转后半部分: 4 → 3

合并:
1 → 4 → 2 → 3
```

## 关键点总结

1. **三步法**：找中点、反转、合并，每一步都是经典的链表操作
2. **快慢指针找中点**：快指针每次走 2 步，慢指针每次走 1 步
3. **断开链表**：找到中点后要将前后两部分断开（`slow.next = None`）
4. **交替合并**：保存下一个节点再修改指针，避免丢失引用
5. **原地修改**：不需要返回值，直接修改原链表

## 易错点

1. **忘记断开链表**：找到中点后要将 `slow.next` 置为 None，否则形成环
2. **指针保存顺序**：合并时要先保存 next 指针再修改，否则丢失引用
3. **边界条件**：空链表、单节点、双节点要特殊处理
4. **快慢指针的终止条件**：`fast.next and fast.next.next` 还是 `fast and fast.next`
5. **合并的终止条件**：当 second 为 None 时终止（因为后半部分可能比前半部分少 1 个）
