## 题目描述

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

**示例 1：**
```
输入：matrix = [[1,4,7,11,15],
               [2,5,8,12,19],
               [3,6,9,16,22],
               [10,13,14,17,24],
               [18,21,23,26,30]], target = 5
输出：true
```

**示例 2：**
```
输入：matrix = [[1,4,7,11,15],
               [2,5,8,12,19],
               [3,6,9,16,22],
               [10,13,14,17,24],
               [18,21,23,26,30]], target = 20
输出：false
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- `-10^9 <= target <= 10^9`

## 解题思路

这道题的关键是利用矩阵的特殊性质：行递增、列递增。

**方法对比：**

1. **暴力遍历**：O(m * n)
2. **每行二分查找**：O(m * log n)
3. **从右上角或左下角开始**：O(m + n) ⭐
4. **分治法**：O(m + n)

**最优解：从右上角开始搜索**

**核心观察：**
- 从右上角 `matrix[0][n-1]` 开始
- 如果当前值 > target，向左移动（减小）
- 如果当前值 < target，向下移动（增大）
- 如果相等，返回 true

**为什么从右上角？**
- 右上角元素是该行最大、该列最小
- 可以根据大小关系明确移动方向
- 左下角同理，也可以

**为什么不从左上角或右下角？**
- 左上角：向右或向下都是增大，无法判断方向
- 右下角：向左或向上都是减小，无法判断方向

## Python 代码实现

### 方法一：从右上角开始（推荐）⭐

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        从右上角开始搜索
        时间复杂度：O(m + n)
        空间复杂度：O(1)
        """
        if not matrix or not matrix[0]:
            return False
        
        m, n = len(matrix), len(matrix[0])
        
        # 从右上角开始
        row, col = 0, n - 1
        
        while row < m and col >= 0:
            current = matrix[row][col]
            
            if current == target:
                return True
            elif current > target:
                # 当前值太大，向左移动
                col -= 1
            else:
                # 当前值太小，向下移动
                row += 1
        
        return False
```

### 方法二：从左下角开始

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        从左下角开始搜索（与右上角对称）
        """
        if not matrix or not matrix[0]:
            return False
        
        m, n = len(matrix), len(matrix[0])
        
        # 从左下角开始
        row, col = m - 1, 0
        
        while row >= 0 and col < n:
            current = matrix[row][col]
            
            if current == target:
                return True
            elif current > target:
                # 当前值太大，向上移动
                row -= 1
            else:
                # 当前值太小，向右移动
                col += 1
        
        return False
```

### 方法三：每行二分查找

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        对每一行进行二分查找
        时间复杂度：O(m * log n)
        空间复杂度：O(1)
        """
        if not matrix or not matrix[0]:
            return False
        
        for row in matrix:
            # 二分查找
            left, right = 0, len(row) - 1
            
            while left <= right:
                mid = (left + right) // 2
                
                if row[mid] == target:
                    return True
                elif row[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
        
        return False
```

### 方法四：使用 Python 内置函数

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        利用 Python 内置的 in 操作符
        时间复杂度：O(m * n)，但代码简洁
        """
        for row in matrix:
            if target in row:
                return True
        return False
```

### 方法五：分治法

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        分治法：将矩阵分成四个子矩阵
        时间复杂度：O(m + n)
        空间复杂度：O(log(min(m, n)))，递归栈
        """
        if not matrix or not matrix[0]:
            return False
        
        def search(top, left, bottom, right):
            # 边界检查
            if top > bottom or left > right:
                return False
            
            # 如果区域在目标值范围之外
            if target < matrix[top][left] or target > matrix[bottom][right]:
                return False
            
            # 选择中间列
            mid = (left + right) // 2
            
            # 在中间列找到最后一个 <= target 的行
            row = top
            while row <= bottom and matrix[row][mid] <= target:
                if matrix[row][mid] == target:
                    return True
                row += 1
            
            # 在左下和右上两个子矩阵中搜索
            # 左下：行范围 [row, bottom]，列范围 [left, mid-1]
            # 右上：行范围 [top, row-1]，列范围 [mid+1, right]
            return search(row, left, bottom, mid - 1) or \
                   search(top, mid + 1, row - 1, right)
        
        return search(0, 0, len(matrix) - 1, len(matrix[0]) - 1)
```

### 方法六：暴力法（仅供理解）

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        暴力遍历所有元素
        时间复杂度：O(m * n)
        """
        for row in matrix:
            for num in row:
                if num == target:
                    return True
        return False
```

## 复杂度分析

**方法一、二（右上角/左下角）：**
- 时间复杂度：O(m + n)，最多移动 m + n 步
- 空间复杂度：O(1)

**方法三（每行二分）：**
- 时间复杂度：O(m * log n)
- 空间复杂度：O(1)

**方法五（分治）：**
- 时间复杂度：O(m + n)，每次递归排除一部分区域
- 空间复杂度：O(log(min(m, n)))，递归栈深度

**方法六（暴力）：**
- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. **利用矩阵性质**：行递增、列递增
2. **选择起点**：右上角或左下角，可以明确移动方向
3. **移动规则**：根据大小关系决定向左/右或向上/下
4. **时间复杂度**：O(m + n)，线性时间
5. **空间复杂度**：O(1)，原地搜索

## 易错点

1. **起点选择**：
   ```python
   # 正确：右上角或左下角
   row, col = 0, n - 1        # 右上角
   row, col = m - 1, 0        # 左下角
   
   # 错误：左上角或右下角（无法确定方向）
   row, col = 0, 0            # 左上角
   row, col = m - 1, n - 1    # 右下角
   ```

2. **边界条件**：
   ```python
   # 正确
   while row < m and col >= 0:
   
   # 错误：可能越界
   while row <= m and col >= 0:
   ```

3. **移动方向**：
   ```python
   # 从右上角开始
   if current > target:
       col -= 1  # 向左
   else:
       row += 1  # 向下
   
   # 从左下角开始
   if current > target:
       row -= 1  # 向上
   else:
       col += 1  # 向右
   ```

4. **空矩阵检查**：
   ```python
   if not matrix or not matrix[0]:
       return False
   ```
