## 题目描述

与 3162 相同，但数组范围更大：
- `1 <= nums1.length, nums2.length <= 10^5`
- `1 <= nums1[i] <= 10^6`
- `1 <= nums2[j] <= 10^6`
- `1 <= k <= 10^3`

需要更高效的算法。

## 解题思路

对 `nums1[i]` 被 `nums2[j] * k` 整除，等价于 `(nums1[i] / k)` 被 `nums2[j]` 整除（仅当 `k | nums1[i]`）。

预处理：统计 `nums2` 中每个值的频率 `cnt2`。

对 `nums1[i]`，若 `nums1[i] % k != 0`，则贡献为 0；否则设 `v = nums1[i] / k`，则需要 `nums2[j]` 是 `v` 的因子，贡献为 `sum(cnt2[d] for d in divisors(v))`。

枚举 `v` 的所有因子，查询 `cnt2[d]`。

## Python 代码实现

### 方法一：枚举因子（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        cnt2 = Counter(nums2)
        ans = 0

        for a in nums1:
            if a % k != 0:
                continue
            v = a // k  # nums1[i] = v * k，需要 nums2[j] | v
            # 枚举 v 的所有因子
            d = 1
            while d * d <= v:
                if v % d == 0:
                    ans += cnt2[d]
                    if d != v // d:
                        ans += cnt2[v // d]
                d += 1

        return ans
```

### 方法二：预处理 nums1 频率

```python
from typing import List
from collections import Counter

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        cnt1 = Counter(a // k for a in nums1 if a % k == 0)
        cnt2 = Counter(nums2)
        ans = 0

        # 对 cnt2 中的每个值 b，找 cnt1 中 b 的所有倍数
        max_v = max(cnt1, default=0)
        for b, cb in cnt2.items():
            mult = b
            while mult <= max_v:
                if mult in cnt1:
                    ans += cnt1[mult] * cb
                mult += b

        return ans
```

## 复杂度分析

- 时间复杂度：O(n1 * sqrt(max_v) + n2 * log(max_v))，方法一；O((max_v/b) * 26) 方法二
- 空间复杂度：O(n1 + n2)

## 关键点总结

1. 等价转化：nums1[i]/k 的因子包含 nums2[j]
2. 枚举因子 O(sqrt(v))，或枚举倍数 O(V/b)
3. 方法二枚举 nums2 值的所有倍数更优（类似筛法）

## 易错点

1. 先检查 nums1[i] % k == 0，否则跳过
2. 枚举因子时不要重复计数（d != v//d）
