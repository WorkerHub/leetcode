## 题目描述

对于某些固定的 n，如果数组 nums 是整数 1, 2, ..., n 组成的排列，使得：

对于每个 i < k < j，都不存在 nums[k] * 2 == nums[i] + nums[j]。

那么数组 nums 是漂亮数组。给定 n，返回任意漂亮数组 nums（保证存在一个）。

## Python 代码实现

```python
from typing import List

class Solution:
    def beautifulArray(self, n: int) -> List[int]:
        result = [1]
        
        while len(result) < n:
            # 奇数部分和偶数部分
            result = [2*x - 1 for x in result] + [2*x for x in result]
        
        return [x for x in result if x <= n]
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)
