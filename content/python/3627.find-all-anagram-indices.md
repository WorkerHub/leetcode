## 题目描述

给你两个字符串 `s` 和 `p`，找出 `s` 中所有 `p` 的 **字母异位词** 的起始下标，以任意顺序返回。

字母异位词是由相同字母重新排列组成的字符串（包含相同字母且每种字母出现次数相同）。

**示例 1：**

```
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释：
- 下标0："cba" 是 "abc" 的异位词
- 下标6："bac" 是 "abc" 的异位词
```

**示例 2：**

```
输入：s = "abab", p = "ab"
输出：[0,1,2]
```

**提示：**

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 只包含小写英文字母

## 解题思路

滑动窗口 + 字符频率比较：

维护一个长度为 `len(p)` 的窗口，滑动时更新窗口内的字符频率，与 `p` 的频率对比。

优化：用差值计数（`diff`）追踪当前窗口和 `p` 的不同字符数，当 `diff == 0` 时为异位词。

## Python 代码实现

### 方法一：滑动窗口 + 差值计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(p) > len(s):
            return []

        p_count = Counter(p)
        window = Counter(s[:len(p)])
        diff = sum((window[c] - p_count[c]) != 0 for c in set(window) | set(p_count))

        result = []
        if diff == 0:
            result.append(0)

        for i in range(len(p), len(s)):
            # 加入新字符
            new_char = s[i]
            old_char = s[i - len(p)]

            # 更新 diff（先处理加入）
            before = (window[new_char] - p_count[new_char]) != 0
            window[new_char] += 1
            after = (window[new_char] - p_count[new_char]) != 0
            diff += after - before

            # 移除旧字符
            before = (window[old_char] - p_count[old_char]) != 0
            window[old_char] -= 1
            after = (window[old_char] - p_count[old_char]) != 0
            diff += after - before

            if diff == 0:
                result.append(i - len(p) + 1)

        return result
```

### 方法二：Counter 比较（简洁版）

```python
from typing import List
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        p_count = Counter(p)
        k = len(p)
        window = Counter(s[:k])
        result = [0] if window == p_count else []

        for i in range(k, len(s)):
            window[s[i]] += 1
            old = s[i - k]
            window[old] -= 1
            if window[old] == 0:
                del window[old]
            if window == p_count:
                result.append(i - k + 1)

        return result
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n * |alphabet|)（方法二）
- 空间复杂度：O(|alphabet|)

## 关键点总结

1. 固定窗口大小为 `len(p)`
2. 差值计数优化：只追踪不一致字符数，O(1) 更新
3. `window == p_count` 在 Python 中是 O(26) 的比较

## 易错点

1. 窗口移除字符后若频率为 0 需删除，否则影响比较
2. 差值计数更新顺序：先更新计数，再计算新旧差值变化
3. 注意 `len(p) > len(s)` 的边界情况
