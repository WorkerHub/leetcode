## 题目描述

给定一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

返回一个表示每个字符串片段的长度的列表。

**示例 1:**
```
输入: s = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释:
划分结果为 "ababcbaca", "defegde", "hijhklij"
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。
```

**示例 2:**
```
输入: s = "eccbbbbdec"
输出: [10]
```

**提示:**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 解题思路

这是一个经典的贪心算法问题。

**核心思想：**
1. 记录每个字符最后出现的位置
2. 遍历字符串，维护当前片段的结束位置
3. 当遍历到当前片段的结束位置时，可以进行切分

**算法流程：**
1. 第一次遍历：记录每个字符最后出现的位置
2. 第二次遍历：
   - 维护当前片段的结束位置
   - 如果当前字符的最后位置超过当前结束位置，更新结束位置
   - 当遍历到结束位置时，切分片段

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # 记录每个字符最后出现的位置
        last_occurrence = {char: i for i, char in enumerate(s)}
        
        result = []
        start = 0
        end = 0
        
        for i, char in enumerate(s):
            # 更新当前片段的结束位置
            end = max(end, last_occurrence[char])
            
            # 如果到达当前片段的结束位置，进行切分
            if i == end:
                result.append(end - start + 1)
                start = i + 1
        
        return result
```

### 方法二：详细注释版（易理解）

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        """
        划分字符串，使得每个字母只出现在一个片段中
        
        思路：
        1. 找到每个字符最后出现的位置
        2. 贪心地选择片段的结束位置
        3. 片段的结束位置是该片段内所有字符的最后位置的最大值
        """
        # 步骤 1: 记录每个字符最后出现的位置
        last_position = {}
        for index, character in enumerate(s):
            last_position[character] = index
        
        # 步骤 2: 遍历字符串，划分片段
        partitions = []
        partition_start = 0  # 当前片段的起始位置
        partition_end = 0    # 当前片段的结束位置
        
        for current_index in range(len(s)):
            current_char = s[current_index]
            
            # 当前字符的最后位置
            char_last_pos = last_position[current_char]
            
            # 更新当前片段的结束位置
            # 必须包含当前字符的所有出现
            partition_end = max(partition_end, char_last_pos)
            
            # 如果当前位置就是片段的结束位置
            # 说明可以在这里切分
            if current_index == partition_end:
                # 计算片段长度
                length = partition_end - partition_start + 1
                partitions.append(length)
                
                # 更新下一个片段的起始位置
                partition_start = current_index + 1
        
        return partitions
```

### 方法三：使用数组代替字典

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # 使用数组记录每个字符最后出现的位置
        last = [0] * 26
        
        for i, char in enumerate(s):
            last[ord(char) - ord('a')] = i
        
        result = []
        start = 0
        end = 0
        
        for i, char in enumerate(s):
            end = max(end, last[ord(char) - ord('a')])
            
            if i == end:
                result.append(end - start + 1)
                start = i + 1
        
        return result
```

### 方法四：一次遍历

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # 找到每个字符最后出现的位置
        last = {c: i for i, c in enumerate(s)}
        
        ans = []
        j = anchor = 0
        
        for i, c in enumerate(s):
            j = max(j, last[c])
            if i == j:
                ans.append(i - anchor + 1)
                anchor = i + 1
        
        return ans
```

### 方法五：函数式编程风格

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        from itertools import groupby
        
        # 记录最后位置
        last = {c: i for i, c in enumerate(s)}
        
        # 为每个位置计算其所在片段的结束位置
        end_positions = []
        current_end = 0
        
        for i, c in enumerate(s):
            current_end = max(current_end, last[c])
            end_positions.append(current_end)
        
        # 按结束位置分组，计算每组长度
        result = []
        for end, group in groupby(enumerate(end_positions), key=lambda x: x[1]):
            group_list = list(group)
            result.append(len(group_list))
        
        return result
```

## 复杂度分析

- **时间复杂度：** O(n)，需要两次遍历字符串
- **空间复杂度：** O(1)，最多存储 26 个字母的位置

## 关键点总结

1. **贪心策略：** 尽可能早地切分片段
2. **最后位置：** 记录每个字符的最后出现位置是关键
3. **动态更新：** 片段结束位置需要动态更新
4. **切分时机：** 当到达当前片段结束位置时切分
5. **片段独立：** 每个片段内的字符不会在其他片段出现

## 易错点

1. **结束位置更新：** 要取所有已遍历字符的最后位置的最大值
2. **切分条件：** 是 `i == end`，不是 `i >= end`
3. **起始位置更新：** 新片段从 `i + 1` 开始
4. **长度计算：** 长度是 `end - start + 1`
5. **边界情况：** 所有字符都不同或所有字符都相同的情况
