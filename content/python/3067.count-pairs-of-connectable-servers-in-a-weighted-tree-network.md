## 题目描述

给你一棵有 `n` 个节点的带权无向树，节点编号 0 到 n-1，以及一个正整数 `signalSpeed`。

如果两个节点 `a` 和 `b` 通过节点 `c` 可连接，需满足：
- `c` 在 `a` 和 `b` 的路径上
- `dist(a, c)` 能被 `signalSpeed` 整除
- `dist(b, c)` 能被 `signalSpeed` 整除

返回数组 `count`，`count[i]` 为通过节点 `i` 可连接的服务器对数。

**提示：**
- `2 <= n <= 1000`
- `edges[i].length == 3`
- `1 <= signalSpeed <= 10^6`

## 解题思路

对每个节点 `c`，枚举以 `c` 为"中转点"的节点对：
1. 以 `c` 为根，对每个相邻节点 `v` 进行 DFS，统计子树中距离 `c` 为 `signalSpeed` 的倍数的节点个数
2. 利用乘法原理，不同子树中的节点可以配对

## Python 代码实现

### 方法一：枚举中转点 + DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairsOfConnectableServers(self, edges: List[List[int]], signalSpeed: int) -> List[int]:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        def dfs(node: int, parent: int, dist: int) -> int:
            # 统计以 node 为根的子树中，距离中转点为 signalSpeed 倍数的节点数
            count = 1 if dist % signalSpeed == 0 else 0
            for neighbor, weight in graph[node]:
                if neighbor != parent:
                    count += dfs(neighbor, node, dist + weight)
            return count

        result = [0] * n
        for c in range(n):
            # 枚举以 c 为中转点
            total = 0
            prev_count = 0
            for neighbor, weight in graph[c]:
                # 统计通过这条边可达的节点中，与 c 距离为 signalSpeed 倍数的节点数
                cnt = dfs(neighbor, c, weight)
                # 与之前的子树配对
                result[c] += prev_count * cnt
                prev_count += cnt

        return result
```

### 方法二：更清晰的两步实现

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairsOfConnectableServers(self, edges: List[List[int]], signalSpeed: int) -> List[int]:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        def count_valid(start: int, parent: int, dist: int) -> int:
            """统计子树中距 parent 为 signalSpeed 倍数的节点数"""
            c = 1 if dist % signalSpeed == 0 else 0
            for nb, wt in graph[start]:
                if nb != parent:
                    c += count_valid(nb, start, dist + wt)
            return c

        ans = [0] * n
        for c in range(n):
            groups = []
            for nb, wt in graph[c]:
                groups.append(count_valid(nb, c, wt))

            # 不同组的节点配对
            total = 0
            prefix = 0
            for g in groups:
                total += prefix * g
                prefix += g
            ans[c] = total

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举 n 个中转点，每次 DFS O(n)
- 空间复杂度：O(n)，递归栈和图

## 关键点总结

1. 枚举每个节点 `c` 作为中转点
2. 对 `c` 的每个子树，统计距离为 `signalSpeed` 倍数的节点数
3. 不同子树的节点可以配对（乘法原理，用前缀和累计）

## 易错点

1. 节点 `c` 本身的距离为 0（0 是任何数的倍数），但通常只考虑 `a != c` 和 `b != c`
2. 不同子树中的节点才能配对（需要通过 `c` 中转）
3. 配对时使用前缀积累方法避免重复计数
