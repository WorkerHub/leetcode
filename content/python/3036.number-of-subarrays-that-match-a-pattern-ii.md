## 题目描述

与 3034 相同题意，但 `n` 和 `m` 扩大到 `10^6`，必须使用 O(n) 的 KMP 算法。

**提示：**
- `2 <= n <= 10^6`
- `1 <= m <= n - 1`

## 解题思路

与 3034 完全相同，将 `nums` 转换为差分符号数组，然后用 KMP 算法匹配 `pattern`。

由于数据量大，必须用 KMP（O(n+m)）而不能用暴力（O(nm)）。

## Python 代码实现

### 方法一：KMP（推荐）

```python
from typing import List

class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        n = len(nums)
        m = len(pattern)

        def sign(x: int) -> int:
            if x > 0: return 1
            if x < 0: return -1
            return 0

        # 构建差分符号数组
        diff = [sign(nums[i+1] - nums[i]) for i in range(n-1)]

        # 构建 KMP 失配表
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and pattern[i] != pattern[j]:
                j = fail[j-1]
            if pattern[i] == pattern[j]:
                j += 1
            fail[i] = j

        # KMP 匹配
        count = 0
        j = 0
        for x in diff:
            while j > 0 and x != pattern[j]:
                j = fail[j-1]
            if x == pattern[j]:
                j += 1
            if j == m:
                count += 1
                j = fail[j-1]

        return count
```

### 方法二：Z 函数方法

```python
from typing import List

class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        n = len(nums)
        m = len(pattern)

        def sign(x):
            return (x > 0) - (x < 0)

        diff = [sign(nums[i+1] - nums[i]) for i in range(n-1)]

        # 拼接 pattern + separator + diff，计算 Z 函数
        # 分隔符用 2（不在 {-1, 0, 1} 中）
        combined = pattern + [2] + diff

        def z_function(arr):
            n = len(arr)
            z = [0] * n
            z[0] = n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and arr[z[i]] == arr[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z

        z = z_function(combined)

        # 在 diff 部分（从位置 m+1 开始）统计 z[i] >= m 的个数
        count = 0
        for i in range(m + 1, len(combined)):
            if z[i] >= m:
                count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. KMP 核心是失配函数（前缀函数），保证每个字符均摊 O(1)
2. Z 函数方法通过拼接字符串同样达到 O(n+m)
3. 差分符号 `sign` 将数值比较转为 {-1, 0, 1} 的序列匹配

## 易错点

1. Z 函数方法中分隔符必须选择不在数组元素集合中的值
2. `diff` 长度为 `n-1`，不是 `n`
