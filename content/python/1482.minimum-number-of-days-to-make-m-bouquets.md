## 题目描述

给你一个整数数组 `bloomDay`，以及两个整数 `m` 和 `k`。

现需制作 `m` 束花。制作每束花需要使用花园中 **相邻的 `k` 朵花**，花园中有 `n` 朵花，第 `i` 朵花会在 `bloomDay[i]` 那天**盛开**，每朵花只能用于一束花。

请你返回从第几天开始可以制作出 `m` 束花，如果不可能，则返回 `-1`。

**示例 1：**

```
输入：bloomDay = [1,10,3,10,2], m = 3, k = 1
输出：3
解释：第 1 天：[x,_,_,_,_]（只有第1朵开）
     第 2 天：[x,_,_,_,x]
     第 3 天：[x,_,x,_,x] → 可以制作 3 束（每束1朵），第3天完成
```

**示例 2：**

```
输入：bloomDay = [1,10,3,10,2], m = 3, k = 2
输出：-1
解释：需要 3*2=6 朵花，但只有 5 朵，不可能。
```

**示例 3：**

```
输入：bloomDay = [7,7,7,7,12,7,7], m = 2, k = 3
输出：12
解释：第 7 天：[x,x,x,x,_,x,x]，可以选前3朵或后3朵，只有1束，不够。
     第 12 天：所有花开，可制作 2 束（下标0-2和下标4-6），第12天完成。
```

**提示：**
- `bloomDay.length == n`
- `1 <= n <= 10^5`
- `1 <= bloomDay[i] <= 10^9`
- `1 <= m <= 10^6`
- `1 <= k <= n`

---

## 解题思路

**二分答案（答案二分法）：**

**关键观察：**
- 天数越多，能制作的花束数量越多（单调性）。
- 所以可以对"天数"进行二分查找。

**二分范围：**
- 左边界 `lo = 1`（最少1天）
- 右边界 `hi = max(bloomDay)`（最多等所有花开）

**判断函数 `can_make(day)`：**
对于给定天数 `day`，统计能制作的花束数量：
- 遍历 `bloomDay`，统计已开的相邻花（`bloomDay[i] <= day`）的连续段长度。
- 每段连续 `k` 朵就能制作一束花（整除）。
- 如果总花束数 >= m，返回 True。

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def minDays(self, bloomDay: List[int], m: int, k: int) -> int:
        n = len(bloomDay)

        # 特判：如果花的数量不够，直接返回 -1
        if m * k > n:
            return -1

        def can_make(day: int) -> bool:
            """判断在第 day 天能否制作出 m 束花"""
            bouquets = 0   # 可以制作的花束数
            consecutive = 0  # 当前连续开放的花朵数

            for bloom in bloomDay:
                if bloom <= day:
                    consecutive += 1           # 这朵花已开放
                    if consecutive == k:
                        bouquets += 1          # 凑够 k 朵，制作一束
                        consecutive = 0        # 重新计数
                else:
                    consecutive = 0            # 花还没开，中断连续段

                if bouquets >= m:
                    return True  # 提前返回，剪枝

            return bouquets >= m

        # 二分查找最小天数
        lo, hi = 1, max(bloomDay)

        while lo < hi:
            mid = (lo + hi) // 2
            if can_make(mid):
                hi = mid  # mid 可以做到，尝试更小的天数
            else:
                lo = mid + 1  # mid 不够，增加天数

        return lo
```

### 方法二：二分 + 简化判断函数

```python
from typing import List

class Solution:
    def minDays(self, bloomDay: List[int], m: int, k: int) -> int:
        n = len(bloomDay)
        if m * k > n:
            return -1

        def count_bouquets(day: int) -> int:
            """统计第 day 天能制作的花束总数"""
            total = 0
            consec = 0
            for d in bloomDay:
                if d <= day:
                    consec += 1
                    total += consec // k  # 每 k 朵连续花制作一束
                    consec %= k           # 余下的花留到下一束
                else:
                    consec = 0
            return total

        lo, hi = min(bloomDay), max(bloomDay)

        # 如果在最大天数时都不够，返回 -1（已在前面特判）
        while lo < hi:
            mid = (lo + hi) // 2
            if count_bouquets(mid) >= m:
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法三：暴力法（仅用于对比理解）

```python
from typing import List

class Solution:
    def minDays(self, bloomDay: List[int], m: int, k: int) -> int:
        n = len(bloomDay)
        if m * k > n:
            return -1

        # 对每一天枚举（时间复杂度过高，仅作演示）
        for day in range(1, max(bloomDay) + 1):
            bouquets = 0
            consec = 0
            for b in bloomDay:
                if b <= day:
                    consec += 1
                    if consec == k:
                        bouquets += 1
                        consec = 0
                else:
                    consec = 0
            if bouquets >= m:
                return day

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(n log D)，D=max(bloomDay) | O(1) |
| 暴力 | O(n * D) | O(1) |

- D = max(bloomDay) <= 10^9，但二分只需 log2(10^9) ≈ 30 次迭代。
- 每次判断 O(n)，总体 O(n * 30) = O(n log D)，非常高效。

## 关键点总结

1. **单调性是二分答案的前提**：天数越多，能制作的花束越多（或相等），满足单调性。
2. 二分区间：`[1, max(bloomDay)]` 或 `[min(bloomDay), max(bloomDay)]`。
3. 判断函数：统计连续 `k` 朵已开放的花能组成多少束，≥ m 则可行。
4. **不可能的特判**：若 `m * k > n`，花的总数不够，直接返回 -1。

---

## 易错点

- **连续相邻**：必须是连续相邻的 k 朵花，不能跳过中间未开的花。
- **特判溢出**：`m * k` 可能很大（m=10^6, k=n=10^5），在 Python 中不会整数溢出，但在其他语言要注意。
- **二分边界**：结束条件 `lo < hi`，最终 `lo == hi` 即为答案。
