## 题目描述

给你一个字符串 `word` 和一个正整数 `numFriends`。

Alice 正在为她的 `numFriends` 个朋友组织一个游戏。游戏中，将 `word` 分割成 `numFriends` 个**非空**字符串，每次分割产生的字符串放入一个盒子中。

Alice 希望找到盒子中**字典序最大**的字符串。

返回所有可能分割方式中，**字典序最大**的字符串。

**示例 1：**

```
输入：word = "dbca", numFriends = 2
输出："dbc"
解释：所有可能的分割：["d","bca"], ["db","ca"], ["dbc","a"]
盒子中最大的字符串是 "dbc"
```

**示例 2：**

```
输入：word = "gggg", numFriends = 4
输出："g"
```

**提示：**
- `1 <= word.length <= 5000`
- `1 <= numFriends <= word.length`
- `word` 只包含小写英文字母

## 解题思路

关键观察：
1. 如果 `numFriends == 1`，整个字符串就是答案
2. 否则，一个分段的最大长度是 `len(word) - numFriends + 1`（其余 numFriends-1 个分段各取一个字符）
3. 我们要找起始位置 `i`，使得 `word[i: i + max_len]` 字典序最大
4. 使用双指针比较所有候选起始位置

枚举每个可能的起始位置 `i`（0 到 len(word)-1），对于每个 `i`，可取的最大长度为 `min(len(word) - numFriends + 1, len(word) - i)`，然后找字典序最大的子串。

## Python 代码实现

### 方法一：枚举起始位置（推荐）

```python
class Solution:
    def answerString(self, word: str, numFriends: int) -> str:
        n = len(word)

        # 特殊情况：只有一个朋友
        if numFriends == 1:
            return word

        # 每个分段的最大可能长度
        max_len = n - numFriends + 1

        result = ""
        for i in range(n):
            # 从位置 i 开始，最多可取 max_len 个字符
            # 但不能超过字符串末尾
            candidate = word[i: i + max_len]
            if candidate > result:
                result = candidate

        return result
```

### 方法二：双指针找最大起始位置

```python
class Solution:
    def answerString(self, word: str, numFriends: int) -> str:
        n = len(word)

        if numFriends == 1:
            return word

        max_len = n - numFriends + 1

        # 找字典序最大的起始位置
        best_start = 0
        i = 0
        j = 1

        while j < n:
            k = 0
            # 比较从 i+k 和 j+k 开始的字符
            while j + k < n and word[i + k] == word[j + k]:
                k += 1

            if j + k < n and word[j + k] > word[i + k]:
                # j 开始的更大
                best_start = j
                i = j + k + 1
                j = i + 1
            else:
                j += k + 1

            if i >= j:
                j = i + 1

        return word[best_start: best_start + max_len]
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n^2)，枚举每个起始位置并进行字符串比较
  - 空间复杂度：O(n)，存储候选子串

- 方法二（双指针）：
  - 时间复杂度：O(n)，线性扫描
  - 空间复杂度：O(1)

## 关键点总结

1. 某个分段的最大长度被限制为 `n - numFriends + 1`
2. `numFriends == 1` 时直接返回整个字符串
3. 字典序最大意味着要找最大的前缀字符，再依次比较后续字符

## 易错点

1. 忘记处理 `numFriends == 1` 的特殊情况
2. 候选子串长度的上限是 `min(max_len, n - i)`，防止越界
3. Python 字符串切片不会越界，但逻辑上要理解限制
