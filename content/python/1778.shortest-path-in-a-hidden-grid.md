## 题目描述

这是一道**交互题**。

有一个 `m x n` 的隐藏网格，你的初始位置在 `(0, 0)`（不保证起点在哪里，但你的初始位置已知）。终点是一个特殊格，你需要找到从初始位置到终点的最短路径。

实现接口：
- `boolean canMove(String direction)`：如果能向该方向移动（格子存在且可通行），则移动并返回 `true`，否则返回 `false`（你仍在原位）。方向为 `"U"`, `"D"`, `"L"`, `"R"`。
- `boolean isTarget()`：如果当前位置是终点，返回 `true`。

**返回**：从起点到终点的最短路径长度，如果不可达返回 `-1`。

## 解题思路

分两步：
1. **DFS 探图**：从起点出发，DFS 遍历所有可达格子，建立已知图
2. **BFS 求最短路**：在建立的图上 BFS 求起点到终点的最短路

**注意**：`canMove` 会真正移动，需要回溯（移动后要移回来）。

## 代码实现

### 方法一：DFS 建图 + BFS 最短路

```python
from collections import deque

# 接口定义（实际提交时由平台提供）
class GridMaster:
    def canMove(self, direction: str) -> bool: ...
    def isTarget(self) -> bool: ...

class Solution:
    def findShortestPath(self, master: 'GridMaster') -> int:
        # 方向映射
        dirs = {
            'U': (-1, 0), 'D': (1, 0),
            'L': (0, -1), 'R': (0, 1)
        }
        # 反方向
        opposite = {'U': 'D', 'D': 'U', 'L': 'R', 'R': 'L'}
        
        # DFS 探图，建立可通行格子集合
        visited = set()
        target = [None]
        
        def dfs(r, c):
            visited.add((r, c))
            if master.isTarget():
                target[0] = (r, c)
            
            for direction, (dr, dc) in dirs.items():
                nr, nc = r + dr, c + dc
                if (nr, nc) not in visited and master.canMove(direction):
                    dfs(nr, nc)
                    # 回溯：移回原位
                    master.canMove(opposite[direction])
        
        dfs(0, 0)
        
        if target[0] is None:
            return -1
        
        # BFS 求最短路
        queue = deque([(0, 0, 0)])
        seen = {(0, 0)}
        
        while queue:
            r, c, dist = queue.popleft()
            if (r, c) == target[0]:
                return dist
            for dr, dc in dirs.values():
                nr, nc = r + dr, c + dc
                if (nr, nc) not in seen and (nr, nc) in visited:
                    seen.add((nr, nc))
                    queue.append((nr, nc, dist + 1))
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(m * n) DFS 探图，O(m * n) BFS 最短路
- **空间复杂度**：O(m * n)，存储已访问格子

## 关键点总结

1. 先用 DFS 探索所有可达格子（带回溯）
2. 再用 BFS 在已知图上求最短路
3. 回溯时通过反方向移动回原位

## 易错点

- DFS 后必须回溯（移回原位），否则位置错乱
- 终点只有一个，DFS 时记录下来
