## 题目描述

给你一个整数数组 `nums`，返回**元素和为奇数**的非空子序列的数量。

由于答案可能很大，返回对 `10^9 + 7` 取模的结果。

**示例 1：**
```
输入：nums = [1,1,1]
输出：4
解释：[1],[1],[1],[1,1,1] 和为奇数（各有不同下标的单元素，以及三个元素的子序列）
实际：单个 1 有 3 个，三元素子序列 1 个，共 4 个。
```

**示例 2：**
```
输入：nums = [1,2,3]
输出：4
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

设奇数个数为 `odd`，偶数个数为 `even`。

元素和为奇数的子序列，必须包含**奇数个**奇数元素（1,3,5,...个）。

对于包含 `k` 个奇数（k 为奇数）和任意个偶数的子序列，数量为：
- `C(odd, k) * 2^even`（奇数中选 k 个，偶数任意选）

总和 = `2^even * sum(C(odd, k) for k in 1,3,5,...)`

由二项式定理：`sum(C(odd, k) for k odd) = 2^(odd-1)`（当 odd > 0）

所以答案 = `2^even * 2^(odd-1)` = `2^(odd + even - 1)` = `2^(n-1)`（当 odd > 0）

当 odd = 0 时，答案为 0（全是偶数，和不可能为奇数）。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
from typing import List

class Solution:
    def subsequenceCount(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        odd = sum(1 for x in nums if x % 2 == 1)
        
        if odd == 0:
            return 0
        
        # 答案 = 2^(n-1)
        return pow(2, n - 1, MOD)
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def subsequenceCount(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        # dp_odd: 和为奇数的子序列数量
        # dp_even: 和为偶数的子序列数量（不含空）
        dp_odd = 0
        dp_even = 0
        
        for x in nums:
            if x % 2 == 1:
                # 加入奇数：奇+偶=奇，偶+奇=奇，新增单元素奇
                new_odd = dp_even + 1  # 原偶数子序列加上 x，或单独 x
                new_even = dp_odd     # 原奇数子序列加上 x
            else:
                # 加入偶数：奇+偶=奇，偶+偶=偶
                new_odd = dp_odd
                new_even = dp_even + 1
            dp_odd = (dp_odd + new_odd) % MOD
            dp_even = (dp_even + new_even) % MOD
        
        return dp_odd
```

## 复杂度分析

- 方法一：O(n) 统计奇数个数，O(log n) 快速幂
- 方法二：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 和为奇数 = 子序列中奇数个数为奇数
2. 数学推导：答案 = `2^(n-1)`（当有奇数元素时）
3. DP 方法更直观，逐个考虑每个元素的加入

## 易错点

1. 当数组中没有奇数时，所有子序列和为偶数，答案为 0
2. 空子序列不计入（dp_even 初始为 0 不含空）
