## 题目描述

给你一个由若干 `0` 和 `1` 组成的数组 `nums`，以及一个整数 `k`。
如果在某个操作中，你选择了相邻的两个不同元素进行交换，则称这次操作为一次**相邻交换**。
请你计算使数组中恰好有 `k` 个连续 `1` 所需的最少相邻交换次数。

**示例 1：**
```
输入：nums = [1,0,0,1,0,1], k = 2
输出：1
```

**示例 2：**
```
输入：nums = [1,0,0,0,0,0,1,1], k = 3
输出：5
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= k <= sum(nums)`

## 解题思路

**核心转化：**
1. 提取所有 `1` 的下标，设为 `pos` 数组
2. 问题转化为：从 `pos` 中选择 `k` 个连续的下标，使这 `k` 个 `1` 聚集在一起所需的最少移动次数

**消除偏移量：**
设选取的是 `pos[i], pos[i+1], ..., pos[i+k-1]`，令 `p[j] = pos[j] - j`（消去自然间距），则这 `k` 个数移动到一起的最小代价等于：以中间元素为中心，移动的总距离（类似「最小移动使数组各元素相等」的变形）。

**滑动窗口 + 前缀和：**
对每个长度为 `k` 的窗口，用中位数贪心+前缀和计算代价，滑动窗口维护最小值。

## 代码实现

### 方法一：前缀和 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minMoves(self, nums: List[int], k: int) -> int:
        # 提取所有1的下标
        pos = [i for i, v in enumerate(nums) if v == 1]
        m = len(pos)
        
        # 消除偏移：p[j] = pos[j] - j
        # 原理：将k个1聚在一起，自然会占k个连续位置，减去j消除这种自然间距
        p = [pos[j] - j for j in range(m)]
        
        # 构建前缀和
        prefix = [0] * (m + 1)
        for i in range(m):
            prefix[i + 1] = prefix[i] + p[i]
        
        ans = float('inf')
        
        # 滑动窗口，枚举每个长度为k的窗口
        for i in range(m - k + 1):
            # 窗口 [i, i+k-1]，中位数索引
            mid = i + k // 2
            # 以 p[mid] 为集合点
            center = p[mid]
            
            # 右半部分（包含mid）的代价
            right_sum = prefix[i + k] - prefix[mid]
            right_cost = right_sum - center * (i + k - mid)
            
            # 左半部分的代价
            left_sum = prefix[mid] - prefix[i]
            left_cost = center * (mid - i) - left_sum
            
            ans = min(ans, left_cost + right_cost)
        
        return ans
```

### 方法二：暴力枚举（仅适用于小数据，便于理解）

```python
from typing import List

class Solution:
    def minMoves(self, nums: List[int], k: int) -> int:
        pos = [i for i, v in enumerate(nums) if v == 1]
        m = len(pos)
        
        if k == 1:
            return 0
        
        # p[j] = pos[j] - j 消除偏移
        p = [pos[j] - j for j in range(m)]
        
        ans = float('inf')
        
        for i in range(m - k + 1):
            # 当前窗口 p[i:i+k]
            window = p[i:i + k]
            # 以中位数为目标，计算总移动代价
            median = window[k // 2]
            cost = sum(abs(x - median) for x in window)
            ans = min(ans, cost)
        
        return ans
```

## 复杂度分析

- **方法一**：
  - 时间复杂度：O(n)，提取下标 O(n)，前缀和 O(m)，滑动窗口 O(m)
  - 空间复杂度：O(m)，m 为 1 的数量
- **方法二**：
  - 时间复杂度：O(m * k)，暴力枚举
  - 空间复杂度：O(m)

## 关键点总结

1. 将 1 的下标提取出来，问题转化为选 k 个连续 1 聚集的最少移动
2. `p[j] = pos[j] - j` 消除偏移后，问题变为找一个值使所有元素移动代价最小（中位数贪心）
3. 用前缀和加速每个窗口的代价计算

## 易错点

- 中位数选取：偶数长度时选左中位数或右中位数均可，但要保持一致
- 前缀和的边界处理，注意下标从 0 还是 1 开始
