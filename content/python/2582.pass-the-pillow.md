## 题目描述

`n` 个人站成一排，编号 1 到 n，初始抱枕的人是编号 1。

每秒钟，抱枕从当前持有者传给旁边的人，若到达端点则反向传递。

经过 `time` 秒后，返回持有抱枕的人的编号。

**示例 1：**

```
输入：n = 4, time = 5
输出：2
解释：1→2→3→4→3→2，第 5 秒时是编号 2。
```

**示例 2：**

```
输入：n = 3, time = 2
输出：3
```

**提示：**

- `2 <= n <= 1000`
- `1 <= time <= 1000`

## 解题思路

每个完整"往返"周期长度为 `2*(n-1)`。对 `time` 取模后，确定在当前周期内的位置。

若余数 <= n-1（正向），则位置为 `1 + 余数`；否则（反向），位置为 `n - (余数 - (n-1))` = `2n - 1 - 余数`。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def passThePillow(self, n: int, time: int) -> int:
        cycle = 2 * (n - 1)
        r = time % cycle
        if r <= n - 1:
            return 1 + r
        else:
            return 2 * n - 1 - r
```

### 方法二：模拟

```python
class Solution:
    def passThePillow(self, n: int, time: int) -> int:
        pos = 1
        direction = 1  # 1 表示向右，-1 表示向左
        for _ in range(time):
            pos += direction
            if pos == n:
                direction = -1
            elif pos == 1:
                direction = 1
        return pos
```

## 复杂度分析

- 方法一时间复杂度：O(1)
- 方法二时间复杂度：O(time)
- 空间复杂度：O(1)

## 关键点总结

1. 周期为 `2*(n-1)`，一个完整往返
2. 取模后根据余数判断正向还是反向
3. 反向时位置 = `2n - 1 - 余数`

## 易错点

1. 余数 = n-1 时恰好在右端，归属于正向段
2. 位置编号从 1 开始，公式中 +1 调整
3. 模拟时要在到达端点后立即改变方向
