## 题目描述

给定一个字符串数组 `wordsDict` 和两个已经存在于该数组中的不同的字符串 `word1` 和 `word2`，返回列表中这两个单词之间的最短距离。

**示例 1：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "coding", word2 = "practice"
输出: 3
```

**示例 2：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "makes", word2 = "coding"
输出: 1
```

**提示：**
- 1 <= wordsDict.length <= 3 * 10^4
- 1 <= wordsDict[i].length <= 10
- wordsDict[i] 由小写英文字母组成
- word1 和 word2 在 wordsDict 中
- word1 != word2

## 解题思路

这道题要求找到两个单词在数组中最近的距离，核心思路是**记录两个单词出现的位置，然后计算最小距离**。

**基本思路：**
1. **暴力法**：找出所有 word1 和 word2 的位置，两两计算距离，取最小值
2. **双指针一次遍历**：遍历数组，记录最近出现的 word1 和 word2 的位置，动态更新最小距离

**关键观察：**
- 只需要记录最近一次出现的位置，不需要记录所有位置
- 每次遇到 word1 或 word2 时，如果另一个单词已经出现过，就可以计算距离
- 使用两个指针分别记录 word1 和 word2 最近出现的位置

**优化思路：**
- 一次遍历就能得到结果，时间复杂度 O(n)
- 只需要常量空间存储两个位置

## Python 代码实现

### 方法一：暴力法（容易理解）

```python
from typing import List

class Solution:
    def shortestDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        找出所有位置，两两计算距离
        时间复杂度：O(n^2)，最坏情况下所有单词都是 word1 或 word2
        空间复杂度：O(n)，存储所有位置
        """
        # 收集 word1 和 word2 的所有位置
        positions1 = []
        positions2 = []
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                positions1.append(i)
            elif word == word2:
                positions2.append(i)
        
        # 计算最小距离
        min_distance = float('inf')
        for pos1 in positions1:
            for pos2 in positions2:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法二：双指针一次遍历（推荐）⭐

```python
from typing import List

class Solution:
    def shortestDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        一次遍历，动态更新最小距离
        时间复杂度：O(n)，遍历一次数组
        空间复杂度：O(1)，只需两个变量
        """
        min_distance = float('inf')
        pos1 = -1  # word1 最近出现的位置
        pos2 = -1  # word2 最近出现的位置
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                pos1 = i
                # 如果 word2 已经出现过，计算距离
                if pos2 != -1:
                    min_distance = min(min_distance, pos1 - pos2)
            elif word == word2:
                pos2 = i
                # 如果 word1 已经出现过，计算距离
                if pos1 != -1:
                    min_distance = min(min_distance, pos2 - pos1)
        
        return min_distance
```

### 方法三：优化的双指针（更简洁）⭐

```python
from typing import List

class Solution:
    def shortestDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        简化版双指针
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = len(wordsDict)
        pos1, pos2 = -1, -1
        
        for i, word in enumerate(wordsDict):
            if word == word1:
                pos1 = i
            elif word == word2:
                pos2 = i
            
            # 只要两个位置都有效，就更新最小距离
            if pos1 != -1 and pos2 != -1:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法四：单指针法（最优化）

```python
from typing import List

class Solution:
    def shortestDistance(self, wordsDict: List[str], word1: str, word2: str) -> int:
        """
        使用单个变量记录上一个匹配单词的位置
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        min_distance = len(wordsDict)
        prev_pos = -1  # 上一个匹配单词的位置
        prev_word = None  # 上一个匹配的是哪个单词
        
        for i, word in enumerate(wordsDict):
            if word == word1 or word == word2:
                # 如果上一个匹配的单词与当前不同，计算距离
                if prev_word is not None and prev_word != word:
                    min_distance = min(min_distance, i - prev_pos)
                
                # 更新上一个匹配的信息
                prev_pos = i
                prev_word = word
        
        return min_distance
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力法 | O(n^2) | O(n) | 需要存储所有位置 |
| 双指针（方法二/三） | O(n) | O(1) | 推荐，清晰易懂 |
| 单指针（方法四） | O(n) | O(1) | 最优化，代码最简洁 |

## 图解示例

以 `wordsDict = ["practice", "makes", "perfect", "coding", "makes"]`, `word1 = "coding"`, `word2 = "practice"` 为例：

```
索引:   0          1       2         3        4
单词: practice   makes  perfect  coding   makes

遍历过程（方法二）：

i=0: word="practice" == word2
     pos2 = 0
     pos1 = -1 (未出现)
     不计算距离

i=1: word="makes" (不匹配)
     跳过

i=2: word="perfect" (不匹配)
     跳过

i=3: word="coding" == word1
     pos1 = 3
     pos2 = 0 (已出现)
     min_distance = min(∞, 3-0) = 3

i=4: word="makes" (不匹配)
     跳过

结果：3
```

再看 `word1 = "makes"`, `word2 = "coding"`：

```
i=0: "practice" (不匹配)
i=1: "makes" == word1, pos1=1
i=2: "perfect" (不匹配)
i=3: "coding" == word2, pos2=3
     min_distance = min(∞, |3-1|) = 2
i=4: "makes" == word1, pos1=4
     min_distance = min(2, |4-3|) = 1

结果：1
```

## 关键点总结

1. **双指针思想**：分别记录两个单词最近出现的位置
2. **动态更新**：每次遇到目标单词就更新位置并计算距离
3. **初始值设置**：位置初始化为 -1，表示未出现
4. **距离计算**：只有两个位置都有效（!= -1）时才计算
5. **一次遍历**：无需记录所有位置，只需记录最近的位置

## 易错点

1. **初始值**：位置初始化为 -1 而不是 0，因为 0 是有效索引
2. **距离公式**：由于遍历是从左到右，且总是新位置 - 旧位置，可以不用 abs()
3. **边界检查**：计算距离前要确保两个位置都有效
4. **最小值初始化**：可以用 `float('inf')` 或 `len(wordsDict)`
5. **相同单词**：题目保证 word1 != word2，所以不需要处理这种情况
