## 题目描述

请你设计一个支持下述操作的栈。

实现自定义栈类 `CustomStack`：

- `CustomStack(int maxSize)`：用 `maxSize` 初始化对象，`maxSize` 是栈中最多能容纳的元素数量，栈在增长到 `maxSize` 之后则不支持 `push`。
- `void push(int x)`：如果栈还未增长到 `maxSize`，就将 `x` 添加到栈顶。
- `int pop()`：弹出栈顶元素，并返回栈顶的值，或栈为空时返回 `-1`。
- `void increment(int k, int val)`：栈底的 `k` 个元素的值都增加 `val`。如果栈中元素总数小于 `k`，则栈中的所有元素都增加 `val`。

**示例：**
```
输入：
["CustomStack","push","push","pop","push","push","push","increment","increment","pop","pop","pop","pop"]
[[3],[1],[2],[],[2],[3],[4],[5,100],[2,100],[],[],[],[]]

输出：
[null,null,null,2,null,null,null,null,null,103,202,201,-1]

解释：
CustomStack stk = new CustomStack(3); // 栈是空的 []
stk.push(1);   // 栈变为 [1]
stk.push(2);   // 栈变为 [1, 2]
stk.pop();     // 返回 2 → 栈变为 [1]
stk.push(2);   // 栈变为 [1, 2]
stk.push(3);   // 栈变为 [1, 2, 3]
stk.push(4);   // 栈已满，不执行 → 栈仍为 [1, 2, 3]
stk.increment(5, 100); // 栈变为 [101, 102, 103]（底部5个都加100，但只有3个）
stk.increment(2, 100); // 栈变为 [201, 202, 103]（底部2个加100）
stk.pop();     // 返回 103 → 栈变为 [201, 202]
stk.pop();     // 返回 202 → 栈变为 [201]
stk.pop();     // 返回 201 → 栈变为 []
stk.pop();     // 返回 -1（栈为空）
```

**提示：**
- `1 <= maxSize <= 1000`
- `1 <= x <= 1000`
- `1 <= k <= 1000`
- `0 <= val <= 100`
- 最多调用 1000 次 `increment`、`push` 和 `pop` 各自的方法

## 解题思路

### 方法一：简单数组模拟（直观但 increment O(k)）

直接用列表模拟栈，push/pop O(1)，increment 需要遍历前 k 个元素 O(k)。

### 方法二：惰性增量（Lazy Increment，推荐，全部 O(1)）

**核心思想：** 不立即对底部 k 个元素加值，而是用一个额外数组 `inc[]` 延迟记录增量：
- `inc[i]` 表示"当 `stack[i]` 被弹出时，需要额外加上 `inc[i]`"。
- `increment(k, val)` 只需将增量记录在 `inc[min(k,top)-1]` 处（影响范围的最顶部元素）。
- `pop()` 时，弹出 `stack[top] + inc[top]`，并将 `inc[top]` 向下传播给 `inc[top-1]`（底部元素同样累积这个增量）。

**为什么这样传播是对的？**
- 当执行 `increment(k, val)` 时，底部 k 个元素都要加 val。
- 可以把这个 val 先"积压"在第 k 个位置（index k-1）。
- 只有当第 k 个元素被 pop 时，才把这个积压传给下面（index k-2）。
- 这样，每个元素被 pop 时，一次性累加所有积压的增量。

## Python 代码实现

### 方法一：简单数组模拟

```python
class CustomStack:
    def __init__(self, maxSize: int):
        self.max_size = maxSize
        self.stack = []  # 用列表模拟栈

    def push(self, x: int) -> None:
        # 未达到最大容量时才入栈
        if len(self.stack) < self.max_size:
            self.stack.append(x)

    def pop(self) -> int:
        # 栈为空返回 -1
        if not self.stack:
            return -1
        return self.stack.pop()

    def increment(self, k: int, val: int) -> None:
        # 对底部 min(k, 当前元素数) 个元素加 val
        limit = min(k, len(self.stack))
        for i in range(limit):
            self.stack[i] += val
```

### 方法二：惰性增量（推荐，所有操作 O(1)）

```python
class CustomStack:
    def __init__(self, maxSize: int):
        self.max_size = maxSize
        self.stack = []        # 存储元素
        self.inc = []          # 惰性增量数组，inc[i] 表示栈第 i 层的待累加增量

    def push(self, x: int) -> None:
        if len(self.stack) < self.max_size:
            self.stack.append(x)
            self.inc.append(0)   # 新元素初始增量为0

    def pop(self) -> int:
        if not self.stack:
            return -1

        # 弹出当前栈顶，加上累积的增量
        val = self.stack.pop() + self.inc[-1]

        # 将当前层的增量向下传播（底部元素同样受这个增量影响）
        inc_val = self.inc.pop()
        if self.inc:
            self.inc[-1] += inc_val   # 传播给新的栈顶

        return val

    def increment(self, k: int, val: int) -> None:
        if self.stack:
            # 增量只记录在影响范围的最顶部元素（下标 min(k,top)-1）
            idx = min(k, len(self.stack)) - 1
            self.inc[idx] += val
```

## 复杂度分析

| 方法 | push | pop | increment |
|------|------|-----|-----------|
| 方法一（数组模拟） | O(1) | O(1) | O(k) |
| 方法二（惰性增量） | O(1) | O(1) | O(1) |

- **空间复杂度**：两种方法都是 O(maxSize)。

## 图解示例（惰性增量）

```
初始：stack=[], inc=[]

push(1): stack=[1], inc=[0]
push(2): stack=[1,2], inc=[0,0]
push(3): stack=[1,2,3], inc=[0,0,0]

increment(5, 100):
  idx = min(5,3)-1 = 2
  inc[2] += 100 → inc=[0,0,100]
  stack=[1,2,3], inc=[0,0,100]（底部3个将获得+100）

increment(2, 100):
  idx = min(2,3)-1 = 1
  inc[1] += 100 → inc=[0,100,100]
  stack=[1,2,3], inc=[0,100,100]（底部2个将获得+100）

pop():
  val = stack[-1] + inc[-1] = 3 + 100 = 103
  inc传播：inc[-1]=100 → inc[-2] += 100 → inc=[0,200]
  返回 103，stack=[1,2], inc=[0,200]

pop():
  val = 2 + 200 = 202
  inc传播：inc[-1]=200 → inc[-2] += 200 → inc=[200]
  返回 202，stack=[1], inc=[200]

pop():
  val = 1 + 200 = 201
  inc=[](空了，不需要传播)
  返回 201，stack=[], inc=[]
```

## 关键点总结

1. **惰性增量的核心**：`increment(k, val)` 只在下标 `min(k, top)-1` 处记录增量，不立即修改所有元素。
2. **pop 时传播增量**：弹出元素时，将当前层的增量传给下方元素（`inc[-2] += inc[-1]`），确保底部元素在未来 pop 时也能获得正确的增量。
3. **三个操作均 O(1)**：惰性增量将批量修改的代价分摊到每次 pop 中。
4. **inc 与 stack 保持同步**：push 时 inc 同步增加0，pop 时 inc 同步删除并传播。

## 易错点

1. **inc[idx] 的下标**：`increment(k, val)` 的影响范围是底部 `min(k, 当前大小)` 个元素，对应下标 `min(k, len)-1`。
2. **传播时机**：增量传播在 pop 时执行（`if self.inc: self.inc[-1] += inc_val`），若栈为空则不传播。
3. **不能直接修改 stack 中的值**：方法二的关键是所有增量存在 `inc` 中，`stack` 中存储原始值。
4. **方法一的 increment 遍历**：小数据量下方法一完全可以，但大数据（k 很大）时方法二明显更优。

1. **先掌握方法一**：最直观的数组模拟，适合理解题意和快速编码。
2. **惰性增量**是算法设计中的重要思想（类似于线段树的懒标记），将批量操作延迟到真正需要时才执行，摊还各操作的复杂度。
3. 类似思想在其他场景也有应用：
   - 线段树的 lazy propagation
   - 差分数组（批量区间修改）
