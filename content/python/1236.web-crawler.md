## 题目描述

给定一个链接 `startUrl` 和一个接口 `HtmlParser`，请你实现一个网络爬虫，爬取所有与 `startUrl` 有相同主机名的链接。

以任意顺序返回你的爬虫获取到的所有链接。

你的网络爬虫应当遵守如下规则：

- 从 `startUrl` 开始
- 调用 `HtmlParser.getUrls(url)` 来从一个URL中获取它指向的所有URL
- 不要爬取相同的URL两次
- 只爬取与 `startUrl` 有相同主机名的URL

如示例所示，所有URL都使用 HTTP 协议，不需要考虑端口号。

示例 1：
```
输入：
urls = [
  "http://news.yahoo.com",
  "http://news.yahoo.com/news",
  "http://news.yahoo.com/news/topics/",
  "http://news.google.com",
  "http://news.yahoo.com/us"
]
edges = [[2,0],[2,1],[3,2],[3,1],[0,4]]
startUrl = "http://news.yahoo.com/news/topics/"
输出：[
  "http://news.yahoo.com",
  "http://news.yahoo.com/news",
  "http://news.yahoo.com/news/topics/",
  "http://news.yahoo.com/us"
]
```

提示：
- `1 <= urls.length <= 1000`
- `1 <= urls[i].length <= 300`
- `startUrl` 是 `urls` 中的一个
- 所有URL都是有效的HTTP URL
- `HtmlParser.getUrls(url)` 返回 URL 对应网页的所有 URL

## 解题思路

这是一个图遍历问题，可以使用DFS或BFS解决。

核心步骤：
1. 从URL中提取主机名
2. 使用集合记录已访问的URL，避免重复爬取
3. 使用DFS或BFS遍历所有链接
4. 只处理与起始URL主机名相同的链接

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class HtmlParser:
    def getUrls(self, url: str) -> List[str]:
        pass

class Solution:
    def crawl(self, startUrl: str, htmlParser: HtmlParser) -> List[str]:
        """
        使用广度优先搜索爬取网页
        
        Args:
            startUrl: 起始URL
            htmlParser: HTML解析器接口
            
        Returns:
            所有相同主机名的URL列表
        """
        # 提取主机名
        def get_hostname(url: str) -> str:
            # http:// 之后，第一个 / 之前的部分
            # 去掉协议头
            url = url.replace('http://', '')
            # 找到第一个 / 的位置
            idx = url.find('/')
            if idx == -1:
                return url
            return url[:idx]
        
        hostname = get_hostname(startUrl)
        visited = {startUrl}
        queue = deque([startUrl])
        result = [startUrl]
        
        while queue:
            url = queue.popleft()
            
            # 获取当前URL的所有链接
            for next_url in htmlParser.getUrls(url):
                # 如果未访问且主机名相同
                if next_url not in visited and get_hostname(next_url) == hostname:
                    visited.add(next_url)
                    queue.append(next_url)
                    result.append(next_url)
        
        return result
```

### 方法二：DFS

```python
from typing import List

class Solution:
    def crawl(self, startUrl: str, htmlParser: HtmlParser) -> List[str]:
        """
        使用深度优先搜索
        """
        def get_hostname(url: str) -> str:
            url = url[7:]  # 去掉 "http://"
            pos = url.find('/')
            return url if pos == -1 else url[:pos]
        
        hostname = get_hostname(startUrl)
        visited = set()
        result = []
        
        def dfs(url: str):
            if url in visited:
                return
            
            visited.add(url)
            result.append(url)
            
            # 遍历所有链接
            for next_url in htmlParser.getUrls(url):
                if next_url not in visited and get_hostname(next_url) == hostname:
                    dfs(next_url)
        
        dfs(startUrl)
        return result
```

### 方法三：使用正则表达式提取主机名

```python
from typing import List
from collections import deque
import re

class Solution:
    def crawl(self, startUrl: str, htmlParser: HtmlParser) -> List[str]:
        """
        使用正则表达式更优雅地提取主机名
        """
        def get_hostname(url: str) -> str:
            # 匹配 http://主机名/...
            match = re.match(r'http://([^/]+)', url)
            return match.group(1) if match else ''
        
        hostname = get_hostname(startUrl)
        visited = {startUrl}
        queue = deque([startUrl])
        
        while queue:
            url = queue.popleft()
            
            for next_url in htmlParser.getUrls(url):
                if (next_url not in visited and 
                    get_hostname(next_url) == hostname):
                    visited.add(next_url)
                    queue.append(next_url)
        
        return list(visited)
```

### 方法四：优化的字符串处理

```python
from typing import List
from collections import deque

class Solution:
    def crawl(self, startUrl: str, htmlParser: HtmlParser) -> List[str]:
        """
        优化的主机名提取
        """
        # 预先提取主机名作为前缀
        # http://hostname/path -> http://hostname
        parts = startUrl.split('/')
        hostname_prefix = '/'.join(parts[:3])  # http://hostname
        
        visited = {startUrl}
        queue = deque([startUrl])
        
        while queue:
            url = queue.popleft()
            
            for next_url in htmlParser.getUrls(url):
                # 检查是否以相同的主机名前缀开头
                if next_url not in visited and next_url.startswith(hostname_prefix):
                    # 还需要确保不是 hostname2 (比如 yahoo 和 yahoo2)
                    # 第三个 / 之后要么是结尾，要么是 /
                    if (len(next_url) == len(hostname_prefix) or 
                        next_url[len(hostname_prefix)] == '/'):
                        visited.add(next_url)
                        queue.append(next_url)
        
        return list(visited)
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(N + E)，其中 N 是URL数量，E 是边（链接）数量
- 空间复杂度：O(N)，存储访问记录和队列/递归栈

## 关键点总结

1. 正确提取主机名是关键
2. 使用集合避免重复访问
3. BFS和DFS都可以，BFS更直观
4. 注意边界情况：URL末尾有无斜杠
5. 可以使用正则表达式或字符串处理

## 易错点

1. 主机名提取错误
   - 错误：直接用 split('/')[2]
   - 正确：考虑末尾没有 / 的情况
2. 没有正确判断主机名相同
   - 注意：yahoo.com 和 yahoo2.com 是不同的
3. 忘记标记起始URL为已访问
4. 重复添加URL到结果
5. 没有考虑URL格式的边界情况
