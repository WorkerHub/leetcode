## 题目描述

给你一个整数数组 `arr`，你一开始在数组的第一个元素处（下标为 0）。

每一步，你可以从下标 `i` 跳到下标：
- `i + 1`（如果 `i + 1 < arr.length`）
- `i - 1`（如果 `i - 1 >= 0`）
- `j`（如果 `arr[i] == arr[j]` 且 `i != j`）

请你返回到达数组最后一个元素的下标处所需的**最少操作次数**。

注意：任何时候你都不能跳到数组外面。

**示例 1：**
```
输入：arr = [100,-23,-23,404,100,23,23,23,3,404]
输出：3
解释：从下标 0 跳到 4（相同值 100），再跳到 3（相同值 404），再跳到 9（相同值 404）。
```

**示例 2：**
```
输入：arr = [7]
输出：0
解释：已经在最后一个位置。
```

**示例 3：**
```
输入：arr = [7,6,9,6,9,6,9,7]
输出：1
解释：从下标 0 跳到 7（相同值 7）。
```

**提示：**
- `1 <= arr.length <= 5 * 10^4`
- `-10^8 <= arr[i] <= 10^8`

## 解题思路

**BFS（广度优先搜索）求最短路径。**

**建图思路：**
- 节点：数组中的每个下标
- 边：
  - 相邻下标之间有边（i <-> i+1）
  - 值相同的下标之间有边

**BFS关键优化：** 当某个值的所有同值下标都被访问过后，从哈希表中删除该值，避免重复处理（否则每次访问到相同值时都要遍历所有同值下标，时间复杂度退化）。

## Python 代码实现

### 方法一：BFS + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minJumps(self, arr: List[int]) -> int:
        n = len(arr)
        
        # 特殊情况：只有一个元素
        if n == 1:
            return 0
        
        # 建立值到下标列表的映射
        val_to_indices = defaultdict(list)
        for i, val in enumerate(arr):
            val_to_indices[val].append(i)
        
        # BFS
        visited = {0}
        queue = deque([0])
        steps = 0
        
        while queue:
            steps += 1
            # 处理当前层的所有节点
            for _ in range(len(queue)):
                i = queue.popleft()
                
                # 相邻下标跳跃
                for j in [i - 1, i + 1]:
                    if 0 <= j < n and j not in visited:
                        if j == n - 1:
                            return steps
                        visited.add(j)
                        queue.append(j)
                
                # 同值下标跳跃
                val = arr[i]
                if val in val_to_indices:
                    for j in val_to_indices[val]:
                        if j not in visited:
                            if j == n - 1:
                                return steps
                            visited.add(j)
                            queue.append(j)
                    # 关键优化：删除已处理的值，避免重复遍历
                    del val_to_indices[val]
        
        return steps  # 理论上不会到这里
```

### 方法二：BFS（代码更清晰的版本）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minJumps(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 1:
            return 0
        
        # 值到下标列表的映射
        graph = defaultdict(list)
        for i, v in enumerate(arr):
            graph[v].append(i)
        
        # BFS：(下标, 步数)
        visited = set([0])
        queue = deque([(0, 0)])
        
        while queue:
            idx, step = queue.popleft()
            
            # 到达终点
            if idx == n - 1:
                return step
            
            # 获取所有可跳跃的下标
            neighbors = [idx - 1, idx + 1]  # 相邻下标
            neighbors.extend(graph[arr[idx]])  # 同值下标
            
            # 删除已处理的同值组（优化：避免后续重复处理）
            if arr[idx] in graph:
                del graph[arr[idx]]
            
            for nxt in neighbors:
                if 0 <= nxt < n and nxt not in visited:
                    visited.add(nxt)
                    queue.append((nxt, step + 1))
        
        return -1  # 不可能到这里
```

### 方法三：双向BFS（进一步优化）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minJumps(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 1:
            return 0
        
        graph = defaultdict(list)
        for i, v in enumerate(arr):
            graph[v].append(i)
        
        # 双向BFS：从起点和终点同时搜索
        front = {0}      # 正向搜索集合
        back = {n - 1}   # 反向搜索集合
        visited = {0, n - 1}
        steps = 0
        
        while front:
            steps += 1
            next_front = set()
            
            for i in front:
                # 相邻跳跃
                for j in [i - 1, i + 1]:
                    if 0 <= j < n:
                        if j in back:
                            return steps
                        if j not in visited:
                            visited.add(j)
                            next_front.add(j)
                
                # 同值跳跃
                val = arr[i]
                if val in graph:
                    for j in graph[val]:
                        if j in back:
                            return steps
                        if j not in visited:
                            visited.add(j)
                            next_front.add(j)
                    del graph[val]
            
            front = next_front
            
            # 交换：始终从小的集合出发（双向BFS优化）
            if len(front) > len(back):
                front, back = back, front
        
        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/二（BFS） | O(n) | O(n) |
| 方法三（双向BFS） | O(n) | O(n) |

- **时间复杂度**：每个下标最多被访问一次，同值优化使得每组相同值只处理一次，总体 O(n)
- **空间复杂度**：哈希表、队列、visited 集合均为 O(n)

## 关键优化说明

```
不优化的问题：
arr = [1, 1, 1, ..., 1, 2]（n-1 个 1 和一个 2）
每次访问值为 1 的节点，都需要遍历所有 n-1 个同值节点，总复杂度 O(n^2)

优化方法：
一旦某个值的所有同值节点都加入了队列，就从 graph 中删除这个值
后续访问到同一个值时，不会再重复遍历
```

## 图解示例

以 `arr = [100,-23,-23,404,100,23,23,23,3,404]` 为例：

```
初始：从位置 0 (值=100) 出发
     val_to_indices = {100:[0,4], -23:[1,2], 404:[3,9], 23:[5,6,7], 3:[8]}

BFS 第 1 轮（steps=1）：
  从 0 出发：
  - 相邻：1（未访问，加入队列）
  - 同值100：4（未访问，加入队列）
  - 删除 graph[100]

BFS 第 2 轮（steps=2）：
  从 1 出发：
  - 相邻：0（已访问），2（加入）
  - 同值-23：2（已加入），... 
  从 4 出发：
  - 相邻：3（加入），5（加入）
  - 同值100：已删除，不处理

BFS 第 3 轮（steps=3）：
  从 3 出发：
  - 同值404：9（终点！）-> 返回 3

答案：3
```

## 关键点总结

1. BFS 保证找到最短路径（层序遍历，每层步数相同）
2. 删除已处理的值是关键优化，防止重复遍历（O(n) 优化关键）
3. 同值节点在第一次访问时统一处理，之后从哈希表删除
4. 终点检查放在出队时或入队时均可，入队时检查更高效

## 易错点

1. 忘记在处理同值节点后删除哈希表条目（导致 TLE）
2. 相邻跳跃要检查越界（`0 <= j < n`）
3. 初始节点 0 要标记为已访问，防止重复入队
