## 题目描述

给你一棵有 `n` 个节点（编号 `0` 到 `n-1`）的树，边集为 `edges`，每个节点有权值 `vals[i]`。

定义树中的一条路径 **合法**，当且仅当路径上的节点权值严格递增。请返回最长合法路径的节点数。

**示例 1：**

```
输入：n = 5, edges = [[0,1],[1,2],[1,3],[3,4]], vals = [2,3,1,4,5]
输出：4
解释：路径 0→1→3→4，权值 2<3<4<5，长度 4
```

**示例 2：**

```
输入：n = 3, edges = [[0,1],[0,2]], vals = [1,2,3]
输出：2
解释：路径 0→1 或 0→2，最长为 2
```

**提示：**

- `2 <= n <= 10^5`
- `edges.length == n - 1`
- `0 <= vals[i] <= 10^9`

## 解题思路

树形 DP + DFS：

定义 `dp[node]` = 以 `node` 为终点的最长严格递增路径长度。

对于每个节点，遍历其所有子节点：若 `vals[child] > vals[node]`，则可以从 child 延伸路径。

在 DFS 过程中，同时维护经过当前节点的最长路径（拼接两条最长子路径）。

## Python 代码实现

### 方法一：树形 DP（DFS 后序遍历）（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestPath(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        self.ans = 1

        def dfs(node: int, parent: int) -> int:
            # 返回以 node 为端点的最长严格递增路径长度
            best1, best2 = 0, 0  # 最长和次长子路径

            for child in graph[node]:
                if child == parent:
                    continue
                child_len = dfs(child, node)
                # 只有子节点权值更大才能接续
                if vals[child] > vals[node]:
                    if child_len > best1:
                        best2 = best1
                        best1 = child_len
                    elif child_len > best2:
                        best2 = child_len

            # 经过 node 的最长路径 = best1 + best2 + 1
            self.ans = max(self.ans, best1 + best2 + 1)
            return best1 + 1

        dfs(0, -1)
        return self.ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestPath(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 拓扑序（叶到根）
        parent = [-1] * n
        order = []
        visited = [False] * n
        stack = [0]
        visited[0] = True

        while stack:
            node = stack.pop()
            order.append(node)
            for child in graph[node]:
                if not visited[child]:
                    visited[child] = True
                    parent[child] = node
                    stack.append(child)

        # 从叶到根计算 dp
        dp = [1] * n
        ans = 1

        for node in reversed(order):
            best1, best2 = 0, 0
            for child in graph[node]:
                if child == parent[node]:
                    continue
                if vals[child] > vals[node]:
                    if dp[child] > best1:
                        best2 = best1
                        best1 = dp[child]
                    elif dp[child] > best2:
                        best2 = dp[child]
            ans = max(ans, best1 + best2 + 1)
            dp[node] = best1 + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点只访问一次
- 空间复杂度：O(n)，递归栈或 dp 数组

## 关键点总结

1. 树上路径问题：用 DFS 从叶到根，每个节点收集最好的两条子路径
2. 只有权值严格递增时才能拼接路径
3. 经过某节点的最长路径 = 最长 + 次长子路径 + 1
4. 返回值是单方向最长路径（为父节点服务）

## 易错点

1. 拼接路径时需要最长和次长，不能用同一条子路径
2. 权值相等时不能连接（严格递增）
3. 递归深度可能超限，n=10^5 时可能需要迭代
