## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。请你从 `nums` 中满足下述条件的全部子数组中找出最大子数组和：

- 子数组的长度为 `k`，且
- 子数组中的所有元素 **各不相同**。

返回满足题面要求的最大子数组和。如果不存在子数组满足这些条件，返回 `0`。

**子数组** 是数组中一段连续非空的元素序列。

**示例 1：**
```
输入：nums = [1,5,4,2,9,9,9], k = 3
输出：15
解释：nums 中长度为 3 且元素各不相同的子数组有：
- [1,5,4]：和 = 10
- [5,4,2]：和 = 11
- [4,2,9]：和 = 15（最大）
- [2,9,9]：元素不唯一，不满足条件
- [9,9,9]：元素不唯一，不满足条件
```

**示例 2：**
```
输入：nums = [4,4,4], k = 3
输出：0
解释：没有满足条件的子数组。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**滑动窗口（固定大小 k）：**

维护一个大小为 k 的滑动窗口，以及窗口内的元素频率表。

1. 先扩充窗口到大小 k
2. 之后每次滑动：加入右端元素，移出左端元素
3. 当窗口内所有元素不重复时（即频率表中只有 1 频率），更新最大和

## 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        freq = defaultdict(int)  # 频率表
        window_sum = 0
        ans = 0

        for right in range(n):
            # 加入右端元素
            freq[nums[right]] += 1
            window_sum += nums[right]

            # 窗口大小超过 k，移除左端元素
            if right >= k:
                left = right - k
                freq[nums[left]] -= 1
                if freq[nums[left]] == 0:
                    del freq[nums[left]]
                window_sum -= nums[left]

            # 窗口大小恰好为 k 时检查
            if right >= k - 1:
                # 若频率表大小等于 k，说明所有元素各不相同
                if len(freq) == k:
                    ans = max(ans, window_sum)

        return ans
```

### 方法二：滑动窗口 + 重复计数

```python
from typing import List
from collections import Counter

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        window_sum = sum(nums[:k])
        freq = Counter(nums[:k])
        duplicates = sum(1 for v in freq.values() if v > 1)

        if duplicates == 0:
            ans = window_sum

        for right in range(k, n):
            left = right - k
            # 加入右端
            window_sum += nums[right]
            freq[nums[right]] += 1
            if freq[nums[right]] == 2:
                duplicates += 1

            # 移出左端
            window_sum -= nums[left]
            if freq[nums[left]] == 2:
                duplicates -= 1
            freq[nums[left]] -= 1
            if freq[nums[left]] == 0:
                del freq[nums[left]]

            if duplicates == 0:
                ans = max(ans, window_sum)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(k) |

## 关键点总结

1. 固定大小 k 的滑动窗口，维护频率表
2. 用 `len(freq) == k` 判断窗口内元素各不相同（频率表大小 = 唯一元素数）
3. 每次滑动 O(1) 更新

## 易错点

- 窗口大小恰好为 k 时才检查，即 `right >= k - 1`
- 频率为 0 时需从字典中删除，否则 `len(freq)` 计数不准确
