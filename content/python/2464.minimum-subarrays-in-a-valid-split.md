## 题目描述

给你一个整数数组 `nums`。

如果将 `nums` 分割成若干子数组，且每个子数组的第一个元素和最后一个元素的最大公因数大于 `1`，则认为该分割方案是有效的。

返回 **有效** 分割方案中，分割出的 **最少** 子数组数目。如果不存在任何有效的分割方案，返回 `-1`。

**示例 1：**
```
输入：nums = [2,6,3,4,3]
输出：2
解释：[2,6,3] 的 gcd(2,3) = 1，不行。[2,6] 的 gcd(2,6) = 2 > 1，[3,4,3] 的 gcd(3,3) = 3 > 1。分成 2 个子数组。
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`

## 解题思路

**动态规划：**

`dp[i]` = 将 `nums[0..i]` 有效分割的最少子数组数。

转移：对于以 `i` 结尾的每个子数组 `[j..i]`（j <= i），若 `gcd(nums[j], nums[i]) > 1`，则：
`dp[i] = min(dp[i], dp[j-1] + 1)`

初始条件：`dp[-1] = 0`（空数组，0 个子数组）

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List
import math

class Solution:
    def validSubarraySplit(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')
        # dp[i] = nums[0..i] 有效分割的最少子数组数
        dp = [INF] * n

        for i in range(n):
            for j in range(i + 1):
                # 子数组 [j..i]，首元素 nums[j]，末元素 nums[i]
                if math.gcd(nums[j], nums[i]) > 1:
                    prev = dp[j - 1] if j > 0 else 0
                    if prev != INF:
                        dp[i] = min(dp[i], prev + 1)

        return dp[n - 1] if dp[n - 1] != INF else -1
```

### 方法二：贪心（局部优化）

```python
from typing import List
import math

class Solution:
    def validSubarraySplit(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(n):
            for j in range(i, n):
                # 子数组 [i..j]
                if math.gcd(nums[i], nums[j]) > 1:
                    if dp[i] != INF:
                        dp[j + 1] = min(dp[j + 1], dp[i] + 1)

        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n^2 * log(max_val)) | O(n) |

## 关键点总结

1. 有效子数组的条件：首尾元素 GCD > 1
2. 单个元素 `nums[i]` 如果 `gcd(nums[i], nums[i]) = nums[i] > 1` 则可单独成一段
3. DP 枚举所有可能的子数组起点

## 易错点

- 单个元素能否独立成一个子数组？能，当 `nums[i] > 1` 时（自身 GCD > 1）
- `nums[i] = 1` 的元素必须与其他元素组合
