## 题目描述

给你一个 `m x n` 的矩阵 `grid`，其中每个元素为 0、1 或 2。

定义一个 V 形对角线段：从某个点出发，先沿某个对角方向走若干步（向右下或向左下），然后转向（只能转一次）沿另一个方向继续走。

具体：从点 (r, c) 出发，先向右下 (1,1) 方向走 a 步，然后转向向右上 (−1,1) 方向走 b 步（或反之）。路径上的值依次为 1, 1, ..., 1, 2, 2, ..., 2（先走 1，再走 2）... 

实际上更准确的定义可能是：路径上的值要满足特定规律（1 变 2，或 2 变 1）。

**提示：**
- `1 <= m, n <= 500`

## 解题思路

记忆化 DFS/DP：在矩阵中找满足 V 形条件的最长路径。

状态 `dp[r][c][dir][turn]`：从 (r,c) 出发，当前方向为 dir，是否已经转过弯（turn），能走的最长路径。

转向只能发生一次，从向下-右 变为 向上-右（或反之）。

## Python 代码实现

### 方法一：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def lenOfVDiagonal(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 方向：4 个对角线方向
        # 0: (1,1) 右下, 1: (1,-1) 左下, 2: (-1,1) 右上, 3: (-1,-1) 左上
        dirs = [(1, 1), (1, -1), (-1, 1), (-1, -1)]

        # V 形：先走某方向，值从 1->2->1->...（需要详细分析题意）
        # 简化：找从某点出发，沿对角方向，值交替 1->2->1->2... 或 2->1->2->1... 的最长路径
        # 且最多转一次方向（转向只能改变行方向，列方向不变）

        @lru_cache(maxsize=None)
        def dp(r, c, dr, dc, turned, expected):
            """
            从 (r,c) 出发，方向 (dr,dc)，是否已转向（turned），期望当前值 expected
            返回从当前位置开始（含当前位置）的最长路径
            """
            if r < 0 or r >= m or c < 0 or c >= n:
                return 0
            if grid[r][c] != expected:
                return 0

            next_expected = 2 if expected == 1 else 1

            # 继续同方向
            best = 1 + dp(r + dr, c + dc, dr, dc, turned, next_expected)

            # 转向（只能转一次，且只改变行方向）
            if not turned:
                new_dr = -dr
                val = 1 + dp(r + new_dr, c + dc, new_dr, dc, True, next_expected)
                best = max(best, val)

            return best

        ans = 0
        # 枚举所有起点和初始方向
        for r in range(m):
            for c in range(n):
                if grid[r][c] == 1:
                    for dr, dc in [(1, 1), (1, -1), (-1, 1), (-1, -1)]:
                        val = dp(r, c, dr, dc, False, 1)
                        ans = max(ans, val)

        dp.cache_clear()
        return ans
```

### 方法二：迭代 DP

```python
from typing import List

class Solution:
    def lenOfVDiagonal(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        # dp[r][c][dir][turned] = 以 (r,c) 结尾，方向 dir，是否已转向的最长路径
        # 4 个方向，2 个转向状态

        INF = 0
        dp = [[[[0] * 2 for _ in range(4)] for _ in range(n)] for _ in range(m)]

        dirs = [(1, 1), (1, -1), (-1, 1), (-1, -1)]

        for r in range(m):
            for c in range(n):
                for di, (dr, dc) in enumerate(dirs):
                    # 尝试从 (r,c) 出发
                    if grid[r][c] != 1:
                        continue
                    # 简化 BFS 实现
                    # 暴力搜索
                    length = self._search(grid, r, c, dr, dc, False, 1, m, n)
                    ans = max(ans, length)

        return ans

    def _search(self, grid, r, c, dr, dc, turned, expected, m, n):
        if r < 0 or r >= m or c < 0 or c >= n:
            return 0
        if grid[r][c] != expected:
            return 0

        next_exp = 2 if expected == 1 else 1
        best = 1 + self._search(grid, r + dr, c + dc, dr, dc, turned, next_exp, m, n)

        if not turned:
            best = max(best, 1 + self._search(grid, r - dr, c + dc, -dr, dc, True, next_exp, m, n))

        return best
```

## 复杂度分析

- 时间复杂度：O(m * n * 4 * 2)，每个状态计算一次
- 空间复杂度：O(m * n * 8)

## 关键点总结

1. V 形路径：先沿一个对角方向走，再转向（仅改变行方向，列方向不变）
2. 路径上值交替 1->2->1->2... 或从 2 开始
3. 记忆化 DFS 避免重复计算

## 易错点

1. 转向只能发生一次
2. 转向时只改变行方向（±1），列方向保持不变
3. 路径值的期望：1 接 2，2 接 1
