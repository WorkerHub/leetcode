## 题目描述

给你一个整数数组 `nums` 和两个整数 `minK` 以及 `maxK`。

`nums` 的定界子数组是满足下述条件的一个子数组：

- 子数组中的 **最小值** 等于 `minK`。
- 子数组中的 **最大值** 等于 `maxK`。

返回定界子数组的数目。

子数组是数组中的一个连续部分。

**示例 1：**
```
输入：nums = [1,3,5,2,7,5], minK = 1, maxK = 5
输出：2
解释：定界子数组是 [1,3,5] 和 [1,3,5,2]。
```

**示例 2：**
```
输入：nums = [1,1,1,1], minK = 1, maxK = 1
输出：10
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i], minK, maxK <= 10^6`
- `minK <= maxK`

## 解题思路

**滑动窗口（一次遍历）：**

对于以 `r` 结尾的定界子数组，需要找满足条件的最多的左端点数。

维护三个变量：
- `bad`：最后一个不在 `[minK, maxK]` 范围内的元素位置（越界位置）
- `last_min`：最后一个值等于 `minK` 的元素位置
- `last_max`：最后一个值等于 `maxK` 的元素位置

以 `r` 结尾的定界子数组，左端点 `l` 必须满足：
- `l > bad`（子数组不包含越界元素）
- `l <= min(last_min, last_max)`（子数组包含 minK 和 maxK）

因此，合法左端点数 = `max(0, min(last_min, last_max) - bad)`。

## 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], minK: int, maxK: int) -> int:
        ans = 0
        bad = -1       # 最后一个越界元素的位置
        last_min = -1  # 最后一个 minK 的位置
        last_max = -1  # 最后一个 maxK 的位置

        for r, x in enumerate(nums):
            # 如果当前元素越界，更新 bad
            if x < minK or x > maxK:
                bad = r

            # 更新 minK 和 maxK 的最后位置
            if x == minK:
                last_min = r
            if x == maxK:
                last_max = r

            # 合法左端点数 = max(0, min(last_min, last_max) - bad)
            left_bound = min(last_min, last_max)
            ans += max(0, left_bound - bad)

        return ans
```

### 方法二：暴力枚举（对比学习，超时）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], minK: int, maxK: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            cur_min, cur_max = float('inf'), float('-inf')
            for j in range(i, n):
                cur_min = min(cur_min, nums[j])
                cur_max = max(cur_max, nums[j])
                if cur_min == minK and cur_max == maxK:
                    ans += 1
                elif cur_min < minK or cur_max > maxK:
                    break  # 超界后不可能再满足

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(n) | O(1) |
| 暴力枚举 | O(n^2) | O(1) |

## 关键点总结

1. 定界子数组：最小值恰好等于 minK，最大值恰好等于 maxK
2. 维护三个位置：越界位置、最后的 minK 位置、最后的 maxK 位置
3. 合法左端点范围：`(bad, min(last_min, last_max)]`（开区间）

## 易错点

- `bad` 是最后一个越界元素的位置，左端点必须严格大于 `bad`
- `min(last_min, last_max)` 是两者中较小的，保证子数组同时包含 minK 和 maxK
