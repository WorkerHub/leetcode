## 题目描述

**完全二叉树** 是每一层（除最后一层外）都是完全填充（即，节点数达到最大）的，并且所有的节点都尽可能地集中在左侧。

设计一个用完全二叉树初始化的数据结构 `CBTInserter`，它支持以下几种操作：

- `CBTInserter(TreeNode root)` 使用头节点为 `root` 的给定完全二叉树初始化该数据结构。
- `int insert(int v)` 向树中插入一个值为 `v` 的新节点，使树保持完全二叉树的性质。返回插入节点的父节点的值。
- `TreeNode get_root()` 返回树的头节点。

**示例：**
```
输入：
["CBTInserter", "insert", "insert", "get_root"]
[[[1, 2]], [3], [4], []]
输出：
[null, 1, 2, [1, 2, 3, 4]]

解释：
CBTInserter cBTInserter = new CBTInserter([1, 2]);
cBTInserter.insert(3);  // 返回 1，树变为 [1, 2, 3]
cBTInserter.insert(4);  // 返回 2，树变为 [1, 2, 3, 4]
cBTInserter.get_root(); // 返回 root 节点，即 [1, 2, 3, 4]
```

**提示：**
- 树中节点数量范围为 `[1, 1000]`
- `0 <= Node.val <= 5000`
- `root` 是完全二叉树
- `0 <= val <= 5000`
- 每个测试用例最多调用 `insert` 和 `get_root` 操作 `10^4` 次

## 解题思路

完全二叉树的特点是除了最后一层，其他层都是满的，且最后一层从左到右填充。

**关键观察：**
1. 使用 BFS（层序遍历）可以按层访问完全二叉树
2. 需要插入的位置一定是第一个还没有填满两个子节点的节点
3. 可以使用队列维护所有可能成为父节点的节点

**设计思路：**
1. 初始化时，使用 BFS 遍历树，找到所有未填满的节点（没有两个子节点）
2. 将这些节点放入队列
3. 插入时，从队列头部取出节点，添加子节点
4. 如果节点填满了两个子节点，将其从队列移除
5. 将新插入的节点加入队列（它将来也可能成为父节点）

## Python 代码实现

### 方法一：队列维护（推荐 ⭐）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class CBTInserter:
    def __init__(self, root: Optional[TreeNode]):
        self.root = root
        # 队列存储所有未填满的节点（还可以添加子节点的节点）
        self.candidates = deque()
        
        # BFS 遍历，找到所有未填满的节点
        queue = deque([root])
        while queue:
            node = queue.popleft()
            
            # 如果节点没有填满，加入候选队列
            if not node.left or not node.right:
                self.candidates.append(node)
            
            # 继续遍历子节点
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    
    def insert(self, val: int) -> int:
        # 创建新节点
        new_node = TreeNode(val)
        
        # 获取第一个未填满的节点
        parent = self.candidates[0]
        
        # 插入新节点
        if not parent.left:
            parent.left = new_node
        else:
            parent.right = new_node
            # 父节点已填满，从队列移除
            self.candidates.popleft()
        
        # 新节点加入候选队列（将来可能成为父节点）
        self.candidates.append(new_node)
        
        return parent.val
    
    def get_root(self) -> Optional[TreeNode]:
        return self.root
```

### 方法二：使用列表存储

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class CBTInserter:
    def __init__(self, root: Optional[TreeNode]):
        self.tree = []  # 按层序存储所有节点
        
        # BFS 遍历，将所有节点存入列表
        queue = deque([root])
        while queue:
            node = queue.popleft()
            self.tree.append(node)
            
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    
    def insert(self, val: int) -> int:
        new_node = TreeNode(val)
        self.tree.append(new_node)
        
        # 父节点的索引：(n-1) // 2
        n = len(self.tree)
        parent_index = (n - 2) // 2  # n-1 是新节点索引，减1除2得父节点
        parent = self.tree[parent_index]
        
        # 判断插入左子节点还是右子节点
        if not parent.left:
            parent.left = new_node
        else:
            parent.right = new_node
        
        return parent.val
    
    def get_root(self) -> Optional[TreeNode]:
        return self.tree[0] if self.tree else None
```

### 方法三：简化版

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class CBTInserter:
    def __init__(self, root: Optional[TreeNode]):
        self.root = root
        self.deque = deque()
        
        # 层序遍历，找到所有未填满的节点
        q = deque([root])
        while q:
            node = q.popleft()
            if not node.left or not node.right:
                self.deque.append(node)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
    
    def insert(self, val: int) -> int:
        node = TreeNode(val)
        parent = self.deque[0]
        
        if not parent.left:
            parent.left = node
        else:
            parent.right = node
            self.deque.popleft()
        
        self.deque.append(node)
        return parent.val
    
    def get_root(self) -> Optional[TreeNode]:
        return self.root
```

## 复杂度分析

**方法一：队列维护**
- 初始化：O(n)，需要遍历所有节点
- 插入：O(1)，直接从队列头部取节点
- 获取根节点：O(1)
- 空间复杂度：O(n)，队列存储未填满的节点

**方法二：列表存储**
- 初始化：O(n)
- 插入：O(1)，通过索引计算父节点
- 获取根节点：O(1)
- 空间复杂度：O(n)，列表存储所有节点

## 关键点总结

1. **完全二叉树性质**：新节点一定插入到第一个未填满的节点处
2. **队列应用**：维护所有未填满的节点
3. **BFS 遍历**：初始化时用 BFS 找到所有未填满的节点
4. **父子关系**：在数组表示中，索引 i 的父节点是 (i-1)//2
5. **两种实现**：队列法和数组法各有优劣

## 易错点

1. **队列维护时机**：节点填满两个子节点时才移出队列
2. **新节点入队**：新插入的节点也要加入队列
3. **索引计算**：数组法中父节点索引是 (n-2)//2，不是 (n-1)//2
4. **左右子节点判断**：要判断是插入左子节点还是右子节点
5. **初始化遍历**：要遍历整棵树找到所有未填满的节点
