## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

如果下标 `i`、`j`、`k` 满足 `i < j < k` 且 `nums[i] < nums[j]` 且 `nums[j] > nums[k]`，则称 `(i, j, k)` 为一个山形三元组。

返回所有山形三元组中 `nums[i] + nums[j] + nums[k]` 的 **最小值**。若不存在山形三元组，返回 `-1`。

**示例 1：**
```
输入：nums = [8,6,1,5,3]
输出：9
```

**示例 2：**
```
输入：nums = [5,4,8,7,10,2]
输出：13
```

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^8`

## 解题思路

本题数据范围大（n 达到 10^5），需要 O(n) 解法。

预处理两个辅助数组：
- `prefix_min[j]`：j 左侧（不含 j）的最小值
- `suffix_min[j]`：j 右侧（不含 j）的最小值

然后枚举中间元素 j：
- 若 `prefix_min[j] < nums[j]` 且 `suffix_min[j] < nums[j]`，则存在合法三元组
- 取 `prefix_min[j] + nums[j] + suffix_min[j]` 的最小值

## Python 代码实现

### 方法一：前缀最小 + 后缀最小（推荐）

```python
from typing import List

class Solution:
    def minimumSum(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')

        # prefix_min[j]: nums[0..j-1] 的最小值
        prefix_min = [INF] * n
        for j in range(1, n):
            prefix_min[j] = min(prefix_min[j - 1], nums[j - 1])

        # suffix_min[j]: nums[j+1..n-1] 的最小值
        suffix_min = [INF] * n
        for j in range(n - 2, -1, -1):
            suffix_min[j] = min(suffix_min[j + 1], nums[j + 1])

        ans = INF
        for j in range(1, n - 1):
            # 山形要求：左侧最小 < nums[j] 且 右侧最小 < nums[j]
            if prefix_min[j] < nums[j] and suffix_min[j] < nums[j]:
                ans = min(ans, prefix_min[j] + nums[j] + suffix_min[j])

        return ans if ans != INF else -1
```

### 方法二：一次遍历维护前缀最小（空间优化）

```python
from typing import List

class Solution:
    def minimumSum(self, nums: List[int]) -> int:
        n = len(nums)
        INF = float('inf')

        # 先预处理后缀最小值
        suffix_min = [INF] * (n + 1)
        for j in range(n - 2, -1, -1):
            suffix_min[j] = min(suffix_min[j + 1], nums[j + 1])

        ans = INF
        cur_prefix_min = INF  # 当前 j 左侧的最小值
        for j in range(n):
            # cur_prefix_min 是 nums[0..j-1] 的最小值
            if (cur_prefix_min < nums[j] and
                    suffix_min[j] < nums[j]):
                ans = min(ans, cur_prefix_min + nums[j] + suffix_min[j])
            # 更新前缀最小
            cur_prefix_min = min(cur_prefix_min, nums[j])

        return ans if ans != INF else -1
```

## 复杂度分析

- 时间复杂度：O(n)，前后各遍历一次数组
- 空间复杂度：O(n)，存储前缀/后缀最小值数组；方法二 O(n)（只存后缀）

## 关键点总结

1. 枚举中间元素，贪心地选左右最小值以最小化和
2. 前缀最小值数组可以在线维护（一个变量），节省一次遍历
3. 条件：左最小 < nums[j] 且 右最小 < nums[j]，缺一不可

## 易错点

1. `prefix_min[j]` 存的是 j 左边（不含 j），初始化时注意边界
2. `suffix_min[j]` 存的是 j 右边（不含 j），同理
3. nums[j] 必须严格大于两侧，等于也不行
