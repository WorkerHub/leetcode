## 题目描述

给你一个 `m x n` 的矩阵 `land`，`land[i][j]` 为 `1` 表示农田，为 `0` 表示荒地。

农田区域是**矩形**的，且不会相邻。找出所有农田组，每组用其**左上角** `(r1, c1)` 和**右下角** `(r2, c2)` 坐标表示。

**示例：**
```
输入：land = [[1,0,0],[0,1,1],[0,1,1]]
输出：[[0,0,0,0],[1,1,2,2]]
```

**提示：**
- `m == land.length`，`n == land[i].length`
- `1 <= m, n <= 300`
- `land[i][j]` 为 `0` 或 `1`

---

## 解题思路

### 核心思想：找每个矩形的左上角，直接推算右下角

由于农田是矩形且不相邻，我们只需：
1. 扫描每个 `land[i][j] == 1` 的左上角（即上方和左方均不是 1）
2. 从左上角向右、向下扩展找右下角
3. 将整个矩形标记（或通过 BFS/DFS）

---

## 代码实现

### 方法一：直接推算右下角（推荐）

```python
from typing import List

class Solution:
    def findFarmland(self, land: List[List[int]]) -> List[List[int]]:
        m, n = len(land), len(land[0])
        result = []

        for i in range(m):
            for j in range(n):
                # 找左上角：当前为 1，且上方和左方不是 1
                if land[i][j] == 1:
                    if (i == 0 or land[i-1][j] == 0) and (j == 0 or land[i][j-1] == 0):
                        # 找右下角：向右扩展
                        r2, c2 = i, j
                        # 向下扩展
                        while r2 + 1 < m and land[r2 + 1][j] == 1:
                            r2 += 1
                        # 向右扩展
                        while c2 + 1 < n and land[i][c2 + 1] == 1:
                            c2 += 1
                        result.append([i, j, r2, c2])

        return result
```

### 方法二：BFS 找每个连通区域的边界

```python
from typing import List
from collections import deque

class Solution:
    def findFarmland(self, land: List[List[int]]) -> List[List[int]]:
        m, n = len(land), len(land[0])
        visited = [[False] * n for _ in range(m)]
        result = []

        for i in range(m):
            for j in range(n):
                if land[i][j] == 1 and not visited[i][j]:
                    # BFS 找整个矩形区域
                    queue = deque([(i, j)])
                    visited[i][j] = True
                    r1, c1, r2, c2 = i, j, i, j

                    while queue:
                        r, c = queue.popleft()
                        r2 = max(r2, r)
                        c2 = max(c2, c)
                        for dr, dc in ((1, 0), (0, 1), (-1, 0), (0, -1)):
                            nr, nc = r + dr, c + dc
                            if 0 <= nr < m and 0 <= nc < n and land[nr][nc] == 1 and not visited[nr][nc]:
                                visited[nr][nc] = True
                                queue.append((nr, nc))

                    result.append([r1, c1, r2, c2])

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(m * n) | O(1) |
| 方法二 | O(m * n) | O(m * n) |

## 关键点总结

1. 农田为矩形且不相邻，可直接找左上角后向右向下推算右下角
2. 方法一无需额外空间，直接利用矩形性质
3. BFS 是通用连通区域方法，适用于任意形状

---

## 易错点

- 方法一中右下角先向下扩展（找最大行），再向右扩展（找最大列）
- 确保只从左上角开始（上方和左方均不是 1）
