## 题目描述

给定你一个整数数组 `nums`。

我们要将 `nums` 数组中的每个元素移动到 `A` 数组或者 `B` 数组中，使得 `A` 数组和 `B` 数组不为空，并且 `A` 数组的平均值等于 `B` 数组的平均值。

如果可以完成则返回 `true`，否则返回 `false`。

**注意**：对于数组 `arr`，`arr` 的平均值是 `arr` 的所有元素之和除以 `arr.length`。

**示例 1:**
```
输入: nums = [1,2,3,4,5,6,7,8]
输出: true
解释: 我们可以将数组分割为 [1,4,5,8] 和 [2,3,6,7], 他们的平均值都是4.5。
```

**示例 2:**
```
输入: nums = [3,1]
输出: false
```

**提示:**
- `1 <= nums.length <= 30`
- `0 <= nums[i] <= 10^4`

## 解题思路

这是一道数学 + 动态规划的困难题。

**数学推导：**

假设数组总和为 `sum`，长度为 `n`。
将数组分为两部分 A 和 B：
- A 的长度为 `k`，和为 `sumA`
- B 的长度为 `n - k`，和为 `sum - sumA`

如果平均值相等：
```
sumA / k = (sum - sumA) / (n - k)
```

化简得：
```
sumA * (n - k) = (sum - sumA) * k
sumA * n - sumA * k = sum * k - sumA * k
sumA * n = sum * k
sumA = sum * k / n
```

**关键观察：**
1. `sumA` 必须是整数，所以 `sum * k % n == 0`
2. 我们只需要找到一个大小为 `k` 的子集，其和为 `sum * k / n`
3. 由于对称性，我们只需检查 `k <= n/2`

**解法：**
使用动态规划或集合来找是否存在这样的子集。

## Python 代码实现

### 方法一：动态规划 + 剪枝（推荐）⭐

```python
from typing import List

class Solution:
    def splitArraySameAverage(self, nums: List[int]) -> bool:
        n = len(nums)
        total_sum = sum(nums)
        
        # 特判：只有一个元素无法分割
        if n == 1:
            return False
        
        # 优化：减去平均值，问题转化为找和为0的子集
        # 这样可以避免浮点数运算
        avg = total_sum / n
        nums = [x - avg for x in nums]
        
        # 只需检查长度 k <= n/2 的情况（对称性）
        half = n // 2
        
        # dp[k] 存储所有长度为 k 的子集和
        possible = [set() for _ in range(half + 1)]
        possible[0].add(0)
        
        for num in nums:
            # 从后往前遍历，避免重复使用
            for k in range(half, 0, -1):
                for prev_sum in possible[k - 1]:
                    possible[k].add(prev_sum + num)
        
        # 检查是否存在和为 0 的子集（长度 > 0 且 < n）
        for k in range(1, half + 1):
            if 0 in possible[k]:
                return True
        
        return False
```

### 方法二：背包 DP（整数版本）

```python
from typing import List

class Solution:
    def splitArraySameAverage(self, nums: List[int]) -> bool:
        n = len(nums)
        total_sum = sum(nums)
        
        if n == 1:
            return False
        
        # dp[k][s] 表示能否选择 k 个数使得和为 s
        # 优化：只需检查 k <= n/2
        half = n // 2
        
        # 使用集合存储可能的和
        dp = [set() for _ in range(half + 1)]
        dp[0].add(0)
        
        for num in nums:
            # 从后往前更新
            for k in range(half, 0, -1):
                for s in list(dp[k - 1]):
                    dp[k].add(s + num)
        
        # 检查是否存在满足条件的分割
        for k in range(1, half + 1):
            # 需要满足：sumA = total_sum * k / n
            if total_sum * k % n == 0:
                target = total_sum * k // n
                if target in dp[k]:
                    return True
        
        return False
```

### 方法三：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def splitArraySameAverage(self, nums: List[int]) -> bool:
        n = len(nums)
        total_sum = sum(nums)
        
        if n == 1:
            return False
        
        # 转换为元组以便缓存
        nums_tuple = tuple(nums)
        
        @lru_cache(maxsize=None)
        def dfs(index: int, k: int, curr_sum: int) -> bool:
            """
            从 index 开始，选择 k 个数，当前和为 curr_sum
            返回是否能达到目标和
            """
            # 已经选够了 k 个数
            if k == 0:
                return curr_sum * n == total_sum * (index - (n - index))
            
            # 剩余数字不够
            if index >= n or n - index < k:
                return False
            
            # 计算目标和
            needed_sum = total_sum * k
            
            # 选择当前数字
            if dfs(index + 1, k - 1, curr_sum + nums_tuple[index]):
                return True
            
            # 不选择当前数字
            if dfs(index + 1, k, curr_sum):
                return True
            
            return False
        
        # 尝试所有可能的分割大小
        for k in range(1, n // 2 + 1):
            if total_sum * k % n == 0:
                target = total_sum * k // n
                if dfs(0, k, 0):
                    return True
        
        return False
```

### 方法四：位运算优化（高效版本）

```python
from typing import List

class Solution:
    def splitArraySameAverage(self, nums: List[int]) -> bool:
        n = len(nums)
        total_sum = sum(nums)
        
        if n == 1:
            return False
        
        # 使用位集合优化
        # possible[k] 是一个整数，第 i 位为 1 表示和 i 可达
        half = n // 2
        possible = [set([0]) for _ in range(half + 1)]
        
        for num in nums:
            for k in range(half, 0, -1):
                for prev in list(possible[k - 1]):
                    possible[k].add(prev + num)
        
        for k in range(1, half + 1):
            if total_sum * k % n == 0:
                if total_sum * k // n in possible[k]:
                    return True
        
        return False
```

## 复杂度分析

### 方法一和方法二：
- **时间复杂度**：O(n² × sum)，其中 n 是数组长度，sum 是数组总和
- **空间复杂度**：O(n × sum)

### 方法三：
- **时间复杂度**：O(n × 2^n)，最坏情况下需要遍历所有子集
- **空间复杂度**：O(n × 2^n)，记忆化缓存

## 关键点总结

1. **数学推导**：将平均值相等转化为寻找特定和的子集
2. **对称性优化**：只需检查 `k <= n/2` 的情况
3. **整除性判断**：`sum * k % n == 0` 是必要条件
4. **动态规划**：背包问题的变种，需要同时记录大小和和
5. **浮点数处理**：可以减去平均值避免浮点数运算

## 易错点

1. **边界条件**：n = 1 时无法分割，直接返回 False
2. **整除判断**：必须先检查 `sum * k % n == 0`
3. **DP 更新顺序**：必须从后往前，避免重复使用元素
4. **空集问题**：两个集合都不能为空
5. **数值范围**：注意可能的和的范围，避免超时
