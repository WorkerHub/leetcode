## 题目描述

给定一个由表示变量之间关系的字符串方程组成的数组 `equations`，每个字符串方程 `equations[i]` 的长度为 `4`，并采用两种不同的形式之一：`"a==b"` 或 `"a!=b"`。在这里，a 和 b 是小写字母（不一定不同），表示单字母变量名。

只有当可以将整数分配给变量名，以便满足所有给定的方程时才返回 `true`，否则返回 `false`。

**示例 1：**

```
输入：equations = ["a==b","b!=a"]
输出：false
解释：如果我们指定，a = 1 且 b = 1，那么可以满足第一个方程，但无法满足第二个方程。
没有办法分配变量同时满足这两个方程。
```

**示例 2：**

```
输入：equations = ["b==a","a==b"]
输出：true
解释：我们可以指定 a = 1 且 b = 1 以满足满足这两个方程。
```

**示例 3：**

```
输入：equations = ["a==b","b==c","a==c"]
输出：true
```

**示例 4：**

```
输入：equations = ["a==b","b!=c","c==a"]
输出：false
```

**提示：**

- `1 <= equations.length <= 500`
- `equations[i].length == 4`
- `equations[i][0]` 和 `equations[i][3]` 是小写字母
- `equations[i][1]` 要么是 `'='`，要么是 `'!'`
- `equations[i][2]` 是 `'='`

## 解题思路

这是一道典型的**并查集（Union-Find）**问题。

**核心思想：**

1. 如果 `a==b` 且 `b==c`，那么 `a==c`（传递性）
2. 利用并查集将所有相等的变量合并到同一个集合
3. 然后检查所有不等式，如果两个变量应该不相等但在同一个集合中，返回 false

**算法流程：**

1. **第一遍遍历**：处理所有相等关系（`==`），使用并查集合并
2. **第二遍遍历**：检查所有不等关系（`!=`），判断是否矛盾
   - 如果两个变量在同一个集合但要求不相等，返回 false
3. 如果所有检查都通过，返回 true

**为什么用并查集？**

并查集非常适合处理"分组"和"连通性"问题。这里的相等关系就是一种连通关系。

## Python 代码实现

### 方法一：并查集（推荐）⭐

```python
from typing import List

class UnionFind:
    """并查集数据结构"""
    
    def __init__(self, n: int):
        """初始化 n 个元素的并查集"""
        self.parent = list(range(n))  # 每个元素的父节点
        self.rank = [0] * n  # 树的秩（用于优化）
    
    def find(self, x: int) -> int:
        """查找 x 的根节点（路径压缩优化）"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]
    
    def union(self, x: int, y: int) -> None:
        """合并 x 和 y 所在的集合"""
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x != root_y:
            # 按秩合并：将秩小的树连接到秩大的树
            if self.rank[root_x] < self.rank[root_y]:
                self.parent[root_x] = root_y
            elif self.rank[root_x] > self.rank[root_y]:
                self.parent[root_y] = root_x
            else:
                self.parent[root_y] = root_x
                self.rank[root_x] += 1
    
    def is_connected(self, x: int, y: int) -> bool:
        """判断 x 和 y 是否在同一个集合"""
        return self.find(x) == self.find(y)

class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        """
        使用并查集解决等式方程可满足性
        时间复杂度：O(n + C*α(C))，n 是方程数，C 是变量数（26），α 是阿克曼函数的反函数
        空间复杂度：O(C) = O(26) = O(1)
        """
        # 初始化并查集（26个小写字母）
        uf = UnionFind(26)
        
        # 第一遍：处理所有相等关系
        for eq in equations:
            if eq[1] == '=':  # 相等关系
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                uf.union(x, y)
        
        # 第二遍：检查所有不等关系
        for eq in equations:
            if eq[1] == '!':  # 不等关系
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                # 如果两个变量在同一个集合中，矛盾
                if uf.is_connected(x, y):
                    return False
        
        return True
```

### 方法二：简化的并查集

```python
class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        """
        简化版并查集（不使用按秩合并）
        """
        # 父节点数组
        parent = list(range(26))
        
        def find(x: int) -> int:
            """查找根节点"""
            if parent[x] != x:
                parent[x] = find(parent[x])  # 路径压缩
            return parent[x]
        
        def union(x: int, y: int) -> None:
            """合并两个集合"""
            parent[find(x)] = find(y)
        
        # 处理相等关系
        for eq in equations:
            if eq[1] == '=':
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                union(x, y)
        
        # 检查不等关系
        for eq in equations:
            if eq[1] == '!':
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                if find(x) == find(y):
                    return False
        
        return True
```

### 方法三：使用字典的并查集

```python
class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        """
        使用字典实现并查集（更直观）
        """
        parent = {}
        
        def find(x: str) -> str:
            """查找根节点"""
            if x not in parent:
                parent[x] = x
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: str, y: str) -> None:
            """合并两个集合"""
            parent[find(x)] = find(y)
        
        # 处理相等关系
        for eq in equations:
            if eq[1] == '=':
                union(eq[0], eq[3])
        
        # 检查不等关系
        for eq in equations:
            if eq[1] == '!':
                if find(eq[0]) == find(eq[3]):
                    return False
        
        return True
```

## 复杂度分析

**方法一（推荐）：**
- 时间复杂度：O(n + C*α(C))，其中 n 是方程数量，C 是变量数量（26），α 是阿克曼函数的反函数（几乎为常数）
- 空间复杂度：O(C) = O(26) = O(1)

**方法二和方法三：**
- 时间复杂度：O(n * α(C))
- 空间复杂度：O(C)

## 关键点总结

1. **并查集的应用**：识别这是一个连通性问题
2. **两遍遍历**：先处理相等，再检查不等
3. **路径压缩**：优化查找操作，降低时间复杂度
4. **字符映射**：将字符转换为 0-25 的索引
5. **逻辑顺序**：必须先建立所有相等关系，再检查不等关系

## 易错点

1. **顺序错误**：不能先检查不等再处理相等，因为相等关系有传递性
2. **字符转索引**：`ord(ch) - ord('a')` 将 'a'-'z' 转为 0-25
3. **边界情况**：`a==a` 永远成立，`a!=a` 永远不成立
4. **忘记路径压缩**：虽然不影响正确性，但影响效率

## 图解示例

以 `equations = ["a==b","b==c","a!=c"]` 为例：

```
第一遍（处理 ==）：
a==b: 合并 a 和 b
  a --- b

b==c: 合并 b 和 c
  a --- b --- c

第二遍（检查 !=）：
a!=c: 检查 a 和 c 是否在同一集合
  发现 a 和 c 在同一集合 → 矛盾！
  返回 false
```
