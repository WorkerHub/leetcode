## 题目描述

给你一个正整数数组 `nums`，请你从该数组中移除**最短子数组（可以为空）**，使得剩余元素的和能被 `p` 整除。

不允许将整个数组都移除，如果无解，返回 -1。

**示例 1：**
```
输入：nums = [3,1,4,2], p = 6
输出：1
解释：总和 = 10，10 mod 6 = 4，移除 [4] 后剩余和 6，可被 6 整除。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= p <= 10^9`

## 解题思路

### 前缀和 + 哈希表

总和 `total % p = r`，需要找最短子数组使其和 % p = r。

`prefix[j] - prefix[i] ≡ r (mod p)` ⟺ `prefix[i] ≡ prefix[j] - r (mod p)`

与 560 题"子数组和等于 K"类似，用哈希表存储每个前缀和余数**最后一次**出现的位置。

枚举 `j`，查找 `(prefix[j] - r) % p` 是否在哈希表中，若在，更新最短子数组长度。

## 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def minSubarray(self, nums: List[int], p: int) -> int:
        total = sum(nums)
        r = total % p
        if r == 0:
            return 0  # 总和已经可被 p 整除

        n = len(nums)
        # 哈希表：前缀和余数 -> 最后一次出现的位置
        last_seen = {0: -1}  # 前缀和为 0 在 -1 位置
        prefix = 0
        ans = n  # 初始为最长（不可能移除全部数组）

        for i, num in enumerate(nums):
            prefix = (prefix + num) % p
            # 需要找 prefix - r (mod p)
            target = (prefix - r) % p
            if target in last_seen:
                length = i - last_seen[target]
                ans = min(ans, length)
            last_seen[prefix] = i

        return ans if ans < n else -1
```

### 方法二：更详细的注释版

```python
from typing import List

class Solution:
    def minSubarray(self, nums: List[int], p: int) -> int:
        n = len(nums)
        r = sum(nums) % p
        if r == 0:
            return 0

        # prefix[i] % p = 当前前缀和模 p
        # 要找最短区间 [l+1, i] 使 (prefix[i] - prefix[l]) % p = r
        # 即 prefix[l] % p = (prefix[i] - r) % p = (prefix[i] + p - r) % p

        seen = {0: -1}  # {前缀和 % p : 最后出现的下标}
        psum = 0
        ans = n

        for i in range(n):
            psum = (psum + nums[i]) % p
            need = (psum - r + p) % p  # 等价于 (psum - r) % p
            if need in seen:
                ans = min(ans, i - seen[need])
            seen[psum] = i  # 更新最新位置

        return -1 if ans == n else ans
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)（哈希表大小最多 min(N, p)）

## 关键点总结

1. 等价于找最短子数组，其和 ≡ `total % p (mod p)`
2. 前缀和 + 哈希表技巧（类似"和为 K 的子数组"）
3. 哈希表存**最新**位置（因为要最短的区间）

## 易错点

- 哈希表存最新（而非最早）位置，因为 `i - last_seen[target]` 越小越好
- 要排除移除全部数组的情况（`ans < n`）
- `target = (prefix - r + p) % p` 处理负数取模
