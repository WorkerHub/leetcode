## 题目描述

给你一个正整数数组 `nums`，请你帮忙从该数组中找出能满足下面要求的最长前缀，并返回该前缀的长度：

- 从前缀中恰好删除一个元素后，剩下每个数字的出现次数都相同。

如果删除这个元素后没有剩余元素存在，仍可认为每个出现的数字都具有相同的出现次数（也就是 0 次）。

示例 1：
```
输入：nums = [2,2,1,1,5,3,3,5]
输出：7
解释：对于长度为 7 的子数组 [2,2,1,1,5,3,3]，如果我们从中删去 nums[4] = 5，就可以得到 [2,2,1,1,3,3]，里面每个数字都出现了两次。
```

示例 2：
```
输入：nums = [1,1,1,2,2,2,3,3,3,4,4,4,5]
输出：13
```

提示：
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

这道题的关键在于判断一个前缀是否满足"删除一个元素后每个数字出现次数相同"。我们需要维护以下信息：

1. 每个数字的出现次数（freq）
2. 每个出现次数对应有多少个数字（freqCount）
3. 当前最大出现次数（maxFreq）

满足条件的情况有以下几种：

1. 所有数字都只出现 1 次：删除任意一个即可
2. 所有数字出现次数相同，且只有 1 个数字：删除这个数字
3. 所有数字出现次数相同，都是 k 次，只有一个数字出现 k+1 次：删除那个多出来的
4. 所有数字都出现 k 次，只有一个数字出现 1 次：删除那个只出现 1 次的
5. 只有一种数字，删除一个后还能保持一致

## Python 代码实现

### 方法一：哈希表 + 频率统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxEqualFreq(self, nums: List[int]) -> int:
        # freq[num] 记录数字 num 出现的次数
        freq = defaultdict(int)
        # freqCount[f] 记录出现次数为 f 的数字有多少个
        freqCount = defaultdict(int)
        maxFreq = 0  # 当前最大出现次数
        maxLen = 0   # 满足条件的最大前缀长度
        
        for i, num in enumerate(nums):
            # 更新数字 num 的频率
            if freq[num] > 0:
                freqCount[freq[num]] -= 1
                if freqCount[freq[num]] == 0:
                    del freqCount[freq[num]]
            
            freq[num] += 1
            freqCount[freq[num]] += 1
            maxFreq = max(maxFreq, freq[num])
            
            length = i + 1  # 当前前缀长度
            
            # 判断是否满足条件的几种情况
            # 情况1: 所有数字都只出现 1 次
            if maxFreq == 1:
                maxLen = length
            
            # 情况2: 所有数字出现次数相同，且总共只有 1 个数字
            elif length == maxFreq:
                maxLen = length
            
            # 情况3: 只有两种不同的出现次数
            elif len(freqCount) == 2:
                freq1, freq2 = sorted(freqCount.keys())
                count1, count2 = freqCount[freq1], freqCount[freq2]
                
                # 情况3a: 高频次只比低频次多 1，且高频次只有 1 个数字
                if freq2 == freq1 + 1 and count2 == 1:
                    maxLen = length
                # 情况3b: 低频次是 1，且只有 1 个这样的数字
                elif freq1 == 1 and count1 == 1:
                    maxLen = length
                # 情况3c: 高频次的数字只有 1 个，删除后剩余长度等于低频次 * 数字个数
                elif count2 == 1 and freq1 * count1 == length - freq2:
                    maxLen = length
                # 情况3d: 低频次的数字只有 1 个，删除后剩余长度等于高频次 * 数字个数
                elif count1 == 1 and freq2 * count2 == length - freq1:
                    maxLen = length
            
            # 情况4: 只有一种出现次数
            elif len(freqCount) == 1:
                freq_val = list(freqCount.keys())[0]
                count = freqCount[freq_val]
                
                # 所有数字都出现 k 次，总共只有 1 个数字
                if count == 1:
                    maxLen = length
                # 所有数字都出现 k 次，删除一个后剩余长度是 k * (count - 1)
                elif freq_val * count == length - 1:
                    maxLen = length
                # 所有数字都出现 k 次，删除一个数字的一次出现
                elif freq_val * count == length - freq_val:
                    maxLen = length
        
        return maxLen
```

### 方法二：简化版判断

```python
from typing import List
from collections import Counter

class Solution:
    def maxEqualFreq(self, nums: List[int]) -> int:
        freq = Counter()
        freqCount = Counter()
        maxFreq = 0
        res = 0
        
        for i, num in enumerate(nums):
            # 更新频率
            if freq[num]:
                freqCount[freq[num]] -= 1
            freq[num] += 1
            freqCount[freq[num]] += 1
            maxFreq = max(maxFreq, freq[num])
            
            length = i + 1
            
            # 检查五种有效情况
            if (maxFreq * freqCount[maxFreq] == length - 1 or  # 删除一个最高频的
                (maxFreq - 1) * freqCount[maxFreq] == length - maxFreq or  # 最高频的只有一个
                maxFreq == 1 or  # 所有元素都出现 1 次
                length == maxFreq + 1 or  # 只有两个不同元素
                freqCount[1] == 1 and maxFreq * (freqCount[maxFreq]) == length - 1):  # 有一个元素出现 1 次
                res = length
        
        return res
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，其中 n 是数组长度，只需要遍历一次数组
- 空间复杂度：O(n)，需要存储频率哈希表和频率计数哈希表

**方法二：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 需要同时维护数字频率和频率计数两个哈希表
2. 关键是枚举所有满足条件的情况，不要遗漏
3. 删除一个元素后满足条件的核心情况：
   - 所有数字频率都是 1
   - 只有一个数字
   - 有一个数字只出现 1 次，其他都相同
   - 有一个数字比其他多出现 1 次
4. 需要特别注意边界情况的处理

## 易错点

1. 忘记更新 freqCount 时要先减少旧频率的计数
2. 判断条件不全，遗漏某些合法情况
3. 没有正确处理只有一种频率或两种频率的情况
4. 边界条件：数组长度为 1 或 2 的特殊处理
