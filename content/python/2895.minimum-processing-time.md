## 题目描述

有 `n` 个处理器，每个处理器有 4 个核心。给你一个长度为 `n` 的整数数组 `processorTime`，表示每个处理器的**空闲时刻**（即从该时刻起可以开始执行任务）。

另有 `4 * n` 个任务，每个任务用时 `tasks[i]`。将这 `4*n` 个任务分配给 n 个处理器，每个处理器分配恰好 4 个任务（同时执行）。

返回所有任务完成的**最早时间**。

**示例 1：**
```
输入：processorTime = [8, 10], tasks = [2, 2, 3, 1, 8, 7, 4, 5]
输出：16
解释：
处理器 0 在时刻 8 空闲，分配任务耗时最大的 4 个：8,7,5,4
完成时刻 = 8 + 8 = 16
处理器 1 在时刻 10 空闲，分配剩余任务：3,2,2,1
完成时刻 = 10 + 3 = 13
答案 = max(16, 13) = 16
```

**示例 2：**
```
输入：processorTime = [10, 20], tasks = [2, 3, 1, 2, 5, 8, 4, 3]
输出：23
```

**提示：**
- `1 <= n <= 25000`
- `1 <= processorTime.length == n`
- `tasks.length == 4 * n`
- `1 <= processorTime[i], tasks[i] <= 10^9`

## 解题思路

**贪心策略：**

- 空闲时刻越晚的处理器，应该分配用时越短的任务（否则会增大完成时间）。
- 等价地：空闲时刻越早的处理器，分配用时最长的 4 个任务。

**证明：**

设两处理器空闲时刻 a < b，任务组 (big4) 和 (small4)。
- 方案1：a 处理 big4，完成 = a + max(big4)；b 处理 small4，完成 = b + max(small4)
- 方案2：a 处理 small4，完成 = a + max(small4)；b 处理 big4，完成 = b + max(big4)
- max(方案1) vs max(方案2)：由于 a < b 且 max(big4) > max(small4)，方案1更优。

**步骤：**
1. 将 `processorTime` 升序排序
2. 将 `tasks` 降序排序
3. 第 i 个处理器（从小到大）分配任务 `tasks[4i..4i+3]`（最大的 4 个）
4. 取所有完成时刻的最大值

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minProcessingTime(self, processorTime: List[int], tasks: List[int]) -> int:
        # 处理器按空闲时刻升序，任务按用时降序
        processorTime.sort()
        tasks.sort(reverse=True)

        ans = 0
        for i, t in enumerate(processorTime):
            # 第 i 个处理器分配任务 tasks[4i], tasks[4i+1], tasks[4i+2], tasks[4i+3]
            # 完成时刻 = 空闲时刻 + 4个任务中最大用时（即 tasks[4i]）
            ans = max(ans, t + tasks[4 * i])

        return ans
```

### 方法二：zip 写法

```python
from typing import List

class Solution:
    def minProcessingTime(self, processorTime: List[int], tasks: List[int]) -> int:
        processorTime.sort()
        tasks.sort(reverse=True)

        # 每个处理器空闲时刻 + 该批任务最大值（即 tasks[4i]）
        return max(
            t + tasks[4 * i]
            for i, t in enumerate(processorTime)
        )
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（忽略排序的辅助空间）

## 关键点总结

1. 贪心：最早空闲的处理器配最耗时的任务
2. 处理器完成时刻 = `processorTime[i] + tasks[4*i]`（每批任务最大值决定完成时间）
3. 每个处理器 4 个任务同时执行，完成时间取决于最慢的那个

## 易错点

1. 每个处理器的 4 个任务同时执行，不是顺序执行
2. 要返回所有处理器的最大完成时刻
