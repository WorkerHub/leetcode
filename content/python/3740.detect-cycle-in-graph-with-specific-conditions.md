## 题目描述

给定一个有 `n` 个节点的有向图，边集为 `edges`，其中 `edges[i] = [u, v]` 表示从节点 `u` 到节点 `v` 有一条有向边。

判断该图中是否存在有向环。若存在返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：n = 4, edges = [[0,1],[1,2],[2,0],[3,0]]
输出：true
解释：存在环 0->1->2->0。
```

**示例 2：**
```
输入：n = 3, edges = [[0,1],[1,2]]
输出：false
解释：图是 DAG，无环。
```

**提示：**
- `2 <= n <= 10^4`
- `0 <= edges.length <= 2 * 10^4`

## 解题思路

**方法一：DFS 染色（三色标记法）**

- 白色（0）：未访问
- 灰色（1）：正在 DFS 中（在栈中）
- 黑色（2）：已完成 DFS

若 DFS 过程中遇到灰色节点，说明存在环。

**方法二：拓扑排序（Kahn 算法）**

若图中存在环，则不是 DAG，拓扑排序无法处理所有节点。统计拓扑排序后处理的节点数，若小于 n 则有环。

## Python 代码实现

### 方法一：DFS 三色标记（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def hasCycle(self, n: int, edges: List[List[int]]) -> bool:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)

        # 0: 未访问，1: 访问中，2: 已完成
        color = [0] * n

        def dfs(u: int) -> bool:
            color[u] = 1  # 标记为访问中
            for v in graph[u]:
                if color[v] == 1:
                    return True  # 发现环
                if color[v] == 0 and dfs(v):
                    return True
            color[u] = 2  # 标记为已完成
            return False

        for i in range(n):
            if color[i] == 0:
                if dfs(i):
                    return True
        return False
```

### 方法二：拓扑排序（BFS）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def hasCycle(self, n: int, edges: List[List[int]]) -> bool:
        graph = defaultdict(list)
        in_degree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            in_degree[v] += 1

        queue = deque([i for i in range(n) if in_degree[i] == 0])
        visited = 0

        while queue:
            u = queue.popleft()
            visited += 1
            for v in graph[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)

        return visited != n  # 若未能处理所有节点，则有环
```

## 复杂度分析

- 时间复杂度：O(n + m)，DFS 或 BFS 各线性
- 空间复杂度：O(n + m)

## 关键点总结

1. DFS 三色标记：灰色节点代表当前 DFS 路径上的节点，再次遇到灰色即为环
2. 拓扑排序：有环的图无法完成拓扑排序
3. 两种方法时间复杂度相同，拓扑排序更易理解

## 易错点

1. DFS 需要对所有节点发起（处理不连通图）
2. 拓扑排序中，自环会导致节点入度永远不为 0
