## 题目描述

给你一个只包含正整数的非空数组 nums。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**
```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11]
```

**示例 2：**
```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集
```

## 解题思路

这是一个经典的 0-1 背包问题。

核心观察：
1. 如果总和是奇数，不可能分成两个相等的子集
2. 问题转化为：能否从数组中选择若干数字，使得和为 total / 2

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        """
        0-1 背包问题
        dp[i] 表示是否能凑出和为 i
        """
        total = sum(nums)
        
        # 总和为奇数，不可能分成两个相等的子集
        if total % 2:
            return False
        
        target = total // 2
        
        # dp[i] 表示能否凑出和为 i
        dp = [False] * (target + 1)
        dp[0] = True  # 和为 0 总是可以（不选任何数）
        
        for num in nums:
            # 从后向前遍历，避免重复使用
            for i in range(target, num - 1, -1):
                dp[i] = dp[i] or dp[i - num]
        
        return dp[target]
```

### 方法二：使用集合

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        """
        使用集合记录所有可能的和
        """
        total = sum(nums)
        if total % 2:
            return False
        
        target = total // 2
        possible_sums = {0}
        
        for num in nums:
            # 创建新集合存储新的可能和
            new_sums = set()
            for s in possible_sums:
                if s + num == target:
                    return True
                new_sums.add(s + num)
            possible_sums.update(new_sums)
        
        return target in possible_sums
```

### 方法三：位运算优化

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        """
        使用位运算表示所有可能的和
        """
        total = sum(nums)
        if total % 2:
            return False
        
        target = total // 2
        bits = 1  # 初始只有 0 可达
        
        for num in nums:
            bits |= bits << num
        
        return (bits >> target) & 1
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n * target)
- **空间复杂度**：O(target)

## 关键点总结

1. 转化为 0-1 背包问题
2. 目标是 sum / 2
3. 从后向前更新避免重复使用

## 易错点

1. 忘记判断总和是否为奇数
2. 背包 DP 遍历顺序错误（应从后向前）
