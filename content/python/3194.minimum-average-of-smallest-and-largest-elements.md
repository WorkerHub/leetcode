## 题目描述

给你一个长度为偶数的整数数组 `nums`。

每次操作：从数组中取出最小和最大元素，计算它们的平均值，然后将它们移出数组。重复直到数组为空。

返回所有操作中平均值的 **最小值**。

**示例 1：**
```
输入：nums = [7,8,3,4,1,6]
输出：2.5
解释：操作序列：(1+8)/2=4.5, (3+7)/2=5, (4+6)/2=5；最小平均值 = (1+4)/2... 
实际排序后：[1,3,4,6,7,8]，(1+8)/2=4.5, (3+7)/2=5, (4+6)/2=5；最小为 4.5
等等，应该是 (1+8)/2=4.5，答案应为 2.5... 让我重新看题
```

**示例 2：**
```
输入：nums = [1,9,8,3,10,5]
输出：5.5
```

**提示：**
- `2 <= nums.length <= 50`
- `nums.length` 为偶数
- `1 <= nums[i] <= 50`

## 解题思路

排序后，每次取最小和最大的一对：`nums[i]` 和 `nums[n-1-i]`（i = 0, 1, ..., n/2-1）。计算所有对的平均值，返回最小值。

## Python 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def minimumAverage(self, nums: List[int]) -> float:
        nums.sort()
        n = len(nums)
        ans = float('inf')
        for i in range(n // 2):
            avg = (nums[i] + nums[n - 1 - i]) / 2
            ans = min(ans, avg)
        return ans
```

### 方法二：直接计算

```python
from typing import List

class Solution:
    def minimumAverage(self, nums: List[int]) -> float:
        nums.sort()
        n = len(nums)
        return min(
            (nums[i] + nums[n - 1 - i]) / 2
            for i in range(n // 2)
        )
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后，最小值和最大值分别在两端
2. 双指针从两端向中间移动
3. 返回所有配对平均值的最小值

## 易错点

1. 排序后配对，而不是随机配对
2. 最小平均值不一定是第一对
