## 题目描述

给你一个数组 `skill`，长度为偶数 `n`，将 `n` 个玩家分成 `n/2` 支队伍，每支队伍恰好 2 名玩家。

要求：所有队伍的技能总和相同。

返回所有队伍的 **化学值** 之和（每支队伍的化学值 = 两名玩家技能值的乘积）。

若无法满足条件，返回 `-1`。

**提示：**
- `2 <= skill.length <= 10^5`
- `1 <= skill[i] <= 1000`
- `skill.length` 是偶数

## 解题思路

**排序 + 双指针：**

若每队技能总和相同，则排序后，最小和最大配对、次小和次大配对……

1. 对 skill 排序
2. 用双指针：左指针指向最小值，右指针指向最大值
3. 检查每对的和是否相同（第一对的和作为目标）
4. 累加每对的乘积

## 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def dividePlayers(self, skill: List[int]) -> int:
        skill.sort()
        n = len(skill)
        target = skill[0] + skill[n - 1]  # 目标队伍技能和
        ans = 0

        left, right = 0, n - 1
        while left < right:
            if skill[left] + skill[right] != target:
                return -1  # 无法满足条件
            ans += skill[left] * skill[right]
            left += 1
            right -= 1

        return ans
```

### 方法二：哈希表（不排序）

```python
from typing import List
from collections import Counter

class Solution:
    def dividePlayers(self, skill: List[int]) -> int:
        count = Counter(skill)
        n = len(skill)
        target = sum(skill) * 2 // n  # 每队技能总和

        ans = 0
        visited = set()
        for s in skill:
            if s in visited:
                continue
            need = target - s
            if need not in count:
                return -1
            if need == s:
                if count[s] < 2:
                    return -1
                ans += s * s * (count[s] // 2)
                count[s] = 0
            else:
                if count[s] != count[need]:
                    return -1
                ans += s * need * count[s]
                count[s] = 0
                count[need] = 0
            visited.add(s)
            visited.add(need)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+双指针 | O(n log n) | O(1) |
| 哈希表 | O(n) | O(n) |

## 关键点总结

1. 排序后，最小和最大必须配对（因为若最小不和最大配，剩余的和将无法平衡）
2. 目标和 = 总和 * 2 / n（每队 2 人）
3. 双指针验证每对的和

## 易错点

- 若任意一对的和不等于目标，立即返回 -1
- 化学值是两人技能的**乘积**而非和
