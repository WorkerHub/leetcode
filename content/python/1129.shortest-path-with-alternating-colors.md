## 题目描述

在一个有向图中，节点分别标记为 `0, 1, ..., n-1`。图中每条边要么是红色，要么是蓝色，且存在自环或平行边。

`red_edges` 中的每一个 `[i, j]` 对表示从节点 `i` 到节点 `j` 的红色有向边。类似地，`blue_edges` 中的每一个 `[i, j]` 对表示从节点 `i` 到节点 `j` 的蓝色有向边。

返回长度为 `n` 的数组 `answer`，其中 `answer[X]` 是从节点 `0` 到节点 `X` 的红色边和蓝色边交替出现的最短路径的长度。如果不存在这样的路径，那么 `answer[X] = -1`。

**示例 1：**
```
输入：n = 3, red_edges = [[0,1],[1,2]], blue_edges = []
输出：[0,1,-1]
解释：从节点 0 到节点 1 有红色边，从节点 1 到节点 2 没有蓝色边，所以无法到达节点 2。
```

**示例 2：**
```
输入：n = 3, red_edges = [[0,1]], blue_edges = [[2,1]]
输出：[0,1,-1]
解释：从节点 0 到节点 1 有红色边，但从节点 1 无法通过蓝色边到达节点 2。
```

**示例 3：**
```
输入：n = 3, red_edges = [[1,0]], blue_edges = [[2,1]]
输出：[0,-1,-1]
解释：从节点 0 无法到达其他节点。
```

**示例 4：**
```
输入：n = 3, red_edges = [[0,1],[0,2]], blue_edges = [[1,0]]
输出：[0,1,1]
```

**提示：**
- `1 <= n <= 100`
- `red_edges.length <= 400`
- `blue_edges.length <= 400`
- `red_edges[i].length == blue_edges[i].length == 2`
- `0 <= red_edges[i][j], blue_edges[i][j] < n`

## 解题思路

这是一个带约束的最短路径问题，约束是**边的颜色必须交替出现**（红-蓝-红-蓝...）。

### 核心思想

使用**广度优先搜索（BFS）**，但需要区分当前路径的最后一条边的颜色。

### 状态设计

- 普通 BFS：状态只有节点编号
- 本题 BFS：状态是 `(节点编号, 最后一条边的颜色)`

### 算法流程

1. 构建红色边和蓝色边的邻接表
2. 使用 BFS，从节点 0 开始，初始状态有两种：
   - `(0, RED)` - 下一步走红色边
   - `(0, BLUE)` - 下一步走蓝色边
3. 每次扩展时，只能走与当前颜色不同的边
4. 记录到达每个节点（通过不同颜色）的最短距离
5. 最终答案取每个节点的两种颜色到达方式的最小值

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def shortestAlternatingPaths(self, n: int, red_edges: List[List[int]], blue_edges: List[List[int]]) -> List[int]:
        # 构建邻接表
        red_graph = defaultdict(list)
        blue_graph = defaultdict(list)
        
        for u, v in red_edges:
            red_graph[u].append(v)
        
        for u, v in blue_edges:
            blue_graph[u].append(v)
        
        # 初始化结果数组
        answer = [-1] * n
        answer[0] = 0  # 起点距离为 0
        
        # BFS 队列：(节点, 最后一条边的颜色, 距离)
        # 颜色用 0 表示红色，1 表示蓝色
        queue = deque([(0, 0, 0), (0, 1, 0)])  # 从节点 0 开始，可以先走红色或蓝色边
        
        # 访问标记：(节点, 颜色) 避免重复访问
        visited = set([(0, 0), (0, 1)])
        
        while queue:
            node, last_color, dist = queue.popleft()
            
            # 根据上一条边的颜色，选择下一步应该走的颜色
            # 如果上一条是红色(0)，下一步走蓝色(1)；反之亦然
            next_color = 1 - last_color
            next_graph = blue_graph if next_color == 1 else red_graph
            
            # 遍历下一步可以到达的节点
            for next_node in next_graph[node]:
                if (next_node, next_color) not in visited:
                    visited.add((next_node, next_color))
                    queue.append((next_node, next_color, dist + 1))
                    
                    # 更新答案（取最小值）
                    if answer[next_node] == -1:
                        answer[next_node] = dist + 1
                    else:
                        answer[next_node] = min(answer[next_node], dist + 1)
        
        return answer
```

### 方法二：使用枚举类型（可读性更好）

```python
from typing import List
from collections import deque, defaultdict
from enum import Enum

class Color(Enum):
    RED = 0
    BLUE = 1

class Solution:
    def shortestAlternatingPaths(self, n: int, red_edges: List[List[int]], blue_edges: List[List[int]]) -> List[int]:
        # 构建图：graph[color][node] = [邻居节点列表]
        graph = {
            Color.RED: defaultdict(list),
            Color.BLUE: defaultdict(list)
        }
        
        for u, v in red_edges:
            graph[Color.RED][u].append(v)
        
        for u, v in blue_edges:
            graph[Color.BLUE][u].append(v)
        
        # 距离数组：dist[node][color] = 从起点通过该颜色到达该节点的最短距离
        INF = float('inf')
        dist = [[INF, INF] for _ in range(n)]
        dist[0][Color.RED.value] = 0
        dist[0][Color.BLUE.value] = 0
        
        # BFS
        queue = deque([(0, Color.RED, 0), (0, Color.BLUE, 0)])
        visited = set([(0, Color.RED), (0, Color.BLUE)])
        
        while queue:
            node, last_color, d = queue.popleft()
            
            # 下一步要走的颜色（交替）
            next_color = Color.BLUE if last_color == Color.RED else Color.RED
            
            for next_node in graph[next_color][node]:
                if (next_node, next_color) not in visited:
                    visited.add((next_node, next_color))
                    dist[next_node][next_color.value] = d + 1
                    queue.append((next_node, next_color, d + 1))
        
        # 构建答案：每个节点取两种颜色的最小值
        answer = []
        for i in range(n):
            min_dist = min(dist[i][0], dist[i][1])
            answer.append(min_dist if min_dist != INF else -1)
        
        return answer
```

### 方法三：简化版本

```python
from typing import List
from collections import deque

class Solution:
    def shortestAlternatingPaths(self, n: int, red_edges: List[List[int]], blue_edges: List[List[int]]) -> List[int]:
        # 构建邻接表：graph[0] 存储红色边，graph[1] 存储蓝色边
        graph = [defaultdict(list) for _ in range(2)]
        
        for u, v in red_edges:
            graph[0][u].append(v)
        
        for u, v in blue_edges:
            graph[1][u].append(v)
        
        # 初始化
        answer = [-1] * n
        answer[0] = 0
        
        # BFS：(节点, 颜色, 距离)
        queue = deque([(0, 0, 0), (0, 1, 0)])
        visited = {(0, 0), (0, 1)}
        
        while queue:
            node, color, dist = queue.popleft()
            
            # 下一步的颜色
            next_color = 1 - color
            
            for neighbor in graph[next_color][node]:
                if (neighbor, next_color) not in visited:
                    visited.add((neighbor, next_color))
                    queue.append((neighbor, next_color, dist + 1))
                    
                    if answer[neighbor] == -1:
                        answer[neighbor] = dist + 1
                    else:
                        answer[neighbor] = min(answer[neighbor], dist + 1)
        
        return answer
```

## 复杂度分析

- **时间复杂度**：O(n + E)，其中 E 是边的总数。每个节点和每条边最多访问常数次（每种颜色各一次）。
- **空间复杂度**：O(n + E)，用于存储图和访问标记。

## 关键点总结

1. **状态扩展**：将普通图搜索的状态 `(节点)` 扩展为 `(节点, 颜色)`
2. **BFS 应用**：保证找到的第一条路径就是最短路径
3. **交替颜色**：通过 `1 - color` 实现颜色切换（0 ↔ 1）
4. **访问标记**：`(节点, 颜色)` 二元组作为访问标记，避免重复
5. **初始状态**：从节点 0 开始，可以选择先走红色边或蓝色边，所以有两个初始状态
6. **最小值更新**：同一个节点可以通过不同颜色的路径到达，取最小值

## 易错点

1. **初始状态设置**：必须同时加入 `(0, RED)` 和 `(0, BLUE)` 两个初始状态
2. **访问标记维度**：不能只标记节点，必须标记 `(节点, 颜色)` 组合
3. **颜色切换逻辑**：下一步的颜色应该与当前颜色相反
4. **答案更新时机**：第一次到达某节点时记录距离，后续到达时更新为最小值
5. **无法到达的节点**：初始化为 -1，如果 BFS 结束后仍为 -1，说明无法到达
