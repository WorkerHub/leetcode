## 题目描述

给你一个二维整数数组 `intervals`，其中 `intervals[i] = [left_i, right_i, weight_i]`。

你需要从中选择一些**不重叠**的区间（两个区间重叠当且仅当它们有公共点），最大化所选区间权重之和。

但有个额外限制：你需要将所选区间分为**4 组**，每组可以是空组，每组内的区间也不重叠。最终每组选取权重最大的那个区间代表该组，4 组权重之和为得分。

更准确地说：选 4 个不重叠区间（允许重复选），最大化它们的权重和。

**示例 1：**

```
输入：intervals = [[1,3,2],[4,5,2],[1,5,5],[8,10,1]]
输出：11
解释：选择 [1,5,5] 和 [8,10,1] 等... 实际需要选 4 个，可以重复
```

**提示：**
- `1 <= intervals.length <= 10^5`
- `1 <= left_i <= right_i <= 10^5`
- `1 <= weight_i <= 10^9`

## 解题思路

这是一个 DP 问题：选 4 个不重叠区间（可重复）最大化权重和。

设 `dp[k][i]` = 从前 i 个区间（按右端点排序）中选 k 个不重叠区间的最大权重和。

转移：对于第 i 个区间：
- 不选：`dp[k][i] = dp[k][i-1]`
- 选：`dp[k][i] = dp[k-1][j] + weight[i]`，其中 j 是最后一个右端点 < left[i] 的区间

用二分查找找 j，预计算 `dp[k-1]` 的前缀最大值。

## Python 代码实现

### 方法一：DP + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumScore(self, intervals: List[List[int]]) -> int:
        # 按右端点排序
        intervals.sort(key=lambda x: x[1])
        n = len(intervals)

        rights = [x[1] for x in intervals]

        # dp[k][i]: 从前 i 个区间选 k 个不重叠区间的最大权重
        # 只需要 4 层
        INF = float('-inf')

        # 初始化：dp[0] 全 0（选 0 个），dp[k] 初始 -inf
        prev = [0] * (n + 1)  # dp[k-1][i], 带前缀最大

        for k in range(1, 5):
            curr = [INF] * (n + 1)
            # curr[i] = 考虑前 i 个区间（1-indexed）选 k 个的最大值
            curr[0] = INF  # 选了 k 个但没有区间，不合法

            for i in range(1, n + 1):
                left_i, right_i, weight_i = intervals[i - 1]
                # 不选第 i 个区间
                curr[i] = curr[i - 1] if curr[i - 1] != INF else INF

                # 选第 i 个区间：找最后一个 right < left_i 的区间 j
                # 在 rights[0..n-1] 中找最后一个 < left_i 的位置
                j = bisect.bisect_left(rights, left_i, 0, i - 1)
                # j 是第一个 >= left_i 的位置，j-1 是最后一个 < left_i 的位置
                # prev[j] 是选了 k-1 个区间（前 j 个中）的最大值
                best_prev = prev[j] if prev[j] != INF else INF
                if best_prev != INF:
                    val = best_prev + weight_i
                    curr[i] = max(curr[i], val) if curr[i] != INF else val

            # 计算前缀最大值
            prev = [INF] * (n + 1)
            prev[0] = 0 if k == 0 else INF
            running_max = INF
            for i in range(1, n + 1):
                if curr[i] != INF:
                    running_max = max(running_max, curr[i]) if running_max != INF else curr[i]
                prev[i] = running_max

        return prev[n] if prev[n] != INF else 0
```

### 方法二：清晰实现版

```python
from typing import List
import bisect

class Solution:
    def maximumScore(self, intervals: List[List[int]]) -> int:
        intervals.sort(key=lambda x: x[1])
        n = len(intervals)
        rights = [x[1] for x in intervals]

        # dp[k][i]: 从前 i 个中选恰好 k 个不重叠区间的最大权重
        # 用滚动数组
        NEG_INF = float('-inf')
        # prev_max[i]: dp[k-1] 的前 i 个最大值（前缀最大）
        prev_max = [0] * (n + 1)  # k=0 时，选 0 个，权重为 0

        ans = 0

        for k in range(1, 5):
            dp = [NEG_INF] * (n + 1)

            for i in range(1, n + 1):
                left_i, right_i, weight_i = intervals[i - 1]

                # 不选第 i 个
                if dp[i - 1] != NEG_INF:
                    dp[i] = dp[i - 1]

                # 选第 i 个：找最后一个 right < left_i 的 j
                pos = bisect.bisect_left(rights, left_i, 0, i - 1)
                # rights[0..pos-1] < left_i（当 left_i 范围适当）
                # 实际上要找 right_j < left_i（严格小于，表示不重叠）
                # 重新确认：若 left_i = right_j 表示边界相邻，是否重叠？
                # 题意：两区间重叠当且仅当有公共点，所以 [1,3] 和 [3,5] 重叠
                # 因此需要 right_j < left_i（严格）
                pos2 = bisect.bisect_left(rights, left_i, 0, i - 1)
                if pos2 > 0 and prev_max[pos2] != NEG_INF:
                    val = prev_max[pos2] + weight_i
                    dp[i] = max(dp[i], val) if dp[i] != NEG_INF else val
                elif pos2 == 0 and prev_max[0] != NEG_INF:
                    val = prev_max[0] + weight_i
                    dp[i] = max(dp[i], val) if dp[i] != NEG_INF else val

            # 更新 prev_max（前缀最大值）
            prev_max = [NEG_INF] * (n + 1)
            prev_max[0] = NEG_INF
            for i in range(1, n + 1):
                prev_max[i] = max(prev_max[i - 1], dp[i]) if dp[i] != NEG_INF else prev_max[i - 1]

            if prev_max[n] != NEG_INF:
                ans = max(ans, prev_max[n])

        return ans
```

## 复杂度分析

- 时间复杂度：O(4 * n log n)，4 层 DP，每层 O(n log n)
- 空间复杂度：O(n)，滚动数组

## 关键点总结

1. 排序后才能用二分查找找"不重叠的前一个区间"
2. DP 层数固定为 4，用滚动数组优化空间
3. 前缀最大值避免重复计算最优前驱

## 易错点

1. 不重叠判断：两区间有公共点即重叠，所以需要 `right_j < left_i`（严格小于）
2. 二分查找要在排好序的 rights 数组中进行
3. INF 和 NEG_INF 的处理要一致
