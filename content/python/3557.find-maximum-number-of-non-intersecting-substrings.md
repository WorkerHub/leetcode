## 题目描述

给定一个字符串 `s` 和整数 `k`。从字符串中找出最多数量的不相交（不重叠）长度为 `k` 的子字符串，使得这些子字符串两两不同。返回能找到的最大数量。

**示例 1：**

```
输入：s = "abcabc", k = 2
输出：3
解释：不重叠的长度为2的不同子串："ab"(0-1), "ca"(2-3), "bc"(4-5)，共3个。
```

**示例 2：**

```
输入：s = "aaaa", k = 2
输出：1
解释：只有 "aa"（0-1 或 1-2 或 2-3），重叠的话取一个，最多1个。
```

**提示：**
- `1 <= k <= s.length <= 10^5`

## 解题思路

贪心策略：从左到右扫描，尽可能早地选取不重叠且唯一的子串。

使用哈希表记录每种子串的最后一次出现位置（或最早出现位置用于贪心）。

实际上：找所有不重叠的长度为 k 的不同子串的最大数量。

贪心：按从左到右的顺序，遇到新的（未选过的）子串时，选取它，并将下一个可选位置移动到当前结束位置之后。

## Python 代码实现

### 方法一：贪心 + 哈希表（推荐）

```python
class Solution:
    def maxNonIntersecting(self, s: str, k: int) -> int:
        n = len(s)
        seen = set()  # 已选的子串
        count = 0
        i = 0  # 当前可选的起始位置

        while i + k <= n:
            sub = s[i:i+k]
            if sub not in seen:
                seen.add(sub)
                count += 1
                i += k  # 跳过当前子串
            else:
                i += 1  # 移动一位继续找

        return count
```

### 方法二：记录首次出现位置

```python
class Solution:
    def maxNonIntersecting(self, s: str, k: int) -> int:
        n = len(s)
        # 记录每个子串的首次出现位置
        first_occurrence = {}
        for i in range(n - k + 1):
            sub = s[i:i+k]
            if sub not in first_occurrence:
                first_occurrence[sub] = i

        # 按首次出现位置贪心选取不重叠的子串
        chosen = []
        for sub, pos in sorted(first_occurrence.items(), key=lambda x: x[1]):
            if not chosen or chosen[-1][1] + k <= pos:
                chosen.append((sub, pos))

        return len(chosen)
```

## 复杂度分析

- 时间复杂度：O(n * k)（字符串哈希），O(n * k log n)（方法二排序）
- 空间复杂度：O(n * k)，存储哈希

## 关键点总结

1. 贪心：优先选最早出现的不重叠唯一子串
2. 使用哈希集合确保选取的子串两两不同
3. 选取后更新下一个可选的起始位置

## 易错点

1. 子串必须不重叠（选后下一个起始位置是当前结束位置 + 1）
2. 两两不同（不能选同一个子串两次）
3. 方法一的贪心中，遇到已见过的子串要跳一位而非跳 k 位
