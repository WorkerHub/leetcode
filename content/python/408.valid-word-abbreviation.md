## 题目描述

给定一个非空字符串 word 和一个缩写 abbr，判断这个缩写是否可以是给定单词的缩写。

字符串 "word" 的所有有效缩写为：
```
["word", "1ord", "w1rd", "wo1d", "wor1", "2rd", "w2d", "wo2", "1o1d", "1or1", "w1r1", "1o2", "2r1", "3d", "w3", "4"]
```

注意单词 "word" 的缩写仅由以下两种形式组成：
- a) 连续的字母
- b) 数字表示被省略的字母的数量

注意事项：
- 假设 word 仅包含小写字母，abbr 仅包含小写字母和数字
- 缩写中的数字不会有前导零

**示例 1：**
```
输入：word = "internationalization", abbr = "i12iz4n"
输出：true
解释：单词 "internationalization" 可以缩写为 "i12iz4n" ("i nternalizatio n")
```

**示例 2：**
```
输入：word = "apple", abbr = "a2e"
输出：false
解释：单词 "apple" 无法缩写为 "a2e"
```

## 解题思路

这是一道双指针问题，需要同时遍历 word 和 abbr。

核心思路：
1. 使用两个指针分别指向 word 和 abbr
2. 如果 abbr 当前字符是字母，必须和 word 对应位置匹配
3. 如果 abbr 当前字符是数字，需要读取完整数字并跳过 word 对应数量的字符
4. 注意数字不能有前导零

## Python 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def validWordAbbreviation(self, word: str, abbr: str) -> bool:
        """
        双指针遍历
        """
        i, j = 0, 0  # i 指向 word，j 指向 abbr
        
        while i < len(word) and j < len(abbr):
            if abbr[j].isdigit():
                # 数字不能有前导零
                if abbr[j] == '0':
                    return False
                
                # 读取完整的数字
                num = 0
                while j < len(abbr) and abbr[j].isdigit():
                    num = num * 10 + int(abbr[j])
                    j += 1
                
                # 跳过 word 中对应数量的字符
                i += num
            else:
                # 字母必须匹配
                if word[i] != abbr[j]:
                    return False
                i += 1
                j += 1
        
        # 两个指针都必须到达末尾
        return i == len(word) and j == len(abbr)
```

### 方法二：简化版

```python
class Solution:
    def validWordAbbreviation(self, word: str, abbr: str) -> bool:
        i = j = 0
        
        while j < len(abbr):
            if abbr[j].isdigit():
                if abbr[j] == '0':
                    return False
                
                num = 0
                while j < len(abbr) and abbr[j].isdigit():
                    num = num * 10 + int(abbr[j])
                    j += 1
                i += num
            else:
                if i >= len(word) or word[i] != abbr[j]:
                    return False
                i += 1
                j += 1
        
        return i == len(word)
```

## 复杂度分析

- **时间复杂度**：O(n + m)
  - n 是 word 的长度，m 是 abbr 的长度
  - 每个指针最多遍历一次
  
- **空间复杂度**：O(1)
  - 只使用常数额外空间

## 关键点总结

1. **前导零检查**：数字不能以 0 开头
2. **完整数字读取**：需要读取连续的数字字符
3. **边界检查**：跳过字符时不能超出 word 长度
4. **最终检查**：两个指针都必须到达末尾

## 易错点

1. 忘记检查前导零
2. 跳过字符后超出边界
3. 只检查一个指针是否到达末尾
