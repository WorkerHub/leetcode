## 题目描述

给你一个字符串数组 `ideas`，表示你在商标申请过程中考虑过的公司名字。你希望从中选出两个名字，通过交换二者的首字母构成一个新的公司名字。

如果得到的新名字不在 `ideas` 中，则认为这对组合是可行的。

返回**可行**的组合数目，其中每一对均是不同的且有序的，即 `(ideaA, ideaB)` 和 `(ideaB, ideaA)` 被视为不同的组合。

**示例 1：**
```
输入：ideas = ["coffee","donuts","time","toffee"]
输出：6
解释：以下组合可行：
("coffee","donuts")：新名字 "doffee"（不在ideas中）和 "conuts"（不在ideas中）
("donuts","coffee")：同上
("donuts","time")："tonuts"和"dime"均不在ideas中
("time","donuts")：同上
("time","coffee")："cime"和"toffee"在ideas中，不可行
```

**提示：**
- `2 <= ideas.length <= 5 * 10^4`
- `1 <= ideas[i].length <= 10`
- `ideas[i]` 由小写英文字母组成
- `ideas` 中所有字符串互不相同

## 解题思路

**核心思想：**
将每个单词拆分为首字母和后缀。对于两个首字母 `a` 和 `b`，交换首字母后两个新单词都不在 ideas 中的充要条件是：后缀 `suffix` 既在 `a` 组中出现，又在 `b` 组中出现时，该交换不可行。

定义 `suffix_set[c]` 为所有首字母为 `c` 的单词的后缀集合。

对于 `(a, b)` 这对首字母，不可行的后缀数为 `|suffix_set[a] ∩ suffix_set[b]|`，设交集大小为 `mutual`，则可行对数为：
`(|suffix_set[a]| - mutual) * (|suffix_set[b]| - mutual) * 2`

枚举所有 26*26 对首字母即可。

## 代码实现

### 方法一：哈希表枚举（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def distinctNames(self, ideas: List[str]) -> int:
        # 按首字母分组，存储后缀集合
        suffix_sets = defaultdict(set)
        for idea in ideas:
            suffix_sets[idea[0]].add(idea[1:])
        
        ans = 0
        chars = list(suffix_sets.keys())
        
        # 枚举所有首字母对 (a, b)
        for i in range(len(chars)):
            for j in range(i + 1, len(chars)):
                a, b = chars[i], chars[j]
                # 计算两个后缀集合的交集大小
                mutual = len(suffix_sets[a] & suffix_sets[b])
                # 从 a 组中去掉交集部分可用的后缀数
                cnt_a = len(suffix_sets[a]) - mutual
                # 从 b 组中去掉交集部分可用的后缀数
                cnt_b = len(suffix_sets[b]) - mutual
                # 乘以 2 因为 (a, b) 和 (b, a) 各算一次
                ans += cnt_a * cnt_b * 2
        
        return ans
```

### 方法二：位运算加速（使用整数表示集合）

```python
from typing import List
from collections import defaultdict

class Solution:
    def distinctNames(self, ideas: List[str]) -> int:
        # 对后缀编号，用整数位表示集合（适用于后缀数量不超过64时）
        # 通用方案：仍使用 set，但枚举全部26个字母
        suffix_sets = [set() for _ in range(26)]
        for idea in ideas:
            suffix_sets[ord(idea[0]) - ord('a')].add(idea[1:])
        
        ans = 0
        for i in range(26):
            for j in range(i + 1, 26):
                mutual = len(suffix_sets[i] & suffix_sets[j])
                cnt_i = len(suffix_sets[i]) - mutual
                cnt_j = len(suffix_sets[j]) - mutual
                ans += cnt_i * cnt_j * 2
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表枚举 | O(n * L + 26^2 * n) | O(n * L) |

其中 n 为 ideas 长度，L 为平均单词长度，26^2 = 676 对组合。

## 关键点总结

1. 将首字母与后缀分离，按首字母分组是解题关键。
2. 两个首字母对的可行数 = `(|A| - |A∩B|) * (|B| - |A∩B|) * 2`。
3. 枚举 26*26 = 676 对首字母，对每对计算集合交集大小。

## 易错点

- 注意每对 (a, b) 和 (b, a) 都算可行，所以要乘以 2。
- 不要忘记：只有当交换后的两个新名字都不在 ideas 中才可行。
