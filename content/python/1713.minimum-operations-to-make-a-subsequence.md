## 题目描述

给你一个数组 `target`，包含若干**互不相同**的整数，以及另一个整数数组 `arr`，`arr` 可能包含重复元素。

每次操作，你可以在 `arr` 的任意位置插入任意整数。比如，如果 `arr = [1,4,2]`，你可以在 `4` 后面插入 `3`，得到 `[1,4,3,2]`。

返回使 `target` 成为 `arr` 的一个子序列所需的最少操作次数。

**示例 1：**
```
输入：target = [5,1,3], arr = [9,4,2,3,4]
输出：2
```

**提示：**
- `1 <= target.length, arr.length <= 10^5`
- `1 <= target[i], arr[i] <= 10^9`
- `target` 中元素互不相同

## 解题思路

最少插入次数 = `len(target)` - 最长公共子序列（LCS）。

但直接求 LCS 是 O(mn)，会超时。利用 `target` 元素互不相同的条件：

1. 将 `target` 中每个元素映射到其下标
2. 将 `arr` 中属于 `target` 的元素替换为其在 `target` 中的下标
3. 问题转化为：求这个下标序列的最长递增子序列（LIS）
4. LIS 等价于 LCS（因为 target 元素唯一且我们已将其映射为有序下标）

最终答案 = `len(target)` - LIS 长度。

## 代码实现

### 方法一：贪心 + 二分查找求 LIS（推荐）

```python
from typing import List
import bisect

class Solution:
    def minOperations(self, target: List[int], arr: List[int]) -> int:
        # 将 target 元素映射到其下标
        pos = {v: i for i, v in enumerate(target)}
        
        # 将 arr 中属于 target 的元素转为对应下标，不属于的忽略
        nums = [pos[x] for x in arr if x in pos]
        
        # 求 nums 的最长递增子序列（LIS）
        # 贪心 + 二分，时间 O(n log n)
        tails = []  # tails[i] 表示长度为 i+1 的递增子序列的最小尾部元素
        
        for x in nums:
            # 找第一个 >= x 的位置
            idx = bisect.bisect_left(tails, x)
            if idx == len(tails):
                tails.append(x)
            else:
                tails[idx] = x
        
        lis_len = len(tails)
        
        # 最少操作次数 = len(target) - LIS长度
        return len(target) - lis_len
```

### 方法二：朴素 LCS（仅适合小数据）

```python
from typing import List

class Solution:
    def minOperations(self, target: List[int], arr: List[int]) -> int:
        # 暴力 LCS，O(mn)，数据大时会超时
        m, n = len(target), len(arr)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if target[i - 1] == arr[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        
        return m - dp[m][n]
```

## 复杂度分析

- **方法一**：时间 O((m+n) log m)，空间 O(m+n)
- **方法二**：时间 O(mn)，空间 O(mn)，大数据超时

## 关键点总结

1. 最少插入次数 = target 长度 - LCS 长度
2. target 元素唯一，可将问题转化为 LIS
3. LIS 用贪心 + 二分查找实现，时间复杂度 O(n log n)

## 易错点

- arr 中不在 target 里的元素需要跳过
- bisect_left 找的是严格递增，不包含等于
