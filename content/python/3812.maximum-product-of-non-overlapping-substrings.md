## 题目描述

给你一个字符串 `s`，你需要选择若干个不重叠的子串，使得所有子串长度之积最大。每个子串必须是 `s` 的子串（连续字符序列），且任意两个子串不重叠。

返回最大乘积（模 `10^9 + 7`）。

**示例 1：**

```
输入：s = "aabc"
输出：6
解释：选择子串 "a"（长度 1）和 "abc"（长度 3），乘积 = 1 * 3 = 3。
或选择 "aa"（长度 2）和 "bc"（长度 2），乘积 = 4。
或选择 "aabc"（长度 4），乘积 = 4。
最大乘积为 4（具体取决于题目约束）。
```

**示例 2：**

```
输入：s = "abcd"
输出：4
解释：选择整个字符串，或分拆为不重叠子串使乘积最大。
```

**提示：**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 解题思路

区间 DP：设 `dp[i][j]` 为在字符串 `s[i..j]` 范围内可获得的最大乘积。
1. 对于区间 `[i, j]`，可以选择不选（乘积为 1），或选某个子区间 `[l, r]` 并在剩余部分递归求解。
2. 枚举分割点：`dp[i][j] = max(dp[i][k] * dp[k+1][j])` for k in [i, j-1]。
3. 对于单个区间 `[i, j]` 直接选择，乘积贡献为 `j - i + 1`。

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        # dp[i][j] = 在 s[i..j] 范围内选不重叠子串的最大长度乘积
        dp = [[1] * n for _ in range(n)]

        # 枚举所有区间，从短到长
        for length in range(1, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                # 选整个 [i, j] 作为一个子串
                dp[i][j] = max(dp[i][j], length)
                # 分割为两部分
                for k in range(i, j):
                    dp[i][j] = max(dp[i][j], dp[i][k] * dp[k + 1][j])

        return dp[0][n - 1] % MOD
```

### 方法二：记忆化递归

```python
from functools import lru_cache

class Solution:
    def maxProduct(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)

        @lru_cache(maxsize=None)
        def dp(i, j):
            if i > j:
                return 1
            # 选整个 [i, j]
            result = j - i + 1
            # 分割
            for k in range(i, j):
                result = max(result, dp(i, k) * dp(k + 1, j))
            return result

        return dp(0, n - 1) % MOD
```

## 复杂度分析

- 时间复杂度：O(n^3)，三重循环（区间长度、起点、分割点）
- 空间复杂度：O(n^2)，DP 表格

## 关键点总结

1. 区间 DP 是处理字符串分割最大化问题的标准范式。
2. 分割点枚举覆盖所有两部分组合。
3. 底层情况：单个字符的贡献为长度 1，整个区间的贡献为其长度。

## 易错点

1. 初始值设为 1（空选择），不能设为 0。
2. 结果需要对 `10^9 + 7` 取模，但在比较大小时不取模（避免模运算影响比较）。
3. `dp[i][j]` 中 i 和 j 的含义要统一为闭区间。
