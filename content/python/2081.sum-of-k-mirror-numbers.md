## 题目描述

一个 `k` 进制下的**镜像数**（k-mirror number）是指：该数字在十进制和 `k` 进制下都是回文数。

给你 `k` 和 `n`，返回最小的 `n` 个 `k` 进制镜像数的**十进制总和**。

**示例：**
```
输入：k = 2, n = 5
输出：sum of [1,3,5,7,9] = 25
（1→1, 3→11, 5→101, 7→111, 9→1001 in binary，均为回文）
```

**提示：**
- `2 <= k <= 9`
- `1 <= n <= 30`

## 解题思路

**枚举十进制回文数，验证 k 进制是否也是回文：**

1. 按位数枚举十进制回文数（奇数位、偶数位分别处理）
2. 对每个十进制回文数，将其转换为 k 进制
3. 验证 k 进制表示是否也是回文
4. 收集 n 个即停止

**生成十进制回文数：** 枚举回文数的"前半部分"，然后镜像得到完整回文数。

## 代码实现

### 方法一：枚举十进制回文 + 验证 k 进制（推荐）

```python
class Solution:
    def kMirror(self, k: int, n: int) -> int:
        def to_base_k(num, k):
            """将 num 转换为 k 进制字符串"""
            if num == 0:
                return "0"
            digits = []
            while num > 0:
                digits.append(str(num % k))
                num //= k
            return ''.join(reversed(digits))

        def is_palindrome(s):
            return s == s[::-1]

        def gen_palindromes(length):
            """生成指定位数的十进制回文数"""
            half = (length + 1) // 2
            start = 10 ** (half - 1)
            end = 10 ** half
            results = []
            for first_half in range(start, end):
                s = str(first_half)
                if length % 2 == 0:
                    # 偶数位：完整镜像
                    palindrome = s + s[::-1]
                else:
                    # 奇数位：去掉最后一个字符再镜像
                    palindrome = s + s[-2::-1]
                results.append(int(palindrome))
            return results

        total = 0
        count = 0
        length = 1  # 枚举十进制位数

        while count < n:
            for num in gen_palindromes(length):
                # 转换为 k 进制并验证
                base_k = to_base_k(num, k)
                if is_palindrome(base_k):
                    total += num
                    count += 1
                    if count == n:
                        break
            length += 1

        return total
```

### 方法二：逐个生成（简洁版）

```python
class Solution:
    def kMirror(self, k: int, n: int) -> int:
        def check(x, k):
            """检查 x 转为 k 进制是否是回文"""
            digits = []
            while x:
                digits.append(x % k)
                x //= k
            return digits == digits[::-1]

        total = 0
        count = 0
        # 枚举十进制长度从 1 开始
        for length in range(1, 20):
            half = (length + 1) // 2
            # 枚举前半部分
            for h in range(10 ** (half - 1), 10 ** half):
                s = str(h)
                if length % 2 == 1:
                    full = s + s[-2::-1]
                else:
                    full = s + s[::-1]
                num = int(full)
                if check(num, k):
                    total += num
                    count += 1
                    if count == n:
                        return total

        return total
```

## 复杂度分析

- 时间复杂度：近似 O(n * 10^(len/2))，与镜像数分布相关
- 空间复杂度：O(log num)，用于进制转换

## 关键点总结

1. 枚举十进制回文数（通过构造前半部分镜像生成，避免逐个检查）
2. 对每个十进制回文验证其 k 进制表示是否也是回文
3. 按位数从小到大枚举，保证顺序

## 易错点

- 奇数位回文：`s + s[-2::-1]`，偶数位回文：`s + s[::-1]`
- 1 位数 (1-9) 是奇数位回文，单独作为 length=1 处理
- `10^0 = 1` 为起始值，正确处理 1 位数的枚举
