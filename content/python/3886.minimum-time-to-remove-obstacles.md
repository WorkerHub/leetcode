## 题目描述

给你一个 `m x n` 的矩阵 `grid`，值为 0（空格）、1（障碍物）或 2（目标）。你从 `(0, 0)` 出发，每步可移动到相邻格子（上下左右），移动代价为 1。若遇到障碍物（1），可以用代价 1 移除它。

返回到达任意目标格子（2）的最少总代价。

**示例 1：**

```
输入：grid = [[0, 1, 1], [0, 0, 2]]
输出：3
解释：路径 (0,0)->(1,0)->(1,1)->(1,2)，代价 = 0+0+1+1... 
```

**提示：**
- `1 <= m, n <= 10^4`
- `m * n <= 10^5`

## 解题思路

**0-1 BFS**（双端队列 BFS）：
- 移动到空格代价为 0（不额外加，移动本身代价 1）... 实际上每次移动代价为 1，移除障碍额外代价 1。
- 等价于：移动到空格代价 1，移动到障碍物代价 2（移动 1 + 移除 1）。
- 用 Dijkstra 或 0-1 BFS 求最短路。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0

        heap = [(0, 0, 0)]  # (代价, 行, 列)

        while heap:
            cost, r, c = heapq.heappop(heap)
            if cost > dist[r][c]:
                continue
            if grid[r][c] == 2:
                return cost

            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 移动到相邻格子的代价
                    move_cost = 1 if grid[nr][nc] != 1 else 2  # 障碍额外代价 1
                    new_cost = cost + move_cost
                    if new_cost < dist[nr][nc]:
                        dist[nr][nc] = new_cost
                        heapq.heappush(heap, (new_cost, nr, nc))

        return -1
```

### 方法二：0-1 BFS（双端队列）

```python
from typing import List
from collections import deque

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0

        dq = deque([(0, 0, 0)])  # (代价, 行, 列)

        while dq:
            cost, r, c = dq.popleft()
            if cost > dist[r][c]:
                continue
            if grid[r][c] == 2:
                return cost

            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    if grid[nr][nc] == 1:
                        new_cost = cost + 2
                        if new_cost < dist[nr][nc]:
                            dist[nr][nc] = new_cost
                            dq.append((new_cost, nr, nc))
                    else:
                        new_cost = cost + 1
                        if new_cost < dist[nr][nc]:
                            dist[nr][nc] = new_cost
                            dq.appendleft((new_cost, nr, nc))  # 代价小的优先

        return -1
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))（Dijkstra）；O(mn)（0-1 BFS）
- 空间复杂度：O(mn)

## 关键点总结

1. 0-1 BFS 适用于边权只有 0 和 1（或其他小整数）的最短路问题。
2. 移动到障碍物代价 2（移动 + 移除），空格代价 1（仅移动）。
3. 0-1 BFS 的代价小的放队头，代价大的放队尾。

## 易错点

1. 障碍物需要先移除才能进入，代价为移动 + 移除 = 2（不是单独 1）。
2. 找到任意一个目标格子时即可返回。
