## 题目描述

给你一个整数数组 `nums` 和若干查询 `queries[i] = [l, r]`，每次查询后，将 `nums[l..r]` 内的重复元素删除（保留每个值的第一次出现）。

返回执行完所有查询后，数组中最少需要的操作（删除）次数总和。

**示例 1：**

```
输入：nums = [1, 2, 2, 3, 1], queries = [[0, 4]]
输出：2
解释：查询 [0,4] 后，删除重复的 2 和 1，删除 2 次。
```

**示例 2：**

```
输入：nums = [1, 2, 3], queries = [[0, 1], [1, 2]]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

每次查询在 `[l, r]` 范围内使元素变得唯一，操作数 = 范围长度 - 范围内不同值的数量。

使用哈希表跟踪每个值最近出现的位置：对于查询 `[l, r]`，统计 `[l, r]` 内重复出现的元素个数。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumOperations(self, nums: List[int], queries: List[List[int]]) -> int:
        total_ops = 0

        for l, r in queries:
            # 统计 nums[l..r] 内重复的元素个数
            seen = set()
            dups = 0
            for i in range(l, r + 1):
                if nums[i] in seen:
                    dups += 1
                else:
                    seen.add(nums[i])
            total_ops += dups

        return total_ops
```

### 方法二：前缀哈希（优化大量查询）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumOperations(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        # 对每个位置，记录该位置的值上一次出现的位置
        last_seen = {}
        prev = [-1] * n  # prev[i] = nums[i] 在 i 之前最近的相同值位置

        for i, v in enumerate(nums):
            prev[i] = last_seen.get(v, -1)
            last_seen[v] = i

        total = 0
        for l, r in queries:
            # 统计 [l, r] 内有多少个 i 满足 prev[i] >= l（重复）
            dups = sum(1 for i in range(l, r + 1) if prev[i] >= l)
            total += dups

        return total
```

## 复杂度分析

- 时间复杂度：O(n * q)（方法一）；可用前缀和优化到 O(n + q log n)
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 每次查询的操作数 = 区间长度 - 区间内不同元素数 = 区间内重复的元素个数。
2. 利用 `prev[i]` 记录前驱位置，判断元素在窗口内是否重复。
3. 可以用线段树或莫队算法优化大量查询的场景。

## 易错点

1. 重复元素数 = 区间总元素数 - 不同元素数，不是相同元素数（注意"重复"的含义）。
2. `prev[i] >= l` 表示 nums[i] 在 [l, i-1] 内已出现过，是重复的。
