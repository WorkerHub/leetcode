## 题目描述

给你一个数组 `nums` 表示 `[1, n]` 的一个排列。我们将 `nums` 插入一个二叉搜索树（BST）中，假设不存在两个相同的数字，每插入一个数字，它就会成为一个新的节点。

请你计算有多少种不同的方法重新排列 `nums`，使得重排后的数组与 `nums` 构造 BST 的结果完全相同。

由于答案可能很大，请对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [2,1,3]
输出：1
解释：[2,1,3] 和 [2,3,1] 都给出相同的BST，所以有1种（不算原数组本身）
```

## 解题思路

### 递归 + 组合数学

对于当前序列，根是第一个元素。其余元素分为左子树元素（< 根）和右子树元素（> 根）。

左右子树的相对顺序分别不变，但可以任意交错。交错方式数 = `C(left_len + right_len, left_len)`。

**递归：** `f(nums) = C(left+right, left) * f(left_nums) * f(right_nums)`

其中 `left_nums` 和 `right_nums` 分别是左右子树对应的元素序列（保持相对顺序）。

答案 = `f(nums) - 1`（减去原始排列本身）。

## 代码实现

### 方法一：递归 + 预计算组合数（推荐）

```python
from typing import List

class Solution:
    def numOfWays(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)

        # 预计算 Pascal 三角形（组合数 C(n, k)）
        C = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            C[i][0] = 1
            for j in range(1, i + 1):
                C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD

        def count(arr: List[int]) -> int:
            if len(arr) <= 1:
                return 1
            root = arr[0]
            left = [x for x in arr if x < root]
            right = [x for x in arr if x > root]
            # C(left+right, left) 种交错方式 * 左右子树各自的方案数
            return C[len(left) + len(right)][len(left)] * count(left) % MOD * count(right) % MOD

        return (count(nums) - 1) % MOD
```

### 方法二：使用 math.comb

```python
from typing import List
from math import comb

class Solution:
    def numOfWays(self, nums: List[int]) -> int:
        MOD = 10**9 + 7

        def count(arr: List[int]) -> int:
            if len(arr) <= 1:
                return 1
            root = arr[0]
            left = [x for x in arr if x < root]
            right = [x for x in arr if x > root]
            return comb(len(arr) - 1, len(left)) * count(left) % MOD * count(right) % MOD

        return (count(nums) - 1) % MOD
```

## 复杂度分析

- **时间复杂度**：O(N^2) 平均，O(N^2) 最坏（列表过滤每层 O(N)，深度 O(N)）
- **空间复杂度**：O(N^2)，递归栈和子数组

## 关键点总结

1. 递归：根固定，左右元素集合固定，只有相对顺序的交错方式可变
2. 交错数 = `C(left+right, left)`（从 left+right 个位置中选 left 个给左子树）
3. 最终答案减 1（排除原始排列本身）

## 易错点

- 最终答案要减 1（不算原排列本身）
- 组合数取模要正确（`math.comb` 不自动取模，需要手动 `% MOD`）
