## 题目描述

给定方法 `rand7()` 可生成 `[1,7]` 范围内的均匀随机整数，试写一个方法 `rand10()` 生成 `[1,10]` 范围内的均匀随机整数。

你只能调用 `rand7()` 且不能调用其他方法。请不要使用系统的 `Math.random()` 方法。

每个测试用例将有一个内部参数 `n`，即你实现的函数 `rand10()` 的调用次数。请注意，这不是传递给 `rand10()` 的参数。

**示例 1：**
```
输入：n = 1
输出：[2]
```

**示例 2：**
```
输入：n = 2
输出：[2,8]
```

**示例 3：**
```
输入：n = 3
输出：[3,8,10]
```

**提示：**
- `1 <= n <= 10^5`

**进阶：**
- `rand7()` 调用次数的期望值是多少？
- 你能否尽量少调用 `rand7()`？

## 解题思路

这是一道经典的**拒绝采样（Rejection Sampling）**问题。

**核心思想：**
1. 用小范围随机数生成大范围随机数
2. 构造一个更大的均匀分布，然后截取需要的部分

**方法：**
1. 调用两次 `rand7()`，生成 `[1, 49]` 的均匀分布
   - `num = (rand7() - 1) * 7 + rand7()`
   - 这样可以得到 1-49 的均匀分布
2. 只取 1-40，映射到 1-10
   - 1-40 可以均分为 4 组，每组 10 个数
   - 如果 num > 40，拒绝并重新采样
3. 映射：`(num - 1) % 10 + 1`

**为什么是 49？**
- 两次 `rand7()` 可以生成 7×7 = 49 种组合
- 每种组合概率相等（1/49）

**为什么拒绝 41-49？**
- 40 可以被 10 整除，保证均匀分布
- 41-49 无法均匀映射到 1-10

## Python 代码实现

### 方法一：基础拒绝采样（推荐）⭐

```python
# The rand7() API is already defined for you.
# def rand7():
#     @return a random integer in the range 1 to 7

class Solution:
    def rand10(self):
        while True:
            # 生成 [1, 49] 的均匀分布
            # (rand7() - 1) 得到 [0, 6]
            # (rand7() - 1) * 7 得到 0, 7, 14, ..., 42
            # 再加上 rand7() 得到 [1, 49]
            num = (rand7() - 1) * 7 + rand7()
            
            # 只接受 [1, 40]
            if num <= 40:
                # 映射到 [1, 10]
                return (num - 1) % 10 + 1
            
            # num > 40，拒绝并重新采样
```

**期望调用次数：** `2 × 49/40 ≈ 2.45` 次

### 方法二：优化拒绝采样（减少浪费）

```python
class Solution:
    def rand10(self):
        while True:
            # 第一轮：生成 [1, 49]
            num = (rand7() - 1) * 7 + rand7()
            
            if num <= 40:
                return (num - 1) % 10 + 1
            
            # 第二轮：利用 [41, 49] 的 9 个数
            # 映射到 [1, 9]，再生成 [1, 63]
            num = (num - 40 - 1) * 7 + rand7()  # [0, 62]
            
            if num <= 60:
                return (num - 1) % 10 + 1
            
            # 第三轮：利用 [61, 63] 的 3 个数
            num = (num - 60 - 1) * 7 + rand7()  # [0, 20]
            
            if num <= 20:
                return (num - 1) % 10 + 1
            
            # 剩余 1 个数，继续循环
```

**期望调用次数：** 约 2.19 次（更优）

### 方法三：详细注释版

```python
class Solution:
    def rand10(self):
        """
        使用 rand7() 生成 rand10()
        
        思路：
        1. 两次 rand7() 生成 [1, 49] 的均匀分布
        2. 取前 40 个数，映射到 [1, 10]
        3. 拒绝 41-49，重新采样
        """
        while True:
            # 第一次调用：得到 [1, 7]，减 1 得到 [0, 6]
            row = rand7() - 1  # [0, 6]
            
            # 第二次调用：得到 [1, 7]
            col = rand7()  # [1, 7]
            
            # 组合成 [1, 49]
            # 可以理解为 7×7 的矩阵，row 是行，col 是列
            num = row * 7 + col  # [1, 49]
            
            # 只接受前 40 个
            if num <= 40:
                # 映射到 [1, 10]
                # 1-10 -> 1, 11-20 -> 2, ..., 31-40 -> 4
                # 然后循环映射
                return (num - 1) % 10 + 1
```

**方法二：**
- 时间复杂度：O(1) 期望，约 2.19 次 `rand7()`
- 空间复杂度：O(1)

**拒绝概率：**

- 优化后更低

## 关键点总结

1. **构造大范围：** 两次 `rand7()` 生成 49 种组合
2. **截取均匀部分：** 只取能均分的 40 个数
3. **拒绝采样：** 拒绝不能均分的部分
4. **映射公式：** `(num - 1) % 10 + 1`
5. **优化空间：** 可以递归利用被拒绝的数

## 易错点

1. **映射公式错误：** 
   ```python
   # 错误：映射范围不对
   return num % 10  # 范围是 [0, 9]
   
   # 正确
   return (num - 1) % 10 + 1  # 范围是 [1, 10]
   ```

2. **范围计算错误：**
   ```python
   # 错误：生成的不是 [1, 49]
   num = rand7() * 7 + rand7()  # 范围是 [8, 56]
   
   # 正确
   num = (rand7() - 1) * 7 + rand7()  # 范围是 [1, 49]
   ```

3. **拒绝条件：**
   ```python
   # 必须保证能均分
   if num <= 40:  # 40 % 10 == 0
       return (num - 1) % 10 + 1
   ```

4. **无限循环风险：** 理论上可能一直被拒绝（概率极低）
   ```python
   # 期望调用次数是有限的
   # 不会真的无限循环
   ```
