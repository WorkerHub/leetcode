## 题目描述

给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2`，返回满足 `nums1[i] + nums1[j] > nums2[i] + nums2[j]` 且 `0 <= i < j < n` 的**数对数目**。

**示例：**
```
输入：nums1 = [2,1,2,1], nums2 = [1,2,1,2]
输出：1
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`

## 解题思路

**变形**：`nums1[i] + nums1[j] > nums2[i] + nums2[j]` 等价于 `(nums1[i] - nums2[i]) + (nums1[j] - nums2[j]) > 0`。

令 `diff[k] = nums1[k] - nums2[k]`，问题转化为统计 `diff[i] + diff[j] > 0` 的数对数（i < j）。

**排序 + 双指针**：对 diff 排序，用双指针统计：
- 对每个 right，找最小的 left 使得 `diff[left] + diff[right] > 0`，则 `[left, right-1]` 中所有满足条件的 left 都合法
- 或等价用二分查找

## 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        diff = sorted(nums1[i] - nums2[i] for i in range(n))

        count = 0
        left, right = 0, n - 1
        while left < right:
            if diff[left] + diff[right] > 0:
                # diff[left..right-1] + diff[right] > 0，共 right - left 对
                count += right - left
                right -= 1
            else:
                left += 1
        return count
```

### 方法二：排序 + 二分查找

```python
import bisect
from typing import List

class Solution:
    def countPairs(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        diff = sorted(nums1[i] - nums2[i] for i in range(n))

        count = 0
        for j in range(1, n):
            # 找最小的 i 使得 diff[i] + diff[j] > 0，即 diff[i] > -diff[j]
            # bisect_right(-diff[j]) 给出第一个 > -diff[j] 的位置
            lo = bisect.bisect_right(diff, -diff[j], 0, j)
            count += j - lo
        return count
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)，diff 数组

## 关键点总结

1. 差值变换：问题转化为 diff 数组中正数对的计数
2. 排序后双指针 O(n) 统计
3. 二分方法：对每个 j，在其左侧二分查找满足条件的 i 的范围

## 易错点

- 双指针中，每次 right 减小时累加 `right - left`（不是 right - left + 1）
