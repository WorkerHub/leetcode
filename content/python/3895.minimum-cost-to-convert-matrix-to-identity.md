## 题目描述

给你一个 `n x n` 的矩阵，每次操作可以交换矩阵中相邻的两个元素（水平或垂直相邻）。

返回将矩阵转换为单位矩阵（对角线为 1，其余为 0）所需的最少操作次数。

**提示：**
- `2 <= n <= 6`

## 解题思路

由于 n 较小（n <= 6），矩阵规模为 36 个元素，可以使用状态压缩或 BFS/IDA* 求解。

核心：将矩阵元素移动到目标位置，总移动次数 = 所有元素到目标位置的曼哈顿距离之和（但有互相干扰，需要实际模拟）。

## Python 代码实现

### 方法一：BFS（状态搜索，小规模）

```python
from typing import List
from collections import deque

class Solution:
    def minCost(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        # 目标：单位矩阵
        target = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
        target_tuple = tuple(v for row in target for v in row)

        # 起始状态
        start = tuple(v for row in matrix for v in row)
        if start == target_tuple:
            return 0

        # BFS
        visited = {start}
        queue = deque([(start, 0)])

        while queue:
            state, ops = queue.popleft()
            grid = [list(state[i*n:(i+1)*n]) for i in range(n)]

            for r in range(n):
                for c in range(n):
                    for dr, dc in [(0,1),(1,0)]:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < n and 0 <= nc < n:
                            # 交换 (r,c) 和 (nr,nc)
                            new_grid = [row[:] for row in grid]
                            new_grid[r][c], new_grid[nr][nc] = new_grid[nr][nc], new_grid[r][c]
                            new_state = tuple(v for row in new_grid for v in row)
                            if new_state == target_tuple:
                                return ops + 1
                            if new_state not in visited:
                                visited.add(new_state)
                                queue.append((new_state, ops + 1))

        return -1
```

### 方法二：曼哈顿距离估算（启发式下界）

```python
from typing import List

class Solution:
    def minCost(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        # 计算每个元素到目标位置的曼哈顿距离之和
        # 目标：matrix[i][j] 应为 1 if i==j else 0
        # 将 1 移到对角线位置
        ones_pos = [(i, j) for i in range(n) for j in range(n) if matrix[i][j] == 1]
        target_pos = [(i, i) for i in range(n)]

        # 简单匹配：用匈牙利算法最优匹配
        from itertools import permutations

        min_cost = float('inf')
        for perm in permutations(range(n)):
            cost = sum(abs(ones_pos[i][0] - target_pos[perm[i]][0]) +
                      abs(ones_pos[i][1] - target_pos[perm[i]][1])
                      for i in range(len(ones_pos)))
            min_cost = min(min_cost, cost)

        return min_cost
```

## 复杂度分析

- 时间复杂度：BFS 最坏 O(n^2 * (n^2)!)，实际因剪枝较快
- 空间复杂度：O((n^2)!)，状态空间

## 关键点总结

1. n <= 6 是暗示可以使用状态搜索（BFS/DFS + 记忆化）。
2. 曼哈顿距离是操作次数的下界。
3. 实际操作中元素互相影响，曼哈顿距离不等于实际操作数。

## 易错点

1. 交换只能相邻元素，不能随意置换。
2. BFS 状态空间可能很大，需要剪枝或使用 A* 算法。
