## 题目描述

实现一个字典树（前缀树），包含以下方法：
- `Trie()` 初始化字典树
- `insert(word)` 向字典树中插入一个字符串 `word`
- `countWordsEqualTo(word)` 返回字典树中等于 `word` 的字符串数
- `countWordsStartingWith(prefix)` 返回以 `prefix` 为前缀的字符串数
- `erase(word)` 从字典树中删除一个字符串 `word`

**示例：**
```
输入：
["Trie", "insert", "insert", "countWordsEqualTo", "countWordsStartingWith", "erase", "countWordsEqualTo", "countWordsStartingWith", "erase", "countWordsStartingWith"]
[[], ["apple"], ["apple"], ["apple"], ["apple"], ["apple"], ["apple"], ["apple"], ["apple"], ["apple"]]
输出：[null, null, null, 2, 2, null, 1, 1, null, 0]
```

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 只包含小写英文字母
- `insert`、`countWordsEqualTo`、`countWordsStartingWith`、`erase` 调用次数之和最多 `3 * 10^4`
- 对每个不存在的 `word` 不会调用 `erase`

## 解题思路

在标准字典树的基础上，每个节点需要维护两个计数：
- `end_count`：以该节点结尾的完整单词数量
- `prefix_count`：经过该节点的单词数量（即以该节点对应前缀开头的单词数）

插入时沿路径递增 `prefix_count`，在末尾节点递增 `end_count`；删除时逆向操作。

## 代码实现

### 方法一：字典树节点类（推荐）

```python
class TrieNode:
    def __init__(self):
        self.children = {}      # 子节点字典
        self.end_count = 0      # 以此节点为结尾的完整单词数
        self.prefix_count = 0   # 经过此节点的单词数


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            node.prefix_count += 1  # 经过该节点的单词数加一
        node.end_count += 1  # 完整单词数加一

    def countWordsEqualTo(self, word: str) -> int:
        node = self.root
        for ch in word:
            if ch not in node.children:
                return 0
            node = node.children[ch]
        return node.end_count  # 返回完整单词数

    def countWordsStartingWith(self, prefix: str) -> int:
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return 0
            node = node.children[ch]
        return node.prefix_count  # 返回以该前缀开头的单词数

    def erase(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.children[ch]
            node.prefix_count -= 1  # 沿路径递减
        node.end_count -= 1  # 完整单词数递减
```

### 方法二：数组存储子节点（效率更高）

```python
class Trie:
    def __init__(self):
        # 用数组存储：children[i] 是字符 i 的子节点索引
        self.children = [[-1] * 26]
        self.end_count = [0]
        self.prefix_count = [0]
        self.size = 1

    def _new_node(self) -> int:
        self.children.append([-1] * 26)
        self.end_count.append(0)
        self.prefix_count.append(0)
        self.size += 1
        return self.size - 1

    def insert(self, word: str) -> None:
        node = 0
        for ch in word:
            idx = ord(ch) - ord('a')
            if self.children[node][idx] == -1:
                self.children[node][idx] = self._new_node()
            node = self.children[node][idx]
            self.prefix_count[node] += 1
        self.end_count[node] += 1

    def countWordsEqualTo(self, word: str) -> int:
        node = 0
        for ch in word:
            idx = ord(ch) - ord('a')
            if self.children[node][idx] == -1:
                return 0
            node = self.children[node][idx]
        return self.end_count[node]

    def countWordsStartingWith(self, prefix: str) -> int:
        node = 0
        for ch in prefix:
            idx = ord(ch) - ord('a')
            if self.children[node][idx] == -1:
                return 0
            node = self.children[node][idx]
        return self.prefix_count[node]

    def erase(self, word: str) -> None:
        node = 0
        for ch in word:
            idx = ord(ch) - ord('a')
            node = self.children[node][idx]
            self.prefix_count[node] -= 1
        self.end_count[node] -= 1
```

## 复杂度分析

- **时间复杂度**：所有操作均为 O(m)，m 为单词或前缀的长度
- **空间复杂度**：O(n * m)，n 为插入的单词数，m 为平均长度

## 关键点总结

1. 每个节点维护两个独立计数：`end_count`（完整单词）和 `prefix_count`（前缀经过数）
2. 删除操作只需递减计数，无需实际移除节点（因为题目保证删除的词存在）
3. 查询前缀计数时，走到前缀最后一个字符对应节点，返回其 `prefix_count`
4. 查询等于时，走到最后一个字符，返回 `end_count`

## 易错点

- `prefix_count` 和 `end_count` 的更新时机不同：`prefix_count` 在走到子节点后更新，`end_count` 在遍历完整个单词后更新
- 删除操作的计数递减顺序必须与插入时一致
