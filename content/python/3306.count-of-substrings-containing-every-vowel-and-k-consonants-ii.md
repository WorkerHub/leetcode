## 题目描述

给你一个字符串 `word` 和一个非负整数 `k`。

返回 `word` 的子字符串中，包含全部 5 个元音字母（`a`、`e`、`i`、`o`、`u`）**且恰好有 `k` 个辅音字母**的子字符串数目。

与第 I 版（3305）相比，本题的数据范围更大：`word.length` 可达 `10^5`，需要 O(n) 解法。

**提示：**
- `5 <= word.length <= 10^5`
- `word` 只含小写英文字母
- `0 <= k <= word.length - 5`

## 解题思路

与 3305 完全相同的思路，但由于数据范围扩大到 10^5，暴力 O(n^2) 会超时，必须使用 O(n) 的滑动窗口方法。

**核心技巧：**
`恰好k个辅音` = `至少k个辅音（含所有元音）` - `至少(k+1)个辅音（含所有元音）`

**滑动窗口 `at_least(min_k)` 函数：**
- 维护双指针 `[l, r]`，统计窗口内各元音数量和辅音总数。
- 当窗口满足"5 种元音都有 + 辅音数 >= min_k"时，以当前左端点 `l` 为起点、当前右端点 `r` 为终点的窗口合法，右端点还可以继续往右，贡献 `n - r` 个子串，然后收缩左端点。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(word)
        
        def at_least(min_k: int) -> int:
            """统计包含所有元音且辅音数 >= min_k 的子串数"""
            count = 0
            vowel_cnt = {}  # 各元音出现次数
            consonant_cnt = 0  # 辅音数量
            l = 0
            
            for r in range(n):
                c = word[r]
                if c in vowels:
                    vowel_cnt[c] = vowel_cnt.get(c, 0) + 1
                else:
                    consonant_cnt += 1
                
                # 当窗口满足条件时，尽量缩小左边界
                while len(vowel_cnt) == 5 and consonant_cnt >= min_k:
                    # 左端点为 l，右端点 r 往右还有 n-r-1 种扩展，共 n-r 个
                    count += n - r
                    lc = word[l]
                    if lc in vowels:
                        vowel_cnt[lc] -= 1
                        if vowel_cnt[lc] == 0:
                            del vowel_cnt[lc]
                    else:
                        consonant_cnt -= 1
                    l += 1
            
            return count
        
        return at_least(k) - at_least(k + 1)
```

### 方法二：单次滑动窗口（避免调用两次）

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(word)
        
        def count_at_least(min_k: int) -> int:
            vowel_cnt = {}
            consonant_cnt = 0
            l = 0
            res = 0
            for r, c in enumerate(word):
                if c in vowels:
                    vowel_cnt[c] = vowel_cnt.get(c, 0) + 1
                else:
                    consonant_cnt += 1
                while len(vowel_cnt) == 5 and consonant_cnt >= min_k:
                    res += n - r
                    lc = word[l]
                    if lc in vowels:
                        vowel_cnt[lc] -= 1
                        if vowel_cnt[lc] == 0:
                            del vowel_cnt[lc]
                    else:
                        consonant_cnt -= 1
                    l += 1
            return res
        
        return count_at_least(k) - count_at_least(k + 1)
```

## 复杂度分析

- 时间复杂度：O(n)，两次滑动窗口各 O(n)，总体 O(n)
- 空间复杂度：O(1)，元音哈希表最多 5 个键

## 关键点总结

1. `恰好k` = `至少k` - `至少(k+1)` 是处理"恰好"类滑动窗口问题的通用技巧。
2. 当窗口满足条件时，固定左端点，右端点从当前 `r` 到 `n-1` 的所有扩展都合法。
3. 本题与 3305 代码完全相同，只是数据范围不同，O(n) 解法在两题中都适用。

## 易错点

1. 元音字典中计数清零时需要删除键（`del vowel_cnt[lc]`），否则 `len(vowel_cnt) == 5` 判断会出错。
2. 每次满足条件时累加的是 `n - r`，不是 `n - r - l`。
3. `at_least(k+1)` 时，`k+1` 可能超出辅音数范围，但函数会正确返回 0，无需特判。
