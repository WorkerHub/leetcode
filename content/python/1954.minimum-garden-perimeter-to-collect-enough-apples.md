## 题目描述

给你一个以坐标原点为中心的无限大二维网格，每个格点 `(i, j)` 有 `|i| + |j|` 个苹果（曼哈顿距离）。

你需要在网格中找一个边长为偶数（2n）的正方形区域（以原点为中心，从 `-n` 到 `n`），使区域内苹果总数至少为 `neededApples`。

返回该正方形的**最小周长**。

**示例 1：**
```
输入：neededApples = 1
输出：8
解释：n=1 的正方形包含 12 个苹果，周长为 8
```

**示例 2：**
```
输入：neededApples = 13
输出：16
```

**提示：**
- `1 <= neededApples <= 10^15`

---

## 解题思路

### 核心思想：数学公式 + 二分查找

**边长为 2n 的正方形（从 -n 到 n）内的苹果总数：**

通过数学推导，正方形内所有苹果数为：`2 * n * (n + 1) * (2n + 1)`

**推导：**
- 从 n-1 到 n 的正方形增加的苹果数 = 苹果在 "边框" 上的数量
- 经推导，半径为 n 的正方形总苹果数 = `2 * n * (n+1) * (2n+1)`

**二分 n 的值：** 对 n 从 1 到某个上界二分，找到最小的 n 使得苹果数 ≥ `neededApples`。

周长 = `8 * n`。

---

## 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def minimumPerimeter(self, neededApples: int) -> int:

        def count_apples(n: int) -> int:
            """计算边长为 2n 的正方形内的苹果总数"""
            return 2 * n * (n + 1) * (2 * n + 1)

        # 二分 n 的值
        lo, hi = 1, 100000

        while lo < hi:
            mid = (lo + hi) // 2
            if count_apples(mid) >= neededApples:
                hi = mid
            else:
                lo = mid + 1

        return 8 * lo
```

### 方法二：直接枚举（验证用）

```python
class Solution:
    def minimumPerimeter(self, neededApples: int) -> int:
        n = 1
        while 2 * n * (n + 1) * (2 * n + 1) < neededApples:
            n += 1
        return 8 * n
```

## 关键点总结

1. 公式推导：半径 n 内苹果数 = `2n(n+1)(2n+1)`
2. 二分最小 n，满足苹果数 ≥ `neededApples`
3. 最小周长 = `8 * n`

---

## 公式推导

对于第 k 层（从原点到第 k 层边框）：
- 一个边框包含 `4 * k + 4 * (k-1) + ...` 等等，整体求和得到 `2n(n+1)(2n+1)`

---

## 易错点

- 二分上界需要足够大（`neededApples <= 10^15`，n 最大约 5000）
- 注意公式是 `2 * n * (n + 1) * (2n + 1)`，不要写错
