## 题目描述

给你一个整数数组 `hours`，表示若干员工的工作时长。

若两个员工工作时长之和恰好是 24 小时的倍数，则称这对员工为 **完整天** 员工对。

返回满足条件的员工对的数目。

**示例 1：**
```
输入：hours = [12,12,30,24,24]
输出：2
解释：(0,1): 12+12=24, (3,4): 24+24=48，均为 24 的倍数
```

**示例 2：**
```
输入：hours = [72,48,24,3]
输出：3
```

**提示：**
- `1 <= hours.length <= 100`
- `1 <= hours[i] <= 10^9`

## 解题思路

两个工作时长之和为 24 的倍数，等价于 `(hours[i] % 24 + hours[j] % 24) % 24 == 0`。

先对所有时长取模 24，然后用哈希表统计：对于余数 r，配对余数为 `(24 - r) % 24`。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        cnt = Counter(h % 24 for h in hours)
        ans = 0
        for r in range(24):
            # 与余数 r 配对的余数
            pair = (24 - r) % 24
            if r < pair:
                ans += cnt[r] * cnt[pair]
            elif r == pair:
                # 余数相同，选 C(cnt[r], 2) 对
                ans += cnt[r] * (cnt[r] - 1) // 2
        return ans
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        n = len(hours)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                if (hours[i] + hours[j]) % 24 == 0:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n + 24) = O(n)，哈希表统计
- 空间复杂度：O(24) = O(1)

## 关键点总结

1. `(a + b) % 24 == 0` 等价于 `(a%24 + b%24) % 24 == 0`
2. 余数配对：r 和 (24-r)%24 配对（两种：r != 24-r 和 r == 24-r 即 r=0 或 r=12）
3. 同余数配对时用组合数 C(n,2)

## 易错点

1. 余数为 0 时，配对余数也是 0，用 C(cnt[0], 2)
2. 余数为 12 时同理
3. 避免重复计数：r < pair 时才统计
