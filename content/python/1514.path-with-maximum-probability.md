## 题目描述

给你一个由 `n` 个节点（下标从 0 开始）组成的无向加权图，用一个正整数 `n` 和边数组 `edges` 来表示，其中 `edges[i] = [a, b]` 表示节点 `a` 和节点 `b` 之间有一条无向边，对应的概率为 `succProb[i]`。

给你两个节点 `start` 和 `end`，请你找出从 `start` 到 `end` 路径中，成功概率最大的路径，并返回其成功概率。如果不存在路径，返回 0。答案若与标准答案误差不超过 `1e-5`，则被视为正确答案。

**示例 1：**
```
输入：n = 3, edges = [[0,1],[1,2],[0,2]], succProb = [0.5,0.5,0.2], start = 0, end = 2
输出：0.25000
```

**提示：**
- `2 <= n <= 10^4`
- `0 <= start, end < n`
- `start != end`

## 解题思路

### Dijkstra 变体（最大概率路径）

类比 Dijkstra 最短路算法，但目标是最大化概率（乘积）而非最小化距离。

**关键变化：**
- 使用最大堆（`-prob` 实现）
- 初始化 `dist[start] = 1.0`，其他为 0
- 松弛操作改为：若 `dist[u] * w > dist[v]`，则更新

## 代码实现

### 方法一：Dijkstra 最大堆（推荐）

```python
import heapq
from collections import defaultdict
from typing import List

class Solution:
    def maxProbability(self, n: int, edges: List[List[int]], succProb: List[float],
                       start: int, end: int) -> float:
        # 建图（邻接表）
        graph = defaultdict(list)
        for (u, v), prob in zip(edges, succProb):
            graph[u].append((v, prob))
            graph[v].append((u, prob))

        # dist[i] 表示 start 到 i 的最大概率
        dist = [0.0] * n
        dist[start] = 1.0

        # 最大堆：(-概率, 节点)，用负数模拟最大堆
        heap = [(-1.0, start)]

        while heap:
            neg_prob, u = heapq.heappop(heap)
            prob = -neg_prob

            # 如果当前概率已不是最优，跳过
            if prob < dist[u]:
                continue

            for v, w in graph[u]:
                new_prob = prob * w
                if new_prob > dist[v]:
                    dist[v] = new_prob
                    heapq.heappush(heap, (-new_prob, v))

        return dist[end]
```

### 方法二：Bellman-Ford（适合边数较少）

```python
from typing import List

class Solution:
    def maxProbability(self, n: int, edges: List[List[int]], succProb: List[float],
                       start: int, end: int) -> float:
        # dist[i] 表示 start 到 i 的最大概率
        dist = [0.0] * n
        dist[start] = 1.0

        # Bellman-Ford：最多 n-1 轮松弛
        for _ in range(n - 1):
            updated = False
            for (u, v), prob in zip(edges, succProb):
                # 从 u 到 v 方向松弛
                if dist[u] * prob > dist[v]:
                    dist[v] = dist[u] * prob
                    updated = True
                # 从 v 到 u 方向松弛（无向图）
                if dist[v] * prob > dist[u]:
                    dist[u] = dist[v] * prob
                    updated = True
            if not updated:
                break  # 提前终止

        return dist[end]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Dijkstra | O((V + E) log V) | O(V + E) |
| Bellman-Ford | O(V * E) | O(V) |

## 关键点总结

1. 最大概率路径问题是 Dijkstra 的变体，用乘法代替加法
2. 最大堆用 `-prob` 实现（Python heapq 只有最小堆）
3. Bellman-Ford 更简单，但在大图上较慢
4. 已访问节点不需要再处理（使用 `if prob < dist[u]: continue`）

## 易错点

- 忘记图是无向的，需要双向建边
- Dijkstra 中松弛条件是 `>`（更大的概率），不是 `<`
- 初始化时 `dist[start] = 1.0`（概率1，不是0）
