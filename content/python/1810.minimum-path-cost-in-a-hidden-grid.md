## 题目描述

这是一道 **交互题**。

有一个隐藏网格，你在格子 `(0, 0)` 出发，目标是到达某一个目标格子（target）。网格中有些格子无法通行，每次移动到相邻格子有不同的代价。

你可以通过调用 `GridMaster` 接口：
- `canMove(direction)` 检查是否能向指定方向移动（不移动）
- `move(direction)` 向指定方向移动并返回该格子的代价（-1 表示目标格子）
- `isTarget()` 检查当前位置是否为目标格子

返回从起点到目标格子的最小代价，若无法到达则返回 -1。

**提示：**
- 方向为 `'U'`（上）、`'D'`（下）、`'L'`（左）、`'R'`（右）

## 解题思路

**两阶段策略**：
1. **DFS 探索**：从起点 (0,0) 出发，通过 DFS 遍历所有可达格子，记录格子坐标和边的代价，构建图
2. **Dijkstra 最短路**：在构建的图上从起点到目标格子求最短路

DFS 时需要记录已访问节点，避免重复访问；每次移动后要回溯（沿反方向移回）。

## 代码实现

### 方法一：DFS 建图 + Dijkstra（推荐）

```python
import heapq
from collections import defaultdict
# 假设 GridMaster 接口已定义

class Solution:
    def findShortestPath(self, master: 'GridMaster') -> int:
        # 方向向量：上下左右 及其反方向
        dirs = {'U': (-1, 0), 'D': (1, 0), 'L': (0, -1), 'R': (0, 1)}
        opposite = {'U': 'D', 'D': 'U', 'L': 'R', 'R': 'L'}

        # 图：graph[(r,c)] = [(cost, (nr, nc)), ...]
        graph = defaultdict(list)
        target = None
        visited = set()
        visited.add((0, 0))

        def dfs(r: int, c: int) -> None:
            nonlocal target
            if master.isTarget():
                target = (r, c)

            for d, (dr, dc) in dirs.items():
                nr, nc = r + dr, c + dc
                if (nr, nc) not in visited and master.canMove(d):
                    visited.add((nr, nc))
                    cost = master.move(d)  # 移动并获取代价
                    graph[(r, c)].append((cost, (nr, nc)))
                    graph[(nr, nc)].append((cost, (r, c)))  # 无向图
                    dfs(nr, nc)
                    master.move(opposite[d])  # 回溯

        dfs(0, 0)

        if target is None:
            return -1

        # Dijkstra 求最短路
        dist = {(0, 0): 0}
        heap = [(0, (0, 0))]
        while heap:
            d, node = heapq.heappop(heap)
            if node == target:
                return d
            if d > dist.get(node, float('inf')):
                continue
            for cost, neighbor in graph[node]:
                new_d = d + cost
                if new_d < dist.get(neighbor, float('inf')):
                    dist[neighbor] = new_d
                    heapq.heappush(heap, (new_d, neighbor))
        return -1
```

### 方法二：DFS 建图 + BFS（代价均等时适用）

```python
from collections import deque, defaultdict

class Solution:
    def findShortestPath(self, master: 'GridMaster') -> int:
        dirs = {'U': (-1, 0), 'D': (1, 0), 'L': (0, -1), 'R': (0, 1)}
        opposite = {'U': 'D', 'D': 'U', 'L': 'R', 'R': 'L'}
        costs = {}   # 节点代价
        reachable = set()
        target = None
        visited = set()
        visited.add((0, 0))

        def dfs(r, c):
            nonlocal target
            if master.isTarget():
                target = (r, c)
            for d, (dr, dc) in dirs.items():
                nr, nc = r + dr, c + dc
                if (nr, nc) not in visited and master.canMove(d):
                    visited.add((nr, nc))
                    c_val = master.move(d)
                    costs[(nr, nc)] = c_val
                    reachable.add((nr, nc))
                    dfs(nr, nc)
                    master.move(opposite[d])

        costs[(0, 0)] = 0
        reachable.add((0, 0))
        dfs(0, 0)

        if target is None:
            return -1

        # 用 Dijkstra（因为每步代价不同）
        import heapq
        dist = {(0, 0): 0}
        heap = [(0, 0, 0)]  # (dist, r, c)
        while heap:
            d, r, c = heapq.heappop(heap)
            if (r, c) == target:
                return d
            for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                nr, nc = r+dr, c+dc
                if (nr, nc) in reachable:
                    nd = d + costs[(nr, nc)]
                    if nd < dist.get((nr, nc), float('inf')):
                        dist[(nr, nc)] = nd
                        heapq.heappush(heap, (nd, nr, nc))
        return -1
```

## 复杂度分析

- **时间复杂度**：O(V + E log V)，V 为可达格子数，E 为边数，Dijkstra 的时间复杂度
- **空间复杂度**：O(V + E)，图存储

## 关键点总结

1. 交互题需要先 DFS 探索建图，再求最短路，两阶段分离
2. DFS 回溯时必须沿反方向移回，保持位置一致
3. 有权图最短路用 Dijkstra，无权图用 BFS

## 易错点

- 忘记 DFS 回溯（每次 move 后必须 move 反方向）
- 起点 (0,0) 的代价为 0，不需要加入 costs
