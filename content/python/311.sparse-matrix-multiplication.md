## 题目描述

给定两个**稀疏矩阵** `mat1`（大小为 `m x k`）和 `mat2`（大小为 `k x n`），返回 `mat1 x mat2` 的结果。你可以假设乘法总是可行的。

**稀疏矩阵**是指矩阵中大多数元素都是 0 的矩阵。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/12/mult-grid.jpg)

```
输入：mat1 = [[1,0,0],[-1,0,3]], mat2 = [[7,0,0],[0,0,0],[0,0,1]]
输出：[[7,0,0],[-7,0,3]]
```

**示例 2：**
```
输入：mat1 = [[0]], mat2 = [[0]]
输出：[[0]]
```

**提示：**
- `m == mat1.length`
- `k == mat1[i].length == mat2.length`
- `n == mat2[i].length`
- `1 <= m, n, k <= 100`
- `-100 <= mat1[i][j], mat2[i][j] <= 100`

## 解题思路

### 普通矩阵乘法

对于矩阵乘法 `C = A × B`：
```
C[i][j] = Σ(A[i][k] * B[k][j])  for k in range(K)
```

时间复杂度：O(m × n × k)

### 稀疏矩阵优化⭐

**关键观察**：如果 `mat1[i][k] = 0` 或 `mat2[k][j] = 0`，则该项对结果无贡献。

**优化策略**：
1. **跳过零元素**：只处理非零元素
2. **压缩存储**：用字典或列表存储非零元素的位置和值
3. **调整循环顺序**：先检查 `mat1[i][k]` 是否为 0

### 三种优化方法

1. **调整循环顺序**：将 k 循环提前，可以提前跳过零元素
2. **稀疏表示**：只存储非零元素
3. **哈希表**：用字典存储每行的非零元素

## Python 代码实现

### 方法一：调整循环顺序（推荐）⭐

```python
from typing import List

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        
        # 初始化结果矩阵
        result = [[0] * n for _ in range(m)]
        
        # 关键：调整循环顺序，将 k 循环放在中间
        for i in range(m):
            for k_ in range(k):
                # 如果 mat1[i][k] == 0，跳过整个内层循环
                if mat1[i][k_] == 0:
                    continue
                
                for j in range(n):
                    # 只有当 mat1[i][k] != 0 时才计算
                    result[i][j] += mat1[i][k_] * mat2[k_][j]
        
        return result
```

### 方法二：稀疏矩阵表示（字典）

```python
from typing import List
from collections import defaultdict

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        
        # 将 mat1 的非零元素存储为字典 {行号: {列号: 值}}
        sparse_mat1 = defaultdict(dict)
        for i in range(m):
            for j in range(k):
                if mat1[i][j] != 0:
                    sparse_mat1[i][j] = mat1[i][j]
        
        # 将 mat2 的非零元素存储为字典 {行号: {列号: 值}}
        sparse_mat2 = defaultdict(dict)
        for i in range(k):
            for j in range(n):
                if mat2[i][j] != 0:
                    sparse_mat2[i][j] = mat2[i][j]
        
        # 初始化结果矩阵
        result = [[0] * n for _ in range(m)]
        
        # 只遍历非零元素
        for i in sparse_mat1:
            for k_ in sparse_mat1[i]:
                if k_ in sparse_mat2:
                    for j in sparse_mat2[k_]:
                        result[i][j] += sparse_mat1[i][k_] * sparse_mat2[k_][j]
        
        return result
```

### 方法三：列表存储非零元素

```python
from typing import List

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        
        # 存储 mat1 每行的非零元素 [(列号, 值)]
        sparse_mat1 = []
        for i in range(m):
            row = []
            for j in range(k):
                if mat1[i][j] != 0:
                    row.append((j, mat1[i][j]))
            sparse_mat1.append(row)
        
        # 存储 mat2 每行的非零元素 [(列号, 值)]
        sparse_mat2 = []
        for i in range(k):
            row = []
            for j in range(n):
                if mat2[i][j] != 0:
                    row.append((j, mat2[i][j]))
            sparse_mat2.append(row)
        
        # 初始化结果矩阵
        result = [[0] * n for _ in range(m)]
        
        # 计算乘积
        for i in range(m):
            for k_, val1 in sparse_mat1[i]:
                for j, val2 in sparse_mat2[k_]:
                    result[i][j] += val1 * val2
        
        return result
```

### 方法五：带详细注释的版本

```python
from typing import List

class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        """
        稀疏矩阵乘法优化
        
        核心思想：
        1. 稀疏矩阵中大部分元素是 0
        2. 如果 mat1[i][k] = 0，则整行的计算都可以跳过
        3. 调整循环顺序，提前判断 mat1[i][k] 是否为 0
        
        标准循环顺序：i -> j -> k
        优化后顺序：i -> k -> j
        
        好处：可以提前跳过 mat1[i][k] = 0 的情况
        """
        m = len(mat1)       # mat1 的行数
        k = len(mat1[0])    # mat1 的列数 = mat2 的行数
        n = len(mat2[0])    # mat2 的列数
        
        # 初始化结果矩阵
        result = [[0] * n for _ in range(m)]
        
        # 外层循环：遍历 mat1 的每一行
        for i in range(m):
            # 中层循环：遍历 mat1 的每一列（也是 mat2 的每一行）
            for k_idx in range(k):
                # 关键优化：如果 mat1[i][k] = 0，跳过
                if mat1[i][k_idx] == 0:
                    continue
                
                # 内层循环：遍历 mat2 的每一列
                # 此时 mat1[i][k] != 0，才进行计算
                for j in range(n):
                    # result[i][j] += mat1[i][k] * mat2[k][j]
                    result[i][j] += mat1[i][k_idx] * mat2[k_idx][j]
        
        return result
```

## 复杂度分析

设稀疏度为 s（非零元素的比例）：

**方法一（调整循环顺序）：**
- 时间复杂度：O(m × k × n)，但实际运行时间大约是 O(m × s×k × n)
- 空间复杂度：O(m × n)，结果矩阵

**方法二、三（稀疏表示）：**
- 时间复杂度：O(m × s1 × s2 × n)，其中 s1、s2 是两个矩阵的稀疏度
- 空间复杂度：O(m×k×s1 + k×n×s2)，存储非零元素

## 关键点总结

1. **循环顺序优化**：`i -> k -> j` 而不是 `i -> j -> k`
2. **提前跳过**：检查 `mat1[i][k]` 是否为 0
3. **稀疏表示**：只存储非零元素，节省空间和时间
4. **字典 vs 列表**：
   - 字典：查找快 O(1)
   - 列表：遍历快，空间省
5. **矩阵乘法公式**：`C[i][j] = Σ(A[i][k] × B[k][j])`

## 易错点

1. **维度理解**：`mat1` 是 m×k，`mat2` 是 k×n，结果是 m×n
2. **索引混淆**：k 既是 mat1 的列索引，也是 mat2 的行索引
3. **循环顺序**：不同的顺序影响优化效果
4. **初始化**：结果矩阵要初始化为 0
5. **边界情况**：单个元素的矩阵
