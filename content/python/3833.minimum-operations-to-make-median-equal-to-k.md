## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，你可以在每次操作中将 `nums` 中任意一个元素加 1 或减 1。

返回使数组中位数等于 `k` 所需的最少操作次数。

**示例 1：**

```
输入：nums = [2, 5, 6, 8, 5], k = 4
输出：2
解释：排序后 [2, 5, 5, 6, 8]，中位数为 5。将两个 5 减到 4，操作 2 次，中位数变为 4。
```

**示例 2：**

```
输入：nums = [1, 2, 3, 4, 5], k = 4
输出：2
解释：排序后中位数为 3，将 3 加到 4 需要 1 次，中位数变为 4。
```

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `1 <= nums[i], k <= 10^9`

## 解题思路

排序后，中位数是第 `n//2` 个元素（0-indexed）。

贪心策略：
1. 排序 nums，找中位数位置 `mid = n // 2`。
2. 若 `nums[mid] == k`，返回 0。
3. 若 `nums[mid] > k`：需要将中位数降到 k，操作所有大于 k 的中位数元素（降到 k）。
4. 若 `nums[mid] < k`：需要将中位数升到 k，操作所有小于 k 的中位数元素（升到 k）。

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minOperationsToMakeMedianK(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        mid = n // 2
        ops = 0

        if nums[mid] == k:
            return 0
        elif nums[mid] > k:
            # 中位数大于 k，需要将中位数及其左侧大于 k 的元素降到 k
            for i in range(mid, -1, -1):
                if nums[i] > k:
                    ops += nums[i] - k
                else:
                    break
        else:
            # 中位数小于 k，需要将中位数及其右侧小于 k 的元素升到 k
            for i in range(mid, n):
                if nums[i] < k:
                    ops += k - nums[i]
                else:
                    break

        return ops
```

### 方法二：只操作中位数位置

```python
from typing import List

class Solution:
    def minOperationsToMakeMedianK(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        mid = n // 2
        ops = 0

        if nums[mid] > k:
            # 将中位数从右向左压低到 k（保持中位数变为 k）
            for i in range(mid, -1, -1):
                if nums[i] <= k:
                    break
                ops += nums[i] - k
                nums[i] = k  # 模拟操作
        elif nums[mid] < k:
            # 将中位数从左向右抬高到 k
            for i in range(mid, n):
                if nums[i] >= k:
                    break
                ops += k - nums[i]
                nums[i] = k

        return ops
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)，原地排序

## 关键点总结

1. 排序后中位数位置固定，只需操作中位数附近的元素。
2. 将中位数降低时，从中位数向左操作（确保中位数等于 k）。
3. 将中位数升高时，从中位数向右操作。

## 易错点

1. 中位数位置是 `n // 2`（0-indexed），奇数长度的中间位置。
2. 操作时注意不要越界，循环有退出条件。
3. 排序后才能确定中位数位置。
