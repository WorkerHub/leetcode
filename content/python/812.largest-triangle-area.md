## 题目描述

给你一个由 X-Y 平面上的点组成的数组 `points`，其中 `points[i] = [xi, yi]`。从其中取任意三个不同的点组成三角形，返回能组成的最大三角形的面积。与真实值误差在 `10^-5` 内的答案将会视为正确答案。

**示例 1:**
```
输入: points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
输出: 2.00000
解释: 输入中的 5 个点如下图所示，红色的三角形面积最大。
```

**示例 2:**
```
输入: points = [[1,0],[0,0],[0,1]]
输出: 0.50000
```

**提示:**
- `3 <= points.length <= 50`
- `-50 <= xi, yi <= 50`
- 给出的所有点 **互不相同**

## 解题思路

使用**鞋带公式**（Shoelace formula）计算三角形面积，枚举所有可能的三个点组合。

**三角形面积公式：**
对于三个点 `(x1, y1)`, `(x2, y2)`, `(x3, y3)`：
```
面积 = |x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)| / 2
```

## Python 代码实现

### 方法一：暴力枚举（推荐）⭐

```python
from typing import List

class Solution:
    def largestTriangleArea(self, points: List[List[int]]) -> float:
        def area(p1, p2, p3):
            """计算三角形面积"""
            x1, y1 = p1
            x2, y2 = p2
            x3, y3 = p3
            return abs(x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2)) / 2.0
        
        n = len(points)
        max_area = 0
        
        # 枚举所有三个点的组合
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    max_area = max(max_area, area(points[i], points[j], points[k]))
        
        return max_area
```

### 方法二：使用 itertools

```python
from typing import List
from itertools import combinations

class Solution:
    def largestTriangleArea(self, points: List[List[int]]) -> float:
        def area(p1, p2, p3):
            return abs(p1[0] * (p2[1] - p3[1]) + 
                      p2[0] * (p3[1] - p1[1]) + 
                      p3[0] * (p1[1] - p2[1])) / 2.0
        
        return max(area(*combo) for combo in combinations(points, 3))
```

## 复杂度分析

- **时间复杂度**：O(n³)，枚举所有三点组合
- **空间复杂度**：O(1)

## 关键点总结

1. **鞋带公式**：计算三角形面积的标准方法
2. **三层循环**：枚举所有可能的三点组合
3. **绝对值**：面积必须是正数

## 易错点

1. **除以 2**：公式结果需要除以 2
2. **绝对值**：结果可能是负数，需要取绝对值
3. **浮点数**：返回值是 float
