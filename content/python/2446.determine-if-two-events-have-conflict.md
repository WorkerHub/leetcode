## 题目描述

给你两个字符串数组 `event1` 和 `event2`，表示发生在同一天的两个事件的开始和结束时间：

- `event1 = [startTime1, endTime1]`
- `event2 = [startTime2, endTime2]`

事件的时间为 `HH:MM` 格式。

如果两个事件存在某个非空的交集（即，某段时间同时属于两个事件），则返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：event1 = ["01:15","02:00"], event2 = ["02:00","03:00"]
输出：true
解释：两个事件在 02:00 相遇。
```

**示例 2：**
```
输入：event1 = ["01:00","02:00"], event2 = ["01:20","03:00"]
输出：true
```

**示例 3：**
```
输入：event1 = ["10:00","11:00"], event2 = ["14:00","15:00"]
输出：false
```

**提示：**
- `event1.length == event2.length == 2`
- `event1[i].length == event2[i].length == 5`
- `startTime1 <= endTime1`
- `startTime2 <= endTime2`

## 解题思路

两个区间有交集，等价于：
- `NOT (event1 结束在 event2 开始之前 OR event2 结束在 event1 开始之前)`

即：`NOT (endTime1 < startTime2 OR endTime2 < startTime1)`

等价于：`startTime1 <= endTime2 AND startTime2 <= endTime1`

由于时间格式 `HH:MM` 可以直接进行字符串字典序比较（格式固定，字典序等价于时间大小）。

## 代码实现

### 方法一：字符串比较（推荐）

```python
from typing import List

class Solution:
    def haveConflict(self, event1: List[str], event2: List[str]) -> bool:
        # 两区间有交集：start1 <= end2 且 start2 <= end1
        return event1[0] <= event2[1] and event2[0] <= event1[1]
```

### 方法二：转换为分钟数

```python
from typing import List

class Solution:
    def haveConflict(self, event1: List[str], event2: List[str]) -> bool:
        def to_minutes(t: str) -> int:
            h, m = map(int, t.split(':'))
            return h * 60 + m

        s1, e1 = to_minutes(event1[0]), to_minutes(event1[1])
        s2, e2 = to_minutes(event2[0]), to_minutes(event2[1])

        # 两区间不重叠：e1 < s2 或 e2 < s1
        return not (e1 < s2 or e2 < s1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 字符串比较 | O(1) | O(1) |
| 转换分钟数 | O(1) | O(1) |

## 关键点总结

1. 区间重叠判断：`start1 <= end2 AND start2 <= end1`
2. `HH:MM` 格式字符串可直接进行字典序比较（等价于时间大小比较）
3. 注意区间边界是闭区间（端点相同也算重叠）

## 易错点

- 端点相同时（如 `02:00` 和 `02:00`）也算重叠，用 `<=` 而不是 `<`
