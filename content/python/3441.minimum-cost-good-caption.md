## 题目描述

给你一个字符串 `caption`（只包含小写字母）。

一次操作中，你可以将任意一个字符替换为任意字符，代价为 1。

**好标题**的条件：每个字符连续出现次数至少为 3（即每种字符的每段连续区间长度 >= 3）。

返回使 `caption` 成为好标题的**最小代价**，以及对应的**字典序最小的好标题**。

**示例 1：**

```
输入：caption = "aab"
输出：["aaa", 1]
解释：将 'b' 改为 'a'，代价 1，得到 "aaa"
```

**示例 2：**

```
输入：caption = "aaabbb"
输出：["aaabbb", 0]
```

**提示：**
- `1 <= caption.length <= 5000`

## 解题思路

动态规划：`dp[i][c]` = 将前 i 个字符处理好（满足好标题条件），且第 i 个字符为 c 的最小代价。

但还需要知道最后一段连续 c 的长度，才能判断是否 >= 3。

设 `dp[i][c][l]` = 前 i 个字符，第 i 个字符为 c，以 c 结尾的最后段长度为 l（1, 2, 3+），的最小代价。

状态数 O(n * 26 * 3)，转移 O(26)，总复杂度 O(n * 26^2)。

## Python 代码实现

### 方法一：三维 DP

```python
class Solution:
    def minCostGoodCaption(self, caption: str) -> list:
        n = len(caption)
        if n < 3:
            # 不可能满足条件（每段至少 3 个）
            # 实际上 n >= 3 时才有意义
            pass

        INF = float('inf')

        # dp[c][l] = 以字符 c 结尾、最后段长度为 l（l=1,2,3代表>=3）的最小代价
        # l=3 表示长度 >= 3（可以继续添加）

        # 初始化：第 0 个字符
        # dp[c][l]: c in 0..25, l in 1,2,3
        prev = [[INF] * 4 for _ in range(26)]
        # l=1: 最后段只有 1 个字符（结束时不合法，但中间状态）
        # l=2: 最后段 2 个字符
        # l=3: 最后段 >= 3 个字符

        for c in range(26):
            cost = 0 if caption[0] == chr(ord('a') + c) else 1
            prev[c][1] = cost

        # 记录路径（字典序最小）
        # 为简化，先只计算最小代价
        for i in range(1, n):
            curr = [[INF] * 4 for _ in range(26)]
            orig = ord(caption[i]) - ord('a')

            for c in range(26):
                chg = 0 if c == orig else 1

                # 情况 1：第 i 个字符和第 i-1 个字符相同（c == prev_c）
                # 这时最后段长度 +1
                # prev_c == c，prev_l 可以是 1, 2, 3
                for pl in range(1, 4):
                    if prev[c][pl] < INF:
                        new_l = min(pl + 1, 3)
                        val = prev[c][pl] + chg
                        if val < curr[c][new_l]:
                            curr[c][new_l] = val

                # 情况 2：第 i 个字符和第 i-1 个字符不同（开始新段）
                # 前一段必须已经合法（l >= 3）
                # prev_c != c
                for pc in range(26):
                    if pc == c:
                        continue
                    if prev[pc][3] < INF:
                        val = prev[pc][3] + chg
                        if val < curr[c][1]:
                            curr[c][1] = val

            prev = curr

        # 最终答案：最后一段长度 >= 3（l == 3）
        min_cost = INF
        for c in range(26):
            if prev[c][3] < min_cost:
                min_cost = prev[c][3]

        # 回溯找字典序最小的字符串（省略详细实现）
        # 返回 [result_string, min_cost]
        return ["", min_cost]
```

### 方法二：简化版（只返回最小代价）

```python
class Solution:
    def minCostGoodCaption(self, caption: str) -> list:
        n = len(caption)
        INF = float('inf')

        # 简化：dp[i][c][l] 三维DP
        # 返回最小代价和对应的字符串
        # l: 1, 2, 3（代表末尾段长度1,2,>=3）

        # 使用字典存储状态
        # state: (c, l) -> (min_cost, path_string)
        from collections import defaultdict

        # 初始化
        states = {}
        for c in range(26):
            ch = chr(ord('a') + c)
            cost = 0 if caption[0] == ch else 1
            key = (c, 1)
            if key not in states or cost < states[key][0]:
                states[key] = (cost, ch)

        for i in range(1, n):
            new_states = {}
            orig = caption[i]
            for c in range(26):
                ch = chr(ord('a') + c)
                chg = 0 if ch == orig else 1

                # 延续前一段
                for l in range(1, 4):
                    key = (c, l)
                    if key in states:
                        prev_cost, prev_path = states[key]
                        new_l = min(l + 1, 3)
                        new_key = (c, new_l)
                        new_cost = prev_cost + chg
                        new_path = prev_path + ch
                        if new_key not in new_states or new_cost < new_states[new_key][0] or \
                           (new_cost == new_states[new_key][0] and new_path < new_states[new_key][1]):
                            new_states[new_key] = (new_cost, new_path)

                # 开始新段（前一段 l=3 合法）
                for pc in range(26):
                    if pc == c:
                        continue
                    key = (pc, 3)
                    if key in states:
                        prev_cost, prev_path = states[key]
                        new_key = (c, 1)
                        new_cost = prev_cost + chg
                        new_path = prev_path + ch
                        if new_key not in new_states or new_cost < new_states[new_key][0] or \
                           (new_cost == new_states[new_key][0] and new_path < new_states[new_key][1]):
                            new_states[new_key] = (new_cost, new_path)

            states = new_states

        # 找最优解
        best_cost = INF
        best_path = None
        for c in range(26):
            key = (c, 3)
            if key in states:
                cost, path = states[key]
                if cost < best_cost or (cost == best_cost and path < best_path):
                    best_cost = cost
                    best_path = path

        return [best_path if best_path else "", best_cost if best_cost < INF else 0]
```

## 复杂度分析

- 时间复杂度：O(n * 26^2)
- 空间复杂度：O(26 * 3)，滚动数组

## 关键点总结

1. 状态：(当前字符, 末尾段长度) 三类（1, 2, >=3）
2. 转移：延续同一字符或开始新段（前提：上一段长度 >= 3）
3. 字典序最小：同代价时按字母序选择较小的字符

## 易错点

1. 末尾段长度 >= 3 才合法，最终只取 l=3 的状态
2. 切换到新字符时，必须保证上一段已合法（l=3）
3. 字典序最小需要在 DP 中同时维护
