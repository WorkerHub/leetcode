## 题目描述

给你一个整数数组 `nums`，假设最小值和最大值各只出现一次，你需要**删除**它们。每次操作只能删除数组的第一个或最后一个元素。

返回删除最小值和最大值所需的**最少操作次数**。

**示例：**
```
输入：nums = [2,10,7,5,4,1,8,6]
输出：5
解释：最小值 1 在下标 5，最大值 10 在下标 1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`
- 最小值和最大值各只出现一次

## 解题思路

设最小值下标为 `minIdx`，最大值下标为 `maxIdx`（均为 0-indexed，满足 `minIdx <= maxIdx`，否则交换）。

删除这两个元素有三种策略：
1. **两者都从左端删除**：操作数 = `maxIdx + 1`（右边的那个下标 +1）
2. **两者都从右端删除**：操作数 = `n - minIdx`（左边那个到末尾的距离）
3. **一个从左端，一个从右端**：操作数 = `(minIdx + 1) + (n - maxIdx)`

取三种策略的最小值。

## 代码实现

### 方法一：贪心三种策略（推荐）

```python
from typing import List

class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)
        min_idx = nums.index(min(nums))
        max_idx = nums.index(max(nums))

        # 保证 min_idx <= max_idx，方便计算
        lo, hi = min(min_idx, max_idx), max(min_idx, max_idx)

        # 三种策略
        # 1. 两者都从左删：删到 hi（含）
        option1 = hi + 1
        # 2. 两者都从右删：从 lo 到末尾
        option2 = n - lo
        # 3. 从左删 lo（含），从右删 hi（含）
        option3 = (lo + 1) + (n - hi)

        return min(option1, option2, option3)
```

### 方法二：枚举说明版

```python
from typing import List

class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)
        a = nums.index(min(nums))
        b = nums.index(max(nums))
        lo, hi = min(a, b), max(a, b)

        # 策略1：从左端把两者都删掉（删 0..hi）
        left_left = hi + 1
        # 策略2：从右端把两者都删掉（删 lo..n-1）
        right_right = n - lo
        # 策略3：从左删 lo（含），从右删 hi（含）
        left_right = (lo + 1) + (n - hi)

        return min(left_left, right_right, left_right)
```

## 复杂度分析

- 时间复杂度：O(n)，找最大最小值各一次
- 空间复杂度：O(1)

## 关键点总结

1. 三种策略：全从左、全从右、一左一右
2. 先将两个目标下标归一化（lo <= hi）
3. 策略3：从左删 `lo+1` 个，从右删 `n-hi` 个

## 易错点

- 必须考虑三种策略，不能只考虑两种
- `lo` 和 `hi` 是两个目标下标中的较小和较大值，与最小/最大值本身无关
- 策略2 的操作数：从 `lo` 到末尾 = `n - lo`（包含 `lo` 位置）
