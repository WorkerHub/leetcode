## 题目描述

给你一个整数数组 `nums`，每次操作可以选择一个非空连续子数组，将其所有元素减 1。

返回使数组所有元素都变为 0 所需的最少操作次数。

**示例 1：**

```
输入：nums = [1, 2, 3, 2, 1]
输出：3
解释：
- 操作 [1,2,3,2,1]：全部减 1 -> [0,1,2,1,0]
- 操作 [1,2,1]：减 1 -> [0,0,1,0,0]
- 操作 [1]：减 1 -> 全 0
共 3 次。
```

**示例 2：**

```
输入：nums = [3, 3]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

关键观察：最少操作次数等于数组的"差分中正值的和"。

差分数组 `diff[0] = nums[0]`，`diff[i] = nums[i] - nums[i-1]`，`diff[n] = -nums[n-1]`。

每次操作相当于在差分数组中选择一个区间 `[l, r]`，`diff[l] -= 1`，`diff[r+1] += 1`。

目标是使所有 `nums[i] = 0`，等价于使差分数组全为 0。

最少操作数 = 差分数组中正值之和（每个正增量需要一次"开始"操作）。

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0

        # 计算差分数组，统计正值之和
        prev = 0
        for i in range(n):
            diff = nums[i] - prev
            if diff > 0:
                ops += diff
            prev = nums[i]

        return ops
```

### 方法二：动态规划（栈）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # 维护一个单调非递减栈
        # 每遇到比栈顶小的元素，需要结束一些操作，操作数增加
        stack = []
        ops = 0

        for v in nums:
            while stack and stack[-1] > v:
                stack.pop()

            if not stack or stack[-1] < v:
                ops += v - (stack[-1] if stack else 0)
                stack.append(v)

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(1)（方法一）；O(n)（方法二，栈）

## 关键点总结

1. 操作次数等于数组"上升台阶"的总高度（差分正值之和）。
2. 差分数组将区间操作转化为端点操作，每个正差分值对应一次新的操作开始。
3. 下降不需要操作，只有上升才需要新的操作。

## 易错点

1. `diff[i] = nums[i] - nums[i-1]`，第一个元素 `diff[0] = nums[0] - 0 = nums[0]`。
2. 只统计正值差分，负值表示操作结束，不额外计数。
