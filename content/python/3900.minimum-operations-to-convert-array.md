## 题目描述

给你两个整数数组 `source` 和 `target`，长度相同，每次操作可以选择 `source` 中的一个元素，将其加 1 或减 1（每次操作代价为 1）。

返回将 `source` 变为 `target` 所需的**最少操作次数**。

**注意：** 在某些版本中，可以使用另一个允许的值列表 `allowed`，每次可以直接将某个元素替换为 `allowed` 中的值（代价为 1）。根据题目实际描述，这里以 BFS + 哈希表版本为主。

**示例 1：**

```
输入：source = [1, 2, 3], target = [4, 1, 2]
输出：4
解释：
- source[0]: 1 -> 4，需要 3 步
- source[1]: 2 -> 1，需要 1 步
- source[2]: 3 -> 2，需要 1 步
最少操作 3 + 1 + 1 = 5? 
注：若允许直接替换为 target[i]，则每个元素操作 |source[i] - target[i]| 次。
```

**示例 2：**

```
输入：source = [1, 3, 5], target = [1, 3, 5]
输出：0
解释：source 与 target 相同，无需操作。
```

**提示：**
- `1 <= source.length, target.length <= 10^5`
- `1 <= source[i], target[i] <= 10^9`

## 解题思路

**基础版本（无跳转）：** 每个元素独立，总代价 = `sum(|source[i] - target[i]|)`。

**BFS + 哈希表版本（含跳转路径）：**

若存在一个允许值集合 `allowed`，可以将某个值"免费"或以代价 1 替换为 allowed 中的某个值，则 BFS 在值域图上进行最短路查找：

1. 建图：每个值到其 +1/-1 以及 allowed 中可达值的边。
2. BFS 求每个 `source[i]` 到 `target[i]` 的最短距离。
3. 对于大值域，需要哈希表记录访问状态。

## Python 代码实现

### 方法一：逐元素绝对差（基础版本，推荐）

```python
from typing import List

class Solution:
    def minOperations(self, source: List[int], target: List[int]) -> int:
        # 每个位置独立，最优策略是直接移动到目标值
        return sum(abs(s - t) for s, t in zip(source, target))
```

### 方法二：BFS + 哈希表（含跳转路径版本）

```python
from typing import List
from collections import deque

class Solution:
    def minOperations(self, source: List[int], target: List[int],
                      allowed: List[int] = None) -> int:
        if allowed is None:
            # 退化为基础版本
            return sum(abs(s - t) for s, t in zip(source, target))

        allowed_set = set(allowed)
        total = 0

        for s, t in zip(source, target):
            if s == t:
                continue

            # BFS 求 s -> t 的最短操作数
            visited = {s}
            queue = deque([(s, 0)])
            found = False

            while queue and not found:
                val, ops = queue.popleft()
                # 三种操作：+1, -1, 跳转到 allowed 中某值
                neighbors = [val + 1, val - 1] + list(allowed_set)
                for nv in neighbors:
                    if nv == t:
                        total += ops + 1
                        found = True
                        break
                    if nv not in visited:
                        visited.add(nv)
                        queue.append((nv, ops + 1))

            if not found and s != t:
                # 若 BFS 无法到达（理论上不可能，因为 +1/-1 可达任意整数）
                total += abs(s - t)

        return total
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n * D)，D 为最大值差；空间复杂度 O(D)（visited 集合）

## 关键点总结

1. 最基础版本：独立移动，答案为 `sum(|source[i] - target[i]|)`。
2. BFS 版本：在值域图上进行最短路搜索（加减 1 的代价为 1，跳转代价也为 1）。
3. 哈希表记录已访问值，避免重复访问。

## 易错点

1. 若 source 与 target 相等，直接返回 0，无需操作。
2. BFS 中不要忘记将起点加入 visited。
3. 值域可能很大（10^9），直接用数组会 MLE，必须用哈希表。
