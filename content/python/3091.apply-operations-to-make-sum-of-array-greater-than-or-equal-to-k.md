## 题目描述

给你一个正整数 `k`。最初 `nums = [1]`，你可以执行以下操作：
1. **增加：** 将 `nums` 中某个元素 +1
2. **复制：** 将 `nums` 中某个元素的值追加到 `nums` 末尾

返回使 `nums` 中所有元素之和 >= `k` 所需的最少操作总次数。

**示例 1：**
```
输入：k = 11
输出：5
解释：1 → +1 → 2 → +1 → 3 → 复制 → [3,3] → 复制 → [3,3,3] → 复制 → [3,3,3,3]
实际：[1] → [2] → [3] → [3,3] → [3,3,3] → [3,3,3,3]，和=12>=11，操作 5 次
```

**示例 2：**
```
输入：k = 1
输出：0
```

**提示：**
- `1 <= k <= 10^5`

## 解题思路

贪心：设最终每个元素的值为 `v`（通过 `v-1` 次增加操作），数组大小为 `m`（通过 `m-1` 次复制操作），则：
- 操作总次数 = `(v - 1) + (m - 1)` = `v + m - 2`
- 满足条件：`v * m >= k`

枚举 `v`（从 1 到 k），最小 m = `ceil(k / v)`，总操作 = `v - 1 + ceil(k/v) - 1`。

## Python 代码实现

### 方法一：枚举 v（推荐）

```python
import math

class Solution:
    def minOperations(self, k: int) -> int:
        if k == 1:
            return 0

        ans = float('inf')
        for v in range(1, k + 1):
            # 需要 m = ceil(k / v) 个元素
            m = math.ceil(k / v)
            ops = (v - 1) + (m - 1)
            ans = min(ans, ops)

        return ans
```

### 方法二：数学优化

```python
import math

class Solution:
    def minOperations(self, k: int) -> int:
        if k == 1:
            return 0

        # 对于固定的 v，m = ceil(k/v)，总操作 = v + m - 2
        # 最优 v 在 sqrt(k) 附近
        # 完整枚举即可（k <= 10^5，枚举 O(sqrt(k)) 即足够）
        ans = float('inf')
        v = 1
        while v * v <= k:
            m = math.ceil(k / v)
            ans = min(ans, v + m - 2)
            v += 1

        # 同时枚举 m
        m = 1
        while m * m <= k:
            v = math.ceil(k / m)
            ans = min(ans, v + m - 2)
            m += 1

        return ans
```

## 复杂度分析

- 方法一：O(k)，枚举所有 v
- 方法二：O(sqrt(k))，只枚举到 sqrt(k)
- 空间复杂度：O(1)

## 关键点总结

1. 操作分两步：先加（确定每个元素值）再复制（确定元素个数）
2. 最终状态：v 的值重复 m 次，满足 `v * m >= k`
3. 最优在 `v ≈ sqrt(k)` 附近（AM-GM 不等式）

## 易错点

1. 初始数组是 `[1]`，所以增加 1 次变为 2（不是 1 次操作得到 1）
2. `v - 1` 次增加（从 1 增加到 v）
3. `m - 1` 次复制（从 1 个元素复制到 m 个）
