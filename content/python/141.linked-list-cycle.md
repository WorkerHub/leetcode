## 题目描述

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**。仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 `true`。否则，返回 `false`。

**示例 1：**
```
输入：head = [3,2,0,-4], pos = 1
输出：true
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**
```
输入：head = [1,2], pos = 0
输出：true
解释：链表中有一个环，其尾部连接到第一个节点。
```

**示例 3：**
```
输入：head = [1], pos = -1
输出：false
解释：链表中没有环。
```

**提示：**
- 链表中节点的数目范围是 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效索引

**进阶：** 你能用 O(1)（即，常量）内存解决此问题吗？

## 解题思路

这是一道经典的链表问题，最优解法是使用**快慢指针（Floyd 判圈算法）**。

**核心思想：龟兔赛跑**

1. **快慢指针法**：
   - 设置两个指针：慢指针 `slow` 每次走 1 步，快指针 `fast` 每次走 2 步
   - 如果链表有环，快指针最终会追上慢指针（在环内相遇）
   - 如果链表无环，快指针会先到达链表末尾（`fast` 或 `fast.next` 为 None）

2. **为什么快慢指针一定会相遇？**
   - 如果有环，慢指针进入环后，快指针也在环内
   - 每次迭代，快指针与慢指针的距离减少 1
   - 最终距离会变为 0，即相遇

3. **时间复杂度分析**：
   - 无环：快指针走到末尾，O(n)
   - 有环：快指针最多绕环一圈追上慢指针，O(n)

## Python 代码实现

### 方法一：快慢指针（推荐）

```python
from typing import Optional

# Definition for singly-linked list.
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        # 边界情况：空链表或只有一个节点
        if not head or not head.next:
            return False
        
        # 初始化快慢指针
        slow = head
        fast = head.next
        
        # 快慢指针移动，直到相遇或 fast 到达末尾
        while slow != fast:
            # 如果 fast 到达末尾，说明无环
            if not fast or not fast.next:
                return False
            slow = slow.next
            fast = fast.next.next
        
        # 快慢指针相遇，说明有环
        return True
```

### 方法二：快慢指针（简化版）

```python
from typing import Optional

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = fast = head
        
        # 只要 fast 和 fast.next 不为空，就继续移动
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            # 如果相遇，说明有环
            if slow == fast:
                return True
        
        # fast 到达末尾，说明无环
        return False
```

### 方法三：哈希表（不满足空间要求）

```python
from typing import Optional

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        seen = set()
        curr = head
        
        while curr:
            # 如果节点已访问过，说明有环
            if curr in seen:
                return True
            seen.add(curr)
            curr = curr.next
        
        # 遍历完整个链表都没有重复，说明无环
        return False
```

### 方法四：修改节点值（破坏性方法，不推荐）

```python
from typing import Optional

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        # 使用一个特殊值作为标记
        VISITED = float('inf')
        curr = head
        
        while curr:
            # 如果遇到已标记的节点，说明有环
            if curr.val == VISITED:
                return True
            # 标记当前节点
            curr.val = VISITED
            curr = curr.next
        
        return False
```

## 复杂度分析

### 方法一、二：快慢指针
- **时间复杂度**：O(n)
  - 无环：快指针走到末尾，最多 n/2 次迭代
  - 有环：快指针最多绕环一圈追上慢指针，O(n)
- **空间复杂度**：O(1)，只使用两个指针

### 方法三：哈希表
- **时间复杂度**：O(n)，遍历链表一次
- **空间复杂度**：O(n)，需要存储所有访问过的节点

### 方法四：修改节点值
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，但会破坏原链表

## 图解示例

以 `head = [3,2,0,-4], pos = 1` 为例：

```
链表结构：
3 → 2 → 0 → -4
    ↑__________|

快慢指针移动过程：

初始：
slow = 3, fast = 3

第1步：
slow = 2, fast = 0

第2步：
slow = 0, fast = 2  (fast 进入环，开始追赶)

第3步：
slow = -4, fast = -4  (相遇！)

结论：有环
```

**无环的情况：**
```
链表: 1 → 2 → 3 → 4 → None

第1步: slow = 2, fast = 3
第2步: slow = 3, fast = None  (fast 到达末尾)

结论：无环
```

## 关键点总结

1. **快慢指针的初始化**：可以都从 head 开始，或者 slow 从 head，fast 从 head.next
2. **循环终止条件**：`fast and fast.next` 确保 `fast.next.next` 不会空指针
3. **相遇即有环**：快指针每次比慢指针多走 1 步，一定会在环内相遇
4. **空间优化**：快慢指针只需 O(1) 空间，优于哈希表的 O(n)
5. **Floyd 判圈算法**：这是一个经典算法，也用于 142 题找环的入口

## 易错点

1. **空指针问题**：移动 fast 前要确保 `fast` 和 `fast.next` 都不为空
2. **初始化位置**：如果 slow 和 fast 都从 head 开始，循环条件要先判断再移动
3. **循环条件**：要判断 `fast and fast.next`，不能只判断 `fast`
4. **相遇条件**：要判断 `slow == fast`，不是判断 `slow.val == fast.val`
5. **边界情况**：空链表和单节点链表要特殊处理
