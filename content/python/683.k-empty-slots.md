## 题目描述

有一个花园,有 n 个位置,位置从 1 到 n 编号。每个位置上要么有花,要么没有花。

花会在某些特定的日子开放。给定一个数组 bulbs,bulbs[i] = x 表示第 (i+1) 天,位置 x 上的花会开。(i 从 0 开始)

同时给定一个整数 k。你需要找到:是否存在某一天,有恰好 k 个相邻的空位置夹在两朵开花的花之间。

如果存在,返回这一天是第几天(从 1 开始);如果不存在,返回 -1。

**示例 1:**
```
输入: bulbs = [1,3,2], k = 1
输出: 2
解释:
第1天: [x, _, _]  (位置1开花)
第2天: [x, _, x]  (位置3开花,此时位置1和3之间有1个空位,满足条件)
第3天: [x, x, x]  (位置2开花)
因此答案是第2天
```

**示例 2:**
```
输入: bulbs = [1,2,3], k = 1
输出: -1
解释:
第1天: [x, _, _]
第2天: [x, x, _]  (位置1和2相邻,中间0个空位)
第3天: [x, x, x]  (位置2和3相邻,中间0个空位)
永远没有恰好1个空位的情况
```

**提示:**
- bulbs.length == n
- 1 <= n <= 2 * 10^4
- 1 <= bulbs[i] <= n
- bulbs 是 [1, 2, ..., n] 的一个排列
- 0 <= k <= 2 * 10^4

**注意:** 这是一道 LeetCode 会员题(Premium)

## 解题思路

这道题的关键是理解:我们需要找到两朵开花的花,它们之间恰好有 k 个空位。

**核心思路:**
- 按天数顺序处理每朵花的开放
- 每天检查新开的花与已开的花之间的距离
- 如果距离恰好是 k+1(中间 k 个空位),则找到答案

**方法一思路(滑动窗口):**
1. days[i] 表示位置 i+1 的花在第几天开
2. 使用滑动窗口 [left, right],窗口大小为 k+2
3. 检查窗口内的 k 个位置是否都在 left 和 right 之后开花
4. 如果是,说明在 max(days[left], days[right]) 天时满足条件

**方法二思路(有序集合):**
1. 使用有序集合维护已开花的位置
2. 每天添加新位置后,查找其前驱和后继
3. 检查与前驱/后继的距离是否为 k+1

## Python 代码实现

### 方法一:滑动窗口(推荐)

```python
from typing import List

class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        # days[i]表示位置i+1的花在第几天开
        n = len(bulbs)
        days = [0] * n
        
        for day, pos in enumerate(bulbs, 1):
            days[pos - 1] = day
        
        # 滑动窗口:[left, right],中间有k个位置
        ans = float('inf')
        left = 0
        right = k + 1
        
        while right < n:
            # 检查中间k个位置是否都在left和right之后开花
            valid = True
            for i in range(left + 1, right):
                if days[i] < days[left] or days[i] < days[right]:
                    # 中间有位置提前开花,不满足条件
                    valid = False
                    left = i  # 从这个位置重新开始
                    right = i + k + 1
                    break
            
            if valid:
                # 找到满足条件的窗口
                ans = min(ans, max(days[left], days[right]))
                left = right
                right = left + k + 1
        
        return ans if ans != float('inf') else -1
```

### 方法二:有序集合(TreeSet模拟)

```python
from typing import List
from sortedcontainers import SortedSet

class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        active = SortedSet()  # 已开花的位置
        
        for day, pos in enumerate(bulbs, 1):
            active.add(pos)
            
            # 查找pos的前驱
            idx = active.index(pos)
            
            # 检查与右边的距离
            if idx + 1 < len(active):
                if active[idx + 1] - pos == k + 1:
                    return day
            
            # 检查与左边的距离
            if idx > 0:
                if pos - active[idx - 1] == k + 1:
                    return day
        
        return -1
```

### 方法三:优化的滑动窗口

```python
from typing import List

class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        n = len(bulbs)
        days = [0] * n
        
        # 记录每个位置在哪天开花
        for day in range(n):
            days[bulbs[day] - 1] = day + 1
        
        ans = float('inf')
        left, right = 0, k + 1
        
        # 滑动窗口
        while right < n:
            # 检查[left+1, right-1]是否都在days[left]和days[right]之后开
            i = left + 1
            while i < right:
                if days[i] < days[left] or days[i] < days[right]:
                    # 窗口失效,从i重新开始
                    left = i
                    right = i + k + 1
                    break
                i += 1
            
            # 窗口有效
            if i == right:
                ans = min(ans, max(days[left], days[right]))
                left = right
                right = left + k + 1
        
        return -1 if ans == float('inf') else ans
```

### 方法四:暴力解法(便于理解)

```python
from typing import List

class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        flowers = [False] * (len(bulbs) + 1)  # 位置1到n
        
        for day, pos in enumerate(bulbs, 1):
            flowers[pos] = True
            
            # 检查左边k+1位置
            if pos - k - 1 > 0 and flowers[pos - k - 1]:
                # 检查中间k个位置是否都没开花
                if all(not flowers[i] for i in range(pos - k, pos)):
                    return day
            
            # 检查右边k+1位置
            if pos + k + 1 <= len(bulbs) and flowers[pos + k + 1]:
                # 检查中间k个位置是否都没开花
                if all(not flowers[i] for i in range(pos + 1, pos + k + 1)):
                    return day
        
        return -1
```

## 复杂度分析

**方法一(滑动窗口):**
- 时间复杂度: O(n),每个位置最多被访问两次
- 空间复杂度: O(n),需要 days 数组

**方法二(有序集合):**
- 时间复杂度: O(n log n),每次插入和查找都是 O(log n)
- 空间复杂度: O(n),存储有序集合

**方法四(暴力):**
- 时间复杂度: O(n * k),每天检查 k 个位置
- 空间复杂度: O(n)

## 关键点总结

1. **逆向思维**: 不要按位置思考,而是记录每个位置在哪天开花
2. **滑动窗口**: 窗口大小为 k+2,检查中间 k 个位置
3. **窗口有效性**: 中间位置的开花时间必须晚于两端
4. **窗口移动**: 如果中间某位置提前开花,从该位置重新开始
5. **有序集合**: 可以快速查找前驱和后继位置

## 易错点

1. **索引转换**: bulbs 中的值是 1-indexed,数组是 0-indexed
2. **天数计数**: 第 i 天对应 enumerate 的 i+1
3. **距离计算**: k 个空位意味着位置差为 k+1
4. **窗口边界**: right 必须 < n,不是 <= n
5. **答案初始化**: 使用 float('inf') 便于判断是否找到答案
