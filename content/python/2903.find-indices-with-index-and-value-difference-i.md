## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`，以及两个整数 `indexDifference` 和 `valueDifference`。

找出满足下述条件的两个下标 `i` 和 `j`：
- `abs(i - j) >= indexDifference`
- `abs(nums[i] - nums[j]) >= valueDifference`

返回整数数组 `[i, j]`。若不存在这样的两个下标，返回 `[-1, -1]`。

**示例 1：**
```
输入：nums = [5,1,4,1], indexDifference = 2, valueDifference = 4
输出：[0,3]
解释：abs(0-3)=3>=2, abs(nums[0]-nums[3])=abs(5-1)=4>=4
```

**示例 2：**
```
输入：nums = [2,1], indexDifference = 0, valueDifference = 0
输出：[0,0]
```

**提示：**
- `1 <= n <= 100`
- `0 <= nums[i] <= 100`
- `0 <= indexDifference <= 100`
- `0 <= valueDifference <= 100`

## 解题思路

数据范围很小（n <= 100），直接暴力枚举所有满足下标差条件的对 `(i, j)`，检查值差是否满足即可。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def findIndices(self, nums: List[int], indexDifference: int, valueDifference: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(n):
                # 检查下标差和值差是否同时满足
                if (abs(i - j) >= indexDifference and
                        abs(nums[i] - nums[j]) >= valueDifference):
                    return [i, j]
        return [-1, -1]
```

### 方法二：固定 j 枚举 i（优化遍历顺序）

```python
from typing import List

class Solution:
    def findIndices(self, nums: List[int], indexDifference: int, valueDifference: int) -> List[int]:
        n = len(nums)
        for j in range(n):
            # i 满足 abs(i-j) >= indexDifference，即 i <= j-indexDifference 或 i >= j+indexDifference
            for i in range(0, j - indexDifference + 1):
                if abs(nums[i] - nums[j]) >= valueDifference:
                    return [i, j]
            for i in range(j + indexDifference, n):
                if abs(nums[i] - nums[j]) >= valueDifference:
                    return [i, j]
        return [-1, -1]
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有下标对
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. 数据范围小，暴力 O(n^2) 完全可接受
2. `abs` 函数处理绝对值，避免分类讨论
3. 找到第一个满足条件的对即可返回

## 易错点

1. 注意 `i == j` 时下标差为 0，若 `indexDifference == 0` 则允许 `i == j`
2. 值差同样用绝对值，两个元素谁大谁小不限制
