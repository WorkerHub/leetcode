## 题目描述

给你一个字符串 `s`，统计满足以下条件的子字符串数量：子字符串是回文串，或者恰好改变一个字符后可以变为回文串。

**示例 1：**

```
输入：s = "abcba"
输出：7
解释：回文子串5个：a,b,c,b,a,aba,abcba；另外如bab,bcb等...
实际需要准确计算
```

**提示：**

- `1 <= s.length <= 10^3`
- `s` 只包含小写字母

## 解题思路

对每个子字符串，判断是否是回文串或至多改变一个字符后成为回文串。

条件：首尾字符对不匹配的对数为 0（已是回文）或 1（改一个字符）。

用中心扩展法，对每个中心扩展时统计不匹配对数。

## Python 代码实现

### 方法一：中心扩展（推荐）

```python
class Solution:
    def countPalindromes(self, s: str) -> int:
        n = len(s)
        count = 0

        def expand(left, right):
            nonlocal count
            mismatches = 0
            while left >= 0 and right < n:
                if s[left] != s[right]:
                    mismatches += 1
                if mismatches <= 1:
                    count += 1  # 改变0或1个字符后是回文
                if mismatches > 1:
                    break
                left -= 1
                right += 1

        # 奇数长度子串
        for i in range(n):
            count += 1  # 单个字符
            expand(i - 1, i + 1)

        # 偶数长度子串
        for i in range(n - 1):
            expand(i, i + 1)

        return count
```

### 方法二：暴力枚举

```python
class Solution:
    def countPalindromes(self, s: str) -> int:
        n = len(s)
        count = 0
        for i in range(n):
            for j in range(i, n):
                sub = s[i:j + 1]
                # 计算不匹配对数
                mismatches = sum(sub[k] != sub[len(sub) - 1 - k]
                                 for k in range(len(sub) // 2))
                if mismatches <= 1:
                    count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O(n^2)（中心扩展），O(n^3)（暴力）
- 空间复杂度：O(1)

## 关键点总结

1. "至多改变一个字符成为回文"等价于首尾不匹配对数 <= 1
2. 中心扩展统计不匹配对数，超过 1 时停止
3. 奇偶长度分别处理

## 易错点

1. 单字符子串（长度 1）始终是回文，单独统计
2. mismatches > 1 时整个方向可以停止
3. 偶数长度从相邻字符开始扩展
