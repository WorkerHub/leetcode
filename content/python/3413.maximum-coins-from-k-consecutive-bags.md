## 题目描述

在一条数轴上有若干个袋子，第 `i` 个袋子位于位置 `position[i]`，包含 `coins[i]` 枚硬币。

你可以选择一个长度为 `k` 的区间 `[x, x+k-1]`（x 为实数），收集所有位置在该区间内的袋子的硬币。

返回你能收集到的**最多硬币数**。

**示例 1：**

```
输入：coins = [[8,3],[1,2],[10,5]], k = 10
输出：9
解释：选择区间 [1,10]，包含位置 1 和 8，收集 2+3=5 枚... 
或选择区间 [1,10]，包含 1,8，但 10 不在 [1,10]（10 的区间是 [1,10]，10 在区间内）
实际：位置 1,8,10 都在 [1,10]，收集 2+3+5=10
```

**示例 2：**

```
输入：coins = [[1,1],[2,2],[3,3]], k = 2
输出：5
解释：选择 [2,3]，收集 2+3=5
```

**提示：**
- `1 <= coins.length <= 10^5`
- `1 <= position[i] <= 10^9`
- `1 <= coins[i] <= 10^5`
- `1 <= k <= 10^9`

## 解题思路

最优区间的端点一定"对齐"某个袋子：区间左端点等于某个袋子的位置，或右端点等于某个袋子的位置。

因此只需枚举 2n 个候选区间：
- 区间 `[position[i], position[i] + k - 1]`（左对齐）
- 区间 `[position[i] - k + 1, position[i]]`（右对齐）

对于每个候选区间，用二分查找和前缀和快速计算区间内的硬币总量。

步骤：
1. 按位置排序
2. 计算前缀和
3. 枚举 2n 个候选区间，用二分 + 前缀和计算每个区间的硬币总量
4. 取最大值

## Python 代码实现

### 方法一：排序 + 前缀和 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumCoins(self, coins: List[List[int]], k: int) -> int:
        # 按位置排序
        coins.sort()
        n = len(coins)

        positions = [c[0] for c in coins]
        values = [c[1] for c in coins]

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + values[i]

        def coins_in_range(left, right):
            """计算位置在 [left, right] 内的硬币总量"""
            lo = bisect.bisect_left(positions, left)
            hi = bisect.bisect_right(positions, right)
            return prefix[hi] - prefix[lo]

        ans = 0

        for i in range(n):
            pos = positions[i]
            # 左对齐：区间 [pos, pos + k - 1]
            ans = max(ans, coins_in_range(pos, pos + k - 1))
            # 右对齐：区间 [pos - k + 1, pos]
            ans = max(ans, coins_in_range(pos - k + 1, pos))

        return ans
```

### 方法二：滑动窗口（适合 k 较小的情况）

```python
from typing import List

class Solution:
    def maximumCoins(self, coins: List[List[int]], k: int) -> int:
        coins.sort()
        n = len(coins)

        ans = 0
        window_sum = 0
        left = 0

        for right in range(n):
            window_sum += coins[right][1]
            # 收缩左边界：确保区间长度 <= k
            while coins[right][0] - coins[left][0] >= k:
                window_sum -= coins[left][1]
                left += 1
            ans = max(ans, window_sum)

        return ans
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n log n)，排序和二分
  - 空间复杂度：O(n)，前缀和数组

- 方法二（滑动窗口）：
  - 时间复杂度：O(n log n)，主要是排序
  - 空间复杂度：O(1)

## 关键点总结

1. 最优区间一定以某个袋子位置为左端点或右端点
2. 排序后用前缀和 + 二分可以 O(log n) 查询任意区间内的硬币总量
3. 滑动窗口直接维护区间内的硬币总量，代码更简洁

## 易错点

1. 区间是 `[x, x+k-1]`，长度为 k，不是 `[x, x+k]`
2. 滑动窗口的收缩条件：`coins[right][0] - coins[left][0] >= k`（大于等于，而不是大于）
3. 位置可以不连续，区间内可能没有袋子（此时硬币为 0）
