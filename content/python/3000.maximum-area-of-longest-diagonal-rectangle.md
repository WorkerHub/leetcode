## 题目描述

给你一个下标从 0 开始的二维整数数组 `dimensions`，其中 `dimensions[i] = [length_i, width_i]` 表示第 `i` 个矩形的长和宽。

返回**对角线最长**的矩形的面积。如果存在多个对角线长度相同的矩形，则返回面积最大的那个矩形的面积。

**示例 1：**
```
输入：dimensions = [[9,3],[8,6]]
输出：48
解释：
- 矩形 0：对角线 = sqrt(9^2 + 3^2) = sqrt(90) ≈ 9.49，面积 = 27
- 矩形 1：对角线 = sqrt(8^2 + 6^2) = sqrt(100) = 10，面积 = 48
对角线最长的是矩形 1，面积为 48。
```

**示例 2：**
```
输入：dimensions = [[3,4],[4,3]]
输出：12
解释：两个矩形对角线都为 5，面积都为 12，返回 12。
```

**提示：**
- `1 <= dimensions.length <= 100`
- `dimensions[i].length == 2`
- `1 <= dimensions[i][0], dimensions[i][1] <= 100`

## 解题思路

遍历所有矩形，比较对角线长度（用对角线的平方来避免浮点数运算），记录最长对角线对应的最大面积。

若当前矩形对角线更长，更新答案；若对角线相同，取面积较大的。

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:
        max_diag_sq = 0  # 最长对角线的平方
        ans = 0

        for l, w in dimensions:
            diag_sq = l * l + w * w  # 对角线平方（避免浮点）
            area = l * w

            if diag_sq > max_diag_sq:
                # 对角线更长，更新
                max_diag_sq = diag_sq
                ans = area
            elif diag_sq == max_diag_sq:
                # 对角线相同，取较大面积
                ans = max(ans, area)

        return ans
```

### 方法二：排序法

```python
from typing import List

class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:
        # 按对角线平方降序，面积降序排列
        dimensions.sort(key=lambda x: (-(x[0]**2 + x[1]**2), -(x[0] * x[1])))
        return dimensions[0][0] * dimensions[0][1]
```

### 方法三：使用 max 函数

```python
from typing import List

class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:
        # 以 (对角线平方, 面积) 为键取最大值
        _, area = max(
            (l*l + w*w, l*w) for l, w in dimensions
        )
        return area
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历所有矩形
- 空间复杂度：O(1)，只用常数额外空间

## 图解示例

```
矩形 [9,3]：对角线² = 81+9 = 90
矩形 [8,6]：对角线² = 64+36 = 100  ← 更大
面积 = 8×6 = 48
```

## 关键点总结

1. 用对角线的平方比较大小，避免浮点数精度问题
2. 对角线长度 = sqrt(l² + w²)，比较 l² + w² 即可
3. 对角线相同时，取面积最大的矩形
4. Python 中 max 函数可以直接比较元组（按字典序）

## 易错点

1. 不要直接比较 sqrt 浮点数，应比较平方值（整数运算更精确）
2. 对角线相同时需取最大面积，不是第一个出现的
3. 面积 = l × w，不要搞错
