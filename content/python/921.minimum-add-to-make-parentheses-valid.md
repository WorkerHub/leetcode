## 题目描述

只有满足下面几点之一，括号字符串才是有效的：

- 它是一个空字符串，或者
- 它可以被写成 `AB`（`A` 与 `B` 连接）, 其中 `A` 和 `B` 都是有效字符串，或者
- 它可以被写作 `(A)`，其中 `A` 是有效字符串。

给定一个括号字符串 `s`，在每一次操作中，你都可以在字符串的任何位置插入一个括号

- 例如，如果 `s = "())"`，你可以插入一个开始括号为 `"(()))"` 或结束括号为 `"()))"`。

返回为使结果字符串 `s` 有效而必须添加的最少括号数。

**示例 1：**
```
输入：s = "())"
输出：1
```

**示例 2：**
```
输入：s = "((("
输出：3
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 只包含 `'('` 和 `')'` 字符

## 解题思路

这道题要求计算需要添加的最少括号数使得字符串有效。

**方法一：栈**
1. 使用栈模拟括号匹配
2. 遇到 `(` 入栈
3. 遇到 `)` 时：
   - 如果栈不为空，出栈（匹配成功）
   - 如果栈为空，需要添加一个 `(`，计数器加 1
4. 最后栈中剩余的 `(` 需要添加对应的 `)`

**方法二：计数器**
1. 使用两个计数器：`left`（未匹配的 `(`）和 `right`（需要添加的 `(`）
2. 遇到 `(` 时，`left` 加 1
3. 遇到 `)` 时：
   - 如果 `left > 0`，匹配一个 `(`，`left` 减 1
   - 如果 `left == 0`，需要添加一个 `(`，`right` 加 1
4. 最终答案是 `left + right`

**方法二更简洁，推荐使用。**

## Python 代码实现

### 方法一：栈

```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        stack = []
        need_left = 0  # 需要添加的左括号数量
        
        for char in s:
            if char == '(':
                stack.append(char)
            else:  # char == ')'
                if stack:
                    stack.pop()  # 匹配成功
                else:
                    need_left += 1  # 需要添加左括号
        
        # 栈中剩余的是未匹配的左括号，需要添加右括号
        need_right = len(stack)
        
        return need_left + need_right
```

### 方法二：计数器（推荐 ⭐）

```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        left = 0   # 未匹配的左括号数量
        right = 0  # 需要添加的左括号数量
        
        for char in s:
            if char == '(':
                left += 1
            else:  # char == ')'
                if left > 0:
                    left -= 1  # 匹配一个左括号
                else:
                    right += 1  # 需要添加一个左括号
        
        # left 是未匹配的左括号，需要添加右括号
        # right 是需要添加的左括号
        return left + right
```

### 方法三：简化版

```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        balance = 0  # 当前未匹配的左括号数
        additions = 0  # 需要添加的括号数
        
        for char in s:
            balance += 1 if char == '(' else -1
            
            # 如果 balance < 0，说明右括号多了，需要添加左括号
            if balance < 0:
                additions += 1
                balance = 0  # 重置平衡
        
        # balance 是剩余未匹配的左括号，需要添加右括号
        return additions + balance
```

## 复杂度分析

**时间复杂度：** O(n)
- 只需遍历字符串一次

**空间复杂度：** 
- 方法一：O(n)，栈的空间
- 方法二/三：O(1)，只用常数空间

## 关键点总结

1. **栈的应用**：括号匹配问题的经典方法
2. **计数器优化**：可以用两个变量代替栈
3. **贪心思想**：遇到不匹配时立即处理
4. **两种情况**：右括号多了，或左括号多了
5. **最优解**：方法二空间 O(1)，代码简洁

## 易错点

1. **理解题意**：返回的是需要添加的括号数，不是最终长度
2. **两种不匹配**：要分别处理左括号多和右括号多
3. **计数器含义**：要明确每个变量的含义
4. **最终结果**：是两个计数器的和

## 图解示例

示例 1：`s = "())"`

```
遍历过程：
'(' : left = 1, right = 0
')' : left = 0, right = 0  (匹配)
')' : left = 0, right = 1  (需要添加左括号)

结果：left + right = 0 + 1 = 1
补充：(())  或  ()()
```

示例 2：`s = "((("`

```
遍历过程：
'(' : left = 1, right = 0
'(' : left = 2, right = 0
'(' : left = 3, right = 0

结果：left + right = 3 + 0 = 3
补充：((()))
```
