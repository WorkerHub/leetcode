## 题目描述

给你一个由正整数组成的数组 `nums`。

返回数组 `nums` 中所有具有最大频率的元素的总频率之和。

频率是指某个元素在数组中出现的次数。

**示例 1：**
```
输入：nums = [1,2,2,3,1,4]
输出：4
解释：元素 1 和 2 的频率均为 2，是最大频率。总频率 = 2 + 2 = 4。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：5
解释：每个元素频率均为 1，均为最大频率。总频率 = 1 * 5 = 5。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

1. 使用哈希表统计每个元素的出现次数
2. 找到最大频率
3. 统计所有频率等于最大频率的元素，将它们的频率累加

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxFrequencyElements(self, nums: List[int]) -> int:
        # 统计每个元素的频率
        freq = Counter(nums)
        # 找到最大频率
        max_freq = max(freq.values())
        # 累加所有最大频率元素的频率
        return sum(v for v in freq.values() if v == max_freq)
```

### 方法二：两步统计

```python
from typing import List
from collections import Counter

class Solution:
    def maxFrequencyElements(self, nums: List[int]) -> int:
        freq = Counter(nums)
        max_freq = max(freq.values())
        # 统计有多少个元素具有最大频率，乘以最大频率
        count = sum(1 for v in freq.values() if v == max_freq)
        return count * max_freq
```

### 方法三：一次遍历

```python
from typing import List

class Solution:
    def maxFrequencyElements(self, nums: List[int]) -> int:
        freq = {}
        for x in nums:
            freq[x] = freq.get(x, 0) + 1

        max_freq = max(freq.values())
        total = 0
        for v in freq.values():
            if v == max_freq:
                total += v
        return total
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组统计频率，再遍历频率表
- 空间复杂度：O(n)，哈希表存储频率

## 关键点总结

1. Counter 是统计频率的最简洁工具
2. 先找最大频率，再累加等于最大频率的值
3. 方法二利用了"所有最大频率元素的频率相同"的特点

## 易错点

1. 返回的是频率之和，不是元素个数
2. 可能有多个元素同时拥有最大频率
