## 题目描述

给你一棵 n 个节点的无向树（编号 1 到 n），以及边 edges。

如果路径上**恰好有 1 个质数节点**，则称该路径为**有效路径**。

返回有效路径的数量（路径是两个不同节点之间的路径）。

**提示：**
- `1 <= n <= 10^5`

## 解题思路

**树形 DP + 路径统计：**

以每条边为分界线统计路径，或以每个节点为根进行换根。

**正确方法：合并子树路径**

对每个节点 v，合并其各子树：
- `f[v][0]` = 以 v 为端点，路径上有 0 个质数的路径数（含 v 自身）
- `f[v][1]` = 以 v 为端点，路径上有 1 个质数的路径数（含 v 自身）

合并时，若 v 本身是质数：
- 路径通过 v 有效：左子树的 0 质数路径 × 右子树的 0 质数路径（v 是唯一质数）

若 v 本身不是质数：
- 路径通过 v 有效：左子树的 1 质数路径 × 右子树的 0 质数路径 + 左 0 × 右 1

## Python 代码实现

### 方法一：DFS 树形 DP（推荐）

```python
from math import isqrt
from collections import defaultdict
from typing import List

class Solution:
    def countValidPaths(self, n: int, edges: List[List[int]]) -> int:
        # 埃氏筛生成质数表
        is_prime = [False, False] + [True] * (n - 1)
        for i in range(2, isqrt(n) + 1):
            if is_prime[i]:
                for j in range(i * i, n + 1, i):
                    is_prime[j] = False

        # 建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 0

        # dfs 返回 (cnt0, cnt1)
        # cnt0: 从 node 出发，经过 0 个质数的路径数
        # cnt1: 从 node 出发，经过 1 个质数的路径数
        def dfs(node: int, parent: int):
            nonlocal ans
            c0 = 1 - is_prime[node]  # node 是非质数则 c0=1，否则 c0=0
            c1 = is_prime[node]      # node 是质数则 c1=1，否则 c1=0

            for nei in graph[node]:
                if nei == parent:
                    continue
                nc0, nc1 = dfs(nei, node)
                # 合并：通过 node 连接两个子树的路径
                if is_prime[node]:
                    # node 是质数：只有两侧都有 0 个质数的路径才有效（共 1 个质数=node）
                    ans += c0 * nc0
                    # 更新 c1（这一侧有质数路径）
                    new_c1 = c1 + nc0  # nc0 条从 nei 来的无质数路径，加上 node 变成有质数
                    new_c0 = c0        # 没有更多无质数路径
                    c0, c1 = new_c0, new_c1
                else:
                    # node 不是质数：一侧有 1 个质数 + 另一侧有 0 个，或两侧都有 1 个
                    ans += c0 * nc1 + c1 * nc0
                    # 更新
                    new_c0 = c0 + nc0
                    new_c1 = c1 + nc1
                    c0, c1 = new_c0, new_c1

            return c0, c1

        dfs(1, -1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，DFS + 埃氏筛 O(n log log n)
- 空间复杂度：O(n)，图和辅助数组

## 关键点总结

1. 树形 DP：维护每个节点出发的 0 质数和 1 质数路径数
2. 合并时根据 node 是否为质数分情况讨论
3. 埃氏筛预处理质数

## 易错点

1. 路径不能只有单个节点（需要两个不同节点）
2. 合并时需要先统计答案，再更新 c0/c1
3. 根节点初始化：是质数则 c1=1, c0=0；否则 c0=1, c1=0
