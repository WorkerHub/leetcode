## 题目描述

我们可以为二叉树 T 定义一个翻转操作，如下所示：选择任意节点，然后交换它的左子树和右子树。

只要经过一定次数的翻转操作后，能使 X 等于 Y，我们就称二叉树 X 翻转等价于二叉树 Y。

编写一个判断两个二叉树是否翻转等价的函数。这些树由根节点 `root1` 和 `root2` 给出。

**示例 1：**
```
输入：root1 = [1,2,3,4,5,6,null,null,null,7,8], root2 = [1,3,2,null,6,4,5,null,null,null,null,8,7]
输出：true
解释：我们翻转值为 1，3 以及 5 的三个节点。
```

**示例 2：**
```
输入：root1 = [], root2 = []
输出：true
```

**示例 3：**
```
输入：root1 = [], root2 = [1]
输出：false
```

**提示：**
- 每棵树节点数在 `[0, 100]` 范围内
- 每棵树中的每个值都是唯一的、在 `[0, 99]` 范围内的整数

## 解题思路

这道题要求判断两棵二叉树是否翻转等价。翻转等价的定义是：通过交换任意节点的左右子树，能让两棵树完全相同。

**核心思想：**
1. 两棵树翻转等价，当且仅当它们的根节点值相同，且：
   - 左子树与左子树翻转等价，右子树与右子树翻转等价（不翻转）
   - 或者左子树与右子树翻转等价，右子树与左子树翻转等价（翻转）

2. 这是一个典型的递归问题，对于每个节点，我们有两种情况需要检查：
   - 不翻转：`flipEquiv(root1.left, root2.left) && flipEquiv(root1.right, root2.right)`
   - 翻转：`flipEquiv(root1.left, root2.right) && flipEquiv(root1.right, root2.left)`

3. 递归终止条件：
   - 如果两个节点都为空，返回 True
   - 如果只有一个为空，返回 False
   - 如果节点值不相同，返回 False

## Python 代码实现

### 方法一：递归（推荐）⭐

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flipEquiv(self, root1: TreeNode, root2: TreeNode) -> bool:
        """
        判断两棵二叉树是否翻转等价
        
        思路：递归检查每个节点，考虑翻转和不翻转两种情况
        """
        # 递归终止条件
        if not root1 and not root2:
            return True
        if not root1 or not root2:
            return False
        if root1.val != root2.val:
            return False
        
        # 情况1：不翻转，左对左，右对右
        no_flip = self.flipEquiv(root1.left, root2.left) and \
                  self.flipEquiv(root1.right, root2.right)
        
        # 情况2：翻转，左对右，右对左
        flip = self.flipEquiv(root1.left, root2.right) and \
               self.flipEquiv(root1.right, root2.left)
        
        # 只要有一种情况成立即可
        return no_flip or flip
```

### 方法二：递归优化版（简化代码）

```python
class Solution:
    def flipEquiv(self, root1: TreeNode, root2: TreeNode) -> bool:
        """
        简化版递归实现
        """
        # 两个都为空
        if not root1 and not root2:
            return True
        # 只有一个为空，或值不同
        if not root1 or not root2 or root1.val != root2.val:
            return False
        
        # 一行代码判断两种情况
        return (self.flipEquiv(root1.left, root2.left) and 
                self.flipEquiv(root1.right, root2.right)) or \
               (self.flipEquiv(root1.left, root2.right) and 
                self.flipEquiv(root1.right, root2.left))
```

### 方法三：标准化树结构（规范化方法）

```python
class Solution:
    def flipEquiv(self, root1: TreeNode, root2: TreeNode) -> bool:
        """
        通过标准化树的结构来判断
        
        标准化规则：对于每个节点，如果左子节点值大于右子节点值，则交换
        """
        def canonicalize(node):
            """标准化树的结构"""
            if not node:
                return None
            
            # 递归标准化左右子树
            node.left = canonicalize(node.left)
            node.right = canonicalize(node.right)
            
            # 如果左子节点值大于右子节点值，交换它们
            if node.left and node.right:
                if node.left.val > node.right.val:
                    node.left, node.right = node.right, node.left
            
            return node
        
        def is_same_tree(p, q):
            """判断两棵树是否完全相同"""
            if not p and not q:
                return True
            if not p or not q:
                return False
            if p.val != q.val:
                return False
            return is_same_tree(p.left, q.left) and is_same_tree(p.right, q.right)
        
        # 标准化两棵树后比较
        return is_same_tree(canonicalize(root1), canonicalize(root2))
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度**：O(min(N1, N2))，其中 N1 和 N2 分别是两棵树的节点数。在最坏情况下，我们需要访问两棵树的所有节点。
- **空间复杂度**：O(min(H1, H2))，其中 H1 和 H2 分别是两棵树的高度。递归调用栈的深度等于树的高度。

**方法三：**
- **时间复杂度**：O(N1 + N2)，需要遍历两棵树各一次进行标准化，再遍历一次进行比较。
- **空间复杂度**：O(H1 + H2)，递归调用栈的空间。

## 关键点总结

1. **递归思维**：将大问题分解为子问题，每个节点只需考虑两种情况（翻转或不翻转）
2. **终止条件**：空节点、单个空节点、值不同三种情况
3. **逻辑或运算**：两种情况只要有一种成立即可，使用 `or` 连接
4. **对称性**：翻转操作本质上是左右子树的对称比较
5. **树的遍历**：使用深度优先搜索（DFS）递归遍历

## 易错点

1. **空节点判断顺序**：必须先判断两个都为空，再判断只有一个为空，否则会出现 `NoneType` 错误
2. **短路求值**：Python 的 `and` 和 `or` 具有短路特性，要注意判断顺序
3. **递归边界**：容易忘记判断节点值是否相等
4. **逻辑运算符优先级**：`and` 优先级高于 `or`，注意加括号
5. **修改原树**：方法三会修改原树结构，如果不允许修改，需要先复制树
