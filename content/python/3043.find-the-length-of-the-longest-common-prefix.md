## 题目描述

给你两个整数数组 `arr1` 和 `arr2`。

返回 `arr1` 中某个整数的前缀 和 `arr2` 中某个整数的前缀 的最长公共前缀的长度。

**注意：** 一个整数的前缀是从最高位开始的连续数字序列（例如 1234 的前缀有：1、12、123、1234）。

**示例 1：**
```
输入：arr1 = [1,10,100], arr2 = [1000]
输出：3
解释：arr1[2]=100 和 arr2[0]=1000，公共前缀为 "100"，长度 3
```

**示例 2：**
```
输入：arr1 = [1,2,3], arr2 = [4,4,4]
输出：0
```

**提示：**
- `1 <= arr1.length, arr2.length <= 5 * 10^4`
- `1 <= arr1[i], arr2[i] <= 10^8`

## 解题思路

将 `arr1` 中所有整数的所有前缀存入哈希集合，然后枚举 `arr2` 中每个整数的所有前缀，找最长匹配。

等价地：将 `arr1` 所有整数的字符串表示的所有前缀存入集合，然后对 `arr2` 中每个整数，从最长前缀开始检查。

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def longestCommonPrefix(self, arr1: List[int], arr2: List[int]) -> int:
        # 将 arr1 中所有整数的所有前缀存入集合
        prefix_set = set()
        for num in arr1:
            s = str(num)
            for i in range(1, len(s) + 1):
                prefix_set.add(s[:i])

        # 枚举 arr2 中每个整数的所有前缀，找最长匹配
        ans = 0
        for num in arr2:
            s = str(num)
            for i in range(len(s), 0, -1):
                if s[:i] in prefix_set:
                    ans = max(ans, i)
                    break  # 已找到最长，无需继续

        return ans
```

### 方法二：字典树（Trie）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}

class Solution:
    def longestCommonPrefix(self, arr1: List[int], arr2: List[int]) -> int:
        # 构建 arr1 的 Trie
        root = TrieNode()
        for num in arr1:
            node = root
            for c in str(num):
                if c not in node.children:
                    node.children[c] = TrieNode()
                node = node.children[c]

        # 在 Trie 中查找 arr2 中每个数的最长公共前缀
        ans = 0
        for num in arr2:
            node = root
            length = 0
            for c in str(num):
                if c in node.children:
                    length += 1
                    node = node.children[c]
                else:
                    break
            ans = max(ans, length)

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + m) * L)，L 为数字最大位数（约 9）
- 空间复杂度：O(n * L)，存储前缀集合或 Trie

## 关键点总结

1. 枚举所有前缀后放入集合，查询时也枚举前缀
2. Trie 结构更高效（无需存储所有前缀字符串）
3. 整数最多 9 位（10^8），前缀最多 9 个

## 易错点

1. 前缀是从最高位开始的，不是任意子序列
2. 注意整数转字符串后操作
