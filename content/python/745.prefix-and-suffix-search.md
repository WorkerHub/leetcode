## 题目描述

设计一个包含一些单词的特殊词典，并能够通过前缀和后缀来检索单词。

实现 `WordFilter` 类：

- `WordFilter(string[] words)` 使用词典中的单词 `words` 初始化对象。
- `f(string pref, string suff)` 返回词典中具有前缀 `pref` 和后缀 `suff` 的单词的最大下标（下标从 0 开始）。如果不存在这样的单词，返回 `-1`。

**示例：**
```
输入：
["WordFilter", "f"]
[[["apple"]], ["a", "e"]]
输出：
[null, 0]
解释：
WordFilter wordFilter = new WordFilter(["apple"]);
wordFilter.f("a", "e"); // 返回 0，因为下标为 0 的单词：前缀 "a" 和后缀 "e"。
```

**示例 2：**
```
输入：
["WordFilter", "f"]
[[["apple", "banana", "appeal"]], ["ap", "l"]]
输出：
[null, 2]
解释：
下标 0：apple（前缀 "ap"，后缀 "e"）
下标 1：banana（前缀 "b"，后缀 "a"）
下标 2：appeal（前缀 "ap"，后缀 "l"）✓
返回 2
```

**提示：**
- `1 <= words.length <= 10^4`
- `1 <= words[i].length <= 7`
- `1 <= pref.length, suff.length <= 7`
- `words[i]`、`pref` 和 `suff` 仅由小写英文字母组成
- 最多对函数 `f` 执行 `10^4` 次调用

## 解题思路

这道题的核心挑战是如何高效地同时匹配前缀和后缀。

**核心策略：前缀+后缀组合**

对于每个单词，我们可以构造所有可能的 `{后缀}#{前缀}` 组合，然后使用字典树或哈希表存储。

例如，对于单词 `"apple"` (索引 0)：
- 可能的后缀：`"e"`, `"le"`, `"ple"`, `"pple"`, `"apple"`
- 可能的前缀：`"a"`, `"ap"`, `"app"`, `"appl"`, `"apple"`
- 组合方式：`"e#apple"`, `"le#apple"`, `"ple#apple"`, ...

查询时，构造 `{suff}#{pref}`，在哈希表中查找即可。

## Python 代码实现

### 方法一：哈希表 + 前后缀组合（推荐）⭐

```python
from typing import List

class WordFilter:
    def __init__(self, words: List[str]):
        # 存储 {后缀#前缀: 索引} 的映射
        self.map = {}
        
        for index, word in enumerate(words):
            length = len(word)
            
            # 生成所有可能的前缀和后缀组合
            for i in range(length + 1):  # 后缀长度
                for j in range(length + 1):  # 前缀长度
                    # 构造 key: 后缀#前缀
                    suffix = word[i:]
                    prefix = word[:j]
                    key = suffix + '#' + prefix
                    
                    # 存储索引（相同 key 保留最大索引）
                    self.map[key] = index
    
    def f(self, pref: str, suff: str) -> int:
        key = suff + '#' + pref
        return self.map.get(key, -1)
```

### 方法二：字典树 Trie

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.weight = 0  # 存储单词的索引

class WordFilter:
    def __init__(self, words: List[str]):
        self.trie = TrieNode()
        
        for index, word in enumerate(words):
            length = len(word)
            
            # 为每个单词生成所有可能的 {后缀}#{前缀} 组合
            for i in range(length + 1):
                suffix = word[i:]
                for j in range(length + 1):
                    prefix = word[:j]
                    
                    # 插入到 Trie 中
                    key = suffix + '#' + prefix
                    node = self.trie
                    
                    for char in key:
                        if char not in node.children:
                            node.children[char] = TrieNode()
                        node = node.children[char]
                        node.weight = index  # 更新权重为当前索引
    
    def f(self, pref: str, suff: str) -> int:
        key = suff + '#' + pref
        node = self.trie
        
        for char in key:
            if char not in node.children:
                return -1
            node = node.children[char]
        
        return node.weight
```

### 方法三：暴力法（仅供理解）

```python
class WordFilter:
    def __init__(self, words: List[str]):
        self.words = words
    
    def f(self, pref: str, suff: str) -> int:
        # 从后往前遍历，找到第一个匹配的就是最大索引
        for i in range(len(self.words) - 1, -1, -1):
            word = self.words[i]
            if word.startswith(pref) and word.endswith(suff):
                return i
        return -1
```

## 复杂度分析

### 方法一：哈希表
- **初始化时间复杂度**：O(N × L^3)，其中 N 是单词数量，L 是单词最大长度
  - 对每个单词生成 O(L^2) 个组合
  - 每个组合的字符串长度为 O(L)
- **查询时间复杂度**：O(L)，构造 key 和哈希查找
- **空间复杂度**：O(N × L^3)

### 方法二：字典树
- **初始化时间复杂度**：O(N × L^3)
- **查询时间复杂度**：O(L)
- **空间复杂度**：O(N × L^3)

### 方法三：暴力法
- **初始化时间复杂度**：O(1)
- **查询时间复杂度**：O(N × L)
- **空间复杂度**：O(1)

## 关键点总结

1. **组合键的构造**：使用 `{后缀}#{前缀}` 作为唯一标识，`#` 用于分隔避免冲突
2. **保留最大索引**：相同组合保留最大的索引（通过遍历顺序自然实现）
3. **预处理优化**：在构造函数中预处理所有可能的组合，查询时 O(1) 或 O(L)
4. **空间换时间**：通过存储大量组合，换取快速查询

## 易错点

1. **分隔符选择**：必须使用 `#` 等特殊字符分隔前后缀，否则会有歧义
   - 例如：`"ab" + "cd"` 和 `"abc" + "d"` 都会变成 `"abcd"`
2. **索引覆盖**：相同组合应该保留较大的索引，所以从前往后遍历时自动覆盖
3. **空字符串处理**：需要考虑前缀或后缀为空的情况
4. **字符串拼接效率**：Python 中字符串拼接开销较大，但由于 L 较小（<= 7），影响不大
