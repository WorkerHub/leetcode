## 题目描述

给你一个整数数组 `nums`（下标从 `0` 开始）和一个整数 `k`。

一个子数组 `(i, j)` 的分数定义为 `min(nums[i], ..., nums[j]) * (j - i + 1)`。

**好子数组**的下标满足 `i <= k <= j`。

请你返回**好子数组**的最大分数。

**示例 1：**
```
输入：nums = [1,4,3,7,4,5], k = 3
输出：15
解释：好子数组是 (1, 5)，最小值为 3，长度为 5，得分 = 3 * 5 = 15
```

**示例 2：**
```
输入：nums = [5,5,4,5,4,1,1,1], k = 0
输出：20
解释：好子数组是 (0, 0)，得分为 5；或 (0, 1)，得分为 10 等。最大为 20
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 2 * 10^4`
- `0 <= k < nums.length`

## 解题思路

**双指针贪心：** 从位置 `k` 出发，初始化 `l = r = k`，`min_val = nums[k]`。每次向左或向右扩展一步，选择能保持较大最小值的方向扩展。

- 若 `l > 0` 且 `r < n-1`：比较 `nums[l-1]` 和 `nums[r+1]`，选较大的方向扩展
- 若只能向一侧扩展：扩展剩余的那侧
- 每次更新 `min_val = min(min_val, 新加入的元素)`
- 计算当前得分并更新最大值

另一种方法：使用单调栈求每个位置作为最小值时的最大区间。

## 代码实现

### 方法一：双指针贪心（推荐）

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        l, r = k, k
        min_val = nums[k]
        ans = nums[k]

        while l > 0 or r < n - 1:
            # 向使最小值更大的方向扩展
            if l == 0:
                r += 1
            elif r == n - 1:
                l -= 1
            elif nums[l - 1] >= nums[r + 1]:
                l -= 1
            else:
                r += 1

            # 更新最小值
            min_val = min(min_val, nums[l], nums[r])
            ans = max(ans, min_val * (r - l + 1))

        return ans
```

### 方法二：单调栈

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 求每个位置向左第一个比它小的位置
        left = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)

        # 求每个位置向右第一个比它小的位置
        right = [n] * n
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)

        ans = 0
        for i in range(n):
            # 以 nums[i] 为最小值的最大区间是 (left[i]+1, right[i]-1)
            l = left[i] + 1
            r = right[i] - 1
            # 必须包含下标 k
            if l <= k <= r:
                ans = max(ans, nums[i] * (r - l + 1))

        return ans
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：O(n)，双指针各移动最多 n 次
- 空间复杂度：O(1)

**方法二（单调栈）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，存储栈和 left/right 数组

## 关键点总结

1. 子数组必须包含下标 k（好子数组的定义）
2. 双指针从 k 出发向两侧扩展，贪心选择保留较大最小值的方向
3. 单调栈求每个元素作为最小值时的覆盖范围，再筛选覆盖 k 的情况
4. 两种方法时间复杂度均为 O(n)

## 易错点

1. 双指针中扩展方向的比较：选 `nums[l-1]` 和 `nums[r+1]` 较大的方向
2. 单调栈中 `left[i]` 是严格小于的位置，注意边界 `-1` 和 `n`
3. 初始分数为 `nums[k]`（区间只有 k 时）
