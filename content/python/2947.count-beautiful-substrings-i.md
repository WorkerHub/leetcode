## 题目描述

给你一个字符串 `s` 和一个正整数 `k`。

设元音字母为 `a, e, i, o, u`。若一个子字符串满足以下条件，则称它为 **美丽子字符串**：
- 元音个数和辅音个数相等
- 元音个数 * 辅音个数可以被 `k` 整除

返回字符串 `s` 中美丽子字符串的数目。

**示例 1：**
```
输入：s = "baeyh", k = 2
输出：2
```

**示例 2：**
```
输入：s = "abba", k = 1
输出：3
```

**提示：**
- `1 <= s.length <= 1000`
- `1 <= k <= 1000`

## 解题思路

枚举所有子字符串，检查两个条件：
1. 元音数 = 辅音数 = len/2（子串长度必须为偶数）
2. (len/2) * (len/2) 能被 k 整除

n <= 1000，O(n^2) 枚举可行。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(s)
        ans = 0

        for l in range(n):
            v_count = 0  # 元音个数
            for r in range(l, n):
                if s[r] in vowels:
                    v_count += 1
                length = r - l + 1
                c_count = length - v_count  # 辅音个数
                if v_count == c_count and v_count * c_count % k == 0:
                    ans += 1

        return ans
```

### 方法二：前缀和优化（稍微快一些）

```python
class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(s)
        # prefix[i] = s[0..i-1] 中元音的个数
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if s[i] in vowels else 0)

        ans = 0
        for l in range(n):
            for r in range(l, n):
                length = r - l + 1
                v = prefix[r + 1] - prefix[l]
                c = length - v
                if v == c and v * c % k == 0:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子字符串
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 元音数 = 辅音数意味着子串长度为偶数，设长度为 2m，则元音数 = 辅音数 = m
2. 条件 2 变为 m*m 能被 k 整除（即 m^2 % k == 0）
3. n<=1000 时 O(n^2) 完全够用

## 易错点

1. 元音和辅音的乘积 = v * c = m * m = m^2，不要计算错
2. 必须先满足 v == c 才能满足条件 2
3. 子串长度奇数时 v != c，直接跳过
