## 题目描述

外国友人仿照中国字谜设计了一个英文版猜字谜小游戏，请你来猜猜看吧。

字谜的迷面 puzzle 按字符串形式给出，如果一个单词 word 符合下面两个条件，那么它就可以算作谜底：

1. 单词 word 中包含谜面 puzzle 的第一个字母。
2. 单词 word 中的每一个字母都可以在谜面 puzzle 中找到。
   - 例如，如果字谜的谜面是 "abcdefg"，那么可以作为谜底的单词有 "faced", "cabbage", 和 "baggage"；而 "beefed"（不含字母 "a"）以及 "based"（其中的 "s" 没有出现在谜面中）都不能作为谜底。

返回一个答案数组 answer，数组中的每个元素 answer[i] 是在给出的单词列表 words 中可以作为字谜迷面 puzzles[i] 所对应的谜底的单词数目。

**示例 1:**
```
输入: 
words = ["aaaa","asas","able","ability","actt","actor","access"], 
puzzles = ["aboveyz","abrodyz","abslute","absoryz","actresz","gaswxyz"]
输出: [1,1,3,2,4,0]
解释:
1 个单词可以作为 "aboveyz" 的谜底 : "aaaa" 
1 个单词可以作为 "abrodyz" 的谜底 : "aaaa"
3 个单词可以作为 "abslute" 的谜底 : "aaaa", "asas", "able"
2 个单词可以作为 "absoryz" 的谜底 : "aaaa", "asas"
4 个单词可以作为 "actresz" 的谜底 : "aaaa", "asas", "actt", "access"
没有单词可以作为 "gaswxyz" 的谜底，因为列表中的单词都不含字母 'g'。
```

**示例 2:**
```
输入: words = ["apple","pleas","please"], puzzles = ["aelwxyz","aelpxyz","aelpsxy","saelpxy","xaelpsy"]
输出: [0,1,3,2,0]
```

**提示:**
- 1 <= words.length <= 10^5
- 4 <= words[i].length <= 50
- 1 <= puzzles.length <= 10^4
- puzzles[i].length == 7
- words[i] 和 puzzles[i] 只包含小写英文字母
- 每个 puzzles[i] 所包含的字符都不重复

## 解题思路

这是一道困难的位运算 + 哈希表优化问题。核心思想是：**用二进制状态表示字符集合，通过枚举子集和哈希表快速统计匹配单词数**。

### 核心观察

1. **字符集合表示**：每个单词和谜面都可以用一个 26 位的二进制数表示其包含的字符
2. **匹配条件**：
   - word 的字符集是 puzzle 字符集的子集
   - word 必须包含 puzzle 的第一个字母
3. **优化关键**：puzzle 长度固定为 7，最多有 2^7 = 128 个子集

### 暴力解法的问题

直接枚举每个 word 和 puzzle 的组合，时间复杂度 O(words.length × puzzles.length × 平均长度)，会超时。

### 优化思路

1. **预处理 words**：将每个 word 转换为字符集合的位表示，用哈希表统计每种字符集合出现的次数
2. **枚举 puzzle 的子集**：对于每个 puzzle，枚举所有包含第一个字母的子集
3. **查询匹配数**：在哈希表中查询该子集对应的 word 数量

### 子集枚举技巧

对于一个集合 S，如何枚举所有子集？
```python
subset = S
while subset:
    # 处理 subset
    subset = (subset - 1) & S  # 下一个子集
```

## Python 代码实现

### 方法一：位运算 + 子集枚举（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findNumOfValidWords(self, words: List[str], puzzles: List[str]) -> List[int]:
        def word_to_bitmask(word: str) -> int:
            """将单词转换为字符集合的位表示"""
            mask = 0
            for char in word:
                mask |= (1 << (ord(char) - ord('a')))
            return mask
        
        # 预处理：统计每种字符集合的单词数量
        word_count = Counter(word_to_bitmask(word) for word in words)
        
        result = []
        
        for puzzle in puzzles:
            # puzzle 的字符集合
            puzzle_mask = word_to_bitmask(puzzle)
            # puzzle 的第一个字母
            first_char_bit = 1 << (ord(puzzle[0]) - ord('a'))
            
            count = 0
            # 枚举 puzzle 的所有子集
            subset = puzzle_mask
            while subset:
                # 如果子集包含第一个字母，统计对应的单词数
                if subset & first_char_bit:
                    count += word_count[subset]
                # 下一个子集
                subset = (subset - 1) & puzzle_mask
            
            result.append(count)
        
        return result
```

### 方法二：优化的子集枚举

```python
from typing import List
from collections import Counter

class Solution:
    def findNumOfValidWords(self, words: List[str], puzzles: List[str]) -> List[int]:
        # 将单词转换为位掩码并统计
        word_count = Counter()
        for word in words:
            mask = 0
            for char in word:
                mask |= (1 << (ord(char) - ord('a')))
            word_count[mask] += 1
        
        result = []
        
        for puzzle in puzzles:
            # 计算 puzzle 的掩码（去除第一个字母）
            first_char = puzzle[0]
            first_bit = 1 << (ord(first_char) - ord('a'))
            
            # 其余字符的掩码
            rest_mask = 0
            for char in puzzle[1:]:
                rest_mask |= (1 << (ord(char) - ord('a')))
            
            count = 0
            # 枚举其余字符的所有子集
            subset = rest_mask
            while True:
                # 加上第一个字母，形成完整的子集
                full_subset = subset | first_bit
                count += word_count[full_subset]
                
                if subset == 0:
                    break
                subset = (subset - 1) & rest_mask
            
            result.append(count)
        
        return result
```

### 方法三：使用字典优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def findNumOfValidWords(self, words: List[str], puzzles: List[str]) -> List[int]:
        # 只统计字符种类不超过 7 的单词（因为 puzzle 只有 7 个不同字符）
        word_count = defaultdict(int)
        
        for word in words:
            # 获取 word 的字符集合
            chars = set(word)
            if len(chars) <= 7:  # 优化：超过 7 种字符的单词不可能是任何 puzzle 的子集
                mask = 0
                for char in chars:
                    mask |= (1 << (ord(char) - ord('a')))
                word_count[mask] += 1
        
        result = []
        
        for puzzle in puzzles:
            first_bit = 1 << (ord(puzzle[0]) - ord('a'))
            puzzle_mask = 0
            for char in puzzle:
                puzzle_mask |= (1 << (ord(char) - ord('a')))
            
            count = 0
            subset = puzzle_mask
            
            while subset:
                if subset & first_bit:
                    count += word_count[subset]
                subset = (subset - 1) & puzzle_mask
            
            result.append(count)
        
        return result
```

### 方法四：递归枚举子集

```python
from typing import List
from collections import Counter

class Solution:
    def findNumOfValidWords(self, words: List[str], puzzles: List[str]) -> List[int]:
        word_count = Counter()
        
        for word in words:
            mask = 0
            for char in set(word):  # 使用 set 去重
                mask |= (1 << (ord(char) - ord('a')))
            word_count[mask] += 1
        
        def count_subsets(puzzle: str) -> int:
            """计算包含第一个字母的子集对应的单词数"""
            first_bit = 1 << (ord(puzzle[0]) - ord('a'))
            puzzle_mask = 0
            for char in puzzle:
                puzzle_mask |= (1 << (ord(char) - ord('a')))
            
            count = 0
            subset = puzzle_mask
            
            while subset:
                if subset & first_bit:
                    count += word_count.get(subset, 0)
                subset = (subset - 1) & puzzle_mask
            
            return count
        
        return [count_subsets(puzzle) for puzzle in puzzles]
```

## 复杂度分析

### 方法一、二、三：位运算 + 子集枚举
- **时间复杂度**：O(W × L_w + P × 2^7)，其中 W 是 words 的数量，L_w 是 word 的平均长度，P 是 puzzles 的数量。预处理 words 需要 O(W × L_w)，每个 puzzle 枚举子集需要 O(2^7) = O(128)
- **空间复杂度**：O(W)，哈希表存储 words 的字符集合

### 暴力解法（会超时）
- **时间复杂度**：O(W × P × (L_w + L_p))
- **空间复杂度**：O(1)

## 关键点总结

1. **位运算表示集合**：用二进制位表示字符集合，高效且节省空间
2. **子集枚举技巧**：`subset = (subset - 1) & S` 是枚举子集的标准方法
3. **哈希表预处理**：将 words 预处理成哈希表，避免重复计算
4. **优化剪枝**：只统计字符种类不超过 7 的单词，减少哈希表大小
5. **第一个字母约束**：只枚举包含第一个字母的子集

## 易错点

1. **子集枚举死循环**：忘记处理 subset = 0 的情况，导致死循环
2. **字符去重**：word 可能有重复字符，要先去重再计算位掩码
3. **第一个字母判断**：容易忘记检查子集是否包含 puzzle 的第一个字母
4. **位运算优先级**：`&` 和 `|` 的优先级低于比较运算符，要加括号
5. **溢出问题**：虽然只有 26 个字母，但要确保使用 32 位或 64 位整数

### 子集枚举原理

对于集合 S = 1011（二进制），如何枚举所有子集？

```
1011 (S)
1010
1001
1000
0011
0010
0001
0000

规律：subset = (subset - 1) & S
- 1011 - 1 = 1010, 1010 & 1011 = 1010
- 1010 - 1 = 1001, 1001 & 1011 = 1001
- 1001 - 1 = 1000, 1000 & 1011 = 1000
- 1000 - 1 = 0111, 0111 & 1011 = 0011
- ...
```

这个技巧保证了每次得到的都是 S 的子集，且不会重复。
