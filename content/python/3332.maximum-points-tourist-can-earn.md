## 题目描述

给你两个整数 `n`（景点数）和 `k`（天数），以及：
- 数组 `stayScore[i][j]`：在第 `j` 天**继续停留**在景点 `i` 的得分。
- 数组 `travelScore[i][j]`：从景点 `i` **移动**到景点 `j` 的得分。

游客 k 天内每天必须在某个景点，可以选择继续停留（得 `stayScore[day][city]`）或移动到其他城市（得 `travelScore[from][to]`）。第 0 天可以在任意城市（无额外得分）。

返回 k 天后的最大得分。

**提示：**
- `1 <= n <= 200`
- `1 <= k <= 200`
- `stayScore.length == k`，`stayScore[i].length == n`
- `travelScore.length == n`，`travelScore[i].length == n`
- `travelScore[i][i] == 0`

## 解题思路

**动态规划：**

`dp[day][city]` = 经过 `day` 天（0 索引），游客在城市 `city` 时的最大得分。

初始状态：第 0 天（未开始），`dp[0][city] = 0` 对所有城市（可以从任意城市开始）。

转移（第 d 天，`d >= 1`）：
- 从城市 `j` 继续停留（第 d-1 天也在 j）：`dp[d][j] = dp[d-1][j] + stayScore[d-1][j]`
- 从城市 `j` 移动到城市 `i`（`i != j`）：`dp[d][i] = max(dp[d-1][j] + travelScore[j][i])`

答案：`max(dp[k][city])` for all cities。

**注意：** 这里的"天"的定义需要仔细对应题目。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, n: int, k: int, stayScore: List[List[int]], travelScore: List[List[int]]) -> int:
        # dp[city] = 当前天在该城市的最大得分
        # 第 0 天：可以在任意城市，得分为 0
        NEG_INF = float('-inf')
        dp = [0] * n  # 初始，第 0 天
        
        for day in range(k):
            new_dp = [NEG_INF] * n
            for city in range(n):
                if dp[city] == NEG_INF:
                    continue
                # 选择1：继续停留在 city
                new_dp[city] = max(new_dp[city], dp[city] + stayScore[day][city])
                # 选择2：移动到其他城市
                for dest in range(n):
                    if dest != city:
                        new_dp[dest] = max(new_dp[dest], dp[city] + travelScore[city][dest])
            dp = new_dp
        
        return max(dp)
```

### 方法二：空间优化

```python
from typing import List

class Solution:
    def maxScore(self, n: int, k: int, stayScore: List[List[int]], travelScore: List[List[int]]) -> int:
        dp = [0] * n
        
        for day in range(k):
            # 每天的转移
            # 停留：dp_stay[city] = dp[city] + stayScore[day][city]
            # 移动：dp_move[dest] = max over all src: dp[src] + travelScore[src][dest]
            
            # 先计算移动后的得分
            new_dp = [max(dp[src] + travelScore[src][dest] for src in range(n) if src != dest)
                      if n > 1 else float('-inf')
                      for dest in range(n)]
            
            # 再考虑停留（取最大值）
            for city in range(n):
                stay = dp[city] + stayScore[day][city]
                new_dp[city] = max(new_dp[city], stay)
            
            dp = new_dp
        
        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(k * n^2)，每天遍历所有城市对
- 空间复杂度：O(n)，一维 DP 数组

## 关键点总结

1. DP 状态：每天结束时，每个城市的最大得分。
2. 每天有两种操作：继续停留（加 stayScore）或移动（加 travelScore）。
3. 移动的目标城市可以是任意城市（包括原地移动，但 `travelScore[i][i] = 0`）。

## 易错点

1. 第 0 天游客可以在任意城市且不得分，所以 `dp` 初始全为 0。
2. `stayScore` 的下标对应：`stayScore[day][city]`，天数从 0 开始。
3. 注意移动时不能移动到自身城市（或者说 `travelScore[i][i] = 0`，效果与停留不同）。
