## 题目描述

给定一个整数数组 `arr`，如果它是有效的山脉数组就返回 `true`，否则返回 `false`。

山脉数组需要满足以下条件：
- `arr.length >= 3`
- 存在某个下标 `i`（`0 < i < arr.length - 1`）使得：
  - `arr[0] < arr[1] < ... < arr[i - 1] < arr[i]`
  - `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]`

**示例 1：**
```
输入：arr = [2,1]
输出：false
```

**示例 2：**
```
输入：arr = [3,5,5]
输出：false
```

**示例 3：**
```
输入：arr = [0,3,2,1]
输出：true
```

**提示：**
- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 10^4`

## 解题思路

这道题要求判断数组是否形成一个山脉形状，即先严格递增后严格递减。

**核心思想：**
1. 山脉必须有上坡和下坡两个部分
2. 山峰不能在数组的起点或终点
3. 相邻元素不能相等（严格递增/递减）

**算法流程：**
1. 先从左往右找到山峰（严格递增的终点）
2. 再从山峰往右检查是否严格递减
3. 检查山峰位置是否合法（不在两端）

**关键观察：**
- 如果爬坡在第一个位置就停止，说明没有上坡部分
- 如果爬坡后没有到达最后，还需要检查是否能一直下坡到结尾
- 任何相等的相邻元素都会导致失败

## Python 代码实现

### 方法一：双指针法（推荐）

```python
class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        n = len(arr)
        
        # 长度至少为 3
        if n < 3:
            return False
        
        # 第一阶段：从左往右找山峰（严格递增）
        i = 0
        while i + 1 < n and arr[i] < arr[i + 1]:
            i += 1
        
        # 山峰不能在起点或终点
        if i == 0 or i == n - 1:
            return False
        
        # 第二阶段：从山峰往右检查（严格递减）
        while i + 1 < n and arr[i] > arr[i + 1]:
            i += 1
        
        # 如果能遍历到最后，说明是有效的山脉数组
        return i == n - 1
```

### 方法二：双向爬坡法

```python
class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False
        
        # 从左边爬坡
        left = 0
        while left + 1 < n and arr[left] < arr[left + 1]:
            left += 1
        
        # 从右边爬坡
        right = n - 1
        while right > 0 and arr[right - 1] > arr[right]:
            right -= 1
        
        # 两边爬坡必须在同一个山峰相遇，且不能在两端
        return left == right and left > 0 and right < n - 1
```

### 方法三：一次遍历标记法

```python
class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False
        
        # 标记是否进入下坡阶段
        is_descending = False
        
        for i in range(n - 1):
            if arr[i] == arr[i + 1]:
                # 相等元素，不符合严格递增/递减
                return False
            
            if arr[i] > arr[i + 1]:
                # 开始下坡
                if i == 0:
                    # 第一个元素就开始下坡，无效
                    return False
                is_descending = True
            else:
                # 还在上坡
                if is_descending:
                    # 下坡后又上坡，无效
                    return False
        
        # 必须经历过下坡阶段
        return is_descending
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是数组长度，最多遍历一到两次数组
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. **长度检查**：山脉数组至少需要 3 个元素（上坡、山峰、下坡）
2. **山峰位置**：山峰不能在数组的起点或终点
3. **严格单调**：必须是严格递增后严格递减，不能有相等的相邻元素
4. **完整性**：必须有上坡和下坡两个阶段，缺一不可
5. **双指针技巧**：可以从两端向中间爬坡，最后检查是否在同一个山峰相遇

## 易错点

1. **忘记检查长度**：数组长度小于 3 时直接返回 false
2. **山峰在边界**：`[1,2,3]` 或 `[3,2,1]` 都不是有效山脉，山峰在边界
3. **相等元素**：`[1,2,2,3,2]` 不是有效山脉，相邻元素不能相等
4. **只有上坡或下坡**：必须同时有上坡和下坡两个阶段
5. **下坡后再上坡**：`[1,3,2,4]` 不是有效山脉，不能有多个山峰
