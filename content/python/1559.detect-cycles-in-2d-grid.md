## 题目描述

给你一个二维字符网格 `grid`，如果 `grid` 中存在**相同值形成的环**（长度至少为 4 的路径，起点终点相同，不能直接走回头路），则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：grid = [["a","a","a","a"],["a","b","b","a"],["a","b","b","a"],["a","a","a","a"]]
输出：true
```

## 解题思路

### 方法一：DFS 检测环

从每个未访问的格子出发做 DFS，记录上一步来自哪个格子（避免立即回头），若访问到已访问的同值格子则说明有环。

### 方法二：并查集

遍历每个格子，对与其**右边**和**下面**相同值的格子做 union。若两格已在同一集合中（即已联通），说明有环。

## 代码实现

### 方法一：DFS（推荐）

```python
from typing import List

class Solution:
    def containsCycle(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        visited = [[False] * n for _ in range(m)]
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        def dfs(r: int, c: int, pr: int, pc: int, val: str) -> bool:
            visited[r][c] = True
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == val:
                    if nr == pr and nc == pc:
                        continue  # 不走回头路
                    if visited[nr][nc]:
                        return True  # 找到环
                    if dfs(nr, nc, r, c, val):
                        return True
            return False

        for i in range(m):
            for j in range(n):
                if not visited[i][j]:
                    if dfs(i, j, -1, -1, grid[i][j]):
                        return True
        return False
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def containsCycle(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        parent = list(range(m * n))
        rank = [0] * (m * n)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return False  # 已在同一集合，有环
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1
            return True

        for i in range(m):
            for j in range(n):
                # 只看右边和下面，避免重复处理
                for di, dj in [(0, 1), (1, 0)]:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == grid[i][j]:
                        if not union(i * n + j, ni * n + nj):
                            return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS | O(M * N) | O(M * N) |
| 并查集 | O(M * N * α) | O(M * N) |

## 关键点总结

1. DFS 中通过记录父节点避免走回头路，若访问到已访问节点则有环
2. 并查集：若两个相邻同值格子已在同一集合，则有环
3. 环的最小长度为 4（不算对角线）

## 易错点

- DFS 中必须记录"上一步"以避免立即回头（不然两步就会误判为环）
- 并查集遍历时只处理右边和下面，避免重复 union
