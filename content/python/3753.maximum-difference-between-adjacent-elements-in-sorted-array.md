## 题目描述

给定一个整数数组 `nums`，将其排序后，求相邻元素之间差值的最大值。

**示例 1：**
```
输入：nums = [9,6,3,1,4,2,8]
输出：3
解释：排序后：[1,2,3,4,6,8,9]，相邻差值：1,1,1,2,2,1，最大差值为 3（8 和 9 之间？不对，是 4 和 6 之间差 2，6 和 8 之间差 2）。
     排序后最大相邻差值为 2。
```

**示例 2：**
```
输入：nums = [1,10,1,10]
输出：9
解释：排序后：[1,1,10,10]，最大相邻差值为 9（1 到 10）。
```

**提示：**
- `2 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

排序后，相邻元素之差的最大值即为所求。

也可以用桶排序（类似 LeetCode 164 Maximum Gap），达到 O(n) 时间复杂度。

## Python 代码实现

### 方法一：排序（推荐）

```python
from typing import List

class Solution:
    def maxGap(self, nums: List[int]) -> int:
        nums.sort()
        max_diff = 0
        for i in range(1, len(nums)):
            max_diff = max(max_diff, nums[i] - nums[i-1])
        return max_diff
```

### 方法二：桶排序（O(n) 时间）

```python
from typing import List

class Solution:
    def maxGap(self, nums: List[int]) -> int:
        n = len(nums)
        if n < 2:
            return 0

        min_val, max_val = min(nums), max(nums)
        if min_val == max_val:
            return 0

        # 桶大小：上取整
        bucket_size = max(1, (max_val - min_val) // (n - 1))
        num_buckets = (max_val - min_val) // bucket_size + 1

        buckets = [[float('inf'), float('-inf')] for _ in range(num_buckets)]
        for x in nums:
            idx = (x - min_val) // bucket_size
            buckets[idx][0] = min(buckets[idx][0], x)
            buckets[idx][1] = max(buckets[idx][1], x)

        max_gap = 0
        prev_max = min_val
        for lo, hi in buckets:
            if lo == float('inf'):
                continue
            max_gap = max(max_gap, lo - prev_max)
            prev_max = hi

        return max_gap
```

## 复杂度分析

- 时间复杂度：方法一 O(n log n)；方法二 O(n)
- 空间复杂度：方法一 O(1)；方法二 O(n)

## 关键点总结

1. 最大相邻差值一定在排序后的相邻元素之间取得
2. 桶排序利用鸽巢原理：最大间距必然来自不同桶的边界

## 易错点

1. 注意是"排序后的相邻差值"，不是原始数组
2. 所有元素相同时最大差值为 0
