## 题目描述

给你一个整数 `n`，如果你可以将 `n` 表示成若干个**不同**的三的幂之和，请你返回 `true`，否则返回 `false`。

对于一个整数 `y`，如果存在整数 `x` 满足 `y == 3^x`，那么 `y` 就是三的幂。

**示例 1：**
```
输入：n = 12
输出：true
解释：12 = 3^1 + 3^2 = 3 + 9
```

**示例 2：**
```
输入：n = 91
输出：true
解释：91 = 3^0 + 3^2 + 3^4 = 1 + 9 + 81
```

**提示：**
- `1 <= n <= 10^7`

## 解题思路

将 `n` 转换为三进制。若三进制表示中每一位都是 0 或 1（没有 2），则可以表示为若干不同的三的幂之和。

## 代码实现

### 方法一：三进制转换（推荐）

```python
class Solution:
    def checkPowersOfThree(self, n: int) -> bool:
        while n > 0:
            if n % 3 == 2:
                return False  # 三进制某位为 2，需要两个相同的幂
            n //= 3
        return True
```

### 方法二：贪心减法

```python
class Solution:
    def checkPowersOfThree(self, n: int) -> bool:
        # 找最大的 3^k <= n，贪心减去
        # 由于三的幂不重复，等价于三进制方法
        power = 1
        while power * 3 <= n:
            power *= 3
        
        while n > 0:
            if n >= power:
                n -= power
            power //= 3
        
        return n == 0
```

## 复杂度分析

- **时间复杂度**：O(log_3(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 三进制表示中，每位只能是 0 或 1（不能是 2）才满足条件
2. 类比于二进制表示中，每位代表一个不同的 2 的幂

## 易错点

- `n % 3 == 2` 说明需要两个相同的 3 的幂，不满足"不同"的条件
