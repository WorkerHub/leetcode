## 题目描述

给你一个网格，初始有 `n+2` 行和 `m+2` 列，在行 0、n+1 和列 0、m+1 之间有条纹（边界固定）。另有 `n` 条横向条纹和 `m` 条纵向条纹，分别位于行 `hBars[i]` 和列 `vBars[i]`。

每次操作可以移除 `hBars` 或 `vBars` 中的一条条纹（内部条纹，不含边界）。

返回移除若干条纹后，能形成的最大正方形洞的面积。

**示例 1：**
```
输入：n = 2, m = 1, hBars = [2,3], vBars = [2]
输出：4
```

**示例 2：**
```
输入：n = 1, m = 1, hBars = [2], vBars = [2]
输出：4
```

**提示：**
- `1 <= n <= 1000`
- `1 <= m <= 1000`
- `1 <= hBars.length <= n`
- `2 <= hBars[i] <= n+1`
- `1 <= vBars.length <= m`
- `2 <= vBars[i] <= m+1`
- hBars 和 vBars 中元素各自不重复

## 解题思路

移除连续相邻的条纹可以扩大空洞。

对 hBars 排序，找最长连续段的长度 `max_h`（连续相邻整数的个数）。正方形洞在高度方向的边长为 `max_h + 1`。

对 vBars 类似，得 `max_v`。

正方形边长 = `min(max_h, max_v) + 1`，面积 = 边长^2。

## Python 代码实现

### 方法一：排序找最长连续段（推荐）

```python
from typing import List

class Solution:
    def maximizeSquareHoleArea(self, n: int, m: int, hBars: List[int], vBars: List[int]) -> int:
        def max_consecutive(bars: List[int]) -> int:
            bars.sort()
            max_len = 1
            cur_len = 1
            for i in range(1, len(bars)):
                if bars[i] == bars[i - 1] + 1:
                    cur_len += 1
                    max_len = max(max_len, cur_len)
                else:
                    cur_len = 1
            return max_len

        max_h = max_consecutive(hBars)
        max_v = max_consecutive(vBars)
        side = min(max_h, max_v) + 1
        return side * side
```

### 方法二：集合差分法

```python
from typing import List

class Solution:
    def maximizeSquareHoleArea(self, n: int, m: int, hBars: List[int], vBars: List[int]) -> int:
        def max_run(bars):
            s = sorted(bars)
            best = cur = 1
            for i in range(1, len(s)):
                if s[i] == s[i-1] + 1:
                    cur += 1
                    best = max(best, cur)
                else:
                    cur = 1
            return best

        h = max_run(hBars) + 1
        v = max_run(vBars) + 1
        s = min(h, v)
        return s * s
```

## 复杂度分析

- 时间复杂度：O(h log h + v log v)，排序
- 空间复杂度：O(1)（排序原地）

## 关键点总结

1. 移除连续的行条纹可以扩展高度：移除 k 条连续条纹使高度增加 k
2. 基础洞大小为 1x1（不移除任何条纹时），每移除一条相邻条纹边长 +1
3. 正方形取横纵方向的最小边长

## 易错点

1. 初始洞大小是 1x1（边长为 1），不是 0
2. 移除 k 条连续条纹后，该方向边长为 k+1（基础 1 + k 条）
3. 正方形必须是两个方向边长的最小值
