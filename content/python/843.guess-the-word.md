## 题目描述

这个问题是 **交互式问题**。

你会得到一个由若干 **不同** 字符串组成的列表 `words`，这些字符串的长度都为 `6`，同时还有一个 **主服务器**，它知道其中一个 `secret` 单词。

你可以调用 `master.guess(word)` 来猜单词。你所猜的单词应当是存在于原列表并且由 `6` 个小写字母组成的类型 `string`。

此函数将会返回一个 `integer` ，表示你的猜测与秘密单词的准确匹配（值和位置同时匹配）的数目。此外，如果你的猜测不在给定的单词列表中，它将返回 `-1`。

对于每个测试用例，你有 `10` 次机会来猜出这个单词。当所有调用都结束时，如果您对 `master.guess` 的调用不超过 `10` 次，并且至少有一次猜到秘密单词，那么您将通过该用例。

## Python 代码实现

```python
from typing import List
import random

class Solution:
    def findSecretWord(self, words: List[str], master: 'Master') -> None:
        def match(w1, w2):
            return sum(c1 == c2 for c1, c2 in zip(w1, w2))
        
        for _ in range(10):
            # 随机选择一个单词（或选择minimax策略）
            guess = random.choice(words)
            matches = master.guess(guess)
            
            if matches == 6:
                return
            
            # 过滤：保留与guess有相同匹配数的单词
            words = [w for w in words if match(w, guess) == matches]
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **交互式**：根据反馈调整策略
2. **过滤策略**：每次猜测后缩小候选范围
3. **Minimax**：可以选择期望减少候选最多的单词
