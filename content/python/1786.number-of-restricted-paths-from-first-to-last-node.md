## 题目描述

现有一个加权无向连通图，共有 `n` 个节点，节点按从 `1` 到 `n` 编号，`edges` 数组中第 `i` 个边 `edges[i] = [ui, vi, weighti]` 代表节点 `ui` 和节点 `vi` 之间有一条边，权重为 `weighti`。

从节点 `n` 开始，定义 `distanceToLastNode(x)` 为节点 `x` 到节点 `n` 的**最短路径**的长度，**受限路径**是指满足以下条件的路径：
- 路径上的节点满足：对于路径上相邻的两个节点 `u` 和 `v`（`u` 在 `v` 前面），必须满足 `distanceToLastNode(u) > distanceToLastNode(v)`

返回从节点 `1` 到节点 `n` 的**受限路径数目**，对 `10^9 + 7` 取余。

**提示：**
- `1 <= n <= 2 * 10^4`
- `n - 1 <= edges.length <= 4 * 10^4`

## 解题思路

1. 从节点 `n` 出发，用 Dijkstra 算法计算所有节点到 `n` 的最短距离 `dist[]`
2. 在受限路径上，节点的 `dist` 值单调递减（从 1 到 n）
3. 设 `dp[v]` 为从节点 `v` 到节点 `n` 的受限路径数目
4. `dp[n] = 1`，对于其他节点，`dp[u] = sum(dp[v])` 对所有满足条件的邻居 `v`（`dist[v] < dist[u]`）
5. 按照 `dist` 从小到大的顺序计算 `dp`（从 `n` 开始向外）

## 代码实现

### 方法一：Dijkstra + 记忆化搜索（推荐）

```python
from typing import List
from heapq import heappush, heappop
from collections import defaultdict
from functools import lru_cache

class Solution:
    def countRestrictedPaths(self, n: int, edges: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7

        # 建图
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # Dijkstra 从节点 n 出发求最短距离
        INF = float('inf')
        dist = [INF] * (n + 1)
        dist[n] = 0
        heap = [(0, n)]

        while heap:
            d, u = heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heappush(heap, (dist[v], v))

        # 记忆化搜索：dp[u] 表示从 u 到 n 的受限路径数
        @lru_cache(maxsize=None)
        def dp(u):
            if u == n:
                return 1
            result = 0
            for v, w in graph[u]:
                # 受限路径要求 dist[u] > dist[v]
                if dist[u] > dist[v]:
                    result = (result + dp(v)) % MOD
            return result

        return dp(1)
```

### 方法二：Dijkstra + 拓扑排序 DP

```python
from typing import List
from heapq import heappush, heappop
from collections import defaultdict

class Solution:
    def countRestrictedPaths(self, n: int, edges: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7

        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # Dijkstra 求各点到 n 的最短距离
        INF = float('inf')
        dist = [INF] * (n + 1)
        dist[n] = 0
        heap = [(0, n)]

        while heap:
            d, u = heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heappush(heap, (dist[v], v))

        # 按 dist 升序排序所有节点，从 n（dist最小=0）向外计算
        order = sorted(range(1, n + 1), key=lambda x: dist[x])
        dp = [0] * (n + 1)
        dp[n] = 1

        for u in order:
            for v, w in graph[u]:
                # 从 u 到 n：若 dist[u] < dist[v]，则 v 可以经 u 到达 n
                if dist[u] < dist[v]:
                    dp[v] = (dp[v] + dp[u]) % MOD

        return dp[1]
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)，Dijkstra 的时间复杂度
- **空间复杂度**：O(V + E)，图的邻接表和 dist 数组

## 关键点总结

1. 先用 Dijkstra（以 n 为源点）求所有节点到 n 的最短距离
2. 受限路径等价于：按 `dist` 递减方向前进（从 1 到 n，dist 不断减小）
3. DP 的计算顺序：按 `dist` 从小到大（从 n 向外），或用记忆化搜索
4. `dp[n] = 1` 作为基准，向外传播路径数

## 易错点

1. Dijkstra 的源点是节点 `n`，不是节点 `1`
2. 受限路径条件是严格大于：`dist[u] > dist[v]`，不是 >=
3. 拓扑排序方向：按 dist 升序排列，从 n（dist=0）开始向外传播
