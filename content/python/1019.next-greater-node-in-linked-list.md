## 题目描述

给定一个长度为 `n` 的链表 `head`。

对于列表中的每个节点，查找下一个更大节点的值。也就是说，对于每个节点，找到它旁边的第一个节点的值，这个值严格大于它的值。

返回一个整数数组 `answer`，其中 `answer[i]` 是第 `i` 个节点（从1开始）的下一个更大的节点的值。如果第 `i` 个节点没有下一个更大的节点，则设 `answer[i] = 0`。

**示例 1：**
```
输入：head = [2,1,5]
输出：[5,5,0]
```

**示例 2：**
```
输入：head = [2,7,4,3,5]
输出：[7,0,5,5,0]
```

**提示：**
- 链表中节点数为 `n`
- `1 <= n <= 10^4`
- `1 <= Node.val <= 10^9`

## 解题思路

这是经典的"下一个更大元素"问题在链表上的应用。

**核心思想**：使用单调栈
1. 单调栈维护递减序列
2. 当遇到更大的元素时，弹出栈中较小的元素
3. 被弹出的元素找到了它们的下一个更大元素

**两种方法**：
1. 链表转数组 + 单调栈
2. 反向遍历（需要先遍历获取长度）

## Python 代码实现

### 方法一：链表转数组 + 单调栈（推荐）⭐

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

from typing import Optional, List

class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        """
        先转为数组，再用单调栈处理
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 1. 链表转数组
        values = []
        current = head
        while current:
            values.append(current.val)
            current = current.next
        
        n = len(values)
        result = [0] * n
        stack = []  # 单调递减栈，存储索引
        
        # 2. 遍历数组
        for i in range(n):
            # 当前元素大于栈顶元素时，找到了栈顶的下一个更大元素
            while stack and values[stack[-1]] < values[i]:
                idx = stack.pop()
                result[idx] = values[i]
            
            stack.append(i)
        
        return result
```

### 方法二：详细注释版

```python
class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        """
        单调栈详解
        
        栈中存储：还没找到下一个更大元素的节点索引
        维护性质：栈底到栈顶，对应值递减
        """
        # 步骤1：将链表值存入数组
        nums = []
        node = head
        while node:
            nums.append(node.val)
            node = node.next
        
        n = len(nums)
        answer = [0] * n
        stack = []  # 存储索引
        
        # 步骤2：从左到右遍历
        for i in range(n):
            current_val = nums[i]
            
            # 当前值大于栈顶对应的值
            # 说明当前值就是栈顶索引处的"下一个更大元素"
            while stack and nums[stack[-1]] < current_val:
                prev_idx = stack.pop()
                answer[prev_idx] = current_val
            
            # 当前索引入栈，等待找到它的下一个更大元素
            stack.append(i)
        
        # 栈中剩余的索引，没有下一个更大元素，保持0
        return answer
```

### 方法三：一次遍历（反向）

```python
class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        """
        反向遍历 + 单调栈
        需要先获取长度和所有值
        """
        # 收集所有值
        values = []
        current = head
        while current:
            values.append(current.val)
            current = current.next
        
        n = len(values)
        result = [0] * n
        stack = []  # 单调递减栈，存储值
        
        # 从右往左遍历
        for i in range(n - 1, -1, -1):
            # 弹出所有小于等于当前值的元素
            while stack and stack[-1] <= values[i]:
                stack.pop()
            
            # 栈顶就是下一个更大元素
            if stack:
                result[i] = stack[-1]
            
            # 当前值入栈
            stack.append(values[i])
        
        return result
```

### 方法四：直接在链表上操作

```python
class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        """
        不转数组，直接处理链表
        使用栈存储 (索引, 值) 对
        """
        result = []
        stack = []  # 存储 (索引, 值)
        idx = 0
        
        current = head
        while current:
            # 先扩展结果数组
            result.append(0)
            
            # 检查栈中是否有小于当前值的元素
            while stack and stack[-1][1] < current.val:
                prev_idx, _ = stack.pop()
                result[prev_idx] = current.val
            
            # 当前节点入栈
            stack.append((idx, current.val))
            
            idx += 1
            current = current.next
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)
  - 遍历链表：O(n)
  - 单调栈：每个元素最多入栈出栈一次，O(n)
- **空间复杂度**：O(n)
  - 数组存储：O(n)
  - 栈空间：O(n)

## 图解示例

以 `head = [2,7,4,3,5]` 为例：

```
数组: [2, 7, 4, 3, 5]
索引:  0  1  2  3  4

i=0, val=2:
  stack=[], 2入栈
  stack=[(0,2)]

i=1, val=7:
  7 > 2, 弹出(0,2), result[0]=7
  stack=[], 7入栈
  stack=[(1,7)]

i=2, val=4:
  4 < 7, 4入栈
  stack=[(1,7), (2,4)]

i=3, val=3:
  3 < 4, 3入栈
  stack=[(1,7), (2,4), (3,3)]

i=4, val=5:
  5 > 3, 弹出(3,3), result[3]=5
  5 > 4, 弹出(2,4), result[2]=5
  5 < 7, 5入栈
  stack=[(1,7), (4,5)]

最终结果: [7, 0, 5, 5, 0]
```

## 关键点总结

1. **单调栈应用**：解决"下一个更大元素"问题
2. **栈存储内容**：索引或(索引,值)对
3. **维护性质**：栈底到栈顶递减
4. **入栈时机**：每个元素都入栈一次
5. **出栈时机**：遇到更大元素时弹出

## 易错点

1. **链表转数组**：不要忘记遍历链表获取所有值
2. **栈存储索引**：要存储索引而不是值，才能更新结果
3. **初始化结果**：结果数组初始化为0
4. **遍历方向**：从左到右或从右到左都可以，逻辑不同
5. **剩余元素**：栈中剩余元素没有下一个更大值
