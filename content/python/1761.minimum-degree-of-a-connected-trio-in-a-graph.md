## 题目描述

给你一个 `n` 个节点的无向图，节点编号从 `1` 到 `n`，同时给你一个大小为 `m` 的数组 `edges`，其中 `edges[i] = [u_i, v_i]` 表示节点 `u_i` 和 `v_i` 之间有一条边。

请你返回所有**连通三元组**中度数的**最小值**。如果图中没有连通三元组，则返回 `-1`。

**连通三元组**：三个节点 `u`、`v`、`w`，满足它们之间每两个节点都有边（即构成三角形）。

**度数**：连通三元组的度数是其中三个节点的度数之和，再减去三元组内部的边数 `* 2`（即去掉内部边的贡献）。

**示例 1：**
```
输入：n = 6, edges = [[1,2],[1,3],[3,2],[4,1],[5,2],[3,6]]
输出：3
```

**提示：**
- `2 <= n <= 400`
- `edges[i].length == 2`
- `1 <= edges[i][0], edges[i][1] <= n`

## 解题思路

枚举所有三元组（三个节点 u, v, w，且三条边都存在），计算每个三元组的度数：
`deg[u] + deg[v] + deg[w] - 6`（内部三条边各计 2 次）

用邻接矩阵快速判断两节点是否相连，枚举所有三元组 O(n^3)。

## 代码实现

### 方法一：枚举三元组（推荐）

```python
from typing import List

class Solution:
    def minTrioDegree(self, n: int, edges: List[List[int]]) -> int:
        # 邻接矩阵
        adj = [[False] * (n + 1) for _ in range(n + 1)]
        deg = [0] * (n + 1)
        
        for u, v in edges:
            adj[u][v] = True
            adj[v][u] = True
            deg[u] += 1
            deg[v] += 1
        
        ans = float('inf')
        
        # 枚举所有三元组 u < v < w
        for u in range(1, n + 1):
            for v in range(u + 1, n + 1):
                if not adj[u][v]:
                    continue
                for w in range(v + 1, n + 1):
                    if adj[u][w] and adj[v][w]:
                        # 找到一个三元组
                        degree = deg[u] + deg[v] + deg[w] - 6
                        ans = min(ans, degree)
        
        return ans if ans != float('inf') else -1
```

### 方法二：优化邻接矩阵（使用集合）

```python
from typing import List

class Solution:
    def minTrioDegree(self, n: int, edges: List[List[int]]) -> int:
        adj = [set() for _ in range(n + 1)]
        deg = [0] * (n + 1)
        
        for u, v in edges:
            adj[u].add(v)
            adj[v].add(u)
            deg[u] += 1
            deg[v] += 1
        
        ans = float('inf')
        
        for u in range(1, n + 1):
            for v in adj[u]:
                if v > u:
                    # 找 u 和 v 的公共邻居 w
                    for w in adj[u]:
                        if w > v and w in adj[v]:
                            degree = deg[u] + deg[v] + deg[w] - 6
                            ans = min(ans, degree)
        
        return ans if ans != float('inf') else -1
```

## 复杂度分析

- **时间复杂度**：O(n^3)，枚举所有三元组
- **空间复杂度**：O(n^2)，邻接矩阵

## 关键点总结

1. 用邻接矩阵快速判断边是否存在 O(1)
2. 三元组度数 = 三个节点度数之和 - 6（内部三条边各被计数两次）
3. 枚举时令 u < v < w 避免重复

## 易错点

- 度数计算：内部三条边每条被两端节点各计一次，共 6 次要减去
- 注意节点编号从 1 开始
