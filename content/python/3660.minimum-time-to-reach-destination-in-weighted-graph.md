## 题目描述

给你一个 `n` 个节点的有向加权图，边集 `edges[i] = [u, v, w]`。从节点 0 出发，每次可以沿边移动（花费对应边权时间），或在当前节点等待 1 单位时间。返回到达节点 `n-1` 的最短时间。

**示例 1：**

```
输入：n = 3, edges = [[0,1,2],[1,2,3]], 
输出：5
```

**示例 2：**

```
输入：n = 4, edges = [[0,1,1],[0,2,4],[1,3,1],[2,3,1]]
输出：2
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= edges.length <= 3 * 10^5`

## 解题思路

标准 Dijkstra 单源最短路，等待操作不影响最短路（因为等待只会增加时间，不如直接走最短路）。

直接用 Dijkstra 求从节点 0 到节点 n-1 的最短路。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))

        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            if u == n - 1:
                return d
            for v, w in graph[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

### 方法二：Bellman-Ford（适合负权边）

```python
from typing import List

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]]) -> int:
        dist = [float('inf')] * n
        dist[0] = 0

        for _ in range(n - 1):
            updated = False
            for u, v, w in edges:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    updated = True
            if not updated:
                break

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)（Dijkstra）
- 空间复杂度：O(V + E)

## 关键点总结

1. 等待操作不影响 Dijkstra 正确性（等待只增加时间）
2. 单源最短路的标准问题
3. 若无法到达返回 -1

## 易错点

1. 有向图只建单向边
2. 检查 `d > dist[u]` 跳过过期状态
3. 到达目标节点时提前返回
