## 题目描述

给定字符串 `s` 和字符串 `t`，找出 `s` 中需要删除的最少字符数，使得 `t` 不再是 `s` 的子序列。

**示例 1：**
```
输入：s = "abcde", t = "ace"
输出：1
解释：删除 'c' 后，s="abde"，t="ace" 不再是其子序列。
```

**示例 2：**
```
输入：s = "abcbdabbacdb", t = "abcd"
输出：2
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= t.length <= 10^5`

## 解题思路

贪心。

**关键观察：** 若删除 `s` 中的某些字符使 `t` 不再是子序列，等价于截断所有 `t` 在 `s` 中的匹配路径。

**最优策略：** 对 `t` 中的每个字符 `t[j]`，在 `s` 中找到所有匹配位置，删除其中某些关键位置。

贪心：从 `t` 的第一个字符到最后一个字符，对每个 `t[j]` 删除 `s` 中最后一个能匹配的字符（使剩余匹配路径断裂）。

更精确：对每个 `t[j]`，有一个最靠前的匹配位置前缀，删除其中一个可以截断该前缀。最少删除数 = `t` 的长度（每个字符的关键匹配至少删一个）的某个子集，通过贪心最小化。

实际上：最少删除数 = `t` 中必须删除的字符数，等于找到 `s` 中"使所有 t 的子序列匹配都不完整"所需的最少删除数。

这等价于最小割（min cut）问题：每条 `t` 在 `s` 中的匹配路径至少要截断一条边。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def minDeletions(self, s: str, t: str) -> int:
        n, m = len(s), len(t)

        # 首先检查 t 是否是 s 的子序列
        def is_subseq(s, t):
            j = 0
            for c in s:
                if j < len(t) and c == t[j]:
                    j += 1
            return j == len(t)

        if not is_subseq(s, t):
            return 0  # 本就不是子序列，无需删除

        # 找到 t 在 s 中匹配的关键位置
        # 贪心：对每个 t[j]，在 s 中找最靠后的匹配位置并删除
        # 这样每次删除最大程度地截断匹配

        # 从右往左，每次删除 t 的某个字符在 s 中的最后一次出现
        result = 0
        j = m - 1  # 从 t 末尾开始
        i = n - 1  # 从 s 末尾开始

        while j >= 0 and i >= 0:
            while i >= 0 and s[i] != t[j]:
                i -= 1
            if i >= 0:
                # 删除 s[i]（t[j] 在 s 中的最靠后匹配位置）
                result += 1
                i -= 1
                j -= 1

        return result
```

### 方法二：DP（精确但复杂）

```python
class Solution:
    def minDeletions(self, s: str, t: str) -> int:
        # 贪心解法等价于：t 的每个字符都需要在 s 中删除一个匹配
        # 等价于从 t 的末尾向前，逐一找 s 中最后匹配的位置删除
        n, m = len(s), len(t)

        # 检查是否需要操作
        j = 0
        for c in s:
            if j < m and c == t[j]:
                j += 1
        if j < m:
            return 0

        # 贪心
        result = 0
        j = m - 1
        i = n - 1
        while j >= 0:
            while i >= 0 and s[i] != t[j]:
                i -= 1
            if i < 0:
                break
            result += 1
            i -= 1
            j -= 1

        return result
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)

## 关键点总结

1. 若 t 不是 s 的子序列，直接返回 0
2. 贪心：从 t 末尾往前，每次删除 t 当前字符在 s 中最靠后的匹配
3. 最少删除数 = t 的长度（若每个字符都需要截断一次）

## 易错点

1. 先判断 t 是否是 s 的子序列
2. 从后往前贪心，确保每次删除的影响最大
