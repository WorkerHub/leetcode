## 题目描述

给你一个正整数 `num`，请你将它分成两个非负整数 `num1` 和 `num2`，满足：
- `num1` 和 `num2` 直接连接后等于 `num`（连接是字符级别的，不允许在任一整数前面添加额外的前导零）
- `num1` 和 `num2` 可以包含前导零

返回 `num1 + num2` 的 **最小** 值。

**注意：** `num` 是无前导零的正整数，`num1` 和 `num2` 的 digit 是从 `num` 中分配的。

**示例 1：**

```
输入：num = 4325
输出：59
解释：分割为 num1=25, num2=34，和为 59。
```

**示例 2：**

```
输入：num = 687
输出：75
解释：分割为 num1=8, num2=67（或 num1=68, num2=7），最优为 num1=7, num2=68... 68+7=75 不对... 实际最优为 6+87=93 或 68+7=75。
```

**提示：**

- `10 <= num <= 10^9`

## 解题思路

**贪心**：将 num 的各位数字排序，交替分配给 num1 和 num2（较小的位分给较高位的那个数）。

具体：排序后，奇数位给 num1，偶数位给 num2（或交替分配），这样两数的最高位都尽可能小。

## Python 代码实现

### 方法一：贪心排序交替分配（推荐）

```python
class Solution:
    def splitNum(self, num: int) -> int:
        # 将各位数字排序
        digits = sorted(str(num))
        # 交替分配给 num1 和 num2
        num1 = int(''.join(digits[::2]))   # 奇数位（0, 2, 4, ...）
        num2 = int(''.join(digits[1::2]))  # 偶数位（1, 3, 5, ...）
        return num1 + num2
```

### 方法二：逐位构建

```python
class Solution:
    def splitNum(self, num: int) -> int:
        digits = sorted(int(d) for d in str(num))
        n1, n2 = 0, 0
        for i, d in enumerate(digits):
            if i % 2 == 0:
                n1 = n1 * 10 + d
            else:
                n2 = n2 * 10 + d
        return n1 + n2
```

## 复杂度分析

- 时间复杂度：O(d log d)，d 为数字位数（最多 10 位）
- 空间复杂度：O(d)

## 关键点总结

1. 排序后交替分配，让两个数的高位都尽可能小
2. 最小化两数之和，贪心策略是让较小的数字放在较高位
3. 奇偶交替保证两数位数均衡

## 易错点

1. 排序的是各位数字，不是 num 本身
2. 交替分配时两个数的位数可能相差 1
3. 注意 `int(''.join(...))` 会自动处理前导零
