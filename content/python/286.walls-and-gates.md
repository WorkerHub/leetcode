## 题目描述

你被给定一个 `m × n` 的二维网格 `rooms`，网格中有以下三种可能的初始化值：

- `-1` 表示墙或是障碍物
- `0` 表示一扇门
- `INF` 无限大表示一个空房间。我们使用 `2^31 - 1 = 2147483647` 代表 `INF`。你可以认为通往门的距离总是小于 `2147483647` 的。

你要给每个空房间填上该房间到最近门的距离，如果无法到达门，则填 `INF`。

**示例 1:**

```
输入: rooms = [
  [2147483647,-1,0,2147483647],
  [2147483647,2147483647,2147483647,-1],
  [2147483647,-1,2147483647,-1],
  [0,-1,2147483647,2147483647]
]
输出: [
  [3,-1,0,1],
  [2,2,1,-1],
  [1,-1,2,-1],
  [0,-1,3,4]
]
```

**示例 2:**

```
输入: rooms = [[-1]]
输出: [[-1]]
```

**示例 3:**

```
输入: rooms = [[2147483647]]
输出: [[2147483647]]
```

**示例 4:**

```
输入: rooms = [[0]]
输出: [[0]]
```

**提示:**

- `m == rooms.length`
- `n == rooms[i].length`
- `1 <= m, n <= 250`
- `rooms[i][j]` 是 `-1`、`0` 或 `2^31 - 1`

## 解题思路

这是一道典型的多源 BFS（广度优先搜索）问题。核心思想是从所有门同时开始扩散，计算每个房间到最近门的距离。

**核心思想：**

1. 多源 BFS：将所有门作为起点同时进行 BFS
2. 层次遍历：每扩散一层，距离加 1
3. 原地修改：直接在原数组上更新距离

**为什么用 BFS 而不是 DFS？**

- BFS 保证找到的是最短距离
- DFS 可能找到的不是最短路径

**算法流程：**

1. 将所有门（值为 0）的位置加入队列
2. 从队列中取出一个位置，向四个方向扩散
3. 如果相邻位置是空房间（INF），更新距离并加入队列
4. 重复步骤 2-3 直到队列为空

**关键观察：**

- 从多个门同时 BFS，天然保证每个房间得到的是最短距离
- 已访问的房间不需要再访问（第一次访问就是最短距离）

## Python 代码实现

### 方法一：多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        """
        多源 BFS，从所有门同时扩散
        时间复杂度 O(m*n)，空间复杂度 O(m*n)
        """
        if not rooms or not rooms[0]:
            return
        
        m, n = len(rooms), len(rooms[0])
        INF = 2147483647
        
        # 队列，存储所有门的位置
        queue = deque()
        
        # 将所有门加入队列
        for i in range(m):
            for j in range(n):
                if rooms[i][j] == 0:
                    queue.append((i, j))
        
        # 四个方向：上下左右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # BFS 扩散
        while queue:
            x, y = queue.popleft()
            
            # 向四个方向扩散
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                # 边界检查 + 只访问空房间（INF）
                if 0 <= nx < m and 0 <= ny < n and rooms[nx][ny] == INF:
                    # 更新距离
                    rooms[nx][ny] = rooms[x][y] + 1
                    # 加入队列继续扩散
                    queue.append((nx, ny))
```

### 方法二：层次遍历版本（更清晰）

```python
from collections import deque

class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        """
        明确标记每一层的 BFS
        """
        if not rooms:
            return
        
        m, n = len(rooms), len(rooms[0])
        INF = 2147483647
        queue = deque()
        
        # 收集所有门
        for i in range(m):
            for j in range(n):
                if rooms[i][j] == 0:
                    queue.append((i, j, 0))  # (x, y, distance)
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while queue:
            x, y, dist = queue.popleft()
            
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                # 检查边界和是否为空房间
                if (0 <= nx < m and 0 <= ny < n and 
                    rooms[nx][ny] == INF):
                    rooms[nx][ny] = dist + 1
                    queue.append((nx, ny, dist + 1))
```

### 方法三：详细注释版（新手友好）

```python
from collections import deque

class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        """
        墙和门问题：计算每个空房间到最近门的距离
        
        算法：多源 BFS
        1. 找出所有门，作为 BFS 的起点
        2. 从所有门同时向外扩散
        3. 遇到空房间就更新距离
        
        为什么多源 BFS？
        - 单源 BFS 需要对每个门分别运行，效率低
        - 多源 BFS 一次遍历就能更新所有房间
        
        示例演示：
        初始：
        [INF, -1,  0, INF]
        [INF,INF,INF, -1]
        [INF, -1,INF, -1]
        [ 0,  -1,INF,INF]
        
        第 0 层（所有门）：[(0,2), (3,0)]
        第 1 层：更新距离为 1 的房间
        第 2 层：更新距离为 2 的房间
        ...
        """
        if not rooms or not rooms[0]:
            return
        
        m, n = len(rooms), len(rooms[0])
        INF = 2147483647
        
        # 初始化队列，包含所有门的位置
        queue = deque()
        for i in range(m):
            for j in range(n):
                if rooms[i][j] == 0:
                    queue.append((i, j))
        
        # 定义四个移动方向（上、下、左、右）
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # BFS 遍历
        while queue:
            # 取出当前位置
            row, col = queue.popleft()
            current_dist = rooms[row][col]
            
            # 尝试向四个方向扩散
            for dr, dc in directions:
                new_row = row + dr
                new_col = col + dc
                
                # 检查新位置是否合法
                # 1. 在边界内
                # 2. 是空房间（值为 INF）
                if (0 <= new_row < m and 
                    0 <= new_col < n and 
                    rooms[new_row][new_col] == INF):
                    
                    # 更新距离
                    rooms[new_row][new_col] = current_dist + 1
                    
                    # 加入队列，继续扩散
                    queue.append((new_row, new_col))
```

### 方法四：DFS 解法（不推荐，仅供对比）

```python
class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        """
        DFS 解法：从每个门开始 DFS
        缺点：可能更新非最短距离，需要额外判断
        """
        if not rooms:
            return
        
        m, n = len(rooms), len(rooms[0])
        INF = 2147483647
        
        def dfs(x, y, dist):
            # 边界检查
            if x < 0 or x >= m or y < 0 or y >= n:
                return
            # 墙壁或距离更短，不更新
            if rooms[x][y] < dist:
                return
            
            # 更新距离
            rooms[x][y] = dist
            
            # 向四个方向递归
            dfs(x + 1, y, dist + 1)
            dfs(x - 1, y, dist + 1)
            dfs(x, y + 1, dist + 1)
            dfs(x, y - 1, dist + 1)
        
        # 从每个门开始 DFS
        for i in range(m):
            for j in range(n):
                if rooms[i][j] == 0:
                    dfs(i, j, 0)
```

## 复杂度分析

**BFS 方法：**
- 时间复杂度：`O(m * n)` 每个单元格最多访问一次
- 空间复杂度：`O(m * n)` 队列最多包含所有单元格

**DFS 方法：**
- 时间复杂度：`O(k * m * n)` k 为门的数量，每个门都要遍历一次
- 空间复杂度：`O(m * n)` 递归栈深度

## 关键点总结

1. **多源 BFS**：将所有起点同时加入队列，一次遍历完成
2. **原地修改**：直接在原数组上更新，节省空间
3. **访问标记**：利用 INF 判断是否访问过，不需要额外 visited 数组
4. **最短路径**：BFS 保证第一次到达某点时就是最短距离
5. **方向数组**：使用 directions 数组简化四方向遍历

## 易错点

1. **单源 BFS**：错误地对每个门分别 BFS，时间复杂度过高
2. **忘记边界检查**：访问数组前没有检查索引合法性
3. **重复访问**：没有判断 `rooms[nx][ny] == INF`，导致重复处理
4. **距离计算错误**：应该是 `rooms[x][y] + 1`，不是 `dist + 1`（如果 dist 未定义）
5. **使用 DFS**：DFS 不能保证最短路径，除非加额外判断
