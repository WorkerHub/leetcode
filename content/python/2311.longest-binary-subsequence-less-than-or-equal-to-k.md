## 题目描述

给你一个二进制字符串 `s` 和一个正整数 `k`。

请你返回 `s` 的**最长**子序列，且该子序列对应的**二进制数字**小于等于 `k`。

注意：子序列可以有**前导 0**，且空字符串视为 0。

**示例 1：**
```
输入：s = "1001010", k = 5
输出：5
解释：最长子序列之一是 "00010"，对应二进制值 2 <= 5。
```

**示例 2：**
```
输入：s = "00101001", k = 1
输出：6
解释：最长子序列之一是 "000001"，对应二进制值 1 <= 1。
```

**提示：**
- `1 <= s.length <= 1000`
- `1 <= k <= 10^9`

## 解题思路

**贪心策略：**
- 所有的 `'0'` 都可以加入子序列（不增大数值）。
- 对于 `'1'`，从右向左尽量多地选取，并保证二进制值不超过 `k`。

**具体做法：**
1. 统计 `s` 中 `'0'` 的个数，这些都可以选。
2. 从右到左，贪心地选取 `'1'`，用一个变量维护当前已选 `'1'` 对应的贡献，只要不超过 `k` 就选。
3. 答案 = 所有 `'0'` 的数量 + 可以选取的 `'1'` 的数量。

## 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def longestSubsequence(self, s: str, k: int) -> int:
        n = len(s)
        zeros = s.count('0')  # 所有 0 都可以选
        ones = 0              # 可以选的 1 的数量
        val = 0               # 已选 1 构成的值
        
        # 从右向左遍历，贪心选取 1
        for i in range(n - 1, -1, -1):
            if s[i] == '1':
                # 当前 1 的权重为 2^(已选 1 的数量)
                bit_val = 1 << ones  # 该位的二进制值
                if val + bit_val <= k:
                    val += bit_val
                    ones += 1
        
        return zeros + ones
```

### 方法二：动态规划

```python
class Solution:
    def longestSubsequence(self, s: str, k: int) -> int:
        n = len(s)
        # dp[i][v] 过于复杂，改用贪心思路的DP形式
        # 记录从右侧选了多少个 1，以及对应的值
        best = 0   # 最多选几个 1
        cur_val = 0
        
        # 从后往前扫描
        for i in range(n - 1, -1, -1):
            if s[i] == '1':
                contrib = 1 << best  # 第 best 个 1（从右数）的值
                if cur_val + contrib <= k:
                    cur_val += contrib
                    best += 1
        
        # zeros 全部可选
        zeros = s.count('0')
        return zeros + best
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(1) |

## 关键点总结

1. `'0'` 不影响数值大小，全部可以选入子序列。
2. 从右向左选 `'1'`，因为靠右的 `'1'` 权重更小，优先选取。
3. 已选 `ones` 个 1 时，下一个 1 的权重为 `2^ones`，若加入后不超过 k 则选。

## 易错点

- 子序列中前导 0 不影响值，所有 0 均可选。
- 贪心选 1 时要从右向左（低位优先），确保尽量多选。
