## 题目描述

请你设计一个迭代器类 `CombinationIterator`，包括以下内容：

- `CombinationIterator(string characters, int combinationLength)`：使用字母表 `characters`（**升序排列**，由唯一字母组成）和数字 `combinationLength` 初始化对象。
- `next()`：按**字典序**返回长度为 `combinationLength` 的下一个字母组合。
- `hasNext()`：如果存在长度为 `combinationLength` 的下一个字母组合，返回 `true`，否则返回 `false`。

**示例：**

```
输入:
["CombinationIterator", "next", "hasNext", "next", "hasNext", "next", "hasNext"]
[["abc", 2], [], [], [], [], [], []]

输出:
[null, "ab", true, "ac", true, "bc", false]

解释：
CombinationIterator iter = new CombinationIterator("abc", 2);
iter.next();    // 返回 "ab"
iter.hasNext(); // 返回 true
iter.next();    // 返回 "ac"
iter.hasNext(); // 返回 true
iter.next();    // 返回 "bc"
iter.hasNext(); // 返回 false
```

**提示：**

- `1 <= combinationLength <= characters.length <= 15`
- `characters` 中每个字符都是**唯一**的。
- 每次调用 `next` 和 `hasNext` 共最多调用 `10^4` 次。
- 题目保证每次调用 `next` 时都存在下一个字母组合。

---

## 解题思路

这道题要求实现一个"按字典序生成组合"的迭代器，有两种主要思路：

### 思路一：预生成所有组合（简单直接）

利用 Python 的 `itertools.combinations` 函数，在初始化时一次性生成所有满足条件的组合，存入列表。`next()` 依次弹出，`hasNext()` 检查是否还有剩余。

**优点**：实现极简，利用 Python 标准库。
**缺点**：占用额外空间，初始化时间较长（若组合数量大）。

### 思路二：回溯法按需生成（经典）

用回溯算法，在初始化时生成并存储所有组合（按字典序），然后按需返回。

**字典序保证**：`characters` 已按升序排列，回溯按顺序选字符，天然保证字典序。

### 思路三：位运算枚举（进阶）

利用二进制掩码枚举所有子集中恰好有 `combinationLength` 个 1 的情况，然后排序输出。

## Python 代码实现

### 方法一：itertools.combinations（最简洁，推荐）

```python
from itertools import combinations

class CombinationIterator:

    def __init__(self, characters: str, combinationLength: int):
        # 生成所有长度为 combinationLength 的组合，转为列表
        # itertools.combinations 按字典序生成
        self.combos = [''.join(combo) for combo in combinations(characters, combinationLength)]
        self.index = 0  # 当前指针位置

    def next(self) -> str:
        # 返回当前组合，指针后移
        result = self.combos[self.index]
        self.index += 1
        return result

    def hasNext(self) -> bool:
        # 检查是否还有未返回的组合
        return self.index < len(self.combos)
```

### 方法二：回溯法生成（理解递归回溯）

```python
from typing import List

class CombinationIterator:

    def __init__(self, characters: str, combinationLength: int):
        self.combos = []
        self._backtrack(characters, combinationLength, 0, [], self.combos)
        self.index = 0

    def _backtrack(self, chars: str, length: int, start: int,
                   current: List[str], result: List[str]) -> None:
        """回溯生成所有长度为 length 的组合"""
        if len(current) == length:
            # 当前选择的字符已满足长度要求，加入结果
            result.append(''.join(current))
            return

        # 从 start 位置开始选择字符
        for i in range(start, len(chars)):
            # 剩余可选字符数量剪枝：若剩余字符不够，提前退出
            remaining_needed = length - len(current)
            remaining_available = len(chars) - i
            if remaining_available < remaining_needed:
                break

            current.append(chars[i])               # 选择字符 chars[i]
            self._backtrack(chars, length, i + 1, current, result)  # 递归
            current.pop()                           # 撤销选择（回溯）

    def next(self) -> str:
        result = self.combos[self.index]
        self.index += 1
        return result

    def hasNext(self) -> bool:
        return self.index < len(self.combos)
```

**回溯过程示例（characters="abc", combinationLength=2）：**

```
start=0, current=[]:
  选 'a' -> current=['a'], start=1:
    选 'b' -> current=['a','b'], 长度满足 -> 加入 "ab"，回溯
    选 'c' -> current=['a','c'], 长度满足 -> 加入 "ac"，回溯
  选 'b' -> current=['b'], start=2:
    选 'c' -> current=['b','c'], 长度满足 -> 加入 "bc"，回溯

结果顺序：["ab", "ac", "bc"]（字典序）
```

### 方法三：使用生成器（懒加载，节省内存）

```python
from itertools import combinations

class CombinationIterator:

    def __init__(self, characters: str, combinationLength: int):
        # 使用生成器，按需生成，节省内存
        self._gen = combinations(characters, combinationLength)
        self._next_val = None   # 预取下一个值
        self._advance()         # 初始化时预取第一个

    def _advance(self) -> None:
        """预取下一个值，若无则设为 None"""
        try:
            self._next_val = ''.join(next(self._gen))
        except StopIteration:
            self._next_val = None

    def next(self) -> str:
        result = self._next_val  # 返回预取的值
        self._advance()          # 预取下一个
        return result

    def hasNext(self) -> bool:
        return self._next_val is not None  # 若预取值不为 None，则还有下一个
```

**方法三的优势**：使用生成器懒加载，内存占用 O(1)（不存储所有组合），适合 `characters` 很长的场景。

## 复杂度分析

设 `n = len(characters)`，`k = combinationLength`，组合总数 `C(n,k)`。

| 方法 | 初始化时间 | next() 时间 | hasNext() 时间 | 空间复杂度 |
|------|-----------|-----------|--------------|-----------|
| 方法一（预生成） | O(C(n,k) * k) | O(1) | O(1) | O(C(n,k) * k) |
| 方法二（回溯） | O(C(n,k) * k) | O(1) | O(1) | O(C(n,k) * k) |
| 方法三（生成器） | O(k) | O(k) | O(1) | O(k) |

- **预生成方法**：初始化时生成并存储所有组合，每次 next() 和 hasNext() 为 O(1)。
- **生成器方法**：初始化 O(k)（预取第一个），next() 调用 O(k)（生成一个组合），内存始终 O(k)。

## 关键点总结

1. `itertools.combinations(iterable, r)` 按字典序生成 `r` 个元素的组合，是 Python 解这类题的利器。
2. 回溯法的核心是"选择-递归-撤销"三步，`current.pop()` 是撤销（回溯）的关键。
3. 回溯中的**剪枝**（若剩余字符不足则提前退出）可以减少无效递归，提高效率。
4. 生成器（`yield`/迭代器对象）实现懒加载，内存效率更高，适合组合数量很大的场景。
5. 字典序由 `characters` 的升序保证：在升序字符串中按从左到右顺序选取字符，生成的组合天然有序。

---

## 易错点

1. **`next()` 不要忘记移动指针**：调用 `next()` 后 `self.index += 1`，否则每次都返回同一个值。
2. **回溯撤销**：`current.pop()` 必须在递归调用之后执行，顺序不能颠倒。
3. **`hasNext()` 的判断**：方法三中用预取值是否为 `None` 判断，而非访问生成器本身（生成器状态不能直接查询）。
4. **初始化时的预取（方法三）**：必须在 `__init__` 中调用 `_advance()` 预取第一个值，否则第一次 `hasNext()` 时 `_next_val` 未被初始化。
