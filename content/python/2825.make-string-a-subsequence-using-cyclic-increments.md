## 题目描述

给你两个下标从 0 开始的字符串 `str1` 和 `str2`。

一次操作中，你可以选择 `str1` 中的若干下标，对每个选中的下标 `i`，将 `str1[i]` 替换为字母表中的下一个字母（循环，`'z'` 的下一个是 `'a'`）。

如果可以通过**一次操作**（零个或多个替换）使 `str2` 成为 `str1` 的**子序列**，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：str1 = "abc", str2 = "ad"
输出：true
解释：将 'c' -> 'd'，则 str1 = "abd"，str2 = "ad" 是子序列
```

**示例 2：**
```
输入：str1 = "zc", str2 = "ad"
输出：true
解释：将 str1[0]='z'->'a'，str1[1]='c'->'d'，str1="ad"，str2="ad" 是子序列
```

**示例 3：**
```
输入：str1 = "ab", str2 = "d"
输出：false
```

**提示：**
- `1 <= str1.length <= 10^5`
- `1 <= str2.length <= 10^5`
- 两个字符串都只包含小写字母

## 解题思路

**双指针：**
- 用指针 `j` 遍历 `str2`，指针 `i` 遍历 `str1`
- 对每个 `str1[i]`，检查是否匹配 `str2[j]`（匹配条件：`str1[i] == str2[j]` 或 `(ord(str1[i]) + 1 - ord('a')) % 26 + ord('a') == ord(str2[j])`）
  - 即 `str1[i]` 可以直接匹配，或加一后匹配
- 若匹配，`j++`
- 最终 `j == len(str2)` 则返回 `true`

## Python 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def canMakeSubsequence(self, str1: str, str2: str) -> bool:
        j = 0  # str2 的指针
        n2 = len(str2)

        for ch in str1:
            if j == n2:
                break
            target = str2[j]
            # 当前字符或加一后等于 target
            next_ch = chr((ord(ch) - ord('a') + 1) % 26 + ord('a'))
            if ch == target or next_ch == target:
                j += 1

        return j == n2
```

### 方法二：更清晰的写法

```python
class Solution:
    def canMakeSubsequence(self, str1: str, str2: str) -> bool:
        j = 0

        for i in range(len(str1)):
            if j >= len(str2):
                break
            c1 = str1[i]
            c2 = str2[j]
            # c1 可以匹配 c2，或者 c1 的循环下一个字符匹配 c2
            if c1 == c2 or chr((ord(c1) - ord('a') + 1) % 26 + ord('a')) == c2:
                j += 1

        return j == len(str2)
```

### 方法三：辅助函数

```python
class Solution:
    def canMakeSubsequence(self, str1: str, str2: str) -> bool:
        def can_match(c1: str, c2: str) -> bool:
            """c1 能否匹配 c2（可以选择加一或不变）"""
            return c1 == c2 or (ord(c1) - ord('a') + 1) % 26 == ord(c2) - ord('a')

        j = 0
        for c in str1:
            if j < len(str2) and can_match(c, str2[j]):
                j += 1

        return j == len(str2)
```

## 复杂度分析

- 时间复杂度：O(n + m)，n = len(str1)，m = len(str2)，双指针各遍历一次
- 空间复杂度：O(1)

## 关键点总结

1. 双指针贪心：尽早匹配 str2 的每个字符
2. 匹配条件：str1[i] == str2[j] 或 str1[i] 循环加一后等于 str2[j]
3. `'z'` 的下一个是 `'a'`：用 `(ord(c) - ord('a') + 1) % 26` 计算

## 易错点

1. 循环加一：`'z'` 的下一个是 `'a'`，不能简单 +1
2. 每个 str1[i] 只能替换一次（但可以选择替换或不替换）
3. 只需要找子序列，不要求连续
