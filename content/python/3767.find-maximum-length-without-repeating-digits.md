## 题目描述

给定正整数 `n`，找出最大的正整数 `x`（`x <= n`），使得 `x` 的十进制表示中没有重复的数字。

**示例 1：**
```
输入：n = 100
输出：98
解释：98 没有重复数字，99 有重复（9 出现两次），100 有重复（0 出现两次）。
     99 之前最大的无重复数字是 98。
```

**示例 2：**
```
输入：n = 1000000
输出：987654
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

从 `n` 开始向下搜索，找到第一个无重复数字的整数。

但直接向下逐个检查可能很慢。

**贪心方法：** 从高位到低位贪心构造最大无重复数字的整数：
1. 尽量保持与 `n` 相同的前缀
2. 当某位出现重复时，将该位减 1，并将后续位设为尽可能大的无重复数字

## Python 代码实现

### 方法一：贪心构造（推荐）

```python
class Solution:
    def maxNonRepeatingDigit(self, n: int) -> int:
        def has_repeat(x: int) -> bool:
            s = str(x)
            return len(s) != len(set(s))

        # 从 n 向下找
        # 对于小规模可以直接搜索
        x = n
        while x > 0 and has_repeat(x):
            x -= 1
        return x
```

### 方法二：贪心逐位构造（高效）

```python
class Solution:
    def maxNonRepeatingDigit(self, n: int) -> int:
        digits = list(str(n))
        length = len(digits)

        # 尝试找与 n 相同前缀、不超过 n 的最大无重复数
        def build_max(used: set, pos: int, tight: bool) -> str:
            """从 pos 位开始，向后贪心填数字，返回剩余部分"""
            if pos == length:
                return ""
            limit = int(digits[pos]) if tight else 9
            for d in range(limit, -1, -1):
                if d not in used:
                    rest = ""
                    cur_used = used | {d}
                    # 后续位贪心填最大
                    for remaining in range(length - pos - 1):
                        for dd in range(9, -1, -1):
                            if dd not in cur_used:
                                rest += str(dd)
                                cur_used = cur_used | {dd}
                                break
                    return str(d) + rest
            return None

        # 尝试直接截断到 tight 的部分
        used = set()
        result = []
        for i, ch in enumerate(digits):
            d = int(ch)
            if d in used:
                # 在当前位减 1（不重复），后续贪心填最大
                for nd in range(d - 1, -1, -1):
                    if nd not in used:
                        rest = ""
                        cur_used = used | {nd}
                        for _ in range(length - i - 1):
                            for dd in range(9, -1, -1):
                                if dd not in cur_used:
                                    rest += str(dd)
                                    cur_used = cur_used | {dd}
                                    break
                        return int(''.join(result) + str(nd) + rest)
                # 无法减，需要回退更高位
                # 简化：直接从高位回退
                return self.maxNonRepeatingDigit(n - 1)
            used.add(d)
            result.append(ch)

        return int(''.join(result))
```

## 复杂度分析

- 时间复杂度：方法一 O(n) 最坏（不实际）；方法二 O(L^2)，L 为位数
- 空间复杂度：O(L)

## 关键点总结

1. n <= 10^9（最多 10 位），无重复数字的最大数为 9876543210（10 位）
2. 贪心：尽量保留前缀，遇到重复则减小当前位
3. 后续位贪心填 9,8,7... 中未使用的数字

## 易错点

1. 遇到 0 时不能减到 -1，需要继续回退
2. 前缀已用数字集合需要正确维护
