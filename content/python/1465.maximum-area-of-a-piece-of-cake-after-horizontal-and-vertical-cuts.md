## 题目描述

给你一个矩形蛋糕，大小为 `h x w`，以及两个整数数组 `horizontalCuts` 和 `verticalCuts`，其中：
- `horizontalCuts[i]` 是从矩形蛋糕顶部到第 `i` 条水平切割线的距离
- `verticalCuts[j]` 是从矩形蛋糕的左侧到第 `j` 条竖直切割线的距离

请你返回按数组 `horizontalCuts` 和 `verticalCuts` 切割后得到的**最大蛋糕块**的面积，由于答案可能是一个很大的数字，返回它对 `10^9 + 7` 取余的结果。

**示例 1：**
```
输入：h = 5, w = 4, horizontalCuts = [1,2,4], verticalCuts = [1,3]
输出：4
解释：按照给出的切割线，得到了 4*4=16 块小蛋糕。
     最大一块的面积是 max水平间距 * max竖直间距 = 2 * 2 = 4
```

**示例 2：**
```
输入：h = 5, w = 4, horizontalCuts = [3,1], verticalCuts = [1]
输出：6
解释：最大间距：水平 max(1,2,2)=2，竖直 max(1,3)=3，面积=6
```

**示例 3：**
```
输入：h = 5, w = 4, horizontalCuts = [3], verticalCuts = [3]
输出：9
```

**提示：**
- `2 <= h, w <= 10^9`
- `1 <= horizontalCuts.length <= min(h-1, 10^5)`
- `1 <= verticalCuts.length <= min(w-1, 10^5)`
- `1 <= horizontalCuts[i] < h`
- `1 <= verticalCuts[i] < w`
- 题目中数据保证 `horizontalCuts` 中的所有元素各不相同，`verticalCuts` 中的所有元素各不相同

## 解题思路

**贪心思路：**

最大蛋糕块面积 = 水平方向最大间距 × 竖直方向最大间距

1. 对水平切割线排序，找相邻切割线（含边界 0 和 h）之间的最大间距
2. 对竖直切割线排序，找相邻切割线（含边界 0 和 w）之间的最大间距
3. 两个最大间距相乘，对 `10^9 + 7` 取模

**注意**：面积可能超过 Python int 范围？不会，Python 的 int 是任意精度的，但需要最后取模。

## Python 代码实现

### 方法一：排序 + 最大间距（推荐）

```python
from typing import List

class Solution:
    def maxArea(self, h: int, w: int, horizontalCuts: List[int],
                verticalCuts: List[int]) -> int:
        MOD = 10 ** 9 + 7

        def max_gap(cuts: List[int], total: int) -> int:
            """计算切割线之间（含两端边界）的最大间距"""
            cuts.sort()
            max_g = 0
            prev = 0
            for c in cuts:
                max_g = max(max_g, c - prev)
                prev = c
            # 最后一个切割线到边界的距离
            max_g = max(max_g, total - prev)
            return max_g

        max_h = max_gap(horizontalCuts, h)
        max_v = max_gap(verticalCuts, w)

        return (max_h * max_v) % MOD
```

### 方法二：更简洁的写法（利用差分）

```python
from typing import List

class Solution:
    def maxArea(self, h: int, w: int, horizontalCuts: List[int],
                verticalCuts: List[int]) -> int:
        MOD = 10 ** 9 + 7

        # 加入边界 0 和总长度，排序后计算相邻差值的最大值
        horizontalCuts = sorted([0] + horizontalCuts + [h])
        verticalCuts = sorted([0] + verticalCuts + [w])

        # 最大水平间距
        max_h = max(horizontalCuts[i] - horizontalCuts[i-1]
                    for i in range(1, len(horizontalCuts)))
        # 最大竖直间距
        max_v = max(verticalCuts[i] - verticalCuts[i-1]
                    for i in range(1, len(verticalCuts)))

        return (max_h * max_v) % MOD
```

### 方法三：使用 zip 计算差值

```python
from typing import List

class Solution:
    def maxArea(self, h: int, w: int, horizontalCuts: List[int],
                verticalCuts: List[int]) -> int:
        MOD = 10 ** 9 + 7

        # 排序并加入边界
        hc = sorted([0] + horizontalCuts + [h])
        vc = sorted([0] + verticalCuts + [w])

        # zip 计算相邻差值
        max_h = max(b - a for a, b in zip(hc, hc[1:]))
        max_v = max(b - a for a, b in zip(vc, vc[1:]))

        return (max_h * max_v) % MOD
```

## 复杂度分析

- 时间复杂度：O(m log m + n log n)，m 和 n 分别是水平和竖直切割线的数量
- 空间复杂度：O(m + n)，排序后的数组

## 关键点总结

1. 最大面积 = 水平最大间距 × 竖直最大间距（贪心，两个维度独立）
2. 排序后，间距就是相邻元素的差，需要加入边界 0 和总长度
3. 取模操作在**最后相乘后**进行，不要对 max_h 或 max_v 单独取模（会影响最大值比较）

## 易错点

- 不要忘记加入蛋糕边界（0 和 h/w），否则第一段和最后一段间距会漏算
- 取模要在乘积之后进行：`(max_h * max_v) % MOD`，不是 `max_h % MOD * max_v % MOD`（虽然数学上等价，但容易出错）
- h、w 可以达到 10^9，面积可能达到 10^18，Python 整数没有溢出问题，但取模是必要的
