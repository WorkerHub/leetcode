## 题目描述

给你两个整数，被除数 `dividend` 和除数 `divisor`。将两数相除，要求不使用乘法、除法和取模运算。

整数除法应该向零截断，也就是截去其小数部分。例如，`8.345` 将被截断为 `8`，`-2.7335` 将被截断至 `-2`。

返回被除数 `dividend` 除以除数 `divisor` 得到的商。

**注意：** 假设我们的环境只能存储 32 位有符号整数，其数值范围是 `[−2^31, 2^31 − 1]`。本题中，如果商严格大于 `2^31 − 1`，则返回 `2^31 − 1`；如果商严格小于 `-2^31`，则返回 `-2^31`。

**示例 1：**
```
输入：dividend = 10, divisor = 3
输出：3
解释：10/3 = 3.33333.. ，向零截断后得到 3
```

**示例 2：**
```
输入：dividend = 7, divisor = -3
输出：-2
解释：7/-3 = -2.33333.. ，向零截断后得到 -2
```

**提示：**
- `-2^31 <= dividend, divisor <= 2^31 - 1`
- `divisor != 0`

## 解题思路

核心思想：用减法实现除法，但直接减法太慢，需要优化。

**优化方法：倍增法**
- 每次将除数翻倍（用位移实现）
- 找到最大的倍数不超过被除数
- 重复此过程处理剩余部分

## Python 代码实现

### 方法一：倍增法（推荐）

```python
class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        # 处理溢出情况
        INT_MIN, INT_MAX = -2**31, 2**31 - 1
        if dividend == INT_MIN and divisor == -1:
            return INT_MAX
        
        # 确定符号
        negative = (dividend < 0) != (divisor < 0)
        
        # 转为正数处理
        dividend, divisor = abs(dividend), abs(divisor)
        
        result = 0
        while dividend >= divisor:
            temp_divisor, count = divisor, 1
            # 找到最大的倍数
            while dividend >= (temp_divisor << 1):
                temp_divisor <<= 1
                count <<= 1
            
            # 减去这个倍数
            dividend -= temp_divisor
            result += count
        
        # 恢复符号
        return -result if negative else result
```

## 复杂度分析

- 时间复杂度：O(log^2 n)
- 空间复杂度：O(1)

## 关键点总结

1. **溢出处理**：特判 `-2^31 / -1` 的情况
2. **符号处理**：先记录符号，转正数处理，最后恢复
3. **倍增优化**：用位移代替乘法

## 易错点

1. **溢出**：`-2^31 / -1 = 2^31` 超出范围
2. **符号**：负数的处理
