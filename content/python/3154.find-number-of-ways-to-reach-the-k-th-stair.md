## 题目描述

给你有一个 **非负** 整数 `k`，你从楼梯第 1 阶出发，按照下面的规则操作：
- 操作 1：向下走一阶（不能连续使用两次，且不能在第 1 阶时使用）
- 操作 2：向上走 `2^jump` 阶，然后 `jump` 加 1（`jump` 初始为 0）

如果当前在第 `k` 阶，记录一次。

返回可以到达第 `k` 阶的次数。

**示例 1：**
```
输入：k = 0
输出：2
```

**示例 2：**
```
输入：k = 1
输出：4
```

**提示：**
- `0 <= k <= 10^9`

## 解题思路

设 `dp(i, jump, down)` 为当前在第 i 阶，已用 jump 次操作 2，上一步是否使用了操作 1（down）时到达 k 的方法数。

由于每次操作 2 向上 2^jump 步，jump 最大约 30（2^30 > 10^9），状态有限。

使用记忆化递归。

## Python 代码实现

### 方法一：记忆化递归（推荐）

```python
from functools import lru_cache

class Solution:
    def waysToReachStair(self, k: int) -> int:
        @lru_cache(maxsize=None)
        def dp(i: int, jump: int, down: bool) -> int:
            # 当前在第 i 阶，已执行 jump 次操作2，down 表示上一步是否向下
            if i > k + 1:
                return 0  # 超过 k+1 无法再回来

            ans = 1 if i == k else 0

            # 操作 2：向上 2^jump 阶
            ans += dp(i + (1 << jump), jump + 1, False)

            # 操作 1：向下一阶（不能连续，不能在第 1 阶以下）
            if not down and i > 0:
                ans += dp(i - 1, jump, True)

            return ans

        return dp(1, 0, False)
```

### 方法二：组合数学

```python
from math import comb

class Solution:
    def waysToReachStair(self, k: int) -> int:
        # 分析路径结构：
        # 执行 m 次操作 2（跳跃），可以在这些跳跃之间插入若干次操作 1（向下）
        # 向下操作数 <= m+1（每次跳跃前后各最多一次），且不能连续
        # 设向下 d 次，则最终位置 = 1 + sum(2^jump_i) - d
        # 需要 1 + sum(2^0..2^{m-1}) - d = k
        # 即 sum = 2^m - 1, 所以 1 + 2^m - 1 - d = k -> d = 2^m - k
        # 组合数：C(m+1, d) 选择哪些间隔插入向下操作

        ans = 0
        for m in range(31):  # m 次操作 2
            d = (1 << m) - k  # 需要向下 d 次，d = 2^m - k
            # 但 1 + 2^m - 1 - d = k，所以实际上 1 + (2^m - 1) - d = k
            # => d = 2^m - k
            if d < 0 or d > m + 1:
                continue
            ans += comb(m + 1, d)
        return ans
```

## 复杂度分析

- 时间复杂度：O(30)，m 最多 30
- 空间复杂度：O(1)

## 关键点总结

1. 操作 2 最多执行约 30 次（因为 2^30 > 10^9）
2. 枚举操作 2 的次数 m，推导需要向下操作的次数 d
3. 用组合数 C(m+1, d) 计算方案数

## 易错点

1. 1 + 2^m - 1 = 2^m，注意起始位置是第 1 阶
2. d < 0 或 d > m+1 时无效
