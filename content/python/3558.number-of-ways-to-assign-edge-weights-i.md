## 题目描述

给定一棵有 `n` 个节点的树，根节点为 `1`。需要为树的每条边分配权重（权重为 1 或 2），使得从根节点到任意叶节点的路径权重之和为奇数或偶数（可以按需求分配）。对于给定的若干查询 `(u, v)`（询问从 u 到 v 的路径），求有多少种边权分配方案使得路径长度为奇数，对 `10^9 + 7` 取模。

**示例：**

```
输入：n = 3, edges = [[1,2],[2,3]], queries = [[2,3],[1,3]]
输出：[1, 2]
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

树上路径奇偶性问题。

分析：路径 u 到 v 的长度的奇偶性 = 路径上边数的奇偶性（当权重只有1和2时，奇偶性由选1的边数决定）。

关键：树上任意路径通过 LCA 分解为两段。路径 u -> v 的边数 = dist(u, root) + dist(v, root) - 2 * dist(LCA, root)（边数距离）。

路径长度奇偶性：选1的边数之和的奇偶性，与整体边权分配方案相关。

更准确：树有 `n-1` 条边，路径上的边是其中一部分。不在路径上的边可以任意分配（2^(n-1-path_edges) 种），在路径上的边需要和为奇数（即选奇数个权重为1的边）的方案数乘以路径外的自由度。

对 `e` 条边的路径，权重和为奇数的分配方案数 = `2^(e-1)`（若 e > 0，否则 0）。

总方案 = `2^(e-1) * 2^(n-1-e)` = `2^(n-2)`（若 e > 0）。

## Python 代码实现

### 方法一：LCA 计算路径边数 + 数学（推荐）

```python
from typing import List
from collections import defaultdict
import math

class Solution:
    def assignEdgeWeights(self, n: int, edges: List[List[int]],
                           queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        LOG = max(1, math.ceil(math.log2(n + 1)))
        depth = [0] * (n + 1)
        parent = [[0] * (n + 1) for _ in range(LOG)]

        # BFS 建树
        from collections import deque
        queue = deque([1])
        visited = {1}
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if v not in visited:
                    visited.add(v)
                    depth[v] = depth[u] + 1
                    parent[0][v] = u
                    queue.append(v)

        # 二进制提升
        for k in range(1, LOG):
            for u in range(1, n+1):
                parent[k][u] = parent[k-1][parent[k-1][u]]

        def lca(u, v):
            if depth[u] < depth[v]:
                u, v = v, u
            diff = depth[u] - depth[v]
            for k in range(LOG):
                if diff >> k & 1:
                    u = parent[k][u]
            if u == v:
                return u
            for k in range(LOG-1, -1, -1):
                if parent[k][u] != parent[k][v]:
                    u, v = parent[k][u], parent[k][v]
            return parent[0][u]

        # 路径边数 = depth[u] + depth[v] - 2*depth[LCA]
        # 方案数：
        # 若 e = 0（u == v）：路径长度为 0，是偶数，无奇数方案，返回 0
        # 若 e > 0：在路径上 e 条边中，选奇数个1的方案数 = 2^(e-1)
        #           路径外 n-1-e 条边任意分配：2^(n-1-e) 种
        #           总方案 = 2^(e-1) * 2^(n-1-e) = 2^(n-2)

        result = []
        for u, v in queries:
            l = lca(u, v)
            e = depth[u] + depth[v] - 2 * depth[l]  # 路径边数
            if e == 0:
                result.append(0)
            else:
                result.append(pow(2, n - 2, MOD))

        return result
```

### 方法二：简化计算

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def assignEdgeWeights(self, n: int, edges: List[List[int]],
                           queries: List[List[int]]) -> List[int]:
        MOD = 10 ** 9 + 7
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        depth = [0] * (n + 1)
        parent = [0] * (n + 1)
        queue = deque([1])
        visited = {1}
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if v not in visited:
                    visited.add(v)
                    depth[v] = depth[u] + 1
                    parent[v] = u
                    queue.append(v)

        def lca_path(u, v):
            path_u, path_v = [], []
            while u != v:
                if depth[u] >= depth[v]:
                    path_u.append(u)
                    u = parent[u]
                else:
                    path_v.append(v)
                    v = parent[v]
            return len(path_u) + len(path_v)

        result = []
        for u, v in queries:
            e = lca_path(u, v)
            if e == 0:
                result.append(0)
            else:
                result.append(pow(2, n - 2, MOD))
        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n log n)

## 关键点总结

1. 路径边数大于 0 时，答案固定为 `2^(n-2)`（与路径边数无关）
2. 路径边数 = 0（u == v）时答案为 0
3. 路径上的边选奇数个 1 的方案数 * 路径外边任意分配 = `2^(e-1) * 2^(n-1-e) = 2^(n-2)`

## 易错点

1. n=2 时，n-2=0，答案为 `2^0 = 1`
2. u == v 时路径长度为 0（偶数），没有奇数方案
3. 需要对 `10^9 + 7` 取模
