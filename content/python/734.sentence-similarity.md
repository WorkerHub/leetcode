## 题目描述

给定两个句子 sentence1 和 sentence2，每个句子是一个字符串数组，表示一个句子中的单词。

同时给定一个字符串对的列表 similarPairs，其中 similarPairs[i] = [xi, yi] 表示两个单词 xi 和 yi 是相似的。

如果 sentence1 和 sentence2 相似则返回 true，否则返回 false。

## Python 代码实现

```python
from typing import List

class Solution:
    def areSentencesSimilar(self, sentence1: List[str], sentence2: List[str], similarPairs: List[List[str]]) -> bool:
        if len(sentence1) != len(sentence2):
            return False
        
        # 构建相似词对集合
        similar = set()
        for w1, w2 in similarPairs:
            similar.add((w1, w2))
            similar.add((w2, w1))
        
        # 检查每对单词
        for w1, w2 in zip(sentence1, sentence2):
            if w1 != w2 and (w1, w2) not in similar:
                return False
        
        return True
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(m)

## 关键点总结

1. 使用哈希集合存储相似词对
2. 逐个比较对应位置的单词
3. 相同单词或相似单词都满足条件
