## 题目描述

给你一个下标从 **0** 开始的二进制字符串 `s`，表示一列火车车厢。`s[i] = '0'` 表示第 `i` 节车厢**不含**违禁货物，`s[i] = '1'` 表示含有违禁货物。

每分钟可以执行以下操作之一：
- 从左端移除一节车厢（耗时 1 分钟）。
- 从右端移除一节车厢（耗时 1 分钟）。
- 移除任意一节含违禁货物的车厢（耗时 2 分钟）。

返回移除所有含违禁货物的车厢所需的**最少时间**。

**示例 1：**
```
输入：s = "1100101"
输出：5
解释：左端去掉前4节(4分钟)，再去掉第5节(1分钟)=5；或者...
```

**提示：**
- `1 <= s.length <= 2 * 10^5`

## 解题思路

**动态规划**

对于每个违禁车厢，有三种策略：
1. 从左端删除到它（代价 = 其左侧到头的长度）。
2. 从右端删除到它（代价 = 其右侧到尾的长度）。
3. 单独删除（每个耗时 2）。

设 `left[i]` = 清除 `s[0..i]` 中所有违禁货物的最小代价：
- `left[i] = left[i-1]`（若 `s[i] == '0'`，不需要额外操作）。
- `left[i] = min(i+1, left[i-1] + 2)`（若 `s[i] == '1'`，要么从左端删到 i，要么在之前基础上单独删）。

类似地，从右到左计算 `right[i]`。

最终答案 = `min(left[i] + right[i+1] for i in range(n))` + 边界情况。

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def minimumTime(self, s: str) -> int:
        n = len(s)
        # left[i]: 处理 s[0..i] 所有违禁车厢的最小代价
        left = [0] * n
        for i in range(n):
            if s[i] == '0':
                left[i] = left[i-1] if i > 0 else 0
            else:
                # 方法1：从左端删到 i（代价 i+1）
                # 方法2：在 left[i-1] 基础上单独删除 s[i]（代价 +2）
                prev = left[i-1] if i > 0 else 0
                left[i] = min(i + 1, prev + 2)

        # right[i]: 处理 s[i..n-1] 所有违禁车厢的最小代价
        right = [0] * n
        for i in range(n - 1, -1, -1):
            if s[i] == '0':
                right[i] = right[i+1] if i < n-1 else 0
            else:
                nxt = right[i+1] if i < n-1 else 0
                right[i] = min(n - i, nxt + 2)

        # 枚举分割点
        # 左侧由 left 处理，右侧由 right 处理
        ans = min(left[n-1], right[0])  # 全由左或右处理
        for i in range(n - 1):
            ans = min(ans, left[i] + right[i+1])

        return ans
```

### 方法二：简化版

```python
class Solution:
    def minimumTime(self, s: str) -> int:
        n = len(s)
        # dp_left[i] = 清除 s[0..i] 的最小代价
        dp = 0
        pre = [0] * n
        for i, c in enumerate(s):
            if c == '1':
                dp = min(i + 1, dp + 2)
            pre[i] = dp

        dp = 0
        ans = pre[-1]  # 全用左侧清除
        for i in range(n - 1, -1, -1):
            if s[i] == '1':
                dp = min(n - i, dp + 2)
            if i > 0:
                ans = min(ans, pre[i-1] + dp)
            else:
                ans = min(ans, dp)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n) | O(n) |

## 关键点总结

1. 预计算从左、从右清除的最优代价数组。
2. 枚举分割点，左边用 `left` 处理，右边用 `right` 处理，取最小。
3. 关键递推：`dp[i] = min(i+1, dp[i-1]+2)`（从左端删或单独删）。

## 易错点

- 分割点枚举包括全由左侧（分割在末尾）和全由右侧（分割在开头）。
- `left[i]` 表示 `s[0..i]`（闭区间），注意下标。
