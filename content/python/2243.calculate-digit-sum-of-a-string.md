## 题目描述

给你一个由数字组成的字符串 `s` 和一个整数 `k`。

每一轮操作，将 `s` 分成若干个长度为 `k` 的组（最后一组可能更短），将每组中所有数字求和，用这些和（转成字符串）拼接成新的字符串 `s`，直到 `s` 的长度不超过 `k`。

返回最终的字符串 `s`。

**示例 1：**
```
输入：s = "11111222223", k = 3
输出："135"
解释：
第1轮：[111,112,222,23] -> [3,4,6,5] -> "3465"
第2轮：[346,5] -> [13,5] -> "135"
长度3，满足条件，返回"135"。
```

**示例 2：**
```
输入：s = "00000000", k = 3
输出："000"
```

## 解题思路

模拟操作：每轮将字符串按 k 分组，每组各位数字求和（可能是多位数），拼成新字符串，重复直到长度 <= k。

## 代码实现

### 方法一：模拟循环（推荐）

```python
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        while len(s) > k:
            new_s = ""
            # 每次取 k 个字符，计算数字和
            for i in range(0, len(s), k):
                group = s[i:i + k]
                # 将该组所有字符（数字）求和
                total = sum(int(c) for c in group)
                new_s += str(total)
            s = new_s
        return s
```

### 方法二：函数式写法

```python
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        while len(s) > k:
            # 分组求和，每组最多 k 个字符
            s = "".join(
                str(sum(int(c) for c in s[i:i+k]))
                for i in range(0, len(s), k)
            )
        return s
```

## 复杂度分析

- 时间复杂度：O(n * log_k(n))，每轮将字符串长度缩减至约 n/k，共 log_k(n) 轮。
- 空间复杂度：O(n)，存储中间结果。

## 关键点总结

1. 模拟题，循环直到字符串长度不超过 k。
2. 每组的和可能是多位数（如 "999" 求和为 27），需转为字符串再拼接。
3. Python 切片处理边界（最后一组自动截断）。

## 易错点

- 每组是字符求和（每个字符是一个数字 0-9），不是将整组当作一个数。
- 组的和可能超过 9（多位数），所以直接用 `str(total)` 转换。
