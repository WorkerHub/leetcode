## 题目描述

请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（`push`、`pop`、`peek`、`empty`）：

实现 `MyQueue` 类：

- `void push(int x)` 将元素 x 推到队列的末尾
- `int pop()` 从队列的开头移除并返回元素
- `int peek()` 返回队列开头的元素
- `boolean empty()` 如果队列为空，返回 `true`；否则，返回 `false`

**说明：**
- 你只能使用标准的栈操作 —— 也就是只有 `push to top`、`peek/pop from top`、`size` 和 `is empty` 操作是合法的。
- 你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。

**示例 1：**
```
输入：
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]
输出：
[null, null, null, 1, 1, false]

解释：
MyQueue myQueue = new MyQueue();
myQueue.push(1); // queue is: [1]
myQueue.push(2); // queue is: [1, 2] (leftmost is front of the queue)
myQueue.peek(); // return 1
myQueue.pop(); // return 1, queue is [2]
myQueue.empty(); // return false
```

**提示：**
- `1 <= x <= 9`
- 最多调用 100 次 `push`、`pop`、`peek` 和 `empty`
- 假设所有操作都是有效的（例如，一个空的队列不会调用 `pop` 或者 `peek` 操作）

**进阶：** 你能否实现每个操作均摊时间复杂度为 O(1) 的队列？换句话说，执行 n 个操作的总时间复杂度为 O(n)，即使其中一个操作可能花费较长时间。

## 解题思路

**核心思想：使用两个栈来模拟队列的先进先出特性**

栈是后进先出（LIFO），队列是先进先出（FIFO）。我们需要用两个栈来"翻转"元素的顺序。

**两个栈的分工：**
1. **输入栈（input_stack）**：用于接收新元素
2. **输出栈（output_stack）**：用于输出元素

**关键操作：**
- `push`：直接压入输入栈
- `pop/peek`：
  - 如果输出栈不为空，直接从输出栈操作
  - 如果输出栈为空，将输入栈的所有元素倒入输出栈，再操作

**为什么这样做：**
- 输入栈：[1, 2, 3]（3 在栈顶）
- 倒入输出栈后：[3, 2, 1]（1 在栈顶）
- 此时从输出栈取出，就是队列的顺序

## Python 代码实现

### 方法一：双栈实现（推荐）⭐

```python
class MyQueue:
    """
    使用两个栈实现队列
    input_stack 负责接收新元素
    output_stack 负责输出元素
    """
    
    def __init__(self):
        self.input_stack = []   # 输入栈
        self.output_stack = []  # 输出栈

    def push(self, x: int) -> None:
        """
        将元素推入队列末尾
        直接压入输入栈即可
        时间复杂度：O(1)
        """
        self.input_stack.append(x)

    def pop(self) -> int:
        """
        从队列开头移除并返回元素
        时间复杂度：均摊 O(1)
        """
        # 确保输出栈有元素
        self._transfer()
        return self.output_stack.pop()

    def peek(self) -> int:
        """
        返回队列开头的元素
        时间复杂度：均摊 O(1)
        """
        # 确保输出栈有元素
        self._transfer()
        return self.output_stack[-1]

    def empty(self) -> bool:
        """
        判断队列是否为空
        时间复杂度：O(1)
        """
        return not self.input_stack and not self.output_stack
    
    def _transfer(self) -> None:
        """
        辅助方法：将输入栈的元素转移到输出栈
        只有在输出栈为空时才转移
        """
        if not self.output_stack:
            while self.input_stack:
                self.output_stack.append(self.input_stack.pop())
```

### 方法二：简化版（不封装转移逻辑）

```python
class MyQueue:
    
    def __init__(self):
        self.input_stack = []
        self.output_stack = []

    def push(self, x: int) -> None:
        self.input_stack.append(x)

    def pop(self) -> int:
        # 如果输出栈为空，将输入栈元素全部转移
        if not self.output_stack:
            while self.input_stack:
                self.output_stack.append(self.input_stack.pop())
        return self.output_stack.pop()

    def peek(self) -> int:
        # 如果输出栈为空，将输入栈元素全部转移
        if not self.output_stack:
            while self.input_stack:
                self.output_stack.append(self.input_stack.pop())
        return self.output_stack[-1]

    def empty(self) -> bool:
        return not self.input_stack and not self.output_stack
```

### 方法三：每次 pop/peek 都转移（不推荐）

```python
class MyQueue:
    """
    每次 pop 或 peek 都进行转移
    效率较低，不符合均摊 O(1) 的要求
    """
    
    def __init__(self):
        self.stack = []

    def push(self, x: int) -> None:
        self.stack.append(x)

    def pop(self) -> int:
        # 创建临时栈
        temp = []
        # 将所有元素倒入临时栈
        while self.stack:
            temp.append(self.stack.pop())
        # 取出第一个元素（队列头）
        result = temp.pop()
        # 将剩余元素倒回
        while temp:
            self.stack.append(temp.pop())
        return result

    def peek(self) -> int:
        temp = []
        while self.stack:
            temp.append(self.stack.pop())
        result = temp[-1]
        while temp:
            self.stack.append(temp.pop())
        return result

    def empty(self) -> bool:
        return not self.stack
```

## 复杂度分析

**方法一（双栈优化版）：**

- `push` 操作：
  - 时间复杂度：O(1)
  - 空间复杂度：O(1)

- `pop/peek` 操作：
  - 时间复杂度：均摊 O(1)
  - 最坏情况：O(n)（需要转移所有元素）
  - 但每个元素最多被转移一次，所以均摊是 O(1)
  - 空间复杂度：O(1)

- `empty` 操作：
  - 时间复杂度：O(1)
  - 空间复杂度：O(1)

- 总空间复杂度：O(n)，n 为队列中的元素个数

**均摊分析：**
- 每个元素最多被移动 2 次（从输入栈到输出栈 1 次，从输出栈弹出 1 次）
- n 个操作的总时间是 O(n)
- 因此均摊时间复杂度是 O(1)

## 关键点总结

1. **两个栈的分工明确**：输入栈负责接收，输出栈负责输出
2. **懒加载策略**：只有在输出栈为空时才转移元素
3. **均摊复杂度**：每个元素最多转移一次，所以均摊 O(1)
4. **避免重复转移**：不要每次 pop/peek 都转移，会导致 O(n) 复杂度
5. **空队列判断**：两个栈都为空才是真正的空

## 易错点

1. **每次都转移元素**：
   ```python
   # 错误：每次 pop 都转移，时间复杂度 O(n)
   def pop(self):
       while self.input_stack:
           self.output_stack.append(self.input_stack.pop())
       return self.output_stack.pop()
   
   # 正确：只在输出栈为空时转移
   def pop(self):
       if not self.output_stack:
           while self.input_stack:
               self.output_stack.append(self.input_stack.pop())
       return self.output_stack.pop()
   ```

2. **忘记检查输出栈**：
   ```python
   # 错误：没有检查输出栈
   def empty(self):
       return not self.input_stack
   
   # 正确：两个栈都要检查
   def empty(self):
       return not self.input_stack and not self.output_stack
   ```

3. **peek 和 pop 代码重复**：可以提取公共方法 `_transfer()`

4. **理解均摊复杂度**：不要认为最坏情况是 O(n) 就不是 O(1)
