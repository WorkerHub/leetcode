## 题目描述

给你一个整数数组 `nums`，返回数组中最小的两个元素（按升序排列）。若数组元素少于 2 个，返回所有元素。

**示例 1：**

```
输入：nums = [3,1,4,1,5,9]
输出：[1,1]
```

**示例 2：**

```
输入：nums = [5]
输出：[5]
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

排序后取前两个，或者线性扫描找最小和次小。

## Python 代码实现

### 方法一：排序（推荐）

```python
from typing import List

class Solution:
    def findFirstTwo(self, nums: List[int]) -> List[int]:
        return sorted(nums)[:2]
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def findFirstTwo(self, nums: List[int]) -> List[int]:
        first = second = float('inf')
        for x in nums:
            if x <= first:
                second = first
                first = x
            elif x < second:
                second = x

        result = [first]
        if second != float('inf'):
            result.append(second)
        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)（方法一），O(n)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 允许重复元素（两个最小可能相同）
2. 线性扫描维护最小和次小

## 易错点

1. 相同值的两个元素也算两个（如 `[1,1]` 返回 `[1,1]`）
2. 只有一个元素时返回一个元素的列表
