## 题目描述

给你两个整数数组 `arr1` 和 `arr2`，返回使 `arr1` 严格递增所需要的最小「操作」数（可能为 0）。

每一步「操作」中，你可以分别从 `arr1` 和 `arr2` 中各选出一个索引，分别为 `i` 和 `j`，`0 <= i < arr1.length` 和 `0 <= j < arr2.length`，然后进行赋值运算 `arr1[i] = arr2[j]`。

如果无法让 `arr1` 严格递增，请返回 `-1`。

**示例 1：**
```
输入：arr1 = [1,5,3,6,7], arr2 = [1,3,2,4]
输出：1
解释：用 2 替换 5，使 arr1 = [1,2,3,6,7]。
```

**示例 2：**
```
输入：arr1 = [1,5,3,6,7], arr2 = [4,3,1]
输出：2
解释：用 3 替换 5，用 4 替换 3，使 arr1 = [1,3,4,6,7]。
```

**示例 3：**
```
输入：arr1 = [1,5,3,6,7], arr2 = [1,6,3,3]
输出：-1
解释：无法使 arr1 严格递增。
```

**提示：**
- `1 <= arr1.length, arr2.length <= 2000`
- `0 <= arr1[i], arr2[i] <= 10^9`

## 解题思路

这道题是一个经典的动态规划问题，需要结合二分查找进行优化。

**核心思路：**

1. **状态定义**：定义 `dp[i][j]` 表示处理到 `arr1[i]` 位置时，已经进行了 `j` 次替换操作，且 `arr1[i]` 的值最小是多少。

2. **状态转移**：对于每个位置 `i`，我们有两种选择：
   - 不替换：如果 `arr1[i]` 大于前一个位置的值，则可以保留
   - 替换：从 `arr2` 中选择一个大于前一个位置值的最小元素

3. **优化技巧**：
   - 对 `arr2` 排序并去重，便于二分查找
   - 使用哈希表存储状态，避免无效的状态转移
   - 只需要关注最小的替换次数和对应的值

## Python 代码实现

### 方法一：动态规划 + 二分查找（推荐）⭐

```python
from typing import List
import bisect

class Solution:
    def makeArrayIncreasing(self, arr1: List[int], arr2: List[int]) -> int:
        # 对 arr2 排序并去重，便于二分查找
        arr2 = sorted(set(arr2))
        
        # dp[i] 表示当前位置的值为 i 时，所需的最小操作次数
        # 初始状态：位置 -1 的值为 -1，操作次数为 0
        dp = {-1: 0}
        
        # 遍历 arr1 的每个元素
        for num in arr1:
            new_dp = {}
            
            # 遍历上一步的所有状态
            for prev_val, operations in dp.items():
                # 情况1：不替换当前元素
                if num > prev_val:
                    # 更新状态：选择操作次数更小的
                    if num not in new_dp or new_dp[num] > operations:
                        new_dp[num] = operations
                
                # 情况2：替换当前元素
                # 在 arr2 中二分查找第一个大于 prev_val 的元素
                idx = bisect.bisect_right(arr2, prev_val)
                if idx < len(arr2):
                    replace_val = arr2[idx]
                    # 更新状态：操作次数加 1
                    if replace_val not in new_dp or new_dp[replace_val] > operations + 1:
                        new_dp[replace_val] = operations + 1
            
            dp = new_dp
        
        # 返回所有状态中操作次数的最小值
        return min(dp.values()) if dp else -1
```

### 方法二：记忆化搜索

```python
from typing import List
import bisect
from functools import lru_cache

class Solution:
    def makeArrayIncreasing(self, arr1: List[int], arr2: List[int]) -> int:
        arr2 = sorted(set(arr2))
        
        @lru_cache(None)
        def dfs(i: int, prev: int) -> int:
            """
            递归搜索从位置 i 开始，前一个值为 prev 时的最小操作次数
            返回 -1 表示无法完成
            """
            # 基础情况：已经处理完所有元素
            if i == len(arr1):
                return 0
            
            res = float('inf')
            
            # 情况1：不替换当前元素
            if arr1[i] > prev:
                sub_res = dfs(i + 1, arr1[i])
                if sub_res != -1:
                    res = min(res, sub_res)
            
            # 情况2：替换当前元素
            idx = bisect.bisect_right(arr2, prev)
            if idx < len(arr2):
                sub_res = dfs(i + 1, arr2[idx])
                if sub_res != -1:
                    res = min(res, sub_res + 1)
            
            return res if res != float('inf') else -1
        
        result = dfs(0, -1)
        return result if result != -1 else -1
```

## 复杂度分析

**方法一：动态规划 + 二分查找**
- **时间复杂度**：O(n × m × log m)，其中 n 是 `arr1` 的长度，m 是 `arr2` 去重后的长度。每个位置最多有 m 种状态，每次二分查找需要 O(log m)。
- **空间复杂度**：O(m)，存储 dp 状态的空间。

**方法二：记忆化搜索**
- **时间复杂度**：O(n × m × log m)
- **空间复杂度**：O(n × m)，递归调用栈和缓存空间。

## 关键点总结

1. **动态规划状态设计**：使用哈希表存储「当前值-最小操作次数」的映射，而不是传统的二维数组
2. **二分查找优化**：对 `arr2` 排序后使用二分查找，快速找到可替换的最小值
3. **去重优化**：`arr2` 中的重复元素是无意义的，去重可以减少状态数
4. **状态转移**：每个位置有两种选择（保留或替换），需要取最优解
5. **边界处理**：使用 `-1` 作为初始的前驱值，确保第一个元素可以正常处理

## 易错点

1. **忘记对 arr2 去重**：重复元素会导致状态冗余，影响效率
2. **二分查找边界错误**：需要使用 `bisect_right` 找到严格大于的元素
3. **状态更新顺序**：必须使用新的 dp 字典，不能在原 dp 上修改
4. **无解判断**：如果某一步的 dp 为空，说明无法继续，应返回 -1
5. **初始化错误**：初始状态应该是 `{-1: 0}`，表示前一个值为 -1，操作次数为 0
