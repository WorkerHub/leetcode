## 题目描述

一开始账户余额为 100。给你一个整数 `purchaseAmount`，代表你购买商品的费用。

商店使用如下舍入规则：
- 如果 `purchaseAmount` 的最后一位（个位）在 [1, 4] 之间，则向下取整到最近的 10 的倍数
- 如果 `purchaseAmount` 的最后一位在 [5, 9] 之间，则向上取整到最近的 10 的倍数

即：将 `purchaseAmount` 四舍五入到最近的 10 的整数倍（5 向上舍入）。

返回购买后账户的余额。

**示例 1：**
```
输入：purchaseAmount = 9
输出：90
解释：9 四舍五入到最近的 10 -> 10，余额 = 100 - 10 = 90
```

**示例 2：**
```
输入：purchaseAmount = 15
输出：80
解释：15 四舍五入到最近的 10 -> 20，余额 = 100 - 20 = 80
```

**提示：**
- `0 <= purchaseAmount <= 100`

## 解题思路

将 `purchaseAmount` 按照以下规则取整到最近的 10 的倍数：
- 个位在 1-4：向下取整（`(purchaseAmount // 10) * 10`）
- 个位在 5-9：向上取整（`(purchaseAmount // 10 + 1) * 10`）
- 个位为 0：不变

等价于 `round(purchaseAmount / 10) * 10`，但需要注意 Python 的 `round()` 使用银行家舍入（向偶数舍入），即 `round(5)` 可能向下舍入。

更安全的写法是：`(purchaseAmount + 5) // 10 * 10`（5 向上舍入）。

## Python 代码实现

### 方法一：数学计算（推荐）

```python
class Solution:
    def accountBalanceAfterPurchase(self, purchaseAmount: int) -> int:
        # 将购买金额四舍五入到最近的 10 的整数倍
        # (purchaseAmount + 5) // 10 * 10 确保 5 向上舍入
        rounded = (purchaseAmount + 5) // 10 * 10
        return 100 - rounded
```

### 方法二：取模判断

```python
class Solution:
    def accountBalanceAfterPurchase(self, purchaseAmount: int) -> int:
        remainder = purchaseAmount % 10  # 取个位数字
        if remainder < 5:
            # 向下取整：去掉个位
            rounded = purchaseAmount - remainder
        else:
            # 向上取整：补到下一个 10 的倍数
            rounded = purchaseAmount + (10 - remainder)
        return 100 - rounded
```

### 方法三：一行写法

```python
class Solution:
    def accountBalanceAfterPurchase(self, purchaseAmount: int) -> int:
        # 注意：Python 的 round() 是银行家舍入，round(25) = 24（向偶数舍入）
        # 所以不能直接用 round(purchaseAmount, -1)
        # 正确做法是手动实现"四舍五入"
        return 100 - ((purchaseAmount + 5) // 10 * 10)
```

## 复杂度分析

- 时间复杂度：O(1)，只需常数次运算
- 空间复杂度：O(1)

## 关键点总结

1. 将数字四舍五入到 10 的倍数：`(n + 5) // 10 * 10`
2. `purchaseAmount % 10 < 5` 向下取整，否则向上取整
3. Python 内置 `round()` 使用银行家舍入，对 5 可能向下，不适用于本题

## 易错点

1. 直接使用 `round(purchaseAmount, -1)` 是错误的，因为银行家舍入规则与题目不符
2. 例如 `round(25)` 在 Python 中返回 24（向偶数），而题目要求返回 30
