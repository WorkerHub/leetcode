## 题目描述

给你一个数组 `favoriteCompanies`，其中 `favoriteCompanies[i]` 是第 `i` 名用户收藏的公司清单（下标从 0 开始）。

找出不是其他任何人收藏的公司清单的**子集**的收藏清单，并以列表形式返回这些清单对应的下标。返回的答案需按升序排列。

**示例 1：**
```
输入：favoriteCompanies = [["leetcode","google","facebook"],["google","microsoft"],["google","facebook"],["google"],["amazon"]]
输出：[0,1,4]
解释：
- favoriteCompanies[2] = ["google","facebook"] 是 favoriteCompanies[0] 的子集。
- favoriteCompanies[3] = ["google"] 是 favoriteCompanies[0]、favoriteCompanies[1]、favoriteCompanies[2] 的子集。
- 其他的收藏清单不是其他人收藏清单的子集。
```

**示例 2：**
```
输入：favoriteCompanies = [["leetcode","google","facebook"],["leetcode","amazon"],["facebook","google"]]
输出：[0,1,2]
解释：三个清单互不为子集。
```

**示例 3：**
```
输入：favoriteCompanies = [["leetcode"],["google"],["facebook"],["amazon"]]
输出：[0,1,2,3]
```

**提示：**
- `1 <= favoriteCompanies.length <= 100`
- `1 <= favoriteCompanies[i].length <= 500`
- `1 <= favoriteCompanies[i][j].length <= 20`
- 每个公司名字只由小写英文字母组成
- 同一个用户的收藏清单内不会存在重复元素
- 所有用户的收藏清单合并后也不包含重复元素（即公司名字在所有清单中唯一）

## 解题思路

**核心思路：集合的子集判断**

将每个用户的公司列表转换为集合，然后对每个用户 `i` 检查：是否存在另一个用户 `j`（`j != i`），使得 `set[i]` 是 `set[j]` 的子集。

- 若不存在这样的 `j`，则下标 `i` 加入答案
- Python 集合提供了内置的 `issubset()` 方法或 `<=` 运算符，可以直接使用

**优化思路：**

由于公司名是全局唯一的（题目保证），可以将公司名映射为整数 ID，然后用整数集合加速比较（但此题数据规模小，字符串集合也足够）。

## Python 代码实现

### 方法一：集合 + 双重遍历（推荐）

```python
from typing import List

class Solution:
    def peopleIndexes(self, favoriteCompanies: List[List[str]]) -> List[int]:
        n = len(favoriteCompanies)
        # 将每个用户的公司列表转为集合，方便子集判断
        sets = [set(companies) for companies in favoriteCompanies]

        result = []
        for i in range(n):
            is_subset = False
            for j in range(n):
                if i == j:
                    continue
                # 检查 sets[i] 是否是 sets[j] 的子集（且不相等）
                # issubset 包括等集的情况，用 <= 也可以
                if sets[i] <= sets[j] and sets[i] != sets[j]:
                    is_subset = True
                    break
                # 也可以用 sets[i] < sets[j]，严格子集（自动排除相等情况）
                # 但题目说公司名唯一，两用户清单不会完全相同
            if not is_subset:
                result.append(i)

        return result
```

### 方法二：使用 issubset 方法（更清晰）

```python
from typing import List

class Solution:
    def peopleIndexes(self, favoriteCompanies: List[List[str]]) -> List[int]:
        n = len(favoriteCompanies)
        sets = [set(companies) for companies in favoriteCompanies]

        result = []
        for i in range(n):
            # 检查是否存在某个 j 使得 sets[i] 是 sets[j] 的真子集
            if not any(sets[i] < sets[j] for j in range(n) if i != j):
                result.append(i)

        return sorted(result)  # 题目要求升序，但 i 本来就是升序枚举的
```

### 方法三：公司名映射为整数集合（优化版）

```python
from typing import List

class Solution:
    def peopleIndexes(self, favoriteCompanies: List[List[str]]) -> List[int]:
        # 将所有公司名映射为唯一整数 ID
        company_to_id = {}
        idx = 0
        for companies in favoriteCompanies:
            for c in companies:
                if c not in company_to_id:
                    company_to_id[c] = idx
                    idx += 1

        # 转换为整数集合
        sets = [frozenset(company_to_id[c] for c in companies)
                for companies in favoriteCompanies]

        result = []
        n = len(sets)
        for i in range(n):
            # any() 短路求值：一旦找到超集就停止
            if not any(sets[i] < sets[j] for j in range(n) if i != j):
                result.append(i)

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 × m)，n 为用户数，m 为平均清单长度。集合子集判断需要 O(min(|A|, |B|))，最坏 O(m)
- 空间复杂度：O(n × m)，存储所有集合

## 关键点总结

1. 将列表转为集合是子集判断的关键操作
2. Python 集合的 `<` 运算符表示**真子集**（严格子集），`<=` 表示子集（含相等）
3. `any()` 配合生成器表达式可以实现短路求值，找到一个就停止
4. 题目保证公司名全局唯一，所以两个不同用户的清单不会完全相同

## 易错点

- 注意是"严格子集"：清单 A 是清单 B 的子集且 A ≠ B。用 `<` 而不是 `<=`
- 不要忘记跳过 `i == j` 的情况（不与自身比较）
- 答案要求升序，由于我们按序枚举 `i`，结果天然有序
