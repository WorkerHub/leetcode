## 题目描述

作为守护者，你需要从 `strength` 数组中选出若干连续子数组，子数组的**强度**定义为：子数组最小值 * 子数组所有元素之和。

返回所有**非空**子数组的强度之和，对 `10^9 + 7` 取模。

**示例 1：**
```
输入：strength = [1,3,1,2]
输出：44
```

**示例 2：**
```
输入：strength = [5,4,6]
输出：213
```

## 解题思路

**单调栈 + 前缀和的前缀和：**

对于每个元素 `strength[i]`，计算以它为最小值的所有子数组的贡献。

设 `left[i]` 为左边第一个严格小于 `strength[i]` 的下标（无则为 -1），`right[i]` 为右边第一个小于等于 `strength[i]` 的下标（无则为 n）。

以 `strength[i]` 为最小值的子数组：左端点 `l ∈ (left[i], i]`，右端点 `r ∈ [i, right[i])`。

贡献 = `strength[i] * sum(sum(strength[l..r]))`，其中 l,r 遍历所有合法组合。

展开：`sum(strength[l..r]) = prefix[r+1] - prefix[l]`

`sum over l,r = sum_r(prefix[r+1]) * (i - left[i]) - sum_l(prefix[l]) * (right[i] - i)`

用前缀和的前缀和 `pp` 快速求这两项。

## 代码实现

### 方法一：单调栈 + 前缀和的前缀和（推荐）

```python
from typing import List

class Solution:
    def totalStrength(self, strength: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(strength)

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + strength[i]

        # 前缀和的前缀和
        pp = [0] * (n + 2)
        for i in range(n + 1):
            pp[i + 1] = pp[i] + prefix[i]

        ans = 0
        stack = []  # 单调递增栈（存下标）

        for i in range(n + 1):
            # 当栈顶元素 >= 当前值时弹出（处理右边界）
            while stack and (i == n or strength[stack[-1]] >= strength[i]):
                mid = stack.pop()
                left = stack[-1] if stack else -1
                right = i

                # 以 strength[mid] 为最小值
                # 左边有 mid - left 个左端点选择，右边有 right - mid 个右端点选择
                # sum of prefix[r+1] for r in [mid, right-1]: pp[right+1] - pp[mid+1]
                # sum of prefix[l] for l in [left+1, mid]: pp[mid+1] - pp[left+1]
                left_cnt = mid - left      # 左边可选个数
                right_cnt = right - mid   # 右边可选个数

                total = (
                    right_cnt * (pp[mid + 1] - pp[left + 1])
                    - left_cnt * (pp[right + 1] - pp[mid + 1])
                ) % MOD

                ans = (ans + strength[mid] * total) % MOD

            stack.append(i)

        return ans % MOD
```

### 方法二：暴力枚举（用于验证，O(n^3)）

```python
from typing import List

class Solution:
    def totalStrength(self, strength: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(strength)
        ans = 0
        for l in range(n):
            min_val = strength[l]
            total = 0
            for r in range(l, n):
                min_val = min(min_val, strength[r])
                total += strength[r]
                ans = (ans + min_val * total) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，单调栈每个元素入栈出栈各一次。
- 空间复杂度：O(n)，前缀和数组和栈。

## 关键点总结

1. 枚举每个元素作为子数组最小值，用单调栈确定其作用范围。
2. 前缀和的前缀和 `pp` 能 O(1) 计算区间内所有前缀和之和。
3. 注意左边界用严格小于（避免重复），右边界用小于等于（处理相等）。

## 易错点

- 取模时乘法可能溢出，Python 无此问题，但需对结果取模。
- `pp` 数组大小要比 `prefix` 多一位，注意下标关系。
- 右边界处理 `i == n` 表示虚拟哨兵，清理栈中剩余元素。
