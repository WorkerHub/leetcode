## 题目描述

给你一个由某个升序数组旋转后得到的整数数组 `nums`（无重复元素）和目标值 `target`，返回目标值在数组中的下标，若不存在返回 -1。

**示例 1：**

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**提示：**

- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中每个值唯一
- `nums` 是某个升序数组旋转一次得到的

## 解题思路

二分查找：通过比较 `nums[mid]` 和 `nums[left]`/`nums[right]` 判断哪半部分有序。

- 若 `nums[left] <= nums[mid]`：左半部分有序
  - 若 `nums[left] <= target < nums[mid]`：在左半部分查找
  - 否则在右半部分
- 否则右半部分有序
  - 若 `nums[mid] < target <= nums[right]`：在右半部分
  - 否则在左半部分

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1

        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid

            # 左半部分有序
            if nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                # 右半部分有序
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1
```

### 方法二：先找旋转点再二分

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        n = len(nums)
        # 找旋转点
        lo, hi = 0, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] > nums[hi]:
                lo = mid + 1
            else:
                hi = mid
        pivot = lo  # 最小元素下标

        # 二分
        left = pivot if target <= nums[-1] else 0
        right = pivot - 1 if target <= nums[-1] else pivot - 1 + n

        left = pivot if target <= nums[n - 1] else 0
        right = (pivot - 1) % n if pivot > 0 else n - 1

        lo, hi = 0, n - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            real_mid = (mid + pivot) % n
            if nums[real_mid] == target:
                return real_mid
            elif nums[real_mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return -1
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 旋转数组每次二分后，至少一半是有序的
2. 通过比较端点值判断哪半部分有序
3. 在有序半部分用常规二分逻辑

## 易错点

1. 边界条件：`nums[left] <= nums[mid]`（包含等号）
2. 判断 target 在有序半部分时需用严格不等号
3. 无重复元素是此算法的前提
