## 题目描述

给你两个整数数组 `nums` 和 `divisors`。`divisors[i]` 的可整除性分数等于 `nums` 中能被 `divisors[i]` 整除的元素个数。

返回可整除性分数最大的 `divisors[i]`，若多个元素得分相同，返回其中最小的。

**示例 1：**
```
输入：nums = [4,7,9,3,9], divisors = [5,2,3]
输出：3
解释：
- 5 能整除 nums 中的 0 个元素，分数 0
- 2 能整除 4，分数 1
- 3 能整除 9,3,9，分数 3
最大分数 3，对应 divisors[2] = 3
```

**示例 2：**
```
输入：nums = [20,14,21,10], divisors = [5,7,5]
输出：5
解释：5 的分数为 3（20,10），7 的分数也为 3（14,21），5 < 7，返回 5
```

**数据范围：**
- 1 <= nums.length, divisors.length <= 1000
- 1 <= nums[i], divisors[i] <= 10^9

## 解题思路

遍历每个除数，统计 `nums` 中能被整除的元素个数，维护最大分数和对应的最小除数。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def maxDivScore(self, nums: List[int], divisors: List[int]) -> int:
        best_score = -1
        best_div = float('inf')

        for d in divisors:
            score = sum(1 for x in nums if x % d == 0)
            if score > best_score or (score == best_score and d < best_div):
                best_score = score
                best_div = d

        return best_div
```

### 方法二：排序后遍历

```python
from typing import List

class Solution:
    def maxDivScore(self, nums: List[int], divisors: List[int]) -> int:
        # 去重并排序，保证同分数时返回最小除数
        ans = min(divisors)  # 初始化为最小除数
        max_score = sum(1 for x in nums if x % ans == 0)

        for d in sorted(set(divisors)):
            score = sum(1 for x in nums if x % d == 0)
            if score > max_score:
                max_score = score
                ans = d

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为 nums 长度，m 为 divisors 长度
- 空间复杂度：O(1)

## 关键点总结

1. 分数为 nums 中能被 d 整除的元素数
2. 分数相同时返回最小的除数
3. 注意更新条件：`score > best_score` 或 `score == best_score and d < best_div`

## 易错点

1. 相同分数时返回最小除数，不是最大除数
2. 可以有多个相同值的 divisors，不影响结果
