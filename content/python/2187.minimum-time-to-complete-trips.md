## 题目描述

给你一个数组 `time`，其中 `time[i]` 表示第 `i` 辆公交车完成**一趟行程**所需的时间。每辆公交车可以**连续**完成多趟行程，即一辆公交车完成一趟行程后，可以立马开始下一趟行程。

同时给你一个整数 `totalTrips`，表示需要完成的**总行程数**。返回完成至少 `totalTrips` 趟行程需要花费的**最少**时间。

**示例 1：**
```
输入：time = [1,2,3], totalTrips = 5
输出：3
解释：t=3 时：
- 第一辆完成 3 趟 (3/1=3)
- 第二辆完成 1 趟 (3/2=1)
- 第三辆完成 1 趟 (3/3=1)
总计 5 趟。
```

**示例 2：**
```
输入：time = [2], totalTrips = 1
输出：2
```

**提示：**
- `1 <= time.length <= 10^5`
- `1 <= time[i], totalTrips <= 10^7`

## 解题思路

**二分查找答案**

答案单调：时间越多，完成行程数越多。对时间 `t` 做二分：

- 可行性判断：在时间 `t` 内，每辆公交 `i` 能完成 `t // time[i]` 趟，总计是否 `>= totalTrips`。

二分范围：`[1, max(time) * totalTrips]`（最慢情况：只用最慢的车完成所有行程）。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, time: List[int], totalTrips: int) -> int:
        def can_finish(t: int) -> bool:
            # 在时间 t 内能否完成 totalTrips 趟
            trips = sum(t // ti for ti in time)
            return trips >= totalTrips

        lo, hi = 1, min(time) * totalTrips  # 上界：最快的车完成全部行程
        while lo < hi:
            mid = (lo + hi) // 2
            if can_finish(mid):
                hi = mid  # 尝试更少的时间
            else:
                lo = mid + 1
        return lo
```

### 方法二：使用 bisect 库

```python
from typing import List
import bisect

class Solution:
    def minimumTime(self, time: List[int], totalTrips: int) -> int:
        def trips_at(t: int) -> int:
            return sum(t // ti for ti in time)

        lo, hi = 1, min(time) * totalTrips
        # 找最小的 t 使得 trips_at(t) >= totalTrips
        # 等价于：在 [lo, hi] 中找第一个满足条件的位置
        while lo < hi:
            mid = (lo + hi) >> 1
            if trips_at(mid) >= totalTrips:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(n * log(min_t * totalTrips)) | O(1) |

## 关键点总结

1. 答案具有单调性：时间越长，完成的行程数越多。
2. 可行性判断：时间 `t` 内每辆车能完成 `t // time[i]` 趟，求总和是否达标。
3. 二分上界取 `min(time) * totalTrips`（最快的车单独跑完所有行程）。

## 易错点

- 二分上界不能太大（避免溢出或超时），用最快车的时间作为上界即可。
- 注意整除运算：在时间 `t` 内完成的趟数是 `t // time[i]`（不是四舍五入）。
