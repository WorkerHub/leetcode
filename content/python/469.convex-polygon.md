## 题目描述

给定一个按顺序连接的多边形的顶点，判断该多边形是否为凸多边形。

**注意：**
1. 顶点个数至少为 3 个且不超过 10000。
2. 坐标范围为 -10000 到 10000。
3. 你可以假定给定的点形成的多边形均为简单多边形（简单多边形的定义）。换句话说，保证每个顶点处恰好是两条边的连接点，并且这些边互不相交。

**示例 1：**
```
输入：points = [[0,0],[0,5],[5,5],[5,0]]
输出：true
```

**示例 2：**
```
输入：points = [[0,0],[0,10],[10,10],[10,0],[5,5]]
输出：false
```

## 解题思路

判断凸多边形的核心是**叉积（Cross Product）**。

**凸多边形性质：**
- 所有内角都小于 180 度
- 或者说：沿边界行走时，始终向同一方向转（全部左转或全部右转）

**数学原理：**
- 使用向量叉积判断转向
- 对于三个连续点 A, B, C：
  - 向量 AB = (B.x - A.x, B.y - A.y)
  - 向量 BC = (C.x - B.x, C.y - B.y)
  - 叉积 = AB.x × BC.y - AB.y × BC.x
  - 叉积 > 0：左转（逆时针）
  - 叉积 < 0：右转（顺时针）
  - 叉积 = 0：共线

**判断凸多边形：**
- 遍历所有连续三个点
- 计算叉积
- 如果所有叉积符号相同（全正或全负），则为凸多边形
- 允许叉积为 0（共线的情况）

## Python 代码实现

### 方法一：叉积法（推荐）⭐

```python
from typing import List

class Solution:
    def isConvex(self, points: List[List[int]]) -> bool:
        n = len(points)
        
        # 记录叉积的符号（正、负或零）
        sign = 0
        
        for i in range(n):
            # 三个连续的点（循环）
            p1 = points[i]
            p2 = points[(i + 1) % n]
            p3 = points[(i + 2) % n]
            
            # 计算向量 p1->p2 和 p2->p3 的叉积
            cross = self.crossProduct(p1, p2, p3)
            
            if cross != 0:  # 忽略共线的情况
                # 检查符号是否一致
                if sign == 0:
                    sign = cross  # 记录第一个非零叉积的符号
                elif sign * cross < 0:  # 符号不一致
                    return False
        
        return True
    
    def crossProduct(self, p1, p2, p3):
        """计算向量 p1->p2 和 p2->p3 的叉积"""
        # 向量 p1->p2
        v1_x = p2[0] - p1[0]
        v1_y = p2[1] - p1[1]
        
        # 向量 p2->p3
        v2_x = p3[0] - p2[0]
        v2_y = p3[1] - p2[1]
        
        # 叉积
        return v1_x * v2_y - v1_y * v2_x
```

### 方法二：简化版

```python
from typing import List

class Solution:
    def isConvex(self, points: List[List[int]]) -> bool:
        n = len(points)
        prev = 0  # 记录前一个叉积的符号
        
        for i in range(n):
            # 计算叉积
            dx1 = points[(i+1) % n][0] - points[i][0]
            dy1 = points[(i+1) % n][1] - points[i][1]
            dx2 = points[(i+2) % n][0] - points[(i+1) % n][0]
            dy2 = points[(i+2) % n][1] - points[(i+1) % n][1]
            
            cross = dx1 * dy2 - dy1 * dx2
            
            if cross != 0:
                # 检查符号一致性
                if cross * prev < 0:
                    return False
                prev = cross
        
        return True
```

- 时间复杂度：O(n)，n 是顶点数
- 空间复杂度：O(1)

## 关键点总结

1. **叉积判断转向：** 正负表示左转/右转
2. **符号一致性：** 所有叉积符号相同
3. **处理共线：** 叉积为 0 时忽略
4. **循环处理：** 使用模运算处理边界
5. **简单多边形假设：** 边不相交

## 易错点

1. **忘记循环：** 最后几个点也要检查
   ```python
   # 正确：使用模运算
   points[(i + 2) % n]
   ```

2. **叉积为零的处理：** 共线点不影响凸性
   ```python
   if cross != 0:
       # 只检查非零叉积
   ```

3. **符号判断：** 使用乘积判断符号
   ```python
   if sign * cross < 0:  # 符号相反
       return False
   ```
