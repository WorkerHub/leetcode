## 题目描述

给定一个按升序排列的整数数组 `nums`，其中 `nums` 中的数字都是唯一的。

在 `nums` 数组的某些位置上，一些数字缺失了。返回从数组最左侧数字开始的第 `k` 个缺失数字。

**示例 1：**
```
输入：nums = [4,7,9,10], k = 1
输出：5
解释：第一个缺失的数字是 5。
```

**示例 2：**
```
输入：nums = [4,7,9,10], k = 3
输出：8
解释：缺失的数字有 [5,6,8,...]，第三个缺失的数字是 8。
```

**示例 3：**
```
输入：nums = [1,2,4], k = 3
输出：6
解释：缺失的数字有 [3,5,6,7,...]，第三个缺失的数字是 6。
```

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 10^7`
- `nums` 严格升序排列
- `1 <= k <= 10^8`

## 解题思路

这道题的关键是理解"缺失数字"的定义和如何高效地找到第 k 个。

**关键观察：**
1. 在位置 `i`，如果没有缺失，应该有 `nums[i] = nums[0] + i`
2. 实际缺失的数字个数为：`nums[i] - nums[0] - i`
3. 可以使用二分查找定位第 k 个缺失数字的位置

**算法思路：**

**方法一：线性扫描**
- 遍历数组，计算每个位置前有多少个缺失的数字
- 找到第一个缺失数字 ≥ k 的位置

**方法二：二分查找（最优）**
- 二分查找第一个"缺失数字数量 ≥ k"的位置
- 然后计算具体的缺失数字

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def missingElement(self, nums: List[int], k: int) -> int:
        """
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        def missing_count(idx: int) -> int:
            """计算 nums[idx] 前有多少个缺失的数字"""
            return nums[idx] - nums[0] - idx
        
        n = len(nums)
        
        # 如果第 k 个缺失数字在数组范围之外
        if k > missing_count(n - 1):
            return nums[-1] + k - missing_count(n - 1)
        
        # 二分查找第一个缺失数字 >= k 的位置
        left, right = 0, n - 1
        
        while left < right:
            mid = (left + right) // 2
            if missing_count(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        # left 是第一个缺失数字 >= k 的位置
        # 第 k 个缺失数字在 nums[left-1] 和 nums[left] 之间
        return nums[left - 1] + k - missing_count(left - 1)
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def missingElement(self, nums: List[int], k: int) -> int:
        """
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(nums)
        
        for i in range(1, n):
            # 计算 nums[i-1] 和 nums[i] 之间缺失的数字个数
            missing = nums[i] - nums[i - 1] - 1
            
            if k <= missing:
                # 第 k 个缺失数字在这两个数之间
                return nums[i - 1] + k
            
            # 减去已经遇到的缺失数字
            k -= missing
        
        # 第 k 个缺失数字在数组最后一个元素之后
        return nums[-1] + k
```

### 方法三：优化的二分查找

```python
from typing import List

class Solution:
    def missingElement(self, nums: List[int], k: int) -> int:
        """
        更简洁的二分查找实现
        """
        n = len(nums)
        
        # 辅助函数：计算位置 i 之前缺失的数字个数
        missing = lambda i: nums[i] - nums[0] - i
        
        # 如果 k 超出数组范围
        if k > missing(n - 1):
            return nums[-1] + k - missing(n - 1)
        
        # 二分查找
        left, right = 0, n - 1
        while left < right:
            mid = left + (right - left) // 2
            if missing(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        # 第 k 个缺失数字
        return nums[left - 1] + k - missing(left - 1)
```

## 复杂度分析

**方法一和方法三：二分查找**
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

**方法二：线性扫描**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

**示例：nums = [4,7,9,10], k = 3**

```
计算每个位置的缺失数字个数：

位置 0: nums[0] = 4
  缺失个数 = 4 - 4 - 0 = 0

位置 1: nums[1] = 7
  缺失个数 = 7 - 4 - 1 = 2
  （缺失的是 5, 6）

位置 2: nums[2] = 9
  缺失个数 = 9 - 4 - 2 = 3
  （缺失的是 5, 6, 8）

位置 3: nums[3] = 10
  缺失个数 = 10 - 4 - 3 = 3

二分查找：
- left = 0, right = 3
- mid = 1, missing(1) = 2 < 3, left = 2
- mid = 2, missing(2) = 3 >= 3, right = 2
- left = right = 2

第 k=3 个缺失数字在 nums[1]=7 和 nums[2]=9 之间
nums[1] + (k - missing(1)) = 7 + (3 - 2) = 8
```

**示例：nums = [1,2,4], k = 3**

```
位置 0: nums[0] = 1, 缺失 = 0
位置 1: nums[1] = 2, 缺失 = 0
位置 2: nums[2] = 4, 缺失 = 1（缺失 3）

k=3 > missing(2)=1，说明第 3 个缺失数字在数组之后
nums[2] + (k - missing(2)) = 4 + (3 - 1) = 6

完整的缺失序列：[3, 5, 6, ...]
第 3 个是 6 ✓
```

## 关键点总结

1. **缺失计算公式**：`missing(i) = nums[i] - nums[0] - i`
2. **二分查找目标**：找到第一个缺失数量 ≥ k 的位置
3. **边界处理**：如果 k 超出数组范围，在最后一个元素后继续计算
4. **结果计算**：`nums[left-1] + k - missing(left-1)`

## 易错点

1. **缺失计数**：注意是相对于 `nums[0]` 的缺失，不是绝对缺失
2. **边界情况**：
   - k 超出数组范围时的处理
   - 数组只有一个元素时
3. **二分边界**：`left < right` 还是 `left <= right`
4. **最终计算**：要从 `nums[left-1]` 开始计算，不是 `nums[left]`
