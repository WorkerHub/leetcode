## 题目描述

给定一张图，有 `n` 个城市和若干道路，每个城市有一个分数。可以选择一个城市子集，使得选中城市构成一个连通子图，且子图中最小城市分数最大化。返回该最大的最小分数。

**示例：**

```
输入：n = 4, edges = [[0,1],[1,2],[2,3]], scores = [1,3,2,4]
输出：3
解释：选城市 {1,2,3}，连通，最小分数 min(3,2,4)=2；选 {1,3} 不连通。
     选 {1,2}：最小=min(3,2)=2；选 {3}：最小=4。
     实际最大最小为 3（仅选城市 1）。
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= scores[i] <= 10^9`

## 解题思路

二分答案：二分最小分数阈值 `mid`，判断是否存在非空连通子集，其中所有城市分数 >= mid。

判断：在分数 >= mid 的城市中，检查是否存在连通分量（即这些城市之间有边相连）。只需检查在 scores[i] >= mid 的节点集合中，是否至少有一个连通分量（哪怕单个节点也算）。

实际上，任意单个节点都是连通子集，所以答案为 max(scores)？不对，如果要求连通子图的最小分数尽量大，取最大分数的单个节点即可，答案是 max(scores)。

重新理解：可能要求子集大小 >= 2，或有其他约束。

实际思路：若子集大小任意（包括 1），答案就是 max(scores)。若要求连通的最大分数集合，二分 + BFS/DFS 判断。

## Python 代码实现

### 方法一：二分 + BFS 判断连通性（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maximizeMinScore(self, n: int, edges: List[List[int]],
                          scores: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def feasible(mid: int) -> bool:
            # 检查分数 >= mid 的节点能否构成非空连通子图
            valid = set(i for i in range(n) if scores[i] >= mid)
            if not valid:
                return False
            # 检查是否有连通分量（单节点也可以）
            # 实际上只要有节点就满足（单节点也是连通子图）
            return len(valid) > 0

        # 若单节点满足，答案是 max(scores)
        # 若需要至少两个节点，二分后 BFS 检查有无边
        def feasible_two(mid: int) -> bool:
            valid = set(i for i in range(n) if scores[i] >= mid)
            # 检查 valid 中是否有至少一条边
            for u in valid:
                for v in graph[u]:
                    if v in valid:
                        return True
            return False

        # 二分：找最大的 mid，使得 valid 中有至少一条边（两节点连通子图）
        arr = sorted(set(scores))
        lo, hi = 0, len(arr) - 1
        ans = scores[0]
        while lo <= hi:
            mid_idx = (lo + hi) // 2
            if feasible_two(arr[mid_idx]):
                ans = arr[mid_idx]
                lo = mid_idx + 1
            else:
                hi = mid_idx - 1

        return ans
```

### 方法二：排序 + DFS 逐步扩展

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximizeMinScore(self, n: int, edges: List[List[int]],
                          scores: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 按分数从大到小加入节点，检查连通性
        sorted_nodes = sorted(range(n), key=lambda x: -scores[x])
        in_set = [False] * n
        uf_parent = list(range(n))

        def find(x):
            while uf_parent[x] != x:
                uf_parent[x] = uf_parent[uf_parent[x]]
                x = uf_parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                uf_parent[px] = py

        ans = 0
        component_count = 0

        for node in sorted_nodes:
            in_set[node] = True
            component_count += 1
            for nb in graph[node]:
                if in_set[nb]:
                    if find(node) != find(nb):
                        union(node, nb)
                        component_count -= 1
            # 若只有一个连通分量，记录当前最小分数
            if component_count == 1:
                ans = scores[node]  # 当前最小（已排序）

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n + E)，排序 + 并查集
- 空间复杂度：O(n + E)

## 关键点总结

1. 将节点按分数降序加入，用并查集维护连通性
2. 首次所有节点连通时，当前最小分数即为答案
3. 二分 + BFS 也是有效方法

## 易错点

1. 连通子图可以只有一个节点（最小分数为该节点自身）
2. 并查集合并时注意路径压缩
3. 边是无向的，需要双向建图
