## 题目描述

给定一个二叉树的**根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**

```
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]

        1            <---
       / \
      2   3          <---
       \   \
        5   4        <---
        
从右侧看：能看到 1, 3, 4
```

**示例 2：**
```
输入：root = [1,null,3]
输出：[1,3]
```

**示例 3：**
```
输入：root = []
输出：[]
```

**提示：**
- 二叉树的节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`

## 解题思路

这道题要求从右侧观察二叉树，每层只能看到最右边的节点。

**核心思想：**

从右侧看二叉树，每一层只能看到最右边的节点。因此：
- 方法1：层序遍历，取每层的最后一个节点
- 方法2：深度优先遍历，优先遍历右子树，每层第一个访问到的节点就是答案

**解法对比：**

| 方法 | 思路 | 实现难度 |
|------|------|----------|
| BFS 层序遍历 | 每层取最右节点 | 简单直观 |
| DFS 先右后左 | 每层第一次访问的节点 | 需要记录深度 |

## Python 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```python
from typing import List, Optional
from collections import deque

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        """
        BFS 层序遍历，每层取最后一个节点
        """
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            
            # 遍历当前层的所有节点
            for i in range(level_size):
                node = queue.popleft()
                
                # 当前层的最后一个节点
                if i == level_size - 1:
                    result.append(node.val)
                
                # 将下一层节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return result
```

**时间复杂度：** O(n) - 每个节点访问一次  
**空间复杂度：** O(n) - 队列最多存储一层的节点

### 方法二：BFS 简化版

```python
from typing import List, Optional
from collections import deque

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        """
        BFS 更简洁的写法：直接取每层最后一个节点
        """
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            # 每层的最后一个节点就是右视图能看到的
            result.append(queue[-1].val)
            
            # 处理当前层，将下一层加入队列
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return result
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)

### 方法三：DFS 深度优先（右→左）⭐

```python
from typing import List, Optional

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        """
        DFS 深度优先遍历
        优先遍历右子树，保证每层第一个访问的是最右节点
        """
        result = []
        
        def dfs(node, depth):
            if not node:
                return
            
            # 如果当前深度第一次访问，说明这是该层最右边的节点
            if depth == len(result):
                result.append(node.val)
            
            # 先访问右子树，再访问左子树
            dfs(node.right, depth + 1)
            dfs(node.left, depth + 1)
        
        dfs(root, 0)
        return result
```

**时间复杂度：** O(n)  
**空间复杂度：** O(h) - h 为树的高度（递归栈）

### 方法四：DFS 迭代版本

```python
from typing import List, Optional

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        """
        DFS 迭代实现（使用栈）
        """
        if not root:
            return []
        
        result = []
        # 栈中存储 (节点, 深度)
        stack = [(root, 0)]
        
        while stack:
            node, depth = stack.pop()
            
            # 当前深度第一次访问
            if depth == len(result):
                result.append(node.val)
            
            # 先压左子树，再压右子树（保证右子树先出栈）
            if node.left:
                stack.append((node.left, depth + 1))
            if node.right:
                stack.append((node.right, depth + 1))
        
        return result
```

**时间复杂度：** O(n)  
**空间复杂度：** O(h)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| BFS 层序 | O(n) | O(w) | w 为树的最大宽度 |
| DFS 递归 | O(n) | O(h) | h 为树的高度 |
| DFS 迭代 | O(n) | O(h) | 栈空间 |

**注意：** 
- 完全二叉树：w ≈ n/2，h = log(n)
- 链式树：w = 1，h = n

## 图解示例

**示例树：**
```
        1            深度 0: [1]      → 取 1
       / \
      2   3          深度 1: [2,3]    → 取 3
       \   \
        5   4        深度 2: [5,4]    → 取 4

右视图：[1, 3, 4]
```

**BFS 过程：**
```
队列变化：
初始: [1]                    → 取 1
第1轮: [2,3]                 → 取 3 (最后一个)
第2轮: [5,4]                 → 取 4 (最后一个)
结果: [1,3,4]
```

**DFS 过程（右→左）：**
```
访问顺序: 1 → 3 → 4 → 2 → 5
深度记录: 0   1   2   1   2

深度0: 第一次访问 → 记录 1
深度1: 第一次访问 → 记录 3
深度2: 第一次访问 → 记录 4
深度1: 已访问过 → 跳过 2
深度2: 已访问过 → 跳过 5
```

## 关键点总结

1. **问题本质**：每层取最右节点
   - BFS：直接取每层最后一个
   - DFS：先右后左，每层第一个访问的就是答案

2. **BFS 优势**：
   - 思路直观，符合题意
   - 代码简单，不易出错
   - 直接按层处理

3. **DFS 技巧**：
   - 使用深度标记访问顺序
   - `depth == len(result)` 判断是否首次访问该层
   - 先右后左的遍历顺序很关键

4. **深度和层的关系**：
   - 深度从 0 开始
   - `len(result)` 表示已访问的层数
   - 两者相等说明进入新层

5. **边界处理**：
   - 空树返回空列表
   - 单节点返回该节点值

## 易错点

1. **BFS 中取错节点**：
   - 错误：取队列第一个节点
   - 正确：取每层最后一个节点（`queue[-1]` 或 `i == level_size - 1`）

2. **DFS 遍历顺序错误**：
   - 错误：先左后右（会看到左侧节点）
   - 正确：先右后左

3. **深度判断条件**：
   - 错误：`depth >= len(result)`（会重复添加）
   - 正确：`depth == len(result)`（仅首次添加）

4. **迭代 DFS 的栈顺序**：
   - 错误：先压右，再压左（左先出栈）
   - 正确：先压左，再压右（右先出栈）

5. **空节点处理**：
   - 忘记判断 `if not root`
   - 添加子节点前忘记判空
