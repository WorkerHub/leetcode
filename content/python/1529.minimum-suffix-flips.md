## 题目描述

给你一个长度为 `n` 的二进制字符串 `target`。初始字符串 `s` 是 `n` 个 `'0'`。

每次操作，你可以选择一个下标 `i`（`0 <= i < n`），将 `s[i..n-1]`（从 `i` 到末尾的后缀）中所有字符翻转（`0` 变 `1`，`1` 变 `0`）。

返回使 `s == target` 所需的最少操作次数。

**示例 1：**
```
输入：target = "10111"
输出：3
解释：初始 s = "00000"
翻转 [0, 4]：s = "11111"
翻转 [1, 4]：s = "10000"
翻转 [2, 4]：s = "10111"
```

**示例 2：**
```
输入：target = "101"
输出：3
```

## 解题思路

### 贪心：从左到右处理

**关键观察：** 当我们从左到右扫描 `target` 时，我们需要让 `s` 的每一位逐步匹配。

- 对于第 `i` 位，若 `s[i]` 与 `target[i]` 不同，就必须翻转以 `i` 开头的后缀（这是唯一的贪心选择）。
- 翻转后 `s[i..n-1]` 全部取反，但 `s[0..i-1]` 已经匹配好，不受影响。

**等价分析：** 统计 `target` 中相邻不同的位置数（包括第一位与初始 `'0'` 的比较）。

即：操作次数 = `target[0]=='1'` 的情况加上 `target[i] != target[i-1]` 的数量。

## 代码实现

### 方法一：贪心（从左到右）

```python
class Solution:
    def minFlips(self, target: str) -> int:
        ans = 0
        # 初始 s 全为 '0'，当前"激活"的翻转状态（0 表示未翻转，1 表示已翻转）
        current = '0'
        for c in target:
            if c != current:
                # 需要翻转，操作次数加 1
                ans += 1
                current = c  # 翻转后当前状态变为 c
        return ans
```

### 方法二：统计相邻不同的位置数

```python
class Solution:
    def minFlips(self, target: str) -> int:
        # 在 '0' 前加一个初始状态，统计相邻变化次数
        full = '0' + target
        ans = sum(1 for i in range(1, len(full)) if full[i] != full[i-1])
        return ans
```

### 方法三：zip 写法

```python
class Solution:
    def minFlips(self, target: str) -> int:
        # 第一位与初始 '0' 比较，后续各位与前一位比较
        prev = '0' + target[:-1]
        return sum(a != b for a, b in zip(prev, target))
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心思路：遇到不匹配就翻转，确保当前位正确
2. 翻转后面所有位，相当于记录"当前全局翻转状态"
3. 操作次数 = `target` 中（包括与初始 `'0'` 比较）相邻不同的次数

## 易错点

- 翻转是对整个后缀，所以每次翻转后所有后续位都取反，用 `current` 跟踪当前状态即可
- 不需要真正模拟翻转数组
