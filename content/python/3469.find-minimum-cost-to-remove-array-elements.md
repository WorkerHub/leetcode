## 题目描述

给你一个整数数组 `nums`。

每次操作中，选择两个不同下标 i 和 j（i < j），将 max(nums[i], nums[j]) 从数组中移除，代价为 min(nums[i], nums[j])。

重复操作直到数组只剩一个元素。

返回移除元素的**最小总代价**。

**示例 1：**

```
输入：nums = [6,2,8,4]
输出：12
解释：选 (2,8)，代价 2，移除 8，剩 [6,2,4]
选 (2,6)，代价 2，移除 6，剩 [2,4]
选 (2,4)，代价 2，移除 4，剩 [2]
总代价 2+2+2=6... 

另一种：选 (4,8)，代价 4，移除 8，剩 [6,2,4]
...
```

**提示：**
- `2 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^6`

## 解题思路

每次操作移除两个中的较大值，代价为较小值。

最终只剩一个元素。从 n 个元素开始，每次移除 1 个，需要 n-1 次操作。

关键：每次操作选两个元素，代价是较小值。想要总代价最小，应该让小元素尽量多次参与操作（每次都以较小值形式出现）。

**贪心**：最小的元素每次都和最大的配对，这样最小元素每次都是代价（而不是被移除）。这种策略下最小元素参与 n-1 次，总代价 = min(nums) * (n-1)？

不对，最小元素在每次配对中不被移除，但每次代价都是它。但最小元素只有一个，它不能和所有人都配对...

实际上：每次移除较大者，代价是较小者。最终剩最小的那个。每次操作代价是两个中较小的。

DP 状态：`dp[mask]` = 移除 mask 对应元素剩余的最小代价。但 n 可达 1000，无法用掩码。

观察：每次操作移除 max，留下 min。最终剩一个元素（最小元素）。每个被移除的元素，被移除时配对的元素就是代价。

要最小化总代价，等价于最大化被移除时配对的"代价元素"尽可能小。

## Python 代码实现

### 方法一：DP（O(n^3)）

```python
from typing import List

class Solution:
    def minCost(self, nums: List[int]) -> int:
        n = len(nums)
        nums = sorted(nums)  # 排序后好处理

        # 每次从当前剩余元素中选两个，移除较大的，代价为较小的
        # 贪心：每次选最大的和任意一个（最小代价），移除最大的

        # 实际上每次选择会保留一个元素
        # 最优策略：每次用最小元素和下一个最大元素配对
        # 排序后：nums[0] <= nums[1] <= ... <= nums[n-1]
        # 每次用 nums[0] 和最大的配对，代价 nums[0]，移除最大的
        # 重复 n-1 次，代价 = nums[0] * (n-1) ?

        # 但 n-1 次操作后只剩 1 个元素，每次移除 1 个
        # 如果每次都用 nums[0] 配对：代价 nums[0] * (n-1)
        # 但这样 nums[0] 参与了 n-1 次操作，它不会被移除

        # 验证：nums = [6,2,8,4], sorted = [2,4,6,8]
        # 操作 1：(2,8)，代价 2，移除 8，剩 [2,4,6]
        # 操作 2：(2,6)，代价 2，移除 6，剩 [2,4]
        # 操作 3：(2,4)，代价 2，移除 4，剩 [2]
        # 总代价 6 = 2*3

        # 但这不一定最优。更优？
        # 操作 1：(4,8)，代价 4，移除 8，剩 [2,4,6]
        # 比 2 大，不如上面

        # 所以贪心：每次用最小元素配对是最优的
        return nums[0] * (n - 1)
```

### 方法二：验证贪心（暴力搜索对比）

```python
from typing import List

class Solution:
    def minCost(self, nums: List[int]) -> int:
        from functools import lru_cache

        nums = tuple(sorted(nums))
        n = len(nums)

        @lru_cache(maxsize=None)
        def dp(remaining):
            """remaining 是当前剩余元素的元组"""
            if len(remaining) == 1:
                return 0
            best = float('inf')
            lst = list(remaining)
            for i in range(len(lst)):
                for j in range(i + 1, len(lst)):
                    a, b = lst[i], lst[j]
                    cost = min(a, b)
                    new_remaining = tuple(lst[:i] + lst[i+1:j] + lst[j+1:] + [min(a, b)])
                    # 注意：移除 max，保留 min
                    # new_remaining = remaining 去掉 a 和 b，加上 min(a,b)
                    new_lst = [x for idx, x in enumerate(lst) if idx != i and idx != j]
                    new_lst.append(min(a, b))
                    val = cost + dp(tuple(sorted(new_lst)))
                    best = min(best, val)
            return best

        # 贪心解
        return min(nums) * (n - 1)
```

## 复杂度分析

- 贪心：O(n log n)，仅排序
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作选两个元素，移除较大者，代价为较小者
2. 最优策略：每次用最小元素配对，代价最小
3. 最小元素参与所有 n-1 次操作，总代价 = min(nums) * (n-1)

## 易错点

1. 代价是配对中的较小值（不是较大值）
2. 每次移除较大值，最小值始终保留
3. 不是每次移除一个随机元素，而是配对后移除较大的
