## 题目描述

字符串的**方差**定义为：字符串中任意两种字母出现次数之差的最大值（即最多的字母出现次数 - 最少的字母出现次数）。

给你一个字符串 `s`，返回 `s` 所有**子字符串**中最大的**方差**。

**示例 1：**
```
输入：s = "aababbb"
输出：3
解释：子字符串 "babbb" 中，b 出现 4 次，a 出现 1 次，方差 4-1=3。
```

**示例 2：**
```
输入：s = "abcde"
输出：0
```

## 解题思路

**枚举字符对 + Kadane 算法变体：**

枚举所有出现的字符对 `(a, b)`，求以 `a` 为"多数字符"、`b` 为"少数字符"的子串的最大方差，即"a 的个数 - b 的个数"的最大值，且子串中**必须包含至少一个 b**。

将 `s` 转化为数组：遇到 `a` 时为 +1，遇到 `b` 时为 -1，其他字符为 0。问题变为：在含有至少一个 -1 的子数组中，求最大子数组和。

用改进的 Kadane 算法：
- `dp1`：当前子数组的最大和（可以不包含 b）。
- `dp2`：必须包含 b 的最大和。
- 遇到 b 时：`dp2 = max(dp1, dp2) - 1`（将之前的 dp1 加上这个 b，或者直接开始新子数组）。
- 答案取 `dp2` 的最大值。

## 代码实现

### 方法一：枚举字符对 + Kadane（推荐）

```python
class Solution:
    def largestVariance(self, s: str) -> int:
        from collections import Counter
        chars = list(set(s))
        ans = 0

        # 枚举所有字符对 (a, b)
        for a in chars:
            for b in chars:
                if a == b:
                    continue
                # 计算 a - b 的最大子数组和（子数组必须含至少一个 b）
                # dp1: 当前子数组的最大 (a_count - b_count)（可以不含 b）
                # dp2: 必须含 b 的当前最大值
                dp1 = 0
                dp2 = -float('inf')

                for ch in s:
                    if ch == a:
                        dp1 += 1
                        dp2 += 1
                    elif ch == b:
                        # 遇到 b 时，dp2 可以从 dp1 开始（消耗这个 b）
                        dp2 = max(dp1, dp2) - 1
                        dp1 = max(dp1 - 1, 0)  # dp1 减 1，但不低于 0（开始新子数组）
                    # 其他字符不影响（当 0 处理）

                    ans = max(ans, dp2)

        return ans
```

### 方法二：Kadane 更清晰版本

```python
class Solution:
    def largestVariance(self, s: str) -> int:
        ans = 0
        chars = set(s)

        for a in chars:
            for b in chars:
                if a == b:
                    continue
                # dp_without_b：包含 a 不包含 b 的最大余额
                # dp_with_b：包含 a 且至少包含一个 b 的最大余额
                dp_no_b = 0
                dp_with_b = float('-inf')

                for ch in s:
                    if ch == a:
                        dp_no_b += 1
                        if dp_with_b != float('-inf'):
                            dp_with_b += 1
                    elif ch == b:
                        dp_with_b = max(dp_no_b - 1, dp_with_b - 1)
                        dp_no_b = max(dp_no_b - 1, 0)
                    # 更新答案（只有含 b 的子数组才有方差）
                    ans = max(ans, dp_with_b)

        return ans
```

## 复杂度分析

- 时间复杂度：O(26^2 * n) = O(n)，最多 26*25 个字符对。
- 空间复杂度：O(1)。

## 关键点总结

1. 枚举字符对将问题分解为 Kadane 算法的变体。
2. 关键约束：子串必须同时包含两种字母才有方差，故 dp2 必须含 b。
3. Kadane：维护含 b 和不含 b 的两个状态，遇到 b 时转化。

## 易错点

- 子串必须包含至少一个 b，否则方差为 0（只有一种字母）。
- `dp1` 减为负数时重置为 0（开始新子数组），但 `dp2` 不重置（保持含 b 的约束）。
