## 题目描述

给你一个整数数组 `colors`（圆形），以及一个整数 `k`。如果圆中任意长度为 `k` 的连续子序列中的颜色是**交替**的，则称为**交替组**。

返回**交替组**的数量。

**示例 1：**
```
输入：colors = [0,1,0,1,0], k = 3
输出：3
```

**示例 2：**
```
输入：colors = [0,1,0,0,1,0,1], k = 6
输出：2
```

**提示：**
- `3 <= colors.length <= 10^5`
- `0 <= colors[i] <= 1`
- `3 <= k <= colors.length`

## 解题思路

滑动窗口思路：

先预处理每个位置是否与下一个不同（圆形），得到差分数组 `diff`，其中 `diff[i] = 1` 表示 `colors[i] != colors[(i+1)%n]`。

长度为 `k` 的交替组对应 `diff` 中连续 `k-1` 个 1。

用滑动窗口统计 `diff` 的连续 1 的个数（需要处理圆形）。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], k: int) -> int:
        n = len(colors)
        # 扩展数组以处理圆形（复制前 k-1 个元素到末尾）
        extended = colors + colors[:k - 1]
        
        ans = 0
        # 统计当前窗口内"相邻不同"的对数
        # 窗口大小为 k，需要 k-1 对相邻不同
        cur_diff = 0
        # 初始化第一个窗口
        for i in range(k - 1):
            if extended[i] != extended[i + 1]:
                cur_diff += 1
        
        # 检查第一个窗口
        if cur_diff == k - 1:
            ans += 1
        
        # 滑动窗口
        for i in range(1, n):
            # 移出左端
            if extended[i - 1] != extended[i]:
                cur_diff -= 1
            # 移入右端
            if extended[i + k - 2] != extended[i + k - 1]:
                cur_diff += 1
            if cur_diff == k - 1:
                ans += 1
        
        return ans
```

### 方法二：记录连续交替长度

```python
from typing import List

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], k: int) -> int:
        n = len(colors)
        ans = 0
        # cnt 表示以 i 结尾的最长交替序列长度（圆形）
        cnt = 1
        # 先遍历整个圆两圈，统计连续交替长度
        for i in range(1, n + k - 1):
            if colors[i % n] != colors[(i - 1) % n]:
                cnt += 1
            else:
                cnt = 1
            if i >= k - 1 and cnt >= k:
                ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n + k)
- 空间复杂度：O(k)（方法一扩展数组）或 O(1)（方法二）

## 关键点总结

1. 圆形数组处理：复制前 k-1 个元素到末尾，或用取模
2. 滑动窗口维护"相邻不同"的对数
3. 交替组条件：连续 k-1 对相邻不同

## 易错点

1. 滑动窗口移入移出要用同一个边界值
2. 圆形处理时注意索引不要越界
