## 题目描述

给你两个正整数数组 `nums1` 和 `nums2`，数组的长度都是 `n`。

数组 `nums1` 和 `nums2` 的**绝对差值和**定义为所有 `|nums1[i] - nums2[i]|` 之和（下标从 0 开始）。

你可以选择将 `nums1` 中**一个**元素替换为 `nums1` 中的**另一个**元素，以此来最小化绝对差值和。

返回最小绝对差值和，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：nums1 = [1,7,5], nums2 = [2,11,7]
输出：1
解释：将 nums1[0]=1 替换为 nums1[2]=5，绝对差值和为 |5-2|+|7-11|+|5-7| = 3+4+2 = 9... 
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^5`

## 解题思路

**二分查找**：

1. 计算原始绝对差值和 `total`
2. 对于每个位置 `i`，计算将 `nums1[i]` 替换为 `nums1` 中某个最优值后能节省的最大差值
3. 最优替换值是 `nums1` 中最接近 `nums2[i]` 的值
4. 用排序后的 `nums1` 和二分查找快速找到最接近 `nums2[i]` 的值

**节省量** = `|nums1[i] - nums2[i]| - |best - nums2[i]|`，取所有位置的最大节省量，从 `total` 中减去即可。

## 代码实现

### 方法一：排序 + 二分查找（推荐）

```python
import bisect
from typing import List

class Solution:
    def minAbsoluteSumDiff(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums1)
        sorted_nums1 = sorted(nums1)  # 排序后的 nums1，用于二分查找

        total = 0
        max_save = 0  # 最大可节省的差值

        for i in range(n):
            diff = abs(nums1[i] - nums2[i])
            total += diff

            # 在 sorted_nums1 中找最接近 nums2[i] 的值
            pos = bisect.bisect_left(sorted_nums1, nums2[i])

            # 检查 pos 处的值
            if pos < n:
                new_diff = abs(sorted_nums1[pos] - nums2[i])
                max_save = max(max_save, diff - new_diff)

            # 检查 pos-1 处的值（比 nums2[i] 小的最大值）
            if pos > 0:
                new_diff = abs(sorted_nums1[pos - 1] - nums2[i])
                max_save = max(max_save, diff - new_diff)

        return (total - max_save) % MOD
```

### 方法二：有序集合（SortedList）

```python
from sortedcontainers import SortedList
from typing import List

class Solution:
    def minAbsoluteSumDiff(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10 ** 9 + 7
        sl = SortedList(nums1)
        total = 0
        max_save = 0

        for a, b in zip(nums1, nums2):
            diff = abs(a - b)
            total += diff

            # 找最接近 b 的值
            idx = sl.bisect_left(b)
            for i in [idx - 1, idx]:
                if 0 <= i < len(sl):
                    new_diff = abs(sl[i] - b)
                    max_save = max(max_save, diff - new_diff)

        return (total - max_save) % MOD
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序 O(n log n)，二分查找 O(log n) * n
- **空间复杂度**：O(n)，排序数组

## 关键点总结

1. 问题转化为：找一个替换位置，使节省的差值最大
2. 最优替换值是 nums1 中最接近 nums2[i] 的值（用二分查找）
3. 二分查找后需检查左右两个候选值（可能在 nums2[i] 两侧）

## 易错点

- 二分查找后同时检查 `pos` 和 `pos-1` 两个位置，取节省最大的
- 结果取模时先减后取模，注意不要出现负数（但 max_save <= total，不会为负）
