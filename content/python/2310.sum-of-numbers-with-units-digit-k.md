## 题目描述

给你两个整数 `num` 和 `k`，考虑具有以下属性的正整数多重集：

- 每个整数个位数字都是 `k`。
- 所有整数之和等于 `num`。

返回该多重集的**最小元素数目**，如果无法找到这样的多重集，返回 `-1`。

注意：多重集中的元素可以重复。

**示例 1：**
```
输入：num = 58, k = 9
输出：2
解释：多重集 [9, 49] 的和为 58，元素个数为 2。
```

**示例 2：**
```
输入：num = 37, k = 2
输出：-1
解释：个位为 2 的数字之和的个位只能是 0, 2, 4, 6, 8，无法得到 37。
```

**示例 3：**
```
输入：num = 0, k = 7
输出：0
```

**提示：**
- `0 <= num <= 3000`
- `0 <= k <= 9`

## 解题思路

**关键观察：**
若使用 `t` 个个位为 `k` 的数，它们个位之和的个位为 `(t * k) % 10`。要使总和等于 `num`，需要 `(t * k) % 10 == num % 10`。

枚举 `t` 从 0 到 10（因为个位是周期为 10 的循环），找到最小满足条件的 `t`，并验证 `t * k <= num` 且 `(num - t * k) % 10 == 0`（剩余部分可由个位为 0 的数凑成，即 10 的倍数）。

**特殊情况：**
- `k = 0`：每个数个位为 0，即 10 的倍数。若 `num % 10 != 0` 则返回 -1；否则返回 `num / 10`（最少用 `num/10` 个 10）。但实际上，若 `num = 0` 则返回 0，否则若 `num % 10 == 0` 返回 1（用一个 `num` 自身，如果它个位为 0）。
  实际上 k=0 时，1 个数就够，只要 num 本身个位是 0 即可。若 `num == 0` 返回 0，若 `num % 10 == 0` 且 `num > 0` 返回 1。

## 代码实现

### 方法一：枚举个数（推荐）

```python
class Solution:
    def minimumNumbers(self, num: int, k: int) -> int:
        if num == 0:
            return 0  # 空多重集，和为 0
        
        # 枚举使用 t 个数（t 从 1 到 10）
        for t in range(1, 11):
            # t 个个位为 k 的数，个位之和的个位为 (t * k) % 10
            if (t * k) % 10 == num % 10 and t * k <= num:
                return t
        
        return -1
```

### 方法二：动态规划

```python
class Solution:
    def minimumNumbers(self, num: int, k: int) -> int:
        if num == 0:
            return 0
        
        # 生成所有个位为 k 且不超过 num 的正整数
        candidates = []
        v = k if k > 0 else 10  # 最小的个位为 k 的正整数
        while v <= num:
            candidates.append(v)
            v += 10
        
        if not candidates:
            return -1
        
        # dp[i] = 凑成 i 所需的最少个数
        INF = float('inf')
        dp = [INF] * (num + 1)
        dp[0] = 0
        
        for i in range(1, num + 1):
            for c in candidates:
                if c > i:
                    break
                if dp[i - c] + 1 < dp[i]:
                    dp[i] = dp[i - c] + 1
        
        return dp[num] if dp[num] != INF else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举个数 | O(10) = O(1) | O(1) |
| 动态规划 | O(num * num/10) | O(num) |

## 关键点总结

1. 个位的循环性：`(t * k) % 10` 最多 10 个不同值，枚举 t 从 1 到 10 即可覆盖所有情况。
2. 需同时验证 `t * k <= num`，确保数值上可行。
3. `num = 0` 单独处理，返回 0。

## 易错点

- `k = 0` 时最小正整数为 10，不是 0。
- 枚举范围为 1 到 10（含），因为个位乘法以 10 为周期。
