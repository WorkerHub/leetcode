## 题目描述

给你一个 `n x 2` 的整数数组 `points`，其中 `points[i] = [xi, yi]` 是第 `i` 个点的坐标。

Alice 选择某个点 `(x1, y1)` 作为左上角，Bob 选择某个点 `(x2, y2)` 作为右下角，构成一个矩形（或退化为线段/点）。

满足条件的对数 `(Alice, Bob)`：
- `x1 <= x2`
- `y1 >= y2`（Alice 在上方，Bob 在下方）
- 所有其他点都**不在**矩形内部或边界上（除了 Alice 和 Bob 的点）

**示例：**
```
输入：points = [[1,1],[2,2],[3,3]]
输出：0
```

**提示：**
- `2 <= n <= 50`
- `points[i].length == 2`
- `0 <= xi, yi <= 50`
- 所有点各不相同

## 解题思路

数据范围小（n <= 50），枚举所有 `(Alice, Bob)` 对：
1. `x1 <= x2` 且 `y1 >= y2`
2. 检查其他所有点是否在矩形 `[x1, x2] x [y2, y1]` 外部

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def numberOfPairs(self, points: List[List[int]]) -> int:
        n = len(points)
        ans = 0

        for i in range(n):
            x1, y1 = points[i]
            for j in range(n):
                if i == j:
                    continue
                x2, y2 = points[j]
                # Alice 选 i，Bob 选 j
                if x1 > x2 or y1 < y2:
                    continue
                # 矩形：x in [x1, x2], y in [y2, y1]
                valid = True
                for k in range(n):
                    if k == i or k == j:
                        continue
                    xk, yk = points[k]
                    if x1 <= xk <= x2 and y2 <= yk <= y1:
                        valid = False
                        break
                if valid:
                    ans += 1

        return ans
```

### 方法二：排序后枚举

```python
from typing import List

class Solution:
    def numberOfPairs(self, points: List[List[int]]) -> int:
        # 按 x 升序，x 相同则 y 降序排序
        points.sort(key=lambda p: (p[0], -p[1]))
        n = len(points)
        ans = 0

        for i in range(n):
            x1, y1 = points[i]
            # Bob 的候选点：x2 >= x1，y2 <= y1
            # 在排好序的数组中，Bob 在 i 之后（x2 >= x1）
            max_y2 = float('-inf')  # 记录当前范围内最大的 y2
            for j in range(i + 1, n):
                x2, y2 = points[j]
                if y2 > y1:
                    continue  # y2 > y1，不满足条件
                # 矩形内不能有其他点
                # 中间点（x1 <= xk <= x2，y2 <= yk <= y1）的 yk 必须在 [y2, y1] 外
                # 利用贪心：若之前已有点 k 满足 x1 <= xk <= x2 且 yk > y2，则 (i,j) 不合法
                if y2 > max_y2:
                    max_y2 = y2
                    ans += 1

        return ans
```

## 复杂度分析

- 方法一：O(n^3)，n <= 50 完全可行
- 方法二：O(n^2)，排序优化
- 空间复杂度：O(1)

## 关键点总结

1. 矩形的四个边界由 Alice(x1,y1) 和 Bob(x2,y2) 确定
2. 检查所有其他点是否在矩形 `[x1,x2] x [y2,y1]` 之外
3. 排序后可以优化：固定 Alice，遍历 Bob 时用贪心判断

## 易错点

1. 注意 Alice 在左上，Bob 在右下：`x1 <= x2` 且 `y1 >= y2`
2. 点在矩形边界上也算"在矩形内"（要排除）
3. Alice 和 Bob 的点本身不算"其他点"
