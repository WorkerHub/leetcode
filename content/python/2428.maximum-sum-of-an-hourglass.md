## 题目描述

给你一个大小为 `m x n` 的整数矩阵 `grid`。

按以下形式将矩阵的一部分定义为一个 **沙漏**：

```
a b c
  d
e f g
```

返回矩阵中所有沙漏的 **最大总和**，沙漏总和是其中所有元素之和。

**注意：** 沙漏不能旋转且必须完整地包含在矩阵中。

**示例 1：**
```
输入：grid = [[6,2,1,3],[4,2,1,5],[9,2,8,7],[4,1,2,9]]
输出：30
解释：左上角的沙漏总和为 6+2+1+2+9+2+8 = 30，是最大值。
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `3 <= m, n <= 150`
- `0 <= grid[i][j] <= 10^6`

## 解题思路

枚举所有可能的沙漏中心点 `(r, c)`，其中 `1 <= r <= m-2`，`1 <= c <= n-2`。

沙漏 7 个元素：
- 上行：`grid[r-1][c-1] + grid[r-1][c] + grid[r-1][c+1]`
- 中行：`grid[r][c]`
- 下行：`grid[r+1][c-1] + grid[r+1][c] + grid[r+1][c+1]`

## 代码实现

### 方法一：枚举中心点（推荐）

```python
from typing import List

class Solution:
    def maxSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        # 枚举沙漏中心点 (r, c)，r 在 1~m-2，c 在 1~n-2
        for r in range(1, m - 1):
            for c in range(1, n - 1):
                # 计算沙漏总和
                total = (grid[r - 1][c - 1] + grid[r - 1][c] + grid[r - 1][c + 1]
                         + grid[r][c]
                         + grid[r + 1][c - 1] + grid[r + 1][c] + grid[r + 1][c + 1])
                ans = max(ans, total)

        return ans
```

### 方法二：枚举左上角（等价写法）

```python
from typing import List

class Solution:
    def maxSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        # 枚举沙漏左上角 (r, c)，r 在 0~m-3，c 在 0~n-3
        for r in range(m - 2):
            for c in range(n - 2):
                # 沙漏形状
                total = (grid[r][c] + grid[r][c + 1] + grid[r][c + 2]
                         + grid[r + 1][c + 1]
                         + grid[r + 2][c] + grid[r + 2][c + 1] + grid[r + 2][c + 2])
                ans = max(ans, total)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 | O(m * n) | O(1) |

## 关键点总结

1. 沙漏共 7 个元素，中心在 `(r, c)` 时，上下行各 3 个，中间 1 个
2. 枚举范围：行 `1 <= r <= m-2`，列 `1 <= c <= n-2`
3. 所有元素非负，最大值至少为 0（但输入保证至少有一个沙漏）

## 易错点

- 枚举范围：行和列都需要留出 1 的边距
- 沙漏是固定形状，不能旋转
