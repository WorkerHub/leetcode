## 题目描述

`n` 座城市和一些连接这些城市的道路 `roads` 共同构成了一个基础设施网络。每条道路都以 `roads[i] = [ai, bi]` 的形式表示，其中 `ai` 和 `bi` 是道路连接的两座城市的编号。

两座不同城市构成的**城市对**的**网络秩**定义为：与这两座城市**直接相连**的道路总数。如果存在一条道路直接连接这两座城市，则这条道路只计算**一次**。

整个基础设施网络的**最大网络秩**是所有不同城市对中的**最大网络秩**。

请你返回整个基础设施网络的**最大网络秩**。

**示例：**
```
输入：n = 4, roads = [[0,1],[0,3],[1,2],[1,3]]
输出：4
解释：城市 0 和 1 的网络秩为 4（0 连接 1,3；1 连接 0,2,3；0-1 共享一条道路不重复计算 → 2+3-1=4）
```

**提示：**
- `2 <= n <= 100`
- `0 <= roads.length <= n * (n-1) / 2`
- `roads[i].length == 2`
- `0 <= ai, bi <= n-1`
- `ai != bi`
- 每对城市之间**最多**有一条道路

## 解题思路

枚举所有城市对 `(i, j)`，计算它们的网络秩：
- 网络秩 = `degree[i] + degree[j]`
- 若 `i` 和 `j` 之间有直接道路，则减 1（避免重复计算）

## 代码实现

### 方法一：枚举所有城市对（推荐）

```python
from typing import List

class Solution:
    def maximalNetworkRank(self, n: int, roads: List[List[int]]) -> int:
        # 统计每个城市的度
        degree = [0] * n
        # 记录哪些城市对之间有直接道路
        connected = set()
        
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
            connected.add((min(a, b), max(a, b)))
        
        max_rank = 0
        for i in range(n):
            for j in range(i + 1, n):
                rank = degree[i] + degree[j]
                # 若 i 和 j 直接相连，减去重复计算的道路
                if (i, j) in connected:
                    rank -= 1
                max_rank = max(max_rank, rank)
        
        return max_rank
```

### 方法二：邻接矩阵

```python
from typing import List

class Solution:
    def maximalNetworkRank(self, n: int, roads: List[List[int]]) -> int:
        # 邻接矩阵标记直连关系
        adj = [[False] * n for _ in range(n)]
        degree = [0] * n
        
        for a, b in roads:
            adj[a][b] = True
            adj[b][a] = True
            degree[a] += 1
            degree[b] += 1
        
        max_rank = 0
        for i in range(n):
            for j in range(i + 1, n):
                rank = degree[i] + degree[j] - (1 if adj[i][j] else 0)
                max_rank = max(max_rank, rank)
        
        return max_rank
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合 | O(n^2 + m) | O(n + m) |
| 邻接矩阵 | O(n^2 + m) | O(n^2) |

n 为城市数，m 为道路数。

## 关键点总结

1. 网络秩 = `degree[i] + degree[j] - (1 if 直连 else 0)`
2. 枚举所有 O(n^2) 个城市对，取最大值
3. 用集合或邻接矩阵快速判断两城市是否直连
4. 注意 `connected` 集合中用 `(min(a,b), max(a,b))` 保证顺序一致

## 易错点

- 若两城市直连，该道路被两城市各算一次度，但网络秩中只算一次，需减 1
- 枚举时 `j` 从 `i+1` 开始，避免重复
- 集合中存储时用有序对 `(min, max)` 避免 `(a,b)` 和 `(b,a)` 重复
