## 题目描述

给定一个二叉树的根节点 `root`，返回它的中序遍历结果。

**示例 1：**

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [1]
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

## 解题思路

中序遍历（Inorder Traversal）是二叉树遍历的三种基本方式之一，遍历顺序为：**左子树 -> 根节点 -> 右子树**。

对于二叉搜索树（BST），中序遍历会得到一个升序的结果序列，这是一个重要的性质。

本题可以用三种方法实现：

1. **递归法**：最简单直观，利用函数调用栈
2. **迭代法（使用栈）**：模拟递归过程，显式使用栈
3. **Morris 遍历**：空间复杂度 O(1)，利用线索二叉树的思想

核心思想：
- 递归：先递归遍历左子树，访问根节点，再递归遍历右子树
- 迭代：用栈保存待访问的节点，先将左子树的所有节点入栈
- Morris：通过修改树的结构（临时建立线索）来实现无栈遍历

## Python 代码实现

### 方法一：递归法（推荐新手）

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        递归实现中序遍历
        时间复杂度：O(n)，每个节点访问一次
        空间复杂度：O(n)，递归栈空间，最坏情况下树退化为链表
        """
        result = []
        
        def inorder(node: Optional[TreeNode]) -> None:
            if not node:
                return
            
            # 左 -> 根 -> 右
            inorder(node.left)      # 遍历左子树
            result.append(node.val)  # 访问根节点
            inorder(node.right)     # 遍历右子树
        
        inorder(root)
        return result
```

### 方法二：迭代法（使用栈）⭐

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        迭代实现中序遍历，使用显式栈
        时间复杂度：O(n)
        空间复杂度：O(n)，栈空间
        """
        result = []
        stack = []
        current = root
        
        # 当前节点不为空或栈不为空时继续遍历
        while current or stack:
            # 一直向左走，将所有左节点入栈
            while current:
                stack.append(current)
                current = current.left
            
            # 弹出栈顶节点（当前最左节点）
            current = stack.pop()
            result.append(current.val)  # 访问节点
            
            # 转向右子树
            current = current.right
        
        return result
```

### 方法三：Morris 遍历（空间优化）

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        Morris 遍历：利用线索二叉树，空间复杂度 O(1)
        核心思想：利用叶子节点的空指针建立临时链接
        时间复杂度：O(n)
        空间复杂度：O(1)，只使用常数额外空间
        """
        result = []
        current = root
        
        while current:
            if not current.left:
                # 左子树为空，直接访问当前节点，然后转向右子树
                result.append(current.val)
                current = current.right
            else:
                # 找到左子树的最右节点（前驱节点）
                predecessor = current.left
                while predecessor.right and predecessor.right != current:
                    predecessor = predecessor.right
                
                if not predecessor.right:
                    # 建立线索：前驱节点的右指针指向当前节点
                    predecessor.right = current
                    current = current.left
                else:
                    # 线索已存在，说明左子树已遍历完
                    predecessor.right = None  # 恢复树结构
                    result.append(current.val)
                    current = current.right
        
        return result
```

### 方法四：统一迭代模板

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        """
        统一的迭代写法，使用标记法
        可以轻松改写为前序、后序遍历
        """
        if not root:
            return []
        
        result = []
        stack = [root]
        
        while stack:
            node = stack.pop()
            
            if node:
                # 中序遍历：右 -> 根 -> 左（栈是后进先出）
                if node.right:
                    stack.append(node.right)  # 右子树
                
                stack.append(node)            # 根节点
                stack.append(None)            # 标记：下次遇到要访问
                
                if node.left:
                    stack.append(node.left)   # 左子树
            else:
                # 遇到标记，访问下一个节点
                result.append(stack.pop().val)
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归法 | O(n) | O(n) | 递归栈深度，最坏情况 O(n) |
| 迭代法 | O(n) | O(n) | 显式栈空间 |
| Morris 遍历 | O(n) | O(1) | 只用常数空间，但会临时修改树结构 |

**说明：**
- n 为二叉树的节点数
- 所有方法都需要访问每个节点一次
- Morris 遍历虽然空间最优，但代码较复杂，实际中递归和迭代法更常用

## 图解示例

以示例 1 为例：`root = [1,null,2,3]`

```
    1
     \
      2
     /
    3
```

**中序遍历过程：**

1. 访问节点 1 的左子树（空）
2. 访问节点 1，输出 `1`
3. 访问节点 1 的右子树（节点 2）
   - 访问节点 2 的左子树（节点 3）
     - 访问节点 3，输出 `3`
   - 访问节点 2，输出 `2`

**结果：** `[1, 3, 2]`

## 关键点总结

1. **中序遍历顺序**：左 -> 根 -> 右，记住口诀"左根右"
2. **递归三部曲**：递归左子树、访问根节点、递归右子树
3. **迭代法核心**：用栈保存路径，先将所有左节点入栈
4. **BST 性质**：对二叉搜索树中序遍历得到升序序列
5. **空间优化**：Morris 遍历可以达到 O(1) 空间复杂度

## 易错点

1. **递归边界条件**
   ```python
   # 错误：忘记判空
   def inorder(node):
       inorder(node.left)  # node 可能为 None
   
   # 正确：先判空
   def inorder(node):
       if not node:
           return
       inorder(node.left)
   ```

2. **迭代法循环条件**
   ```python
   # 错误：只判断 stack
   while stack:  # current 为空但栈不为空时会漏掉节点
   
   # 正确：两个条件都要判断
   while current or stack:
   ```

3. **访问顺序混淆**
   - 前序遍历：根 -> 左 -> 右
   - 中序遍历：左 -> 根 -> 右
   - 后序遍历：左 -> 右 -> 根

4. **Morris 遍历忘记恢复结构**
   ```python
   # 必须恢复前驱节点的右指针
   predecessor.right = None  # 不能省略
   ```
