## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

如果下标对 `(i, j)` 满足：
- `0 <= i < j <= nums.length - 1`
- `nums[i]` 的 **首位数字** 和 `nums[j]` 的 **末位数字** 互质（最大公因数为 1）

则称 `(i, j)` 为 **美丽数对**。

返回数组中 **美丽数对** 的总数目。

**示例 1：**
```
输入：nums = [2,1,5,1,3]
输出：5
解释：(0,1),(0,2),(0,4),(2,3),(2,4) 满足条件
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 9999`

## 解题思路

暴力枚举所有 (i, j) 对，获取 `nums[i]` 的首位数字和 `nums[j]` 的末位数字，检查 gcd 是否为 1。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def countBeautifulPairs(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            first_i = int(str(nums[i])[0])  # nums[i] 的首位数字
            for j in range(i + 1, n):
                last_j = nums[j] % 10  # nums[j] 的末位数字
                if gcd(first_i, last_j) == 1:
                    ans += 1
        return ans
```

### 方法二：预计算首位数字

```python
from typing import List
from math import gcd

class Solution:
    def countBeautifulPairs(self, nums: List[int]) -> int:
        n = len(nums)
        # 提取每个数字的首位
        first = [int(str(x)[0]) for x in nums]
        last = [x % 10 for x in nums]
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                if gcd(first[i], last[j]) == 1:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max_digit))，gcd 的时间为常数
- 空间复杂度：O(1)

## 关键点总结

1. 首位数字：转字符串后取第一个字符，或反复整除 10
2. 末位数字：`num % 10`
3. 互质：`gcd(a, b) == 1`

## 易错点

1. 注意 `i < j`，不能重复计算
2. gcd 中若 `last_j == 0` 需要特殊处理（但题目保证 `nums[i] >= 1`，末位为 0 时 gcd(x, 0) = x，不互质除非 x=1）
