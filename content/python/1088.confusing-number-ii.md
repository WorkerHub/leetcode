## 题目描述

此题为 LeetCode Premium 题目。

**混淆数（Confusing Number）**是指一个数字在旋转 180 度之后，得到一个与原数字不同的新数字，且新数字的每一位都是有效的。

数字 `0, 1, 6, 8, 9` 旋转 180 度后分别得到 `0, 1, 9, 8, 6`。

数字 `2, 3, 4, 5, 7` 旋转 180 度后无效。

给定一个正整数 `n`，返回 `1` 到 `n` 之间（包含边界）混淆数的个数。

**示例 1：**
```
输入：n = 20
输出：6
解释：混淆数为 [6,9,10,16,18,19]
- 6 → 9
- 9 → 6
- 10 → 01 = 1
- 16 → 91
- 18 → 81
- 19 → 61
```

**示例 2：**
```
输入：n = 100
输出：19
解释：混淆数为 [6,9,10,16,18,19,60,61,66,68,80,81,86,89,90,91,98,99,100]
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

这是一道**回溯 + 剪枝**的数学问题。

### 核心思想

1. **有效数字**：只能由 `0, 1, 6, 8, 9` 组成
2. **旋转映射**：
   - 0 → 0
   - 1 → 1
   - 6 → 9
   - 8 → 8
   - 9 → 6

3. **混淆条件**：旋转后的数字与原数字不同

4. **回溯生成**：
   - 从高位到低位，尝试添加每个有效数字
   - 剪枝：当前数字 > n 时停止
   - 检查：生成的数字旋转后是否与原数字不同

### 关键优化

- 不需要枚举 1 到 n 的所有数字
- 直接回溯生成所有可能的有效数字
- 时间复杂度从 O(n) 降低到 O(5^log n)

## Python 代码实现

### 方法一：回溯生成（推荐）

```python
class Solution:
    def confusingNumberII(self, n: int) -> int:
        # 数字旋转映射
        rotation = {0: 0, 1: 1, 6: 9, 8: 8, 9: 6}
        valid_digits = [0, 1, 6, 8, 9]
        
        def is_confusing(num: int) -> bool:
            """判断一个数字是否是混淆数"""
            original = num
            rotated = 0
            
            while num > 0:
                digit = num % 10
                rotated = rotated * 10 + rotation[digit]
                num //= 10
            
            return rotated != original
        
        def backtrack(current: int) -> int:
            """回溯生成所有可能的数字"""
            if current > n:
                return 0
            
            count = 0
            
            # 检查当前数字是否是混淆数
            if current > 0 and is_confusing(current):
                count += 1
            
            # 尝试添加每个有效数字
            for digit in valid_digits:
                next_num = current * 10 + digit
                if next_num > n:
                    break
                count += backtrack(next_num)
            
            return count
        
        return backtrack(0)
```

### 方法二：迭代生成（BFS）

```python
from collections import deque

class Solution:
    def confusingNumberII(self, n: int) -> int:
        rotation = {0: 0, 1: 1, 6: 9, 8: 8, 9: 6}
        valid_digits = [0, 1, 6, 8, 9]
        
        def rotate(num: int) -> int:
            """旋转数字"""
            result = 0
            while num > 0:
                result = result * 10 + rotation[num % 10]
                num //= 10
            return result
        
        count = 0
        queue = deque([1, 6, 8, 9])  # 从1位数开始
        
        while queue:
            num = queue.popleft()
            
            if num > n:
                continue
            
            # 检查是否是混淆数
            if rotate(num) != num:
                count += 1
            
            # 生成下一位
            for digit in valid_digits:
                next_num = num * 10 + digit
                if next_num <= n:
                    queue.append(next_num)
        
        return count
```

### 方法三：DFS + 记忆化

```python
class Solution:
    def confusingNumberII(self, n: int) -> int:
        rotation = {0: 0, 1: 1, 6: 9, 8: 8, 9: 6}
        valid_digits = [0, 1, 6, 8, 9]
        
        def rotate(num: int) -> int:
            result = 0
            while num > 0:
                result = result * 10 + rotation[num % 10]
                num //= 10
            return result
        
        def dfs(num: int, rotated: int, base: int) -> int:
            """
            num: 当前构建的数字
            rotated: 当前数字旋转后的值
            base: 当前位的权重（10^i）
            """
            count = 0
            
            if num != rotated:
                count += 1
            
            for digit in valid_digits:
                next_num = num * 10 + digit
                if next_num > n:
                    break
                
                # 计算旋转后的值（优化：直接计算而不是每次调用函数）
                next_rotated = rotation[digit] * base + rotated
                count += dfs(next_num, next_rotated, base * 10)
            
            return count
        
        result = 0
        for digit in [1, 6, 8, 9]:  # 首位不能是0
            if digit <= n:
                result += dfs(digit, rotation[digit], 10)
        
        return result
```

## 复杂度分析

**方法一、三（回溯）：**
- **时间复杂度**：O(5^d)，d 是 n 的位数
  - 每位有 5 个选择，最多 d 层
  - 实际由于剪枝，远小于理论上界
- **空间复杂度**：O(d)，递归栈深度

**方法二（BFS）：**
- **时间复杂度**：O(5^d)
- **空间复杂度**：O(5^d)，队列大小

## 关键点总结

1. **有效数字集合**：只有 5 个数字可用
2. **旋转映射**：理解 180 度旋转的对应关系
3. **回溯剪枝**：当前数字 > n 时停止递归
4. **直接生成**：不枚举 1 到 n，而是直接生成有效数字
5. **优化计算**：在 DFS 过程中直接计算旋转值，避免重复计算

## 易错点

1. **首位为 0**：数字的首位不能是 0（10, 100 等除外）
2. **旋转计算**：注意旋转是倒序的（10 → 01 = 1）
3. **边界处理**：n 本身可能是混淆数
4. **剪枝时机**：`next_num > n` 时应该 break 而不是 continue
5. **混淆定义**：必须旋转后**不同**，相同的不算（如 0, 1, 8）
