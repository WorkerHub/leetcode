## 题目描述

给你一个字符串 `s`，每次操作可以将 `s` 中**相邻两个字符**对换位置。返回将 `s` 变成**回文串**所需的**最少**操作次数。

**示例 1：**
```
输入：s = "aabb"
输出：2
解释：移动 2 步变成 "abba"（"aabb" → "abab" → "abba"）。
```

**示例 2：**
```
输入：s = "letelt"
输出：2
解释："letelt" → "letetl" → "lteelt"，或者其他 2 步方案。
```

**提示：**
- `1 <= s.length <= 2000`
- `s` 只含小写英文字母
- `s` 可以变成回文串

## 解题思路

**贪心：从两端往中间匹配**

字符串可以变成回文串（题目保证），所以每个字母出现次数至多有一个是奇数（奇数长度时）。

贪心策略：
1. 找到最左边的字符 `s[left]`，在右侧找到与之相同的字符 `s[right]`。
2. 将 `s[right]` 移到最右边（需要 `n-1-right` 步）。
3. 同时 `left` 右移 1（`s[left]` 还没动，但右边已经确定好了最右一个字符）。
4. 如果找不到匹配（奇数出现次数的字符），将 `s[left]` 移到中间位置（`n//2 - left` 步）。

## 代码实现

### 方法一：贪心双指针（推荐）

```python
class Solution:
    def minMovesToMakePalindrome(self, s: str) -> int:
        s = list(s)
        n = len(s)
        ans = 0
        left = 0
        right = n - 1

        while left < right:
            # 在右侧找和 s[left] 相同的字符
            r = right
            while r > left and s[r] != s[left]:
                r -= 1

            if r == left:
                # 找不到匹配：s[left] 是奇数次字符，移到中间
                s[left], s[left + 1] = s[left + 1], s[left]
                ans += 1
                # left 不移动，继续处理
            else:
                # 将 s[r] 移到 right 位置
                ans += right - r
                # 交换到最右边
                while r < right:
                    s[r], s[r + 1] = s[r + 1], s[r]
                    r += 1
                left += 1
                right -= 1

        return ans
```

### 方法二：树状数组优化（O(n log n)）

```python
class BIT:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i, val=1):
        while i <= self.n:
            self.tree[i] += val
            i += i & -i

    def query(self, i) -> int:
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def pos_of_kth(self, k) -> int:
        # 找第 k 个 1 的位置（1-indexed）
        lo, hi = 1, self.n
        while lo < hi:
            mid = (lo + hi) // 2
            if self.query(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo

from collections import defaultdict

class Solution:
    def minMovesToMakePalindrome(self, s: str) -> int:
        n = len(s)
        # 按字符分组位置（1-indexed）
        pos = defaultdict(list)
        for i, c in enumerate(s):
            pos[c].append(i + 1)

        # BIT 跟踪哪些位置"还未配对"
        bit = BIT(n)
        for i in range(1, n + 1):
            bit.update(i)

        # 每个字符的左右指针
        ptr = {c: [0, len(lst) - 1] for c, lst in pos.items()}

        ans = 0
        for i in range(1, n // 2 + 1):
            c = s[i - 1]  # 当前处理的字符（从左到右）
            lp, rp = ptr[c]

            if lp > rp:
                # 只有奇数个字符，移到中间
                actual_pos = bit.pos_of_kth(bit.query(pos[c][lp]))
                ans += abs(actual_pos - (n + 1) // 2)
                bit.update(pos[c][lp], -1)
                ptr[c][0] += 1
                continue

            # 左侧第 lp 个 c 和右侧第 rp 个 c 配对
            l_pos = pos[c][lp]
            r_pos = pos[c][rp]

            # 当前实际排名（BIT 查询）
            l_rank = bit.query(l_pos)
            r_rank = bit.query(r_pos)

            # 左边要移到第 i 个位置（从左），右边要移到第 n+1-i 个位置
            # 注意：先处理右边再左边，或简化：移动步数 = (l_rank - i) + (r_rank - (n - i + 1))
            ans += (l_rank - i) + (n - i + 1 - r_rank)

            bit.update(l_pos, -1)
            bit.update(r_pos, -1)
            ptr[c][0] += 1
            ptr[c][1] -= 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心双指针 | O(n^2) | O(n) |
| BIT 优化 | O(n log n) | O(n) |

## 关键点总结

1. 贪心：每次处理最左边的字符，在右边找匹配，将右侧匹配字符移到最右端。
2. 奇数次字符（最多一个）移到字符串中间。
3. BIT 优化可以将位置查询从 O(n) 降到 O(log n)。

## 易错点

- 模拟时实际在修改字符串（交换操作），BIT 方法则无需真正交换。
- 奇数字符处理：移到中间位置，步数为当前位置到中间的距离。
