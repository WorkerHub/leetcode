## 题目描述

给你一个整数数组 `target`。从由全 `1` 组成的数组开始，进行如下步骤，直到得到 `target`：

1. 设 `x` 为当前数组中的所有元素之和。
2. 选择满足 `0 <= i < target.length` 的下标 `i`，将当前数组中的下标 `i` 处的值修改为 `x`。
3. 不断重复此过程。

如果可以从全 `1` 的数组出发，通过上述过程构造出 `target` 数组，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：target = [9,3,5]
输出：true
解释：从 [1,1,1] 开始：
[1,1,1] -> sum=3, 修改 index=0 -> [3,1,1]
[3,1,1] -> sum=5, 修改 index=2 -> [3,1,5]
[3,1,5] -> sum=9, 修改 index=0 -> [9,1,5]
[9,1,5] -> 修改 index=1 -> [9,3,5]  等等，似乎不对
实际路径：
[1,1,1] -> [1,1,3] -> [1,5,3] -> [9,5,3] -> [9,5,9]... 等
答案是 true
```

**示例 2：**
```
输入：target = [1,1,1,2]
输出：false
```

**示例 3：**
```
输入：target = [8,5]
输出：true
```

**提示：**
- `n == target.length`
- `1 <= n <= 5 * 10^4`
- `1 <= target[i] <= 10^9`

## 解题思路

**逆向思维：** 从 `target` 逆推回全 `1` 数组。

正向操作是：选一个位置 i，把 `arr[i]` 替换为所有元素之和 `S`。  
那么逆向操作是：选当前数组最大值 `x`，把它替换回它原来的值 `x - (S - x) = 2x - S`（其中 S 是当前总和）。

**算法：**
1. 用最大堆（Python 用负值模拟）维护当前数组。
2. 每次取出最大值 `x`，其余元素之和 `rest = S - x`。
3. 如果 `rest == 0`：只有一个元素，只能是 `[1]`，否则返回 False。
4. 将 `x` 替换为 `x mod rest`（对应多次回退的优化）：
   - 如果 `x mod rest == 0`，实际应为 `rest`（不能变成 0）。
   - 如果新值 < 1，返回 False。
5. 如果所有元素都等于 1，返回 True。

**为什么用取模？**

每次逆向操作 `x -> x - rest`，若 `x` 远大于 `rest`，需要重复多次才能降到 `[1, rest]` 范围。直接用取模 `x % rest` 一步完成多次减法，避免超时（否则 `target = [10^9, 1]` 时需 10^9 次操作）。

## Python 代码实现

### 方法一：逆向模拟 + 最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def isPossible(self, target: List[int]) -> bool:
        # Python 的 heapq 是最小堆，用负值模拟最大堆
        total = sum(target)
        heap = [-x for x in target]
        heapq.heapify(heap)
        
        while True:
            # 取出当前最大值
            x = -heapq.heappop(heap)
            
            # 全 1 时说明可以构造
            if x == 1:
                return True
            
            # 其余元素之和
            rest = total - x
            
            # 只剩一个元素时，必须是 1
            if rest == 0:
                return x == 1
            
            # 逆向操作：x 替换为 x mod rest
            # x mod rest 是 x 经过多次减 rest 后的结果
            new_val = x % rest
            
            # new_val 必须 >= 1（不能变成 0）
            if new_val == 0:
                new_val = rest  # 最后一次操作不减，所以实际是 rest
            
            # 如果 new_val >= x，说明无法缩小，无法逆推（死循环）
            # 等价于 rest >= x，即 new_val == x % rest == x（x < rest）
            if new_val >= x:
                return False
            
            # 更新总和并放回堆
            total = total - x + new_val
            heapq.heappush(heap, -new_val)
```

### 方法二：更严谨的实现（处理边界条件）

```python
from typing import List
import heapq

class Solution:
    def isPossible(self, target: List[int]) -> bool:
        total = sum(target)
        # 用负值构建最大堆
        heap = [-v for v in target]
        heapq.heapify(heap)
        
        while heap[0] != -1:  # 最大值不为 1 时继续
            x = -heapq.heappop(heap)
            rest = total - x  # 其余元素之和
            
            # rest == 0 说明只有一个元素了，只有 [1] 才是初始状态
            if rest == 0:
                return x == 1
            
            # rest >= x：当前最大值不超过其余总和，说明之前某次操作无法产生 x
            # 因为正向操作中，被替换的值等于所有元素之和 > 其余元素之和（需 > rest）
            # 这里等号也不行：若 x == rest，那 x 是由 sum = 2*rest 产生的，
            # 但此时原来的 x' = sum - rest = rest，与当前 rest 相等，会陷入死循环。
            if rest >= x:
                return False
            
            # 计算逆向后的值
            # x 是由某个 x0 经过若干次被 rest 整除后得到的
            # 即 x = x0 + k * rest，所以 x0 = x mod rest
            new_x = x % rest
            
            # new_x 不能为 0（数组中的值最小是 1）
            if new_x == 0:
                # x 是 rest 的整数倍，逆推到 rest（最后一步 1 * rest = x0 = rest）
                # 这表示 x0 = rest，合法（rest >= 1）
                new_x = rest
            
            total = total - x + new_x
            heapq.heappush(heap, -new_x)
        
        return True  # 所有值都是 1
```

### 方法三：暴力逆推（适合理解，大数据会超时）

```python
from typing import List
import heapq

class Solution:
    def isPossible(self, target: List[int]) -> bool:
        """
        暴力版本，不使用取模优化，仅用于理解思路
        时间复杂度：O(n * max(target))，会超时
        """
        total = sum(target)
        heap = [-x for x in target]
        heapq.heapify(heap)
        
        while heap[0] < -1:
            x = -heapq.heappop(heap)
            rest = total - x
            if rest == 0 or rest >= x:
                return rest == 0 and x == 1
            # 每次只减一次 rest
            new_x = x - rest
            if new_x < 1:
                return False
            total = total - x + new_x
            heapq.heappush(heap, -new_x)
        
        return True
```

## 复杂度分析

- 时间复杂度：O(n log n + log(max_val) * log n)。初始建堆 O(n)，每次操作取模使得值至少减半，所以最多操作 O(log(max_val)) 次，每次堆操作 O(log n)。总体约 O(n log n + log(10^9) * log n)。
- 空间复杂度：O(n)，堆的空间。

## 关键点总结

1. **逆向思维**：从 target 逆推回全 1 数组，每次把最大值替换为其原始值（`x mod rest`）。
2. **取模优化**：避免多次重复减 rest，直接取模一步到位，防止超时。
3. **合法性检查**：`rest >= x` 说明最大值不超过其余总和，无法通过正向操作得到当前状态。
4. **new_x == 0 的边界**：`x % rest == 0` 时不能变成 0，应该是 `rest`（说明 x 是由 rest 经一次操作得到）。
5. **单元素特判**：`rest == 0` 即只有一个元素时，只有 `[1]` 是合法起始状态。

## 易错点

- `new_val == 0` 的处理：此时 `x` 是 `rest` 的整数倍，逆推结果应为 `rest`（不是 0）。不处理这个边界会导致错误的 False 返回。
- `rest >= x` 的终止条件：若 `rest >= x`，则最大值已经不是最大的了（或等于 rest），无法构造。不加此判断可能死循环。
- Python 最大堆用负值模拟，注意每次取出和放入时都要取反。
