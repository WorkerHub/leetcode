## 题目描述

和谐数组是指一个数组里元素的最大值和最小值之间的差别正好是 `1`。

现在，给你一个整数数组 `nums`，请你在所有可能的子序列中找到最长的和谐子序列的长度。

**示例：**
```
输入：nums = [1,3,2,2,5,2,3,7]
输出：5
解释：最长的和谐子序列是 [3,2,2,2,3]
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

## Python 代码实现

```python
from typing import List
from collections import Counter

class Solution:
    def findLHS(self, nums: List[int]) -> int:
        """
        哈希表统计
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        count = Counter(nums)
        result = 0
        
        for num in count:
            if num + 1 in count:
                result = max(result, count[num] + count[num + 1])
        
        return result
```

## 关键点总结

1. **哈希表计数**：统计每个数字出现次数
2. **相邻数字**：只需检查 num 和 num+1
3. **和谐定义**：最大值-最小值=1
