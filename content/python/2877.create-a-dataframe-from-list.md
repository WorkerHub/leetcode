## 题目描述

编写一个解决方案，从二维列表 `student_data` 创建一个 DataFrame。该二维列表包含一些学生的 ID 和年龄数据，DataFrame 应该有两列，ID 和 Age，行的顺序与给定列表相同。

**示例 1：**
```
输入：
student_data = [
  [1, 15],
  [2, 11],
  [3, 11],
  [4, 20],
]

输出：
+----+-----+
| ID | Age |
+----+-----+
|  1 |  15 |
|  2 |  11 |
|  3 |  11 |
|  4 |  20 |
+----+-----+
```

## 解题思路

使用 `pd.DataFrame(data, columns=columns)` 从列表创建 DataFrame。

## Python 代码实现

### 方法一：pd.DataFrame（推荐）

```python
import pandas as pd
from typing import List

def createDataframe(student_data: List[List[int]]) -> pd.DataFrame:
    # 直接从二维列表创建 DataFrame，指定列名
    return pd.DataFrame(student_data, columns=['student_id', 'age'])
```

### 方法二：从字典创建

```python
import pandas as pd
from typing import List

def createDataframe(student_data: List[List[int]]) -> pd.DataFrame:
    # 先解包列，再创建
    ids = [row[0] for row in student_data]
    ages = [row[1] for row in student_data]
    return pd.DataFrame({'student_id': ids, 'age': ages})
```

## 复杂度分析

- 时间复杂度：O(n)，n 为数据行数
- 空间复杂度：O(n)

## 关键点总结

1. `pd.DataFrame(data, columns=cols)` 是从列表创建 DataFrame 最简单的方法
2. `columns` 参数指定列名，顺序与数据一致
3. 数据中每个子列表对应一行

## 易错点

1. 列名顺序要与数据一致（第一列 student_id，第二列 age）
2. 若数据是 `[[col1_val, col2_val], ...]` 格式，不需要转置
