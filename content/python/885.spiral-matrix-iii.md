## 题目描述

在 rows x cols 的网格上，从单元格 (rStart, cStart) 面向东面开始。网格的西北角位于第一行第一列，东南角位于最后一行最后一列。

你需要以顺时针按螺旋状行走，访问此网格中的每个位置。每当移出网格的边界时，需要继续在网格之外行走（但稍后可能会返回到网格边界）。

最终，我们到过网格的所有 rows x cols 个空间。

按照访问顺序返回表示网格位置的坐标列表。

**提示：**
- 1 <= rows, cols <= 100
- 0 <= rStart < rows
- 0 <= cStart < cols

## 解题思路

模拟螺旋路径：
- 方向：东、南、西、北
- 步数规律：1, 1, 2, 2, 3, 3, ...

## Python 代码实现

```python
class Solution:
    def spiralMatrixIII(self, rows: int, cols: int, rStart: int, cStart: int) -> List[List[int]]:
        # 方向：东、南、西、北
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        result = []
        r, c = rStart, cStart
        result.append([r, c])
        
        if rows * cols == 1:
            return result
        
        steps = 1
        di = 0
        
        while len(result) < rows * cols:
            for _ in range(2):  # 每个步数走两个方向
                dr, dc = directions[di]
                for _ in range(steps):
                    r, c = r + dr, c + dc
                    if 0 <= r < rows and 0 <= c < cols:
                        result.append([r, c])
                        if len(result) == rows * cols:
                            return result
                di = (di + 1) % 4
            steps += 1
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(max(rows, cols)²)
- **空间复杂度**：O(1)，不含输出

## 关键点总结

1. **步数规律**：1, 1, 2, 2, 3, 3, ...
2. **方向循环**：东南西北
3. **边界检查**：只记录在网格内的位置
