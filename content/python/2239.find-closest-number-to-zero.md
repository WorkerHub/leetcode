## 题目描述

给你一个整数数组 `nums`，返回距离 0 **最近** 的数字。如果有多个答案，返回**最大**的那个数字。

**示例 1：**
```
输入：nums = [-4,-2,1,4,8]
输出：1
```

**示例 2：**
```
输入：nums = [2,-1,1]
输出：1
```

## 解题思路

遍历数组，维护当前最优答案：
- 若 `abs(x) < abs(ans)`，更新答案为 `x`。
- 若 `abs(x) == abs(ans)`，取较大值（即 `x` 和 `ans` 中正数）。

## 代码实现

### 方法一：遍历比较（推荐）

```python
from typing import List

class Solution:
    def findClosestNumber(self, nums: List[int]) -> int:
        ans = nums[0]
        for x in nums:
            # 绝对值更小，或绝对值相等但 x 更大（正数优先）
            if abs(x) < abs(ans) or (abs(x) == abs(ans) and x > ans):
                ans = x
        return ans
```

### 方法二：自定义排序键

```python
from typing import List

class Solution:
    def findClosestNumber(self, nums: List[int]) -> int:
        # 按绝对值升序排，绝对值相同时按值降序排
        return min(nums, key=lambda x: (abs(x), -x))
```

### 方法三：利用 Python min

```python
from typing import List

class Solution:
    def findClosestNumber(self, nums: List[int]) -> int:
        # 先找最小绝对值，再在绝对值相同的中取最大
        min_abs = min(abs(x) for x in nums)
        return max(x for x in nums if abs(x) == min_abs)
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)。

## 关键点总结

1. 距离 0 最近 = 绝对值最小。
2. 绝对值相同时取较大值（即正数）。
3. 方法二用元组排序键，简洁优雅。

## 易错点

- 绝对值相同时要取**最大值**（正数优先于负数）。
- 不能简单地用 `min(key=abs)` 因为没有处理绝对值相同时的情况。
