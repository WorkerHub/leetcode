## 题目描述

给你一个整数数组 `hours`，表示若干任务的时长（小时）。

如果两个任务的时长之和是 24 的倍数（即 `(hours[i] + hours[j]) % 24 == 0`，i < j），则称这两个任务形成一个 **完整的一天**。

返回满足条件的配对数量。

**示例 1：**
```
输入：hours = [12,12,30,24,24]
输出：2
解释：(12,12) 和 (24,24) 各形成 24 的倍数
```

**提示：**
- `1 <= hours.length <= 100`
- `1 <= hours[i] <= 10^9`

## 解题思路

对每个 hours[i]，计算 `hours[i] % 24`，然后找之前有多少个 `(24 - r) % 24` 的余数（注意 r=0 时，需要找余数为 0 的）。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        cnt = defaultdict(int)
        ans = 0
        for h in hours:
            r = h % 24
            # 需要找余数为 (24 - r) % 24 的已有元素
            need = (24 - r) % 24
            ans += cnt[need]
            cnt[r] += 1
        return ans
```

### 方法二：暴力（小数据）

```python
from typing import List

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        n = len(hours)
        return sum(
            1
            for i in range(n)
            for j in range(i + 1, n)
            if (hours[i] + hours[j]) % 24 == 0
        )
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(24) = O(1)

## 关键点总结

1. 只需要余数模 24
2. 对当前 h，需要找之前余数为 `(24 - h%24) % 24` 的元素
3. 注意 h%24 = 0 时，需要找余数为 0 的（用 %24 处理）

## 易错点

1. 余数为 0 时，`24 - 0 = 24`，需要 `% 24 = 0`，所以需要 `(24 - r) % 24`
2. 每次先查询再更新（避免自身配对）
