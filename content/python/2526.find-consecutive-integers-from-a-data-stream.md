## 题目描述

给你一个整数数据流。请你实现一个数据结构，它支持以下两种操作：

1. `DataStream(int value, int k)` 用两个整数 `value` 和 `k` 初始化对象。
2. `boolean consec(int num)` 将 `num` 添加到数据流中，若数据流中的 **最后 k 个数** 全部等于 `value`，则返回 `true`，否则返回 `false`。

**示例：**

```
输入：
["DataStream", "consec", "consec", "consec", "consec"]
[[4, 3], [4], [4], [4], [3]]
输出：
[null, false, false, true, false]
```

**提示：**

- `1 <= value, num <= 10^9`
- `1 <= k <= 10^5`
- 最多调用 `consec` 10^5 次

## 解题思路

维护一个计数器 `count`，记录最近连续等于 `value` 的元素数目。

当 `num == value` 时，`count += 1`；否则 `count = 0`。

若 `count >= k`，则说明最后 k 个数都等于 `value`，返回 `true`。

## Python 代码实现

### 方法一：计数器（推荐）

```python
class DataStream:
    def __init__(self, value: int, k: int):
        self.value = value
        self.k = k
        # 记录当前连续等于 value 的数量
        self.count = 0

    def consec(self, num: int) -> bool:
        if num == self.value:
            self.count += 1
        else:
            # 不等于 value，重置计数
            self.count = 0
        # 若连续数量 >= k，则最后 k 个全等于 value
        return self.count >= self.k
```

### 方法二：使用队列（适合扩展其他查询）

```python
from collections import deque

class DataStream:
    def __init__(self, value: int, k: int):
        self.value = value
        self.k = k
        self.window = deque()  # 滑动窗口，长度为 k
        self.match_count = 0   # 窗口内等于 value 的数量

    def consec(self, num: int) -> bool:
        # 加入新元素
        self.window.append(num)
        if num == self.value:
            self.match_count += 1

        # 保持窗口大小为 k
        if len(self.window) > self.k:
            removed = self.window.popleft()
            if removed == self.value:
                self.match_count -= 1

        # 窗口满且全等于 value
        return len(self.window) == self.k and self.match_count == self.k
```

## 复杂度分析

- 方法一每次 `consec` 操作：O(1)
- 方法二每次 `consec` 操作：O(1)
- 空间复杂度：O(1)（方法一），O(k)（方法二）

## 关键点总结

1. 方法一最简洁：用计数器记录连续等于 value 的长度
2. 只要某次 num != value，连续性打破，计数归零
3. 方法二使用队列更直观，适合扩展到其他窗口查询

## 易错点

1. 不需要存储所有历史数据，只需知道最近的连续情况
2. 计数超过 k 没关系（如 count = 10, k = 3 也应返回 true）
3. 方法二中窗口还未满 k 个时应返回 false
