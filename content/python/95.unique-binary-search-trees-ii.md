## 题目描述

给你一个整数 `n`，请你生成并返回所有由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的不同**二叉搜索树**。可以按**任意顺序**返回答案。

**示例 1：**

```
输入：n = 3
输出：[[1,null,2,null,3],[1,null,3,2],[2,1,3],[3,1,null,null,2],[3,2,null,1]]
```

**示例 2：**

```
输入：n = 1
输出：[[1]]
```

**提示：**

- `1 <= n <= 8`

## 解题思路

这道题要求生成所有可能的二叉搜索树（BST），而不仅仅是计算数量（第 96 题）。这是一个典型的**分治 + 回溯**问题。

**核心思想：**

对于范围 `[start, end]` 内的数字：
1. 枚举每个数字 `i` 作为根节点
2. `[start, i-1]` 的所有数字构成左子树的所有可能
3. `[i+1, end]` 的所有数字构成右子树的所有可能
4. 左右子树的所有组合，配上根节点 `i`，就是所有可能的 BST

**递归分治：**
- **子问题**：生成区间 `[start, end]` 的所有 BST
- **分解**：选择根节点，递归生成左右子树
- **合并**：左右子树的笛卡尔积（每个左子树配每个右子树）

**边界条件：**
- `start > end`：返回 `[None]`，表示空树
- `start == end`：返回只有一个节点的树

**优化：**
- 可以使用记忆化搜索（动态规划）缓存已计算的结果
- 由于 BST 的结构只与节点数量有关，可以通过偏移量复用结果

## Python 代码实现

### 方法一：递归分治（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        """
        递归生成所有可能的 BST
        时间复杂度：O(4^n / n^(3/2))，卡特兰数相关
        空间复杂度：O(4^n / n^(3/2))，存储所有树
        """
        if n == 0:
            return []
        
        def generate(start: int, end: int) -> List[Optional[TreeNode]]:
            """
            生成区间 [start, end] 内所有可能的 BST
            """
            if start > end:
                # 空树
                return [None]
            
            all_trees = []
            
            # 枚举每个数字作为根节点
            for i in range(start, end + 1):
                # 递归生成所有可能的左子树
                left_trees = generate(start, i - 1)
                
                # 递归生成所有可能的右子树
                right_trees = generate(i + 1, end)
                
                # 左右子树的笛卡尔积：每个左子树配每个右子树
                for left in left_trees:
                    for right in right_trees:
                        # 创建当前根节点
                        root = TreeNode(i)
                        root.left = left
                        root.right = right
                        all_trees.append(root)
            
            return all_trees
        
        return generate(1, n)
```

### 方法二：记忆化搜索（优化版）

```python
class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        """
        使用记忆化搜索避免重复计算
        时间复杂度：O(4^n / n^(3/2))
        空间复杂度：O(4^n / n^(3/2))
        """
        if n == 0:
            return []
        
        # 记忆化缓存：memo[start][end] 存储区间 [start, end] 的所有 BST
        memo = {}
        
        def generate(start: int, end: int) -> List[Optional[TreeNode]]:
            # 检查缓存
            if (start, end) in memo:
                return memo[(start, end)]
            
            if start > end:
                return [None]
            
            all_trees = []
            
            for i in range(start, end + 1):
                left_trees = generate(start, i - 1)
                right_trees = generate(i + 1, end)
                
                for left in left_trees:
                    for right in right_trees:
                        root = TreeNode(i)
                        root.left = left
                        root.right = right
                        all_trees.append(root)
            
            # 缓存结果
            memo[(start, end)] = all_trees
            return all_trees
        
        return generate(1, n)
```

### 方法三：动态规划（结构复用）

```python
class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        """
        动态规划：复用相同长度区间的 BST 结构
        通过偏移量生成不同的节点值
        """
        if n == 0:
            return []
        
        def clone(root: Optional[TreeNode], offset: int) -> Optional[TreeNode]:
            """
            克隆树并给所有节点值加上 offset
            """
            if not root:
                return None
            
            new_root = TreeNode(root.val + offset)
            new_root.left = clone(root.left, offset)
            new_root.right = clone(root.right, offset)
            return new_root
        
        def generate(start: int, end: int) -> List[Optional[TreeNode]]:
            if start > end:
                return [None]
            
            all_trees = []
            
            for i in range(start, end + 1):
                left_trees = generate(start, i - 1)
                right_trees = generate(i + 1, end)
                
                for left in left_trees:
                    for right in right_trees:
                        root = TreeNode(i)
                        root.left = left
                        root.right = right
                        all_trees.append(root)
            
            return all_trees
        
        return generate(1, n)
```

### 方法四：迭代法（从底向上构建）

```python
class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        """
        迭代法：从长度为 1 的区间开始，逐步构建更长的区间
        """
        if n == 0:
            return []
        
        # dp[length][start] 表示从 start 开始，长度为 length 的所有 BST
        dp = [[[] for _ in range(n + 1)] for _ in range(n + 2)]
        
        # 初始化：长度为 0（空树）
        for i in range(n + 1):
            dp[0][i] = [None]
        
        # 枚举长度：从 1 到 n
        for length in range(1, n + 1):
            # 枚举起始位置
            for start in range(1, n - length + 2):
                end = start + length - 1
                trees = []
                
                # 枚举根节点
                for root_val in range(start, end + 1):
                    left_len = root_val - start
                    right_len = end - root_val
                    
                    # 获取左右子树
                    left_trees = dp[left_len][start]
                    right_trees = dp[right_len][root_val + 1]
                    
                    # 组合
                    for left in left_trees:
                        for right in right_trees:
                            root = TreeNode(root_val)
                            root.left = left
                            root.right = right
                            trees.append(root)
                
                dp[length][start] = trees
        
        return dp[n][1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归分治 | O(4^n / n^(3/2)) | O(4^n / n^(3/2)) | 卡特兰数，指数级 |
| 记忆化搜索 | O(4^n / n^(3/2)) | O(4^n / n^(3/2)) | 避免重复计算 |
| 动态规划 | O(4^n / n^(3/2)) | O(4^n / n^(3/2)) | 迭代实现 |

**说明：**
- 不同 BST 的数量是第 n 个卡特兰数：C_n = (2n)! / ((n+1)! * n!)
- 时间复杂度渐近于 O(4^n / n^(3/2))
- 由于需要存储所有可能的树，空间复杂度也是指数级的
- 题目限制 n <= 8，所以复杂度可以接受

## 图解示例

以 `n = 3` 为例，生成 `[1, 2, 3]` 的所有 BST：

```
选择 1 作为根：
  1              1
   \              \
    3              2
   /                \
  2                  3

选择 2 作为根：
    2
   / \
  1   3

选择 3 作为根：
    3            3
   /            /
  2            1
 /              \
1                2
```

**生成过程（以选择 2 作为根为例）：**

1. 根节点 = 2
2. 左子树范围 `[1, 1]`，生成树：`[1]`
3. 右子树范围 `[3, 3]`，生成树：`[3]`
4. 组合：左子树 `1` + 根 `2` + 右子树 `3`

**总共 5 种不同的 BST**

## 关键点总结

1. **分治思想**：选择根节点，递归生成左右子树，然后组合
2. **BST 性质**：左子树所有值 < 根节点 < 右子树所有值
3. **笛卡尔积**：每个左子树都要和每个右子树组合
4. **边界条件**：`start > end` 时返回 `[None]` 表示空树
5. **卡特兰数**：n 个节点的不同 BST 数量是卡特兰数

## 易错点

1. **忘记处理空树**
   ```python
   # 错误：没有返回 [None]
   if start > end:
       return []  # 这样会导致后续循环无法执行
   
   # 正确：返回 [None]
   if start > end:
       return [None]  # 允许左右子树的循环继续
   ```

2. **节点重复使用问题**
   ```python
   # 错误：所有树共享同一个节点对象
   root = TreeNode(i)
   for left in left_trees:
       for right in right_trees:
           root.left = left   # 会被覆盖
           root.right = right
           all_trees.append(root)
   
   # 正确：每次创建新节点
   for left in left_trees:
       for right in right_trees:
           root = TreeNode(i)  # 在循环内创建
           root.left = left
           root.right = right
           all_trees.append(root)
   ```

3. **区间边界错误**
   ```python
   # 注意左右子树的范围
   left_trees = generate(start, i - 1)    # 不是 i
   right_trees = generate(i + 1, end)     # 不是 i
   ```

4. **忘记 n = 0 的情况**
   ```python
   if n == 0:
       return []  # 题目虽然说 n >= 1，但最好处理边界
   ```

## 学习建议

1. **先理解问题本质**：
   - 这是生成所有可能的组合问题
   - 不是简单的遍历或搜索，而是构造所有解

2. **掌握分治思想**：
   - 大问题分解为小问题（选择根节点）
   - 小问题的解组合成大问题的解（笛卡尔积）

3. **理解 BST 性质**：
   - 为什么可以把区间分为左右两部分？
   - 因为 BST 的定义保证了值的大小关系

4. **画图辅助理解**：
   - 从 n = 1, 2, 3 开始手动画出所有可能的树
   - 观察递归的分解和组合过程

5. **对比第 96 题**：
   - 第 96 题只需要计数，可以用动态规划优化
   - 本题需要生成所有树，无法简单优化

6. **注意数据范围**：
   - n <= 8 的限制是因为结果数量是指数级的
   - 理解为什么不能处理更大的 n

7. **递归调试技巧**：
   - 打印递归调用的层次和参数
   - 观察左右子树的组合过程

8. **扩展思考**：
   - 如何生成所有可能的二叉树（不限制 BST）？
   - 如何生成平衡的 BST？
