## 题目描述

给你一个 `m x n` 的括号矩阵 `grid`，每个元素是 `'('` 或 `')'`。

一条**合法路径**从左上角 `(0,0)` 出发，到右下角 `(m-1, n-1)`，只能向右或向下走，且路径上所有括号形成一个**合法括号字符串**。

若存在合法路径则返回 `true`，否则返回 `false`。

**合法括号字符串：** 长度为偶数，`(` 和 `)` 成对匹配。

**示例 1：**
```
输入：grid = [["(","(","("],[")","(",")"],["(","(",")"],["(","(",")"]]
输出：true
```

## 解题思路

**DP：** `dp[i][j]` = 从 `(0,0)` 到 `(i,j)` 的所有合法路径中，可能的"当前未匹配左括号数"的集合。

状态为当前未匹配 `(` 的数量（非负整数）。

状态转移：从 `dp[i-1][j]` 和 `dp[i][j-1]` 出发，根据 `grid[i][j]` 更新。

路径长度为 `m + n - 1`，必须为偶数（否则直接返回 `false`）。答案为 `dp[m-1][n-1]` 中是否包含 0。

## 代码实现

### 方法一：DP 集合（推荐）

```python
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])

        # 路径长度必须为偶数
        if (m + n - 1) % 2 == 1:
            return False

        # dp[i][j] = 到达 (i,j) 时可能的未匹配左括号数量的集合
        dp = [set() for _ in range(n)]

        for i in range(m):
            new_dp = [set() for _ in range(n)]
            for j in range(n):
                ch = grid[i][j]
                # 收集前一状态
                prev_states = set()
                if i > 0:
                    prev_states |= dp[j]
                if j > 0:
                    prev_states |= new_dp[j - 1]
                if i == 0 and j == 0:
                    prev_states.add(0)  # 起点

                for bal in prev_states:
                    if ch == '(':
                        new_dp[j].add(bal + 1)
                    else:
                        if bal > 0:
                            new_dp[j].add(bal - 1)
            dp = new_dp

        return 0 in dp[n - 1]
```

### 方法二：滚动 DP（位掩码优化）

```python
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        if (m + n - 1) % 2 == 1:
            return False

        # 最大未匹配数不超过 min(m, n)（路径最多转折这么多次）
        max_bal = (m + n - 1) // 2

        # dp[j] 为到达当前行第 j 列时可能的余额集合
        # 用 frozenset 或 bitset
        INF = max_bal + 1

        # 用 bitset（整数）表示集合
        prev_row = [0] * n

        for i in range(m):
            curr_row = [0] * n
            for j in range(n):
                incoming = 0
                if i > 0:
                    incoming |= prev_row[j]
                if j > 0:
                    incoming |= curr_row[j - 1]
                if i == 0 and j == 0:
                    incoming = 1  # bit 0 表示余额 0

                ch = grid[i][j]
                if ch == '(':
                    # 余额 +1：左移一位
                    new_bits = (incoming << 1) & ((1 << (INF + 1)) - 1)
                else:
                    # 余额 -1：右移一位（去掉余额为0的情况）
                    new_bits = incoming >> 1

                curr_row[j] = new_bits
            prev_row = curr_row

        # 检查余额为 0 的位（bit 0）
        return bool(prev_row[n - 1] & 1)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(m * n * min(m,n))，每个格子的状态集合大小最多 O(min(m,n))。
- 空间复杂度：O(n * min(m,n))。

**方法二（位掩码）：**
- 时间复杂度：O(m * n)，位运算 O(1)。
- 空间复杂度：O(n)。

## 关键点总结

1. 路径长度 = m + n - 1，必须为偶数才可能有合法括号串。
2. DP 状态记录当前可能的未匹配 `(` 数量集合。
3. 遇到 `(` 余额 +1，遇到 `)` 余额 -1（余额 < 0 时路径无效）。
4. 最终检查是否可以达到余额 0。

## 易错点

- 路径长度奇数时直接返回 false（无法形成合法括号串）。
- 余额减为负数的情况需过滤（`if bal > 0`）。
