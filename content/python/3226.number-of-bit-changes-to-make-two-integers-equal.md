## 题目描述

给你两个正整数 `n` 和 `k`。

你可以执行以下操作**任意次**：选择 `n` 中一个值为 `1` 的位，将其修改为 `0`。

返回使 `n` 等于 `k` 所需的**最少操作次数**。若无法实现，返回 `-1`。

**示例 1：**
```
输入：n = 13, k = 4
输出：2
解释：13 = 1101, 4 = 0100。将 n 的第 0 位和第 3 位的 1 改为 0 -> 0100 = 4。
```

**示例 2：**
```
输入：n = 21, k = 21
输出：0
```

**示例 3：**
```
输入：n = 14, k = 13
输出：-1
解释：14 = 1110, 13 = 1101。k 的第 0 位是 1 但 n 是 0，无法通过把 1 变 0 实现。
```

**提示：**
- `1 <= n, k <= 10^6`

## 解题思路

操作只能将 `n` 的 1 变为 0，不能将 0 变为 1。

因此：
- 若 `k` 有某一位是 1 而 `n` 对应位是 0，则无法实现，返回 -1
- 等价条件：`k & n != k`（k 的某些 1 在 n 中不存在）
- 操作次数 = `n` 中有而 `k` 中没有的 1 的个数 = `bin(n & ~k).count('1')` = `bin(n ^ k).count('1')`（当可以实现时）

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def minChanges(self, n: int, k: int) -> int:
        # k 中有 1 但 n 中对应位是 0 -> 无法实现
        if k & n != k:
            return -1
        # 需要改变的次数 = n 中比 k 多的 1 的个数
        return bin(n ^ k).count('1')
```

### 方法二：逐位判断

```python
class Solution:
    def minChanges(self, n: int, k: int) -> int:
        ops = 0
        while n or k:
            nb = n & 1
            kb = k & 1
            if kb == 1 and nb == 0:
                return -1   # k 有 1 但 n 没有，无法操作
            if nb == 1 and kb == 0:
                ops += 1    # n 有 1 但 k 没有，需要一次操作
            n >>= 1
            k >>= 1
        return ops
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 操作只能 1 -> 0，所以 k 需要是 n 的"子集"（按位）
2. 操作次数 = n 中有、k 中没有的 1 的数量
3. `(n & ~k)` 或 `(n ^ k)` 的 popcount 即为答案（当 k 是 n 的子集时两者等价）

## 易错点

1. 条件判断：`k & n == k` 等价于 k 是 n 的子集（按位）
2. 注意不是判断 n == k，而是判断 k 的所有 1 位在 n 中都有
