## 题目描述

给你一个字符串数组 `nums`，其中每个字符串的长度均为 `n`，且仅包含 `'0'` 或 `'1'`。请你返回一个长度为 `n` 且**没有出现在 `nums` 中**的二进制字符串。如果存在多个答案，返回任意一个均可。

**示例 1：**
```
输入：nums = ["01","10"]
输出："11"
```

**示例 2：**
```
输入：nums = ["00","01"]
输出："11"
```

**示例 3：**
```
输入：nums = ["111","011","001"]
输出："101"
```

**提示：**
- `1 <= n <= 16`
- `nums.length == n`
- `nums[i].length == n`

---

## 解题思路

### 核心思想：对角线 Cantor 对角化

注意 `nums` 恰好有 `n` 个长度为 `n` 的字符串，而长度为 `n` 的二进制字符串共有 `2^n` 个（`n >= 1`，故 `2^n > n`），必定存在答案。

**对角线构造法（康托对角化）**：
- 构造答案字符串 `res`，令 `res[i]` 与 `nums[i][i]` 不同
- 这样 `res` 与每个 `nums[i]` 至少在第 `i` 位不同，保证不重复

---

## 代码实现

### 方法一：对角线构造（推荐，O(n)）

```python
from typing import List

class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        n = len(nums)
        # res[i] = 与 nums[i][i] 不同的字符
        res = []
        for i in range(n):
            # 若对角线是 '0' 就取 '1'，反之取 '0'
            res.append('1' if nums[i][i] == '0' else '0')
        return ''.join(res)
```

### 方法二：哈希集合 + 枚举

```python
from typing import List

class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        n = len(nums)
        num_set = set(nums)

        # 枚举所有 n 位二进制字符串，找到不在集合中的
        for i in range(2 ** n):
            candidate = bin(i)[2:].zfill(n)  # 转为 n 位二进制字符串
            if candidate not in num_set:
                return candidate

        return ""
```

### 方法三：回溯（通用解法）

```python
from typing import List

class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        n = len(nums)
        num_set = set(nums)

        def backtrack(path: list) -> str:
            if len(path) == n:
                s = ''.join(path)
                if s not in num_set:
                    return s
                return ""
            # 先尝试 '0'，再尝试 '1'
            for c in ('0', '1'):
                path.append(c)
                result = backtrack(path)
                if result:
                    return result
                path.pop()
            return ""

        return backtrack([])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（对角化） | O(n) | O(n) |
| 方法二（枚举） | O(2^n) | O(n) |
| 方法三（回溯） | O(2^n) 最坏 | O(n) |

---

## 关键点总结

1. 数组恰好 n 个，共 2^n 种可能，必有答案
2. 对角线构造法保证 O(n) 时间，且不依赖哈希
3. 方法二和三适用于一般情况（n 较小时）

---

## 易错点

- 对角线构造：`res[i]` 只与 `nums[i][i]` 有关，不要混淆索引
- 方法二中 `bin(i)[2:].zfill(n)` 将整数转为 n 位二进制字符串
