## 题目描述

给你两个正整数 `n` 和 `m`。

计算以下两个值之差：
- `num1`：1 到 n 之间**不能**被 m 整除的整数之和
- `num2`：1 到 n 之间**能**被 m 整除的整数之和

返回 `num1 - num2`。

**示例 1：**
```
输入：n = 10, m = 3
输出：19
解释：
不能被 3 整除：1,2,4,5,7,8,10，和 = 37
能被 3 整除：3,6,9，和 = 18
答案 = 37 - 18 = 19
```

**示例 2：**
```
输入：n = 5, m = 6
输出：15
解释：
不能被 6 整除：1,2,3,4,5，和 = 15
能被 6 整除：无，和 = 0
答案 = 15 - 0 = 15
```

**提示：**
- `1 <= n, m <= 1000`

## 解题思路

**方法一：直接计算**

遍历 1 到 n，分类累加。

**方法二：数学公式**

设 total = n*(n+1)//2（1 到 n 之和）。

能被 m 整除的数为：m, 2m, 3m, ..., km（其中 k = n // m）。

其和为 m * (1+2+...+k) = m * k*(k+1)//2。

设 div_sum = m * k*(k+1)//2，则：
- num2 = div_sum
- num1 = total - div_sum
- 答案 = num1 - num2 = total - 2 * div_sum

## Python 代码实现

### 方法一：遍历（简单直接）

```python
class Solution:
    def differenceOfSums(self, n: int, m: int) -> int:
        num1 = sum(i for i in range(1, n + 1) if i % m != 0)
        num2 = sum(i for i in range(1, n + 1) if i % m == 0)
        return num1 - num2
```

### 方法二：数学公式（推荐）

```python
class Solution:
    def differenceOfSums(self, n: int, m: int) -> int:
        # 1 到 n 的总和
        total = n * (n + 1) // 2
        # 能被 m 整除的数的个数
        k = n // m
        # 能被 m 整除的数之和：m + 2m + ... + km = m * k*(k+1)//2
        div_sum = m * k * (k + 1) // 2
        # num1 - num2 = (total - div_sum) - div_sum = total - 2 * div_sum
        return total - 2 * div_sum
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(1)，空间复杂度 O(1)

## 关键点总结

1. 核心公式：`num1 - num2 = total - 2 * div_sum`
2. 能被 m 整除的数为等差数列，求和公式 `m * k*(k+1)//2`
3. `k = n // m` 是 n 以内 m 的倍数个数

## 易错点

1. 注意是 1 到 n（含 n），不是 0 到 n
2. `n // m` 使用整数除法
