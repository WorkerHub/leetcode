## 题目描述

给你一个字符串 `date`，它的格式为 `Day Month Year`，其中：
- `Day` 是集合 `{"1st", "2nd", "3rd", "4th", ..., "30th", "31st"}` 中的一个元素
- `Month` 是集合 `{"Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"}` 中的一个元素
- `Year` 的范围在 `[1900, 2100]` 之间

请你将字符串转变为 `YYYY-MM-DD` 的格式，其中：
- `YYYY` 表示 4 位的年份
- `MM` 表示 2 位的月份
- `DD` 表示 2 位的天数

**示例 1：**
```
输入：date = "20th Oct 2052"
输出："2052-10-20"
```

**示例 2：**
```
输入：date = "6th Jun 1933"
输出："1933-06-06"
```

## 解题思路

### 方法一：字符串处理 + 字典映射

1. 按空格分割字符串，得到 day 字符串、month 字符串、year 字符串
2. 从 day 字符串中去掉后缀（"st"/"nd"/"rd"/"th"），得到数字
3. 用字典将月份缩写转换为数字
4. 格式化输出，用 `zfill(2)` 补零

## 代码实现

### 方法一：字典映射（推荐）

```python
class Solution:
    def reformatDate(self, date: str) -> str:
        # 月份缩写到数字的映射
        month_map = {
            "Jan": "01", "Feb": "02", "Mar": "03", "Apr": "04",
            "May": "05", "Jun": "06", "Jul": "07", "Aug": "08",
            "Sep": "09", "Oct": "10", "Nov": "11", "Dec": "12"
        }
        # 按空格分割
        parts = date.split()
        day_str, month_str, year_str = parts[0], parts[1], parts[2]

        # 去掉 day 的后缀（st/nd/rd/th），转为2位数字
        day_num = ''.join(filter(str.isdigit, day_str)).zfill(2)

        # 月份转换
        month_num = month_map[month_str]

        # 拼接结果
        return f"{year_str}-{month_num}-{day_num}"
```

### 方法二：使用 datetime 模块

```python
class Solution:
    def reformatDate(self, date: str) -> str:
        from datetime import datetime
        # 去掉日期后缀（st/nd/rd/th）
        for suffix in ["1st","2nd","3rd","4th","5th","6th","7th","8th","9th","10th",
                       "11th","12th","13th","14th","15th","16th","17th","18th","19th","20th",
                       "21st","22nd","23rd","24th","25th","26th","27th","28th","29th","30th","31st"]:
            date = date.replace(suffix, suffix[:-2] if suffix[-2:] in ("st","nd","rd") else suffix[:-2])
        # 简化：直接用 replace 去除英文后缀
        import re
        clean = re.sub(r'(\d+)(st|nd|rd|th)', r'\1', date)
        # 解析 "20 Oct 2052"
        dt = datetime.strptime(clean, "%d %b %Y")
        return dt.strftime("%Y-%m-%d")
```

### 方法三：简洁写法

```python
import re

class Solution:
    def reformatDate(self, date: str) -> str:
        months = ["Jan","Feb","Mar","Apr","May","Jun",
                  "Jul","Aug","Sep","Oct","Nov","Dec"]
        day, month, year = date.split()
        # 提取天数中的数字部分
        d = re.sub(r'\D', '', day).zfill(2)
        # 月份转数字（1-indexed）
        m = str(months.index(month) + 1).zfill(2)
        return f"{year}-{m}-{d}"
```

## 复杂度分析

- **时间复杂度**：O(1)，字符串长度有上界，处理是常数时间
- **空间复杂度**：O(1)，只用常数个变量

## 关键点总结

1. 日期后缀（st/nd/rd/th）可以用 `filter(str.isdigit, ...)` 或正则提取数字
2. 月份映射用字典最清晰
3. `zfill(2)` 可以将 "6" 补成 "06"
4. Python 的 `datetime.strptime` 可以用 `%b` 直接解析月份缩写

## 易错点

- 忘记对天数和月份补零（个位数需要前置 0）
- 月份字典键大小写敏感，需要与输入格式一致
