## 题目描述

给你两个字符串 s 和 goal ，只要我们可以通过交换 s 中的两个字母得到与 goal 相等的结果，就返回 true；否则返回 false 。

交换字母的定义是：取两个下标 i 和 j （下标从 0 开始）且满足 i != j ，接着交换 s[i] 和 s[j] 处的字符。

例如，在 "abcd" 中交换下标 0 和下标 2 的元素可以生成 "cbad" 。

**示例 1：**
```
输入：s = "ab", goal = "ba"
输出：true
解释：你可以交换 s[0] = 'a' 和 s[1] = 'b' 生成 "ba"，此时 s 和 goal 相等。
```

**示例 2：**
```
输入：s = "ab", goal = "ab"
输出：false
解释：你只能交换 s[0] = 'a' 和 s[1] = 'b' 生成 "ba"，此时 s 和 goal 不相等。
```

**示例 3：**
```
输入：s = "aa", goal = "aa"
输出：true
解释：你可以交换 s[0] = 'a' 和 s[1] = 'a' 生成 "aa"，此时 s 和 goal 相等。
```

**提示：**
- 1 <= s.length, goal.length <= 2 × 10^4
- s 和 goal 由小写英文字母组成

## 解题思路

这道题需要考虑**两种情况**：

**情况1：s 和 goal 不相等**
- 必须通过交换一次使得相等
- 找到所有不同的位置，必须恰好有 2 个
- 这 2 个位置交换后能使字符串相等

**情况2：s 和 goal 相等**
- 需要交换两个相同的字符（交换后仍相等）
- 只要 s 中有重复字符即可

**算法流程：**
1. 如果长度不同，直接返回 false
2. 找出所有 s[i] != goal[i] 的位置
3. 如果有 0 个不同：检查是否有重复字符
4. 如果有 2 个不同：检查交换后是否相等
5. 其他情况：返回 false

## Python 代码实现

### 方法一：直接模拟（推荐）⭐

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        # 长度不同，无法通过交换得到
        if len(s) != len(goal):
            return False
        
        # 如果两个字符串相等
        if s == goal:
            # 需要有重复字符才能交换（交换后仍相等）
            return len(set(s)) < len(s)
        
        # 找出所有不同的位置
        diff = [(s[i], goal[i]) for i in range(len(s)) if s[i] != goal[i]]
        
        # 必须恰好有 2 个不同的位置
        # 且交换后能相等
        return len(diff) == 2 and diff[0] == diff[1][::-1]
```

**代码说明：**
- `diff` 存储所有不同位置的字符对
- `diff[0] == diff[1][::-1]` 检查交换后是否相等
- `len(set(s)) < len(s)` 检查是否有重复字符

### 方法二：使用列表存储差异位置

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        if len(s) != len(goal):
            return False
        
        if s == goal:
            # 检查是否有重复字符
            seen = set()
            for char in s:
                if char in seen:
                    return True
                seen.add(char)
            return False
        
        # 记录不同位置
        diff_positions = []
        for i in range(len(s)):
            if s[i] != goal[i]:
                diff_positions.append(i)
        
        # 必须恰好 2 个不同
        if len(diff_positions) != 2:
            return False
        
        i, j = diff_positions
        return s[i] == goal[j] and s[j] == goal[i]
```

**代码说明：**
- 显式记录差异位置的索引
- 检查交换后是否匹配

### 方法三：使用 Counter

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        from collections import Counter
        
        if len(s) != len(goal):
            return False
        
        # 字符计数必须相同（必要条件）
        if Counter(s) != Counter(goal):
            return False
        
        if s == goal:
            # 至少有一个字符出现 2 次
            return any(count >= 2 for count in Counter(s).values())
        
        # 恰好有 2 个位置不同
        diff = sum(s[i] != goal[i] for i in range(len(s)))
        return diff == 2
```

**代码说明：**
- 先用 Counter 检查字符集是否相同
- 再检查具体条件

### 方法四：简洁版

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        if len(s) != len(goal):
            return False
        
        diff = [(a, b) for a, b in zip(s, goal) if a != b]
        
        if len(diff) == 0:
            return len(s) > len(set(s))
        
        if len(diff) == 2:
            return diff[0] == diff[1][::-1]
        
        return False
```

## 关键点总结

1. **两种情况**：s == goal 和 s != goal 分别处理
2. **重复字符检查**：`len(set(s)) < len(s)`
3. **差异位置**：必须恰好 2 个
4. **交换验证**：`diff[0] == diff[1][::-1]`
5. **长度检查**：首先检查长度是否相同

## 易错点

1. **忘记处理 s == goal 的情况**：
   ```python
   # ❌ 错误：没有检查重复字符
   if s == goal:
       return False
   
   # ✅ 正确
   if s == goal:
       return len(set(s)) < len(s)
   ```

2. **差异位置数量判断**：
   - 0 个：需要有重复字符
   - 2 个：需要交换后匹配
   - 其他：false

3. **交换验证错误**：
   ```python
   # ✅ 正确
   return diff[0] == diff[1][::-1]
   
   # ❌ 错误：只检查一个方向
   return diff[0][0] == diff[1][1]
   ```
