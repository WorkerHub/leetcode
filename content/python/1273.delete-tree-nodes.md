## 题目描述

给你一棵以节点 0 为根节点的树，树中共有 n 个节点，节点编号从 0 到 n-1。

每个节点都有一个关联值，由数组 value 给出，节点 i 的值为 value[i]。

另外，节点 i 的父节点由数组 parent 给出，其中 parent[0] == -1（根节点没有父节点）。

删除所有"值之和为 0 的子树"。当一个节点的子树中所有节点值之和为 0 时，删除该节点及其整个子树。

返回删除后树中剩余的节点数。

**示例 1：**
```
输入：nodes = 7, parent = [-1,0,0,1,2,2,2], value = [1,-2,4,0,-2,-1,-1]
输出：2
```

**示例 2：**
```
输入：nodes = 7, parent = [-1,0,0,1,2,2,2], value = [1,-2,4,0,-2,-1,-2]
输出：6
```

**示例 3：**
```
输入：nodes = 5, parent = [-1,0,1,2,3], value = [-672,441,18,766,1]
输出：5
```

**提示：**
- `1 <= nodes <= 10^4`
- `parent.length == nodes`
- `0 <= parent[i] <= nodes - 1`
- `parent[0] == -1` 表示节点 0 是根节点
- `value.length == nodes`
- `-10^5 <= value[i] <= 10^5`
- 该树是一棵有效的树

## 解题思路

**核心思想：** 用深度优先搜索（DFS）对树做后序遍历。

**为什么选后序遍历？**
后序遍历的特点是先处理子节点，再处理父节点。这样当我们处理某个节点时，它所有子节点的信息已经计算完毕，可以直接汇总。

**算法流程：**

1. 先用 parent 数组建立树的邻接表（子节点列表）
2. 对每个节点做 DFS，计算：
   - 该节点子树的 **节点值之和**
   - 该节点子树的 **节点数量**
3. 如果某节点子树值之和等于 0，则节点数设为 0（相当于删除）
4. 最终返回根节点的节点数量

**图解示例（示例 1）：**
```
         0(+1)
        / \
      1(-2) 2(+4)
      |    /|\
    3(0) 4(-2)5(-1)6(-1)

后序遍历处理顺序：3 -> 1 -> 4 -> 5 -> 6 -> 2 -> 0

节点3：sum=0，count=0（删除）
节点1：sum=-2+0=-2，count=1+0=1
节点4：sum=-2，count=1
节点5：sum=-1，count=1
节点6：sum=-1，count=1
节点2：sum=4+(-2)+(-1)+(-1)=0，count=0（删除整个子树！）
节点0：sum=1+(-2)+0=−1，count=1+1+0=2

结果：2
```

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def deleteTreeNodes(self, nodes: int, parent: List[int], value: List[int]) -> int:
        # 建立树的邻接表：key 为父节点，value 为子节点列表
        children = defaultdict(list)
        for i in range(1, nodes):  # 从1开始，因为0是根节点无父节点
            children[parent[i]].append(i)

        def dfs(node: int):
            """
            返回 (子树节点值之和, 子树节点数量)
            如果子树值之和为0，节点数量返回0表示被删除
            """
            total_sum = value[node]   # 当前节点的值
            total_count = 1           # 当前节点本身计为1

            for child in children[node]:
                child_sum, child_count = dfs(child)
                total_sum += child_sum       # 累加子树的值
                total_count += child_count   # 累加子树的节点数

            # 如果整棵子树的值之和为0，删除它（节点数置为0）
            if total_sum == 0:
                total_count = 0

            return total_sum, total_count

        # 从根节点0开始DFS，返回最终节点数
        _, result = dfs(0)
        return result
```

### 方法二：BFS 拓扑排序（迭代，自底向上）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def deleteTreeNodes(self, nodes: int, parent: List[int], value: List[int]) -> int:
        # 建立邻接表和统计每个节点的子节点数
        children = defaultdict(list)
        child_count = [0] * nodes  # 每个节点的子节点数量

        for i in range(1, nodes):
            children[parent[i]].append(i)
            child_count[parent[i]] += 1

        # 初始化每个节点的子树值和节点数
        subtree_sum = value[:]         # 子树节点值之和（初始为自身值）
        subtree_count = [1] * nodes    # 子树节点数量（初始为1）

        # 从叶子节点开始，逐层向根节点汇总（拓扑排序）
        queue = deque()
        for i in range(nodes):
            if child_count[i] == 0:  # 叶子节点（无子节点）
                queue.append(i)

        while queue:
            node = queue.popleft()

            # 如果当前子树值之和为0，删除（节点数置为0）
            if subtree_sum[node] == 0:
                subtree_count[node] = 0

            # 将信息汇总到父节点
            par = parent[node]
            if par != -1:
                subtree_sum[par] += subtree_sum[node]
                subtree_count[par] += subtree_count[node]
                child_count[par] -= 1
                if child_count[par] == 0:  # 父节点的所有子节点都处理完了
                    queue.append(par)

        return subtree_count[0]
```

### 方法三：DFS 迭代（使用栈，避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def deleteTreeNodes(self, nodes: int, parent: List[int], value: List[int]) -> int:
        # 建立邻接表
        children = defaultdict(list)
        for i in range(1, nodes):
            children[parent[i]].append(i)

        subtree_sum = value[:]
        subtree_count = [1] * nodes

        # 使用迭代DFS，先找到后序遍历顺序
        order = []
        stack = [0]
        while stack:
            node = stack.pop()
            order.append(node)
            for child in children[node]:
                stack.append(child)

        # 按后序（逆序）处理
        for node in reversed(order):
            if subtree_sum[node] == 0:
                subtree_count[node] = 0
            par = parent[node]
            if par != -1:
                subtree_sum[par] += subtree_sum[node]
                subtree_count[par] += subtree_count[node]

        return subtree_count[0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 递归 | O(n) | O(n)（递归栈+邻接表） |
| BFS 拓扑排序 | O(n) | O(n) |
| DFS 迭代 | O(n) | O(n) |

- **时间复杂度 O(n)**：每个节点只访问一次
- **空间复杂度 O(n)**：邻接表存储 n-1 条边，递归深度最坏为 O(n)（链状树）

## 关键点总结

1. **后序遍历**：必须先处理子节点再处理父节点，才能正确汇总子树信息
2. **删除操作转化**：不需要真正删除节点，只需将节点数设为 0 即可
3. **子树信息上传**：每个节点向父节点传递两个信息：值之和与节点数量
4. **判断时机**：在汇总完所有子节点信息后，再判断该子树是否需要删除
5. **建树方式**：通过 parent 数组构建邻接表，方便 DFS 遍历子节点

## 易错点

1. **处理顺序错误**：不能在处理子节点之前判断是否删除，必须等子树信息全部汇总后才判断
2. **根节点特殊处理**：parent[0] == -1，建树时要从 i=1 开始循环
3. **值之和为0才删除**：是"子树节点值之和"为0，不是单个节点的值为0
4. **递归深度**：节点数可达 10^4，链状树时递归深度为 10^4，Python 默认递归限制为 1000，实际竞赛中需要注意，可改用迭代版本
