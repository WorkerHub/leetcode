## 题目描述

给定一个数字字符串 `num`，比如 `"11235813"`，我们可以将它分成一个斐波那契式的序列 `[1, 1, 2, 3, 5, 8, 13]`。

返回任意一组序列分割方式。如果不能分割则返回 `[]`。

斐波那契式序列是一个非负整数列表 `f`，且满足：
- `0 <= f[i] < 2^31` 
- `f.length >= 3`
- 对于所有的 `i + 2 < f.length` 都有 `f[i] + f[i+1] = f[i+2]`

## Python 代码实现

```python
from typing import List

class Solution:
    def splitIntoFibonacci(self, num: str) -> List[int]:
        n = len(num)
        
        def backtrack(index, path):
            if index == n and len(path) >= 3:
                return path
            
            for i in range(index, n):
                # 前导零检查
                if num[index] == '0' and i > index:
                    break
                
                curr = int(num[index:i+1])
                
                # 溢出检查
                if curr >= 2**31:
                    break
                
                # 斐波那契检查
                if len(path) < 2 or path[-1] + path[-2] == curr:
                    result = backtrack(i + 1, path + [curr])
                    if result:
                        return result
                elif len(path) >= 2 and path[-1] + path[-2] < curr:
                    break
            
            return []
        
        return backtrack(0, [])
```

## 复杂度分析

- **时间复杂度**：O(n × 2^n)
- **空间复杂度**：O(n)

## 关键点总结

1. **回溯**：尝试所有分割方式
2. **剪枝**：前导零、溢出、大于和 都可剪枝
3. **斐波那契性质**：前两个数确定后面所有数
