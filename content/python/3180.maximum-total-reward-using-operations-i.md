## 题目描述

给你一个整数数组 `rewardValues`，长度为 `n`，代表 n 个奖励值。

初始总奖励为 0，你可以按任意顺序选取奖励，但每次选取的值必须 **严格大于** 当前总奖励。

返回可能获得的 **最大** 总奖励。

**示例 1：**
```
输入：rewardValues = [1,1,3,3]
输出：4
解释：先取 1，总奖励 1；再取 3（3>1），总奖励 4；无法再取。
```

**示例 2：**
```
输入：rewardValues = [1,6,4,3,2]
输出：11
解释：取 1+2+3+5... 最优为 1+4+6=11
```

**提示：**
- `1 <= rewardValues.length <= 2000`
- `1 <= rewardValues[i] <= 2000`

## 解题思路

排序后，DP 判断哪些总奖励值是可以达到的。

`dp[v]` 表示总奖励值 v 是否可达。对每个奖励 r（从小到大），若当前总奖励 v < r，则 v + r 可以由 v 转移得到。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        rewardValues = sorted(set(rewardValues))
        max_val = rewardValues[-1]
        # dp[v] = 总奖励为 v 是否可达
        dp = [False] * (max_val * 2)
        dp[0] = True

        for r in rewardValues:
            # 从 r-1 到 0 倒序遍历，避免重复使用
            for v in range(r - 1, -1, -1):
                if dp[v]:
                    dp[v + r] = True

        return max(v for v in range(len(dp)) if dp[v])
```

### 方法二：使用 bitset

```python
from typing import List

class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        rewardValues = sorted(set(rewardValues))
        # 用整数位图表示可达集合
        dp = 1  # dp & (1 << v) 表示总奖励 v 可达，初始 v=0 可达

        for r in rewardValues:
            # 可达的 v（0 <= v < r）加上 r 后仍然可达
            # 取 dp 中 v < r 的部分，左移 r 位
            mask = (1 << r) - 1
            dp |= (dp & mask) << r

        return dp.bit_length() - 1
```

## 复杂度分析

- 时间复杂度：O(n * max_val)（方法一），O(n * max_val / 64)（方法二 bitset）
- 空间复杂度：O(max_val)

## 关键点总结

1. 排序后，每个奖励只能在当前总奖励小于它时使用
2. DP 标记所有可达总奖励值
3. bitset 优化将位操作并行化

## 易错点

1. 去重 rewardValues（相同值只使用一次）
2. 倒序遍历避免重复使用同一奖励
