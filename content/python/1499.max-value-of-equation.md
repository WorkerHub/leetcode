## 题目描述

给你一个数组 `points`，它包含 `N` 个点 `(xi, yi)`，这些点按照 `xi` 从小到大排序。同时给你一个整数 `k`。

请你从 `points` 中找出满足 `xi <= xj` 且 `|xi - xj| <= k` 的点对 `(i, j)`，使得 `yi + yj + |xi - xj|` 的值最大，并返回该最大值。

你只有在满足至少有一对有效点的情况下，才能从上述函数中返回结果。

**示例 1：**

```
输入：points = [[1,3],[2,0],[5,10],[6,-10]], k = 1
输出：4
解释：(1,3) 和 (2,0) 满足 |1-2| = 1 <= k=1
yi + yj + |xi - xj| = 3 + 0 + 1 = 4
（其他所有有效点对的值都 <= 4）
```

**示例 2：**

```
输入：points = [[0,0],[3,0],[9,2]], k = 3
输出：3
解释：(0,0) 和 (3,0)：0+0+3=3
(3,0) 和 (9,2)：|3-9|=6 > 3，不满足
最大值 = 3
```

**提示：**

- `2 <= points.length <= 10^5`
- `points[i].length == 2`
- `-10^8 <= xi, yi <= 10^8`
- `0 <= k <= 2 * 10^8`
- `xi < xj`（任意两点 x 坐标不同）
- `xi` 单调递增

## 解题思路

**数学化简是关键。**

由于 `points` 按 `xi` 升序排列，对于任意 `i < j`，有 `xi < xj`，因此 `|xi - xj| = xj - xi`。

原式变为：

```
yi + yj + xj - xi = (yj + xj) + (yi - xi)
```

固定 `j`（外层循环），需要在满足 `xj - xi <= k` 的所有 `i < j` 中，找使 `(yi - xi)` 最大的 `i`。

**单调双端队列（单调队列）维护窗口最大值：**

- 队列中存储下标，队列头部的元素具有最大的 `(yi - xi)` 值。
- 当新来的点 `j` 时：
  1. 弹出队头超出窗口的点（`xj - x_head > k`）。
  2. 队头的 `(y_head - x_head)` 就是当前窗口的最大值，更新答案。
  3. 将 `j` 加入队尾前，弹出所有 `(yi - xi) <= (yj - xj)` 的尾部元素（维护单调性：保证队列从头到尾的 `yi - xi` 值单调递减）。

**堆方法：** 用最大堆存储 `(yi - xi, xi)`，每次弹出过期元素（`xj - xi > k`），堆顶即为最大值。

## Python 代码实现

### 方法一：单调双端队列（推荐，O(n)）

```python
from typing import List
from collections import deque

class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        # 单调队列：存储 (y - x, x)，队头始终是当前窗口内 (yi - xi) 最大的点
        dq = deque()
        ans = float('-inf')

        for xj, yj in points:
            # 1. 弹出队头不在窗口内的元素（xj - xi > k）
            while dq and xj - dq[0][1] > k:
                dq.popleft()

            # 2. 若队列非空，更新答案
            if dq:
                # ans = (yj + xj) + max(yi - xi)
                ans = max(ans, yj + xj + dq[0][0])

            # 3. 维护单调性：弹出队尾所有 (yi - xi) <= (yj - xj) 的元素
            # （当前点 j 比它们更优，且 j 的 xj 更大，能覆盖更多未来的 j'）
            while dq and dq[-1][0] <= yj - xj:
                dq.pop()

            # 4. 将当前点加入队尾
            dq.append((yj - xj, xj))

        return ans
```

### 方法二：最大堆（O(n log n)）

```python
from typing import List
import heapq

class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        # 最大堆：存储 (-(yi-xi), xi)（Python heapq 是最小堆，取负模拟最大堆）
        heap = []
        ans = float('-inf')

        for xj, yj in points:
            # 弹出超出窗口的堆顶元素
            while heap and xj - heap[0][1] > k:
                heapq.heappop(heap)

            # 堆顶是当前窗口内 (yi - xi) 最大的元素
            if heap:
                ans = max(ans, yj + xj + (-heap[0][0]))

            # 将当前点加入堆
            heapq.heappush(heap, (-(yj - xj), xj))

        return ans
```

### 方法三：暴力枚举（O(n^2)，仅用于理解）

```python
from typing import List

class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        n = len(points)
        ans = float('-inf')

        for j in range(n):
            xj, yj = points[j]
            for i in range(j):
                xi, yi = points[i]
                # 检查距离约束
                if xj - xi > k:
                    continue
                val = yi + yj + (xj - xi)
                ans = max(ans, val)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（单调队列） | O(n) | O(n) |
| 方法二（堆） | O(n log n) | O(n) |
| 方法三（暴力） | O(n^2) | O(1) |

- 单调队列每个元素最多入队/出队一次，总 O(n)
- 堆方法每个元素最多入堆/出堆一次，O(log n) 操作，总 O(n log n)
- n 可达 10^5，方法一最优

```

     ans = 0+2 + 2 = 4
     y-x = 0-2 = -2 < 2，直接追加 dq: [(2,1),(-2,2)]

     加入 dq: [(5,5)]（y-x=10-5=5）

```

## 关键点总结

1. **代数化简**：`yi + yj + |xi - xj| = (yj + xj) + (yi - xi)`，分离变量是解题关键。
2. **单调队列思想**：维护滑动窗口最大值，每个元素入队出队各一次，O(n) 完成。
3. **队列存储内容**：存 `(yi - xi, xi)` 方便同时检查窗口约束（用 xi）和取最大值（用 yi-xi）。
4. **先更新答案，后维护队列**：必须先用队头更新答案，再将当前点加入队列（否则点会与自身配对）。

## 易错点

- **先弹队头再更新**：每次先弹出过期的队头，再用新队头更新答案。
- **先更新答案再入队**：当前点 `j` 不能与自身配对，必须先用已有队列更新答案后再加入。
- **单调队列维护方向**：队列从头到尾 `yi - xi` 单调递减（队头最大），这样队头始终是最大值。
- **`xi < xj` 的利用**：题目保证 x 坐标严格递增，所以 `|xi-xj| = xj-xi`，大大简化了推导。
