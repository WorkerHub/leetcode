## 题目描述

给你一个整数 `num`。你可以对它进行如下操作：

- 选择 `num` 中某一位数字 `x`（`0 <= x <= 9`）。
- 选择另一个数字 `y`（`0 <= y <= 9`），将 `num` 中**所有** `x` 替换为 `y`。

注意替换后的数字不能有前导零（除非结果就是 0 本身），且不能是零（即不能让整数变为 0）。

你可以对 `num` 执行上述操作**两次**，第一次操作让 `num` 尽可能大（得到 `a`），第二次让 `num` 尽可能小（得到 `b`）。

返回 `a - b`。

**示例 1：**
```
输入：num = 555
输出：888
解释：
a = 999（将 5 替换为 9）
b = 111（将 5 替换为 1）
a - b = 888
```

**示例 2：**
```
输入：num = 9
输出：8
解释：
a = 9（已是最大）
b = 1（将 9 替换为 1）
a - b = 8
```

**示例 3：**
```
输入：num = 123456
输出：820000+...
解释：
a = 923456（将 1 替换为 9）
b = 103456（将 2 替换为 0）
```

**提示：**
- `1 <= num <= 10^8`

## 解题思路

**贪心策略：**

**求最大值 a（将某位替换为 9）：**
- 从左到右找第一个不是 `9` 的数字，将其全部替换为 `9`。
- 若所有位都是 `9`，则 `a = num`。

**求最小值 b（将某位替换为 0 或 1）：**
- 如果**首位不是 `1`**：将首位替换为 `1`，可以最小化（首位不能为 0，否则有前导零）。
- 如果**首位是 `1`**：从左到右找第一个不是 `0` 也不是 `1` 的数字，将其替换为 `0`。
- 若所有位都是 `0` 或 `1`，则无法减小，`b = num`（实际上此时 b 已经很小了）。

## Python 代码实现

### 方法一：字符串替换（推荐）

```python
class Solution:
    def maxDiff(self, num: int) -> int:
        s = str(num)

        # --- 求最大值 a ---
        # 找第一个非 9 的数字，替换为 9
        a = s
        for ch in s:
            if ch != '9':
                a = s.replace(ch, '9')
                break

        # --- 求最小值 b ---
        # 首位不是 1：将首位替换为 1（不产生前导零）
        b = s
        if s[0] != '1':
            b = s.replace(s[0], '1')
        else:
            # 首位是 1：找第一个非 0 非 1 的数字，替换为 0
            for ch in s[1:]:  # 跳过首位
                if ch != '0' and ch != '1':
                    b = s.replace(ch, '0')
                    break

        return int(a) - int(b)
```

### 方法二：显式遍历（更清晰的逻辑）

```python
class Solution:
    def maxDiff(self, num: int) -> int:
        digits = list(str(num))

        # --- 求最大值 a ---
        # 找第一个非 9 的位，全部替换为 9
        replace_for_max = None
        for d in digits:
            if d != '9':
                replace_for_max = d
                break

        if replace_for_max:
            a_digits = [('9' if d == replace_for_max else d) for d in digits]
        else:
            a_digits = digits[:]

        # --- 求最小值 b ---
        replace_for_min = None
        replace_with = None

        if digits[0] != '1':
            # 首位不是 1，将首位替换为 1
            replace_for_min = digits[0]
            replace_with = '1'
        else:
            # 首位是 1，找第一个非 0 非 1 的位（从第二位开始）
            for d in digits[1:]:
                if d != '0' and d != '1':
                    replace_for_min = d
                    replace_with = '0'
                    break

        if replace_for_min:
            b_digits = [(replace_with if d == replace_for_min else d) for d in digits]
        else:
            b_digits = digits[:]

        a = int(''.join(a_digits))
        b = int(''.join(b_digits))
        return a - b
```

### 方法三：简洁版（利用 Python 字符串 replace 特性）

```python
class Solution:
    def maxDiff(self, num: int) -> int:
        s = str(num)

        # 最大值：找第一个非9的字符替换成9
        a = int(s.replace(next((c for c in s if c != '9'), ''), '9') or s)

        # 最小值
        if s[0] != '1':
            # 首位非1，替换首位为1
            b = int(s.replace(s[0], '1'))
        else:
            # 找第一个非0非1的字符替换成0
            target = next((c for c in s[1:] if c not in '01'), None)
            b = int(s.replace(target, '0')) if target else int(s)

        return a - b
```

## 复杂度分析

- **时间复杂度：** O(d)，d 为 `num` 的位数（最多 9 位），字符串替换操作 O(d)。
- **空间复杂度：** O(d)，存储字符串。

## 图解示例

```
num = 123456，s = "123456"

求最大值 a：
  第一个非 9 的字符是 '1'
  将所有 '1' 替换为 '9' -> "923456"
  a = 923456

求最小值 b：
  首位 '1' == '1'，进入第二个分支
  从第二位开始，找第一个非 0 非 1 的字符 -> '2'
  将所有 '2' 替换为 '0' -> "103456"
  b = 103456

a - b = 923456 - 103456 = 820000
```

## 关键点总结

1. 求最大值：找第一个不是 `9` 的位，全部改为 `9`（贪心，越高位越大）。
2. 求最小值：首位只能改为 `1`（不能有前导零）；非首位可以改为 `0`。
3. Python 的 `str.replace(old, new)` 会替换所有出现，刚好符合题意。
4. 如果首位已经是 `1`，则从第二位开始找替换目标。

## 易错点

- 首位替换为 `0` 会产生前导零，这是非法的，必须替换为 `1`。
- 求最小值时，首位是 `1` 的情况需要单独处理，不能简单地将 `1` 替换为 `0`。
- Python 的 `replace` 是全局替换，符合题意（题目要求将所有同一位数字都替换）。
