## 题目描述

给定一个只包含三种字符的字符串：'('、')' 和 '*'，判断字符串是否有效。

有效字符串需满足：
1. 任何左括号 '(' 必须有相应的右括号 ')'
2. 任何右括号 ')' 必须有相应的左括号 '('
3. 左括号 '(' 必须在对应的右括号之前 ')'
4. '*' 可以被视为单个右括号 ')' 、单个左括号 '(' 、或一个空字符串

**示例 1：**
```
输入：s = "()"
输出：true
```

**示例 2：**
```
输入：s = "(*)"
输出：true
```

**示例 3：**
```
输入：s = "(*))"
输出：true
```

**提示：**
- 1 <= s.length <= 100
- s[i] 为 '('、')' 或 '*'

## 解题思路

这道题的难点在于 '*' 的多种可能性。

**核心思想：**
维护可能的左括号数量的范围 [low, high]。

**贪心策略：**
- 遇到 '('：low++, high++
- 遇到 ')'：low--, high--
- 遇到 '*'：
  - 当作 '(' 时：high++
  - 当作 ')' 时：low--
  - 当作空字符时：不变
  - 因此：low--, high++

**关键判断：**
- high < 0：右括号太多，无法匹配
- low < 0：将low重置为0（可以用*抵消）
- 最后 low == 0：所有左括号都匹配

## Python 代码实现

### 方法一：贪心（推荐）⭐

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = high = 0  # 可能的左括号数量范围
        
        for char in s:
            if char == '(':
                low += 1
                high += 1
            elif char == ')':
                low -= 1
                high -= 1
            else:  # char == '*'
                low -= 1   # 把*当作)
                high += 1  # 把*当作(
            
            # 右括号太多，无法匹配
            if high < 0:
                return False
            
            # low不能小于0，重置为0
            low = max(low, 0)
        
        # 最后必须能消除所有左括号
        return low == 0
```

### 方法二：双向扫描

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        # 从左到右：检查右括号是否过多
        balance = 0
        for char in s:
            if char in '(*':
                balance += 1
            else:
                balance -= 1
            
            if balance < 0:
                return False
        
        # 从右到左：检查左括号是否过多
        balance = 0
        for char in reversed(s):
            if char in ')*':
                balance += 1
            else:
                balance -= 1
            
            if balance < 0:
                return False
        
        return True
```

### 方法三：动态规划

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        n = len(s)
        # dp[i][j]: s[i:j+1]是否有效
        dp = [[False] * n for _ in range(n)]
        
        # 单个字符：只有*有效
        for i in range(n):
            if s[i] == '*':
                dp[i][i] = True
        
        # 两个字符
        for i in range(n - 1):
            if (s[i] == '(' or s[i] == '*') and (s[i+1] == ')' or s[i+1] == '*'):
                dp[i][i+1] = True
            elif s[i] == '*' and s[i+1] == '*':
                dp[i][i+1] = True
        
        # 更长的子串
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                # 情况1：s[i]和s[j]配对
                if (s[i] == '(' or s[i] == '*') and (s[j] == ')' or s[j] == '*'):
                    if i + 1 > j - 1 or dp[i+1][j-1]:
                        dp[i][j] = True
                
                # 情况2：分割成两部分
                if not dp[i][j]:
                    for k in range(i, j):
                        if dp[i][k] and dp[k+1][j]:
                            dp[i][j] = True
                            break
        
        return dp[0][n-1] if n > 0 else True
```

### 方法四：栈

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        left_stack = []   # 存储'('的索引
        star_stack = []   # 存储'*'的索引
        
        for i, char in enumerate(s):
            if char == '(':
                left_stack.append(i)
            elif char == '*':
                star_stack.append(i)
            else:  # char == ')'
                if left_stack:
                    left_stack.pop()
                elif star_stack:
                    star_stack.pop()
                else:
                    return False
        
        # 匹配剩余的左括号和星号
        while left_stack and star_stack:
            # 左括号必须在星号之前
            if left_stack[-1] > star_stack[-1]:
                return False
            left_stack.pop()
            star_stack.pop()
        
        return len(left_stack) == 0
```

## 复杂度分析

**方法一：贪心**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法二：双向扫描**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法三：动态规划**
- 时间复杂度：O(n³)
- 空间复杂度：O(n²)

**方法四：栈**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **范围思想**：维护可能的左括号数量范围
2. **贪心策略**：*在不同位置选择不同的角色
3. **重置low**：low可能小于0，要重置为0
4. **high检查**：high<0说明右括号太多
5. **最终判断**：low必须为0，high可以>0

## 易错点

1. **low重置**：low<0时要重置为0，不能直接返回false
2. **high判断**：high<0才返回false，不是low<0
3. **最终条件**：返回low==0，不是high==0
4. **栈方法**：要检查左括号索引是否在星号之前
5. **空字符串**：要处理空字符串的情况
