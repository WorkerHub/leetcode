## 题目描述

实现一个线程安全的有界阻塞队列，该队列具有以下方法：

- `BoundedBlockingQueue(int capacity)` 构造方法，队列的容量为 `capacity`。
- `void enqueue(int element)` 在队首增加一个元素。如果队列已满，调用线程会被阻塞，直到队列不满。
- `int dequeue()` 返回队尾元素并从队列中移除。如果队列为空，调用线程会被阻塞，直到队列非空。
- `int size()` 返回队列中的元素数量。

实现应该支持多个线程同时调用 `enqueue`、`dequeue` 和 `size` 方法。

**示例：**
```
输入：
1
1
["BoundedBlockingQueue","enqueue","dequeue","dequeue","enqueue","enqueue","enqueue","enqueue","dequeue"]
[[2],[1],[],[],[0],[2],[3],[4],[]]

输出：
[1,0,2,2]

解释：
线程1: BoundedBlockingQueue queue = new BoundedBlockingQueue(2);
线程1: queue.enqueue(1);  // 队列为 [1]
线程2: queue.dequeue();    // 返回 1，队列为 []
线程3: queue.dequeue();    // 阻塞等待
线程1: queue.enqueue(0);  // 队列为 [0]，线程3被唤醒
线程3: 返回 0，队列为 []
线程1: queue.enqueue(2);  // 队列为 [2]
线程1: queue.enqueue(3);  // 队列为 [2,3]
线程1: queue.enqueue(4);  // 阻塞等待，因为队列已满
线程2: queue.dequeue();    // 返回 2，队列为 [3]，线程1被唤醒
线程1: queue.enqueue(4);  // 队列为 [3,4]
线程3: queue.size();       // 返回 2
```

**提示：**
- `1 <= Number of Prcesses <= 4`
- `1 <= Number of Calls <= 4000`
- `1 <= queue.capacity, queue.size() <= 4000`
- `0 <= element <= 10^9`

## 解题思路

这道题是一个经典的生产者-消费者问题，需要实现线程安全的阻塞队列。

**核心思路：**

1. **线程同步机制**：使用锁（Lock）和条件变量（Condition）来实现线程间的同步和通信。

2. **阻塞条件**：
   - `enqueue` 时，如果队列已满，需要等待（阻塞）
   - `dequeue` 时，如果队列为空，需要等待（阻塞）

3. **唤醒机制**：
   - `enqueue` 成功后，唤醒等待 dequeue 的线程
   - `dequeue` 成功后，唤醒等待 enqueue 的线程

4. **数据结构选择**：使用 Python 的 `collections.deque` 作为底层队列，支持高效的两端操作。

## Python 代码实现

### 方法一：使用 threading.Condition（推荐）⭐

```python
from threading import Lock, Condition
from collections import deque

class BoundedBlockingQueue:
    def __init__(self, capacity: int):
        """
        初始化有界阻塞队列
        :param capacity: 队列的最大容量
        """
        self.capacity = capacity
        self.queue = deque()
        self.lock = Lock()
        # 条件变量：队列非满
        self.not_full = Condition(self.lock)
        # 条件变量：队列非空
        self.not_empty = Condition(self.lock)

    def enqueue(self, element: int) -> None:
        """
        在队列尾部添加元素，如果队列已满则阻塞
        :param element: 要添加的元素
        """
        with self.not_full:
            # 如果队列已满，等待
            while len(self.queue) >= self.capacity:
                self.not_full.wait()
            
            # 添加元素
            self.queue.append(element)
            
            # 通知等待 dequeue 的线程
            self.not_empty.notify()

    def dequeue(self) -> int:
        """
        从队列头部移除并返回元素，如果队列为空则阻塞
        :return: 队列头部的元素
        """
        with self.not_empty:
            # 如果队列为空，等待
            while len(self.queue) == 0:
                self.not_empty.wait()
            
            # 移除并返回元素
            element = self.queue.popleft()
            
            # 通知等待 enqueue 的线程
            self.not_full.notify()
            
            return element

    def size(self) -> int:
        """
        返回队列中的元素数量
        :return: 队列大小
        """
        with self.lock:
            return len(self.queue)
```

### 方法二：使用 queue.Queue（简化版）

```python
from queue import Queue

class BoundedBlockingQueue:
    def __init__(self, capacity: int):
        """
        使用 Python 标准库的 Queue
        """
        self.queue = Queue(maxsize=capacity)

    def enqueue(self, element: int) -> None:
        """
        Queue.put() 会自动阻塞
        """
        self.queue.put(element)

    def dequeue(self) -> int:
        """
        Queue.get() 会自动阻塞
        """
        return self.queue.get()

    def size(self) -> int:
        """
        返回队列大小
        """
        return self.queue.qsize()
```

### 方法三：使用信号量 Semaphore

```python
from threading import Semaphore, Lock
from collections import deque

class BoundedBlockingQueue:
    def __init__(self, capacity: int):
        """
        使用信号量实现生产者-消费者模型
        """
        self.capacity = capacity
        self.queue = deque()
        # 信号量：表示空位数量
        self.empty_slots = Semaphore(capacity)
        # 信号量：表示元素数量
        self.full_slots = Semaphore(0)
        # 互斥锁：保护队列操作
        self.lock = Lock()

    def enqueue(self, element: int) -> None:
        """
        入队操作
        """
        # 获取一个空位（如果没有空位则阻塞）
        self.empty_slots.acquire()
        
        with self.lock:
            self.queue.append(element)
        
        # 释放一个元素信号量
        self.full_slots.release()

    def dequeue(self) -> int:
        """
        出队操作
        """
        # 获取一个元素（如果没有元素则阻塞）
        self.full_slots.acquire()
        
        with self.lock:
            element = self.queue.popleft()
        
        # 释放一个空位信号量
        self.empty_slots.release()
        
        return element

    def size(self) -> int:
        """
        返回队列大小
        """
        with self.lock:
            return len(self.queue)
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：
  - `enqueue`：O(1)
  - `dequeue`：O(1)
  - `size`：O(1)
- **空间复杂度**：O(capacity)，存储队列元素的空间

## 关键点总结

1. **条件变量的使用**：`Condition` 允许线程在特定条件下等待和被唤醒
2. **while 而非 if**：使用 `while` 循环检查条件，防止虚假唤醒
3. **通知机制**：`notify()` 唤醒一个等待线程，`notify_all()` 唤醒所有等待线程
4. **上下文管理器**：使用 `with` 语句自动管理锁的获取和释放
5. **信号量的语义**：`Semaphore(n)` 表示有 n 个资源可用

## 易错点

1. **使用 if 代替 while**：必须使用 `while` 循环检查条件，因为可能发生虚假唤醒
2. **忘记通知等待线程**：入队后要通知出队线程，出队后要通知入队线程
3. **死锁风险**：确保每次获取锁后最终都会释放
4. **size 方法的线程安全**：即使是简单的 `len()` 操作也需要加锁
5. **条件变量共享锁**：`not_full` 和 `not_empty` 必须共享同一个锁
