## 题目描述

与 3297 完全相同的问题，但数据范围更大：
- `1 <= word1.length <= 10^6`
- `1 <= word2.length <= 10^4`

**示例 1：**
```
输入：word1 = "bcca", word2 = "abc"
输出：1
```

**提示：**
- `1 <= word1.length <= 10^6`

## 解题思路

与 3297 完全相同的滑动窗口算法，O(n) 时间，可以处理更大的数据范围。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def validSubstringCount(self, word1: str, word2: str) -> int:
        need = Counter(word2)
        win = Counter()
        deficit = len(need)  # 还需满足的字符种数
        
        left = 0
        ans = 0
        n = len(word1)
        
        for right in range(n):
            c = word1[right]
            win[c] += 1
            if c in need and win[c] == need[c]:
                deficit -= 1
            
            while deficit == 0:
                # 以 right 结尾的满足条件的子串数 = left（含 [0..right], [1..right], ..., [left..right]）
                ans += n - right
                lc = word1[left]
                win[lc] -= 1
                if lc in need and win[lc] < need[lc]:
                    deficit += 1
                left += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(|word1| + |word2|)
- 空间复杂度：O(26)

## 关键点总结

与 3297 相同，滑动窗口实现无需优化即可处理 10^6 的数据量。
