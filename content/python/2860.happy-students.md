## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，其中 `nums[i]` 是第 i 名学生**期望**选中的数量（包括自己）。

从 `n` 名学生中选出 `k` 名（0 <= k <= n）：
- 被选中的学生 i 满足 `k > nums[i]`（选的比期望多）
- 未被选中的学生 i 满足 `k < nums[i]`（选的比期望少）

返回能让**所有学生都快乐**的选法数量。

**示例 1：**
```
输入：nums = [1,1]
输出：2
解释：k=0：所有人未选，需要 k < nums[i]，即 0 < 1 ✓；k=2：所有人选，需要 k > nums[i]，即 2 > 1 ✓
k=1：选 1 人，选中的要 k > nums[i] 即 1>1 ✗
答案 = 2
```

**示例 2：**
```
输入：nums = [6,0,3,3,6,7,2,7]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= n`

## 解题思路

排序后枚举选 k 人（0 到 n）：

排序后，若选 k 人（下标 0 到 k-1 被选）：
- 对于选中的 k 人（下标 0 到 k-1）：需要 `k > nums[i]`，即 `nums[k-1] < k`（排序后最大的那个满足就行）
- 对于未选中的 n-k 人（下标 k 到 n-1）：需要 `k < nums[i]`，即 `nums[k] > k`（排序后最小的那个满足就行）

**特殊情况：**
- k = 0：没有人被选，所有人未被选，需要 `nums[i] > 0` for all i，即 `nums[0] > 0`
- k = n：所有人被选，需要 `nums[i] < n` for all i，即 `nums[n-1] < n`

## Python 代码实现

### 方法一：排序 + 枚举（推荐）

```python
from typing import List

class Solution:
    def countWays(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        ans = 0

        for k in range(n + 1):
            # k = 0：所有人未被选，需要 nums[0] > 0
            if k == 0:
                if nums[0] > 0:
                    ans += 1
            # k = n：所有人被选，需要 nums[n-1] < n
            elif k == n:
                if nums[n - 1] < n:
                    ans += 1
            else:
                # 选 k 人（下标 0..k-1）
                # 最后一个被选的：nums[k-1] < k（满足被选条件）
                # 第一个未选的：nums[k] > k（满足未选条件）
                if nums[k - 1] < k and nums[k] > k:
                    ans += 1

        return ans
```

### 方法二：更简洁

```python
from typing import List

class Solution:
    def countWays(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        ans = 0

        # k=0 特殊处理
        if nums[0] > 0:
            ans += 1

        # k=1 到 k=n-1
        for k in range(1, n):
            if nums[k - 1] < k < nums[k]:
                ans += 1

        # k=n 特殊处理
        if nums[-1] < n:
            ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后，选 k 人时只需检查边界条件（排序后的第 k 个和第 k+1 个）
2. 被选条件 k > nums[i] 对所有被选者成立 ⟺ 最大被选者 nums[k-1] < k
3. 未选条件 k < nums[i] 对所有未选者成立 ⟺ 最小未选者 nums[k] > k

## 易错点

1. k=0 和 k=n 的边界情况需单独处理
2. 条件 `nums[k-1] < k < nums[k]`：中间那个 `k` 是被选的人数，不是下标
3. `nums` 排序前保留各人的偏好，排序后最小的先被选
