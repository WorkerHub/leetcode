## 题目描述

给你三个正整数 `a`、`b` 和 `c`。每次操作你可以选择其中两个**非零**整数同时减 1。请你通过三次这样的操作来最大化操作次数。

**示例 1：**
```
输入：a = 2, b = 4, c = 6
输出：6
```

**示例 2：**
```
输入：a = 4, b = 4, c = 6
输出：7
```

**示例 3：**
```
输入：a = 1, b = 8, c = 8
输出：8
```

**提示：**
- `1 <= a, b, c <= 10^5`

## 解题思路

贪心：每次选最大的两个数各减 1，尽量让数字均衡。

**数学结论**：
- 设三个数之和为 `s = a + b + c`
- 若最大值 >= 另外两个数之和，则答案为另外两个数之和（最大值太多，只能和其他配对）
- 否则答案为 `s // 2`（可以尽量均匀地消耗）

## 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def maximumScore(self, a: int, b: int, c: int) -> int:
        # 排序，令 a <= b <= c
        a, b, c = sorted([a, b, c])
        
        if c >= a + b:
            # 最大值太多，只能消耗掉 a 和 b
            return a + b
        else:
            # 可以均衡消耗，答案为总和的一半
            return (a + b + c) // 2
```

### 方法二：贪心模拟（直观，适合理解）

```python
import heapq

class Solution:
    def maximumScore(self, a: int, b: int, c: int) -> int:
        # 最大堆（Python 用负数模拟）
        heap = [-a, -b, -c]
        heapq.heapify(heap)
        
        count = 0
        while True:
            # 取最大两个数
            x = -heapq.heappop(heap)
            y = -heapq.heappop(heap)
            
            if x == 0 or y == 0:
                break
            
            # 各减 1
            heapq.heappush(heap, -(x - 1))
            heapq.heappush(heap, -(y - 1))
            count += 1
        
        return count
```

## 复杂度分析

- **方法一**：O(1)，纯数学
- **方法二**：O((a+b+c) log 3)，堆操作

## 关键点总结

1. 贪心每次选最大两个，等价于尽可能均衡地消耗
2. 若最大值 >= 其他两者之和，答案受限于小两数之和
3. 否则总能消耗掉一半（向下取整）

## 易错点

- 三个数排序后，最大值是第三个
- 整数除法 `//` 向下取整
