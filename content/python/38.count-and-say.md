## 题目描述

「外观数列」是一个整数序列，从数字 1 开始，序列中的每一项都是对前一项的描述。

前五项如下：
```
1.     1
2.     11
3.     21
4.     1211
5.     111221
```

`1` 被读作 `"one 1"` (`"一个一"`) , 即 `11`。
`11` 被读作 `"two 1s"` (`"两个一"`）, 即 `21`。
`21` 被读作 `"one 2"`, `"one 1"` （`"一个二"`, `"一个一"`), 即 `1211`。

给定一个正整数 `n`，输出外观数列的第 `n` 项。

**示例 1：**
```
输入：n = 1
输出："1"
```

**示例 2：**
```
输入：n = 4
输出："1211"
```

**提示：**
- `1 <= n <= 30`

## 解题思路

核心思想：模拟生成过程

关键步骤：
1. 从 "1" 开始
2. 统计连续相同数字的个数
3. 生成 "个数 + 数字" 的描述
4. 重复 n-1 次

## Python 代码实现

```python
class Solution:
    def countAndSay(self, n: int) -> str:
        result = "1"
        
        for _ in range(n - 1):
            result = self.getNext(result)
        
        return result
    
    def getNext(self, s: str) -> str:
        result = []
        i = 0
        
        while i < len(s):
            count = 1
            digit = s[i]
            
            # 统计连续相同数字
            while i + count < len(s) and s[i + count] == digit:
                count += 1
            
            # 添加 "个数 + 数字"
            result.append(str(count) + digit)
            i += count
        
        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O(n × m)，m 为字符串长度
- 空间复杂度：O(m)

## 关键点总结

1. **统计连续**：使用双指针统计连续相同数字
2. **拼接字符串**：个数 + 数字
3. **迭代生成**：重复 n-1 次

## 易错点

1. **初始值**：从 "1" 开始
2. **边界**：统计时注意数组越界
