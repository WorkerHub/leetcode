## 题目描述

给你一棵二叉树的根节点 `root`，返回满足以下条件的节点数：该节点的值等于其**所有后代节点值之和**（空子树视为 0）。

**示例：**
```
输入：root = [10, 3, 4, 2, 1]
输出：2
解释：节点 3（值 3 = 2 + 1），节点 4（值 4，叶节点，后代和 = 0？）
等等... 节点 10 的后代和 = 3 + 4 + 2 + 1 = 10，满足
节点 3 的后代和 = 2 + 1 = 3，满足
```

**提示：**
- 节点数 `1 <= n <= 10^4`
- `-10^5 <= Node.val <= 10^5`

---

## 解题思路

### 核心思想：后序遍历 DFS

对每个节点，通过后序遍历获取其所有后代节点的值之和，然后判断是否等于该节点的值。

---

## 代码实现

### 方法一：后序遍历（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def equalToDescendants(self, root: Optional[TreeNode]) -> int:
        self.count = 0

        def dfs(node: Optional[TreeNode]) -> int:
            """返回以 node 为根的子树的所有节点值之和（包含 node 自身）"""
            if node is None:
                return 0

            # 递归获取左右子树的节点值总和
            left_sum = dfs(node.left)
            right_sum = dfs(node.right)

            # 后代节点值之和（不含 node 本身）
            desc_sum = left_sum + right_sum

            if node.val == desc_sum:
                self.count += 1

            # 返回包含 node 本身的子树总和
            return desc_sum + node.val

        dfs(root)
        return self.count
```

### 方法二：返回元组（避免实例变量）

```python
from typing import Optional, Tuple

class Solution:
    def equalToDescendants(self, root: Optional[TreeNode]) -> int:

        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            """返回 (满足条件的节点数, 子树总和（含自身）)"""
            if node is None:
                return 0, 0

            lcount, lsum = dfs(node.left)
            rcount, rsum = dfs(node.right)

            desc_sum = lsum + rsum
            cur_count = lcount + rcount + (1 if node.val == desc_sum else 0)

            return cur_count, desc_sum + node.val

        return dfs(root)[0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 后序遍历 | O(n) | O(h) |

h 为树的高度，最坏 O(n)。

---

## 关键点总结

1. 后序遍历：先处理子树，再处理根
2. 每个节点返回子树总和，用于父节点判断
3. 后代和 = 左子树总和 + 右子树总和（不含当前节点）

---

## 易错点

- 注意"后代节点"不包含节点本身
- 节点值可以为负数，需要正确计算总和
