## 题目描述

给定一个候选人编号的集合 `candidates` 和一个目标数 `target`，找出 `candidates` 中所有可以使数字和为 `target` 的组合。

`candidates` 中的每个数字在每个组合中只能使用一次。

**注意：** 解集不能包含重复的组合。

**示例 1：**
```
输入：candidates = [10,1,2,7,6,1,5], target = 8
输出：[[1,1,6],[1,2,5],[1,7],[2,6]]
```

**示例 2：**
```
输入：candidates = [2,5,2,1,2], target = 5
输出：[[1,2,2],[5]]
```

**提示：**
- `1 <= candidates.length <= 100`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`

## 解题思路

与题目 39 类似，但有两个关键区别：
1. 每个数字只能使用一次
2. 要去除重复组合

**解决方案：**
1. 先排序
2. 回溯时跳过重复元素
3. 每个元素最多使用一次

## Python 代码实现

```python
from typing import List

class Solution:
    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:
        result = []
        candidates.sort()  # 排序便于去重
        
        def backtrack(start: int, path: List[int], remain: int):
            if remain == 0:
                result.append(path[:])
                return
            if remain < 0:
                return
            
            for i in range(start, len(candidates)):
                # 跳过重复元素
                if i > start and candidates[i] == candidates[i-1]:
                    continue
                
                path.append(candidates[i])
                # 注意：下一层从 i+1 开始，不能重复使用
                backtrack(i + 1, path, remain - candidates[i])
                path.pop()
        
        backtrack(0, [], target)
        return result
```

## 复杂度分析

- 时间复杂度：O(2^n)
- 空间复杂度：O(n)

## 关键点总结

1. **排序**：便于去重
2. **去重条件**：`i > start and candidates[i] == candidates[i-1]`
3. **不重复使用**：下一层从 `i+1` 开始

## 易错点

1. **去重条件**：必须是 `i > start` 而非 `i > 0`
2. **排序**：去重的前提是数组有序
