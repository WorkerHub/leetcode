## 题目描述

给定一棵二叉树的根节点 `root` 和树中的一个节点 `u`，返回与 `u` **在同一层**中距离**最近**的**右侧**节点，如果 `u` 是其所在层中最右侧的节点，则返回 `null`。

**示例 1：**
```
输入：root = [1,2,3,null,4,5,6], u = 4
输出：5
```

**示例 2：**
```
输入：root = [3,null,4,2], u = 2
输出：null（2 是其层中最右侧节点）
```

**提示：**
- 树中节点数目在范围 `[1, 10^5]` 内
- `1 <= Node.val <= 10^5`
- 树中所有节点的值都是唯一的
- `u` 是给定的树中的一个节点

## 解题思路

使用**广度优先搜索（BFS）**进行层序遍历，找到 `u` 节点后，返回同层的下一个节点。

**核心思想：**
1. 使用队列进行层序遍历
2. 每层遍历时，找到目标节点 `u` 后，直接返回队列中的下一个节点
3. 如果 `u` 是该层最后一个节点，则返回 `None`

## 代码实现

### 方法一：BFS 层序遍历（推荐）

```python
from collections import deque
from typing import Optional

# 二叉树节点定义
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findNearestRightNode(self, root: TreeNode, u: TreeNode) -> Optional[TreeNode]:
        if not root:
            return None
        
        queue = deque([root])
        
        while queue:
            size = len(queue)  # 当前层的节点数
            for i in range(size):
                node = queue.popleft()
                
                # 找到目标节点
                if node == u:
                    # 如果是当前层最后一个节点，返回 None
                    # 否则返回下一个（已在队列头部）
                    return queue[0] if queue else None
                
                # 将子节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return None
```

### 方法二：DFS 记录层级

```python
from typing import Optional

class Solution:
    def findNearestRightNode(self, root: TreeNode, u: TreeNode) -> Optional[TreeNode]:
        target_depth = -1   # 目标节点所在深度
        self.result = None  # 结果节点
        found = [False]     # 是否已找到目标节点
        
        def dfs(node: TreeNode, depth: int):
            nonlocal target_depth
            if not node or self.result:
                return
            
            if found[0]:
                # 已找到目标，当前节点是同层的下一个（因为 DFS 顺序）
                if depth == target_depth:
                    self.result = node
                return
            
            if node == u:
                # 标记找到目标，记录深度
                found[0] = True
                target_depth = depth
                return
            
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        
        dfs(root, 0)
        return self.result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS  | O(n) | O(n)（队列最大为一层节点数） |
| DFS  | O(n) | O(h)（h 为树的高度） |

## 关键点总结

1. BFS 天然按层遍历，找到 `u` 后直接看队列头部即可
2. 同层最后一个节点找到时，队列头部已是下一层节点，此时应返回 `None`
3. DFS 方法需要记录目标深度，按先序遍历顺序，找到目标后下一个同层节点就是答案
4. 利用 `found` 标志位避免重复处理

## 易错点

- BFS 中，找到 `u` 后要先判断 `queue` 是否为空（`u` 是同层最右时为空）
- DFS 方法中，必须保证遍历顺序是从左到右，这样找到目标后的第一个同层节点才是"最近右侧"
- 当 `u` 就是根节点时，根节点是第 0 层唯一节点，应返回 `None`
