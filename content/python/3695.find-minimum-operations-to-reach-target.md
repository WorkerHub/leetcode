## 题目描述

给你一个目标整数 `target` 和整数 `maxValue`，从 0 开始，每次操作可以将当前值加 1，或将当前值乘以 2（若结果不超过 `maxValue`）。返回到达 `target` 的最少操作次数。

**示例 1：**

```
输入：target = 5, maxValue = 10
输出：4
解释：0→1(+1)→2(*2)→4(*2)→5(+1)，4次
```

**示例 2：**

```
输入：target = 3, maxValue = 4
输出：3
解释：0→1→2→3，3次（或0→1→2(*2)不对）
```

**提示：**

- `1 <= target <= 10^9`
- `1 <= maxValue <= 10^9`

## 解题思路

**逆向贪心**：从 `target` 反推到 0。

- 若当前值为偶数，且 `<=  maxValue`，优先"除以 2"（逆向乘 2 操作）
- 若为奇数，先"减 1"变偶数
- 当值 > maxValue 时，只能减 1

从 target 开始：
- 若 target > maxValue：直接加减次数 `target - maxValue`
- 若 target 为偶数：除以 2（一步），反向操作
- 若 target 为奇数：减 1（一步），变偶数

## Python 代码实现

### 方法一：逆向贪心（推荐）

```python
class Solution:
    def minOperations(self, target: int, maxValue: int) -> int:
        ops = 0

        # 先处理超过 maxValue 的部分
        if target > maxValue:
            ops += target - maxValue
            target = maxValue

        # 反向从 target 到 1
        while target > 1:
            if target % 2 == 1:
                target -= 1
                ops += 1
            else:
                target //= 2
                ops += 1

        # 从 0 到 1 需要 1 步
        ops += 1
        return ops
```

### 方法二：BFS

```python
from collections import deque

class Solution:
    def minOperations(self, target: int, maxValue: int) -> int:
        if target <= 0:
            return 0
        # 只有小 target 用 BFS
        if target <= 1000:
            dist = {0: 0}
            queue = deque([0])
            while queue:
                curr = queue.popleft()
                if curr == target:
                    return dist[curr]
                for nxt in [curr + 1, curr * 2]:
                    if nxt <= max(target, maxValue) and nxt not in dist:
                        dist[nxt] = dist[curr] + 1
                        queue.append(nxt)
        return self.minOperations(target, maxValue)  # fallback
```

## 复杂度分析

- 时间复杂度：O(log target)
- 空间复杂度：O(1)

## 关键点总结

1. 逆向思路：从 target 推到 0
2. 超过 maxValue 的部分只能逐步减 1
3. 在 maxValue 内，偶数尽量除 2

## 易错点

1. 从 0 到 1 需要 1 步（+1），不要忘记
2. target > maxValue 时先减到 maxValue
3. 乘 2 操作有上界 maxValue 约束
