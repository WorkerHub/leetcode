## 题目描述

在用笛卡尔坐标系表示的海平面上，有一些船。每艘船在整数坐标点上，且每个整数坐标点最多只有一艘船。

有一个函数 `Sea.hasShips(topRight, bottomLeft)` 可以判断在矩形（包含边界）内是否有船存在。其中：
- `topRight` = `[x2, y2]` 是矩形右上角坐标
- `bottomLeft` = `[x1, y1]` 是矩形左下角坐标

返回矩形 `topRight = [x2, y2]`，`bottomLeft = [x1, y1]` 区域内的船的数量。

**限制：**
- 最多调用 400 次 `hasShips` 函数
- `0 <= bottomLeft[0] <= topRight[0] <= 1000`
- `0 <= bottomLeft[1] <= topRight[1] <= 1000`
- 如果矩形内没有船，`hasShips` 返回 `false`

**示例 1：**
```
输入：ships = [[1,1],[2,2],[3,3],[5,5]], topRight = [4,4], bottomLeft = [0,0]
输出：3
解释：在矩形 (0,0) 到 (4,4) 内有 3 艘船，位于 (1,1)、(2,2)、(3,3)
```

**注意：** 这是一道交互题，`Sea.hasShips` 是系统给定的 API，不能直接访问船的位置。

## 解题思路

**为什么不能暴力？**

坐标范围是 0~1000，最多有 1001 * 1001 ≈ 100 万个格子，逐格查询远超 400 次限制。

**分治思想：**

把一个大矩形不断地对半切分，直到：
1. 矩形内没有船（`hasShips` 返回 false）-> 返回 0
2. 矩形缩小到一个点（x1==x2 且 y1==y2）-> `hasShips` 返回 true 时返回 1

**算法步骤：**

```
count(topRight, bottomLeft):
    1. 如果 hasShips(topRight, bottomLeft) == False，返回 0（剪枝）
    2. 如果是单个点（x1==x2 且 y1==y2），返回 1
    3. 找到矩形中点 (midX, midY)
    4. 将矩形分成 4 个子矩形，递归计算各自的船数并求和
```

**为什么查询次数不超过 400？**

每次分治最多有 4 个子问题，但关键在于：
- 空矩形立即返回 0（不再递归），这是最重要的剪枝
- 船的数量最多有限（题目保证），只有含船的矩形才会继续分裂
- 每艘船最多引发 O(log(1000)) ≈ 10 次分裂，整体查询次数有保证

**图解：**
```
整个矩形 (0,0)~(4,4)
    |
    |-- 左下 (0,0)~(2,2)  有船 -> 继续分
    |-- 右下 (3,0)~(4,2)  无船 -> 返回0
    |-- 左上 (0,3)~(2,4)  无船 -> 返回0
    |-- 右上 (3,3)~(4,4)  有船 -> 继续分
    ...
```

## Python 代码实现

### 方法一：分治递归（标准解法）

```python
# """
# This is Sea's API interface.
# You should not implement it, or speculate about its implementation
# """
# class Sea:
#    def hasShips(self, topRight: 'Point', bottomLeft: 'Point') -> bool:

# class Point:
# 	def __init__(self, x: int, y: int):
# 		self.x = x
# 		self.y = y

class Solution:
    def countShips(self, sea: 'Sea', topRight: 'Point', bottomLeft: 'Point') -> int:
        """
        分治法：将矩形不断二分，直到找到所有船
        """
        x1, y1 = bottomLeft.x, bottomLeft.y
        x2, y2 = topRight.x, topRight.y

        # 剪枝1：当前矩形内没有船，直接返回0（最关键的优化）
        if not sea.hasShips(topRight, bottomLeft):
            return 0

        # 基础情况：矩形缩小为单个点，且该点有船
        if x1 == x2 and y1 == y2:
            return 1

        # 计算矩形中点
        midX = (x1 + x2) // 2
        midY = (y1 + y2) // 2

        # 将矩形分成4个子矩形，分别统计船的数量
        # 注意：四个子矩形不重叠且完全覆盖原矩形

        # 左下角子矩形
        count = self.countShips(
            sea,
            Point(midX, midY),      # 右上角
            Point(x1, y1)           # 左下角
        )

        # 右下角子矩形（x从midX+1到x2，y从y1到midY）
        if midX < x2:  # 防止x方向已经是单列
            count += self.countShips(
                sea,
                Point(x2, midY),        # 右上角
                Point(midX + 1, y1)     # 左下角
            )

        # 左上角子矩形（x从x1到midX，y从midY+1到y2）
        if midY < y2:  # 防止y方向已经是单行
            count += self.countShips(
                sea,
                Point(midX, y2),        # 右上角
                Point(x1, midY + 1)     # 左下角
            )

        # 右上角子矩形（x从midX+1到x2，y从midY+1到y2）
        if midX < x2 and midY < y2:
            count += self.countShips(
                sea,
                Point(x2, y2),          # 右上角
                Point(midX + 1, midY + 1)  # 左下角
            )

        return count
```

### 方法二：分治递归（更简洁的写法）

```python
class Solution:
    def countShips(self, sea: 'Sea', topRight: 'Point', bottomLeft: 'Point') -> int:
        """
        简洁版本：直接用坐标参数，避免每次创建Point对象
        """
        def solve(x1, y1, x2, y2):
            # 坐标无效（防止越界）
            if x1 > x2 or y1 > y2:
                return 0

            # 剪枝：此区域无船
            if not sea.hasShips(Point(x2, y2), Point(x1, y1)):
                return 0

            # 单点且有船
            if x1 == x2 and y1 == y2:
                return 1

            # 二分切割
            midX = (x1 + x2) // 2
            midY = (y1 + y2) // 2

            # 四个子矩形：左下、右下、左上、右上
            return (solve(x1, y1, midX, midY) +
                    solve(midX + 1, y1, x2, midY) +
                    solve(x1, midY + 1, midX, y2) +
                    solve(midX + 1, midY + 1, x2, y2))

        return solve(bottomLeft.x, bottomLeft.y, topRight.x, topRight.y)
```

### 方法三：本地测试版本（含模拟 API）

```python
from typing import List

# 模拟 Sea API 和 Point 类，用于本地测试
class Point:
    def __init__(self, x: int, y: int):
        self.x = x
        self.y = y

class Sea:
    def __init__(self, ships: List[List[int]]):
        self.ships = set(map(tuple, ships))
        self.call_count = 0  # 统计API调用次数

    def hasShips(self, topRight: Point, bottomLeft: Point) -> bool:
        self.call_count += 1
        # 检查矩形内是否有船
        for x, y in self.ships:
            if bottomLeft.x <= x <= topRight.x and bottomLeft.y <= y <= topRight.y:
                return True
        return False

class Solution:
    def countShips(self, sea: 'Sea', topRight: 'Point', bottomLeft: 'Point') -> int:
        def solve(x1, y1, x2, y2):
            if x1 > x2 or y1 > y2:
                return 0
            if not sea.hasShips(Point(x2, y2), Point(x1, y1)):
                return 0
            if x1 == x2 and y1 == y2:
                return 1
            midX = (x1 + x2) // 2
            midY = (y1 + y2) // 2
            return (solve(x1, y1, midX, midY) +
                    solve(midX + 1, y1, x2, midY) +
                    solve(x1, midY + 1, midX, y2) +
                    solve(midX + 1, midY + 1, x2, y2))

        return solve(bottomLeft.x, bottomLeft.y, topRight.x, topRight.y)

# 测试
if __name__ == "__main__":
    ships = [[1, 1], [2, 2], [3, 3], [5, 5]]
    sea = Sea(ships)
    sol = Solution()
    result = sol.countShips(sea, Point(4, 4), Point(0, 0))
    print(f"矩形(0,0)~(4,4)内有 {result} 艘船")  # 3
    print(f"共调用API {sea.call_count} 次")
```

## 复杂度分析

- **时间复杂度：** O(S * log(max(X, Y)))，其中 S 是船的数量，X 和 Y 是坐标范围
  - 每艘船最多引发 O(log(1000)) ≈ 10 次递归分裂
  - 实际 API 调用次数远小于 400

- **空间复杂度：** O(log(max(X, Y)))
  - 递归深度为矩形边长的二分次数，约为 log(1000) ≈ 10 层

## 关键点总结

1. **分治剪枝**：`hasShips` 返回 false 时立即返回，避免无效搜索，是本题的核心优化
2. **终止条件**：矩形缩小为单点且有船时返回 1
3. **四分割**：将矩形沿 x 和 y 中点切成四份，注意边界不重叠
4. **坐标有效性**：midX < x2 等判断防止生成无效矩形
5. **查询次数**：每艘船最多触发 O(log n) 次 API 调用，总量可控

## 易错点

1. **矩形边界重叠**：四个子矩形必须不重叠且覆盖原矩形，右下/左上/右上要从 midX+1 或 midY+1 开始
2. **无效矩形**：当矩形退化（x1 > x2 或 y1 > y2）时直接返回 0，避免死循环
3. **API调用顺序**：要先调用 hasShips 剪枝，再判断是否是单点
4. **中点计算**：使用整数除法，确保每次分割都能缩小矩形
5. **Point 对象**：注意 Point 的 x 是横坐标（列），y 是纵坐标（行）
