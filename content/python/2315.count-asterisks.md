## 题目描述

给你一个字符串 `s`，`s` 中的每对竖线 `|` 将 `s` 分割成若干部分。两个 `|` 之间的内容被认为是一对（第奇数个 `|` 与第偶数个 `|` 配对）。

返回不在两个 `|` 之间的 `*` 的数目。

**示例 1：**
```
输入：s = "l|*e*et|co|*de|"
输出：2
解释：不在 | 对之间的 * 有索引 1 和 9 的两个 *。
```

**示例 2：**
```
输入：s = "iamprogrammer"
输出：0
```

**示例 3：**
```
输入：s = "yo|uar|e**|b|e|a|rt"
输出：2
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 由小写英文字母、`*` 和 `|` 组成
- `s` 中 `|` 的数目是**偶数**

## 解题思路

用一个标志变量 `in_pair` 表示当前是否在一对 `|` 内。遇到 `|` 则翻转标志；若当前不在对内且字符为 `*`，则计数加一。

## 代码实现

### 方法一：遍历计数（推荐）

```python
class Solution:
    def countAsterisks(self, s: str) -> int:
        count = 0
        in_pair = False  # 是否在一对 | 内
        
        for c in s:
            if c == '|':
                in_pair = not in_pair  # 切换状态
            elif c == '*' and not in_pair:
                count += 1
        
        return count
```

### 方法二：按 | 分割

```python
class Solution:
    def countAsterisks(self, s: str) -> int:
        # 按 | 分割字符串，偶数位置（0, 2, 4, ...）的段不在 | 对内
        parts = s.split('|')
        count = 0
        for i in range(0, len(parts), 2):  # 只取偶数索引的段
            count += parts[i].count('*')
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 遍历计数 | O(n) | O(1) |
| 分割 | O(n) | O(n) |

## 关键点总结

1. `|` 是成对出现的，用一个布尔值跟踪当前是否在一对 `|` 内。
2. 按 `|` 分割后，奇数索引的段在 `|` 对内，偶数索引段不在。

## 易错点

- 题目保证 `|` 的数目为偶数，不需要处理奇数个 `|` 的情况。
- 分割方法中，分割后有 `|` 数量 + 1 个段，偶数索引（0, 2, 4...）段不在 `|` 对内。
