## 题目描述

给你一个二维整数数组 `tasks`，其中 `tasks[i] = [start_i, end_i, duration_i]`，表示第 `i` 个任务必须在时间区间 `[start_i, end_i]` 内完成，且需要连续执行 `duration_i` 个时间单位。

每次只能执行一个任务，任务可以暂停和恢复。请返回完成所有任务的最短时间，如果无法完成所有任务则返回 `-1`。

**示例 1：**

```
输入：tasks = [[1,3,2],[2,5,3],[3,5,1]]
输出：5
解释：
时间1-2：执行任务0（需要2单位）
时间2-5：执行任务1（需要3单位）
时间3-3：执行任务2（需要1单位）
总时间5
```

**示例 2：**

```
输入：tasks = [[1,2,3]]
输出：-1
解释：任务需要3单位但只有2单位时间窗口
```

**提示：**

- `1 <= tasks.length <= 10^5`
- `1 <= start_i <= end_i <= 10^9`
- `1 <= duration_i <= end_i - start_i + 1`

## 解题思路

贪心 + 延迟调度（EDF，Earliest Deadline First）：

1. 优先执行截止时间最早的任务（EDF 调度）
2. 将任务按截止时间排序
3. 用贪心策略：在每个截止时刻，尽量先做截止时间早的任务

类似于操作系统调度问题，用优先队列维护当前可以执行的任务集合（按截止时间最小堆）。

具体步骤：
- 离散化时间点（按截止时间排序处理）
- 在每个时间窗口结束前，尽量完成该时间点截止的任务
- 若某截止时间前无法完成其所有任务，返回 -1

## Python 代码实现

### 方法一：EDF 贪心 + 差分数组（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, tasks: List[List[int]]) -> int:
        # 按截止时间排序
        tasks.sort(key=lambda t: t[1])

        # 用差分数组标记已规划的时间段
        # 贪心：在截止时间前，尽量靠后安排任务（节省前面时间给早截止任务）
        run = [0] * (tasks[-1][1] + 2)  # run[t]=1 表示时间 t 被使用

        for start, end, duration in tasks:
            # 检查 [start, end] 内已有多少时间被使用
            already = sum(run[start:end + 1])
            need = duration - already
            if need < 0:
                need = 0
            # 从 end 向前填满 need 个空闲时间槽
            t = end
            while need > 0:
                if run[t] == 0:
                    run[t] = 1
                    need -= 1
                t -= 1
                if t < start:
                    return -1  # 无法在窗口内完成

        return sum(run)
```

```python
        for start, end, duration in tasks:
            already = sum(1 for t in range(start, end + 1) if run[t])
            need = duration - already
            t = end
            while need > 0 and t >= start:
                if not run[t]:
                    run[t] = True
                    need -= 1
                t -= 1
            if need > 0:
                return -1

        return sum(run)
```

## 复杂度分析

- 时间复杂度：O(n * T)，T 为最大时间窗口（差分数组方案可用线段树优化到 O(n log T)）
- 空间复杂度：O(T)

## 关键点总结

1. EDF（最早截止时间优先）是此类调度问题的经典贪心策略
2. 靠后安排任务（从截止时间往前填），为早截止任务留出前面时间
3. 若某任务在窗口内无法获得足够时间槽，返回 -1
4. 差分数组/线段树可加速区间查询

## 易错点

1. 任务可中断（preemptive），与不可中断调度不同
2. 靠后填充而非靠前，这是贪心策略的关键
3. 时间范围可能很大，需考虑离散化
