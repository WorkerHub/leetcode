## 题目描述

给定整数数组 `nums`，找出数组中任意一个**偶数**元素与任意一个**奇数**元素之差的最大绝对值。即 `max(|nums[i] - nums[j]|)`，其中 `nums[i]` 为偶数，`nums[j]` 为奇数（或反之）。

**示例 1：**
```
输入：nums = [1,2,3,4,5,6]
输出：5
解释：偶数最大为 6，奇数最小为 1，差为 5。
```

**示例 2：**
```
输入：nums = [2,4,1,3]
输出：3
解释：|4-1| = 3。
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- 数组中同时存在偶数和奇数

## 解题思路

分别找出数组中偶数的最大值、最小值和奇数的最大值、最小值，然后：

最大差 = `max(max_even - min_odd, max_odd - min_even)`

## Python 代码实现

### 方法一：直接统计（推荐）

```python
from typing import List

class Solution:
    def maxDifference(self, nums: List[int]) -> int:
        evens = [x for x in nums if x % 2 == 0]
        odds = [x for x in nums if x % 2 != 0]

        # 最大差：偶数最大 - 奇数最小，或 奇数最大 - 偶数最小
        return max(max(evens) - min(odds), max(odds) - min(evens))
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def maxDifference(self, nums: List[int]) -> int:
        max_even = min_even = None
        max_odd = min_odd = None

        for x in nums:
            if x % 2 == 0:
                max_even = x if max_even is None else max(max_even, x)
                min_even = x if min_even is None else min(min_even, x)
            else:
                max_odd = x if max_odd is None else max(max_odd, x)
                min_odd = x if min_odd is None else min(min_odd, x)

        return max(max_even - min_odd, max_odd - min_even)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（方法一）或 O(1)（方法二）

## 关键点总结

1. 最大绝对差一定在"一种类型的最大值"与"另一种类型的最小值"之间取得
2. 两种方向都需要考虑（偶-奇 或 奇-偶）

## 易错点

1. 题目保证同时存在奇数和偶数，不需要处理空集
2. 是绝对差的最大值，两种方向都要考虑
