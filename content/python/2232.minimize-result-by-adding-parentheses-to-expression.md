## 题目描述

给你一个下标从 0 开始的字符串 `expression`，格式为 `"<num1>+<num2>"`，其中 `<num1>` 和 `<num2>` 表示正整数。

向 expression 中添加一对括号，使得添加后的表达式值**最小**。括号内的表达式先计算，但加法运算符左右两侧可能有数字（乘法与括号外的数字相乘）。

具体规则：在 `+` 号前（`num1` 中）选一个位置 `i`，在 `+` 号后（`num2` 中）选一个位置 `j`，将括号加在 `(num1[i:]+ num2[:j+1])` 外。

原表达式变为：`num1[:i] * (num1[i:] + num2[:j+1]) * num2[j+1:]`（其中若某部分为空则视为 1）。

**示例 1：**
```
输入：expression = "247+38"
输出："2(47+38)"
```

**示例 2：**
```
输入：expression = "12+34"
输出："1(2+3)4"
```

## 解题思路

暴力枚举括号的位置：
- 设 `+` 号位置为 `p`。
- 左括号可以在 `[0, p-1]` 的任意位置（`i` 从 0 到 p-1，枚举 `i` 个字符前）。
- 右括号可以在 `[p+1, n-1]` 的任意位置。
- 对每种组合计算 `left * (mid1 + mid2) * right`，找最小值。

## 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def minimizeResult(self, expression: str) -> str:
        plus_idx = expression.index('+')
        n = len(expression)
        left_part = expression[:plus_idx]   # '+' 左边
        right_part = expression[plus_idx + 1:]  # '+' 右边

        min_val = float('inf')
        best = ""

        # 枚举左括号位置（在 left_part 中截取后缀）
        for i in range(len(left_part)):
            # 枚举右括号位置（在 right_part 中截取前缀）
            for j in range(1, len(right_part) + 1):
                # 括号外左边（可能为空，则视为1）
                a = int(left_part[:i]) if i > 0 else 1
                # 括号内
                b = int(left_part[i:]) + int(right_part[:j])
                # 括号外右边（可能为空，则视为1）
                c = int(right_part[j:]) if j < len(right_part) else 1

                val = a * b * c
                if val < min_val:
                    min_val = val
                    # 构造结果字符串
                    best = left_part[:i] + '(' + left_part[i:] + '+' + right_part[:j] + ')' + right_part[j:]

        return best
```

### 方法二：同上，使用 split 分割

```python
class Solution:
    def minimizeResult(self, expression: str) -> str:
        nums = expression.split('+')
        s1, s2 = nums[0], nums[1]
        n1, n2 = len(s1), len(s2)

        best_val = float('inf')
        best = ""

        for i in range(n1):
            for j in range(1, n2 + 1):
                left = int(s1[:i]) if i > 0 else 1
                mid = int(s1[i:]) + int(s2[:j])
                right = int(s2[j:]) if j < n2 else 1

                val = left * mid * right
                if val < best_val:
                    best_val = val
                    best = s1[:i] + '(' + s1[i:] + '+' + s2[:j] + ')' + s2[j:]

        return best
```

## 复杂度分析

- 时间复杂度：O(n^2)，n 为数字的总位数，枚举所有括号位置。
- 空间复杂度：O(n)，存储结果字符串。

## 关键点总结

1. 暴力枚举括号位置，计算每种情况的值，取最小。
2. 括号外的空部分视为 1（不乘以 0，而是不参与乘法，即乘以 1）。
3. 数字最多 10 位，枚举次数不超过 100，完全可以暴力。

## 易错点

- 左侧或右侧为空时，对应因子为 1，不是 0。
- 括号内是加法 `num1[i:] + num2[:j]`，外面是乘法。
