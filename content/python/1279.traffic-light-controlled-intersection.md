## 题目描述

在一个十字路口，有两条道路：
- 道路1：连接北/南方向的车辆（`roadId = 1`）
- 道路2：连接东/西方向的车辆（`roadId = 2`）

同一时间只能允许**一个方向**的车辆通过路口。

请实现 `TrafficLight` 类：

- **`TrafficLight()`**：初始化交通灯，初始状态下，道路 1 的绿灯亮起
- **`void carArrived(carId, roadId, direction, turnGreen, crossCar)`**：
  - `carId`：到达的车辆 ID
  - `roadId`：车辆所在的道路（1 或 2）
  - `direction`：车辆行驶方向
  - `turnGreen`：一个函数，调用后将当前道路的信号灯变为绿色
  - `crossCar`：一个函数，调用后允许车辆通过

**规则：**
- 如果来车方向的信号灯已经是绿灯，直接调用 `crossCar`
- 如果来车方向的信号灯是红灯，先调用 `turnGreen`（切换信号灯），再调用 `crossCar`
- 同一时刻只能有一辆车通过，但同方向的车无需等待信号灯切换

**示例：**
```
输入：
carId = [1, 3, 5, 2, 4], roadId = [1, 2, 1, 2, 3],
directions = [2, 1, 3, 4, 2],
arrivalTimes = [10, 20, 30, 40, 50]

输出：
#car 1 passing（road 1 绿灯，直接通过）
turnGreen #car 3（road 2 来车，切换绿灯）
crossCar #car 3
#car 5 passing（road 1 来车，切换回绿灯）
turnGreen #car 5
crossCar #car 5
...
```

**提示：**
- `1 <= carId <= 10^6`
- `roadId` 为 1 或 2
- 多个线程并发调用 `carArrived`
- 本题保证调用顺序满足实际交通规则（无冲突输入）

## 解题思路

**并发控制的核心问题：**

多辆车（多个线程）同时到达路口，需要确保：
1. **互斥访问**：同一时刻只有一辆车在检查/切换信号灯（否则可能出现竞态条件）
2. **状态记录**：记住当前绿灯是哪条路

**解决方案：使用互斥锁（Lock）**

`threading.Lock` 是 Python 标准库中的互斥锁：
- `lock.acquire()`：获取锁（若已被占用则等待）
- `lock.release()`：释放锁
- 或使用 `with lock:` 语法自动管理

**算法流程：**
```
1. carArrived 被多线程并发调用
2. 用锁保证同一时刻只有一个线程执行核心逻辑
3. 判断来车道路是否与当前绿灯方向一致：
   - 一致：直接 crossCar()
   - 不一致：先 turnGreen()，更新绿灯方向，再 crossCar()
4. 释放锁，允许下一辆车通过
```

**为什么需要锁？**

想象两辆车同时到达（线程 A 和线程 B）：
- 线程 A 读到绿灯是道路 1，自己是道路 2，准备切换
- 线程 B 也读到绿灯是道路 1，自己是道路 2，也准备切换
- 两者都调用 turnGreen，切换了两次（变回道路1的绿灯）

加锁后，两个操作串行执行，避免这种问题。

## Python 代码实现

### 方法一：使用 threading.Lock（推荐）

```python
import threading

class TrafficLight:

    def __init__(self):
        # 当前绿灯所在的道路（初始为道路 1）
        self.green_road = 1
        # 互斥锁：保证同一时刻只有一辆车在操作信号灯
        self.lock = threading.Lock()

    def carArrived(
        self,
        carId: int,
        roadId: int,
        direction: int,
        turnGreen: 'Callable[[], None]',
        crossCar: 'Callable[[], None]'
    ) -> None:
        # 获取锁，保证互斥访问
        with self.lock:
            # 如果来车道路与当前绿灯方向不同，需要切换信号灯
            if roadId != self.green_road:
                turnGreen()                  # 切换绿灯到来车方向
                self.green_road = roadId     # 更新当前绿灯方向

            # 允许车辆通过（无论是否切换了绿灯）
            crossCar()
```

### 方法二：使用 threading.Semaphore

```python
import threading

class TrafficLight:

    def __init__(self):
        self.green_road = 1
        # 信号量初始值为1，效果与互斥锁相同
        self.semaphore = threading.Semaphore(1)

    def carArrived(
        self,
        carId: int,
        roadId: int,
        direction: int,
        turnGreen: 'Callable[[], None]',
        crossCar: 'Callable[[], None]'
    ) -> None:
        # 等待信号量（获取"通行权"）
        self.semaphore.acquire()

        try:
            # 判断是否需要切换信号灯
            if roadId != self.green_road:
                turnGreen()
                self.green_road = roadId
            crossCar()
        finally:
            # 确保无论如何都要释放信号量（避免死锁）
            self.semaphore.release()
```

### 方法三：手动 acquire/release（显式锁）

```python
import threading

class TrafficLight:

    def __init__(self):
        self.green_road = 1
        self.lock = threading.Lock()

    def carArrived(
        self,
        carId: int,
        roadId: int,
        direction: int,
        turnGreen: 'Callable[[], None]',
        crossCar: 'Callable[[], None]'
    ) -> None:
        # 手动获取锁
        self.lock.acquire()

        # 核心逻辑：检查并切换信号灯，然后放行
        if roadId != self.green_road:
            turnGreen()
            self.green_road = roadId
        crossCar()

        # 手动释放锁（注意：如果 crossCar 抛出异常，锁可能永远不会释放）
        # 推荐使用 with lock: 语句（方法一），自动处理异常情况
        self.lock.release()
```

### 方法四：本地测试版本

```python
import threading
import time
from typing import List

class TrafficLight:
    def __init__(self):
        self.green_road = 1
        self.lock = threading.Lock()

    def carArrived(self, carId, roadId, direction, turnGreen, crossCar):
        with self.lock:
            if roadId != self.green_road:
                turnGreen()
                self.green_road = roadId
            crossCar()

# 测试代码
def simulate():
    tl = TrafficLight()
    results = []

    def make_callbacks(car_id, road_id):
        def turn_green():
            results.append(f"turnGreen for car {car_id} (road {road_id})")
        def cross_car():
            results.append(f"crossCar for car {car_id} (road {road_id})")
        return turn_green, cross_car

    # 模拟多辆车并发到达
    cars = [
        (1, 1, 2, 10),   # (carId, roadId, direction, arrivalTime)
        (3, 2, 1, 20),
        (5, 1, 3, 30),
        (2, 2, 4, 40),
    ]

    threads = []
    for car_id, road_id, direction, arrival_time in cars:
        def run(cid=car_id, rid=road_id, d=direction):
            tg, cc = make_callbacks(cid, rid)
            tl.carArrived(cid, rid, d, tg, cc)

        t = threading.Thread(target=run)
        threads.append((arrival_time, t))

    # 按到达时间顺序启动线程
    for arrival_time, t in sorted(threads, key=lambda x: x[0]):
        t.start()
        time.sleep(0.001)  # 模拟不同到达时间

    for _, t in threads:
        t.join()

    for r in results:
        print(r)

if __name__ == "__main__":
    simulate()
```

## 复杂度分析

- **时间复杂度：** O(1) 每次调用（不考虑锁等待时间）
- **空间复杂度：** O(1)（只存储当前绿灯方向和一把锁）

## 关键点总结

1. **互斥锁的作用**：防止多个线程同时操作共享变量 `green_road`，避免竞态条件
2. **with lock 语法**：Python 推荐使用上下文管理器（with 语句）管理锁，避免忘记释放
3. **判断逻辑**：只有来车道路与当前绿灯不同时才调用 turnGreen，否则直接 crossCar
4. **状态更新**：切换绿灯后必须更新 `green_road`，否则下次判断还会切换
5. **锁的粒度**：整个判断+切换+通行的过程都要在锁内完成，不能只锁一部分

## 易错点

1. **忘记更新状态**：调用 `turnGreen()` 后必须更新 `self.green_road = roadId`
2. **锁泄漏**：手动 acquire/release 时，如果中间抛出异常，lock 永远不会释放，导致死锁。应使用 `with lock:` 或 `try/finally`
3. **不需要锁的误解**：即使逻辑简单，多线程环境下的读-修改-写操作都可能出现竞态条件，必须加锁
4. **死锁**：本题不会死锁（只有一把锁），但多把锁时要注意加锁顺序一致
5. **道路1是初始绿灯**：题目说初始状态道路1绿灯，所以 `self.green_road = 1` 是正确的初始值

## 并发基础知识

**Python 常用并发原语：**

| 类 | 用途 |
|----|------|
| `threading.Lock` | 互斥锁，同时只有一个线程持有 |
| `threading.Semaphore(n)` | 信号量，允许最多 n 个线程同时持有 |
| `threading.Event` | 事件，线程间的简单通知 |
| `threading.Condition` | 条件变量，配合复杂的等待/通知逻辑 |
| `threading.Barrier(n)` | 栅栏，等待 n 个线程都到达后再继续 |
