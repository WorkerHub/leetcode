## 题目描述

给你一个整数数组 `nums`。

你可以删除任意数量的元素（包括不删除），使得剩余数组（保持原顺序）中每个元素都是唯一的（即各不相同）。

返回满足条件的剩余数组中元素之和的最大值。

**示例 1：**

```
输入：nums = [1,2,3,4,5]
输出：15
解释：不删除任何元素，各元素唯一，和为 15
```

**示例 2：**

```
输入：nums = [1,1,2,2,3]
输出：6
解释：可选 [1,2,3]，和为 6
```

**示例 3：**

```
输入：nums = [-1,-1,-2,-2,-3]
输出：-1
解释：负数越少越好，只选 -1（最大的负数），和为 -1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

贪心：对于正数，尽量全选（每种只选一次，选最大值即唯一副本）；对于负数，最多选一个（最大的负数，若所有数都是负数）。

具体：
- 若存在正数：对每个正数值，选择一次（重复的丢弃），贡献为正值。答案 = 所有不同正数之和。
- 若所有数都是负数：选最大的那个（负数中最接近 0 的），只选一个。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        # 若存在正数，选所有不同正数
        pos = set(x for x in nums if x > 0)
        if pos:
            return sum(pos)

        # 全为负数或零，选最大值（只能选一个唯一元素）
        return max(nums)
```

### 方法二：哈希表计数

```python
from typing import List
from collections import Counter

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        positives = {v for v in cnt if v > 0}

        if positives:
            return sum(positives)

        # 全非正数
        return max(nums)
```

### 方法三：排序贪心

```python
from typing import List

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        unique_vals = set(nums)
        pos_vals = [v for v in unique_vals if v > 0]

        if pos_vals:
            return sum(pos_vals)

        # 没有正数，只能选一个最大值
        return max(nums)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 若有正数：所有不同正数都选，负数一个都不选（只会降低总和）
2. 全为负数/零：只能选最大值（选 1 个元素，必须是最大的）
3. 元素唯一意味着每种值最多出现一次

## 易错点

1. 全为负数时，不能不选（题目要求至少选一个吗？实际是可以选 0 个，但空数组和为 0，若有负数则负数 < 0，选 0 个更优）
2. 实际上若全为负数，选 0 个元素，和为 0，比选任何负数都大。需确认题意。
3. 若题目要求必须保留至少一个元素，则答案是 max(nums)
