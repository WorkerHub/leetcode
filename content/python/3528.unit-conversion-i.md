## 题目描述

给定若干单位换算关系，每个换算 `[unit1, unit2, factor]` 表示 `1 unit1 = factor unit2`。给定一组查询 `[from, to]`，求将 `1 unit_from` 换算为 `unit_to` 的数值。若无法换算，返回 `-1.0`。

**示例 1：**

```
输入：conversions = [["meter","centimeter",100],["centimeter","millimeter",10]]
       queries = [["meter","millimeter"]]
输出：[1000.0]
解释：1 meter = 100 cm = 1000 mm。
```

**示例 2：**

```
输入：conversions = [["kg","g",1000]], queries = [["g","kg"],["kg","g"]]
输出：[0.001, 1000.0]
```

**提示：**
- 换算关系构成树形结构（无环）
- `1 <= conversions.length <= 100`
- `1 <= queries.length <= 100`

## 解题思路

将换算关系构建为图（有向图，双向），然后对每个查询用 BFS/DFS 找从起点到终点的路径，沿路乘以换算因子。

由于图可能是有向的，逆方向的换算因子为 `1/factor`。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def unitConversion(self, conversions: List[List], queries: List[List]) -> List[float]:
        # 构建图：双向边
        graph = defaultdict(list)
        for unit1, unit2, factor in conversions:
            graph[unit1].append((unit2, factor))
            graph[unit2].append((unit1, 1.0 / factor))

        def bfs(start, end):
            if start == end:
                return 1.0
            queue = deque([(start, 1.0)])
            visited = {start}
            while queue:
                node, val = queue.popleft()
                for neighbor, factor in graph[node]:
                    if neighbor == end:
                        return val * factor
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append((neighbor, val * factor))
            return -1.0

        return [bfs(f, t) for f, t in queries]
```

### 方法二：DFS

```python
from typing import List
from collections import defaultdict

class Solution:
    def unitConversion(self, conversions: List[List], queries: List[List]) -> List[float]:
        graph = defaultdict(list)
        for unit1, unit2, factor in conversions:
            graph[unit1].append((unit2, float(factor)))
            graph[unit2].append((unit1, 1.0 / factor))

        def dfs(curr, target, visited, acc):
            if curr == target:
                return acc
            for neighbor, factor in graph[curr]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    result = dfs(neighbor, target, visited, acc * factor)
                    if result != -1.0:
                        return result
                    visited.discard(neighbor)
            return -1.0

        results = []
        for f, t in queries:
            if f not in graph and f != t:
                results.append(-1.0)
            else:
                results.append(dfs(f, t, {f}, 1.0))
        return results
```

## 复杂度分析

- 时间复杂度：O(q * (V + E))，q 为查询数，V 为节点数，E 为边数
- 空间复杂度：O(V + E)，图的存储

## 关键点总结

1. 双向建图：正向因子 `f`，逆向因子 `1/f`
2. BFS/DFS 在图上寻路，沿路累乘换算因子
3. 不可达时返回 `-1.0`

## 易错点

1. 逆方向换算因子是 `1/factor` 而不是 `-factor`
2. 起点和终点相同时返回 `1.0`
3. 需要标记已访问节点，避免死循环
