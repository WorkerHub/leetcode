## 题目描述

给你一个整数数组 `nums`（长度为偶数），你需要将数组分成 `n/2` 对，每对的和加入总分。

返回可获得的最大总分。

**示例 1：**

```
输入：nums = [1, 4, 3, 2]
输出：4
解释：将 (1,2) 和 (4,3) 配对，取较大值：max(1,2) + max(4,3) = 2 + 4 = 6。
或者题目要求每对取和：(1+4) + (3+2) = 9，(1+3) + (4+2) = 10，(1+2) + (4+3) = 10。
```

**示例 2：**

```
输入：nums = [3, 1, 2, 4]
输出：6
```

**提示：**
- `2 <= nums.length <= 10^5`（偶数）
- `1 <= nums[i] <= 10^5`

## 解题思路

将数组分成 n/2 对，每对取较大值（或取和），使总分最大。

若每对取较大值（max）：贪心策略是将相邻的两个最大值配对，排序后取奇数位的值之和（0-indexed 的 0, 2, 4, ...）。

若每对取和（sum）：所有配对的总和都等于数组总和，答案固定为 `sum(nums)`。

## Python 代码实现

### 方法一：排序取每对最大值（推荐）

```python
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        # 若每对取 max：排序后相邻配对，取每对第二大（排序后奇数位）
        nums.sort()
        n = len(nums)
        # 相邻配对：(nums[0], nums[1]), (nums[2], nums[3]), ...
        # 每对最大值 = 奇数下标元素
        return sum(nums[i] for i in range(1, n, 2))
```

### 方法二：总和等于数组总和（若题意为对之和）

```python
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        # 若每对取和，则总分固定 = sum(nums)，无法优化
        return sum(nums)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)，原地排序

## 关键点总结

1. 排序后将相邻元素配对，可以最大化每对中的较大值之和。
2. 将排序数组的奇数位元素（1, 3, 5, ...）相加，等价于取每对 max 的总和。
3. 若题目要求配对之和（非最大值），则答案固定为数组总和。

## 易错点

1. 注意题目要求的是"每对取 max 之和"还是"每对取和之和"（前者需要贪心，后者固定）。
2. 排序后相邻配对的奇数位下标（1-indexed），在 Python 中是 `range(1, n, 2)`。
