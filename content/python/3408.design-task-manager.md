## 题目描述

设计一个任务管理器，支持以下操作：

- `TaskManager(tasks)`: 初始化，`tasks` 为 `[userId, taskId, priority]` 列表
- `add(userId, taskId, priority)`: 添加任务
- `edit(taskId, newPriority)`: 修改任务优先级
- `remove(taskId)`: 删除任务
- `execTop()`: 执行优先级最高的任务，返回对应的 userId；若无任务返回 -1。优先级相同时，taskId 更大的优先执行

**示例：**

```
输入：
["TaskManager","add","edit","execTop","remove","execTop","execTop"]
[[[1,101,10],[2,102,20],[3,103,15]],[4,104,5],[102,8],[],[101],[],[]]
输出：
[null,null,null,3,null,2,1]
```

**提示：**
- `1 <= tasks.length <= 10^5`
- `1 <= userId, taskId, priority <= 10^5`
- 每个 taskId 唯一
- 每种操作最多 2 * 10^5 次

## 解题思路

需要高效支持：
1. 按 (priority, taskId) 排序，取最大值
2. 按 taskId 查找和修改优先级

使用两个数据结构：
- 哈希表 `task_info`：taskId -> (userId, priority)，支持 O(1) 查找
- 有序集合（`SortedList`）：存储 (priority, taskId) 对，支持 O(log n) 插入删除，O(1) 取最大值

编辑和删除时，在有序集合中删除旧记录，插入新记录。

## Python 代码实现

### 方法一：SortedList（推荐）

```python
from sortedcontainers import SortedList
from typing import List

class TaskManager:

    def __init__(self, tasks: List[List[int]]):
        # 任务信息：taskId -> [userId, priority]
        self.task_info = {}
        # 有序集合：存储 (priority, taskId)，支持高效最大值查询
        self.sorted_tasks = SortedList()

        for userId, taskId, priority in tasks:
            self.task_info[taskId] = [userId, priority]
            self.sorted_tasks.add((priority, taskId))

    def add(self, userId: int, taskId: int, priority: int) -> None:
        self.task_info[taskId] = [userId, priority]
        self.sorted_tasks.add((priority, taskId))

    def edit(self, taskId: int, newPriority: int) -> None:
        userId, oldPriority = self.task_info[taskId]
        # 删除旧记录
        self.sorted_tasks.remove((oldPriority, taskId))
        # 插入新记录
        self.sorted_tasks.add((newPriority, taskId))
        # 更新哈希表
        self.task_info[taskId][1] = newPriority

    def remove(self, taskId: int) -> None:
        userId, priority = self.task_info.pop(taskId)
        self.sorted_tasks.remove((priority, taskId))

    def execTop(self) -> int:
        if not self.sorted_tasks:
            return -1
        # SortedList 升序排列，取最后一个（最大值）
        priority, taskId = self.sorted_tasks[-1]
        self.sorted_tasks.pop()
        userId, _ = self.task_info.pop(taskId)
        return userId
```

### 方法二：使用堆 + 懒删除

```python
import heapq
from typing import List

class TaskManager:

    def __init__(self, tasks: List[List[int]]):
        self.task_info = {}  # taskId -> (userId, priority)
        # 最大堆（用负数模拟）：(-priority, -taskId)
        self.heap = []
        # 已删除的任务集合（懒删除标记）
        self.removed = set()

        for userId, taskId, priority in tasks:
            self.task_info[taskId] = (userId, priority)
            heapq.heappush(self.heap, (-priority, -taskId))

    def add(self, userId: int, taskId: int, priority: int) -> None:
        self.task_info[taskId] = (userId, priority)
        heapq.heappush(self.heap, (-priority, -taskId))

    def edit(self, taskId: int, newPriority: int) -> None:
        userId, oldPriority = self.task_info[taskId]
        # 标记旧记录为删除
        self.removed.add((oldPriority, taskId))
        # 插入新记录
        self.task_info[taskId] = (userId, newPriority)
        heapq.heappush(self.heap, (-newPriority, -taskId))

    def remove(self, taskId: int) -> None:
        userId, priority = self.task_info.pop(taskId)
        self.removed.add((priority, taskId))

    def execTop(self) -> int:
        # 弹出堆顶，跳过已删除的任务
        while self.heap:
            neg_p, neg_tid = self.heap[0]
            priority, taskId = -neg_p, -neg_tid
            if (priority, taskId) in self.removed:
                heapq.heappop(self.heap)
                self.removed.discard((priority, taskId))
                continue
            heapq.heappop(self.heap)
            if taskId in self.task_info:
                return self.task_info.pop(taskId)[0]
        return -1
```

## 复杂度分析

- 方法一（SortedList）：
  - add/edit/remove：O(log n)
  - execTop：O(log n)
  - 空间复杂度：O(n)

- 方法二（堆 + 懒删除）：
  - add：O(log n)
  - edit/remove：O(log n) 均摊
  - execTop：O(log n) 均摊
  - 空间复杂度：O(n)

## 关键点总结

1. 需要同时支持按优先级排序和按 taskId 快速查找，因此结合哈希表和有序结构
2. 优先级相同时 taskId 更大的优先，(priority, taskId) 的字典序就是比较准则
3. 懒删除是堆中删除任意元素的常用技巧

## 易错点

1. `edit` 操作要先从有序结构删除旧记录，再插入新记录
2. 优先级相同时，taskId 大的优先——SortedList 天然支持，堆中需要用 `-taskId`
3. `execTop` 后要同时从哈希表和有序结构删除该任务
