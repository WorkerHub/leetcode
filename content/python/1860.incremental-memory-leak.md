## 题目描述

给你两个整数 `memory1` 和 `memory2`，分别表示两个内存条中可用的内存量（以位为单位）。

每一秒 `i`（从 1 开始），系统将把 `i` 位内存从可用内存多的内存条中分配出去（若相等则从第一个内存条分配）。如果两个内存条可用内存都小于 `i`，则系统在该秒崩溃。

返回 `[crashTime, memory1crash, memory2crash]`，其中 `crashTime` 是崩溃时的秒数，`memory1crash` 和 `memory2crash` 是崩溃时各内存条的可用内存量。

**示例 1：**
```
输入：memory1 = 2, memory2 = 2
输出：[3,1,0]
```

**示例 2：**
```
输入：memory1 = 8, memory2 = 11
输出：[6,0,4]
```

## 解题思路

**直接模拟**：按照题目规则逐秒模拟，直到两个内存条都不够分配为止。

由于分配量 i 从 1 开始递增，总分配量约为 `1+2+...+k ≈ k^2/2`，而 memory1 + memory2 有限，所以崩溃时间 k 约为 `sqrt(2*(m1+m2))`，最大约为 `sqrt(2*2*10^9) ≈ 63246`，模拟次数可接受。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def memLeak(self, memory1: int, memory2: int) -> List[int]:
        i = 1
        while True:
            # 检查是否崩溃
            if memory1 < i and memory2 < i:
                return [i, memory1, memory2]

            # 从可用内存多的（相等则选第一个）分配
            if memory1 >= memory2:
                memory1 -= i
            else:
                memory2 -= i

            i += 1
```

### 方法二：数学估算 + 从估算点开始（优化）

```python
from typing import List
import math

class Solution:
    def memLeak(self, memory1: int, memory2: int) -> List[int]:
        # 从 i=1 开始模拟（直接模拟即可，约 6万次）
        i = 1
        while memory1 >= i or memory2 >= i:
            if memory1 >= memory2:
                memory1 -= i
            else:
                memory2 -= i
            i += 1
        return [i, memory1, memory2]
```

## 复杂度分析

- **时间复杂度**：O(sqrt(m1 + m2))，模拟步数约为总内存量的平方根
- **空间复杂度**：O(1)

## 关键点总结

1. 相等时优先分配给内存条 1
2. 模拟步数上界约为 `sqrt(2 * max_memory)` ≈ 63246，无需优化
3. 循环退出条件：两个内存条都不够分配 `i` 位

## 易错点

- 退出条件是两个都不够（`and`），不是其中一个不够
- 分配时先判断谁多，相等选第一个
