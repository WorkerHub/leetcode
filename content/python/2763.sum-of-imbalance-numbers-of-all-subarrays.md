## 题目描述

一个数组的 **不平衡数字** 定义为：将数组排序后，相邻元素差 > 1 的相邻对数目。

给你一个下标从 **0** 开始的整数数组 `nums`，返回所有子数组不平衡数字的总和。

**示例 1：**
```
输入：nums = [2,3,1,4]
输出：3
解释：[2,3]:0, [2,3,1]:0, [2,3,1,4]:1, [3,1]:1, [3,1,4]:1, ...
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= nums.length`

## 解题思路

**枚举贡献**：对每个元素 `nums[i]`，计算它在多少个子数组中"贡献"了一次不平衡。

对于固定左端 `l`，遍历右端 `r`，动态维护有序集合，每次插入 `nums[r]`：
- 若 `nums[r]` 的前驱存在且差 > 1：不平衡数 + 1
- 若 `nums[r]` 的后继存在且差 > 1：不平衡数 + 1
- 若 `nums[r]` 的前驱和后继都存在：不平衡数 - 1（填补了间隙）

用 Python `SortedList` 或直接枚举。

## Python 代码实现

### 方法一：暴力枚举（O(n^3) 适用于 n<=1000）

```python
from typing import List

class Solution:
    def sumImbalanceNumbers(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0

        for l in range(n):
            seen = set()
            for r in range(l, n):
                seen.add(nums[r])
                # 计算当前子数组的不平衡数
                sorted_arr = sorted(seen)
                imbalance = sum(1 for i in range(len(sorted_arr) - 1)
                                if sorted_arr[i + 1] - sorted_arr[i] > 1)
                total += imbalance

        return total
```

### 方法二：增量维护（O(n^2)）

```python
from typing import List

class Solution:
    def sumImbalanceNumbers(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0

        for l in range(n):
            # 用有序集合动态维护
            import sortedcontainers
            sl = sortedcontainers.SortedList()
            imbalance = 0

            for r in range(l, n):
                x = nums[r]
                sl.add(x)
                idx = sl.index(x)
                # 检查左邻
                if idx > 0 and x - sl[idx - 1] > 1:
                    imbalance += 1
                # 检查右邻
                if idx < len(sl) - 1 and sl[idx + 1] - x > 1:
                    imbalance += 1
                # 若左右都有，且之前左右差 > 1，现在被填补
                if idx > 0 and idx < len(sl) - 1:
                    if sl[idx + 1] - sl[idx - 1] > 1:
                        # 原来 sl[idx-1] 和 sl[idx+1] 之间有间隙，现在填补了
                        # 但我们已经加了左邻和右邻的贡献，若原本间隙存在需减 1
                        if sl[idx + 1] - sl[idx - 1] > 2:
                            imbalance -= 1
                total += imbalance

        return total
```

## 复杂度分析

- 方法一：时间复杂度 O(n^3 log n)
- 方法二：时间复杂度 O(n^2 log n)
- 空间复杂度：O(n)

## 关键点总结

1. 对每个左端固定，动态维护有序集合
2. 每次插入元素时增量更新不平衡数
3. 插入元素可能填补间隙（减少不平衡），也可能产生新间隙（增加不平衡）

## 易错点

1. 动态维护时，插入元素同时检查左右两侧的影响
2. 填补间隙时需要确认原来存在间隙（差 > 1）
