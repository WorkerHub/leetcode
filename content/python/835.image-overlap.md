## 题目描述

给你两个图像 `img1` 和 `img2`，两个图像的大小都是 `n x n`，用大小相同的二维正方形矩阵表示。（并且为二进制矩阵，只包含若干 `0` 和若干 `1`）。

我们可以平移其中一个图像，将它们放置在另一个图像的上方。之后，该平移的 **重叠** 是指两个图像 **都具有 `1`** 的位置的数目。

返回最大的重叠数量。

## Python 代码实现

```python
from typing import List
from collections import Counter

class Solution:
    def largestOverlap(self, img1: List[List[int]], img2: List[List[int]]) -> int:
        n = len(img1)
        
        # 记录所有1的位置
        ones1 = [(i, j) for i in range(n) for j in range(n) if img1[i][j]]
        ones2 = [(i, j) for i in range(n) for j in range(n) if img2[i][j]]
        
        # 计算所有可能的平移向量
        counter = Counter()
        for i1, j1 in ones1:
            for i2, j2 in ones2:
                counter[(i1 - i2, j2 - j1)] += 1
        
        return max(counter.values()) if counter else 0
```

## 复杂度分析

- **时间复杂度**：O(n⁴)
- **空间复杂度**：O(n²)

## 关键点总结

1. **平移向量**：记录所有1之间的相对位置
2. **Counter统计**：相同平移向量出现次数即重叠数
3. **优化思路**：只考虑1的位置

## 学习建议

1. **向量思维**：用向量表示平移
2. **Counter应用**：统计频率
