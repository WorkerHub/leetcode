## 题目描述

给你一个二进制数组 `nums`（只含 0 和 1），每次操作可以翻转任意两个相邻元素。返回使数组中 0 的数量等于 1 的数量（即 n/2 个 0 和 n/2 个 1，n 为偶数）所需的最少操作次数。若 n 为奇数或无法实现，返回 -1。

**示例 1：**

```
输入：nums = [0,0,1,1]
输出：0
解释：已经平衡
```

**示例 2：**

```
输入：nums = [0,1,0,1,1,0]
输出：1
```

**提示：**

- `2 <= nums.length <= 10^5`
- `nums[i]` 为 0 或 1

## 解题思路

贪心：统计 0 的数量和 1 的数量。若两者不等（或 n 为奇数），无法平衡。

但翻转相邻元素时，0 和 1 可以"移动位置"。操作次数 = 将多余的 1 移到需要 1 的位置的最小代价（冒泡排序思想）。

等价于：将 0 移到前半部分（或使 0 和 1 各占一半），最小移动次数。

实际解法：统计每个 1 需要移动的距离之和。

## Python 代码实现

### 方法一：贪心配对（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        if n % 2 == 1:
            return -1

        count_0 = nums.count(0)
        count_1 = n - count_0

        if count_0 != count_1:
            return -1

        # 将多余的 1 移到对应位置
        # 目标：交替排列或前半0后半1？任意平衡排列
        # 贪心：将所有 1 移到下标为奇数位（或偶数位）
        # 最优目标下标序列
        target_ones = list(range(1, n, 2))  # 下标 1,3,5,...
        one_positions = [i for i, x in enumerate(nums) if x == 1]

        ops1 = sum(abs(one_positions[i] - target_ones[i]) for i in range(n // 2))

        target_ones2 = list(range(0, n, 2))  # 下标 0,2,4,...
        ops2 = sum(abs(one_positions[i] - target_ones2[i]) for i in range(n // 2))

        # 每次操作移动一步，总操作数为总移动距离
        return min(ops1, ops2)
```

### 方法二：模拟移动

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        if n % 2 != 0 or nums.count(1) != n // 2:
            return -1

        # 找 1 的位置，目标位置（偶数或奇数下标）
        ones = [i for i, x in enumerate(nums) if x == 1]
        half = n // 2

        # 目标：1 在偶数位
        ops_even = sum(abs(ones[i] - 2 * i) for i in range(half))
        # 目标：1 在奇数位
        ops_odd = sum(abs(ones[i] - (2 * i + 1)) for i in range(half))

        return min(ops_even, ops_odd)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 翻转相邻元素 = 交换两元素，等价于冒泡排序的一步
2. 最小操作数 = 将 1 移到目标位置的最小曼哈顿距离和
3. 有两种目标：1 在偶数位或奇数位

## 易错点

1. n 为奇数或 0/1 数量不等时返回 -1
2. 两种目标位置取最小
3. 配对时保持顺序（第 i 个 1 对应第 i 个目标位）
