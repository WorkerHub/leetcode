## 题目描述

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

**示例 1：**

```
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
```

**示例 2：**

```
输入：temperatures = [30,40,50,60]
输出：[1,1,1,0]
```

**示例 3：**

```
输入：temperatures = [30,60,90]
输出：[1,1,0]
```

**提示：**
- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

## 解题思路

这是一道经典的 **单调栈** 问题。

**核心思想：**
- 使用栈维护递减的温度索引
- 遇到更高温度时，弹出栈中较低温度的索引
- 计算天数差值

**算法流程：**
1. 遍历温度数组
2. 如果当前温度 > 栈顶索引对应的温度，弹出并计算天数差
3. 将当前索引入栈

**为什么用单调栈？**
- 需要找"下一个更大元素"
- 单调栈能在 O(1) 时间内找到
- 总时间复杂度 O(n)

## Python 代码实现

### 方法一：单调栈（推荐）⭐

```python
from typing import List

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        """
        单调递减栈
        栈中存储索引，对应的温度递减
        """
        n = len(temperatures)
        answer = [0] * n
        stack = []  # 存储索引
        
        for i, temp in enumerate(temperatures):
            # 当前温度更高，弹出栈中较低温度
            while stack and temperatures[stack[-1]] < temp:
                prev_index = stack.pop()
                answer[prev_index] = i - prev_index
            
            # 将当前索引入栈
            stack.append(i)
        
        # 栈中剩余的索引，说明后面没有更高温度，已经初始化为 0
        return answer
```

### 方法二：详细注释版

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        answer = [0] * n  # 默认为 0（后面没有更高温度）
        stack = []        # 单调递减栈（存储索引）
        
        for i in range(n):
            current_temp = temperatures[i]
            
            # 如果当前温度高于栈顶索引对应的温度
            # 说明找到了栈顶索引的"下一个更高温度"
            while stack and temperatures[stack[-1]] < current_temp:
                prev_index = stack.pop()
                # 计算天数差
                answer[prev_index] = i - prev_index
            
            # 将当前索引入栈
            # 维护栈的单调递减性质
            stack.append(i)
        
        return answer
```

### 方法三：从后往前遍历

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        """
        从后往前遍历，栈中维护递减温度的索引
        """
        n = len(temperatures)
        answer = [0] * n
        stack = []
        
        for i in range(n - 1, -1, -1):
            # 弹出所有不大于当前温度的索引
            while stack and temperatures[stack[-1]] <= temperatures[i]:
                stack.pop()
            
            # 如果栈不为空，栈顶就是下一个更高温度
            if stack:
                answer[i] = stack[-1] - i
            
            stack.append(i)
        
        return answer
```

### 方法四：暴力解法（用于对比）

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        """
        暴力解法：对每个位置向后查找
        时间复杂度 O(n²)，会超时
        """
        n = len(temperatures)
        answer = [0] * n
        
        for i in range(n):
            for j in range(i + 1, n):
                if temperatures[j] > temperatures[i]:
                    answer[i] = j - i
                    break
        
        return answer
```

## 复杂度分析

### 单调栈：
- **时间复杂度：** O(n)，每个元素最多入栈出栈一次
- **空间复杂度：** O(n)，栈的空间

### 暴力解法：
- **时间复杂度：** O(n²)
- **空间复杂度：** O(1)

## 关键点总结

1. **单调栈模板**：维护递减（或递增）序列的栈
2. **找下一个更大元素**：单调栈的经典应用
3. **栈存索引**：而不是温度值，方便计算天数差
4. **初始化为 0**：简化处理，栈中剩余元素无需再处理
5. **时间复杂度**：虽然有嵌套循环，但每个元素最多进出栈一次，所以是 O(n)

## 易错点

1. **栈存储内容**：应该存索引，不是温度值
2. **弹出条件**：是 `<` 不是 `<=`（题目要求"更高"）
3. **天数计算**：是 `i - prev_index`，不要写反
4. **初始化值**：answer 初始化为 0，处理没有更高温度的情况
5. **单调性**：是递减栈还是递增栈要根据题意确定
