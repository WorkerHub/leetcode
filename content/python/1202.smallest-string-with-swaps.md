## 题目描述

[LeetCode 1202. Smallest String With Swaps](https://leetcode.com/problems/smallest-string-with-swaps/)

给你一个字符串 `s`，以及该字符串中的一些「索引对」数组 `pairs`，其中 `pairs[i] = [a, b]` 表示字符串中的两个索引（编号从 0 开始）。

你可以任意多次交换在 `pairs` 中任意一对索引处的字符。

返回在经过若干次交换后，`s` 可以变成的按字典序最小的字符串。

**示例 1:**
```
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
解释：
交换 s[0] 和 s[3], s = "bcad"
交换 s[1] 和 s[2], s = "bacd"
```

**示例 2:**
```
输入：s = "dcab", pairs = [[0,3],[1,2],[0,2]]
输出："abcd"
解释：
交换 s[0] 和 s[3], s = "bcad"
交换 s[0] 和 s[2], s = "acbd"
交换 s[1] 和 s[2], s = "abcd"
```

**示例 3:**
```
输入：s = "cba", pairs = [[0,1],[1,2]]
输出："abc"
解释：
交换 s[0] 和 s[1], s = "bca"
交换 s[1] 和 s[2], s = "bac"
交换 s[0] 和 s[1], s = "abc"
```

**提示:**
- 1 <= s.length <= 10^5
- 0 <= pairs.length <= 10^5
- 0 <= pairs[i][0], pairs[i][1] < s.length
- s 中只含有小写英文字母

## 解题思路

这道题的关键在于理解**可传递的交换关系**。

### 核心观察

1. **传递性**：如果位置 a 和 b 可以交换，b 和 c 可以交换，那么 a、b、c 三个位置的字符可以任意排列
2. **连通分量**：可以交换的位置形成一个连通分量，连通分量内的字符可以任意重排
3. **最优策略**：对每个连通分量内的字符按字典序排序，然后放回对应位置

### 算法思路

使用并查集（Union-Find）找出所有连通分量：
1. 将所有可交换的索引对进行合并
2. 将属于同一连通分量的索引和字符分组
3. 对每组字符按字典序排序
4. 将排序后的字符按索引顺序放回原位置

### 为什么用并查集

并查集非常适合处理"等价关系"和"分组"问题：
- 可以高效地判断两个元素是否在同一组
- 可以快速合并两个组
- 时间复杂度接近 O(1)

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        
        # 并查集初始化
        parent = list(range(n))
        
        def find(x: int) -> int:
            # 路径压缩：将路径上所有节点直接连到根节点
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> None:
            # 合并两个集合
            root_x, root_y = find(x), find(y)
            if root_x != root_y:
                parent[root_x] = root_y
        
        # 构建并查集：合并所有可交换的索引对
        for a, b in pairs:
            union(a, b)
        
        # 将同一连通分量的索引和字符分组
        groups = defaultdict(list)
        for i in range(n):
            root = find(i)
            groups[root].append(i)
        
        # 构建结果
        result = list(s)
        for indices in groups.values():
            # 提取该连通分量的所有字符
            chars = [s[i] for i in indices]
            # 按字典序排序
            chars.sort()
            # 索引也需要排序，确保按位置顺序放置字符
            indices.sort()
            # 将排序后的字符放回对应位置
            for i, char in zip(indices, chars):
                result[i] = char
        
        return ''.join(result)
```

### 方法二：并查集 + 按秩合并优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        
        # 并查集初始化
        parent = list(range(n))
        rank = [0] * n  # 记录树的高度
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> None:
            root_x, root_y = find(x), find(y)
            if root_x != root_y:
                # 按秩合并：将较矮的树连接到较高的树
                if rank[root_x] < rank[root_y]:
                    parent[root_x] = root_y
                elif rank[root_x] > rank[root_y]:
                    parent[root_y] = root_x
                else:
                    parent[root_y] = root_x
                    rank[root_x] += 1
        
        # 构建并查集
        for a, b in pairs:
            union(a, b)
        
        # 分组
        groups = defaultdict(list)
        for i in range(n):
            groups[find(i)].append(i)
        
        # 构建结果
        result = list(s)
        for indices in groups.values():
            chars = sorted([s[i] for i in indices])
            indices.sort()
            for i, char in zip(indices, chars):
                result[i] = char
        
        return ''.join(result)
```

### 方法三：DFS 找连通分量

```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        
        # 构建邻接表
        graph = defaultdict(list)
        for a, b in pairs:
            graph[a].append(b)
            graph[b].append(a)
        
        visited = [False] * n
        result = list(s)
        
        def dfs(node: int, indices: List[int]) -> None:
            # 深度优先搜索找出连通分量中的所有索引
            visited[node] = True
            indices.append(node)
            for neighbor in graph[node]:
                if not visited[neighbor]:
                    dfs(neighbor, indices)
        
        # 对每个未访问的节点进行 DFS
        for i in range(n):
            if not visited[i]:
                indices = []
                dfs(i, indices)
                
                # 对连通分量内的字符排序
                chars = sorted([s[idx] for idx in indices])
                indices.sort()
                
                # 放回结果
                for idx, char in zip(indices, chars):
                    result[idx] = char
        
        return ''.join(result)
```

## 复杂度分析

### 方法一：并查集

- **时间复杂度**：O(n + m × α(n) + n log n)
  - n 是字符串长度，m 是 pairs 的长度
  - 初始化并查集：O(n)
  - 处理 m 个 pairs：O(m × α(n))，α(n) 是反阿克曼函数，接近常数
  - 分组和排序：O(n log n)
  
- **空间复杂度**：O(n)
  - parent 数组：O(n)
  - groups 字典：O(n)
  - result 数组：O(n)

### 方法二：并查集 + 按秩合并

- **时间复杂度**：O(n + m × α(n) + n log n)，与方法一相同，但常数更小
- **空间复杂度**：O(n)

### 方法三：DFS

- **时间复杂度**：O(n + m + n log n)
  - 构建邻接表：O(m)
  - DFS 遍历：O(n + m)
  - 排序：O(n log n)
  
- **空间复杂度**：O(n + m)
  - 邻接表：O(m)
  - visited 数组：O(n)
  - 递归栈：O(n)

## 关键点总结

1. **识别连通分量**：理解可交换关系的传递性，将问题转化为找连通分量

2. **并查集的应用**：并查集是处理动态连通性问题的标准数据结构

3. **路径压缩优化**：在 find 操作中，将路径上的节点直接连到根节点，降低树的高度

4. **分组排序**：对每个连通分量独立处理，组内排序后按位置放回

5. **索引排序的必要性**：提取字符时和放回字符时都要确保索引有序，保证对应关系正确

## 易错点

1. **忘记对索引排序**：在放回字符时，如果索引没有排序，会导致字符放错位置

2. **理解传递性**：可能只考虑直接可交换的对，忽略了间接可交换的情况
   - 例如：[0,1], [1,2] 意味着 0、1、2 三个位置可以任意排列

3. **并查集实现错误**：
   - find 函数忘记路径压缩
   - union 函数直接修改 parent[x] 而不是 parent[find(x)]

4. **DFS 栈溢出**：对于极长的链式连通分量，递归 DFS 可能栈溢出，应改用迭代版本

5. **边界情况**：
   - pairs 为空时，直接返回原字符串
   - s 长度为 1 时，无法交换
