## 题目描述

如果一个数列由至少两个元素组成，且每两个连续元素之间的差值都相同，那么这个序列就是一个**等差数列**。

给你一个整数数组 `nums` 和两个整数数组 `l` 和 `r`，对于每个查询 `[l[i], r[i]]`，判断 `nums[l[i]..r[i]]`（包含端点，重新排列后）是否可以构成等差数列。

返回一个布尔数组，每个元素对应一个查询的答案。

**示例：**
```
输入：nums = [4,6,5,9,3,7], l = [0,0,2], r = [2,3,5]
输出：[true,false,true]
解释：
- [4,6,5] 排序后 [4,5,6]，公差=1，是等差数列
- [4,6,5,9] 排序后 [4,5,6,9]，不是等差数列
- [5,9,3,7] 排序后 [3,5,7,9]，公差=2，是等差数列
```

## 解题思路

对每个查询，提取子数组，排序后检查是否是等差数列：
1. 排序后，相邻元素的差应该都相等
2. 或者：`max - min = (n-1) * d`，且差值都是 d

## 代码实现

### 方法一：排序检验（推荐）

```python
from typing import List

class Solution:
    def checkArithmeticSubarrays(self, nums: List[int], l: List[int], r: List[int]) -> List[bool]:
        def is_arithmetic(sub: List[int]) -> bool:
            sub.sort()
            if len(sub) < 2:
                return True
            d = sub[1] - sub[0]
            for i in range(2, len(sub)):
                if sub[i] - sub[i-1] != d:
                    return False
            return True
        
        return [is_arithmetic(nums[l[i]: r[i] + 1]) for i in range(len(l))]
```

### 方法二：哈希表检验（不需要排序）

```python
from typing import List

class Solution:
    def checkArithmeticSubarrays(self, nums: List[int], l: List[int], r: List[int]) -> List[bool]:
        def is_arithmetic(l_idx: int, r_idx: int) -> bool:
            sub = nums[l_idx: r_idx + 1]
            n = len(sub)
            if n < 2:
                return True
            
            min_val = min(sub)
            max_val = max(sub)
            
            if (max_val - min_val) % (n - 1) != 0:
                return False
            
            d = (max_val - min_val) // (n - 1)
            
            if d == 0:
                # 所有元素相同
                return all(x == min_val for x in sub)
            
            # 检查每个期望值是否都存在
            seen = set(sub)
            for k in range(n):
                if min_val + k * d not in seen:
                    return False
            return True
        
        return [is_arithmetic(l[i], r[i]) for i in range(len(l))]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序检验 | O(q * m log m) | O(m) |
| 哈希表检验 | O(q * m) | O(m) |

q 为查询数，m 为子数组平均长度。

## 关键点总结

1. 排序后检查相邻差是否相等，是最直观的方法
2. 哈希表方法：先用最大最小值确定公差，再验证每个期望值存在
3. 等差数列的必要条件：`(max - min) % (n-1) == 0`
4. 特殊情况：所有元素相同（公差为 0）

## 易错点

- 切片 `nums[l[i]: r[i] + 1]` 要包含右端点 `r[i]`
- 哈希表方法中，公差为 0 时需要特殊处理
- 子数组长度为 1 时也算等差数列（或根据题意返回 True）
