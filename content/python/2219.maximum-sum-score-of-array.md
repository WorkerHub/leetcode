## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，数组长度为 `n`。

`nums` 在下标 `i`（`0 <= i < n`）处的**得分**定义为：`max(前缀和 [0..i], 后缀和 [i..n-1])`。

返回 `nums` 在所有下标处的**最大得分**。

**示例 1：**
```
输入：nums = [4,3,-2,5]
输出：10
解释：
下标0：max(4, 4+3-2+5=10) = 10
下标1：max(4+3=7, 3-2+5=6) = 7
下标2：max(4+3-2=5, -2+5=3) = 5
下标3：max(4+3-2+5=10, 5) = 10
最大得分为10。
```

**示例 2：**
```
输入：nums = [-3,-5]
输出：-3
```

## 解题思路

预计算前缀和数组和后缀和数组，对每个下标 i 取两者较大值，返回全局最大。

## 代码实现

### 方法一：前缀和 + 后缀和（推荐）

```python
from typing import List

class Solution:
    def maximumSumScore(self, nums: List[int]) -> int:
        n = len(nums)

        # 计算前缀和：prefix[i] = nums[0] + nums[1] + ... + nums[i]
        prefix = [0] * n
        prefix[0] = nums[0]
        for i in range(1, n):
            prefix[i] = prefix[i - 1] + nums[i]

        # 计算后缀和：suffix[i] = nums[i] + nums[i+1] + ... + nums[n-1]
        suffix = [0] * n
        suffix[-1] = nums[-1]
        for i in range(n - 2, -1, -1):
            suffix[i] = suffix[i + 1] + nums[i]

        # 对每个下标取前缀和与后缀和的最大值，返回全局最大
        return max(max(prefix[i], suffix[i]) for i in range(n))
```

### 方法二：一次遍历（边算边取最大）

```python
from typing import List

class Solution:
    def maximumSumScore(self, nums: List[int]) -> int:
        total = sum(nums)
        prefix = 0
        ans = float('-inf')

        for x in nums:
            prefix += x
            suffix = total - prefix + x  # suffix[i] = total - prefix[i-1]
            ans = max(ans, max(prefix, suffix))

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，计算前缀和和后缀和各一次遍历。
- 空间复杂度：O(n)（方法一），O(1)（方法二）。

## 关键点总结

1. 前缀和 `prefix[i]` 和后缀和 `suffix[i]` 可以 O(n) 预计算。
2. 方法二利用 `suffix[i] = total - prefix[i-1]`，只需一次遍历，空间 O(1)。

## 易错点

- 后缀和计算：`suffix[i] = total - prefix + x`（`prefix` 是包含当前元素的累积和，`total` 是全数组和）。
