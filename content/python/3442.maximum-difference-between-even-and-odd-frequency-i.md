## 题目描述

给你一个字符串 `s`（只包含小写字母）。

返回字符串中**出现奇数次的字符的最大频率**与**出现偶数次的字符的最小频率**之差。

如果不存在出现奇数次或偶数次的字符，差值分别视为 0。

**示例 1：**

```
输入：s = "aaaaabbc"
输出：3
解释：
a 出现 5 次（奇数），b 出现 2 次（偶数），c 出现 1 次（奇数）
奇数频率最大 = 5，偶数频率最小 = 2
差值 = 5 - 2 = 3
```

**示例 2：**

```
输入：s = "abcabcab"
输出：1
解释：
a 出现 3 次，b 出现 3 次，c 出现 2 次
奇数最大 = 3，偶数最小 = 2，差 = 1
```

**提示：**
- `3 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

统计每个字符的出现次数，然后将频率分为奇数组和偶数组，分别求最大值和最小值，计算差值。

## Python 代码实现

### 方法一：Counter + 分组（推荐）

```python
from collections import Counter

class Solution:
    def maxDifference(self, s: str) -> int:
        freq = Counter(s)

        odd_freqs = [f for f in freq.values() if f % 2 == 1]
        even_freqs = [f for f in freq.values() if f % 2 == 0]

        max_odd = max(odd_freqs) if odd_freqs else 0
        min_even = min(even_freqs) if even_freqs else 0

        return max_odd - min_even
```

### 方法二：一次遍历

```python
from collections import Counter

class Solution:
    def maxDifference(self, s: str) -> int:
        freq = Counter(s)

        max_odd = 0
        min_even = float('inf')

        for f in freq.values():
            if f % 2 == 1:
                max_odd = max(max_odd, f)
            else:
                min_even = min(min_even, f)

        if min_even == float('inf'):
            min_even = 0

        return max_odd - min_even
```

### 方法三：简洁版

```python
from collections import Counter

class Solution:
    def maxDifference(self, s: str) -> int:
        vals = list(Counter(s).values())
        odd = [v for v in vals if v % 2 == 1]
        even = [v for v in vals if v % 2 == 0]
        return (max(odd) if odd else 0) - (min(even) if even else 0)
```

## 复杂度分析

- 时间复杂度：O(n + k)，n 为字符串长度，k 为不同字符数（最多 26）
- 空间复杂度：O(k)

## 关键点总结

1. 用 Counter 统计频率
2. 按奇偶分组，分别找最大奇频和最小偶频
3. 若某种频率类型不存在，按题意视为 0

## 易错点

1. 不存在偶数频率时，min_even 不能是 inf（会返回负数差值），而是 0
2. 不存在奇数频率时，max_odd 为 0
3. 只有一个字符时可能只有奇数或只有偶数频率
