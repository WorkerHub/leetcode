## 题目描述

给你一个整数数组 `nums`，你可以最多进行一次操作：删除数组中的一个元素。

判断是否能通过最多一次删除操作使数组变为非递减序列（即 `nums[i] <= nums[i+1]`）。

**示例 1：**

```
输入：nums = [4, 2, 3]
输出：true
解释：删除 4，数组变为 [2, 3]，非递减。
```

**示例 2：**

```
输入：nums = [4, 2, 1]
输出：false
解释：无论删除哪个元素，都无法使数组非递减。
```

**示例 3：**

```
输入：nums = [1, 2, 3]
输出：true
解释：已经非递减，无需操作。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

找到第一个"违规点"（即 `nums[i] > nums[i+1]`）：
1. 若没有违规点，直接返回 True。
2. 若有违规点，尝试删除 `nums[i]` 或 `nums[i+1]`，检查剩余数组是否非递减。

## Python 代码实现

### 方法一：贪心找违规点（推荐）

```python
from typing import List

class Solution:
    def checkPossibility(self, nums: List[int]) -> bool:
        def is_non_decreasing(arr):
            return all(arr[i] <= arr[i + 1] for i in range(len(arr) - 1))

        for i in range(len(nums) - 1):
            if nums[i] > nums[i + 1]:
                # 尝试删除 nums[i] 或 nums[i+1]
                return (is_non_decreasing(nums[:i] + nums[i + 1:]) or
                        is_non_decreasing(nums[:i + 1] + nums[i + 2:]))

        return True  # 无违规点
```

### 方法二：O(n) 优化（不拼接数组）

```python
from typing import List

class Solution:
    def checkPossibility(self, nums: List[int]) -> bool:
        def check(skip):
            """检查跳过下标 skip 后数组是否非递减"""
            prev = float('-inf')
            for i, v in enumerate(nums):
                if i == skip:
                    continue
                if v < prev:
                    return False
                prev = v
            return True

        for i in range(len(nums) - 1):
            if nums[i] > nums[i + 1]:
                return check(i) or check(i + 1)

        return True
```

## 复杂度分析

- 时间复杂度：O(n)，最多遍历两次数组
- 空间复杂度：O(1)，方法二不创建新数组

## 关键点总结

1. 找到第一个违规点后，只需尝试删除这两个位置中的一个。
2. 不需要枚举所有可能的删除，贪心地删除违规点处的元素即可。
3. 最多只有一次违规点需要处理（超过两处则必须删除超过一个元素）。

## 易错点

1. 不要创建新数组（`nums[:i] + nums[i+1:]`），这会带来额外的 O(n) 时间和空间。
2. 遇到第一个违规后必须立即检查，不能继续遍历（后面可能有更多违规）。
