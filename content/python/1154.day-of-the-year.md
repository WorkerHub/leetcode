## 题目描述

给你一个字符串 date，它的格式为 Day-Month-Year，其中：
- Day 是集合 {1, 2, ..., 31} 中的一个整数
- Month 是集合 {Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec} 中的一个字符串
- Year 的范围在 [1900, 2100] 之间

请你返回给定日期是这一年的第几天。

**示例 1：**
```
输入：date = "05-May-1977"
输出：125
```

**示例 2：**
```
输入：date = "10-Jan-2019"
输出：10
```

**示例 3：**
```
输入：date = "20-Sep-2011"
输出：263
```

**提示：**
- 给定日期保证是合法的

## 解题思路

计算给定日期是一年中的第几天，需要考虑：

1. **月份天数**：
   - 1,3,5,7,8,10,12月：31天
   - 4,6,9,11月：30天
   - 2月：平年28天，闰年29天

2. **闰年判断**：
   - 能被400整除是闰年
   - 能被4整除但不能被100整除是闰年
   - 其他是平年

3. **计算方法**：
   - 累加之前所有月份的天数
   - 加上当前月份的天数

## Python 代码实现

### 方法一：直接计算 ⭐

```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        """
        解析日期并计算天数
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        # 解析日期
        parts = date.split('-')
        day = int(parts[0])
        month_str = parts[1]
        year = int(parts[2])
        
        # 月份映射
        months = {
            "Jan": 1, "Feb": 2, "Mar": 3, "Apr": 4,
            "May": 5, "Jun": 6, "Jul": 7, "Aug": 8,
            "Sep": 9, "Oct": 10, "Nov": 11, "Dec": 12
        }
        month = months[month_str]
        
        # 每月天数（平年）
        days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 判断闰年
        is_leap = (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)
        if is_leap:
            days_in_month[1] = 29
        
        # 累加之前月份的天数
        result = sum(days_in_month[:month - 1]) + day
        
        return result
```

### 方法二：使用 datetime 库 ⭐ 推荐

```python
from datetime import datetime

class Solution:
    def dayOfYear(self, date: str) -> int:
        """
        使用 Python 内置库
        """
        # 解析日期
        day, month, year = date.split('-')
        
        # 月份映射
        month_num = {
            "Jan": "01", "Feb": "02", "Mar": "03", "Apr": "04",
            "May": "05", "Jun": "06", "Jul": "07", "Aug": "08",
            "Sep": "09", "Oct": "10", "Nov": "11", "Dec": "12"
        }[month]
        
        # 构造日期字符串
        date_str = f"{year}-{month_num}-{day.zfill(2)}"
        dt = datetime.strptime(date_str, "%Y-%m-%d")
        
        # 获取一年中的第几天
        return dt.timetuple().tm_yday
```

### 方法三：简化版本

```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        """
        更简洁的实现
        """
        day, month_str, year = date.split('-')
        day, year = int(day), int(year)
        
        # 月份到数字的映射
        month_map = ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
                     "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
        month = month_map.index(month_str) + 1
        
        # 平年每月天数
        days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 闰年2月+1天
        if (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0):
            days[1] = 29
        
        return sum(days[:month - 1]) + day
```

### 方法四：使用列表推导

```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        """
        使用列表推导式
        """
        day, month, year = date.split('-')
        day, year = int(day), int(year)
        
        months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
                  "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
        days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 闰年判断
        if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
            days[1] = 29
        
        # 找到月份索引
        m = months.index(month)
        
        # 累加天数
        return sum(days[:m]) + day
```

## 关键点总结

1. **闰年判断公式**：
   - `year % 400 == 0` 或
   - `year % 4 == 0 and year % 100 != 0`

2. **月份天数**：
   - 使用列表存储：[31,28,31,30,31,30,31,31,30,31,30,31]

3. **计算方法**：
   - 前面月份天数之和 + 当前天数

4. **字符串解析**：
   - 使用 split('-') 分割
   - 月份需要转换为数字

5. **边界处理**：
   - 题目保证日期合法，无需验证

## 易错点

1. **闰年判断顺序**：
   ```python
   # 错误：顺序错误
   year % 4 == 0 and year % 100 != 0 or year % 400 == 0
   
   # 正确：400的优先级最高
   year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
   ```

2. **月份索引**：
   - 月份从1开始，数组索引从0开始
   - `sum(days[:month - 1])` 不是 `sum(days[:month])`

3. **2月天数**：
   - 平年28天，闰年29天
   - 忘记更新闰年2月天数

4. **月份映射**：
   - 字符串月份需要转换为数字
   - 注意大小写

5. **返回值**：
   - 返回累加和 + 当前天数
   - 不是只返回累加和

## 闰年规则详解

```python
def is_leap_year(year):
    """
    闰年判断规则：
    1. 能被400整除的是闰年（如2000）
    2. 能被4整除但不能被100整除的是闰年（如2004）
    3. 其他是平年（如1900, 2001）
    """
    if year % 400 == 0:
        return True  # 2000是闰年
    if year % 100 == 0:
        return False  # 1900不是闰年
    if year % 4 == 0:
        return True  # 2004是闰年
    return False  # 2001不是闰年
    
    # 简化版本
    return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
```
