## 题目描述

给定一棵二叉树（根节点为 `root`）和一个整数数组 `arr`，判断 `arr` 是否与二叉树中某条**从根节点到叶子节点**的路径上的节点值序列完全一致。

叶子节点定义：没有子节点的节点。

**示例 1：**
```
输入：root = [0,1,0,0,1,0,null,null,1,0,0], arr = [0,1,0,1]
输出：true
解释：路径 0 -> 1 -> 0 -> 1 对应数组 arr
```

**示例 2：**
```
输入：root = [0,1,0,0,1,0,null,null,1,0,0], arr = [0,0,1]
输出：false
解释：路径 0 -> 0 不存在对应的叶子节点结尾
```

**提示：**
- 树中节点数量在 `[1, 5000]` 范围内
- `0 <= Node.val <= 9`
- `1 <= arr.length <= 5000`

## 解题思路

**核心思路：DFS 递归匹配**

从根节点出发，同步遍历数组和树的路径：
1. 当前节点值必须等于 `arr[index]`。
2. 到达叶子节点时，`index` 必须正好等于 `arr` 最后一个元素的下标（即数组恰好用完）。
3. 若当前节点为空或值不匹配，直接返回 `False`。
4. 递归检查左子树或右子树。

**关键判断条件（叶子节点处）：**  
节点无左子节点且无右子节点，且 `index == len(arr) - 1`，返回 `True`。

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import Optional, List

# 二叉树节点定义
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isValidSequence(self, root: Optional[TreeNode], arr: List[int]) -> bool:
        def dfs(node: Optional[TreeNode], index: int) -> bool:
            # 节点为空，或当前值与数组不匹配，返回 False
            if node is None or index >= len(arr) or node.val != arr[index]:
                return False

            # 到达叶子节点：必须刚好用完数组
            if node.left is None and node.right is None:
                return index == len(arr) - 1

            # 递归检查左子树和右子树
            return dfs(node.left, index + 1) or dfs(node.right, index + 1)

        return dfs(root, 0)
```

### 方法二：BFS 迭代

```python
from typing import Optional, List
from collections import deque

class Solution:
    def isValidSequence(self, root: Optional[TreeNode], arr: List[int]) -> bool:
        if not root:
            return False

        n = len(arr)
        # 队列存储 (节点, 当前匹配到的下标)
        queue = deque([(root, 0)])

        while queue:
            node, idx = queue.popleft()

            # 值不匹配，跳过
            if idx >= n or node.val != arr[idx]:
                continue

            # 到达叶子节点，且刚好匹配到数组末尾
            if node.left is None and node.right is None and idx == n - 1:
                return True

            # 将子节点加入队列
            if node.left:
                queue.append((node.left, idx + 1))
            if node.right:
                queue.append((node.right, idx + 1))

        return False
```

### 方法三：DFS 迭代（显式栈）

```python
from typing import Optional, List

class Solution:
    def isValidSequence(self, root: Optional[TreeNode], arr: List[int]) -> bool:
        if not root:
            return False

        n = len(arr)
        # 栈存储 (节点, 当前下标)
        stack = [(root, 0)]

        while stack:
            node, idx = stack.pop()

            # 边界检查和值匹配
            if idx >= n or node.val != arr[idx]:
                continue

            # 叶子节点且数组用尽
            if node.left is None and node.right is None:
                if idx == n - 1:
                    return True
                continue

            # 将子节点压栈
            if node.right:
                stack.append((node.right, idx + 1))
            if node.left:
                stack.append((node.left, idx + 1))

        return False
```

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 为树的节点数，最坏情况下遍历所有节点。
- **空间复杂度：** O(h)，h 为树的高度，递归调用栈的深度。最坏情况（链状树）为 O(n)，平衡树为 O(log n)。

## 关键点总结

1. 叶子节点的判断必须同时满足两个条件：是叶子节点，且数组下标正好到达末尾。
2. 仅路径长度等于数组长度且每个节点值对应匹配才算有效序列。
3. DFS 只要找到一条满足条件的路径就返回 `True`，用 `or` 连接左右子树的递归。
4. 注意 `index >= len(arr)` 的越界检查放在节点值比较之前。

## 易错点

- 误将"到达空节点"当作成功条件，忘记检查是否是叶子节点。
- 忘记检查 `index == len(arr) - 1`，导致路径长于或短于数组都返回 `True`。
- 非叶子节点的路径中途用完了数组，未正确处理此边界。
