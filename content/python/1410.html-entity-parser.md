## 题目描述

HTML 实体解析器 是一种特殊的解析器，它将 HTML 代码作为输入，并用字符本身替换掉所有这些特殊的字符实体。

HTML 里这些特殊字符和它们对应的字符实体包括：

| 字符 | 实体 |
|------|------|
| `"` | `&quot;` |
| `'` | `&apos;` |
| `&` | `&amp;` |
| `>` | `&gt;` |
| `<` | `&lt;` |
| `/` | `&frasl;` |

给你输入字符串 `text` ，实现一个 HTML 实体解析器，返回解析器解析后的结果。

**示例 1：**

```
输入：text = "&amp; is an HTML entity but &ambassador; is not."
输出："& is an HTML entity but &ambassador; is not."
```

**示例 2：**

```
输入：text = "and I quote: &quot;...&quot;"
输出："and I quote: \"...\""
```

**示例 3：**

```
输入：text = "Stay home! Practice on Leetcode :)"
输出："Stay home! Practice on Leetcode :)"
```

**提示：**

- `1 <= text.length <= 10^5`
- 字符串可能包含 256 个 ASCII 字符中的任意字符

## 解题思路

### 方法一：哈希表 + str.replace()（推荐）

建立一个从实体到字符的映射字典，然后依次替换。

**注意顺序：** `&amp;` 必须最后替换（或者先替换），否则会把其他实体中的 `&` 提前替换掉，导致实体识别失败。

例如 `&amp;amp;` 如果先替换 `&amp;` 变成 `&amp;`（但这里演示 `&amp;amp;` 应被解析成字面量 `&amp;`），所以 `&amp;` 必须最后处理。

正确顺序：先处理其他5个实体，最后处理 `&amp;`。

### 方法二：正则表达式

用正则一次性匹配所有实体，通过回调函数替换，天然避免顺序问题。

### 方法三：手动扫描

遍历字符串，遇到 `&` 时向后寻找 `;`，提取实体名称并查表替换。这是最"手工"的方法，但最清晰。

## Python 代码实现

### 方法一：哈希表 + str.replace()（推荐）

```python
class Solution:
    def entityParser(self, text: str) -> str:
        # 定义实体到字符的映射
        # 注意：&amp; 必须放在最后替换，避免影响其他实体中的 &
        entities = [
            ("&quot;", '"'),
            ("&apos;", "'"),
            ("&gt;",   ">"),
            ("&lt;",   "<"),
            ("&frasl;", "/"),
            ("&amp;",  "&"),   # 必须最后替换
        ]

        for entity, char in entities:
            text = text.replace(entity, char)

        return text
```

### 方法二：正则表达式（一次扫描）

```python
import re

class Solution:
    def entityParser(self, text: str) -> str:
        # 建立映射字典
        mapping = {
            "&quot;":  '"',
            "&apos;":  "'",
            "&amp;":   "&",
            "&gt;":    ">",
            "&lt;":    "<",
            "&frasl;": "/",
        }

        # 用正则匹配所有已知实体，通过 lambda 查表替换
        # 正则的好处：一次扫描，不存在顺序问题
        pattern = re.compile("|".join(re.escape(k) for k in mapping))
        return pattern.sub(lambda m: mapping[m.group(0)], text)
```

### 方法三：手动字符扫描（逐字符处理）

```python
class Solution:
    def entityParser(self, text: str) -> str:
        # 建立映射字典
        mapping = {
            "&quot;":  '"',
            "&apos;":  "'",
            "&amp;":   "&",
            "&gt;":    ">",
            "&lt;":    "<",
            "&frasl;": "/",
        }

        result = []
        i = 0
        n = len(text)

        while i < n:
            if text[i] == '&':
                # 向后找分号，最多看 7 个字符（最长实体 &frasl; 长7）
                j = text.find(';', i + 1, i + 8)
                if j != -1:
                    entity = text[i:j + 1]
                    if entity in mapping:
                        # 识别到合法实体，替换后跳过
                        result.append(mapping[entity])
                        i = j + 1
                        continue
            # 不是实体，直接添加当前字符
            result.append(text[i])
            i += 1

        return "".join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| str.replace() | O(6 * n) = O(n) | O(n) |
| 正则表达式 | O(n) | O(n) |
| 手动扫描 | O(n) | O(n) |

其中 `n` 为字符串长度。

## 关键点总结

1. `&amp;` 必须最后替换（方法一），否则会引起连锁替换错误
2. 正则方法用 `re.compile("|".join(...))` 一次匹配多个模式，性能更好
3. 手动扫描用 `find(';', i+1, i+8)` 限定搜索范围，避免过长匹配
4. 最长实体 `&frasl;` 有 7 个字符，所以搜索范围最多 `i+8`

## 易错点

1. 方法一中 `&amp;` 顺序错误：如果先替换 `&amp;`，会破坏字符串中其他位置的 `&` 开头的实体
2. 方法三中 `find` 的范围：`text.find(';', i+1, i+8)` 中第三个参数是 exclusive，要写 `i+8` 而不是 `i+7`
3. 实体 `&apos;` 是单引号 `'`，不是反引号
