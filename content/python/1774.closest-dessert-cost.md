## 题目描述

你打算做甜点，现在需要购买配料。目前共有 `n` 种冰淇淋基料和 `m` 种配料可供选购。而打算做的甜点会有一份冰淇淋基料，可以添加**一种或多种**配料，也可以不添加任何配料。

给你以下三个输入：
- `baseCosts`，一个长度为 `n` 的整数数组，其中每个 `baseCosts[i]` 表示第 `i` 种冰淇淋基料的价格。
- `toppingCosts`，一个长度为 `m` 的整数数组，其中每个 `toppingCosts[i]` 表示**一份**第 `i` 种配料的价格。
- `target`，一个整数，代表你参照的价格。

你希望自己做的甜点总费用尽可能接近（差值尽量小） `target`。

每种配料可以添加 0 份、1 份或 2 份，但冰淇淋基料只能添加 1 份。

返回最接近 `target` 的甜点总费用，如果有多种方案，返回**较小**的总费用。

**提示：**
- `1 <= baseCosts.length, toppingCosts.length <= 10`
- `1 <= baseCosts[i], toppingCosts[i] <= 10^4`
- `1 <= target <= 10^4`

## 解题思路

**回溯/DP**：由于 `toppingCosts` 最多 10 种，每种可选 0/1/2 份，共 3^10 = 59049 种配料组合。

枚举每种基料，再枚举所有配料组合，找到最接近 target 的值。

## 代码实现

### 方法一：回溯（推荐）

```python
from typing import List

class Solution:
    def closestCost(self, baseCosts: List[int], toppingCosts: List[int], target: int) -> int:
        self.ans = float('inf')
        m = len(toppingCosts)
        
        def backtrack(idx, current):
            # 更新答案
            diff = abs(current - target)
            ans_diff = abs(self.ans - target)
            if diff < ans_diff or (diff == ans_diff and current < self.ans):
                self.ans = current
            
            # 剪枝：当前已超过 target 且大于已知最优
            if current >= target:
                return
            
            if idx == m:
                return
            
            # 配料 idx 可以加 0、1 或 2 份
            for cnt in range(3):
                backtrack(idx + 1, current + toppingCosts[idx] * cnt)
        
        for base in baseCosts:
            backtrack(0, base)
        
        return self.ans
```

### 方法二：动态规划（背包思路）

```python
from typing import List

class Solution:
    def closestCost(self, baseCosts: List[int], toppingCosts: List[int], target: int) -> int:
        # dp[c] 表示是否可以达到费用 c
        # 配料最多 2 * sum(toppingCosts) <= 2 * 10 * 10000 = 200000，但 target <= 10^4
        # 只需考虑 0 到 2 * target 范围
        max_cost = 2 * target
        
        # 所有可能的配料总费用组合
        topping_costs_set = {0}
        for t in toppingCosts:
            new_set = set()
            for c in topping_costs_set:
                for cnt in range(3):
                    nc = c + t * cnt
                    if nc <= max_cost:
                        new_set.add(nc)
            topping_costs_set = new_set
        
        ans = float('inf')
        for base in baseCosts:
            for tc in topping_costs_set:
                cost = base + tc
                diff = abs(cost - target)
                ans_diff = abs(ans - target)
                if diff < ans_diff or (diff == ans_diff and cost < ans):
                    ans = cost
        
        return ans
```

## 复杂度分析

- **方法一**：时间 O(n * 3^m)，n 是基料数，m 是配料数
- **方法二**：时间 O(3^m + n * 3^m)，空间 O(3^m)

## 关键点总结

1. 枚举所有基料，对每个基料枚举所有配料组合
2. 目标是最小化 `|cost - target|`，同分时取较小的 cost
3. 剪枝：当 current > target 时可以停止（已经超了）

## 易错点

- 多种答案时返回**较小**的费用
- 每种配料可加 0、1 或 2 份
