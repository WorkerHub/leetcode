## 题目描述

给你一个字符串 `s`，它包含一些括号对，每个括号中有一个键。同时给你一个映射 `knowledge`，其中 `knowledge[i] = [keyi, valuei]` 表示一对键值。

你需要将 `s` 中所有被括号括起来的键替换为对应的值（如果键存在于 `knowledge` 中），若键不存在则替换为 `"?"`。

返回替换后的字符串。

**示例 1：**
```
输入：s = "(name)is(age)yearsold", knowledge = [["name","bob"],["age","two"]]
输出："bobistwoyearsold"
```

**示例 2：**
```
输入：s = "hi(name)", knowledge = [["a","b"]]
输出："hi?"
```

**提示：**
- `1 <= s.length <= 10^5`
- `0 <= knowledge.length <= 10^5`
- `knowledge[i].length == 2`
- `s` 中不会有嵌套括号

## 解题思路

先将 `knowledge` 列表转换为哈希表，然后扫描字符串 `s`：
- 遇到 `(` 时开始收集键名，直到 `)`
- 遇到普通字符直接加入结果

用哈希表实现 O(1) 的键值查询。

## 代码实现

### 方法一：哈希表 + 字符串扫描（推荐）

```python
from typing import List

class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        # 构建哈希表，O(k) 时间
        kv_map = {key: val for key, val in knowledge}
        result = []
        i = 0
        n = len(s)
        while i < n:
            if s[i] == '(':
                # 找到对应的右括号
                j = i + 1
                while j < n and s[j] != ')':
                    j += 1
                key = s[i+1:j]
                result.append(kv_map.get(key, '?'))
                i = j + 1  # 跳过右括号
            else:
                result.append(s[i])
                i += 1
        return ''.join(result)
```

### 方法二：正则替换

```python
import re
from typing import List

class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        kv_map = {key: val for key, val in knowledge}
        # 使用正则找到所有括号内的键并替换
        return re.sub(r'\(([^)]+)\)', lambda m: kv_map.get(m.group(1), '?'), s)
```

## 复杂度分析

- **时间复杂度**：O(n + k)，n 为字符串长度，k 为 knowledge 长度
- **空间复杂度**：O(n + k)，结果字符串和哈希表

## 关键点总结

1. 先构建哈希表，查询效率从 O(k) 降到 O(1)
2. 使用列表收集结果后最后 join，比字符串拼接效率更高
3. 正则方法代码简洁，适合竞赛快速实现

## 易错点

- 直接用字符串 `+=` 拼接在 Python 中效率低，应使用列表 + join
- 注意跳过右括号时 i 应设为 j+1，不能设为 j
