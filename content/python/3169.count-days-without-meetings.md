## 题目描述

给你一个正整数 `days`，表示员工可用的总天数，以及一个二维整数数组 `meetings`，`meetings[i] = [start_i, end_i]`。

返回员工可以工作但没有安排会议的天数。

**示例 1：**
```
输入：days = 10, meetings = [[5,7],[1,3],[9,10]]
输出：2
解释：会议覆盖 1-3、5-7、9-10，空闲天数 4、8，共 2 天。
```

**提示：**
- `1 <= days <= 10^9`
- `1 <= meetings.length <= 10^5`

## 解题思路

合并重叠区间，计算会议覆盖的总天数，答案 = days - 覆盖天数。

## Python 代码实现

### 方法一：合并区间（推荐）

```python
from typing import List

class Solution:
    def countDays(self, days: int, meetings: List[List[int]]) -> int:
        meetings.sort()
        # 合并重叠区间
        merged = []
        for start, end in meetings:
            if merged and start <= merged[-1][1] + 1:
                merged[-1][1] = max(merged[-1][1], end)
            else:
                merged.append([start, end])

        # 计算覆盖天数
        covered = sum(e - s + 1 for s, e in merged)
        return days - covered
```

### 方法二：差分数组（大 days 不可用，但思路清晰）

```python
from typing import List

class Solution:
    def countDays(self, days: int, meetings: List[List[int]]) -> int:
        meetings.sort()
        free = 0
        cur_end = 0  # 当前合并区间的结尾

        for start, end in meetings:
            if start > cur_end + 1:
                free += start - cur_end - 1  # 中间的空闲天
            cur_end = max(cur_end, end)

        # 最后一个会议之后的空闲天
        free += days - cur_end
        return free
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 合并重叠区间后计算覆盖天数
2. 空闲天数 = 总天数 - 覆盖天数
3. 区间合并：排序后比较相邻区间

## 易错点

1. 注意合并时判断条件是 `start <= cur_end + 1`（连续也算重叠）
2. 最后要加上最后一个会议之后的空闲天
