## 题目描述

给你一个由 `n` 个数对组成的数对数组 `pairs`，其中 `pairs[i] = [left_i, right_i]` 且 `left_i < right_i`。

现在，我们定义一种**跟随**关系，当且仅当 `b < c` 时，数对 `p2 = [c, d]` 才可以跟在 `p1 = [a, b]` 后面。我们用这种形式来构造**数对链**。

找出并返回能够形成的**最长数对链的长度**。

你不需要用到所有的数对，你可以以任何顺序选择其中的一些数对来构造。

**示例 1：**

```
输入：pairs = [[1,2],[2,3],[3,4]]
输出：2
解释：最长的数对链是 [1,2] -> [3,4]
```

**示例 2：**

```
输入：pairs = [[1,2],[7,8],[4,5]]
输出：3
解释：最长的数对链是 [1,2] -> [4,5] -> [7,8]
```

**提示：**

- `n == pairs.length`
- `1 <= n <= 1000`
- `-1000 <= left_i < right_i <= 1000`

## 解题思路

**核心：贪心算法**

类似于区间调度问题：
1. 按照第二个元素排序
2. 贪心选择：每次选择结束时间最早的区间

## Python 代码实现

### 方法一：贪心（推荐）⭐

```python
from typing import List

class Solution:
    def findLongestChain(self, pairs: List[List[int]]) -> int:
        """
        贪心算法
        
        时间复杂度：O(n log n)
        空间复杂度：O(1)
        """
        # 按第二个元素排序
        pairs.sort(key=lambda x: x[1])
        
        count = 0
        current_end = float('-inf')
        
        for start, end in pairs:
            if start > current_end:
                count += 1
                current_end = end
        
        return count
```

### 方法二：动态规划

```python
class Solution:
    def findLongestChain(self, pairs: List[List[int]]) -> int:
        """
        DP
        
        时间复杂度：O(n^2)
        空间复杂度：O(n)
        """
        pairs.sort()
        n = len(pairs)
        dp = [1] * n
        
        for i in range(n):
            for j in range(i):
                if pairs[j][1] < pairs[i][0]:
                    dp[i] = max(dp[i], dp[j] + 1)
        
        return max(dp)
```

## 关键点总结

1. **贪心选择**：按结束时间排序
2. **类似区间调度**：435. Non-overlapping Intervals
3. **DP 也可解**：但贪心更优
