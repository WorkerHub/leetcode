## 题目描述

给你一个区间列表，请你删除列表中被其他区间所覆盖的区间。

只有当 `c <= a` 且 `b <= d` 时，区间 `[a,b]` 才被区间 `[c,d]` 覆盖。

在完成所有删除操作后，请你返回列表中剩余区间的数目。

**示例 1：**

```
输入：intervals = [[1,4],[3,6],[2,8]]
输出：2
解释：区间 [3,6] 被区间 [2,8] 覆盖，所以它被删除了。
```

**示例 2：**

```
输入：intervals = [[1,4],[2,3]]
输出：1
解释：区间 [2,3] 被区间 [1,4] 覆盖，所以它被删除了。
```

**提示：**

- `1 <= intervals.length <= 1000`
- `intervals[i].length == 2`
- `0 <= intervals[i][0] <= intervals[i][1] <= 10^5`
- 所有区间都是**唯一**的。

---

## 解题思路

### 覆盖的定义

区间 `[a,b]` 被 `[c,d]` 覆盖，意味着 `c <= a` 且 `b <= d`，即 `[c,d]` 完全包含 `[a,b]`。

### 贪心策略：排序后扫描

**排序规则**：
- 按**左端点升序**排列。
- 左端点相同时，按**右端点降序**排列（右端点大的排前面）。

**为什么这样排序？**
- 左端点相同时，右端点更大的区间一定覆盖右端点更小的区间（因为左端点相同，c=a，且 d>b，所以 [a,b] 被 [a,d] 覆盖）。
- 把右端点大的排前面，处理时只需维护一个"最大右端点"。

**扫描过程**：
- 维护变量 `max_right`，表示已处理过的所有区间中右端点的最大值。
- 遍历排序后的区间 `[l, r]`：
  - 如果 `r <= max_right`：当前区间的右端点 <= 已有区间的最大右端点，且由于排序，当前区间的左端点 >= 产生该最大右端点的区间的左端点，所以当前区间被覆盖，不计入答案。
  - 如果 `r > max_right`：当前区间不被覆盖，计入答案，更新 `max_right = r`。

**图解示例（intervals = [[1,4],[3,6],[2,8]]）：**

```
排序后（左端点升序，左端点相同则右端点降序）：
[1,4], [2,8], [3,6]

遍历：
  [1,4]: r=4 > max_right=0，不被覆盖，count=1，max_right=4
  [2,8]: r=8 > max_right=4，不被覆盖，count=2，max_right=8
  [3,6]: r=6 <= max_right=8，被覆盖（[3,6] 被 [2,8] 覆盖），跳过

最终 count=2，返回 2
```

## Python 代码实现

### 方法一：排序 + 贪心扫描（推荐）

```python
from typing import List

class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        # 按左端点升序，左端点相同则按右端点降序
        intervals.sort(key=lambda x: (x[0], -x[1]))

        count = 0       # 未被覆盖的区间数
        max_right = 0   # 当前最大右端点

        for l, r in intervals:
            if r > max_right:
                # 右端点超过已知最大值，当前区间未被覆盖
                count += 1
                max_right = r
            # 否则 r <= max_right，当前区间被之前某个区间覆盖，跳过

        return count
```

### 方法二：暴力双重循环（用于理解覆盖定义）

```python
from typing import List

class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        n = len(intervals)
        removed = [False] * n  # 标记每个区间是否被覆盖

        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                # 检查 intervals[i] 是否被 intervals[j] 覆盖
                a, b = intervals[i]
                c, d = intervals[j]
                if c <= a and b <= d:
                    # [a,b] 被 [c,d] 覆盖
                    removed[i] = True
                    break

        # 返回未被覆盖的区间数量
        return sum(1 for r in removed if not r)
```

**注意**：方法二时间复杂度 O(n²)，当 n=1000 时约 10^6 次操作，可以 AC，但方法一更优。

### 方法三：更详细注释的贪心版本（帮助理解）

```python
from typing import List

class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        # 排序：左端点升序，确保遍历时前面的区间左端点 <= 当前区间左端点
        # 左端点相同时右端点降序：这样左端点相同时，大区间在前，小区间会被识别为被覆盖
        intervals.sort(key=lambda x: (x[0], -x[1]))

        result = 0    # 最终保留的区间数量
        max_r = 0     # 到目前为止，所有已保留区间中的最大右端点

        for left, right in intervals:
            # 由于排序，当前区间的 left >= 所有已处理区间的 left
            # 如果 right <= max_r，则当前区间被某个已处理区间覆盖（该区间左端点<=left，右端点>=right）
            if right > max_r:
                result += 1     # 当前区间不被任何已处理区间覆盖
                max_r = right   # 更新最大右端点

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 贪心 | O(n log n) | O(1) |
| 暴力双重循环 | O(n²) | O(n) |

- **排序贪心**：排序 O(n log n)，遍历 O(n)，总体 O(n log n)。
- **空间**：排序原地进行（Python 的 `list.sort()` 是原地排序），结果变量为 O(1)。

## 关键点总结

1. **排序是关键**：将区间按左端点升序、右端点降序排列后，只需维护一个"最大右端点"变量，就可以 O(n) 完成检测。
2. **覆盖判断简化**：排序后，遍历时当前区间的左端点必然 >= 所有已处理区间的左端点，因此只需比较右端点。
3. **不需要"哪个区间覆盖了哪个"**：只需知道当前区间是否被覆盖（即 `r <= max_right`），不需要找到具体的覆盖区间。
4. **左端点相同时右端点降序的作用**：确保左端点相同的区间中，大区间先被处理（更新 max_right），后来的小区间会因 `r <= max_right` 被识别为覆盖。
5. **count 初始化为 0**：从 0 开始，每发现一个未被覆盖的区间就 +1。

以 `intervals = [[1,4],[2,3],[3,6],[1,6]]` 为例：

**排序后（左端点升序，右端点降序）：**
```
[1,6], [1,4], [2,3], [3,6]
```

**扫描过程：**
```
max_right = 0

[1,6]: r=6 > 0, count=1, max_right=6
[1,4]: r=4 <= 6, 被 [1,6] 覆盖，跳过
[2,3]: r=3 <= 6, 被 [1,6] 覆盖，跳过

```

## 易错点

1. **排序方式**：左端点相同时必须按右端点**降序**，若写成 `intervals.sort(key=lambda x: (x[0], x[1]))` 则会将小区间排在大区间前，导致小区间先被计入 count（更新 max_right），大区间反而无法被识别为非覆盖。
2. **初始 max_right**：初始化为 0 而非 -1 或 float('-inf')，因为区间右端点 `intervals[i][1] >= 0`，max_right=0 等同于"还未处理任何区间"（第一个区间的 r 必然 > 0）。
3. **覆盖的定义**：`c <= a AND b <= d`，是完全包含，不是单侧包含。暴力解法中注意两个条件都要满足。
4. **相同区间**：题目说"所有区间都是唯一的"，所以不需要处理两个完全相同的区间互相覆盖的情况。

## 学习建议

区间类题目是面试和竞赛中的常见题型，核心技巧通常是**先排序，再线性扫描**：

1. **排序策略的选择**：根据题目需求决定排序方式。覆盖问题用"左端点升序+右端点降序"；合并问题用"左端点升序"；最少删除用"右端点升序"。

2. **理解为什么排序后可以线性扫描**：排序建立了区间之间的偏序关系，使得扫描过程中只需维护有限的状态（如最大右端点），而不需要对所有已处理区间进行检查。

3. **建议做题顺序**：56（合并区间）-> 435（最少删除）-> 1288（本题）-> 986（区间交集），由浅入深掌握区间类题目的解题模式。
