## 题目描述

给你两个大小为 `n x n` 的二进制矩阵 `mat` 和 `target`，判断能否通过将 `mat` 顺时针旋转 0、90、180、270 度后等于 `target`。

**示例 1：**
```
输入：mat = [[0,1],[1,0]], target = [[1,0],[0,1]]
输出：true（旋转90度）
```

**示例 2：**
```
输入：mat = [[0,1],[1,1]], target = [[1,0],[1,1]]
输出：false
```

## 解题思路

将 mat 旋转 0、90、180、270 度，逐一与 target 比较，若有一次相等则返回 true。

顺时针旋转 90 度的变换：`new[j][n-1-i] = mat[i][j]`（或等价 `new[i][j] = mat[n-1-j][i]`）。

## 代码实现

### 方法一：枚举四种旋转（推荐）

```python
from typing import List

class Solution:
    def findRotation(self, mat: List[List[int]], target: List[List[int]]) -> bool:
        n = len(mat)

        def rotate_90(matrix: List[List[int]]) -> List[List[int]]:
            """顺时针旋转 90 度"""
            return [[matrix[n - 1 - j][i] for j in range(n)] for i in range(n)]

        current = mat
        for _ in range(4):
            if current == target:
                return True
            current = rotate_90(current)
        return False
```

### 方法二：直接枚举所有旋转条件

```python
from typing import List

class Solution:
    def findRotation(self, mat: List[List[int]], target: List[List[int]]) -> bool:
        n = len(mat)
        # 检查四种旋转
        # 0度、90度、180度、270度
        for _ in range(4):
            if mat == target:
                return True
            # 顺时针旋转 90 度（原地）
            mat = [[mat[n - 1 - j][i] for j in range(n)] for i in range(n)]
        return False
```

## 复杂度分析

- **时间复杂度**：O(n^2)，旋转和比较各 O(n^2)，共 4 次
- **空间复杂度**：O(n^2)，存储旋转后的矩阵

## 关键点总结

1. 只需检查 4 种旋转（0、90、180、270 度）
2. 顺时针旋转 90 度：`new[i][j] = old[n-1-j][i]`
3. 连续旋转 4 次会回到原始状态

## 易错点

- 旋转公式：顺时针 90 度是 `new[i][j] = old[n-1-j][i]`，不要记混方向
