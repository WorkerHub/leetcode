## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`，其中每个元素为 0 或 1。

**直角三角形** 定义为三个值均为 1 的单元格，其中两个单元格在同一行，另一个单元格在同一列（直角在拐角处）。

返回矩阵中直角三角形的数目。

**示例：**
```
输入：grid = [[0,1,0],[0,1,1],[0,1,0]]
输出：2
```

**提示：**
- `1 <= m, n <= 1000`
- `0 <= grid[i][j] <= 1`

## 解题思路

对每个值为 1 的格子 `(i, j)`，它可以作为直角的顶点（即直角在该格子处）。此时：
- 同行中其他 1 的个数为 `row[i] - 1`
- 同列中其他 1 的个数为 `col[j] - 1`

以 `(i, j)` 为直角顶点的直角三角形数量为 `(row[i] - 1) * (col[j] - 1)`。

遍历所有值为 1 的格子，累加即为答案。

## Python 代码实现

### 方法一：预计算行列统计（推荐）

```python
from typing import List

class Solution:
    def numberOfRightTriangles(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 预计算每行、每列中 1 的个数
        row_count = [sum(grid[i]) for i in range(m)]
        col_count = [sum(grid[i][j] for i in range(m)) for j in range(n)]

        ans = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    # (i,j) 作为直角顶点
                    ans += (row_count[i] - 1) * (col_count[j] - 1)
        return ans
```

### 方法二：使用 numpy 向量化

```python
from typing import List

class Solution:
    def numberOfRightTriangles(self, grid: List[List[int]]) -> int:
        row_c = [sum(row) for row in grid]
        col_c = [sum(grid[i][j] for i in range(len(grid))) for j in range(len(grid[0]))]

        return sum(
            (row_c[i] - 1) * (col_c[j] - 1)
            for i in range(len(grid))
            for j in range(len(grid[0]))
            if grid[i][j] == 1
        )
```

## 复杂度分析

- 时间复杂度：O(m * n)，预计算和遍历各一次
- 空间复杂度：O(m + n)，存储行列统计

## 关键点总结

1. 直角三角形的直角顶点处：同行有其他 1，同列也有其他 1
2. 对每个 1 格子，贡献 `(row-1) * (col-1)` 个三角形
3. 先预计算行列 1 的个数，避免重复计算

## 易错点

1. 是 row_count - 1 和 col_count - 1，因为当前格子本身算在内
2. 只有值为 1 的格子才能作为顶点
