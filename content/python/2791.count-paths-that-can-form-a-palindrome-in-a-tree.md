## 题目描述

给你一棵 **根为 0** 的树，`n` 个节点（编号 0 到 n-1），边上有标签（小写字母）。给你 `parent` 数组和 `s`（每条边的标签）。

统计满足路径上的字符可以重排为 **回文串** 的节点对数 `(u, v)`（`u < v`）的数量。

**提示：**
- 路径上的字符能重排为回文串，当且仅当至多一个字符出现奇数次（用 26 位掩码表示）
- `n <= 10^5`

## 解题思路

**DFS + 位掩码**：从根节点到每个节点的路径可以用 26 位掩码表示（每位对应一个字母是否出现奇数次）。

对节点对 (u, v)，路径 u->v 的掩码 = mask[u] XOR mask[v]（公共前缀（LCA 到根）被抵消）。

路径能组成回文 ↔ XOR 结果中至多一位为 1（即 XOR == 0 或 XOR 是 2 的幂）。

用哈希表统计每个掩码出现次数，对每个节点 v 的掩码 m，查找：
1. 与 m 相同的掩码数（XOR = 0）
2. 与 m XOR 2^i 相同的掩码数（XOR = 2^i，i = 0..25）

## Python 代码实现

### 方法一：DFS + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPalindromePaths(self, parent: List[int], s: str) -> int:
        n = len(parent)
        # 构建树
        children = defaultdict(list)
        for i in range(1, n):
            children[parent[i]].append(i)

        ans = 0
        # mask_count[m] = 从根到某节点路径掩码为 m 的节点数
        mask_count = defaultdict(int)
        mask_count[0] = 1  # 根节点（掩码 0）

        def dfs(node, mask):
            nonlocal ans
            # 当前路径掩码
            # 查找可以与当前节点配对的节点
            # XOR == 0 或 XOR == 2^i
            ans += mask_count[mask]
            for i in range(26):
                ans += mask_count[mask ^ (1 << i)]
            mask_count[mask] += 1
            for child in children[node]:
                # 边 (parent[child], child) 的标签为 s[child]
                bit = ord(s[child]) - ord('a')
                dfs(child, mask ^ (1 << bit))
            mask_count[mask] -= 1  # 回溯

        dfs(0, 0)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 26)
- 空间复杂度：O(n)

## 关键点总结

1. 根到节点的路径用 26 位掩码表示字母奇偶性
2. 两节点路径 = 两掩码 XOR（LCA 以上部分抵消）
3. 掩码 XOR 结果至多一位为 1 时可组成回文

## 易错点

1. 根节点掩码为 0（空路径）
2. 回溯时减少掩码计数（DFS 的正确性）
