## 题目描述

**全字母句** 是指包含英语字母表中每个字母至少一次的句子。

给你一个仅由小写英文字母组成的字符串 `sentence`，如果它是全字母句，则返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：sentence = "thequickbrownfoxjumpsoverthelazydog"
输出：true
```

**示例 2：**
```
输入：sentence = "leetcode"
输出：false
```

**提示：**
- `1 <= sentence.length <= 1000`
- `sentence` 只包含小写英文字母

## 解题思路

判断字符串中是否包含所有 26 个小写字母。用集合统计出现过的字母，判断集合大小是否为 26。

## 代码实现

### 方法一：集合判断（推荐）

```python
class Solution:
    def checkIfPangram(self, sentence: str) -> bool:
        # 将字符串转为集合，判断是否包含所有 26 个字母
        return len(set(sentence)) == 26
```

### 方法二：位掩码

```python
class Solution:
    def checkIfPangram(self, sentence: str) -> bool:
        # 用一个整数的 26 位表示 26 个字母是否出现
        mask = 0
        for ch in sentence:
            mask |= 1 << (ord(ch) - ord('a'))
        # 26 位全为 1 时，mask = (1 << 26) - 1
        return mask == (1 << 26) - 1
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（集合最多 26 个元素）

## 关键点总结

1. `set(sentence)` 自动去重，大小为 26 即全字母句
2. 位掩码方法空间更省，每位对应一个字母

## 易错点

- 26 个字母，不是 25 个
- 只包含小写字母，无需考虑大小写问题
