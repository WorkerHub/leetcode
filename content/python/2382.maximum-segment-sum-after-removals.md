## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums` 和 `removeQueries`，均含 `n` 个元素。对于第 `i` 次查询，从 `nums` 中**删除** `removeQueries[i]` 位置的元素（不删除实际上是将其变为 0，并将其与周围元素隔开）。

返回一个长度为 `n` 的数组 `answer`，其中 `answer[i]` 是第 `i` 次查询**之后** `nums` 中各段和的**最大值**（段是连续非删除元素的序列）。

**提示：**
- `n == nums.length == removeQueries.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**逆向 + 并查集：**
从后往前处理（相当于逐步添加元素），用并查集维护连通分量及其和，每次添加一个元素后更新最大段和。

**算法：**
1. 逆序处理 `removeQueries`（从最后一次删除到第一次删除）。
2. 每次"添加"一个元素，合并与左右已存在元素的连通分量。
3. 维护一个 `max_sum` 变量记录当前最大段和。
4. 将 `max_sum` 记录在答案的对应位置（时间逆序）。

## 代码实现

### 方法一：逆向并查集（推荐）

```python
from typing import List

class Solution:
    def maximumSegmentSum(self, nums: List[int], removeQueries: List[int]) -> List[int]:
        n = len(nums)
        parent = list(range(n))
        seg_sum = [0] * n   # 每个连通分量的和
        added = [False] * n  # 该位置是否已添加
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(x, y):
            rx, ry = find(x), find(y)
            if rx == ry:
                return
            # 合并（简单按大小合并或任意）
            parent[ry] = rx
            seg_sum[rx] += seg_sum[ry]
        
        max_sum = 0
        ans = [0] * n
        
        # 逆向添加元素
        for i in range(n - 1, -1, -1):
            idx = removeQueries[i]
            added[idx] = True
            seg_sum[idx] = nums[idx]
            
            # 合并左邻
            if idx > 0 and added[idx - 1]:
                union(idx, idx - 1)
            # 合并右邻
            if idx < n - 1 and added[idx + 1]:
                union(idx, idx + 1)
            
            max_sum = max(max_sum, seg_sum[find(idx)])
            ans[i] = max_sum
        
        return ans
```

### 方法二：有序集合（TreeMap 模拟）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def maximumSegmentSum(self, nums: List[int], removeQueries: List[int]) -> List[int]:
        n = len(nums)
        # 用哨兵简化边界处理
        # 删除后剩余区间的端点
        # 直接用并查集更清晰，方法一已是最优
        # 此处实现逆向扫描
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        # 用有序集合记录已删除位置（分隔符）
        # 初始全部删除，逆向添加
        deleted = SortedList(range(-1, n + 1))  # 哨兵 -1 和 n
        max_sum = 0
        ans = [0] * n
        
        for i in range(n - 1, -1, -1):
            idx = removeQueries[i]
            # 从删除集合中移除 idx（添加回来）
            deleted.remove(idx)
            # 找 idx 左右的最近已删除位置
            pos = deleted.bisect_left(idx)
            left = deleted[pos - 1]   # 左边第一个删除位置（哨兵）
            right = deleted[pos]       # 右边第一个删除位置（哨兵）
            # 区间 (left, right) 的和
            seg = prefix[right] - prefix[left + 1]
            max_sum = max(max_sum, seg)
            ans[i] = max_sum
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 | O(n * alpha(n)) | O(n) |
| 有序集合 | O(n log n) | O(n) |

## 关键点总结

1. 逆向思维：删除 -> 添加，用并查集维护连通分量。
2. 每次添加一个元素，合并左右邻居，更新最大段和。
3. 答案从后往前填写，最后是第 0 次查询之后。

## 易错点

- 答案记录的是每次查询**之后**的最大段和，而不是之前。
- 并查集的 `seg_sum` 存储在根节点，合并时要正确更新。
