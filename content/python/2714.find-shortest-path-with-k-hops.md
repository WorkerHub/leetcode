## 题目描述

给你一个 `n` 个节点（编号 0 到 n-1）的无向带权图，以及整数 `src`、`dst`、`k`。

你最多可以使用 `k` 次 **跳跃**（hop），每次跳跃让你以 0 代价通过一条边（即忽略这条边的权重）。

返回从 `src` 到 `dst` 的最短路径长度，如果不可达返回 -1。

**示例 1：**
```
输入：n = 4, edges = [[0,1,4],[0,2,2],[2,3,6]], src = 0, dst = 3, k = 1
输出：2
解释：路径 0->2->3，正常距离 2+6=8；使用 1 次跳跃免费走 2->3，距离变为 2。
```

**提示：**
- `2 <= n <= 500`
- `1 <= edges.length <= 10^4`
- `1 <= k <= n`

## 解题思路

**扩展 Dijkstra**：状态设为 `(节点, 已用跳跃次数)`，总状态数 O(n * k)。

- `dist[node][hops]` = 使用了 `hops` 次跳跃到达 `node` 的最短距离
- 普通边：代价为边权；跳跃边：代价为 0（消耗一次跳跃机会）
- Dijkstra 贪心扩展最短路

## Python 代码实现

### 方法一：扩展 Dijkstra（推荐）

```python
import heapq
from typing import List
from collections import defaultdict

class Solution:
    def shortestPathWithHops(self, n: int, edges: List[List[int]], src: int, dst: int, k: int) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # dist[node][hops] = 使用 hops 次跳跃到达 node 的最短距离
        INF = float('inf')
        dist = [[INF] * (k + 1) for _ in range(n)]
        dist[src][0] = 0

        # 优先队列：(距离, 节点, 已用跳跃数)
        heap = [(0, src, 0)]

        while heap:
            d, u, hops = heapq.heappop(heap)
            if d > dist[u][hops]:
                continue
            for v, w in graph[u]:
                # 普通走法
                new_d = d + w
                if new_d < dist[v][hops]:
                    dist[v][hops] = new_d
                    heapq.heappush(heap, (new_d, v, hops))
                # 使用跳跃（免费）
                if hops < k and d < dist[v][hops + 1]:
                    dist[v][hops + 1] = d
                    heapq.heappush(heap, (d, v, hops + 1))

        ans = min(dist[dst])
        return ans if ans < INF else -1
```

### 方法二：将跳跃数作为第三维 Dijkstra

```python
import heapq
from typing import List
from collections import defaultdict

class Solution:
    def shortestPathWithHops(self, n: int, edges: List[List[int]], src: int, dst: int, k: int) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        INF = float('inf')
        # 用字典记录已访问状态
        visited = {}
        heap = [(0, src, 0)]  # (dist, node, hops_used)

        while heap:
            d, u, h = heapq.heappop(heap)
            if (u, h) in visited:
                continue
            visited[(u, h)] = d
            if u == dst:
                return d
            for v, w in graph[u]:
                if (v, h) not in visited:
                    heapq.heappush(heap, (d + w, v, h))
                if h < k and (v, h + 1) not in visited:
                    heapq.heappush(heap, (d, v, h + 1))

        return -1
```

## 复杂度分析

- 时间复杂度：O((n*k + E) * log(n*k))，E 为边数
- 空间复杂度：O(n*k + E)

## 关键点总结

1. 将状态扩展为 (节点, 已用跳跃数)，标准 Dijkstra 处理
2. 跳跃边代价为 0，普通边代价为边权
3. 跳跃次数不超过 k

## 易错点

1. 跳跃时距离不增加（d 不变，不是 d+0 特别是在浮点比较时）
2. 最终答案取 `min(dist[dst][0..k])`
