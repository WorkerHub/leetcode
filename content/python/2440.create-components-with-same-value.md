## 题目描述

有一棵 `n` 个节点的无向树，节点编号为 `0` 到 `n - 1`。

给你一个整数数组 `nums`，其中 `nums[i]` 表示第 `i` 个节点的值。另外给你一个长度为 `n - 1` 的二维整数数组 `edges`，其中 `edges[i] = [ai, bi]` 表示 `ai` 和 `bi` 之间有一条无向边。

你可以 **删除** 一些边，将这棵树分割成多个连通分量。每个分量的 **值** 等于该分量中所有节点的值之和。

返回能删除的 **最多** 边数，使得每个分量的值相等。

**提示：**
- `1 <= n <= 2 * 10^4`
- `1 <= nums[i] <= 50`
- `edges.length == n - 1`

## 解题思路

**枚举分量个数 + 树形 DP：**

设总和 `S = sum(nums)`，若分成 `k` 个等值分量，则每个分量值 = `S / k`。

`k` 必须是 `S` 的因子，且 `k` 个分量需要删除 `k - 1` 条边。

**枚举每个可能的 k（S 的因子）：**
- 验证能否把树分成 k 个等值分量
- 树形 DP：DFS 计算每棵子树的和，当子树和等于 `S/k` 时，切断该子树（贡献一个分量）

## 代码实现

### 方法一：枚举因子 + 树形 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def componentValue(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        S = sum(nums)

        # 建邻接表
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        def dfs(node: int, parent: int, target: int) -> int:
            """返回以 node 为根的子树的和（mod target）
            如果子树已构成一个分量（和等于 target），返回 0 继续累计
            如果任何子树和超过 target，返回 -1 表示不可行
            """
            sub_sum = nums[node]
            for child in adj[node]:
                if child == parent:
                    continue
                child_sum = dfs(child, node, target)
                if child_sum == -1:
                    return -1
                sub_sum += child_sum
            if sub_sum > target:
                return -1
            return sub_sum % target  # 若 sub_sum == target，返回 0（分割一个分量）

        # 枚举 S 的因子 k（从大到小，尽早找到最大答案）
        for k in range(n, 1, -1):
            if S % k == 0:
                target = S // k
                if dfs(0, -1, target) == 0:
                    return k - 1  # 删除 k-1 条边

        return 0
```

### 方法二：优化枚举（只枚举合法因子）

```python
from typing import List
from collections import defaultdict

class Solution:
    def componentValue(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        S = sum(nums)
        max_val = max(nums)

        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        def check(target: int) -> bool:
            def dfs(node: int, parent: int) -> int:
                s = nums[node]
                for child in adj[node]:
                    if child != parent:
                        child_s = dfs(child, node)
                        if child_s < 0:
                            return -1
                        s += child_s
                if s > target:
                    return -1
                return s % target

            return dfs(0, -1) == 0

        # 枚举因子，target 必须 >= max(nums)
        for k in range(n, 1, -1):
            if S % k == 0:
                target = S // k
                if target >= max_val and check(target):
                    return k - 1

        return 0
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 + DFS | O(n * d(S)) | O(n) |

其中 d(S) 是 S 的因子个数（S <= 50 * 2 * 10^4 = 10^6，因子数较少）。

## 关键点总结

1. 枚举分割成 k 个等值分量，每个分量值 = S/k
2. DFS 返回子树和，若等于目标值则切断（返回 0）
3. 若子树和超过目标值，返回 -1 表示不可行

## 易错点

- 每个分量的值必须 >= max(nums)（单个最大值节点也必须满足）
- DFS 中超过 target 返回 -1，而不是继续累加
