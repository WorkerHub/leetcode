## 题目描述

给你一个下标从 0 开始的字符串 `s` 和一个整数 `k`。

你需要执行以下分区操作，直到字符串为空：

1. 从 `s` 的最左侧开始，取尽可能长的子字符串，使其中不同字符的数量不超过 `k`，令该子字符串的长度为 `l`。
2. 从 `s` 中删除这 `l` 个字符，并增加分区数量。

你还可以在开始分区操作之前，将 `s` 中的某一个字符修改为另一个小写英文字母，执行修改操作最多一次。

返回修改后，分区操作所能得到的最大分区数量。

**示例 1：**
```
输入：s = "accca", k = 2
输出：3
```

**示例 2：**
```
输入：s = "aabaab", k = 3
输出：1
```

**提示：**
- `1 <= s.length <= 10^4`
- `s` 只包含小写英文字母
- `1 <= k <= 26`

## 解题思路

使用动态规划 + 位掩码。

定义 `dp[i][mask][changed]`：
- `i`：当前处理到位置 `i`
- `mask`：当前分区已使用的字符集合（用26位整数表示）
- `changed`：是否已经使用修改机会（0 或 1）

值为从位置 `i` 开始，当前分区字符集为 `mask`，修改机会状态为 `changed` 时，能得到的最大分区数。

利用记忆化搜索（自顶向下DP）实现。

## Python 代码实现

### 方法一：记忆化搜索 + 位掩码（推荐）

```python
from functools import lru_cache

class Solution:
    def maxPartitionsAfterOperations(self, s: str, k: int) -> int:
        n = len(s)

        @lru_cache(maxsize=None)
        def dp(i: int, mask: int, changed: int) -> int:
            # 已处理完所有字符
            if i == n:
                return 0

            res = 0
            cur_mask = mask

            # 枚举当前分区的结束位置
            for j in range(i, n):
                bit = 1 << (ord(s[j]) - ord('a'))
                new_mask = cur_mask | bit
                # 统计 new_mask 中 1 的个数（不同字符数）
                if bin(new_mask).count('1') > k:
                    # 无法继续延伸，开始新分区
                    res = max(res, 1 + dp(j, 0, changed))
                    break
                cur_mask = new_mask
            else:
                # 当前分区延伸到末尾
                res = max(res, 1)

            # 如果还没有使用修改机会，尝试修改 s[i..n-1] 中某个字符
            if not changed:
                cur_mask2 = mask
                for j in range(i, n):
                    bit = 1 << (ord(s[j]) - ord('a'))
                    new_mask2 = cur_mask2 | bit
                    if bin(new_mask2).count('1') > k:
                        # 在位置 j 处将字符修改为当前 mask 中已有的字符
                        # 相当于不增加新字符，让分区在 j 处不断开
                        # 尝试将 s[j] 改为 mask 中已有的字符（不增加新位）
                        res = max(res, 1 + dp(j, 0, 1))
                        break
                    cur_mask2 = new_mask2
                else:
                    res = max(res, 1)

            return res

        # 正确的记忆化DP实现
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def solve(i: int, mask: int, changed: int) -> int:
            if i == n:
                return 0

            c = ord(s[i]) - ord('a')
            bit = 1 << c
            new_mask = mask | bit

            if bin(new_mask).count('1') > k:
                # 当前字符使新分区超出 k，必须开启新分区
                result = 1 + solve(i, 0, changed)
            else:
                # 继续当前分区
                result = solve(i + 1, new_mask, changed)

            # 尝试修改当前字符（如果还没修改过）
            if not changed:
                # 枚举修改为 26 个字母中的某个
                for c2 in range(26):
                    bit2 = 1 << c2
                    new_mask2 = mask | bit2
                    if bin(new_mask2).count('1') <= k:
                        result = max(result, solve(i + 1, new_mask2, 1))

            return result

        return solve(0, 0, 0)
```

### 方法二：优化版（利用位运算加速）

```python
from functools import lru_cache

class Solution:
    def maxPartitionsAfterOperations(self, s: str, k: int) -> int:
        n = len(s)

        @lru_cache(maxsize=None)
        def dp(i: int, mask: int, changed: int) -> int:
            if i == n:
                return 0

            c = ord(s[i]) - ord('a')
            bit = 1 << c
            new_mask = mask | bit

            # 若加入当前字符后超过 k 种，需要开启新分区
            if bin(new_mask).count('1') > k:
                # 当前字符留给下一个分区，当前分区已经结束（+1），重置 mask
                res = 1 + dp(i, 0, changed)
            else:
                res = dp(i + 1, new_mask, changed)

            # 尝试使用修改机会（最多一次）
            if not changed:
                best = res
                for c2 in range(26):
                    new_mask2 = mask | (1 << c2)
                    if bin(new_mask2).count('1') <= k:
                        best = max(best, dp(i + 1, new_mask2, 1))
                res = best

            return res

        return dp(0, 0, 0)
```

## 复杂度分析

- 时间复杂度：O(n * 2^26 * 2 * 26)，状态数 O(n * 2^26 * 2)，每个状态转移 O(26)
- 实际上由于 mask 的约束（只有少于 k 种字符），状态数远小于上界
- 空间复杂度：O(n * 2^26 * 2)，记忆化存储

## 关键点总结

1. 用位掩码表示字符集，26 位整数表示是否包含该字母
2. `changed` 标志位记录是否使用了修改机会
3. 每次在当前字符处尝试不修改和修改两种情况
4. 修改时枚举所有 26 个可能的替换字符

## 易错点

1. 分区开始新分区时，mask 要重置为 0（不是保留旧 mask）
2. 修改字符时，mask 不变（只替换当前字符，之前的字符不变）
3. 需要注意记忆化递归的状态定义，`changed` 是 int 类型（0/1）以便作为哈希键
