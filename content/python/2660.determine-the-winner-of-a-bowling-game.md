## 题目描述

给你两个下标从 0 开始的整数数组 `player1` 和 `player2`，分别表示两位玩家的保龄球得分（每轮击倒的瓶数）。

计分规则：若玩家在第 `i` 轮打出的分数在前 2 轮内（即 `i-1` 或 `i-2`）曾击倒 10 根球，则本轮得分翻倍。

返回获胜者：1 表示玩家 1 获胜，2 表示玩家 2 获胜，0 表示平局。

**示例 1：**
```
输入：player1 = [4,10,7,9], player2 = [6,5,2,3]
输出：1
解释：player1 第2轮打10（满分），所以第3、4轮翻倍：4+10+14+18=46；player2：6+5+2+3=16
```

**数据范围：**
- 1 <= player1.length == player2.length <= 1000
- 0 <= player1[i], player2[i] <= 10

## 解题思路

模拟计分过程：遍历每轮，检查前两轮是否有满分（10 分），若有则当前轮得分翻倍。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def isWinner(self, player1: List[int], player2: List[int]) -> int:
        def calc_score(scores):
            n = len(scores)
            total = 0
            for i in range(n):
                multiplier = 1
                # 检查前 1 轮
                if i >= 1 and scores[i - 1] == 10:
                    multiplier = 2
                # 检查前 2 轮
                elif i >= 2 and scores[i - 2] == 10:
                    multiplier = 2
                total += scores[i] * multiplier
            return total

        s1 = calc_score(player1)
        s2 = calc_score(player2)

        if s1 > s2:
            return 1
        elif s2 > s1:
            return 2
        else:
            return 0
```

### 方法二：一行计算

```python
from typing import List

class Solution:
    def isWinner(self, player1: List[int], player2: List[int]) -> int:
        def score(arr):
            return sum(
                v * (2 if (i > 0 and arr[i-1] == 10) or (i > 1 and arr[i-2] == 10) else 1)
                for i, v in enumerate(arr)
            )

        s1, s2 = score(player1), score(player2)
        return 1 if s1 > s2 else (2 if s2 > s1 else 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 前两轮有满分（任意一轮）则当前轮翻倍
2. 前 1 轮满分 和 前 2 轮满分是 OR 关系（任一满足即可）

## 易错点

1. 只检查前 1 轮和前 2 轮（不是所有之前的轮次）
2. 翻倍条件是"前两轮"，即 `i-1` 或 `i-2`，不是 `i-1` 和 `i-2`
