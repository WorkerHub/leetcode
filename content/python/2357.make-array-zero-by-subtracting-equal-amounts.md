## 题目描述

给你一个非负整数数组 `nums`。在一步操作中，你必须：
1. 选出一个正整数 `x`，`x` 需要**小于或等于** `nums` 中**最小的非零元素**。
2. 将 `nums` 中所有非零元素减去 `x`。

返回使 `nums` 中**所有元素都等于 0** 所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [1,5,0,3,5]
输出：3
解释：第一次减 1，得 [0,4,0,2,4]；第二次减 2，得 [0,2,0,0,2]；第三次减 2，得 [0,0,0,0,0]。
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 解题思路

每次操作可以将当前最小的非零元素变为 0（选 x = 最小非零值），同时其他元素减少相同量。所以每次操作消灭一个"层级"（不同的正数值），操作次数 = 不同正数值的个数。

## 代码实现

### 方法一：统计不同正数值（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        # 去掉 0，统计不同正数的个数
        return len(set(x for x in nums if x > 0))
```

### 方法二：模拟

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        ops = 0
        nums = nums[:]  # 不修改原数组
        
        while any(x > 0 for x in nums):
            min_val = min(x for x in nums if x > 0)
            for i in range(len(nums)):
                if nums[i] > 0:
                    nums[i] -= min_val
            ops += 1
        
        return ops
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合计数 | O(n) | O(n) |
| 模拟 | O(n * distinct_values) | O(n) |

## 关键点总结

1. 每次操作消灭当前最小正数（全部清零），操作次数等于不同正数值的个数。
2. 用集合快速统计不同正数的个数，O(n) 完成。

## 易错点

- 0 不参与计数，只统计正数的不同值个数。
- 不同值 = 不同的正整数层级数。
