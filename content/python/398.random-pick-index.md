## 题目描述

给你一个可能含有 **重复元素** 的整数数组 `nums`，请你随机输出给定的目标数字 `target` 的索引。你可以假设给定的数字一定存在于数组中。

实现 `Solution` 类：

- `Solution(int[] nums)` 用数组 `nums` 初始化对象。
- `int pick(int target)` 从 `nums` 中选出一个满足 `nums[i] == target` 的随机索引 `i`。如果存在多个有效的索引，则每个索引的返回概率应该相等。

**示例:**

```
输入
["Solution", "pick", "pick", "pick"]
[[[1, 2, 3, 3, 3]], [3], [1], [3]]
输出
[null, 4, 0, 2]

解释
Solution solution = new Solution([1, 2, 3, 3, 3]);
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。
solution.pick(1); // 返回 0 。因为只有 nums[0] 等于 1 。
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。
```

**提示:**

- `1 <= nums.length <= 2 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `target` 是 `nums` 中的一个整数
- 最多调用 `pick` 函数 `10^4` 次

**进阶:** 如果数组非常大且内存有限，该怎么办？

## 解题思路

本题有两种主要解法：**预处理 + 随机选择** 和 **蓄水池抽样**。

### 思路一：预处理（空间换时间）

初始化时用哈希表存储每个值对应的所有索引，pick 时从对应列表中随机选择。

**优点：** pick 时间复杂度 O(1)  
**缺点：** 空间复杂度 O(n)

### 思路二：蓄水池抽样（时间换空间）⭐

每次 pick 时遍历数组，使用蓄水池抽样保证等概率选择。

**优点：** 空间复杂度 O(1)（不算输入数组）  
**缺点：** pick 时间复杂度 O(n)

**蓄水池抽样算法：**

1. 遍历数组，遇到第 k 个 target
2. 以 1/k 的概率选择该索引
3. 最终每个索引被选中的概率都是 1/总数

## Python 代码实现

### 方法一：预处理 + 哈希表（推荐）⭐

```python
from typing import List
import random
from collections import defaultdict

class Solution:
    def __init__(self, nums: List[int]):
        """
        预处理：存储每个值的所有索引
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        self.indices = defaultdict(list)
        for i, num in enumerate(nums):
            self.indices[num].append(i)

    def pick(self, target: int) -> int:
        """
        随机选择一个索引
        时间复杂度: O(1)
        """
        return random.choice(self.indices[target])
```

### 方法二:蓄水池抽样（空间优化）⭐⭐⭐

```python
from typing import List
import random

class Solution:
    def __init__(self, nums: List[int]):
        """
        只保存原数组
        时间复杂度: O(1)
        空间复杂度: O(1)
        """
        self.nums = nums

    def pick(self, target: int) -> int:
        """
        蓄水池抽样
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        count = 0
        result = -1
        
        for i, num in enumerate(self.nums):
            if num == target:
                count += 1
                # 以 1/count 的概率选择当前索引
                if random.randint(1, count) == 1:
                    result = i
        
        return result
```

### 方法三：蓄水池抽样（另一种写法）

```python
from typing import List
import random

class Solution:
    def __init__(self, nums: List[int]):
        self.nums = nums

    def pick(self, target: int) -> int:
        """
        使用 random.randrange
        """
        result = -1
        count = 0
        
        for i, num in enumerate(self.nums):
            if num == target:
                # 以 1/(count+1) 的概率选择当前索引
                if random.randrange(count + 1) == 0:
                    result = i
                count += 1
        
        return result
```

### 方法四：预处理（列表推导）

```python
from typing import List
import random

class Solution:
    def __init__(self, nums: List[int]):
        """
        更简洁的预处理
        """
        self.nums = nums
        self.indices = {}

    def pick(self, target: int) -> int:
        """
        懒加载：第一次遇到 target 时才收集索引
        """
        if target not in self.indices:
            self.indices[target] = [i for i, num in enumerate(self.nums) if num == target]
        
        return random.choice(self.indices[target])
```

## 复杂度分析

### 方法一：预处理

**时间复杂度：**
- 初始化：O(n)
- pick：O(1)

**空间复杂度：** O(n)
- 需要存储所有索引

### 方法二：蓄水池抽样

**时间复杂度：**
- 初始化：O(1)
- pick：O(n)

**空间复杂度：** O(1)
- 不算输入数组

## 关键点总结

1. **蓄水池抽样**：在不知道总数的情况下等概率随机选择
2. **空间时间权衡**：预处理快但耗空间，蓄水池慢但省空间
3. **概率证明**：第 k 个元素被选中的概率是 1/k
4. **进阶要求**：内存有限时必须用蓄水池抽样
5. **懒加载优化**：可以在第一次 pick 时才收集索引

## 易错点

1. **概率理解**：要保证每个索引被选中的概率相等
2. **随机数范围**：`randint(1, count)` 是闭区间 [1, count]
3. **初始值**：result 初始化为 -1，count 初始化为 0
4. **空数组**：题目保证 target 存在，不用处理找不到的情况
5. **蓄水池理解**：需要理解为什么这样可以保证等概率

## 图解示例

```
nums = [1, 2, 3, 3, 3]
target = 3

蓄水池抽样过程:

索引 0: num=1 ≠ 3，跳过
索引 1: num=2 ≠ 3，跳过
索引 2: num=3 = 3
  count = 1
  random(1, 1) = 1，选中
  result = 2

索引 3: num=3 = 3
  count = 2
  random(1, 2) ∈ {1, 2}
  如果 = 1 (概率 1/2)，result = 3
  如果 = 2 (概率 1/2)，result 保持 2

索引 4: num=3 = 3
  count = 3
  random(1, 3) ∈ {1, 2, 3}
  如果 = 1 (概率 1/3)，result = 4
  否则 (概率 2/3)，result 保持不变

最终概率:
- 索引 2: (1) * (1/2) * (2/3) = 1/3
- 索引 3: (1/2) * (2/3) = 1/3
- 索引 4: 1/3

每个索引概率相等 ✓
```
