## 题目描述

给你两个字符串数组 `queries` 和 `dictionary`。数组中所有单词都只包含小写英文字母，且长度都相同。

如果 `dictionary` 中存在一个单词，**恰好在两个或以下** 位置和 `queries[i]` 不同，则认为 `queries[i]` 满足条件。

返回满足条件的所有 `queries[i]` 组成的列表，其中 `queries[i]` 的顺序与原数组一致。

**示例 1：**
```
输入：queries = ["word","note","ants","wood"], dictionary = ["wood","joke","moat"]
输出：["word","wood"]
解释：
- "word" 和 "wood" 有 1 个不同位置，满足条件。
- "note" 和 "wood"、"joke" 均有 >= 3 个不同位置，不满足。
- "ants" 和 "wood"、"joke"、"moat" 均 >= 3 个不同位置，不满足。
- "wood" 和 "wood" 完全相同（0 个不同），满足条件。
```

**提示：**
- `1 <= queries.length, dictionary.length <= 100`
- `n == queries[i].length == dictionary[j].length`
- `1 <= n <= 100`

## 解题思路

**暴力匹配：**

对每个 `queries[i]`，遍历 `dictionary` 中每个单词，计算不同位置的数量。若存在至多 2 个不同位置的单词，则该 query 满足条件。

由于数组长度和单词长度均 <= 100，暴力 O(|Q| * |D| * n) 完全可以接受。

## 代码实现

### 方法一：暴力比较（推荐）

```python
from typing import List

class Solution:
    def twoEditWords(self, queries: List[str], dictionary: List[str]) -> List[str]:
        def diff_count(s: str, t: str) -> int:
            """计算两个字符串不同位置的数量"""
            return sum(a != b for a, b in zip(s, t))

        result = []
        for q in queries:
            # 检查 dictionary 中是否有单词与 q 的差距 <= 2
            for d in dictionary:
                if diff_count(q, d) <= 2:
                    result.append(q)
                    break  # 找到一个就可以，跳出内层循环

        return result
```

### 方法二：字典树（处理大规模数据更高效）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def twoEditWords(self, queries: List[str], dictionary: List[str]) -> List[str]:
        # 构建字典树（适用于大规模问题）
        root = TrieNode()
        for word in dictionary:
            node = root
            for ch in word:
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]
            node.is_end = True

        def search(query: str, node: TrieNode, idx: int, errors: int) -> bool:
            """DFS 在字典树中查找与 query 差距 <= 2 的单词"""
            if errors > 2:
                return False
            if idx == len(query):
                return node.is_end
            ch = query[idx]
            for c, child in node.children.items():
                new_errors = errors + (0 if c == ch else 1)
                if search(query, child, idx + 1, new_errors):
                    return True
            return False

        return [q for q in queries if search(q, root, 0, 0)]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力比较 | O(Q * D * n) | O(1) |
| 字典树 | O(D * n + Q * 26^2 * n) | O(D * n) |

## 关键点总结

1. 距离 <= 2 意味着不同位置最多 2 个
2. 暴力方法在题目规模内完全可行
3. 字典树对大规模查询更高效

## 易错点

- 找到一个满足条件的词后立即 `break`，避免重复添加
- 字典树方法中剪枝：`errors > 2` 时立即返回
