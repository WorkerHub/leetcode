## 题目描述

**未知**整数数组 `arr` 由 `n` 个非负整数组成。

给你的是经编码的数组 `encoded`，其中 `encoded[i] = arr[i] XOR arr[i + 1]`。已知 `arr[0] == first`。

请你解码返回原始数组 `arr`。

**示例 1：**
```
输入：encoded = [1,2,3], first = 1
输出：[1,0,2,1]
```

**提示：**
- `2 <= n <= 10^4`
- `0 <= encoded[i] <= 10^5`
- `0 <= first <= 10^5`

## 解题思路

利用异或的性质：`a XOR b = c` 则 `a XOR c = b`。

已知 `arr[0] = first` 和 `encoded[i] = arr[i] XOR arr[i+1]`，则：
`arr[i+1] = arr[i] XOR encoded[i]`

从第 0 个元素开始，逐个推出后续元素。

## 代码实现

### 方法一：逐步解码（推荐）

```python
from typing import List

class Solution:
    def decode(self, encoded: List[int], first: int) -> List[int]:
        n = len(encoded) + 1
        arr = [0] * n
        arr[0] = first
        
        for i in range(len(encoded)):
            # arr[i+1] = arr[i] XOR encoded[i]
            arr[i + 1] = arr[i] ^ encoded[i]
        
        return arr
```

### 方法二：itertools.accumulate

```python
from typing import List
from itertools import accumulate
from operator import xor

class Solution:
    def decode(self, encoded: List[int], first: int) -> List[int]:
        # 从 first 开始，依次用 xor 累积
        return list(accumulate([first] + encoded, xor))
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历一次
- **空间复杂度**：O(n)，存储结果

## 关键点总结

1. 异或的可逆性：`a ^ b = c` 则 `a ^ c = b`
2. 已知首元素和相邻异或值，可以依次还原所有元素

## 易错点

- 输出数组长度为 `len(encoded) + 1`
