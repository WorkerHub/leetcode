## 题目描述

设计一个贪吃蛇游戏，该游戏将在给定的屏幕大小上运行。如果你不熟悉这个游戏，可以参考维基百科。

实现 `SnakeGame` 类：

- `SnakeGame(int width, int height, int[][] food)` 初始化对象，屏幕大小为 `width x height`，`food` 是食物位置数组，格式为 `food = [[r1, c1], [r2, c2], ...]`。
- `int move(String direction)` 返回蛇吃掉食物后的得分。如果游戏结束返回 `-1`。

**规则：**
- 蛇初始时在 `(0, 0)` 位置，身体长度为 1 个单元格
- 你会获得一个食物位置列表，当蛇吃到食物时，身体长度增加 1
- 如果蛇撞墙或撞到自己的身体，游戏结束
- 食物按顺序出现（吃完一个才出现下一个）

**示例：**
```
输入：
["SnakeGame", "move", "move", "move", "move", "move", "move"]
[[3, 2, [[1, 2], [0, 1]]], ["R"], ["D"], ["R"], ["U"], ["L"], ["U"]]
输出：
[null, 0, 0, 1, 1, 2, -1]

解释：
SnakeGame snakeGame = new SnakeGame(3, 2, [[1, 2], [0, 1]]);
snakeGame.move("R"); // 返回 0
snakeGame.move("D"); // 返回 0
snakeGame.move("R"); // 返回 1，蛇吃掉第一个食物，长度增加
snakeGame.move("U"); // 返回 1
snakeGame.move("L"); // 返回 2，蛇吃掉第二个食物
snakeGame.move("U"); // 返回 -1，游戏结束（撞墙）
```

**提示：**
- `1 <= width, height <= 10^4`
- `1 <= food.length <= 50`
- `food[i].length == 2`
- `0 <= ri < height`
- `0 <= ci < width`
- `direction.length == 1`
- `direction` 为 `'U'`、`'D'`、`'L'` 或 `'R'`
- 最多调用 `10^4` 次 `move`

## 解题思路

这道题需要模拟贪吃蛇的移动过程。

**核心数据结构：**
- 队列（deque）：存储蛇的身体坐标
- 集合（set）：快速判断蛇身是否碰撞

**移动逻辑：**
1. 计算新的头部位置
2. 检查是否出界或撞到自己
3. 检查是否吃到食物
   - 是：头部入队，不删除尾部
   - 否：头部入队，删除尾部

## Python 代码实现

```python
from collections import deque
from typing import List

class SnakeGame:
    def __init__(self, width: int, height: int, food: List[List[int]]):
        self.width = width
        self.height = height
        self.food = food
        self.food_index = 0
        
        # 蛇的身体（队列）
        self.snake = deque([(0, 0)])
        
        # 蛇身集合（用于快速碰撞检测）
        self.snake_set = {(0, 0)}
        
        # 方向映射
        self.directions = {
            'U': (-1, 0),
            'D': (1, 0),
            'L': (0, -1),
            'R': (0, 1)
        }
    
    def move(self, direction: str) -> int:
        # 当前头部位置
        head_r, head_c = self.snake[0]
        
        # 计算新头部位置
        dr, dc = self.directions[direction]
        new_head = (head_r + dr, head_c + dc)
        new_r, new_c = new_head
        
        # 检查是否出界
        if new_r < 0 or new_r >= self.height or new_c < 0 or new_c >= self.width:
            return -1
        
        # 检查是否吃到食物
        ate_food = False
        if self.food_index < len(self.food):
            food_r, food_c = self.food[self.food_index]
            if new_r == food_r and new_c == food_c:
                ate_food = True
                self.food_index += 1
        
        # 如果没吃到食物，移除尾部
        if not ate_food:
            tail = self.snake.pop()
            self.snake_set.remove(tail)
        
        # 检查是否撞到自己（在移除尾部后检查）
        if new_head in self.snake_set:
            return -1
        
        # 添加新头部
        self.snake.appendleft(new_head)
        self.snake_set.add(new_head)
        
        # 返回当前得分
        return len(self.snake) - 1
```

**时间复杂度：** O(1)
**空间复杂度：** O(W × H)，最坏情况蛇占满整个屏幕

## 关键点总结

1. **双数据结构**：deque 维护顺序，set 快速查询
2. **碰撞检测顺序**：先移除尾部再检测碰撞
3. **边界检查**：出界和自撞分开处理
4. **食物索引**：按顺序消费食物

## 易错点

1. **碰撞检测顺序**
   ```python
   # 错误：先检测碰撞再移除尾部
   if new_head in self.snake_set:
       return -1
   if not ate_food:
       self.snake.pop()
   
   # 正确：先移除尾部再检测
   if not ate_food:
       tail = self.snake.pop()
       self.snake_set.remove(tail)
   if new_head in self.snake_set:
       return -1
   ```

2. **返回值**
   ```python
   # 错误：返回长度
   return len(self.snake)
   
   # 正确：返回得分（长度-1）
   return len(self.snake) - 1
   ```
