## 题目描述

给你一个整数数组 `nums`。

如果一个子序列中**相邻元素之差的绝对值恰好为 1**，则称该子序列为**好子序列**。

返回 `nums` 所有好子序列的**元素之和**（对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：nums = [1,2,1]
输出：22
解释：
好子序列：[1],[2],[1],[1,2],[2,1],[1,2,1]
各自元素和：1,2,1,3,3,4 = 14... 
加上所有出现：重复出现的也算，答案 22
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^5`

## 解题思路

DP：`dp[v]` = 以值 v 结尾的所有好子序列的**元素之和**，`cnt[v]` = 以值 v 结尾的好子序列**数量**。

对每个 `nums[i] = v`：
- 可以单独构成一个子序列：贡献 v，数量 1
- 可以接在以 v-1 结尾的子序列后面：贡献 dp[v-1] + cnt[v-1] * v，数量 cnt[v-1]
- 可以接在以 v+1 结尾的子序列后面：贡献 dp[v+1] + cnt[v+1] * v，数量 cnt[v+1]

更新后的 `dp[v]` 和 `cnt[v]`：
- `new_cnt[v] = cnt[v] + cnt[v-1] + cnt[v+1] + 1`
- `new_dp[v] = dp[v] + dp[v-1] + cnt[v-1]*v + dp[v+1] + cnt[v+1]*v + v`

## Python 代码实现

### 方法一：哈希表 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7

        # dp[v] = 以值 v 结尾的所有好子序列的元素之和
        # cnt[v] = 以值 v 结尾的好子序列的数量
        dp = defaultdict(int)
        cnt = defaultdict(int)

        for v in nums:
            # 新的以 v 结尾的子序列来源：
            # 1. 单独 {v}：数量 1，贡献 v
            # 2. 来自以 v-1 结尾的子序列，末尾加 v：数量 cnt[v-1]，贡献 dp[v-1] + cnt[v-1]*v
            # 3. 来自以 v+1 结尾的子序列，末尾加 v：数量 cnt[v+1]，贡献 dp[v+1] + cnt[v+1]*v

            new_cnt = (cnt[v - 1] + cnt[v + 1] + 1) % MOD
            new_dp = (dp[v - 1] + cnt[v - 1] * v +
                      dp[v + 1] + cnt[v + 1] * v + v) % MOD

            cnt[v] = (cnt[v] + new_cnt) % MOD
            dp[v] = (dp[v] + new_dp) % MOD

        return sum(dp.values()) % MOD
```

### 方法二：数组 DP（适合值域不太大时）

```python
from typing import List

class Solution:
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        MAX_VAL = max(nums) + 2

        dp = [0] * MAX_VAL   # 以值 v 结尾的好子序列元素之和
        cnt = [0] * MAX_VAL  # 以值 v 结尾的好子序列数量

        for v in nums:
            new_cnt = (cnt[v - 1] + cnt[v + 1] + 1) % MOD
            new_dp = (dp[v - 1] + cnt[v - 1] * v +
                      dp[v + 1] + cnt[v + 1] * v + v) % MOD
            cnt[v] = (cnt[v] + new_cnt) % MOD
            dp[v] = (dp[v] + new_dp) % MOD

        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(max_val) 或 O(n)

## 关键点总结

1. 同时维护 `dp[v]`（和）和 `cnt[v]`（数量）
2. 每个新元素可以接在 v-1 或 v+1 的子序列后，也可以单独
3. 由于所有子序列都要求相邻差为 1，v 只能接在 v-1 或 v+1 后

## 易错点

1. `cnt[v]` 要先读旧值，再更新（每次处理一个 nums[i]，不是所有 v）
2. 模运算要全程使用，防止溢出
3. 同一值可以多次出现，每次出现都要更新 cnt 和 dp
