## 题目描述

给定整数数组 `nums`，每次操作可以将数组中任意一个元素增加 1。求使数组变为严格递增所需的最少操作次数。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：0
解释：已经是严格递增，不需操作。
```

**示例 2：**
```
输入：nums = [1,2,1,4]
输出：2
解释：将 nums[2] 增加 2：1->3，使 [1,2,3,4] 严格递增，共 2 次操作。
```

**示例 3：**
```
输入：nums = [3,2,1]
输出：3
解释：从右往左调整：nums[1] 增加 1(=3)，nums[2] 增加 2(=5)... 
     实际：nums[2] 需变为 >= nums[1]+1 >= nums[0]+2 = 5，操作 4 次；
     nums[1] 需变为 >= nums[0]+1 = 4，操作 2 次；总 6 次。
     或：nums[0]=3, nums[1] 需 >= 4，增加 2；nums[2] 需 >= 5，增加 4。共 6 次。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^8`

## 解题思路

贪心：从左到右，维护当前最小必要值 `prev`（上一元素的目标值）。

对于每个 `nums[i]`，目标值至少为 `max(nums[i], prev + 1)`，操作次数 = 目标值 - `nums[i]`。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0
        prev = nums[0]  # 上一元素的实际值（经过调整后）

        for i in range(1, n):
            # nums[i] 的目标值至少为 prev + 1
            target = max(nums[i], prev + 1)
            ops += target - nums[i]
            prev = target

        return ops
```

### 方法二：等价变换（减去递增基准）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # 将 nums[i] 减去 i，问题等价于：使变换后的数组非递减
        # 变换后元素 nums[i] - i 需要非递减
        # 对非递减化，策略为每个元素至少等于前一个
        n = len(nums)
        transformed = [nums[i] - i for i in range(n)]
        ops = 0
        prev = transformed[0]

        for i in range(1, n):
            if transformed[i] < prev:
                ops += prev - transformed[i]
                # 不需要修改 prev，因为我们是增加 nums[i]
                # 但等价于强制 transformed[i] >= prev
            else:
                prev = transformed[i]

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只能增加元素，贪心地从左到右保持最小必要值
2. 每个元素的目标值 = `max(原值, 前一个目标值 + 1)`
3. 操作次数 = 目标值 - 原值

## 易错点

1. 只能增加，不能减少，因此目标值取 `max(nums[i], prev+1)`
2. 累加的是 `目标值 - nums[i]`（原始值），不是 `目标值 - prev`
