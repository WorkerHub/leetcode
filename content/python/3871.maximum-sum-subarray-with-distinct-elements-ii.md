## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，找到长度至少为 `k` 且元素互不相同的子数组中，元素之和最大的那个，返回该最大和。如果不存在这样的子数组则返回 0。

**示例 1：**

```
输入：nums = [1, 2, 3, 1, 2], k = 2
输出：6
解释：子数组 [1,2,3] 长度 3 >= 2，和为 6，且元素互不相同。
```

**示例 2：**

```
输入：nums = [1, 2, 3], k = 4
输出：0
解释：没有长度 >= 4 的子数组。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

在 3870 的基础上增加长度约束：长度至少为 k。

使用**滑动窗口**：
1. 维护无重复元素的窗口 `[left, right]`。
2. 只有当窗口长度 >= k 时，才更新最大和。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        left = 0
        curr_sum = 0
        max_sum = 0
        freq = defaultdict(int)

        for right in range(len(nums)):
            v = nums[right]
            freq[v] += 1
            curr_sum += v

            # 有重复，收缩左端
            while freq[v] > 1:
                lv = nums[left]
                freq[lv] -= 1
                curr_sum -= lv
                left += 1

            # 窗口长度满足 >= k 才记录
            if right - left + 1 >= k:
                max_sum = max(max_sum, curr_sum)

        return max_sum
```

### 方法二：记录最优无重复子数组前缀和

```python
from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        last_seen = {}
        left = 0
        curr_sum = 0
        max_sum = 0

        for right, v in enumerate(nums):
            if v in last_seen and last_seen[v] >= left:
                while left <= last_seen[v]:
                    curr_sum -= nums[left]
                    left += 1
            curr_sum += v
            last_seen[v] = right

            if right - left + 1 >= k:
                max_sum = max(max_sum, curr_sum)

        return max_sum
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 在 3870 基础上增加长度 >= k 的判断，其余逻辑相同。
2. 窗口长度 = `right - left + 1`。
3. 若没有满足长度 >= k 且无重复的子数组，返回 0。

## 易错点

1. 长度检查 `right - left + 1 >= k`，不是 `>= k - 1`。
2. 若所有子数组长度均达不到 k，返回默认值 0。
