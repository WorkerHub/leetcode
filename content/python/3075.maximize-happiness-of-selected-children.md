## 题目描述

给你一个长度为 `n` 的整数数组 `happiness` 和整数 `k`。

在你选择每个孩子时，所有未被选中的孩子的快乐值减 1（最小为 0）。每次你选择一个孩子时，该孩子的快乐值是当时的值。

选择 `k` 个孩子，使选中孩子的快乐值总和最大。

返回这个最大值。

**示例 1：**
```
输入：happiness = [1,2,3], k = 2
输出：4
解释：选最大的两个：选 3 时获得 3，再选 2 时获得 2-1=1；总 4
     或者选 3，然后选 2（此时降为 1）：3+1=4
```

**示例 2：**
```
输入：happiness = [1,1,1,1], k = 2
输出：1
```

**提示：**
- `1 <= n <= 2 * 10^5`
- `1 <= happiness[i] <= 10^8`
- `1 <= k <= n`

## 解题思路

贪心：按快乐值降序选择孩子。

第 `i` 次选择（0-indexed），选择的孩子快乐值 = `max(0, sorted_happiness[i] - i)`（因为已经被跳过 `i` 次）。

排序后，选前 `k` 个，每个贡献 `max(0, happiness[i] - i)`。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def maximumHappinessSum(self, happiness: List[int], k: int) -> int:
        happiness.sort(reverse=True)
        total = 0
        for i in range(k):
            val = max(0, happiness[i] - i)
            total += val
        return total
```

### 方法二：早停优化

```python
from typing import List

class Solution:
    def maximumHappinessSum(self, happiness: List[int], k: int) -> int:
        happiness.sort(reverse=True)
        total = 0
        for i in range(k):
            val = happiness[i] - i
            if val <= 0:
                break  # 后续值更小，不再增加
            total += val
        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 降序排序，每次选最大值
2. 第 `i` 次选择（0-indexed）时，该孩子快乐值减少 `i`（前面的 `i` 次选择都跳过了它）
3. 快乐值最小为 0

## 易错点

1. 快乐值不能为负，要取 `max(0, val)`
2. 贪心每次选当前最大的是正确的（降序选择不会更差）
