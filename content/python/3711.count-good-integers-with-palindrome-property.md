## 题目描述

给定整数 `n` 和 `k`，统计所有满足以下条件的 `n` 位整数的个数：
1. 该整数是一个回文数（从左读和从右读相同）
2. 该整数能被 `k` 整除

返回满足条件的整数个数。

**示例 1：**
```
输入：n = 1, k = 4
输出：2
解释：1 位回文数为 1-9，其中 4 和 8 能被 4 整除，共 2 个。
```

**示例 2：**
```
输入：n = 5, k = 6
输出：2
解释：5 位回文数能被 6 整除的有 2 个。
```

**提示：**
- `1 <= n <= 9`
- `1 <= k <= 9`

## 解题思路

枚举所有 n 位回文数，检查其是否能被 k 整除。

**回文数的生成方法：**
- n 位回文数由前 `ceil(n/2)` 位决定，后半部分是前半部分的镜像。
- 枚举前半部分 `half`，从 `10^(ceil(n/2)-1)` 到 `10^(ceil(n/2)) - 1`（保证首位不为 0）。
- 构造完整回文数后检查是否被 k 整除。

为了避免重复计数（同一数字的不同排列），使用集合存储已排序的数字组合。

## Python 代码实现

### 方法一：枚举回文数（推荐）

```python
import math

class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        count = 0
        half_len = (n + 1) // 2  # 前半部分长度

        # 枚举前半部分
        start = 10 ** (half_len - 1)  # 最小的 half_len 位数（首位不为 0）
        end = 10 ** half_len          # 上界（不含）

        seen = set()  # 避免重复计数（同一组字符的不同回文）

        for half in range(start, end):
            half_str = str(half)
            # 构造完整回文串
            if n % 2 == 0:
                full_str = half_str + half_str[::-1]
            else:
                full_str = half_str + half_str[-2::-1]

            num = int(full_str)
            if num % k == 0:
                # 用排序后的字符串去重（避免统计重复的数字组合）
                key = ''.join(sorted(full_str))
                if key not in seen:
                    seen.add(key)
                    # 计算这组数字能组成多少个合法回文数
                    # 实际上每个回文数是唯一的，不需要去重
                    count += 1

        # 注意：上面的 seen 去重是错误的，每个回文数本身是唯一的
        # 直接统计即可
        return count
```

### 方法二：直接枚举（正确版本）

```python
import math

class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        count = 0
        half_len = (n + 1) // 2

        start = 10 ** (half_len - 1)
        end = 10 ** half_len

        for half in range(start, end):
            half_str = str(half)
            # 根据奇偶性构造回文
            if n % 2 == 0:
                full_str = half_str + half_str[::-1]
            else:
                # 奇数长度：中间字符不重复
                full_str = half_str + half_str[-2::-1]

            num = int(full_str)
            if num % k == 0:
                count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(10^(n/2))，枚举前半部分的所有可能
- 空间复杂度：O(n)，存储字符串

## 关键点总结

1. n 位回文数由前 `ceil(n/2)` 位唯一确定
2. 奇数长度回文：`half + half[-2::-1]`；偶数长度：`half + half[::-1]`
3. 首位不能为 0，因此前半部分从 `10^(half_len-1)` 开始枚举

## 易错点

1. 奇数和偶数长度的回文构造方式不同
2. n=1 时 `half_len=1`，`half[-2::-1]` 为空串，只取 `half` 本身
