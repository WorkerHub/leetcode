## 题目描述

给你一个二维数组 `events`，其中 `events[i] = [index, time]` 表示第 `i` 次按下按钮 `index`，时间为 `time`。

计算每个按钮被按住的总时间。两次相邻按键之间的时间差就是第一次按键的"按住时间"。

返回**按住时间最长**的按钮 `index`。若有多个相同，返回 `index` 最小的。

**提示：**
- `events[i] = [index, time]`，events 已按时间排序
- 第一次按键时间（从 0 开始算）就是 events[0][1] - 0（假设从 0 开始）

## 解题思路

遍历相邻事件，计算每个按键的按住时间（相邻时间差），找最大值。

第一次按键的按住时间 = `events[0][1]`（从 0 到第一次时间戳）。
后续按键 `i` 的按住时间 = `events[i][1] - events[i-1][1]`。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def buttonWithLongestTime(self, events: List[List[int]]) -> int:
        best_time = 0
        best_index = -1
        
        prev_time = 0  # 上一次事件的时间
        
        for index, time in events:
            duration = time - prev_time
            if duration > best_time or (duration == best_time and index < best_index):
                best_time = duration
                best_index = index
            prev_time = time
        
        return best_index
```

### 方法二：enumerate 版本

```python
from typing import List

class Solution:
    def buttonWithLongestTime(self, events: List[List[int]]) -> int:
        # 第一次按键从时间 0 开始
        times = []
        prev = 0
        for idx, t in events:
            times.append((t - prev, idx))
            prev = t
        
        # 找最大持续时间（相同时取 index 最小）
        best = max(times, key=lambda x: (x[0], -x[1]))
        return best[1]
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每次按键的持续时间 = 当前时间 - 上次时间（第一次为 time - 0）。
2. 找持续时间最长的按键，相同时取 index 最小。
3. 保持前一次时间戳 `prev_time` 即可，不需要额外空间。

## 易错点

1. 第一次按键从时间 0 开始，持续时间 = `events[0][1]`。
2. 相同持续时间取 index 最小（不是取最后一个）。
3. 按 `(持续时间降序, index 升序)` 找最优。
