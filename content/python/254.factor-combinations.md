## 题目描述

数字可以被视为其因子的乘积。例如：

```
8 = 2 × 2 × 2
  = 2 × 4
```

编写一个函数，返回整数 n 的所有可能的因子组合。

**注意：**
1. 每个组合的因子必须按升序排列
2. 答案中不应包含单独的 n
3. 你可以以任何顺序返回答案

**示例 1：**

```
输入：n = 1
输出：[]
```

**示例 2：**

```
输入：n = 12
输出：[[2,6],[3,4],[2,2,3]]
解释：
12 = 2 × 6
   = 3 × 4
   = 2 × 2 × 3
```

**示例 3：**

```
输入：n = 37
输出：[]
解释：37 是质数
```

**提示：**
- `1 <= n <= 10^7`

## 解题思路

这是一道经典的回溯问题，需要找出所有因子的组合。

核心思想：
1. 从最小因子 2 开始尝试
2. 如果 i 是 n 的因子，有两个选择：
   - 选择 i，继续对 n/i 进行分解
   - 不选择 i，尝试下一个更大的因子
3. 递归终止条件：n 变为 1 或找不到因子

关键点：
- 避免重复：通过传递起始因子确保因子升序
- 剪枝：只需要搜索到 sqrt(n)，因为更大的因子会在递归中自然出现
- 边界：不包含 n 本身作为单独的因子组合

## Python 代码实现

### 方法一：回溯（推荐）⭐

```python
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        """
        回溯法找出所有因子组合
        时间复杂度：O(2^log n)
        空间复杂度：O(log n)
        """
        result = []
        
        def backtrack(num: int, start: int, path: List[int]):
            """
            num: 当前需要分解的数
            start: 起始因子，确保因子升序
            path: 当前的因子组合
            """
            # 如果 path 不为空，说明已经有因子了
            # 此时 num 可以作为最后一个因子
            if path:
                # 将当前组合加入结果（包含 num 作为最后一个因子）
                result.append(path + [num])
            
            # 尝试从 start 到 sqrt(num) 的所有因子
            # 只需要搜索到 sqrt(num)，因为更大的因子会作为 num//i 出现
            i = start
            while i * i <= num:
                if num % i == 0:
                    # i 是因子，递归分解 num//i
                    backtrack(num // i, i, path + [i])
                i += 1
        
        backtrack(n, 2, [])
        return result
```

### 方法二：回溯 + 优化（更清晰的版本）

```python
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        """
        回溯法的另一种写法，逻辑更清晰
        """
        if n <= 1:
            return []
        
        result = []
        
        def backtrack(num: int, start: int, path: List[int]):
            # 终止条件：num 为 1，说明已经完全分解
            if num == 1:
                # 只有当 path 长度 >= 2 时才是有效组合
                # 排除 n 本身作为单独因子
                if len(path) > 1:
                    result.append(path[:])
                return
            
            # 尝试所有可能的因子
            for i in range(start, int(num ** 0.5) + 1):
                if num % i == 0:
                    # 选择 i 作为因子
                    path.append(i)
                    backtrack(num // i, i, path)
                    path.pop()
            
            # 将 num 本身作为最后一个因子
            # 只有当 path 不为空时才添加（确保不是只有 n 本身）
            if path:
                path.append(num)
                result.append(path[:])
                path.pop()
        
        backtrack(n, 2, [])
        return result
```

### 方法三：迭代 + 记忆化

```python
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        """
        使用记忆化避免重复计算
        """
        memo = {}
        
        def helper(num: int, start: int) -> List[List[int]]:
            # 检查缓存
            if (num, start) in memo:
                return memo[(num, start)]
            
            result = []
            
            # 尝试所有因子
            i = start
            while i * i <= num:
                if num % i == 0:
                    quotient = num // i
                    # 添加 [i, quotient] 这个组合
                    result.append([i, quotient])
                    
                    # 递归分解 quotient
                    for sub in helper(quotient, i):
                        result.append([i] + sub)
                i += 1
            
            memo[(num, start)] = result
            return result
        
        return helper(n, 2)
```

### 方法四：暴力递归（用于理解）

```python
from typing import List

class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        """
        简单递归，更容易理解
        """
        result = []
        
        def dfs(num: int, start: int, path: List[int]):
            # 遍历所有可能的因子
            for i in range(start, num):
                if num % i == 0:
                    # 找到因子 i
                    quotient = num // i
                    
                    if quotient >= i:  # 确保因子升序
                        # 直接添加 [i, quotient]
                        result.append(path + [i, quotient])
                        
                        # 继续分解 quotient
                        dfs(quotient, i, path + [i])
        
        dfs(n, 2, [])
        return result
```

## 复杂度分析

**方法一（回溯）：**
- 时间复杂度：O(2^log n)，最坏情况下有指数级的组合
- 空间复杂度：O(log n)，递归栈的深度

**方法三（记忆化）：**
- 时间复杂度：O(n^(3/2))，带记忆化后避免重复计算
- 空间复杂度：O(n log n)，存储中间结果

## 图解示例

以 `n = 12` 为例：

```
                    12
                   /  \
                  /    \
              2×6      3×4
             /   \      |
            /     \     |
        2×2×3    2×6   3×4
        
搜索树：
start=2, num=12
├─ i=2: 12%2==0 → 分解 6
│  └─ start=2, num=6
│     ├─ i=2: 6%2==0 → 分解 3
│     │  └─ start=2, num=3 → [2,2,3] ✓
│     └─ i=3: 超过sqrt(6) → [2,6] ✓
│
└─ i=3: 12%3==0 → 分解 4
   └─ start=3, num=4
      └─ 没有>=3的因子 → [3,4] ✓

结果：[[2,6], [2,2,3], [3,4]]
```

## 关键点总结

1. **回溯模板**：选择因子 → 递归分解 → 撤销选择
2. **剪枝优化**：只搜索到 sqrt(n)，避免重复
3. **升序保证**：通过 start 参数确保因子升序排列
4. **终止条件**：num 为 1 或找不到因子时终止
5. **边界处理**：排除 n 本身作为单独的因子组合

## 易错点

1. **忘记排除 n 本身**
   ```python
   # 错误：会包含 [12] 这样的结果
   result.append(path + [num])
   
   # 正确：只有当 path 不为空时才添加
   if path:
       result.append(path + [num])
   ```

2. **搜索范围错误**
   ```python
   # 低效：搜索到 num-1
   for i in range(start, num):
   
   # 高效：只搜索到 sqrt(num)
   while i * i <= num:
   ```

3. **重复组合**
   ```python
   # 错误：可能产生 [2,3] 和 [3,2] 这样的重复
   backtrack(num // i, 2, path + [i])
   
   # 正确：从 i 开始，确保升序
   backtrack(num // i, i, path + [i])
   ```

4. **边界条件**
   ```python
   # 记得处理 n=1 的情况
   if n <= 1:
       return []
   ```
