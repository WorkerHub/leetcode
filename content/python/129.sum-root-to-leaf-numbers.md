## 题目描述

给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 `0` 到 `9` 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：

- 例如，从根节点到叶节点的路径 `1 -> 2 -> 3` 表示数字 `123`。

计算从根节点到叶节点生成的**所有数字之和**。

**叶节点**是指没有子节点的节点。

**示例 1：**
```
输入: root = [1,2,3]
    1
   / \
  2   3
输出: 25
解释:
从根到叶子节点路径 1->2 代表数字 12
从根到叶子节点路径 1->3 代表数字 13
因此，数字总和 = 12 + 13 = 25
```

**示例 2：**
```
输入: root = [4,9,0,5,1]
      4
     / \
    9   0
   / \
  5   1
输出: 1026
解释:
从根到叶子节点路径 4->9->5 代表数字 495
从根到叶子节点路径 4->9->1 代表数字 491
从根到叶子节点路径 4->0 代表数字 40
因此，数字总和 = 495 + 491 + 40 = 1026
```

**提示：**
- 树中节点的数目在范围 `[1, 1000]` 内
- `0 <= Node.val <= 9`
- 树的深度不超过 `10`

## 解题思路

这是一道典型的**二叉树路径问题**，核心是 **DFS（深度优先搜索）**。

### 核心思想：

1. **DFS 遍历所有路径**：从根节点到每个叶子节点
2. **累加路径数字**：每向下一层，当前数字 = 上层数字 × 10 + 当前节点值
3. **叶子节点处理**：到达叶子节点时，将当前数字加入总和

### 算法步骤：

1. 定义递归函数 `dfs(node, current_num)`
2. 如果是叶子节点，返回当前累积的数字
3. 如果不是叶子节点，递归左右子树，累加结果
4. 每次递归时，更新当前数字：`current_num = current_num * 10 + node.val`

### 示例演示：

```
输入: [1,2,3]
    1
   / \
  2   3

路径1: 1 -> 2
  第1层: current = 0 * 10 + 1 = 1
  第2层: current = 1 * 10 + 2 = 12 (叶子节点)

路径2: 1 -> 3
  第1层: current = 0 * 10 + 1 = 1
  第2层: current = 1 * 10 + 3 = 13 (叶子节点)

总和: 12 + 13 = 25
```

## Python 代码实现

### 方法一：递归 DFS（推荐）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], current_num: int) -> int:
            if not node:
                return 0
            
            # 更新当前路径的数字
            current_num = current_num * 10 + node.val
            
            # 叶子节点：返回当前数字
            if not node.left and not node.right:
                return current_num
            
            # 非叶子节点：递归左右子树，累加结果
            left_sum = dfs(node.left, current_num)
            right_sum = dfs(node.right, current_num)
            
            return left_sum + right_sum
        
        return dfs(root, 0)
```

### 方法二：迭代 DFS（使用栈）

```python
from typing import Optional

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        total_sum = 0
        # 栈中存储 (节点, 当前路径数字)
        stack = [(root, root.val)]
        
        while stack:
            node, current_num = stack.pop()
            
            # 叶子节点
            if not node.left and not node.right:
                total_sum += current_num
            
            # 右子树（后进先出，所以先压入右子树）
            if node.right:
                stack.append((node.right, current_num * 10 + node.right.val))
            
            # 左子树
            if node.left:
                stack.append((node.left, current_num * 10 + node.left.val))
        
        return total_sum
```

### 方法三：BFS（使用队列）

```python
from typing import Optional
from collections import deque

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        total_sum = 0
        # 队列中存储 (节点, 当前路径数字)
        queue = deque([(root, root.val)])
        
        while queue:
            node, current_num = queue.popleft()
            
            # 叶子节点
            if not node.left and not node.right:
                total_sum += current_num
            
            # 左子树
            if node.left:
                queue.append((node.left, current_num * 10 + node.left.val))
            
            # 右子树
            if node.right:
                queue.append((node.right, current_num * 10 + node.right.val))
        
        return total_sum
```

### 方法四：简洁递归版

```python
from typing import Optional

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        def dfs(node, num):
            if not node:
                return 0
            
            num = num * 10 + node.val
            
            # 叶子节点
            if not node.left and not node.right:
                return num
            
            return dfs(node.left, num) + dfs(node.right, num)
        
        return dfs(root, 0)
```

### 方法五：全局变量版（不推荐）

```python
from typing import Optional

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        self.total = 0
        
        def dfs(node, current_num):
            if not node:
                return
            
            current_num = current_num * 10 + node.val
            
            # 叶子节点
            if not node.left and not node.right:
                self.total += current_num
                return
            
            dfs(node.left, current_num)
            dfs(node.right, current_num)

        return self.total
```

## 复杂度分析

设树的节点数为 n。

### 方法一：递归 DFS
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 是树的高度
  - 最好情况（平衡树）：O(log n)
  - 最坏情况（链状树）：O(n)

### 方法二/三：迭代 DFS/BFS
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈/队列最多存储所有节点

## 关键点总结

1. **数字构造方式**：`current_num = current_num * 10 + node.val`
2. **叶子节点判断**：`not node.left and not node.right`
3. **累加时机**：只在叶子节点累加，非叶子节点继续递归
4. **初始值传递**：从根节点开始，初始值为 0
5. **递归返回值**：返回左右子树的和

## 易错点

1. **非叶子节点也累加**
   ```python
   # 错误：所有节点都累加
   total_sum += current_num
   
   # 正确：只在叶子节点累加
   if not node.left and not node.right:
       total_sum += current_num
   ```

2. **数字构造错误**
   ```python
   # 错误：数字拼接方式错误
   current_num = current_num + node.val
   
   # 正确：每下一层乘以 10
   current_num = current_num * 10 + node.val
   ```

3. **空节点处理**
   ```python
   # 必须处理空节点
   if not node:
       return 0
   ```

4. **初始值错误**
   ```python
   # 错误：初始值为 node.val
   dfs(root, root.val)
   
   # 正确：初始值为 0，在函数内计算
   dfs(root, 0)
   ```

5. **只有根节点的情况**
   ```python
   # 根节点也是叶子节点，要正确处理
   if not node.left and not node.right:
       return current_num
   ```
