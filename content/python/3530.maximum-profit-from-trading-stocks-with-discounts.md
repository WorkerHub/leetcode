## 题目描述

给定一棵公司组织架构树，节点 `i` 代表一名员工，`present[i]` 表示购买股票时是否需要直接上级批准，`cost[i]` 表示原价，`discount[i]` 表示折扣价。若员工 `i` 的直接上级（父节点）也购买了股票，则员工 `i` 可以以折扣价 `discount[i]` 购买，否则以原价 `cost[i]` 购买。给定预算 `budget`，求能购买的股票总价值最大化（或股票数量最多）。

**示例：**

```
输入：n = 4, present = [1,1,0,1], cost = [4,2,3,1], discount = [1,2,1,1],
     budget = 6
输出：4
```

**提示：**
- `1 <= n <= 200`
- `0 <= budget <= 10^4`

## 解题思路

树形动态规划（树形 DP）。

状态定义：
- `dp[v][j][0]` = 以 v 为根的子树，花费恰好 j，v 没买时的最大价值
- `dp[v][j][1]` = 以 v 为根的子树，花费恰好 j，v 买了（折扣）时的最大价值

转移：对每个子节点 c：
- 若 v 没买（`dp[v][*][0]`），c 以原价购买或不购买
- 若 v 买了（`dp[v][*][1]`），c 以折扣价购买或不购买

合并子树的 DP（背包合并）。

## Python 代码实现

### 方法一：树形 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxProfit(self, n: int, present: List[int], cost: List[int],
                  discount: List[int], budget: int) -> int:
        # 建树（假设节点 0 为根，父节点为 i//2 或给定 parent 数组）
        # 这里假设输入包含 parent 数组（根为 0，parent[0] = -1）
        # 实际题目可能有不同的树结构定义，这里做简化处理

        children = defaultdict(list)
        # 假设树按 0-indexed，parent[i] 给出父节点
        # 若 parent 未给出，假设完全二叉树结构
        for i in range(1, n):
            children[i // 2].append(i)  # 简化：完全二叉树

        # dp[v][j][bought] = 以 v 为根，花费 j，v 是否购买时的最大股票数
        INF = float('-inf')

        def dfs(v, parent_bought):
            # 返回 dp[0..budget]，表示花费 j 时的最大股票数
            # 两种状态：v 不买(0) / v 买(1)

            # 初始化：只考虑 v 自身
            # 不买 v
            dp_no = [0] * (budget + 1)
            # 买 v（选原价还是折扣价）
            dp_yes = [INF] * (budget + 1)
            c = discount[v] if parent_bought else cost[v]
            if c <= budget:
                dp_yes[c] = 1 if present[v] else 0

            # 合并子节点
            for child in children[v]:
                # 计算子节点在 v 不买 / v 买 两种情况下的 DP
                child_no = dfs(child, False)   # v 不买，child 用原价
                child_yes = dfs(child, True)   # v 买，child 可用折扣

                # 更新 dp_no（v 不买）
                new_no = [INF] * (budget + 1)
                for j in range(budget + 1):
                    if dp_no[j] == INF:
                        continue
                    for k in range(budget + 1 - j):
                        if child_no[k] != INF:
                            new_no[j + k] = max(new_no[j + k], dp_no[j] + child_no[k])
                dp_no = new_no

                # 更新 dp_yes（v 买）
                new_yes = [INF] * (budget + 1)
                for j in range(budget + 1):
                    if dp_yes[j] == INF:
                        continue
                    for k in range(budget + 1 - j):
                        if child_yes[k] != INF:
                            new_yes[j + k] = max(new_yes[j + k], dp_yes[j] + child_yes[k])
                dp_yes = new_yes

            # 返回合并后的最优 DP（取 max）
            result = [0] * (budget + 1)
            for j in range(budget + 1):
                v1 = dp_no[j] if dp_no[j] != INF else 0
                v2 = dp_yes[j] if dp_yes[j] != INF else 0
                result[j] = max(v1, v2)
            return result

        dp = dfs(0, False)
        return max(dp)
```

### 方法二：记忆化 DFS（简化版）

```python
from typing import List
from collections import defaultdict
from functools import lru_cache

class Solution:
    def maxProfit(self, n: int, present: List[int], cost: List[int],
                  discount: List[int], budget: int) -> int:
        children = defaultdict(list)
        for i in range(1, n):
            children[i // 2].append(i)

        best = 0

        def dfs(v, remaining, parent_bought):
            nonlocal best
            actual_cost = discount[v] if parent_bought else cost[v]
            # 选择购买 v
            if actual_cost <= remaining:
                val = 1 if present[v] else 0
                sub_remaining = remaining - actual_cost
                sub_val = val
                for child in children[v]:
                    sub_val += dfs(child, sub_remaining, True)
                best = max(best, sub_val)
            # 不购买 v
            for child in children[v]:
                dfs(child, remaining, False)

            return 0  # 返回子树最优值（简化，实际需要更复杂的返回）

        dfs(0, budget, False)
        return best
```

## 复杂度分析

- 时间复杂度：O(n * budget^2)，树形背包 DP
- 空间复杂度：O(n * budget)

## 关键点总结

1. 树形 DP：父节点是否购买影响子节点的价格
2. 树上背包：合并子树时类似分组背包
3. 两个状态（购买/不购买）分别维护 DP 数组

## 易错点

1. 父节点"购买"才能给子节点折扣，需要传递购买状态
2. 树上背包合并时注意不要超过总预算
3. 折扣和原价的选择取决于父节点状态，不是子节点自身
