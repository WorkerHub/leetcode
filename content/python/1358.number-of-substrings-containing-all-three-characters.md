## 题目描述

给你一个字符串 `s`，它只包含三种字符 `a`、`b` 和 `c`。

请你返回 `a`、`b` 和 `c` 都**至少出现过一次**的子字符串数目。

**示例 1：**
```
输入：s = "abcabc"
输出：10
解释：包含 a、b 和 c 各至少一次的子字符串为：
"abc"、"abca"、"abcab"、"abcabc"、"bca"、"bcab"、"bcabc"、"cab"、"cabc"、"abc"(最后一个)
共 10 个。
```

**示例 2：**
```
输入：s = "aaacb"
输出：3
解释：包含三种字符的子字符串为：
"aaacb"、"aacb"、"acb"，共 3 个。
```

**示例 3：**
```
输入：s = "abc"
输出：1
```

**提示：**
- `3 <= s.length <= 5 * 10^4`
- `s` 只包含字符 `a`、`b` 和 `c`。

## 解题思路

**关键观察：** 如果子字符串 `s[left:right+1]` 包含了 a、b、c 各至少一次，那么 `s[left:right+1]`、`s[left:right+2]`、……、`s[left:n]`（即扩展右边界的所有子串）也都满足条件。

这意味着对于每个左端点 `left`，找到最短的满足条件的子串 `s[left:min_right+1]`，那么以 `left` 为起点的合法子串共有 `n - min_right` 个。

**滑动窗口算法：**
1. 维护右指针 `r` 和一个字符计数字典 `cnt`。
2. 对每个左端点 `l`（从 0 到 n-1）：
   - 不断移动右指针直到窗口中 a、b、c 都有（或 `r` 越界）。
   - 此时以 `l` 开头的合法子串数 = `n - r`（`r` 是最短满足窗口的右端点+1）。
   - 移动左指针（将 `s[l]` 从窗口中移除）。

另一种等价写法：对每个右端点 `r`，找最短满足的左端点 `min_l`，合法子串数 = `min_l + 1`。

## Python 代码实现

### 方法一：滑动窗口（左端点枚举，推荐）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        count = {'a': 0, 'b': 0, 'c': 0}  # 当前窗口内各字符的计数
        ans = 0
        r = 0  # 右指针（窗口 [l, r) 中 r 为下一个待加入的位置）
        
        for l in range(n):
            # 扩展右边界直到窗口包含 a, b, c 各至少一次
            while r < n and not (count['a'] and count['b'] and count['c']):
                count[s[r]] += 1
                r += 1
            
            # 如果当前窗口 [l, r-1] 包含三种字符
            # 则以 l 为左端点，右端点为 r-1, r, r+1, ..., n-1 的子串都合法
            # 共 n - (r-1) = n - r + 1 个... 不对
            # 窗口是 [l, r-1]，右端点最小是 r-1，最大是 n-1
            # 合法子串数 = (n-1) - (r-1) + 1 = n - r + 1
            if count['a'] and count['b'] and count['c']:
                ans += n - r + 1
            
            # 移动左指针：将 s[l] 移出窗口
            count[s[l]] -= 1
        
        return ans
```

### 方法二：滑动窗口（右端点枚举，更直观）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        # last[c] 表示字符 c 最后一次出现的位置（-1 表示未出现）
        last = {'a': -1, 'b': -1, 'c': -1}
        ans = 0
        
        for r in range(n):
            # 更新当前字符的最后位置
            last[s[r]] = r
            
            # 以 r 结尾的合法子串的左端点范围：
            # 左端点必须 <= min(last['a'], last['b'], last['c'])
            # 这样才能保证窗口内包含 a, b, c 各至少一次
            # 合法左端点有 min_last + 1 个（从 0 到 min_last）
            min_last = min(last['a'], last['b'], last['c'])
            
            if min_last >= 0:  # 三种字符都出现过
                ans += min_last + 1
        
        return ans
```

**方法二解释：**

对于右端点 `r`，设 `last['a']`、`last['b']`、`last['c']` 分别是 a、b、c 在 `s[0:r+1]` 中最后一次出现的位置。

令 `min_last = min(last['a'], last['b'], last['c'])`。

子串 `s[l:r+1]` 包含三种字符当且仅当 `l <= min_last`（因为 l 必须不超过最后一次出现的最小位置，才能确保三种字符都在 `[l, r]` 中）。

所以以 `r` 结尾的合法子串个数 = `min_last + 1`（左端点可以是 0, 1, ..., min_last）。

### 方法三：暴力解法（理解用，效率低）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        ans = 0
        
        for l in range(n):
            cnt = {'a': 0, 'b': 0, 'c': 0}
            for r in range(l, n):
                cnt[s[r]] += 1
                # 三种字符都出现过
                if cnt['a'] > 0 and cnt['b'] > 0 and cnt['c'] > 0:
                    # [l, r] 合法，且 [l, r], [l, r+1], ..., [l, n-1] 都合法
                    ans += n - r
                    break  # 已经找到最短合法右端点，后续更长的都计入了
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（滑动窗口，左端点枚举） | O(N) | O(1) |
| 方法二（右端点枚举） | O(N) | O(1) |
| 方法三（暴力+剪枝） | O(N^2) 最坏 | O(1) |

## 关键点总结

1. **右端点枚举法**（方法二）是本题最优雅的解法，利用"三种字符最后出现位置的最小值"直接计算合法子串数。
2. 对于右端点 `r`，合法左端点个数 = `min(last_a, last_b, last_c) + 1`。
3. **滑动窗口左端点枚举法**（方法一）更通用，适合处理"至少包含某些元素"的子字符串问题。
4. 两种 O(N) 方法的核心思想相同：利用单调性计数而非逐个枚举。

## 易错点

- 方法一中合法子串数的计算：窗口 `[l, r-1]` 合法时，以 `l` 为左端点、右端点从 `r-1` 到 `n-1` 都合法，共 `n - r + 1` 个（注意 `r` 在循环中已经多加 1）。
- 方法二中 `min_last` 可能为 -1（某种字符尚未出现），此时不应加任何计数，用 `if min_last >= 0` 过滤。
- 暴力方法中的剪枝：找到最短合法右端点后 `break`，后续更长的子串已通过 `n - r` 计入，不需再枚举。
