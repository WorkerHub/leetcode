## 题目描述

给你一个由**正整数**组成的数组 `nums`。

返回数组中**严格递增**子数组的数目。

**注意：** 长度为 **1** 的子数组也视为严格递增。

**示例 1：**
```
输入：nums = [1,3,5,4,4,6]
输出：10
解释：严格递增子数组：[1],[3],[5],[4],[4],[6],[1,3],[3,5],[1,3,5],[4,6]
长度 1 的有 6 个，长度 2 的有 3 个，长度 3 的有 1 个，共 10 个
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：15
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**动态规划 / 数学规律：**

对于每个位置 `i`，设 `dp[i]` 为以 `nums[i]` 结尾的严格递增子数组数量：
- 若 `nums[i] > nums[i-1]`，则 `dp[i] = dp[i-1] + 1`（可以在所有以 `nums[i-1]` 结尾的子数组后追加 `nums[i]`，再加上 `[nums[i]]` 自身）。
- 否则 `dp[i] = 1`（只有自身）。

答案 = `sum(dp)`。

**数学解释：** 若某段连续严格递增子数组长度为 `L`，则该段贡献的子数组数为 `L*(L+1)//2`。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        cur = 1  # 以当前元素结尾的严格递增子数组数量
        
        for i in range(n):
            if i > 0 and nums[i] > nums[i - 1]:
                cur += 1  # 可以追加到前一个连续递增段
            else:
                cur = 1   # 重新开始（只有自身）
            total += cur
        
        return total
```

### 方法二：按连续段计算

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        total = 0
        length = 1  # 当前连续严格递增段的长度
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                length += 1
            else:
                # 当前段结束，贡献 length*(length+1)//2 个子数组
                total += length * (length + 1) // 2
                length = 1
        
        # 最后一段
        total += length * (length + 1) // 2
        
        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n) | O(1) |
| 按段计算 | O(n) | O(1) |

## 关键点总结

1. 以每个位置结尾的严格递增子数组数 = 当前连续递增段长度。
2. 动态规划：`cur = cur + 1`（若递增）或 `cur = 1`（否则）。
3. 一段长度为 `L` 的连续递增子数组共有 `L*(L+1)//2` 个子数组。

## 易错点

- 长度为 1 的子数组也算，初始 `cur = 1`，不能忘记每个元素自身。
- 按段计算时，最后一段不能忘记处理（循环结束后还需加上最后一段的贡献）。
