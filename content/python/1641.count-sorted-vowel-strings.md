## 题目描述

给你一个整数 `n`，请返回长度为 `n`、仅由元音（`a`、`e`、`i`、`o`、`u`）组成且按**字典序非递减顺序**排列的字符串数目。

字典序非递减：每个字符串中，后面的字符不小于前面的字符。例如 `"aeeiu"` 合法，`"uae"` 不合法。

**示例：**
```
输入：n = 1
输出：5（a, e, i, o, u）

输入：n = 2
输出：15（aa, ae, ai, ao, au, ee, ei, eo, eu, ii, io, iu, oo, ou, uu）
```

## 解题思路

**数学方法（组合数）：** 从 5 个元音中选 n 个（允许重复，有序不递减），等价于**隔板法**：从 `5 + n - 1 = n + 4` 个元素中选 `n` 个，即 `C(n+4, 4)`。

**DP 方法：** `dp[i][j]` = 长度为 i，以第 j 个元音（0-based）结尾的串数。

## 代码实现

### 方法一：组合数公式（推荐）

```python
import math

class Solution:
    def countVowelStrings(self, n: int) -> int:
        # 等价于 C(n+4, 4)
        return math.comb(n + 4, 4)
```

### 方法二：动态规划

```python
class Solution:
    def countVowelStrings(self, n: int) -> int:
        # dp[j] = 当前长度下以第 j 个元音结尾的字符串数
        # 元音：a(0), e(1), i(2), o(3), u(4)
        dp = [1] * 5  # 初始：长度为 1，每个元音各 1 种
        
        for _ in range(n - 1):
            # 长度加 1：以第 j 个元音结尾的串数 = 所有 <= j 的元音的上一轮总和
            new_dp = [0] * 5
            for j in range(5):
                new_dp[j] = sum(dp[:j+1])
            dp = new_dp
        
        return sum(dp)
```

### 方法三：DP 前缀和优化

```python
class Solution:
    def countVowelStrings(self, n: int) -> int:
        # 初始：dp[j] = 1（每个元音各 1 种）
        dp = [1] * 5
        
        for _ in range(n - 1):
            # 用前缀和计算：dp[j] = sum(dp[0..j])
            for j in range(1, 5):
                dp[j] += dp[j-1]
        
        return sum(dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 组合数 | O(1) | O(1) |
| DP | O(5n) = O(n) | O(5) = O(1) |

## 关键点总结

1. 数学本质：有重复的非递减选择 = 隔板法 = `C(n+4, 4)`
2. DP 方法：每次用前缀和更新，以第 j 个元音结尾的串 = 以 <= j 的元音结尾的所有串之和
3. Python `math.comb(n+4, 4)` 直接计算，最简洁

## 易错点

- `math.comb(n+4, 4)` 而不是 `C(n, 4)`（隔板法公式）
- DP 方法中前缀和更新方向必须是从小到大（`j=0` 到 `j=4`）
