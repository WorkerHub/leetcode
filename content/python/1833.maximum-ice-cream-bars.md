## 题目描述

夏日炎炎，小男孩 Tony 想要尽可能多地买冰淇淋。

给你价格数组 `costs`（`costs[i]` 是第 i 支冰淇淋的价格）和零花钱 `coins`。Tony 以任意顺序购买冰淇淋。

返回 Tony 用 `coins` 能买到的最多冰淇淋数目。

**示例 1：**
```
输入：costs = [1,3,2,4,1], coins = 7
输出：4
解释：依次购买价格为 1,1,2,3 的冰淇淋，总花费 7
```

**示例 2：**
```
输入：costs = [10,6,8,7,7,8], coins = 5
输出：0
```

**提示：**
- `costs.length <= 10^5`
- `1 <= costs[i] <= 10^5`
- `1 <= coins <= 10^8`

## 解题思路

**贪心**：优先买价格最低的冰淇淋，能买最多支。将 costs 排序，从最小价格开始累加，直到零花钱不足。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def maxIceCream(self, costs: List[int], coins: int) -> int:
        costs.sort()  # 按价格升序排列
        count = 0
        for cost in costs:
            if coins >= cost:
                coins -= cost
                count += 1
            else:
                break  # 后续价格更贵，不需要继续
        return count
```

### 方法二：计数排序（价格范围小时更快）

```python
from typing import List

class Solution:
    def maxIceCream(self, costs: List[int], coins: int) -> int:
        # 价格范围为 1 到 10^5，用计数排序
        max_cost = max(costs)
        freq = [0] * (max_cost + 1)
        for c in costs:
            freq[c] += 1

        count = 0
        for price in range(1, max_cost + 1):
            if freq[price] == 0 or coins < price:
                continue
            # 能买 min(freq[price], coins // price) 支
            buy = min(freq[price], coins // price)
            count += buy
            coins -= buy * price
            if coins == 0:
                break
        return count
```

## 复杂度分析

- **方法一（排序贪心）**：
  - 时间复杂度：O(n log n)
  - 空间复杂度：O(1)（原地排序）
- **方法二（计数排序）**：
  - 时间复杂度：O(n + max_cost)
  - 空间复杂度：O(max_cost)

## 关键点总结

1. 贪心策略：优先买最便宜的，总能买到最多支
2. 计数排序在价格范围有界时比比较排序更快
3. 对每个价格，可以批量购买同价格的多支冰淇淋

## 易错点

- 方法一中排序后遇到不够钱的就可以 break（后续更贵）
- 方法二中计算能买的数量：`min(freq[price], coins // price)`，避免超出预算
