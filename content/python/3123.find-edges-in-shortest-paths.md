## 题目描述

给你一个 `n` 个顶点的无向加权图，顶点编号 0 到 n-1，以及边数组 `edges`，`edges[i] = [ai, bi, wi]`。

如果存在从顶点 0 到顶点 n-1 的最短路径经过边 `edges[i]`，则称边 `edges[i]` 在最短路径上。

返回大小为 `m` 的布尔数组 `answer`，`answer[i]` 表示第 `i` 条边是否在某条最短路径上。

**提示：**
- `2 <= n <= 5 * 10^4`
- `m == edges.length`
- `1 <= m <= 10^5`

## 解题思路

1. 从顶点 0 跑 Dijkstra，得到 `dist0[v]` = 0 到 v 的最短距离
2. 从顶点 n-1 跑 Dijkstra，得到 `dist_n[v]` = n-1 到 v 的最短距离
3. 边 `(u, v, w)` 在最短路上当且仅当：
   - `dist0[u] + w + dist_n[v] == dist0[n-1]` 或
   - `dist0[v] + w + dist_n[u] == dist0[n-1]`

## Python 代码实现

### 方法一：双向 Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def findAnswer(self, n: int, edges: List[List[int]]) -> List[bool]:
        # 建图
        graph = defaultdict(list)
        for i, (u, v, w) in enumerate(edges):
            graph[u].append((v, w, i))
            graph[v].append((u, w, i))

        def dijkstra(src: int) -> List[int]:
            dist = [float('inf')] * n
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w, _ in graph[u]:
                    nd = d + w
                    if nd < dist[v]:
                        dist[v] = nd
                        heapq.heappush(heap, (nd, v))
            return dist

        dist0 = dijkstra(0)
        dist_end = dijkstra(n - 1)
        total = dist0[n - 1]

        if total == float('inf'):
            return [False] * len(edges)

        ans = []
        for u, v, w in edges:
            # 判断该边是否在某条最短路上
            on_path = (
                dist0[u] + w + dist_end[v] == total or
                dist0[v] + w + dist_end[u] == total
            )
            ans.append(on_path)
        return ans
```

### 方法二：带边索引的 Dijkstra

```python
from typing import List
import heapq

class Solution:
    def findAnswer(self, n: int, edges: List[List[int]]) -> List[bool]:
        adj = [[] for _ in range(n)]
        for i, (u, v, w) in enumerate(edges):
            adj[u].append((v, w))
            adj[v].append((u, w))

        INF = float('inf')

        def dijkstra(src):
            d = [INF] * n
            d[src] = 0
            pq = [(0, src)]
            while pq:
                dd, u = heapq.heappop(pq)
                if dd > d[u]:
                    continue
                for v, w in adj[u]:
                    if d[u] + w < d[v]:
                        d[v] = d[u] + w
                        heapq.heappush(pq, (d[v], v))
            return d

        d0 = dijkstra(0)
        dn = dijkstra(n - 1)
        total = d0[n - 1]

        return [
            d0[u] + w + dn[v] == total or d0[v] + w + dn[u] == total
            for u, v, w in edges
        ]
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，两次 Dijkstra
- 空间复杂度：O(n + m)

## 关键点总结

1. 从两端各跑一次 Dijkstra
2. 边 (u,v,w) 在最短路上的充要条件：`dist0[u] + w + dist_n[v] == total` 或反向
3. 若 0 到 n-1 不可达，所有边都不在最短路上

## 易错点

1. 无向图需要两个方向都判断
2. 0 到 n-1 不可达时需要特殊处理
