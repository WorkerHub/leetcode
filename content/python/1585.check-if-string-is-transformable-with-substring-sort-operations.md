## 题目描述

给你两个字符串 `s` 和 `t`，都由数字 `'1'` 到 `'9'` 组成。

每次操作可以选取 `s` 的任意**非空子串**并将其排序（非递减顺序）。

判断能否通过若干次操作将 `s` 变为 `t`。

**示例 1：**
```
输入：s = "84532", t = "34852"
输出：true
```

**提示：**
- `1 <= s.length, t.length <= 10^5`
- `s` 和 `t` 只包含 '1'-'9'

## 解题思路

### 贪心：模拟排序的等价条件

每次对子串排序等价于可以将字符向**左**移动（因为排序会把小的数字移到前面）。

但不能把大数字移到小数字前面（排序只能把小的移前）。

**结论：** `s` 可以变为 `t` 当且仅当：
- 两者字符集相同（各字符出现次数相同）
- 对 `t` 中每个位置的字符 `d = t[i]`，在 `s` 中找到该字符的第一次出现位置，其前面不应有任何比 `d` **小**的字符（因为那些小字符无法被"排到 d 后面"去）

用队列（deque）维护每个数字 0-9 在 `s` 中的位置，贪心地逐字符匹配。

## 代码实现

### 方法一：贪心 + 队列（推荐）

```python
from collections import deque

class Solution:
    def isTransformable(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        # 记录 s 中每个数字的位置（按顺序）
        pos = [deque() for _ in range(10)]
        for i, c in enumerate(s):
            pos[int(c)].append(i)

        for c in t:
            d = int(c)
            # 如果 s 中没有 d，不可能转换
            if not pos[d]:
                return False
            # 找 s 中第一个 d 的位置
            idx = pos[d][0]
            # 检查该位置前是否有比 d 小的数字（不能被移过去）
            for smaller in range(d):
                if pos[smaller] and pos[smaller][0] < idx:
                    return False
            # 匹配成功，弹出该 d
            pos[d].popleft()

        return True
```

### 方法二：优化（减少内层循环）

```python
from collections import deque

class Solution:
    def isTransformable(self, s: str, t: str) -> bool:
        pos = [deque() for _ in range(10)]
        for i, c in enumerate(s):
            pos[int(c)].append(i)

        for c in t:
            d = int(c)
            if not pos[d]:
                return False
            idx = pos[d][0]
            # 若 s 中 d 之前有更小的数字，无法将 d 移到该位置
            for j in range(d):
                if pos[j] and pos[j][0] < idx:
                    return False
            pos[d].popleft()

        return True
```

## 复杂度分析

- **时间复杂度**：O(N * 9) = O(N)，N = len(t)
- **空间复杂度**：O(N)

## 关键点总结

1. 子串排序 = 可以把小数字向左移（不能把大数字向右移）
2. 匹配 `t[i]` 时，在 `s` 中找到该字符，其左边不能有更小的字符
3. 用队列按顺序弹出已匹配的字符

## 易错点

- 排序子串后，小数字会移到前面，大数字不会被推到小数字之前
- 内层检查 `smaller < d`（不包括 d 本身）
