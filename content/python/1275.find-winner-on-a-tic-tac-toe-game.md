## 题目描述

A 和 B 在一个 3 x 3 的棋盘上玩井字棋（Tic-Tac-Toe）。

- A 总是先手，B 总是后手
- 棋盘上每一格都可以放一个棋子
- 第一个在横向、纵向或对角线方向连成三个棋子的玩家获胜
- 如果所有格子都被填满，则平局

给你一个数组 `moves`，其中 `moves[i] = [rowi, coli]` 表示第 i 步棋落在第 rowi 行、第 coli 列（从 0 开始编号），奇数步（0, 2, 4, ...）是 A 下的，偶数步（1, 3, 5, ...）是 B 下的（注意第 0 步是 A 的第 1 步）。

返回游戏结果：
- 若 **A 赢**，返回 `"A"`
- 若 **B 赢**，返回 `"B"`
- 若 **平局**（棋盘已满），返回 `"Draw"`
- 若 **游戏未结束**（棋盘未满且无人获胜），返回 `"Pending"`

**示例 1：**
```
输入：moves = [[0,0],[2,0],[1,1],[2,1],[2,2]]
输出："A"
解释：
A 下了 (0,0), (1,1), (2,2)，对角线连成三个，A 赢
```

**示例 2：**
```
输入：moves = [[0,0],[1,1],[0,1],[0,2],[1,0],[2,0]]
输出："B"
```

**示例 3：**
```
输入：moves = [[0,0],[1,1],[2,0],[1,0],[1,2],[2,1],[0,1],[0,2],[2,2]]
输出："Draw"
```

**示例 4：**
```
输入：moves = [[0,0],[1,1]]
输出："Pending"
```

**提示：**
- `1 <= moves.length <= 9`
- `moves[i].length == 2`
- `0 <= moves[i][j] <= 2`
- 没有重复的下棋位置
- `moves` 遵循井字棋的规则

## 解题思路

**核心思想：** 模拟游戏，判断谁在哪条线上连成三子。

**胜利条件分析：**

3x3 的棋盘共有 8 条可能的连线：
- 3 行：row 0, row 1, row 2
- 3 列：col 0, col 1, col 2
- 2 条对角线：主对角线（左上到右下），副对角线（右上到左下）

**高效判断方法：** 用计数器记录每个玩家在每行、每列、每条对角线上的棋子数，当某个计数器达到 3 时，该玩家获胜。

**判断流程：**
```
1. 逐步模拟下棋（奇数索引是A，偶数索引是B）
2. 每下一步，更新对应行/列/对角线的计数
3. 如果某个计数器 == 3，当前玩家获胜
4. 所有棋都下完无人获胜 -> Draw
5. 棋没下完无人获胜 -> Pending
```

## Python 代码实现

### 方法一：计数器法（推荐）

```python
from typing import List

class Solution:
    def tictactoe(self, moves: List[List[int]]) -> str:
        # 用计数器记录每个玩家在各行、各列、两条对角线上的棋子数
        # +1 代表 A，-1 代表 B
        rows = [0] * 3     # 三行计数
        cols = [0] * 3     # 三列计数
        diag = 0           # 主对角线（左上到右下）计数
        anti_diag = 0      # 副对角线（右上到左下）计数

        for i, (r, c) in enumerate(moves):
            # A 下的步骤（偶数索引：0, 2, 4...），B 下的步骤（奇数索引：1, 3, 5...）
            player = 1 if i % 2 == 0 else -1  # A 用 +1，B 用 -1

            # 更新行和列计数
            rows[r] += player
            cols[c] += player

            # 更新主对角线（r == c 时在主对角线上）
            if r == c:
                diag += player

            # 更新副对角线（r + c == 2 时在副对角线上）
            if r + c == 2:
                anti_diag += player

            # 判断是否有人获胜（任意一行/列/对角线达到3或-3）
            if abs(rows[r]) == 3 or abs(cols[c]) == 3 or abs(diag) == 3 or abs(anti_diag) == 3:
                return "A" if player == 1 else "B"

        # 没有人获胜时，判断棋盘是否已满
        return "Draw" if len(moves) == 9 else "Pending"
```

### 方法二：模拟棋盘法（直观易懂）

```python
from typing import List

class Solution:
    def tictactoe(self, moves: List[List[int]]) -> str:
        # 创建 3x3 棋盘，0表示空，1表示A，2表示B
        board = [[0] * 3 for _ in range(3)]

        # 在棋盘上落子
        for i, (r, c) in enumerate(moves):
            board[r][c] = 1 if i % 2 == 0 else 2  # A=1, B=2

        def check_winner(player):
            """检查指定玩家是否获胜"""
            # 检查三行
            for r in range(3):
                if all(board[r][c] == player for c in range(3)):
                    return True
            # 检查三列
            for c in range(3):
                if all(board[r][c] == player for r in range(3)):
                    return True
            # 检查主对角线
            if all(board[i][i] == player for i in range(3)):
                return True
            # 检查副对角线
            if all(board[i][2 - i] == player for i in range(3)):
                return True
            return False

        # 检查A是否获胜
        if check_winner(1):
            return "A"
        # 检查B是否获胜
        if check_winner(2):
            return "B"
        # 判断平局或未结束
        return "Draw" if len(moves) == 9 else "Pending"
```

### 方法三：利用集合检查（Python 风格）

```python
from typing import List

class Solution:
    def tictactoe(self, moves: List[List[int]]) -> str:
        # 分别记录 A 和 B 的落子位置
        a_moves = set()  # A 的落子集合
        b_moves = set()  # B 的落子集合

        for i, move in enumerate(moves):
            if i % 2 == 0:
                a_moves.add(tuple(move))
            else:
                b_moves.add(tuple(move))

        # 定义所有获胜线路（8条）
        win_lines = [
            # 三行
            {(0,0), (0,1), (0,2)},
            {(1,0), (1,1), (1,2)},
            {(2,0), (2,1), (2,2)},
            # 三列
            {(0,0), (1,0), (2,0)},
            {(0,1), (1,1), (2,1)},
            {(0,2), (1,2), (2,2)},
            # 两条对角线
            {(0,0), (1,1), (2,2)},
            {(0,2), (1,1), (2,0)},
        ]

        # 检查 A 是否获胜
        for line in win_lines:
            if line.issubset(a_moves):
                return "A"

        # 检查 B 是否获胜
        for line in win_lines:
            if line.issubset(b_moves):
                return "B"

        return "Draw" if len(moves) == 9 else "Pending"
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 计数器法 | O(n)，n 最大为 9 | O(1) |
| 模拟棋盘法 | O(n) | O(1)，棋盘固定 3x3 |
| 集合法 | O(n) | O(n) |

由于棋盘固定为 3x3，n 最大为 9，所以实际上所有方法都是 O(1)。

## 关键点总结

1. **下棋顺序**：moves 数组索引为偶数（0,2,4...）的是 A 下的，奇数（1,3,5...）的是 B 下的
2. **胜利线路**：共 8 条线路（3行+3列+2对角线），任意一条被同一玩家占满即获胜
3. **对角线判断**：主对角线条件 `r == c`，副对角线条件 `r + c == 2`
4. **结果优先级**：先判断是否有人获胜，再判断平局/未结束
5. **平局与未结束**：moves 长度等于 9 则平局，否则未结束

## 易错点

1. **A 和 B 的下棋顺序**：A 是索引 0, 2, 4（偶数），B 是 1, 3, 5（奇数），不要搞反
2. **对角线位置**：副对角线是 (0,2), (1,1), (2,0)，条件是 `r + c == n-1`（n=3时为2）
3. **判断获胜时机**：每下一步就检查，不需要等棋盘下满
4. **Pending vs Draw**：moves.length < 9 且无人获胜是 Pending，= 9 且无人获胜是 Draw
5. **不需要记录整个棋盘**：方法一只需要计数器即可，空间更优
