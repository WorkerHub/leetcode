## 题目描述

给定两个单词 `word1` 和 `word2`，返回使得 `word1` 和 `word2` 相同所需的最小步数。

每步可以删除任意一个字符串中的一个字符。

**示例 1：**
```
输入：word1 = "sea", word2 = "eat"
输出：2
解释：第一步将 "sea" 变为 "ea"，第二步将 "eat" 变为 "ea"
```

**示例 2：**
```
输入：word1 = "leetcode", word2 = "etco"
输出：4
```

**提示：**
- `1 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 只包含小写英文字母

## 解题思路

本质是求最长公共子序列（LCS）。

最小删除步数 = len(word1) + len(word2) - 2 * LCS_length

## Python 代码实现

### 方法一：LCS（推荐）⭐

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        """
        转化为LCS问题
        
        时间复杂度：O(m * n)
        空间复杂度：O(m * n)
        """
        m, n = len(word1), len(word2)
        
        # dp[i][j] = word1[:i] 和 word2[:j] 的 LCS 长度
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        lcs = dp[m][n]
        return m + n - 2 * lcs
```

### 方法二：直接DP

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        """
        直接计算删除步数
        
        时间复杂度：O(m * n)
        空间复杂度：O(m * n)
        """
        m, n = len(word1), len(word2)
        
        # dp[i][j] = 使 word1[:i] 和 word2[:j] 相同的最小步数
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 初始化
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + 1
        
        return dp[m][n]
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)，可优化到O(n)

## 关键点总结

1. **LCS转化**：删除步数 = m + n - 2*LCS
2. **DP状态**：dp[i][j] 表示前i和前j个字符的结果
3. **状态转移**：字符相同时不删除，不同时删除一个
