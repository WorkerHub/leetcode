## 题目描述

把符合下列属性的数组 `arr` 称为 **山脉数组**：
- `arr.length >= 3`
- 存在下标 `i`（`0 < i < arr.length - 1`）使得：
  - `arr[0] < arr[1] < ... < arr[i - 1] < arr[i]`
  - `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]`

给出一个整数数组 `arr`，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 `0`。

**示例 1:**
```
输入: arr = [2,1,4,7,3,2,5]
输出: 5
解释: 最长的山脉子数组是 [1,4,7,3,2]，长度为 5。
```

**示例 2:**
```
输入: arr = [2,2,2]
输出: 0
解释: 不存在山脉子数组。
```

**提示:**
- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 10^4`

## Python 代码实现

### 方法一：枚举山顶（推荐）⭐

```python
from typing import List

class Solution:
    def longestMountain(self, arr: List[int]) -> int:
        n = len(arr)
        if n < 3:
            return 0
        
        max_length = 0
        
        for i in range(1, n - 1):
            # i 是否是山顶
            if arr[i] > arr[i - 1] and arr[i] > arr[i + 1]:
                left = i - 1
                right = i + 1
                
                # 向左扩展
                while left > 0 and arr[left] > arr[left - 1]:
                    left -= 1
                
                # 向右扩展
                while right < n - 1 and arr[right] > arr[right + 1]:
                    right += 1
                
                # 计算山脉长度
                max_length = max(max_length, right - left + 1)
        
        return max_length
```

### 方法二：双数组

```python
from typing import List

class Solution:
    def longestMountain(self, arr: List[int]) -> int:
        n = len(arr)
        if n < 3:
            return 0
        
        # up[i]: 以 i 结尾的最长上升子数组长度
        up = [0] * n
        # down[i]: 以 i 开始的最长下降子数组长度
        down = [0] * n
        
        # 计算 up 数组
        for i in range(1, n):
            if arr[i] > arr[i - 1]:
                up[i] = up[i - 1] + 1
        
        # 计算 down 数组
        for i in range(n - 2, -1, -1):
            if arr[i] > arr[i + 1]:
                down[i] = down[i + 1] + 1
        
        # 找最长山脉
        max_length = 0
        for i in range(n):
            if up[i] > 0 and down[i] > 0:
                max_length = max(max_length, up[i] + down[i] + 1)
        
        return max_length
```

### 方法三：一次遍历

```python
from typing import List

class Solution:
    def longestMountain(self, arr: List[int]) -> int:
        n = len(arr)
        max_length = 0
        i = 0
        
        while i < n:
            # 找到上升的起点
            start = i
            
            # 上升阶段
            while i + 1 < n and arr[i] < arr[i + 1]:
                i += 1
            
            peak = i
            
            # 下降阶段
            while i + 1 < n and arr[i] > arr[i + 1]:
                i += 1
            
            # 如果既有上升又有下降
            if start < peak < i:
                max_length = max(max_length, i - start + 1)
            
            # 如果没有移动，手动前进
            if i == start:
                i += 1
        
        return max_length
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1) 或 O(n)

## 关键点总结

1. **山顶特征**：左右两边都严格递减
2. **双向扩展**：从山顶向两边扩展
3. **边界条件**：山顶不能在两端

## 易错点

1. **严格递增/递减**：不能有相等
2. **山脉定义**：必须有上升和下降
3. **最小长度**：至少为 3
