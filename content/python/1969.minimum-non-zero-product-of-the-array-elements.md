## 题目描述

给你一个正整数 `p`，你有一个数组包含 `2^p - 1` 个正整数，分别是 `1` 到 `2^p - 1` 的每个整数。

你可以将**任意两个元素的任意位**互相交换（无限次）。

返回数组所有元素乘积的**最小非零值**，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：p = 1
输出：1
解释：只有 [1]，乘积为 1
```

**示例 2：**
```
输入：p = 2
输出：6
解释：数组 [1,2,3]，可交换位得到 [1,1,3]，乘积 = 3；或 [1,3,1]... 最小是 3？
等等，题目要求非零，实际最小是 [1, 1, 3] = 3，但 6 = 1 * 2 * 3... 重新看
```

实际上：最优策略是让一个元素等于 `2^p - 1`（最大值），其余元素尽量小（等于 1）。

通过位操作可以将 `(2^p - 1)` 和 `1` 对换一些位，把 `x` 和 `(2^p - x)` 凑成 `(2^p - 1)`。

最终乘积 = `(2^p - 1) * (2^(p-1) - 1)^(2^(p-1) - 1)` ... 实际需要具体推导。

**正确答案：** `(2^p - 1) * (2^(p-1))^(2^(p-1) - 1)` ... 让我重新推导。

---

## 解题思路

### 正确推导

数组 `[1, 2, ..., 2^p - 1]`，可以交换任意两数的任意对应位。

关键观察：`i` 和 `(2^p - 1 - i)` 的二进制互补（XOR 和 = 2^p - 1）。

通过交换，可以将每对 `(i, 2^p-1-i)` 变为 `(1, 2^p-1-1) = (1, 2^p-2)` ... 

实际最优：将每对 `(i, 2^p-1-i)` 变为 `(1, 2^p-2)`，再乘以 `(2^p-1)`（中间值）。

结果：`(2^p - 1) * (2^(p-1))^(2^(p-1)-1)` ... 具体是 `(2^p-1) * 1^(2^(p-1)-1)` 的乘积。

等等，让我换一个角度：最优是将 `2^(p-1) - 1` 对 `(i, 2^p-1-i)` 都变成 `(1, 2^p-2)`（每对乘积 = `2^p-2`），加上中间 `2^p-1`。

所以答案 = `(2^p - 1) * (2^p - 2)^(2^(p-1) - 1) mod (10^9 + 7)`

---

## 代码实现

### 方法一：数学 + 快速幂（推荐）

```python
class Solution:
    def minNonZeroProduct(self, p: int) -> int:
        MOD = 10**9 + 7
        # 最大值 max_val = 2^p - 1
        max_val = (1 << p) - 1
        # 次大值 = 2^p - 2
        second = max_val - 1
        # 共 2^(p-1) - 1 对（加上 max_val 本身）
        # 答案 = max_val * (2^p - 2)^(2^(p-1) - 1)
        pairs = (1 << (p - 1)) - 1
        return max_val % MOD * pow(second, pairs, MOD) % MOD
```

### 方法二：递归思路（验证）

```python
class Solution:
    def minNonZeroProduct(self, p: int) -> int:
        MOD = 10**9 + 7

        def solve(p: int) -> int:
            if p == 1:
                return 1  # 只有 [1]
            # max_val = 2^p - 1（保留）
            # 其他 2^p - 2 个元素通过配对压缩
            max_val = (1 << p) - 1
            second_val = max_val - 1  # 2^p - 2
            pairs = (1 << (p - 1)) - 1  # 配对数量
            return max_val % MOD * pow(second_val, pairs, MOD) % MOD

        return solve(p)
```

## 关键点总结

1. 每对互补数 `(i, 2^p-1-i)` 可以通过位交换变为 `(1, 2^p-2)`
2. 最优策略：保留 `2^p-1`，其余每对都变为 `1` 和 `2^p-2`
3. 答案公式：`(2^p-1) * (2^p-2)^(2^(p-1)-1) mod (10^9+7)`

---

## 易错点

- 快速幂的指数是 `2^(p-1) - 1`，不是 `2^p - 1`
- `max_val` 本身要对 MOD 取余，但不影响乘法运算
