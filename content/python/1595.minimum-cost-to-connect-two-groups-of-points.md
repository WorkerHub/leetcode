## 题目描述

给你两组点，第一组有 `size1` 个点，第二组有 `size2` 个点。`cost[i][j]` 表示第一组第 `i` 个点和第二组第 `j` 个点的连接成本。

你需要用最小代价连接两组点，使得每个点都至少与另一组中的一个点相连。

返回连接两组点的最小代价。

**提示：**
- `size1 == cost.length`
- `size2 == cost[i].length`
- `1 <= size1, size2 <= 12`
- `1 <= cost[i][j] <= 100`

## 解题思路

### 状态压缩 DP

`size2 ≤ 12`，可以用位掩码表示第二组哪些点已被覆盖。

**状态定义：** `dp[i][mask]` = 处理了第一组前 `i` 个点，且第二组被覆盖的点集为 `mask` 时的最小代价。

**状态转移：** 第 `i` 个点可以连接第二组的若干点（至少连一个）。

**关键优化：** 预处理每个第二组点 `j` 的最小连接代价 `min_cost[j]`，即 `min(cost[i][j] for all i)`，用于处理第一组全部处理后，未被覆盖的第二组点用最小代价补全。

**更实用做法：** `dp[i][mask]` 表示已经处理完第一组第 `i` 个点，第二组覆盖了 `mask` 的最小代价，枚举第 `i` 个点连接第二组点的子集（至少一个）。

简化实现：逐个处理第一组的点，每次枚举它连接第二组的哪个点（可以连多个，但通常只连一个，利用状态迁移积累多连）。

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        size1, size2 = len(cost), len(cost[0])
        full = (1 << size2) - 1  # 第二组全覆盖的掩码

        # 预处理：每个第二组点被第一组任意点连接的最小代价
        min_cost = [min(cost[i][j] for i in range(size1)) for j in range(size2)]

        # dp[mask] = 处理完第一组所有点，第二组覆盖 mask 的最小代价
        INF = float('inf')
        dp = [INF] * (1 << size2)
        dp[0] = 0

        for i in range(size1):
            new_dp = [INF] * (1 << size2)
            for mask in range(1 << size2):
                if dp[mask] == INF:
                    continue
                # 第 i 个点连接第二组的第 j 个点
                for j in range(size2):
                    new_mask = mask | (1 << j)
                    new_dp[new_mask] = min(new_dp[new_mask], dp[mask] + cost[i][j])
            dp = new_dp

        # 处理完第一组后，补齐未覆盖的第二组点（用最小代价）
        ans = INF
        for mask in range(1 << size2):
            if dp[mask] == INF:
                continue
            extra = 0
            for j in range(size2):
                if not (mask >> j & 1):
                    extra += min_cost[j]  # 补连该点的最小代价
            ans = min(ans, dp[mask] + extra)

        return ans
```

### 方法二：带记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        size1, size2 = len(cost), len(cost[0])
        min_cost = [min(cost[i][j] for i in range(size1)) for j in range(size2)]

        @lru_cache(maxsize=None)
        def dp(i, mask):
            # 处理完第一组所有点后，补齐剩余
            if i == size1:
                extra = sum(min_cost[j] for j in range(size2) if not (mask >> j & 1))
                return extra
            # 枚举第 i 个点连第二组哪个点
            res = float('inf')
            for j in range(size2):
                res = min(res, cost[i][j] + dp(i + 1, mask | (1 << j)))
            return res

        return dp(0, 0)
```

## 复杂度分析

- **时间复杂度**：O(size1 * size2 * 2^size2)
- **空间复杂度**：O(2^size2)

## 关键点总结

1. 用位掩码表示第二组的覆盖状态（size2 ≤ 12）
2. 每个第一组的点必须连接第二组的至少一个点（枚举连哪个）
3. 处理完第一组后，剩余未覆盖的第二组点用全局最小代价补全

## 易错点

- 每个第一组点只连一个第二组点，通过状态迁移积累；不需要枚举子集
- 最后的补全逻辑：对每个未覆盖的第二组点，取所有第一组点的最小代价
