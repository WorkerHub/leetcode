## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，长度均为 `n`。

构造一个数组 `nums3`，对每个下标 `i`（`0 <= i < n`），从 `nums1[i]` 和 `nums2[i]` 中选一个。

返回 `nums3` 中 **最长非递减子数组** 的长度。

**示例 1：**
```
输入：nums1 = [2,3,1], nums2 = [1,2,1]
输出：2
解释：选 [2,2,1]，最长非递减子数组 [2,2]，长度 2
```

**示例 2：**
```
输入：nums1 = [1,3,2,1], nums2 = [2,1,3,4]
输出：4
解释：选 [2,3,3,4]，整个数组非递减，长度 4
```

**提示：**
- `1 <= nums1.length == nums2.length == n <= 10^5`

## 解题思路

**DP**：`dp[i][0]` = 以 `nums1[i]` 结尾的最长非递减子数组长度；`dp[i][1]` = 以 `nums2[i]` 结尾的最长非递减子数组长度。

转移：
- `dp[i][0]`：若 `nums1[i-1] <= nums1[i]`，可从 `dp[i-1][0]` 延续；若 `nums2[i-1] <= nums1[i]`，可从 `dp[i-1][1]` 延续
- `dp[i][1]` 同理

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxNonDecreasingLength(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        # dp0, dp1: 以 nums1[i] 或 nums2[i] 结尾的最长非递减子数组长度
        dp0 = dp1 = 1
        ans = 1

        for i in range(1, n):
            new0 = new1 = 1
            # 以 nums1[i] 结尾
            if nums1[i - 1] <= nums1[i]:
                new0 = max(new0, dp0 + 1)
            if nums2[i - 1] <= nums1[i]:
                new0 = max(new0, dp1 + 1)
            # 以 nums2[i] 结尾
            if nums1[i - 1] <= nums2[i]:
                new1 = max(new1, dp0 + 1)
            if nums2[i - 1] <= nums2[i]:
                new1 = max(new1, dp1 + 1)

            dp0, dp1 = new0, new1
            ans = max(ans, dp0, dp1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. DP 状态只需保留上一位的两个值
2. 每个位置有两种选择，分别对应两种结尾
3. 四种转移路径（前位两种选择 x 当前两种选择）

## 易错点

1. 转移时使用上一步的 dp0, dp1，不能边更新边使用
2. ans 需要比较 dp0 和 dp1 两者
