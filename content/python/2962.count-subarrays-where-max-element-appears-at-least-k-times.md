## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

返回满足以下条件的子数组数目：子数组中 `nums` 的 **最大元素** 至少出现 `k` 次。

**示例 1：**
```
输入：nums = [1,3,2,3,3], k = 2
输出：6
解释：最大元素为 3，至少出现 2 次的子数组有 6 个
```

**示例 2：**
```
输入：nums = [1,4,2,1], k = 3
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= k <= 10^5`

## 解题思路

滑动窗口：找最大元素，然后统计最大元素出现 >= k 次的子数组数目。

对于每个右端点 `r`（包含第 k 个最大元素），左端点 `l` 可以从 0 到某个位置。

具体地：记录最大元素每次出现的位置 `positions`。对于 positions[k-1] 到 positions[k]...（第 k 次到第 k+1 次出现之间），左端点可以从 0 到 positions[k-2]（包含第 k-1 次出现的位置）。

滑动窗口更直接：维护窗口内最大元素的出现次数 `cnt`。当 cnt >= k 时，所有以该右端点结尾、左端点在 [0, left] 的子数组都满足条件，累加 left+1。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        max_val = max(nums)
        n = len(nums)
        ans = 0
        cnt = 0  # 窗口内最大元素的出现次数
        left = 0

        for right in range(n):
            if nums[right] == max_val:
                cnt += 1
            # 当 cnt >= k 时，收缩左端直到 cnt == k-1
            while cnt >= k:
                if nums[left] == max_val:
                    cnt -= 1
                left += 1
            # 此时 [left, right] 中最大元素出现次数 < k
            # 但是 [0, right] 到 [left-1, right] 的所有子数组最大元素出现次数 >= k
            ans += left

        return ans
```

### 方法二：记录位置

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        max_val = max(nums)
        positions = [i for i, x in enumerate(nums) if x == max_val]

        if len(positions) < k:
            return 0

        ans = 0
        n = len(nums)
        for i in range(k - 1, len(positions)):
            # 右端点在 positions[i] 及之后，左端点在 0 到 positions[i-k+1] 之间
            # 对于右端点 r in [positions[i], positions[i+1]-1]（若 i+1 < len，否则到 n-1）
            left_bound = positions[i - k + 1]  # 左端点最右为 positions[i-k+1]
            right_bound = positions[i + 1] - 1 if i + 1 < len(positions) else n - 1

            # 右端点为 positions[i] 时，左端点范围 [0, left_bound]
            # 右端点为 positions[i]+1 到 right_bound 时，左端点范围同上
            for r in range(positions[i], right_bound + 1):
                ans += left_bound + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各遍历 n 次
- 空间复杂度：O(1)

## 关键点总结

1. 滑动窗口：收缩到 cnt < k 时，[0, left-1] 是有效的左端点
2. 每个右端点 right 贡献 `left` 个有效子数组（左端点 0 到 left-1）
3. 关键：使用滑动窗口将"收缩到恰好 cnt == k-1"的位置作为左端界

## 易错点

1. 只关注全局最大元素，不是局部最大
2. 累加的是 `left`（左端点可选范围的个数），不是 right-left+1
3. 收缩后 left 是"第一个使 cnt < k 的左端点"
