## 题目描述

给你一个顾客访问记录字符串 `customers`，其中 `customers[i]` 为 `'Y'`（有顾客）或 `'N'`（无顾客）。

在第 `j` 小时关店的代价：
- 关店前（`[0, j-1]`）每个 `'N'` 贡献 1 点代价（本应开门却没顾客）
- 关店后（`[j, n-1]`）每个 `'Y'` 贡献 1 点代价（本应关门却有顾客）

返回代价最小的关店时刻 `j`（`j` 取 `0` 到 `n`，其中 `j=0` 表示一开始就关门，`j=n` 表示一直开到最后）。

若有多个答案返回最早的那个。

**提示：**
- `1 <= customers.length <= 10^5`
- `customers[i] 是 'Y' 或 'N'`

## 解题思路

**前缀和枚举：**

设 `prefix_Y[i]` 为前 i 个字符中 'Y' 的个数，`total_Y` 为总 'Y' 数。

在第 j 小时关门的代价：
- 前缀 N 数 = j - prefix_Y[j]
- 后缀 Y 数 = total_Y - prefix_Y[j]
- 总代价 = (j - prefix_Y[j]) + (total_Y - prefix_Y[j])

枚举 j 取最小代价即可。

## 代码实现

### 方法一：前缀和（推荐）

```python
class Solution:
    def bestClosingTime(self, customers: str) -> int:
        n = len(customers)
        total_Y = customers.count('Y')

        min_penalty = float('inf')
        ans = 0
        prefix_Y = 0  # 前 j 个字符中 Y 的数量

        for j in range(n + 1):
            # 前缀 N 的数量（开门期间无顾客）
            prefix_N = j - prefix_Y
            # 后缀 Y 的数量（关门后有顾客）
            suffix_Y = total_Y - prefix_Y
            penalty = prefix_N + suffix_Y

            if penalty < min_penalty:
                min_penalty = penalty
                ans = j

            # 更新 prefix_Y（为下一次迭代准备）
            if j < n and customers[j] == 'Y':
                prefix_Y += 1

        return ans
```

### 方法二：差分更新

```python
class Solution:
    def bestClosingTime(self, customers: str) -> int:
        # 从全部关门（代价=Y总数）开始，逐步向右扩展开门时间
        # 每扩展一个位置：
        #   若是 Y：代价 -1（减少后缀Y）
        #   若是 N：代价 +1（增加前缀N）
        penalty = customers.count('Y')  # j=0 时的初始代价
        min_penalty = penalty
        ans = 0

        for j, c in enumerate(customers):
            if c == 'Y':
                penalty -= 1  # 多开一小时，减少一个后缀 Y
            else:
                penalty += 1  # 多开一小时，增加一个前缀 N

            if penalty < min_penalty:
                min_penalty = penalty
                ans = j + 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(1) |
| 差分更新 | O(n) | O(1) |

## 关键点总结

1. 关店时刻 j 的代价 = 前缀 N 数 + 后缀 Y 数
2. 从 j=0 开始，每向右扩展一个位置：Y 使代价减 1，N 使代价加 1
3. 维护最小代价时取最早出现的 j

## 易错点

- j 的范围是 0 到 n（包含两端）
- 若有多个最小代价，返回最早的，要用严格小于
