## 题目描述

给你一个正整数 `n`。`n` 的每一位数字都会按下述规则分配一个符号：
- **最高位**数字的符号为 **正**
- 剩余每位数字的符号都与相邻数字 **相反**

返回所有数字及其对应符号的和。

**示例 1：**

```
输入：n = 521
输出：4
解释：(+5) + (-2) + (+1) = 4
```

**示例 2：**

```
输入：n = 111
输出：1
解释：(+1) + (-1) + (+1) = 1
```

**示例 3：**

```
输入：n = 886996
输出：0
```

**提示：**

- `1 <= n <= 10^9`

## 解题思路

将 n 转为字符串，从左到右交替加减各位数字。最高位为正号，奇数位（从 0 开始）为正，偶数位为负。

## Python 代码实现

### 方法一：字符串遍历（推荐）

```python
class Solution:
    def alternateDigitSum(self, n: int) -> int:
        result = 0
        sign = 1  # 最高位为正
        for ch in str(n):
            result += sign * int(ch)
            sign = -sign  # 交替正负
        return result
```

### 方法二：数学计算

```python
class Solution:
    def alternateDigitSum(self, n: int) -> int:
        digits = []
        temp = n
        while temp > 0:
            digits.append(temp % 10)
            temp //= 10
        # digits 是从低位到高位，需要反转
        digits.reverse()

        result = 0
        for i, d in enumerate(digits):
            result += d if i % 2 == 0 else -d
        return result
```

## 复杂度分析

- 时间复杂度：O(log n)，位数为 O(log n)
- 空间复杂度：O(log n)，字符串或数组存储各位

## 关键点总结

1. 最高位为正，然后交替正负
2. 使用 `sign` 变量每次乘以 -1 切换符号
3. 字符串方法直接从左到右处理，简洁直观

## 易错点

1. 最高位（字符串第 0 位）是正号
2. 不是按奇偶数字本身，而是按位置交替
3. 注意符号初始化和切换逻辑
