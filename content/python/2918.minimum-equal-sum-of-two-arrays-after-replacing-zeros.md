## 题目描述

给你两个由正整数和 0 组成的数组 `nums1` 和 `nums2`。

你可以将两个数组中的任意 0 替换成任意**正整数**（不同 0 可以替换为不同正整数）。

你的目标是使两个数组的元素和相等。返回实现目标的最小可能的 **相等元素和**，如果不存在合法方案则返回 `-1`。

**示例 1：**
```
输入：nums1 = [3,2,0,1,0], nums2 = [6,5,0]
输出：12
解释：nums1 中 0 替换为 2 和 1，nums2 中 0 替换为 1
nums1 = [3,2,2,1,1], sum=9? 不对，最优：
nums1 的 0 替换为 2,1 -> sum=3+2+2+1+1=9，nums2 的 0 替换为 3 -> sum=6+5+3=14，不等
最优：nums1 的 0 替换为 1,1 -> sum=7，nums2 的 0 替换为 5 -> sum=11，不等
...让 sum1 尽量大，sum2 尽量大：
若 sum1_min = 3+2+1+1+1=8（每个0替换为1）
若 sum2_min = 6+5+1=12（每个0替换为1）
所以 sum >= max(sum1_min, sum2_min) = 12
nums1 的 0 替换使总和为 12：3+2+0+1+6=12，即 0 换成 6 和 0 换成 0 不行……
实际：sum1_min=8，可以增大；sum2_min=12，若 nums1 无 0 则不能增大
具体：ans = max(sum1_min, sum2_min) = 12
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `0 <= nums1[i], nums2[i] <= 10^6`

## 解题思路

对于每个数组，将 0 替换为正整数（最小为 1），计算两个数组的最小可能和：
- `min_sum1 = sum(nums1) + count0_in_nums1`（每个 0 至少替换为 1）
- `min_sum2 = sum(nums2) + count0_in_nums2`

目标等于 `max(min_sum1, min_sum2)`。

但需要验证可行性：
- 若 `min_sum1 > min_sum2` 且 `nums2` 中没有 0，则 nums2 的和固定为 min_sum2，无法增大到 min_sum1，返回 -1
- 若 `min_sum2 > min_sum1` 且 `nums1` 中没有 0，则同理返回 -1

## Python 代码实现

### 方法一：贪心分析（推荐）

```python
from typing import List

class Solution:
    def minSum(self, nums1: List[int], nums2: List[int]) -> int:
        sum1 = sum(nums1)
        sum2 = sum(nums2)
        zeros1 = nums1.count(0)
        zeros2 = nums2.count(0)

        # 最小可能和（每个 0 替换为 1）
        min_sum1 = sum1 + zeros1
        min_sum2 = sum2 + zeros2

        # 若一方无 0，其和固定；另一方需要能达到相同的和
        if zeros1 == 0 and zeros2 == 0:
            return min_sum1 if min_sum1 == min_sum2 else -1

        if zeros1 == 0:
            # nums1 的和固定为 sum1，nums2 需要等于 sum1
            if sum1 < min_sum2:
                return -1  # nums2 最小和已超过 sum1
            return sum1  # nums2 的 0 可以调整

        if zeros2 == 0:
            if sum2 < min_sum1:
                return -1
            return sum2

        # 两者都有 0，目标和为 max(min_sum1, min_sum2)
        return max(min_sum1, min_sum2)
```

### 方法二：统一处理

```python
from typing import List

class Solution:
    def minSum(self, nums1: List[int], nums2: List[int]) -> int:
        def min_possible_sum(nums):
            return sum(nums) + nums.count(0)

        s1 = min_possible_sum(nums1)
        s2 = min_possible_sum(nums2)
        has_zero1 = 0 in nums1
        has_zero2 = 0 in nums2

        target = max(s1, s2)

        # 验证可行性
        if not has_zero1 and s1 < target:
            return -1
        if not has_zero2 and s2 < target:
            return -1

        return target
```

## 复杂度分析

- 时间复杂度：O(n + m)，遍历两个数组
- 空间复杂度：O(1)

## 关键点总结

1. 每个 0 至少要替换为 1，所以最小可能和 = 非零元素之和 + 零的个数
2. 两数组的公共目标和 >= max(min_sum1, min_sum2)
3. 若某数组没有 0 且其和 < 目标，则无法达成 -> 返回 -1

## 易错点

1. 没有 0 的数组和是固定的，不能任意增大
2. 目标是最小的相等和，所以取 max(min_sum1, min_sum2)
3. 两个数组都没有 0 时，只有 sum1 == sum2 才有解
