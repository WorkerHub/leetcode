## 题目描述

给你一个下标从 **0** 开始、长度为 `n` 的整数数组 `nums` 和一个整数 `k`，返回满足下述条件的下标对 `(i, j)` 的数目：

- `0 <= i < j <= n - 1`
- `nums[i] * nums[j]` 能被 `k` 整除

**示例 1：**
```
输入：nums = [1,2,3,4,5], k = 2
输出：7
解释：共有 7 对乘积能被 2 整除的下标对。
```

**示例 2：**
```
输入：nums = [1,2,3,4], k = 5
输出：0
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= nums[i], k <= 10^5`

## 解题思路

**数论优化：按 gcd 分组**

`nums[i] * nums[j]` 被 `k` 整除，等价于：

`gcd(nums[i], k) * gcd(nums[j], k)` 能被 `k` 整除。

设 `g = gcd(nums[i], k)`，则 `nums[j]` 需要提供的因子数为 `k // g`，即 `gcd(nums[j], k)` 必须是 `k // g` 的倍数。

做法：
1. 统计 `cnt[d]` = 数组中满足 `gcd(x, k) == d` 的元素数量（其中 `d` 是 `k` 的因子）。
2. 枚举所有因子对 `(d1, d2)`，若 `d1 * d2 % k == 0`，则贡献 `cnt[d1] * cnt[d2]`（注意去重）。

## 代码实现

### 方法一：按 gcd(x,k) 分组（推荐）

```python
from typing import List
from math import gcd
from collections import defaultdict

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        # 统计每个 gcd(x, k) 值出现的次数
        cnt = defaultdict(int)
        for x in nums:
            cnt[gcd(x, k)] += 1

        # k 的所有因子
        divisors = [d for d in range(1, k + 1) if k % d == 0]

        ans = 0
        # 枚举所有有序因子对 (d1, d2)，d1 <= d2
        for i, d1 in enumerate(divisors):
            for j, d2 in enumerate(divisors):
                if j < i:
                    continue
                if (d1 * d2) % k == 0:
                    if d1 == d2:
                        # 同组内选两个
                        c = cnt[d1]
                        ans += c * (c - 1) // 2
                    else:
                        ans += cnt[d1] * cnt[d2]

        return ans
```

### 方法二：枚举 + 暴力（小数据可用）

```python
from typing import List
from math import gcd

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                if (nums[i] * nums[j]) % k == 0:
                    ans += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| gcd 分组 | O(n + d(k)^2)，d(k) 为 k 的因子数 | O(d(k)) |
| 暴力 | O(n^2) | O(1) |

`d(k)` 通常很小（k <= 10^5 时 d(k) <= 128），所以方法一高效。

## 关键点总结

1. `nums[i]*nums[j] % k == 0` 等价于 `gcd(nums[i],k) * gcd(nums[j],k) % k == 0`。
2. 只需统计每种 `gcd(x,k)` 的数量，再枚举因子对。
3. k 的因子数很小，枚举因子对复杂度极低。

## 易错点

- 同组内（d1 == d2）要用组合数 `C(cnt, 2) = cnt*(cnt-1)//2`，避免重复计数。
- `d1 * d2` 可能溢出（Python 无此问题，但其他语言需注意）。
