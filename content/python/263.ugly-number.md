## 题目描述

丑数是只包含质因数 `2`、`3` 和 `5` 的正整数。

给你一个整数 `n`，请你判断 `n` 是否为丑数。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入: n = 6
输出: true
解释: 6 = 2 × 3
```

**示例 2：**
```
输入: n = 1
输出: true
解释: 1 没有质因数，被视为丑数
```

**示例 3：**
```
输入: n = 14
输出: false
解释: 14 = 2 × 7，包含质因数 7
```

**提示：**
- `-2^31 <= n <= 2^31 - 1`

## 解题思路

判断一个数是否为丑数，核心思路是：
1. 丑数必须是正整数（n > 0）
2. 丑数只包含质因数 2、3、5
3. 不断除以 2、3、5，最终结果应该为 1

**算法步骤：**
1. 如果 n <= 0，直接返回 false
2. 循环除以 2、3、5，直到不能整除为止
3. 检查最终结果是否为 1

**特殊情况：**
- n = 1 是丑数（1 没有质因数）
- n <= 0 不是丑数
- 包含其他质因数（如 7、11）的数不是丑数

## Python 代码实现

### 方法一：循环除法（推荐）⭐

```python
class Solution:
    def isUgly(self, n: int) -> bool:
        # 非正整数不是丑数
        if n <= 0:
            return False
        
        # 不断除以 2、3、5
        for factor in [2, 3, 5]:
            while n % factor == 0:
                n //= factor
        
        # 如果最终为 1，说明只包含 2、3、5 这些质因数
        return n == 1
```

### 方法二：递归写法

```python
class Solution:
    def isUgly(self, n: int) -> bool:
        # 基本情况
        if n <= 0:
            return False
        if n == 1:
            return True
        
        # 递归除以 2、3、5
        if n % 2 == 0:
            return self.isUgly(n // 2)
        if n % 3 == 0:
            return self.isUgly(n // 3)
        if n % 5 == 0:
            return self.isUgly(n // 5)
        
        # 不能被 2、3、5 整除，说明有其他质因数
        return False
```

### 方法三：while 循环分别处理

```python
class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False
        
        # 除尽所有的 2
        while n % 2 == 0:
            n //= 2
        
        # 除尽所有的 3
        while n % 3 == 0:
            n //= 3
        
        # 除尽所有的 5
        while n % 5 == 0:
            n //= 5
        
        return n == 1
```

### 方法四：数学优化（一行代码）

```python
class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False
        
        # 不断除以 2、3、5，直到无法继续
        while n % 2 == 0: n //= 2
        while n % 3 == 0: n //= 3
        while n % 5 == 0: n //= 5
        
        return n == 1
```

### 方法五：使用 reduce（Python 特色）

```python
from functools import reduce

class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False
        
        def divide_by_factor(num: int, factor: int) -> int:
            """除尽某个因数"""
            while num % factor == 0:
                num //= factor
            return num
        
        # 依次除以 2、3、5
        n = reduce(divide_by_factor, [2, 3, 5], n)
        
        return n == 1
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(log n)
  - 最坏情况下，n 是 2 的幂次，需要除以 2 约 log₂(n) 次
  - 除以 3、5 同理
  - 总共最多 O(log₂(n) + log₃(n) + log₅(n)) = O(log n)
  
- **空间复杂度**：O(1)
  - 方法二递归深度最多 O(log n)，但其他方法都是 O(1)

## 图解示例

以 n = 60 为例：

```
60
├─ 60 ÷ 2 = 30
   ├─ 30 ÷ 2 = 15
      ├─ 15 ÷ 3 = 5
         ├─ 5 ÷ 5 = 1  ✓ 是丑数
```

以 n = 14 为例：

```
14
├─ 14 ÷ 2 = 7
   ├─ 7 不能被 2、3、5 整除
      └─ 最终结果 = 7 ≠ 1  ✗ 不是丑数
```

## 关键点总结

1. **丑数定义**：只包含质因数 2、3、5 的正整数
2. **边界条件**：n <= 0 不是丑数，n = 1 是丑数
3. **核心算法**：不断除以 2、3、5，最终应该得到 1
4. **循环顺序**：先除哪个因数都可以，结果一样
5. **优化技巧**：使用 for 循环遍历 [2, 3, 5] 更简洁

## 易错点

1. **忘记判断非正数**：n <= 0 不是丑数
2. **1 的特殊性**：1 是丑数（定义规定）
3. **整除判断**：要用 `n % factor == 0` 而不是 `n / factor`
4. **整数除法**：Python3 中要用 `//` 而不是 `/`
5. **最终判断**：最后要判断 `n == 1`，而不是 `n <= 1`

```python
assert Solution().isUgly(6) == True    # 2 × 3
assert Solution().isUgly(8) == True    # 2³
assert Solution().isUgly(14) == False  # 2 × 7

# 边界情况
assert Solution().isUgly(1) == True    # 特殊：1 是丑数

assert Solution().isUgly(-10) == False # 负数

# 极端情况
assert Solution().isUgly(2**30) == True      # 大的 2 的幂次
assert Solution().isUgly(2 * 3 * 5) == True  # 30
assert Solution().isUgly(7) == False         # 质数（非 2、3、5）
```
