## 题目描述

给你一个类似 Lisp 语句的字符串表达式 expression，求出其计算结果。

表达式语法如下所示:
- 表达式可以为整数，let 表达式，add 表达式，mult 表达式，或赋值的变量。
- 表达式的结果总是一个整数。

## Python 代码实现

```python
class Solution:
    def evaluate(self, expression: str) -> int:
        def parse(expr, scope):
            if expr[0] != '(':
                # 数字或变量
                if expr.lstrip('-').isdigit():
                    return int(expr)
                return scope[expr]
            
            # 去掉括号
            expr = expr[1:-1]
            tokens = []
            i = 0
            
            # 分词
            while i < len(expr):
                if expr[i] == ' ':
                    i += 1
                    continue
                
                if expr[i] == '(':
                    # 找到匹配的右括号
                    count = 1
                    j = i + 1
                    while count > 0:
                        if expr[j] == '(':
                            count += 1
                        elif expr[j] == ')':
                            count -= 1
                        j += 1
                    tokens.append(expr[i:j])
                    i = j
                else:
                    # 读取单词或数字
                    j = i
                    while j < len(expr) and expr[j] != ' ':
                        j += 1
                    tokens.append(expr[i:j])
                    i = j
            
            # 执行操作
            op = tokens[0]
            if op == 'add':
                return parse(tokens[1], scope) + parse(tokens[2], scope)
            elif op == 'mult':
                return parse(tokens[1], scope) * parse(tokens[2], scope)
            else:  # let
                new_scope = scope.copy()
                i = 1
                while i < len(tokens) - 1:
                    var = tokens[i]
                    val = parse(tokens[i+1], new_scope)
                    new_scope[var] = val
                    i += 2
                return parse(tokens[-1], new_scope)
        
        return parse(expression, {})
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

2. 使用作用域管理变量
3. 正确处理括号匹配
