## 题目描述

我们称一个数 X 为**好数**，当它满足以下条件时：
- 将 X 旋转 180 度后，能得到一个不同的有效数字

数字旋转规则如下：
- `0`, `1`, `8` 旋转后仍是自己
- `2` 和 `5` 互相旋转
- `6` 和 `9` 互相旋转
- 其他数字（`3`, `4`, `7`）旋转后无效

给定正整数 `n`，返回小于等于 `n` 的好数的数量。

**示例 1：**
```
输入: n = 10
输出: 4
解释: 
在 [1, 10] 中有 4 个好数: 2, 5, 6, 9
- 1 旋转后还是 1，不是好数
- 2 旋转后变成 5，是好数
- 3 旋转后无效
- 4 旋转后无效
- 5 旋转后变成 2，是好数
- 6 旋转后变成 9，是好数
- 7 旋转后无效
- 8 旋转后还是 8，不是好数
- 9 旋转后变成 6，是好数
- 10 旋转后无效（因为 1 和 0 旋转后还是自己）
```

**示例 2：**
```
输入: n = 1
输出: 0
```

**示例 3：**
```
输入: n = 2
输出: 1
```

**提示：**
- `1 <= n <= 10^4`

## 解题思路

这是一道数学模拟题，核心在于理解"好数"的定义。

**关键观察：**
1. 好数必须满足两个条件：
   - 所有数字都是有效的（只包含 0, 1, 2, 5, 6, 8, 9）
   - 至少包含一个会变化的数字（2, 5, 6, 9）
2. 不能包含 3, 4, 7（旋转后无效）
3. 不能全是 0, 1, 8（旋转后不变）

**解法分析：**

**方法一：暴力枚举 + 数字判断**
- 遍历 [1, n] 的每个数字
- 检查每个数字的每一位是否满足条件
- 时间复杂度较高，但思路直接

**方法二：数位判断优化**
- 将数字转为字符串，逐位检查
- 使用集合快速判断数字类型
- 优化判断逻辑

**方法三：数位 DP（进阶）**
- 适合 n 很大的情况
- 记忆化搜索，避免重复计算
- 本题 n <= 10^4，不需要用到，但可以作为学习

## Python 代码实现

### 方法一：暴力枚举（推荐新手）

```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        """
        暴力枚举每个数字，判断是否为好数
        
        时间复杂度：O(n * log n)
        空间复杂度：O(1)
        """
        def is_good(num: int) -> bool:
            """判断一个数字是否为好数"""
            # 无效数字集合（旋转后无效）
            invalid = {'3', '4', '7'}
            # 不变数字集合（旋转后仍是自己）
            same = {'0', '1', '8'}
            # 会变化的数字集合
            diff = {'2', '5', '6', '9'}
            
            num_str = str(num)
            
            # 包含无效数字，直接返回 False
            if any(d in invalid for d in num_str):
                return False
            
            # 至少包含一个会变化的数字
            if any(d in diff for d in num_str):
                return True
            
            return False
        
        count = 0
        for i in range(1, n + 1):
            if is_good(i):
                count += 1
        
        return count
```

### 方法二：优化的数位判断

```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        """
        优化的数位判断，一次遍历完成检查
        
        时间复杂度：O(n * log n)
        空间复杂度：O(1)
        """
        count = 0
        
        for num in range(1, n + 1):
            # 标记是否有效和是否有变化
            valid = True
            has_diff = False
            
            # 检查每一位数字
            temp = num
            while temp > 0:
                digit = temp % 10
                
                # 包含无效数字
                if digit in [3, 4, 7]:
                    valid = False
                    break
                
                # 包含会变化的数字
                if digit in [2, 5, 6, 9]:
                    has_diff = True
                
                temp //= 10
            
            # 有效且有变化才是好数
            if valid and has_diff:
                count += 1
        
        return count
```

### 方法三：字符串处理 + 集合判断

```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        """
        使用字符串处理和集合判断
        
        时间复杂度：O(n * log n)
        空间复杂度：O(log n)
        """
        count = 0
        
        for num in range(1, n + 1):
            s = str(num)
            
            # 包含无效数字，跳过
            if any(c in '347' for c in s):
                continue
            
            # 包含会变化的数字，计数
            if any(c in '2569' for c in s):
                count += 1
        
        return count
```

### 方法四：数位 DP（进阶，适合大数据）

```python
from functools import lru_cache

class Solution:
    def rotatedDigits(self, n: int) -> int:
        """
        数位 DP 解法，适合 n 很大的情况
        
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        s = str(n)
        
        @lru_cache(None)
        def dp(pos: int, is_limit: bool, has_diff: bool) -> int:
            """
            pos: 当前处理到第几位
            is_limit: 是否受到 n 的限制
            has_diff: 是否已经包含会变化的数字
            """
            # 所有位都处理完了
            if pos == len(s):
                return 1 if has_diff else 0
            
            # 确定当前位可以填的数字范围
            up = int(s[pos]) if is_limit else 9
            
            res = 0
            for d in range(0, up + 1):
                # 无效数字，跳过
                if d in [3, 4, 7]:
                    continue
                
                # 递归处理下一位
                res += dp(
                    pos + 1,
                    is_limit and (d == up),
                    has_diff or (d in [2, 5, 6, 9])
                )
            
            return res
        
        # 从第 0 位开始，受限制，还没有变化的数字
        # 需要减 1，因为数位 DP 会计算 0，但题目要求 >= 1
        return dp(0, True, False)
```

## 复杂度分析

### 方法一、二、三：枚举判断
- **时间复杂度：** O(n × log n)，遍历 n 个数字，每个数字有 O(log n) 位
- **空间复杂度：** O(1) 或 O(log n)（字符串处理需要额外空间）

### 方法四：数位 DP
- **时间复杂度：** O((log n)²)，状态数是 O(log n × 2 × 2)，每个状态计算 O(10)
- **空间复杂度：** O((log n) × 2 × 2)，记忆化缓存

## 关键点总结

1. **理解题意**：好数需要同时满足"所有位有效"和"至少一位会变化"
2. **数字分类**：
   - 无效数字：3, 4, 7
   - 不变数字：0, 1, 8
   - 会变化的数字：2, 5, 6, 9
3. **判断逻辑**：使用集合或数组快速判断数字属于哪一类
4. **优化思路**：对于小范围 (n <= 10^4)，暴力枚举足够；大范围需要数位 DP
5. **边界情况**：注意 n = 1 时返回 0（1 旋转后还是 1）

## 易错点

1. **误判好数条件**：只检查了"不包含 3, 4, 7"，忘记检查"至少包含一个 2, 5, 6, 9"
2. **包含 0 的情况**：0, 1, 8 旋转后不变，但如果数字中同时包含 2, 5, 6, 9，仍然是好数
3. **数位 DP 的边界**：从 1 开始计数，不包括 0
4. **字符串比较**：使用 `in` 操作符判断字符是否在集合中时，注意是字符而不是数字
