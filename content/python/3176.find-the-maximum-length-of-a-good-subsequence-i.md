## 题目描述

给你一个整数数组 `nums` 和一个非负整数 `k`。

如果一个下标序列 `seq` 对应的子序列满足：相邻元素不同的个数不超过 `k`，则称该子序列是 **好** 的。

返回 `nums` 的最长好子序列的长度。

**示例 1：**
```
输入：nums = [1,2,1,1,3], k = 2
输出：4
解释：子序列 [1,2,1,1] 有 2 处相邻不同（1-2 和 2-1），满足 k=2。
```

**提示：**
- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^9`
- `0 <= k <= min(nums.length, 25)`

## 解题思路

动态规划：`dp[i][j]` 表示以 `nums[i]` 结尾、恰好有 `j` 处相邻不同的最长好子序列长度。

转移：对 `i > l`，若 `nums[i] == nums[l]`，则 `dp[i][j] = max(dp[l][j]) + 1`；否则 `dp[i][j] = max(dp[l][j-1]) + 1`。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # dp[i][j]: 以 i 结尾、有 j 处相邻不同的最长子序列
        dp = [[0] * (k + 1) for _ in range(n)]
        for i in range(n):
            dp[i][0] = 1  # 单个元素，0 处不同

        ans = 1
        for i in range(1, n):
            for l in range(i):
                diff = 0 if nums[i] == nums[l] else 1
                for j in range(k + 1):
                    if j >= diff:
                        dp[i][j] = max(dp[i][j], dp[l][j - diff] + 1)
            ans = max(ans, max(dp[i]))

        return ans
```

### 方法二：哈希表优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # best[v][j]: 值为 v，有 j 处不同时，子序列的最长长度
        best = defaultdict(lambda: [0] * (k + 1))
        # global_best[j]: 有 j 处不同时全局最优（任意值结尾）
        global_best = [0] * (k + 1)

        ans = 0
        for x in nums:
            new_best = [0] * (k + 1)
            for j in range(k + 1):
                # 接在相同值后：不增加不同数
                new_best[j] = max(new_best[j], best[x][j] + 1)
                # 接在不同值后：不同数 +1
                if j > 0:
                    new_best[j] = max(new_best[j], global_best[j - 1] + 1)
            for j in range(k + 1):
                best[x][j] = max(best[x][j], new_best[j])
                global_best[j] = max(global_best[j], new_best[j])
                ans = max(ans, new_best[j])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)（方法一），O(n * k)（方法二）
- 空间复杂度：O(n * k)（方法一），O(V * k)（方法二）

## 关键点总结

1. DP 状态：以某元素结尾，恰好有 j 处不同
2. 接在相同值后不增加不同数，接在不同值后加 1
3. 哈希表优化记录每个值结尾的最优状态

## 易错点

1. k = 0 时子序列中所有相邻元素必须相同
2. 哈希表方法需要先读旧值再写新值
