## 题目描述

给你一棵二叉树的根节点 `root`，每个节点的值为 `0`、`1`、`2`、`3`、`4` 之一：
- `0` 和 `1` 表示叶子节点的值（`false` 或 `true`）。
- `2` 表示布尔运算 `OR`。
- `3` 表示布尔运算 `AND`。
- `4` 表示布尔运算 `NOT`（只有右子节点）。

翻转操作指将节点值在 `0` 和 `1` 之间切换（只能翻转叶子节点）。

返回使根节点值等于 `result` 所需的**最小翻转次数**。

**提示：**
- 树中节点数量在 `[1, 10^5]` 范围内
- 节点值为 `0, 1, 2, 3, 4`

## 解题思路

**树形 DP：**
对每个节点，计算使该节点结果为 `true` 和 `false` 分别所需的最小翻转次数，记为 `(cost0, cost1)`。

- 叶子节点：`0` -> `(0, 1)`（本身为 false，变为 true 需要 1 次翻转）；`1` -> `(1, 0)`。
- `OR` 节点：`cost1 = min(left1+right0, left0+right1, left1+right1)`；`cost0 = left0 + right0`。
- `AND` 节点：`cost0 = min(left0+right1, left1+right0, left0+right0)`；`cost1 = left1 + right1`。
- `NOT` 节点（只有右子）：`cost0 = right1`；`cost1 = right0`。

## 代码实现

### 方法一：树形 DP（推荐）

```python
from typing import Optional, Tuple

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def minimumFlips(self, root: Optional[TreeNode], result: bool) -> int:

        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            # 返回 (使该节点为 false 的最小翻转数, 使该节点为 true 的最小翻转数)
            if node is None:
                return (0, 0)
            
            val = node.val
            
            # 叶子节点
            if val == 0:
                return (0, 1)  # 本身 false，需要 1 次翻转变 true
            if val == 1:
                return (1, 0)  # 本身 true，需要 1 次翻转变 false
            
            lc0, lc1 = dfs(node.left)   # 左子树为 false/true 的代价
            rc0, rc1 = dfs(node.right)  # 右子树为 false/true 的代价
            
            if val == 2:  # OR
                # 结果为 true：至少一个为 true
                cost1 = min(lc1 + rc0, lc0 + rc1, lc1 + rc1)
                # 结果为 false：两个都为 false
                cost0 = lc0 + rc0
            elif val == 3:  # AND
                # 结果为 true：两个都为 true
                cost1 = lc1 + rc1
                # 结果为 false：至少一个为 false
                cost0 = min(lc0 + rc1, lc1 + rc0, lc0 + rc0)
            else:  # val == 4, NOT（只有右子）
                cost0 = rc1  # NOT true = false
                cost1 = rc0  # NOT false = true
            
            return (cost0, cost1)

        cost0, cost1 = dfs(root)
        return cost1 if result else cost0
```

### 方法二：带注释的递归版本

```python
from typing import Optional

class Solution:
    def minimumFlips(self, root: Optional[TreeNode], result: bool) -> int:
        INF = float('inf')

        def dp(node):
            if not node:
                return INF, INF
            v = node.val
            if v == 0:
                return 0, 1  # (cost_false, cost_true)
            if v == 1:
                return 1, 0
            
            l0, l1 = dp(node.left)
            r0, r1 = dp(node.right)
            
            if v == 2:  # OR
                return l0 + r0, min(l1 + r0, l0 + r1, l1 + r1)
            if v == 3:  # AND
                return min(l0 + r0, l0 + r1, l1 + r0), l1 + r1
            # v == 4, NOT
            return r1, r0

        c0, c1 = dp(root)
        return c1 if result else c0
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 树形 DP | O(n) | O(h)（h 为树高） |

## 关键点总结

1. 每个节点维护两个状态：使结果为 0 和 1 的最小翻转次数。
2. OR 节点结果为 false 要求左右都为 false；AND 节点结果为 true 要求左右都为 true。
3. NOT 节点只有右子节点，直接交换左右状态代价。

## 易错点

- NOT 节点只处理右子，左子为空，不要访问 `node.left`。
- OR 和 AND 的代价计算方向容易搞反。
