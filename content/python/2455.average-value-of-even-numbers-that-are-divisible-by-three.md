## 题目描述

给你一个正整数数组 `nums`，返回其中可以被 `3` 整除的所有偶数的平均值。

注意：`n` 个元素的平均值等于 `n` 个元素 **求和** 再除以 `n`，结果 **向下取整** 到最近的整数。

如果不存在满足条件的元素，则返回 `0`。

**示例 1：**
```
输入：nums = [1,3,6,10,12,15]
输出：9
解释：满足条件的数（偶数且能被 3 整除）有 6 和 12，平均值 = (6+12)/2 = 9。
```

**示例 2：**
```
输入：nums = [1,2,4,7,10]
输出：0
解释：没有满足条件的数。
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`

## 解题思路

既是偶数又能被 3 整除，等价于能被 6 整除。筛选出所有 6 的倍数，求平均值。

## 代码实现

### 方法一：列表推导式（推荐）

```python
from typing import List

class Solution:
    def averageValue(self, nums: List[int]) -> int:
        # 偶数且被 3 整除 = 被 6 整除
        filtered = [x for x in nums if x % 6 == 0]
        return sum(filtered) // len(filtered) if filtered else 0
```

### 方法二：逐步筛选

```python
from typing import List

class Solution:
    def averageValue(self, nums: List[int]) -> int:
        total = 0
        count = 0

        for x in nums:
            if x % 2 == 0 and x % 3 == 0:
                total += x
                count += 1

        return total // count if count > 0 else 0
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 列表推导 | O(n) | O(n) |
| 逐步筛选 | O(n) | O(1) |

## 关键点总结

1. 偶数 + 能被 3 整除 = 能被 6 整除（6 = lcm(2, 3)）
2. 平均值向下取整（整数除法 `//`）
3. 没有满足条件的元素时返回 0

## 易错点

- 空列表时不能做除法，需要先判断是否为空
- 用 `x % 6 == 0` 比分别判断 `x % 2 == 0 and x % 3 == 0` 更简洁
