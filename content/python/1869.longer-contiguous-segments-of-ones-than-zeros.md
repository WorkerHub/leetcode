## 题目描述

给你一个二进制字符串 `s`，如果字符串中由 `'1'` 组成的最长连续子字符串**严格长于** `'0'` 组成的最长连续子字符串，则返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "1101"
输出：true
解释：最长 '1' 段为 "11"（长度2），最长 '0' 段为 "0"（长度1）
```

**示例 2：**
```
输入：s = "111000"
输出：false
```

**提示：**
- `1 <= s.length <= 100`

## 解题思路

计算字符串中最长的连续 '1' 段和最长的连续 '0' 段，比较两者的长度。

## 代码实现

### 方法一：线性扫描（推荐）

```python
class Solution:
    def checkZeroOnes(self, s: str) -> bool:
        def max_consecutive(ch: str) -> int:
            """计算字符 ch 的最长连续段长度"""
            max_len = 0
            cur_len = 0
            for c in s:
                if c == ch:
                    cur_len += 1
                    max_len = max(max_len, cur_len)
                else:
                    cur_len = 0
            return max_len

        return max_consecutive('1') > max_consecutive('0')
```

### 方法二：使用 split 方法

```python
class Solution:
    def checkZeroOnes(self, s: str) -> bool:
        # 按 '0' 分割得到所有 '1' 段，取最大长度
        max_ones = max(len(seg) for seg in s.split('0'))
        # 按 '1' 分割得到所有 '0' 段，取最大长度
        max_zeros = max(len(seg) for seg in s.split('1'))
        return max_ones > max_zeros
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（方法一），O(n)（方法二，split 创建新列表）

## 关键点总结

1. 分别统计 '1' 和 '0' 的最长连续段，比较长度
2. 方法二利用 Python 的 split 简洁实现

## 易错点

- 严格大于（`>`），不是大于等于（`>=`）
