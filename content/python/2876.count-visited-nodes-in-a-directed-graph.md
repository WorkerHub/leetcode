## 题目描述

给你一个有 `n` 个节点的有向图，每个节点有且只有一条出边，`edges[i]` 表示节点 i 的出边指向 `edges[i]`（0-indexed）。

从节点 i 出发，一直沿出边走，设 `answer[i]` = 能访问的不同节点数（含自身）。

返回 `answer` 数组。

**示例 1：**
```
输入：edges = [1,2,0,0]
输出：[3,3,3,4]
解释：
0->1->2->0（形成环 0,1,2）从 0,1,2 出发各能访问 3 个
3->0->1->2->0 从 3 出发访问 4 个（3,0,1,2）
```

**提示：**
- `2 <= n <= 10^5`

## 解题思路

**内向基环树（Functional Graph）：** 每个节点恰好有一条出边，所以最终必然进入一个环。

**算法：**
1. 找到所有环（DFS/拓扑排序）
2. 环上每个节点的答案 = 环的长度
3. 非环节点：DFS 时记录路径，到达环后答案 = 链长 + 对应环节点的答案

**步骤：**
1. 拓扑排序找到所有非环节点（入度为 0 的节点依次处理）
2. 剩余未处理的节点形成环，计算环的大小
3. 用 DFS 从链的端点向后传播答案

## Python 代码实现

### 方法一：拓扑排序 + DFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def countVisitedNodes(self, edges: List[int]) -> List[int]:
        n = len(edges)
        in_degree = [0] * n
        for v in edges:
            in_degree[v] += 1

        # 步骤 1：拓扑排序，处理所有非环节点
        ans = [0] * n
        queue = deque(i for i in range(n) if in_degree[i] == 0)
        visited = [False] * n

        while queue:
            node = queue.popleft()
            visited[node] = True
            nxt = edges[node]
            in_degree[nxt] -= 1
            if in_degree[nxt] == 0:
                queue.append(nxt)

        # 步骤 2：处理环（未被拓扑排序访问的节点）
        for i in range(n):
            if not visited[i]:
                # 找环的大小
                cycle = []
                cur = i
                while not visited[cur]:
                    visited[cur] = True
                    cycle.append(cur)
                    cur = edges[cur]
                # cycle 中的节点都在同一个环上
                cycle_len = len(cycle)
                for node in cycle:
                    ans[node] = cycle_len

        # 步骤 3：从链端点反向传播（按拓扑逆序）
        # 重新计算：对每个节点，如果未设置 ans，则从其出边的答案 + 1
        # 用记忆化方式

        def get_ans(node: int) -> int:
            if ans[node] != 0:
                return ans[node]
            ans[node] = get_ans(edges[node]) + 1
            return ans[node]

        import sys
        sys.setrecursionlimit(200000)
        for i in range(n):
            if ans[i] == 0:
                get_ans(i)

        return ans
```

### 方法二：迭代方式（避免递归）

```python
from typing import List
from collections import deque

class Solution:
    def countVisitedNodes(self, edges: List[int]) -> List[int]:
        n = len(edges)
        in_deg = [0] * n
        for v in edges:
            in_deg[v] += 1

        ans = [0] * n
        q = deque(i for i in range(n) if in_deg[i] == 0)
        on_cycle = [True] * n

        while q:
            u = q.popleft()
            on_cycle[u] = False
            v = edges[u]
            in_deg[v] -= 1
            if in_deg[v] == 0:
                q.append(v)

        # 标记环节点，计算环的大小
        visited = [False] * n
        for i in range(n):
            if on_cycle[i] and not visited[i]:
                cur = i
                cycle = []
                while not visited[cur]:
                    visited[cur] = True
                    cycle.append(cur)
                    cur = edges[cur]
                for node in cycle:
                    ans[node] = len(cycle)

        # 从链（非环节点）传播答案
        # 按"距环的距离"从近到远（反向遍历）
        # 重建入度（只统计非环节点）
        in_deg2 = [0] * n
        for i in range(n):
            if not on_cycle[i]:
                in_deg2[edges[i]] += 1

        q = deque(i for i in range(n) if not on_cycle[i] and in_deg2[i] == 0)
        while q:
            u = q.popleft()
            v = edges[u]
            ans[u] = ans[v] + 1
            in_deg2[v] -= 1
            if not on_cycle[v] and in_deg2[v] == 0:
                q.append(v)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，拓扑排序和环处理各 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 函数图（每节点一条出边）必然有环
2. 拓扑排序找非环节点（入度为 0 的先处理）
3. 环上节点答案 = 环的长度；链上节点答案 = 链长 + 环节点答案

## 易错点

1. 递归解法需要提高递归深度限制（n 可达 10^5）
2. 处理链节点时，必须从距环最近的开始（确保 `ans[edges[u]]` 已计算）
3. 环节点的 visited 标记要单独处理，不能和链节点混用
