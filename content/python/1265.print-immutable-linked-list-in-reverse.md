## 题目描述

给你一个不可变的链表，请你以逆序打印每个节点的值。

你只能使用以下接口访问链表（**不能直接访问 `ImmutableListNode`**）：
- `ImmutableListNode.printValue()`：打印当前节点的值
- `ImmutableListNode.getNext()`：返回下一个节点

**注意：**
- 不能修改链表
- 不能使用 `prev` 指针（链表不可变）
- 每个节点只能向前访问（单向）

**示例 1：**
```
输入：head = [1,2,3,4]
输出：4 3 2 1
```

**示例 2：**
```
输入：head = [0,-4,-1,3,-5]
输出：-5 3 -1 -4 0
```

**示例 3：**
```
输入：head = [-2,0,6,4,4,-6]
输出：-6 4 4 6 0 -2
```

**提示：**
- 链表的长度在 `[1, 1000]` 之间
- 每个节点的值在 `[-1000, 1000]` 之间

**ImmutableListNode 接口定义（仅供理解）：**
```python
class ImmutableListNode:
    def printValue(self) -> None: ...  # 打印当前节点值
    def getNext(self) -> 'ImmutableListNode': ...  # 返回下一个节点，末尾返回 None
```

---

## 解题思路

由于链表不可变且只能单向访问，我们无法直接从尾部遍历。核心思路是：**先走到末尾，再回退时打印**。

主要有三种方法：

1. **递归法**：利用函数调用栈天然实现"先进后出"，递归到末尾后在回溯时打印。
2. **辅助栈**：遍历链表将节点存入栈中，再依次弹出打印。
3. **两次遍历（求长度）**：先求出链表长度 n，然后用双指针或嵌套循环的方式，每次找到第 n-i 个节点打印。

---

## Python 代码实现

### 方法一：递归法（推荐）

**思路：** 递归调用，先走到末尾，再从末尾往回打印。利用系统调用栈作为隐式栈。

```python
class Solution:
    def printLinkedListInReverse(self, head: 'ImmutableListNode') -> None:
        # 递归终止条件：到达末尾
        if head is None:
            return
        # 先递归到下一个节点
        self.printLinkedListInReverse(head.getNext())
        # 回溯时打印当前节点值（此时已到达链表末尾并开始返回）
        head.printValue()
```

**图解：**
```
链表：1 -> 2 -> 3 -> 4 -> None

递归调用栈（向下）：
  print(1) -> print(2) -> print(3) -> print(4) -> print(None) 返回
回溯打印（向上）：
  打印 4 -> 打印 3 -> 打印 2 -> 打印 1
```

**优点：** 代码简洁，思路清晰。
**缺点：** 链表很长时（约 1000 层）可能导致递归栈溢出（Python 默认递归深度约 1000）。

---

### 方法二：辅助栈（迭代法，推荐）

**思路：** 用一个列表模拟栈，遍历链表将每个节点压栈，最后依次弹出打印。

```python
class Solution:
    def printLinkedListInReverse(self, head: 'ImmutableListNode') -> None:
        stack = []
        # 第一步：遍历链表，将所有节点压栈
        node = head
        while node is not None:
            stack.append(node)
            node = node.getNext()
        # 第二步：弹出栈顶元素依次打印（后进先出 = 逆序）
        while stack:
            stack.pop().printValue()
```

**图解：**
```
链表：1 -> 2 -> 3 -> 4

压栈过程：stack = [node1, node2, node3, node4]
弹出过程：node4.printValue() -> node3.printValue() -> ...
输出：4 3 2 1
```

**优点：** 不受递归深度限制，更稳定。
**缺点：** 需要 O(n) 额外空间。

---

### 方法三：双指针求长度法（不使用额外存储节点）

**思路：** 先遍历一次求出链表长度 n，然后打印第 n 个节点，再打印第 n-1 个节点，依次类推。每次都从头走到目标位置。

```python
class Solution:
    def printLinkedListInReverse(self, head: 'ImmutableListNode') -> None:
        # 第一步：求链表长度
        length = 0
        node = head
        while node is not None:
            length += 1
            node = node.getNext()

        # 第二步：逐一从末尾往前打印
        # 每次找到第 i 个节点（i 从 length 到 1）
        for i in range(length, 0, -1):
            node = head
            # 走 i-1 步到达第 i 个节点（0-indexed: 走 i-1 步）
            for _ in range(i - 1):
                node = node.getNext()
            node.printValue()
```

**优点：** 空间复杂度 O(1)（不存储节点）。
**缺点：** 时间复杂度 O(n^2)，性能较差，不推荐用于大输入。

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一：递归 | O(n) | O(n) | 递归栈深度为 n |
| 方法二：辅助栈 | O(n) | O(n) | 存储 n 个节点引用 |
| 方法三：双指针 | O(n^2) | O(1) | 每次从头走到目标位置 |

---

## 关键点总结

1. 链表不可变，只能单向前进，无法直接逆序访问——需要借助"先进后出"的数据结构。
2. 递归的本质就是利用系统调用栈，每次调用压栈，返回时弹栈，天然实现逆序。
3. 方法二（辅助栈）是最实用的方案，不受 Python 递归深度限制（Python 默认 sys.setrecursionlimit 约 1000）。
4. 方法三用 O(1) 空间换取 O(n^2) 时间，当空间极其有限时可以考虑。
5. 此题是"利用栈解决逆序问题"的经典示范，与逆序打印相关的题目都可以用类似思路。

---

## 易错点

1. **递归终止条件**：`if head is None: return` 必须放在最前面，否则对空链表会报错。
2. **Python 递归深度限制**：链表长度接近 1000 时，方法一可能触发 `RecursionError`。面试中建议优先使用方法二（迭代栈）。
3. **方法三的步数计算**：从 head 走到第 i 个节点（1-indexed）需要走 `i-1` 步，不要写成 `i` 步。
4. **只能调用接口**：不能尝试 `head.val` 或 `head.next`，只能用 `printValue()` 和 `getNext()`。
