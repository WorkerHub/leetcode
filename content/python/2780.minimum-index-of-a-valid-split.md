## 题目描述

如果元素 `x` 在一个长度为 `m` 的数组中出现超过 `m/2` 次（即超过半数），则称它为该数组的 **支配元素**。

给你一个下标从 **0** 开始的整数数组 `nums`，其中有支配元素 `x`。

找到一个 **最小下标** `i`（`0 <= i < nums.length - 1`），使得：
- `nums[0..i]` 的支配元素是 `x`
- `nums[i+1..n-1]` 的支配元素也是 `x`

返回最小下标，若不存在返回 -1。

**示例 1：**
```
输入：nums = [1,2,2,2]
输出：2
解释：x=2，在 [1,2,2] 和 [2] 中都是支配元素
```

**示例 2：**
```
输入：nums = [2,1,3,1,1,1,7,1,2,1]
输出：4
```

**提示：**
- `1 <= nums.length <= 10^5`

## 解题思路

首先找到整体的支配元素 `x`（出现次数 > n/2），然后遍历每个分割点，检查前缀和后缀中 `x` 是否超半数。

## Python 代码实现

### 方法一：Boyer-Moore 投票 + 前缀计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        n = len(nums)
        # 找支配元素
        cnt = Counter(nums)
        dom = max(cnt, key=cnt.get)
        total = cnt[dom]

        # 遍历分割点
        prefix_cnt = 0
        for i in range(n - 1):
            if nums[i] == dom:
                prefix_cnt += 1
            left_len = i + 1
            right_cnt = total - prefix_cnt
            right_len = n - left_len
            # 检查前缀和后缀中 dom 是否超半数
            if prefix_cnt * 2 > left_len and right_cnt * 2 > right_len:
                return i

        return -1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（Counter）

## 关键点总结

1. 先用 Counter 找整体支配元素
2. 遍历分割点，用前缀和计算前缀出现次数，后缀 = 总次数 - 前缀次数
3. 支配元素条件：出现次数 * 2 > 长度

## 易错点

1. 分割点 `i` 的范围是 `[0, n-2]`（前后各至少 1 个元素）
2. 严格超过半数：`count * 2 > length`
