## 题目描述

给你一个二维数组 `access_times`，其中 `access_times[i] = [worker_name, access_time]` 表示员工 `worker_name` 在 `access_time` 时刻进行了访问（24 小时制，格式为 `HHMM`）。

若一个员工在**任意一小时内**（即任意 60 分钟的时间窗口内）进行了**不少于 3 次**访问，则该员工被视为**高访问员工**。

返回所有高访问员工的名单（顺序不限）。

**示例 1：**
```
输入：access_times = [["a","0549"],["b","0457"],["a","0532"],["a","0621"],["b","0540"]]
输出：["a"]
解释：员工 a 在 0532, 0549, 0621 各访问一次，0532 到 0621 差 49 分钟，3 次在 60 分钟内
```

**提示：**
- `1 <= access_times.length <= 100`
- `access_times[i].length == 2`
- `1 <= access_times[i][0].length <= 10`
- `access_times[i][1].length == 4`
- 时间格式为 HHMM，`00 <= HH <= 23`，`00 <= MM <= 59`

## 解题思路

按员工分组，对每个员工的访问时间排序。

对排序后的时间，用滑动窗口检查是否存在连续 3 个时间点中，最晚的时间 - 最早的时间 < 60 分钟。

## Python 代码实现

### 方法一：哈希表 + 排序 + 滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findHighAccessEmployees(self, access_times: List[List[str]]) -> List[str]:
        # 按员工分组并转换时间为分钟数
        employee_times = defaultdict(list)
        for name, time in access_times:
            hh, mm = int(time[:2]), int(time[2:])
            minutes = hh * 60 + mm
            employee_times[name].append(minutes)

        result = []
        for name, times in employee_times.items():
            times.sort()
            n = len(times)
            # 检查是否存在 3 个访问时间在 60 分钟内
            for i in range(n - 2):
                if times[i + 2] - times[i] < 60:
                    result.append(name)
                    break

        return result
```

### 方法二：直接排序后检查

```python
from typing import List
from collections import defaultdict

class Solution:
    def findHighAccessEmployees(self, access_times: List[List[str]]) -> List[str]:
        groups = defaultdict(list)
        for name, t in access_times:
            groups[name].append(int(t))  # 直接用 HHMM 的整数形式

        def to_minutes(t):
            return (t // 100) * 60 + (t % 100)

        result = []
        for name, times in groups.items():
            min_times = sorted(to_minutes(t) for t in times)
            for i in range(len(min_times) - 2):
                if min_times[i + 2] - min_times[i] < 60:
                    result.append(name)
                    break

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，哈希表存储

## 关键点总结

1. 将时间字符串转换为分钟数便于比较
2. 排序后，检查相邻三个时间中首尾差是否 < 60（严格小于，因为是任意 60 分钟窗口）
3. 一旦找到一个满足条件的三元组，该员工就是高访问员工，直接 break

## 易错点

1. 时间差 < 60（不是 <= 60），因为窗口是"一小时内"（不含边界）
2. 需要对时间进行排序，不能直接用原始顺序
3. 员工可能只有 1-2 次访问，需要至少 3 次才可能是高访问员工
