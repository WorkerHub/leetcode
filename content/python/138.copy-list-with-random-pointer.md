## 题目描述

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。

构造这个链表的**深拷贝**。深拷贝应该正好由 `n` 个**全新**节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点**。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y`。那么在复制链表中对应的两个节点 `x` 和 `y`，同样有 `x.random --> y`。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：
- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null`。

你的代码**只**接受原链表的头节点 `head` 作为传入参数。

**示例 1：**
```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**示例 2：**
```
输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]
```

**示例 3：**
```
输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]
```

**提示：**
- `0 <= n <= 1000`
- `-10^4 <= Node.val <= 10^4`
- `Node.random` 为 `null` 或指向链表中的节点

## 解题思路

这道题的难点在于 `random` 指针的处理，因为在复制节点时，`random` 指向的节点可能还未创建。

**核心思想：建立原节点与新节点的映射关系**

### 方法一：哈希表映射
1. **第一次遍历**：创建所有新节点，建立 `原节点 → 新节点` 的映射
2. **第二次遍历**：设置新节点的 `next` 和 `random` 指针，通过哈希表查找对应关系

### 方法二：节点拆分（不使用额外空间）
1. **第一步**：在每个原节点后面插入复制节点
   - 原链表：`1 → 2 → 3`
   - 变成：`1 → 1' → 2 → 2' → 3 → 3'`
2. **第二步**：设置复制节点的 `random` 指针
   - `node.next.random = node.random.next`
3. **第三步**：拆分链表，恢复原链表并得到新链表

## Python 代码实现

### 方法一：哈希表（推荐，易理解）

```python
from typing import Optional

# Definition for a Node.
class Node:
    def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
        self.val = int(x)
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head: Optional['Node']) -> Optional['Node']:
        if not head:
            return None
        
        # 哈希表：原节点 -> 新节点
        node_map = {}
        
        # 第一次遍历：创建所有新节点
        curr = head
        while curr:
            node_map[curr] = Node(curr.val)
            curr = curr.next
        
        # 第二次遍历：设置新节点的 next 和 random 指针
        curr = head
        while curr:
            # 设置 next 指针
            if curr.next:
                node_map[curr].next = node_map[curr.next]
            # 设置 random 指针
            if curr.random:
                node_map[curr].random = node_map[curr.random]
            curr = curr.next
        
        return node_map[head]
```

### 方法二：哈希表（一次遍历优化版）

```python
from typing import Optional

class Solution:
    def copyRandomList(self, head: Optional['Node']) -> Optional['Node']:
        if not head:
            return None
        
        # 哈希表：原节点 -> 新节点
        node_map = {}
        
        def get_cloned_node(node):
            """获取或创建克隆节点"""
            if not node:
                return None
            if node not in node_map:
                node_map[node] = Node(node.val)
            return node_map[node]
        
        # 遍历原链表
        curr = head
        while curr:
            # 获取或创建当前节点的克隆
            cloned = get_cloned_node(curr)
            # 设置 next 和 random
            cloned.next = get_cloned_node(curr.next)
            cloned.random = get_cloned_node(curr.random)
            curr = curr.next
        
        return node_map[head]
```

### 方法三：节点拆分（O(1) 空间）

```python
from typing import Optional

class Solution:
    def copyRandomList(self, head: Optional['Node']) -> Optional['Node']:
        if not head:
            return None
        
        # 第一步：在每个节点后面插入复制节点
        # 1 -> 2 -> 3  变成  1 -> 1' -> 2 -> 2' -> 3 -> 3'
        curr = head
        while curr:
            cloned = Node(curr.val, curr.next)
            curr.next = cloned
            curr = cloned.next
        
        # 第二步：设置复制节点的 random 指针
        curr = head
        while curr:
            if curr.random:
                curr.next.random = curr.random.next
            curr = curr.next.next
        
        # 第三步：拆分链表
        curr = head
        cloned_head = head.next
        while curr:
            cloned = curr.next
            curr.next = cloned.next
            if cloned.next:
                cloned.next = cloned.next.next
            curr = curr.next
        
        return cloned_head
```

### 方法四：递归 + 哈希表

```python
from typing import Optional

class Solution:
    def __init__(self):
        self.visited = {}
    
    def copyRandomList(self, head: Optional['Node']) -> Optional['Node']:
        if not head:
            return None
        
        # 如果已经访问过，直接返回克隆节点
        if head in self.visited:
            return self.visited[head]
        
        # 创建新节点
        node = Node(head.val)
        self.visited[head] = node
        
        # 递归复制 next 和 random
        node.next = self.copyRandomList(head.next)
        node.random = self.copyRandomList(head.random)
        
        return node
```

## 复杂度分析

### 方法一、二、四：哈希表
- **时间复杂度**：O(n)，需要遍历链表 1-2 次
- **空间复杂度**：O(n)，哈希表存储 n 个节点的映射

### 方法三：节点拆分
- **时间复杂度**：O(n)，需要遍历链表 3 次
- **空间复杂度**：O(1)，不使用额外空间（不考虑返回值）

## 图解示例

以 `head = [[7,null],[13,0],[11,4],[10,2],[1,0]]` 为例：

**原链表：**
```
节点:  7  →  13  →  11  →  10  →  1
random: ↓    ↓     ↓      ↓     ↓
       null  7     1      11    7
```

**方法三（节点拆分）过程：**

**步骤1：插入复制节点**
```
7 → 7' → 13 → 13' → 11 → 11' → 10 → 10' → 1 → 1'
```

**步骤2：设置 random（以节点 13 为例）**
```
原节点 13.random 指向 7
复制节点 13'.random = 13.random.next = 7'
```

**步骤3：拆分链表**
```
原链表: 7 → 13 → 11 → 10 → 1
新链表: 7' → 13' → 11' → 10' → 1'
```

## 关键点总结

1. **深拷贝的理解**：新链表的所有节点和指针都是新创建的，不能指向原链表
2. **映射关系的建立**：哈希表是最直观的方式，建立原节点到新节点的映射
3. **节点拆分技巧**：巧妙地将新节点插入原节点后面，利用位置关系代替哈希表
4. **指针操作的顺序**：拆分链表时要注意先保存指针再修改，避免丢失引用
5. **边界情况**：空链表、只有一个节点、random 指向 null 等情况

## 易错点

1. **忘记处理 random 为 null**：设置 random 指针前要判断是否为 null
2. **拆分链表时丢失节点**：要先保存 `next` 指针再修改
3. **死循环**：节点拆分时，步进要用 `curr.next.next` 而不是 `curr.next`
4. **修改原链表**：方法三最后要恢复原链表的结构
5. **哈希表键的类型**：Python 中可以直接用节点对象作为键
