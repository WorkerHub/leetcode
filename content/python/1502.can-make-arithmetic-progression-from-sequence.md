## 题目描述

给你一个数字数组 `arr`，如果可以重新排列数组使其构成等差数列，请你返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：arr = [3,5,1]
输出：true
解释：对数组重新排序得到 [1,3,5] 或者 [5,3,1]，任意一个都是等差数列。
```

**示例 2：**
```
输入：arr = [1,2,4]
输出：false
解释：无法重新排列数组使其成为等差数列。
```

**提示：**
- `2 <= arr.length <= 1000`
- `-10^6 <= arr[i] <= 10^6`

## 解题思路

### 方法一：排序后检验（推荐）

排序后，等差数列要求相邻元素之差相同。
1. 对数组排序
2. 计算 `arr[1] - arr[0]` 作为公差 `d`
3. 遍历检验每对相邻元素之差是否都等于 `d`

### 方法二：数学方法（不排序）

等差数列排序后的最小值是 `min_val`，最大值是 `max_val`，公差是 `(max_val - min_val) / (n - 1)`。
利用集合检验所有应该出现的值是否都在数组中，且公差能被 `(n-1)` 整除。

## 代码实现

### 方法一：排序后逐一检验（推荐）

```python
from typing import List

class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        # 对数组排序
        arr.sort()
        # 计算第一对相邻元素的差作为公差
        d = arr[1] - arr[0]
        # 检验每对相邻元素是否都有相同的差
        for i in range(2, len(arr)):
            if arr[i] - arr[i - 1] != d:
                return False
        return True
```

### 方法二：集合验证（不排序）

```python
from typing import List

class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        n = len(arr)
        min_val = min(arr)
        max_val = max(arr)
        # 公差必须能整除
        if (max_val - min_val) % (n - 1) != 0:
            return False
        d = (max_val - min_val) // (n - 1)
        # 构造等差数列的元素集合
        expected = set(min_val + i * d for i in range(n))
        # 判断数组元素是否与期望集合完全一致
        return set(arr) == expected and len(arr) == len(set(arr))
```

### 方法三：Python 一行写法

```python
from typing import List

class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        # 排序后检验相邻差是否全部相同
        arr.sort()
        diffs = [arr[i+1] - arr[i] for i in range(len(arr)-1)]
        return len(set(diffs)) == 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（排序） | O(N log N) | O(1) |
| 方法二（集合） | O(N) | O(N) |
| 方法三（一行） | O(N log N) | O(N) |

## 关键点总结

1. 等差数列排序后，相邻元素差值相同
2. 排序是最直观的方法，时间复杂度由排序主导
3. 集合方法可以 O(N) 但需要额外空间
4. 注意数组长度为 2 时，任意两元素都能构成等差数列

## 易错点

- 方法二中，若 `(max - min) % (n-1) != 0`，不能构成等差数列要提前返回 `False`
- 数组中有重复元素时（公差为 0），集合方法要额外检查 `len(arr) == len(set(arr))`，或者方法二的集合大小要与 n 一致
