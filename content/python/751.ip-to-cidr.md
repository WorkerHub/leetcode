## 题目描述

给定一个起始 IP 地址 `ip` 和一个我们需要包含的 IP 数量 `n`，返回用列表（最小可能的长度）表示的 CIDR 块的范围。

CIDR 块是包含 IP 地址的字符串，后跟斜杠和前缀长度。例如："123.45.67.89/20"。该前缀长度 "20" 表示前面是 32 位中的前 20 个公共位。

**示例 1:**
```
输入: ip = "255.0.0.7", n = 10
输出: ["255.0.0.7/32","255.0.0.8/29","255.0.0.16/32"]
解释:
转换为二进制，255.0.0.7 -> 11111111 00000000 00000000 00000111
所转换的 IP 地址为：
11111111 00000000 00000000 00000111  255.0.0.7
11111111 00000000 00000000 00001000  255.0.0.8
11111111 00000000 00000000 00001111  255.0.0.15
11111111 00000000 00000000 00010000  255.0.0.16
```

## 解题思路

这道题的核心是理解 CIDR 表示法和如何将连续的 IP 地址范围转换为最少的 CIDR 块。

**关键观察：**
1. IP 地址可以转换为 32 位整数
2. CIDR 块的大小必须是 2 的幂次
3. CIDR 块的起始地址必须是其大小的倍数
4. 我们需要贪心地选择最大可能的 CIDR 块

**算法流程：**
1. 将 IP 地址转换为整数
2. 对于剩余需要覆盖的 IP 数量：
   - 找到当前 IP 地址最右边的 1（这决定了最大可能的块大小）
   - 取该大小和剩余数量的最小值
   - 生成对应的 CIDR 块
   - 更新当前 IP 和剩余数量

## Python 代码实现

### 方法一：位运算 + 贪心（推荐）⭐

```python
from typing import List

class Solution:
    def ipToCIDR(self, ip: str, n: int) -> List[str]:
        # 将 IP 地址转换为整数
        def ip_to_int(ip: str) -> int:
            parts = list(map(int, ip.split('.')))
            return (parts[0] << 24) + (parts[1] << 16) + (parts[2] << 8) + parts[3]
        
        # 将整数转换为 IP 地址
        def int_to_ip(num: int) -> str:
            return f"{(num >> 24) & 255}.{(num >> 16) & 255}.{(num >> 8) & 255}.{num & 255}"
        
        result = []
        start = ip_to_int(ip)
        
        while n > 0:
            # 找到起始地址最右边的 1 的位置
            # 这决定了能创建的最大 CIDR 块
            # 例如：如果地址是 8 (1000)，最右边的 1 在位置 3，可以创建大小为 2^3 = 8 的块
            mask = max(33 - (start & -start).bit_length(), 33 - n.bit_length())
            
            # 添加当前 CIDR 块
            result.append(f"{int_to_ip(start)}/{mask}")
            
            # 更新起始地址和剩余数量
            block_size = 1 << (32 - mask)
            start += block_size
            n -= block_size
        
        return result
```

### 方法二：简化版本

```python
class Solution:
    def ipToCIDR(self, ip: str, n: int) -> List[str]:
        def ip_to_long(ip):
            # 将 IP 转换为长整数
            parts = ip.split('.')
            return sum(int(part) << (8 * (3 - i)) for i, part in enumerate(parts))
        
        def long_to_ip(num):
            # 将长整数转换为 IP
            return '.'.join(str((num >> (8 * (3 - i))) & 255) for i in range(4))
        
        start = ip_to_long(ip)
        result = []
        
        while n > 0:
            # 找到最右边的 1 的位置（从右往左数）
            trailing_zeros = (start & -start).bit_length() - 1
            
            # 计算可以创建的最大块大小
            max_block = 1 << trailing_zeros
            
            # 取最大块和剩余数量的较小值
            current_block = max_block
            mask = 32 - trailing_zeros
            
            # 如果剩余数量小于最大块，需要调整
            while current_block > n:
                current_block >>= 1
                mask += 1
            
            result.append(f"{long_to_ip(start)}/{mask}")
            start += current_block
            n -= current_block
        
        return result
```

## 复杂度分析

- **时间复杂度：** O(log n)，其中 n 是需要覆盖的 IP 数量。每次迭代至少覆盖一个 IP，最坏情况下需要 log n 次迭代（每次覆盖 1 个 IP）。
- **空间复杂度：** O(1)，只使用常数额外空间（结果列表不计入）。

## 关键点总结

1. **IP 地址转换：** 理解如何在 IP 字符串和 32 位整数之间转换
2. **位运算技巧：** `x & -x` 可以获取最右边的 1 及其右边的所有 0
3. **CIDR 块规则：** 块大小必须是 2 的幂，起始地址必须对齐
4. **贪心策略：** 每次选择最大可能的 CIDR 块
5. **边界处理：** 确保块大小不超过剩余需要覆盖的数量

## 易错点

1. **IP 转换错误：** 注意字节顺序和位移方向
2. **块大小计算：** 要同时考虑地址对齐和剩余数量
3. **掩码计算：** CIDR 掩码是 32 减去块大小的对数（以 2 为底）
4. **整数溢出：** Python 中整数不会溢出，但其他语言需要注意
5. **边界情况：** n = 1 时要正确处理
