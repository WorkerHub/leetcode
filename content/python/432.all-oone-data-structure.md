## 题目描述

请你设计一个用于存储字符串计数的数据结构，并能够返回计数最小和最大的字符串。

实现 `AllOne` 类：

- `AllOne()` 初始化数据结构的对象。
- `inc(String key)` 字符串 `key` 的计数增加 1。如果数据结构中尚不存在 `key`，那么插入计数为 1 的 `key`。
- `dec(String key)` 字符串 `key` 的计数减少 1。如果 `key` 的计数在减少后为 0，那么需要将这个 `key` 从数据结构中删除。测试用例保证：在减少计数前，`key` 存在于数据结构中。
- `getMaxKey()` 返回任意一个计数最大的字符串。如果没有元素存在，返回一个空字符串 `""`。
- `getMinKey()` 返回任意一个计数最小的字符串。如果没有元素存在，返回一个空字符串 `""`。

**注意**：每个函数都应当满足 O(1) 平均时间复杂度。

**示例：**
```
输入
["AllOne", "inc", "inc", "getMaxKey", "getMinKey", "inc", "getMaxKey", "getMinKey"]
[[], ["hello"], ["hello"], [], [], ["leet"], [], []]
输出
[null, null, null, "hello", "hello", null, "hello", "leet"]

解释
AllOne allOne = new AllOne();
allOne.inc("hello");
allOne.inc("hello");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "hello"
allOne.inc("leet");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "leet"
```

**提示：**
- `1 <= key.length <= 10`
- `key` 由小写英文字母组成
- 测试用例保证：在每次调用 `dec` 时，数据结构中总存在 `key`
- 最多调用 `inc`、`dec`、`getMaxKey` 和 `getMinKey` 方法 `5 * 10^4` 次

## 解题思路

这道题要求实现一个全 O(1) 的数据结构。核心思想是使用哈希表 + 双向链表。

**关键观察：**
1. 需要 O(1) 时间获取最大和最小计数的 key
2. 需要 O(1) 时间增加和减少计数
3. 可以使用双向链表维护计数的有序性
4. 使用哈希表快速定位 key 所在的节点

**数据结构设计：**
1. **Bucket（桶）**：存储相同计数的所有 key
   - count: 计数值
   - keys: 该计数下的所有 key（使用集合）
   
2. **双向链表**：按计数值升序连接所有桶
   - head -> 计数最小的桶 -> ... -> 计数最大的桶 -> tail

3. **哈希表**：
   - key_bucket: key -> 所在的桶节点
   
**算法流程：**
- `inc(key)`: 
  1. 如果 key 不存在，加入计数为 1 的桶
  2. 如果 key 存在，从当前桶移到下一个桶（count+1）
  
- `dec(key)`:
  1. 从当前桶移到上一个桶（count-1）
  2. 如果 count 变为 0，删除 key

- `getMaxKey()`: 返回尾部桶中的任意 key
- `getMinKey()`: 返回头部桶中的任意 key

## Python 代码实现

### 方法一：双向链表 + 哈希表 ⭐ 推荐

```python
class Bucket:
    """存储相同计数的所有 key"""
    def __init__(self, count):
        self.count = count
        self.keys = set()
        self.prev = None
        self.next = None

class AllOne:
    def __init__(self):
        # 哨兵节点
        self.head = Bucket(0)
        self.tail = Bucket(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        
        # key -> Bucket 的映射
        self.key_bucket = {}
    
    def _insert_bucket_after(self, new_bucket, prev_bucket):
        """在 prev_bucket 后插入 new_bucket"""
        new_bucket.prev = prev_bucket
        new_bucket.next = prev_bucket.next
        prev_bucket.next.prev = new_bucket
        prev_bucket.next = new_bucket
    
    def _remove_bucket(self, bucket):
        """移除空桶"""
        bucket.prev.next = bucket.next
        bucket.next.prev = bucket.prev
    
    def inc(self, key: str) -> None:
        if key in self.key_bucket:
            # key 已存在，移动到下一个桶
            bucket = self.key_bucket[key]
            new_count = bucket.count + 1
            
            # 检查下一个桶是否是 count+1
            if bucket.next.count != new_count:
                # 创建新桶
                new_bucket = Bucket(new_count)
                self._insert_bucket_after(new_bucket, bucket)
            else:
                new_bucket = bucket.next
            
            # 移动 key
            new_bucket.keys.add(key)
            self.key_bucket[key] = new_bucket
            
            # 从旧桶移除
            bucket.keys.remove(key)
            if not bucket.keys:
                self._remove_bucket(bucket)
        else:
            # key 不存在，加入计数为 1 的桶
            if self.head.next.count != 1:
                # 创建计数为 1 的桶
                new_bucket = Bucket(1)
                self._insert_bucket_after(new_bucket, self.head)
            else:
                new_bucket = self.head.next
            
            new_bucket.keys.add(key)
            self.key_bucket[key] = new_bucket
    
    def dec(self, key: str) -> None:
        bucket = self.key_bucket[key]
        
        if bucket.count == 1:
            # 计数变为 0，删除 key
            del self.key_bucket[key]
        else:
            # 移动到上一个桶
            new_count = bucket.count - 1
            
            # 检查上一个桶是否是 count-1
            if bucket.prev.count != new_count:
                # 创建新桶
                new_bucket = Bucket(new_count)
                self._insert_bucket_after(new_bucket, bucket.prev)
            else:
                new_bucket = bucket.prev
            
            # 移动 key
            new_bucket.keys.add(key)
            self.key_bucket[key] = new_bucket
        
        # 从旧桶移除
        bucket.keys.remove(key)
        if not bucket.keys:
            self._remove_bucket(bucket)
    
    def getMaxKey(self) -> str:
        if self.tail.prev == self.head:
            return ""
        return next(iter(self.tail.prev.keys))
    
    def getMinKey(self) -> str:
        if self.head.next == self.tail:
            return ""
        return next(iter(self.head.next.keys))
```

### 方法二：简化版（使用 OrderedDict）

```python
from collections import defaultdict, OrderedDict

class AllOne:
    def __init__(self):
        self.key_count = {}  # key -> count
        self.count_keys = defaultdict(set)  # count -> keys
        self.min_count = 0
        self.max_count = 0
    
    def inc(self, key: str) -> None:
        count = self.key_count.get(key, 0)
        new_count = count + 1
        
        # 更新 key_count
        self.key_count[key] = new_count
        
        # 从旧计数中移除
        if count > 0:
            self.count_keys[count].remove(key)
            if not self.count_keys[count]:
                del self.count_keys[count]
        
        # 加入新计数
        self.count_keys[new_count].add(key)
        
        # 更新最小最大计数
        if count == self.min_count and not self.count_keys[count]:
            self.min_count = new_count
        elif new_count < self.min_count or self.min_count == 0:
            self.min_count = new_count
        
        if new_count > self.max_count:
            self.max_count = new_count
    
    def dec(self, key: str) -> None:
        count = self.key_count[key]
        
        # 从旧计数中移除
        self.count_keys[count].remove(key)
        if not self.count_keys[count]:
            del self.count_keys[count]
        
        if count == 1:
            # 删除 key
            del self.key_count[key]
        else:
            # 移动到新计数
            new_count = count - 1
            self.key_count[key] = new_count
            self.count_keys[new_count].add(key)
        
        # 更新最小最大计数
        if count == self.max_count and not self.count_keys[count]:
            self.max_count = max(self.count_keys.keys()) if self.count_keys else 0
        
        if count == self.min_count and not self.count_keys[count]:
            self.min_count = min(self.count_keys.keys()) if self.count_keys else 0
    
    def getMaxKey(self) -> str:
        if self.max_count == 0:
            return ""
        return next(iter(self.count_keys[self.max_count]))
    
    def getMinKey(self) -> str:
        if self.min_count == 0:
            return ""
        return next(iter(self.count_keys[self.min_count]))
```

## 复杂度分析

**方法一：双向链表**
- 时间复杂度：所有操作都是 O(1)
  - inc/dec: O(1) 插入/删除操作
  - getMaxKey/getMinKey: O(1) 访问头尾
- 空间复杂度：O(n)，n 是不同 key 的数量

**方法二：简化版**
- 时间复杂度：
  - inc: O(1) 平均
  - dec: O(n) 最坏（需要查找新的最大/最小值）
  - getMaxKey/getMinKey: O(1)
- 空间复杂度：O(n)

## 关键点总结

1. **双向链表设计**：按计数值升序维护桶节点
2. **桶的概念**：相同计数的 key 放在同一个桶中
3. **哨兵节点**：简化边界处理
4. **空桶删除**：桶中没有 key 时要及时删除
5. **O(1) 保证**：通过双向链表和哈希表实现常数时间操作

## 易错点

1. **空桶处理**：桶为空时必须从链表中移除
2. **边界情况**：第一个/最后一个桶的特殊处理
3. **next/iter**：从集合中获取任意元素用 `next(iter(set))`
4. **哨兵节点**：使用哨兵简化插入和删除逻辑
5. **链表操作**：双向链表的插入和删除要更新两个方向的指针
