## 题目描述

有一个 `m x n` 的二元网格 `grid`，其中 `1` 表示砖块，`0` 表示空白。砖块 **稳定**（不会掉落）的前提是：
- 砖块直接连接到网格的顶部，或者
- 至少有一块相邻（4 个方向之一）砖块 **稳定** 不会掉落时

给你一个数组 `hits`，这是需要依次消除砖块的位置。每当消除 `hits[i] = (rowi, coli)` 位置上的砖块时，对应位置的砖块（若存在）会消失，然后其他的砖块可能因为这一消除操作而 **掉落**。

返回一个数组 `result`，其中 `result[i]` 表示第 `i` 次消除操作对应掉落的砖块数目。

**注意**：消除可能指向是没有砖块的空白位置，如果发生这种情况，则没有砖块掉落。

**示例 1:**
```
输入: grid = [[1,0,0,0],[1,1,1,0]], hits = [[1,0]]
输出: [2]
解释: 网格开始为:
[[1,0,0,0],
 [1,1,1,0]]
消除 (1,0) 处的砖块，得到网格:
[[1,0,0,0],
 [0,1,1,0]]
两个砖块不再稳定，因为它们不再与顶部相连，也不再与另一个稳定的砖块相连，因此它们将掉落。
得到的网格为:
[[1,0,0,0],
 [0,0,0,0]]
因此，结果为 [2]。
```

**示例 2:**
```
输入: grid = [[1,0,0,0],[1,1,0,0]], hits = [[1,1],[1,0]]
输出: [0,0]
解释: 网格开始为:
[[1,0,0,0],
 [1,1,0,0]]
消除 (1,1) 处的砖块，得到网格:
[[1,0,0,0],
 [1,0,0,0]]
剩下的砖块都很稳定，所以不会掉落。网格保持不变:
[[1,0,0,0],
 [1,0,0,0]]
接下来消除 (1,0) 处的砖块，得到网格:
[[1,0,0,0],
 [0,0,0,0]]
剩下的砖块仍然是稳定的，所以不会有砖块掉落。
因此，结果为 [0,0]。
```

**提示:**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `grid[i][j]` 为 `0` 或 `1`
- `1 <= hits.length <= 4 * 10^4`
- `hits[i].length == 2`
- `0 <= xi <= m - 1`
- `0 <= yi <= n - 1`
- 所有 `(xi, yi)` 互不相同

## 解题思路

这是一道经典的**逆向思维 + 并查集**问题。

**核心思想**：
- 正向模拟每次敲击很困难，因为需要检查大量砖块是否掉落
- **逆向思考**：从最终状态开始，倒序添加砖块，计算每次添加砖块导致多少砖块重新稳定

**算法流程**：

1. **预处理**：先把所有要敲击的砖块标记为消除（设为 2）
2. **构建最终状态的并查集**：
   - 创建一个虚拟节点代表"顶部"
   - 将所有稳定的砖块连接到并查集中
   - 第一行的砖块连接到虚拟顶部节点
3. **逆序恢复砖块**：
   - 从后往前遍历 hits 数组
   - 每次恢复一个砖块，检查与顶部连接的砖块数量变化
   - 变化量 - 1 就是因为这次敲击掉落的砖块数

**关键点**：
- 使用并查集维护连通性和大小
- 虚拟节点技巧：添加一个额外节点代表顶部
- 逆向思维：从结果倒推原因

## Python 代码实现

### 方法一：并查集 + 逆向思维（推荐）⭐

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return
        # 将 y 合并到 x
        self.parent[root_y] = root_x
        self.size[root_x] += self.size[root_y]
    
    def get_size(self, x):
        return self.size[self.find(x)]

class Solution:
    def hitBricks(self, grid: List[List[int]], hits: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        
        # 将二维坐标转换为一维
        def pos(i, j):
            return i * n + j
        
        # 复制网格，标记要敲击的位置
        status = [row[:] for row in grid]
        for i, j in hits:
            status[i][j] = 0
        
        # 创建并查集，额外增加一个虚拟顶部节点
        roof = m * n
        uf = UnionFind(m * n + 1)
        
        # 将所有剩余的砖块加入并查集
        for i in range(m):
            for j in range(n):
                if status[i][j] == 1:
                    # 第一行连接到虚拟顶部
                    if i == 0:
                        uf.union(pos(i, j), roof)
                    
                    # 连接上方和左方的砖块
                    if i > 0 and status[i-1][j] == 1:
                        uf.union(pos(i, j), pos(i-1, j))
                    if j > 0 and status[i][j-1] == 1:
                        uf.union(pos(i, j), pos(i, j-1))
        
        # 四个方向
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        result = []
        
        # 逆序恢复砖块
        for i, j in reversed(hits):
            # 如果原来就没有砖块，掉落数为 0
            if grid[i][j] == 0:
                result.append(0)
                continue
            
            # 记录恢复前与顶部连接的砖块数
            prev_size = uf.get_size(roof)
            
            # 恢复砖块
            status[i][j] = 1
            
            # 第一行连接到虚拟顶部
            if i == 0:
                uf.union(pos(i, j), roof)
            
            # 连接四个方向的砖块
            for di, dj in directions:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and status[ni][nj] == 1:
                    uf.union(pos(i, j), pos(ni, nj))
            
            # 记录恢复后与顶部连接的砖块数
            curr_size = uf.get_size(roof)
            
            # 掉落的砖块数 = 增加的砖块数 - 1（减去当前恢复的砖块）
            result.append(max(0, curr_size - prev_size - 1))
        
        # 因为是逆序处理的，需要反转结果
        return result[::-1]
```

### 方法二：带路径压缩优化的并查集

```python
from typing import List

class Solution:
    def hitBricks(self, grid: List[List[int]], hits: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        
        # 并查集
        parent = list(range(m * n + 1))
        size = [1] * (m * n + 1)
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            rx, ry = find(x), find(y)
            if rx != ry:
                parent[ry] = rx
                size[rx] += size[ry]
        
        def get_size(x):
            return size[find(x)]
        
        # 标记要敲击的位置
        status = [row[:] for row in grid]
        for r, c in hits:
            status[r][c] = 0
        
        roof = m * n  # 虚拟顶部节点
        
        # 构建初始并查集
        for i in range(m):
            for j in range(n):
                if status[i][j] == 1:
                    idx = i * n + j
                    if i == 0:
                        union(idx, roof)
                    if i > 0 and status[i-1][j] == 1:
                        union(idx, (i-1) * n + j)
                    if j > 0 and status[i][j-1] == 1:
                        union(idx, i * n + (j-1))
        
        result = []
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        # 逆序恢复
        for r, c in reversed(hits):
            if grid[r][c] == 0:
                result.append(0)
                continue
            
            prev = get_size(roof)
            idx = r * n + c
            status[r][c] = 1
            
            if r == 0:
                union(idx, roof)
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and status[nr][nc] == 1:
                    union(idx, nr * n + nc)
            
            curr = get_size(roof)
            result.append(max(0, curr - prev - 1))
        
        return result[::-1]
```

## 复杂度分析

- **时间复杂度**：O(m × n + k × α(m × n))，其中 k 是 hits 的长度，α 是阿克曼函数的反函数
- **空间复杂度**：O(m × n)，并查集和复制的网格

## 关键点总结

1. **逆向思维**：从结果倒推，添加砖块比移除砖块更容易计算
2. **虚拟节点技巧**：用一个额外节点代表顶部，简化判断
3. **并查集维护连通性**：高效地查询和合并连通块
4. **大小追踪**：并查集需要维护每个集合的大小
5. **边界处理**：原本就没有砖块的位置，掉落数为 0

## 易错点

1. **忘记检查原网格**：hits 位置原本可能没有砖块
2. **结果需要反转**：因为是逆序处理的
3. **掉落数计算**：要减去当前恢复的砖块本身（-1）
4. **虚拟节点大小**：初始大小应该为 1
5. **并查集实现**：需要同时维护 parent 和 size
