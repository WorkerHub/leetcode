## 题目描述

给定一个正整数 `x`，我们将会写出一个形如 `x (op1) x (op2) x (op3) x ...` 的表达式，其中每个运算符 `op1`，`op2`，… 可以是加、减、乘、除（`+`，`-`，`*`，或是 `/`）之一。例如，对于 `x = 3`，我们可以写出表达式 `3 * 3 / 3 + 3 - 3`，该式的值为 3。

在写这样的表达式时，我们需要遵守下面的惯例：
1. 除运算符（`/`）返回有理数。
2. 任何地方都没有括号。
3. 我们使用通常的操作顺序：乘法和除法发生在加法和减法之前。
4. 不允许使用一元否定运算符（`-`）。例如，"`x - x`" 是一个有效的表达式，因为它只使用减法，但是 "`-x + x`" 不是，因为它使用了否定运算符。

我们希望编写一个能使表达式等于给定的 `target` 值的表达式，且运算符最少。返回所用运算符的最少数量。

**示例 1：**
```
输入：x = 3, target = 19
输出：5
解释：3 * 3 + 3 * 3 + 3 / 3
表达式包含 5 个运算符。
```

**示例 2：**
```
输入：x = 5, target = 501
输出：8
解释：5 * 5 * 5 * 5 - 5 * 5 * 5 + 5 / 5
表达式包含 8 个运算符。
```

**示例 3：**
```
输入：x = 100, target = 100000000
输出：3
解释：100 * 100 * 100 * 100
表达式包含 3 个运算符。
```

**提示：**
- `2 <= x <= 100`
- `1 <= target <= 2 * 10^8`

## 解题思路

这是一道非常困难的数学 + 动态规划题目。

**核心思想：**
1. 将 target 用 x 的幂次表示（类似进制转换）
2. target 可以表示为：`a₀·x⁰ + a₁·x¹ + a₂·x² + ... + aₙ·xⁿ`
3. 每个系数 aᵢ 可以是负数或正数
4. 使用记忆化搜索计算最少操作符数

**关键观察：**
- `x^k` 需要 k 个乘法符号（k-1 个 `*` 加 1 个 `x`，共 k 个运算符）
- `x/x` = 1，需要 2 个运算符
- 可以使用"进位"思想：如果某位系数很大，可以向高位进位

**状态定义：**
- `dfs(i, target)` 表示使用 x^i 及更高次幂凑出 target 的最小操作符数

## Python 代码实现

### 方法一：记忆化搜索（推荐）⭐

```python
from functools import lru_cache

class Solution:
    def leastOpsExpressTarget(self, x: int, target: int) -> int:
        @lru_cache(None)
        def dfs(target):
            """计算达到 target 的最小操作符数"""
            # 基础情况
            if target == 0:
                return 0
            if target == 1:
                return 1  # x/x 需要 2 个字符，但只有 1 个运算符
            if target < x:
                # target < x 时，只能用 x/x 凑
                # target 个 x/x 相加，需要 2*target - 1 个运算符
                # 或者用 x - (x - target) 个 x/x
                return min(2 * target - 1, 2 * (x - target))
            
            # 找到最接近 target 的 x 的幂次
            power = 1
            ops_for_power = 0  # 构造 x^power 需要的操作符数
            
            # 找到 x^power <= target < x^(power+1) 的 power
            while power * x <= target:
                power *= x
                ops_for_power += 1
            
            # 情况1：使用 power（即 x^k），剩余 target - power
            # 需要 ops_for_power + 1 + dfs(target - power) 个操作符
            # (+1 是因为需要一个加号连接)
            if power == target:
                return ops_for_power
            
            result = ops_for_power + dfs(target - power)
            
            # 情况2：使用更高的幂次 power * x（即 x^(k+1)），然后减去多余的
            # 需要 ops_for_power + 1 + 1 + dfs(power * x - target) 个操作符
            # (第一个+1是构造x^(k+1)，第二个+1是减号)
            if power * x - target < target:
                result = min(result, ops_for_power + 1 + dfs(power * x - target))
            
            return result
        
        return dfs(target) - 1  # 减1是因为第一个数字不需要运算符
```

### 方法二：动态规划（优化版）

```python
class Solution:
    def leastOpsExpressTarget(self, x: int, target: int) -> int:
        # pos: 达到当前余数的最小操作符（使用加法）
        # neg: 达到当前余数的最小操作符（使用减法）
        pos = neg = k = 0
        
        while target:
            target, remainder = divmod(target, x)
            
            if k:
                # 使用 x^k（需要 k 个运算符构造，1 个运算符连接）
                pos, neg = min(remainder * k + pos, (remainder + 1) * k + neg), \
                           min((x - remainder) * k + pos, (x - remainder - 1) * k + neg)
            else:
                # k = 0 时，使用 x/x
                pos, neg = remainder * 2, (x - remainder) * 2
            
            k += 1
        
        return min(pos - 1, k + neg - 1)
```

### 方法三：BFS（理解用）

```python
from collections import deque

class Solution:
    def leastOpsExpressTarget(self, x: int, target: int) -> int:
        # BFS 搜索最少操作符
        queue = deque([(target, 0)])  # (当前目标值, 操作符数)
        visited = {target}
        
        # 预计算 x 的幂次
        powers = []
        power = 1
        while power <= 2 * 10**8:
            powers.append(power)
            power *= x
        
        while queue:
            curr, ops = queue.popleft()
            
            if curr == 0:
                return ops - 1  # 减1因为不需要前导运算符
            
            # 尝试加上或减去每个幂次
            for i, p in enumerate(powers):
                if p > curr * 2:  # 剪枝
                    break
                
                # 使用加法
                next_val = abs(curr - p)
                cost = i if i > 0 else 2  # x/x 需要 2 个操作符
                
                if next_val not in visited or ops + cost + 1 < visited.get(next_val, float('inf')):
                    visited[next_val] = ops + cost + 1
                    queue.append((next_val, ops + cost + 1))
        
        return -1  # 理论上不会到这里
```

## 复杂度分析

### 方法一：记忆化搜索
- **时间复杂度**：O(log target)，每次递归 target 至少减半
- **空间复杂度**：O(log target)，递归栈和缓存空间

### 方法二：动态规划
- **时间复杂度**：O(log target)
- **空间复杂度**：O(1)

### 方法三：BFS
- **时间复杂度**：O(target)，最坏情况
- **空间复杂度**：O(target)

## 关键点总结

1. **进制思想**：将问题转化为用 x 的幂次表示 target
2. **贪心选择**：每次选择最接近的幂次
3. **双向考虑**：可以加上较小的幂次，也可以减去较大的幂次
4. **操作符计数**：x^k 需要 k 个操作符（k-1 个乘号 + 1 个 x）
5. **边界处理**：target = 1 和 target < x 的特殊情况

## 易错点

1. **操作符数量**：容易混淆字符数和操作符数
2. **x/x 的处理**：表示 1 时需要 2 个操作符
3. **减1 问题**：最终结果要减 1（第一个数不需要运算符）
4. **溢出问题**：x^k 可能很大，需要注意范围
5. **递归边界**：target = 0 和 target = 1 的处理
