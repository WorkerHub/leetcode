## 题目描述

给你一个循环数组 `nums` 和一个查询数组 `queries`。

对于每个查询 `queries[i]`，找到从下标 `queries[i]` 出发，在循环数组中（可以向左或向右走）遇到的与 `nums[queries[i]]` 值相同的最近元素的距离。如果不存在其他相同值的元素，返回 -1。

**示例：**

```
输入：nums = [1,3,1,3,2], queries = [0,1,2]
输出：[2,2,2]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

预处理：对每个值，记录所有出现该值的下标列表（有序）。

对每个查询位置 pos，值为 v，在 v 的下标列表中二分查找 pos，找到前后最近的同值下标，计算循环距离取最小值。

## Python 代码实现

### 方法一：哈希表 + 二分查找（推荐）

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        n = len(nums)
        # 建立值 -> 下标列表的映射
        pos_map = defaultdict(list)
        for i, v in enumerate(nums):
            pos_map[v].append(i)

        def circular_dist(a, b, n):
            """循环数组中 a 和 b 的距离"""
            d = abs(a - b)
            return min(d, n - d)

        results = []
        for q in queries:
            v = nums[q]
            indices = pos_map[v]

            if len(indices) == 1:
                results.append(-1)
                continue

            # 二分查找 q 在 indices 中的位置
            idx = bisect.bisect_left(indices, q)

            min_dist = float('inf')

            # 检查前一个相同值
            prev_idx = (idx - 1) % len(indices)
            min_dist = min(min_dist, circular_dist(q, indices[prev_idx], n))

            # 检查后一个相同值
            next_idx = (idx + 1) % len(indices)
            min_dist = min(min_dist, circular_dist(q, indices[next_idx], n))

            results.append(min_dist)

        return results
```

### 方法二：处理循环边界

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        n = len(nums)
        pos_map = defaultdict(list)
        for i, v in enumerate(nums):
            pos_map[v].append(i)

        ans = []
        for q in queries:
            v = nums[q]
            inds = pos_map[v]
            m = len(inds)

            if m == 1:
                ans.append(-1)
                continue

            # q 一定在 inds 中，找其位置
            idx = bisect.bisect_left(inds, q)  # inds[idx] == q

            best = n  # 最大距离为 n
            # 前一个（循环）
            prev = inds[(idx - 1) % m]
            d1 = (q - prev) % n
            best = min(best, d1)

            # 后一个（循环）
            nxt = inds[(idx + 1) % m]
            d2 = (nxt - q) % n
            best = min(best, d2)

            ans.append(best)

        return ans
```

### 方法三：预计算每个位置的答案

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        n = len(nums)
        pos_map = defaultdict(list)
        for i, v in enumerate(nums):
            pos_map[v].append(i)

        # 预计算每个位置的最近相同值距离
        dist = [-1] * n
        for v, inds in pos_map.items():
            m = len(inds)
            if m == 1:
                continue
            for idx, pos in enumerate(inds):
                prev_pos = inds[(idx - 1) % m]
                next_pos = inds[(idx + 1) % m]
                d = min((pos - prev_pos) % n, (next_pos - pos) % n)
                dist[pos] = d

        return [dist[q] for q in queries]
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，预处理 O(n log n)，每次查询 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 对每个值，下标列表有序，可以二分查找
2. 循环距离：`min(|a-b|, n-|a-b|)`
3. 在有序下标列表中，前后相邻的就是最近的同值元素

## 易错点

1. 循环数组中距离计算：`(b - a) % n` 是顺时针距离
2. 查询位置 q 在 inds 中的位置用 bisect_left
3. 只有一个该值的下标时返回 -1
