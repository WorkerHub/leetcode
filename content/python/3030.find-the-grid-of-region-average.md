## 题目描述

给你一个 `m x n` 的整数矩阵 `image` 和整数 `threshold`。

像素矩阵中，相邻像素（上下左右）的差的绝对值不超过 `threshold` 则构成"区域"。

对于每个像素，如果它属于某个区域，则用该区域的平均值（向下取整）替换；否则保持不变。

注意：这里"区域"的定义需要用连通分量来确定（所有像素的相邻差都 <= threshold）。

**示例 1：**
```
输入：image = [[5,6,7,10],[8,8,10,10],[11,10,10,9]], threshold = 3
输出：[[9,9,9,9],[9,9,9,9],[9,9,9,9]]
```

**提示：**
- `3 <= n, m <= 500`
- `0 <= image[i][j] <= 255`
- `0 <= threshold <= 255`

## 解题思路

BFS/DFS 求连通分量，每个连通分量内的所有像素都使用同一区域平均值替换。

定义连通性：两个相邻像素（上下左右）的差 <= threshold，则它们在同一区域。

步骤：
1. 用并查集或 BFS/DFS 找所有连通分量
2. 计算每个连通分量的平均值（向下取整）
3. 输出结果矩阵

## Python 代码实现

### 方法一：BFS 求连通分量（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def resultGrid(self, image: List[List[int]], threshold: int) -> List[List[int]]:
        m, n = len(image), len(image[0])
        visited = [[-1] * n for _ in range(m)]  # 记录每个像素所属的区域编号
        regions = []  # 每个区域的像素列表

        def bfs(start_r, start_c, region_id):
            queue = deque([(start_r, start_c)])
            visited[start_r][start_c] = region_id
            region = [(start_r, start_c)]
            while queue:
                r, c = queue.popleft()
                for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and visited[nr][nc] == -1:
                        if abs(image[nr][nc] - image[r][c]) <= threshold:
                            visited[nr][nc] = region_id
                            queue.append((nr, nc))
                            region.append((nr, nc))
            return region

        # 找所有连通分量
        region_id = 0
        for i in range(m):
            for j in range(n):
                if visited[i][j] == -1:
                    region = bfs(i, j, region_id)
                    regions.append(region)
                    region_id += 1

        # 构建结果矩阵
        result = [row[:] for row in image]  # 复制原图

        for region in regions:
            # 计算区域平均值（向下取整）
            total = sum(image[r][c] for r, c in region)
            avg = total // len(region)
            for r, c in region:
                result[r][c] = avg

        return result
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def resultGrid(self, image: List[List[int]], threshold: int) -> List[List[int]]:
        m, n = len(image), len(image[0])
        parent = list(range(m * n))
        size = [1] * (m * n)
        total = [image[i][j] for i in range(m) for j in range(n)]

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            rx, ry = find(x), find(y)
            if rx == ry:
                return
            if size[rx] < size[ry]:
                rx, ry = ry, rx
            parent[ry] = rx
            size[rx] += size[ry]
            total[rx] += total[ry]

        # 合并相邻满足条件的像素
        for i in range(m):
            for j in range(n):
                for di, dj in [(0, 1), (1, 0)]:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n:
                        if abs(image[i][j] - image[ni][nj]) <= threshold:
                            union(i * n + j, ni * n + nj)

        # 构建结果
        result = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                root = find(i * n + j)
                result[i][j] = total[root] // size[root]

        return result
```

## 复杂度分析

- 时间复杂度：O(m * n * alpha)（并查集），O(m * n) BFS/DFS
- 空间复杂度：O(m * n)

## 关键点总结

1. 连通分量内相邻像素差 <= threshold
2. 每个连通分量的像素统一替换为区域平均值（向下取整）
3. BFS/DFS 或并查集均可求连通分量

## 易错点

1. 连通性判断：相邻两像素差 <= threshold（不是整个区域内任意两像素）
2. 结果是向下取整（`//`），不是四舍五入
3. 孤立像素（只有自身的连通分量）保持不变（实际上其平均值就是自身，也正确）
