## 题目描述

给你两个字符串 `firstString` 和 `secondString`，二者均由小写英文字母组成，并且二者都**不含重复字母**。

如果两个子字符串 `firstString[i..j]` 和 `secondString[a..b]` 满足 `i - a` 最小（如果有多个最小值，则 `j - b` 也最小），那么我们称这样的 **(i, j, a, b)** 是一个**最优四元组**。

如果 `firstString[i..j] == secondString[a..b]`（即两个子字符串相等），则这个四元组满足**等值条件**。

你需要找出满足等值条件且**具有最小 `i - a` 值**的四元组，并返回满足这一条件的四元组的**数量**。

**注意：** 由于两个字符串不含重复字母，每个字母在每个字符串中最多出现一次。

**示例 1：**
```
输入：firstString = "abcd", secondString = "bccda"
输出：1
解释：最优四元组 (0, 0, 4, 4)：firstString[0..0] = "a" = secondString[4..4]，i-a = 0-4 = -4
```

**提示：**
- `1 <= firstString.length, secondString.length <= 100`
- 两个字符串均由小写英文字母组成，且各自不含重复字母

## 解题思路

由于两个字符串不含重复字母，每个字符在各自字符串中最多出现一次。

对于每个在两个字符串中都出现的字母 `c`，设它在 `firstString` 中的位置为 `i`（同时也是 `j`，因为是单字符子串），在 `secondString` 中的位置为 `a`，则这对 `(i, a)` 的差为 `i - a`。

找出使 `i - a` 最小的字母，统计达到最小值的字母个数。

注意：子串不一定是单个字符，但由于不含重复字母，最优子串必然是单字符（更长的子串会使 `i - a` 更大或更小，但具体分析后可知单字符是最优的）。

## 代码实现

### 方法一：枚举公共字符（推荐）

```python
class Solution:
    def countQuadruples(self, firstString: str, secondString: str) -> int:
        # 记录每个字母在两个字符串中的位置
        pos1 = {c: i for i, c in enumerate(firstString)}
        pos2 = {c: i for i, c in enumerate(secondString)}

        min_diff = float('inf')
        count = 0

        # 枚举在两个字符串中都出现的字母
        for c in pos1:
            if c in pos2:
                diff = pos1[c] - pos2[c]
                if diff < min_diff:
                    min_diff = diff
                    count = 1
                elif diff == min_diff:
                    count += 1

        return count
```

### 方法二：集合求交集

```python
class Solution:
    def countQuadruples(self, firstString: str, secondString: str) -> int:
        pos1 = {c: i for i, c in enumerate(firstString)}
        pos2 = {c: i for i, c in enumerate(secondString)}

        common = set(pos1.keys()) & set(pos2.keys())
        if not common:
            return 0

        diffs = [pos1[c] - pos2[c] for c in common]
        min_diff = min(diffs)
        return diffs.count(min_diff)
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 和 m 为两个字符串的长度，枚举 26 个字母
- **空间复杂度**：O(1)，字母表大小固定为 26

## 关键点总结

1. 不含重复字母，每个字母在字符串中最多出现一次
2. 最优子串是单字符（每个字母在两字符串中各自出现一次，最小差由单字符决定）
3. 找所有公共字母的 `pos1[c] - pos2[c]` 最小值，统计达到最小值的个数

## 易错点

1. 如果没有公共字母，返回 0
2. 最小差可能为负数，要用 `min_diff = float('inf')` 而非 `0` 初始化
3. 注意题目中的 `i - a` 是有符号差，可以为负
