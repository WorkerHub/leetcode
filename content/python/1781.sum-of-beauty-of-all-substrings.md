## 题目描述

一个字符串的**美丽值**定义为：出现频率最高的字符频率与出现频率最低的字符频率之差。

给你一个字符串 `s`，返回其所有子字符串的**美丽值**之和。

**示例：**
```
输入：s = "aabcb"
输出：5
解释：美丽值不为 0 的子字符串为 ["aab","aabc","aabcb","abcb","bcb"]，各美丽值分别为 1, 1, 2, 1, 0... 
```

**提示：**
- `1 <= s.length <= 500`
- `s` 只由小写英文字母组成

## 解题思路

暴力枚举所有子字符串（O(n^2)），对每个子字符串统计字符频率，计算最大频率与最小频率之差。

由于 `n <= 500`，O(n^2 * 26) 足够。

## 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def beautySum(self, s: str) -> int:
        n = len(s)
        total = 0
        
        for i in range(n):
            count = [0] * 26
            for j in range(i, n):
                count[ord(s[j]) - ord('a')] += 1
                # 计算美丽值
                max_freq = max(count)
                min_freq = min(c for c in count if c > 0)
                total += max_freq - min_freq
        
        return total
```

### 方法二：使用 Counter 优化

```python
from collections import Counter

class Solution:
    def beautySum(self, s: str) -> int:
        n = len(s)
        total = 0
        
        for i in range(n):
            cnt = Counter()
            for j in range(i, n):
                cnt[s[j]] += 1
                if len(cnt) >= 2:
                    max_f = max(cnt.values())
                    min_f = min(cnt.values())
                    total += max_f - min_f
        
        return total
```

## 复杂度分析

- **时间复杂度**：O(n^2 * 26)，n^2 枚举子串，26 求最大最小
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 枚举起点 `i`，内层维护当前子串的字符频率
2. 每次扩展一个字符，O(1) 更新频率，O(26) 计算美丽值
3. 美丽值 = 最高频率 - 最低频率（只考虑出现过的字符）

## 易错点

- 最低频率只考虑出现过的字符（频率 > 0）
- 单字符子串美丽值为 0（只有一种字符，最高=最低）
