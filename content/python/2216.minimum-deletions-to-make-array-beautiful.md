## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。如果满足下述条件，则认为数组 `nums` 是一个**美丽数组**：

- `nums.length` 为偶数。
- 对所有满足 `i % 2 == 0` 的下标 `i`，`nums[i] != nums[i+1]`（即奇偶位置的相邻对不相等）。

每一步操作中，可以删除 `nums` 中的一个元素。返回让 `nums` 变成美丽数组的**最少删除次数**。

**示例 1：**
```
输入：nums = [1,1,2,3,5]
输出：1
解释：删除 nums[0]=1，得 [1,2,3,5]，满足条件。
```

**示例 2：**
```
输入：nums = [1,1,1,2,3,3]
输出：2
```

## 解题思路

**贪心双指针：** 每次取两个相邻元素组成一对，若相等则删除其中一个（不接受这对），跳过。

维护一个计数器 `deleted`，遍历时模拟配对过程：
- 用变量追踪"当前已接受的元素数量"（即未被删除的元素数）。
- 每两个未被删除的元素组成一对，若相等则删除后一个（`deleted++`，不接受）。
- 最后若剩余未配对的元素（奇数个），再删除最后一个使长度为偶数。

**等价思路：** 遍历数组，用 `i` 表示当前元素在结果数组中的"逻辑位置"（偶数位/奇数位交替）。若当前是偶数位且 `nums[i] == nums[i+1]`，则删除并跳过。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minDeletion(self, nums: List[int]) -> int:
        deleted = 0
        n = len(nums)
        j = 0  # j 表示当前"有效"位置的逻辑下标

        for i in range(n):
            # 当前元素在结果数组中处于偶数位（j 为偶数）
            # 若它等于下一个有效元素，删除它
            if j % 2 == 0 and i + 1 < n and nums[i] == nums[i + 1]:
                deleted += 1
                # 不递增 j，跳过这个元素
            else:
                j += 1

        # 若有效长度为奇数，还需删一个
        if j % 2 == 1:
            deleted += 1

        return deleted
```

### 方法二：模拟配对

```python
from typing import List

class Solution:
    def minDeletion(self, nums: List[int]) -> int:
        ans = 0
        i = 0  # 遍历下标

        while i < len(nums) - 1:
            if nums[i] == nums[i + 1]:
                # 这两个相邻元素相等，删一个（选择删 nums[i]，即跳过）
                ans += 1
                i += 1  # 只移动一步，让 nums[i+1] 成为下一个偶数位候选
            else:
                # 接受这对 (nums[i], nums[i+1])
                i += 2

        # 若还剩一个元素未配对（i == len(nums) - 1）
        if i == len(nums) - 1:
            ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)，常数额外空间。

## 关键点总结

1. 每次贪心地接受不相等的相邻对，遇到相等对就删一个。
2. 最后若剩余奇数个有效元素，需再删一个保证长度为偶数。
3. 方法二的双指针直接模拟，逻辑清晰。

## 易错点

- 删除后数组结构发生变化，应用逻辑下标而非物理下标来追踪位置。
- 最后需检查有效长度是否为偶数，若为奇数还需额外删一个。
