## 题目描述

给你一个由英文字母组成的字符串 `s`，请你找出并返回 `s` 中的**最大**英文字母。返回的字母必须同时以大写和小写形式出现在 `s` 中。

如果不存在满足条件的字母，则返回空字符串 `""`。

**示例 1：**
```
输入：s = "lEeTcOdE"
输出："E"
解释：字母 'E' 同时以大写（'E'）和小写（'e'）出现在 s 中，并且没有其他字母满足此条件。
```

**示例 2：**
```
输入：s = "arRAzFif"
输出："R"
```

**示例 3：**
```
输入：s = "AbCdEfGhIjK"
输出：""
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 由小写和大写英文字母组成

## 解题思路

**方法一：哈希表**
将 `s` 中所有字符存入集合，然后从 `'Z'` 到 `'A'` 倒序枚举每个字母，找到第一个大小写均存在的字母。

**方法二：集合交集**
找出大写字母集合与小写字母集合的交集，取 ASCII 码最大的那个。

## 代码实现

### 方法一：哈希表枚举（推荐）

```python
class Solution:
    def greatestLetter(self, s: str) -> str:
        char_set = set(s)
        # 从 Z 到 A 枚举，找到第一个大小写均存在的字母
        for c in reversed("ABCDEFGHIJKLMNOPQRSTUVWXYZ"):
            if c in char_set and c.lower() in char_set:
                return c
        return ""
```

### 方法二：集合交集

```python
class Solution:
    def greatestLetter(self, s: str) -> str:
        # 找出大写字母集合
        upper = {c for c in s if c.isupper()}
        # 找出小写字母集合对应的大写形式
        lower_as_upper = {c.upper() for c in s if c.islower()}
        # 取交集，找最大值
        common = upper & lower_as_upper
        return max(common) if common else ""
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表枚举 | O(n + 26) | O(n) |
| 集合交集 | O(n) | O(n) |

## 关键点总结

1. 先将所有字符放入集合，查找操作为 O(1)。
2. 从 Z 开始倒序枚举，找到的第一个就是最大的满足条件的字母。
3. 大小写转换：`c.lower()` / `c.upper()`。

## 易错点

- 注意返回的是大写字母形式（题目要求返回大写字母）。
- 枚举顺序要从大到小，才能找到"最大"的字母。
