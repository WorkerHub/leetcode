## 题目描述

给你两个长度可能不等的整数数组 `nums1` 和 `nums2`。两个数组中的所有值都在 `1` 到 `6` 之间（包含 `1` 和 `6`）。

每次操作中，你可以选择**任意**数组中的任意一个整数，将它变成 `1` 到 `6` 之间的**任意**值（包含）。

请你返回使 `nums1` 中所有数的和与 `nums2` 中所有数的和相等的最少操作次数。如果无法使两者的和相等，请返回 `-1`。

**示例 1：**
```
输入：nums1 = [1,2,3,4,5,6], nums2 = [1,1,2,2,2,2]
输出：3
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `1 <= nums1[i], nums2[i] <= 6`

## 解题思路

设 `s1 = sum(nums1)`，`s2 = sum(nums2)`，目标是使 s1 = s2。

如果 `s1 == s2`，直接返回 0。

不妨设 s1 < s2（否则交换），需要减小 s2 或增大 s1。

贪心：每次操作尽量减少差距，优先进行变化量最大的操作：
- 对 `nums2` 中的每个数 `x`，可以将其减少到 1，贡献 `x - 1`
- 对 `nums1` 中的每个数 `y`，可以将其增加到 6，贡献 `6 - y`

将所有可能的贡献排降序，每次取最大贡献，直到差值 <= 0。

## 代码实现

### 方法一：贪心 + 桶排序优化（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        s1, s2 = sum(nums1), sum(nums2)
        
        if s1 == s2:
            return 0
        
        # 不妨设 s1 < s2，需要增大 nums1 或减小 nums2
        if s1 > s2:
            nums1, nums2 = nums2, nums1
            s1, s2 = s2, s1
        
        # 检查可行性：即使 nums1 全为6、nums2 全为1，是否能使 s1 = s2
        if 6 * len(nums1) < 1 * len(nums2):
            return -1  # nums2 最小和比 nums1 最大和还大
        
        diff = s2 - s1
        
        # 统计每种贡献值的数量（用桶，贡献值 1-5）
        # nums1 中 y 的最大贡献 = 6 - y
        # nums2 中 x 的最大贡献 = x - 1
        gain_count = [0] * 7  # gain_count[g] = 贡献为 g 的操作数量
        for y in nums1:
            gain_count[6 - y] += 1
        for x in nums2:
            gain_count[x - 1] += 1
        
        ops = 0
        for g in range(5, 0, -1):
            if diff <= 0:
                break
            # 每次贡献 g，需要 ceil(diff/g) 次，但不超过 gain_count[g]
            use = min(gain_count[g], (diff + g - 1) // g)
            diff -= use * g
            ops += use
        
        return ops if diff <= 0 else -1
```

### 方法二：排序所有贡献（更直观）

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        s1, s2 = sum(nums1), sum(nums2)
        if s1 == s2:
            return 0
        
        if s1 > s2:
            nums1, nums2 = nums2, nums1
            s1, s2 = s2, s1
        
        diff = s2 - s1
        
        # 收集所有可能的增量
        gains = []
        for y in nums1:
            gains.append(6 - y)
        for x in nums2:
            gains.append(x - 1)
        
        gains.sort(reverse=True)
        
        ops = 0
        for g in gains:
            if diff <= 0:
                break
            diff -= g
            ops += 1
        
        return ops if diff <= 0 else -1
```

## 复杂度分析

- **方法一**：时间 O(n + m)，桶排序
- **方法二**：时间 O((n + m) log(n + m))，排序

## 关键点总结

1. 贪心：每次操作选贡献最大的（差值减少最多）
2. 贡献值范围 1-5，可以用桶排序代替普通排序
3. 不可行的情况：`6 * len(较小和数组) < 1 * len(较大和数组)` —— 但实际用差值 <= 0 即可

## 易错点

- 不妨设 s1 < s2，再处理，避免两种情况分类讨论
- 桶排序时注意贡献为 0 的操作不需要处理
