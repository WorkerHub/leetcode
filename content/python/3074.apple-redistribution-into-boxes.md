## 题目描述

给你两个长度为 `n` 和 `m` 的整数数组 `apple` 和 `capacity`。

`n` 个包裹中，第 `i` 个包裹有 `apple[i]` 个苹果。你需要将所有苹果转移到 `m` 个箱子中（每个箱子最多放 `capacity[i]` 个）。

返回需要的最少箱子数量。

**示例 1：**
```
输入：apple = [1,3,2], capacity = [4,3,1,5,2]
输出：2
解释：总苹果数 6，最大容量箱子优先：5 + 4 = 9 >= 6，需要 2 个
```

**提示：**
- `1 <= n <= 50`
- `1 <= m <= 50`
- `1 <= apple[i] <= 50`
- `1 <= capacity[i] <= 50`

## 解题思路

贪心：将箱子按容量降序排序，从最大容量开始使用，直到总容量 >= 总苹果数。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minimumBoxes(self, apple: List[int], capacity: List[int]) -> int:
        total = sum(apple)
        capacity.sort(reverse=True)
        used = 0
        for i, cap in enumerate(capacity):
            used += cap
            if used >= total:
                return i + 1
        return len(capacity)
```

### 方法二：简洁版

```python
from typing import List

class Solution:
    def minimumBoxes(self, apple: List[int], capacity: List[int]) -> int:
        total = sum(apple)
        capacity.sort(reverse=True)
        acc = 0
        for i, c in enumerate(capacity):
            acc += c
            if acc >= total:
                return i + 1
        return -1  # 理论上不会到这里
```

## 复杂度分析

- 时间复杂度：O(m log m)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：优先使用最大容量的箱子
2. 累计容量直到 >= 总苹果数，返回已用箱子数

## 易错点

1. 注意是"最少箱子数"，不是"最少总容量"
2. 题目保证总容量足够，一定能找到答案
