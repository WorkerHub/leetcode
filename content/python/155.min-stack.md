## 题目描述

设计一个支持 `push`，`pop`，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象
- `void push(int val)` 将元素 `val` 推入堆栈
- `void pop()` 删除堆栈顶部的元素
- `int top()` 获取堆栈顶部的元素
- `int getMin()` 获取堆栈中的最小元素

**示例：**

```
输入:
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出:
[null,null,null,null,-3,null,0,-2]

解释:
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
```

**提示：**

- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top` 和 `getMin` 操作总是在非空栈上调用
- `push`、`pop`、`top` 和 `getMin` 最多被调用 `3 * 10^4` 次

## 解题思路

要实现 O(1) 时间获取最小值，关键是在每次 push 和 pop 时维护最小值信息。

**核心问题：**

- 普通栈可以 O(1) 完成 push、pop、top
- 但获取最小值需要遍历，O(n)
- 如何优化到 O(1)？

**解决方案：**

使用辅助栈，同步记录每个状态下的最小值。

**方法对比：**

| 方法 | 空间复杂度 | 实现难度 | 推荐度 |
|------|-----------|---------|--------|
| 双栈法 | O(n) | 简单 | ★★★★★ |
| 单栈法（存差值） | O(n) | 中等 | ★★★ |
| 链表法 | O(n) | 简单 | ★★★★ |

## Python 代码实现

### 方法一：双栈法（推荐）

```python
class MinStack:
    """
    使用两个栈：
    - stack: 存储所有元素
    - min_stack: 存储每个状态下的最小值
    """
    
    def __init__(self):
        self.stack = []
        self.min_stack = []  # 存储当前最小值
    
    def push(self, val: int) -> None:
        self.stack.append(val)
        
        # 更新最小值栈
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            # 新的最小值是 val 和当前最小值的较小者
            self.min_stack.append(min(val, self.min_stack[-1]))
    
    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()
    
    def top(self) -> int:
        return self.stack[-1]
    
    def getMin(self) -> int:
        return self.min_stack[-1]
```

### 方法二：优化的双栈法（减少空间）

```python
class MinStack:
    """
    优化：min_stack 只在必要时压入
    """
    
    def __init__(self):
        self.stack = []
        self.min_stack = []
    
    def push(self, val: int) -> None:
        self.stack.append(val)
        
        # 只有当 val <= 当前最小值时，才压入 min_stack
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
    
    def pop(self) -> None:
        val = self.stack.pop()
        
        # 如果弹出的是最小值，也要从 min_stack 弹出
        if val == self.min_stack[-1]:
            self.min_stack.pop()
    
    def top(self) -> int:
        return self.stack[-1]
    
    def getMin(self) -> int:
        return self.min_stack[-1]
```

### 方法三：单栈法（存储差值）

```python
class MinStack:
    """
    只用一个栈，存储元素与最小值的差值
    """
    
    def __init__(self):
        self.stack = []
        self.min_val = None  # 当前最小值
    
    def push(self, val: int) -> None:
        if not self.stack:
            self.stack.append(0)  # 第一个元素，差值为 0
            self.min_val = val
        else:
            # 存储差值
            diff = val - self.min_val
            self.stack.append(diff)
            
            # 如果新值更小，更新最小值
            if val < self.min_val:
                self.min_val = val
    
    def pop(self) -> None:
        diff = self.stack.pop()
        
        # 如果差值 < 0，说明弹出的是最小值
        # 需要恢复之前的最小值
        if diff < 0:
            self.min_val = self.min_val - diff
    
    def top(self) -> int:
        diff = self.stack[-1]
        
        # 如果差值 < 0，栈顶是当前最小值
        if diff < 0:
            return self.min_val
        else:
            return self.min_val + diff
    
    def getMin(self) -> int:
        return self.min_val
```

### 方法四：链表实现

```python
class Node:
    def __init__(self, val, min_val, next_node=None):
        self.val = val
        self.min_val = min_val  # 当前状态下的最小值
        self.next = next_node

class MinStack:
    """
    使用链表，每个节点存储值和当前最小值
    """
    
    def __init__(self):
        self.head = None
    
    def push(self, val: int) -> None:
        if not self.head:
            self.head = Node(val, val)
        else:
            # 新节点的最小值是 val 和之前最小值的较小者
            min_val = min(val, self.head.min_val)
            self.head = Node(val, min_val, self.head)
    
    def pop(self) -> None:
        self.head = self.head.next
    
    def top(self) -> int:
        return self.head.val
    
    def getMin(self) -> int:
        return self.head.min_val
```

### 方法五：使用元组（简化版双栈）

```python
class MinStack:
    """
    栈中每个元素存储 (值, 当前最小值) 的元组
    """
    
    def __init__(self):
        self.stack = []
    
    def push(self, val: int) -> None:
        if not self.stack:
            self.stack.append((val, val))
        else:
            current_min = min(val, self.stack[-1][1])
            self.stack.append((val, current_min))
    
    def pop(self) -> None:
        self.stack.pop()
    
    def top(self) -> int:
        return self.stack[-1][0]
    
    def getMin(self) -> int:
        return self.stack[-1][1]
```

## 复杂度分析

**所有方法的时间复杂度：**

- `push`: O(1)
- `pop`: O(1)
- `top`: O(1)
- `getMin`: O(1)

**空间复杂度：**

- 方法一：O(n) - 两个栈都存储 n 个元素
- 方法二：O(n) - min_stack 最多存储 n 个元素，但平均会少一些
- 方法三：O(n) - 一个栈 + 一个变量
- 方法四：O(n) - 链表存储 n 个节点
- 方法五：O(n) - 栈存储 n 个元组

## 图解示例

以方法一（双栈法）为例：

```
操作序列: push(-2), push(0), push(-3), getMin(), pop(), top(), getMin()

push(-2):
stack:     [-2]
min_stack: [-2]

push(0):
stack:     [-2, 0]
min_stack: [-2, -2]  # min(-2, 0) = -2

push(-3):
stack:     [-2, 0, -3]
min_stack: [-2, -2, -3]  # min(-2, -3) = -3

getMin():
返回 min_stack[-1] = -3

pop():
stack:     [-2, 0]
min_stack: [-2, -2]

top():
返回 stack[-1] = 0

getMin():
返回 min_stack[-1] = -2
```

方法二（优化双栈）的区别：

```
push(-2):
stack:     [-2]
min_stack: [-2]  # -2 <= min (空), 压入

push(0):
stack:     [-2, 0]
min_stack: [-2]  # 0 > -2, 不压入

push(-3):
stack:     [-2, 0, -3]
min_stack: [-2, -3]  # -3 <= -2, 压入

pop():  # 弹出 -3
stack:     [-2, 0]
min_stack: [-2]  # -3 == min_stack[-1], 也弹出
```

## 关键点总结

1. **双栈思想**：
   - 主栈存储所有元素
   - 辅助栈存储每个状态的最小值
   - 两个栈同步操作

2. **空间优化**：
   - 方法二：只在必要时压入 min_stack
   - 减少空间，但逻辑稍复杂

3. **单栈技巧**：
   - 存储差值而不是原值
   - 通过差值的正负判断是否需要更新最小值

4. **链表实现**：
   - 每个节点存储当前状态的最小值
   - 不需要额外的辅助栈

5. **元组方法**：
   - 代码最简洁
   - 但每个元素占用两倍空间

## 易错点

1. **方法二的 pop 操作**：
   - 必须判断弹出的元素是否是最小值
   - 如果是，min_stack 也要弹出

2. **方法二的 push 条件**：
   - 是 `val <= min_stack[-1]`，不是 `val < min_stack[-1]`
   - 因为可能有重复的最小值

3. **方法三的复杂性**：
   - 差值可能溢出（val - min_val）
   - top() 和 pop() 需要根据差值正负分情况处理

4. **空栈判断**：
   - getMin() 前要确保栈非空
   - 题目保证了这一点，但实际使用要注意

5. **初始化**：
   - 第一个元素的处理要特殊考虑
   - min_stack 为空时的判断
