## 题目描述

给你一棵树，树上有 `n` 个节点，按从 `0` 到 `n-1` 编号。树以父节点数组的形式给出，其中 `parent[i]` 是节点 `i` 的父节点。树的根节点是编号为 `0` 的节点。

请你设计并实现 `getKthAncestor(int node, int k)` 函数，函数返回节点 `node` 的第 `k` 个祖先节点。若不存在这样的祖先节点，返回 `-1`。

树节点的第 `k` 个祖先节点是：从该节点到根节点路径上的第 `k` 个节点。

**示例 1：**

```
输入：
["TreeAncestor","getKthAncestor","getKthAncestor","getKthAncestor"]
[[7,[-1,0,0,1,1,2,2]],[3,1],[5,2],[6,3]]
输出：
[null,1,0,-1]

解释：
树结构：
        0
       / \
      1   2
     / \ / \
    3  4 5  6
getKthAncestor(3, 1) = 1  // 3 的第1个祖先是 1
getKthAncestor(5, 2) = 0  // 5 的第2个祖先是 0（5→2→0）
getKthAncestor(6, 3) = -1 // 6 只有2个祖先（2和0），没有第3个
```

**提示：**
- `1 <= n <= 5 * 10^4`
- `0 <= node < n`
- `tree.height <= log(n)` 不一定，可能是链状树
- `0 <= k <= 5 * 10^4`
- 最多调用 `getKthAncestor` 函数 `5 * 10^4` 次

---

## 解题思路

**问题分析：**
暴力方法：每次 `getKthAncestor(node, k)` 从 node 出发，沿父节点指针走 k 步。
- 最坏情况（链状树）：每次查询 O(k)，总时间 O(n*k) 可达 O(n^2)，对于 n=5*10^4 会超时。

**二进制提升（倍增）算法：**
- 预处理 `dp[j][i]`：节点 `i` 的第 `2^j` 个祖先。
- `dp[0][i] = parent[i]`（第 1 个祖先，即直接父节点）
- `dp[j][i] = dp[j-1][dp[j-1][i]]`（第 `2^j` 个祖先 = 第 `2^(j-1)` 个祖先的第 `2^(j-1)` 个祖先）
- 查询时，将 k 分解为二进制：每个二进制位对应一次跳跃。
  - 例如 k=5=101(二进制)：先跳 4 步，再跳 1 步。

## Python 代码实现

### 方法一：二进制提升（倍增）（推荐）

```python
import math

class TreeAncestor:

    def __init__(self, n: int, parent: list):
        # LOG：需要预处理的最大幂次，2^LOG >= n
        LOG = max(1, math.ceil(math.log2(n + 1))) + 1

        # dp[j][i]：节点 i 的第 2^j 个祖先，-1 表示不存在
        # dp 大小：LOG × n
        self.dp = [[-1] * n for _ in range(LOG)]
        self.LOG = LOG

        # 初始化：第 0 层，即直接父节点
        for i in range(n):
            self.dp[0][i] = parent[i]

        # 递推：dp[j][i] = dp[j-1][dp[j-1][i]]
        for j in range(1, LOG):
            for i in range(n):
                mid = self.dp[j - 1][i]  # 节点 i 的第 2^(j-1) 个祖先
                if mid != -1:
                    self.dp[j][i] = self.dp[j - 1][mid]  # 再跳 2^(j-1) 步
                # 若 mid == -1，则 dp[j][i] 保持 -1

    def getKthAncestor(self, node: int, k: int) -> int:
        # 将 k 分解为二进制，按位跳跃
        cur = node
        for j in range(self.LOG):
            if k & (1 << j):  # 如果 k 的第 j 位是 1
                cur = self.dp[j][cur]
                if cur == -1:
                    return -1  # 越过根节点，不存在
        return cur
```

### 方法二：暴力法（仅用于小数据或对比）

```python
class TreeAncestor:

    def __init__(self, n: int, parent: list):
        self.parent = parent  # 直接存储父节点数组

    def getKthAncestor(self, node: int, k: int) -> int:
        cur = node
        for _ in range(k):
            if cur == -1:
                return -1
            cur = self.parent[cur]
        return cur
```

### 方法三：二进制提升（用字典优化，处理稀疏祖先）

```python
import math

class TreeAncestor:

    def __init__(self, n: int, parent: list):
        LOG = 16  # 2^16 = 65536 > 5*10^4，足够

        # 使用列表的列表
        self.anc = [parent[:]]  # anc[0] = 直接父节点

        for j in range(1, LOG):
            prev = self.anc[j - 1]
            cur_level = []
            for i in range(n):
                p = prev[i]
                # p 的第 2^(j-1) 个祖先
                cur_level.append(prev[p] if p != -1 else -1)
            self.anc.append(cur_level)

        self.LOG = LOG

    def getKthAncestor(self, node: int, k: int) -> int:
        cur = node
        for j in range(self.LOG):
            if (k >> j) & 1:
                cur = self.anc[j][cur]
                if cur == -1:
                    return -1
        return cur
```

## 复杂度分析

| 方法 | 预处理时间 | 查询时间 | 空间 |
|------|-----------|---------|------|
| 二进制提升 | O(n log n) | O(log n) | O(n log n) |
| 暴力 | O(n) | O(k) | O(n) |

- 二进制提升预处理 O(n log n)，单次查询 O(log n)，总体远优于暴力的 O(n * k)。

## 图解示例

以 `n=7, parent=[-1,0,0,1,1,2,2]` 为例：

```
树结构：
        0（根）
       / \
      1   2
     / \ / \
    3  4 5  6

LOG = 3（2^3=8 >= 7）

dp[0]（第 2^0=1 步的祖先）:
  dp[0][0] = -1（根节点无父）
  dp[0][1] = 0
  dp[0][2] = 0
  dp[0][3] = 1
  dp[0][4] = 1
  dp[0][5] = 2
  dp[0][6] = 2

dp[1]（第 2^1=2 步的祖先）:
  dp[1][3] = dp[0][dp[0][3]] = dp[0][1] = 0
  dp[1][5] = dp[0][dp[0][5]] = dp[0][2] = 0
  ...

查询 getKthAncestor(5, 2)：
  k=2=10(二进制)
  j=0: k&1=0，不跳
  j=1: k&2=2≠0，跳 2^1=2 步：cur = dp[1][5] = 0
  返回 0 ✓
```

## 关键点总结

1. **二进制提升**是处理"第 k 个祖先"问题的标准算法，利用二进制分解 k，将 O(k) 的查询优化到 O(log k)。
2. 预处理 `dp[j][i]` 表示节点 `i` 的第 `2^j` 个祖先，递推公式：`dp[j][i] = dp[j-1][dp[j-1][i]]`。
3. 查询时将 k 写成二进制，逐位跳跃，遇到 -1 则提前返回 -1。
4. `LOG` 取 `ceil(log2(n)) + 1`，保证 `2^LOG > n`。

---

## 易错点

- **dp 初始化**：`dp[0][root] = -1`（根节点的父节点是 -1）。
- **递推时的 -1 判断**：`dp[j-1][i] = -1` 时，`dp[j][i]` 也应为 -1，不能继续访问 `dp[j-1][-1]`（会访问到最后一个元素）。
- **LOG 的大小**：保证 `2^LOG >= n`，n=5*10^4 时取 16 或 17 均可（2^16=65536）。
