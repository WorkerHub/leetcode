## 题目描述

给你一个下标从 0 开始的整数数组 `coins` 和一个整数 `target`。

从数组中选出若干硬币，可以凑出 1 到 `target` 之间的任意整数金额。你可以向数组中**添加**任意面值的硬币（面值必须为正整数）。

返回为了能凑出 1 到 `target` 之间所有整数，需要添加的最少硬币数目。

**示例 1：**
```
输入：coins = [1,4,10], target = 19
输出：2
解释：添加面值 2 和 8，可以凑出 1 到 19 的所有整数
```

**示例 2：**
```
输入：coins = [1,4,10,5,7,19], target = 19
输出：1
```

**提示：**
- `1 <= coins.length <= 10^5`
- `1 <= coins[i] <= 10^9`
- `coins.length <= target <= 10^9`

## 解题思路

贪心：维护当前能凑出 [1, reach] 的最大范围 `reach`，初始 reach = 0。

将 coins 排序，依次处理每个硬币 c：
- 若 `c > reach + 1`：[1, reach] 之后存在空缺，需要添加硬币 `reach + 1`（贪心：添加能填补当前空缺的最大面值），添加后 reach 翻倍（reach += reach + 1 = 2*reach + 1）
- 若 `c <= reach + 1`：将 reach 扩展到 `reach + c`

重复直到 reach >= target 或所有硬币处理完。

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minimumAddedCoins(self, coins: List[int], target: int) -> int:
        coins.sort()
        reach = 0  # 当前能凑出 [1, reach] 的所有整数
        ans = 0
        i = 0
        n = len(coins)

        while reach < target:
            if i < n and coins[i] <= reach + 1:
                # 当前硬币能扩展 reach
                reach += coins[i]
                i += 1
            else:
                # 存在空缺，添加 reach + 1
                reach += reach + 1
                ans += 1

        return ans
```

### 方法二：贪心（显式说明）

```python
from typing import List

class Solution:
    def minimumAddedCoins(self, coins: List[int], target: int) -> int:
        coins.sort()
        reach = 0
        ops = 0
        idx = 0

        while reach < target:
            # 检查是否有面值 <= reach+1 的硬币未使用
            if idx < len(coins) and coins[idx] <= reach + 1:
                reach += coins[idx]
                idx += 1
            else:
                # 添加面值为 reach+1 的硬币
                reach = reach * 2 + 1
                ops += 1

        return ops
```

## 复杂度分析

- 时间复杂度：O(n log n + log(target))，排序 + 贪心步数
- 空间复杂度：O(1)（不计排序的栈空间）

## 关键点总结

1. 贪心：维护当前可达范围 [1, reach]，遇到空缺就添加 reach+1
2. 添加 reach+1 后，reach 变为 2*reach+1（最高效地填补空缺）
3. 排序后按序处理硬币

## 易错点

1. 添加 reach+1 而不是添加 1（贪心地选最大能补空缺的面值）
2. reach 从 0 开始，不是 1
3. 最终条件是 reach >= target
