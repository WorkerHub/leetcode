## 题目描述

给定正整数 `n`，返回在 `[1, n]` 范围内具有至少 1 位重复数字的正整数的个数。

**示例 1：**
```
输入：n = 20
输出：1
解释：只有 11 包含重复的数字。
```

**示例 2：**
```
输入：n = 100
输出：10
解释：包含重复数字的数字是：11, 22, 33, 44, 55, 66, 77, 88, 99, 100
```

**示例 3：**
```
输入：n = 1000
输出：262
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

这是一道经典的数位DP问题。与其直接计算有重复数字的个数，不如计算没有重复数字的个数，然后用总数减去。

**核心思想**：
- 答案 = n - (没有重复数字的个数)
- 计算不大于n且无重复数字的数的个数

**分两部分计算**：
1. 位数小于n的无重复数字的数
2. 位数等于n的无重复数字的数

## Python 代码实现

### 方法一：数位DP（推荐）⭐

```python
class Solution:
    def numDupDigitsAtMostN(self, n: int) -> int:
        """
        数位DP：计算无重复数字的个数，然后用n减去
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        # 计算A(m, n) = m!/(m-n)! = m*(m-1)*...*(m-n+1)
        def A(m: int, n: int) -> int:
            """排列数：从m个不同元素中取n个的排列数"""
            if n == 0:
                return 1
            result = 1
            for i in range(n):
                result *= (m - i)
            return result
        
        # 将n转为数字列表
        digits = []
        temp = n
        while temp:
            digits.append(temp % 10)
            temp //= 10
        digits.reverse()
        
        num_digits = len(digits)
        count_no_dup = 0  # 无重复数字的个数
        
        # 1. 计算位数小于n的无重复数字的数
        for i in range(1, num_digits):
            if i == 1:
                # 1位数：1-9，共9个
                count_no_dup += 9
            else:
                # i位数：首位1-9共9种选择，其余位从剩余9个数字中选
                # 9 * A(9, i-1)
                count_no_dup += 9 * A(9, i - 1)
        
        # 2. 计算位数等于n的无重复数字的数
        used = set()  # 已使用的数字
        
        for i in range(num_digits):
            # 计算第i位可以填的数字个数
            for d in range(0 if i > 0 else 1, digits[i]):
                if d not in used:
                    # 如果d可用，计算以d开头的无重复数字个数
                    remaining_positions = num_digits - i - 1
                    available_digits = 10 - len(used) - 1
                    count_no_dup += A(available_digits, remaining_positions)
            
            # 如果当前位的数字已经使用过，后面不可能无重复
            if digits[i] in used:
                break
            
            used.add(digits[i])
        else:
            # 如果所有位都无重复，n本身也算一个
            count_no_dup += 1
        
        # 返回有重复数字的个数
        return n - count_no_dup
```

### 方法二：详细注释版

```python
class Solution:
    def numDupDigitsAtMostN(self, n: int) -> int:
        """
        反向思考：计算[1, n]中无重复数字的个数
        然后用n减去得到有重复数字的个数
        """
        def permutation(m: int, n: int) -> int:
            """
            计算排列数 A(m,n) = m!/(m-n)!
            从m个不同元素中选n个进行排列
            """
            if n == 0:
                return 1
            result = 1
            for i in range(m, m - n, -1):
                result *= i
            return result
        
        # 转换为数字数组
        num_str = str(n)
        length = len(num_str)
        
        # 统计无重复数字的个数
        no_duplicate = 0
        
        # 第一部分：位数小于length的所有无重复数字
        for i in range(1, length):
            if i == 1:
                no_duplicate += 9  # 1-9
            else:
                # 首位：1-9（9种）
                # 其余位：从剩余9个数字中选i-1个排列
                no_duplicate += 9 * permutation(9, i - 1)
        
        # 第二部分：位数等于length的无重复数字
        used_digits = set()
        
        for i, digit in enumerate(num_str):
            d = int(digit)
            
            # 计算当前位填小于d的数字的方案数
            for smaller in range(1 if i == 0 else 0, d):
                if smaller not in used_digits:
                    # 剩余位数
                    remaining = length - i - 1
                    # 可用数字个数
                    available = 10 - len(used_digits) - 1
                    no_duplicate += permutation(available, remaining)
            
            # 如果当前数字已使用过，后续不可能无重复
            if d in used_digits:
                break
            
            used_digits.add(d)
        else:
            # n本身无重复数字
            no_duplicate += 1
        
        return n - no_duplicate
```

## 复杂度分析

- **时间复杂度**：O(D²)，D为n的位数，最多10位
  - 外层循环D次
  - 内层循环最多10次
  - 排列数计算O(D)
- **空间复杂度**：O(D)，存储数字和已使用集合

## 图解示例

以 n = 100 为例：

```
100的数字表示：[1, 0, 0]
长度为3

第一部分：位数小于3的无重复数字
- 1位数：1-9，共9个
- 2位数：首位1-9(9种)，第二位从剩余9个选1个
  9 * A(9,1) = 9 * 9 = 81个
小计：90个

第二部分：3位数且≤100的无重复数字
首位可以填0（但是3位数，所以不能）
首位只能填0，但0 < 1，且0未使用
  剩余2位，可用9个数字
  A(9, 2) = 9 * 8 = 72
但是首位是1时：
  第二位可以填0
  剩余1位，可用8个数字（除了1和0）
  A(8, 1) = 8
  第三位可以填0
  剩余0位
  A(8, 0) = 1
  
100本身：1已用，0已用，0重复 → 不算

无重复总数 = 90 + ... = 90
有重复 = 100 - 90 = 10
```

## 关键点总结

1. **反向思考**：计算无重复数字更简单
2. **分段计算**：位数小于n + 位数等于n
3. **排列组合**：A(m,n) = m!/(m-n)!
4. **数位DP**：逐位枚举，维护已使用数字
5. **提前终止**：发现重复数字立即break

## 易错点

1. **首位不能为0**：多位数的首位只能是1-9
2. **排列数计算**：是排列不是组合，顺序重要
3. **边界条件**：n本身是否无重复要单独判断
4. **已使用集合**：要正确维护used集合
5. **循环范围**：第i位的范围要根据是否首位决定
