## 题目描述

给你一个字符串 `compressed`，它是某个字符串的压缩形式，格式为 `字符 + 数字` 的重复。

返回该字符串的 **更好的压缩方式**：将所有相同字符的出现次数合并，然后按字母顺序排列，格式仍为 `字符 + 数字`。

**示例 1：**
```
输入：compressed = "a3b1a1c2"
输出："a4b1c2"
```

**示例 2：**
```
输入：compressed = "a2b4c1"
输出："a2b4c1"
```

**提示：**
- `2 <= compressed.length <= 6 * 10^4`
- `compressed` 由小写字母和数字组成，字母和数字交替出现，且以字母开头

## 解题思路

解析压缩字符串，统计每个字符的总次数，然后按字母顺序重新构建压缩字符串。

## Python 代码实现

### 方法一：解析 + 排序（推荐）

```python
from collections import defaultdict

class Solution:
    def betterCompression(self, compressed: str) -> str:
        cnt = defaultdict(int)
        i = 0
        n = len(compressed)
        while i < n:
            c = compressed[i]
            i += 1
            # 读取数字
            j = i
            while j < n and compressed[j].isdigit():
                j += 1
            num = int(compressed[i:j])
            cnt[c] += num
            i = j

        # 按字母顺序重建
        return ''.join(c + str(cnt[c]) for c in sorted(cnt))
```

### 方法二：正则解析

```python
import re
from collections import Counter

class Solution:
    def betterCompression(self, compressed: str) -> str:
        pairs = re.findall(r'([a-z])(\d+)', compressed)
        cnt = Counter()
        for c, n in pairs:
            cnt[c] += int(n)
        return ''.join(c + str(cnt[c]) for c in sorted(cnt))
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26)，解析 O(n)，排序 O(26 log 26)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 解析时字符后紧跟数字（可多位）
2. 统计每个字符的总次数
3. 按字母顺序输出

## 易错点

1. 数字可能不止一位（如 "a12"）
2. 排序后构建时，每个字符只输出一次（总次数）
