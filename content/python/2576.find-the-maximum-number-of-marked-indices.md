## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

一次操作，你可以选择两个不同的下标 `i` 和 `j`（两个下标均 **未** 被标记），若 `2 * nums[i] <= nums[j]`，则将 `i` 和 `j` 都标记。

返回可以标记的最多下标数目。

**示例 1：**

```
输入：nums = [3,5,2,4]
输出：2
解释：选 i=2（值2）和 j=1（值5），2*2=4<=5，标记 {2,1}。不能再选更多。
```

**示例 2：**

```
输入：nums = [9,2,5,4]
输出：4
解释：选 (i=1, j=0)：2*2=4<=9；选 (i=3, j=2)：2*4=8>5 不行... 选 (i=1, j=2)：2*2=4<=5；选 (i=3, j=0)：2*4=8<=9。
```

**提示：**

- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**贪心**：排序后，将数组分为两半。前半部分（较小）与后半部分（较大）配对。

对排序后的数组 nums[0..n-1]，将 nums[0..m-1] 与 nums[n-m..n-1] 配对（m 为最多可配对的数量），贪心保证前半最小配后半最小。

**二分答案**：二分可以标记的数量 k（k 必须是偶数），验证是否可行。

可行性验证：排序后，前 k/2 个分别和后 k/2 个配对，检查 `2 * nums[i] <= nums[n - k/2 + i]` 对所有 i < k/2。

## Python 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
from typing import List

class Solution:
    def maxNumOfMarkedIndices(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)

        def can_mark(k):
            # 能否标记 k 对（2k 个元素）
            # 前 k 个最小值和后 k 个最大值配对
            for i in range(k):
                if 2 * nums[i] > nums[n - k + i]:
                    return False
            return True

        lo, hi = 0, n // 2
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_mark(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo * 2
```

### 方法二：双指针贪心

```python
from typing import List

class Solution:
    def maxNumOfMarkedIndices(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        # 贪心：左指针从 0 开始，右指针从 n//2 开始
        left, right = 0, (n + 1) // 2
        count = 0

        while right < n:
            if 2 * nums[left] <= nums[right]:
                count += 2
                left += 1
            right += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后贪心：最小的与最大的配对
2. 可以标记的最多对数 = 满足条件的最大 k（前 k 个和后 k 个两两配对）
3. 双指针：左指针从 0 开始，右指针从中点开始

## 易错点

1. 标记数量必须是偶数（每次操作标记 2 个）
2. 排序后前 k 个元素和后 k 个元素的对应关系：nums[i] vs nums[n-k+i]
3. 双指针中右指针初始位置在中点（不是 n-1）
