## 题目描述

给你一个 `m x n` 的矩阵 `grid` 和一个整数数组 `limits`，长度为 `m`，以及整数 `k`。

对于第 `i` 行，最多可以选择 `limits[i]` 个元素。总共最多选 `k` 个元素。

返回选取元素的**最大总和**。

**示例 1：**

```
输入：grid = [[1,2],[3,4]], limits = [1,2], k = 2
输出：7
解释：第 0 行最多选 1 个：选 2；第 1 行最多选 2 个：选 4，3。但总共只选 2 个。
选 4（第1行）和 2（第0行），和 = 6... 或选 4 和 3，和 = 7（第1行2个，第0行0个）
最优：7
```

**提示：**
- `m == grid.length == limits.length`
- `n == grid[i].length`
- `1 <= m, n <= 500`
- `0 <= grid[i][j] <= 10^5`
- `1 <= limits[i] <= n`
- `1 <= k <= m * n`

## 解题思路

贪心：
1. 对每行取前 `limits[i]` 个最大元素（这些是该行可选元素）
2. 将所有可选元素排序（降序）
3. 取最大的 k 个（不超过 k 个）

注意：每行选的元素总数不超过 limits[i]，且所有行合计不超过 k。

## Python 代码实现

### 方法一：堆排序合并（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxSum(self, grid: List[List[int]], limits: List[int], k: int) -> int:
        # 收集每行可选的最大元素
        candidates = []

        for i, row in enumerate(grid):
            # 取该行最大的 limits[i] 个
            top = sorted(row, reverse=True)[:limits[i]]
            candidates.extend(top)

        # 从所有候选中选最大的 k 个
        candidates.sort(reverse=True)
        return sum(candidates[:k])
```

### 方法二：使用堆

```python
from typing import List
import heapq

class Solution:
    def maxSum(self, grid: List[List[int]], limits: List[int], k: int) -> int:
        # 使用最小堆维护最大 k 个元素
        heap = []  # 最小堆

        for i, row in enumerate(grid):
            # 取该行最大的 limits[i] 个
            top_vals = heapq.nlargest(limits[i], row)
            for v in top_vals:
                heapq.heappush(heap, v)
                if len(heap) > k:
                    heapq.heappop(heap)

        return sum(heap)
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(m * n log n + C log C)，C = sum(limits[i])
  - 空间复杂度：O(C)

## 关键点总结

1. 每行独立取最大的 limits[i] 个元素
2. 全局从所有候选中贪心选最大的 k 个
3. 两步贪心：先行内贪心，再全局贪心

## 易错点

1. 从每行取前 limits[i] 个最大，而不是最小
2. 最终从候选中取 min(k, len(candidates)) 个
3. 不能跨行"借用"额度（每行有自己的 limits[i] 限制）
