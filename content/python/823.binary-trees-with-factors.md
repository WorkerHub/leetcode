## 题目描述

给出一个含有不重复整数元素的数组 `arr`，每个整数 `arr[i]` 均大于 `1`。

用这些整数来构建二叉树，每个整数可以使用任意次数。其中：每个非叶结点的值应等于它的两个子结点的值的乘积。

满足条件的二叉树一共有多少个？答案可能很大，返回 **对** `10^9 + 7` **取余** 的结果。

**示例 1:**
```
输入: arr = [2, 4]
输出: 3
解释: 可以构建三棵二叉树：
  4       4       2
 /         \     / \
2           2   2   2
```

**示例 2:**
```
输入: arr = [2, 4, 5, 10]
输出: 7
解释: 可以构建下列二叉树:
  10      10      10      10      2       4       5
 /  \    /  \    /  \    /  \    / \     / \     / \
2    5  4    5  5    2  5    4  2   2   2   2   5   5
```

## Python 代码实现

```python
from typing import List

class Solution:
    def numFactoredBinaryTrees(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        arr.sort()
        dp = {}
        
        for i, num in enumerate(arr):
            dp[num] = 1  # 单节点树
            
            # 枚举左子树的根
            for j in range(i):
                if num % arr[j] == 0 and num // arr[j] in dp:
                    dp[num] += dp[arr[j]] * dp[num // arr[j]]
                    dp[num] %= MOD
        
        return sum(dp.values()) % MOD
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **动态规划**：dp[x] = 以x为根的树的数量
2. **因子枚举**：左右子树的乘积等于根
3. **排序**：确保子问题先计算
