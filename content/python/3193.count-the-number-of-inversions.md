## 题目描述

给你一个整数 `n` 和一个二维整数数组 `requirements`，`requirements[i] = [endi, cnti]`。

数组 `[0, 1, ..., n-1]` 的一个排列 `perm` 满足：对每个 `requirements[i]`，`perm[0..endi]` 子数组的逆序对数等于 `cnti`。

返回满足所有条件的排列数量，对 `10^9 + 7` 取模。

**示例：**
```
输入：n = 3, requirements = [[2, 2], [0, 0]]
输出：2
解释：满足条件的排列：[2,0,1] 和 [1,0,2]
```

**提示：**
- `2 <= n <= 300`
- `1 <= requirements.length <= n`
- `requirements[i][0] < n`

## 解题思路

DP：`dp[i][j]` = 前 i+1 个元素（0..i）的子数组中有 j 个逆序对的方案数。

将 i 插入前 i 个元素的排列时，新增的逆序对数为 0 到 i（插入到第 0 位有 i 个新逆序对，插入到第 i 位有 0 个）。

转移：`dp[i][j] = sum(dp[i-1][j-k] for k in 0..i)`（可用前缀和优化）。

## Python 代码实现

### 方法一：DP + 前缀和（推荐）

```python
from typing import List

class Solution:
    def numberOfPermutations(self, n: int, requirements: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7

        # 将 requirements 转为字典
        req = {end: cnt for end, cnt in requirements}

        # 确定最大逆序对数
        max_inv = req.get(n - 1, n * (n - 1) // 2)
        # 实际上每个端点的上限不同，这里取全局上限
        max_inv = max(cnt for _, cnt in requirements) if requirements else 0

        # dp[j] = 前 i 个元素有 j 个逆序对的方案数
        # 初始：前 1 个元素，逆序对数为 0
        dp = [0] * (max_inv + 1)
        dp[0] = 1

        for i in range(1, n):
            # 插入第 i 个元素（0-indexed），可新增 0 到 i 个逆序对
            # dp_new[j] = sum(dp[j-k] for k in 0..i if j-k >= 0)
            # = prefix[j] - prefix[j-i-1]
            prefix = [0] * (max_inv + 2)
            for j in range(max_inv + 1):
                prefix[j + 1] = (prefix[j] + dp[j]) % MOD

            new_dp = [0] * (max_inv + 1)
            for j in range(max_inv + 1):
                lo = max(0, j - i)
                hi = j
                new_dp[j] = (prefix[hi + 1] - prefix[lo]) % MOD

            # 应用约束
            if i in req:
                cnt = req[i]
                if cnt > max_inv:
                    return 0
                # 只保留 j == cnt 的方案
                forced = new_dp[cnt]
                new_dp = [0] * (max_inv + 1)
                new_dp[cnt] = forced

            dp = new_dp

        target = req.get(n - 1, None)
        if target is not None:
            return dp[target] % MOD
        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n * max_inv)，max_inv 最大 n^2/2
- 空间复杂度：O(max_inv)

## 关键点总结

1. 逐步插入元素，维护逆序对数的 DP
2. 前缀和优化将每步转移从 O(i) 降至 O(1)
3. 遇到约束时，将非约束值的 DP 归零

## 易错点

1. 约束在中间节点时，需要在对应步骤强制归零
2. 前缀和的边界处理
