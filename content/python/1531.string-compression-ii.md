## 题目描述

行程编码是一种字符串压缩方法，将连续相同字符序列替换为"字符+出现次数"（出现1次则只写字符）。

给你一个字符串 `s` 和一个整数 `k`。你需要**删除至多 k 个字符**，使得剩下字符串的行程编码长度最小。返回最小可能的行程编码长度。

**示例 1：**
```
输入：s = "aaabcccd", k = 2
输出：4
解释：删除两个 b/c 字符后，如 "aaccc" 压缩为 "a2c3" 长度 4，或删掉 bcc 剩 "aaad" 长度3。
```

**提示：**
- `1 <= s.length <= 100`
- `0 <= k <= s.length`
- `s` 只包含小写英文字母

## 解题思路

### 区间 DP

定义 `dp[i][j]` = 对字符串 `s[0..i-1]` 删除 `j` 个字符后，最小行程编码长度。

**状态转移：**
枚举字符串中一段连续相同字符作为最后一段，或枚举删除位置：

更实用的定义：`dp[i][j]` = `s[i:]` 保留，且已使用 `j` 次删除，从位置 `i` 到末尾的最小编码长度。

实际标准做法：`dp[i][j]` = 前 `i` 个字符删去 `j` 个后的最小编码长度。

对每个位置 `i`，枚举最后一组字符 `c = s[t]`（`t <= i`），将 `t` 到 `i` 中的所有非 `c` 字符删掉，计算这段的编码长度。

## 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def getLengthOfOptimalCompression(self, s: str, k: int) -> int:
        from functools import lru_cache

        n = len(s)

        def run_len(count: int) -> int:
            """行程编码中 count 个字符的长度贡献"""
            if count == 0:
                return 0
            if count == 1:
                return 1
            elif count < 10:
                return 2
            elif count < 100:
                return 3
            else:
                return 4

        @lru_cache(maxsize=None)
        def dp(i: int, last: str, last_cnt: int, rem: int) -> int:
            """
            i: 当前处理到第 i 个字符
            last: 上一段的字符
            last_cnt: 上一段已有的数量
            rem: 剩余可删除次数
            返回从 i 开始的最小编码长度增量
            """
            if rem < 0:
                return float('inf')
            if i == n:
                return 0
            # 选择1: 删除 s[i]
            delete = dp(i + 1, last, last_cnt, rem - 1)
            # 选择2: 保留 s[i]
            if s[i] == last:
                # 接续上一段，last_cnt -> last_cnt+1
                # 长度增量：run_len(last_cnt+1) - run_len(last_cnt)
                inc = run_len(last_cnt + 1) - run_len(last_cnt)
                keep = inc + dp(i + 1, last, last_cnt + 1, rem)
            else:
                # 开始新段
                keep = 1 + dp(i + 1, s[i], 1, rem)

            return min(delete, keep)

        return dp(0, '', 0, k)
```

### 方法二：二维 DP（迭代）

```python
class Solution:
    def getLengthOfOptimalCompression(self, s: str, k: int) -> int:
        n = len(s)
        # dp[i][j] = 前 i 个字符删去 j 个后的最小编码长度
        INF = float('inf')
        dp = [[INF] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        def run_len(c: int) -> int:
            if c <= 0: return 0
            if c == 1: return 1
            if c < 10: return 2
            if c < 100: return 3
            return 4

        for i in range(1, n + 1):
            for j in range(min(i, k) + 1):
                # 选择1: 删除 s[i-1]
                if j > 0:
                    dp[i][j] = min(dp[i][j], dp[i-1][j-1])
                # 选择2: 保留 s[i-1]，枚举与之配对的起始位置
                cnt = 0
                del_cnt = 0
                for l in range(i, 0, -1):
                    if s[l-1] == s[i-1]:
                        cnt += 1
                    else:
                        del_cnt += 1
                    if j - del_cnt >= 0:
                        dp[i][j] = min(dp[i][j],
                                       dp[l-1][j - del_cnt] + run_len(cnt))

        return min(dp[n])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（记忆化） | O(N^2 * K * 26) | O(N^2 * K * 26) |
| 方法二（迭代） | O(N^2 * K) | O(N * K) |

N=100, K=100，方法二约 10^6 次操作，可以接受。

## 关键点总结

1. 行程编码长度：1个字符贡献1，10以上需要3位数字
2. 枚举最后一段字符的起始位置，计算删除中间非目标字符的代价
3. 用 `run_len(count)` 函数计算编码长度

## 易错点

- `run_len` 函数要正确处理各区间（1, 2-9, 10-99, 100+）
- 枚举最后一段时，中间不同字符需要计为删除次数
