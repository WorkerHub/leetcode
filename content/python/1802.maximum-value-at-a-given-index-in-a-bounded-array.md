## 题目描述

给你三个正整数 `n`、`index` 和 `maxSum`，需要构造一个满足下列条件的数组 `nums`：
- `nums.length == n`
- `nums[i]` 是正整数，即 `nums[i] >= 1`
- `abs(nums[i] - nums[i+1]) <= 1`
- `nums` 中所有元素之和不超过 `maxSum`
- `nums[index]` 的值最大化

返回 `nums[index]` 的最大值。

**示例 1：**
```
输入：n = 4, index = 2, maxSum = 6
输出：2
```

**示例 2：**
```
输入：n = 6, index = 1, maxSum = 10
输出：3
```

**提示：**
- `1 <= n <= maxSum <= 10^9`
- `0 <= index < n`

## 解题思路

**二分查找 + 贪心验证**

对 `nums[index]` 的值进行二分查找。对于给定的目标值 `v`，判断能否构造满足条件的数组：

以 `index` 为中心，两侧的元素尽可能小（每步减 1，到 1 后保持为 1）。用数学公式计算以 `v` 为峰值时的最小数组之和：
- 左侧长度为 `left = index`，右侧长度为 `right = n - index - 1`
- 对于某一侧长度为 `L`，峰值为 `v`：如果 `L >= v`，则该侧之和为 `v*(v-1)/2 + (L - v + 1)`（先递减到1，剩余填1）；否则为 `(v + v - L) * (L + 1) / 2`（等差数列）

若最小总和 <= `maxSum`，则 `v` 可行。

## 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def maxValue(self, n: int, index: int, maxSum: int) -> int:
        def calc_sum(v: int, length: int) -> int:
            """计算从峰值 v 开始，向一侧延伸 length 个元素的最小和（含峰值侧）"""
            if length >= v:
                # v 递减到 1 需要 v-1 步，剩余 length - (v-1) 个填 1
                return v * (v + 1) // 2 + (length - v)
            else:
                # 全部是从 v 下降的等差数列
                return (v + v - length) * (length + 1) // 2

        left, right = 1, maxSum
        while left < right:
            mid = (left + right + 1) // 2
            # 计算以 mid 为 nums[index] 值时的最小总和
            total = calc_sum(mid, index) + calc_sum(mid, n - index - 1) - mid
            if total <= maxSum:
                left = mid
            else:
                right = mid - 1
        return left
```

### 方法二：二分查找（分段计算版）

```python
class Solution:
    def maxValue(self, n: int, index: int, maxSum: int) -> int:
        def min_sum(peak: int, count: int) -> int:
            """count 个位置，最右侧为 peak，向左递减，到 1 后保持 1，返回最小和"""
            if peak >= count:
                # 足够递减，形成 count, count-1, ..., peak-count+1 的等差数列
                # 等差数列：首项 peak-count+1，末项 peak，共 count 项
                return (peak - count + 1 + peak) * count // 2
            else:
                # 前 count - peak 个为 1，后 peak 个为 1,2,...,peak
                return (count - peak) + peak * (peak + 1) // 2

        lo, hi = 1, maxSum
        while lo < hi:
            mid = (lo + hi + 1) // 2
            # index 左侧有 index 个元素，右侧有 n-index-1 个元素
            s = min_sum(mid, index + 1) + min_sum(mid, n - index) - mid
            if s <= maxSum:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- **时间复杂度**：O(log(maxSum))，二分查找的范围是 [1, maxSum]
- **空间复杂度**：O(1)，只使用常数额外空间

## 关键点总结

1. 对答案进行二分查找，而非对数组元素枚举
2. 最优策略是让 `nums[index]` 为峰值，两侧尽可能小
3. 用等差数列公式快速计算某一侧的最小和，避免逐一枚举
4. 注意边界：当峰值高度超过该侧长度时，需要在低端填 1

## 易错点

- 等差数列公式中首末项的计算容易出错
- 二分查找边界取 left 还是 right 需根据是否满足条件判断
- 计算总和时峰值本身不要重复计算
