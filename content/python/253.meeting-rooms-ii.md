## 题目描述

给你一个会议时间安排的数组 `intervals`，每个会议时间都会包括开始和结束的时间 `intervals[i] = [starti, endi]`，返回所需会议室的最小数量。

**示例 1：**

```
输入：intervals = [[0,30],[5,10],[15,20]]
输出：2
解释：
- 会议1: [0,30]
- 会议2: [5,10]
- 会议3: [15,20]
在时间点 5，会议1和会议2同时进行，需要 2 个会议室
```

**示例 2：**

```
输入：intervals = [[7,10],[2,4]]
输出：1
解释：两个会议不重叠，只需要 1 个会议室
```

**提示：**
- `1 <= intervals.length <= 10^4`
- `0 <= starti < endi <= 10^6`

## 解题思路

这道题是 252 题的进阶版，不仅要判断是否冲突，还要求出最少需要多少个会议室。

核心思想有两种：

### 思路一：最小堆（优先队列）

1. 将所有会议按开始时间排序
2. 使用最小堆维护当前正在使用的会议室的结束时间
3. 对于每个新会议：
   - 如果堆顶（最早结束的会议）已经结束，可以复用这个会议室
   - 否则，需要分配新的会议室
4. 堆的大小就是同时需要的最多会议室数量

### 思路二：双指针（扫描线）

1. 分别提取所有会议的开始时间和结束时间
2. 对这两个数组分别排序
3. 使用双指针扫描：
   - 遇到开始时间，会议室数量 +1
   - 遇到结束时间，会议室数量 -1
4. 记录过程中的最大值

## Python 代码实现

### 方法一：最小堆（推荐）⭐

```python
from typing import List
import heapq

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        """
        使用最小堆追踪会议室的结束时间
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        if not intervals:
            return 0
        
        # 按照会议开始时间排序
        intervals.sort(key=lambda x: x[0])
        
        # 最小堆，存储每个会议室的结束时间
        heap = []
        
        # 遍历每个会议
        for interval in intervals:
            start, end = interval[0], interval[1]
            
            # 如果最早结束的会议已经结束，可以复用会议室
            if heap and heap[0] <= start:
                heapq.heappop(heap)
            
            # 将当前会议的结束时间加入堆
            heapq.heappush(heap, end)
        
        # 堆的大小就是需要的会议室数量
        return len(heap)
```

### 方法二：双指针扫描线（推荐）⭐

```python
from typing import List

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        """
        扫描线算法：分别处理开始和结束事件
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        if not intervals:
            return 0
        
        # 分别提取开始时间和结束时间
        starts = sorted([i[0] for i in intervals])
        ends = sorted([i[1] for i in intervals])
        
        rooms = 0  # 当前使用的会议室数量
        max_rooms = 0  # 需要的最大会议室数量
        start_ptr = 0  # 开始时间指针
        end_ptr = 0  # 结束时间指针
        
        # 使用双指针扫描
        while start_ptr < len(starts):
            # 如果有会议开始时间 < 最早的结束时间，需要新会议室
            if starts[start_ptr] < ends[end_ptr]:
                rooms += 1
                max_rooms = max(max_rooms, rooms)
                start_ptr += 1
            else:
                # 有会议结束，释放会议室
                rooms -= 1
                end_ptr += 1
        
        return max_rooms
```

### 方法三：事件排序（更直观的扫描线）

```python
from typing import List

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        """
        将开始和结束看作事件，统一排序处理
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        events = []
        
        # 创建事件：(时间, 类型)
        # 开始事件标记为 1，结束事件标记为 -1
        for interval in intervals:
            events.append((interval[0], 1))   # 会议开始
            events.append((interval[1], -1))  # 会议结束
        
        # 排序：先按时间，再按类型（结束优先于开始）
        # 这样如果一个会议刚好结束，另一个开始，可以复用会议室
        events.sort(key=lambda x: (x[0], x[1]))
        
        rooms = 0
        max_rooms = 0
        
        for event in events:
            rooms += event[1]
            max_rooms = max(max_rooms, rooms)
        
        return max_rooms
```

### 方法四：暴力解法（用于对比）

```python
from typing import List

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        """
        暴力解法：检查每个时间点有多少会议同时进行
        时间复杂度：O(n * max_time)
        空间复杂度：O(max_time)
        不推荐，仅用于理解
        """
        if not intervals:
            return 0
        
        # 找到时间范围
        max_time = max(interval[1] for interval in intervals)
        
        # 记录每个时间点有多少会议
        timeline = [0] * (max_time + 1)
        
        for start, end in intervals:
            for t in range(start, end):
                timeline[t] += 1
        
        return max(timeline)
```

## 复杂度分析

**方法一（最小堆）：**
- 时间复杂度：O(n log n)，排序 O(n log n) + 堆操作 O(n log n)
- 空间复杂度：O(n)，堆的大小最多为 n

**方法二（双指针）：**
- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(n)，需要存储开始和结束时间数组

**方法四（暴力）：**
- 时间复杂度：O(n * max_time)
- 空间复杂度：O(max_time)

## 关键点总结

1. **排序是基础**：所有方法都需要先排序或处理时间顺序
2. **最小堆的意义**：维护最早结束的会议，判断能否复用会议室
3. **扫描线思想**：将问题转化为处理开始和结束事件
4. **双指针技巧**：分别处理有序的开始和结束时间
5. **贪心策略**：总是优先复用最早结束的会议室

## 易错点

1. **堆中存储的内容**
   ```python
   # 错误：存储整个区间
   heapq.heappush(heap, interval)
   
   # 正确：只存储结束时间
   heapq.heappush(heap, end)
   ```

2. **双指针的比较条件**
   ```python
   # 注意使用 < 而不是 <=
   # 如果一个会议刚好结束，另一个开始，可以复用会议室
   if starts[start_ptr] < ends[end_ptr]:
       rooms += 1
   ```

3. **事件排序的优先级**
   ```python
   # 结束事件应该优先于开始事件
   # 这样可以在时间相同时先释放会议室
   events.sort(key=lambda x: (x[0], x[1]))
   # 其中结束事件为 -1，开始事件为 1
   ```

4. **忘记更新最大值**：在双指针方法中，要实时更新 `max_rooms`
