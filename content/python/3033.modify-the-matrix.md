## 题目描述

给你一个 `m x n` 的整数矩阵 `matrix`，将矩阵中所有值为 `-1` 的元素替换为该元素所在列的最大值。

返回替换后的矩阵。

**示例 1：**
```
输入：matrix = [[1,2,-1],[4,-1,6],[-1,5,7]]
输出：[[1,2,6],[4,5,6],[4,5,7]]
```

**提示：**
- `m == matrix.length`
- `n == matrix[0].length`
- `2 <= m, n <= 50`
- `-1 <= matrix[i][j] <= 100`

## 解题思路

1. 先计算每列的最大值（排除 -1）
2. 将所有 -1 替换为对应列的最大值

## Python 代码实现

### 方法一：两遍扫描（推荐）

```python
from typing import List

class Solution:
    def modifiedMatrix(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])

        # 计算每列的最大值
        col_max = []
        for j in range(n):
            max_val = max(matrix[i][j] for i in range(m) if matrix[i][j] != -1)
            col_max.append(max_val)

        # 替换 -1
        result = [row[:] for row in matrix]
        for i in range(m):
            for j in range(n):
                if result[i][j] == -1:
                    result[i][j] = col_max[j]

        return result
```

### 方法二：列表推导简洁版

```python
from typing import List

class Solution:
    def modifiedMatrix(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        # 每列最大值
        col_max = [max(matrix[i][j] for i in range(m) if matrix[i][j] != -1) for j in range(n)]

        return [
            [col_max[j] if matrix[i][j] == -1 else matrix[i][j] for j in range(n)]
            for i in range(m)
        ]
```

## 复杂度分析

- 时间复杂度：O(m * n)，两遍扫描矩阵
- 空间复杂度：O(n)，存储列最大值

## 关键点总结

1. 先计算每列最大值（忽略 -1）
2. 再将 -1 替换为对应列最大值
3. 题目保证每列至少有一个非 -1 的值

## 易错点

1. 计算列最大值时要排除 -1
2. 注意返回新矩阵而不是原地修改（或原地修改后返回同一矩阵，均可）
