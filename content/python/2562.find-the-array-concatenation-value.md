## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

**拼接值** = 通过以下操作不断将数组对折，累计所有拼接结果的和：
1. 若数组不为空，拼接首尾两个元素（即将 nums[0] 和 nums[-1] 拼接成字符串转为整数加入累积和），然后删除它们
2. 若只剩一个元素，直接加入累积和

返回 `nums` 的拼接值。

**示例 1：**

```
输入：nums = [7, 52, 2, 4]
输出：596
解释：
- 拼接 7 和 4 → 74，删除后 [52, 2]
- 拼接 52 和 2 → 522，删除后 []
- 拼接值 = 74 + 522 = 596
```

**示例 2：**

```
输入：nums = [5, 14, 13, 8, 12]
输出：673
```

**提示：**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`

## 解题思路

双指针：`left` 从头，`right` 从尾，每次取两端拼接，直到两指针相遇。

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def findTheArrayConcVal(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        total = 0

        while left < right:
            # 拼接首尾元素
            concat = int(str(nums[left]) + str(nums[right]))
            total += concat
            left += 1
            right -= 1

        if left == right:
            # 奇数长度，中间元素直接加入
            total += nums[left]

        return total
```

### 方法二：Python 列表模拟

```python
from typing import List

class Solution:
    def findTheArrayConcVal(self, nums: List[int]) -> int:
        nums = list(nums)
        total = 0
        while len(nums) > 1:
            total += int(str(nums[0]) + str(nums[-1]))
            nums = nums[1:-1]
        if nums:
            total += nums[0]
        return total
```

## 复杂度分析

- 方法一时间复杂度：O(n * d)，d 为最大数字位数
- 方法二时间复杂度：O(n²)，列表切片
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 双指针从两端向中间移动，模拟对折操作
2. 拼接用字符串操作：`str(a) + str(b)` 转为整数
3. 奇数长度时，最后一个元素单独加入

## 易错点

1. 拼接是字符串级别的，不是算术加法（7 和 4 拼接是 74，不是 11）
2. 奇数个元素时，最中间的元素直接加入，不需要拼接
3. 双指针终止条件：`left < right`，等于时单独处理
