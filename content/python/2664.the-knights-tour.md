## 题目描述

给你两个正整数 `m` 和 `n`，以及两个整数 `r` 和 `c`，分别表示 `m x n` 棋盘上骑士的初始行列（0-indexed）。

骑士每次移动按马的方式（L形），需要访问棋盘上每个格子恰好一次。返回一个 `m x n` 矩阵，`grid[i][j]` 表示骑士在第几步（0-indexed）访问 `(i,j)`。若不存在这样的路径，返回空数组。

**示例：**
```
输入：m=1, n=1, r=0, c=0
输出：[[0]]
```

**数据范围：**
- 1 <= m, n <= 5
- 0 <= r < m, 0 <= c < n

## 解题思路

回溯法：从起点出发，尝试所有 8 种马的移动方式，使用 Warnsdorff's 启发式（优先选择下一步可移动方向最少的格子）来加速找到解。

## Python 代码实现

### 方法一：回溯 + Warnsdorff 启发式（推荐）

```python
from typing import List

class Solution:
    def tourOfKnight(self, m: int, n: int, r: int, c: int) -> List[List[int]]:
        grid = [[-1] * n for _ in range(m)]
        moves = [(-2,-1),(-2,1),(-1,-2),(-1,2),(1,-2),(1,2),(2,-1),(2,1)]

        def count_moves(x, y):
            """计算从 (x,y) 出发可以移动的格数（Warnsdorff 启发）"""
            cnt = 0
            for dx, dy in moves:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == -1:
                    cnt += 1
            return cnt

        def backtrack(x, y, step):
            grid[x][y] = step
            if step == m * n - 1:
                return True

            # Warnsdorff：按下一步可移动数升序排序（优先选择出路少的）
            next_moves = []
            for dx, dy in moves:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == -1:
                    next_moves.append((count_moves(nx, ny), nx, ny))
            next_moves.sort()

            for _, nx, ny in next_moves:
                if backtrack(nx, ny, step + 1):
                    return True

            grid[x][y] = -1  # 回溯
            return False

        if backtrack(r, c, 0):
            return grid
        return []
```

### 方法二：纯回溯（无启发式，适用于小棋盘）

```python
from typing import List

class Solution:
    def tourOfKnight(self, m: int, n: int, r: int, c: int) -> List[List[int]]:
        grid = [[-1] * n for _ in range(m)]
        moves = [(-2,-1),(-2,1),(-1,-2),(-1,2),(1,-2),(1,2),(2,-1),(2,1)]

        def backtrack(x, y, step):
            grid[x][y] = step
            if step == m * n - 1:
                return True
            for dx, dy in moves:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == -1:
                    if backtrack(nx, ny, step + 1):
                        return True
            grid[x][y] = -1
            return False

        if backtrack(r, c, 0):
            return grid
        return []
```

## 复杂度分析

- 方法一：借助 Warnsdorff 启发，实践中接近 O(mn)
- 方法二：最坏 O(8^(mn))，但 m,n <= 5，可接受
- 空间复杂度：O(mn)

## 关键点总结

1. 马的 8 种移动方式：L 形（一格+两格）
2. Warnsdorff 启发式：优先选择下一步可选格最少的，减少回溯
3. 回溯时恢复 grid 状态

## 易错点

1. 马的 8 种移动方向要写全
2. 越界和已访问格的检查
3. 注意 step 从 0 开始，最后一步为 mn-1
