## 题目描述

给你一个 `n x n` 整数矩阵 `grid`。

生成一个大小为 `(n-2) x (n-2)` 的整数矩阵 `maxLocal`，其中 `maxLocal[i][j]` 等于 `grid` 中以 `(i+1, j+1)` 为中心的 `3x3` 矩阵中的**最大值**。

换句话说，`maxLocal[i][j]` 是 `grid[i..i+2][j..j+2]` 中的最大值。

返回生成的矩阵。

**示例：**
```
输入：grid = [[9,9,8,1],[5,6,2,6],[8,2,6,4],[6,2,2,2]]
输出：[[9,9],[8,6]]
```

**提示：**
- `n == grid.length == grid[i].length`
- `3 <= n <= 100`

## 解题思路

直接枚举每个 3x3 区域的最大值。对每个 `(i, j)`（0 <= i < n-2，0 <= j < n-2），计算以 `(i, j)` 为左上角的 3x3 区域最大值。

## 代码实现

### 方法一：枚举 3x3 区域（推荐）

```python
from typing import List

class Solution:
    def largestLocal(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        result = []
        
        for i in range(n - 2):
            row = []
            for j in range(n - 2):
                # 计算以 (i, j) 为左上角的 3x3 区域最大值
                local_max = max(
                    grid[r][c]
                    for r in range(i, i + 3)
                    for c in range(j, j + 3)
                )
                row.append(local_max)
            result.append(row)
        
        return result
```

### 方法二：使用嵌套列表推导

```python
from typing import List

class Solution:
    def largestLocal(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        return [
            [
                max(grid[r][c] for r in range(i, i + 3) for c in range(j, j + 3))
                for j in range(n - 2)
            ]
            for i in range(n - 2)
        ]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 | O(n^2 * 9) = O(n^2) | O(1)（不含输出） |

## 关键点总结

1. 输出矩阵大小为 `(n-2) x (n-2)`，每个位置对应一个 3x3 区域。
2. `grid[i..i+2][j..j+2]` 的最大值，通过嵌套循环 9 次枚举求最大值。
3. 由于 n <= 100，O(n^2 * 9) 完全可以接受。

## 易错点

- 输出矩阵的 `(i, j)` 对应 grid 中以 `(i, j)` 为左上角（不是中心）的 3x3 区域。
- 索引范围：`i` 和 `j` 均从 0 到 `n-3`（包含），即 `range(n-2)`。
