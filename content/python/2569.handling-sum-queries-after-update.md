## 题目描述

给你两个整数数组 `nums1` 和 `nums2`（长度均为 n），以及一个二维整数数组 `queries`（长度为 q）。

对于查询 `queries[i]`：
- 类型 1 `[1, l, r]`：将 nums1[l..r] 的所有元素翻转（0 变 1，1 变 0）
- 类型 2 `[2, p, 0]`：将 nums2 的所有元素加上 `p * sum(nums1)`
- 类型 3 `[3, 0, 0]`：查询 nums2 的所有元素之和

返回所有类型 3 查询的结果数组。

**提示：**

- `1 <= n, q <= 10^5`
- `nums1[i]` 为 0 或 1
- `0 <= nums2[i] <= 10^9`
- `1 <= p <= 10^6`

## 解题思路

**线段树**（带懒惰传播）维护 nums1：支持区间翻转和查询区间和。

对类型 1：线段树区间翻转操作。
对类型 2：加上 `p * 线段树.query(0, n-1)` 到 nums2 的全局累加器。
对类型 3：输出 `sum(nums2) + 全局累加器`。

预计算 `sum(nums2)` 是固定的，全局累加器 `extra` 累加所有类型 2 的贡献。

## Python 代码实现

### 方法一：线段树 + 区间翻转（推荐）

```python
from typing import List

class Solution:
    def handleQuery(self, nums1: List[int], nums2: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums1)
        # 线段树
        tree = [0] * (4 * n)  # 区间和
        lazy = [False] * (4 * n)  # 懒惰翻转标记

        def build(node, l, r):
            if l == r:
                tree[node] = nums1[l]
                return
            mid = (l + r) // 2
            build(2*node, l, mid)
            build(2*node+1, mid+1, r)
            tree[node] = tree[2*node] + tree[2*node+1]

        def push_down(node, l, r):
            if lazy[node]:
                mid = (l + r) // 2
                # 翻转左子树
                tree[2*node] = (mid - l + 1) - tree[2*node]
                lazy[2*node] = not lazy[2*node]
                # 翻转右子树
                tree[2*node+1] = (r - mid) - tree[2*node+1]
                lazy[2*node+1] = not lazy[2*node+1]
                lazy[node] = False

        def update(node, l, r, ql, qr):
            if ql <= l and r <= qr:
                tree[node] = (r - l + 1) - tree[node]
                lazy[node] = not lazy[node]
                return
            push_down(node, l, r)
            mid = (l + r) // 2
            if ql <= mid:
                update(2*node, l, mid, ql, qr)
            if qr > mid:
                update(2*node+1, mid+1, r, ql, qr)
            tree[node] = tree[2*node] + tree[2*node+1]

        def query(node, l, r, ql, qr):
            if ql <= l and r <= qr:
                return tree[node]
            push_down(node, l, r)
            mid = (l + r) // 2
            res = 0
            if ql <= mid:
                res += query(2*node, l, mid, ql, qr)
            if qr > mid:
                res += query(2*node+1, mid+1, r, ql, qr)
            return res

        build(1, 0, n - 1)
        base_sum2 = sum(nums2)
        extra = 0
        result = []

        for q in queries:
            if q[0] == 1:
                update(1, 0, n - 1, q[1], q[2])
            elif q[0] == 2:
                extra += q[1] * query(1, 0, n - 1, 0, n - 1)
            else:
                result.append(base_sum2 + extra)

        return result
```

### 方法二：BIT（树状数组）版本（较简洁）

```python
from typing import List

class Solution:
    def handleQuery(self, nums1: List[int], nums2: List[int], queries: List[List[int]]) -> List[int]:
        # 此处用线段树方案，BIT 不支持区间翻转的懒惰传播
        # 保留线段树方案作为主要方法
        return self.handleQuery_segtree(nums1, nums2, queries)

    def handleQuery_segtree(self, nums1, nums2, queries):
        n = len(nums1)
        size = 1
        while size < n:
            size <<= 1
        tree = [0] * (2 * size)
        flip = [False] * (2 * size)
        lengths = [0] * (2 * size)

        # 初始化
        for i in range(n):
            tree[size + i] = nums1[i]
            lengths[size + i] = 1
        for i in range(size - 1, 0, -1):
            tree[i] = tree[2*i] + tree[2*i+1]
            lengths[i] = lengths[2*i] + lengths[2*i+1]

        def push_down(i):
            if flip[i]:
                for child in [2*i, 2*i+1]:
                    tree[child] = lengths[child] - tree[child]
                    flip[child] = not flip[child]
                flip[i] = False

        def update(l, r, node=1, nl=0, nr=None):
            if nr is None:
                nr = size - 1
            if l <= nl and nr <= r:
                tree[node] = lengths[node] - tree[node]
                flip[node] = not flip[node]
                return
            push_down(node)
            mid = (nl + nr) // 2
            if l <= mid:
                update(l, r, 2*node, nl, mid)
            if r > mid:
                update(l, r, 2*node+1, mid+1, nr)
            tree[node] = tree[2*node] + tree[2*node+1]

        base = sum(nums2)
        extra = 0
        ans = []

        for q in queries:
            t = q[0]
            if t == 1:
                update(q[1], q[2])
            elif t == 2:
                extra += q[1] * tree[1]
            else:
                ans.append(base + extra)

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，线段树操作
- 空间复杂度：O(n)，线段树空间

## 关键点总结

1. 线段树支持区间翻转（0/1 翻转），用懒惰标记延迟更新
2. 类型 2 只需查询 nums1 的总和，不修改 nums2（用全局变量累积）
3. 类型 3 直接返回 sum(nums2) + 累积的额外值

## 易错点

1. 翻转操作：区间 [l, r] 的新和 = (r - l + 1) - 旧和
2. 懒惰标记需要在向下访问前传播（push_down）
3. 类型 2 改变的是 nums2 的所有元素，等价于全局加法
