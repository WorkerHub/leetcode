## 题目描述

给你字符串 `s` 和整数 `k`，请返回字符串 `s` 中长度为 `k` 的单个子字符串中可能包含的最大元音字母数。

英文中的**元音字母**为（`a`，`e`，`i`，`o`，`u`）。

**示例 1：**
```
输入：s = "abciiidef", k = 3
输出：3
解释：子字符串 "iii" 包含 3 个元音字母。
```

**示例 2：**
```
输入：s = "aeiou", k = 2
输出：2
解释：任意长度为 2 的子字符串都包含 2 个元音字母。
```

**示例 3：**
```
输入：s = "leetcode", k = 3
输出：2
解释："lee"、"eet" 和 "ode" 都包含 2 个元音字母。
```

**示例 4：**
```
输入：s = "rhythms", k = 4
输出：0
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成
- `1 <= k <= s.length`

## 解题思路

**滑动窗口**是本题的核心思路。

不必每次重新计算整个窗口内的元音数，而是利用"窗口向右滑动"的特性：
- 窗口右移一位时，加入新字符（若是元音则计数 +1）
- 同时移出最左侧字符（若是元音则计数 -1）

这样每次滑动只需 O(1) 的操作，整体时间复杂度降至 O(n)。

**算法步骤：**
1. 初始化：统计前 k 个字符中的元音数
2. 向右滑动窗口：逐步移入右侧字符、移出左侧字符
3. 每次更新最大值

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set('aeiou')  # 元音字符集合，O(1) 查询

        # 初始化：计算第一个窗口（前 k 个字符）的元音数
        current = sum(1 for c in s[:k] if c in vowels)
        result = current

        # 滑动窗口：从第 k 个字符开始向右扫描
        for i in range(k, len(s)):
            # 加入右侧新字符
            if s[i] in vowels:
                current += 1
            # 移出左侧旧字符（左侧字符下标为 i - k）
            if s[i - k] in vowels:
                current -= 1
            # 更新最大值
            result = max(result, current)

        return result
```

### 方法二：前缀和（O(n) 预处理 + O(1) 查询）

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(s)

        # 构建前缀和：prefix[i] 表示 s[0..i-1] 中元音个数
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if s[i] in vowels else 0)

        # 查询每个长度为 k 的子串中的元音数
        result = 0
        for i in range(n - k + 1):
            # s[i..i+k-1] 中的元音数 = prefix[i+k] - prefix[i]
            count = prefix[i + k] - prefix[i]
            result = max(result, count)

        return result
```

### 方法三：暴力法（了解，不推荐大数据量）

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        result = 0
        n = len(s)

        # 枚举每个起始位置
        for i in range(n - k + 1):
            # 统计子串 s[i:i+k] 中的元音数
            count = sum(1 for c in s[i:i + k] if c in vowels)
            result = max(result, count)

        return result
        # 时间复杂度 O(n*k)，不适合大数据
```

## 复杂度分析

**方法一（滑动窗口）：**
- 时间复杂度：O(n)，每个字符只处理一次
- 空间复杂度：O(1)，只用了常数额外空间

**方法二（前缀和）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，前缀和数组

**方法三（暴力）：**
- 时间复杂度：O(n × k)
- 空间复杂度：O(1)

## 关键点总结

1. 滑动窗口的核心：窗口右移时，只需处理进入和离开窗口的两个字符，不需要重新统计整个窗口
2. 用 `set('aeiou')` 做元音查询，时间复杂度 O(1)，比 `in 'aeiou'` 稍快（虽然实际差异很小）
3. 左侧移出的字符下标为 `i - k`，右侧新加入的字符下标为 `i`

## 易错点

- 初始化窗口时不要忘记计算前 k 个字符的元音数
- 滑动时 `i` 从 `k` 开始，而不是从 `0` 或 `1` 开始
- 左侧移出字符的下标是 `i - k`，容易写错
