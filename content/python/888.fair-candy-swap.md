## 题目描述

Alice 和 Bob 拥有不同总数量的糖果。给你两个数组 aliceSizes 和 bobSizes ，aliceSizes[i] 是 Alice 拥有的第 i 盒糖果中的糖果数量，bobSizes[j] 是 Bob 拥有的第 j 盒糖果中的糖果数量。

两人想要互相交换一盒糖果，这样在交换之后，他们就可以拥有相同总数量的糖果。

返回一个整数数组 answer，其中 answer[0] 是 Alice 必须交换的糖果盒中的糖果的数目，answer[1] 是 Bob 必须交换的糖果盒中的糖果的数目。如果存在多个答案，你可以返回其中 任何一个 。题目保证存在答案。

**提示：**
- 1 <= aliceSizes.length, bobSizes.length <= 10^4
- 1 <= aliceSizes[i], bobSizes[j] <= 10^5
- Alice 和 Bob 的糖果总数量不同。
- 题目保证至少存在一个有效答案。

## 解题思路

**数学方法：**
1. sumA - x + y = sumB - y + x
2. 化简得：y = x + (sumB - sumA) / 2
3. 遍历 Alice 的每盒，用哈希表查找 Bob 是否有对应的盒子

## Python 代码实现

```python
class Solution:
    def fairCandySwap(self, aliceSizes: List[int], bobSizes: List[int]) -> List[int]:
        sumA, sumB = sum(aliceSizes), sum(bobSizes)
        diff = (sumB - sumA) // 2
        bobSet = set(bobSizes)
        
        for x in aliceSizes:
            y = x + diff
            if y in bobSet:
                return [x, y]
        
        return []
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(n)

## 关键点总结

1. **数学推导**：列方程求解
2. **哈希查找**：O(1) 时间查找
3. **整数除法**：差值一定是偶数
