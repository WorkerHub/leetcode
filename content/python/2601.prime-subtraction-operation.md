## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，数组长度为 `n`。

你可以对数组执行任意次如下操作：
- 选择一个下标 `i`（0 <= i < n），以及一个质数 `p`（要求 `p` 严格小于 `nums[i]`），然后从 `nums[i]` 减去 `p`。

如果通过上述操作，能使 `nums` 成为严格递增数组，则返回 `true`；否则返回 `false`。

**注意：** 每个下标最多只能执行一次操作。

**示例 1：**
```
输入：nums = [4,9,6,10]
输出：true
解释：
- 对 nums[0]=4，减去质数 3，得 1
- 对 nums[1]=9，减去质数 7，得 2
- 对 nums[2]=6，减去质数 3，得 3
- 对 nums[3]=10，减去质数 3，得 7
结果 [1,2,3,7] 严格递增
```

**示例 2：**
```
输入：nums = [6,8,11,12]
输出：true
解释：数组已经严格递增
```

**示例 3：**
```
输入：nums = [5,8,3]
输出：false
```

**数据范围：**
- 1 <= nums.length <= 1000
- 1 <= nums[i] <= 1000

## 解题思路

贪心 + 二分查找：从左到右遍历数组，对每个元素尽可能减去最大的质数，使其刚好大于前一个元素（贪心地让当前值尽量小，给后续元素留更多空间）。

具体步骤：
1. 预先筛出所有不超过 1000 的质数（埃拉托斯特尼筛法）
2. 对每个 `nums[i]`，需要找一个质数 `p`，使得 `nums[i] - p > prev`
3. 等价于 `p < nums[i] - prev`，用二分查找找满足条件的最大质数
4. 若找不到（即 `nums[i] - prev <= 0` 或最大可减质数仍不够），返回 `false`

## Python 代码实现

### 方法一：贪心 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def primeSubOperation(self, nums: List[int]) -> bool:
        # 埃拉托斯特尼筛法，预处理 1000 以内的质数
        sieve = [True] * 1001
        sieve[0] = sieve[1] = False
        for i in range(2, 32):
            if sieve[i]:
                for j in range(i * i, 1001, i):
                    sieve[j] = False
        primes = [i for i in range(2, 1001) if sieve[i]]

        prev = 0  # 前一个元素处理后的值
        for num in nums:
            # 需要找最大质数 p < num - prev
            # 即在 primes 中找严格小于 (num - prev) 的最大值
            upper = num - prev  # p 必须严格小于此值
            if upper <= 1:
                # 不存在这样的质数，且 num 本身也不够大
                if num <= prev:
                    return False
                prev = num
                continue
            # 二分查找：找 < upper 的最大质数
            idx = bisect.bisect_left(primes, upper) - 1
            if idx >= 0:
                best_prime = primes[idx]
                prev = num - best_prime
            else:
                # 没有可用质数，直接用 num
                prev = num
            if prev <= (prev - (num - prev)):  # 检查是否严格递增
                pass
            # 实际判断：处理后的值必须 > 上一个处理后的值
            # prev 已经更新为 num - best_prime 或 num
            # 需要重新验证
        return True

    def primeSubOperation(self, nums: List[int]) -> bool:
        # 预处理质数
        sieve = [True] * 1001
        sieve[0] = sieve[1] = False
        for i in range(2, 32):
            if sieve[i]:
                for j in range(i * i, 1001, i):
                    sieve[j] = False
        primes = [i for i in range(2, 1001) if sieve[i]]

        prev = 0
        for num in nums:
            # 找最大质数 p，满足 p < num 且 num - p > prev
            # 即 p < num - prev，且 p < num
            limit = num - prev  # p 需严格小于此值，且正数
            if limit <= 0:
                return False
            # 二分查找 primes 中 < limit 的最大值
            idx = bisect.bisect_left(primes, limit) - 1
            if idx >= 0:
                prev = num - primes[idx]
            else:
                prev = num  # 没有合适质数，不减
            if prev <= 0 and num > 0:
                # prev 必须 > 上一个 prev（这里是 0 起始）
                pass
        return True
```

### 方法二：清晰实现版

```python
from typing import List
import bisect

class Solution:
    def primeSubOperation(self, nums: List[int]) -> bool:
        # 筛质数
        def get_primes(n):
            sieve = [True] * (n + 1)
            sieve[0] = sieve[1] = False
            for i in range(2, int(n**0.5) + 1):
                if sieve[i]:
                    for j in range(i*i, n+1, i):
                        sieve[j] = False
            return [i for i in range(2, n+1) if sieve[i]]

        primes = get_primes(1000)
        prev = 0  # 上一个操作后的结果

        for num in nums:
            # 需要 num - p > prev，即 p < num - prev
            # 选最大的满足条件的质数使 num - p 最小
            diff = num - prev
            if diff <= 0:
                return False  # 即使不减也无法大于 prev
            # 找严格小于 diff 的最大质数
            pos = bisect.bisect_left(primes, diff) - 1
            if pos >= 0:
                prev = num - primes[pos]
            else:
                prev = num  # 没有合适质数，保持原值
        return True
```

## 复杂度分析

- 时间复杂度：O(n log P)，n 为数组长度，P 为质数个数（约 168 个）
- 空间复杂度：O(P)，存储质数列表

## 关键点总结

1. 贪心策略：每次减去尽可能大的质数，使当前值尽量小，为后续元素留余地
2. 预处理质数列表，用二分查找加速
3. 关键约束：p < nums[i] 且 nums[i] - p > prev
4. 若 nums[i] <= prev 且无合适质数可减，直接返回 false

## 易错点

1. 质数要求严格小于 `nums[i]`，不能等于
2. 每个下标最多操作一次，但贪心选最大质数已满足此约束
3. 边界：若差值 <= 1，无可用质数（最小质数为 2）
