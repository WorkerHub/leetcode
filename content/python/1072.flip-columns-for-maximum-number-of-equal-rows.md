## 题目描述

给定一个 `m x n` 的二进制矩阵 `matrix`。

你可以选择矩阵中的任意数量的列并翻转其上的每个单元格（即，将单元格的值从 0 变为 1，或从 1 变为 0）。

返回在执行若干次翻转后，能够使得矩阵中所有值相等的行的最大数量。

**示例 1：**
```
输入：matrix = [[0,1],[1,1]]
输出：1
解释：不进行翻转，有 1 行所有值相等
```

**示例 2：**
```
输入：matrix = [[0,1],[1,0]]
输出：2
解释：翻转第一列后，两行的值都相等
```

**示例 3：**
```
输入：matrix = [[0,0,0],[0,0,1],[1,1,0]]
输出：2
解释：翻转第一、第二列后，前两行的值相等
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 300`
- `matrix[i][j]` 为 0 或 1

## 解题思路

这道题的核心在于理解**行的模式**：

1. **关键观察**：
   - 如果两行要通过翻转列变成相同，它们必须满足某种"互补关系"
   - 例如：`[0,1,0]` 和 `[1,0,1]` 是互补的，翻转所有列后可以变成相同
   - 又如：`[0,1,0]` 和 `[0,1,0]` 本身就相同，不需要翻转

2. **模式定义**：
   - 两行具有相同模式，当且仅当它们要么完全相同，要么完全相反
   - 我们可以将每一行标准化：如果第一个元素是 1，就翻转整行
   - 这样，所有具有相同模式的行会被映射到同一个标准形式

3. **算法流程**：
   - 遍历每一行，将其转换为标准形式（或使用原始形式和补码形式作为键）
   - 使用哈希表统计每种模式出现的次数
   - 返回出现次数最多的模式的计数

4. **为什么这样做有效？**
   - 具有相同模式的行，可以通过相同的列翻转操作变成相等
   - 我们要找的就是能够通过统一操作变成相等的最大行数

## Python 代码实现

### 方法一：哈希表统计模式（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def maxEqualRowsAfterFlips(self, matrix: List[List[int]]) -> int:
        # 使用哈希表统计每种模式的出现次数
        pattern_count = Counter()
        
        for row in matrix:
            # 将行转换为标准形式：如果第一个元素是 1，翻转整行
            # 这样，相同模式的行会有相同的标准形式
            if row[0] == 1:
                # 翻转：0->1, 1->0
                pattern = tuple(1 - x for x in row)
            else:
                pattern = tuple(row)
            
            pattern_count[pattern] += 1
        
        # 返回出现次数最多的模式
        return max(pattern_count.values())
```

### 方法二：同时存储原始和补码模式

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxEqualRowsAfterFlips(self, matrix: List[List[int]]) -> int:
        pattern_count = defaultdict(int)
        
        for row in matrix:
            # 将行转换为元组（原始形式）
            original = tuple(row)
            # 计算补码形式
            complement = tuple(1 - x for x in row)
            
            # 只统计原始形式（因为原始和补码会映射到同一组）
            # 使用字典序较小的作为标准形式
            pattern = min(original, complement)
            pattern_count[pattern] += 1
        
        return max(pattern_count.values())
```

### 方法三：字符串哈希

```python
from typing import List
from collections import Counter

class Solution:
    def maxEqualRowsAfterFlips(self, matrix: List[List[int]]) -> int:
        pattern_count = Counter()
        
        for row in matrix:
            # 将行转换为字符串形式
            # 标准化：以第一个元素为基准
            pattern = ''.join(str(x ^ row[0]) for x in row)
            pattern_count[pattern] += 1
        
        return max(pattern_count.values())
```

### 方法四：暴力枚举（理解用）

```python
from typing import List

class Solution:
    def maxEqualRowsAfterFlips(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        max_count = 0
        
        # 对每一行，尝试找出有多少行可以与它通过翻转变成相同
        for i in range(m):
            count = 0
            for j in range(m):
                # 检查 matrix[j] 是否与 matrix[i] 相同或完全相反
                if all(matrix[i][k] == matrix[j][k] for k in range(n)) or \
                   all(matrix[i][k] != matrix[j][k] for k in range(n)):
                    count += 1
            
            max_count = max(max_count, count)
        
        return max_count
```

## 复杂度分析

**方法一、二、三（推荐）：**
- **时间复杂度**：O(m × n)
  - 遍历 m 行，每行处理 n 个元素
  - 哈希表操作平均 O(1)
- **空间复杂度**：O(m × n)
  - 哈希表最多存储 m 个不同的模式，每个模式长度为 n

**方法四：**
- **时间复杂度**：O(m² × n)，双重循环遍历所有行对
- **空间复杂度**：O(1)，只使用常数额外空间

原始矩阵：

## 关键点总结

1. **模式识别**：两行能变成相同的充要条件是它们相同或完全互补
2. **标准化技巧**：将每一行转换为标准形式，简化比较
3. **哈希表应用**：使用 Counter 或 defaultdict 统计模式出现次数
4. **异或操作**：`x ^ row[0]` 可以优雅地实现标准化（以第一个元素为基准）
5. **元组作为键**：Python 中列表不能作为字典键，需要转换为元组

## 易错点

1. **理解错题意**：不是要让所有行都相等，而是找最多有多少行可以变成相等
2. **模式判断**：忘记考虑互补的情况，只比较完全相同的行
3. **哈希键类型**：列表是可变的，不能直接作为字典键，必须转换为元组或字符串
4. **边界情况**：单行矩阵或单列矩阵需要特殊处理（实际上算法自然处理）
5. **翻转理解**：翻转是针对整列，不是单个元素
