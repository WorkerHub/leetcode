## 题目描述

给你一个加权有向图，节点编号从 0 到 n-1，边集 `edges[i] = [u, v, w]`。从节点 0 到节点 n-1 的一条路径的 **总代价** 为路径上所有边权之和。另外，经过中间节点 `v`（非起点和终点）时，需要额外支付 `cost[v]`。

返回从 0 到 n-1 的最小总代价。

**示例 1：**

```
输入：n = 3, edges = [[0,1,1],[1,2,2]], cost = [0,5,0]
输出：8
解释：路径0→1→2，边权1+2=3，过节点1需额外5，总8
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= cost[i] <= 10^4`

## 解题思路

修改 Dijkstra：边权 = 实际边权，到达节点 v（非起点/终点）时额外加 `cost[v]`。

初始化 `dist[0] = 0`，到达非终点的非起点节点时代价 = 路径代价 + cost[v]。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]], cost: List[int]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))

        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            if u == n - 1:
                return d
            for v, w in graph[u]:
                # 经过节点 v 的额外代价（若 v 不是终点）
                node_cost = 0 if v == n - 1 else cost[v]
                nd = d + w + node_cost
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

### 方法二：修改边权（预处理）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]], cost: List[int]) -> int:
        # 将节点代价分摊到入边
        graph = defaultdict(list)
        for u, v, w in edges:
            node_cost = 0 if v == n - 1 else cost[v]
            graph[u].append((v, w + node_cost))

        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    heapq.heappush(heap, (d + w, v))

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)
- 空间复杂度：O(V + E)

## 关键点总结

1. 节点代价等价于增加入边权重
2. 终点 n-1 不需要额外代价（不是"经过"）
3. 起点 0 不需要额外代价

## 易错点

1. 终点的代价不需要加（到达即可）
2. 注意路径可能绕行，需要完整的 Dijkstra
3. 若无法到达返回 -1
