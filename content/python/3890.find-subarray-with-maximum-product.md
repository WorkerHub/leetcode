## 题目描述

给你一个整数数组 `nums`，找到乘积最大的非空连续子数组，返回该子数组。如果有多个答案，返回出现最早的那个。

**示例 1：**

```
输入：nums = [2, 3, -2, 4]
输出：[2, 3]
解释：[2,3] 乘积为 6，是所有子数组中最大的。
```

**示例 2：**

```
输入：nums = [-2, 0, -1]
输出：[-1]
解释：单元素 -1 的乘积为 -1，比 0 大，但 [-2,-1]... 不连续，只有 [-2], [0], [-1], [-2,0], [0,-1], [-2,0,-1]。
最大为 0... 或 -1? 0 > -1 > -2，最大乘积为 0（[0]）。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10 <= nums[i] <= 10`

## 解题思路

在求最大乘积子数组的同时，记录最优子数组的起止位置。

使用动态规划：
- `max_dp[i]` = 以 i 结尾的最大乘积
- `min_dp[i]` = 以 i 结尾的最小乘积（负负得正可能变大）

同时记录每个状态的起始位置。

## Python 代码实现

### 方法一：DP + 位置记录（推荐）

```python
from typing import List

class Solution:
    def maxProductSubarray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        max_prod = nums[0]
        min_prod = nums[0]
        max_start = min_start = 0

        best_prod = nums[0]
        best_start = best_end = 0

        for i in range(1, n):
            v = nums[i]
            candidates_max = [v, max_prod * v, min_prod * v]
            candidates_min = [v, max_prod * v, min_prod * v]

            new_max = max(candidates_max)
            new_min = min(candidates_min)

            # 确定新的起始位置
            if new_max == v:
                max_start = i
            elif new_max == max_prod * v:
                pass  # max_start 不变
            else:
                max_start = min_start

            if new_min == v:
                min_start = i
            elif new_min == min_prod * v:
                pass
            else:
                min_start = max_start

            max_prod = new_max
            min_prod = new_min

            if max_prod > best_prod:
                best_prod = max_prod
                best_start = max_start
                best_end = i

        return nums[best_start:best_end + 1]
```

### 方法二：暴力枚举（小数据验证）

```python
from typing import List

class Solution:
    def maxProductSubarray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        best_prod = float('-inf')
        best_l, best_r = 0, 0

        for l in range(n):
            prod = 1
            for r in range(l, n):
                prod *= nums[r]
                if prod > best_prod or (prod == best_prod and l < best_l):
                    best_prod = prod
                    best_l, best_r = l, r

        return nums[best_l:best_r + 1]
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n^2)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 最大乘积子数组 DP 同时维护最大值和最小值（负数情况）。
2. 记录每个状态的起始位置，以便恢复最优子数组。
3. 多个最优子数组时取最早出现的（字典序最小或下标最小）。

## 易错点

1. 状态转移时需要同时考虑三种情况：单独成子数组、接在最大值后、接在最小值后。
2. 起始位置的追踪需要谨慎，容易出错。
3. 暴力法在大数据时超时，仅用于验证。
