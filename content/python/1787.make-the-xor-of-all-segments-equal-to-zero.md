## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。区间 `[left, right]`（`left <= right`）的**异或值**定义为 `nums[left] XOR nums[left+1] XOR ... XOR nums[right]`。

所有长度为 `k` 的区间的异或值都等于零，则该数组是**合法**的。

请你返回使该数组合法的**最少修改次数**。可以将 `nums` 中任意位置的值改为**任意非负整数**。

**示例 1：**
```
输入：nums = [1,2,0,3,0], k = 1
输出：3
解释：将 nums[0], nums[2], nums[4] 改为 0，得到 [0,2,0,3,0]，每个长度 1 的区间（即每个元素）都为 0
```

**示例 2：**
```
输入：nums = [3,4,5,2,1,7,3,4,7], k = 3
输出：3
```

**提示：**
- `1 <= k <= nums.length <= 2000`
- `0 <= nums[i] < 2^10`

## 解题思路

若所有长度为 k 的区间异或值均为 0，则：
- `nums[0] XOR nums[1] XOR ... XOR nums[k-1] = 0`
- `nums[1] XOR nums[2] XOR ... XOR nums[k] = 0`
- 由此推出 `nums[0] = nums[k] = nums[2k] = ...`，即位置模 k 相同的元素必须相等

设同余组 `g` 为所有索引 `i mod k == g` 的元素组成的集合，需要：
1. 每组内所有元素改为同一个值
2. 所有组的值异或之和为 0

设 `dp[i][v]` 为前 `i+1` 组，第 `i` 组选值 `v` 时的最小修改次数。

对每组，不修改的元素个数 = 该值在组内出现的次数，修改次数 = 组大小 - 出现次数。

状态转移利用贪心：对当前组，枚举选取值 `v`，修改次数为 `group_size - count[v]`。前 i-1 组累积的最小值 + 当前组修改次数。

用前缀最小值优化：维护上一轮 dp 的全局最小值 `prev_min`，对不在本组出现的值，代价为 `prev_min + group_size`；对出现的值，代价为 `min(prev_dp[prev_v] for all prev_v) + group_size - count[v]`（即 `prev_min + group_size - count[v]`）。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        n = len(nums)
        MAX_VAL = 1024  # nums[i] < 2^10
        INF = float('inf')

        # dp[v] = 前几组处理完，当前组异或和为 v 的最小修改次数
        dp = [INF] * MAX_VAL
        dp[0] = 0

        for g in range(k):
            # 第 g 组：索引 g, g+k, g+2k, ...
            group = [nums[g + j * k] for j in range((n - g - 1) // k + 1)]
            size = len(group)
            count = Counter(group)  # 统计每个值的出现次数

            # 上一轮 dp 的全局最小值
            prev_min = min(dp)

            new_dp = [INF] * MAX_VAL
            for v in range(MAX_VAL):
                # 本组选值 v，修改次数 = size - count.get(v, 0)
                # 前缀最小代价 = prev_min（与上一组选什么无关，只要XOR正确）
                # 注：实际上要对所有 prev_v XOR v = 某值的 prev_v 取最小
                # 简化：new_dp[v] = min over prev_v of (dp[prev_v XOR v]) + size - count[v]
                # 可以分两部分：v 在组内出现，用 dp[prev_v] + size - count[v]
                # 全局最小 = prev_min
                new_dp[v] = prev_min + size - count.get(v, 0)

            # 对组内出现的值，可以更精确地优化
            for val, cnt in count.items():
                for prev_v in range(MAX_VAL):
                    # 第 g 组选 val，前面组异或和为 prev_v，则当前总异或和为 prev_v XOR val
                    if dp[prev_v] + size - cnt < new_dp[prev_v ^ val]:
                        new_dp[prev_v ^ val] = dp[prev_v] + size - cnt

            dp = new_dp

        return dp[0]
```

### 方法二：优化版 DP

```python
from typing import List
from collections import Counter

class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        n = len(nums)
        MAX_VAL = 1024
        INF = float('inf')

        dp = [INF] * MAX_VAL
        dp[0] = 0

        for g in range(k):
            group = [nums[i] for i in range(g, n, k)]
            size = len(group)
            count = Counter(group)
            prev_min = min(dp)

            # 新 dp：默认用全局最小代价（组内选不在 count 中的值）
            new_dp = [prev_min + size] * MAX_VAL

            # 对组内出现的值，用更精细的代价
            for val, cnt in count.items():
                for prev_xor in range(MAX_VAL):
                    if dp[prev_xor] == INF:
                        continue
                    target = prev_xor ^ val
                    cost = dp[prev_xor] + size - cnt
                    if cost < new_dp[target]:
                        new_dp[target] = cost

            dp = new_dp

        return dp[0]
```

## 复杂度分析

- **时间复杂度**：O(n/k * k * MAX_VAL) = O(n * MAX_VAL)，每组枚举 MAX_VAL 个值
- **空间复杂度**：O(MAX_VAL)，存储 dp 数组

## 关键点总结

1. 位置 mod k 相同的元素必须相等（由连续 k 个区间异或为 0 推导）
2. 将问题分解为 k 个同余组，每组选一个代表值
3. 所有组的代表值异或之和必须为 0
4. DP 转移时，用全局最小值加速非组内值的计算

## 易错点

1. 每组大小可能不同（当 `n` 不是 `k` 的倍数时）
2. `new_dp` 初始化为 `prev_min + size`（选组外值时代价），不是 INF
3. 最终答案是 `dp[0]`（所有组异或和为 0）
