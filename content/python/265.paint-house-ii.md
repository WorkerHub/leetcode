## 题目描述

假如有一排房子共有 `n` 幢，每个房子可以被粉刷成 `k` 种颜色中的一种。房子粉刷成不同颜色的成本也是不同的。

你需要粉刷所有的房子并且使其相邻的两个房子颜色不能相同。

成本用一个 `n × k` 的矩阵 `costs` 表示：
- `costs[i][j]` 表示粉刷第 `i` 幢房子颜色 `j` 的成本

返回粉刷完所有房子的最小成本。

**示例 1：**
```
输入: costs = [[1,5,3],[2,9,4]]
输出: 5
解释: 
房子 0 刷成颜色 0 的成本为 1
房子 1 刷成颜色 2 的成本为 4
总成本: 1 + 4 = 5
```

**示例 2：**
```
输入: costs = [[1,3],[2,4]]
输出: 5
```

**提示：**
- `costs.length == n`
- `costs[i].length == k`
- `1 <= n <= 100`
- `2 <= k <= 20`
- `1 <= costs[i][j] <= 20`

## 解题思路

这是"粉刷房子 I"的进阶版，从 3 种颜色扩展到 k 种颜色。

**动态规划思路：**

**状态定义：**
- `dp[i][j]` 表示粉刷前 i+1 个房子，且第 i 个房子颜色为 j 的最小成本

**状态转移：**
- `dp[i][j] = costs[i][j] + min(dp[i-1][p])` (p ≠ j)
- 即：第 i 个房子颜色 j 的最小成本 = 当前成本 + 前一个房子非 j 颜色的最小成本

**优化关键：**
- 朴素做法：对于每个 (i, j)，遍历 k 种颜色找最小值，时间复杂度 O(n × k²)
- 优化方法：记录前一行的最小值和次小值，时间复杂度降为 O(n × k)

## Python 代码实现

### 方法一：动态规划 + 最小值优化（推荐）⭐

```python
class Solution:
    def minCostII(self, costs: List[List[int]]) -> int:
        if not costs or not costs[0]:
            return 0
        
        n, k = len(costs), len(costs[0])
        
        # 初始化：第一个房子的成本
        dp = costs[0][:]
        
        for i in range(1, n):
            # 找到前一行的最小值和次小值
            min1 = min2 = float('inf')
            min1_idx = -1
            
            for j in range(k):
                if dp[j] < min1:
                    min2 = min1
                    min1 = dp[j]
                    min1_idx = j
                elif dp[j] < min2:
                    min2 = dp[j]
            
            # 计算当前行
            new_dp = [0] * k
            for j in range(k):
                # 如果当前颜色不是前一行最小值的颜色，使用最小值
                # 否则使用次小值
                if j != min1_idx:
                    new_dp[j] = costs[i][j] + min1
                else:
                    new_dp[j] = costs[i][j] + min2
            
            dp = new_dp
        
        return min(dp)
```

### 方法二：二维 DP（空间未优化）

```python
class Solution:
    def minCostII(self, costs: List[List[int]]) -> int:
        if not costs or not costs[0]:
            return 0
        
        n, k = len(costs), len(costs[0])
        
        # dp[i][j] 表示粉刷前 i+1 个房子，第 i 个房子颜色为 j 的最小成本
        dp = [[0] * k for _ in range(n)]
        
        # 初始化第一行
        dp[0] = costs[0][:]
        
        for i in range(1, n):
            # 找前一行的最小值和次小值
            prev = dp[i - 1][:]
            min1 = min(prev)
            min1_idx = prev.index(min1)
            
            # 找次小值
            min2 = float('inf')
            for j in range(k):
                if j != min1_idx:
                    min2 = min(min2, prev[j])
            
            # 状态转移
            for j in range(k):
                if j != min1_idx:
                    dp[i][j] = costs[i][j] + min1
                else:
                    dp[i][j] = costs[i][j] + min2
        
        return min(dp[-1])
```

### 方法三：原地修改（节省空间）

```python
class Solution:
    def minCostII(self, costs: List[List[int]]) -> int:
        if not costs or not costs[0]:
            return 0
        
        n, k = len(costs), len(costs[0])
        
        for i in range(1, n):
            # 找上一行的最小值和次小值
            min1 = min2 = float('inf')
            min1_idx = -1
            
            for j in range(k):
                if costs[i - 1][j] < min1:
                    min2 = min1
                    min1 = costs[i - 1][j]
                    min1_idx = j
                elif costs[i - 1][j] < min2:
                    min2 = costs[i - 1][j]
            
            # 更新当前行
            for j in range(k):
                if j != min1_idx:
                    costs[i][j] += min1
                else:
                    costs[i][j] += min2
        
        return min(costs[-1])
```

### 方法四：辅助函数提取

```python
class Solution:
    def minCostII(self, costs: List[List[int]]) -> int:
        if not costs or not costs[0]:
            return 0
        
        n, k = len(costs), len(costs[0])
        
        def get_two_mins(arr: List[int]) -> tuple:
            """获取数组中的最小值和次小值及最小值索引"""
            min1 = min2 = float('inf')
            min1_idx = -1
            
            for i, val in enumerate(arr):
                if val < min1:
                    min2 = min1
                    min1 = val
                    min1_idx = i
                elif val < min2:
                    min2 = val
            
            return min1, min2, min1_idx
        
        # 初始化
        dp = costs[0][:]
        
        for i in range(1, n):
            min1, min2, min1_idx = get_two_mins(dp)
            
            new_dp = [
                costs[i][j] + (min1 if j != min1_idx else min2)
                for j in range(k)
            ]
            
            dp = new_dp
        
        return min(dp)
```

### 方法五：暴力 DP（不推荐，超时）

```python
class Solution:
    def minCostII(self, costs: List[List[int]]) -> int:
        """
        时间复杂度 O(n * k^2)，会超时
        仅供理解思路
        """
        if not costs or not costs[0]:
            return 0
        
        n, k = len(costs), len(costs[0])
        dp = costs[0][:]
        
        for i in range(1, n):
            new_dp = [0] * k
            for j in range(k):
                # 遍历前一个房子的所有颜色
                new_dp[j] = costs[i][j] + min(
                    dp[p] for p in range(k) if p != j
                )
            dp = new_dp
        
        return min(dp)
```

## 复杂度分析

### 方法一、二、三、四（最小值优化）
- **时间复杂度**：O(n × k)
  - 遍历 n 个房子
  - 每个房子遍历 k 种颜色
  - 找最小值和次小值是 O(k)
  - 总计：O(n × k)

- **空间复杂度**：
  - 方法一、四：O(k)，只用一维数组
  - 方法二：O(n × k)，二维 DP 数组
  - 方法三：O(1)，原地修改

### 方法五（暴力）
- **时间复杂度**：O(n × k²)，会超时
- **空间复杂度**：O(k)

## 图解示例

以 `costs = [[1,5,3],[2,9,4]]` 为例（k=3, n=2）：

```
第 0 个房子：
  颜色 0: 成本 1
  颜色 1: 成本 5
  颜色 2: 成本 3
  dp = [1, 5, 3]

第 1 个房子：
  前一行: dp = [1, 5, 3]
  最小值: min1 = 1 (索引 0)
  次小值: min2 = 3
  
  颜色 0: 2 + min2 = 2 + 3 = 5 (不能用 min1，因为索引相同)
  颜色 1: 9 + min1 = 9 + 1 = 10
  颜色 2: 4 + min1 = 4 + 1 = 5
  
  dp = [5, 10, 5]

答案: min(dp) = 5
```

## 关键点总结

1. **最小值优化**：记录前一行的最小值和次小值，避免 O(k) 遍历
2. **次小值的作用**：当前颜色等于前一行最小值颜色时，使用次小值
3. **空间优化**：只需要一维数组，滚动更新即可
4. **状态转移核心**：
   ```python
   dp[j] = costs[i][j] + (min1 if j != min1_idx else min2)
   ```
5. **边界条件**：第一行直接使用原始成本

## 易错点

1. **忘记找次小值**：只记录最小值会导致无法处理相同颜色的情况
2. **索引混淆**：要区分颜色索引和最小值索引
3. **空数组处理**：需要检查 `costs` 是否为空
4. **初始化错误**：第一行应该直接用 `costs[0]`，不需要计算
5. **原地修改陷阱**：如果要原地修改，注意不要破坏上一行数据
6. **最小值查找**：要同时记录最小值、次小值和最小值的索引
