## 题目描述

给你一个大小为 `m x n` 的整数矩阵 `isWater`，它代表了一个由**陆地**和**水域**单元格组成的地图。
- `isWater[i][j] == 0` 表示该单元格是陆地单元格。
- `isWater[i][j] == 1` 表示该单元格是水域单元格。

你需要按照下述规则给每个单元格安排高度：
- 每个单元格的高度都必须是非负整数。
- 如果一个单元格是**水域**，那么它的高度必须为 `0`。
- 任意相邻的单元格高度差**至多**为 `1`。

找出这个方案中的**最大高度**，并返回一个大小为 `m x n` 的整数矩阵，其中 `height[i][j]` 是单元格 `(i, j)` 的高度。如果有多种方案，请返回任意一种。

**提示：**
- `m == isWater.length`
- `n == isWater[0].length`
- `1 <= m, n <= 1000`
- `isWater[i][j]` 为 `0` 或 `1`

## 解题思路

多源 BFS：将所有水域单元格作为初始源点（高度 0），然后 BFS 扩展，每向外一层高度加 1。

这样每个陆地单元格的高度就是它到最近水域的距离，且相邻单元格高度差不超过 1。

## 代码实现

### 方法一：多源 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def highestPeak(self, isWater: List[List[int]]) -> List[List[int]]:
        m, n = len(isWater), len(isWater[0])
        height = [[-1] * n for _ in range(m)]
        queue = deque()
        
        # 初始化：所有水域高度为 0，加入队列
        for i in range(m):
            for j in range(n):
                if isWater[i][j] == 1:
                    height[i][j] = 0
                    queue.append((i, j))
        
        # BFS 扩展
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        while queue:
            r, c = queue.popleft()
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and height[nr][nc] == -1:
                    height[nr][nc] = height[r][c] + 1
                    queue.append((nr, nc))
        
        return height
```

### 方法二：初始化为 -1 的替代写法

```python
from typing import List
from collections import deque

class Solution:
    def highestPeak(self, isWater: List[List[int]]) -> List[List[int]]:
        m, n = len(isWater), len(isWater[0])
        
        # 初始化高度：水域为 0，陆地为 -1（未访问）
        height = [[0 if isWater[i][j] else -1 for j in range(n)] for i in range(m)]
        
        # 多源 BFS 起始点
        queue = deque((i, j) for i in range(m) for j in range(n) if isWater[i][j] == 1)
        
        while queue:
            r, c = queue.popleft()
            for dr, dc in ((0,1),(0,-1),(1,0),(-1,0)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and height[nr][nc] == -1:
                    height[nr][nc] = height[r][c] + 1
                    queue.append((nr, nc))
        
        return height
```

## 复杂度分析

- **时间复杂度**：O(m * n)，每个单元格最多入队一次
- **空间复杂度**：O(m * n)，高度矩阵和队列

## 关键点总结

1. 多源 BFS 是多个源点同时出发的 BFS，适合"所有点到最近特殊点的距离"问题
2. 水域作为源点，BFS 扩展即得到每个点到最近水域的距离
3. 用 `-1` 标记未访问的陆地，避免重复访问

## 易错点

- 多源 BFS 需要把所有源点一起加入初始队列
- 不能先逐个 BFS 再取最小（效率低），要同时 BFS
