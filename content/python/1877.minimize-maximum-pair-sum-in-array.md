## 题目描述

数组中 **对** 的定义为下标不同的两个元素的组合，一个数组的 **对和** 定义为所有对的元素之和。将 `nums` 中的元素配成 `n/2` 对，每个元素只属于一对，返回最小的**最大对和**。

**示例 1：**
```
输入：nums = [3,5,2,3]
输出：7
解释：配对为 (2,5) 和 (3,3)，最大对和为 7
```

**示例 2：**
```
输入：nums = [3,5,4,2,4,6]
输出：8
解释：配对为 (2,6), (3,5), (4,4)，最大对和为 8
```

**提示：**
- `n == nums.length`，n 为偶数
- `2 <= n <= 10^5`

## 解题思路

**贪心 + 双指针**：

排序后，将最小值与最大值配对（双指针从两端向中间）。这样可以均衡各对之间的差异，使最大对和最小。

**正确性**：设排序后数组为 a[0] <= a[1] <= ... <= a[n-1]，最优策略是 a[0]+a[n-1], a[1]+a[n-2], ...。

## 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def minPairSum(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        max_pair = 0
        for i in range(n // 2):
            max_pair = max(max_pair, nums[i] + nums[n - 1 - i])
        return max_pair
```

### 方法二：排序后 zip

```python
from typing import List

class Solution:
    def minPairSum(self, nums: List[int]) -> int:
        nums.sort()
        return max(a + b for a, b in zip(nums, reversed(nums)))
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：最小值配最大值，可以让各对之间的差异最小，从而最小化最大对和
2. 排序后双指针从两端向中间，每对取和，返回最大值

## 易错点

- 只配对 n/2 次（不是 n 次）
- 双指针从两端向中间，不是从中间向两端
