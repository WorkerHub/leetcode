## 题目描述

给你一个长度为 **偶数** 的整数数组 `nums`，将其分成两个长度相等的数组 `arr1` 和 `arr2`。

若可以使两个数组中都没有相同的元素，则返回 `true`，否则返回 `false`。

注意：数组中每个元素只能分配给一个数组（arr1 或 arr2）。

**示例 1：**
```
输入：nums = [3,2,2,3]
输出：false
```

**示例 2：**
```
输入：nums = [1,1,2,4]
输出：true
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `nums.length` 为偶数

## 解题思路

要使两个数组都没有重复元素，整个 `nums` 中每个元素最多出现 2 次（各分一个到两个数组）。

若某元素出现 3 次或以上，无论如何分配，至少有一个数组会有重复元素。

**结论：** 若所有元素出现次数 <= 2，则可以成功分割；否则不行。

## Python 代码实现

### 方法一：计数判断（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def isPossibleToSplit(self, nums: List[int]) -> bool:
        freq = Counter(nums)
        return all(v <= 2 for v in freq.values())
```

### 方法二：使用 set

```python
from typing import List

class Solution:
    def isPossibleToSplit(self, nums: List[int]) -> bool:
        from collections import Counter
        return max(Counter(nums).values()) <= 2
```

### 方法三：手动统计

```python
from typing import List

class Solution:
    def isPossibleToSplit(self, nums: List[int]) -> bool:
        seen = {}
        for x in nums:
            seen[x] = seen.get(x, 0) + 1
            if seen[x] > 2:
                return False
        return True
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每个元素最多出现 2 次，各放一个到两个数组，两个数组内均无重复
2. 若某元素出现 >= 3 次，不可能实现（鸽巢原理）

## 易错点

1. 两个数组**各自内部**不能有重复，但两个数组间可以有相同元素
2. 不需要实际构造两个数组，只需判断频率是否 <= 2
