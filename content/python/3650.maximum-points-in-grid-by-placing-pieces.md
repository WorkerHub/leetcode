## 题目描述

给你一个 `m x n` 的矩阵 `grid`，每个格子有权值。你需要在矩阵中放置若干棋子，每个棋子覆盖一个格子，约束条件是：任意两个棋子不在同一行也不在同一列（类似八皇后）。

返回最大总权值。

**示例 1：**

```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：15
解释：选 (0,2)=3, (1,1)=5, (2,0)=7，但有更优：选(0,0)=1,(1,1)=5,(2,2)=9=15
实际最优：(0,2)+(1,0)+(2,1)=3+4+8=15 或 (0,0)+(1,1)+(2,2)=1+5+9=15
```

**提示：**

- `1 <= m, n <= 100`
- `-10^4 <= grid[i][j] <= 10^4`

## 解题思路

等价于最大权二分匹配（行作为左侧节点，列作为右侧节点），用匈牙利算法或 KM 算法求解。

或者对于小规模，用 DP（状态压缩）：`dp[mask]` 表示使用了 `mask` 中的列，选了 `popcount(mask)` 行时的最大权值。

## Python 代码实现

### 方法一：状态压缩 DP（小 n）（推荐）

```python
from typing import List

class Solution:
    def maxPoints(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # dp[mask] = 选了 mask 对应列的行（按行序选）的最大权值
        dp = [-float('inf')] * (1 << n)
        dp[0] = 0

        for i in range(m):
            new_dp = dp[:]
            for mask in range(1 << n):
                row = bin(mask).count('1')  # 已选了几行
                if row >= m:
                    continue
                if dp[mask] == -float('inf'):
                    continue
                # 为第 row 行（即第 i 行，若 row == i）选一列
                if row == i:
                    for j in range(n):
                        if not (mask >> j & 1):
                            new_mask = mask | (1 << j)
                            new_dp[new_mask] = max(new_dp[new_mask], dp[mask] + grid[i][j])
            dp = new_dp

        return max(dp)
```

### 方法二：KM 算法（最大权二分匹配）

```python
from typing import List

class Solution:
    def maxPoints(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        # KM 算法求最大权完全匹配
        # 左侧 m 个行节点，右侧 n 个列节点
        # 为保证完全匹配，取 k = min(m, n)

        k = min(m, n)
        # 对 grid 取前 k 行，KM 找最大权匹配
        lx = [max(grid[i]) for i in range(k)]
        ly = [0] * n
        match_l = [-1] * k
        match_r = [-1] * n

        def dfs(u, visited_r, slack):
            for v in range(n):
                if visited_r[v]:
                    continue
                gap = lx[u] + ly[v] - grid[u][v]
                if gap == 0:
                    visited_r[v] = True
                    if match_r[v] == -1 or dfs(match_r[v], visited_r, slack):
                        match_l[u] = v
                        match_r[v] = u
                        return True
                else:
                    slack[v] = min(slack[v], gap)
            return False

        for u in range(k):
            while True:
                visited_r = [False] * n
                slack = [INF] * n
                if dfs(u, visited_r, slack):
                    break
                delta = min(slack[v] for v in range(n) if not visited_r[v])
                for i in range(k):
                    if any(visited_r):
                        pass
                lx[u] -= delta
                for v in range(n):
                    if visited_r[v]:
                        ly[v] += delta

        return sum(grid[match_r[v]][v] for v in range(n) if match_r[v] != -1)
```

## 复杂度分析

- 时间复杂度：O(min(m,n) * m * n)（KM），O(2^n * n)（状态压缩 DP，n<=20 可用）
- 空间复杂度：O(2^n) 或 O(m+n)

## 关键点总结

1. 问题等价于最大权二分匹配
2. KM 算法是最大权二分匹配的经典算法
3. 小 n 时可用状态压缩 DP

## 易错点

1. 允许不放满所有行/列（若权值可能为负，可以选择不放）
2. KM 算法需处理不完全二部图（添加权值为 0 的虚拟边）
