## 题目描述

在给定单词列表 `wordlist` 的情况下，我们希望实现一个拼写检查器，将查询单词转换为正确的单词。

对于给定的查询单词 `query`，拼写检查器将会处理两类拼写错误：
- **大小写**：如果查询单词与单词列表中的某个单词在不考虑大小写的情况下匹配，则返回匹配的单词。
  - 例如：`wordlist = ["yellow"]`，`query = "YellOw"`，结果为 `"yellow"`
  - 例如：`wordlist = ["Yellow"]`，`query = "yellow"`，结果为 `"Yellow"`
  - 例如：`wordlist = ["yellow"]`，`query = "yellow"`，结果为 `"yellow"`
- **元音错误**：如果在将查询单词和单词列表中的单词中的元音（'a'，'e'，'i'，'o'，'u'）分别替换为元音通配符后，查询单词与单词列表中的某个单词匹配，则返回匹配的单词。
  - 例如：`wordlist = ["YellOw"]`，`query = "yollow"`，结果为 `"YellOw"`
  - 例如：`wordlist = ["YellOw"]`，`query = "yeellow"`，结果为 `""`（不匹配）

此外，拼写检查器应遵循以下优先级规则：
1. 当查询单词完全匹配（大小写敏感）单词列表中的某个单词时，应返回相同的单词。
2. 当查询单词大小写不敏感地匹配到单词列表中的某个单词时，应返回匹配的第一个单词。
3. 当查询单词可以通过替换元音匹配到单词列表中的某个单词时，应返回匹配的第一个单词。
4. 如果没有匹配项，则返回空字符串。

给出一些查询 `queries`，返回一个单词列表 `answer`，其中 `answer[i]` 是由查询 `query = queries[i]` 得到的正确单词。

**示例 1：**
```
输入：wordlist = ["KiTe","kite","hare","Hare"], queries = ["kite","Kite","KiTe","Hare","HARE","Hear","hear","keti","keet","keto"]
输出：["kite","KiTe","KiTe","Hare","hare","","","KiTe","","KiTe"]
```

**示例 2：**
```
输入：wordlist = ["yellow"], queries = ["YellOw"]
输出：["yellow"]
```

**提示：**
- `1 <= wordlist.length, queries.length <= 5000`
- `1 <= wordlist[i].length, queries[i].length <= 7`
- `wordlist[i]` 和 `queries[i]` 仅由英文字母组成

## 解题思路

这道题需要实现一个拼写检查器，按优先级匹配单词。

**核心思想：**
1. 建立三个哈希表：
   - 完全匹配：原始单词
   - 大小写不敏感匹配：小写形式 -> 原始单词
   - 元音替换匹配：元音替换为 `*` -> 原始单词
2. 查询时按优先级依次查找

**元音模式：**
- 将所有元音字母 (a, e, i, o, u) 替换为统一的符号（如 `*`）
- 例如："yellow" -> "y*ll*w"

## Python 代码实现

### 方法一：三个哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def spellchecker(self, wordlist: List[str], queries: List[str]) -> List[str]:
        # 元音集合
        vowels = set('aeiouAEIOU')
        
        def to_pattern(word):
            """将单词转换为元音模式（元音替换为 *）"""
            return ''.join('*' if c in vowels else c for c in word)
        
        # 三个哈希表
        exact_match = set(wordlist)  # 完全匹配
        case_insensitive = {}  # 大小写不敏感
        vowel_insensitive = {}  # 元音不敏感
        
        # 构建哈希表
        for word in wordlist:
            # 小写形式（只记录第一次出现的）
            lower = word.lower()
            if lower not in case_insensitive:
                case_insensitive[lower] = word
            
            # 元音模式（只记录第一次出现的）
            pattern = to_pattern(lower)
            if pattern not in vowel_insensitive:
                vowel_insensitive[pattern] = word
        
        # 处理查询
        result = []
        for query in queries:
            # 1. 完全匹配
            if query in exact_match:
                result.append(query)
                continue
            
            # 2. 大小写不敏感匹配
            lower_query = query.lower()
            if lower_query in case_insensitive:
                result.append(case_insensitive[lower_query])
                continue
            
            # 3. 元音不敏感匹配
            pattern_query = to_pattern(lower_query)
            if pattern_query in vowel_insensitive:
                result.append(vowel_insensitive[pattern_query])
                continue
            
            # 4. 没有匹配
            result.append("")
        
        return result
```

### 方法二：优化版（使用字典方法）

```python
from typing import List

class Solution:
    def spellchecker(self, wordlist: List[str], queries: List[str]) -> List[str]:
        def devowel(word):
            """将元音替换为 #"""
            return ''.join('#' if c in 'aeiou' else c for c in word.lower())
        
        # 精确匹配
        words_exact = set(wordlist)
        
        # 大小写匹配：存储第一个出现的单词
        words_cap = {}
        for word in wordlist:
            words_cap.setdefault(word.lower(), word)
        
        # 元音匹配：存储第一个出现的单词
        words_vow = {}
        for word in wordlist:
            words_vow.setdefault(devowel(word), word)
        
        # 处理查询
        def solve(query):
            if query in words_exact:
                return query
            
            if query.lower() in words_cap:
                return words_cap[query.lower()]
            
            if devowel(query) in words_vow:
                return words_vow[devowel(query)]
            
            return ""
        
        return [solve(q) for q in queries]
```

### 方法三：类封装版

```python
from typing import List

class SpellChecker:
    def __init__(self, wordlist: List[str]):
        self.exact = set(wordlist)
        self.lower_case = {}
        self.vowel_pattern = {}
        
        for word in wordlist:
            lower = word.lower()
            if lower not in self.lower_case:
                self.lower_case[lower] = word
            
            pattern = self._to_pattern(lower)
            if pattern not in self.vowel_pattern:
                self.vowel_pattern[pattern] = word
    
    def _to_pattern(self, word):
        """转换为元音模式"""
        vowels = 'aeiou'
        return ''.join('*' if c in vowels else c for c in word)
    
    def check(self, query):
        """检查单词"""
        # 1. 精确匹配
        if query in self.exact:
            return query
        
        # 2. 大小写匹配
        lower = query.lower()
        if lower in self.lower_case:
            return self.lower_case[lower]
        
        # 3. 元音匹配
        pattern = self._to_pattern(lower)
        if pattern in self.vowel_pattern:
            return self.vowel_pattern[pattern]
        
        # 4. 无匹配
        return ""

class Solution:
    def spellchecker(self, wordlist: List[str], queries: List[str]) -> List[str]:
        checker = SpellChecker(wordlist)
        return [checker.check(q) for q in queries]
```

## 复杂度分析

### 所有方法
- **时间复杂度**：
  - 预处理：O(W × L)，W 是 wordlist 长度，L 是单词平均长度
  - 查询：O(Q × L)，Q 是 queries 长度
  - 总计：O((W + Q) × L)
- **空间复杂度**：O(W × L)，存储哈希表

## 关键点总结

1. **优先级处理**：按精确匹配 -> 大小写匹配 -> 元音匹配的顺序
2. **哈希表应用**：用三个哈希表分别处理三种匹配
3. **元音处理**：统一替换为某个符号（如 `*` 或 `#`）
4. **首次记录**：大小写和元音匹配只记录第一次出现的单词
5. **代码简洁**：使用 `setdefault` 或条件判断避免重复赋值

## 易错点

1. **优先级顺序**：必须按题目要求的顺序检查
2. **首次匹配**：对于大小写和元音匹配，要返回第一个匹配的单词
3. **大小写**：元音替换前要先转小写
4. **集合 vs 字典**：精确匹配用集合即可，其他需要字典
5. **空字符串**：无匹配时返回 `""`，不是 `None`
