## 题目描述

给你两个非负整数 `low` 和 `high`，请你返回 `low` 和 `high` 之间（包括二者）**奇数的数目**。

**示例 1：**
```
输入：low = 3, high = 7
输出：3
解释：奇数为 3, 5, 7
```

**示例 2：**
```
输入：low = 8, high = 10
输出：1
解释：奇数为 9
```

**提示：**
- `0 <= low <= high <= 10^9`

## 解题思路

### 数学公式

`[1, n]` 中奇数的数量 = `(n + 1) // 2`。

所以 `[low, high]` 中奇数的数量 = `count(high) - count(low - 1)`，其中 `count(n) = (n + 1) // 2`。

直接展开：若 `high` 是奇数，则 `[low, high]` 中奇数数量多 1 个；若 `low` 是奇数，也多 1 个。

## 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # [1, n] 中奇数数量 = (n + 1) // 2
        def count_odds_up_to(n: int) -> int:
            return (n + 1) // 2

        # [low, high] = [1, high] - [1, low-1]
        return count_odds_up_to(high) - count_odds_up_to(low - 1)
```

### 方法二：直接计算

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # 总数量的一半
        ans = (high - low) // 2
        # 如果两端有奇数，再加 1
        if low % 2 == 1 or high % 2 == 1:
            ans += 1
        return ans
```

### 方法三：极简写法

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # (high + 1) // 2 - low // 2
        return (high + 1) // 2 - low // 2
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. `[1, n]` 中奇数数量 = `(n + 1) // 2`（1, 3, 5, ... 共 ceil(n/2) 个）
2. `[low, high]` 的奇数数量 = `count(high) - count(low - 1)`
3. 极简公式：`(high + 1) // 2 - low // 2`

## 易错点

- 注意是闭区间 `[low, high]`，所以是减去 `count(low - 1)` 而不是 `count(low)`
- 方法二中，两端都是奇数时只加 1（因为区间包含 low 和 high 本身）
