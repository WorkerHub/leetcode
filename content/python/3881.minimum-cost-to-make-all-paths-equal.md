## 题目描述

给你一个有向图（DAG），共 `n` 个节点，边 `edges[i] = [u, v, w]`。你可以修改边的权重，代价为 1（将权重改为任意非负整数）。

使得从源点到汇点的所有路径长度相等，返回最小修改边数。

**提示：**
- `2 <= n <= 1000`
- DAG（有向无环图）

## 解题思路

使用动态规划，找到所有路径并使它们等长：
1. 计算从源到每个节点的最短和最长路径。
2. 若某条边两端的路径差不满足条件，需要修改。
3. 贪心：尽量不修改边，找最多可保持不变的边。

## Python 代码实现

### 方法一：DAG DP（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]]) -> int:
        # 构建邻接表和入度
        graph = defaultdict(list)
        in_degree = [0] * n

        for u, v, w in edges:
            graph[u].append((v, w))
            in_degree[v] += 1

        # 拓扑排序 + DP
        # dist_from[u] = 从源点到 u 的最长路径
        dist_from = [0] * n
        queue = deque([0])  # 假设节点 0 为源点

        while queue:
            u = queue.popleft()
            for v, w in graph[u]:
                dist_from[v] = max(dist_from[v], dist_from[u] + w)
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)

        # 目标路径长度 = 从源到汇的最长路径
        target = dist_from[n - 1]

        # 找需要修改的边数
        # 若 dist_from[u] + w != dist_from[v]，且 dist_from[v] = target 可达，则需要修改
        # 等价于：保留不需要修改的边数，其余修改

        # 贪心：若 dist_from[u] + w == dist_from[v]，则边 (u,v) 无需修改
        can_keep = sum(1 for u, v, w in edges if dist_from[u] + w == dist_from[v])

        return len(edges) - can_keep
```

### 方法二：最短路 Dijkstra

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))

        # 从源点的最短路
        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        # 目标路径 = 最短路到达 n-1
        target = dist[n - 1]
        can_keep = sum(1 for u, v, w in edges if dist[u] + w == dist[v] == dist[n-1] or
                      dist[u] + w == dist[v])

        return len(edges) - can_keep
```

## 复杂度分析

- 时间复杂度：O(V + E)，DAG 拓扑排序
- 空间复杂度：O(V + E)

## 关键点总结

1. DAG 上的 DP 通过拓扑排序求从源点到各节点的最长路径。
2. 所有路径等长 => 将所有路径对齐到最长路径，需修改边使较短路径变长。
3. 不需要修改的边：边权 w = `dist[v] - dist[u]`（恰好在最长路上）。

## 易错点

1. 只统计在"最优路径"上的边（dist[u] + w == dist[v]），这些边无需修改。
2. 注意 DAG 的方向，不能反向遍历。
