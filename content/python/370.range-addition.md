## 题目描述

假设你有一个长度为 `n` 的数组，初始情况下所有的数字均为 `0`，你将会被给出 `k` 个更新操作。

每个操作会被表示为一个三元组：`[startIndex, endIndex, inc]`，你需要将子数组 `[startIndex, endIndex]`（包括两端）中的每个元素都增加 `inc`。

请你返回 `k` 次操作后的数组。

**示例 1：**

```
输入：length = 5, updates = [[1,3,2],[2,4,3],[0,2,-2]]
输出：[-2,0,3,5,3]

解释：
初始状态：[0,0,0,0,0]

执行 [1,3,2]：[0,2,2,2,0]
执行 [2,4,3]：[0,2,5,5,3]
执行 [0,2,-2]：[-2,0,3,5,3]
```

**提示：**
- `1 <= length <= 10^5`
- `0 <= updates.length <= 10^4`
- `0 <= startIndex <= endIndex < length`
- `-1000 <= inc <= 1000`

## 解题思路

这是一道经典的**差分数组**问题。

### 暴力方法

对每个操作，遍历 `[startIndex, endIndex]` 区间的所有元素并加上 `inc`。

时间复杂度：O(n × k)，当 n 和 k 都很大时会超时。

### 差分数组方法（推荐）

**差分数组**是前缀和的逆运算。

**核心思想**：
- 对于区间 `[start, end]` 增加 `inc`：
  - 在 `start` 位置标记 `+inc`
  - 在 `end+1` 位置标记 `-inc`
- 最后对差分数组求前缀和，得到最终结果

**为什么有效**：
- 差分数组记录的是相邻元素的差值
- 区间操作转化为两个端点的标记操作
- 最后的前缀和将标记转换为实际值

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def getModifiedArray(self, length: int, updates: List[List[int]]) -> List[int]:
        """
        差分数组方法
        时间复杂度：O(n + k)
        空间复杂度：O(n)
        """
        # 初始化差分数组
        diff = [0] * length
        
        # 处理每个更新操作
        for start, end, inc in updates:
            diff[start] += inc
            if end + 1 < length:
                diff[end + 1] -= inc
        
        # 求前缀和得到最终结果
        result = [0] * length
        result[0] = diff[0]
        for i in range(1, length):
            result[i] = result[i - 1] + diff[i]
        
        return result
```

### 方法二：原地操作（优化空间）

```python
from typing import List

class Solution:
    def getModifiedArray(self, length: int, updates: List[List[int]]) -> List[int]:
        """
        直接在结果数组上操作，节省空间
        时间复杂度：O(n + k)
        空间复杂度：O(1)（不算返回值）
        """
        result = [0] * length
        
        # 在结果数组上标记差分
        for start, end, inc in updates:
            result[start] += inc
            if end + 1 < length:
                result[end + 1] -= inc
        
        # 原地计算前缀和
        for i in range(1, length):
            result[i] += result[i - 1]
        
        return result
```

### 方法三：暴力方法（用于对比）

```python
from typing import List

class Solution:
    def getModifiedArray(self, length: int, updates: List[List[int]]) -> List[int]:
        """
        暴力方法：直接对每个区间进行更新
        时间复杂度：O(n × k)
        空间复杂度：O(1)
        
        当 n 和 k 很大时会超时
        """
        result = [0] * length
        
        for start, end, inc in updates:
            for i in range(start, end + 1):
                result[i] += inc
        
        return result
```

### 方法四：使用差分数组类（封装）

```python
from typing import List

class Difference:
    """
    差分数组工具类
    """
    def __init__(self, nums: List[int]):
        n = len(nums)
        self.diff = [0] * n
        self.diff[0] = nums[0]
        for i in range(1, n):
            self.diff[i] = nums[i] - nums[i - 1]
    
    def increment(self, start: int, end: int, val: int) -> None:
        """
        对区间 [start, end] 增加 val
        """
        self.diff[start] += val
        if end + 1 < len(self.diff):
            self.diff[end + 1] -= val
    
    def result(self) -> List[int]:
        """
        返回最终结果
        """
        res = [0] * len(self.diff)
        res[0] = self.diff[0]
        for i in range(1, len(self.diff)):
            res[i] = res[i - 1] + self.diff[i]
        return res

class Solution:
    def getModifiedArray(self, length: int, updates: List[List[int]]) -> List[int]:
        """
        使用差分数组类
        """
        diff_array = Difference([0] * length)
        
        for start, end, inc in updates:
            diff_array.increment(start, end, inc)
        
        return diff_array.result()
```

## 复杂度分析

### 方法一/二：差分数组
- 时间复杂度：O(n + k)
  - 处理 k 个更新：O(k)
  - 计算前缀和：O(n)
- 空间复杂度：O(n)（方法一）或 O(1)（方法二，不算返回值）

### 方法三：暴力
- 时间复杂度：O(n × k)
- 空间复杂度：O(1)

## 关键点总结

1. **差分数组核心**：将区间更新 O(n) 优化为端点标记 O(1)
2. **标记规则**：
   - `diff[start] += inc`（开始位置）
   - `diff[end+1] -= inc`（结束位置的下一个）
3. **前缀和还原**：差分数组的前缀和就是原数组
4. **边界检查**：`end + 1 < length` 防止越界
5. **应用场景**：频繁的区间修改 + 最后一次查询

## 易错点

1. **边界越界**：`end + 1` 可能越界，需要判断
2. **前缀和方向**：从左到右累加
3. **理解差分**：差分数组是相邻元素的差，不是原数组
4. **初始化**：初始数组全为 0，差分数组也全为 0
5. **负数增量**：`inc` 可以是负数，表示减少

## 图解示例

### 示例：length = 5, updates = [[1,3,2],[2,4,3],[0,2,-2]]

```
初始：result = [0,0,0,0,0]

操作 1：[1,3,2]
  diff[1] += 2  -> diff = [0,2,0,0,-2]
  diff[4] -= 2

操作 2：[2,4,3]
  diff[2] += 3  -> diff = [0,2,3,0,-2]
  diff[5] -= 3  (越界，不操作)

操作 3：[0,2,-2]
  diff[0] += -2 -> diff = [-2,2,3,0,-2]
  diff[3] -= -2 -> diff = [-2,2,3,2,-2]

前缀和：
  result[0] = -2
  result[1] = -2 + 2 = 0
  result[2] = 0 + 3 = 3
  result[3] = 3 + 2 = 5
  result[4] = 5 + (-2) = 3

最终：[-2,0,3,5,3]
```
