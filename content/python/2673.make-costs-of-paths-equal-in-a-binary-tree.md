## 题目描述

给你一棵完全二叉树，共 `n` 个节点（节点编号 1 到 n，根为 1，节点 `i` 的子节点为 `2i` 和 `2i+1`）。每个节点有代价 `cost[i-1]`（1-indexed）。每次操作可以给任意节点增加代价（代价只增不减），使得所有从根到叶子节点路径的代价之和相等。返回所需的最少增加代价总量。

**示例：**
```
输入：n = 7, cost = [1,5,2,2,3,3,1]
输出：6
```

**数据范围：**
- 3 <= n <= 10^5 且 n+1 为 2 的幂（完全二叉树）
- 1 <= cost.length == n
- 1 <= cost[i] <= 10^4

## 解题思路

贪心：从叶节点往上处理。对于每对兄弟节点（同父节点），将代价较小的那个增加到与兄弟相同，然后将两者中较大值加到父节点。

等价地：对每个内部节点，其两个子树的最大路径和要相等，差值即为需要增加的代价。

## Python 代码实现

### 方法一：贪心（自底向上，推荐）

```python
from typing import List

class Solution:
    def minIncrements(self, n: int, cost: List[int]) -> int:
        ans = 0
        # 从最后一个内部节点开始（叶节点的父节点）
        # 内部节点编号 1 到 n//2
        for i in range(n // 2, 0, -1):
            left = cost[2 * i - 1]   # 左子节点（1-indexed: 2i，0-indexed: 2i-1）
            right = cost[2 * i]       # 右子节点（1-indexed: 2i+1，0-indexed: 2i）
            # 将较小的增加到较大（需要增加 |left - right| 的代价）
            ans += abs(left - right)
            # 将较大值"传递"给父节点
            cost[i - 1] += max(left, right)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（原地修改 cost 数组）

## 关键点总结

1. 贪心：从叶节点往上，每次使兄弟节点的路径和相等（补差值）
2. 差值就是需要增加的代价
3. 将较大值传递给父节点，父节点加上较大值后再向上处理

## 易错点

1. 节点编号为 1-indexed，cost 数组为 0-indexed，需要注意转换
2. 从倒数第二层（叶节点的父节点）开始处理，不处理叶节点本身
