## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是**回文串**。返回 `s` 所有可能的分割方案。

**示例 1：**
```
输入: s = "aab"
输出: [["a","a","b"],["aa","b"]]
```

**示例 2：**
```
输入: s = "a"
输出: [["a"]]
```

**提示：**
- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## 解题思路

这是一道典型的**回溯 + 动态规划优化**问题。

### 核心思想：回溯搜索所有可能的分割方案

1. **回溯框架**：从字符串开头开始，尝试所有可能的分割点
2. **剪枝优化**：只有当前子串是回文串时，才继续递归
3. **动态规划预处理**：提前计算所有子串是否为回文，避免重复判断

### 算法步骤：

1. **预处理**（可选）：使用动态规划计算所有子串是否为回文
2. **回溯搜索**：
   - 从当前位置开始，尝试每个可能的结束位置
   - 如果当前子串是回文，加入路径，继续递归
   - 递归到字符串末尾，将当前路径加入结果
   - 回溯，尝试其他分割方案

### 示例演示：

```
输入: s = "aab"

回溯树：
              ""
            /  |  \
          a    aa  aab(×)
         / \    |
       a   ab(×) b
      /
     b
   结果

路径1: ["a", "a", "b"]
路径2: ["aa", "b"]
```

## Python 代码实现

### 方法一：回溯 + DP 预处理（推荐）⭐

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        
        # DP 预处理：计算所有子串是否为回文
        # dp[i][j] 表示 s[i:j+1] 是否为回文
        dp = [[False] * n for _ in range(n)]
        
        # 每个单字符是回文
        for i in range(n):
            dp[i][i] = True
        
        # 长度为 2 的子串
        for i in range(n - 1):
            dp[i][i + 1] = (s[i] == s[i + 1])
        
        # 长度 >= 3 的子串
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = (s[i] == s[j] and dp[i + 1][j - 1])
        
        # 回溯搜索所有分割方案
        result = []
        path = []
        
        def backtrack(start):
            # 到达字符串末尾，记录当前路径
            if start == n:
                result.append(path[:])
                return
            
            # 尝试所有可能的结束位置
            for end in range(start, n):
                # 如果 s[start:end+1] 是回文
                if dp[start][end]:
                    path.append(s[start:end + 1])
                    backtrack(end + 1)
                    path.pop()  # 回溯
        
        backtrack(0)
        return result
```

### 方法二：回溯 + 双指针判断回文

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        result = []
        path = []
        
        # 判断字符串是否为回文
        def is_palindrome(sub):
            left, right = 0, len(sub) - 1
            while left < right:
                if sub[left] != sub[right]:
                    return False
                left += 1
                right -= 1
            return True
        
        def backtrack(start):
            if start == len(s):
                result.append(path[:])
                return
            
            for end in range(start, len(s)):
                substring = s[start:end + 1]
                if is_palindrome(substring):
                    path.append(substring)
                    backtrack(end + 1)
                    path.pop()
        
        backtrack(0)
        return result
```

### 方法三：回溯 + 记忆化（判断回文）

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        result = []
        path = []
        # 记忆化：缓存已判断的子串
        memo = {}
        
        def is_palindrome(start, end):
            if (start, end) in memo:
                return memo[(start, end)]
            
            left, right = start, end
            while left < right:
                if s[left] != s[right]:
                    memo[(start, end)] = False
                    return False
                left += 1
                right -= 1
            
            memo[(start, end)] = True
            return True
        
        def backtrack(start):
            if start == n:
                result.append(path[:])
                return
            
            for end in range(start, n):
                if is_palindrome(start, end):
                    path.append(s[start:end + 1])
                    backtrack(end + 1)
                    path.pop()
        
        backtrack(0)
        return result
```

### 方法四：中心扩展 + 回溯

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        result = []
        
        # 使用中心扩展法预处理所有回文子串
        palindromes = [[] for _ in range(n)]
        
        def expand_around_center(left, right):
            while left >= 0 and right < n and s[left] == s[right]:
                # s[left:right+1] 是回文
                palindromes[left].append(right)
                left -= 1
                right += 1
        
        # 以每个位置为中心扩展
        for i in range(n):
            expand_around_center(i, i)      # 奇数长度
            expand_around_center(i, i + 1)  # 偶数长度
        
        path = []
        
        def backtrack(start):
            if start == n:
                result.append(path[:])
                return
            
            for end in palindromes[start]:
                path.append(s[start:end + 1])
                backtrack(end + 1)
                path.pop()
        
        backtrack(0)
        return result
```

### 方法五：简洁版（初学者友好）

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        def is_palindrome(sub):
            return sub == sub[::-1]
        
        result = []
        
        def backtrack(start, path):
            if start == len(s):
                result.append(path[:])
                return
            
            for i in range(start, len(s)):
                substring = s[start:i + 1]
                if is_palindrome(substring):
                    backtrack(i + 1, path + [substring])
        
        backtrack(0, [])
        return result
```

## 复杂度分析

设字符串长度为 n。

### 方法一：回溯 + DP 预处理
- **时间复杂度**：O(n × 2^n)
  - DP 预处理：O(n^2)
  - 回溯：最坏情况有 2^n 种分割方案，每种方案需要 O(n) 复制
- **空间复杂度**：O(n^2)，DP 数组 + 递归栈

### 方法二：回溯 + 双指针
- **时间复杂度**：O(n × 2^n)
  - 每次判断回文：O(n)
  - 回溯：2^n 种方案
- **空间复杂度**：O(n)，递归栈

## 关键点总结

1. **回溯框架**：枚举所有分割点，递归搜索所有方案
2. **剪枝优化**：只有当前子串是回文时才继续
3. **DP 预处理**：提前计算所有子串是否回文，避免重复判断
4. **路径记录**：使用 `path[:]` 复制当前路径
5. **回溯操作**：`path.pop()` 恢复状态

## 易错点

1. **忘记复制路径**
   ```python
   # 错误：直接添加引用
   result.append(path)
   
   # 正确：复制路径
   result.append(path[:])
   ```

2. **回文判断错误**
   ```python
   # 错误：索引范围错误
   dp[i][j] = (s[i] == s[j] and dp[i][j-1])
   
   # 正确：内部子串
   dp[i][j] = (s[i] == s[j] and dp[i+1][j-1])
   ```

3. **DP 初始化顺序错误**
   ```python
   # 必须按长度递增的顺序初始化
   for length in range(1, n + 1):
       for i in range(n - length + 1):
           ...
   ```

4. **忘记回溯**
   ```python
   path.append(substring)
   backtrack(end + 1)
   # 必须回溯
   path.pop()
   ```

5. **索引越界**
   ```python
   # 注意 DP 边界条件
   if length == 1:
       dp[i][i] = True
   elif length == 2:
       dp[i][i+1] = (s[i] == s[i+1])
   ```
