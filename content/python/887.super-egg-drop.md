## 题目描述

你将获得 k 个鸡蛋，并可以使用一栋从第 1 层到第 n 层共有 n 层楼的建筑。

每个鸡蛋的功能都是一样的，如果一个鸡蛋碎了，你就不能再把它掉下去。你知道存在楼层 f ，满足 0 <= f <= n ，任何从 高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一个鸡蛋从任何一层楼扔下（1 <= i <= n），请计算最坏情况下最少需要几次操作才能找到楼层 f 。

**提示：**
- 1 <= k <= 100
- 1 <= n <= 10^4

## 解题思路

**DP + 二分优化：**
- `dp[k][m]` = k 个鸡蛋，m 次操作最多能测试多少层
- 转换思路：不求"n层需要多少次"，而求"m次能测多少层"

**状态转移：**
- 在某层扔鸡蛋：
  - 碎了：下面 `dp[k-1][m-1]` 层
  - 没碎：上面 `dp[k][m-1]` 层
- `dp[k][m] = dp[k-1][m-1] + dp[k][m-1] + 1`

## Python 代码实现

```python
class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        # dp[m] 表示 m 次操作能测试的最大楼层数
        # dp[m][k] 表示 k 个鸡蛋 m 次操作能测试的楼层数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        
        for m in range(1, n + 1):
            for eggs in range(1, k + 1):
                dp[m][eggs] = dp[m-1][eggs-1] + dp[m-1][eggs] + 1
            if dp[m][k] >= n:
                return m
        
        return n
```

### 优化空间

```python
class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        dp = [0] * (k + 1)
        m = 0
        
        while dp[k] < n:
            m += 1
            for i in range(k, 0, -1):
                dp[i] = dp[i-1] + dp[i] + 1
        
        return m
```

## 复杂度分析

- **时间复杂度**：O(kn)
- **空间复杂度**：O(k)

## 关键点总结

1. **逆向思维**：求次数能测多少层
2. **状态转移**：碎了和没碎两种情况
3. **空间优化**：滚动数组
