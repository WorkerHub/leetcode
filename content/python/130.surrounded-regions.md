## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，**捕获** 所有**被围绕的区域**：

- **连接**：一个单元格与水平或垂直方向上相邻的单元格连接。
- **区域**：连接所有 `'O'` 的单元格来形成一个区域。
- **围绕**：如果您可以用 `'X'` 单元格连接这个区域，并且区域中没有任何单元格位于 `board` 边缘，则该区域被 `'X'` 单元格围绕。

通过将输入矩阵 `board` 中的所有 `'O'` 替换为 `'X'` 来**捕获被围绕的区域**。

**示例 1：**
```
输入: board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
输出: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
解释:
在上图中，底部的区域没有被捕获，因为它在 board 的边缘并且不能被围绕。
```

**示例 2：**
```
输入: board = [["X"]]
输出: [["X"]]
```

**提示：**
- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`

## 解题思路

这道题的关键是理解**什么样的 'O' 不会被捕获**：
- 位于边界的 'O'
- 与边界 'O' 连通的 'O'

### 核心思想：反向思维

1. **找出不被捕获的 'O'**：从边界的 'O' 开始，标记所有连通的 'O'
2. **剩余的 'O' 都要被捕获**：将未标记的 'O' 改为 'X'
3. **恢复标记的 'O'**：将标记的 'O' 恢复

### 算法步骤（DFS/BFS）：

1. 遍历矩阵的四条边
2. 对边界上的每个 'O'，进行 DFS/BFS，将连通的 'O' 标记为特殊字符（如 '#'）
3. 遍历整个矩阵：
   - 'O' → 'X'（被围绕的区域）
   - '#' → 'O'（不被围绕的区域）

## Python 代码实现

### 方法一：DFS（推荐）⭐

```python
from typing import List

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        """
        Do not return anything, modify board in-place instead.
        """
        if not board or not board[0]:
            return
        
        m, n = len(board), len(board[0])
        
        # DFS 标记与边界连通的 'O'
        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != 'O':
                return
            
            # 标记为 '#'
            board[i][j] = '#'
            
            # 向四个方向递归
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)
        
        # 1. 从边界的 'O' 开始 DFS
        # 第一行和最后一行
        for j in range(n):
            if board[0][j] == 'O':
                dfs(0, j)
            if board[m-1][j] == 'O':
                dfs(m-1, j)
        
        # 第一列和最后一列
        for i in range(m):
            if board[i][0] == 'O':
                dfs(i, 0)
            if board[i][n-1] == 'O':
                dfs(i, n-1)
        
        # 2. 处理剩余的 'O' 和 '#'
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'  # 被围绕的区域
                elif board[i][j] == '#':
                    board[i][j] = 'O'  # 不被围绕的区域
```

### 方法二：BFS

```python
from typing import List
from collections import deque

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        if not board or not board[0]:
            return
        
        m, n = len(board), len(board[0])
        
        # BFS 标记与边界连通的 'O'
        def bfs(i, j):
            queue = deque([(i, j)])
            board[i][j] = '#'
            
            while queue:
                x, y = queue.popleft()
                
                # 四个方向
                for dx, dy in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
                    nx, ny = x + dx, y + dy
                    
                    if 0 <= nx < m and 0 <= ny < n and board[nx][ny] == 'O':
                        board[nx][ny] = '#'
                        queue.append((nx, ny))
        
        # 从边界的 'O' 开始 BFS
        for j in range(n):
            if board[0][j] == 'O':
                bfs(0, j)
            if board[m-1][j] == 'O':
                bfs(m-1, j)
        
        for i in range(m):
            if board[i][0] == 'O':
                bfs(i, 0)
            if board[i][n-1] == 'O':
                bfs(i, n-1)
        
        # 处理剩余的 'O' 和 '#'
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'
                elif board[i][j] == '#':
                    board[i][j] = 'O'
```

### 方法三：并查集

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        root_x = self.find(x)
        root_y = self.find(y)
        if root_x != root_y:
            self.parent[root_x] = root_y

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        if not board or not board[0]:
            return
        
        m, n = len(board), len(board[0])
        # 创建并查集，多一个虚拟节点代表边界
        uf = UnionFind(m * n + 1)
        dummy = m * n  # 虚拟节点索引
        
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    # 边界的 'O' 与虚拟节点相连
                    if i == 0 or i == m-1 or j == 0 or j == n-1:
                        uf.union(i * n + j, dummy)
                    else:
                        # 与四周的 'O' 相连
                        if i > 0 and board[i-1][j] == 'O':
                            uf.union(i * n + j, (i-1) * n + j)
                        if j > 0 and board[i][j-1] == 'O':
                            uf.union(i * n + j, i * n + j - 1)
        
        # 不与虚拟节点连通的 'O' 要被捕获
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O' and uf.find(i * n + j) != uf.find(dummy):
                    board[i][j] = 'X'
```

### 方法四：优化的 DFS（迭代版，避免栈溢出）

```python
from typing import List

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        if not board or not board[0]:
            return
        
        m, n = len(board), len(board[0])
        
        # 迭代 DFS，避免递归栈溢出
        def dfs_iterative(i, j):
            stack = [(i, j)]
            
            while stack:
                x, y = stack.pop()
                
                if x < 0 or x >= m or y < 0 or y >= n or board[x][y] != 'O':
                    continue
                
                board[x][y] = '#'
                
                # 四个方向
                stack.append((x + 1, y))
                stack.append((x - 1, y))
                stack.append((x, y + 1))
                stack.append((x, y - 1))
        
        # 从边界开始 DFS
        for j in range(n):
            if board[0][j] == 'O':
                dfs_iterative(0, j)
            if board[m-1][j] == 'O':
                dfs_iterative(m-1, j)
        
        for i in range(m):
            if board[i][0] == 'O':
                dfs_iterative(i, 0)
            if board[i][n-1] == 'O':
                dfs_iterative(i, n-1)
        
        # 处理剩余的元素
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'
                elif board[i][j] == '#':
                    board[i][j] = 'O'
```

## 复杂度分析

设矩阵大小为 m × n。

### 方法一/二：DFS/BFS
- **时间复杂度**：O(m × n)，最多访问每个格子一次
- **空间复杂度**：
  - DFS 递归：O(m × n)，最坏情况递归栈深度
  - BFS/迭代 DFS：O(m × n)，队列/栈空间

### 方法三：并查集
- **时间复杂度**：O(m × n × α(m×n))，α 是反阿克曼函数
- **空间复杂度**：O(m × n)，并查集数组

## 关键点总结

1. **反向思维**：不找被围绕的，找不被围绕的
2. **边界扩散**：从边界的 'O' 开始扩散，标记所有连通的 'O'
3. **临时标记**：用 '#' 标记不被围绕的 'O'，避免混淆
4. **原地修改**：直接在原矩阵上修改，节省空间
5. **四个方向遍历**：上下左右四个方向

## 易错点

1. **忘记检查边界**
   ```python
   # 错误：没检查边界就递归
   dfs(i + 1, j)
   
   # 正确：先检查边界
   if i < 0 or i >= m or j < 0 or j >= n:
       return
   ```

2. **只遍历部分边界**
   ```python
   # 错误：忘记遍历某些边
   for j in range(n):
       if board[0][j] == 'O':
           dfs(0, j)
   # 忘记最后一行
   
   # 正确：遍历所有四条边
   ```

3. **标记字符选择不当**
   ```python
   # 错误：用 'O' 或 'X' 标记，会混淆
   board[i][j] = 'O'
   
   # 正确：用其他字符如 '#'
   board[i][j] = '#'
   ```

4. **递归栈溢出**
   ```python
   # 对于大矩阵，递归可能栈溢出
   # 解决：使用迭代 DFS 或 BFS
   ```

5. **修改顺序错误**
   ```python
   # 错误：边遍历边修改，会影响后续判断
   # 正确：先标记所有不被围绕的，再统一修改
   ```
