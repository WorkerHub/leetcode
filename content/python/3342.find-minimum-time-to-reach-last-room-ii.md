## 题目描述

与 3341 类似，但移动的时间不再固定为 1 秒，而是**交替为 1 秒和 2 秒**（第奇数步移动 1 秒，第偶数步移动 2 秒，从第 1 步开始算）。

给你 `moveTime` 矩阵和相同规则，返回到达 `(n-1, m-1)` 的最短时间。

**提示：**
- `2 <= n, m <= 750`
- `0 <= moveTime[i][j] <= 10^9`

## 解题思路

**Dijkstra + 奇偶步数状态：**

由于移动时间交替（奇数步 1 秒，偶数步 2 秒），Dijkstra 的状态需要包含当前已走的步数的奇偶性。

状态：`(时间, 行, 列, 步数奇偶)`

从 `(r, c)` 移到 `(nr, nc)`：
- 若当前步是奇数步（parity = 0，即将走第奇数步），移动时间为 1。
- 若当前步是偶数步（parity = 1，即将走第偶数步），移动时间为 2。

到达时间 = `max(当前时间, moveTime[nr][nc]) + move_cost`

下一步的奇偶性反转。

## Python 代码实现

### 方法一：Dijkstra + 奇偶状态（推荐）

```python
from typing import List
import heapq

class Solution:
    def minTimeToReach(self, moveTime: List[List[int]]) -> int:
        n, m = len(moveTime), len(moveTime[0])
        INF = float('inf')
        
        # dist[r][c][parity]：当步数奇偶性为 parity 时到达 (r, c) 的最短时间
        dist = [[[INF, INF] for _ in range(m)] for _ in range(n)]
        dist[0][0][0] = 0  # 出发时，即将走第 1 步（奇数步，parity=0）
        
        # 堆：(时间, 行, 列, 奇偶性)
        heap = [(0, 0, 0, 0)]
        
        while heap:
            t, r, c, parity = heapq.heappop(heap)
            
            if t > dist[r][c][parity]:
                continue
            
            if r == n - 1 and c == m - 1:
                return t
            
            move_cost = 1 if parity == 0 else 2  # 奇数步1秒，偶数步2秒
            
            for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < m:
                    arrive = max(t, moveTime[nr][nc]) + move_cost
                    new_parity = 1 - parity  # 切换奇偶
                    if arrive < dist[nr][nc][new_parity]:
                        dist[nr][nc][new_parity] = arrive
                        heapq.heappush(heap, (arrive, nr, nc, new_parity))
        
        return min(dist[n-1][m-1])
```

## 复杂度分析

- 时间复杂度：O(n * m * log(n * m))，Dijkstra（状态数翻倍为 2nm）
- 空间复杂度：O(n * m)

## 关键点总结

1. 移动代价交替：1 秒（奇数步）和 2 秒（偶数步）。
2. Dijkstra 状态扩展为 `(时间, 行, 列, 奇偶性)` 来追踪当前步数奇偶。
3. 每次移动后奇偶性反转（`1 - parity`）。

## 易错点

1. 出发时即将走第 1 步（奇数步），初始 parity = 0。
2. parity 表示"即将走的这一步"是奇数（0）还是偶数（1），不是"已走步数"的奇偶。
3. 到达终点时，两种奇偶状态都可能是答案，取最小值。
