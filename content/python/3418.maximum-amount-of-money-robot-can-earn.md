## 题目描述

给你一个 `m x n` 的矩阵 `coins`，其中每个格子包含一定数量的金币（可以是负数，表示罚款）。

一个机器人从 `(0,0)` 出发，每次只能向右或向下移动，最终到达 `(m-1, n-1)`。

机器人可以**中和**最多 `2` 个负数格子（将那个格子的金币设为 0）。

返回机器人能收集到的**最多金币**。

**示例 1：**

```
输入：coins = [[0,1,-1],[1,-2,3],[2,-3,4]]
输出：8
解释：路径 (0,0)->(1,0)->(2,0)->(2,1)->(2,2)，金币 0+1+2+(-3中和)+4=7+1=8
```

**示例 2：**

```
输入：coins = [[10,20,-5],[30,-10,40]]
输出：110
```

**提示：**
- `m == coins.length`
- `n == coins[0].length`
- `1 <= m, n <= 500`
- `-1000 <= coins[i][j] <= 1000`

## 解题思路

DP + 状态机。设 `dp[i][j][k]` 表示到达位置 `(i,j)` 时，已使用 `k` 次中和（k = 0, 1, 2）的最大金币数。

转移方程（来自上方或左方）：
```
dp[i][j][k] = max(dp[i-1][j][k], dp[i][j-1][k]) + coins[i][j]  // 不使用中和

dp[i][j][k] = max(dp[i-1][j][k-1], dp[i][j-1][k-1]) + 0  // 使用中和（coins[i][j] < 0 时才有意义）
```

最终答案为 `max(dp[m-1][n-1][0], dp[m-1][n-1][1], dp[m-1][n-1][2])`。

## Python 代码实现

### 方法一：三维 DP（推荐）

```python
from typing import List

class Solution:
    def maximumAmount(self, coins: List[List[int]]) -> int:
        m, n = len(coins), len(coins[0])
        NEG_INF = float('-inf')

        # dp[i][j][k]: 到(i,j)，已用 k 次中和的最大金币
        dp = [[[NEG_INF] * 3 for _ in range(n)] for _ in range(m)]
        dp[0][0][0] = coins[0][0]
        # 如果 (0,0) 是负数，可以中和
        if coins[0][0] < 0:
            dp[0][0][1] = 0  # 用一次中和

        # 初始化第一行
        for j in range(1, n):
            for k in range(3):
                if dp[0][j-1][k] != NEG_INF:
                    # 不中和
                    val = dp[0][j-1][k] + coins[0][j]
                    dp[0][j][k] = max(dp[0][j][k], val)
                    # 使用中和（仅对负数有意义，但也可对正数）
                    if k < 2:
                        val2 = dp[0][j-1][k] + (0 if coins[0][j] < 0 else coins[0][j])
                        # 实际上中和就是跳过负数代价
                        val2 = dp[0][j-1][k]  # 直接不加负数
                        dp[0][j][k+1] = max(dp[0][j][k+1], val2)

        # 初始化第一列
        for i in range(1, m):
            for k in range(3):
                if dp[i-1][0][k] != NEG_INF:
                    val = dp[i-1][0][k] + coins[i][0]
                    dp[i][0][k] = max(dp[i][0][k], val)
                    if k < 2:
                        val2 = dp[i-1][0][k]
                        dp[i][0][k+1] = max(dp[i][0][k+1], val2)

        # 填充 DP 表
        for i in range(1, m):
            for j in range(1, n):
                for k in range(3):
                    # 来自上方或左方
                    prev_val = max(
                        dp[i-1][j][k] if dp[i-1][j][k] != NEG_INF else NEG_INF,
                        dp[i][j-1][k] if dp[i][j-1][k] != NEG_INF else NEG_INF
                    )
                    if prev_val != NEG_INF:
                        # 不使用中和
                        dp[i][j][k] = max(dp[i][j][k], prev_val + coins[i][j])
                    # 使用中和（k-1 -> k）
                    if k > 0:
                        prev_k1 = max(
                            dp[i-1][j][k-1] if dp[i-1][j][k-1] != NEG_INF else NEG_INF,
                            dp[i][j-1][k-1] if dp[i][j-1][k-1] != NEG_INF else NEG_INF
                        )
                        if prev_k1 != NEG_INF:
                            # 中和当前格子（设为 0）
                            dp[i][j][k] = max(dp[i][j][k], prev_k1)

        return max(dp[m-1][n-1])
```

### 方法二：简洁版（正确处理边界）

```python
from typing import List

class Solution:
    def maximumAmount(self, coins: List[List[int]]) -> int:
        m, n = len(coins), len(coins[0])
        NEG_INF = float('-inf')

        # dp[k] 表示使用了 k 次中和的最优值
        # 使用滚动数组
        INF = float('-inf')

        # dp[i][j][k]
        dp = [[[INF] * 3 for _ in range(n)] for _ in range(m)]

        for i in range(m):
            for j in range(n):
                c = coins[i][j]
                for k in range(3):
                    # 来自上方
                    from_up = dp[i-1][j][k] if i > 0 else INF
                    # 来自左方
                    from_left = dp[i][j-1][k] if j > 0 else INF
                    # 起点
                    if i == 0 and j == 0:
                        if k == 0:
                            dp[i][j][k] = c
                        # k > 0 时，起点使用中和
                    else:
                        prev = max(from_up, from_left)
                        if prev != INF:
                            dp[i][j][k] = prev + c

                    # 使用中和到达当前（k-1 -> k）
                    if k > 0:
                        from_up_k1 = dp[i-1][j][k-1] if i > 0 else INF
                        from_left_k1 = dp[i][j-1][k-1] if j > 0 else INF
                        if i == 0 and j == 0:
                            if k == 1:
                                dp[i][j][k] = max(dp[i][j][k], 0)
                        else:
                            prev_k1 = max(from_up_k1, from_left_k1)
                            if prev_k1 != INF:
                                # 中和当前格子
                                dp[i][j][k] = max(dp[i][j][k], prev_k1)

        return max(dp[m-1][n-1])
```

## 复杂度分析

- 时间复杂度：O(m * n * 3) = O(m * n)
- 空间复杂度：O(m * n * 3) = O(m * n)

## 关键点总结

1. 状态：(位置, 已用中和次数)，共 3 层 DP
2. 转移：不使用中和时加当前格子值；使用中和时当前格子设为 0（相当于不加）
3. 取最终位置三种状态的最大值

## 易错点

1. 中和只对当前格子生效，之前路径已经确定
2. 正数格子也可以"中和"（但这不会更优，可以优化）
3. 起始格子 (0,0) 的初始化需要特殊处理
