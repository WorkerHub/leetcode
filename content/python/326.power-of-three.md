## 题目描述

给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 `true`；否则，返回 `false`。

整数 `n` 是 3 的幂次方需满足：存在整数 `x` 使得 `n == 3^x`。

**示例 1:**

```
输入：n = 27
输出：true
解释：27 = 3^3
```

**示例 2:**

```
输入：n = 0
输出：false
解释：不存在 x 使得 3^x = 0
```

**示例 3:**

```
输入：n = 9
输出：true
解释：9 = 3^2
```

**示例 4:**

```
输入：n = 45
输出：false
```

**提示:**

- `-2^31 <= n <= 2^31 - 1`

**进阶：** 你能不使用循环或者递归来完成本题吗？

## 解题思路

判断一个数是否是 3 的幂次方，有多种方法。

### 思路一：循环除法（最直观）

- 如果 `n` 是 3 的幂次方，那么不断除以 3，最终会得到 1
- 如果中途出现无法整除的情况，则不是 3 的幂次方

### 思路二：递归

- 基础情况：`n == 1` 返回 `true`，`n <= 0` 或 `n % 3 != 0` 返回 `false`
- 递归情况：`isPowerOfThree(n / 3)`

### 思路三：对数法

- 如果 `n = 3^x`，则 `x = log₃(n) = log(n) / log(3)`
- 判断 `x` 是否为整数

### 思路四：最大 3 的幂次方（最巧妙）

- 在 32 位整数范围内，3 的最大幂次方是 `3^19 = 1162261467`
- 如果 `n` 是 3 的幂次方，则 `1162261467 % n == 0`
- 这是因为 3 的幂次方只包含质因子 3

## Python 代码实现

### 方法一：循环除法（推荐新手）⭐

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        循环除法：不断除以 3，看最终是否为 1
        """
        if n <= 0:
            return False
        
        while n % 3 == 0:
            n //= 3
        
        return n == 1
```

### 方法二：递归

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        递归解法
        """
        if n == 1:
            return True
        if n <= 0 or n % 3 != 0:
            return False
        
        return self.isPowerOfThree(n // 3)
```

### 方法三：对数法

```python
import math

class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        对数法：判断 log₃(n) 是否为整数
        """
        if n <= 0:
            return False
        
        # 计算 log₃(n) = log(n) / log(3)
        x = math.log(n, 3)
        
        # 判断 x 是否为整数（考虑浮点数精度误差）
        return abs(x - round(x)) < 1e-10
```

### 方法四：最大 3 的幂次方（巧妙）⭐

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        利用 3 的最大幂次方：3^19 = 1162261467
        如果 n 是 3 的幂次方，则 3^19 % n == 0
        """
        return n > 0 and 1162261467 % n == 0
```

### 方法五：字符串法（Python 特色）

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        转换为三进制字符串，检查是否为 1000...0 的形式
        """
        if n <= 0:
            return False
        
        # 转换为三进制字符串
        base3 = ""
        while n > 0:
            base3 = str(n % 3) + base3
            n //= 3
        
        # 检查是否为 "1" 后面跟若干 "0"
        return base3[0] == '1' and all(c == '0' for c in base3[1:])
```

### 方法六：使用 Python 内置函数

```python
import numpy as np

class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        """
        使用 numpy 判断对数是否为整数
        """
        if n <= 0:
            return False
        
        return (np.log(n) / np.log(3)).is_integer()
```

## 复杂度分析

**方法一：循环除法**

- **时间复杂度**：O(log₃n)
  - 循环次数等于 n 中包含质因子 3 的个数
  
- **空间复杂度**：O(1)

**方法二：递归**

- **时间复杂度**：O(log₃n)
- **空间复杂度**：O(log₃n)
  - 递归栈的深度

**方法三：对数法**

- **时间复杂度**：O(1)
  - 对数计算是常数时间
  
- **空间复杂度**：O(1)

**方法四：最大 3 的幂次方**

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **边界情况**：`n <= 0` 一定不是 3 的幂次方
2. **循环除法**：最直观，不断除以 3 直到无法整除
3. **对数法**：需要注意浮点数精度问题
4. **最大幂次方法**：利用 3 的质因数特性，非常巧妙
   - 32 位整数范围内，3 的最大幂是 `3^19 = 1162261467`
   - 只有 3 的幂次方才能整除它
5. **三进制表示**：3 的幂次方在三进制下是 `1000...0` 的形式

## 易错点

1. **忘记处理负数和 0**：`n <= 0` 直接返回 `false`
2. **对数精度问题**：浮点数计算有误差，需要设置容差 `1e-10`
3. **整除判断**：要用 `n % 3 == 0`，不能用 `n % 3`（虽然结果相同，但不够清晰）
4. **最大值计算错误**：
   - 正确：`3^19 = 1162261467`
   - 错误：`3^20 = 3486784401 > 2^31 - 1`（超出 32 位整数范围）
5. **递归栈溢出**：对于很大的 n，递归深度可能很深

```
对数法：
log₃(27) = log(27) / log(3) = 3.0
3.0 是整数 ✓ → 返回 true

1162261467 % 27 = 0 ✓ → 返回 true

三进制表示：

```
