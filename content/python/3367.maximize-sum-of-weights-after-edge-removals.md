## 题目描述

给你一棵有 `n` 个节点的树，边权重为正整数，每条边有权重 `w`。

每个节点最多保留 `k` 条相邻边（可以删除多余的边）。

在满足每个节点度数 <= k 的前提下，最大化保留边的权重之和。

**提示：**
- `2 <= n <= 10^5`
- `k >= 1`

## 解题思路

**树形 DP + 贪心（DFS）：**

对树进行 DFS，对每个节点 `v`，从其子节点的边中选最大的若干条（不超过 `k-1` 条，留 1 条给父节点）。

具体地：
- `dp[v][0]` = 以 `v` 为根的子树，`v` 不连接父节点时的最大权重和。
- `dp[v][1]` = 以 `v` 为根的子树，`v` 连接父节点时的最大权重和。

转移：
- 对 `v` 的每个子节点 `c`（边权 `w`），可以选择保留 `v-c` 边（`dp[c][1] + w`）或不保留（`dp[c][0]`）。
- 贪心地选择收益最大的 `k` 条边（`dp[v][0]` 选前 `k` 条，`dp[v][1]` 选前 `k-1` 条）。

## Python 代码实现

### 方法一：树形 DP + 贪心（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximizeSumOfWeights(self, edges: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))
        
        import sys
        sys.setrecursionlimit(200000)
        
        def dfs(node, parent):
            """
            返回 (dp0, dp1)：
            dp0 = node 不连接 parent 时的最大权重和
            dp1 = node 连接 parent 时的最大权重和
            """
            gains = []  # 每条子边的净收益：选择连接比不连接多赚多少
            base = 0    # 不连接任何子节点时的基础收益（dp[c][0] 之和）
            
            for child, w in graph[node]:
                if child == parent:
                    continue
                c0, c1 = dfs(child, node)
                base += c0
                # 选择连接边 (node, child)：额外收益 = c1 + w - c0
                gains.append(c1 + w - c0)
            
            # 对 gains 降序排序
            gains.sort(reverse=True)
            
            # dp0：最多选 k 条子边
            dp0 = base
            for i in range(min(k, len(gains))):
                if gains[i] > 0:
                    dp0 += gains[i]
                else:
                    break
            
            # dp1：最多选 k-1 条子边（留 1 个连接父节点）
            dp1 = base
            for i in range(min(k - 1, len(gains))):
                if gains[i] > 0:
                    dp1 += gains[i]
                else:
                    break
            
            return dp0, dp1
        
        dp0, dp1 = dfs(0, -1)
        return dp0
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS + 每个节点的排序
- 空间复杂度：O(n)，递归栈

## 关键点总结

1. 树形 DP 中，每个节点有两种状态：连接或不连接父节点。
2. 贪心选择：对每个节点，选择净收益（`c1 + w - c0`）最大的前 k 条或 k-1 条子边。
3. 只有净收益 > 0 的边才值得选择。

## 易错点

1. 根节点（无父节点）选前 k 条子边，其他节点选前 k-1 条（留一条给父节点）。
2. 净收益可能为负（`c1 + w < c0`），此时不应选择该边。
3. 递归深度可能达到 n，需要设置 `sys.setrecursionlimit`。
