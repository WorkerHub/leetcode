## 题目描述

给你三个整数 `n`、`m` 和 `k`。

一个长度为 `n` 的数组 `arr` 被称为**合法**的，如果：
- 数组中每个元素都在 `[1, m]` 范围内
- 恰好有 `k` 对相邻元素满足 `arr[i-1] == arr[i]`（即恰好 `k` 个位置 i 满足 arr[i] == arr[i-1]）

返回合法数组的数量对 `10^9 + 7` 取模的结果。

**示例 1：**

```
输入：n = 3, m = 2, k = 1
输出：4
解释：[1,1,2], [1,2,2], [2,2,1], [2,1,1] 各有 1 对相邻相等元素
```

**示例 2：**

```
输入：n = 4, m = 2, k = 2
输出：2
解释：[1,1,1,2], [2,2,2,1] 等...实际答案是 2
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= m <= 10^5`
- `0 <= k <= n - 1`

## 解题思路

将 n 个元素的数组看作由一些"块"构成，每块内的元素相同。设有 `t` 个块，则相邻相等对数为 `n - t`，所以 `t = n - k`。

步骤：
1. 确定块数：`t = n - k`，若 `t < 1` 或 `t > n`，返回 0
2. 将 n 个位置分为 t 块（每块连续）：
   - 相当于将 n 个位置分为 t 个非空连续段的方案数
   - 等价于从 n-1 个间隔中选 t-1 个"切割点"：C(n-1, t-1)
3. 为每块选颜色（第一块 m 种，后续每块 m-1 种，不能和前一块相同）：
   - 方案数 = m * (m-1)^(t-1)
4. 最终答案 = C(n-1, t-1) * m * (m-1)^(t-1) mod (10^9+7)

## Python 代码实现

### 方法一：组合数学公式（推荐）

```python
class Solution:
    def countGoodArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7

        # 块数
        t = n - k

        # 特判
        if t < 1 or t > n:
            return 0

        # 预计算组合数 C(n-1, t-1)
        # 使用 Lucas 定理或直接计算
        # C(n-1, t-1) = (n-1)! / ((t-1)! * (n-t)!)

        def power(base, exp, mod):
            """快速幂"""
            result = 1
            base %= mod
            while exp > 0:
                if exp & 1:
                    result = result * base % mod
                base = base * base % mod
                exp >>= 1
            return result

        def modinv(a, mod):
            """模逆元（费马小定理，mod 为质数）"""
            return power(a, mod - 2, mod)

        def comb(n, r, mod):
            """计算 C(n, r) mod p"""
            if r < 0 or r > n:
                return 0
            if r == 0:
                return 1
            # 计算分子 n * (n-1) * ... * (n-r+1)
            numerator = 1
            for i in range(r):
                numerator = numerator * (n - i) % mod
            # 计算分母 r!
            denominator = 1
            for i in range(1, r + 1):
                denominator = denominator * i % mod
            return numerator * modinv(denominator, mod) % mod

        # C(n-1, t-1)：将 n 个位置分为 t 个非空块的方案数
        ways_split = comb(n - 1, t - 1, MOD)

        # m * (m-1)^(t-1)：为 t 个块分配颜色的方案数
        ways_color = m * power(m - 1, t - 1, MOD) % MOD

        return ways_split * ways_color % MOD
```

### 方法二：预处理阶乘和逆元（适合多次查询）

```python
class Solution:
    def countGoodArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7
        t = n - k

        if t < 1 or t > n:
            return 0

        # 预计算阶乘
        max_n = n + 1
        fact = [1] * max_n
        for i in range(1, max_n):
            fact[i] = fact[i - 1] * i % MOD

        # 预计算逆元阶乘
        inv_fact = [1] * max_n
        inv_fact[max_n - 1] = pow(fact[max_n - 1], MOD - 2, MOD)
        for i in range(max_n - 2, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        # C(n-1, t-1)
        r = t - 1
        nn = n - 1
        if r < 0 or r > nn:
            c = 0
        else:
            c = fact[nn] * inv_fact[r] % MOD * inv_fact[nn - r] % MOD

        # m * (m-1)^(t-1)
        color = m * pow(m - 1, t - 1, MOD) % MOD

        return c * color % MOD
```

## 复杂度分析

- 时间复杂度：O(n)，预处理阶乘
- 空间复杂度：O(n)，存储阶乘数组

## 关键点总结

1. 将"恰好 k 对相邻相等"转化为"分成 n-k 个连续块"
2. 分块方案：插板法 C(n-1, t-1)
3. 染色方案：m * (m-1)^(t-1)（第一块 m 种，后续每块都不能和前一块同色）
4. 所有计算在模 10^9+7 下进行，需要用费马小定理求逆元

## 易错点

1. `t = n - k` 可能超出范围，需要特判
2. 当 `m == 1` 且 `t > 1` 时，`(m-1)^(t-1) = 0`，自然返回 0
3. 组合数中 n-1 而不是 n（间隔数比元素数少 1）
