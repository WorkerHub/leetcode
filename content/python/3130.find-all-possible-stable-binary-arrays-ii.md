## 题目描述

与 3129 题相同，但 `zero`, `one`, `limit` 的范围更大：
- `1 <= zero, one, limit <= 1000`

需要更高效的算法。

## 解题思路

与 3129 思路相同，但需要用前缀和优化 DP 转移，将 O(zero * one * limit) 优化为 O(zero * one)。

`dp[i][j][v]` = 放了 i 个 0, j 个 1，末位为 v 的方案数

转移：
- `dp[i][j][0] = sum(dp[i-k][j][1], k=1..limit)` = `prefix1[i-1][j] - prefix1[i-limit-1][j]`
- `dp[i][j][1] = sum(dp[i][j-k][0], k=1..limit)` = `prefix0[i][j-1] - prefix0[i][j-limit-1]`

## Python 代码实现

### 方法一：DP + 前缀和优化（推荐）

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i][j][0/1]: 使用 i 个 0, j 个 1, 末位为 0/1 的方案数
        dp = [[[0, 0] for _ in range(one + 1)] for _ in range(zero + 1)]

        # 初始化：全 0 段和全 1 段
        for i in range(1, min(zero, limit) + 1):
            dp[i][0][0] = 1
        for j in range(1, min(one, limit) + 1):
            dp[0][j][1] = 1

        # 前缀和：p0[i][j] = sum(dp[0..i][j][0]), p1[i][j] = sum(dp[i][0..j][1])
        for i in range(1, zero + 1):
            for j in range(1, one + 1):
                # dp[i][j][0] 来自 dp[i-1][j][1], dp[i-2][j][1], ..., dp[i-limit][j][1]
                # 即 sum(dp[i-k][j][1] for k in 1..limit if i-k >= 0)
                for k in range(1, min(i, limit) + 1):
                    dp[i][j][0] = (dp[i][j][0] + dp[i-k][j][1]) % MOD
                # dp[i][j][1] 来自 dp[i][j-1][0], ..., dp[i][j-limit][0]
                for k in range(1, min(j, limit) + 1):
                    dp[i][j][1] = (dp[i][j][1] + dp[i][j-k][0]) % MOD

        return (dp[zero][one][0] + dp[zero][one][1]) % MOD
```

### 方法二：真正前缀和 O(zero * one)

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [[[0, 0] for _ in range(one + 2)] for _ in range(zero + 2)]

        for i in range(1, min(zero, limit) + 1):
            dp[i][0][0] = 1
        for j in range(1, min(one, limit) + 1):
            dp[0][j][1] = 1

        # 前缀和：按列对 dp[][j][1] 求前缀和，按行对 dp[i][][0] 求前缀和
        # prefix_by_row[i][j] = sum of dp[0..i][j][1]
        # prefix_by_col[i][j] = sum of dp[i][0..j][0]

        pr = [[0] * (one + 2) for _ in range(zero + 2)]  # row prefix for [1]
        pc = [[0] * (one + 2) for _ in range(zero + 2)]  # col prefix for [0]

        for i in range(zero + 1):
            for j in range(one + 1):
                pr[i][j] = (dp[i][j][1] + (pr[i-1][j] if i > 0 else 0)) % MOD
                pc[i][j] = (dp[i][j][0] + (pc[i][j-1] if j > 0 else 0)) % MOD

                if i > 0 and j > 0:
                    # 重新计算 dp[i][j]
                    r = pr[i-1][j] - (pr[i-limit-1][j] if i-limit-1 >= 0 else 0)
                    dp[i][j][0] = r % MOD
                    c = pc[i][j-1] - (pc[i][j-limit-1] if j-limit-1 >= 0 else 0)
                    dp[i][j][1] = c % MOD

        return (dp[zero][one][0] + dp[zero][one][1]) % MOD
```

## 复杂度分析

- 时间复杂度：O(zero * one) 使用前缀和，O(zero * one * limit) 朴素方法
- 空间复杂度：O(zero * one)

## 关键点总结

1. 与 3129 相同，但需要前缀和将转移 O(limit) 优化为 O(1)
2. 对行方向（0 的维度）维护末位为 1 的前缀和
3. 对列方向（1 的维度）维护末位为 0 的前缀和

## 易错点

1. 前缀和的边界：当 i - limit - 1 < 0 时，减去的前缀和为 0
2. 初始化阶段（j=0 或 i=0）需要单独处理
