## 题目描述

给你一个长度为 `n` 下标从 **0** 开始的数组 `nums`，数组中每个元素均为非负整数。

对于 `0 <= i < n`，令 `ans[i]` 是 `nums[i..j]`（`i <= j < n`）中元素按位 **OR** 的最大值，且满足这个最大值对应的 `j` 的最小值。换言之，`ans[i]` 是 `nums[i]` 到 `nums[n-1]` 的子数组中，所有按位 OR 值达到最大的子数组中长度最短的那个的结束下标。

返回数组 `ans`，其中 `ans[i]` 是对应 `nums[i]` 的子数组长度。

**示例 1：**
```
输入：nums = [1,0,2,1,3]
输出：[3,3,2,2,1]
```

**示例 2：**
```
输入：nums = [1,2]
输出：[2,1]
```

## 解题思路

**关键观察：**
- 子数组的 OR 值随右端点增大是单调不减的（OR 操作只增不减）
- 对于位置 `i`，OR 最大值 = `nums[i] | nums[i+1] | ... | nums[n-1]`（整个后缀）
- 需要找到最早出现的下标 `j` 使得 `OR(i..j)` 达到最大值

**从右往左处理：**
对每一位（共 30 位），记录该位最后一次出现 1 的位置（从右往左遍历）。
对位置 `i`，所需的最短子数组长度取决于：
- 只需要让所有在后缀中出现的位都被覆盖
- 右端点 = 所有必要位的最右出现位置的最大值

## 代码实现

### 方法一：位追踪（推荐）

```python
from typing import List

class Solution:
    def smallestSubarrays(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # last[bit] = 该位（二进制位）最后一次出现 1 的位置
        last = [0] * 30

        ans = [0] * n

        for i in range(n - 1, -1, -1):
            # 更新每一位最后出现的位置
            for bit in range(30):
                if nums[i] >> bit & 1:
                    last[bit] = i

            # 当前位置 i 的答案：所有非零位中最远位置 - i + 1
            j = max(last)  # 子数组最小需要延伸到 j
            ans[i] = j - i + 1

        return ans
```

### 方法二：维护后缀 OR 的位位置

```python
from typing import List

class Solution:
    def smallestSubarrays(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [1] * n
        # 对每一位，记录从当前位置向右，该位最近出现 1 的下标
        bit_last = [-1] * 30

        for i in range(n - 1, -1, -1):
            for b in range(30):
                if (nums[i] >> b) & 1:
                    bit_last[b] = i

            # 需要到达的最远位置
            farthest = i  # 至少包含自身
            for b in range(30):
                if bit_last[b] != -1:
                    farthest = max(farthest, bit_last[b])

            ans[i] = farthest - i + 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 位追踪 | O(n * 30) | O(30) = O(1) |

## 关键点总结

1. OR 操作只增不减，最大 OR 值就是包含全部后缀的 OR
2. 对每个位独立追踪其最后出现的位置
3. 子数组至少需要延伸到所有被需要的位中的最远位置

## 易错点

- 初始化 `last = [0] * 30` 而非 `[-1] * 30`，因为我们取 `max(last)` 作为右端点
- 若某位在 `i` 之后从未出现，该位就不需要考虑（OR 最大值不含此位）
