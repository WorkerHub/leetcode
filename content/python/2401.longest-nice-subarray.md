## 题目描述

给你一个由 **正** 整数组成的数组 `nums`。

如果 `nums` 的子数组中位于 **不同** 位置的每对元素按位 `AND` 运算的结果等于 `0`，则称该子数组为 **优美子数组**。

返回 **最长** 的优美子数组的长度。

**子数组** 是数组中一个 **连续** 部分。

**注意：** 长度为 `1` 的子数组始终视作优美子数组。

**示例 1：**
```
输入：nums = [1,3,8,48,10]
输出：3
解释：最长的优美子数组是 [3,8,48]。
  - 3 AND 8 = 0
  - 3 AND 48 = 0
  - 8 AND 48 = 0
```

**示例 2：**
```
输入：nums = [3,1,5,11,13]
输出：1
解释：没有两个元素按位 AND 等于 0，所以最长的优美子数组长度为 1。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

优美子数组的条件是：子数组中任意两个不同元素按位 AND 为 0，即这些元素的所有位互不重叠。

等价条件：子数组中所有元素的二进制位互不相同（没有两个元素在同一个二进制位上同时为 1）。

**滑动窗口思路：**
1. 维护一个窗口 `[left, right]` 和窗口内所有数字按位 OR 的结果 `used`
2. 当加入 `nums[right]` 时，若 `nums[right] & used != 0`，说明有位重叠，需要从左缩小窗口
3. 每次将 `nums[left]` 从 `used` 中移除时，将 `nums[left]` 与 `used` 做 XOR（因为位不重叠，XOR 等价于减法）
4. 更新答案为窗口长度的最大值

## 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def longestNiceSubarray(self, nums: List[int]) -> int:
        ans = 1
        left = 0
        used = 0  # 记录当前窗口内所有数字使用的位

        for right in range(len(nums)):
            # 如果当前数字与已用位有重叠，缩小左边界
            while used & nums[right]:
                used ^= nums[left]  # 移除最左侧元素占用的位
                left += 1
            # 将当前数字加入窗口
            used |= nums[right]
            # 更新最大长度
            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：暴力枚举（对比学习）

```python
from typing import List

class Solution:
    def longestNiceSubarray(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 1

        for i in range(n):
            used = nums[i]
            for j in range(i + 1, n):
                # 检查 nums[j] 与窗口内所有位是否有重叠
                if used & nums[j]:
                    break
                used |= nums[j]  # 加入当前元素的位
                ans = max(ans, j - i + 1)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 暴力枚举 | O(n^2) | O(1) |

由于整数最多 30 个二进制位，每次滑动时窗口内最多有 30 个元素，所以 while 循环均摊下来是 O(1)，总体 O(n)。

## 关键点总结

1. 优美子数组等价于：所有元素的二进制位互不相交（OR 等于各个元素之和）
2. 滑动窗口中用 `used` 记录已占用的位集合
3. 移除左端元素时用 XOR 操作清除其占用的位（因为位不重叠）
4. `while used & nums[right]` 保证窗口合法性

## 易错点

- 移除元素时应使用 `used ^= nums[left]` 而非 `used -= nums[left]`（虽然结果相同，但 XOR 语义更清晰）
- 初始化 `ans = 1` 而不是 0，因为单个元素始终是优美子数组
