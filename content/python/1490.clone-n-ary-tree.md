## 题目描述

给定一棵 N 叉树的根节点 `root`，返回该树的**深拷贝**（克隆）。

N 叉树中每个节点均包含一个整数值 `val` 和一个子节点列表 `children`。

```python
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
```

**注意：** 深拷贝意味着新树中的每个节点都是全新创建的，不与原树共享引用。

**示例 1：**

```
输入：root = [1, null, 3, 2, 4, null, 5, 6]
输出：[1, null, 3, 2, 4, null, 5, 6]
```

**示例 2：**

```
输入：root = [1, null, 2, 3, 4, 5, null, null, 6, 7, null, 8, null, 9, 10, null, null, 11, null, 12, null, 13, null, null, 14]
输出：[1, null, 2, 3, 4, 5, null, null, 6, 7, null, 8, null, 9, 10, null, null, 11, null, 12, null, 13, null, null, 14]
```

**提示：**

- 节点总数在 `[0, 10^4]` 之间。
- 每个节点值 `0 <= Node.val <= 10^4`。
- N 叉树的高度不超过 1000。

## 解题思路

深拷贝一棵树，核心思路是：**为每个原节点创建一个对应的新节点，并递归处理其所有子节点。**

有两种经典的树遍历方式可以实现：

**方法一：DFS 递归**

- 若当前节点为空，直接返回 None
- 创建与当前节点值相同的新节点
- 递归克隆每个子节点，加入新节点的 children 列表
- 返回新节点

这种方式代码最简洁，利用系统调用栈完成深度优先遍历。

**方法二：BFS 迭代（使用队列）**

- 使用队列存储 (原节点, 克隆节点) 对
- 每次取出一对，对原节点的每个子节点创建克隆，加入克隆节点的 children，并将 (原子节点, 克隆子节点) 加入队列
- 直到队列为空

**方法三：DFS 迭代（使用栈）**

与 BFS 类似，用栈代替队列即可实现深度优先。

## Python 代码实现

### 方法一：DFS 递归（推荐，最简洁）

```python
from typing import Optional

# N 叉树节点定义（LeetCode 提供）
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []

class Solution:
    def cloneTree(self, root: 'Node') -> 'Node':
        # 空节点直接返回
        if root is None:
            return None

        # 创建新节点
        new_node = Node(root.val)

        # 递归克隆每个子节点
        for child in root.children:
            new_node.children.append(self.cloneTree(child))

        return new_node
```

### 方法二：BFS 迭代（使用队列）

```python
from collections import deque
from typing import Optional

class Solution:
    def cloneTree(self, root: 'Node') -> 'Node':
        if root is None:
            return None

        # 克隆根节点
        new_root = Node(root.val)

        # 队列存储 (原节点, 克隆节点) 对
        queue = deque([(root, new_root)])

        while queue:
            orig_node, clone_node = queue.popleft()

            # 克隆每个子节点
            for child in orig_node.children:
                # 创建克隆子节点
                clone_child = Node(child.val)
                # 加入克隆父节点的子列表
                clone_node.children.append(clone_child)
                # 将该对放入队列继续处理
                queue.append((child, clone_child))

        return new_root
```

### 方法三：DFS 迭代（使用栈）

```python
class Solution:
    def cloneTree(self, root: 'Node') -> 'Node':
        if root is None:
            return None

        new_root = Node(root.val)
        # 栈存储 (原节点, 克隆节点) 对
        stack = [(root, new_root)]

        while stack:
            orig_node, clone_node = stack.pop()

            for child in orig_node.children:
                clone_child = Node(child.val)
                clone_node.children.append(clone_child)
                stack.append((child, clone_child))

        return new_root
```

### 方法四：哈希表辅助（处理有环/重复引用的图结构变种）

```python
class Solution:
    def cloneTree(self, root: 'Node') -> 'Node':
        """
        使用哈希表映射原节点到克隆节点
        对于普通树来说不必要，但处理图结构时可防止重复克隆
        """
        if root is None:
            return None

        # 哈希表：原节点 -> 克隆节点
        memo = {}

        def dfs(node):
            if node is None:
                return None
            if node in memo:
                return memo[node]

            clone = Node(node.val)
            memo[node] = clone

            for child in node.children:
                clone.children.append(dfs(child))

            return clone

        return dfs(root)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 递归 | O(n) | O(h)，h 为树高 |
| BFS 迭代 | O(n) | O(w)，w 为最大宽度 |
| DFS 迭代 | O(n) | O(h) |
| 哈希表辅助 | O(n) | O(n) |

- `n` 为节点总数，所有方法都需要访问每个节点一次
- 递归方法空间取决于递归深度（树高），最坏 O(n)（链状树）
- BFS 的队列空间取决于树的最大宽度

## 关键点总结

1. **深拷贝 vs 浅拷贝**：深拷贝要求每个节点都是新对象，修改克隆树不影响原树。
2. **递归思路最自然**：克隆当前节点，递归克隆子节点，组合即可。
3. **BFS/DFS 迭代适合大树**：避免递归深度过大导致栈溢出。
4. **children 列表也需新建**：Node 构造时 children 默认为新空列表，无需额外处理。

## 易错点

- **忘记处理空节点**：root 为 None 时应直接返回 None。
- **浅拷贝陷阱**：直接 `new_node.children = root.children` 会共享列表引用，修改一个会影响另一个。
- **DFS 迭代中子节点顺序**：使用栈时，子节点弹出顺序与压入顺序相反，但对于克隆来说顺序需要保持一致（按原顺序加入 children）。

2. 掌握 DFS 递归版本后，再学习 BFS 迭代版本，体会两种遍历方式的差异。
