## 题目描述

给定一个按非递减顺序排列的数字数组 `digits`。你可以用任意次数 `digits[i]` 来写数字。例如，如果 `digits = ['1','3','5']`，我们可以写数字，如 `'13'`, `'551'`, 和 `'1351315'`。

返回可以生成的小于或等于给定整数 `n` 的正整数的个数。

**示例 1：**
```
输入：digits = ["1","3","5","7"], n = 100
输出：20
解释：
可写出的数字有：
1, 3, 5, 7, 11, 13, 15, 17, 31, 33, 35, 37, 51, 53, 55, 57, 71, 73, 75, 77
```

**示例 2：**
```
输入：digits = ["1","4","9"], n = 1000000000
输出：29523
解释：
我们可以写 3 位数字，4 位数字，5 位数字，6 位数字，7 位数字，8 位数字，或 9 位数字。
总共，可以使用 digits 写出 29523 个整数。
```

**提示：**
- 1 <= digits.length <= 9
- digits[i].length == 1
- digits[i] 是从 '1' 到 '9' 的数字
- digits 中的所有值都不同
- digits 按非递减顺序排列
- 1 <= n <= 10^9

## 解题思路

这是一道数位 DP 问题。核心思想是分类讨论：
1. **位数少于 n 的数字**：可以自由组合
2. **位数等于 n 的数字**：需要逐位判断

**算法流程：**

假设 n 有 k 位：
1. 计算位数小于 k 的所有合法数字：对于 i 位数，有 `len(digits)^i` 种组合
2. 计算位数等于 k 的合法数字：
   - 从高位到低位逐位判断
   - 如果当前位可以填比 n 对应位小的数字，后面位可以随意填
   - 如果只能填等于 n 对应位的数字，继续检查下一位
   - 如果没有合适的数字可填，结束

**关键观察：**
- 位数少的数字一定小于 n（因为 digits 不包含 '0'）
- 对于位数相同的，需要逐位比较
- 使用组合数学计算，避免枚举所有数字

## Python 代码实现

### 方法一：数位 DP（推荐）⭐

```python
from typing import List

class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        # 将 n 转换为字符串
        s = str(n)
        k = len(s)  # n 的位数
        d = len(digits)  # 可用数字的个数
        
        result = 0
        
        # 1. 计算位数小于 k 的所有数字
        for i in range(1, k):
            result += d ** i
        
        # 2. 计算位数等于 k 的数字
        for i in range(k):
            # 统计有多少个 digit 小于 s[i]
            count = 0
            has_same = False  # 是否存在等于 s[i] 的数字
            
            for digit in digits:
                if digit < s[i]:
                    count += 1
                elif digit == s[i]:
                    has_same = True
            
            # 如果有 count 个数字小于 s[i]，那么这一位可以填这些数字
            # 后面的 k-i-1 位可以任意填
            result += count * (d ** (k - i - 1))
            
            # 如果当前位没有等于 s[i] 的数字，无法继续构造
            if not has_same:
                break
        else:
            # 所有位都能找到相等的数字，n 本身也是合法的
            result += 1
        
        return result
```

### 方法二：数位 DP（递归版本）

```python
from typing import List

class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        s = str(n)
        k = len(s)
        d = len(digits)
        
        # 记忆化搜索
        from functools import lru_cache
        
        @lru_cache(None)
        def dp(pos: int, is_limit: bool, is_num: bool) -> int:
            """
            pos: 当前处理到第几位
            is_limit: 当前是否受到 n 的限制
            is_num: 之前是否填了数字
            """
            if pos == k:
                # 到达末尾，如果填了数字就计数
                return int(is_num)
            
            res = 0
            
            # 可以选择不填数字（跳过前导零）
            if not is_num:
                res = dp(pos + 1, False, False)
            
            # 确定当前位可以填的数字范围
            up = s[pos] if is_limit else '9'
            
            for digit in digits:
                if digit > up:
                    break
                res += dp(pos + 1, is_limit and digit == up, True)
            
            return res
        
        # 减去位数小于 k 且没有填数字的情况
        return dp(0, True, False)
```

### 方法三：优化的迭代版本

```python
from typing import List

class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        s = str(n)
        k = len(s)
        d = len(digits)
        
        # 位数少于 k 的数字个数
        ans = sum(d ** i for i in range(1, k))
        
        # 位数等于 k 的数字
        for i, char in enumerate(s):
            # 计算有多少个 digit < char
            cnt = sum(digit < char for digit in digits)
            ans += cnt * (d ** (k - i - 1))
            
            # 如果没有 digit 等于 char，无法继续
            if char not in digits:
                break
        else:
            # n 本身也是合法的
            ans += 1
        
        return ans
```

## 复杂度分析

**方法一（迭代数位 DP）：**
- 时间复杂度：O(k × d)，其中 k 是 n 的位数，d 是 digits 的长度
  - 外层循环 k 次，内层循环 d 次
- 空间复杂度：O(k)，存储 n 的字符串表示

**方法二（递归数位 DP）：**
- 时间复杂度：O(k × d)，记忆化后每个状态只计算一次
- 空间复杂度：O(k)，递归栈的深度

## 关键点总结

1. **分类讨论**：将问题分为位数小于 n 和位数等于 n 两种情况
2. **组合计数**：位数为 i 的合法数字有 `d^i` 个
3. **逐位判断**：对于位数相同的，从高位到低位逐个比较
4. **提前终止**：如果某一位无法匹配，后续位不需要再检查
5. **边界处理**：最后要判断 n 本身是否合法

## 易错点

1. **for-else 语法**：Python 的 for-else 在循环正常结束时执行 else，被 break 打断时不执行
2. **位数计算**：位数为 i 的数字有 `d^i` 个，不是 `d^(i-1)`
3. **n 本身**：别忘了判断 n 本身是否可以由 digits 构成
4. **数字范围**：digits 不包含 '0'，所以位数少的数字一定大于 0
5. **幂运算**：`d ** 0 = 1`，表示没有后续位时只有一种选择
