## 题目描述

给定一个 N 叉树的根节点 `root`，返回其节点值的前序遍历。

## Python 代码实现

### 方法一：递归

```python
class Solution:
    def preorder(self, root: 'Node') -> List[int]:
        result = []
        def dfs(node):
            if not node:
                return
            result.append(node.val)
            for child in node.children:
                dfs(child)
        dfs(root)
        return result
```

### 方法二：迭代

```python
class Solution:
    def preorder(self, root: 'Node') -> List[int]:
        if not root:
            return []
        stack, result = [root], []
        while stack:
            node = stack.pop()
            result.append(node.val)
            stack.extend(reversed(node.children))
        return result
```
