## 题目描述

请你设计一个可以解释字符串 `command` 的**目标解析器**。`command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成。

目标解析器的解释规则：
- `"G"` -> `"G"`
- `"()"` -> `"o"`
- `"(al)"` -> `"al"`

返回解析 `command` 后的字符串。

**示例：**
```
输入：command = "G()(al)"
输出："Goal"

输入：command = "(al)G(al)()()G"
输出："alGalooG"
```

## 解题思路

按顺序扫描字符串，根据当前字符判断下一步操作：
- 遇到 `G`：直接添加 `G`
- 遇到 `()`：添加 `o`
- 遇到 `(al)`：添加 `al`

也可以用字符串替换一步完成。

## 代码实现

### 方法一：字符串替换（推荐，最简洁）

```python
class Solution:
    def interpret(self, command: str) -> str:
        return command.replace("()", "o").replace("(al)", "al")
```

### 方法二：逐字符扫描

```python
class Solution:
    def interpret(self, command: str) -> str:
        result = []
        i = 0
        n = len(command)
        
        while i < n:
            if command[i] == 'G':
                result.append('G')
                i += 1
            elif command[i:i+2] == '()':
                result.append('o')
                i += 2
            else:  # command[i:i+4] == '(al)'
                result.append('al')
                i += 4
        
        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 字符串替换 | O(n) | O(n) |
| 逐字符扫描 | O(n) | O(n) |

## 关键点总结

1. 方法一最简洁：先替换 `()`，再替换 `(al)`（注意顺序）
2. 如果先替换 `(al)` 会将其中的 `()` 先变成 `o`（影响结果），但其实 `(al)` 中没有 `()`，所以两种顺序都可以
3. 逐字符扫描时，`(` 开头时区分 `()` 和 `(al)` 即可

## 易错点

- 替换时，`()` 替换为小写 `o`，不是大写
- `(al)` 内的 `al` 是小写
