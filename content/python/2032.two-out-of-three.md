## 题目描述

给你三个整数数组 `nums1`、`nums2` 和 `nums3`，请你构造并返回一个**不同**数组，且由**至少**在**两个**数组中出现的所有值组成。数组中的元素可以按**任意**顺序排列。

**示例 1：**
```
输入：nums1 = [1,1,3,2], nums2 = [2,3], nums3 = [3]
输出：[3,2]
解释：3 在 nums1,nums2,nums3 都出现；2 在 nums1,nums2 出现
```

**示例 2：**
```
输入：nums1 = [3,1], nums2 = [2,3], nums3 = [1,2]
输出：[2,3,1]
```

**提示：**
- `1 <= nums1.length, nums2.length, nums3.length <= 100`
- `1 <= nums1[i], nums2[i], nums3[i] <= 100`

## 解题思路

对每个数字统计它在多少个数组中出现（注意同一数组内重复不算），出现次数 >= 2 的数字加入结果。

## 代码实现

### 方法一：集合计数（推荐）

```python
from typing import List

class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        from collections import Counter
        # 每个数组去重后合并，统计每个数字出现在多少个数组中
        count = Counter(set(nums1)) + Counter(set(nums2)) + Counter(set(nums3))
        return [num for num, cnt in count.items() if cnt >= 2]
```

### 方法二：哈希表手动统计

```python
from typing import List

class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        appear = {}  # 记录每个数字出现在哪些数组中

        for num in set(nums1):
            appear[num] = appear.get(num, 0) + 1
        for num in set(nums2):
            appear[num] = appear.get(num, 0) + 1
        for num in set(nums3):
            appear[num] = appear.get(num, 0) + 1

        return [num for num, cnt in appear.items() if cnt >= 2]
```

### 方法三：位运算标记

```python
from typing import List

class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        # 用位掩码表示每个数出现在哪些数组
        # bit 0 = nums1, bit 1 = nums2, bit 2 = nums3
        mask = {}
        for num in set(nums1):
            mask[num] = mask.get(num, 0) | 1
        for num in set(nums2):
            mask[num] = mask.get(num, 0) | 2
        for num in set(nums3):
            mask[num] = mask.get(num, 0) | 4

        # 至少2个数组中出现：位掩码中至少2位为1
        return [num for num, m in mask.items() if bin(m).count('1') >= 2]
```

## 复杂度分析

- 时间复杂度：O(n1 + n2 + n3)
- 空间复杂度：O(n1 + n2 + n3)

## 关键点总结

1. 先对每个数组去重（使用 `set()`），避免同一数组内重复计数
2. 统计每个数字出现的数组数量，筛选 >= 2 的
3. 使用 `Counter` 加法可以优雅合并多个数组的计数

## 易错点

- 必须先去重再统计，否则 `[1,1]` 中的 1 会被计算两次
- 返回的是不重复的数字列表（题目要求"不同"数组）
