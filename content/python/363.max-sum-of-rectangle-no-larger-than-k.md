## 题目描述

给你一个 `m x n` 的矩阵 `matrix` 和一个整数 `k`，找出并返回矩阵内部矩形区域的不超过 `k` 的最大数值和。

题目数据保证总会存在一个数值和不超过 `k` 的矩形区域。

**示例 1：**

```
输入：matrix = [[1,0,1],[0,-2,3]], k = 2
输出：2
解释：蓝色矩形区域 [[0,1],[-2,3]] 的数值和是 2，且 2 是不超过 k 的最大数字（k = 2）
```

**示例 2：**

```
输入：matrix = [[2,2,-1]], k = 3
输出：3
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-100 <= matrix[i][j] <= 100`
- `-10^5 <= k <= 10^5`

**进阶：**
如果行数远大于列数，该如何设计解决方案？

## 解题思路

这是一道综合性很强的题目，涉及前缀和、降维、有序集合等多个技巧。

### 核心思想

1. **降维处理**：将二维矩形和问题转化为一维数组的子数组和问题
2. **枚举行边界**：固定上下边界，将问题降维到一维
3. **有序集合优化**：使用有序集合（如 TreeSet）快速查找满足条件的前缀和

### 算法流程

1. 枚举矩形的上边界 `i`
2. 枚举矩形的下边界 `j`（从 `i` 到 `m-1`）
3. 计算从第 `i` 行到第 `j` 行每列的和，得到一维数组
4. 在一维数组中找不超过 `k` 的最大子数组和

### 一维子数组和问题

对于一维数组，要找不超过 `k` 的最大子数组和：
- 使用前缀和 `preSum`
- 要找 `preSum[j] - preSum[i] <= k`，即 `preSum[i] >= preSum[j] - k`
- 使用有序集合快速找到 `>= preSum[j] - k` 的最小值

## Python 代码实现

### 方法一：前缀和 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def maxSumSubmatrix(self, matrix: List[List[int]], k: int) -> int:
        """
        使用前缀和 + 有序集合
        时间复杂度：O(m^2 * n * log(n))
        """
        m, n = len(matrix), len(matrix[0])
        max_sum = float('-inf')
        
        # 枚举上边界
        for top in range(m):
            # 记录从 top 行到当前行每列的累计和
            col_sum = [0] * n
            
            # 枚举下边界
            for bottom in range(top, m):
                # 更新列和
                for col in range(n):
                    col_sum[col] += matrix[bottom][col]
                
                # 在一维数组 col_sum 中找不超过 k 的最大子数组和
                max_sum = max(max_sum, self.maxSumSubarray(col_sum, k))
                
                # 提前退出优化
                if max_sum == k:
                    return k
        
        return max_sum
    
    def maxSumSubarray(self, nums: List[int], k: int) -> int:
        """
        在一维数组中找不超过 k 的最大子数组和
        使用有序集合优化
        """
        max_sum = float('-inf')
        prefix_sum = 0
        sorted_sums = SortedList([0])  # 存储前缀和
        
        for num in nums:
            prefix_sum += num
            
            # 找 prefix_sum - x <= k，即 x >= prefix_sum - k
            # 在有序集合中查找 >= prefix_sum - k 的最小值
            target = prefix_sum - k
            idx = sorted_sums.bisect_left(target)
            
            if idx < len(sorted_sums):
                max_sum = max(max_sum, prefix_sum - sorted_sums[idx])
            
            sorted_sums.add(prefix_sum)
        
        return max_sum
```

### 方法二：不使用第三方库（使用 bisect）

```python
from typing import List
import bisect

class Solution:
    def maxSumSubmatrix(self, matrix: List[List[int]], k: int) -> int:
        m, n = len(matrix), len(matrix[0])
        max_sum = float('-inf')
        
        # 优化：选择较小的维度作为外层循环
        # 如果 m > n，转置矩阵
        if m > n:
            matrix = list(zip(*matrix))
            m, n = n, m
        
        for top in range(m):
            col_sum = [0] * n
            
            for bottom in range(top, m):
                for col in range(n):
                    col_sum[col] += matrix[bottom][col]
                
                # 在一维数组中找不超过 k 的最大子数组和
                max_sum = max(max_sum, self.maxSumSubarray(col_sum, k))
                
                if max_sum == k:
                    return k
        
        return max_sum
    
    def maxSumSubarray(self, nums: List[int], k: int) -> int:
        """
        使用有序列表（手动维护）
        """
        max_sum = float('-inf')
        prefix_sum = 0
        sorted_sums = [0]  # 存储前缀和，保持有序
        
        for num in nums:
            prefix_sum += num
            
            # 二分查找 >= prefix_sum - k 的最小值
            target = prefix_sum - k
            idx = bisect.bisect_left(sorted_sums, target)
            
            if idx < len(sorted_sums):
                max_sum = max(max_sum, prefix_sum - sorted_sums[idx])
            
            # 插入当前前缀和，保持有序
            bisect.insort(sorted_sums, prefix_sum)
        
        return max_sum
```

### 方法三：暴力法（用于理解）

```python
from typing import List

class Solution:
    def maxSumSubmatrix(self, matrix: List[List[int]], k: int) -> int:
        """
        暴力枚举所有矩形，计算和
        时间复杂度：O(m^2 * n^2)
        """
        m, n = len(matrix), len(matrix[0])
        max_sum = float('-inf')
        
        # 预计算前缀和
        prefix = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                prefix[i][j] = (matrix[i-1][j-1] + 
                               prefix[i-1][j] + 
                               prefix[i][j-1] - 
                               prefix[i-1][j-1])
        
        # 枚举所有矩形
        for i1 in range(1, m + 1):
            for j1 in range(1, n + 1):
                for i2 in range(i1, m + 1):
                    for j2 in range(j1, n + 1):
                        # 计算矩形和
                        rect_sum = (prefix[i2][j2] - 
                                   prefix[i1-1][j2] - 
                                   prefix[i2][j1-1] + 
                                   prefix[i1-1][j1-1])
                        
                        if rect_sum <= k:
                            max_sum = max(max_sum, rect_sum)
        
        return max_sum
```

## 复杂度分析

### 方法一：前缀和 + 有序集合
- 时间复杂度：O(m^2 × n × log n)
  - 枚举上下边界：O(m^2)
  - 每次查找一维最大和：O(n × log n)
- 空间复杂度：O(n)

### 方法二：优化后
- 时间复杂度：O(min(m, n)^2 × max(m, n) × log(max(m, n)))
- 空间复杂度：O(max(m, n))

### 方法三：暴力法
- 时间复杂度：O(m^2 × n^2)
- 空间复杂度：O(m × n)

## 关键点总结

1. **降维思想**：二维问题转化为一维问题是关键
2. **有序集合**：快速查找满足条件的前缀和
3. **前缀和技巧**：快速计算子数组和
4. **优化策略**：选择较小的维度作为外层循环
5. **提前退出**：找到等于 k 的结果可立即返回

## 易错点

1. **边界条件**：前缀和数组的索引容易出错
2. **初始化**：有序集合要初始化为 [0]，表示空前缀
3. **查找方向**：要找 `>= target` 的最小值，使用 `bisect_left`
4. **矩阵转置**：优化时注意正确转置矩阵
5. **负数处理**：数组中有负数，不能用滑动窗口
