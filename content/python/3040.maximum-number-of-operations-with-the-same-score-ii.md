## 题目描述

给你一个整数数组 `nums`，每次操作从数组中选择**前两个**或**后两个**或**第一个和最后一个**元素相加得到分数，然后删除这两个元素。

所有操作的分数必须相同。

返回最多能执行多少次操作。

**示例 1：**
```
输入：nums = [3,2,1,2,3,4]
输出：3
```

**示例 2：**
```
输入：nums = [3,2,6,1,4]
输出：2
```

**提示：**
- `2 <= nums.length <= 2000`
- `1 <= nums[i] <= 1000`

## 解题思路

第一次操作确定目标分数 `target`，可以是：
- `nums[0] + nums[1]`（前两个）
- `nums[-1] + nums[-2]`（后两个）
- `nums[0] + nums[-1]`（首尾）

对每种可能的 `target`，用区间 DP（记忆化搜索）计算最多操作数。

`dp(l, r)` = 在 `nums[l..r]` 中，使用固定 `target` 分数的最多操作次数。

每次可以：
- 取 `nums[l] + nums[l+1]`（若 == target）
- 取 `nums[r-1] + nums[r]`（若 == target）
- 取 `nums[l] + nums[r]`（若 == target）

## Python 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxOperations(self, nums: List[int]) -> int:
        n = len(nums)

        def solve(target: int) -> int:
            @lru_cache(maxsize=None)
            def dp(l: int, r: int) -> int:
                if r - l + 1 < 2:
                    return 0

                best = 0
                # 取前两个
                if nums[l] + nums[l+1] == target:
                    best = max(best, 1 + dp(l+2, r))
                # 取后两个
                if nums[r-1] + nums[r] == target:
                    best = max(best, 1 + dp(l, r-2))
                # 取首尾
                if nums[l] + nums[r] == target:
                    best = max(best, 1 + dp(l+1, r-1))

                return best

            result = dp(0, n-1)
            dp.cache_clear()
            return result

        # 三种可能的 target
        targets = set()
        targets.add(nums[0] + nums[1])
        targets.add(nums[-1] + nums[-2])
        targets.add(nums[0] + nums[-1])

        return max(solve(t) for t in targets)
```

### 方法二：自底向上 DP

```python
from typing import List

class Solution:
    def maxOperations(self, nums: List[int]) -> int:
        n = len(nums)

        def solve(target: int) -> int:
            # dp[l][r] = nums[l..r] 中最多操作数
            dp = [[0] * n for _ in range(n)]

            for length in range(2, n + 1, 2):  # 只考虑偶数长度
                for l in range(n - length + 1):
                    r = l + length - 1

                    if nums[l] + nums[l+1] == target and l+2 <= r:
                        dp[l][r] = max(dp[l][r], 1 + dp[l+2][r])
                    elif nums[l] + nums[l+1] == target and length == 2:
                        dp[l][r] = max(dp[l][r], 1)

                    if nums[r-1] + nums[r] == target and l <= r-2:
                        dp[l][r] = max(dp[l][r], 1 + dp[l][r-2])
                    elif nums[r-1] + nums[r] == target and length == 2:
                        dp[l][r] = max(dp[l][r], 1)

                    if nums[l] + nums[r] == target and length >= 2:
                        if length == 2:
                            dp[l][r] = max(dp[l][r], 1)
                        else:
                            dp[l][r] = max(dp[l][r], 1 + dp[l+1][r-1])

            return dp[0][n-1]

        targets = {nums[0]+nums[1], nums[-1]+nums[-2], nums[0]+nums[-1]}
        return max(solve(t) for t in targets)
```

## 复杂度分析

- 时间复杂度：O(n^2)，状态数 O(n^2)，每个状态 O(1)
- 空间复杂度：O(n^2)

## 关键点总结

1. 第一次操作有三种选择，每种确定不同的 target
2. 对每个 target 用区间 DP 求最大操作数
3. 取三种 target 中的最大值

## 易错点

1. 三种 target 可能相等，用 set 去重避免重复计算
2. 注意区间长度必须为偶数（每次消耗两个元素）
3. `l > r - 1` 时区间不合法，需要检查边界
