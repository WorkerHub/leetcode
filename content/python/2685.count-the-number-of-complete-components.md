## 题目描述

给你一个整数 `n`（节点 0 到 n-1）和无向图的边数组 `edges`。若一个连通分量是**完全图**（任意两节点间都有边），则称其为**完全连通分量**。

返回完全连通分量的数量。

**示例 1：**
```
输入：n = 6, edges = [[0,1],[0,2],[1,2],[3,4]]
输出：3
解释：{0,1,2} 是完全图（3个节点3条边），{3,4} 是完全图（2个节点1条边），{5} 单节点，共3个
```

**数据范围：**
- 1 <= n <= 50
- 0 <= edges.length <= n*(n-1)/2

## 解题思路

1. 找出所有连通分量（DFS/BFS/并查集）
2. 对每个连通分量，若节点数为 `k`，则完全图应有 `k*(k-1)/2` 条边
3. 统计分量内的边数，若等于 `k*(k-1)/2` 则为完全连通分量

## Python 代码实现

### 方法一：DFS + 边数统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCompleteComponents(self, n: int, edges: List[List[int]]) -> int:
        # 建邻接表
        graph = defaultdict(set)
        for u, v in edges:
            graph[u].add(v)
            graph[v].add(u)

        visited = [False] * n

        def dfs(node):
            """DFS 返回 (节点集合)"""
            component = []
            stack = [node]
            visited[node] = True
            while stack:
                u = stack.pop()
                component.append(u)
                for v in graph[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            return component

        ans = 0
        for i in range(n):
            if not visited[i]:
                comp = dfs(i)
                k = len(comp)
                # 计算分量内的边数
                edge_count = sum(len(graph[u]) for u in comp) // 2
                if edge_count == k * (k - 1) // 2:
                    ans += 1

        return ans
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def countCompleteComponents(self, n: int, edges: List[List[int]]) -> int:
        parent = list(range(n))
        rank = [0] * n

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1

        for u, v in edges:
            union(u, v)

        from collections import defaultdict
        groups = defaultdict(lambda: [0, 0])  # root -> [node_count, edge_count]
        for i in range(n):
            groups[find(i)][0] += 1
        for u, v in edges:
            groups[find(u)][1] += 1

        return sum(1 for k, e in groups.values() if e == k * (k - 1) // 2)
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 完全图：k 个节点恰好 `k*(k-1)/2` 条边
2. 先找连通分量，再验证是否完全图
3. 单个节点也是完全连通分量（0 条边）

## 易错点

1. 统计边数时每条边被两个节点各统计一次，需除以 2
2. 单节点（孤立节点）符合完全连通分量的定义
