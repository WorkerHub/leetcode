## 题目描述

给你一个正整数 `n`，表示正多边形的顶点数。每个顶点上有一只猴子，每只猴子随机沿顺时针或逆时针方向移动一步（到相邻顶点）。

如果有两只猴子在同一条边或同一顶点相遇，则发生碰撞。

返回发生碰撞的概率的分子（分母为 `2^n`，结果对 `10^9 + 7` 取模）。

注：**不发生碰撞**的方案只有两种：所有猴子同时顺时针移动，或所有猴子同时逆时针移动。

发生碰撞的方案数 = 总方案数 - 不发生碰撞的方案数 = `2^n - 2`。

**示例 1：**

```
输入：n = 3
输出：6
解释：2^3 - 2 = 6
```

**示例 2：**

```
输入：n = 4
输出：14
解释：2^4 - 2 = 14
```

**提示：**

- `3 <= n <= 10^9`

## 解题思路

不碰撞的充要条件：所有猴子朝同一方向移动（全顺时针或全逆时针），共 2 种方案。

总方案数 = 2^n（每只猴子独立选择方向）。

碰撞方案数 = 2^n - 2（对 10^9 + 7 取模）。

## Python 代码实现

### 方法一：快速幂（推荐）

```python
MOD = 10**9 + 7

class Solution:
    def monkeyMove(self, n: int) -> int:
        # 碰撞方案数 = 2^n - 2
        return (pow(2, n, MOD) - 2 + MOD) % MOD
```

### 方法二：递推计算 2^n

```python
MOD = 10**9 + 7

class Solution:
    def monkeyMove(self, n: int) -> int:
        # 快速幂计算 2^n mod MOD
        result = 1
        base = 2
        exp = n
        while exp > 0:
            if exp % 2 == 1:
                result = result * base % MOD
            base = base * base % MOD
            exp //= 2
        return (result - 2 + MOD) % MOD
```

## 复杂度分析

- 时间复杂度：O(log n)，快速幂
- 空间复杂度：O(1)

## 关键点总结

1. 不碰撞只有 2 种（全顺时针/全逆时针），总方案 2^n
2. 碰撞方案数 = 2^n - 2
3. 减法取模时要加 MOD 防止负数

## 易错点

1. n 可以很大（10^9），必须用快速幂（`pow(base, exp, mod)`）
2. 减 2 后取模：`(2^n - 2 + MOD) % MOD`
3. Python 内置 `pow(2, n, MOD)` 已经是快速幂，直接使用
