## 题目描述

给你一个二维整数数组 `intervals`，其中 `intervals[i] = [lefti, righti]` 表示 **闭** 区间 `[lefti, righti]`。

你需要将 `intervals` 划分为一个或多个区间 **组**，使得每组中任意两个区间之间 **不相交**。返回 **最少** 需要划分成多少组。

如果两个区间覆盖的点有一个公共点，那么我们称这两个区间是 **相交** 的。比如区间 `[1, 5]` 和 `[5, 8]` 相交。

**示例 1：**
```
输入：intervals = [[5,10],[6,8],[1,5],[2,3],[1,10]]
输出：3
```

**示例 2：**
```
输入：intervals = [[1,3],[5,6],[8,10],[11,13]]
输出：1
```

**提示：**
- `1 <= intervals.length <= 10^5`
- `1 <= lefti <= righti <= 10^6`

## 解题思路

**关键观察：** 最少分组数 = 最大同时重叠的区间数。

原因：如果某个时间点有 k 个区间同时覆盖，这 k 个区间必须分到不同组中，所以至少需要 k 组。反过来，贪心地每次能放进已有组就放，否则新开一组，可以证明永远不需要多于 k 组。

**方法一（差分数组）：**
- 对每个区间 `[l, r]`，在 l 位置加 1，在 r+1 位置减 1
- 求前缀和的最大值即为答案

**方法二（最小堆）：**
- 按左端点排序区间
- 维护一个最小堆，堆中存储每组最后一个区间的右端点
- 对每个新区间，若堆顶 < 当前左端点，弹出堆顶（该组可以容纳新区间）；否则新开一组

## 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def minGroups(self, intervals: List[List[int]]) -> int:
        # 差分数组记录区间覆盖次数
        diff = {}
        for left, right in intervals:
            diff[left] = diff.get(left, 0) + 1    # 区间开始
            diff[right + 1] = diff.get(right + 1, 0) - 1  # 区间结束

        # 扫描线：求前缀和的最大值
        ans = 0
        cur = 0
        for key in sorted(diff):
            cur += diff[key]
            ans = max(ans, cur)

        return ans
```

### 方法二：最小堆贪心

```python
from typing import List
import heapq

class Solution:
    def minGroups(self, intervals: List[List[int]]) -> int:
        # 按左端点排序
        intervals.sort()
        # 最小堆，存储各组最后一个区间的右端点
        heap = []

        for left, right in intervals:
            if heap and heap[0] < left:
                # 可以放入最早结束的组（注意是严格小于，相交不能同组）
                heapq.heappop(heap)
            # 加入当前区间的右端点（新组或复用旧组）
            heapq.heappush(heap, right)

        # 堆的大小即为组数
        return len(heap)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 差分数组 | O(n log n) | O(n) |
| 最小堆 | O(n log n) | O(n) |

## 关键点总结

1. 最少分组数 = 最大同时重叠区间数（扫描线经典结论）
2. 差分数组：区间 `[l, r]` 对应 `diff[l]++, diff[r+1]--`
3. 堆方法中，`heap[0] < left`（严格小于）才能合并，等于时不行（因为是闭区间）

## 易错点

- 差分数组中区间结束位置是 `right + 1`，不是 `right`（闭区间）
- 堆方法判断条件：`heap[0] < left` 而非 `heap[0] <= left`，因为区间端点相等也算相交
