## 题目描述

给你一个整数数组 `nums`。

将 `nums` 划分为若干 **连续子数组**，每个子数组 `[a0, a1, a2, ..., ak]` 的 **代价** 为 `a0 - a1 + a2 - a3 + ...`（交替加减）。

返回所有子数组代价之和的 **最大值**。

**示例 1：**
```
输入：nums = [1,-2,3,4]
输出：10
解释：[1],[-2],[3,4] -> 1 + (-2) + (3-4) = 0。还是 [1,-2,3,4] -> 1-(-2)+3-4=2... 
最优划分使得每个元素都作为正项或负项。
实际：最优可能是每个元素单独一个子数组，总代价=1+(-2)+3+4=6；或者 [1,-2,3,4]→1-(-2)+3-4=2...
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

DP：对每个元素，它在子数组中的奇偶位置决定了符号（+或-）。

`dp[i][0]` = nums[i] 作为其所在子数组的 **第一个元素**（正号）时的最大总代价
`dp[i][1]` = nums[i] 作为其所在子数组的 **非第一个元素**（正负交替）时的最大总代价

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maximumTotalCost(self, nums: List[int]) -> int:
        n = len(nums)
        # f: 当前元素为子数组第一个元素（正号）的最大代价
        # g: 当前元素为子数组第二个元素（负号）的最大代价
        f = nums[0]   # 以 nums[0] 为起点
        g = float('-inf')

        for i in range(1, n):
            # nums[i] 可以：
            # 1. 作为新子数组的第一个元素：前驱 max(f, g)
            # 2. 作为上一个元素后面的第二个元素（负号）：前驱 f
            new_f = max(f, g) + nums[i]
            new_g = f - nums[i]  # 接在正号元素后面，以负号出现
            f, g = new_f, new_g

        return max(f, g)
```

### 方法二：更清晰的状态定义

```python
from typing import List

class Solution:
    def maximumTotalCost(self, nums: List[int]) -> int:
        # pos: 当前元素以 + 号出现的最优总代价
        # neg: 当前元素以 - 号出现的最优总代价
        pos = nums[0]
        neg = float('-inf')

        for i in range(1, n := len(nums)):
            # 下一个元素
            x = nums[i]
            # 接在 pos 后面：可以是新子数组开头（+）或同一子数组的第二个（-）
            new_pos = max(pos, neg) + x
            new_neg = pos - x
            pos, neg = new_pos, new_neg

        return max(pos, neg)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个元素要么作为新子数组开头（+号）要么作为上一个 + 号元素的后继（-号）
2. 负号元素只能紧跟一个正号元素（-号只能在偶数位置）
3. DP 维护两个状态（当前正号/负号结尾）

## 易错点

1. 负号元素只能接在正号元素之后（不能连续出现）
2. 新子数组可以接在任何前驱后面
