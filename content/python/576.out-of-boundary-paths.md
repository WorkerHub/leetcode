## 题目描述

给你一个大小为 `m x n` 的网格和一个球。球的起始坐标为 `[startRow, startColumn]`。你可以将球移动到在四个方向上相邻的单元格内（可以穿过网格边界到达网格之外）。你最多可以移动 `maxMove` 次球。

给你五个整数 `m`、`n`、`maxMove`、`startRow` 以及 `startColumn`，找出并返回可以将球移出边界的路径数量。因为答案可能非常大，返回对 `10^9 + 7` **取余** 后的结果。

**示例 1：**
```
输入：m = 2, n = 2, maxMove = 2, startRow = 0, startColumn = 0
输出：6
```

**示例 2：**
```
输入：m = 1, n = 3, maxMove = 3, startRow = 0, startColumn = 1
输出：12
```

**提示：**
- `1 <= m, n <= 50`
- `0 <= maxMove <= 50`
- `0 <= startRow < m`
- `0 <= startColumn < n`

## 解题思路

三维动态规划问题。

状态定义：
- `dp[k][i][j]` 表示移动 k 次后在位置 (i,j) 的路径数

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
class Solution:
    def findPaths(self, m: int, n: int, maxMove: int, startRow: int, startColumn: int) -> int:
        """
        三维 DP
        
        时间复杂度：O(maxMove * m * n)
        空间复杂度：O(m * n)
        """
        MOD = 10**9 + 7
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        
        # dp[i][j] 表示当前步数到达 (i,j) 的路径数
        dp = [[0] * n for _ in range(m)]
        dp[startRow][startColumn] = 1
        
        result = 0
        
        for move in range(maxMove):
            temp = [[0] * n for _ in range(m)]
            for i in range(m):
                for j in range(n):
                    if dp[i][j] > 0:
                        for dx, dy in directions:
                            ni, nj = i + dx, j + dy
                            if 0 <= ni < m and 0 <= nj < n:
                                temp[ni][nj] = (temp[ni][nj] + dp[i][j]) % MOD
                            else:
                                # 出界，累加到结果
                                result = (result + dp[i][j]) % MOD
            dp = temp
        
        return result
```

### 方法二：记忆化搜索

```python
class Solution:
    def findPaths(self, m: int, n: int, maxMove: int, startRow: int, startColumn: int) -> int:
        """
        记忆化 DFS
        
        时间复杂度：O(maxMove * m * n)
        空间复杂度：O(maxMove * m * n)
        """
        MOD = 10**9 + 7
        memo = {}
        
        def dfs(i, j, moves):
            if i < 0 or i >= m or j < 0 or j >= n:
                return 1
            if moves == 0:
                return 0
            if (i, j, moves) in memo:
                return memo[(i, j, moves)]
            
            count = 0
            for di, dj in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                count = (count + dfs(i + di, j + dj, moves - 1)) % MOD
            
            memo[(i, j, moves)] = count
            return count
        
        return dfs(startRow, startColumn, maxMove)
```

## 复杂度分析

- **时间复杂度**：O(maxMove × m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **状态定义**：dp[k][i][j] 表示 k 步到达 (i,j) 的路径数
2. **边界处理**：移出边界时累加到结果
3. **取模**：每次计算都要取模
4. **滚动数组**：只需要前一步的状态
