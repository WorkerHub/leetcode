## 题目描述

假设有从 1 到 n 的 n 个整数。用这些整数构造一个数组 `perm`（下标从 1 开始），使得对于每个 `i`（1 <= i <= n），满足以下条件之一：
- `perm[i]` 能被 `i` 整除
- `i` 能被 `perm[i]` 整除

返回可以构造的美丽排列的数量。

## Python 代码实现

```python
class Solution:
    def countArrangement(self, n: int) -> int:
        """回溯"""
        def backtrack(index, visited):
            if index > n:
                return 1
            
            count = 0
            for num in range(1, n + 1):
                if not visited[num] and (num % index == 0 or index % num == 0):
                    visited[num] = True
                    count += backtrack(index + 1, visited)
                    visited[num] = False
            
            return count
        
        return backtrack(1, [False] * (n + 1))
```

## 复杂度分析

- **时间复杂度**：O(n!)
- **空间复杂度**：O(n)
