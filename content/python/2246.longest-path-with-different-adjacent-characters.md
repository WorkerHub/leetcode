## 题目描述

给你一棵 **树**（一个无环连通图），`n` 个节点（编号 0 到 n-1），根节点是 0。

给你一个长度为 `n-1` 的整数数组 `parent`，`parent[i]` 是节点 `i` 的父节点（节点 0 的父节点是 -1）。

另给你一个字符串 `s`，`s[i]` 是节点 `i` 的字符。

返回路径上相邻节点字符**不同**的**最长路径**的长度（节点数）。

**示例 1：**
```
输入：parent = [-1,0,0,1,1,2], s = "abacbe"
输出：3
解释：路径 3->1->0 或 3->1->4，节点字符不同，长度3。
```

**示例 2：**
```
输入：parent = [-1,0,0,0], s = "aabc"
输出：3
```

## 解题思路

**树形 DP（DFS）：**

对每个节点 `u`，递归计算其所有子节点的"以子节点为起点、字符各不相同的最长链"，合并两条最长链（加上节点 u 本身）作为答案。

具体：
- `dfs(u)` 返回"从 u 出发向下，相邻字符不同的最长链长度"。
- 对 u 的每个子节点 v，若 `s[v] != s[u]`，则 `dfs(v) + 1` 是以 u 为起点通过 v 的链长。
- 取最长的两条链相加（加上 u 本身）更新答案。

## 代码实现

### 方法一：树形 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestPath(self, parent: List[int], s: str) -> int:
        n = len(parent)
        # 建邻接表（子节点列表）
        children = defaultdict(list)
        for i in range(1, n):
            children[parent[i]].append(i)

        self.ans = 1

        def dfs(u: int) -> int:
            """返回从 u 出发，路径上相邻字符不同的最长链（包含 u 自身）"""
            # 保存最长和次长
            top1 = top2 = 0

            for v in children[u]:
                down = dfs(v)
                if s[v] == s[u]:
                    continue  # 字符相同，不能延伸
                if down > top1:
                    top2 = top1
                    top1 = down
                elif down > top2:
                    top2 = down

            # 更新全局答案：通过 u 连接两条链
            self.ans = max(self.ans, top1 + top2 + 1)
            return top1 + 1  # 返回最长单链

        dfs(0)
        return self.ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestPath(self, parent: List[int], s: str) -> int:
        n = len(parent)
        children = defaultdict(list)
        for i in range(1, n):
            children[parent[i]].append(i)

        # 拓扑序处理（从叶子到根）
        # 用数组记录每个节点向下的最长链
        dp = [1] * n  # dp[u] = 从 u 出发最长合法链
        ans = 1

        # 按父节点关系，从叶子到根处理（拓扑序）
        # 计算入度（作为叶子：入度=0）
        indegree = [0] * n
        for i in range(1, n):
            indegree[parent[i]] += 1

        from collections import deque
        # 从叶子开始
        queue = deque(i for i in range(n) if indegree[i] == 0)
        # 记录每个节点的两条最长链
        best = [[0, 0] for _ in range(n)]  # [top1, top2]

        while queue:
            v = queue.popleft()
            p = parent[v]
            if p == -1:
                continue
            chain = dp[v]
            if s[v] != s[p]:
                b = best[p]
                if chain > b[0]:
                    b[1] = b[0]
                    b[0] = chain
                elif chain > b[1]:
                    b[1] = chain
            indegree[p] -= 1
            if indegree[p] == 0:
                dp[p] = best[p][0] + 1
                ans = max(ans, best[p][0] + best[p][1] + 1)
                queue.append(p)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(n)，递归栈或队列。

## 关键点总结

1. 树形 DP：对每个节点，合并最长的两条来自不同子节点的链。
2. 只有子节点字符与当前节点字符不同，才能延伸路径。
3. 答案在所有节点的"双向最长链"中取最大。

## 易错点

- 相邻字符相同时不能延伸（直接跳过），但仍需递归处理子节点（子节点的子树可能有合法路径）。
- 返回值是最长单链（top1 + 1），但更新答案时是 top1 + top2 + 1（通过当前节点连接两个方向）。
