## 题目描述

给你一个整数数组 `nums` 和一个整数 `threshold`。

找到长度为 `k` 的子数组，使得子数组中**每一个**元素都大于 `threshold / k`。

返回任意一个满足条件的子数组的**左端点**下标，如果不存在则返回 `-1`。

**示例 1：**
```
输入：nums = [1,3,4,3,1], threshold = 6
输出：3
解释：子数组 [3,1] 不行，[3,4,3]：每个元素 > 6/3=2，满足条件，左端点为 1。
```

**示例 2：**
```
输入：nums = [6,5,6,5,8], threshold = 7
输出：1
解释：子数组 [5,6,5]：每个元素 > 7/3≈2.33，满足，左端点为 1。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], threshold <= 10^9`

## 解题思路

**单调栈思路：**
对于长度为 k 的子数组，要求每个元素 > `threshold / k`，即 `k > threshold / min(subarray)`，即 `k * min > threshold`。

枚举子数组的最小值：用单调栈，对每个位置 `i` 找到以 `nums[i]` 为最小值的最长子数组范围 `[left, right]`，子数组长度最大为 `right - left - 1`。若此长度满足 `length * nums[i] > threshold`，则找到答案。

**并查集思路：**
按值从大到小加入元素，合并相邻元素，当某个连通分量大小满足条件时返回。

## 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def validSubarraySize(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        # 用单调栈找每个元素作为最小值的范围 [left+1, right-1]
        left = [-1] * n   # 左边第一个比 nums[i] 小的位置
        right = [n] * n   # 右边第一个比 nums[i] 小的位置
        
        stack = []
        # 求 left
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)
        
        stack = []
        # 求 right
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)
        
        for i in range(n):
            # 以 nums[i] 为最小值的最大子数组长度
            k = right[i] - left[i] - 1
            if k * nums[i] > threshold:
                # 合法子数组左端点（以 i 为中心，长度至少为 ceil(threshold/nums[i])+1）
                # 找任意满足条件的左端点
                return left[i] + 1
        
        return -1
```

### 方法二：并查集（从大到小插入）

```python
from typing import List

class Solution:
    def validSubarraySize(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        parent = list(range(n + 1))  # n 作为虚拟节点
        size = [0] * (n + 1)         # 连通分量大小（不含虚拟节点）

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            rx, ry = find(x), find(y)
            if rx == ry:
                return
            parent[ry] = rx
            size[rx] += size[ry]

        # 按值从大到小排序后依次加入
        order = sorted(range(n), key=lambda i: -nums[i])
        added = [False] * n

        for i in order:
            added[i] = True
            size[find(i)] = 1  # 初始化为 1
            # 合并左邻
            if i > 0 and added[i - 1]:
                union(i, i - 1)
            # 合并右邻
            if i < n - 1 and added[i + 1]:
                union(i, i + 1)
            
            # 当前连通分量大小
            k = size[find(i)]
            if k * nums[i] > threshold:
                # 找该连通分量的左端点
                root = find(i)
                # 遍历找左端点（优化：可在合并时记录左端点）
                for j in range(n):
                    if find(j) == root:
                        return j
        
        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单调栈 | O(n) | O(n) |
| 并查集 | O(n log n) | O(n) |

## 关键点总结

1. 条件等价于：存在长度为 k 的子数组，其最小值 > `threshold / k`。
2. 单调栈对每个元素求以其为最小值的最长子数组范围，O(n) 完成。
3. 若最长范围满足条件，则输出左端点。

## 易错点

- 单调栈中使用严格小于（`>= nums[i]` 时弹出）处理相等元素。
- 答案是子数组左端点，要根据 `left[i] + 1` 返回。
