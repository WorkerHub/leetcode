## 题目描述

给你一个链表的头节点 `head`，删除链表的**中间节点**，并返回修改后的链表的头节点。

**中间节点定义：** 对于长度为 `n` 的链表，中间节点是下标为 `⌊n/2⌋` 的节点（下标从 0 开始）。

**示例：**
```
输入：head = [1,3,4,7,1,2,6]
输出：[1,3,4,1,2,6]
解释：长度 7，中间节点下标 3（值 7），删除后得到 [1,3,4,1,2,6]
```

**提示：**
- 链表中节点数目 `[1, 10^5]`
- `1 <= Node.val <= 10^5`

## 解题思路

**快慢指针：**

- 快指针每次走两步，慢指针每次走一步
- 当快指针到达末尾时，慢指针在中间节点
- 需要找到中间节点的**前驱**才能删除，所以需要额外处理

**关键：** 用前驱指针 `prev` 跟踪慢指针的前一个节点。

### 方法一：正确实现

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return None

        # 使用 dummy 节点简化操作
        dummy = ListNode(0, head)
        slow = dummy  # slow 指向中间节点的前驱
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # slow.next 是中间节点
        slow.next = slow.next.next

        return dummy.next
```

### 方法二：计算长度后删除

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return None

        # 计算长度
        n = 0
        cur = head
        while cur:
            n += 1
            cur = cur.next

        # 找到中间节点的前驱（下标 n//2 - 1）
        mid = n // 2
        cur = head
        for _ in range(mid - 1):
            cur = cur.next
        cur.next = cur.next.next

        return head
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 快慢指针 | O(n) | O(1) |
| 计算长度 | O(n) | O(1) |

## 关键点总结

1. 使用 dummy 节点 + 快慢指针，slow 从 dummy 出发，最终停在中间节点的前驱
2. `fast` 从 `head` 出发，每次走两步；`slow` 每次走一步
3. 当 `fast` 无法再走两步时，`slow` 指向中间节点的前驱

## 易错点

- 只有一个节点时，删除后返回 `None`
- `slow` 必须从 dummy 出发（而非 head），才能得到前驱
- 使用 dummy 节点避免头节点被删除的边界情况
