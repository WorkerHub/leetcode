## 题目描述

给你一个算术表达式的**后缀表示法**（逆波兰表达式），请你设计一个将其转化为表达式树的算法，并实现一个 `evaluate()` 函数用于计算该树的值。

表达式树是一棵二叉树，叶节点是操作数，非叶节点是运算符（`+`、`-`、`*`、`/`）。

实现接口：
- `Node` 类的 `evaluate()` 方法，返回节点代表的值
- `TreeBuilder` 的 `buildTree(postfix)` 方法，构建表达式树并返回根节点

**示例：**
```
输入：["3","4","+","2","*","7","/"]
输出：2
解释：((3+4)*2)/7 = 2
```

## 解题思路

**构建表达式树（后缀表达式 -> 树）：**
1. 用栈处理后缀表达式
2. 遇到数字：创建叶节点，压栈
3. 遇到运算符：弹出两个节点作为右子树和左子树，创建运算符节点，压栈

**求值（evaluate）：**
- 叶节点：直接返回数字值
- 非叶节点：递归计算左右子树的值，然后应用运算符

## 代码实现

### 方法一：栈 + 递归求值（推荐）

```python
from abc import ABC, abstractmethod
from typing import List

class Node(ABC):
    @abstractmethod
    def evaluate(self) -> int:
        pass

# 数字节点（叶节点）
class NumNode(Node):
    def __init__(self, val: str):
        self.val = int(val)
    
    def evaluate(self) -> int:
        return self.val

# 运算符节点（非叶节点）
class OpNode(Node):
    def __init__(self, op: str, left: Node, right: Node):
        self.op = op
        self.left = left
        self.right = right
    
    def evaluate(self) -> int:
        left_val = self.left.evaluate()
        right_val = self.right.evaluate()
        
        if self.op == '+':
            return left_val + right_val
        elif self.op == '-':
            return left_val - right_val
        elif self.op == '*':
            return left_val * right_val
        elif self.op == '/':
            return int(left_val / right_val)  # 向零截断
        return 0

class TreeBuilder:
    def buildTree(self, postfix: List[str]) -> Node:
        stack = []
        ops = {'+', '-', '*', '/'}
        
        for token in postfix:
            if token not in ops:
                # 数字，创建叶节点
                stack.append(NumNode(token))
            else:
                # 运算符，弹出两个操作数
                right = stack.pop()  # 先弹出的是右操作数
                left = stack.pop()
                stack.append(OpNode(token, left, right))
        
        return stack[0]
```

### 方法二：统一节点类

```python
from typing import List, Optional

class Node:
    def __init__(self, val: str, left=None, right=None):
        self.val = val
        self.left = left   # 左子节点
        self.right = right  # 右子节点
    
    def evaluate(self) -> int:
        # 叶节点（数字）
        if self.left is None and self.right is None:
            return int(self.val)
        
        left_val = self.left.evaluate()
        right_val = self.right.evaluate()
        
        if self.val == '+':
            return left_val + right_val
        elif self.val == '-':
            return left_val - right_val
        elif self.val == '*':
            return left_val * right_val
        elif self.val == '/':
            return int(left_val / right_val)

class TreeBuilder:
    def buildTree(self, postfix: List[str]) -> Node:
        stack = []
        ops = {'+', '-', '*', '/'}
        
        for token in postfix:
            node = Node(token)
            if token in ops:
                node.right = stack.pop()
                node.left = stack.pop()
            stack.append(node)
        
        return stack[0]
```

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| buildTree | O(n) | O(n) |
| evaluate | O(n) | O(h) |

n 为表达式中的 token 数，h 为树的高度。

## 关键点总结

1. 后缀表达式用栈构建表达式树，遇到运算符时弹出两个操作数
2. 注意右操作数先弹出（后缀表达式中右操作数更后进入栈）
3. 递归求值：叶节点返回数字，非叶节点递归计算后应用运算符
4. 除法用 `int()` 而不是 `//`（处理负数的截断方向不同）

## 易错点

- 弹栈顺序：先 `pop` 得到**右**操作数，再 `pop` 得到**左**操作数
- 除法需要向零截断（`int(a/b)`），Python 的 `//` 是向下取整，对负数结果不同
- 运算符集合的判断要在字符串集合中查找，不能只判断是否为数字
