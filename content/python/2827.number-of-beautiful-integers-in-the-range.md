## 题目描述

给你正整数 `low`、`high` 和 `k`。

如果一个整数满足以下两个条件，则称其为**美丽整数**：
1. 奇数位数字数量等于偶数位数字数量
2. 整数能被 `k` 整除

返回区间 `[low, high]` 内美丽整数的数量。

**示例 1：**
```
输入：low = 10, high = 20, k = 3
输出：2
解释：[10,20] 中整除 3 且奇数位数=偶数位数的有：12（1 奇 1 偶），18（1 奇 1 偶）
```

**示例 2：**
```
输入：low = 1, high = 10, k = 1
输出：1
解释：只有 10 满足条件（1 奇 1 偶，且能整除 1）
```

**提示：**
- `0 < low <= high <= 10^9`
- `0 < k <= 20`

## 解题思路

**数位 DP（Digit DP）：**

`f(n, k)` = [1, n] 中美丽整数的数量，答案 = `f(high, k) - f(low-1, k)`。

**DP 状态：**
- `pos`：当前填第几位
- `remainder`：当前数 mod k 的余数
- `balance`：奇数位数 - 偶数位数（可以为负数，偏移存储）
- `tight`：是否紧贴上界
- `started`：是否已开始（是否有前导零）

**终止条件：** `pos == n` 时，若 `remainder == 0` 且 `balance == 0`（奇偶位数相等），且 `started == True`，计数 1。

## Python 代码实现

### 方法一：数位 DP + 记忆化搜索（推荐）

```python
from functools import lru_cache

class Solution:
    def numberOfBeautifulIntegers(self, low: int, high: int, k: int) -> int:

        def count(limit: int) -> int:
            s = str(limit)
            n = len(s)

            @lru_cache(maxsize=None)
            def dp(pos: int, rem: int, balance: int, tight: bool, started: bool) -> int:
                """
                pos: 当前位置
                rem: 当前余数 mod k
                balance: 奇数位数 - 偶数位数（偶数位到奇数位的增加量）
                tight: 是否紧贴上界
                started: 是否已开始填数字
                """
                if pos == n:
                    if not started:
                        return 0
                    return 1 if rem == 0 and balance == 0 else 0

                hi = int(s[pos]) if tight else 9
                result = 0

                for d in range(0, hi + 1):
                    if d == 0 and not started:
                        # 前导零
                        result += dp(pos + 1, 0, 0, tight and d == hi, False)
                    else:
                        # 奇数位数字：d 为奇数；偶数位数字：d 为偶数
                        is_odd_digit = 1 if d % 2 == 1 else 0
                        new_balance = balance + (1 if is_odd_digit else -1)
                        new_rem = (rem * 10 + d) % k
                        result += dp(pos + 1, new_rem, new_balance, tight and d == hi, True)

                return result

            res = dp(0, 0, 0, True, False)
            dp.cache_clear()
            return res

        return count(high) - count(low - 1)
```

### 方法二：更清晰的注释版

```python
from functools import lru_cache

class Solution:
    def numberOfBeautifulIntegers(self, low: int, high: int, k: int) -> int:

        def solve(num: int) -> int:
            digits = list(map(int, str(num)))
            n = len(digits)

            @lru_cache(maxsize=None)
            def dfs(i: int, rem: int, odd_cnt: int, even_cnt: int,
                    is_tight: bool, has_started: bool) -> int:
                if i == n:
                    if not has_started:
                        return 0
                    # 奇数位数 == 偶数位数，且整除 k
                    return 1 if odd_cnt == even_cnt and rem == 0 else 0

                limit = digits[i] if is_tight else 9
                total = 0
                for d in range(0, limit + 1):
                    if d == 0 and not has_started:
                        total += dfs(i + 1, 0, 0, 0, is_tight and d == limit, False)
                    else:
                        new_odd = odd_cnt + (1 if d % 2 == 1 else 0)
                        new_even = even_cnt + (1 if d % 2 == 0 else 0)
                        new_rem = (rem * 10 + d) % k
                        total += dfs(i + 1, new_rem, new_odd, new_even,
                                     is_tight and d == limit, True)
                return total

            res = dfs(0, 0, 0, 0, True, False)
            dfs.cache_clear()
            return res

        return solve(high) - solve(low - 1)
```

## 复杂度分析

- 时间复杂度：O(10 × n × k × 2n × 2 × 2)，其中 n <= 10（10^9 最多 10 位），k <= 20
  - 实际状态数：O(n × k × n)，n <= 10，k <= 20，balance 范围 [-n, n]
- 空间复杂度：O(n × k × n)

## 关键点总结

1. 数位 DP 四要素：位置、余数、奇偶位数差、tight/started 标志
2. `f(high) - f(low-1)` 计算区间内满足条件的数
3. 前导零需要单独处理（不算入奇偶位数统计）
4. balance（奇数位-偶数位）表示平衡度，0 表示相等

## 易错点

1. 前导零的 balance 不应计入（0 是偶数，前导零会影响统计）
2. 注意 k 最大 20，余数状态范围为 [0, k-1]
3. 两次调用 dp 之间需要清空缓存
