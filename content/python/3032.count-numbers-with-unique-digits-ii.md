## 题目描述

给你两个整数 `a` 和 `b`，返回 `[a, b]` 范围内各位数字互不相同的整数个数。

**示例 1：**
```
输入：a = 1, b = 20
输出：19
解释：11 不满足（有重复数字），其余都满足
```

**示例 2：**
```
输入：a = 9, b = 25
输出：15
```

**提示：**
- `1 <= a <= b <= 1000`

## 解题思路

由于 `b <= 1000`，数据范围小，可以直接枚举 `[a, b]` 中每个数，判断其各位是否互不相同。

也可以用数位 DP 计算 `f(b) - f(a-1)`，其中 `f(n)` 是 `[1, n]` 中各位互不相同的数的个数。

## Python 代码实现

### 方法一：直接枚举（推荐，因范围小）

```python
class Solution:
    def numberCount(self, a: int, b: int) -> int:
        def has_unique_digits(n: int) -> bool:
            digits = str(n)
            return len(digits) == len(set(digits))

        return sum(1 for n in range(a, b + 1) if has_unique_digits(n))
```

### 方法二：数位 DP（通用解法）

```python
class Solution:
    def numberCount(self, a: int, b: int) -> int:
        def count_up_to(n: int) -> int:
            """计算 [1, n] 中各位互不相同的整数个数"""
            digits = list(map(int, str(n)))
            k = len(digits)
            result = 0

            # 位数小于 k 的数（1 到 k-1 位）
            # 1 位：9 个（1-9）
            # 2 位：9 * 9 = 81 个
            # 3 位：9 * 9 * 8 = 648 个
            # ...
            for length in range(1, k):
                if length == 1:
                    result += 9
                else:
                    ways = 9  # 首位：1-9
                    for i in range(1, length):
                        ways *= (10 - i)
                    result += ways

            # 恰好 k 位且 <= n 的数
            used = set()
            for i, d in enumerate(digits):
                lo = 1 if i == 0 else 0
                for x in range(lo, d):
                    if x not in used:
                        # 前 i 位确定了，后面可以自由选择
                        remaining = k - i - 1
                        ways = 1
                        for j in range(remaining):
                            ways *= (10 - i - 1 - j)
                        result += ways

                if d in used:
                    break  # 无法继续（d 重复）
                used.add(d)
            else:
                # n 本身满足条件
                result += 1

            return result

        return count_up_to(b) - count_up_to(a - 1)
```

## 复杂度分析

- 方法一：O(b - a)，直接枚举，b <= 1000 时为 O(1000)
- 方法二：O(log n)，数位 DP
- 空间复杂度：O(log n)

## 关键点总结

1. 各位互不相同：转字符串后判断长度与集合大小是否相等
2. 数据范围小，直接枚举是最简单的方法
3. 数位 DP 是通用方法，适合大范围

## 易错点

1. 数字 0 的各位数字是 `{0}`，满足互不相同（但题目 `a >= 1`）
2. 枚举时注意包含端点 `a` 和 `b`
