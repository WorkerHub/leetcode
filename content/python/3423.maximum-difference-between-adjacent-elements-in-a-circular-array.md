## 题目描述

给你一个**循环**数组 `nums`，返回相邻元素之间差的绝对值的最大值。

在循环数组中，最后一个元素和第一个元素相邻。

**示例 1：**

```
输入：nums = [1,2,4]
输出：3
解释：相邻差：|1-2|=1, |2-4|=2, |4-1|=3（循环），最大值为 3
```

**示例 2：**

```
输入：nums = [-5,-10,-5]
输出：5
解释：|-5-(-10)|=5, |-10-(-5)|=5, |-5-(-5)|=0，最大值为 5
```

**提示：**
- `2 <= nums.length <= 100`
- `-100 <= nums[i] <= 100`

## 解题思路

遍历所有相邻对，包括 `(nums[n-1], nums[0])` 这一对（循环边），取绝对差的最大值。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def maxAdjacentDistance(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            # 相邻元素（循环：最后一个与第一个相邻）
            diff = abs(nums[i] - nums[(i + 1) % n])
            ans = max(ans, diff)

        return ans
```

### 方法二：使用 zip 和循环

```python
from typing import List

class Solution:
    def maxAdjacentDistance(self, nums: List[int]) -> int:
        # 将 nums 和其循环移位版本 zip
        # 循环移位：nums[1], nums[2], ..., nums[0]
        shifted = nums[1:] + [nums[0]]
        return max(abs(a - b) for a, b in zip(nums, shifted))
```

### 方法三：一行写法

```python
from typing import List

class Solution:
    def maxAdjacentDistance(self, nums: List[int]) -> int:
        n = len(nums)
        return max(abs(nums[i] - nums[(i + 1) % n]) for i in range(n))
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 循环数组：最后一个元素和第一个元素也是相邻的
2. 使用 `(i + 1) % n` 处理循环边界
3. 取所有相邻差绝对值的最大值

## 易错点

1. 忘记处理循环边：`nums[n-1]` 和 `nums[0]` 也是相邻的
2. 注意是绝对差，不是差值（可能为负）
