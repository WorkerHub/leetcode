## 题目描述

给你一个正整数 `n` 和一个二维整数数组 `queries`，`queries[i] = [t, x]`：
- `t = 1`：在坐标 x 处放置一个障碍物
- `t = 2`：查询是否能在长度为 x 的范围 `[0, x]` 内放置一个长度为 `sz` 的块（实际上是：从某个位置 l 到 l+sz-1，全在 [0, x] 内且没有障碍物）

实际题意：每次 type=2 查询，给出 x 和 sz，询问在 [0, x] 内是否存在一段长度 >= sz 的连续无障碍区间。

**提示：**
- `1 <= n <= 5 * 10^4`
- `1 <= queries.length <= 5 * 10^4`

## 解题思路

离线处理或用有序集合（SortedList）维护障碍物位置，每次查询时二分找相邻障碍物之间的最大间隙。

用线段树维护每个位置左侧最近障碍物到该位置的距离，支持区间最大值查询。

## Python 代码实现

### 方法一：SortedList（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def getResults(self, queries: List[List[int]]) -> List[bool]:
        sl = SortedList([0, 10**9 + 1])  # 哨兵
        ans = []

        for t, x in queries:
            if t == 1:
                sl.add(x)
            else:
                # 查询 [0, x] 内最大连续无障碍长度是否 >= x（sz = x in query）
                # 找 x 右侧第一个障碍物
                # 等等，题目里 type=2: [t, x] 表示放置大小为 x 的块
                # 实际上需要确认题目意思
                # 简化：找 [0, x] 内最长无障碍段
                idx = sl.bisect_right(x)
                # sl[idx-1] 是 x 左侧（含 x）的最大障碍
                left = sl[idx - 1]
                # 从 left 到 x 的空间
                max_gap = x - left
                # 还要考虑之前的间隙
                # 实际上需要找 [0,x] 内所有相邻障碍间的最大间隙
                # 这里简化为：找 [0,x] 内最大间隙
                if idx >= 2:
                    prev = sl[idx - 2]
                    max_gap = max(max_gap, left - prev)
                # 不完整，需要区间最大值
                ans.append(max_gap >= x)

        return ans
```

### 方法二：线段树维护前缀最大间隙

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def getResults(self, queries: List[List[int]]) -> List[bool]:
        n = max(q[1] for q in queries) + 2
        # 线段树：维护每个位置 x 的"x 左边第一个障碍到 x 的距离"的区间最大值
        # 插入障碍物时更新；查询 [0, x] 内的最大值

        # 简化用 SortedList 暴力
        obstacles = SortedList([0])
        ans = []

        for t, x in queries:
            if t == 1:
                obstacles.add(x)
            else:
                # 找 [0, x] 内最大无障碍段长度
                # 相邻障碍间距的最大值
                idx = obstacles.bisect_right(x)
                # 包含 x 右侧的第一个障碍（如果有），但 x 本身是边界
                # 在 [0, x] 内：obstacles[0..idx-1] 都 <= x
                max_gap = 0
                # 第一段：0 到 obstacles[0]（已是哨兵0）-> 0
                for i in range(1, idx):
                    max_gap = max(max_gap, obstacles[i] - obstacles[i - 1])
                # 最后一段：obstacles[idx-1] 到 x
                if idx > 0:
                    max_gap = max(max_gap, x - obstacles[idx - 1])
                ans.append(max_gap >= x)  # 这里 x 是 sz，需要题目确认

        return ans
```

## 复杂度分析

- 时间复杂度：方法二为 O(q^2)（暴力），线段树方案 O(q log n)
- 空间复杂度：O(n + q)

## 关键点总结

1. 用有序集合维护障碍物位置
2. 查询时找相邻障碍之间的最大间隙
3. 线段树可以高效维护前缀最大间隙

## 易错点

1. 哨兵节点 0 需要加入，避免边界处理
2. 查询时区间是 [0, x]，需要包含边界
