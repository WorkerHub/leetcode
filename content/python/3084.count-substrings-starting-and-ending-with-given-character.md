## 题目描述

给你一个字符串 `s` 和字符 `c`，统计以 `c` 开头且以 `c` 结尾的子字符串数量。

**示例 1：**
```
输入：s = "abada", c = "a"
输出：6
解释：a 出现在位置 0, 2, 4，C(3,2) + 3 = 3 + 3 = 6
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母
- `c` 是单字符小写英文字母

## 解题思路

统计 `s` 中字符 `c` 的出现次数 `cnt`。

以 `c` 开头且以 `c` 结尾的子字符串：
- 单个字符 `c`：`cnt` 个
- 两端均为 `c` 的子字符串（长度 >= 2）：从 `cnt` 个 `c` 的位置中选 2 个，C(cnt, 2) = cnt*(cnt-1)//2 个

总数 = `cnt + cnt*(cnt-1)//2 = cnt*(cnt+1)//2`。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def countSubstrings(self, s: str, c: str) -> int:
        cnt = s.count(c)
        return cnt * (cnt + 1) // 2
```

### 方法二：枚举位置

```python
class Solution:
    def countSubstrings(self, s: str, c: str) -> int:
        positions = [i for i, ch in enumerate(s) if ch == c]
        cnt = len(positions)
        # 任选两个位置（包含相同位置即单字符子串）
        return cnt * (cnt + 1) // 2
```

## 复杂度分析

- 时间复杂度：O(n)，统计字符 c 的出现次数
- 空间复杂度：O(1)

## 关键点总结

1. 只需统计字符 c 的出现次数 cnt
2. 总子字符串数 = 从 cnt 个位置中选 1 或 2 个的方案数 = C(cnt,1) + C(cnt,2) = cnt*(cnt+1)/2

## 易错点

1. 单字符子字符串（开头 = 结尾）也算
2. 选两个位置时不需要连续，只要起止位置都是 c 即可
