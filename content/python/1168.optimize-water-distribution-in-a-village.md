## 题目描述

村里有 `n` 栋房子。我们希望通过建造水井和铺设管道来为所有房子供水。

对于每栋房子 `i`，我们可以直接在内部建造一口水井，花费为 `wells[i]`，或者从另一口井铺设管道引水。每条管道的铺设成本由数组 `pipes` 给出，其中每个 `pipes[i] = [house1, house2, cost]` 表示用管道连接 `house1` 和 `house2` 的成本为 `cost`。连接是双向的。

找出为所有房子供水的最小总成本。

示例：

```
输入：n = 3, wells = [1,2,2], pipes = [[1,2,1],[2,3,1]]
输出：3
解释：
最佳方案是：
- 在第一栋房子建井，花费 1
- 从第一栋房子到第二栋房子铺管道，花费 1
- 从第二栋房子到第三栋房子铺管道，花费 1
总成本为 1 + 1 + 1 = 3
```

## 解题思路

这是一道最小生成树的变形题目，核心是将建井问题转化为图的边。

**关键观察：**

1. 可以引入虚拟节点 0，代表"水源"
2. 将每栋房子建井的成本转化为从虚拟节点 0 到该房子的边
3. 问题转化为标准的最小生成树问题：连接所有节点到虚拟水源的最小成本

**算法：Kruskal 算法**

使用并查集+贪心，选择成本最小的边进行连接。

## Python 代码实现

### 方法一：Kruskal + 并查集（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
        return True

class Solution:
    def minCostToSupplyWater(self, n: int, wells: List[int], pipes: List[List[int]]) -> int:
        """
        Kruskal 最小生成树算法
        
        时间复杂度：O((n+m) log(n+m))
        空间复杂度：O(n)
        """
        # 构建边集：添加虚拟节点 0 到每栋房子的边（建井成本）
        edges = []
        for i, cost in enumerate(wells):
            edges.append((cost, 0, i + 1))  # (成本, 虚拟节点, 房子编号)
        
        # 添加管道边
        for house1, house2, cost in pipes:
            edges.append((cost, house1, house2))
        
        # 按成本排序
        edges.sort()
        
        # 并查集：n+1 个节点（0 是虚拟节点，1~n 是房子）
        uf = UnionFind(n + 1)
        total_cost = 0
        edges_used = 0
        
        # Kruskal 算法：选择最小边
        for cost, u, v in edges:
            if uf.union(u, v):
                total_cost += cost
                edges_used += 1
                # 最小生成树有 n 条边（连接 n 个房子到虚拟节点）
                if edges_used == n:
                    break
        
        return total_cost
```

### 方法二：Prim 算法

```python
from typing import List
import heapq

class Solution:
    def minCostToSupplyWater(self, n: int, wells: List[int], pipes: List[List[int]]) -> int:
        """
        Prim 最小生成树算法
        
        时间复杂度：O((n+m) log n)
        空间复杂度：O(n+m)
        """
        # 构建邻接表
        graph = [[] for _ in range(n + 1)]
        
        # 添加虚拟节点 0 到每栋房子的边
        for i, cost in enumerate(wells):
            graph[0].append((cost, i + 1))
            graph[i + 1].append((cost, 0))
        
        # 添加管道边
        for house1, house2, cost in pipes:
            graph[house1].append((cost, house2))
            graph[house2].append((cost, house1))
        
        # Prim 算法
        visited = set([0])
        min_heap = graph[0][:]  # 从虚拟节点开始
        heapq.heapify(min_heap)
        total_cost = 0
        
        while len(visited) <= n and min_heap:
            cost, house = heapq.heappop(min_heap)
            if house in visited:
                continue
            
            visited.add(house)
            total_cost += cost
            
            # 添加新节点的邻边
            for next_cost, next_house in graph[house]:
                if next_house not in visited:
                    heapq.heappush(min_heap, (next_cost, next_house))
        
        return total_cost
```

## 复杂度分析

**Kruskal 算法：**
- 时间复杂度：`O((n+m) log(n+m))`，排序边
- 空间复杂度：`O(n)`，并查集

**Prim 算法：**
- 时间复杂度：`O((n+m) log n)`，堆操作
- 空间复杂度：`O(n+m)`，邻接表和堆

## 关键点总结

1. **虚拟节点技巧**：将建井转化为连接虚拟节点的边
2. **最小生成树**：标准的 Kruskal 或 Prim 算法
3. **并查集优化**：路径压缩和按秩合并
4. **贪心策略**：每次选择最小成本的边

## 易错点

1. 忘记添加虚拟节点
2. 房子编号从 1 开始，要注意索引转换
3. 边数判断错误，应该是 n 条边而不是 n-1
