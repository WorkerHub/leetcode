## 题目描述

树的直径是指树中任意两个节点之间最长路径上的边数。

给定一个有 n 个节点的无向树，节点编号从 0 到 n - 1。给你一个二维数组 edges，其中 edges.length == n - 1，edges[i] = [ai, bi] 表示树中节点 ai 和 bi 之间存在一条无向边。

请你返回这棵树的直径。

**示例 1：**

```
输入：edges = [[0,1],[0,2]]
输出：2
解释：最长路径是路径 1 - 0 - 2
```

**示例 2：**

```
输入：edges = [[0,1],[1,2],[2,3],[1,4],[4,5]]
输出：4
解释：最长路径是路径 3 - 2 - 1 - 4 - 5
```

**提示：**

- `0 <= edges.length < 10^4`
- `edges[i][0] != edges[i][1]`
- `0 <= edges[i][j] <= edges.length`
- 给定的边会形成一棵无向树

## 解题思路

树的直径问题是一道经典的树形问题，有多种解决方案。核心思想是找到树中距离最远的两个节点。

### 核心观察

1. 树的直径一定是某个节点到另一个节点的最长路径
2. 关键发现：从任意节点出发，找到距离它最远的节点 A，然后从节点 A 出发找到距离它最远的节点 B，则 A 到 B 的路径就是树的直径

### 两次 BFS/DFS 方法（推荐）

这是最经典的解法，分为两个步骤：

1. 第一次搜索：从任意节点（通常选择节点 0）开始 BFS 或 DFS，找到距离它最远的节点（记为节点 A）
2. 第二次搜索：从节点 A 开始 BFS 或 DFS，找到距离它最远的节点（记为节点 B），此时的距离就是树的直径

**为什么这样做是正确的？**

- 假设树的直径两端是节点 u 和 v
- 从任意节点 s 开始 DFS，找到的最远节点一定是直径的某一端（u 或 v）
- 再从这一端出发，找到的最远节点必然是直径的另一端
- 这是因为树中任意两点间只有唯一路径

### 一次 DFS 方法

在 DFS 的过程中，同时记录：
1. 从当前节点向下的最长路径
2. 从当前节点向下的次长路径
3. 两者之和就是经过当前节点的最长路径

不断更新全局最大值即可。

## Python 代码实现

### 方法一：两次 BFS（推荐，思路清晰）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        # 构建邻接表
        if not edges:
            return 0
        
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # BFS 找到从起点最远的节点
        def bfs(start: int) -> tuple:
            visited = {start}
            queue = deque([(start, 0)])  # (节点, 距离)
            farthest_node = start
            max_distance = 0
            
            while queue:
                node, dist = queue.popleft()
                
                # 更新最远节点
                if dist > max_distance:
                    max_distance = dist
                    farthest_node = node
                
                # 遍历相邻节点
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append((neighbor, dist + 1))
            
            return farthest_node, max_distance
        
        # 第一次 BFS：从节点 0 找到最远的节点
        farthest_from_0, _ = bfs(0)
        
        # 第二次 BFS：从最远节点找到树的直径
        _, diameter = bfs(farthest_from_0)
        
        return diameter
```

### 方法二：两次 DFS（空间优化）

```python
from typing import List
from collections import defaultdict

class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        if not edges:
            return 0
        
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # DFS 找到从起点最远的节点
        def dfs(start: int) -> tuple:
            visited = {start}
            max_distance = 0
            farthest_node = start
            
            def helper(node: int, dist: int):
                nonlocal max_distance, farthest_node
                
                # 更新最远节点
                if dist > max_distance:
                    max_distance = dist
                    farthest_node = node
                
                # 递归遍历相邻节点
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        helper(neighbor, dist + 1)
            
            helper(start, 0)
            return farthest_node, max_distance
        
        # 第一次 DFS：从节点 0 找到最远的节点
        farthest_from_0, _ = dfs(0)
        
        # 第二次 DFS：从最远节点找到树的直径
        _, diameter = dfs(farthest_from_0)
        
        return diameter
```

### 方法三：一次 DFS（最优解，代码稍复杂）

```python
from typing import List
from collections import defaultdict

class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        if not edges:
            return 0
        
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        self.diameter = 0
        
        # DFS 返回从当前节点向下的最长路径
        def dfs(node: int, parent: int) -> int:
            # 记录最长和次长路径
            max1 = max2 = 0
            
            for neighbor in graph[node]:
                if neighbor == parent:
                    continue
                
                # 递归获取子树的最长路径
                depth = dfs(neighbor, node)
                
                # 更新最长和次长路径
                if depth > max1:
                    max2 = max1
                    max1 = depth
                elif depth > max2:
                    max2 = depth
            
            # 更新直径：经过当前节点的最长路径 = 最长 + 次长
            self.diameter = max(self.diameter, max1 + max2)
            
            # 返回从当前节点向下的最长路径
            return max1 + 1
        
        # 从节点 0 开始 DFS
        dfs(0, -1)
        
        return self.diameter
```

## 复杂度分析

### 方法一和方法二：两次 BFS/DFS

- 时间复杂度：O(n)，其中 n 是节点数。需要遍历两次树，每次遍历访问所有节点和边
- 空间复杂度：O(n)，用于存储邻接表和访问标记

### 方法三：一次 DFS

- 时间复杂度：O(n)，只需要一次 DFS 遍历
- 空间复杂度：O(n)，递归调用栈的深度最多为 n（在链状树的情况下）

## 关键点总结

1. 树的直径可以通过两次 BFS/DFS 找到：先从任意点找最远点，再从最远点找直径
2. 一次 DFS 的方法更优雅，核心是记录每个节点向下的最长路径和次长路径
3. 需要正确构建无向图的邻接表（双向添加边）
4. 边界情况：空树或只有一个节点的情况
5. 树的性质：n 个节点的树有 n-1 条边，任意两点间只有唯一路径

## 易错点

1. 忘记处理空树的情况（edges 为空）
2. 构建邻接表时忘记添加双向边（无向图）
3. DFS 时忘记标记访问过的节点，导致死循环
4. 一次 DFS 方法中，忘记传递 parent 参数避免回到父节点
5. 混淆路径上的边数和节点数（本题求的是边数）
