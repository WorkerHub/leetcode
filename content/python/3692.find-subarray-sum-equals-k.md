## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回元素之和等于 `k` 的子数组数量。

**示例 1：**

```
输入：nums = [1,1,1], k = 2
输出：2
解释：[1,1]（下标0-1）和[1,1]（下标1-2）
```

**示例 2：**

```
输入：nums = [1,2,3], k = 3
输出：2
解释：[3]（下标2）和[1,2]（下标0-1）
```

**提示：**

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 解题思路

前缀和 + 哈希表：

`sum[l..r] = prefix[r+1] - prefix[l] = k`，即 `prefix[l] = prefix[r+1] - k`。

遍历时维护前缀和出现次数，对每个 `prefix[r+1]`，查询 `prefix[r+1] - k` 的出现次数。

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        count[0] = 1
        prefix = 0
        ans = 0

        for x in nums:
            prefix += x
            ans += count[prefix - k]
            count[prefix] += 1

        return ans
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            s = 0
            for j in range(i, n):
                s += nums[j]
                if s == k:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)（方法一），O(1)（方法二）

## 关键点总结

1. 前缀和哈希表是此类问题的标准解法
2. 初始化 `count[0] = 1`（空子数组，前缀和 0 出现 1 次）
3. 每次查询 `count[prefix - k]`，然后更新 `count[prefix]`

## 易错点

1. `count[0] = 1` 不能忘（处理从头开始的子数组）
2. 先查询再更新（避免同一位置自己匹配自己）
3. 数组可能包含负数，不能用滑动窗口
