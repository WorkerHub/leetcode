## 题目描述

给定一些区域列表，每个列表的第一个区域直接包含该列表中的所有其他区域。

如果区域 x 直接包含区域 y，并且区域 y 直接包含区域 z，那么我们认为区域 x 间接包含区域 z。根据定义，一个区域 x 包含它自己。

给定两个区域 region1 和 region2，返回包含它们两者的最小区域。题目保证最小区域一定存在。

**示例 1:**

```
输入: 
regions = [
  ["Earth","North America","South America"],
  ["North America","United States","Canada"],
  ["United States","New York","Boston"],
  ["Canada","Ontario","Quebec"],
  ["South America","Brazil"]
]
region1 = "Quebec"
region2 = "New York"
输出: "North America"
```

**示例 2:**

```
输入:
regions = [
  ["Earth", "North America", "South America"],
  ["North America", "United States", "Canada"],
  ["United States", "New York", "Boston"],
  ["Canada", "Ontario", "Quebec"],
  ["South America", "Brazil"]
]
region1 = "Canada"
region2 = "South America"
输出: "Earth"
```

**提示:**

- 2 <= regions.length <= 10^4
- 2 <= regions[i].length <= 20
- 1 <= regions[i][j].length, region1.length, region2.length <= 20
- region1 != region2
- regions[i][j], region1, 和 region2 由英文字母组成

## 解题思路

这道题本质上是在树结构中寻找两个节点的最近公共祖先（Lowest Common Ancestor, LCA）。

**核心思想：**

1. 构建父节点映射：遍历 regions 列表，为每个子区域记录其父区域
2. 找到 region1 的所有祖先路径
3. 从 region2 开始向上查找，第一个出现在 region1 祖先路径中的区域就是答案

**算法流程：**

1. 建立哈希表 parent，key 是子区域，value 是父区域
2. 从 region1 开始，沿着父节点一路向上，将所有祖先存入集合 ancestors
3. 从 region2 开始，沿着父节点一路向上，第一个在 ancestors 中的节点就是 LCA

## Python 代码实现

### 方法一：哈希表 + 祖先路径（推荐）

```python
from typing import List

class Solution:
    def findSmallestRegion(self, regions: List[List[str]], region1: str, region2: str) -> str:
        # 构建父节点映射
        parent = {}
        for region_list in regions:
            parent_region = region_list[0]
            # 第一个是父区域，后面都是子区域
            for i in range(1, len(region_list)):
                parent[region_list[i]] = parent_region
        
        # 收集 region1 的所有祖先（包括自己）
        ancestors = set()
        current = region1
        while current:
            ancestors.add(current)
            current = parent.get(current)  # 向上查找父节点
        
        # 从 region2 向上查找，第一个在 ancestors 中的就是答案
        current = region2
        while current:
            if current in ancestors:
                return current
            current = parent.get(current)
        
        return ""  # 题目保证一定有解，不会到这里
```

### 方法二：路径比较法

```python
from typing import List

class Solution:
    def findSmallestRegion(self, regions: List[List[str]], region1: str, region2: str) -> str:
        # 构建父节点映射
        parent = {}
        for region_list in regions:
            for i in range(1, len(region_list)):
                parent[region_list[i]] = region_list[0]
        
        # 获取从某个区域到根节点的完整路径
        def get_path(region: str) -> List[str]:
            path = []
            current = region
            while current:
                path.append(current)
                current = parent.get(current)
            return path
        
        # 获取两个区域的完整路径
        path1 = get_path(region1)
        path2 = get_path(region2)
        
        # 反转路径，从根节点开始比较
        path1.reverse()
        path2.reverse()
        
        # 找到最后一个公共节点
        result = path1[0]  # 至少有根节点
        for i in range(min(len(path1), len(path2))):
            if path1[i] == path2[i]:
                result = path1[i]
            else:
                break
        
        return result
```

### 方法三：字典嵌套法（树结构）

```python
from typing import List

class Solution:
    def findSmallestRegion(self, regions: List[List[str]], region1: str, region2: str) -> str:
        # 构建父节点映射
        parent = {}
        for region_list in regions:
            for i in range(1, len(region_list)):
                parent[region_list[i]] = region_list[0]
        
        # 找到 region1 的深度（到根节点的距离）
        def get_depth(region: str) -> int:
            depth = 0
            current = region
            while current in parent:
                current = parent[current]
                depth += 1
            return depth
        
        # 获取两个区域的深度
        depth1 = get_depth(region1)
        depth2 = get_depth(region2)
        
        # 让深度更深的先向上移动，使两者在同一深度
        while depth1 > depth2:
            region1 = parent[region1]
            depth1 -= 1
        
        while depth2 > depth1:
            region2 = parent[region2]
            depth2 -= 1
        
        # 同时向上移动，直到相遇
        while region1 != region2:
            region1 = parent[region1]
            region2 = parent[region2]
        
        return region1
```

## 复杂度分析

**方法一：哈希表 + 祖先路径**

- 时间复杂度：O(N + H)，N 是所有区域的总数，H 是树的高度
  - 构建父节点映射需要 O(N)
  - 查找祖先路径最坏需要 O(H)
- 空间复杂度：O(N)，需要存储父节点映射和祖先集合

**方法二：路径比较法**

- 时间复杂度：O(N + H)，同方法一
- 空间复杂度：O(N + H)，需要额外存储两条完整路径

**方法三：字典嵌套法**

- 时间复杂度：O(N + H)，同方法一
- 空间复杂度：O(N)，只需存储父节点映射

## 关键点总结

1. 本质是最近公共祖先（LCA）问题，但树结构以列表形式给出
2. 构建父节点映射是关键，类似于建立反向索引
3. 可以使用集合快速判断某个节点是否在祖先路径中
4. 注意根节点没有父节点，使用 parent.get(current) 避免 KeyError
5. 题目保证答案存在，不需要处理无解情况

## 易错点

1. 忘记根节点没有父节点，直接使用 parent[current] 会报错
   - 应使用 parent.get(current) 或先判断 current in parent
2. 混淆父子关系：regions[i][0] 是父区域，regions[i][1:] 是子区域
3. 遗漏节点自己也是祖先之一
4. 方法三中，忘记让两个节点先对齐到同一深度
