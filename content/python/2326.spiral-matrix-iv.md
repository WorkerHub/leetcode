## 题目描述

给你两个整数 `m` 和 `n`，表示一个 `m x n` 的矩阵。另给你一个整数链表的头节点 `head`。

请你生成一个大小为 `m x n` 的螺旋矩阵，矩阵包含链表中的所有整数。从矩阵**左上角**开始，按**顺时针螺旋**顺序填充链表的值，剩余位置填充 `-1`。

**示例：**
```
输入：m = 3, n = 5, head = [3,0,2,6,8,1,7,9,4,2,5,5,0]
输出：[[3,0,2,6,8],[5,0,-1,-1,1],[5,2,4,9,7]]
```

**提示：**
- `1 <= m, n <= 10^5`
- `1 <= m * n <= 10^5`
- 链表中节点数目在范围 `[1, m * n]` 内

## 解题思路

模拟螺旋遍历过程，依次填入链表节点的值，链表耗尽后剩余位置填 -1。

螺旋方向：右 → 下 → 左 → 上，循环。

## 代码实现

### 方法一：模拟螺旋（推荐）

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def spiralMatrix(self, m: int, n: int, head: Optional[ListNode]) -> List[List[int]]:
        # 初始化矩阵，全部填 -1
        matrix = [[-1] * n for _ in range(m)]
        
        # 四个方向：右、下、左、上
        dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        d = 0          # 当前方向
        r, c = 0, 0    # 当前位置
        
        node = head
        total = m * n
        
        for _ in range(total):
            if node is None:
                break  # 链表已耗尽
            matrix[r][c] = node.val
            node = node.next
            
            # 计算下一个位置
            nr = r + dirs[d][0]
            nc = c + dirs[d][1]
            
            # 若越界或已访问，转向
            if not (0 <= nr < m and 0 <= nc < n) or matrix[nr][nc] != -1:
                d = (d + 1) % 4
                nr = r + dirs[d][0]
                nc = c + dirs[d][1]
            
            r, c = nr, nc
        
        return matrix
```

### 方法二：使用边界收缩

```python
from typing import Optional, List

class Solution:
    def spiralMatrix(self, m: int, n: int, head: Optional[ListNode]) -> List[List[int]]:
        matrix = [[-1] * n for _ in range(m)]
        top, bottom, left, right = 0, m - 1, 0, n - 1
        node = head
        
        while top <= bottom and left <= right:
            # 向右
            for c in range(left, right + 1):
                if node:
                    matrix[top][c] = node.val
                    node = node.next
            top += 1
            # 向下
            for r in range(top, bottom + 1):
                if node:
                    matrix[r][right] = node.val
                    node = node.next
            right -= 1
            # 向左
            for c in range(right, left - 1, -1):
                if node:
                    matrix[bottom][c] = node.val
                    node = node.next
            bottom -= 1
            # 向上
            for r in range(bottom, top - 1, -1):
                if node:
                    matrix[r][left] = node.val
                    node = node.next
            left += 1
        
        return matrix
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟螺旋 | O(m * n) | O(m * n) |
| 边界收缩 | O(m * n) | O(m * n) |

## 关键点总结

1. 螺旋遍历用方向数组 + 转向条件，或边界收缩两种方式都可实现。
2. 链表耗尽后剩余位置已初始化为 -1，不需要额外处理。
3. 转向条件：下一格越界或已被填充（非 -1）。

## 易错点

- 初始化矩阵时填 -1（不是 0），这样可以用 `!= -1` 判断是否已访问。
- 链表可能比矩阵大小短，需要随时判断 `node is None`。
