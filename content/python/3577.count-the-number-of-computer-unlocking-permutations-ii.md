## 题目描述

有 `n` 台电脑，编号 `0` 到 `n-1`，密码为 `complexity[i]`。电脑 `0` 默认解锁。若要解锁电脑 `i`（`i > 0`），需要先解锁某台密码**严格小于** `complexity[i]` 的电脑。求合法解锁排列数量，对 `10^9 + 7` 取模。

本题与 3543 类似，但数据规模更大（n 可达 10^5）。

**示例 1：**

```
输入：complexity = [1, 2, 3]
输出：2
```

**示例 2：**

```
输入：complexity = [1, 2, 2]
输出：2
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= complexity[i] <= 10^9`

## 解题思路

关键数学观察：
1. 电脑 0 的密码必须是最小的（否则无法解锁任何其他电脑）
2. 若 `complexity[0]` 不是最小值，返回 0
3. 排序后，对每台电脑 `i`（按密码升序），它能解锁的前提是存在密码严格小于 `complexity[i]` 的已解锁电脑
4. 设按密码排序后第 `i` 台电脑（0-indexed），前面有 `cnt[i]` 台密码严格小于它的电脑，则它有 `cnt[i]` 个选择位置（可以放在任何一个"前驱"之后）

答案 = `product(cnt[i])` for i from 1 to n-1（按密码升序）。

`cnt[i]` = 前 i 台中密码严格小于 `complexity[sorted_order[i]]` 的数量。

## Python 代码实现

### 方法一：排序 + 乘积（推荐）

```python
from typing import List

class Solution:
    def countPermutations(self, complexity: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(complexity)

        # 检查 complexity[0] 是否是最小值
        if complexity[0] != min(complexity):
            return 0

        # 按密码升序排列（除电脑 0 外）
        sorted_c = sorted(complexity[1:])

        min_val = complexity[0]
        result = 1

        for i, c in enumerate(sorted_c):
            if c <= min_val:
                # 与最小密码相等或更小，无法解锁（需要严格小于）
                return 0
            # 前面已有 i+1 台（电脑0 + 已处理的 i 台）密码 <= 当前
            # 但需要密码严格小于 c 的数量
            # 当所有密码唯一时：有 i+1 台密码严格小于 c（0 到 i 排序后）
            # 当有重复密码时：同密码组的第一台可以被解锁，后续的同密码不能被前一个同密码解锁
            result = result * (i + 1) % MOD

        return result
```

### 方法二：处理重复密码

```python
from typing import List
from collections import Counter

class Solution:
    def countPermutations(self, complexity: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(complexity)

        if complexity[0] != min(complexity):
            return 0

        # 排序后，按密码值分组
        # 同密码组内，只有第一个可以被解锁（被前面小密码的电脑解锁）
        # 其余同密码的只能被"更小密码已解锁的某台"解锁

        sorted_others = sorted(complexity[1:])
        min_val = complexity[0]
        result = 1
        smaller_count = 1  # 电脑 0 的密码 < 所有其他的

        for i, c in enumerate(sorted_others):
            if c <= min_val:
                return 0
            # 能解锁当前电脑的前驱数量 = i + 1（所有已处理的更小密码的电脑数）
            result = result * (i + 1) % MOD

        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 电脑 0 必须是密码最小的
2. 排序后，第 i 台电脑（按密码升序）有 i 个前驱可以选择
3. 答案 = `1 * 2 * ... * (n-1)` = `(n-1)!`（当所有密码唯一且合法时）

## 易错点

1. 若有密码等于最小值的其他电脑，返回 0（严格小于）
2. 乘积是 `1 * 2 * ... * (n-1)`，而不是 `n!`
3. 重复密码的处理：同密码的电脑不能互相解锁
