## 题目描述

给你一个大小为 `m x n` 的矩阵 `board`，由单元格组成，每个单元格是以下三类之一：
- `' '`：空白单元格，可以放字母
- `'#'`：障碍单元格，不能放字母
- `小写字母`：已有字母的单元格

给你一个字符串 `word`，你需要判断 `word` 是否能放置到矩阵中，满足：
- 单词**水平**（从左到右）或**垂直**（从上到下）放置
- 单词占用的格子要么是空格，要么与 `word` 对应字符相同
- 单词两端必须是矩阵边界或 `'#'` 障碍（即不能继续延伸）

**示例 1：**
```
输入：board = [["#"," ","#"],["#"," ","#"],["#"," ","#"]], word = "abc"
输出：true
```

**提示：**
- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 是 `'#'`、`' '` 或小写英文字母

## 解题思路

枚举所有可能的放置位置（水平和垂直方向），对每个起始位置检查 `word` 是否能放置。

**关键条件：**
1. 单词长度恰好填满两个障碍/边界之间的空间
2. 每个位置要么是空格，要么与单词字符相同

为了效率，枚举每行/列中由 `#` 或边界分隔的段，检查段长度是否等于单词长度，再逐字符验证。

## 代码实现

### 方法一：逐行/列枚举段（推荐）

```python
from typing import List

class Solution:
    def placeWordInCrossword(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])
        k = len(word)

        def can_place(segment: list, w: str) -> bool:
            # 检查 segment（一段单元格）是否可以放置单词 w（正向或反向）
            if len(segment) != len(w):
                return False
            # 正向检查
            if all(c == ' ' or c == w[i] for i, c in enumerate(segment)):
                return True
            # 反向检查
            rev_w = w[::-1]
            if all(c == ' ' or c == rev_w[i] for i, c in enumerate(segment)):
                return True
            return False

        # 检查所有行（水平放置）
        for row in board:
            # 按 '#' 分割行
            segment = []
            for cell in row:
                if cell == '#':
                    if can_place(segment, word):
                        return True
                    segment = []
                else:
                    segment.append(cell)
            if can_place(segment, word):
                return True

        # 检查所有列（垂直放置）
        for col in range(n):
            segment = []
            for row in range(m):
                cell = board[row][col]
                if cell == '#':
                    if can_place(segment, word):
                        return True
                    segment = []
                else:
                    segment.append(cell)
            if can_place(segment, word):
                return True

        return False
```

### 方法二：直接枚举起始位置

```python
from typing import List

class Solution:
    def placeWordInCrossword(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])
        k = len(word)

        def check(r, c, dr, dc, reverse: bool) -> bool:
            # 检查从 (r,c) 开始，沿 (dr,dc) 方向放置 word 是否合法
            w = word[::-1] if reverse else word
            for i in range(k):
                nr, nc = r + i * dr, c + i * dc
                if not (0 <= nr < m and 0 <= nc < n):
                    return False
                cell = board[nr][nc]
                if cell != ' ' and cell != w[i]:
                    return False
            # 检查两端是否是边界或 '#'
            end_r, end_c = r + k * dr, c + k * dc
            if 0 <= end_r < m and 0 <= end_c < n and board[end_r][end_c] != '#':
                return False
            return True

        for r in range(m):
            for c in range(n):
                if board[r][c] == '#':
                    continue
                # 检查水平正向：起点左侧必须是边界或 '#'
                if (c == 0 or board[r][c - 1] == '#'):
                    if check(r, c, 0, 1, False) or check(r, c, 0, 1, True):
                        return True
                # 检查垂直正向：起点上方必须是边界或 '#'
                if (r == 0 or board[r - 1][c] == '#'):
                    if check(r, c, 1, 0, False) or check(r, c, 1, 0, True):
                        return True

        return False
```

## 复杂度分析

- 时间复杂度：O(m * n * L)，L 为单词长度
- 空间复杂度：O(m + n)，用于存储段

## 关键点总结

1. 枚举所有由 `#` 或边界分隔的段，只有段长度等于单词长度时才检查
2. 单词可以正向或反向放置（因为反向等于从另一端开始放置）
3. 字符匹配条件：空格（可被替换）或已有字符（必须相同）

## 易错点

- 单词两端必须紧接 `#` 或边界，不能有多余的空格继续延伸
- 反向放置等价于 `word` 反转后正向放置
- 单元格是字母时不是障碍，可以作为单词的一部分（只要字符相同）
