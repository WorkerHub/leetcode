## 题目描述

给定整数 `n` 和整数 `k`，翻转 `n` 的二进制表示中第 `k` 位（从第 0 位开始，第 0 位是最低位），返回翻转后的结果。

**示例 1：**
```
输入：n = 10, k = 2
输出：14
解释：10 = 1010（二进制），翻转第 2 位：1010 -> 1110 = 14。
```

**示例 2：**
```
输入：n = 7, k = 1
输出：5
解释：7 = 111，翻转第 1 位：111 -> 101 = 5。
```

**提示：**
- `0 <= n <= 10^9`
- `0 <= k <= 30`

## 解题思路

使用位运算：将第 `k` 位翻转，等价于将 `n` 与 `1 << k` 进行异或（XOR）。

- 若第 `k` 位为 0，异或后变为 1
- 若第 `k` 位为 1，异或后变为 0

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def flipBit(self, n: int, k: int) -> int:
        # 将第 k 位翻转：与 (1 << k) 异或
        return n ^ (1 << k)
```

### 方法二：通过掩码操作

```python
class Solution:
    def flipBit(self, n: int, k: int) -> int:
        mask = 1 << k
        if n & mask:
            # 第 k 位为 1，清零
            return n & ~mask
        else:
            # 第 k 位为 0，置 1
            return n | mask
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. XOR 是翻转特定位的最简洁操作：`n ^ (1 << k)`
2. `1 << k` 生成只有第 k 位为 1 的掩码
3. Python 整数无溢出，k 最大 30 时 `1 << 30 = 1073741824`

## 易错点

1. k 从第 0 位（最低位）开始，`1 << k` 正确
2. XOR 操作无条件翻转位，无需判断原来是 0 还是 1
