## 题目描述

给你一个 **下标从 0 开始** 的整数数组 `nums` 和一个整数 `value`。

一次操作中，你可以对 `nums` 中任意一个元素加上或减去 `value`（可以操作多次）。

操作后，数组的 **MEX**（最小非负缺失整数）是 `nums` 中不存在的最小非负整数。

返回操作 **任意次** 后，`nums` 的 **最大 MEX**。

**示例 1：**

```
输入：nums = [1,-10,7,13,6,8], value = 5
输出：4
解释：对 nums 进行操作，得到 [-9,-10,7,13,1,3]（等价类：-10%5=0, 1%5=1, 6%5=1 → 我们可以凑出 0,1,2,3 各一个）
```

**示例 2：**

```
输入：nums = [1,-10,7,13,6,8], value = 7
输出：2
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `1 <= value <= 10^9`

## 解题思路

**数学 + 哈希表**：

每个元素 `x` 可以通过加减 `value` 变为任意 `x + t * value`（t 为整数），即 `x` 可以变成 `x mod value`（取余后的等价类）。

因此，同一个余数 `r = x % value` 的所有元素（取模后非负），可以按顺序分配给 `r, r + value, r + 2*value, ...`。

按余数分组，每组有 `cnt` 个元素，可以覆盖从 `r` 开始的 `cnt` 个值：`r, r+value, r+2*value, ...`。

贪心找最小未覆盖的 MEX：
- 从 0 开始，检查 `0 % value = 0` 这个余数的元素能覆盖多远，再检查 `1, 2, ...` 直到某余数没有足够元素覆盖。

## Python 代码实现

### 方法一：按余数分组计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findSmallestInteger(self, nums: List[int], value: int) -> int:
        # 统计每个余数的元素个数（Python 的取余结果非负）
        cnt = Counter(x % value for x in nums)

        mex = 0
        while cnt[mex % value] > 0:
            cnt[mex % value] -= 1
            mex += 1

        return mex
```

### 方法二：排序分配验证

```python
from typing import List
from collections import defaultdict

class Solution:
    def findSmallestInteger(self, nums: List[int], value: int) -> int:
        # 按余数分组
        groups = defaultdict(int)
        for x in nums:
            groups[x % value] += 1

        mex = 0
        # 从 0 开始逐一检查
        while True:
            r = mex % value
            if groups[r] == 0:
                return mex
            groups[r] -= 1
            mex += 1
```

## 复杂度分析

- 时间复杂度：O(n + MEX)，统计 O(n) + 查找 MEX O(MEX)
- 空间复杂度：O(value)，余数种类最多 value 个

## 关键点总结

1. 每个元素通过加减 `value` 变换后，余数 `x % value` 不变
2. 同一余数的 `cnt` 个元素可以覆盖 `cnt` 个等差为 `value` 的整数
3. 贪心：从 0 开始找，每次消耗对应余数的一个元素

## 易错点

1. Python 的 `%` 运算对负数也返回非负结果（`-10 % 5 = 0`），利用此特性无需特殊处理
2. MEX 逐步增大，每次消耗 `mex % value` 的一个元素
3. 当某余数的计数为 0 时，对应的 `mex` 就是答案
