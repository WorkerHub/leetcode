## 题目描述

给你一个下标从 **0** 开始的正整数数组 `nums`。请你找出并统计满足下述条件的三元组 `(i, j, k)` 的数目：

- `0 <= i < j < k < nums.length`
- `nums[i]`、`nums[j]` 和 `nums[k]` **两两不同**，即 `nums[i] != nums[j]`、`nums[i] != nums[k]` 且 `nums[j] != nums[k]`。

**示例 1：**
```
输入：nums = [4,4,2,4,3]
输出：3
解释：三元组 (i,j,k) 满足：(0,2,4)、(1,2,4)、(2,3,4)（下标和值不同）。
```

**示例 2：**
```
输入：nums = [1,1,1,1,1]
输出：0
```

**提示：**
- `3 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 解题思路

**方法一（暴力）：** 三重循环枚举所有三元组，检查是否满足条件。

**方法二（计数优化）：** 利用乘法原理，将不同值的出现次数相乘。

排序后，枚举中间元素 j，左边出现过的不同值个数为 `left`，右边出现过的不同值个数为 `right`，贡献 = `left * right`（选一个不等于 j 值且在左边的，选一个不等于 j 值且在右边的）。

但这里需要确保选的值不等于 `nums[j]` 且三个值互不相同。

实际上，更简单的思路：按值分组，用组合数学计算。

设各值出现次数为 `c_1, c_2, ..., c_m`（共 m 种不同值）。答案 = C(n, 3) - 有重复值的三元组数。

但最简洁的方法：直接三重循环（n <= 100，可行）。

## 代码实现

### 方法一：暴力三重循环（推荐，简单）

```python
from typing import List

class Solution:
    def unequalTriplets(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[i] != nums[j] and nums[i] != nums[k] and nums[j] != nums[k]:
                        ans += 1

        return ans
```

### 方法二：计数（高效）

```python
from typing import List
from collections import Counter

class Solution:
    def unequalTriplets(self, nums: List[int]) -> int:
        count = Counter(nums)
        ans = 0
        n = len(nums)

        # 枚举「中间」值 v，前面 a 个、后面 b 个来自其他值
        prefix = 0  # 已经遍历过的不同于当前值的元素数量

        for v, c in count.items():
            suffix = n - prefix - c  # 后面不同于 v 的元素数量
            ans += prefix * c * suffix  # 从前选一个，从 c 个中选一个，从后选一个
            prefix += c

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力三重循环 | O(n^3) | O(1) |
| 计数 | O(n) | O(n) |

## 关键点总结

1. 三值互不相同的条件：`nums[i] != nums[j]`、`nums[i] != nums[k]`、`nums[j] != nums[k]`
2. 计数方法：对每个值 v，作为中间值，前面有 prefix 个不同值，后面有 suffix 个不同值，贡献 `prefix * c * suffix`
3. n <= 100 时暴力可行

## 易错点

- 三个索引必须满足 i < j < k（有序）
- 计数方法中，枚举中间值时要保证前后元素不属于同一值类别
