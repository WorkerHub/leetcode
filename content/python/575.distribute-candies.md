## 题目描述

Alice 有 `n` 枚糖，这些糖的类型由数组 `candyType` 表示。Alice 注意到她的体重正在增长，所以她去看了医生。

医生建议 Alice 只吃她所有糖的 `n / 2`（n 是偶数）。Alice 非常喜欢糖果，她想在遵循医生建议的同时，尽可能多地吃不同类型的糖果。

给定一个长度为 `n` 的整数数组 `candyType`，返回 Alice 在只吃 `n / 2` 枚糖的情况下，能够吃到的不同类型糖果的最大数量。

**示例 1：**
```
输入：candyType = [1,1,2,2,3,3]
输出：3
解释：Alice 只能吃 6 / 2 = 3 枚糖。由于有3种糖，她可以每种吃一枚。
```

**示例 2：**
```
输入：candyType = [1,1,2,3]
输出：2
解释：Alice 只能吃 4 / 2 = 2 枚糖。无论她选择吃哪两枚，她最多只能吃到 2 种不同类型的糖。
```

**示例 3：**
```
输入：candyType = [6,6,6,6]
输出：1
解释：Alice 只能吃 4 / 2 = 2 枚糖。即使她可以吃2枚，她也只能吃到1种糖。
```

**提示：**
- `n == candyType.length`
- `2 <= n <= 10^4`
- `n` 是偶数
- `-10^5 <= candyType[i] <= 10^5`

## 解题思路

这是一道简单的贪心题。

核心观察：
- 最多能吃 n/2 枚糖
- 要使类型最多，应该尽量选不同类型
- 答案 = min(不同类型数, n/2)

## Python 代码实现

### 方法一：集合（推荐）⭐

```python
from typing import List

class Solution:
    def distributeCandies(self, candyType: List[int]) -> int:
        """
        使用集合统计类型数
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        return min(len(set(candyType)), len(candyType) // 2)
```

### 方法二：哈希表

```python
from typing import List

class Solution:
    def distributeCandies(self, candyType: List[int]) -> int:
        """
        使用哈希表统计
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        unique_types = len(set(candyType))
        max_eat = len(candyType) // 2
        return min(unique_types, max_eat)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，集合存储

## 关键点总结

1. **贪心策略**：尽量选不同类型
2. **两个限制**：类型数和能吃的数量
3. **取最小值**：min(类型数, n/2)
