## 题目描述

给你一个字符串 `s`、一个整数 `k`、一个字母 `letter` 和一个整数 `repetition`。

返回 `s` 的长度为 `k` 且字典序最小的子序列，其中 `letter` 至少出现 `repetition` 次。

**子序列**是从字符串中按顺序选取字符得到的（不一定连续）。

**示例 1：**
```
输入：s = "leet", k = 3, letter = "e", repetition = 1
输出："eet"
```

**示例 2：**
```
输入：s = "leetcode", k = 4, letter = "e", repetition = 2
输出："ecde"
```

**提示：**
- `1 <= repetition <= k <= s.length <= 5 * 10^4`
- `s` 只含小写字母
- `letter` 是小写字母
- `s` 中 `letter` 至少出现 `repetition` 次

## 解题思路

使用**贪心 + 单调栈**：

类似"最小 k 个字符的子序列"，但增加了 `letter` 出现次数的约束。

**贪心策略：**
1. 维护一个栈，确保栈中字符字典序尽可能小
2. 可以弹出栈顶字符的条件：
   - 剩余字符（包括当前）足够填满 k 个
   - 弹出后不会导致 `letter` 的数量不够

**关键变量：**
- `remaining`：从当前位置到末尾的字符数
- `letter_remaining`：从当前位置到末尾的 `letter` 数
- `letter_in_stack`：栈中 `letter` 的数量

**弹出条件：**
- 当前字符 `c < stack[-1]`（可能更优）
- `len(stack) - 1 + remaining >= k`（弹出后还能凑够 k 个）
- `letter_in_stack + letter_remaining >= repetition`（弹出后 letter 仍够）
- 如果栈顶是 `letter` 且弹出后 `letter_in_stack - 1 + letter_remaining >= repetition`

## 代码实现

### 方法一：贪心单调栈（推荐）

```python
class Solution:
    def smallestSubsequence(self, s: str, k: int, letter: str, repetition: int) -> str:
        n = len(s)
        stack = []
        letter_in_stack = 0  # 栈中 letter 的数量

        # 预计算后缀 letter 计数
        letter_count = s.count(letter)  # 剩余的 letter 数量

        for i, c in enumerate(s):
            remaining = n - i  # 包括当前字符的剩余字符数

            # 尝试弹出栈顶
            while stack and c < stack[-1]:
                # 弹出需要满足的条件
                top_is_letter = (stack[-1] == letter)

                # 剩余字符数（不含已弹出）能否填满 k 个
                if len(stack) - 1 + remaining < k:
                    break  # 弹出后凑不够 k 个

                # letter 数量是否仍然够
                new_letter_in_stack = letter_in_stack - (1 if top_is_letter else 0)
                if new_letter_in_stack + letter_count < repetition:
                    break  # 弹出后 letter 不够

                # 可以弹出
                if top_is_letter:
                    letter_in_stack -= 1
                stack.pop()

            # 决定是否将当前字符加入栈
            if len(stack) < k:
                if c == letter:
                    stack.append(c)
                    letter_in_stack += 1
                elif k - len(stack) > repetition - letter_in_stack:
                    # 还有空间放非 letter 字符
                    stack.append(c)
            # 更新剩余 letter 数量
            if c == letter:
                letter_count -= 1

        return "".join(stack)
```

### 方法二：分步构建

```python
class Solution:
    def smallestSubsequence(self, s: str, k: int, letter: str, repetition: int) -> str:
        n = len(s)
        # 后缀字母计数
        suffix_letter = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_letter[i] = suffix_letter[i + 1] + (s[i] == letter)

        stack = []
        letter_count = 0

        for i, c in enumerate(s):
            # 尝试弹出栈顶（单调递增栈）
            while (stack and c < stack[-1] and
                   len(stack) - 1 + (n - i) >= k and
                   letter_count - (stack[-1] == letter) + suffix_letter[i] >= repetition):
                if stack[-1] == letter:
                    letter_count -= 1
                stack.pop()

            if len(stack) < k:
                # 检查是否必须加入：剩余位置和 letter 需求
                slots_left = k - len(stack)
                letters_needed = repetition - letter_count - (c == letter)
                if c == letter or slots_left > suffix_letter[i + 1] - letters_needed:
                    stack.append(c)
                    if c == letter:
                        letter_count += 1

        return "".join(stack)
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符最多入栈出栈一次
- 空间复杂度：O(k)，栈空间

## 关键点总结

1. 单调栈贪心找字典序最小子序列，同时维护 `letter` 出现次数约束
2. 弹出栈顶需满足：字符数够用、`letter` 数量不会不足
3. 决定是否加入当前字符时，考虑剩余空间与 `letter` 需求的平衡

## 易错点

- 弹出 `letter` 类字符时，需要检查剩余是否够 `repetition` 次
- 加入字符时，即使字符不理想（字典序大），如果没有选择也必须加入
- `remaining` 指从当前位置（含）到末尾的字符数
