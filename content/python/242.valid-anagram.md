## 题目描述

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

**注意：** 若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

**示例 1：**
```
输入: s = "anagram", t = "nagaram"
输出: true
```

**示例 2：**
```
输入: s = "rat", t = "car"
输出: false
```

**提示：**
- 1 <= s.length, t.length <= 5 * 10^4
- s 和 t 仅包含小写字母

**进阶：** 如果输入字符串包含 Unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 解题思路

判断两个字符串是否为字母异位词，核心是**判断两个字符串中每个字符出现的次数是否相同**。

**基本思路：**
1. **排序法**：将两个字符串排序后比较是否相等
2. **哈希表法**：统计每个字符出现的次数，然后比较
3. **数组计数法**：利用小写字母只有 26 个的特点，用数组统计

**关键观察：**
- 如果两个字符串长度不同，直接返回 False
- 字母异位词意味着字符种类和数量完全相同，只是顺序不同
- 可以用 Python 的 `collections.Counter` 简化实现

## Python 代码实现

### 方法一：排序法（最直观）

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        将两个字符串排序后比较
        时间复杂度：O(n log n)，排序的时间复杂度
        空间复杂度：O(log n)，排序的空间复杂度（Python 的 Timsort）
        """
        # 长度不同，直接返回 False
        if len(s) != len(t):
            return False
        
        # 排序后比较
        return sorted(s) == sorted(t)
```

### 方法二：哈希表统计（推荐）⭐

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        使用 Counter 统计字符频次
        时间复杂度：O(n)，遍历字符串
        空间复杂度：O(1)，最多 26 个小写字母
        """
        # 长度不同，直接返回 False
        if len(s) != len(t):
            return False
        
        # 比较字符频次
        return Counter(s) == Counter(t)
```

### 方法三：手动哈希表（进阶理解）

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        手动实现哈希表统计
        时间复杂度：O(n)
        空间复杂度：O(1)，最多 26 个字母
        """
        if len(s) != len(t):
            return False
        
        # 统计 s 中每个字符的频次
        char_count = {}
        for char in s:
            char_count[char] = char_count.get(char, 0) + 1
        
        # 在 t 中减去对应字符的频次
        for char in t:
            if char not in char_count:
                return False
            char_count[char] -= 1
            if char_count[char] < 0:
                return False
        
        # 检查是否所有字符频次都为 0
        return all(count == 0 for count in char_count.values())
```

### 方法四：数组计数法（最优解）⭐

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        利用小写字母只有 26 个的特点，用数组统计
        时间复杂度：O(n)
        空间复杂度：O(1)，固定大小的数组
        """
        if len(s) != len(t):
            return False
        
        # 创建长度为 26 的计数数组
        count = [0] * 26
        
        # 统计字符频次
        for i in range(len(s)):
            count[ord(s[i]) - ord('a')] += 1  # s 中的字符 +1
            count[ord(t[i]) - ord('a')] -= 1  # t 中的字符 -1
        
        # 如果是异位词，所有计数都应该为 0
        return all(c == 0 for c in count)
```

### 方法五：单次遍历优化

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        单次遍历 + 提前返回优化
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if len(s) != len(t):
            return False
        
        count = [0] * 26
        
        for i in range(len(s)):
            count[ord(s[i]) - ord('a')] += 1
            count[ord(t[i]) - ord('a')] -= 1
        
        # Python 简洁写法
        return count == [0] * 26
```

### 进阶：支持 Unicode 字符

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        支持 Unicode 字符（中文、emoji 等）
        时间复杂度：O(n)
        空间复杂度：O(n)，字符种类可能很多
        """
        if len(s) != len(t):
            return False
        
        # Counter 可以处理任何字符
        return Counter(s) == Counter(t)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 排序法 | O(n log n) | O(log n) | 简单直观，但效率较低 |
| Counter | O(n) | O(1) | Python 推荐写法 |
| 手动哈希表 | O(n) | O(1) | 帮助理解原理 |
| 数组计数 | O(n) | O(1) | 最优解，利用题目条件 |


## 关键点总结

1. **长度检查**：两个字符串长度不同，直接返回 False，可以提前剪枝
2. **字符频次**：核心是统计每个字符出现的次数是否相同
3. **空间优化**：利用题目条件（仅小写字母），可以用固定大小的数组
4. **Python 技巧**：`Counter` 是处理字符频次的最佳工具
5. **Unicode 支持**：哈希表方法天然支持 Unicode，数组方法仅适用于有限字符集

## 易错点

1. **忘记长度检查**：虽然后续逻辑也能判断，但提前检查更高效
2. **字符范围假设**：题目明确说明只有小写字母，但进阶要求考虑 Unicode
3. **数组索引越界**：使用数组计数时，要确保 `ord(char) - ord('a')` 在 [0, 25] 范围内
4. **空字符串处理**：两个空字符串应该返回 True（它们互为异位词）
5. **哈希表残留**：方法三中要检查所有字符频次是否为 0
