## 题目描述

给定一个整数 `n`，构造一个 `2^n x 2^n` 的矩阵，满足特殊的递归填充规则：
- 对于 1x1 矩阵，填入 `0`
- 对于 `2^n x 2^n` 矩阵，将其分为四个 `2^(n-1) x 2^(n-1)` 的子矩阵：
  - 左上角：递归填充，元素不变
  - 右上角：递归填充，元素加上 `3 * 4^(n-1)`
  - 左下角：递归填充，元素加上 `1 * 4^(n-1)`
  - 右下角：递归填充，元素加上 `2 * 4^(n-1)`

**示例 1：**

```
输入：n = 1
输出：[[0,2],[1,3]]
```

**示例 2：**

```
输入：n = 2
输出：[[0,2,8,10],[1,3,9,11],[4,6,12,14],[5,7,13,15]]
```

**提示：**
- `0 <= n <= 6`

## 解题思路

递归分治构造：
1. 基础情况：n=0 时返回 `[[0]]`
2. 递归情况：构造四个子矩阵，分别加上对应偏移量后拼接

偏移量：
- 左上角：+0
- 右上角：+3 * 4^(n-1)
- 左下角：+1 * 4^(n-1)  
- 右下角：+2 * 4^(n-1)

## Python 代码实现

### 方法一：递归构造（推荐）

```python
from typing import List

class Solution:
    def specialGrid(self, n: int) -> List[List[int]]:
        def build(n):
            if n == 0:
                return [[0]]
            sub = build(n - 1)
            size = len(sub)
            offset = 4 ** (n - 1)

            # 构造四个子矩阵（加偏移）
            def add_offset(mat, off):
                return [[val + off for val in row] for row in mat]

            top_left = add_offset(sub, 0)
            top_right = add_offset(sub, 3 * offset)
            bot_left = add_offset(sub, 1 * offset)
            bot_right = add_offset(sub, 2 * offset)

            # 拼接矩阵
            result = []
            for i in range(size):
                result.append(top_left[i] + top_right[i])
            for i in range(size):
                result.append(bot_left[i] + bot_right[i])
            return result

        return build(n)
```

### 方法二：迭代构造

```python
from typing import List

class Solution:
    def specialGrid(self, n: int) -> List[List[int]]:
        size = 1 << n  # 2^n
        grid = [[0] * size for _ in range(size)]

        def fill(r, c, sz, base):
            if sz == 1:
                grid[r][c] = base
                return
            half = sz // 2
            quarter = half * half
            # 左上
            fill(r, c, half, base)
            # 左下
            fill(r + half, c, half, base + quarter)
            # 右上
            fill(r, c + half, half, base + 3 * quarter)
            # 右下
            fill(r + half, c + half, half, base + 2 * quarter)

        fill(0, 0, size, 0)
        return grid
```

## 复杂度分析

- 时间复杂度：O(4^n)，每个格子填一次
- 空间复杂度：O(4^n)，矩阵大小

## 关键点总结

1. 分治构造：每次将矩阵分为四个等大子矩阵
2. 偏移量按规则：左上+0，左下+1倍，右下+2倍，右上+3倍
3. `4^(n-1)` 是每个子矩阵包含的元素数量

## 易错点

1. 偏移量的顺序：左上0，左下1，右下2，右上3（与直觉不同）
2. 基础情况是 n=0（1x1 矩阵），返回 `[[0]]`
3. 矩阵拼接时注意行列顺序
