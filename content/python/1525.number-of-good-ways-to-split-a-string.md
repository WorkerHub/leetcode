## 题目描述

给你一个字符串 `s`，一个 **好的分割** 指的是把 `s` 分成两个非空字符串 `p` 和 `q`，使得 `p` 中不同字符的数目等于 `q` 中不同字符的数目。

返回好的分割的数目。

**示例 1：**
```
输入：s = "aacaba"
输出：2
解释：分割位置 2 和 5（前缀长度），"aa"和"caba"各有2种字符，"aacab"和"a"各有3种和1种不行。
```

**示例 2：**
```
输入：s = "abcd"
输出：1
```

**提示：**
- `s` 只包含小写英文字母
- `1 <= s.length <= 10^5`

## 解题思路

### 前缀/后缀不同字符数统计

枚举分割位置 `i`（`1 <= i <= n-1`）：
- 前缀 `s[0..i-1]` 的不同字符数
- 后缀 `s[i..n-1]` 的不同字符数

如果两者相等，则是一个好的分割。

**优化：**
- 预处理前缀不同字符数数组 `prefix[i]`
- 预处理后缀不同字符数数组 `suffix[i]`
- 枚举所有分割点，O(N) 比较

## 代码实现

### 方法一：前缀后缀数组（推荐）

```python
class Solution:
    def numSplits(self, s: str) -> int:
        n = len(s)
        # 前缀不同字符数
        prefix = [0] * n
        seen = set()
        for i, c in enumerate(s):
            seen.add(c)
            prefix[i] = len(seen)

        # 后缀不同字符数
        suffix = [0] * n
        seen = set()
        for i in range(n - 1, -1, -1):
            seen.add(s[i])
            suffix[i] = len(seen)

        # 统计好的分割
        ans = 0
        for i in range(n - 1):
            if prefix[i] == suffix[i + 1]:
                ans += 1
        return ans
```

### 方法二：双指针（两个集合）

```python
class Solution:
    def numSplits(self, s: str) -> int:
        from collections import Counter
        n = len(s)
        # 左边的字符计数
        left = Counter()
        # 右边的字符计数
        right = Counter(s)

        ans = 0
        for i in range(n - 1):
            c = s[i]
            left[c] += 1
            right[c] -= 1
            if right[c] == 0:
                del right[c]
            # 比较不同字符数
            if len(left) == len(right):
                ans += 1
        return ans
```

### 方法三：位掩码（仅26个字母适用）

```python
class Solution:
    def numSplits(self, s: str) -> int:
        n = len(s)
        # 用整数位掩码表示字符集合
        prefix_mask = [0] * n
        suffix_mask = [0] * n

        mask = 0
        for i, c in enumerate(s):
            mask |= 1 << (ord(c) - ord('a'))
            prefix_mask[i] = mask

        mask = 0
        for i in range(n - 1, -1, -1):
            mask |= 1 << (ord(s[i]) - ord('a'))
            suffix_mask[i] = mask

        ans = 0
        for i in range(n - 1):
            # bin(x).count('1') 计算 popcount
            if bin(prefix_mask[i]).count('1') == bin(suffix_mask[i+1]).count('1'):
                ans += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（数组） | O(N) | O(N) |
| 方法二（双指针） | O(N) | O(26) = O(1) |
| 方法三（位掩码） | O(N) | O(N) |

## 关键点总结

1. 核心是统计前缀和后缀的不同字符数
2. 方法二用两个 Counter 动态维护，空间更优
3. 分割点枚举范围是 `[1, n-1]`，确保两边非空

## 易错点

- 分割点 `i` 表示前缀长度，后缀从 `i` 开始（不是从 `i+1`）
- 枚举到 `n-2`（下标），即 `range(n-1)`
