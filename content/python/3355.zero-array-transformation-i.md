## 题目描述

给你一个整数数组 `nums` 和一个二维数组 `queries`，其中 `queries[i] = [l, r]`。

每次查询可以对 `nums[l..r]` 中的每个元素减 1（不能减到负数，即最小值为 0）。

判断：在执行所有查询后，`nums` 是否能变成全 0 数组？

返回 `true` 或 `false`。

**示例：**
```
输入：nums = [1, 0, 1], queries = [[0, 2]]
输出：true
解释：执行 queries[0]：nums[0..2] -= 1 => [0, -1, 0]，最小 0 => [0, 0, 0]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

**差分数组：**

对每个查询 `[l, r]`，相当于给区间 `[l, r]` 加 1（可以减的次数 +1）。

用差分数组计算每个位置 `i` 被覆盖了多少次（即可以减多少次），然后检验 `nums[i] <= 覆盖次数[i]`。

## Python 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:
        n = len(nums)
        
        # 差分数组：cover[i] = 位置 i 被查询覆盖的次数
        diff = [0] * (n + 1)
        for l, r in queries:
            diff[l] += 1
            diff[r + 1] -= 1
        
        # 还原覆盖次数
        cover = 0
        for i in range(n):
            cover += diff[i]
            if nums[i] > cover:
                return False
        
        return True
```

### 方法二：前缀和验证

```python
from typing import List

class Solution:
    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:
        n = len(nums)
        count = [0] * (n + 1)
        
        for l, r in queries:
            count[l] += 1
            count[r + 1] -= 1
        
        prefix = 0
        for i in range(n):
            prefix += count[i]
            if nums[i] > prefix:
                return False
        
        return True
```

## 复杂度分析

- 时间复杂度：O(n + q)，差分数组操作 + 一次前缀和
- 空间复杂度：O(n)，差分数组

## 关键点总结

1. 差分数组将区间操作化为单点操作，前缀和还原每个位置的覆盖次数。
2. `nums[i] > cover[i]` 时，该位置无法被减为 0，返回 False。
3. 区间 `[l, r]` 对应差分操作 `diff[l]++, diff[r+1]--`。

## 易错点

1. 差分数组大小需要 `n+1`（防止 `r+1 == n` 越界）。
2. 减法不能使元素低于 0，但题目问的是"能否变成 0"，只需判断覆盖次数 >= nums[i]。
3. 覆盖次数的计算用滚动前缀和，不需要额外数组。
