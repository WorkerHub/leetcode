## 题目描述

给你一个仅由数字（`'0'` - `'9'`）组成的字符串 `num`，返回可以从中选取的最大回文数字字符串（即选取 `num` 的一个子集，重新排列成最大的回文）。

返回的值**不能**含有前导零（除非数字本身为 `"0"`）。

**示例 1：**
```
输入：num = "444947137"
输出："7449447"
```

**示例 2：**
```
输入：num = "00009"
输出："9"
```

**提示：**
- `1 <= num.length <= 10^5`
- `num` 只包含数字

## 解题思路

**贪心构造：**
1. 统计每个数字的出现次数。
2. 对于回文，每个数字可以用偶数次（放在两端）；出现奇数次的数字可以贡献一个单独放在中间。
3. 为了最大化回文数字：从大数字（9）到小数字（0）构建前半部分。
4. 注意：前导零问题——若最大数字只有 0，则返回 `"0"`。

## 代码实现

### 方法一：贪心构造（推荐）

```python
from collections import Counter

class Solution:
    def largestPalindromic(self, num: str) -> str:
        count = Counter(num)
        
        # 构建前半部分（从大到小）
        half = []
        middle = ''
        
        for d in '9876543210':
            pairs = count[d] // 2
            if pairs > 0:
                half.append(d * pairs)
            # 记录最大的可以放中间的数字
            if count[d] % 2 == 1 and (not middle or d > middle):
                middle = d
        
        half_str = ''.join(half)
        
        # 去掉前导零
        half_str = half_str.lstrip('0')
        
        if not half_str:
            # 若前半部分全是 0 或为空，则结果只能是单个最大奇数数字或 "0"
            return middle if middle else '0'
        
        return half_str + middle + half_str[::-1]
```

### 方法二：更简洁版

```python
from collections import Counter

class Solution:
    def largestPalindromic(self, num: str) -> str:
        cnt = Counter(num)
        
        # 前半部分：从大到小，每个数字用 count//2 次
        half = ''.join(d * (cnt[d] // 2) for d in '9876543210')
        # 去前导零
        half = half.lstrip('0') or ''
        
        # 中间：最大的出现奇数次的数字
        mid = max((d for d in cnt if cnt[d] % 2 == 1), default='')
        
        if not half:
            return mid or '0'
        
        return half + mid + half[::-1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(1)（10 种数字） |

## 关键点总结

1. 从大到小贪心选取成对数字构建前半部分，保证最大值。
2. 中间位选最大的出现奇数次的数字。
3. 处理前导零：若前半部分去零后为空，则结果只有中间位。

## 易错点

- 若只有 0 出现（如 `"000"`），结果应为 `"0"` 而不是 `"000"`。
- 前导零处理：`lstrip('0')` 后若为空，说明前半全为 0。
- 结果不能为空字符串，至少返回 `"0"` 或中间单个数字。
