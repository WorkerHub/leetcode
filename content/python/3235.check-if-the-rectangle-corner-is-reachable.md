## 题目描述

给你两个正整数 `xCorner` 和 `yCorner` 以及一个二维整数数组 `circles`，其中 `circles[i] = [xi, yi, ri]` 表示第 `i` 个圆的圆心和半径。

判断是否存在一条从 `(0, 0)` 到 `(xCorner, yCorner)` 的路径，使得路径不穿过任何圆（路径可以接触圆的边界）。

路径必须保持在矩形 `[0, xCorner] x [0, yCorner]` 内。

**示例 1：**
```
输入：xCorner = 3, yCorner = 4, circles = [[2,1,1]]
输出：true
```

**示例 2：**
```
输入：xCorner = 3, yCorner = 3, circles = [[1,1,2]]
输出：false
```

**提示：**
- `1 <= xCorner, yCorner <= 10^9`
- `1 <= circles.length <= 1000`
- `circles[i].length == 3`
- `1 <= xi, yi, ri <= 10^9`

## 解题思路

关键思路：路径不可达当且仅当存在一条圆的"障碍链"，将从 `(0,0)` 出发的路径切断。

具体地：路径从左下到右上不可达，等价于圆与圆、圆与上边界、圆与左边界形成一条连续的"屏障"，将矩形分为两个不连通的区域。

用**并查集**：
- 若两圆相交（圆心距 <= r1 + r2），则合并
- 虚拟节点：左边界（x=0）和上边界（y=yCorner）
- 若某圆与左边界和上边界都相连，则路径被切断

具体：
- 圆与左边界相交：`x - r <= 0`，即 `x <= r`
- 圆与上边界相交：`y + r >= yCorner`，即 `y >= yCorner - r`
- 圆与下边界相交：`y - r <= 0`
- 圆与右边界相交：`x + r >= xCorner`

路径不可达 = 左边界和上边界在同一集合，或者 下边界和右边界在同一集合（两种切断方式）。

另外还需要检查圆是否覆盖了起点 `(0,0)` 或终点 `(xCorner, yCorner)`。

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class Solution:
    def canReachCorner(self, xCorner: int, yCorner: int, circles: List[List[int]]) -> bool:
        n = len(circles)
        parent = list(range(n + 2))
        # n: 左边界+上边界（障碍链1的虚拟节点）
        # n+1: 下边界+右边界（障碍链2的虚拟节点）
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py
        
        def circles_intersect(i, j):
            x1, y1, r1 = circles[i]
            x2, y2, r2 = circles[j]
            # 使用平方避免浮点
            return (x1 - x2) ** 2 + (y1 - y2) ** 2 <= (r1 + r2) ** 2
        
        # 检查起点和终点是否在圆内（严格内部）
        for x, y, r in circles:
            if x * x + y * y < r * r:  # 起点 (0,0) 在圆内
                return False
            if (x - xCorner) ** 2 + (y - yCorner) ** 2 < r * r:  # 终点在圆内
                return False
        
        for i in range(n):
            x, y, r = circles[i]
            # 圆是否与左边界或上边界相交
            touch_left_top = (x <= r) or (y + r >= yCorner)
            # 圆是否与下边界或右边界相交
            touch_bottom_right = (y <= r) or (x + r >= xCorner)
            
            if touch_left_top:
                union(i, n)
            if touch_bottom_right:
                union(i, n + 1)
            
            for j in range(i + 1, n):
                if circles_intersect(i, j):
                    union(i, j)
        
        return find(n) != find(n + 1)
```

## 复杂度分析

- 时间复杂度：O(n^2 * alpha(n))，枚举所有圆对
- 空间复杂度：O(n)

## 关键点总结

1. 路径不可达 = 存在圆的障碍链将矩形切断
2. 用并查集合并相交的圆，以及与边界相交的圆
3. 路径被切断 = 左上边界虚拟节点和右下边界虚拟节点在同一集合

## 易错点

1. 用整数平方避免浮点精度问题
2. 要检查起点和终点是否被圆覆盖（严格内部）
3. 圆与边界相交的判断要细致（上下左右四条边）
