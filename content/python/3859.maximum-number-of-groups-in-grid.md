## 题目描述

给你一个 `m x n` 的矩阵，你需要将矩阵中的所有单元格分成若干组，使得每组内的单元格数量严格递增（第 1 组 1 个，第 2 组 2 个，第 3 组 3 个...）。

返回最多可以分成的组数。

**示例 1：**

```
输入：m = 2, n = 3
输出：3
解释：6 个格子分成 1+2+3=6，恰好 3 组。
```

**示例 2：**

```
输入：m = 1, n = 1
输出：1
解释：只有 1 个格子，最多 1 组。
```

**提示：**
- `1 <= m, n <= 10^5`
- `m * n <= 10^12`

## 解题思路

设最多分 k 组，则需要的格子总数为 `1 + 2 + ... + k = k*(k+1)/2`。

需要满足 `k*(k+1)/2 <= m*n`。

用二分查找找最大的 k 满足此条件。

## Python 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def maximumGroups(self, m: int, n: int) -> int:
        total = m * n

        # 找最大 k 使得 k*(k+1)/2 <= total
        lo, hi = 1, int((2 * total) ** 0.5) + 2

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if mid * (mid + 1) // 2 <= total:
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：数学公式直接求解

```python
import math

class Solution:
    def maximumGroups(self, m: int, n: int) -> int:
        total = m * n
        # k*(k+1)/2 <= total => k^2 + k - 2*total <= 0
        # k = (-1 + sqrt(1 + 8*total)) / 2
        k = int((-1 + math.sqrt(1 + 8 * total)) / 2)
        # 验证并调整（浮点误差）
        while (k + 1) * (k + 2) // 2 <= total:
            k += 1
        return k
```

## 复杂度分析

- 时间复杂度：O(log(sqrt(mn))) = O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 最多 k 组的充要条件：`k*(k+1)/2 <= m*n`。
2. 二分查找上界设为 `sqrt(2*mn)`，因为最大 k 约为这个量级。
3. 数学公式直接求解，但需注意浮点误差，用整数验证。

## 易错点

1. m * n 可能超过 int 范围（最大 10^12），Python 自动处理大整数，不需要担心。
2. 浮点计算 `sqrt` 可能有误差，需验证和调整。
