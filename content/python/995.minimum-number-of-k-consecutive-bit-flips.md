## 题目描述

给你一个二进制数组 nums 和一个整数 k。

k 位翻转就是从 nums 中选择一个长度为 k 的子数组，同时把子数组中的每一个 0 都改成 1，把子数组中的每一个 1 都改成 0。

返回使数组中不存在 0 的最少 k 位翻转次数。如果不可能，返回 -1。

## Python 代码实现

```python
from typing import List

class Solution:
    def minKBitFlips(self, nums: List[int], k: int) -> int:
        n = len(nums)
        flipped = 0  # 当前位置被翻转的次数（奇偶性）
        result = 0
        is_flipped = [0] * n
        
        for i in range(n):
            if i >= k:
                flipped ^= is_flipped[i - k]
            
            if (nums[i] ^ flipped) == 0:
                # 需要翻转
                if i + k > n:
                    return -1
                
                result += 1
                is_flipped[i] = 1
                flipped ^= 1
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)
