## 题目描述

给定整数数组 `nums` 和整数 `k`，对于每个子数组 `[l, r]`，统计其中满足 `nums[i] % k == 0` 的元素数量。对所有子数组的这个计数求总和。

**示例 1：**
```
输入：nums = [1,2,3,4,5], k = 2
输出：15
解释：能被 2 整除的元素下标为 1(2) 和 3(4)。
     包含 nums[1] 的子数组数量：1*(n-1) = 1*4 = 4（左端点 0 个选择，右端点从 1 到 4）。
     实际：子数组 [0,1],[0,2],[0,3],[0,4],[1,1],[1,2],[1,3],[1,4] 共 8 个包含 nums[1]。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

对于每个位置 `i`，若 `nums[i] % k == 0`，则统计包含 `i` 的子数组数量。

包含下标 `i` 的子数组个数 = `(i + 1) * (n - i)`（左端点有 `i+1` 种选择，右端点有 `n-i` 种选择）。

答案 = `sum((i+1) * (n-i) for i in range(n) if nums[i] % k == 0)`

## Python 代码实现

### 方法一：枚举可整除元素（推荐）

```python
from typing import List

class Solution:
    def countDivisiblePairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = 0

        for i in range(n):
            if nums[i] % k == 0:
                # 包含下标 i 的子数组数量
                total += (i + 1) * (n - i)

        return total
```

### 方法二：前缀和统计

```python
from typing import List

class Solution:
    def countDivisiblePairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # pre[i]: nums[0..i-1] 中能被 k 整除的元素数量
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i+1] = pre[i] + (1 if nums[i] % k == 0 else 0)

        # 对每个子数组 [l,r] 的贡献 = pre[r+1] - pre[l]
        # 总和 = sum over all [l,r] of (pre[r+1] - pre[l])
        # = sum_r sum_l (pre[r+1] - pre[l])
        # = sum_r (r+1) * pre[r+1] - sum_l pre[l] * (n - l)

        total = 0
        for i in range(n):
            if nums[i] % k == 0:
                total += (i + 1) * (n - i)
        return total
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 元素 `i` 的贡献 = 包含 `i` 的子数组数量 × 1（若可整除）
2. 包含下标 `i` 的子数组数量 = `(i+1) * (n-i)`
3. 直接累加即可，无需枚举所有子数组

## 易错点

1. 是统计每个子数组中可整除元素的总个数之和，不是统计子数组数量
2. `(i+1) * (n-i)` 中 `i` 从 0 开始
