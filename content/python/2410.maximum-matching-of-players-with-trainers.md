## 题目描述

给你一个下标从 **0** 开始的整数数组 `players`，其中 `players[i]` 表示第 `i` 名运动员的 **能力** 值，另给你一个下标从 **0** 开始的整数数组 `trainers`，其中 `trainers[j]` 表示第 `j` 名训练师的 **训练能力值**。

如果第 `i` 名运动员的能力值 **小于等于** 第 `j` 名训练师的训练能力值，则第 `i` 名运动员可以 **匹配** 第 `j` 名训练师。每位运动员最多匹配一位训练师，每位训练师最多匹配一位运动员。

返回满足上述要求 `players` 和 `trainers` 之间的 **最大** 匹配数。

**示例 1：**
```
输入：players = [4,7,9], trainers = [8,2,5,8]
输出：2
解释：players[0] 匹配 trainers[0]（4 <= 8），players[1] 匹配 trainers[3]（7 <= 8）。
```

**示例 2：**
```
输入：players = [1,1,1], trainers = [10]
输出：1
```

**提示：**
- `1 <= players.length, trainers.length <= 10^5`
- `1 <= players[i], trainers[j] <= 10^9`

## 解题思路

**贪心 + 双指针：**

将运动员和训练师都排序，然后用双指针贪心匹配：
- 对能力值最小的运动员，用恰好能匹配的（最小的满足条件的）训练师来匹配
- 这样能保证最优（更强的训练师留给能力更强的运动员）

**双指针流程：**
1. 两个数组升序排序
2. `i` 指向当前运动员，`j` 指向当前训练师
3. 若 `players[i] <= trainers[j]`，匹配成功，两指针都前进
4. 否则训练师太弱，训练师指针前进找更强的

## 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def matchPlayersAndTrainers(self, players: List[int], trainers: List[int]) -> int:
        players.sort()
        trainers.sort()

        ans = 0
        j = 0  # 训练师指针

        for p in players:
            # 找第一个能匹配当前运动员的训练师
            while j < len(trainers) and trainers[j] < p:
                j += 1
            if j < len(trainers):
                # 匹配成功
                ans += 1
                j += 1  # 该训练师已被使用

        return ans
```

### 方法二：排序 + 贪心（明确双指针）

```python
from typing import List

class Solution:
    def matchPlayersAndTrainers(self, players: List[int], trainers: List[int]) -> int:
        players.sort()
        trainers.sort()

        i, j = 0, 0
        ans = 0

        while i < len(players) and j < len(trainers):
            if players[i] <= trainers[j]:
                # 当前运动员与当前训练师匹配
                ans += 1
                i += 1  # 运动员已匹配，移到下一个
                j += 1  # 训练师已使用，移到下一个
            else:
                # 训练师太弱，换更强的训练师
                j += 1

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 双指针 | O(n log n + m log m) | O(1) |

其中 n、m 分别为运动员和训练师的数量。

## 关键点总结

1. 排序后双指针贪心，是经典的「二部图最大匹配」的贪心解法
2. 对最弱的运动员，用最弱的满足条件的训练师匹配，不浪费强训练师
3. 训练师指针只向右走，整体复杂度 O(n + m)

## 易错点

- 两个数组都需要排序，单排一个是不够的
- 训练师指针不能倒退，保证每个训练师最多使用一次
