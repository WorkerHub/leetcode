## 题目描述

给定一个二叉树，检查它是否是镜像对称的。

**示例 1：**
```
    1
   / \
  2   2
 / \ / \
3  4 4  3
```
输入：root = [1,2,2,3,4,4,3]
输出：true

**示例 2：**
```
    1
   / \
  2   2
   \   \
   3    3
```
输入：root = [1,2,2,null,3,null,3]
输出：false

**提示：**
- 树中节点数目在范围 [1, 1000] 内
- -100 <= Node.val <= 100

## 解题思路

判断一棵二叉树是否对称，实际上是判断**左子树和右子树是否镜像对称**。

**镜像对称的定义：**
1. 两棵树的根节点值相同
2. 一棵树的左子树与另一棵树的右子树镜像对称
3. 一棵树的右子树与另一棵树的左子树镜像对称

可以使用**递归**或**迭代**两种方法实现。

## Python 代码实现

### 方法一：递归（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        """递归判断二叉树是否对称"""
        if not root:
            return True
        
        return self.isMirror(root.left, root.right)
    
    def isMirror(self, left: Optional[TreeNode], right: Optional[TreeNode]) -> bool:
        """判断两棵树是否镜像对称"""
        # 两个节点都为空，对称
        if not left and not right:
            return True
        
        # 只有一个节点为空，不对称
        if not left or not right:
            return False
        
        # 当前节点值相同，且左子树的左孩子与右子树的右孩子镜像
        # 左子树的右孩子与右子树的左孩子镜像
        return (left.val == right.val and 
                self.isMirror(left.left, right.right) and 
                self.isMirror(left.right, right.left))
```

### 方法二：迭代（使用队列）

```python
from typing import Optional
from collections import deque

class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        """使用队列迭代判断二叉树是否对称"""
        if not root:
            return True
        
        # 使用队列存储需要比较的节点对
        queue = deque([(root.left, root.right)])
        
        while queue:
            left, right = queue.popleft()
            
            # 两个节点都为空，继续下一对
            if not left and not right:
                continue
            
            # 只有一个节点为空，或值不相等，不对称
            if not left or not right or left.val != right.val:
                return False
            
            # 将需要比较的子节点对加入队列
            # 左子树的左孩子 vs 右子树的右孩子
            queue.append((left.left, right.right))
            # 左子树的右孩子 vs 右子树的左孩子
            queue.append((left.right, right.left))
        
        return True
```

### 方法三：迭代（使用栈）

```python
from typing import Optional

class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        """使用栈迭代判断二叉树是否对称"""
        if not root:
            return True
        
        stack = [(root.left, root.right)]
        
        while stack:
            left, right = stack.pop()
            
            if not left and not right:
                continue
            
            if not left or not right or left.val != right.val:
                return False
            
            # 注意入栈顺序
            stack.append((left.left, right.right))
            stack.append((left.right, right.left))
        
        return True
```

## 复杂度分析

**方法一：递归**
- 时间复杂度：O(n)，其中 n 是树中节点总数，需要遍历每个节点一次
- 空间复杂度：O(h)，其中 h 是树的高度，递归调用栈的深度。最坏情况下（树完全不平衡）为 O(n)，最好情况下（完全平衡）为 O(log n)

**方法二/三：迭代**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，队列或栈中最多存储 n/2 个节点（最底层）

## 关键点总结

1. **对称性转化**：树的对称 → 左右子树镜像对称
2. **递归三要素**：
   - 终止条件：两节点都为空（对称）或只有一个为空（不对称）
   - 返回值：bool 类型表示是否镜像
   - 递归逻辑：值相同 && 交叉比较子树
3. **迭代方法**：使用队列/栈存储待比较的节点对
4. **注意顺序**：左.left vs 右.right，左.right vs 右.left

## 易错点

1. **忘记交叉比较**：应该是 left.left vs right.right，不是 left.left vs right.left
2. **边界条件处理**：要先判断节点是否为空，再访问 val 属性
3. **根节点处理**：根节点本身不需要判断，直接判断其左右子树是否镜像
