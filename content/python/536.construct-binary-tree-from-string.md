## 题目描述

你需要从一个由括号和整数组成的字符串构建一棵二叉树。

整个输入表示一棵二叉树。它包含一个整数，后面跟着零个、一个或两对括号。整数表示根节点的值，一对括号内表示同样结构的子二叉树。

如果存在左子节点，你总是先构建父节点的左子节点。

**示例 1：**

![](https://fastly.jsdelivr.net/gh/doocs/leetcode@main/solution/0500-0599/0536.Construct%20Binary%20Tree%20from%20String/images/butree.jpg)

```
输入: s = "4(2(3)(1))(6(5))"
输出: [4,2,6,3,1,5]
解释:
      4
    /   \
   2     6
  / \   /
 3   1 5
```

**示例 2：**
```
输入: s = "4(2(3)(1))(6(5)(7))"
输出: [4,2,6,3,1,5,7]
```

**示例 3：**
```
输入: s = "-4(2(3)(1))(6(5)(7))"
输出: [-4,2,6,3,1,5,7]
```

**提示：**
- `0 <= s.length <= 3 * 10^4`
- `s` 只包含数字、`'('`、`')'` 和 `'-'`
- 树中所有节点的值最多为 `2^30`

## 解题思路

这道题需要从字符串表示解析出二叉树结构。关键是理解字符串的格式规则。

**字符串格式规则：**

```
value               -> 只有根节点
value(left)         -> 有左子树，无右子树
value()(right)      -> 无左子树，有右子树（空括号表示左子树为空）
value(left)(right)  -> 有左右子树
```

**核心思想：**

使用递归（DFS）解析字符串，关键步骤：

1. **提取根节点值**：从字符串开头到第一个 `'('` 之前
2. **找到左子树字符串**：第一对匹配的括号内的内容
3. **找到右子树字符串**：第二对匹配的括号内的内容
4. **递归构建**：对左右子树字符串递归调用构建函数

**括号匹配技巧：**

使用计数器 `cnt` 跟踪括号平衡：
- 遇到 `'('`：`cnt++`
- 遇到 `')'`：`cnt--`
- 当 `cnt == 0` 时，找到一对匹配的括号

**算法流程：**

```python
def str2tree(s):
    1. 如果 s 为空，返回 None
    2. 找到第一个 '(' 的位置 p
    3. 如果没有 '('，s 是纯数字，创建叶子节点返回
    4. 提取 s[:p] 作为根节点值
    5. 使用括号计数找到左右子树的字符串范围
    6. 递归构建左右子树
    7. 返回根节点
```

## Python 代码实现

### 方法一：递归 + 括号匹配（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        """
        使用递归和括号匹配构建二叉树
        时间复杂度 O(n)，空间复杂度 O(n)
        """
        def dfs(s: str) -> Optional[TreeNode]:
            # 基础情况：空字符串返回 None
            if not s:
                return None
            
            # 找到第一个 '(' 的位置
            p = s.find('(')
            
            # 如果没有括号，说明是叶子节点
            if p == -1:
                return TreeNode(int(s))
            
            # 提取根节点值
            root = TreeNode(int(s[:p]))
            
            # 使用括号计数找到左右子树的范围
            start = p  # 记录子树字符串的起始位置
            cnt = 0    # 括号计数器
            
            for i in range(p, len(s)):
                if s[i] == '(':
                    cnt += 1
                elif s[i] == ')':
                    cnt -= 1
                
                # 当括号平衡时，找到一个完整的子树
                if cnt == 0:
                    if start == p:
                        # 第一次括号平衡，是左子树
                        root.left = dfs(s[start + 1:i])
                        start = i + 1
                    else:
                        # 第二次括号平衡，是右子树
                        root.right = dfs(s[start + 1:i])
            
            return root
        
        return dfs(s)
```

### 方法二：迭代 + 栈

```python
from typing import Optional

class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        """
        使用栈模拟递归过程
        更直观地展示构建过程
        """
        if not s:
            return None
        
        stack = []
        i = 0
        
        while i < len(s):
            if s[i] == ')':
                # 遇到 ')'，弹出栈顶元素
                stack.pop()
                i += 1
            elif s[i] == '(':
                # 遇到 '('，跳过
                i += 1
            else:
                # 解析数字（可能是负数或多位数）
                j = i
                if s[i] == '-':
                    i += 1
                while i < len(s) and s[i].isdigit():
                    i += 1
                
                # 创建节点
                node = TreeNode(int(s[j:i]))
                
                if stack:
                    # 如果栈不为空，当前节点是栈顶节点的子节点
                    parent = stack[-1]
                    if parent.left is None:
                        parent.left = node
                    else:
                        parent.right = node
                
                # 当前节点入栈
                stack.append(node)
        
        return stack[0] if stack else None
```

### 方法三：详细注释版（适合初学者）

```python
from typing import Optional

class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        """
        最详细的实现，包含每个步骤的解释
        """
        def build_tree(s: str) -> Optional[TreeNode]:
            """
            从字符串构建二叉树的递归函数
            
            参数：
                s: 字符串，格式为 "value(left)(right)"
            
            返回：
                构建的二叉树根节点
            
            示例：
                s = "4(2(3)(1))(6(5))"
                第一步：提取根值 "4"
                第二步：找到左子树 "2(3)(1)"
                第三步：找到右子树 "6(5)"
                第四步：递归构建左右子树
            """
            # 基础情况 1: 空字符串
            if not s:
                return None
            
            # 步骤 1: 找到第一个左括号的位置
            # 示例: "4(2)(6)" -> p = 1
            left_paren_pos = s.find('(')
            
            # 基础情况 2: 没有括号，说明只有一个数字（叶子节点）
            # 示例: "3" -> 返回 TreeNode(3)
            if left_paren_pos == -1:
                return TreeNode(int(s))
            
            # 步骤 2: 提取根节点的值
            # 示例: "4(2)(6)" -> root_val = "4" -> TreeNode(4)
            root_val = int(s[:left_paren_pos])
            root = TreeNode(root_val)
            
            # 步骤 3: 使用括号计数找到左右子树的字符串
            start = left_paren_pos  # 子树字符串的起始位置
            cnt = 0                  # 括号平衡计数器
            
            # 遍历字符串，找到匹配的括号
            for i in range(left_paren_pos, len(s)):
                char = s[i]
                
                # 遇到左括号，计数加 1
                if char == '(':
                    cnt += 1
                # 遇到右括号，计数减 1
                elif char == ')':
                    cnt -= 1
                
                # 当计数为 0 时，找到一对匹配的括号
                if cnt == 0:
                    if start == left_paren_pos:
                        # 第一对括号是左子树
                        # 示例: "4(2(3)(1))(6)" 中的 "(2(3)(1))"
                        left_subtree_str = s[start + 1:i]
                        root.left = build_tree(left_subtree_str)
                        
                        # 更新 start 为下一对括号的起始位置
                        start = i + 1
                    else:
                        # 第二对括号是右子树
                        # 示例: "4(2)(6(5))" 中的 "(6(5))"
                        right_subtree_str = s[start + 1:i]
                        root.right = build_tree(right_subtree_str)
            
            return root
        
        return build_tree(s)
```

### 方法四：正则表达式解析（进阶）

```python
import re
from typing import Optional

class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        """
        使用正则表达式辅助解析
        适合处理复杂格式
        """
        if not s:
            return None
        
        def dfs(s: str) -> Optional[TreeNode]:
            if not s:
                return None
            
            # 匹配第一个数字（包括负数）
            match = re.match(r'-?\d+', s)
            if not match:
                return None
            
            val = int(match.group())
            root = TreeNode(val)
            
            # 如果只有数字，没有括号
            if len(s) == match.end():
                return root
            
            # 找到左右子树
            start = match.end()
            if start < len(s) and s[start] == '(':
                cnt = 0
                for i in range(start, len(s)):
                    if s[i] == '(':
                        cnt += 1
                    elif s[i] == ')':
                        cnt -= 1
                    if cnt == 0:
                        root.left = dfs(s[start + 1:i])
                        if i + 1 < len(s):
                            root.right = dfs(s[i + 2:-1])
                        break
            
            return root
        
        return dfs(s)
```

## 复杂度分析

### 方法一：递归 + 括号匹配
- **时间复杂度**：O(n²)
  - 每次递归需要遍历字符串找括号：O(n)
  - 递归深度最多为树高：O(n)
  - 总体：O(n²)
- **空间复杂度**：O(n)
  - 递归调用栈：O(树高) = O(n)
  - 字符串切片：O(n)

### 方法二：迭代 + 栈
- **时间复杂度**：O(n)，只需一次遍历字符串
- **空间复杂度**：O(n)，栈的大小最多为树高

**推荐使用方法一或方法二**，代码清晰易懂。

## 关键点总结

1. **括号匹配技巧**：使用计数器 `cnt` 跟踪括号平衡状态
2. **字符串切片**：提取子树字符串 `s[start+1:i]`（去掉外层括号）
3. **处理负数**：`int()` 函数自动处理负号
4. **左右子树的区分**：第一对匹配括号是左子树，第二对是右子树
5. **空子树表示**：`()` 表示空左子树，需要跳过

## 易错点

1. **忘记去掉括号**
   ```python
   # 错误：包含括号
   root.left = dfs(s[start:i])  # 包含 '(' 和 ')'
   
   # 正确：去掉外层括号
   root.left = dfs(s[start + 1:i])  # 只取括号内的内容
   ```

2. **括号计数初始值错误**
   ```python
   # 错误：从 0 开始
   for i in range(p, len(s)):
       cnt = 0  # 错误：每次循环都重置
   
   # 正确：在循环外初始化
   cnt = 0
   for i in range(p, len(s)):
       # 累加计数
   ```

3. **处理负数时索引错误**
   ```python
   # 需要考虑负号
   s = "-4(2)(6)"
   # 第一个 '(' 在索引 2，不是 1
   ```

4. **空字符串处理**
   ```python
   # 必须处理空字符串
   if not s:
       return None
   ```

5. **区分左右子树**
   ```python
   # 需要标记是第一次还是第二次括号平衡
   if start == p:
       # 第一次：左子树
   else:
       # 第二次：右子树
   ```
