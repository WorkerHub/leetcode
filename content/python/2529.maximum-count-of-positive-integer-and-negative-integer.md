## 题目描述

给你一个按 **非递减顺序** 排列的数组 `nums`，返回正整数数目和负整数数目中的 **最大值**。

- 换句话说，如果 `nums` 中正整数的数目是 `pos`，负整数的数目是 `neg`，返回 `max(pos, neg)`。

**注意：** 0 既不是正整数也不是负整数。

**示例 1：**

```
输入：nums = [-2,-1,-1,1,2,3]
输出：3
解释：正整数数目为 3，负整数数目为 2，返回 max(3, 2) = 3。
```

**示例 2：**

```
输入：nums = [-3,-2,-1,0,0,1,2]
输出：3
```

**示例 3：**

```
输入：nums = [5,20,66,1314]
输出：4
```

**提示：**

- `1 <= nums.length <= 2000`
- `-2000 <= nums[i] <= 2000`
- `nums` 按非递减顺序排列

## 解题思路

由于数组有序，可以用二分查找确定负数和正数的边界：
- 负整数数目 = 第一个 >= 0 的位置
- 正整数数目 = n - 第一个 > 0 的位置（即第一个 >= 1 的位置）

也可以直接计数，O(n) 扫描即可。

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumCount(self, nums: List[int]) -> int:
        # 负整数：< 0，即下标 [0, first_non_negative)
        neg = bisect.bisect_left(nums, 0)
        # 正整数：> 0，即下标 [first_positive, n)
        pos = len(nums) - bisect.bisect_right(nums, 0)
        return max(neg, pos)
```

### 方法二：线性计数

```python
from typing import List

class Solution:
    def maximumCount(self, nums: List[int]) -> int:
        neg = sum(1 for x in nums if x < 0)
        pos = sum(1 for x in nums if x > 0)
        return max(neg, pos)
```

## 复杂度分析

- 方法一时间复杂度：O(log n)，二分查找
- 方法二时间复杂度：O(n)，线性扫描
- 空间复杂度：O(1)

## 关键点总结

1. `bisect_left(nums, 0)` 返回第一个 >= 0 的位置，即负数的数目
2. `bisect_right(nums, 0)` 返回第一个 > 0 的位置，n 减去它即为正数数目
3. 0 既不算正也不算负，需要跳过

## 易错点

1. 使用 `bisect_left` 和 `bisect_right` 区分 < 0 和 > 0 的边界
2. 注意 `bisect_left(nums, 0)` 找的是 0 的左边界（即 < 0 的数量）
3. `bisect_right(nums, 0)` 找的是 0 的右边界（0 之后第一个位置）
