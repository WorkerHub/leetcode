## 题目描述

给你一个 32 位的有符号整数 `x`，返回将 `x` 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 `[−2^31, 2^31 − 1]`，就返回 0。

假设环境不允许存储 64 位整数（有符号或无符号）。

**示例 1：**
```
输入：x = 123
输出：321
```

**示例 2：**
```
输入：x = -123
输出：-321
```

**示例 3：**
```
输入：x = 120
输出：21
```

**提示：**
- `-2^31 <= x <= 2^31 - 1`

## 解题思路

这道题的核心是：
1. 将整数的数字部分反转
2. 检查反转后是否溢出

关键观察：
- Python 的整数没有大小限制，所以可以直接反转后检查范围
- 负数需要单独处理符号
- 反转可以通过数学方法（每次取余数）或字符串方法

## Python 代码实现

### 方法一：数学方法（推荐）

```python
class Solution:
    def reverse(self, x: int) -> int:
        # 定义32位整数范围
        INT_MIN, INT_MAX = -2**31, 2**31 - 1
        
        # 记录符号
        sign = 1 if x >= 0 else -1
        x = abs(x)
        
        # 反转数字
        result = 0
        while x != 0:
            # 取最后一位数字
            digit = x % 10
            # 去掉最后一位
            x //= 10
            # 将数字添加到结果中
            result = result * 10 + digit
        
        # 恢复符号
        result *= sign
        
        # 检查是否溢出
        if result < INT_MIN or result > INT_MAX:
            return 0
        
        return result
```

### 方法二：字符串方法（简化版）

```python
class Solution:
    def reverse(self, x: int) -> int:
        # 定义32位整数范围
        INT_MIN, INT_MAX = -2**31, 2**31 - 1
        
        # 转换为字符串处理
        s = str(abs(x))
        # 反转字符串
        reversed_s = s[::-1]
        # 转回整数
        result = int(reversed_s)
        
        # 恢复符号
        if x < 0:
            result = -result
        
        # 检查溢出
        if result < INT_MIN or result > INT_MAX:
            return 0
        
        return result
```

### 方法三：提前检查溢出

```python
class Solution:
    def reverse(self, x: int) -> int:
        INT_MIN, INT_MAX = -2**31, 2**31 - 1
        
        sign = 1 if x >= 0 else -1
        x = abs(x)
        
        result = 0
        while x != 0:
            digit = x % 10
            x //= 10
            
            # 提前检查是否会溢出
            # 如果 result > INT_MAX // 10，则 result * 10 会溢出
            # 如果 result == INT_MAX // 10 且 digit > 7，则也会溢出
            if result > INT_MAX // 10:
                return 0
            if result == INT_MAX // 10 and digit > 7:
                return 0
            
            result = result * 10 + digit
        
        result *= sign
        
        # 最后还需要检查负数溢出
        if result < INT_MIN:
            return 0
        
        return result
```

## 复杂度分析

**方法一和方法三：**
- 时间复杂度：O(log x)，x 有多少位就需要循环多少次
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(log x)
- 空间复杂度：O(log x)，需要存储字符串

## 关键点总结

1. **溢出检查**：必须在反转前或反转后检查是否超出 32 位整数范围
2. **符号处理**：负数需要单独记录符号，处理绝对值后再恢复
3. **数学反转**：通过 `%` 取最后一位，`//` 去掉最后一位
4. **边界情况**：特别注意 `INT_MIN` 和 `INT_MAX` 的边界

## 易错点

1. **忘记检查溢出**：题目明确要求超出范围返回 0
2. **负数处理错误**：直接对负数取余会得到负数，容易出错
3. **溢出检查时机**：
   - 方法一在反转后检查（简单但不符合"不能存储64位整数"的严格要求）
   - 方法三在反转过程中检查（更严格）
4. **Python 特性**：Python 整数无限大，容易忽略溢出问题
