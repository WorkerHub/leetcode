## 题目描述

给你一个整数数组 `nums` 和两个正整数 `k` 和 `m`。

返回从 `nums` 中选取 `k` 个**不重叠**且每个长度**至少为 m** 的子数组，使其元素之和**最大**。

**示例 1：**

```
输入：nums = [1,2,3,-1,2,4,1], k = 2, m = 2
输出：14
解释：选 [2,3] 和 [2,4,1]，和 5+7=12... 
选 [2,3,-1,2,4] 和...
```

**提示：**
- `1 <= nums.length <= 2000`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= floor(nums.length / m)`
- `1 <= m <= floor(nums.length / k)`

## 解题思路

DP：`dp[i][j]` = 从 `nums[0..i-1]` 中选 j 个不重叠、长度 >= m 的子数组的最大和。

转移：
- 不选以位置 i-1 结尾的子数组：`dp[i][j] = dp[i-1][j]`
- 选以位置 i-1 结尾、长度 >= m 的子数组（子数组 [l, i-1]，l <= i-m）：
  `dp[i][j] = max(dp[l][j-1] + sum(nums[l..i-1])) for l in [0, i-m]`

用前缀和计算区间和，优化内层转移。

## Python 代码实现

### 方法一：DP + 前缀和

```python
from typing import List

class Solution:
    def maxSumOfKSubarrays(self, nums: List[int], k: int, m: int) -> int:
        n = len(nums)

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        def range_sum(l, r):
            """sum(nums[l..r])"""
            return prefix[r + 1] - prefix[l]

        NEG_INF = float('-inf')

        # dp[i][j]: nums[0..i-1] 中选 j 个子数组的最大和
        # i in 0..n, j in 0..k
        dp = [[NEG_INF] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0
        for i in range(1, n + 1):
            dp[i][0] = 0

        for j in range(1, k + 1):
            # 维护 max(dp[l][j-1] - prefix[l]) for l in 0..i-m
            # sum(nums[l..i-1]) = prefix[i] - prefix[l]
            # dp[l][j-1] + prefix[i] - prefix[l] = prefix[i] + (dp[l][j-1] - prefix[l])

            max_prev = NEG_INF

            for i in range(1, n + 1):
                # 不选以 i 结尾的子数组
                if dp[i-1][j] != NEG_INF:
                    dp[i][j] = max(dp[i][j], dp[i-1][j])

                # 更新 max_prev：在 i-m 时，可以用 dp[i-m][j-1] - prefix[i-m]
                if i >= m:
                    l = i - m
                    if dp[l][j-1] != NEG_INF:
                        val = dp[l][j-1] - prefix[l]
                        max_prev = max(max_prev, val)

                # 选以位置 i-1 结尾的子数组
                if max_prev != NEG_INF:
                    dp[i][j] = max(dp[i][j], max_prev + prefix[i])

        return dp[n][k]
```

### 方法二：空间优化版

```python
from typing import List

class Solution:
    def maxSumOfKSubarrays(self, nums: List[int], k: int, m: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        NEG_INF = float('-inf')

        # 滚动数组
        prev = [0] + [NEG_INF] * n  # prev[i] = dp[i][j-1]

        for j in range(1, k + 1):
            curr = [NEG_INF] * (n + 1)
            curr[0] = NEG_INF
            max_prev = NEG_INF

            for i in range(1, n + 1):
                # 不选
                curr[i] = curr[i - 1]

                # 更新 max_prev
                if i >= m:
                    l = i - m
                    if prev[l] != NEG_INF:
                        max_prev = max(max_prev, prev[l] - prefix[l])

                # 选
                if max_prev != NEG_INF:
                    curr[i] = max(curr[i], max_prev + prefix[i])

            prev = curr

        return prev[n]
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(n)（滚动数组）

## 关键点总结

1. 转移优化：用 `dp[l][j-1] + prefix[i] - prefix[l]` = `prefix[i] + (dp[l][j-1] - prefix[l])`
2. 维护 `max(dp[l][j-1] - prefix[l])` 随 i 增大逐步更新
3. 前缀和快速计算区间和

## 易错点

1. 子数组长度至少 m，所以 l <= i-m（最短子数组从 l 到 i-1，长度 m）
2. max_prev 在 i >= m 时才开始更新
3. `curr[i] = curr[i-1]` 表示不选以 i 结尾的子数组（继承前面的最优解）
