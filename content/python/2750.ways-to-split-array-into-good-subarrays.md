## 题目描述

给你一个 **二进制** 数组 `nums`，如果一个子数组 **恰好** 包含一个值为 1 的元素，则该子数组为 **好子数组**。

将 `nums` 分割成若干 **好子数组** 的方案数（对 `10^9 + 7` 取模）。

**示例 1：**
```
输入：nums = [0,1,0,0,1]
输出：3
解释：3 种分法，每个子数组恰含 1 个 1
```

**示例 2：**
```
输入：nums = [0,1,0]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i]` 是 0 或 1

## 解题思路

分割方案数等于相邻两个 1 之间（不含两端的 1）的 0 的个数 + 1 的乘积。

若相邻两个 1 的位置为 `pos[i]` 和 `pos[i+1]`，则它们之间的间隔（0 的个数 + 1）= `pos[i+1] - pos[i]`，这段可以在任何位置切割（`pos[i+1] - pos[i]` 种选择）。

所有间隔的选择数乘起来即为答案。

## Python 代码实现

### 方法一：统计 1 的位置（推荐）

```python
from typing import List

class Solution:
    def numberOfGoodSubarraySplits(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        # 若没有 1，无法分割
        ones = [i for i, x in enumerate(nums) if x == 1]
        if not ones:
            return 0

        ans = 1
        for i in range(1, len(ones)):
            # 相邻两个 1 之间的间距（切割点数 = 间距）
            ans = ans * (ones[i] - ones[i - 1]) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（存储 1 的位置）

## 关键点总结

1. 好的分割必须保证每段恰好有一个 1
2. 相邻两个 1 之间的 0 串可以任意分割，有 `gap` 种方式（`gap = pos[i+1] - pos[i]`）
3. 各段独立，方案数相乘

## 易错点

1. 若数组中没有 1，不存在好的分割，返回 0
2. 若只有一个 1，只有 1 种分割，答案为 1
