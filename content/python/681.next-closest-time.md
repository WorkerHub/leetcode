## 题目描述

给定一个形如 "HH:MM" 的时间 time，找出能够由给定数字重新组合得到的下一个最近时间。

每个数字都可以被无限次使用。你可以假设给定的字符串是一个有效的时间，小时在 00-23 之间，分钟在 00-59 之间。

**示例 1：**
```
输入：time = "19:34"
输出："19:39"
解释：下一个最近时间是使用数字1, 9, 3, 4组成的"19:39"
```

**示例 2：**
```
输入：time = "23:59"
输出："22:22"
解释：下一个最近时间是明天的"22:22"（循环到第二天）
```

**提示：**
- time 是有效的 24 小时制时间
- time.length == 5

## 解题思路

这道题可以通过枚举或模拟来解决。

**核心思想：**
只能使用time中出现的数字，找到下一个最接近的有效时间。

**方法一：暴力枚举**
- 从当前时间开始，每次加1分钟
- 检查新时间的数字是否都在给定数字集合中
- 最多枚举 24*60 = 1440 次

**方法二：构造法**
- 从右到左尝试替换每一位
- 用集合中大于当前位的最小数字替换
- 如果无法替换，进位到下一位

## Python 代码实现

### 方法一：暴力枚举（推荐）⭐

```python
class Solution:
    def nextClosestTime(self, time: str) -> str:
        # 提取可用的数字
        digits = set(time.replace(':', ''))
        
        # 转换为分钟数
        hour, minute = map(int, time.split(':'))
        current = hour * 60 + minute
        
        # 枚举接下来的每一分钟
        for i in range(1, 24 * 60 + 1):
            next_time = (current + i) % (24 * 60)
            h = next_time // 60
            m = next_time % 60
            
            # 检查时间的每一位是否都在可用数字中
            time_str = f"{h:02d}:{m:02d}"
            if all(c in digits for c in time_str if c != ':'):
                return time_str
        
        return time  # 理论上不会到达这里
```

### 方法二：构造法

```python
class Solution:
    def nextClosestTime(self, time: str) -> str:
        digits = sorted(set(time.replace(':', '')))
        time_list = list(time)
        
        # 从右到左尝试增大每一位
        for i in [4, 3, 1, 0]:  # 跳过冒号位置2
            # 找到比当前位大的最小数字
            for d in digits:
                if d > time_list[i]:
                    time_list[i] = d
                    
                    # 右边的位都设为最小数字
                    if i == 0:
                        time_list[1] = digits[0]
                    if i in [0, 1]:
                        time_list[3] = digits[0]
                        time_list[4] = digits[0]
                    elif i == 3:
                        time_list[4] = digits[0]
                    
                    # 检查是否有效
                    result = ''.join(time_list)
                    if self.is_valid(result):
                        return result
        
        # 如果无法增大，返回最小时间
        return digits[0] * 2 + ':' + digits[0] * 2
    
    def is_valid(self, time: str) -> bool:
        """检查时间是否有效"""
        h, m = map(int, time.split(':'))
        return 0 <= h < 24 and 0 <= m < 60
```

### 方法三：生成所有可能时间

```python
class Solution:
    def nextClosestTime(self, time: str) -> str:
        digits = set(time.replace(':', ''))
        
        # 生成所有可能的有效时间
        valid_times = []
        for h1 in digits:
            for h2 in digits:
                for m1 in digits:
                    for m2 in digits:
                        h = int(h1 + h2)
                        m = int(m1 + m2)
                        if h < 24 and m < 60:
                            valid_times.append(h * 60 + m)
        
        valid_times.sort()
        
        # 当前时间（分钟数）
        h, m = map(int, time.split(':'))
        current = h * 60 + m
        
        # 找到下一个时间
        for t in valid_times:
            if t > current:
                return f"{t // 60:02d}:{t % 60:02d}"
        
        # 循环到第二天的最小时间
        return f"{valid_times[0] // 60:02d}:{valid_times[0] % 60:02d}"
```

### 方法四：简洁的枚举

```python
class Solution:
    def nextClosestTime(self, time: str) -> str:
        digits = {int(d) for d in time if d != ':'}
        hour, minute = map(int, time.split(':'))
        
        while True:
            # 下一分钟
            minute += 1
            if minute == 60:
                minute = 0
                hour += 1
                if hour == 24:
                    hour = 0
            
            # 检查是否所有数字都可用
            if all(d in digits for d in [hour // 10, hour % 10, 
                                          minute // 10, minute % 10]):
                return f"{hour:02d}:{minute:02d}"
```

## 复杂度分析

**方法一：暴力枚举**
- 时间复杂度：O(24 × 60) = O(1440)
- 空间复杂度：O(1)

**方法三：生成所有时间**
- 时间复杂度：O(4^4) = O(256)，生成所有可能
- 空间复杂度：O(256)

## 关键点总结

1. **数字复用**：每个数字可以无限次使用
2. **时间循环**：到23:59后循环到00:00
3. **有效性检查**：小时0-23，分钟0-59
4. **格式化输出**：使用02d保证两位数
5. **最多枚举1440次**：一天的分钟数

## 易错点

1. **时间格式**：要保持两位数，如"01:09"
2. **循环处理**：23:59的下一分钟是00:00
3. **无解情况**：题目保证有解（给定时间本身就是一个解）
4. **冒号跳过**：构造时要注意跳过冒号
5. **有效性判断**：生成的时间要检查是否有效
