## 题目描述

给你一个字符数组 `letters`，该数组按非递减顺序排序，以及一个字符 `target`。`letters` 里至少有两个不同的字符。

返回 `letters` 中大于 `target` 的最小的字符。如果不存在这样的字符，则返回 `letters` 的第一个字符。

**示例 1：**
```
输入：letters = ["c","f","j"], target = "a"
输出："c"
解释：letters 中大于 'a' 的最小字符是 'c'。
```

**示例 2：**
```
输入：letters = ["c","f","j"], target = "c"
输出："f"
解释：letters 中大于 'c' 的最小字符是 'f'。
```

**示例 3：**
```
输入：letters = ["x","x","y","y"], target = "z"
输出："x"
解释：letters 中没有大于 'z' 的字符，所以返回第一个字符 'x'。
```

**提示：**
- `2 <= letters.length <= 10^4`
- `letters[i]` 是一个小写字母
- `letters` 按非递减顺序排序
- `letters` 至少包含两个不同的字母
- `target` 是一个小写字母

## 解题思路

这道题是二分查找的经典应用。关键点在于：
1. 数组已经排序
2. 需要找到第一个大于 target 的字符
3. 如果不存在，返回第一个字符（循环特性）

**核心策略：**
- 使用二分查找找到第一个大于 target 的位置
- 注意边界情况：如果所有字符都不大于 target，返回 letters[0]

## Python 代码实现

### 方法一：二分查找（推荐）⭐

```python
from typing import List

class Solution:
    def nextGreatestLetter(self, letters: List[str], target: str) -> str:
        left, right = 0, len(letters) - 1
        
        # 如果 target 大于等于最后一个字符，直接返回第一个
        if target >= letters[-1]:
            return letters[0]
        
        # 二分查找第一个大于 target 的位置
        while left < right:
            mid = (left + right) // 2
            
            if letters[mid] <= target:
                # 当前字符不大于 target，在右半部分查找
                left = mid + 1
            else:
                # 当前字符大于 target，可能是答案，在左半部分继续查找
                right = mid
        
        return letters[left]
```

### 方法二：二分查找（统一模板）

```python
class Solution:
    def nextGreatestLetter(self, letters: List[str], target: str) -> str:
        left, right = 0, len(letters)
        
        while left < right:
            mid = (left + right) // 2
            
            if letters[mid] <= target:
                left = mid + 1
            else:
                right = mid
        
        # 如果 left 越界，返回第一个字符
        return letters[left % len(letters)]
```

### 方法三：线性查找（简单直观）

```python
class Solution:
    def nextGreatestLetter(self, letters: List[str], target: str) -> str:
        # 遍历数组，找到第一个大于 target 的字符
        for letter in letters:
            if letter > target:
                return letter
        
        # 如果没找到，返回第一个字符
        return letters[0]
```

### 方法四：使用 bisect 模块

```python
import bisect

class Solution:
    def nextGreatestLetter(self, letters: List[str], target: str) -> str:
        # bisect_right 返回大于 target 的第一个位置
        index = bisect.bisect_right(letters, target)
        
        # 如果 index 越界，返回第一个字符
        return letters[index % len(letters)]
```

## 复杂度分析

### 二分查找（方法一、二、四）
- **时间复杂度**：O(log n)，其中 n 是数组长度
- **空间复杂度**：O(1)

### 线性查找（方法三）
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **二分查找模板**：查找第一个大于 target 的位置
2. **循环特性**：使用取模 `% len(letters)` 处理越界情况
3. **边界优化**：提前判断 `target >= letters[-1]` 可以减少不必要的二分查找
4. **bisect 模块**：Python 内置的二分查找工具，`bisect_right` 返回大于目标值的第一个位置

## 易错点

1. **等于的情况**：题目要求严格大于，所以 `letters[mid] <= target` 时需要向右查找
2. **循环数组**：所有字符都不大于 target 时，需要返回第一个字符
3. **二分边界**：注意 `left < right` 的终止条件和返回值
4. **空数组**：虽然题目保证至少有 2 个字符，但在实际应用中要注意

## 图解示例

以示例 2 为例：`letters = ["c","f","j"], target = "c"`

```
初始：left = 0, right = 2
      letters = [c, f, j]
                 ↑     ↑
               left  right

第1轮：mid = 1
      letters[1] = 'f' > 'c'
      right = mid = 1
      
      letters = [c, f, j]
                 ↑  ↑
               left right

第2轮：mid = 0
      letters[0] = 'c' <= 'c'
      left = mid + 1 = 1
      
      letters = [c, f, j]
                    ↑
                 left=right

结束：返回 letters[1] = 'f'
```
