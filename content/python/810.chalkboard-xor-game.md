## 题目描述

黑板上写着一个非负整数数组 `nums[i]`。Alice 和 Bob 轮流从黑板上擦掉一个数字，Alice 先手。如果擦除一个数字后，剩余的所有数字按位异或运算得出的结果等于 `0` 的话，当前玩家游戏失败。另外，如果只剩一个数字，按位异或运算得到它本身；如果无数字剩余，按位异或运算结果为 `0`。

并且，轮到某个玩家时，如果当前黑板上所有数字按位异或运算结果等于 `0`，这个玩家获胜。

假设两个玩家每步都使用最优解，当且仅当 Alice 获胜时返回 `true`。

**示例 1:**
```
输入: nums = [1,1,2]
输出: false
解释:
Alice 有两个选择: 擦掉数字 1 或 2。
如果擦掉 1, 数组变成 [1, 2]。剩余数字异或得到 1 XOR 2 = 3。那么 Bob 可以擦掉任意数字，因为 Alice 会成为在没有数字的情况下失败的那一个。
如果 Alice 擦掉 2，那么数组变成[1, 1]。剩余数字异或得到 1 XOR 1 = 0。Alice 仍然会失败。
```

**示例 2:**
```
输入: nums = [0,1]
输出: true
```

**示例 3:**
```
输入: nums = [1,2,3]
输出: true
```

**提示:**
- `1 <= nums.length <= 1000`
- `0 <= nums[i] < 2^16`

## 解题思路

这是一道数学 + 博弈论问题，关键在于找到数学规律，而不是模拟游戏过程。

**关键观察：**

1. **初始异或为 0**：如果开始时所有数字异或为 0，Alice 直接获胜
2. **数组长度为偶数**：如果初始异或不为 0 但数组长度为偶数，Alice 必胜

**数学证明：**

假设数组长度为偶数且初始异或不为 0：
- 设所有数字异或结果为 `xor_sum ≠ 0`
- 对于 Alice 要选择的数字 `nums[i]`，擦除后剩余数字异或为 `xor_sum ^ nums[i]`
- 如果所有的 `xor_sum ^ nums[i]` 都等于 0，则：
  ```
  nums[0] ^ nums[1] ^ ... ^ nums[n-1] ^ (xor_sum ^ nums[0]) ^ (xor_sum ^ nums[1]) ^ ... = 0
  ```
  这将推出 `xor_sum = 0`，矛盾！
- 因此，Alice 总能找到一个数字，擦除后异或不为 0
- 由于长度为偶数，最终 Bob 会面对奇数个数字，Alice 会面对偶数个数字
- 通过归纳，Alice 总能避免失败

**结论：**
Alice 获胜的充要条件是：
1. 初始异或为 0，或
2. 数组长度为偶数

## Python 代码实现

### 方法一：数学结论（推荐）⭐

```python
from typing import List
from functools import reduce
import operator

class Solution:
    def xorGame(self, nums: List[int]) -> bool:
        # Alice 获胜的两种情况：
        # 1. 初始异或为 0
        # 2. 数组长度为偶数
        xor_sum = reduce(operator.xor, nums, 0)
        return xor_sum == 0 or len(nums) % 2 == 0
```

### 方法四：详细注释版本

```python
from typing import List

class Solution:
    def xorGame(self, nums: List[int]) -> bool:
        """
        判断 Alice 是否能获胜
        
        获胜条件：
        1. 初始状态下所有数字异或为 0，Alice 直接获胜
        2. 数组长度为偶数且初始异或不为 0，Alice 也能获胜
        
        原因：如果长度为偶数且异或不为 0，Alice 总能选择一个数
              使得剩余数字异或不为 0，将问题传递给 Bob
        """
        # 计算初始异或值
        xor_sum = 0
        for num in nums:
            xor_sum ^= num
        
        # 检查获胜条件
        if xor_sum == 0:
            # 初始异或为 0，Alice 直接获胜
            return True
        
        if len(nums) % 2 == 0:
            # 长度为偶数，Alice 必胜
            return True
        
        # 其他情况，Alice 失败
        return False
```

## 复杂度分析

- **时间复杂度**：O(n)，需要遍历数组计算异或
- **空间复杂度**：O(1)，只使用常量额外空间

## 关键点总结

1. **博弈论**：不是模拟游戏，而是找数学规律
2. **异或性质**：`a ^ a = 0`, `a ^ 0 = a`, 满足交换律和结合律
3. **奇偶性**：数组长度的奇偶性是关键
4. **数学证明**：通过反证法证明偶数长度时 Alice 必胜
5. **简洁解法**：理解规律后代码非常简单

## 易错点

1. **误以为需要模拟**：不需要真的模拟游戏过程
2. **忽略长度为偶数的情况**：这是隐藏的获胜条件
3. **异或计算错误**：初始值应该是 0
4. **逻辑混淆**：要清楚两个充分条件的"或"关系

## 博弈论分析

**为什么偶数长度时 Alice 必胜？**

假设长度为 `n`（偶数），初始异或为 `S ≠ 0`。

- Alice 可选的数字集合为 `{nums[0], nums[1], ..., nums[n-1]}`
- 如果 Alice 选择 `nums[i]`，剩余异或为 `S ^ nums[i]`
- 假设所有选择都导致异或为 0（Alice 失败）：
  ```
  S ^ nums[0] = 0
  S ^ nums[1] = 0
  ...
  S ^ nums[n-1] = 0
  ```
- 这意味着 `nums[0] = nums[1] = ... = nums[n-1] = S`
- 但 `n` 个相同数字的异或（n 为偶数）应该为 0，与 `S ≠ 0` 矛盾！
- 因此 Alice 必能找到一个选择使得异或不为 0
