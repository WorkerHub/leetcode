## 题目描述

给你两个正整数 `n` 和 `m`，每次操作可以将 `n` 加 1。返回使 `n` 被 `m` 整除所需的最少操作次数。

**示例 1：**

```
输入：n = 10, m = 3
输出：2
解释：10 → 11 → 12，12 % 3 = 0，操作2次
```

**示例 2：**

```
输入：n = 10, m = 10
输出：0
解释：10 % 10 = 0
```

**提示：**

- `1 <= n, m <= 10^9`

## 解题思路

若 `n % m == 0`，返回 0。
否则返回 `m - n % m`（差多少步到下一个 m 的倍数）。

## Python 代码实现

### 方法一：直接计算（推荐）

```python
class Solution:
    def minimumOperations(self, n: int, m: int) -> int:
        remainder = n % m
        if remainder == 0:
            return 0
        return m - remainder
```

### 方法二：使用取模运算

```python
class Solution:
    def minimumOperations(self, n: int, m: int) -> int:
        return (m - n % m) % m
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 下一个 m 的倍数 = `n + (m - n%m)%m`
2. 若已整除返回 0
3. 方法二用模运算统一两种情况

## 易错点

1. 若 `n % m == 0` 时，`m - n%m = m`，需用 `% m` 处理返回 0
2. n 和 m 均为正整数，无需处理负数
