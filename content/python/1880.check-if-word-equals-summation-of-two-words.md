## 题目描述

**字母值** 指的是字母在字母表中的位置（a=0, b=1, ..., z=25）。

给你三个字符串 `firstWord`、`secondWord`、`targetWord`，判断 `firstWord` 和 `secondWord` 按字母值拼接成的数，相加后是否等于 `targetWord` 按字母值拼接成的数。

**示例：**
```
输入：firstWord = "acb", secondWord = "cba", targetWord = "cdb"
输出：true
解释："acb" = 021 = 21，"cba" = 210，21+210=231，"cdb" = 231
```

## 解题思路

将字符串按字母值转化为数字（类似进制转换，每位是 0-25 的数字），然后判断两数之和等于第三数。

## 代码实现

### 方法一：字母值转数字（推荐）

```python
class Solution:
    def isSumEqual(self, firstWord: str, secondWord: str, targetWord: str) -> bool:
        def word_to_num(word: str) -> int:
            """将单词转为对应数字（字母值拼接，每位是 0-25）"""
            result = 0
            for ch in word:
                result = result * 10 + (ord(ch) - ord('a'))
            return result

        return word_to_num(firstWord) + word_to_num(secondWord) == word_to_num(targetWord)
```

### 方法二：使用 join 和 int

```python
class Solution:
    def isSumEqual(self, firstWord: str, secondWord: str, targetWord: str) -> bool:
        def to_num(s: str) -> int:
            return int(''.join(str(ord(c) - ord('a')) for c in s))

        return to_num(firstWord) + to_num(secondWord) == to_num(targetWord)
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为字符串长度
- **空间复杂度**：O(n)，字符串拼接

## 关键点总结

1. 字母值 a=0, b=1, ..., z=25，每个字符对应一个 0-25 的数字
2. 拼接数字（类似十进制，但每位是 0-25，不是 0-9）

## 易错点

- 不是普通十进制，每位是 0-25（单个字符可能是两位数，如 z=25）
- 使用 join 方法时，每个字符的值可能是两位，但整体连接是正确的（如 "az" = "025" = 25）
