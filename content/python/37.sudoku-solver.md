## 题目描述

编写一个程序，通过填充空格来解决数独问题。

数独的解法需遵循如下规则：

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。

数独部分空格内已填入了数字，空白格用 `'.'` 表示。

**示例：**
```
输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]

输出：
[["5","3","4","6","7","8","9","1","2"]
,["6","7","2","1","9","5","3","4","8"]
,["1","9","8","3","4","2","5","6","7"]
,["8","5","9","7","6","1","4","2","3"]
,["4","2","6","8","5","3","7","9","1"]
,["7","1","3","9","2","4","8","5","6"]
,["9","6","1","5","3","7","2","8","4"]
,["2","8","7","4","1","9","6","3","5"]
,["3","4","5","2","8","6","1","7","9"]]
```

## 解题思路

### 核心思想：回溯算法

数独求解是经典的回溯问题。

**算法流程：**
1. 遍历数独的每个空格
2. 尝试填入 1-9
3. 检查是否合法（不违反数独规则）
4. 如果合法，继续递归填下一个空格
5. 如果所有空格都填完，返回 true
6. 如果无法填入任何数字，回溯（撤销当前选择）

**优化技巧：**
- 用三个布尔数组记录每行、每列、每宫格已使用的数字
- 减少重复检查

## Python 代码实现

### 方法一：回溯 + 哈希表

```python
class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        """
        Do not return anything, modify board in-place instead.
        """
        # 记录每行、每列、每宫格已使用的数字
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        
        # 初始化：记录已填入的数字
        for i in range(9):
            for j in range(9):
                if board[i][j] != '.':
                    num = board[i][j]
                    rows[i].add(num)
                    cols[j].add(num)
                    boxes[(i // 3) * 3 + j // 3].add(num)
        
        def backtrack(pos):
            """从位置pos开始填数"""
            if pos == 81:  # 填完所有格子
                return True
            
            i, j = pos // 9, pos % 9
            
            # 如果当前格子已填，跳过
            if board[i][j] != '.':
                return backtrack(pos + 1)
            
            # 尝试填入1-9
            box_index = (i // 3) * 3 + j // 3
            for num in '123456789':
                # 检查是否可以填入
                if num not in rows[i] and num not in cols[j] and num not in boxes[box_index]:
                    # 填入
                    board[i][j] = num
                    rows[i].add(num)
                    cols[j].add(num)
                    boxes[box_index].add(num)
                    
                    # 递归
                    if backtrack(pos + 1):
                        return True
                    
                    # 回溯
                    board[i][j] = '.'
                    rows[i].remove(num)
                    cols[j].remove(num)
                    boxes[box_index].remove(num)
            
            return False
        
        backtrack(0)
```

### 方法二：回溯 + 位运算（优化版）

```python
class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        # 用位掩码记录每行、每列、每宫格可用的数字
        rows = [0] * 9
        cols = [0] * 9
        boxes = [0] * 9
        
        # 初始化
        for i in range(9):
            for j in range(9):
                if board[i][j] != '.':
                    num = int(board[i][j]) - 1
                    bit = 1 << num
                    rows[i] |= bit
                    cols[j] |= bit
                    boxes[(i // 3) * 3 + j // 3] |= bit
        
        def backtrack(pos):
            if pos == 81:
                return True
            
            i, j = pos // 9, pos % 9
            
            if board[i][j] != '.':
                return backtrack(pos + 1)
            
            box_index = (i // 3) * 3 + j // 3
            # 计算可用数字（三个约束的交集）
            available = ~(rows[i] | cols[j] | boxes[box_index]) & 0x1ff
            
            while available:
                # 取最低位的1
                bit = available & -available
                available ^= bit
                
                # 计算数字
                num = bin(bit).count('0') - 1
                
                # 填入
                board[i][j] = str(num + 1)
                rows[i] |= bit
                cols[j] |= bit
                boxes[box_index] |= bit
                
                if backtrack(pos + 1):
                    return True
                
                # 回溯
                board[i][j] = '.'
                rows[i] ^= bit
                cols[j] ^= bit
                boxes[box_index] ^= bit
            
            return False
        
        backtrack(0)
```

### 方法三：递归（更直观的写法）

```python
class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        def isValid(board, row, col, num):
            """检查在(row, col)位置填入num是否合法"""
            # 检查行
            if num in board[row]:
                return False
            
            # 检查列
            for i in range(9):
                if board[i][col] == num:
                    return False
            
            # 检查3×3宫格
            box_row, box_col = 3 * (row // 3), 3 * (col // 3)
            for i in range(box_row, box_row + 3):
                for j in range(box_col, box_col + 3):
                    if board[i][j] == num:
                        return False
            
            return True
        
        def backtrack():
            for i in range(9):
                for j in range(9):
                    if board[i][j] == '.':
                        # 尝试填入1-9
                        for num in '123456789':
                            if isValid(board, i, j, num):
                                board[i][j] = num
                                
                                if backtrack():
                                    return True
                                
                                # 回溯
                                board[i][j] = '.'
                        
                        return False
            
            return True
        
        backtrack()
```

## 复杂度分析

- **时间复杂度**：O(9^m)，m 是空格数量，最坏情况下需要尝试 9^m 种组合
- **空间复杂度**：O(1)，递归深度最多 81，但空间复杂度可以视为常数

## 关键点总结

1. **回溯三步骤**：
   - 选择：尝试填入 1-9
   - 递归：继续填下一个格子
   - 撤销：如果失败，恢复现场

2. **剪枝优化**：
   - 用数组/集合记录已使用的数字
   - 避免重复检查

3. **位运算优化**：
   - 用位掩码表示 1-9 的使用情况
   - 空间更优，速度更快

4. **遍历方式**：
   - 方法一：按位置顺序遍历（0-80）
   - 方法三：嵌套循环遍历

## 易错点

1. **回溯要完整**：
   - 填入数字后要标记
   - 回溯时要取消标记
   - 不能遗漏任何一步

2. **递归终止条件**：
   - 所有格子都填完
   - 或者当前格子无法填入任何数字

3. **宫格索引**：
   - `(i // 3) * 3 + j // 3`

## 优化技巧

1. **优先填约束多的格子**：
   - 先找可选数字最少的格子填
   - 减少回溯次数

2. **位运算优化**：
   - 用位掩码加速
   - 降低常数时间

3. **唯一值优化**：
   - 如果某格子只有一个候选数字，直接填入
