## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32 位整数。

**示例 1：**

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2：**

```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是连续子数组。
```

**提示：**

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何前缀或后缀的乘积都保证是一个 32 位整数

## 解题思路

这道题是第 53 题"最大子数组和"的变体，但乘法有特殊性：
- 负数乘以负数会变成正数
- 最小值遇到负数可能变成最大值

**关键观察：**

1. 如果当前数是正数：
   - 希望之前的乘积越大越好
2. 如果当前数是负数：
   - 希望之前的乘积越小越好（负负得正）
3. 如果当前数是 0：
   - 乘积归零，重新开始

**动态规划思路：**

维护两个状态：
- `max_product`：以当前位置结尾的最大乘积
- `min_product`：以当前位置结尾的最小乘积（可能是负数）

状态转移：
```
max_product = max(nums[i], max_product * nums[i], min_product * nums[i])
min_product = min(nums[i], max_product * nums[i], min_product * nums[i])
```

为什么需要 `min_product`？
- 当前数如果是负数，之前的最小值（负数）乘以它可能得到最大值

## Python 代码实现

### 方法一：动态规划（标准解法，推荐）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 初始化
        max_prod = min_prod = result = nums[0]
        
        # 从第二个元素开始遍历
        for i in range(1, len(nums)):
            num = nums[i]
            
            # 如果当前数是负数，交换 max 和 min
            # 因为负数会让最大变最小，最小变最大
            if num < 0:
                max_prod, min_prod = min_prod, max_prod
            
            # 状态转移
            max_prod = max(num, max_prod * num)
            min_prod = min(num, min_prod * num)
            
            # 更新全局最大值
            result = max(result, max_prod)
        
        return result
```

### 方法二：不交换的写法（更清晰）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        max_prod = min_prod = result = nums[0]
        
        for i in range(1, len(nums)):
            num = nums[i]
            
            # 同时考虑三种情况：
            # 1. 当前数字单独作为子数组
            # 2. 当前数字乘以之前的最大乘积
            # 3. 当前数字乘以之前的最小乘积（负负得正）
            candidates = [num, max_prod * num, min_prod * num]
            
            max_prod = max(candidates)
            min_prod = min(candidates)
            
            result = max(result, max_prod)
        
        return result
```

### 方法三：使用数组记录（DP 经典形式）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        
        # dp_max[i]: 以 nums[i] 结尾的最大乘积
        # dp_min[i]: 以 nums[i] 结尾的最小乘积
        dp_max = [0] * n
        dp_min = [0] * n
        
        dp_max[0] = dp_min[0] = nums[0]
        result = nums[0]
        
        for i in range(1, n):
            # 考虑三种选择
            dp_max[i] = max(nums[i], 
                           dp_max[i-1] * nums[i], 
                           dp_min[i-1] * nums[i])
            
            dp_min[i] = min(nums[i], 
                           dp_max[i-1] * nums[i], 
                           dp_min[i-1] * nums[i])
            
            result = max(result, dp_max[i])
        
        return result
```

### 方法四：前缀积和后缀积（巧妙思路）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        """
        思路：从左到右和从右到左各扫描一次
        遇到 0 时重置为 1
        """
        n = len(nums)
        result = float('-inf')
        
        # 从左到右
        product = 1
        for num in nums:
            product *= num
            result = max(result, product)
            if product == 0:
                product = 1
        
        # 从右到左
        product = 1
        for i in range(n - 1, -1, -1):
            product *= nums[i]
            result = max(result, product)
            if product == 0:
                product = 1
        
        return result
```

## 复杂度分析

**方法一、二、三：动态规划**

- 时间复杂度：O(n)
  - 遍历数组一次
- 空间复杂度：
  - 方法一、二：O(1) - 只用常数个变量
  - 方法三：O(n) - 使用 dp 数组

**方法四：双向遍历**

- 时间复杂度：O(n)
  - 两次遍历
- 空间复杂度：O(1)

## 图解示例

以 `nums = [2, 3, -2, 4]` 为例：

```
初始: max_prod=2, min_prod=2, result=2

i=1, num=3:
  candidates: [3, 2*3=6, 2*3=6]
  max_prod = 6
  min_prod = 3
  result = 6

i=2, num=-2:
  candidates: [-2, 6*(-2)=-12, 3*(-2)=-6]
  max_prod = -2
  min_prod = -12
  result = 6 (保持不变)

i=3, num=4:
  candidates: [4, -2*4=-8, -12*4=-48]
  max_prod = 4
  min_prod = -48
  result = 6

最终结果: 6
```

以 `nums = [2, -5, -2, -4, 3]` 为例（有负数的情况）：

```
初始: max=2, min=2, result=2

i=1, num=-5:
  交换后: max=2, min=2
  max = max(-5, 2*(-5)) = -5
  min = min(-5, 2*(-5)) = -10
  result = 2

i=2, num=-2:
  max = max(-2, -5*(-2), -10*(-2)) = 20
  min = min(-2, -5*(-2), -10*(-2)) = -2
  result = 20

i=3, num=-4:
  max = max(-4, 20*(-4), -2*(-4)) = 8
  min = min(-4, 20*(-4), -2*(-4)) = -80
  result = 20

i=4, num=3:
  max = max(3, 8*3, -80*3) = 24
  min = min(3, 8*3, -80*3) = -240
  result = 24

最终结果: 24 (整个数组的乘积)
```

## 关键点总结

1. **维护两个状态**：
   - 最大乘积：用于更新答案
   - 最小乘积：可能在遇到负数时变成最大值

2. **负数的影响**：
   - 负数会使最大变最小，最小变最大
   - 方法一中交换 max 和 min 是一个优化技巧

3. **三种选择**：
   - 当前数字单独成为子数组（重新开始）
   - 乘以之前的最大乘积
   - 乘以之前的最小乘积

4. **0 的处理**：
   - 乘以 0 会归零
   - 自动处理，不需要特殊判断
   - max/min 都会变成 0，然后从下一个数重新开始

5. **动态规划的优化**：
   - 状态只依赖前一个位置，可以用变量代替数组
   - 空间复杂度从 O(n) 优化到 O(1)

## 易错点

1. **忘记维护最小值**：
   - 只维护最大值无法处理负数情况
   - 例如 `[2, -5, -2]`，最大乘积是 20

2. **状态转移时的选择**：
   - 必须考虑三种情况，不能只考虑两种
   - `max(num, max_prod * num)` 是不够的

3. **初始化**：
   - `result` 要初始化为 `nums[0]`，而不是 0
   - 如果数组全是负数，0 会导致错误结果

4. **交换的时机**：
   - 在更新 max_prod 和 min_prod 之前交换
   - 如果在之后交换，会影响状态转移

5. **边界情况**：
   - 空数组（题目保证不会）
   - 单个元素
   - 全是负数
   - 包含 0
