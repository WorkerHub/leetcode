## 题目描述

给定两个字符串 `s` 和 `t`。你可以从 `s` 中选取一个子串，从 `t` 中选取一个子串，将它们拼接后，求能组成的最长回文串的长度。

**示例 1：**

```
输入：s = "abcde", t = "ecdba"
输出：5
解释：从 s 取 "abc"，从 t 取 "cba"，拼接得 "abccba" 长度 6；
     或从 s 取 "a"，从 t 取 "a"，拼接得 "aa" 长度 2。
     最长回文为 "abcba"，长度 5。
```

**示例 2：**

```
输入：s = "ab", t = "ab"
输出：3
```

**提示：**
- `1 <= s.length, t.length <= 30`
- `s` 和 `t` 只含小写英母

## 解题思路

枚举 `s` 的所有子串和 `t` 的所有子串，拼接后用双指针或 Manacher 算法检验是否是回文串，取最大长度。

由于数据规模较小（长度 <= 30），子串数量为 O(n^2)，拼接后检验回文为 O(n)，总复杂度 O(n^4) 可接受。

优化思路：利用动态规划预计算每个子串是否为回文，以及最长回文子串。

## Python 代码实现

### 方法一：枚举所有子串拼接（推荐）

```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        def is_palindrome(st):
            return st == st[::-1]

        n, m = len(s), len(t)
        res = 1  # 至少有长度 1 的回文

        # 枚举 s 的子串 s[i:j+1] 和 t 的子串 t[p:q+1]
        for i in range(n):
            for j in range(i, n):
                sub_s = s[i:j+1]
                for p in range(m):
                    for q in range(p, m):
                        sub_t = t[p:q+1]
                        combined = sub_s + sub_t
                        if is_palindrome(combined):
                            res = max(res, len(combined))

        # 也考虑只用 s 的子串或只用 t 的子串
        for i in range(n):
            for j in range(i, n):
                if is_palindrome(s[i:j+1]):
                    res = max(res, j - i + 1)
        for p in range(m):
            for q in range(p, m):
                if is_palindrome(t[p:q+1]):
                    res = max(res, q - p + 1)

        return res
```

### 方法二：动态规划预处理 + 双指针扩展

```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        def is_palindrome(st: str) -> bool:
            l, r = 0, len(st) - 1
            while l < r:
                if st[l] != st[r]:
                    return False
                l += 1
                r -= 1
            return True

        n, m = len(s), len(t)
        res = 1

        # 枚举所有子串组合
        s_subs = [s[i:j+1] for i in range(n) for j in range(i, n)]
        t_subs = [t[p:q+1] for p in range(m) for q in range(p, m)]

        # 先检查单独子串
        for sub in s_subs + t_subs:
            if is_palindrome(sub):
                res = max(res, len(sub))

        # 检查拼接
        for ss in s_subs:
            for ts in t_subs:
                combined = ss + ts
                if is_palindrome(combined):
                    res = max(res, len(combined))

        return res
```

## 复杂度分析

- 时间复杂度：O(n^2 * m^2 * (n + m))，其中 n = len(s)，m = len(t)
- 空间复杂度：O(n + m)，检验回文时临时空间

## 关键点总结

1. 数据规模小（<=30），可以枚举所有子串组合
2. 回文检验用双指针或反转比较均可
3. 注意也要考虑只用 s 或只用 t 的子串构成回文的情况

## 易错点

1. 不要忘记只选一个字符串的子串的情况
2. 空子串拼接后仍需检验
3. 结果初始值应为 1（单字符必然是回文）
