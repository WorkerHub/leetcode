## 题目描述

街上有 `n` 栋房屋，颜色由数组 `colors` 给出（`colors[i]` 是第 `i` 栋房屋的颜色）。

找出两栋颜色**不同**的房屋，使它们之间的**距离**最大，返回这个最大距离。

**示例：**
```
输入：colors = [1,1,1,6,1,1,1]
输出：3
解释：颜色 1（索引 0）与颜色 6（索引 3）距离为 3
```

**提示：**
- `n == colors.length`
- `2 <= n <= 100`
- `0 <= colors[i] <= 100`
- 生成的测试用例满足**至少**有 2 栋房屋颜色不同

## 解题思路

**贪心：** 最远的两个不同颜色的房屋，一定是"首+某个右端"或"某个左端+尾"：

- 从左端 `colors[0]` 往右找，第一个与其颜色不同的右侧房屋 `j`，取 `j - 0`
- 从右端 `colors[n-1]` 往左找，第一个与其颜色不同的左侧房屋 `i`，取 `(n-1) - i`
- 两者取最大值

这是因为最优解一定包含最左或最右的房屋之一。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxDistance(self, colors: List[int]) -> int:
        n = len(colors)
        ans = 0

        # 枚举左端点为 0 的情况：找最右边颜色不同的
        for j in range(n - 1, 0, -1):
            if colors[j] != colors[0]:
                ans = max(ans, j)
                break

        # 枚举右端点为 n-1 的情况：找最左边颜色不同的
        for i in range(n - 1):
            if colors[i] != colors[n - 1]:
                ans = max(ans, n - 1 - i)
                break

        return ans
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def maxDistance(self, colors: List[int]) -> int:
        n = len(colors)
        ans = 0

        for i in range(n):
            for j in range(i + 1, n):
                if colors[i] != colors[j]:
                    ans = max(ans, j - i)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(n) | O(1) |
| 暴力 | O(n²) | O(1) |

## 关键点总结

1. 最优解一定涉及最左或最右的房屋（贪心证明）
2. 从两端分别向内查找第一个颜色不同的房屋即可
3. 题目保证至少有两栋颜色不同，所以答案一定存在

## 易错点

- 不需要检查所有对，贪心从两端检查即可
- 两个方向都要检查（左→右 和 右→左）
