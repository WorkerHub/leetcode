## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，对于每个下标 `i`（1 <= i <= nums.length - 2），`nums[i]` 的**美丽值**等于：

- 若 `nums[i]` 的最大美丽值满足以下两个条件，则为 **2**：
  - `nums[i]` 严格大于所有下标小于 `i` 的元素（即 `nums[0..i-1]` 中的最大值 `< nums[i]`）
  - `nums[i]` 严格小于所有下标大于 `i` 的元素（即 `nums[i+1..n-1]` 中的最小值 `> nums[i]`）
- 若 `nums[i]` 仅满足以下条件，则为 **1**：
  - `nums[i-1] < nums[i] < nums[i+1]`
- 否则为 **0**

返回所有下标的**美丽值之和**。

**示例 1：**
```
输入：nums = [1,2,3]
输出：2
解释：index 1 的美丽值为 2
```

**示例 2：**
```
输入：nums = [2,4,6,4]
输出：1
解释：index 1 美丽值2，index 2 美丽值0（右侧有4<6），实际只有1
```

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**预处理前缀最大值和后缀最小值：**
- `prefix_max[i]`：`nums[0..i]` 的最大值
- `suffix_min[i]`：`nums[i..n-1]` 的最小值

对于每个 `i`（1 到 n-2）：
- 若 `prefix_max[i-1] < nums[i] < suffix_min[i+1]`，美丽值为 2
- 否则若 `nums[i-1] < nums[i] < nums[i+1]`，美丽值为 1
- 否则为 0

## 代码实现

### 方法一：前缀最大值 + 后缀最小值（推荐）

```python
from typing import List

class Solution:
    def sumOfBeauties(self, nums: List[int]) -> int:
        n = len(nums)

        # 预处理前缀最大值
        prefix_max = [0] * n
        prefix_max[0] = nums[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i])

        # 预处理后缀最小值
        suffix_min = [0] * n
        suffix_min[n - 1] = nums[n - 1]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i])

        result = 0
        for i in range(1, n - 1):
            if prefix_max[i - 1] < nums[i] < suffix_min[i + 1]:
                result += 2  # 满足美丽值为2的条件
            elif nums[i - 1] < nums[i] < nums[i + 1]:
                result += 1  # 仅满足美丽值为1的条件
            # 否则美丽值为0，不累加

        return result
```

### 方法二：原地计算（节省空间）

```python
from typing import List

class Solution:
    def sumOfBeauties(self, nums: List[int]) -> int:
        n = len(nums)

        # 只需前缀最大值数组和后缀最小值
        prefix_max = nums[:]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i])

        suffix_min = nums[:]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i])

        ans = 0
        for i in range(1, n - 1):
            if prefix_max[i - 1] < nums[i] and nums[i] < suffix_min[i + 1]:
                ans += 2
            elif nums[i - 1] < nums[i] < nums[i + 1]:
                ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，三次线性遍历
- 空间复杂度：O(n)，前缀最大和后缀最小数组

## 关键点总结

1. 预处理前缀最大值和后缀最小值是解题关键
2. 美丽值为 2 的条件比美丽值为 1 更严格，先检查 2 再检查 1
3. 注意下标范围：`i` 从 1 到 `n-2`（不含首尾元素）

## 易错点

- 严格大于/小于（不包含等于）
- `prefix_max[i-1]`（不是 `prefix_max[i]`）与 `suffix_min[i+1]`（不是 `suffix_min[i]`）
- 先判断条件 2 再判断条件 1，两者是互斥的判断顺序
