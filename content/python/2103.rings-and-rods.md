## 题目描述

总计有 `n` 个环，环的颜色可以是红、绿、蓝中的一种。这些环分别穿在 10 根编号为 0 到 9 的杆上。

给你一个长度为 `2n` 的字符串 `rings`，表示这 `n` 个环在各杆上的分布情况。`rings` 中每两个字符形成一对，第一个字符表示环的颜色（`'R'`、`'G'`、`'B'`），第二个字符表示套在哪根杆上（`'0'` 到 `'9'`）。

找出所有集齐**全部三种颜色**环的杆，并返回这种杆的数量。

**示例 1：**
```
输入：rings = "B0B6G0R6R0R6G9"
输出：1
解释：
- 0 号杆上有 3 个环：B、G、R（集齐全部颜色）
- 6 号杆上有 3 个环：B、R、G（集齐全部颜色）
- 9 号杆上有 1 个环：G
仅 0 号杆集齐了全部三种颜色的环。
```

**提示：**
- `rings.length == 2 * n`
- `1 <= n <= 100`
- `rings[i]` 为 `'R'`、`'G'`、`'B'` 之一（偶数下标）
- `rings[i]` 为 `'0'` 到 `'9'` 之一（奇数下标）

## 解题思路

**哈希表记录每根杆拥有的颜色集合**

遍历字符串，每两个字符为一组，将颜色加入对应杆的集合。最后统计集合大小为 3 的杆数。

## 代码实现

### 方法一：哈希表 + 集合（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPoints(self, rings: str) -> int:
        # 每根杆对应一个颜色集合
        rod_colors = defaultdict(set)
        # 每次处理两个字符
        for i in range(0, len(rings), 2):
            color = rings[i]
            rod = rings[i + 1]
            rod_colors[rod].add(color)
        # 统计集齐三种颜色的杆数
        return sum(1 for colors in rod_colors.values() if len(colors) == 3)
```

### 方法二：位运算（高效简洁）

```python
class Solution:
    def countPoints(self, rings: str) -> int:
        # 用位掩码记录每根杆的颜色状态
        # R=001, G=010, B=100，三种颜色全有则 mask=111=7
        color_bit = {'R': 1, 'G': 2, 'B': 4}
        rod_mask = [0] * 10  # 10 根杆
        for i in range(0, len(rings), 2):
            color = rings[i]
            rod = int(rings[i + 1])
            rod_mask[rod] |= color_bit[color]
        # mask 等于 7 (0b111) 表示集齐三种颜色
        return sum(1 for mask in rod_mask if mask == 7)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(1)（最多 10 根杆） |
| 位运算 | O(n) | O(1) |

## 关键点总结

1. 每两个字符是一对：颜色在偶数位，杆编号在奇数位。
2. 集合或位掩码记录颜色状态，集齐三色即可计数。
3. 位运算版本更简洁，`R=1, G=2, B=4`，三色全有时 mask=7。

## 易错点

- 遍历时步长应为 2，而非 1。
- 杆编号是字符 `'0'` 到 `'9'`，位运算时需转为整数。
