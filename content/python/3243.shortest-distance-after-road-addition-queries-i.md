## 题目描述

给你一个整数 `n` 和一个二维整数数组 `queries`。

初始有一条从 0 到 n-1 的单向路，即 `0 -> 1 -> 2 -> ... -> n-1`（每条边长度为 1）。

每次查询 `queries[i] = [ui, vi]` 表示添加一条从 `ui` 到 `vi` 的有向边。

每次添加边后，返回从节点 `0` 到节点 `n-1` 的最短路径长度。

**示例 1：**
```
输入：n = 5, queries = [[2,4],[0,2],[0,4]]
输出：[3,2,1]
```

**示例 2：**
```
输入：n = 4, queries = [[0,3],[0,2]]
输出：[1,1]
```

**提示：**
- `3 <= n <= 500`
- `1 <= queries.length <= 500`
- `queries[i].length == 2`

## 解题思路

每次添加边后，做一次 BFS 求从 0 到 n-1 的最短路。

由于 n 和 queries 都不超过 500，每次 BFS 的复杂度 O(n + q) 可以接受。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def shortestDistanceAfterQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        # 初始图：0 -> 1 -> ... -> n-1
        graph = [[] for _ in range(n)]
        for i in range(n - 1):
            graph[i].append(i + 1)
        
        def bfs():
            dist = [-1] * n
            dist[0] = 0
            q = deque([0])
            while q:
                u = q.popleft()
                for v in graph[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        q.append(v)
            return dist[n - 1]
        
        ans = []
        for u, v in queries:
            graph[u].append(v)
            ans.append(bfs())
        
        return ans
```

### 方法二：动态规划（适合有向无环图）

```python
from typing import List

class Solution:
    def shortestDistanceAfterQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        # 由于只有从小到大的边（初始 i->i+1，查询 u<v），图是 DAG
        # 用 DP 求最短路
        graph = [[] for _ in range(n)]
        for i in range(n - 1):
            graph[i].append(i + 1)
        
        def dp_shortest():
            dp = [float('inf')] * n
            dp[0] = 0
            for u in range(n):
                if dp[u] == float('inf'):
                    continue
                for v in graph[u]:
                    dp[v] = min(dp[v], dp[u] + 1)
            return dp[n - 1]
        
        ans = []
        for u, v in queries:
            graph[u].append(v)
            ans.append(dp_shortest())
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(q * (n + q))，每次查询后做 BFS
- 空间复杂度：O(n + q)

## 关键点总结

1. 每次添加边后重新 BFS 求最短路
2. 图是有向无环图（所有边从小编号到大编号），可用 DP 替代 BFS
3. 数据范围小，简单做法即可

## 易错点

1. 图是有向图，不要用无向图的 BFS
2. 注意每次添加新边后图在变化，需要重新计算
