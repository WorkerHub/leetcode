## 题目描述

给你两个字符串 `word1` 和 `word2`。请你从 `word1` 开始，通过**交替添加字母**来合并字符串。如果一个字符串比另一个字符串长，就将多出来的字母追加到合并后字符串的末尾。

返回**合并后的字符串**。

**示例 1：**
```
输入：word1 = "abc", word2 = "pqr"
输出："apbqcr"
```

**示例 2：**
```
输入：word1 = "ab", word2 = "pqrs"
输出："apbqrs"
```

**提示：**
- `1 <= word1.length, word2.length <= 100`
- `word1` 和 `word2` 由小写英文字母组成

## 解题思路

双指针，分别指向两个字符串的当前位置，交替取字符，最后拼接剩余部分。

## 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        result = []
        i, j = 0, 0
        
        while i < len(word1) and j < len(word2):
            result.append(word1[i])
            result.append(word2[j])
            i += 1
            j += 1
        
        result.append(word1[i:])
        result.append(word2[j:])
        
        return ''.join(result)
```

### 方法二：zip + 残余拼接

```python
class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        # zip 自动截断到较短的长度
        merged = ''.join(a + b for a, b in zip(word1, word2))
        # 拼接较长字符串的剩余部分
        n = min(len(word1), len(word2))
        return merged + word1[n:] + word2[n:]
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)，结果字符串

## 关键点总结

1. 交替取字符，直到较短字符串用完
2. 将较长字符串的剩余部分拼接到末尾

## 易错点

- word1 先取，word2 后取（题目指定从 word1 开始）
