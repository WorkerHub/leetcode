## 题目描述

给定一个字符串数组 `arr`，字符串 `s` 是将 `arr` 某一子序列字符串连接所得的字符串，如果 `s` 中的每一个字符都只出现过一次，那么它就是一个可行解。

请返回所有可行解 `s` 中最长长度。

示例 1：
```
输入：arr = ["un","iq","ue"]
输出：4
解释：所有可能的串联组合是 "","un","iq","ue","uniq" 和 "ique"，最大长度为 4。
```

示例 2：
```
输入：arr = ["cha","r","act","ers"]
输出：6
解释：可能的解答有 "chaers" 和 "acters"。
```

示例 3：
```
输入：arr = ["abcdefghijklmnopqrstuvwxyz"]
输出：26
```

提示：
- `1 <= arr.length <= 16`
- `1 <= arr[i].length <= 26`
- `arr[i]` 中只含有小写英文字母

## 解题思路

这是一个组合优化问题，可以用回溯或位运算解决。

核心思路：
1. 对于每个字符串，有选或不选两种选择
2. 如果选择当前字符串，需要检查它与已选字符串是否有重复字符
3. 使用回溯尝试所有可能的组合
4. 记录最大长度

优化技巧：
- 提前过滤掉内部有重复字符的字符串
- 使用位掩码表示字符集合，加速重复检查
- 剪枝：如果剩余字符串总长度加当前长度都不超过已知最大值，提前返回

## Python 代码实现

### 方法一：回溯 + 集合（推荐）

```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        """
        使用回溯搜索所有可能的组合
        
        Args:
            arr: 字符串数组
            
        Returns:
            最大长度
        """
        def is_unique(s: str) -> bool:
            """检查字符串内部是否有重复字符"""
            return len(s) == len(set(s))
        
        # 过滤掉内部有重复字符的字符串
        arr = [s for s in arr if is_unique(s)]
        
        self.max_len = 0
        
        def backtrack(index: int, current: str):
            """回溯搜索"""
            # 更新最大长度
            self.max_len = max(self.max_len, len(current))
            
            # 遍历剩余字符串
            for i in range(index, len(arr)):
                # 检查是否有重复字符
                if not set(current) & set(arr[i]):
                    backtrack(i + 1, current + arr[i])
        
        backtrack(0, "")
        return self.max_len
```

### 方法二:位掩码 + 回溯（最优）

```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        """
        使用位掩码表示字符集合
        """
        def str_to_mask(s: str) -> int:
            """将字符串转换为位掩码"""
            mask = 0
            for c in s:
                bit = ord(c) - ord('a')
                if mask & (1 << bit):
                    return -1  # 有重复字符
                mask |= (1 << bit)
            return mask
        
        # 转换为位掩码并过滤
        masks = []
        for s in arr:
            mask = str_to_mask(s)
            if mask != -1:
                masks.append((mask, len(s)))
        
        self.max_len = 0
        
        def backtrack(index: int, current_mask: int, current_len: int):
            self.max_len = max(self.max_len, current_len)
            
            for i in range(index, len(masks)):
                mask, length = masks[i]
                # 检查是否有重复：按位与为 0 表示没有重复
                if current_mask & mask == 0:
                    backtrack(i + 1, current_mask | mask, current_len + length)
        
        backtrack(0, 0, 0)
        return self.max_len
```

### 方法三：迭代 + 动态规划思想

```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        """
        迭代构建所有可能的组合
        """
        # dp 存储所有可能的 (字符集合, 长度) 组合
        dp = [set()]
        
        for s in arr:
            # 检查 s 内部是否有重复
            if len(s) != len(set(s)):
                continue
            
            s_set = set(s)
            # 尝试将 s 加入所有已有组合
            for chars in dp[:]:  # 使用切片创建副本避免迭代时修改
                # 检查是否有重复
                if not (chars & s_set):
                    dp.append(chars | s_set)
        
        # 返回最大长度
        return max(len(chars) for chars in dp)
```

### 方法四：优化的位运算

```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        """
        使用列表存储位掩码
        """
        dp = [0]  # 初始：空字符串，位掩码为 0
        
        for s in arr:
            # 计算 s 的位掩码
            mask = 0
            for c in s:
                bit = 1 << (ord(c) - ord('a'))
                if mask & bit:  # s 内部有重复
                    mask = 0
                    break
                mask |= bit
            
            if mask == 0:  # s 内部有重复，跳过
                continue
            
            # 尝试将 s 加入所有已有组合
            for prev_mask in dp[:]:
                if prev_mask & mask == 0:  # 没有重复字符
                    dp.append(prev_mask | mask)
        
        # 计算最大长度：位掩码中 1 的个数
        return max(bin(mask).count('1') for mask in dp)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(2^n)，其中 n 是数组长度
- 空间复杂度：O(n)，递归栈

**方法二（推荐）：**
- 时间复杂度：O(2^n)
- 空间复杂度：O(n)

**方法三和方法四：**
- 时间复杂度：O(2^n × m)，其中 m 是字符串平均长度
- 空间复杂度：O(2^n)

## 关键点总结

1. 提前过滤内部有重复字符的字符串
2. 使用集合的交集操作检查重复：`set1 & set2`
3. 位掩码可以加速字符集合的表示和比较
4. 回溯和迭代两种思路都可以
5. 注意迭代时不要修改正在遍历的列表

## 易错点

1. 忘记检查字符串内部是否有重复字符
2. 集合操作理解错误：用 `|` 而不是 `&` 检查重复
3. 迭代时修改列表导致错误
4. 位运算时位的计算错误
5. 没有初始化 dp 为包含空集的状态
