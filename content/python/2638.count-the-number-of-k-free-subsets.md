## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。若 `nums` 的一个子集中不存在两个元素之差恰好为 `k`，则称该子集为 **k-free** 子集。

返回 `nums` 的 **k-free** 子集的数目。

**示例 1：**
```
输入：nums = [5,4,6], k = 1
输出：5
解释：子集 {4,6} 不是 1-free（6-5=1不行，但4和6差2，5-4=1不行），
有效子集：{}, {4}, {5}, {6}, {4,6}，共 5 个
```

**示例 2：**
```
输入：nums = [2,3,5,8], k = 5
输出：12
```

**数据范围：**
- 1 <= nums.length <= 50
- 1 <= nums[i] <= 1000
- 1 <= k <= 1000

## 解题思路

按模 `k` 分组：若两个元素差为 `k`，则它们对 `k` 取模的余数相同。因此将 `nums` 按模 `k` 分组，不同组之间独立，最终答案为各组答案的乘积。

对每组（排序后的等差数列，公差为 `k`），用动态规划计算 k-free 子集数：`dp[i] = dp[i-1] + dp[i-2]`（选或不选当前元素），类似打家劫舍。

特殊情况：`k = 0` 时，相同的元素成组，每组中只能选至多一个，答案为各组出现次数 + 1 的乘积（+1 包括不选）。

## Python 代码实现

### 方法一：分组 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countTheNumOfKFreeSubsets(self, nums: List[int], k: int) -> int:
        # 按 num % k 分组
        groups = defaultdict(list)
        for x in sorted(nums):
            groups[x % k].append(x)

        ans = 1
        for group in groups.values():
            # 组内排序（已排序），相邻差为 k 的元素不能同时选
            # dp[i]: 考虑前 i 个元素时的 k-free 子集数
            # dp[0] = 1（空集）
            # dp[j] = dp[j-1] + dp[j-2] 若 group[j-1] - group[j-2] == k
            #       = dp[j-1] * 2 若 group[j-1] - group[j-2] != k（独立）
            n = len(group)
            dp = [1] * (n + 1)
            dp[1] = 2  # 选或不选第一个元素
            for j in range(2, n + 1):
                if group[j - 1] - group[j - 2] == k:
                    dp[j] = dp[j - 1] + dp[j - 2]
                else:
                    # 不相关，乘以 2
                    dp[j] = dp[j - 1] * 2
            ans *= dp[n]

        return ans
```

### 方法二：类打家劫舍 DP

```python
from typing import List
from collections import defaultdict

class Solution:
    def countTheNumOfKFreeSubsets(self, nums: List[int], k: int) -> int:
        groups = defaultdict(list)
        for x in sorted(nums):
            groups[x % k].append(x)

        ans = 1
        for group in groups.values():
            # f: 不选当前元素时的子集数
            # g: 选当前元素时的子集数
            f, g = 1, 1
            prev = None
            for x in group:
                if prev is not None and x - prev == k:
                    # 与前一个冲突：选当前 = 不选前一个（f）
                    new_f = f + g  # 不选当前：前两种情况都行
                    new_g = f      # 选当前：前一个必须不选
                    f, g = new_f, new_g
                else:
                    # 与前一个不冲突：独立
                    new_f = (f + g)
                    new_g = (f + g)
                    f, g = new_f, new_g
                prev = x
            ans *= (f + g)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，分组存储

## 关键点总结

1. 差为 `k` 的元素对 `k` 取模余数相同，按此分组
2. 组内问题类似打家劫舍（不能选相邻元素）
3. 不同组独立，乘以各组答案

## 易错点

1. 组内相邻元素差不一定是 `k`（可能有重复取模余数但差不是 `k`），需判断
2. 空集也算一个 k-free 子集
3. 答案初始为 1（空集），逐组相乘
