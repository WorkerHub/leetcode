## 题目描述

给你一个整数数组 nums，将它重新排列成 nums[0] <= nums[1] >= nums[2] <= nums[3]... 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

**示例 1：**
```
输入: nums = [3,5,2,1,6,4]
输出: [3,5,1,6,2,4]
解释: [1,6,2,5,3,4] 也是有效的答案
```

**示例 2：**
```
输入: nums = [6,6,5,6,3,8]
输出: [6,6,5,6,3,8]
```

**提示：**
- 1 <= nums.length <= 5 * 10^4
- 0 <= nums[i] <= 10^4
- 题目数据保证可以找到满足题目要求的答案

**进阶：** 你能用 O(n) 时间复杂度和/或原地 O(1) 额外空间来实现吗？

## 解题思路

### 理解摆动排序

摆动排序的规律：
- 偶数索引（0, 2, 4, ...）：`nums[i] <= nums[i+1]`
- 奇数索引（1, 3, 5, ...）：`nums[i] >= nums[i+1]`

形象化：`小 <= 大 >= 小 <= 大 >= ...`

### 思路一：排序后交换（简单但非最优）

1. 对数组排序
2. 将排序后的数组按规则交换相邻元素
3. 时间复杂度：O(n log n)

### 思路二：贪心算法（最优解）

**核心观察：**
- 遍历数组，检查每个位置是否满足摆动条件
- 如果不满足，交换当前元素和下一个元素即可

**为什么贪心有效？**
- 对于偶数位置 i：如果 nums[i] > nums[i+1]，交换后 nums[i] <= nums[i+1]
- 交换不会影响前面已经满足的条件
- 时间复杂度：O(n)，空间复杂度：O(1)

## Python 代码实现

### 方法一：贪心算法（推荐）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        贪心算法，原地修改，O(n) 时间，O(1) 空间
        Do not return anything, modify nums in-place instead.
        """
        for i in range(len(nums) - 1):
            # 偶数位置：nums[i] <= nums[i+1]
            if i % 2 == 0:
                if nums[i] > nums[i + 1]:
                    nums[i], nums[i + 1] = nums[i + 1], nums[i]
            # 奇数位置：nums[i] >= nums[i+1]
            else:
                if nums[i] < nums[i + 1]:
                    nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

### 方法二：更简洁的贪心写法

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        简化版贪心算法
        """
        for i in range(len(nums) - 1):
            # 判断当前位置应该是 <= 还是 >=
            # 偶数位置应该 <=，奇数位置应该 >=
            should_be_less = (i % 2 == 0)
            
            # 检查是否违反条件
            if (nums[i] > nums[i + 1]) == should_be_less:
                nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

### 方法三：排序后重排（易理解但不够优）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        排序后交换相邻元素
        时间复杂度：O(n log n)
        """
        nums.sort()
        
        # 交换每对相邻元素（从索引 1 开始）
        for i in range(1, len(nums) - 1, 2):
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

### 方法四：详细注释版（便于理解）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        详细解释的贪心算法
        """
        n = len(nums)
        
        # 遍历数组（不包括最后一个元素）
        for i in range(n - 1):
            # 判断当前位置的期望关系
            if i % 2 == 0:
                # 偶数位置（0, 2, 4, ...）
                # 期望：nums[i] <= nums[i+1]
                # 如果 nums[i] > nums[i+1]，则违反条件
                if nums[i] > nums[i + 1]:
                    # 交换使其满足条件
                    nums[i], nums[i + 1] = nums[i + 1], nums[i]
            else:
                # 奇数位置（1, 3, 5, ...）
                # 期望：nums[i] >= nums[i+1]
                # 如果 nums[i] < nums[i+1]，则违反条件
                if nums[i] < nums[i + 1]:
                    # 交换使其满足条件
                    nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

### 方法五：使用异或技巧（一行判断）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        使用异或运算简化判断
        """
        for i in range(len(nums) - 1):
            # (nums[i] > nums[i+1]) ^ (i % 2 == 1) 判断是否需要交换
            # 偶数位置：期望 <=，如果 > 则交换（True ^ False = True）
            # 奇数位置：期望 >=，如果 < 则交换（False ^ True = True）
            if (nums[i] > nums[i + 1]) ^ (i % 2 == 1):
                nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

## 复杂度分析

### 方法一、二、四、五：贪心算法

**时间复杂度：** O(n)
- 遍历数组一次
- 每次操作 O(1)

**空间复杂度：** O(1)
- 原地修改，不使用额外空间

### 方法三：排序后重排

**时间复杂度：** O(n log n)
- 排序：O(n log n)
- 交换：O(n)

**空间复杂度：** O(log n) 或 O(n)
- 取决于排序算法的实现

## 图解示例

**示例：** nums = [3, 5, 2, 1, 6, 4]

**贪心算法过程：**

```
初始: [3, 5, 2, 1, 6, 4]

i=0 (偶数位置，期望 <=):
  3 <= 5 ✓ 不需要交换
  [3, 5, 2, 1, 6, 4]

i=1 (奇数位置，期望 >=):
  5 >= 2 ✓ 不需要交换
  [3, 5, 2, 1, 6, 4]

i=2 (偶数位置，期望 <=):
  2 <= 1 ✗ 需要交换
  [3, 5, 1, 2, 6, 4]

i=3 (奇数位置，期望 >=):
  2 >= 6 ✗ 需要交换
  [3, 5, 1, 6, 2, 4]

i=4 (偶数位置，期望 <=):
  2 <= 4 ✓ 不需要交换
  [3, 5, 1, 6, 2, 4]

最终结果: [3, 5, 1, 6, 2, 4]
验证: 3<=5, 5>=1, 1<=6, 6>=2, 2<=4 ✓
```

**排序法过程：**

```
原数组: [3, 5, 2, 1, 6, 4]
排序后: [1, 2, 3, 4, 5, 6]

交换 (1, 2): [1, 3, 2, 4, 5, 6]
交换 (3, 4): [1, 3, 2, 5, 4, 6]
交换 (5, 6): [1, 3, 2, 5, 4, 6]

结果: [1, 3, 2, 5, 4, 6]
验证: 1<=3, 3>=2, 2<=5, 5>=4, 4<=6 ✓
```

## 关键点总结

1. **贪心策略**：逐个检查并修正，不会影响已处理的部分
2. **局部最优性**：交换相邻元素可以立即满足当前位置的条件
3. **不影响前面**：交换 i 和 i+1 不会破坏 i-1 和 i 的关系
4. **条件判断**：
   - 偶数位置：`nums[i] <= nums[i+1]`
   - 奇数位置：`nums[i] >= nums[i+1]`
5. **原地算法**：O(1) 空间复杂度

## 易错点

1. **索引的奇偶判断**
   ```python
   # 错误：混淆奇偶位置的条件
   if i % 2 == 0:
       if nums[i] < nums[i + 1]:  # 错误！应该是 >
           swap
   
   # 正确
   if i % 2 == 0:
       if nums[i] > nums[i + 1]:  # 偶数位置期望 <=
           swap
   ```

2. **忘记修改是原地的**
   ```python
   # 错误：返回新数组
   def wiggleSort(self, nums):
       result = nums[:]
       ...
       return result
   
   # 正确：原地修改
   def wiggleSort(self, nums):
       ...
       # Do not return anything
   ```

3. **数组越界**
   ```python
   # 错误：访问 nums[i+1] 时可能越界
   for i in range(len(nums)):  # 错误！
   
   # 正确：循环到 len(nums) - 1
   for i in range(len(nums) - 1):
   ```

4. **排序法的交换范围**
   ```python
   # 错误：从索引 0 开始交换
   for i in range(0, len(nums) - 1, 2):
       swap(nums[i], nums[i + 1])
   
   # 正确：从索引 1 开始交换
   for i in range(1, len(nums) - 1, 2):
       swap(nums[i], nums[i + 1])
   ```
