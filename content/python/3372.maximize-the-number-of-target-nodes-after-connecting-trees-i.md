## 题目描述

给你两棵树（邻接表 `edges1` 和 `edges2`）。

可以在树 1 的某个节点和树 2 的某个节点之间连一条边。

对于树 1 中的每个节点 `i`，找最优的连接方式（连接哪个树 2 的节点），使得距离 <= k（边数）的节点数最多。

返回树 1 中每个节点 `i` 能覆盖的最大节点数（包括树 1 和树 2 的节点）。

**提示：**
- `2 <= n, m <= 1000`
- `0 <= k <= 1000`

## 解题思路

**分步计算：**

1. 对树 1 的每个节点 `i`，计算在树 1 中距离 <= k 的节点数 `c1[i]`（BFS）。
2. 对树 2 的每个节点 `j`，计算在树 2 中距离 <= k-1 的节点数 `c2[j]`（新加的边占用 1 步）。
3. 对树 1 的每个节点 `i`，答案 = `c1[i] + max(c2[j])` for all j in tree 2。

即：连接树 1 节点 `i` 和树 2 中能覆盖最多节点的节点（覆盖半径 k-1）。

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]], k: int) -> List[int]:
        def build_tree(edges):
            graph = defaultdict(list)
            for u, v in edges:
                graph[u].append(v)
                graph[v].append(u)
            return graph
        
        def count_within_dist(graph, n, source, max_dist):
            """BFS 计算从 source 出发，距离 <= max_dist 的节点数"""
            if max_dist < 0:
                return 0
            visited = {source}
            queue = deque([(source, 0)])
            count = 1
            while queue:
                node, dist = queue.popleft()
                if dist >= max_dist:
                    continue
                for nb in graph[node]:
                    if nb not in visited:
                        visited.add(nb)
                        queue.append((nb, dist + 1))
                        count += 1
            return count
        
        g1 = build_tree(edges1)
        g2 = build_tree(edges2)
        n1 = len(edges1) + 1
        n2 = len(edges2) + 1
        
        # 树 1 每个节点距离 <= k 的节点数
        c1 = [count_within_dist(g1, n1, i, k) for i in range(n1)]
        
        # 树 2 每个节点距离 <= k-1 的节点数（新边占 1 步）
        c2 = [count_within_dist(g2, n2, j, k - 1) for j in range(n2)]
        
        best_c2 = max(c2) if c2 else 0
        
        return [c1[i] + best_c2 for i in range(n1)]
```

## 复杂度分析

- 时间复杂度：O((n1 + n2) * (n1 + n2))，每个节点做一次 BFS
- 空间复杂度：O(n1 + n2)

## 关键点总结

1. 连接树 1 的节点 `i` 和树 2 的节点 `j`，额外获得树 2 中距离 j <= k-1 的节点数。
2. 对每个树 1 节点，选树 2 中 `c2[j]` 最大的节点连接。
3. 答案 = `c1[i] + max(c2)`（树 2 中的最优连接点）。

## 易错点

1. 连接边占 1 步，所以树 2 中覆盖半径是 `k-1`（不是 k）。
2. `k = 0` 时，连接树 2 后只能覆盖树 2 中距离 -1 的节点（即 0 个）。
3. `max(c2)` 对所有树 2 节点取最大，每个树 1 节点用同一个最大值。
