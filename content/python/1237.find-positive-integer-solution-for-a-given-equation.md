## 题目描述

给定一个可调用的函数 `f(x, y)` 和一个值 `z`，请你找出所有满足 `f(x, y) == z` 的正整数对 `[x, y]`。

函数 `f` 具有以下特性：

- `f(x, y) < f(x + 1, y)`（对于任意 `x`，`f` 在 `x` 上单调递增）
- `f(x, y) < f(x, y + 1)`（对于任意 `y`，`f` 在 `y` 上单调递增）

你需要返回所有满足条件的正整数对，按任意顺序返回即可。

**示例 1：**

```
输入：function_id = 1, z = 5
输出：[[1,4],[2,3],[3,2],[4,1]]
解释：function_id = 1 表示 f(x, y) = x + y
```

**示例 2：**

```
输入：function_id = 2, z = 5
输出：[[1,5],[5,1]]
解释：function_id = 2 表示 f(x, y) = x * y
```

**提示：**

- 题目保证 `f(x, y) == z` 的解都在 `1 <= x, y <= 1000` 的范围内
- 题目保证在 `1 <= x, y <= 1000` 时，`f(x, y)` 在 32 位有符号整数范围内

## 解题思路

这道题的关键在于利用函数的**单调性**。

**核心观察：**

由于 `f(x, y)` 在 `x` 和 `y` 上都是单调递增的，我们可以使用：

1. **双指针法**：从两端向中间靠拢
2. **二分查找**：固定一个变量，二分搜索另一个

**双指针策略：**

- 从 `x = 1, y = 1000` 开始
- 如果 `f(x, y) < z`，则 `x++`（因为需要更大的值）
- 如果 `f(x, y) > z`，则 `y--`（因为需要更小的值）
- 如果 `f(x, y) == z`，则记录结果，同时 `x++` 继续搜索

**二分查找策略：**

- 枚举 `x` 从 1 到 1000
- 对于每个 `x`，二分查找 `y` 使得 `f(x, y) == z`

## Python 代码实现

### 方法一：双指针（推荐）⭐

```python
from typing import List

# 这是一个给定的函数接口（题目会提供）
class CustomFunction:
    def f(self, x: int, y: int) -> int:
        pass

class Solution:
    def findSolution(self, customfunction: 'CustomFunction', z: int) -> List[List[int]]:
        """
        双指针法：利用函数单调性
        
        时间复杂度：O(1000) = O(1)
        空间复杂度：O(1)
        """
        result = []
        
        # 从左下角开始：x 最小，y 最大
        x, y = 1, 1000
        
        while x <= 1000 and y >= 1:
            value = customfunction.f(x, y)
            
            if value < z:
                # 值太小，增加 x
                x += 1
            elif value > z:
                # 值太大，减少 y
                y -= 1
            else:
                # 找到一个解
                result.append([x, y])
                # 继续搜索，x 和 y 都可以移动
                # 这里选择 x++，因为要找所有解
                x += 1
                # 也可以 y--，但不能同时移动（会漏掉解）
        
        return result
```

### 方法二：二分查找

```python
from typing import List

class Solution:
    def findSolution(self, customfunction: 'CustomFunction', z: int) -> List[List[int]]:
        """
        枚举 x，二分查找 y
        
        时间复杂度：O(n log n)，n = 1000
        空间复杂度：O(1)
        """
        result = []
        
        # 枚举所有可能的 x
        for x in range(1, 1001):
            # 二分查找 y
            left, right = 1, 1000
            
            while left <= right:
                mid = (left + right) // 2
                value = customfunction.f(x, mid)
                
                if value < z:
                    left = mid + 1
                elif value > z:
                    right = mid - 1
                else:
                    # 找到解
                    result.append([x, mid])
                    break
        
        return result
```

### 方法三：暴力枚举（不推荐）

```python
from typing import List

class Solution:
    def findSolution(self, customfunction: 'CustomFunction', z: int) -> List[List[int]]:
        """
        暴力枚举所有可能的 (x, y) 组合
        
        时间复杂度：O(n^2) = O(1000 * 1000)
        空间复杂度：O(1)
        """
        result = []
        
        for x in range(1, 1001):
            for y in range(1, 1001):
                if customfunction.f(x, y) == z:
                    result.append([x, y])
        
        return result
```

### 方法四：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def findSolution(self, customfunction: 'CustomFunction', z: int) -> List[List[int]]:
        """
        双指针法详细解释
        """
        result = []
        
        # 初始化双指针
        # x 从最小值开始（1）
        # y 从最大值开始（1000）
        x = 1
        y = 1000
        
        # 当 x 和 y 都在有效范围内时继续搜索
        while x <= 1000 and y >= 1:
            # 计算当前 (x, y) 的函数值
            current_value = customfunction.f(x, y)
            
            # 情况1：函数值太小
            if current_value < z:
                # 由于 f 在 x 上单调递增
                # 增加 x 会使函数值变大
                x += 1
            
            # 情况2：函数值太大
            elif current_value > z:
                # 由于 f 在 y 上单调递增
                # 减少 y 会使函数值变小
                y -= 1
            
            # 情况3：找到一个解
            else:
                # 记录这个解
                result.append([x, y])
                
                # 继续搜索其他解
                # 增加 x，同时 y 可能会减少
                x += 1
                # 注意：这里只移动 x
                # 如果同时移动 x 和 y，可能会漏掉某些解
        
        return result
```

## 复杂度分析

**方法一（双指针）：**

- **时间复杂度**：O(m + n) = O(1000 + 1000) = O(1)
  - x 最多从 1 增加到 1000
  - y 最多从 1000 减少到 1
  - 总共最多 2000 次操作

- **空间复杂度**：O(1)（不计结果数组）

**方法二（二分查找）：**

- **时间复杂度**：O(n log n) = O(1000 * log 1000) ≈ O(10000)
- **空间复杂度**：O(1)

**方法三（暴力）：**

- **时间复杂度**：O(n^2) = O(1000 * 1000) = O(10^6)
- **空间复杂度**：O(1)

## 关键点总结

1. **利用单调性**：函数在 x 和 y 上都单调递增
2. **双指针技巧**：从对角线的两端向中间靠拢
3. **移动策略**：值小则增 x，值大则减 y
4. **找到解后**：继续移动一个指针寻找其他解
5. **时间优化**：双指针 O(n) 优于二分 O(n log n) 优于暴力 O(n^2)

## 易错点

1. **找到解后同时移动两个指针**：
   - 错误：`x++; y--;` 同时执行
   - 正确：只移动一个指针，避免漏掉解

2. **边界条件**：
   - 确保 `x <= 1000` 和 `y >= 1`
   - 否则可能越界或漏掉解

3. **循环终止条件**：
   - 应该是 `x <= 1000 and y >= 1`
   - 不是 `x < y`

4. **理解单调性**：
   - `f(x, y)` 在 x 和 y 上**都**单调递增
   - 不是只在一个维度上递增

5. **返回顺序**：
   - 题目说任意顺序，不需要排序
