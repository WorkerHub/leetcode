## 题目描述

给你一个 `n x n` 的矩阵 `grid`，`grid[i][j]` 表示骑士访问该格子的顺序（从 0 到 n^2-1 各出现一次）。判断骑士是否可以按照 `grid` 中的顺序通过合法的骑士跳（国际象棋中的马步）依次访问所有格子。

骑士的移动方向：`(±1, ±2)` 或 `(±2, ±1)`。

**示例 1：**

```
输入：grid = [[0,11,16,5,20],[17,4,19,10,15],[12,1,8,21,6],[3,18,23,14,9],[24,13,2,7,22]]
输出：true
```

**示例 2：**

```
输入：grid = [[0,3,6],[5,8,1],[2,7,4]]
输出：false
```

**提示：**

- `n == grid.length == grid[i].length`
- `3 <= n <= 7`
- `0 <= grid[i][j] <= n^2 - 1`

## 解题思路

1. 从 `grid` 中找出每个顺序编号对应的位置 `pos[v] = (r, c)`
2. 检查相邻编号 `v` 和 `v+1` 之间是否是合法的马步
3. 合法马步：行差和列差的绝对值分别为 1 和 2（或 2 和 1）

## Python 代码实现

### 方法一：直接验证（推荐）

```python
from typing import List

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        # 骑士从 0 开始
        if grid[0][0] != 0:
            return False

        pos = [None] * (n * n)
        for i in range(n):
            for j in range(n):
                pos[grid[i][j]] = (i, j)

        knight_moves = {(1, 2), (1, -2), (-1, 2), (-1, -2),
                        (2, 1), (2, -1), (-2, 1), (-2, -1)}

        for v in range(n * n - 1):
            r1, c1 = pos[v]
            r2, c2 = pos[v + 1]
            if (r2 - r1, c2 - c1) not in knight_moves:
                return False

        return True
```

### 方法二：数学判断马步

```python
from typing import List

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        if grid[0][0] != 0:
            return False

        pos = {}
        for i in range(n):
            for j in range(n):
                pos[grid[i][j]] = (i, j)

        for v in range(n * n - 1):
            r1, c1 = pos[v]
            r2, c2 = pos[v + 1]
            dr, dc = abs(r2 - r1), abs(c2 - c1)
            if not ((dr == 1 and dc == 2) or (dr == 2 and dc == 1)):
                return False

        return True
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 先建立编号到位置的映射
2. 逐步检查相邻编号间是否是合法马步
3. 马步条件：`(|dr|, |dc|) ∈ {(1,2), (2,1)}`

## 易错点

1. 骑士必须从位置 (0,0) 出发（编号 0 在左上角）
2. 马步是行差和列差的组合，需用绝对值
3. 只需检查相邻编号的步骤，不需要 BFS 整个路径
