## 题目描述

给你两个长度相同的字符串 `s1` 和 `s2`，它们都只包含字符 `"x"` 和 `"y"`。

你可以交换 `s1[i]` 和 `s2[j]`，其中 `i` 和 `j` 可以是任意位置的索引。

返回使 `s1` 和 `s2` 相同所需的最小交换次数，如果无法使二者相同，则返回 `-1`。

**示例 1：**

```
输入：s1 = "xx", s2 = "yy"
输出：1
解释：交换 s1[0] 和 s2[1]，得到 s1 = "yx", s2 = "yx"。
```

**示例 2：**

```
输入：s1 = "xy", s2 = "yx"
输出：2
解释：交换 s1[0] 和 s2[0]，得到 s1 = "yy", s2 = "xx"。
交换 s1[0] 和 s2[1]，得到 s1 = "xy", s2 = "xy"。
注意，你不能交换 s1[0] 和 s1[1] 使得 s1 变成 "yx"，因为我们只能交换不同字符串中的字符。
```

**示例 3：**

```
输入：s1 = "xx", s2 = "xy"
输出：-1
```

**提示：**

- `1 <= s1.length, s2.length <= 1000`
- `s1` 和 `s2` 的长度相同
- `s1` 和 `s2` 只包含 `'x'` 或 `'y'`

## 解题思路

这道题的关键是找出哪些位置需要交换，以及如何最小化交换次数。

### 核心观察

1. **相同位置不需要处理**：如果 `s1[i] == s2[i]`，这个位置已经匹配，不需要考虑。

2. **不匹配位置的分类**：对于 `s1[i] != s2[i]` 的位置，只有两种情况：
   - 情况 A：`s1[i] = 'x', s2[i] = 'y'`（记为 xy 型）
   - 情况 B：`s1[i] = 'y', s2[i] = 'x'`（记为 yx 型）

3. **交换规则**：
   - 两个 xy 型位置可以通过 1 次交换解决（例如位置 i 和 j，交换 s1[i] 和 s2[j]）
   - 两个 yx 型位置可以通过 1 次交换解决（例如位置 i 和 j，交换 s1[i] 和 s2[j]）
   - 一个 xy 型和一个 yx 型位置需要 2 次交换解决

4. **可行性判断**：如果 `(xy型数量 + yx型数量)` 是奇数，则无法使两个字符串相同，返回 -1。

### 算法流程

1. 统计 xy 型不匹配的数量（count_xy）和 yx 型不匹配的数量（count_yx）
2. 如果总数是奇数，返回 -1
3. 计算最小交换次数：
   - 每 2 个同类型的不匹配需要 1 次交换
   - 剩余的异类型不匹配需要 2 次交换

## Python 代码实现

### 方法一：贪心算法（推荐）

```python
class Solution:
    def minimumSwap(self, s1: str, s2: str) -> int:
        # 统计两种不匹配类型
        xy = 0  # s1[i]='x', s2[i]='y' 的数量
        yx = 0  # s1[i]='y', s2[i]='x' 的数量
        
        # 遍历字符串，统计不匹配位置
        for c1, c2 in zip(s1, s2):
            if c1 == 'x' and c2 == 'y':
                xy += 1
            elif c1 == 'y' and c2 == 'x':
                yx += 1
        
        # 如果不匹配总数是奇数，无法使两个字符串相同
        if (xy + yx) % 2 == 1:
            return -1
        
        # 计算最小交换次数
        # 每 2 个 xy 型需要 1 次交换，每 2 个 yx 型需要 1 次交换
        # 剩余的 1 个 xy 和 1 个 yx 需要 2 次交换
        return xy // 2 + yx // 2 + (xy % 2) * 2
```

### 方法二：数学公式简化

```python
class Solution:
    def minimumSwap(self, s1: str, s2: str) -> int:
        # 统计不匹配类型
        xy, yx = 0, 0
        
        for c1, c2 in zip(s1, s2):
            if c1 != c2:
                if c1 == 'x':
                    xy += 1
                else:
                    yx += 1
        
        # 总数为奇数时无解
        total = xy + yx
        if total % 2 == 1:
            return -1
        
        # 优化公式：(xy + 1) // 2 + (yx + 1) // 2
        # 等价于：xy // 2 + yx // 2 + (xy % 2 + yx % 2)
        # 因为如果 xy 和 yx 都是奇数，则 (xy % 2 + yx % 2) = 2
        # 否则都是偶数，(xy % 2 + yx % 2) = 0
        return (xy + 1) // 2 + (yx + 1) // 2
```

### 方法三：详细注释版（适合新手）

```python
from typing import List

class Solution:
    def minimumSwap(self, s1: str, s2: str) -> int:
        """
        计算使两个字符串相同所需的最小交换次数
        
        参数:
            s1: 第一个字符串
            s2: 第二个字符串
        
        返回:
            最小交换次数，如果无法相同则返回 -1
        """
        # 步骤 1：统计不匹配的位置
        xy_count = 0  # s1 是 'x'，s2 是 'y' 的位置数
        yx_count = 0  # s1 是 'y'，s2 是 'x' 的位置数
        
        for i in range(len(s1)):
            if s1[i] != s2[i]:
                if s1[i] == 'x':
                    xy_count += 1
                else:
                    yx_count += 1
        
        # 步骤 2：检查是否可能使两个字符串相同
        # 不匹配总数必须是偶数，否则无法配对
        if (xy_count + yx_count) % 2 == 1:
            return -1
        
        # 步骤 3：计算最小交换次数
        swaps = 0
        
        # 每 2 个相同类型的不匹配可以通过 1 次交换解决
        # 例如：s1="xx", s2="yy" 中有 2 个 xy 型
        # 交换 s1[0] 和 s2[1]，变成 s1="yx", s2="yx"
        swaps += xy_count // 2
        swaps += yx_count // 2
        
        # 如果还剩 1 个 xy 型和 1 个 yx 型（xy_count % 2 == 1）
        # 需要 2 次交换来解决
        # 例如：s1="xy", s2="yx"
        # 第 1 次交换：s1[0] 和 s2[0]，得到 s1="yy", s2="xx"
        # 第 2 次交换：s1[0] 和 s2[1]，得到 s1="xy", s2="xy"
        if xy_count % 2 == 1:
            swaps += 2
        
        return swaps
```

## 复杂度分析

### 时间复杂度

- O(n)，其中 n 是字符串的长度
- 只需要遍历一次字符串统计不匹配的位置

### 空间复杂度

- O(1)
- 只使用了常数个变量来存储计数

## 图解示例

以 `s1 = "xxyyxy"`, `s2 = "yxyxyx"` 为例：

```
位置:  0  1  2  3  4  5
s1:    x  x  y  y  x  y
s2:    y  x  y  x  y  x
匹配:  ✗  ✓  ✓  ✗  ✗  ✗
类型:  xy    -  -  yx xy yx

统计：
- xy 型：2 个（位置 0, 4）
- yx 型：2 个（位置 3, 5）

计算：
- xy // 2 = 2 // 2 = 1
- yx // 2 = 2 // 2 = 1
- xy % 2 = 0，无需额外交换
- 总交换次数 = 1 + 1 = 2
```

## 关键点总结

1. **分类统计**：将不匹配位置分为 xy 型和 yx 型两类
2. **奇偶性检查**：不匹配总数必须是偶数才有解
3. **贪心策略**：优先配对同类型的不匹配（1 次交换解决 2 个）
4. **剩余处理**：异类型的不匹配需要 2 次交换
5. **数学优化**：可以用 `(xy + 1) // 2 + (yx + 1) // 2` 简化计算

## 易错点

1. **忘记检查奇偶性**：如果不匹配总数是奇数，直接返回 -1
2. **交换理解错误**：只能交换不同字符串中的字符，不能交换同一字符串内的字符
3. **计数错误**：要正确区分 xy 型和 yx 型
4. **边界情况**：当两个字符串完全相同时，返回 0
5. **公式理解**：`(xy % 2) * 2` 只有在 xy 是奇数时才等于 2，偶数时为 0
