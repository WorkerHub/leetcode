## 题目描述

给你一个字符串数组 `words` 和一个字符串 `s`，返回 `words` 中**是 `s` 的前缀**的字符串的数量。

字符串 `w` 是 `s` 的前缀，当且仅当 `s` 以 `w` 开头。

**示例 1：**
```
输入：words = ["a","b","c","ab","bc","abc"], s = "abc"
输出：3
解释："a"、"ab"、"abc" 都是 "abc" 的前缀。
```

**示例 2：**
```
输入：words = ["a","a"], s = "aa"
输出：2
```

## 解题思路

遍历 `words`，对每个单词检查 `s.startswith(word)`，统计满足条件的数量。

## 代码实现

### 方法一：startswith（推荐）

```python
from typing import List

class Solution:
    def countPrefixes(self, words: List[str], s: str) -> int:
        return sum(1 for w in words if s.startswith(w))
```

### 方法二：字符串切片

```python
from typing import List

class Solution:
    def countPrefixes(self, words: List[str], s: str) -> int:
        count = 0
        for w in words:
            # 检查 s 的前 len(w) 个字符是否等于 w
            if s[:len(w)] == w:
                count += 1
        return count
```

### 方法三：前缀集合

```python
from typing import List

class Solution:
    def countPrefixes(self, words: List[str], s: str) -> int:
        # 预计算 s 的所有前缀
        prefixes = {s[:i] for i in range(1, len(s) + 1)}
        return sum(1 for w in words if w in prefixes)
```

## 复杂度分析

- 时间复杂度：O(sum of len(words[i]))，对每个单词检查是否为前缀。
- 空间复杂度：O(1)（方法一），O(|s|) （方法三）。

## 关键点总结

1. `str.startswith(prefix)` 是 Python 内置函数，简洁高效。
2. 方法三预计算所有前缀存入集合，适合 words 数量很多的情况（O(1) 查询）。

## 易错点

- 注意 `words` 中可能有重复，每个都独立统计。
- `startswith` 方法检查的是前缀，不是子串。
