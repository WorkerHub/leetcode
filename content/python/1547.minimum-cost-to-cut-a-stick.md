## 题目描述

有一根长度为 `n` 个单位的木棍，棍上从 `0` 到 `n` 标有刻度。

给你一个整数数组 `cuts`，其中 `cuts[i]` 表示你需要将木棍切开的位置。每次切割木棍的费用等于**被切割的木棍的长度**，总费用等于所有切割费用之和。

返回完成所有切割所需的**最小总费用**。

**示例 1：**
```
输入：n = 7, cuts = [1,3,4,5]
输出：16
```

## 解题思路

### 区间 DP

将 `cuts` 排序，加入端点 `0` 和 `n`，得到有序切割点列表。

定义 `dp[i][j]` = 在区间 `(cuts[i], cuts[j])` 内进行所有切割的最小费用。

**状态转移：**
`dp[i][j] = min(dp[i][k] + dp[k][j]) + cuts[j] - cuts[i]`，其中 `i < k < j`

即在 `i` 和 `j` 之间选一个切割点 `k` 先切，总费用 = 当前区间长度 + 两子区间最小费用。

## 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List

class Solution:
    def minCost(self, n: int, cuts: List[int]) -> int:
        # 将端点加入，排序
        cuts = sorted([0] + cuts + [n])
        m = len(cuts)
        # dp[i][j] 表示在 cuts[i] 到 cuts[j] 区间内切割的最小费用
        dp = [[0] * m for _ in range(m)]

        # 枚举区间长度（从小到大）
        for length in range(2, m):  # 至少间隔为 2（i+2<=j）
            for i in range(m - length):
                j = i + length
                dp[i][j] = float('inf')
                for k in range(i + 1, j):
                    cost = dp[i][k] + dp[k][j] + cuts[j] - cuts[i]
                    dp[i][j] = min(dp[i][j], cost)

        return dp[0][m - 1]
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def minCost(self, n: int, cuts: List[int]) -> int:
        cuts = sorted([0] + cuts + [n])
        m = len(cuts)

        @lru_cache(maxsize=None)
        def dp(i: int, j: int) -> int:
            if j - i <= 1:
                return 0
            # 在区间 (cuts[i], cuts[j]) 中枚举切割点
            res = float('inf')
            for k in range(i + 1, j):
                cost = dp(i, k) + dp(k, j) + cuts[j] - cuts[i]
                res = min(res, cost)
            return res

        return dp(0, m - 1)
```

## 复杂度分析

- **时间复杂度**：O(M^3)，M = len(cuts) + 2，切割点数量
- **空间复杂度**：O(M^2)，dp 表大小

由于 `cuts.length <= 100`，M <= 102，M^3 ≈ 10^6，可以接受。

## 关键点总结

1. 加入端点 `0` 和 `n`，使区间表示更统一
2. 区间 DP 的状态：`dp[i][j]` = 在 `(cuts[i], cuts[j])` 之间切割的最小费用
3. 转移：枚举第一刀的位置 `k`，费用 = 当前长度 + 左右子问题
4. 按区间长度从小到大计算（确保子问题已解）

## 易错点

- 区间长度从 2 开始（长度为 1 时无切割点，费用为 0）
- 费用包含当前区间长度 `cuts[j] - cuts[i]`（每次切割费用等于被切木棍长度）
