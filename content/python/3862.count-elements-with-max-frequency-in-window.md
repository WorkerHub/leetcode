## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，对于每个长度为 `k` 的窗口，统计出现频率等于窗口内最大频率的元素数目。

返回所有窗口的统计结果数组。

**示例 1：**

```
输入：nums = [1, 2, 2, 3, 2], k = 3
输出：[1, 2, 1]
解释：
- 窗口 [1,2,2]：最大频率 2，有 1 个元素（2）达到最大频率。
- 窗口 [2,2,3]：最大频率 2，有 1 个元素（2）达到最大频率。
- 窗口 [2,3,2]：最大频率 2，有 1 个元素（2）达到最大频率。
```

**示例 2：**

```
输入：nums = [1, 1, 2, 2], k = 2
输出：[1, 2, 1]
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

使用**滑动窗口 + 频率表**：
1. 维护 `freq[v]` = 窗口内值 v 的频率。
2. 维护 `max_freq` = 窗口内最大频率。
3. 维护 `count_max` = 达到最大频率的元素种类数。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countElements(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        freq = defaultdict(int)
        max_freq = 0
        count_max = 0  # 达到 max_freq 的元素种类数
        ans = []

        for i in range(n):
            # 加入右端元素
            v = nums[i]
            freq[v] += 1
            if freq[v] > max_freq:
                max_freq = freq[v]
                count_max = 1
            elif freq[v] == max_freq:
                count_max += 1

            # 窗口大小超过 k，移除左端
            if i >= k:
                lv = nums[i - k]
                if freq[lv] == max_freq:
                    count_max -= 1
                freq[lv] -= 1
                if freq[lv] == 0:
                    del freq[lv]
                # 若最大频率降低，重新计算
                if count_max == 0:
                    max_freq -= 1
                    count_max = sum(1 for c in freq.values() if c == max_freq)

            # 记录结果（窗口大小为 k）
            if i >= k - 1:
                ans.append(count_max)

        return ans
```

### 方法二：暴力（小数据验证）

```python
from typing import List
from collections import Counter

class Solution:
    def countElements(self, nums: List[int], k: int) -> List[int]:
        ans = []
        for i in range(len(nums) - k + 1):
            window = nums[i:i + k]
            cnt = Counter(window)
            max_f = max(cnt.values())
            count_max = sum(1 for v in cnt.values() if v == max_f)
            ans.append(count_max)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一，摊销）；O(n * k)（方法二）
- 空间复杂度：O(k)，窗口频率表

## 关键点总结

1. 维护 `max_freq` 和 `count_max` 两个变量跟踪最大频率及其种类数。
2. 右端元素加入时更新这两个变量：若新频率 > max_freq 则重置，= max_freq 则累加。
3. 左端元素移除时若 count_max 降为 0，说明最大频率降低了 1，需重新统计。

## 易错点

1. `count_max = 0` 时，最大频率降低 1，需要重新扫描频率表（但这种情况不常见）。
2. 窗口大小恰好为 k 后才记录答案（`i >= k - 1`）。
