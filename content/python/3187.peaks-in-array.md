## 题目描述

给你一个整数数组 `nums` 和一个二维整数数组 `queries`。

**峰值** 定义为：`nums[i-1] < nums[i] > nums[i+1]`（1 <= i <= n-2）。

两种查询：
- `queries[j] = [1, index, val]`：将 `nums[index]` 更新为 `val`
- `queries[j] = [2, l, r]`：返回 `nums[l..r]` 中峰值的数量

返回每次类型 2 查询的答案数组。

**提示：**
- `3 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

用树状数组（BIT）维护峰值的前缀和。

- 初始化：计算所有下标是否为峰值，建立 BIT
- 更新操作：修改 nums[index]，重新计算 index-1, index, index+1 的峰值状态
- 查询操作：BIT 区间求和（注意峰值只存在于 [1, n-2]，查询时取交集 [l+1, r-1]）

## Python 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List

class Solution:
    def countOfPeaks(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)

        # 树状数组
        bit = [0] * (n + 1)

        def update(i, delta):
            while i <= n:
                bit[i] += delta
                i += i & (-i)

        def query(i) -> int:
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        def range_query(l, r) -> int:
            if l > r:
                return 0
            return query(r) - query(l - 1)

        def is_peak(i) -> bool:
            return 0 < i < n - 1 and nums[i - 1] < nums[i] > nums[i + 1]

        # 初始化 BIT
        for i in range(1, n - 1):
            if is_peak(i):
                update(i + 1, 1)  # BIT 下标从 1 开始，nums 下标 i 对应 BIT i+1

        def toggle(i, prev_peak: bool):
            curr_peak = is_peak(i)
            if prev_peak and not curr_peak:
                update(i + 1, -1)
            elif not prev_peak and curr_peak:
                update(i + 1, 1)

        ans = []
        for q in queries:
            if q[0] == 1:
                _, idx, val = q
                # 更新前先记录邻居的峰值状态
                prev = [is_peak(j) for j in range(max(0, idx - 1), min(n, idx + 2))]
                nums[idx] = val
                for j_off, j in enumerate(range(max(0, idx - 1), min(n, idx + 2))):
                    if 0 < j < n - 1:
                        toggle(j, prev[j_off - (max(0, idx - 1) - (idx - 1))])
            else:
                _, l, r = q
                # 峰值在 [l+1, r-1] 之间（下标）
                if l + 1 > r - 1:
                    ans.append(0)
                else:
                    ans.append(range_query(l + 2, r))  # BIT 下标 = nums 下标 + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 树状数组维护峰值前缀计数
2. 更新 nums[i] 时，需要重新判断 i-1, i, i+1 三个位置的峰值状态
3. 查询 [l, r] 中的峰值实际是查 [l+1, r-1]

## 易错点

1. 峰值只能在下标 1 到 n-2 之间（首尾不能是峰值）
2. 更新后需要同时检查相邻位置的峰值变化
