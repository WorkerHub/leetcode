## 题目描述

给定一个非负整数数组 nums，如果数组中每对相邻元素之和都是完全平方数，则该数组称为平方数组。

返回 nums 所有排列中平方数组的数量。

## Python 代码实现

```python
from typing import List
from collections import Counter
import math

class Solution:
    def numSquarefulPerms(self, nums: List[int]) -> int:
        def is_square(n):
            root = int(math.sqrt(n))
            return root * root == n
        
        count = Counter(nums)
        
        def dfs(prev, remaining):
            if remaining == 0:
                return 1
            
            result = 0
            for num in count:
                if count[num] > 0:
                    if prev == -1 or is_square(prev + num):
                        count[num] -= 1
                        result += dfs(num, remaining - 1)
                        count[num] += 1
            
            return result
        
        return dfs(-1, len(nums))
```

## 复杂度分析

- 时间复杂度：O(n!)
- 空间复杂度：O(n)
