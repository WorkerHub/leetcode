## 题目描述

给你一个混合了数字和字母的字符串 `s`，其中的字母均为小写英文字母。

请你将该字符串重新格式化，使得任意两个相邻字符的类型都不同。也就是说，字母后面跟着数字，或者数字后面跟着字母。

重新格式化后，返回新的字符串；如果无法重新格式化，则返回一个 **空字符串**。

**示例 1：**

```
输入：s = "a0b1c2"
输出："0a1b2c" 或 "a0b1c2"（任意合法结果均可）
```

**示例 2：**

```
输入：s = "leetcode"
输出：""
解释：只有字母，无法重新格式化。
```

**示例 3：**

```
输入：s = "1229857369"
输出：""
解释：只有数字，无法重新格式化。
```

**示例 4：**

```
输入：s = "covid2019"
输出："c2o0v1i9d"
```

**提示：**

- `1 <= s.length <= 500`
- `s` 仅由小写英文字母和/或数字组成

## 解题思路

### 核心思路

1. 分别收集所有字母和所有数字到两个列表
2. 检查合法性：字母数量和数字数量之差最多为 1（否则无法交替）
3. 若合法，交替合并两个列表

**判断合法性：**
- 若 `|len(letters) - len(digits)| > 1`，返回 `""`
- 若 `len(letters) == len(digits)`，字母开头或数字开头均可
- 若 `len(letters) > len(digits)`，字母开头
- 若 `len(digits) > len(letters)`，数字开头

**合并方式：**

使用 Python 的 `zip` 函数或手动交替拼接。

## Python 代码实现

### 方法一：分组后交替合并（推荐）

```python
class Solution:
    def reformat(self, s: str) -> str:
        # 分别收集字母和数字
        letters = [c for c in s if c.isalpha()]
        digits  = [c for c in s if c.isdigit()]

        # 检查合法性：数量差超过 1 则无法交替
        if abs(len(letters) - len(digits)) > 1:
            return ""

        # 确保 letters 和 digits 中较多的那个放在前面
        # 若数字更多，交换使数字先出现
        if len(digits) > len(letters):
            letters, digits = digits, letters

        # 交替合并：letters 开头（数量 >= digits）
        # letters[0], digits[0], letters[1], digits[1], ...
        result = []
        for i in range(len(digits)):
            result.append(letters[i])
            result.append(digits[i])
        # 若 letters 比 digits 多一个，追加最后一个 letter
        if len(letters) > len(digits):
            result.append(letters[-1])

        return "".join(result)
```

### 方法二：zip 合并（Pythonic 写法）

```python
class Solution:
    def reformat(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()]
        digits  = [c for c in s if c.isdigit()]

        if abs(len(letters) - len(digits)) > 1:
            return ""

        # 确保较多的放前面
        if len(digits) > len(letters):
            letters, digits = digits, letters

        # zip 配对后展开，再拼接多出来的那一个
        # zip(letters, digits) 生成 (l0,d0), (l1,d1), ...
        # 最后如果 letters 多一个，追加到末尾
        paired = [c for pair in zip(letters, digits) for c in pair]
        if len(letters) > len(digits):
            paired.append(letters[-1])

        return "".join(paired)
```

### 方法三：使用 itertools.chain 和 zip_longest

```python
from itertools import zip_longest

class Solution:
    def reformat(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()]
        digits  = [c for c in s if c.isdigit()]

        if abs(len(letters) - len(digits)) > 1:
            return ""

        if len(digits) > len(letters):
            letters, digits = digits, letters

        # zip_longest 用 None 填充较短的列表
        result = []
        for a, b in zip_longest(letters, digits):
            result.append(a)   # a 来自 letters，一定不为 None
            if b is not None:
                result.append(b)

        return "".join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 所有方法 | O(n) | O(n) |

`n` 为字符串长度，只需一次遍历分组，一次遍历合并。

## 关键点总结

1. 分开收集字母和数字，检查数量差是否 ≤ 1
2. 较多的那类字符放在前面（决定首字符类型）
3. 使用 `zip` 交替合并，最后追加多余的那个字符
4. 返回 `"".join(result)` 拼接结果

## 易错点

1. 不要直接用下标合并，边界处理容易出错；用 `zip` 更安全
2. 题目要求返回**任意合法结果**，不需要特定顺序（但需要交替）
3. 只有字母或只有数字时，`abs(len(letters) - len(digits)) > 1`，正确返回 ""
4. 字母和数字恰好一样多时，字母开头或数字开头均可
