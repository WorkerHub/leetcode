## 题目描述

给你一个数组 `nums`，其中 `nums[i]` 是非负整数。

定义 `rev(x)` 为 `x` 的十进制各位反转后的值。例如 `rev(123) = 321`，`rev(120) = 21`。

一个下标对 `(i, j)` 满足 `0 <= i < j < nums.length`，若 `nums[i] + rev(nums[j]) == nums[j] + rev(nums[i])`，则称为 **漂亮数对**。

返回漂亮数对的数目，由于结果可能很大，返回对 `10^9 + 7` 取余的结果。

**示例 1：**
```
输入：nums = [42,11,1,97]
输出：2
解释：漂亮数对为 (0,3) 和 (1,2)
```

**示例 2：**
```
输入：nums = [13,10,35,24,76]
输出：4
```

## 解题思路

等式 `nums[i] + rev(nums[j]) == nums[j] + rev(nums[i])` 等价于：
`nums[i] - rev(nums[i]) == nums[j] - rev(nums[j])`

令 `diff[i] = nums[i] - rev(nums[i])`，问题转化为：统计 diff 数组中相同值的对数。

用哈希表统计每个 diff 值出现的次数，若某值出现 `k` 次，则贡献 `k*(k-1)/2` 对。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from collections import Counter
from typing import List

class Solution:
    def countNicePairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7

        def rev(x: int) -> int:
            """翻转整数各位"""
            return int(str(x)[::-1])

        # 计算每个元素的 diff = nums[i] - rev(nums[i])
        diffs = [x - rev(x) for x in nums]

        # 统计相同 diff 值的对数
        count = Counter(diffs)
        result = 0
        for k in count.values():
            result = (result + k * (k - 1) // 2) % MOD
        return result
```

### 方法二：排序后统计连续相同值

```python
from typing import List

class Solution:
    def countNicePairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7

        def rev(x: int) -> int:
            return int(str(x)[::-1])

        diffs = sorted(x - rev(x) for x in nums)

        result = 0
        i = 0
        n = len(diffs)
        while i < n:
            j = i
            # 统计连续相同的元素个数
            while j < n and diffs[j] == diffs[i]:
                j += 1
            k = j - i  # 相同元素个数
            result = (result + k * (k - 1) // 2) % MOD
            i = j
        return result
```

## 复杂度分析

- **时间复杂度**：O(n * d)，d 为数字位数（最多 10 位），整体约 O(n)
- **空间复杂度**：O(n)，哈希表存储

## 关键点总结

1. 变形等式是关键：将两变量的等式转化为单变量的统计问题
2. 相同 diff 值的 k 个元素，两两配对数为 C(k,2) = k*(k-1)/2
3. 结果需要取模，注意中间计算也可能溢出

## 易错点

- `rev(120) = 21`，不是 021，即翻转后没有前导零
- Python 的 `int(str(x)[::-1])` 自动处理了前导零问题
- 对数取模要在每次累加时取，防止溢出
