## 题目描述

给你一棵有 `n` 个节点（编号 0 到 n-1）的树，每个节点有金币数 `coins[i]`。你从节点 0 出发，每次移动到相邻节点耗时 1。目标是收集所有金币后返回节点 0，返回最小时间。

每个节点的金币只需经过一次即可收集（不需要停留）。

**示例 1：**

```
输入：edges = [[0,1],[0,2],[1,3]], coins = [1,1,1,1]
输出：6
解释：0→1→3→1→0→2→0，路径长度6
```

**提示：**

- `1 <= n <= 3 * 10^4`
- `coins.length == n`
- `0 <= coins[i] <= 10^4`

## 解题思路

贪心 + DFS：类似"收集所有叶子的最小路径"问题。

对于每个子树，若子树中有金币，必须进入并收集，代价为 2 * (子树深度)。无金币的子树可以跳过。

用 DFS 计算每个子树的最大深度（仅考虑有金币的节点），总代价 = 所有需要访问的边 * 2（因为来回）。

## Python 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        if n == 1:
            return 0

        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 拓扑排序，剪枝：删去不含金币的叶子
        from collections import deque
        degree = [len(graph[i]) for i in range(n)]
        queue = deque(i for i in range(n) if degree[i] == 1 and coins[i] == 0)

        while queue:
            node = queue.popleft()
            for nb in graph[node]:
                degree[nb] -= 1
                if degree[nb] == 1 and coins[nb] == 0:
                    queue.append(nb)

        # 再次去除叶子两层（只去一次实际上去两层叶子）
        # 第一轮：去叶子
        queue = deque(i for i in range(n) if degree[i] == 1)
        for _ in range(2):
            new_queue = deque()
            while queue:
                node = queue.popleft()
                degree[node] = 0  # 标记删除
                for nb in graph[node]:
                    if degree[nb] > 0:
                        degree[nb] -= 1
                        if degree[nb] == 1:
                            new_queue.append(nb)
            queue = new_queue

        # 剩余边数 * 2
        ans = sum(2 for u, v in edges if degree[u] > 0 and degree[v] > 0)
        return ans
```

### 方法二：DFS 计算需要访问的深度

```python
from typing import List
from collections import defaultdict

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        visited = [False] * n
        self.ans = 0

        def dfs(node, parent):
            visited[node] = True
            max_depth = 0
            for nb in graph[node]:
                if not visited[nb]:
                    depth = dfs(nb, node)
                    if depth >= 0:
                        self.ans += 2 * (depth + 1)
                    max_depth = max(max_depth, depth + 1 if depth >= 0 else -1)

            if coins[node] > 0 or max_depth > 0:
                return max_depth
            return -1  # 无需访问

        dfs(0, -1)
        return self.ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 无金币的叶子节点可以被剪枝（不需要访问）
2. 每条需要访问的边来回走需要 2 步
3. 拓扑排序剪枝后，统计剩余边数即可

## 易错点

1. 剪枝需迭代进行，直到没有无金币的叶子
2. 答案是 2 * 需要经过的边数，不是节点数
3. 根节点（起点）即使无金币也不能删除
