## 题目描述

给你一个含 n 个整数的数组 nums，其中 nums[i] 在区间 [1, n] 内。请你找出所有在 [1, n] 范围内但没有出现在 nums 中的数字，并以数组的形式返回结果。

**示例 1:**

```
输入: nums = [4,3,2,7,8,2,3,1]
输出: [5,6]
```

**示例 2:**

```
输入: nums = [1,1]
输出: [2]
```

**提示:**

- n == nums.length
- 1 <= n <= 10^5
- 1 <= nums[i] <= n

**进阶:** 你能在不使用额外空间且时间复杂度为 O(n) 的情况下解决这个问题吗？你可以假定返回的数组不算在额外空间内。

## 解题思路

这道题与 [442. Find All Duplicates in an Array](https://leetcode.com/problems/find-all-duplicates-in-an-array/) 非常相似，都利用了**数字范围 [1, n] 与索引范围 [0, n-1] 的对应关系**。

**核心思想：原地哈希标记法**

1. 遍历数组，对于每个数字 num，将索引 `abs(num) - 1` 位置的数字标记为负数
2. 第二次遍历数组，如果索引 i 位置的数字是正数，说明数字 i+1 没有出现过
3. 将 i+1 加入结果数组

**为什么可以用负数标记？**
- 所有数字都是正数（1 到 n）
- 将某个位置标记为负数不影响我们获取其绝对值
- 负数表示"这个位置对应的数字出现过"

## Python 代码实现

### 方法一：原地哈希标记法（推荐，符合进阶要求）

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        """
        原地哈希标记法
        时间复杂度: O(n)
        空间复杂度: O(1) - 不计输出数组
        """
        # 第一次遍历：标记出现过的数字
        for num in nums:
            # 获取绝对值（因为可能已经被标记为负数）
            index = abs(num) - 1
            # 标记为负数
            if nums[index] > 0:
                nums[index] = -nums[index]
        
        # 第二次遍历：找出未被标记的位置
        result = []
        for i in range(len(nums)):
            if nums[i] > 0:
                # 索引 i 对应的数字 i+1 没有出现
                result.append(i + 1)
        
        return result
```

### 方法二：集合法（不符合空间要求，但思路简单）

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        """
        使用集合求差集
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        # 创建包含所有应该出现的数字的集合
        full_set = set(range(1, len(nums) + 1))
        # 创建实际出现的数字的集合
        nums_set = set(nums)
        # 求差集
        return list(full_set - nums_set)
```

### 方法三：计数数组法

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        """
        使用额外的计数数组
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        n = len(nums)
        count = [0] * (n + 1)  # 索引 0 不使用
        
        # 统计每个数字出现次数
        for num in nums:
            count[num] += 1
        
        # 找出出现次数为 0 的数字
        result = []
        for i in range(1, n + 1):
            if count[i] == 0:
                result.append(i)
        
        return result
```

### 方法四：位置交换法

```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        """
        将每个数字放到其应该在的位置
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        n = len(nums)
        
        # 将每个数字放到正确的位置
        for i in range(n):
            # 将 nums[i] 放到索引 nums[i]-1 的位置
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                correct_index = nums[i] - 1
                nums[i], nums[correct_index] = nums[correct_index], nums[i]
        
        # 找出位置不正确的数字
        result = []
        for i in range(n):
            if nums[i] != i + 1:
                result.append(i + 1)
        
        return result
```

## 复杂度分析

**方法一（原地哈希标记）：**
- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)，只使用常量额外空间

**方法二（集合法）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法三（计数数组）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法四（位置交换）：**
- 时间复杂度：O(n)，虽然有嵌套循环，但每个元素最多交换一次
- 空间复杂度：O(1)

## 关键点总结

1. **数组索引映射**：数字 num 对应索引 num-1
2. **负数标记技巧**：用负数表示"已访问"，不需要额外空间
3. **绝对值使用**：取 `abs(num)` 获取原始数字
4. **两次遍历**：第一次标记，第二次收集结果
5. **原地修改**：满足 O(1) 空间复杂度要求

## 易错点

1. **忘记取绝对值**：
   ```python
   # 错误：num 可能已经被标记为负数
   index = num - 1
   
   # 正确：使用绝对值
   index = abs(num) - 1
   ```

2. **重复标记问题**：
   ```python
   # 推荐：先判断是否已经为负数
   if nums[index] > 0:
       nums[index] = -nums[index]
   
   # 或者：直接取绝对值后变负
   nums[index] = -abs(nums[index])
   ```

3. **索引越界**：
   - 数字范围是 [1, n]
   - 索引范围是 [0, n-1]
   - 映射关系是 `index = num - 1`

4. **结果范围**：
   - 缺失的数字是 `i + 1` 而不是 `i`
   - 不要忘记 +1
