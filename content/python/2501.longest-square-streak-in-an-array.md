## 题目描述

给你一个整数数组 `nums`。如果 `nums` 的子序列满足下述条件，则认为该子序列是一个 **平方连续序列**：

- 子序列的长度至少为 2
- 将子序列从小到大排序后，除第一个元素外，每个元素都是前一个元素的 **平方**

返回 `nums` 中最长平方连续序列的长度，如果不存在平方连续序列，则返回 `-1`。

**示例 1：**

```
输入：nums = [4, 3, 6, 16, 8, 2]
输出：3
解释：子序列 [2, 4, 16]，满足 4=2²，16=4²，长度为 3。
```

**示例 2：**

```
输入：nums = [2, 3, 5, 6, 7]
输出：-1
```

**提示：**

- `2 <= nums.length <= 10^5`
- `2 <= nums[i] <= 10^5`

## 解题思路

将数组存入哈希集合，然后对每个数字 x 构建以 x 为起点的平方序列：x, x², x⁴, ...。

优化：只从序列起点（即 √x 不在集合中，或 x 本身不是某元素的平方）开始构建，避免重复计算。

动态规划思路：dp[x] 表示以 x 结尾的最长平方序列。若 √x 是整数且在集合中，则 dp[x] = dp[√x] + 1。

## Python 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List
import math

class Solution:
    def longestSquareStreak(self, nums: List[int]) -> int:
        num_set = set(nums)
        max_len = -1

        for num in num_set:
            # 检查当前数是否是序列的起点（其平方根不在集合中）
            sqrt_val = math.isqrt(num)
            if sqrt_val * sqrt_val == num and sqrt_val in num_set:
                # 当前数不是起点，跳过，避免重复
                continue

            # 从当前数开始，不断平方，统计序列长度
            length = 1
            cur = num
            while cur * cur in num_set:
                cur = cur * cur
                length += 1

            if length >= 2:
                max_len = max(max_len, length)

        return max_len
```

### 方法二：排序 + 动态规划

```python
from typing import List
import math

class Solution:
    def longestSquareStreak(self, nums: List[int]) -> int:
        # 排序去重后用 DP
        nums_sorted = sorted(set(nums))
        # dp[x] 表示以 x 结尾的最长平方序列长度
        dp = {}
        max_len = -1

        for num in nums_sorted:
            sqrt_val = math.isqrt(num)
            if sqrt_val * sqrt_val == num and sqrt_val in dp:
                # 当前数是 sqrt_val 的平方，序列可延伸
                dp[num] = dp[sqrt_val] + 1
                if dp[num] >= 2:
                    max_len = max(max_len, dp[num])
            else:
                dp[num] = 1

        return max_len
```

## 复杂度分析

- 时间复杂度：O(n log log M)，M 为最大值，每个数最多平方 log log M 次
- 空间复杂度：O(n)，哈希集合和 DP 字典的开销

## 关键点总结

1. 平方序列增长极快，序列长度不超过 log log(10^5) ≈ 4
2. 方法二的 DP 更简洁：从小到大处理，若完全平方根在 dp 中则延伸
3. 需要去重，相同元素只计算一次

## 易错点

1. 浮点精度：`int(x**0.5)` 对大数可能有误差，推荐使用 `math.isqrt`
2. 只有长度 >= 2 才算有效序列，单个元素不算
3. 注意 `cur * cur` 在 Python 中不会溢出，但可能超过集合范围
