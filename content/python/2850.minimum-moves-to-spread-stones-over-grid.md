## 题目描述

给你一个大小为 3x3 的整数矩阵 `grid`，每个格子初始有若干块石头。

每次移动，你可以将一块石头移到相邻（上下左右）的格子。

返回使每个格子恰好有 1 块石头所需的**最少移动次数**（曼哈顿距离总和）。

**示例 1：**
```
输入：grid = [[1,1,0],[1,1,1],[1,2,1]]
输出：1
解释：将 grid[2][1] 的一块多余石头移到 grid[0][2]
```

**示例 2：**
```
输入：grid = [[1,3,0],[1,0,0],[1,0,3]]
输出：4
```

**提示：**
- `grid.length == grid[i].length == 3`
- `0 <= grid[i][j] <= 9`
- `sum(grid[i][j]) == 9`（总石头数等于格子数）

## 解题思路

网格大小固定为 3×3，最多 9 个格子。

**策略：** 找出所有多余石头（grid[i][j] > 1）的位置（和数量）和空格（grid[i][j] == 0）的位置，然后通过**全排列枚举**最优匹配。

每块多余石头需要移到某个空格，移动次数 = 曼哈顿距离。

由于空格和多余石头的数量不多（最多 9 个格子），枚举全排列 O(k!) 可行（k <= 9）。

实际上，也可以用**最小费用最大流**或**匈牙利算法**，但数据量小，枚举更简单。

## Python 代码实现

### 方法一：全排列枚举（推荐）

```python
from typing import List
from itertools import permutations

class Solution:
    def minimumMoves(self, grid: List[List[int]]) -> int:
        # 收集多余石头（每块多余 1 的石头记录位置）
        extras = []
        empties = []
        for i in range(3):
            for j in range(3):
                if grid[i][j] > 1:
                    for _ in range(grid[i][j] - 1):
                        extras.append((i, j))  # 每块多余的石头
                elif grid[i][j] == 0:
                    empties.append((i, j))

        # 多余石头和空格一定数量相等
        ans = float('inf')
        for perm in permutations(range(len(empties))):
            # 将 extras[i] 的石头移到 empties[perm[i]]
            cost = sum(
                abs(extras[i][0] - empties[perm[i]][0]) + abs(extras[i][1] - empties[perm[i]][1])
                for i in range(len(extras))
            )
            ans = min(ans, cost)

        return ans
```

### 方法二：DP 状态压缩（更高效）

```python
from typing import List

class Solution:
    def minimumMoves(self, grid: List[List[int]]) -> int:
        extras = []
        empties = []
        for i in range(3):
            for j in range(3):
                if grid[i][j] > 1:
                    for _ in range(grid[i][j] - 1):
                        extras.append((i, j))
                elif grid[i][j] == 0:
                    empties.append((i, j))

        n = len(empties)
        # dp[mask] = 已分配 empties[i] (i in mask) 所需最少移动
        dp = [float('inf')] * (1 << n)
        dp[0] = 0

        for mask in range(1 << n):
            # 当前分配了 popcount(mask) 个 empty，使用 extras[popcount(mask)] 来分配
            assigned = bin(mask).count('1')
            if assigned >= n:
                continue
            # 选择下一个 empty 分配
            for j in range(n):
                if not (mask >> j & 1):
                    dist = abs(extras[assigned][0] - empties[j][0]) + abs(extras[assigned][1] - empties[j][1])
                    dp[mask | (1 << j)] = min(dp[mask | (1 << j)], dp[mask] + dist)

        return dp[(1 << n) - 1]
```

## 复杂度分析

- 方法一：时间 O(k! × k)，k 为多余/空格数（最多 9），空间 O(k)
- 方法二：时间 O(2^k × k)，空间 O(2^k)

## 关键点总结

1. 分解多余石头和空格，问题变为最优匹配
2. 全排列枚举简单可行（k <= 9，9! = 362880 可接受）
3. 每次移动代价 = 曼哈顿距离（上下左右移动）

## 易错点

1. 每块多余石头单独计入 extras（而不是每个格子），才能正确枚举
2. extras 和 empties 数量相等（总石头数 = 格子数 = 9）
3. 枚举 empties 的全排列，而非 extras（因为 extras 顺序固定）
