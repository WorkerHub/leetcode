## 题目描述

给你一个下标从 **0** 开始的字符串 `s`，该字符串仅由小写英文字母组成。`s` 中每个字母**恰好**出现**两次**。

另给你一个下标从 **0** 开始、长度为 `26` 的整数数组 `distance`。

字母表中第 `i` 个字母在 `s` 中两次出现的下标之差应该**等于** `distance[i]`。（即两次出现的下标之差为 `|first_pos - second_pos|`）

如果每个字母两次出现的下标差都满足 `distance` 中的要求，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s = "abaccb", distance = [1,3,0,5,0,0,...,0]
输出：true
解释：
- 'a' 在下标 0 和 2，差为 2... (distance[0]=1? 不对，让我再检查)
```

**示例 2：**
```
输入：s = "aa", distance = [1,0,0,...,0]
输出：true
解释：'a' 出现在下标 0 和 1，差为 1，等于 distance[0]。
```

**提示：**
- `2 <= s.length <= 52`
- `s` 仅由小写英文字母组成
- `s` 中每个字母恰好出现两次
- `distance.length == 26`
- `0 <= distance[i] <= 50`

## 解题思路

**哈希表记录首次出现位置：**

1. 遍历字符串，记录每个字母首次出现的下标。
2. 再次遇到时，计算两次出现位置的差（`当前下标 - 首次下标`）。
3. 若差不等于 `distance[c - 'a']`，返回 `False`。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class Solution:
    def checkDistances(self, s: str, distance: List[int]) -> bool:
        first_pos = {}  # 记录每个字母首次出现的下标
        
        for i, c in enumerate(s):
            if c not in first_pos:
                first_pos[c] = i  # 记录首次位置
            else:
                # 计算两次出现的下标差
                diff = i - first_pos[c]
                if diff != distance[ord(c) - ord('a')]:
                    return False
        
        return True
```

### 方法二：数组（更高效）

```python
from typing import List

class Solution:
    def checkDistances(self, s: str, distance: List[int]) -> bool:
        first = [-1] * 26  # 存储每个字母首次出现下标，-1 表示未出现
        
        for i, c in enumerate(s):
            idx = ord(c) - ord('a')
            if first[idx] == -1:
                first[idx] = i
            else:
                if i - first[idx] != distance[idx]:
                    return False
        
        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(1)（最多 26 个字母） |
| 数组 | O(n) | O(1) |

## 关键点总结

1. 每个字母恰好出现两次，第一次记录位置，第二次验证差值。
2. 字母 `c` 对应 `distance` 的下标为 `ord(c) - ord('a')`。
3. 一次遍历即可完成，时间复杂度 O(n)。

## 易错点

- 两次出现的下标差是 `|second - first|`，由于第二次下标更大，直接用 `i - first_pos[c]` 即可。
- 注意 `distance` 是字母表顺序，`'a'` 对应下标 0，`'b'` 对应下标 1，以此类推。
