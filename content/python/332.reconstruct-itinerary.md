## 题目描述

给你一份航线列表 `tickets`，其中 `tickets[i] = [from_i, to_i]` 表示飞机出发和降落的机场地点。请你对该行程进行重新规划排序。

所有这些机票都属于一个从 `JFK`（肯尼迪国际机场）出发的先生，所以该行程必须从 `JFK` 开始。如果存在多种有效的行程，请你按**字典序**返回最小的行程组合。

- 例如，行程 `["JFK", "LGA"]` 与 `["JFK", "LGB"]` 相比就更小，字典序更靠前。

假定所有机票至少存在一种合理的行程。且所有的机票必须都用一次且只能用一次。

**示例 1:**

```
输入：tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]
输出：["JFK","MUC","LHR","SFO","SJC"]
```

**示例 2:**

```
输入：tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]
输出：["JFK","ATL","JFK","SFO","ATL","SFO"]
解释：另一种有效的行程是 ["JFK","SFO","ATL","JFK","ATL","SFO"]，但是它字典序更大。
```

**提示:**

- `1 <= tickets.length <= 300`
- `tickets[i].length == 2`
- `from_i.length == 3`
- `to_i.length == 3`
- `from_i` 和 `to_i` 由大写英文字母组成
- `from_i != to_i`

## 解题思路

这道题是经典的**欧拉路径**问题，使用 **Hierholzer 算法**求解。

### 核心概念

1. **欧拉路径**：图中经过每条边恰好一次的路径
2. **欧拉回路**：起点和终点相同的欧拉路径

### 算法思想

1. **构建图**：用邻接表存储图，每个机场对应一个目的地列表
2. **排序**：将每个机场的目的地按字典序排序（保证字典序最小）
3. **DFS 遍历**：
   - 从 `JFK` 开始深度优先搜索
   - 每次选择字典序最小的未访问边
   - 访问完所有边后，将节点加入结果
4. **逆序输出**：DFS 的访问顺序是逆序的，需要反转

### Hierholzer 算法原理

- **后序遍历**：先访问完所有邻居，再将当前节点加入结果
- **为什么逆序？**：因为是后序遍历，最后访问的节点（终点）先加入结果

## Python 代码实现

### 方法一：Hierholzer 算法（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def findItinerary(self, tickets: List[List[str]]) -> List[str]:
        """
        Hierholzer 算法：求欧拉路径
        """
        # 构建图（邻接表）
        graph = defaultdict(list)
        for src, dst in tickets:
            graph[src].append(dst)
        
        # 对每个机场的目的地按字典序排序
        for src in graph:
            graph[src].sort(reverse=True)  # 逆序排序，方便后续 pop
        
        result = []
        
        def dfs(airport: str):
            """深度优先搜索"""
            # 访问所有邻居
            while graph[airport]:
                # 选择字典序最小的邻居（因为是逆序，所以 pop 最后一个）
                next_airport = graph[airport].pop()
                dfs(next_airport)
            
            # 后序遍历：所有邻居访问完后，将当前节点加入结果
            result.append(airport)
        
        dfs("JFK")
        
        # 逆序返回（因为是后序遍历）
        return result[::-1]
```

### 方法二：迭代版 Hierholzer 算法

```python
from typing import List
from collections import defaultdict

class Solution:
    def findItinerary(self, tickets: List[List[str]]) -> List[str]:
        """
        迭代版 Hierholzer 算法
        """
        # 构建图
        graph = defaultdict(list)
        for src, dst in tickets:
            graph[src].append(dst)
        
        # 排序
        for src in graph:
            graph[src].sort(reverse=True)
        
        stack = ["JFK"]
        result = []
        
        while stack:
            current = stack[-1]
            
            # 如果当前节点有未访问的邻居
            if graph[current]:
                # 访问字典序最小的邻居
                next_airport = graph[current].pop()
                stack.append(next_airport)
            else:
                # 所有邻居都访问完了，将当前节点加入结果
                result.append(stack.pop())
        
        # 逆序返回
        return result[::-1]
```

### 方法三：使用优先队列（堆）

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def findItinerary(self, tickets: List[List[str]]) -> List[str]:
        """
        使用最小堆保证字典序
        """
        # 构建图（使用最小堆）
        graph = defaultdict(list)
        for src, dst in tickets:
            heapq.heappush(graph[src], dst)
        
        result = []
        
        def dfs(airport: str):
            # 访问所有邻居（按字典序）
            while graph[airport]:
                next_airport = heapq.heappop(graph[airport])
                dfs(next_airport)
            
            # 后序遍历
            result.append(airport)
        
        dfs("JFK")
        
        return result[::-1]
```

### 方法四：回溯 DFS（备选方案）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findItinerary(self, tickets: List[List[str]]) -> List[str]:
        """
        回溯 DFS（较慢，但更直观）
        """
        # 构建图
        graph = defaultdict(list)
        for src, dst in tickets:
            graph[src].append(dst)
        
        # 排序
        for src in graph:
            graph[src].sort()
        
        result = []
        
        def dfs(airport: str, path: List[str]):
            # 所有机票都用完了
            if len(path) == len(tickets) + 1:
                result.append(path[:])
                return True
            
            # 尝试所有目的地
            for i, next_airport in enumerate(graph[airport]):
                # 使用这张机票
                graph[airport].pop(i)
                path.append(next_airport)
                
                if dfs(next_airport, path):
                    return True
                
                # 回溯
                path.pop()
                graph[airport].insert(i, next_airport)
            
            return False
        
        dfs("JFK", ["JFK"])
        return result[0] if result else []
```

## 复杂度分析

**方法一/二/三：Hierholzer 算法**

- **时间复杂度**：O(E log E)
  - E：边的数量（机票数）
  - 排序：O(E log E)
  - DFS：O(E)，每条边访问一次
  
- **空间复杂度**：O(E)
  - 图的存储：O(E)
  - 递归栈/显式栈：O(E)

**方法四：回溯 DFS**

- **时间复杂度**：O(E!)
  - 最坏情况下尝试所有排列
  
- **空间复杂度**：O(E)

## 关键点总结

1. **欧拉路径问题**：每条边恰好经过一次
2. **Hierholzer 算法**：后序遍历 + 逆序输出
3. **字典序最小**：对邻居按字典序排序
4. **逆序排序技巧**：`sort(reverse=True)` + `pop()` 等价于正序 + `pop(0)`，但效率更高
5. **后序遍历**：先访问完所有邻居，再处理当前节点
6. **为什么要逆序**：DFS 后序遍历得到的是逆序的路径

## 易错点

1. **排序方向**：
   - 正序排序 + `pop(0)`：O(n)
   - 逆序排序 + `pop()`：O(1)（推荐）

2. **后序遍历理解**：
   - 错误：先将当前节点加入结果，再访问邻居
   - 正确：先访问完所有邻居，再将当前节点加入结果

3. **结果要逆序**：因为是后序遍历

4. **图的构建**：使用 `defaultdict(list)` 避免 KeyError

5. **起点固定**：必须从 `"JFK"` 开始

12. 回到 JFK，加入结果：result = [SFO, ATL, SFO, JFK, ATL, JFK]
