## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成尽可能多的**唯一非空子字符串**（不能重复）。

注意：分割后子字符串按顺序拼接仍需等于 `s`。

**示例 1：**
```
输入：s = "ababccc"
输出：5
解释：一种分割方案是 ["a", "b", "ab", "c", "cc"]，共 5 段。
```

**示例 2：**
```
输入：s = "aba"
输出：2
解释：["a", "ba"] 或 ["ab", "a"]
```

**提示：**
- `1 <= s.length <= 16`

## 解题思路

### 回溯

字符串长度 ≤ 16，可以枚举所有可能的分割方式。

**思路：**
1. 从当前位置开始，枚举所有前缀子串
2. 若该子串未被使用过，加入集合，继续递归处理剩余部分
3. 递归返回时回溯（移出集合）
4. 记录最大分割数

**剪枝：** 若当前已用段数 + 剩余字符数 ≤ 当前最优，可以提前终止。

## 代码实现

### 方法一：回溯（推荐）

```python
class Solution:
    def maxUniqueSplit(self, s: str) -> int:
        n = len(s)
        self.ans = 1
        used = set()

        def backtrack(start, count):
            # 剪枝：即使剩余每个字符都独立，也不会超过当前最优
            if count + (n - start) <= self.ans:
                return
            if start == n:
                self.ans = max(self.ans, count)
                return
            for end in range(start + 1, n + 1):
                sub = s[start:end]
                if sub not in used:
                    used.add(sub)
                    backtrack(end, count + 1)
                    used.remove(sub)

        backtrack(0, 0)
        return self.ans
```

### 方法二：回溯（不带剪枝，用于对比）

```python
class Solution:
    def maxUniqueSplit(self, s: str) -> int:
        n = len(s)
        ans = [0]

        def dfs(i, seen):
            if i == n:
                ans[0] = max(ans[0], len(seen))
                return
            for j in range(i + 1, n + 1):
                t = s[i:j]
                if t not in seen:
                    seen.add(t)
                    dfs(j, seen)
                    seen.remove(t)

        dfs(0, set())
        return ans[0]
```

## 复杂度分析

- **时间复杂度**：O(N · 2^N)，最多 2^N 种分割方式，每次比较 O(N)
- **空间复杂度**：O(N)，递归栈深度和集合大小

## 关键点总结

1. 字符串长度 ≤ 16，回溯可行
2. 集合维护已使用子串，回溯时撤销
3. 剪枝优化：剩余长度不足时提前退出

## 易错点

- 子字符串必须**连续**，不是子序列
- 回溯时要从集合中移除（恢复现场）
- 剪枝条件 `count + (n - start) <= self.ans` 注意是 `<=`
