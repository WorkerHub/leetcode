## 题目描述

给你一个由字符串二元组组成的数组 `equations`，以及一个实数值数组 `values`，其中 `equations[i] = [A_i, B_i]` 且 `values[i]` 表示 `A_i / B_i = values[i]`。

判断这些方程式是否存在**矛盾**。如果存在矛盾，返回 `true`；否则返回 `false`。

**注意：**两个方程式不会同时出现 `A / B = v` 和 `A / B = w`（`v != w`）的情况。

**示例 1：**
```
输入：equations = [["a","b"],["b","c"],["a","c"]], values = [3,0.5,1.5]
输出：false
解释：a/b=3，b/c=0.5，则 a/c=1.5，与第三个方程一致，无矛盾。
```

**示例 2：**
```
输入：equations = [["le","et"],["le","code"],["code","et"]], values = [2,5,0.5]
输出：true
解释：le/et=2，le/code=5，则 code/et=0.4，但给出 code/et=0.5，矛盾。
```

**提示：**
- `1 <= equations.length <= 100`
- `equations[i].length == 2`
- `1 <= equations[i][0].length, equations[i][1].length <= 5`
- `values.length == equations.length`
- `0 < values[i] <= 10`

## 解题思路

**方法一：带权并查集**

用带权并查集维护每个节点相对于根节点的比值。合并时检查是否产生矛盾。

**方法二：建图 + DFS**

建立带权有向图，对每对节点用 DFS 求比值，检查是否与给定值一致。

## 代码实现

### 方法一：带权并查集（推荐）

```python
from typing import List

class Solution:
    def checkContradictions(self, equations: List[List[str]], values: List[float]) -> bool:
        # 带权并查集：parent[x] = (root, ratio)，表示 x / root = ratio
        parent = {}

        def find(x):
            if x not in parent:
                parent[x] = (x, 1.0)
            root, ratio = parent[x]
            if root == x:
                return x, 1.0
            # 路径压缩
            real_root, root_ratio = find(root)
            parent[x] = (real_root, ratio * root_ratio)
            return parent[x]

        def union(x, y, val):
            # x / y = val
            rx, ratio_x = find(x)
            ry, ratio_y = find(y)
            if rx == ry:
                # 已在同一集合，检查是否矛盾
                # x / root = ratio_x，y / root = ratio_y
                # x / y = ratio_x / ratio_y
                return abs(ratio_x / ratio_y - val) > 1e-5
            # 合并：将 ry 挂到 rx 下
            # x / rx = ratio_x，y / ry = ratio_y
            # x / y = val => ratio_x / (ratio_y * (ry / rx)) = val
            # => ry / rx = ratio_x / (ratio_y * val)
            parent[ry] = (rx, ratio_x / (ratio_y * val))
            return False

        for (a, b), val in zip(equations, values):
            if union(a, b, val):
                return True
        return False
```

### 方法二：建图 + DFS

```python
from typing import List
from collections import defaultdict

class Solution:
    def checkContradictions(self, equations: List[List[str]], values: List[float]) -> bool:
        # 建带权有向图
        graph = defaultdict(list)
        for (a, b), val in zip(equations, values):
            graph[a].append((b, val))
            graph[b].append((a, 1.0 / val))

        # 记录每个节点相对某基准的比值
        ratio = {}

        def dfs(node, val):
            if node in ratio:
                # 检查是否矛盾
                return abs(ratio[node] - val) > 1e-5
            ratio[node] = val
            for neighbor, w in graph[node]:
                if dfs(neighbor, val / w):
                    return True
            return False

        # 对每个连通分量做 DFS
        for node in list(graph.keys()):
            if node not in ratio:
                if dfs(node, 1.0):
                    return True

        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 带权并查集 | O(n * alpha(n)) | O(n) |
| 建图 DFS | O(n^2) | O(n) |

## 关键点总结

1. 带权并查集中每个节点存储与根节点的比值关系。
2. 合并时若两节点已在同一集合，检查比值是否一致。
3. 使用浮点数比较时需要容忍微小误差（如 `1e-5`）。

## 易错点

- 浮点数精度问题：比较时需使用容差而非 `==`。
- 路径压缩时要同步更新权值。
