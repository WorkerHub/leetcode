## 题目描述

给定 `n` 个节点的无向图，节点编号 `0` 到 `n-1`，每个节点有权值 `nums[i]`。若两个节点 `u, v` 满足 `|nums[u] - nums[v]| <= maxDiff`，则它们之间存在边。给定若干查询 `[u, v]`，判断节点 `u` 和节点 `v` 之间是否存在路径。

**示例 1：**

```
输入：n = 3, nums = [0, 1, 3], maxDiff = 1, queries = [[0,1],[0,2]]
输出：[true, false]
解释：
边：|0-1|=1<=1 -> 0-1，|0-3|=3>1 -> 无，|1-3|=2>1 -> 无
0 和 1 连通，0 和 2 不连通。
```

**提示：**
- `1 <= n <= 100`
- `0 <= nums[i] <= 100`
- `0 <= maxDiff <= 100`
- `1 <= queries.length <= 100`

## 解题思路

由于 n 较小，可以直接建图后用 BFS/DFS 或并查集判断连通性。

关键：两节点之间有边当且仅当权值差的绝对值不超过 `maxDiff`。

更高效的观察：将节点按权值排序，则只有权值相近的节点才连通，形成连续的"区间块"。权值在同一区间内（区间长度为 `maxDiff`）的节点相互连通（通过中间节点可以传递连通性）。

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int],
                              maxDiff: int, queries: List[List[int]]) -> List[bool]:
        # 并查集
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py

        # 建图：枚举所有节点对
        for i in range(n):
            for j in range(i+1, n):
                if abs(nums[i] - nums[j]) <= maxDiff:
                    union(i, j)

        return [find(u) == find(v) for u, v in queries]
```

### 方法二：BFS

```python
from typing import List
from collections import deque

class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int],
                              maxDiff: int, queries: List[List[int]]) -> List[bool]:
        # 建邻接表
        graph = [[] for _ in range(n)]
        for i in range(n):
            for j in range(i+1, n):
                if abs(nums[i] - nums[j]) <= maxDiff:
                    graph[i].append(j)
                    graph[j].append(i)

        def bfs(start, end):
            if start == end:
                return True
            visited = {start}
            queue = deque([start])
            while queue:
                node = queue.popleft()
                for nb in graph[node]:
                    if nb == end:
                        return True
                    if nb not in visited:
                        visited.add(nb)
                        queue.append(nb)
            return False

        return [bfs(u, v) for u, v in queries]
```

## 复杂度分析

- 时间复杂度：O(n^2 + q * alpha(n))（并查集），O(n^2 + q * n)（BFS）
- 空间复杂度：O(n^2)，邻接表存储

## 关键点总结

1. 边的存在条件：权值差绝对值不超过 maxDiff
2. 并查集高效判断连通性，预处理一次即可回答所有查询
3. 连通性是传递的，通过中间节点可以间接连通

## 易错点

1. 需要枚举所有节点对（不只是相邻的）
2. 并查集的路径压缩保证查询效率
3. 自身到自身的查询返回 true
