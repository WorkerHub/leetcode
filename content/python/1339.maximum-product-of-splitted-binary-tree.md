## 题目描述

给你一棵二叉树，它的根为 `root`。请你删除 1 条边，使二叉树分裂成两棵子树，且它们所有节点值之积**最大**。

由于答案可能很大，请你将结果对 `10^9 + 7` 取模后再返回。

**示例 1：**
```
输入：root = [1,2,3,4,5,6]
输出：110
解释：删除红色的边后，得到两棵子树，节点值分别为 [1,2,3,4,5] 和 [6]，乘积 = 26 * 6 = 110。
```

**示例 2：**
```
输入：root = [1,null,2,3,4]
输出：6
解释：子树 [3] 和 [1,null,2,null,4]，乘积 = 3 * 3 = 9？不对。
     子树 [2,3,4] 和 [1]，乘积 = 9 * 1 = 9？
     最大乘积是 6 = 2 * 3。
```

**示例 3：**
```
输入：root = [1,2,3,null,4,null,5]
输出：1000
```

**提示：**
- 每棵树最多有 `50000` 个节点，且至少有 `2` 个节点。
- 每个节点的值在 `[1, 10000]` 之间。

## 解题思路

**核心观察：**

删除一条边后，树分成两部分：一部分是某个子树（设其节点和为 `sub`），另一部分是剩余的树（节点和为 `total - sub`）。

因此，乘积 = `sub * (total - sub)`。

**算法步骤：**
1. 第一次 DFS：计算整棵树所有节点的总和 `total`
2. 第二次 DFS：计算每个子树的节点和，寻找使 `sub * (total - sub)` 最大的 `sub`
3. 返回最大乘积对 `10^9 + 7` 取模的结果

**注意：** 取模应在最后取，中间计算时不能取模（取模会影响大小比较）。

## Python 代码实现

### 方法一：两次 DFS（推荐）

```python
from typing import Optional

# 二叉树节点定义
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxProduct(self, root: Optional[TreeNode]) -> int:
        MOD = 10 ** 9 + 7
        
        # 第一次 DFS：计算整棵树的总和
        def tree_sum(node):
            if not node:
                return 0
            return node.val + tree_sum(node.left) + tree_sum(node.right)
        
        total = tree_sum(root)
        
        # 第二次 DFS：遍历每个子树和，找最大乘积
        self.max_prod = 0
        
        def dfs(node):
            if not node:
                return 0
            # 当前子树的节点和
            sub = node.val + dfs(node.left) + dfs(node.right)
            # 删除连接此节点与父节点的边，乘积为 sub * (total - sub)
            self.max_prod = max(self.max_prod, sub * (total - sub))
            return sub
        
        dfs(root)
        
        return self.max_prod % MOD
```

### 方法二：一次 DFS（记录所有子树和）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxProduct(self, root: Optional[TreeNode]) -> int:
        MOD = 10 ** 9 + 7
        
        # 收集所有子树的节点和
        sub_sums = []
        
        def dfs(node) -> int:
            if not node:
                return 0
            s = node.val + dfs(node.left) + dfs(node.right)
            sub_sums.append(s)
            return s
        
        total = dfs(root)  # 最后一个（根节点）即为总和
        
        # 对每个子树和，计算乘积 sub * (total - sub)
        max_prod = max(s * (total - s) for s in sub_sums)
        
        return max_prod % MOD
```

### 方法三：详细注释版（适合新手理解）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxProduct(self, root: Optional[TreeNode]) -> int:
        MOD = 10 ** 9 + 7
        
        # 步骤 1：计算整棵树的节点值之和
        def calc_sum(node) -> int:
            if node is None:
                return 0
            return node.val + calc_sum(node.left) + calc_sum(node.right)
        
        total_sum = calc_sum(root)
        
        # 步骤 2：枚举每条边（等价于枚举每个非根子树）
        # 删除某条边后，一棵子树的和为 sub，另一部分的和为 total_sum - sub
        # 乘积 = sub * (total_sum - sub)
        # 注意：要在取模之前找最大值！
        
        best = [0]  # 用列表以便在嵌套函数中修改
        
        def find_best(node) -> int:
            """返回以 node 为根的子树的节点和，并更新最大乘积"""
            if node is None:
                return 0
            
            # 递归计算左右子树和
            left_sum = find_best(node.left)
            right_sum = find_best(node.right)
            
            # 当前子树的节点和
            current_sum = node.val + left_sum + right_sum
            
            # 如果删除 node 与其父节点的连接：
            # 一部分和 = current_sum，另一部分和 = total_sum - current_sum
            product = current_sum * (total_sum - current_sum)
            best[0] = max(best[0], product)
            
            return current_sum
        
        find_best(root)
        
        # 步骤 3：取模后返回
        return best[0] % MOD
```

### 方法四：Python 简洁写法

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxProduct(self, root: Optional[TreeNode]) -> int:
        MOD = 10 ** 9 + 7
        subs = []
        
        def dfs(node):
            if not node:
                return 0
            s = node.val + dfs(node.left) + dfs(node.right)
            subs.append(s)
            return s
        
        total = dfs(root)
        return max(s * (total - s) for s in subs) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（两次DFS） | O(n) | O(h)（h为树高） |
| 方法二/四（一次DFS） | O(n) | O(n)（存储所有子树和） |

- 树高 h 最坏为 O(n)（退化链表），平均 O(log n)
- 方法二/四需要 O(n) 空间存储所有子树和

## 图解示例

```
      1
    /   \
   2     3
  / \   /
 4   5 6

总和 total = 1+2+3+4+5+6 = 21

各子树和：
- 节点4: sub=4,  乘积 = 4*(21-4) = 4*17 = 68
- 节点5: sub=5,  乘积 = 5*(21-5) = 5*16 = 80
- 节点2: sub=11, 乘积 = 11*(21-11) = 11*10 = 110  <-- 最大
- 节点6: sub=6,  乘积 = 6*(21-6) = 6*15 = 90
- 节点3: sub=9,  乘积 = 9*(21-9) = 9*12 = 108
- 节点1: sub=21, 乘积 = 21*0 = 0（根节点不能删，或者说删了只剩一棵树）

最大乘积 = 110
```

## 关键点总结

1. 删边等价于枚举每个子树：子树和为 `sub`，另一部分为 `total - sub`
2. 先求总和，再找使 `sub * (total - sub)` 最大的分割点
3. **取模必须在最后**，中间不能取模（取模后不能正确比较大小）
4. 函数最大值在 `sub = total / 2` 时取得（两部分尽量平均）

## 易错点

1. 取模时机：一定要先找最大乘积，最后才对结果取模
2. 根节点也要处理（虽然乘积为 0），但其子树节点都需要遍历到
3. 节点值都是正数，所以 `sub` 越接近 `total/2`，乘积越大
