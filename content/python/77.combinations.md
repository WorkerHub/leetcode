## 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按任何顺序返回答案。

**示例 1：**
```
输入：n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

**示例 2：**
```
输入：n = 1, k = 1
输出：[[1]]
```

**提示：**
- `1 <= n <= 20`
- `1 <= k <= n`

## 解题思路

核心思想：回溯

关键步骤：
1. 从start开始选择数字
2. 选择后递归处理剩余数字
3. 达到k个数时加入结果

## Python 代码实现

```python
from typing import List

class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        result = []
        
        def backtrack(start: int, path: List[int]):
            # 剪枝：剩余数字不够
            if len(path) + (n - start + 1) < k:
                return
            
            if len(path) == k:
                result.append(path[:])
                return
            
            for i in range(start, n + 1):
                path.append(i)
                backtrack(i + 1, path)
                path.pop()
        
        backtrack(1, [])
        return result
```

## 复杂度分析

- 时间复杂度：O(C(n,k) × k)
- 空间复杂度：O(k)

## 关键点总结

1. **回溯模板**：选择→递归→撤销
2. **剪枝优化**：剩余数字不够时提前返回
3. **去重**：start从i+1开始，避免重复
