## 题目描述

一辆车从位置 0 出发，初始油量为 `fuel`，每行驶 1 单位距离消耗 1 单位油量。沿路有 `stations` 个加油站，`stations[i] = [position_i, fuel_i]` 表示在位置 `position_i` 有 `fuel_i` 单位的燃油可加。

求车能行驶的最大总距离。

**示例 1：**
```
输入：fuel = 10, stations = [[3,3],[5,2],[7,4],[12,1]]
输出：18
解释：到达位置 3 加 3（剩 10），位置 5 加 2（剩 9），位置 7 加 4（剩 9），位置 12（剩 4），继续到 16，燃油耗尽。总距离 16。
     若不加油站 12：在 7 加完 4，继续到 7+9=16。考虑加 12 的燃油：到 12 时剩 7-5=（7+4-5）=6，加 1=7，到 12+7=19... 重新算。
```

**提示：**
- `1 <= fuel <= 10^9`
- `0 <= stations.length <= 500`
- `0 <= stations[i][0] < stations[i+1][0]`
- `1 <= stations[i][1] <= 10^6`

## 解题思路

贪心 + 最大堆：类似于跳远加油站问题。

**策略：** 前进时，记录所有经过的加油站的燃油量。当燃油耗尽时，从经过的加油站中选燃油最多的一个"回头加油"（等价于在之前某点加满了油）。

使用最大堆维护已经过的加油站的燃油量。

## Python 代码实现

### 方法一：贪心 + 最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxDistance(self, fuel: int, stations: List[List[int]]) -> int:
        heap = []  # 最大堆（用负值）
        cur_fuel = fuel
        prev_pos = 0
        total_dist = 0
        stations_idx = 0

        # 目标位置依次推进
        # 贪心：每次到达某位置时，收集沿途加油站的燃油入堆
        # 若燃油不足到达下一站，从堆中取最大燃油补充

        # 简化：在每个加油站，若能到达则继续，否则加堆中最大燃油
        all_pos = stations + [[float('inf'), 0]]  # 哨兵

        for pos, fuel_at in all_pos:
            # 从 prev_pos 到 pos 需要 pos - prev_pos 燃油
            dist = pos - prev_pos

            while cur_fuel < dist and heap:
                # 补充最多的燃油
                cur_fuel += -heapq.heappop(heap)

            if cur_fuel < dist:
                # 用完所有燃油
                total_dist += cur_fuel
                cur_fuel = 0
                break

            cur_fuel -= dist
            total_dist += dist
            prev_pos = pos

            if fuel_at > 0:
                heapq.heappush(heap, -fuel_at)
        else:
            # 用剩余燃油继续前进
            pass

        # 加上堆中所有燃油（已经在终点之前，可以继续前进）
        # 实际上已在循环中处理
        return total_dist + cur_fuel  # 剩余燃油可以继续行驶
```

### 方法二：贪心简化版

```python
from typing import List
import heapq

class Solution:
    def maxDistance(self, fuel: int, stations: List[List[int]]) -> int:
        heap = []
        cur_fuel = fuel
        prev = 0

        for pos, f in stations:
            cur_fuel -= (pos - prev)
            prev = pos
            # 若燃油不足，回头取最大油量
            heapq.heappush(heap, -f)
            while cur_fuel < 0 and heap:
                cur_fuel += -heapq.heappop(heap)

        return prev + cur_fuel  # 当前位置 + 剩余燃油行驶距离
```

## 复杂度分析

- 时间复杂度：O(n log n)，最大堆操作
- 空间复杂度：O(n)，堆的大小

## 关键点总结

1. 贪心：优先使用最多的燃油补充（从堆中取最大值）
2. "回头加油"等价于在之前某站提前加满油
3. 最终答案 = 当前位置 + 剩余燃油

## 易错点

1. 燃油耗尽时如果堆为空则无法继续前进
2. 最终剩余燃油可以继续向前行驶，需要加到总距离中
