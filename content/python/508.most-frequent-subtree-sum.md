## 题目描述

给你一个二叉树的根节点 `root`，计算出现最频繁的子树元素和。一个节点的子树元素和定义为以该节点为根的二叉树上所有节点的元素之和（包括节点本身）。

你需要返回出现频率最高的子树元素和。如果有多个元素出现的频率相同，返回所有出现频率最高的子树元素和（不限顺序）。

**示例 1：**
```
输入：root = [5,2,-3]
输出：[2,-3,4]
解释：
  5
 / \
2  -3

子树和：
节点 2 的子树和 = 2
节点 -3 的子树和 = -3
节点 5 的子树和 = 5 + 2 + (-3) = 4

每个和都出现一次，所以返回所有的和。
```

**示例 2：**
```
输入：root = [5,2,-5]
输出：[2]
解释：
  5
 / \
2  -5

子树和：
节点 2 的子树和 = 2（出现1次）
节点 -5 的子树和 = -5（出现1次）
节点 5 的子树和 = 2（出现2次）

2 出现的频率最高，为 2 次。
```

**提示：**
- 树中节点数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这道题需要：
1. 计算每个子树的元素和
2. 统计每个和出现的频率
3. 找出频率最高的所有和

### 核心思想：
- 使用**后序遍历**（DFS）计算子树和
- 使用**哈希表**统计频率
- 找出最大频率，返回所有对应的和

### 算法流程：
1. 定义递归函数，返回子树和
2. 后序遍历：先计算左右子树和，再加上根节点
3. 用哈希表记录每个和出现的次数
4. 遍历哈希表，找出最大频率
5. 返回所有频率等于最大频率的和

## Python 代码实现

### 方法一：DFS + 哈希表（推荐）⭐

```python
from typing import List, Optional
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        """
        后序遍历计算子树和，哈希表统计频率
        时间复杂度：O(n)，空间复杂度：O(n)
        """
        if not root:
            return []
        
        # 哈希表统计每个和的出现次数
        count = defaultdict(int)
        
        def dfs(node):
            """计算以 node 为根的子树和"""
            if not node:
                return 0
            
            # 后序遍历：左 -> 右 -> 根
            left_sum = dfs(node.left)
            right_sum = dfs(node.right)
            
            # 当前子树和
            tree_sum = node.val + left_sum + right_sum
            
            # 记录频率
            count[tree_sum] += 1
            
            return tree_sum
        
        # 计算所有子树和
        dfs(root)
        
        # 找出最大频率
        max_count = max(count.values())
        
        # 返回所有频率等于最大频率的和
        return [s for s, c in count.items() if c == max_count]
```

### 方法二：使用 Counter（更 Pythonic）

```python
from collections import Counter

class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        """
        使用 Counter 简化统计
        时间复杂度：O(n)，空间复杂度：O(n)
        """
        if not root:
            return []
        
        sums = []  # 收集所有子树和
        
        def dfs(node):
            if not node:
                return 0
            
            left_sum = dfs(node.left)
            right_sum = dfs(node.right)
            tree_sum = node.val + left_sum + right_sum
            
            sums.append(tree_sum)
            return tree_sum
        
        dfs(root)
        
        # 统计频率
        count = Counter(sums)
        max_count = max(count.values())
        
        return [s for s, c in count.items() if c == max_count]
```

### 方法三：一次遍历（边计算边找最大）

```python
class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        """
        边遍历边维护最大频率和结果
        时间复杂度：O(n)，空间复杂度：O(n)
        """
        if not root:
            return []
        
        count = {}
        self.max_count = 0
        
        def dfs(node):
            if not node:
                return 0
            
            tree_sum = node.val + dfs(node.left) + dfs(node.right)
            count[tree_sum] = count.get(tree_sum, 0) + 1
            
            # 更新最大频率
            self.max_count = max(self.max_count, count[tree_sum])
            
            return tree_sum
        
        dfs(root)
        
        return [s for s, c in count.items() if c == self.max_count]
```

### 方法四：非递归实现（使用栈）

```python
class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        """
        非递归后序遍历
        时间复杂度：O(n)，空间复杂度：O(n)
        """
        if not root:
            return []
        
        count = defaultdict(int)
        sum_map = {}  # 记录每个节点的子树和
        stack = []
        current = root
        last_visited = None
        
        while stack or current:
            # 一直向左
            while current:
                stack.append(current)
                current = current.left
            
            peek = stack[-1]
            
            # 如果右子树存在且未访问，访问右子树
            if peek.right and peek.right != last_visited:
                current = peek.right
            else:
                # 访问当前节点
                node = stack.pop()
                
                left_sum = sum_map.get(node.left, 0)
                right_sum = sum_map.get(node.right, 0)
                tree_sum = node.val + left_sum + right_sum
                
                sum_map[node] = tree_sum
                count[tree_sum] += 1
                
                last_visited = node
        
        max_count = max(count.values())
        return [s for s, c in count.items() if c == max_count]
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(n)
  - 遍历所有节点一次：O(n)
  - 查找最大频率和结果：O(n)
- **空间复杂度**：O(n)
  - 递归栈深度：O(h)，最坏 O(n)
  - 哈希表：O(n)

## 关键点总结

1. **后序遍历**：先计算子树和，再处理根节点
2. **子树和定义**：节点值 + 左子树和 + 右子树和
3. **频率统计**：使用哈希表或 Counter
4. **多个结果**：可能有多个和的频率相同
5. **返回格式**：返回列表，不限顺序

## 易错点

1. **遍历顺序**：必须是后序遍历，不能是前序或中序
2. **空节点处理**：空节点的子树和为 0，不计入统计
3. **负数情况**：节点值可以为负，子树和也可能为负
4. **返回格式**：返回的是列表，不是单个值
5. **频率相同**：注意处理多个和频率相同的情况
