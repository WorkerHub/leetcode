## 题目描述

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按任意顺序返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

```
2: abc
3: def
4: ghi
5: jkl
6: mno
7: pqrs
8: tuv
9: wxyz
```

**示例 1：**
```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**示例 2：**
```
输入：digits = ""
输出：[]
```

**示例 3：**
```
输入：digits = "2"
输出：["a","b","c"]
```

**提示：**
- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字

## 解题思路

这是一道经典的回溯（DFS）问题：

1. **建立映射**：创建数字到字母的映射关系
2. **回溯搜索**：对每个数字，尝试其对应的所有字母
3. **组合构建**：当处理完所有数字时，得到一个完整组合

回溯的核心思想：
- 选择：从当前数字对应的字母中选择一个
- 递归：继续处理下一个数字
- 撤销：回溯到上一步，尝试其他选择

## Python 代码实现

### 方法一：回溯法（推荐）

```python
from typing import List

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        
        # 建立映射
        phone_map = {
            '2': 'abc',
            '3': 'def',
            '4': 'ghi',
            '5': 'jkl',
            '6': 'mno',
            '7': 'pqrs',
            '8': 'tuv',
            '9': 'wxyz'
        }
        
        result = []
        
        def backtrack(index: int, combination: str):
            # 递归终止条件：已经处理完所有数字
            if index == len(digits):
                result.append(combination)
                return
            
            # 获取当前数字对应的字母
            current_digit = digits[index]
            letters = phone_map[current_digit]
            
            # 尝试每个字母
            for letter in letters:
                # 选择当前字母，继续处理下一个数字
                backtrack(index + 1, combination + letter)
        
        backtrack(0, "")
        return result
```

### 方法二：迭代法（队列/广度优先）

```python
from typing import List

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        
        phone_map = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
        }
        
        # 初始化结果为第一个数字的所有字母
        result = ['']
        
        # 遍历每个数字
        for digit in digits:
            letters = phone_map[digit]
            # 临时列表存储当前层的所有组合
            temp = []
            
            # 对于之前的每个组合
            for combination in result:
                # 添加当前数字的每个字母
                for letter in letters:
                    temp.append(combination + letter)
            
            result = temp
        
        return result
```

### 方法三：使用列表推导式（Python 特色）

```python
from typing import List
from functools import reduce

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        
        phone_map = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
        }
        
        # 使用 reduce 进行组合
        return reduce(
            lambda acc, digit: [x + y for x in acc for y in phone_map[digit]],
            digits,
            ['']
        )
```

### 方法四：使用 itertools

```python
from typing import List
from itertools import product

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        
        phone_map = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
        }
        
        # 获取所有数字对应的字母集合
        letter_groups = [phone_map[digit] for digit in digits]
        
        # 使用 product 生成笛卡尔积
        return [''.join(combination) for combination in product(*letter_groups)]
```

## 复杂度分析

设 n 为 digits 的长度，m 为平均每个数字对应的字母数（约为 3.5）。

**所有方法：**
- 时间复杂度：O(m^n)，需要生成所有可能的组合
- 空间复杂度：O(m^n)，存储结果

**回溯法额外说明：**
- 递归调用栈深度为 O(n)

## 关键点总结

1. **回溯模板**：选择 → 递归 → 撤销（这里字符串不可变，无需显式撤销）
2. **映射表**：使用字典存储数字到字母的映射
3. **边界处理**：空字符串返回空列表
4. **多种实现**：回溯、迭代、函数式编程都可以解决

## 易错点

1. **空字符串处理**：`digits = ""` 应返回 `[]` 而不是 `[""]`
2. **递归终止条件**：`index == len(digits)` 时添加结果
3. **字符串拼接**：Python 字符串不可变，每次拼接会创建新对象
4. **结果顺序**：题目说可以任意顺序，不需要特别排序

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径)

        做选择

```
