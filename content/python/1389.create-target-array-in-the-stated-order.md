## 题目描述

给你两个整数数组 `nums` 和 `index`。你需要按照以下规则创建目标数组：

- 目标数组 `target` 最初为空。
- 按从左到右的顺序依次读取 `nums[i]` 和 `index[i]`，在 `target` 数组中的下标 `index[i]` 处插入值 `nums[i]`。
- 重复上一步，直到在 `nums` 和 `index` 中都没有要读取的元素。

请你返回目标数组。

**题目保证**数字插入位置总是存在。

**示例 1：**

```
输入：nums = [0,1,2,3,4], index = [0,1,2,2,1]
输出：[0,4,1,3,2]
解释：
nums       index     target
0            0        [0]
1            1        [0,1]
2            2        [0,1,2]
3            2        [0,1,3,2]
4            1        [0,4,1,3,2]
```

**示例 2：**

```
输入：nums = [1,2,3,4,0], index = [0,1,2,3,0]
输出：[0,1,2,3,4]
```

**示例 3：**

```
输入：nums = [1], index = [0]
输出：[1]
```

**提示：**

- `1 <= nums.length, index.length <= 100`
- `nums.length == index.length`
- `0 <= nums[i] <= 100`
- `0 <= index[i] <= i`

## 解题思路

这道题是纯模拟题，只需要按照题目描述的步骤逐一执行即可。

**核心操作：** Python 的 `list.insert(i, x)` 方法可以在索引 `i` 处插入元素 `x`，原索引 `i` 及之后的元素自动后移。

**步骤：**

1. 创建空列表 `target`
2. 遍历 `nums` 和 `index` 的每一对元素
3. 在 `target[index[i]]` 位置插入 `nums[i]`
4. 返回 `target`

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def createTargetArray(self, nums: List[int], index: List[int]) -> List[int]:
        target = []  # 初始化空目标数组
        for num, idx in zip(nums, index):
            # 在 idx 位置插入 num，原位置及之后的元素自动右移
            target.insert(idx, num)
        return target
```

### 方法二：手动移位模拟

不使用 `insert`，手动实现插入逻辑，帮助理解底层原理：

```python
from typing import List

class Solution:
    def createTargetArray(self, nums: List[int], index: List[int]) -> List[int]:
        target = []
        for i in range(len(nums)):
            idx = index[i]
            # 先添加一个占位符
            target.append(0)
            # 从末尾向目标位置逐个右移，腾出空位
            for j in range(len(target) - 1, idx, -1):
                target[j] = target[j - 1]
            # 在目标位置放入 nums[i]
            target[idx] = nums[i]
        return target
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（list.insert） | O(n^2) | O(n) |
| 方法二（手动移位） | O(n^2) | O(n) |

- **时间复杂度 O(n^2)**：每次 `insert` 操作在最坏情况下需要移动 O(n) 个元素，共 n 次操作。
- **空间复杂度 O(n)**：目标数组存储 n 个元素。

由于数据规模 n ≤ 100，O(n^2) 完全够用。

## 关键点总结

1. Python 的 `list.insert(index, value)` 是解决此类插入模拟题的利器
2. `zip(nums, index)` 可以同时遍历两个数组，代码更简洁
3. 题目保证 `0 <= index[i] <= i`，所以插入位置一定合法（不会越界）
4. `insert` 操作的底层是 O(n) 的，因此总复杂度是 O(n^2)

## 易错点

- 不要把 `insert` 和 `append` 混淆：`append` 只能在末尾添加，`insert` 可以在任意位置插入
- 每次插入之后，后续元素的索引都会改变，这正是 `insert` 自动处理的逻辑
- 不要提前分配固定大小的数组，因为每次插入都要改变大小
