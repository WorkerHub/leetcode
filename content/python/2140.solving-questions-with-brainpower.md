## 题目描述

给你一个下标从 **0** 开始的二维整数数组 `questions`，其中 `questions[i] = [pointsi, brainpoweri]`。

这个数组表示一场考试，你需要按顺序做题，对于第 `i` 题你可以：
- **解决**：获得 `pointsi` 分，但接下来 `brainpoweri` 道题必须跳过。
- **跳过**：不获分，可以考虑下一题。

返回考试中可以获得的**最高分数**。

**示例：**
```
输入：questions = [[3,2],[4,3],[4,4],[2,5]]
输出：5
解释：解决第 0 题（3分，跳过 2 题），然后解决第 3 题（2分），共 5 分。
或者解决第 1 题（4分，跳过 3 题），共 4 分。
最优：5 分。
```

**提示：**
- `1 <= questions.length <= 10^5`
- `questions[i].length == 2`
- `1 <= pointsi, brainpoweri <= 10^5`

## 解题思路

**动态规划（从右到左）**

设 `dp[i]` = 从第 `i` 道题开始能获得的最高分。

- 若跳过第 `i` 题：`dp[i] = dp[i+1]`。
- 若解决第 `i` 题：`dp[i] = points[i] + dp[min(i + brainpower[i] + 1, n)]`。

取两者最大值：`dp[i] = max(dp[i+1], points[i] + dp[next])`。

从右到左计算，`dp[n] = 0`（边界）。

## 代码实现

### 方法一：DP 从右到左（推荐）

```python
from typing import List

class Solution:
    def mostPoints(self, questions: List[List[int]]) -> int:
        n = len(questions)
        # dp[i] = 从第 i 题开始能获得的最高分
        dp = [0] * (n + 1)

        for i in range(n - 1, -1, -1):
            points, brainpower = questions[i]
            # 解决第 i 题后跳到的位置
            next_idx = min(i + brainpower + 1, n)
            # 选择：跳过 or 解决
            dp[i] = max(dp[i + 1], points + dp[next_idx])

        return dp[0]
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def mostPoints(self, questions: List[List[int]]) -> int:
        n = len(questions)

        @lru_cache(maxsize=None)
        def dp(i: int) -> int:
            if i >= n:
                return 0
            points, brainpower = questions[i]
            # 跳过 or 解决
            return max(dp(i + 1), points + dp(i + brainpower + 1))

        return dp(0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP 迭代 | O(n) | O(n) |
| 记忆化递归 | O(n) | O(n) |

## 关键点总结

1. 从右到左 DP，避免需要向前看的依赖关系。
2. 每道题有两个选择：跳过（到 dp[i+1]）或解决（到 dp[i+brainpower+1]）。
3. `next_idx = min(i + brainpower + 1, n)` 防止下标越界。

## 易错点

- 下一道可做的题是 `i + brainpower + 1`（解决第 i 题后跳过 brainpower 道）。
- 注意上限 `min(..., n)`，超出范围时 dp 值为 0。
