## 题目描述

与 3184 相同，但数组范围更大：
- `1 <= hours.length <= 5 * 10^5`
- `1 <= hours[i] <= 10^9`

## 解题思路

与 3184 相同，哈希表统计余数。数据范围变大，但算法不变，仍为 O(n)。

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        cnt = defaultdict(int)
        ans = 0
        for h in hours:
            r = h % 24
            need = (24 - r) % 24
            ans += cnt[need]
            cnt[r] += 1
        return ans
```

### 方法二：使用固定大小数组

```python
from typing import List

class Solution:
    def countCompleteDayPairs(self, hours: List[int]) -> int:
        cnt = [0] * 24
        ans = 0
        for h in hours:
            r = h % 24
            need = (24 - r) % 24
            ans += cnt[need]
            cnt[r] += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(24) = O(1)

## 关键点总结

1. 只需模 24 的余数
2. 固定大小数组（24 个桶）比哈希表更快

## 易错点

1. 与 3184 完全相同，注意答案可能很大（不需要取模）
2. 使用 `(24 - r) % 24` 处理 r=0 的特殊情况
