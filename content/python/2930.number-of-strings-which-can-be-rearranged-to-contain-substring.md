## 题目描述

给你一个整数 `n`，统计长度为 `n` 的、由小写英文字母组成的字符串中，重新排列后可以包含子字符串 `"leet"` 的字符串数量。

结果对 `10^9 + 7` 取余。

**示例 1：**
```
输入：n = 4
输出：12
解释：12 个长度为 4 的字符串重排后包含 "leet"
```

**示例 2：**
```
输入：n = 10
输出：83943898
```

**提示：**
- `1 <= n <= 10^5`

## 解题思路

包含 "leet" 需要：至少 1 个 `'l'`，至少 2 个 `'e'`，至少 1 个 `'t'`。

用容斥原理，计算"不能包含 leet"的字符串数，再从总数 26^n 减去。

设：
- A：`'l'` 出现 0 次的字符串数 = 25^n
- B：`'e'` 出现少于 2 次的字符串数 = 25^n + n * 25^(n-1)（0次或1次）
- C：`'t'` 出现 0 次的字符串数 = 25^n

用容斥：
- |A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

最终答案 = 26^n - |A ∪ B ∪ C|。

## Python 代码实现

### 方法一：容斥原理（推荐）

```python
class Solution:
    def stringCount(self, n: int) -> int:
        MOD = 10**9 + 7

        def pw(base, exp):
            return pow(base, exp, MOD)

        # 总方案数
        total = pw(26, n)

        # A: l 出现 0 次
        A = pw(25, n)
        # B: e 出现 0 次或 1 次
        B = pw(25, n) + n * pw(25, n - 1) % MOD
        B %= MOD
        # C: t 出现 0 次
        C = pw(25, n)

        # A∩B: l=0 且 e<2：24^n + n*24^(n-1)
        AB = (pw(24, n) + n * pw(24, n - 1)) % MOD
        # A∩C: l=0 且 t=0：24^n
        AC = pw(24, n)
        # B∩C: e<2 且 t=0：25^n + n*25^(n-1) （无 t）
        BC = (pw(24, n) + n * pw(24, n - 1)) % MOD
        # B∩C 实际：e<2 且 t=0，可用字母 24 个（去掉 e 和 t）
        # e=0: 24^n, e=1: n * 24^(n-1) * 1（e 的位置有 n 种，其余 24 种）
        # 但实际 e 有一种字符，所以 e=1 时有 n 选择位置，其余位置 24 种
        BC = (pw(24, n) + n * pw(24, n - 1)) % MOD

        # A∩B∩C: l=0, e<2, t=0
        # 可用字母：24 种（去 l, t）
        # e=0: 23^n, e=1: n * 23^(n-1)
        ABC = (pw(23, n) + n * pw(23, n - 1)) % MOD

        bad = (A + B + C - AB - AC - BC + ABC) % MOD
        return (total - bad) % MOD
```

### 方法二：动态规划（状态压缩）

```python
class Solution:
    def stringCount(self, n: int) -> int:
        MOD = 10**9 + 7
        # 状态：(has_l, e_count, has_t)
        # has_l in {0,1}, e_count in {0,1,2+}, has_t in {0,1}
        # 共 2*3*2 = 12 个状态
        # dp[state] = 长度为 i 的字符串处于该状态的数量
        # 状态编码：(l, e, t)，l=0/1，e=0/1/2，t=0/1

        # 初始状态：all zeros
        dp = {}
        dp[(0, 0, 0)] = 1

        for _ in range(n):
            new_dp = {}
            for (l, e, t), cnt in dp.items():
                # 添加字符 'l'
                nl, ne, nt = min(l + 1, 1), e, t
                new_dp[(nl, ne, nt)] = (new_dp.get((nl, ne, nt), 0) + cnt) % MOD
                # 添加字符 'e'
                nl, ne, nt = l, min(e + 1, 2), t
                new_dp[(nl, ne, nt)] = (new_dp.get((nl, ne, nt), 0) + cnt) % MOD
                # 添加字符 't'
                nl, ne, nt = l, e, min(t + 1, 1)
                new_dp[(nl, ne, nt)] = (new_dp.get((nl, ne, nt), 0) + cnt) % MOD
                # 添加其他字母（23 种）
                nl, ne, nt = l, e, t
                new_dp[(nl, ne, nt)] = (new_dp.get((nl, ne, nt), 0) + 23 * cnt) % MOD
            dp = new_dp

        # 目标状态：l=1, e=2, t=1
        return dp.get((1, 2, 1), 0)
```

## 复杂度分析

- 时间复杂度：O(1)（方法一，容斥原理）；O(12n)（方法二，DP）
- 空间复杂度：O(1)（方法一）；O(12)（方法二）

## 关键点总结

1. 问题转化：字符串重排能包含 "leet" 等价于至少有 1 个 l、2 个 e、1 个 t
2. 容斥原理：求补集（不满足条件的）更简单
3. DP 方法：跟踪 l/e/t 各自的满足状态（只需知道是否达到要求，e 需要 2 个）

## 易错点

1. "e" 需要出现至少 2 次，B = "e 出现 0 次或 1 次"的方案数
2. 容斥中的交集计算：减少可用字母种类
3. pow(base, exp, MOD) 在 Python 中高效计算模幂
