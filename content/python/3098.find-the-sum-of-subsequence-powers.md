## 题目描述

给你一个整数数组 `nums` 和正整数 `k`。

定义长度为 `k` 的子序列的**幂**：子序列中相邻元素的差的绝对值的最小值。

返回所有长度为 `k` 的子序列的幂之和，答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3,4], k = 3
输出：4
```

**提示：**
- `2 <= n <= 50`
- `2 <= k <= n`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

先排序，然后 DP。

对于排好序的数组，子序列中相邻元素差的最小值等价于选出的元素中相邻元素之差的最小值（因为排序后相邻选中元素的差就是最小差）。

等等，子序列不要求连续，但排序后选出 k 个元素，相邻（在子序列中）的差由排序顺序决定。

**DP 定义：** `dp[i][j][last_diff]` = 选了 `j` 个元素，最后一个元素是 `nums[i]`，当前最小差为 `last_diff` 的子序列数。

但 `last_diff` 是连续值，需要离散化。

实际上：排序后，dp[i][j][min_diff] = 已选 j 个，末尾是 nums[i]，当前最小差为 min_diff 的方案数。

`min_diff` 取值为排序后相邻元素的差，最多 n-1 种值 + 无穷大（只有 1 个元素时）。

## Python 代码实现

### 方法一：排序 + DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def sumOfPowers(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        nums.sort()

        # dp[i][j][d] = 选了 j 个元素，最后一个是 nums[i]，最小差为 d 的方案数
        # 利用字典存储不同 d 值
        # dp[i][d] = {cnt_for_each_j}

        # 状态：(最后元素下标, 已选元素数, 最小差) → 方案数
        # 由于 n <= 50，可以用 dict

        INF = float('inf')

        # dp[i][j] = {min_diff: count}
        dp = [[defaultdict(int) for _ in range(k + 1)] for _ in range(n)]

        # 初始化：选 1 个元素，最小差为 INF（无相邻）
        for i in range(n):
            dp[i][1][INF] = 1

        # 转移
        for j in range(2, k + 1):
            for i in range(j - 1, n):
                for prev in range(i):
                    diff = nums[i] - nums[prev]  # 已排序，diff >= 0
                    for min_d, cnt in dp[prev][j - 1].items():
                        new_min_d = min(min_d, diff)
                        dp[i][j][new_min_d] = (dp[i][j][new_min_d] + cnt) % MOD

        # 统计所有长度为 k 的子序列的幂之和
        ans = 0
        for i in range(n):
            for d, cnt in dp[i][k].items():
                if d != INF:
                    ans = (ans + d * cnt) % MOD

        return ans
```

### 方法二：简化实现

```python
from typing import List
from functools import lru_cache

class Solution:
    def sumOfPowers(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        nums.sort()
        n = len(nums)
        INF = float('inf')

        # 状态：(idx, count, min_diff) → 子序列数
        # 但 min_diff 连续，需要离散化
        # 用记忆化搜索

        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(last: int, count: int, min_diff: int) -> dict:
            """返回：{幂值: 方案数} 字典"""
            if count == k:
                return {min_diff: 1} if min_diff != INF else {}

            result = defaultdict(int)
            for next_idx in range(last + 1, n):
                diff = nums[next_idx] - nums[last]
                new_min = min(min_diff, diff)
                for d, cnt in dp(next_idx, count + 1, new_min).items():
                    result[d] = (result[d] + cnt) % MOD
            return dict(result)

        # 对每个起始点
        ans = 0
        for start in range(n):
            for d, cnt in dp(start, 1, INF).items():
                if d != INF:
                    ans = (ans + d * cnt) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * k * D)，D 为不同差值数（最多 n^2）
- 空间复杂度：O(n * k * D)
- n <= 50，实际可行

## 关键点总结

1. 排序后选子序列，幂 = 相邻选中元素的差的最小值
2. DP 状态包含"最小差"，用字典存储不同差值的方案数
3. 最终答案 = 所有方案的 (幂值 × 方案数) 之和

## 易错点

1. 排序后子序列的"幂"即相邻（在子序列中）元素之差的最小值
2. 初始只选 1 个元素时，最小差为无穷大（无相邻元素）
3. 取模操作要在每次加法后进行
