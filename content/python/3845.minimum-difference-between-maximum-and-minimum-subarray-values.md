## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，在所有长度恰好为 `k` 的子数组中，找到最大值与最小值之差最小的那一个。

返回该最小差值。

**示例 1：**

```
输入：nums = [1, 5, 9, 2, 6], k = 3
输出：4
解释：
- [1,5,9]：差 = 9-1 = 8
- [5,9,2]：差 = 9-2 = 7
- [9,2,6]：差 = 9-2 = 7
- [2,6,...]：差 = ...
最小差为 4（某子数组）。
```

**示例 2：**

```
输入：nums = [3, 3, 3], k = 2
输出：0
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

对每个长度为 k 的窗口，需要同时维护最大值和最小值。

使用**两个单调队列**：
1. 单调递减队列维护窗口最大值。
2. 单调递增队列维护窗口最小值。
3. 每次窗口右移时更新两个队列，差值 = 最大值 - 最小值。

## Python 代码实现

### 方法一：双单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        if k == 1:
            return 0

        n = len(nums)
        max_dq = deque()  # 单调递减，维护最大值
        min_dq = deque()  # 单调递增，维护最小值
        ans = float('inf')

        for i in range(n):
            # 维护最大值队列（递减）
            while max_dq and nums[max_dq[-1]] <= nums[i]:
                max_dq.pop()
            max_dq.append(i)

            # 维护最小值队列（递增）
            while min_dq and nums[min_dq[-1]] >= nums[i]:
                min_dq.pop()
            min_dq.append(i)

            # 窗口大小达到 k
            if i >= k - 1:
                # 移除过期元素
                while max_dq[0] <= i - k:
                    max_dq.popleft()
                while min_dq[0] <= i - k:
                    min_dq.popleft()

                diff = nums[max_dq[0]] - nums[min_dq[0]]
                ans = min(ans, diff)

        return ans
```

### 方法二：排序每个窗口（小 k）

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        if k == 1:
            return 0

        ans = float('inf')
        for i in range(len(nums) - k + 1):
            window = sorted(nums[i:i + k])
            ans = min(ans, window[-1] - window[0])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n * k log k)（方法二）
- 空间复杂度：O(k)，队列大小

## 关键点总结

1. 双单调队列同时维护最大值和最小值，是滑动窗口极值的经典方法。
2. 单调递减队列队首是窗口最大值，单调递增队列队首是最小值。
3. 每次右移后检查队首是否过期（下标 <= i - k）。

## 易错点

1. 过期元素检查时用 `<= i - k` 而非 `< i - k`（窗口左端为 `i - k + 1`）。
2. `k = 1` 时最大值等于最小值，差为 0，直接返回。
3. 两个队列分别独立维护，不要混淆。
