## 题目描述

给定一棵 `n` 个节点的无向树，每条边都有一个小写字母标签。统计树中所有满足"路径上的字符构成回文串"的点对 `(u, v)`（`u < v`）的数量。

**示例 1：**
```
输入：n = 5, edges = [[0,1,'a'],[0,2,'b'],[1,3,'a'],[1,4,'b']]
输出：4
解释：路径 (0,3)="aa"（回文），路径 (1,2)="ab"（不是），...
```

**示例 2：**
```
输入：n = 3, edges = [[0,1,'a'],[1,2,'a']]
输出：3
解释：路径 (0,2)="aa"（回文），(0,1)="a"（回文），(1,2)="a"（回文）。
```

**提示：**
- `2 <= n <= 10^5`
- 边标签为小写字母

## 解题思路

树上路径回文判断，使用 DFS + 哈希表。

**关键观察：** 一条路径的字符构成回文串，当且仅当路径上奇数次出现的字符最多有 1 个。这可以用位掩码（bitmask）表示：26 位中每位对应一个字母，第 i 位为 1 表示字母 i 出现奇数次。

路径 `(u, v)` 的 XOR 掩码 = `mask[u]` XOR `mask[v]`（从根到各节点的路径掩码的异或），其中 `mask[u]` 为从根到 `u` 的路径上各字母出现次数的奇偶性。

路径构成回文 ⟺ XOR 结果 = 0（全偶次），或 XOR 结果为 2 的幂（恰好一个奇数次字母）。

DFS 过程中，用哈希表记录之前出现过的掩码，快速统计满足条件的对数。

## Python 代码实现

### 方法一：DFS + 位掩码（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPalindromicPaths(self, n: int, edges: List[List]) -> int:
        # 建图（边带字符标签）
        graph = defaultdict(list)
        for u, v, c in edges:
            bit = 1 << (ord(c) - ord('a'))
            graph[u].append((v, bit))
            graph[v].append((u, bit))

        mask_count = defaultdict(int)
        mask_count[0] = 1  # 根节点（虚拟起点）的掩码为 0
        ans = 0

        def dfs(node: int, parent: int, mask: int) -> None:
            nonlocal ans
            # 统计与当前节点路径掩码配对的数量
            # 配对条件：mask XOR prev_mask == 0 或 2^i
            ans += mask_count[mask]  # 完全相同（差为 0）
            for i in range(26):
                ans += mask_count[mask ^ (1 << i)]  # 差为一个位

            mask_count[mask] += 1

            for child, bit in graph[node]:
                if child != parent:
                    dfs(child, node, mask ^ bit)

            mask_count[mask] -= 1  # 回溯

        dfs(0, -1, 0)
        return ans
```

### 方法二：离线 DFS（不回溯版本）

```python
from typing import List
from collections import defaultdict
import sys

sys.setrecursionlimit(200000)

class Solution:
    def countPalindromicPaths(self, n: int, edges: List[List]) -> int:
        graph = defaultdict(list)
        for u, v, c in edges:
            bit = 1 << (ord(c) - ord('a'))
            graph[u].append((v, bit))
            graph[v].append((u, bit))

        # 计算每个节点到根的路径掩码
        root_mask = [0] * n
        parent = [-1] * n

        stack = [(0, -1, 0)]
        order = []
        while stack:
            node, par, mask = stack.pop()
            root_mask[node] = mask
            parent[node] = par
            order.append(node)
            for child, bit in graph[node]:
                if child != par:
                    stack.append((child, node, mask ^ bit))

        # 统计满足条件的对
        mask_count = defaultdict(int)
        ans = 0
        for node in order:
            m = root_mask[node]
            ans += mask_count[m]
            for i in range(26):
                ans += mask_count[m ^ (1 << i)]
            mask_count[m] += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 26)，每个节点处理 26 种可能的掩码
- 空间复杂度：O(n)

## 关键点总结

1. 路径回文 ⟺ 路径上字符的奇偶掩码 XOR 为 0 或 2 的幂
2. 从根到各节点的路径掩码 XOR 等于路径 `(u, v)` 的掩码
3. 哈希表快速统计满足条件的历史掩码

## 易错点

1. DFS 回溯时需要恢复 `mask_count`，或使用离线方法
2. 每对节点只统计一次（注意是否重复计数）
