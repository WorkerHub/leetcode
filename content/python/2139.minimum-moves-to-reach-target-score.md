## 题目描述

初始分数为 1，目标分数为 `target`，最多可以使用 `maxDoubles` 次"加倍"操作（`score *= 2`），其余时候可以"加一"（`score += 1`）。

返回到达 `target` 分数所需的**最少操作次数**。

**示例 1：**
```
输入：target = 5, maxDoubles = 0
输出：4
解释：1->2->3->4->5，全部加一，4 步。
```

**示例 2：**
```
输入：target = 19, maxDoubles = 2
输出：7
解释：1->2->4->5->6->12->19，共7步（加倍2次，加一5次）。
```

**提示：**
- `1 <= target <= 10^9`
- `0 <= maxDoubles <= 100`

## 解题思路

**贪心：从 target 逆向思考**

从 target 逆向操作到 1：
- 若 target 为偶数且还有加倍次数，则"除以 2"（逆向加倍），操作次数 +1，maxDoubles-1。
- 若 target 为奇数，则"减 1"（逆向加一），操作次数 +1。
- 若 maxDoubles 用完，剩余 target - 1 步全部加一。

贪心合理性：对于大数，加倍减半更高效；越接近 1 越应该用加一。

## 代码实现

### 方法一：逆向贪心（推荐）

```python
class Solution:
    def minMoves(self, target: int, maxDoubles: int) -> int:
        if maxDoubles == 0:
            return target - 1

        ops = 0
        while target > 1 and maxDoubles > 0:
            if target % 2 == 1:
                # target 为奇数，必须先减 1
                target -= 1
                ops += 1
            else:
                # target 为偶数，且还有加倍次数，除以 2
                target //= 2
                ops += 1
                maxDoubles -= 1

        # 剩余需要 target - 1 次加一
        ops += target - 1
        return ops
```

### 方法二：更紧凑的写法

```python
class Solution:
    def minMoves(self, target: int, maxDoubles: int) -> int:
        ans = 0
        while target > 1 and maxDoubles > 0:
            ans += 1  # 本次操作
            if target % 2 == 1:
                target -= 1  # 减 1（逆向加一）
            else:
                target //= 2  # 除以 2（逆向加倍）
                maxDoubles -= 1
        # 剩余全部加一
        return ans + target - 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 逆向贪心 | O(min(log target, maxDoubles)) | O(1) |

每次加倍使 target 减半，最多 log2(target) 次加倍；maxDoubles 最多 100 次，故循环上界为 min(log target, maxDoubles)。

## 关键点总结

1. 逆向思考：从 target 逆推到 1，"减一"和"除以二"。
2. 奇数时只能先减一，偶数时若有加倍次数则除以二（更快）。
3. 加倍次数用完后，剩余 `target - 1` 次全部用加一解决。

## 易错点

- 奇数时不能直接除以二，必须先减一。
- 加倍次数 `maxDoubles` 可能用不完（target 已变为 1）。
