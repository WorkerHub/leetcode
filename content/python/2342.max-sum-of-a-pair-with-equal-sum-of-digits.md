## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，数组中的元素都是**正**整数。请你选出两个下标 `i` 和 `j`（`i != j`），使得 `nums[i] + nums[j]` 的值**最大**，且满足 `nums[i]` 和 `nums[j]` 的**数位和**相等。

返回这两个数之和，若不存在满足条件的组合则返回 `-1`。

**示例 1：**
```
输入：nums = [18,43,36,13,7]
输出：54
解释：数位和为 9 的有 18 和 36，18+36=54。
```

**示例 2：**
```
输入：nums = [10,12,19,14]
输出：-1
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**哈希表分组：**
按数位和分组，对每组找最大的两个数，其和为候选答案。取所有组候选答案的最大值。

## 代码实现

### 方法一：哈希表存每组最大值（推荐）

```python
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        def digit_sum(x: int) -> int:
            s = 0
            while x > 0:
                s += x % 10
                x //= 10
            return s
        
        # 每个数位和对应的最大值
        best = {}  # digit_sum -> 该组的最大数
        ans = -1
        
        for x in nums:
            ds = digit_sum(x)
            if ds in best:
                # 找到同组数，更新答案
                ans = max(ans, best[ds] + x)
                # 更新该组的最大值
                best[ds] = max(best[ds], x)
            else:
                best[ds] = x
        
        return ans
```

### 方法二：哈希表存每组前两大值

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        def digit_sum(x):
            return sum(int(c) for c in str(x))
        
        groups = defaultdict(list)
        for x in nums:
            groups[digit_sum(x)].append(x)
        
        ans = -1
        for vals in groups.values():
            if len(vals) >= 2:
                vals.sort(reverse=True)
                ans = max(ans, vals[0] + vals[1])
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表最大值 | O(n * log(max_num)) | O(n) |
| 分组排序 | O(n * log(n)) | O(n) |

## 关键点总结

1. 数位和相同的数分为一组，每组内找最大两数之和。
2. 方法一只需维护每组最大值，遍历时实时更新答案，O(1) 空间（除哈希表外）。
3. 注意同一组内遍历时，先用当前最大值更新答案，再更新最大值。

## 易错点

- 先用 `best[ds] + x` 更新 ans，再更新 `best[ds]`，顺序不能颠倒（否则可能用 x 和 x 本身配对）。
