## 题目描述

你的任务是计算 `a^b` 对 `1337` 取模，其中 `a` 是一个正整数，`b` 是一个非常大的正整数且会以数组形式给出。

**示例 1：**

```
输入：a = 2, b = [3]
输出：8
```

**示例 2：**

```
输入：a = 2, b = [1,0]
输出：1024
```

**示例 3：**

```
输入：a = 1, b = [4,3,3,8,5,2]
输出：1
```

**提示：**
- `1 <= a <= 2^31 - 1`
- `1 <= b.length <= 2000`
- `0 <= b[i] <= 9`
- `b` 不含前导 0

## 解题思路

这道题涉及三个核心知识点：

### 1. 快速幂算法

计算 `a^n % mod` 的高效方法：
```
a^n = (a^2)^(n/2)           如果 n 是偶数
a^n = a * (a^2)^((n-1)/2)   如果 n 是奇数
```

### 2. 模运算性质

```
(a * b) % mod = ((a % mod) * (b % mod)) % mod
(a^b) % mod = ((a % mod)^b) % mod
```

### 3. 指数分解

对于 `b = [1,2,3]`（即 123）：
```
a^123 = a^(120 + 3) = a^120 * a^3 = (a^12)^10 * a^3
```

递归公式：
```
superPow(a, [1,2,3]) = superPow(a, [1,2])^10 * a^3
```

## Python 代码实现

### 方法一：递归分解（推荐）

```python
from typing import List

class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        """
        递归分解指数
        时间复杂度：O(n)，n 为 b 的长度
        空间复杂度：O(n)，递归栈
        """
        MOD = 1337
        
        # 先对 a 取模，避免大数
        a = a % MOD
        
        # 递归终止条件
        if not b:
            return 1
        
        # 取出最后一位
        last_digit = b.pop()
        
        # 递归公式：a^[1,2,3] = (a^[1,2])^10 * a^3
        part1 = self.myPow(self.superPow(a, b), 10)
        part2 = self.myPow(a, last_digit)
        
        return (part1 * part2) % MOD
    
    def myPow(self, a: int, k: int) -> int:
        """
        快速幂：计算 a^k % MOD
        """
        MOD = 1337
        result = 1
        a = a % MOD
        
        while k > 0:
            if k % 2 == 1:
                result = (result * a) % MOD
            a = (a * a) % MOD
            k //= 2
        
        return result
```

### 方法二：迭代处理（从左到右）

```python
from typing import List

class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        """
        从左到右迭代处理
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        MOD = 1337
        result = 1
        
        for digit in b:
            # result = result^10 * a^digit
            result = self.myPow(result, 10) * self.myPow(a, digit) % MOD
        
        return result
    
    def myPow(self, a: int, k: int) -> int:
        """
        快速幂
        """
        MOD = 1337
        result = 1
        a = a % MOD
        
        while k > 0:
            if k & 1:
                result = (result * a) % MOD
            a = (a * a) % MOD
            k >>= 1
        
        return result
```

### 方法三：优化的递归（不修改输入）

```python
from typing import List

class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        """
        递归但不修改原数组
        """
        MOD = 1337
        return self.helper(a, b, len(b) - 1)
    
    def helper(self, a: int, b: List[int], idx: int) -> int:
        """
        计算 a^b[0:idx+1] % MOD
        """
        MOD = 1337
        
        if idx < 0:
            return 1
        
        # 递归计算前面的部分
        part1 = self.myPow(self.helper(a, b, idx - 1), 10)
        # 计算最后一位
        part2 = self.myPow(a, b[idx])
        
        return (part1 * part2) % MOD
    
    def myPow(self, a: int, k: int) -> int:
        """
        快速幂
        """
        MOD = 1337
        result = 1
        a = a % MOD
        
        while k > 0:
            if k & 1:
                result = (result * a) % MOD
            a = (a * a) % MOD
            k >>= 1
        
        return result
```

### 方法四：使用 Python 内置函数（作弊，供理解）

```python
from typing import List

class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        """
        使用 Python 内置的 pow 函数
        pow(a, b, mod) 内部已经实现了快速幂和取模
        """
        MOD = 1337
        # 将数组转换为整数
        b_int = int(''.join(map(str, b)))
        return pow(a, b_int, MOD)
```

## 复杂度分析

### 方法一/二/三：递归/迭代
- 时间复杂度：O(n × log k)
  - n 为数组长度
  - 每次快速幂需要 O(log k)，k 最大为 10
- 空间复杂度：O(n)（递归）或 O(1)（迭代）

### 方法四：内置函数
- 时间复杂度：O(n + log b)
- 空间复杂度：O(1)

## 关键点总结

1. **快速幂**：O(log n) 计算 a^n，避免直接循环
2. **模运算性质**：
   - `(a * b) % p = ((a % p) * (b % p)) % p`
   - 每步都取模，避免溢出
3. **指数分解**：将大指数分解为小指数的组合
4. **递归公式**：`a^[1,2,3] = (a^[1,2])^10 * a^3`
5. **及时取模**：每次运算后都要取模

## 易错点

1. **溢出问题**：即使在 Python 中，也要及时取模避免数字过大
2. **递归终止**：空数组时返回 1
3. **快速幂实现**：注意取模的位置
4. **数组修改**：方法一会修改原数组，注意是否允许
5. **模数固定**：本题模数固定为 1337

## 图解示例

### 示例：a = 2, b = [1,0] (即 2^10)

**方法一（递归）：**
```
superPow(2, [1,0])
= superPow(2, [1])^10 * 2^0
= (superPow(2, [])^10 * 2^1)^10 * 1
= ((1^10 * 2)^10) * 1
= 2^10
= 1024 % 1337
= 1024
```

**快速幂计算 2^10：**
```
k = 10 (1010 in binary)
result = 1

k = 10, 偶数, a = 2^2 = 4, k = 5
k = 5,  奇数, result = 1 * 4 = 4, a = 4^2 = 16, k = 2
k = 2,  偶数, a = 16^2 = 256, k = 1
k = 1,  奇数, result = 4 * 256 = 1024, k = 0

返回 1024
```
