## 题目描述

给定一个非负整数，你最多可以交换一次数字中的任意两位。返回你能得到的最大值。

**示例 1：**
```
输入：num = 2736
输出：7236
解释：交换数字2和数字7
```

**示例 2：**
```
输入：num = 9973
输出：9973
解释：不需要交换
```

**提示：**
- 0 <= num <= 10^8

## 解题思路

贪心策略：找到高位上较小的数和低位上较大的数进行交换。

**核心思想：**
1. 从左到右找第一个不是最大数字的位置
2. 从右到左找最大的数字（比该位置大）
3. 交换这两个位置

**优化策略：**
- 记录每个数字最后出现的位置
- 从高位开始，找第一个可以被更大数字替换的位置
- 用最大且最靠右的数字替换

**算法流程：**
1. 将数字转换为数组
2. 记录每个数字(0-9)最后出现的索引
3. 从左到右遍历，对每一位找更大的替换数字
4. 找到后交换并返回

## Python 代码实现

### 方法一：贪心 + 哈希表（推荐）⭐

```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        # 转换为列表方便操作
        digits = list(str(num))
        n = len(digits)
        
        # 记录每个数字最后出现的位置
        last = {int(d): i for i, d in enumerate(digits)}
        
        # 从左到右遍历每一位
        for i in range(n):
            # 尝试找一个更大的数字来替换当前位
            for d in range(9, int(digits[i]), -1):
                # 如果存在更大的数字，且在当前位之后
                if d in last and last[d] > i:
                    # 交换
                    digits[i], digits[last[d]] = digits[last[d]], digits[i]
                    return int(''.join(digits))
        
        # 无需交换
        return num
```

### 方法二：一次遍历找最优交换

```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        digits = list(str(num))
        n = len(digits)
        
        # 找到应该交换的两个位置
        max_idx = n - 1  # 最大数字的索引
        swap_i = swap_j = -1  # 要交换的两个位置
        
        # 从右到左遍历
        for i in range(n - 2, -1, -1):
            if digits[i] < digits[max_idx]:
                # 找到一个可以交换的位置
                swap_i, swap_j = i, max_idx
            elif digits[i] > digits[max_idx]:
                # 更新最大值位置
                max_idx = i
        
        # 执行交换
        if swap_i != -1:
            digits[swap_i], digits[swap_j] = digits[swap_j], digits[swap_i]
        
        return int(''.join(digits))
```

### 方法三：暴力枚举

```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        digits = list(str(num))
        n = len(digits)
        max_num = num
        
        # 枚举所有可能的交换
        for i in range(n):
            for j in range(i + 1, n):
                # 交换
                digits[i], digits[j] = digits[j], digits[i]
                max_num = max(max_num, int(''.join(digits)))
                # 恢复
                digits[i], digits[j] = digits[j], digits[i]
        
        return max_num
```

## 复杂度分析

**方法一：贪心 + 哈希表**
- 时间复杂度：O(n)，n 为数字位数，最多10位
- 空间复杂度：O(n)

**方法二：一次遍历**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法三：暴力枚举**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 图解示例

以 num = 2736 为例：

```
方法一：贪心 + 哈希表

digits = ['2', '7', '3', '6']
last = {2:0, 7:1, 3:2, 6:3}

i=0, digits[0]='2':
  尝试 d=9: 不在last中
  尝试 d=8: 不在last中
  尝试 d=7: 在last中，last[7]=1 > 0 ✓
  交换 digits[0] 和 digits[1]
  结果：['7', '2', '3', '6'] -> 7236

方法二：一次遍历

从右到左：
i=3: '6', max_idx=3
i=2: '3' < '6', swap_i=2, swap_j=3
i=1: '7' > '6', max_idx=1
i=0: '2' < '7', swap_i=0, swap_j=1

最终交换 i=0 和 j=1
结果：7236
```

## 关键点总结

1. **贪心策略**：优先交换高位的小数字和低位的大数字
2. **最后出现位置**：同样大的数字选择最右边的（保证交换后更大）
3. **一次交换**：最多只能交换一次，要找最优解
4. **从大到小尝试**：对每一位，从9到当前位尝试替换
5. **提前终止**：找到第一个可交换位置就可以返回

## 易错点

1. **重复数字处理**：记录最后出现位置，保证选最右边的
2. **无需交换**：已经是最大值时直接返回原数
3. **交换位置**：要交换索引，不是交换值
4. **字符串转换**：注意数字和字符串之间的转换
5. **贪心正确性**：第一个可交换位置就是最优，不需要继续找
