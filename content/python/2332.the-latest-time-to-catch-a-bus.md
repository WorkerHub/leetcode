## 题目描述

给你一个下标从 **0** 开始的整数数组 `buses`，表示每辆公交车的出发时间；整数数组 `passengers`，表示每位乘客的到站时间；整数 `capacity`，表示每辆公交车可以容纳的**最多**乘客数。

每位乘客**必须**在公交出发前到达（即乘客到站时间 <= 公交出发时间）。每位乘客只能乘坐**一辆**公交。

你也需要在某一时刻到达公交站以搭乘公交（你的到站时间也必须 <= 所乘公交出发时间），且你的到站时间**不能与任何乘客的到站时间相同**。

返回你能搭乘公交的**最晚**到站时间。

**提示：**
- `n == buses.length`
- `m == passengers.length`
- `1 <= n, m, capacity <= 10^5`
- `2 <= buses[i], passengers[j] <= 10^9`

## 解题思路

**贪心 + 排序：**
1. 对 `buses` 和 `passengers` 排序。
2. 模拟乘客上车过程，记录每辆公交实际搭载的乘客。
3. 确定"我"能选择的最晚时间：
   - 若末班车有剩余容量，则可以在末班车出发时刻（或之前一点）上车。
   - 否则，找到末班车最后一个上车乘客的前一个时刻。
4. 需要找一个时刻，这个时刻没有其他乘客，且 <= 某辆公交出发时间。

## 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def latestTimeCatchTheBus(self, buses: List[int], passengers: List[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        
        passenger_set = set(passengers)
        j = 0  # 乘客指针
        
        # 模拟每辆公交的上客过程
        for i, bus in enumerate(buses):
            cnt = 0  # 当前公交已上客数
            while j < len(passengers) and passengers[j] <= bus and cnt < capacity:
                cnt += 1
                j += 1
        
        # 此时 j 指向"末班车后未上车的第一位乘客"，或所有乘客已上车
        # 末班车出发时间
        last_bus = buses[-1]
        
        # 回退 j 到末班车能上的最后一位乘客
        # j 现在已经是末班车处理结束后的位置
        # 需要找最晚的合法时间
        
        # 末班车有剩余容量，可以在末班车出发时刻之前
        # 找末班车出发时刻之前，且不与任何乘客重叠的最晚时间
        
        # 先找候选时间：末班车出发时间（若末班车有余量）或末班车最后上车乘客的前一刻
        # 再往前找到不与已有乘客冲突的时刻
        
        # 重新模拟，记录末班车最后上车的乘客到站时间
        j = 0
        for bus in buses:
            cnt = 0
            while j < len(passengers) and passengers[j] <= bus and cnt < capacity:
                cnt += 1
                j += 1
        
        # 末班车是否有剩余容量
        last_capacity = capacity
        j_start = j  # 末班车之后的乘客位置
        
        # 重新计算末班车上车情况
        j2 = 0
        for idx, bus in enumerate(buses):
            cnt = 0
            if idx == len(buses) - 1:
                j_last_start = j2
            while j2 < len(passengers) and passengers[j2] <= bus and cnt < capacity:
                cnt += 1
                j2 += 1
            if idx == len(buses) - 1:
                last_capacity = capacity - cnt
        
        # 若末班车有余量，从末班车出发时间往前找不冲突的时刻
        if last_capacity > 0:
            t = buses[-1]
        else:
            # 从末班车最后上车的乘客往前找
            t = passengers[j2 - 1]
        
        # 往前找第一个不在 passenger_set 中的时刻
        while t in passenger_set:
            t -= 1
        
        return t
```

### 方法二：简洁版

```python
from typing import List

class Solution:
    def latestTimeCatchTheBus(self, buses: List[int], passengers: List[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        taken = set(passengers)  # 已有乘客的到站时间集合
        
        j = 0  # 乘客指针
        for bus in buses:
            cap = capacity
            while j < len(passengers) and passengers[j] <= bus and cap > 0:
                cap -= 1
                j += 1
        
        # 找最晚合法时刻
        # 末班车有余量则从 buses[-1] 开始，否则从末班车最后一个乘客开始
        t = buses[-1] if cap > 0 else passengers[j - 1]
        
        while t in taken:
            t -= 1
        
        return t
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 双指针 | O((n + m) log(n + m)) | O(m) |

## 关键点总结

1. 排序后模拟上客过程，用双指针高效推进。
2. 末班车有余量时，最晚可到 `buses[-1]`；否则最晚可到末班车最后一位乘客的时刻。
3. 从候选时刻往前找不与任何乘客冲突的时刻。

## 易错点

- `cap` 变量在循环中被修改，要注意循环结束后的 `cap` 值代表末班车的剩余容量。
- 候选时刻不能与**任何**已有乘客冲突，即使该乘客没有上这辆公交。
