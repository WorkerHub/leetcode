## 题目描述

给你一个字符串数组 `words`，可以在任意字符串之间移动字符（不限次数）。

若可以使数组中所有字符串相等，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：words = ["abc","aabc","bc"]
输出：true
解释：将第二个字符串中的一个 'a' 移动到第一个字符串：["aabc","abc","bc"] -> 不对
实际上：移动后可得 ["abc","abc","abc"]
```

**示例 2：**
```
输入：words = ["ab","a"]
输出：false
解释：字符 'b' 出现 1 次，无法平均分配给 2 个字符串
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 只包含小写英文字母

## 解题思路

**计数**：

所有字符串拼接后，统计每个字符的出现次数。若每个字符的出现次数都能被 `n`（字符串数量）整除，则可以均分，返回 `true`。

## 代码实现

### 方法一：Counter（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def makeEqual(self, words: List[str]) -> bool:
        n = len(words)
        # 统计所有字符的总出现次数
        cnt = Counter(''.join(words))
        # 每个字符的次数必须能被 n 整除
        return all(v % n == 0 for v in cnt.values())
```

### 方法二：手动计数

```python
from typing import List

class Solution:
    def makeEqual(self, words: List[str]) -> bool:
        n = len(words)
        freq = [0] * 26  # 统计 26 个字母

        for word in words:
            for ch in word:
                freq[ord(ch) - ord('a')] += 1

        # 检查每个字母的出现次数是否能被 n 整除
        for count in freq:
            if count % n != 0:
                return False

        return True
```

### 方法三：一行解法

```python
from typing import List
from collections import Counter

class Solution:
    def makeEqual(self, words: List[str]) -> bool:
        n = len(words)
        # 用集合推导式检查所有字符频次均整除 n
        return not any(v % n for v in Counter(c for w in words for c in w).values())
```

## 复杂度分析

- **时间复杂度**：O(n * L)，n 为字符串数量，L 为平均长度
- **空间复杂度**：O(26) = O(1)，只存 26 个字母的计数

## 关键点总结

1. 所有字符串可以任意重新分配字符，问题转化为每种字符的总数能否被 n 整除
2. 用 Counter 或数组统计字符频次
3. 检查所有字符的频次对 n 取模均为 0

## 易错点

- 不需要关心字符在哪个字符串里，只需要看总频次能否均分
- 频次为 0 的字符不影响结果（0 整除任何正整数）
