## 题目描述

爱丽丝和鲍勃继续他们的石子游戏。许多堆石子排成一行，每堆都有正整数颗石子 piles[i]。游戏以谁手中的石子最多来决出胜负。

爱丽丝和鲍勃轮流进行，爱丽丝先开始。最初，M = 1。

在每个玩家的回合中，该玩家可以拿走剩下的前 X 堆的所有石子，其中 1 <= X <= 2M。然后，令 M = max(M, X)。

游戏一直持续到所有石子都被拿走。

假设爱丽丝和鲍勃都发挥出最佳水平，返回爱丽丝可以得到的最大数量的石头。

**示例 1：**
```
输入：piles = [2,7,9,4,4]
输出：10
解释：
如果爱丽丝拿走第一堆，鲍勃拿走第二、三堆，然后爱丽丝拿走最后两堆。
爱丽丝得到：2 + 4 + 4 = 10
鲍勃得到：7 + 9 = 16
如果爱丽丝先拿 1 堆，然后鲍勃拿 2 堆，爱丽丝再拿 2 堆。
爱丽丝得到：2 + 4 + 4 = 10
鲍勃得到：7 + 9 = 16
```

**示例 2：**
```
输入：piles = [1,2,3,4,5,100]
输出：104
```

**提示：**
- 1 <= piles.length <= 100
- 1 <= piles[i] <= 10^4

## 解题思路

这是一个博弈类动态规划问题，核心思想是：

1. **博弈特点**：
   - 双方都采取最优策略
   - 当前玩家希望最大化自己的收益
   - 对手也会最大化自己的收益（即最小化我方收益）

2. **状态定义**：
   - `dp[i][m]`：从索引 i 开始，当前 M = m 时，先手玩家能获得的最大石子数
   - 先手玩家可以选择拿走前 1 到 2M 堆石子

3. **状态转移**：
   - 对于位置 i 和参数 M，先手可以选择拿 x 堆（1 <= x <= 2M）
   - 拿走 x 堆后：
     - 先手得到 sum(piles[i:i+x])
     - 后手变成先手，从 i+x 开始，M' = max(M, x)
   - 先手要选择使自己收益最大的 x

4. **关键观察**：
   - 使用后缀和优化：`suffix[i]` = sum(piles[i:])
   - `dp[i][m] = suffix[i] - min(dp[i+x][max(m,x)])` for x in 1..2m
   - 因为后手拿的越多，先手剩下的越少

## Python 代码实现

### 方法一：记忆化递归 ⭐

```python
from typing import List
from functools import lru_cache

class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        """
        使用记忆化递归求解博弈问题
        时间复杂度：O(n^3)
        空间复杂度：O(n^2)
        """
        n = len(piles)
        
        # 计算后缀和：从 i 到末尾的石子总数
        suffix_sum = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_sum[i] = suffix_sum[i + 1] + piles[i]
        
        @lru_cache(maxsize=None)
        def dfs(i: int, m: int) -> int:
            """
            从索引 i 开始，M = m 时，先手能获得的最大石子数
            """
            # 如果剩余堆数 <= 2M，可以全部拿走
            if i + 2 * m >= n:
                return suffix_sum[i]
            
            # 尝试拿走 x 堆（1 <= x <= 2M）
            max_stones = 0
            for x in range(1, 2 * m + 1):
                # 拿走 x 堆后，对手能获得的最大值
                opponent_best = dfs(i + x, max(m, x))
                # 我方获得 = 总数 - 对手获得
                my_stones = suffix_sum[i] - opponent_best
                max_stones = max(max_stones, my_stones)
            
            return max_stones
        
        return dfs(0, 1)
```

### 方法二：动态规划（自底向上）⭐

```python
class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        """
        自底向上的动态规划
        时间复杂度：O(n^3)
        空间复杂度：O(n^2)
        """
        n = len(piles)
        
        # 计算后缀和
        suffix_sum = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_sum[i] = suffix_sum[i + 1] + piles[i]
        
        # dp[i][m]：从 i 开始，M=m 时先手的最大收益
        # M 最大可能为 n（拿走所有剩余堆）
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        
        # 从后往前填表
        for i in range(n - 1, -1, -1):
            for m in range(1, n + 1):
                # 如果可以全拿，直接拿走
                if i + 2 * m >= n:
                    dp[i][m] = suffix_sum[i]
                else:
                    # 尝试拿 x 堆
                    for x in range(1, 2 * m + 1):
                        if i + x <= n:
                            new_m = max(m, x)
                            # 拿 x 堆后对手的最优解
                            opponent = dp[i + x][new_m] if new_m <= n else 0
                            # 我方收益 = 总数 - 对手收益
                            dp[i][m] = max(dp[i][m], suffix_sum[i] - opponent)
        
        return dp[0][1]
```

### 方法三：优化的记忆化搜索（使用字典）

```python
class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        """
        使用字典存储状态，更灵活
        """
        n = len(piles)
        
        # 后缀和
        suffix = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix[i] = suffix[i + 1] + piles[i]
        
        # 记忆化字典
        memo = {}
        
        def helper(index: int, m: int) -> int:
            # 边界：可以全拿
            if index >= n:
                return 0
            if index + 2 * m >= n:
                return suffix[index]
            
            # 查缓存
            if (index, m) in memo:
                return memo[(index, m)]
            
            # 计算最优解
            result = 0
            for x in range(1, 2 * m + 1):
                # 当前拿 x 堆，剩下的给对手
                current = suffix[index] - helper(index + x, max(m, x))
                result = max(result, current)
            
            memo[(index, m)] = result
            return result
        
        return helper(0, 1)
```

## 复杂度分析

**时间复杂度**：O(n³)
- 状态数：O(n²)，i 的范围是 [0, n)，M 的范围是 [1, n]
- 每个状态的转移：O(n)，需要枚举 x
- 总时间：O(n² × n) = O(n³)

**空间复杂度**：O(n²)
- DP 数组或记忆化缓存：O(n²)
- 后缀和数组：O(n)
- 递归栈深度：O(n)

## 关键点总结

1. **后缀和优化**：预计算后缀和避免重复求和
2. **博弈思想**：我方最大 = 总数 - 对手最大
3. **状态设计**：`(当前位置, 当前M)` 唯一确定状态
4. **边界条件**：当 `i + 2M >= n` 时可以全拿
5. **M 的更新**：M = max(M, X)，M 单调不减

## 易错点

1. **M 的范围**：M 可以增长到 n，数组大小要足够
2. **边界判断**：`i + 2*m >= n` 时可以全拿，注意等号
3. **状态转移理解**：容易混淆先手和后手的收益
4. **后缀和索引**：suffix[i] 表示从 i 到末尾的和
5. **初始 M 值**：游戏开始时 M = 1
