## 题目描述

一个班有 n 个学生，编号为 0 到 n-1。给你一个整数数组 `chalk` 和一个整数 `k`，其中 `chalk[i]` 是第 i 个学生每次回答问题使用的粉笔量。

学生从 0 开始轮流回答，当某学生粉笔不足时，该学生需要补充粉笔。

返回需要补充粉笔的学生编号。

**示例 1：**
```
输入：chalk = [5,1,5], k = 22
输出：0
解释：
学生 0 使用 5 粉笔，k=22-5=17
学生 1 使用 1，k=16
学生 2 使用 5，k=11
学生 0 使用 5，k=6
学生 1 使用 1，k=5
学生 2 使用 5，k=0
学生 0 需要 5，但 k=0 < 5，返回 0
```

**示例 2：**
```
输入：chalk = [3,4,1,2], k = 25
输出：1
```

**提示：**
- `chalk.length == n`
- `1 <= n <= 10^5`
- `1 <= chalk[i] <= 10^5`
- `1 <= k <= 10^9`

## 解题思路

**前缀和 + 二分查找**：

1. 先计算总粉笔量 `total = sum(chalk)`
2. 用 `k %= total` 去掉完整的轮次
3. 在前缀和数组中二分查找第一个 `prefix[i] > k` 的位置，即为答案

## 代码实现

### 方法一：前缀和 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def chalkReplacer(self, chalk: List[int], k: int) -> int:
        total = sum(chalk)
        k %= total  # 去掉完整轮次

        # 构建前缀和
        prefix = []
        s = 0
        for c in chalk:
            s += c
            prefix.append(s)

        # 二分查找第一个前缀和 > k 的位置
        # 即第一个 chalk[0..i] 的累加和超过 k 的学生
        return bisect.bisect_right(prefix, k)
```

### 方法二：线性扫描（模拟）

```python
from typing import List

class Solution:
    def chalkReplacer(self, chalk: List[int], k: int) -> int:
        total = sum(chalk)
        k %= total  # 去掉完整轮次

        # 逐个学生减少粉笔，找到第一个粉笔不足的
        for i, c in enumerate(chalk):
            if k < c:
                return i
            k -= c

        return 0  # 不会到达这里
```

### 方法三：前缀和 + bisect_left

```python
from typing import List
import bisect

class Solution:
    def chalkReplacer(self, chalk: List[int], k: int) -> int:
        n = len(chalk)
        k %= sum(chalk)

        # 前缀和数组（从 chalk[0] 开始累加）
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + chalk[i]

        # 找第一个 prefix[i+1] > k 的 i
        # 等价于找 bisect_right(prefix, k) - 1
        idx = bisect.bisect_right(prefix, k) - 1
        return idx
```

## 复杂度分析

- **时间复杂度**：O(n + log n)，计算前缀和 O(n)，二分查找 O(log n)
- **空间复杂度**：O(n)，前缀和数组

## 关键点总结

1. 先用 `k %= total` 去掉完整轮次，避免超时
2. 用前缀和 + 二分查找定位第一个不够粉笔的学生
3. `bisect_right(prefix, k)` 返回第一个严格大于 k 的位置

## 易错点

- 必须先取模，否则 k 可能很大导致超时
- 二分查找的目标是「前缀和第一次超过 k」的位置
