## 题目描述

有 `n` 根高度各不相同的木棍，排成一行后从左侧观看，只有当一根木棍比它左边所有木棍都高时才可见。

给你 `n` 和 `k`，求恰好能看到 `k` 根木棍的排列数，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：n = 3, k = 2
输出：3
```

**示例 2：**
```
输入：n = 5, k = 1
输出：1
解释：只有排成降序 [5,4,3,2,1] 时才只能看到 1 根
```

**提示：**
- `1 <= n <= 1000`
- `1 <= k <= n`

## 解题思路

**动态规划**：`dp[n][k]` 为 n 根木棍恰好看到 k 根的方案数。

考虑最短木棍（高度为 1）的位置：
- 若最短木棍在**最左边**：高度最小，永远可见，问题变为从剩余 n-1 根中看到 k-1 根：`dp[n-1][k-1]`
- 若最短木棍在**其他位置**：最短木棍不可见，插入最短木棍后 k 不变。等价于从 n-1 根中看到 k 根，最短木棍有 n-1 个插入位置（任何非最左位置）：`(n-1) * dp[n-1][k]`

递推：`dp[n][k] = dp[n-1][k-1] + (n-1) * dp[n-1][k]`

这正是**无符号斯特林数**（第一类斯特林数）的递推公式！

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def rearrangeSticks(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7

        # dp[i][j] = i 根木棍恰好看到 j 根的排列数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 1  # 0 根木棍看到 0 根，1 种方式

        for i in range(1, n + 1):
            for j in range(1, k + 1):
                # 最短木棍放最左边
                dp[i][j] = dp[i - 1][j - 1]
                # 最短木棍放其他位置（i-1 种选择）
                dp[i][j] = (dp[i][j] + (i - 1) * dp[i - 1][j]) % MOD

        return dp[n][k]
```

### 方法二：空间优化（滚动数组）

```python
class Solution:
    def rearrangeSticks(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # 只需保留当前行，prev 为上一行
        prev = [0] * (k + 1)
        prev[0] = 1

        for i in range(1, n + 1):
            curr = [0] * (k + 1)
            for j in range(1, min(i, k) + 1):
                curr[j] = (prev[j - 1] + (i - 1) * prev[j]) % MOD
            prev = curr

        return prev[k]
```

## 复杂度分析

- **时间复杂度**：O(n * k)
- **空间复杂度**：O(n * k)（方法一），O(k)（方法二）

## 关键点总结

1. 递推基于最短木棍的位置：最左位置贡献 `dp[n-1][k-1]`，其他位置贡献 `(n-1) * dp[n-1][k]`
2. 本质是**第一类无符号斯特林数**（将 n 个元素排成 k 个循环的排列数）
3. 边界：`dp[0][0] = 1`，`dp[i][0] = 0`（i > 0）

## 易错点

- 只有 0 根木棍看到 0 根才有 1 种（dp[0][0]=1），1 根及以上看到 0 根为 0
- `j` 的范围最大为 `min(i, k)`，避免无效状态
