## 题目描述

给你四个整数数组 nums1、nums2、nums3 和 nums4，数组长度都是 n，请你计算有多少个元组 (i, j, k, l) 能满足：

- 0 <= i, j, k, l < n
- nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

**示例 1:**

```
输入: nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出: 2
解释:
两个元组如下:
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0
```

**示例 2:**

```
输入: nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
输出: 1
```

**提示:**

- n == nums1.length == nums2.length == nums3.length == nums4.length
- 1 <= n <= 200
- -2^28 <= nums1[i], nums2[i], nums3[i], nums4[i] <= 2^28

## 解题思路

这道题如果暴力枚举四层循环，时间复杂度是 O(n^4)，会超时。使用**哈希表**可以优化到 O(n^2)。

**核心思想：分组 + 哈希**
1. 将四个数组分成两组：(nums1, nums2) 和 (nums3, nums4)
2. 用哈希表记录前两个数组所有可能的和
3. 遍历后两个数组，查找是否存在对应的相反数

## Python 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        """
        哈希表优化
        时间复杂度: O(n^2)
        空间复杂度: O(n^2)
        """
        # 统计 nums1 + nums2 所有可能的和
        sum_map = defaultdict(int)
        for a in nums1:
            for b in nums2:
                sum_map[a + b] += 1
        
        # 查找 nums3 + nums4 的相反数
        count = 0
        for c in nums3:
            for d in nums4:
                target = -(c + d)
                count += sum_map[target]
        
        return count
```

### 方法二：Counter 简化版

```python
from typing import List
from collections import Counter

class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        """使用 Counter"""
        # 统计前两个数组的和
        sum_count = Counter(a + b for a in nums1 for b in nums2)
        
        # 查找后两个数组
        return sum(sum_count[-(c + d)] for c in nums3 for d in nums4)
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. **分组策略**：四个数组分成两组处理
2. **哈希优化**：用空间换时间，O(n^2) 代替 O(n^4)
3. **相反数查找**：a+b+c+d=0 等价于 a+b=-(c+d)
