## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

如果下标 `i`、`j`、`k` 满足 `i < j < k` 且 `nums[i] < nums[j]` 且 `nums[j] > nums[k]`，则称 `(i, j, k)` 为一个山形三元组。

返回所有山形三元组中 `nums[i] + nums[j] + nums[k]` 的 **最小值**。若不存在山形三元组，返回 `-1`。

**示例 1：**
```
输入：nums = [8,6,1,5,3]
输出：9
解释：(2,3,4): nums[2]+nums[3]+nums[4]=1+5+3=9
```

**示例 2：**
```
输入：nums = [5,4,8,7,10,2]
输出：13
解释：(1,3,5): nums[1]+nums[3]+nums[5]=4+7+2=13
```

**提示：**
- `3 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

数据范围极小（n <= 50），直接三重循环暴力枚举所有 (i, j, k) 组合。

## Python 代码实现

### 方法一：暴力三重循环（推荐）

```python
from typing import List

class Solution:
    def minimumSum(self, nums: List[int]) -> int:
        n = len(nums)
        ans = float('inf')
        for i in range(n):
            for j in range(i + 1, n):
                if nums[j] <= nums[i]:
                    continue  # 不满足 nums[i] < nums[j]
                for k in range(j + 1, n):
                    if nums[k] < nums[j]:  # 满足 nums[j] > nums[k]
                        ans = min(ans, nums[i] + nums[j] + nums[k])
        return ans if ans != float('inf') else -1
```

### 方法二：预处理左最小和右最小

```python
from typing import List

class Solution:
    def minimumSum(self, nums: List[int]) -> int:
        n = len(nums)
        # left_min[j]: j 左侧严格小于 nums[j] 的最小值
        left_min = [float('inf')] * n
        for j in range(1, n):
            for i in range(j):
                if nums[i] < nums[j]:
                    left_min[j] = min(left_min[j], nums[i])

        # right_min[j]: j 右侧严格小于 nums[j] 的最小值
        right_min = [float('inf')] * n
        for j in range(n - 2, -1, -1):
            for k in range(j + 1, n):
                if nums[k] < nums[j]:
                    right_min[j] = min(right_min[j], nums[k])

        ans = float('inf')
        for j in range(1, n - 1):
            if left_min[j] != float('inf') and right_min[j] != float('inf'):
                ans = min(ans, left_min[j] + nums[j] + right_min[j])

        return ans if ans != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n^3)，三重循环；方法二为 O(n^2)
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 山形三元组：中间元素是"峰值"，两侧元素比它小
2. 求最小和，因此希望 left_min 和 right_min 尽可能小
3. n <= 50 时暴力枚举完全够用

## 易错点

1. 注意是严格大于/小于（`<` 和 `>`），不能取等
2. 找不到三元组时返回 -1，不是 0 或无穷大
