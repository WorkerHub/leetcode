## 题目描述

给你一个下标从 0 开始的字符串 `s`，另有一个下标从 0 开始、长度为 `k` 的字符串 `queryCharacters`，以及一个下标从 0 开始、长度也为 `k` 的整数数组 `queryIndices`。

第 `i` 个查询将 `s[queryIndices[i]]` 替换为 `queryCharacters[i]`。

返回每次查询后，`s` 中仅由**单一字符**组成的**最长子字符串**的长度，结果放入数组返回。

**示例 1：**
```
输入：s = "babacc", queryCharacters = "bcb", queryIndices = [1,3,3]
输出：[3,3,4]
```

**示例 2：**
```
输入：s = "abyzz", queryCharacters = "aa", queryIndices = [2,1]
输出：[2,3]
```

**提示：**
- `1 <= s.length <= 10^5`
- `k == queryCharacters.length == queryIndices.length`
- `1 <= k <= 10^5`

## 解题思路

每次查询后求最长全同字符子串，暴力法每次查询 O(n) 总体 O(nk) 会超时。

**线段树解法：** 维护以下信息：
- `lmax`：从左端起最长前缀同字符长度。
- `rmax`：从右端起最长后缀同字符长度。
- `ans`：区间内最长全同字符子串长度。
- `lchar`：区间最左字符。
- `rchar`：区间最右字符。
- `len`：区间长度。

合并两个区间时，若左区间的 `rchar == 右区间的 lchar`，跨区间可以合并，更新 `ans`。

每次单点更新后查询整个区间的 `ans`。

## 代码实现

### 方法一：线段树（推荐）

```python
from typing import List

class Solution:
    def longestRepeating(self, s: str, queryCharacters: str, queryIndices: List[int]) -> List[int]:
        n = len(s)
        s = list(s)

        # 线段树节点：[lmax, rmax, ans, lchar, rchar, length]
        tree = [[0, 0, 0, '', '', 0]] * (4 * n)

        def build(node, start, end):
            if start == end:
                tree[node] = [1, 1, 1, s[start], s[start], 1]
                return
            mid = (start + end) // 2
            build(2 * node, start, mid)
            build(2 * node + 1, mid + 1, end)
            pushup(node)

        def pushup(node):
            left = tree[2 * node]
            right = tree[2 * node + 1]
            lmax = left[0]
            rmax = right[1]
            ans = max(left[2], right[2])
            lchar = left[3]
            rchar = right[4]
            length = left[5] + right[5]

            # 如果左区间右字符 == 右区间左字符，可以合并
            if left[4] == right[3]:
                merge = left[1] + right[0]
                ans = max(ans, merge)
                if left[0] == left[5]:  # 左区间全是同字符
                    lmax = left[5] + right[0]
                if right[1] == right[5]:  # 右区间全是同字符
                    rmax = right[5] + left[1]

            tree[node] = [lmax, rmax, ans, lchar, rchar, length]

        def update(node, start, end, idx, char):
            if start == end:
                tree[node] = [1, 1, 1, char, char, 1]
                return
            mid = (start + end) // 2
            if idx <= mid:
                update(2 * node, start, mid, idx, char)
            else:
                update(2 * node + 1, mid + 1, end, idx, char)
            pushup(node)

        build(1, 0, n - 1)

        ans = []
        for c, i in zip(queryCharacters, queryIndices):
            s[i] = c
            update(1, 0, n - 1, i, c)
            ans.append(tree[1][2])
        return ans
```

### 方法二：有序集合维护分段（暴力对比，适合小数据）

```python
from typing import List

class Solution:
    def longestRepeating(self, s: str, queryCharacters: str, queryIndices: List[int]) -> List[int]:
        # 暴力法，适合理解题意
        s = list(s)
        res = []
        for c, i in zip(queryCharacters, queryIndices):
            s[i] = c
            # 计算最长全同子串
            max_len = 1
            cur_len = 1
            for j in range(1, len(s)):
                if s[j] == s[j - 1]:
                    cur_len += 1
                    max_len = max(max_len, cur_len)
                else:
                    cur_len = 1
            res.append(max_len)
        return res
```

## 复杂度分析

**方法一（线段树）：**
- 时间复杂度：O((n + k) log n)，建树 O(n log n)，每次查询 O(log n)。
- 空间复杂度：O(n)，线段树节点。

**方法二（暴力）：**
- 时间复杂度：O(nk)，每次查询 O(n)，总体 O(nk)，适合小数据。
- 空间复杂度：O(n)。

## 关键点总结

1. 线段树区间合并：需存储左端字符、右端字符、前缀/后缀同字符长度。
2. 两区间合并时，若左尾字符 == 右首字符，跨越中间点可以延伸最长子串。
3. 每次单点更新后直接查询根节点的 `ans` 即为全局答案。

## 易错点

- 合并时前缀/后缀更新逻辑复杂：若左区间全同字符，则新前缀 = 左长度 + 右前缀。
- Python 线段树的列表赋值注意浅拷贝问题，需用 `[...]` 创建新列表。
