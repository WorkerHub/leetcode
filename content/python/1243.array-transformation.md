## 题目描述

给你一个初始数组 `arr`，每一天你都要根据前一天的数组生成新的数组。

第 `i` 天所生成的数组，是由你对第 `i-1` 天的数组进行如下操作所得的：

- 如果一个元素小于它的左右邻居，那么该元素自增 1。
- 如果一个元素大于它的左右邻居，那么该元素自减 1。
- 首、尾元素永远不会改变。

当数组不再发生变化时，请你返回这个最终数组。

示例 1：

```
输入：arr = [6,2,3,4]
输出：[6,3,3,4]
解释：
第一天，数组从 [6,2,3,4] 变为 [6,3,3,4]。
无法再对该数组进行更多操作。
```

示例 2：

```
输入：arr = [1,6,3,4,3,5]
输出：[1,4,4,4,4,5]
解释：
第一天，数组从 [1,6,3,4,3,5] 变为 [1,5,4,3,4,5]。
第二天，数组从 [1,5,4,3,4,5] 变为 [1,4,4,4,4,5]。
无法再对该数组进行更多操作。
```

提示：

- `1 <= arr.length <= 100`
- `1 <= arr[i] <= 100`

## 解题思路

这道题的核心是模拟数组的变化过程，直到数组稳定不再变化为止。

关键观察：
1. 每次变化时，需要基于前一天的数组状态来计算新的数组
2. 首尾元素永远不变，只需要处理中间元素
3. 需要判断数组是否稳定（不再变化），如果两次数组相同则停止
4. 对于中间元素 `arr[i]`：
   - 如果 `arr[i] < arr[i-1]` 且 `arr[i] < arr[i+1]`（局部最小值），则 `arr[i] += 1`
   - 如果 `arr[i] > arr[i-1]` 且 `arr[i] > arr[i+1]`（局部最大值），则 `arr[i] -= 1`
   - 否则保持不变

算法流程：
1. 循环执行变换操作
2. 每次创建新数组存储变换结果
3. 比较新数组和旧数组，如果相同则返回
4. 否则继续下一轮变换

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def transformArray(self, arr: List[int]) -> List[int]:
        """
        模拟数组变换过程，直到数组稳定
        
        时间复杂度：O(n * k)，k 为变换次数
        空间复杂度：O(n)
        """
        n = len(arr)
        # 如果数组长度小于等于2，首尾元素不变，直接返回
        if n <= 2:
            return arr
        
        while True:
            # 创建新数组存储本次变换结果
            new_arr = arr[:]  # 复制数组
            changed = False  # 标记是否发生变化
            
            # 只处理中间元素（索引 1 到 n-2）
            for i in range(1, n - 1):
                # 局部最小值：小于左右邻居，自增 1
                if arr[i] < arr[i - 1] and arr[i] < arr[i + 1]:
                    new_arr[i] = arr[i] + 1
                    changed = True
                # 局部最大值：大于左右邻居，自减 1
                elif arr[i] > arr[i - 1] and arr[i] > arr[i + 1]:
                    new_arr[i] = arr[i] - 1
                    changed = True
            
            # 如果没有发生变化，说明数组已稳定
            if not changed:
                break
            
            # 更新数组为新数组
            arr = new_arr
        
        return arr
```

### 方法二：优化判断（使用标志位）

```python
from typing import List

class Solution:
    def transformArray(self, arr: List[int]) -> List[int]:
        """
        使用标志位优化，避免不必要的数组比较
        
        时间复杂度：O(n * k)
        空间复杂度：O(n)
        """
        n = len(arr)
        if n <= 2:
            return arr
        
        # 持续变换直到稳定
        while True:
            # 记录每个位置是否需要增加或减少
            changes = [0] * n  # 0表示不变，1表示增加，-1表示减少
            
            for i in range(1, n - 1):
                if arr[i] < arr[i - 1] and arr[i] < arr[i + 1]:
                    changes[i] = 1
                elif arr[i] > arr[i - 1] and arr[i] > arr[i + 1]:
                    changes[i] = -1
            
            # 如果所有位置都不需要改变，则已稳定
            if all(c == 0 for c in changes):
                break
            
            # 应用变化
            for i in range(1, n - 1):
                arr[i] += changes[i]
        
        return arr
```

### 方法三：函数式编程风格

```python
from typing import List

class Solution:
    def transformArray(self, arr: List[int]) -> List[int]:
        """
        使用辅助函数使代码更清晰
        
        时间复杂度：O(n * k)
        空间复杂度：O(n)
        """
        def transform_once(array: List[int]) -> List[int]:
            """执行一次变换"""
            n = len(array)
            if n <= 2:
                return array
            
            new_array = array[:]
            for i in range(1, n - 1):
                if array[i] < array[i - 1] and array[i] < array[i + 1]:
                    new_array[i] = array[i] + 1
                elif array[i] > array[i - 1] and array[i] > array[i + 1]:
                    new_array[i] = array[i] - 1
            
            return new_array
        
        # 持续变换直到数组不再变化
        while True:
            new_arr = transform_once(arr)
            if new_arr == arr:
                break
            arr = new_arr
        
        return arr
```

## 复杂度分析

### 方法一：直接模拟

- 时间复杂度：O(n × k)，其中 n 是数组长度，k 是变换次数。最坏情况下，k 可能达到 O(max(arr))，因为每次最多只能改变 1。但在实际情况中，k 通常较小。
- 空间复杂度：O(n)，需要创建新数组存储变换结果。

### 方法二和方法三

- 时间复杂度：O(n × k)，同方法一
- 空间复杂度：O(n)

## 关键点总结

1. 模拟题目关键在于理解变换规则，准确实现逻辑
2. 首尾元素不变，只需处理中间元素
3. 每次变换需要基于前一次的状态，不能边遍历边修改
4. 判断稳定的方法：比较前后两次数组或使用变化标志
5. 局部最大值/最小值的判断需要同时满足与左右邻居的关系

## 易错点

1. 边界处理：忘记首尾元素不变，导致越界或错误修改
2. 状态混乱：在遍历时直接修改原数组，导致后续判断基于错误的状态
3. 判断条件：局部最大/最小需要同时满足两个条件（与左右邻居比较）
4. 终止条件：没有正确判断数组是否稳定，导致死循环或提前终止
5. 特殊情况：数组长度为 1 或 2 时，应直接返回原数组
