## 题目描述

给你一个由 `n` 个正整数组成的数组 `nums`。

先求出数组中所有非空连续子数组的和，然后按升序排列。返回排列后下标从 `left` 到 `right`（从1开始）的和，答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3,4], n = 4, left = 1, right = 5
输出：13
解释：子数组和为 [1,3,6,10,2,5,9,3,7,4]，排序后为 [1,2,3,3,4,5,6,7,9,10]，下标1~5的和 = 1+2+3+3+4 = 13
```

**示例 2：**
```
输入：nums = [1,2,3,4], n = 4, left = 3, right = 4
输出：6
```

**提示：**
- `n == nums.length`
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 100`
- `1 <= left <= right <= n*(n+1)/2`

## 解题思路

### 方法一：暴力枚举（推荐用于本题规模）

1. 枚举所有连续子数组的和，存入列表
2. 排序列表
3. 取下标 `left-1` 到 `right-1` 的元素求和

由于 `n <= 1000`，子数组数量最多 `n*(n+1)/2 = 500500`，暴力可以接受。

### 方法二：双指针 + 优先队列（适合更大 n）

利用最小堆，每次提取最小子数组和，找到第 k 小的和。

## 代码实现

### 方法一：暴力枚举排序（推荐）

```python
from typing import List

class Solution:
    def rangeSum(self, nums: List[int], n: int, left: int, right: int) -> int:
        MOD = 10**9 + 7
        sums = []
        # 枚举所有连续子数组
        for i in range(n):
            s = 0
            for j in range(i, n):
                s += nums[j]
                sums.append(s)
        # 排序后取指定范围求和
        sums.sort()
        return sum(sums[left-1:right]) % MOD
```

### 方法二：前缀和 + 排序

```python
from typing import List

class Solution:
    def rangeSum(self, nums: List[int], n: int, left: int, right: int) -> int:
        MOD = 10**9 + 7
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]

        # 所有子数组和 = prefix[j] - prefix[i]，0 <= i < j <= n
        sums = []
        for i in range(n):
            for j in range(i+1, n+1):
                sums.append(prefix[j] - prefix[i])

        sums.sort()
        return sum(sums[left-1:right]) % MOD
```

### 方法三：堆（优先队列）O(k log n)

```python
import heapq
from typing import List

class Solution:
    def rangeSum(self, nums: List[int], n: int, left: int, right: int) -> int:
        MOD = 10**9 + 7
        # 最小堆：(当前子数组和, 起始下标, 结束下标)
        # 初始化：每个以 i 开始的、仅含 nums[i] 的子数组
        heap = [(nums[i], i, i) for i in range(n)]
        heapq.heapify(heap)

        ans = 0
        for k in range(1, right + 1):
            val, start, end = heapq.heappop(heap)
            if k >= left:
                ans = (ans + val) % MOD
            # 扩展：把 end+1 加入子数组
            if end + 1 < n:
                heapq.heappush(heap, (val + nums[end+1], start, end+1))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一/二（暴力） | O(N^2 log N) | O(N^2) |
| 方法三（堆） | O(right * log N) | O(N) |

## 关键点总结

1. 子数组总数为 `n*(n+1)/2`，n=1000 时约 50 万，暴力排序可以接受
2. 堆方法每次弹出最小的子数组和，适合 right 较小的情况
3. 注意答案对 `10^9 + 7` 取模

## 易错点

- 下标从 1 开始，取 `sums[left-1:right]`（Python 切片右边是开区间）
- 取模在最后统一做，避免中间求和溢出（Python 整数无溢出，但题目要求取模）
