## 题目描述

给你一个整数数组 `arr` 和一个整数数组的数组 `pieces`，其中 `pieces` 中的整数**各不相同**。你的目标是按**顺序**连接 `pieces` 中的数组，从而形成 `arr`。

你可以以任意顺序选取 `pieces` 中的数组（每个数组只能使用一次），但在同一个数组中的整数顺序**不能改变**。

如果可以形成 `arr`，则返回 `true`；否则，返回 `false`。

**示例：**
```
输入：arr = [85], pieces = [[85]]
输出：true

输入：arr = [15,88], pieces = [[88],[15]]
输出：true

输入：arr = [49,18,16], pieces = [[16,18,49]]
输出：false
（顺序错误）
```

## 解题思路

用哈希表将 `pieces` 中每个数组的**首元素**映射到该数组，然后遍历 `arr`：
- 在哈希表中找到当前元素对应的 piece
- 检查 piece 中的所有元素是否与 arr 中对应位置匹配

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class Solution:
    def canFormArray(self, arr: List[int], pieces: List[List[int]]) -> bool:
        # 用首元素作为 key，映射到对应 piece
        piece_map = {p[0]: p for p in pieces}
        
        i = 0
        while i < len(arr):
            if arr[i] not in piece_map:
                return False  # 当前元素没有对应的 piece
            
            piece = piece_map[arr[i]]
            # 检查 piece 中所有元素是否顺序匹配
            for j, val in enumerate(piece):
                if i + j >= len(arr) or arr[i + j] != val:
                    return False
            
            i += len(piece)  # 跳过已匹配的部分
        
        return True
```

### 方法二：构造字符串比较

```python
from typing import List

class Solution:
    def canFormArray(self, arr: List[int], pieces: List[List[int]]) -> bool:
        # 将 arr 转为字符串
        arr_str = ','.join(map(str, arr))
        
        # 将每个 piece 也转为字符串，并检查是否是 arr_str 的子串
        # 注意：pieces 拼接后必须等于 arr_str
        
        piece_map = {p[0]: p for p in pieces}
        result = []
        i = 0
        
        while i < len(arr):
            if arr[i] not in piece_map:
                return False
            piece = piece_map[arr[i]]
            result.extend(piece)
            i += len(piece)
        
        return result == arr
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(m) |

n 为 arr 长度，m 为 pieces 总元素数。

## 关键点总结

1. 以首元素为 key 建立哈希表，O(1) 查找对应 piece
2. 遍历 arr，找到 piece 后顺序验证所有元素
3. 题目保证 pieces 中整数各不相同，所以首元素唯一

## 易错点

- piece 内部顺序不能改变，必须按原顺序匹配
- 遍历时 i 需要跳过整个 piece 的长度
- 如果 arr 中某个位置的元素在任何 piece 的首位都不存在，直接返回 False
