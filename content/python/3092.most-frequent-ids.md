## 题目描述

一个数字系统中，每个步骤后，某个 ID 的出现次数会变化。

给你两个长度为 `n` 的整数数组 `nums` 和 `freq`，在第 `i` 步，ID `nums[i]` 的频率变化 `freq[i]`（正为增加，负为减少）。

返回每一步后出现频率最高的 ID 的频率，若不存在 ID 则为 0。

**示例 1：**
```
输入：nums = [2,3,2,1], freq = [3,2,-3,1]
输出：[3,3,2,2]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `-10^5 <= freq[i] <= 10^5`

## 解题思路

使用最大堆（懒删除）：
- 维护哈希表 `count`，记录每个 ID 的当前频率
- 维护最大堆 `(-freq, id)`，堆顶为最大频率
- 每次操作后，懒删除堆顶中过时的频率

## Python 代码实现

### 方法一：最大堆 + 懒删除（推荐）

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def mostFrequentIDs(self, nums: List[int], freq: List[int]) -> List[int]:
        n = len(nums)
        count = defaultdict(int)
        heap = []  # 最大堆（存负值）
        result = []

        for i in range(n):
            uid = nums[i]
            count[uid] += freq[i]
            heapq.heappush(heap, (-count[uid], uid))

            # 懒删除：弹出过时的堆顶
            while heap and -heap[0][0] != count[heap[0][1]]:
                heapq.heappop(heap)

            if heap:
                result.append(-heap[0][0])
            else:
                result.append(0)

        return result
```

### 方法二：SortedDict

```python
from typing import List
from collections import defaultdict
from sortedcontainers import SortedDict

class Solution:
    def mostFrequentIDs(self, nums: List[int], freq: List[int]) -> List[int]:
        count = defaultdict(int)
        # SortedDict: key=频率, value=该频率的ID集合
        freq_to_ids = SortedDict()
        result = []

        for uid, f in zip(nums, freq):
            old_freq = count[uid]
            new_freq = old_freq + f

            # 从旧频率中移除
            if old_freq in freq_to_ids:
                freq_to_ids[old_freq].discard(uid)
                if not freq_to_ids[old_freq]:
                    del freq_to_ids[old_freq]

            # 加入新频率
            count[uid] = new_freq
            if new_freq > 0:
                if new_freq not in freq_to_ids:
                    freq_to_ids[new_freq] = set()
                freq_to_ids[new_freq].add(uid)

            if freq_to_ids:
                result.append(freq_to_ids.peekitem(-1)[0])  # 最大频率
            else:
                result.append(0)

        return result
```

## 复杂度分析

- 方法一：O(n log n)，堆操作
- 方法二：O(n log n)，SortedDict 操作
- 空间复杂度：O(n)

## 关键点总结

1. 懒删除：堆中保留旧值，只在需要时验证是否过期
2. 频率可以变为 0 或负数，需要判断 count > 0 才有效
3. 每步只需要最大频率，堆或有序字典均可

## 易错点

1. 频率可能为负（减少操作），频率 <= 0 的 ID 不计入统计
2. 懒删除时要比较当前实际频率与堆中存储的频率是否一致
