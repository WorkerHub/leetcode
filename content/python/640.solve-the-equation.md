## 题目描述

求解一个给定的方程，将 x 以字符串 "x=#value" 的形式返回。

该方程仅包含 '+'、'-' 操作，变量 x 和其对应系数。

**示例 1：**
```
输入：equation = "x+5-3+x=6+x-2"
输出："x=2"
```

**示例 2：**
```
输入：equation = "x=x"
输出："Infinite solutions"
```

**示例 3：**
```
输入：equation = "2x=x"
输出："x=0"
```

**示例 4：**
```
输入：equation = "2x+3x-6x=x+2"
输出："x=-1"
```

**提示：**
- 3 <= equation.length <= 1000
- 方程只有一个 '='

## 解题思路

解析方程，分别统计 x 的系数和常数项。

## Python 代码实现

### 方法一：字符串解析

```python
class Solution:
    def solveEquation(self, equation: str) -> str:
        left, right = equation.split('=')
        
        def parse(expr):
            """解析表达式，返回 (x的系数, 常数项)"""
            coef = 0  # x 的系数
            const = 0  # 常数项
            
            # 添加 '+' 方便处理
            expr = '+' + expr
            i = 0
            n = len(expr)
            
            while i < n:
                # 找到符号
                j = i + 1
                while j < n and expr[j] not in '+-':
                    j += 1
                
                # 提取数字部分
                term = expr[i+1:j]
                sign = 1 if expr[i] == '+' else -1
                
                if 'x' in term:
                    # 处理 x 的系数
                    if term == 'x':
                        coef += sign
                    else:
                        coef += sign * int(term[:-1])
                else:
                    # 处理常数项
                    const += sign * int(term)
                
                i = j
            
            return coef, const
        
        # 解析左右两边
        left_coef, left_const = parse(left)
        right_coef, right_const = parse(right)
        
        # 移项：所有 x 移到左边，常数移到右边
        coef = left_coef - right_coef
        const = right_const - left_const
        
        if coef == 0:
            if const == 0:
                return "Infinite solutions"
            else:
                return "No solution"
        else:
            return f"x={const // coef}"
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 分别解析等号两边的表达式
2. 统计 x 的系数和常数项
3. 移项后求解
