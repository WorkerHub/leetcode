## 题目描述

给你一个带时间限制的无向图，图中有 `n` 个节点，编号 0 到 `n-1`。`values[i]` 是节点 `i` 的价值。`edges` 数组中每条边有权重（时间）。

你从节点 0 出发，**最多** `maxTime` 时间内必须回到节点 0。每个节点可以多次经过，但其价值**只计算一次**。

返回回到 0 节点时，路径上收集的**最大总价值**。

**示例 1：**
```
输入：values = [0,32,10,43], edges = [[0,1,10],[1,2,15],[0,3,10]], maxTime = 49
输出：75
解释：路径 0->3->0->1->0 总时间 10+10+10+10=40<=49，价值 0+43+0+32=75
```

**提示：**
- `n == values.length`
- `1 <= n <= 1000`
- `0 <= edges.length <= 2000`
- `0 <= values[i] <= 10^8`
- `1 <= time_i <= 10^3`
- `1 <= maxTime <= 100`

## 解题思路

**回溯 + DFS：**

从节点 0 出发，探索所有路径，回溯到 0 时更新答案。

**关键优化：** `maxTime <= 100`，每条边时间 >= 1，所以路径最多经过 100 条边。实际上因为图是稀疏的（最多 2000 条边），DFS 可行。

用 `visited_count[node]` 记录当前路径中经过节点 `node` 的次数，价值只在首次经过时计入。

## 代码实现

### 方法一：回溯 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximalPathQuality(self, values: List[int], edges: List[List[int]], maxTime: int) -> int:
        n = len(values)
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))
            graph[v].append((u, t))

        visited_count = [0] * n
        ans = [0]

        def dfs(node: int, time_left: int, current_value: int):
            if node == 0:
                ans[0] = max(ans[0], current_value)

            for nei, edge_time in graph[node]:
                if time_left >= edge_time:
                    is_new = visited_count[nei] == 0
                    visited_count[nei] += 1
                    new_val = current_value + (values[nei] if is_new else 0)
                    dfs(nei, time_left - edge_time, new_val)
                    visited_count[nei] -= 1

        visited_count[0] = 1
        dfs(0, maxTime, values[0])
        return ans[0]
```

### 方法二：回溯 + 剪枝优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximalPathQuality(self, values: List[int], edges: List[List[int]], maxTime: int) -> int:
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))
            graph[v].append((u, t))

        n = len(values)
        visited = [False] * n
        ans = [0]

        def dfs(node, elapsed, gain):
            if node == 0:
                ans[0] = max(ans[0], gain)

            for nei, t in graph[node]:
                if elapsed + t <= maxTime:
                    if not visited[nei]:
                        visited[nei] = True
                        dfs(nei, elapsed + t, gain + values[nei])
                        visited[nei] = False
                    else:
                        dfs(nei, elapsed + t, gain)

        visited[0] = True
        dfs(0, 0, values[0])
        return ans[0]
```

## 复杂度分析

- 时间复杂度：最坏 O(n * maxTime)，但实际远小于此（路径长度受 maxTime 限制）
- 空间复杂度：O(n + E)

## 关键点总结

1. 回溯：每次探索一条边，回溯时恢复状态
2. 价值只在首次经过时计入（用访问计数判断）
3. 剪枝：剩余时间不足以走下一条边时停止
4. 关键：到达节点 0 时更新答案（可以经过 0 后继续走）

## 易错点

- 必须能**回到**节点 0 才更新答案（不是路径结束就更新）
- 节点 0 可以经过多次，但价值只计一次
- 不需要在时间刚好用完时回到 0，只需 `elapsed <= maxTime` 且 `node == 0`
