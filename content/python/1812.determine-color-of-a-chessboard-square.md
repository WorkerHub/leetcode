## 题目描述

给你一个坐标 `coordinates`，它是一个字符串，表示国际象棋棋盘中一个格子的坐标。

- 行由 `a` 到 `h` 的字母表示（列号 1~8）
- 列由数字 `1` 到 `8` 表示

如果所给格子的颜色是白色，则返回 `true`；如果是黑色，则返回 `false`。

**示例 1：**
```
输入：coordinates = "a1"
输出：false
解释：a1 是黑色格子
```

**示例 2：**
```
输入：coordinates = "h3"
输出：true
```

**提示：**
- `coordinates.length == 2`
- `'a' <= coordinates[0] <= 'h'`
- `'1' <= coordinates[1] <= '8'`

## 解题思路

国际象棋棋盘的颜色规律：当列字母序号和行数字之和为偶数时是黑色，奇数时是白色（或相反，取决于定义）。

具体规律：`(列序号 + 行数字)` 的奇偶性决定颜色。
- `a=1, b=2, ..., h=8`
- 如果 `(列序号 + 行数字)` 为奇数，则是白色；为偶数，则是黑色

验证：a1 -> 1+1=2（偶数）-> 黑色（符合示例），h3 -> 8+3=11（奇数）-> 白色（符合示例）。

## 代码实现

### 方法一：奇偶判断（推荐）

```python
class Solution:
    def squareIsWhite(self, coordinates: str) -> bool:
        # 将列字母转为序号（a=1,...,h=8）
        col = ord(coordinates[0]) - ord('a') + 1
        row = int(coordinates[1])
        # 奇数和为白色，偶数和为黑色
        return (col + row) % 2 == 1
```

### 方法二：位运算判断奇偶

```python
class Solution:
    def squareIsWhite(self, coordinates: str) -> bool:
        # 用异或判断奇偶：两个字符的 ASCII 码最低位异或
        # 若最低位不同（一奇一偶），结果为 1，表示白色
        return (ord(coordinates[0]) ^ ord(coordinates[1])) & 1 == 1
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 棋盘颜色由行列序号之和的奇偶性决定
2. 位运算 `(ord(a) ^ ord(b)) & 1` 判断两字符 ASCII 奇偶是否不同，更简洁
3. 字母的 ASCII 值：`a=97`（奇数），`b=98`（偶数），正好与棋盘颜色对应

## 易错点

- 注意 a1 是黑色（题目以 a1 为黑色起点），不要搞反白黑
- `ord('a')=97`（奇数），数字 '1' 的 ASCII 是 49（奇数），两者异或的最低位为 0（偶数），因此 a1 为黑色
