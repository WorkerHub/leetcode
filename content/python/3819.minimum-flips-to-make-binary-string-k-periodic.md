## 题目描述

给你一个二进制字符串 `s` 和一个正整数 `k`，其中 `k` 是 `s` 的长度的因子。

通过若干次翻转操作（将 `0` 变为 `1` 或将 `1` 变为 `0`），使字符串 `s` 变为 k-周期字符串（即 `s[i] == s[i+k]` 对所有合法 i 成立）。

返回最少翻转次数。

**示例 1：**

```
输入：s = "001001", k = 3
输出：0
解释：s 已经是 3-周期的（"001" 重复两次）。
```

**示例 2：**

```
输入：s = "110100", k = 2
输出：2
解释：需要翻转 2 次使字符串变为 2-周期。
```

**提示：**
- `1 <= s.length <= 10^6`
- `s` 仅由 '0' 和 '1' 组成
- `k` 整除 `s.length`

## 解题思路

k-周期意味着字符串由长度 k 的模式重复组成。

对于每个位置 `j`（0 <= j < k），位置 `j, j+k, j+2k, ...` 处的字符都必须相同。

因此：
1. 对每个 `j` in `[0, k)`，统计位置 `j, j+k, j+2k, ...` 中 `0` 和 `1` 的个数。
2. 将较少的那种翻转为较多的那种，代价为 `min(count_0, count_1)`。
3. 所有位置的翻转代价之和即为答案。

## Python 代码实现

### 方法一：按列统计（推荐）

```python
class Solution:
    def minimumFlips(self, s: str, k: int) -> int:
        n = len(s)
        total_flips = 0

        # 对每个余数 j，统计 s[j], s[j+k], s[j+2k], ... 中 0 和 1 的数量
        for j in range(k):
            count_0 = 0
            count_1 = 0
            # 位置 j, j+k, j+2k, ...
            i = j
            while i < n:
                if s[i] == '0':
                    count_0 += 1
                else:
                    count_1 += 1
                i += k
            # 翻转较少的一方
            total_flips += min(count_0, count_1)

        return total_flips
```

### 方法二：数组切片

```python
class Solution:
    def minimumFlips(self, s: str, k: int) -> int:
        n = len(s)
        total = 0

        for j in range(k):
            # 提取该列的所有字符
            col = s[j::k]  # 等价于 s[j], s[j+k], s[j+2k], ...
            ones = col.count('1')
            zeros = len(col) - ones
            total += min(ones, zeros)

        return total
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有字符恰好一次
- 空间复杂度：O(n/k)，每次切片的临时字符串（可优化为 O(1)）

## 关键点总结

1. k-周期 => 将字符串分成 k 列，每列内所有字符必须相同。
2. 每列的最少翻转次数 = `min(列中0的个数, 列中1的个数)`。
3. Python 的切片 `s[j::k]` 可以直接取出第 j 列所有字符。

## 易错点

1. k 整除 n，所以每列的长度相同（n/k 个元素）。
2. 不要误以为只能选 0 或只能选 1，每列独立决策。
