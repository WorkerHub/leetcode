## 题目描述

给你一个 `m x n` 的空二维网格，网格中的每个单元格初始时都是水域。我们可以通过执行 `addLand` 操作，将某个位置的水域变成陆地。

给你一个数组 `positions`，其中 `positions[i] = [ri, ci]` 表示第 `i` 次操作中将位置 `(ri, ci)` 变成陆地。

返回一个整数数组 `answer`，其中 `answer[i]` 是将单元格 `(ri, ci)` 转变成陆地后，网格中岛屿的数量。

**岛屿**的定义是被水包围，并且通过水平或垂直方向上相邻的陆地连接而成的。你可以假设网格的四个边均被水包围。

**示例 1：**
```
输入：m = 3, n = 3, positions = [[0,0],[0,1],[1,2],[2,1]]
输出：[1,1,2,3]
解释：
初始时，网格全是水域：
. . .
. . .
. . .

操作 #1：addLand(0, 0) 将 (0,0) 变成陆地，有 1 个岛屿
X . .
. . .
. . .

操作 #2：addLand(0, 1) 将 (0,1) 变成陆地，仍然是 1 个岛屿（与 (0,0) 相连）
X X .
. . .
. . .

操作 #3：addLand(1, 2) 将 (1,2) 变成陆地，现在有 2 个岛屿
X X .
. . X
. . .

操作 #4：addLand(2, 1) 将 (2,1) 变成陆地，现在有 3 个岛屿
X X .
. . X
. X .
```

**示例 2：**
```
输入：m = 1, n = 1, positions = [[0,0]]
输出：[1]
```

**提示：**
- `1 <= m, n, positions.length <= 10^4`
- `1 <= m * n <= 10^4`
- `positions[i].length == 2`
- `0 <= ri < m`
- `0 <= ci < n`

## 解题思路

这是一道典型的**动态连通性问题**，最适合用**并查集（Union-Find）**来解决。

### 核心思路

1. **初始状态**：所有格子都是水域，岛屿数量为 0
2. **添加陆地**：
   - 将该位置标记为陆地，岛屿数量 +1
   - 检查四个方向（上、下、左、右）是否有相邻的陆地
   - 如果有，使用并查集合并，每合并一次，岛屿数量 -1

### 并查集操作

- **初始化**：每个位置的父节点是自己
- **查找**：找到某个位置所属的岛屿的根节点（路径压缩优化）
- **合并**：将两个岛屿合并成一个（按秩合并优化）

### 坐标转换

二维坐标 `(i, j)` 转换为一维索引：`index = i * n + j`

## Python 代码实现

### 方法一：并查集（推荐）⭐

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        """初始化并查集"""
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = 0  # 岛屿数量
    
    def find(self, x: int) -> int:
        """查找 x 的根节点（带路径压缩）"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        """合并 x 和 y 所在的集合"""
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return False  # 已经在同一个集合
        
        # 按秩合并
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
        
        self.count -= 1  # 合并后岛屿数量减 1
        return True

class Solution:
    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        uf = UnionFind(m * n)
        result = []
        island = set()  # 记录哪些位置是陆地
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]  # 四个方向
        
        for r, c in positions:
            # 将二维坐标转换为一维索引
            idx = r * n + c
            
            # 如果已经是陆地，跳过（题目可能有重复位置）
            if idx in island:
                result.append(uf.count)
                continue
            
            # 添加新陆地，岛屿数量 +1
            island.add(idx)
            uf.count += 1
            
            # 检查四个方向的相邻陆地
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                neighbor_idx = nr * n + nc
                
                # 如果相邻位置在范围内且是陆地
                if 0 <= nr < m and 0 <= nc < n and neighbor_idx in island:
                    uf.union(idx, neighbor_idx)
            
            result.append(uf.count)
        
        return result
```

from typing import List

class Solution:
    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        parent = {}  # 只存储陆地的父节点
        rank = {}
        
        def find(x: int) -> int:
            """查找根节点（路径压缩）"""
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            """合并两个集合"""
            root_x, root_y = find(x), find(y)
            
            if root_x == root_y:
                return False
            
            # 按秩合并
            if rank[root_x] < rank[root_y]:
                parent[root_x] = root_y
            elif rank[root_x] > rank[root_y]:
                parent[root_y] = root_x
            else:
                parent[root_y] = root_x
                rank[root_x] += 1
            
            return True
        
        result = []
        count = 0
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        for r, c in positions:
            idx = r * n + c
            
            # 如果已经是陆地
            if idx in parent:
                result.append(count)
                continue
            
            # 初始化新陆地
            parent[idx] = idx
            rank[idx] = 0
            count += 1
            
            # 尝试与四个方向的陆地合并
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                neighbor_idx = nr * n + nc
                
                if 0 <= nr < m and 0 <= nc < n and neighbor_idx in parent:
                    if union(idx, neighbor_idx):
                        count -= 1
            
            result.append(count)
        
        return result

### 方法三：带详细注释的版本

```python
from typing import List

class Solution:
    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        """
        使用并查集解决动态岛屿问题
        
        核心思想：
        1. 添加陆地时，岛屿数量 +1
        2. 与相邻陆地合并时，岛屿数量 -1
        """
        parent = {}  # 字典存储父节点（只存陆地）
        
        def find(x: int) -> int:
            """查找根节点并路径压缩"""
            if parent[x] != x:
                parent[x] = find(parent[x])  # 路径压缩
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            """
            合并两个集合
            返回：True 表示成功合并，False 表示已在同一集合
            """
            root_x = find(x)
            root_y = find(y)
            
            if root_x != root_y:
                parent[root_x] = root_y  # 简化版，不使用按秩合并
                return True
            
            return False
        
        result = []
        count = 0  # 当前岛屿数量
        
        # 四个方向：右、左、下、上
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        for r, c in positions:
            # 二维转一维
            idx = r * n + c
            
            # 重复添加同一个位置
            if idx in parent:
                result.append(count)
                continue
            
            # 添加新陆地
            parent[idx] = idx  # 初始时父节点是自己
            count += 1
            
            # 检查四个方向
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                neighbor_idx = nr * n + nc
                
                # 边界检查 + 是否是陆地
                if 0 <= nr < m and 0 <= nc < n and neighbor_idx in parent:
                    # 尝试合并
                    if union(idx, neighbor_idx):
                        count -= 1  # 合并成功，岛屿数量减 1
            
            result.append(count)
        
        return result
```

## 复杂度分析

**并查集方法：**
- 时间复杂度：O(k × α(m×n))，其中 k 是 positions 的长度，α 是反阿克曼函数，几乎是常数
- 空间复杂度：O(m × n)，并查集的空间

## 关键点总结

1. **并查集的应用**：动态连通性问题的标准解法
2. **岛屿数量的变化规律**：
   - 添加陆地：+1
   - 合并两个岛屿：-1
3. **路径压缩**：`parent[x] = find(parent[x])` 优化查询
4. **按秩合并**：将较小的树合并到较大的树，优化树的高度
5. **坐标转换**：二维 `(i, j)` → 一维 `i * n + j`

## 易错点

1. **重复添加**：positions 可能包含重复的位置，需要判断
2. **合并条件**：只有当两个根节点不同时才需要合并
3. **计数错误**：合并时忘记 `count -= 1`
4. **边界检查**：检查相邻位置是否在网格范围内
5. **初始化**：新陆地的父节点初始化为自己
