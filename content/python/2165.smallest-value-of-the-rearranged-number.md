## 题目描述

给你一个整数 `num`，**重排** `num` 中的各位数字，使其值**最小化**且不含**前导零**（`0` 本身除外）。

**注意：** 负数的绝对值应最大（即重排后负号不动，只重排数字）。

**示例 1：**
```
输入：num = 310
输出：103
解释：[3,1,0] 的最小排列（无前导零）为 103。
```

**示例 2：**
```
输入：num = -7605
输出：-7650
解释：[-7,-6,-5,-0] 的绝对值最大排列（数字最大）为 7650，加上负号为 -7650。
```

**提示：**
- `-10^15 <= num <= 10^15`

## 解题思路

**正数：** 排序数字，将 0 放在最前的非零数字后面（避免前导零）。

**负数：** 取绝对值后，将数字降序排列（越大绝对值越大，即越小的负数）。

## 代码实现

### 方法一：分正负处理（推荐）

```python
class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0

        if num > 0:
            # 正数：数字升序排列，但最小非零数字放最前
            digits = sorted(str(num))
            # 找第一个非零数字，放到最前面
            first_nonzero = next(i for i, d in enumerate(digits) if d != '0')
            digits[0], digits[first_nonzero] = digits[first_nonzero], digits[0]
            return int(''.join(digits))
        else:
            # 负数：绝对值数字降序排列
            digits = sorted(str(-num), reverse=True)
            return -int(''.join(digits))
```

### 方法二：使用字符串操作

```python
class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0

        sign = 1 if num > 0 else -1
        digits = sorted(str(abs(num)), reverse=(sign < 0))

        if sign > 0 and digits[0] == '0':
            # 将最小非零数字移到首位
            for i in range(1, len(digits)):
                if digits[i] != '0':
                    digits[0], digits[i] = digits[i], digits[0]
                    break

        return sign * int(''.join(digits))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 | O(d log d)，d 为位数 | O(d) |

## 关键点总结

1. 正数：升序排列，处理前导零（将最小非零数字放首位）。
2. 负数：降序排列（绝对值最大 = 负数最小）。
3. 特殊情况：num = 0 直接返回 0。

## 易错点

- 正数含有 0 时，不能将 0 放在最前面（前导零）。
- 负数是取绝对值后降序，再加负号，不是直接排负数。
