## 题目描述

给定一副牌，每张牌上都写着一个整数。

此时，你需要选定一个数字 `X`，使我们可以将整副牌按下述规则分成 1 组或更多组：

- 每组都有 `X` 张牌。
- 组内所有的牌上都写着相同的整数。

仅当你可选的 `X >= 2` 时返回 `true`。

**示例 1：**
```
输入：deck = [1,2,3,4,4,3,2,1]
输出：true
解释：可行的分组是 [1,1]，[2,2]，[3,3]，[4,4]
```

**示例 2：**
```
输入：deck = [1,1,1,2,2,2,3,3]
输出：false
解释：没有满足要求的分组。
```

**示例 3：**
```
输入：deck = [1]
输出：false
解释：X 必须 >= 2
```

**提示：**
- `1 <= deck.length <= 10^4`
- `0 <= deck[i] < 10^4`

## 解题思路

这道题的关键是理解题意：要找到一个 `X >= 2`，使得每种数字的数量都是 `X` 的倍数。

**数学角度：**
- 统计每种数字的出现次数
- 问题转化为：是否存在 `X >= 2`，使得所有计数都是 `X` 的倍数
- 这等价于：所有计数的 **最大公约数（GCD）** 是否 `>= 2`

**解题步骤：**
1. 使用哈希表统计每个数字的出现次数
2. 计算所有计数的最大公约数
3. 判断最大公约数是否大于等于 2

**为什么是最大公约数？**
- 如果所有计数的 GCD 是 g，那么每个计数都是 g 的倍数
- 任何 g 的约数也都满足条件
- 最大的满足条件的 X 就是 GCD

## Python 代码实现

### 方法一：GCD（推荐 ⭐）

```python
from typing import List
from collections import Counter
from math import gcd
from functools import reduce

class Solution:
    def hasGroupsSizeX(self, deck: List[int]) -> bool:
        # 统计每个数字的出现次数
        count = Counter(deck)
        
        # 计算所有计数的最大公约数
        # reduce(gcd, values) 对所有值求 GCD
        g = reduce(gcd, count.values())
        
        # 判断 GCD 是否 >= 2
        return g >= 2
```

### 方法二：逐步计算 GCD

```python
from typing import List
from collections import Counter
from math import gcd

class Solution:
    def hasGroupsSizeX(self, deck: List[int]) -> bool:
        # 统计每个数字的出现次数
        count = Counter(deck)
        
        # 获取所有计数值
        values = list(count.values())
        
        # 从第一个值开始，逐步计算 GCD
        result = values[0]
        for val in values[1:]:
            result = gcd(result, val)
            # 如果 GCD 已经是 1，可以提前退出
            if result == 1:
                return False
        
        return result >= 2
```

### 方法三：手写 GCD

```python
from typing import List
from collections import Counter

class Solution:
    def hasGroupsSizeX(self, deck: List[int]) -> bool:
        def gcd(a, b):
            """计算最大公约数（辗转相除法）"""
            while b:
                a, b = b, a % b
            return a
        
        # 统计每个数字的出现次数
        count = Counter(deck)
        
        # 计算所有计数的 GCD
        values = list(count.values())
        result = values[0]
        
        for val in values[1:]:
            result = gcd(result, val)
            if result == 1:
                return False
        
        return result >= 2
```

### 方法四：暴力枚举

```python
from typing import List
from collections import Counter

class Solution:
    def hasGroupsSizeX(self, deck: List[int]) -> bool:
        # 统计每个数字的出现次数
        count = Counter(deck)
        values = list(count.values())
        
        # X 的最大值是最小计数值
        min_count = min(values)
        
        # 枚举 X 从 2 到 min_count
        for x in range(2, min_count + 1):
            # 检查所有计数是否都是 x 的倍数
            if all(val % x == 0 for val in values):
                return True
        
        return False
```

## 复杂度分析

**方法一/二/三：GCD**
- 时间复杂度：O(n + k log C)
  - n 是数组长度，用于统计
  - k 是不同数字的数量
  - C 是最大计数值，log C 是 GCD 的时间复杂度
- 空间复杂度：O(k)，哈希表空间

**方法四：暴力枚举**
- 时间复杂度：O(n + C * k)
  - 枚举 X 需要 O(C)
  - 每次检查需要 O(k)
- 空间复杂度：O(k)

## 关键点总结

1. **问题转化**：将分组问题转化为最大公约数问题
2. **GCD 应用**：所有计数的 GCD 就是最大的可行分组大小
3. **Counter 使用**：统计元素频率
4. **reduce 函数**：对多个值求 GCD
5. **提前退出**：如果 GCD 为 1，可以提前返回

## 易错点

1. **理解题意**：要求所有数字的计数都是 X 的倍数，不是总数
2. **X 的范围**：X 必须 >= 2
3. **单个元素**：只有一个元素时无法分组，返回 false
4. **GCD 计算**：要计算所有计数的 GCD，不是任意两个
5. **空数组**：虽然题目保证 length >= 1，但要注意
