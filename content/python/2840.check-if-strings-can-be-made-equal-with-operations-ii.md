## 题目描述

给你两个**长度相等**的字符串 `s1` 和 `s2`。

一次操作可以选择 `s1` 中两个**奇偶性相同**的下标 `i` 和 `j`（|i-j| 为偶数），然后交换 `s1[i]` 和 `s1[j]`。

判断通过若干次操作后，`s1` 是否能变为 `s2`。

**示例 1：**
```
输入：s1 = "abcdba", s2 = "cabdab"
输出：true
```

**示例 2：**
```
输入：s1 = "abe", s2 = "bea"
输出：false
```

**提示：**
- `1 <= s1.length <= 10^5`
- `s1.length == s2.length`
- 字符串只包含小写字母

## 解题思路

与 2839 类似，只是字符串长度更大。

**关键观察：** 操作只能在奇偶性相同的下标间交换，即：
- 偶数位置（0, 2, 4, ...）之间的字符可以任意排列
- 奇数位置（1, 3, 5, ...）之间的字符可以任意排列

判断条件：
- `s1` 偶数位的字符集合 == `s2` 偶数位的字符集合
- `s1` 奇数位的字符集合 == `s2` 奇数位的字符集合

## Python 代码实现

### 方法一：Counter 比较（推荐）

```python
from collections import Counter

class Solution:
    def checkStrings(self, s1: str, s2: str) -> bool:
        # 提取偶数位和奇数位字符
        even1 = Counter(s1[i] for i in range(0, len(s1), 2))
        even2 = Counter(s2[i] for i in range(0, len(s2), 2))
        odd1 = Counter(s1[i] for i in range(1, len(s1), 2))
        odd2 = Counter(s2[i] for i in range(1, len(s2), 2))
        return even1 == even2 and odd1 == odd2
```

### 方法二：排序比较

```python
class Solution:
    def checkStrings(self, s1: str, s2: str) -> bool:
        # 偶数位和奇数位分别排序后比较
        return (sorted(s1[::2]) == sorted(s2[::2]) and
                sorted(s1[1::2]) == sorted(s2[1::2]))
```

### 方法三：切片写法

```python
class Solution:
    def checkStrings(self, s1: str, s2: str) -> bool:
        # s1[::2] 是下标 0,2,4,... 的字符（偶数位）
        # s1[1::2] 是下标 1,3,5,... 的字符（奇数位）
        even_ok = sorted(s1[::2]) == sorted(s2[::2])
        odd_ok = sorted(s1[1::2]) == sorted(s2[1::2])
        return even_ok and odd_ok
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序操作
- 空间复杂度：O(n)，中间字符列表

## 关键点总结

1. 偶数下标的字符只能在偶数下标间重排，奇数类似
2. 判断条件：偶数位字符多重集相同且奇数位字符多重集相同
3. Python 切片 `s[::2]` 取所有偶数位，`s[1::2]` 取所有奇数位

## 易错点

1. 和 2839 的区别在于字符串长度可变，策略完全一致但需要处理任意长度
2. 字符集合要用多重集（Counter 或 sorted），不能用 set（忽略重复）
3. 下标奇偶性是 0, 2, 4, ... 和 1, 3, 5, ...，与值的奇偶无关
