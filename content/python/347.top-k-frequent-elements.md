## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。你可以按任意顺序返回答案。

**示例 1：**
```
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

**示例 2：**
```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的

**进阶：** 你所设计算法的时间复杂度必须优于 O(n log n)，其中 n 是数组大小。

## 解题思路

这道题是经典的 TopK 问题，有多种解法。

**核心步骤：**
1. 统计每个元素的出现频率
2. 找出频率最高的 k 个元素

**多种解法：**
- 排序：统计频率后排序，取前 k 个，O(n log n)
- 堆：使用最小堆维护 k 个最高频元素，O(n log k)
- 桶排序：按频率分桶，从高到低取元素，O(n)
- 快速选择：类似快速排序的分区思想，平均 O(n)

**最优解：** 桶排序，时间复杂度 O(n)，满足进阶要求。

## Python 代码实现

### 方法一：哈希表 + 排序（最直观）

```python
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. 统计频率
        count = Counter(nums)
        
        # 2. 按频率排序
        # sorted() 返回 [(元素, 频率), ...] 的列表
        sorted_items = sorted(count.items(), key=lambda x: x[1], reverse=True)
        
        # 3. 取前 k 个元素
        return [item[0] for item in sorted_items[:k]]
```

**时间复杂度：** O(n log n)
**空间复杂度：** O(n)

### 方法二：最小堆（推荐）⭐

```python
from collections import Counter
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. 统计频率
        count = Counter(nums)
        
        # 2. 使用最小堆维护 k 个最高频元素
        # Python 的 heapq 是最小堆
        heap = []
        
        for num, freq in count.items():
            # 堆中存储 (频率, 元素)
            heapq.heappush(heap, (freq, num))
            
            # 保持堆的大小为 k
            if len(heap) > k:
                heapq.heappop(heap)  # 弹出频率最小的
        
        # 3. 返回堆中的所有元素
        return [num for freq, num in heap]
```

**时间复杂度：** O(n log k)
**空间复杂度：** O(n)

**优化版本：**
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)
        
        # 使用 nlargest 函数，内部使用堆实现
        # key 参数指定比较的依据
        return heapq.nlargest(k, count.keys(), key=count.get)
```

### 方法三：桶排序（最优解）⭐⭐

```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. 统计频率
        count = Counter(nums)
        
        # 2. 创建桶，索引表示频率
        # 频率最大为 n（所有元素相同）
        n = len(nums)
        buckets = [[] for _ in range(n + 1)]
        
        # 3. 将元素放入对应频率的桶中
        for num, freq in count.items():
            buckets[freq].append(num)
        
        # 4. 从高频到低频收集元素
        result = []
        for freq in range(n, 0, -1):
            if buckets[freq]:
                result.extend(buckets[freq])
                # 如果已经收集够 k 个，提前结束
                if len(result) >= k:
                    return result[:k]
        
        return result
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

### 方法四：快速选择（平均最优）

```python
import random

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)
        unique = list(count.keys())
        
        def partition(left, right, pivot_index):
            pivot_frequency = count[unique[pivot_index]]
            # 将 pivot 移到末尾
            unique[pivot_index], unique[right] = unique[right], unique[pivot_index]
            
            # 将所有频率小于 pivot 的元素移到左边
            store_index = left
            for i in range(left, right):
                if count[unique[i]] < pivot_frequency:
                    unique[store_index], unique[i] = unique[i], unique[store_index]
                    store_index += 1
            
            # 将 pivot 移到最终位置
            unique[right], unique[store_index] = unique[store_index], unique[right]
            return store_index
        
        def quickselect(left, right, k_smallest):
            """找到第 k_smallest 小的元素的索引"""
            if left == right:
                return
            
            # 随机选择 pivot
            pivot_index = random.randint(left, right)
            
            # 分区
            pivot_index = partition(left, right, pivot_index)
            
            # 如果 pivot 就是我们要找的位置
            if k_smallest == pivot_index:
                return
            elif k_smallest < pivot_index:
                quickselect(left, pivot_index - 1, k_smallest)
            else:
                quickselect(pivot_index + 1, right, k_smallest)
        
        n = len(unique)
        # 找第 n - k 小的元素，这样右边就是最大的 k 个
        quickselect(0, n - 1, n - k)
        
        return unique[n - k:]
```

**时间复杂度：** 平均 O(n)，最坏 O(n^2)
**空间复杂度：** O(n)

### 方法五：Python 特色（最简洁）

```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # Counter 的 most_common(k) 方法返回频率最高的 k 个元素
        return [num for num, freq in Counter(nums).most_common(k)]
```

**注意：** `most_common()` 内部使用堆实现，时间复杂度 O(n log k)。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 排序 | O(n log n) | O(n) | 简单直观 | 不满足进阶要求 |
| 最小堆 | O(n log k) | O(n) | 适合 k 很小 | k 大时慢 |
| 桶排序 | O(n) | O(n) | 最优解 | 需要额外空间 |
| 快速选择 | 平均 O(n) | O(n) | 平均最快 | 最坏 O(n^2) |
| most_common | O(n log k) | O(n) | 最简洁 | 同堆方法 |

## 图解示例

```
输入：nums = [1,1,1,2,2,3], k = 2

步骤1：统计频率
count = {1: 3, 2: 2, 3: 1}

方法：桶排序
创建桶（索引为频率）：
buckets[0] = []
buckets[1] = [3]     ← 频率为 1 的元素
buckets[2] = [2]     ← 频率为 2 的元素
buckets[3] = [1]     ← 频率为 3 的元素
buckets[4] = []
...

从高频到低频遍历：
freq=3: [1]      → result = [1]
freq=2: [2]      → result = [1, 2]
len(result) >= k，停止

返回 [1, 2]

方法：最小堆
遍历 count：
1. (3, 1) 入堆: heap = [(3, 1)]
2. (2, 2) 入堆: heap = [(2, 2), (3, 1)]
3. (1, 3) 入堆: heap = [(1, 3), (3, 1), (2, 2)]
   len > k，弹出 (1, 3): heap = [(2, 2), (3, 1)]

最终堆: [(2, 2), (3, 1)]
返回 [2, 1]
```

## 关键点总结

1. **Counter 使用**：统计频率的标准工具
2. **堆的应用**：维护 TopK 的经典数据结构
3. **桶排序思想**：将频率作为索引，O(n) 排序
4. **快速选择**：类似快排的分区思想
5. **空间换时间**：桶排序用额外空间换取 O(n) 时间

## 易错点

1. **堆的元素顺序**
   ```python
   # 错误：只存频率或只存元素
   heapq.heappush(heap, freq)
   
   # 正确：存储元组 (频率, 元素)
   heapq.heappush(heap, (freq, num))
   ```

2. **桶的大小**
   ```python
   # 错误：桶大小为 n
   buckets = [[] for _ in range(n)]
   
   # 正确：桶大小为 n+1（频率可以从 1 到 n）
   buckets = [[] for _ in range(n + 1)]
   ```

3. **most_common 的返回值**
   ```python
   # 错误：返回整个元组列表
   return Counter(nums).most_common(k)
   
   # 正确：只返回元素
   return [num for num, freq in Counter(nums).most_common(k)]
   ```

4. **堆的大小控制**
   ```python
   # 错误：先判断再入堆
   if len(heap) < k:
       heapq.heappush(heap, (freq, num))
   
   # 正确：先入堆再判断
   heapq.heappush(heap, (freq, num))
   if len(heap) > k:
       heapq.heappop(heap)
   ```

5. **快速选择的位置**
   ```python
   # 要找频率最高的 k 个
   # 等价于找第 (n-k) 小的元素
   # 右侧就是最大的 k 个
   quickselect(0, n - 1, n - k)
   return unique[n - k:]
   ```
