## 题目描述

给你一个字符串 `s`，每个字符为 `'E'`（进入等候室）或 `'L'`（离开等候室）。

返回等候室需要准备的 **最少** 椅子数。

**示例 1：**
```
输入：s = "EEEEEEE"
输出：7
```

**示例 2：**
```
输入：s = "ELELEEL"
输出：2
```

**提示：**
- `1 <= s.length <= 50`
- `s` 只包含 `'E'` 和 `'L'`

## 解题思路

模拟：维护当前在室内的人数 `cur`，遇到 `E` 加 1，遇到 `L` 减 1。记录 `cur` 的历史最大值即为答案。

## Python 代码实现

### 方法一：模拟（推荐）

```python
class Solution:
    def minimumChairs(self, s: str) -> int:
        cur = 0
        ans = 0
        for c in s:
            if c == 'E':
                cur += 1
                ans = max(ans, cur)
            else:
                cur -= 1
        return ans
```

### 方法二：使用 accumulate

```python
from itertools import accumulate

class Solution:
    def minimumChairs(self, s: str) -> int:
        deltas = [1 if c == 'E' else -1 for c in s]
        return max(accumulate(deltas))
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 模拟人数变化，记录最大值
2. 最少椅子数 = 同时在室内人数的最大值

## 易错点

1. `L` 操作是离开，人数减 1
2. 答案是历史最大人数，不是最终人数
