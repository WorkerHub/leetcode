## 题目描述

一张桌子上共有 `n` 个**有序**硬币堆。第 `i` 个堆的第 `j` 枚硬币值为 `piles[i][j]`，且每个堆从顶到底价值递减（即越深越贵，但只能从顶部取）。

每次操作可以从任意一个堆的顶部取一枚硬币。一共可以取 `k` 次，返回最多能取的硬币总价值。

**注意：** 只能从每个堆的顶部取，且每次只能取一枚。

**示例 1：**
```
输入：piles = [[1,100,3],[7,8,9]], k = 2
输出：101
解释：从第1堆取1（顶部），从第2堆取100（第2层），等等... 最优是取第1堆的1和100，总和101。
```

**示例 2：**
```
输入：piles = [[100],[100],[100],[100],[100],[100],[1,1,1,1,1,1,700]], k = 7
输出：706
```

## 解题思路

**分组背包动态规划。**

从每个堆中取 j 枚硬币（j = 0, 1, ..., min(k, len(piles[i]))），等价于在每个堆中选择从顶取多少枚。用前缀和 `prefix[i][j]` 表示第 `i` 堆取前 j 枚的总价值。

`dp[i][j]`：前 `i` 堆中取 `j` 枚的最大价值。

转移：
```
dp[i][j] = max(dp[i-1][j - t] + prefix[i][t])   对所有 t = 0, 1, ..., min(j, len(piles[i-1]))
```

## 代码实现

### 方法一：分组背包 DP（推荐）

```python
from typing import List
from itertools import accumulate

class Solution:
    def maxValueOfCoins(self, piles: List[List[int]], k: int) -> int:
        n = len(piles)
        # dp[j]：取 j 枚硬币的最大价值（滚动数组）
        dp = [0] * (k + 1)

        for pile in piles:
            # 计算当前堆的前缀和
            # prefix[t] = 从当前堆取前 t 枚的总价值
            prefix = [0] + list(accumulate(pile))
            max_take = min(len(pile), k)  # 最多取该堆的全部

            # 逆序更新（类似01背包）
            new_dp = [0] * (k + 1)
            for j in range(k + 1):
                for t in range(min(j, max_take) + 1):
                    new_dp[j] = max(new_dp[j], dp[j - t] + prefix[t])
            dp = new_dp

        return dp[k]
```

### 方法二：二维 DP（更清晰）

```python
from typing import List

class Solution:
    def maxValueOfCoins(self, piles: List[List[int]], k: int) -> int:
        n = len(piles)
        # 预计算每堆的前缀和
        prefixes = []
        for pile in piles:
            pre = [0]
            for v in pile:
                pre.append(pre[-1] + v)
            prefixes.append(pre)

        # dp[i][j]：前 i 堆取 j 枚的最大价值
        dp = [[0] * (k + 1) for _ in range(n + 1)]

        for i in range(1, n + 1):
            pre = prefixes[i - 1]
            max_take = len(piles[i - 1])
            for j in range(k + 1):
                dp[i][j] = dp[i - 1][j]  # 不从第 i 堆取
                for t in range(1, min(j, max_take) + 1):
                    dp[i][j] = max(dp[i][j], dp[i - 1][j - t] + pre[t])

        return dp[n][k]
```

## 复杂度分析

- 时间复杂度：O(k * sum_of_pile_sizes)，对每堆遍历 k 次，每次枚举取的数量。
- 空间复杂度：O(k)，滚动数组。

## 关键点总结

1. 分组背包：每个堆是一"组"，从每组中恰好选 0 到 min(k, pile_size) 件。
2. 前缀和预处理每堆取 t 枚的总价值，避免重复求和。
3. 使用滚动数组节省空间，但需注意更新顺序（此题用新数组 new_dp 代替逆序更新）。

## 易错点

- 每次必须用新的 `new_dp` 而非原地更新，否则同一层会互相影响。
- 枚举 t 的范围是 `0` 到 `min(j, len(pile))`，不能超过堆的大小。
