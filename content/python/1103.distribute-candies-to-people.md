## 题目描述

我们买了一些糖果 `candies`,打算把它们分给排成一排的 `n = num_people` 个小朋友。

给第一个小朋友 1 颗糖果,第二个小朋友 2 颗糖果,第三个小朋友 3 颗糖果,依此类推,直到给最后一个小朋友 `n` 颗糖果。

然后,我们再回到队伍的起点,给第一个小朋友 `n + 1` 颗糖果,第二个小朋友 `n + 2` 颗糖果,依此类推,直到给最后一个小朋友 `2 * n` 颗糖果。

重复上述过程(每次都比上一次多给出一颗糖果,当到达队伍终点后再次从队伍起点开始),直到我们分完所有的糖果。注意,就算最后剩下的糖果不够(不比前一次发出的糖果多),我们也会尽可能分给当前小朋友。

返回一个长度为 `num_people`、元素之和为 `candies` 的数组,以表示糖果的最终分发情况。

**示例 1:**
```
输入: candies = 7, num_people = 4
输出: [1,2,3,1]
解释:
第一次,ans[0] += 1,数组变为 [1,0,0,0]
第二次,ans[1] += 2,数组变为 [1,2,0,0]
第三次,ans[2] += 3,数组变为 [1,2,3,0]
第四次,ans[3] += 1(剩余糖果只有1颗),最终数组变为 [1,2,3,1]
```

**示例 2:**
```
输入: candies = 10, num_people = 3
输出: [5,2,3]
解释:
第一次,ans[0] += 1,数组变为 [1,0,0]
第二次,ans[1] += 2,数组变为 [1,2,0]
第三次,ans[2] += 3,数组变为 [1,2,3]
第四次,ans[0] += 4,最终数组变为 [5,2,3]
```

**提示:**
- `1 <= candies <= 10^9`
- `1 <= num_people <= 1000`

## 解题思路

这是一道模拟题,需要模拟分发糖果的过程。

**核心思想:**
1. 按顺序给每个人分发糖果,分发数量依次为 1, 2, 3, 4, ...
2. 到达队伍末尾后回到起点继续分发
3. 最后一次分发可能不足,需要将剩余糖果全部分给当前小朋友

**优化思路:**
- 方法一: 直接模拟,逐个分发
- 方法二: 数学公式优化,计算每个人在每一轮获得的糖果

## Python 代码实现

### 方法一: 直接模拟(推荐) ⭐

```python
from typing import List

class Solution:
    def distributeCandies(self, candies: int, num_people: int) -> List[int]:
        # 初始化结果数组
        result = [0] * num_people
        
        # 当前要分发的糖果数量,从1开始
        give = 1
        # 当前分发给的人的索引
        index = 0
        
        # 循环分发糖果
        while candies > 0:
            # 分发糖果,取剩余糖果和应该分发数量的较小值
            result[index] += min(candies, give)
            # 减少剩余糖果
            candies -= give
            # 下次要分发的数量加1
            give += 1
            # 移动到下一个人,循环回到起点
            index = (index + 1) % num_people
        
        return result
```

### 方法二: 数学优化(计算每轮)

```python
from typing import List

class Solution:
    def distributeCandies(self, candies: int, num_people: int) -> List[int]:
        result = [0] * num_people
        
        # 计算完整的轮数和剩余糖果
        # 第k次分发的糖果数是k,前n次总共分发 n*(n+1)/2
        # 解方程 n*(n+1)/2 <= candies,得到最多能分发多少次
        
        # 二分查找或直接计算完整分发次数
        total_gives = 0
        give = 1
        temp_candies = candies
        
        while temp_candies >= give:
            temp_candies -= give
            total_gives += 1
            give += 1
        
        # 计算完整轮数和余数
        complete_rounds = total_gives // num_people
        remaining_people = total_gives % num_people
        
        # 为每个人分配完整轮的糖果
        for i in range(num_people):
            # 第i个人在每轮获得: i+1, i+1+n, i+1+2n, ..., i+1+(complete_rounds-1)*n
            # 这是等差数列,首项 a1 = i+1, 公差 d = num_people, 项数 = complete_rounds
            # 求和公式: S = n * a1 + n*(n-1)*d/2
            if complete_rounds > 0:
                first_term = i + 1
                last_term = i + 1 + (complete_rounds - 1) * num_people
                result[i] = complete_rounds * (first_term + last_term) // 2
        
        # 处理最后一轮不完整的分发
        give = complete_rounds * num_people + 1
        for i in range(remaining_people):
            result[i] += give
            candies -= give
            give += 1
        
        # 处理最后剩余的糖果
        if candies > 0:
            result[remaining_people] += candies
        
        return result
```

### 方法三: 更简洁的模拟

```python
from typing import List

class Solution:
    def distributeCandies(self, candies: int, num_people: int) -> List[int]:
        result = [0] * num_people
        i = 0  # 当前分发次数(从0开始)
        
        while candies > 0:
            # 当前应该分发的糖果数是 i+1
            # 当前分发给的人的索引是 i % num_people
            result[i % num_people] += min(candies, i + 1)
            candies -= (i + 1)
            i += 1
        
        return result
```

## 复杂度分析

### 方法一和方法三(直接模拟):
- **时间复杂度**: O(√C),其中 C 是糖果总数。总共分发次数约为 √(2C),因为 1+2+...+n = n(n+1)/2 ≈ C
- **空间复杂度**: O(1),只使用常数额外空间(不计结果数组)

### 方法二(数学优化):
- **时间复杂度**: O(N),其中 N 是人数,需要为每个人计算等差数列和
- **空间复杂度**: O(1)

## 关键点总结

1. **模拟过程**: 按照题意逐步模拟分发过程
2. **循环索引**: 使用取模运算 `index % num_people` 实现循环分发
3. **边界处理**: 最后一次分发可能不足,使用 `min(candies, give)` 处理
4. **数学优化**: 可以通过等差数列求和公式优化计算
5. **分发次数**: 总分发次数约为 √(2 * candies)

## 易错点

1. **剩余糖果处理**: 最后剩余的糖果可能不够分发应有的数量,需要特殊处理
2. **索引循环**: 使用取模运算确保索引在 [0, num_people) 范围内
3. **糖果递减**: 每次分发后要减少对应数量的糖果
4. **循环条件**: while 条件是 `candies > 0`,而不是 `candies >= give`
