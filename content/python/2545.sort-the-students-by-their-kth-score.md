## 题目描述

给你一个 `m x n` 的整数矩阵 `score`，表示 `m` 个学生在 `n` 次考试中的成绩。另给你一个整数 `k`（0 <= k < n）。

将矩阵按第 `k` 列的成绩 **降序** 排序，并返回排序后的矩阵。

**示例 1：**

```
输入：score = [[10,6,9,1],[7,5,11,2],[4,8,3,15]], k = 2
输出：[[7,5,11,2],[10,6,9,1],[4,8,3,15]]
解释：按第 2 列（11, 9, 3）降序排序。
```

**提示：**

- `m == score.length`
- `n == score[i].length`
- `1 <= m, n <= 250`
- `1 <= score[i][j] <= 10^5`
- `score` 由 **不同** 的整数组成
- `0 <= k < n`

## 解题思路

直接按每行第 k 个元素的值降序排序整个矩阵。Python 的 `sorted` 函数支持自定义 key，非常简洁。

## Python 代码实现

### 方法一：内置排序（推荐）

```python
from typing import List

class Solution:
    def sortTheStudents(self, score: List[List[int]], k: int) -> List[List[int]]:
        # 按第 k 列降序排序
        return sorted(score, key=lambda row: -row[k])
```

### 方法二：原地排序

```python
from typing import List

class Solution:
    def sortTheStudents(self, score: List[List[int]], k: int) -> List[List[int]]:
        # 原地排序，reverse=True 表示降序
        score.sort(key=lambda row: row[k], reverse=True)
        return score
```

## 复杂度分析

- 时间复杂度：O(m log m)，排序 m 行
- 空间复杂度：O(m)，排序需要 O(m) 额外空间（Python timsort）

## 关键点总结

1. 按特定列排序整行（整行作为排序单元）
2. 降序：key 取负值或使用 `reverse=True`
3. 矩阵中无重复元素，排序结果唯一

## 易错点

1. 排序是按第 k 列降序，不是升序
2. 整行一起移动，不能只移动某列
3. k 从 0 开始索引
