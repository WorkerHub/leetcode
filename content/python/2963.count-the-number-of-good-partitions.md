## 题目描述

给你一个整数数组 `nums`，将数组分成若干个**子数组**（连续元素组成），满足：
- 每个值在 `nums` 中的**所有出现位置**都在同一个子数组中

此类分法称为 **好分法**。

返回好分法的数目，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：8
解释：每个元素只出现一次，任意分法都是好分法，共 2^3 = 8 种（3 个分割点）
```

**示例 2：**
```
输入：nums = [1,2,1,3]
输出：2
解释：1 出现在位置 0 和 2，必须在同一子数组中
```

**提示：**
- `1 <= nums.length <= 10^6`
- `1 <= nums[i] <= 10^9`

## 解题思路

每个值必须出现在同一个子数组中。换句话说，某个值的最后一次出现位置决定了它所在子数组的最右边界。

从左到右扫描，维护当前子数组必须延伸到的最右位置 `max_end`：
- 对每个 nums[i]，其最后一次出现位置为 `last[nums[i]]`，需要 `max_end = max(max_end, last[nums[i]])`
- 若 `i == max_end`：当前位置是一个合法的分割点（当前子数组可以在此结束），分割点数 +1

答案 = 2^(分割点数 - 1)（每个分割点可选分或不分，但最后一个分割点固定为数组末尾）。

## Python 代码实现

### 方法一：贪心统计分割点（推荐）

```python
from typing import List

class Solution:
    def numberOfGoodPartitions(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        # 预处理每个值的最后出现位置
        last = {}
        for i, x in enumerate(nums):
            last[x] = i

        n = len(nums)
        max_end = 0  # 当前子数组必须延伸到的最右位置
        partition_points = 0  # 合法分割点数（包括末尾）

        for i in range(n):
            max_end = max(max_end, last[nums[i]])
            if i == max_end:
                partition_points += 1

        # 分割点数为 k，则有 k-1 个内部分割点，答案为 2^(k-1)
        return pow(2, partition_points - 1, MOD)
```

### 方法二：区间合并

```python
from typing import List

class Solution:
    def numberOfGoodPartitions(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        first = {}
        last = {}
        for i, x in enumerate(nums):
            if x not in first:
                first[x] = i
            last[x] = i

        # 每个值对应一个区间 [first[x], last[x]]
        # 必须在同一子数组中 => 区间合并
        intervals = sorted({(first[x], last[x]) for x in first})

        # 合并区间，统计合并后的区间数（即子数组的最少分法，每个合并区间是一个强制块）
        merged = []
        for a, b in intervals:
            if merged and a <= merged[-1][1]:
                merged[-1] = (merged[-1][0], max(merged[-1][1], b))
            else:
                merged.append([a, b])

        # 合并后有 k 个区间，k-1 个间隙，每个间隙可以选择分或不分
        k = len(merged)
        return pow(2, k - 1, MOD)
```

## 复杂度分析

- 时间复杂度：O(n)，方法一；O(n log n)，方法二（排序）
- 空间复杂度：O(n)

## 关键点总结

1. 每个值的所有出现位置必须在同一子数组中，等价于合并各值的 [first, last] 区间
2. 合并后每个区间是一个"强制块"，块与块之间的分割点可以任意选择
3. k 个强制块之间有 k-1 个可选分割点，方案数 = 2^(k-1)

## 易错点

1. 同一个值多次出现时，区间是 [first_occurrence, last_occurrence]
2. 区间合并时需要处理嵌套情况（一个区间完全包含另一个）
3. 结果 2^(k-1) 对 MOD 取余，k 可能很大
