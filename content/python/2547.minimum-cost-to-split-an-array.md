## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。将数组分割为若干子数组，子数组的 **代价** = `k + trim(subarray)` 的长度。

`trim(subarray)` 是删去子数组中所有出现恰好一次的元素后的子数组。

总代价是所有子数组代价之和。返回分割 `nums` 的 **最小总代价**。

**示例 1：**

```
输入：nums = [1,2,1,2,1,3,3], k = 2
输出：8
解释：分割为 [1,2,1,2,1] 和 [3,3]，代价分别为 2+5=7 和 2+2=4，总代价... 实际最优为 8。
```

**提示：**

- `1 <= n <= 1000`
- `0 <= nums[i] <= n`
- `1 <= k <= 10^9`

## 解题思路

**动态规划**：`dp[i]` = 分割 `nums[0..i-1]` 的最小代价。

`dp[i] = min(dp[j] + k + importance(nums[j..i-1]))` for j from 0 to i-1，其中 `importance(arr)` = arr 长度 - 只出现一次的元素个数 = 出现 >= 2 次的元素所占位置数（包括重复计数）。

预计算每个子数组的 importance 可用滑动窗口 + 哈希表。

## Python 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minCost(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # dp[i] = 分割 nums[0..i-1] 的最小代价
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            # 枚举子数组 nums[j..i-1]
            freq = defaultdict(int)
            importance = 0  # 当前子数组的 importance

            for j in range(i - 1, -1, -1):
                freq[nums[j]] += 1
                if freq[nums[j]] == 2:
                    # 该元素从出现一次变为出现两次，importance 增加 2
                    importance += 2
                elif freq[nums[j]] > 2:
                    # 该元素新增一次出现，importance 增加 1
                    importance += 1
                # 子数组 nums[j..i-1] 的代价
                if dp[j] != INF:
                    dp[i] = min(dp[i], dp[j] + k + importance)

        return dp[n]
```

### 方法二：预计算所有子数组的 importance

```python
from typing import List
from collections import Counter

class Solution:
    def minCost(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # imp[i][j] = importance(nums[i..j])
        imp = [[0] * n for _ in range(n)]
        for i in range(n):
            cnt = Counter()
            for j in range(i, n):
                cnt[nums[j]] += 1
                if cnt[nums[j]] >= 2:
                    # 重复出现，贡献 1（首次重复贡献 2，后续各 1）
                    imp[i][j] = imp[i][j-1] + (1 if cnt[nums[j]] > 2 else 2) if j > i else (0 if cnt[nums[j]] == 1 else 2)

        # 动态规划
        dp = [float('inf')] * (n + 1)
        dp[0] = 0
        for i in range(1, n + 1):
            freq = defaultdict(int)
            importance = 0
            for j in range(i - 1, -1, -1):
                freq[nums[j]] += 1
                if freq[nums[j]] == 2:
                    importance += 2
                elif freq[nums[j]] > 2:
                    importance += 1
                dp[i] = min(dp[i], dp[j] + k + importance)

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n²)，枚举所有子数组起点
- 空间复杂度：O(n)，DP 数组和哈希表

## 关键点总结

1. importance(arr) = arr 中出现 >= 2 次的元素计入（包括重复次数）
2. 维护当前子数组的 importance：某元素第 2 次出现 +2，第 3+ 次 +1
3. DP 转移：枚举每个子数组的起点，取最小代价

## 易错点

1. importance 的计算：出现恰好一次的不计，出现两次的贡献 2，出现三次的贡献 3，以此类推
2. 从 i-1 向 0 扩展子数组起点（从右到左），动态维护 importance 更高效
3. dp[0] = 0 表示空前缀代价为 0
