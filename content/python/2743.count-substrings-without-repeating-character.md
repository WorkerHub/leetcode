## 题目描述

给你一个字符串 `s`，统计 `s` 中 **没有重复字符** 的非空子字符串的数目。

**示例 1：**
```
输入：s = "abcabc"
输出：10
解释：不含重复字符的子串："a","b","c","ab","bc","abc","ca","cb","abc","...
```

**示例 2：**
```
输入：s = "aaaa"
输出：4
解释：只有长度为 1 的子串 "a" x4
```

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

**滑动窗口**：维护无重复字符的窗口 `[left, right]`。右端每移动一步，以 `right` 结尾的无重复子串数量等于窗口长度 `right - left + 1`。

当 `s[right]` 在窗口内已存在时，移动左端直到无重复。

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
class Solution:
    def numberOfSpecialSubstrings(self, s: str) -> int:
        last_pos = {}  # 记录每个字符最近出现的位置
        left = 0
        ans = 0

        for right, ch in enumerate(s):
            # 若 ch 在窗口内，移动 left 到其上次出现位置+1
            if ch in last_pos and last_pos[ch] >= left:
                left = last_pos[ch] + 1
            last_pos[ch] = right
            # 以 right 结尾的无重复子串数量
            ans += right - left + 1

        return ans
```

### 方法二：滑动窗口 + Counter

```python
from collections import defaultdict

class Solution:
    def numberOfSpecialSubstrings(self, s: str) -> int:
        count = defaultdict(int)
        left = 0
        ans = 0

        for right, ch in enumerate(s):
            count[ch] += 1
            while count[ch] > 1:
                count[s[left]] -= 1
                left += 1
            ans += right - left + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集大小固定 26）

## 关键点总结

1. 每个 right 位置，以 right 结尾的合法子串数等于窗口长度
2. 方法一记录上次位置，O(1) 移动左端；方法二使用计数器

## 易错点

1. 方法一中需要检查 `last_pos[ch] >= left`，确保上次出现在当前窗口内
