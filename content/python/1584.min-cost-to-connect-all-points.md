## 题目描述

给你一个 `points` 数组，表示二维平面上的一些点，`points[i] = [xi, yi]`。

连接点 `(xi, yi)` 和点 `(xj, yj)` 的费用为它们之间的**曼哈顿距离**：`|xi - xj| + |yi - yj|`。

返回将所有点连接的最小费用（即最小生成树的权值总和）。

**示例 1：**
```
输入：points = [[0,0],[2,2],[3,10],[5,2],[7,0]]
输出：20
```

## 解题思路

### 最小生成树（Kruskal 或 Prim）

**Kruskal 算法：** 枚举所有边，按权值排序，用并查集贪心地选取不形成环的边。

**Prim 算法：** 从一个点出发，每次选择代价最小的边连接未访问节点，使用堆优化。

由于 n <= 1000，边数 O(N^2)，两种方法都可行。

## 代码实现

### 方法一：Kruskal + 并查集（推荐）

```python
from typing import List

class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        # 枚举所有边
        edges = []
        for i in range(n):
            for j in range(i + 1, n):
                dist = abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1])
                edges.append((dist, i, j))
        edges.sort()

        # 并查集
        parent = list(range(n))
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        total = 0
        edge_count = 0
        for dist, i, j in edges:
            pi, pj = find(i), find(j)
            if pi != pj:
                parent[pi] = pj
                total += dist
                edge_count += 1
                if edge_count == n - 1:
                    break

        return total
```

### 方法二：Prim 算法（堆优化）

```python
import heapq
from typing import List

class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        visited = [False] * n
        # 最小堆：(权值, 节点)
        heap = [(0, 0)]
        total = 0
        count = 0

        while count < n:
            cost, u = heapq.heappop(heap)
            if visited[u]:
                continue
            visited[u] = True
            total += cost
            count += 1
            for v in range(n):
                if not visited[v]:
                    dist = abs(points[u][0] - points[v][0]) + abs(points[u][1] - points[v][1])
                    heapq.heappush(heap, (dist, v))

        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Kruskal | O(N^2 log N) | O(N^2) |
| Prim（堆） | O(N^2 log N) | O(N) |

## 关键点总结

1. 完全图（任意两点之间都有边），MST 标准算法
2. Kruskal：排序所有边，贪心用并查集
3. Prim：从一个点出发，逐步扩展，用堆取最小边

## 易错点

- 曼哈顿距离 = `|xi - xj| + |yi - yj|`（不是欧几里得距离）
- 连接 n 个点需要 n-1 条边
