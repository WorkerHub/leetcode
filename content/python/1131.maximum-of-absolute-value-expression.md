## 题目描述

给你两个长度相等的整数数组 `arr1` 和 `arr2`，返回以下表达式的最大值：

`|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|`

其中下标 `i`，`j` 满足 `0 <= i, j < arr1.length`。

**示例 1：**
```
输入：arr1 = [1,2,3,4], arr2 = [-1,4,5,6]
输出：13
解释：选择 i = 1 和 j = 3，得到 |2 - 4| + |4 - 6| + |1 - 3| = 2 + 2 + 2 = 6。
实际上最大值是 i = 0, j = 3：|1 - 4| + |-1 - 6| + |0 - 3| = 3 + 7 + 3 = 13
```

**示例 2：**
```
输入：arr1 = [1,-2,-5,0,10], arr2 = [0,-2,-1,-7,-4]
输出：20
解释：选择 i = 0 和 j = 4，得到 |1 - 10| + |0 - (-4)| + |0 - 4| = 9 + 4 + 4 = 17。
实际上最大值是 i = 1, j = 4：|-2 - 10| + |-2 - (-4)| + |1 - 4| = 12 + 2 + 3 = 17。
等等，让我重新计算...
实际上选择 i = 0, j = 4：|1 - 10| + |0 - (-4)| + |0 - 4| = 9 + 4 + 4 = 17
或者 i = 1, j = 4：|-2 - 10| + |-2 - (-4)| + |1 - 4| = 12 + 2 + 3 = 17
...最大值应该是 20
```

**提示：**
- `2 <= arr1.length == arr2.length <= 40000`
- `-10^6 <= arr1[i], arr2[i] <= 10^6`

## 解题思路

直接暴力求解需要 O(n²) 时间，会超时。关键是**去掉绝对值符号**。

### 绝对值展开

对于三个绝对值 `|a| + |b| + |c|`，每个都可以是正或负，共有 2³ = 8 种组合：

设：
- `p1 = arr1[i] - arr1[j]`
- `p2 = arr2[i] - arr2[j]`
- `p3 = i - j`

由于 `i, j` 的对称性，假设 `i < j`（或者说我们遍历所有 i, j 对），则 `p3 = i - j < 0`。

但实际上，我们可以不假设 i 和 j 的顺序，而是展开所有情况：

`|p1| + |p2| + |p3|` 可以展开为 8 种情况：
1. `p1 + p2 + p3`
2. `p1 + p2 - p3`
3. `p1 - p2 + p3`
4. `p1 - p2 - p3`
5. `-p1 + p2 + p3`
6. `-p1 + p2 - p3`
7. `-p1 - p2 + p3`
8. `-p1 - p2 - p3`

将 `p1, p2, p3` 代入：

例如情况 1：
```
(arr1[i] - arr1[j]) + (arr2[i] - arr2[j]) + (i - j)
= (arr1[i] + arr2[i] + i) - (arr1[j] + arr2[j] + j)
```

设 `f1[i] = arr1[i] + arr2[i] + i`，则情况 1 = `f1[i] - f1[j]`

最大值 = `max(f1) - min(f1)`

同理，8 种情况对应 8 个不同的函数，每个函数形如 `±arr1[i] ± arr2[i] ± i`。

### 简化分析

实际上，由于对称性，我们只需要考虑 4 种情况：
1. `(arr1[i] + arr2[i] + i) - (arr1[j] + arr2[j] + j)`
2. `(arr1[i] + arr2[i] - i) - (arr1[j] + arr2[j] - j)`
3. `(arr1[i] - arr2[i] + i) - (arr1[j] - arr2[j] + j)`
4. `(arr1[i] - arr2[i] - i) - (arr1[j] - arr2[j] - j)`

对于每种情况，最大值 = 该函数的最大值 - 最小值。

## Python 代码实现

### 方法一：数学展开（推荐）

```python
from typing import List

class Solution:
    def maxAbsValExpr(self, arr1: List[int], arr2: List[int]) -> int:
        n = len(arr1)
        
        # 四种情况的系数：(arr1系数, arr2系数, i系数)
        cases = [
            (1, 1, 1),    # arr1[i] + arr2[i] + i
            (1, 1, -1),   # arr1[i] + arr2[i] - i
            (1, -1, 1),   # arr1[i] - arr2[i] + i
            (1, -1, -1),  # arr1[i] - arr2[i] - i
        ]
        
        max_result = 0
        
        for c1, c2, c3 in cases:
            # 计算当前情况下每个位置的函数值
            values = [c1 * arr1[i] + c2 * arr2[i] + c3 * i for i in range(n)]
            
            # 最大值 - 最小值
            max_result = max(max_result, max(values) - min(values))
        
        return max_result
```

### 方法二：一次遍历优化

```python
from typing import List

class Solution:
    def maxAbsValExpr(self, arr1: List[int], arr2: List[int]) -> int:
        n = len(arr1)
        
        # 四种情况，分别记录最大值和最小值
        max_vals = [float('-inf')] * 4
        min_vals = [float('inf')] * 4
        
        for i in range(n):
            # 四种组合
            expressions = [
                arr1[i] + arr2[i] + i,
                arr1[i] + arr2[i] - i,
                arr1[i] - arr2[i] + i,
                arr1[i] - arr2[i] - i
            ]
            
            for j in range(4):
                max_vals[j] = max(max_vals[j], expressions[j])
                min_vals[j] = min(min_vals[j], expressions[j])
        
        # 计算四种情况的最大差值
        result = 0
        for j in range(4):
            result = max(result, max_vals[j] - min_vals[j])
        
        return result
```

### 方法三：更简洁的写法

```python
from typing import List

class Solution:
    def maxAbsValExpr(self, arr1: List[int], arr2: List[int]) -> int:
        n = len(arr1)
        result = 0
        
        # 枚举四种符号组合
        for s1 in [1, -1]:
            for s2 in [1, -1]:
                max_val = float('-inf')
                min_val = float('inf')
                
                for i in range(n):
                    val = s1 * arr1[i] + s2 * arr2[i] + i
                    max_val = max(max_val, val)
                    min_val = min(min_val, val)
                
                result = max(result, max_val - min_val)
        
        return result
```

### 方法四：暴力解法（会超时，仅用于理解）

```python
from typing import List

class Solution:
    def maxAbsValExpr(self, arr1: List[int], arr2: List[int]) -> int:
        n = len(arr1)
        max_result = 0
        
        for i in range(n):
            for j in range(n):
                if i != j:
                    val = abs(arr1[i] - arr1[j]) + abs(arr2[i] - arr2[j]) + abs(i - j)
                    max_result = max(max_result, val)
        
        return max_result
```

## 复杂度分析

### 方法一、二、三

- **时间复杂度**：O(n)，遍历 4 次数组
- **空间复杂度**：O(1)，只用常数个变量（方法一用了 O(n) 的临时数组，可优化）

### 方法四（暴力）

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **绝对值展开**：`|a - b|` 可以是 `a - b` 或 `b - a`
2. **组合枚举**：三个绝对值有 8 种组合，但由于对称性只需考虑 4 种
3. **差值最大化**：对于表达式 `f(i) - f(j)`，最大值 = `max(f) - min(f)`
4. **曼哈顿距离**：本质上是三维空间中的曼哈顿距离问题
5. **优化思路**：从 O(n²) 暴力优化到 O(n) 的数学方法

## 数学推导

原式：
```
|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|
```

设 `x = arr1[i] - arr1[j]`, `y = arr2[i] - arr2[j]`, `z = i - j`

则 `|x| + |y| + |z|` 在不同符号组合下：

| x符号 | y符号 | z符号 | 展开式 |
|-------|-------|-------|--------|
| +     | +     | +     | (a1[i] + a2[i] + i) - (a1[j] + a2[j] + j) |
| +     | +     | -     | (a1[i] + a2[i] - i) - (a1[j] + a2[j] - j) |
| +     | -     | +     | (a1[i] - a2[i] + i) - (a1[j] - a2[j] + j) |
| +     | -     | -     | (a1[i] - a2[i] - i) - (a1[j] - a2[j] - j) |

注：由于 i, j 可以互换，负号组合等价于正号组合，所以只需 4 种。

## 易错点

1. **组合数量**：不是 8 种而是 4 种（理解对称性）
2. **索引处理**：`i` 的系数有时是 `+i` 有时是 `-i`，不要遗漏
3. **初始值设置**：最大值初始化为 `-inf`，最小值初始化为 `+inf`
4. **理解本质**：这不是简单的数学题，而是三维曼哈顿距离的最大值
