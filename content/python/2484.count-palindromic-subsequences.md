## 题目描述

给你一个数字字符串 `s`，返回 `s` 中长度为 `5` 的 **回文子序列** 数目，结果对 `10^9 + 7` 取模。

回文子序列：第 1 位 = 第 5 位，第 2 位 = 第 4 位，第 3 位可以任意。

**提示：**
- `1 <= s.length <= 10^4`
- `s` 只包含数字字符

## 解题思路

**枚举中间字符 + 前后缀统计：**

长度为 5 的回文子序列形如 `a b c b a`，其中：
- 第 1 位 = 第 5 位 = `a`
- 第 2 位 = 第 4 位 = `b`
- 第 3 位 = `c`（任意）

枚举第 2 位和第 4 位的位置 `(i, j)`（即 b 的位置），设 `s[i] = s[j] = b`：
- 在 `[0, i-1]` 中统计每个数字 a 出现次数（作为外层字符）
- 在 `[i+1, j-1]` 中统计每个数字 b 配对的 c 有多少个（即中间字符数 = j - i - 1）
- 在 `[j+1, n-1]` 中统计每个数字 a 出现次数

实际上，我们枚举 b 的两个位置 `(i, j)`：
`dp[i][j]` 中间子串长度 * 左侧 a 的个数 * 右侧 a 的个数（a 和 b 不需要相同）

**更高效思路：** 枚举中间三元组的中间位置 k，以及 b 字符 digit1 和外层 a 字符 digit2：
- `left2[k][d]`：位置 k 左侧距离 >= 2 的 d 的个数（可作为外层字符）
- `right2[k][d]`：位置 k 右侧距离 >= 2 的 d 的个数

实际上最简洁：枚举内层字符对 (i, j)（`s[i] = s[j]`），贡献为：
- 左侧每种字符的个数 × 右侧每种字符的个数 × (j-i-1) 中间字符数

## 代码实现

### 方法一：枚举内层字符对（推荐）

```python
class Solution:
    def countPalindromes(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)

        # 预处理：left[i][d] = s[0..i-1] 中数字 d 出现的次数
        # 预处理：right[i][d] = s[i+1..n-1] 中数字 d 出现的次数
        left = [[0] * 10 for _ in range(n)]
        right = [[0] * 10 for _ in range(n)]

        # 构建 left
        for i in range(1, n):
            for d in range(10):
                left[i][d] = left[i - 1][d]
            left[i][int(s[i - 1])] += 1

        # 构建 right
        for i in range(n - 2, -1, -1):
            for d in range(10):
                right[i][d] = right[i + 1][d]
            right[i][int(s[i + 1])] += 1

        ans = 0
        # 枚举内层字符对的位置 (i, j)，s[i] = s[j] = b
        for i in range(1, n - 3):
            for j in range(i + 2, n - 1):
                if s[i] == s[j]:
                    # 中间字符数（第 3 位）= j - i - 1
                    mid = j - i - 1
                    # 外层字符 a 的选择数 = left[i] 中所有字符总数 * right[j] 中所有字符总数
                    # 但 a 也需要配对，枚举 a 的值
                    for d in range(10):
                        ans = (ans + left[i][d] * right[j][d] * mid) % MOD

        return ans
```

### 方法二：枚举中间字符 + 前后缀二元对

```python
class Solution:
    def countPalindromes(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)

        # pre2[i][a][b] = s[0..i-1] 中以 (a, b) 结尾的长度为 2 的子序列数
        # suf2[i][a][b] = s[i+1..n-1] 中以 (a, b) 开头的长度为 2 的子序列数
        # 枚举中间位置 k

        pre2 = [[[0] * 10 for _ in range(10)] for _ in range(n)]
        pre1 = [[0] * 10 for _ in range(n)]

        for i in range(n):
            if i > 0:
                for a in range(10):
                    for b in range(10):
                        pre2[i][a][b] = pre2[i - 1][a][b]
                for a in range(10):
                    pre1[i][a] = pre1[i - 1][a]
                # 以 s[i] 结尾的二元组：前面任意 a，加上 s[i]
                d = int(s[i - 1]) if i > 0 else -1
                if i > 0:
                    for a in range(10):
                        pre2[i][a][int(s[i - 1])] += pre1[i - 1][a]
                    pre1[i][int(s[i - 1])] += 1

        # 简化处理：直接枚举
        # 对于中间位置 k (2 <= k <= n-3)
        # 贡献 = sum over (a,b): pre2_count(a,b,0..k-1) * suf2_count(b,a,k+1..n-1)

        # 使用更直接的 O(n * 100) 方法
        ans = 0
        # 预计算每个位置左侧的 (a,b) 对数量和右侧的 (a,b) 对数量
        L2 = [[0] * 100 for _ in range(n)]  # L2[i][a*10+b] = 左侧 ab 对数
        R2 = [[0] * 100 for _ in range(n)]

        cnt1 = [0] * 10
        for i in range(n):
            # L2[i] 代表 s[0..i-1] 中 (a,b) 对数
            if i > 0:
                for x in range(100):
                    L2[i][x] = L2[i - 1][x]
                b = int(s[i - 1])
                for a in range(10):
                    L2[i][a * 10 + b] += cnt1[a]
                cnt1[int(s[i - 1])] += 1

        cnt1 = [0] * 10
        for i in range(n - 1, -1, -1):
            if i < n - 1:
                for x in range(100):
                    R2[i][x] = R2[i + 1][x]
                a = int(s[i + 1])
                for b in range(10):
                    R2[i][a * 10 + b] += cnt1[b]
                cnt1[int(s[i + 1])] += 1

        for k in range(2, n - 2):
            for a in range(10):
                for b in range(10):
                    ans = (ans + L2[k][a * 10 + b] * R2[k][b * 10 + a]) % MOD

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举内层对 | O(n^2 * 10) | O(n * 10) |
| 前后缀二元对 | O(n * 100) | O(n * 100) |

## 关键点总结

1. 长度 5 的回文形如 `abcba`，枚举内层 `(i, j)` 满足 `s[i] == s[j]`
2. 外层字符 a 从左侧 `s[0..i-1]` 和右侧 `s[j+1..n-1]` 中各取一个相同值
3. 中间字符任意，个数 = `j - i - 1`

## 易错点

- 枚举 (i, j) 时保证 `i >= 1, j <= n-2`（给外层字符留位置）
- 记得对每个数字 d 分别统计，不能笼统地用总数量
