## 题目描述

给你一个整数数组 `nums`。

选择任意两个下标 `i < j`，计算 `nums[i] + nums[j] + gcd(nums[i], nums[j])` 的最大值。

**示例 1：**
```
输入：nums = [3,4,9,12,6]
输出：30
解释：选 i=2 (9), j=3 (12)：9+12+gcd(9,12)=9+12+3=24
选 i=1 (4), j=4 (6)：4+6+gcd(4,6)=4+6+2=12
选 i=3 (12), j=4 (6)：12+6+gcd(12,6)=12+6+6=24
选 i=0 (3), j=4 (6)：3+6+gcd(3,6)=3+6+3=12
最大：i=2,j=3 -> 24? 还是有更大的？
nums[2]+nums[3]+gcd=9+12+3=24
```

**提示：**
- `2 <= nums.length <= 10^3`
- `1 <= nums[i] <= 10^6`

## 解题思路

暴力枚举所有对 (i, j)，计算 `nums[i] + nums[j] + gcd(nums[i], nums[j])`，维护最大值。

n <= 1000，O(n^2 log(max)) 完全可行。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def maxGcdSum(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                val = nums[i] + nums[j] + gcd(nums[i], nums[j])
                ans = max(ans, val)
        return ans
```

### 方法二：排序优化（部分剪枝）

```python
from typing import List
from math import gcd

class Solution:
    def maxGcdSum(self, nums: List[int]) -> int:
        # 排序后，较大的数对往往和更大
        # 但 gcd 的贡献可能让小数对更优，所以不能只看最大两个
        nums.sort(reverse=True)
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                val = nums[i] + nums[j] + gcd(nums[i], nums[j])
                ans = max(ans, val)
                # 可提前退出：若 nums[i]+nums[j] < ans - max_possible_gcd，剪枝
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max))，n^2 对数，每对 gcd 计算 O(log(max))
- 空间复杂度：O(1)

## 关键点总结

1. gcd(a, b) <= min(a, b)，最大 gcd = min，当 a 是 b 的倍数时取到
2. 暴力枚举在 n <= 1000 时完全够用
3. 最优对通常是两个较大且有较大公约数的数

## 易错点

1. gcd 的贡献不可忽视，简单选最大两个不一定正确
2. i < j 的约束（避免重复，但由于对称性，只遍历 j > i 即可）
