## 题目描述

给你一个字符串 `s`，你可以在每次操作中将字符串中的任意一个字符替换为另一个字符。

返回使字符串变为回文串所需的最少替换次数。

**示例 1：**

```
输入：s = "abcd"
输出：2
解释：将 'a' 替换为 'd'（或 'd' 替换为 'a'），再将 'b' 替换为 'c'，得到 "dccd"（回文）。
或将 "abcd" 变为 "abba" 需要 2 次替换。
```

**示例 2：**

```
输入：s = "abcba"
输出：0
解释：已经是回文串。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

双指针，对称位置比较：
1. 用左右双指针 `l = 0`，`r = n - 1`。
2. 若 `s[l] != s[r]`，需要一次替换（将其中一个改为另一个）。
3. 每次替换使两端对称，移动双指针向中间。
4. 操作数 = 不匹配的对数。

## Python 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def minOperations(self, s: str) -> int:
        n = len(s)
        ops = 0
        l, r = 0, n - 1

        while l < r:
            if s[l] != s[r]:
                ops += 1  # 替换其中一个，使两者相同
            l += 1
            r -= 1

        return ops
```

### 方法二：与逆序比较

```python
class Solution:
    def minOperations(self, s: str) -> int:
        # 统计不匹配的字符对数（每对只计一次）
        n = len(s)
        ops = 0
        for i in range(n // 2):
            if s[i] != s[n - 1 - i]:
                ops += 1
        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(1)

## 关键点总结

1. 回文串要求 `s[i] == s[n-1-i]`，每对不匹配需要恰好 1 次替换。
2. 不需要知道替换成什么字符，只统计不匹配对数即可。
3. 奇数长度字符串的中间字符无需替换。

## 易错点

1. 每对对称位置只需 1 次替换（改一个即可，不需要改两个）。
2. 不要将替换看成"两个都要改"。
