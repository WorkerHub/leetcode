## 题目描述

给你两个整数数组 `capacity` 和 `rocks`，`capacity[i]` 是第 `i` 个袋子的最大容量，`rocks[i]` 是当前袋子中的石块数。同时给你一个整数 `additionalRocks`，表示可以向袋子中额外添加的石块总数。

在最优情况下，返回**装满**的袋子的**最多数量**。

**示例 1：**
```
输入：capacity = [2,3,4,5], rocks = [1,2,4,4], additionalRocks = 2
输出：3
解释：袋子0差1，袋子1差1，袋子2已满，袋子3差1。添加1+1=2，装满3、0、1。
```

**示例 2：**
```
输入：capacity = [10,2,2], rocks = [2,2,0], additionalRocks = 100
输出：3
```

## 解题思路

**贪心：** 优先装满"最容易装满"的袋子（即缺少石块最少的袋子）。

计算每个袋子还需要多少石块 `gap[i] = capacity[i] - rocks[i]`，排序后贪心地用 `additionalRocks` 从 `gap` 最小的袋子开始填满。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def maximumBags(self, capacity: List[int], rocks: List[int], additionalRocks: int) -> int:
        # 计算每个袋子还需要的石块数，排序
        gaps = sorted(capacity[i] - rocks[i] for i in range(len(capacity)))

        count = 0
        for gap in gaps:
            if additionalRocks >= gap:
                additionalRocks -= gap
                count += 1
            else:
                break  # 剩余石块不足以装满下一个

        return count
```

### 方法二：zip 计算差值

```python
from typing import List

class Solution:
    def maximumBags(self, capacity: List[int], rocks: List[int], additionalRocks: int) -> int:
        gaps = sorted(c - r for c, r in zip(capacity, rocks))
        ans = 0
        remaining = additionalRocks
        for g in gaps:
            remaining -= g
            if remaining < 0:
                break
            ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(n)，存储 gap 数组。

## 关键点总结

1. 贪心：优先装需要石块最少的袋子，最大化装满袋子数。
2. 计算差值 gap，排序后依次填满。
3. 当剩余石块不足以装满下一个袋子时停止。

## 易错点

- 已经满了的袋子（`capacity[i] == rocks[i]`）的 gap 为 0，直接计入答案（不消耗石块）。
- 排序后遇到无法装满的袋子后，后续袋子所需更多，直接 break。
