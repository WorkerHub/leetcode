## 题目描述

给定一个整数 `n`，如果它是 `4` 的幂次方，返回 `true`；否则，返回 `false`。

整数 `n` 是 `4` 的幂次方需满足：存在整数 `x` 使得 `n == 4^x`

**进阶：** 你能不使用循环或者递归来完成本题吗？

**示例 1：**
```
输入：n = 16
输出：true
```

**示例 2：**
```
输入：n = 5
输出：false
```

**示例 3：**
```
输入：n = 1
输出：true
解释：4^0 = 1
```

**提示：**
- `-2^31 <= n <= 2^31 - 1`

## 解题思路

4 的幂次方有特殊的性质：
- `4^0 = 1 = 0b1`
- `4^1 = 4 = 0b100`
- `4^2 = 16 = 0b10000`
- `4^3 = 64 = 0b1000000`

**核心观察：**
1. 4 的幂一定是 2 的幂（因为 4 = 2^2）
2. 4 的幂的二进制表示中，1 只出现在偶数位上（从右往左第 0、2、4、6... 位）
3. 4 的幂减 1 后，模 3 的余数是 0（数学性质：4^x - 1 = (2^2)^x - 1 能被 3 整除）

**多种解法：**
- 循环除法：不断除以 4，看最后是否等于 1
- 位运算：检查是否是 2 的幂且 1 在偶数位
- 数学性质：4 的幂满足 `(n & (n-1)) == 0` 且 `n % 3 == 1`

## Python 代码实现

### 方法一：循环除法（最直观）

```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        # 负数和 0 不可能是 4 的幂
        if n <= 0:
            return False
        
        # 不断除以 4
        while n % 4 == 0:
            n //= 4
        
        # 如果最终等于 1，说明原数是 4 的幂
        return n == 1
```

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

### 方法二：位运算 + 掩码（推荐）⭐

```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        # 条件 1：n > 0
        # 条件 2：n 是 2 的幂（只有一个 1）
        # 条件 3：1 在偶数位上（与掩码 0x55555555 做与运算不为 0）
        
        # 0x55555555 = 0b01010101010101010101010101010101
        # 这个掩码在所有偶数位（从右数第 0、2、4...位）上都是 1
        
        return n > 0 and (n & (n - 1)) == 0 and (n & 0x55555555) != 0
```

**解释：**
- `n & (n - 1) == 0`：确保 n 只有一个 1（2 的幂的特征）
- `n & 0x55555555 != 0`：确保这个 1 在偶数位上

**时间复杂度：** O(1)
**空间复杂度：** O(1)

### 方法三：数学性质（最简洁）⭐

```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        # 条件 1：n > 0
        # 条件 2：n 是 2 的幂
        # 条件 3：n % 3 == 1（4 的幂特有性质）
        
        return n > 0 and (n & (n - 1)) == 0 and n % 3 == 1
```

**数学推导：**
```
4^0 = 1 = 3 * 0 + 1  → 1 % 3 = 1
4^1 = 4 = 3 * 1 + 1  → 4 % 3 = 1
4^2 = 16 = 3 * 5 + 1 → 16 % 3 = 1
4^3 = 64 = 3 * 21 + 1 → 64 % 3 = 1

而 2 的幂但不是 4 的幂：
2^1 = 2 = 3 * 0 + 2  → 2 % 3 = 2
2^3 = 8 = 3 * 2 + 2  → 8 % 3 = 2
2^5 = 32 = 3 * 10 + 2 → 32 % 3 = 2
```

**时间复杂度：** O(1)
**空间复杂度：** O(1)

### 方法四：对数法

```python
import math

class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        if n <= 0:
            return False
        
        # 计算以 4 为底的对数
        log_result = math.log(n) / math.log(4)
        
        # 检查是否是整数（考虑浮点误差）
        return abs(log_result - round(log_result)) < 1e-10
```

**注意：** 这种方法可能有浮点精度问题，不推荐在面试中使用。

### 方法五：打表法（32位整数范围）

```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        # 32 位整数范围内所有 4 的幂
        # 4^0 到 4^15（4^16 超出 32 位整数范围）
        powers_of_four = {
            1, 4, 16, 64, 256, 1024, 4096, 16384, 65536,
            262144, 1048576, 4194304, 16777216, 67108864,
            268435456, 1073741824
        }
        
        return n in powers_of_four
```

**时间复杂度：** O(1)
**空间复杂度：** O(1)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 循环除法 | O(log n) | O(1) | 直观易懂 | 时间较慢 |
| 位运算+掩码 | O(1) | O(1) | 高效 | 需要理解位运算 |
| 数学性质 | O(1) | O(1) | 简洁优雅 | 需要数学推导 |
| 对数法 | O(1) | O(1) | 思路简单 | 浮点精度问题 |
| 打表法 | O(1) | O(1) | 最快 | 仅适用于有限范围 |

## 关键点总结

1. **2 的幂判断**：`n & (n-1) == 0` 判断是否只有一个 1
2. **位置判断**：4 的幂的 1 只在偶数位（0, 2, 4, 6...）
3. **数学性质**：4^x % 3 恒等于 1
4. **边界情况**：n <= 0 一定不是 4 的幂
5. **优化思路**：从数学性质或位运算角度优化到 O(1)

## 易错点

1. **忘记判断 n <= 0**
   ```python
   # 错误：没有处理负数和 0
   return (n & (n - 1)) == 0 and n % 3 == 1
   
   # 正确：
   return n > 0 and (n & (n - 1)) == 0 and n % 3 == 1
   ```

2. **掩码写错**
   ```python
   # 错误：0xAAAAAAAA 是奇数位的掩码
   return n > 0 and (n & (n - 1)) == 0 and (n & 0xAAAAAAAA) != 0
   
   # 正确：0x55555555 是偶数位的掩码
   return n > 0 and (n & (n - 1)) == 0 and (n & 0x55555555) != 0
   ```

3. **位运算优先级**
   ```python
   # 错误：& 优先级低于 ==，需要加括号
   return n > 0 and n & (n - 1) == 0  # 实际是 n & ((n-1) == 0)
   
   # 正确：
   return n > 0 and (n & (n - 1)) == 0
   ```

4. **模运算判断**
   ```python
   # 错误：2 的幂但不是 4 的幂，n % 3 == 2
   # 不能只用 n % 3 == 1，还要确保是 2 的幂
   
   # 正确：
   return n > 0 and (n & (n - 1)) == 0 and n % 3 == 1
   ```
