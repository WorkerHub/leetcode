## 题目描述

给你一个字符串 `s`，由小写英文字母和大写英文字母组成。

我们把字母的大小写视为同一个键（例如 `'a'` 和 `'A'` 是同一个键）。

返回在输入字符串 `s` 的过程中，**换键** 的次数（不区分大小写）。

换键：连续两个字符（不区分大小写）不相同，就算换键一次。

**示例 1：**
```
输入：s = "aAbBcC"
输出：2
```

**示例 2：**
```
输入：s = "AaAaAaaA"
输出：0
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含英文字母（大写和小写）

## 解题思路

将字符串转为全小写（或全大写），然后统计相邻字符不同的次数。

## Python 代码实现

### 方法一：转小写后比较（推荐）

```python
class Solution:
    def countKeyChanges(self, s: str) -> int:
        s = s.lower()
        count = 0
        for i in range(1, len(s)):
            if s[i] != s[i - 1]:
                count += 1
        return count
```

### 方法二：使用 zip

```python
class Solution:
    def countKeyChanges(self, s: str) -> int:
        s = s.lower()
        return sum(a != b for a, b in zip(s, s[1:]))
```

### 方法三：一行写法

```python
class Solution:
    def countKeyChanges(self, s: str) -> int:
        return sum(s[i].lower() != s[i-1].lower() for i in range(1, len(s)))
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(n)，转换后的字符串（方法一），O(1)（方法三）

## 关键点总结

1. 大小写不区分，先统一转为小写再比较
2. 换键次数 = 相邻字符（不区分大小写）不同的次数

## 易错点

1. 不要忘记大小写统一处理，`'A'` 和 `'a'` 是同一键
2. 返回换键次数，而不是不同键的种数
