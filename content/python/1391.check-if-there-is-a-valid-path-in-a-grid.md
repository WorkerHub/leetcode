## 题目描述

给你一个 `m x n` 的网格 `grid`。网格里的每个单元格都代表一条街道，`grid[i][j]` 的街道可以是以下类型：

- **1**：连接左格与右格的街道（水平直线）
- **2**：连接上格与下格的街道（垂直直线）
- **3**：连接左格与下格的街道（左下 L 形）
- **4**：连接右格与下格的街道（右下 L 形）
- **5**：连接左格与上格的街道（左上 L 形）
- **6**：连接右格与上格的街道（右上 L 形）

你从左上角格子 `(0, 0)` 出发，目标是抵达右下角格子 `(m-1, n-1)`。如果存在一条有效路径，则返回 `true`；否则返回 `false`。

**有效路径**要求：相邻两格之间必须都朝向对方方向连接。

**示例 1：**

```
输入：grid = [[2,4,3],[6,5,2]]
输出：true
```

**示例 2：**

```
输入：grid = [[1,2,1],[1,2,1]]
输出：false
```

**示例 3：**

```
输入：grid = [[1,1,2]]
输出：false
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 300`
- `1 <= grid[i][j] <= 6`

## 解题思路

**核心思想：** BFS/DFS 遍历，关键在于判断两个相邻格子之间能否互相连通。

**连通方向定义：**

每种街道类型的连通方向（可以从哪个方向进出）：
- 类型1：左、右
- 类型2：上、下
- 类型3：左、下
- 类型4：右、下
- 类型5：左、上
- 类型6：右、上

**关键判断：** 从格子 A 移动到格子 B（方向为 d），需要同时满足：
1. A 可以朝 d 方向连出
2. B 可以朝 d 的反方向连入

例如从 A 向右移动到 B：
- A 必须有"右"方向出口
- B 必须有"左"方向入口

## Python 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def hasValidPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        # 定义四个方向：上、下、左、右，对应索引 0,1,2,3
        # 每个方向用 (行偏移, 列偏移) 表示
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        # 反方向索引：上的反方向是下(1)，下的反方向是上(0)，左的反方向是右(3)，右的反方向是左(2)
        opposite = [1, 0, 3, 2]

        # 每种街道类型可以连通的方向集合（使用方向索引）
        # 上=0, 下=1, 左=2, 右=3
        street_dirs = {
            1: {2, 3},   # 左右
            2: {0, 1},   # 上下
            3: {2, 1},   # 左下
            4: {3, 1},   # 右下
            5: {2, 0},   # 左上
            6: {3, 0},   # 右上
        }

        visited = [[False] * n for _ in range(m)]
        visited[0][0] = True
        queue = deque([(0, 0)])

        while queue:
            r, c = queue.popleft()
            # 如果已经到达右下角，返回 True
            if r == m - 1 and c == n - 1:
                return True

            cur_type = grid[r][c]
            # 尝试往四个方向走
            for d, (dr, dc) in enumerate(directions):
                nr, nc = r + dr, c + dc
                # 检查边界
                if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc]:
                    next_type = grid[nr][nc]
                    # 判断当前格子能否朝 d 方向走出，且下一格能否从反方向走入
                    if d in street_dirs[cur_type] and opposite[d] in street_dirs[next_type]:
                        visited[nr][nc] = True
                        queue.append((nr, nc))

        # 若队列空了还没到终点
        return visited[m - 1][n - 1]
```

### 方法二：DFS 递归

```python
from typing import List
import sys
sys.setrecursionlimit(300 * 300 + 10)

class Solution:
    def hasValidPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        # 上=0, 下=1, 左=2, 右=3
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        opposite = [1, 0, 3, 2]
        street_dirs = {
            1: {2, 3}, 2: {0, 1}, 3: {2, 1},
            4: {3, 1}, 5: {2, 0}, 6: {3, 0},
        }

        visited = [[False] * n for _ in range(m)]

        def dfs(r: int, c: int) -> bool:
            if r == m - 1 and c == n - 1:
                return True
            visited[r][c] = True
            cur_type = grid[r][c]
            for d, (dr, dc) in enumerate(directions):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc]:
                    next_type = grid[nr][nc]
                    if d in street_dirs[cur_type] and opposite[d] in street_dirs[next_type]:
                        if dfs(nr, nc):
                            return True
            return False

        return dfs(0, 0)
```

## 复杂度分析

- **时间复杂度 O(m * n)**：每个格子最多访问一次。
- **空间复杂度 O(m * n)**：`visited` 数组和队列/递归栈的空间。

## 图解示例

街道类型示意图：

```
类型1: ─   类型2: │   类型3: ┘   类型4: └   类型5: ┐   类型6: ┌
```

判断两格是否可连通（以向右移动为例）：

```
当前格(r,c) 向右 --> 下一格(r,c+1)
要求：grid[r][c] 有"右"出口 且 grid[r][c+1] 有"左"入口
即：3 in street_dirs[grid[r][c]] 且 2 in street_dirs[grid[r][c+1]]
```

## 关键点总结

1. 用字典 `street_dirs` 表示每种街道的可达方向，便于查询
2. 两格互联需要**双向验证**：A 有出口朝向 B，B 有入口朝向 A
3. BFS 适合此类"是否可达"问题，且不用担心递归栈溢出
4. `opposite` 数组快速获取反方向，避免重复写逻辑

## 易错点

- 只验证单方向连通，忘记验证对面格子的反方向
  - 例如 A 是类型1（左右）想向右走，B 是类型2（上下），B 没有左方向入口，不能连通
- BFS 中忘记标记 `visited`，导致死循环或重复访问
- DFS 递归深度可能达到 300*300=90000，需设置递归限制
