## 题目描述

在一个 `m x n` 的金矿网格 `grid` 中，每个单元格的值代表该单元格中的黄金数量。如果值为 `0`，表示该单元格为空。

请你返回你能收集到的黄金的最大数量，需要遵循以下规则：

- 每当你处于一个单元格时，你将收集该单元格中的所有黄金
- 从你的位置，你可以向左、右、上、下四个方向之一移动一步
- 你不能访问同一个单元格超过一次
- 永远不能访问黄金数量为 `0` 的单元格
- 你可以从网格中任何一个有黄金的位置开始和停止收集

**示例 1：**

```
输入：grid = [[0,6,0],[5,8,7],[0,9,0]]
输出：24
解释：
[[0,6,0],
 [5,8,7],
 [0,9,0]]
路径：9 -> 8 -> 7。
```

**示例 2：**

```
输入：grid = [[1,0,7],[2,0,6],[3,4,5],[0,3,0],[9,0,20]]
输出：28
解释：
[[1,0,7],
 [2,0,6],
 [3,4,5],
 [0,3,0],
 [9,0,20]]
路径：1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7。
```

**提示：**

- `1 <= grid.length, grid[i].length <= 15`
- `0 <= grid[i][j] <= 100`
- 最多 `25` 个单元格包含黄金

## 解题思路

这是一道经典的**回溯（Backtracking）**问题，需要遍历所有可能的路径来找到最大黄金数量。

**核心思想：**

1. 从每个包含黄金的单元格开始尝试作为起点
2. 使用 DFS（深度优先搜索）+ 回溯探索所有可能的路径
3. 在探索过程中标记已访问的单元格，回溯时恢复现场
4. 记录所有路径中的最大黄金数量

**为什么用回溯？**

- 需要探索所有可能的路径组合
- 每个单元格只能访问一次，需要状态恢复
- 起点不固定，需要尝试所有可能的起点

**算法步骤：**

1. 遍历网格，找到所有非零单元格作为起点
2. 从每个起点开始 DFS，探索四个方向
3. 使用标记数组或修改原数组来记录访问状态
4. 递归探索时累加黄金数量
5. 回溯时恢复单元格状态

## Python 代码实现

### 方法一：回溯（修改原数组）⭐

```python
from typing import List

class Solution:
    def getMaximumGold(self, grid: List[List[int]]) -> int:
        """
        使用回溯法，通过修改原数组来标记访问状态
        
        时间复杂度：O(m * n * 4^k)，k 是黄金单元格数量（最多25）
        空间复杂度：O(k)，递归栈深度
        """
        m, n = len(grid), len(grid[0])
        max_gold = 0
        
        def dfs(x: int, y: int) -> int:
            """
            从 (x, y) 开始探索，返回能收集到的最大黄金数量
            """
            # 边界检查和有效性检查
            if x < 0 or x >= m or y < 0 or y >= n or grid[x][y] == 0:
                return 0
            
            # 收集当前位置的黄金
            current_gold = grid[x][y]
            
            # 标记为已访问（临时设为0）
            grid[x][y] = 0
            
            # 探索四个方向，取最大值
            max_path = 0
            for dx, dy in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                max_path = max(max_path, dfs(x + dx, y + dy))
            
            # 回溯：恢复当前位置的黄金数量
            grid[x][y] = current_gold
            
            # 返回当前黄金 + 后续路径的最大黄金
            return current_gold + max_path
        
        # 尝试从每个有黄金的位置开始
        for i in range(m):
            for j in range(n):
                if grid[i][j] != 0:
                    max_gold = max(max_gold, dfs(i, j))
        
        return max_gold
```

### 方法二：回溯（使用访问标记集合）

```python
from typing import List

class Solution:
    def getMaximumGold(self, grid: List[List[int]]) -> int:
        """
        使用 visited 集合来标记访问状态，不修改原数组
        """
        m, n = len(grid), len(grid[0])
        max_gold = 0
        
        def dfs(x: int, y: int, visited: set) -> int:
            """
            从 (x, y) 开始探索，visited 记录已访问的单元格
            """
            # 边界检查
            if (x < 0 or x >= m or y < 0 or y >= n or 
                grid[x][y] == 0 or (x, y) in visited):
                return 0
            
            # 标记为已访问
            visited.add((x, y))
            current_gold = grid[x][y]
            
            # 探索四个方向
            max_path = 0
            directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
            for dx, dy in directions:
                max_path = max(max_path, dfs(x + dx, y + dy, visited))
            
            # 回溯：移除访问标记
            visited.remove((x, y))
            
            return current_gold + max_path
        
        # 尝试所有起点
        for i in range(m):
            for j in range(n):
                if grid[i][j] != 0:
                    max_gold = max(max_gold, dfs(i, j, set()))
        
        return max_gold
```

### 方法三：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def getMaximumGold(self, grid: List[List[int]]) -> int:
        """
        回溯算法详细解释版本
        """
        rows = len(grid)
        cols = len(grid[0])
        result = 0
        
        def backtrack(row: int, col: int) -> int:
            """
            递归函数：从 (row, col) 开始收集黄金
            返回从该位置能收集到的最大黄金数量
            """
            # 情况1：越界
            if row < 0 or row >= rows or col < 0 or col >= cols:
                return 0
            
            # 情况2：当前位置没有黄金或已访问过
            if grid[row][col] == 0:
                return 0
            
            # 步骤1：收集当前位置的黄金
            gold_here = grid[row][col]
            
            # 步骤2：标记当前位置为已访问（设为0）
            # 这样在后续递归中就不会重复访问
            grid[row][col] = 0
            
            # 步骤3：探索四个方向（上、下、左、右）
            # 找出哪个方向能收集到最多黄金
            max_from_neighbors = 0
            
            # 向上
            max_from_neighbors = max(max_from_neighbors, 
                                    backtrack(row - 1, col))
            # 向下
            max_from_neighbors = max(max_from_neighbors, 
                                    backtrack(row + 1, col))
            # 向左
            max_from_neighbors = max(max_from_neighbors, 
                                    backtrack(row, col - 1))
            # 向右
            max_from_neighbors = max(max_from_neighbors, 
                                    backtrack(row, col + 1))
            
            # 步骤4：回溯 - 恢复当前位置的黄金数量
            # 这很重要！因为我们要尝试从其他位置开始的路径
            grid[row][col] = gold_here
            
            # 步骤5：返回总黄金数 = 当前黄金 + 后续路径最大黄金
            return gold_here + max_from_neighbors
        
        # 主逻辑：尝试从每个有黄金的单元格开始
        for i in range(rows):
            for j in range(cols):
                # 只从有黄金的位置开始
                if grid[i][j] > 0:
                    # 计算从该位置开始能收集的最大黄金
                    gold_from_here = backtrack(i, j)
                    # 更新全局最大值
                    result = max(result, gold_from_here)
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(m × n × 4^k)
  - m × n：遍历所有单元格作为起点
  - 4^k：每个单元格有4个方向，k 是黄金单元格数量（最多25）
  - 由于 k ≤ 25，实际运行效率可接受

- **空间复杂度**：O(k)
  - 递归栈的深度最多为黄金单元格的数量
  - 方法二额外需要 O(k) 的集合空间

## 关键点总结

1. **回溯三步骤**：选择（标记）→ 探索（递归）→ 撤销（恢复）
2. **状态恢复**：必须在递归返回后恢复 grid 的值，否则影响其他路径
3. **起点枚举**：需要尝试所有有黄金的位置作为起点
4. **剪枝优化**：遇到 0 或越界直接返回，避免无效探索
5. **方向数组**：使用 `[(0,1), (0,-1), (1,0), (-1,0)]` 简化代码

## 易错点

1. **忘记回溯**：
   - 错误：修改 grid 后不恢复
   - 后果：影响其他路径的探索，导致结果错误

2. **重复访问问题**：
   - 错误：没有标记已访问的单元格
   - 后果：可能陷入无限循环

3. **边界检查顺序**：
   - 正确：先检查越界，再检查 grid[x][y]
   - 错误：先访问 grid[x][y] 可能导致数组越界

4. **起点选择**：
   - 错误：只从第一个黄金位置开始
   - 正确：必须尝试所有有黄金的位置

5. **返回值理解**：
   - DFS 函数返回的是从当前位置能收集的最大黄金
   - 不是累积值，而是当前 + 后续最大值

## 学习建议

1. **理解回溯本质**：
   - 回溯 = DFS + 状态恢复
   - 关键在于"做选择"和"撤销选择"

2. **练习顺序**：
   - 先做简单的 DFS 题目（如岛屿数量）
   - 再做需要回溯的题目（本题）
   - 最后挑战路径类回溯题（如单词搜索）

3. **调试技巧**：
   - 打印每次递归的参数和返回值
   - 验证回溯是否正确恢复状态
   - 用小数据手动模拟递归过程

4. **优化思路**：
   - 剪枝：提前结束无效路径
   - 记忆化：缓存重复子问题（本题不适用）
   - 状态压缩：用位运算代替集合（高级优化）
