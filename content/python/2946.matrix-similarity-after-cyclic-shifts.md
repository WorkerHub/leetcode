## 题目描述

给你一个大小为 `m x n` 的整数矩阵 `mat` 和一个整数 `k`。

对矩阵执行循环移位操作：
- 奇数行（1-indexed）向右循环移位 `k` 次
- 偶数行向左循环移位 `k` 次

若移位后的矩阵与原矩阵相等，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 4
输出：false
```

**示例 2：**
```
输入：mat = [[2,2],[2,2]], k = 3
输出：true
```

**提示：**
- `1 <= m <= 25`
- `1 <= n <= 25`
- `1 <= mat[i][j] <= 25`
- `1 <= k <= 25`

## 解题思路

对每行分别模拟循环移位，然后与原矩阵比较。

向右循环移位 k 次相当于向右移位 `k % n`。
向左循环移位 k 次相当于向左移位 `k % n`，等价于向右移位 `n - k % n`。

若 `k % n == 0`，任何方向的移位都不改变数组。

## Python 代码实现

### 方法一：模拟移位（推荐）

```python
from typing import List

class Solution:
    def areSimilar(self, mat: List[List[int]], k: int) -> bool:
        m, n = len(mat), len(mat[0])
        shift = k % n

        if shift == 0:
            return True

        for i in range(m):
            row = mat[i]
            if (i + 1) % 2 == 1:
                # 奇数行（1-indexed），向右移位 shift
                rotated = row[-shift:] + row[:-shift]
            else:
                # 偶数行，向左移位 shift
                rotated = row[shift:] + row[:shift]
            if rotated != row:
                return False

        return True
```

### 方法二：利用对称性简化

```python
from typing import List

class Solution:
    def areSimilar(self, mat: List[List[int]], k: int) -> bool:
        m, n = len(mat), len(mat[0])
        k %= n
        if k == 0:
            return True
        for i, row in enumerate(mat):
            if i % 2 == 0:
                # 奇数行（0-indexed 偶数行），向右移 k
                if row != row[-k:] + row[:-k]:
                    return False
            else:
                # 偶数行（0-indexed 奇数行），向左移 k
                if row != row[k:] + row[:k]:
                    return False
        return True
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历所有元素
- 空间复杂度：O(n)，存储旋转后的行

## 关键点总结

1. 循环移位可以对 n 取余，减少实际移位量
2. 向右循环移位 k：`row[-k:] + row[:-k]`
3. 向左循环移位 k：`row[k:] + row[:k]`
4. k % n == 0 时，任何移位都保持不变，直接返回 true

## 易错点

1. 注意行的编号是 1-indexed（题目中奇数行从 1 开始数），代码中用 (i+1)%2 判断
2. 向左移 k 等于向右移 n-k，两种写法均可
3. k % n 为 0 时无需移位，直接返回 true
