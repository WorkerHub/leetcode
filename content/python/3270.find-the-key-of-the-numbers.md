## 题目描述

给你三个**正整数** `num1`、`num2` 和 `num3`。

数字的**密钥**：对三个数字的每一位（从个位到最高位），取三者中的**最小值**，组成新数（忽略前导零）。

**示例 1：**
```
输入：num1 = 1, num2 = 10, num3 = 1000
输出：0
解释：
个位：min(1,0,0)=0
十位：min(0,1,0)=0
百位：min(0,0,0)=0
千位：min(0,0,1)=0
密钥是 0000 = 0
```

**示例 2：**
```
输入：num1 = 987, num2 = 879, num3 = 798
输出：777
```

**提示：**
- `1 <= num1, num2, num3 <= 9999`

## 解题思路

按位取最小值：逐位比较三个数字，取最小值。

将三个数字用字符串对齐（补零到相同长度），逐位取最小。

## Python 代码实现

### 方法一：字符串对齐取最小（推荐）

```python
class Solution:
    def generateKey(self, num1: int, num2: int, num3: int) -> int:
        # 对齐到4位（最大4位数）
        s1 = str(num1).zfill(4)
        s2 = str(num2).zfill(4)
        s3 = str(num3).zfill(4)
        
        result = ''
        for a, b, c in zip(s1, s2, s3):
            result += str(min(int(a), int(b), int(c)))
        
        return int(result)
```

### 方法二：逐位取最小

```python
class Solution:
    def generateKey(self, num1: int, num2: int, num3: int) -> int:
        result = 0
        place = 1  # 当前位的权重（个位=1，十位=10，...）
        
        for _ in range(4):  # 最多4位
            d1 = (num1 // place) % 10
            d2 = (num2 // place) % 10
            d3 = (num3 // place) % 10
            result += min(d1, d2, d3) * place
            place *= 10
        
        return result
```

## 复杂度分析

- 时间复杂度：O(1)，最多处理 4 位
- 空间复杂度：O(1)

## 关键点总结

1. 按位取最小，位数用零补齐
2. 最大 4 位（1 <= num <= 9999）
3. 前导零会被自动忽略（int 转换去除）

## 易错点

1. 位数不同时需要补零（`zfill`）
2. 结果可能有前导零，转 int 自动处理
