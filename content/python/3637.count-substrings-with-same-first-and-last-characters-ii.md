## 题目描述

给你一个字符串 `s`，返回首尾字符相同的子字符串数量（子字符串长度至少为 1）。

**示例 1：**

```
输入：s = "abcba"
输出：7
解释：a,b,c,b,a,aba,abcba 共7个
```

**示例 2：**

```
输入：s = "aaaa"
输出：10
解释：所有子串均满足（共10个），因为首尾都是a
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含小写字母

## 解题思路

对于每个字符 `c`，统计以 `c` 为首尾的子字符串数量。

若字符 `c` 在字符串中出现了 `k` 次，则以 `c` 为首尾的子字符串数量为：
- 单字符：k 个
- 首尾均为 `c` 的多字符子串：`C(k, 2) = k*(k-1)/2` 个

总答案 = Σ (k_c * (k_c + 1) / 2) for each character c

## Python 代码实现

### 方法一：计数 + 组合数（推荐）

```python
from collections import Counter

class Solution:
    def countSubstrings(self, s: str) -> int:
        freq = Counter(s)
        ans = 0
        for c, k in freq.items():
            # k 个单字符 + C(k,2) 个多字符
            ans += k * (k + 1) // 2
        return ans
```

### 方法二：双指针枚举

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        # 预处理每个字符的所有位置
        from collections import defaultdict
        pos = defaultdict(list)
        for i, c in enumerate(s):
            pos[c].append(i)

        ans = 0
        for c, positions in pos.items():
            k = len(positions)
            # 每对位置 (i, j) 构成一个首尾为 c 的子串（i <= j）
            ans += k * (k + 1) // 2
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 首尾相同的子串数 = 每种字符 k 次出现构成的 `C(k+1, 2)` 个子串
2. `k*(k+1)//2` 是 1+2+...+k 的求和公式
3. 利用组合数学避免逐对枚举

## 易错点

1. 长度为 1 的子串也满足（首尾相同字符为自身）
2. 公式是 `k*(k+1)/2` 而非 `k*(k-1)/2`
3. 不同字符的贡献互相独立
