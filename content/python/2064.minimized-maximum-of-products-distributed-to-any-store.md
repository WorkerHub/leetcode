## 题目描述

给你一个整数 `n` 表示商店数量，和一个整数数组 `quantities`，`quantities[i]` 是第 `i` 种产品的数量。

你需要将**所有产品**分配给商店，每个商店只能分配**一种**产品，商店的产品数量可以为 0。

最小化**最大**分配量（即所有商店中分配量最大的那个商店的分配量的最小值）。

**示例 1：**
```
输入：n = 6, quantities = [11,6]
输出：3
解释：11 分给4个店（3,3,3,2），6 分给2个店（3,3），最大值最小为3
```

**提示：**
- `m == quantities.length`
- `1 <= m <= n <= 10^5`
- `1 <= quantities[i] <= 10^5`

## 解题思路

**二分答案：** 二分最大分配量 `x`，检查是否能在最大分配量不超过 `x` 的情况下，用不超过 `n` 个商店分配所有产品。

**检验函数：** 对于最大分配量 `x`，每种产品需要 `ceil(quantities[i] / x)` 个商店，若所有产品所需商店总数 ≤ n，则合法。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List
import math

class Solution:
    def minimizedMaximum(self, n: int, quantities: List[int]) -> int:
        def can_distribute(max_per_store: int) -> bool:
            # 检查最大分配量为 max_per_store 时，所需商店数是否 <= n
            total_stores = sum(math.ceil(q / max_per_store) for q in quantities)
            return total_stores <= n

        # 二分范围：最小为 1，最大为 max(quantities)
        lo, hi = 1, max(quantities)
        while lo < hi:
            mid = (lo + hi) // 2
            if can_distribute(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：更简洁的二分

```python
from typing import List

class Solution:
    def minimizedMaximum(self, n: int, quantities: List[int]) -> int:
        lo, hi = 1, max(quantities)
        while lo < hi:
            mid = (lo + hi) // 2
            # 每种产品需要 ceil(q/mid) 个商店
            if sum((q + mid - 1) // mid for q in quantities) <= n:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(m log V)，m 为产品种类数，V 为最大产品数量
- 空间复杂度：O(1)

## 关键点总结

1. 二分最大分配量（答案具有单调性：越大越容易满足商店数量限制）
2. 每种产品需要 `ceil(q / x)` 个商店
3. `ceil(a / b) = (a + b - 1) // b`（整数上取整）

## 易错点

- 二分的右边界是 `max(quantities)`（最坏情况下一种产品只用一个商店）
- 检验条件是 `<=` n（允许等于）
- 注意上取整的整数写法
