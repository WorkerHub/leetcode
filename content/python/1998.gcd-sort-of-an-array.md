## 题目描述

给你一个整数数组 `nums`，你可以对数组中的两个元素执行**交换操作**：若这两个元素的 GCD 严格大于 1，则可以互换。

如果可以通过若干次上述操作使数组**有序**，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：nums = [7,21,3]
输出：true
解释：gcd(7,21)=7>1，交换得 [21,7,3]，再 gcd(21,3)=3>1 交换得 [21,3,7]，还能...
实际上 gcd(7,21)=7>1，gcd(21,3)=3>1，所以 7,21,3 可以互相排列 → true
```

**示例 2：**
```
输入：nums = [5,2,6,2]
输出：true
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `2 <= nums[i] <= 3 * 10^4`

---

## 解题思路

### 核心思想：并查集 + 质因数分解

两个数 GCD > 1 等价于它们共享一个**质因数**。

**关键思路**：
- 用并查集，将共享同一质因数的所有数放在同一连通分量中
- 对每个 `nums[i]` 做质因数分解，将 `nums[i]` 与其所有质因数合并
- 最后检查：对每个位置 `i`，`nums[i]` 和排序后应在该位置的数 `sorted_nums[i]` 是否在同一连通分量中（即可以通过一系列交换实现）

## 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class Solution:
    def gcdSort(self, nums: List[int]) -> bool:
        MAX_VAL = max(nums) + 1

        # 并查集
        parent = list(range(MAX_VAL))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py

        # 对每个数做质因数分解，将该数与其质因数合并
        for v in nums:
            x = v
            d = 2
            while d * d <= x:
                if x % d == 0:
                    union(v, d)
                    while x % d == 0:
                        x //= d
                d += 1
            if x > 1:
                union(v, x)

        # 检查排序后每个位置对应的数是否在同一连通分量
        sorted_nums = sorted(nums)
        for a, b in zip(nums, sorted_nums):
            if find(a) != find(b):
                return False

        return True
```

### 方法二：线性筛质因数 + 并查集

```python
from typing import List

class Solution:
    def gcdSort(self, nums: List[int]) -> bool:
        MAX_VAL = max(nums) + 1

        # 线性筛：min_prime[i] = i 的最小质因数
        min_prime = list(range(MAX_VAL))
        for i in range(2, MAX_VAL):
            if min_prime[i] == i:  # i 是质数
                for j in range(i * i, MAX_VAL, i):
                    if min_prime[j] == j:
                        min_prime[j] = i

        parent = list(range(MAX_VAL))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        # 对每个数用最小质因数分解，合并
        for v in nums:
            x = v
            while x > 1:
                p = min_prime[x]
                union(v, p)
                while x % p == 0:
                    x //= p

        sorted_nums = sorted(nums)
        for a, b in zip(nums, sorted_nums):
            if find(a) != find(b):
                return False

        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n * sqrt(M) * α(M)) | O(M) |
| 方法二 | O(M + n log M * α(M)) | O(M) |

M = max(nums)。

---

## 关键点总结

1. GCD > 1 等价于共享质因数，用并查集连通共享质因数的元素
2. 将每个数与其所有质因数合并（而非两两比较）
3. 最后检查排序前后对应位置的数是否同组

---

## 易错点

- 并查集合并的是"数值"而非"下标"，需要开到 max(nums)+1 大小
- 路径压缩是必要的，否则复杂度退化
