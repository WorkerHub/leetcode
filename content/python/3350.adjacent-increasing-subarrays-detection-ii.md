## 题目描述

与 3349 类似，但返回最大的 `k` 值，使得存在两个相邻且不重叠的长度为 `k` 的严格递增子数组。

**提示：**
- `2 <= nums.length <= 2 * 10^5`

## 解题思路

**预处理递增长度 + 二分查找：**

1. 预处理 `inc[i]`：从位置 `i` 开始的最长严格递增子数组长度。

2. 对于某个 `k`，判断是否满足条件：遍历所有 `a` 检查 `inc[a] >= k && inc[a+k] >= k`。

3. 答案具有单调性（`k` 满足则 `k-1` 也满足），因此可以二分查找最大 k。

**优化（直接扫描）：**

枚举第二段的起始位置 `j`（`j = k, k+1, ..., n-k`），`k` 的候选值从大到小：对每个 `j`，最大有效 `k = min(inc[j-inc[j-1]], inc[j])` ... 

直接的方法：对每个位置 `j`，第一段结束于 `j-1`，第二段从 `j` 开始，两段各长 `k`，最大 `k = min(inc[j-k], inc[j])` for some k... 

**简化：** 由于有单调性，二分答案 `k`，然后 O(n) 验证。

## Python 代码实现

### 方法一：预处理 + 二分答案（推荐）

```python
from typing import List

class Solution:
    def maxIncreasingSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 预处理 inc[i]：从 i 开始的最长严格递增子数组长度
        inc = [1] * n
        for i in range(n - 2, -1, -1):
            if nums[i] < nums[i + 1]:
                inc[i] = inc[i + 1] + 1
        
        def check(k):
            for a in range(n - 2 * k + 1):
                if inc[a] >= k and inc[a + k] >= k:
                    return True
            return False
        
        # 二分答案
        lo, hi = 1, n // 2
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        
        return lo if check(lo) else 0
```

### 方法二：直接 O(n) 扫描

```python
from typing import List

class Solution:
    def maxIncreasingSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        
        inc = [1] * n
        for i in range(n - 2, -1, -1):
            if nums[i] < nums[i + 1]:
                inc[i] = inc[i + 1] + 1
        
        ans = 0
        # 对于每个可能的分割点 j（第二段从 j 开始）
        # 最大 k = min(第一段长度, 第二段长度)
        # 第一段以 j-1 结尾，第一段起始为 j - k，需要 inc[j-k] >= k
        # 贪心：第一段尽量长（len1），第二段 inc[j]
        
        # 直接枚举所有连续递增段，相邻段之间取最小
        # 找所有连续递增段的长度
        segments = []
        i = 0
        while i < n:
            l = inc[i]
            segments.append(l)
            i += l
        
        # 相邻两个递增段，各自取最小
        for s in range(len(segments) - 1):
            ans = max(ans, min(segments[s], segments[s+1]))
        
        # 同一个连续递增段内，可以分成相邻两半
        for s in segments:
            ans = max(ans, s // 2)
        
        return ans
```

## 复杂度分析

**方法二：**
- 时间复杂度：O(n)，一次遍历找所有递增段
- 空间复杂度：O(n)，递增段列表

## 关键点总结

1. 两段可以在同一个递增段内（将其对半分）。
2. 两段也可以是相邻的两个递增段（各自取最小长度）。
3. 以上两种情况覆盖了所有可能，取最大即可。

## 易错点

1. 同一递增段内：最大 k = 段长度 // 2。
2. 相邻两个递增段：最大 k = min(左段长, 右段长)。
3. 别忘了同一段内的情况（段长 >= 2 时可以分成两个相邻递增子数组）。
