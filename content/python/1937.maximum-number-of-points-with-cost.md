## 题目描述

给你一个 `m x n` 的整数矩阵 `points`（下标从 0 开始），分数从选择一些格子开始。

规则：从每行恰好选择一个格子，从第一行到最后一行。第 `i` 行选择了第 `c1` 列，第 `i+1` 行选择了第 `c2` 列，则代价为 `|c1 - c2|`。

总得分 = 所有选定格子的值之和 - 所有相邻行选定格子之间的代价之和。

返回最大得分。

**示例 1：**
```
输入：points = [[1,2,3],[1,5,1],[3,1,1]]
输出：9
解释：选 (0,2), (1,1), (2,0)：3 + 5 + 3 - |2-1| - |1-0| = 9
```

**提示：**
- `m == points.length`，`n == points[i].length`
- `1 <= m, n <= 10^5`
- `0 <= points[i][j] <= 10^5`

---

## 解题思路

### 核心思想：DP + 前缀最大值优化

定义 `dp[j]` = 选择当前行第 `j` 列时的最大得分。

转移时，`dp_new[j] = max(dp[k] - |j-k|) + points[i][j]`

对每个 `j`：
- 来自左侧 `k <= j`：`dp[k] - (j - k) = dp[k] + k - j`，即 `max(dp[k] + k) - j`
- 来自右侧 `k >= j`：`dp[k] - (k - j) = dp[k] - k + j`，即 `max(dp[k] - k) + j`

用两次线性扫描（从左到右和从右到左）维护最大值，将 O(n²) 优化到 O(n)。

## 代码实现

### 方法一：DP + 前缀最大值优化（推荐）

```python
from typing import List

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        m, n = len(points), len(points[0])
        # dp[j] = 选择上一行第 j 列时的最大得分
        dp = points[0][:]

        for i in range(1, m):
            new_dp = [0] * n

            # 从左到右扫描：处理 k <= j 的情况
            # max_left[j] = max(dp[k] + k) for k <= j
            left_max = dp[0]  # dp[0] + 0
            for j in range(n):
                left_max = max(left_max, dp[j] + j)
                new_dp[j] = max(new_dp[j], left_max - j + points[i][j])

            # 从右到左扫描：处理 k >= j 的情况
            # max_right[j] = max(dp[k] - k) for k >= j
            right_max = dp[n - 1] - (n - 1)  # dp[n-1] - (n-1)
            for j in range(n - 1, -1, -1):
                right_max = max(right_max, dp[j] - j)
                new_dp[j] = max(new_dp[j], right_max + j + points[i][j])

            dp = new_dp

        return max(dp)
```

### 方法二：暴力 DP（O(mn²)，对比学习，小数据验证用）

```python
from typing import List

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        m, n = len(points), len(points[0])
        dp = points[0][:]

        for i in range(1, m):
            new_dp = [-float('inf')] * n
            for j in range(n):
                for k in range(n):
                    # 从第 i-1 行选 k，第 i 行选 j
                    score = dp[k] - abs(j - k) + points[i][j]
                    new_dp[j] = max(new_dp[j], score)
            dp = new_dp

        return max(dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 优化 DP | O(mn) | O(n) |
| 暴力 DP | O(mn²) | O(n) |

---

## 关键点总结

1. 关键拆分：`|j-k| = (j-k)` 当 `k<=j` 或 `(k-j)` 当 `k>=j`
2. 左侧最大：维护 `max(dp[k]+k)` 从左到右扫描
3. 右侧最大：维护 `max(dp[k]-k)` 从右到左扫描

---

## 易错点

- 初始化 `left_max` 和 `right_max` 时注意加减 k 的偏置
- 每行处理完后 `dp = new_dp`，不要原地修改
