## 题目描述

与 3380 相同，但数据范围更大：`points.length <= 4 * 10^4`，需要高效算法。

找最大轴对齐矩形，四角在给定点集中，内部无点。

**提示：**
- `1 <= points.length <= 4 * 10^4`
- `0 <= x, y <= 10^9`

## 解题思路

**扫描线 + 树状数组：**

1. 对点集按 y 坐标分组，对每对 x 坐标 `(x1, x2)`，找满足条件的 y 坐标对。

2. 枚举两个 x 坐标 `x1 < x2`（只枚举同一列，实际需要找两列有公共 y 的情况）。

3. **关键优化：** 对每个 y，记录有哪些 x；对每对 (y1, y2)，矩形 `[x1, x2] x [y1, y2]` 合法的条件：四角在点集中，且矩形内部无点。

4. 扫描线：按 y 扫描，用树状数组维护活跃的 x 坐标，枚举可能的矩形。

由于实现复杂，以下提供基础框架：

## Python 代码实现

### 方法一：枚举（适合中等规模）

```python
from typing import List
from collections import defaultdict
from sortedcontainers import SortedList

class Solution:
    def maxRectangleArea(self, xCoord: List[int], yCoord: List[int]) -> int:
        n = len(xCoord)
        points = list(zip(xCoord, yCoord))
        point_set = set(points)
        
        # 按 y 坐标将点分组
        by_y = defaultdict(list)
        for x, y in points:
            by_y[y].append(x)
        
        # 对每个 y，排序其中的 x 值
        for y in by_y:
            by_y[y].sort()
        
        ys = sorted(by_y.keys())
        
        best = -1
        
        # 对相邻 y 层之间的矩形进行检查（优化：只考虑相邻的两个 y）
        # 完整解法需要考虑所有 y 对
        
        # 简化：枚举所有 y 对（对小数据）
        for i in range(len(ys)):
            for j in range(i + 1, len(ys)):
                y1, y2 = ys[i], ys[j]
                # 找在两行都出现的 x 值
                common_x = sorted(set(by_y[y1]) & set(by_y[y2]))
                if len(common_x) < 2:
                    continue
                
                # 对每对相邻的 x 值，检查矩形内是否有点
                for k in range(len(common_x) - 1):
                    x1, x2 = common_x[k], common_x[k+1]
                    
                    # 检查矩形 [x1, x2] x [y1, y2] 内部是否有点
                    has_inner = any(
                        x1 < px < x2 and y1 < py < y2
                        for px, py in points
                    )
                    
                    if not has_inner:
                        area = (x2 - x1) * (y2 - y1)
                        best = max(best, area)
        
        return best
```

## 复杂度分析

- 时间复杂度：O(n^2 * log n)（有优化）或 O(n^3)（暴力）
- 空间复杂度：O(n)

## 关键点总结

1. 矩形四角在点集中，等价于两行各有两个公共 x 坐标。
2. 矩形内部无点：严格内部（不含边界）无点。
3. 大数据时需要扫描线 + 线段树/树状数组优化。

## 易错点

1. 内部无点的检查需要严格不等（`x1 < px < x2 AND y1 < py < y2`）。
2. 相邻 x 坐标对（在同一行公共 x 中相邻）保证矩形底边和顶边上无内部点。
3. 枚举的 y 对还需要检查中间 y 层是否有点在 `[x1, x2]` 范围内。
