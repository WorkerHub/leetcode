## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，返回长度为 `n - 1` 的数组 `answer`，其中 `answer[i] = nums[i] OR nums[i + 1]`。

**示例：**
```
输入：nums = [1,3,7,15]
输出：[3,7,15]
解释：1|3=3, 3|7=7, 7|15=15
```

**提示：**
- `2 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 解题思路

直接遍历，对每对相邻元素计算按位或。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def orArray(self, nums: List[int]) -> List[int]:
        return [nums[i] | nums[i + 1] for i in range(len(nums) - 1)]
```

### 方法二：zip

```python
from typing import List

class Solution:
    def orArray(self, nums: List[int]) -> List[int]:
        return [a | b for a, b in zip(nums, nums[1:])]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. 相邻元素按位或
2. 结果长度为 n-1

## 易错点

1. 注意结果数组比原数组少一个元素
2. 是 OR 运算，不是 AND 或 XOR
