## 题目描述

给你一个字符串 `title`，它由单个空格连接一个或多个单词组成，每个单词仅由英文字母组成。

根据以下规则**大写**标题：

- 如果单词的长度为 1 或 2，将其**全部字母变成小写**。
- 否则，将单词**首字母大写，其余字母小写**。

返回大写后的 `title`。

**示例 1：**
```
输入：title = "capiTalIze tHe titLe"
输出："Capitalize The Title"
```

**示例 2：**
```
输入：title = "First letter of each Word"
输出："First Letter of Each Word"
解释：单词"of"长度为2，全小写；其余均首字母大写。
```

**提示：**
- `1 <= title.length <= 100`
- `title` 由单个空格连接单词，不含前导/尾随空格

## 解题思路

分割字符串为单词，按长度决定每个单词的大小写形式，再拼接。

## 代码实现

### 方法一：分割处理（推荐）

```python
class Solution:
    def capitalizeTitle(self, title: str) -> str:
        result = []
        for word in title.split():
            if len(word) <= 2:
                result.append(word.lower())
            else:
                result.append(word.capitalize())  # 首字母大写，其余小写
        return ' '.join(result)
```

### 方法二：列表推导式（简洁版）

```python
class Solution:
    def capitalizeTitle(self, title: str) -> str:
        return ' '.join(
            word.lower() if len(word) <= 2 else word.capitalize()
            for word in title.split()
        )
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分割处理 | O(n) | O(n) |

## 关键点总结

1. Python 的 `str.capitalize()` 将首字母大写、其余字母小写，恰好满足要求。
2. `str.lower()` 将全部字母转小写。
3. 用 `split()` 和 `join()` 处理空格分割，简洁高效。

## 易错点

- `str.title()` 不符合题意（长度为 1 或 2 的词也会首字母大写）。
- `capitalize()` 会将除首字母外的所有字母变小写，比 `title()` 更严格，正好符合题意。
