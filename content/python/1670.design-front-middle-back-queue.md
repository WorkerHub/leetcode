## 题目描述

请你设计一个队列，支持在前、中、后三个位置的 `push` 和 `pop` 操作：

- `pushFront(val)`：将 `val` 添加到队列的**最前面**
- `pushMiddle(val)`：将 `val` 添加到队列的**中间位置**
- `pushBack(val)`：将 `val` 添加到队列的**最后面**
- `popFront()`：从队列的**最前面**移除并返回值；若队列为空返回 `-1`
- `popMiddle()`：从队列的**中间位置**移除并返回值；若队列为空返回 `-1`
- `popBack()`：从队列的**最后面**移除并返回值；若队列为空返回 `-1`

若有两个中间位置，选择**靠前**的中间位置（如长度为 4 时，中间是第 2 个元素，下标 1）。

## 解题思路

使用**两个双端队列（deque）**：
- `left` 和 `right` 各维护一半，保持 `len(left) == len(right)` 或 `len(left) == len(right) + 1`（奇数时左多一个）
- 每次操作后**平衡**两个队列

## 代码实现

### 方法一：双 deque（推荐）

```python
from collections import deque

class FrontMiddleBackQueue:

    def __init__(self):
        self.left = deque()   # 前半部分
        self.right = deque()  # 后半部分
    
    def _balance(self):
        """保持 len(left) == len(right) 或 len(left) == len(right) + 1"""
        if len(self.left) > len(self.right) + 1:
            self.right.appendleft(self.left.pop())
        elif len(self.right) > len(self.left):
            self.left.append(self.right.popleft())

    def pushFront(self, val: int) -> None:
        self.left.appendleft(val)
        self._balance()

    def pushMiddle(self, val: int) -> None:
        if len(self.left) > len(self.right):
            # 奇数长度，中间偏左，val 插到 left 最后（即中间位置）
            self.right.appendleft(self.left.pop())
        self.left.append(val)
        # 不需要额外 balance，因为已经平衡了

    def pushBack(self, val: int) -> None:
        self.right.append(val)
        self._balance()

    def popFront(self) -> int:
        if not self.left and not self.right:
            return -1
        val = self.left.popleft() if self.left else self.right.popleft()
        self._balance()
        return val

    def popMiddle(self) -> int:
        if not self.left and not self.right:
            return -1
        val = self.left.pop()
        self._balance()
        return val

    def popBack(self) -> int:
        if not self.left and not self.right:
            return -1
        val = self.right.pop() if self.right else self.left.pop()
        self._balance()
        return val
```

### 方法二：列表（简单但操作 O(n)）

```python
class FrontMiddleBackQueue:

    def __init__(self):
        self.data = []

    def pushFront(self, val: int) -> None:
        self.data.insert(0, val)

    def pushMiddle(self, val: int) -> None:
        mid = len(self.data) // 2
        self.data.insert(mid, val)

    def pushBack(self, val: int) -> None:
        self.data.append(val)

    def popFront(self) -> int:
        return self.data.pop(0) if self.data else -1

    def popMiddle(self) -> int:
        if not self.data:
            return -1
        mid = (len(self.data) - 1) // 2
        return self.data.pop(mid)

    def popBack(self) -> int:
        return self.data.pop() if self.data else -1
```

## 复杂度分析

| 方法 | push/pop 时间复杂度 | 空间复杂度 |
|------|-------------------|-----------|
| 双 deque | O(1) | O(n) |
| 列表 | O(n) | O(n) |

## 关键点总结

1. 双 deque 方法：左半存前一半，右半存后一半，维持大小平衡
2. 中间位置：奇数长度时，`left` 的最后一个元素就是中间元素
3. 平衡条件：`len(left) == len(right)` 或 `len(left) == len(right) + 1`
4. `pushMiddle` 后不需要额外 balance（手动平衡了）

## 易错点

- 奇数长度时，"中间"靠前一个（左半最后一个元素）
- 队列为空时返回 -1
- `popFront` 时若 left 为空但 right 非空，从 right 取
