## 题目描述

给你一个 `n` 个顶点的无向加权图，顶点编号从 0 开始，初始没有边。

给你数组 `edges`，`edges[i] = [ui, vi, wi]` 表示顶点 `ui` 和 `vi` 之间有一条权重为 `wi` 的边。

**路径的开销**定义为路径上所有边的权重的按位与（AND）结果。

给你一个二维整数数组 `query`，其中 `query[j] = [sj, tj]`。对于每个查询，你需要找到从 `sj` 到 `tj` 的 **最小开销路径**，如果不存在路径则返回 `-1`。

返回数组 `answer`，`answer[j]` 为第 `j` 个查询的答案。

**提示：**
- `2 <= n <= 10^5`
- `0 <= edges.length <= 10^5`
- `0 <= query.length <= 10^5`

## 解题思路

关键观察：按位与的结果随着参与运算的数增多只会减小或不变（AND 单调不增）。因此，若 s 和 t 在同一连通分量中，我们可以走遍该连通分量的所有边，得到的开销就是连通分量内所有边权重的 AND，这是该连通分量内任意路径开销的最小值。

使用并查集维护连通分量，同时记录每个连通分量内所有边权的 AND 值。

## Python 代码实现

### 方法一：并查集 + 位运算（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        # 并查集
        parent = list(range(n))
        rank = [0] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩
                x = parent[x]
            return x

        def union(x: int, y: int) -> None:
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1

        # 建立并查集
        for u, v, _ in edges:
            union(u, v)

        # 计算每个连通分量的所有边权 AND
        comp_and = {}  # 根节点 -> AND 值
        for u, v, w in edges:
            root = find(u)
            if root not in comp_and:
                comp_and[root] = w
            else:
                comp_and[root] &= w

        # 回答查询
        ans = []
        for s, t in query:
            ps, pt = find(s), find(t)
            if ps != pt:
                ans.append(-1)  # 不连通
            elif s == t:
                ans.append(0)   # 同一顶点
            else:
                ans.append(comp_and.get(ps, 0))
        return ans
```

### 方法二：更简洁的实现

```python
from typing import List

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        parent = list(range(n))
        comp_and = [(1 << 17) - 1] * n  # 初始为全 1（17 位足够）

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y, w):
            px, py = find(x), find(y)
            comp_and[px] &= w
            comp_and[py] &= w
            if px != py:
                parent[px] = py
                comp_and[py] &= comp_and[px]

        for u, v, w in edges:
            union(u, v, w)

        return [
            -1 if find(s) != find(t) else (0 if s == t else comp_and[find(s)])
            for s, t in query
        ]
```

## 复杂度分析

- 时间复杂度：O((n + m + q) * alpha(n))，其中 m 为边数，q 为查询数，alpha 为反阿克曼函数（近似常数）
- 空间复杂度：O(n)

## 关键点总结

1. 按位与只会越来越小，走更多边开销不会更大
2. 同一连通分量内最优路径开销为该分量所有边权的 AND
3. 并查集合并时同步维护 AND 值

## 易错点

1. s == t 时开销为 0（空路径）
2. AND 的初始值应为全 1，不能是 0
