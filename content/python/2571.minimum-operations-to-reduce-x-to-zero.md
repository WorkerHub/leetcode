## 题目描述

给你一个整数数组 `nums` 和一个整数 `x`。每次操作，你可以选择数组 **最左边** 或 **最右边** 的元素，将其从数组中删去，并将该值从 `x` 中减去。

若可以将 `x` 恰好减为 `0`，返回 **最少操作次数**；否则返回 `-1`。

**示例 1：**

```
输入：nums = [1,1,4,2,3], x = 5
输出：2
解释：最优操作：删去右侧的 3 和 2，2 次操作。
```

**示例 2：**

```
输入：nums = [5,6,7,8,9], x = 4
输出：-1
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i], x <= 10^9`

## 解题思路

**逆向思维**：从两端删除数字使和为 x，等价于保留中间一段子数组使其和为 `sum(nums) - x`。

找最长子数组使其和恰好等于 `target = sum(nums) - x`，用滑动窗口解决（因为 nums 全正）。

最少操作次数 = n - 最长子数组长度。

## Python 代码实现

### 方法一：逆向滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        if target < 0:
            return -1
        if target == 0:
            return len(nums)

        n = len(nums)
        max_len = -1
        cur_sum = 0
        left = 0

        for right in range(n):
            cur_sum += nums[right]
            while cur_sum > target and left <= right:
                cur_sum -= nums[left]
                left += 1
            if cur_sum == target:
                max_len = max(max_len, right - left + 1)

        return n - max_len if max_len != -1 else -1
```

### 方法二：前缀和 + 哈希表

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        if target < 0:
            return -1

        prefix = {0: -1}  # 前缀和 -> 最早出现的下标
        cur = 0
        max_len = -1

        for i, num in enumerate(nums):
            cur += num
            if cur - target in prefix:
                max_len = max(max_len, i - prefix[cur - target])
            if cur not in prefix:
                prefix[cur] = i

        return len(nums) - max_len if max_len != -1 else -1
```

## 复杂度分析

- 方法一时间复杂度：O(n)，滑动窗口
- 方法二时间复杂度：O(n)，哈希表前缀和
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 逆向思维：找中间最长子数组和为 target
2. 所有元素为正，滑动窗口具有单调性（窗口和随右扩展单调增）
3. 最少操作 = n - 最长子数组长度

## 易错点

1. target = sum - x 可能为负，需提前判断
2. target = 0 时，保留空子数组，操作次数 = n
3. 滑动窗口缩小时从左侧移除元素
