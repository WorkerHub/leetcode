## 题目描述

给你一个整数 n，返回和为 n 的完全平方数的最少数量。

完全平方数是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

**示例 1：**
```
输入: n = 12
输出: 3 
解释: 12 = 4 + 4 + 4
```

**示例 2：**
```
输入: n = 13
输出: 2
解释: 13 = 4 + 9
```

**提示：**
- 1 <= n <= 10^4

## 解题思路

这道题有多种解法，从动态规划到 BFS，再到数学定理。

### 思路一：动态规划

定义 `dp[i]` 为和为 i 的完全平方数的最少数量。

**状态转移：**
- 对于每个 i，尝试所有可能的完全平方数 j^2（j^2 <= i）
- `dp[i] = min(dp[i - j^2] + 1)` for all j where j^2 <= i

**初始状态：**
- `dp[0] = 0`
- `dp[i] = i`（最坏情况，i 个 1）

### 思路二：BFS（广度优先搜索）

将问题看作图的最短路径：
- 从 0 开始，每次可以加上一个完全平方数
- 目标是到达 n，求最少步数

### 思路三：数学定理（四平方和定理）

**拉格朗日四平方和定理：** 任何正整数都可以表示为至多 4 个完全平方数的和。

进一步优化：
- 如果 n 本身是完全平方数，答案是 1
- 如果 n = 4^k * (8m + 7)，答案是 4
- 否则，检查能否用 2 个完全平方数表示，不能则答案是 3

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def numSquares(self, n: int) -> int:
        """
        动态规划：dp[i] 表示和为 i 的完全平方数的最少数量
        """
        # 初始化 dp 数组
        dp = [float('inf')] * (n + 1)
        dp[0] = 0
        
        # 预计算所有可能的完全平方数
        squares = []
        i = 1
        while i * i <= n:
            squares.append(i * i)
            i += 1
        
        # 状态转移
        for i in range(1, n + 1):
            for square in squares:
                if square > i:
                    break
                dp[i] = min(dp[i], dp[i - square] + 1)
        
        return dp[n]
```

### 方法二：优化的动态规划

```python
class Solution:
    def numSquares(self, n: int) -> int:
        """
        动态规划优化版本
        """
        dp = [0] * (n + 1)
        
        for i in range(1, n + 1):
            # 最坏情况：i 个 1
            dp[i] = i
            
            # 尝试所有完全平方数
            j = 1
            while j * j <= i:
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        
        return dp[n]
```

### 方法三：BFS（广度优先搜索）

```python
from collections import deque

class Solution:
    def numSquares(self, n: int) -> int:
        """
        BFS 求最短路径
        """
        # 预计算完全平方数
        squares = []
        i = 1
        while i * i <= n:
            squares.append(i * i)
            i += 1
        
        # BFS
        queue = deque([(0, 0)])  # (当前和, 步数)
        visited = {0}
        
        while queue:
            current_sum, steps = queue.popleft()
            
            # 尝试加上每个完全平方数
            for square in squares:
                next_sum = current_sum + square
                
                if next_sum == n:
                    return steps + 1
                
                if next_sum < n and next_sum not in visited:
                    visited.add(next_sum)
                    queue.append((next_sum, steps + 1))
        
        return 0
```

### 方法四：数学方法（四平方和定理）

```python
import math

class Solution:
    def numSquares(self, n: int) -> int:
        """
        基于数学定理的方法
        """
        # 检查是否是完全平方数
        def is_perfect_square(x):
            sqrt = int(math.sqrt(x))
            return sqrt * sqrt == x
        
        # 情况 1: n 本身是完全平方数
        if is_perfect_square(n):
            return 1
        
        # 情况 2: n = 4^k * (8m + 7)，答案是 4
        temp = n
        while temp % 4 == 0:
            temp //= 4
        if temp % 8 == 7:
            return 4
        
        # 情况 3: 检查是否可以用 2 个完全平方数表示
        i = 1
        while i * i <= n:
            if is_perfect_square(n - i * i):
                return 2
            i += 1
        
        # 情况 4: 需要 3 个完全平方数
        return 3
```

### 方法五：记忆化递归

```python
from functools import lru_cache

class Solution:
    def numSquares(self, n: int) -> int:
        """
        记忆化递归
        """
        # 预计算完全平方数
        squares = []
        i = 1
        while i * i <= n:
            squares.append(i * i)
            i += 1
        
        @lru_cache(None)
        def dfs(remain):
            # 如果剩余为 0，不需要更多的平方数
            if remain == 0:
                return 0
            
            # 如果剩余本身是完全平方数
            if remain in squares:
                return 1
            
            # 尝试所有可能的完全平方数
            min_count = float('inf')
            for square in squares:
                if square > remain:
                    break
                min_count = min(min_count, dfs(remain - square) + 1)
            
            return min_count
        
        return dfs(n)
```

## 复杂度分析

### 方法一、二：动态规划

**时间复杂度：** O(n * √n)
- 外层循环 n 次
- 内层循环 √n 次（所有完全平方数）

**空间复杂度：** O(n)
- dp 数组

### 方法三：BFS

**时间复杂度：** O(n * √n)
- 最坏情况访问所有节点
- 每个节点尝试 √n 个完全平方数

**空间复杂度：** O(n)
- 队列和 visited 集合

### 方法四：数学方法

**时间复杂度：** O(√n)
- 检查是否可以用 2 个平方数表示

**空间复杂度：** O(1)

## 关键点总结

1. **动态规划思路**：和为 i 的方案 = min(和为 i-j^2 的方案 + 1)
2. **BFS 思路**：将问题转化为图的最短路径
3. **数学优化**：利用四平方和定理，答案只可能是 1、2、3 或 4
4. **完全平方数的范围**：只需考虑 <= n 的完全平方数（最多 √n 个）
5. **方法选择**：
   - 动态规划最通用，易理解
   - BFS 思路清晰，但空间可能更大
   - 数学方法最快，但不够直观

## 易错点

1. **dp 初始化**
   ```python
   # 错误：初始化为 0
   dp = [0] * (n + 1)
   
   # 正确：初始化为无穷大（或 i）
   dp = [float('inf')] * (n + 1)
   dp[0] = 0
   ```

2. **完全平方数的遍历顺序**
   ```python
   # 优化：从小到大遍历，可以提前 break
   for square in squares:
       if square > i:
           break
       dp[i] = min(dp[i], dp[i - square] + 1)
   ```

3. **BFS 中的访问标记**
   ```python
   # 必须标记访问过的节点，避免重复
   if next_sum not in visited:
       visited.add(next_sum)
       queue.append((next_sum, steps + 1))
   ```

4. **数学方法的边界**
   ```python
   # 注意判断完全平方数时的精度问题
   def is_perfect_square(x):
       sqrt = int(math.sqrt(x))
       return sqrt * sqrt == x  # 精确比较
   ```
