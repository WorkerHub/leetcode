## 题目描述

给你一个字符串数组 `words`，数组中的每个字符串都可以看作是一个单词。请你按**任意** 顺序返回 `words` 中是其他单词的子字符串的所有单词。

如果你可以删除 `words[j]` 最左侧和/或最右侧的若干字符得到 `word[i]`，那么字符串 `words[i]` 就是 `words[j]` 的一个子字符串。

**示例 1：**

```
输入：words = ["mass","as","hero","superhero"]
输出：["as","mass"]
解释："as" 是 "mass" 的子字符串，"hero" 是 "superhero" 的子字符串。
["hero","as"] 也是有效的答案。
```

**示例 2：**

```
输入：words = ["leetcode","et","code"]
输出：["et","code"]
解释："et", "code" 都是 "leetcode" 的子字符串。
```

**示例 3：**

```
输入：words = ["blue","green","bu"]
输出：[]
```

**提示：**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 30`
- `words[i]` 仅包含小写英文字母
- `words` 中的所有字符串**互不相同**

## 解题思路

**暴力双重循环：** 对每个单词 `words[i]`，遍历其他所有单词 `words[j]`（`j != i`），检查 `words[i]` 是否是 `words[j]` 的子字符串。

Python 中用 `in` 运算符可以直接判断子字符串关系：`words[i] in words[j]`。

由于数据规模小（words.length ≤ 100，每个单词长度 ≤ 30），O(n^2 * L) 完全够用。

## Python 代码实现

### 方法一：双重循环 + in 运算符（推荐）

```python
from typing import List

class Solution:
    def stringMatching(self, words: List[str]) -> List[str]:
        result = []
        n = len(words)
        for i in range(n):
            for j in range(n):
                if i != j and words[i] in words[j]:
                    # words[i] 是 words[j] 的子字符串
                    result.append(words[i])
                    break  # 找到一个即可，不重复添加
        return result
```

### 方法二：列表推导式（Python 简洁写法）

```python
from typing import List

class Solution:
    def stringMatching(self, words: List[str]) -> List[str]:
        return [
            word
            for word in words
            # 检查 word 是否是其他任意一个单词的子字符串
            if any(word in other for other in words if other != word)
        ]
```

### 方法三：拼接字符串（巧妙方法）

```python
from typing import List

class Solution:
    def stringMatching(self, words: List[str]) -> List[str]:
        # 将所有单词用特殊分隔符连接成一个大字符串
        # 这样 words[i] in big_str 会匹配所有出现位置，包括在其他单词中
        # 但因为分隔符存在，不会跨单词匹配
        big_str = ' '.join(words)
        result = []
        for word in words:
            # 在 big_str 中，word 会出现至少一次（是自身），
            # 如果 word 在 big_str 中出现超过一次，说明是其他单词的子字符串
            # 但此方法有问题：word 本身也在 big_str 中，需要额外处理
            # 更简单：检查 big_str 中去掉 word 自身后是否还有匹配
            pass

        # 正确方式：直接排除自身
        return [
            word for word in words
            if big_str.count(word) > 1 or any(word in w for w in words if w != word)
        ]
```

**注意：** 方法三不如方法一直观，推荐方法一或方法二。

### 方法四：使用 KMP/Aho-Corasick（理论进阶）

对于大规模数据，可以用 Aho-Corasick 多模式匹配一次性处理所有模式。但本题数据量小，不需要。

```python
from typing import List

class Solution:
    def stringMatching(self, words: List[str]) -> List[str]:
        # 先按长度排序，短的在前
        # 短字符串更可能是长字符串的子串
        words_sorted = sorted(words, key=len)
        result = []
        n = len(words_sorted)

        for i in range(n):
            # 只需在比 words_sorted[i] 长的单词中查找
            for j in range(i + 1, n):
                if words_sorted[i] in words_sorted[j]:
                    result.append(words_sorted[i])
                    break

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（双重循环） | O(n^2 * L) | O(n) |
| 方法四（排序+剪枝） | O(n^2 * L) 最坏，实际更快 | O(n) |

- n = 100，L = 30，O(n^2 * L) = 300,000 次操作，完全够用。
- Python 的 `in` 运算符底层使用改良的 Boyer-Moore 或 KMP，单次匹配 O(L)。

## 关键点总结

1. Python 的 `word1 in word2` 直接判断子字符串关系，非常方便
2. 双重循环时，`i != j` 排除自身（一个字符串是自身的子字符串，但不满足题意）
3. `break` 避免同一个单词被重复添加到结果中
4. 方法四通过排序和剪枝（只在更长的单词中查找）略微优化

## 易错点

- 忘记排除 `i == j` 的情况：每个单词都是自身的子字符串，不应被计入
- 没有使用 `break`：如果 `words[0]` 既是 `words[1]` 又是 `words[2]` 的子串，没有 `break` 会重复添加
- 注意题目说"互不相同"，所以不会有完全相同的两个单词导致误判
