## 题目描述

给你一个 `n` 个节点的树（也就是一个无环连通无向图），节点编号从 `0` 到 `n - 1`，且恰好有 `n - 1` 条边，每个节点有一个值。树的**根节点**为节点 `0`。

给你一个整数数组 `nums` 和一个二维数组 `edges` 分别表示每个节点的值和树的边。

对于每个节点 `i`，你需要找出离节点 `i` **最近的祖先节点 j`（`j != i`），如果节点 `j` 的值和节点 `i` 的值**互质**，则返回节点 `j`，否则返回 `-1`。

如果两个整数的最大公因子为 `1`，则它们**互质**。

返回一个大小为 `n` 的数组 `ans`，其中 `ans[i]` 是节点 `i` 的满足条件的最近祖先。

**提示：**
- `nums[i]` 在 `1` 到 `50` 之间

## 解题思路

由于节点值在 `1` 到 `50` 之间，可以预计算所有互质对。

DFS 遍历树，维护当前路径（根到当前节点的祖先列表）。对每个节点，枚举与其互质的值（预计算），在路径中找到深度最深的那个节点即为最近互质祖先。

## 代码实现

### 方法一：DFS + 路径维护（推荐）

```python
from typing import List
from collections import defaultdict
from math import gcd

class Solution:
    def getCoprimes(self, nums: List[int], edges: List[List[int]]) -> List[int]:
        n = len(nums)
        
        # 预计算 1-50 中的互质对
        coprimes = defaultdict(list)
        for i in range(1, 51):
            for j in range(1, 51):
                if gcd(i, j) == 1:
                    coprimes[i].append(j)
        
        # 建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        ans = [-1] * n
        # path[v] = 当前路径中值为 v 的节点列表（存(节点编号, 深度)）
        path = defaultdict(list)
        
        def dfs(node, parent, depth):
            # 找最近互质祖先：枚举与 nums[node] 互质的值
            best_depth = -1
            best_node = -1
            for v in coprimes[nums[node]]:
                if path[v]:
                    ancestor_node, ancestor_depth = path[v][-1]
                    if ancestor_depth > best_depth:
                        best_depth = ancestor_depth
                        best_node = ancestor_node
            ans[node] = best_node
            
            # 将当前节点加入路径
            path[nums[node]].append((node, depth))
            
            for neighbor in graph[node]:
                if neighbor != parent:
                    dfs(neighbor, node, depth + 1)
            
            # 回溯
            path[nums[node]].pop()
        
        dfs(0, -1, 0)
        return ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict
from math import gcd

class Solution:
    def getCoprimes(self, nums: List[int], edges: List[List[int]]) -> List[int]:
        n = len(nums)
        
        coprimes = {}
        for i in range(1, 51):
            coprimes[i] = [j for j in range(1, 51) if gcd(i, j) == 1]
        
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        ans = [-1] * n
        path = defaultdict(list)  # 值 -> [(节点, 深度)]
        
        # 迭代 DFS，(节点, 父节点, 深度, 是否回溯)
        stack = [(0, -1, 0, False)]
        
        while stack:
            node, parent, depth, backtrack = stack.pop()
            
            if backtrack:
                path[nums[node]].pop()
                continue
            
            # 找最近互质祖先
            best_depth = -1
            best_node = -1
            for v in coprimes[nums[node]]:
                if path[v]:
                    nd, dd = path[v][-1]
                    if dd > best_depth:
                        best_depth = dd
                        best_node = nd
            ans[node] = best_node
            
            path[nums[node]].append((node, depth))
            # 先压入回溯标记
            stack.append((node, parent, depth, True))
            
            for neighbor in graph[node]:
                if neighbor != parent:
                    stack.append((neighbor, node, depth + 1, False))
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n * 50)，每个节点枚举最多 50 个互质值
- **空间复杂度**：O(n + 50^2)

## 关键点总结

1. 预计算互质对，避免重复计算 gcd
2. 维护路径上每种值的节点栈，快速查找最近祖先
3. DFS 时在路径中查找，回溯时撤销

## 易错点

- 回溯时需要从路径中删除当前节点
- 找最近祖先时要比较深度，取深度最大的
