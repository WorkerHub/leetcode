## 题目描述

给你一个 `m x n` 的整数矩阵 `mat` 和一个整数 `target`。

从矩阵的每一行中选择一个整数，你的目标是让**所选元素之和**与 `target` 的**绝对差最小**。

返回所选元素之和与 `target` 的**最小绝对差**。

**示例 1：**
```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], target = 13
输出：0
解释：选 1+6+6? 不对... 选 1+5+7=13
```

**示例 2：**
```
输入：mat = [[1],[2],[3]], target = 100
输出：94
```

**提示：**
- `m == mat.length`，`n == mat[i].length`
- `1 <= m, n <= 70`
- `1 <= mat[i][j] <= 70`
- `1 <= target <= 800`

---

## 解题思路

### 核心思想：DP + 集合去重

用集合（或位运算）维护当前可能的所有行选择之和，逐行枚举并更新。

- 初始集合 `sums = {0}`
- 对每一行，将集合中每个值加上本行每个元素，得到新集合
- 为控制复杂度，每行处理后对集合剪枝（只保留 <= target + max_per_row * remaining_rows 范围内的值）

由于矩阵元素 1-70，m、n 最大 70，总和最大 70 * 70 = 4900，集合大小有界。

## 代码实现

### 方法一：集合 DP（推荐）

```python
from typing import List

class Solution:
    def minimizeTheDifference(self, mat: List[List[int]], target: int) -> int:
        # 当前可能的所有和的集合
        dp = {0}
        for row in mat:
            # 新集合 = 旧集合中每个值 + 本行每个元素
            new_dp = set()
            row_vals = set(row)  # 去重减少运算
            for s in dp:
                for v in row_vals:
                    new_dp.add(s + v)
            dp = new_dp

        return min(abs(s - target) for s in dp)
```

### 方法二：位运算优化

```python
from typing import List

class Solution:
    def minimizeTheDifference(self, mat: List[List[int]], target: int) -> int:
        MAX_SUM = 70 * 70 + 1  # 最大可能总和

        # 用整数的二进制位表示哪些和可以达到
        dp = 1  # 初始只有 0（第 0 位为 1）

        for row in mat:
            # 本行所有可能值的位掩码
            row_mask = 0
            for v in set(row):
                row_mask |= 1 << v
            # 新 dp：对 row_mask 中每个 v，将 dp 左移 v 位，取并集
            new_dp = 0
            v = 1
            tmp = row_mask
            while tmp:
                if tmp & 1:
                    new_dp |= dp << v
                tmp >>= 1
                v += 1
            dp = new_dp

        # 找最接近 target 的可达和
        ans = float('inf')
        for s in range(MAX_SUM + 1):
            if dp >> s & 1:
                ans = min(ans, abs(s - target))
        return ans
```

### 方法三：排序行 + 集合（剪枝优化）

```python
from typing import List

class Solution:
    def minimizeTheDifference(self, mat: List[List[int]], target: int) -> int:
        dp = {0}
        # 每行排序，用于剪枝
        for row in mat:
            sorted_row = sorted(set(row))
            new_dp = set()
            for s in dp:
                for v in sorted_row:
                    new_dp.add(s + v)
            dp = new_dp

        return min(abs(s - target) for s in dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合 DP | O(m * n * S)，S 为可达和数目 | O(S) |
| 位运算 | O(m * max_val * S/64) | O(S/64) |

S 最大约 4900，整体可接受。

---

## 关键点总结

1. 集合 DP：每行扩展可达和集合
2. 行内去重（`set(row)`）减少重复计算
3. 位运算优化空间和速度

---

## 易错点

- 总和上限 = 每行最大值之和 = 70 * 70 = 4900，不会溢出
- 最终求 `min(abs(s-target))`，不是 `target - s`
