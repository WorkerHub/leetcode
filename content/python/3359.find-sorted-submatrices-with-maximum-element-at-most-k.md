## 题目描述

给你一个 `n x m` 的整数矩阵 `grid` 和一个整数 `k`。

返回 `grid` 中满足以下条件的子矩阵数目：
1. 子矩阵中每列（从上到下）都是严格递减的。
2. 子矩阵的最大元素 <= `k`。

**提示：**
- `1 <= n, m <= 1000`
- `1 <= grid[i][j] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

**逐列处理 + 单调栈：**

对每一列，首先找出"合法高度"：从某行开始向上，连续严格递减的行数。

定义 `h[i][j]` = 从 `(i, j)` 向上，连续严格递减（`grid[r][j] > grid[r+1][j]`）的最大长度（含 `(i, j)` 本身）。

然后，对于每行 `i`，找满足以下条件的子矩阵：
- 行范围：从 `(i - height + 1, j)` 到 `(i, j)` 中高度 `h` 的矩形。
- 最大元素 <= k（需要检查矩阵内所有元素 <= k）。

这道题的完整解法较复杂，下面提供基础的暴力实现。

## Python 代码实现

### 方法一：暴力枚举（适合小规模数据）

```python
from typing import List

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        n, m = len(grid), len(grid[0])
        count = 0
        
        # 枚举所有子矩阵
        for r1 in range(n):
            for c1 in range(m):
                for r2 in range(r1, n):
                    for c2 in range(c1, m):
                        # 检查子矩阵 [r1..r2, c1..c2]
                        valid = True
                        max_val = 0
                        
                        # 检查每列严格递减
                        for c in range(c1, c2 + 1):
                            for r in range(r1, r2):
                                if grid[r][c] <= grid[r+1][c]:
                                    valid = False
                                    break
                            if not valid:
                                break
                        
                        if not valid:
                            continue
                        
                        # 检查最大元素
                        for r in range(r1, r2 + 1):
                            for c in range(c1, c2 + 1):
                                max_val = max(max_val, grid[r][c])
                        
                        if max_val <= k:
                            count += 1
        
        return count
```

### 方法二：预处理高度 + 行列枚举

```python
from typing import List

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        n, m = len(grid), len(grid[0])
        
        # h[i][j] = 从 (i, j) 向上连续严格递减的长度（含自身）
        h = [[1] * m for _ in range(n)]
        for i in range(1, n):
            for j in range(m):
                if grid[i-1][j] > grid[i][j]:
                    h[i][j] = h[i-1][j] + 1
        
        count = 0
        
        # 对每行 i，枚举所有满足条件的以行 i 结尾的子矩阵
        for i in range(n):
            # 对列区间 [c1, c2]，子矩阵高度 = min(h[i][c1..c2])
            # 最大元素 <= k 要求每个 grid[r][c] <= k
            
            for c1 in range(m):
                min_h = h[i][c1]
                for c2 in range(c1, m):
                    min_h = min(min_h, h[i][c2])
                    
                    # 子矩阵行范围：[i - min_h + 1, i]，列范围：[c1, c2]
                    # 检查最大元素
                    max_val = 0
                    valid = True
                    for r in range(i - min_h + 1, i + 1):
                        for c in range(c1, c2 + 1):
                            if grid[r][c] > k:
                                valid = False
                                break
                        if not valid:
                            break
                    
                    if valid:
                        count += 1
        
        return count
```

## 复杂度分析

- 时间复杂度：O(n^2 * m^2)，暴力
- 空间复杂度：O(n * m)

## 关键点总结

1. 每列严格递减的子矩阵高度可以用 `h[i][j]` 预处理。
2. 对每行枚举列区间，最小化高度为各列高度的最小值。
3. 额外需要检查最大元素 <= k 的约束。

## 易错点

1. 列递减方向：严格递减是 `grid[r-1][j] > grid[r][j]`（从上到下严格减小）。
2. 子矩阵高度 = min(h[c1], ..., h[c2])，随列增加而可能减少。
3. 最大元素约束和列递减约束是独立的两个条件，都需要满足。
