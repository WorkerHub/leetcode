## 题目描述

给你一个正整数 `k`，统计有多少种方式可以将 `k` 表示为若干个**连续正整数**之和。

**示例 1：**

```
输入：k = 5
输出：2
解释：5 = 5 = 2+3，共 2 种。
```

**示例 2：**

```
输入：k = 9
输出：3
解释：9 = 9 = 4+5 = 2+3+4，共 3 种。
```

**提示：**
- `1 <= k <= 10^9`

## 解题思路

设从 `a` 开始的 `n` 个连续正整数之和：
`a + (a+1) + ... + (a+n-1) = n*a + n*(n-1)/2 = k`

所以 `n*a = k - n*(n-1)/2`，即 `a = (k - n*(n-1)/2) / n`。

要使 `a` 为正整数：
1. `k - n*(n-1)/2 > 0`，即 `n*(n-1)/2 < k`，故 `n < (1 + sqrt(1 + 8k)) / 2`。
2. `(k - n*(n-1)/2)` 能被 `n` 整除。

## Python 代码实现

### 方法一：枚举连续段长度（推荐）

```python
class Solution:
    def consecutiveNumbersSum(self, k: int) -> int:
        count = 0
        n = 1

        while n * (n - 1) // 2 < k:
            remainder = k - n * (n - 1) // 2
            if remainder % n == 0:
                count += 1
            n += 1

        return count
```

### 方法二：因子分析

```python
class Solution:
    def consecutiveNumbersSum(self, k: int) -> int:
        # k = n*a + n*(n-1)/2 => 2k = n*(2a + n - 1)
        # 设 n 和 (2a + n - 1)，两者之积 = 2k，一奇一偶
        count = 0
        n = 1

        while True:
            # 需要 2k - n*(n-1) > 0 且能被 n 整除
            val = 2 * k - n * (n - 1)
            if val <= 0:
                break
            if val % (2 * n) == 0:
                count += 1
            n += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(sqrt(k))，n 最大约为 sqrt(2k)
- 空间复杂度：O(1)

## 关键点总结

1. 设连续段长度为 n，起始值为 a，由 `n*a + n*(n-1)/2 = k` 求 a。
2. n 的上界约为 sqrt(2k)，枚举 n 即可。
3. 条件：`k - n*(n-1)/2` 为正数且能被 n 整除。

## 易错点

1. 起始值 a 必须为正整数（>= 1），不能为 0 或负数。
2. n 的上界通过 `n*(n-1)/2 < k` 确定，不要超出。
3. 注意与问题 829（同名但可能不同）的区分。
