## 题目描述

给你一个整数数组 `arr`，请你将该数组分隔为长度最多为 `k` 的一些（连续）子数组。分隔完成后，每个子数组的中的所有值都会变为该子数组中的最大值。

返回将数组分隔变换后能够得到的元素最大和。本题所用到的测试用例会确保答案是一个 32 位整数。

**示例 1：**
```
输入：arr = [1,15,7,9,2,5,10], k = 3
输出：84
解释：
数组变为 [15,15,15,9,10,10,10]
最优分隔：[1,15,7], [9], [2,5,10]
- [1,15,7] -> 最大值15，和 = 15*3 = 45
- [9] -> 最大值9，和 = 9*1 = 9
- [2,5,10] -> 最大值10，和 = 10*3 = 30
总和 = 45 + 9 + 30 = 84
```

**示例 2：**
```
输入：arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
输出：83
```

**示例 3：**
```
输入：arr = [1], k = 1
输出：1
```

**提示：**
- `1 <= arr.length <= 500`
- `0 <= arr[i] <= 10^9`
- `1 <= k <= arr.length`

## 解题思路

这是一道经典的动态规划题目，需要找到最优的分隔方案。

### 动态规划思路

**定义状态**：
- `dp[i]` 表示前 `i` 个元素（`arr[0...i-1]`）能够得到的最大和

**状态转移**：
对于位置 `i`，我们可以尝试将最后 `j` 个元素（`1 <= j <= min(k, i)`）作为一个子数组：
- 这个子数组的范围是 `arr[i-j...i-1]`
- 子数组的最大值为 `max(arr[i-j...i-1])`
- 子数组的和为 `j * max_value`
- 转移方程：`dp[i] = max(dp[i-j] + j * max_value)` for all valid j

**边界条件**：
- `dp[0] = 0`（空数组的和为0）

**目标**：
- 返回 `dp[n]`，其中 n 是数组长度

### 优化思路

可以使用滚动数组或者从后向前遍历来优化空间复杂度。

## Python 代码实现

### 方法一：动态规划（标准解法）

```python
from typing import List

class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        n = len(arr)
        # dp[i] 表示前 i 个元素的最大和
        dp = [0] * (n + 1)
        
        # 遍历每个位置
        for i in range(1, n + 1):
            max_val = 0
            max_sum = 0
            
            # 尝试最后 j 个元素作为一个子数组
            for j in range(1, min(k, i) + 1):
                # 当前子数组的最大值
                max_val = max(max_val, arr[i - j])
                # 当前分隔方案的总和
                current_sum = dp[i - j] + j * max_val
                max_sum = max(max_sum, current_sum)
            
            dp[i] = max_sum
        
        return dp[n]
```

### 方法二：逆向动态规划

```python
from typing import List

class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        n = len(arr)
        # dp[i] 表示从 i 开始到末尾的最大和
        dp = [0] * (n + 1)
        
        # 从后向前遍历
        for i in range(n - 1, -1, -1):
            max_val = 0
            max_sum = 0
            
            # 尝试从 i 开始的 length 个元素作为子数组
            for length in range(1, min(k, n - i) + 1):
                # 更新子数组最大值
                max_val = max(max_val, arr[i + length - 1])
                # 当前分隔的总和
                current_sum = length * max_val + dp[i + length]
                max_sum = max(max_sum, current_sum)
            
            dp[i] = max_sum
        
        return dp[0]
```

### 方法三：详细注释版（便于理解）

```python
from typing import List

class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        """
        动态规划求解数组分隔最大和
        
        思路：
        dp[i] = 前 i 个元素的最大和
        对于每个位置 i，尝试最后 1-k 个元素作为一个子数组
        """
        n = len(arr)
        
        # 初始化 dp 数组
        # dp[i] 表示 arr[0...i-1] 的最大和
        dp = [0] * (n + 1)
        
        # 遍历每个位置
        for i in range(1, n + 1):
            max_val = 0  # 当前子数组的最大值
            
            # 尝试不同的分隔长度 j (1 <= j <= min(k, i))
            for j in range(1, min(k, i) + 1):
                # 子数组范围：arr[i-j...i-1]
                # 更新这个子数组的最大值
                max_val = max(max_val, arr[i - j])
                
                # 计算当前分隔方案的总和
                # = (前 i-j 个元素的最大和) + (最后 j 个元素变成最大值后的和)
                # = dp[i-j] + j * max_val
                current_sum = dp[i - j] + j * max_val
                
                # 更新 dp[i]
                dp[i] = max(dp[i], current_sum)
        
        return dp[n]
```

### 方法四：优化版（变量命名更清晰）

```python
from typing import List

class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        n = len(arr)
        dp = [0] * (n + 1)
        
        for end in range(1, n + 1):
            # 尝试最后一个子数组的不同起始位置
            for start in range(max(0, end - k), end):
                # 子数组长度
                length = end - start
                # 子数组最大值
                max_in_partition = max(arr[start:end])
                # 更新最大和
                dp[end] = max(dp[end], dp[start] + length * max_in_partition)
        
        return dp[n]
```

### 方法五：记忆化搜索（递归版本）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        n = len(arr)
        
        @lru_cache(None)
        def dp(index: int) -> int:
            """返回从 index 到末尾的最大和"""
            if index >= n:
                return 0
            
            max_sum = 0
            max_val = 0
            
            # 尝试从 index 开始的不同长度子数组
            for length in range(1, min(k, n - index) + 1):
                max_val = max(max_val, arr[index + length - 1])
                current_sum = length * max_val + dp(index + length)
                max_sum = max(max_sum, current_sum)
            
            return max_sum
        
        return dp(0)
```

## 复杂度分析

- **时间复杂度**：O(n * k)
  - 外层循环遍历 n 个位置
  - 内层循环最多遍历 k 次
  - 总时间复杂度 O(n * k)

- **空间复杂度**：O(n)
  - dp 数组需要 O(n) 空间
  - 记忆化搜索的递归栈深度为 O(n)

## 关键点总结

1. **动态规划定义**：`dp[i]` 表示前 i 个元素的最大和
2. **子问题划分**：尝试最后 1-k 个元素作为一个子数组
3. **状态转移**：`dp[i] = max(dp[i-j] + j * max(arr[i-j...i-1]))`
4. **最大值维护**：在内层循环中逐步更新子数组最大值，避免重复计算
5. **边界处理**：`dp[0] = 0`，`j` 的范围是 `1` 到 `min(k, i)`

## 易错点

1. **索引转换**：
   - `dp[i]` 表示前 i 个元素，对应 `arr[0...i-1]`
   - 访问数组时注意下标：`arr[i-j]` 而不是 `arr[i-j-1]`

2. **最大值计算**：
   - 不要每次都用 `max(arr[i-j:i])`，时间复杂度会退化
   - 应该在循环中逐步更新：`max_val = max(max_val, arr[i-j])`

3. **边界条件**：
   - `j` 的上界是 `min(k, i)`，不能超过当前位置
   - 防止数组越界

4. **初始化**：
   - `dp` 数组大小应该是 `n+1`，不是 `n`
   - `dp[0] = 0` 表示空数组

5. **理解题意**：
   - 每个子数组的所有元素都变成该子数组的最大值
   - 求的是变换后的总和，不是原数组的和
