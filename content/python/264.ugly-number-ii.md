## 题目描述

给你一个整数 `n`，请你找出并返回第 `n` 个丑数。

丑数是只包含质因数 `2`、`3` 和 `5` 的正整数。

**示例 1：**
```
输入: n = 10
输出: 12
解释: [1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是前 10 个丑数
```

**示例 2：**
```
输入: n = 1
输出: 1
解释: 1 没有质因数，被视为第 1 个丑数
```

**提示：**
- `1 <= n <= 1690`

## 解题思路

这道题是"丑数 I"的进阶版，不能简单地逐个判断，因为时间复杂度太高。

**核心观察：**
- 丑数可以由前面的丑数乘以 2、3 或 5 得到
- 第一个丑数是 1
- 后续丑数 = min(前面某个丑数 × 2, 前面某个丑数 × 3, 前面某个丑数 × 5)

**三种经典解法：**

### 解法 1：三指针动态规划（最优）
- 维护三个指针 p2, p3, p5，分别指向待乘以 2、3、5 的丑数位置
- 每次选择三者中的最小值作为下一个丑数
- 更新对应的指针

### 解法 2：最小堆
- 使用堆维护候选丑数
- 每次取出最小值，并生成新的候选（乘以 2、3、5）
- 使用集合去重

### 解法 3：暴力 + 判断（不推荐）
- 逐个判断每个数是否为丑数
- 时间复杂度过高，不推荐

## Python 代码实现

### 方法一：三指针动态规划（推荐）⭐

```python
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        # dp[i] 表示第 i+1 个丑数
        dp = [0] * n
        dp[0] = 1  # 第一个丑数是 1
        
        # 三个指针，分别指向待乘以 2、3、5 的丑数位置
        p2 = p3 = p5 = 0
        
        for i in range(1, n):
            # 计算三个候选值
            num2 = dp[p2] * 2
            num3 = dp[p3] * 3
            num5 = dp[p5] * 5
            
            # 选择最小的作为下一个丑数
            dp[i] = min(num2, num3, num5)
            
            # 更新指针（注意：可能同时满足多个条件，都要更新）
            if dp[i] == num2:
                p2 += 1
            if dp[i] == num3:
                p3 += 1
            if dp[i] == num5:
                p5 += 1
        
        return dp[n - 1]
```

### 方法二：最小堆

```python
import heapq

class Solution:
    def nthUglyNumber(self, n: int) -> int:
        # 最小堆，初始只有 1
        heap = [1]
        seen = {1}  # 去重集合
        
        ugly = 1
        for _ in range(n):
            # 取出当前最小的丑数
            ugly = heapq.heappop(heap)
            
            # 生成新的候选丑数
            for factor in [2, 3, 5]:
                new_ugly = ugly * factor
                if new_ugly not in seen:
                    seen.add(new_ugly)
                    heapq.heappush(heap, new_ugly)
        
        return ugly
```

### 方法三：优化的三指针（更清晰的写法）

```python
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        ugly = [1]  # 丑数列表
        i2 = i3 = i5 = 0  # 三个指针
        
        while len(ugly) < n:
            # 计算下一个候选
            next2 = ugly[i2] * 2
            next3 = ugly[i3] * 3
            next5 = ugly[i5] * 5
            
            # 选择最小值
            next_ugly = min(next2, next3, next5)
            ugly.append(next_ugly)
            
            # 移动指针（可能同时移动多个）
            if next_ugly == next2:
                i2 += 1
            if next_ugly == next3:
                i3 += 1
            if next_ugly == next5:
                i5 += 1
        
        return ugly[-1]
```

### 方法四：数学方法（打表）

```python
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        """
        由于 n 最大为 1690，可以预计算所有丑数
        适合多次调用的场景
        """
        if not hasattr(Solution, 'ugly_numbers'):
            # 首次调用时计算所有丑数
            ugly = [1]
            i2 = i3 = i5 = 0
            
            while len(ugly) < 1690:
                next_ugly = min(ugly[i2] * 2, ugly[i3] * 3, ugly[i5] * 5)
                ugly.append(next_ugly)
                
                if next_ugly == ugly[i2] * 2:
                    i2 += 1
                if next_ugly == ugly[i3] * 3:
                    i3 += 1
                if next_ugly == ugly[i5] * 5:
                    i5 += 1
            
            Solution.ugly_numbers = ugly
        
        return Solution.ugly_numbers[n - 1]
```

## 复杂度分析

### 方法一（三指针动态规划）
- **时间复杂度**：O(n)，需要计算 n 个丑数，每次 O(1) 操作
- **空间复杂度**：O(n)，存储 n 个丑数

### 方法二（最小堆）
- **时间复杂度**：O(n log n)，堆操作 log n，执行 n 次
- **空间复杂度**：O(n)，堆和集合最多存储 O(n) 个元素

第 5 步:
  候选: 3×2=6, 3×3=9, 2×5=10

## 关键点总结

1. **动态规划思想**：每个丑数都由前面的丑数乘以 2、3 或 5 得到
2. **三指针维护**：
   - p2 指向待乘以 2 的位置
   - p3 指向待乘以 3 的位置
   - p5 指向待乘以 5 的位置
3. **去重关键**：同时满足多个条件时，所有指针都要移动
   - 例如：6 = 2×3 = 3×2，p2 和 p3 都要移动
4. **时间优化**：三指针法 O(n) 优于堆方法 O(n log n)
5. **空间优化**：可以预计算（打表），适合多次查询

## 易错点

1. **指针更新错误**：必须使用 if 而不是 elif
   ```python
   # 错误写法
   if dp[i] == num2:
       p2 += 1
   elif dp[i] == num3:  # ❌ 应该用 if
       p3 += 1
   
   # 正确写法：都用 if，因为可能同时满足
   if dp[i] == num2:
       p2 += 1
   if dp[i] == num3:
       p3 += 1
   ```

2. **初始值设置**：dp[0] = 1，第一个丑数是 1

3. **返回值错误**：返回 dp[n-1] 而不是 dp[n]

4. **堆方法的去重**：必须使用集合去重，否则会有重复

5. **边界情况**：n = 1 时直接返回 1
