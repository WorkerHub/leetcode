## 题目描述

将非负整数 num 转换为其对应的英文表示。

**示例 1：**
```
输入: num = 123
输出: "One Hundred Twenty Three"
```

**示例 2：**
```
输入: num = 12345
输出: "Twelve Thousand Three Hundred Forty Five"
```

**示例 3：**
```
输入: num = 1234567
输出: "One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven"
```

**提示：**
- 0 <= num <= 2^31 - 1

## 解题思路

这道题看似复杂，但只要找到规律就不难。

### 核心思路

英文数字的表示有规律：
1. **基本单位**：个位（0-9）、十位（10-19）、整十位（20-90）
2. **更大单位**：Hundred（百）、Thousand（千）、Million（百万）、Billion（十亿）

### 关键观察

1. 数字可以按照每三位分组：个、千、百万、十亿
   - 1234567 = 1,234,567 = 1 Million, 234 Thousand, 567
   
2. 每组内部的处理方式相同：
   - 百位 + "Hundred"
   - 十位和个位（特殊处理 10-19）

3. 特殊情况：
   - 0 单独处理为 "Zero"
   - 10-19 有特殊单词（Eleven, Twelve 等）
   - 避免多余空格

### 算法步骤

1. 准备单词映射表
2. 按照 Billion、Million、Thousand 的顺序处理每组
3. 每组内部按照百位、十位、个位处理
4. 拼接结果，去除多余空格

## Python 代码实现

### 方法一：递归分组处理（推荐）

```python
class Solution:
    def numberToWords(self, num: int) -> str:
        """
        将数字转换为英文表示
        """
        if num == 0:
            return "Zero"
        
        # 基础数字映射
        below_20 = ["", "One", "Two", "Three", "Four", "Five", "Six", "Seven",
                    "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen",
                    "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen",
                    "Nineteen"]
        
        tens = ["", "", "Twenty", "Thirty", "Forty", "Fifty", 
                "Sixty", "Seventy", "Eighty", "Ninety"]
        
        thousands = ["", "Thousand", "Million", "Billion"]
        
        def helper(n):
            """
            处理小于 1000 的数字
            """
            if n == 0:
                return ""
            elif n < 20:
                return below_20[n] + " "
            elif n < 100:
                return tens[n // 10] + " " + helper(n % 10)
            else:
                return below_20[n // 100] + " Hundred " + helper(n % 100)
        
        result = ""
        # 从低位到高位，每三位处理一次
        for i in range(len(thousands)):
            if num % 1000 != 0:
                result = helper(num % 1000) + thousands[i] + " " + result
            num //= 1000
        
        # 去除多余空格
        return result.strip()
```

### 方法二：迭代处理

```python
class Solution:
    def numberToWords(self, num: int) -> str:
        """
        迭代方式处理每一组
        """
        if num == 0:
            return "Zero"
        
        # 基础单词
        ones = ["", "One", "Two", "Three", "Four", "Five", "Six", "Seven",
                "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen",
                "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen",
                "Nineteen"]
        
        tens = ["", "", "Twenty", "Thirty", "Forty", "Fifty",
                "Sixty", "Seventy", "Eighty", "Ninety"]
        
        def convert_below_thousand(n):
            """
            转换小于 1000 的数字
            """
            if n == 0:
                return ""
            elif n < 20:
                return ones[n]
            elif n < 100:
                return tens[n // 10] + ("" if n % 10 == 0 else " " + ones[n % 10])
            else:
                hundred = ones[n // 100] + " Hundred"
                rest = convert_below_thousand(n % 100)
                return hundred + ("" if not rest else " " + rest)
        
        # 处理每个单位
        billion = num // 1_000_000_000
        million = (num // 1_000_000) % 1000
        thousand = (num // 1000) % 1000
        remainder = num % 1000
        
        result = []
        
        if billion:
            result.append(convert_below_thousand(billion) + " Billion")
        if million:
            result.append(convert_below_thousand(million) + " Million")
        if thousand:
            result.append(convert_below_thousand(thousand) + " Thousand")
        if remainder:
            result.append(convert_below_thousand(remainder))
        
        return " ".join(result)
```

### 方法三：完全展开版本（易理解）

```python
class Solution:
    def numberToWords(self, num: int) -> str:
        """
        完全展开的版本，逻辑更清晰
        """
        if num == 0:
            return "Zero"
        
        # 1-19 的单词
        self.below_20 = ["", "One", "Two", "Three", "Four", "Five", "Six",
                         "Seven", "Eight", "Nine", "Ten", "Eleven", "Twelve",
                         "Thirteen", "Fourteen", "Fifteen", "Sixteen",
                         "Seventeen", "Eighteen", "Nineteen"]
        
        # 整十的单词
        self.tens = ["", "", "Twenty", "Thirty", "Forty", "Fifty",
                     "Sixty", "Seventy", "Eighty", "Ninety"]
        
        # 单位
        self.thousands = ["Billion", "Million", "Thousand", ""]
        
        return self.int_to_string(num).strip()
    
    def int_to_string(self, num):
        """
        递归转换
        """
        if num == 0:
            return ""
        elif num < 20:
            return self.below_20[num] + " "
        elif num < 100:
            return self.tens[num // 10] + " " + self.int_to_string(num % 10)
        elif num < 1000:
            return self.below_20[num // 100] + " Hundred " + self.int_to_string(num % 100)
        else:
            # 处理 thousand, million, billion
            for i, word in enumerate(self.thousands):
                if num >= 1000 ** (4 - i):
                    return self.int_to_string(num // (1000 ** (4 - i))) + word + " " + \
                           self.int_to_string(num % (1000 ** (4 - i)))
```

## 复杂度分析

**时间复杂度：** O(1)
- 虽然有循环和递归，但数字最大为 2^31 - 1
- 最多处理 4 组（Billion, Million, Thousand, 个位）
- 可以认为是常数时间

**空间复杂度：** O(1)
- 使用固定大小的字符串数组
- 递归深度有限（最多 4 层）

## 关键点总结

1. **分组思想**：按照每三位分组，分别处理 Billion、Million、Thousand
2. **递归处理**：每组内部可以用递归处理百位、十位、个位
3. **特殊情况**：
   - 0 单独返回 "Zero"
   - 10-19 有特殊单词
   - 避免多余空格
4. **边界处理**：每组为 0 时不添加单位词
5. **字符串处理**：使用 strip() 去除首尾空格

## 易错点

1. **0 的处理**：单独处理，直接返回 "Zero"
   ```python
   if num == 0:
       return "Zero"
   ```

2. **10-19 的特殊处理**：这些数字有独立的单词
   ```python
   below_20 = ["", "One", ..., "Nineteen"]  # 包含 10-19
   ```

3. **空格处理**：避免多余空格
   ```python
   # 错误：可能产生连续空格
   result = "One  Hundred"  # 两个空格
   
   # 正确：最后统一去除
   return result.strip()
   ```

4. **分组边界**：每组为 0 时不添加单位
   ```python
   if num % 1000 != 0:  # 只有非 0 时才处理
       result = helper(num % 1000) + thousands[i] + " " + result
   ```

5. **单词拼写**：注意英文单词的正确拼写
   - Forty (不是 Fourty)
   - Twelve (不是 Tweleve)
