## 题目描述

给你两个字符串 `s` 和 `pattern`。

如果一个字符串与 `pattern` **至多有一个位置**的字符不同，则称该字符串与 `pattern` "几乎相等"。

返回 `s` 中 `pattern` 的"几乎相等"子串第一次出现的起始下标。若不存在，返回 `-1`。

**示例 1：**
```
输入：s = "abcdefg", pattern = "bcdffg"
输出：1
解释：s[1..6] = "bcdefg"，与 "bcdffg" 只在下标 3 处不同（'e' vs 'f'）
```

**示例 2：**
```
输入：s = "ababbababa", pattern = "bacaba"
输出：4
```

**提示：**
- `1 <= pattern.length <= s.length <= 10^5`
- `s` 和 `pattern` 只含小写英文字母

## 解题思路

**Z 函数（Z-array）方法：**

1. 构造 Z 函数：`z[i]` 表示从 `s[i]` 开始的子串与 `s` 的公共前缀长度。

2. 对于每个位置 `i`（`0 <= i <= n - m`），我们需要验证 `s[i:i+m]` 与 `pattern` 是否几乎相等：
   - 使用 `z_prefix[i]`（前向 Z 函数）得到从 `i` 开始能匹配 `pattern` 的最长前缀长度 `l`。
   - 使用 `z_suffix[i]`（后向 Z 函数）得到从 `s[i+m-1]` 向左能匹配 `pattern` 末尾的最长后缀长度 `r`。
   - 若 `l + r >= m - 1`，则该位置符合条件（只有中间最多一个不匹配）。

3. 构造 `pattern + '#' + s` 的 Z 函数得到前缀匹配信息。
4. 构造 `reverse(pattern) + '#' + reverse(s)` 的 Z 函数得到后缀匹配信息。

## Python 代码实现

### 方法一：Z 函数（推荐）

```python
class Solution:
    def minStartingIndex(self, s: str, pattern: str) -> int:
        def z_function(t: str):
            n = len(t)
            z = [0] * n
            z[0] = n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and t[z[i]] == t[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z
        
        n, m = len(s), len(pattern)
        
        # 前向 Z 函数：pattern + '#' + s
        # z_pre[m+1+i] 表示 s[i:] 与 pattern 的最长公共前缀
        z_pre = z_function(pattern + '#' + s)
        
        # 后向 Z 函数：reverse(pattern) + '#' + reverse(s)
        # 对应 s 位置 i 的后缀匹配长度需要转换
        z_suf = z_function(pattern[::-1] + '#' + s[::-1])
        
        for i in range(n - m + 1):
            # 从 i 开始，s[i:] 与 pattern 的最长公共前缀
            l = min(z_pre[m + 1 + i], m)
            # 从 s[i+m-1] 结尾往左，与 pattern 末尾的最长公共后缀
            # 对应反转后的位置 n - (i + m)
            r = min(z_suf[m + 1 + (n - i - m)], m)
            # 若前缀+后缀覆盖了 m-1 个字符（最多差1个），则合法
            if l + r >= m - 1:
                return i
        
        return -1
```

### 方法二：暴力（仅适用于小数据）

```python
class Solution:
    def minStartingIndex(self, s: str, pattern: str) -> int:
        n, m = len(s), len(pattern)
        for i in range(n - m + 1):
            diff = 0
            for j in range(m):
                if s[i + j] != pattern[j]:
                    diff += 1
                if diff > 1:
                    break
            if diff <= 1:
                return i
        return -1
```

## 复杂度分析

- 时间复杂度：O(n + m)，Z 函数构造和遍历均为线性
- 空间复杂度：O(n + m)，Z 函数数组的空间

## 关键点总结

1. Z 函数能在 O(n) 时间内计算字符串所有位置与前缀的最长公共前缀。
2. 同时计算前向和后向的 Z 函数，可以快速判断"至多一处不同"的条件。
3. 合并条件：`前缀匹配长度 + 后缀匹配长度 >= m - 1`。

## 易错点

1. Z 函数拼接时 `#` 分隔符必不可少，防止 pattern 和 s 之间的越界匹配。
2. 后向 Z 函数需要对字符串取反，下标转换容易出错。
3. `min(z_pre[...], m)` 防止前缀匹配超过 pattern 长度。
