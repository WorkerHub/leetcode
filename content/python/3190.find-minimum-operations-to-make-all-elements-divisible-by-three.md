## 题目描述

给你一个整数数组 `nums`，每次操作可以将任意元素加 1 或减 1。

返回使所有元素都能被 3 整除所需的 **最少** 操作次数。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：3
解释：1->0(减1), 2->3(加1), 4->3(减1)，共3次。
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

对每个元素，计算其模 3 的余数。余数为 0 不需要操作，余数为 1 需要 1 次（减 1），余数为 2 也需要 1 次（加 1）。

## Python 代码实现

### 方法一：统计余数（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        ans = 0
        for x in nums:
            r = x % 3
            if r != 0:
                ans += 1  # r=1 减1, r=2 加1，都是1次操作
        return ans
```

### 方法二：更简洁

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        return sum(1 for x in nums if x % 3 != 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个元素只需 1 次操作即可变为 3 的倍数（余数为 1 减 1，余数为 2 加 1）
2. 统计余数非 0 的元素个数

## 易错点

1. 余数为 2 时，加 1 比减 2 操作次数少（1 < 2）
2. 余数为 0 时不需要操作
