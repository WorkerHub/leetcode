## 题目描述

给定一个正整数 n，找到并返回 n 的二进制表示中两个 相邻 1 之间的 最长距离 。如果不存在两个相邻的 1，返回 0 。

如果只有 0 将两个 1 分隔开（可能不存在 0 ），则认为这两个 1 彼此 相邻 。两个 1 之间的距离是它们的 位置 之间的绝对差。例如，"1001" 中的两个 1 的距离为 3 。

**示例 1：**
```
输入：n = 22
输出：2
解释：22 的二进制是 "10110" 。
第一个相邻的两个 1 的距离为 2 。
第二个相邻的两个 1 的距离为 1 。
答案取两者中最大的，也就是 2 。
```

**示例 2：**
```
输入：n = 8
输出：0
解释：8 的二进制是 "1000" 。
在 8 的二进制表示中没有相邻的两个 1，所以返回 0 。
```

**提示：**
- 1 <= n <= 10^9

## 解题思路

找到所有 1 的位置，计算相邻 1 之间的最大距离。

## Python 代码实现

### 方法一：位运算（推荐）⭐

```python
class Solution:
    def binaryGap(self, n: int) -> int:
        positions = []
        pos = 0
        
        while n:
            if n & 1:
                positions.append(pos)
            n >>= 1
            pos += 1
        
        if len(positions) < 2:
            return 0
        
        return max(positions[i] - positions[i-1] for i in range(1, len(positions)))
```

### 方法二：字符串

```python
class Solution:
    def binaryGap(self, n: int) -> int:
        binary = bin(n)[2:]  # 去掉 '0b'
        positions = [i for i, c in enumerate(binary) if c == '1']
        
        if len(positions) < 2:
            return 0
        
        return max(positions[i] - positions[i-1] for i in range(1, len(positions)))
```

### 方法三：一次遍历

```python
class Solution:
    def binaryGap(self, n: int) -> int:
        last = -1
        result = 0
        pos = 0
        
        while n:
            if n & 1:
                if last != -1:
                    result = max(result, pos - last)
                last = pos
            n >>= 1
            pos += 1
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(log n)，二进制位数
- **空间复杂度**：O(1) 或 O(log n)

## 关键点总结

1. **位运算**：`n & 1` 检查最低位，`n >>= 1` 右移
2. **记录位置**：所有 1 的位置
3. **计算间距**：相邻位置的差值
