## 题目描述

给定一个二叉搜索树的根节点 root 和一个值 key，删除二叉搜索树中的 key 对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。

一般来说，删除节点可分为两个步骤：

1. 首先找到需要删除的节点
2. 如果找到了，删除它

**示例 1:**

```
输入: root = [5,3,6,2,4,null,7], key = 3
输出: [5,4,6,2,null,null,7]
解释: 给定需要删除的节点值是 3，所以我们首先找到 3 这个节点，然后删除它。
一个正确的答案是 [5,4,6,2,null,null,7]
另一个正确的答案是 [5,2,6,null,4,null,7]
```

**示例 2:**

```
输入: root = [5,3,6,2,4,null,7], key = 0
输出: [5,3,6,2,4,null,7]
解释: 二叉树不包含值为 0 的节点
```

**示例 3:**

```
输入: root = [], key = 0
输出: []
```

**提示:**

- 节点数的范围 [0, 10^4]
- -10^5 <= Node.val <= 10^5
- 节点值唯一
- root 是合法的二叉搜索树
- -10^5 <= key <= 10^5

**进阶:** 要求算法时间复杂度为 O(h)，h 为树的高度。

## 解题思路

删除 BST 节点是一个经典问题，关键在于删除后如何保持 BST 性质。

**删除节点的三种情况：**

1. **叶子节点（无子节点）**：直接删除
2. **只有一个子节点**：用子节点替代被删除节点
3. **有两个子节点**：
   - 找到右子树的最小节点（后继节点）或左子树的最大节点（前驱节点）
   - 用后继/前驱节点的值替换被删除节点的值
   - 递归删除后继/前驱节点

**核心思想：**
- 利用 BST 性质快速定位节点
- 删除后保持 BST 性质：左 < 根 < 右

## Python 代码实现

### 方法一：递归法（推荐）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        """
        递归删除 BST 节点
        时间复杂度: O(h)，h 为树高
        空间复杂度: O(h)，递归栈
        """
        if not root:
            return None
        
        # 在左子树中查找并删除
        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        # 在右子树中查找并删除
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        # 找到要删除的节点
        else:
            # 情况 1: 叶子节点或只有右子树
            if not root.left:
                return root.right
            # 情况 2: 只有左子树
            elif not root.right:
                return root.left
            # 情况 3: 有两个子节点
            else:
                # 找到右子树的最小节点（后继节点）
                min_node = self.findMin(root.right)
                # 用后继节点的值替换当前节点
                root.val = min_node.val
                # 递归删除后继节点
                root.right = self.deleteNode(root.right, min_node.val)
        
        return root
    
    def findMin(self, node: TreeNode) -> TreeNode:
        """找到以 node 为根的子树中的最小节点"""
        while node.left:
            node = node.left
        return node
```

### 方法二：使用前驱节点（左子树最大值）

```python
class Solution:
    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        """
        使用左子树的最大节点（前驱）替代
        """
        if not root:
            return None
        
        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        else:
            # 只有右子树或叶子节点
            if not root.left:
                return root.right
            # 只有左子树
            elif not root.right:
                return root.left
            # 有两个子节点：使用前驱节点
            else:
                # 找到左子树的最大节点
                max_node = self.findMax(root.left)
                root.val = max_node.val
                root.left = self.deleteNode(root.left, max_node.val)
        
        return root
    
    def findMax(self, node: TreeNode) -> TreeNode:
        """找到以 node 为根的子树中的最大节点"""
        while node.right:
            node = node.right
        return node
```

### 方法三：迭代法

```python
class Solution:
    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        """
        迭代实现删除
        时间复杂度: O(h)
        空间复杂度: O(1)
        """
        # 找到要删除的节点及其父节点
        parent = None
        current = root
        
        # 查找目标节点
        while current and current.val != key:
            parent = current
            if key < current.val:
                current = current.left
            else:
                current = current.right
        
        # 未找到目标节点
        if not current:
            return root
        
        # 删除节点
        # 情况 1 和 2: 至少有一个子节点为空
        if not current.left or not current.right:
            # 选择非空子节点，或者 None（都为空的情况）
            new_node = current.left if current.left else current.right
            
            # 如果删除的是根节点
            if not parent:
                return new_node
            
            # 更新父节点的指针
            if parent.left == current:
                parent.left = new_node
            else:
                parent.right = new_node
        
        # 情况 3: 有两个子节点
        else:
            # 找到右子树的最小节点
            successor_parent = current
            successor = current.right
            
            while successor.left:
                successor_parent = successor
                successor = successor.left
            
            # 用后继节点的值替换当前节点
            current.val = successor.val
            
            # 删除后继节点
            if successor_parent.left == successor:
                successor_parent.left = successor.right
            else:
                successor_parent.right = successor.right
        
        return root
```

### 方法四：简化递归版本

```python
class Solution:
    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        """
        更简洁的递归实现
        """
        if not root:
            return None
        
        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        else:
            # 情况 1 和 2
            if not root.left:
                return root.right
            if not root.right:
                return root.left
            
            # 情况 3: 找右子树最小值
            min_node = root.right
            while min_node.left:
                min_node = min_node.left
            
            # 替换值并删除
            root.val = min_node.val
            root.right = self.deleteNode(root.right, min_node.val)
        
        return root
```

## 复杂度分析

**递归法：**
- 时间复杂度：O(h)，h 是树的高度
  - 平衡树：O(log n)
  - 退化成链：O(n)
- 空间复杂度：O(h)，递归调用栈

**迭代法：**
- 时间复杂度：O(h)
- 空间复杂度：O(1)

## 关键点总结

1. **三种删除情况**：无子节点、单子节点、双子节点
2. **后继节点**：右子树的最小节点（最左节点）
3. **前驱节点**：左子树的最大节点（最右节点）
4. **BST 性质**：删除后仍需保持左 < 根 < 右
5. **递归思想**：删除操作可以递归应用到子树

## 易错点

1. **忘记返回新的根节点**：
   ```python
   # 错误：忘记返回
   self.deleteNode(root.left, key)
   
   # 正确：需要更新子树
   root.left = self.deleteNode(root.left, key)
   ```

2. **双子节点情况处理不当**：
   - 必须先替换值，再删除后继/前驱节点
   - 不能直接移动节点指针

3. **空节点检查**：
   - 递归基础情况：`if not root: return None`
   - 删除根节点的情况

4. **后继节点可能就是右子节点**：
   ```python
   # 如果右子节点没有左子树
   # 后继节点就是 root.right
   # 需要正确处理这种情况
   ```

   - 前驱：左子树最大值
