## 题目描述

给你一个 `m x n` 的棋盘 `board`，每个格子包含一个正整数。每次操作可以选择棋盘上的一行或一列，将其所有元素减去 1。若某个格子的值变为 0，则该格子被清除。

返回清除棋盘上所有格子所需的最少操作次数。

**示例 1：**

```
输入：board = [[1, 2], [3, 4]]
输出：4
解释：操作第 1 列 2 次（清除 (0,0) 和减少其他），操作第 2 列 2 次...
```

**示例 2：**

```
输入：board = [[2, 2], [2, 2]]
输出：2
解释：操作每行各一次或每列各一次。
```

**提示：**
- `1 <= m, n <= 100`
- `1 <= board[i][j] <= 100`

## 解题思路

每个格子 `(i, j)` 需要被减 `board[i][j]` 次，这些操作可以通过行操作或列操作完成。

对于格子 `(i, j)`，设对第 i 行操作 `r[i]` 次，对第 j 列操作 `c[j]` 次，则 `r[i] + c[j] >= board[i][j]`。

目标：最小化 `sum(r) + sum(c)`，满足所有格子的约束。

## Python 代码实现

### 方法一：贪心（每格子取行或列的最大值）

```python
from typing import List

class Solution:
    def minimumOperations(self, board: List[List[int]]) -> int:
        m, n = len(board), len(board[0])

        # 对每行，操作次数至少为该行最大值
        # 对每列，操作次数至少为该列最大值
        # 但行和列操作共同作用于格子

        # 贪心：分配策略
        # 对每个格子，其需求由行和列分担
        # 最优：行操作次数 = 该行最大值，列操作次数适当减少
        # 或：列操作次数 = 该列最大值，行操作次数适当减少

        # 简化：每行操作次数为行最大值，列操作次数为列最大值中超过行已覆盖的部分
        # 这等价于：ops = max(max_each_row, max_each_col) 对每对 (i,j)

        # 正确方法：行操作数 r[i]，列操作数 c[j]
        # 对每个 (i,j)：r[i] + c[j] >= board[i][j]
        # 最小化 sum(r) + sum(c)

        # 简单上界：让行操作次数等于行最大值
        row_ops = [max(board[i]) for i in range(m)]
        col_ops = [0] * n

        for j in range(n):
            for i in range(m):
                needed = board[i][j] - row_ops[i]
                col_ops[j] = max(col_ops[j], needed)

        return sum(row_ops) + sum(col_ops)
```

### 方法二：枚举行操作分配

```python
from typing import List

class Solution:
    def minimumOperations(self, board: List[List[int]]) -> int:
        m, n = len(board), len(board[0])
        best = float('inf')

        # 枚举每行的操作次数（0 到行最大值）
        # 对小规模（m,n<=10）可枚举
        # 对大规模使用贪心或LP松弛

        # 贪心：两种策略取最优
        for strategy in range(2):
            if strategy == 0:
                # 策略一：行操作 = 行最大值
                r = [max(board[i]) for i in range(m)]
                c = [max(board[i][j] - r[i] for i in range(m)) for j in range(n)]
                c = [max(0, x) for x in c]
            else:
                # 策略二：列操作 = 列最大值
                c = [max(board[i][j] for i in range(m)) for j in range(n)]
                r = [max(board[i][j] - c[j] for j in range(n)) for i in range(m)]
                r = [max(0, x) for x in r]

            best = min(best, sum(r) + sum(c))

        return best
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m + n)

## 关键点总结

1. 行操作和列操作共同作用于格子，两者之和需满足格子值的约束。
2. 贪心：先确定行操作量（取行最大值），再用列操作补足不足的部分。
3. 两种策略（先确定行 vs 先确定列）取最优。

## 易错点

1. 列操作的补足量 = `max(0, board[i][j] - r[i])`，不能为负。
2. 两种分配策略结果不同，取最优值。
