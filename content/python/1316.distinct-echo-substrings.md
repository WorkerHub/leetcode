## 题目描述

返回 `text` 中**不同非空**回声子字符串的数量。

字符串 `str` 是 `text` 的一个**子字符串**，需满足：

1. `str.length` 是**偶数**
2. 将 `str` 分成长度相同的两半，即 `str = str1 + str2`，且 `str1 == str2`

**示例 1：**

```
输入：text = "abcabcabc"
输出：3
解释：3 个回声子字符串为 "abcabc"、"bcabca"、"cabcab"
```

**示例 2：**

```
输入：text = "leetcodeleet"
输出：2
解释：2 个回声子字符串为 "leet" 和 "leetcodeleet"
```

**提示：**

- `1 <= text.length <= 2000`

## 解题思路

**什么是回声子字符串？**

形如 `str1 + str1` 的字符串，即由两个相同的子串拼接而成（长度至少为 2）。

例如：`"aa"`、`"abab"`、`"leet"` 不是（`"le" + "et"` 不相等），`"leet"="leet"+"leet"` 中 `"leet"` 本身是回声，即 `"leetleet"` 才是，但这里说的是 `"leet"` 中的子串...

让我们重新理解：字符串 `s` 的一个子串 `s[i..j]`，其长度为 `2L`，如果 `s[i..i+L-1] == s[i+L..j]`，则它是回声子字符串。

---

**方法一：暴力枚举 + 集合去重**

枚举所有偶数长度的子串，判断前后两半是否相等，用集合存储所有符合条件的不同子串。

**方法二：滚动哈希（Rabin-Karp）**

对于每个可能的"半长度" L（从 1 到 n/2），同时维护两个长度为 L 的滚动哈希窗口，如果在某个位置两个窗口的哈希值相等（且字符串相等），则找到一个回声子串。

## Python 代码实现

### 方法一：暴力枚举（直观理解）

```python
class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:
        n = len(text)
        seen = set()
        
        # 枚举起始位置 i 和半长度 L
        for i in range(n):
            for L in range(1, (n - i) // 2 + 1):
                # 子串为 text[i : i + 2*L]，判断前后两半是否相等
                if text[i : i + L] == text[i + L : i + 2 * L]:
                    seen.add(text[i : i + 2 * L])
        
        return len(seen)
```

### 方法二：滚动哈希（推荐，高效）

```python
class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:
        n = len(text)
        MOD = (1 << 61) - 1  # 大质数，减少哈希碰撞
        BASE = 31
        
        seen = set()
        
        # 对每个半长度 L 使用滚动哈希
        for L in range(1, n // 2 + 1):
            # 初始化两个窗口的哈希值
            # 第一个窗口：text[0..L-1]
            # 第二个窗口：text[L..2L-1]
            h1 = h2 = 0
            power = pow(BASE, L - 1, MOD)
            
            # 计算初始窗口哈希
            for i in range(L):
                h1 = (h1 * BASE + ord(text[i]) - ord('a') + 1) % MOD
            for i in range(L, 2 * L):
                h2 = (h2 * BASE + ord(text[i]) - ord('a') + 1) % MOD
            
            # 滑动两个窗口
            for start in range(n - 2 * L + 1):
                if h1 == h2:
                    # 哈希相等，再验证字符串（避免哈希碰撞）
                    s = text[start : start + 2 * L]
                    if text[start : start + L] == text[start + L : start + 2 * L]:
                        seen.add(s)
                
                if start + 2 * L < n:
                    # 更新第一个窗口：移除 text[start]，加入 text[start+L]
                    h1 = (h1 - (ord(text[start]) - ord('a') + 1) * power % MOD) % MOD
                    h1 = (h1 * BASE + ord(text[start + L]) - ord('a') + 1) % MOD
                    # 更新第二个窗口：移除 text[start+L]，加入 text[start+2L]
                    h2 = (h2 - (ord(text[start + L]) - ord('a') + 1) * power % MOD) % MOD
                    h2 = (h2 * BASE + ord(text[start + 2 * L]) - ord('a') + 1) % MOD
        
        return len(seen)
```

### 方法三：Z函数（高效求所有相同前后缀）

```python
class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:
        n = len(text)
        seen = set()
        
        def z_function(s):
            """计算 Z 函数：z[i] 表示 s[i:] 与 s 的最长公共前缀长度"""
            n = len(s)
            z = [0] * n
            z[0] = n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and s[z[i]] == s[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            return z
        
        # 对每个起始位置 i，用 Z 函数找所有满足条件的 L
        for i in range(n - 1):
            # 构造从 i 开始的子串的 Z 函数
            suffix = text[i:]
            z = z_function(suffix)
            # z[L] >= L 表示 suffix[L:] 的前 L 个字符与 suffix 前 L 个字符相同
            # 即 text[i:i+L] == text[i+L:i+2L]
            for L in range(1, len(suffix) // 2 + 1):
                if z[L] >= L:
                    seen.add(text[i : i + 2 * L])
        
        return len(seen)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^3)（含字符串比较）| O(n^2) |
| 滚动哈希 | O(n^2) | O(n^2) |
| Z 函数 | O(n^2) | O(n^2) |

空间复杂度 O(n^2) 来自 `seen` 集合中最多存储 O(n^2) 个子串。

## 关键点总结

1. 回声子串 = 两个相同子串拼接，长度必须为偶数
2. 使用集合自动去重，避免重复计数
3. 滚动哈希可将字符串比较降至 O(1)（近似），提高效率
4. Z 函数是处理字符串前缀匹配问题的强力工具

## 易错点

1. **字符串比较用集合存储**：即使不同位置的子串内容相同，也只计一次
2. **哈希碰撞**：滚动哈希时需要在哈希相等时再做字符串验证，避免误判
3. **滑动窗口的更新**：两个窗口要同时向右滑动，步进为 1
