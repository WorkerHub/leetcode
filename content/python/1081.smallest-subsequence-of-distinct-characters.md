## 题目描述

给定一个字符串 `s`，返回 `s` 的**字典序最小的子序列**，该子序列包含 `s` 中所有不同的字符，且每个字符只出现一次。

**注意**：该题与 [316. 去除重复字母](https://leetcode.com/problems/remove-duplicate-letters/) 相同。

**示例 1：**
```
输入：s = "bcabc"
输出："abc"
解释：所有不同字符为 'a', 'b', 'c'，字典序最小的排列是 "abc"
```

**示例 2：**
```
输入：s = "cbacdcbc"
输出："acdb"
解释：包含所有不同字符 'a', 'b', 'c', 'd'，字典序最小的是 "acdb"
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 由小写英文字母组成

## 解题思路

这是一道经典的**单调栈 + 贪心**问题。

### 核心思想

1. **目标**：
   - 包含所有不同字符（每个字符恰好一次）
   - 字典序最小

2. **贪心策略**：
   - 尽可能让较小的字符排在前面
   - 如果当前字符比栈顶字符小，且栈顶字符后面还会出现，可以弹出栈顶

3. **关键观察**：
   - 使用**单调栈**维护结果
   - 需要知道每个字符的**最后出现位置**或**剩余出现次数**
   - 如果栈顶字符 > 当前字符，且栈顶字符后面还有，就弹出栈顶

4. **算法流程**：
   - 统计每个字符的剩余出现次数
   - 遍历字符串：
     - 如果字符已在栈中，跳过（每个字符只要一次）
     - 否则，尝试弹出栈顶：
       - 栈顶 > 当前字符
       - 栈顶字符后面还会出现（剩余次数 > 0）
     - 将当前字符入栈
     - 减少当前字符的剩余次数

## Python 代码实现

### 方法一：单调栈 + 计数器（推荐）

```python
from collections import Counter

class Solution:
    def smallestSubsequence(self, s: str) -> str:
        # 统计每个字符的剩余出现次数
        remaining = Counter(s)
        
        # 记录字符是否已在栈中
        in_stack = set()
        
        # 单调栈（用列表模拟）
        stack = []
        
        for char in s:
            # 减少剩余次数
            remaining[char] -= 1
            
            # 如果字符已在栈中，跳过
            if char in in_stack:
                continue
            
            # 维护单调性：弹出栈顶较大的、后面还会出现的字符
            while stack and stack[-1] > char and remaining[stack[-1]] > 0:
                removed = stack.pop()
                in_stack.remove(removed)
            
            # 当前字符入栈
            stack.append(char)
            in_stack.add(char)
        
        return ''.join(stack)
```

### 方法二：使用最后出现位置

```python
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        # 记录每个字符最后出现的位置
        last_occurrence = {char: i for i, char in enumerate(s)}
        
        # 记录字符是否已在结果中
        used = set()
        
        # 结果栈
        stack = []
        
        for i, char in enumerate(s):
            # 已使用过，跳过
            if char in used:
                continue
            
            # 弹出栈顶：更大、后面还会出现
            while stack and stack[-1] > char and last_occurrence[stack[-1]] > i:
                removed = stack.pop()
                used.remove(removed)
            
            # 加入当前字符
            stack.append(char)
            used.add(char)
        
        return ''.join(stack)
```

### 方法三：使用字典计数

```python
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        # 统计每个字符的总出现次数
        char_count = {}
        for char in s:
            char_count[char] = char_count.get(char, 0) + 1
        
        # 已加入结果的字符
        in_result = set()
        
        # 结果列表
        result = []
        
        for char in s:
            # 减少剩余次数
            char_count[char] -= 1
            
            # 已在结果中
            if char in in_result:
                continue
            
            # 尝试弹出栈顶
            while result and result[-1] > char and char_count[result[-1]] > 0:
                removed = result.pop()
                in_result.remove(removed)
            
            # 加入当前字符
            result.append(char)
            in_result.add(char)
        
        return ''.join(result)
```

### 方法四：递归（理解用，不推荐）

```python
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        if not s:
            return ""
        
        # 统计字符出现次数
        count = {}
        for char in s:
            count[char] = count.get(char, 0) + 1
        
        # 找到最小的、后面包含所有字符的位置
        pos = 0
        for i in range(len(s)):
            if s[i] < s[pos]:
                pos = i
            
            count[s[i]] -= 1
            # 如果某字符用完了，必须在此位置之前选择
            if count[s[i]] == 0:
                break
        
        # 选择 s[pos]，递归处理剩余部分（去除 s[pos] 字符）
        return s[pos] + self.smallestSubsequence(s[pos+1:].replace(s[pos], ""))
```

## 复杂度分析

**方法一、二、三（推荐）：**
- **时间复杂度**：O(n)
  - 遍历字符串：O(n)
  - 每个字符最多入栈出栈一次：O(n)
- **空间复杂度**：O(1) 或 O(26) = O(1)
  - 栈最多 26 个字符（小写字母）
  - Counter 和 set 也最多 26 个元素

**方法四（递归）：**
- **时间复杂度**：O(n²)，每层递归 O(n)，最多 26 层
- **空间复杂度**：O(n²)，字符串切片和递归栈

## 关键点总结

1. **单调栈应用**：维护字典序递增的字符序列
2. **贪心思想**：优先保留较小的字符
3. **剩余次数**：判断是否可以弹出栈顶的关键
4. **去重处理**：使用 set 记录已在栈中的字符
5. **与 316 题相同**：这两题完全一样

## 易错点

1. **忘记去重**：没有检查字符是否已在栈中，导致重复
2. **弹出条件**：三个条件必须同时满足（栈非空、栈顶更大、栈顶后面还有）
3. **剩余次数更新**：必须先减少剩余次数，再判断是否入栈
4. **set 同步**：弹出栈顶时，必须同时从 set 中移除
5. **理解单调栈**：不是严格单调递增，而是尽可能单调
