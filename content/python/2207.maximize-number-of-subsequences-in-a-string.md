## 题目描述

给你一个下标从 0 开始的字符串 `text` 和另一个下标从 0 开始且长度为 2 的字符串 `pattern`，两者都只包含小写英文字母，共 `n` 个字符。

你可以在 `text` 中任意位置插入一个字符，插入后 `text` 的长度变为 `n + 1`。返回插入一个字符后，`text` 中出现 `pattern` 作为**子序列**的最大次数。

**子序列**：从字符串中删除若干字符（可以不删）后得到的字符串，不改变字符的相对顺序。

**示例 1：**
```
输入：text = "abdcdbc", pattern = "ac"
输出：4
解释：在开头插入 'a' 得到 "aabdcdbc"，"ac" 子序列数为 4。
```

**示例 2：**
```
输入：text = "aabb", pattern = "ab"
输出：6
```

**提示：**
- `1 <= text.length <= 10^5`
- `pattern.length == 2`

## 解题思路

设 `pattern = p0 p1`。

插入一个字符有两种选择：
1. **在最前面插入 `p0`**：新增的子序列数 = 原 `text` 中 `p1` 的总数（新插入的 `p0` 与所有 `p1` 组合）。
2. **在最后面插入 `p1`**：新增的子序列数 = 原 `text` 中 `p0` 的总数。

为什么只需考虑这两种？因为将 `p0` 插入到越靠前，与越多的 `p1` 组合；将 `p1` 插入到越靠后，与越多的 `p0` 组合。

**原有子序列数** = 遍历 `text`，维护 `p0` 的出现次数，每遇到 `p1` 就加上当前 `p0` 的计数。

答案 = 原有子序列数 + max(count_p1, count_p0)。

## 代码实现

### 方法一：前缀和贪心（推荐）

```python
class Solution:
    def maximumSubsequenceCount(self, text: str, pattern: str) -> int:
        p0, p1 = pattern[0], pattern[1]

        # 计算原 text 中 pattern 的子序列数
        # 同时统计 p0 和 p1 的总出现次数
        count_p0 = 0  # 已遍历过的 p0 数量
        count_p1 = 0  # p1 的总数量
        subseq = 0    # 当前子序列计数

        for ch in text:
            if ch == p1:
                subseq += count_p0  # 与前面所有 p0 配对
                count_p1 += 1
            if ch == p0:
                count_p0 += 1

        # 两种插入策略，取最大增量
        # 策略1：在开头插入 p0，新增 count_p1 个子序列
        # 策略2：在末尾插入 p1，新增 count_p0 个子序列
        return subseq + max(count_p0, count_p1)
```

### 方法二：分别计算两种情况

```python
class Solution:
    def maximumSubsequenceCount(self, text: str, pattern: str) -> int:
        p0, p1 = pattern[0], pattern[1]

        def count_subseq(s: str) -> int:
            """计算字符串 s 中 pattern 的子序列数"""
            cnt0 = 0
            result = 0
            for ch in s:
                if ch == p1:
                    result += cnt0
                if ch == p0:
                    cnt0 += 1
            return result

        # 方案1：在最开头加 p0
        case1 = count_subseq(p0 + text)

        # 方案2：在最末尾加 p1
        case2 = count_subseq(text + p1)

        return max(case1, case2)
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)，常数额外空间。

## 关键点总结

1. 只需考虑在最前面插入 `p0` 或在最后面插入 `p1` 两种贪心策略。
2. 插入 `p0` 到最前：与所有后面的 `p1` 匹配，增量为 `count(p1)`。
3. 插入 `p1` 到最后：与所有前面的 `p0` 匹配，增量为 `count(p0)`。
4. 注意 `p0 == p1` 的情况：方法一中需先处理 `p1` 再处理 `p0`（或反之），避免同一字符被重复计数（方法一代码已正确处理）。

## 易错点

- 当 `p0 == p1` 时，遍历时要注意先更新 `subseq` 再更新 `count_p0`（方法一中先判断 `p1` 后判断 `p0`，若相同字符也正确，因为先记录组合再增加计数）。
