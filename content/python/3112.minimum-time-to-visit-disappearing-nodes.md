## 题目描述

给你一个 `n` 个顶点的无向图，顶点编号从 0 到 n-1。

给你一个二维数组 `edges`，`edges[i] = [ui, vi, lengthi]`，表示顶点 `ui` 和 `vi` 之间有一条长度为 `lengthi` 的边。

同时给你一个数组 `disappear`，`disappear[i]` 表示顶点 `i` 在时刻 `disappear[i]` **消失**，你无法在该时刻或之后访问该顶点。

返回数组 `answer`，`answer[i]` 是从顶点 0 出发，**恰好** 到达顶点 `i` 的最短时间。如果无法到达，则 `answer[i] = -1`。

**提示：**
- `1 <= n <= 5 * 10^4`
- `0 <= edges.length <= 10^5`
- `0 <= disappear[i] <= 10^5`

## 解题思路

标准 Dijkstra 最短路算法，但需要在松弛时额外判断：到达某顶点的时间必须严格小于该顶点的消失时间（即 `dist[v] < disappear[v]`）。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], disappear: List[int]) -> List[int]:
        # 建图
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0

        # 检查起点是否已消失
        if disappear[0] <= 0:
            return [-1] * n

        heap = [(0, 0)]  # (距离, 顶点)
        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                nd = d + w
                # 到达时间必须严格小于消失时间
                if nd < disappear[v] and nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        return [d if d < INF else -1 for d in dist]
```

### 方法二：带剪枝的 Dijkstra

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], disappear: List[int]) -> List[int]:
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))

        dist = [-1] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if dist[u] != d and dist[u] != 0:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < disappear[v]:
                    if dist[v] == -1 or nd < dist[v]:
                        dist[v] = nd
                        heapq.heappush(heap, (nd, v))

        return dist
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 本质是带约束的最短路：到达时间 < 消失时间
2. Dijkstra 保证第一次到达某顶点时已是最短路
3. 松弛条件：`nd < disappear[v] and nd < dist[v]`

## 易错点

1. 消失时间是严格小于，即 `nd < disappear[v]`
2. 初始顶点 0 也有消失时间限制
