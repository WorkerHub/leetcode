## 题目描述

给定一个长度为偶数的整数数组 `arr`，只有对 `arr` 进行重组后可以满足 "对于每个 `0 <= i < len(arr) / 2`，都有 `arr[2 * i + 1] = 2 * arr[2 * i]`" 时，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：arr = [3,1,3,6]
输出：false
```

**示例 2：**
```
输入：arr = [2,1,2,6]
输出：false
```

**示例 3：**
```
输入：arr = [4,-2,2,-4]
输出：true
解释：可以用 [-2,-4] 和 [2,4] 这两组组成 [-2,-4,2,4] 或是 [2,4,-2,-4]
```

**提示：**
- `0 <= arr.length <= 3 * 10^4`
- `arr.length` 是偶数
- `-10^5 <= arr[i] <= 10^5`

## 解题思路

这道题要求判断数组能否重组为每对元素都满足后者是前者的 2 倍。

**核心思想：**

1. **贪心策略**：从绝对值最小的数开始配对
   - 为什么？因为绝对值小的数可配对的选择更少
   - 例如：2 可以和 1 或 4 配对，但 1 只能和 2 配对

2. **哈希表计数**：统计每个数字的出现次数
   - 对于每个数 x，需要找到对应的 2x
   - 配对成功后，两者的计数都减 1

3. **排序技巧**：按绝对值排序
   - 确保从小到大处理
   - 负数需要特殊处理：-2 的配对是 -4（不是 -1）

**算法流程：**
1. 统计每个数字的出现次数
2. 按绝对值对数字排序
3. 从小到大遍历，为每个数寻找配对
4. 如果某个数无法配对，返回 False
5. 全部配对成功，返回 True

## Python 代码实现

### 方法一：贪心 + 哈希表（推荐）⭐

```python
from typing import List
from collections import Counter

class Solution:
    def canReorderDoubled(self, arr: List[int]) -> bool:
        """
        贪心算法：从绝对值最小的数开始配对
        
        思路：
        1. 统计每个数字的出现次数
        2. 按绝对值排序
        3. 为每个数寻找其两倍的配对
        """
        # 统计每个数字的出现次数
        count = Counter(arr)
        
        # 按绝对值排序（从小到大）
        # 这样可以确保先处理绝对值小的数
        for x in sorted(count.keys(), key=abs):
            # 如果 x 已经全部配对完，跳过
            if count[x] == 0:
                continue
            
            # x 需要配对的目标数
            target = 2 * x
            
            # 检查 target 是否有足够的数量
            if count[target] < count[x]:
                return False
            
            # 配对成功，减少计数
            count[target] -= count[x]
        
        return True
```

### 方法二：分正负数处理

```python
class Solution:
    def canReorderDoubled(self, arr: List[int]) -> bool:
        """
        分别处理正数和负数
        
        思路：
        - 正数：从小到大配对，x 与 2x
        - 负数：从大到小配对（绝对值从小到大），x 与 2x
        - 0 单独处理，必须是偶数个
        """
        count = Counter(arr)
        
        # 处理 0：必须是偶数个
        if count[0] % 2 != 0:
            return False
        
        # 处理正数：从小到大
        for x in sorted([num for num in count if num > 0]):
            if count[x] > 0:
                target = 2 * x
                if count[target] < count[x]:
                    return False
                count[target] -= count[x]
        
        # 处理负数：从大到小（绝对值从小到大）
        for x in sorted([num for num in count if num < 0], reverse=True):
            if count[x] > 0:
                target = 2 * x
                if count[target] < count[x]:
                    return False
                count[target] -= count[x]
        
        return True
```

### 方法三：直接排序数组

```python
class Solution:
    def canReorderDoubled(self, arr: List[int]) -> bool:
        """
        直接对数组排序后配对
        
        思路：
        1. 按绝对值排序
        2. 使用字典记录每个数的剩余可用次数
        3. 遍历数组，尝试配对
        """
        # 按绝对值排序
        arr.sort(key=abs)
        
        # 记录每个数的可用次数
        count = Counter(arr)
        
        for num in arr:
            # 如果当前数已经被配对完
            if count[num] == 0:
                continue
            
            # 寻找配对
            target = 2 * num
            
            # 检查 target 是否存在
            if count[target] == 0:
                return False
            
            # 配对成功
            count[num] -= 1
            count[target] -= 1
        
        return True
```

### 方法四：优化的贪心算法

```python
class Solution:
    def canReorderDoubled(self, arr: List[int]) -> bool:
        """
        优化版本：只遍历一次
        """
        from collections import defaultdict
        
        count = defaultdict(int)
        for num in arr:
            count[num] += 1
        
        # 特殊处理 0
        if count[0] % 2:
            return False
        
        # 按绝对值排序所有唯一值
        keys = sorted(count.keys(), key=lambda x: (abs(x), x))
        
        for x in keys:
            while count[x] > 0:
                # 尝试配对 x 和 2x
                if count[2 * x] <= 0:
                    return False
                count[x] -= 1
                count[2 * x] -= 1
        
        return True
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(N log N)
  - 统计次数：O(N)
  - 排序：O(K log K)，K 是不同数字的个数，K ≤ N
  - 遍历配对：O(K)
- **空间复杂度**：O(N)，哈希表存储计数

**方法二：**
- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

**方法三：**
- **时间复杂度**：O(N log N)，排序数组
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心选择**：从绝对值最小的数开始配对是关键
2. **排序技巧**：使用 `key=abs` 按绝对值排序
3. **负数处理**：负数的两倍仍是负数，且绝对值更大
4. **计数器应用**：Counter 简化了计数和查找操作
5. **边界情况**：特别注意 0 的处理

## 易错点

1. **负数配对**：容易忘记负数也需要配对，-2 的配对是 -4
2. **排序键选择**：直接排序不对，必须按绝对值排序
3. **0 的处理**：0 的两倍还是 0，需要特殊处理
4. **计数器修改**：配对后要同时减少两个数的计数
5. **顺序问题**：必须从小到大处理，否则会出现错误配对
