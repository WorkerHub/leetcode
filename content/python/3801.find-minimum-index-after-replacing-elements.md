## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，你需要对数组执行若干次替换操作。每次操作中，你可以选择数组中的一个元素，将其替换为该元素的某个因子（包括 1 和该元素本身）。

找到替换操作完成后，数组中最小元素第一次出现的下标。要求在替换后使得数组字典序最小的同时，找到最小值的第一个下标。

**示例 1：**

```
输入：nums = [4, 2, 6, 3]
输出：1
解释：最小元素为 1，可以将任意元素替换为 1。但为使数组整体最优，最小值最先出现在下标 1。
```

**示例 2：**

```
输入：nums = [1, 3, 5, 7]
输出：0
解释：nums[0] = 1 已经是最小值，直接返回下标 0。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

由于任何正整数都可以替换为 1（其因子），所以数组中任意位置都可以变成 1。问题转化为：在使数组字典序最小的前提下，找到第一个可以取到最小值的位置。

核心观察：
1. 如果数组中已经存在 1，直接返回第一个 1 的位置。
2. 否则，任何元素都可以替换为 1，返回下标 0（因为替换第一个元素为 1 可以使字典序最小）。
3. 若需要保留某些约束，用哈希表记录每个元素第一次出现的位置。

## Python 代码实现

### 方法一：哈希表记录首次出现位置（推荐）

```python
from typing import List

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        # 用哈希表记录每个值第一次出现的位置
        first_occurrence = {}
        for i, num in enumerate(nums):
            if num not in first_occurrence:
                first_occurrence[num] = i

        # 找到数组最小值
        min_val = min(nums)

        # 返回最小值第一次出现的位置
        return first_occurrence[min_val]
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        # 线性扫描，同时记录最小值和其第一次出现的下标
        min_val = nums[0]
        min_idx = 0

        for i in range(1, len(nums)):
            if nums[i] < min_val:
                min_val = nums[i]
                min_idx = i

        return min_idx
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组一次或两次
- 空间复杂度：O(n)，哈希表存储首次出现位置；方法二为 O(1)

## 关键点总结

1. 替换为因子的操作使得任何元素都可以变为 1。
2. 问题本质是找数组最小值第一次出现的位置。
3. 哈希表可以在 O(n) 时间内完成记录。

## 易错点

1. 注意"第一次出现"，不是最后一次。
2. 数组可能有重复的最小值，只取第一个下标。
