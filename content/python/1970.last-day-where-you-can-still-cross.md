## 题目描述

给你一个 `row x col` 的矩阵，初始全为陆地（0）。给你 `cells` 数组，`cells[i] = [ri, ci]` 表示第 `i` 天该格子变为水（1）。

返回你可以从**最左列**走到**最右列**的**最后一天**（可以从左往右或上下走，不能走水格）。

**提示：**
- `2 <= row, col <= 2 * 10^4`
- `4 <= row * col <= 2 * 10^4`

---

## 解题思路

### 方法一：二分 + BFS/DFS

**二分答案**：第几天是最后可以穿越的。

对于第 `t` 天，前 `t` 个格子变为水，用 BFS/DFS 判断是否仍可从左列到右列。

### 方法二：逆向并查集

从最后一天（全是水）逆向，每天恢复一格（变回陆地），用并查集判断左列和右列是否连通。

## 代码实现

### 方法一：二分 + BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def latestDayToCross(self, row: int, col: int, cells: List[List[int]]) -> int:

        def can_cross(day: int) -> bool:
            """判断第 day 天后是否可以从左列到右列"""
            # 构建水域矩阵
            grid = [[0] * col for _ in range(row)]
            for i in range(day):
                r, c = cells[i]
                grid[r - 1][c - 1] = 1  # 变为水

            # BFS：从最左列的所有陆地格出发
            queue = deque()
            for r in range(row):
                if grid[r][0] == 0:  # 最左列的陆地
                    queue.append((r, 0))
                    grid[r][0] = 1  # 标记已访问

            while queue:
                r, c = queue.popleft()
                if c == col - 1:  # 到达最右列
                    return True
                for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < row and 0 <= nc < col and grid[nr][nc] == 0:
                        grid[nr][nc] = 1
                        queue.append((nr, nc))
            return False

        # 二分：找最后一个可以穿越的天
        lo, hi = 1, len(cells)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_cross(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：逆向并查集（O(n * alpha)，更优）

```python
from typing import List

class Solution:
    def latestDayToCross(self, row: int, col: int, cells: List[List[int]]) -> int:
        n = row * col
        parent = list(range(n + 2))  # 额外 n 和 n+1 分别代表左列和右列虚节点
        rank = [0] * (n + 2)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1

        LEFT = n    # 左列虚节点
        RIGHT = n + 1  # 右列虚节点

        grid = [[1] * col for _ in range(row)]  # 初始全为水

        # 逆向：从最后一天往前，逐步恢复陆地
        for day in range(len(cells) - 1, -1, -1):
            r, c = cells[day][0] - 1, cells[day][1] - 1
            grid[r][c] = 0  # 恢复为陆地
            idx = r * col + c

            # 连接虚节点
            if c == 0:
                union(idx, LEFT)
            if c == col - 1:
                union(idx, RIGHT)

            # 连接相邻陆地
            for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < row and 0 <= nc < col and grid[nr][nc] == 0:
                    union(idx, nr * col + nc)

            # 检查左右是否连通
            if find(LEFT) == find(RIGHT):
                return day

        return 0
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分 + BFS | O(n log n) | O(n) |
| 逆向并查集 | O(n * alpha) | O(n) |

---

## 关键点总结

1. 二分答案，对每天用 BFS 验证连通性
2. 逆向并查集：从全水逆推，每次加入一格后检查左右连通
3. 两个虚节点分别代表左右边界，简化连通性判断

---

## 易错点

- `cells` 的坐标是 1-indexed，使用时需 `-1`
- 二分时找"最后一个满足条件的天"，用 `lo = mid` 的写法
