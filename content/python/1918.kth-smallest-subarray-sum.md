## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，返回所有非空**子数组和**中第 `k` 小的值。

**子数组**是数组中的一段连续元素。

**示例 1：**
```
输入：nums = [2, 1, 3], k = 4
输出：3
解释：子数组和：[2]=2, [1]=1, [3]=3, [2,1]=3, [1,3]=4, [2,1,3]=6
排序：[1,2,3,3,4,6]，第 4 小 = 3
```

**示例 2：**
```
输入：nums = [3, 3, 5, 5], k = 7
输出：10
```

**提示：**
- `n == nums.length`
- `1 <= n <= 3 * 10^4`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= n*(n+1)/2`

---

## 解题思路

### 核心思想：二分答案 + 滑动窗口计数

**二分目标值 `mid`**，统计所有子数组中和 ≤ `mid` 的数量 `cnt`：
- 若 `cnt >= k`，则第 k 小 ≤ `mid`，缩小上界
- 否则缩小下界

**如何快速统计和 ≤ `mid` 的子数组数？**

由于 `nums[i] >= 1`（全正数），前缀和单调递增，可用**滑动窗口（双指针）**：
- 固定右端点 `r`，左端点 `l` 尽量向左移动
- 找到满足 `sum(nums[l..r]) <= mid` 的最大 `l`，则以 `r` 为右端的合法子数组数为 `r - l + 1`

---

## 代码实现

### 方法一：二分 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def kthSmallestSubarraySum(self, nums: List[int], k: int) -> int:

        def count_le(target: int) -> int:
            """统计子数组和 <= target 的数量"""
            cnt = 0
            window_sum = 0
            left = 0
            for right in range(len(nums)):
                window_sum += nums[right]
                # 缩小左端点，直到窗口和 <= target
                while window_sum > target:
                    window_sum -= nums[left]
                    left += 1
                # 以 right 为右端的合法子数组数
                cnt += right - left + 1
            return cnt

        # 二分答案范围：[最小值（单个最小元素）, 所有元素总和]
        lo, hi = min(nums), sum(nums)

        while lo < hi:
            mid = (lo + hi) // 2
            if count_le(mid) >= k:
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：前缀和 + 排序（暴力，对比学习）

```python
from typing import List

class Solution:
    def kthSmallestSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 枚举所有子数组和
        sums = []
        for i in range(n):
            cur_sum = 0
            for j in range(i, n):
                cur_sum += nums[j]
                sums.append(cur_sum)
        sums.sort()
        return sums[k - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分 + 滑动窗口 | O(n log(sum)) | O(1) |
| 暴力排序 | O(n² log n) | O(n²) |

## 关键点总结

1. 全为正数时，子数组和与滑动窗口结合高效计数
2. 二分的是答案值，而非下标
3. 二分终止后 `lo` 就是第 k 小的值（因为 `count_le(lo) >= k` 且 `count_le(lo-1) < k`）

---

## 易错点

- 二分左边界应是 `min(nums)` 而非 0（所有子数组至少有一个正数元素）
- 滑动窗口中累计的是 `right - left + 1` 个子数组（以 right 为右端点的所有合法子数组）
