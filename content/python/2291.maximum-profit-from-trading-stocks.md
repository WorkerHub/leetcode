## 题目描述

给你两个下标从 **0** 开始的数组 `present` 和 `future`，长度均为 `n`，`present[i]` 和 `future[i]` 分别表示第 `i` 支股票现在和未来的价格。给你一个整数 `budget`，可以购买任意数量的股票（每支只能买一次，也可以不买）。

返回在预算内能获得的**最大利润**。

**示例 1：**
```
输入：present = [5,4,6,2,3], future = [8,5,4,3,5], budget = 10
输出：6
解释：购买股票 0（花费 5，利润 3）和 3（花费 2，利润 1），总花费 7，总利润 4。或购买 0 和 4，总花费 8，利润 5。最优买 0 和 4？不对，再算：0 利润 3，4 利润 2，总花费 8，总利润 5。实际最优答案 6。
```

**示例 2：**
```
输入：present = [2,2,5], future = [3,4,10], budget = 6
输出：5
```

## 解题思路

**0/1 背包问题：**

每支股票要么买（花费 `present[i]`，获利 `future[i] - present[i]`），要么不买。只考虑利润 > 0 的股票（买亏本的没意义）。

定义 `dp[j]` 为在预算 `j` 内能获得的最大利润，标准 0/1 背包：
- `dp[j] = max(dp[j], dp[j - present[i]] + profit[i])`（倒序遍历）。

## 代码实现

### 方法一：0/1 背包 DP（推荐）

```python
from typing import List

class Solution:
    def maximumProfit(self, present: List[int], future: List[int], budget: int) -> int:
        # dp[j] = 在预算 j 内能获得的最大利润
        dp = [0] * (budget + 1)

        for p, f in zip(present, future):
            profit = f - p
            if profit <= 0:
                continue  # 不买亏本股票
            # 0/1 背包，倒序遍历
            for j in range(budget, p - 1, -1):
                dp[j] = max(dp[j], dp[j - p] + profit)

        return dp[budget]
```

### 方法二：完整背包写法（含注释）

```python
from typing import List

class Solution:
    def maximumProfit(self, present: List[int], future: List[int], budget: int) -> int:
        n = len(present)
        # 只考虑有利润的股票
        stocks = [(present[i], future[i] - present[i])
                  for i in range(n) if future[i] > present[i]]

        # 0/1 背包
        dp = [0] * (budget + 1)
        for cost, profit in stocks:
            # 倒序确保每支股票最多购买一次
            for j in range(budget, cost - 1, -1):
                if dp[j - cost] + profit > dp[j]:
                    dp[j] = dp[j - cost] + profit

        return dp[budget]
```

## 复杂度分析

- 时间复杂度：O(n * budget)，标准 0/1 背包。
- 空间复杂度：O(budget)，一维 dp 数组。

## 关键点总结

1. 本质是 0/1 背包：物品为股票，重量为 `present[i]`，价值为 `future[i] - present[i]`。
2. 只放利润 > 0 的股票（利润 <= 0 的股票不买）。
3. 0/1 背包倒序遍历容量，防止重复使用同一股票。

## 易错点

- 利润为负或 0 的股票直接跳过，不影响正确性但能提升效率。
- 背包容量从 `budget` 倒序到 `present[i]`，不能正序（0/1 背包）。
