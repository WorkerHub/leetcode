## 题目描述

给你一个大小为 `m x n` 的整数矩阵 `grid` 和一个整数 `x`。每次操作可以将矩阵中**任意**一个元素加 `x` 或减 `x`。

若所有元素最终变为相同值，返回所需的**最少操作次数**；否则，返回 `-1`。

**示例 1：**
```
输入：grid = [[2,4],[6,8]], x = 2
输出：4
解释：将所有元素变为 4，操作次数：|2-4|/2 + |6-4|/2 + |8-4|/2 = 1+1+2 = 4
```

**示例 2：**
```
输入：grid = [[1,5],[2,3]], x = 1
输出：5
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10^5`
- `1 <= grid[i][j] <= 10^5`
- `1 <= x <= 10^4`

## 解题思路

**可行性判断：** 所有元素模 `x` 的余数必须相同。若不同，无法使所有元素相等，返回 `-1`。

**最优目标值：** 最小操作次数时，目标值应取所有元素的**中位数**（经典结论：使绝对差和最小的值是中位数）。

**步骤：**
1. 将矩阵展平为一维数组并排序
2. 检查所有元素模 `x` 的余数是否相同
3. 取中位数作为目标值
4. 累加每个元素到目标值的操作次数

## 代码实现

### 方法一：排序 + 中位数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        # 展平矩阵
        nums = []
        for row in grid:
            nums.extend(row)

        nums.sort()
        n = len(nums)

        # 检查所有元素能否变为同一值
        remainder = nums[0] % x
        for num in nums:
            if num % x != remainder:
                return -1  # 余数不同，无法通过加减 x 使所有元素相等

        # 取中位数作为目标值（最小化绝对差之和）
        median = nums[n // 2]

        # 计算操作次数
        ops = 0
        for num in nums:
            ops += abs(num - median) // x

        return ops
```

### 方法二：前缀和优化（大数组时更快）

```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        nums = sorted(v for row in grid for v in row)
        n = len(nums)

        remainder = nums[0] % x
        if any(num % x != remainder for num in nums):
            return -1

        # 计算各个候选目标值的总操作数
        # 候选值只考虑 nums 中的值（排序后），中位数一定在其中
        median = nums[n // 2]
        return sum(abs(num - median) // x for num in nums)
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))，排序主导
- 空间复杂度：O(mn)，展平数组

## 关键点总结

1. 合法性：所有元素模 `x` 的余数必须相同（否则无法通过 `+x/-x` 统一）
2. 最优目标值是中位数（绝对值之和最小化问题的经典结论）
3. 操作次数 = `|num - target| / x`（因为每次操作改变 `x`）

## 易错点

- 中位数取 `nums[n//2]`（偶数个元素时取两个中间值中的任一个，操作数相同）
- `|num - target|` 必须整除 `x`（由可行性保证）
- 展平矩阵时注意 `extend` 而非 `append`
