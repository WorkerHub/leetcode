## 题目描述

你需要设计一个**身份验证管理器**，其中每个身份验证令牌在生成时都有一个唯一的标识符，并有一个**过期时间**。

请你实现 `AuthenticationManager` 类：

- `AuthenticationManager(int timeToLive)`：构造函数，将 `timeToLive` 设置为时间窗口大小（秒）
- `generate(string tokenId, int currentTime)`：在 `currentTime` 时刻以 `tokenId` 生成一个新令牌，令牌在 `currentTime + timeToLive` 时刻**过期**
- `renew(string tokenId, int currentTime)`：在 `currentTime` 时刻，将给定 `tokenId` 的**未过期**令牌的过期时间更新为 `currentTime + timeToLive`。如果令牌不存在或已经过期，忽略本次操作
- `countUnexpiredTokens(int currentTime)`：返回在 `currentTime` 时刻**未过期**的令牌数量

令牌在恰好到达过期时间时视为已过期（即过期时刻 <= currentTime 时过期）。

**提示：**
- `1 <= timeToLive <= 10^8`
- `1 <= currentTime <= 10^8`
- `1 <= tokenId.length <= 5`
- `tokenId` 只包含小写字母
- 所有操作中的 `currentTime` 都严格递增
- 调用 `generate` 时，`tokenId` 一定是未存在或已过期的令牌

## 解题思路

使用哈希表 `tokens` 存储每个令牌的过期时间（`tokenId -> expire_time`）。

- `generate`：直接写入 `tokens[tokenId] = currentTime + timeToLive`
- `renew`：若令牌存在且未过期，更新过期时间
- `countUnexpiredTokens`：遍历所有令牌，统计未过期的数量

由于 `currentTime` 严格递增，可以在每次操作时顺便清理过期令牌（惰性删除），但不是必须的。

## 代码实现

### 方法一：哈希表（推荐）

```python
class AuthenticationManager:
    def __init__(self, timeToLive: int):
        self.ttl = timeToLive
        self.tokens = {}  # tokenId -> 过期时间

    def generate(self, tokenId: str, currentTime: int) -> None:
        # 生成新令牌，设置过期时间
        self.tokens[tokenId] = currentTime + self.ttl

    def renew(self, tokenId: str, currentTime: int) -> None:
        # 只有令牌存在且未过期才更新
        if tokenId in self.tokens and self.tokens[tokenId] > currentTime:
            self.tokens[tokenId] = currentTime + self.ttl

    def countUnexpiredTokens(self, currentTime: int) -> int:
        # 统计未过期令牌数量
        return sum(1 for exp in self.tokens.values() if exp > currentTime)
```

### 方法二：带惰性清理的哈希表

```python
class AuthenticationManager:
    def __init__(self, timeToLive: int):
        self.ttl = timeToLive
        self.tokens = {}

    def _clean(self, currentTime: int) -> None:
        # 清理已过期的令牌（可选优化）
        expired = [tid for tid, exp in self.tokens.items() if exp <= currentTime]
        for tid in expired:
            del self.tokens[tid]

    def generate(self, tokenId: str, currentTime: int) -> None:
        self.tokens[tokenId] = currentTime + self.ttl

    def renew(self, tokenId: str, currentTime: int) -> None:
        if tokenId in self.tokens and self.tokens[tokenId] > currentTime:
            self.tokens[tokenId] = currentTime + self.ttl

    def countUnexpiredTokens(self, currentTime: int) -> int:
        self._clean(currentTime)
        return len(self.tokens)
```

## 复杂度分析

**方法一：**
- `generate`：O(1)
- `renew`：O(1)
- `countUnexpiredTokens`：O(n)，n 为令牌数量

**方法二（带清理）：**
- `countUnexpiredTokens`：清理后 O(1)，但清理本身 O(n)

## 关键点总结

1. 核心数据结构：哈希表存储令牌及其过期时间
2. 过期判断：`expire_time > currentTime`（严格大于，等于时已过期）
3. `generate` 调用时令牌一定不存在或已过期，可以直接覆盖
4. 惰性删除：不一定在每次操作时清理，按需即可

## 易错点

1. 过期条件是 `expire_time <= currentTime`（到达过期时刻就算过期），不是 `<`
2. `renew` 只有未过期的才能续期，过期的要忽略
3. 方法二中清理时不能在遍历时直接删除，需要先收集再删除
