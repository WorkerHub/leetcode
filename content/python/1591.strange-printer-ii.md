## 题目描述

有一台奇怪的打印机，每次打印操作时，打印机可以打印一个字符的矩形区域，且每次打印会**覆盖**之前的内容。

给你一个 `m x n` 的矩阵 `targetGrid`，判断能否通过若干次打印操作得到该矩阵。

打印机每次操作选择一个矩形区域 `(r1,c1)` 到 `(r2,c2)`，并用某个颜色填充该区域（会覆盖已有内容）。

**提示：**
- `1 <= m, n <= 60`
- `1 <= targetGrid[i][j] <= 60`

## 解题思路

### 拓扑排序

**核心思想：** 若颜色 A 的矩形区域内有颜色 B，则 A 必须在 B 之前打印（B 后来覆盖了 A 的一部分）。建立"A 必须先于 B"的有向图，判断是否有环（有环则不可能实现）。

**步骤：**
1. 对每种颜色，找其最小覆盖矩形（`min_r, max_r, min_c, max_c`）
2. 在该矩形内，若存在其他颜色，则建立"当前颜色 -> 其他颜色"的有向边
3. 拓扑排序，若存在环则返回 False

## 代码实现

### 方法一：拓扑排序（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def isPrintable(self, targetGrid: List[List[int]]) -> bool:
        m, n = len(targetGrid), len(targetGrid[0])
        MAX_COLOR = 61

        # 找每种颜色的最小覆盖矩形
        bounds = {}  # color -> [min_r, max_r, min_c, max_c]
        for i in range(m):
            for j in range(n):
                c = targetGrid[i][j]
                if c not in bounds:
                    bounds[c] = [i, i, j, j]
                else:
                    bounds[c][0] = min(bounds[c][0], i)
                    bounds[c][1] = max(bounds[c][1], i)
                    bounds[c][2] = min(bounds[c][2], j)
                    bounds[c][3] = max(bounds[c][3], j)

        # 建有向图：若颜色 a 的矩形内有颜色 b，则 a -> b（a 先打印，b 后覆盖）
        graph = {c: set() for c in bounds}
        in_degree = {c: 0 for c in bounds}
        all_edges = set()

        for c, (r1, r2, c1, c2) in bounds.items():
            for i in range(r1, r2 + 1):
                for j in range(c1, c2 + 1):
                    other = targetGrid[i][j]
                    if other != c and (c, other) not in all_edges:
                        all_edges.add((c, other))
                        graph[c].add(other)
                        in_degree[other] += 1

        # 拓扑排序（BFS）
        queue = deque([c for c in bounds if in_degree[c] == 0])
        processed = 0
        while queue:
            c = queue.popleft()
            processed += 1
            for nxt in graph[c]:
                in_degree[nxt] -= 1
                if in_degree[nxt] == 0:
                    queue.append(nxt)

        return processed == len(bounds)
```

## 复杂度分析

- **时间复杂度**：O(M * N * C)，C 为颜色数（至多 60），M * N 为矩阵大小
- **空间复杂度**：O(C^2)，图的边数

## 关键点总结

1. 每种颜色的"最终覆盖范围"是最小外接矩形
2. 若矩形内有其他颜色，说明该颜色必须先打印
3. 拓扑排序检测循环依赖

## 易错点

- 建边时要去重（同一对颜色关系只建一次边）
- 最后检查所有颜色都被处理（`processed == len(bounds)`）
