## 题目描述

我们从一块字母板上的位置 (0, 0) 出发，该坐标对应的字符为 board[0][0]。

在本题里，字母板为：
```
["abcde",
 "fghij",
 "klmno",
 "pqrst",
 "uvwxy",
 "z"]
```

我们可以按下面的指令规则移动：
- 如果方格存在，'U' 意味着将我们的位置上移一行
- 如果方格存在，'D' 意味着将我们的位置下移一行
- 如果方格存在，'L' 意味着将我们的位置左移一列
- 如果方格存在，'R' 意味着将我们的位置右移一列
- '!' 会把在我们当前位置 (r, c) 的字符 board[r][c] 添加到答案中

返回指令序列，用最小的行动次数让答案和目标 target 相同。你可以返回任何达成目标的路径。

**示例 1：**
```
输入：target = "leet"
输出："DDR!UURRR!!DDD!"
```

**示例 2：**
```
输入：target = "code"
输出："RR!DDRR!UUL!R!"
```

**提示：**
- 1 <= target.length <= 100
- target 仅由小写英文字母组成

## 解题思路

这道题的关键是理解字母板的布局和移动规则：

1. **字母板坐标映射**：
   - 每个字母都有固定坐标：a(0,0), b(0,1), ..., z(5,0)
   - 可以通过 ASCII 值计算：行 = (ord(ch) - ord('a')) // 5，列 = (ord(ch) - ord('a')) % 5

2. **特殊情况处理 - 'z' 的位置**：
   - 'z' 在第 5 行第 0 列，是唯一的特殊位置
   - 从其他位置到 'z'：必须先左移到第 0 列，再下移
   - 从 'z' 到其他位置：必须先上移，再右移
   - 这样避免移动到不存在的格子

3. **移动策略**：
   - 一般情况：先垂直移动，再水平移动（或相反）
   - 涉及 'z' 时：必须调整顺序避免越界

4. **路径生成**：
   - 计算当前位置到目标位置的行列差
   - 根据差值生成 U/D/L/R 指令
   - 添加 '!' 表示选择当前字符

## Python 代码实现

### 方法一：模拟 + 特殊处理 ⭐

```python
class Solution:
    def alphabetBoardPath(self, target: str) -> str:
        """
        模拟移动过程，特别处理 'z' 的情况
        时间复杂度：O(n)，n 为 target 长度
        空间复杂度：O(n)，结果字符串
        """
        result = []
        # 当前位置
        cur_row, cur_col = 0, 0
        
        for char in target:
            # 计算目标字符的坐标
            target_row = (ord(char) - ord('a')) // 5
            target_col = (ord(char) - ord('a')) % 5
            
            # 计算需要移动的行列数
            row_diff = target_row - cur_row
            col_diff = target_col - cur_col
            
            # 关键：处理 'z' 的特殊情况
            # 如果目标是 'z' (5,0)，先左移再下移
            # 如果当前是 'z'，先上移再右移
            
            if cur_row == 5:  # 当前在 'z'
                # 先上移
                result.append('U' * abs(row_diff))
                # 再右移
                result.append('R' * abs(col_diff))
            elif target_row == 5:  # 目标是 'z'
                # 先左移
                if col_diff < 0:
                    result.append('L' * abs(col_diff))
                # 再下移
                if row_diff > 0:
                    result.append('D' * abs(row_diff))
            else:  # 普通情况
                # 垂直移动
                if row_diff > 0:
                    result.append('D' * row_diff)
                else:
                    result.append('U' * abs(row_diff))
                # 水平移动
                if col_diff > 0:
                    result.append('R' * col_diff)
                else:
                    result.append('L' * abs(col_diff))
            
            # 选择当前字符
            result.append('!')
            
            # 更新当前位置
            cur_row, cur_col = target_row, target_col
        
        return ''.join(result)
```

### 方法二：简化版（统一处理）⭐ 推荐

```python
class Solution:
    def alphabetBoardPath(self, target: str) -> str:
        """
        更简洁的实现：始终先处理左移和上移，再处理下移和右移
        这样可以避免移动到不存在的格子
        """
        result = []
        cur_row, cur_col = 0, 0
        
        for char in target:
            # 计算目标坐标
            target_row = (ord(char) - ord('a')) // 5
            target_col = (ord(char) - ord('a')) % 5
            
            # 计算移动距离
            row_diff = target_row - cur_row
            col_diff = target_col - cur_col
            
            # 策略：先左移、上移（离开 z 或避免进入 z 的无效区域）
            if col_diff < 0:
                result.append('L' * abs(col_diff))
            if row_diff < 0:
                result.append('U' * abs(row_diff))
            
            # 再下移、右移（安全进入 z 或其他位置）
            if row_diff > 0:
                result.append('D' * row_diff)
            if col_diff > 0:
                result.append('R' * col_diff)
            
            # 选择字符
            result.append('!')
            
            # 更新位置
            cur_row, cur_col = target_row, target_col
        
        return ''.join(result)
```

### 方法三：使用坐标字典

```python
class Solution:
    def alphabetBoardPath(self, target: str) -> str:
        """
        预先构建字母到坐标的映射
        """
        # 构建字母到坐标的映射
        board = ["abcde", "fghij", "klmno", "pqrst", "uvwxy", "z"]
        pos = {}
        for r, row in enumerate(board):
            for c, char in enumerate(row):
                pos[char] = (r, c)
        
        result = []
        cur_r, cur_c = 0, 0
        
        for char in target:
            target_r, target_c = pos[char]
            
            # 先左移和上移
            if cur_c > target_c:
                result.append('L' * (cur_c - target_c))
            if cur_r > target_r:
                result.append('U' * (cur_r - target_r))
            
            # 再下移和右移
            if cur_r < target_r:
                result.append('D' * (target_r - cur_r))
            if cur_c < target_c:
                result.append('R' * (target_c - cur_c))
            
            result.append('!')
            cur_r, cur_c = target_r, target_c
        
        return ''.join(result)
```

## 复杂度分析

**时间复杂度**：O(n)，其中 n 是 target 的长度
- 需要遍历 target 中的每个字符
- 每个字符的处理时间为常数级别

**空间复杂度**：O(n)
- 结果字符串的长度最多为 O(n)
- 最坏情况下每个字符需要移动最多 9 步（从 z 到 e）

## 关键点总结

1. **坐标计算公式**：行 = (ord(ch) - ord('a')) // 5，列 = (ord(ch) - ord('a')) % 5
2. **'z' 的特殊性**：位于 (5, 0)，其右侧和下方没有有效格子
3. **移动顺序**：先左移/上移，再下移/右移，避免越界
4. **字符串拼接优化**：使用列表收集结果，最后 join
5. **边界安全性**：移动顺序保证永远不会到达无效格子

## 易错点

1. **'z' 处理遗漏**：忘记特殊处理 'z' 导致移动到无效位置
2. **移动顺序错误**：先下移再左移可能越界
3. **忘记添加 '!'**：每次到达目标位置后必须添加
4. **坐标计算错误**：行列计算公式弄反
5. **重复移动**：没有更新当前位置导致重复计算
