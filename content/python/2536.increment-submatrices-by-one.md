## 题目描述

给你一个正整数 `n`，表示 `n x n` 矩阵，初始全为 0。同时给你二维数组 `queries`，其中 `queries[i] = [row1, col1, row2, col2]`。

对每个查询，将以 `(row1, col1)` 为左上角、`(row2, col2)` 为右下角的子矩阵中所有元素加 1。

返回执行完所有查询后的矩阵。

**示例 1：**

```
输入：n = 3, queries = [[1,1,2,2],[0,0,1,1]]
输出：[[1,1,0],[1,2,1],[0,1,1]]
```

**示例 2：**

```
输入：n = 2, queries = [[0,0,1,1]]
输出：[[1,1],[1,1]]
```

**提示：**

- `1 <= n <= 500`
- `1 <= queries.length <= 10^4`

## 解题思路

**二维差分数组**：对矩形区域的批量加一操作，用二维差分数组高效处理。

对于矩形 `(r1, c1)` 到 `(r2, c2)` 加 1，差分数组操作：
- `diff[r1][c1] += 1`
- `diff[r1][c2+1] -= 1`
- `diff[r2+1][c1] -= 1`
- `diff[r2+1][c2+1] += 1`

最后对差分数组做二维前缀和还原。

## Python 代码实现

### 方法一：二维差分数组（推荐）

```python
from typing import List

class Solution:
    def rangeAddQueries(self, n: int, queries: List[List[int]]) -> List[List[int]]:
        # 差分数组大小 (n+1) x (n+1)
        diff = [[0] * (n + 1) for _ in range(n + 1)]

        for r1, c1, r2, c2 in queries:
            diff[r1][c1] += 1
            if c2 + 1 <= n:
                diff[r1][c2 + 1] -= 1
            if r2 + 1 <= n:
                diff[r2 + 1][c1] -= 1
            if r2 + 1 <= n and c2 + 1 <= n:
                diff[r2 + 1][c2 + 1] += 1

        # 前缀和还原
        ans = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if i > 0:
                    diff[i][j] += diff[i-1][j]
                if j > 0:
                    diff[i][j] += diff[i][j-1]
                if i > 0 and j > 0:
                    diff[i][j] -= diff[i-1][j-1]
                ans[i][j] = diff[i][j]

        return ans
```

### 方法二：逐行差分

```python
from typing import List

class Solution:
    def rangeAddQueries(self, n: int, queries: List[List[int]]) -> List[List[int]]:
        # 对每行用一维差分，然后逐行处理
        ans = [[0] * n for _ in range(n)]

        for r1, c1, r2, c2 in queries:
            for row in range(r1, r2 + 1):
                ans[row][c1] += 1
                if c2 + 1 < n:
                    ans[row][c2 + 1] -= 1

        # 对每行求前缀和
        for row in range(n):
            for col in range(1, n):
                ans[row][col] += ans[row][col - 1]

        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(q + n²)，q 次差分操作 + n² 前缀和还原
- 方法二时间复杂度：O(q * (r2-r1) + n²)，最坏 O(q*n + n²)
- 空间复杂度：O(n²)

## 关键点总结

1. 二维差分数组解决矩形区域批量更新问题
2. 差分操作：4 个角点的加减操作
3. 最后通过二维前缀和还原实际值

## 易错点

1. 差分数组需要 (n+1) x (n+1) 大小，避免越界
2. 二维前缀和还原顺序：先行前缀和，再列前缀和（或同时处理）
3. 前缀和计算中要减去重复加的部分（容斥）
