## 题目描述

`RandomizedCollection` 是一种包含数字集合(可能是重复的)的数据结构。它应该支持插入和删除特定元素，以及随机获取元素。

实现 `RandomizedCollection` 类:

- `RandomizedCollection()` 初始化空的 `RandomizedCollection` 对象。
- `bool insert(int val)` 将一个 `val` 项插入到集合中，即使该项已经存在。如果该项不存在，则返回 `true`，否则返回 `false`。
- `bool remove(int val)` 如果存在，从集合中移除一个 `val` 项。如果该项存在，则返回 `true`，否则返回 `false`。注意，如果 `val` 在集合中出现多次，我们只删除其中一个。
- `int getRandom()` 从当前的元素集合中返回一个随机元素。每个元素被返回的概率与集合中包含的相同值的数量成线性相关。

你必须实现类的函数，使每个函数的**平均**时间复杂度为 **O(1)**。

**注意：** 生成测试用例时，只有在 `RandomizedCollection` 中**至少有一项**时，才会调用 `getRandom`。

**示例 1:**

```
输入
["RandomizedCollection", "insert", "insert", "insert", "getRandom", "remove", "getRandom"]
[[], [1], [1], [2], [], [1], []]
输出
[null, true, false, true, 2, true, 1]

解释
RandomizedCollection randomizedCollection = new RandomizedCollection();
randomizedCollection.insert(1);   // 返回 true，集合不包含 1。
                                  // 插入 1 到集合。
randomizedCollection.insert(1);   // 返回 false，集合包含 1。
                                  // 再次插入 1 到集合，集合现在包含 [1,1]。
randomizedCollection.insert(2);   // 返回 true，集合不包含 2。
                                  // 插入 2 到集合，集合现在包含 [1,1,2]。
randomizedCollection.getRandom(); // getRandom 应当:
                                  // 有 2/3 的概率返回 1，
                                  // 有 1/3 的概率返回 2。
randomizedCollection.remove(1);   // 返回 true，集合包含 1。
                                  // 从集合中移除 1，集合现在包含 [1,2]。
randomizedCollection.getRandom(); // getRandom 应当:
                                  // 有 1/2 的概率返回 1，
                                  // 有 1/2 的概率返回 2。
```

**提示:**

- `-2^31 <= val <= 2^31 - 1`
- `insert`, `remove` 和 `getRandom` 最多被调用 `2 * 10^5` 次
- 当调用 `getRandom` 时，数据结构中**至少有一个**元素

## 解题思路

本题是 [380. Insert Delete GetRandom O(1)](https://leetcode.com/problems/insert-delete-getrandom-o1/) 的进阶版，区别在于允许重复元素。

**核心思想：**

1. **数组 + 哈希表组合**：
   - 使用**动态数组** `nums` 存储所有元素（包括重复的）
   - 使用**哈希表** `val_to_indices` 存储每个值对应的所有索引位置（集合形式）

2. **插入操作**：
   - 将元素添加到数组末尾
   - 在哈希表中记录该元素在数组中的索引
   - 如果是第一次插入该值，返回 `true`；否则返回 `false`

3. **删除操作（关键）**：
   - 找到要删除元素的任意一个索引位置
   - 将数组末尾元素移动到要删除的位置（覆盖）
   - 更新哈希表：
     - 更新末尾元素的索引集合
     - 删除被移除元素的该索引
   - 删除数组末尾元素

4. **随机获取**：
   - 直接从数组中随机选择一个索引返回

**为什么使用集合存储索引？**

因为同一个值可能在数组中出现多次，我们需要记录所有位置。删除时只需删除其中一个位置即可。

## Python 代码实现

### 方法一：数组 + 哈希表（推荐）⭐

```python
from typing import List
import random
from collections import defaultdict

class RandomizedCollection:
    def __init__(self):
        """初始化数据结构"""
        self.nums = []  # 存储所有元素
        self.val_to_indices = defaultdict(set)  # 值 -> 索引集合的映射

    def insert(self, val: int) -> bool:
        """
        插入元素到集合中
        时间复杂度: O(1)
        """
        # 记录该值是否是第一次出现
        is_new = len(self.val_to_indices[val]) == 0
        
        # 将元素添加到数组末尾
        self.nums.append(val)
        
        # 在哈希表中记录索引位置
        self.val_to_indices[val].add(len(self.nums) - 1)
        
        return is_new

    def remove(self, val: int) -> bool:
        """
        删除集合中的一个元素
        时间复杂度: O(1)
        """
        # 如果元素不存在，返回 False
        if not self.val_to_indices[val]:
            return False
        
        # 获取要删除元素的任意一个索引
        remove_idx = self.val_to_indices[val].pop()
        
        # 获取数组末尾元素
        last_val = self.nums[-1]
        
        # 将末尾元素移动到要删除的位置
        self.nums[remove_idx] = last_val
        
        # 更新末尾元素的索引集合
        self.val_to_indices[last_val].add(remove_idx)
        self.val_to_indices[last_val].discard(len(self.nums) - 1)
        
        # 删除数组末尾元素
        self.nums.pop()
        
        # 特殊情况：如果删除的就是末尾元素，需要清理索引
        # 这种情况下 remove_idx 可能等于 len(self.nums)
        if remove_idx == len(self.nums):
            self.val_to_indices[last_val].discard(remove_idx)
        
        return True

    def getRandom(self) -> int:
        """
        随机返回一个元素
        时间复杂度: O(1)
        """
        return random.choice(self.nums)
```

### 方法二：优化的删除逻辑

```python
from typing import List
import random
from collections import defaultdict

class RandomizedCollection:
    def __init__(self):
        self.nums = []
        self.val_to_indices = defaultdict(set)

    def insert(self, val: int) -> bool:
        self.nums.append(val)
        self.val_to_indices[val].add(len(self.nums) - 1)
        return len(self.val_to_indices[val]) == 1

    def remove(self, val: int) -> bool:
        if not self.val_to_indices[val]:
            return False
        
        # 要删除的索引
        remove_idx = self.val_to_indices[val].pop()
        last_idx = len(self.nums) - 1
        last_val = self.nums[last_idx]
        
        # 将末尾元素移到要删除的位置
        self.nums[remove_idx] = last_val
        
        # 更新索引集合
        self.val_to_indices[last_val].add(remove_idx)
        self.val_to_indices[last_val].discard(last_idx)
        
        # 删除末尾元素
        self.nums.pop()
        
        return True

    def getRandom(self) -> int:
        return self.nums[random.randint(0, len(self.nums) - 1)]
```

## 复杂度分析

**时间复杂度：**
- `insert(val)`: O(1) - 数组末尾插入和哈希表添加都是常数时间
- `remove(val)`: O(1) - 哈希表查找、数组末尾删除、集合添加/删除都是常数时间
- `getRandom()`: O(1) - 随机访问数组元素

**空间复杂度：** O(n)
- `nums` 数组存储所有元素：O(n)
- `val_to_indices` 哈希表存储所有索引：O(n)

## 关键点总结

1. **数据结构选择**：数组支持 O(1) 随机访问，哈希表支持 O(1) 查找
2. **删除技巧**：用末尾元素覆盖要删除的元素，然后删除末尾，避免数组元素移动
3. **集合存储索引**：同一值可能有多个索引，使用 `set` 存储所有位置
4. **边界情况处理**：删除的元素恰好是末尾元素时，需要正确更新索引
5. **随机性保证**：由于重复元素在数组中占多个位置，随机选择时自然符合概率要求

## 易错点

1. **忘记处理重复元素**：同一个值可能出现多次，需要用集合存储所有索引
2. **删除末尾元素的特殊情况**：当删除的恰好是最后一个元素时，不要重复更新索引
3. **索引更新顺序**：必须先添加新索引，再删除旧索引，避免集合为空
4. **返回值错误**：`insert` 返回的是"是否是新值"，不是"是否插入成功"
