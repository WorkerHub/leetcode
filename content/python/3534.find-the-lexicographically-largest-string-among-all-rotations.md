## 题目描述

给定一个字符串 `s`，找出其所有旋转（循环移位）中字典序最大的那个。旋转 `k` 次指将字符串向左循环移位 `k` 个位置。

**示例 1：**

```
输入：s = "abcd"
输出："dabc"
解释：旋转 1 次: "bcda"，旋转 2 次: "cdab"，旋转 3 次: "dabc"，旋转 0 次: "abcd"
     字典序最大的是 "dabc"。
```

**示例 2：**

```
输入：s = "zza"
输出："zza"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只含小写字母

## 解题思路

枚举所有旋转，找字典序最大的。但 O(n^2) 可能超时，需要更高效的方法。

高效方法：
1. 找字符串中最大字符的位置
2. 若有多个最大字符，进一步比较它们开始的旋转串
3. 使用后缀数组或哈希比较

更简单：构造双倍字符串 `s + s`，找其中长度为 n 的子串中字典序最大的，其起始位置对应最优旋转量。

## Python 代码实现

### 方法一：双倍字符串 + 最大子串（推荐）

```python
class Solution:
    def largestRotation(self, s: str) -> str:
        n = len(s)
        doubled = s + s
        # 找 doubled 中所有长度为 n 的子串的最大值
        best_start = 0
        for i in range(1, n):
            if doubled[i:i+n] > doubled[best_start:best_start+n]:
                best_start = i
        return doubled[best_start:best_start+n]
```

### 方法二：找最大字符起始位置

```python
class Solution:
    def largestRotation(self, s: str) -> str:
        n = len(s)
        max_char = max(s)
        # 找所有最大字符的位置
        candidates = [i for i, c in enumerate(s) if c == max_char]

        # 在候选位置中找字典序最大的旋转
        best = s[candidates[0]:] + s[:candidates[0]]
        for i in candidates[1:]:
            rot = s[i:] + s[:i]
            if rot > best:
                best = rot

        return best
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一字符串比较），O(n * k)（方法二，k 为最大字符数）
- 空间复杂度：O(n)

## 关键点总结

1. 旋转 k 次等价于从位置 k 开始的后缀拼接前缀
2. 最大旋转一定从最大字符开始
3. 双倍字符串技巧：枚举起始位置

## 易错点

1. 旋转后字符串长度不变，仍为 n
2. 有多个最大字符时需要逐个比较
3. 方法一的字符串比较是 O(n)，整体为 O(n^2)，对大数据可能超时
