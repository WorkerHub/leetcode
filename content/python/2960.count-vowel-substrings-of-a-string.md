## 题目描述

给你一个字符串 `word`，统计满足以下条件的子字符串数目：
- 该子字符串只包含元音字母（`a, e, i, o, u`）
- 该子字符串包含五个元音字母中的每一个至少一次

**示例 1：**
```
输入：word = "aeiouu"
输出：2
解释："aeiou" 和 "aeiouu" 满足条件
```

**示例 2：**
```
输入：word = "unicornarihan"
输出：0
```

**提示：**
- `1 <= word.length <= 100`
- `word` 只含小写英文字母

## 解题思路

暴力枚举所有子字符串，检查两个条件：1. 只含元音；2. 包含所有五种元音。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')
        n = len(word)
        ans = 0

        for i in range(n):
            if word[i] not in vowels:
                continue
            seen = set()
            for j in range(i, n):
                if word[j] not in vowels:
                    break  # 遇到辅音，停止
                seen.add(word[j])
                if len(seen) == 5:
                    ans += 1

        return ans
```

### 方法二：使用 Counter

```python
from collections import Counter

class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')
        n = len(word)
        ans = 0
        for i in range(n):
            if word[i] not in vowels:
                continue
            cnt = Counter()
            for j in range(i, n):
                if word[j] not in vowels:
                    break
                cnt[word[j]] += 1
                if len(cnt) == 5:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有起始位置和子串
- 空间复杂度：O(1)（集合最多 5 个元素）

## 关键点总结

1. 遇到辅音直接 break（子串必须只含元音）
2. 用集合跟踪子串包含的不同元音数，等于 5 时符合条件
3. n <= 100 时 O(n^2) 完全够用

## 易错点

1. 子串必须连续（不是子序列）
2. 遇到辅音要停止当前起点的内层循环
3. 包含全部五种元音（而不是至少 5 个元音字母）
