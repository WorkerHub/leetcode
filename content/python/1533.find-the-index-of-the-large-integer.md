## 题目描述

这是一道**交互题**。

有一个隐藏数组 `arr`，它由整数组成，里面恰好有一个元素大于其他所有元素（最大值唯一）。

你可以通过 `ArrayReader` 接口查询：
- `reader.compareSub(l, r, x, y)`：比较 `arr[l..r]` 的和与 `arr[x..y]` 的和，返回 1（前者大），0（相等），-1（前者小）
- `reader.length()`：返回数组长度

用最多 **20 次查询** 找到最大值的下标。

## 解题思路

### 二分查找

将数组分成左右两半，比较两半的和。最大元素所在的那半和更大（或相等时需要特殊处理）。

每次将搜索范围缩小一半，最多 `log2(1000) ≈ 10` 次查询可以找到答案。

**关键：** 若两半长度不同（奇数长度），需要处理中间元素。

## 代码实现

### 方法一：二分查找（推荐）

```python
class Solution:
    def getIndex(self, reader: 'ArrayReader') -> int:
        lo, hi = 0, reader.length() - 1

        while lo < hi:
            mid = (lo + hi) // 2
            # 左半 [lo, mid]，右半 [mid+1, hi]
            left_len = mid - lo + 1
            right_len = hi - mid

            if left_len == right_len:
                # 等长比较
                result = reader.compareSub(lo, mid, mid + 1, hi)
                if result == 1:
                    hi = mid
                elif result == -1:
                    lo = mid + 1
                else:
                    # 相等不可能（只有一个最大值）
                    # 实际上相等说明最大值不在这段里，但本题保证有唯一最大值
                    break
            else:
                # 左半多一个，先比较等长部分
                result = reader.compareSub(lo, mid - 1, mid + 1, hi)
                if result == 1:
                    hi = mid - 1
                elif result == -1:
                    lo = mid + 1
                else:
                    # 两侧等长部分和相等，最大值在中间位置 mid
                    return mid

        return lo
```

### 方法二：更清晰的等长二分

```python
class Solution:
    def getIndex(self, reader: 'ArrayReader') -> int:
        lo, hi = 0, reader.length() - 1

        while lo < hi:
            mid = (lo + hi) // 2
            # 保证比较等长区间，若总长为奇数，中间元素 mid 先不比
            left_right_len = (hi - lo) // 2

            # 左半 [lo, lo + left_right_len - 1]，右半 [hi - left_right_len + 1, hi]
            # 更简单：总是比较左右等长部分
            l_end = lo + left_right_len - 1 if (hi - lo + 1) % 2 == 0 else mid - 1
            r_start = hi - left_right_len + 1 if (hi - lo + 1) % 2 == 0 else mid + 1

            if (hi - lo + 1) % 2 == 0:
                # 偶数长度，直接二等分
                result = reader.compareSub(lo, mid, mid + 1, hi)
                if result >= 0:
                    hi = mid
                else:
                    lo = mid + 1
            else:
                # 奇数长度，比较等长的左右两段（排除中间 mid）
                result = reader.compareSub(lo, mid - 1, mid + 1, hi)
                if result > 0:
                    hi = mid - 1
                elif result < 0:
                    lo = mid + 1
                else:
                    return mid  # 中间元素是最大值

        return lo
```

## 复杂度分析

- **时间复杂度**：O(log N)，每次查询将范围缩小一半
- **空间复杂度**：O(1)
- **查询次数**：最多 `ceil(log2(n))` 次，n=1000 时约 10 次

## 关键点总结

1. 每次比较两半，最大值必在和更大的那半
2. 奇数长度时，中间元素单独处理（若两侧和相等，中间即为答案）
3. 最多 20 次查询绰绰有余（log2(1000) ≈ 10）

## 易错点

- 奇数长度比较时，如果两侧等长部分和相等，答案是中间位置
- 偶数长度时不需要特殊处理中间元素
