## 题目描述

给你两个下标从 **0** 开始的字符串 `s` 和 `target`。你可以从 `s` 中取字符（每个字符只能取一次）来重新排列，组成 `target` 的一个或多个副本。

返回可以组成的 `target` **最多副本数**。

**示例 1：**
```
输入：s = "ilovecodingonleetcode", target = "code"
输出：2
解释：s 中 c:2, o:3, d:2, e:3，target 中 c:1, o:1, d:1, e:1，各取最少 2 个，故最多 2 副本。
```

**示例 2：**
```
输入：s = "abcba", target = "abc"
输出：1
```

## 解题思路

统计 `s` 中每个字符的频次 `cs` 和 `target` 中每个字符的频次 `ct`，对 `target` 中每个字符 `c`，最多能组成 `cs[c] // ct[c]` 副本，取所有字符的最小值。

## 代码实现

### 方法一：Counter + 整除（推荐）

```python
from collections import Counter

class Solution:
    def rearrangeCharacters(self, s: str, target: str) -> int:
        cs = Counter(s)
        ct = Counter(target)
        # 对 target 中每个字符，计算能组成的副本数，取最小
        return min(cs[c] // ct[c] for c in ct)
```

### 方法二：手动统计

```python
class Solution:
    def rearrangeCharacters(self, s: str, target: str) -> int:
        # 统计各字符频次
        freq_s = {}
        for c in s:
            freq_s[c] = freq_s.get(c, 0) + 1

        freq_t = {}
        for c in target:
            freq_t[c] = freq_t.get(c, 0) + 1

        ans = float('inf')
        for c, need in freq_t.items():
            have = freq_s.get(c, 0)
            ans = min(ans, have // need)

        return ans
```

## 复杂度分析

- 时间复杂度：O(|s| + |target|)，统计频次。
- 空间复杂度：O(1)，字符集大小固定（26 个字母）。

## 关键点总结

1. 对 `target` 中每个字符，能组成的副本数 = `freq_s[c] // freq_t[c]`。
2. 取所有字符能组成副本数的最小值（短板效应）。
3. `Counter` 对不存在的键默认返回 0，可以直接 `cs[c]`。

## 易错点

- 若 `target` 中某字符不在 `s` 中，`cs[c] // ct[c] = 0 // k = 0`，结果正确。
- 注意是每个字符只能取一次（不是无限供应）。
