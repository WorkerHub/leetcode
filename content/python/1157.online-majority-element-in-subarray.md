## 题目描述

设计一个数据结构，用来查询指定子数组中满足出现次数达到阈值的元素。

实现 `MajorityChecker` 类：

- `MajorityChecker(int[] arr)` 使用给定的数组 `arr` 初始化实例
- `int query(int left, int right, int threshold)` 返回子数组 `arr[left...right]` 中出现次数至少为 `threshold` 的元素，如果不存在这样的元素则返回 `-1`

示例：

```
输入：
["MajorityChecker", "query", "query", "query"]
[[[1, 1, 2, 2, 1, 1]], [0, 5, 4], [0, 3, 3], [2, 3, 2]]
输出：
[null, 1, -1, 2]

解释：
MajorityChecker majorityChecker = new MajorityChecker([1, 1, 2, 2, 1, 1]);
majorityChecker.query(0, 5, 4); // 返回 1，在区间 [0,5] 中，1 出现了 4 次
majorityChecker.query(0, 3, 3); // 返回 -1，没有元素出现至少 3 次
majorityChecker.query(2, 3, 2); // 返回 2，在区间 [2,3] 中，2 出现了 2 次
```

提示：

- `1 <= arr.length <= 2 * 10^4`
- `1 <= arr[i] <= 2 * 10^4`
- `0 <= left <= right < arr.length`
- `threshold <= right - left + 1`
- 最多调用 `query` 方法 `10^4` 次

## 解题思路

这是一道设计类难题，核心挑战在于如何高效查询子数组中的多数元素。直接遍历会超时，需要优化。

**核心观察：**

1. 如果一个元素在子数组中出现次数达到 threshold，它必须是该子数组的"候选多数元素"之一
2. 在任意子数组中，出现次数超过 threshold 的元素最多只有少数几个
3. 我们可以使用随机化 + 哈希表 + 二分查找的组合策略

**算法策略：**

**方法一：预处理 + 随机化 + 二分查找**
- 预处理阶段：为每个元素记录它在数组中所有出现的位置索引
- 查询阶段：随机选择子数组中的一些元素作为候选，用二分查找验证其出现次数
- 随机选择若干次，概率上能找到正确答案

**方法二：摩尔投票法 + 二分查找**
- 使用摩尔投票法找出可能的候选元素
- 然后用二分查找验证候选元素的实际出现次数

## Python 代码实现

### 方法一：随机化 + 二分查找（推荐）

```python
from typing import List
from collections import defaultdict
import random
import bisect

class MajorityChecker:
    def __init__(self, arr: List[int]):
        """
        初始化数据结构
        预处理：记录每个元素的所有出现位置
        """
        self.arr = arr
        # positions[x] 存储元素 x 在数组中的所有索引位置（有序）
        self.positions = defaultdict(list)
        for i, num in enumerate(arr):
            self.positions[num].append(i)
    
    def query(self, left: int, right: int, threshold: int) -> int:
        """
        查询子数组 [left, right] 中出现次数至少为 threshold 的元素
        
        算法思想：
        1. 随机采样：在子数组中随机选择元素作为候选
        2. 如果真的存在多数元素，随机选中它的概率很高
        3. 用二分查找快速计算候选元素在区间内的出现次数
        """
        # 随机采样次数（通常 20 次足够，概率接近 100%）
        for _ in range(20):
            # 在 [left, right] 范围内随机选择一个索引
            rand_idx = random.randint(left, right)
            candidate = self.arr[rand_idx]
            
            # 使用二分查找计算 candidate 在 [left, right] 区间的出现次数
            pos_list = self.positions[candidate]
            # 找到第一个 >= left 的位置
            left_pos = bisect.bisect_left(pos_list, left)
            # 找到第一个 > right 的位置
            right_pos = bisect.bisect_right(pos_list, right)
            
            # 区间内的出现次数
            count = right_pos - left_pos
            
            # 如果满足阈值要求，返回该元素
            if count >= threshold:
                return candidate
        
        # 20 次随机采样都没找到，说明不存在
        return -1
```

### 方法二：摩尔投票 + 二分查找

```python
from typing import List
from collections import defaultdict
import bisect

class MajorityChecker:
    def __init__(self, arr: List[int]):
        """初始化，记录每个元素的位置"""
        self.arr = arr
        self.positions = defaultdict(list)
        for i, num in enumerate(arr):
            self.positions[num].append(i)
    
    def query(self, left: int, right: int, threshold: int) -> int:
        """使用摩尔投票法找候选元素"""
        # 摩尔投票法找出可能的多数元素
        candidate, count = -1, 0
        for i in range(left, right + 1):
            num = self.arr[i]
            if count == 0:
                candidate = num
                count = 1
            elif num == candidate:
                count += 1
            else:
                count -= 1
        
        # 验证候选元素的实际出现次数
        pos_list = self.positions[candidate]
        left_pos = bisect.bisect_left(pos_list, left)
        right_pos = bisect.bisect_right(pos_list, right)
        actual_count = right_pos - left_pos
        
        return candidate if actual_count >= threshold else -1
```

### 方法三：线段树（最优但实现复杂）

```python
from typing import List
from collections import defaultdict
import bisect

class MajorityChecker:
    def __init__(self, arr: List[int]):
        """预处理位置信息"""
        self.arr = arr
        self.positions = defaultdict(list)
        for i, num in enumerate(arr):
            self.positions[num].append(i)
    
    def _get_count(self, num: int, left: int, right: int) -> int:
        """使用二分查找获取元素在区间内的出现次数"""
        pos_list = self.positions[num]
        left_pos = bisect.bisect_left(pos_list, left)
        right_pos = bisect.bisect_right(pos_list, right)
        return right_pos - left_pos
    
    def query(self, left: int, right: int, threshold: int) -> int:
        """优化的随机化方法"""
        length = right - left + 1
        # 最多尝试 30 次随机采样
        for _ in range(30):
            # 随机选择一个位置
            idx = left + (hash(_) % length)
            candidate = self.arr[idx]
            
            # 快速验证
            if self._get_count(candidate, left, right) >= threshold:
                return candidate
        
        return -1
```

## 复杂度分析

**方法一：随机化 + 二分查找**
- 时间复杂度：
  - 初始化：`O(n)`，需要遍历数组建立位置映射
  - 单次查询：`O(k * log n)`，其中 k 是随机采样次数（通常 k=20），二分查找的时间复杂度为 `O(log n)`
- 空间复杂度：`O(n)`，存储每个元素的位置列表

**方法二：摩尔投票 + 二分查找**
- 时间复杂度：
  - 初始化：`O(n)`
  - 单次查询：`O(m + log n)`，其中 m 是查询区间长度
- 空间复杂度：`O(n)`

## 关键点总结

1. **随机化算法的正确性**：如果存在出现次数 >= threshold 的元素，随机选中它的概率为 threshold/(right-left+1)，多次采样后成功概率接近 100%

2. **二分查找优化**：预处理每个元素的位置列表后，可以用二分查找在 O(log n) 时间内计算区间出现次数

3. **trade-off**：用少量的随机性换取高效的查询性能，这是处理在线查询的常用技巧

4. **摩尔投票法的局限**：对于 threshold 较小的情况，摩尔投票法可能找不到正确答案，因为它只能找出现次数 > 50% 的元素

5. **实际应用**：这类问题在流式数据处理、实时统计分析中很常见

## 易错点

1. **边界处理**：注意 bisect_left 和 bisect_right 的区别，计算区间出现次数时要用对函数

2. **随机次数选择**：采样次数太少可能导致错误，通常 20-30 次是比较稳妥的选择

3. **候选验证**：找到候选元素后必须验证实际出现次数，不能直接返回

4. **空区间处理**：虽然题目保证了合法输入，但实际应用中要注意处理空区间情况

5. **摩尔投票适用性**：摩尔投票只对 threshold > length/2 的情况有效，本题 threshold 可以更小
