## 题目描述

给你一个字符串 `word`，使用以下算法进行压缩：

从空字符串 `comp` 开始，按以下步骤操作直到 `word` 为空：
1. 找 `word` 当前字符 `word[0]`，计算连续重复的次数 `cnt`（最多 9）
2. 将 `cnt` 的字符串形式和 `word[0]` 追加到 `comp`
3. 从 `word` 中删除这 `cnt` 个字符

返回压缩后的字符串 `comp`。

**示例 1：**
```
输入：word = "abcde"
输出："1a1b1c1d1e"
```

**示例 2：**
```
输入：word = "aaaaaaaaaaaaaabb"
输出："9a5a2b"
解释：连续 a 有 14 个，第一组最多取 9，剩余 5，然后 2 个 b
```

**提示：**
- `1 <= word.length <= 2 * 10^5`
- `word` 只包含小写字母

## 解题思路

贪心：从左到右遍历，统计每段连续相同字符的长度，每次最多取 9 个，分组追加到结果。

## Python 代码实现

### 方法一：贪心分组（推荐）

```python
class Solution:
    def compressedString(self, word: str) -> str:
        res = []
        i = 0
        n = len(word)
        while i < n:
            c = word[i]
            cnt = 0
            while i < n and word[i] == c and cnt < 9:
                cnt += 1
                i += 1
            res.append(str(cnt) + c)
        return ''.join(res)
```

### 方法二：使用 itertools.groupby

```python
from itertools import groupby

class Solution:
    def compressedString(self, word: str) -> str:
        res = []
        for c, group in groupby(word):
            count = len(list(group))
            while count > 0:
                take = min(count, 9)
                res.append(str(take) + c)
                count -= take
        return ''.join(res)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，结果字符串

## 关键点总结

1. 每段相同字符最多取 9 个，超过则分多组
2. 每组格式为 `数字+字符`

## 易错点

1. 连续相同字符超过 9 个时，需要多次输出
2. 每组的数字最大为 9，不是无限
