## 题目描述

给定一个二维平面上的 `n` 栋建筑，每栋建筑的位置为 `(x, y)`。若一栋建筑在同一行（x 相同）有另一栋建筑在其左侧和右侧，且在同一列（y 相同）有另一栋建筑在其上方和下方，则该建筑被"覆盖"。求被覆盖的建筑数量。

**示例：**

```
输入：n = 5, buildings = [[1,2],[2,2],[3,2],[2,1],[2,3]]
输出：1
解释：(2,2) 在第2行有 (1,2) 和 (3,2)，在第2列有 (2,1) 和 (2,3)，故被覆盖。
```

**提示：**
- `1 <= n <= 10^5`
- `buildings[i]` 的坐标唯一

## 解题思路

对于每栋建筑 `(x, y)`：
1. 在同一行（相同 x 坐标）中，是否存在 y' < y 和 y'' > y 的建筑
2. 在同一列（相同 y 坐标）中，是否存在 x' < x 和 x'' > x 的建筑

预处理：
- 对每行（x 坐标），记录该行所有建筑的 y 坐标的最小值和最大值
- 对每列（y 坐标），记录该列所有建筑的 x 坐标的最小值和最大值

对每栋建筑，只需检查四个条件：
- 同行最小 y < y（左侧有建筑）
- 同行最大 y > y（右侧有建筑）
- 同列最小 x < x（下方有建筑）
- 同列最大 x > x（上方有建筑）

## Python 代码实现

### 方法一：哈希表预处理（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCoveredBuildings(self, n: int, buildings: List[List[int]]) -> int:
        # 按行统计 y 的最小最大值
        row_min_y = defaultdict(lambda: float('inf'))
        row_max_y = defaultdict(lambda: float('-inf'))
        # 按列统计 x 的最小最大值
        col_min_x = defaultdict(lambda: float('inf'))
        col_max_x = defaultdict(lambda: float('-inf'))

        for x, y in buildings:
            row_min_y[x] = min(row_min_y[x], y)
            row_max_y[x] = max(row_max_y[x], y)
            col_min_x[y] = min(col_min_x[y], x)
            col_max_x[y] = max(col_max_x[y], x)

        count = 0
        for x, y in buildings:
            # 检查四个方向是否都有建筑
            if (row_min_y[x] < y and row_max_y[x] > y and
                    col_min_x[y] < x and col_max_x[y] > x):
                count += 1

        return count
```

### 方法二：排序后检查

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCoveredBuildings(self, n: int, buildings: List[List[int]]) -> int:
        rows = defaultdict(list)
        cols = defaultdict(list)

        for x, y in buildings:
            rows[x].append(y)
            cols[y].append(x)

        # 排序后用首尾判断
        for key in rows:
            rows[key].sort()
        for key in cols:
            cols[key].sort()

        count = 0
        for x, y in buildings:
            row_ys = rows[x]
            col_xs = cols[y]
            # 同行：y 不是最小也不是最大
            # 同列：x 不是最小也不是最大
            if row_ys[0] < y and row_ys[-1] > y and col_xs[0] < x and col_xs[-1] > x:
                count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n log n)（方法二排序）
- 空间复杂度：O(n)，哈希表存储

## 关键点总结

1. 只需检查每行/列中的最小最大坐标即可确定是否有左右/上下建筑
2. 被覆盖的条件：四个方向各至少有一栋建筑
3. 预处理行列的极值，查询为 O(1)

## 易错点

1. 严格大于/小于（不是大于等于），即当前建筑不能和边界建筑重合
2. 一行只有一栋建筑时，无法被左右覆盖
3. 两栋建筑重合时不计（题目保证坐标唯一）
