## 题目描述

如果可以使用以下操作从一个字符串得到另一个字符串，则认为两个字符串**接近**：
- 操作 1：交换现有字符（重新排列字符）
- 操作 2：将现有的所有某种字符转换为另一种现有字符，反之亦然

给你两个字符串 `word1` 和 `word2`，如果两字符串**接近**则返回 `true`，否则返回 `false`。

**示例：**
```
输入：word1 = "abc", word2 = "bca"
输出：true（操作 1 交换字符）

输入：word1 = "a", word2 = "aa"
输出：false
```

## 解题思路

两个字符串接近的充要条件：
1. 两个字符串包含**相同的字符集合**（出现的字符种类相同）
2. 字符频率的**多重集合**相同（频率的排序后序列相同）

**例如：**
- "abc" 和 "cbc"：字符集不同（a 出现在 word1 但不在 word2），不接近
- "aabb" 和 "bbaa"：字符集 {a,b} 相同，频率 {2,2} 相同，接近

## 代码实现

### 方法一：Counter 比较（推荐）

```python
from collections import Counter

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        c1 = Counter(word1)
        c2 = Counter(word2)
        
        # 条件 1：字符集相同
        if set(c1.keys()) != set(c2.keys()):
            return False
        
        # 条件 2：频率多重集合相同（排序后比较）
        if sorted(c1.values()) != sorted(c2.values()):
            return False
        
        return True
```

### 方法二：位运算优化（字符集用 bitmask）

```python
from collections import Counter

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        c1 = Counter(word1)
        c2 = Counter(word2)
        
        # 字符集作为 bitmask
        mask1 = sum(1 << (ord(c) - ord('a')) for c in c1)
        mask2 = sum(1 << (ord(c) - ord('a')) for c in c2)
        
        return mask1 == mask2 and sorted(c1.values()) == sorted(c2.values())
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter 比较 | O(n + 26 log 26) = O(n) | O(26) = O(1) |

## 关键点总结

1. 两个条件缺一不可：字符集相同 + 频率多重集相同
2. `set(c1.keys()) != set(c2.keys())` 检查字符种类
3. `sorted(c1.values()) != sorted(c2.values())` 检查频率分布

## 易错点

- 只检查频率排序不够，还要确保字符集相同（"aab" 和 "bbc" 频率 [2,1] 相同但字符集不同）
- 只检查字符集也不够，"aabbc" 和 "aabbb" 字符集相同但频率不同
