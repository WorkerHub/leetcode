## 题目描述

给你一个方程，左边用 `words` 表示，右边用 `result` 表示。

你需要根据以下规则检查方程是否可解：

- 每个字符都会被解码成一位数字（0-9）
- 每对不同的字符必须映射到不同的数字
- 每个 `words[i]` 和 `result` 都会被解码成一个没有前导零的数字
- 左侧数字之和（`words`）等于右侧数字（`result`）

如果方程可解，返回 `true`，否则返回 `false`。

示例 1：
```
输入：words = ["SEND","MORE"], result = "MONEY"
输出：true
解释：映射 'S'-> 9, 'E'->5, 'N'->6, 'D'->7, 'M'->1, 'O'->0, 'R'->8, 'Y'->2
所以 "SEND" + "MORE" = "MONEY" ,  9567 + 1085 = 10652
```

示例 2：
```
输入：words = ["SIX","SEVEN","SEVEN"], result = "TWENTY"
输出：true
解释：映射 'S'-> 6, 'I'->5, 'X'->0, 'E'->8, 'V'->7, 'N'->2, 'T'->1, 'W'->'3', 'Y'->4
所以 "SIX" + "SEVEN" + "SEVEN" = "TWENTY" ,  650 + 68782 + 68782 = 138214
```

示例 3：
```
输入：words = ["LEET","CODE"], result = "POINT"
输出：false
解释：无解，无法使等式成立
```

提示：
- `2 <= words.length <= 5`
- `1 <= words[i].length, result.length <= 7`
- `words[i]`, `result` 只包含大写英文字母
- 表达式中使用的不同字符数不会超过 10

## 解题思路

这是一个典型的约束满足问题（CSP），使用回溯算法求解。

关键点：
1. 每个字母对应一个 0-9 的数字，且映射关系是一一对应的
2. 每个单词和结果都不能有前导零
3. 所有单词的数值之和必须等于结果的数值

优化策略：
1. 按列从右到左处理（从个位到高位），可以提前剪枝
2. 维护进位信息，及时发现不可行的分配
3. 使用位掩码快速判断数字是否已被使用

## Python 代码实现

### 方法一：回溯 + 列处理（推荐）⭐

```python
from typing import List

class Solution:
    def isSolvable(self, words: List[str], result: str) -> bool:
        # 获取所有唯一字符
        chars = set()
        for word in words:
            chars.update(word)
        chars.update(result)
        
        # 如果字符数超过 10，无解
        if len(chars) > 10:
            return False
        
        chars = list(chars)
        char_to_digit = {}
        used_digits = set()
        
        # 找出不能为 0 的字符（首字母）
        leading_chars = set()
        for word in words:
            if len(word) > 1:
                leading_chars.add(word[0])
        if len(result) > 1:
            leading_chars.add(result[0])
        
        # 按列组织字符（从右到左）
        max_len = max(len(word) for word in words + [result])
        columns = []
        for col in range(max_len):
            column_chars = []
            # words 中该列的字符
            for word in words:
                if col < len(word):
                    column_chars.append((word[-(col+1)], 1))  # 加数
            # result 中该列的字符
            if col < len(result):
                column_chars.append((result[-(col+1)], -1))  # 减数
            columns.append(column_chars)
        
        def backtrack(char_idx: int, col_idx: int, carry: int) -> bool:
            # 所有字符都已分配，检查最后的进位
            if char_idx == len(chars):
                if carry != 0:
                    return False
                # 验证等式
                return verify()
            
            char = chars[char_idx]
            
            # 尝试为当前字符分配 0-9
            for digit in range(10):
                # 跳过已使用的数字
                if digit in used_digits:
                    continue
                
                # 前导字符不能为 0
                if digit == 0 and char in leading_chars:
                    continue
                
                # 分配
                char_to_digit[char] = digit
                used_digits.add(digit)
                
                # 递归
                if backtrack(char_idx + 1, col_idx, carry):
                    return True
                
                # 回溯
                del char_to_digit[char]
                used_digits.remove(digit)
            
            return False
        
        def verify() -> bool:
            # 验证等式是否成立
            total = 0
            for word in words:
                num = 0
                for char in word:
                    num = num * 10 + char_to_digit[char]
                total += num
            
            result_num = 0
            for char in result:
                result_num = result_num * 10 + char_to_digit[char]
            
            return total == result_num
        
        return backtrack(0, 0, 0)
```

### 方法二：简化版回溯

```python
from typing import List

class Solution:
    def isSolvable(self, words: List[str], result: str) -> bool:
        # 收集所有字符
        all_chars = set()
        for word in words + [result]:
            all_chars.update(word)
        
        if len(all_chars) > 10:
            return False
        
        chars = list(all_chars)
        
        # 不能为 0 的字符
        no_zero = set()
        for word in words + [result]:
            if len(word) > 1:
                no_zero.add(word[0])
        
        def word_to_num(word: str, mapping: dict) -> int:
            num = 0
            for c in word:
                if c not in mapping:
                    return -1
                num = num * 10 + mapping[c]
            return num
        
        def backtrack(idx: int, mapping: dict, used: set) -> bool:
            if idx == len(chars):
                # 检查等式
                left_sum = sum(word_to_num(word, mapping) for word in words)
                right = word_to_num(result, mapping)
                return left_sum == right
            
            char = chars[idx]
            
            for digit in range(10):
                if digit in used:
                    continue
                if digit == 0 and char in no_zero:
                    continue
                
                mapping[char] = digit
                used.add(digit)
                
                if backtrack(idx + 1, mapping, used):
                    return True
                
                del mapping[char]
                used.remove(digit)
            
            return False
        
        return backtrack(0, {}, set())
```

## 复杂度分析

- 时间复杂度：O(10!)，最坏情况下需要尝试所有可能的字母到数字的映射。实际运行中由于剪枝会快很多。
- 空间复杂度：O(n)，其中 n 是字符的数量，主要是递归栈和映射表的空间

## 关键点总结

1. 这是一个约束满足问题，使用回溯算法
2. 需要记录哪些数字已被使用（避免重复分配）
3. 首字母不能映射到 0（避免前导零）
4. 可以按列从右到左处理，结合进位进行剪枝优化
5. 字符数超过 10 时直接返回 false

## 易错点

1. 忘记检查前导零的约束
2. 没有正确维护已使用数字的集合
3. 回溯时忘记恢复状态
4. 字符数超过 10 的边界情况
