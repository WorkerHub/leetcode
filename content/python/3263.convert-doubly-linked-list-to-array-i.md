## 题目描述

给你一个双向链表，每个节点包含 `val`、`prev` 和 `next` 指针。

将双向链表转换为数组，按从头到尾的顺序。

**示例：**
```
输入：head = [1,2,3,4,5]（双向链表）
输出：[1,2,3,4,5]
```

**提示：**
- 链表节点数在 `[1, 50]` 之间

## 解题思路

从头节点开始，沿 `next` 指针遍历，将每个节点的 `val` 加入数组。

## Python 代码实现

### 方法一：顺序遍历（推荐）

```python
from typing import Optional, List

class Node:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next

class Solution:
    def toArray(self, root: Optional[Node]) -> List[int]:
        result = []
        curr = root
        while curr:
            result.append(curr.val)
            curr = curr.next
        return result
```

### 方法二：生成器写法

```python
from typing import Optional, List

class Solution:
    def toArray(self, root: Optional[Node]) -> List[int]:
        return [node.val for node in iter(lambda: (root := root.next) or root, None)]
        # 简化版
        result = []
        while root:
            result.append(root.val)
            root = root.next
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 双向链表可以从头或尾遍历，通常从头节点开始
2. 沿 next 指针逐节点遍历即可

## 易错点

1. 注意循环终止条件：`curr is None`
2. 不需要使用 prev 指针（从头到尾遍历）
