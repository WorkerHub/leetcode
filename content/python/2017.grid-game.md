## 题目描述

给你一个下标从 0 开始的二维数组 `grid`，大小为 `2 x n`，其中每个单元格有一个正整数。

有两个机器人，都从 `(0, 0)` 出发，前往 `(1, n-1)`。机器人只能向右或向下移动。

- **机器人一** 先走，收集沿途所有格子的值，并将经过的格子清零
- **机器人二** 再走，收集剩余的格子值（机器人一走过的格子已经为 0）

机器人二想要最大化自己的得分。机器人一想要最小化机器人二的得分。

假设两个机器人都使用**最优策略**，返回机器人二的最大得分。

**示例 1：**
```
输入：grid = [[2,5,4],[1,5,1]]
输出：4
```

**示例 2：**
```
输入：grid = [[3,3,1],[8,5,2]]
输出：4
```

**提示：**
- `grid.length == 2`
- `n == grid[0].length`
- `1 <= n <= 5 * 10^4`
- `1 <= grid[i][j] <= 10^5`

## 解题思路

机器人一只能在某列 `j` 从第 0 行转到第 1 行（在 `j` 列向下）。

转入列 `j` 后：
- 机器人二如果选择上方路线：只能拿 `grid[0][j+1..n-1]` 的和（`top_suffix[j+1]`）
- 机器人二如果选择下方路线：只能拿 `grid[1][0..j-1]` 的和（`bot_prefix[j]`）
- 机器人二会取两者中的最大值

机器人一枚举所有转弯列 `j`，选使机器人二得分最小的列。答案是这个最小值。

## 代码实现

### 方法一：前缀和枚举（推荐）

```python
from typing import List

class Solution:
    def gridGame(self, grid: List[List[int]]) -> int:
        n = len(grid[0])

        # 计算第一行后缀和：top_suffix[j] = grid[0][j..n-1] 之和
        top_suffix = [0] * (n + 1)
        for j in range(n - 1, -1, -1):
            top_suffix[j] = top_suffix[j + 1] + grid[0][j]

        # 计算第二行前缀和：bot_prefix[j] = grid[1][0..j-1] 之和
        bot_prefix = [0] * (n + 1)
        for j in range(n):
            bot_prefix[j + 1] = bot_prefix[j] + grid[1][j]

        ans = float('inf')

        # 枚举机器人一在第 j 列向下转弯
        for j in range(n):
            # 机器人一收集：grid[0][0..j] + grid[1][j..n-1]
            # 机器人二可以选择：
            #   上方剩余：top_suffix[j+1]（第一行 j+1 到 n-1 列）
            #   下方剩余：bot_prefix[j]（第二行 0 到 j-1 列）
            robot2 = max(top_suffix[j + 1], bot_prefix[j])
            ans = min(ans, robot2)  # 机器人一要最小化机器人二的得分

        return ans
```

### 方法二：实时计算前后缀

```python
from typing import List

class Solution:
    def gridGame(self, grid: List[List[int]]) -> int:
        n = len(grid[0])
        top_sum = sum(grid[0])   # 第一行总和
        bot_sum = 0               # 第二行前缀和
        ans = float('inf')

        for j in range(n):
            top_sum -= grid[0][j]  # 机器人一在 j 列转弯，第一行 j 之后的部分留给机器人二
            # 此时 top_sum = grid[0][j+1..n-1]，bot_sum = grid[1][0..j-1]
            robot2 = max(top_sum, bot_sum)
            ans = min(ans, robot2)
            bot_sum += grid[1][j]  # 更新第二行前缀

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：方法一 O(n)，方法二 O(1)

## 关键点总结

1. 机器人一必须在某列 `j` 从第 0 行转入第 1 行
2. 机器人二面对的剩余格子：第一行 `j+1` 到 `n-1`，第二行 `0` 到 `j-1`
3. 机器人二选最优（取最大），机器人一选最差给机器人二（取最小）
4. 方法二用变量维护前后缀和，空间 O(1)

## 易错点

- 机器人一经过列 `j` 转弯，该列两个格子机器人二都得不到（被机器人一拿走）
- 答案是 `min(max(top, bot))`，不能搞反 min/max 的层次
