## 题目描述

给定一棵二叉树的根节点 `root`，请判断是否可以通过删除**恰好一条**边将树分成两棵子树，使得两棵子树的节点值之和相等。

如果可以，返回 `true`，否则返回 `false`。

**示例 1:**

```
输入：root = [5,10,10,null,null,2,3]
输出：true
解释：
    5
   / \
  10  10
     /  \
    2    3
删除边 5-10（右），得到两棵树：[5,10] 和 [10,2,3]
和分别为 15 和 15
```

**示例 2:**

```
输入：root = [1,2,10,null,null,2,20]
输出：false
解释：无法找到这样的边
```

**提示:**
- 树中节点数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

### 核心观察

如果删除一条边后两棵树的和相等，那么：
- 原树的总和 = `total_sum`
- 删除某条边后，一棵子树的和 = `total_sum / 2`

所以问题转化为：**是否存在某棵子树，其和等于 total_sum / 2**

### 算法流程

1. 计算整棵树的总和 `total_sum`
2. 如果 `total_sum` 为奇数，直接返回 false
3. DFS 遍历，计算每棵子树的和
4. 如果某棵子树的和等于 `total_sum / 2`，返回 true
5. **注意**：不能删除根节点的边（会导致只有一棵树）

## Python 代码实现

### 方法一：DFS + 哈希集合（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def checkEqualTree(self, root: Optional[TreeNode]) -> bool:
        """
        DFS 计算所有子树的和
        """
        # 存储所有子树的和
        subtree_sums = []
        
        def get_sum(node: Optional[TreeNode]) -> int:
            """计算子树和，并记录"""
            if not node:
                return 0
            
            left_sum = get_sum(node.left)
            right_sum = get_sum(node.right)
            current_sum = node.val + left_sum + right_sum
            
            # 记录所有非根节点的子树和
            subtree_sums.append(current_sum)
            
            return current_sum
        
        total_sum = get_sum(root)
        
        # 如果总和为奇数，无法平分
        if total_sum % 2 != 0:
            return False
        
        target = total_sum // 2
        
        # 检查是否存在子树和等于 target
        # 注意：要排除根节点本身
        return subtree_sums.count(target) > 1 if target == 0 else target in subtree_sums[:-1]
```

### 方法二：优化版本

```python
class Solution:
    def checkEqualTree(self, root: Optional[TreeNode]) -> bool:
        """
        两次 DFS
        """
        def get_total(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return node.val + get_total(node.left) + get_total(node.right)
        
        total_sum = get_total(root)
        
        if total_sum % 2 != 0:
            return False
        
        target = total_sum // 2
        self.found = False
        
        def check_subtree(node: Optional[TreeNode], is_root: bool) -> int:
            if not node or self.found:
                return 0
            
            current_sum = node.val + check_subtree(node.left, False) + check_subtree(node.right, False)
            
            # 不是根节点且和等于 target
            if not is_root and current_sum == target:
                self.found = True
            
            return current_sum
        
        check_subtree(root, True)
        return self.found
```

### 方法三：单次遍历

```python
class Solution:
    def checkEqualTree(self, root: Optional[TreeNode]) -> bool:
        seen = []
        
        def dfs(node):
            if not node:
                return 0
            total = node.val + dfs(node.left) + dfs(node.right)
            seen.append(total)
            return total
        
        total = dfs(root)
        if total % 2:
            return False
        
        seen.pop()  # 移除根节点
        return total // 2 in seen
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，存储子树和

## 关键点总结

1. **总和判断**：总和必须是偶数
2. **排除根节点**：不能删除根节点的边
3. **特殊情况**：总和为 0 时，需要至少两棵子树和为 0
4. **子树和**：记录所有子树的和

## 易错点

1. 忘记排除根节点
2. 总和为 0 的特殊情况
3. 奇数总和没有提前返回
