## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `k`。

一开始你在下标 `0` 处。每一步，你最多可以往前跳 `k` 步，但你不能跳出数组的边界。也就是说，你可以从下标 `i` 跳到 `[i+1, min(i+k, n-1)]` 中的任意下标。

你的得分为你经过的所有数字之和（包括起点和终点）。

请你返回你能得到的**最大得分**。

**示例 1：**
```
输入：nums = [1,-1,-2,4,-7,3], k = 2
输出：7
解释：选择路径 1 -> 4 -> 3，得分 1 + 4 + 3 = 8。最优路径是：1 -> 4 -> 3，得分为 8，不对
实际最优：1 + (-1) + 4 + 3 = 7
输出 7
```

**示例 2：**
```
输入：nums = [10,-5,-2,4,0,3], k = 3
输出：17
解释：选择下标 0, 3, 5，得分 10 + 4 + 3 = 17
```

**提示：**
- `1 <= nums.length, k <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

设 `dp[i]` 为到达下标 `i` 时的最大得分，则：
`dp[i] = max(dp[j]) + nums[i]`，其中 `max(i-k, 0) <= j <= i-1`（加上 dp[0]=nums[0]）

需要在长度为 `k` 的滑动窗口内，快速找到 `dp` 的最大值。使用**单调递减队列**，队首始终是窗口内的最大值。

## 代码实现

### 方法一：单调队列（推荐，O(n)）

```python
from typing import List
from collections import deque

class Solution:
    def maxResult(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]

        # 单调递减队列，存下标，队首是窗口内 dp 最大值的下标
        dq = deque()
        dq.append(0)

        for i in range(1, n):
            # 移除队首超出窗口的元素
            while dq and dq[0] < i - k:
                dq.popleft()

            # 队首是窗口内 dp 最大值的下标
            dp[i] = dp[dq[0]] + nums[i]

            # 维护单调递减队列（移除队尾比 dp[i] 小的元素）
            while dq and dp[dq[-1]] <= dp[i]:
                dq.pop()
            dq.append(i)

        return dp[n - 1]
```

### 方法二：最大堆（O(n log n)）

```python
from typing import List
import heapq

class Solution:
    def maxResult(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]

        # 最大堆，存 (-dp值, 下标)（Python 是最小堆，用负数模拟最大堆）
        heap = [(-dp[0], 0)]

        for i in range(1, n):
            # 移除堆顶中超出窗口的元素（惰性删除）
            while heap[0][1] < i - k:
                heapq.heappop(heap)

            # 堆顶是窗口内 dp 的最大值
            dp[i] = -heap[0][0] + nums[i]
            heapq.heappush(heap, (-dp[i], i))

        return dp[n - 1]
```

## 复杂度分析

**方法一（单调队列）：**
- 时间复杂度：O(n)，每个元素入队出队最多一次
- 空间复杂度：O(n)，dp 数组 + 队列

**方法二（最大堆）：**
- 时间复杂度：O(n log n)，堆的操作
- 空间复杂度：O(n)

## 关键点总结

1. DP 状态转移：`dp[i] = max(dp[i-k..i-1]) + nums[i]`
2. 单调队列在滑动窗口内维护最大值，比堆更高效
3. 队首维护最大值，每次计算直接取队首
4. 保持队列单调递减：新元素入队前，弹出所有比它小的队尾元素

## 易错点

1. 窗口范围是 `[i-k, i-1]`，不是 `[i-k+1, i]`
2. 单调队列中要同时维护"超出窗口"的出队逻辑（队首）和"单调性"的出队逻辑（队尾）
3. `dp[0] = nums[0]`，起点的得分就是 `nums[0]`
