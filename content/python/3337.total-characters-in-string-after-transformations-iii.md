## 题目描述

这是字符串转换长度系列的第三题。给你字符串 `s`、整数 `t` 和长度为 26 的数组 `nums`，其中每个字符 `i` 每次转换变成接下来 `nums[i]` 个字符（循环）。

注意：本题与 3336 实际上是同一道题（或非常相似）。如果是新的题，可能引入额外约束或更复杂的转换规则。

基于已知信息，本题解法与 3336 相同，使用矩阵快速幂处理大 `t`。

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= t <= 10^15`（t 更大）
- `1 <= nums[i] <= 26`

## 解题思路

与 3336 完全相同的矩阵快速幂方法，只是 `t` 的范围更大（10^15），仍然在矩阵快速幂 O(26^3 * log t) 的能力范围内。

## Python 代码实现

### 方法一：矩阵快速幂（推荐）

```python
from typing import List

class Solution:
    def lengthAfterTransformations(self, s: str, t: int, nums: List[int]) -> int:
        MOD = 10**9 + 7
        
        # 构建 26x26 转移矩阵
        # M[j][i] = 1 若字符 i 转换后包含字符 j（可能多次，但每字符转换一次产生 nums[i] 个新字符）
        M = [[0] * 26 for _ in range(26)]
        for i in range(26):
            for step in range(1, nums[i] + 1):
                j = (i + step) % 26
                M[j][i] = (M[j][i] + 1) % MOD
        
        def mat_mul(A, B, n=26):
            """矩阵乘法"""
            C = [[0] * n for _ in range(n)]
            for i in range(n):
                for k in range(n):
                    if A[i][k] == 0:
                        continue
                    for j in range(n):
                        if B[k][j]:
                            C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
            return C
        
        def mat_pow(mat, p, n=26):
            """矩阵快速幂"""
            # 单位矩阵
            result = [[int(i == j) for j in range(n)] for i in range(n)]
            while p > 0:
                if p & 1:
                    result = mat_mul(result, mat)
                mat = mat_mul(mat, mat)
                p >>= 1
            return result
        
        # 初始字符计数
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1
        
        # M^t
        Mt = mat_pow(M, t)
        
        # 计算结果
        ans = 0
        for j in range(26):
            val = sum(Mt[j][i] * cnt[i] for i in range(26)) % MOD
            ans = (ans + val) % MOD
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(26^3 * log t + |s|)
- 空间复杂度：O(26^2)

## 关键点总结

1. 矩阵快速幂是处理线性递推的通用方法，即使 t 达到 10^15 也能高效处理。
2. 26 个字母的状态空间使得矩阵大小固定为 26x26，乘法复杂度 O(26^3) 是常数。
3. 每次转换的线性性质（各字母数量的线性组合）是能用矩阵表示的关键。

## 易错点

1. 矩阵幂运算时，初始化为单位矩阵（对角线为 1，其余为 0）。
2. 所有矩阵乘法都要对 MOD 取模，防止中间结果溢出。
3. `nums[i]` 是产生的字符数量，不是单一字符的偏移。
