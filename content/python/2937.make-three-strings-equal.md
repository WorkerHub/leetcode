## 题目描述

给你三个字符串 `s1`、`s2` 和 `s3`，每次可以对任意字符串的最后一个字符执行删除操作。

返回使三个字符串相等的最少操作次数。若不可能，返回 `-1`。

**示例 1：**
```
输入：s1 = "abc", s2 = "abb", s3 = "ab"
输出：2
解释：删除 s1 的末尾 'c'，再删除 s2 的末尾 'b'，三者均为 "ab"
```

**示例 2：**
```
输入：s1 = "dac", s2 = "bac", s3 = "cac"
输出：-1
```

**提示：**
- `1 <= s1.length, s2.length, s3.length <= 100`
- `s1`、`s2`、`s3` 只含小写字母

## 解题思路

三字符串最终相等意味着它们有共同的前缀（因为只能删末尾字符）。

找三个字符串的最长公共前缀长度 `k`（即 `s1[0..k-1] == s2[0..k-1] == s3[0..k-1]`）。

若 k == 0，则无公共前缀，不可能相等（返回 -1）。

最少操作数 = (len(s1) - k) + (len(s2) - k) + (len(s3) - k)。

## Python 代码实现

### 方法一：找最长公共前缀（推荐）

```python
class Solution:
    def findMinimumOperations(self, s1: str, s2: str, s3: str) -> int:
        # 找最长公共前缀长度
        min_len = min(len(s1), len(s2), len(s3))
        k = 0
        for i in range(min_len):
            if s1[i] == s2[i] == s3[i]:
                k += 1
            else:
                break

        if k == 0:
            return -1

        return (len(s1) - k) + (len(s2) - k) + (len(s3) - k)
```

### 方法二：逐字符检查

```python
class Solution:
    def findMinimumOperations(self, s1: str, s2: str, s3: str) -> int:
        # 使用 zip 同时遍历
        k = 0
        for c1, c2, c3 in zip(s1, s2, s3):
            if c1 == c2 == c3:
                k += 1
            else:
                break

        if k == 0:
            return -1
        return len(s1) + len(s2) + len(s3) - 3 * k
```

## 复杂度分析

- 时间复杂度：O(min(len(s1), len(s2), len(s3)))
- 空间复杂度：O(1)

## 关键点总结

1. 只能删末尾字符，所以最终相等的字符串必须是某个公共前缀
2. 最长公共前缀长度 k 决定最少操作数：每个字符串删去 len - k 个字符
3. k == 0 时不可能相等（三个字符串的第一个字符不全相同）

## 易错点

1. k 为 0 时返回 -1，不是 0
2. 注意是三个字符串的公共前缀（不是两两公共）
3. 操作数 = 三个字符串各自需要删除的字符数之和
