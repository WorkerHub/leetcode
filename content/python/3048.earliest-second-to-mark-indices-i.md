## 题目描述

给你两个整数数组 `nums` 和 `changeIndices`，分别长度为 `n` 和 `m`。

初始时，所有下标均未被标记。每秒 `t`（从 1 到 m），你可以执行以下之一：
- 将一个未标记的 **任意** 下标 `i` 标记（当 `i` 是任意值时）
- 若 `nums[changeIndices[t-1]] == 0`，将 `changeIndices[t-1]` 对应的下标标记

等等，重新理解：每秒 t，可以执行两种操作之一：
1. 将某个下标 i 的值 `nums[i]` 减 1
2. 若 `nums[changeIndices[t-1]-1] == 0`，标记下标 `changeIndices[t-1]-1`

返回标记所有下标（1 到 n）的最早秒数，若不可能返回 -1。

**提示：**
- `1 <= n <= 5000`
- `1 <= m <= 5000`
- `0 <= nums[i] <= 1000`
- `1 <= changeIndices[i] <= n`

## 解题思路

二分答案：二分最早的时间 `T`，判断在 `T` 秒内是否能标记所有下标。

**贪心验证：** 对于前 `T` 秒：
- 每个下标 `i` 需要：`nums[i]` 次减 1 操作 + 1 次标记操作
- `changeIndices[t-1]` 指定了第 `t` 秒的"特殊机会"（可以用于标记某个下标）
- 应该贪心地使用最晚的 `changeIndices` 机会来减少操作（让每个下标尽量晚地被处理）

具体地：从后往前贪心分配每个下标最后一次出现的 `changeIndices` 时刻。

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List

class Solution:
    def earliestSecondToMarkIndices(self, nums: List[int], changeIndices: List[int]) -> int:
        n = len(nums)
        m = len(changeIndices)

        def can_do(T: int) -> bool:
            # 判断前 T 秒能否标记所有 n 个下标
            # 为每个下标找最后一次出现在 changeIndices[0..T-1] 中的时刻
            last = {}
            for t in range(T):
                idx = changeIndices[t] - 1  # 转为 0-indexed
                last[idx] = t  # 记录最后一次出现的时刻

            # 若某个下标从未出现，则无法通过特殊标记
            for i in range(n):
                if i not in last:
                    return False

            # 贪心：从后往前，为每个下标的最后出现时刻分配"标记"机会
            # 剩余空闲时间用于减 1 操作
            # 总减 1 需求 = sum(nums)
            # 按时刻从后往前处理：
            free = 0  # 空闲时间（可以做减 1 操作）
            marked = [False] * n  # 哪些下标已在计划中被标记
            used = set()

            # 将 last 按时刻从大到小排序
            order = sorted(last.items(), key=lambda x: -x[1])

            # 从后往前分配标记时刻
            # 对每个时刻 t 从 T-1 到 0：
            #   若时刻 t = last[i] 且 i 未被标记，分配给 i
            #   否则 free += 1（空闲时间）

            schedule = {}
            for i, t in order:
                if t not in used:
                    schedule[t] = i
                    used.add(t)

            # 若有下标未被分配
            if len(schedule) < n:
                return False

            # 验证：从后往前，每次要标记某个下标，需要先把其 nums[i] 减到 0
            free = 0
            dec_needed = 0
            for t in range(T - 1, -1, -1):
                if t in schedule:
                    i = schedule[t]
                    dec_needed += nums[i]  # 需要 nums[i] 次减 1
                else:
                    free += 1  # 此时刻空闲，可以做减 1

            return free >= dec_needed

        lo, hi = 1, m
        ans = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_do(mid):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1

        return ans
```

### 方法二：简化贪心

```python
from typing import List

class Solution:
    def earliestSecondToMarkIndices(self, nums: List[int], changeIndices: List[int]) -> int:
        n = len(nums)
        m = len(changeIndices)

        def check(T: int) -> bool:
            # 找每个下标在前 T 秒内最后出现的时刻
            last = [-1] * n
            for t in range(T):
                last[changeIndices[t] - 1] = t

            if any(x == -1 for x in last):
                return False

            # 按最后出现时刻排序，分配操作
            order = sorted(range(n), key=lambda i: last[i])
            free = 0
            ptr = 0

            for t in range(T):
                idx = changeIndices[t] - 1
                if ptr < n and last[order[ptr]] == t:
                    # 分配此时刻给 order[ptr]
                    if free < nums[order[ptr]]:
                        return False
                    free -= nums[order[ptr]]
                    ptr += 1
                else:
                    free += 1

            return ptr == n

        lo, hi = n, m
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo if check(lo) else -1
```

## 复杂度分析

- 时间复杂度：O(m log m)，二分 O(log m)，每次验证 O(n + m)
- 空间复杂度：O(n)

## 关键点总结

1. 二分答案：时间 T 越大越容易成功，具有单调性
2. 每个下标需要一个专门的"标记时刻"（其最后出现时刻）
3. 剩余时刻用于减 1 操作，空闲时刻数必须 >= 总减 1 需求

## 易错点

1. `changeIndices` 是 1-indexed，需要减 1 转为 0-indexed
2. 每个下标必须至少在前 T 秒内出现一次（作为标记机会）
3. 减 1 操作必须在标记之前完成
