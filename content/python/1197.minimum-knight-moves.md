## 题目描述

在一个无限大的棋盘上，一个国际象棋中的马位于 `(0, 0)` 处。

现在，马想要移动到 `(x, y)` 的位置。

每一步，马可以按照国际象棋中马的移动规则：

- 横竖各走一个和两个方格（即 8 个方向）

返回马到达目标位置所需的最少步数。如果马无法到达目标位置，返回 `-1`。

**示例 1：**
```
输入：x = 2, y = 1
输出：1
解释：[0, 0] → [2, 1]
```

**示例 2：**
```
输入：x = 5, y = 5
输出：4
解释：[0, 0] → [2, 1] → [4, 2] → [3, 4] → [5, 5]
```

**提示：**
- `-300 <= x, y <= 300`
- `0 <= |x| + |y| <= 300`

## 解题思路

这是一个经典的 BFS（广度优先搜索）问题，求最短路径。

**核心思路：**

1. **BFS 搜索**：从起点 `(0, 0)` 开始，逐层扩展，直到找到目标点。

2. **优化技巧**：
   - **对称性**：利用对称性，将目标点转换为第一象限 `(|x|, |y|)`
   - **剪枝**：限制搜索范围，避免探索过远的位置
   - **双向 BFS**：从起点和终点同时搜索，减少搜索空间

3. **马的移动方向**：8 个方向
   ```
   (±2, ±1) 和 (±1, ±2)
   ```

4. **剪枝策略**：
   - 马的位置不应该超出目标点太远（通常 `abs(nx) <= |x| + 2` 且 `abs(ny) <= |y| + 2`）
   - 这是因为一旦偏离太远，返回会增加步数

## Python 代码实现

### 方法一：BFS + 剪枝（推荐）⭐

```python
from collections import deque
from typing import Tuple

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        """
        使用 BFS 搜索最短路径，利用对称性优化
        """
        # 利用对称性，只考虑第一象限
        x, y = abs(x), abs(y)
        
        # 马的 8 个移动方向
        directions = [
            (2, 1), (1, 2), (-1, 2), (-2, 1),
            (-2, -1), (-1, -2), (1, -2), (2, -1)
        ]
        
        # BFS 队列：(x, y, steps)
        queue = deque([(0, 0, 0)])
        visited = {(0, 0)}
        
        while queue:
            cur_x, cur_y, steps = queue.popleft()
            
            # 到达目标点
            if cur_x == x and cur_y == y:
                return steps
            
            # 遍历 8 个方向
            for dx, dy in directions:
                nx, ny = cur_x + dx, cur_y + dy
                
                # 剪枝：限制搜索范围
                # 允许稍微超出目标点，因为可能需要绕路
                if (nx, ny) not in visited and -2 <= nx <= x + 2 and -2 <= ny <= y + 2:
                    visited.add((nx, ny))
                    queue.append((nx, ny, steps + 1))
        
        return -1  # 理论上不会到达这里
```

### 方法二：双向 BFS

```python
from collections import deque

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        """
        双向 BFS：从起点和终点同时搜索
        """
        x, y = abs(x), abs(y)
        
        directions = [
            (2, 1), (1, 2), (-1, 2), (-2, 1),
            (-2, -1), (-1, -2), (1, -2), (2, -1)
        ]
        
        # 两个方向的队列和访问集合
        queue_start = deque([(0, 0, 0)])
        queue_end = deque([(x, y, 0)])
        visited_start = {(0, 0): 0}
        visited_end = {(x, y): 0}
        
        while queue_start or queue_end:
            # 从起点扩展
            if queue_start:
                cur_x, cur_y, steps = queue_start.popleft()
                
                # 检查是否与终点的搜索相遇
                if (cur_x, cur_y) in visited_end:
                    return steps + visited_end[(cur_x, cur_y)]
                
                for dx, dy in directions:
                    nx, ny = cur_x + dx, cur_y + dy
                    if (nx, ny) not in visited_start and -2 <= nx <= x + 2 and -2 <= ny <= y + 2:
                        visited_start[(nx, ny)] = steps + 1
                        queue_start.append((nx, ny, steps + 1))
            
            # 从终点扩展
            if queue_end:
                cur_x, cur_y, steps = queue_end.popleft()
                
                if (cur_x, cur_y) in visited_start:
                    return steps + visited_start[(cur_x, cur_y)]
                
                for dx, dy in directions:
                    nx, ny = cur_x + dx, cur_y + dy
                    if (nx, ny) not in visited_end and -2 <= nx <= x + 2 and -2 <= ny <= y + 2:
                        visited_end[(nx, ny)] = steps + 1
                        queue_end.append((nx, ny, steps + 1))
        
        return -1
```

### 方法三：A* 搜索

```python
import heapq

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        """
        使用 A* 搜索算法
        """
        x, y = abs(x), abs(y)
        
        def heuristic(cx, cy):
            """
            启发函数：估计从 (cx, cy) 到目标的最少步数
            """
            dx, dy = abs(x - cx), abs(y - cy)
            # 切比雪夫距离除以 2（马每次移动覆盖 2 格）
            return max(dx, dy) // 2
        
        directions = [
            (2, 1), (1, 2), (-1, 2), (-2, 1),
            (-2, -1), (-1, -2), (1, -2), (2, -1)
        ]
        
        # 优先队列：(f值, 步数, x, y)
        # f = g + h，g 是已走步数，h 是启发值
        heap = [(heuristic(0, 0), 0, 0, 0)]
        visited = {(0, 0)}
        
        while heap:
            _, steps, cur_x, cur_y = heapq.heappop(heap)
            
            if cur_x == x and cur_y == y:
                return steps
            
            for dx, dy in directions:
                nx, ny = cur_x + dx, cur_y + dy
                
                if (nx, ny) not in visited and -2 <= nx <= x + 2 and -2 <= ny <= y + 2:
                    visited.add((nx, ny))
                    f_value = steps + 1 + heuristic(nx, ny)
                    heapq.heappush(heap, (f_value, steps + 1, nx, ny))
        
        return -1
```

### 方法四：记忆化 DFS（不推荐）

```python
from functools import lru_cache

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        """
        使用记忆化递归（效率较低）
        """
        @lru_cache(None)
        def dfs(x, y):
            # 利用对称性
            x, y = abs(x), abs(y)
            
            # 基础情况
            if x + y == 0:
                return 0
            if x + y == 2:
                return 2
            
            # 递归搜索
            return min(dfs(x - 2, y - 1), dfs(x - 1, y - 2)) + 1
        
        return dfs(x, y)
```

## 复杂度分析

**方法一：BFS**
- **时间复杂度**：O(max(|x|, |y|)²)，最坏情况下需要探索的节点数
- **空间复杂度**：O(max(|x|, |y|)²)，存储访问过的节点

**方法二：双向 BFS**
- **时间复杂度**：O(max(|x|, |y|)²)，但实际更快
- **空间复杂度**：O(max(|x|, |y|)²)

**方法三：A***
- **时间复杂度**：O(max(|x|, |y|)² log(max(|x|, |y|)))，堆操作
- **空间复杂度**：O(max(|x|, |y|)²)

## 关键点总结

1. **对称性优化**：将问题转换到第一象限，减少搜索空间
2. **剪枝策略**：限制搜索范围，避免探索过远的位置
3. **BFS 求最短路径**：BFS 第一次到达目标就是最短路径
4. **双向 BFS 优化**：从两端同时搜索，减少搜索空间
5. **特殊情况处理**：`(1, 1)` 需要 2 步，不是 1 步

## 易错点

1. **忘记利用对称性**：不用对称性会导致搜索空间过大
2. **剪枝范围错误**：剪枝范围太小会遗漏最优解
3. **特殊情况遗漏**：`(1, 1)` 和 `(2, 2)` 等特殊情况
4. **无限循环**：必须使用 `visited` 集合避免重复访问
5. **负坐标处理**：利用对称性时要正确处理负坐标
