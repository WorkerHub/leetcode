## 题目描述

给你一个整数数组 `nums`。`nums` 的子序列 `sub` 的长度为 `x`，如果其满足以下条件，则称其为**有效子序列**：

- `(sub[0] + sub[1]) % 2 == (sub[1] + sub[2]) % 2 == ... == (sub[x - 2] + sub[x - 1]) % 2`

返回 `nums` 的**最长有效子序列**的长度。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：4
解释：最长有效子序列是 [1,2,3,4]，相邻元素之和的奇偶性均相同。
```

**示例 2：**
```
输入：nums = [1,2,1,1,2,1,2]
输出：6
```

**提示：**
- `2 <= nums.length <= 2 * 10^5`
- `1 <= nums[i] <= 10^7`

## 解题思路

有效子序列要求相邻元素之和的奇偶性一致。分析可知只有三种情况：
1. 所有相邻和为偶数（即奇奇或偶偶交替，或全奇，或全偶）
2. 奇偶交替出现（奇偶奇偶...）
3. 偶奇交替出现（偶奇偶奇...）

因此只需统计：
- 全部偶数元素的数量
- 全部奇数元素的数量
- 奇偶交替的最大长度
- 偶奇交替的最大长度

取最大值即可。

## Python 代码实现

### 方法一：分情况统计（推荐）

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        # 统计全奇和全偶的数量
        even_count = sum(1 for x in nums if x % 2 == 0)
        odd_count = len(nums) - even_count

        # 计算奇偶交替（以奇开始）和偶奇交替（以偶开始）的最大长度
        def alternating(start_parity):
            # start_parity: 0 表示偶数开头，1 表示奇数开头
            count = 0
            expected = start_parity
            for x in nums:
                if x % 2 == expected:
                    count += 1
                    expected = 1 - expected  # 切换期望奇偶性
            return count

        alt_odd_first = alternating(1)   # 奇数开头的交替子序列
        alt_even_first = alternating(0)  # 偶数开头的交替子序列

        return max(even_count, odd_count, alt_odd_first, alt_even_first)
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        # dp[r] 表示以余数 r 结尾的最长有效子序列长度
        # 对于模2，只有0和1两种余数
        # dp[0][0] 和 dp[1][1] 分别表示相邻和为偶的情况
        # dp[0][1] 和 dp[1][0] 分别表示相邻和为奇的情况

        # 更简洁：dp[last_parity][target_sum_parity]
        dp = [[0, 0], [0, 0]]
        # dp[p][q]: 末尾元素奇偶性为p，与前一元素之和奇偶性为q，的最长子序列
        ans = 0
        for x in nums:
            p = x % 2
            for q in range(2):
                # 前一元素奇偶性 prev_p 满足 (prev_p + p) % 2 == q
                # 即 prev_p = (q - p) % 2
                prev_p = (q - p) % 2
                dp[p][q] = dp[prev_p][q] + 1
                ans = max(ans, dp[p][q])
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. 有效子序列的相邻和奇偶性一致，分析后只有全偶、全奇、奇偶交替三大类
2. 奇偶性只取决于 mod 2，可以简化状态
3. 贪心地选取满足条件的元素即可得到最长子序列

## 易错点

1. 奇偶交替有两种起始方式（奇开始和偶开始），都需要考虑
2. 全奇和全偶也是有效子序列，不要遗漏
