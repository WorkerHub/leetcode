## 题目描述

给定一个整数数组，它表示二叉搜索树（BST）的前序遍历，请构造该树并返回其根节点。

保证对于给定的测试用例，总能找到满足要求的二叉搜索树。

**示例 1：**
```
输入：preorder = [8,5,1,7,10,12]
输出：[8,5,10,1,7,null,12]
```

**示例 2：**
```
输入：preorder = [1,3]
输出：[1,null,3]
```

**提示：**
- `1 <= preorder.length <= 100`
- `1 <= preorder[i] <= 10^8`
- `preorder` 中的值互不相同

## 解题思路

BST的性质：左子树所有节点值 < 根节点值 < 右子树所有节点值

前序遍历特点：根节点 -> 左子树 -> 右子树

**核心思想**：
1. 前序遍历的第一个元素是根节点
2. 找到第一个大于根节点的元素位置，将数组分为左右子树
3. 递归构造左右子树

**关键观察**：
- 利用BST的上下界性质可以优化
- 不需要真正分割数组，使用索引范围即可

## Python 代码实现

### 方法一：递归分治（推荐）⭐

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, List

class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        """
        递归构造BST
        时间复杂度：O(n^2) 最坏情况（链状树），O(nlogn) 平衡树
        空间复杂度：O(n) 递归栈
        """
        if not preorder:
            return None
        
        # 第一个元素是根节点
        root = TreeNode(preorder[0])
        
        # 找到第一个大于根节点的位置，分割左右子树
        i = 1
        while i < len(preorder) and preorder[i] < preorder[0]:
            i += 1
        
        # 递归构造左右子树
        root.left = self.bstFromPreorder(preorder[1:i])
        root.right = self.bstFromPreorder(preorder[i:])
        
        return root
```

### 方法二：优化递归（避免数组切片）⭐⭐

```python
class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        """
        使用索引范围避免数组切片，减少空间开销
        时间复杂度：O(n^2) 最坏，O(nlogn) 平均
        空间复杂度：O(h) h为树高度
        """
        def build(start: int, end: int) -> Optional[TreeNode]:
            # 递归终止条件
            if start > end:
                return None
            
            # 根节点
            root = TreeNode(preorder[start])
            
            # 找到右子树的起始位置
            i = start + 1
            while i <= end and preorder[i] < preorder[start]:
                i += 1
            
            # 递归构造左右子树
            # 左子树：[start+1, i-1]
            # 右子树：[i, end]
            root.left = build(start + 1, i - 1)
            root.right = build(i, end)
            
            return root
        
        return build(0, len(preorder) - 1)
```

### 方法三：单调栈优化（最优解）⭐⭐⭐

```python
class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        """
        利用单调栈，O(n)时间构造
        
        核心思想：
        - 维护从根到当前节点的路径（单调递减）
        - 当遇到更大的值时，找到它的父节点（第一个更大的值）
        
        时间复杂度：O(n)
        空间复杂度：O(h)
        """
        if not preorder:
            return None
        
        root = TreeNode(preorder[0])
        stack = [root]
        
        for i in range(1, len(preorder)):
            # 当前值
            val = preorder[i]
            node = TreeNode(val)
            
            # 如果当前值小于栈顶，作为左子节点
            if val < stack[-1].val:
                stack[-1].left = node
            else:
                # 找到第一个大于当前值的节点作为父节点
                parent = stack[-1]
                while stack and stack[-1].val < val:
                    parent = stack.pop()
                # 作为右子节点
                parent.right = node
            
            stack.append(node)
        
        return root
```

### 方法四：利用上下界（最优递归）⭐⭐⭐

```python
class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        """
        利用BST的上下界性质，O(n)时间构造
        
        每个节点都有一个值的范围限制
        - 左子树：(lower, root.val)
        - 右子树：(root.val, upper)
        
        时间复杂度：O(n)
        空间复杂度：O(h)
        """
        self.idx = 0  # 当前处理的索引
        
        def build(lower: float, upper: float) -> Optional[TreeNode]:
            # 递归终止条件
            if self.idx >= len(preorder):
                return None
            
            val = preorder[self.idx]
            # 如果当前值不在范围内，返回None
            if val < lower or val > upper:
                return None
            
            # 创建节点并移动索引
            self.idx += 1
            root = TreeNode(val)
            
            # 递归构造左右子树
            root.left = build(lower, val)
            root.right = build(val, upper)
            
            return root
        
        return build(float('-inf'), float('inf'))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一 | O(n²) | O(n) | 数组切片开销大 |
| 方法二 | O(n²) | O(h) | 避免切片，但查找分界点仍需O(n) |
| 方法三 | O(n) | O(h) | 单调栈优化，最优解之一 |
| 方法四 | O(n) | O(h) | 上下界递归，最优解之一 |

其中 h 为树的高度，最坏 O(n)，平衡树 O(logn)

## 关键点总结

1. **BST性质**：利用左<根<右的性质分割子树
2. **前序遍历**：第一个元素是根节点
3. **优化方向**：
   - 避免数组切片 → 使用索引范围
   - 避免重复查找 → 单调栈或上下界
4. **单调栈技巧**：维护根到当前节点的路径
5. **上下界技巧**：每个节点值都有范围限制

## 易错点

1. **数组越界**：查找分界点时要检查索引范围
2. **空树处理**：需要处理空数组情况
3. **单调栈逻辑**：理解何时作为左子节点、何时作为右子节点
4. **索引管理**：方法四中的全局索引要正确递增
5. **边界条件**：上下界的初始值和更新逻辑
