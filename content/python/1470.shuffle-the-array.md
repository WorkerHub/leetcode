## 题目描述

给你一个数组 `nums`，数组中有 `2n` 个元素，按 `[x1, x2, ..., xn, y1, y2, ..., yn]` 的格式排列。

请你将数组按 `[x1, y1, x2, y2, ..., xn, yn]` 格式重新排列，返回重排后的数组。

**示例 1：**

```
输入：nums = [2,5,1,3,4,7], n = 3
输出：[2,3,5,4,1,7]
解释：由于 x1=2, x2=5, x3=1, y1=3, y2=4, y3=7，
     所以答案为 [2,3,5,4,1,7]
```

**示例 2：**

```
输入：nums = [1,2,3,4,4,3,2,1], n = 4
输出：[1,4,2,3,3,2,4,1]
```

**示例 3：**

```
输入：nums = [1,1,2,2], n = 2
输出：[1,2,1,2]
```

**提示：**
- `1 <= n <= 500`
- `nums.length == 2n`
- `1 <= nums[i] <= 10^3`

---

## 解题思路

**核心思想：** 前半部分是 x 序列（索引 0 到 n-1），后半部分是 y 序列（索引 n 到 2n-1）。交错合并两个序列即可。

**具体方法：**
- 对于 `i` 从 0 到 n-1，依次取 `nums[i]`（x 序列）和 `nums[i+n]`（y 序列）。
- 可以使用列表推导、`zip`、或原地操作。

---

## Python 代码实现

### 方法一：列表推导（推荐）

```python
from typing import List

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        # 列表推导：对每个索引 i，先取 x[i] 再取 y[i]
        return [val for i in range(n) for val in (nums[i], nums[i + n])]
```

### 方法二：zip + 展开

```python
from typing import List

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        result = []
        # zip 将 x 序列和 y 序列配对
        for x, y in zip(nums[:n], nums[n:]):
            result.append(x)
            result.append(y)
        return result
```

使用 `itertools.chain` 可以更 Pythonic：

```python
from typing import List
from itertools import chain

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        # chain.from_iterable 展开 zip 产生的元组序列
        return list(chain.from_iterable(zip(nums[:n], nums[n:])))
```

### 方法三：普通循环（直观版）

```python
from typing import List

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        result = []
        for i in range(n):
            result.append(nums[i])       # 取 x[i]
            result.append(nums[i + n])   # 取 y[i]
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 列表推导 | O(n) | O(n) |
| zip 展开 | O(n) | O(n) |
| 普通循环 | O(n) | O(n) |

- **时间复杂度 O(n)**：遍历 n 对元素。
- **空间复杂度 O(n)**：结果数组长度为 2n。

---

## 关键点总结

1. 数组前半部分是 x 序列（索引 `[0, n)`），后半部分是 y 序列（索引 `[n, 2n)`）。
2. 交错合并：第 `i` 对元素是 `nums[i]` 和 `nums[i+n]`。
3. Python 的 `zip` 函数可以简洁地配对两个序列。
4. 列表推导是最 Pythonic 的写法，一行解决。

---

## 易错点

- **下标偏移错误**：y 序列的起始索引是 `n` 而不是 `n+1`。
- **切片范围**：`nums[:n]` 取前 n 个，`nums[n:]` 取后 n 个，两者合起来恰好是 2n 个元素。
- **直接修改原数组**：如果要求原地修改，需要更复杂的位操作技巧（本题不要求）。
