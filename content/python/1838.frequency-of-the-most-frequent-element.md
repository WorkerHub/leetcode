## 题目描述

元素的**频率**是该元素在数组中出现的次数。

给你一个整数数组 `nums` 和一个整数 `k`，每次操作可以选择一个元素，将其加 1。

返回至多 `k` 次操作后，数组中频率最高的元素的最大频率。

**示例 1：**
```
输入：nums = [1,2,4], k = 5
输出：3
解释：将 1 加 3 次变为 4，将 2 加 2 次变为 4，4 的频率为 3
```

**示例 2：**
```
输入：nums = [1,4], k = 5
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^5`

## 解题思路

**排序 + 滑动窗口**：

排序后，对于窗口 `[l, r]`，将窗口内所有元素变为 `nums[r]` 所需操作数为 `nums[r] * (r-l+1) - sum(nums[l..r])`。

若所需操作数 <= k，则当前窗口大小 `r-l+1` 是可行的，继续扩展右边界；否则收缩左边界。

用前缀和快速计算窗口内的元素和。

## 代码实现

### 方法一：排序 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        left = 0
        window_sum = 0
        result = 1

        for right in range(n):
            window_sum += nums[right]
            # 检查将窗口内所有元素变为 nums[right] 所需操作数
            while nums[right] * (right - left + 1) - window_sum > k:
                window_sum -= nums[left]
                left += 1
            result = max(result, right - left + 1)

        return result
```

### 方法二：排序 + 二分查找

```python
import bisect
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        result = 1
        for right in range(1, n):
            target = nums[right]
            # 对于固定 right，找最小 left 使得操作数 <= k
            # 操作数 = target * (right - left + 1) - (prefix[right+1] - prefix[left])
            # target * (right - left + 1) - prefix[right+1] + prefix[left] <= k
            # prefix[left] >= target * (right - left + 1) + prefix[right+1] - k - target
            # 二分查找最小的 left
            lo, hi = 0, right
            while lo < hi:
                mid = (lo + hi) // 2
                length = right - mid + 1
                cost = target * length - (prefix[right + 1] - prefix[mid])
                if cost <= k:
                    hi = mid
                else:
                    lo = mid + 1
            result = max(result, right - lo + 1)

        return result
```

## 复杂度分析

- **方法一（滑动窗口）**：
  - 时间复杂度：O(n log n)（排序） + O(n)（滑动窗口）= O(n log n)
  - 空间复杂度：O(1)
- **方法二（二分）**：
  - 时间复杂度：O(n log n)
  - 空间复杂度：O(n)（前缀和）

## 关键点总结

1. 排序后，目标频率最高的元素一定是某个 `nums[r]`（将窗口内元素都变成它）
2. 操作代价公式：`target * window_size - window_sum`
3. 滑动窗口保证窗口内代价不超过 k，维护最大窗口大小

## 易错点

- 只能增加元素，不能减少，所以将元素改变为窗口最大值（而非最小值）
- 检查条件：`nums[r] * window_size - window_sum <= k`
