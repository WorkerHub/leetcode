## 题目描述

给定一个无向图，有 `n` 个节点（编号 0 到 n-1）。图中有两类边：
- 普通边：`edges[i] = [u, v, w]`，边权为 w
- 特殊边：通过节点访问顺序有额外费用

从节点 0 出发到节点 n-1，找一条路径，使得路径总费用最小。费用包括边权和节点费用（若题目定义节点有费用）。

**示例：**

```
输入：n = 4, edges = [[0,1,1],[1,2,2],[2,3,3],[0,2,4]]
输出：6
解释：路径 0->1->2->3，费用 1+2+3=6。
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= edges.length <= 2 * 10^5`
- `1 <= w <= 10^9`

## 解题思路

标准 Dijkstra 最短路算法：
- 建无向图邻接表
- 使用最小堆（优先队列）维护当前最短距离
- 从节点 0 出发，松弛所有邻边
- 到达节点 n-1 时返回最短距离

若图中有特殊节点费用，将节点费用加到到达该节点的距离中。

## Python 代码实现

### 方法一：Dijkstra 最短路（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]]) -> int:
        # 建图
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # Dijkstra
        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0
        heap = [(0, 0)]  # (距离, 节点)

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            if u == n - 1:
                return d
            for v, w in graph[u]:
                new_d = d + w
                if new_d < dist[v]:
                    dist[v] = new_d
                    heapq.heappush(heap, (new_d, v))

        return dist[n - 1] if dist[n - 1] != INF else -1
```

### 方法二：带节点费用的 Dijkstra

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, edges: List[List[int]],
                    node_cost: List[int] = None) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        if node_cost is None:
            node_cost = [0] * n

        INF = float('inf')
        dist = [INF] * n
        dist[0] = node_cost[0]
        heap = [(node_cost[0], 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                new_d = d + w + node_cost[v]
                if new_d < dist[v]:
                    dist[v] = new_d
                    heapq.heappush(heap, (new_d, v))

        return dist[n - 1] if dist[n - 1] != INF else -1
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)，Dijkstra 标准复杂度
- 空间复杂度：O(V + E)，邻接表和距离数组

## 关键点总结

1. Dijkstra 适用于非负权图的单源最短路
2. 使用最小堆保证每次处理当前最短距离的节点
3. 跳过已处理的节点（`if d > dist[u]: continue`）

## 易错点

1. 无向图需要双向添加边
2. 若图不连通，目标节点可能不可达，返回 -1
3. 优先队列中可能有过时的距离，需要懒删除判断
