## 题目描述

给你一个字符串 `target`，初始时屏幕上显示 `"a"`。

每次操作可以：
1. 将当前字符串的最后一个字符改为字母表中的下一个字母（'z' 后不操作此步）。
2. 在当前字符串末尾追加 `'a'`。

返回从 `"a"` 变成 `target` 过程中，屏幕上出现的所有字符串序列（包含 `"a"` 和 `target`）。

**示例：**
```
输入：target = "abc"
输出：["a","b","c","ca","cb","cc","cba","cbb","cbc","cbca",...]
等等，重新理解：
```

**重新理解：** 每步只能做一种操作：(1) 最后一个字母 +1，或 (2) 追加 'a'。目标是从 "a" 变到 target，返回路径上所有出现的字符串。

**示例：**
```
输入：target = "abc"
输出：["a","b","c","ca","cb","cc","cba","cbb","cbc","cbca",...]
```

不对，让我再理解一下。从"a"出发，操作1：最后一个字母变为下一个字母；操作2：追加'a'。最短路径变成"abc"：

a -> b -> c -> ca -> cb -> cc -> ... 这不对。

正确路径：a -> ab -> ac -> abc（a追加a=aa，aa最后字母+1=ab，ab追加a=aba... 不对）

让我从具体结果反推：目标"abc"。
- 从"a"出发：
  - 操作1: "b"
  - 操作2: "aa"
- 到"abc"需要：a -> ... -> ab -> ... -> abc
  - a -> a+'a'=aa ... 不对，追加'a'后是"aa"
  
Wait, the sequence is simpler: starting from "a", we want to reach "target" using minimum operations. The key insight is: to get target[0..k], we go character by character. 

For target = "abc":
- Start: "a"
- Need first char 'a', done. Then append 'a': "aa"
- Wait, that adds an extra 'a'. 

Let me re-read: maybe the process is:
1. Each step either increments the last char or appends 'a'
2. We want all strings that appear on the way from "a" to target

The greedy path: for each character in target from left to right, we build the string.

For target[i]: if current last char != target[i], increment until it equals target[i]. Then if i < len(target)-1, append 'a'.

For "abc": 
- Start: "a" (= "a", target[0]='a', done)
- Append 'a': "aa"
- Increment last until 'b': "ab"
- Append 'a': "aba"  
- Increment last until 'c': "abc"... "abb" -> "abc"

Actually: "aa" -> "ab" (increment 'a' to 'b'), then to get target[2]='c', append 'a' -> "aba", increment -> "abb" -> "abc". 

But that's not quite matching the example output given. Let me just implement the straightforward simulation.

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def stringSequence(self, target: str) -> List[str]:
        result = []
        current = ""
        
        for c in target:
            # 追加 'a'
            current += 'a'
            result.append(current)
            
            # 逐步将最后一个字符从 'a' 增加到目标字符 c
            while current[-1] != c:
                current = current[:-1] + chr(ord(current[-1]) + 1)
                result.append(current)
        
        return result
```

### 方法二：字符串构建

```python
from typing import List

class Solution:
    def stringSequence(self, target: str) -> List[str]:
        result = []
        
        for i, c in enumerate(target):
            # 先追加 'a'，得到长度为 i+1 的字符串
            prefix = target[:i]  # 已确定的前缀
            # 从 prefix + 'a' 到 prefix + c
            for ch in range(ord('a'), ord(c) + 1):
                result.append(prefix + chr(ch))
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n * 26)，每个字符最多 26 步
- 空间复杂度：O(n * 26)，结果序列

## 关键点总结

1. 逐字符构建目标字符串，每个字符经历从 'a' 到目标值的逐步增加。
2. 每次追加 'a' 后，逐步递增最后一个字符到目标字符。
3. 最终返回路径上所有字符串（含初始的"a"和目标 target）。

## 易错点

1. 每次需要先追加 'a'，再递增到目标字符，顺序不能颠倒。
2. 字符递增范围是 `[a, target[i]]`，包含两端。
3. 前缀已经确定，只有最后一个字符在变化。
