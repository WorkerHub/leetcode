## 题目描述

给你一个字符串 `s` 和一个 **长度相同** 的整数数组 `indices`。

请你重新排列字符串 `s` ，其中第 `i` 个字符需要移动到 `indices[i]` 指示的位置。

返回重新排列后的字符串。

**示例 1：**
```
输入：s = "codeleet", indices = [4,5,6,7,0,2,1,3]
输出："leetcode"
解释：如 indices[4]=0 表示 s[4]='l' 应该移到下标 0，结果 result[0]='l'。
```

**示例 2：**
```
输入：s = "abc", indices = [0,1,2]
输出："abc"
```

**提示：**
- `s.length == indices.length == n`
- `1 <= n <= 100`
- `s` 仅包含小写英文字母
- `0 <= indices[i] < n`
- `indices` 的所有值都是**唯一**的

## 解题思路

### 直接按位置赋值

创建一个长度为 `n` 的结果数组（或字符列表），然后将 `s[i]` 放到 `result[indices[i]]` 的位置。

## 代码实现

### 方法一：列表直接赋值（推荐）

```python
from typing import List

class Solution:
    def restoreString(self, s: str, indices: List[int]) -> str:
        n = len(s)
        result = [''] * n
        for i, c in enumerate(s):
            # 将字符 c 放到目标位置 indices[i]
            result[indices[i]] = c
        return ''.join(result)
```

### 方法二：zip 配对

```python
from typing import List

class Solution:
    def restoreString(self, s: str, indices: List[int]) -> str:
        # 将字符和目标位置配对，按目标位置排序
        pairs = sorted(zip(indices, s))
        return ''.join(c for _, c in pairs)
```

### 方法三：Python 一行写法

```python
from typing import List

class Solution:
    def restoreString(self, s: str, indices: List[int]) -> str:
        # 按 indices 的值作为键排序，取对应字符
        return ''.join(c for _, c in sorted(zip(indices, s)))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N) | O(N) |
| 方法二/三（排序） | O(N log N) | O(N) |

## 关键点总结

1. `result[indices[i]] = s[i]`：第 i 个字符去到下标 `indices[i]`
2. 方法一直接赋值，O(N) 最优
3. 方法二用排序，写法简洁但稍慢

## 易错点

- 注意是 `result[indices[i]] = s[i]`，不是 `result[i] = s[indices[i]]`（逻辑相反）
