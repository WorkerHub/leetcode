## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的前序遍历，`inorder` 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

**示例 1：**

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2：**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

**提示：**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均无重复元素
- `inorder` 均出现在 `preorder`
- `preorder` 保证为二叉树的前序遍历序列
- `inorder` 保证为二叉树的中序遍历序列

## 解题思路

这道题的核心是理解前序遍历和中序遍历的特点：

1. **前序遍历**：根节点 -> 左子树 -> 右子树
2. **中序遍历**：左子树 -> 根节点 -> 右子树

**关键观察**：
- 前序遍历的第一个元素一定是根节点
- 在中序遍历中找到根节点的位置后，其左边都是左子树的节点，右边都是右子树的节点
- 根据左子树节点的数量，可以在前序遍历中划分出左子树和右子树的部分

**算法流程**：
1. 从前序遍历中取出第一个元素作为根节点
2. 在中序遍历中找到根节点的位置
3. 根据位置计算左子树的节点数量
4. 递归构造左子树和右子树
5. 返回根节点

**优化技巧**：
- 使用哈希表存储中序遍历中每个值的索引，避免重复查找
- 使用索引范围而不是切片数组，避免额外的空间开销

## Python 代码实现

### 方法一：递归 + 哈希表（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 构建中序遍历值到索引的映射，方便快速查找根节点位置
        inorder_map = {val: idx for idx, val in enumerate(inorder)}
        
        def build(pre_left: int, pre_right: int, in_left: int, in_right: int) -> Optional[TreeNode]:
            """
            递归构建二叉树
            pre_left, pre_right: 前序遍历的左右边界
            in_left, in_right: 中序遍历的左右边界
            """
            # 递归终止条件：没有节点可以构建
            if pre_left > pre_right:
                return None
            
            # 前序遍历的第一个节点就是根节点
            root_val = preorder[pre_left]
            root = TreeNode(root_val)
            
            # 在中序遍历中找到根节点的位置
            in_root_index = inorder_map[root_val]
            
            # 计算左子树的节点数量
            left_subtree_size = in_root_index - in_left
            
            # 递归构建左子树
            # 前序遍历：[pre_left+1, pre_left+left_subtree_size]
            # 中序遍历：[in_left, in_root_index-1]
            root.left = build(
                pre_left + 1, 
                pre_left + left_subtree_size,
                in_left, 
                in_root_index - 1
            )
            
            # 递归构建右子树
            # 前序遍历：[pre_left+left_subtree_size+1, pre_right]
            # 中序遍历：[in_root_index+1, in_right]
            root.right = build(
                pre_left + left_subtree_size + 1,
                pre_right,
                in_root_index + 1,
                in_right
            )
            
            return root
        
        # 开始递归构建
        return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

### 方法二：递归 + 数组切片（易理解版）

```python
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 递归终止条件
        if not preorder or not inorder:
            return None
        
        # 前序遍历的第一个元素是根节点
        root_val = preorder[0]
        root = TreeNode(root_val)
        
        # 在中序遍历中找到根节点的位置
        mid_index = inorder.index(root_val)
        
        # 递归构建左子树和右子树
        # 左子树：中序遍历的左半部分，前序遍历去掉根节点后的前 mid_index 个
        root.left = self.buildTree(preorder[1:mid_index+1], inorder[:mid_index])
        # 右子树：中序遍历的右半部分，前序遍历去掉根节点和左子树部分
        root.right = self.buildTree(preorder[mid_index+1:], inorder[mid_index+1:])
        
        return root
```

### 方法三：迭代 + 栈

```python
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder:
            return None
        
        root = TreeNode(preorder[0])
        stack = [root]
        inorder_index = 0
        
        # 遍历前序遍历的每个节点
        for i in range(1, len(preorder)):
            pre_val = preorder[i]
            node = stack[-1]
            
            # 如果栈顶节点不等于中序遍历的当前节点
            # 说明还在构建左子树
            if node.val != inorder[inorder_index]:
                node.left = TreeNode(pre_val)
                stack.append(node.left)
            else:
                # 找到该开始构建右子树的节点
                while stack and stack[-1].val == inorder[inorder_index]:
                    node = stack.pop()
                    inorder_index += 1
                
                # 构建右子树
                node.right = TreeNode(pre_val)
                stack.append(node.right)
        
        return root
```

## 复杂度分析

### 方法一：递归 + 哈希表

- **时间复杂度**：O(n)，其中 n 是树中的节点数。每个节点都会被访问一次，哈希表查找的时间复杂度是 O(1)。
- **空间复杂度**：O(n)，哈希表需要存储 n 个节点的映射关系，递归调用栈的深度最坏情况下为 O(n)。

### 方法二：递归 + 数组切片

- **时间复杂度**：O(n²)，每次递归都需要切片数组和查找索引，最坏情况下是 O(n²)。
- **空间复杂度**：O(n²)，切片会创建新的数组副本。

### 方法三：迭代 + 栈

- **时间复杂度**：O(n)，每个节点入栈出栈各一次。
- **空间复杂度**：O(n)，栈的空间。

## 关键点总结

1. **理解遍历特性**：前序遍历第一个是根节点，中序遍历根节点将左右子树分开
2. **使用哈希表优化**：预先构建中序遍历的值到索引的映射，避免重复查找
3. **索引边界计算**：准确计算左子树大小，正确划分前序和中序遍历的区间
4. **递归终止条件**：当区间为空时（left > right）返回 None
5. **避免数组切片**：使用索引范围传递而不是切片，可以优化空间复杂度

## 易错点

1. **索引计算错误**：左子树大小的计算要特别小心，是 `in_root_index - in_left`
2. **边界条件**：递归的左右边界容易出错，要仔细推导
3. **哈希表构建**：确保中序遍历的值没有重复，题目已保证
4. **空节点处理**：要正确处理空树的情况
5. **数组切片性能**：方法二虽然代码简洁，但性能较差，面试时要说明
