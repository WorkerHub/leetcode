## 题目描述

你有 `n` 台电脑，同时有 `m` 个电池，`batteries[i]` 表示第 `i` 个电池的供电量（单位：分钟）。

你可以将电池插入或拔出电脑（操作不耗时）。每台电脑**同时只能插一块电池**，每块电池**同时只能供一台电脑**。

返回你可以让 `n` 台电脑**同时**运行的**最长时间**。

**示例 1：**
```
输入：n = 2, batteries = [3,3,3]
输出：4
解释：前 3 分钟：电脑 0 用电池 0，电脑 1 用电池 1；然后拔出电池 0 和 1，换上电池 0(已用3)+新的或者拼凑...
实际上：用电池 0 和 1 先运行 3 分钟，然后用电池 1 和 2 运行 1 分钟（电池 0 已没电），总 4 分钟。
```

**提示：**
- `1 <= n <= batteries.length <= 10^5`
- `1 <= batteries[i] <= 10^9`

## 解题思路

**二分查找 + 贪心验证**

二分目标时间 `T`：判断能否让 n 台电脑同时运行 T 分钟。

**验证 T 的可行性：**
- 对于每块电池，它最多贡献 `min(battery, T)` 分钟（一块电池最多只能用 T 分钟给一台电脑）。
- 总供电量 = `sum(min(b, T) for b in batteries)`。
- 若总供电量 >= `n * T`，则可行。

**理由：** 如果某电池电量 > T，超出部分无用（每台电脑最多需要 T 分钟供电）。剩余电量可以自由分配，只需总量足够即可。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def maxRunTime(self, n: int, batteries: List[int]) -> int:
        def can_run(T: int) -> bool:
            # 判断能否让 n 台电脑同时运行 T 分钟
            total = sum(min(b, T) for b in batteries)
            return total >= n * T

        lo, hi = 0, sum(batteries) // n
        while lo < hi:
            mid = (lo + hi + 1) // 2  # 上取整
            if can_run(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

### 方法二：贪心（利用排序优化）

```python
from typing import List

class Solution:
    def maxRunTime(self, n: int, batteries: List[int]) -> int:
        batteries.sort()
        total = sum(batteries)

        # 从最大的电池开始，若一块电池比 total/n 还大，则它独占一台电脑
        while batteries[-1] > total // n:
            total -= batteries.pop()
            n -= 1

        # 此时剩余电池均可以均分给 n 台电脑
        return total // n
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(m log(sum/n)) | O(1) |
| 贪心排序 | O(m log m) | O(1) |

## 关键点总结

1. 关键观察：每块电池对时间 T 的贡献上限为 `min(b, T)`。
2. 总供电量 >= n * T 时，可以合理调度使 n 台电脑同时运行 T 分钟。
3. 二分目标时间，验证函数 O(m)，总时间 O(m log(sum/n))。

## 易错点

- 二分上界是 `sum(batteries) // n`（总电量均分），不能超过。
- 二分时用上取整（`(lo + hi + 1) // 2`），防止死循环。
