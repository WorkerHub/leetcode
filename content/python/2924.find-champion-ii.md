## 题目描述

`n` 支队伍参加比赛，给你一个整数 `n` 和有向边列表 `edges`，其中 `edges[i] = [u, v]` 表示队伍 `u` 比队伍 `v` 强。

若一支队伍没有任何其他队伍比它强（即入度为 0），则它是 **潜在冠军**。

若只有一支潜在冠军，返回该队伍编号；否则返回 `-1`。

**示例 1：**
```
输入：n = 3, edges = [[0,1],[1,2]]
输出：0
解释：只有队伍 0 的入度为 0
```

**示例 2：**
```
输入：n = 4, edges = [[0,2],[1,3],[1,2]]
输出：-1
解释：队伍 0 和 1 的入度都为 0
```

**提示：**
- `1 <= n <= 100`
- `m == edges.length`
- `0 <= m <= n * (n-1) / 2`
- `edges[i].length == 2`
- `0 <= edges[i][0], edges[i][1] <= n-1`
- `edges[i][0] != edges[i][1]`
- 输入保证无重复边

## 解题思路

计算每个节点的入度（被多少条有向边指向）。入度为 0 的节点没有被任何队伍"击败"，是潜在冠军。

若恰好有一个入度为 0 的节点，返回它；否则返回 -1。

## Python 代码实现

### 方法一：统计入度（推荐）

```python
from typing import List

class Solution:
    def findChampion(self, n: int, edges: List[List[int]]) -> int:
        # 计算每个节点的入度
        in_degree = [0] * n
        for u, v in edges:
            in_degree[v] += 1

        # 找入度为 0 的节点
        champions = [i for i in range(n) if in_degree[i] == 0]

        return champions[0] if len(champions) == 1 else -1
```

### 方法二：集合求差

```python
from typing import List

class Solution:
    def findChampion(self, n: int, edges: List[List[int]]) -> int:
        # 有入边的节点集合
        has_in_edge = set(v for u, v in edges)
        # 没有入边的节点
        no_in_edge = [i for i in range(n) if i not in has_in_edge]
        return no_in_edge[0] if len(no_in_edge) == 1 else -1
```

## 复杂度分析

- 时间复杂度：O(n + m)，遍历所有边和节点
- 空间复杂度：O(n)，入度数组

## 关键点总结

1. 冠军 = 入度为 0 的节点（没有被任何队伍击败）
2. 若多个入度为 0 的节点，无法确定唯一冠军，返回 -1
3. 本题与拓扑排序中的"起点"概念一致

## 易错点

1. 返回 -1 而非第一个，当有多个入度为 0 的节点时
2. 孤立节点（无边）也是入度为 0，需要计入
3. n=1 时唯一队伍入度为 0，直接返回 0
