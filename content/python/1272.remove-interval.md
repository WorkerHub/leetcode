## 题目描述

给你一个**有序的**区间列表 `intervals`，其中 `intervals[i] = [a, b]`，表示区间 `[a, b]`（闭区间）。

区间列表满足：
- 各区间不重叠
- 已按起点从小到大排序

另外给你一个需要删除的区间 `toBeRemoved = [c, d]`。

请你返回删除 `toBeRemoved` 之后剩余的有序区间列表（同样不重叠、按起点排序）。

**示例 1：**
```
输入：intervals = [[0,2],[3,4],[5,7]], toBeRemoved = [1,6]
输出：[[0,1],[6,7]]
解释：
  [0,2] 与 [1,6] 重叠，剩余 [0,1]
  [3,4] 完全在 [1,6] 内，删除
  [5,7] 与 [1,6] 重叠，剩余 [6,7]
```

**示例 2：**
```
输入：intervals = [[0,5]], toBeRemoved = [2,3]
输出：[[0,2],[3,5]]
解释：[0,5] 被 [2,3] 分割成两段 [0,2] 和 [3,5]
```

**示例 3：**
```
输入：intervals = [[-5,-4],[-3,-2],[1,2],[3,5],[8,9]], toBeRemoved = [-1,4]
输出：[[-5,-4],[-3,-2],[4,5],[8,9]]
```

**提示：**
- `1 <= intervals.length <= 10^4`
- `-10^9 <= intervals[i][0] < intervals[i][1] <= 10^9`
- `toBeRemoved` 也是一个区间，满足格式 `[c, d]` 其中 `c < d`

---

## 解题思路

**分情况讨论：**

对于每个区间 `[a, b]` 和需要删除的区间 `[c, d]`，有以下几种情况：

```
情况1：完全在左边，无重叠
  a -------- b
                  c ------- d
  保留 [a, b] 原样

情况2：完全在右边，无重叠
                  c ------- d
  a -------- b
  保留 [a, b] 原样

情况3：被完全包含（完全覆盖）
  c ----- a -------- b ----- d
  删除，不保留任何内容

情况4：左侧部分重叠
  a --- c -------- b
              d
  保留 [a, c]，删除 [c, b] 中被覆盖的部分

情况5：右侧部分重叠
       a -------- b --- d
  c
  保留 [d, b]

情况6：被分割（toBeRemoved 在区间内部）
  a --- c -------- d --- b
  保留 [a, c] 和 [d, b] 两段
```

**简化判断逻辑：**
- 如果 `b <= c`（区间在删除区间左边）：保留 `[a, b]`
- 如果 `a >= d`（区间在删除区间右边）：保留 `[a, b]`
- 否则（有重叠）：
  - 如果 `a < c`：保留左侧 `[a, c]`
  - 如果 `b > d`：保留右侧 `[d, b]`

## Python 代码实现

### 方法一：直接分情况处理（推荐）

```python
from typing import List

class Solution:
    def removeInterval(self, intervals: List[List[int]], toBeRemoved: List[int]) -> List[List[int]]:
        c, d = toBeRemoved  # 需要删除的区间边界
        result = []

        for a, b in intervals:
            # 情况1：当前区间完全在删除区间的左边，无重叠
            if b <= c:
                result.append([a, b])
            # 情况2：当前区间完全在删除区间的右边，无重叠
            elif a >= d:
                result.append([a, b])
            # 情况3/4/5/6：有重叠，保留未被覆盖的部分
            else:
                # 保留左侧：如果当前区间的左端在删除区间左端的左边
                if a < c:
                    result.append([a, c])
                # 保留右侧：如果当前区间的右端在删除区间右端的右边
                if b > d:
                    result.append([d, b])
                # 否则（完全被覆盖）：什么都不保留

        return result
```

**图解演示（示例 1）：**
```
intervals = [[0,2],[3,4],[5,7]], toBeRemoved = [1,6]
c=1, d=6

[0,2]: a=0, b=2
  b=2 > c=1（不是左边），a=0 < d=6（不是右边），有重叠
  a=0 < c=1 → 保留左侧 [0,1]
  b=2 < d=6 → 不保留右侧
  result = [[0,1]]

[3,4]: a=3, b=4
  b=4 > c=1（不是左边），a=3 < d=6（不是右边），有重叠
  a=3 > c=1 → 不保留左侧
  b=4 < d=6 → 不保留右侧（完全被覆盖）
  result = [[0,1]]

[5,7]: a=5, b=7
  b=7 > c=1（不是左边），a=5 < d=6（不是右边），有重叠
  a=5 > c=1 → 不保留左侧
  b=7 > d=6 → 保留右侧 [6,7]
  result = [[0,1],[6,7]]

输出：[[0,1],[6,7]] ✓
```

### 方法二：更紧凑的写法

```python
from typing import List

class Solution:
    def removeInterval(self, intervals: List[List[int]], toBeRemoved: List[int]) -> List[List[int]]:
        c, d = toBeRemoved
        result = []

        for a, b in intervals:
            # 保留左侧部分：[a, min(b,c)]，当且仅当 min(b,c) > a
            if a < c:
                # 当前区间左端超出删除区间的左边，保留 [a, c] 或 [a, b]（取较小者）
                result.append([a, min(b, c)])
            # 保留右侧部分：[max(a,d), b]，当且仅当 max(a,d) < b
            if b > d:
                result.append([max(a, d), b])

        return result
```

**为什么这样写等价？**

对于任意区间 `[a, b]` 和删除区间 `[c, d]`：
- 左侧保留条件：`a < c`，保留 `[a, min(b,c)]`
  - 若 `b <= c`（无重叠，左边），则 `min(b,c)=b`，保留整个 `[a,b]`，正确
  - 若 `b > c`（有重叠，左侧），则 `min(b,c)=c`，保留 `[a,c]`，正确
  - 若 `a >= c`，则条件 `a < c` 不满足，不保留，正确
- 右侧保留条件：`b > d`，保留 `[max(a,d), b]`
  - 若 `a >= d`（无重叠，右边），则 `max(a,d)=a`，保留整个 `[a,b]`，正确
  - 若 `a < d`（有重叠，右侧），则 `max(a,d)=d`，保留 `[d,b]`，正确

### 方法三：显式处理所有情况（最清晰）

```python
from typing import List

class Solution:
    def removeInterval(self, intervals: List[List[int]], toBeRemoved: List[int]) -> List[List[int]]:
        c, d = toBeRemoved
        result = []

        for a, b in intervals:
            # 区分六种情况
            if b <= c or a >= d:
                # 无重叠，直接保留
                result.append([a, b])
            else:
                # 有重叠：可能保留左部分和/或右部分
                if a < c:
                    result.append([a, c])   # 保留左部分
                if b > d:
                    result.append([d, b])   # 保留右部分
                # 完全覆盖（a>=c 且 b<=d）：不保留

        return result
```

## 关键点总结

1. **分情况讨论**：处理区间问题时，先枚举所有情况（无重叠/有重叠），再逐一处理，是最清晰的思路。
2. **无重叠的判断**：`b <= c`（在左边）或 `a >= d`（在右边）表示无重叠，直接保留。
3. **有重叠时的拆分**：
   - 左侧剩余：`a < c` 时，保留 `[a, c]`
   - 右侧剩余：`b > d` 时，保留 `[d, b]`
4. **方法二的精妙**：将无重叠和有重叠的情况统一用 `min/max` 处理，代码更简洁但需要多想一下。
5. **结果顺序**：由于输入已有序，且每个区间最多产生两个片段（先左后右），结果天然有序，无需额外排序。

---

## 易错点

1. **边界是否包含**：本题的区间是闭区间，`b <= c` 表示 b 等于 c 时也无重叠（即 [a,c] 和 [c,d] 视为不重叠，端点相切但不交叉），要注意等号的方向。
2. **不要遗漏"完全被覆盖"的情况**：当 `a >= c` 且 `b <= d` 时，区间被完全覆盖，不产生任何输出。方法一中 `else` 分支的两个 `if` 都不满足，自然处理；方法二也是如此。
3. **结果区间不能为空**：方法二中 `[a, min(b,c)]` 只在 `a < c` 时添加，若 `a >= c`，则左侧无剩余（不添加）；`[max(a,d), b]` 只在 `b > d` 时添加，确保添加的区间长度大于 0。
4. **输入已有序，输出也应有序**：由于每个区间最多分裂为左右两部分，且左部分先于右部分，输出仍然有序，不需要排序。
