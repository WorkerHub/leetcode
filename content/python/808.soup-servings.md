## 题目描述

有 `A` 和 `B` 两种类型的汤。一开始每种类型的汤有 `n` 毫升。有四种分配操作：

1. 提供 100ml 的 **汤A** 和 0ml 的 **汤B**
2. 提供 75ml 的 **汤A** 和 25ml 的 **汤B**
3. 提供 50ml 的 **汤A** 和 50ml 的 **汤B**
4. 提供 25ml 的 **汤A** 和 75ml 的 **汤B**

当我们把汤分配给某人之后，汤就没有了。每个回合，我们将从四种概率同为 0.25 的操作中进行分配选择。如果汤的剩余量不足以完成某次操作，我们将尽可能分配。当两种类型的汤都分配完时，停止操作。

返回 **汤A** 先分配完的概率 + **汤A和汤B** 同时分配完的概率 / 2。结果在正确答案 `10^-5` 的范围内将被认为是正确的。

**示例 1:**
```
输入: n = 50
输出: 0.62500
解释: 如果我们选择前两个操作，A 首先将变为空。
对于第三个操作，A 和 B 会同时变为空。
对于第四个操作，B 首先将变为空。
所以 A 变为空的总概率加上 A 和 B 同时变为空的概率的一半是 0.25 * (1 + 1 + 0.5 + 0) = 0.625。
```

**示例 2:**
```
输入: n = 100
输出: 0.71875
```

**提示:**
- `0 <= n <= 10^9`

## 解题思路

这是一道概率 DP 问题，需要注意数学优化。

**核心思想：**
1. 用 `dp[a][b]` 表示当汤 A 剩余 a 毫升、汤 B 剩余 b 毫升时，满足条件的概率
2. 四种操作的概率均为 0.25
3. 当 n 很大时（如 n > 5000），由于 A 消耗总是 >= B，概率会非常接近 1

**状态转移：**
```
dp[a][b] = 0.25 * (dp[a-100][b] + dp[a-75][b-25] + dp[a-50][b-50] + dp[a-25][b-75])
```

**边界条件：**
- `dp[0][0] = 0.5`（同时为空，贡献 0.5）
- `dp[0][b] = 1`（A 先空，贡献 1）
- `dp[a][0] = 0`（B 先空，贡献 0）

**优化：**
由于 n 可能很大，我们需要：
1. 将 n 转换为 25ml 的倍数（除以 25 向上取整）
2. 当 n > 5000 时，直接返回 1（数学分析可证明概率接近 1）

## Python 代码实现

### 方法一：记忆化递归（推荐）⭐

```python
from functools import lru_cache

class Solution:
    def soupServings(self, n: int) -> float:
        # 当 n 很大时，概率接近 1
        if n > 5000:
            return 1.0
        
        # 转换为 25ml 的倍数
        n = (n + 24) // 25
        
        @lru_cache(maxsize=None)
        def dp(a: int, b: int) -> float:
            """
            返回当汤A剩余a份、汤B剩余b份时的概率
            """
            # 边界条件
            if a <= 0 and b <= 0:
                return 0.5  # 同时为空
            if a <= 0:
                return 1.0  # A 先空
            if b <= 0:
                return 0.0  # B 先空
            
            # 四种操作，每种概率 0.25
            return 0.25 * (
                dp(a - 4, b) +      # 操作1: A-100, B-0
                dp(a - 3, b - 1) +  # 操作2: A-75, B-25
                dp(a - 2, b - 2) +  # 操作3: A-50, B-50
                dp(a - 1, b - 3)    # 操作4: A-25, B-75
            )
        
        return dp(n, n)
```

### 方法二：自底向上 DP

```python
class Solution:
    def soupServings(self, n: int) -> float:
        if n > 5000:
            return 1.0
        
        # 转换为 25ml 的倍数
        n = (n + 24) // 25
        
        # dp[a][b] 表示汤A剩余a份、汤B剩余b份时的概率
        dp = [[0.0] * (n + 1) for _ in range(n + 1)]
        
        # 边界条件
        dp[0][0] = 0.5
        for b in range(1, n + 1):
            dp[0][b] = 1.0
        
        # 状态转移
        for a in range(1, n + 1):
            for b in range(1, n + 1):
                dp[a][b] = 0.25 * (
                    dp[max(0, a - 4)][b] +
                    dp[max(0, a - 3)][max(0, b - 1)] +
                    dp[max(0, a - 2)][max(0, b - 2)] +
                    dp[max(0, a - 1)][max(0, b - 3)]
                )
        
        return dp[n][n]
```

### 方法三：带边界优化的递归

```python
from functools import lru_cache

class Solution:
    def soupServings(self, n: int) -> float:
        if n > 5000:
            return 1.0
        
        # 转换为 25ml 单位
        n = -(-n // 25)  # 向上取整
        
        @lru_cache(maxsize=None)
        def solve(a: int, b: int) -> float:
            # A 和 B 都空了
            if a <= 0 and b <= 0:
                return 0.5
            # 只有 A 空了
            if a <= 0:
                return 1.0
            # 只有 B 空了
            if b <= 0:
                return 0.0
            
            # 递归计算
            return 0.25 * sum([
                solve(a - 4, b),
                solve(a - 3, b - 1),
                solve(a - 2, b - 2),
                solve(a - 1, b - 3)
            ])
        
        return solve(n, n)
```

### 方法四：字典记忆化

```python
class Solution:
    def soupServings(self, n: int) -> float:
        if n > 5000:
            return 1.0
        
        n = (n + 24) // 25
        memo = {}
        
        def dp(a: int, b: int) -> float:
            if (a, b) in memo:
                return memo[(a, b)]
            
            if a <= 0 and b <= 0:
                return 0.5
            if a <= 0:
                return 1.0
            if b <= 0:
                return 0.0
            
            result = 0.25 * (
                dp(a - 4, b) +
                dp(a - 3, b - 1) +
                dp(a - 2, b - 2) +
                dp(a - 1, b - 3)
            )
            
            memo[(a, b)] = result
            return result
        
        return dp(n, n)
```

## 复杂度分析

### 记忆化递归：
- **时间复杂度**：O(n²)，最多计算 n² 个不同状态
- **空间复杂度**：O(n²)，记忆化缓存和递归栈

### 自底向上 DP：
- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **概率 DP**：状态转移方程包含概率权重
2. **数学优化**：n > 5000 时直接返回 1.0
3. **单位转换**：除以 25 减少状态数量
4. **边界处理**：三种边界情况需要分别处理
5. **向上取整**：`(n + 24) // 25` 或 `-(-n // 25)`

## 易错点

1. **忘记数学优化**：n 很大时会超时，需要特判
2. **边界条件**：同时为空返回 0.5，不是 1
3. **单位转换**：必须向上取整，不能简单除以 25
4. **概率计算**：每种操作概率是 0.25
5. **负数处理**：剩余量可能为负，需要用 max(0, a - x)
