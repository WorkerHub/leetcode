## 题目描述

给定两个字符串 `s` 和 `goal`，如果在若干次旋转操作之后，`s` 能变成 `goal`，那么返回 `true`。

`s` 的旋转操作就是将 `s` 最左边的字符移动到最右边。

例如，若 `s = 'abcde'`，在旋转一次之后结果就是 `'bcdea'`。

**示例 1：**
```
输入：s = "abcde", goal = "cdeab"
输出：true
```

**示例 2：**
```
输入：s = "abcde", goal = "abced"
输出：false
```

**提示：**
- `1 <= s.length, goal.length <= 100`
- `s` 和 `goal` 由小写英文字母组成

## 解题思路

这是一道经典的字符串旋转问题。核心观察是：**如果 `s` 可以通过旋转得到 `goal`，那么 `goal` 一定是 `s + s` 的子串**。

**为什么这样做？**

当我们把 `s` 拼接成 `s + s` 后，实际上包含了 `s` 所有可能的旋转结果。例如：
- `s = "abcde"`
- `s + s = "abcdeabcde"`

这个字符串包含了所有旋转结果：
- "abcde"（旋转 0 次）
- "bcdea"（旋转 1 次）
- "cdeab"（旋转 2 次）
- "deabc"（旋转 3 次）
- "eabcd"（旋转 4 次）

因此，只需要检查 `goal` 是否在 `s + s` 中即可。

**注意边界条件：**
- 两个字符串长度必须相等
- 空字符串的情况

## Python 代码实现

### 方法一：字符串拼接法（推荐）

```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        """
        利用字符串拼接的性质判断旋转
        
        思路：如果 goal 是 s 的旋转结果，那么 goal 一定是 s+s 的子串
        
        参数：
            s: 原始字符串
            goal: 目标字符串
            
        返回：
            bool: 是否可以通过旋转得到
        """
        # 长度不等，直接返回 False
        if len(s) != len(goal):
            return False
        
        # 检查 goal 是否是 s+s 的子串
        return goal in s + s
```

### 方法二：逐个旋转模拟

```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        """
        模拟旋转过程，逐个检查
        
        思路：尝试所有可能的旋转次数，看是否能得到 goal
        
        参数：
            s: 原始字符串
            goal: 目标字符串
            
        返回：
            bool: 是否可以通过旋转得到
        """
        # 长度不等，直接返回 False
        if len(s) != len(goal):
            return False
        
        # 长度为 0 的特殊情况
        if len(s) == 0:
            return True
        
        # 尝试所有可能的旋转次数
        for i in range(len(s)):
            # 旋转 i 次：将前 i 个字符移到后面
            rotated = s[i:] + s[:i]
            if rotated == goal:
                return True
        
        return False
```

### 方法三：使用 collections.deque

```python
from collections import deque

class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        """
        使用双端队列进行旋转
        
        思路：利用 deque 的 rotate 方法模拟旋转过程
        
        参数：
            s: 原始字符串
            goal: 目标字符串
            
        返回：
            bool: 是否可以通过旋转得到
        """
        # 长度不等，直接返回 False
        if len(s) != len(goal):
            return False
        
        # 将字符串转为 deque
        dq = deque(s)
        
        # 尝试所有可能的旋转
        for _ in range(len(s)):
            if ''.join(dq) == goal:
                return True
            # 左旋：将最左边的元素移到最右边
            dq.rotate(-1)
        
        return False
```

## 复杂度分析

### 方法一：字符串拼接法
- **时间复杂度：** O(n)，其中 n 是字符串长度。字符串拼接需要 O(n)，子串查找平均 O(n)
- **空间复杂度：** O(n)，需要创建 `s + s` 的新字符串

### 方法二：逐个旋转模拟
- **时间复杂度：** O(n²)，最多旋转 n 次，每次比较需要 O(n)
- **空间复杂度：** O(n)，每次旋转都需要创建新字符串

### 方法三：使用 deque
- **时间复杂度：** O(n²)，最多旋转 n 次，每次转换和比较需要 O(n)
- **空间复杂度：** O(n)，deque 存储所有字符

## 关键点总结

1. **核心技巧**：`s + s` 包含了 `s` 的所有旋转结果，这是最关键的观察
2. **边界条件**：需要先检查两个字符串长度是否相等
3. **方法选择**：方法一最简洁高效，是面试中的最佳答案
4. **字符串不可变性**：Python 中字符串是不可变的，每次旋转都会创建新字符串
5. **子串查找**：Python 的 `in` 操作符对字符串查找做了优化，效率较高

## 易错点

1. **忘记检查长度**：如果两个字符串长度不同，一定无法通过旋转得到，这是必要条件
2. **空字符串处理**：空字符串的旋转仍是空字符串，返回 `True`
3. **相同字符串**：`s` 和 `goal` 相同时也应返回 `True`（旋转 0 次或 n 次）
4. **字符串拼接陷阱**：不要写成 `s in goal + goal`，应该是 `goal in s + s`
5. **索引越界**：在方法二中，切片操作要确保索引正确
