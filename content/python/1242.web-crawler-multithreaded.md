## 题目描述

给定一个 URL `startUrl` 和一个接口 `HtmlParser`，实现一个多线程网页爬虫，爬取从 `startUrl` 开始的所有与其同一主机名下的链接。

返回爬虫获取的所有 URL，返回顺序不限。

你的爬虫应该：
- 从页面 `startUrl` 开始
- 调用 `HtmlParser.getUrls(url)` 获取给定网页的所有 URL
- 不要爬取相同的链接两次
- 只探索与 `startUrl` 同一主机名下的链接

HtmlParser 接口：

```python
class HtmlParser(object):
    def getUrls(self, url: str) -> List[str]:
        """
        返回给定 URL 网页上的所有 URL
        """
        pass
```

主机名定义：
- 为简单起见，假设所有 URL 都使用 HTTP 协议，不指定端口
- 例如，URL `http://leetcode.com/problems` 和 `http://leetcode.com/contest` 在同一主机名下
- 但 `http://example.org/test` 和 `http://example.com/abc` 不在同一主机名下

约束条件：
- 1 <= urls.length <= 1000
- 1 <= urls[i].length <= 300
- startUrl 是 urls 中的一个
- 主机名唯一
- getUrls(url) 保证在 15ms 内返回
- 单线程解决方案会超时

示例 1：

输入：

```
urls = [
  "http://news.yahoo.com",
  "http://news.yahoo.com/news",
  "http://news.yahoo.com/news/topics/",
  "http://news.google.com",
  "http://news.yahoo.com/us"
]
edges = [[2,0],[2,1],[3,2],[3,1],[0,4]]
startUrl = "http://news.yahoo.com/news/topics/"
```

输出：

```
[
  "http://news.yahoo.com",
  "http://news.yahoo.com/news",
  "http://news.yahoo.com/news/topics/",
  "http://news.yahoo.com/us"
]
```

示例 2：

输入：

```
urls = [
  "http://news.yahoo.com",
  "http://news.yahoo.com/news",
  "http://news.yahoo.com/news/topics/",
  "http://news.google.com"
]
edges = [[0,2],[2,1],[3,2],[3,1],[3,0]]
startUrl = "http://news.google.com"
```

输出：

```
["http://news.google.com"]
```

解释：startUrl 链接到的所有其他页面都不在同一主机名下。

## 解题思路

这道题是一个经典的网络爬虫问题，需要使用多线程来提高效率。核心思想：

1. 从 `startUrl` 提取主机名
2. 使用 BFS 或 DFS 遍历所有可达的 URL
3. 对于每个 URL，检查是否为同一主机名，是否已访问
4. 使用多线程并发爬取，提高效率
5. 使用线程安全的数据结构（如 set + lock）避免重复访问

关键点：
- 提取主机名：从 URL 中解析出主机名部分
- 去重：使用 set 记录已访问的 URL
- 线程安全：使用 Lock 保护共享数据结构
- 任务队列：使用 Queue 管理待爬取的 URL
- 线程池：使用 ThreadPoolExecutor 管理线程

## Python 代码实现

### 方法一：使用 ThreadPoolExecutor + Queue（推荐）

```python
from typing import List
from concurrent.futures import ThreadPoolExecutor
from queue import Queue
import threading

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        """
        使用线程池和队列实现多线程爬虫
        
        参数：
            startUrl: 起始URL
            htmlParser: HTML解析器接口
        
        返回：
            所有爬取到的同主机名URL列表
        """
        # 提取主机名
        def get_hostname(url: str) -> str:
            # 去掉 "http://"
            url = url[7:]
            # 找到第一个 '/' 的位置
            end = url.find('/')
            if end == -1:
                return url
            return url[:end]
        
        hostname = get_hostname(startUrl)
        visited = {startUrl}  # 已访问的URL集合
        result = [startUrl]   # 结果列表
        lock = threading.Lock()  # 线程锁
        queue = Queue()  # 任务队列
        queue.put(startUrl)
        
        def crawl_url(url: str):
            """爬取单个URL"""
            urls = htmlParser.getUrls(url)
            
            for next_url in urls:
                # 检查主机名是否相同
                if get_hostname(next_url) != hostname:
                    continue
                
                # 使用锁保护共享数据
                with lock:
                    if next_url not in visited:
                        visited.add(next_url)
                        result.append(next_url)
                        queue.put(next_url)
        
        # 使用线程池
        with ThreadPoolExecutor(max_workers=5) as executor:
            while not queue.empty():
                current_url = queue.get()
                executor.submit(crawl_url, current_url)
        
        return result
```

### 方法二：使用 threading.Thread + 条件变量

```python
from typing import List
import threading
from collections import deque

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        """
        使用条件变量实现线程同步
        """
        # 提取主机名
        def get_hostname(url: str) -> str:
            url = url.replace("http://", "")
            parts = url.split('/')
            return parts[0]
        
        hostname = get_hostname(startUrl)
        visited = {startUrl}
        queue = deque([startUrl])
        lock = threading.Lock()
        cv = threading.Condition(lock)
        active_threads = 0
        max_threads = 5
        
        def worker():
            nonlocal active_threads
            
            while True:
                with cv:
                    # 等待有任务或所有线程空闲
                    while not queue and active_threads > 0:
                        cv.wait()
                    
                    # 没有任务且没有活跃线程，退出
                    if not queue and active_threads == 0:
                        cv.notify_all()
                        return
                    
                    if not queue:
                        return
                    
                    url = queue.popleft()
                    active_threads += 1
                
                # 爬取URL（释放锁）
                try:
                    urls = htmlParser.getUrls(url)
                    
                    with cv:
                        for next_url in urls:
                            if get_hostname(next_url) == hostname and next_url not in visited:
                                visited.add(next_url)
                                queue.append(next_url)
                finally:
                    with cv:
                        active_threads -= 1
                        cv.notify_all()
        
        # 创建线程
        threads = [threading.Thread(target=worker) for _ in range(max_threads)]
        for thread in threads:
            thread.start()
        for thread in threads:
            thread.join()
        
        return list(visited)
```

### 方法三：使用 concurrent.futures + set

```python
from typing import List
from concurrent.futures import ThreadPoolExecutor, as_completed
import threading

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        """
        使用 futures 和 as_completed 实现
        """
        # 提取主机名
        hostname = startUrl.split('/')[2]
        
        visited = set()
        lock = threading.Lock()
        
        def crawl_page(url: str) -> List[str]:
            """
            爬取单个页面，返回新发现的URL
            """
            with lock:
                if url in visited:
                    return []
                visited.add(url)
            
            urls = htmlParser.getUrls(url)
            new_urls = []
            
            for next_url in urls:
                next_hostname = next_url.split('/')[2]
                if next_hostname == hostname:
                    with lock:
                        if next_url not in visited:
                            new_urls.append(next_url)
            
            return new_urls
        
        # 使用线程池
        with ThreadPoolExecutor(max_workers=4) as executor:
            futures = {executor.submit(crawl_page, startUrl)}
            
            while futures:
                # 等待任务完成
                done, futures = as_completed(futures), set()
                
                for future in done:
                    new_urls = future.result()
                    for url in new_urls:
                        futures.add(executor.submit(crawl_page, url))
        
        return list(visited)
```

### 方法四：简化版（使用递归锁）

```python
from typing import List
from concurrent.futures import ThreadPoolExecutor
import threading

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        """
        简化版实现，使用递归锁
        """
        # 提取主机名
        hostname = startUrl[7:].split('/')[0]
        
        visited = set()
        lock = threading.RLock()  # 递归锁
        
        def dfs(url: str):
            """深度优先搜索"""
            with lock:
                if url in visited:
                    return
                visited.add(url)
            
            urls = htmlParser.getUrls(url)
            
            # 过滤同主机名的URL
            same_host_urls = [
                u for u in urls 
                if u[7:].split('/')[0] == hostname
            ]
            
            # 并行爬取
            with ThreadPoolExecutor(max_workers=5) as executor:
                executor.map(dfs, same_host_urls)
        
        dfs(startUrl)
        return list(visited)
```

## 复杂度分析

时间复杂度：
- O(N)，其中 N 是需要爬取的 URL 数量
- 每个 URL 只会被访问一次（使用 visited 集合去重）
- 多线程可以显著减少总体运行时间

空间复杂度：
- O(N)，用于存储已访问的 URL 集合和结果列表
- 队列在最坏情况下也可能存储 O(N) 个 URL

## 关键点总结

1. 主机名提取：从 URL 中正确解析主机名（去掉协议和路径）
2. 线程安全：使用 Lock 保护共享数据结构（visited、queue、result）
3. 避免重复：使用 set 记录已访问的 URL
4. 线程池管理：合理控制线程数量（通常 4-10 个线程）
5. 任务分发：使用队列或 futures 管理待处理的 URL

## 易错点

1. 主机名提取错误：没有正确处理 URL 的各个部分
2. 竞态条件：多个线程同时修改共享数据结构导致重复访问
3. 死锁：不当的锁使用导致线程死锁
4. 线程未等待：主线程退出前未等待所有工作线程完成
5. 队列判空错误：在多线程环境下，queue.empty() 不是线程安全的

### Follow-up 问题解答

假设有 10000 个节点和 10 亿个 URL 需要爬取，如何设计分布式爬虫？

1. URL 分片：使用一致性哈希将 URL 分配到不同节点
2. 主机名分组：相同主机名的 URL 分配到同一节点（避免重复请求）
3. 中心协调：使用消息队列（如 Kafka）分发任务
4. 去重策略：
   - 本地去重：每个节点维护自己的 visited 集合
   - 全局去重：使用分布式缓存（如 Redis）或布隆过滤器
5. 负载均衡：监控每个节点的任务队列长度，动态调整分配
6. 容错机制：任务失败后重试，节点宕机后任务重新分配
