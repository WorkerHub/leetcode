## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

**示例 1：**

```
输入：prices = [7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```

**提示：**

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## 解题思路

这是股票买卖系列问题中最简单的一道，只允许进行一次交易（买入+卖出）。

**核心思想：**

1. **贪心思想**：在最低点买入，在最低点之后的最高点卖出
2. **一次遍历**：维护当前的最低价格和最大利润
3. **动态规划**：定义状态表示持有/未持有股票时的最大利润

**关键观察：**

- 要获得最大利润，必须在某个低点买入，在之后的高点卖出
- 只需要记录到目前为止的最低价格，然后计算当前价格卖出的利润
- 不断更新最大利润即可

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 记录到目前为止的最低价格
        min_price = float('inf')
        # 记录最大利润
        max_profit = 0
        
        for price in prices:
            # 更新最低价格
            if price < min_price:
                min_price = price
            # 计算如果今天卖出的利润
            elif price - min_price > max_profit:
                max_profit = price - min_price
        
        return max_profit
```

### 方法二：简化版

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            min_price = min(min_price, price)
            max_profit = max(max_profit, price - min_price)
        
        return max_profit
```

### 方法三：动态规划

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0
        
        # dp[i][0] 表示第 i 天不持有股票的最大利润
        # dp[i][1] 表示第 i 天持有股票的最大利润
        dp = [[0, 0] for _ in range(n)]
        
        # 初始化
        dp[0][0] = 0              # 第 0 天不持有，利润为 0
        dp[0][1] = -prices[0]     # 第 0 天持有，利润为 -prices[0]
        
        for i in range(1, n):
            # 不持有：要么昨天就不持有，要么今天卖出
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            # 持有：要么昨天就持有，要么今天买入（只能交易一次，所以买入时利润为 -prices[i]）
            dp[i][1] = max(dp[i-1][1], -prices[i])
        
        # 最后一天不持有股票的利润最大
        return dp[n-1][0]
```

### 方法四：动态规划 + 空间优化

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 不持有股票的最大利润
        not_hold = 0
        # 持有股票的最大利润
        hold = -prices[0]
        
        for i in range(1, len(prices)):
            # 更新不持有和持有的状态
            not_hold = max(not_hold, hold + prices[i])
            hold = max(hold, -prices[i])
        
        return not_hold
```

### 方法五：暴力解法（不推荐，超时）

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        max_profit = 0
        n = len(prices)
        
        # 枚举所有买入和卖出的组合
        for i in range(n):
            for j in range(i + 1, n):
                profit = prices[j] - prices[i]
                max_profit = max(max_profit, profit)
        
        return max_profit
```

## 复杂度分析

**方法一、二：一次遍历**
- 时间复杂度：O(n)，只需要遍历一次数组
- 空间复杂度：O(1)，只使用常量额外空间

**方法三：动态规划**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要二维 DP 数组

**方法四：DP + 空间优化**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法五：暴力解法**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 关键点总结

1. **贪心策略**：在最低点买入，在之后的最高点卖出
2. **一次遍历**：只需要记录最低价格和最大利润
3. **状态定义**：DP 中定义持有/不持有股票的最大利润
4. **买卖限制**：只能交易一次，所以买入时利润为负的价格
5. **边界条件**：价格一直下跌时，利润为 0

## 易错点

1. **理解题意**：必须先买入再卖出，不能在买入前卖出
2. **最大利润为 0**：如果价格一直下跌，返回 0 而不是负数
3. **更新顺序**：要先判断是否更新最低价格，再计算利润
4. **初始化**：最低价格初始化为正无穷或第一个价格
5. **DP 状态转移**：持有股票时，买入利润为 `-prices[i]` 而不是 `not_hold - prices[i]`
