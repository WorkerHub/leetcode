## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，找到数组中某个 **连续子数组** 的按位或（OR）值与 `k` 最接近（绝对差最小）。

返回该最小绝对差。

**示例 1：**
```
输入：nums = [1,2,4,5], k = 3
输出：0
解释：[1,2] 的 OR = 3，差为 0。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

对固定右端点 r，随左端点 l 增大，OR 值单调不增（每移动一步 l 右移，OR 不会增大）。

对每个右端点 r，维护所有不同 OR 值（至多 30 个，因为每次增加至少一位从 0 变 1）。

用集合维护以 r 为右端点所有可能的 OR 值，每次加入 nums[r] 后更新，并检查与 k 的绝对差。

## Python 代码实现

### 方法一：维护当前右端点的 OR 值集合（推荐）

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        ans = float('inf')
        # 维护以当前位置结尾的所有不同 OR 值
        prev = set()

        for x in nums:
            curr = {x}  # 至少包含 x 本身（长度为 1 的子数组）
            for v in prev:
                curr.add(v | x)
            for v in curr:
                ans = min(ans, abs(v - k))
            prev = curr

        return ans
```

### 方法二：用列表（去重版）

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        ans = float('inf')
        # or_vals: 以前一位置结尾的所有 OR 值（去重）
        or_vals = []

        for x in nums:
            new_vals = list({v | x for v in or_vals} | {x})
            for v in new_vals:
                ans = min(ans, abs(v - k))
            or_vals = new_vals

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 30)，每个右端点最多 30 个不同 OR 值
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. 固定右端点，随左端点右移 OR 值单调不增
2. 每个右端点的不同 OR 值最多 30 个（32 位整数，每次至少多一个 1）
3. 枚举所有不同 OR 值与 k 的差

## 易错点

1. OR 值只能增大，不能减小，因此不同值数量有上限
2. 每步要更新 prev 为当前所有 OR 值
