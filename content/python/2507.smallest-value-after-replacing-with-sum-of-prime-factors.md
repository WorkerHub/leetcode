## 题目描述

给你一个正整数 `n`。

请你将 `n` **替换** 为 `n` 的 **质因数之和**（包含重复的质因数）。

- 例如，`15 = 3 * 5`，质因数之和为 `3 + 5 = 8`；`25 = 5 * 5`，质因数之和为 `5 + 5 = 10`。

不断重复这一过程，直到 `n` 无法再被减小。

返回 `n` 可以取到的 **最小值**。

**示例 1：**

```
输入：n = 15
输出：5
解释：15 → 3+5=8 → 2+2+2=6 → 2+3=5 → 5（质数，无法继续）
```

**示例 2：**

```
输入：n = 3
输出：3
解释：3 是质数，无法被替换。
```

**提示：**

- `2 <= n <= 10^5`

## 解题思路

模拟题。每次对 n 进行质因数分解，求质因数之和，替换 n，直到 n 不再减小（即 n 为质数，此时质因数之和等于 n 本身）。

质因数分解：从 2 开始试除，每除一次记录该质因数。

终止条件：当某次替换后 n 的值不变（即 n 本身是质数）时停止。

## Python 代码实现

### 方法一：模拟 + 质因数分解（推荐）

```python
class Solution:
    def smallestValue(self, n: int) -> int:
        def prime_factor_sum(x: int) -> int:
            # 返回 x 的所有质因数之和（含重复）
            total = 0
            d = 2
            while d * d <= x:
                while x % d == 0:
                    total += d
                    x //= d
                d += 1
            # 若 x > 1，则剩余的 x 是质因数
            if x > 1:
                total += x
            return total

        while True:
            new_n = prime_factor_sum(n)
            if new_n == n:
                # n 是质数，无法再减小
                return n
            n = new_n
```

### 方法二：使用集合记录已处理的值

```python
class Solution:
    def smallestValue(self, n: int) -> int:
        def prime_factor_sum(x: int) -> int:
            total = 0
            d = 2
            while d * d <= x:
                while x % d == 0:
                    total += d
                    x //= d
                d += 1
            return total + (x if x > 1 else 0)

        # 用集合避免无限循环（理论上不会，但保险）
        seen = set()
        while n not in seen:
            seen.add(n)
            new_n = prime_factor_sum(n)
            if new_n == n:
                return n
            n = new_n
        return n
```

## 复杂度分析

- 每次质因数分解：O(√n)
- 迭代次数：O(log n)，每次替换后 n 迅速减小
- 总时间复杂度：O(√n * log n)
- 空间复杂度：O(1)

## 关键点总结

1. 质因数之和必然 <= n，且当 n 是质数时相等，过程单调不增
2. 迭代会很快收敛，因为质因数分解后的和远小于原数
3. 终止条件：新值等于旧值（即已是质数）

## 易错点

1. 质因数之和包含重复的因数（如 4 = 2*2，和为 4，不是 2）
2. 当 n 是质数时，`prime_factor_sum(n) == n`，直接停止
3. 注意 `d * d <= x` 是试除法的正确条件，不要写成 `d <= x`
