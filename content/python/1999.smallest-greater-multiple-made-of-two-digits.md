## 题目描述

给你三个整数 `k`、`digit1` 和 `digit2`，找到**最小的大于** `k` 的正整数，满足：
- 该整数是 `k` 的倍数
- 该整数只包含数字 `digit1` 和 `digit2`（可以只含其中一个）

返回该整数，若不存在则返回 -1。

**示例 1：**
```
输入：k = 2, digit1 = 0, digit2 = 2
输出：20
```

**示例 2：**
```
输入：k = 3, digit1 = 4, digit2 = 2
输出：24
```

**提示：**
- `1 <= k <= 1000`
- `0 <= digit1, digit2 <= 9`

---

## 解题思路

### 核心思想：BFS 枚举所有只含两种数字的数

用 BFS/BFS 队列，从较小的数字（digit1, digit2）出发，每次在末尾添加 digit1 或 digit2 扩展，直到找到 > k 且是 k 的倍数的数。

由于两种数字都确定，只含这两个数字的正整数是可枚举的（BFS 按位数从小到大）。

注意：若 digit1 = digit2 = 0，则无法构造正整数，返回 -1；若某个数字为 0，首位不能是 0。

---

## 代码实现

### 方法一：BFS 枚举（推荐）

```python
from collections import deque

class Solution:
    def findInteger(self, k: int, digit1: int, digit2: int) -> int:
        digits = sorted(set([digit1, digit2]))

        if digits == [0]:
            return -1  # 只有 0，无法构造正整数

        # BFS：按数值从小到大生成只含 digit1/digit2 的正整数
        queue = deque()
        for d in digits:
            if d != 0:
                queue.append(d)

        LIMIT = 2 * 10**9  # 防止无限循环

        while queue:
            num = queue.popleft()
            if num > LIMIT:
                return -1
            if num > k and num % k == 0:
                return num
            # 扩展：末尾加 digit1 或 digit2
            for d in digits:
                queue.append(num * 10 + d)

        return -1
```

### 方法二：迭代枚举（逐位构造）

```python
from collections import deque

class Solution:
    def findInteger(self, k: int, digit1: int, digit2: int) -> int:
        # 用 BFS，但限制位数（最多 9 位，10^9 以内足够）
        d1, d2 = digit1, digit2
        if d1 == 0 and d2 == 0:
            return -1

        digits = list(set([d1, d2]))
        queue = deque()

        # 初始化：非零开头的数字
        for d in digits:
            if d != 0:
                queue.append(d)

        visited_limit = 2 * 10**9

        while queue:
            x = queue.popleft()
            if x > visited_limit:
                break
            if x > k and x % k == 0:
                return x
            for d in digits:
                nxt = x * 10 + d
                if nxt <= visited_limit:
                    queue.append(nxt)

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(2^L)，L 为答案位数 | O(2^L) |

在实际数据范围内（k<=1000），答案位数不超过 12 位。

---

## 关键点总结

1. BFS 按数值大小（按位数）枚举，保证找到最小值
2. 首位不能为 0（排除以 0 开头的情况）
3. 设置上限防止无限循环，超出返回 -1

---

## 易错点

- 若 digit1 = digit2，只有一种数字构成的数
- 若两个数字都包含 0，首位必须是非 0 数字
