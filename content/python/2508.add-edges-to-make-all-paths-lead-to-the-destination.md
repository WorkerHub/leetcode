## 题目描述

给你一个有向图，包含 `n` 个节点（编号 0 到 n-1）和若干有向边。有向图中可能存在自环、重复边。

你需要添加若干有向边，使得图中所有路径最终都指向节点 `destination`。

如果存在一种添加边的方案使得所有路径都指向 `destination`，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：n = 5, edges = [[0,2],[0,3],[1,2],[3,4]], destination = 2
输出：true
解释：可以添加边 (4,2)，使得所有路径均指向节点 2。
```

**示例 2：**

```
输入：n = 3, edges = [[0,1],[1,1],[1,2]], destination = 1
输出：false
解释：节点 1 有自环，且有出边到 2，无法让所有路径只到 1。
```

**提示：**

- `1 <= n <= 10^4`
- `0 <= edges.length <= 10^4`
- `edges[i].length == 2`
- `0 <= edges[i][0], edges[i][1] < n`
- `0 <= destination < n`

## 解题思路

**DFS 判断可行性**：逐步检查每个节点能否使所有路径到达 destination：

1. `destination` 节点不能有出边（否则路径会继续延伸）
2. 其他节点：若出度为 0，则需要添加边到 destination（可以）；若出度 >= 2，则已经确定了多条路径，需确保每条路径都到达 destination；不能有环（环使路径无法终止）

使用 DFS + 三色标记（未访问=0，访问中=1，已完成=2）：
- 若遇到"访问中"节点，说明有环，返回 false
- 若遇到 destination，不需要继续遍历

## Python 代码实现

### 方法一：DFS 三色标记

```python
from typing import List
from collections import defaultdict

class Solution:
    def leadsToDestination(self, n: int, edges: List[List[int]], destination: int) -> bool:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)

        # destination 不能有出边
        if graph[destination]:
            return False

        # 三色 DFS：0=未访问，1=访问中，2=已完成
        color = [0] * n

        def dfs(node: int) -> bool:
            if color[node] == 1:
                # 当前路径上再次遇到，说明有环
                return False
            if color[node] == 2:
                # 已确认该节点所有路径都到达 destination
                return True

            color[node] = 1  # 标记为"访问中"

            if not graph[node]:
                # 叶子节点必须是 destination
                color[node] = 2
                return node == destination

            for neighbor in graph[node]:
                if not dfs(neighbor):
                    return False

            color[node] = 2
            return True

        # 检查所有节点
        return all(dfs(i) for i in range(n))
```

### 方法二：迭代拓扑排序

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def leadsToDestination(self, n: int, edges: List[List[int]], destination: int) -> bool:
        graph = defaultdict(list)
        in_degree = [0] * n
        for u, v in edges:
            graph[u].append(v)
            in_degree[v] += 1

        if graph[destination]:
            return False

        # 拓扑排序，检查是否所有叶子节点都是 destination
        queue = deque()
        for i in range(n):
            if in_degree[i] == 0:
                queue.append(i)

        visited = 0
        while queue:
            node = queue.popleft()
            visited += 1
            for nb in graph[node]:
                in_degree[nb] -= 1
                if in_degree[nb] == 0:
                    queue.append(nb)

        # 若有未访问节点，说明存在环
        return visited == n
```

## 复杂度分析

- 时间复杂度：O(n + e)，其中 e 为边数
- 空间复杂度：O(n + e)，邻接表和颜色数组

## 关键点总结

1. destination 节点有出边时直接返回 false
2. 三色 DFS 是检测有环并验证所有路径的标准方法
3. 叶子节点（出度为 0）必须是 destination，否则无法添加有效路径

## 易错点

1. 自环是一种特殊的环，DFS 三色法能正确检测
2. destination 可能有入边（正常），但不能有出边
3. 孤立节点（无入边无出边）如果不是 destination 也是问题
