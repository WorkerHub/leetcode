## 题目描述

给定一个 24 小时制的时间列表，时间格式为 `"HH:MM"`，找出列表中任意两个时间点之间的最小时间差（以分钟为单位）。

**示例 1：**
```
输入: timePoints = ["23:59","00:00"]
输出: 1
解释: 从 23:59 到 00:00 只差 1 分钟
```

**示例 2：**
```
输入: timePoints = ["00:00","23:59","00:00"]
输出: 0
解释: 有两个相同的时间点 "00:00"，时间差为 0
```

**提示：**
- `2 <= timePoints.length <= 2 * 10^4`
- `timePoints[i]` 的格式为 `"HH:MM"`

## 解题思路

这道题的核心是计算任意两个时间点之间的最小差值。关键观察：

1. **鸽笼原理**：一天只有 `24 × 60 = 1440` 分钟，如果时间点数量超过 1440，必然有重复时间，可以直接返回 0

2. **时间转换**：将 `"HH:MM"` 格式转换为分钟数，便于计算差值
   - 例如：`"13:14"` 转换为 `13 × 60 + 14 = 794` 分钟

3. **排序优化**：排序后，最小时间差一定出现在相邻的两个时间点之间

4. **环形处理**：24 小时是环形的，需要考虑跨越午夜的情况
   - 例如：`23:59` 到 `00:00` 的差值是 1 分钟，而不是 1439 分钟
   - 解决方法：将最小时间加上 1440 附加到列表末尾

**算法流程：**

1. 如果时间点数量 > 1440，直接返回 0
2. 将所有时间转换为分钟数
3. 对分钟数进行排序
4. 将最小时间 + 1440 附加到列表末尾（处理环形）
5. 遍历相邻时间点，计算最小差值

## Python 代码实现

### 方法一：排序法（推荐）

```python
from typing import List

class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        """
        使用排序解决最小时间差问题
        时间复杂度 O(n log n)，空间复杂度 O(n)
        """
        # 鸽笼原理：一天只有 1440 分钟，超过则必有重复
        if len(timePoints) > 1440:
            return 0
        
        # 将时间字符串转换为分钟数
        nums = []
        for time in timePoints:
            # 解析 "HH:MM" 格式
            hours = int(time[:2])
            minutes = int(time[3:])
            total_minutes = hours * 60 + minutes
            nums.append(total_minutes)
        
        # 排序
        nums.sort()
        
        # 将最小时间 + 1440 添加到末尾，处理跨午夜的情况
        nums.append(nums[0] + 1440)
        
        # 计算相邻时间点的最小差值
        min_diff = float('inf')
        for i in range(1, len(nums)):
            min_diff = min(min_diff, nums[i] - nums[i - 1])
        
        return min_diff
```

### 方法二：一行式写法（Python 特色）

```python
from typing import List
from itertools import pairwise

class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        """
        使用 Python 特性简化代码
        利用列表推导式和 pairwise 函数
        """
        if len(timePoints) > 1440:
            return 0
        
        # 一行转换并排序
        nums = sorted(int(x[:2]) * 60 + int(x[3:]) for x in timePoints)
        
        # 添加环形处理
        nums.append(nums[0] + 1440)
        
        # 使用 pairwise 计算相邻差值的最小值
        return min(b - a for a, b in pairwise(nums))
```

### 方法三：详细注释版（适合初学者）

```python
from typing import List

class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        """
        最详细的实现，包含每个步骤的解释
        """
        # 边界情况：如果时间点超过一天的总分钟数，必有重复
        if len(timePoints) > 1440:
            return 0
        
        # 步骤 1: 将所有时间转换为分钟数
        minutes_list = []
        for time in timePoints:
            # 分割字符串 "HH:MM"
            parts = time.split(':')
            hours = int(parts[0])
            mins = int(parts[1])
            
            # 转换为从 00:00 开始的总分钟数
            total_mins = hours * 60 + mins
            minutes_list.append(total_mins)
        
        # 步骤 2: 排序（升序）
        minutes_list.sort()
        
        # 步骤 3: 处理环形时间（跨午夜的情况）
        # 将第一个时间 + 1440（一天的分钟数）添加到末尾
        # 例如：如果最小时间是 00:30（30 分钟），添加 30 + 1440 = 1470
        # 这样可以计算 23:59（1439 分钟）到 00:30 的差值：1470 - 1439 = 31 分钟
        minutes_list.append(minutes_list[0] + 1440)
        
        # 步骤 4: 计算相邻时间点的最小差值
        min_difference = float('inf')
        for i in range(1, len(minutes_list)):
            difference = minutes_list[i] - minutes_list[i - 1]
            min_difference = min(min_difference, difference)
        
        return min_difference
```

### 方法四：使用集合检测重复

```python
from typing import List

class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        """
        优化：先用集合检测是否有重复时间
        如果有重复，直接返回 0
        """
        # 使用集合检测重复
        if len(timePoints) != len(set(timePoints)):
            return 0
        
        # 转换为分钟数
        nums = [int(t[:2]) * 60 + int(t[3:]) for t in timePoints]
        
        # 排序
        nums.sort()
        
        # 环形处理
        nums.append(nums[0] + 1440)
        
        # 计算最小差值
        return min(nums[i] - nums[i - 1] for i in range(1, len(nums)))
```

## 复杂度分析

### 方法一：排序法
- **时间复杂度**：O(n log n)
  - 时间转换：O(n)
  - 排序：O(n log n)
  - 计算最小差值：O(n)
  - 总体：O(n log n)
- **空间复杂度**：O(n)，用于存储转换后的分钟数

### 方法二：一行式写法
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

### 方法三和方法四
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

**推荐使用方法一或方法二**，代码清晰且高效。

## 关键点总结

1. **鸽笼原理应用**：1440 个可能的时间点，超过则必有重复
2. **时间转换技巧**：`hours * 60 + minutes` 统一转换为分钟数
3. **排序后相邻比较**：最小差值一定在排序后的相邻元素之间
4. **环形时间处理**：将最小时间 + 1440 附加到末尾，处理跨午夜情况
5. **边界优化**：提前检测重复或超过 1440 个时间点的情况

## 易错点

1. **忘记处理跨午夜的情况**
   ```python

       min_diff = min(min_diff, nums[i] - nums[i-1])
   
   # 正确：添加第一个时间 + 1440 到末尾
   nums.append(nums[0] + 1440)
   for i in range(1, len(nums)):
       min_diff = min(min_diff, nums[i] - nums[i-1])
   ```

2. **字符串解析错误**
   ```python
   # 错误：直接转换整个字符串
   time = int("13:14")  # 报错
   
   # 正确：分别解析小时和分钟
   hours = int(time[:2])   # 13
   minutes = int(time[3:]) # 14
   ```
