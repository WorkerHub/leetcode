## 题目描述

给你一个下标从 **0** 开始的字符串数组 `garbage`，其中 `garbage[i]` 表示第 `i` 个房子的垃圾集合。`garbage[i]` 只包含字符 `'M'`、`'P'`、`'G'`，分别代表金属垃圾、纸垃圾和玻璃垃圾。垃圾车每辆各负责一种垃圾，每辆车从房子 `0` 开始，**只能向右**行驶。

给你一个下标从 **0** 开始的整数数组 `travel`，其中 `travel[i]` 是从房子 `i` 行驶到房子 `i+1` 所需的时间。

- 收集每单位垃圾需要 **1** 分钟。
- 每辆车需要行驶到最后一个**含对应垃圾**的房子。

返回收集所有垃圾需要的最少总时间。

**示例 1：**
```
输入：garbage = ["G","P","GP","GG"], travel = [2,4,3]
输出：21
```

**提示：**
- `2 <= garbage.length <= 10^5`
- `garbage[i]` 只含 'M', 'P', 'G'
- `1 <= travel.length < garbage.length`
- `1 <= travel[i] <= 100`

## 解题思路

**前缀和 + 贪心：**

1. 每辆垃圾车需要行驶到最后一个含该种垃圾的房子。
2. 行驶时间 = 前缀和 `prefix[last_idx]`（从 0 到 last_idx 的行驶时间）。
3. 收集时间 = 所有垃圾字符的总数。
4. 总时间 = 收集时间 + 三辆车的行驶时间之和。

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def garbageCollection(self, garbage: List[str], travel: List[int]) -> int:
        # 计算行驶时间前缀和
        prefix = [0] * len(travel)
        prefix[0] = travel[0]
        for i in range(1, len(travel)):
            prefix[i] = prefix[i - 1] + travel[i]
        
        total = 0
        
        for g_type in 'MPG':
            # 找该类垃圾最后出现的房子
            last = -1
            count = 0
            for i, s in enumerate(garbage):
                cnt = s.count(g_type)
                if cnt > 0:
                    last = i
                    count += cnt
            
            # 收集时间
            total += count
            # 行驶时间（从 0 到 last 的 travel 之和）
            if last > 0:
                total += prefix[last - 1]
        
        return total
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def garbageCollection(self, garbage: List[str], travel: List[int]) -> int:
        # 各类垃圾的最后位置
        last = {'M': 0, 'P': 0, 'G': 0}
        total_garbage = 0
        
        for i, s in enumerate(garbage):
            total_garbage += len(s)
            for c in s:
                last[c] = i
        
        # 行驶时间：从 0 到 last[type] 的 travel 之和
        travel_time = 0
        for g_type in 'MPG':
            travel_time += sum(travel[:last[g_type]])
        
        return total_garbage + travel_time
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(n) |
| 一次遍历 | O(n) | O(1) |

## 关键点总结

1. 收集时间 = 所有垃圾字符总数（每字符 1 分钟）。
2. 行驶时间 = 每辆车到达最后一个目标房子的累计 travel 之和。
3. 三辆车独立计算，互不影响。

## 易错点

- 行驶时间是 `sum(travel[:last])` 而不是 `travel[last]`（要累加从 0 到 last-1 的路段）。
- 若该类垃圾只在房子 0，则行驶时间为 0（无需移动）。
- `travel` 数组长度为 `n-1`，`travel[i]` 是从 `i` 到 `i+1` 的时间。
