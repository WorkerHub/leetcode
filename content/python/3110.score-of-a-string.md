## 题目描述

给你一个字符串 `s`，返回其 **得分**。

字符串的 **得分** 定义为相邻字符 ASCII 值差的绝对值之和。

**示例 1：**
```
输入：s = "hello"
输出：13
解释：h(104), e(101), l(108), l(108), o(111)
|104-101| + |101-108| + |108-108| + |108-111| = 3 + 7 + 0 + 3 = 13
```

**示例 2：**
```
输入：s = "zaz"
输出：50
解释：|122-97| + |97-122| = 25 + 25 = 50
```

**提示：**
- `2 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

直接遍历字符串，对每对相邻字符计算 ASCII 值差的绝对值，累加求和即可。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
class Solution:
    def scoreOfString(self, s: str) -> int:
        ans = 0
        for i in range(1, len(s)):
            ans += abs(ord(s[i]) - ord(s[i - 1]))
        return ans
```

### 方法二：使用 zip 简化

```python
class Solution:
    def scoreOfString(self, s: str) -> int:
        return sum(abs(ord(b) - ord(a)) for a, b in zip(s, s[1:]))
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 相邻字符的 ASCII 差取绝对值后求和
2. `ord()` 函数获取字符的 ASCII 值

## 易错点

1. 注意要取绝对值，不能直接相减
2. 遍历从下标 1 开始，或使用 zip(s, s[1:])
