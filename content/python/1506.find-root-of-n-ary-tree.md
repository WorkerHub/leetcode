## 题目描述

给你一个 N 叉树的所有节点（列表形式），请你找出并返回树的根节点。

N 叉树的序列化格式见 LeetCode 题目说明。节点定义如下：

```python
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
```

**示例 1：**
树结构为 1 -> [3,2,4]，3 -> [5,6]，输入为该树的所有节点列表，输出根节点（值为 1 的节点）。

**提示：**
- 节点总数在 `[1, 5 * 10^4]` 范围内
- 每个节点有唯一的值
- 不能修改树的结构

## 解题思路

### 方法一：统计所有子节点（推荐）

**核心思想：**
根节点不是任何节点的子节点。遍历所有节点，将所有出现在 `children` 中的节点收集到一个集合里，不在集合中的节点就是根节点。

### 方法二：XOR 异或技巧

利用异或性质：每个非根节点恰好出现一次（在某个父节点的 children 中）并且在节点列表中也出现一次，共出现 2 次，异或抵消为 0。只有根节点在列表中出现 1 次（不在任何 children 中），XOR 后剩下的就是根节点的值。

## 代码实现

### 方法一：集合记录所有子节点（推荐）

```python
from typing import List

class Solution:
    def findRoot(self, tree: List['Node']) -> 'Node':
        # 收集所有出现在 children 中的节点
        children_set = set()
        for node in tree:
            for child in node.children:
                children_set.add(child.val)

        # 不在 children_set 中的节点就是根节点
        for node in tree:
            if node.val not in children_set:
                return node
        return None
```

### 方法二：异或找根节点

```python
from typing import List

class Solution:
    def findRoot(self, tree: List['Node']) -> 'Node':
        # 所有节点 val 异或，再异或所有 children val
        # 非根节点各出现 2 次，异或为 0；根节点只出现 1 次
        xor_val = 0
        for node in tree:
            xor_val ^= node.val          # 每个节点本身
            for child in node.children:
                xor_val ^= child.val     # 每个子节点值

        # xor_val 就是根节点的值，找到对应节点
        for node in tree:
            if node.val == xor_val:
                return node
        return None
```

### 方法三：使用节点引用集合

```python
from typing import List

class Solution:
    def findRoot(self, tree: List['Node']) -> 'Node':
        # 直接存节点对象引用（更快）
        all_nodes = set(tree)
        child_nodes = set()
        for node in tree:
            for child in node.children:
                child_nodes.add(child)
        # 只在 all_nodes 但不在 child_nodes 中的就是根
        root_candidates = all_nodes - child_nodes
        return root_candidates.pop()
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N) | O(N) |
| 方法二（XOR） | O(N) | O(1) |
| 方法三 | O(N) | O(N) |

方法二空间最优，因为 XOR 只用一个整数变量。

## 关键点总结

1. 根节点是唯一一个不出现在任何节点的 `children` 中的节点
2. 异或技巧利用了"非根节点恰好出现两次"的性质
3. 方法二在空间上比集合方法更优

## 易错点

- 方法一用 `val` 而非节点引用作为标识时，需要保证 val 唯一（题目已保证）
- 方法二要对节点本身和子节点都进行 XOR，不能漏掉一方
