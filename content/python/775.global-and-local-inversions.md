## 题目描述

给定一个长度为 `n` 的整数数组 `nums`，表示一个 `0` 到 `n - 1` 的排列。

**全局倒置** 的数目等于满足下述条件不同下标对 `(i, j)` 的数目：
- `0 <= i < j < n`
- `nums[i] > nums[j]`

**局部倒置** 的数目等于满足下述条件的下标 `i` 的数目：
- `0 <= i < n - 1`
- `nums[i] > nums[i + 1]`

当数组 `nums` 中全局倒置的数量等于局部倒置的数量时，返回 `true`；否则，返回 `false`。

**示例 1:**
```
输入: nums = [1,0,2]
输出: true
解释: 有 1 个全局倒置，和 1 个局部倒置。
```

**示例 2:**
```
输入: nums = [1,2,0]
输出: false
解释: 有 2 个全局倒置，和 1 个局部倒置。
```

## 解题思路

局部倒置一定是全局倒置，所以只需要检查是否存在非局部的全局倒置。即：是否存在 `i` 和 `j`（`j > i + 1`）使得 `nums[i] > nums[j]`。

## Python 代码实现

### 方法一：检查是否存在非局部倒置（推荐）⭐

```python
from typing import List

class Solution:
    def isIdealPermutation(self, nums: List[int]) -> bool:
        # 维护前面的最大值（不包括相邻的前一个）
        max_so_far = nums[0]
        
        for i in range(2, len(nums)):
            if max_so_far > nums[i]:
                return False
            max_so_far = max(max_so_far, nums[i - 1])
        
        return True
```

### 方法二：检查每个元素是否接近其理想位置

```python
class Solution:
    def isIdealPermutation(self, nums: List[int]) -> bool:
        # 每个元素与其索引的差不能超过 1
        for i, num in enumerate(nums):
            if abs(num - i) > 1:
                return False
        return True
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 关键点总结

1. **局部倒置 ⊆ 全局倒置**
2. **条件等价：** 不存在跨度大于 1 的倒置
3. **位置约束：** 每个元素只能在其理想位置的 ±1 范围内
