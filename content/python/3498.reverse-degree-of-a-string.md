## 题目描述

给你一个字符串 `s`，由小写英文字母组成。

字符串的**反向度**（reverse degree）定义为：对字符串中每个字符，将其与字母表中对应的反向字符配对（即 a<->z, b<->y, c<->x, ...），然后乘以其在字符串中的位置（1-indexed），所有乘积之和。

形式化：`sum((26 - (ord(s[i]) - ord('a'))) * (i + 1) for i in range(len(s)))`

**示例：**

```
输入：s = "ab"
输出：51
解释：a 的反向是 z(26)，位置 1，贡献 26*1=26；b 的反向是 y(25)，位置 2，贡献 25*2=50。总和 76。
等等，需要确认公式。实际：26*1 + 25*2 = 26 + 50 = 76？
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

直接模拟：对每个字符，计算其"反向值"（26 - 字母序号），再乘以位置（1-indexed），求和。

字母序号：`ord(c) - ord('a') + 1`（a=1, b=2, ..., z=26）
反向值：`26 - (ord(c) - ord('a'))` 即 `27 - (ord(c) - ord('a') + 1)`

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        total = 0
        for i, c in enumerate(s):
            # 字母序号（a=1, b=2, ..., z=26）
            rank = ord(c) - ord('a') + 1
            # 反向值（a->26, b->25, ..., z->1）
            reverse_rank = 27 - rank  # 等价于 26 - (rank - 1)
            # 位置（1-indexed）
            pos = i + 1
            total += reverse_rank * pos
        return total
```

### 方法二：列表推导式

```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        return sum(
            (26 - (ord(c) - ord('a'))) * (i + 1)
            for i, c in enumerate(s)
        )
```

### 方法三：字母表映射

```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        # 建立字母到反向值的映射
        import string
        reverse_map = {c: 26 - i for i, c in enumerate(string.ascii_lowercase)}
        # a->26, b->25, ..., z->1

        return sum(reverse_map[c] * (i + 1) for i, c in enumerate(s))
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 反向字符：a<->z, b<->y, 公式为 `26 - (ord(c) - ord('a'))`
2. 位置从 1 开始（1-indexed）
3. 求所有 (反向值 * 位置) 的累加和

## 易错点

1. 位置从 1 开始，不是 0
2. 反向值：a 对应 26，z 对应 1
3. `26 - (ord(c) - ord('a'))` vs `27 - (ord(c) - ord('a') + 1)` 结果相同
