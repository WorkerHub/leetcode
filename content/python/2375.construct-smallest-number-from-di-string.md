## 题目描述

给你下标从 **0** 开始、长度为 `n` 的字符串 `pattern`，它包含两种字符：
- `'I'`（递增）：`num[i] < num[i+1]`
- `'D'`（递减）：`num[i] > num[i+1]`

请你返回**最小的** `num`，满足：
- `num` 由 `'1'` 到 `'9'` 的数字组成，长度为 `n+1`。
- 每个数字最多使用一次。

**示例 1：**
```
输入：pattern = "IIIDIDDD"
输出："123549876"
```

**示例 2：**
```
输入：pattern = "DDD"
输出："4321"
```

**提示：**
- `1 <= pattern.length <= 8`

## 解题思路

**栈贪心：**
遍历 pattern（含虚拟位置），维护一个栈。遇到 `'I'` 时（或遍历结束），将栈中元素全部弹出并添加到结果中。

具体：用 1 到 n+1 按顺序分配数字，遇到 `'I'` 时倒序输出之前积压的数字（通过栈实现）。

## 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def smallestNumber(self, pattern: str) -> str:
        n = len(pattern)
        stack = []
        result = []
        
        for i in range(n + 1):
            stack.append(i + 1)  # 压入数字 1 到 n+1
            # 遇到 'I' 或到达末尾，弹出栈中所有元素
            if i == n or pattern[i] == 'I':
                while stack:
                    result.append(stack.pop())
        
        return ''.join(map(str, result))
```

### 方法二：直接构造

```python
class Solution:
    def smallestNumber(self, pattern: str) -> str:
        n = len(pattern)
        result = []
        
        i = 0
        while i <= n:
            # 找连续 'D' 段的长度
            j = i
            while j < n and pattern[j] == 'D':
                j += 1
            # 从 j+1 到 i+1（倒序）填入
            for k in range(j + 1, i, -1):
                result.append(str(k))
            i = j + 1
        
        return ''.join(result)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 栈 | O(n) | O(n) |

## 关键点总结

1. 连续的 `'D'` 段需要将该段数字倒序排列。
2. 用栈实现倒序：先压入再弹出。
3. 遇到 `'I'` 或末尾时，弹出栈中积压的数字。

## 易错点

- 处理边界：最后一个位置后面没有 pattern 字符，相当于虚拟 `'I'`，需要在 `i == n` 时也弹出栈。
- 数字从 1 开始，到 n+1 结束（n+1 个数字）。
