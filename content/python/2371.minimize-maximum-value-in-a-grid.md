## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，每个值各不相同。你需要将每个格子的值替换为一个正整数，满足：
- 替换后矩阵中**同行**和**同列**的值是**非递减**的。
- 使每个格子的**最大值**尽可能小。

返回替换后矩阵的**最大值**的最小可能值。

**提示：**
- `m == grid.length`，`n == grid[i].length`
- `1 <= m, n <= 1000`
- `1 <= grid[i][j] <= 10^6`，所有值不同

## 解题思路

**贪心排序：**

将所有格子按原始值从小到大排序。对每个格子，其替换后的值 = `max(同行已分配最大值 + 1, 同列已分配最大值 + 1)`（即至少比它所在行和列中排在它前面的格子大 1）。

因为原始值唯一且按大小排序，处理顺序从小到大，前面处理过的格子在同行或同列中原始值更小，约束已满足。

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def minScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 收集所有格子并按原始值排序
        cells = sorted((grid[i][j], i, j) for i in range(m) for j in range(n))
        
        row_max = [0] * m  # 每行当前已分配的最大值
        col_max = [0] * n  # 每列当前已分配的最大值
        result = [[0] * n for _ in range(m)]
        
        for _, i, j in cells:
            # 当前格子的值至少比行最大值和列最大值各大 1
            val = max(row_max[i], col_max[j]) + 1
            result[i][j] = val
            row_max[i] = val
            col_max[j] = val
        
        return max(max(row) for row in result)
```

### 方法二：同方法一，返回最后一个赋值

```python
from typing import List

class Solution:
    def minScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        cells = sorted((grid[i][j], i, j) for i in range(m) for j in range(n))
        row_max = [0] * m
        col_max = [0] * n
        ans = 0
        
        for _, i, j in cells:
            v = max(row_max[i], col_max[j]) + 1
            row_max[i] = col_max[j] = v
            ans = max(ans, v)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(m*n * log(m*n)) | O(m*n) |

## 关键点总结

1. 原始值按从小到大排序处理，保证当前格子之前处理的同行列格子原始值更小。
2. 替换值取"行最大值"和"列最大值"中的较大者 + 1。
3. 贪心保证每个格子的替换值尽可能小（最小化局部值），从而最小化整体最大值。

## 易错点

- 所有格子值唯一，可以直接按值排序（无需处理相同值）。
- 最终答案是最大的替换值，由于最大原始值最后处理，其替换值即为答案。
