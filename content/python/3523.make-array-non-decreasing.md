## 题目描述

给定一个整数数组 `nums`，每次操作可以将某个元素替换为它左边或右边相邻元素的值。求使数组变为非递减所需的最少操作次数。

**示例 1：**

```
输入：nums = [3, 2, 4, 5, 1]
输出：2
解释：将 3 替换为 2（使用右邻居的值），再将 1 替换为 5，得 [2,2,4,5,5]，非递减，操作2次。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`

## 解题思路

贪心 + 单调栈。

关键观察：要使数组非递减，需要处理"下降"的位置。使用单调栈找到需要修改的元素数量。

实际上，最少操作次数等于 `n - 最长非递减子序列的长度`（LIS 的变体），但对于这道题有更简单的观察：

用单调栈统计严格需要"改变"的元素：
1. 维护一个非递减单调栈
2. 每次新元素比栈顶小时，需要操作
3. 操作次数等于需要"调整"的元素数

## Python 代码实现

### 方法一：单调栈贪心（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        # 找最长非递减子序列，答案 = n - LIS长度
        # 但可以用单调栈简化（因为可以用相邻元素替换）
        n = len(nums)
        if n <= 1:
            return 0

        # 单调栈：维护当前非递减序列
        stack = []
        ops = 0

        for x in nums:
            if not stack or x >= stack[-1]:
                stack.append(x)
            else:
                # 需要修改 x（用前面某个值替换）
                ops += 1
                # 不需要改变 stack（x 被修改为 stack[-1]）

        return ops
```

### 方法二：动态规划求最长非递减子序列

```python
from typing import List
from bisect import bisect_right

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        # 最长非递减子序列（允许相等）
        tails = []
        for x in nums:
            pos = bisect_right(tails, x)
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x
        # 操作次数 = n - 最长非递减子序列长度
        return n - len(tails)
```

## 复杂度分析

- 时间复杂度：O(n log n)（方法二），O(n)（方法一）
- 空间复杂度：O(n)

## 关键点总结

1. 最少操作次数 = `n - 最长非递减子序列长度`
2. 二分查找加速 LIS 计算
3. 单调栈可以简单统计需要修改的元素数

## 易错点

1. 非递减（允许相等）和严格递增的 LIS 算法有细微区别（`bisect_right` vs `bisect_left`）
2. 替换操作是用相邻元素的值，不能用任意值（但对于非递减问题，贪心上等效）
3. 结果是 `n - LIS长度`，不是 LIS 长度本身
