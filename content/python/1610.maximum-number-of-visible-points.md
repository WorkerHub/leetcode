## 题目描述

给你一个点数组 `points` 和两个整数 `angle` 和 `location`，其中 `location = [posx, posy]` 且 `angle` 表示**视野的角度**（度数）。

你站在 `location` 处，**可以看到**所有在以你为圆心的 `angle` 度角扇形范围内的点。你的**视野可以 360 度自由旋转**。

返回你能看到的点的**最大数目**。

**注意：**
- 位于 `location` 处的点始终可以被看到（即使视野角度是 0）
- `angle` 度的视野可以看到边界上的点

**示例：**
```
输入：points = [[2,1],[2,2],[3,3]], angle = 90, location = [1,1]
输出：3
```

## 解题思路

1. 将所有点转换为**相对于 `location` 的极角**（使用 `atan2`，范围 (-π, π]）
2. 与 `location` 重合的点单独计数（始终可见）
3. 对极角排序后，将角度列表**复制一份加上 2π**（处理环形问题）
4. 使用**滑动窗口**，窗口大小为 `angle`（转换为弧度），找最多的点数

## 代码实现

### 方法一：极角排序 + 滑动窗口（推荐）

```python
from typing import List
import math

class Solution:
    def visiblePoints(self, points: List[List[int]], angle: int, location: List[int]) -> int:
        ox, oy = location
        angles = []
        same = 0  # 与 location 重合的点
        
        for px, py in points:
            if px == ox and py == oy:
                same += 1  # 重合点直接计数
                continue
            # 计算极角（度数），范围 (-180, 180]
            a = math.degrees(math.atan2(py - oy, px - ox))
            angles.append(a)
        
        angles.sort()
        
        # 将角度列表复制一份加 360，处理环形（视野可以跨过 0 度）
        n = len(angles)
        angles = angles + [a + 360 for a in angles]
        
        # 滑动窗口：找窗口内最多的角度数
        max_visible = 0
        left = 0
        for right in range(len(angles)):
            # 当窗口超过 angle 度时，缩小左边界
            while angles[right] - angles[left] > angle:
                left += 1
            max_visible = max(max_visible, right - left + 1)
        
        return max_visible + same
```

### 方法二：使用二分查找代替双指针

```python
from typing import List
import math
import bisect

class Solution:
    def visiblePoints(self, points: List[List[int]], angle: int, location: List[int]) -> int:
        ox, oy = location
        angles = []
        same = 0
        
        for px, py in points:
            if px == ox and py == oy:
                same += 1
                continue
            a = math.degrees(math.atan2(py - oy, px - ox))
            angles.append(a)
        
        angles.sort()
        n = len(angles)
        angles_ext = angles + [a + 360 for a in angles]
        
        max_visible = 0
        for i in range(n):
            # 找到 angles[i] + angle 在 angles_ext 中的位置
            end = bisect.bisect_right(angles_ext, angles_ext[i] + angle)
            max_visible = max(max_visible, end - i)
        
        return max_visible + same
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n log n) | O(n) |
| 二分查找 | O(n log n) | O(n) |

## 关键点总结

1. 将笛卡尔坐标转换为极角是关键步骤（`atan2` 返回弧度，可转换为度数）
2. 复制角度列表并加 360，处理视野跨越 360/0 度的情况
3. 滑动窗口中，窗口宽度不超过 `angle` 度
4. 与 `location` 重合的点单独计数，不参与角度计算

## 易错点

- `atan2` 参数顺序是 `(y, x)` 而不是 `(x, y)`
- 重合点要单独处理（加入角度列表会导致 `atan2(0, 0)` 计算异常）
- 复制时加 360 度，不能加 2π（因为用的是度数）
- 滑动窗口边界处理：`angles[right] - angles[left] > angle` 而不是 `>=`（边界上的点也能看到）
