## 题目描述

请你将一些箱子装在一辆卡车上。给你一个二维数组 `boxTypes`，其中 `boxTypes[i] = [numberOfBoxes_i, numberOfUnitsPerBox_i]`：
- `numberOfBoxes_i` 是类型 `i` 的箱子的数量
- `numberOfUnitsPerBox_i` 是类型 `i` 每个箱子可以装载的单元数量

整数 `truckSize` 表示卡车上可以装载箱子的最大数量。只要箱子数量不超过 `truckSize`，你就可以选择任意箱子装到卡车上。

返回卡车可以装载的最大单元数量。

**示例 1：**
```
输入：boxTypes = [[1,3],[2,2],[3,1]], truckSize = 4
输出：8
解释：选1个[1,3]，2个[2,2]，1个[3,1]，总单元 = 3+4+1 = 8
```

**提示：**
- `1 <= boxTypes.length <= 1000`
- `1 <= numberOfBoxes_i, numberOfUnitsPerBox_i <= 1000`
- `1 <= truckSize <= 10^6`

## 解题思路

贪心策略：优先装每箱单元数最多的箱子，直到卡车装满为止。

步骤：
1. 按每箱单元数降序排序
2. 从单元数最多的箱子开始装，直到达到卡车容量

## 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maximumUnits(self, boxTypes: List[List[int]], truckSize: int) -> int:
        # 按每箱单元数降序排序
        boxTypes.sort(key=lambda x: -x[1])
        
        total_units = 0
        remaining = truckSize  # 剩余可装箱子数
        
        for num_boxes, units_per_box in boxTypes:
            if remaining <= 0:
                break
            # 取当前类型中能装的数量
            take = min(num_boxes, remaining)
            total_units += take * units_per_box
            remaining -= take
        
        return total_units
```

### 方法二：使用 sorted 不修改原数组

```python
from typing import List

class Solution:
    def maximumUnits(self, boxTypes: List[List[int]], truckSize: int) -> int:
        # 按每箱单元数从大到小排序
        sorted_boxes = sorted(boxTypes, key=lambda x: x[1], reverse=True)
        
        total = 0
        capacity = truckSize
        
        for cnt, units in sorted_boxes:
            # 本类型能选的箱子数
            chosen = min(cnt, capacity)
            total += chosen * units
            capacity -= chosen
            # 如果卡车已满，提前结束
            if capacity == 0:
                break
        
        return total
```

## 复杂度分析

- **时间复杂度**：O(n log n)，主要花费在排序
- **空间复杂度**：O(1) 或 O(n)（取决于是否创建新数组）

## 关键点总结

1. 贪心思路：每箱单元数越多越优先
2. 对每类箱子取 `min(可用数量, 剩余容量)`
3. 排序后线性扫描即可

## 易错点

- 要取 `min(num_boxes, remaining)`，不能直接全部取用
- 单元数要累乘数量
