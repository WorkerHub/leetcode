## 题目描述

给你一个整数数组 `arr` ，请使用**煎饼翻转**完成对数组的排序。

一次煎饼翻转的执行过程如下：
- 选择一个整数 `k` ，`1 <= k <= arr.length`
- 反转子数组 `arr[0...k-1]`（**下标从 0 开始**）

例如，`arr = [3,2,1,4]` ，选择 `k = 3` 进行一次煎饼翻转，反转子数组 `[3,2,1]` ，得到 `arr = [1,2,3,4]` 。

以数组形式返回能使 `arr` 有序的煎饼翻转操作所对应的 `k` 值序列。任何将数组排序且翻转次数在 `10 * arr.length` 范围内的有效答案都将被判断为正确。

**示例 1：**
```
输入：[3,2,4,1]
输出：[4,2,4,3]
解释：
我们执行 4 次煎饼翻转，k 值分别为 4，2，4，和 3。
初始状态 arr = [3, 2, 4, 1]
第一次翻转后（k = 4）：arr = [1, 4, 2, 3]
第二次翻转后（k = 2）：arr = [4, 1, 2, 3]
第三次翻转后（k = 4）：arr = [3, 2, 1, 4]
第四次翻转后（k = 3）：arr = [1, 2, 3, 4]，此时已完成排序。
```

**示例 2：**
```
输入：[1,2,3]
输出：[]
解释：输入已经排序，因此不需要翻转任何内容。
请注意，其他可能的答案，如 [3，3] ，也将被判断为正确。
```

**提示：**
- `1 <= arr.length <= 100`
- `1 <= arr[i] <= arr.length`
- `arr` 中的所有整数互不相同（即，`arr` 是从 `1` 到 `arr.length` 整数的一个排列）

## 解题思路

煎饼排序的核心思想是：每次找到未排序部分的最大值，通过两次翻转将其放到正确位置。

**算法流程：**
1. 对于当前未排序部分 `arr[0...i]`
2. 找到最大值的位置 `max_idx`
3. 第一次翻转：将最大值翻到最前面（翻转 `arr[0...max_idx]`）
4. 第二次翻转：将最大值翻到当前未排序部分的末尾（翻转 `arr[0...i]`）
5. 重复以上过程，直到整个数组排序完成

**示例演示：**
```
arr = [3,2,4,1]

1. 找到最大值 4 在索引 2
   - 翻转 arr[0...2]：[4,2,3,1]
   - 翻转 arr[0...3]：[1,3,2,4]
   
2. 找到次大值 3 在索引 1
   - 翻转 arr[0...1]：[3,1,2,4]
   - 翻转 arr[0...2]：[2,1,3,4]
   
3. 找到次次大值 2 在索引 0
   - 已在正确位置，翻转 arr[0...1]：[1,2,3,4]
```

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        result = []
        n = len(arr)
        
        # 从大到小排序
        for target in range(n, 0, -1):
            # 找到当前目标值的位置
            max_idx = arr.index(target)
            
            # 如果已经在正确位置，跳过
            if max_idx == target - 1:
                continue
            
            # 如果不在第一位，先翻到第一位
            if max_idx != 0:
                result.append(max_idx + 1)
                arr[:max_idx + 1] = arr[:max_idx + 1][::-1]
            
            # 翻转到目标位置
            result.append(target)
            arr[:target] = arr[:target][::-1]
        
        return result
```

### 方法二：原地翻转

```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        def flip(arr, k):
            """翻转 arr[0...k-1]"""
            left, right = 0, k - 1
            while left < right:
                arr[left], arr[right] = arr[right], arr[left]
                left += 1
                right -= 1
        
        result = []
        n = len(arr)
        
        for size in range(n, 1, -1):
            # 找到当前未排序部分的最大值索引
            max_idx = 0
            for i in range(size):
                if arr[i] > arr[max_idx]:
                    max_idx = i
            
            # 如果最大值已在正确位置，跳过
            if max_idx == size - 1:
                continue
            
            # 第一次翻转：将最大值翻到最前面
            if max_idx > 0:
                flip(arr, max_idx + 1)
                result.append(max_idx + 1)
            
            # 第二次翻转：将最大值翻到末尾
            flip(arr, size)
            result.append(size)
        
        return result
```

### 方法三：使用辅助函数

```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        def find_max(arr, n):
            """找到前 n 个元素中最大值的索引"""
            max_idx = 0
            for i in range(n):
                if arr[i] > arr[max_idx]:
                    max_idx = i
            return max_idx
        
        def reverse(arr, k):
            """反转前 k 个元素"""
            arr[:k] = reversed(arr[:k])
        
        result = []
        n = len(arr)
        
        for curr_size in range(n, 1, -1):
            # 找到当前范围内的最大值
            max_idx = find_max(arr, curr_size)
            
            # 如果最大值不在末尾
            if max_idx != curr_size - 1:
                # 如果最大值不在开头，先翻到开头
                if max_idx != 0:
                    reverse(arr, max_idx + 1)
                    result.append(max_idx + 1)
                
                # 再翻到末尾
                reverse(arr, curr_size)
                result.append(curr_size)
        
        return result
```

### 方法四：递归版本

```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        def sort_helper(arr, n):
            """递归排序前 n 个元素"""
            if n <= 1:
                return []
            
            # 找到前 n 个元素中的最大值索引
            max_idx = arr.index(max(arr[:n]))
            
            result = []
            
            # 如果最大值不在第一位，翻到第一位
            if max_idx != 0:
                arr[:max_idx + 1] = arr[:max_idx + 1][::-1]
                result.append(max_idx + 1)
            
            # 翻转前 n 个元素，将最大值放到第 n 位
            if n > 1:
                arr[:n] = arr[:n][::-1]
                result.append(n)
            
            # 递归处理前 n-1 个元素
            return result + sort_helper(arr, n - 1)
        
        return sort_helper(arr, len(arr))
```

### 方法五：简洁版

```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        res = []
        for target in range(len(arr), 1, -1):
            idx = arr.index(target)
            if idx != target - 1:
                if idx != 0:
                    res.append(idx + 1)
                    arr[:idx + 1] = arr[:idx + 1][::-1]
                res.append(target)
                arr[:target] = arr[:target][::-1]
        return res
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n²)
  - 外层循环 n 次
  - 每次查找最大值 O(n)
  - 翻转操作 O(n)
- **空间复杂度**：O(1) 或 O(n)
  - 不考虑返回结果：O(1)
  - 考虑返回结果：O(n)

## 关键点总结

1. **贪心策略**：每次将未排序部分的最大值移到正确位置
2. **两次翻转**：先翻到首位，再翻到目标位置
3. **倒序处理**：从最大值开始，逐个处理到最小值
4. **边界优化**：如果元素已在正确位置，跳过
5. **Python 切片**：使用 `arr[:k][::-1]` 简洁实现翻转

## 易错点

1. **索引转换**：k 值是长度（1-based），索引是 0-based
2. **判断跳过**：最大值已在正确位置时可以跳过
3. **翻转范围**：注意是 `arr[0...k-1]`，不是 `arr[0...k]`
4. **结果记录**：记录的是 k 值，不是索引
5. **边界情况**：数组已排序时返回空列表
