## 题目描述

给定一个二叉树的根节点 `root`，以及两个整数 `val` 和 `depth`，在给定的深度 `depth` 处添加一行值为 `val` 的节点。

注意，根节点 `root` 位于深度 1。

加法规则如下：
- 给定一个深度值 `depth`（大于等于 1），针对深度为 `depth - 1` 的每个非空节点 `N`，创建两个值为 `val` 的新节点作为 `N` 的左子树根和右子树根。
- `N` 原来的左子树应该作为新左子树根的左子树。
- `N` 原来的右子树应该作为新右子树根的右子树。
- 如果 `depth = 1`，创建一个新的根节点，原来的整棵树作为新根节点的左子树。

**示例 1：**

```
输入：root = [4,2,6,3,1,5], val = 1, depth = 2
输出：[4,1,1,2,6,3,1,5]
解释：
原树：     4
         /   \
        2     6
       / \   /
      3   1 5

新树：     4
         /   \
        1     1
       /       \
      2         6
     / \       /
    3   1     5
```

**示例 2：**

```
输入：root = [4,2,null,3,1], val = 1, depth = 3
输出：[4,2,null,1,1,3,null,null,1]
```

**提示：**
- 节点数在 `[1, 10^4]` 范围内
- 树的深度在 `[1, 10^4]` 范围内
- `-100 <= Node.val <= 100`
- `-10^5 <= val <= 10^5`
- `1 <= depth <= 树的深度 + 1`

## 解题思路

这道题的核心是在指定深度插入一行新节点。需要分两种情况处理：

1. **depth = 1**：需要创建新的根节点，原树作为新根的左子树
2. **depth > 1**：找到深度为 `depth - 1` 的所有节点，在它们的下方插入新节点

可以使用 DFS（深度优先搜索）或 BFS（广度优先搜索）来遍历到目标深度：
- **DFS**：递归地向下遍历，记录当前深度
- **BFS**：层序遍历，逐层处理直到目标深度

关键观察：
- 需要在深度 `depth - 1` 的节点处进行操作
- 对每个目标节点，创建两个新节点分别作为其新的左右孩子
- 原来的左右孩子要挂到新节点下面

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def addOneRow(self, root: Optional[TreeNode], val: int, depth: int) -> Optional[TreeNode]:
        """
        在二叉树的指定深度添加一行节点
        
        参数:
            root: 二叉树的根节点
            val: 新节点的值
            depth: 要插入的深度
        
        返回:
            新树的根节点
        """
        # 特殊情况：在根节点上方插入
        if depth == 1:
            new_root = TreeNode(val)
            new_root.left = root
            return new_root
        
        # 使用 DFS 找到 depth - 1 层的所有节点
        def dfs(node: Optional[TreeNode], current_depth: int) -> None:
            if not node:
                return
            
            # 到达目标深度的上一层
            if current_depth == depth - 1:
                # 保存原来的左右孩子
                old_left = node.left
                old_right = node.right
                
                # 创建新的左右节点
                node.left = TreeNode(val)
                node.right = TreeNode(val)
                
                # 将原来的孩子挂到新节点下
                node.left.left = old_left
                node.right.right = old_right
                return
            
            # 继续向下递归
            dfs(node.left, current_depth + 1)
            dfs(node.right, current_depth + 1)
        
        dfs(root, 1)
        return root
```

**时间复杂度：** O(n)，最坏情况下需要遍历所有节点  
**空间复杂度：** O(h)，递归栈的深度，h 是树的高度

### 方法二：BFS 层序遍历

```python
from collections import deque
from typing import Optional

class Solution:
    def addOneRow(self, root: Optional[TreeNode], val: int, depth: int) -> Optional[TreeNode]:
        """使用 BFS 层序遍历实现"""
        # 特殊情况：在根节点上方插入
        if depth == 1:
            new_root = TreeNode(val)
            new_root.left = root
            return new_root
        
        # BFS 遍历到 depth - 1 层
        queue = deque([root])
        current_depth = 1
        
        while queue:
            # 如果到达目标深度的上一层
            if current_depth == depth - 1:
                # 处理该层的所有节点
                for _ in range(len(queue)):
                    node = queue.popleft()
                    
                    # 保存原来的左右孩子
                    old_left = node.left
                    old_right = node.right
                    
                    # 创建新节点并插入
                    node.left = TreeNode(val)
                    node.right = TreeNode(val)
                    node.left.left = old_left
                    node.right.right = old_right
                break
            
            # 继续遍历下一层
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            current_depth += 1
        
        return root
```

**时间复杂度：** O(n)，最坏情况下需要遍历到目标深度的所有节点  
**空间复杂度：** O(w)，w 是树的最大宽度（队列的最大长度）

### 方法三：简化的 DFS

```python
class Solution:
    def addOneRow(self, root: Optional[TreeNode], val: int, depth: int) -> Optional[TreeNode]:
        """简化版 DFS，代码更简洁"""
        if depth == 1:
            return TreeNode(val, left=root)
        
        def insert(node: Optional[TreeNode], d: int) -> None:
            if not node:
                return
            
            if d == 1:
                # 同时创建左右新节点
                node.left = TreeNode(val, left=node.left)
                node.right = TreeNode(val, right=node.right)
            else:
                # 递归处理左右子树
                insert(node.left, d - 1)
                insert(node.right, d - 1)
        
        insert(root, depth - 1)
        return root
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，n 是节点总数，最坏情况需要遍历到倒数第二层
- 空间复杂度：
  - DFS：O(h)，h 是树的高度，递归栈空间
  - BFS：O(w)，w 是树的最大宽度，队列空间

以示例 1 为例：`root = [4,2,6,3,1,5], val = 1, depth = 2`

```

  深度 1:       4
               / \
  深度 2:     2   6
             / \ /
  深度 3:   3  1 5

步骤 2：在深度 2 插入新节点
- 找到深度 1 的节点：4
- 4 的原左孩子是 2，原右孩子是 6

           / \     /
  深度 4: 3   1   5
```

## 关键点总结

1. **特殊处理 depth = 1**：需要创建新根节点，原树作为左子树
2. **目标是 depth - 1 层**：在父节点层进行操作，而不是在插入层
3. **保存原孩子节点**：插入前要先保存原来的左右孩子引用
4. **DFS vs BFS**：DFS 代码更简洁，BFS 更直观（层序遍历）
5. **节点创建时机**：可以在创建时直接指定孩子节点（简化代码）

## 易错点

1. **深度理解错误**：题目中根节点深度为 1，不是 0
2. **忘记处理 depth = 1**：这是特殊情况，需要单独处理
3. **孩子节点丢失**：插入新节点前没有保存原来的左右孩子
4. **递归终止条件**：应该在 `depth - 1` 层停止，而不是 `depth` 层
5. **空节点判断**：递归或遍历时要判断节点是否为 null
