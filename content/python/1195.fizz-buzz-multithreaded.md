## 题目描述

你有一个类：

```python
class FizzBuzz {
    public FizzBuzz(int n) { ... }   // 构造函数
    public void fizz(printFizz) { ... }  // 仅打印 "fizz"
    public void buzz(printBuzz) { ... }  // 仅打印 "buzz"
    public void fizzbuzz(printFizzBuzz) { ... }  // 仅打印 "fizzbuzz"
    public void number(printNumber) { ... }  // 仅打印数字
}
```

请你实现一个有四个线程的多线程版 FizzBuzz，同一个 `FizzBuzz` 实例会被如下四个线程使用：

- 线程 A 将调用 `fizz()` 来判断是否能被 3 整除，如果可以，则输出 "fizz"。
- 线程 B 将调用 `buzz()` 来判断是否能被 5 整除，如果可以，则输出 "buzz"。
- 线程 C 将调用 `fizzbuzz()` 来判断是否能同时被 3 和 5 整除，如果可以，则输出 "fizzbuzz"。
- 线程 D 将调用 `number()` 来打印数字。

请你实现 `FizzBuzz` 类来使四个线程能够正确地协作，按照正确的顺序输出结果。

**示例：**
```
输入：n = 15
输出：[1,2,"fizz",4,"buzz","fizz",7,8,"fizz","buzz",11,"fizz",13,14,"fizzbuzz"]
```

**提示：**
- 本题已经提供了打印字符串的相关方法，如 `printFizz()` 等，具体方法名请以实际情况为准。

## 解题思路

这是一个经典的多线程同步问题，需要确保四个线程按照正确的顺序执行。

**核心思路：**

1. **线程同步**：使用锁和条件变量确保线程按顺序执行。

2. **状态控制**：维护一个计数器，记录当前应该处理的数字。

3. **条件判断**：
   - 能被 15 整除：打印 "fizzbuzz"
   - 能被 3 整除但不能被 5 整除：打印 "fizz"
   - 能被 5 整除但不能被 3 整除：打印 "buzz"
   - 其他情况：打印数字

4. **等待与唤醒**：
   - 每个线程检查当前数字是否符合自己的条件
   - 如果不符合，等待
   - 如果符合，执行打印并唤醒其他线程

## Python 代码实现

### 方法一：使用 Condition（推荐）⭐

```python
from threading import Lock, Condition

class FizzBuzz:
    def __init__(self, n: int):
        self.n = n
        self.current = 1  # 当前数字
        self.lock = Lock()
        self.condition = Condition(self.lock)

    def fizz(self, printFizz):
        """
        打印 "fizz"：能被 3 整除但不能被 5 整除
        """
        while True:
            with self.condition:
                # 等待直到当前数字符合条件或超出范围
                while self.current <= self.n and not (
                    self.current % 3 == 0 and self.current % 5 != 0
                ):
                    self.condition.wait()
                
                # 检查是否结束
                if self.current > self.n:
                    return
                
                # 打印 "fizz"
                printFizz()
                self.current += 1
                
                # 唤醒其他等待的线程
                self.condition.notify_all()

    def buzz(self, printBuzz):
        """
        打印 "buzz"：能被 5 整除但不能被 3 整除
        """
        while True:
            with self.condition:
                while self.current <= self.n and not (
                    self.current % 5 == 0 and self.current % 3 != 0
                ):
                    self.condition.wait()
                
                if self.current > self.n:
                    return
                
                printBuzz()
                self.current += 1
                self.condition.notify_all()

    def fizzbuzz(self, printFizzBuzz):
        """
        打印 "fizzbuzz"：能同时被 3 和 5 整除
        """
        while True:
            with self.condition:
                while self.current <= self.n and not (
                    self.current % 15 == 0
                ):
                    self.condition.wait()
                
                if self.current > self.n:
                    return
                
                printFizzBuzz()
                self.current += 1
                self.condition.notify_all()

    def number(self, printNumber):
        """
        打印数字：不能被 3 或 5 整除
        """
        while True:
            with self.condition:
                while self.current <= self.n and (
                    self.current % 3 == 0 or self.current % 5 == 0
                ):
                    self.condition.wait()
                
                if self.current > self.n:
                    # 唤醒所有线程使它们都能退出
                    self.condition.notify_all()
                    return
                
                printNumber(self.current)
                self.current += 1
                self.condition.notify_all()
```

### 方法二：使用信号量

```python
from threading import Semaphore

class FizzBuzz:
    def __init__(self, n: int):
        self.n = n
        self.current = 1
        # 使用信号量控制每个线程的执行
        self.fizz_sem = Semaphore(0)
        self.buzz_sem = Semaphore(0)
        self.fizzbuzz_sem = Semaphore(0)
        self.number_sem = Semaphore(1)  # number 先执行

    def fizz(self, printFizz):
        for i in range(1, self.n + 1):
            if i % 3 == 0 and i % 5 != 0:
                self.fizz_sem.acquire()
                printFizz()
                self._release_next(i + 1)

    def buzz(self, printBuzz):
        for i in range(1, self.n + 1):
            if i % 5 == 0 and i % 3 != 0:
                self.buzz_sem.acquire()
                printBuzz()
                self._release_next(i + 1)

    def fizzbuzz(self, printFizzBuzz):
        for i in range(1, self.n + 1):
            if i % 15 == 0:
                self.fizzbuzz_sem.acquire()
                printFizzBuzz()
                self._release_next(i + 1)

    def number(self, printNumber):
        for i in range(1, self.n + 1):
            if i % 3 != 0 and i % 5 != 0:
                self.number_sem.acquire()
                printNumber(i)
                self._release_next(i + 1)

    def _release_next(self, num):
        """
        根据下一个数字释放对应的信号量
        """
        if num > self.n:
            # 释放所有信号量，确保所有线程都能退出
            self.fizz_sem.release()
            self.buzz_sem.release()
            self.fizzbuzz_sem.release()
            self.number_sem.release()
        elif num % 15 == 0:
            self.fizzbuzz_sem.release()
        elif num % 3 == 0:
            self.fizz_sem.release()
        elif num % 5 == 0:
            self.buzz_sem.release()
        else:
            self.number_sem.release()
```

### 方法三：使用事件（Event）

```python
from threading import Event, Lock

class FizzBuzz:
    def __init__(self, n: int):
        self.n = n
        self.current = 1
        self.lock = Lock()
        self.event = Event()
        self.event.set()  # 初始状态为可运行

    def fizz(self, printFizz):
        while True:
            self.event.wait()
            with self.lock:
                if self.current > self.n:
                    return
                if self.current % 3 == 0 and self.current % 5 != 0:
                    printFizz()
                    self.current += 1

    def buzz(self, printBuzz):
        while True:
            self.event.wait()
            with self.lock:
                if self.current > self.n:
                    return
                if self.current % 5 == 0 and self.current % 3 != 0:
                    printBuzz()
                    self.current += 1

    def fizzbuzz(self, printFizzBuzz):
        while True:
            self.event.wait()
            with self.lock:
                if self.current > self.n:
                    return
                if self.current % 15 == 0:
                    printFizzBuzz()
                    self.current += 1

    def number(self, printNumber):
        while True:
            self.event.wait()
            with self.lock:
                if self.current > self.n:
                    return
                if self.current % 3 != 0 and self.current % 5 != 0:
                    printNumber(self.current)
                    self.current += 1
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，每个数字只被处理一次
- **空间复杂度**：O(1)，只使用了常数个同步原语

## 关键点总结

1. **条件变量的使用**：`Condition` 允许线程等待特定条件并被唤醒
2. **while 循环检查**：使用 `while` 而非 `if` 检查条件，防止虚假唤醒
3. **notify_all 的必要性**：因为有多个线程等待，需要唤醒所有线程
4. **退出机制**：当 `current > n` 时，所有线程都应该退出
5. **判断顺序**：先判断能否被 15 整除，再判断 3 或 5

## 易错点

1. **使用 if 代替 while**：必须用 `while` 循环检查条件
2. **忘记唤醒其他线程**：每次处理完要 `notify_all()`
3. **退出条件错误**：所有线程都需要检查 `current > n`
4. **死锁问题**：确保每个线程最终都能被唤醒和退出
5. **判断顺序错误**：必须先判断 15，否则会被 3 或 5 的条件误判
