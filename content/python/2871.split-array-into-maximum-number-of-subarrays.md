## 题目描述

给你一个整数数组 `nums`，将 `nums` 分割为尽可能多的**非空子数组**，使得每个子数组中所有元素的**按位与（AND）**等于零。

如果无法，则最多分割为 1 个子数组（整个数组）。

返回最多能分割的子数组数。

**示例 1：**
```
输入：nums = [1,0,2,0,1,2]
输出：3
解释：[1,0], [2,0], [1,2] 每段 AND 为 0
```

**示例 2：**
```
输入：nums = [5,7,1,3]
输出：1
解释：整个数组 AND = 5&7&1&3 = 1 ≠ 0，无法分割为多个全 AND=0 的子数组
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`

## 解题思路

**贪心：** 从左到右扫描，维护当前子数组的 AND 值。当 AND 值变为 0 时，分割，重置 AND。

**关键性质：** AND 具有单调性，随着元素增加，AND 值只会减小（位只会被清零，不会增加）。

**贪心正确性：** 尽早分割（AND 变为 0 就立刻分割）可以最大化后续子数组数量。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxSubarrays(self, nums: List[int]) -> int:
        cur_and = ~0  # 初始为全 1（所有位为 1）
        count = 0

        for x in nums:
            cur_and &= x
            if cur_and == 0:
                count += 1
                cur_and = ~0  # 重置

        return max(count, 1)  # 至少返回 1
```

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def maxSubarrays(self, nums: List[int]) -> int:
        cur_and = (1 << 20) - 1  # 足够大的全 1（nums[i] <= 10^6 < 2^20）
        count = 0

        for x in nums:
            cur_and &= x
            if cur_and == 0:
                count += 1
                cur_and = (1 << 20) - 1  # 重置为全 1

        # 如果 count = 0，说明整个数组的 AND ≠ 0，只能 1 个子数组
        return max(count, 1)
```

## 复杂度分析

- 时间复杂度：O(n)，线性扫描
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：AND 变为 0 就立刻分割
2. 整数初始化为全 1（`~0` 或 `(1 << 20) - 1`）
3. `max(count, 1)` 处理无法分割的情况

## 易错点

1. 初始化 `cur_and` 为全 1（不是 0），否则第一个数 AND 后永远是 0
2. `~0` 在 Python 中是 -1（全 1 的补码），`-1 & x = x` 正确
3. 分割后必须重置 `cur_and`
