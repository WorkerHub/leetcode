## 题目描述

给你一个整数 `n`，你需要重复执行以下操作将其转换为 `0`：
1. 将 `n` 的最右侧非零位改为 `0`
2. 如果 `n` 最右侧非零位的右边还有位，将 `n` 的**倒数第二个**非零位改为 `1`

返回将 `n` 变为 `0` 的**最小操作数**。

**示例：**
```
输入：n = 6    (110)
输出：4
```

**提示：**
- `0 <= n <= 10^9`

## 解题思路

这道题的本质是**格雷码**的逆变换。格雷码与二进制的关系：
- 格雷码 -> 二进制：`g[i] = b[i]`（最高位相同），`b[i-1] = b[i] XOR g[i-1]`
- 二进制 -> 格雷码：`g[i] = b[i] XOR b[i+1]`

对于 `n = 2^k`（只有第 k 位为 1），将其变为 0 需要 `2^(k+1) - 1` 步。

**递推公式：**
- `f(0) = 0`
- `f(n) = f(n 去掉最高位) + 2^(最高位) ^ f(去掉最高位后的值) + ...`

实际上，`f(n)` 就是 n 的格雷码对应的十进制值。

## 代码实现

### 方法一：格雷码逆变换（推荐）

```python
class Solution:
    def minimumOneBitOperations(self, n: int) -> int:
        # 格雷码 g 对应的二进制值就是所需步数
        # 将 n（格雷码）转换为二进制整数
        result = 0
        while n:
            result ^= n
            n >>= 1
        return result
```

### 方法二：递归 + 记忆化

```python
from functools import lru_cache

class Solution:
    def minimumOneBitOperations(self, n: int) -> int:
        @lru_cache(maxsize=None)
        def dp(x: int) -> int:
            if x == 0:
                return 0
            # 找到最高位的位置 k
            k = x.bit_length() - 1
            # 将 x 最高位清除
            rest = x ^ (1 << k)
            # 步骤：
            # 1. 将 rest 变为 0（dp(rest) 步）
            # 2. 将 2^k 变为 0（2^k 步）
            # 3. 将新 rest（即 2^(k-1)）变为 0（dp(2^(k-1)) 步，但 rest=0 时...）
            # 实际：f(2^k | rest) = 2^(k+1) - 1 - dp(rest)
            return (1 << (k + 1)) - 1 - dp(rest)
        
        return dp(n)
```

### 方法三：迭代（位运算）

```python
class Solution:
    def minimumOneBitOperations(self, n: int) -> int:
        # 与方法一等价，逐位处理
        ans = 0
        mask = 1
        while mask <= n:
            if n & mask:
                ans ^= mask
            mask <<= 1
        # 等价写法
        result = 0
        cur = n
        while cur:
            result ^= cur
            cur >>= 1
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 格雷码转换 | O(log n) | O(1) |
| 记忆化递归 | O(log n) | O(log n) |

## 关键点总结

1. 本题本质是格雷码逆变换：将格雷码 `n` 转换为对应的自然数
2. 格雷码 -> 自然数的公式：累积 XOR，即 `result = n XOR (n>>1) XOR (n>>2) XOR ...`
3. 对于 `2^k`：转换为 0 需要 `2^(k+1) - 1` 步
4. 递归公式：`f(2^k | rest) = 2^(k+1) - 1 - f(rest)`

## 易错点

- 不要试图模拟操作，步骤数会指数级增长（n 可达 10^9）
- 记忆化递归中，`rest = x ^ (1 << k)` 去掉最高位
- 格雷码转换中累积 XOR 时，要不断右移 n 直到为 0
