## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，找到最长的连续子序列，使得相邻元素之差恰好为 `k`（可以是 `+k` 或 `-k`）。

返回这样的最长子序列的长度。

**示例 1：**

```
输入：nums = [1, 2, 3, 4], k = 1
输出：4
解释：整个数组 [1,2,3,4] 相邻差为 1，长度 4。
```

**示例 2：**

```
输入：nums = [1, 3, 5, 3, 1], k = 2
输出：3
解释：子序列 [1, 3, 5] 或 [5, 3, 1] 长度为 3。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

哈希表 DP：
- `dp[v]` = 以值 v 结尾的满足条件子序列的最大长度。
- 对每个 `nums[i] = v`，`dp[v] = max(dp[v-k], dp[v+k]) + 1`（可以从 v-k 或 v+k 转移）。
- 注意：这里是子序列（可以不连续），按位置从左到右处理。

## Python 代码实现

### 方法一：哈希表 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumConsecutive(self, nums: List[int], k: int) -> int:
        # dp[v] = 以值 v 结尾的满足相邻差为 k 的最长子序列长度
        dp = defaultdict(int)
        ans = 1

        for v in nums:
            # 可以接在 v-k 或 v+k 之后
            dp[v] = max(dp[v - k], dp[v + k]) + 1
            ans = max(ans, dp[v])

        return ans
```

### 方法二：枚举起点（小数组）

```python
from typing import List

class Solution:
    def maximumConsecutive(self, nums: List[int], k: int) -> int:
        val_set = set(nums)
        ans = 1

        for start in val_set:
            # 向上延伸
            length = 1
            curr = start + k
            while curr in val_set:
                length += 1
                curr += k
            ans = max(ans, length)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n * max_chain_length)（方法二）
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 哈希表 DP 按元素值记录状态，从 `v-k` 或 `v+k` 转移。
2. 相邻差允许 +k 或 -k，因此两个方向都要考虑。
3. 按位置从左到右处理，保证子序列的顺序性。

## 易错点

1. 差值可以是 +k 或 -k（双向），不仅仅是 +k。
2. `defaultdict(int)` 自动返回 0，查询不存在的键安全。
3. 初始答案设为 1（单个元素构成长度为 1 的子序列）。
