## 题目描述

作为一位web开发者， 懂得怎样去规划一个页面的尺寸是很重要的。 所以，现给定一个具体的矩形页面面积，你的任务是设计一个长度为 L 和宽度为 W 且满足以下要求的矩形的页面。

要求：
1. 矩形页面必须满足 L * W = area
2. 长度 L 和宽度 W 的差距应当尽可能小
3. L >= W

返回数组 [L, W]，其中 L 和 W 是你按照顺序设计的网页的长度和宽度。

**示例 1：**
```
输入：area = 4
输出：[2,2]
解释：目标面积是 4，所有可能的构造方案有 [1,4], [2,2], [4,1]。
但是根据要求2，[1,4] 不符合要求；根据要求3，[4,1] 不符合要求。所以返回长度为 2，宽度为 2 的矩形 [2,2]。
```

**示例 2：**
```
输入：area = 37
输出：[37,1]
```

**示例 3：**
```
输入：area = 122122
输出：[427,286]
```

**提示：**
- 1 <= area <= 10^7

## 解题思路

这道题本质是找两个因数，使得它们的乘积等于给定面积，且差距最小。

### 核心思想

1. **因数配对**：
   - 对于面积 area，找到两个因数 L 和 W
   - 满足 L * W = area 且 L >= W

2. **最小差距**：
   - 要使 L - W 最小，L 和 W 应该尽可能接近
   - 最接近的情况是两者都接近 √area

3. **搜索策略**：
   - 从 √area 开始向下搜索
   - 找到第一个能整除 area 的数作为 W
   - L = area / W

4. **优化**：
   - 只需要搜索到 √area
   - 因为如果 i 是因数，area/i 也是因数
   - 从大到小搜索 W，保证找到的第一个就是最接近 √area 的

## Python 代码实现

### 方法一：从 √area 向下搜索（推荐）

```python
from typing import List
import math

class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        """
        从 √area 向下搜索第一个因数
        
        时间复杂度：O(√area)
        空间复杂度：O(1)
        """
        # 从 √area 开始向下搜索
        w = int(math.sqrt(area))
        
        # 找到第一个能整除 area 的 w
        while area % w != 0:
            w -= 1
        
        l = area // w
        
        return [l, w]
```

### 方法二：枚举所有因数

```python
class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        """
        枚举所有因数对
        
        时间复杂度：O(√area)
        空间复杂度：O(1)
        """
        min_diff = float('inf')
        result = [area, 1]
        
        # 只需要枚举到 √area
        for w in range(1, int(area ** 0.5) + 1):
            if area % w == 0:
                l = area // w
                # 计算差距
                diff = l - w
                if diff < min_diff:
                    min_diff = diff
                    result = [l, w]
        
        return result
```

### 方法三：数学优化

```python
class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        """
        直接从 √area 找最接近的因数
        
        时间复杂度：O(√area)
        空间复杂度：O(1)
        """
        # 宽度从 √area 开始递减
        width = int(area ** 0.5)
        
        # 找到第一个因数
        while area % width:
            width -= 1
        
        return [area // width, width]
```

### 方法四：简洁版

```python
class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        """
        最简洁的实现
        
        时间复杂度：O(√area)
        空间复杂度：O(1)
        """
        w = int(area ** 0.5)
        while area % w:
            w -= 1
        return [area // w, w]
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(√area)
  - 最坏情况下从 √area 搜索到 1
  - 例如 area = 素数时

- **空间复杂度**：O(1)
  - 只使用常数额外空间

## 关键点总结

1. **数学观察**：最接近的因数对在 √area 附近
2. **搜索方向**：从 √area 向下搜索更快
3. **整除判断**：使用模运算判断是否为因数
4. **边界情况**：质数的因数对是 (area, 1)
5. **优化**：只搜索到 √area，不需要遍历所有数

## 易错点

1. **浮点数精度**
   - int(math.sqrt(area)) 可能有精度问题
   - 但对本题影响不大，因为向下搜索会找到正确答案

2. **搜索范围**
   - 不需要从 area 开始搜索
   - 从 √area 开始即可

3. **L 和 W 的顺序**
   - 返回 [L, W]，L >= W
   - 不要返回 [W, L]

4. **特殊情况**
   - area = 1 时，返回 [1, 1]
   - area 为质数时，返回 [area, 1]

5. **整除检查**
   - 使用 % 判断，不是 /
   - area % w == 0 表示 w 是因数

## 学习建议

1. **数学思维**：
   - 理解因数的性质
   - 如果 a * b = n，且 a <= b，则 a <= √n
   - 利用对称性优化搜索

2. **优化搜索范围**：
   - 不是所有问题都需要遍历全部
   - 观察数学性质减小范围

3. **边界情况**：
   - 完全平方数：L = W = √area
   - 质数：L = area, W = 1
   - 一般情况：找最接近的因数对

4. **代码简洁性**：
   - 理解问题本质后代码可以很简洁
   - 方法四只需 3 行

5. **测试用例**：
   - 完全平方数：4, 9, 16
   - 质数：2, 3, 5, 7, 11
   - 一般情况：6, 12, 15
   - 大数：10^7

6. **性能考虑**：
   - 对于大数，O(√n) 比 O(n) 快得多
   - √10^7 ≈ 3162，而不是 10000000
