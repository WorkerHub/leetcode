## 题目描述

给你一个整数数组 `cardPoints`（牌堆）和一个整数 `k`，每次你可以从牌堆的最左端或最右端取一张牌。恰好取 `k` 张牌，返回所取牌的最大总分。

**示例 1：**

```
输入：cardPoints = [1, 2, 3, 4, 5, 6, 1], k = 3
输出：12
解释：从右端取 3 张：[6, 5, 4]... 不对，取 6+5+4=15? 或取 1+6+5=12。
最优：取右端 6, 5, 1 = 12，或左端 1, 2, 3 = 6，或 1(左) + 6, 5(右) = 12。
```

**示例 2：**

```
输入：cardPoints = [2, 2, 2], k = 2
输出：4
```

**提示：**
- `1 <= cardPoints.length <= 10^5`
- `1 <= cardPoints[i] <= 10^4`
- `1 <= k <= cardPoints.length`

## 解题思路

取 k 张牌后，剩余 `n - k` 张牌是连续的中间段。

等价于：在长度为 `n - k` 的连续子数组中，使其和最小，则取的 k 张牌和最大（总和 - 最小中间段和）。

## Python 代码实现

### 方法一：滑动窗口求最小中间段（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)
        window_size = n - k  # 中间剩余的牌数

        if window_size == 0:
            return sum(cardPoints)

        # 找长度为 window_size 的子数组的最小和
        window_sum = sum(cardPoints[:window_size])
        min_window = window_sum

        for i in range(window_size, n):
            window_sum += cardPoints[i] - cardPoints[i - window_size]
            min_window = min(min_window, window_sum)

        return sum(cardPoints) - min_window
```

### 方法二：前缀和 + 枚举

```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)
        total = sum(cardPoints)

        if k == n:
            return total

        # 枚举从左取 i 张，从右取 k-i 张（i in [0, k]）
        # 左取 i 张的和：prefix[i]
        # 右取 k-i 张的和：suffix[k-i]

        prefix = [0] * (k + 1)
        for i in range(k):
            prefix[i + 1] = prefix[i] + cardPoints[i]

        suffix = [0] * (k + 1)
        for i in range(k):
            suffix[i + 1] = suffix[i] + cardPoints[n - 1 - i]

        best = 0
        for i in range(k + 1):
            best = max(best, prefix[i] + suffix[k - i])

        return best
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一）；O(k)（方法二）

## 关键点总结

1. 核心转化：取 k 张 = 总和 - 中间不取的 n-k 张的最小和。
2. 固定大小 `n-k` 的滑动窗口求最小和。
3. 方法二枚举所有分配方式（左取 i 张 + 右取 k-i 张）。

## 易错点

1. `window_size = n - k`，若 k = n 则 window_size = 0，直接返回总和。
2. 方法一的初始窗口 = 前 window_size 个元素。
