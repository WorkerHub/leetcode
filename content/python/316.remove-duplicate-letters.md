## 题目描述

给你一个字符串 `s` ，请你去除字符串中重复的字母，使得每个字母只出现一次。需保证**返回结果的字典序最小**（要求不能打乱其他字符的相对位置）。

**示例 1：**
```
输入：s = "bcabc"
输出："abc"
```

**示例 2：**
```
输入：s = "cbacdcbc"
输出："acdb"
```

**提示：**
- `1 <= s.length <= 10^4`
- `s` 由小写英文字母组成

## 解题思路

这道题需要满足三个条件：
1. **去重**：每个字符只出现一次
2. **字典序最小**：结果是最小的
3. **保持相对顺序**：不能任意排列

### 核心思想：贪心 + 单调栈

使用单调栈维护结果，关键在于决定何时弹出栈顶元素：
- 当前字符比栈顶小
- 栈顶字符后面还会出现（可以后面再加入）
- 当前字符不在栈中（避免重复）

## Python 代码实现

### 方法一：单调栈 + 贪心（推荐）⭐

```python
class Solution:
    def removeDuplicateLetters(self, s: str) -> str:
        # 统计每个字符的最后出现位置
        last_occurrence = {c: i for i, c in enumerate(s)}
        
        # 单调栈
        stack = []
        # 记录栈中已有的字符
        in_stack = set()
        
        for i, char in enumerate(s):
            # 如果字符已在栈中，跳过
            if char in in_stack:
                continue
            
            # 维护单调性：当前字符比栈顶小，且栈顶后面还会出现
            while stack and char < stack[-1] and i < last_occurrence[stack[-1]]:
                removed = stack.pop()
                in_stack.remove(removed)
            
            # 将当前字符入栈
            stack.append(char)
            in_stack.add(char)
        
        return ''.join(stack)
```

### 方法二：使用计数器

```python
from collections import Counter

class Solution:
    def removeDuplicateLetters(self, s: str) -> str:
        # 统计每个字符出现次数
        count = Counter(s)
        stack = []
        in_stack = set()
        
        for char in s:
            # 减少计数
            count[char] -= 1
            
            # 已在栈中，跳过
            if char in in_stack:
                continue
            
            # 弹出条件：栈顶更大 且 后面还有
            while stack and char < stack[-1] and count[stack[-1]] > 0:
                removed = stack.pop()
                in_stack.remove(removed)
            
            stack.append(char)
            in_stack.add(char)
        
        return ''.join(stack)
```

### 方法三：带详细注释的版本

```python
class Solution:
    def removeDuplicateLetters(self, s: str) -> str:
        """
        单调栈 + 贪心
        
        核心思想：
        1. 每个字符只保留一次
        2. 结果字典序最小
        3. 保持相对顺序
        
        策略：
        - 遍历字符串
        - 如果当前字符比栈顶小，且栈顶后面还会出现，就弹出栈顶
        - 直到不满足条件，将当前字符入栈
        """
        # 记录每个字符最后出现的位置
        last_pos = {}
        for i, c in enumerate(s):
            last_pos[c] = i
        
        stack = []  # 结果栈
        used = set()  # 已使用的字符
        
        for i, char in enumerate(s):
            # 1. 如果字符已在结果中，跳过
            if char in used:
                continue
            
            # 2. 维护单调性（贪心）
            # 条件：
            # - 栈不为空
            # - 当前字符 < 栈顶字符（想要更小的字典序）
            # - 栈顶字符后面还会出现（可以后面再加）
            while stack and char < stack[-1] and i < last_pos[stack[-1]]:
                removed = stack.pop()
                used.remove(removed)
            
            # 3. 加入当前字符
            stack.append(char)
            used.add(char)
        
        return ''.join(stack)
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符最多入栈出栈一次
- 空间复杂度：O(1)，字符集大小固定（26 个字母）

## 关键点总结

1. **单调栈**：维护字典序递增
2. **贪心策略**：能弹就弹，让后面的小字符靠前
3. **弹出条件**：
   - 当前字符 < 栈顶
   - 栈顶后面还会出现
   - 当前字符不在栈中
4. **最后出现位置**：判断能否弹出的依据
5. **in_stack 集合**：快速判断字符是否已在结果中

## 易错点

1. **重复处理**：已在栈中的字符要跳过
2. **弹出条件**：三个条件都要满足
3. **计数 vs 最后位置**：
   - 计数：需要每次减 1
   - 最后位置：一次性计算
4. **集合操作**：弹出时要同步更新 in_stack
5. **字符集大小**：固定 26，空间是 O(1)
