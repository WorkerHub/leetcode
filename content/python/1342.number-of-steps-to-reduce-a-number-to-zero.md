## 题目描述

给你一个非负整数 `num`，请你返回将它变成 0 所需要的步数。如果当前数字是偶数，你需要把它除以 2；否则，减去 1。

**示例 1：**
```
输入：num = 14
输出：6
解释：
14 -> 7  （除以2）
7  -> 6  （减去1）
6  -> 3  （除以2）
3  -> 2  （减去1）
2  -> 1  （除以2）
1  -> 0  （减去1）
共 6 步
```

**示例 2：**
```
输入：num = 8
输出：4
解释：8 -> 4 -> 2 -> 1 -> 0，共 4 步
```

**示例 3：**
```
输入：num = 123
输出：12
```

**提示：**
- `0 <= num <= 10^6`

## 解题思路

**方法一：模拟**

按照规则直接模拟，直到 num 变为 0。

**方法二：位运算分析**

将 num 转为二进制，观察规律：
- 偶数（末位为0）：右移一位（去掉末位0），步数+1
- 奇数（末位为1）：减1（末位从1变0），步数+1，但下一步还要除2

本质上：
- 每个二进制位（0 或 1）对应若干步操作
- 最高位是 1：减1变0（1步）即可消除
- 其余每个 1：需要减1（1步）+ 右移（1步）= 2步
- 每个 0（非最高位）：只需右移（1步）= 1步

所以总步数 = 二进制总位数（决定了几次右移）+ 1的个数（每个1都需要额外减1操作）- 1（最高位只需减1，不需要右移）

更简洁：设二进制有 `b` 位，其中有 `k` 个 1，步数 = `(b - 1) + k`

但最简单还是直接模拟，代码更直观。

## Python 代码实现

### 方法一：模拟（推荐新手）

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        steps = 0
        while num > 0:
            if num % 2 == 0:
                num //= 2      # 偶数：除以 2
            else:
                num -= 1       # 奇数：减去 1
            steps += 1
        return steps
```

### 方法二：位运算简化模拟

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        steps = 0
        while num > 0:
            if num & 1:        # 奇数（末位为1）
                num -= 1
            else:              # 偶数（末位为0）
                num >>= 1      # 等价于 num //= 2
            steps += 1
        return steps
```

### 方法三：位运算直接计算（O(1) 思路）

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        if num == 0:
            return 0
        
        # 将 num 转为二进制字符串（去掉前缀 '0b'）
        binary = bin(num)[2:]
        
        # 分析：
        # - 每个二进制位都需要一次右移（除了我们到达 0 之后）
        # - 除了最高位，每个 '1' 还需要一次额外的减1操作
        # 总步数 = 位数 + 1的个数 - 1
        #        = len(binary) - 1 + binary.count('1')
        
        bits = len(binary)      # 总位数
        ones = binary.count('1')  # 1 的个数
        
        return bits - 1 + ones
```

### 方法四：利用 Python 内置（简洁写法）

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        if num == 0:
            return 0
        b = bin(num)[2:]  # 二进制字符串，如 '1110' 表示 14
        # 每个字符对应一步右移（最高位不需要右移，共 len-1 次）
        # 每个 '1' 额外一步减法（共 count('1') 次）
        return len(b) - 1 + b.count('1')
```

### 方法五：递归写法

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        if num == 0:
            return 0
        if num % 2 == 0:
            return 1 + self.numberOfSteps(num // 2)
        else:
            return 1 + self.numberOfSteps(num - 1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/二（模拟） | O(log num) | O(1) |
| 方法三/四（位运算） | O(log num) | O(log num) |
| 方法五（递归） | O(log num) | O(log num) |

## 图解示例

以 `num = 14 = (1110)_2` 为例：

```
二进制: 1 1 1 0
         ^ ^ ^ ^
         |   | +-- 最低位0：右移1步
         |   +---- 中间位1：减1(1步) + 右移(1步)
         +-------- 次高位1：减1(1步) + 右移(1步)
    最高位1：减1(1步)（不需要右移，变为0就结束了）

总步数 = 位数(4) - 1 + 1的个数(3) = 3 + 3 = 6

验证：14 -> 7 -> 6 -> 3 -> 2 -> 1 -> 0，共 6 步 ✓
```

## 关键点总结

1. 模拟是最直观的方法，每步按规则操作直到为 0
2. 位运算方法：二进制中每个 0 对应 1 步（右移），每个 1 对应 2 步（减1+右移），最高位只需 1 步
3. 总步数 = 二进制位数 - 1 + 1的个数（等价公式）
4. `num & 1` 判断奇偶，`num >>= 1` 等价于 `num //= 2`

## 易错点

1. 需要处理 `num = 0` 的特殊情况（while 循环直接不进入，返回 0，方法一自然处理）
2. 位运算方法三/四记得特判 `num == 0`（否则 `bin(0)[2:]` 是 `'0'`，计算错误）
3. 递归方法注意 base case：`num == 0` 返回 0
