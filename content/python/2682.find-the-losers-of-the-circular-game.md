## 题目描述

`n` 个朋友围成一圈编号 1 到 n，游戏开始从第 1 个人出发，第 1 次传球传 `k` 个位置，第 2 次传 `2k` 个位置，第 3 次传 `3k`... 若一个人收到两次球，游戏结束。返回**没有**收到球的人的编号列表（升序）。

**示例 1：**
```
输入：n = 5, k = 2
输出：[4,5]
解释：从1出发，传2位到3，传4位到2，传6%5=1位到3，3已经收过球，游戏结束
收到球：1,3,2，未收到：4,5
```

**示例 2：**
```
输入：n = 4, k = 4
输出：[2,3,4]
```

**数据范围：**
- 1 <= k <= n <= 50

## 解题思路

模拟游戏：记录每次传球落点，直到某人收到第二次球，返回从未收到球的人。

## Python 代码实现

### 方法一：模拟 + 集合（推荐）

```python
from typing import List

class Solution:
    def circularGameLosers(self, n: int, k: int) -> List[int]:
        visited = set()
        current = 1  # 当前位置（1-indexed）
        step = k     # 当前传球距离

        while current not in visited:
            visited.add(current)
            current = (current - 1 + step) % n + 1  # 传球后的新位置
            step += k  # 下一次传球距离 +k

        # 返回未收到球的人
        return sorted(i for i in range(1, n + 1) if i not in visited)
```

### 方法二：数组标记

```python
from typing import List

class Solution:
    def circularGameLosers(self, n: int, k: int) -> List[int]:
        received = [False] * (n + 1)
        pos = 1
        step = k

        while not received[pos]:
            received[pos] = True
            pos = (pos - 1 + step) % n + 1
            step += k

        return [i for i in range(1, n + 1) if not received[i]]
```

## 复杂度分析

- 时间复杂度：O(n)（最多传 n 次）
- 空间复杂度：O(n)

## 关键点总结

1. 游戏在某人收到第二次球时结束
2. 传球距离逐次增加 k（第 i 次传 `i*k`）
3. 循环位置：`(current - 1 + step) % n + 1`

## 易错点

1. 位置用 1-indexed，需要转换为 0-indexed 再取模
2. 每次步长递增 k，不是每次 +1
