## 题目描述

给你两个整数 `m` 和 `n`，表示 `m x n` 的网格，使用 3 种颜色（1, 2, 3）涂色，满足：
- 每个格子恰好涂一种颜色
- 相邻（上下左右）格子颜色不同

返回满足条件的涂色方案数，结果对 `10^9 + 7` 取余。

**示例 1：**
```
输入：m = 1, n = 1
输出：3
```

**示例 2：**
```
输入：m = 1, n = 2
输出：6
```

**示例 3：**
```
输入：m = 5, n = 5
输出：580986
```

**提示：**
- `1 <= m <= 5`，`1 <= n <= 1000`

---

## 解题思路

### 核心思想：列状态压缩 DP

由于 `m <= 5`，每列有 `3^m` 种可能的颜色状态。

1. **枚举合法列状态**：每列相邻格子颜色不同（列内约束）
2. **预计算相邻列兼容性**：两个相邻列的对应位置颜色不同（列间约束）
3. **DP 转移**：`dp[j][state]` = 第 `j` 列状态为 `state` 时的方案数

## 代码实现

### 方法一：列状态压缩 DP（推荐）

```python
class Solution:
    def colorTheGrid(self, m: int, n: int) -> int:
        MOD = 10**9 + 7

        # 生成所有合法列状态（列内相邻颜色不同）
        def is_valid_col(state, m):
            for i in range(m - 1):
                if (state // (3**i)) % 3 == (state // (3**(i+1))) % 3:
                    return False
            return True

        valid_states = [s for s in range(3**m) if is_valid_col(s, m)]

        # 预计算两个列状态是否相邻兼容（对应行颜色不同）
        def compatible(s1, s2, m):
            for i in range(m):
                if (s1 // (3**i)) % 3 == (s2 // (3**i)) % 3:
                    return False
            return True

        compat = {s: [] for s in valid_states}
        for s1 in valid_states:
            for s2 in valid_states:
                if compatible(s1, s2, m):
                    compat[s1].append(s2)

        # DP 初始化：第一列所有合法状态各一种
        dp = {s: 1 for s in valid_states}

        for _ in range(n - 1):
            new_dp = {s: 0 for s in valid_states}
            for s, cnt in dp.items():
                for ns in compat[s]:
                    new_dp[ns] = (new_dp[ns] + cnt) % MOD
            dp = new_dp

        return sum(dp.values()) % MOD
```

### 方法二：矩阵快速幂优化（n 很大时）

```python
class Solution:
    def colorTheGrid(self, m: int, n: int) -> int:
        MOD = 10**9 + 7

        def is_valid(state):
            for i in range(m - 1):
                if (state // (3**i)) % 3 == (state // (3**(i+1))) % 3:
                    return False
            return True

        valid = [s for s in range(3**m) if is_valid(s)]
        k = len(valid)
        idx = {s: i for i, s in enumerate(valid)}

        # 构建转移矩阵
        trans = [[0] * k for _ in range(k)]
        for i, s1 in enumerate(valid):
            for j, s2 in enumerate(valid):
                ok = True
                for r in range(m):
                    if (s1 // (3**r)) % 3 == (s2 // (3**r)) % 3:
                        ok = False
                        break
                if ok:
                    trans[i][j] = 1

        # 矩阵快速幂
        def mat_mul(A, B):
            size = len(A)
            C = [[0]*size for _ in range(size)]
            for i in range(size):
                for l in range(size):
                    if A[i][l] == 0:
                        continue
                    for j in range(size):
                        C[i][j] = (C[i][j] + A[i][l] * B[l][j]) % MOD
            return C

        def mat_pow(M, p):
            size = len(M)
            result = [[int(i==j) for j in range(size)] for i in range(size)]
            while p:
                if p & 1:
                    result = mat_mul(result, M)
                M = mat_mul(M, M)
                p >>= 1
            return result

        T = mat_pow(trans, n)
        return sum(T[i][j] for i in range(k) for j in range(k)) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n * V²) 其中 V = 3^m | O(V) |
| 矩阵快速幂 | O(V³ log n) | O(V²) |

## 关键点总结

1. m ≤ 5，每列最多 3^5=243 种状态，但合法状态更少
2. 预计算列内合法状态和列间兼容性，加速 DP
3. n 较大时矩阵快速幂有优势（本题 n ≤ 1000 时直接 DP 更简单）

---

## 易错点

- 用三进制表示列状态，第 i 行的颜色 = `(state // 3^i) % 3`
- 列间相邻：每行的颜色（对应行）必须不同
