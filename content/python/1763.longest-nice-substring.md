## 题目描述

当一个字符串 `s` 包含的每一种字母的大写和小写形式**同时**出现在 `s` 中，就称这个字符串 `s` 是**美好**字符串。比如，`"abABB"` 是美好字符串，因为 `'A'` 和 `'a'` 同时出现了，且 `'B'` 和 `'b'` 也同时出现了。然而，`"abA"` 不是美好字符串，因为 `'b'` 出现了，而 `'B'` 没有出现。

给你一个字符串 `s`，请你返回 `s` 最长的美好子字符串。如果有多个答案，请你返回**最早**出现的那个。如果不存在美好子字符串，请你返回一个空字符串。

**示例 1：**
```
输入：s = "YazaAay"
输出："aAa"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 由大小写英文字母组成

## 解题思路

**分治法**：找到第一个"不符合条件"的字符（其大小写形式只有一种出现），以该字符为分割点，递归处理左右两部分。

或者暴力枚举所有子字符串，判断是否为美好字符串。

## 代码实现

### 方法一：分治（推荐）

```python
class Solution:
    def longestNiceSubstring(self, s: str) -> str:
        if len(s) < 2:
            return ""
        
        char_set = set(s)
        
        # 找第一个不满足条件的字符（大小写只有一种）
        for i, c in enumerate(s):
            if c.swapcase() not in char_set:
                # 以 i 为分割点，递归左右两部分
                left = self.longestNiceSubstring(s[:i])
                right = self.longestNiceSubstring(s[i + 1:])
                # 返回较长的（长度相同时返回左边，即较早出现的）
                return left if len(left) >= len(right) else right
        
        # 所有字符都满足条件，整个字符串是美好的
        return s
```

### 方法二：暴力枚举

```python
class Solution:
    def longestNiceSubstring(self, s: str) -> str:
        def is_nice(sub: str) -> bool:
            chars = set(sub)
            for c in chars:
                if c.swapcase() not in chars:
                    return False
            return True
        
        n = len(s)
        best = ""
        
        for i in range(n):
            for j in range(i + 2, n + 1):
                sub = s[i:j]
                if is_nice(sub) and len(sub) > len(best):
                    best = sub
        
        return best
```

## 复杂度分析

- **方法一**：时间 O(n^2)（分治），空间 O(n) 递归栈
- **方法二**：时间 O(n^3)，空间 O(n)

## 关键点总结

1. 分治：找到不满足条件的字符，以之为分割点递归
2. 递归基准：长度 < 2 返回空字符串
3. 字符 `c` 满足条件 = `c.swapcase()` 也在字符串中

## 易错点

- 分治中要返回长度相同时更早出现的（即左边），所以用 `>=`
