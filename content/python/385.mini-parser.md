## 题目描述

给定一个字符串 s 表示一个整数嵌套列表，实现一个解析它的语法分析器并返回解析的结果 `NestedInteger`。

列表中的每个元素只可能是整数或整数嵌套列表

**示例 1:**

```
输入：s = "324"
输出：324
解释：你应该返回一个 NestedInteger 对象，其中只包含整数值 324。
```

**示例 2:**

```
输入：s = "[123,[456,[789]]]"
输出：[123,[456,[789]]]
解释：返回一个 NestedInteger 对象包含一个有两个元素的嵌套列表：
1. 一个 integer 包含值 123
2. 一个包含两个元素的嵌套列表：
    i.  一个 integer 包含值 456
    ii. 一个包含一个元素的嵌套列表
         a. 一个 integer 包含值 789
```

**提示:**

- `1 <= s.length <= 5 * 10^4`
- `s` 由数字、方括号 `"[]"`、负号 `'-'`、逗号 `','` 组成
- `s` 是有效的 NestedInteger 表示
- 输入中的所有值的范围是 `[-10^6, 10^6]`

## 解题思路

本题是经典的**嵌套结构解析**问题，可以使用栈或递归来解决。

### 核心思想：栈模拟嵌套结构

**算法流程：**

1. **使用栈保存嵌套层级**：
   - 遇到 `[` 时，创建新的 NestedInteger 并压栈
   - 遇到 `]` 时，弹出栈顶，添加到新的栈顶（上一层）
   - 遇到数字时，解析完整数字并添加到当前层

2. **处理数字**：
   - 可能是多位数
   - 可能是负数
   - 需要在遇到 `,` 或 `]` 时完成解析

3. **边界情况**：
   - 单个整数（没有括号）
   - 空列表 `[]`
   - 负数

### 思路对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 栈 | 直观，易理解 | 需要额外空间 |
| 递归 | 代码简洁 | 理解稍难 |

### 方法一：栈模拟（推荐）⭐

```python
# This is the interface that allows for creating nested lists.
# You should not implement it, or speculate about its implementation
class NestedInteger:
    def __init__(self, value=None):
        """
        If value is not specified, initializes an empty list.
        Otherwise initializes a single integer equal to value.
        """
        pass

    def isInteger(self) -> bool:
        """
        @return True if this NestedInteger holds a single integer, rather than a nested list.
        """
        pass

    def add(self, elem):
        """
        Set this NestedInteger to hold a nested list and adds a nested integer elem to it.
        """
        pass

    def setInteger(self, value: int):
        """
        Set this NestedInteger to hold a single integer equal to value.
        """
        pass

    def getInteger(self) -> int:
        """
        @return the single integer that this NestedInteger holds, if it holds a single integer
        Return None if this NestedInteger holds a nested list
        """
        pass

    def getList(self):
        """
        @return the nested list that this NestedInteger holds, if it holds a nested list
        Return None if this NestedInteger holds a single integer
        """
        pass


class Solution:
    def deserialize(self, s: str) -> NestedInteger:
        """
        使用栈解析嵌套结构
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        # 特殊情况：单个整数
        if s[0] != '[':
            return NestedInteger(int(s))
        
        stack = []
        num_str = ""  # 存储当前正在构建的数字字符串
        
        for i, char in enumerate(s):
            if char == '[':
                # 开始新的嵌套层级
                stack.append(NestedInteger())
            
            elif char == ']':
                # 完成当前数字（如果有）
                if num_str:
                    stack[-1].add(NestedInteger(int(num_str)))
                    num_str = ""
                
                # 弹出当前层，添加到上一层
                if len(stack) > 1:
                    top = stack.pop()
                    stack[-1].add(top)
            
            elif char == ',':
                # 完成当前数字（如果有）
                if num_str:
                    stack[-1].add(NestedInteger(int(num_str)))
                    num_str = ""
            
            else:
                # 数字或负号
                num_str += char
        
        return stack[0]
```

### 方法二：更清晰的栈实现

```python
class Solution:
    def deserialize(self, s: str) -> NestedInteger:
        """
        改进的栈实现，逻辑更清晰
        """
        # 特殊情况
        if not s:
            return NestedInteger()
        if s[0] != '[':
            return NestedInteger(int(s))
        
        stack = []
        num = ""
        
        for i, char in enumerate(s):
            if char == '[':
                stack.append(NestedInteger())
            
            elif char == ']' or char == ',':
                # 处理累积的数字
                if num:
                    stack[-1].add(NestedInteger(int(num)))
                    num = ""
                
                # 如果是右括号且不是最后一个，需要合并
                if char == ']' and len(stack) > 1:
                    top = stack.pop()
                    stack[-1].add(top)
            
            elif char == '-' or char.isdigit():
                num += char
        
        return stack[0]
```

### 方法三：递归解析

```python
class Solution:
    def deserialize(self, s: str) -> NestedInteger:
        """
        递归解析
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        self.index = 0
        self.s = s
        return self.parseNestedInteger()
    
    def parseNestedInteger(self) -> NestedInteger:
        """递归解析一个 NestedInteger"""
        if self.s[self.index] == '[':
            # 解析列表
            self.index += 1  # 跳过 '['
            result = NestedInteger()
            
            while self.s[self.index] != ']':
                if self.s[self.index] == ',':
                    self.index += 1
                result.add(self.parseNestedInteger())
            
            self.index += 1  # 跳过 ']'
            return result
        else:
            # 解析整数
            num_str = ""
            while self.index < len(self.s) and (self.s[self.index] == '-' or self.s[self.index].isdigit()):
                num_str += self.s[self.index]
                self.index += 1
            return NestedInteger(int(num_str))
```

### 方法四：使用正则表达式（创意解法）

```python
import re

class Solution:
    def deserialize(self, s: str) -> NestedInteger:
        """
        使用正则表达式分割
        适合理解，但不是最优解
        """
        # 如果是单个数字
        if s[0] != '[':
            return NestedInteger(int(s))
        
        # 使用正则找到所有 token
        tokens = re.findall(r'\[|\]|-?\d+', s)
        
        stack = []
        for token in tokens:
            if token == '[':
                stack.append(NestedInteger())
            elif token == ']':
                if len(stack) > 1:
                    top = stack.pop()
                    stack[-1].add(top)
            else:
                stack[-1].add(NestedInteger(int(token)))
        
        return stack[0]
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历字符串的每个字符一次
- 每个字符最多被处理一次

**空间复杂度：** O(n)
- 栈的深度取决于嵌套层数，最坏情况 O(n)
- 递归调用栈也是 O(n)

## 关键点总结

1. **栈的使用**：用栈保存不同嵌套层级的 NestedInteger
2. **数字累积**：遇到数字字符时需要累积完整的数字（多位数、负数）
3. **边界处理**：单个整数、空列表、负数等特殊情况
4. **弹栈时机**：遇到 `]` 时完成当前层，弹出并添加到上一层
5. **逗号的作用**：分隔符，用于完成当前数字的解析

## 易错点

1. **忘记处理负数**：`-123` 需要正确解析为 -123
2. **多位数问题**：`123` 不是三个数字，需要累积
3. **空列表**：`[]` 是合法的嵌套列表
4. **单个整数**：`"123"` 没有括号，直接返回 NestedInteger
5. **逗号处理**：遇到逗号时要完成之前数字的解析
6. **最后的数字**：如 `[1,2,3]` 中的 `3` 后面是 `]` 而不是 `,`

## 图解示例

```
输入: "[123,[456,[789]]]"

解析过程:

1. 遇到 '[': stack = [NestedInteger()]
2. 遇到 '123': stack[-1].add(123)
3. 遇到 ',': 完成数字
4. 遇到 '[': stack = [NestedInteger(), NestedInteger()]
5. 遇到 '456': stack[-1].add(456)
6. 遇到 ',': 完成数字
7. 遇到 '[': stack = [外层, 中层, NestedInteger()]
8. 遇到 '789': stack[-1].add(789)
9. 遇到 ']': 弹出内层 [789]，添加到中层
              stack = [外层, 中层(含 456 和 [789])]
10. 遇到 ']': 弹出中层，添加到外层
              stack = [外层(含 123 和 [456,[789]])]
11. 遇到 ']': 完成，返回 stack[0]

结果: [123,[456,[789]]]
```
