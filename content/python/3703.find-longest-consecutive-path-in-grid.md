## 题目描述

给定一个 `m × n` 的整数矩阵 `grid`，从任意单元格出发，每次只能移动到上、下、左、右四个相邻单元格，且要求下一个单元格的值恰好等于当前值加一。返回这样的最长连续路径的长度。

**示例 1：**
```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：5
解释：路径 1->2->3->6->9 或 1->2->3->6->5 等，最长为 5 步（值连续递增 1）。
     实际上：1->2->3->4->5 长度为 5（不一定，要看相邻关系）。
```

**示例 2：**
```
输入：grid = [[9,8,7],[6,5,4],[3,2,1]]
输出：9
解释：所有元素恰好组成一条蛇形路径，长度为 9。
```

**提示：**
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 10^6`

## 解题思路

深度优先搜索（DFS）配合记忆化，避免重复计算。

对每个单元格 `(i, j)`，定义 `dp[i][j]` 为以该单元格为起点的最长连续路径长度。
- 若某个相邻单元格 `(ni, nj)` 满足 `grid[ni][nj] == grid[i][j] + 1`，则可以从 `(i,j)` 走到 `(ni,nj)`。
- `dp[i][j] = 1 + max(dp[ni][nj] for valid neighbors)`
- 用记忆化避免重复搜索，整体时间复杂度为 O(mn)。

## Python 代码实现

### 方法一：DFS + 记忆化（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def longestPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        @lru_cache(maxsize=None)
        def dfs(i: int, j: int) -> int:
            # 以 (i,j) 为起点的最长连续递增路径长度
            best = 1
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    if grid[ni][nj] == grid[i][j] + 1:
                        # 相邻格子值恰好大 1，可以继续
                        best = max(best, 1 + dfs(ni, nj))
            return best

        ans = 0
        for i in range(m):
            for j in range(n):
                ans = max(ans, dfs(i, j))

        return ans
```

### 方法二：迭代 DP（按值排序）

```python
from typing import List

class Solution:
    def longestPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        # 按格子值从小到大处理
        cells = sorted((grid[i][j], i, j) for i in range(m) for j in range(n))
        dp = [[1] * n for _ in range(m)]

        ans = 1
        for val, i, j in cells:
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    if grid[ni][nj] == val - 1:
                        # (ni,nj) 的值比当前小 1，可以从 (ni,nj) 到达 (i,j)
                        dp[i][j] = max(dp[i][j], dp[ni][nj] + 1)
            ans = max(ans, dp[i][j])

        return ans
```

## 复杂度分析

- 时间复杂度：O(mn)，每个单元格最多计算一次
- 空间复杂度：O(mn)，记忆化或 DP 数组

## 关键点总结

1. 问题转化为有向无环图（DAG）上的最长路径，因为路径值严格递增
2. 记忆化 DFS 和按值排序的迭代 DP 都是解决此类问题的标准模式
3. 因为路径值严格单调，不存在环，DFS 不需要 visited 数组

## 易错点

1. 路径是严格连续递增（每次加 1），不是任意递增
2. 方向是四联通（上下左右），不包括斜方向
