## 题目描述

有 `n` 个气球，编号为 `0` 到 `n - 1`，每个气球上都标有一个数字，这些数字存在数组 `nums` 中。

现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币。这里的 `i - 1` 和 `i + 1` 代表和 `i` 相邻的两个气球的序号。如果 `i - 1` 或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。

求所能获得硬币的最大数量。

**示例 1：**
```
输入：nums = [3,1,5,8]
输出：167
解释：
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167
```

**示例 2：**
```
输入：nums = [1,5]
输出：10
```

**提示：**
- `n == nums.length`
- `1 <= n <= 300`
- `0 <= nums[i] <= 100`

## 解题思路

这是一道非常经典的区间 DP 问题。

### 为什么不能贪心？

戳破气球的顺序会影响后续的收益，因为每次戳破气球后，相邻关系会改变。

### 核心思路：逆向思维

**正向思考**（困难）：先戳哪个气球？
- 戳破一个气球后，相邻关系改变，难以处理

**逆向思考**（巧妙）：最后戳哪个气球？⭐
- 假设最后戳破的是第 `k` 个气球
- 此时左右两边的气球都已被戳破
- 收益为：`nums[left-1] * nums[k] * nums[right+1]`
- 加上左右两边的最优收益

### 状态定义

`dp[i][j]` 表示戳破区间 `(i, j)` 开区间内所有气球能获得的最大硬币数。

**注意**：是开区间，不包括 `i` 和 `j`。

### 状态转移

对于区间 `(i, j)`，枚举最后戳破的气球 `k`（`i < k < j`）：

```
dp[i][j] = max(dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j])
           for k in range(i+1, j)
```

解释：
- `dp[i][k]`：左边区间的最优解
- `nums[i]*nums[k]*nums[j]`：戳破 k 的收益（此时 i 和 j 还在）
- `dp[k][j]`：右边区间的最优解

### 边界处理

在数组两端添加虚拟气球 `1`，方便处理边界。

## Python 代码实现

### 方法一：区间 DP（推荐）⭐

```python
from typing import List

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        # 添加虚拟气球
        nums = [1] + nums + [1]
        n = len(nums)
        
        # dp[i][j] 表示戳破开区间 (i, j) 内所有气球的最大收益
        dp = [[0] * n for _ in range(n)]
        
        # 区间长度从小到大
        for length in range(3, n + 1):  # 长度至少为 3（包含两个虚拟气球）
            # 枚举区间起点
            for i in range(n - length + 1):
                j = i + length - 1
                
                # 枚举最后戳破的气球 k
                for k in range(i + 1, j):
                    # 戳破 k 的收益 + 左右两边的最优收益
                    coins = nums[i] * nums[k] * nums[j]
                    dp[i][j] = max(dp[i][j], dp[i][k] + coins + dp[k][j])
        
        # 返回整个区间的最优解（不包括虚拟气球）
        return dp[0][n - 1]
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        nums = [1] + nums + [1]
        
        @lru_cache(None)
        def dp(i: int, j: int) -> int:
            """返回戳破开区间 (i, j) 内所有气球的最大收益"""
            # 区间内没有气球
            if i + 1 == j:
                return 0
            
            max_coins = 0
            # 枚举最后戳破的气球 k
            for k in range(i + 1, j):
                coins = nums[i] * nums[k] * nums[j]
                max_coins = max(max_coins, dp(i, k) + coins + dp(k, j))
            
            return max_coins
        
        return dp(0, len(nums) - 1)
```

### 方法三：带详细注释的版本

```python
from typing import List

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        """
        区间 DP 解决戳气球问题
        
        核心思想：逆向思考，考虑最后戳破哪个气球
        
        为什么要逆向？
        - 正向：戳破一个气球后，相邻关系改变，难以处理
        - 逆向：最后戳破时，左右气球已知（就是区间边界）
        
        为什么添加虚拟气球？
        - 方便处理边界情况
        - 统一状态转移方程
        """
        # 步骤1：添加虚拟气球（值为 1）
        nums = [1] + nums + [1]
        n = len(nums)
        
        # 步骤2：初始化 DP 数组
        # dp[i][j] = 戳破开区间 (i, j) 内所有气球的最大收益
        # 开区间：不包括 i 和 j
        dp = [[0] * n for _ in range(n)]
        
        # 步骤3：从小区间到大区间计算
        # length = 区间长度（包括两个边界）
        for length in range(3, n + 1):
            # 枚举区间起点 i
            for i in range(n - length + 1):
                # 计算区间终点 j
                j = i + length - 1
                
                # 枚举最后戳破的气球 k（在开区间 (i, j) 内）
                for k in range(i + 1, j):
                    # 计算收益
                    # 1. 左边区间 (i, k) 的最优解
                    left = dp[i][k]
                    
                    # 2. 戳破 k 的收益
                    # 此时只剩下 i, k, j 三个气球
                    current = nums[i] * nums[k] * nums[j]
                    
                    # 3. 右边区间 (k, j) 的最优解
                    right = dp[k][j]
                    
                    # 更新最大值
                    dp[i][j] = max(dp[i][j], left + current + right)
        
        # 返回整个区间的最优解
        # 区间 (0, n-1) 即原数组加两个虚拟气球
        return dp[0][n - 1]
```

### 方法四：递归写法

```python
from typing import List

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        nums = [1] + nums + [1]
        n = len(nums)
        memo = {}
        
        def dfs(i: int, j: int) -> int:
            """计算区间 (i, j) 的最大收益"""
            if i + 1 == j:
                return 0
            
            if (i, j) in memo:
                return memo[(i, j)]
            
            max_coins = 0
            for k in range(i + 1, j):
                coins = nums[i] * nums[k] * nums[j]
                max_coins = max(max_coins, dfs(i, k) + coins + dfs(k, j))
            
            memo[(i, j)] = max_coins
            return max_coins
        
        return dfs(0, n - 1)
```

## 复杂度分析

- 时间复杂度：O(n³)
  - 外层循环：O(n)（区间长度）
  - 中层循环：O(n)（区间起点）
  - 内层循环：O(n)（枚举 k）
- 空间复杂度：O(n²)，DP 数组

## 关键点总结

1. **逆向思维**：考虑最后戳破哪个气球，而不是第一个
2. **虚拟气球**：在两端添加值为 1 的气球，简化边界处理
3. **开区间**：`dp[i][j]` 是开区间 `(i, j)`，不包括 `i` 和 `j`
4. **区间 DP**：从小区间到大区间计算
5. **状态转移**：枚举最后戳破的气球 `k`，分成左右两部分

## 易错点

1. **区间定义**：是开区间还是闭区间，要统一
2. **虚拟气球**：忘记添加或添加错误
3. **循环顺序**：区间长度要从小到大
4. **边界条件**：`i + 1 == j` 时没有气球可戳
5. **最后戳破**：收益是 `nums[i]*nums[k]*nums[j]`，不是 `nums[k-1]*nums[k]*nums[k+1]`
