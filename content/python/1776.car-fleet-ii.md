## 题目描述

在一条单行道上，有 `n` 辆车向着同一方向行驶。给你一个长度为 `n` 的数组 `cars`，其中 `cars[i] = [position_i, speed_i]`，代表第 `i` 辆车在初始时处于 `position_i`，以 `speed_i` 的速度行驶（位置从小到大，速度为正数）。

每辆车会**无限期地**（包括碰到其他车后）保持初始速度行驶，直到到达无穷远处，或者跟上前方最近的车队。

对于每辆车 `i`，如果没有车可以跟上的话，返回 `-1`。否则，返回第 `i` 辆车与紧接其前方的车队相遇所需的时间。

**提示：**
- `1 <= cars.length <= 10^5`

## 解题思路

从右往左用单调栈处理。

维护一个栈，存放尚未被追上的车队信息。对于每辆车 `i`：
1. 它能追上紧前方的车（栈顶）需要的时间 `t = (pos[i+1] - pos[i]) / (speed[i] - speed[i+1])`（若 `speed[i] <= speed[i+1]`，追不上）
2. 若 `t` 大于栈顶之前被更前面的车追上的时间，则当前车会和更前面的车队一起被追上，弹出栈顶

## 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def getCollisionTimes(self, cars: List[List[int]]) -> List[float]:
        n = len(cars)
        ans = [-1.0] * n
        
        # 栈存 (下标)，从右往左处理
        # 栈顶是最靠右的车（目标）
        stack = []  # 存储下标，表示尚未被追上的车队
        
        for i in range(n - 1, -1, -1):
            pos, speed = cars[i]
            
            # 判断能否追上栈顶的车
            while stack:
                j = stack[-1]
                pos_j, speed_j = cars[j]
                
                if speed <= speed_j:
                    # 追不上，弹出（栈顶对当前车无用，但对左边的车可能有用）
                    stack.pop()
                    continue
                
                # 追上时间
                t = (pos_j - pos) / (speed - speed_j)
                
                # 如果栈顶的车在 t 时刻之前已经被更前面的车追上
                # 则栈顶车在 t 时刻之前已加入更前面的车队
                if ans[j] != -1 and ans[j] <= t:
                    stack.pop()
                    continue
                
                # 能追上栈顶的车
                ans[i] = t
                break
            
            stack.append(i)
        
        return ans
```

### 方法二：堆（按追上时间排序）

```python
from typing import List
import heapq

class Solution:
    def getCollisionTimes(self, cars: List[List[int]]) -> List[float]:
        n = len(cars)
        ans = [-1.0] * n
        
        # 单调栈实现（同方法一，不同注释视角）
        stack = []
        
        for i in range(n - 1, -1, -1):
            p, s = cars[i]
            
            while stack:
                j = stack[-1]
                pj, sj = cars[j]
                
                # 若当前车速 <= 前车速，追不上前车
                if s <= sj:
                    stack.pop()
                    continue
                
                t = (pj - p) / (s - sj)
                
                # 前车已经在时间 t 之前被更前的车追上（合并）
                if ans[j] > 0 and t >= ans[j]:
                    stack.pop()
                    continue
                
                ans[i] = t
                break
            
            stack.append(i)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n)，每辆车最多入栈出栈一次
- **空间复杂度**：O(n)，栈空间

## 关键点总结

1. 从右往左处理，单调栈维护"有效"的追赶目标
2. 若追不上（速度不比前车快），弹出栈顶
3. 若前车在当前车追到之前已被合并，也要弹出

## 易错点

- 速度相同追不上，不能除以零
- 前车被追上的时间的判断：`ans[j] != -1 and ans[j] <= t`
