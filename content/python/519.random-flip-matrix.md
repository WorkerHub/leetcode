## 题目描述

给你一个 `m x n` 的二元矩阵 `matrix`，且所有值被初始化为 `0`。请你设计一个算法，随机选取一个满足 `matrix[i][j] == 0` 的下标 `(i, j)`，并将它的值变为 `1`。所有满足 `matrix[i][j] == 0` 的下标 `(i, j)` 被选取的概率应当均等。

尽量最少调用内置的随机函数，并且优化时间和空间复杂度。

实现 `Solution` 类：
- `Solution(int m, int n)` 使用二元矩阵的大小 `m` 和 `n` 初始化该对象
- `int[] flip()` 返回一个满足 `matrix[i][j] == 0` 的随机下标 `[i, j]`，并将其对应格子中的值变为 `1`
- `void reset()` 将矩阵中所有的值重置为 `0`

**示例：**
```
输入
["Solution", "flip", "flip", "flip", "reset", "flip"]
[[3, 1], [], [], [], [], []]
输出
[null, [1, 0], [2, 0], [0, 0], null, [2, 0]]

解释
Solution solution = new Solution(3, 1);
solution.flip();  // 返回 [1, 0]，此时返回 [0,0]、[1,0] 和 [2,0] 的概率应当相同
solution.flip();  // 返回 [2, 0]，因为 [1,0] 已经返回过了，此时返回 [2,0] 和 [0,0] 的概率应当相同
solution.flip();  // 返回 [0, 0]，根据前面已经返回过的下标，此时只能返回 [0,0]
solution.reset(); // 所有值都重置为 0 ，并可以再次选择下标返回
solution.flip();  // 返回 [2, 0]，此时返回 [0,0]、[1,0] 和 [2,0] 的概率应当相同
```

**提示：**
- `1 <= m, n <= 10^4`
- 每次调用 `flip` 时，矩阵中至少存在一个值为 0 的格子
- 最多调用 `1000` 次 `flip` 和 `reset` 方法

## 解题思路

核心挑战：**大矩阵中避免 O(m×n) 空间**。

### 方法对比：
1. **集合存储**：记录已翻转的位置
2. **虚拟数组 + 交换**：类似洗牌算法

## Python 代码实现

### 方法一：哈希表映射（推荐）⭐

```python
import random

class Solution:
    def __init__(self, m: int, n: int):
        """
        使用哈希表记录映射关系
        空间复杂度：O(k)，k 是 flip 调用次数
        """
        self.m = m
        self.n = n
        self.total = m * n
        self.map = {}  # 映射关系
    
    def flip(self) -> List[int]:
        """
        随机翻转一个 0
        时间复杂度：O(1)
        """
        # 随机选择一个未翻转的位置
        idx = random.randint(0, self.total - 1)
        
        # 获取实际位置（可能被映射过）
        actual = self.map.get(idx, idx)
        
        # 将这个位置映射到最后一个未使用位置
        self.map[idx] = self.map.get(self.total - 1, self.total - 1)
        
        # 减少可用位置数
        self.total -= 1
        
        # 转换为二维坐标
        return [actual // self.n, actual % self.n]
    
    def reset(self) -> None:
        """
        重置
        时间复杂度：O(1)
        """
        self.total = self.m * self.n
        self.map.clear()
```

### 方法二：集合记录（空间较大）

```python
class Solution:
    def __init__(self, m: int, n: int):
        """
        使用集合记录已翻转的位置
        空间复杂度：O(k)
        """
        self.m = m
        self.n = n
        self.flipped = set()
    
    def flip(self) -> List[int]:
        """
        随机选择未翻转的位置
        时间复杂度：O(1) 平均
        """
        total = self.m * self.n
        while True:
            idx = random.randint(0, total - 1)
            if idx not in self.flipped:
                self.flipped.add(idx)
                return [idx // self.n, idx % self.n]
    
    def reset(self) -> None:
        self.flipped.clear()
```

## 复杂度分析

### 方法一（哈希表）：
- **flip**：O(1)
- **reset**：O(1)
- **空间**：O(k)，k 是 flip 次数

### 方法二（集合）：
- **flip**：O(1) 平均，最坏可能需要多次尝试
- **reset**：O(1)
- **空间**：O(k)

## 关键点总结

1. **虚拟数组**：将二维坐标映射为一维
2. **交换技巧**：类似洗牌算法
3. **哈希表优化**：只记录映射关系
4. **坐标转换**：`[i, j]` ↔ `i * n + j`

## 易错点

1. **坐标转换**：注意是 `i * n + j`
2. **边界处理**：total 要及时更新
3. **映射更新**：要考虑位置已被映射的情况
