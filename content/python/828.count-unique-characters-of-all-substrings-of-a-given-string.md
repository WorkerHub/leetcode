## 题目描述

我们定义了一个函数 `countUniqueChars(s)` 来统计字符串 `s` 中的唯一字符，并返回唯一字符的个数。

例如：`s = "LEETCODE"`，则其中 `"L"`, `"T"`, `"C"`, `"O"`, `"D"` 都是唯一字符，因为它们只出现一次，所以 `countUniqueChars(s) = 5`。

本题将会给你一个字符串 `s`，我们需要返回 `countUniqueChars(t)` 的总和，其中 `t` 是 `s` 的子字符串。输入用例保证答案符合 32 位带符号整数范围。

注意，某些子字符串可能是重复的，但你统计时也必须算上这些重复的子字符串（也就是说，你必须统计 `s` 的所有子字符串中的唯一字符）。

**示例 1:**
```
输入: s = "ABC"
输出: 10
解释: 所有可能的子串为："A","B","C","AB","BC"和"ABC"。
每个子字符串中唯一字符分别是："A","B","C","AB","BC"和"ABC"。
所以答案就是 1 + 1 + 1 + 2 + 2 + 3 = 10
```

**示例 2:**
```
输入: s = "ABA"
输出: 8
解释: 除了 countUniqueChars("ABA") = 1 之外，其余与示例 1 相同。
```

**示例 3:**
```
输入: s = "LEETCODE"
输出: 92
```

## Python 代码实现

```python
class Solution:
    def uniqueLetterString(self, s: str) -> int:
        n = len(s)
        # 记录每个字符出现的位置
        pos = {}
        for i, c in enumerate(s):
            if c not in pos:
                pos[c] = []
            pos[c].append(i)
        
        result = 0
        for c, indices in pos.items():
            # 在首尾添加虚拟位置
            indices = [-1] + indices + [n]
            
            # 对于每个出现位置，计算其作为唯一字符的贡献
            for i in range(1, len(indices) - 1):
                left = indices[i] - indices[i - 1]
                right = indices[i + 1] - indices[i]
                result += left * right
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贡献法**：计算每个字符在多少子串中唯一
2. **位置记录**：记录每个字符的所有位置
3. **乘法原理**：左右区间长度相乘
