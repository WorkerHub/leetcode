## 题目描述

给你一个整数数组 `nums`，每次操作可以删除数组中的任意一个元素。

返回使 `nums` 成为回文数组所需的**最少删除次数**。

**示例 1：**

```
输入：nums = [1, 2, 3, 2, 1]
输出：0
解释：数组本身已经是回文，无需删除。
```

**示例 2：**

```
输入：nums = [1, 2, 2, 3, 1]
输出：1
解释：删除 nums[2]=2（或 nums[1]=2），得到 [1, 2, 3, 1] -> 还需删除? 
实际: 删除 3 -> [1, 2, 2, 1] 是回文，只需删 1 次。
```

**示例 3：**

```
输入：nums = [1, 3, 2, 3, 1, 2]
输出：2
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`

## 解题思路

**转化：最少删除次数 = n - 最长回文子序列（LPS）的长度。**

原因：保留尽可能多的元素使其构成回文，删除其余元素。保留元素构成最长回文子序列，其余删除。

**最长回文子序列（LPS）DP：**
- `dp[i][j]` = `nums[i..j]` 中最长回文子序列的长度。
- 若 `nums[i] == nums[j]`：`dp[i][j] = dp[i+1][j-1] + 2`
- 否则：`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

答案 = `n - dp[0][n-1]`

## Python 代码实现

### 方法一：区间 DP 求最长回文子序列（推荐）

```python
from typing import List

class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)

        # dp[i][j] = nums[i..j] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]

        # 长度为 1 的子数组都是回文
        for i in range(n):
            dp[i][i] = 1

        # 按子数组长度从小到大枚举
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if nums[i] == nums[j]:
                    # 两端相等，两端都取
                    dp[i][j] = dp[i + 1][j - 1] + 2 if length > 2 else 2
                else:
                    # 删左或删右，取较优
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        # 最少删除 = 总长度 - 最长回文子序列
        return n - dp[0][n - 1]
```

### 方法二：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)

        @lru_cache(maxsize=None)
        def lps(i: int, j: int) -> int:
            """nums[i..j] 的最长回文子序列长度"""
            if i > j:
                return 0
            if i == j:
                return 1
            if nums[i] == nums[j]:
                return lps(i + 1, j - 1) + 2
            return max(lps(i + 1, j), lps(i, j - 1))

        return n - lps(0, n - 1)
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子数组
- 空间复杂度：O(n^2)，DP 表

## 关键点总结

1. 核心转化：最少删除 = n - 最长回文子序列（LPS）长度。
2. LPS 区间 DP：两端相等时 `dp[i][j] = dp[i+1][j-1] + 2`，否则取左右最大。
3. 区间 DP 枚举顺序：按长度从小到大（确保子问题先求解）。

## 易错点

1. 长度为 2 时 `dp[i+1][j-1]` 的下标 `i+1 > j-1`，需特判为 0。
2. 答案是 `n - LPS`，不是 LPS 本身。
3. 与最长回文子串不同：子序列不要求连续。
