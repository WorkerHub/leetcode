## 题目描述

给你一个已经排好序的整数数组 `nums` 和整数 `a`、`b`、`c`。对于数组中的每一个元素 `nums[i]`，计算函数值 `f(x) = ax^2 + bx + c`，请按升序返回结果数组。

**示例 1：**
```
输入：nums = [-4,-2,2,4], a = 1, b = 3, c = 5
输出：[3,9,15,33]
```

**示例 2：**
```
输入：nums = [-4,-2,2,4], a = -1, b = 3, c = 5
输出：[-23,-5,1,7]
```

**提示：**
- `1 <= nums.length <= 200`
- `-100 <= nums[i], a, b, c <= 100`
- `nums` 按升序排列

**进阶：** 你可以在时间复杂度为 O(n) 的情况下解决这个问题吗？

## 解题思路

这道题的关键是利用二次函数的性质。

**核心观察：**
1. 当 a > 0 时，抛物线开口向上，两端的值较大
2. 当 a < 0 时，抛物线开口向下，两端的值较小
3. 当 a = 0 时，是线性函数

**双指针策略：**
- a > 0：从两端向中间，选择较大的值
- a < 0：从两端向中间，选择较小的值
- a = 0：单调，直接计算

## Python 代码实现

```python
from typing import List

class Solution:
    def sortTransformedArray(self, nums: List[int], a: int, b: int, c: int) -> List[int]:
        def f(x):
            return a * x * x + b * x + c
        
        n = len(nums)
        result = [0] * n
        left, right = 0, n - 1
        
        if a >= 0:
            # 开口向上或线性，从后往前填充（大的在后面）
            index = n - 1
            while left <= right:
                left_val = f(nums[left])
                right_val = f(nums[right])
                
                if left_val >= right_val:
                    result[index] = left_val
                    left += 1
                else:
                    result[index] = right_val
                    right -= 1
                
                index -= 1
        else:
            # 开口向下，从前往后填充（小的在前面）
            index = 0
            while left <= right:
                left_val = f(nums[left])
                right_val = f(nums[right])
                
                if left_val <= right_val:
                    result[index] = left_val
                    left += 1
                else:
                    result[index] = right_val
                    right -= 1
                
                index += 1
        
        return result
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

## 图解示例

```
nums = [-4,-2,2,4], a = 1, b = 3, c = 5

f(x) = x^2 + 3x + 5（开口向上）

计算各点的值：
f(-4) = 16 - 12 + 5 = 9
f(-2) = 4 - 6 + 5 = 3
f(2) = 4 + 6 + 5 = 15
f(4) = 16 + 12 + 5 = 33

双指针（开口向上，从大到小填充）：
left=-4(9), right=4(33)
  → 33 > 9，result[3] = 33, right--

left=-4(9), right=2(15)
  → 15 > 9，result[2] = 15, right--

left=-4(9), right=-2(3)
  → 9 > 3，result[1] = 9, left++

left=-2(3), right=-2(3)
  → result[0] = 3

最终：[3, 9, 15, 33]
```

## 关键点总结

1. **二次函数性质**：开口方向决定填充顺序
2. **双指针**：从两端向中间
3. **O(n) 时间**：避免排序
4. **空间优化**：可以原地修改

## 易错点

1. **a = 0 的情况**：按 a >= 0 处理即可
2. **填充方向**：a > 0 从后往前，a < 0 从前往后
