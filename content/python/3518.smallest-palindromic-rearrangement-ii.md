## 题目描述

给定一个回文字符串 `s` 和整数 `k`，返回字典序第 `k` 小的回文串（对 `s` 的字符重排，保持回文性质）。若重排数量不足 `k`，返回空字符串。

**示例 1：**

```
输入：s = "abba", k = 2
输出："baab"
解释：所有回文重排按字典序：["abba", "baab"]，第2小为 "baab"。
```

**示例 2：**

```
输入：s = "aa", k = 2
输出：""
解释：只有一种回文重排 "aa"，k=2 不存在。
```

**提示：**
- `1 <= s.length <= 1000`
- `1 <= k <= 10^9`
- `s` 是回文字符串

## 解题思路

问题转化：回文串的前半部分决定整个串，因此问题等价于求前半部分字符集的第 `k` 小全排列。

步骤：
1. 统计字符频次，得到前半部分的字符集（每个字符出现次数除以 2）
2. 计算前半部分所有排列数（考虑重复字符）：`n! / (c1! * c2! * ... * cm!)`
3. 用逐位确定的方法：从左到右，对每个位置枚举字符，计算选该字符后剩余的排列数，找到第 `k` 小的排列
4. 构建完整回文串

需要处理大数（k 可达 10^9），Python 的大整数支持很方便。

## Python 代码实现

### 方法一：逐位确定第 k 小排列（推荐）

```python
from collections import Counter
from math import factorial

class Solution:
    def smallestPalindrome(self, s: str, k: int) -> str:
        cnt = Counter(s)

        # 前半部分字符频次
        half_cnt = {}
        middle = ''
        for c, freq in cnt.items():
            if freq // 2 > 0:
                half_cnt[c] = freq // 2
            if freq % 2 == 1:
                middle = c

        half_len = sum(half_cnt.values())

        # 计算多重集排列数
        def perm_count(cnt_dict):
            total = sum(cnt_dict.values())
            result = factorial(total)
            for v in cnt_dict.values():
                result //= factorial(v)
            return result

        # 检查总排列数是否 >= k
        total = perm_count(half_cnt)
        if total < k:
            return ""

        # 逐位确定前半部分
        half = []
        remaining = dict(half_cnt)

        for pos in range(half_len):
            for c in sorted(remaining.keys()):
                if remaining[c] == 0:
                    continue
                # 计算选择字符 c 后的排列数
                remaining[c] -= 1
                if remaining[c] == 0:
                    del remaining[c]
                count = perm_count(remaining)
                if k <= count:
                    half.append(c)
                    break
                else:
                    k -= count
                    remaining[c] = remaining.get(c, 0) + 1
            else:
                return ""

        half_str = ''.join(half)
        return half_str + middle + half_str[::-1]
```

### 方法二：使用大整数比较（处理极大 k）

```python
from collections import Counter
from math import factorial

class Solution:
    def smallestPalindrome(self, s: str, k: int) -> str:
        cnt = Counter(s)
        half_cnt = {c: freq // 2 for c, freq in cnt.items() if freq // 2 > 0}
        middle = next((c for c, freq in cnt.items() if freq % 2 == 1), '')
        half_len = sum(half_cnt.values())

        def perm_count(d):
            if not d:
                return 1
            n = sum(d.values())
            res = factorial(n)
            for v in d.values():
                res //= factorial(v)
            return res

        total = perm_count(half_cnt)
        if k > total:
            return ""

        half = []
        rem = dict(half_cnt)

        for _ in range(half_len):
            for c in sorted(rem):
                if rem[c] == 0:
                    continue
                rem[c] -= 1
                if rem[c] == 0:
                    del rem[c]
                cnt_after = perm_count(rem)
                if k <= cnt_after:
                    half.append(c)
                    break
                k -= cnt_after
                rem[c] = rem.get(c, 0) + 1

        half_str = ''.join(half)
        return half_str + middle + half_str[::-1]
```

## 复杂度分析

- 时间复杂度：O(n * 26)，n 为前半部分长度，每位枚举 26 个字母
- 空间复杂度：O(n)

## 关键点总结

1. 回文串的字典序等价于其前半部分的字典序
2. 第 k 小排列：逐位确定，利用剩余排列数计数
3. Python 原生支持大整数，不需要担心阶乘溢出

## 易错点

1. 多重集排列数公式：`n! / (c1! * c2! * ...)`
2. k 的剩余量在逐位确定时需要正确递减
3. 前半部分排好后，后半部分是其镜像
