## 题目描述

给你一个二维整数数组 `queries`，其中 `queries[i] = [xi, yi]` 表示在坐标 `(xi, yi)` 添加一个障碍物，以及一个整数 `k`。

在每次添加障碍物后，返回距离原点最近的第 `k` 个障碍物的**曼哈顿距离**（若不足 k 个障碍物，返回 -1）。

**示例 1：**
```
输入：queries = [[1,2],[3,4],[2,3],[-3,0]], k = 2
输出：[3,-1,-1,3]
```

**示例 2：**
```
输入：queries = [[5,5],[4,4],[3,3]], k = 1
输出：[10,8,6]
```

**提示：**
- `1 <= queries.length <= 2 * 10^5`
- `queries[i].length == 2`
- `1 <= k <= queries.length`
- `-10^9 <= xi, yi <= 10^9`

## 解题思路

维护一个大小为 k 的**最大堆**，堆顶是当前前 k 近的最大距离。

每次添加新障碍物，计算其曼哈顿距离（`|x| + |y|`），维护堆的大小为 k：
- 若堆中元素 < k，直接入堆
- 若新距离 < 堆顶，替换堆顶

答案为堆顶（第 k 近），若堆未满返回 -1。

## Python 代码实现

### 方法一：最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        ans = []
        # 最大堆（Python 用负数模拟）
        heap = []  # 存负距离，堆顶为最大距离的负值
        
        for x, y in queries:
            dist = abs(x) + abs(y)
            if len(heap) < k:
                heapq.heappush(heap, -dist)
            elif -heap[0] > dist:
                # 新距离更小，替换堆顶
                heapq.heapreplace(heap, -dist)
            
            if len(heap) == k:
                ans.append(-heap[0])
            else:
                ans.append(-1)
        
        return ans
```

### 方法二：排序（简单但慢）

```python
from typing import List

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        dists = []
        ans = []
        for x, y in queries:
            dists.append(abs(x) + abs(y))
            if len(dists) < k:
                ans.append(-1)
            else:
                ans.append(sorted(dists)[k - 1])
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n log k)，空间复杂度 O(k)
- 方法二：时间复杂度 O(n^2 log n)，不推荐

## 关键点总结

1. 维护大小为 k 的最大堆，堆顶是第 k 近的距离
2. 当堆满时，若新距离 < 堆顶，替换
3. 当堆未满时，返回 -1

## 易错点

1. Python 的 heapq 是最小堆，用负数模拟最大堆
2. 只有堆满 k 个元素时才有答案
