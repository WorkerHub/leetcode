## 题目描述

如果整数 `x` 满足：对于 `x` 中的每一位数字 `d`，这个数字在 `x` 中恰好出现 `d` 次，则称 `x` 是一个**数值平衡数**。

例如：`122` 是平衡数（1 出现 1 次，2 出现 2 次），`1333339` 是平衡数（1 出现 1 次，3 出现 3 次，9 出现 9 次）。

给你一个整数 `n`，请你返回**严格大于** `n` 的**最小数值平衡数**。

**示例 1：**
```
输入：n = 1
输出：22
```

**示例 2：**
```
输入：n = 1000000000
输出：1224444444
```

**提示：**
- `0 <= n <= 10^6`

## 解题思路

由于 `n <= 10^6`，答案范围不会太大。可以从 `n + 1` 开始逐个检查是否是平衡数。

**平衡数的最大位数：** 一个数最多 7 位（因为 1+2+3+4+5+6+7=28 位）。

实际上，可以**预先生成所有平衡数**（不超过 10 位），然后找第一个大于 n 的。

## 代码实现

### 方法一：逐个检查（暴力）

```python
class Solution:
    def nextBeautifulNumber(self, n: int) -> int:
        def is_balanced(x: int) -> bool:
            s = str(x)
            from collections import Counter
            cnt = Counter(s)
            # 每个数字 d 出现次数必须等于 d
            return all(cnt[d] == int(d) for d in cnt)

        x = n + 1
        while not is_balanced(x):
            x += 1
        return x
```

### 方法二：生成所有平衡数（推荐）

```python
class Solution:
    def nextBeautifulNumber(self, n: int) -> int:
        # 预先生成所有平衡数
        # 平衡数的构成：选择一些数字 d（每个 d 出现 d 次），排列组合
        # 可能的组合：{1},{2},{3},...,{1,2},{1,3},...,{1,2,3},...
        # 最大数：1+2+3+4+5+6+7 = 28 位（远超1000000000=10位）
        # 实际上7位最大（9999999 ~ 9^7），但 n <= 10^6 所以关注7位以内

        from itertools import combinations

        balanced = set()

        # 枚举所有可能的数字组合（每个数字 d 出现 d 次）
        # 可选数字：1-7（因为 1+2+...+7 = 28，超过 n 的范围）
        for digits in range(1, 8):  # 选多少个不同数字
            for combo in combinations(range(1, 10), digits):
                # 检查总位数
                total_digits = sum(combo)
                if total_digits > 10:  # 最多10位（10^9 是10位）
                    continue
                # 生成所有排列
                from itertools import permutations
                chars = []
                for d in combo:
                    chars.extend([str(d)] * d)

                seen_perms = set()
                for perm in permutations(chars):
                    if perm[0] == '0':
                        continue  # 不能有前导零（但本题无0）
                    num = int(''.join(perm))
                    balanced.add(num)

        # 找最小的大于 n 的平衡数
        return min(x for x in balanced if x > n)
```

### 方法三：简化逐个检查（快速验证）

```python
class Solution:
    def nextBeautifulNumber(self, n: int) -> int:
        from collections import Counter

        x = n + 1
        while True:
            cnt = Counter(str(x))
            if all(cnt[d] == int(d) for d in cnt):
                return x
            x += 1
```

## 复杂度分析

- 方法一/三（逐个检查）：O(D * k)，D 为到答案的距离，k 为数字位数
- 方法二（预生成）：O(combinations)，很快

## 关键点总结

1. 平衡数条件：每个出现的数字 `d`，恰好出现 `d` 次
2. 不能出现 `0`（否则 0 需出现 0 次，矛盾）
3. 对 `n <= 10^6`，答案不会太大，暴力逐个检查可行

## 易错点

- 数字 0 不能出现（因为 0 需要出现 0 次，但若出现就不满足）
- `Counter` 的键是字符串，比较时 `cnt[d] == int(d)` 而非 `cnt[d] == d`
