## 题目描述

给你一个下标从 **0** 开始的字符串数组 `words` 和一个字符串 `target`。

该数组是 **循环** 的，即将最后一个元素的下一个元素视为第一个元素，第一个元素的上一个元素视为最后一个元素。

从 `startIndex` 位置出发，你可以顺时针（下标递增）或逆时针（下标递减）移动，每次移动距离为 1。

返回从 `startIndex` 出发到达 **任意** `target` 所在位置的 **最短距离**，若 `target` 不在 `words` 中，返回 `-1`。

**示例 1：**

```
输入：words = ["hello","i","am","leetcode","hello"], target = "hello", startIndex = 1
输出：1
解释：
- 从 1 顺时针到 4：距离为 3
- 从 1 逆时针到 0：距离为 1（最短）
```

**示例 2：**

```
输入：words = ["a","b","leetcode"], target = "leetcode", startIndex = 0
输出：2
```

**提示：**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 和 `target` 只包含英文字母
- `0 <= startIndex < words.length`

## 解题思路

遍历所有 target 出现的位置，对每个位置计算顺时针和逆时针的距离，取两者较小值，然后对所有位置取最小值。

在循环数组中，从 i 到 j：
- 顺时针距离：`(j - i) % n`
- 逆时针距离：`(i - j) % n`
- 最短距离：两者取最小值

## Python 代码实现

### 方法一：遍历所有 target 位置（推荐）

```python
from typing import List

class Solution:
    def closetTarget(self, words: List[str], target: str, startIndex: int) -> int:
        n = len(words)
        ans = float('inf')

        for i, word in enumerate(words):
            if word == target:
                # 顺时针和逆时针距离
                clockwise = (i - startIndex) % n
                counter_clockwise = (startIndex - i) % n
                ans = min(ans, min(clockwise, counter_clockwise))

        return ans if ans != float('inf') else -1
```

### 方法二：两个方向分别计算

```python
from typing import List

class Solution:
    def closetTarget(self, words: List[str], target: str, startIndex: int) -> int:
        n = len(words)
        ans = n  # 最大距离不超过 n//2

        found = False
        for i in range(n):
            if words[i] == target:
                found = True
                diff = abs(i - startIndex)
                # 圆形距离 = min(正向, 反向)
                dist = min(diff, n - diff)
                ans = min(ans, dist)

        return ans if found else -1
```

## 复杂度分析

- 时间复杂度：O(n)，线性扫描
- 空间复杂度：O(1)

## 关键点总结

1. 循环数组中两点之间有两条路径，取较短的一条
2. 顺时针：`(j - i + n) % n`；逆时针：`(i - j + n) % n`
3. 最短距离 = `min(diff, n - diff)`，其中 `diff = abs(i - j)`

## 易错点

1. 若 target 不存在，返回 -1，而不是 0 或无穷大
2. 距离公式中要加 n 后取模，避免负数：`(j - i + n) % n`
3. 可能有多个 target 位置，要取所有位置的最短距离
