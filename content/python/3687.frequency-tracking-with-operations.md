## 题目描述

设计一个数据结构，支持以下操作：

1. `add(number)`：将 number 加入数据结构
2. `remove(number)`：将 number 从数据结构中移除一次
3. `hasFrequency(frequency)`：判断是否存在某个数，其在数据结构中的出现次数恰好为 frequency

**示例：**

```
operations = ["FrequencyTracker", "add", "add", "hasFrequency",
              "remove", "hasFrequency"]
inputs = [[], [3], [3], [2], [3], [1]]
输出：[null, null, null, true, null, true]
```

**提示：**

- `1 <= number <= 10^5`
- `1 <= frequency <= 10^5`
- 最多 `2 * 10^5` 次操作

## 解题思路

使用两个哈希表：

1. `count[num]`：每个数字的出现次数
2. `freq_count[f]`：出现次数为 f 的数字的数量

每次 `add`/`remove` 时，同步更新两个哈希表。

## Python 代码实现

### 方法一：双哈希表（推荐）

```python
from collections import defaultdict

class FrequencyTracker:
    def __init__(self):
        self.count = defaultdict(int)      # 每个数字的频率
        self.freq_count = defaultdict(int)  # 每种频率的数字数

    def add(self, number: int) -> None:
        old_freq = self.count[number]
        if old_freq > 0:
            self.freq_count[old_freq] -= 1
        self.count[number] += 1
        self.freq_count[self.count[number]] += 1

    def remove(self, number: int) -> None:
        old_freq = self.count[number]
        if old_freq == 0:
            return
        self.freq_count[old_freq] -= 1
        self.count[number] -= 1
        if self.count[number] > 0:
            self.freq_count[self.count[number]] += 1

    def hasFrequency(self, frequency: int) -> bool:
        return self.freq_count[frequency] > 0
```

### 方法二：只用单哈希表（O(n) hasFrequency）

```python
from collections import defaultdict

class FrequencyTracker:
    def __init__(self):
        self.count = defaultdict(int)

    def add(self, number: int) -> None:
        self.count[number] += 1

    def remove(self, number: int) -> None:
        if self.count[number] > 0:
            self.count[number] -= 1

    def hasFrequency(self, frequency: int) -> bool:
        return frequency in self.count.values()
```

## 复杂度分析

- 时间复杂度：O(1) 所有操作（方法一）
- 空间复杂度：O(n)

## 关键点总结

1. 双哈希表维护频率的频率
2. 更新 count 时同步更新 freq_count
3. 更新顺序：先减少旧频率计数，再增加新频率计数

## 易错点

1. 先更新 `freq_count[old_freq]--`，再更新 `count[num]`
2. 若 count 减为 0，不增加 `freq_count[0]`
3. `remove` 时若 count 为 0，直接返回
