## 题目描述

给你一个下标从 0 开始的**非递减**整数数组 `nums`。

每次操作，你可以删除两个下标 `i` 和 `j`（`i < j`），满足 `nums[i] < nums[j]`。

返回最多执行这样的操作后，数组的最短长度（无法再执行操作时停止）。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：0
解释：(1,2), (3,4) 两对，删完，长度 0
```

**示例 2：**
```
输入：nums = [1,1,2,2,3]
输出：1
解释：(1,2), (1,2)，剩余 [3]，长度 1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- nums 是非递减的

## 解题思路

**关键观察：** 设数组中出现次数最多的元素出现了 `max_count` 次，数组长度为 `n`。

- 若 `max_count > n / 2`，则最多只能删除 `n - max_count` 对（该元素没有足够的配对对象），剩余 = `2 * max_count - n`
- 若 `max_count <= n / 2`，可以把所有元素配对，剩余 = `n % 2`（奇偶性决定）

**证明：** 
- 若 `max_count > n/2`，最多配 `n - max_count` 对（其余 `n - max_count` 个不同元素各配一次），剩余 `= max_count - (n - max_count) = 2*max_count - n`
- 若 `max_count <= n/2`，所有元素都能配对（满足条件），可配 `n // 2` 对

## Python 代码实现

### 方法一：Counter 统计（推荐）

```python
from collections import Counter
from typing import List

class Solution:
    def minLengthAfterRemovals(self, nums: List[int]) -> int:
        n = len(nums)
        cnt = Counter(nums)
        max_count = max(cnt.values())

        if max_count > n // 2:
            # 出现最多的元素无法全部配对
            return 2 * max_count - n
        else:
            # 可以配对所有元素（或接近）
            return n % 2
```

### 方法二：双指针验证

```python
from typing import List

class Solution:
    def minLengthAfterRemovals(self, nums: List[int]) -> int:
        n = len(nums)
        # 双指针：左指针 l 指向前半，右指针 r 指向后半
        # 贪心配对：前半部分和后半部分配对
        l, r = 0, n // 2
        pairs = 0

        while l < n // 2 and r < n:
            if nums[l] < nums[r]:
                pairs += 1
                l += 1
                r += 1
            else:
                r += 1

        return n - 2 * pairs
```

## 复杂度分析

- 方法一：时间 O(n)，空间 O(k)，k 为不同元素数
- 方法二：时间 O(n)，空间 O(1)

## 关键点总结

1. 最多出现次数超过 n/2 时，是限制因素
2. 结论：`max(n % 2, 2 * max_count - n)` 或等价写法
3. 方法二双指针：前半和后半配对，非常优雅

## 易错点

1. 条件是 `nums[i] < nums[j]`（严格小于），相等的数不能配对
2. 数组非递减，相同元素聚集在一起
3. `n % 2` 考虑奇偶：n 为奇数时至少剩 1 个
