## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 是第 `i+1` 种水果的价格（1-indexed）。

若你购买第 `i` 种水果，可以免费获得之后的 `i` 种水果（即第 i+1 到 i+i 种免费）。

返回购买所有 n 种水果所需的最少花费。

**示例 1：**
```
输入：prices = [3,1,2]
输出：3
解释：买第 1 种（花费 3），免费得第 2、3 种
```

**示例 2：**
```
输入：prices = [1,10,1,1]
输出：2
解释：买第 1 种（1），免费得第 2 种，买第 3 种（1），免费得第 4 种
```

**提示：**
- `1 <= prices.length <= 1000`
- `1 <= prices[i] <= 10^5`

## 解题思路

定义 `dp[i]` 为购买完前 i 种水果的最少花费（1-indexed）。

购买第 j 种水果（花费 prices[j-1]），可以免费得到第 j+1 到 j+j 种水果。

转移：若买第 j 种，下一个需要买的水果从 j+j+1 开始（即 2j+1 或更早）。

`dp[i] = min over j in [ceil(i/2), i]: dp[j-1] + prices[j-1]`

即从后半段选一个 j，用它的免费范围覆盖到 i。

用单调队列（deque）维护 dp 的滑动窗口最小值。

## Python 代码实现

### 方法一：动态规划 + 单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumCoins(self, prices: List[int]) -> int:
        n = len(prices)
        # dp[i] = 已获得前 i 种水果的最小花费（1-indexed，dp[0]=0）
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        # 对于每个 i，需要从 [ceil(i/2), i] 中选 j
        # dp[i] = min(dp[j-1] + prices[j-1]) for j in [ceil(i/2), i]
        # 等价于：dp[i] = min(dp[j-1] + prices[j-1]) for j-1 in [ceil(i/2)-1, i-1]
        # 使用单调队列维护滑动窗口最小值

        # 从 i=1 到 n
        dq = deque()  # 存 (dp[j-1] + prices[j-1], j) = (cost, j)

        for i in range(1, n + 1):
            # 将 j = i 加入队列（j 从 1 到 i）
            # 实际上 j 的范围是 [ceil(i/2), i]
            # 我们在遍历 i 时，同时维护可用的 j

            # 当 i 增大时，j 的下界 ceil(i/2) 也在增大
            # 用单调队列：先移除不在 [ceil(i/2), i] 范围的 j

            # 先加入 j = i
            cost_j = dp[i - 1] + prices[i - 1]
            while dq and dq[-1][0] >= cost_j:
                dq.pop()
            dq.append((cost_j, i))

            # 移除 j < ceil(i/2) 的元素
            lo = (i + 1) // 2  # ceil(i/2)
            while dq and dq[0][1] < lo:
                dq.popleft()

            dp[i] = dq[0][0]

        return dp[n]
```

### 方法二：暴力 DP（n<=1000 可用）

```python
from typing import List

class Solution:
    def minimumCoins(self, prices: List[int]) -> int:
        n = len(prices)
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            # 买第 j 种水果（j <= i），免费到 j+j
            # 若 j+j >= i，则可以覆盖到 i
            lo = (i + 1) // 2  # 最小的 j，使得 j+j >= i
            for j in range(lo, i + 1):
                dp[i] = min(dp[i], dp[j - 1] + prices[j - 1])

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n)（方法一，单调队列）；O(n^2)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 买第 j 种水果（1-indexed），覆盖范围 [j+1, 2j]（免费）
2. dp[i] 的有效转移来自 j in [ceil(i/2), i]
3. 单调队列维护滑动窗口最小值

## 易错点

1. 下界 ceil(i/2) = (i+1)//2（Python 整数向上取整）
2. dp 下标从 0 开始（dp[0] = 0），prices 下标从 0 开始，但题意是 1-indexed
3. 单调队列需要按 j 的顺序维护
