## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，其中 `nums.length == 2^n`。

对数组执行以下操作直到数组只有**一个元素**：
- 创建一个新数组 `newNums`，长度为 `nums.length / 2`。
- 对每个偶数下标 `i`：`newNums[i/2] = min(nums[i], nums[i+1])`。
- 对每个奇数下标 `i`：`newNums[i/2] = max(nums[i], nums[i+1])`。
- 用 `newNums` 替换 `nums`。

返回最终数组中**唯一**的元素。

**示例 1：**
```
输入：nums = [1,3,5,2,4,8,2,2]
输出：1
```

**示例 2：**
```
输入：nums = [3]
输出：3
```

## 解题思路

直接模拟：反复执行上述操作，直到数组长度为 1。每轮将数组长度减半。

## 代码实现

### 方法一：原地模拟（推荐）

```python
from typing import List

class Solution:
    def minMaxGame(self, nums: List[int]) -> int:
        while len(nums) > 1:
            new_nums = []
            for i in range(0, len(nums), 2):
                idx = i // 2  # 新数组下标
                if idx % 2 == 0:
                    new_nums.append(min(nums[i], nums[i + 1]))
                else:
                    new_nums.append(max(nums[i], nums[i + 1]))
            nums = new_nums
        return nums[0]
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def minMaxGame(self, nums: List[int]) -> int:
        while len(nums) > 1:
            # 偶数新下标用 min，奇数新下标用 max
            nums = [
                (min if (i // 2) % 2 == 0 else max)(nums[i], nums[i + 1])
                for i in range(0, len(nums), 2)
            ]
        return nums[0]
```

## 复杂度分析

- 时间复杂度：O(n)，每轮减半，共 log n 轮，总操作 n + n/2 + ... = O(n)。
- 空间复杂度：O(n)，新数组。

## 关键点总结

1. 每轮操作：相邻两元素按新下标的奇偶性取 min 或 max。
2. 关键：是**新数组下标** `i/2` 的奇偶性，不是原数组下标 `i` 的奇偶性。
3. 数组长度为 2^n，操作 n 次后变为 1。

## 易错点

- 区分新下标和原下标：`idx = i // 2`，判断 `idx % 2` 而非 `i % 2`。
- 每对 `(nums[i], nums[i+1])` 步长为 2，`range(0, len(nums), 2)`。
