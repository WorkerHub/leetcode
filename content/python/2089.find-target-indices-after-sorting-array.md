## 题目描述

给你一个整数数组 `nums` 和整数 `target`，将 `nums` 排序后，返回 `target` 在排序后数组中的**所有下标**（按升序排列）。

**示例：**
```
输入：nums = [1,2,5,2,3], target = 2
输出：[1,2]
解释：排序后 [1,2,2,3,5]，target 2 在下标 1 和 2
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i], target <= 100`

## 解题思路

**方法一：** 排序后遍历找到所有等于 target 的下标。

**方法二（数学）：** 不需要真正排序。target 在排序后的下标等于比 target 小的元素个数（设为 less），从 less 到 less + count - 1（count 为 target 的个数）。

## 代码实现

### 方法一：排序后遍历（推荐）

```python
from typing import List

class Solution:
    def targetIndices(self, nums: List[int], target: int) -> List[int]:
        nums.sort()
        return [i for i, v in enumerate(nums) if v == target]
```

### 方法二：计数（不排序）

```python
from typing import List

class Solution:
    def targetIndices(self, nums: List[int], target: int) -> List[int]:
        less = sum(1 for x in nums if x < target)   # 比 target 小的元素数
        count = sum(1 for x in nums if x == target)  # target 的个数

        return list(range(less, less + count))
```

### 方法三：二分查找

```python
from typing import List
import bisect

class Solution:
    def targetIndices(self, nums: List[int], target: int) -> List[int]:
        nums.sort()
        left = bisect.bisect_left(nums, target)
        right = bisect.bisect_right(nums, target)
        return list(range(left, right))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序遍历 | O(n log n) | O(1) |
| 计数 | O(n) | O(1) |
| 二分查找 | O(n log n) | O(1) |

## 关键点总结

1. 最简洁：`sorted(nums).index(target)` 不行（只返回第一个），需要找所有位置
2. 计数方法最优：O(n) 时间，统计小于 target 的个数即为起始下标
3. 二分查找在有序数组上直接找左右边界

## 易错点

- 注意返回的是下标列表而不是单个值
- 如果 target 不在数组中，返回空列表
