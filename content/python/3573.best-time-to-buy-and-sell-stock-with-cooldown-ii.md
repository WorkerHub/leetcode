## 题目描述

给定股票价格数组 `prices`，可以多次买卖，但卖出后必须等待至少 `k` 天才能再次买入（冷冻期为 k 天）。求最大利润。

**示例 1：**

```
输入：prices = [1, 2, 3, 0, 2], k = 1
输出：3
解释：第1天买入，第3天卖出（利润2），冷冻1天，第5天买入卖出（利润2），但第4天也可以买入...
     实际最优：第1天买入，第3天卖出利润2，冷冻1天，第5天不能再操作或买入。
```

**示例 2：**

```
输入：prices = [1, 3, 1, 3, 5], k = 2
输出：4
```

**提示：**
- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`
- `1 <= k <= prices.length`

## 解题思路

动态规划，状态：
- `hold[i]`：第 i 天持有股票时的最大利润
- `sold[i]`：第 i 天刚卖出股票时的最大利润
- `cool[i]`：第 i 天处于冷冻期（或休息）时的最大利润

状态转移：
- `hold[i] = max(hold[i-1], cool[i-1] - prices[i])`（继续持有或买入）
- `sold[i] = hold[i-1] + prices[i]`（今天卖出）
- `cool[i] = max(cool[i-1], sold[i-k])`（冷冻 k 天后恢复）

当冷冻期为 k 时，卖出后需等 k 天才能买入，即第 i 天卖出后，第 `i+k+1` 天才能买入。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], k: int) -> int:
        n = len(prices)
        if n <= 1:
            return 0

        # hold[i]: 第 i 天持有股票时的最大利润
        # free[i]: 第 i 天不持有股票且可以买入时的最大利润
        # 卖出后需要等 k 天

        # 简化：三状态 DP
        # hold = 持有股票
        # sold = 刚卖出（今天卖的）
        # rest = 休息/冷冻中

        # 扩展冷冻期为 k
        INF = float('-inf')
        # sold[j] = j 天前卖出（j = 0,1,...,k）
        sold = [INF] * (k + 1)  # sold[j] = j 天前卖出时的利润
        hold = INF
        rest = 0

        for price in prices:
            # 今天的状态
            new_hold = max(hold, rest - price)  # 继续持有或今天买入
            new_sold_today = hold + price  # 今天卖出
            # 更新 sold 队列（向后移一位）
            new_rest = max(rest, sold[-1])  # 冷冻 k 天后恢复

            sold = [new_sold_today] + sold[:-1]
            hold = new_hold
            rest = new_rest

        return max(rest, sold[-1] if sold[-1] != INF else 0)
```

### 方法二：滚动数组 DP

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], k: int) -> int:
        n = len(prices)
        INF = float('-inf')

        # dp[i][0] = 第 i 天不持有（且不在冷冻期）的最大利润
        # dp[i][1] = 第 i 天持有股票的最大利润
        # 冷冻期：卖出后 k 天不能买入

        hold = INF
        free = [0] * (n + k + 1)  # free[i] = 第 i 天不持有且可以买入的最大利润

        for i in range(n):
            new_hold = max(hold, free[i] - prices[i])
            sold_today = hold + prices[i] if hold != INF else INF
            free[i + k + 1] = max(free[i + k], sold_today if sold_today != INF else 0)
            hold = new_hold

        return max(free[n:n+k+1])
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(k)，冷冻期队列

## 关键点总结

1. 卖出后需等 k 天（冷冻期）才能再次买入
2. 用滑动窗口或队列维护 k 天前的卖出状态
3. 三状态 DP：持有、刚卖出、冷冻/休息

## 易错点

1. 冷冻期是 k 天（不是 k-1 天），卖出后第 k+1 天才能买入
2. 初始状态：第 0 天不持有，利润为 0
3. 持有股票的初始值为负无穷（未买入）
