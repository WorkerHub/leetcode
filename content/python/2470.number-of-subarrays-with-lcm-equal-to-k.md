## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回 `nums` 的子数组中，元素的最小公倍数等于 `k` 的子数组数目。

子数组是数组中一个连续非空的元素序列。

**示例 1：**
```
输入：nums = [3,6,2,7,1], k = 6
输出：4
解释：以 6 为 LCM 的子数组为 [3,6]、[6]、[6,2]、[3,6,2]。
```

**示例 2：**
```
输入：nums = [3], k = 2
输出：0
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i], k <= 1000`

## 解题思路

枚举所有子数组，维护当前子数组的 LCM。利用 LCM 的单调性（只增不减）进行剪枝。

**关键性质：**
- 子数组 LCM 随右端点增大单调不减
- 若当前 LCM > k，后续加入更多元素只会使 LCM 更大（不可能等于 k）

## 代码实现

### 方法一：枚举子数组（推荐）

```python
from typing import List
import math

class Solution:
    def subarrayLCM(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            cur_lcm = 1
            for j in range(i, n):
                cur_lcm = cur_lcm * nums[j] // math.gcd(cur_lcm, nums[j])
                if cur_lcm == k:
                    ans += 1
                elif cur_lcm > k:
                    break  # LCM 只增不减，超过 k 则跳出

        return ans
```

### 方法二：利用 LCM 状态数少的特性

```python
from typing import List
import math
from collections import defaultdict

class Solution:
    def subarrayLCM(self, nums: List[int], k: int) -> int:
        # 以某位置结尾，不同 LCM 值的数量不超过 O(log(k)) 种
        ans = 0
        prev = defaultdict(int)  # {lcm: 该 lcm 对应的子数组数量}

        for x in nums:
            if k % x != 0:
                # x 不是 k 的因子，包含 x 的子数组 LCM 不可能等于 k
                prev = defaultdict(int)
                continue

            new_prev = defaultdict(int)
            new_prev[x] += 1  # 单个元素 x

            for lcm, cnt in prev.items():
                new_lcm = lcm * x // math.gcd(lcm, x)
                if k % new_lcm == 0:  # 剪枝：只保留 k 的因子
                    new_prev[new_lcm] += cnt

            ans += new_prev[k]
            prev = new_prev

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举子数组 | O(n^2 * log(max_val)) | O(1) |
| 优化方法 | O(n * log(k)^2) | O(log(k)) |

## 关键点总结

1. LCM 单调不减（子数组越长，LCM 越大或不变）
2. 超过 k 时提前终止枚举
3. `k % x != 0` 时包含 x 的任何子数组 LCM 都不等于 k（因为 LCM 是 x 的倍数）

## 易错点

- LCM 计算：`lcm(a, b) = a * b // gcd(a, b)`
- 中间值可能超过 k，但超过后不能再减小，可以 break
