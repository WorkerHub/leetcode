## 题目描述

给定一个正整数 `a`，找出最小的正整数 `b`，使得 `b` 的各位数字相乘等于 `a`。

如果无解，或者答案不符合 32 位有符号整数，则返回 0。

**示例 1：**

```
输入：a = 48
输出：68
解释：48 = 6 × 8，所以 68 的各位数字相乘等于 48
```

**示例 2：**

```
输入：a = 15
输出：35
解释：15 = 3 × 5，所以 35 的各位数字相乘等于 15
```

**示例 3：**

```
输入：a = 1
输出：1
```

**示例 4：**

```
输入：a = 13
输出：0
解释：13 是质数，无法分解为单个数字的乘积
```

**提示：**
- `1 <= a <= 10^9`

## 解题思路

这道题的核心是将数字 `a` 分解为尽可能多的单个数字（2-9）的乘积，并且这些数字组成的数要最小。

**关键观察：**

1. **数字范围**：只能使用 2-9 的数字（1 无意义，0 会让乘积为 0）
2. **贪心策略**：为了让结果最小，应该：
   - 使用的数字尽可能少（位数少）
   - 数字按升序排列（高位小）
3. **分解方法**：从大到小（9 到 2）尝试分解，优先使用大的因子
   - 使用大因子可以减少位数
   - 最后倒序排列得到最小的数

**算法步骤：**

1. 特殊情况：`a < 2` 时，直接返回 `a`
2. 从 9 到 2 遍历，尝试分解 `a`：
   - 如果 `a % i == 0`，记录因子 `i`，并更新 `a = a / i`
   - 重复直到无法整除
3. 如果最后 `a > 1`，说明 `a` 包含大于 9 的质因子，无解
4. 将记录的因子按升序排列，组成最小的数
5. 检查是否超过 32 位整数范围

**为什么从大到小分解？**

例如 `a = 24`：
- 分解：24 = 8 × 3 = 2 × 2 × 2 × 3
- 从大到小：24 / 8 = 3，得到 [8, 3] → 38
- 从小到大：24 / 2 = 12 / 2 = 6 / 2 = 3，得到 [2, 2, 2, 3] → 2223
- 显然 38 < 2223

## Python 代码实现

### 方法一：贪心分解（推荐）

```python
class Solution:
    def smallestFactorization(self, a: int) -> int:
        """
        找出各位数字乘积等于 a 的最小正整数
        
        参数:
            a: 目标数字
        
        返回:
            最小的正整数 b，如果无解返回 0
        """
        # 特殊情况
        if a < 2:
            return a
        
        # 记录因子（从大到小分解，最后倒序）
        factors = []
        
        # 从 9 到 2 尝试分解
        for digit in range(9, 1, -1):
            while a % digit == 0:
                factors.append(digit)
                a //= digit
        
        # 如果 a > 1，说明有大于 9 的质因子，无解
        if a > 1:
            return 0
        
        # 倒序排列得到最小的数
        factors.reverse()
        
        # 组成结果
        result = 0
        for factor in factors:
            result = result * 10 + factor
        
        # 检查是否超过 32 位整数
        if result > 2**31 - 1:
            return 0
        
        return result
```

**时间复杂度：** O(log a)，最多分解 O(log a) 次  
**空间复杂度：** O(log a)，存储因子

### 方法二：简化版本

```python
class Solution:
    def smallestFactorization(self, a: int) -> int:
        """简化版本，直接构造结果"""
        if a < 2:
            return a
        
        result = 0
        multiplier = 1  # 当前位的权重（个位、十位、百位...）
        
        # 从小到大（2 到 9）查找因子，构造最小数
        for digit in range(9, 1, -1):
            while a % digit == 0:
                # 在最低位添加因子（因为从大到小遍历，倒序添加）
                result = digit * multiplier + result
                multiplier *= 10
                a //= digit
        
        # 检查是否有剩余或超出范围
        if a > 1 or result > 2**31 - 1:
            return 0
        
        return result
```

### 方法三：使用字符串拼接

```python
class Solution:
    def smallestFactorization(self, a: int) -> int:
        """使用字符串拼接，更直观"""
        if a < 2:
            return a
        
        digits = []
        
        for d in range(9, 1, -1):
            while a % d == 0:
                digits.append(str(d))
                a //= d
        
        if a > 1:
            return 0
        
        # 倒序拼接
        result_str = ''.join(reversed(digits))
        result = int(result_str)
        
        return result if result <= 2**31 - 1 else 0
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(log a)，每次分解至少减少一个因子
- 空间复杂度：O(log a)，存储因子列表

## 图解示例

以 `a = 48` 为例：

```
初始：a = 48，factors = []

步骤 1：尝试 digit = 9
48 % 9 ≠ 0，跳过

步骤 2：尝试 digit = 8
48 % 8 = 0 ✓
factors = [8]
a = 48 / 8 = 6

步骤 3：继续 digit = 8
6 % 8 ≠ 0，跳过

步骤 4：尝试 digit = 7
6 % 7 ≠ 0，跳过

步骤 5：尝试 digit = 6
6 % 6 = 0 ✓
factors = [8, 6]
a = 6 / 6 = 1

步骤 6：a = 1，分解完成
factors = [8, 6]

步骤 7：倒序排列
factors.reverse() → [6, 8]

步骤 8：组成数字
result = 6 * 10 + 8 = 68

检查范围：68 <= 2^31 - 1 ✓

输出：68
```

**为什么不是 48？**

```
如果用 4 和 8 分解：
48 = 4 × 12（12 > 9，无法继续）
48 = 6 × 8 ✓（都是单个数字）
或 48 = 2 × 2 × 2 × 2 × 3 → 22223（更大）

所以 68 是最小的
```

## 关键点总结

1. **贪心思想**：从大到小分解，减少位数
2. **倒序排列**：分解后的因子倒序排列才能得到最小数
3. **质因子检查**：如果最后 `a > 1`，说明有大于 9 的质因子
4. **范围检查**：结果要在 32 位有符号整数范围内
5. **特殊情况**：`a = 1` 直接返回 1

## 易错点

1. **忘记倒序**：
   ```python
   # 错误：直接使用 factors
   for factor in factors:
       result = result * 10 + factor
   
   # 正确：先倒序
   factors.reverse()
   for factor in factors:
       result = result * 10 + factor
   ```

2. **范围判断**：32 位有符号整数的最大值是 `2^31 - 1 = 2147483647`

3. **质因子判断**：
   ```python
   # 错误：忘记检查 a
   return result
   
   # 正确：检查是否完全分解
   if a > 1:
       return 0
   ```

4. **特殊值**：`a = 1` 返回 1，`a = 10` 无解（包含因子 5×2，但 10 不是单个数字）

5. **分解顺序**：必须从 9 到 2，而不是从 2 到 9

## 扩展思考

**为什么一定要从 9 到 2？**

因为要让结果最小：
- 位数最少：使用大因子可以减少位数
- 高位最小：倒序后大因子在低位，小因子在高位

例如 `a = 24`：
- 方案 1：2 × 2 × 2 × 3 = [2,2,2,3] → 2223（4 位）
- 方案 2：8 × 3 = [8,3] → 38（2 位）✓
- 方案 3：6 × 4 = [6,4] → 46
- 方案 4：6 × 2 × 2 = [6,2,2] → 226

显然方案 2 最小。

**如果题目改为求最大的数？**

那就不用倒序，直接按分解顺序（9 到 2）拼接：
```python
result = int(''.join(map(str, factors)))  # 不倒序
```
