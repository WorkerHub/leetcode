## 题目描述

有 n 盏灯，编号从 1 到 n，初始时所有灯都是开着的。

有 4 个按钮，每个按钮的功能如下：
1. 翻转所有灯的状态
2. 翻转编号为偶数的灯的状态
3. 翻转编号为奇数的灯的状态
4. 翻转编号为 3k+1 的灯的状态（k = 0, 1, 2, ...），即 1, 4, 7, 10, ...

给定 n 和 presses（按钮按压次数），返回 presses 次按压后，可能的灯状态数量。

**示例 1：**
```
输入：n = 1, presses = 1
输出：2
解释：
初始状态：[开]
按按钮1：[关]
只有2种可能状态
```

**示例 2：**
```
输入：n = 2, presses = 1
输出：3
解释：
初始状态：[开, 开]
按按钮1：[关, 关]
按按钮2：[开, 关]
按按钮3：[关, 开]
有3种可能状态
```

**示例 3：**
```
输入：n = 3, presses = 1
输出：4
```

**提示：**
- 1 <= n <= 1000
- 0 <= presses <= 1000

## 解题思路

这是一道数学 + 状态分析题，关键是找到规律。

**核心观察：**
1. 按同一个按钮两次等于没按（异或性质）
2. 按钮顺序不影响结果（交换律）
3. 只需考虑每个按钮按0次或1次
4. 前3个灯的状态可以代表整个序列的状态

**重要规律：**
- n >= 3 时，只需看前3个灯的状态
- presses >= 3 时，相当于每个按钮可以任意选择按或不按
- 总共有 2^4 = 16 种按钮组合

**特殊情况分析：**
- presses = 0：只有1种状态（全开）
- presses = 1：最多4种状态（按4个按钮之一）
- presses = 2：7种状态
- presses >= 3：所有可能的有效状态

## Python 代码实现

### 方法一：数学分析（推荐）⭐

```python
class Solution:
    def flipLights(self, n: int, presses: int) -> int:
        # 特殊情况处理
        if presses == 0:
            return 1
        
        if n == 1:
            # 只有1个灯，按钮1和3效果相同，按钮2和4无效
            return 2
        
        if n == 2:
            if presses == 1:
                return 3  # 按1、2、3的效果（按4无效）
            else:
                return 4  # presses >= 2
        
        # n >= 3
        if presses == 1:
            return 4
        elif presses == 2:
            return 7
        else:
            return 8
```

### 方法二：枚举所有状态

```python
class Solution:
    def flipLights(self, n: int, presses: int) -> int:
        # 只需考虑前3个灯
        n = min(n, 3)
        states = set()
        
        # 枚举所有按钮组合（每个按钮按0或1次）
        for mask in range(16):  # 2^4 = 16
            # 计算按了几个按钮
            count = bin(mask).count('1')
            
            # 按钮次数的奇偶性必须匹配
            if count % 2 != presses % 2:
                continue
            
            # 如果按钮次数超过presses，跳过
            if count > presses:
                continue
            
            # 计算前n个灯的状态
            lights = [1] * n  # 初始全开
            
            if mask & 1:  # 按钮1
                for i in range(n):
                    lights[i] ^= 1
            
            if mask & 2:  # 按钮2
                for i in range(1, n, 2):  # 偶数位（索引1）
                    lights[i] ^= 1
            
            if mask & 4:  # 按钮3
                for i in range(0, n, 2):  # 奇数位（索引0）
                    lights[i] ^= 1
            
            if mask & 8:  # 按钮4
                for i in range(0, n, 3):  # 1, 4, 7, ...（索引0, 3, 6...）
                    lights[i] ^= 1
            
            states.add(tuple(lights))
        
        return len(states)
```

## 关键点总结

1. **异或性质**：按两次等于不按
2. **前缀代表**：前3个灯的状态可以代表整个序列
3. **奇偶性**：按钮次数的奇偶性很重要
4. **上界分析**：presses >= 3 时达到最大状态数
5. **分类讨论**：按 n 和 presses 的大小分情况

## 易错点

1. **状态爆炸**：不要真的模拟所有可能，用数学规律
2. **重复状态**：不同按钮组合可能产生相同状态
3. **奇偶性**：presses=2 不能通过按一个按钮两次实现
4. **n的影响**：n=1,2,3 有不同规律，n>=3 后规律稳定
5. **按钮效果**：要理解每个按钮影响哪些灯
