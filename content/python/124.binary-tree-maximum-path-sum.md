## 题目描述

二叉树中的路径被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。

路径和是路径中各节点值的总和。

给你一个二叉树的根节点 `root`，返回其最大路径和。

**示例 1：**

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

**示例 2：**

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42
```

**提示：**

- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

## 解题思路

这是一道经典的树形 DP 问题，难点在于理解路径的定义和如何处理负数节点。

**核心思想：**

1. **路径的定义**：
   - 路径可以从任意节点开始，到任意节点结束
   - 路径不一定经过根节点
   - 路径至少包含一个节点

2. **递归思路**：
   - 对于每个节点，计算以该节点为"最高点"的路径最大和
   - 以节点为最高点的路径 = 左子树贡献 + 节点值 + 右子树贡献
   - 向上传递时，只能选择左或右其中一条路径（不能分叉）

3. **负数处理**：
   - 如果子树的贡献为负数，可以选择不要该子树（贡献为 0）
   - 这样可以避免负数降低路径和

**关键观察：**

- 对于每个节点，有两种情况：
  1. 该节点作为路径的"最高点"（左子树 + 节点 + 右子树）
  2. 该节点作为路径的一部分，向上传递（节点 + max(左子树, 右子树)）

## Python 代码实现

### 方法一：后序遍历 + 全局变量（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.max_sum = float('-inf')
        
        def max_gain(node: Optional[TreeNode]) -> int:
            """返回以 node 为起点的单边路径最大和"""
            if not node:
                return 0
            
            # 递归计算左右子树的最大贡献
            # 如果贡献为负，则不选择该子树（贡献为 0）
            left_gain = max(max_gain(node.left), 0)
            right_gain = max(max_gain(node.right), 0)
            
            # 以当前节点为"最高点"的路径和
            path_sum = node.val + left_gain + right_gain
            
            # 更新全局最大路径和
            self.max_sum = max(self.max_sum, path_sum)
            
            # 向上传递时，只能选择左或右其中一条路径
            return node.val + max(left_gain, right_gain)
        
        max_gain(root)
        return self.max_sum
```

### 方法二：使用列表存储结果（避免全局变量）

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        def max_gain(node: Optional[TreeNode], max_sum: list) -> int:
            if not node:
                return 0
            
            # 计算左右子树的贡献
            left_gain = max(max_gain(node.left, max_sum), 0)
            right_gain = max(max_gain(node.right, max_sum), 0)
            
            # 更新最大路径和
            path_sum = node.val + left_gain + right_gain
            max_sum[0] = max(max_sum[0], path_sum)
            
            # 返回单边最大路径
            return node.val + max(left_gain, right_gain)
        
        max_sum = [float('-inf')]
        max_gain(root, max_sum)
        return max_sum[0]
```

### 方法三：使用类封装

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        class Result:
            def __init__(self):
                self.max_sum = float('-inf')
        
        result = Result()
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            
            left = max(dfs(node.left), 0)
            right = max(dfs(node.right), 0)
            
            # 更新最大路径和
            result.max_sum = max(result.max_sum, node.val + left + right)
            
            # 返回单边路径
            return node.val + max(left, right)
        
        dfs(root)
        return result.max_sum
```

### 方法四：返回两个值（路径和、单边最大值）

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode]) -> tuple:
            """返回 (以node为最高点的路径最大和, 以node为起点的单边最大和)"""
            if not node:
                return float('-inf'), 0
            
            # 递归左右子树
            left_path, left_gain = dfs(node.left)
            right_path, right_gain = dfs(node.right)
            
            # 计算左右的正贡献
            left_gain = max(left_gain, 0)
            right_gain = max(right_gain, 0)
            
            # 以当前节点为最高点的路径和
            curr_path = node.val + left_gain + right_gain
            
            # 单边最大和
            curr_gain = node.val + max(left_gain, right_gain)
            
            # 最大路径和（考虑左右子树的情况）
            max_path = max(curr_path, left_path, right_path)
            
            return max_path, curr_gain
        
        max_path, _ = dfs(root)
        return max_path
```

### 方法五：迭代实现（较复杂，不推荐）

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        max_sum = float('-inf')
        node_gain = {}  # 存储每个节点的单边最大贡献
        
        # 后序遍历
        stack = []
        prev = None
        curr = root
        
        while curr or stack:
            # 遍历到最左
            while curr:
                stack.append(curr)
                curr = curr.left
            
            curr = stack[-1]
            
            # 如果右子树不存在或已访问，处理当前节点
            if not curr.right or curr.right == prev:
                stack.pop()
                
                # 计算左右贡献
                left_gain = max(node_gain.get(curr.left, 0), 0)
                right_gain = max(node_gain.get(curr.right, 0), 0)
                
                # 更新最大路径和
                path_sum = curr.val + left_gain + right_gain
                max_sum = max(max_sum, path_sum)
                
                # 存储单边贡献
                node_gain[curr] = curr.val + max(left_gain, right_gain)
                
                prev = curr
                curr = None
            else:
                # 访问右子树
                curr = curr.right
        
        return max_sum
```

## 复杂度分析

**方法一、二、三、四：递归**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈的深度，h 为树的高度

**方法五：迭代**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要栈和哈希表

## 关键点总结

1. **路径理解**：路径可以从任意节点到任意节点，不一定经过根
2. **分叉问题**：节点作为"最高点"时可以包含左右子树，向上传递时只能选一边
3. **负数处理**：贡献为负时不选择该子树（max(gain, 0)）
4. **后序遍历**：需要先计算子树的结果，再处理当前节点
5. **全局最大值**：在递归过程中不断更新全局最大路径和

## 易错点

1. **忘记处理负数**：没有用 `max(gain, 0)` 处理负贡献
2. **返回值错误**：向上返回时应该是单边最大值，不是路径和
3. **初始化错误**：`max_sum` 应初始化为负无穷，不是 0（因为可能全是负数）
4. **理解路径**：路径是连续的，不能跳跃节点
5. **遍历顺序**：必须用后序遍历，因为需要先知道子树的结果

## 图解示例

```
示例：[-10, 9, 20, null, null, 15, 7]

        -10
        /  \
       9   20
          /  \
         15   7

递归过程（后序遍历）：

1. 节点 15：
   - left_gain = 0, right_gain = 0
   - path_sum = 15
   - 返回 15

2. 节点 7：
   - left_gain = 0, right_gain = 0
   - path_sum = 7
   - 返回 7

3. 节点 20：
   - left_gain = max(15, 0) = 15
   - right_gain = max(7, 0) = 7
   - path_sum = 20 + 15 + 7 = 42（最大！）
   - 返回 20 + max(15, 7) = 35

4. 节点 9：
   - left_gain = 0, right_gain = 0
   - path_sum = 9
   - 返回 9

5. 节点 -10：
   - left_gain = max(9, 0) = 9
   - right_gain = max(35, 0) = 35
   - path_sum = -10 + 9 + 35 = 34
   - 返回 -10 + max(9, 35) = 25

最大路径和 = 42（路径：15 -> 20 -> 7）
```

## 为什么要取 max(gain, 0)？

```
如果不处理负数：

        5
       / \
     -3  -2

不取 max：
left_gain = -3, right_gain = -2
path_sum = 5 + (-3) + (-2) = 0

取 max：
left_gain = max(-3, 0) = 0
right_gain = max(-2, 0) = 0
path_sum = 5 + 0 + 0 = 5

显然，不选择负贡献的子树更优。
```
