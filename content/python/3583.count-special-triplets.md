## 题目描述

给定一个整数数组 `nums`。定义"特殊三元组"：下标 `i < j < k`，满足 `nums[i] == nums[j] / 2` 且 `nums[k] == nums[j] * 2`（即 nums[j] 是 nums[i] 的两倍，nums[k] 是 nums[j] 的两倍）。求特殊三元组的数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：nums = [1, 2, 4, 8]
输出：1
解释：三元组 (0,1,2)：1, 2, 4 满足 2=1*2, 4=2*2。
```

**示例 2：**

```
输入：nums = [1, 2, 4, 2, 4]
输出：3
解释：多个满足条件的三元组。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

枚举中间元素 `nums[j]`，统计左边有多少个 `nums[j]/2`，右边有多少个 `nums[j]*2`。

对每个位置 `j`：
- 左侧 `nums[j]/2` 的个数：`left[nums[j]/2]`
- 右侧 `nums[j]*2` 的个数：`right[nums[j]*2]`
- 贡献 = `left * right`

可以预计算右侧频次，然后从左到右遍历，边更新左侧频次边计算。

## Python 代码实现

### 方法一：枚举中间元素（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countSpecialTriplets(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # 预计算右侧频次
        right = Counter(nums)
        left = Counter()
        result = 0

        for x in nums:
            # 以 x 为中间元素
            right[x] -= 1

            # nums[j] = x，需要 nums[i] = x/2（x 必须是偶数），nums[k] = x*2
            if x % 2 == 0:
                half = x // 2
                double = x * 2
                result = (result + left[half] * right[double]) % MOD

            # 更新左侧
            left[x] += 1

        return result
```

### 方法二：哈希表预处理

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSpecialTriplets(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # 统计每个值的所有位置
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)

        result = 0
        for j in range(n):
            x = nums[j]
            if x % 2 != 0:
                continue
            half = x // 2
            double = x * 2
            # 统计 j 左边的 half 个数
            left_count = sum(1 for p in pos[half] if p < j)
            # 统计 j 右边的 double 个数
            right_count = sum(1 for p in pos[double] if p > j)
            result = (result + left_count * right_count) % MOD

        return result
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 枚举中间元素，统计左右两侧满足条件的元素数量
2. 先预计算右侧频次，遍历时动态更新左侧频次
3. 中间元素必须是偶数（`nums[j]/2` 需为整数）

## 易错点

1. `nums[j]` 必须是偶数，才能有 `nums[i] = nums[j]/2`（整数）
2. 右侧频次在遍历前需要先减去当前元素（排除 j 本身）
3. 结果需要对 `10^9 + 7` 取模
