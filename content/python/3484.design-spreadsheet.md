## 题目描述

设计一个电子表格，支持以下操作：

- `Spreadsheet(int rows)`：初始化 `rows` 行、26 列（A-Z）的表格，初始值均为 0
- `void setCell(String cell, int value)`：将单元格 `cell`（如 "A1"）的值设为 `value`
- `void resetCell(String cell)`：将单元格重置为 0
- `int getValue(String formula)`：计算公式的值。公式是形如 `"=A1+B2+3+..."` 的字符串，包含单元格引用和整数之和

**示例：**

```
Spreadsheet sp = new Spreadsheet(3);
sp.setCell("A1", 5);
sp.setCell("B2", 3);
sp.getValue("=A1+B2+10"); // 返回 18
sp.resetCell("A1");
sp.getValue("=A1+B2");    // 返回 3
```

**提示：**
- `1 <= rows <= 9`（行号为 1-9）
- 单元格格式：一个大写字母 + 一个数字
- 公式以 `=` 开头，各项以 `+` 分隔

## 解题思路

用哈希表存储非零单元格的值。解析公式时，按 `+` 分割，判断每个 token 是单元格引用还是整数。

## Python 代码实现

### 方法一：哈希表 + 公式解析（推荐）

```python
class Spreadsheet:

    def __init__(self, rows: int):
        self.cells = {}  # cell_name -> value
        self.rows = rows

    def setCell(self, cell: str, value: int) -> None:
        self.cells[cell] = value

    def resetCell(self, cell: str) -> None:
        self.cells.pop(cell, None)

    def getValue(self, formula: str) -> int:
        # 去掉开头的 '='
        expr = formula[1:]
        tokens = expr.split('+')
        total = 0
        for token in tokens:
            if token and token[0].isupper():
                # 单元格引用
                total += self.cells.get(token, 0)
            else:
                # 整数
                total += int(token)
        return total
```

### 方法二：二维数组存储

```python
class Spreadsheet:

    def __init__(self, rows: int):
        self.rows = rows
        # 26 列（A-Z），行从 1 开始
        self.data = [[0] * 26 for _ in range(rows + 1)]

    def _parse_cell(self, cell: str):
        col = ord(cell[0]) - ord('A')
        row = int(cell[1:])
        return row, col

    def setCell(self, cell: str, value: int) -> None:
        row, col = self._parse_cell(cell)
        self.data[row][col] = value

    def resetCell(self, cell: str) -> None:
        row, col = self._parse_cell(cell)
        self.data[row][col] = 0

    def getValue(self, formula: str) -> int:
        expr = formula[1:]
        total = 0
        for token in expr.split('+'):
            if token and token[0].isupper():
                row, col = self._parse_cell(token)
                total += self.data[row][col]
            else:
                total += int(token)
        return total
```

### 方法三：正则解析公式

```python
import re

class Spreadsheet:

    def __init__(self, rows: int):
        self.cells = {}

    def setCell(self, cell: str, value: int) -> None:
        self.cells[cell] = value

    def resetCell(self, cell: str) -> None:
        if cell in self.cells:
            del self.cells[cell]

    def getValue(self, formula: str) -> int:
        # 提取所有 token
        tokens = re.split(r'\+', formula[1:])
        total = 0
        for t in tokens:
            if re.match(r'^[A-Z]\d+$', t):
                total += self.cells.get(t, 0)
            elif t.isdigit():
                total += int(t)
        return total
```

## 复杂度分析

- setCell/resetCell：O(1)
- getValue：O(L)，L 为公式长度
- 空间复杂度：O(n)，n 为非零单元格数量

## 关键点总结

1. 哈希表存储非零单元格，节省空间
2. 公式解析：以 `+` 分割，区分单元格引用和整数
3. 单元格引用识别：首字符为大写字母

## 易错点

1. 公式以 `=` 开头，解析时要跳过
2. 重置单元格后值为 0，getValue 中未找到的单元格也为 0
3. 单元格引用可能是多位行号（如 "A12"），但题目限制行 <= 9，可用简单判断
