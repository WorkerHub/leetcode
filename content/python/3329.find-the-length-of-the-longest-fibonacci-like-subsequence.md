## 题目描述

给你一个**严格递增**的正整数数组 `arr`。

如果一个序列 `x_1, x_2, ..., x_k` 满足 `x_{i+2} = x_i + x_{i+1}`（i >= 1）且 k >= 3，则称它为**类斐波那契序列**。

返回 `arr` 中最长的类斐波那契子序列的长度，若不存在返回 0。

**示例：**
```
输入：arr = [1, 2, 3, 4, 5, 6, 7, 8]
输出：5
解释：[1, 2, 3, 5, 8] 是最长的类斐波那契子序列
```

**提示：**
- `3 <= arr.length <= 1000`
- `1 <= arr[i] < arr[i+1] <= 10^9`

## 解题思路

**动态规划 + 哈希表：**

定义 `dp[i][j]` = 以 `arr[i]` 和 `arr[j]`（`i < j`）结尾的类斐波那契子序列的最长长度。

初始状态：`dp[i][j] = 2`（任意两个数都能是序列的末尾两项，但需要长度 >= 3）。

转移：若存在 `arr[k] = arr[j] - arr[i]` 且 `k < i`，则 `dp[i][j] = dp[k][i] + 1`。

使用哈希表存储每个元素的下标，快速查找 `arr[j] - arr[i]` 是否存在。

## Python 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List

class Solution:
    def lenLongestFibSubseq(self, arr: List[int]) -> int:
        n = len(arr)
        index = {val: i for i, val in enumerate(arr)}
        
        # dp[(i,j)] = 以 arr[i], arr[j] 结尾的最长类斐波那契子序列长度
        dp = {}
        ans = 0
        
        for j in range(n):
            for i in range(j):
                # 找 arr[j] - arr[i] 是否在数组中且下标 < i
                prev = arr[j] - arr[i]
                if prev < arr[i] and prev in index:
                    k = index[prev]
                    # dp[(k,i)] + 1
                    dp[(i, j)] = dp.get((k, i), 2) + 1
                    ans = max(ans, dp[(i, j)])
        
        return ans if ans >= 3 else 0
```

### 方法二：二维数组 DP

```python
from typing import List

class Solution:
    def lenLongestFibSubseq(self, arr: List[int]) -> int:
        n = len(arr)
        val_set = set(arr)
        index = {val: i for i, val in enumerate(arr)}
        
        dp = [[0] * n for _ in range(n)]
        ans = 0
        
        for j in range(n):
            for i in range(j):
                diff = arr[j] - arr[i]
                if diff < arr[i] and diff in index:
                    k = index[diff]
                    dp[i][j] = (dp[k][i] if dp[k][i] > 0 else 2) + 1
                    ans = max(ans, dp[i][j])
        
        return ans if ans >= 3 else 0
```

## 复杂度分析

- 时间复杂度：O(n^2)，双重循环
- 空间复杂度：O(n^2)，DP 数组（或字典）

## 关键点总结

1. 对每对 `(i, j)`，通过哈希表 O(1) 查找前驱元素 `arr[j] - arr[i]`。
2. `prev < arr[i]` 保证序列严格递增（`arr` 本身严格递增，所以 `prev = arr[j] - arr[i] < arr[j] - 0 = arr[j]`，但也需要 `prev < arr[i]` 保证前驱小于当前）。
3. 初始长度设为 2（两个元素），满足 3 个才记入答案。

## 易错点

1. 严格递增保证 `arr[j] - arr[i] > 0`，但还需 `arr[j] - arr[i] < arr[i]` 才能保证序列严格递增。
2. DP 值为 0 时表示只有两个元素（长度 2），需要特判加 1。
3. 最终答案需要 >= 3 才有意义。
