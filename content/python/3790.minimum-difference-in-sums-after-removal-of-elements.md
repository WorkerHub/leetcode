## 题目描述

给定长度为 `3n` 的整数数组 `nums`，从数组中移除恰好 `n` 个元素，使得剩余 `2n` 个元素中，前 `n` 个的和与后 `n` 个的和的差（前 n 的和 - 后 n 的和）最小化。

返回该最小差值。

**示例 1：**
```
输入：nums = [3,1,2], n = 1
输出：-1
解释：移除 1 个元素。可以移除 3，剩 [1,2]，差 = 1-2=-1。
     移除 1，剩 [3,2]，差 = 3-2=1。
     移除 2，剩 [3,1]，差 = 3-1=2。
     最小差为 -1。
```

**示例 2：**
```
输入：nums = [7,9,5,8,1,3], n = 2
输出：1
解释：移除 2 个元素，剩 4 个，前 2 个和 - 后 2 个和最小。
```

**提示：**
- `nums.length == 3 * n`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**关键思路：** 用分割点 `k`（`n <= k <= 2n`）将数组分为两部分：
- 前半部分 `nums[0..k-1]` 取最小的 `n` 个元素（前 n 的和）
- 后半部分 `nums[k..3n-1]` 取最大的 `n` 个元素（后 n 的和）

枚举分割点 `k`，对每个 `k`：
- `left[k]` = `nums[0..k-1]` 中最小 `n` 个元素之和
- `right[k]` = `nums[k..3n-1]` 中最大 `n` 个元素之和

答案 = `min(left[k] - right[k]) for k in [n, 2n]`

用最大堆计算前缀最小 n 个和，用最小堆计算后缀最大 n 个和。

## Python 代码实现

### 方法一：堆 + 前后缀（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        total = len(nums)
        n = total // 3
        INF = float('inf')

        # left[i]: nums[0..i-1] 中最小 n 个元素之和（i >= n）
        left = [0] * (total + 1)
        max_heap = []
        cur_sum = 0

        for i in range(n):
            heapq.heappush(max_heap, -nums[i])
            cur_sum += nums[i]

        left[n] = cur_sum

        for i in range(n, 2 * n):
            heapq.heappush(max_heap, -nums[i])
            cur_sum += nums[i]
            # 弹出最大值（堆顶），保持前 n 个最小
            cur_sum += heapq.heappop(max_heap)  # 堆顶是负数，加上等于减去
            left[i + 1] = cur_sum

        # right[i]: nums[i..3n-1] 中最大 n 个元素之和（i <= 2n）
        right = [0] * (total + 1)
        min_heap = []
        cur_sum = 0

        for i in range(total - 1, total - n - 1, -1):
            heapq.heappush(min_heap, nums[i])
            cur_sum += nums[i]

        right[total - n] = cur_sum

        for i in range(total - n - 1, n - 1, -1):
            heapq.heappush(min_heap, nums[i])
            cur_sum += nums[i]
            # 弹出最小值，保持后 n 个最大
            cur_sum -= heapq.heappop(min_heap)
            right[i] = cur_sum

        ans = INF
        for k in range(n, 2 * n + 1):
            ans = min(ans, left[k] - right[k])

        return ans
```

### 方法二：暴力（适合小 n）

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 3
        ans = float('inf')

        for k in range(n, 2 * n + 1):
            left_n = sorted(nums[:k])[:n]
            right_n = sorted(nums[k:])[-n:]
            diff = sum(left_n) - sum(right_n)
            ans = min(ans, diff)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作
- 空间复杂度：O(n)

## 关键点总结

1. 分割点 `k` 从 `n` 到 `2n` 枚举
2. 用最大堆维护前缀最小 n 个元素的和
3. 用最小堆维护后缀最大 n 个元素的和

## 易错点

1. 最大堆用负数模拟，累加时注意符号
2. 分割点范围 `[n, 2n]`，两端均包含
