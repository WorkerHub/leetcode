## 题目描述

有 `n` 个花园，按从 `1` 到 `n` 标记。另有数组 `paths`，其中 `paths[i] = [xi, yi]` 描述了花园 `xi` 到花园 `yi` 的双向路径。

在每个花园中，你打算种下四种花之一。

另外，所有花园最多有 3 条路径可以进入或离开。

你需要为每个花园选择一种花，使得通过路径相连的任何两个花园中的花的种类互不相同。

以数组形式返回任一满足题意的方案作为答案 `answer`，其中 `answer[i]` 为在第 `(i+1)` 个花园中种植的花的种类。花的种类用 1、2、3、4 表示。保证存在答案。

**示例 1：**
```
输入：n = 3, paths = [[1,2],[2,3],[3,1]]
输出：[1,2,3]
解释：
花园 1 和 2 不同种类
花园 2 和 3 不同种类
花园 3 和 1 不同种类
可以选择 [1,2,3] 或 [2,1,4] 等方案
```

**示例 2：**
```
输入：n = 4, paths = [[1,2],[3,4]]
输出：[1,2,1,2]
解释：
花园 1 和 2 不同种类
花园 3 和 4 不同种类
花园 1 和 3 可以相同，花园 2 和 4 可以相同
```

**示例 3：**
```
输入：n = 4, paths = [[1,2],[2,3],[3,4],[4,1],[1,3],[2,4]]
输出：[1,2,3,4]
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= paths.length <= 2 * 10^4`
- `paths[i].length == 2`
- `1 <= xi, yi <= n`
- `xi != yi`
- 每个花园最多有 3 条路径可以进入或离开

## 解题思路

这是一个图着色问题，但有一个重要的约束条件：每个节点最多有 3 个邻居。

### 核心观察

1. **保证有解**：因为有 4 种颜色可选，而每个花园最多有 3 个邻居
   - 即使 3 个邻居用了 3 种不同的颜色，我们还有第 4 种颜色可用
   - 这保证了一定存在可行的着色方案

2. **贪心策略**：
   - 按照花园编号顺序遍历
   - 对于每个花园，查看其已着色的邻居使用了哪些颜色
   - 选择一个未被邻居使用的颜色

3. **数据结构**：
   - 使用邻接表表示图
   - 使用数组记录每个花园的颜色

### 算法流程

1. 构建邻接表，存储每个花园的相邻花园
2. 初始化结果数组，所有花园初始颜色为 0（未着色）
3. 遍历每个花园：
   - 收集已着色邻居的颜色集合
   - 从 1-4 中选择一个不在集合中的颜色
4. 返回结果数组

## Python 代码实现

### 方法一：贪心 + 邻接表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        # 构建邻接表
        graph = defaultdict(list)
        for x, y in paths:
            graph[x].append(y)
            graph[y].append(x)
        
        # 初始化结果数组，0 表示未着色
        answer = [0] * n
        
        # 遍历每个花园
        for garden in range(1, n + 1):
            # 收集邻居已使用的颜色
            used_colors = set()
            for neighbor in graph[garden]:
                if answer[neighbor - 1] != 0:
                    used_colors.add(answer[neighbor - 1])
            
            # 选择第一个未被使用的颜色（1-4）
            for color in range(1, 5):
                if color not in used_colors:
                    answer[garden - 1] = color
                    break
        
        return answer
```

### 方法三：详细注释版（便于理解）

```python
from typing import List
from collections import defaultdict

class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        """
        图着色问题 - 贪心解法
        
        关键观察：
        1. 有4种颜色，每个节点最多3个邻居
        2. 保证有解：3个邻居最多用3种颜色，总有第4种可用
        """
        # 步骤1：构建邻接表
        # graph[i] 存储花园 i 的所有邻居
        graph = defaultdict(list)
        for garden1, garden2 in paths:
            # 双向边
            graph[garden1].append(garden2)
            graph[garden2].append(garden1)
        
        # 步骤2：初始化结果数组
        # answer[i] 表示第 i+1 个花园的颜色
        # 0 表示未着色，1-4 表示颜色类型
        answer = [0] * n
        
        # 步骤3：遍历每个花园，贪心着色
        for garden_id in range(1, n + 1):
            # 收集当前花园所有邻居已使用的颜色
            used_colors = set()
            
            for neighbor_id in graph[garden_id]:
                neighbor_color = answer[neighbor_id - 1]
                if neighbor_color != 0:  # 邻居已着色
                    used_colors.add(neighbor_color)
            
            # 从 1-4 中选择一个未被邻居使用的颜色
            for color in range(1, 5):
                if color not in used_colors:
                    answer[garden_id - 1] = color
                    break  # 找到可用颜色就停止
        
        return answer
```

                if color not in neighbor_colors:
                    answer[i] = color
                    break
        
        return answer

### 方法五：DFS 着色（备选方案）

```python
from typing import List
from collections import defaultdict

class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        # 构建邻接表
        graph = defaultdict(list)
        for x, y in paths:
            graph[x].append(y)
            graph[y].append(x)
        
        # 初始化颜色数组
        colors = [0] * (n + 1)
        
        def dfs(node: int) -> None:
            """深度优先搜索着色"""
            if colors[node] != 0:
                return
            
            # 收集邻居颜色
            used = {colors[neighbor] for neighbor in graph[node]}
            
            # 分配颜色
            for c in range(1, 5):
                if c not in used:
                    colors[node] = c
                    break
            
            # 递归着色邻居
            for neighbor in graph[node]:
                dfs(neighbor)
        
        # 从每个未着色的节点开始 DFS
        for i in range(1, n + 1):
            if colors[i] == 0:
                dfs(i)
        
        return colors[1:]
```

## 复杂度分析

- **时间复杂度**：O(n + m)
  - 构建邻接表：O(m)，其中 m 是边数
  - 遍历所有花园：O(n)
  - 对每个花园检查邻居颜色：O(3) = O(1)（最多3个邻居）
  - 总时间：O(n + m)

- **空间复杂度**：O(n + m)
  - 邻接表：O(m)
  - 结果数组：O(n)

## 关键点总结

1. **关键约束**：每个节点最多3个邻居，4种颜色可选，保证有解
2. **贪心策略**：顺序遍历，选择第一个可用颜色即可
3. **邻接表**：使用邻接表存储图，方便查询邻居
4. **索引转换**：花园编号从1开始，数组索引从0开始，注意转换
5. **集合运算**：使用集合快速判断颜色是否可用

## 易错点

1. **索引问题**：
   - 花园编号 1-n，数组索引 0-(n-1)
   - `answer[garden - 1]` 存储 garden 的颜色
   
2. **邻接表构建**：
   - 双向边要加两次：`graph[x].append(y)` 和 `graph[y].append(x)`
   
3. **初始值**：
   - 颜色范围是 1-4，不是 0-3
   - 0 表示未着色
   
4. **默认字典使用**：
   - 使用 `defaultdict(list)` 避免键不存在的错误
   
5. **提前终止**：
   - 找到可用颜色后要 `break`，不要继续尝试
