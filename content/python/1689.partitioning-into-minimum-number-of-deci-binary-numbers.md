## 题目描述

如果一个十进制数字不含任何前导零，且每一位上的数字都在 `0` 到 `1` 之间，那么该数字就是一个**十进制二进制数**。

例如，`101` 和 `1100` 都是**十进制二进制数**，而 `112` 和 `3001` 不是。

给你一个表示十进制整数的字符串 `n`，请你返回和为 `n` 的**十进制二进制数**的**最少数量**。

**示例 1：**
```
输入：n = "32"
输出：3
解释：10 + 11 + 11 = 32
```

**示例 2：**
```
输入：n = "82734"
输出：8
解释：需要 8 个十进制二进制数
```

**提示：**
- `1 <= n.length <= 10^5`
- `n` 仅由数字组成
- `n` 不含任何前导零且 `n != "0"`

## 解题思路

十进制二进制数每一位只能是 0 或 1。要凑出数字 `n` 的某一位 `d`（0 到 9），需要 `d` 个十进制二进制数在该位上贡献 1。

所以，需要的十进制二进制数的数量，就是 `n` 中**最大的数字**。

例如：`n = "32"`，最大数字是 3，需要 3 个数，每个数在十位贡献 1，在个位分别贡献 1、1、0，凑成 32。

## 代码实现

### 方法一：求最大字符（推荐）

```python
class Solution:
    def minPartitions(self, n: str) -> int:
        # 最少需要的数量等于 n 中最大的数字
        return int(max(n))
```

### 方法二：遍历字符串

```python
class Solution:
    def minPartitions(self, n: str) -> int:
        max_digit = 0
        for c in n:
            d = int(c)
            if d > max_digit:
                max_digit = d
            if max_digit == 9:
                # 已经是最大值，提前退出
                break
        return max_digit
```

## 复杂度分析

- **时间复杂度**：O(|n|)，遍历字符串一次
- **空间复杂度**：O(1)

## 关键点总结

1. 每个十进制二进制数的每一位只能贡献 0 或 1
2. 要凑出某位的数字 `d`，至少需要 `d` 个十进制二进制数
3. 所有位中取最大值，就是最少需要的数量
4. 一行代码 `int(max(n))` 即可解决（利用字符的字典序等价于数字大小比较）

## 易错点

1. `max(n)` 是对字符串求最大字符，结果是字符，需要用 `int()` 转换
2. 对于 `'0'` 到 `'9'` 的字符，字符大小与数字大小完全一致，所以 `max(n)` 是正确的
