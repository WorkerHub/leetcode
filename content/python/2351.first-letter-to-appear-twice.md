## 题目描述

给你一个由小写英文字母组成的字符串 `s`，返回第一个**出现两次**的字母。

**注意：** 如果字母 `a` 在 `s` 中出现两次及以上，则称其出现了两次（或更多次）。

**示例 1：**
```
输入：s = "abccbaacz"
输出："c"
解释：字符 'c' 是第一个出现两次的字母（第 2、3 位）。
```

**示例 2：**
```
输入：s = "abcdd"
输出："d"
```

**提示：**
- `2 <= s.length <= 100`
- `s` 由小写英文字母组成
- `s` 中存在至少一个出现两次的字母

## 解题思路

遍历字符串，用集合记录已出现的字母，遇到已在集合中的字母即为答案。

也可用位运算：用整数的 26 位表示 26 个字母，检查某位是否已被设置。

## 代码实现

### 方法一：集合（推荐）

```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        seen = set()
        for c in s:
            if c in seen:
                return c
            seen.add(c)
        return ''  # 题目保证存在，不会到达这里
```

### 方法二：位运算

```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        mask = 0  # 用整数的 26 位表示各字母是否出现
        for c in s:
            bit = 1 << (ord(c) - ord('a'))
            if mask & bit:
                return c
            mask |= bit
        return ''
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合 | O(n) | O(1)（最多 26 个字母） |
| 位运算 | O(n) | O(1) |

## 关键点总结

1. 集合维护已出现字母，第一次遇到重复的就返回。
2. 位运算用整数的低 26 位代替集合，更节省空间。
3. 题目保证答案存在，无需处理不存在的情况。

## 易错点

- 注意是找"第一个出现两次的字母"，不是出现次数最多的。
- 位运算中 `1 << (ord(c) - ord('a'))` 对应字母 c 的位。
