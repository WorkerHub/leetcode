## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，长度均为 n，以及一个整数 `k`。

对于每个下标 i，你需要选择 nums1 中最多 k 个满足 `nums1[j] < nums1[i]` 的下标 j，使得 `nums2[j]` 之和最大。

返回一个长度为 n 的数组 `answer`，其中 `answer[i]` 是对下标 i 的最优选择所得的 nums2 值之和。

**示例：**

```
输入：nums1 = [4,2,1,5,3], nums2 = [10,20,30,40,50], k = 2
输出：[60,0,0,80,30]
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^9`
- `1 <= k <= n`

## 解题思路

排序 + 最大堆（或最小堆维护 top-k）：

1. 将 (nums1[i], nums2[i], i) 按 nums1[i] 排序
2. 对排序后的数组，维护一个大小为 k 的最小堆，记录当前已遍历的 nums2 值中最大的 k 个
3. 遍历时，对 nums1 值相同的一批元素，其答案是当前堆中所有元素之和
4. 然后将这批元素的 nums2 值加入堆

## Python 代码实现

### 方法一：排序 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        # 按 nums1 排序，记录原下标
        sorted_idx = sorted(range(n), key=lambda i: nums1[i])

        answer = [0] * n
        heap = []  # 最小堆，维护 nums2 中最大的 k 个值
        heap_sum = 0

        i = 0
        while i < n:
            # 找出 nums1 值相同的一组
            j = i
            while j < n and nums1[sorted_idx[j]] == nums1[sorted_idx[i]]:
                j += 1

            # 这一组的答案是当前堆的总和
            for idx in range(i, j):
                answer[sorted_idx[idx]] = heap_sum

            # 将这一组的 nums2 值加入堆
            for idx in range(i, j):
                v = nums2[sorted_idx[idx]]
                heapq.heappush(heap, v)
                heap_sum += v
                if len(heap) > k:
                    heap_sum -= heapq.heappop(heap)

            i = j

        return answer
```

### 方法二：逐元素处理（更清晰）

```python
from typing import List
import heapq
from itertools import groupby

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        pairs = sorted(zip(nums1, nums2, range(n)))

        answer = [0] * n
        heap = []
        heap_sum = 0

        i = 0
        while i < n:
            # 收集相同 nums1 值的组
            cur_val = pairs[i][0]
            group = []
            while i < n and pairs[i][0] == cur_val:
                group.append(pairs[i])
                i += 1

            # 先记录答案（用当前堆），再更新堆
            for v1, v2, idx in group:
                answer[idx] = heap_sum

            # 更新堆
            for v1, v2, idx in group:
                heapq.heappush(heap, v2)
                heap_sum += v2
                if len(heap) > k:
                    heap_sum -= heapq.heappop(heap)

        return answer
```

### 方法三：SortedList 方案

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        pairs = sorted(zip(nums1, nums2, range(n)))

        answer = [0] * n
        sl = SortedList()
        window_sum = 0

        i = 0
        while i < n:
            cur_val = pairs[i][0]
            group = []
            while i < n and pairs[i][0] == cur_val:
                group.append(pairs[i])
                i += 1

            for _, v2, idx in group:
                answer[idx] = window_sum

            for _, v2, idx in group:
                sl.add(v2)
                window_sum += v2
                if len(sl) > k:
                    window_sum -= sl[0]
                    sl.pop(0)

        return answer
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和堆操作
- 空间复杂度：O(n)

## 关键点总结

1. 排序后分组处理相同 nums1 值
2. 维护大小为 k 的最小堆（保存 top-k 个 nums2 值）
3. 先记录答案再更新堆（确保严格小于 nums1[i]）

## 易错点

1. 必须先记录答案再将当前组加入堆，否则会包含 nums1[j] == nums1[i] 的元素
2. 堆超过 k 时弹出最小值，堆中存的是最大的 k 个 nums2 值
3. heap_sum 维护堆中所有元素之和
