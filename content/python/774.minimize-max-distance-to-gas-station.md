## 题目描述

在一条水平线上有 `n` 个加油站。给定一个数组 `stations` 表示每个加油站的位置。

你有 `k` 个额外的加油站要添加。返回可以达到的最大距离的最小可能值。

## 解题思路

使用二分查找答案，检查是否可以用 k 个加油站使最大距离不超过 mid。

## Python 代码实现

```python
from typing import List

class Solution:
    def minmaxGasDist(self, stations: List[int], k: int) -> float:
        def possible(distance):
            count = 0
            for i in range(len(stations) - 1):
                count += int((stations[i + 1] - stations[i]) / distance)
            return count <= k
        
        left, right = 0, stations[-1] - stations[0]
        
        while right - left > 1e-6:
            mid = (left + right) / 2
            if possible(mid):
                right = mid
            else:
                left = mid
        
        return left
```

## 复杂度分析

- **时间复杂度：** O(n log(max_distance / precision))
- **空间复杂度：** O(1)

## 关键点总结

1. 二分查找答案
2. 浮点数精度
3. 贪心验证
