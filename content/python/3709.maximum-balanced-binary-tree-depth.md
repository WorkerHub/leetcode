## 题目描述

给定一棵二叉树的根节点 `root`，找出树中**最大平衡子树**的深度（高度）。

平衡二叉树的定义：每个节点的左右子树高度差不超过 1，且左右子树本身也都是平衡的。

**示例 1：**
```
输入：root = [1,2,3,4,5,6,7]
输出：3
解释：整棵树是平衡的，深度为 3。
```

**示例 2：**
```
输入：root = [1,2,3,4,5,null,null,8]
输出：2
解释：以节点 2 为根的子树（含 4 和 5）是平衡的，深度为 2。整棵树不平衡。
```

**提示：**
- 树的节点数在 `[1, 5000]` 范围内
- `-10^4 <= Node.val <= 10^4`

## 解题思路

后序遍历（DFS）：对每个节点，先递归计算左右子树的信息，再判断以该节点为根的子树是否平衡。

定义辅助函数 `check(node)`，返回：
- 若以 `node` 为根的子树是平衡的，返回其高度（正整数）
- 若不平衡，返回 `-1`

同时维护全局最大平衡深度 `ans`：
- 若左右子树都平衡（高度差 <= 1），则以 `node` 为根的子树是平衡的，高度 = `max(left, right) + 1`，更新 `ans`。
- 否则返回 `-1` 表示不平衡。

## Python 代码实现

### 方法一：后序 DFS（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxBalancedDepth(self, root: Optional[TreeNode]) -> int:
        self.ans = 0

        def dfs(node: Optional[TreeNode]) -> int:
            """
            返回以 node 为根的平衡子树高度，不平衡返回 -1
            """
            if node is None:
                return 0

            left = dfs(node.left)
            right = dfs(node.right)

            if left == -1 or right == -1:
                # 子树不平衡，当前树也不平衡
                return -1

            if abs(left - right) <= 1:
                # 当前子树平衡
                height = max(left, right) + 1
                self.ans = max(self.ans, height)
                return height
            else:
                return -1

        dfs(root)
        return self.ans
```

### 方法二：枚举每个节点检查是否平衡

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxBalancedDepth(self, root: Optional[TreeNode]) -> int:
        def height(node):
            """计算树的高度，不平衡时返回 -1"""
            if node is None:
                return 0
            l = height(node.left)
            r = height(node.right)
            if l == -1 or r == -1 or abs(l - r) > 1:
                return -1
            return max(l, r) + 1

        ans = 0

        def traverse(node):
            nonlocal ans
            if node is None:
                return
            h = height(node)
            if h != -1:
                ans = max(ans, h)
            # 即使当前节点不平衡，子树可能平衡，继续遍历
            traverse(node.left)
            traverse(node.right)

        traverse(root)
        return ans
```

## 复杂度分析

- 时间复杂度：方法一 O(n)，后序遍历每个节点一次；方法二 O(n^2) 最坏情况
- 空间复杂度：O(h)，h 为树的高度，递归栈空间

## 关键点总结

1. 后序遍历：先处理子树再处理当前节点，自底向上计算平衡信息
2. 用返回值 `-1` 表示不平衡是常见技巧，避免额外的布尔变量
3. 不平衡的节点其子树可能平衡，不能提前终止遍历（但方法一通过返回 -1 向上传播）

## 易错点

1. 根节点可能不是最大平衡子树的根
2. 注意高度差条件：`abs(left - right) <= 1`
