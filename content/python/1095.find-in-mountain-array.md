## 题目描述

给定一个山脉数组 `mountainArr`，请你返回能够使得 `mountainArr.get(index)` 等于 `target` 最小的下标 `index` 值。如果不存在这样的下标 `index`，就请返回 `-1`。

**山脉数组的定义：**
- `mountainArr.length >= 3`
- 存在某个索引 `i`（`0 < i < mountainArr.length - 1`），使得：
  - `mountainArr[0] < mountainArr[1] < ... < mountainArr[i]`
  - `mountainArr[i] > mountainArr[i + 1] > ... > mountainArr[mountainArr.length - 1]`

**重要约束：**

你不能直接访问山脉数组，必须通过 `MountainArray` 接口来访问：
- `MountainArray.get(k)` - 返回索引 `k` 处的元素（下标从 0 开始）
- `MountainArray.length()` - 返回数组的长度

**注意：** 对 `MountainArray.get` 的调用次数不得超过 100 次，否则将被判定为错误答案。

**示例 1：**
```
输入：array = [1,2,3,4,5,3,1], target = 3
输出：2
解释：3 在数组中出现了两次，下标分别为 2 和 5，我们返回最小的下标 2。
```

**示例 2：**
```
输入：array = [0,1,2,4,2,1], target = 3
输出：-1
解释：3 在数组中没有出现，返回 -1。
```

**提示：**
- `3 <= mountainArr.length() <= 10^4`
- `0 <= target <= 10^9`
- `0 <= mountainArr.get(index) <= 10^9`

## 解题思路

这道题是二分查找的经典应用，关键在于：
1. **找到山峰位置**：使用二分查找找到数组的峰值索引
2. **分段搜索**：在升序部分和降序部分分别进行二分查找
3. **返回最小索引**：优先在左侧（升序部分）查找，找到就直接返回

**核心观察：**
- 山脉数组的左半部分是严格递增的
- 山脉数组的右半部分是严格递减的
- 因为要返回最小索引，所以先在左半部分查找

**算法流程：**
1. 使用二分查找找到峰值索引 `peak`
2. 在 `[0, peak]` 范围内使用升序二分查找
3. 如果找到目标值，直接返回索引
4. 如果没找到，在 `[peak, length-1]` 范围内使用降序二分查找
5. 返回结果或 -1

**优化要点：**
- 为了满足 100 次调用限制，需要缓存已访问的值
- 每次二分查找最多 log(n) 次调用，三次二分查找总共约 3*log(n) 次

## Python 代码实现

### 方法一：三次二分查找（推荐）⭐

```python
# """
# This is MountainArray's API interface.
# You should not implement it, or speculate about its implementation
# """
# class MountainArray:
#    def get(self, index: int) -> int:
#    def length(self) -> int:

class Solution:
    def findInMountainArray(self, target: int, mountain_arr: 'MountainArray') -> int:
        """
        使用三次二分查找：
        1. 找到峰值位置
        2. 在升序部分查找目标值
        3. 在降序部分查找目标值
        """
        n = mountain_arr.length()
        
        # 第一步：找到峰值索引
        peak = self.find_peak(mountain_arr, 0, n - 1)
        
        # 第二步：在升序部分（左侧）查找目标值
        index = self.binary_search_ascending(mountain_arr, target, 0, peak)
        if index != -1:
            return index
        
        # 第三步：在降序部分（右侧）查找目标值
        return self.binary_search_descending(mountain_arr, target, peak + 1, n - 1)
    
    def find_peak(self, mountain_arr: 'MountainArray', left: int, right: int) -> int:
        """找到山脉数组的峰值索引"""
        while left < right:
            mid = left + (right - left) // 2
            # 如果中间值小于右侧值，说明峰值在右侧
            if mountain_arr.get(mid) < mountain_arr.get(mid + 1):
                left = mid + 1
            else:
                # 否则峰值在左侧（包括 mid）
                right = mid
        return left
    
    def binary_search_ascending(self, mountain_arr: 'MountainArray', 
                                target: int, left: int, right: int) -> int:
        """在升序部分进行二分查找"""
        while left <= right:
            mid = left + (right - left) // 2
            value = mountain_arr.get(mid)
            
            if value == target:
                return mid
            elif value < target:
                left = mid + 1
            else:
                right = mid - 1
        
        return -1
    
    def binary_search_descending(self, mountain_arr: 'MountainArray', 
                                 target: int, left: int, right: int) -> int:
        """在降序部分进行二分查找"""
        while left <= right:
            mid = left + (right - left) // 2
            value = mountain_arr.get(mid)
            
            if value == target:
                return mid
            elif value < target:
                # 降序数组中，如果当前值小于目标值，目标在左侧
                right = mid - 1
            else:
                left = mid + 1
        
        return -1
```

### 方法二：带缓存优化的版本

```python
class Solution:
    def findInMountainArray(self, target: int, mountain_arr: 'MountainArray') -> int:
        """
        带缓存的版本，减少重复调用
        """
        n = mountain_arr.length()
        cache = {}  # 缓存已访问的值
        
        def get_value(index: int) -> int:
            """带缓存的获取值"""
            if index not in cache:
                cache[index] = mountain_arr.get(index)
            return cache[index]
        
        # 找到峰值索引
        left, right = 0, n - 1
        while left < right:
            mid = left + (right - left) // 2
            if get_value(mid) < get_value(mid + 1):
                left = mid + 1
            else:
                right = mid
        peak = left
        
        # 在升序部分查找
        left, right = 0, peak
        while left <= right:
            mid = left + (right - left) // 2
            value = get_value(mid)
            
            if value == target:
                return mid
            elif value < target:
                left = mid + 1
            else:
                right = mid - 1
        
        # 在降序部分查找
        left, right = peak + 1, n - 1
        while left <= right:
            mid = left + (right - left) // 2
            value = get_value(mid)
            
            if value == target:
                return mid
            elif value < target:
                right = mid - 1
            else:
                left = mid + 1
        
        return -1
```

### 方法三：简化版（单函数实现）

```python
class Solution:
    def findInMountainArray(self, target: int, mountain_arr: 'MountainArray') -> int:
        """简化版实现"""
        n = mountain_arr.length()
        
        # 找峰值
        l, r = 0, n - 1
        while l < r:
            m = (l + r) // 2
            if mountain_arr.get(m) < mountain_arr.get(m + 1):
                l = m + 1
            else:
                r = m
        peak = l
        
        # 升序查找
        l, r = 0, peak
        while l <= r:
            m = (l + r) // 2
            val = mountain_arr.get(m)
            if val == target:
                return m
            l, r = (m + 1, r) if val < target else (l, m - 1)
        
        # 降序查找
        l, r = peak + 1, n - 1
        while l <= r:
            m = (l + r) // 2
            val = mountain_arr.get(m)
            if val == target:
                return m
            l, r = (l, m - 1) if val < target else (m + 1, r)
        
        return -1
```

## 复杂度分析

**时间复杂度：** O(log n)
- 找峰值：O(log n)
- 升序部分二分查找：O(log n)
- 降序部分二分查找：O(log n)
- 总计：O(3 log n) = O(log n)

**空间复杂度：** O(1)
- 只使用常数级别的额外空间
- 如果使用缓存优化，空间复杂度为 O(log n)，因为最多缓存约 3*log(n) 个值

**API 调用次数：**
- 最坏情况：约 3*log(n) 次
- 对于 n = 10^4，约为 3*14 = 42 次，远小于 100 次的限制

## 关键点总结

1. **山脉数组特性**：左半部分严格递增，右半部分严格递减，利用这个性质进行二分查找
2. **三次二分**：分别找峰值、搜索左半部分、搜索右半部分
3. **优先左侧**：因为要返回最小索引，所以先在左半部分查找
4. **降序二分**：在降序数组中进行二分查找时，比较逻辑需要反转
5. **调用次数限制**：使用二分查找保证调用次数在 100 次以内

## 易错点

1. **峰值查找边界**：找峰值时使用 `left < right` 而不是 `left <= right`，避免越界
2. **降序二分逻辑**：在降序部分，如果当前值小于目标值，应该向左搜索（right = mid - 1）
3. **搜索范围**：升序部分是 `[0, peak]`，降序部分是 `[peak+1, n-1]`，注意 peak 只在升序部分搜索
4. **提前返回**：在升序部分找到目标值后应立即返回，不需要继续搜索降序部分
5. **API 调用优化**：相同索引的值可以缓存，避免重复调用
