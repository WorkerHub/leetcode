## 题目描述

给你一棵 **完美二叉树** 的根节点 `root`（即所有叶子节点都在同一层，每个内部节点都有两个子节点）。

反转这棵树 **奇数层** 的节点值，并返回反转后的根节点。

- 例如，假设第 3 层的节点值是 `[2,1,3,4,7,11,29,18]`，那么反转后变成 `[18,29,11,7,4,3,1,2]`。

**示例 1：**
```
输入：root = [2,3,5,8,13,21,34]
输出：[2,5,3,8,13,21,34]
解释：第 1 层的节点值是 [3,5]，反转后为 [5,3]。
```

**示例 2：**
```
输入：root = [7,13,11]
输出：[7,11,13]
```

**提示：**
- 树中的节点数目在 `[1, 2^14]` 范围内
- `0 <= Node.val <= 10^5`
- 所有树中的节点的值 **互不相同**

## 解题思路

**BFS（层序遍历）方法：**
- 逐层遍历，对奇数层（1, 3, 5, ...）收集节点，然后从两端向中间交换值

**DFS（递归）方法：**
- 递归地处理完美二叉树的对称节点：同时传入左子树和右子树的对应节点
- 在奇数层时交换两节点的值，然后递归处理它们的子节点

## 代码实现

### 方法一：BFS 层序遍历（推荐）

```python
from typing import Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def reverseOddLevels(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return root

        queue = deque([root])
        level = 0  # 根节点为第 0 层（偶数层）

        while queue:
            size = len(queue)
            nodes = []

            for _ in range(size):
                node = queue.popleft()
                nodes.append(node)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            # 奇数层：反转节点的值
            if level % 2 == 1:
                left, right = 0, len(nodes) - 1
                while left < right:
                    nodes[left].val, nodes[right].val = nodes[right].val, nodes[left].val
                    left += 1
                    right -= 1

            level += 1

        return root
```

### 方法二：DFS 递归

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def reverseOddLevels(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def dfs(left: Optional[TreeNode], right: Optional[TreeNode], is_odd: bool) -> None:
            """同时处理完美二叉树中对称的两个节点"""
            if left is None:
                return
            if is_odd:
                # 奇数层：交换两节点的值
                left.val, right.val = right.val, left.val
            # 继续递归：下一层是偶数/奇数取反
            # 注意：对称地传递子节点
            dfs(left.left, right.right, not is_odd)
            dfs(left.right, right.left, not is_odd)

        # 根节点为第 0 层（偶数），其子节点为第 1 层（奇数）
        dfs(root.left, root.right, True)
        return root
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n) | O(n)（队列最多一层节点）|
| DFS | O(n) | O(log n)（递归栈深度）|

## 关键点总结

1. 只需交换节点的值，不需要改变节点结构
2. BFS 按层收集节点，奇数层时从两端向中间交换值
3. DFS 利用完美二叉树的对称性，同时传入镜像对称的两个节点

## 易错点

- 根节点是第 0 层（偶数层），不需要反转；第 1 层是奇数层，需要反转
- DFS 方法中递归子节点时，`left.right` 对应 `right.left`（镜像对应）
