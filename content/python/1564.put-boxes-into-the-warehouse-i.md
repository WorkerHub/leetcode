## 题目描述

给你两个正整数数组 `boxes` 和 `warehouse`，分别表示箱子的高度和仓库每个房间的高度。

仓库的房间从左到右排列，只能从左边将箱子推入。每个房间只能放一个箱子，且箱子必须满足高度 <= 路过的所有房间高度。

返回最多能放入仓库的箱子数量。

**示例 1：**
```
输入：boxes = [4,3,4,1], warehouse = [2,1,3,1,2]
输出：3
```

## 解题思路

### 预处理仓库 + 贪心

由于箱子从左推入，位置 `i` 的实际有效高度是 `min(warehouse[0..i])`（前缀最小值）。

预处理有效高度后，将 `boxes` 和有效高度都排序，贪心地将小箱子放入小格子。

**贪心策略：**
- 排序后，从最大可用格子开始，尽量放最大的箱子（二分或双指针）
- 或：排序后用双指针，从小到大匹配

## 代码实现

### 方法一：预处理 + 双指针贪心（推荐）

```python
from typing import List

class Solution:
    def maxBoxesInWarehouse(self, boxes: List[int], warehouse: List[int]) -> int:
        # 预处理：从左到右的前缀最小值
        n = len(warehouse)
        effective = warehouse[:]
        for i in range(1, n):
            effective[i] = min(effective[i], effective[i-1])

        # 两者排序
        boxes.sort()
        effective.sort()

        # 双指针：尽量将每个格子放入能放的最大箱子
        ans = 0
        bi = 0  # boxes 指针
        for h in effective:
            if bi < len(boxes) and boxes[bi] <= h:
                ans += 1
                bi += 1

        return ans
```

### 方法二：贪心（从大到小）

```python
from typing import List

class Solution:
    def maxBoxesInWarehouse(self, boxes: List[int], warehouse: List[int]) -> int:
        n = len(warehouse)
        # 预处理有效高度（前缀最小值）
        effective = []
        min_h = float('inf')
        for h in warehouse:
            min_h = min(min_h, h)
            effective.append(min_h)

        boxes.sort(reverse=True)
        effective.sort(reverse=True)

        ans = 0
        ei = 0  # effective 指针
        for box in boxes:
            while ei < len(effective) and effective[ei] < box:
                ei += 1
            if ei < len(effective):
                ans += 1
                ei += 1

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N log N + M log M)，N = len(warehouse), M = len(boxes)
- **空间复杂度**：O(N)

## 关键点总结

1. 仓库的有效高度 = 从左到右的前缀最小值
2. 贪心：排序后，小箱子匹配小格子（或大箱子匹配大格子）
3. 双指针一次扫描完成匹配

## 易错点

- 有效高度是前缀最小值，不是 warehouse 的原始值
- 排序后的双指针只能往后走，不能回头
