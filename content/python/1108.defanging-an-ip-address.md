## 题目描述

给你一个有效的 IPv4 地址 `address`，返回这个 IP 地址的无效化版本。

所谓无效化 IP 地址，其实就是用 `"[.]"` 代替了每个 `"."`。

**示例 1：**
```
输入：address = "1.1.1.1"
输出："1[.]1[.]1[.]1"
```

**示例 2：**
```
输入：address = "255.100.50.0"
输出："255[.]100[.]50[.]0"
```

**提示：**
- 给出的 `address` 是一个有效的 IPv4 地址

## 解题思路

这是一道非常简单的字符串替换题目，核心就是把字符串中的所有点号 `"."` 替换成 `"[.]"`。

**解题方法：**
1. **直接使用字符串替换函数**：Python 的 `str.replace()` 方法可以一行解决
2. **字符串遍历拼接**：遍历每个字符，遇到 `'.'` 就替换成 `'[.]'`
3. **使用正则表达式**：使用 `re.sub()` 进行替换
4. **字符串分割重组**：先按 `'.'` 分割，再用 `'[.]'` 连接

## Python 代码实现

### 方法一：replace() 方法（推荐）

```python
class Solution:
    def defangIPaddr(self, address: str) -> str:
        # 直接使用 replace 方法替换所有的点号
        return address.replace('.', '[.]')
```

### 方法二：遍历拼接

```python
class Solution:
    def defangIPaddr(self, address: str) -> str:
        result = []
        
        # 遍历地址中的每个字符
        for char in address:
            if char == '.':
                # 遇到点号，添加 '[.]'
                result.append('[.]')
            else:
                # 其他字符直接添加
                result.append(char)
        
        # 拼接成字符串
        return ''.join(result)
```

### 方法三：列表推导式

```python
class Solution:
    def defangIPaddr(self, address: str) -> str:
        # 使用列表推导式和三元表达式
        return ''.join('[.]' if char == '.' else char for char in address)
```

### 方法四：split() + join()

```python
class Solution:
    def defangIPaddr(self, address: str) -> str:
        # 先按 '.' 分割成列表，再用 '[.]' 连接
        return '[.]'.join(address.split('.'))
```

### 方法五：正则表达式

```python
import re

class Solution:
    def defangIPaddr(self, address: str) -> str:
        # 使用正则表达式替换
        return re.sub(r'\.', '[.]', address)
```

## 复杂度分析

**方法一（replace）：**
- 时间复杂度：O(n)，其中 n 是字符串的长度，需要遍历整个字符串
- 空间复杂度：O(n)，需要创建新的字符串存储结果

**方法二（遍历）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，result 列表存储结果

**方法三（列表推导式）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法四（split + join）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要额外空间存储分割后的列表

**方法五（正则）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

所有方法的复杂度都是相同的，选择使用哪种主要看个人喜好和代码简洁性。

以 `address = "1.1.1.1"` 为例：

一步到位，直接替换

## 关键点总结

1. **字符串不可变性**：Python 中字符串是不可变对象，任何修改操作都会创建新字符串
2. **方法选择**：
   - `replace()`：最简洁直观，推荐使用
   - 列表推导式：Pythonic，代码简洁
   - `split() + join()`：思路清晰，适合分割重组的场景
3. **性能考虑**：虽然所有方法复杂度相同，但 `replace()` 是 C 实现的内置方法，实际运行速度最快
4. **正则表达式**：对于简单替换来说过于重量级，不推荐

## 易错点

1. **忘记转义**：虽然在 `replace()` 中不需要转义点号，但在正则表达式中 `'.'` 需要转义为 `r'\.'`
2. **字符串拼接效率**：不要使用 `result += '[.]'` 这种方式在循环中拼接字符串，效率很低，应该使用列表
3. **边界情况**：虽然题目保证输入是有效 IPv4，但实际开发中应该考虑空字符串等边界情况
