## 题目描述

序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。

请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。

**提示：** 输入输出格式与 LeetCode 目前使用的方式一致，详情请参阅 LeetCode 序列化二叉树的格式。你并非必须采取这种方式，你也可以采用其他的方法解决这个问题。

**示例 1：**
```
输入：root = [1,2,3,null,null,4,5]
输出：[1,2,3,null,null,4,5]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**提示：**
- 树中节点数在范围 [0, 10^4] 内
- -1000 <= Node.val <= 1000

## 解题思路

序列化和反序列化是一对互逆操作，关键是设计合理的编码格式。

**常见方法对比：**

| 方法 | 优点 | 缺点 |
|------|------|------|
| 前序遍历 + null 标记 | 简单直观，递归实现 | 需要标记空节点 |
| 层序遍历 + null 标记 | 符合 LeetCode 格式 | 需要队列 |
| 括号表示法 | 结构清晰 | 字符串较长 |

**核心要点：**
1. 必须能够唯一确定树的结构
2. 序列化和反序列化必须匹配
3. 需要标记空节点（null）的位置

## Python 代码实现

### 方法一：前序遍历（DFS）推荐

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Codec:
    """
    使用前序遍历（根-左-右）序列化
    用 'null' 标记空节点，用 ',' 分隔
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        将树序列化为字符串
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        def dfs(node):
            if not node:
                vals.append('null')
                return
            vals.append(str(node.val))
            dfs(node.left)
            dfs(node.right)
        
        vals = []
        dfs(root)
        return ','.join(vals)
    
    def deserialize(self, data: str) -> TreeNode:
        """
        从字符串反序列化为树
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        def dfs():
            val = next(vals)
            if val == 'null':
                return None
            node = TreeNode(int(val))
            node.left = dfs()
            node.right = dfs()
            return node
        
        vals = iter(data.split(','))
        return dfs()
```

### 方法二：层序遍历（BFS）

```python
from collections import deque

class Codec:
    """
    使用层序遍历（BFS）序列化
    这种方式与 LeetCode 的输入输出格式一致
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        层序遍历序列化
        """
        if not root:
            return ''
        
        result = []
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            if node:
                result.append(str(node.val))
                queue.append(node.left)
                queue.append(node.right)
            else:
                result.append('null')
        
        # 去除末尾的 null
        while result and result[-1] == 'null':
            result.pop()
        
        return ','.join(result)
    
    def deserialize(self, data: str) -> TreeNode:
        """
        层序遍历反序列化
        """
        if not data:
            return None
        
        vals = data.split(',')
        root = TreeNode(int(vals[0]))
        queue = deque([root])
        i = 1
        
        while queue and i < len(vals):
            node = queue.popleft()
            
            # 处理左子节点
            if i < len(vals) and vals[i] != 'null':
                node.left = TreeNode(int(vals[i]))
                queue.append(node.left)
            i += 1
            
            # 处理右子节点
            if i < len(vals) and vals[i] != 'null':
                node.right = TreeNode(int(vals[i]))
                queue.append(node.right)
            i += 1
        
        return root
```

### 方法三：括号表示法

```python
class Codec:
    """
    使用括号表示树的结构
    格式：1(2)(3(4)(5))
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        括号表示法序列化
        """
        if not root:
            return ''
        
        result = str(root.val)
        
        # 如果有子节点，添加括号
        if root.left or root.right:
            result += '(' + self.serialize(root.left) + ')'
        if root.right:
            result += '(' + self.serialize(root.right) + ')'
        
        return result
    
    def deserialize(self, data: str) -> TreeNode:
        """
        括号表示法反序列化
        """
        if not data:
            return None
        
        # 找到第一个左括号的位置
        idx = data.find('(')
        
        if idx == -1:
            # 没有括号，只有根节点
            return TreeNode(int(data))
        
        # 根节点的值
        root = TreeNode(int(data[:idx]))
        
        # 找到左子树的范围
        count = 0
        for i in range(idx, len(data)):
            if data[i] == '(':
                count += 1
            elif data[i] == ')':
                count -= 1
            if count == 0:
                # 左子树结束
                root.left = self.deserialize(data[idx + 1:i])
                # 右子树（如果存在）
                if i + 1 < len(data):
                    root.right = self.deserialize(data[i + 2:-1])
                break
        
        return root
```

### 方法四：后序遍历

```python
class Codec:
    """
    使用后序遍历（左-右-根）序列化
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        后序遍历序列化
        """
        def postorder(node):
            if not node:
                vals.append('null')
                return
            postorder(node.left)
            postorder(node.right)
            vals.append(str(node.val))
        
        vals = []
        postorder(root)
        return ','.join(vals)
    
    def deserialize(self, data: str) -> TreeNode:
        """
        后序遍历反序列化（从后向前）
        """
        def build():
            val = vals.pop()
            if val == 'null':
                return None
            node = TreeNode(int(val))
            # 注意：后序遍历，先构建右子树
            node.right = build()
            node.left = build()
            return node
        
        vals = data.split(',')
        return build()
```

### 方法五：紧凑格式（优化空间）

```python
class Codec:
    """
    使用更紧凑的格式，减少空间
    前序遍历 + 特殊分隔符
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        序列化，用 # 表示 null，用 , 分隔
        """
        def dfs(node):
            if not node:
                return '#'
            return f"{node.val},{dfs(node.left)},{dfs(node.right)}"
        
        return dfs(root)
    
    def deserialize(self, data: str) -> TreeNode:
        """
        反序列化
        """
        def dfs(vals):
            val = next(vals)
            if val == '#':
                return None
            node = TreeNode(int(val))
            node.left = dfs(vals)
            node.right = dfs(vals)
            return node
        
        return dfs(iter(data.split(',')))
```

## 复杂度分析

### 所有方法：

**时间复杂度：**
- serialize: O(n) - 遍历所有节点
- deserialize: O(n) - 构建所有节点

**空间复杂度：**
- serialize: O(n) - 存储序列化字符串
- deserialize: O(n) - 递归栈或队列

## 图解示例

示例树：
```
    1
   / \
  2   3
     / \
    4   5
```

### 前序遍历序列化：
```
访问顺序：1 → 2 → null → null → 3 → 4 → null → null → 5 → null → null

序列化结果：
"1,2,null,null,3,4,null,null,5,null,null"

反序列化过程：
1. 读取 "1"，创建节点 1
2. 递归处理左子树：
   - 读取 "2"，创建节点 2
   - 递归处理左子树：读取 "null"，返回 None
   - 递归处理右子树：读取 "null"，返回 None
3. 递归处理右子树：
   - 读取 "3"，创建节点 3
   - 递归处理左子树：
     - 读取 "4"，创建节点 4
     - ...
```

### 层序遍历序列化：
```
层次访问：
第1层：1
第2层：2, 3
第3层：null, null, 4, 5
第4层：null, null, null, null

序列化结果：
"1,2,3,null,null,4,5"
（末尾的 null 可以省略）

反序列化过程：
1. 创建根节点 1，加入队列
2. 从队列取出 1：
   - 左子节点是 2，创建并加入队列
   - 右子节点是 3，创建并加入队列
3. 从队列取出 2：
   - 左子节点是 null，跳过
   - 右子节点是 null，跳过
4. 从队列取出 3：
   - 左子节点是 4，创建并加入队列
   - 右子节点是 5，创建并加入队列
```

## 关键点总结

1. **遍历顺序**：前序、中序、后序、层序都可以，但必须标记 null
2. **null 标记**：必须标记空节点位置，否则无法唯一确定树
3. **迭代器技巧**：使用 iter() 和 next() 简化索引管理
4. **分隔符选择**：常用逗号，也可以用其他字符
5. **递归匹配**：序列化和反序列化的递归顺序必须一致

## 易错点

1. **忘记标记 null**
   ```python
   # 错误：不标记 null，无法确定结构
   def serialize(root):
       if not root:
           return ''
       return f"{root.val},{serialize(root.left)},{serialize(root.right)}"
   
   # 正确：必须标记 null
   if not root:
       return 'null'
   ```

2. **反序列化时索引混乱**
   ```python
   # 错误：使用全局索引容易出错
   i = 0
   def deserialize(vals):
       nonlocal i
       val = vals[i]
       i += 1
       # 容易忘记更新 i
   
   # 正确：使用迭代器
   vals = iter(data.split(','))
   val = next(vals)
   ```

3. **层序遍历的子节点处理**
   ```python
   # 错误：没有正确处理 null 节点
   while queue:
       node = queue.popleft()
       node.left = TreeNode(int(vals[i]))  # vals[i] 可能是 'null'
   
   # 正确：检查是否为 null
   if vals[i] != 'null':
       node.left = TreeNode(int(vals[i]))
       queue.append(node.left)
   ```

4. **后序遍历的顺序**
   ```python
   # 错误：反序列化时顺序错误
   def build():
       node = TreeNode(int(vals.pop()))
       node.left = build()  # 错误！后序是左-右-根
       node.right = build()
   
   # 正确：先右后左（因为从后往前）
   def build():
       node = TreeNode(int(vals.pop()))
       node.right = build()
       node.left = build()
   ```

5. **空树处理**
   ```python
   # 错误：没有处理空树
   def serialize(root):
       vals = []
       dfs(root)
       return ','.join(vals)
   # 空树会返回 ''，反序列化时可能出错
   
   # 正确：空树也要处理
   def deserialize(data):
       if not data:
           return None
   ```
