## 题目描述

给你一个整数 `n`，返回**大于等于 n 且二进制表示中所有位都是 1 的最小整数**。

即返回最小的 `2^k - 1`（k 个 1 组成的二进制数），使得该值 >= n。

**示例：**
```
输入：n = 5
输出：7
解释：5 = 101，最小的全 1 二进制数 >= 5 是 7 = 111
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

找最小的 `2^k - 1 >= n`，即找最小的 `k` 使得 `2^k - 1 >= n`，等价于 `2^k > n`，即 `k > log2(n)`。

最小的 `k = ceil(log2(n+1))`，答案 = `2^k - 1`。

也可以用位运算：找 `n` 的最高位长度，如果 `n` 本身已是全 1，则返回 n；否则返回 `(1 << n.bit_length()) - 1`。

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        # 若 n 已经是全 1（即 n & (n+1) == 0），直接返回 n
        # 否则，取 n 的位长度 k，返回 2^k - 1
        if n & (n + 1) == 0:
            return n
        k = n.bit_length()
        return (1 << k) - 1
```

### 方法二：循环找

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        result = 1
        while result < n:
            result = result * 2 + 1  # 下一个全 1 数：1, 3, 7, 15, 31, ...
        return result
```

## 复杂度分析

- 时间复杂度：O(log n)，找位长度
- 空间复杂度：O(1)

## 关键点总结

1. 全 1 二进制数形如 `1, 3, 7, 15, 31, 63, ...`（即 `2^k - 1`）。
2. `n & (n+1) == 0` 当且仅当 `n` 是全 1 数。
3. `n.bit_length()` 返回 n 的二进制位数，`(1 << k) - 1` 是 k 位全 1 数。

## 易错点

1. 若 `n` 本身已是全 1，返回 `n` 本身，不要再进一步扩大。
2. `bit_length()` 对 n=0 返回 0，但本题 n >= 1，不影响。
3. `(1 << k) - 1` 的位长是 k，等于所有 k 位都是 1。
