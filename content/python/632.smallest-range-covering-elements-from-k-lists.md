## 题目描述

你有 `k` 个升序排列的整数列表。找到一个最小区间，使得 `k` 个列表中的每个列表至少有一个数包含在其中。

我们定义如果 `b - a < d - c` 或者在 `b - a == d - c` 时 `a < c`，则区间 `[a,b]` 比 `[c,d]` 小。

**示例 1：**

```
输入：nums = [[4,10,15,24,26],[0,9,12,20],[5,18,22,30]]
输出：[20,24]
解释：
列表 1：[4, 10, 15, 24, 26]，24 在区间 [20, 24] 中。
列表 2：[0, 9, 12, 20]，20 在区间 [20, 24] 中。
列表 3：[5, 18, 22, 30]，22 在区间 [20, 24] 中。
```

**示例 2：**

```
输入：nums = [[1,2,3],[1,2,3],[1,2,3]]
输出：[1,1]
```

**提示：**
- `nums.length == k`
- `1 <= k <= 3500`
- `1 <= nums[i].length <= 50`
- `-10^5 <= nums[i][j] <= 10^5`
- `nums[i]` 按升序排列

## 解题思路

这道题的核心是找到一个最小的区间，覆盖所有 k 个列表中的至少一个元素。

**关键观察：**

1. **最小区间的端点**：区间的右端点必须是某个列表中的某个元素，左端点也是
2. **滑动窗口思想**：维护一个包含所有列表的"窗口"，尝试收缩它
3. **使用最小堆**：追踪当前窗口中每个列表的最小元素

**算法策略：**

使用最小堆 + 贪心：

1. **初始化**：
   - 将每个列表的第一个元素加入最小堆
   - 记录当前的最大值 `max_val`
   - 初始区间为 `[堆顶, max_val]`

2. **迭代优化**：
   - 弹出堆顶（当前最小值）`min_val`
   - 区间 `[min_val, max_val]` 是一个候选答案
   - 将 `min_val` 所在列表的下一个元素加入堆
   - 更新 `max_val`（如果新元素更大）
   - 重复直到某个列表用完

3. **终止条件**：当某个列表的所有元素都被考虑过，无法再维护覆盖所有列表的区间

**为什么这个贪心是正确的？**

- 堆顶是当前窗口的最小值（左端点候选）
- 当前最大值是右端点
- 移动最小值（弹出并加入下一个）是唯一可能缩小区间的方式
- 遍历所有可能的最小值，保证找到最优解

## Python 代码实现

### 方法一：最小堆 + 贪心（推荐）

```python
import heapq
from typing import List

class Solution:
    def smallestRange(self, nums: List[List[int]]) -> List[int]:
        """
        找到覆盖所有列表的最小区间
        
        参数:
            nums: k 个升序列表
        
        返回:
            最小区间 [left, right]
        """
        # 最小堆：(值, 列表索引, 元素索引)
        min_heap = []
        max_val = float('-inf')
        
        # 初始化：每个列表的第一个元素
        for i in range(len(nums)):
            heapq.heappush(min_heap, (nums[i][0], i, 0))
            max_val = max(max_val, nums[i][0])
        
        # 初始化最小区间
        result = [min_heap[0][0], max_val]
        
        while True:
            # 弹出当前最小值
            min_val, list_idx, elem_idx = heapq.heappop(min_heap)
            
            # 更新最小区间（如果当前区间更小）
            if max_val - min_val < result[1] - result[0]:
                result = [min_val, max_val]
            
            # 将该列表的下一个元素加入堆
            elem_idx += 1
            if elem_idx >= len(nums[list_idx]):
                # 该列表用完了，无法再覆盖所有列表
                break
            
            # 加入下一个元素
            next_val = nums[list_idx][elem_idx]
            heapq.heappush(min_heap, (next_val, list_idx, elem_idx))
            
            # 更新最大值
            max_val = max(max_val, next_val)
        
        return result
```

**时间复杂度：** O(n log k)，n 是所有元素总数，k 是列表数量  
**空间复杂度：** O(k)，堆的大小

### 方法二：合并排序 + 双指针

```python
class Solution:
    def smallestRange(self, nums: List[List[int]]) -> List[int]:
        """
        方法二：将所有元素合并排序，然后用滑动窗口
        """
        # 合并所有元素，记录来源列表
        merged = []
        for i in range(len(nums)):
            for num in nums[i]:
                merged.append((num, i))
        
        # 按值排序
        merged.sort()
        
        # 滑动窗口
        k = len(nums)
        count = {}  # 统计窗口中每个列表的元素个数
        left = 0
        result = [merged[0][0], merged[-1][0]]
        
        for right in range(len(merged)):
            # 加入右端点
            val, list_idx = merged[right]
            count[list_idx] = count.get(list_idx, 0) + 1
            
            # 收缩左端点
            while len(count) == k:  # 窗口覆盖了所有列表
                # 更新结果
                left_val, right_val = merged[left][0], merged[right][0]
                if right_val - left_val < result[1] - result[0]:
                    result = [left_val, right_val]
                
                # 移除左端点
                left_list_idx = merged[left][1]
                count[left_list_idx] -= 1
                if count[left_list_idx] == 0:
                    del count[left_list_idx]
                left += 1
        
        return result
```

**时间复杂度：** O(n log n)，n 是所有元素总数  
**空间复杂度：** O(n)，合并后的数组

### 方法三：优化的堆方法（使用 next 指针）

```python
class Solution:
    def smallestRange(self, nums: List[List[int]]) -> List[int]:
        """使用指针数组代替堆中存储索引"""
        k = len(nums)
        # 指针数组，记录每个列表当前的位置
        pointers = [0] * k
        
        # 最小堆：(值, 列表索引)
        min_heap = []
        max_val = float('-inf')
        
        # 初始化
        for i in range(k):
            heapq.heappush(min_heap, (nums[i][0], i))
            max_val = max(max_val, nums[i][0])
        
        result = [min_heap[0][0], max_val]
        
        while True:
            min_val, list_idx = heapq.heappop(min_heap)
            
            # 更新结果
            if max_val - min_val < result[1] - result[0]:
                result = [min_val, max_val]
            
            # 移动指针
            pointers[list_idx] += 1
            if pointers[list_idx] >= len(nums[list_idx]):
                break
            
            # 加入下一个元素
            next_val = nums[list_idx][pointers[list_idx]]
            heapq.heappush(min_heap, (next_val, list_idx))
            max_val = max(max_val, next_val)
        
        return result
```

## 复杂度分析

**方法一（最小堆）：**
- 时间复杂度：O(n log k)，n 是总元素数，每次堆操作 O(log k)
- 空间复杂度：O(k)，堆的大小

**方法二（合并排序）：**
- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(n)，合并数组

## 关键点总结

1. **堆维护最小值**：堆顶始终是当前窗口的最小值（左端点）
2. **变量维护最大值**：max_val 是当前窗口的右端点
3. **贪心移动**：每次移动最小值所在列表的指针，尝试缩小区间
4. **终止条件**：某个列表用完，无法再覆盖所有列表
5. **区间比较**：长度相同时，选择左端点更小的

## 易错点

1. **初始化 max_val**：
   ```python
   # 错误
   max_val = 0
   # 正确
   max_val = float('-inf')  # 或 max(nums[i][0] for i in range(k))
   ```

2. **区间比较逻辑**：
   ```python
   # 错误：只比较长度
   if max_val - min_val < result[1] - result[0]:
   
   # 正确：长度相同时比较起点
   if (max_val - min_val < result[1] - result[0] or 
       (max_val - min_val == result[1] - result[0] and min_val < result[0])):
   
   # 更简单：题目保证只需要比较长度（因为我们按顺序遍历）
   if max_val - min_val < result[1] - result[0]:
   ```

3. **越界判断**：移动指针前要检查是否越界

4. **忘记更新 max_val**：加入新元素后要更新 max_val

5. **堆的初始化**：每个列表都要加入堆

## 扩展思考

**为什么不能用双指针遍历所有可能的区间？**

因为 k 个列表，每个列表可能有 m 个元素，所有可能的区间组合是 O(m^k)，指数级别，无法接受。

**为什么堆方法是最优的？**

堆方法利用了每个列表已排序的特性，每次只移动最小值，保证了：
1. 不会遗漏最优解
2. 时间复杂度只与元素总数和列表数量有关，与每个列表的长度无关
