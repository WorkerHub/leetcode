## 题目描述

某种外星语也使用英文小写字母，但可能顺序不同。字母表的顺序（`order`）是该语言字母的排列顺序。

给定一组用外星语书写的单词 `words`，以及其字母表的顺序 `order`，只有当给定的单词在这种外星语中按字典序排列时，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
输出：true
解释：在该语言的字母表中，'h' 在 'l' 之前，所以单词序列是按字典序排列的。
```

**示例 2：**
```
输入：words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
输出：false
解释：在该语言的字母表中，'d' 在 'l' 之后，那么 words[0] > words[1]，因此单词序列不是按字典序排列的。
```

**示例 3：**
```
输入：words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
输出：false
解释："apple" > "app"，因为 'e' > '∅'（'∅' 代表不存在的字符）。
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 20`
- `order.length == 26`
- `words[i]` 和 `order` 中的所有字符都是英文小写字母

## 解题思路

这道题的本质是验证单词序列是否按照给定的字母表顺序排列。

**核心思想：**

1. **字典序比较**：按照外星字母表的顺序比较相邻两个单词
2. **建立映射**：将外星字母映射到其顺序位置（0-25）
3. **逐对比较**：只需要比较相邻的两个单词是否满足字典序

**算法流程：**
1. 创建字母到位置的哈希表映射
2. 遍历相邻的单词对
3. 比较每对单词的字典序
4. 如果发现逆序，返回 False
5. 全部通过，返回 True

**字典序比较规则：**
- 从左到右逐个字符比较
- 如果字符不同，比较它们的顺序
- 如果前缀相同，较短的单词应该在前面

## Python 代码实现

### 方法一：哈希表映射 + 双指针比较（推荐）⭐

```python
from typing import List

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        """
        验证单词是否按外星字母表顺序排列
        
        思路：
        1. 建立字母到位置的映射
        2. 比较相邻单词的字典序
        """
        # 建立字母顺序映射
        order_map = {char: i for i, char in enumerate(order)}
        
        # 比较相邻的单词
        for i in range(len(words) - 1):
            word1, word2 = words[i], words[i + 1]
            
            # 比较两个单词
            if not self.is_sorted(word1, word2, order_map):
                return False
        
        return True
    
    def is_sorted(self, word1: str, word2: str, order_map: dict) -> bool:
        """
        判断 word1 是否应该排在 word2 前面
        """
        min_len = min(len(word1), len(word2))
        
        # 逐字符比较
        for i in range(min_len):
            char1, char2 = word1[i], word2[i]
            
            # 如果字符不同，比较它们的顺序
            if char1 != char2:
                return order_map[char1] < order_map[char2]
        
        # 如果前缀相同，检查长度
        # 如果 word1 更长，说明逆序（例如 "apple" 和 "app"）
        return len(word1) <= len(word2)
```

### 方法二：一次遍历简化版

```python
class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        """
        简化版实现，使用 zip 配对字符
        """
        # 建立顺序映射
        order_map = {c: i for i, c in enumerate(order)}
        
        # 比较相邻单词
        for i in range(len(words) - 1):
            word1, word2 = words[i], words[i + 1]
            
            # 逐字符比较
            for c1, c2 in zip(word1, word2):
                if c1 != c2:
                    # 如果顺序错误，返回 False
                    if order_map[c1] > order_map[c2]:
                        return False
                    # 找到第一个不同的字符且顺序正确，跳出
                    break
            else:
                # for-else: 所有字符都相同
                # 如果 word1 更长，说明逆序
                if len(word1) > len(word2):
                    return False
        
        return True
```

### 方法三：利用 Python 排序特性

```python
class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        """
        利用 Python 的排序功能
        
        思路：将单词按外星字母表排序，检查是否与原序列相同
        """
        # 建立顺序映射
        order_map = {c: i for i, c in enumerate(order)}
        
        # 自定义排序键：将每个字符映射到其顺序值
        def word_key(word):
            return [order_map[c] for c in word]
        
        # 检查原序列是否已排序
        return words == sorted(words, key=word_key)
```

### 方法四：转换为标准字母表

```python
class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        """
        将外星单词转换为标准字母表单词，然后比较
        
        思路：
        1. 建立外星字母到标准字母的映射
        2. 转换所有单词
        3. 检查转换后的单词是否已排序
        """
        # 建立外星字母到标准字母的映射
        # 例如：外星字母表第一个字母 -> 'a'，第二个 -> 'b'，...
        trans_map = {c: chr(ord('a') + i) for i, c in enumerate(order)}
        
        # 转换所有单词
        translated_words = []
        for word in words:
            translated = ''.join(trans_map[c] for c in word)
            translated_words.append(translated)
        
        # 检查是否已排序
        return translated_words == sorted(translated_words)
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度**：O(N × M)
  - N 是单词数量
  - M 是单词的平均长度
  - 需要比较 N-1 对单词，每次比较最多 M 个字符
- **空间复杂度**：O(1) 或 O(26) = O(1)，字母表固定为 26 个字母

**方法三：**
- **时间复杂度**：O(N × M × log N)，排序需要 O(N log N) 次比较，每次比较 O(M)
- **空间复杂度**：O(N × M)，排序需要额外空间

**方法四：**
- **时间复杂度**：O(N × M)，转换和排序
- **空间复杂度**：O(N × M)，存储转换后的单词

## 关键点总结

1. **哈希表映射**：将字母映射到位置索引，O(1) 查询
2. **相邻比较**：只需比较相邻单词，不需要全局比较
3. **提前终止**：找到第一个不同字符即可判断顺序
4. **边界处理**：特别注意前缀相同时的长度比较
5. **for-else 用法**：Python 特有的语法糖，当循环正常结束（未 break）时执行

## 易错点

1. **前缀问题**：忘记处理一个单词是另一个单词前缀的情况
   - 例如："apple" 和 "app"，"apple" 不应该排在 "app" 前面
2. **边界条件**：
   - 单词数组长度为 1：直接返回 True
   - 空字符串：需要考虑
3. **循环边界**：比较 N-1 对单词，而不是 N 对
4. **字符比较**：要比较映射后的值，不是字符本身
5. **for-else 陷阱**：容易混淆 else 的执行时机
