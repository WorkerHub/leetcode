## 题目描述

给你一个表示大整数的字符串 `num` 和一个整数 `k`，返回将 `num` 变成其**第 k 个更大排列**所需的**最少相邻交换次数**。

**示例 1：**
```
输入：num = "5489355142", k = 4
输出：2
```

**示例 2：**
```
输入：num = "11112", k = 4
输出：4
```

**提示：**
- `2 <= num.length <= 1000`
- `1 <= k <= 1000`

## 解题思路

**两步解法**：

1. **找第 k 个更大排列**：对 num 执行 k 次 Next Permutation，得到目标字符串 `target`
2. **计算最少交换次数**：用贪心双指针，统计将 num 变为 target 所需的最少相邻交换次数（类似于冒泡排序中的交换次数）

**Next Permutation**：标准算法（找下降点、找交换点、交换、反转后缀）

**最少交换次数**：对 target 的每个位置，在 num 中找到对应字符的最近位置，将其移动到正确位置（类似插入排序）。

## 代码实现

### 方法一：Next Permutation + 贪心交换（推荐）

```python
class Solution:
    def getMinSwaps(self, num: str, k: int) -> int:
        original = list(num)
        arr = list(num)

        def next_permutation(a: list) -> None:
            n = len(a)
            i = n - 2
            while i >= 0 and a[i] >= a[i + 1]:
                i -= 1
            if i < 0:
                return
            j = n - 1
            while a[j] <= a[i]:
                j -= 1
            a[i], a[j] = a[j], a[i]
            a[i + 1:] = a[i + 1:][::-1]

        # 执行 k 次 Next Permutation，得到目标排列
        for _ in range(k):
            next_permutation(arr)
        target = arr

        # 计算 original 变为 target 的最少相邻交换次数
        swaps = 0
        orig = list(original)
        for i in range(len(orig)):
            if orig[i] != target[i]:
                # 在 orig[i+1:] 中找到 target[i]
                j = i + 1
                while orig[j] != target[i]:
                    j += 1
                # 将 orig[j] 移动到位置 i（需要 j-i 次相邻交换）
                while j > i:
                    orig[j], orig[j - 1] = orig[j - 1], orig[j]
                    j -= 1
                    swaps += 1
        return swaps
```

### 方法二：使用 Python 标准库简化

```python
class Solution:
    def getMinSwaps(self, num: str, k: int) -> int:
        from itertools import permutations

        # 使用内置函数找第 k 个排列
        arr = list(num)
        for _ in range(k):
            # Next Permutation
            n = len(arr)
            i = n - 2
            while i >= 0 and arr[i] >= arr[i + 1]:
                i -= 1
            if i >= 0:
                j = n - 1
                while arr[j] <= arr[i]:
                    j -= 1
                arr[i], arr[j] = arr[j], arr[i]
                arr[i + 1:] = reversed(arr[i + 1:])
        target = arr

        orig = list(num)
        swaps = 0
        for i in range(len(orig)):
            if orig[i] != target[i]:
                j = i + 1
                while orig[j] != target[i]:
                    j += 1
                while j > i:
                    orig[j], orig[j - 1] = orig[j - 1], orig[j]
                    j -= 1
                    swaps += 1
        return swaps
```

## 复杂度分析

- **时间复杂度**：O(k * n + n^2)，k 次 Next Permutation 各 O(n)，计算交换次数 O(n^2)
- **空间复杂度**：O(n)

## 关键点总结

1. 第一步：k 次 Next Permutation 找目标排列
2. 第二步：贪心地将 original 中每个位置对齐到 target，统计交换次数
3. 相邻交换最少次数的贪心：找最近的匹配字符，逐步移过来

## 易错点

- Next Permutation 后缀反转时使用 `a[i+1:] = a[i+1:][::-1]` 或 `reversed()`
- 查找目标字符时从当前位置的下一个开始（`j = i + 1`）
