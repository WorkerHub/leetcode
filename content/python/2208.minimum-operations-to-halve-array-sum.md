## 题目描述

给你一个正整数数组 `nums`。每次操作中，你可以从 `nums` 中选择 **任意** 一个数并将它减少至 **恰好** 一半（即 `nums[i] = nums[i] / 2`，可以是小数）。

返回使 `nums` 的元素和减少 **至少** 一半所需的 **最少操作次数**。

**示例 1：**
```
输入：nums = [5,19,8,1]
输出：3
解释：初始和 33，目标 <= 16.5。
操作1：19 -> 9.5，和 = 23.5
操作2：9.5 -> 4.75，和 = 18.75
操作3：8 -> 4，和 = 14.75 <= 16.5
```

**示例 2：**
```
输入：nums = [3,8,20]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^7`

## 解题思路

**贪心策略**：每次选择当前最大的元素减半，这样每次操作能减少最多的和。使用**最大堆**来高效地获取当前最大值。

**步骤：**
1. 计算初始总和 `total`，目标减少量 `target = total / 2`。
2. 建最大堆。
3. 每次弹出最大值 `x`，将其减半，减少量为 `x / 2`，累计减少量直到 >= `target`。

## 代码实现

### 方法一：最大堆贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def halveArray(self, nums: List[int]) -> int:
        total = sum(nums)
        target = total / 2  # 需要减少的总量

        # Python 只有最小堆，取负值模拟最大堆
        heap = [-x for x in nums]
        heapq.heapify(heap)

        reduced = 0.0  # 已减少的总量
        ops = 0

        while reduced < target:
            # 取出当前最大值（存的是负数）
            x = -heapq.heappop(heap)
            half = x / 2
            reduced += half       # 减少了 half
            heapq.heappush(heap, -half)  # 减半后的值重新入堆
            ops += 1

        return ops
```

### 方法二：使用 Python sortedcontainers（对比）

```python
from typing import List
import heapq

class Solution:
    def halveArray(self, nums: List[int]) -> int:
        # 与方法一相同逻辑，但注释更详细
        total = sum(nums)
        need = total / 2  # 需要减少的量

        # 最大堆（用负数模拟）
        pq = [-float(x) for x in nums]
        heapq.heapify(pq)

        ans = 0
        cur_reduced = 0.0

        while cur_reduced < need:
            # 弹出当前最大值
            val = -heapq.heappop(pq)
            # 减半后减少了 val/2
            cur_reduced += val / 2
            # 将减半后的值放回堆
            heapq.heappush(pq, -(val / 2))
            ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(k log n)，k 为操作次数，每次堆操作 O(log n)。k 最多约 O(n log(max_val))。
- 空间复杂度：O(n)，堆的空间。

## 关键点总结

1. 贪心：每次对当前最大值减半，收益最大。
2. 最大堆维护当前最大元素，注意 Python 用负数模拟最大堆。
3. 用浮点数追踪减少量，避免整数精度问题。

## 易错点

- Python 的 `heapq` 是最小堆，需要存负值模拟最大堆。
- 减少量用浮点数而非整数，因为可以无限减半。
- 循环条件是 `reduced < target`，即严格要求减少至少一半。
