## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，长度分别为 `n` 和 `m`。

计算：
- `answer1`：`nums1` 中存在于 `nums2` 中的元素个数（统计 nums1 中的每个元素，若该元素在 nums2 中存在，则计数，包括重复）
- `answer2`：`nums2` 中存在于 `nums1` 中的元素个数（同理）

返回 `[answer1, answer2]`。

**示例 1：**
```
输入：nums1 = [4,3,2,3,1], nums2 = [2,2,5,2,3,6]
输出：[3,4]
解释：
nums1 中 3,2,3 在 nums2 中出现，answer1=3
nums2 中 2,2,2,3 在 nums1 中出现，answer2=4
```

**示例 2：**
```
输入：nums1 = [3,4,2,3], nums2 = [1,5]
输出：[0,0]
```

**提示：**
- `n == nums1.length`
- `m == nums2.length`
- `1 <= n, m <= 100`
- `1 <= nums1[i], nums2[i] <= 100`

## 解题思路

用集合存储每个数组的元素，然后统计另一个数组中每个元素是否在集合中。

## Python 代码实现

### 方法一：集合查找（推荐）

```python
from typing import List

class Solution:
    def findIntersectionValues(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set1 = set(nums1)
        set2 = set(nums2)
        answer1 = sum(1 for x in nums1 if x in set2)
        answer2 = sum(1 for x in nums2 if x in set1)
        return [answer1, answer2]
```

### 方法二：Counter 统计

```python
from typing import List
from collections import Counter

class Solution:
    def findIntersectionValues(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set1 = set(nums1)
        set2 = set(nums2)
        return [
            sum(x in set2 for x in nums1),
            sum(x in set1 for x in nums2)
        ]
```

## 复杂度分析

- 时间复杂度：O(n + m)，建集合 O(n+m)，查找 O(n+m)
- 空间复杂度：O(n + m)，集合存储

## 关键点总结

1. 用集合加速查找（O(1) 查找）
2. answer1 统计 nums1 的每个元素（含重复），不是唯一元素
3. 两个方向分别统计

## 易错点

1. 包含重复计数：nums1 = [3,3]，若 3 在 nums2 中，answer1 = 2
2. 使用集合查找而不是遍历，避免 O(n*m)
