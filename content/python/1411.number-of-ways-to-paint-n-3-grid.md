## 题目描述

你有一个 `n x 3` 的网格，你需要用 **3 种不同颜色**涂色，使得相邻的格子（上下左右）颜色不同。

请问有多少种涂色方案？答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 1
输出：12
解释：对于 1×3 的网格，每行3格，相邻格子不同色，方案数为 3*2*2 = 12。
```

**示例 2：**

```
输入：n = 2
输出：54
```

**示例 3：**

```
输入：n = 3
输出：246
```

**提示：**

- `1 <= n <= 5000`

## 解题思路

这道题的核心在于：**每一行的涂色方案只有两类**。

### 关键观察：行的模式分类

对于一行 3 个格子，相邻格子颜色不同，设三种颜色为 1、2、3：

**ABA 型（首尾相同，共 12 种）：**

- 第1格和第3格颜色相同，第2格不同
- 计算：3 * 2 * 1 = 6 种... 实际上是 3（第1格颜色）* 2（第2格颜色）= 6，但第3格必须等于第1格，所以共 3 * 2 = 6? 
- 实际：A 有 3 种选法，B 有 2 种（不等于 A），第3格 = A，共 3 * 2 = 6 种？
- 不对，让我重新算：颜色数 = 3，ABA 型：A 的选法 3，B 的选法 2（不等于A），共 **3 * 2 = 6** 种... 但我们有颜色 {1,2,3}，ABA 型：(1,2,1), (1,3,1), (2,1,2), (2,3,2), (3,1,3), (3,2,3) → 共 **6 种**

**ABC 型（三格颜色各不同，共 6 种）：**

- 三格颜色两两不同
- A 有 3 种，B 有 2 种（不等于A），C 有 1 种（不等于A也不等于B）
- 共 3 * 2 * 1 = **6 种**

总计 6 + 6 = 12 种，与 n=1 时答案吻合。

### 行间转换规则

设上一行某个模式，下一行某个模式，需要对应列颜色不同：

**ABA 型转下一行：**
- 转 ABA 型：上行 (a, b, a) → 下行 (x, y, x)，需要 x≠a，y≠b，x≠a（y 还要不等于 x）。共 **3 种**
- 转 ABC 型：上行 (a, b, a) → 下行 (x, y, z)，需要 x≠a，y≠b，z≠a，x≠y，y≠z，x≠z。共 **2 种**（可推导）

**ABC 型转下一行：**
- 转 ABA 型：上行 (a, b, c) → 下行 (x, y, x)，需要 x≠a，y≠b，x≠c。共 **2 种**
- 转 ABC 型：上行 (a, b, c) → 下行 (x, y, z)，需要 x≠a，y≠b，z≠c，x≠y，y≠z，x≠z。共 **2 种**（可验证）

转换系数汇总：
- ABA → ABA: 3
- ABA → ABC: 2
- ABC → ABA: 2
- ABC → ABC: 2

### DP 状态定义

设 `aba[i]` 和 `abc[i]` 分别为第 `i` 行使用 ABA 型和 ABC 型的方案总数：

- `aba[1] = 6`（共6种ABA排列）
- `abc[1] = 6`（共6种ABC排列）
- `aba[i] = aba[i-1] * 3 + abc[i-1] * 2`
- `abc[i] = aba[i-1] * 2 + abc[i-1] * 2`

答案为 `aba[n] + abc[n]`。

## Python 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def numOfWays(self, n: int) -> int:
        MOD = 10**9 + 7

        # 初始化第一行
        # ABA 型（首尾颜色相同）：共 6 种
        aba = 6
        # ABC 型（三色各不同）：共 6 种
        abc = 6

        for _ in range(n - 1):
            # 计算下一行的方案数
            # 新 ABA = 旧 ABA * 3 + 旧 ABC * 2
            # 新 ABC = 旧 ABA * 2 + 旧 ABC * 2
            new_aba = aba * 3 + abc * 2
            new_abc = aba * 2 + abc * 2
            aba = new_aba % MOD
            abc = new_abc % MOD

        return (aba + abc) % MOD
```

### 方法二：矩阵快速幂（适合超大 n）

```python
class Solution:
    def numOfWays(self, n: int) -> int:
        MOD = 10**9 + 7

        def matrix_mult(A, B):
            """2x2 矩阵乘法"""
            n = len(A)
            C = [[0] * n for _ in range(n)]
            for i in range(n):
                for j in range(n):
                    for k in range(n):
                        C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
            return C

        def matrix_pow(M, p):
            """矩阵快速幂"""
            # 初始化单位矩阵
            result = [[1 if i == j else 0 for j in range(len(M))] for i in range(len(M))]
            while p:
                if p & 1:
                    result = matrix_mult(result, M)
                M = matrix_mult(M, M)
                p >>= 1
            return result

        # 转移矩阵：[[3, 2], [2, 2]]
        # state = [aba, abc]
        # 下一个 state = M * state
        M = [[3, 2], [2, 2]]

        # 计算 M^(n-1)
        Mn = matrix_pow(M, n - 1)

        # 初始 state = [6, 6]
        aba = (Mn[0][0] * 6 + Mn[0][1] * 6) % MOD
        abc = (Mn[1][0] * 6 + Mn[1][1] * 6) % MOD

        return (aba + abc) % MOD
```

### 方法三：暴力枚举（仅用于理解和验证，n 很小时）

```python
from typing import List

class Solution:
    def numOfWays(self, n: int) -> int:
        MOD = 10**9 + 7

        def valid_row(row: List[int]) -> bool:
            """检查一行内相邻格子颜色不同"""
            return row[0] != row[1] and row[1] != row[2]

        def compatible(row1: List[int], row2: List[int]) -> bool:
            """检查两行对应格子颜色不同"""
            return all(a != b for a, b in zip(row1, row2))

        # 生成所有合法的单行方案
        valid_rows = []
        for a in range(3):
            for b in range(3):
                for c in range(3):
                    row = [a, b, c]
                    if valid_row(row):
                        valid_rows.append(row)

        # dp[i] = 以 valid_rows[i] 结尾的方案数
        dp = [1] * len(valid_rows)

        for _ in range(n - 1):
            new_dp = [0] * len(valid_rows)
            for j, row2 in enumerate(valid_rows):
                for i, row1 in enumerate(valid_rows):
                    if compatible(row1, row2):
                        new_dp[j] = (new_dp[j] + dp[i]) % MOD
            dp = new_dp

        return sum(dp) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n) | O(1) |
| 矩阵快速幂 | O(log n) | O(1) |
| 暴力枚举 | O(n * 12^2) | O(12) |

本题 `n <= 5000`，O(n) DP 完全够用。

## 图解示例

以 n=2 验证：

```
第1行（12种）：ABA(6种) + ABC(6种)
第2行：
  ABA 贡献：6 * 3 + 6 * 2 = 30 种 ABA
  ABC 贡献：6 * 2 + 6 * 2 = 24 种 ABC
  总计：30 + 24 = 54 ✓
```

## 关键点总结

1. 将每行的12种合法方案归为 ABA（首尾同色）和 ABC（三色不同）两类
2. 推导两类之间的转移系数：ABA→ABA=3, ABA→ABC=2, ABC→ABA=2, ABC→ABC=2
3. 转移系数的推导需要枚举，确保理解正确
4. 每步取模，防止大数溢出
5. 矩阵快速幂可进一步优化到 O(log n)，适用于 n 极大的场景

## 易错点

1. 转移系数推导错误：建议手动枚举 (a,b,a) 的所有下一行情况来验证
2. 初始值：第1行 ABA 和 ABC 各有 6 种，总计 12 种
3. 模运算：每一步都要取模，不能只在最后取模
