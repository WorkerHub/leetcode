## 题目描述

给你一个字符串 `text`，该字符串由若干被空格包围的单词组成。每个单词由一个或多个小写英文字母组成，且两个单词之间至少有一个空格。

请重新排列空格，使每对相邻单词之间的空格数目都相等，并尽可能**最大化**该数目。如果不能重新平均分配所有空格，将多余的空格放在字符串末尾。

返回重新排列空格后的字符串。

**示例 1：**
```
输入：text = "  this is  a sentence "
输出："this   is   a   sentence"
解释：有 9 个空格，4 个单词，每两个单词之间放 9//3=3 个空格，余 0 个。
```

**提示：**
- `1 <= text.length <= 100`

## 解题思路

### 统计空格和单词

1. 统计总空格数 `total_spaces`
2. 分割出所有单词
3. 若只有一个单词，所有空格放末尾
4. 否则：间隔空格 = `total_spaces // (len(words) - 1)`，末尾空格 = 余数

## 代码实现

### 方法一：直接计算（推荐）

```python
class Solution:
    def reorderSpaces(self, text: str) -> str:
        total_spaces = text.count(' ')
        words = text.split()
        n = len(words)

        if n == 1:
            return words[0] + ' ' * total_spaces

        gap = total_spaces // (n - 1)
        remainder = total_spaces % (n - 1)

        return (' ' * gap).join(words) + ' ' * remainder
```

### 方法二：逐步计算

```python
class Solution:
    def reorderSpaces(self, text: str) -> str:
        spaces = sum(1 for c in text if c == ' ')
        words = text.split()

        if len(words) <= 1:
            return words[0] + ' ' * spaces if words else ' ' * spaces

        between = spaces // (len(words) - 1)
        extra = spaces % (len(words) - 1)
        sep = ' ' * between
        return sep.join(words) + ' ' * extra
```

## 复杂度分析

- **时间复杂度**：O(N)，N 为字符串长度
- **空间复杂度**：O(N)

## 关键点总结

1. 统计空格总数，分割单词
2. 只有一个单词时，所有空格放末尾
3. 间隔空格数 = `总空格 // (单词数 - 1)`，余数放末尾

## 易错点

- 只有一个单词时不能用 `(n-1)` 分母（除零）
- `text.split()` 会自动去掉多余空格
