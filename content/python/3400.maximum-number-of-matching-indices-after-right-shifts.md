## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，长度均为 `n`。

每次操作可以对 `nums1` 进行**右移**（将最后一个元素移到最前面）。

求在进行若干次右移后，`nums1[i] == nums2[i]` 的下标 `i` 的最大数量。

**示例：**
```
输入：nums1 = [3,2,1,4,7], nums2 = [1,2,3,4,3]
输出：3
解释：右移 2 次后 nums1 = [1,4,7,3,2]，与 nums2 比较：
     位置 1 (2==2), 位置 3 (3==3) ... 等等，找最大匹配数。
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 1000`

## 解题思路

**枚举右移次数：**

右移 `k` 次后，`nums1[(i - k) % n] == nums2[i]`，即 `nums1[j] == nums2[(j + k) % n]`。

等价于：枚举 `k` 从 0 到 n-1，统计匹配数 `sum(1 for i in range(n) if nums1[i] == nums2[(i + k) % n])`，取最大值。

**双指针优化（对排列类数组）：**

若直接枚举，时间复杂度为 O(n^2)，对 n <= 1000 完全够用。

对于更大的 n，可以用 FFT 计算相关性，但本题范围内暴力即可。

## Python 代码实现

### 方法一：枚举右移次数（推荐）

```python
from typing import List

class Solution:
    def maximumMatchingIndices(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        best = 0
        
        for k in range(n):
            # 右移 k 次后：nums1 的第 i 个元素变为原来的 nums1[(i - k) % n]
            # 即检查 nums1[(i - k) % n] == nums2[i]，等价于 nums1[j] == nums2[(j + k) % n]
            count = sum(1 for j in range(n) if nums1[j] == nums2[(j + k) % n])
            best = max(best, count)
        
        return best
```

### 方法二：拼接数组（直观写法）

```python
from typing import List

class Solution:
    def maximumMatchingIndices(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        best = 0
        
        # 拼接 nums2 与自身，用滑动窗口比较
        doubled_nums2 = nums2 + nums2
        
        for k in range(n):
            # 右移 k 次：nums1 的起始位置相当于 nums2 的偏移 k
            count = sum(1 for i in range(n) if nums1[i] == doubled_nums2[i + k])
            best = max(best, count)
        
        return best
```

### 方法三：直接模拟右移

```python
from typing import List
from collections import deque

class Solution:
    def maximumMatchingIndices(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        dq = deque(nums1)
        best = 0
        
        for _ in range(n):
            count = sum(1 for i in range(n) if dq[i] == nums2[i])
            best = max(best, count)
            # 右移一次：将最后一个移到最前面
            dq.appendleft(dq.pop())
        
        return best
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举 n 种右移，每次比较 O(n)
- 空间复杂度：O(n)，方法二的拼接数组

## 关键点总结

1. 右移 k 次等价于将 nums1 的第 i 个元素与 nums2 的第 `(i + k) % n` 个元素比较。
2. 枚举 k 从 0 到 n-1，统计每种右移下的匹配数，取最大值。
3. 拼接 nums2 双份可以避免取模操作，代码更直观。

## 易错点

1. 右移和左移的方向：右移 k 次使 `nums1[-k:]` 移到最前面，等价于 `nums1[(i-k)%n]` 对应 `nums2[i]`。
2. 双份拼接法中，偏移量 k 对应从 `doubled_nums2[k]` 开始的 n 个元素与 `nums1` 比较。
3. k 取 0 到 n-1（共 n 种右移），不是 1 到 n。
