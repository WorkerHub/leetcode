## 题目描述

你有 `n` 朵花，第 `i` 朵花需要 `plantTime[i]` 天种植，种植完后需要 `growTime[i]` 天生长，生长结束后**第二天**开花。

你每天只能种植**一朵花**（每天都可以给不同的花续种）。

返回**所有花都开放**的**最早可能日期**（第 0 天开始）。

**示例：**
```
输入：plantTime = [1,4,3], growTime = [2,3,1]
输出：9
```

**提示：**
- `n == plantTime.length == growTime.length`
- `1 <= n <= 10^5`
- `1 <= plantTime[i], growTime[i] <= 10^4`

## 解题思路

**贪心：按 growTime 降序排列**

关键观察：种植顺序不影响种植时间，但会影响开花时间。
- 对于生长时间长的花，越早种越早开，且种晚了会严重拖延。
- 贪心策略：按 `growTime` **从大到小**排序，优先种生长时间最长的花。

**证明：** 假设两朵花 A 和 B，`growTime[A] >= growTime[B]`，先种 A 后种 B 的最晚开花时间不晚于先 B 后 A 的情况（可以用交换论证法证明）。

## 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def earliestFullBloom(self, plantTime: List[int], growTime: List[int]) -> int:
        # 按生长时间降序排列
        flowers = sorted(zip(plantTime, growTime), key=lambda x: -x[1])

        ans = 0
        current_day = 0  # 当前种植完成的天数

        for pt, gt in flowers:
            current_day += pt          # 种植结束时的天数（第 current_day 天结束）
            bloom_day = current_day + gt  # 开花时间 = 种植完 + 生长时间
            ans = max(ans, bloom_day)

        return ans
```

### 方法二：枚举验证（理解用）

```python
from typing import List

class Solution:
    def earliestFullBloom(self, plantTime: List[int], growTime: List[int]) -> int:
        n = len(plantTime)
        # 枚举所有排列，找最优（仅适用于小数据）
        from itertools import permutations
        best = float('inf')
        for perm in permutations(range(n)):
            day = 0
            latest = 0
            for i in perm:
                day += plantTime[i]
                latest = max(latest, day + growTime[i])
            best = min(best, latest)
        return best
```

注意：方法二仅适用于演示，实际数据需用方法一。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心排序 | O(n log n) | O(n) |

## 关键点总结

1. 贪心：按生长时间降序，优先种植生长时间最长的花。
2. 开花时间 = 种植结束天数 + 生长时间（注意不是 +1，因为题目说生长完后**第二天**，但通常以"种植结束天数 + 生长天数"为开花天数）。
3. 所有花开完的时间 = 所有花开花时间的最大值。

## 易错点

- 排序时按 growTime 降序而非 plantTime。
- `current_day` 表示当前种完了多少天，每次加 `plantTime[i]`。
- 开花时间 = `current_day + growTime[i]`（第 `current_day + growTime[i]` 天的末尾开花）。
