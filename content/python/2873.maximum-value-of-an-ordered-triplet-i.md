## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

返回所有满足 `i < j < k` 的下标三元组 `(i, j, k)` 中，`(nums[i] - nums[j]) * nums[k]` 的**最大值**。如果所有三元组的值都是负数，返回 0。

**示例 1：**
```
输入：nums = [12,6,1,2,7]
输出：77
解释：(i=0,j=2,k=4): (12-1)*7 = 77
```

**示例 2：**
```
输入：nums = [1,10,3,4,19]
输出：133
解释：(i=1,j=2,k=4): (10-3)*19 = 133
```

**提示：**
- `3 <= nums.length <= 100`（简单版，小数据）
- `1 <= nums[i] <= 10^6`

## 解题思路

数据量小（n <= 100），直接枚举所有三元组 O(n^3)。

**优化（用于理解 2874）：**
- 固定 j，找最大的 nums[i]（i < j）和最大的 nums[k]（k > j）
- `(nums[i] - nums[j]) * nums[k]` 最大化

## Python 代码实现

### 方法一：暴力枚举（推荐，简单版）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    val = (nums[i] - nums[j]) * nums[k]
                    ans = max(ans, val)
        return ans
```

### 方法二：前缀最大值优化（O(n^2)）

```python
from typing import List

class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        # 预处理前缀最大值
        prefix_max = [0] * n
        prefix_max[0] = nums[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i])

        for j in range(1, n - 1):
            for k in range(j + 1, n):
                # 最优 nums[i] = prefix_max[j-1]
                val = (prefix_max[j - 1] - nums[j]) * nums[k]
                ans = max(ans, val)

        return ans
```

## 复杂度分析

- 方法一：时间 O(n^3)，空间 O(1)
- 方法二：时间 O(n^2)，空间 O(n)

## 关键点总结

1. 结果为负时返回 0
2. 暴力三重循环对小数据完全适用
3. 要最大化 `(nums[i] - nums[j]) * nums[k]`：nums[i] 越大越好，nums[j] 越小越好，nums[k] 越大越好

## 易错点

1. 注意下标约束 `i < j < k`
2. 返回值 >= 0（所有负值时返回 0）
