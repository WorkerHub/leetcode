## 题目描述

给你一个下标从 **0** 开始的正整数数组 `nums` 和一个正整数 `k`。

如果满足 `popcount(num1 OR num2) + popcount(num1 AND num2) >= k`，则称 `(num1, num2)` 是一个**优质数对**（其中 `popcount` 为二进制中 1 的个数，元素下标可以相同但下标不同）。

返回**优质数对**的数目。

**示例 1：**
```
输入：nums = [1,2,3,1], k = 3
输出：5
解释：有 5 个优质数对。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 60`

## 解题思路

**关键公式：**
`popcount(a OR b) + popcount(a AND b) = popcount(a) + popcount(b)`

**证明：**
`a OR b` 的每一位中，若 a 和 b 对应位都为 1（AND 为 1），它在 OR 中算 1 次，在 AND 中算 1 次，共 2 次；若只有一个为 1（AND 为 0），它在 OR 中算 1 次，AND 中 0 次，共 1 次。这恰好等于 `popcount(a) + popcount(b)`。

**因此条件化简为：`popcount(num1) + popcount(num2) >= k`**

**算法：**
1. 对每个数计算 `popcount`。
2. 统计各 popcount 出现次数。
3. 用二分查找，对每个 popcount 值 `p1`，找需要 `popcount >= k - p1` 的数的个数。

## 代码实现

### 方法一：前缀和 + 二分（推荐）

```python
from typing import List
from collections import Counter
import bisect

class Solution:
    def countExcellentPairs(self, nums: List[int], k: int) -> int:
        # 去重（num1 和 num2 下标不同即可，值可重复，但题目实际上要找有序数对）
        # 实际上需要去重吗？看题目：nums 中有重复，(i,j) 是下标对
        # 先去重求不同值，再考虑有序对
        unique = list(set(nums))
        
        # 计算每个唯一值的 popcount
        pops = sorted(bin(x).count('1') for x in unique)
        n = len(pops)
        
        # 前缀和：pops 已排序，pop_sum[i] 表示前 i 个数
        ans = 0
        for p in pops:
            # 需要 >= k - p 的数的个数
            need = k - p
            # 在有序数组中找第一个 >= need 的位置
            idx = bisect.bisect_left(pops, need)
            ans += n - idx
        
        return ans
```

### 方法二：计数数组

```python
from typing import List

class Solution:
    def countExcellentPairs(self, nums: List[int], k: int) -> int:
        unique = set(nums)
        
        # 统计各 popcount 的数量
        cnt = [0] * 31  # popcount 最大为 30（10^9 < 2^30）
        for x in unique:
            cnt[bin(x).count('1')] += 1
        
        # 计算 cnt 的后缀和（>= p 的数量）
        suffix = [0] * 32
        for p in range(29, -1, -1):
            suffix[p] = suffix[p + 1] + cnt[p]
        
        ans = 0
        for p1 in range(30):
            if cnt[p1] == 0:
                continue
            need = k - p1
            if need <= 0:
                # 所有数都满足
                ans += cnt[p1] * len(unique)
            elif need <= 30:
                ans += cnt[p1] * suffix[need]
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分 | O(n log n) | O(n) |
| 计数数组 | O(n) | O(1) |

## 关键点总结

1. 核心等式：`popcount(a OR b) + popcount(a AND b) = popcount(a) + popcount(b)`。
2. 去重后只需考虑不同值之间的组合。
3. 对 popcount 排序后用二分快速统计满足条件的对数。

## 易错点

- 题目允许 `(i, i)`（同一下标），即一个数与自身配对，也算优质数对。
- 去重后，有序对 `(a, b)` 和 `(b, a)` 都算，需要计算所有有序对，不是无序对。
