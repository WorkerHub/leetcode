## 题目描述

给你一个字符串 `word`。如果某个字母满足：其小写形式 **只** 出现在所有其大写形式 **之前**，则称该字母为 **特殊字母**。

更精确地说，字母 `c` 是特殊字母，当且仅当：
- `c` 的小写和大写形式都出现在 `word` 中
- `word` 中 `c` 的最后一次小写出现的位置，严格小于 `c` 的第一次大写出现的位置

返回 `word` 中 **特殊字母** 的数量。

**示例 1：**
```
输入：word = "aaAbcBC"
输出：3
解释：'a': last_lower=1, first_upper=2 -> 合法；'b': last_lower=3, first_upper=5 -> 合法；'c': last_lower=4, first_upper=6 -> 合法
```

**示例 2：**
```
输入：word = "Aa"
输出：0
解释：'a' 大写在索引 0，小写在索引 1，不满足。
```

**提示：**
- `1 <= word.length <= 2 * 10^5`
- `word` 只包含英文字母

## 解题思路

对每个字母，记录其小写最后出现的位置 `last_lower` 和大写最早出现的位置 `first_upper`。若两者都存在且 `last_lower < first_upper`，则该字母为特殊字母。

## Python 代码实现

### 方法一：哈希表记录位置（推荐）

```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        last_lower = {}   # 字母小写最后出现的位置
        first_upper = {}  # 字母大写最早出现的位置

        for i, c in enumerate(word):
            if c.islower():
                last_lower[c] = i  # 记录最后位置，覆盖即可
            else:
                lower_c = c.lower()
                if lower_c not in first_upper:
                    first_upper[lower_c] = i  # 只记录第一次

        ans = 0
        for c in 'abcdefghijklmnopqrstuvwxyz':
            if c in last_lower and c in first_upper:
                if last_lower[c] < first_upper[c]:
                    ans += 1
        return ans
```

### 方法二：一次遍历

```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        # last[c] 记录每个字符最后出现的位置
        last = {}
        for i, c in enumerate(word):
            last[c] = i

        ans = 0
        for c in 'abcdefghijklmnopqrstuvwxyz':
            C = c.upper()
            if c in last and C in last:
                # 小写的最后位置必须在大写的最早位置之前
                # 大写的最早位置：遍历找第一个大写
                # 等价于：所有小写都在所有大写之前
                # 即：小写最后位置 < 大写最早位置
                # 用 last[C] 不行，需要 first[C]
                pass

        # 正确做法还是用方法一
        return ans
```

## 复杂度分析

- 时间复杂度：O(n + 26)，n 为字符串长度
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 特殊字母要求：所有小写出现在所有大写之前
2. 只需比较小写最后位置 vs 大写最早位置
3. 需要同时存在大写和小写

## 易错点

1. 是小写的「最后」位置 < 大写的「最早」位置
2. 大写的最早位置不能用最后位置代替
