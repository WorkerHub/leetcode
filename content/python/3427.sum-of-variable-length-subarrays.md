## 题目描述

给你一个整数数组 `nums`，下标从 0 开始。

对于每个下标 `i`，定义该下标的贡献为子数组 `nums[max(0, i - nums[i])..i]` 的所有元素之和。

返回所有下标贡献之和。

**示例 1：**

```
输入：nums = [2,3,1]
输出：11
解释：
- i=0: 子数组 nums[max(0,0-2)..0] = nums[0..0] = [2]，和为 2
- i=1: 子数组 nums[max(0,1-3)..1] = nums[0..1] = [2,3]，和为 5
- i=2: 子数组 nums[max(0,2-1)..2] = nums[1..2] = [3,1]，和为 4
总和 = 2+5+4 = 11
```

**示例 2：**

```
输入：nums = [3,1,1]
输出：13
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= nums.length`

## 解题思路

对每个 `i`，计算 `sum(nums[max(0, i - nums[i])..i])`，累加得到总和。

使用**前缀和**数组可以 O(1) 计算任意区间的和。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int]) -> int:
        n = len(nums)

        # 构建前缀和：prefix[i] = nums[0] + nums[1] + ... + nums[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        total = 0
        for i in range(n):
            # 子数组起始下标
            left = max(0, i - nums[i])
            # 子数组 [left, i] 的和 = prefix[i+1] - prefix[left]
            total += prefix[i + 1] - prefix[left]

        return total
```

### 方法二：直接切片求和

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int]) -> int:
        total = 0
        for i in range(len(nums)):
            left = max(0, i - nums[i])
            # 切片求和
            total += sum(nums[left: i + 1])
        return total
```

### 方法三：一行写法

```python
from typing import List

class Solution:
    def subarraySum(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        return sum(prefix[i + 1] - prefix[max(0, i - nums[i])] for i in range(n))
```

## 复杂度分析

- 方法一（前缀和）：
  - 时间复杂度：O(n)
  - 空间复杂度：O(n)

- 方法二（直接切片）：
  - 时间复杂度：O(n^2)
  - 空间复杂度：O(1)

## 关键点总结

1. 子数组范围 `[max(0, i - nums[i]), i]`
2. 前缀和使区间查询降至 O(1)
3. `prefix[i+1] - prefix[left]` = `sum(nums[left..i])`

## 易错点

1. 左边界需要 `max(0, ...)` 防止下标越界
2. 前缀和数组 `prefix` 比 `nums` 多一个元素，`prefix[0] = 0`
3. 区间 `[left, i]` 对应 `prefix[i+1] - prefix[left]`（注意 i+1 而不是 i）
