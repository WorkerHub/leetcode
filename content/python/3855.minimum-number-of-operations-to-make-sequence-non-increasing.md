## 题目描述

给你一个整数数组 `nums`，每次操作可以将数组中的任意一个元素减 1（不能低于 0）。

返回使数组变为非递增序列所需的最少操作次数。

**示例 1：**

```
输入：nums = [3, 2, 5, 1]
输出：3
解释：将 5 减为 2（3 次操作），得到 [3, 2, 2, 1]，非递增。
```

**示例 2：**

```
输入：nums = [5, 3, 1]
输出：0
解释：已经非递增。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

从左到右遍历，维护当前允许的最大值（即前一个元素的值）。

每当 `nums[i] > prev`，需要将 `nums[i]` 减少到 `prev`，操作数增加 `nums[i] - prev`，同时将 `prev` 更新为 `prev`（保持当前值）。

## Python 代码实现

### 方法一：贪心遍历（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        ops = 0
        # 当前允许的最大值（非递增：每个元素 <= 前一个元素）
        max_allowed = float('inf')

        for v in nums:
            if v > max_allowed:
                # 需要将 v 减到 max_allowed
                ops += v - max_allowed
            else:
                max_allowed = v  # 更新允许的最大值为当前值

        return ops
```

### 方法二：前缀最小值

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        ops = 0
        curr_max = float('inf')

        for i in range(n):
            # 非递增：nums[i] 需要 <= nums[i-1]
            target = min(nums[i], curr_max)
            ops += nums[i] - target
            curr_max = target

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：从左到右，每次将当前元素降到不大于前一个元素的值。
2. 操作数 = 超出部分的总和。
3. 只能减少元素，不能增加（若 nums[i] < prev，保持不变，更新 curr_max）。

## 易错点

1. 只能减少（减 1），不能增加；若元素已满足条件则无需操作。
2. `curr_max` 更新为 `min(nums[i], curr_max)`，确保非递增单调性传递。
