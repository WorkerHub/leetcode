## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

```
翻转前：          翻转后：
     4             4
   /   \         /   \
  2     7       7     2
 / \   / \     / \   / \
1   3 6   9   9   6 3   1
```

**示例 2：**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

这道题是一道非常经典的二叉树问题，也是 Homebrew 作者 Max Howell 在 Google 面试时被问到的题目（虽然他是 Homebrew 的作者，但因为没有做出这道题而被拒）。

### 核心思想

翻转二叉树就是**交换每个节点的左右子树**。可以使用递归或迭代两种方式实现。

### 递归思路

1. 如果当前节点为空，直接返回
2. 递归翻转左子树
3. 递归翻转右子树
4. 交换当前节点的左右子树

### 迭代思路

使用队列（BFS）或栈（DFS）遍历所有节点，交换每个节点的左右子树。

## Python 代码实现

### 方法一：递归（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        # 基本情况：空节点直接返回
        if not root:
            return None
        
        # 交换左右子树
        root.left, root.right = root.right, root.left
        
        # 递归翻转左右子树
        self.invertTree(root.left)
        self.invertTree(root.right)
        
        return root
```

### 方法二：递归（先递归后交换）

```python
from typing import Optional

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        
        # 先递归翻转左右子树
        left = self.invertTree(root.left)
        right = self.invertTree(root.right)
        
        # 再交换
        root.left = right
        root.right = left
        
        return root
```

### 方法三：迭代（BFS 层序遍历）

```python
from typing import Optional
from collections import deque

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            
            # 交换当前节点的左右子树
            node.left, node.right = node.right, node.left
            
            # 将子节点加入队列
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        return root
```

### 方法四：迭代（DFS 前序遍历）

```python
from typing import Optional

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        
        stack = [root]
        
        while stack:
            node = stack.pop()
            
            # 交换左右子树
            node.left, node.right = node.right, node.left
            
            # 将子节点压入栈
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        
        return root
```

### 方法五：一行代码（Python 特色）

```python
from typing import Optional

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        return TreeNode(root.val, self.invertTree(root.right), self.invertTree(root.left)) if root else None
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是树中节点的数量，每个节点都要访问一次
- 空间复杂度：
  - 递归：O(h)，其中 h 是树的高度，递归调用栈的深度
  - 迭代：O(w)，其中 w 是树的最大宽度，队列或栈中最多存储一层的节点

## 关键点总结

1. **递归思想**：自顶向下或自底向上都可以
2. **交换操作**：Python 的元组赋值 `a, b = b, a` 简洁优雅
3. **遍历方式**：前序、后序、层序遍历都可以
4. **基本情况**：空节点直接返回
5. **原地修改**：直接修改原树，不需要创建新树

## 易错点

1. **忘记返回根节点**：函数需要返回翻转后的根节点
2. **交换顺序**：交换后再递归 vs 递归后再交换，两种都可以
3. **空节点检查**：要先检查节点是否为空
4. **迭代时的子节点检查**：加入队列/栈前要检查子节点是否为空
5. **误以为需要创建新树**：实际上直接修改原树即可
