## 题目描述

给你一个整数 `limit` 和一个二维整数数组 `queries`，`queries[i] = [xi, yi]`。

初始时，所有球（0 到 limit）都是无色的。每次查询将球 `xi` 染成颜色 `yi`。

返回每次查询后，具有独特颜色（即该颜色只有一个球拥有）的球的数量。

**示例 1：**
```
输入：limit = 4, queries = [[1,4],[2,5],[1,3],[3,4]]
输出：[1,2,2,3]
```

**提示：**
- `1 <= limit <= 10^9`
- `1 <= queries.length <= 10^5`

## 解题思路

维护两个哈希表：
1. `ball_color`：每个球当前的颜色
2. `color_count`：每种颜色被多少个球拥有
3. `unique_count`：颜色数量恰好为 1 的种数

每次染色时更新三个数据结构，并维护 unique_count。

## Python 代码实现

### 方法一：双哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def queryResults(self, limit: int, queries: List[List[int]]) -> List[int]:
        ball_color = {}      # 球 -> 当前颜色
        color_count = defaultdict(int)  # 颜色 -> 球数
        unique = 0           # 颜色数恰好为 1 的种数

        ans = []
        for x, y in queries:
            # 如果球 x 之前有颜色，移除旧颜色的计数
            if x in ball_color:
                old_c = ball_color[x]
                if color_count[old_c] == 1:
                    unique -= 1  # 旧颜色不再是唯一
                color_count[old_c] -= 1
                if color_count[old_c] == 1:
                    unique += 1  # 旧颜色现在是唯一

            # 添加新颜色 y
            if color_count[y] == 1:
                unique -= 1  # 新颜色原来是唯一，即将不再
            color_count[y] += 1
            if color_count[y] == 1:
                unique += 1  # 新颜色现在是唯一

            ball_color[x] = y
            ans.append(unique)

        return ans
```

### 方法二：维护唯一颜色集合

```python
from typing import List
from collections import defaultdict

class Solution:
    def queryResults(self, limit: int, queries: List[List[int]]) -> List[int]:
        ball_color = {}
        color_cnt = defaultdict(int)
        unique_colors = set()

        ans = []
        for x, y in queries:
            if x in ball_color:
                old = ball_color[x]
                color_cnt[old] -= 1
                if color_cnt[old] == 0:
                    unique_colors.discard(old)
                elif color_cnt[old] == 1:
                    unique_colors.add(old)
                else:
                    unique_colors.discard(old)

            old_cnt = color_cnt[y]
            color_cnt[y] += 1
            if old_cnt == 0:
                unique_colors.add(y)
            elif old_cnt == 1:
                unique_colors.discard(y)

            ball_color[x] = y
            ans.append(len(unique_colors))

        return ans
```

## 复杂度分析

- 时间复杂度：O(q)，每次查询 O(1)
- 空间复杂度：O(q)，哈希表大小

## 关键点总结

1. 维护 color_count 跟踪每种颜色的球数
2. 每次操作时更新 unique 计数（颜色数量从非 1 变为 1 或从 1 变为非 1）
3. 球的旧颜色和新颜色都需要处理

## 易错点

1. 更新旧颜色时：减 1 后若变为 1，则 unique+1；若从 1 减为 0，则 unique-1
2. 更新新颜色时：加 1 前若为 1，则 unique-1；加 1 后若变为 1，则 unique+1
