## 题目描述

给你一个整数数组 `arr` 和一个整数值 `target`。

请你在 `arr` 中找**两个互不重叠的子数组**，且每个子数组的数字和都等于 `target`。可能会有多种方案，请你返回满足要求的两个子数组**长度之和的最小值**；如果无法找到这样的两个子数组，请返回 **-1**。

**子数组**是数组的一个连续部分。

**示例 1：**

```
输入：arr = [3,2,2,4,3], target = 3
输出：2
解释：找到两个子数组：[3]（长度1）和 [3]（长度1），长度之和=2
```

**示例 2：**

```
输入：arr = [7,3,4,7], target = 7
输出：2
解释：找到 [7]（下标0）和 [7]（下标3），长度和=2
```

**示例 3：**

```
输入：arr = [4,3,2,6,2,3,4], target = 6
输出：-1
解释：没有两个不重叠的子数组各自和等于 6
```

**示例 4：**

```
输入：arr = [5,5,4,4,5], target = 3
输出：-1
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`
- **注意：数组元素均为正数**，这是滑动窗口可行的关键条件。

---

## 解题思路

**核心算法：滑动窗口 + 动态规划前缀最小值**

由于数组元素均为正数，可以用**滑动窗口**找到所有和等于 `target` 的子数组。

**步骤：**
1. 用滑动窗口遍历数组，找到所有和等于 `target` 的子数组，记录其结束位置和长度。
2. 维护前缀 DP 数组 `min_left[i]`：以下标 `i` 为右端点，`arr[0..i]` 中和等于 `target` 的子数组的最短长度。
3. 再次用滑动窗口从左到右遍历，当找到一个以 `i` 结尾的目标子数组时，查看其左边（`arr[0..l-1]`，其中 `l` 是子数组起始位置的前一个位置）是否存在另一个目标子数组，用 `min_left[l-1]` 获取最短长度并更新答案。

## Python 代码实现

### 方法一：滑动窗口 + 前缀DP（推荐）

```python
from typing import List

class Solution:
    def minSumOfLengths(self, arr: List[int], target: int) -> int:
        n = len(arr)
        INF = float('inf')

        # min_left[i]：arr[0..i] 范围内，和为 target 的子数组最短长度
        min_left = [INF] * n

        best = INF   # 当前遇到的最短目标子数组长度
        ans = INF    # 最终答案

        left = 0
        cur_sum = 0

        for right in range(n):
            cur_sum += arr[right]  # 扩展右边界

            # 窗口和超过 target 时，收缩左边界
            while cur_sum > target:
                cur_sum -= arr[left]
                left += 1

            # 找到和为 target 的窗口
            if cur_sum == target:
                length = right - left + 1  # 当前子数组长度

                # 如果左边存在另一个目标子数组，更新答案
                if left > 0 and min_left[left - 1] < INF:
                    ans = min(ans, min_left[left - 1] + length)

                best = min(best, length)  # 更新最短长度

            # 记录前缀最小值
            min_left[right] = best

        return ans if ans < INF else -1
```

### 方法二：两次扫描（前缀最小 + 后缀最小）

```python
from typing import List

class Solution:
    def minSumOfLengths(self, arr: List[int], target: int) -> int:
        n = len(arr)
        INF = float('inf')

        # 找出所有和为 target 的子数组（起止位置和长度）
        segments = []
        left = 0
        cur_sum = 0
        for right in range(n):
            cur_sum += arr[right]
            while cur_sum > target:
                cur_sum -= arr[left]
                left += 1
            if cur_sum == target:
                segments.append((left, right, right - left + 1))

        if len(segments) < 2:
            # 检查是否存在两个不重叠的
            pass

        if not segments:
            return -1

        # 构建前缀最小长度数组
        prefix_min = [INF] * n  # prefix_min[i]：arr[0..i] 中最短目标子数组长度
        for l, r, length in segments:
            if l == 0:
                prefix_min[r] = min(prefix_min[r] if r > 0 else INF, length)
            # 向右传播最小值
        cur_min = INF
        for i in range(n):
            for l, r, length in segments:
                if r == i:
                    cur_min = min(cur_min, length)
            prefix_min[i] = cur_min

        # 从右到左找最小长度对
        ans = INF
        suffix_min = INF
        for l, r, length in reversed(segments):
            if l > 0 and prefix_min[l - 1] < INF:
                ans = min(ans, prefix_min[l - 1] + length)

        return ans if ans < INF else -1
```

### 方法三：哈希表记录前缀和（两次遍历）

```python
from typing import List

class Solution:
    def minSumOfLengths(self, arr: List[int], target: int) -> int:
        n = len(arr)
        INF = float('inf')

        # 用哈希表记录前缀和出现的最近位置
        prefix_sum = {0: -1}  # 前缀和 -> 最近下标
        cur_sum = 0

        # best[i]：arr[0..i] 中和为 target 的子数组的最短长度
        best = [INF] * n
        cur_best = INF

        ans = INF

        for i in range(n):
            cur_sum += arr[i]

            # 检查是否存在以 i 结尾、和为 target 的子数组
            if cur_sum - target in prefix_sum:
                l = prefix_sum[cur_sum - target] + 1  # 子数组起始位置
                length = i - l + 1

                # 查找左侧（l-1 之前）的最短目标子数组
                if l > 0 and best[l - 1] < INF:
                    ans = min(ans, best[l - 1] + length)

                cur_best = min(cur_best, length)

            best[i] = cur_best
            prefix_sum[cur_sum] = i  # 记录当前前缀和位置

        return ans if ans < INF else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 + 前缀DP | O(n) | O(n) |
| 哈希表前缀和 | O(n) | O(n) |

- 所有方法时间复杂度均为 O(n)，一次或两次线性扫描。

## 关键点总结

1. **数组元素为正数**是使用滑动窗口的前提，否则不能用滑动窗口（因为加入元素时窗口和单调增加）。
2. 前缀 DP 数组 `min_left[i]` 记录 `arr[0..i]` 范围内最短的目标子数组长度，方便 O(1) 查询。
3. 找到以 `right` 结尾的目标子数组（起始 `left`）后，查 `min_left[left-1]` 获取不重叠的最短子数组。
4. 注意处理 `left == 0` 的情况（子数组从头开始，左侧没有空间放第二个子数组）。

---

## 易错点

- **左侧越界**：当 `left == 0` 时，没有左侧空间，不能访问 `min_left[-1]`。
- **不重叠条件**：两个子数组必须不重叠，所以第二个子数组的起始位置必须 > 第一个子数组的结束位置。
- **收缩条件**：滑动窗口收缩时，`while cur_sum > target` 而不是 `>=`，因为要允许 `cur_sum == target`。
