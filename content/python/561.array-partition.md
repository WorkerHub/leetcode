## 题目描述

给定长度为 `2n` 的整数数组 `nums`，你的任务是将这些数分成 `n` 对，例如 `(a1, b1), (a2, b2), ..., (an, bn)`，使得从 1 到 n 的 `min(ai, bi)` 总和最大。

返回该最大总和。

**示例 1：**
```
输入：nums = [1,4,3,2]
输出：4
解释：所有可能的分法（忽略元素顺序）为：
1. (1, 4), (2, 3) -> min(1, 4) + min(2, 3) = 1 + 2 = 3
2. (1, 3), (2, 4) -> min(1, 3) + min(2, 4) = 1 + 2 = 3
3. (1, 2), (3, 4) -> min(1, 2) + min(3, 4) = 1 + 3 = 4
所以最大总和为 4
```

**示例 2：**
```
输入：nums = [6,2,6,5,1,2]
输出：9
解释：最优的分法是 (2, 1), (2, 5), (6, 6). min(2, 1) + min(2, 5) + min(6, 6) = 1 + 2 + 6 = 9
```

**提示：**
- `1 <= n <= 10^4`
- `nums.length == 2 * n`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

这是一道贪心问题。

核心观察：
- 要使 min(a, b) 的和最大，需要让配对的两个数尽可能接近
- 排序后，相邻的数配对是最优策略
- 取排序后的第 0, 2, 4, ... 个元素

## Python 代码实现

### 方法一：排序 + 贪心（推荐）⭐

```python
from typing import List

class Solution:
    def arrayPairSum(self, nums: List[int]) -> int:
        """
        排序后取偶数索引元素
        
        时间复杂度：O(n log n)
        空间复杂度：O(log n)，排序的空间
        """
        nums.sort()
        return sum(nums[::2])
```

### 方法二：显式遍历

```python
from typing import List

class Solution:
    def arrayPairSum(self, nums: List[int]) -> int:
        """
        显式遍历
        
        时间复杂度：O(n log n)
        空间复杂度：O(log n)
        """
        nums.sort()
        result = 0
        for i in range(0, len(nums), 2):
            result += nums[i]
        return result
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(log n)，排序的栈空间

## 关键点总结

1. **贪心策略**：排序后相邻配对
2. **Python 切片**：`nums[::2]` 取偶数索引
3. **数学证明**：相邻配对使损失最小
