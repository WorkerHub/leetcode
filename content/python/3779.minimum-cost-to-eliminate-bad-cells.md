## 题目描述

给定 `m × n` 的矩阵，其中 `0` 表示空格，`1` 表示坏格子。可以花费代价消除坏格子（将其变为 0）。从左上角 `(0,0)` 出发，到达右下角 `(m-1,n-1)`，每次只能向右或向下移动。求使路径中不含坏格子的最小代价。

**示例 1：**
```
输入：grid = [[0,1,0],[0,0,1],[1,0,0]]
输出：1
解释：路径 (0,0)->(1,0)->(1,1)->(2,1)->(2,2)，不含坏格。代价 0。
     路径 (0,0)->(0,1)... 但 (0,1)=1，需消除它，代价 1，或选不经过它的路径。
     存在代价 0 的路径，答案为 0？检查：(0,0),(1,0),(1,1),(2,1),(2,2) 均为 0，代价 0。
```

**提示：**
- `1 <= m, n <= 100`
- `grid[i][j]` 为 0 或 1

## 解题思路

最短路问题：每个格子的代价为 `grid[i][j]`（0 或 1），求从左上到右下的最小代价路径（只能向右或向下）。

用 Dijkstra 或 0-1 BFS（双端队列）求解，代价为路径上所有坏格子的数量。

## Python 代码实现

### 方法一：0-1 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minCostPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = grid[0][0]

        # 0-1 BFS：代价为 0 的边放队首，代价为 1 的边放队尾
        dq = deque([(0, 0)])
        dirs = [(0, 1), (1, 0)]  # 只能向右或向下

        while dq:
            r, c = dq.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    new_cost = dist[r][c] + grid[nr][nc]
                    if new_cost < dist[nr][nc]:
                        dist[nr][nc] = new_cost
                        if grid[nr][nc] == 0:
                            dq.appendleft((nr, nc))
                        else:
                            dq.append((nr, nc))

        return dist[m-1][n-1]
```

### 方法二：DP（若只向右或向下移动）

```python
from typing import List

class Solution:
    def minCostPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[float('inf')] * n for _ in range(m)]
        dp[0][0] = grid[0][0]

        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                top = dp[i-1][j] if i > 0 else float('inf')
                left = dp[i][j-1] if j > 0 else float('inf')
                dp[i][j] = min(top, left) + grid[i][j]

        return dp[m-1][n-1]
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 坏格子代价为 1，好格子代价为 0，用 0-1 BFS 求最短路
2. 若只能向右/向下，DP 是更简单的解法
3. 0-1 BFS 比 Dijkstra 快（O(mn) vs O(mn log(mn))）

## 易错点

1. 起点的代价是 `grid[0][0]`（可能是坏格）
2. 方向约束（只向右或向下）时 DP 更优
