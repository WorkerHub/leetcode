## 题目描述

在柠檬水摊上，每一杯柠檬水的售价为 5 美元。顾客排队购买你的产品，（按账单 bills 支付的顺序）一次购买一杯。

每位顾客只买一杯柠檬水，然后向你付 5 美元、10 美元或 20 美元。你必须给每个顾客正确找零，也就是说净交易是每位顾客向你支付 5 美元。

注意，一开始你手头没有任何零钱。

给你一个整数数组 bills ，其中 bills[i] 是第 i 位顾客付的账。如果你能给每位顾客正确找零，返回 true ，否则返回 false 。

**示例 1：**
```
输入：bills = [5,5,5,10,20]
输出：true
解释：
前 3 位顾客那里，我们按顺序收到 3 张 5 美元的钞票。
第 4 位顾客那里，我们收到一张 10 美元的钞票，并返还 5 美元。
第 5 位顾客那里，我们找还一张 10 美元的钞票和一张 5 美元的钞票。
由于所有客户都得到了正确的找零，所以我们输出 true。
```

**示例 2：**
```
输入：bills = [5,5,10,10,20]
输出：false
解释：
前 2 位顾客那里，我们按顺序收到 2 张 5 美元的钞票。
对于接下来的 2 位顾客，我们收到一张 10 美元的钞票，然后返还 5 美元。
对于最后一位顾客，我们无法退回 15 美元，因为我们现在只有两张 10 美元的钞票。
由于不是每位顾客都得到了正确的找零，所以答案是 false。
```

**提示：**
- 1 <= bills.length <= 10^5
- bills[i] 不是 5 就是 10 或是 20

## 解题思路

这是一道典型的**贪心算法**题目。

**核心思想：**
- 维护手头的 5 美元和 10 美元钞票数量
- 找零时优先使用大面额（10 美元）

**找零规则：**
1. **收到 5 美元**：直接收下，不需要找零
2. **收到 10 美元**：找零 5 美元
3. **收到 20 美元**：找零 15 美元
   - 优先：1张10美元 + 1张5美元
   - 其次：3张5美元

**为什么优先使用 10 美元找零？**
- 5 美元更通用，10 美元只能找 20 美元
- 保留更多 5 美元可以应对更多情况

**算法流程：**
1. 记录 5 美元和 10 美元的数量
2. 遍历每个顾客的账单
3. 根据面额进行找零
4. 如果无法找零，返回 false

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five = 0  # 5 美元的数量
        ten = 0   # 10 美元的数量
        
        for bill in bills:
            if bill == 5:
                # 收到 5 美元，不需要找零
                five += 1
            elif bill == 10:
                # 收到 10 美元，找零 5 美元
                if five == 0:
                    return False
                five -= 1
                ten += 1
            else:  # bill == 20
                # 收到 20 美元，找零 15 美元
                # 优先：1张10 + 1张5
                if ten > 0 and five > 0:
                    ten -= 1
                    five -= 1
                # 其次：3张5
                elif five >= 3:
                    five -= 3
                else:
                    return False
        
        return True
```

**代码说明：**
- 只需要记录 5 和 10 的数量，不需要记录 20（20 不能用来找零）
- 找 20 时优先用 10+5 而不是 5+5+5

### 方法二：字典计数

```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        cash = {5: 0, 10: 0}
        
        for bill in bills:
            if bill == 5:
                cash[5] += 1
            elif bill == 10:
                if cash[5] == 0:
                    return False
                cash[5] -= 1
                cash[10] += 1
            else:  # 20
                # 优先 10 + 5
                if cash[10] > 0 and cash[5] > 0:
                    cash[10] -= 1
                    cash[5] -= 1
                # 否则 5 + 5 + 5
                elif cash[5] >= 3:
                    cash[5] -= 3
                else:
                    return False
        
        return True
```

### 方法三：简化版

```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five, ten = 0, 0
        
        for bill in bills:
            if bill == 5:
                five += 1
            elif bill == 10:
                if not five:
                    return False
                five, ten = five - 1, ten + 1
            else:
                # 优先使用 10 + 5
                if ten and five:
                    five, ten = five - 1, ten - 1
                elif five >= 3:
                    five -= 3
                else:
                    return False
        
        return True
```

### 方法四：详细注释版（便于理解）

```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        # 记录手头的零钱
        count_5 = 0
        count_10 = 0
        # 注意：不需要记录 20，因为 20 无法用来找零
        
        for bill in bills:
            if bill == 5:
                # 顾客支付 5 美元
                # 不需要找零，直接收下
                count_5 += 1
            
            elif bill == 10:
                # 顾客支付 10 美元
                # 需要找零 5 美元
                if count_5 < 1:
                    return False  # 无法找零
                count_5 -= 1
                count_10 += 1
            
            else:  # bill == 20
                # 顾客支付 20 美元
                # 需要找零 15 美元
                
                # 策略1：优先使用 1张10 + 1张5
                # 原因：5 美元更万能，尽量保留
                if count_10 >= 1 and count_5 >= 1:
                    count_10 -= 1
                    count_5 -= 1
                
                # 策略2：使用 3张5
                elif count_5 >= 3:
                    count_5 -= 3
                
                # 无法找零
                else:
                    return False
        
        return True
```

## 关键点总结

1. **贪心策略**：找 20 时优先用 10+5 而不是 5+5+5
2. **只记录 5 和 10**：20 不能用来找零，无需记录
3. **即时判断**：一旦无法找零立即返回 false
4. **优先级**：5 美元比 10 美元更重要，因为更通用
5. **简单模拟**：按顺序处理，不需要复杂的数据结构

## 易错点

1. **找零顺序错误**：
   ```python
   # ❌ 错误：优先使用 3张5
   if five >= 3:
       five -= 3
   elif ten > 0 and five > 0:
       ten -= 1
       five -= 1
   
   # ✅ 正确：优先使用 10+5
   if ten > 0 and five > 0:
       ten -= 1
       five -= 1
   elif five >= 3:
       five -= 3
   ```

2. **记录 20 的数量**：20 无法用来找零，记录它没有意义

3. **条件判断不完整**：
   ```python
   # ❌ 错误：没有检查是否有足够的零钱
   five -= 1
   
   # ✅ 正确：先检查
   if five == 0:
       return False
   five -= 1
   ```
