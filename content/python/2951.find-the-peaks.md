## 题目描述

给你一个下标从 0 开始的整数数组 `mountain`。

如果下标 `i` 满足 `0 < i < mountain.length - 1`（非边界），且 `mountain[i] > mountain[i-1]` 且 `mountain[i] > mountain[i+1]`，则称该下标为 **峰值**。

返回数组 `mountain` 中所有峰值的下标组成的数组，顺序任意。

**示例 1：**
```
输入：mountain = [2,4,4]
输出：[]
```

**示例 2：**
```
输入：mountain = [1,4,3,8,5]
输出：[1,3]
```

**提示：**
- `3 <= mountain.length <= 100`
- `1 <= mountain[i] <= 100`

## 解题思路

遍历所有非边界位置（下标 1 到 n-2），检查是否严格大于相邻两侧。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def findPeaks(self, mountain: List[int]) -> List[int]:
        n = len(mountain)
        return [i for i in range(1, n - 1)
                if mountain[i] > mountain[i - 1] and mountain[i] > mountain[i + 1]]
```

### 方法二：显式循环

```python
from typing import List

class Solution:
    def findPeaks(self, mountain: List[int]) -> List[int]:
        peaks = []
        for i in range(1, len(mountain) - 1):
            if mountain[i] > mountain[i - 1] and mountain[i] > mountain[i + 1]:
                peaks.append(i)
        return peaks
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(k)，k 为峰值个数

## 关键点总结

1. 峰值必须是非边界位置（下标 1 到 n-2）
2. 严格大于两侧（不能等于）
3. 返回下标，不是值

## 易错点

1. 边界下标 0 和 n-1 不能是峰值
2. 严格大于（不是 >=）
