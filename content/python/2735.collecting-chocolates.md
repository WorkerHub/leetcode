## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，代表收集不同类型巧克力的代价，以及一个整数 `x`。

你可以执行以下操作 **任意次**：
- 将每种类型 `i` 的收集代价改为类型 `(i+1) % n` 的代价，整体操作代价为 `x`

收集所有 `n` 种类型巧克力的最小代价是什么？

**示例 1：**
```
输入：nums = [20,1,15], x = 5
输出：13
解释：操作 1 次（代价5）后，类型0可用1收集，类型2可用1收集：min cost = 1+1+1+5=8? 
重新计算：类型0可选 min(20,1)=1，类型1可选 min(1,15)=1，类型2可选 min(15,20,1)=1，操作1次代价5+3=8
```

**示例 2：**
```
输入：nums = [1,2,3], x = 4
输出：6
```

**提示：**
- `1 <= nums.length <= 10^3`
- `1 <= nums[i] <= 10^9`
- `1 <= x <= 10^9`

## 解题思路

枚举操作次数 `k`（从 0 到 n-1）：
- 操作 `k` 次后，每种类型 `i` 可从 `nums[i], nums[(i-1)%n], ..., nums[(i-k)%n]` 中选最小值
- 总代价 = `k * x` + 各类型最小代价之和

预处理每种类型在不同操作次数下的最小代价，逐步更新 `min_cost[i] = min(min_cost[i], nums[(i-k)%n])`。

## Python 代码实现

### 方法一：枚举操作次数（推荐）

```python
from typing import List

class Solution:
    def minCostToAcquireAllTypesOfFruits(self, nums: List[int], x: int) -> int:
        n = len(nums)
        # min_cost[i] 记录类型 i 在当前操作次数下的最小代价
        min_cost = list(nums)
        ans = sum(min_cost)  # 0 次操作

        for k in range(1, n):
            # 操作 k 次后，类型 i 可以选 nums[(i-k)%n]
            for i in range(n):
                min_cost[i] = min(min_cost[i], nums[(i - k) % n])
            # 总代价 = k*x + 各类型最小代价之和
            ans = min(ans, k * x + sum(min_cost))

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 操作 k 次可以让类型 i 访问 k+1 个候选值（循环偏移）
2. 枚举操作次数，逐步更新每个类型的最小代价
3. 操作次数从 0 到 n-1（超过 n 次无意义）

## 易错点

1. 循环索引使用 `(i - k) % n` 处理环形
2. 0 次操作时不需要乘以 x，直接是 `sum(nums)`
