## 题目描述

给定一个包含 `[0, n]` 中 `n` 个数的数组 `nums`，找出 `[0, n]` 这个范围内没有出现在数组中的那个数。

**示例 1：**
```
输入: nums = [3,0,1]
输出: 2
解释: n = 3，因为有 3 个数字，所以所有的数字都在范围 [0,3] 内。
2 是缺失的数字，因为它没有出现在 nums 中。
```

**示例 2：**
```
输入: nums = [0,1]
输出: 2
解释: n = 2，因为有 2 个数字，所以所有的数字都在范围 [0,2] 内。
2 是缺失的数字。
```

**示例 3：**
```
输入: nums = [9,6,4,2,3,5,7,0,1]
输出: 8
解释: n = 9，缺失的数字是 8。
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^4`
- `0 <= nums[i] <= n`
- `nums` 中的所有数字都**唯一**

**进阶：** 你能否实现线性时间复杂度、仅使用额外常数空间的算法？

## 解题思路

这是一道经典的数组问题，有多种巧妙的解法。

**核心观察：**
- 数组长度为 n，包含 [0, n] 中的 n 个不同数字
- 恰好缺少一个数字

**五种经典解法：**

1. **数学求和**：期望和 - 实际和 = 缺失数字
2. **位运算（异或）**：利用 x ^ x = 0 的性质
3. **哈希表**：标记出现过的数字
4. **排序**：排序后检查不连续的位置
5. **原地哈希**：利用数组本身作为哈希表

## Python 代码实现

### 方法一：数学求和（推荐）⭐

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        n = len(nums)
        # 0 到 n 的和：n * (n + 1) / 2
        expected_sum = n * (n + 1) // 2
        actual_sum = sum(nums)
        return expected_sum - actual_sum
```

### 方法二：位运算（异或）⭐

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        """
        利用异或的性质：
        1. x ^ x = 0
        2. x ^ 0 = x
        3. 异或满足交换律和结合律
        
        思路：将 [0, n] 所有数字和 nums 中所有数字异或
        成对的数字会相互抵消，剩下的就是缺失的数字
        """
        n = len(nums)
        result = n  # 先异或 n（因为 nums 中只有 0 到 n-1）
        
        for i in range(n):
            result ^= i ^ nums[i]
        
        return result
```

### 方法三：集合差集

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        n = len(nums)
        # 完整集合 - 当前集合 = 缺失的数字
        full_set = set(range(n + 1))
        nums_set = set(nums)
        return (full_set - nums_set).pop()
```

### 方法四：排序

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        nums.sort()
        
        # 检查是否缺失 0
        if nums[0] != 0:
            return 0
        
        # 检查是否缺失 n
        n = len(nums)
        if nums[-1] != n:
            return n
        
        # 检查中间缺失的数字
        for i in range(1, n):
            if nums[i] != nums[i - 1] + 1:
                return nums[i - 1] + 1
```

### 方法五：一行代码（数学方法）

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        n = len(nums)
        return n * (n + 1) // 2 - sum(nums)
```

### 方法六：位运算简化版

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        """更简洁的异或写法"""
        result = len(nums)
        for i, num in enumerate(nums):
            result ^= i ^ num
        return result
```

### 方法七：使用 reduce

```python
from functools import reduce
import operator

class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        n = len(nums)
        # 将所有索引和值异或
        all_xor = reduce(operator.xor, range(n + 1), 0)
        nums_xor = reduce(operator.xor, nums, 0)
        return all_xor ^ nums_xor
```

## 复杂度分析

### 方法一、五（数学求和）
- **时间复杂度**：O(n)，遍历数组一次求和
- **空间复杂度**：O(1)

### 方法二、六、七（位运算）
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)

### 方法三（集合）
- **时间复杂度**：O(n)，构建两个集合
- **空间复杂度**：O(n)，额外的集合空间

### 方法四（排序）
- **时间复杂度**：O(n log n)，排序的时间
- **空间复杂度**：O(1) 或 O(n)，取决于排序算法

## 图解示例

### 数学方法示例：`nums = [3,0,1]`

```
n = 3

期望和: 0 + 1 + 2 + 3 = 6
实际和: 3 + 0 + 1 = 4

缺失数字: 6 - 4 = 2
```

### 异或方法示例：`nums = [3,0,1]`

```
初始: result = 3 (n)

i=0: result = 3 ^ 0 ^ 3 = 0
i=1: result = 0 ^ 1 ^ 0 = 1
i=2: result = 1 ^ 2 ^ 1 = 2

缺失数字: 2

原理解释：
完整序列: 0, 1, 2, 3
数组中:   3, 0, 1

异或所有数字:
0 ^ 1 ^ 2 ^ 3 ^ 3 ^ 0 ^ 1
= (0 ^ 0) ^ (1 ^ 1) ^ 2 ^ (3 ^ 3)
= 0 ^ 0 ^ 2 ^ 0
= 2
```

## 关键点总结

1. **数学方法最直观**：利用等差数列求和公式 `n(n+1)/2`
2. **位运算最巧妙**：
   - 利用 `x ^ x = 0` 和 `x ^ 0 = x`
   - 所有成对的数字会抵消
3. **空间优化**：方法一和二都是 O(1) 空间
4. **溢出问题**：
   - Python 整数不会溢出
   - 其他语言可能需要考虑 `(n * (n + 1)) / 2` 的溢出
5. **异或的优势**：不会有溢出问题

## 易错点

1. **求和公式错误**：
   ```python
   # 正确
   n * (n + 1) // 2
   
   # 错误（忘记加 1）
   n * n // 2
   ```

2. **数组长度理解**：
   - 数组长度为 n
   - 完整范围是 [0, n]，共 n+1 个数
   - 数组中有 n 个数，缺 1 个

3. **异或初始值**：
   ```python
   # 正确：初始化为 n
   result = len(nums)
   
   # 错误：初始化为 0
   result = 0  # 需要额外异或 n
   ```

4. **边界情况**：
   - `nums = [0]` → 缺失 1
   - `nums = [1]` → 缺失 0

5. **除法运算**：使用 `//` 而不是 `/`（Python3）

