## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回满足以下条件的下标对 `(i, j)` 的数量：

- `0 <= i < j < n`
- `|nums[i] - nums[j]| <= k`

**示例 1：**

```
输入：nums = [1,2,3,4], k = 1
输出：3
解释：(0,1):|1-2|=1, (1,2):|2-3|=1, (2,3):|3-4|=1
```

**示例 2：**

```
输入：nums = [1,3,5], k = 2
输出：1
解释：只有(0,1):|1-3|=2<=2
```

**提示：**

- `2 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

**暴力 O(n^2)**：枚举所有对，判断差值。

**排序 + 双指针**：先排序，对每个右端点 `j`，找最小的 `i` 使得 `nums[j] - nums[i] <= k`（因为排序后 `nums[j] >= nums[i]`），统计有效下标数。

注意：排序会打乱原始下标，但题目只要求计数。

## Python 代码实现

### 方法一：暴力（推荐，n<=10^4可接受）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            for j in range(i + 1, n):
                if abs(nums[i] - nums[j]) <= k:
                    count += 1
        return count
```

### 方法二：排序 + 双指针

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        nums_sorted = sorted(nums)
        n = len(nums_sorted)
        count = 0
        left = 0

        for right in range(n):
            # 移动左指针，找最小的 left 使得 nums_sorted[right] - nums_sorted[left] <= k
            while nums_sorted[right] - nums_sorted[left] > k:
                left += 1
            # [left, right-1] 中的所有元素都满足条件
            count += right - left

        return count
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一），O(n log n)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 绝对值差 `|a - b| <= k` 等价于 `-k <= a - b <= k`
2. 排序后可以利用单调性，用双指针降低复杂度
3. 排序方法中 `right - left` 统计了满足条件的左端点数量

## 易错点

1. 排序破坏了原始下标，但题目只要求计数
2. 双指针：`count += right - left`（不含 right 本身）
3. k = 0 时只统计相等的对
