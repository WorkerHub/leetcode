## 题目描述

给你 `n` 名英雄，每名英雄有对应的力量值 `heroes[i]`，以及 `m` 枚硬币，每枚硬币有对应的值 `coins[j]` 和难度 `difficulty[j]`。

如果英雄力量值 >= 硬币难度值，该英雄可以收集该硬币。

返回一个数组，`ans[i]` = 第 i 名英雄可以收集的所有硬币的**总值**。

**示例 1：**
```
输入：heroes = [1,4,2], coins = [1,6,2,3,3,5], difficulty = [2,3,1,1,4,3]
输出：[1,7,4]
解释：
英雄 1（力量=1）：只能收集难度<=1 的硬币：coin[2]=2（难度1），收集...等等
```

**提示：**
- `1 <= n, m <= 10^5`
- `1 <= heroes[i], coins[j], difficulty[j] <= 10^9`

## 解题思路

**排序 + 前缀和 + 二分查找：**

1. 将 (difficulty, coin_value) 按 difficulty 排序
2. 计算按 difficulty 排序后的 coin_value 前缀和
3. 对每个英雄，二分查找力量值能覆盖的硬币范围（difficulty <= power），直接用前缀和得到总值

## Python 代码实现

### 方法一：排序 + 前缀和 + 二分查找（推荐）

```python
import bisect
from typing import List

class Solution:
    def maximumCoins(self, heroes: List[int], coins: List[int], difficulty: List[int]) -> List[int]:
        # 将硬币按难度排序，同时保留硬币值
        sorted_coins = sorted(zip(difficulty, coins))
        
        # 计算前缀和
        m = len(sorted_coins)
        prefix = [0] * (m + 1)
        sorted_diff = []
        for i, (d, c) in enumerate(sorted_coins):
            sorted_diff.append(d)
            prefix[i + 1] = prefix[i] + c

        # 对每个英雄，二分查找可收集的硬币
        result = []
        for power in heroes:
            # 找第一个难度 > power 的位置
            idx = bisect.bisect_right(sorted_diff, power)
            result.append(prefix[idx])

        return result
```

### 方法二：两指针（排序英雄）

```python
from typing import List

class Solution:
    def maximumCoins(self, heroes: List[int], coins: List[int], difficulty: List[int]) -> List[int]:
        n = len(heroes)
        m = len(coins)

        # 排序硬币和英雄（记录原始下标）
        sorted_coins = sorted(zip(difficulty, coins))
        sorted_heroes = sorted(enumerate(heroes), key=lambda x: x[1])

        ans = [0] * n
        total = 0
        j = 0  # 硬币指针

        for idx, power in sorted_heroes:
            # 加入所有难度 <= power 的硬币
            while j < m and sorted_coins[j][0] <= power:
                total += sorted_coins[j][1]
                j += 1
            ans[idx] = total

        return ans
```

## 复杂度分析

- 方法一：时间 O((n+m) log m)，空间 O(m)
- 方法二：时间 O(n log n + m log m)，空间 O(n + m)

## 关键点总结

1. 排序硬币后，前缀和直接回答"难度 <= x 的所有硬币之和"
2. 二分查找找边界，O(log m) 回答每个英雄的查询
3. 方法二用双指针，只对英雄排序一次，更高效

## 易错点

1. 排序时同时排 difficulty 和对应的 coin_value
2. 二分用 `bisect_right`（找第一个 > power 的位置），包含等于的情况
3. 方法二要记录英雄的原始下标，最后还原结果顺序
