## 题目描述

给你一个正整数数组 `nums` 和一个正整数 `k`。

每次操作中，你需要从 `nums` 的**末尾**删除一个元素。

返回使 `nums` 包含 `1` 到 `k` 之间所有元素所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [3,1,5,2,5,3], k = 5
输出：5
解释：从末尾删除 5 次：[3,1,5,2,5,3] -> [3,1,5,2,5] -> ... -> [3,1]? 等等
删除操作将末尾元素移走。我们需要剩余数组中包含 1 到 5 所有元素。
末尾 5 次删除后，剩余 [3,1]，但没有 2,4,5...
```

**修正：** 实际上，每次操作从末尾删除，当已收集到 1..k 所有值时停止。

所以从末尾开始收集：找到最少删除次数使剩余前缀包含 1..k。

**示例 1：**
```
nums = [3,1,5,2,5,3], k = 5
从末尾：收集 3(没满) -> 5(收3,5) -> 5(已有5) -> 2(收2) -> 1(收1) -> 3(已有，但还缺4)
等等，没有 4，但 k=5 需要 {1,2,3,4,5}... 实际例子可能不同
```

## 解题思路

从末尾开始删除，维护已收集的 1..k 的集合。当集合大小等于 k 时停止。

每次删除一个末尾元素，若该元素在 1..k 范围内且尚未收集，加入集合。

## Python 代码实现

### 方法一：从末尾遍历（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        collected = set()
        n = len(nums)

        for i in range(n - 1, -1, -1):
            x = nums[i]
            if 1 <= x <= k:
                collected.add(x)
            if len(collected) == k:
                return n - i  # 从末尾删除了 n - i 个元素

        return n  # 理论上不会到这里（题目保证有解）
```

### 方法二：位掩码优化

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        # 用位掩码表示已收集的元素
        mask = 0
        target = (1 << k) - 1  # k 位全为 1

        n = len(nums)
        for i in range(n - 1, -1, -1):
            x = nums[i]
            if 1 <= x <= k:
                mask |= (1 << (x - 1))  # 标记第 x 个元素
            if mask == target:
                return n - i

        return n
```

## 复杂度分析

- 时间复杂度：O(n)，从末尾遍历一次
- 空间复杂度：O(k)，集合最多 k 个元素

## 关键点总结

1. 从末尾开始删除，每次收集新的 1..k 元素
2. 当集合大小 = k 时，删除的次数 = n - 当前下标
3. 位掩码可以 O(1) 检查是否收集完全

## 易错点

1. 只统计 1 到 k 范围内的元素
2. 操作次数 = 从末尾开始删除了多少个元素，即 `n - i`（当在下标 i 时收集完毕）
3. 题目保证数组包含 1..k 所有元素
