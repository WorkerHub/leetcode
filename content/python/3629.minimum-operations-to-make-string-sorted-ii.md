## 题目描述

给你一个字符串 `s`，每次操作选择最长的严格递减后缀，将其反转并追加到当前字符串末尾（可理解为一种字典序递增的变换）。

返回使字符串变为字典序最大排列所需的最小操作次数，结果对 `10^9 + 7` 取模。

**示例 1：**

```
输入：s = "cba"
输出：5
解释：cba → cbacba → ... 经过5步变换达到最大排列
```

**示例 2：**

```
输入：s = "aabb"
输出：2
```

**提示：**

- `1 <= s.length <= 3000`
- `s` 只包含小写字母

## 解题思路

等价于：计算字符串在所有排列中按字典序的排名（从末尾开始）。

操作等价于找到当前排列在所有排列中从末尾数第几个，即字典序排名从小到大中的位置。

**公式**：当前排列的排名（从最大排列计）= `Σ (cnt_i! / prod(freq_j!)) * (比s[i]大的字符数) * i!`

使用组合数学：计算在所有 `n!` 个排列中，当前排列之后还有多少个排列，就是操作次数。

## Python 代码实现

### 方法一：组合数学逆序统计（推荐）

```python
class Solution:
    def makeStringSorted(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)

        # 预计算阶乘和逆元
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        def modinv(a, m=MOD):
            return pow(a, m - 2, m)

        # 字符频率
        from collections import Counter
        freq = Counter(s)

        # 计算当前排列之前有多少个排列（即操作次数）
        ans = 0
        # 剩余字符的全排列数 = n! / (freq[c]! for all c)
        # 对每个位置，统计比当前字符小的字符数量，乘以剩余全排列数

        # 分母：当前频率下的排列除数
        denom = 1
        for c in freq:
            denom = denom * fact[freq[c]] % MOD
        inv_denom = modinv(denom)

        remaining = n
        for char in s:
            # 比 char 小的字符数
            smaller = sum(freq[c] for c in freq if c < char)
            # 当前位置选这些字符中任一的排列数
            perms = fact[remaining - 1] * inv_denom % MOD
            ans = (ans + smaller * perms) % MOD

            # 更新
            inv_denom = inv_denom * freq[char] % MOD  # 去掉 char 一个，分母缩小 freq[char]，逆元乘以 freq[char]
            freq[char] -= 1
            if freq[char] == 0:
                del freq[char]
            remaining -= 1

        return ans
```

### 方法二：模拟（小数据）

```python
class Solution:
    def makeStringSorted(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        # 找最长严格递减后缀并操作（仅用于理解，效率低）
        ops = 0
        s = list(s)
        target = sorted(s, reverse=True)
        while s != target:
            # 找最长递减后缀
            i = len(s) - 1
            while i > 0 and s[i] >= s[i - 1]:
                i -= 1
            # 翻转后缀
            s[i:] = s[i:][::-1]
            ops = (ops + 1) % MOD
        return ops
```

## 复杂度分析

- 时间复杂度：O(n * 26)，遍历字符串每个位置
- 空间复杂度：O(26)

## 关键点总结

1. 操作次数 = 当前排列的字典序排名（从1开始）- 1
2. 利用组合数公式计算排名：逐位统计小于当前字符的个数乘以剩余排列数
3. 需要模运算的逆元处理重复字符

## 易错点

1. 有重复字符时，全排列数要除以各字符频率的阶乘
2. 逆元更新时：去掉一个字符 `c`，分母从 `freq[c]!` 变为 `(freq[c]-1)!`，故逆元乘以 `freq[c]`
3. 注意模运算不影响逆元的正确性
