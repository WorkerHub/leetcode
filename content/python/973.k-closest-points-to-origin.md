## 题目描述

给定一个数组 `points`，其中 `points[i] = [xi, yi]` 表示 X-Y 平面上的一个点，并且是一个整数 `k`，返回离原点 `(0, 0)` 最近的 `k` 个点。

这里，平面上两点之间的距离是**欧几里德距离**（即，`√(x1 - x2)² + (y1 - y2)²`）。

你可以按**任何顺序**返回答案。除了点坐标的顺序之外，答案**确保**是**唯一**的。

**示例 1：**
```
输入：points = [[1,3],[-2,2]], k = 1
输出：[[-2,2]]
解释：
(1, 3) 和原点之间的距离为 sqrt(10)，
(-2, 2) 和原点之间的距离为 sqrt(8)，
由于 sqrt(8) < sqrt(10)，(-2, 2) 离原点更近。
我们只需要距离原点最近的 K = 1 个点，所以答案就是 [[-2,2]]。
```

**示例 2：**
```
输入：points = [[3,3],[5,-1],[-2,4]], k = 2
输出：[[3,3],[-2,4]]
解释：答案 [[-2,4],[3,3]] 也会被接受。
```

**提示：**
- `1 <= k <= points.length <= 10^4`
- `-10^4 < xi, yi < 10^4`

## 解题思路

这是一道经典的 TopK 问题，有多种解法。

**核心思想：**
1. 计算每个点到原点的距离
2. 找出距离最小的 k 个点
3. 注意：不需要计算真实距离（开方），比较距离平方即可

**方法选择：**
- 排序：O(n log n)
- 堆：O(n log k)
- 快速选择：O(n) 平均

## Python 代码实现

### 方法一：排序（最简单）⭐

```python
from typing import List

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        # 按距离平方排序
        points.sort(key=lambda p: p[0]**2 + p[1]**2)
        return points[:k]
```

### 方法二：最大堆（推荐）

```python
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        # 使用最大堆维护最小的 k 个距离
        # Python 的 heapq 是最小堆，用负数模拟最大堆
        heap = []
        
        for x, y in points:
            dist = x**2 + y**2
            
            if len(heap) < k:
                heapq.heappush(heap, (-dist, [x, y]))
            elif dist < -heap[0][0]:
                heapq.heapreplace(heap, (-dist, [x, y]))
        
        return [point for _, point in heap]
```

### 方法三：快速选择（最优）

```python
import random

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        def dist(point):
            return point[0]**2 + point[1]**2
        
        def partition(left, right):
            """快速选择的分区函数"""
            # 随机选择 pivot
            pivot_idx = random.randint(left, right)
            pivot_dist = dist(points[pivot_idx])
            
            # 将 pivot 移到末尾
            points[pivot_idx], points[right] = points[right], points[pivot_idx]
            
            # 分区
            store_idx = left
            for i in range(left, right):
                if dist(points[i]) < pivot_dist:
                    points[i], points[store_idx] = points[store_idx], points[i]
                    store_idx += 1
            
            # 将 pivot 放回正确位置
            points[store_idx], points[right] = points[right], points[store_idx]
            
            return store_idx
        
        def quick_select(left, right, k):
            """快速选择第 k 小的元素"""
            if left >= right:
                return
            
            pivot_idx = partition(left, right)
            
            if pivot_idx == k:
                return
            elif pivot_idx < k:
                quick_select(pivot_idx + 1, right, k)
            else:
                quick_select(left, pivot_idx - 1, k)
        
        quick_select(0, len(points) - 1, k)
        return points[:k]
```

### 方法四：最小堆

```python
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        # 计算所有点的距离并放入堆
        heap = []
        for x, y in points:
            dist = x**2 + y**2
            heapq.heappush(heap, (dist, [x, y]))
        
        # 取出最小的 k 个
        result = []
        for _ in range(k):
            _, point = heapq.heappop(heap)
            result.append(point)
        
        return result
```

### 方法五：使用 nsmallest

```python
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        return heapq.nsmallest(k, points, key=lambda p: p[0]**2 + p[1]**2)
```

## 复杂度分析

### 方法一：排序
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)，排序栈空间

### 方法二：最大堆
- **时间复杂度**：O(n log k)
- **空间复杂度**：O(k)

### 方法三：快速选择
- **时间复杂度**：O(n) 平均，O(n²) 最坏
- **空间复杂度**：O(log n)，递归栈

### 方法五：nsmallest
- **时间复杂度**：O(n log k)
- **空间复杂度**：O(k)

## 关键点总结

1. **距离计算**：只需要比较距离平方，无需开方
2. **TopK 问题**：有排序、堆、快速选择三种经典方法
3. **堆的选择**：k 较小用最大堆，否则用排序
4. **快速选择**：最优解，但代码复杂
5. **Python 技巧**：heapq.nsmallest 最简洁

## 易错点

1. **距离计算**：不要忘记平方和
2. **堆的类型**：维护最小 k 个用最大堆
3. **快速选择**：分区函数的边界处理
4. **k 的范围**：题目保证 k <= len(points)
5. **返回顺序**：任意顺序都可以
