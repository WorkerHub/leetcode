## 题目描述

给你一个大小为 `m x n` 的二维整数矩阵 `grid`，以及一个整数 `k`。

从左上角 `(0, 0)` 出发，只能向右或向下移动，到达右下角 `(m-1, n-1)`。

路径上所有元素的**异或值**等于 `k` 的路径数量，结果对 `10^9 + 7` 取模。

**示例：**
```
输入：grid = [[2,1,5],[7,10,0],[12,6,4]], k = 11
输出：3
```

**提示：**
- `1 <= m, n <= 300`
- `0 <= grid[i][j] <= 15`（取值范围小，异或结果也在 [0, 15]）
- `0 <= k <= 15`

## 解题思路

**动态规划：**

定义 `dp[i][j][v]` = 从 `(0,0)` 到 `(i,j)` 且路径异或值为 `v` 的路径数量。

转移方程：
- `dp[i][j][v] = dp[i-1][j][v ^ grid[i][j]] + dp[i][j-1][v ^ grid[i][j]]`
- 即：要使到达 `(i,j)` 时异或值为 `v`，则到达上方或左方时的异或值应为 `v ^ grid[i][j]`

初始条件：`dp[0][0][grid[0][0]] = 1`（其他为 0）

由于 `grid[i][j] <= 15`，异或结果最多 4 位，取值 `[0, 15]`，第三维只需 16。

## Python 代码实现

### 方法一：三维 DP（推荐）

```python
from typing import List

class Solution:
    def countPathsWithXorValue(self, grid: List[List[int]], k: int) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])
        MAX_XOR = 16  # 因为 grid[i][j] <= 15，异或值范围 [0, 15]
        
        # dp[i][j][v] = 从 (0,0) 到 (i,j) 且路径异或值为 v 的路径数
        dp = [[[0] * MAX_XOR for _ in range(n)] for _ in range(m)]
        
        dp[0][0][grid[0][0]] = 1
        
        # 第一行：只能从左走
        for j in range(1, n):
            for v in range(MAX_XOR):
                prev_v = v ^ grid[0][j]
                dp[0][j][v] = (dp[0][j][v] + dp[0][j - 1][prev_v]) % MOD
        
        # 第一列：只能从上走
        for i in range(1, m):
            for v in range(MAX_XOR):
                prev_v = v ^ grid[i][0]
                dp[i][0][v] = (dp[i][0][v] + dp[i - 1][0][prev_v]) % MOD
        
        # 其余格子
        for i in range(1, m):
            for j in range(1, n):
                for v in range(MAX_XOR):
                    prev_v = v ^ grid[i][j]
                    dp[i][j][v] = (dp[i - 1][j][prev_v] + dp[i][j - 1][prev_v]) % MOD
        
        return dp[m - 1][n - 1][k] % MOD
```

### 方法二：滚动数组优化空间

```python
from typing import List

class Solution:
    def countPathsWithXorValue(self, grid: List[List[int]], k: int) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])
        MAX_XOR = 16
        
        # 只保留当前行
        prev_row = [[0] * MAX_XOR for _ in range(n)]
        
        # 初始化第一行
        prev_row[0][grid[0][0]] = 1
        for j in range(1, n):
            for v in range(MAX_XOR):
                prev_v = v ^ grid[0][j]
                prev_row[j][v] = prev_row[j - 1][prev_v] % MOD
        
        for i in range(1, m):
            curr_row = [[0] * MAX_XOR for _ in range(n)]
            for j in range(n):
                for v in range(MAX_XOR):
                    prev_v = v ^ grid[i][j]
                    # 从上方
                    curr_row[j][v] = prev_row[j][prev_v]
                    # 从左方
                    if j > 0:
                        curr_row[j][v] = (curr_row[j][v] + curr_row[j - 1][prev_v]) % MOD
            prev_row = curr_row
        
        return prev_row[n - 1][k]
```

## 复杂度分析

- 时间复杂度：O(m * n * 16)，三重循环
- 空间复杂度：O(m * n * 16) 方法一，O(n * 16) 方法二

## 关键点总结

1. 异或的逆运算是其自身：`a ^ b = c` 等价于 `a = c ^ b`，用于反推前驱状态的异或值。
2. 由于值域小（0-15），第三维只需 16，状态空间可控。
3. 滚动数组可将空间从 O(m*n*16) 降至 O(n*16)。

## 易错点

1. DP 中 `prev_v = v ^ grid[i][j]`，而不是 `v ^ grid[i][j] = prev_v`（注意方向）。
2. 第一行和第一列的初始化需要单独处理（只有一个方向来源）。
3. 注意对 `MOD` 取模，防止溢出。
