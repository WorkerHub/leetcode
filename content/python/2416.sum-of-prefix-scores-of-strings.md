## 题目描述

给你一个长度为 `n` 的数组 `words`，该数组由 **非空** 字符串组成。

定义字符串 `word` 的 **分数** 等于 `words` 中以 `word` 为 **前缀** 的字符串数目。

- 例如，若 `words = ["a","ab","bc","b"]`，那么 `"b"` 的分数为 2（`"bc"` 和 `"b"` 以 `"b"` 为前缀）。

返回一个长度为 `n` 的数组 `ans`，其中 `ans[i]` 等于第 `i` 个字符串所有前缀的分数之和。

**示例 1：**
```
输入：words = ["abc","ab","bc","b"]
输出：[5,4,3,2]
解释：
- "abc" 的所有前缀：a(2)、ab(2)、abc(1)，总分 = 5
- "ab" 的所有前缀：a(2)、ab(2)，总分 = 4
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 1000`
- `words[i]` 由小写英文字母组成

## 解题思路

**字典树（Trie）方法：**
1. 构建字典树，每个节点记录经过该节点的字符串数量 `count`
2. 将所有 `words` 插入字典树，每经过一个节点，`count + 1`
3. 对每个 `words[i]`，沿着字典树查询，累加路径上每个节点的 `count`，即为前缀分数之和

**为什么正确？** 字典树节点 `count` 表示有多少个 `words` 的前缀经过此节点，等于以该节点路径为前缀的字符串数目。

## 代码实现

### 方法一：字典树（推荐）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.count = 0  # 经过此节点的字符串数量

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        """插入单词，路径上每个节点 count+1"""
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            node.count += 1

    def score(self, word: str) -> int:
        """查询单词所有前缀的分数之和"""
        node = self.root
        total = 0
        for ch in word:
            if ch not in node.children:
                break
            node = node.children[ch]
            total += node.count
        return total

class Solution:
    def sumPrefixScores(self, words: List[str]) -> List[int]:
        trie = Trie()
        # 将所有单词插入字典树
        for word in words:
            trie.insert(word)
        # 查询每个单词的前缀分数之和
        return [trie.score(word) for word in words]
```

### 方法二：哈希表暴力（对比学习）

```python
from typing import List
from collections import defaultdict

class Solution:
    def sumPrefixScores(self, words: List[str]) -> List[int]:
        # 统计所有前缀的出现次数
        prefix_count = defaultdict(int)
        for word in words:
            for i in range(1, len(word) + 1):
                prefix_count[word[:i]] += 1

        # 计算每个单词的前缀分数之和
        ans = []
        for word in words:
            total = sum(prefix_count[word[:i]] for i in range(1, len(word) + 1))
            ans.append(total)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 字典树 | O(n * L) | O(n * L) |
| 哈希表暴力 | O(n * L^2) | O(n * L^2) |

其中 n 为单词数量，L 为平均单词长度。

## 关键点总结

1. 字典树每个节点的 `count` 统计经过该节点的单词数
2. 对每个单词，沿字典树遍历，将路径上所有节点的 `count` 累加
3. 这等价于统计所有前缀各自在 `words` 中出现的次数之和

## 易错点

- 插入时每个节点 `count+1`（不是叶子节点 +1）
- 查询时要累加路径上所有节点的 count，而不是只看终点
