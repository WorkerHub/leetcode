## 题目描述

你有一段用于拆除炸弹的代码。给你一个长度为 `n` 的**环形**整数数组 `code` 和一个密钥 `k`。

要解密代码，你必须替换掉每一个数字。所有数字同时被替换：
- 如果 `k > 0`，将第 `i` 个数字用**接下来 `k` 个数字之和**来替换
- 如果 `k < 0`，将第 `i` 个数字用**之前 `|k|` 个数字之和**来替换
- 如果 `k == 0`，将第 `i` 个数字替换为 `0`

由于数组是**环形**的，序列中的下一个元素会循环到第一个。

返回解密后的数组。

**示例：**
```
输入：code = [5,7,1,4], k = 3
输出：[12,10,16,13]
解释：5 的后 3 个是 7+1+4=12，7 的后 3 个是 1+4+5=10，等
```

## 解题思路

**滑动窗口：**
- k > 0：窗口为 `[i+1, i+k]`
- k < 0：窗口为 `[i+k, i-1]`（`|k|` 个前面的数）
- k == 0：直接返回全 0 数组

## 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def decrypt(self, code: List[int], k: int) -> int:
        n = len(code)
        result = [0] * n
        
        if k == 0:
            return result
        
        # 确定滑动窗口的起点和终点
        # 用取模处理环形
        
        # 初始化第一个窗口的和
        if k > 0:
            start, end = 1, k
        else:
            start, end = n + k, n - 1
        
        window_sum = sum(code[i % n] for i in range(start, end + 1))
        
        for i in range(n):
            result[i] = window_sum
            # 滑动窗口：移出旧元素，加入新元素
            window_sum -= code[start % n]
            window_sum += code[(end + 1) % n]
            start += 1
            end += 1
        
        return result
```

### 方法二：前缀和

```python
from typing import List

class Solution:
    def decrypt(self, code: List[int], k: int) -> int:
        n = len(code)
        if k == 0:
            return [0] * n
        
        # 将数组复制一份（处理环形）
        extended = code * 2
        prefix = [0] * (2 * n + 1)
        for i in range(2 * n):
            prefix[i + 1] = prefix[i] + extended[i]
        
        result = []
        for i in range(n):
            if k > 0:
                l, r = i + 1, i + k
            else:
                l, r = i + n + k, i + n - 1
            result.append(prefix[r + 1] - prefix[l])
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 前缀和 | O(n) | O(n) |

## 关键点总结

1. 环形数组：下标用 `% n` 处理
2. k > 0 看后面 k 个，k < 0 看前面 |k| 个
3. 滑动窗口每次移动时减去最左边元素，加上最右边新元素

## 易错点

- 环形下标处理：`(i + j) % n`
- k < 0 时窗口在 i 的左边：初始窗口为 `[n+k, n-1]`（相对下标）
- k == 0 时直接返回全 0
