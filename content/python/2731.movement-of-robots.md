## 题目描述

一些机器人在无限长的数轴上移动。给你一个整数数组 `nums`，其中 `nums[i]` 是第 `i` 个机器人的初始位置。同时给你一个字符串 `s`，其中 `s[i]` 是 `'L'` 或 `'R'`，表示机器人的移动方向。

每一秒，每个机器人向指定方向移动一步。两个机器人相撞时，它们 **互换方向**（等价于穿透彼此）。

经过 `d` 秒后，返回所有机器人对之间距离的总和（对 `10^9 + 7` 取模）。

**示例 1：**
```
输入：nums = [-2,0,2], s = "RLL", d = 3
输出：8
```

**提示：**
- `2 <= nums.length <= 10^5`
- `-2 * 10^9 <= nums[i] <= 2 * 10^9`
- `0 <= d <= 10^9`
- `s.length == nums.length`

## 解题思路

**关键洞察**：碰撞并互换方向等价于机器人穿透（位置互换标签不影响总体位置集合）。

1. 每个机器人独立移动 `d` 步后，最终位置为 `nums[i] + d`（R）或 `nums[i] - d`（L）
2. 对最终位置排序
3. 计算所有对之间的距离总和：排序后，每个位置 `pos[i]` 对前 `i` 个位置的贡献 = `pos[i] * i - prefix_sum`

## Python 代码实现

### 方法一：排序 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def sumDistance(self, nums: List[int], s: str, d: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)

        # 计算每个机器人 d 秒后的位置
        final_pos = []
        for i, num in enumerate(nums):
            if s[i] == 'R':
                final_pos.append(num + d)
            else:
                final_pos.append(num - d)

        # 排序
        final_pos.sort()

        # 计算所有对距离之和
        # 排序后，对 i, j (i < j): dist = pos[j] - pos[i]
        # pos[i] 对后面 n-1-i 个元素的贡献（作为较小值）：-(n-1-i) * pos[i]
        # pos[i] 对前面 i 个元素的贡献（作为较大值）：i * pos[i]
        # 总贡献 = (2*i - (n-1)) * pos[i]
        ans = 0
        prefix = 0
        for i, pos in enumerate(final_pos):
            ans = (ans + pos * i - prefix) % MOD
            prefix += pos

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 碰撞等价于穿透，最终位置集合不变
2. 排序后用前缀和 O(n) 计算所有对距离之和
3. 对第 `i` 个（0-indexed）元素，前面有 `i` 个更小的，贡献 `pos[i] * i - prefix`

## 易错点

1. 机器人位置可能很大，中间计算需取模
2. 碰撞穿透原理是解题核心，不需要模拟碰撞
