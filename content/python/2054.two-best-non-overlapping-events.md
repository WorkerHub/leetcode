## 题目描述

给你一个由 `events` 组成的二维整数数组，`events[i] = [startTime_i, endTime_i, value_i]`，表示一个时间区间 `[startTime_i, endTime_i]` 内的活动，参与后可获得 `value_i` 的价值。

你**最多**可以参加 **2 个** 活动，且活动不能在同一时间同时进行（即不能重叠，但可以相邻：一个在时间 `t` 结束，另一个在时间 `t+1` 开始）。

返回你能获得的最大价值之和。

**示例 1：**
```
输入：events = [[1,3,2],[4,5,2],[2,4,3]]
输出：4
解释：参加活动 0 和 1（[1,3] 和 [4,5]），获得 2+2=4
```

**提示：**
- `2 <= events.length <= 10^5`
- `1 <= startTime_i <= endTime_i <= 10^9`
- `1 <= value_i <= 10^6`

## 解题思路

**排序 + 二分查找：**
1. 按结束时间排序
2. 对于每个活动 `i`，找在它开始之前结束的最大价值活动（二分查找）
3. 维护前缀最大价值数组

**DP 变体：**
- `best[i]` = 前 `i` 个活动（按结束时间排序）中的最大价值
- 对活动 `i`，找结束时间 `< start_i` 的最后一个活动 `j`，计算 `best[j] + value_i`

## 代码实现

### 方法一：排序 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxTwoEvents(self, events: List[List[int]]) -> int:
        # 按结束时间排序
        events.sort(key=lambda x: x[1])
        n = len(events)

        # ends[i] = events[i] 的结束时间
        ends = [e[1] for e in events]

        # best[i] = events[0..i] 中的最大价值（i 从 0 开始）
        best = [0] * n
        best[0] = events[0][2]
        for i in range(1, n):
            best[i] = max(best[i - 1], events[i][2])

        ans = 0
        for i in range(n):
            start, end, val = events[i]

            # 参加一个活动
            ans = max(ans, val)

            # 找在 start-1 之前结束的最后一个活动
            pos = bisect.bisect_right(ends, start - 1) - 1
            if pos >= 0:
                ans = max(ans, best[pos] + val)

        return ans
```

### 方法二：堆（最小堆，按结束时间）

```python
from typing import List
import heapq

class Solution:
    def maxTwoEvents(self, events: List[List[int]]) -> int:
        # 按开始时间排序
        events.sort(key=lambda x: x[0])

        # 最小堆存 (结束时间, 价值)
        heap = []  # (end_time, value)
        max_val_so_far = 0
        ans = 0

        for start, end, val in events:
            # 弹出所有在 start 之前结束的活动，更新最大价值
            while heap and heap[0][0] < start:
                max_val_so_far = max(max_val_so_far, heapq.heappop(heap)[1])

            # 当前活动与之前最优活动组合
            ans = max(ans, val + max_val_so_far)

            # 单独参加当前活动
            heapq.heappush(heap, (end, val))

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+二分 | O(n log n) | O(n) |
| 堆 | O(n log n) | O(n) |

## 关键点总结

1. 两个活动不能重叠：一个结束时间 `<` 另一个开始时间
2. 排序后二分查找找到最近的不冲突活动
3. `best` 数组维护前缀最大价值（而非单个活动的价值）

## 易错点

- 活动不重叠条件：`end1 < start2`（严格小于），即活动 1 的结束时间严格小于活动 2 的开始时间
- 二分查找找的是 `end <= start - 1`，即 `bisect_right(ends, start - 1) - 1`
