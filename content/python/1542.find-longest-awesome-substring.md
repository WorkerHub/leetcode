## 题目描述

给你一个字符串 `s`，请你返回 `s` 中**最长的 awesome 子字符串**的长度。

"awesome" 字符串定义为：可以重新排列后构成一个回文字符串（即至多有一个字符出现奇数次）。

**示例 1：**
```
输入：s = "3242415"
输出：5
解释："24241" 可以重新排列成 "24142" 或其他回文串
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只含数字字符（0-9）

## 解题思路

### 前缀异或 + 哈希表

回文串的条件：至多一个字符出现奇数次 → 用 10 位二进制数（对应 0-9 各字符的奇偶性）表示状态。

`prefix_mask[i]` = `s[0..i-1]` 中各数字出现奇偶性的 XOR 掩码。

子串 `s[l..r]` 能构成回文 iff `prefix_mask[r+1] XOR prefix_mask[l]` 中至多 1 位为 1（最多一个字符奇数次）。

**算法：**
- 遍历 `i`，维护 `mask`（当前前缀的奇偶状态）
- 对每个 `i`：
  1. 若 `mask` 在哈希表中已存在（奇偶状态完全相同），子串 `s[first[mask]..i-1]` 全为偶数次 → 更新答案
  2. 对每一位 `j`（0-9），若 `mask XOR (1<<j)` 在哈希表中存在（仅 j 位不同），子串中只有 j 对应数字出现奇数次 → 更新答案

## 代码实现

### 方法一：前缀异或 + 哈希表（推荐）

```python
class Solution:
    def longestAwesome(self, s: str) -> int:
        # first_seen[mask] = 该 mask 第一次出现的位置（前缀结束位置）
        first_seen = {0: -1}  # mask=0 在下标 -1 处（空前缀）
        mask = 0
        ans = 0

        for i, c in enumerate(s):
            # 翻转第 c 位（c 为数字字符）
            mask ^= 1 << int(c)

            # 情况1：当前 mask 之前出现过（偶数次子串）
            if mask in first_seen:
                ans = max(ans, i - first_seen[mask])
            else:
                first_seen[mask] = i

            # 情况2：至多一个字符奇数次（翻转一位后之前出现过）
            for j in range(10):
                target = mask ^ (1 << j)
                if target in first_seen:
                    ans = max(ans, i - first_seen[target])

        return ans
```

### 方法二：使用数组代替字典（更快）

```python
class Solution:
    def longestAwesome(self, s: str) -> int:
        # mask 最多 2^10 = 1024 种状态
        first_seen = [-2] * 1024  # -2 表示未见过
        first_seen[0] = -1  # 空前缀
        mask = 0
        ans = 0

        for i, c in enumerate(s):
            mask ^= 1 << int(c)

            # 情况1：完全相同 mask
            if first_seen[mask] != -2:
                ans = max(ans, i - first_seen[mask])
            else:
                first_seen[mask] = i

            # 情况2：只有一位不同
            for j in range(10):
                target = mask ^ (1 << j)
                if first_seen[target] != -2:
                    ans = max(ans, i - first_seen[target])

        return ans
```

## 复杂度分析

- **时间复杂度**：O(10 * N) = O(N)
- **空间复杂度**：O(2^10) = O(1024) = O(1)

## 关键点总结

1. 用 10 位掩码记录各数字出现奇偶性
2. 子串能构成回文 iff 前缀 XOR 至多 1 位不同
3. 哈希表记录每个 mask 第一次出现的位置（越早越能构成更长子串）

## 易错点

- `first_seen` 中存第一次出现的位置（不是最后），因为要最长子串
- 情况1中，已存在的 mask 不更新位置（保持最早的）
