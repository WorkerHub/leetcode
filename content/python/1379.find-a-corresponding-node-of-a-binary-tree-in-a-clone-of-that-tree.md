## 题目描述

给你两棵二叉树，原始树 `original` 和克隆树 `cloned`（它们的结构完全相同）。同时给你一个指向原始树中某个节点的引用 `target`。

请找出克隆树 `cloned` 中，与 `target` 相对应的那个节点，并返回对它的引用（即：克隆树中结构位置与 `target` 在原树中位置相同的节点）。

**注意：** 你不能对两棵树进行修改。你只能返回对 `cloned` 中某节点的引用，而不能修改树的结构。

**示例 1：**
```
输入：tree = [7,4,3,null,null,6,19], target = 3
输出：3
解释：原树中值为3的节点对应克隆树中值为3的节点（位置相同）
```

**示例 2：**
```
输入：tree = [7], target = 7
输出：7
```

**示例 3：**
```
输入：tree = [8,null,6,null,5,null,4,null,3,null,2,null,1], target = 4
输出：4
```

**提示：**
- 树中节点数在 `[1, 10^4]` 范围内
- 同一棵树中，节点值**可能重复**（这是本题的关键！）
- `target` 是原树中某节点的引用
- `cloned` 是 `original` 的精确结构克隆

## 解题思路

### 核心思想

由于树中节点值可能重复，不能单纯用值来查找目标节点。

**正确做法：同步遍历两棵树**
- 同时在 `original` 和 `cloned` 中遍历，两棵树走相同的路径。
- 当 `original` 的当前节点就是 `target`（引用相同，用 `is` 判断）时，返回 `cloned` 的对应节点。

**为什么用 `is` 而不是 `==`？**
- 节点值可能重复，需要判断引用（内存地址）是否相同，而不是值是否相等。
- `node is target` 检查的是同一个对象，`node == target` 检查的是值相等。

## Python 代码实现

### 方法一：DFS 同步递归（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Solution:
    def getTargetCopy(
        self,
        original: TreeNode,
        cloned: TreeNode,
        target: TreeNode
    ) -> TreeNode:
        def dfs(orig_node, clone_node):
            """
            同步遍历两棵树：
            - orig_node: 原树当前节点
            - clone_node: 克隆树对应位置的节点
            当 orig_node 是 target 时，返回 clone_node
            """
            if orig_node is None:
                return None

            # 找到目标节点（用 is 判断引用相同）
            if orig_node is target:
                return clone_node

            # 先搜索左子树
            left_result = dfs(orig_node.left, clone_node.left)
            if left_result:
                return left_result

            # 再搜索右子树
            return dfs(orig_node.right, clone_node.right)

        return dfs(original, cloned)
```

### 方法二：BFS 同步层序遍历

```python
from typing import Optional
from collections import deque

class Solution:
    def getTargetCopy(
        self,
        original: TreeNode,
        cloned: TreeNode,
        target: TreeNode
    ) -> Optional[TreeNode]:
        # BFS：同时处理两棵树对应层级的节点
        queue = deque([(original, cloned)])

        while queue:
            orig_node, clone_node = queue.popleft()

            if orig_node is None:
                continue

            # 找到目标节点
            if orig_node is target:
                return clone_node

            # 将左右子节点同时入队
            queue.append((orig_node.left, clone_node.left))
            queue.append((orig_node.right, clone_node.right))

        return None
```

### 方法三：迭代 DFS（显式栈，避免递归溢出）

```python
from typing import Optional

class Solution:
    def getTargetCopy(
        self,
        original: TreeNode,
        cloned: TreeNode,
        target: TreeNode
    ) -> Optional[TreeNode]:
        # 使用显式栈模拟 DFS，避免深树时递归栈溢出
        stack = [(original, cloned)]

        while stack:
            orig_node, clone_node = stack.pop()

            if orig_node is None:
                continue

            if orig_node is target:
                return clone_node

            # 将左右子节点压栈（先右后左，保证左子树先处理）
            stack.append((orig_node.right, clone_node.right))
            stack.append((orig_node.left, clone_node.left))

        return None
```

### 方法四：使用路径（先找路径，再按路径找克隆节点）

```python
from typing import Optional, List

class Solution:
    def getTargetCopy(
        self,
        original: TreeNode,
        cloned: TreeNode,
        target: TreeNode
    ) -> Optional[TreeNode]:
        # 先在原树中找从根到 target 的路径（用 L/R 表示方向）
        path = []

        def find_path(node):
            if not node:
                return False
            if node is target:
                return True
            path.append('L')
            if find_path(node.left):
                return True
            path.pop()
            path.append('R')
            if find_path(node.right):
                return True
            path.pop()
            return False

        find_path(original)

        # 按路径在克隆树中找对应节点
        node = cloned
        for direction in path:
            if direction == 'L':
                node = node.left
            else:
                node = node.right

        return node
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 同步递归 | O(n) | O(h) |
| BFS 层序 | O(n) | O(w) |
| 迭代 DFS | O(n) | O(h) |

- **时间复杂度**：O(n)，最坏情况遍历所有节点。
- **空间复杂度**：O(h)（DFS，h 为树高）或 O(w)（BFS，w 为树的最大宽度）。

## 关键点总结

1. **用引用 `is` 判断，不用值 `==`**：节点值可重复，必须通过内存引用（`is`）判断是否是同一个对象。
2. **同步遍历**：两棵树始终保持相同的遍历路径，原树找到目标时，克隆树的位置就是答案。
3. **提前返回**：找到目标后立即返回，避免无意义的继续搜索。
4. **Python 中 `is` vs `==`**：`is` 判断两个变量是否指向同一对象，`==` 判断值是否相等。
5. 本题看似简单，但"节点值可重复"是设计的陷阱，强制使用引用判断。

## 易错点

1. **用 `node.val == target.val` 来查找**：节点值重复时会找错节点，必须用 `node is target`。
2. **忘记空节点处理**：DFS/BFS 中需要判断 `orig_node is None` 才能安全访问子节点。
3. **只遍历一棵树**：只在克隆树中遍历会找不到正确位置（克隆树节点和 target 不是同一对象）。
