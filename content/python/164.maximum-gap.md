## 题目描述

给定一个无序的数组 `nums`，返回数组在排序之后，相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 0。

你必须编写一个在「线性时间」内运行并使用「线性额外空间」的算法。

**示例 1：**
```
输入：nums = [3,6,9,1]
输出：3
解释：排序后的数组是 [1,3,6,9]，其中相邻元素 (3,6) 和 (6,9) 之间都存在最大差值 3。
```

**示例 2：**
```
输入：nums = [10]
输出：0
解释：数组元素个数小于 2，因此返回 0。
```

**提示：**
- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^9

## 解题思路

题目要求线性时间 O(n) 和线性空间 O(n)，这排除了比较排序（O(n log n)）。

### 思路一：桶排序（推荐）⭐

**核心思想：**

1. **鸽巢原理**：n 个数分布在 [min, max] 范围内，如果均匀分布，相邻元素的平均间距是 `(max - min) / (n - 1)`

2. **关键观察**：
   - 最大间距至少是平均间距
   - 如果使用桶大小等于平均间距，最大间距不会出现在桶内，只会出现在桶与桶之间
   - 只需比较相邻非空桶之间的间距

**算法流程：**

1. 找到数组的最小值 min_val 和最大值 max_val
2. 如果 min_val == max_val，返回 0（所有元素相同）
3. 计算桶的大小：bucket_size = max(1, (max_val - min_val) // (n - 1))
4. 计算桶的数量：bucket_count = (max_val - min_val) // bucket_size + 1
5. 为每个桶记录其中的最小值和最大值
6. 遍历所有数字，放入对应的桶
7. 遍历桶，计算相邻非空桶之间的间距（当前桶的最小值 - 前一个桶的最大值）

### 思路二：基数排序

使用基数排序在 O(n) 时间内排序，然后遍历找最大间距。

### 思路三：直接排序（不满足时间要求）

使用内置排序 O(n log n)，然后遍历找最大间距。虽然不满足题目要求，但可以作为对比。

## Python 代码实现

### 方法一：桶排序（推荐）⭐

```python
from typing import List

class Solution:
    def maximumGap(self, nums: List[int]) -> int:
        """
        桶排序思想：利用鸽巢原理
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        if n < 2:
            return 0
        
        # 找到最小值和最大值
        min_val = min(nums)
        max_val = max(nums)
        
        # 所有元素相同
        if min_val == max_val:
            return 0
        
        # 计算桶的大小和数量
        # 桶大小至少为 1，最大为平均间距
        bucket_size = max(1, (max_val - min_val) // (n - 1))
        bucket_count = (max_val - min_val) // bucket_size + 1
        
        # 初始化桶，每个桶记录其中的最小值和最大值
        # 使用 None 表示桶为空
        buckets = [[None, None] for _ in range(bucket_count)]
        
        # 将每个数字放入对应的桶
        for num in nums:
            # 计算桶索引
            idx = (num - min_val) // bucket_size
            
            # 更新桶的最小值和最大值
            if buckets[idx][0] is None:
                buckets[idx][0] = buckets[idx][1] = num
            else:
                buckets[idx][0] = min(buckets[idx][0], num)
                buckets[idx][1] = max(buckets[idx][1], num)
        
        # 计算最大间距
        max_gap = 0
        prev_max = min_val  # 前一个非空桶的最大值
        
        for bucket in buckets:
            # 跳过空桶
            if bucket[0] is None:
                continue
            
            # 当前桶的最小值 - 前一个桶的最大值
            max_gap = max(max_gap, bucket[0] - prev_max)
            
            # 更新前一个桶的最大值
            prev_max = bucket[1]
        
        return max_gap
```

### 方法二：基数排序

```python
class Solution:
    def maximumGap(self, nums: List[int]) -> int:
        """
        基数排序 + 遍历找最大间距
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(nums)
        if n < 2:
            return 0
        
        # 基数排序
        def radix_sort(nums: List[int]) -> List[int]:
            if not nums:
                return nums
            
            # 找到最大值，确定位数
            max_val = max(nums)
            
            # 从个位开始，逐位排序
            exp = 1  # 当前位的权重（1, 10, 100, ...）
            while max_val // exp > 0:
                # 计数排序
                counting_sort(nums, exp)
                exp *= 10
            
            return nums
        
        def counting_sort(nums: List[int], exp: int) -> None:
            """按照 exp 位进行计数排序"""
            n = len(nums)
            output = [0] * n
            count = [0] * 10  # 0-9 十个桶
            
            # 统计每个数字在当前位上的出现次数
            for num in nums:
                digit = (num // exp) % 10
                count[digit] += 1
            
            # 计算累计次数
            for i in range(1, 10):
                count[i] += count[i - 1]
            
            # 从后向前遍历，保证稳定性
            for i in range(n - 1, -1, -1):
                digit = (nums[i] // exp) % 10
                output[count[digit] - 1] = nums[i]
                count[digit] -= 1
            
            # 复制回原数组
            for i in range(n):
                nums[i] = output[i]
        
        # 基数排序
        radix_sort(nums)
        
        # 找最大间距
        max_gap = 0
        for i in range(1, n):
            max_gap = max(max_gap, nums[i] - nums[i - 1])
        
        return max_gap
```

### 方法三：直接排序（不满足要求）

```python
class Solution:
    def maximumGap(self, nums: List[int]) -> int:
        """
        直接排序法（不满足线性时间要求）
        时间复杂度：O(n log n)
        空间复杂度：O(1) 或 O(n)，取决于排序算法
        """
        n = len(nums)
        if n < 2:
            return 0
        
        # 排序
        nums.sort()
        
        # 找最大间距
        max_gap = 0
        for i in range(1, n):
            max_gap = max(max_gap, nums[i] - nums[i - 1])
        
        return max_gap
```

### 方法四：优化的桶排序

```python
class Solution:
    def maximumGap(self, nums: List[int]) -> int:
        """
        优化的桶排序，使用字典存储桶
        """
        n = len(nums)
        if n < 2:
            return 0
        
        min_val, max_val = min(nums), max(nums)
        
        if min_val == max_val:
            return 0
        
        # 桶大小
        bucket_size = max(1, (max_val - min_val) // (n - 1))
        
        # 使用字典存储桶，只存储非空桶
        buckets = {}
        
        for num in nums:
            idx = (num - min_val) // bucket_size
            if idx not in buckets:
                buckets[idx] = [num, num]  # [min, max]
            else:
                buckets[idx][0] = min(buckets[idx][0], num)
                buckets[idx][1] = max(buckets[idx][1], num)
        
        # 按桶索引排序
        sorted_indices = sorted(buckets.keys())
        
        max_gap = 0
        prev_max = buckets[sorted_indices[0]][1]
        
        for i in range(1, len(sorted_indices)):
            idx = sorted_indices[i]
            max_gap = max(max_gap, buckets[idx][0] - prev_max)
            prev_max = buckets[idx][1]
        
        return max_gap
```

## 复杂度分析

**方法一（桶排序）：**
- 时间复杂度：O(n)，遍历数组常数次
- 空间复杂度：O(n)，桶的数量最多为 n

**方法二（基数排序）：**
- 时间复杂度：O(d * n)，其中 d 是最大数字的位数，对于 32 位整数 d 是常数，所以是 O(n)
- 空间复杂度：O(n)

**方法三（直接排序）：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(1) 或 O(n)

## 图解示例

示例：nums = [3, 6, 9, 1]

```
原数组：[3, 6, 9, 1]
min_val = 1, max_val = 9, n = 4

桶大小：(9 - 1) / (4 - 1) = 8 / 3 = 2（向下取整）
桶数量：(9 - 1) / 2 + 1 = 5

数字分配：
1: 桶0 (1-1)/2 = 0  → buckets[0] = [1, 1]
3: 桶1 (3-1)/2 = 1  → buckets[1] = [3, 3]
6: 桶2 (6-1)/2 = 2  → buckets[2] = [6, 6]
9: 桶4 (9-1)/2 = 4  → buckets[4] = [9, 9]

桶状态：
桶0: [1, 1]
桶1: [3, 3]
桶2: [6, 6]
桶3: 空
桶4: [9, 9]

计算间距：
桶0 → 桶1: 3 - 1 = 2
桶1 → 桶2: 6 - 3 = 3
桶2 → 桶4: 9 - 6 = 3

最大间距：3
```

## 关键点总结

1. **鸽巢原理**：n 个数分成 n-1 个桶，必有空桶，最大间距在桶之间
2. **桶大小选择**：使用平均间距，确保最大间距不在桶内
3. **只记录最值**：每个桶只需记录最小值和最大值
4. **跳过空桶**：空桶不影响结果
5. **线性时间**：桶排序和基数排序都能达到 O(n)

## 易错点

1. **边界情况**：n < 2 或所有元素相同时返回 0
2. **桶大小为 0**：当 max_val == min_val 时需要特殊处理
3. **桶索引计算**：`(num - min_val) // bucket_size`
4. **空桶处理**：遍历桶时需要跳过空桶
5. **初始化 prev_max**：应该初始化为 min_val，而不是第一个桶的最大值
