## 题目描述

给你一个 `n` 个节点的有向图，边集为 `edges`，其中 `edges[i] = [u, v, time]` 表示从 `u` 到 `v` 有一条耗时 `time` 的有向边。另外有一个等待规则：若当前时间不是 `k` 的倍数，则无法从某些节点出发。

请返回从节点 `0` 到节点 `n-1` 的最短时间，若无法到达返回 `-1`。

**示例 1：**

```
输入：n = 4, edges = [[0,1,3],[1,2,3],[2,3,3]], k = 3
输出：9
解释：0→1（时间3）→2（时间6）→3（时间9）
```

**示例 2：**

```
输入：n = 3, edges = [[0,1,1],[1,2,1]], k = 2
输出：4
解释：时间0出发→时间1到达1→等到时间2→时间3到达2
实际需调整：0→1（t=1，不是2的倍数）等到t=2→3到达，共4
```

**提示：**

- `2 <= n <= 10^4`
- `1 <= edges.length <= 10^5`
- `0 <= u, v < n`
- `1 <= time <= 10^3`
- `1 <= k <= 10^3`

## 解题思路

使用 Dijkstra 算法变体：在每个节点处理等待时间。

到达节点后，若当前时间不是 `k` 的倍数，需等待到下一个 `k` 的倍数才能出发。等待时间 = `k - (current_time % k)`（若 `current_time % k != 0`）。

用最小堆实现 Dijkstra，状态为 `(当前时间, 节点)`。

## Python 代码实现

### 方法一：Dijkstra + 等待时间（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], k: int) -> int:
        # 建图
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))

        # Dijkstra
        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]  # (时间, 节点)

        while heap:
            time, node = heapq.heappop(heap)
            if time > dist[node]:
                continue
            if node == n - 1:
                return time

            # 计算出发时间（等待到 k 的倍数）
            if time % k == 0:
                depart = time
            else:
                depart = time + (k - time % k)

            for neighbor, edge_time in graph[node]:
                new_time = depart + edge_time
                if new_time < dist[neighbor]:
                    dist[neighbor] = new_time
                    heapq.heappush(heap, (new_time, neighbor))

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

### 方法二：BFS（等权图）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]], k: int) -> int:
        graph = defaultdict(list)
        for u, v, t in edges:
            graph[u].append((v, t))

        dist = [float('inf')] * n
        dist[0] = 0
        queue = deque([(0, 0)])

        while queue:
            time, node = queue.popleft()
            if time > dist[node]:
                continue
            depart = time if time % k == 0 else time + (k - time % k)
            for neighbor, edge_time in graph[node]:
                new_time = depart + edge_time
                if new_time < dist[neighbor]:
                    dist[neighbor] = new_time
                    queue.append((new_time, neighbor))

        return dist[n - 1] if dist[n - 1] != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)，Dijkstra 的标准复杂度
- 空间复杂度：O(V + E)

## 关键点总结

1. Dijkstra 适合带权有向图最短路
2. 等待时间计算：`k - (t % k)`，当 `t % k == 0` 时无需等待
3. 状态为到达时间，而非出发时间
4. 出发条件约束在离开节点时处理

## 易错点

1. 出发时间是到达时间经过等待后的时间，不是到达时间
2. `t % k == 0` 时直接出发，不需额外等待
3. 注意有向图建图方向
