## 题目描述

给你一个整数数组 `nums`。

每次操作可以选择一个下标 `i`，将 `nums[i]` 除以它的任意一个**大于 1 的因数**，结果向下取整。

目标：使数组非递减（`nums[i] <= nums[i+1]`）。

返回所需的最少操作次数，若无法实现，返回 `-1`。

**示例：**
```
输入：nums = [25, 7]
输出：1
解释：将 25 除以 5 得 5，数组变为 [5, 7]，非递减
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**贪心（从右到左）：**

关键观察：将 `nums[i]` 通过一次操作能得到的最小值，是将其除以最大质因子，即 `nums[i] / 最大质因子`（取整）。

因为每次只能除以一个大于 1 的因数（一次操作），最优策略是尽量将 `nums[i]` 降到最小，即除以其最大质因子。

**为什么从右到左贪心？**
- 从最右边开始，对于 `nums[i] > nums[i+1]` 的情况，需要减小 `nums[i]`。
- 将 `nums[i]` 除以最大质因子，得到新值。
- 若新值仍 > `nums[i+1]`，则无解（因为一次只能除一个因数，且已经除了最大的）。

注意：每个数字最多只能操作**一次**（题目没有说）... 再读题目：题目说每次操作可以对任意 `i`，每次操作改变一个元素，可以对同一元素多次操作。但贪心地，只需要对每个元素最多操作一次（将其除以最大质因子）。

实际上，将一个数除以最大质因子得到的结果已经是"一次操作能得到的最小值"中最大可能减小幅度... 不，是"能一步得到的最小值"是除以最大因数（即除以数本身，得到 1），但我们要的是非递减，不是最小化。

**正确贪心：** 从右到左，若 `nums[i] > nums[i+1]`，我们需要对 `nums[i]` 进行操作。最优操作是将 `nums[i]` 替换为 `nums[i]` 的最小质因子... 不对，是除以最大质因子得到最小值？

Wait: 我们要 `nums[i] <= nums[i+1]`。如果 `nums[i] > nums[i+1]`，将 `nums[i]` 减小。一次操作的最大减小：除以最大因子（即数本身），结果为 1。但这可能过度减小。

最优策略：找最大因数 d 使得 `nums[i] / d <= nums[i+1]`，即 d >= `nums[i] / nums[i+1]`。选最大 d（使结果最大且 <= nums[i+1]）来保留尽量大的值（为左边元素留出更大空间）。

这样每次操作只需考虑"将 nums[i] 除以某个因数使其 <= nums[i+1]"，最优选择是除以最小满足条件的因数（使 nums[i] 尽量大）。

但贪心的结论是：把 nums[i] 直接除以其最大质因子，得到的结果已经是"一步内能达到的最大值且仍然小于等于 nums[i+1] 的可能性"的边界。

实际正确方法：对每个 nums[i]，预处理其**最小质因子**，nums[i] / 最小质因子 是一次操作能得到的最大值（保留最多）。

**正确贪心：** 从右到左，若 `nums[i] > nums[i+1]`：
- 将 nums[i] 替换为 `nums[i] // 最小质因子(nums[i])`（一次操作能得到的最大值）。
- 若替换后仍 > nums[i+1]，返回 -1。
- 否则操作数 +1，继续检查。

## Python 代码实现

### 方法一：贪心 + 预处理最小质因子（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        MAX_VAL = 10**6 + 1
        
        # 线性筛预处理最小质因子
        spf = list(range(MAX_VAL))  # spf[i] = i 的最小质因子
        for i in range(2, int(MAX_VAL**0.5) + 1):
            if spf[i] == i:  # i 是质数
                for j in range(i * i, MAX_VAL, i):
                    if spf[j] == j:
                        spf[j] = i
        
        n = len(nums)
        ops = 0
        
        # 从右到左贪心
        for i in range(n - 2, -1, -1):
            if nums[i] <= nums[i + 1]:
                continue
            # 将 nums[i] 除以最小质因子（一次操作能得到的最大值）
            nums[i] //= spf[nums[i]]
            if nums[i] > nums[i + 1]:
                return -1
            ops += 1
        
        return ops
```

## 复杂度分析

- 时间复杂度：O(max_val * log(log(max_val)) + n)，筛法预处理 + 一次遍历
- 空间复杂度：O(max_val)，最小质因子数组

## 关键点总结

1. 对每个过大的 `nums[i]`，最优操作是除以其最小质因子（得到一次操作后的最大可能值）。
2. 从右到左处理，确保右边元素已经满足条件。
3. 若一次操作后仍不满足（`nums[i] > nums[i+1]`），则无解。

## 易错点

1. 一次操作取最小质因子（不是最大因子），是为了让 nums[i] 保留尽量大的值。
2. 每个元素最多只操作一次（因为再操作只会更小，但需要满足左边的约束）。
3. 线性筛预处理最小质因子的时间复杂度是 O(max_val)，比逐个分解快。
