## 题目描述

给定 `m x n` 的整数矩阵 `grid` 和整数 `k`，统计元素和不超过 `k` 的子矩阵数量。

**示例 1：**
```
输入：grid = [[1,0],[1,1]], k = 2
输出：5
解释：和 <= 2 的子矩阵：
     [1],[0],[1],[1] 各 1x1 子矩阵（四个），
     [1,0]（和=1），共 5 个。
```

**示例 2：**
```
输入：grid = [[2,1],[1,1]], k = 5
输出：9
解释：所有子矩阵（共 9 个），最大和为 5，均满足。
```

**提示：**
- `m == grid.length, n == grid[0].length`
- `1 <= m, n <= 100`
- `0 <= grid[i][j] <= 10^5`
- `0 <= k <= 10^9`

## 解题思路

**枚举行范围 + 列前缀和排序（经典子矩阵求和方法）：**

枚举上下行边界 `[r1, r2]`，将每列在 `[r1, r2]` 内的元素和压缩为一维数组 `col_sums`。

问题转化为：统计 `col_sums` 的子数组和 <= k 的数量。

使用前缀和 + 排序（或二分）在 O(n log n) 内处理每个 `(r1, r2)` 组合。

总时间复杂度：O(m^2 * n log n)。

## Python 代码实现

### 方法一：枚举行 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList
import bisect

class Solution:
    def countSubmatrixesWithSumAtMostK(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        for r1 in range(m):
            col_sum = [0] * n  # 每列从 r1 到 r2 的累计和

            for r2 in range(r1, m):
                # 更新列和
                for j in range(n):
                    col_sum[j] += grid[r2][j]

                # 统计 col_sum 中子数组和 <= k 的数量
                # 用前缀和 + 有序列表
                prefix_sums = SortedList([0])
                cur = 0
                for s in col_sum:
                    cur += s
                    # 找满足 cur - prev_sum <= k 的 prev_sum 数量
                    # 即 prev_sum >= cur - k
                    idx = prefix_sums.bisect_left(cur - k)
                    ans += len(prefix_sums) - idx
                    prefix_sums.add(cur)

        return ans
```

### 方法二：枚举行 + O(n^2) 暴力（适合小规模）

```python
from typing import List

class Solution:
    def countSubmatrixesWithSumAtMostK(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        for r1 in range(m):
            col_sum = [0] * n

            for r2 in range(r1, m):
                for j in range(n):
                    col_sum[j] += grid[r2][j]

                # 枚举列范围 [c1, c2]，计算子数组和
                for c1 in range(n):
                    total = 0
                    for c2 in range(c1, n):
                        total += col_sum[c2]
                        if total <= k:
                            ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(m^2 * n log n)（方法一），O(m^2 * n^2)（方法二）
- 空间复杂度：O(m * n)，前缀和空间

## 关键点总结

1. 枚举行范围将二维问题降维为一维
2. 一维子数组和 <= k 的计数用前缀和 + 有序集合/二分
3. 外层枚举 O(m^2)，内层 O(n log n)

## 易错点

1. 子数组和包括单个元素（长度为 1 的子数组）
2. 有序集合初始包含 0（空前缀）
3. 注意是 `<= k` 不是 `< k`
