## 题目描述

如果字符串中不含有任何 `'aaa'`，`'bbb'` 或 `'ccc'` 这样的字符串作为子串，那么该字符串就是一个「快乐字符串」。

给你三个整数 `a`、`b`、`c`，请你返回**最长的快乐字符串**。如果存在多个最长快乐字符串，那么返回其中任意一个即可。如果不存在这样的字符串，请返回一个空字符串 `""`。

`a`、`b`、`c` 分别代表字符串中可以使用的 `'a'`、`'b'`、`'c'` 的最大数量。

**示例 1：**

```
输入：a = 1, b = 1, c = 7
输出："ccaccbcc"
解释：输出 "ccbccacc" 也是正确答案。
```

**示例 2：**

```
输入：a = 2, b = 2, c = 1
输出："aabbc" 或 "aabbcc" 或 ...
```

**示例 3：**

```
输入：a = 7, b = 1, c = 0
输出："aabaa"
```

**提示：**

- `0 <= a, b, c <= 100`
- `a + b + c > 0`

## 解题思路

**贪心策略：** 每次优先选择剩余数量最多的字符，但要避免连续出现 3 个相同字符。

**规则：**
1. 每次从剩余量最大的字符开始选
2. 如果当前字符串末尾已有 2 个相同字符，则选剩余量次大的字符
3. 重复直到没有可选字符

**实现：** 使用**最大堆**来维护各字符的剩余量，每次取最大量的字符。若取出的字符不能用（末尾已有 2 个相同），则取次大量的字符。

## Python 代码实现

### 方法一：最大堆（贪心）（推荐）

```python
import heapq

class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        # 最大堆（Python heapq 是最小堆，用负数模拟最大堆）
        heap = []
        if a > 0:
            heapq.heappush(heap, (-a, 'a'))
        if b > 0:
            heapq.heappush(heap, (-b, 'b'))
        if c > 0:
            heapq.heappush(heap, (-c, 'c'))

        result = []

        while heap:
            # 取出剩余量最多的字符
            neg_cnt, char = heapq.heappop(heap)
            cnt = -neg_cnt

            # 检查是否会产生 3 个连续相同字符
            if len(result) >= 2 and result[-1] == char and result[-2] == char:
                # 不能用当前字符，尝试次大的
                if not heap:
                    break  # 没有其他字符可用，结束
                neg_cnt2, char2 = heapq.heappop(heap)
                cnt2 = -neg_cnt2

                # 使用次大字符
                result.append(char2)
                cnt2 -= 1
                if cnt2 > 0:
                    heapq.heappush(heap, (-cnt2, char2))
                # 把原来最大的字符放回
                heapq.heappush(heap, (-cnt, char))
            else:
                # 可以使用当前字符
                result.append(char)
                cnt -= 1
                if cnt > 0:
                    heapq.heappush(heap, (-cnt, char))

        return ''.join(result)
```

### 方法二：直接贪心（不用堆，简洁版）

```python
class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        result = []
        counts = [('a', a), ('b', b), ('c', c)]

        while True:
            # 按剩余量降序排序
            counts.sort(key=lambda x: -x[1])
            char1, cnt1 = counts[0]
            char2, cnt2 = counts[1]

            if cnt1 == 0:
                break  # 没有字符可用

            # 判断是否可以用最多的字符
            can_use_first = not (len(result) >= 2 and result[-1] == char1 and result[-2] == char1)

            if can_use_first:
                result.append(char1)
                counts[0] = (char1, cnt1 - 1)
            elif cnt2 > 0:
                result.append(char2)
                counts[1] = (char2, cnt2 - 1)
            else:
                break  # 两个都不能用，结束

        return ''.join(result)
```

### 方法三：每次最多添加2个（优化版）

```python
import heapq

class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        """
        每次尝试添加 1 或 2 个当前最多的字符（最多2个），
        然后再添加 1 个次多的字符
        """
        heap = [(-cnt, ch) for cnt, ch in [(a,'a'),(b,'b'),(c,'c')] if cnt > 0]
        heapq.heapify(heap)
        result = []

        while heap:
            neg1, c1 = heapq.heappop(heap)
            cnt1 = -neg1

            if result and result[-1] == c1:
                # 末尾已有一个 c1，判断能否再加
                if len(result) >= 2 and result[-2] == c1:
                    # 已有两个，不能再加，必须用别的
                    if not heap:
                        break
                    neg2, c2 = heapq.heappop(heap)
                    cnt2 = -neg2
                    result.append(c2)
                    if cnt2 - 1 > 0:
                        heapq.heappush(heap, (-(cnt2-1), c2))
                    heapq.heappush(heap, (-cnt1, c1))
                else:
                    result.append(c1)
                    if cnt1 - 1 > 0:
                        heapq.heappush(heap, (-(cnt1-1), c1))
            else:
                result.append(c1)
                if cnt1 - 1 > 0:
                    heapq.heappush(heap, (-(cnt1-1), c1))

        return ''.join(result)
```

## 复杂度分析

- **时间复杂度 O((a+b+c) * log 3)**：每次堆操作 O(log 3) = O(1)（只有 3 个元素），总操作次数为字符串长度（最多 a+b+c）。
- **空间复杂度 O(a+b+c)**：结果字符串的空间。

## 图解示例

以 `a=7, b=1, c=0` 为例：

```
heap: [(-7,'a'), (-1,'b')]

取 (-7,'a')→'a'，末尾无限制，加'a'，heap: [(-6,'a'),(-1,'b')], result="a"
取 (-6,'a')→'a'，末尾有1个'a'，加'a'，heap: [(-5,'a'),(-1,'b')], result="aa"
取 (-5,'a')→'a'，末尾有2个'a'，不能用！取次大(-1,'b')→'b'
  加'b'，'a'放回，heap: [(-5,'a')], result="aab"
取 (-5,'a')→'a'，末尾有1个'a'，加'a'，heap: [(-4,'a')], result="aaba"
...以此类推

最终结果类似 "aabaa" 或 "aabaaaa..."
```

## 关键点总结

1. 贪心每次优先选剩余量最多的字符
2. 唯一限制：连续相同字符不超过 2 个
3. 最大堆保证每次能快速找到剩余最多和次多的字符
4. 当最多的字符不可用时，用次多的字符，并将最多的字符放回堆中

## 易错点

- 判断"末尾2个相同"时，要同时检查 `result[-1] == char` 和 `result[-2] == char`（且 `len(result) >= 2`）
- 次大字符用完后要把最大字符放回堆中，不要遗忘
- 当次大字符也没有（heap 为空）时，直接结束，不能强行加入不可用的字符
