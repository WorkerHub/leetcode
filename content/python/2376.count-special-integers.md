## 题目描述

如果一个正整数的每一位数字都是**不同的**，则称该整数为**特殊整数**。

给你一个正整数 `n`，返回区间 `[1, n]` 内**特殊整数**的数目。

**示例 1：**
```
输入：n = 20
输出：19
解释：1-9 共 9 个，10, 12, 13, 14, 15, 16, 17, 18, 19 共 10 个，20 不行（两个 0），合计 19 个。
```

**示例 2：**
```
输入：n = 5
输出：5
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

**数位 DP（记忆化搜索）：**
统计 `[1, n]` 中每位数字都不同的整数数目。

定义 `dp(pos, mask, tight, started)`：
- `pos`：当前填写的位数。
- `mask`：已使用的数字集合（位掩码）。
- `tight`：当前是否受上界约束。
- `started`：是否已经填写了非零数字（处理前导零）。

## 代码实现

### 方法一：数位 DP 记忆化搜索（推荐）

```python
from functools import lru_cache

class Solution:
    def countSpecialNumbers(self, n: int) -> int:
        digits = str(n)
        length = len(digits)
        
        @lru_cache(maxsize=None)
        def dp(pos: int, mask: int, tight: bool, started: bool) -> int:
            # pos: 当前位置，mask: 已用数字集合，tight: 是否受上界约束，started: 是否已开始
            if pos == length:
                return 1 if started else 0
            
            limit = int(digits[pos]) if tight else 9
            result = 0
            
            for d in range(0, limit + 1):
                if d == 0 and not started:
                    # 前导零，不算已开始
                    result += dp(pos + 1, mask, tight and d == limit, False)
                elif (mask >> d) & 1:
                    # 数字已使用，跳过
                    continue
                else:
                    result += dp(pos + 1, mask | (1 << d), tight and d == limit, True)
            
            return result
        
        return dp(0, 0, True, False)
```

### 方法二：排列计数（数学方法）

```python
class Solution:
    def countSpecialNumbers(self, n: int) -> int:
        s = str(n)
        m = len(s)
        
        # 统计位数小于 m 的特殊整数数量
        # k 位（k < m）：第一位 1-9，后面 k-1 位从剩余 9 个数字中选（9, 8, ..., 9-k+2）
        from math import perm
        
        count = 0
        # 1 到 m-1 位的所有特殊整数
        for k in range(1, m):
            count += 9 * perm(9, k - 1)  # 第一位非零，后续 k-1 位从剩余 9 个中选
        
        # 恰好 m 位且 <= n 的特殊整数
        used = set()
        for i, c in enumerate(s):
            d = int(c)
            lo = 1 if i == 0 else 0
            
            for x in range(lo, d):
                if x not in used:
                    # 当前位选 x，后面位自由选（从未用数字中选）
                    remaining = m - i - 1
                    available = 10 - len(used) - 1  # 已用 + 当前位 x
                    count += perm(available, remaining)
            
            if d in used:
                break  # d 已被用过，无法继续（n 本身不满足）
            used.add(d)
            if i == m - 1:
                count += 1  # n 本身满足条件
        
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数位 DP | O(10 * 2^10 * m * 2) | O(2^10 * m) |
| 数学 | O(m^2) | O(m) |

## 关键点总结

1. 数位 DP 用位掩码 `mask` 记录已使用的数字集合，10 个数字最多 2^10=1024 种状态。
2. `tight` 约束确保不超过 n 的上界。
3. 数学方法利用排列数公式，按位数和前缀分类计数。

## 易错点

- 前导零处理：`started=False` 时，填 0 不算使用了 0（前导零不计入数字）。
- 数学方法中，当前位可选范围：首位 `[1, d-1]`，非首位 `[0, d-1]`（但需排除已用数字）。
