## 题目描述

给你一个字符串 `word`，若两个相邻字符满足 `|word[i] - word[i+1]| <= 1`，则称它们为 **几乎相等** 的字符。

每次操作可以将任意字符修改为任意字母。

返回消除所有相邻几乎相等字符对所需的最少操作次数（修改后不得产生新的相邻几乎相等对）。

**示例 1：**
```
输入：word = "aaaaa"
输出：2
解释：修改位置 1 和 3：变为 "acaca"，无相邻几乎相等对
```

**示例 2：**
```
输入：word = "abddez"
输出：2
```

**提示：**
- `1 <= word.length <= 100`
- `word` 只含小写英文字母

## 解题思路

贪心：从左到右遍历，遇到相邻几乎相等对时，修改右边的字符（选择一个与两侧都不几乎相等的字符），然后跳过下一个字符（因为已经修改过了）。

## Python 代码实现

### 方法一：贪心跳跃（推荐）

```python
class Solution:
    def removeAlmostEqualCharacters(self, word: str) -> int:
        n = len(word)
        ans = 0
        i = 0
        while i < n - 1:
            if abs(ord(word[i]) - ord(word[i + 1])) <= 1:
                ans += 1
                i += 2  # 修改 word[i+1]，跳过 i+1
            else:
                i += 1
        return ans
```

### 方法二：动态规划

```python
class Solution:
    def removeAlmostEqualCharacters(self, word: str) -> int:
        n = len(word)
        # dp[i] = 处理 word[0..i] 的最少操作数
        dp = [0] * n
        for i in range(1, n):
            if abs(ord(word[i]) - ord(word[i - 1])) <= 1:
                # 需要修改 word[i-1] 或 word[i]
                # 若修改 word[i]，则跳过 i，下一个从 i+1 开始
                dp[i] = dp[i - 1] + 1
                if i >= 2:
                    dp[i] = min(dp[i], dp[i - 2] + 1)
            else:
                dp[i] = dp[i - 1]
        return dp[n - 1]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（贪心），O(n)（DP）

## 关键点总结

1. 贪心：遇到几乎相等对时，修改后面的字符，并跳过它
2. 跳过策略：修改 i+1 后，i+1 与 i+2 的关系未知，从 i+2 开始重新检查
3. 贪心正确性：尽量在右侧修改，保护左侧已处理的位置

## 易错点

1. 修改后跳过一个位置（i += 2），否则会重复检查已修改的字符
2. `|c1 - c2| <= 1` 时是几乎相等，包括相同字符（差值 0）
3. 修改字符时可以改为任意字母（不受原字符限制）
