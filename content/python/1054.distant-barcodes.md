## 题目描述

在一个仓库里，有一排条形码，其中第 `i` 个条形码为 `barcodes[i]`。

请你重新排列这些条形码，使其中任意两个相邻的条形码不能相等。你可以返回任何满足该要求的答案，此题保证存在答案。

**示例 1：**
```
输入：barcodes = [1,1,1,2,2,2]
输出：[2,1,2,1,2,1]
```

**示例 2：**
```
输入：barcodes = [1,1,1,1,2,2,3,3]
输出：[1,3,1,3,1,2,1,2]
```

**提示：**
- `1 <= barcodes.length <= 10000`
- `1 <= barcodes[i] <= 10000`

## 解题思路

这道题的核心是**如何避免相同元素相邻**。关键策略是：
1. 优先放置出现次数最多的元素
2. 采用"间隔放置"的方式

**贪心策略：**
- 先统计每个元素的出现次数
- 按照出现次数从大到小排序
- 先在偶数位置（0, 2, 4, ...）放置元素
- 偶数位置放满后，在奇数位置（1, 3, 5, ...）放置

**为什么这样可行？**
- 出现次数最多的元素最容易造成相邻
- 间隔放置可以保证同一元素至少相隔一个位置
- 题目保证有解，说明最高频元素的数量 ≤ (n+1)//2

## Python 代码实现

### 方法一：计数 + 间隔放置（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def rearrangeBarcodes(self, barcodes: List[int]) -> List[int]:
        """
        时间复杂度：O(n log k)，k 为不同元素个数
        空间复杂度：O(n)
        """
        n = len(barcodes)
        result = [0] * n
        
        # 统计每个元素出现次数，按次数降序排列
        counter = Counter(barcodes)
        sorted_items = sorted(counter.items(), key=lambda x: -x[1])
        
        # 当前填充位置
        index = 0
        
        # 按照出现次数从大到小填充
        for num, count in sorted_items:
            for _ in range(count):
                result[index] = num
                index += 2
                # 偶数位置填满后，从位置 1 开始填奇数位置
                if index >= n:
                    index = 1
        
        return result
```

### 方法二：使用堆（最大堆）

```python
from typing import List
from collections import Counter
import heapq

class Solution:
    def rearrangeBarcodes(self, barcodes: List[int]) -> List[int]:
        """
        使用最大堆贪心选择
        时间复杂度：O(n log k)
        空间复杂度：O(n)
        """
        # 统计频率，构建最大堆（Python 是最小堆，用负数模拟最大堆）
        counter = Counter(barcodes)
        max_heap = [(-count, num) for num, count in counter.items()]
        heapq.heapify(max_heap)
        
        result = []
        prev_count, prev_num = 0, 0
        
        while max_heap:
            # 取出频率最高的
            count, num = heapq.heappop(max_heap)
            result.append(num)
            
            # 如果前一个还有剩余，放回堆中
            if prev_count < 0:
                heapq.heappush(max_heap, (prev_count, prev_num))
            
            # 当前元素使用一次，更新计数
            prev_count, prev_num = count + 1, num
        
        return result
```

### 方法三：优化的间隔放置

```python
from typing import List
from collections import Counter

class Solution:
    def rearrangeBarcodes(self, barcodes: List[int]) -> List[int]:
        """
        简化版间隔放置
        """
        n = len(barcodes)
        # 按出现次数排序
        counter = Counter(barcodes)
        barcodes.sort(key=lambda x: (counter[x], x))
        
        # 间隔放置
        result = [0] * n
        result[::2] = barcodes[:(n + 1) // 2]  # 偶数位置
        result[1::2] = barcodes[(n + 1) // 2:]  # 奇数位置
        
        return result
```

## 复杂度分析

**方法一：计数 + 间隔放置**
- 时间复杂度：O(n log k)，其中 k 是不同元素个数，排序需要 O(k log k)，填充需要 O(n)
- 空间复杂度：O(n)，需要额外数组存储结果

**方法二：堆**
- 时间复杂度：O(n log k)，每次堆操作 O(log k)，共 n 次
- 空间复杂度：O(n)

**方法三：排序 + 切片**
- 时间复杂度：O(n log n)，排序整个数组
- 空间复杂度：O(n)

## 关键点总结

1. **贪心策略**：优先放置出现次数最多的元素
2. **间隔放置**：先填偶数位置，再填奇数位置，保证相邻不同
3. **题目保证有解**：最高频元素数量不超过 ⌈n/2⌉
4. **多种方法**：计数排序、堆、排序切片都可以解决

## 易错点

1. **索引越界**：填充偶数位置时注意 `index >= n` 要切换到奇数位置
2. **排序依据**：必须按出现次数降序排序，不能按元素值排序
3. **切片赋值**：方法三中要注意切片的长度和赋值数组的长度匹配
4. **理解题意**：任意满足要求的答案都可以，不需要字典序最小
