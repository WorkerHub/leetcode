## 题目描述

给定字符串 `s` 和模式串 `part`，重复执行以下操作：找到 `s` 中最靠左的 `part` 的出现位置，将其删除。直到 `s` 中不再包含 `part` 为止。返回最终的字符串。

本题与第 1910 题类似，但 `s` 和 `part` 的长度更大，需要高效实现。

**示例 1：**
```
输入：s = "daabcbaabcbc", part = "abc"
输出："dab"
解释：
- s = "daabcbaabcbc", 删除最左的 "abc" -> "dabaabcbc"
- s = "dabaabcbc", 删除最左的 "abc" -> "dababcbc"... 
  实际上第一次删除位置 2-4: "da" + "baabcbc" = "dabaabcbc"
  第二次删除: "dab" + "bc" = "dabbc"
  第三次: 找不到 "abc"... 
  正确过程：s = "daabcbaabcbc"
  删 "abc"(位置2): "dabaabcbc" -> 删 "abc"(位置4): "dababc" -> 删 "abc"(位置3): "dab"
```

**示例 2：**
```
输入：s = "axxxxyyyyb", part = "xy"
输出："ab"
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= part.length <= 10^3`
- `s` 和 `part` 只含小写英文字母

## 解题思路

利用栈 + KMP 失配函数高效实现。

**核心思路：**
用一个栈来模拟构建过程，同时用 KMP 的 `fail` 数组追踪当前栈顶是否即将匹配 `part`：

1. 维护一个字符栈，同时维护一个 KMP 状态栈（记录每个字符对应的 KMP 匹配状态）。
2. 将 `s` 的字符依次入栈，更新 KMP 状态。
3. 若 KMP 状态达到 `len(part)`，说明栈顶恰好组成了 `part`，将其弹出。
4. 最终栈中剩余的字符拼接即为答案。

## Python 代码实现

### 方法一：栈 + KMP（推荐）

```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        m = len(part)
        # 构建 KMP 失配函数
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and part[i] != part[j]:
                j = fail[j - 1]
            if part[i] == part[j]:
                j += 1
            fail[i] = j

        # 字符栈和 KMP 状态栈
        char_stack = []
        state_stack = [0]  # state_stack[i] 表示处理 char_stack[i-1] 后的 KMP 状态

        for c in s:
            # 尝试用当前字符推进 KMP 状态
            cur_state = state_stack[-1]
            while cur_state > 0 and c != part[cur_state]:
                cur_state = fail[cur_state - 1]
            if c == part[cur_state]:
                cur_state += 1

            char_stack.append(c)
            state_stack.append(cur_state)

            # 若 KMP 状态到达 m，说明刚好匹配了 part
            if cur_state == m:
                # 弹出 part 长度个字符
                for _ in range(m):
                    char_stack.pop()
                    state_stack.pop()

        return ''.join(char_stack)
```

### 方法二：暴力替换（适用于短字符串）

```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        # 直接用 Python 的 replace 不会重复处理，需要循环
        while part in s:
            s = s.replace(part, '', 1)  # 每次只替换最左一个
        return s
```

## 复杂度分析

- 时间复杂度：方法一 O(n + m)，KMP 线性；方法二 O(n * n/m)，暴力每次 O(n) 最多 n/m 次
- 空间复杂度：O(n + m)

## 关键点总结

1. KMP + 栈的组合是处理"重复删除匹配子串"的高效方法
2. 状态栈记录的是每个字符入栈后的 KMP 匹配进度
3. 一旦匹配完成，弹出栈顶的 `m` 个字符，KMP 状态自动回滚

## 易错点

1. 状态栈比字符栈多一个初始状态（0），需要保持同步
2. 弹出时同时弹出字符栈和状态栈的对应元素
