## 题目描述

给你一个整数数组 `nums`，将它重新排列成 `nums[0] < nums[1] > nums[2] < nums[3]...` 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

**示例 1:**

```
输入：nums = [1, 5, 1, 1, 6, 4]
输出：[1, 6, 1, 5, 1, 4]
解释：[1, 4, 1, 5, 1, 6] 同样是符合题目要求的结果，可以被判题程序接受。
```

**示例 2:**

```
输入：nums = [1, 3, 2, 2, 3, 1]
输出：[2, 3, 1, 3, 1, 2]
```

**提示:**

- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 5000`
- 题目数据保证，对于给定的输入 `nums`，总能产生满足题目要求的结果

**进阶:** 你能用 `O(n)` 时间复杂度和 / 或原地 `O(1)` 额外空间来实现吗？

## 解题思路

这道题要求将数组排列成摆动序列，关键是理解**穿插策略**。

### 核心思想

1. **排序 + 穿插**：
   - 将数组排序后分为两部分：较小的一半和较大的一半
   - 从两部分的末尾开始，交替放入结果数组
   - 这样可以避免相等元素相邻

2. **为什么从末尾开始穿插？**
   - 例如 `[1, 1, 1, 4, 5, 6]` 分为 `[1, 1, 1]` 和 `[4, 5, 6]`
   - 如果从前向后：`[1, 4, 1, 5, 1, 6]` ✓
   - 如果从后向前：`[1, 6, 1, 5, 1, 4]` ✓
   - 关键是避免相等元素（如多个 1）相邻

3. **索引映射技巧**：
   - 使用虚拟索引映射，实现原地排序（进阶要求）

### 算法流程

1. 排序数组
2. 找到中位数位置 `mid`
3. 将数组分为 `[0...mid]` 和 `[mid+1...n-1]`
4. 从两部分末尾开始交替取值

## Python 代码实现

### 方法一：排序 + 穿插（推荐新手）⭐

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        排序后穿插放置，使用额外空间
        """
        # 排序
        sorted_nums = sorted(nums)
        n = len(nums)
        
        # 找到中位数位置（较小部分的末尾）
        mid = (n - 1) // 2
        
        # 从两部分的末尾开始交替取值
        # 较小部分：[0...mid]，从 mid 向 0 取
        # 较大部分：[mid+1...n-1]，从 n-1 向 mid+1 取
        left = mid  # 较小部分的末尾
        right = n - 1  # 较大部分的末尾
        
        for i in range(n):
            if i % 2 == 0:
                # 偶数位置放较小的数
                nums[i] = sorted_nums[left]
                left -= 1
            else:
                # 奇数位置放较大的数
                nums[i] = sorted_nums[right]
                right -= 1
```

### 方法二：原地三向切分 + 虚拟索引（进阶）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        O(n) 时间 + O(1) 空间：快速选择 + 虚拟索引映射
        """
        n = len(nums)
        
        # 找到中位数（使用快速选择算法）
        median = self.findKthLargest(nums, (n + 1) // 2)
        
        # 虚拟索引映射函数
        def index(i):
            return (1 + 2 * i) % (n | 1)
        
        # 三向切分：将数组分为 < median, = median, > median
        i, j, k = 0, 0, n - 1
        
        while j <= k:
            if nums[index(j)] > median:
                nums[index(i)], nums[index(j)] = nums[index(j)], nums[index(i)]
                i += 1
                j += 1
            elif nums[index(j)] < median:
                nums[index(j)], nums[index(k)] = nums[index(k)], nums[index(j)]
                k -= 1
            else:
                j += 1
    
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """快速选择算法找第 k 大的元素"""
        import random
        
        def partition(left, right, pivot_index):
            pivot = nums[pivot_index]
            nums[pivot_index], nums[right] = nums[right], nums[pivot_index]
            store_index = left
            
            for i in range(left, right):
                if nums[i] > pivot:
                    nums[store_index], nums[i] = nums[i], nums[store_index]
                    store_index += 1
            
            nums[right], nums[store_index] = nums[store_index], nums[right]
            return store_index
        
        left, right = 0, len(nums) - 1
        
        while True:
            pivot_index = random.randint(left, right)
            pivot_index = partition(left, right, pivot_index)
            
            if pivot_index == k - 1:
                return nums[pivot_index]
            elif pivot_index < k - 1:
                left = pivot_index + 1
            else:
                right = pivot_index - 1
```

### 方法三：简化版（使用临时数组）

```python
from typing import List

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        简化版：直接使用 Python 特性
        """
        nums.sort()
        half = len(nums[::2])  # 较小部分的长度
        
        # 切分并反转，然后穿插
        nums[::2], nums[1::2] = nums[:half][::-1], nums[half:][::-1]
```

## 复杂度分析

**方法一：排序 + 穿插**

- **时间复杂度**：O(n log n)

- **空间复杂度**：O(n)

  - 原地操作

## 关键点总结

1. **穿插策略**：从两部分的末尾开始取值，避免相等元素相邻
2. **中位数位置**：`mid = (n - 1) // 2`，确保两部分长度合理
3. **虚拟索引映射**：`(1 + 2*i) % (n | 1)` 实现原地穿插
   - `n | 1` 将 n 变为最接近的奇数
   - 映射规律：`0 -> 1, 1 -> 3, 2 -> 5, ...`（奇数位置优先）
4. **三向切分**：将数组分为 `< median`、`= median`、`> median` 三部分
5. **快速选择**：O(n) 时间找中位数

## 易错点

1. **中位数位置计算错误**：
   - 奇数长度：`mid = (n - 1) // 2`
   - 偶数长度：`mid = (n - 1) // 2`
   
2. **穿插方向错误**：必须从末尾向前取，否则相等元素可能相邻

3. **索引越界**：确保 `left` 和 `right` 的初始值和边界正确

4. **虚拟索引理解**：需要仔细理解映射公式的含义

5. **原地修改**：题目要求原地修改（`Do not return anything, modify nums in-place instead.`）
