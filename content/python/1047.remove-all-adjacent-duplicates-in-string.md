## 题目描述

给出由小写字母组成的字符串 `s`，**重复项删除操作**会选择两个相邻且相同的字母，并删除它们。

在 `s` 上反复执行重复项删除操作，直到无法继续删除。

在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

**示例 1：**

```
输入："abbaca"
输出："ca"
解释：
例如，在 "abbaca" 中，我们可以删除 "bb" 由于两字母相邻且相同，这是此时唯一可以执行删除操作的重复项。之后我们得到字符串 "aaca"，其中又只有 "aa" 可以执行重复项删除操作，所以最后的字符串为 "ca"。
```

**示例 2：**

```
输入："azxxzy"
输出："ay"
```

**提示：**

- `1 <= s.length <= 10⁵`
- `s` 仅由小写英文字母组成

## 解题思路

这道题的核心是**消除相邻的重复字符**，这个过程类似于**括号匹配**问题，非常适合使用**栈**数据结构。

**关键观察：**
1. 需要比较当前字符和前一个字符是否相同
2. 如果相同则删除，如果不同则保留
3. 删除操作会影响后续的比较（删除后前面的字符会暴露出来）

**栈的思想：**
- 栈顶元素就是"前一个字符"
- 如果当前字符与栈顶相同 → 消除（弹出栈顶）
- 如果当前字符与栈顶不同 → 保留（压入栈）
- 最后栈中剩余的字符就是结果

**算法流程：**
1. 遍历字符串中的每个字符
2. 如果栈不为空且栈顶字符等于当前字符，弹出栈顶（消除）
3. 否则，将当前字符压入栈
4. 最后将栈中所有字符拼接成字符串

## Python 代码实现

### 方法一：栈（推荐）

```python
from typing import List

class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []
        
        # 遍历字符串中的每个字符
        for char in s:
            # 如果栈不为空且栈顶字符等于当前字符，弹出栈顶（消除重复）
            if stack and stack[-1] == char:
                stack.pop()
            else:
                # 否则将当前字符压入栈
                stack.append(char)
        
        # 将栈中剩余字符拼接成字符串
        return ''.join(stack)
```

### 方法二：双指针模拟栈（优化空间）

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        # 将字符串转换为列表，方便原地修改
        chars = list(s)
        # slow 指针指向栈顶位置（下一个要写入的位置）
        slow = 0
        
        # fast 指针遍历整个字符串
        for fast in range(len(chars)):
            # 如果 slow > 0 且栈顶字符等于当前字符，消除（slow 回退）
            if slow > 0 and chars[slow - 1] == chars[fast]:
                slow -= 1
            else:
                # 否则将当前字符写入栈顶位置
                chars[slow] = chars[fast]
                slow += 1
        
        # 返回前 slow 个字符
        return ''.join(chars[:slow])
```

### 方法三：递归（理解用，不推荐）

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        # 找到第一对相邻重复字符
        for i in range(len(s) - 1):
            if s[i] == s[i + 1]:
                # 删除这一对，递归处理剩余字符串
                return self.removeDuplicates(s[:i] + s[i + 2:])
        
        # 如果没有找到重复字符，返回原字符串
        return s
```

### 方法四：字符串替换（暴力解法，不推荐）

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        # 持续查找并删除相邻重复字符，直到无法删除
        i = 0
        while i < len(s) - 1:
            if s[i] == s[i + 1]:
                # 删除这一对字符
                s = s[:i] + s[i + 2:]
                # 回退指针，重新检查
                i = max(0, i - 1)
            else:
                i += 1
        
        return s
```

## 复杂度分析

### 方法一：栈（推荐）
- **时间复杂度：** `O(n)` - 只需遍历一次字符串，每个字符最多入栈和出栈各一次
- **空间复杂度：** `O(n)` - 最坏情况下（无重复字符），栈需要存储所有字符

### 方法二：双指针模拟栈
- **时间复杂度：** `O(n)` - 遍历一次字符串
- **空间复杂度：** `O(n)` - 需要将字符串转换为列表

### 方法三：递归
- **时间复杂度：** `O(n²)` - 最坏情况下每次递归只删除一对字符，需要递归 `n/2` 次，每次需要 `O(n)` 时间
- **空间复杂度：** `O(n²)` - 递归调用栈 + 字符串拼接的空间

### 方法四：字符串替换
- **时间复杂度：** `O(n²)` - 每次删除需要创建新字符串
- **空间复杂度：** `O(n)` - 字符串不可变，每次修改都会创建新字符串

## 图解示例

以 `s = "abbaca"` 为例：

```
初始：stack = []

步骤 1：读取 'a'
  stack 为空，压入 'a'
  stack = ['a']

步骤 2：读取 'b'
  stack[-1] = 'a' ≠ 'b'，压入 'b'
  stack = ['a', 'b']

步骤 3：读取 'b'
  stack[-1] = 'b' == 'b'，弹出栈顶（消除）
  stack = ['a']

步骤 4：读取 'a'
  stack[-1] = 'a' == 'a'，弹出栈顶（消除）
  stack = []

步骤 5：读取 'c'
  stack 为空，压入 'c'
  stack = ['c']

步骤 6：读取 'a'
  stack[-1] = 'c' ≠ 'a'，压入 'a'
  stack = ['c', 'a']

结果："ca"
```

## 关键点总结

1. **栈的应用**：遇到需要和"前一个元素"比较的问题，优先考虑栈
2. **字符串处理**：Python 字符串不可变，使用列表（栈）操作更高效
3. **优化技巧**：双指针可以模拟栈，实现原地操作
4. **边界条件**：栈为空时需要特殊处理（压入字符而不是比较）
5. **时间优化**：栈的一次遍历解法远优于递归和字符串替换

## 易错点

1. **忘记检查栈是否为空**
   ```python
   # 错误：可能导致索引越界
   if stack[-1] == char:
       stack.pop()
   
   # 正确：先判断栈是否为空
   if stack and stack[-1] == char:
       stack.pop()
   ```

2. **字符串拼接效率问题**
   ```python
   # 低效：每次拼接都创建新字符串
   result = ""
   for char in stack:
       result += char
   
   # 高效：使用 join
   result = ''.join(stack)
   ```

3. **双指针方法的边界**
   ```python
   # 注意：slow 表示下一个要写入的位置
   # slow - 1 才是当前栈顶
   if slow > 0 and chars[slow - 1] == chars[fast]:
       slow -= 1
   ```

4. **递归方法的性能陷阱**
   ```python
   # 不推荐：每次递归都创建新字符串，效率低
   return self.removeDuplicates(s[:i] + s[i + 2:])
   ```
