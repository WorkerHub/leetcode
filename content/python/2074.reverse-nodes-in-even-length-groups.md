## 题目描述

给你一个链表的头节点 `head`。

链表中的节点**按顺序**分组，第 `i` 组包含第 `i` 个节点（从 1 开始）：
- 第 1 组：1 个节点
- 第 2 组：2 个节点
- 第 3 组：3 个节点
- ...以此类推

**注意：** 最后一组可能包含的节点数少于 `i`。

对于每个**偶数长度**的组，将该组的节点**反转**。

返回修改后的链表。

**示例：**
```
输入：head = [5,2,6,3,9,1,7,3,8,4]
输出：[5,6,2,3,1,9,7,4,8,3]
解释：第2组[2,6]反转为[6,2]，第4组[3,9,1,7]反转为[7,1,9,3]
```

**提示：**
- 链表中节点数目范围 `[1, 10^5]`
- `0 <= Node.val <= 10^5`

## 解题思路

1. 逐组遍历链表，记录每组的起始前驱节点和实际长度
2. 如果当前组长度为偶数，反转该组
3. 移动到下一组

## 代码实现

### 方法一：逐组处理（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseEvenLengthGroups(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy  # 当前组的前驱节点
        group_size = 1  # 当前组的预期大小

        while prev.next:
            # 计算实际组大小（可能比预期小）
            actual_size = 0
            node = prev.next
            while node and actual_size < group_size:
                node = node.next
                actual_size += 1

            # 如果实际大小为偶数，反转该组
            if actual_size % 2 == 0:
                # 反转 prev.next 开始的 actual_size 个节点
                prev.next = self._reverse_group(prev.next, actual_size)

            # 移到下一组的前驱
            for _ in range(actual_size):
                prev = prev.next

            group_size += 1

        return dummy.next

    def _reverse_group(self, start: ListNode, size: int) -> ListNode:
        # 反转从 start 开始的 size 个节点，返回新的头节点
        # 保留 start 之后的节点引用
        tail = start
        for _ in range(size - 1):
            tail = tail.next
        after = tail.next  # 组后面的节点

        # 反转
        prev_node = after
        cur = start
        for _ in range(size):
            nxt = cur.next
            cur.next = prev_node
            prev_node = cur
            cur = nxt

        return prev_node  # 新的头节点（原来的 tail）
```

### 方法二：收集后重建

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseEvenLengthGroups(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 收集所有节点
        nodes = []
        cur = head
        while cur:
            nodes.append(cur)
            cur = cur.next

        # 分组处理
        i = 0
        g = 1
        while i < len(nodes):
            end = min(i + g, len(nodes))
            actual = end - i
            if actual % 2 == 0:
                # 反转这段
                nodes[i:end] = nodes[i:end][::-1]
            i = end
            g += 1

        # 重建链表
        for j in range(len(nodes) - 1):
            nodes[j].next = nodes[j + 1]
        nodes[-1].next = None

        return nodes[0]
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点处理一次
- 空间复杂度：方法一 O(1)，方法二 O(n)

## 关键点总结

1. 逐组遍历，每组的预期大小从 1 递增
2. 最后一组可能节点不足预期，以实际大小为准
3. 实际大小为偶数时才反转

## 易错点

- 最后一组节点可能少于预期，需要计算实际大小
- 反转后需要连接回链表（`prev.next` 指向新头节点，新尾节点指向下一组）
