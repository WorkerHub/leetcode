## 题目描述

一个**等值子字符串**是仅包含同一字符的一个非空子字符串。

例如，`"aaa"` 是 `"aaabbbbbccc"` 的等值子字符串之一。

给你一个数字字符串 `s`，如果 `s` 能够被分解成**一个或多个**等值子字符串的连接，且每个等值子字符串的长度**都能被 3 整除**，**除了恰好一个**等值子字符串的长度不能被 3 整除（该子字符串长度对 3 取余为 1 或 2），则返回 `true`；否则返回 `false`。

**等价表述：** 所有连续相同字符的分组中，恰好有一组长度对 3 取余不为 0，且该余数为 1（即恰好有一个分组长度 mod 3 == 1，无分组长度 mod 3 == 2）。

等等，让我重新看题目描述……

实际题目：如果 `s` 可以被分解为若干等值子字符串，其中恰好一个的长度不能被 3 整除（其余的都能被 3 整除），且该不能被 3 整除的子字符串长度模 3 等于 1，则返回 `true`。

**示例 1：**
```
输入：s = "000111000"
输出：false
解释：s 只能被分解为 "000"、"111"、"000"，每部分都能被 3 整除，但没有恰好一个不能被 3 整除的。
```

**示例 2：**
```
输入：s = "00011111222"
输出：false
解释：s 分解为 "000"、"11111"、"222"，"11111" 长度 5 = 3+2，模 3 = 2，不满足。
```

**示例 3：**
```
输入：s = "011100"
输出：false
```

**示例 4：**
```
输入：s = "0000111"
输出：false
```

## 解题思路

### 核心思想：统计各连续段的长度模 3 的余数

将字符串按连续相同字符分组，统计：
- 长度模 3 为 0 的段：合法，可整除
- 长度模 3 为 1 的段：恰好只能有 1 个
- 长度模 3 为 2 的段：不允许出现

最终：余数为 1 的段恰好有 1 个，余数为 2 的段为 0 个，则返回 `true`。

## 代码实现

### 方法一：分组统计（推荐）

```python
from itertools import groupby

class Solution:
    def isDecomposable(self, s: str) -> bool:
        count_mod1 = 0  # 长度 mod 3 == 1 的分组数

        for key, group in groupby(s):
            length = len(list(group))
            rem = length % 3
            if rem == 2:
                # 不允许有余数为 2 的分组
                return False
            if rem == 1:
                count_mod1 += 1
                if count_mod1 > 1:
                    # 余数为 1 的分组超过 1 个，不合法
                    return False

        return count_mod1 == 1
```

### 方法二：手动计数（不依赖 itertools）

```python
class Solution:
    def isDecomposable(self, s: str) -> bool:
        count_mod1 = 0
        i = 0
        n = len(s)

        while i < n:
            j = i
            # 找连续相同字符的区间
            while j < n and s[j] == s[i]:
                j += 1
            length = j - i
            rem = length % 3

            if rem == 2:
                return False
            if rem == 1:
                count_mod1 += 1
                if count_mod1 > 1:
                    return False
            i = j

        return count_mod1 == 1
```

## 关键点总结

1. 将字符串按连续相同字符分组
2. 每组长度模 3：为 0 合法，为 1 只允许恰好 1 次，为 2 不允许
3. `itertools.groupby` 可简化分组操作

---

## 易错点

- 余数为 2 时直接返回 false
- 最后必须检查 `count_mod1 == 1`（恰好 1 个），不能是 0 个
