## 题目描述

给你一个循环链表的头节点 `list`（最后节点指向头节点），将其平均分成两个循环链表。若节点数为奇数，第一个链表多一个节点。

返回长度为 2 的数组，包含两个链表的头节点。

**示例 1：**
```
输入：list = [1,5,7]
输出：[[1,5],[7]]
```

**示例 2：**
```
输入：list = [2,6,1,5]
输出：[[2,6],[1,5]]
```

**数据范围：**
- 链表中节点数在 [2, 10^5]

## 解题思路

快慢指针找中点：
- 慢指针每次走 1 步，快指针每次走 2 步
- 快指针回到头节点时，慢指针在中间位置

然后断开连接，形成两个独立的循环链表。

## Python 代码实现

### 方法一：快慢指针（推荐）

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def splitCircularLinkedList(self, list: ListNode) -> List[ListNode]:
        # 快慢指针找中点
        slow = list
        fast = list

        # 注意循环链表的终止条件
        while fast.next != list and fast.next.next != list:
            slow = slow.next
            fast = fast.next.next

        # 处理偶数和奇数节点数
        # 偶数：fast.next.next == list（fast 在倒数第二个）
        # 奇数：fast.next == list（fast 在最后一个）
        if fast.next.next == list:
            fast = fast.next  # 偶数时 fast 需要再走一步

        # 现在 slow 是第一个链表的最后一个节点
        # fast 是第二个链表的最后一个节点（也是整个链表的最后一个）
        head2 = slow.next

        # 断开两个链表
        slow.next = list    # 第一个链表成环
        fast.next = head2   # 第二个链表成环

        return [list, head2]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 快慢指针找中点：快指针走两步，慢指针走一步
2. 偶数节点时，第一个链表正好 n/2 个；奇数时第一个多一个
3. 断开时设置各自的环形连接

## 易错点

1. 循环链表终止条件：`fast.next == list` 或 `fast.next.next == list`
2. 奇偶节点数处理不同：偶数时 fast 需要多走一步到达末尾
3. 断开后要设置 `fast.next = head2` 使第二个链表成环
