## 题目描述

给你四个整数 `length`、`width`、`height` 和 `mass`，分别表示一个箱子的长、宽、高和质量。

根据以下规则对箱子分类：
- 若满足 **任一** 条件则为 **大型（Bulky）**：
  - 长、宽或高中至少有一个 >= 10^4
  - 体积（长 × 宽 × 高）>= 10^9
- 若质量 >= 100 则为 **重型（Heavy）**

根据以上规则返回分类：
- 既大型又重型：`"Both"`
- 只大型：`"Bulky"`
- 只重型：`"Heavy"`
- 两者都不是：`"Neither"`

**示例 1：**

```
输入：length = 1000, width = 35, height = 700, mass = 300
输出："Heavy"
解释：体积 = 1000 × 35 × 700 = 24,500,000 < 10^9，任何维度 < 10^4，不是大型。质量 300 >= 100，是重型。
```

**示例 2：**

```
输入：length = 200, width = 50, height = 800, mass = 50
输出："Neither"
```

**提示：**

- `1 <= length, width, height <= 10^5`
- `1 <= mass <= 10^3`

## 解题思路

直接按条件判断即可。注意体积计算时可能整数溢出（Python 不存在此问题）。

## Python 代码实现

### 方法一：直接条件判断（推荐）

```python
class Solution:
    def categorizeBox(self, length: int, width: int, height: int, mass: int) -> str:
        # 判断是否为大型（Bulky）
        is_bulky = (
            max(length, width, height) >= 10**4 or
            length * width * height >= 10**9
        )
        # 判断是否为重型（Heavy）
        is_heavy = mass >= 100

        if is_bulky and is_heavy:
            return "Both"
        elif is_bulky:
            return "Bulky"
        elif is_heavy:
            return "Heavy"
        else:
            return "Neither"
```

### 方法二：用位掩码简化返回

```python
class Solution:
    def categorizeBox(self, length: int, width: int, height: int, mass: int) -> str:
        bulky = any(d >= 10000 for d in [length, width, height]) or \
                length * width * height >= 10**9
        heavy = mass >= 100

        results = ["Neither", "Bulky", "Heavy", "Both"]
        return results[bulky * 1 + heavy * 2]
```

## 复杂度分析

- 时间复杂度：O(1)，固定数量的判断
- 空间复杂度：O(1)

## 关键点总结

1. 大型判断有两个条件：任一维度 >= 10^4，或体积 >= 10^9
2. 重型判断：质量 >= 100
3. 四种分类：Both / Bulky / Heavy / Neither

## 易错点

1. 体积是三个维度相乘，不是最大维度
2. 大型条件是"任一"，即 `or` 而不是 `and`
3. Python 整数运算不溢出，但在其他语言中体积可能溢出需要用 long
