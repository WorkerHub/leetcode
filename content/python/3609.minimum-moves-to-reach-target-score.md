## 题目描述

给你两个正整数 `target` 和 `maxDoubles`。初始分数为 1，每次操作可以：

1. 将分数加 1
2. 将分数乘以 2（最多可以用 `maxDoubles` 次）

请返回从 1 到 `target` 所需的最少操作次数。

**示例 1：**

```
输入：target = 5, maxDoubles = 0
输出：4
解释：1 → 2 → 3 → 4 → 5，共 4 次加法
```

**示例 2：**

```
输入：target = 19, maxDoubles = 2
输出：7
解释：1 → 2（双倍）→ 3 → 4（双倍）→ ... → 19
最优：1+1=2(×2)→4(+1)→5(×2)→10(+9)→19，共7步
```

**示例 3：**

```
输入：target = 10, maxDoubles = 4
输出：4
解释：1(×2)→2(×2)→4(+1)→5(×2)→10，共4步
```

**提示：**

- `1 <= target <= 10^9`
- `0 <= maxDoubles <= 100`

## 解题思路

**逆向贪心**：从 `target` 反推到 1。

- 若当前值为偶数，且还有双倍次数，优先使用"除以 2"（逆向双倍）
- 若当前值为奇数，先减 1（逆向加 1）变为偶数
- 若没有双倍次数了，直接用 `current - 1` 步完成

贪心依据：双倍操作每次将问题规模减半，一定比多次加 1 更优，所以应尽量用双倍。

## Python 代码实现

### 方法一：逆向贪心（推荐）

```python
class Solution:
    def minMoves(self, target: int, maxDoubles: int) -> int:
        moves = 0
        while target > 1 and maxDoubles > 0:
            if target % 2 == 1:
                # 奇数，先减 1
                target -= 1
                moves += 1
            else:
                # 偶数，除以 2（使用一次双倍）
                target //= 2
                moves += 1
                maxDoubles -= 1
        # 剩余部分全靠加 1
        moves += target - 1
        return moves
```

### 方法二：BFS（适合小数据范围）

```python
from collections import deque

class Solution:
    def minMoves(self, target: int, maxDoubles: int) -> int:
        # 状态 (当前值, 剩余双倍次数)
        queue = deque([(1, maxDoubles, 0)])
        visited = set()
        visited.add((1, maxDoubles))

        while queue:
            curr, doubles, steps = queue.popleft()
            if curr == target:
                return steps
            # 操作1：加 1
            if curr + 1 <= target and (curr + 1, doubles) not in visited:
                visited.add((curr + 1, doubles))
                queue.append((curr + 1, doubles, steps + 1))
            # 操作2：乘 2
            if doubles > 0 and curr * 2 <= target and (curr * 2, doubles - 1) not in visited:
                visited.add((curr * 2, doubles - 1))
                queue.append((curr * 2, doubles - 1, steps + 1))

        return -1
```

## 复杂度分析

- 时间复杂度：O(log target + maxDoubles)，每次双倍将 target 减半
- 空间复杂度：O(1)（方法一）

## 关键点总结

1. 逆向思维：从 target 反推到 1，更直观
2. 贪心：双倍次数有限，应尽量用在偶数时
3. 奇数必须先 -1 变偶数才能使用双倍
4. 双倍用完后，剩余步数直接为 `target - 1`

## 易错点

1. 不要从正向 BFS，target 可达 10^9，状态空间太大
2. 双倍用在奇数时不如先 -1 变偶再双倍
3. 初始值是 1，不是 0
