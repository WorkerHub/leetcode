## 题目描述

给你一个整数数组 `arr`。

现需要从数组中取三个下标 `i`、`j` 和 `k`，其中 `(0 <= i < j <= k < arr.length)`。

定义：
- `a = arr[i] XOR arr[i+1] XOR ... XOR arr[j-1]`
- `b = arr[j] XOR arr[j+1] XOR ... XOR arr[k]`

注意，当 `j == i + 1` 时，`a` 等于 `arr[i]`。

请返回能够令 `a == b` 成立的三元组 `(i, j, k)` 的数目。

**示例 1：**
```
输入：arr = [2,3,1,6,7]
输出：4
解释：满足条件的三元组为：
(0,1,2): a=2, b=3 XOR 1=2，满足
(0,2,2): a=2 XOR 3=1? 不对
让我们重新算：
  a = arr[i..j-1]，b = arr[j..k]
  (0,1,2): a=arr[0]=2, b=arr[1] XOR arr[2]=3 XOR 1=2，满足
  (0,1,3): a=arr[0]=2, b=arr[1..3]=3 XOR 1 XOR 6=4，不满足
  (0,2,3): a=arr[0..1]=2 XOR 3=1, b=arr[2..3]=1 XOR 6=7，不满足
  (1,2,3): a=arr[1]=3, b=arr[2..3]=1 XOR 6=7，不满足
  (1,2,4): a=arr[1]=3, b=arr[2..4]=1 XOR 6 XOR 7=0，不满足
  (1,3,4): a=arr[1..2]=3 XOR 1=2, b=arr[3..4]=6 XOR 7=1，不满足
  (0,3,4): a=arr[0..2]=2 XOR 3 XOR 1=0, b=arr[3..4]=6 XOR 7=1，不满足
  重新计算示例...
答案为 4
```

**示例 2：**
```
输入：arr = [1,1,1,1,1]
输出：10
```

**提示：**
- `1 <= arr.length <= 300`
- `1 <= arr[i] <= 10^8`

## 解题思路

**关键数学推导：**

若 `a == b`，则 `a XOR b == 0`。

而 `a XOR b = arr[i] XOR arr[i+1] XOR ... XOR arr[k]`（即 `i` 到 `k` 的全部元素的 XOR）。

所以条件等价于：**`arr[i] XOR arr[i+1] XOR ... XOR arr[k] == 0`**。

也就是说，对于任意满足 `prefix_xor[i] == prefix_xor[k+1]` 的一对 `(i, k+1)`，区间 `[i, k]` 内的 XOR 为 0，`j` 可以是 `[i+1, k]` 中的任意值，共有 `k - i` 种选择。

**算法：**
1. 计算前缀 XOR 数组 `prefix`，其中 `prefix[i] = arr[0] XOR ... XOR arr[i-1]`。
2. 对所有 `i < k+1` 且 `prefix[i] == prefix[k+1]` 的对，贡献 `k - i` 个三元组。

### 方法一暴力思路：

枚举所有三元组 `(i, j, k)`，计算 a 和 b 是否相等，O(n³)。

### 优化思路（前缀XOR）：

直接枚举 `(i, k)`，若两端前缀 XOR 相等，贡献 `k - i` 个三元组，O(n²)。

## Python 代码实现

### 方法一：暴力枚举（O(n³)，用于理解）

```python
from typing import List

class Solution:
    def countTriplets(self, arr: List[int]) -> int:
        n = len(arr)
        count = 0

        for i in range(n):
            for k in range(i + 1, n):
                # 计算 arr[i..k] 的总 XOR
                xor_total = 0
                for x in range(i, k + 1):
                    xor_total ^= arr[x]

                # 若总 XOR 为 0，则 j 可以是 i+1 到 k 中的任意值
                if xor_total == 0:
                    count += k - i  # j 的选择数量为 k - i

        return count
```

### 方法二：前缀 XOR + O(n²) 枚举（推荐）

```python
from typing import List

class Solution:
    def countTriplets(self, arr: List[int]) -> int:
        n = len(arr)
        # 构建前缀 XOR，prefix[i] = arr[0] XOR ... XOR arr[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] ^ arr[i]

        count = 0
        # 枚举 i 和 k，注意 i < k（j 至少有一个选择）
        for i in range(n):
            for k in range(i + 1, n):
                # arr[i..k] 的 XOR = prefix[k+1] XOR prefix[i]
                if prefix[k + 1] == prefix[i]:
                    # j 可以是 i+1 到 k，共 k-i 种
                    count += k - i

        return count
```

### 方法三：哈希表优化（O(n)）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countTriplets(self, arr: List[int]) -> int:
        # 哈希表记录每个前缀 XOR 值出现的下标和频次
        # 对于每个位置 k+1，若 prefix[k+1] 在之前出现过（下标为 i），
        # 则贡献 (k+1 - 1) - i = k - i 个三元组
        # 等价于：贡献 (当前下标 - 1) - 之前所有出现下标 的总和
        # = 频次 * (cur - 1) - 之前下标的总和

        count_map = defaultdict(int)   # 前缀 XOR -> 出现次数
        index_map = defaultdict(int)   # 前缀 XOR -> 出现下标之和

        count_map[0] = 1   # prefix[0] = 0，出现 1 次
        index_map[0] = 0   # 下标 0

        prefix = 0
        result = 0

        for k in range(len(arr)):
            prefix ^= arr[k]
            cur = k + 1  # 当前前缀 XOR 的下标（prefix[k+1]）

            # 找所有 prefix[i] == prefix[k+1] 的 i（i < cur）
            # 贡献为 sum(cur - 1 - i) = 频次 * (cur-1) - 下标之和
            if prefix in count_map:
                result += count_map[prefix] * (cur - 1) - index_map[prefix]

            count_map[prefix] += 1
            index_map[prefix] += cur

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（暴力） | O(n³) | O(1) |
| 方法二（前缀XOR） | O(n²) | O(n) |
| 方法三（哈希表） | O(n) | O(n) |

## 图解示例

```
arr = [2,3,1,6,7]
前缀 XOR：prefix = [0, 2, 1, 0, 6, 1]
                    0  1  2  3  4  5

找所有 i < k+1 使得 prefix[i] == prefix[k+1]：
  prefix[0]=0, prefix[3]=0 → i=0, k+1=3, k=2，贡献 2-0=2
  prefix[0]=0, prefix[3]=0 → 已处理
  prefix[2]=1, prefix[5]=1 → i=2, k+1=5, k=4，贡献 4-2=2

总计：2 + 2 = 4，答案正确！
```

## 关键点总结

1. 核心数学：`a == b` 等价于 `a XOR b == 0`，等价于区间 `[i, k]` 的总 XOR 为 0。
2. 前缀 XOR：`xor(i, k) = prefix[k+1] XOR prefix[i]`，O(1) 查询区间 XOR。
3. `j` 的贡献：一旦确定 `(i, k)` 满足条件，`j` 有 `k - i` 种选择。
4. 哈希表优化：记录每个前缀 XOR 出现的下标和，一次遍历 O(n)。

## 易错点

- 混淆 `j` 的范围：`j` 从 `i+1` 到 `k`（含 k），共 `k - i` 种（不是 `k - i + 1`，因为 j 不包含 i 和 k+1 两端）。
- 前缀 XOR 下标偏移：`prefix[i]` 表示 `arr[0..i-1]` 的 XOR，区间 `[i, k]` 的 XOR 是 `prefix[k+1] XOR prefix[i]`。
- 方法三中对初始状态的处理：`prefix[0] = 0` 需要预置到哈希表中。
