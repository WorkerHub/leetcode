## 题目描述

给你一个数组 `nums` 和一个整数 `target`。

请你返回**不重叠子数组的最多数目**，其中每个子数组的元素总和都等于 `target`。

**示例 1：**
```
输入：nums = [1,1,1,1,1], target = 2
输出：2
解释：两个不重叠子数组 [1,1] 和 [1,1]
```

**示例 2：**
```
输入：nums = [-1,3,5,1,4,2,-9], target = 6
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `0 <= target <= 10^6`

## 解题思路

### 贪心 + 前缀和

**贪心策略：** 尽可能早地找到一个和为 `target` 的子数组（即子数组的右端点越小越好），然后从右端点的下一个位置继续找。

**实现：**
- 用哈希表 `seen` 记录前缀和的出现位置
- 若当前前缀和 `prefix - target` 在 `seen` 中，说明找到了一个满足条件的子数组
- 找到后，清空 `seen`（重新开始，避免与该子数组重叠），答案加 1

## 代码实现

### 方法一：贪心 + 前缀和哈希表（推荐）

```python
from typing import List

class Solution:
    def maxNonOverlapping(self, nums: List[int], target: int) -> int:
        ans = 0
        prefix = 0
        seen = {0}  # 包含前缀和为 0 的情况（空子数组）

        for num in nums:
            prefix += num
            if prefix - target in seen:
                # 找到一个和为 target 的子数组，贪心选取（尽早结束）
                ans += 1
                # 重置：清空 seen，重新开始
                seen = {prefix}  # 新的起点从当前位置开始
                prefix = 0  # 重置前缀和（实际上等价于从下一个位置重新计算）
                # 注意：重置 prefix 和 seen 到新状态
            else:
                seen.add(prefix)

        return ans
```

### 方法二：更清晰的实现

```python
from typing import List

class Solution:
    def maxNonOverlapping(self, nums: List[int], target: int) -> int:
        ans = 0
        n = len(nums)
        i = 0

        while i < n:
            # 从 i 开始，用哈希表找最短的和为 target 的子数组
            seen = {0}
            prefix = 0
            found = False
            for j in range(i, n):
                prefix += nums[j]
                if prefix - target in seen:
                    ans += 1
                    i = j + 1  # 从 j+1 继续
                    found = True
                    break
                seen.add(prefix)
            if not found:
                break  # 从 i 开始找不到，结束

        return ans
```

### 方法三：贪心（修正版）

```python
from typing import List

class Solution:
    def maxNonOverlapping(self, nums: List[int], target: int) -> int:
        ans = 0
        prefix = 0
        seen = {0}

        for num in nums:
            prefix += num
            if prefix - target in seen:
                ans += 1
                seen = {0}   # 从下一个位置重新开始，前缀和重置为 0
                prefix = 0
            seen.add(prefix)  # 将当前（可能已重置后的）前缀和加入

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)（哈希表最大 N 个元素）

## 关键点总结

1. 贪心：尽早找到满足条件的子数组（最短满足条件的）
2. 找到一个后，重置前缀和和哈希表，从下一个位置重新开始
3. 哈希表初始包含 `{0}`，对应从当前位置开始的子数组

## 易错点

- 重置时 `seen = {0}` 且 `prefix = 0`（同时重置，保持一致性）
- 重置后仍要将新的 `prefix` 加入 `seen`
