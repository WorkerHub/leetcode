## 题目描述

给你一个字符串 `num`，表示一个大整数。请你在 `num` 的所有**非空子字符串**中找出**值最大**的奇数，并以字符串形式返回。如果不存在奇数，则返回空字符串 `""`。

**注意：** 子字符串是字符串中的一个连续的字符序列，且只考虑 `num` 作为整数对应的数值。

**示例 1：**
```
输入：num = "52"
输出："5"
解释：非空子字符串有 "5", "2", "52"。其中 "52" 和 "2" 是偶数，"5" 是奇数。
```

**示例 2：**
```
输入：num = "4206"
输出：""
解释：所有子字符串都是偶数，无奇数。
```

**示例 3：**
```
输入：num = "35427"
输出："35427"
解释：35427 本身是奇数。
```

**提示：**
- `1 <= num.length <= 10^5`
- `num` 仅由数字组成，不含前导零

---

## 解题思路

### 核心思想：贪心 - 找最右边的奇数位

一个整数是奇数，当且仅当其**最后一位（个位）是奇数**（1, 3, 5, 7, 9）。

要找最大的奇数子字符串，关键观察：
- 字符串越长，数值越大（因为没有前导零）
- 因此，我们应该找**最长的**以奇数位结尾的前缀
- 只需从右往左扫描，找到第一个奇数数字，返回从开头到该位置的子字符串

---

## 代码实现

### 方法一：从右往左扫描（推荐）

```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        # 从右往左找第一个奇数位
        for i in range(len(num) - 1, -1, -1):
            if int(num[i]) % 2 == 1:
                # 返回从开头到该位置（含）的子字符串
                return num[:i + 1]
        # 没有奇数位，返回空字符串
        return ""
```

### 方法二：使用字符串方法（Python 风格）

```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        # 奇数字符集合
        odd_digits = set('13579')
        # 从右往左找奇数字符
        i = len(num) - 1
        while i >= 0 and num[i] not in odd_digits:
            i -= 1
        # i = -1 时表示没有奇数
        return num[:i + 1]
```

### 方法三：使用 rstrip（去除尾部偶数位）

```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        # 去除末尾所有偶数字符
        result = num.rstrip('02468')
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(1) |
| 方法二 | O(n) | O(1) |
| 方法三 | O(n) | O(1) |

其中 n 为字符串长度。

## 关键点总结

1. 奇偶性只由最后一位（个位）决定
2. 越长的前缀对应越大的数值（无前导零）
3. 贪心策略：找最右边的奇数位，取其前缀作为答案
4. `rstrip` 方法最为简洁

---

## 易错点

- 不要返回任意奇数，要返回**值最大**的奇数（即最长的以奇数结尾的前缀）
- 注意字符 `'0'` 到 `'9'` 与整数的转换
