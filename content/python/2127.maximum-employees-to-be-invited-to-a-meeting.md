## 题目描述

公司有 `n` 名员工，编号为 `0` 到 `n-1`。每位员工都有一位**最喜欢的员工**，可以是自己。公司希望邀请部分员工参加圆桌会议，要求：

- 每位员工只能坐在他**最喜欢的员工**旁边（即两者必须相邻）。

给你整数数组 `favorite`，`favorite[i]` 表示员工 `i` 最喜欢的员工。返回参加圆桌会议的**最多员工数**。

**示例 1：**
```
输入：favorite = [2,2,1,2]
输出：3
```

**提示：**
- `n == favorite.length`
- `2 <= n <= 10^5`
- `0 <= favorite[i] <= n-1`
- `favorite[i] != i`（不能喜欢自己，但题目原文允许，这里假设不允许）

## 解题思路

**功能图（functional graph）分析**

每个节点恰好有一条出边（指向 `favorite[i]`），构成**功能图**。功能图中每个连通分量恰有一个环。

问题分两类：

**情形 1：** 环长度 >= 3 时，只能用这个环本身，环上的节点都参加。取所有这类环中最大的。

**情形 2：** 环长度 == 2 时（即互相喜欢的两人，`a -> b, b -> a`），这两人坐在一起，且从 a 和 b 各自沿入边延伸的最长链可以全部加入。所有长度为 2 的环对应的"哑铃"结构可以在圆桌上拼接（因为可以排成一排弧度）。

最终答案 = max(情形1最大环, 情形2所有哑铃链之和)。

## 代码实现

### 方法一：拓扑排序 + 环检测（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maximumInvitations(self, favorite: List[int]) -> int:
        n = len(favorite)
        in_degree = [0] * n
        for f in favorite:
            in_degree[f] += 1

        # 拓扑排序，剥离链状结构，统计每个节点的最长入链
        depth = [1] * n  # 从叶子到当前节点的最长链长
        queue = deque(i for i in range(n) if in_degree[i] == 0)
        on_cycle = [True] * n  # 拓扑排序后剩余的是环上的节点

        while queue:
            u = queue.popleft()
            on_cycle[u] = False
            v = favorite[u]
            in_degree[v] -= 1
            depth[v] = max(depth[v], depth[u] + 1)
            if in_degree[v] == 0:
                queue.append(v)

        # 情形1：长度 >= 3 的环
        ans_cycle = 0
        # 情形2：长度 == 2 的环，累加链长度
        ans_chain = 0

        visited = [False] * n
        for i in range(n):
            if on_cycle[i] and not visited[i]:
                # 遍历整个环
                cycle_len = 0
                cur = i
                while not visited[cur]:
                    visited[cur] = True
                    cur = favorite[cur]
                    cycle_len += 1
                if cycle_len == 2:
                    # 两节点互相喜欢，各自从入链方向延伸
                    # depth[i] 包含 i 到其入链的最长距离
                    ans_chain += depth[i] + depth[favorite[i]]
                else:
                    ans_cycle = max(ans_cycle, cycle_len)

        return max(ans_cycle, ans_chain)
```

### 方法二：DFS 找环

```python
from typing import List

class Solution:
    def maximumInvitations(self, favorite: List[int]) -> int:
        n = len(favorite)
        # 计算每个节点的最长入链（通过反向图BFS）
        from collections import defaultdict, deque
        
        in_degree = [0] * n
        for f in favorite:
            in_degree[f] += 1
        
        depth = [1] * n
        queue = deque(i for i in range(n) if in_degree[i] == 0)
        on_cycle = [True] * n
        
        while queue:
            u = queue.popleft()
            on_cycle[u] = False
            v = favorite[u]
            in_degree[v] -= 1
            depth[v] = max(depth[v], depth[u] + 1)
            if in_degree[v] == 0:
                queue.append(v)
        
        max_cycle = 0
        chain_sum = 0
        visited = [False] * n
        
        for start in range(n):
            if on_cycle[start] and not visited[start]:
                length = 0
                cur = start
                while not visited[cur]:
                    visited[cur] = True
                    cur = favorite[cur]
                    length += 1
                if length >= 3:
                    max_cycle = max(max_cycle, length)
                else:  # length == 2
                    chain_sum += depth[start] + depth[favorite[start]]
        
        return max(max_cycle, chain_sum)
```

## 关键点总结

1. 功能图每个分量有且仅有一个环。
2. 长度 >= 3 的环只能整体参会，取最大的。
3. 长度 == 2 的环可拼接，链延伸长度用拓扑排序（从叶子向环方向）计算。

## 易错点

- 长度为 2 的环的贡献 = `depth[a] + depth[b]`，其中 `depth` 包含节点本身。
- 多个长度为 2 的环可以累加（情形 2 的答案是所有哑铃的链长之和）。
