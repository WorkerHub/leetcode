## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，代表一摞石头，`nums[0]` 是最顶部的元素。每步操作可以选择：

- **移除** 最顶部的元素（弹出）。
- **放回** 之前移除的某个元素到顶部（仅限已移除的元素中的一个）。

在恰好 `k` 步操作后，返回堆顶元素的最大值。如果无法得到非空堆，返回 `-1`。

**示例 1：**
```
输入：nums = [5,2,2,4,0,6], k = 4
输出：5
解释：移除5,2,2,4，然后放回5。共4步，顶部为5。
```

**示例 2：**
```
输入：nums = [2], k = 1
输出：-1
解释：只有1个元素，移走后没法在奇数次操作后保留非空堆。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i], k <= 10^9`

## 解题思路

关键观察：

- 若移除前 `i` 个元素（0 <= i <= min(k, n)），然后把移除的最大值放回（消耗1步），则总步数为 `i + 1`。要使 `i + 1 <= k` 且奇偶性匹配，即 `i <= k - 1`。
- 另一种方案：移除恰好 `k` 个元素后，顶部变成 `nums[k]`（若 `k < n`）。
- 对于 `k >= n`：可以先全部移除再按需放回，能取任意元素。
- 对于 `n == 1`：只能反复推入/弹出 `nums[0]`，若 `k` 为偶数则顶部是 `nums[0]`，否则为 -1。

**贪心策略：**
候选答案是：
1. `nums[k]`（若 `k < n`）——移除恰好 k 个，顶部自然是 `nums[k]`。
2. `max(nums[0..k-1])`（若 `k >= 1`）——移除 i 个后放回最大值，需要 `i + 1 <= k` 且 `i <= k-1`。

## 代码实现

### 方法一：贪心枚举候选（推荐）

```python
from typing import List

class Solution:
    def maximumTop(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # 特殊情况：只有一个元素
        if n == 1:
            # k 为偶数时可放回，奇数时堆为空
            return nums[0] if k % 2 == 0 else -1

        # k == 0：不操作，顶部就是 nums[0]
        if k == 0:
            return nums[0]

        ans = -1

        # 候选1：移除恰好 k 个，顶部是 nums[k]（若 k < n）
        if k < n:
            ans = max(ans, nums[k])

        # 候选2：移除前 i 个（0 <= i <= min(k-1, n)），放回其中最大值
        # i + 1 <= k => i <= k - 1；放回时用1步
        # 最多移除 min(k-1, n) 个（不能超过数组长度）
        top = max(nums[:min(k - 1, n)])
        ans = max(ans, top)

        return ans
```

### 方法二：分情况讨论（更清晰）

```python
from typing import List

class Solution:
    def maximumTop(self, nums: List[int], k: int) -> int:
        n = len(nums)

        if k == 0:
            return nums[0]

        if n == 1:
            # 只有一个元素，偶数步可以保持，奇数步必须移走
            return nums[0] if k % 2 == 0 else -1

        candidates = []

        # 情况1：恰好移走 k 个，顶部变成 nums[k]
        if k < n:
            candidates.append(nums[k])

        # 情况2：移走 0 到 min(k-1, n) 个后放回最大值
        # 取前 min(k-1, n) 个中的最大
        limit = min(k - 1, n)
        if limit > 0:
            candidates.append(max(nums[:limit]))

        return max(candidates) if candidates else -1
```

## 复杂度分析

- 时间复杂度：O(min(k, n))，求前缀最大值。
- 空间复杂度：O(1)，只用常数额外空间。

## 关键点总结

1. `n == 1` 是特殊情况，奇数步后堆为空返回 -1。
2. 两种候选：移走 k 个后的 `nums[k]`，以及移走 i 个后放回最大值。
3. `k >= n` 时可以访问任意元素（全部移走再放回最大）。

## 易错点

- 忘记 `n == 1` 的边界情况。
- `k == 0` 时直接返回 `nums[0]`，无需操作。
- 候选2的范围是 `nums[0..min(k-1,n)-1]`，不包括 `nums[k-1+1]`。
