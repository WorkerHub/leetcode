## 题目描述

给定一个非空的字符串 s，检查是否可以通过由它的一个子串重复多次构成。

**示例 1:**

```
输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成。
```

**示例 2:**

```
输入: s = "aba"
输出: false
```

**示例 3:**

```
输入: s = "abcabcabcabc"
输出: true
解释: 可由子串 "abc" 重复四次构成 (或子串 "abcabc" 重复两次构成)。
```

**提示:**

- 1 <= s.length <= 10^4
- s 由小写英文字母组成

## 解题思路

**方法一：枚举所有可能的周期长度**
- 周期长度必须是字符串长度的因数
- 检查每个可能的周期

**方法二：拼接字符串技巧**
- 如果 s 由重复子串构成，则 s+s 中必然包含 s（除了首尾）
- 检查 (s+s)[1:-1] 中是否包含 s

## Python 代码实现

### 方法一：枚举周期（推荐）

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        """
        枚举所有可能的周期长度
        时间复杂度: O(n * sqrt(n))
        空间复杂度: O(n)
        """
        n = len(s)
        
        # 周期长度最多是 n//2
        for i in range(1, n // 2 + 1):
            # 周期长度必须是 n 的因数
            if n % i == 0:
                pattern = s[:i]
                # 检查是否由该模式重复构成
                if pattern * (n // i) == s:
                    return True
        
        return False
```

### 方法二：拼接字符串技巧

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        """
        字符串拼接技巧
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        return s in (s + s)[1:-1]
```

### 方法三：KMP 算法

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        """
        KMP 算法
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        n = len(s)
        if n == 0:
            return False
        
        # 构建 next 数组
        next_arr = [0] * n
        j = 0
        
        for i in range(1, n):
            while j > 0 and s[i] != s[j]:
                j = next_arr[j - 1]
            if s[i] == s[j]:
                j += 1
            next_arr[i] = j
        
        # 如果 next[n-1] != 0 且长度是周期的整数倍
        return next_arr[n - 1] != 0 and n % (n - next_arr[n - 1]) == 0
```
