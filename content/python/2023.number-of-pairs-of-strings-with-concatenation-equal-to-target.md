## 题目描述

给你一个**数字**字符串数组 `nums` 和一个数字字符串 `target`。

请你返回 `nums[i] + nums[j]`（字符串连接，`i != j`）等于 `target` 的数对 `(i, j)` 的数目。

**示例 1：**
```
输入：nums = ["777","7","77","77"], target = "7777"
输出：4
解释：有效数对：(0,1),(1,0),(2,3),(3,2)
```

**示例 2：**
```
输入：nums = ["123","4","12","34"], target = "1234"
输出：2
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i].length <= 100`
- `2 <= target.length <= 200`
- `nums[i]` 和 `target` 只含数字

## 解题思路

**方法一（暴力）：** 枚举所有 `(i, j)`（`i != j`），检查 `nums[i] + nums[j] == target`。

**方法二（哈希表）：** 对每个 `nums[i]`，查找 `target` 以 `nums[i]` 开头的情况，剩余部分是否在哈希表中。

由于数据规模小（n ≤ 100），暴力法即可。

## 代码实现

### 方法一：暴力枚举

```python
from typing import List

class Solution:
    def numOfPairs(self, nums: List[str], target: str) -> int:
        count = 0
        n = len(nums)
        for i in range(n):
            for j in range(n):
                if i != j and nums[i] + nums[j] == target:
                    count += 1
        return count
```

### 方法二：哈希表优化（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def numOfPairs(self, nums: List[str], target: str) -> int:
        freq = Counter(nums)  # 统计每个字符串出现次数
        count = 0

        for i in range(1, len(target)):
            prefix = target[:i]  # 前缀
            suffix = target[i:]  # 后缀

            if prefix in freq and suffix in freq:
                if prefix == suffix:
                    # 前后缀相同时，数对数 = n * (n-1)
                    count += freq[prefix] * (freq[suffix] - 1)
                else:
                    count += freq[prefix] * freq[suffix]

        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2 * L)，L 为字符串长度 | O(1) |
| 哈希表 | O(n * L + L^2) | O(n * L) |

## 关键点总结

1. 字符串连接 `a + b == target` 等价于 `target` 以 `a` 开头，`b` 为剩余部分
2. 哈希表方法枚举所有分割点，查找前缀和后缀是否都在 `nums` 中
3. 前缀等于后缀时要特殊处理（排除自身配对）

## 易错点

- 数对是有序的 `(i, j)`，`i` 和 `j` 可以互换（`(i,j)` 和 `(j,i)` 各算一次）
- 当 `i != j` 时，两个不同下标的字符串值可以相同
- 哈希表方法中前缀等于后缀时，`freq[prefix] * (freq[suffix] - 1)` 而不是乘方
