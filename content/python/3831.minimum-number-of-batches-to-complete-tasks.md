## 题目描述

给你一个整数数组 `tasks`，表示若干任务的持续时间，以及一个整数 `batchSize`，每批次最多可以执行 `batchSize` 个任务。

每批次结束后需要休息 1 个时间单位，但最后一批次不需要休息。

返回完成所有任务所需的最少批次数。

**示例 1：**

```
输入：tasks = [1, 2, 3, 4], batchSize = 2
输出：2
解释：第一批执行任务 [3, 4]，第二批执行任务 [1, 2]，共 2 批。
```

**示例 2：**

```
输入：tasks = [1, 2, 3, 4, 5], batchSize = 3
输出：2
解释：第一批 3 个任务，第二批 2 个任务。
```

**提示：**
- `1 <= tasks.length <= 10^5`
- `1 <= batchSize <= 10^5`

## 解题思路

最少批次数 = `ceil(n / batchSize)` = `(n + batchSize - 1) // batchSize`。

这是因为每批次最多 `batchSize` 个任务，要覆盖所有 n 个任务，最少需要向上取整的批次数。

## Python 代码实现

### 方法一：数学计算（推荐）

```python
from typing import List
import math

class Solution:
    def minimumBatches(self, tasks: List[int], batchSize: int) -> int:
        n = len(tasks)
        # 向上取整
        return math.ceil(n / batchSize)
```

### 方法二：位运算向上取整

```python
from typing import List

class Solution:
    def minimumBatches(self, tasks: List[int], batchSize: int) -> int:
        n = len(tasks)
        # 等价于 (n + batchSize - 1) // batchSize
        return (n + batchSize - 1) // batchSize
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 最少批次数由任务总数和每批上限决定，与具体任务持续时间无关（本题只问批次数）。
2. 向上取整公式 `(n + k - 1) // k` 是常用的整数除法技巧。
3. 若题目要求最短总时间（含休息），则需要 `(batches - 1) * rest + sum(tasks)`。

## 易错点

1. 注意区分"批次数"和"总时间"，本题只要求批次数。
2. 若 n 是 batchSize 的整倍数，`ceil(n/batchSize) = n/batchSize`，无需额外处理。
