## 题目描述

给你一个字符串 `word`，`word` 可以包含 **重复** 的小写英文字母。

重新分配字母到键盘按键（2-9，共 8 个键），每个按键可以映射任意数量字母。输入一个字母的代价等于它在对应按键上的位置（1-indexed）。

返回输入 `word` 的最小总代价。

**示例 1：**
```
输入：word = "aabbccddeeffgghhiiiiii"
输出：24
```

**示例 2：**
```
输入：word = "xyzxyzxyzxyz"
输出：12
```

**提示：**
- `1 <= word.length <= 10^5`
- `word` 只包含小写英文字母

## 解题思路

贪心策略：频率越高的字母应该分配到代价越低的位置（代价为 1 的位置有 8 个，代价为 2 的位置有 8 个，以此类推）。

1. 统计每个字母的频率
2. 按频率从大到小排序
3. 前 8 个高频字母代价 1，后 8 个代价 2，依此类推

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from collections import Counter

class Solution:
    def minimumPushes(self, word: str) -> int:
        # 统计每个字母的频率
        freq = Counter(word)
        # 按频率从大到小排序
        counts = sorted(freq.values(), reverse=True)

        total = 0
        for i, cnt in enumerate(counts):
            # 第 i 个（0-indexed）字母的代价为 i // 8 + 1
            total += cnt * (i // 8 + 1)

        return total
```

### 方法二：使用 heapq

```python
from collections import Counter
import heapq

class Solution:
    def minimumPushes(self, word: str) -> int:
        freq = Counter(word)
        # 使用最大堆（取负值模拟）
        heap = [-v for v in freq.values()]
        heapq.heapify(heap)

        total = 0
        i = 0
        while heap:
            cnt = -heapq.heappop(heap)
            total += cnt * (i // 8 + 1)
            i += 1

        return total
```

### 方法三：详细注释版

```python
from collections import Counter

class Solution:
    def minimumPushes(self, word: str) -> int:
        freq = Counter(word)
        # 按频率降序排列所有字母的频率
        counts = sorted(freq.values(), reverse=True)

        total = 0
        for rank, cnt in enumerate(counts):
            # rank 从 0 开始
            # 第 0-7 位：代价 1（第一次按键）
            # 第 8-15 位：代价 2（第二次按键）
            # ...
            press_cost = rank // 8 + 1
            total += cnt * press_cost

        return total
```

## 复杂度分析

- 时间复杂度：O(n + K log K)，K 为不同字母数（最多 26），排序 O(26 log 26) = O(1)
- 空间复杂度：O(K) = O(1)

## 关键点总结

1. 贪心：频率最高的字母应占代价最小的位置（代价 1 的位置）
2. 排序后按 `i // 8 + 1` 计算每个字母的按键代价
3. 最多 26 个不同字母，排序代价忽略不计

## 易错点

1. 按频率排序，不是按字母排序
2. 注意代价是按键次数（`i // 8 + 1`），要乘以频率
3. 与 3014 区别：3014 所有字母不同，本题有重复
