## 题目描述

给你一个字符串 `s`，返回出现次数最多的字符及其出现次数。如果有多个字符出现次数相同，返回字典序最小的字符。

**示例 1：**

```
输入：s = "aababc"
输出：["a", 3]
解释：'a' 出现 3 次，是最多的。
```

**示例 2：**

```
输入：s = "bbccc"
输出：["c", 3]
解释：'c' 出现 3 次，与 'b' 相同... 不对，'c' 出现 3 次，'b' 出现 2 次。
```

**提示：**
- `1 <= s.length <= 100`
- `s` 仅由小写英文字母组成

## 解题思路

使用哈希表统计每个字符的出现次数，然后找出现次数最多的字符（次数相同时取字典序最小）。

## Python 代码实现

### 方法一：Counter（推荐）

```python
from collections import Counter

class Solution:
    def maxRepeated(self, s: str) -> list:
        cnt = Counter(s)
        max_count = max(cnt.values())
        # 找出所有出现次数等于 max_count 的字符，取字典序最小
        chars = [c for c, v in cnt.items() if v == max_count]
        return [min(chars), max_count]
```

### 方法二：排序

```python
class Solution:
    def maxRepeated(self, s: str) -> list:
        from collections import Counter
        cnt = Counter(s)
        # 按 (-次数, 字符) 排序，取第一个
        best = min(cnt.items(), key=lambda x: (-x[1], x[0]))
        return [best[0], best[1]]
```

## 复杂度分析

- 时间复杂度：O(n)，统计频率
- 空间复杂度：O(26) = O(1)，只有 26 个小写字母

## 关键点总结

1. Counter 是 Python 中统计频率的最简洁方式。
2. 次数相同时取字典序最小，用 `min(chars)` 即可（字符串默认按字典序比较）。
3. 排序时以 `(-次数, 字符)` 为键，自然得到最优解。

## 易错点

1. 次数相同时要返回字典序最小的字符，不是任意一个。
2. 返回格式：字符和次数的列表，注意顺序。
