## 题目描述

给定一棵 `n` 个节点的无向树，节点编号为 `0` 到 `n-1`，树的边用 `edges` 数组描述。每个节点有一个值 `vals[i]`。

从任意节点出发，沿着边移动，规则为：每次只能移动到值更大的节点。求从某个节点出发能进行的最大移动次数（即最长严格递增路径的边数）。

**示例 1：**
```
输入：n = 5, edges = [[0,1],[0,2],[1,3],[1,4]], vals = [3,1,4,1,5]
输出：3
解释：路径 2(val=4)->0(val=3) 不合法（值减小）。
     路径 3(val=1)->1(val=1) 不合法（值相等）。
     路径 3->1->0: 1->1->3 不合法。
     路径 4(val=5)->1(val=1): 5>1 合法，但只有 1 步。
     最长：某路径长度为 3。
```

**示例 2：**
```
输入：n = 4, edges = [[0,1],[1,2],[2,3]], vals = [1,2,3,4]
输出：3
解释：路径 0->1->2->3，值依次为 1<2<3<4，可以走 3 步。
```

**提示：**
- `2 <= n <= 5 * 10^4`
- `edges.length == n - 1`
- `0 <= vals[i] <= 10^5`

## 解题思路

树上的最长严格递增路径问题，类似于矩阵中的最长递增路径（329题），但在树上操作。

由于树是无向的，路径可以从任意节点出发向任意方向走，只要下一个节点的值严格更大。

**关键思路：**
- 对树进行 DFS，对每个节点计算两个方向（作为根时，子树中的最长递增路径；向父节点方向的最长递增路径）。
- 或者：枚举每个节点作为路径的"最低点"（值最小的端点），统计能向更高值节点延伸的最长路径。

**换根 DP 方法：**
1. 第一次 DFS（根为 0）：计算每个节点的 `down[v]`，即从 v 出发往子树方向的最长严格递增路径长度。
2. 第二次 DFS：计算 `up[v]`，即从 v 出发往父节点方向的最长严格递增路径长度。
3. 答案为 `max(down[v] + up[v])` 对所有 v 取最大。

## Python 代码实现

### 方法一：换根 DP（推荐）

```python
from typing import List
from collections import defaultdict
import sys

sys.setrecursionlimit(100000)

class Solution:
    def maxMoves(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # down[v]: 从 v 出发，向子树方向的最长严格递增路径（边数）
        down = [0] * n

        def dfs1(v: int, parent: int) -> None:
            for u in graph[v]:
                if u == parent:
                    continue
                dfs1(u, v)
                if vals[u] > vals[v]:
                    # 可以从 v 移动到 u
                    down[v] = max(down[v], down[u] + 1)

        dfs1(0, -1)

        ans = max(down)
        # up[v]: 从 v 出发，向父节点方向的最长严格递增路径（边数）
        up = [0] * n

        def dfs2(v: int, parent: int) -> None:
            nonlocal ans
            # 收集子节点向下的最优和次优
            children_down = []
            for u in graph[v]:
                if u == parent:
                    continue
                if vals[u] > vals[v]:
                    children_down.append(down[u] + 1)
                else:
                    children_down.append(0)
            children_down.sort(reverse=True)

            for i, u in enumerate([c for c in graph[v] if c != parent]):
                # 计算 up[u]
                # up[u] = 从 u 向 v 走（若 vals[v] > vals[u]），再从 v 向上走
                contribution_from_v = 0
                if vals[v] > vals[u]:
                    # 子节点 u 可以到父节点 v，再向上
                    # v 向上：up[v]；v 向其他子节点：最优的子树（排除 u 自身）
                    best_other = 0
                    for w in graph[v]:
                        if w == parent or w == u:
                            continue
                        if vals[w] > vals[v]:
                            best_other = max(best_other, down[w] + 1)
                    # v 能向上走的最大步数（up[v]）
                    contribution_from_v = 1 + max(up[v], best_other)
                up[u] = contribution_from_v
                ans = max(ans, up[u] + down[u])
                dfs2(u, v)

        dfs2(0, -1)
        return ans
```

### 方法二：暴力 DFS（简化版，适合小数据）

```python
from typing import List
from collections import defaultdict
import sys

sys.setrecursionlimit(100000)

class Solution:
    def maxMoves(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 0

        def dfs(v: int, parent: int, steps: int) -> None:
            nonlocal ans
            ans = max(ans, steps)
            for u in graph[v]:
                if u != parent and vals[u] > vals[v]:
                    dfs(u, v, steps + 1)

        for start in range(n):
            dfs(start, -1, 0)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，换根 DP 两次 DFS；暴力解为 O(n^2)
- 空间复杂度：O(n)，递归栈和 DP 数组

## 关键点总结

1. 树上最长路径问题常用换根 DP（两次 DFS）求解
2. 首次 DFS 计算每个节点向下的最优值，第二次 DFS 补充向上的最优值
3. 严格递增意味着不能有环（实际上树本身就无环），DFS 无需 visited

## 易错点

1. 换根时需要注意"排除当前子节点"的最优子树计算
2. 递归深度可能很大，需要设置 `sys.setrecursionlimit`
