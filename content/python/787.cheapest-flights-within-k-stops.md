## 题目描述

在 `n` 个城市中，有 `m` 个航班。给定三个数组 `flights`、起点 `src`、终点 `dst` 以及中转次数上限 `k`。

`flights[i] = [from_i, to_i, price_i]` 表示从城市 `from_i` 到城市 `to_i` 有一班航班，票价为 `price_i`。

现在从城市 `src` 出发到城市 `dst`，最多经过 `k` 站中转，求最低票价。如果无法到达，返回 `-1`。

**示例 1：**
```
输入: 
n = 4, flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]], src = 0, dst = 3, k = 1
输出: 700
解释: 
从城市 0 到城市 3 经过最多 1 站中转的最便宜价格是 700。
路径为：0 -> 1 -> 3
```

**示例 2：**
```
输入: 
n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 1
输出: 200
解释: 
从城市 0 到城市 2 经过最多 1 站中转的最便宜价格是 200。
路径为：0 -> 1 -> 2
```

**示例 3：**
```
输入: 
n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 0
输出: 500
解释: 
从城市 0 到城市 2 不经过中转的最便宜价格是 500。
路径为：0 -> 2
```

**提示：**
- `1 <= n <= 100`
- `0 <= flights.length <= (n * (n - 1) / 2)`
- `flights[i].length == 3`
- `0 <= from_i, to_i < n`
- `from_i != to_i`
- `1 <= price_i <= 10^4`
- 不存在重复的航班
- `0 <= src, dst, k < n`
- `src != dst`

## 解题思路

这道题是一个典型的**带约束的最短路径问题**，关键在于"最多经过 k 站中转"这个限制。

**核心观察：**
1. 这是一个图论问题，城市是节点，航班是有向边，票价是边权
2. 不能直接用 Dijkstra 算法，因为有中转次数限制
3. 需要同时记录"到达该城市的最低价格"和"已经中转的次数"

**解法分析：**

**方法一：动态规划（Bellman-Ford 思想）**
- 定义状态：`dp[i][j]` 表示经过最多 `i` 次中转到达城市 `j` 的最低价格
- 状态转移：遍历所有航班，更新可达城市的最低价格
- 最多需要 k+1 轮迭代（k 次中转意味着 k+1 条边）

**方法二：BFS（广度优先搜索）**
- 从起点开始层次遍历，每层代表一次航班
- 使用队列记录 `(当前城市, 当前总价格)`
- 记录到达每个城市的最低价格，剪枝优化
- 最多遍历 k+1 层

**方法三：优先队列优化的 Dijkstra 变体**
- 使用最小堆记录 `(当前价格, 当前城市, 已用中转次数)`
- 每次取出价格最低的状态扩展
- 当中转次数超过 k 时停止扩展该路径

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        """
        使用动态规划求解最多经过 k 站中转的最低票价
        
        时间复杂度：O((k+1) * m)，m 是航班数量
        空间复杂度：O(n)
        """
        # 初始化：所有城市的价格都是无穷大
        INF = float('inf')
        dp = [INF] * n
        dp[src] = 0  # 起点价格为 0
        
        # 最多经过 k 站中转，需要迭代 k+1 轮
        for i in range(k + 1):
            # 使用临时数组避免状态污染
            temp = dp[:]
            
            # 遍历所有航班
            for from_city, to_city, price in flights:
                # 如果起点可达，则更新终点的最低价格
                if dp[from_city] != INF:
                    temp[to_city] = min(temp[to_city], dp[from_city] + price)
            
            dp = temp
        
        # 如果目的地不可达，返回 -1
        return dp[dst] if dp[dst] != INF else -1
```

### 方法二：BFS 广度优先搜索

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        """
        使用 BFS 层次遍历，每层代表一次航班
        
        时间复杂度：O(k * m)
        空间复杂度：O(n + m)
        """
        # 构建邻接表
        graph = defaultdict(list)
        for from_city, to_city, price in flights:
            graph[from_city].append((to_city, price))
        
        # 记录到达每个城市的最低价格
        min_cost = [float('inf')] * n
        min_cost[src] = 0
        
        # BFS 队列：(当前城市, 当前总价格)
        queue = deque([(src, 0)])
        stops = 0
        
        while queue and stops <= k:
            size = len(queue)
            
            # 处理当前层的所有城市
            for _ in range(size):
                curr_city, curr_cost = queue.popleft()
                
                # 遍历当前城市的所有邻居
                for next_city, price in graph[curr_city]:
                    new_cost = curr_cost + price
                    
                    # 只有价格更低时才继续扩展
                    if new_cost < min_cost[next_city]:
                        min_cost[next_city] = new_cost
                        queue.append((next_city, new_cost))
            
            stops += 1
        
        return min_cost[dst] if min_cost[dst] != float('inf') else -1
```

### 方法三：优先队列优化（Dijkstra 变体）

```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        """
        使用最小堆优化的 Dijkstra 算法
        
        时间复杂度：O(m * log(m))
        空间复杂度：O(n + m)
        """
        # 构建邻接表
        graph = defaultdict(list)
        for from_city, to_city, price in flights:
            graph[from_city].append((to_city, price))
        
        # 最小堆：(当前价格, 当前城市, 已用中转次数)
        heap = [(0, src, 0)]
        
        # 记录到达每个城市时的最少中转次数
        visited = {}
        
        while heap:
            curr_cost, curr_city, stops = heapq.heappop(heap)
            
            # 到达目的地，返回价格
            if curr_city == dst:
                return curr_cost
            
            # 中转次数超限，跳过
            if stops > k:
                continue
            
            # 如果之前访问过该城市且中转次数更少，跳过
            # （因为相同价格下，中转次数少的路径更优）
            if curr_city in visited and visited[curr_city] <= stops:
                continue
            visited[curr_city] = stops
            
            # 扩展邻居节点
            for next_city, price in graph[curr_city]:
                heapq.heappush(heap, (curr_cost + price, next_city, stops + 1))
        
        return -1
```

## 复杂度分析

### 方法一：动态规划
- **时间复杂度：** O((k+1) × m)，其中 m 是航班数量，需要迭代 k+1 轮，每轮遍历所有航班
- **空间复杂度：** O(n)，需要两个长度为 n 的数组

### 方法二：BFS
- **时间复杂度：** O(k × m)，最多遍历 k+1 层，每层可能处理所有边
- **空间复杂度：** O(n + m)，邻接表存储图和队列空间

### 方法三：优先队列
- **时间复杂度：** O(m × log(m))，每条边最多入堆一次，堆操作是 O(log m)
- **空间复杂度：** O(n + m)，邻接表和堆的空间

## 关键点总结

1. **问题本质**：这是带约束的最短路径问题，关键是处理"最多 k 次中转"的限制
2. **状态设计**：需要同时记录价格和中转次数，不能只关注价格最优
3. **算法选择**：
   - 动态规划最稳定，适合新手理解
   - BFS 思路清晰，层次遍历自然对应中转次数
   - Dijkstra 变体效率高，但需要注意剪枝条件
4. **状态更新**：DP 方法需要使用临时数组避免同一轮内的状态污染
5. **边界处理**：注意 k=0 的情况（不允许中转，直达航班）

## 易错点

1. **中转次数理解错误**：k 次中转意味着 k+1 条边（k+1 个航班），DP 需要迭代 k+1 轮
2. **状态污染**：DP 方法如果不用临时数组，同一轮内的更新会相互影响
3. **剪枝条件**：Dijkstra 方法中，不能简单用 visited 判断是否访问过，因为后续可能以更少中转次数到达同一城市
4. **无穷大处理**：初始化时用 `float('inf')`，最后判断是否可达
5. **图的存储**：注意是有向图，不是无向图
