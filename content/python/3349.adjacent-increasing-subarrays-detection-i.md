## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

判断 `nums` 中是否存在**两个相邻且不重叠的长度为 k 的严格递增子数组**。

即：是否存在下标 `a`，使得 `nums[a..a+k-1]` 和 `nums[a+k..a+2k-1]` 都是严格递增的。

**示例：**
```
输入：nums = [2, 5, 7, 8, 9, 2, 3, 4, 3, 1], k = 3
输出：true
解释：nums[2..4] = [7,8,9] 和 nums[5..7] = [2,3,4] 都是严格递增的
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= k <= nums.length // 2`

## 解题思路

预处理每个位置开始的严格递增子数组的长度，然后检查是否存在长度 >= k 的相邻对。

或者直接暴力枚举所有可能的起始位置 `a`，验证两段是否都严格递增。

## Python 代码实现

### 方法一：预处理递增长度（推荐）

```python
from typing import List

class Solution:
    def hasIncreasingSubarrays(self, nums: List[int], k: int) -> bool:
        n = len(nums)
        
        # inc[i] = 从 i 开始的最长严格递增子数组长度
        inc = [1] * n
        for i in range(n - 2, -1, -1):
            if nums[i] < nums[i + 1]:
                inc[i] = inc[i + 1] + 1
        
        # 检查是否存在位置 a 使 inc[a] >= k 且 inc[a+k] >= k
        for a in range(n - 2 * k + 1):
            if inc[a] >= k and inc[a + k] >= k:
                return True
        
        return False
```

### 方法二：直接暴力枚举

```python
from typing import List

class Solution:
    def hasIncreasingSubarrays(self, nums: List[int], k: int) -> bool:
        n = len(nums)
        
        def is_increasing(start, length):
            for i in range(start, start + length - 1):
                if nums[i] >= nums[i + 1]:
                    return False
            return True
        
        for a in range(n - 2 * k + 1):
            if is_increasing(a, k) and is_increasing(a + k, k):
                return True
        
        return False
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，预处理 + 一次遍历
- 空间复杂度：O(n)，递增长度数组

**方法二：**
- 时间复杂度：O(n * k)，暴力验证
- 空间复杂度：O(1)

## 关键点总结

1. 预处理每个位置的最长严格递增子数组长度，可以 O(1) 验证每个起始位置。
2. 两段子数组必须相邻且不重叠，第二段从 `a + k` 开始。
3. 数据范围小（n <= 100），暴力也可通过。

## 易错点

1. 严格递增：每个元素必须比前一个**严格大**，不能等于。
2. 两段不重叠：第一段 `[a, a+k-1]`，第二段 `[a+k, a+2k-1]`。
3. 枚举范围：`a` 最大为 `n - 2k`（确保两段都在数组内）。
