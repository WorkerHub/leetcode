## 题目描述

给你一个有向图，其中有 `n` 个节点（编号 `0` 到 `n-1`）。

给你一个长度为 `n` 的整数数组 `edges`，其中 `edges[i]` 表示从节点 `i` 到节点 `edges[i]` 有一条有向边。

节点 `i` 的**边分数**是所有指向节点 `i` 的边的节点编号之和。

返回**边分数最高**的节点，若有多个，返回**编号最小**的。

**示例 1：**
```
输入：edges = [1,0,0,0,0,7,7,5]
输出：7
解释：节点 7 的边分数 = 5 + 6 = 11（节点 5 和 6 都指向 7），最高。
```

**提示：**
- `n == edges.length`
- `2 <= n <= 10^5`
- `0 <= edges[i] < n`
- `edges[i] != i`

## 解题思路

遍历 `edges`，对每个节点 `i`，将 `i` 加到 `edges[i]` 的分数上。最后找分数最大的节点（若相同取编号最小的）。

## 代码实现

### 方法一：哈希表计分（推荐）

```python
from typing import List

class Solution:
    def edgeScore(self, edges: List[int]) -> int:
        n = len(edges)
        score = [0] * n
        
        # 统计每个节点的边分数
        for i, e in enumerate(edges):
            score[e] += i
        
        # 找分数最高的节点（分数相同取编号最小的）
        best = 0
        for i in range(1, n):
            if score[i] > score[best]:
                best = i
        
        return best
```

### 方法二：Python 简洁版

```python
from typing import List

class Solution:
    def edgeScore(self, edges: List[int]) -> int:
        score = [0] * len(edges)
        for i, e in enumerate(edges):
            score[e] += i
        # max 函数：按 score 最大，相同时按编号最小（编号升序遍历，先遇到的编号更小）
        return score.index(max(score))
```

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接计分 | O(n) | O(n) |

## 关键点总结

1. 遍历一次 `edges`，将每个节点 i 的编号累加到 `edges[i]` 的分数上。
2. `list.index(max_val)` 返回第一个最大值的下标（即编号最小的）。
3. 分数可能很大（n 最大 10^5，节点编号最大 10^5-1），Python 无上限无需担心溢出。

## 易错点

- 边分数是"指向该节点的所有边的**源节点编号之和**"，不是边的数量。
- 若有多个最高分节点，返回**编号最小**的，`index` 方法天然返回第一个。
