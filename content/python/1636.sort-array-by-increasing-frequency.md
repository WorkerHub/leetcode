## 题目描述

给你一个整数数组 `nums`，请你将数组按照每个值的频率**升序**排序。如果有多个值的频率相同，请你按照数值本身**降序**进行排序。

请你返回排序后的数组。

**示例：**
```
输入：nums = [1,1,2,2,2,3]
输出：[3,1,1,2,2,2]
解释：'3' 频率为 1，'1' 频率为 2，'2' 频率为 3

输入：nums = [2,3,1,3,2]
输出：[1,3,3,2,2]
解释：'1' 和 '3' 频率都是... '2' 频率为 2 > '1' 频率 1 = '3' 频率... 先频率升序，同频率降序
```

## 解题思路

1. 用 Counter 统计每个元素的频率
2. 自定义排序键：`(频率, -值)`（频率升序，值降序）

## 代码实现

### 方法一：Counter + 自定义排序（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        freq = Counter(nums)
        # 排序：先按频率升序，再按值降序（取负值实现降序）
        return sorted(nums, key=lambda x: (freq[x], -x))
```

### 方法二：分组排序

```python
from typing import List
from collections import Counter

class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        freq = Counter(nums)
        # 按频率分组，同频率组内按值降序排列
        groups = {}
        for num, cnt in freq.items():
            if cnt not in groups:
                groups[cnt] = []
            groups[cnt].append(num)
        
        result = []
        for cnt in sorted(groups.keys()):
            # 同频率内按值降序
            for num in sorted(groups[cnt], reverse=True):
                result.extend([num] * cnt)
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter + 排序 | O(n log n) | O(n) |
| 分组排序 | O(n log n) | O(n) |

## 关键点总结

1. `Counter` 统计频率，O(n) 时间
2. 排序键 `(freq[x], -x)`：频率升序，值降序
3. Python 的 `sorted` 稳定排序，可以先排值再排频率

## 易错点

- 相同频率时按值**降序**（`-x`），不是升序
- 排序后需要完整返回数组（包含重复元素），不是唯一元素列表
