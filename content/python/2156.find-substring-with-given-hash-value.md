## 题目描述

给你一个字符串 `s`（小写英文字母），以及整数 `power`、`modulo`、`k`、`hashValue`。

字符串的**哈希值**定义为：
```
hash(s, power, modulo, k, hashValue) = (val(s[0]) * power^0 + val(s[1]) * power^1 + ... + val(s[k-1]) * power^(k-1)) mod modulo
```

其中 `val(c) = c - 'a' + 1`。

找到字符串 `s` 中第一个长度为 `k`、哈希值为 `hashValue` 的子串，并返回该子串。若不存在，保证一定存在答案。

**提示：**
- `1 <= k <= s.length <= 2 * 10^4`
- `1 <= power, modulo <= 10^9`
- `0 <= hashValue < modulo`

## 解题思路

**从右向左滚动哈希**

从左向右滚动哈希时，移除窗口左端需要除法（模逆元），较复杂。

**从右向左**滚动则只需乘法：
- 滑动时，哈希值 `h = (h - val(s[i+k]) * power^(k-1)) * power^(-1) + val(s[i]) * 1`。
- 反过来，从右向左时，窗口 `[i, i+k-1]` 的哈希为：
  `h[i] = val(s[i]) + val(s[i+1]) * power + ... + val(s[i+k-1]) * power^(k-1)`
- 向左移动时：`h[i-1] = val(s[i-1]) + h[i] * power`（相当于整体乘 power 再加新元素）。

从最后一个窗口开始，向左推进，记录最近找到的匹配窗口（最终返回最左边的）。

## 代码实现

### 方法一：从右向左滚动哈希（推荐）

```python
class Solution:
    def subStrHash(self, s: str, power: int, modulo: int, k: int, hashValue: int) -> str:
        n = len(s)
        # power^(k-1) % modulo
        pk_minus_1 = pow(power, k - 1, modulo)

        # 初始化最后一个窗口的哈希值
        h = 0
        for i in range(n - 1, n - k - 1, -1):
            h = (h * power + (ord(s[i]) - ord('a') + 1)) % modulo

        # 向左滑动
        ans_start = -1
        if h == hashValue:
            ans_start = n - k

        for i in range(n - k - 1, -1, -1):
            # 移出右端字符，移入左端字符
            # h_new = (h - val(s[i+k]) * pk_minus_1) * power_inv + val(s[i])
            # 但这里从右向左的递推：
            # h[i] = val(s[i]) + val(s[i+1])*p + ... + val(s[i+k-1])*p^(k-1)
            # h[i-1] = val(s[i-1]) + h[i] * p（如果把窗口左移一位）
            # 不对，让我重新推导：
            # 从右向左构造：
            # curr_hash 表示当前窗口 [i+1, i+k] 的哈希
            # 新窗口 [i, i+k-1] 的哈希 = val(s[i]) + val(s[i+1])*p + ... + val(s[i+k-1])*p^(k-1)
            # = val(s[i]) + p * (val(s[i+1]) + val(s[i+2])*p + ... + val(s[i+k-1])*p^(k-2))
            # 而 val(s[i+1]) + ... + val(s[i+k])*p^(k-1) = curr_hash
            # 所以：new_hash = val(s[i]) + p * (curr_hash - val(s[i+k]) * p^(k-1))
            remove = (ord(s[i + k]) - ord('a') + 1) * pk_minus_1 % modulo
            h = ((h - remove) * power + (ord(s[i]) - ord('a') + 1)) % modulo
            if h == hashValue:
                ans_start = i

        return s[ans_start: ans_start + k]
```

### 方法二：直接用模逆元从左到右

```python
class Solution:
    def subStrHash(self, s: str, power: int, modulo: int, k: int, hashValue: int) -> str:
        n = len(s)

        # 模逆元（modulo 必须是质数时才适用 Fermat 小定理）
        # 本题 modulo 不保证为质数，需要 extended GCD
        def mod_inverse(a, m):
            # 扩展欧几里得
            g, x, _ = extended_gcd(a % m, m)
            if g != 1:
                return None
            return x % m

        def extended_gcd(a, b):
            if a == 0:
                return b, 0, 1
            g, x, y = extended_gcd(b % a, a)
            return g, y - (b // a) * x, x

        inv_power = mod_inverse(power, modulo)
        if inv_power is None:
            # power 和 modulo 不互质，用从右向左方法
            return self.subStrHash(s, power, modulo, k, hashValue)

        # 计算初始窗口哈希
        h = 0
        pk = 1
        for i in range(k):
            h = (h + (ord(s[i]) - ord('a') + 1) * pk) % modulo
            pk = pk * power % modulo

        ans = None
        if h == hashValue:
            ans = s[:k]

        for i in range(1, n - k + 1):
            # 移出 s[i-1]，移入 s[i+k-1]
            h = (h - (ord(s[i-1]) - ord('a') + 1)) * inv_power % modulo
            h = (h + (ord(s[i+k-1]) - ord('a') + 1) * pow(power, k-1, modulo)) % modulo
            if h == hashValue:
                ans = s[i:i+k]

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 从右向左 | O(n) | O(1) |

## 关键点总结

1. 从右向左滚动哈希，避免需要模逆元的除法操作。
2. 递推关系：`h[i] = val(s[i]) + p * (h[i+1] - val(s[i+k]) * p^(k-1))`。
3. 记录最后一次匹配的位置（最左侧匹配）。

## 易错点

- 取模运算中可能出现负数，需要加 `% modulo` 保证非负：`(h - remove + modulo) % modulo`。
- 返回的是最左侧的匹配，从右向左遍历时记录每次匹配，最终返回最左的。
