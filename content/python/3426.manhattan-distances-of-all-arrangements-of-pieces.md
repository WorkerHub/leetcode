## 题目描述

给你三个整数 `m`、`n` 和 `k`。

考虑一个 `m x n` 的网格，将 `k` 个不可区分的棋子放置在其中（每个格子最多放一个）。

返回所有可能放置方案的**曼哈顿距离之和的总和**（对所有方案，对所有棋子对，求曼哈顿距离之和，再对所有方案求和）对 `10^9 + 7` 取模的结果。

**示例：**

```
输入：m = 2, n = 2, k = 2
输出：8
解释：C(4,2)=6 种方案，每种方案有 C(2,2)=1 对棋子...
```

**提示：**
- `1 <= m, n <= 10^5`
- `2 <= k <= m * n`
- `k * (k-1) <= 10 * m * n`（保证 k 较小）

## 解题思路

曼哈顿距离可以分解为行距离和列距离：`|r1-r2| + |c1-c2|`。

因此，总和 = 行距离总和 + 列距离总和。

**行距离总和**：
固定两行 `r1 < r2`（行差 `d = r2-r1`），放置 k 个棋子时，这两行各有一个棋子的方案数 * 列的搭配数 * d。

**贡献分离**：
对每对格子 `(r1,c1)` 和 `(r2,c2)`，其对行距离的贡献是 `|r1-r2|`，乘以包含这两个格子的方案数（从剩余 mn-2 个格子选 k-2 个）。

总行距离和 = `C(mn-2, k-2) * sum over all pairs (r1,c1),(r2,c2) of |r1-r2|`
           = `C(mn-2, k-2) * n^2 * sum_{d=1}^{m-1} d * (m-d) * 2` ... 不，需要仔细推导。

对 mn 个格子的所有对，`|r_i - r_j|` 的和 = `n^2 * sum_{d=1}^{m-1} d * (m-d)`（每个行差 d 有 n 种列选择给格子1，n 种列选择给格子2）... 需要仔细计算。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def distanceSum(self, m: int, n: int, k: int) -> int:
        MOD = 10**9 + 7

        def modinv(a, mod):
            return pow(a, mod - 2, mod)

        # 预计算阶乘和逆元
        max_n = m * n + 5
        fact = [1] * max_n
        for i in range(1, max_n):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * max_n
        inv_fact[max_n - 1] = modinv(fact[max_n - 1], MOD)
        for i in range(max_n - 2, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        def C(n, r):
            if r < 0 or r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

        mn = m * n

        # 对所有 mn*(mn-1)/2 对格子，计算曼哈顿距离和
        # 分行和列两部分
        # 行距离和：对所有格子对 (i,j),(i',j')，|row_i - row_j|
        # = n^2 * sum_{d=1}^{m-1} d * (m - d)
        # 其中 d 是行差，共有 m-d 对满足行差为 d 的行对，每对有 n*n 个格子对

        row_dist_sum = 0
        for d in range(1, m):
            # 行差为 d 的行对数 = m - d
            # 每对行有 n*n 个格子对
            row_dist_sum = (row_dist_sum + d * (m - d) % MOD * n % MOD * n) % MOD

        # 列距离和：对称
        col_dist_sum = 0
        for d in range(1, n):
            col_dist_sum = (col_dist_sum + d * (n - d) % MOD * m % MOD * m) % MOD

        total_pair_dist = (row_dist_sum + col_dist_sum) % MOD

        # 每对格子被选中的方案数 = C(mn-2, k-2)（从剩余 mn-2 个格子中选 k-2 个）
        ways = C(mn - 2, k - 2)

        return total_pair_dist * ways % MOD
```

### 方法二：分段计算行/列贡献

```python
class Solution:
    def distanceSum(self, m: int, n: int, k: int) -> int:
        MOD = 10**9 + 7

        mn = m * n

        # 计算 1D 距离和函数：对长度为 L 的一维数组，所有对 (i,j) 的 |i-j| 和
        def one_d_dist(L):
            # sum_{d=1}^{L-1} d * (L-d) = sum_{d=1}^{L-1} (d*L - d^2)
            # = L * L*(L-1)/2 - L*(L-1)*(2L-1)/6
            L = L % MOD
            s = L * (L - 1) % MOD * pow(2, MOD - 2, MOD) % MOD  # L*(L-1)/2
            s2 = L * (L - 1) % MOD * (2 * L - 1) % MOD * pow(6, MOD - 2, MOD) % MOD
            return (L * s - s2) % MOD

        # 行距离和 = one_d_dist(m) * n^2（每个行对有 n^2 个格子对）
        row_dist = one_d_dist(m) * n % MOD * n % MOD

        # 列距离和 = one_d_dist(n) * m^2
        col_dist = one_d_dist(n) * m % MOD * m % MOD

        total = (row_dist + col_dist) % MOD

        # 组合数 C(mn-2, k-2)
        max_v = mn + 5
        fact = [1] * max_v
        for i in range(1, max_v):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * max_v
        inv_fact[max_v - 1] = pow(fact[max_v - 1], MOD - 2, MOD)
        for i in range(max_v - 2, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        def C(n, r):
            if r < 0 or r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

        return total * C(mn - 2, k - 2) % MOD
```

## 复杂度分析

- 时间复杂度：O(mn)，预计算阶乘
- 空间复杂度：O(mn)

## 关键点总结

1. 曼哈顿距离分解为行差 + 列差，分别计算
2. 对所有格子对的行距离和 = one_d_dist(m) * n^2
3. 每对格子被 k 个棋子包含的方案数 = C(mn-2, k-2)

## 易错点

1. 公式中 d 从 1 到 m-1（不包含 0）
2. 行差为 d 的行对有 m-d 对，列数 n 对应 n*n 个格子对
3. 所有计算要在模 10^9+7 下进行
