## 题目描述

与 3151 题相同的"特殊"定义：相邻元素奇偶性不同。

给你一个整数数组 `nums` 和一个二维数组 `queries`，`queries[i] = [fromi, toi]`。

对每个查询，返回 `nums[fromi..toi]` 是否为特殊数组。

**示例：**
```
输入：nums = [3,4,1,2,6], queries = [[0,4]]
输出：[false]
解释：[3,4,1,2,6]: (3,4)奇偶不同，(4,1)不同，(1,2)不同，(2,6)同偶，所以 false
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

预处理：对每个下标 i（i >= 1），若 `nums[i]` 和 `nums[i-1]` 奇偶性相同，则记 `bad[i] = 1`（违规位置）；否则 `bad[i] = 0`。

子数组 `[l, r]` 是特殊的当且仅当 `sum(bad[l+1..r]) == 0`。

用前缀和快速查询。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def isArraySpecial(self, nums: List[int], queries: List[List[int]]) -> List[bool]:
        n = len(nums)
        # bad[i] = 1 表示 nums[i] 和 nums[i-1] 奇偶性相同
        prefix = [0] * (n + 1)
        for i in range(1, n):
            prefix[i + 1] = prefix[i] + (1 if nums[i] % 2 == nums[i - 1] % 2 else 0)

        ans = []
        for l, r in queries:
            # 子数组 [l, r] 的违规次数
            bad_count = prefix[r + 1] - prefix[l + 1]
            ans.append(bad_count == 0)
        return ans
```

### 方法二：二分查找

```python
from typing import List
import bisect

class Solution:
    def isArraySpecial(self, nums: List[int], queries: List[List[int]]) -> List[bool]:
        n = len(nums)
        # 记录所有违规位置
        bad = [i for i in range(1, n) if nums[i] % 2 == nums[i - 1] % 2]

        ans = []
        for l, r in queries:
            # 检查 (l+1, r] 范围内是否有违规位置
            idx = bisect.bisect_left(bad, l + 1)
            if idx < len(bad) and bad[idx] <= r:
                ans.append(False)
            else:
                ans.append(True)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n + q)，预处理 O(n)，每次查询 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 预处理违规位置或前缀和
2. 子数组特殊当且仅当范围内无违规位置
3. 前缀和查询 O(1)

## 易错点

1. 前缀和的范围：`[l+1, r]` 而不是 `[l, r]`（相邻对是 (i-1, i)）
2. bad 数组的下标对应两个相邻元素中较大的那个
