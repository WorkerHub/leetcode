## 题目描述

给你一个 `m x n` 的网格 `grid`，网格里面的每个单元都有一个方向标记：
- `1`：向右（移动到 `(i, j+1)`）
- `2`：向左（移动到 `(i, j-1)`）
- `3`：向下（移动到 `(i+1, j)`）
- `4`：向上（移动到 `(i-1, j)`）

一步操作中，你可以将一个单元格的方向改为其他方向（代价为 `1`）；如果按当前方向移动，代价为 `0`。

你从 `(0, 0)` 出发，想要到达 `(m-1, n-1)`。

返回到达目的地的**最小代价**（即修改方向的最少次数）。

**注意：** 每步你都可以走到相邻的单元格，但必须沿着某个方向走（修改后也算）。

**示例 1：**
```
输入：grid = [[1,1,1,1],[2,2,2,2],[1,1,1,1],[2,2,2,2]]
输出：3
```

**示例 2：**
```
输入：grid = [[1,1,3],[3,2,2],[1,1,4]]
输出：0
解释：从 (0,0) 出发：右到(0,1)，右到(0,2)，下到(1,2)，左到(1,1)，左到(1,0)...不对
实际：(0,0)->右->(0,1)->右->(0,2)->下->(1,2)->左->(1,1)->下->(2,1)->右->(2,2)... 不对
看示例：0 means no modification needed.
```

**示例 3：**
```
输入：grid = [[1,2],[4,3]]
输出：1
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 4`

## 解题思路

本题是一个**最短路径问题**，边的权重只有 0 或 1：
- 按当前格子的方向移动：权重 0（免费）
- 改变方向后移动：权重 1（付费）

对于边权只有 0/1 的最短路问题，最优算法是 **0-1 BFS（使用双端队列）**，时间复杂度 O(m*n)，比 Dijkstra 的 O(m*n*log(m*n)) 更高效。

**0-1 BFS 算法：**

使用 `deque`（双端队列）代替普通队列：
- 代价为 0 的边（同方向移动）：将新节点加入队列**头部**（`appendleft`）
- 代价为 1 的边（改方向移动）：将新节点加入队列**尾部**（`append`）

这样队列始终按代价从小到大排列，保证每个节点第一次被访问时就是最小代价，类似于 BFS 处理 0-1 权重图的优化 Dijkstra。

**另一种思路：** Dijkstra + 优先队列（适合权重更通用的情况）。

## Python 代码实现

### 方法一：0-1 BFS（双端队列，推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 方向映射：方向标记 -> (行偏移, 列偏移)
        # 1=右, 2=左, 3=下, 4=上
        DIRS = {1: (0, 1), 2: (0, -1), 3: (1, 0), 4: (-1, 0)}
        ALL_DIRS = [(0, 1), (0, -1), (1, 0), (-1, 0)]  # 右、左、下、上
        
        # dist[i][j] = 从 (0,0) 到 (i,j) 的最小代价
        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        
        # 双端队列，存储 (代价, 行, 列)
        dq = deque([(0, 0, 0)])
        
        while dq:
            cost, r, c = dq.popleft()
            
            # 如果当前代价已经不是最优，跳过（延迟删除）
            if cost > dist[r][c]:
                continue
            
            # 遍历四个方向
            for d, (dr, dc) in enumerate(ALL_DIRS, 1):  # d: 1~4
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 判断是否需要修改方向
                    move_cost = 0 if grid[r][c] == d else 1
                    new_cost = cost + move_cost
                    if new_cost < dist[nr][nc]:
                        dist[nr][nc] = new_cost
                        if move_cost == 0:
                            dq.appendleft((new_cost, nr, nc))  # 免费移动，加头部
                        else:
                            dq.append((new_cost, nr, nc))      # 付费移动，加尾部
        
        return dist[m-1][n-1]
```

### 方法二：Dijkstra（优先队列）

```python
from typing import List
import heapq

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 四个方向：右(1)、左(2)、下(3)、上(4)
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        # 优先队列：(代价, 行, 列)
        heap = [(0, 0, 0)]
        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        
        while heap:
            cost, r, c = heapq.heappop(heap)
            
            if cost > dist[r][c]:
                continue
            
            if r == m - 1 and c == n - 1:
                return cost  # 提前返回
            
            for d, (dr, dc) in enumerate(dirs, 1):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 当前格子方向与移动方向一致则免费
                    move_cost = 0 if grid[r][c] == d else 1
                    new_cost = cost + move_cost
                    if new_cost < dist[nr][nc]:
                        dist[nr][nc] = new_cost
                        heapq.heappush(heap, (new_cost, nr, nc))
        
        return dist[m-1][n-1]
```

### 方法三：BFS 分层（按代价分层）

```python
from typing import List
from collections import deque

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]  # 右、左、下、上（对应 1,2,3,4）
        
        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        
        # 当前代价为 0 的节点集合（逐步扩展）
        # 先把所有代价 0 可达的节点用 BFS 扩展
        # 再将代价 1 可达的节点作为下一轮的起点
        
        current = deque([(0, 0)])
        cost = 0
        
        while current:
            next_level = []
            
            # 扩展所有当前代价为 cost 的节点（代价 0 的边）
            while current:
                r, c = current.popleft()
                
                if dist[r][c] < cost:
                    continue
                
                # 方向 d 对应 dirs[d-1]
                d = grid[r][c]
                dr, dc = dirs[d - 1]
                nr, nc = r + dr, c + dc
                
                if 0 <= nr < m and 0 <= nc < n and dist[nr][nc] > cost:
                    dist[nr][nc] = cost
                    current.append((nr, nc))  # 免费，继续本层
            
            # 将代价 cost+1 可达的节点（改方向）加入下一层
            for r in range(m):
                for c in range(n):
                    if dist[r][c] == cost:
                        for dd, (dr, dc) in enumerate(dirs, 1):
                            nr, nc = r + dr, c + dc
                            if 0 <= nr < m and 0 <= nc < n and dist[nr][nc] == float('inf'):
                                if grid[r][c] != dd:  # 需要改方向
                                    dist[nr][nc] = cost + 1
                                    next_level.append((nr, nc))
            
            cost += 1
            current = deque(next_level)
        
        return dist[m-1][n-1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 0-1 BFS | O(m*n) | O(m*n) |
| Dijkstra | O(m*n*log(m*n)) | O(m*n) |
| BFS 分层 | O(m*n) | O(m*n) |

## 算法对比：0-1 BFS vs Dijkstra

0-1 BFS 是专门针对边权只有 0 或 1 的最短路优化：
- 代价 0 的边：新节点放队头（优先级最高，立即处理）
- 代价 1 的边：新节点放队尾（下一批处理）

这保证了队列头部的代价始终 <= 队列尾部，类似于 Dijkstra 的效果，但避免了堆操作的 O(log N) 开销。

## 关键点总结

1. **0-1 BFS 适用场景**：边权只有 0 或 1 时，用双端队列实现 O(V+E) 的最短路。
2. **代价判断**：`grid[r][c]` 是当前格子的方向标记（1~4），与移动方向（对应 dirs[d-1]）一致则代价 0，否则代价 1。
3. **双端队列规则**：代价 0 加队头，代价 1 加队尾，保证队列头部代价始终最小。
4. **延迟删除**：从队列取出时检查 `cost > dist[r][c]`，跳过过时的节点。
5. **方向编码**：dirs 列表中索引 0~3 对应方向标记 1~4（右、左、下、上），用 `enumerate(dirs, 1)` 从 1 开始。

## 易错点

- 方向标记与索引的对应：题目中 1=右, 2=左, 3=下, 4=上，`dirs[0]=(0,1)=右`，注意一一对应。
- 0-1 BFS 中 `appendleft` 和 `append` 的正确使用：代价 0 用 `appendleft`（加队头），代价 1 用 `append`（加队尾）。
- 需要用 `dist` 数组记录最短距离，避免重复处理同一节点（通过 `cost > dist[r][c]` 跳过过时节点）。
