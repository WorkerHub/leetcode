## 题目描述

给定一个区间的集合 `intervals`，其中 `intervals[i] = [starti, endi]`。返回需要移除区间的最小数量，使剩余区间互不重叠。

**示例 1：**
```
输入：intervals = [[1,2],[2,3],[3,4],[1,3]]
输出：1
解释：移除 [1,3] 后，剩下的区间没有重叠。
```

**示例 2：**
```
输入：intervals = [[1,2],[1,2],[1,2]]
输出：2
解释：你需要移除两个 [1,2] 来使剩下的区间没有重叠。
```

**示例 3：**
```
输入：intervals = [[1,2],[2,3]]
输出：0
解释：你不需要移除任何区间，因为它们已经是无重叠的了。
```

**提示：**
- `1 <= intervals.length <= 10^5`
- `intervals[i].length == 2`
- `-5 * 10^4 <= starti < endi <= 5 * 10^4`

## 解题思路

这道题要求移除最少的区间使剩余区间不重叠。核心思想是贪心算法。

**关键观察：**
1. 移除最少的区间 = 保留最多的不重叠区间
2. 按结束时间排序，贪心地选择结束最早的区间
3. 类似于活动选择问题

**算法流程（贪心）：**
1. 按区间结束时间升序排序
2. 遍历排序后的区间：
   - 如果当前区间与前一个保留的区间不重叠，保留它
   - 否则，跳过（移除）当前区间
3. 总区间数 - 保留的区间数 = 需要移除的区间数

**为什么按结束时间排序？**
- 结束越早的区间，为后续区间留下的空间越大
- 这样能保留更多的区间

## Python 代码实现

### 方法一：贪心（按结束时间排序）⭐ 推荐

```python
from typing import List

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        
        # 按结束时间升序排序
        intervals.sort(key=lambda x: x[1])
        
        # 保留的区间数
        count = 1
        end = intervals[0][1]
        
        for i in range(1, len(intervals)):
            # 如果不重叠，保留当前区间
            if intervals[i][0] >= end:
                count += 1
                end = intervals[i][1]
            # 否则，跳过（移除）当前区间
        
        # 需要移除的区间数
        return len(intervals) - count
```

### 方法二：贪心（按开始时间排序）

```python
from typing import List

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        
        # 按开始时间升序排序，结束时间降序排序
        intervals.sort(key=lambda x: (x[0], -x[1]))
        
        removed = 0
        end = intervals[0][1]
        
        for i in range(1, len(intervals)):
            if intervals[i][0] < end:
                # 重叠，移除结束时间较晚的
                removed += 1
                end = min(end, intervals[i][1])
            else:
                # 不重叠，更新结束时间
                end = intervals[i][1]
        
        return removed
```

### 方法三：动态规划（了解即可）

```python
from typing import List

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        
        # 按开始时间排序
        intervals.sort()
        n = len(intervals)
        
        # dp[i] 表示以第 i 个区间结尾的最长不重叠子序列长度
        dp = [1] * n
        
        for i in range(1, n):
            for j in range(i):
                # 如果区间 j 和区间 i 不重叠
                if intervals[j][1] <= intervals[i][0]:
                    dp[i] = max(dp[i], dp[j] + 1)
        
        # 最多保留的区间数
        max_keep = max(dp)
        return n - max_keep
```

## 复杂度分析

**方法一：贪心（按结束时间）**
- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(log n)，排序的栈空间

**方法二：贪心（按开始时间）**
- 时间复杂度：O(n log n)
- 空间复杂度：O(log n)

**方法三：动态规划**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 关键点总结

1. **贪心策略**：按结束时间排序，优先选择结束早的区间
2. **重叠判断**：`start < end` 表示重叠
3. **转化思路**：移除最少 = 保留最多
4. **活动选择**：这是经典的活动选择问题
5. **排序选择**：按结束时间排序是最优策略

## 易错点

1. **重叠定义**：`[1,2]` 和 `[2,3]` 不重叠（边界相等不算重叠）
2. **排序关键字**：按结束时间排序，不是开始时间
3. **比较条件**：`intervals[i][0] >= end` 表示不重叠
4. **计数方式**：可以统计保留的，也可以统计移除的
5. **空数组**：空数组返回 0
