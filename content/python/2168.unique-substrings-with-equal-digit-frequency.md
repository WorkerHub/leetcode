## 题目描述

给你一个数字字符串 `s`，返回 `s` 中所有**每个数字出现频率相同**的子字符串的不同数量。

**示例：**
```
输入：s = "1212"
输出：5
解释：满足条件的不同子字符串：
- "1"，"2"，"12"，"21"，"1212"（每个数字出现次数相同）
- "11"，"22"，"12"，"21" 中频率相同的：
  "1"(1次)，"2"(1次)，"12"(各1次)，"21"(各1次)，"1212"(各2次)
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 仅含数字字符（`'0'` 到 `'9'`）

## 解题思路

**暴力枚举 + 哈希集合去重**

枚举所有子串，判断每个子串中每个数字的出现频率是否相等（所有出现过的数字频率相同），用集合去重。

n <= 1000，O(n^2) 个子串，每个 O(n) 判断，总体 O(n^3)，但 n = 1000 时 10^9 可能超时，可以用滚动哈希优化或优化判断。

## 代码实现

### 方法一：暴力枚举（推荐新手）

```python
from collections import Counter

class Solution:
    def equalDigitFrequency(self, s: str) -> int:
        seen = set()
        n = len(s)
        for i in range(n):
            for j in range(i + 1, n + 1):
                substr = s[i:j]
                cnt = Counter(substr)
                # 判断所有数字出现频率相同
                freq_vals = set(cnt.values())
                if len(freq_vals) == 1:
                    seen.add(substr)
        return len(seen)
```

### 方法二：滚动哈希去重

```python
from collections import Counter

class Solution:
    def equalDigitFrequency(self, s: str) -> int:
        MOD = (1 << 61) - 1
        BASE = 131
        seen = set()
        n = len(s)
        
        for i in range(n):
            cnt = [0] * 10
            h = 0
            unique_cnt = 0
            for j in range(i, n):
                d = int(s[j])
                if cnt[d] == 0:
                    unique_cnt += 1
                cnt[d] += 1
                h = (h * BASE + d + 1) % MOD
                
                # 判断所有出现的数字频率是否相同
                # 最大频率 * 不同数字数 == 子串长度
                max_freq = max(cnt[k] for k in range(10) if cnt[k] > 0)
                length = j - i + 1
                if max_freq * unique_cnt == length:
                    seen.add(h)
        
        return len(seen)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力 | O(n^3) | O(n^2) |
| 滚动哈希 | O(n^2) | O(n^2) |

## 关键点总结

1. 判断频率相等：`max_freq * unique_digit_count == length`（所有出现数字频率相同的充要条件）。
2. 用滚动哈希代替字符串作为集合元素，避免字符串哈希的 O(n) 代价。
3. 注意哈希碰撞（概率极低，竞赛中可接受）。

## 易错点

- 频率相等不等于所有数字都出现，只是出现的数字频率相同。
- 用字符串直接存入集合时，Python 自动处理哈希，但速度稍慢。
