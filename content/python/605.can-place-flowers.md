## 题目描述

假设有一个很长的花坛，一部分地块种植了花，另一部分却没有。可是，花不能种植在相邻的地块上，它们会争夺水源，两者都会死去。

给你一个整数数组 `flowerbed` 表示花坛，由若干 0 和 1 组成，其中 0 表示没种植花，1 表示种植了花。另有一个数 `n`，能否在不打破种植规则的情况下种入 `n` 朵花？能则返回 `true`，不能则返回 `false`。

**示例 1：**

```
输入：flowerbed = [1,0,0,0,1], n = 1
输出：true
```

**示例 2：**

```
输入：flowerbed = [1,0,0,0,1], n = 2
输出：false
```

**提示：**

- `1 <= flowerbed.length <= 2 * 10^4`
- `flowerbed[i]` 为 0 或 1
- `flowerbed` 中不存在相邻的两朵花
- `0 <= n <= flowerbed.length`

## 解题思路

这是一道经典的**贪心算法**题目。核心思想是：尽可能多地种植花朵，然后判断能否达到 n。

**种植规则：**
- 当前位置为 0（未种花）
- 前一个位置为 0 或不存在（边界）
- 后一个位置为 0 或不存在（边界）

**贪心策略：**
从左到右遍历，只要满足条件就立即种植，这样可以为后面留出更多空间。

**关键观察：**
- 位置 i 可以种花的条件：`flowerbed[i] == 0 && (i == 0 || flowerbed[i-1] == 0) && (i == len-1 || flowerbed[i+1] == 0)`
- 种植后需要将 `flowerbed[i]` 标记为 1，防止下一个位置违反规则

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        """
        贪心算法：从左到右尽可能多地种花
        
        时间复杂度：O(n)，n 为数组长度
        空间复杂度：O(1)
        """
        count = 0  # 记录能种植的花朵数量
        length = len(flowerbed)
        
        for i in range(length):
            # 检查当前位置是否可以种花
            if flowerbed[i] == 0:
                # 检查前一个位置（边界或为0）
                prev_empty = (i == 0) or (flowerbed[i - 1] == 0)
                # 检查后一个位置（边界或为0）
                next_empty = (i == length - 1) or (flowerbed[i + 1] == 0)
                
                if prev_empty and next_empty:
                    # 种植花朵
                    flowerbed[i] = 1
                    count += 1
                    
                    # 提前返回优化
                    if count >= n:
                        return True
        
        return count >= n
```

### 方法二：简化版（不修改原数组）

```python
class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        """
        不修改原数组的版本
        """
        count = 0
        length = len(flowerbed)
        # 复制数组避免修改原数组
        bed = flowerbed[:]
        
        for i in range(length):
            if bed[i] == 0:
                # 使用 get 方法简化边界判断
                if (i == 0 or bed[i-1] == 0) and \
                   (i == length - 1 or bed[i+1] == 0):
                    bed[i] = 1
                    count += 1
                    if count >= n:
                        return True
        
        return count >= n
```

### 方法三：一行流（Python 特色）

```python
class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        """
        技巧：在数组两端添加虚拟的0，简化边界判断
        """
        # 前后各加一个0，避免边界判断
        bed = [0] + flowerbed + [0]
        
        for i in range(1, len(bed) - 1):
            if bed[i-1] == bed[i] == bed[i+1] == 0:
                bed[i] = 1
                n -= 1
        
        return n <= 0
```

### 方法四：跳跃优化

```python
class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        """
        优化：种植后可以跳过下一个位置（因为不能相邻）
        """
        count = 0
        i = 0
        length = len(flowerbed)
        
        while i < length:
            if flowerbed[i] == 0 and \
               (i == 0 or flowerbed[i-1] == 0) and \
               (i == length - 1 or flowerbed[i+1] == 0):
                flowerbed[i] = 1
                count += 1
                i += 2  # 跳过下一个位置
                if count >= n:
                    return True
            else:
                i += 1
        
        return count >= n
```

## 复杂度分析

### 方法一、二、三
- **时间复杂度**：O(m)，m 为数组长度，需要遍历一遍数组
- **空间复杂度**：O(1)（方法一）或 O(m)（方法二、三复制数组）

### 方法四（跳跃优化）
- **时间复杂度**：O(m)，最坏情况仍需遍历整个数组，但平均情况下更快
- **空间复杂度**：O(1)


## 关键点总结

1. **贪心思想**：从左到右尽可能多地种花，不会错过更优解
2. **边界处理**：第一个和最后一个位置只需检查一侧
3. **状态更新**：种植后立即更新数组，防止影响后续判断
4. **提前返回**：一旦 count >= n 就可以返回 true
5. **跳跃优化**：种植后下一个位置必然不能种，可以直接跳过

## 易错点

1. **边界条件处理不当**：
   ```python
   # ❌ 错误：没有处理数组边界
   if flowerbed[i-1] == 0 and flowerbed[i+1] == 0:
       # 当 i=0 或 i=length-1 时会越界
   ```

2. **忘记更新数组**：
   ```python
   # ❌ 错误：没有标记种植
   if prev_empty and next_empty:
       count += 1
       # flowerbed[i] = 1  # 必须加这行！
   ```
   不更新会导致相邻位置也被判断为可种植

3. **判断顺序错误**：
   ```python
   # ❌ 错误：先检查相邻再检查当前
   if (i == 0 or flowerbed[i-1] == 0):  # 当前位置可能是1
   ```
   应该先确保 `flowerbed[i] == 0`

4. **返回条件错误**：
   ```python
   # ❌ 错误：返回 count == n
   return count == n  # 应该是 count >= n
   ```

## 学习建议

**新手学习路径：**

1. **理解贪心算法**：
   - 贪心：每一步做出当前最优选择
   - 本题：能种就种，不会错过更好的方案
   - 证明：种植在位置 i 不会影响 i-2 及之前的位置，只可能影响 i+1

2. **边界处理技巧**：
   - 方法一：使用布尔表达式 `(i == 0) or (flowerbed[i-1] == 0)`
   - 方法三：在两端添加虚拟元素，统一处理逻辑

3. **循序渐进**：
   - 第一步：写出暴力检查（不考虑优化）
   - 第二步：添加提前返回优化
   - 第三步：尝试跳跃优化

4. **推荐方法**：
   - 初学者：方法一，逻辑清晰
   - 追求简洁：方法三，代码优雅
   - 追求性能：方法四，跳跃优化

5. **测试用例**：
   ```python
   # 边界情况
   [0], n=1          # 单个元素
   [1], n=0          # 已有花
   [0,0,0], n=2      # 全空
   [1,0,1], n=1      # 无法种植
   [0,0,1,0,0], n=2  # 正好可以种2朵
   ```

**实战技巧：**
- 贪心算法的关键是证明局部最优能导致全局最优
- 遇到"相邻限制"问题，优先考虑贪心
- 修改原数组前，考虑是否需要保留原始数据
- 适当的跳跃可以优化性能，但要保证正确性
