## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。

如果从数组中删除**最多** `k` 个元素后，剩余数组中存在一个全由**相同元素**组成的子数组（连续），返回这个子数组的最大可能长度。

**示例 1：**
```
输入：nums = [3,3,3,3,7,3,3], k = 2
输出：6
解释：删除下标 4 的 7（1个），剩余 [3,3,3,3,3,3]，长度 6（>=2-1）
```

**示例 2：**
```
输入：nums = [1,3,2,3,1,3], k = 3
输出：3
解释：删除下标 0,2,4 的元素，剩余 [3,3,3]，长度 3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= nums.length`
- `0 <= k <= nums.length`

## 解题思路

**滑动窗口 + 哈希表：**

对于每种值 `v`，维护一个滑动窗口，窗口内的非 `v` 元素数量 <= k。

- 用哈希表记录每个值出现的下标列表
- 对每种值，用双指针维护窗口：`[i, j]` 表示 v 的出现位置的区间
  - 窗口内 v 出现 `j - i + 1` 次，窗口总长度 = `pos[j] - pos[i] + 1`
  - 需要删除 `(pos[j] - pos[i] + 1) - (j - i + 1)` 个元素（非 v 的）
  - 如果 <= k，则窗口合法，答案候选 = j - i + 1

## Python 代码实现

### 方法一：哈希表 + 滑动窗口（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def longestEqualSubarray(self, nums: List[int], k: int) -> int:
        # 记录每个值出现的位置列表
        positions = defaultdict(list)
        for i, v in enumerate(nums):
            positions[v].append(i)

        ans = 1
        for v, pos in positions.items():
            m = len(pos)
            left = 0
            for right in range(m):
                # 窗口内 v 的数量：right - left + 1
                # 窗口总长度：pos[right] - pos[left] + 1
                # 需要删除的元素数：总长度 - v 的数量
                while pos[right] - pos[left] + 1 - (right - left + 1) > k:
                    left += 1
                ans = max(ans, right - left + 1)

        return ans
```

### 方法二：二分查找版

```python
from collections import defaultdict
import bisect
from typing import List

class Solution:
    def longestEqualSubarray(self, nums: List[int], k: int) -> int:
        positions = defaultdict(list)
        for i, v in enumerate(nums):
            positions[v].append(i)

        ans = 0
        for v, pos in positions.items():
            # 对每个右端点 j（pos 数组中的下标），二分找最左 i
            # 满足 pos[j] - pos[i] - (j - i) <= k
            # 即 pos[j] - pos[i] <= k + j - i
            for j in range(len(pos)):
                # 需要：pos[j] - pos[i] + 1 - (j - i + 1) <= k
                # 即：pos[j] - pos[i] - j + i <= k
                # 变形：(pos[j] - j) - (pos[i] - i) <= k
                # 找最左满足条件的 i
                target = (pos[j] - j) - k  # pos[i] - i >= target
                # 二分查找
                arr = [pos[x] - x for x in range(j + 1)]
                idx = bisect.bisect_left(arr, target)
                ans = max(ans, j - idx + 1)

        return ans
```

## 复杂度分析

- 方法一：时间 O(n)，空间 O(n)（每个元素最多进出窗口一次）
- 方法二：时间 O(n log n)，空间 O(n)

## 关键点总结

1. 针对每个值分别用滑动窗口，利用该值的位置列表
2. 窗口合法条件：需删除的元素数 = 窗口长度 - 值出现次数 <= k
3. 双指针：left 随 right 增大而可能右移

## 易错点

1. "窗口"是在原数组中连续的范围，不是 positions 数组中的连续范围
2. 需删除的元素 = `(pos[right] - pos[left] + 1) - (right - left + 1)`（原数组窗口长度 - v 的个数）
3. 初始 ans = 1 是因为任意单个元素就满足
