## 题目描述

给定一个整数数组 `nums`。对于每个下标 `i`，若 `nums[i]` 的各位数字之和等于 `i`，则称下标 `i` 为"特殊下标"。返回最小的特殊下标，若不存在则返回 `-1`。

**示例 1：**

```
输入：nums = [1, 3, 2, 4, 5]
输出：3
解释：i=3 时，nums[3]=4，4的各位数字和=4=3？不对，4≠3。
     i=0: sum(1)=1≠0，i=1: sum(3)=3≠1，i=2: sum(2)=2=2，返回2。
```

**示例 2：**

```
输入：nums = [1, 10, 11]
输出：1
解释：i=1: sum(10)=1+0=1=1，返回1。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^9`

## 解题思路

遍历数组，对每个下标 `i` 计算 `nums[i]` 的各位数字之和，若等于 `i` 则返回 `i`。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        for i, x in enumerate(nums):
            # 计算 x 的各位数字之和
            digit_sum = sum(int(d) for d in str(x))
            if digit_sum == i:
                return i
        return -1
```

### 方法二：数学计算各位和

```python
from typing import List

class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        def digit_sum(x):
            s = 0
            while x > 0:
                s += x % 10
                x //= 10
            return s

        for i, x in enumerate(nums):
            if digit_sum(x) == i:
                return i
        return -1
```

## 复杂度分析

- 时间复杂度：O(n * log10(max_val))，遍历数组并计算各位和
- 空间复杂度：O(1)

## 关键点总结

1. 各位数字之和：将数字转为字符串后逐位求和，或用取模运算
2. 找最小满足条件的索引：从左到右遍历，第一个满足的即为答案
3. 没有满足条件的索引则返回 -1

## 易错点

1. 各位数字之和是 `nums[i]` 的数字和，不是 `i` 的数字和
2. 注意下标从 0 开始，`i=0` 时需要 `nums[0]` 的数字和为 0（只有 nums[0]=0 时满足，但题目说 nums[i]>=1）
3. 遍历顺序从小到大，第一个满足的下标就是最小特殊下标
