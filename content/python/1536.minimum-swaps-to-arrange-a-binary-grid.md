## 题目描述

给你一个 `n x n` 的二进制网格 `grid`，每次操作可以选择两个**相邻行**并交换。

目标：使网格满足——对角线及以上全为 1，对角线以下全为 0（即上三角矩阵形式），具体是第 `i` 行末尾至少有 `n-1-i` 个 0。

返回最少交换次数，如果无法完成返回 -1。

**示例 1：**
```
输入：grid = [[0,0,1],[1,1,0],[1,0,0]]
输出：3
```

## 解题思路

### 贪心：统计每行末尾 0 的数量

第 `i` 行（0-indexed）需要末尾至少 `n-1-i` 个 0。

1. 预处理每行末尾连续 0 的数量 `tail_zeros[i]`
2. 对每行 `i`，从 `i` 往下找第一行满足 `tail_zeros[j] >= n-1-i` 的行 `j`
3. 将第 `j` 行交换到第 `i` 行（需要 `j-i` 次相邻交换）
4. 更新 `tail_zeros` 数组

## 代码实现

### 方法一：贪心模拟（推荐）

```python
from typing import List

class Solution:
    def minSwaps(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # 计算每行末尾连续 0 的数量
        tail_zeros = []
        for row in grid:
            count = 0
            for j in range(n - 1, -1, -1):
                if row[j] == 0:
                    count += 1
                else:
                    break
            tail_zeros.append(count)

        total_swaps = 0
        for i in range(n):
            need = n - 1 - i  # 第 i 行需要末尾至少 need 个 0
            if need == 0:
                continue  # 最后一行无需求
            # 找从 i 往下第一个满足条件的行
            found = -1
            for j in range(i, n):
                if tail_zeros[j] >= need:
                    found = j
                    break
            if found == -1:
                return -1  # 无法满足
            # 将 found 行交换到 i 行
            total_swaps += found - i
            # 更新 tail_zeros（冒泡到位）
            tail_zeros.pop(found)
            tail_zeros.insert(i, n - 1 - i)  # 占位，值不影响后续（已满足）

        return total_swaps
```

### 方法二：更清晰的写法

```python
from typing import List

class Solution:
    def minSwaps(self, grid: List[List[int]]) -> int:
        n = len(grid)

        def count_trailing_zeros(row):
            cnt = 0
            for j in range(n - 1, -1, -1):
                if row[j] == 0:
                    cnt += 1
                else:
                    break
            return cnt

        zeros = [count_trailing_zeros(row) for row in grid]
        ans = 0

        for i in range(n):
            need = n - 1 - i
            # 找满足条件的最近行
            pos = -1
            for j in range(i, n):
                if zeros[j] >= need:
                    pos = j
                    break
            if pos == -1:
                return -1
            # 把 pos 行移到 i 行：连续的相邻交换
            ans += pos - i
            # 模拟交换（向上冒泡）
            for j in range(pos, i, -1):
                zeros[j] = zeros[j - 1]
            zeros[i] = need

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N^2)，外层 N 行，内层最多 N 次查找
- **空间复杂度**：O(N)

## 关键点总结

1. 第 `i` 行需要末尾至少 `n-1-i` 个 0（第 0 行需要 n-1 个，最后一行需要 0 个）
2. 贪心：对每行，找最近的满足条件的行，将其冒泡到当前位置
3. 无法找到则返回 -1

## 易错点

- 不是任意交换，只能交换**相邻行**
- 把找到的行移到目标位置需要连续相邻交换，次数 = `j - i`
