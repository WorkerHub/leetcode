## 题目描述

给你一个长度 >= 3 的整数数组 `nums`，数组中所有元素互不相同。

按以下规则将 `nums` 的元素分配到两个数组 `arr1` 和 `arr2` 中：

1. `arr1` 和 `arr2` 都从 `nums[0]` 和 `nums[1]` 各选一个开始（`arr1` 得 `nums[0]`，`arr2` 得 `nums[1]`）
2. 从 `nums[2]` 开始，对每个 `nums[i]`：
   - 若 `arr1` 的最后一个元素 > `arr2` 的最后一个元素，将 `nums[i]` 追加到 `arr1`
   - 否则追加到 `arr2`
3. 返回 `arr1 + arr2`（合并后的数组）

**示例：**
```
输入：nums = [2,1,3]
输出：[2,3,1]
```

**提示：**
- `3 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `nums` 中所有元素互不相同

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        arr1 = [nums[0]]
        arr2 = [nums[1]]

        for i in range(2, len(nums)):
            if arr1[-1] > arr2[-1]:
                arr1.append(nums[i])
            else:
                arr2.append(nums[i])

        return arr1 + arr2
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 按规则逐一将元素分配到 arr1 或 arr2
2. 比较两数组的最后一个元素决定分配方向

## 易错点

1. 初始化时 `arr1 = [nums[0]]`，`arr2 = [nums[1]]`，从 `nums[2]` 开始处理
2. 题目保证所有元素互不相同，不会有相等情况（`arr1[-1] > arr2[-1]` 和 `else` 的边界）
