## 题目描述

给定一个整数 `n`，请你计算有多少个长度为 `n` 的字符串可以被形成，需要满足以下规则：

**规则：**

- 字符串中的每个字符都是小写元音字母（'a', 'e', 'i', 'o', 'u'）
- 每个元音 `'a'` 后面只能跟着 `'e'`
- 每个元音 `'e'` 后面只能跟着 `'a'` 或 `'i'`
- 每个元音 `'i'` 后面**不能**再跟着另一个 `'i'`
- 每个元音 `'o'` 后面只能跟着 `'i'` 或 `'u'`
- 每个元音 `'u'` 后面只能跟着 `'a'`

由于答案可能会很大，请返回结果对 `10^9 + 7` 取模后的值。

**示例 1：**

```
输入：n = 1
输出：5
解释：所有可能的字符串是："a", "e", "i", "o", "u"。
```

**示例 2：**

```
输入：n = 2
输出：10
解释：所有可能的字符串是："ae", "ea", "ei", "ia", "ie", "io", "iu", "oi", "ou", "ua"。
```

**示例 3：**

```
输入：n = 5
输出：68
```

**提示：**

- `1 <= n <= 2 * 10^4`

## 解题思路

这是一道经典的**动态规划**问题，关键在于理清状态转移关系。

**核心思想：**

1. 定义状态：`dp[i][j]` 表示长度为 `i` 且以第 `j` 个元音结尾的字符串数量
2. 根据规则建立状态转移方程
3. 最终答案是长度为 `n` 时所有元音结尾的字符串数量之和

**状态转移分析：**

根据题目规则，建立转移关系（用 0-4 分别代表 a, e, i, o, u）：

- 以 `a` 结尾的字符串：前一个字符可以是 `e`, `i`, `u`
  - `dp[i][0] = dp[i-1][1] + dp[i-1][2] + dp[i-1][4]`

- 以 `e` 结尾的字符串：前一个字符可以是 `a`, `i`
  - `dp[i][1] = dp[i-1][0] + dp[i-1][2]`

- 以 `i` 结尾的字符串：前一个字符可以是 `e`, `o`
  - `dp[i][2] = dp[i-1][1] + dp[i-1][3]`

- 以 `o` 结尾的字符串：前一个字符只能是 `i`
  - `dp[i][3] = dp[i-1][2]`

- 以 `u` 结尾的字符串：前一个字符可以是 `i`, `o`
  - `dp[i][4] = dp[i-1][2] + dp[i-1][3]`

**初始状态：**

- `dp[1][0] = dp[1][1] = dp[1][2] = dp[1][3] = dp[1][4] = 1`

## Python 代码实现

### 方法一：动态规划（二维数组）⭐

```python
class Solution:
    def countVowelPermutation(self, n: int) -> int:
        """
        二维 DP 解法
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        MOD = 10**9 + 7
        
        # dp[i][j] 表示长度为 i，以第 j 个元音结尾的字符串数量
        # j: 0=a, 1=e, 2=i, 3=o, 4=u
        dp = [[0] * 5 for _ in range(n + 1)]
        
        # 初始化：长度为 1 时，每个元音都可以作为起始
        for j in range(5):
            dp[1][j] = 1
        
        # 状态转移
        for i in range(2, n + 1):
            # a 可以由 e, i, u 转移而来
            dp[i][0] = (dp[i-1][1] + dp[i-1][2] + dp[i-1][4]) % MOD
            
            # e 可以由 a, i 转移而来
            dp[i][1] = (dp[i-1][0] + dp[i-1][2]) % MOD
            
            # i 可以由 e, o 转移而来
            dp[i][2] = (dp[i-1][1] + dp[i-1][3]) % MOD
            
            # o 只能由 i 转移而来
            dp[i][3] = dp[i-1][2]
            
            # u 可以由 i, o 转移而来
            dp[i][4] = (dp[i-1][2] + dp[i-1][3]) % MOD
        
        # 返回所有以不同元音结尾的字符串数量之和
        return sum(dp[n]) % MOD
```

### 方法二：动态规划（空间优化）⭐

```python
class Solution:
    def countVowelPermutation(self, n: int) -> int:
        """
        空间优化版本：只需要保存前一个状态
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        MOD = 10**9 + 7
        
        # 当前长度以各元音结尾的字符串数量
        a, e, i, o, u = 1, 1, 1, 1, 1
        
        for _ in range(2, n + 1):
            # 计算新的状态（注意要用临时变量保存）
            new_a = (e + i + u) % MOD
            new_e = (a + i) % MOD
            new_i = (e + o) % MOD
            new_o = i
            new_u = (i + o) % MOD
            
            # 更新状态
            a, e, i, o, u = new_a, new_e, new_i, new_o, new_u
        
        return (a + e + i + o + u) % MOD
```

### 方法三：矩阵快速幂（高级优化）

```python
from typing import List

class Solution:
    def countVowelPermutation(self, n: int) -> int:
        """
        矩阵快速幂解法，适用于 n 非常大的情况
        
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        MOD = 10**9 + 7
        
        # 转移矩阵：matrix[i][j] = 1 表示 j 可以转移到 i
        # 行：下一个字符（a, e, i, o, u）
        # 列：当前字符（a, e, i, o, u）
        transition = [
            [0, 1, 1, 0, 1],  # a 可以由 e, i, u 转移
            [1, 0, 1, 0, 0],  # e 可以由 a, i 转移
            [0, 1, 0, 1, 0],  # i 可以由 e, o 转移
            [0, 0, 1, 0, 0],  # o 可以由 i 转移
            [0, 0, 1, 1, 0],  # u 可以由 i, o 转移
        ]
        
        def matrix_multiply(A: List[List[int]], B: List[List[int]]) -> List[List[int]]:
            """矩阵乘法"""
            size = len(A)
            result = [[0] * size for _ in range(size)]
            for i in range(size):
                for j in range(size):
                    for k in range(size):
                        result[i][j] += A[i][k] * B[k][j]
                        result[i][j] %= MOD
            return result
        
        def matrix_power(matrix: List[List[int]], power: int) -> List[List[int]]:
            """矩阵快速幂"""
            size = len(matrix)
            # 初始化为单位矩阵
            result = [[1 if i == j else 0 for j in range(size)] for i in range(size)]
            base = [row[:] for row in matrix]  # 复制矩阵
            
            while power > 0:
                if power & 1:
                    result = matrix_multiply(result, base)
                base = matrix_multiply(base, base)
                power >>= 1
            
            return result
        
        if n == 1:
            return 5
        
        # 计算转移矩阵的 n-1 次幂
        result_matrix = matrix_power(transition, n - 1)
        
        # 初始状态：每个元音都是 1
        # 最终答案是结果矩阵每一行的和（相当于从每个起点开始）
        total = 0
        for i in range(5):
            for j in range(5):
                total += result_matrix[i][j]
                total %= MOD
        
        return total
```

### 方法四：详细注释版（新手友好）

```python
class Solution:
    def countVowelPermutation(self, n: int) -> int:
        """
        动态规划详细解释版
        """
        MOD = 10**9 + 7
        
        # 用字典表示元音，方便理解
        # 当前长度以各元音结尾的字符串数量
        count = {
            'a': 1,
            'e': 1,
            'i': 1,
            'o': 1,
            'u': 1
        }
        
        # 从长度 2 开始计算到长度 n
        for length in range(2, n + 1):
            # 创建新的计数字典
            new_count = {
                'a': 0,
                'e': 0,
                'i': 0,
                'o': 0,
                'u': 0
            }
            
            # 根据规则计算新的计数
            # 规则1：a 后面只能跟 e
            # 反向理解：e 前面可以是 a
            new_count['e'] += count['a']
            
            # 规则2：e 后面可以跟 a 或 i
            new_count['a'] += count['e']
            new_count['i'] += count['e']
            
            # 规则3：i 后面不能跟 i
            # 反向理解：i 前面可以是 a, e, o, u（除了 i）
            new_count['a'] += count['i']
            new_count['e'] += count['i']
            new_count['o'] += count['i']
            new_count['u'] += count['i']
            
            # 规则4：o 后面可以跟 i 或 u
            new_count['i'] += count['o']
            new_count['u'] += count['o']
            
            # 规则5：u 后面只能跟 a
            new_count['a'] += count['u']
            
            # 对每个计数取模
            for vowel in new_count:
                new_count[vowel] %= MOD
            
            # 更新计数
            count = new_count
        
        # 返回所有元音的总数
        total = sum(count.values()) % MOD
        return total
```

## 复杂度分析

**方法一和方法二：**

- **时间复杂度**：O(n)，需要计算 n 个长度
- **空间复杂度**：O(n)（方法一）或 O(1)（方法二）

**方法三（矩阵快速幂）：**

- **时间复杂度**：O(log n)，适合 n 非常大的情况
- **空间复杂度**：O(1)，只需要固定大小的矩阵

## 关键点总结

1. **状态定义清晰**：以某个元音结尾的字符串数量
2. **反向思考**：从"后面能跟什么"转换为"前面能来自哪"
3. **取模操作**：每次计算后都要取模，防止溢出
4. **空间优化**：只需要保存上一个状态，可以优化到 O(1)
5. **矩阵快速幂**：当 n 非常大时（10^9 级别）可以用矩阵快速幂优化到 O(log n)

## 易错点

1. **取模时机**：
   - 错误：最后才取模，可能导致中间结果溢出
   - 正确：每次加法后都取模

2. **状态转移方向**：
   - 容易混淆"a 后面跟 e"和"a 前面是谁"
   - 建议画图理清关系

3. **同时更新状态**：
   - 错误：直接修改当前状态变量（会影响后续计算）
   - 正确：使用临时变量保存新状态，最后统一更新

4. **初始化**：
   - n = 1 时，每个元音都是 1
   - 不要从 0 开始

5. **最终结果**：
   - 要把所有元音结尾的数量相加
   - 不要忘记对最终结果也要取模

## 学习建议

1. **掌握 DP 基本套路**：
   - 定义状态
   - 找出状态转移方程
   - 确定初始状态和边界条件

2. **练习空间优化**：
   - 观察是否只需要前一个状态
   - 滚动数组技巧

3. **学习矩阵快速幂**：
   - 适用于线性递推关系
   - 可以将 O(n) 优化到 O(log n)

4. **注意取模运算**：
   - 加法取模：(a + b) % MOD
   - 乘法取模：(a * b) % MOD
   - 幂运算取模：使用快速幂

5. **从简单到复杂**：
   - 先用朴素 DP 解决
   - 再考虑空间优化
   - 最后学习高级优化（矩阵快速幂）
