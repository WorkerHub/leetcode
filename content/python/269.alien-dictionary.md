## 题目描述

现有一种使用英语字母的外星文语言，这门语言的字母顺序与英语顺序不同。

给定一个字符串列表 `words`，作为这门语言的词典，`words` 中的字符串已经按这门新语言的字母顺序进行了排序。

请你根据该词典还原出此语言中已知的字母顺序，并以字符串形式返回。

若不存在合法字母顺序，返回 `""`。若存在多种可能的合法字母顺序，返回其中任意一种即可。

当且仅当对于词典中的任意两个相邻单词 `a` 和 `b`，在新语言的字母顺序中，`a` 在 `b` 之前，则称该字母顺序合法。

**示例 1：**
```
输入: words = ["wrt","wrf","er","ett","rftt"]
输出: "wertf"
解释: 
从 "wrt" < "wrf" 可知 t < f
从 "wrf" < "er" 可知 w < e
从 "er" < "ett" 可知 r < t
从 "ett" < "rftt" 可知 e < r
综合起来：w < e < r < t < f
```

**示例 2：**
```
输入: words = ["z","x"]
输出: "zx"
```

**示例 3：**
```
输入: words = ["z","x","z"]
输出: ""
解释: 不存在合法顺序，因为 z < x 且 x < z 形成环
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 仅由小写英文字母组成

## 解题思路

这是一道经典的**拓扑排序**问题。

**核心思路：**

1. **构建有向图**：
   - 比较相邻的两个单词，找到第一个不同的字符
   - 建立字符的先后关系（有向边）

2. **拓扑排序**：
   - 使用 BFS（Kahn算法）或 DFS 进行拓扑排序
   - 检测是否有环（环意味着不存在合法顺序）

3. **边界情况**：
   - 如果前缀相同但前面的单词更长，则无效（如 ["abc", "ab"]）
   - 检测环的存在
   - 确保所有字符都被包含

**算法步骤：**

1. 构建图的邻接表和入度数组
2. 比较相邻单词，建立字符关系
3. BFS/DFS 拓扑排序
4. 检测环和验证结果

## Python 代码实现

### 方法一：BFS 拓扑排序（Kahn 算法）（推荐）⭐

```python
from collections import defaultdict, deque

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        # 初始化图
        graph = defaultdict(set)
        in_degree = {c: 0 for word in words for c in word}
        
        # 构建图：比较相邻单词
        for i in range(len(words) - 1):
            word1, word2 = words[i], words[i + 1]
            min_len = min(len(word1), len(word2))
            
            # 检查前缀情况：如果 word1 是 word2 的前缀且更长，无效
            if word1[:min_len] == word2[:min_len] and len(word1) > len(word2):
                return ""
            
            # 找到第一个不同的字符
            for j in range(min_len):
                if word1[j] != word2[j]:
                    # word1[j] < word2[j]
                    if word2[j] not in graph[word1[j]]:
                        graph[word1[j]].add(word2[j])
                        in_degree[word2[j]] += 1
                    break  # 只需要第一个不同的字符
        
        # BFS 拓扑排序
        queue = deque([c for c in in_degree if in_degree[c] == 0])
        result = []
        
        while queue:
            char = queue.popleft()
            result.append(char)
            
            # 更新邻居的入度
            for neighbor in graph[char]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        # 检查是否所有字符都被访问（是否有环）
        if len(result) != len(in_degree):
            return ""
        
        return ''.join(result)
```

### 方法二：DFS 拓扑排序

```python
from collections import defaultdict

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        # 初始化图
        graph = defaultdict(set)
        chars = set()
        
        for word in words:
            for c in word:
                chars.add(c)
        
        # 构建图
        for i in range(len(words) - 1):
            word1, word2 = words[i], words[i + 1]
            min_len = min(len(word1), len(word2))
            
            # 检查无效情况
            if word1[:min_len] == word2[:min_len] and len(word1) > len(word2):
                return ""
            
            for j in range(min_len):
                if word1[j] != word2[j]:
                    graph[word1[j]].add(word2[j])
                    break
        
        # DFS 拓扑排序
        # 0: 未访问, 1: 访问中, 2: 已完成
        state = {c: 0 for c in chars}
        result = []
        
        def dfs(char: str) -> bool:
            """返回 False 表示有环"""
            if state[char] == 1:  # 正在访问，发现环
                return False
            if state[char] == 2:  # 已完成
                return True
            
            state[char] = 1  # 标记为访问中
            
            for neighbor in graph[char]:
                if not dfs(neighbor):
                    return False
            
            state[char] = 2  # 标记为已完成
            result.append(char)  # 后序遍历
            return True
        
        # 对所有字符进行 DFS
        for char in chars:
            if not dfs(char):
                return ""
        
        # 反转结果（后序遍历是反向的拓扑排序）
        return ''.join(reversed(result))
```

### 方法三：优化的 BFS

```python
from collections import defaultdict, deque, Counter

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        # 收集所有字符并初始化入度
        chars = set(''.join(words))
        graph = defaultdict(set)
        in_degree = Counter({c: 0 for c in chars})
        
        # 构建图
        for word1, word2 in zip(words, words[1:]):
            min_len = min(len(word1), len(word2))
            
            # 检查前缀但 word1 更长的情况
            if word1[:min_len] == word2[:min_len]:
                if len(word1) > len(word2):
                    return ""
                continue  # 完全前缀关系，无法确定字符顺序
            
            # 找第一个不同的字符
            for c1, c2 in zip(word1, word2):
                if c1 != c2:
                    if c2 not in graph[c1]:
                        graph[c1].add(c2)
                        in_degree[c2] += 1
                    break
        
        # BFS
        queue = deque([c for c in in_degree if in_degree[c] == 0])
        result = []
        
        while queue:
            char = queue.popleft()
            result.append(char)
            
            for neighbor in graph[char]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        return ''.join(result) if len(result) == len(chars) else ""
```

## 复杂度分析

### 方法一、二、三
- **时间复杂度**：O(C)
  - C 是所有单词的字符总数
  - 构建图：O(C)，需要遍历所有字符
  - 拓扑排序：O(V + E)，V 是字符种类数（最多26），E 是边数
  - 总体：O(C)

- **空间复杂度**：O(1) 或 O(26) = O(1)
  - 字符集固定为小写字母（最多26个）
  - 图的空间：O(V + E) = O(1)

## 图解示例

以 `words = ["wrt","wrf","er","ett","rftt"]` 为例：

```
1. 比较相邻单词，建立关系:

   "wrt" vs "wrf":
   w == w, r == r, t != f
   → t < f  (添加边 t → f)

   "wrf" vs "er":
   w != e
   → w < e  (添加边 w → e)

   "er" vs "ett":
   e == e, r != t
   → r < t  (添加边 r → t)

   "ett" vs "rftt":
   e != r
   → e < r  (添加边 e → r)

2. 构建的图:
   w → e
   e → r
   r → t
   t → f

3. 计算入度:
   w: 0
   e: 1
   r: 1
   t: 1
   f: 1

4. BFS 拓扑排序:
   队列初始: [w]
   
   取出 w → 结果: [w]
   → e 入度减 1 → 0，加入队列
   
   取出 e → 结果: [w, e]
   → r 入度减 1 → 0，加入队列
   
   取出 r → 结果: [w, e, r]
   → t 入度减 1 → 0，加入队列
   
   取出 t → 结果: [w, e, r, t]
   → f 入度减 1 → 0，加入队列
   
   取出 f → 结果: [w, e, r, t, f]

5. 最终结果: "wertf"
```

## 关键点总结

1. **拓扑排序应用**：字典序问题本质是拓扑排序
2. **图的构建**：
   - 只比较相邻单词
   - 只需要第一个不同的字符
   - 注意去重（同一条边不要重复添加）
3. **特殊情况处理**：
   - 前缀但前面单词更长：["abc", "ab"] 无效
   - 环的检测：拓扑排序结果数量 < 字符总数
4. **BFS vs DFS**：
   - BFS（Kahn算法）更直观
   - DFS 需要记录访问状态（0/1/2）
5. **入度数组初始化**：确保所有出现的字符都被包含

## 易错点

1. **前缀陷阱**：
   ```python
   # ["abc", "ab"] 是无效的
   # 因为 abc 应该在 ab 后面，但前缀相同且 abc 更长
   if word1[:min_len] == word2[:min_len] and len(word1) > len(word2):
       return ""
   ```

2. **重复边问题**：
   ```python
   # 需要检查边是否已存在
   if c2 not in graph[c1]:
       graph[c1].add(c2)
       in_degree[c2] += 1
   ```

3. **只取第一个不同字符**：
   ```python
   for j in range(min_len):
       if word1[j] != word2[j]:
           # 添加边
           break  # 关键：找到第一个就停止
   ```

4. **环检测**：
   ```python
   # DFS 中要用三种状态
   # 0: 未访问, 1: 访问中, 2: 已完成
   if state[char] == 1:  # 正在访问中遇到，说明有环
       return False
   ```

5. **字符集初始化**：要包含所有出现过的字符，不仅仅是有边的字符
