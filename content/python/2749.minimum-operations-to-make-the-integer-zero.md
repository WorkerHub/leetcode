## 题目描述

给你两个整数 `num1` 和 `num2`，每步操作可以选择一个整数 `i`（`0 <= i <= 60`），并令 `num1 -= (2^i + num2)`。

返回使 `num1` 变为 0 的 **最少操作次数**，如果不可能则返回 -1。

**示例 1：**
```
输入：num1 = 3, num2 = -2
输出：3
解释：num1 = 3 - (1 + (-2)) = 4, = 4 - (4+(-2)) = 2, = 2 - (2+(-2)) = 0
```

**示例 2：**
```
输入：num1 = 5, num2 = 7
输出：-1
```

**提示：**
- `-10^9 <= num1, num2 <= 10^9`

## 解题思路

进行 `k` 次操作后，`num1 - k * num2 = 2^i1 + 2^i2 + ... + 2^ik`（每次选一个 `i` 的 2 的幂）。

令 `val = num1 - k * num2`，需要：
1. `val > 0`（各 2 的幂之和必须为正）
2. `val` 的二进制中 1 的个数 <= `k`（k 个操作对应 k 个 2 的幂，可以重复）

枚举 `k` 从 1 开始，检查上述条件。

## Python 代码实现

### 方法一：枚举操作次数（推荐）

```python
class Solution:
    def makeTheIntegerZero(self, num1: int, num2: int) -> int:
        for k in range(1, 64):  # 最多 63 次操作（2^63 已足够大）
            val = num1 - k * num2
            # val 必须 > 0，且二进制 1 的个数 <= k
            if val > 0 and bin(val).count('1') <= k:
                return k
        return -1
```

## 复杂度分析

- 时间复杂度：O(60)
- 空间复杂度：O(1)

## 关键点总结

1. `k` 次操作相当于凑出 `val = num1 - k * num2` 的二进制表示
2. `val` 的 1 的个数是最少需要的操作次数（每次消掉一个最高位），但允许"重复"（将 2^i 拆成 2 * 2^(i-1)），所以 bits <= k 即可
3. 同时需要 `val > 0`（不能是负数或0，因为 2 的幂都是正数）

## 易错点

1. `val <= 0` 时无效，需要跳过
2. 循环上界 64 即可（操作超过 64 次时 `k * num2` 可能非常大，需要分情况讨论但实际上提前就满足条件了）
