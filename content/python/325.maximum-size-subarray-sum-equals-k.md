## 题目描述

给定一个数组 `nums` 和一个目标值 `k`，找到和等于 `k` 的最长连续子数组长度。如果不存在任意一个符合要求的子数组，则返回 `0`。

**示例 1:**

```
输入: nums = [1, -1, 5, -2, 3], k = 3
输出: 4
解释: 子数组 [1, -1, 5, -2] 和为 3，且长度最长。
```

**示例 2:**

```
输入: nums = [-2, -1, 2, 1], k = 1
输出: 2
解释: 子数组 [-1, 2] 和为 1，且长度为 2。
```

**提示:**

- `1 <= nums.length <= 2 * 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `-10^9 <= k <= 10^9`

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题是经典的**前缀和 + 哈希表**问题，求和为 `k` 的最长子数组。

### 核心思想

1. **前缀和定义**：`prefix_sum[i]` 表示 `nums[0...i]` 的和
2. **子数组和公式**：子数组 `nums[i...j]` 的和 = `prefix_sum[j] - prefix_sum[i-1]`
3. **转化问题**：找到和为 `k` 的子数组 `nums[i...j]`，即：
   - `prefix_sum[j] - prefix_sum[i-1] = k`
   - `prefix_sum[i-1] = prefix_sum[j] - k`
4. **哈希表记录**：用哈希表记录每个前缀和**第一次出现的位置**
   - 为什么记录第一次？因为要求**最长**子数组，越早出现长度越长

### 算法流程

1. 初始化哈希表 `{0: -1}`（前缀和 0 出现在索引 -1，便于处理从索引 0 开始的子数组）
2. 遍历数组，累加前缀和
3. 检查 `prefix_sum - k` 是否在哈希表中：
   - 如果在，计算长度并更新最大值
   - 如果当前 `prefix_sum` 第一次出现，记录到哈希表

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）⭐

```python
from typing import List

class Solution:
    def maxSubArrayLen(self, nums: List[int], k: int) -> int:
        """
        前缀和 + 哈希表：记录每个前缀和第一次出现的位置
        """
        # 哈希表：{前缀和: 第一次出现的索引}
        prefix_map = {0: -1}  # 初始化：前缀和 0 在索引 -1
        prefix_sum = 0
        max_len = 0
        
        for i, num in enumerate(nums):
            prefix_sum += num
            
            # 检查是否存在前缀和为 prefix_sum - k
            if prefix_sum - k in prefix_map:
                # 计算子数组长度
                max_len = max(max_len, i - prefix_map[prefix_sum - k])
            
            # 只记录第一次出现的位置（保证最长）
            if prefix_sum not in prefix_map:
                prefix_map[prefix_sum] = i
        
        return max_len
```

### 方法二：详细注释版（便于理解）

```python
from typing import List

class Solution:
    def maxSubArrayLen(self, nums: List[int], k: int) -> int:
        """
        前缀和思想：
        如果 nums[i...j] 的和为 k，则：
        prefix_sum[j] - prefix_sum[i-1] = k
        即：prefix_sum[i-1] = prefix_sum[j] - k
        """
        prefix_map = {0: -1}  # 前缀和 0 对应索引 -1
        prefix_sum = 0
        max_len = 0
        
        for i in range(len(nums)):
            # 计算当前前缀和
            prefix_sum += nums[i]
            
            # 查找是否存在前缀和 = prefix_sum - k
            target = prefix_sum - k
            if target in prefix_map:
                # 找到了，计算子数组长度
                start_index = prefix_map[target]
                length = i - start_index
                max_len = max(max_len, length)
            
            # 只在第一次出现时记录（越早出现，后续匹配时长度越长）
            if prefix_sum not in prefix_map:
                prefix_map[prefix_sum] = i
        
        return max_len
```

### 方法三：暴力解法（超时，仅用于理解）

```python
from typing import List

class Solution:
    def maxSubArrayLen(self, nums: List[int], k: int) -> int:
        """
        暴力解法：枚举所有子数组
        时间复杂度 O(n^2)，会超时
        """
        n = len(nums)
        max_len = 0
        
        for i in range(n):
            current_sum = 0
            for j in range(i, n):
                current_sum += nums[j]
                if current_sum == k:
                    max_len = max(max_len, j - i + 1)
        
        return max_len
```

## 复杂度分析

**方法一/二：前缀和 + 哈希表**

- **时间复杂度**：O(n)
  - 遍历一次数组
  - 哈希表查找和插入都是 O(1)
  
- **空间复杂度**：O(n)
  - 哈希表最多存储 n 个不同的前缀和

**方法三：暴力解法**

- **时间复杂度**：O(n^2)
  - 双层循环枚举所有子数组
  
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和技巧**：将子数组和问题转化为前缀和差值问题
2. **哈希表用途**：快速查找 `prefix_sum - k` 是否存在
3. **只记录第一次**：因为求最长子数组，越早出现的前缀和，后续匹配时长度越长
4. **初始化 `{0: -1}`**：处理从索引 0 开始的子数组
   - 例如 `nums = [1], k = 1`，当 `i = 0` 时，`prefix_sum = 1`，需要找 `1 - 1 = 0`
   - `0` 在索引 `-1`，长度 = `0 - (-1) = 1` ✓
5. **与 560 题的区别**：
   - 560 题求子数组个数，需要记录每个前缀和出现的次数
   - 本题求最长子数组，只需记录第一次出现的位置

## 易错点

1. **初始化遗漏**：忘记初始化 `prefix_map[0] = -1`
2. **记录所有出现位置**：错误地更新哈希表中的索引，应该只记录第一次
3. **长度计算错误**：
   - 正确：`i - prefix_map[target]`
   - 错误：`i - prefix_map[target] + 1`（因为 `prefix_map[target]` 存的是前一个位置）
4. **边界情况**：数组全为 0，`k = 0` 的情况
