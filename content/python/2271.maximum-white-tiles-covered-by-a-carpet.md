## 题目描述

给你一个二维整数数组 `tiles`，`tiles[i] = [li, ri]` 表示第 `i` 块白色瓷砖覆盖 `[li, ri]` 范围，以及一个整数 `carpetLen`，表示地毯的长度。

返回地毯能覆盖的**最多白色瓷砖数**。

**示例 1：**
```
输入：tiles = [[1,5],[10,11],[12,18],[20,25],[30,32]], carpetLen = 10
输出：9
解释：地毯从位置12开始，覆盖[12,21]，白色瓷砖有[12,18]共7格，[20,21]共2格，总9格。
```

## 解题思路

**排序 + 前缀和 + 二分：**

1. 将 `tiles` 按左端点排序。
2. 预计算前缀和 `prefix[i]` = 前 `i` 块瓷砖的总白色格子数。
3. 贪心：地毯的最优位置一定从某块瓷砖的左端点开始（否则向右移对齐某瓷砖只会更优或相等）。
4. 对每块瓷砖的左端点 `l`，地毯覆盖 `[l, l + carpetLen - 1]`，用二分找到最后一块被完全覆盖的瓷砖，计算总覆盖白色格数。

## 代码实现

### 方法一：排序 + 前缀和 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumWhiteTiles(self, tiles: List[List[int]], carpetLen: int) -> int:
        # 排序
        tiles.sort()
        n = len(tiles)

        # 前缀和：prefix[i] = 前 i 块瓷砖的总白色格子数
        prefix = [0] * (n + 1)
        for i, (l, r) in enumerate(tiles):
            prefix[i + 1] = prefix[i] + (r - l + 1)

        ans = 0
        # 枚举地毯左端从每块瓷砖的起始位置开始
        for i, (l, r) in enumerate(tiles):
            carpet_end = l + carpetLen - 1

            # 用二分找最后一块 right <= carpet_end 的瓷砖的下标
            # 即在 tiles 中找最后一个 tiles[j][0] <= carpet_end
            # 但需要考虑部分覆盖
            # 找最后一块被地毯完全覆盖的瓷砖
            # tiles[j][1] <= carpet_end
            lo, hi = i, n - 1
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if tiles[mid][0] <= carpet_end:
                    lo = mid
                else:
                    hi = mid - 1

            # tiles[lo] 是最后一块左端点 <= carpet_end 的瓷砖
            j = lo
            # 完全覆盖的白色格子
            covered = prefix[j + 1] - prefix[i]
            # tiles[j] 可能只有一部分被覆盖
            if tiles[j][1] > carpet_end:
                covered -= tiles[j][1] - carpet_end

            ans = max(ans, covered)

        return ans
```

### 方法二：使用 bisect 简化二分

```python
from typing import List
import bisect

class Solution:
    def maximumWhiteTiles(self, tiles: List[List[int]], carpetLen: int) -> int:
        tiles.sort()
        n = len(tiles)
        prefix = [0] * (n + 1)
        for i, (l, r) in enumerate(tiles):
            prefix[i + 1] = prefix[i] + r - l + 1

        lefts = [t[0] for t in tiles]
        ans = 0

        for i, (l, r) in enumerate(tiles):
            end = l + carpetLen - 1
            # 找最后一块左端点 <= end 的瓷砖（二分）
            j = bisect.bisect_right(lefts, end) - 1
            # 累计完整覆盖
            covered = prefix[j + 1] - prefix[i]
            # 末块可能只部分覆盖
            if tiles[j][1] > end:
                covered -= tiles[j][1] - end
            ans = max(ans, covered)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 每个瓷砖的二分查找。
- 空间复杂度：O(n)，前缀和数组。

## 关键点总结

1. 贪心：地毯左端点对齐某块瓷砖的起始位置最优。
2. 二分找最后一块被地毯覆盖（部分或完全）的瓷砖。
3. 最后一块可能只有部分被覆盖，需要减去超出部分。

## 易错点

- 最后一块瓷砖可能部分超出地毯范围，需用 `min(tiles[j][1], end)` 计算实际覆盖。
- 排序是按左端点而非右端点。
