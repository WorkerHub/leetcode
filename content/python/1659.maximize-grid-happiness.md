## 题目描述

给你四个整数 `m`、`n`、`introvertsCount` 和 `extrovertsCount`。有一个 `m x n` 网格，你需要决定如何放置内向人和外向人，最大化总幸福感。

规则：
- 每格至多一人
- **内向人**基础幸福感 +120，但每个相邻人 -30
- **外向人**基础幸福感 +40，但每个相邻人 +20

**提示：**
- `1 <= m, n <= 5`

## 解题思路

由于 `m, n <= 5`，使用**状态压缩 DP + 逐行处理**。

每行的状态用三进制（0=空，1=内向，2=外向）表示，共 3^n 种状态。

**DP 状态：** `dp[row][introverts_used][extroverts_used][state]`

**逐行转移：** 对每行的每种放置方案，计算当前行内部的幸福感 + 与上一行的交互幸福感。

## 代码实现

### 方法一：状态压缩 DP（逐行）

```python
from functools import lru_cache

class Solution:
    def getMaxGridHappiness(self, m: int, n: int, introvertsCount: int, extrovertsCount: int) -> int:
        # 三进制枚举每行状态（0=空, 1=内向, 2=外向）
        
        def get_happiness_in_row(state: list) -> int:
            """计算一行内部相邻的幸福感变化"""
            h = 0
            for k in range(n):
                if state[k] == 0:
                    continue
                base = 120 if state[k] == 1 else 40
                h += base
                if k > 0 and state[k-1] != 0:
                    # 相邻带来的影响（双向）
                    h += (-30 if state[k] == 1 else 20)
                    h += (-30 if state[k-1] == 1 else 20)
            return h
        
        def get_happiness_between_rows(prev: list, curr: list) -> int:
            """计算相邻行之间的幸福感变化"""
            h = 0
            for k in range(n):
                if prev[k] != 0 and curr[k] != 0:
                    h += (-30 if curr[k] == 1 else 20)
                    h += (-30 if prev[k] == 1 else 20)
            return h
        
        # 预生成所有行状态
        all_states = []
        def gen_states(col, state, ni, ei):
            if col == n:
                all_states.append((state[:], ni, ei))
                return
            state.append(0)
            gen_states(col + 1, state, ni, ei)
            state[-1] = 1
            gen_states(col + 1, state, ni + 1, ei)
            state[-1] = 2
            gen_states(col + 1, state, ni, ei + 1)
            state.pop()
        
        gen_states(0, [], 0, 0)
        
        @lru_cache(maxsize=None)
        def dp(row: int, ni: int, ei: int, prev_state_idx: int) -> int:
            if row == m:
                return 0
            
            best = 0
            prev_state = all_states[prev_state_idx][0]
            
            for s_idx, (state, s_ni, s_ei) in enumerate(all_states):
                if ni + s_ni > introvertsCount or ei + s_ei > extrovertsCount:
                    continue
                
                h = get_happiness_in_row(state)
                h += get_happiness_between_rows(prev_state, state)
                h += dp(row + 1, ni + s_ni, ei + s_ei, s_idx)
                best = max(best, h)
            
            return best
        
        # 找所有状态中空状态的下标
        empty_idx = 0  # 全空状态
        return dp(0, 0, 0, empty_idx)
```

### 方法二：简化版（直接枚举）

```python
from functools import lru_cache

class Solution:
    def getMaxGridHappiness(self, m: int, n: int, introvertsCount: int, extrovertsCount: int) -> int:
        # 将行状态编码为整数（三进制）
        def decode(state: int) -> list:
            row = []
            for _ in range(n):
                row.append(state % 3)
                state //= 3
            return row
        
        max_state = 3 ** n
        
        @lru_cache(maxsize=None)
        def dp(row: int, ni: int, ei: int, prev: int) -> int:
            if row == m or (ni == introvertsCount and ei == extrovertsCount):
                return 0
            
            best = dp(row + 1, ni, ei, 0) if row < m else 0  # 跳过此行（全空）
            prev_row = decode(prev)
            
            for curr in range(max_state):
                curr_row = decode(curr)
                s_ni = curr_row.count(1)
                s_ei = curr_row.count(2)
                
                if ni + s_ni > introvertsCount or ei + s_ei > extrovertsCount:
                    continue
                
                h = 0
                for k in range(n):
                    if curr_row[k] == 0:
                        continue
                    h += 120 if curr_row[k] == 1 else 40
                    if k > 0 and curr_row[k-1] != 0:
                        h += (-30 if curr_row[k] == 1 else 20)
                        h += (-30 if curr_row[k-1] == 1 else 20)
                    if prev_row[k] != 0:
                        h += (-30 if curr_row[k] == 1 else 20)
                        h += (-30 if prev_row[k] == 1 else 20)
                
                h += dp(row + 1, ni + s_ni, ei + s_ei, curr)
                best = max(best, h)
            
            return best
        
        return dp(0, 0, 0, 0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 状态压缩 DP | O(m * I * E * 3^(2n)) | O(m * I * E * 3^n) |

I, E 最大为 6（introvertsCount, extrovertsCount），3^5 = 243，总计可控。

## 关键点总结

1. 内向人：基础 +120，每相邻一人 -30；外向人：基础 +40，每相邻一人 +20
2. 逐行处理，记录上一行状态
3. 相邻产生的效果是双向的（两个相邻的人都受影响）
4. 状态压缩用三进制（0/1/2 分别代表空/内/外）

## 易错点

- 相邻幸福感是**双向**的，两人都受影响
- 内向人的 -30 是每相邻，不是总 -30
- 记忆化时 prev_state 必须包含在状态中
