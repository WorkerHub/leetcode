## 题目描述

我们给出了一个（轴对齐的）二维矩形列表 `rectangles`。对于 `rectangle[i] = [x1, y1, x2, y2]`，其中 `(x1, y1)` 是矩形 `i` 左下角的坐标，`(x2, y2)` 是该矩形 **右上角** 的坐标。

计算平面中所有 `rectangles` 所覆盖的 **总面积**。由于答案可能太大，返回 **对 `10^9 + 7` 取模** 的结果。

**示例 1:**
```
输入: rectangles = [[0,0,2,2],[1,0,2,3],[1,0,3,1]]
输出: 6
解释: 如图所示，三个矩形覆盖了总面积为 6 的区域。
```

**示例 2:**
```
输入: rectangles = [[0,0,1000000000,1000000000]]
输出: 49
解释: 答案是 10^18 对 (10^9 + 7) 取模的结果， 即 49 。
```

## Python 代码实现

```python
from typing import List

class Solution:
    def rectangleArea(self, rectangles: List[List[int]]) -> int:
        MOD = 10**9 + 7
        
        # 提取所有 x 坐标并排序
        x_coords = sorted(set(x for x1, y1, x2, y2 in rectangles for x in [x1, x2]))
        
        # 坐标压缩
        x_index = {v: i for i, v in enumerate(x_coords)}
        
        # 按 y 坐标排序的事件
        events = []
        for x1, y1, x2, y2 in rectangles:
            events.append((y1, x1, x2, 1))   # 矩形开始
            events.append((y2, x1, x2, -1))  # 矩形结束
        events.sort()
        
        area = 0
        active = [0] * len(x_coords)
        prev_y = 0
        
        for y, x1, x2, delta in events:
            # 计算当前高度的面积贡献
            width = sum((x_coords[i + 1] - x_coords[i]) * (active[i] > 0) 
                       for i in range(len(x_coords) - 1))
            area += width * (y - prev_y)
            area %= MOD
            
            # 更新活跃区间
            for i in range(x_index[x1], x_index[x2]):
                active[i] += delta
            
            prev_y = y
        
        return area
```

## 复杂度分析

- **时间复杂度**：O(n² log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **扫描线算法**：按 y 坐标扫描
2. **坐标压缩**：离散化 x 坐标
3. **事件驱动**：矩形的开始和结束

## 学习建议

1. **扫描线**：处理矩形覆盖的经典算法
2. **坐标压缩**：处理大范围坐标
3. **线段树**：可以优化到 O(n log n)
