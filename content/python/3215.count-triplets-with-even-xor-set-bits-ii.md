## 题目描述

给你三个整数数组 `a`、`b` 和 `c`。

返回三元组 `(a[i], b[j], c[k])` 的数量，使得 `a[i] XOR b[j] XOR c[k]` 中设置位（1的个数）的数量为**偶数**。

**示例 1：**
```
输入：a = [1], b = [2], c = [3]
输出：1
解释：1 XOR 2 XOR 3 = 0，popcount(0) = 0（偶数）
```

**示例 2：**
```
输入：a = [1,1], b = [2,3], c = [1,5]
输出：4
```

**提示：**
- `1 <= a.length, b.length, c.length <= 10^5`
- `0 <= a[i], b[j], c[k] <= 10^9`

## 解题思路

关键观察：`popcount(x XOR y) % 2 == (popcount(x) + popcount(y)) % 2`（XOR 的每一位独立影响 popcount 的奇偶性）。

因此，`popcount(a[i] XOR b[j] XOR c[k]) % 2 == (popcount(a[i]) + popcount(b[j]) + popcount(c[k])) % 2`。

我们需要三个 popcount 之和为偶数，即三个值中奇数 popcount 的个数为偶数（0 或 2 个）。

分别统计各数组中 popcount 为奇/偶的数量，然后组合计数：
- 全为偶：`even_a * even_b * even_c`
- 两奇一偶：`odd_a * odd_b * even_c + odd_a * even_b * odd_c + even_a * odd_b * odd_c`

## Python 代码实现

### 方法一：统计奇偶 popcount（推荐）

```python
from typing import List

class Solution:
    def numberOfTriplets(self, a: List[int], b: List[int], c: List[int]) -> int:
        def count_parity(arr):
            # 返回 (偶数popcount的数量, 奇数popcount的数量)
            even = sum(1 for x in arr if bin(x).count('1') % 2 == 0)
            odd = len(arr) - even
            return even, odd
        
        ea, oa = count_parity(a)
        eb, ob = count_parity(b)
        ec, oc = count_parity(c)
        
        # 三个 popcount 奇偶性之和为偶数
        # 情况1：全偶
        ans = ea * eb * ec
        # 情况2：两奇一偶
        ans += oa * ob * ec
        ans += oa * eb * oc
        ans += ea * ob * oc
        
        return ans
```

### 方法二：位运算优化

```python
from typing import List

class Solution:
    def numberOfTriplets(self, a: List[int], b: List[int], c: List[int]) -> int:
        # 利用 bin(x).count('1') 或 x.bit_count() (Python 3.10+)
        def parity(x):
            return bin(x).count('1') & 1
        
        ca = [0, 0]  # ca[0] = 偶数popcount计数, ca[1] = 奇数popcount计数
        cb = [0, 0]
        cc = [0, 0]
        
        for x in a:
            ca[parity(x)] += 1
        for x in b:
            cb[parity(x)] += 1
        for x in c:
            cc[parity(x)] += 1
        
        # 三个奇偶值相加为偶（0+0+0 或 1+1+0 的三种排列）
        return (ca[0]*cb[0]*cc[0] + ca[1]*cb[1]*cc[0] +
                ca[1]*cb[0]*cc[1] + ca[0]*cb[1]*cc[1])
```

## 复杂度分析

- 时间复杂度：O(n + m + p)，n, m, p 分别为三个数组长度
- 空间复杂度：O(1)

## 关键点总结

1. XOR 的 popcount 奇偶性等于各个数 popcount 奇偶性的 XOR（加法模2）
2. 三个数 popcount 之和为偶数的情况：全偶或两奇一偶
3. 分别统计三个数组的奇偶 popcount 数量，直接乘法组合

## 易错点

1. 注意是三个数 popcount 奇偶性之和为偶，不是 XOR 结果为偶
2. Python 3.10+ 可用 `x.bit_count()`，否则用 `bin(x).count('1')`
