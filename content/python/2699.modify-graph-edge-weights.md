## 题目描述

给你一个 `n` 个节点的无向带权图，边权可以是正整数，也可以是 -1（表示待定）。将所有 -1 的边改为正整数，使得从 `source` 到 `destination` 的最短路径长度恰好等于 `target`。

若存在这样的方案，返回修改后的边列表；否则返回空数组。

**数据范围：**
- 1 <= n <= 100
- 1 <= edges.length <= n*(n-1)/2
- 1 <= source, destination < n
- 1 <= target <= 10^9

## 解题思路

两次 Dijkstra 方法：

1. **第一次 Dijkstra**：忽略所有 -1 边（视为不存在），求现有固定边的最短路。若最短路 < target，则无论如何设置 -1 边都无法使最短路 = target（因为 -1 边只能增大或保持距离），返回 []。若最短路 = target，将所有 -1 边设为大值（如 target+1），直接返回。

2. **第二次 Dijkstra**：逐一设置 -1 边，对每条 -1 边 (u, v)，设其权重为 `1 + d[u] + (target - dist[v])`（利用当前最短路信息，将边权设为刚好使路径长度达到 target 所需的值）。

## Python 代码实现

### 方法一：两次 Dijkstra

```python
from typing import List
import heapq

class Solution:
    def modifiedGraphEdges(self, n: int, edges: List[List[int]],
                           source: int, destination: int, target: int) -> List[List[int]]:
        INF = int(2e9)

        def dijkstra(adj, src):
            dist = [INF] * n
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in adj[u]:
                    if dist[u] + w < dist[v]:
                        dist[v] = dist[u] + w
                        heapq.heappush(heap, (dist[v], v))
            return dist

        # 第一次 Dijkstra：只用固定权重的边（-1 边设为 INF）
        adj1 = [[] for _ in range(n)]
        for u, v, w in edges:
            if w != -1:
                adj1[u].append((v, w))
                adj1[v].append((u, w))

        dist1 = dijkstra(adj1, source)
        if dist1[destination] < target:
            return []  # 固定边已经使最短路 < target，无法修改

        # 第二次：逐一启用 -1 边
        adj2 = [adj1[i][:] for i in range(n)]
        for i, (u, v, w) in enumerate(edges):
            if w == -1:
                # 先以最小权重 1 添加
                edges[i][2] = 1
                adj2[u].append((v, 1))
                adj2[v].append((u, 1))
                dist2 = dijkstra(adj2, source)
                if dist2[destination] <= target:
                    # 调整这条边的权重使最短路恰好等于 target
                    edges[i][2] += target - dist2[destination]
                    # 将后续所有 -1 边设为大值
                    for j in range(i + 1, len(edges)):
                        if edges[j][2] == -1:
                            edges[j][2] = INF
                    return edges
                # 更新邻接表（使用新权重）
                adj2[u][-1] = (v, edges[i][2])
                adj2[v][-1] = (u, edges[i][2])

        return []
```

## 复杂度分析

- 时间复杂度：O(m * (n + m) * log n)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 先判断固定边的最短路，若已经 < target 则无解
2. 逐一启用 -1 边（权重 1），若某次后最短路 <= target，则调整该边权重使恰好 = target
3. 后续未处理的 -1 边可以设为任意大值（不影响最短路）

## 易错点

1. 调整边权时要正确计算差值
2. 修改一条边后，后续的 Dijkstra 要使用更新后的邻接表
3. -1 边以外的边不能修改
