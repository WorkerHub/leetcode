## 题目描述

[LeetCode 1208. Get Equal Substrings Within Budget](https://leetcode.com/problems/get-equal-substrings-within-budget/)

给你两个长度相同的字符串，`s` 和 `t`。

将 `s` 中的第 `i` 个字符变到 `t` 中的第 `i` 个字符需要 `|s[i] - t[i]|` 的开销（开销可能为 0），也就是两个字符的 ASCII 码值的差的绝对值。

用于变更字符串的最大预算是 `maxCost`。在转化字符串时，总开销应当小于等于该预算，这也意味着字符串的转化可能是不完全的。

如果你可以将 `s` 的子字符串转化为它在 `t` 中对应的子字符串，则返回可以转化的最大长度。

如果 `s` 中没有子字符串可以转化成 `t` 中对应的子字符串，则返回 0。

**示例 1:**
```
输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3
解释：s 中的 "abc" 可以变为 "bcd"。开销为 3，所以最大长度为 3。
```

**示例 2:**
```
输入：s = "abcd", t = "cdef", maxCost = 3
输出：1
解释：s 中的任一字符要想变成 t 中对应的字符，其开销都是 2。因此，最大长度为 1。
```

**示例 3:**
```
输入：s = "abcd", t = "acde", maxCost = 0
输出：1
解释：a -> a, 开销为 0，最大长度为 1。
```

**提示:**
- 1 <= s.length, t.length <= 10^5
- 0 <= maxCost <= 10^6
- s 和 t 都只含小写英文字母

## 解题思路

这道题是典型的滑动窗口问题，核心在于找到满足条件的最长连续子串。

### 问题转化

1. **计算开销数组**：先计算每个位置的转换开销 `cost[i] = |s[i] - t[i]|`
2. **滑动窗口**：在 cost 数组上找最长的连续子数组，使得子数组和不超过 maxCost

### 滑动窗口模板

```
初始化：left = 0, right = 0, sum = 0
while right < n:
    扩大窗口：sum += cost[right]
    while 不满足条件（sum > maxCost）:
        缩小窗口：sum -= cost[left], left++
    更新答案：max_len = max(max_len, right - left + 1)
    right++
```

### 为什么用滑动窗口

- **单调性**：如果 [left, right] 满足条件，[left+1, right] 也满足条件
- **连续性**：要求的是连续子串，不能跳过中间元素
- **高效性**：双指针一次遍历，时间复杂度 O(n)

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        n = len(s)
        
        # 计算每个位置的转换开销
        cost = [abs(ord(s[i]) - ord(t[i])) for i in range(n)]
        
        left = 0
        current_cost = 0
        max_length = 0
        
        # 滑动窗口
        for right in range(n):
            # 扩大窗口
            current_cost += cost[right]
            
            # 如果开销超出预算，缩小窗口
            while current_cost > maxCost:
                current_cost -= cost[left]
                left += 1
            
            # 更新最大长度
            max_length = max(max_length, right - left + 1)
        
        return max_length
```

### 方法二：优化的滑动窗口（无需数组）

```python
from typing import List

class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        n = len(s)
        left = 0
        current_cost = 0
        max_length = 0
        
        for right in range(n):
            # 直接计算开销，无需额外数组
            current_cost += abs(ord(s[right]) - ord(t[right]))
            
            # 缩小窗口直到满足预算
            while current_cost > maxCost:
                current_cost -= abs(ord(s[left]) - ord(t[left]))
                left += 1
            
            # 更新最大长度
            max_length = max(max_length, right - left + 1)
        
        return max_length
```

### 方法三：固定窗口大小优化

```python
from typing import List

class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        n = len(s)
        left = 0
        current_cost = 0
        
        for right in range(n):
            current_cost += abs(ord(s[right]) - ord(t[right]))
            
            # 只在需要时移动左指针，保持窗口尽可能大
            # 这样 right - left 就是当前窗口大小
            if current_cost > maxCost:
                current_cost -= abs(ord(s[left]) - ord(t[left]))
                left += 1
        
        # 最终窗口大小就是答案
        return n - left
```

### 方法四：前缀和 + 二分查找

```python
from typing import List

class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        n = len(s)
        
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + abs(ord(s[i]) - ord(t[i]))
        
        max_length = 0
        
        # 对每个起点，二分查找最远的终点
        for left in range(n):
            # 二分查找最大的 right，使得 prefix[right+1] - prefix[left] <= maxCost
            lo, hi = left, n
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if prefix[mid] - prefix[left] <= maxCost:
                    lo = mid
                else:
                    hi = mid - 1
            
            max_length = max(max_length, lo - left)
        
        return max_length
```

## 复杂度分析

### 方法一、二、三：滑动窗口

- **时间复杂度**：O(n)
  - 每个元素最多被访问两次（right 指针一次，left 指针一次）
  - 虽然有嵌套循环，但 left 指针总共只移动 n 次
  
- **空间复杂度**：
  - 方法一：O(n)，需要 cost 数组
  - 方法二、三：O(1)，不需要额外数组

### 方法四：前缀和 + 二分

- **时间复杂度**：O(n log n)
  - 计算前缀和：O(n)
  - 对每个起点二分查找：O(n log n)
  
- **空间复杂度**：O(n)，前缀和数组

## 关键点总结

1. **问题转化**：将字符串问题转化为数组求和问题，更容易处理

2. **滑动窗口识别**：
   - 求最长/最短连续子数组
   - 有明确的约束条件（和不超过 maxCost）
   - 具有单调性

3. **双指针移动规则**：
   - right 指针一直向右移动（扩大窗口）
   - 当条件不满足时，移动 left 指针（缩小窗口）
   - 每次移动后更新答案

4. **优化技巧**：
   - 方法二：边计算边使用，节省空间
   - 方法三：利用窗口只增不减的特性，简化代码

5. **ASCII 码计算**：`ord(char)` 返回字符的 ASCII 码值

## 易错点

1. **while vs if**：
   - 缩小窗口时应该用 `while`，因为可能需要移动多次
   - 方法三用 `if` 是因为每次只需要移动一次，维持窗口大小

2. **窗口长度计算**：
   - 长度是 `right - left + 1`，不是 `right - left`
   - 方法三的长度是 `n - left`，因为 right 最终是 n-1

3. **边界条件**：
   - maxCost = 0 时，只能找完全相同的字符
   - s 和 t 完全相同时，整个字符串都满足条件

4. **开销计算**：
   - 一定要用绝对值 `abs()`
   - ord() 返回的是整数，可以直接相减

5. **前缀和边界**：
   - 方法四中前缀和数组大小是 n+1，prefix[0] = 0
   - 区间 [left, right] 的和是 `prefix[right+1] - prefix[left]`
