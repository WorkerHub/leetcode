## 题目描述

给你一棵二叉树的根节点 `root` 和树中的一个节点 `u`（保证 `u` 在树中存在），返回 `u` 的镜像节点（即镜像翻转整棵树后，`u` 所在位置的节点）。

**示例 1：**

```
输入：root = [1,2,3], u = 2
输出：3（镜像后，原来2的位置是3）
```

**示例 2：**

```
输入：root = [1,2,3,4,5], u = 4
输出：5
```

**提示：**

- 树的节点数在 `[1, 1000]`
- `1 <= Node.val <= 1000`
- 每个节点值唯一

## 解题思路

递归找镜像节点：

同时在原树和镜像树中搜索。原树走左子树时，镜像树走右子树（反之亦然）。

若原树当前节点就是 `u`，则返回镜像树的当前节点。

## Python 代码实现

### 方法一：递归同步遍历（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def mirrorNode(self, root: Optional[TreeNode], u: TreeNode) -> Optional[TreeNode]:
        def find(original, mirror):
            if original is None:
                return None
            if original is u:
                return mirror
            # 原树走左 → 镜像走右（反之亦然）
            left_result = find(original.left, mirror.right)
            if left_result:
                return left_result
            return find(original.right, mirror.left)

        return find(root, root)
```

### 方法二：先找路径再走镜像路径

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def mirrorNode(self, root: Optional[TreeNode], u: TreeNode) -> Optional[TreeNode]:
        # 找从根到 u 的路径（L/R 序列）
        path = []

        def find_path(node, target):
            if node is None:
                return False
            if node is target:
                return True
            path.append('L')
            if find_path(node.left, target):
                return True
            path.pop()
            path.append('R')
            if find_path(node.right, target):
                return True
            path.pop()
            return False

        find_path(root, u)

        # 沿镜像路径走
        curr = root
        for direction in path:
            if direction == 'L':
                curr = curr.right  # 镜像：L→R
            else:
                curr = curr.left   # 镜像：R→L

        return curr
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树高

## 关键点总结

1. 镜像操作：每次走左时镜像走右，走右时镜像走左
2. 同步遍历两棵树（原树和其镜像）
3. 找到原树中的 u 时返回镜像树中的对应节点

## 易错点

1. 不是找值相同的节点，而是位置镜像对应的节点
2. 路径法：记录 L/R 路径后，在镜像路径中走相反方向
3. 根节点的镜像是根节点本身
