## 题目描述

给你一个整数数组 `nums` 和一个整数 `x`。每一次操作时，你应当移除数组 `nums` 最左边或最右边的元素，然后从 `x` 中减去该元素的值。注意，需要修改数组以供接下来的操作使用。

如果可以将 `x` 恰好减到 `0`，返回**最少操作数**；否则，返回 `-1`。

**示例：**
```
输入：nums = [1,1,4,2,3], x = 5
输出：2（移除右边的 3 和 2）

输入：nums = [3,2,20,1,1,3], x = 10
输出：5
```

## 解题思路

**等价转化：** 从两端移除总和为 `x` 的元素，等价于找**中间子数组的最大长度**，使得子数组总和为 `sum(nums) - x`。

若 `target = sum(nums) - x < 0`，则无解。

**滑动窗口：** 找最长子数组，使得子数组和等于 `target`。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        
        if target < 0:
            return -1
        
        if target == 0:
            return len(nums)
        
        n = len(nums)
        max_len = -1  # 满足条件的最长子数组长度
        curr_sum = 0
        left = 0
        
        for right in range(n):
            curr_sum += nums[right]
            
            # 若当前和超过 target，缩小左边界
            while curr_sum > target and left <= right:
                curr_sum -= nums[left]
                left += 1
            
            if curr_sum == target:
                max_len = max(max_len, right - left + 1)
        
        if max_len == -1:
            return -1
        return n - max_len
```

### 方法二：前缀和 + 哈希表

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        
        if target < 0:
            return -1
        
        if target == 0:
            return len(nums)
        
        prefix_sum = {0: -1}  # 前缀和 -> 最早出现的下标
        curr_sum = 0
        max_len = -1
        
        for i, num in enumerate(nums):
            curr_sum += num
            if curr_sum - target in prefix_sum:
                length = i - prefix_sum[curr_sum - target]
                max_len = max(max_len, length)
            if curr_sum not in prefix_sum:
                prefix_sum[curr_sum] = i
        
        return len(nums) - max_len if max_len != -1 else -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 前缀和 | O(n) | O(n) |

## 关键点总结

1. 问题转化：找最长子数组使和为 `sum - x`
2. 数组元素均为正（否则滑动窗口无法保证单调性）
3. 最少操作数 = `n - 最长中间子数组长度`
4. `target == 0` 时，整个数组就是满足条件的子数组

## 易错点

- `target < 0` 时无解（总和小于 x）
- 滑动窗口适用于正整数数组（单调性）
- 返回 `n - max_len`，不是 `max_len`
