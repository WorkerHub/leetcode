## 题目描述

给定整数数组 `nums` 和整数 `k`，找出最多有多少个不重叠的子数组，使得每个子数组的元素之和恰好等于 `k`。

**示例 1：**
```
输入：nums = [1,1,1,1,1], k = 2
输出：2
解释：子数组 [1,1] 出现两次（[0,1] 和 [2,3]），不重叠，共 2 个。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5], k = 5
输出：2
解释：子数组 [5]（下标 4）和 [2,3]（下标 1-2）或 [1,4]...
     [2,3] 和 [5] 不重叠，共 2 个。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `-10^9 <= k <= 10^9`

## 解题思路

贪心 + 前缀和 + 哈希表。

**核心思路：** 贪心地选取尽可能早结束的和为 k 的子数组。

用前缀和 `pre[i]` 表示 `nums[0..i-1]` 的前缀和。子数组 `[l, r]` 的和等于 `k` 等价于 `pre[r+1] - pre[l] = k`，即 `pre[l] = pre[r+1] - k`。

**贪心 DP：**
- `dp[i]` 表示在 `nums[0..i-1]` 中能选到的最多不重叠和为 k 的子数组数。
- 遍历每个右端点 `r`，用哈希表找最近的满足 `pre[l] = pre[r+1] - k` 的左端点 `l`，且 `l` 要在上一个选取的子数组结束后。

使用哈希表存储：`{前缀和: (对应右端点, dp值)}`，贪心取最新的满足条件的左端点。

## Python 代码实现

### 方法一：贪心 + 前缀和哈希（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxNonOverlapping(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # pre_map: {前缀和 -> 最大的 dp 值}
        # dp[i]: 到位置 i 为止（不含i）的最多不重叠子数组数
        # 贪心：找最晚开始的满足条件子数组（等价于最早结束）

        pre_map = {0: 0}  # 前缀和 -> 对应位置 dp 值
        pre_sum = 0
        dp = 0  # 当前最优

        for i in range(n):
            pre_sum += nums[i]
            target = pre_sum - k
            if target in pre_map:
                # 找到一个以 i 结尾的和为 k 的子数组
                dp = max(dp, pre_map[target] + 1)
            # 更新哈希表：记录当前前缀和对应的最优 dp 值
            if pre_sum not in pre_map or pre_map[pre_sum] < dp:
                pre_map[pre_sum] = dp

        return dp
```

### 方法二：暴力 DP（O(n^2)，适合小数据）

```python
from typing import List

class Solution:
    def maxNonOverlapping(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * (n + 1)  # dp[i]: nums[0..i-1] 的最优解

        for i in range(1, n + 1):
            dp[i] = dp[i - 1]  # 不以 i 结尾
            cur_sum = 0
            for l in range(i, 0, -1):
                cur_sum += nums[l - 1]
                if cur_sum == k:
                    dp[i] = max(dp[i], dp[l - 1] + 1)

        return dp[n]
```

## 复杂度分析

- 时间复杂度：方法一 O(n)；方法二 O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心策略：尽量早地结束每个子数组，为后续留下更多空间
2. 前缀和将子数组和问题转化为两个前缀和之差
3. 哈希表记录"某前缀和对应的最优 DP 值"，一次遍历完成

## 易错点

1. 哈希表需要记录 dp 值而非仅仅位置，以正确传递状态
2. 需要保证选取的子数组不重叠（通过 DP 传递非重叠约束）
