## 题目描述

给你一个下标从 **0** 开始的整数数组 `hours`，其中 `hours[i]` 表示第 `i` 位员工工作的小时数，以及一个整数 `target`。

返回工作时间 **至少** `target` 小时的员工人数。

**示例 1：**
```
输入：hours = [0,1,2,3,4], target = 2
输出：3
解释：hours[2]=2, hours[3]=3, hours[4]=4 均 >= 2
```

**示例 2：**
```
输入：hours = [5,1,4,2,2], target = 6
输出：0
```

**提示：**
- `1 <= hours.length <= 50`
- `0 <= hours[i], target <= 10^5`

## 解题思路

简单统计，遍历数组，计算 `>= target` 的元素个数。

## Python 代码实现

### 方法一：列表推导式（推荐）

```python
from typing import List

class Solution:
    def numberOfEmployeesWhoMetTarget(self, hours: List[int], target: int) -> int:
        return sum(1 for h in hours if h >= target)
```

### 方法二：filter

```python
from typing import List

class Solution:
    def numberOfEmployeesWhoMetTarget(self, hours: List[int], target: int) -> int:
        return len([h for h in hours if h >= target])
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 条件是 `>= target`（至少），注意包含等于
2. Python `sum` + 条件生成器最简洁

## 易错点

1. 是 `>=`（至少），而不是 `>`（严格大于）
