## 题目描述

给你 `n` 枚硬币和一个正整数 `k`。你需要将这些硬币排列成若干行，其中第 `i` 行恰好有 `i` 枚硬币（阶梯形），且每行不超过 `k` 枚硬币。

返回将硬币恰好用完且满足上述条件的排列方案数（模 `10^9 + 7`）。

**示例 1：**

```
输入：n = 6, k = 3
输出：1
解释：唯一方案是第 1 行 1 枚，第 2 行 2 枚，第 3 行 3 枚，共 6 枚。
```

**示例 2：**

```
输入：n = 10, k = 5
输出：2
解释：
- 方案一：1 + 2 + 3 + 4 = 10（4 行）
- 方案二：1 + 2 + 3 + 4 = 10（不同 k 约束下的其他组合）
```

**提示：**
- `1 <= n <= 10^9`
- `1 <= k <= 10^4`

## 解题思路

前 `r` 行的总硬币数为 `r*(r+1)/2`，同时每行最多 `k` 枚，即行数 `r <= k`。

问题转化为：找满足 `r*(r+1)/2 = n` 且 `r <= k` 的正整数 `r` 的个数。

若 n 恰好等于某个三角数并且行数不超过 k，则该方案合法。

对于更通用的版本（非严格阶梯，允许不同填充方式），使用动态规划或数学组合。

## Python 代码实现

### 方法一：数学枚举（推荐）

```python
class Solution:
    def arrangeCoins(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        count = 0

        # 枚举行数 r，从 1 到 min(k, 约等于 sqrt(2n))
        r = 1
        while r * (r + 1) // 2 <= n and r <= k:
            if r * (r + 1) // 2 == n:
                count += 1
            r += 1

        return count % MOD
```

### 方法二：二分查找优化

```python
class Solution:
    def arrangeCoins(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        count = 0

        # 二分查找：找满足 r*(r+1)/2 == n 且 r <= k 的 r
        lo, hi = 1, min(k, int((2 * n) ** 0.5) + 2)

        for r in range(lo, hi + 1):
            total = r * (r + 1) // 2
            if total == n:
                count += 1
            elif total > n:
                break

        return count % MOD
```

### 方法三：动态规划（通用版）

```python
from typing import List

class Solution:
    def arrangeCoins(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i] = 使用恰好 i 枚硬币的方案数
        # 转移：dp[i] += dp[i - row]，其中 row 是当前行数
        dp = [0] * (n + 1)
        dp[0] = 1

        row = 1
        while row * (row + 1) // 2 <= n and row <= k:
            coins = row * (row + 1) // 2
            # 背包式 DP
            for j in range(n, coins - 1, -1):
                dp[j] = (dp[j] + dp[j - coins]) % MOD
            row += 1

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(sqrt(n))，枚举行数不超过 sqrt(2n)
- 空间复杂度：O(1)（方法一、二）；O(n)（方法三 DP）

## 关键点总结

1. 前 r 行的硬币总数是三角数 `r*(r+1)/2`。
2. 有效行数 `r` 不超过 `min(k, sqrt(2n))`，因此枚举范围有限。
3. 若 n 是某个三角数则有唯一合法行数，否则答案为 0。

## 易错点

1. 行数约束 `r <= k` 不能遗漏。
2. 浮点数精度问题：用整数运算 `r*(r+1)//2` 代替浮点。
