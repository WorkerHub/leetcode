## 题目描述

给你一个整数数组 `nums` 和正整数 `k`。

定义子数组的"值"：子数组中第一个和最后一个元素的较大值。

返回值等于 `k` 的子数组数量。

**示例 1：**
```
输入：nums = [2,3,1,2,4,3], k = 2
输出：6
```

**示例 2：**
```
输入：nums = [1,1,1,1], k = 1
输出：10
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 9`
- `1 <= k <= 9`

## 解题思路

枚举所有子数组，判断首尾较大值是否等于 `k`。

子数组值 = `max(nums[i], nums[j])`，其中 `i <= j`。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            for j in range(i, n):
                if max(nums[i], nums[j]) == k:
                    count += 1
        return count
```

### 方法二：枚举左端点优化

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            if nums[i] > k:
                break  # 左端点已经超过 k，后续不可能
            for j in range(i, n):
                val = max(nums[i], nums[j])
                if val == k:
                    count += 1
                elif val > k:
                    break  # 右端点超过 k
        return count
```

## 复杂度分析

- 时间复杂度：O(n^2)，n <= 100 完全可行
- 空间复杂度：O(1)

## 关键点总结

1. 子数组的值定义为首尾元素的最大值
2. 枚举所有 `(i, j)` 对（i <= j），包括单元素子数组（i == j）

## 易错点

1. 单元素子数组 `[nums[i]]`：首尾相同，值 = `nums[i]`
2. `max(nums[i], nums[j])` 不是整个子数组的最大值，只是首尾的最大值
