## 题目描述

给你一个字符串 `s` 和一个整数 `k`，请你统计并返回 `s` 中长度为 `k` 且其中没有重复字符的子串的个数。

**示例 1:**

```
输入: s = "havefunonleetcode", k = 5
输出: 6
解释: 
总共有 6 个满足题意的子串，分别是：
'havef','avefu','vefun','efuno','etcod','tcode'
```

**示例 2:**

```
输入: s = "home", k = 5
输出: 0
解释: 
注意：k 可能比 s 的长度大，这种情况下没有满足条件的子串。
```

**提示:**

- `1 <= s.length <= 10^4`
- `s` 由小写英文字母组成
- `1 <= k <= 10^4`

## 解题思路

这是一道典型的**滑动窗口**问题，核心思想是维护一个长度为 k 的窗口，并检查窗口内是否有重复字符。

**关键观察：**
1. 需要检查的是固定长度为 k 的子串
2. 每个子串内不能有重复字符
3. 不需要找到具体是哪些子串，只需要计数

**滑动窗口的思路：**
1. 使用哈希表（或数组）记录窗口内每个字符的出现次数
2. 维护一个长度为 k 的滑动窗口
3. 每次窗口滑动时：
   - 移除左边界的字符
   - 添加右边界的新字符
   - 检查窗口内是否有重复字符
4. 如果窗口内所有字符都唯一，计数器加 1

**判断窗口内字符是否唯一的方法：**
- 方法 1：检查哈希表的大小是否等于 k
- 方法 2：维护一个变量记录唯一字符的数量
- 方法 3：使用集合，检查集合大小是否等于 k

## Python 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
from typing import Dict

class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        """
        滑动窗口 + 哈希表解法
        时间复杂度: O(n)
        空间复杂度: O(k)
        """
        n = len(s)
        
        # 如果 k 大于字符串长度，或 k 大于 26（小写字母总数），不可能有满足条件的子串
        if k > n or k > 26:
            return 0
        
        count = 0
        char_count = {}  # 记录窗口内每个字符的出现次数
        
        # 初始化第一个窗口
        for i in range(k):
            char_count[s[i]] = char_count.get(s[i], 0) + 1
        
        # 检查第一个窗口
        if len(char_count) == k:
            count += 1
        
        # 滑动窗口
        for i in range(k, n):
            # 添加新字符（右边界）
            char_count[s[i]] = char_count.get(s[i], 0) + 1
            
            # 移除旧字符（左边界）
            left_char = s[i - k]
            char_count[left_char] -= 1
            if char_count[left_char] == 0:
                del char_count[left_char]
            
            # 检查当前窗口
            if len(char_count) == k:
                count += 1
        
        return count
```

### 方法二：滑动窗口 + 集合

```python
class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        """
        滑动窗口 + 集合解法
        时间复杂度: O(n * k)  # 每次窗口移动时创建新集合需要 O(k)
        空间复杂度: O(k)
        """
        n = len(s)
        
        if k > n or k > 26:
            return 0
        
        count = 0
        
        # 遍历所有长度为 k 的子串
        for i in range(n - k + 1):
            # 获取当前子串
            substring = s[i:i + k]
            # 使用集合判断是否有重复字符
            if len(set(substring)) == k:
                count += 1
        
        return count
```

### 方法三：滑动窗口 + Counter

```python
from collections import Counter

class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        """
        使用 Counter 的滑动窗口解法
        时间复杂度: O(n)
        空间复杂度: O(k)
        """
        n = len(s)
        
        if k > n or k > 26:
            return 0
        
        count = 0
        window = Counter(s[:k])  # 初始化第一个窗口
        
        # 检查第一个窗口
        if len(window) == k:
            count += 1
        
        # 滑动窗口
        for i in range(k, n):
            # 添加新字符
            window[s[i]] += 1
            
            # 移除旧字符
            window[s[i - k]] -= 1
            if window[s[i - k]] == 0:
                del window[s[i - k]]
            
            # 检查当前窗口
            if len(window) == k:
                count += 1
        
        return count
```

### 方法四：优化版滑动窗口（数组实现）

```python
class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        """
        使用数组代替哈希表的优化版本
        时间复杂度: O(n)
        空间复杂度: O(26) = O(1)
        """
        n = len(s)
        
        if k > n or k > 26:
            return 0
        
        count = 0
        char_freq = [0] * 26  # 记录每个字母的频率
        unique_count = 0      # 记录窗口内唯一字符的数量
        
        # 初始化第一个窗口
        for i in range(k):
            idx = ord(s[i]) - ord('a')
            if char_freq[idx] == 0:
                unique_count += 1
            char_freq[idx] += 1
        
        # 检查第一个窗口
        if unique_count == k:
            count += 1
        
        # 滑动窗口
        for i in range(k, n):
            # 添加新字符
            new_idx = ord(s[i]) - ord('a')
            if char_freq[new_idx] == 0:
                unique_count += 1
            char_freq[new_idx] += 1
            
            # 移除旧字符
            old_idx = ord(s[i - k]) - ord('a')
            char_freq[old_idx] -= 1
            if char_freq[old_idx] == 0:
                unique_count -= 1
            
            # 检查当前窗口
            if unique_count == k:
                count += 1
        
        return count
```

### 方法五：Python 简洁版

```python
class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        """
        Python 简洁写法
        时间复杂度: O(n * k)
        空间复杂度: O(k)
        """
        if k > len(s):
            return 0
        
        return sum(len(set(s[i:i+k])) == k for i in range(len(s) - k + 1))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 滑动窗口 + 哈希表 | O(n) | O(k) | 推荐解法，最优性能 |
| 滑动窗口 + 集合 | O(n * k) | O(k) | 每次创建集合需要 O(k) |
| 滑动窗口 + Counter | O(n) | O(k) | 代码简洁，性能优秀 |
| 数组实现 | O(n) | O(1) | 空间最优，只用 26 个元素 |
| Python 简洁版 | O(n * k) | O(k) | 代码最简单，但效率稍低 |

其中 n 是字符串 s 的长度。

## 关键点总结

1. **滑动窗口核心思想**：维护固定大小的窗口，每次移动一个位置，时间复杂度 O(n)
2. **判断重复的方法**：使用哈希表的大小判断是否有重复字符（大小等于 k 表示无重复）
3. **边界条件处理**：
   - k > n：不可能有满足条件的子串
   - k > 26：小写字母只有 26 个，不可能有 k 个不同字符
4. **空间优化**：可以用固定大小的数组（26个元素）代替哈希表
5. **窗口初始化**：先处理第一个窗口，然后从第 k 个字符开始滑动

## 易错点

1. **忘记检查 k > n 的情况**：如果 k 大于字符串长度，应该返回 0
2. **忘记检查 k > 26 的情况**：小写字母只有 26 个，k > 26 时不可能有满足条件的子串
3. **窗口边界错误**：
   - 错误：`for i in range(k, n + 1)`（会越界）
   - 正确：`for i in range(k, n)`
4. **集合创建开销**：每次创建 `set(s[i:i+k])` 需要 O(k) 时间，导致总复杂度 O(n*k)
5. **哈希表删除字符时的处理**：
   - 必须在计数为 0 时删除键，否则 `len(char_count)` 会不准确
6. **初始窗口的处理**：容易忘记检查第一个窗口是否满足条件
