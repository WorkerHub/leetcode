## 题目描述

给你一个由 `n` 个整数组成的数组 `nums`，和一个目标值 `target`。请你找出并返回满足下述全部条件且不重复的四元组 `[nums[a], nums[b], nums[c], nums[d]]`（若两个四元组元素一一对应，则认为两个四元组重复）：

- `0 <= a, b, c, d < n`
- `a`、`b`、`c` 和 `d` 互不相同
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按任意顺序返回答案。

**示例 1：**
```
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

**示例 2：**
```
输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]
```

## 解题思路

### 核心思想：排序 + 双层循环 + 双指针

这道题是「三数之和」的进阶版，思路类似：
1. **排序**：对数组排序，方便去重和使用双指针
2. **固定两个数**：用两层循环固定前两个数
3. **双指针**：在剩余数组中用双指针查找后两个数
4. **去重**：避免重复的四元组

**算法流程：**
1. 对数组进行排序
2. 第一层循环固定第一个数 `nums[i]`
3. 第二层循环固定第二个数 `nums[j]`（`j > i`）
4. 双指针在 `[j+1, n-1]` 范围内查找剩余两数
5. 四个位置都要去重

## Python 代码实现

### 方法：排序 + 双指针

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()  # 排序
        result = []
        n = len(nums)
        
        # 固定第一个数
        for i in range(n - 3):
            # 去重
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            # 剪枝：如果最小的四个数之和都大于target，后面不可能有解
            if nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target:
                break
            
            # 剪枝：如果当前数加上最大的三个数还小于target，跳过
            if nums[i] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target:
                continue
            
            # 固定第二个数
            for j in range(i + 1, n - 2):
                # 去重
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                
                # 剪枝
                if nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target:
                    break
                if nums[i] + nums[j] + nums[n - 2] + nums[n - 1] < target:
                    continue
                
                # 双指针查找剩余两个数
                left, right = j + 1, n - 1
                
                while left < right:
                    current_sum = nums[i] + nums[j] + nums[left] + nums[right]
                    
                    if current_sum == target:
                        result.append([nums[i], nums[j], nums[left], nums[right]])
                        
                        # 去重
                        while left < right and nums[left] == nums[left + 1]:
                            left += 1
                        while left < right and nums[right] == nums[right - 1]:
                            right -= 1
                        
                        left += 1
                        right -= 1
                    elif current_sum < target:
                        left += 1
                    else:
                        right -= 1
        
        return result
```

### 简化版（去掉部分剪枝）

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        result = []
        n = len(nums)
        
        for i in range(n - 3):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            for j in range(i + 1, n - 2):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                
                left, right = j + 1, n - 1
                
                while left < right:
                    total = nums[i] + nums[j] + nums[left] + nums[right]
                    
                    if total == target:
                        result.append([nums[i], nums[j], nums[left], nums[right]])
                        while left < right and nums[left] == nums[left + 1]:
                            left += 1
                        while left < right and nums[right] == nums[right - 1]:
                            right -= 1
                        left += 1
                        right -= 1
                    elif total < target:
                        left += 1
                    else:
                        right -= 1
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n³)
  - 排序：O(n log n)
  - 三层循环：第一层 O(n)，第二层 O(n)，第三层双指针 O(n)
  - 总体：O(n³)

- **空间复杂度**：O(log n)，排序所需的栈空间（不计结果数组）

## 关键点总结

1. **层次递进**：
   - 两数之和：一层循环或哈希表
   - 三数之和：一层循环 + 双指针（O(n²)）
   - 四数之和：两层循环 + 双指针（O(n³)）
   - n 数之和：(n-2)层循环 + 双指针

2. **去重四个位置**：
   - 第一个数：`if i > 0 and nums[i] == nums[i-1]: continue`
   - 第二个数：`if j > i+1 and nums[j] == nums[j-1]: continue`
   - 第三、四个数：找到解后跳过重复元素

3. **剪枝优化**（可选但推荐）：
   - 最小四数和 > target：`break`
   - 最大四数和 < target：`continue`

4. **注意溢出**：
   - Python 不会溢出，但 Java/C++ 需要用 `long` 类型

## 易错点

1. **去重条件**：
   - ❌ `if nums[j] == nums[j-1]` 会在 `j = i+1` 时误判
   - ✅ `if j > i+1 and nums[j] == nums[j-1]`

2. **循环范围**：
   - 第一层：`range(n - 3)` 保证至少有 4 个数
   - 第二层：`range(i + 1, n - 2)` 保证至少有 3 个数

3. **剪枝条件**：
   - 要用正确的索引（最小的、最大的）
