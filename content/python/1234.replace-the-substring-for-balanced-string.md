## 题目描述

有一个只含有 'Q', 'W', 'E', 'R' 四种字符，且长度为 n 的字符串。

假如在该字符串中，这四个字符都恰好出现 n/4 次，那么它就是一个「平衡字符串」。

给你一个这样的字符串 s，请通过「替换一个子串」的方式，使原字符串 s 变成一个「平衡字符串」。

你可以用和「待替换子串」长度相同的任何其他字符串来完成替换。

请返回待替换子串的最小可能长度。

如果原字符串自身就是一个平衡字符串，则返回 0。

示例 1：
```
输入：s = "QWER"
输出：0
解释：s 已经是平衡的了。
```

示例 2：
```
输入：s = "QQWE"
输出：1
解释：我们需要把一个 'Q' 替换成 'R'，这样得到的 "RQWE" (或 "QRWE") 是平衡的。
```

示例 3：
```
输入：s = "QQQW"
输出：2
解释：我们可以把前面的 "QQ" 替换成 "ER"。
```

示例 4：
```
输入：s = "QQQQ"
输出：3
解释：我们可以替换后 3 个 'Q'，使 s = "QWER"。
```

提示：
- `1 <= s.length <= 10^5`
- `s.length` 是 4 的倍数
- `s` 中只含有 'Q', 'W', 'E', 'R' 四种字符

## 解题思路

这道题的关键insight是：我们需要替换的子串，应该包含所有"多余"的字符。

核心思路：
1. 统计每个字符的出现次数，计算每个字符多余的数量
2. 使用滑动窗口找到最小的子串，使得子串外的所有字符数量都 <= n/4
3. 如果子串外的所有字符都不超过 n/4，那么我们可以通过替换子串内的字符来平衡整个字符串

滑动窗口的判断条件：
- 窗口外的字符计数都 <= n/4
- 等价于：窗口内包含了所有多余的字符

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import Counter

class Solution:
    def balancedString(self, s: str) -> int:
        """
        使用滑动窗口找到最小的需要替换的子串
        
        Args:
            s: 输入字符串
            
        Returns:
            最小替换子串长度
        """
        n = len(s)
        target = n // 4  # 每个字符应该出现的次数
        
        # 统计每个字符的出现次数
        count = Counter(s)
        
        # 如果已经平衡，返回 0
        if all(count[c] <= target for c in 'QWER'):
            return 0
        
        # 使用滑动窗口找最小子串
        left = 0
        min_len = n
        
        for right in range(n):
            # 移入右边界的字符
            count[s[right]] -= 1
            
            # 尝试收缩左边界
            while left <= right and all(count[c] <= target for c in 'QWER'):
                min_len = min(min_len, right - left + 1)
                # 移出左边界的字符
                count[s[left]] += 1
                left += 1
        
        return min_len
```

### 方法二：更清晰的写法

```python
class Solution:
    def balancedString(self, s: str) -> int:
        """
        滑动窗口的另一种写法
        """
        n = len(s)
        target = n // 4
        count = {'Q': 0, 'W': 0, 'E': 0, 'R': 0}
        
        # 统计频率
        for c in s:
            count[c] += 1
        
        # 已经平衡
        if max(count.values()) <= target:
            return 0
        
        # 滑动窗口
        left = 0
        result = n
        
        for right in range(n):
            count[s[right]] -= 1
            
            # 收缩窗口
            while left < n and max(count.values()) <= target:
                result = min(result, right - left + 1)
                count[s[left]] += 1
                left += 1
        
        return result
```

### 方法三：使用辅助函数

```python
from collections import Counter

class Solution:
    def balancedString(self, s: str) -> int:
        """
        使用辅助函数判断是否满足条件
        """
        n = len(s)
        target = n // 4
        count = Counter(s)
        
        def is_valid() -> bool:
            """检查窗口外的字符是否都不超过 target"""
            return all(count[c] <= target for c in 'QWER')
        
        if is_valid():
            return 0
        
        left = 0
        min_len = n
        
        for right in range(n):
            # 窗口包含 s[right]，所以窗口外的 s[right] 减少
            count[s[right]] -= 1
            
            # 尝试收缩
            while is_valid():
                min_len = min(min_len, right - left + 1)
                count[s[left]] += 1
                left += 1
        
        return min_len
```

### 方法四：优化的检查

```python
class Solution:
    def balancedString(self, s: str) -> int:
        """
        只跟踪超出的字符
        """
        n = len(s)
        target = n // 4
        count = [0] * 128  # ASCII
        
        for c in s:
            count[ord(c)] += 1
        
        # 计算每个字符超出的数量
        excess = {}
        for c in 'QWER':
            if count[ord(c)] > target:
                excess[c] = count[ord(c)] - target
        
        if not excess:
            return 0
        
        # 滑动窗口：找到包含所有超出字符的最小窗口
        window = {c: 0 for c in excess}
        left = 0
        result = n
        covered = 0  # 已经覆盖的超出字符种类数
        
        for right in range(n):
            c = s[right]
            if c in window:
                window[c] += 1
                if window[c] == excess[c]:
                    covered += 1
            
            # 尝试收缩
            while covered == len(excess):
                result = min(result, right - left + 1)
                
                left_char = s[left]
                if left_char in window:
                    if window[left_char] == excess[left_char]:
                        covered -= 1
                    window[left_char] -= 1
                left += 1
        
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是字符串长度，每个字符最多被访问两次
- 空间复杂度：O(1)，只使用固定大小的计数器（4个字符）

## 关键点总结

1. 理解题意：替换子串使得整个字符串平衡
2. 关键insight：子串外的字符都应该 <= n/4
3. 滑动窗口的收缩条件：窗口外所有字符都不超标
4. 窗口内的字符可以被任意替换
5. 优化：只需要跟踪超出的字符

## 易错点

1. 误解题意：以为要找包含所有字符的平衡子串
2. 滑动窗口的条件搞反：应该是窗口外的字符不超标
3. 忘记处理已经平衡的情况（返回 0）
4. 计数器的更新时机错误
5. 边界条件：n 很小或已经平衡
