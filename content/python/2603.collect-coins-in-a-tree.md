## 题目描述

给你一棵 `n` 个节点的无向树，节点编号 0 到 `n-1`，其中 `coins[i]` 表示节点 `i` 的金币数。每条边的收集方式如下：你可以选择树中任一节点出发，每次移动可以沿任意边移动，收集途经节点的所有金币，每条边最多经过两次（来回）。

返回收集所有金币所需的最少移动次数。

**示例 1：**
```
输入：coins = [1,0,0,0,0,1], edges = [[0,1],[1,2],[2,3],[3,4],[4,5]]
输出：2
```

**示例 2：**
```
输入：coins = [0,0,0,1,1,0,0,1], edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[5,6],[5,7]]
输出：6
```

**数据范围：**
- n == coins.length
- 1 <= n <= 3 * 10^4
- 0 <= coins[i] <= 1
- edges.length == n - 1
- 0 <= ai, bi < n

## 解题思路

拓扑排序剪枝：

1. **第一轮剪枝**：反复删除没有金币的叶子节点，直到所有叶子节点都有金币为止（消除无用分支）
2. **第二轮剪枝**：再删除两轮叶子节点（无论是否有金币），因为从任意节点出发，最多向外走 2 步就能收集完所有金币
3. 剩余树中每条边需要走两次，答案 = 剩余边数 * 2

## Python 代码实现

### 方法一：拓扑排序（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        # 建邻接表
        graph = [set() for _ in range(n)]
        for u, v in edges:
            graph[u].add(v)
            graph[v].add(u)

        # 第一步：删除所有没有金币的叶子节点（拓扑排序）
        queue = deque()
        for i in range(n):
            if len(graph[i]) == 1 and coins[i] == 0:
                queue.append(i)

        while queue:
            node = queue.popleft()
            if not graph[node]:
                continue
            neighbor = next(iter(graph[node]))
            graph[node].discard(neighbor)
            graph[neighbor].discard(node)
            # 若邻居变成没有金币的叶子，继续删除
            if len(graph[neighbor]) == 1 and coins[neighbor] == 0:
                queue.append(neighbor)

        # 第二步：再删除两次叶子节点（有金币也删）
        for _ in range(2):
            leaves = [i for i in range(n) if len(graph[i]) == 1]
            for leaf in leaves:
                if not graph[leaf]:
                    continue
                neighbor = next(iter(graph[leaf]))
                graph[leaf].discard(neighbor)
                graph[neighbor].discard(leaf)

        # 统计剩余边数
        remaining_edges = sum(len(adj) for adj in graph) // 2
        return remaining_edges * 2
```

### 方法二：入度数组实现拓扑排序

```python
from typing import List
from collections import deque

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        graph = [[] for _ in range(n)]
        degree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
            degree[u] += 1
            degree[v] += 1

        removed = [False] * n

        # 第一轮：删除无金币叶子
        queue = deque(i for i in range(n) if degree[i] == 1 and coins[i] == 0)
        while queue:
            u = queue.popleft()
            removed[u] = True
            for v in graph[u]:
                if not removed[v]:
                    degree[v] -= 1
                    if degree[v] == 1 and coins[v] == 0:
                        queue.append(v)

        # 第二轮：删两次有金币叶子
        for _ in range(2):
            queue = deque(i for i in range(n) if not removed[i] and degree[i] == 1)
            while queue:
                u = queue.popleft()
                removed[u] = True
                for v in graph[u]:
                    if not removed[v]:
                        degree[v] -= 1

        # 统计剩余边数（两端均未删除的边）
        edge_count = 0
        for u, v in edges:
            if not removed[u] and not removed[v]:
                edge_count += 1
        return edge_count * 2
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点最多被处理常数次
- 空间复杂度：O(n)，邻接表和辅助数组

## 关键点总结

1. 无金币叶子节点可以直接删除，不影响结果
2. 删除两轮叶子，因为收集时最远只需走到深度 2 的节点
3. 最终每条剩余边需要走两次（来回）

## 易错点

1. 第一步删无金币叶子时要递归地检查新产生的叶子
2. 节点数为 1 时（n=1）要特判
3. 剩余边数而非节点数
