## 题目描述

一个 `k x k` 的**幻方**是指每一行、每一列以及两条对角线的元素和都相同的 `k x k` 矩阵。

给你一个 `m x n` 的整数矩阵 `grid`，返回矩阵中**最大幻方的尺寸 k**。

**示例 1：**
```
输入：grid = [[7,1,4,5,6],[2,5,1,6,4],[1,5,4,3,2],[1,2,7,3,4]]
输出：3
解释：3x3 幻方在 grid[0..2][1..3]：
1 4 5
5 1 6
5 4 3
每行每列对角线之和均为 10
```

**示例 2：**
```
输入：grid = [[5,1,3,1],[9,3,3,1],[1,3,3,8]]
输出：2
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 50`
- `1 <= grid[i][j] <= 10^6`

## 解题思路

**前缀和 + 枚举**：

预计算每行和每列的前缀和，然后枚举所有可能的 k x k 子矩阵，验证是否为幻方。

验证幻方：
1. 所有行的和相等
2. 所有列的和相等
3. 两条对角线的和相等
4. 所有和等于同一个值

利用前缀和 O(1) 计算任意行列区间和。

## 代码实现

### 方法一：前缀和 + 枚举（推荐）

```python
from typing import List

class Solution:
    def largestMagicSquare(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 预计算行前缀和
        row_prefix = [[0] * (n + 1) for _ in range(m)]
        for i in range(m):
            for j in range(n):
                row_prefix[i][j + 1] = row_prefix[i][j] + grid[i][j]

        # 预计算列前缀和
        col_prefix = [[0] * n for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                col_prefix[i + 1][j] = col_prefix[i][j] + grid[i][j]

        def row_sum(r, c1, c2):
            """计算 grid[r][c1..c2] 的和"""
            return row_prefix[r][c2 + 1] - row_prefix[r][c1]

        def col_sum(c, r1, r2):
            """计算 grid[r1..r2][c] 的和"""
            return col_prefix[r2 + 1][c] - col_prefix[r1][c]

        def is_magic(r, c, k):
            """判断左上角 (r,c) 的 k×k 子矩阵是否为幻方"""
            # 计算第一行的和作为目标值
            target = row_sum(r, c, c + k - 1)

            # 验证所有行
            for i in range(r, r + k):
                if row_sum(i, c, c + k - 1) != target:
                    return False

            # 验证所有列
            for j in range(c, c + k):
                if col_sum(j, r, r + k - 1) != target:
                    return False

            # 验证主对角线（左上到右下）
            diag1 = sum(grid[r + t][c + t] for t in range(k))
            if diag1 != target:
                return False

            # 验证副对角线（右上到左下）
            diag2 = sum(grid[r + t][c + k - 1 - t] for t in range(k))
            if diag2 != target:
                return False

            return True

        # 从大到小枚举 k
        for k in range(min(m, n), 0, -1):
            for r in range(m - k + 1):
                for c in range(n - k + 1):
                    if is_magic(r, c, k):
                        return k

        return 1
```

### 方法二：预计算对角线前缀和

```python
from typing import List

class Solution:
    def largestMagicSquare(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 行前缀和
        row_pre = [[0] * (n + 1) for _ in range(m)]
        for i in range(m):
            for j in range(n):
                row_pre[i][j + 1] = row_pre[i][j] + grid[i][j]

        # 列前缀和
        col_pre = [[0] * n for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                col_pre[i + 1][j] = col_pre[i][j] + grid[i][j]

        ans = 1
        # 枚举所有 k×k 子矩阵
        for k in range(2, min(m, n) + 1):
            for r in range(m - k + 1):
                for c in range(n - k + 1):
                    target = row_pre[r][c + k] - row_pre[r][c]
                    ok = True

                    # 检查所有行
                    for i in range(r, r + k):
                        if row_pre[i][c + k] - row_pre[i][c] != target:
                            ok = False
                            break

                    if not ok:
                        continue

                    # 检查所有列
                    for j in range(c, c + k):
                        if col_pre[r + k][j] - col_pre[r][j] != target:
                            ok = False
                            break

                    if not ok:
                        continue

                    # 检查两条对角线
                    d1 = sum(grid[r + t][c + t] for t in range(k))
                    d2 = sum(grid[r + t][c + k - 1 - t] for t in range(k))
                    if d1 == target and d2 == target:
                        ans = k

        return ans
```

## 复杂度分析

- **时间复杂度**：O(min(m,n) * m * n * k)，枚举所有子矩阵并验证
- **空间复杂度**：O(m * n)，前缀和数组

## 关键点总结

1. 利用行列前缀和 O(1) 计算区间和，避免重复计算
2. 幻方需要验证：所有行相等、所有列相等、两条对角线相等
3. 从大到小枚举 k，找到第一个幻方即可返回

## 易错点

- 两条对角线：主对角线 `(r+t, c+t)` 和副对角线 `(r+t, c+k-1-t)`
- 数据范围较小（50×50），O(n^4) 也可接受
