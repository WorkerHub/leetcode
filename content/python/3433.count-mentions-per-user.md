## 题目描述

给你一个整数 `numberOfUsers` 和一个二维字符串数组 `events`。

每个 `events[i]` 可能是以下类型：
- `["MESSAGE", "timestamp", "mentions_string"]`：在时刻 timestamp 发送消息，mentions_string 是被 @ 的用户列表（空格分隔），可能包含 `"ALL"`（@所有用户）或 `"HERE"`（@所有在线用户）
- `["OFFLINE", "timestamp", "userId"]`：userId 在时刻 timestamp 离线（60 时间单位后上线）

初始所有用户在线。

返回每个用户被 @ 的次数数组。

**示例：**

```
输入：numberOfUsers = 2, events = [["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","71","HERE"]]
输出：[2,2]
```

**提示：**
- `1 <= numberOfUsers <= 100`
- `1 <= events.length <= 100`

## 解题思路

模拟过程：
1. 按时间戳排序事件（同时间戳时 OFFLINE 先处理）
2. 维护每个用户的在线状态（上线时间）
3. 处理每个事件：
   - OFFLINE：记录用户离线，并设置重新上线时间（当前时间 + 60）
   - MESSAGE + ALL：所有用户 @次数 +1
   - MESSAGE + HERE：所有当前在线用户 @次数 +1
   - MESSAGE + 用户列表：对应用户 @次数 +1

## Python 代码实现

### 方法一：模拟排序处理（推荐）

```python
from typing import List

class Solution:
    def countMentions(self, numberOfUsers: int, events: List[List[str]]) -> List[int]:
        # 按时间排序，OFFLINE 事件优先（同时间戳时先处理离线）
        events.sort(key=lambda x: (int(x[1]), x[0] == "MESSAGE"))

        mentions = [0] * numberOfUsers
        # offline_until[i] = 用户 i 的重新上线时间（若 <= 当前时间则在线）
        offline_until = [0] * numberOfUsers  # 初始全部在线（0 <= 任何时间戳）

        for event in events:
            event_type = event[0]
            timestamp = int(event[1])

            if event_type == "OFFLINE":
                user_id = int(event[2])
                offline_until[user_id] = timestamp + 60

            elif event_type == "MESSAGE":
                mention_str = event[2]

                if mention_str == "ALL":
                    # @所有用户
                    for i in range(numberOfUsers):
                        mentions[i] += 1

                elif mention_str == "HERE":
                    # @当前在线用户
                    for i in range(numberOfUsers):
                        if offline_until[i] <= timestamp:
                            mentions[i] += 1

                else:
                    # 具体用户列表
                    for uid_str in mention_str.split():
                        uid = int(uid_str[2:])  # 去掉 "id" 前缀
                        mentions[uid] += 1

        return mentions
```

### 方法二：更健壮的实现

```python
from typing import List

class Solution:
    def countMentions(self, numberOfUsers: int, events: List[List[str]]) -> List[int]:
        # 解析并排序
        parsed = []
        for e in events:
            t = int(e[1])
            parsed.append((t, e[0], e[2]))

        # 同时间戳：OFFLINE 先于 MESSAGE 处理
        parsed.sort(key=lambda x: (x[0], 0 if x[1] == "OFFLINE" else 1))

        mentions = [0] * numberOfUsers
        offline_until = [-1] * numberOfUsers  # -1 表示一直在线

        for t, etype, data in parsed:
            if etype == "OFFLINE":
                uid = int(data)
                offline_until[uid] = t + 60

            else:  # MESSAGE
                if data == "ALL":
                    for i in range(numberOfUsers):
                        mentions[i] += 1

                elif data == "HERE":
                    for i in range(numberOfUsers):
                        # 在线条件：offline_until[i] <= t（或从未离线）
                        if offline_until[i] <= t:
                            mentions[i] += 1

                else:
                    users = data.split()
                    for u in users:
                        uid = int(u[2:])  # "idX" -> X
                        mentions[uid] += 1

        return mentions
```

## 复杂度分析

- 时间复杂度：O(m log m + m * n)，m 为事件数，n 为用户数
- 空间复杂度：O(n + m)

## 关键点总结

1. 事件按时间戳排序，同时间戳时 OFFLINE 优先处理
2. 用户离线后 60 个时间单位后重新上线
3. HERE 只 @ 当前在线用户，ALL 不区分在线状态

## 易错点

1. 用户 ID 以 "id" 开头，需要去掉前缀再转换为整数
2. 同时间戳时，OFFLINE 事件先于 MESSAGE 处理（题目要求）
3. 用户 offline_until 初始为 0 或 -1（表示一直在线），当 offline_until[i] <= 当前时间时表示在线
