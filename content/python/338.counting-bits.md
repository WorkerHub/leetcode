## 题目描述

给你一个整数 `n`，对于 `0 <= i <= n` 中的每个 `i`，计算其二进制表示中 `1` 的个数，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。

**示例 1:**

```
输入：n = 2
输出：[0,1,1]
解释：
0 --> 0
1 --> 1
2 --> 10
```

**示例 2:**

```
输入：n = 5
输出：[0,1,1,2,1,2]
解释：
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

**提示:**

- `0 <= n <= 10^5`

**进阶:**

- 很容易就能实现时间复杂度为 `O(n log n)` 的解决方案，你可以在线性时间复杂度 `O(n)` 内用一趟扫描解决此问题吗？
- 你能不使用任何内置函数解决此问题吗？（如，C++ 中的 `__builtin_popcount`）

## 解题思路

这道题有多种解法，从暴力到优化，核心是找到**递推关系**。

### 思路一：动态规划（最低位）

**观察规律**：
- `i` 的二进制表示中 1 的个数 = `i // 2` 的二进制表示中 1 的个数 + `i % 2`
- 即：`dp[i] = dp[i >> 1] + (i & 1)`

**原理**：
- `i >> 1` 是 `i` 右移一位（去掉最低位）
- `i & 1` 是 `i` 的最低位（0 或 1）

### 思路二：动态规划（最低设置位）

**观察规律**：
- `i & (i - 1)` 可以去掉 `i` 最右边的 1
- `dp[i] = dp[i & (i - 1)] + 1`

**原理**：
- `i & (i - 1)` 去掉最右边的 1
- 再加上被去掉的那个 1

### 思路三：动态规划（最高有效位）

**观察规律**：
- 找到小于等于 `i` 的最大 2 的幂 `highBit`
- `dp[i] = dp[i - highBit] + 1`

## Python 代码实现

### 方法一：动态规划（最低位）⭐

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        动态规划：dp[i] = dp[i >> 1] + (i & 1)
        """
        dp = [0] * (n + 1)
        
        for i in range(1, n + 1):
            # i 右移一位 + 最低位
            dp[i] = dp[i >> 1] + (i & 1)
        
        return dp
```

### 方法二：动态规划（最低设置位）

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        动态规划：dp[i] = dp[i & (i - 1)] + 1

```

### 方法三：动态规划（最高有效位）

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        动态规划：按 2 的幂分段
        """
        dp = [0] * (n + 1)
        highBit = 0
        
        for i in range(1, n + 1):
            # 如果 i 是 2 的幂，更新 highBit
            if i & (i - 1) == 0:
                highBit = i
            
            # dp[i] = dp[i - highBit] + 1
            dp[i] = dp[i - highBit] + 1
        
        return dp
```

### 方法四：Brian Kernighan 算法

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        Brian Kernighan 算法：每次去掉最右边的 1
        时间复杂度 O(n * k)，k 是二进制位数
        """
        def count_ones(x: int) -> int:
            count = 0
            while x:
                x &= x - 1  # 去掉最右边的 1
                count += 1
            return count
        
        return [count_ones(i) for i in range(n + 1)]
```

### 方法五：暴力解法（内置函数）

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        使用 Python 内置函数 bin().count('1')
        不符合进阶要求
        """
        return [bin(i).count('1') for i in range(n + 1)]
```

### 方法六：位运算统计

```python
from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        """
        逐位统计 1 的个数
        """
        def count_ones(x: int) -> int:
            count = 0
            while x:
                count += x & 1  # 检查最低位
                x >>= 1  # 右移一位
            return count
        
        return [count_ones(i) for i in range(n + 1)]
```

## 复杂度分析

**方法一/二/三：动态规划**

- **时间复杂度**：O(n)
  - 遍历 0 到 n，每次 O(1)
  
- **空间复杂度**：O(1)
  - 不考虑返回值的空间

**方法四/六：逐位统计**

- **时间复杂度**：O(n * log n)
  - 每个数字需要 O(log n) 时间统计 1 的个数
  
- **空间复杂度**：O(1)

**方法五：内置函数**

- **时间复杂度**：O(n * log n)
  - bin() 转换和 count() 都需要时间
  
- **空间复杂度**：O(1)

## 关键点总结

1. **三种 DP 递推关系**：
   - 最低位：`dp[i] = dp[i >> 1] + (i & 1)`
   - 最低设置位：`dp[i] = dp[i & (i - 1)] + 1`
   - 最高有效位：`dp[i] = dp[i - highBit] + 1`

2. **位运算技巧**：
   - `i >> 1`：右移一位，相当于 `i // 2`
   - `i & 1`：获取最低位
   - `i & (i - 1)`：去掉最右边的 1

3. **2 的幂判断**：`i & (i - 1) == 0`

4. **Brian Kernighan 算法**：`x &= x - 1` 去掉最右边的 1

5. **O(n) 优化**：利用已计算的结果，避免重复计算

## 易错点

1. **数组长度**：应该是 `n + 1`，包括 0

2. **初始值**：`dp[0] = 0`（0 的二进制中没有 1）

3. **位运算优先级**：
   - `i & 1` 需要加括号：`(i & 1)`
   - 否则可能与 `+` 的优先级冲突

4. **方法三的 highBit 更新**：
   - 只在 `i` 是 2 的幂时更新
   - 判断条件：`i & (i - 1) == 0`

5. **Brian Kernighan 算法**：
   - 是 `x &= x - 1`，不是 `x &= x + 1`
