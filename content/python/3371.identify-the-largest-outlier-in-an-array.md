## 题目描述

给你一个整数数组 `nums`，其中包含 `n-2` 个"普通数"、一个特殊数和一个异常值。

规则：`n-2` 个普通数的和等于特殊数，异常值与其他数不满足此规则。

找出哪个数是"最大的异常值"。

**理解：** 数组中有一个数是"特殊数 S"，还有一个"异常值 O"。去掉 S 和 O 后，剩余 n-2 个数之和等于 S。

找出最大的可能的 O（异常值）。

**示例：**
```
输入：nums = [2, 3, 5, 10]
输出：10
解释：去掉 10（异常值）和 5（特殊数），剩余 [2, 3] 之和 = 5 = 特殊数
```

**提示：**
- `3 <= nums.length <= 10^5`

## 解题思路

设总和为 `total`，去掉特殊数 `S` 和异常值 `O` 后，剩余和 = `S`。

因此：`total - S - O = S`，即 `O = total - 2*S`。

枚举每个数作为特殊数 `S`，计算 `O = total - 2*S`，检验 `O` 是否在数组中（且 O != S 或 S 在数组中出现多次）。

取所有合法的 `O` 中的最大值。

## Python 代码实现

### 方法一：哈希表枚举（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def getLargestOutlier(self, nums: List[int]) -> int:
        total = sum(nums)
        cnt = Counter(nums)
        ans = float('-inf')
        
        # 枚举每个数作为特殊数 S
        for S in cnt:
            O = total - 2 * S  # 异常值
            # 检验 O 是否在数组中（且 O 和 S 是不同的两个位置）
            if O in cnt:
                if O != S or cnt[O] >= 2:
                    ans = max(ans, O)
        
        return ans
```

### 方法二：遍历（等价实现）

```python
from typing import List
from collections import Counter

class Solution:
    def getLargestOutlier(self, nums: List[int]) -> int:
        total = sum(nums)
        freq = Counter(nums)
        best = float('-inf')
        
        for x in nums:
            # 假设 x 是特殊数 S
            outlier = total - 2 * x
            # 检查 outlier 是否在原数组中（去掉 x 一个后仍存在）
            freq[x] -= 1
            if freq.get(outlier, 0) > 0:
                best = max(best, outlier)
            freq[x] += 1
        
        return best
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表构建 + 枚举
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 公式推导：`O = total - 2 * S`。
2. 枚举每个数作为特殊数 S，计算对应的异常值 O。
3. 验证 O 在数组中存在（注意 O 和 S 可以相等，但需要数组中有至少两个该值）。

## 易错点

1. `O == S` 时，需要原数组中有至少两个该值（一个作为 S，一个作为 O）。
2. 取的是 O 的最大值，不是 S 的最大值。
3. 总和包含 S、O 和所有普通数，公式：`total - S - O = S` => `O = total - 2S`。
