## 题目描述

给定整数数组 `nums` 和整数 `k`，统计满足 `nums[i] * nums[j] == k`（`i < j`）的配对数量。

**示例 1：**
```
输入：nums = [1,2,3,4,6,12], k = 12
输出：4
解释：(1,12),(2,6),(3,4),(4,3) -> 下标对 (0,5),(1,4),(2,3),(3,2)，共 4 对。
     实际满足的下标对：(0,5):1*12=12, (1,4):2*6=12, (2,3):3*4=12，共 3 对。
     注意去重：(i,j) 中 i < j。
```

**示例 2：**
```
输入：nums = [2,4,2,1,4], k = 8
输出：3
解释：2*4=8，有 3 对满足条件的下标对。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i], k <= 10^9`

## 解题思路

哈希表统计。

遍历数组，对于每个 `nums[i]`：
1. 若 `k % nums[i] == 0`（`nums[i]` 是 `k` 的因数），则需要找之前出现过的 `k // nums[i]` 的数量。
2. 将当前 `nums[i]` 加入哈希表，记录其出现次数。

这样每个配对 `(i, j)` 只会在处理 `j` 时被统计一次（因为 `i < j`）。

## Python 代码实现

### 方法一：哈希表一次遍历（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countProductPairs(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        result = 0

        for num in nums:
            if k % num == 0:
                # 找之前出现的 k // num
                complement = k // num
                result += count[complement]
            # 将当前数加入哈希表
            count[num] += 1

        return result
```

### 方法二：暴力双重循环（适合小数组）

```python
from typing import List

class Solution:
    def countProductPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] * nums[j] == k:
                    result += 1
        return result
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表一次遍历
- 空间复杂度：O(n)，哈希表存储所有元素

## 关键点总结

1. 经典的"两数之积等于 k"用哈希表解决，类似于两数之和
2. 先检查是否整除（`k % num == 0`）再查找配对，避免浮点误差
3. 先查询再插入，自动保证 `i < j`

## 易错点

1. 注意是整数乘积，需要先判断整除关系
2. 一次遍历保证了不重复统计（先查后存）
3. 负数情况下需要特殊处理（本题 `nums[i] >= 1`）
