## 题目描述

你有一辆货运卡车，从仓库出发，向所有港口送货，最后返回仓库。你有一个货箱数组 `boxes` 和整数 `portsCount`、`maxBoxes`、`maxWeight`。

- `boxes[i] = [ports_i, weight_i]`，其中 `ports_i` 表示第 `i` 个货箱需要送到的港口，`weight_i` 是货箱的重量
- `portsCount` 是港口数量
- `maxBoxes` 是卡车每次行程最多能装的货箱数量
- `maxWeight` 是卡车每次行程的最大承重

送货规则：
- 卡车必须按顺序（从 `boxes[0]` 开始）装货
- 每次行程从仓库出发，在港口卸货，**最终返回仓库**
- 每次去一个新的港口需要行驶一次（代价为 1），最后返回仓库也需要 1 次

返回将所有箱子送完需要的**最少行程次数**。

**示例 1：**
```
输入：boxes = [[1,1],[2,1],[1,1]], portsCount = 2, maxBoxes = 3, maxWeight = 3
输出：4
解释：最优方案：行程 1 送 [1,1]（港口1），行程 2 送 [2,1]，行程 3 送 [1,1]，共 4 次行程
```

**提示：**
- `1 <= boxes.length <= 10^5`
- `1 <= portsCount, maxBoxes, maxWeight <= 10^5`
- `1 <= ports_i <= portsCount`
- `1 <= weight_i <= maxWeight`

## 解题思路

设 `dp[i]` 为送完前 `i` 个箱子需要的最少行程次数（`dp[0] = 0`）。

对于每次行程，设运送了 `boxes[j..i-1]`（`j` 从某个位置开始），则：
`dp[i] = dp[j] + cost(j, i) + 1`

其中 `cost(j, i)` 是运送 `j` 到 `i-1` 这批货箱，在港口间转移的次数（相邻不同港口时需要+1）。

设 `diff[i]` = `boxes[i][0] != boxes[i-1][0]`（相邻货箱是否去不同港口），则 `cost(j, i) = sum(diff[j+1..i-1])`。

用前缀和记录 `diff_sum`，转移方程变为：
`dp[i] = dp[j] + diff_sum[i] - diff_sum[j+1] + 1`
`dp[i] = (dp[j] - diff_sum[j+1]) + diff_sum[i] + 1`

用单调队列维护 `dp[j] - diff_sum[j+1]` 的最小值，同时保证 `j` 在合法范围内。

## 代码实现

### 方法一：动态规划 + 单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def boxDelivering(self, boxes: List[List[int]], portsCount: int, maxBoxes: int, maxWeight: int) -> int:
        n = len(boxes)
        # diff[i] 表示 boxes[i] 和 boxes[i-1] 是否送不同的港口（i >= 1）
        # diff_sum[i] = diff[1] + diff[2] + ... + diff[i-1]（前缀和）
        diff_sum = [0] * (n + 1)
        for i in range(1, n):
            diff_sum[i] = diff_sum[i - 1] + (1 if boxes[i][0] != boxes[i - 1][0] else 0)
        diff_sum[n] = diff_sum[n - 1]  # 最后一段不需要再加

        # weight_sum[i] = boxes[0..i-1] 的重量前缀和
        weight_sum = [0] * (n + 1)
        for i in range(n):
            weight_sum[i + 1] = weight_sum[i] + boxes[i][1]

        # dp[i] 表示送完前 i 个箱子的最少行程数
        # dp[i] = dp[j] + diff_sum[i-1] - diff_sum[j] + 2
        # 其中 j 满足：i-j <= maxBoxes, weight_sum[i]-weight_sum[j] <= maxWeight
        dp = [0] * (n + 1)
        # 单调队列存下标 j，维护 dp[j] - diff_sum[j] 的最小值
        dq = deque()
        dq.append(0)

        for i in range(1, n + 1):
            # 移除不满足约束的队首元素
            while dq and (i - dq[0] > maxBoxes or
                          weight_sum[i] - weight_sum[dq[0]] > maxWeight):
                dq.popleft()

            # dp[i] = min(dp[j] - diff_sum[j]) + diff_sum[i-1] + 2
            j = dq[0]
            dp[i] = dp[j] - diff_sum[j] + diff_sum[i - 1] + 2

            # 维护单调队列（单调递增，保留最小的 dp[j] - diff_sum[j]）
            val = dp[i] - diff_sum[i]
            while dq and dp[dq[-1]] - diff_sum[dq[-1]] >= val:
                dq.pop()
            dq.append(i)

        return dp[n]
```

### 方法二：DP + 暴力优化（适合理解）

```python
from typing import List

class Solution:
    def boxDelivering(self, boxes: List[List[int]], portsCount: int, maxBoxes: int, maxWeight: int) -> int:
        n = len(boxes)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        # 前缀重量和
        weight_sum = [0] * (n + 1)
        for i in range(n):
            weight_sum[i + 1] = weight_sum[i] + boxes[i][1]

        # 维护滑动窗口内的最优 j（这里简化为 O(n) 滑动窗口）
        left = 0  # 窗口左边界
        # 用一个简单的前缀差计数代替全部暴力
        # 此处给出简化版（接近 O(n) 但最坏 O(n^2)，仅用于理解）
        for i in range(1, n + 1):
            # 维护 left，使得 [left, i) 满足约束
            while (i - left > maxBoxes or
                   weight_sum[i] - weight_sum[left] > maxWeight):
                left += 1
            # 枚举合法的 j（此处直接找最优，实际需单调队列）
            best = INF
            temp_diff = 0
            prev_port = None
            for j in range(i - 1, left - 1, -1):
                if j < i - 1:
                    if boxes[j][0] != (prev_port or boxes[j + 1][0]):
                        temp_diff += 1
                best = min(best, dp[j] - temp_diff)
                prev_port = boxes[j][0]
            # 这里只是示意，实际应用方法一
            dp[i] = best + temp_diff + 2  # 不准确，仅为结构示意

        return dp[n]
```

## 复杂度分析

**方法一（单调队列 DP）：**
- 时间复杂度：O(n)，每个元素入队出队最多一次
- 空间复杂度：O(n)，存储 dp 数组和辅助数组

## 关键点总结

1. 关键等式：`cost(j, i)` 可以用差分前缀和表示
2. 通过变形 `dp[i] = (dp[j] - diff_sum[j]) + diff_sum[i-1] + 2`，将 j 相关部分提取到括号内
3. 单调队列维护括号内表达式的最小值，同时用双指针维护合法窗口
4. 最终答案是 `dp[n]`（送完所有 n 个箱子）

## 易错点

1. `diff_sum` 的下标定义要仔细，避免差一错误
2. 每次行程的代价是"港口切换次数 + 1（返回仓库）"，即最终要 +2
3. 单调队列出队条件同时要检查 `maxBoxes` 和 `maxWeight` 两个约束
