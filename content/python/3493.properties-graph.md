## 题目描述

给你一个二维整数数组 `properties`，其中 `properties[i]` 是第 i 个元素的属性集合。

如果两个元素 i 和 j 的属性集合有至少 2 个公共属性，则在它们之间添加一条边。

返回这个属性图中**连通分量**的数量。

**示例：**

```
输入：properties = [[1,2],[1,2,3],[2,3],[4]]
输出：2
解释：
0-1 有公共属性 {1,2}（2个），相连
1-2 有公共属性 {2,3}（2个），相连
3 无连接
连通分量：{0,1,2} 和 {3}，共 2 个
```

**提示：**
- `1 <= properties.length <= 100`
- `1 <= properties[i].length <= 10`
- `1 <= properties[i][j] <= 100`

## 解题思路

构建图：对每对 (i, j) 计算公共属性数，若 >= 2 则连边。
然后用并查集或 BFS/DFS 统计连通分量数。

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1

    def count_components(self):
        return len(set(self.find(i) for i in range(len(self.parent))))

class Solution:
    def numberOfComponents(self, properties: List[List[int]], k: int) -> int:
        n = len(properties)
        sets = [set(p) for p in properties]
        uf = UnionFind(n)

        for i in range(n):
            for j in range(i + 1, n):
                if len(sets[i] & sets[j]) >= k:
                    uf.union(i, j)

        return uf.count_components()
```

### 方法二：BFS/DFS

```python
from typing import List

class Solution:
    def numberOfComponents(self, properties: List[List[int]], k: int) -> int:
        n = len(properties)
        sets = [set(p) for p in properties]

        # 构建邻接表
        adj = [[] for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                if len(sets[i] & sets[j]) >= k:
                    adj[i].append(j)
                    adj[j].append(i)

        # BFS 统计连通分量
        visited = [False] * n
        components = 0

        for start in range(n):
            if not visited[start]:
                components += 1
                queue = [start]
                visited[start] = True
                while queue:
                    node = queue.pop()
                    for neighbor in adj[node]:
                        if not visited[neighbor]:
                            visited[neighbor] = True
                            queue.append(neighbor)

        return components
```

### 方法三：矩阵连通性

```python
from typing import List

class Solution:
    def numberOfComponents(self, properties: List[List[int]], k: int) -> int:
        n = len(properties)
        sets = [set(p) for p in properties]

        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        for i in range(n):
            for j in range(i + 1, n):
                if len(sets[i] & sets[j]) >= k:
                    union(i, j)

        return len({find(i) for i in range(n)})
```

## 复杂度分析

- 时间复杂度：O(n^2 * p)，n 为元素数，p 为属性集合大小，并查集近似 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 集合交集：Python 的 `set & set` 操作计算公共属性
2. 并查集：高效统计连通分量
3. 阈值 k（题目固定为 2）：公共属性数 >= k 时连边

## 易错点

1. 注意 k 的值（本题为 2），代码中要参数化
2. 集合求交集用 `&` 操作符或 `intersection()`
3. 连通分量数 = 不重复的根节点数
