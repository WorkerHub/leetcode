## 题目描述

给你一个整数 `n`，请你返回一个含 `n` 个字符的字符串，其中**每种字符**在该字符串中都恰好出现**奇数次**。

返回的字符串必须只含小写英文字母。注意，不需要考虑字符串的唯一性。

**示例 1：**
```
输入：n = 4
输出："pppz"
解释："pppz" 包含两种字符，'p' 出现 3 次，'z' 出现 1 次，均为奇数次。
```

**示例 2：**
```
输入：n = 2
输出："xy"
解释："xy" 包含两种字符，各出现 1 次，均为奇数次。
```

**示例 3：**
```
输入：n = 7
输出："holasss"
```

**提示：**
- `1 <= n <= 500`

## 解题思路

### 核心思想

本题最简单的策略是**只使用最多2种字符**：

- **n 为奇数**：直接返回 `n` 个 `'a'`，因为 `n` 本身是奇数。
- **n 为偶数**：返回 `(n-1)` 个 `'a'` 加 1 个 `'b'`。
  - `n-1` 为奇数（偶数减1是奇数），`'a'` 出现奇数次。
  - `'b'` 出现1次，1是奇数次。

这两种情况都满足"每种字符均出现奇数次"的条件。

### 方法一：直接构造（推荐）

根据奇偶性选择一或两种字符。

### 方法二：三元表达式简化

## Python 代码实现

### 方法一：if-else 直接构造（推荐，最清晰）

```python
class Solution:
    def generateTheString(self, n: int) -> str:
        if n % 2 == 1:
            # n 是奇数：直接返回 n 个 'a'
            # 只有一种字符 'a'，出现 n 次（奇数次）
            return 'a' * n
        else:
            # n 是偶数：返回 (n-1) 个 'a' 和 1 个 'b'
            # 'a' 出现 n-1 次（奇数次），'b' 出现 1 次（奇数次）
            return 'a' * (n - 1) + 'b'
```

### 方法二：三元表达式（简洁版）

```python
class Solution:
    def generateTheString(self, n: int) -> str:
        # n 奇数：全 'a'；n 偶数：(n-1) 个 'a' + 1 个 'b'
        return 'a' * n if n % 2 == 1 else 'a' * (n - 1) + 'b'
```

### 方法三：通用思路（可处理更多字符种类）

```python
class Solution:
    def generateTheString(self, n: int) -> str:
        # 通用方法：尝试先放1个'b'，剩余n-1个全用'a'
        # 若 n-1 为奇数（即 n 为偶数），则 'a' 出现 n-1（奇）次，'b' 出现 1（奇）次
        # 若 n 为奇数，直接全用 'a'
        if n % 2 == 0:
            # 偶数长度：1个'b' + (n-1)个'a'，n-1为奇数
            return 'b' + 'a' * (n - 1)
        else:
            # 奇数长度：n个'a'，出现奇数次
            return 'a' * n
```

### 方法四：利用 Python 的负索引技巧（函数式风格）

```python
class Solution:
    def generateTheString(self, n: int) -> str:
        # 若 n 为奇数，extra = ''；若 n 为偶数，extra = 'b'
        # 对应：'a' * n 或 'a' * (n-1) + 'b'
        extra = '' if n % 2 else 'b'
        return 'a' * (n - len(extra)) + extra
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接构造 | O(n) | O(n) |

- **时间复杂度**：O(n)，构造长度为 n 的字符串需要 O(n)。
- **空间复杂度**：O(n)，输出字符串的长度为 n。

## 关键点总结

1. **奇偶分情况**：n 的奇偶性决定了策略，奇数时全用一种字符即可。
2. **偶数情况用两种字符**：一种 n-1 个（奇数），另一种 1 个（奇数），总长度 n。
3. **不要使用两种字符来处理奇数 n**：如果 n 是奇数，用两种字符（如 k 个和 n-k 个），那么 k 和 n-k 中至少一个是偶数，不满足条件。
4. 题目只要求每种字符出现奇数次，不要求字符串唯一，策略越简单越好。
5. Python 中 `'a' * n` 是 O(n) 操作，直接高效。

## 易错点

1. **偶数情况不能直接全用 'a'**：n 个 'a' 时，'a' 出现 n 次，若 n 是偶数则不满足奇数次条件。
2. **'a' * (n-1) + 'b' 中，n-1 必须是奇数**：当 n 是偶数时，n-1 是奇数，这才正确。若 n 是奇数，n-1 是偶数，不能使用这个策略。
3. **不要用两种字符平均分**：比如 n=4 时用 2 个 'a' 和 2 个 'b'，'a' 和 'b' 都出现 2 次（偶数），错误！
