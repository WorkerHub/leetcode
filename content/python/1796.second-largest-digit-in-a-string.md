## 题目描述

给你一个混合字符串 `s`，请你返回 `s` 中**第二大**的数字，如果不存在第二大的数字，请你返回 `-1`。

**混合字符串**由小写英文字母和数字组成。

**示例 1：**
```
输入：s = "dfa12321afd"
输出：2
解释：出现在 s 中的数字有 [1, 2, 3]，第二大的数字是 2
```

**示例 2：**
```
输入：s = "abc1111"
输出：-1
解释：出现在 s 中的数字只有 [1]，没有第二大的数字
```

**提示：**
- `1 <= s.length <= 500`
- `s` 只包含小写英文字母和数字

## 解题思路

提取字符串中所有数字字符，去重后排序，返回第二大的值；若不足两个不同数字则返回 -1。

或者只维护最大值和第二大值两个变量，一次遍历完成。

## 代码实现

### 方法一：集合去重 + 排序（推荐，简洁）

```python
class Solution:
    def secondHighest(self, s: str) -> int:
        # 提取所有不同的数字
        digits = sorted(set(int(c) for c in s if c.isdigit()), reverse=True)
        return digits[1] if len(digits) >= 2 else -1
```

### 方法二：维护最大值和第二大值

```python
class Solution:
    def secondHighest(self, s: str) -> int:
        first = -1   # 最大值
        second = -1  # 第二大值

        for c in s:
            if c.isdigit():
                d = int(c)
                if d > first:
                    second = first
                    first = d
                elif d > second and d != first:
                    second = d

        return second
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，遍历字符串 + O(1) 排序（最多 10 个数字）
- 空间复杂度：O(1)，集合最多 10 个元素

**方法二：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只关心**不同**的数字，需要去重
2. 数字字符：`c.isdigit()` 判断，`int(c)` 转换
3. 集合去重后，数字范围 0-9，最多 10 个，排序开销可以忽略

## 易错点

1. 如果所有数字都相同（如 "abc1111"），只有一个不同值，返回 -1
2. 方法二中更新第二大值的条件：`d > second` 且 `d != first`（严格不同）
3. 初始值 -1 刚好作为"不存在"的返回值，因为有效数字是 0-9
