## 题目描述

给你一个字符串 `s`，请你按照单词在 `s` 中的出现顺序将它们全部竖向排列。

单词是仅由非空格字符组成的字符串。此外，请你消除每一行中的空尾随空格。

**示例 1：**

```
输入：s = "HOW ARE YOU"
输出：["HAY","OR","WEU"]
解释：每个单词都竖向排列。
 "HAY"
 "OR"
 "WEU"
```

**示例 2：**

```
输入：s = "TO BE OR NOT TO BE"
输出：["TBONTB","OEROOE","   T"]
解释：题目允许有多个空格，但必须消除末尾空格。
```

**示例 3：**

```
输入：s = "CONTEST IS COMING"
输出：["CIC","OSO","N M","T I","E N","S G","T"]
```

**提示：**

- `1 <= s.length <= 200`
- `s` 仅含大写英文字母和空格
- 题目数据保证两个单词之间只有一个空格

## 解题思路

**模拟过程：**

1. 将字符串按空格分割得到单词列表
2. 找到最长单词的长度 `max_len`，这决定了结果列表的长度
3. 对第 `i` 行（第 `i` 列）：取每个单词的第 `i` 个字符（不足长度的用空格补齐），拼接成字符串
4. 去掉每行末尾的空格（`rstrip()`）

**直觉图解（s = "HOW ARE YOU"）：**

```
单词：HOW  ARE  YOU
      H    A    Y    -> "HAY"（第0行）
      O    R    O    -> "ORO" -> 去尾部空格 -> "ORO" 
      W    E    U    -> "WEU"（第2行）
```

**s = "TO BE OR NOT TO BE"：**

```
单词：TO BE OR NOT TO BE
      T  B  O  N   T  B   -> "TBONTB"
      O  E  R  O   O  E   -> "OEROOE"
         空 空 T   空 空   -> "   T  " -> rstrip -> "   T"
```

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()
        max_len = max(len(w) for w in words)
        
        result = []
        for i in range(max_len):
            # 构建第 i 列的字符串
            row = ''
            for word in words:
                # 如果单词长度超过 i，取第 i 个字符，否则用空格填充
                if i < len(word):
                    row += word[i]
                else:
                    row += ' '
            # 去除末尾空格
            result.append(row.rstrip())
        
        return result
```

### 方法二：zip_longest（Pythonic）

```python
from typing import List
from itertools import zip_longest

class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()
        # zip_longest 将多个列表并排，不足的位置用 fillvalue 填充
        # 转置：将每个"列"（同一行字符位置的字符）打包在一起
        result = []
        for chars in zip_longest(*words, fillvalue=' '):
            result.append(''.join(chars).rstrip())
        return result
```

### 方法三：列表推导式（最简洁）

```python
from typing import List
from itertools import zip_longest

class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()
        return [
            ''.join(chars).rstrip()
            for chars in zip_longest(*words, fillvalue=' ')
        ]
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为单词数，m 为最长单词长度
- **空间复杂度**：O(n * m)，结果列表的大小

## 关键点总结

1. 问题本质是矩阵转置：将"行=单词，列=字符位置"转换为"行=字符位置，列=单词"
2. 短单词的对应位置用空格补齐，再用 `rstrip()` 去掉末尾空格
3. `zip_longest(*words, fillvalue=' ')` 完美实现了"不等长列表的并排遍历"
4. `itertools.zip_longest` 是处理不等长序列的利器

## 易错点

1. **不能直接用 `zip`**：`zip` 遇到最短序列就停止，会截断较长的单词；应使用 `zip_longest`
2. **只去末尾空格**：只用 `rstrip()`，不能用 `strip()`（中间的空格是有意义的，代表该单词在该行没有字符）
3. **行数等于最长单词长度**：结果列表的行数由最长单词决定
