## 题目描述

给你 `numBottles` 满水瓶和 `numExchange` 个空瓶可以换一瓶满水。

每次你喝掉一瓶水，它就成为空瓶。你可以用 `numExchange` 个空瓶换取一瓶满水。

请你计算最多能喝多少瓶水。

**示例 1：**
```
输入：numBottles = 9, numExchange = 3
输出：13
解释：喝9瓶，换3瓶，再喝3瓶，换1瓶，再喝1瓶，共13瓶。
```

**示例 2：**
```
输入：numBottles = 15, numExchange = 4
输出：19
```

**提示：**
- `1 <= numBottles <= 100`
- `2 <= numExchange <= 100`

## 解题思路

### 方法一：模拟

直接模拟过程：每次将满水瓶全部喝掉，累加数量，然后用空瓶换新的满水瓶，直到空瓶不够换为止。

### 方法二：数学公式

设满水瓶数量为 `b`，每次换 1 瓶需要 `e` 个空瓶。
- 每次换瓶操作：消耗 `e` 个空瓶，得到 `1` 瓶满水（净消耗 `e-1` 个空瓶）
- 初始 `b` 个满水瓶，喝掉后有 `b` 个空瓶
- 可以换的轮数 = `(b - 1) // (e - 1)`（最后一轮换了之后喝完就没有多余空瓶了）
- 总饮水 = `b + (b - 1) // (e - 1)`

（此公式有边界情况，模拟更直观）

## 代码实现

### 方法一：模拟（推荐，最直观）

```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        total = 0
        empty = 0
        full = numBottles

        while full > 0:
            # 喝掉所有满瓶
            total += full
            empty += full
            full = 0
            # 用空瓶换满瓶
            full = empty // numExchange
            empty = empty % numExchange  # 剩余空瓶

        return total
```

### 方法二：数学公式

```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        # 初始 numBottles 瓶，每次 numExchange 个空瓶换 1 个满瓶
        # 喝完后空瓶 = numBottles，每轮换一次净消耗 (numExchange-1) 个空瓶
        # 可以多喝的瓶数 = (numBottles - 1) // (numExchange - 1)
        # （因为换的最后一轮需要至少 numExchange 个空瓶，但喝完后只剩余不足 numExchange 个）
        if numExchange == 1:
            return float('inf')  # 理论上无限（题目保证 numExchange >= 2）
        return numBottles + (numBottles - 1) // (numExchange - 1)
```

### 方法三：精简模拟

```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        total = numBottles
        empty = numBottles
        while empty >= numExchange:
            # 换出新瓶数
            new = empty // numExchange
            total += new
            # 更新空瓶数：换剩的 + 新喝的
            empty = empty % numExchange + new
        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(log_{e} N) | O(1) |
| 数学 | O(1) | O(1) |

模拟每轮空瓶数缩小为原来的 `1/e`，所以是对数级别。

## 关键点总结

1. 每次换瓶后，新喝的水瓶也变成空瓶，需要一并计入空瓶数
2. 模拟法简单直观，不容易出错
3. 数学公式：初始 b 个，多喝 `(b-1)//(e-1)` 个

## 易错点

- 换完新瓶后，新瓶喝掉也会变成空瓶（需要 `empty = empty % e + new`）
- 数学公式中 `(numBottles - 1)` 而不是 `numBottles`，否则边界情况会多算一个
