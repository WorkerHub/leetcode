## 题目描述

给你一个二维整数数组 `paint`，其中 `paint[i] = [start_i, end_i]`。每天你在 `[start_i, end_i)` 范围内涂色。

返回一个整数数组 `worklog`，其中 `worklog[i]` 是第 `i` 天**新涂**的区域长度（不含已涂区域）。

**示例 1：**
```
输入：paint = [[1,4],[4,7],[5,8]]
输出：[3,3,1]
解释：
- 第0天：[1,4) 全新，worklog[0]=3
- 第1天：[4,7) 全新，worklog[1]=3
- 第2天：[5,8) 中只有 [7,8) 是新的，worklog[2]=1
```

**提示：**
- `1 <= paint.length <= 10^5`
- `paint[i].length == 2`
- `0 <= start_i < end_i <= 5 * 10^4`

## 解题思路

**线段树或跳表（jump table）**

方法：维护一个"下一个未涂位置"的跳表 `next_new[i]`，初始 `next_new[i] = i`。当位置 i 被涂色后，`next_new[i] = next_new[i+1]`（跳过已涂区域）。

每天涂色 `[l, r)` 时，从 `next_new[l]` 开始，不断跳跃到下一个未涂位置，直到超过 r 为止，统计新涂面积。

## 代码实现

### 方法一：跳表（推荐，O(n * alpha(n))）

```python
from typing import List

class Solution:
    def amountPainted(self, paint: List[List[int]]) -> List[int]:
        MAX = 50001
        # next_new[i] = i 位置及其后第一个未涂色的位置
        next_new = list(range(MAX + 1))

        def find_next(x: int) -> int:
            # 路径压缩找到 x 之后第一个未涂位置
            if next_new[x] == x:
                return x
            next_new[x] = find_next(next_new[x])
            return next_new[x]

        result = []
        for l, r in paint:
            count = 0
            pos = find_next(l)
            while pos < r:
                count += 1
                next_new[pos] = pos + 1  # 标记为已涂，跳到下一个
                pos = find_next(pos + 1)
            result.append(count)

        return result
```

### 方法二：线段树（懒标记）

```python
from typing import List

class Solution:
    def amountPainted(self, paint: List[List[int]]) -> List[int]:
        MAX = 50001
        # 线段树懒标记
        covered = [False] * (MAX * 4)
        sum_tree = [0] * (MAX * 4)

        def build(node, start, end):
            sum_tree[node] = end - start
            if start + 1 == end:
                return
            mid = (start + end) // 2
            build(2*node, start, mid)
            build(2*node+1, mid, end)

        def query_and_cover(node, start, end, l, r):
            if covered[node]:
                return 0  # 全部已涂，新涂面积为 0
            if l >= end or r <= start:
                return 0
            if l <= start and end <= r:
                # 全区间，计算未涂面积后标记
                result = sum_tree[node]
                covered[node] = True
                sum_tree[node] = 0
                return result
            mid = (start + end) // 2
            left = query_and_cover(2*node, start, mid, l, r)
            right = query_and_cover(2*node+1, mid, end, l, r)
            sum_tree[node] = sum_tree[2*node] + sum_tree[2*node+1]
            if sum_tree[node] == 0:
                covered[node] = True
            return left + right

        build(1, 0, MAX)
        result = []
        for l, r in paint:
            result.append(query_and_cover(1, 0, MAX, l, r))
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 跳表 | O(n * alpha(n)) | O(MAX) |
| 线段树 | O(n log MAX) | O(MAX) |

## 关键点总结

1. 跳表法：用路径压缩快速跳过已涂区域，每个位置只被处理一次，总体近似 O(n)。
2. 线段树懒标记：整区间已涂时直接返回 0，否则递归查询未涂面积。
3. 跳表法代码更简洁，线段树更通用。

## 易错点

- 跳表的路径压缩：`next_new[x] = find_next(next_new[x])`，确保每次查询后都压缩路径。
- 线段树的懒标记传播需要正确处理。
