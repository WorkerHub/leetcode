## 题目描述

给你一个 `n` 个节点的无向图和边集 `edges`。对于每个节点 `i`（0 到 n-1），假设移除节点 `i` 及其所有关联边，计算剩余图的连通分量数。

返回一个长度为 `n` 的数组 `answer`，`answer[i]` 表示移除节点 `i` 后的连通分量数。

**示例 1：**

```
输入：n = 5, edges = [[0,1],[1,2],[3,4]]
输出：[2,2,2,3,3]
解释：
移除0：{1,2},{3,4} → 2个分量
移除1：{0},{2},{3,4} → 3个分量？
```

**提示：**

- `1 <= n <= 10^4`
- `0 <= edges.length <= min(n*(n-1)/2, 2*10^4)`

## 解题思路

暴力法：对每个节点，移除后重新做 DFS/BFS 计算连通分量数。

优化：利用关节点（割点）理论。移除割点会增加连通分量数；移除普通节点不会增加分量数（可能减少）。

但暴力在 n <= 10^4 时可接受：O(n * (n + E))。

## Python 代码实现

### 方法一：暴力 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = defaultdict(set)
        for u, v in edges:
            graph[u].add(v)
            graph[v].add(u)

        def count_cc(skip: int) -> int:
            visited = set([skip])
            count = 0
            for node in range(n):
                if node not in visited:
                    # DFS
                    stack = [node]
                    visited.add(node)
                    while stack:
                        curr = stack.pop()
                        for nb in graph[curr]:
                            if nb not in visited:
                                visited.add(nb)
                                stack.append(nb)
                    count += 1
            return count

        return [count_cc(i) for i in range(n)]
```

### 方法二：关节点优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 先计算原图连通分量数
        visited = [False] * n
        base_cc = 0
        for i in range(n):
            if not visited[i]:
                base_cc += 1
                stack = [i]
                visited[i] = True
                while stack:
                    u = stack.pop()
                    for v in graph[u]:
                        if not visited[v]:
                            visited[v] = True
                            stack.append(v)

        # 对每个节点，移除后重新计算
        result = []
        for skip in range(n):
            visited = [False] * n
            visited[skip] = True
            cc = 0
            for i in range(n):
                if not visited[i]:
                    cc += 1
                    stack = [i]
                    visited[i] = True
                    while stack:
                        u = stack.pop()
                        for v in graph[u]:
                            if not visited[v]:
                                visited[v] = True
                                stack.append(v)
            result.append(cc)
        return result
```

## 复杂度分析

- 时间复杂度：O(n * (n + E))
- 空间复杂度：O(n + E)

## 关键点总结

1. 移除节点等价于标记该节点为"已访问"再做 BFS/DFS
2. 每个节点做一次 BFS，计算从其他节点出发的连通分量数
3. 割点移除会增加连通分量数

## 易错点

1. 被移除的节点本身不计入连通分量
2. 移除节点意味着其所有邻边也消失
3. 连通分量数中不包含孤立的被移除节点
