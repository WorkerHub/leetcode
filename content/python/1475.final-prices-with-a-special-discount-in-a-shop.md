## 题目描述

给你一个数组 `prices`，其中 `prices[i]` 是商店里第 `i` 件商品的价格。

商店里正在进行促销活动，如果你要买第 `i` 件商品，那么你可以得到与 `prices[j]` 相等的折扣，其中 `j` 是满足 `j > i` 且 `prices[j] <= prices[i]` 的**最小下标**；如果没有满足条件的 `j`，你将没有任何折扣。

请你返回一个数组，数组中第 `i` 个元素是折扣后你购买商品 `i` 最终需要支付的价格。

**示例 1：**

```
输入：prices = [8,4,6,2,3]
输出：[4,2,4,2,3]
解释：
- 商品0：价格8，下标1的价格4<=8，折扣=4，实付=8-4=4
- 商品1：价格4，下标3的价格2<=4，折扣=2，实付=4-2=2
- 商品2：价格6，下标3的价格2<=6，折扣=2，实付=6-2=4（实际折扣是下标3的2）
  （注：下标3是第一个<=6的，因为下标2是它自己之后，下标3价格2<=6）
  等等，重新看：j>2且prices[j]<=6，j=3满足prices[3]=2<=6，折扣=2，实付=4
- 商品3：价格2，之后没有<=2的，实付=2
- 商品4：价格3，之后没有元素，实付=3
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：[1,2,3,4,5]
解释：后面没有更小或相等的价格，所以没有折扣。
```

**示例 3：**

```
输入：prices = [10,1,1,6]
输出：[9,0,1,6]
```

**提示：**
- `1 <= prices.length <= 500`
- `1 <= prices[i] <= 10^3`

---

## 解题思路

**问题本质：** 对每个元素，找其右边第一个**小于等于它**的元素，即"下一个不大于当前值的元素"。

**方法一：暴力法**
- 对每个 `i`，遍历 `j > i`，找第一个 `prices[j] <= prices[i]`。
- 时间复杂度 O(n^2)，数据范围 n=500 时可通过。

**方法二：单调栈（非递增栈）**
- 维护一个**单调不递增**的栈，存储下标。
- 当遍历到 `prices[i]` 时，如果栈顶元素的价格 `prices[stack[-1]] >= prices[i]`，说明 `i` 就是栈顶元素的折扣来源，弹出并计算折扣。
- 最终栈中剩余的元素没有折扣（折扣为 0）。

## Python 代码实现

### 方法一：暴力枚举（直观版）

```python
from typing import List

class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        n = len(prices)
        result = prices[:]  # 复制原数组

        for i in range(n):
            for j in range(i + 1, n):
                if prices[j] <= prices[i]:
                    result[i] = prices[i] - prices[j]  # 减去折扣
                    break  # 找到第一个即可

        return result
```

### 方法二：单调栈（推荐，高效版）

```python
from typing import List

class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        n = len(prices)
        result = prices[:]  # 复制原数组，默认无折扣
        stack = []  # 单调栈，存储下标，维护非递增顺序

        for i in range(n):
            # 当栈非空且当前价格 <= 栈顶价格时，栈顶元素找到了折扣
            while stack and prices[stack[-1]] >= prices[i]:
                idx = stack.pop()
                result[idx] = prices[idx] - prices[i]  # 折扣 = 当前价格

            stack.append(i)  # 将当前下标压栈

        # 栈中剩余元素没有折扣，result 已经是原价（无需修改）
        return result
```

### 方法三：从右到左遍历（另一种思路）

```python
from typing import List

class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        n = len(prices)
        result = prices[:]
        stack = []  # 单调栈，存储价格值

        for i in range(n - 1, -1, -1):
            # 弹出所有大于当前价格的元素（它们不能成为折扣来源）
            while stack and stack[-1] > prices[i]:
                stack.pop()

            # 栈顶（若有）就是 prices[i] 右边第一个 <= prices[i] 的值
            if stack:
                result[i] = prices[i] - stack[-1]

            stack.append(prices[i])  # 将当前价格入栈

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2) | O(1) |
| 单调栈（从左到右） | O(n) | O(n) |
| 单调栈（从右到左） | O(n) | O(n) |

- 单调栈方法每个元素**最多入栈和出栈各一次**，因此总时间复杂度为 O(n)。

## 图解示例

以 `prices = [8, 4, 6, 2, 3]` 为例，使用从左到右单调栈：

```
i=0, prices[0]=8: 栈空，直接入栈。栈=[0]
i=1, prices[1]=4: 4<=prices[0]=8，弹出0，result[0]=8-4=4。栈=[]，再入栈1。栈=[1]
i=2, prices[2]=6: 6>prices[1]=4，不弹出，入栈2。栈=[1,2]
i=3, prices[3]=2: 2<=prices[2]=6，弹出2，result[2]=6-2=4
                  2<=prices[1]=4，弹出1，result[1]=4-2=2
                  栈空，入栈3。栈=[3]
i=4, prices[4]=3: 3>prices[3]=2，不弹出，入栈4。栈=[3,4]

栈中剩余 [3,4]，无折扣，result[3]=2, result[4]=3 保持原价。
最终 result = [4, 2, 4, 2, 3]
```

## 关键点总结

1. 单调栈是解决"找下一个更小/更大元素"类问题的利器。
2. 本题要找"右边第一个不大于当前值"的元素，维护**非递增单调栈**。
3. 当新元素可以成为栈顶元素的折扣来源时（`prices[i] <= prices[stack[-1]]`），弹栈并计算折扣。
4. 栈中剩余元素（没有找到折扣）保持原价。

---

## 易错点

- **单调栈的方向**：本题是非递增栈（栈底到栈顶价格不递增），当新元素较小时弹栈。
- **等号处理**：条件是 `prices[i] <= prices[j]`，即相等时也算折扣，所以弹栈条件包含等号。
- **结果初始化**：`result = prices[:]` 复制原数组，栈中剩余元素无折扣自动保持原价。
