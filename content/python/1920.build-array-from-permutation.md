## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，它是 `[0, 1, 2, ..., n-1]` 的一个排列。

构建一个同样下标从 0 开始的数组 `ans`，其中对每个 `0 <= i < n` 有 `ans[i] = nums[nums[i]]`，返回 `ans`。

**示例 1：**
```
输入：nums = [0, 2, 1, 5, 3, 4]
输出：[0, 1, 2, 4, 5, 3]
解释：
ans[0] = nums[nums[0]] = nums[0] = 0
ans[1] = nums[nums[1]] = nums[2] = 1
ans[2] = nums[nums[2]] = nums[1] = 2
ans[3] = nums[nums[3]] = nums[5] = 4
ans[4] = nums[nums[4]] = nums[3] = 5
ans[5] = nums[nums[5]] = nums[4] = 3
```

**提示：**
- `1 <= nums.length <= 1000`
- `0 <= nums[i] < nums.length`
- `nums` 是 `[0, 1, ..., n-1]` 的排列

---

## 解题思路

### 核心思想：直接模拟

直接按定义构建答案数组：`ans[i] = nums[nums[i]]`。

进阶：能否在 O(1) 额外空间内完成？利用 `nums[i] < n`，可以在原数组中编码两个值：
- 将 `nums[i]` 编码为 `nums[i] + (nums[nums[i]] % n) * n`
- 恢复时：`ans[i] = nums[i] // n`

---

## 代码实现

### 方法一：新建数组（推荐，最直观）

```python
from typing import List

class Solution:
    def buildArray(self, nums: List[int]) -> List[int]:
        # 直接按定义构建答案
        return [nums[nums[i]] for i in range(len(nums))]
```

### 方法二：O(1) 空间原地操作（进阶）

```python
from typing import List

class Solution:
    def buildArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 第一遍：在原值上编码新值
        # nums[i] 的新值为 nums[nums[i]] % n（取模保留原值）
        # 编码：nums[i] += (nums[nums[i]] % n) * n
        for i in range(n):
            nums[i] += (nums[nums[i]] % n) * n
        # 第二遍：解码得到答案
        for i in range(n):
            nums[i] //= n
        return nums
```

### 方法三：zip + 列表推导

```python
from typing import List

class Solution:
    def buildArray(self, nums: List[int]) -> List[int]:
        # 等价写法
        ans = [0] * len(nums)
        for i, v in enumerate(nums):
            ans[i] = nums[v]
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(n) |
| 方法二 | O(n) | O(1)（原地） |
| 方法三 | O(n) | O(n) |

---

## 关键点总结

1. 题目定义非常直接：`ans[i] = nums[nums[i]]`
2. O(1) 空间技巧：利用 `nums[i] < n`，用 `nums[i] += new_val * n` 同时存储新旧值
3. 解码：`new_val = nums[i] // n`，原值：`nums[i] % n`

---

## 易错点

- O(1) 空间方法中，第一遍编码时 `nums[nums[i]] % n` 才是原始值（因为 nums[i] 可能已被修改）
- 注意 `nums[nums[i]]` 需要先取模以得到原值
