## 题目描述

给你两个长度分别 `n` 和 `m` 的整数数组 `nums` 和 `multipliers`，其中 `n >= m`，数组下标**从 1 开始**计数。

初始时，你的分数为 `0`。你需要执行恰好 `m` 步操作。在第 `i` 步操作（从 1 开始计数）中，需要：
- 选择数组 `nums` 开头处的元素或者末尾处的元素。
- 你选择的元素与 `multipliers[i]` 相乘，将乘积加到你的分数上。
- 将选择的元素从数组 `nums` 中删除。

请你返回执行 `m` 步操作后，你能得到的**最大分数**。

**示例 1：**
```
输入：nums = [1,2,3], multipliers = [3,2,1]
输出：14
解释：选 1（前端），再选3（后端），再选2（前端），3*1+2*3+2*1=3+6+5=14...
实际：multipliers[0]*nums[0]=3*1=3，multipliers[1]*nums[2]=2*3=6，multipliers[2]*nums[1]=1*2=2，共11? 最大是 14: 选3,3,1
```

**提示：**
- `n == nums.length`
- `m == multipliers.length`
- `1 <= m <= min(n, 300)`

## 解题思路

DP 定义：`dp[i][j]` 表示已进行 `i` 步操作，其中从前端取了 `j` 个（从后端取了 `i-j` 个）的最大分数。

转移：
- 从前端取第 `j` 个元素（第 0 到 j-1 共 j 个已取）：`dp[i][j] = dp[i-1][j-1] + nums[j-1] * multipliers[i-1]`
- 从后端取：`dp[i][j] = dp[i-1][j] + nums[n-(i-j)] * multipliers[i-1]`

## 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], multipliers: List[int]) -> int:
        n, m = len(nums), len(multipliers)
        
        # dp[i][j] = 第 i 步，从前取了 j 个时的最大分数
        # 后取数量 = i - j
        dp = [[float('-inf')] * (m + 1) for _ in range(m + 1)]
        dp[0][0] = 0
        
        ans = float('-inf')
        
        for i in range(1, m + 1):
            mult = multipliers[i - 1]
            for j in range(0, i + 1):
                back = i - j  # 从后取了 back 个
                if j > 0 and dp[i-1][j-1] != float('-inf'):
                    # 从前端取
                    dp[i][j] = max(dp[i][j], dp[i-1][j-1] + nums[j-1] * mult)
                if back > 0 and dp[i-1][j] != float('-inf'):
                    # 从后端取
                    dp[i][j] = max(dp[i][j], dp[i-1][j] + nums[n - back] * mult)
                
                if i == m:
                    ans = max(ans, dp[i][j])
        
        return ans
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumScore(self, nums: List[int], multipliers: List[int]) -> int:
        n, m = len(nums), len(multipliers)
        
        @lru_cache(maxsize=None)
        def dp(step, left):
            """第 step 步（0-indexed），已从前端取了 left 个"""
            if step == m:
                return 0
            mult = multipliers[step]
            right = step - left  # 已从后取了 right 个
            
            # 取前端
            take_left = nums[left] * mult + dp(step + 1, left + 1)
            # 取后端
            take_right = nums[n - 1 - right] * mult + dp(step + 1, left)
            
            return max(take_left, take_right)
        
        return dp(0, 0)
```

## 复杂度分析

- **时间复杂度**：O(m^2)
- **空间复杂度**：O(m^2)

## 关键点总结

1. DP 状态用 `(步骤, 从前取了几个)` 表示，后取数量由差得出
2. 记忆化搜索写法更直观

## 易错点

- 后端第 `back` 个元素的下标是 `nums[n - back]`，注意方向
