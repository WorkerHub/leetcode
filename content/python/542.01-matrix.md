## 题目描述

给定一个由 0 和 1 组成的矩阵 mat，请输出一个大小相同的矩阵，其中每一个格子是 mat 中对应位置元素到最近的 0 的距离。

两个相邻元素间的距离为 1。

**示例 1：**
```
输入：mat = [[0,0,0],[0,1,0],[0,0,0]]
输出：[[0,0,0],[0,1,0],[0,0,0]]
```

**示例 2：**
```
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]
```

**提示：**
- m == mat.length
- n == mat[i].length
- 1 <= m, n <= 10^4
- 1 <= m * n <= 10^4
- mat[i][j] is either 0 or 1.
- mat 中至少有一个 0

## 解题思路

这道题的核心是计算每个位置到最近 0 的距离。有两种经典的解法：

**思路1：多源BFS（推荐）**
- 将所有 0 的位置作为起点，同时进行 BFS
- 从 0 开始向外扩散，第一次到达某个位置时，该距离就是最短距离
- 使用队列实现层次遍历

**思路2：动态规划**
- 两次遍历：一次从左上到右下，一次从右下到左上
- 每次遍历时，更新当前位置与相邻位置的最小距离

## Python 代码实现

### 方法一：多源BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        # 初始化距离矩阵
        dist = [[0] * n for _ in range(m)]
        # 标记是否访问过
        visited = [[False] * n for _ in range(m)]
        # 队列用于BFS
        queue = deque()
        
        # 将所有0的位置加入队列，作为多源BFS的起点
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 0:
                    queue.append((i, j))
                    visited[i][j] = True
        
        # 四个方向：上下左右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # BFS遍历
        while queue:
            x, y = queue.popleft()
            
            # 遍历四个方向
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                # 检查边界和是否访问过
                if 0 <= nx < m and 0 <= ny < n and not visited[nx][ny]:
                    # 距离等于前一个位置的距离+1
                    dist[nx][ny] = dist[x][y] + 1
                    visited[nx][ny] = True
                    queue.append((nx, ny))
        
        return dist
```

### 方法二：动态规划

```python
from typing import List

class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        # 初始化距离矩阵，将1的位置设为无穷大
        dist = [[float('inf')] * n for _ in range(m)]
        
        # 将所有0的位置距离设为0
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 0:
                    dist[i][j] = 0
        
        # 第一次遍历：从左上到右下，只考虑上方和左方
        for i in range(m):
            for j in range(n):
                if i > 0:
                    dist[i][j] = min(dist[i][j], dist[i-1][j] + 1)
                if j > 0:
                    dist[i][j] = min(dist[i][j], dist[i][j-1] + 1)
        
        # 第二次遍历：从右下到左上，只考虑下方和右方
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if i < m - 1:
                    dist[i][j] = min(dist[i][j], dist[i+1][j] + 1)
                if j < n - 1:
                    dist[i][j] = min(dist[i][j], dist[i][j+1] + 1)
        
        return dist
```

## 复杂度分析

**方法一：多源BFS**
- 时间复杂度：O(m * n)，每个格子最多访问一次
- 空间复杂度：O(m * n)，需要队列和访问标记数组

**方法二：动态规划**
- 时间复杂度：O(m * n)，需要遍历两次矩阵
- 空间复杂度：O(1)，只使用了结果矩阵，不需要额外空间

## 关键点总结

1. 多源BFS的关键是将所有起点同时加入队列
2. BFS保证第一次到达某个位置时距离最短
3. 动态规划需要两次遍历才能得到正确结果
4. 注意边界条件的处理

## 易错点

1. 忘记将所有0同时加入队列，导致距离计算错误
2. 动态规划只遍历一次，无法考虑所有方向
3. 没有正确处理边界情况
4. 初始化距离矩阵时忘记将1设为无穷大
