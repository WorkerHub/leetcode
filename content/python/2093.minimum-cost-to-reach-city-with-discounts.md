## 题目描述

给你 `n` 个城市（编号 0 到 `n-1`），`highways` 表示高速公路，`highways[i] = [city1, city2, toll]` 表示 city1 和 city2 之间有收费 toll 的高速公路（无向图）。

你有 `discounts` 次折扣机会，每次使用可以将某条高速公路的费用减半（向下取整）。

返回从城市 0 到城市 `n-1` 的最小费用，若无法到达返回 `-1`。

**提示：**
- `1 <= n <= 1000`
- `0 <= highways.length <= 1000`
- `0 <= discounts <= 500`

## 解题思路

**Dijkstra + 状态扩展：**

将状态定义为 `(城市, 已用折扣次数)`，用 Dijkstra 求最短路。

状态转移：
- 不使用折扣：`(next_city, used, cost + toll)`
- 使用折扣：`(next_city, used+1, cost + toll//2)`

## 代码实现

### 方法一：Dijkstra 状态扩展（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, highways: List[List[int]], discounts: int) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v, toll in highways:
            graph[u].append((v, toll))
            graph[v].append((u, toll))

        # Dijkstra：状态 (cost, city, used_discounts)
        # dist[city][k] = 到达 city 时已用 k 次折扣的最小费用
        INF = float('inf')
        dist = [[INF] * (discounts + 1) for _ in range(n)]
        dist[0][0] = 0

        heap = [(0, 0, 0)]  # (cost, city, used)

        while heap:
            cost, city, used = heapq.heappop(heap)

            if cost > dist[city][used]:
                continue

            if city == n - 1:
                return cost

            for nb, toll in graph[city]:
                # 不使用折扣
                new_cost = cost + toll
                if new_cost < dist[nb][used]:
                    dist[nb][used] = new_cost
                    heapq.heappush(heap, (new_cost, nb, used))

                # 使用折扣
                if used < discounts:
                    new_cost2 = cost + toll // 2
                    if new_cost2 < dist[nb][used + 1]:
                        dist[nb][used + 1] = new_cost2
                        heapq.heappush(heap, (new_cost2, nb, used + 1))

        return -1 if min(dist[n-1]) == INF else min(dist[n-1])
```

### 方法二：提前终止优化

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumCost(self, n: int, highways: List[List[int]], discounts: int) -> int:
        graph = defaultdict(list)
        for u, v, w in highways:
            graph[u].append((v, w))
            graph[v].append((u, w))

        INF = float('inf')
        # dist[city][k] = 到达 city 使用了 k 次折扣的最小代价
        dist = [[INF] * (discounts + 1) for _ in range(n)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]

        while heap:
            d, u, k = heapq.heappop(heap)
            if d > dist[u][k]:
                continue
            for v, w in graph[u]:
                # 不打折
                if d + w < dist[v][k]:
                    dist[v][k] = d + w
                    heapq.heappush(heap, (dist[v][k], v, k))
                # 打折
                if k < discounts and d + w // 2 < dist[v][k + 1]:
                    dist[v][k + 1] = d + w // 2
                    heapq.heappush(heap, (dist[v][k + 1], v, k + 1))

        ans = min(dist[n - 1])
        return -1 if ans == INF else ans
```

## 复杂度分析

- 时间复杂度：O((E + n) * D * log(n * D))，D 为折扣次数
- 空间复杂度：O(n * D)

## 关键点总结

1. 状态 = (城市, 已用折扣次数)，扩展标准 Dijkstra
2. 每条边有两种转移：用折扣（toll//2）或不用折扣
3. 目标状态：到达城市 n-1，取所有折扣用量下的最小值

## 易错点

- `toll // 2` 是整除向下取整
- 不能用 BFS（权重不均一），必须用 Dijkstra 优先队列
- 注意判断最终无法到达的情况（返回 -1）
