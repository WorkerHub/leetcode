## 题目描述

平面上有 `n` 个点，`points[i] = [xi, yi]`。

每秒你可以进行以下移动之一（**八方向移动**）：
- 向上、下、左、右移动 1 步（水平或垂直方向）
- 向左上、左下、右上、右下对角移动 1 步

请你计算访问所有点所需的**最少时间**（必须按照给定顺序依次访问每个点）。

**示例 1：**
```
输入：points = [[1,1],[3,4],[-1,0]]
输出：7
解释：
  [1,1] -> [3,4] 需要 3 秒（切比雪夫距离）
  [3,4] -> [-1,0] 需要 4 秒
  总计：3 + 4 = 7 秒
```

**示例 2：**
```
输入：points = [[3,2],[-2,2]]
输出：5
```

**提示：**
- `points.length == n`
- `1 <= n <= 100`
- `points[i].length == 2`
- `-100 <= points[i][0], points[i][1] <= 100`

---

## 解题思路

**核心观察：切比雪夫距离**

从点 `(x1, y1)` 移动到点 `(x2, y2)`，每步可以水平、垂直或对角移动。

分析到达目标需要的步数：
- 设 `dx = |x2 - x1`，`dy = |y2 - y1|`
- 对角方向可以同时消耗 x 和 y 方向的差距
- 最优策略：先沿对角线走 `min(dx, dy)` 步（同时减少 x 和 y 的差距），再沿直线走 `|dx - dy|` 步
- 所以总步数 = `min(dx, dy) + |dx - dy| = max(dx, dy)`

这就是**切比雪夫距离**（Chebyshev Distance）！

```
从 (1,1) 到 (3,4)：dx=2, dy=3 → max(2,3) = 3 步
```

因此，答案就是相邻两点切比雪夫距离之和。

## Python 代码实现

### 方法一：直接计算切比雪夫距离（推荐）

```python
from typing import List

class Solution:
    def minTimeToVisitAllPoints(self, points: List[List[int]]) -> int:
        total_time = 0
        # 遍历相邻的点对
        for i in range(len(points) - 1):
            x1, y1 = points[i]
            x2, y2 = points[i + 1]
            # 计算 x 和 y 方向的差值
            dx = abs(x2 - x1)
            dy = abs(y2 - y1)
            # 切比雪夫距离 = max(dx, dy)
            # 解释：对角线走 min(dx,dy) 步 + 直线走 |dx-dy| 步 = max(dx,dy) 步
            total_time += max(dx, dy)
        return total_time
```

**图解演示（示例 1）：**
```
points = [[1,1], [3,4], [-1,0]]

第一段：[1,1] -> [3,4]
  dx = |3-1| = 2, dy = |4-1| = 3
  路径：(1,1)->(2,2)->(3,3)->(3,4) 共 3 步
  max(2,3) = 3 ✓

第二段：[3,4] -> [-1,0]
  dx = |-1-3| = 4, dy = |0-4| = 4
  路径：沿对角线走 4 步 (3,4)->(2,3)->(1,2)->(0,1)->(-1,0) 共 4 步
  max(4,4) = 4 ✓

总计：3 + 4 = 7
```

### 方法二：Python 简洁写法（zip 配对）

```python
from typing import List

class Solution:
    def minTimeToVisitAllPoints(self, points: List[List[int]]) -> int:
        # 用 zip 将相邻点配对，计算每对点的切比雪夫距离并求和
        return sum(
            max(abs(x2 - x1), abs(y2 - y1))
            for (x1, y1), (x2, y2) in zip(points, points[1:])
        )
```

`zip(points, points[1:])` 的效果：
```
points     = [[1,1], [3,4], [-1,0]]
points[1:] = [[3,4], [-1,0]]
zip 结果   = [([1,1],[3,4]), ([3,4],[-1,0])]
```

|------|-----------|-----------|------|
| 方法一 | O(n) | O(1) | 遍历一次相邻点对 |
| 方法二 | O(n) | O(n) | `points[1:]` 产生切片副本 |

其中 n 是 points 的长度。

## 关键点总结

1. **切比雪夫距离**：在八方向移动中，从 A 到 B 的最少步数 = `max(|dx|, |dy|)`。
2. **对角线的作用**：对角移动可以同时减少 x 和 y 方向的差距，因此最优策略是先走对角线。
3. **按顺序访问**：只需对相邻点对求距离然后累加，不需要考虑路径优化。
4. **整数距离**：由于坐标都是整数，切比雪夫距离也一定是整数，不需要处理浮点数。

---

## 易错点

1. **不要用欧几里得距离**：直线距离 `sqrt(dx^2 + dy^2)` 是错误的，因为题目允许对角移动。
2. **不要用曼哈顿距离**：`dx + dy` 也是错误的，因为对角移动一步可以同时前进 x 和 y 方向。
3. **切比雪夫距离的推导**：`min(dx,dy) + |dx-dy| = min(dx,dy) + max(dx,dy) - min(dx,dy) = max(dx,dy)`。
4. **边界情况**：只有一个点时，`len(points) - 1 = 0`，循环不执行，返回 0，这是正确的。

## 学习建议

1. **理解三种距离**：欧几里得距离（斜线）、曼哈顿距离（只走横竖）、切比雪夫距离（八方向）是算法中常用的三种距离度量，要能区分它们的使用场景。
2. **几何直觉**：画图辅助理解，在坐标纸上画出两个点，想象用最少步数走到目标点，先走对角线再走直线的策略一目了然。
3. **类比扩展**：本题的思路可以推广到"棋盘上的国王走法"——国王每步也是八方向移动，从 A 走到 B 的最少步数同样是切比雪夫距离。
