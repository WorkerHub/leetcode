## 题目描述

给你一个数组 `candies` 和一个整数 `extraCandies`，其中 `candies[i]` 表示第 `i` 个小朋友拥有的糖果数量。

对每一个小朋友，检查是否存在一种方案，将额外的 `extraCandies` 颗糖果全部分配给某一个小朋友后，此小朋友是否会拥有**最多**的糖果（允许并列）。

返回一个布尔数组 `result`，若第 `i` 个小朋友在获得额外糖果后可以拥有最多糖果则 `result[i]` 为 `true`，否则为 `false`。

**示例 1：**
```
输入：candies = [2,3,5,1,3], extraCandies = 3
输出：[true,true,true,false,true]
解释：
- 小朋友 1：2 + 3 = 5，等于最大值，true
- 小朋友 2：3 + 3 = 6，大于最大值，true
- 小朋友 3：5 + 3 = 8，大于最大值，true
- 小朋友 4：1 + 3 = 4，小于最大值 5，false
- 小朋友 5：3 + 3 = 6，大于最大值，true
```

**示例 2：**
```
输入：candies = [4,2,1,1,2], extraCandies = 1
输出：[true,false,false,false,false]
```

**提示：**
- `2 <= candies.length <= 100`
- `1 <= candies[i] <= 100`
- `1 <= extraCandies <= 50`

## 解题思路

**思路分析：**

判断第 `i` 个小朋友能否成为拥有最多糖果的孩子，等价于：
```
candies[i] + extraCandies >= max(candies)
```

**算法步骤：**
1. 先求 `candies` 中的最大值 `max_candy`。
2. 遍历每个小朋友，判断 `candies[i] + extraCandies >= max_candy`。
3. 将结果组成布尔数组返回。

时间复杂度仅 O(n)，非常简洁。

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        # 先求当前最多的糖果数
        max_candy = max(candies)
        # 判断每个孩子加上额外糖果后是否能达到最大值
        return [c + extraCandies >= max_candy for c in candies]
```

### 方法二：列表推导式（显式循环版，更易理解）

```python
from typing import List

class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        max_candy = max(candies)
        result = []
        for c in candies:
            if c + extraCandies >= max_candy:
                result.append(True)
            else:
                result.append(False)
        return result
```

### 方法三：使用 map 函数

```python
from typing import List

class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        max_candy = max(candies)
        # 用 map 将每个元素映射为布尔值
        return list(map(lambda c: c + extraCandies >= max_candy, candies))
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历数组两次（一次求最大值，一次生成结果）。
- **空间复杂度：** O(1)，仅用常数额外空间（不计输出数组）。

## 图解示例

```
candies = [2, 3, 5, 1, 3], extraCandies = 3
max_candy = 5

下标 0: 2 + 3 = 5 >= 5  --> True
下标 1: 3 + 3 = 6 >= 5  --> True
下标 2: 5 + 3 = 8 >= 5  --> True
下标 3: 1 + 3 = 4 < 5   --> False
下标 4: 3 + 3 = 6 >= 5  --> True

结果: [True, True, True, False, True]
```

## 关键点总结

1. 关键观察：只需要和"当前最大值"比较，不需要考虑给其他孩子糖果后的变化。
2. `extraCandies` 全部给一个孩子，所以直接加上即可。
3. Python 的列表推导式可以非常简洁地表达这个逻辑。
4. 允许并列，所以用 `>=`（大于等于），而非 `>`。

## 易错点

- 使用 `>` 而非 `>=`，漏掉了"并列第一"的情况。
- 忘记先求最大值，直接在循环中每次调用 `max()` 导致 O(n²) 时间复杂度（虽然数据规模小不影响结果，但习惯要好）。
