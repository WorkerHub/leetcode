## 题目描述

给你两个整数 `n` 和 `m`，分别代表按位 AND 和 OR 操作后的可能值范围。

具体地，给你一个长度为 `n` 的二进制数组 `nums`（元素为 0 或 1），你可以对任意相邻两个元素执行按位操作（AND 或 OR），将结果替换其中一个元素，重复操作直到只剩一个元素。

请返回可能得到的最大值和最小值（作为数组 `[max, min]`）。

**示例 1：**

```
输入：nums = [0,1,0,1]
输出：[1,0]
解释：最大值：通过OR操作可得1；最小值：通过AND操作可得0
```

**示例 2：**

```
输入：nums = [1,1,1]
输出：[1,1]
```

**提示：**

- `1 <= nums.length <= 10^5`
- `nums[i]` 为 0 或 1

## 解题思路

观察规律：

- **最大值**：若数组中存在至少一个 1，通过 OR 操作最终可得 1；否则为 0
- **最小值**：若数组中全为 1，通过 AND 操作最终仍为 1；若有任意 0，通过 AND 最终可得 0

所以：
- `max_val = 1 if 1 in nums else 0`
- `min_val = 1 if all(x == 1 for x in nums) else 0`

## Python 代码实现

### 方法一：直接判断（推荐）

```python
from typing import List

class Solution:
    def minMaxAfterOperations(self, nums: List[int]) -> List[int]:
        # 最大值：有1则为1
        max_val = 1 if any(x == 1 for x in nums) else 0
        # 最小值：全1才为1
        min_val = 1 if all(x == 1 for x in nums) else 0
        return [max_val, min_val]
```

### 方法二：计数简洁版

```python
from typing import List

class Solution:
    def minMaxAfterOperations(self, nums: List[int]) -> List[int]:
        ones = sum(nums)
        n = len(nums)
        max_val = 1 if ones > 0 else 0
        min_val = 1 if ones == n else 0
        return [max_val, min_val]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. OR 操作具有"扩散性"：只要有一个 1，最终可得 1
2. AND 操作具有"收敛性"：只要有一个 0，最终可得 0
3. 不需要模拟具体操作过程

## 易错点

1. 这里操作的是 0/1 数组，不是整数数组
2. 相邻操作并非只能操作一次，可以多次操作
