## 题目描述

给你一个字符串 `time`，格式为 `hh:mm`（小时：分钟），其中某些数字被隐藏了（用 `?` 表示）。

有效的时间需满足 `00:00` 到 `23:59`。

请你将每一个隐藏的数字 (`?`) 替换为 `0-9` 中的某一数字，使得生成的时间是一天中**最晚**的时间（即最大的有效时间）。

返回替换后的字符串。

**示例 1：**
```
输入：time = "2?:?0"
输出："23:50"
```

**示例 2：**
```
输入：time = "0?:3?"
输出："09:39"
```

**提示：**
- `time` 的格式为 `hh:mm`
- 保证 `time` 是一个有效时间，即在 `00:00` 到 `23:59` 之间

## 解题思路

贪心地为每个 `?` 填入最大可能的数字：

- 第 0 位（小时十位）：
  - 若第 1 位是 `?` 或 `0/1/2/3`，则最大可填 `2`
  - 若第 1 位是 `4/5/6/7/8/9`，则小时十位只能是 `1`（因为 `2x` 时 `x > 3` 无效）
- 第 1 位（小时个位）：
  - 若第 0 位是 `2`，则最大填 `3`
  - 否则最大填 `9`
- 第 3 位（分钟十位）：最大填 `5`
- 第 4 位（分钟个位）：最大填 `9`

## 代码实现

### 方法一：逐位贪心（推荐）

```python
class Solution:
    def maximumTime(self, time: str) -> str:
        t = list(time)
        
        # 第 0 位：小时十位
        if t[0] == '?':
            # 第 1 位决定十位的上限
            if t[1] == '?' or int(t[1]) <= 3:
                t[0] = '2'  # 可以让小时最大到 29（但29超范围，实际会被第1位限制）
            else:
                t[0] = '1'  # 小时个位 >= 4，十位只能是 1
        
        # 第 1 位：小时个位
        if t[1] == '?':
            if t[0] == '2':
                t[1] = '3'  # 2x 最大 23
            else:
                t[1] = '9'  # 其他情况最大 9
        
        # 第 3 位：分钟十位（最大 5）
        if t[3] == '?':
            t[3] = '5'
        
        # 第 4 位：分钟个位（最大 9）
        if t[4] == '?':
            t[4] = '9'
        
        return ''.join(t)
```

### 方法二：枚举所有可能时间

```python
class Solution:
    def maximumTime(self, time: str) -> str:
        # 枚举每个 ? 的可能值，找最大有效时间
        # 简化：直接按规则填
        h, m = time.split(':')
        
        h0 = h[0]
        h1 = h[1]
        m0 = m[0]
        m1 = m[1]
        
        # 确定小时
        if h0 == '?' and h1 == '?':
            h0, h1 = '2', '3'
        elif h0 == '?':
            h0 = '2' if int(h1) <= 3 else '1'
        elif h1 == '?':
            h1 = '3' if h0 == '2' else '9'
        
        # 确定分钟
        if m0 == '?':
            m0 = '5'
        if m1 == '?':
            m1 = '9'
        
        return f"{h0}{h1}:{m0}{m1}"
```

## 复杂度分析

- **时间复杂度**：O(1)，字符串长度固定为 5
- **空间复杂度**：O(1)

## 关键点总结

1. 各位数字的范围：小时十位 0-2，小时个位 0-9（十位为2时0-3），分钟十位 0-5，分钟个位 0-9
2. 贪心：在合法范围内取最大值
3. 注意小时两位之间的约束关系

## 易错点

- 当小时十位是 `2` 时，个位最大只能是 `3`
- 当小时个位 >= `4` 时，十位最大只能是 `1`（不能是 `2`，否则超过 23）
