## 题目描述

有一个无限大的二维网格，初始全是白色。在 `n` 分钟内，按如下规则涂色：
- 第 1 分钟：将 `(0, 0)` 涂成蓝色
- 第 `i` 分钟（i > 1）：将所有与蓝色格子相邻（共享边）的白色格子都涂成蓝色

返回 `n` 分钟后蓝色格子的总数。

**示例 1：**

```
输入：n = 1
输出：1
```

**示例 2：**

```
输入：n = 2
输出：5
解释：第 2 分钟新增 4 个格子，共 5 个。
```

**示例 3：**

```
输入：n = 3
输出：13
解释：第 3 分钟新增 8 个格子，共 13 个。
```

**提示：**

- `1 <= n <= 10^5`

## 解题思路

观察规律：
- n=1：1
- n=2：5 = 1 + 4
- n=3：13 = 5 + 8
- n=4：25 = 13 + 12

每分钟新增格子数：4, 8, 12, ...，即 4*(i-1)（i 从 2 开始）。

总格子数 = 1 + 4 + 8 + ... + 4*(n-1) = 1 + 4 * (1 + 2 + ... + (n-1)) = 1 + 4 * n*(n-1)/2 = 2n² - 2n + 1。

## Python 代码实现

### 方法一：数学公式（推荐）

```python
class Solution:
    def coloredCells(self, n: int) -> int:
        # 总格子数 = 2*n^2 - 2*n + 1
        return 2 * n * n - 2 * n + 1
```

### 方法二：迭代模拟

```python
class Solution:
    def coloredCells(self, n: int) -> int:
        total = 1
        for i in range(2, n + 1):
            # 第 i 分钟新增 4*(i-1) 个格子
            total += 4 * (i - 1)
        return total
```

## 复杂度分析

- 方法一时间复杂度：O(1)
- 方法二时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 规律：每分钟新增 4*(分钟数-1) 个格子
2. 数学公式：`2n² - 2n + 1`
3. 图形上，n 分钟后蓝色格子构成一个"菱形"（旋转 45° 的正方形）

## 易错点

1. 数字很大时（n=10^5），2n² 约 2*10^10，Python 无溢出问题
2. n=1 时公式给出 1，正确
3. 迭代法从 i=2 开始，不要从 i=1 开始（i=1 时已有初始格子）
