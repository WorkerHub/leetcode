## 题目描述

给你一个由非负整数 `a1, a2, ..., an` 组成的数据流输入，请你将到目前为止看到的数字总结为不相交的区间列表。

实现 `SummaryRanges` 类：

- `SummaryRanges()` 初始化对象。
- `void addNum(int value)` 向数据流中添加整数 `value`。
- `int[][] getIntervals()` 以不相交区间 `[starti, endi]` 的列表形式返回对数据流中的整数的总结。答案应该按 `starti` 升序排列。

**示例：**
```
输入：
["SummaryRanges", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals"]
[[], [1], [], [3], [], [7], [], [2], [], [6], []]
输出：
[null, null, [[1, 1]], null, [[1, 1], [3, 3]], null, [[1, 1], [3, 3], [7, 7]], null, [[1, 3], [7, 7]], null, [[1, 3], [6, 7]]]

解释：
SummaryRanges summaryRanges = new SummaryRanges();
summaryRanges.addNum(1);      // 数据流: [1]
summaryRanges.getIntervals(); // 返回 [[1, 1]]
summaryRanges.addNum(3);      // 数据流: [1, 3]
summaryRanges.getIntervals(); // 返回 [[1, 1], [3, 3]]
summaryRanges.addNum(7);      // 数据流: [1, 3, 7]
summaryRanges.getIntervals(); // 返回 [[1, 1], [3, 3], [7, 7]]
summaryRanges.addNum(2);      // 数据流: [1, 2, 3, 7]
summaryRanges.getIntervals(); // 返回 [[1, 3], [7, 7]]
summaryRanges.addNum(6);      // 数据流: [1, 2, 3, 6, 7]
summaryRanges.getIntervals(); // 返回 [[1, 3], [6, 7]]
```

**提示：**
- `0 <= value <= 10^4`
- 最多调用 `addNum` 和 `getIntervals` 方法 `3 * 10^4` 次

**进阶：** 如果存在大量合并，并且与数据流的大小相比，不相交区间的数量很小，该怎么办？

## 解题思路

这道题的核心是维护一个有序的、不相交的区间列表。

**关键操作：**
1. **添加数字**：可能需要合并相邻区间
2. **获取区间**：直接返回当前区间列表

**实现方案：**
- 使用有序列表存储区间
- 二分查找定位插入位置
- 合并可能的左右区间

## Python 代码实现

### 方法一：二分查找 + 合并⭐

```python
from typing import List
import bisect

class SummaryRanges:
    def __init__(self):
        # 存储不相交的区间，按起点排序
        self.intervals = []
    
    def addNum(self, value: int) -> None:
        # 新区间
        new_interval = [value, value]
        
        if not self.intervals:
            self.intervals.append(new_interval)
            return
        
        # 二分查找插入位置
        # 找到第一个起点 > value 的区间
        pos = bisect.bisect_left(self.intervals, [value, value])
        
        # 检查是否可以与前一个区间合并
        left = pos - 1 if pos > 0 else -1
        # 检查是否可以与后一个区间合并
        right = pos
        
        # 判断是否已存在
        if left >= 0 and self.intervals[left][0] <= value <= self.intervals[left][1]:
            return  # 已经在某个区间内
        
        # 判断能否与左边区间合并
        merge_left = left >= 0 and self.intervals[left][1] + 1 >= value
        # 判断能否与右边区间合并
        merge_right = right < len(self.intervals) and self.intervals[right][0] - 1 <= value
        
        if merge_left and merge_right:
            # 合并左右两个区间
            self.intervals[left][1] = self.intervals[right][1]
            self.intervals.pop(right)
        elif merge_left:
            # 只合并左边
            self.intervals[left][1] = max(self.intervals[left][1], value)
        elif merge_right:
            # 只合并右边
            self.intervals[right][0] = min(self.intervals[right][0], value)
        else:
            # 插入新区间
            self.intervals.insert(pos, new_interval)
    
    def getIntervals(self) -> List[List[int]]:
        return self.intervals
```

**时间复杂度：**
- addNum: O(n)，最坏情况需要移动元素
- getIntervals: O(1)

**空间复杂度：** O(n)

### 方法二：使用集合 + 排序

```python
class SummaryRanges:
    def __init__(self):
        self.nums = set()
    
    def addNum(self, value: int) -> None:
        self.nums.add(value)
    
    def getIntervals(self) -> List[List[int]]:
        if not self.nums:
            return []
        
        # 排序
        sorted_nums = sorted(self.nums)
        intervals = []
        start = sorted_nums[0]
        end = sorted_nums[0]
        
        for num in sorted_nums[1:]:
            if num == end + 1:
                # 扩展当前区间
                end = num
            else:
                # 保存当前区间，开始新区间
                intervals.append([start, end])
                start = end = num
        
        # 添加最后一个区间
        intervals.append([start, end])
        
        return intervals
```

**时间复杂度：**
- addNum: O(1)
- getIntervals: O(n log n)

## 关键点总结

1. **二分查找**：快速定位插入位置
2. **区间合并**：判断相邻或重叠
3. **边界处理**：左右区间的合并条件
4. **去重**：避免重复添加

## 易错点

1. **合并条件**
   ```python
   # 错误：只考虑紧邻
   merge_left = self.intervals[left][1] + 1 == value
   
   # 正确：考虑重叠
   merge_left = self.intervals[left][1] + 1 >= value
   ```

2. **重复添加**
   ```python
   # 需要检查是否已在区间内
   if left >= 0 and self.intervals[left][0] <= value <= self.intervals[left][1]:
       return
   ```
