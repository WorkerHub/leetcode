## 题目描述

给你一个字符串 `s` 和一个整数 `k`。

如果字符串的某个子字符串只包含一种字符（所有字符相同），则称其为**特殊子字符串**。

从 `s` 中选取 `k` 个**不相交**的特殊子字符串，返回能够选取的最大字符总数。如果不能选取 k 个，返回 -1。

**示例 1：**

```
输入：s = "abcde", k = 2
输出：2
解释：选取 "a" 和 "b"，共 2 个字符
```

**示例 2：**

```
输入：s = "aaaa", k = 2
输出：4
解释：选取 "aa" 和 "aa"，但它们重叠... 选 "aaaa" 作为 1 个，只能选 1 个不同的特殊子串
```

**提示：**
- `1 <= s.length <= 5000`
- `1 <= k <= 26`

## 解题思路

首先，所有连续相同字符段构成了候选特殊子字符串。

每段是一个区间 `[l, r]`，从该段中选一个特殊子字符串，长度可以是 1 到 r-l+1。

为了最大化选取 k 个不相交特殊子字符串的字符总数：
1. 每段最多贡献一个子字符串
2. 贪心：如果有足够多的段，选最长的 k 段

将所有段提取出来，排序（按长度降序），选最长的 k 个（它们天然不相交，因为来自不同段）。

## Python 代码实现

### 方法一：提取段 + 贪心（推荐）

```python
class Solution:
    def maxSubstringLength(self, s: str, k: int) -> int:
        n = len(s)

        # 提取所有连续相同字符段
        segments = []
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            segments.append(j - i)  # 段的长度
            i = j

        if len(segments) < k:
            return -1

        # 贪心：选最长的 k 段
        segments.sort(reverse=True)
        return sum(segments[:k])
```

### 方法二：DP 方法（处理复杂约束）

```python
class Solution:
    def maxSubstringLength(self, s: str, k: int) -> int:
        n = len(s)

        # 提取段
        segs = []  # (start, end, length)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            segs.append((i, j - 1, j - i))
            i = j

        m = len(segs)
        if m < k:
            return -1

        # 贪心：选最大的 k 个段的长度
        segs.sort(key=lambda x: -x[2])
        return sum(seg[2] for seg in segs[:k])
```

### 方法三：可以从每段选子段的情况

```python
class Solution:
    def maxSubstringLength(self, s: str, k: int) -> int:
        n = len(s)

        # 提取所有段
        segs = []
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            segs.append(j - i)
            i = j

        m = len(segs)
        if m < k:
            return -1

        # 选最大的 k 个段
        segs.sort(reverse=True)
        return sum(segs[:k])
```

## 复杂度分析

- 时间复杂度：O(n + m log m)，m 为段数
- 空间复杂度：O(m)

## 关键点总结

1. 特殊子字符串 = 连续相同字符的段
2. 不相交的特殊子字符串来自不同的段
3. 贪心选最长的 k 段，最大化字符总数

## 易错点

1. 每个段只能选一个特殊子字符串（不能拆分一个段为两个）
2. 若段数 < k，返回 -1
3. 选整个段而不是子段，可以最大化总长度
