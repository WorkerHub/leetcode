## 题目描述

给你两个**正整数** `n` 和 `k`，如果一个 `n` 位整数满足：
1. 它能被 `k` 整除
2. 它的十进制表示是一个**回文数**

则称其为**好整数**。

返回 `n` 位**好整数**的数量。

**示例 1：**
```
输入：n = 1, k = 4
输出：2
解释：1 位能被 4 整除的回文数：4, 8
```

**示例 2：**
```
输入：n = 3, k = 5
输出：27
```

**提示：**
- `1 <= n <= 10`
- `1 <= k <= 9`

## 解题思路

枚举所有 n 位回文数：
- 回文数由前 ceil(n/2) 位决定
- 枚举前半部分（注意首位不能为 0）
- 构造完整回文数，检查是否能被 k 整除

但要避免重复计数（不同的前半部分可能生成相同的回文数，实际上不会）。

另一种方法：枚举并统计。

## Python 代码实现

### 方法一：枚举回文数（推荐）

```python
class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        half = (n + 1) // 2
        
        # 枚举前半部分
        start = 10 ** (half - 1)  # 最小前半（首位不为0）
        end = 10 ** half           # 最大前半+1
        
        ans = 0
        
        for first_half in range(start, end):
            s = str(first_half)
            # 构造回文数
            if n % 2 == 0:
                palindrome = s + s[::-1]
            else:
                palindrome = s + s[-2::-1]
            
            num = int(palindrome)
            if num % k == 0:
                ans += 1
        
        return ans
```

### 方法二：统计不同排列

```python
class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        # 收集所有满足条件的回文数的"规范形式"（排序后的数字）
        # 然后统计每种数字组合的 n 位回文排列数
        
        from math import factorial
        from collections import Counter
        
        half = (n + 1) // 2
        start = 10 ** (half - 1)
        end = 10 ** half
        
        seen = set()  # 记录已统计的数字组合
        ans = 0
        
        for first_half in range(start, end):
            s = str(first_half)
            if n % 2 == 0:
                palindrome = s + s[::-1]
            else:
                palindrome = s + s[-2::-1]
            
            num = int(palindrome)
            if num % k != 0:
                continue
            
            # 标准化：排序后的数字字符串
            key = ''.join(sorted(palindrome))
            if key in seen:
                continue
            seen.add(key)
            
            # 统计这种数字组合能构成多少 n 位无前导零的回文数
            # 实际上每种前半部分唯一对应一个回文数，所以直接+1
            ans += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(10^(n/2))，枚举前半部分
- 空间复杂度：O(1)

## 关键点总结

1. 回文数由前半部分唯一决定
2. 首位不为 0（start 从 10^(half-1) 开始）
3. 枚举并检查能否被 k 整除

## 易错点

1. n 为奇数时中间位只出现一次，构造方式与偶数不同
2. 1 位数的情况：half = 1，palindrome = s（没有镜像）
