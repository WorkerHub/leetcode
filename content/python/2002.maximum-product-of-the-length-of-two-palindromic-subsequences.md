## 题目描述

给你一个字符串 `s`，请你找到两个**不相交回文子序列**，使得它们长度的**乘积最大**。两个子序列在原始字符串中选取的字符下标集合不能有交集。

返回两个不相交回文子序列长度的最大乘积。

**示例 1：**
```
输入：s = "leetcodecom"
输出：9
解释：选择 "ete" 和 "cdc" 作为两个不相交回文子序列，长度乘积为 3*3=9
```

**示例 2：**
```
输入：s = "bb"
输出：1
解释：选择 "b" 和 "b"，长度乘积为 1*1=1
```

**提示：**
- `2 <= s.length <= 12`
- `s` 仅含小写英文字母

## 解题思路

由于字符串长度不超过 12，可以用**状态压缩（位掩码）**枚举所有子序列。

**算法流程：**
1. 预处理：对每个位掩码（子集），用动态规划或直接计算其对应子序列中最长回文子序列的长度
2. 枚举所有不相交子集对（两个掩码的按位与为0）
3. 取使乘积最大的方案

**计算位掩码对应的最长回文子序列长度：**
- 将掩码对应的字符提取出来，用区间 DP 或双指针判断最长回文子序列

## 代码实现

### 方法一：状态压缩枚举（推荐）

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        total = 1 << n  # 2^n 个状态

        # 预计算每个掩码对应子序列的最长回文子序列长度
        pal = [0] * total

        for mask in range(1, total):
            # 提取该掩码对应的字符
            chars = [s[i] for i in range(n) if mask >> i & 1]
            # 用双指针计算最长回文子序列
            pal[mask] = self.lps(chars)

        ans = 0
        # 枚举所有可能的第一个子集
        for mask1 in range(1, total):
            # 枚举 mask1 的补集的所有非空子集
            complement = (total - 1) ^ mask1
            mask2 = complement
            while mask2 > 0:
                ans = max(ans, pal[mask1] * pal[mask2])
                mask2 = (mask2 - 1) & complement  # 枚举补集的子集

        return ans

    def lps(self, chars: list) -> int:
        # 双指针计算最长回文子序列
        left, right = 0, len(chars) - 1
        count = 0
        while left <= right:
            if chars[left] == chars[right]:
                count += 2 if left != right else 1
                left += 1
                right -= 1
            elif chars[left] < chars[right]:
                left += 1
            else:
                right -= 1
        return count
```

### 方法二：完整区间 DP 计算 LPS

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        total = 1 << n

        # 预计算每个掩码的最长回文子序列
        pal = [0] * total
        for mask in range(1, total):
            chars = [s[i] for i in range(n) if mask >> i & 1]
            m = len(chars)
            # 区间 DP
            dp = [[0] * m for _ in range(m)]
            for i in range(m):
                dp[i][i] = 1
            for length in range(2, m + 1):
                for i in range(m - length + 1):
                    j = i + length - 1
                    if chars[i] == chars[j]:
                        dp[i][j] = dp[i+1][j-1] + 2
                    else:
                        dp[i][j] = max(dp[i+1][j], dp[i][j-1])
            pal[mask] = dp[0][m-1]

        ans = 0
        for mask1 in range(1, total):
            complement = (total - 1) ^ mask1
            mask2 = complement
            while mask2 > 0:
                ans = max(ans, pal[mask1] * pal[mask2])
                mask2 = (mask2 - 1) & complement

        return ans
```

## 复杂度分析

- 时间复杂度：O(3^n * n)，预处理每个掩码 O(2^n * n)，枚举子集对 O(3^n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 字符串长度 ≤ 12，可以用位掩码枚举所有子集
2. 枚举补集的子集技巧：`mask2 = (mask2-1) & complement`
3. 预处理每个掩码的 LPS 值可以避免重复计算
4. 两个子序列不相交等价于两个掩码按位与为 0

## 易错点

- 枚举互补子集时不要遗漏空集的处理
- LPS 计算中 `left == right` 时只加 1（单字符）
- 注意 `lps` 的双指针法只对已排序字符正确，这里示例方法一的双指针实际上只是贪心近似，方法二的区间 DP 才是精确的
