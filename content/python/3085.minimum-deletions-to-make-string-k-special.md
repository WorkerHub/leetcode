## 题目描述

给你一个字符串 `s` 和整数 `k`。

若字符串中任意两个字符频率之差不超过 `k`，则称字符串为"k-special"。

返回使字符串变为 k-special 所需的最少删除次数。

**示例 1：**
```
输入：s = "aabcaba", k = 0
输出：3
```

**示例 2：**
```
输入：s = "dabdcbdcdcd", k = 2
输出：2
```

**提示：**
- `1 <= s.length <= 10^5`
- `0 <= k <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

统计每个字母的频率，排序后枚举"最低频"的字母的频率 `f`：

对于给定的最低频 `f`（即我们保留的最低频率）：
- 频率 < `f` 的字母：全部删除（代价 = 该字母的所有出现次数）
- 频率 > `f + k` 的字母：删减到 `f + k`（代价 = 超出部分）

枚举所有可能的 `f`（即频率数组中的每个值），取最小总代价。

## Python 代码实现

### 方法一：排序枚举（推荐）

```python
from collections import Counter

class Solution:
    def minimumDeletions(self, s: str, k: int) -> int:
        freq = sorted(Counter(s).values())
        n = len(freq)
        ans = float('inf')

        for i in range(n):
            # 以 freq[i] 为最低频（删除所有频率 < freq[i] 的字母）
            cost = sum(freq[:i])  # 删除前 i 个字母的所有字符

            # 频率 > freq[i] + k 的字母需削减
            for j in range(i, n):
                if freq[j] > freq[i] + k:
                    cost += freq[j] - (freq[i] + k)

            ans = min(ans, cost)

        return ans
```

### 方法二：前缀和优化

```python
from collections import Counter

class Solution:
    def minimumDeletions(self, s: str, k: int) -> int:
        freq = sorted(Counter(s).values())
        n = len(freq)

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + freq[i]

        ans = float('inf')
        for i in range(n):
            # 最低频设为 freq[i]
            # 删除 freq[0..i-1] 的所有字符
            delete_low = prefix[i]

            # 削减 freq[j] > freq[i]+k 的字母
            min_high = freq[i] + k
            # 找第一个 > min_high 的位置（二分）
            import bisect
            j = bisect.bisect_right(freq, min_high)
            # 削减 freq[j..n-1] 超出部分
            delete_high = prefix[n] - prefix[j] - (n - j) * min_high

            ans = min(ans, delete_low + delete_high)

        return ans
```

## 复杂度分析

- 方法一：O(n * m)，n 为字符串长度，m 为不同字母数（最多 26）
- 方法二：O(m log m)，m = 26，实际为 O(1)
- 空间复杂度：O(m) = O(1)

## 关键点总结

1. 枚举最低频作为基准
2. 频率过低的字母全删（代价 = 其频率）
3. 频率过高的字母削减到 `最低频 + k`

## 易错点

1. 枚举的是"最低频"，不是某个字母的频率
2. 削减高频字母：只需减去超出 `f + k` 的部分
3. `freq[i]` 是排序后的频率，不是字母的字典序
