## 题目描述

给你一个下标从 0 开始的字符串数组 `details`，`details[i]` 描述第 `i` 位旅客的信息，格式为：
- 前 15 个字符：电话号码
- 第 16 个字符：性别（'M' 或 'F'）
- 第 17-18 个字符：年龄（两位数）
- 第 19-22 个字符：座位号

返回年龄**严格大于 60** 的旅客数量。

**示例 1：**
```
输入：details = ["7868190130M7522","5303914400F9211","9273338290F4010"]
输出：2
解释：第1位年龄75，第2位年龄92，第3位年龄40，前两位>60
```

**数据范围：**
- 1 <= details.length <= 1000
- details[i].length == 15

## 解题思路

提取每个字符串第 11-12 个字符（0-indexed：[11:13]）作为年龄，转为整数与 60 比较。

## Python 代码实现

### 方法一：字符串切片（推荐）

```python
from typing import List

class Solution:
    def countSeniors(self, details: List[str]) -> int:
        count = 0
        for d in details:
            age = int(d[11:13])  # 第 12-13 个字符（0-indexed 11-12）为年龄
            if age > 60:
                count += 1
        return count
```

### 方法二：sum + 生成器

```python
from typing import List

class Solution:
    def countSeniors(self, details: List[str]) -> int:
        return sum(1 for d in details if int(d[11:13]) > 60)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 年龄在字符串固定位置（下标 11-12，0-indexed）
2. 严格大于 60（不包括 60 岁）

## 易错点

1. 年龄从下标 11 开始，切片 `d[11:13]` 取两个字符
2. 需要转为整数后比较
