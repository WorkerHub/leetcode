## 题目描述

给你一个 `n x n` 整数矩阵 `grid`，请你返回**非零偏移下降路径**数字和的最小值。

**非零偏移下降路径**定义为：从 `grid` 数组中的每一行分别选择一个数字，且按顺序选出来的数字中，相邻数字不在原数组的同一列。

**示例 1：**

```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：13
解释：最优下降路径如下：
  [1, 5, 7]（列 0 -> 列 1 -> 列 0）
  [1, 5, 9]（列 0 -> 列 1 -> 列 2）
  [1, 6, 7]（列 0 -> 列 2 -> 列 0）
  [1, 6, 8]（列 0 -> 列 2 -> 列 1）
  最优路径和为 1 + 5 + 7 = 13
```

**示例 2：**

```
输入：grid = [[7]]
输出：7
```

**提示：**

- `n == grid.length == grid[i].length`
- `1 <= n <= 200`
- `-99 <= grid[i][j] <= 99`

## 解题思路

### 核心观察

这道题是经典的动态规划问题。定义 `dp[i][j]` 为从第 0 行下降到第 `i` 行第 `j` 列时的最小路径和。

状态转移方程：

```
dp[i][j] = grid[i][j] + min(dp[i-1][k])，其中 k != j
```

**关键优化：**

朴素做法对每个 `j`，都要遍历所有 `k != j`，时间复杂度为 O(n^3)。

观察到：对于每一列 `j`，我们需要的是上一行**除 `j` 列之外**的最小值。

只需要记录上一行的**最小值**和**次小值**（以及最小值对应的列下标）：
- 如果当前列 `j` 不是上一行最小值所在列，直接使用最小值
- 如果当前列 `j` 恰好是上一行最小值所在列，则使用次小值

这样每一行只需 O(n) 即可完成，总时间复杂度降为 O(n^2)。

### 算法流程

1. 初始化 `dp` 为第一行的值
2. 逐行遍历，对每行找到上一行的最小值、次小值及最小值所在列
3. 更新当前行的 `dp` 值
4. 返回最后一行 `dp` 的最小值

## Python 代码实现

### 方法一：动态规划 + 最小值/次小值优化（推荐）

```python
from typing import List

class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # 初始化 dp 为第一行的值
        dp = grid[0][:]

        for i in range(1, n):
            # 找上一行的最小值和次小值，以及最小值所在的列
            min1 = min2 = float('inf')  # min1 <= min2
            min1_col = -1

            for j in range(n):
                if dp[j] < min1:
                    min2 = min1
                    min1 = dp[j]
                    min1_col = j
                elif dp[j] < min2:
                    # dp[j] 在 min1 和 min2 之间，只更新 min2
                    min2 = dp[j]

            # 计算当前行的 dp 值
            new_dp = []
            for j in range(n):
                if j == min1_col:
                    # 当前列恰好是上一行最小值所在列，使用次小值
                    new_dp.append(grid[i][j] + min2)
                else:
                    # 否则使用上一行最小值
                    new_dp.append(grid[i][j] + min1)

            dp = new_dp

        return min(dp)
```

### 方法二：朴素动态规划 O(n^3)（便于理解，不推荐用于大输入）

```python
from typing import List

class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # dp[i][j] 表示到达第 i 行第 j 列时的最小路径和
        dp = [row[:] for row in grid]

        for i in range(1, n):
            for j in range(n):
                # 从上一行所有不同列中取最小值
                prev_min = min(dp[i - 1][k] for k in range(n) if k != j)
                dp[i][j] = grid[i][j] + prev_min

        # 返回最后一行的最小值
        return min(dp[n - 1])
```

### 方法三：使用 heapq 记录上一行最小两个值（另一种写法）

```python
from typing import List
import heapq

class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dp = grid[0][:]

        for i in range(1, n):
            # 用 heapq 找上一行最小的两个值及其列下标
            # 注意：可能有多个相同的最小值，nsmallest 返回前两个
            indexed = [(dp[j], j) for j in range(n)]
            smallest_two = heapq.nsmallest(2, indexed)

            new_dp = []
            for j in range(n):
                # 找到一个最小值，其列下标不等于 j
                for val, col in smallest_two:
                    if col != j:
                        new_dp.append(grid[i][j] + val)
                        break

            dp = new_dp

        return min(dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（最优） | O(n^2) | O(n) |
| 方法二（朴素DP） | O(n^3) | O(n^2) |
| 方法三（heapq） | O(n^2 log n) | O(n) |

**方法一详解：**
- 时间：共 n 行，每行找最小/次小值 O(n)，更新 dp O(n)，总计 O(n^2)
- 空间：只保存一维 dp 数组，O(n)

## 图解示例

以 `grid = [[1,2,3],[4,5,6],[7,8,9]]` 为例：

```
初始 dp = [1, 2, 3]

第 1 行：
  上一行最小值 min1=1（列0），次小值 min2=2
  j=0：列0 == min1_col，使用 min2=2，dp[0] = 4 + 2 = 6
  j=1：使用 min1=1，dp[1] = 5 + 1 = 6
  j=2：使用 min1=1，dp[2] = 6 + 1 = 7
  dp = [6, 6, 7]

第 2 行：
  上一行最小值 min1=6（列0），次小值 min2=6（列1）
  j=0：列0 == min1_col，使用 min2=6，dp[0] = 7 + 6 = 13
  j=1：使用 min1=6，dp[1] = 8 + 6 = 14
  j=2：使用 min1=6，dp[2] = 9 + 6 = 15
  dp = [13, 14, 15]

结果：min(dp) = 13
```

## 关键点总结

1. **本题与 931 题的区别**：931 题是相邻列（只能移动到下一行的相邻列），本题是非同列（下一行任意列，只要不同列即可）
2. **核心优化思路**：记录最小值和次小值，避免每次 O(n) 枚举所有列
3. **次小值的作用**：当当前列恰好是最小值所在列时，使用次小值
4. **空间优化**：只需要维护一维 dp，不需要二维数组
5. **边界处理**：n=1 时，路径只有一个元素，直接返回 grid[0][0]

## 易错点

- **min1_col 的更新顺序**：更新 min1 时，必须先将 min1 的值转移给 min2，再更新 min1 和 min1_col
- **次小值 min2 的含义**：min2 是第二小的值，不是第二小且不同列的值（两者效果相同，因为如果最小列 j 下一行也取最小，那就用次小）
- **不能直接用 min(dp[i-1])**：如果不排除同列，结果可能错误
