## 题目描述

一条街道上有建筑物，每栋建筑物都有高度。给你一个整数 `n`，表示街道有 `n` 个位置（1 到 n）。

另给你一个二维整数数组 `buildings`，`buildings[i] = [start_i, end_i, height_i]` 表示一栋从位置 `start_i` 到 `end_i`（包含两端）高度为 `height_i` 的建筑物。

每个位置可能被多栋建筑物覆盖。一个位置的高度是覆盖它的所有建筑物的**平均高度**（向下取整）。

返回一个二维数组 `result`，`result[i] = [left_i, right_i, averageHeight_i]`，其中每段 `[left_i, right_i]` 的平均高度是连续且相同的。**相邻段的平均高度不同**，且段之间不能重叠。

**提示：**
- `1 <= n <= 10^7`
- `0 <= buildings.length <= 10^5`

## 解题思路

使用**差分数组 + 扫描线**思想：
- 对高度使用差分：在 `start` 处加 `height`，在 `end+1` 处减 `height`
- 对计数使用差分：在 `start` 处加 1，在 `end+1` 处减 1
- 扫描所有差分事件点，计算每段的平均高度
- 合并相邻等高段

## 代码实现

### 方法一：差分数组 + 扫描线（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def averageHeightOfBuildings(self, n: int, buildings: List[List[int]]) -> List[List[int]]:
        # 使用差分思想，记录所有事件点
        height_diff = defaultdict(int)  # 高度差分
        count_diff = defaultdict(int)   # 覆盖计数差分

        for start, end, height in buildings:
            height_diff[start] += height
            height_diff[end + 1] -= height
            count_diff[start] += 1
            count_diff[end + 1] -= 1

        result = []
        cur_height = 0  # 当前累积高度
        cur_count = 0   # 当前覆盖建筑数

        prev_pos = -1   # 上一个事件点
        prev_avg = -1   # 上一段的平均高度

        # 遍历所有事件点（排序后处理）
        for pos in sorted(height_diff.keys()):
            # 结算上一段（如果有覆盖）
            if cur_count > 0 and prev_pos != -1:
                avg = cur_height // cur_count
                if result and result[-1][2] == avg and result[-1][1] == prev_pos - 1:
                    # 与上一段合并
                    result[-1][1] = pos - 1
                else:
                    result.append([prev_pos, pos - 1, avg])

            # 更新差分
            cur_height += height_diff[pos]
            cur_count += count_diff[pos]
            prev_pos = pos

        # 处理最后一段（若有覆盖）
        if cur_count > 0:
            avg = cur_height // cur_count
            if result and result[-1][2] == avg and result[-1][1] == prev_pos - 1:
                result[-1][1] = n
            else:
                result.append([prev_pos, n, avg])

        return result
```

### 方法二：事件点排序扫描

```python
from typing import List

class Solution:
    def averageHeightOfBuildings(self, n: int, buildings: List[List[int]]) -> List[List[int]]:
        # 收集所有区间端点事件
        events = []
        for start, end, height in buildings:
            events.append((start, height, 1))    # 起点：高度+，计数+
            events.append((end + 1, -height, -1))  # 终点后：高度-，计数-

        events.sort()

        result = []
        total_height = 0
        total_count = 0
        prev = 1

        i = 0
        while i < len(events):
            pos = events[i][0]
            # 处理 [prev, pos-1] 段
            if total_count > 0 and prev <= pos - 1:
                avg = total_height // total_count
                if result and result[-1][2] == avg and result[-1][1] == prev - 1:
                    result[-1][1] = pos - 1
                else:
                    result.append([prev, pos - 1, avg])
            # 处理所有在 pos 位置的事件
            while i < len(events) and events[i][0] == pos:
                total_height += events[i][1]
                total_count += events[i][2]
                i += 1
            prev = pos

        return result
```

## 复杂度分析

- 时间复杂度：O(m log m)，m 为 buildings 数量（排序主导）
- 空间复杂度：O(m)，事件点数组

## 关键点总结

1. 差分数组思想：在区间两端打标记，通过前缀和还原每个位置的值
2. 只需处理有事件的关键点，不需要遍历所有 1 到 n 的位置
3. 合并相邻平均高度相同的段，减少输出长度

## 易错点

- 区间是闭区间 `[start, end]`，差分在 `end+1` 处减（不是 `end`）
- 注意整数除法：平均高度向下取整（`//`）
- 当 `cur_count == 0` 时该位置无建筑覆盖，不输出
