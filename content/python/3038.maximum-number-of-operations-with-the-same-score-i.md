## 题目描述

给你一个整数数组 `nums`，你可以执行以下操作任意次：

每次操作，从 `nums` 中选择前两个元素（下标 0 和 1），将它们相加得到分数，然后删除这两个元素。

所有操作必须具有相同的分数。

返回最多能执行多少次操作。

**示例 1：**
```
输入：nums = [3,2,1,4,5]
输出：2
解释：第一次：3+2=5（分数 5），第二次：1+4=5（分数 5），第三次不行（5 != 5+X 或只剩一个）
```

**示例 2：**
```
输入：nums = [3,2,6,1,4]
输出：1
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 解题思路

第一次操作的分数固定为 `nums[0] + nums[1]`，之后每次操作取前两个元素，分数必须相同。

从前往后，每次取两个元素求和，如果等于第一次的分数则继续，否则停止。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def maxOperations(self, nums: List[int]) -> int:
        n = len(nums)
        if n < 2:
            return 0

        target = nums[0] + nums[1]
        count = 0

        i = 0
        while i + 1 < n:
            if nums[i] + nums[i+1] == target:
                count += 1
                i += 2
            else:
                break

        return count
```

### 方法二：列表推导

```python
from typing import List

class Solution:
    def maxOperations(self, nums: List[int]) -> int:
        if len(nums) < 2:
            return 0

        target = nums[0] + nums[1]
        count = 0

        for i in range(0, len(nums) - 1, 2):
            if nums[i] + nums[i+1] == target:
                count += 1
            else:
                break

        return count
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 目标分数由第一次操作（前两个元素）决定
2. 从前往后，连续取两个元素，一旦分数不同则停止

## 易错点

1. 注意遇到不满足条件时立即停止（break），不能跳过
2. 步长为 2，不是 1
