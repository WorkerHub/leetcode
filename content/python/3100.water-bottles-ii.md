## 题目描述

给你两个整数 `numBottles`（初始满瓶数）和 `numExchange`（每次换空瓶所需数量，且每次交换后 `numExchange` 加 1）。

你可以饮用所有满瓶，并可以用空瓶换取满瓶（每 `numExchange` 个空瓶换 1 瓶）。

返回最多能喝到的瓶数。

**示例 1：**
```
输入：numBottles = 13, numExchange = 6
输出：15
```

**示例 2：**
```
输入：numBottles = 10, numExchange = 3
输出：13
```

**提示：**
- `1 <= numBottles <= 100`
- `1 <= numExchange <= 100`

## 解题思路

模拟过程：
1. 喝掉所有满瓶，得到空瓶
2. 若空瓶数 >= numExchange，换 1 瓶满瓶，numExchange 加 1
3. 重复直到空瓶数不够兑换

## Python 代码实现

### 方法一：模拟（推荐）

```python
class Solution:
    def maxBottlesDrunk(self, numBottles: int, numExchange: int) -> int:
        total = numBottles  # 总喝了的瓶数
        empty = numBottles  # 当前空瓶数

        while empty >= numExchange:
            # 用 numExchange 个空瓶换 1 瓶
            empty -= numExchange
            numExchange += 1  # 下次兑换需要更多空瓶
            total += 1
            empty += 1  # 喝掉新换的瓶，得到 1 个空瓶

        return total
```

### 方法二：等价写法

```python
class Solution:
    def maxBottlesDrunk(self, numBottles: int, numExchange: int) -> int:
        drunk = numBottles
        empties = numBottles
        rate = numExchange

        while empties >= rate:
            empties = empties - rate + 1  # 用 rate 个换 1 个，再喝掉得 1 个空瓶
            rate += 1
            drunk += 1

        return drunk
```

## 复杂度分析

- 时间复杂度：O(sqrt(n))，兑换次数不超过 sqrt(2 * numBottles)
- 空间复杂度：O(1)

## 关键点总结

1. 每次兑换后 `numExchange` 增加 1，兑换难度递增
2. 每次兑换：消耗 `numExchange` 个空瓶，得到 1 个满瓶 → 喝掉 → 得 1 个空瓶
3. 净变化：空瓶数减少 `numExchange - 1`，总喝数 +1

## 易错点

1. 兑换后 `numExchange` 立即增加（下次兑换用新值）
2. 换来的满瓶喝掉后变成空瓶（empty += 1）
3. 总喝瓶数包含初始瓶和换来的瓶
