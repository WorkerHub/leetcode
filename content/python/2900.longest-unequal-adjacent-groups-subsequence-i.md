## 题目描述

给你一个长度为 `n` 的字符串数组 `words` 和一个长度为 `n` 的**二进制数组** `groups`（只含 0 和 1）。

你需要选出 `words` 的一个**最长子序列**，满足子序列中相邻元素对应的 `groups` 值**不同**（即交替出现 0 和 1）。

若有多个最长子序列，返回任意一个（字典序最小也可以）。

**示例 1：**
```
输入：words = ["e","a","b"], groups = [0, 0, 1]
输出：["e","b"] 或 ["a","b"]
解释：
选下标 0, 2：groups = [0, 1]，相邻不同，长度 2
选下标 1, 2：groups = [0, 1]，相邻不同，长度 2
不能选 0, 1（groups 都是 0）
```

**示例 2：**
```
输入：words = ["a","b","c","d"], groups = [1, 0, 1, 1]
输出：["a","b","c"]
解释：选下标 0,1,2，groups = [1,0,1]，交替不同，长度 3
```

**提示：**
- `1 <= n <= 100`
- `words[i]` 只含英文小写字母
- `groups[i]` 为 0 或 1

## 解题思路

**贪心：**

从左到右扫描，每次遇到与上一个选中元素 `groups` 不同的元素，就将其加入结果。

这是最优的，因为我们不跳过任何可以加入的元素，保证了子序列长度最长。

**为什么贪心有效？**

若当前元素 `groups[i]` 与上一个选中的不同，则选它一定不差（可以让后续有更多选择）。

## Python 代码实现

### 方法一：贪心扫描（推荐）

```python
from typing import List

class Solution:
    def getLongestSubsequence(self, words: List[str], groups: List[int]) -> List[str]:
        ans = [words[0]]
        last_group = groups[0]

        for i in range(1, len(words)):
            if groups[i] != last_group:
                ans.append(words[i])
                last_group = groups[i]

        return ans
```

### 方法二：动态规划（标准 LIS 变体）

```python
from typing import List

class Solution:
    def getLongestSubsequence(self, words: List[str], groups: List[int]) -> List[str]:
        n = len(words)
        # dp[i] = 以 i 结尾的最长交替子序列长度
        dp = [1] * n
        prev = [-1] * n  # 记录前驱下标，用于重建路径

        for i in range(1, n):
            for j in range(i - 1, -1, -1):
                if groups[j] != groups[i] and dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    prev[i] = j
                    break  # 找到最近的不同 group 即可（贪心）

        # 找最大 dp 值的结尾位置
        end = dp.index(max(dp))

        # 重建路径
        path = []
        while end != -1:
            path.append(words[end])
            end = prev[end]

        return path[::-1]
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)（不含输出）
- 方法二：时间复杂度 O(n^2)，空间复杂度 O(n)

## 关键点总结

1. 贪心：遇到与上一个不同 group 的元素就选，保证最长
2. 等价于求 groups 数组的最长交替子序列
3. 由于 groups 只有 0 和 1，最长交替子序列就是去掉连续重复后的长度

## 易错点

1. 子序列（subsequence）不需要连续，但保持相对顺序
2. 返回的是 `words` 中的字符串，不是下标
3. 第一个元素一定选入结果（初始化时加入）
