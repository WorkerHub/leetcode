## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，对于每个长度为 `k` 的子数组，计算其中不同整数的数目，返回由这些计数值组成的数组。

**示例：**
```
输入：nums = [1,2,3,2,2,1,3], k = 3
输出：[3,2,2,2,3]
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**滑动窗口 + 哈希表**：

维护一个大小为 k 的滑动窗口，用哈希表记录窗口内每个元素的频率。窗口向右滑动时：
- 加入新元素，若频率从 0 变为 1，不同数计数 +1
- 移除旧元素，若频率从 1 变为 0，不同数计数 -1

## 代码实现

### 方法一：滑动窗口 + 频率哈希表（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def distinctNumbers(self, nums: List[int], k: int) -> List[int]:
        freq = defaultdict(int)
        distinct = 0
        result = []
        n = len(nums)

        for i in range(n):
            # 加入右端新元素
            if freq[nums[i]] == 0:
                distinct += 1
            freq[nums[i]] += 1

            # 移除超出窗口的左端元素
            if i >= k:
                left = nums[i - k]
                freq[left] -= 1
                if freq[left] == 0:
                    distinct -= 1

            # 窗口大小达到 k 时记录结果
            if i >= k - 1:
                result.append(distinct)

        return result
```

### 方法二：使用 Counter 滑动窗口

```python
from collections import Counter
from typing import List

class Solution:
    def distinctNumbers(self, nums: List[int], k: int) -> List[int]:
        # 初始化第一个窗口
        window = Counter(nums[:k])
        result = [len(window)]

        for i in range(k, len(nums)):
            # 加入新元素
            window[nums[i]] += 1
            # 移除旧元素
            old = nums[i - k]
            window[old] -= 1
            if window[old] == 0:
                del window[old]
            result.append(len(window))

        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多入窗口和出窗口各一次
- **空间复杂度**：O(k)，窗口内最多 k 个不同元素

## 关键点总结

1. 滑动窗口维护频率字典，通过计数变化来更新不同数的数量
2. 在频率降为 0 时删除该键（或减少不同数计数），不需要重新扫描整个窗口
3. 方法二使用 Counter，自动处理字典操作

## 易错点

- 删除旧元素时，频率降为 0 才减少不同数计数，不能仅仅减少频率
- 窗口大小恰好为 k 时才开始记录结果（索引 i >= k-1）
