## 题目描述

一条街道上共有 `n * 2` 块地，分成 `n` 对，每对相邻地块的其中一块朝向街道正面，另一块朝向后面。总共有 `n` 对，前 `n` 块为正面，后 `n` 块为背面。

你需要给这些地块安置房子，规则是**同一侧**的相邻地块不能同时有房子（即同侧不能连续安置房子）。

返回安置房子的方式数目。由于答案可能很大，请取 `10^9 + 7` 的模。

注意，两侧安置方案彼此独立。

**示例 1：**
```
输入：n = 1
输出：4
解释：每侧 1 块地，各有 2 种方案（放或不放），共 2*2=4 种。
```

**示例 2：**
```
输入：n = 2
输出：9
解释：每侧 2 块地，各有 3 种方案（00,01,10），共 3*3=9 种。
```

**提示：**
- `1 <= n <= 10^4`

## 解题思路

两侧独立，先求单侧 n 块地的方案数 `f(n)`，答案为 `f(n)^2 % MOD`。

**单侧 DP：**
设 `dp[i]` 为前 `i` 块地的合法方案数：
- `dp[0] = 1`（空）
- `dp[1] = 2`（放或不放）
- `dp[i] = dp[i-1] + dp[i-2]`（第 i 块不放，方案数为 `dp[i-1]`；第 i 块放，则第 i-1 块必须不放，方案数为 `dp[i-2]`）

这实际上是斐波那契数列！

## 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def countHousePlacements(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        
        # 计算单侧 n 块地的方案数
        if n == 1:
            return 4  # 2 * 2
        
        # dp[i] 表示前 i 块地的方案数
        prev2 = 1  # dp[0]
        prev1 = 2  # dp[1]
        
        for i in range(2, n + 1):
            cur = (prev1 + prev2) % MOD
            prev2 = prev1
            prev1 = cur
        
        # 两侧独立，方案数相乘
        return (prev1 * prev1) % MOD
```

### 方法二：斐波那契数组

```python
class Solution:
    def countHousePlacements(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        
        # 单侧斐波那契
        fib = [0] * (n + 1)
        fib[0] = 1  # 0 块地：1 种方案
        if n >= 1:
            fib[1] = 2
        for i in range(2, n + 1):
            fib[i] = (fib[i - 1] + fib[i - 2]) % MOD
        
        # 两侧方案数相乘
        return (fib[n] * fib[n]) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滚动变量 DP | O(n) | O(1) |
| 数组 DP | O(n) | O(n) |

## 关键点总结

1. 两侧独立，答案为单侧方案数的平方。
2. 单侧问题等价于斐波那契：不放 or 放（上一块不放）。
3. 注意取模在每步计算中进行，避免大数问题。

## 易错点

- 两侧**独立**意味着方案数是相乘，不是相加。
- `fib[0] = 1`（空序列只有一种方案），`fib[1] = 2`（放或不放）。
