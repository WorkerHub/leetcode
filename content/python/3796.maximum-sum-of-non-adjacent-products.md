## 题目描述

给定整数数组 `nums`，选择若干个不相邻的元素对 `(i, i+1)`（即选某个位置 `i` 后，位置 `i-1` 和 `i+2` 就不能再选），使选出的相邻元素对的乘积之和最大。返回最大乘积和，结果对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：10
解释：选 (1,2) 和 (4,5)，乘积和 = 1*2 + 4*5 = 2 + 20 = 22？
     或选 (2,3) 乘积和 = 6，再选 (5) 不是对...
     选不相邻对：(0,1) 和 (3,4)，乘积 = 2 + 20 = 22。
```

**示例 2：**
```
输入：nums = [3,5]
输出：15
解释：只有一对 (3,5)，乘积 = 15。
```

**提示：**
- `2 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

**动态规划：**

选择一对 `(i, i+1)` 后，下一对至少从 `i+2` 开始（实际上要从 `i+3` 开始，因为 `i+2` 与 `i+1` 相邻会被禁止）。

设 `dp[i]` 为考虑前 `i` 个元素时的最大乘积和：
- 不选以 `i` 结尾的对：`dp[i] = dp[i-1]`
- 选以 `(i-1, i)` 结尾的对（即第 `i-1` 和第 `i` 个元素）：`dp[i] = dp[i-2] + nums[i-1] * nums[i]`（0-indexed 下为 `nums[i-2] * nums[i-1]`）

注意：选了对 `(i-1, i)` 之后，`i+1` 和 `i-2` 都不能与已选对相邻，因此状态转移需跳过一个位置。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        if n < 2:
            return 0

        # dp[i]: 前 i 个元素（0-indexed: nums[0..i-1]）的最大乘积和
        # dp[0] = 0, dp[1] = 0（1个元素无法构成对）
        # dp[i] = max(dp[i-1], dp[i-2] + nums[i-2]*nums[i-1])
        # （选或不选以 i-1 结尾的对）
        dp_prev2 = 0  # dp[i-2]
        dp_prev1 = 0  # dp[i-1]

        for i in range(2, n + 1):
            # 选 (nums[i-2], nums[i-1]) 这一对
            product = nums[i - 2] * nums[i - 1]
            dp_cur = max(dp_prev1, dp_prev2 + product)
            dp_prev2 = dp_prev1
            dp_prev1 = dp_cur

        return dp_prev1 % MOD
```

### 方法二：完整 DP 数组版本

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # dp[i]: 从 nums[0..i-1] 中选不相邻对的最大乘积和
        dp = [0] * (n + 1)

        for i in range(2, n + 1):
            # 不选以 i-1 结尾的对
            dp[i] = dp[i - 1]
            # 选 (nums[i-2], nums[i-1]) 这一对，上一对最晚到 i-3
            if i >= 2:
                dp[i] = max(dp[i], (dp[i - 2] if i >= 2 else 0) + nums[i - 2] * nums[i - 1])

        return dp[n] % MOD
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 每次选一对相邻元素 `(i, i+1)` 贡献 `nums[i] * nums[i+1]`
2. 选了某对后，相邻对不能再选（间隔至少 2 个位置）
3. 类似打家劫舍问题，状态转移为选或不选当前对

## 易错点

1. 索引偏移：`dp[i]` 对应 `nums[0..i-1]`，选对时用 `nums[i-2]*nums[i-1]`
2. 注意取模（乘积可能很大）
3. 不相邻是指选的对不能共享元素
