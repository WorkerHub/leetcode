## 题目描述

给你一个链表的头节点 `head`，链表中的所有节点按**绝对值**的非递减顺序排列。请返回按**实际值**的非递减顺序排列的链表。

**示例 1：**
```
输入：head = [0,2,-5,5,10,-10]
输出：[-10,-5,0,2,5,10]
```

**示例 2：**
```
输入：head = [0,1,2]
输出：[0,1,2]
```

**提示：**
- 链表节点数目在 `[1, 10^5]` 范围内
- `-5000 <= Node.val <= 5000`
- 链表按绝对值的非递减顺序排列

## 解题思路

由于链表已按绝对值排序，负数部分是**单调递减**（绝对值递增即负值递减），正数部分是**单调递增**。

**将链表分为两条链：**
1. 负数链（按绝对值递增，即按实际值递减）
2. 非负数链（按实际值递增）

将负数链**反转**后，与非负数链**合并**（类似归并排序的合并步骤）。

## 代码实现

### 方法一：分离 + 反转 + 合并（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortLinkedList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 分离负数链和非负数链
        neg_head = None   # 负数链头（反向构建为头插法）
        pos_dummy = ListNode(0)
        pos_tail = pos_dummy

        cur = head
        while cur:
            nxt = cur.next
            if cur.val < 0:
                # 头插到负数链（使负数链按绝对值递减，即实际值递增）
                cur.next = neg_head
                neg_head = cur
            else:
                # 追加到正数链尾
                pos_tail.next = cur
                cur.next = None
                pos_tail = cur
            cur = nxt

        # 合并负数链（已升序）和正数链（已升序）
        dummy = ListNode(0)
        tail = dummy
        p1, p2 = neg_head, pos_dummy.next

        while p1 and p2:
            if p1.val <= p2.val:
                tail.next = p1
                p1 = p1.next
            else:
                tail.next = p2
                p2 = p2.next
            tail = tail.next

        tail.next = p1 if p1 else p2
        return dummy.next
```

### 方法二：提取值排序后重建（简单但非最优）

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortLinkedList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 提取所有值，排序，重建链表
        vals = []
        cur = head
        while cur:
            vals.append(cur.val)
            cur = cur.next

        vals.sort()  # 排序

        # 重建链表
        cur = head
        for v in vals:
            cur.val = v
            cur = cur.next

        return head
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 分离+反转+合并 | O(n) | O(1) |
| 提取排序重建 | O(n log n) | O(n) |

## 关键点总结

1. 链表按绝对值排序，负数部分自然是"反向"的（用头插法使之变为升序）
2. 分为负数链（头插反转）和正数链，再归并合并
3. 归并合并两个有序链表是经典操作

## 易错点

- 头插时要断开节点的 `next` 指针，防止成环
- 合并后 `tail.next` 需要设为 `None`（来自原链表的节点可能有残留 `next`）
