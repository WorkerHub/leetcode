## 题目描述

给你一个整数数组 `nums`，选取两个下标 `i` 和 `j`（不要求 i != j）组成 **强对**，满足 `|nums[i] - nums[j]| <= min(nums[i], nums[j])`。

返回所有强对中 `nums[i] XOR nums[j]` 的最大值。

**提示：**
- `1 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 2^20 - 1`

## 解题思路

强对条件：`|x - y| <= min(x, y)` 等价于 `max(x,y) <= 2 * min(x,y)`，即排序后 `y <= 2x`（x <= y）。

n 大，需要 O(n log^2 n) 或 O(n log n) 解法。

使用字典树（Trie）+ 滑动窗口：
1. 将 nums 排序
2. 使用双指针，右指针 j 从 0 到 n-1 遍历，维护左指针 i 使得 nums[j] <= 2*nums[i]（即 nums[i] >= nums[j]/2）
3. 对每个 j，从字典树中查询与 nums[j] XOR 最大的值（字典树中存的是 nums[left..j-1] 中满足条件的值）
4. 字典树随左右指针动态增删

## Python 代码实现

### 方法一：字典树 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        BITS = 20  # nums[i] < 2^20

        # 字典树节点：children[0/1], count（记录引用计数用于删除）
        trie = {}

        def insert(val, delta):
            node = trie
            for bit in range(BITS - 1, -1, -1):
                b = (val >> bit) & 1
                if b not in node:
                    node[b] = {'cnt': 0}
                node[b]['cnt'] += delta
                node = node[b]

        def query_max_xor(val):
            node = trie
            xor = 0
            for bit in range(BITS - 1, -1, -1):
                b = (val >> bit) & 1
                want = 1 - b  # 希望的位，使 XOR 最大
                if want in node and node[want].get('cnt', 0) > 0:
                    xor |= (1 << bit)
                    node = node[want]
                elif b in node and node[b].get('cnt', 0) > 0:
                    node = node[b]
                else:
                    break
            return xor

        ans = 0
        left = 0

        for right in range(n):
            insert(nums[right], 1)
            # 移除不满足条件的左端（nums[right] > 2 * nums[left]）
            while nums[right] > 2 * nums[left]:
                insert(nums[left], -1)
                left += 1
            # 查询字典树中与 nums[right] XOR 最大的值
            ans = max(ans, query_max_xor(nums[right]))

        return ans
```

### 方法二：暴力（小数据验证）

```python
from typing import List

class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        nums.sort()
        ans = 0
        n = len(nums)
        for i in range(n):
            for j in range(i, n):
                if nums[j] <= 2 * nums[i]:
                    ans = max(ans, nums[i] ^ nums[j])
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log(maxVal))，排序 O(n log n)，每次插入/查询 O(log(maxVal))
- 空间复杂度：O(n * BITS)，字典树存储

## 关键点总结

1. 排序后强对条件变为 y <= 2x（x <= y），用双指针维护有效区间
2. 字典树支持高效查询最大 XOR
3. 字典树需要支持删除（用引用计数），随左指针移动删除过期元素

## 易错点

1. 字典树需要支持"删除"操作（引用计数），因为左端元素会被移除
2. 查询最大 XOR 时，若希望的位不存在则退而求次
3. 包含自身（i == j），因此 right 加入字典树后直接查询（包含 nums[right] 自身）
