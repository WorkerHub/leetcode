## 题目描述

使用下面描述的算法可以扰乱字符串 `s` 得到字符串 `t`：
1. 如果字符串的长度为 1，算法停止
2. 如果字符串的长度 > 1，执行下述步骤：
   - 在一个随机下标处将字符串分割成两个非空的子字符串。即，如果已知字符串 `s`，则可以将其分成两个子字符串 `x` 和 `y`，且满足 `s = x + y`
   - 随机决定是要「交换两个子字符串」还是要「保持这两个子字符串的顺序不变」。即，在执行这一步骤之后，`s` 可能是 `s = x + y` 或者 `s = y + x`
   - 在 `x` 和 `y` 这两个子字符串上继续从步骤 1 开始递归执行此算法

给定两个长度相等的字符串 `s1` 和 `s2`，判断 `s2` 是否是 `s1` 的扰乱字符串。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s1 = "great", s2 = "rgeat"
输出：true
解释：s1 上可能发生的一种情形是：
"great" --> "gr/eat" // 在一个随机下标处分割得到两个子字符串
"gr/eat" --> "gr/eat" // 随机决定：「保持这两个子字符串的顺序不变」
"gr/eat" --> "g/r / e/at" // 在子字符串上递归执行此算法，两个子字符串分别在随机下标处进行一轮分割
"g/r / e/at" --> "r/g / e/at" // 随机决定：第一组「交换两个子字符串」，第二组「保持这两个子字符串的顺序不变」
"r/g / e/at" --> "r/g / e/ a/t" // 继续递归执行此算法，将 "at" 分割得到 "a/t"
"r/g / e/ a/t" --> "r/g / e/ a/t" // 随机决定：「保持这两个子字符串的顺序不变」
算法终止，结果字符串和 s2 相同，都是 "rgeat"
这是一种能够扰乱 s1 得到 s2 的情形，可以认为 s2 是 s1 的扰乱字符串，返回 true
```

**示例 2：**
```
输入：s1 = "abcde", s2 = "caebd"
输出：false
```

**示例 3：**
```
输入：s1 = "a", s2 = "a"
输出：true
```

**提示：**
- `s1.length == s2.length`
- `1 <= s1.length <= 30`
- `s1` 和 `s2` 由小写英文字母组成

## 解题思路

核心思想：使用递归 + 记忆化搜索，枚举所有可能的分割点。

**关键观察：**
1. 如果 `s1` 和 `s2` 长度不同，直接返回 `false`
2. 如果 `s1` 和 `s2` 完全相同，返回 `true`
3. 如果 `s1` 和 `s2` 的字符集不同（字符频次不同），返回 `false`
4. 对于每个分割点 i，有两种情况：
   - **不交换**：`s1[:i]` 对应 `s2[:i]`，且 `s1[i:]` 对应 `s2[i:]`
   - **交换**：`s1[:i]` 对应 `s2[-i:]`，且 `s1[i:]` 对应 `s2[:-i]`

**算法流程：**
1. 剪枝：检查长度、完全相同、字符集
2. 枚举所有分割点 i (1 到 n-1)
3. 对于每个分割点，递归检查两种情况
4. 使用记忆化避免重复计算

## Python 代码实现

### 方法一：递归 + 记忆化（推荐）

```python
from collections import Counter

class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        # 记忆化缓存
        memo = {}
        
        def dfs(s1: str, s2: str) -> bool:
            # 如果已经计算过，直接返回
            if (s1, s2) in memo:
                return memo[(s1, s2)]
            
            # 基本情况：完全相同
            if s1 == s2:
                return True
            
            # 剪枝：字符集不同
            if Counter(s1) != Counter(s2):
                memo[(s1, s2)] = False
                return False
            
            n = len(s1)
            
            # 枚举所有分割点
            for i in range(1, n):
                # 情况1：不交换
                # s1[:i] -> s2[:i], s1[i:] -> s2[i:]
                if dfs(s1[:i], s2[:i]) and dfs(s1[i:], s2[i:]):
                    memo[(s1, s2)] = True
                    return True
                
                # 情况2：交换
                # s1[:i] -> s2[-i:], s1[i:] -> s2[:-i]
                if dfs(s1[:i], s2[-i:]) and dfs(s1[i:], s2[:-i]):
                    memo[(s1, s2)] = True
                    return True
            
            # 所有分割点都不满足
            memo[(s1, s2)] = False
            return False
        
        return dfs(s1, s2)
```

### 方法二：三维动态规划

```python
class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        n = len(s1)
        
        # dp[i][j][k] 表示 s1[i:i+k] 和 s2[j:j+k] 是否互为扰乱字符串
        dp = [[[False] * (n + 1) for _ in range(n)] for _ in range(n)]
        
        # 初始化：长度为 1 的子串
        for i in range(n):
            for j in range(n):
                dp[i][j][1] = (s1[i] == s2[j])
        
        # 枚举子串长度
        for length in range(2, n + 1):
            # 枚举 s1 的起始位置
            for i in range(n - length + 1):
                # 枚举 s2 的起始位置
                for j in range(n - length + 1):
                    # 枚举分割点
                    for k in range(1, length):
                        # 情况1：不交换
                        if dp[i][j][k] and dp[i + k][j + k][length - k]:
                            dp[i][j][length] = True
                            break
                        
                        # 情况2：交换
                        if dp[i][j + length - k][k] and dp[i + k][j][length - k]:
                            dp[i][j][length] = True
                            break
        
        return dp[0][0][n]
```

### 方法三：优化的递归（使用索引）

```python
from collections import Counter

class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        memo = {}
        
        def dfs(i1: int, i2: int, length: int) -> bool:
            # 记忆化
            if (i1, i2, length) in memo:
                return memo[(i1, i2, length)]
            
            # 提取子串
            str1 = s1[i1:i1 + length]
            str2 = s2[i2:i2 + length]
            
            # 完全相同
            if str1 == str2:
                return True
            
            # 字符集不同
            if Counter(str1) != Counter(str2):
                memo[(i1, i2, length)] = False
                return False
            
            # 枚举分割点
            for k in range(1, length):
                # 不交换
                if dfs(i1, i2, k) and dfs(i1 + k, i2 + k, length - k):
                    memo[(i1, i2, length)] = True
                    return True
                
                # 交换
                if dfs(i1, i2 + length - k, k) and dfs(i1 + k, i2, length - k):
                    memo[(i1, i2, length)] = True
                    return True
            
            memo[(i1, i2, length)] = False
            return False
        
        return dfs(0, 0, len(s1))
```

## 复杂度分析

**方法一（递归 + 记忆化）：**
- 时间复杂度：O(n^4)，状态数 O(n^3)，每个状态需要 O(n) 枚举分割点
- 空间复杂度：O(n^3)，记忆化缓存

**方法二（三维 DP）：**
- 时间复杂度：O(n^4)，三层循环枚举状态，一层循环枚举分割点
- 空间复杂度：O(n^3)，三维 DP 数组

**方法三（优化索引）：**
- 时间复杂度：O(n^4)
- 空间复杂度：O(n^3)

## 关键点总结

1. **递归定义**：问题可以分解为子问题，适合递归求解
2. **两种情况**：每个分割点有交换和不交换两种可能
3. **剪枝优化**：通过字符频次快速排除不可能的情况
4. **记忆化**：避免重复计算相同的子问题
5. **状态表示**：可以用字符串对或索引三元组表示状态

## 易错点

1. **分割点范围**：应该是 `range(1, n)`，不包括 0 和 n
2. **索引对应**：交换时，s1 的前 i 个字符对应 s2 的后 i 个字符
3. **剪枝条件**：使用 Counter 比较字符集，而不是简单的排序比较
4. **边界情况**：长度为 1 时直接比较字符相等性
