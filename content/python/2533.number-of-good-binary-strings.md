## 题目描述

给你四个整数 `minLength`、`maxLength`、`oneGroup` 和 `zeroGroup`。

**好二进制字符串** 是满足以下条件的二进制字符串：
- 长度在 `[minLength, maxLength]` 之间
- 字符串中每个 `1` 的组的长度都是 `oneGroup` 的倍数
- 字符串中每个 `0` 的组的长度都是 `zeroGroup` 的倍数

返回满足条件的不同好二进制字符串的数目（对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：minLength = 2, maxLength = 3, oneGroup = 1, zeroGroup = 2
输出：2
解释：好字符串为 "00" 和 "11"。
```

**示例 2：**

```
输入：minLength = 4, maxLength = 4, oneGroup = 4, zeroGroup = 4
输出：2
解释："0000" 和 "1111"。
```

**提示：**

- `1 <= minLength <= maxLength <= 10^5`
- `1 <= oneGroup, zeroGroup <= maxLength`

## 解题思路

**动态规划**：`dp[i]` = 长度恰好为 i 的好二进制字符串数目。

转移：在长度为 i 的好字符串末尾，可以通过追加：
- `zeroGroup` 个 0（从 dp[i - zeroGroup] 转移）
- `oneGroup` 个 1（从 dp[i - oneGroup] 转移）

最终答案 = sum(dp[minLength..maxLength])。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
MOD = 10**9 + 7

class Solution:
    def goodBinaryStrings(self, minLength: int, maxLength: int, oneGroup: int, zeroGroup: int) -> int:
        # dp[i] = 长度为 i 的好二进制字符串数目
        dp = [0] * (maxLength + 1)
        dp[0] = 1  # 空字符串

        for i in range(1, maxLength + 1):
            # 在长度为 i-zeroGroup 的好字符串后追加 zeroGroup 个 0
            if i >= zeroGroup:
                dp[i] = (dp[i] + dp[i - zeroGroup]) % MOD
            # 在长度为 i-oneGroup 的好字符串后追加 oneGroup 个 1
            if i >= oneGroup:
                dp[i] = (dp[i] + dp[i - oneGroup]) % MOD

        return sum(dp[minLength:maxLength + 1]) % MOD
```

### 方法二：带前缀和加速

```python
MOD = 10**9 + 7

class Solution:
    def goodBinaryStrings(self, minLength: int, maxLength: int, oneGroup: int, zeroGroup: int) -> int:
        dp = [0] * (maxLength + 1)
        dp[0] = 1

        for i in range(1, maxLength + 1):
            if i >= zeroGroup:
                dp[i] += dp[i - zeroGroup]
            if i >= oneGroup:
                dp[i] += dp[i - oneGroup]
            dp[i] %= MOD

        ans = 0
        for i in range(minLength, maxLength + 1):
            ans = (ans + dp[i]) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(maxLength)，线性 DP
- 空间复杂度：O(maxLength)，DP 数组

## 关键点总结

1. DP 状态转移：好字符串通过在末尾添加完整的 0 组或 1 组构建
2. 空字符串是 dp[0] = 1 的基础状态
3. 最终对 [minLength, maxLength] 范围内的 dp 值求和

## 易错点

1. 边界条件：dp[0] = 1，表示空字符串是有效起点
2. 每次添加的是整组（zeroGroup 个 0 或 oneGroup 个 1），不是单个字符
3. 注意取模，累加可能超过 MOD
