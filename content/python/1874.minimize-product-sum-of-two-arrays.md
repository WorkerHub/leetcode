## 题目描述

给你两个长度相同的整数数组 `nums1` 和 `nums2`，将 `nums1` 中的元素与 `nums2` 中的元素一一配对（可以重排 `nums1`），使得所有配对的乘积之和**最小**，返回该最小乘积之和。

**示例 1：**
```
输入：nums1 = [5,3,4,2], nums2 = [4,2,2,5]
输出：40
解释：nums1 升序后 [2,3,4,5]，nums2 降序后 [5,4,2,2]，乘积为 2*5+3*4+4*2+5*2=10+12+8+10=40
```

**示例 2：**
```
输入：nums1 = [2,1,4,5,7], nums2 = [3,2,4,8,6]
输出：65
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`

## 解题思路

**贪心**：将一个数组升序排列，另一个数组降序排列，然后一一配对，乘积之和最小。

**证明**（排序不等式）：对于任意两对 `(a, b)` 和 `(c, d)`，若 `a < c`，则 `a*d + c*b <= a*b + c*d`（即大配小、小配大更优）。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def minProductSum(self, nums1: List[int], nums2: List[int]) -> int:
        nums1.sort()               # 升序
        nums2.sort(reverse=True)   # 降序
        return sum(a * b for a, b in zip(nums1, nums2))
```

### 方法二：等价写法

```python
from typing import List

class Solution:
    def minProductSum(self, nums1: List[int], nums2: List[int]) -> int:
        nums1.sort()
        nums2.sort()
        n = len(nums1)
        # nums1 升序，nums2 降序等价于 nums2[-1-i] 配 nums1[i]
        return sum(nums1[i] * nums2[n - 1 - i] for i in range(n))
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 排序不等式：大配小、小配大乘积之和最小
2. 一个升序，另一个降序，然后 zip 配对

## 易错点

- 两个数组必须一个升序一个降序，不能同向
