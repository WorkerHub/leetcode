## 题目描述

给你一个整数数组 `arr`，以及 `a`、`b`、`c` 三个整数。

请你统计其中**好三元组**的数量。如果三元组 `(arr[i], arr[j], arr[k])` 满足下列全部条件，则认为它是一个好三元组：
- `0 <= i < j < k < arr.length`
- `|arr[i] - arr[j]| <= a`
- `|arr[j] - arr[k]| <= b`
- `|arr[i] - arr[k]| <= c`

**示例 1：**
```
输入：arr = [3,0,1,1,9,7], a = 7, b = 2, c = 3
输出：4
```

**提示：**
- `3 <= arr.length <= 100`
- `0 <= arr[i] <= 1000`
- `0 <= a, b, c <= 1000`

## 解题思路

### 暴力三重循环

数组长度最多 100，三重循环复杂度 O(N^3) = O(10^6)，完全可以接受。

## 代码实现

### 方法一：三重循环（推荐）

```python
from typing import List

class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        n = len(arr)
        count = 0
        for i in range(n):
            for j in range(i + 1, n):
                # 先检查条件一，提前剪枝
                if abs(arr[i] - arr[j]) > a:
                    continue
                for k in range(j + 1, n):
                    if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c:
                        count += 1
        return count
```

### 方法二：使用 itertools.combinations

```python
from typing import List
from itertools import combinations

class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        count = 0
        for i, j, k in combinations(range(len(arr)), 3):
            if (abs(arr[i] - arr[j]) <= a and
                abs(arr[j] - arr[k]) <= b and
                abs(arr[i] - arr[k]) <= c):
                count += 1
        return count
```

### 方法三：更简洁的三层嵌套

```python
from typing import List

class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        n = len(arr)
        return sum(
            1
            for i in range(n)
            for j in range(i + 1, n) if abs(arr[i] - arr[j]) <= a
            for k in range(j + 1, n)
            if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c
        )
```

## 复杂度分析

- **时间复杂度**：O(N^3)，N=100 时约 10^6 次运算，可接受
- **空间复杂度**：O(1)

## 关键点总结

1. 直接暴力枚举三元组，数组规模小（≤100）完全够用
2. 提前剪枝（条件一不满足就跳过内层循环）可以减少常数

## 易错点

- 三个条件必须同时满足（AND 关系），不是 OR
- 下标必须满足 `i < j < k`
