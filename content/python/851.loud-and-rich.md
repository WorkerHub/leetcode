## 题目描述

有一组 n 个人作为实验对象，从 0 到 n - 1 编号，其中每个人都有不同数目的钱，以及不同程度的安静值（quietness）。

为了方便起见，我们将编号为 x 的人简称为 "person x "。

给你一个数组 richer ，其中 richer[i] = [ai, bi] 表示 person ai 比 person bi 更有钱。另给你一个整数数组 quiet ，其中 quiet[i] 是 person i 的安静值。

richer 中所给出的数据 逻辑自洽（也就是说，在 person x 比 person y 更有钱的同时，不会出现 person y 比 person x 更有钱的情况）。

现在，返回一个整数数组 answer 作为答案，其中 answer[x] = y 的前提是，在所有拥有的钱肯定不少于 person x 的人中，person y 是最安静的人（也就是安静值 quiet[y] 最小的人）。

**示例 1：**
```
输入：richer = [[1,0],[2,1],[3,1],[3,7],[4,3],[5,3],[6,3]], quiet = [3,2,5,4,6,1,7,0]
输出：[5,5,2,5,4,5,6,7]
解释：
answer[0] = 5，
person 5 比 person 3 有更多的钱，person 3 比 person 1 有更多的钱，person 1 比 person 0 有更多的钱。
唯一较为安静（有较低的安静值 quiet[x]）的人是 person 7，
但是目前还不清楚他是否比 person 0 有更多的钱。
answer[7] = 7，
在所有拥有的钱肯定不少于 person 7 的人中（这可能包括 person 3，4，5，6 以及 7），
最安静（有较低安静值 quiet[x]）的人是 person 7。
其他的答案也可以用类似的推理来解释。
```

**示例 2：**
```
输入：richer = [], quiet = [0]
输出：[0]
```

**提示：**
- n == quiet.length
- 1 <= n <= 500
- 0 <= quiet[i] < n
- quiet 的所有值互不相同
- 0 <= richer.length <= n * (n - 1) / 2
- 0 <= ai, bi < n
- ai != bi
- richer 中的所有数对互不相同
- 对 richer 的观察在逻辑上是一致的

## 解题思路

这道题本质上是一个**图的遍历问题**。我们需要找到"所有比 x 更有钱或同样有钱的人中，最安静的人"。

**核心观察：**
1. 如果 A 比 B 有钱，那么比 A 有钱的人也一定比 B 有钱
2. 对于每个人 x，我们需要在"所有比 x 有钱的人 + x 自己"中找最安静的
3. 这是一个**有向图的可达性问题**

**算法流程：**
1. 构建图：`graph[b].append(a)` 表示 b 的钱不多于 a（反向建图）
2. 对每个人进行 DFS，找到所有比他有钱或同样有钱的人
3. 在这些人中选择最安静的
4. 使用记忆化避免重复计算

**为什么反向建图？**
- richer[i] = [a, b] 表示 a 比 b 有钱
- 我们需要从 x 出发，找所有比 x 有钱的人
- 所以建边 b -> a，方便从 x 向上查找

## Python 代码实现

### 方法一：DFS + 记忆化（推荐）⭐

```python
class Solution:
    def loudAndRich(self, richer: List[List[int]], quiet: List[int]) -> List[int]:
        n = len(quiet)
        # 构建图：graph[b] 存储所有比 b 有钱的人
        graph = [[] for _ in range(n)]
        for a, b in richer:
            graph[b].append(a)  # a 比 b 有钱，从 b 指向 a
        
        # answer[x] 表示所有不比 x 穷的人中最安静的人
        answer = [-1] * n
        
        def dfs(x: int) -> int:
            """返回所有不比 x 穷的人中最安静的人的编号"""
            if answer[x] != -1:
                return answer[x]
            
            # 初始化为自己
            answer[x] = x
            
            # 遍历所有比 x 有钱的人
            for richer_person in graph[x]:
                # 递归获取比 richer_person 有钱的人中最安静的
                candidate = dfs(richer_person)
                # 更新最安静的人
                if quiet[candidate] < quiet[answer[x]]:
                    answer[x] = candidate
            
            return answer[x]
        
        # 对每个人计算答案
        for i in range(n):
            dfs(i)
        
        return answer
```

**代码说明：**
- `graph[b]` 存储所有比 b 有钱的人
- `dfs(x)` 返回"所有不比 x 穷的人中最安静的人"
- 记忆化避免重复计算

### 方法二：拓扑排序

```python
class Solution:
    def loudAndRich(self, richer: List[List[int]], quiet: List[int]) -> List[int]:
        from collections import deque
        
        n = len(quiet)
        graph = [[] for _ in range(n)]
        in_degree = [0] * n
        
        # 构建图和入度数组
        for a, b in richer:
            graph[a].append(b)  # a 比 b 有钱，从 a 指向 b
            in_degree[b] += 1
        
        # 初始化答案数组
        answer = list(range(n))
        
        # 拓扑排序队列
        queue = deque([i for i in range(n) if in_degree[i] == 0])
        
        while queue:
            x = queue.popleft()
            
            # 更新所有比 x 穷的人
            for y in graph[x]:
                # y 可以选择 x 的最安静的人作为候选
                if quiet[answer[x]] < quiet[answer[y]]:
                    answer[y] = answer[x]
                
                in_degree[y] -= 1
                if in_degree[y] == 0:
                    queue.append(y)
        
        return answer
```

**代码说明：**
- 按照拓扑顺序处理，从最有钱的人开始
- 每个人的答案可以从更有钱的人那里继承

### 方法三：BFS 暴力搜索

```python
class Solution:
    def loudAndRich(self, richer: List[List[int]], quiet: List[int]) -> List[int]:
        from collections import deque
        
        n = len(quiet)
        # 构建图
        graph = [[] for _ in range(n)]
        for a, b in richer:
            graph[b].append(a)
        
        answer = []
        
        for x in range(n):
            # 对每个人进行 BFS
            visited = {x}
            queue = deque([x])
            min_quiet = quiet[x]
            min_person = x
            
            while queue:
                person = queue.popleft()
                
                for richer_person in graph[person]:
                    if richer_person not in visited:
                        visited.add(richer_person)
                        queue.append(richer_person)
                        
                        if quiet[richer_person] < min_quiet:
                            min_quiet = quiet[richer_person]
                            min_person = richer_person
            
            answer.append(min_person)
        
        return answer
```

## 复杂度分析

### 方法一：DFS + 记忆化
- **时间复杂度**：O(n + m)，其中 n 是人数，m 是 richer 的长度。每个节点最多访问一次。
- **空间复杂度**：O(n + m)，图的存储空间 + 递归栈空间。

### 方法二：拓扑排序
- **时间复杂度**：O(n + m)，拓扑排序的标准复杂度。
- **空间复杂度**：O(n + m)，图和队列的空间。

### 方法三：BFS
- **时间复杂度**：O(n × (n + m))，每个人都要进行一次 BFS。
- **空间复杂度**：O(n + m)。

## 关键点总结

1. **反向建图**：从"穷人"指向"富人"，方便查找所有比某人有钱的人
2. **记忆化搜索**：避免重复计算，将时间复杂度降到线性
3. **图的遍历**：DFS 和拓扑排序都可以解决
4. **状态定义**：`answer[x]` 表示所有不比 x 穷的人中最安静的人
5. **递归思想**：当前人的答案可以从更有钱的人那里获得

## 易错点

1. **建图方向错误**：容易把 `graph[a].append(b)` 和 `graph[b].append(a)` 搞混
   - 记住：我们需要从穷人找富人，所以 `graph[b].append(a)`

2. **初始化错误**：忘记把自己也算进候选
   - 每个人至少是他自己的答案

3. **没有使用记忆化**：导致超时
   - 必须使用 `answer` 数组缓存结果

4. **理解题意错误**：是"不少于"而不是"大于"
   - 要包含自己
