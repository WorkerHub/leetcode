## 题目描述

给你一个字符串 `s`，考虑其所有重复子串（`s` 的连续子串，在 `s` 中出现 2 次或更多次）。

返回任意一个最长的重复子串。如果 `s` 不含重复子串，那么答案为 `""`。

**示例 1：**
```
输入：s = "banana"
输出："ana"
解释："ana" 在 "banana" 中出现了 2 次
```

**示例 2：**
```
输入：s = "abcd"
输出：""
解释：没有重复的子串
```

**提示：**
- `2 <= s.length <= 3 * 10^4`
- `s` 由小写英文字母组成

## 解题思路

这是一道困难题，需要使用高级算法来高效解决。

### 核心思想

1. **二分查找长度**：重复子串的长度在 `[0, n-1]` 之间，可以用二分查找找到最大的满足条件的长度
2. **滚动哈希检测重复**：对于固定长度 L，使用滚动哈希（Rabin-Karp）算法快速检测是否存在长度为 L 的重复子串

### 二分查找

如果存在长度为 L 的重复子串，那么必然也存在长度为 L-1 的重复子串（取前 L-1 个字符即可）。

这个单调性使得我们可以用二分查找：
- 左边界：0（没有重复）
- 右边界：n-1（最长可能）
- 目标：找到最大的 L，使得存在长度为 L 的重复子串

### 滚动哈希（Rabin-Karp）

对于固定长度 L，如何快速检测是否存在重复子串？

**朴素方法**：
- 枚举所有长度为 L 的子串，用集合判断是否重复
- 时间复杂度：O(n * L)

**滚动哈希优化**：
- 将字符串看作 base 进制数，计算哈希值
- 滑动窗口时，O(1) 更新哈希值
- 时间复杂度：O(n)

**哈希计算**：
- `hash(s[i:i+L]) = s[i]*base^(L-1) + s[i+1]*base^(L-2) + ... + s[i+L-1]`
- 滚动更新：`hash(s[i+1:i+L+1]) = (hash(s[i:i+L]) - s[i]*base^(L-1)) * base + s[i+L]`

为避免溢出，对一个大质数取模。

## Python 代码实现

### 方法一：二分查找 + 滚动哈希（推荐）

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        # 将字符转换为数字（a=0, b=1, ...）
        nums = [ord(c) - ord('a') for c in s]
        
        # 二分查找最长重复子串的长度
        left, right = 0, n - 1
        result = ""
        
        while left <= right:
            mid = (left + right) // 2
            # 检查是否存在长度为 mid 的重复子串
            dup = self.search(nums, mid)
            if dup != -1:
                # 找到了，尝试更长的
                result = s[dup:dup + mid]
                left = mid + 1
            else:
                # 没找到，尝试更短的
                right = mid - 1
        
        return result
    
    def search(self, nums: list, L: int) -> int:
        """
        使用滚动哈希检测是否存在长度为 L 的重复子串
        返回重复子串的起始位置，不存在返回 -1
        """
        if L == 0:
            return -1
        
        # 哈希参数
        base = 26  # 字母表大小
        mod = 2**63 - 1  # 大质数，避免溢出
        
        # 计算 base^(L-1) % mod
        base_L = pow(base, L - 1, mod)
        
        # 计算第一个窗口的哈希值
        h = 0
        for i in range(L):
            h = (h * base + nums[i]) % mod
        
        # 存储已见过的哈希值及其起始位置
        seen = {h: 0}
        
        # 滑动窗口
        for start in range(1, len(nums) - L + 1):
            # 移除最左边的字符，添加新字符
            h = (h * base - nums[start - 1] * base_L + nums[start + L - 1]) % mod
            
            if h in seen:
                # 找到重复的哈希值，返回起始位置
                return start
            seen[h] = start
        
        return -1
```

### 方法二：二分查找 + 字符串集合（简化版）

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        left, right = 0, n - 1
        result = ""
        
        while left <= right:
            mid = (left + right) // 2
            dup = self.findDuplicate(s, mid)
            if dup:
                result = dup
                left = mid + 1
            else:
                right = mid - 1
        
        return result
    
    def findDuplicate(self, s: str, length: int) -> str:
        """查找长度为 length 的重复子串"""
        if length == 0:
            return ""
        
        seen = set()
        for i in range(len(s) - length + 1):
            sub = s[i:i + length]
            if sub in seen:
                return sub
            seen.add(sub)
        
        return ""
```

### 方法三：详细注释版（便于理解）

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        """
        二分查找 + 滚动哈希
        
        思路：
        1. 二分查找重复子串的长度
        2. 对于每个长度，用滚动哈希检测是否存在重复
        """
        n = len(s)
        
        # 将字符串转换为数字数组，方便计算哈希
        # 'a' -> 0, 'b' -> 1, ..., 'z' -> 25
        nums = [ord(ch) - ord('a') for ch in s]
        
        # 二分查找重复子串的最大长度
        left, right = 0, n - 1
        result_start = -1  # 结果子串的起始位置
        result_length = 0  # 结果子串的长度
        
        while left <= right:
            mid = (left + right) // 2
            
            # 检查是否存在长度为 mid 的重复子串
            start_pos = self.rabinKarp(nums, mid)
            
            if start_pos != -1:
                # 存在长度为 mid 的重复子串
                result_start = start_pos
                result_length = mid
                # 尝试更长的
                left = mid + 1
            else:
                # 不存在，尝试更短的
                right = mid - 1
        
        # 返回结果
        if result_start == -1:
            return ""
        return s[result_start:result_start + result_length]
    
    def rabinKarp(self, nums: list, L: int) -> int:
        """
        Rabin-Karp 滚动哈希算法
        检测是否存在长度为 L 的重复子串
        
        返回：重复子串的起始位置，不存在返回 -1
        """
        if L == 0:
            return -1
        
        n = len(nums)
        
        # 哈希参数
        base = 26  # 进制（字母表大小）
        mod = 2**63 - 1  # 模数（大质数，避免整数溢出）
        
        # 预计算 base^(L-1) % mod
        # 用于移除窗口最左边字符的贡献
        base_power = pow(base, L - 1, mod)
        
        # 计算第一个窗口 [0, L) 的哈希值
        current_hash = 0
        for i in range(L):
            current_hash = (current_hash * base + nums[i]) % mod
        
        # 存储已见过的哈希值
        # key: 哈希值, value: 起始位置
        hash_to_pos = {current_hash: 0}
        
        # 滑动窗口，计算每个长度为 L 的子串的哈希值
        for start in range(1, n - L + 1):
            # 滚动更新哈希值
            # 1. 移除最左边字符 nums[start-1] 的贡献
            # 2. 左移一位（乘以 base）
            # 3. 添加新字符 nums[start+L-1] 的贡献
            current_hash = (
                (current_hash - nums[start - 1] * base_power) * base 
                + nums[start + L - 1]
            ) % mod
            
            # 检查是否见过这个哈希值
            if current_hash in hash_to_pos:
                # 找到重复！返回当前位置
                return start
            
            # 记录当前哈希值
            hash_to_pos[current_hash] = start
        
        return -1
```

### 方法四：使用后缀数组（高级方法）

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        """
        使用后缀数组的方法（更复杂但更通用）
        """
        n = len(s)
        # 构建后缀数组
        suffixes = [(s[i:], i) for i in range(n)]
        suffixes.sort()
        
        max_length = 0
        result_start = -1
        
        # 比较相邻后缀的公共前缀
        for i in range(n - 1):
            lcp = self.longestCommonPrefix(suffixes[i][0], suffixes[i + 1][0])
            if lcp > max_length:
                max_length = lcp
                result_start = suffixes[i][1]
        
        if result_start == -1:
            return ""
        return s[result_start:result_start + max_length]
    
    def longestCommonPrefix(self, s1: str, s2: str) -> int:
        """计算两个字符串的最长公共前缀长度"""
        length = 0
        for i in range(min(len(s1), len(s2))):
            if s1[i] == s2[i]:
                length += 1
            else:
                break
        return length
```

## 复杂度分析

### 方法一：二分查找 + 滚动哈希

- **时间复杂度**：O(n log n)
  - 二分查找：O(log n) 次
  - 每次检查：O(n) 使用滚动哈希
  - 总时间：O(n log n)

- **空间复杂度**：O(n)
  - 哈希表存储 O(n) 个哈希值
  - 数字数组：O(n)

### 方法二：二分查找 + 字符串集合

- **时间复杂度**：O(n^2 log n)
  - 二分查找：O(log n) 次
  - 每次检查：O(n * L)，最坏 L = n/2
  - 总时间：O(n^2 log n)

- **空间复杂度**：O(n^2)
  - 集合存储 O(n) 个长度为 O(n) 的字符串

### 方法四：后缀数组

- **时间复杂度**：O(n^2 log n)
  - 排序后缀：O(n^2 log n)
  
- **空间复杂度**：O(n^2)
  - 存储所有后缀

## 关键点总结

1. **二分查找单调性**：如果存在长度 L 的重复子串，必存在长度 L-1 的重复子串
2. **滚动哈希**：O(1) 时间更新窗口哈希值，避免重复计算
3. **哈希冲突**：使用大质数取模，降低冲突概率（本题可接受小概率冲突）
4. **字符编码**：将字符转换为数字，方便哈希计算
5. **模运算性质**：`(a - b) % m` 可能为负，需要加 m 再取模

## 易错点

1. **哈希溢出**：
   - Python 整数无限大，但取模很重要
   - 使用 `2^63 - 1` 这样的大质数

2. **滚动哈希更新**：
   - 移除左边：`-= nums[left] * base^(L-1)`
   - 左移：`*= base`
   - 添加右边：`+= nums[right]`
   - 最后取模

3. **边界条件**：
   - `L = 0` 时的处理
   - 窗口范围：`start` 从 1 到 `n - L`

4. **索引转换**：
   - 字符串索引从 0 开始
   - 窗口 `[start, start+L)` 对应 `s[start:start+L]`

5. **结果返回**：
   - 返回子串本身，不是长度或位置
   - 可能没有重复子串，返回空字符串
