## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长公共子序列的长度。如果不存在公共子序列，返回 `0`。

一个字符串的子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的公共子序列是这两个字符串所共同拥有的子序列。

**示例 1：**
```
输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace"，它的长度为 3。
```

**示例 2：**
```
输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc"，它的长度为 3。
```

**示例 3：**
```
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0。
```

**提示：**
- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字符组成

## 解题思路

这是经典的LCS（Longest Common Subsequence）问题，使用动态规划解决。

**DP定义**：
- `dp[i][j]` = text1[0..i-1] 和 text2[0..j-1] 的最长公共子序列长度

**状态转移**：
1. 如果 `text1[i-1] == text2[j-1]`：
   - `dp[i][j] = dp[i-1][j-1] + 1`
2. 否则：
   - `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

**初始化**：
- `dp[0][j] = 0` (text1为空)
- `dp[i][0] = 0` (text2为空)

## Python 代码实现

### 方法一：二维DP（推荐）⭐

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        """
        经典二维DP
        时间复杂度：O(m*n)
        空间复杂度：O(m*n)
        """
        m, n = len(text1), len(text2)
        
        # dp[i][j] = LCS长度 for text1[0:i] and text2[0:j]
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    # 字符相同，长度+1
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    # 字符不同，取最大值
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        return dp[m][n]
```

### 方法二：空间优化（一维DP）

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        """
        空间优化：只用一维数组
        时间复杂度：O(m*n)
        空间复杂度：O(min(m,n))
        """
        # 确保text2是较短的
        if len(text1) < len(text2):
            text1, text2 = text2, text1
        
        m, n = len(text1), len(text2)
        prev = [0] * (n + 1)
        
        for i in range(1, m + 1):
            curr = [0] * (n + 1)
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    curr[j] = prev[j-1] + 1
                else:
                    curr[j] = max(prev[j], curr[j-1])
            prev = curr
        
        return prev[n]
```

### 方法三：记忆化递归

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        """
        记忆化递归
        时间复杂度：O(m*n)
        空间复杂度：O(m*n)
        """
        from functools import lru_cache
        
        @lru_cache(maxsize=None)
        def dp(i: int, j: int) -> int:
            """
            返回text1[i:]和text2[j:]的LCS长度
            """
            # 边界条件
            if i == len(text1) or j == len(text2):
                return 0
            
            # 字符相同
            if text1[i] == text2[j]:
                return 1 + dp(i + 1, j + 1)
            
            # 字符不同，选择较大的分支
            return max(dp(i + 1, j), dp(i, j + 1))
        
        return dp(0, 0)
```

### 方法四：详细注释版

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        """
        详细版动态规划
        
        dp[i][j]的含义：
        - text1的前i个字符（text1[0:i]）
        - text2的前j个字符（text2[0:j]）
        - 它们的最长公共子序列长度
        
        状态转移方程：
        - text1[i-1] == text2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
        - text1[i-1] != text2[j-1]: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        """
        m, n = len(text1), len(text2)
        
        # 创建DP表，多一行一列用于边界
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 填充DP表
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 当前比较的字符
                char1 = text1[i - 1]
                char2 = text2[j - 1]
                
                if char1 == char2:
                    # 字符匹配，在之前的基础上+1
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    # 字符不匹配，取删除其中一个的较大值
                    # dp[i-1][j]: 不考虑text1的当前字符
                    # dp[i][j-1]: 不考虑text2的当前字符
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        return dp[m][n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（2D DP） | O(m×n) | O(m×n) |
| 方法二（1D DP） | O(m×n) | O(min(m,n)) |
| 方法三（记忆化） | O(m×n) | O(m×n) |

其中 m 和 n 分别是两个字符串的长度

## 图解示例

以 `text1 = "abcde"`, `text2 = "ace"` 为例：

```
     ""  a  c  e
""    0  0  0  0
a     0  1  1  1
b     0  1  1  1
c     0  1  2  2
d     0  1  2  2
e     0  1  2  3

DP过程：
- dp[1][1]: 'a'=='a' → dp[0][0]+1 = 1
- dp[2][1]: 'b'!='a' → max(dp[1][1], dp[2][0]) = 1
- dp[3][2]: 'c'=='c' → dp[2][1]+1 = 2
- dp[5][3]: 'e'=='e' → dp[4][2]+1 = 3

最长公共子序列: "ace", 长度3
```

## 关键点总结

1. **DP定义**：`dp[i][j]` 表示前i和前j个字符的LCS长度
2. **状态转移**：字符相同则+1，不同则取max
3. **边界初始化**：第0行和第0列都是0
4. **索引对应**：`dp[i][j]` 对应 `text1[i-1]` 和 `text2[j-1]`
5. **空间优化**：可以用滚动数组优化到O(n)空间

## 易错点

1. **索引混淆**：dp数组比字符串多一位，注意索引对应
2. **初始化**：边界要初始化为0
3. **状态转移**：不匹配时是取max，不是+1
4. **返回值**：返回`dp[m][n]`，不是`dp[m-1][n-1]`
5. **子序列vs子串**：子序列不要求连续
