## 题目描述

水果散落在一条数轴上，给定二维整数数组 `fruits`，其中 `fruits[i] = [position_i, amount_i]` 表示位置 `position_i` 处有 `amount_i` 个水果。

你从位置 `startPos` 出发，最多可以移动 `k` 步。每到达一个位置，可以采摘该位置所有水果。

返回你最多能采摘到的水果总数。

**示例 1：**
```
输入：fruits = [[2,8],[6,3],[8,6]], startPos = 5, k = 4
输出：9
解释：向右走到位置 6，再向右走到位置 8，采摘 3+6=9 个水果。
```

**示例 2：**
```
输入：fruits = [[0,9],[4,1],[5,7],[6,2],[7,4],[10,9]], startPos = 5, k = 4
输出：14
解释：先向左走到位置 4，再向右走到位置 8，采摘 1+7+2+4=14 个水果。
```

**提示：**
- `1 <= fruits.length <= 10^5`
- `fruits[i].length == 2`
- `0 <= startPos <= 10^5`
- `position_i` 互不相同，且按升序排列
- `1 <= amount_i <= 10^4`
- `0 <= k <= 10^5`

## 解题思路

**滑动窗口 + 前缀和**

最多走 k 步，可能的路径只有三种：
1. 只向右走（采摘 startPos 到 startPos+k 范围内的水果）
2. 只向左走（采摘 startPos-k 到 startPos 范围内的水果）
3. 先向左走 j 步，再向右走（覆盖 [startPos-j, startPos + (k-2j)] 范围）
4. 先向右走 j 步，再向左走（覆盖 [startPos - (k-2j), startPos+j] 范围）

实际上，所有可行区间 `[l, r]` 满足：
- `l <= startPos <= r`，或 `r < startPos`，或 `l > startPos`
- 区间长度代价：`min(|startPos - l|, |startPos - r|) * 2 + max(|startPos - l|, |startPos - r|) <= k`

用滑动窗口枚举右端点 r，维护最大可行窗口的左端点 l。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxTotalFruits(self, fruits: List[List[int]], startPos: int, k: int) -> int:
        n = len(fruits)
        # 前缀和，用于快速计算区间水果数
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + fruits[i][1]

        def get_range_sum(l_idx: int, r_idx: int) -> int:
            # 返回下标 [l_idx, r_idx] 范围内的水果总数
            if l_idx > r_idx:
                return 0
            return prefix[r_idx + 1] - prefix[l_idx]

        def can_reach(l_idx: int, r_idx: int) -> bool:
            # 判断是否能在 k 步内采摘 [fruits[l_idx][0], fruits[r_idx][0]] 范围
            left_pos = fruits[l_idx][0]
            right_pos = fruits[r_idx][0]
            if left_pos > startPos:
                # 都在右边，只需向右走
                return right_pos - startPos <= k
            if right_pos < startPos:
                # 都在左边，只需向左走
                return startPos - left_pos <= k
            # 横跨 startPos，先左后右或先右后左
            go_left = startPos - left_pos
            go_right = right_pos - startPos
            return min(go_left, go_right) * 2 + max(go_left, go_right) <= k

        ans = 0
        l = 0
        for r in range(n):
            # 滑动窗口：收缩左边界直到可达
            while not can_reach(l, r):
                l += 1
            ans = max(ans, get_range_sum(l, r))
        return ans
```

### 方法二：二分查找

```python
from typing import List
import bisect

class Solution:
    def maxTotalFruits(self, fruits: List[List[int]], startPos: int, k: int) -> int:
        positions = [f[0] for f in fruits]
        n = len(positions)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + fruits[i][1]

        def range_sum(lo: int, hi: int) -> int:
            # 位置范围 [lo, hi] 内的水果总数（二分找下标）
            l = bisect.bisect_left(positions, lo)
            r = bisect.bisect_right(positions, hi) - 1
            if l > r:
                return 0
            return prefix[r + 1] - prefix[l]

        ans = 0
        # 枚举向左走的步数 j（0 <= j <= k）
        for j in range(k + 1):
            left = startPos - j
            right = startPos + max(0, k - 2 * j)
            ans = max(ans, range_sum(left, right))
            # 枚举向右走的步数 j（先右后左）
            left2 = startPos - max(0, k - 2 * j)
            right2 = startPos + j
            ans = max(ans, range_sum(left2, right2))
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(n) |
| 二分查找 | O(k log n) | O(n) |

## 关键点总结

1. 任意最优路径一定是先走一个方向，再折回走另一方向（不会来回多次）。
2. 能到达的区间 `[l, r]` 的判断：`min(left, right) * 2 + max(left, right) <= k`。
3. 滑动窗口左边界随右边界单调不降，利用该单调性保证 O(n) 时间。

## 易错点

- 路径判断：必须考虑区间和 startPos 的相对位置三种情况。
- 二分法枚举时两个方向都要枚举（先左后右 + 先右后左）。
