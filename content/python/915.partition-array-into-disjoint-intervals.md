## 题目描述

给定一个数组 `nums`，将其划分为两个连续子数组 `left` 和 `right`，使得：

- `left` 中的每个元素都小于或等于 `right` 中的每个元素。
- `left` 和 `right` 都是非空的。
- `left` 的长度要尽可能小。

在完成这样的分组后返回 `left` 的 **长度**。

**示例 1：**
```
输入：nums = [5,0,3,8,6]
输出：3
解释：left = [5,0,3]，right = [8,6]
```

**示例 2：**
```
输入：nums = [1,1,1,0,6,12]
输出：4
解释：left = [1,1,1,0]，right = [6,12]
```

**提示：**
- `2 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`
- 可以保证至少有一种方法能够按题目所述来分割 `nums`

## 解题思路

这道题要求找到一个分割点，使得左边的最大值小于等于右边的最小值。

**核心思想：**
- 对于分割点 `i`，需要满足：`max(nums[0...i]) <= min(nums[i+1...n-1])`
- 我们需要找到最小的 `i` 满足上述条件

**方法一：预处理前缀最大值和后缀最小值**
1. 计算前缀最大值数组：`prefix_max[i]` 表示 `nums[0...i]` 的最大值
2. 计算后缀最小值数组：`suffix_min[i]` 表示 `nums[i...n-1]` 的最小值
3. 从左到右遍历，找到第一个满足 `prefix_max[i] <= suffix_min[i+1]` 的位置

**方法二：一次遍历优化**
- 维护左边部分的最大值
- 动态更新分割点

## Python 代码实现

### 方法一：预处理（推荐 ⭐）

```python
from typing import List

class Solution:
    def partitionDisjoint(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 计算前缀最大值
        prefix_max = [0] * n
        prefix_max[0] = nums[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i])
        
        # 计算后缀最小值
        suffix_min = [0] * n
        suffix_min[n - 1] = nums[n - 1]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i])
        
        # 找到第一个满足条件的分割点
        for i in range(n - 1):
            if prefix_max[i] <= suffix_min[i + 1]:
                return i + 1
        
        return n - 1  # 理论上不会到这里
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def partitionDisjoint(self, nums: List[int]) -> int:
        n = len(nums)
        
        # left_max: 左边部分的最大值
        # max_so_far: 到目前为止的最大值
        # partition: 分割点
        left_max = nums[0]
        max_so_far = nums[0]
        partition = 0
        
        for i in range(1, n):
            max_so_far = max(max_so_far, nums[i])
            
            # 如果当前元素小于左边的最大值，需要扩展左边部分
            if nums[i] < left_max:
                partition = i
                left_max = max_so_far
        
        return partition + 1
```

### 方法三：简化版

```python
from typing import List

class Solution:
    def partitionDisjoint(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 后缀最小值数组
        min_right = [0] * n
        min_right[n - 1] = nums[n - 1]
        for i in range(n - 2, -1, -1):
            min_right[i] = min(min_right[i + 1], nums[i])
        
        # 遍历找分割点
        max_left = 0
        for i in range(n - 1):
            max_left = max(max_left, nums[i])
            if max_left <= min_right[i + 1]:
                return i + 1
        
        return n - 1
```

## 复杂度分析

**方法一：预处理**
- 时间复杂度：O(n)，需要三次遍历
- 空间复杂度：O(n)，前缀和后缀数组

**方法二：一次遍历**
- 时间复杂度：O(n)，只需一次遍历
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. **前缀后缀**：使用前缀最大值和后缀最小值辅助判断
2. **分割条件**：左边最大值 <= 右边最小值
3. **一次遍历优化**：动态维护分割点和左边最大值
4. **贪心思想**：找到第一个满足条件的分割点（最小长度）
5. **边界处理**：至少要留一个元素在右边

## 易错点

1. **分割点定义**：返回的是左边部分的长度，不是索引
2. **边界条件**：右边至少要有一个元素
3. **等于情况**：条件是 `<=` 不是 `<`
4. **一次遍历逻辑**：要正确理解何时更新分割点
