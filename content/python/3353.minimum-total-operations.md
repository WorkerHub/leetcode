## 题目描述

给你一个整数数组 `nums`，初始数组为空。

每次操作可以将 `nums` 中的任意一个元素追加到目标数组末尾。

但目标数组必须是非递减的（每次追加时新元素 >= 最后一个元素）。

如果 `nums[i] < nums[i-1]`，需要额外一次操作来"重置"（即将当前位置作为新的起点）。

返回将 `nums` 中所有元素按顺序排列所需要的最少操作次数。

**重新理解：** 实际上，题目可能问的是将数组分成最少的非递减子数组的个数。

每次分段需要一次"新开始"操作，所以答案是下降次数 + 1（连续下降的位置数 + 1 段）。

**示例：**
```
输入：nums = [1, 2, 1, 4, 3]
输出：3
解释：[1, 2] | [1, 4] | [3] => 3 段
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 100`

## 解题思路

统计数组中相邻元素的下降次数（`nums[i] < nums[i-1]`），答案等于下降次数 + 1（段数）。

## Python 代码实现

### 方法一：统计下降次数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # 统计相邻元素的下降次数
        drops = sum(1 for i in range(1, len(nums)) if nums[i] < nums[i-1])
        return drops + 1  # 段数 = 下降次数 + 1
```

### 方法二：直接统计段数

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        segments = 1
        for i in range(1, len(nums)):
            if nums[i] < nums[i-1]:
                segments += 1
        return segments
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 将数组分成若干非递减段，段数即操作次数。
2. 每次 `nums[i] < nums[i-1]` 就开始新段。
3. 初始有 1 段，每次下降 +1。

## 易错点

1. 非递减允许相等，只有严格下降才开始新段。
2. 初始段数为 1（至少有一段）。
