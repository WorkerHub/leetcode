## 题目描述

Alice 和 Bob 用几堆石子在做游戏。一共有偶数堆石子，排成一行；每堆都有正整数颗石子，数目为 piles[i] 。

游戏以谁手中的石子最多来决出胜负。石子的总数是奇数，所以没有平局。

Alice 和 Bob 轮流进行，Alice 先开始 。 每回合，玩家从行的 开始 或 结束 处取走整堆石头。 这种情况一直持续到没有更多的石子堆为止，此时手中 石子最多 的玩家获胜。

假设 Alice 和 Bob 都发挥出最佳水平，当 Alice 赢得比赛时返回 true ，当 Bob 赢得比赛时返回 false 。

**提示：**
- 2 <= piles.length <= 500
- piles.length 是 偶数
- 1 <= piles[i] <= 500
- sum(piles[i]) 是 奇数

## 解题思路

**数学结论：**
- Alice 先手，堆数为偶数，Alice 必胜！
- 原因：Alice 可以选择拿所有奇数位置或所有偶数位置的堆
- 由于总和是奇数，奇数位置和偶数位置的总和必然一个更大
- Alice 可以策略性地选择更大的那一组

**DP 解法（练习用）：**
- `dp[i][j]` 表示剩下 `[i, j]` 堆石子时，当前玩家与另一个玩家的石子数量之差的最大值

### 方法二：动态规划（学习用）

```python
class Solution:
    def stoneGame(self, piles: List[int]) -> bool:
        n = len(piles)
        # dp[i][j] 表示从 [i, j] 中先手能获得的最大石子差
        dp = [[0] * n for _ in range(n)]
        
        # 初始化：只有一堆时，先手拿走
        for i in range(n):
            dp[i][i] = piles[i]
        
        # 枚举长度
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                # 拿左边或右边，选最优
                dp[i][j] = max(
                    piles[i] - dp[i+1][j],  # 拿左边
                    piles[j] - dp[i][j-1]   # 拿右边
                )
        
        return dp[0][n-1] > 0
```

### 方法三：记忆化搜索

```python
class Solution:
    def stoneGame(self, piles: List[int]) -> bool:
        from functools import lru_cache
        
        @lru_cache(None)
        def dp(i, j):
            if i > j:
                return 0
            if i == j:
                return piles[i]
            return max(piles[i] - dp(i+1, j), piles[j] - dp(i, j-1))
        
        return dp(0, len(piles) - 1) > 0
```

## 关键点总结

1. **数学技巧**：偶数堆+奇数和 → 先手必胜
2. **博弈DP**：`dp[i][j]` 表示石子差值
3. **状态转移**：选择左边或右边的最优策略
4. **负号含义**：对手的最优就是我的最差

## 易错点

1. **理解题意**：Alice 先手，堆数偶数，总和奇数
2. **DP 含义**：是差值，不是绝对值
3. **负号**：`piles[i] - dp[i+1][j]` 表示我拿了 i 后，对手的最优
