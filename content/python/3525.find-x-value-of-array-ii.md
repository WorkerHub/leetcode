## 题目描述

给定一个整数数组 `nums`、正整数 `k` 和若干查询。每个查询给出区间 `[l, r]` 和目标值 `x`，问区间内有多少个子数组，其元素乘积对 `k` 取模等于 `x`。

**示例：**

```
输入：nums = [1,2,3,4,5], k = 3, queries = [[0,3,2],[1,4,0]]
输出：[2, 3]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= k <= 100`
- `1 <= queries.length <= 10^5`

## 解题思路

线段树维护区间内子数组乘积余数的分布。

核心思想：
1. 线段树每个节点维护一个数组 `cnt[0..k-1]`，表示该区间内所有子数组乘积 mod k 等于各值的数量
2. 合并两个区间时，左区间所有子数组、右区间所有子数组，以及跨越左右的子数组
3. 对每个查询，查询线段树对应区间的 `cnt[x]`

合并操作：
- 左区间有子数组乘积余数分布 `L[r]`，右区间有前缀乘积余数分布 `R[r]`
- 跨越边界的子数组 = 左区间后缀 * 右区间前缀
- 需要维护区间的前缀乘积余数分布和后缀乘积余数分布

## Python 代码实现

### 方法一：线段树（推荐）

```python
from typing import List

class Solution:
    def findXValue(self, nums: List[int], k: int, queries: List[List[int]]) -> List[int]:
        n = len(nums)

        # 线段树节点：存储区间内子数组乘积余数的分布
        # node = (cnt, prefix_cnt, suffix_cnt, all_prod)
        # cnt[r] = 子数组乘积 mod k == r 的数量
        # prefix_cnt[r] = 前缀乘积 mod k == r 的数量
        # suffix_cnt[r] = 后缀乘积 mod k == r 的数量
        # all_prod = 整个区间乘积 mod k

        def make_leaf(x):
            # 单个元素 x mod k
            r = x % k
            cnt = [0] * k
            cnt[r] = 1
            pre = [0] * k
            pre[r] = 1
            suf = [0] * k
            suf[r] = 1
            return (cnt, pre, suf, r)

        def merge(left, right):
            lcnt, lpre, lsuf, lall = left
            rcnt, rpre, rsuf, rall = right
            # 合并 cnt
            cnt = [lcnt[i] + rcnt[i] for i in range(k)]
            # 跨越边界的子数组：左后缀 * 右前缀
            for lr in range(k):
                if lsuf[lr] == 0:
                    continue
                for rr in range(k):
                    if rpre[rr] == 0:
                        continue
                    combined = (lr * rr) % k
                    cnt[combined] += lsuf[lr] * rpre[rr]
            # 前缀：left的前缀 + 整个left * right的前缀
            pre = list(lpre)
            for rr in range(k):
                if rpre[rr] == 0:
                    continue
                combined = (lall * rr) % k
                pre[combined] += rpre[rr]
            # 后缀：right的后缀 + 整个right * left的后缀
            suf = list(rsuf)
            for lr in range(k):
                if lsuf[lr] == 0:
                    continue
                combined = (rall * lr) % k
                suf[combined] += lsuf[lr]
            # 整体乘积
            all_prod = (lall * rall) % k
            return (cnt, pre, suf, all_prod)

        # 构建线段树
        tree = [None] * (4 * n)

        def build(node, start, end):
            if start == end:
                tree[node] = make_leaf(nums[start])
                return
            mid = (start + end) // 2
            build(2*node, start, mid)
            build(2*node+1, mid+1, end)
            tree[node] = merge(tree[2*node], tree[2*node+1])

        def query(node, start, end, l, r):
            if l <= start and end <= r:
                return tree[node]
            mid = (start + end) // 2
            if r <= mid:
                return query(2*node, start, mid, l, r)
            if l > mid:
                return query(2*node+1, mid+1, end, l, r)
            left = query(2*node, start, mid, l, r)
            right = query(2*node+1, mid+1, end, l, r)
            return merge(left, right)

        build(1, 0, n-1)

        result = []
        for l, r, x in queries:
            res = query(1, 0, n-1, l, r)
            result.append(res[0][x])
        return result
```

### 方法二：离线处理 + 前缀和

```python
from typing import List
from collections import defaultdict

class Solution:
    def findXValue(self, nums: List[int], k: int, queries: List[List[int]]) -> List[int]:
        n = len(nums)
        # 对每个查询暴力计算（适合数据规模较小的情况）
        result = []
        for l, r, x in queries:
            count = 0
            for i in range(l, r+1):
                p = 1
                for j in range(i, r+1):
                    p = (p * nums[j]) % k
                    if p == x:
                        count += 1
            result.append(count)
        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) * k^2 * log n)（方法一线段树），O(q * n^2)（方法二暴力）
- 空间复杂度：O(n * k)，线段树节点存储 k 大小的数组

## 关键点总结

1. 线段树节点维护子数组乘积余数的统计信息
2. 合并操作需要处理跨越边界的子数组
3. 前缀和后缀乘积余数分布是合并的关键辅助信息
4. 每个节点需要存储 cnt、prefix、suffix、all_prod 四个信息

## 易错点

1. 合并时，跨越边界的子数组 = 左区间某后缀 * 右区间某前缀
2. 前缀余数更新：原有前缀 + (整体左乘积 * 右前缀)
3. 乘积对 k 取模时不能简化为加法
