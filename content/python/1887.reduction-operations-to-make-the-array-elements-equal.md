## 题目描述

给你一个整数数组 `nums`，每步操作选择 `nums` 中的**最大值**，将其替换为数组中**第二大**的值（若没有第二大则不需替换）。

返回使数组中所有元素相等所需的操作次数。

**示例 1：**
```
输入：nums = [5,1,3]
输出：3
解释：5->3->1->1（操作3次）
```

**示例 2：**
```
输入：nums = [1,1,1]
输出：0
```

## 解题思路

**排序分析**：

排序后，相同的元素不需要操作。

对于不同的值，设排序后不同值的个数为 `k`，第 i 大的值（从小到大，i=1 最小）变成最小值需要 `i-1` 步（每次降一级）。

若某个值出现 `cnt` 次，它们一起需要操作，每次操作所有相同的最大值都降一级，共 `层数 * cnt` 次操作。

更简单地：按排序后的不同值（去重），每个非最小值的值，转化为最小值需要多少步。排序后从大到小数层数，每层的元素数乘以层数即为该层的操作次数。

## 代码实现

### 方法一：排序统计层数（推荐）

```python
from typing import List

class Solution:
    def reductionOperations(self, nums: List[int]) -> int:
        nums.sort()
        result = 0
        levels = 0  # 当前需要的层数（降几步才到最小值）

        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                levels += 1  # 遇到新值，层数加一
            result += levels  # 当前元素需要 levels 步操作

        return result
```

### 方法二：统计不同值的个数（原理相同）

```python
from typing import List
from collections import Counter

class Solution:
    def reductionOperations(self, nums: List[int]) -> int:
        sorted_unique = sorted(set(nums))
        cnt = Counter(nums)
        result = 0
        for i in range(1, len(sorted_unique)):
            # 值 sorted_unique[i] 到达最小值需要 i 步，该值共 cnt[sorted_unique[i]] 个
            result += i * cnt[sorted_unique[i]]
        return result
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后，每遇到一个比前一个大的值，层数加一
2. 每个元素到达最小值需要「当前层数」步操作
3. 相同的元素不增加层数

## 易错点

- 最小值（排序后第一个不同值）不需要操作，层数从 0 开始
- 每遇到一个不同的新值，层数才加一
