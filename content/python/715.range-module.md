## 题目描述

Range模块是跟踪数字范围的模块。设计一个数据结构来跟踪表示为 **半开区间** 的范围并查询它们。

**半开区间** `[left, right)` 表示所有 `left <= x < right` 的实数 `x`。

实现 `RangeModule` 类:

- `RangeModule()` 初始化数据结构的对象。
- `void addRange(int left, int right)` 添加 **半开区间** `[left, right)`，跟踪该区间中的每个实数。添加与当前跟踪的数字部分重叠的区间时，应当添加在区间 `[left, right)` 中尚未跟踪的任何数字。
- `boolean queryRange(int left, int right)` 只有在当前正在跟踪区间 `[left, right)` 中的每一个实数时，才返回 `true` ，否则返回 `false` 。
- `void removeRange(int left, int right)` 停止跟踪 **半开区间** `[left, right)` 中当前正在跟踪的每个实数。

**示例：**

```
输入
["RangeModule", "addRange", "removeRange", "queryRange", "queryRange", "queryRange"]
[[], [10, 20], [14, 16], [10, 14], [13, 15], [16, 17]]
输出
[null, null, null, true, false, true]

解释
RangeModule rangeModule = new RangeModule();
rangeModule.addRange(10, 20);
rangeModule.removeRange(14, 16);
rangeModule.queryRange(10, 14);  // 返回 true
rangeModule.queryRange(13, 15);  // 返回 false
rangeModule.queryRange(16, 17);  // 返回 true
```

**提示：**
- `1 <= left < right <= 10^9`
- 在单个测试用例中，对 `addRange`、`queryRange` 和 `removeRange` 的调用总数不超过 `10^4` 次

## 解题思路

这道题需要高效地维护和查询区间集合。

**核心思想：**
- 使用有序的区间列表维护所有被跟踪的区间
- 区间需要合并，避免重叠
- 使用二分查找优化查询

**关键操作：**
1. **添加区间**：找到所有重叠的区间，合并成一个大区间
2. **查询区间**：检查该区间是否被某个跟踪区间完全覆盖
3. **删除区间**：将重叠的区间拆分，移除指定部分

## Python 代码实现

### 方法一：有序列表 + 二分查找（推荐）⭐

```python
import bisect

class RangeModule:
    def __init__(self):
        """
        使用列表存储不重叠的区间，按起点排序
        intervals: [(left1, right1), (left2, right2), ...]
        """
        self.intervals = []
    
    def addRange(self, left: int, right: int) -> None:
        """添加区间 [left, right)"""
        new_intervals = []
        i = 0
        n = len(self.intervals)
        
        # 添加所有在 [left, right) 之前的区间
        while i < n and self.intervals[i][1] < left:
            new_intervals.append(self.intervals[i])
            i += 1
        
        # 合并所有与 [left, right) 重叠的区间
        while i < n and self.intervals[i][0] <= right:
            left = min(left, self.intervals[i][0])
            right = max(right, self.intervals[i][1])
            i += 1
        
        new_intervals.append((left, right))
        
        # 添加所有在 [left, right) 之后的区间
        while i < n:
            new_intervals.append(self.intervals[i])
            i += 1
        
        self.intervals = new_intervals
    
    def queryRange(self, left: int, right: int) -> bool:
        """查询区间 [left, right) 是否被完全覆盖"""
        # 使用二分查找找到可能覆盖该区间的位置
        idx = bisect.bisect_right(self.intervals, (left, right))
        
        # 检查前一个区间是否覆盖 [left, right)
        if idx > 0:
            interval = self.intervals[idx - 1]
            return interval[0] <= left and right <= interval[1]
        
        return False
    
    def removeRange(self, left: int, right: int) -> None:
        """移除区间 [left, right)"""
        new_intervals = []
        
        for interval_left, interval_right in self.intervals:
            # 无重叠，保留
            if interval_right <= left or interval_left >= right:
                new_intervals.append((interval_left, interval_right))
            else:
                # 有重叠，可能拆分成两个区间
                # 左半部分
                if interval_left < left:
                    new_intervals.append((interval_left, left))
                # 右半部分
                if right < interval_right:
                    new_intervals.append((right, interval_right))
        
        self.intervals = new_intervals
```

### 方法二：简化版

```python
class RangeModule:
    def __init__(self):
        self.ranges = []
    
    def addRange(self, left: int, right: int) -> None:
        result = []
        inserted = False
        
        for l, r in self.ranges:
            if r < left or (inserted and l > right):
                # 不重叠，直接添加
                result.append((l, r))
            elif not inserted:
                # 可能重叠，合并
                left = min(left, l)
                right = max(right, r)
                if l > right:
                    result.append((left, right))
                    result.append((l, r))
                    inserted = True
        
        if not inserted:
            result.append((left, right))
        
        self.ranges = result
    
    def queryRange(self, left: int, right: int) -> bool:
        for l, r in self.ranges:
            if l <= left and right <= r:
                return True
        return False
    
    def removeRange(self, left: int, right: int) -> None:
        result = []
        
        for l, r in self.ranges:
            if r <= left or l >= right:
                result.append((l, r))
            else:
                if l < left:
                    result.append((l, left))
                if right < r:
                    result.append((right, r))
        
        self.ranges = result
```

## 复杂度分析

### 方法一：
- **addRange:** O(n)，最坏情况需要遍历所有区间
- **queryRange:** O(log n)，使用二分查找
- **removeRange:** O(n)，需要遍历所有区间
- **空间复杂度：** O(n)，n 为区间数量

## 关键点总结

1. **区间合并**：重叠或相邻的区间需要合并
2. **有序维护**：保持区间按起点排序，方便查询
3. **二分优化**：使用二分查找加速查询操作
4. **区间拆分**：删除时可能将一个区间拆成两个
5. **半开区间**：注意 `[left, right)` 不包含 right

## 易错点

1. **区间边界处理**：半开区间的边界判断容易出错
2. **合并条件**：`intervals[i][0] <= right` 才能合并
3. **查询优化**：使用二分查找而不是遍历
4. **删除后的区间**：可能产生 0、1 或 2 个新区间
5. **空列表情况**：初始状态和删除完后的处理
