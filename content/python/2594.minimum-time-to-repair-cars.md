## 题目描述

给你一个整数数组 `ranks`，表示一些机械师的技能等级。`ranks[i]` 是第 `i` 位机械师的技能等级。技能等级为 `r` 的机械师修理 `n` 辆车需要 `r * n^2` 分钟。

同时给你一个整数 `cars`，表示总共需要修理的汽车数目。

每位机械师可以同时工作，返回修理所有汽车所需的 **最少时间**。

**示例 1：**

```
输入：ranks = [4,2,3,1], cars = 10
输出：16
解释：时间 16 分钟时：
- 第 1 位（rank=4）：修 2 辆（4*4=16）
- 第 2 位（rank=2）：修 2√2 ≈ 2.8 → 2 辆（2*4=8≤16）实际 2√(16/2) ≈ 2.8 → 2辆
```

**提示：**

- `1 <= ranks.length <= 10^5`
- `1 <= ranks[i] <= 100`
- `1 <= cars <= 10^6`

## 解题思路

**二分答案**：

二分时间 `t`，验证在时间 `t` 内能否修完所有 `cars` 辆车。

技能等级为 `r` 的机械师在时间 `t` 内最多修 `floor(sqrt(t / r))` 辆车。

验证函数：`sum(floor(sqrt(t / r)) for r in ranks) >= cars`。

二分范围：`[1, min(ranks) * cars^2]`。

## Python 代码实现

### 方法一：二分答案（推荐）

```python
from typing import List
import math

class Solution:
    def repairCars(self, ranks: List[int], cars: int) -> int:
        def can_finish(t: int) -> bool:
            # 时间 t 内，所有机械师合计能修的汽车数
            total = 0
            for r in ranks:
                total += int(math.isqrt(t // r))
                if total >= cars:  # 提前终止
                    return True
            return total >= cars

        # 二分范围：[1, min_rank * cars^2]
        lo, hi = 1, min(ranks) * cars * cars
        while lo < hi:
            mid = (lo + hi) // 2
            if can_finish(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：优化二分（按 rank 去重计数）

```python
from typing import List
import math
from collections import Counter

class Solution:
    def repairCars(self, ranks: List[int], cars: int) -> int:
        rank_count = Counter(ranks)

        def can_finish(t: int) -> bool:
            total = 0
            for r, cnt in rank_count.items():
                total += int(math.isqrt(t // r)) * cnt
                if total >= cars:
                    return True
            return total >= cars

        lo, hi = 1, min(ranks) * cars * cars
        while lo < hi:
            mid = (lo + hi) // 2
            if can_finish(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log(min_rank * cars^2))，二分 × 每次验证 O(n)
- 空间复杂度：O(1) 或 O(distinct_ranks)

## 关键点总结

1. 二分时间，验证可行性
2. rank=r 的机械师在时间 t 内能修 `floor(sqrt(t/r))` 辆
3. 二分上界：最慢的机械师（rank 最小的）单独修完所有车的时间

## 易错点

1. `math.isqrt` 比 `int(math.sqrt(...))` 更精确（避免浮点误差）
2. 上界要足够大：`min(ranks) * cars * cars`（最慢工人单独完成的时间）
3. 提前终止优化：`total >= cars` 时直接返回 `True`
