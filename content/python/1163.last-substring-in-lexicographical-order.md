## 题目描述

给定一个字符串 `s`，返回其字典序最大的子字符串。

示例 1：

```
输入：s = "abab"
输出："bab"
解释：子字符串列表为 ["a", "ab", "aba", "abab", "b", "ba", "bab"]。其中字典序最大的子字符串是 "bab"。
```

示例 2：

```
输入：s = "leetcode"
输出："tcode"
```

提示：

- `1 <= s.length <= 4 * 10^5`
- `s` 仅包含小写英文字母

## 解题思路

这道题的直观思路是生成所有子字符串并比较，但这样的时间复杂度是 O(n^3)，对于 4 * 10^5 的长度会超时。

**核心观察：**

1. 字典序最大的子字符串一定是从某个位置开始到字符串末尾的后缀
2. 因为如果截断后缀的任何部分，字典序都会变小或不变
3. 问题转化为：找到字典序最大的后缀

**优化策略：**

使用双指针比较不同位置的后缀，淘汰字典序较小的：
- 维护一个候选位置 i（当前找到的最大后缀起始位置）
- 用指针 j 遍历字符串，与 i 比较
- 用指针 k 表示 i 和 j 后缀的相对偏移量

**算法步骤：**

1. 从位置 0 开始，维护候选最大后缀起始位置 i
2. 用 j 从 i+1 开始遍历
3. 比较 s[i+k] 和 s[j+k]：
   - 如果 s[i+k] > s[j+k]，j 及其后面一段都不可能是最大后缀，跳过
   - 如果 s[i+k] < s[j+k]，更新 i = j
   - 如果 s[i+k] == s[j+k]，继续比较下一个字符
4. 返回 s[i:]

## Python 代码实现

### 方法一：双指针优化（推荐）

```python
class Solution:
    def lastSubstring(self, s: str) -> str:
        """
        使用双指针找到字典序最大的后缀
        
        时间复杂度：O(n)
        空间复杂度：O(1)，不算返回值
        """
        n = len(s)
        i = 0  # 当前候选最大后缀的起始位置
        j = 1  # 遍历指针
        k = 0  # 比较偏移量
        
        while j + k < n:
            if s[i + k] == s[j + k]:
                # 当前字符相同，继续比较下一个
                k += 1
            elif s[i + k] > s[j + k]:
                # i 位置的后缀更大，j 跳过已比较的部分
                j = j + k + 1
                k = 0
            else:
                # j 位置的后缀更大，更新候选位置
                # i 及其后面 k 个位置都不可能是答案
                i = max(i + k + 1, j)
                j = i + 1
                k = 0
        
        return s[i:]
```

### 方法二：简化版双指针

```python
class Solution:
    def lastSubstring(self, s: str) -> str:
        """
        简化代码逻辑，更易理解
        """
        n = len(s)
        i, j, k = 0, 1, 0
        
        while j + k < n:
            if s[i + k] == s[j + k]:
                k += 1
            else:
                # 谁小谁跳过，跳过长度为 k+1
                if s[i + k] < s[j + k]:
                    i = max(i + k + 1, j)
                    j = i + 1
                else:
                    j += k + 1
                k = 0
        
        return s[i:]
```

### 方法三：暴力解法（会超时，仅供理解）

```python
class Solution:
    def lastSubstring(self, s: str) -> str:
        """
        暴力方法：生成所有后缀，找最大的
        
        时间复杂度：O(n^2)
        空间复杂度：O(n^2)
        
        仅用于理解题意，实际会超时
        """
        n = len(s)
        max_suffix = ""
        
        for i in range(n):
            suffix = s[i:]
            if suffix > max_suffix:
                max_suffix = suffix
        
        return max_suffix
```

### 方法四：排序方法（会超时）

```python
class Solution:
    def lastSubstring(self, s: str) -> str:
        """
        生成所有后缀并排序
        
        时间复杂度：O(n^2 log n)
        会超时
        """
        n = len(s)
        suffixes = [s[i:] for i in range(n)]
        return max(suffixes)
```

## 复杂度分析

**方法一（双指针优化）：**
- 时间复杂度：`O(n)`
  - 虽然有三层循环（i、j、k），但分析可知每个位置最多被访问常数次
  - i 和 j 单调递增，k 的总移动次数也是 O(n)
- 空间复杂度：`O(1)`，只使用了几个变量（不算返回的字符串）

**方法三（暴力）：**
- 时间复杂度：`O(n^2)`，n 个后缀，每个比较需要 O(n)
- 空间复杂度：`O(n^2)`，存储所有后缀

## 关键点总结

1. **后缀性质**：字典序最大的子字符串必然是某个后缀（从某位置到末尾）

2. **双指针优化**：通过比较跳过不可能的位置，避免枚举所有后缀

3. **跳跃策略**：当发现 s[i+k] < s[j+k] 时，i 到 i+k 这段都不可能是答案，直接跳到 i+k+1

4. **单调性**：i 和 j 都是单调递增的，保证了 O(n) 的时间复杂度

5. **边界处理**：注意 j + k < n 的边界条件

## 易错点

1. **忘记后缀性质**：
   ```python
   # 错误：枚举所有子字符串
   for i in range(n):
       for j in range(i, n):
           substring = s[i:j+1]
   
   # 正确：只需要考虑后缀
   for i in range(n):
       suffix = s[i:]
   ```

2. **跳跃距离错误**：
   ```python
   # 错误：只跳一个位置
   j = j + 1
   
   # 正确：跳过已比较的 k+1 个位置
   j = j + k + 1
   ```

3. **更新 i 时的边界**：
   ```python
   # 可能错误：i 可能会后退
   i = i + k + 1
   
   # 正确：确保 i 不后退
   i = max(i + k + 1, j)
   ```

4. **忘记重置 k**：
   ```python
   # 错误：更新 i 或 j 后忘记重置 k
   if s[i+k] < s[j+k]:
       i = max(i+k+1, j)
       # 忘记 k = 0
   ```

5. **字符串切片的空间开销**：虽然算法本身是 O(1) 空间，但返回 s[i:] 会创建新字符串
