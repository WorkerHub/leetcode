## 题目描述

有两种形状的瓷砖：
- 一种是 `2 x 1` 的多米诺骨牌（domino）
- 一种是 `L` 形的三格骨牌（tromino）

```
多米诺骨牌（2种放置方式）：
XX    X
      X

三格骨牌（4种放置方式）：
XX    X    XX     X
 X    XX     X   XX
```

给定整数 `n`，返回可以铺满 `2 x n` 的面板的方案数。答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入: n = 3
输出: 5
解释: 5种不同的方法如下所示：
XYY XXZ YYY XXX XYY
XYY XXZ YYX YYX ZZX
```

**示例 2：**
```
输入: n = 1
输出: 1
```

**提示：**
- `1 <= n <= 1000`

## 解题思路

这是一道经典的**动态规划**问题，难点在于状态定义和转移方程的推导。

**关键观察：**

1. **状态定义的复杂性**：
   - 不仅要考虑铺满的情况，还要考虑"部分铺满"的中间状态
   - 定义两种状态：
     - `dp[i]`：完全铺满 `2 x i` 的方案数
     - `partial[i]`：铺到第 `i` 列时，有一行多出一格的方案数

2. **状态转移分析**：
   
   **完全铺满 `2 x i` 的方式：**
   - 在 `dp[i-1]` 的基础上，竖着放一个多米诺骨牌
   - 在 `dp[i-2]` 的基础上，横着放两个多米诺骨牌
   - 在 `partial[i-1]` 的基础上，用三格骨牌补全（2种方式）
   
   **部分铺满到第 `i` 列的方式：**
   - 在 `dp[i-2]` 的基础上，用一个三格骨牌（2种方式）
   - 在 `partial[i-1]` 的基础上，横着放一个多米诺骨牌

3. **递推公式**：
   ```
   dp[i] = dp[i-1] + dp[i-2] + 2 * partial[i-1]
   partial[i] = dp[i-2] + partial[i-1]
   ```

4. **化简**：
   将 `partial[i]` 代入 `dp[i]`，可以得到：
   ```
   dp[i] = dp[i-1] + dp[i-2] + 2 * (dp[i-3] + partial[i-2])
        = dp[i-1] + dp[i-2] + 2 * partial[i-1]
        
   或者更简洁的形式：
   dp[i] = 2 * dp[i-1] + dp[i-3]
   ```

## Python 代码实现

### 方法一：双状态动态规划（推荐理解）

```python
class Solution:
    def numTilings(self, n: int) -> int:
        """
        使用两个 DP 数组分别记录完全铺满和部分铺满的状态
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        MOD = 10**9 + 7
        
        # dp[i]: 完全铺满 2 x i 的方案数
        dp = [0] * (n + 1)
        # partial[i]: 部分铺满到第 i 列的方案数（一行多一格）
        partial = [0] * (n + 1)
        
        # 初始化
        dp[0] = 1
        dp[1] = 1
        dp[2] = 2
        partial[0] = 0
        partial[1] = 1
        partial[2] = 2
        
        # 递推
        for i in range(3, n + 1):
            # 完全铺满的方案数
            dp[i] = (dp[i-1] + dp[i-2] + 2 * partial[i-1]) % MOD
            # 部分铺满的方案数
            partial[i] = (dp[i-2] + partial[i-1]) % MOD
        
        return dp[n]
```

### 方法二：简化的单状态 DP

```python
class Solution:
    def numTilings(self, n: int) -> int:
        """
        使用简化的递推公式：dp[i] = 2 * dp[i-1] + dp[i-3]
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if n <= 2:
            return n
        
        MOD = 10**9 + 7
        
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1
        dp[2] = 2
        
        for i in range(3, n + 1):
            dp[i] = (2 * dp[i-1] + dp[i-3]) % MOD
        
        return dp[n]
```

### 方法三：空间优化（滚动数组）

```python
class Solution:
    def numTilings(self, n: int) -> int:
        """
        使用滚动数组优化空间
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if n <= 2:
            return n
        
        MOD = 10**9 + 7
        
        # 只保留最近的三个状态
        dp0, dp1, dp2 = 1, 1, 2
        
        for i in range(3, n + 1):
            dp3 = (2 * dp2 + dp0) % MOD
            dp0, dp1, dp2 = dp1, dp2, dp3
        
        return dp2
```

### 方法四：详细的状态转移（新手学习版）

```python
class Solution:
    def numTilings(self, n: int) -> int:
        """
        详细展示状态转移过程
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        MOD = 10**9 + 7
        
        # dp[i][0]: 铺满 2 x i，第 i 列两行都平齐
        # dp[i][1]: 铺到第 i 列，上行多出一格
        # dp[i][2]: 铺到第 i 列，下行多出一格
        dp = [[0] * 3 for _ in range(n + 1)]
        
        # 初始化
        dp[0][0] = 1
        dp[1][0] = 1
        
        for i in range(2, n + 1):
            # 铺满第 i 列的方式：
            # 1. 前一列铺满，竖着放一个多米诺
            # 2. 前两列铺满，横着放两个多米诺
            # 3. 前一列上行多一格，用三格骨牌补全
            # 4. 前一列下行多一格，用三格骨牌补全
            dp[i][0] = (dp[i-1][0] + dp[i-2][0] + dp[i-1][1] + dp[i-1][2]) % MOD
            
            # 上行多一格的方式：
            # 1. 前两列铺满，用三格骨牌
            # 2. 前一列下行多一格，横着放一个多米诺
            dp[i][1] = (dp[i-2][0] + dp[i-1][2]) % MOD
            
            # 下行多一格的方式（对称）
            dp[i][2] = (dp[i-2][0] + dp[i-1][1]) % MOD
        
        return dp[n][0]
```

## 复杂度分析

### 方法一、二、四
- **时间复杂度：** O(n)，需要遍历 n 次
- **空间复杂度：** O(n)，使用 DP 数组

### 方法三
- **时间复杂度：** O(n)
- **空间复杂度：** O(1)，只使用常数个变量

## 关键点总结

1. **状态定义的重要性**：不仅考虑完全铺满，还要考虑部分铺满的中间状态
2. **递推关系推导**：通过分析最后一步的放置方式，得出状态转移方程
3. **两种状态的相互依赖**：`dp[i]` 依赖 `partial[i-1]`，`partial[i]` 依赖 `dp[i-2]`
4. **化简技巧**：可以将双状态 DP 化简为单状态 DP，公式更简洁
5. **取模运算**：每次计算都要取模，防止溢出

## 易错点

1. **初始化错误**：`dp[0] = 1`（空板有 1 种方案），`dp[1] = 1`，`dp[2] = 2`
2. **状态遗漏**：只考虑完全铺满的状态，忘记考虑部分铺满的中间状态
3. **递推公式错误**：没有正确分析所有转移情况
4. **取模时机**：在每次加法和乘法后都要取模
5. **边界情况**：`n = 1` 和 `n = 2` 需要特殊处理
