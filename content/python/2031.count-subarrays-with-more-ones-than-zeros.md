## 题目描述

给你一个只含 `0` 和 `1` 的数组 `nums`，返回**好子数组**的数目。

**好子数组**定义：子数组中 `1` 的个数严格大于 `0` 的个数。

**示例 1：**
```
输入：nums = [0,1,1,0,1]
输出：9
解释：好子数组如 [0,1,1],[0,1,1,0,1] 等，共9个
```

**示例 2：**
```
输入：nums = [1]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `nums[i]` 是 0 或 1

## 解题思路

将 `0` 替换为 `-1`，则"1 的个数 > 0 的个数"等价于"子数组和 > 0"。

**转化问题：** 统计 `prefix[j] - prefix[i] > 0`，即 `prefix[j] > prefix[i]`（`i < j`）的对数。

这是经典的**逆序对变体**，可以用归并排序（Merge Sort）或树状数组（BIT）解决。

## 代码实现

### 方法一：归并排序（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        # 将 0 替换为 -1，转化为前缀和逆序对问题
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if nums[i] == 1 else -1)

        # 统计 prefix[j] > prefix[i] 的对数（i < j）
        MOD = 10**9 + 7
        count = [0]

        def merge_sort(arr: list, left: int, right: int):
            if right - left <= 1:
                return
            mid = (left + right) // 2
            merge_sort(arr, left, mid)
            merge_sort(arr, mid, right)

            # 合并并统计跨越 mid 的有效对
            j = mid
            for i in range(left, mid):
                while j < right and arr[j] <= arr[i]:
                    j += 1
                count[0] = (count[0] + right - j) % MOD

            # 标准合并
            temp = sorted(arr[left:right])
            arr[left:right] = temp

        arr = prefix[:]
        merge_sort(arr, 0, n + 1)
        return count[0]
```

### 方法二：树状数组（BIT）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        MOD = 10**9 + 7

        # 计算前缀和（将0变为-1后）
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if nums[i] == 1 else -1)

        # 离散化：前缀和范围 -n 到 n
        offset = n  # 偏移量，使下标非负
        size = 2 * n + 2

        # 树状数组
        bit = [0] * (size + 1)

        def update(idx: int):
            idx += 1
            while idx <= size:
                bit[idx] += 1
                idx += idx & (-idx)

        def query(idx: int) -> int:
            idx += 1
            res = 0
            while idx > 0:
                res += bit[idx]
                idx -= idx & (-idx)
            return res

        ans = 0
        for p in prefix:
            # 统计前面比 p 小的前缀和数量（即 prefix[j] > prefix[i] 的 i 数）
            if p + offset - 1 >= 0:
                ans = (ans + query(p + offset - 1)) % MOD
            update(p + offset)

        # 等等，我们要统计 prefix[j] > prefix[i]（i < j）
        # 即对于每个 j，找之前 i < j 中 prefix[i] < prefix[j] 的数量
        # 重新实现：
        bit2 = [0] * (size + 1)

        def update2(idx: int):
            idx += 1
            while idx <= size:
                bit2[idx] += 1
                idx += idx & (-idx)

        def query2(idx: int) -> int:
            if idx < 0:
                return 0
            idx += 1
            res = 0
            while idx > 0:
                res += bit2[idx]
                idx -= idx & (-idx)
            return res

        ans = 0
        for p in prefix:
            # 查询之前有多少个前缀和 < p
            cnt = query2(p + offset - 1)
            ans = (ans + cnt) % MOD
            update2(p + offset)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 归并排序 | O(n log n) | O(n) |
| 树状数组 | O(n log n) | O(n) |

## 关键点总结

1. 将 0 替换为 -1，子数组和 > 0 等价于 1 比 0 多
2. 转化为统计前缀和中"顺序对"（`prefix[i] < prefix[j]`，`i < j`）
3. 归并排序天然适合统计跨越分割点的有效对数

## 易错点

- 结果取模 `10^9 + 7`
- 树状数组需要离散化（前缀和范围 -n 到 n，需要偏移）
- 统计的是 `prefix[j] > prefix[i]`（j 在后），不是逆序对
