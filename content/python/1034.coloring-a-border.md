## 题目描述

给定一个二维整数数组 `grid`，以及三个整数 `row`、`col` 和 `color`。`grid` 中每个值表示该位置处的网格块的颜色。

如果两个方块在任意 4 个方向上相邻，则称它们是相邻的。

如果两个方块具有相同的颜色且相邻，则它们属于同一个连通分量。

连通分量的边界是指连通分量中满足下列条件之一的所有网格块：

- 在上、下、左、右任意一个方向上与不属于同一连通分量的网格块相邻
- 在网格的边界上（第一行/列或最后一行/列）

请你使用指定颜色 `color` 为所有包含网格块 `grid[row][col]` 的连通分量的边界进行着色。

最后返回经过上色渲染后的网格。

**示例 1：**

```
输入: grid = [[1,1],[1,2]], row = 0, col = 0, color = 3
输出: [[3,3],[3,2]]
解释: 
起始位置 grid[0][0] 的颜色为 1
与其连通的有 grid[0][1], grid[1][0]
这些格子的边界包括 grid[0][0], grid[0][1], grid[1][0]
将它们着色为 3
```

**示例 2：**

```
输入: grid = [[1,2,2],[2,3,2]], row = 0, col = 1, color = 3
输出: [[1,3,3],[2,3,3]]
解释:
起始位置 grid[0][1] 的颜色为 2
与其连通的有 grid[0][2], grid[1][2]
边界为 grid[0][1], grid[0][2], grid[1][2]
```

**示例 3：**

```
输入: grid = [[1,1,1],[1,1,1],[1,1,1]], row = 1, col = 1, color = 2
输出: [[2,2,2],[2,1,2],[2,2,2]]
解释:
所有格子都在同一连通分量中
中心的格子不是边界，因为四周都是相同颜色的格子
只有外围的 8 个格子是边界
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 50`
- `1 <= grid[i][j], color <= 1000`
- `0 <= row < m`
- `0 <= col < n`

## 解题思路

这道题的核心是：
1. 找到从 `grid[row][col]` 开始的连通分量（所有相同颜色且相邻的格子）
2. 判断连通分量中哪些格子是边界
3. 只给边界格子着色

**边界的判定条件**：
- 在矩阵的边缘（第一行/列或最后一行/列）
- 至少有一个相邻格子不属于同一连通分量

**算法步骤**：
1. 使用 DFS 或 BFS 遍历连通分量
2. 记录所有属于连通分量的格子
3. 对每个格子判断是否是边界
4. 给边界格子着色

**关键点**：
- 需要先遍历完整个连通分量，再着色，避免着色后影响连通性判断
- 使用 visited 数组标记已访问的格子

## Python 代码实现

### 方法一：DFS 深度优先搜索（推荐）

```python
from typing import List

class Solution:
    def colorBorder(self, grid: List[List[int]], row: int, col: int, color: int) -> List[List[int]]:
        """
        使用 DFS 找到连通分量并标记边界
        
        时间复杂度: O(m*n)
        空间复杂度: O(m*n)
        """
        m, n = len(grid), len(grid[0])
        original_color = grid[row][col]
        visited = set()
        border = []
        
        def dfs(r: int, c: int) -> None:
            """深度优先搜索遍历连通分量"""
            if (r, c) in visited:
                return
            
            visited.add((r, c))
            
            # 判断是否是边界
            is_border = False
            
            # 在矩阵边缘
            if r == 0 or r == m - 1 or c == 0 or c == n - 1:
                is_border = True
            
            # 四个方向
            directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                
                # 越界或颜色不同，说明是边界
                if nr < 0 or nr >= m or nc < 0 or nc >= n or grid[nr][nc] != original_color:
                    is_border = True
                # 同颜色且未访问，继续 DFS
                elif (nr, nc) not in visited:
                    dfs(nr, nc)
            
            # 如果是边界，记录下来
            if is_border:
                border.append((r, c))
        
        # 从起始位置开始 DFS
        dfs(row, col)
        
        # 给边界着色
        for r, c in border:
            grid[r][c] = color
        
        return grid
```

### 方法二：BFS 广度优先搜索

```python
from typing import List
from collections import deque

class Solution:
    def colorBorder(self, grid: List[List[int]], row: int, col: int, color: int) -> List[List[int]]:
        """
        使用 BFS 找到连通分量并标记边界
        
        时间复杂度: O(m*n)
        空间复杂度: O(m*n)
        """
        m, n = len(grid), len(grid[0])
        original_color = grid[row][col]
        visited = [[False] * n for _ in range(m)]
        border = []
        
        queue = deque([(row, col)])
        visited[row][col] = True
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while queue:
            r, c = queue.popleft()
            
            # 判断是否是边界
            is_border = False
            
            # 在矩阵边缘
            if r == 0 or r == m - 1 or c == 0 or c == n - 1:
                is_border = True
            
            # 检查四个方向
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                
                # 越界或颜色不同
                if nr < 0 or nr >= m or nc < 0 or nc >= n or grid[nr][nc] != original_color:
                    is_border = True
                # 同颜色且未访问
                elif not visited[nr][nc]:
                    visited[nr][nc] = True
                    queue.append((nr, nc))
            
            if is_border:
                border.append((r, c))
        
        # 给边界着色
        for r, c in border:
            grid[r][c] = color
        
        return grid
```

### 方法三：优化的 DFS（原地修改）

```python
from typing import List

class Solution:
    def colorBorder(self, grid: List[List[int]], row: int, col: int, color: int) -> List[List[int]]:
        """
        使用负数标记已访问，避免额外的 visited 数组
        
        时间复杂度: O(m*n)
        空间复杂度: O(m*n)，递归栈空间
        """
        m, n = len(grid), len(grid[0])
        original_color = grid[row][col]
        
        def dfs(r: int, c: int) -> bool:
            """
            返回当前格子是否是边界
            使用负数标记已访问的格子
            """
            if r < 0 or r >= m or c < 0 or c >= n or abs(grid[r][c]) != original_color:
                return True
            
            # 已经访问过
            if grid[r][c] < 0:
                return False
            
            # 标记为已访问（使用负数）
            grid[r][c] = -grid[r][c]
            
            # 检查四个方向
            is_border = False
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                if dfs(r + dr, c + dc):
                    is_border = True
            
            # 如果是边界，着色；否则恢复原色
            if is_border:
                grid[r][c] = color
            else:
                grid[r][c] = -grid[r][c]
            
            return False
        
        dfs(row, col)
        return grid
```

### 方法四：两次遍历法（最清晰）

```python
from typing import List

class Solution:
    def colorBorder(self, grid: List[List[int]], row: int, col: int, color: int) -> List[List[int]]:
        """
        第一次遍历找到所有连通分量的格子
        第二次遍历判断边界并着色
        
        时间复杂度: O(m*n)
        空间复杂度: O(m*n)
        """
        m, n = len(grid), len(grid[0])
        original_color = grid[row][col]
        component = set()
        
        # 第一次 DFS：找到所有连通分量的格子
        def find_component(r: int, c: int) -> None:
            if (r, c) in component:
                return
            if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] != original_color:
                return
            
            component.add((r, c))
            
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                find_component(r + dr, c + dc)
        
        find_component(row, col)
        
        # 第二次遍历：判断边界并着色
        for r, c in component:
            # 在矩阵边缘
            if r == 0 or r == m - 1 or c == 0 or c == n - 1:
                grid[r][c] = color
                continue
            
            # 检查是否有邻居不在连通分量中
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                nr, nc = r + dr, c + dc
                if (nr, nc) not in component:
                    grid[r][c] = color
                    break
        
        return grid
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS | O(m×n) | O(m×n) | visited 集合 + 递归栈 |
| BFS | O(m×n) | O(m×n) | visited 数组 + 队列 |
| 优化 DFS | O(m×n) | O(m×n) | 原地标记，只有递归栈 |
| 两次遍历 | O(m×n) | O(m×n) | 最清晰，推荐新手 |

## 关键点总结

1. **连通分量**：相同颜色且相邻的格子组成连通分量
2. **边界判定**：在矩阵边缘或至少有一个邻居不在连通分量中
3. **先遍历后着色**：必须先找到所有连通分量的格子，再判断边界
4. **避免重复访问**：使用 visited 数组或集合标记
5. **四个方向**：上下左右四个方向，不包括对角线

## 易错点

1. **提前着色**：不能边遍历边着色，会影响连通性判断
2. **边界条件**：不要忘记检查矩阵边缘的情况
3. **原色相同**：如果 color 和 original_color 相同，仍需正确处理
4. **已访问标记**：避免死循环和重复访问
5. **方向数组**：只有上下左右四个方向，不包括对角线
