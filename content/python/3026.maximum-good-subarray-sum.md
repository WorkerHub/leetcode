## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和正整数 `k`。

如果 `nums` 的某个子数组 `nums[i..j]`（`0 <= i <= j <= n-1`）满足 `|nums[i] - nums[j]| < k`，则称其为**好子数组**。

返回所有好子数组中，元素和的最大值。如果不存在好子数组，返回 0。

**示例 1：**
```
输入：nums = [1,2,3,1,2,3], k = 3
输出：9
```

**示例 2：**
```
输入：nums = [-1,3,2,4,5], k = 3
输出：11
```

**示例 3：**
```
输入：nums = [-1,-2,-3,-4], k = 2
输出：-6
```

**提示：**
- `2 <= n <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `1 <= k <= 2 * 10^9`

## 解题思路

前缀和 + 哈希表。

对于子数组 `nums[i..j]`，其和 = `prefix[j+1] - prefix[i]`，好子数组的条件 `|nums[i] - nums[j]| < k`。

枚举右端点 `j`，希望找到满足 `|nums[i] - nums[j]| < k` 的最小前缀和 `prefix[i]`（使得 `prefix[j+1] - prefix[i]` 最大）。

条件等价于 `nums[j] - k < nums[i] < nums[j] + k`。

用哈希表存储 `nums[i]` 到最小前缀和 `prefix[i]` 的映射，对每个 `j` 查询区间 `(nums[j]-k, nums[j]+k)` 内的最小前缀和。

但是哈希表查询区间效率不高，需要改用有序字典或分析特殊情况。

由于条件是 `|nums[i] - nums[j]| < k`，对每个 `j`，在哈希表中查 `nums[j]-k+1` 到 `nums[j]+k-1` 范围内的键。

## Python 代码实现

### 方法一：哈希表枚举（推荐）

```python
from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # min_prefix[v] = 以值为 v 的元素开头的子数组的最小前缀和 prefix[i]
        min_prefix = {}
        ans = float('-inf')
        found = False

        for j in range(n):
            v = nums[j]
            # 查找所有满足 |nums[i] - v| < k 的 i，即 nums[i] in (v-k, v+k)
            # 在哈希表中查询 v 及其附近的键
            # 由于 k 可能很大，直接枚举哈希表中 v-k+1 到 v+k-1 的所有键效率可能低
            # 但实际上哈希表中只有 j 个键，可以用 sorted keys + 二分

            # 简化：枚举哈希表中所有键，检查条件
            for u, min_p in min_prefix.items():
                if abs(u - v) < k:
                    subarray_sum = prefix[j + 1] - min_p
                    if not found or subarray_sum > ans:
                        ans = subarray_sum
                        found = True

            # 更新 min_prefix[v]
            if v not in min_prefix or prefix[j] < min_prefix[v]:
                min_prefix[v] = prefix[j]

        return ans if found else 0
```

### 方法二：SortedList 优化

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 用有序列表存储 (nums[i], prefix[i]) 对
        # 对每个 j，找 nums[i] in (nums[j]-k, nums[j]+k) 中 prefix[i] 最小的
        from sortedcontainers import SortedDict

        # val_to_min_prefix: 按 nums[i] 值有序
        val_min = SortedDict()  # key: nums[i], value: min prefix[i]
        ans = float('-inf')
        found = False

        for j in range(n):
            v = nums[j]
            lo, hi = v - k + 1, v + k - 1

            # 查找 val_min 中键在 [lo, hi] 的最小值
            l_idx = val_min.bisect_left(lo)
            r_idx = val_min.bisect_right(hi)

            for idx in range(l_idx, r_idx):
                min_p = val_min.peekitem(idx)[1]
                subarray_sum = prefix[j + 1] - min_p
                if not found or subarray_sum > ans:
                    ans = subarray_sum
                    found = True

            # 更新
            if v not in val_min or prefix[j] < val_min[v]:
                val_min[v] = prefix[j]

        return ans if found else 0
```

## 复杂度分析

- 方法一：O(n^2) 最坏情况（所有键值都在范围内）
- 方法二：O(n log n)（有序字典）
- 空间复杂度：O(n)

## 关键点总结

1. 子数组和 = 右前缀和 - 左前缀和，希望左前缀和最小
2. 好子数组条件 `|nums[i] - nums[j]| < k` 即两端值差小于 k
3. 用哈希表记录每个值对应的最小前缀和，避免重复计算

## 易错点

1. 注意条件是 **严格** 小于 `k`（`|..| < k`，不是 `<=`）
2. 哈希表存的是"该值作为左端点的最小前缀和"
3. 如果不存在好子数组返回 0，注意初始化和判断
