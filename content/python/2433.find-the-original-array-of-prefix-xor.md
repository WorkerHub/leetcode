## 题目描述

给你一个长度为 `n` 的 **整数** 数组 `pref`。找出并返回满足下述条件且长度为 `n` 的数组 `arr`：

- `pref[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]`

注意 `^` 表示 **按位异或**（XOR）运算。

题目保证答案是 **唯一** 的。

**示例 1：**
```
输入：pref = [5,2,0,3,1]
输出：[5,7,2,3,2]
解释：
arr[0] = pref[0] = 5
arr[1] = pref[1] ^ pref[0] = 2 ^ 5 = 7
arr[2] = pref[2] ^ pref[1] = 0 ^ 2 = 2
```

**示例 2：**
```
输入：pref = [13]
输出：[13]
```

**提示：**
- `1 <= pref.length <= 10^5`
- `0 <= pref[i] <= 10^6`

## 解题思路

利用异或前缀的性质：
- `pref[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]`
- `pref[i-1] = arr[0] ^ arr[1] ^ ... ^ arr[i-1]`
- 两式异或：`pref[i] ^ pref[i-1] = arr[i]`

因此：
- `arr[0] = pref[0]`
- `arr[i] = pref[i] ^ pref[i-1]`（对 i >= 1）

## 代码实现

### 方法一：前缀异或差分（推荐）

```python
from typing import List

class Solution:
    def findArray(self, pref: List[int]) -> List[int]:
        n = len(pref)
        arr = [0] * n
        arr[0] = pref[0]  # 第一个元素直接取

        for i in range(1, n):
            # arr[i] = pref[i] XOR pref[i-1]
            arr[i] = pref[i] ^ pref[i - 1]

        return arr
```

### 方法二：列表推导式（简洁版）

```python
from typing import List

class Solution:
    def findArray(self, pref: List[int]) -> List[int]:
        # pref[0] 直接保留，后续每个 arr[i] = pref[i] ^ pref[i-1]
        return [pref[0]] + [pref[i] ^ pref[i - 1] for i in range(1, len(pref))]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 一次遍历 | O(n) | O(n)（输出数组）|

## 关键点总结

1. XOR 的逆运算还是 XOR：`a ^ b = c` 则 `a = b ^ c`
2. `arr[i] = pref[i] ^ pref[i-1]` 是前缀异或的差分公式
3. 第一个元素直接等于 `pref[0]`

## 易错点

- 第一个元素是 `arr[0] = pref[0]`，不是 `0 ^ pref[0]`
- 对比前缀和：`arr[i] = prefix[i] - prefix[i-1]`，这里用 XOR 代替加减
