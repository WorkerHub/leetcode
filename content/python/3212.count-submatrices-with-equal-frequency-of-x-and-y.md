## 题目描述

给你一个二维字符矩阵 `grid`，其中每个字符为 `'X'`、`'Y'` 或 `'.'`。

返回左上角在 `(0, 0)` 的子矩阵（即从 `(0,0)` 到 `(i,j)` 的子矩阵）中，`'X'` 和 `'Y'` 出现频率相等且**至少有一个 `'X'`** 的子矩阵数量。

**示例 1：**
```
输入：grid = [["X","Y","."],["Y",".","."]]
输出：3
```

**示例 2：**
```
输入：grid = [["X","X"],["X","Y"]]
输出：0
```

**提示：**
- `1 <= grid.length, grid[0].length <= 1000`
- `grid[i][j]` 为 `'X'`、`'Y'` 或 `'.'`

## 解题思路

使用二维前缀和：
- `px[i][j]` = 从 (0,0) 到 (i,j) 中 'X' 的数量
- `py[i][j]` = 从 (0,0) 到 (i,j) 中 'Y' 的数量

对于每个 (i, j)，检查 `px[i][j] == py[i][j]` 且 `px[i][j] > 0`。

## Python 代码实现

### 方法一：二维前缀和（推荐）

```python
from typing import List

class Solution:
    def numberOfSubmatrices(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        # px[i][j]：从(0,0)到(i,j)的X数量
        # py[i][j]：从(0,0)到(i,j)的Y数量
        px = [[0] * (n + 1) for _ in range(m + 1)]
        py = [[0] * (n + 1) for _ in range(m + 1)]
        
        ans = 0
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                cell = grid[i - 1][j - 1]
                px[i][j] = px[i-1][j] + px[i][j-1] - px[i-1][j-1] + (1 if cell == 'X' else 0)
                py[i][j] = py[i-1][j] + py[i][j-1] - py[i-1][j-1] + (1 if cell == 'Y' else 0)
                # 子矩阵(0,0)到(i-1,j-1)满足条件
                if px[i][j] == py[i][j] and px[i][j] > 0:
                    ans += 1
        
        return ans
```

### 方法二：逐行更新前缀和

```python
from typing import List

class Solution:
    def numberOfSubmatrices(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0
        # 用一维数组维护列的前缀和
        count_x = [0] * n
        count_y = [0] * n
        
        for i in range(m):
            cx, cy = 0, 0
            for j in range(n):
                if grid[i][j] == 'X':
                    count_x[j] += 1
                elif grid[i][j] == 'Y':
                    count_y[j] += 1
                cx += count_x[j]
                cy += count_y[j]
                if cx == cy and cx > 0:
                    ans += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)（方法一）或 O(n)（方法二）

## 关键点总结

1. 利用二维前缀和，快速计算从 (0,0) 到 (i,j) 的字符数量
2. 条件是 X 和 Y 数量相等且 X 数量大于 0
3. 方法二通过累加列的和来模拟二维前缀和，空间更优

## 易错点

1. 需要 X 数量 > 0，不能只判断相等
2. 前缀和索引偏移要处理正确
