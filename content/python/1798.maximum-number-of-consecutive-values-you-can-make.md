## 题目描述

给你一个整数数组 `coins`，代表你拥有的硬币的面值。任意顺序叠加硬币，你可以用这些硬币凑出多少种**不同**的值？

具体地，如果你凑出了值 `0, 1, 2, ..., k` 中每一个值，则返回 `k + 1`，即你可以凑出的**连续整数值**的个数（从 0 开始）。

**示例 1：**
```
输入：coins = [1,3]
输出：2
解释：可以凑出 0（不选），1（选1），但无法凑出 2，所以返回 2
```

**示例 2：**
```
输入：coins = [1,1,1,4]
输出：8
解释：可以凑出 0 到 7 的所有值
```

**示例 3：**
```
输入：coins = [1,4,10,3,1]
输出：20
```

**提示：**
- `coins[i] >= 1`
- `1 <= coins.length <= 4 * 10^4`
- `1 <= coins[i] <= 4 * 10^4`

## 解题思路

排序后，使用贪心算法。

设当前可以凑出 `[0, reach]` 内的所有值（`reach` 表示当前已能凑出的最大值）。

对排序后的 `coins[i]`：
- 若 `coins[i] <= reach + 1`：将 `coins[i]` 加入后，可以凑出 `[0, reach + coins[i]]`（因为之前能凑出所有 `[0, reach]`，加上 `coins[i]` 后，凑出了 `[coins[i], reach + coins[i]]`，合并得 `[0, reach + coins[i]]`）
- 若 `coins[i] > reach + 1`：`reach + 1` 无法被凑出，停止

初始 `reach = 0`（只能凑出 0），最终返回 `reach + 1`。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def getMaximumConsecutive(self, coins: List[int]) -> int:
        coins.sort()
        reach = 0  # 当前可以凑出 [0, reach] 中所有值

        for coin in coins:
            if coin > reach + 1:
                # coin 太大，无法填补 reach+1 这个空缺
                break
            # 将 coin 加入后，可以凑出 [0, reach + coin]
            reach += coin

        return reach + 1  # 可以凑出 0 到 reach，共 reach+1 个值
```

### 方法二：带详细注释的版本

```python
from typing import List

class Solution:
    def getMaximumConsecutive(self, coins: List[int]) -> int:
        # 排序：从小面值硬币开始处理
        coins.sort()

        # reach：当前能凑出的连续范围 [0, reach]
        # 初始只能凑出 0（不选任何硬币）
        reach = 0

        for coin in coins:
            # 关键条件：只要 coin <= reach+1，就能覆盖 reach+1 这个数
            # 因为之前能凑出 [0, reach]，加上 coin 能凑出 [coin, reach+coin]
            # 当 coin <= reach+1 时，[0, reach] 和 [coin, reach+coin] 有重叠，合并为 [0, reach+coin]
            if coin <= reach + 1:
                reach += coin
            else:
                # 存在空缺，reach+1 无法凑出
                break

        # 能凑出 0, 1, 2, ..., reach，共 reach+1 个连续值
        return reach + 1
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序的时间复杂度
- **空间复杂度**：O(1)，只用到常数额外空间

## 关键点总结

1. 排序保证从小到大依次处理硬币
2. 贪心不变式：处理完前 i 个硬币后，能凑出 `[0, reach]` 所有值
3. 条件 `coin <= reach + 1`：当前硬币能填补 `reach + 1` 的空缺
4. 经典算法思路：与"接缝"类型的区间扩展问题相同

## 易错点

1. 初始 `reach = 0`（能凑出 0），不是 -1 或 1
2. 循环中如果 `coin > reach + 1`，直接 break，无需继续（后面的 coin 更大）
3. 最终返回 `reach + 1`（包含 0，共 reach+1 个值）
