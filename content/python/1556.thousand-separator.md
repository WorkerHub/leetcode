## 题目描述

给你一个整数 `n`，请你每隔三位添加点（即千分位分隔符）并返回该整数的字符串表示。

**示例 1：**
```
输入：n = 987
输出："987"
```

**示例 2：**
```
输入：n = 1234567891
输出："1.234.567.891"
```

**提示：**
- `0 <= n < 2^31`

## 解题思路

### 从右到左每三位插入点

将数字转为字符串，从右到左每隔 3 位插入 `'.'`。

## 代码实现

### 方法一：逆序分组（推荐）

```python
class Solution:
    def thousandSeparator(self, n: int) -> str:
        s = str(n)
        result = []
        for i, c in enumerate(reversed(s)):
            if i > 0 and i % 3 == 0:
                result.append('.')
            result.append(c)
        return ''.join(reversed(result))
```

### 方法二：切片分组

```python
class Solution:
    def thousandSeparator(self, n: int) -> str:
        s = str(n)
        # 从右到左每3位分一组
        groups = []
        while s:
            groups.append(s[-3:])
            s = s[:-3]
        return '.'.join(reversed(groups))
```

### 方法三：正则或格式化（Python 技巧）

```python
class Solution:
    def thousandSeparator(self, n: int) -> str:
        # Python 格式化：使用逗号分隔，再替换为点
        return f"{n:,}".replace(',', '.')
```

## 复杂度分析

- **时间复杂度**：O(log N)，数字位数为 O(log N)
- **空间复杂度**：O(log N)

## 关键点总结

1. 从右到左每 3 位一组，用 `'.'` 分隔
2. Python 格式化 `f"{n:,}"` 使用逗号分隔，再替换为点是最简洁的方法
3. 方法一通过枚举逆序字符，每 3 位插入分隔符

## 易错点

- `n = 0` 时输出 `"0"`（没有分隔符），各方法都能正确处理
- 分隔符是 `.`（点），不是 `,`（逗号）
