## 题目描述

给你一个字符串 `number`（正整数），和一个字符 `digit`。

`number` 中恰好有一次或多次出现 `digit`。请你选择 `number` 中 `digit` 出现的**某一处**，将其删除，使得结果数字**最大**。

返回最大结果（字符串形式）。

**示例 1：**
```
输入：number = "123", digit = "1"
输出："23"
```

**示例 2：**
```
输入：number = "1231", digit = "1"
输出："231"
```

**示例 3：**
```
输入：number = "551", digit = "5"
输出："51"
```

## 解题思路

**贪心：** 遍历 `number`，找到第一个满足"删除后数字最大"的 `digit` 位置。

规则：在所有出现 `digit` 的位置中，删除哪个使结果最大？

若 `digit` 在位置 `i` 的下一个字符 `number[i+1] > digit`（即下一个字符更大），则删除 `i` 处使得数字增大（高位变大），这是最优的。

否则保留，继续检查下一个 `digit` 位置。如果所有位置都没有比 `digit` 大的下一个字符，则删除最后一个出现的 `digit`。

## 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def removeDigit(self, number: str, digit: str) -> str:
        last_pos = -1  # 记录最后一个 digit 的位置

        for i, ch in enumerate(number):
            if ch == digit:
                last_pos = i
                # 若下一个字符大于 digit，删除当前位置
                if i + 1 < len(number) and number[i + 1] > digit:
                    return number[:i] + number[i + 1:]

        # 没有找到"下一个更大"的情况，删除最后一个 digit
        return number[:last_pos] + number[last_pos + 1:]
```

### 方法二：枚举所有可能，取最大

```python
class Solution:
    def removeDigit(self, number: str, digit: str) -> str:
        best = ""
        for i, ch in enumerate(number):
            if ch == digit:
                candidate = number[:i] + number[i + 1:]
                if candidate > best:
                    best = candidate
        return best
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(n)，字符串切片创建新字符串。

**方法二：**
- 时间复杂度：O(n^2)，每次候选比较 O(n)。
- 空间复杂度：O(n)。

## 关键点总结

1. 贪心：找到第一个 `digit[i]` 后面有更大字符的位置，删除之。
2. 若无此位置，删除最后一个 `digit`（去掉最低有效位中的该数字）。
3. 方法二暴力枚举所有候选，用字符串大小比较，适合理解。

## 易错点

- 字符串比较 `>` 是字典序，对数字字符串恰好等价于数值比较（相同长度）。
- 方法一记录 `last_pos` 是为了处理所有下一位都不更大的情况。
