## 题目描述

给你一个下标从 **0** 开始的整数数组 `tires`，其中 `tires[i] = [fi, ri]` 表示第 `i` 种轮胎：
- 第一圈用时 `fi`
- 之后每圈乘以系数 `ri`（第 k 圈用时 `fi * ri^(k-1)`）

同时给你整数 `changeTime`（换轮胎所需时间）和整数 `numLaps`（总圈数）。

每次换轮胎后从第 1 圈重新开始。返回完成比赛所需的**最少**时间。

**示例 1：**
```
输入：tires = [[2,3],[3,4]], changeTime = 5, numLaps = 4
输出：21
```

**示例 2：**
```
输入：tires = [[1,10],[2,2],[3,4]], changeTime = 6, numLaps = 5
输出：25
```

**提示：**
- `1 <= tires.length <= 10^5`
- `tires[i].length == 2`
- `1 <= fi, changeTime <= 10^5`
- `2 <= ri <= 10^5`
- `1 <= numLaps <= 1000`

## 解题思路

**预处理 + DP**

关键观察：由于 `ri >= 2`，连续用同一套轮胎跑 `k` 圈后，时间会指数增长。当 `fi * ri^(k-1) >= fi + changeTime` 时，换一套新轮胎比继续用旧轮胎更优。因此每套轮胎连续使用的圈数不超过约 `log2(fi + changeTime)` 圈，实际不超过 `18~20` 圈。

步骤：
1. 预计算 `best[k]`：连续跑 `k` 圈（中途不换胎）的最少时间（枚举所有轮胎）。
2. DP：`dp[i]` = 跑完前 `i` 圈的最少总时间（含换胎时间）。
   - `dp[i] = min(dp[i-k] + changeTime + best[k])` 对所有合法的 `k`。
   - 第一次不需要 `changeTime`（初始不需要换胎）。

## 代码实现

### 方法一：预处理 + DP（推荐）

```python
from typing import List

class Solution:
    def minimumFinishTime(self, tires: List[List[int]], changeTime: int, numLaps: int) -> int:
        INF = float('inf')
        MAX_K = 18  # 单套轮胎最多连续跑的圈数（指数增长，超过20圈不划算）

        # best[k] = 用一套轮胎连续跑 k 圈的最小时间
        best = [INF] * (MAX_K + 1)

        for f, r in tires:
            time = f   # 累计时间
            cur = f    # 当圈时间
            for k in range(1, MAX_K + 1):
                if time >= INF:
                    break
                best[k] = min(best[k], time)
                cur *= r
                if cur > f + changeTime:
                    break  # 超过换胎成本，不再延伸
                time += cur

        # dp[i] = 跑完 i 圈的最少时间（包含换胎时间，但第一套不需换）
        dp = [INF] * (numLaps + 1)
        dp[0] = -changeTime  # 初始化：还没开始，-changeTime 是为了抵消第一次换胎时间

        for i in range(1, numLaps + 1):
            for k in range(1, min(i, MAX_K) + 1):
                if best[k] < INF:
                    dp[i] = min(dp[i], dp[i - k] + changeTime + best[k])

        return dp[numLaps]
```

### 方法二：等价写法（显式处理第一套轮胎）

```python
from typing import List

class Solution:
    def minimumFinishTime(self, tires: List[List[int]], changeTime: int, numLaps: int) -> int:
        INF = float('inf')
        MAX_K = 18

        best = [INF] * (MAX_K + 2)
        for f, r in tires:
            cur = f
            total = 0
            for k in range(1, MAX_K + 1):
                total += cur
                if cur > f + changeTime:
                    break
                best[k] = min(best[k], total)
                cur = cur * r

        dp = [INF] * (numLaps + 1)
        dp[0] = 0
        for i in range(1, numLaps + 1):
            for k in range(1, min(i, MAX_K) + 1):
                if best[k] < INF and dp[i - k] < INF:
                    cost = (changeTime if i - k > 0 else 0) + best[k]
                    dp[i] = min(dp[i], dp[i - k] + cost)

        return dp[numLaps]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 预处理 + DP | O(numLaps * MAX_K + len(tires) * MAX_K) | O(numLaps + MAX_K) |

MAX_K 约为 18~20，numLaps <= 1000，整体高效。

## 关键点总结

1. 单套轮胎连续圈数有上限（约 18 圈），因为时间指数增长。
2. 预处理 `best[k]` 后，问题转化为简单的 DP。
3. 初始状态技巧：`dp[0] = -changeTime`，统一处理换胎时间。

## 易错点

- MAX_K 取 18 是因为 `2^18 * 1 > 10^5`（fi 最小为 1，ri 最小为 2）。
- 注意第一圈不需要换胎时间，需要特殊处理（或用初始值技巧）。
