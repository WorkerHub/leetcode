## 题目描述

给定一个整数数组 `asteroids`，表示在同一行的小行星。

对于数组中的每一个元素，其绝对值表示小行星的大小，正负表示小行星的移动方向（正表示向右移动，负表示向左移动）。每一颗小行星以相同的速度移动。

找出碰撞后剩下的所有小行星。碰撞规则：两个小行星相互碰撞，较小的小行星会爆炸。如果两颗小行星大小相同，则两颗都会爆炸。两颗移动方向相同的小行星，永远不会发生碰撞。

**示例 1：**

```
输入：asteroids = [5,10,-5]
输出：[5,10]
解释：10 和 -5 碰撞后只剩下 10。5 和 10 永远不会发生碰撞。
```

**示例 2：**

```
输入：asteroids = [8,-8]
输出：[]
解释：8 和 -8 碰撞后，两者都爆炸。
```

**示例 3：**

```
输入：asteroids = [10,2,-5]
输出：[10]
解释：2 和 -5 发生碰撞后剩下 -5。10 和 -5 发生碰撞后剩下 10。
```

## 解题思路

**核心思想：使用栈模拟碰撞**

只有向右的小行星（正数）和向左的小行星（负数）相遇才会碰撞。

**算法流程：**
1. 遍历小行星
2. 如果是正数或栈为空或栈顶是负数，直接入栈
3. 如果是负数且栈顶是正数，模拟碰撞

## Python 代码实现

### 方法一：栈模拟（推荐）⭐

```python
from typing import List

class Solution:
    def asteroidCollision(self, asteroids: List[int]) -> List[int]:
        stack = []
        
        for asteroid in asteroids:
            # 处理碰撞
            while stack and asteroid < 0 < stack[-1]:
                # 栈顶（向右）vs 当前（向左）
                if stack[-1] < -asteroid:
                    # 栈顶较小，爆炸
                    stack.pop()
                    continue
                elif stack[-1] == -asteroid:
                    # 大小相同，都爆炸
                    stack.pop()
                break
            else:
                # 没有碰撞或当前存活
                stack.append(asteroid)
        
        return stack
```

### 方法二：详细注释版

```python
class Solution:
    def asteroidCollision(self, asteroids: List[int]) -> List[int]:
        stack = []
        
        for ast in asteroids:
            alive = True  # 当前小行星是否存活
            
            # 只有当前向左（负数）且栈顶向右（正数）才碰撞
            while alive and ast < 0 and stack and stack[-1] > 0:
                # 比较大小
                if stack[-1] < -ast:
                    # 栈顶爆炸
                    stack.pop()
                elif stack[-1] == -ast:
                    # 都爆炸
                    stack.pop()
                    alive = False
                else:
                    # 当前爆炸
                    alive = False
            
            if alive:
                stack.append(ast)
        
        return stack
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(n)

## 关键点总结

1. **碰撞条件**：栈顶向右（>0），当前向左（<0）
2. **三种结果**：栈顶爆炸、都爆炸、当前爆炸
3. **while循环**：一个小行星可能引发多次碰撞
