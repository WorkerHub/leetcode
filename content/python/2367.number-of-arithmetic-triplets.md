## 题目描述

给你一个下标从 **0** 开始、**严格递增**的整数数组 `nums` 和一个正整数 `diff`。如果满足下述全部条件，则三元组 `(i, j, k)` 就是一个**等差三元组**：
- `i < j < k`
- `nums[j] - nums[i] == diff`
- `nums[k] - nums[j] == diff`

返回不同**等差三元组**的数目。

**示例 1：**
```
输入：nums = [0,1,4,6,7,10], diff = 3
输出：2
解释：(0, 2, 4) 和 (1, 3, 5) 是等差三元组（nums[0]=0, nums[2]=4, nums[4]=7 和 nums[1]=1, nums[3]=6, nums[5]=10）。
```

**提示：**
- `3 <= nums.length <= 200`
- `0 <= nums[i] <= 200`
- `1 <= diff <= 50`
- `nums` 严格递增

## 解题思路

**方法一：哈希表**
将所有元素放入集合，对每个元素 `x`，检查 `x + diff` 和 `x + 2*diff` 是否都在集合中。

**方法二：三重枚举**
暴力枚举所有 i < j < k 的组合，检查是否满足条件。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class Solution:
    def arithmeticTriplets(self, nums: List[int], diff: int) -> int:
        num_set = set(nums)
        count = 0
        
        for x in nums:
            # 检查 x + diff 和 x + 2*diff 是否都存在
            if x + diff in num_set and x + 2 * diff in num_set:
                count += 1
        
        return count
```

### 方法二：双指针

```python
from typing import List

class Solution:
    def arithmeticTriplets(self, nums: List[int], diff: int) -> int:
        count = 0
        n = len(nums)
        
        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                if nums[j] - nums[i] != diff:
                    continue
                for k in range(j + 1, n):
                    if nums[k] - nums[j] == diff:
                        count += 1
        
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(n) | O(n) |
| 三重枚举 | O(n^3) | O(1) |

## 关键点总结

1. 等差三元组等价于找 x、x+diff、x+2*diff 都在数组中的元素 x。
2. 哈希表 O(1) 查找，遍历一次即可。
3. 数组严格递增保证了不会重复计数。

## 易错点

- 枚举的是 x（三元组第一个元素），而不是 j（中间元素），这样更直观。
- 不需要检查下标顺序，严格递增的数组中 `x < x+diff < x+2*diff` 时下标天然递增。
