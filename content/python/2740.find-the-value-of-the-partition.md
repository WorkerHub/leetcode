## 题目描述

给你一个 **正整数** 数组 `nums`，将它分成两个非空子集 `subset1` 和 `subset2`（每个元素恰好属于一个子集），分区值定义为 `|max(subset1) - min(subset2)|`。

返回所有可能分区的 **最小分区值**。

**示例 1：**
```
输入：nums = [1,3,2,4]
输出：1
解释：分区 [1,2] 和 [3,4]，分区值 |2-3| = 1
```

**示例 2：**
```
输入：nums = [100,1,10]
输出：9
解释：分区 [1] 和 [10,100]，分区值 |1-10| = 9
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

排序后，最优分区是取前 `k` 个元素和后 `n-k` 个元素。分区值 = `nums[k] - nums[k-1]`（排序后相邻元素之差的最小值）。

只需遍历排序数组，找相邻元素差的最小值。

## Python 代码实现

### 方法一：排序 + 相邻差（推荐）

```python
from typing import List

class Solution:
    def findValueOfPartition(self, nums: List[int]) -> int:
        nums.sort()
        # 最小分区值就是排序后相邻元素之差的最小值
        return min(nums[i+1] - nums[i] for i in range(len(nums) - 1))
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后，最优分区一定是某个前缀和后缀
2. 分区值 = 前缀最大值（nums[k-1]）与后缀最小值（nums[k]）之差

## 易错点

1. 分区后取绝对值，但排序后 `nums[k] >= nums[k-1]`，差值非负
