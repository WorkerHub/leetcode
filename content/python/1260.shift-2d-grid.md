## 题目描述

给定一个 m x n 的二维网格 grid 和一个整数 k。你需要将 grid 进行 k 次移位操作。

每次移位操作规则如下：

- grid[i][j] 位置的元素移动到 grid[i][j + 1]
- grid[i][n - 1] 位置的元素移动到 grid[i + 1][0]
- grid[m - 1][n - 1] 位置的元素移动到 grid[0][0]

返回进行 k 次移位操作后的二维网格。

**示例 1:**

```
输入: grid = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出: [[9,1,2],[3,4,5],[6,7,8]]
解释:
初始: [[1,2,3],
       [4,5,6],
       [7,8,9]]
      
移位 1 次后:
      [[9,1,2],
       [3,4,5],
       [6,7,8]]
```

**示例 2:**

```
输入: grid = [[3,8,1,9],[19,7,2,5],[4,6,11,10],[12,0,21,13]], k = 4
输出: [[12,0,21,13],[3,8,1,9],[19,7,2,5],[4,6,11,10]]
```

**示例 3:**

```
输入: grid = [[1,2,3],[4,5,6],[7,8,9]], k = 9
输出: [[1,2,3],[4,5,6],[7,8,9]]
解释: k = 9 相当于移动了一整圈，回到原位
```

**提示:**

- m == grid.length
- n == grid[i].length
- 1 <= m <= 50
- 1 <= n <= 50
- -1000 <= grid[i][j] <= 1000
- 0 <= k <= 100

## 解题思路

这道题本质上是一个循环移位问题。可以将二维矩阵看作一维数组的环形排列。

**核心思想：**

1. 将二维矩阵"展平"为一维数组
2. 对一维数组进行循环右移 k 位
3. 将一维数组重新"折叠"回二维矩阵

**关键观察：**

- 总共有 m * n 个元素
- 移动 k 次后，位置 i 的元素会移动到位置 (i + k) % (m * n)
- 可以直接计算每个元素的新位置，不需要真的移动 k 次

**优化：**

- k 可能很大，可以先对 k 取模：k = k % (m * n)
- 如果 k = 0 或 k = m * n，直接返回原矩阵

## Python 代码实现

### 方法一：一维展平 + 重建（推荐）

```python
from typing import List

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        total = m * n
        
        # 优化：k 对总元素数取模
        k = k % total
        if k == 0:
            return grid
        
        # 将二维数组展平为一维
        flat = []
        for row in grid:
            flat.extend(row)
        
        # 循环右移 k 位
        # 将后 k 个元素移到前面
        shifted = flat[-k:] + flat[:-k]
        
        # 重建二维数组
        result = []
        for i in range(m):
            result.append(shifted[i * n:(i + 1) * n])
        
        return result
```

### 方法二：直接计算新位置

```python
from typing import List

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        total = m * n
        k = k % total
        
        # 创建新矩阵
        result = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                # 计算当前位置在一维数组中的索引
                old_index = i * n + j
                # 计算移动后的新索引
                new_index = (old_index + k) % total
                # 计算新索引对应的二维坐标
                new_i = new_index // n
                new_j = new_index % n
                # 将元素放到新位置
                result[new_i][new_j] = grid[i][j]
        
        return result
```

### 方法三：原地修改（使用辅助数组）

```python
from typing import List

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        k = k % (m * n)
        
        # 提取所有元素
        elements = []
        for i in range(m):
            for j in range(n):
                elements.append(grid[i][j])
        
        # 计算移位后的起始位置
        start = len(elements) - k
        
        # 重新填充 grid
        index = 0
        for i in range(m):
            for j in range(n):
                grid[i][j] = elements[(start + index) % len(elements)]
                index += 1
        
        return grid
```

### 方法四：使用 deque（双端队列）

```python
from typing import List
from collections import deque

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        k = k % (m * n)
        
        # 展平为一维
        flat = deque()
        for row in grid:
            flat.extend(row)
        
        # 使用 rotate 方法右移
        flat.rotate(k)
        
        # 重建二维数组
        result = []
        for i in range(m):
            row = []
            for j in range(n):
                row.append(flat.popleft())
            result.append(row)
        
        return result
```

### 方法五：数学公式（最优化）

```python
from typing import List

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        
        # 二维坐标转一维索引
        def to_1d(i: int, j: int) -> int:
            return i * n + j
        
        # 一维索引转二维坐标
        def to_2d(index: int) -> tuple:
            return index // n, index % n
        
        result = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                # 计算新位置
                old_pos = to_1d(i, j)
                new_pos = (old_pos + k) % (m * n)
                new_i, new_j = to_2d(new_pos)
                result[new_i][new_j] = grid[i][j]
        
        return result
```

## 复杂度分析

**方法一：一维展平 + 重建**

- 时间复杂度：O(m * n)
  - 展平需要 O(m * n)
  - 切片操作 O(m * n)
  - 重建需要 O(m * n)
- 空间复杂度：O(m * n)，需要额外的一维数组和结果数组

**方法二：直接计算新位置**

- 时间复杂度：O(m * n)，遍历一次矩阵
- 空间复杂度：O(m * n)，结果数组

**方法三：原地修改**

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

**方法四：使用 deque**

- 时间复杂度：O(m * n)
  - rotate 操作是 O(k)，但 k 已经取模
- 空间复杂度：O(m * n)

**方法五：数学公式**

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 将二维问题转化为一维问题，简化思考
2. 使用取模优化：k = k % (m * n)，避免不必要的计算
3. 循环右移 k 位 = 将后 k 个元素移到前面
4. 理解二维坐标和一维索引的转换关系：
   - 一维索引 = i * n + j
   - i = 一维索引 // n
   - j = 一维索引 % n
5. 如果 k = 0，直接返回原矩阵

## 易错点

1. 忘记对 k 取模
   - k 可能远大于元素总数，会导致重复移动
2. 切片边界错误
   - 右移 k 位：flat[-k:] + flat[:-k]
   - 不是 flat[k:] + flat[:k]（这是左移）
3. 二维坐标转换错误
   - new_i = new_index // n（行号）
   - new_j = new_index % n（列号）
4. 特殊情况处理
   - k = 0 或 k = m * n 时，应直接返回原矩阵
5. 列表切片时空列表的处理
   - flat[-0:] 会返回空列表，需要特殊判断 k == 0
