## 题目描述

在一条单行道上，有 n 辆车开往同一目的地，目的地是几英里以外的 target 。

给定两个整数数组 position 和 speed ，长度都是 n ，其中 position[i] 是第 i 辆车的位置， speed[i] 是第 i 辆车的速度（单位：英里/小时）。

一辆车永远不会超过前面的另一辆车，但它可以追上去，并以较慢车的速度在另一辆车旁边行驶。

车队 是指并排行驶的一辆或几辆汽车。车队的速度是车队中 最慢 的车的速度。

即便一辆车在 target 才赶上了一个车队，它们仍然会被视为是同一个车队。

返回到达目的地的 车队数量 。

**示例 1：**
```
输入：target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]
输出：3
解释：
- 从 10 和 8 开始的车会组成一个车队，它们在 12 处相遇。车队在 target 形成。
- 在 0 处的车不会追上其他车，所以它自己是一个车队。
- 从 5 和 3 开始的车会组成一个车队，它们在 6 处相遇。注意，在到达 target 之前，车队可能发生变化（比如在 6 处，车队从 [5,3] 变为只有一辆车）。
```

**示例 2：**
```
输入：target = 10, position = [3], speed = [3]
输出：1
解释：只有一辆车，因此只有一个车队。
```

**示例 3：**
```
输入：target = 100, position = [0,2,4], speed = [4,2,1]
输出：1
解释：
- 从 0，2 和 4 开始的车向右行驶。
- 速度分别为 4，2，1 的车在位置 4，4 和 4 相遇，形成一个车队。
- 车队在 target 到达。
```

**提示：**
- n == position.length == speed.length
- 1 <= n <= 10^5
- 0 < target <= 10^6
- 0 <= position[i] < target
- position 中每个值都不同
- 0 < speed[i] <= 10^6

## 解题思路

这道题的关键是理解**车队的形成规则**：
1. 后面的车如果比前面的车快，会追上并减速到前车速度
2. 后面的车如果比前面的车慢，永远追不上

**核心观察：**
1. **按位置从后往前考虑**：离目标近的车先考虑
2. **计算到达时间**：`time = (target - position) / speed`
3. **合并规则**：如果后面的车到达时间 ≤ 前面的车，它们会合并成一个车队
4. **单调性**：从后往前，如果当前车到达时间 > 前一个车队的到达时间，说明它无法追上，形成新车队

**算法流程：**
1. 将车按位置从大到小排序（从离目标近到远）
2. 计算每辆车到达目标的时间
3. 从前往后遍历，使用栈维护车队
4. 如果当前车的到达时间 > 栈顶车队时间，说明无法追上，入栈形成新车队
5. 否则，当前车会追上栈顶车队，不入栈

## Python 代码实现

### 方法一：排序 + 单调栈（推荐）⭐

```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        # 将车按位置从大到小排序（离目标近的在前）
        cars = sorted(zip(position, speed), reverse=True)
        
        # 栈存储每个车队到达目标的时间
        stack = []
        
        for pos, spd in cars:
            # 计算当前车到达目标的时间
            time = (target - pos) / spd
            
            # 如果栈为空，或当前车到达时间大于栈顶（无法追上前面的车队）
            if not stack or time > stack[-1]:
                stack.append(time)
            # 否则，当前车会追上栈顶车队，合并（不入栈）
        
        return len(stack)
```

**代码说明：**
- 按位置排序，从离目标近的车开始处理
- 栈存储每个车队的到达时间
- 如果当前车到达时间 > 栈顶，说明它追不上，形成新车队

### 方法二：排序 + 计数（不使用栈）

```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        # 按位置从大到小排序
        cars = sorted(zip(position, speed), reverse=True)
        
        fleets = 0
        prev_time = 0  # 前一个车队的到达时间
        
        for pos, spd in cars:
            # 计算当前车到达时间
            time = (target - pos) / spd
            
            # 如果当前车到达时间 > 前一个车队时间，形成新车队
            if time > prev_time:
                fleets += 1
                prev_time = time
        
        return fleets
```

**代码说明：**
- 不使用栈，只记录前一个车队的到达时间
- 更简洁，空间复杂度更低

### 方法三：排序 + 列表遍历

```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        # 按位置从小到大排序
        cars = sorted(zip(position, speed))
        
        # 计算所有车到达时间
        times = [(target - pos) / spd for pos, spd in cars]
        
        fleets = 0
        # 从后往前遍历（从离目标近的车开始）
        i = len(times) - 1
        while i >= 0:
            fleets += 1
            time = times[i]
            # 跳过所有能追上当前车队的车
            i -= 1
            while i >= 0 and times[i] <= time:
                i -= 1
        
        return fleets
```

**代码说明：**
- 从后往前处理，每次找到一个新车队
- 跳过所有能追上的车

### 方法四：使用字典优化

```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        # 创建位置到速度的映射
        pos_speed = {p: s for p, s in zip(position, speed)}
        
        # 按位置从大到小排序
        sorted_positions = sorted(position, reverse=True)
        
        stack = []
        for pos in sorted_positions:
            spd = pos_speed[pos]
            time = (target - pos) / spd
            
            if not stack or time > stack[-1]:
                stack.append(time)
        
        return len(stack)
```

## 复杂度分析

### 方法一、二：
- **时间复杂度**：O(n log n)，排序的时间复杂度。
- **空间复杂度**：O(n)，排序和栈的空间。

### 方法三：
- **时间复杂度**：O(n log n)，排序 + 线性遍历。
- **空间复杂度**：O(n)，存储到达时间数组。

## 图解示例

**示例 1**：`target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]`

```
位置排序（从大到小）：
位置: 10,  8,  5,  3,  0
速度:  2,  4,  1,  3,  1
时间:  1, 1, 7,  3, 12

处理过程：
1. 位置 10，时间 1  → stack = [1]，车队数 = 1
2. 位置 8， 时间 1  → 1 <= 1（追上了），不入栈，stack = [1]
3. 位置 5， 时间 7  → 7 > 1（追不上），入栈，stack = [1, 7]，车队数 = 2
4. 位置 3， 时间 3  → 3 <= 7（追上了），不入栈，stack = [1, 7]
5. 位置 0， 时间 12 → 12 > 7（追不上），入栈，stack = [1, 7, 12]，车队数 = 3

最终车队数：3
```

**车队组成：**
- 车队 1：位置 10 和 8 的车（在位置 12 相遇）
- 车队 2：位置 5 和 3 的车（在位置 6 相遇）
- 车队 3：位置 0 的车（自己一个车队）

## 关键点总结

1. **排序策略**：按位置从大到小排序，从离目标近的车开始处理
2. **到达时间**：`time = (target - position) / speed`
3. **合并判断**：后车到达时间 ≤ 前车时间，说明会追上并合并
4. **单调栈应用**：栈中存储的是每个车队的到达时间，保持单调递增
5. **贪心思想**：每辆车尽可能追上前面的车队

## 易错点

1. **排序方向错误**：应该从位置大的（离目标近的）开始处理
   ```python
   # ✅ 正确：从大到小
   cars = sorted(zip(position, speed), reverse=True)
   
   # ❌ 错误：从小到大会导致逻辑混乱
   cars = sorted(zip(position, speed))
   ```

2. **到达时间计算错误**：
   ```python
   # ✅ 正确
   time = (target - pos) / spd
   
   # ❌ 错误：忘记减去当前位置
   time = target / spd
   ```

3. **合并条件判断错误**：
   - 应该是 `time > stack[-1]` 才形成新车队
   - 如果 `time <= stack[-1]`，说明会追上，不应该入栈

4. **整数除法问题**：Python 3 中 `/` 是浮点除法，`//` 是整数除法，这里必须用 `/`
