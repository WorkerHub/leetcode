## 题目描述

给你一个数组 `arr`，请你将每个元素用它右边最大的元素替换，如果是最后一个元素，用 `-1` 替换。

完成所有替换操作后，请你返回这个数组。

**示例 1：**

```
输入：arr = [17,18,5,4,6,1]
输出：[18,6,6,6,1,-1]
解释：
- 下标 0 的元素（17）右边最大元素是 18
- 下标 1 的元素（18）右边最大元素是 6
- 下标 2 的元素（5）右边最大元素是 6
- 下标 3 的元素（4）右边最大元素是 6
- 下标 4 的元素（6）右边最大元素是 1
- 下标 5 的元素（1）是最后一个，替换为 -1
```

**示例 2：**

```
输入：arr = [400]
输出：[-1]
解释：只有一个元素，直接替换为 -1
```

**提示：**

- `1 <= arr.length <= 10^4`
- `1 <= arr[i] <= 10^5`

## 解题思路

### 方法一：从右向左扫描（最优）

**核心思想**：

如果从左向右遍历，每次计算右边最大值都需要重新扫描右侧所有元素，时间复杂度 O(n^2)。

改为**从右向左**遍历，用一个变量 `max_right` 维护"当前位置右边的最大值"：
- 处理最后一个元素时，右边无元素，`max_right = -1`
- 从倒数第二个元素开始向左，每次：
  1. 记录当前元素的原始值（因为当前元素会成为左边元素的"右边元素之一"）
  2. 将当前位置替换为 `max_right`
  3. 更新 `max_right = max(max_right, 原始值)`

这样只需一次遍历，时间复杂度降为 O(n)。

**示例演示**（arr = [17, 18, 5, 4, 6, 1]）：

```
从右向左处理：
  i=5：arr[5]=1，右边无元素，替换为 -1，max_right = max(-1, 1) = 1
  i=4：arr[4]=6，替换为 max_right=1，max_right = max(1, 6) = 6
  i=3：arr[3]=4，替换为 max_right=6，max_right = max(6, 4) = 6
  i=2：arr[2]=5，替换为 max_right=6，max_right = max(6, 5) = 6
  i=1：arr[1]=18，替换为 max_right=6，max_right = max(6, 18) = 18
  i=0：arr[0]=17，替换为 max_right=18，max_right = max(18, 17) = 18
结果：[18, 6, 6, 6, 1, -1]
```

### 方法二：暴力枚举（理解用）

对每个位置，直接扫描其右侧所有元素取最大值，时间复杂度 O(n^2)，不推荐。

## Python 代码实现

### 方法一：从右向左一次扫描（推荐）

```python
from typing import List

class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        n = len(arr)
        # max_right 表示当前位置右边所有元素的最大值
        # 最后一个位置右边无元素，初始化为 -1
        max_right = -1

        # 从右向左遍历
        for i in range(n - 1, -1, -1):
            # 记录当前元素原始值（后续更新 max_right 时需要）
            cur = arr[i]
            # 将当前位置替换为右边最大值
            arr[i] = max_right
            # 更新右边最大值（当前元素也是其左边元素的"右边元素之一"）
            max_right = max(max_right, cur)

        return arr
```

### 方法二：暴力枚举（超时，仅用于理解）

```python
from typing import List

class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        n = len(arr)
        result = []

        for i in range(n):
            if i == n - 1:
                # 最后一个元素替换为 -1
                result.append(-1)
            else:
                # 取 i 右边所有元素的最大值
                result.append(max(arr[i + 1:]))

        return result
```

**说明**：`max(arr[i+1:])` 内部需要扫描右侧所有元素，整体 O(n^2)。数据量大时会超时。

### 方法三：使用后缀最大值数组（变种）

显式构建后缀最大值数组，逻辑更清晰：

```python
from typing import List

class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        n = len(arr)
        # suffix_max[i] 表示 arr[i+1:] 中的最大值
        # 最后一个位置的后缀最大值为 -1
        suffix_max = [-1] * n

        # 从右向左计算后缀最大值
        for i in range(n - 2, -1, -1):
            # arr[i] 右边的最大值 = max(arr[i+1], arr[i+1] 右边的最大值)
            suffix_max[i] = max(arr[i + 1], suffix_max[i + 1])

        # 用后缀最大值替换原数组
        return suffix_max
```

**说明**：方法三与方法一本质相同，只是方法三显式存储了中间结果，空间略多。方法一是方法三的原地优化版本。

## 复杂度分析

### 方法一（推荐）

- **时间复杂度**：O(n)，只需一次从右到左的遍历
- **空间复杂度**：O(1)，原地修改数组，只用了常数级额外空间

### 方法二（暴力）

- **时间复杂度**：O(n^2)，每个元素需要扫描右侧所有元素
- **空间复杂度**：O(n)，存储结果数组

### 方法三（后缀数组）

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，显式存储了后缀最大值数组

## 关键点总结

1. **从右向左遍历**：当问题涉及"右侧最大/最小值"时，优先考虑从右向左扫描
2. **单变量维护后缀信息**：用一个变量 `max_right` 维护右侧最大值，无需额外数组
3. **先替换再更新**：必须先用旧的 `max_right` 替换当前位置，再用当前元素更新 `max_right`，顺序不能颠倒
4. **原地修改**：方法一直接在原数组上操作，空间最优
5. **边界情况**：只有一个元素时，直接返回 `[-1]`，代码自然处理

## 易错点

1. **顺序颠倒**：先更新 `max_right` 再替换 `arr[i]` 是错的，因为 `max_right` 应该是当前位置"右边"的最大值，还不包含当前元素
2. **从左遍历的陷阱**：从左遍历时，替换了 `arr[i]` 之后，当处理 `arr[i-1]` 时，原来的 `arr[i]` 值已经被覆盖，需要备份，逻辑更复杂
3. **最后一个元素**：最后一个元素直接替换为 `-1`，不能用 `max(arr[n:])` 因为空序列的 `max` 会报错
