## 题目描述

有一个立方体房间，其长宽高都等于 `n` 个单位。请你在房间里放 `n` 个盒子，要求每个盒子都要放在**角落**里，且每个盒子要么放在地板上，要么放在另一个盒子的正上方（每个盒子正上方只能放一个盒子）。同时，盒子之间不能悬空（盒子下面有支撑）。

你想把 `n` 个盒子全部放进房间，需要**最少接触地板的盒子数量**是多少？

更正式地说：给定 `n`，求最少需要放在地板上的盒子数（底面积最小化）。

**示例 1：**
```
输入：n = 3
输出：3
```

**示例 2：**
```
输入：n = 10
输出：6
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

**数学规律**：
- 用层数描述：第 1 层放 1 个盒子，第 2 层加 1 行形成 3 个，第 3 层加 1 行形成 6 个...
- 第 `k` 层（三角数层）总盒子数：`1 + 3 + 6 + ... + k*(k+1)/2 = k*(k+1)*(k+2)/6`
- 底面积（接触地板的盒子数）：`1 + 2 + ... + k = k*(k+1)/2`

**算法**：
1. 找最大的 `k` 使得 `k*(k+1)*(k+2)/6 <= n`
2. 剩余 `n - k*(k+1)*(k+2)/6` 个盒子额外放在第 k+1 层的斜面上
3. 这些额外盒子需要额外的底面格子数（1, 2, 3, ... 即三角数序列）

## 代码实现

### 方法一：数学 + 二分查找（推荐）

```python
class Solution:
    def minimumBoxes(self, n: int) -> int:
        # 找最大 k 使得完整 k 层能放下 <= n 个盒子
        # k 层总容量：k*(k+1)*(k+2)//6
        # 二分找最大 k
        
        left, right = 1, 1000  # k 最大约 1000（因为 1000^3/6 ~ 1.67e8 < 1e9）
        while right * (right + 1) * (right + 2) // 6 < n:
            right *= 2
        
        # 二分找最大 k，使 k*(k+1)*(k+2)//6 <= n
        lo, hi = 0, right
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if mid * (mid + 1) * (mid + 2) // 6 <= n:
                lo = mid
            else:
                hi = mid - 1
        
        k = lo
        # k 层的底面积
        base = k * (k + 1) // 2
        # 已放入的盒子数
        placed = k * (k + 1) * (k + 2) // 6
        # 剩余需要放的盒子数
        remaining = n - placed
        
        # 额外行：放 1 个需要 1 个底面格，放 3 个需要 2 个底面格，放 6 个需要 3 个底面格...
        # 即第 j 个额外格能容纳 j*(j+1)//2 个盒子（累积）
        # 找最小 extra 使得 extra*(extra+1)//2 >= remaining
        extra = 0
        while extra * (extra + 1) // 2 < remaining:
            extra += 1
        
        return base + extra
```

### 方法二：直接循环（无二分）

```python
class Solution:
    def minimumBoxes(self, n: int) -> int:
        # 逐层计算
        total = 0   # 已放盒子总数
        base = 0    # 当前底面积
        k = 0       # 当前层数
        
        # 找完整层数
        while total + (k + 1) * (k + 2) // 2 <= n:
            k += 1
            base += k
            total += k * (k + 1) // 2
        
        # 处理剩余
        remaining = n - total
        extra = 0
        while remaining > 0:
            extra += 1
            remaining -= extra
        
        return base + extra
```

## 复杂度分析

- **方法一**：O(log n)，二分查找
- **方法二**：O(n^(1/3))，循环次数约为 n^(1/3)

## 关键点总结

1. 三角数规律：第 k 层完整堆放的总容量是 `k*(k+1)*(k+2)/6`
2. 先找最大完整层数，再处理剩余盒子
3. 剩余盒子每增加 `j` 个底面格，可多放 `j` 个盒子

## 易错点

- 注意整除和边界处理
- `remaining` 为 0 时不需要额外底面格
