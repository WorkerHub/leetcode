## 题目描述

给你二叉搜索树的根节点 `root`，该树中的 **恰好** 两个节点的值被错误地交换。请在不改变其结构的情况下，恢复这棵树。

**示例 1：**

```
输入：root = [1,3,null,null,2]
输出：[3,1,null,null,2]
解释：3 不能是 1 的左孩子，因为 3 > 1。交换 1 和 3 使二叉搜索树有效。
```

**示例 2：**

```
输入：root = [3,1,4,null,null,2]
输出：[2,1,4,null,null,3]
解释：2 不能在 3 的右子树中，因为 2 < 3。交换 2 和 3 使二叉搜索树有效。
```

**提示：**

- 树上节点的数目在范围 `[2, 1000]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

**进阶：** 使用 O(n) 空间复杂度的解法很容易实现。你能想出一个只使用 O(1) 空间的解决方案吗？

## 解题思路

这道题建立在第 98 题（验证 BST）的基础上，需要利用 BST 的中序遍历性质。

**核心思想：**

1. **BST 性质：** 正确的 BST 中序遍历结果是严格递增序列
2. **错误特征：** 如果两个节点被交换，中序遍历会出现逆序对（前一个数大于后一个数）
3. **交换情况分析：**
   - **相邻交换：** 只有一个逆序对，如 `[1,3,2,4]`（交换了 3 和 2）
   - **不相邻交换：** 有两个逆序对，如 `[1,4,3,2,5]`（交换了 4 和 2）

**算法流程：**

1. 进行中序遍历，找到所有逆序对
2. 记录第一个逆序对的第一个节点（较大的）
3. 记录最后一个逆序对的第二个节点（较小的）
4. 交换这两个节点的值

**示例演示：**

- **相邻交换：** `[1, 3, 2, 4]` 
  - 逆序对：3 > 2
  - 需要交换：3 和 2

- **不相邻交换：** `[1, 4, 3, 2, 5]`
  - 第一个逆序对：4 > 3（记录 4）
  - 第二个逆序对：3 > 2（记录 2）
  - 需要交换：4 和 2

## Python 代码实现

### 方法一：递归中序遍历（推荐）

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def recoverTree(self, root: TreeNode) -> None:
        """
        递归中序遍历法：找到被交换的两个节点并交换回来
        不要返回，直接修改 root 节点
        """
        self.first = None   # 第一个错误节点（第一个逆序对的较大值）
        self.second = None  # 第二个错误节点（最后一个逆序对的较小值）
        self.prev = None    # 中序遍历的前一个节点
        
        # 中序遍历找到错误节点
        self.inorder(root)
        
        # 交换两个错误节点的值
        if self.first and self.second:
            self.first.val, self.second.val = self.second.val, self.first.val
    
    def inorder(self, node: TreeNode) -> None:
        """中序遍历，找到被交换的节点"""
        if not node:
            return
        
        # 遍历左子树
        self.inorder(node.left)
        
        # 检查当前节点
        if self.prev and self.prev.val > node.val:
            # 发现逆序对
            if not self.first:
                # 第一个逆序对：记录较大的节点
                self.first = self.prev
            # 无论是第一个还是第二个逆序对，都更新 second
            # 这样可以处理相邻和不相邻两种情况
            self.second = node
        
        # 更新 prev
        self.prev = node
        
        # 遍历右子树
        self.inorder(node.right)
```

### 方法二：迭代中序遍历

```python
class Solution:
    def recoverTree(self, root: TreeNode) -> None:
        """
        迭代中序遍历：使用栈模拟递归
        """
        stack = []
        first = second = prev = None
        current = root
        
        while stack or current:
            # 一直向左走
            while current:
                stack.append(current)
                current = current.left
            
            # 处理当前节点
            current = stack.pop()
            
            # 检查是否出现逆序
            if prev and prev.val > current.val:
                if not first:
                    first = prev
                second = current
            
            prev = current
            current = current.right
        
        # 交换节点值
        if first and second:
            first.val, second.val = second.val, first.val
```

### 方法三：Morris 中序遍历（O(1) 空间，进阶）

```python
class Solution:
    def recoverTree(self, root: TreeNode) -> None:
        """
        Morris 遍历：O(1) 空间复杂度
        通过修改树的结构（线索二叉树）来实现无栈的中序遍历
        """
        first = second = prev = None
        current = root
        
        while current:
            if not current.left:
                # 没有左子树，直接处理当前节点
                if prev and prev.val > current.val:
                    if not first:
                        first = prev
                    second = current
                prev = current
                current = current.right
            else:
                # 有左子树，找到前驱节点
                predecessor = current.left
                while predecessor.right and predecessor.right != current:
                    predecessor = predecessor.right
                
                if not predecessor.right:
                    # 建立线索
                    predecessor.right = current
                    current = current.left
                else:
                    # 已经建立过线索，说明左子树已遍历完
                    # 处理当前节点
                    if prev and prev.val > current.val:
                        if not first:
                            first = prev
                        second = current
                    prev = current
                    
                    # 恢复树的结构
                    predecessor.right = None
                    current = current.right
        
        # 交换节点值
        if first and second:
            first.val, second.val = second.val, first.val
```

### 方法四：数组法（最直观，适合初学者）

```python
class Solution:
    def recoverTree(self, root: TreeNode) -> None:
        """
        数组法：先中序遍历存储节点，找到错误节点后交换
        """
        # 存储中序遍历的节点（不是值，是节点引用）
        nodes = []
        
        def inorder(node: TreeNode) -> None:
            if not node:
                return
            inorder(node.left)
            nodes.append(node)
            inorder(node.right)
        
        # 获取中序遍历结果
        inorder(root)
        
        # 找到被交换的两个节点
        first = second = None
        for i in range(len(nodes) - 1):
            if nodes[i].val > nodes[i + 1].val:
                if not first:
                    first = nodes[i]
                second = nodes[i + 1]
        
        # 交换节点值
        if first and second:
            first.val, second.val = second.val, first.val
```

## 复杂度分析

**方法一、二、四：**

- **时间复杂度：** O(n)，n 是树中节点数量，需要遍历所有节点
- **空间复杂度：**
  - 方法一、二：O(h)，递归栈或迭代栈的空间，h 是树高
  - 方法四：O(n)，需要额外数组存储所有节点

**方法三（Morris）：**

- **时间复杂度：** O(n)，虽然有嵌套循环，但每条边最多访问 2 次
- **空间复杂度：** O(1)，只使用常量级别的额外空间

## 关键点总结

1. **中序遍历是关键：** BST 的中序遍历是递增序列，被交换的节点会破坏这个性质
2. **逆序对识别：** 
   - 相邻交换：1 个逆序对
   - 不相邻交换：2 个逆序对
3. **节点记录策略：**
   - `first`：第一个逆序对的较大节点
   - `second`：持续更新为逆序对的较小节点（最后一次更新的值）
4. **交换的是值而非节点：** 题目要求不改变树的结构，所以交换节点的 `val` 而不是节点引用
5. **Morris 遍历：** 通过临时修改树结构实现 O(1) 空间，是进阶技巧

## 易错点

1. **记录节点而非值：**
   ```python
   # 错误：只记录值
   first_val = prev.val  # 无法后续交换
   
   # 正确：记录节点引用
   first = prev  # 可以通过 first.val 交换
   ```

2. **second 的更新策略：**
   ```python
   # 错误：只在第二个逆序对时更新
   if self.first and self.prev.val > node.val:
       self.second = node  # 相邻交换时会丢失
   
   # 正确：每次逆序都更新 second
   if self.prev.val > node.val:
       if not self.first:
           self.first = self.prev
       self.second = node  # 相邻和不相邻都能处理
   ```

3. **忘记交换：**
   - 找到节点后必须交换值，不能只是记录

4. **Morris 遍历恢复结构：**
   ```python
   # 必须恢复树的原始结构
   predecessor.right = None  # 断开临时建立的线索
   ```

5. **边界条件：**
   - 确保 `first` 和 `second` 都不为 `None` 才交换
