## 题目描述

给你三个整数 `n`、`m` 和 `k`。

构造一个长度为 `n` 的数组，每个元素在 `[1, m]` 之间，且数组中**相邻元素之积为偶数的对数**恰好为 `k`。

返回满足条件的数组数量，对 `10^9 + 7` 取模。

**提示：**
- `1 <= n <= 10^5`
- `1 <= m <= 10^5`
- `0 <= k <= n-1`

## 解题思路

**分析相邻对的奇偶性：**

两个数的乘积为偶数当且仅当至少一个为偶数，即两个都为奇数时乘积才为奇数。

因此：
- 相邻元素乘积为偶数 <=> 至少一个为偶数
- 相邻元素乘积为奇数 <=> 两个都为奇数

长度为 `n` 的数组中，相邻对共 `n-1` 对。

设奇数元素有 `p` 个（选在哪些位置），则奇数对（相邻都奇数）的数量取决于奇数的分布。

**等价转化：** 设数组中相邻奇数对有 `n-1-k` 对（偶数对有 `k` 对）。即需要 `n-1-k` 个"相邻奇数对"。

**DP 方法：**

`dp[i][j]` = 处理完前 `i` 个元素，有 `j` 个相邻元素乘积为奇数（即 j 个相邻奇数对），最后一个元素的奇偶性。

设 `odd = (m+1)//2`（奇数个数），`even = m//2`（偶数个数）。

状态：`dp[i][j][0/1]`（0=最后偶数，1=最后奇数），但可以简化。

实际上：
- 奇数对的数量等于连续奇数段的（长度-1）之和。
- 若奇数在数组中形成长度为 `l_1, l_2, ...` 的连续段，则奇数对数量 = sum(l_i - 1) = (奇数总数) - (奇数段数)。

换言之：若有 `p` 个奇数，形成了 `c` 个连续段，则奇数对数 = `p - c`，偶数对数 = `(n-1) - (p-c) = n-1-p+c`。需要偶数对数 = k，即 `p - c = n - 1 - k`。

这个问题相当于：选 `p` 个位置放奇数（其余放偶数），形成 `c` 个连续段，满足 `p - c = n - 1 - k`，计算方案数。

令 `q = n-1-k`（需要的奇数对数），需要 `p - c = q`，即 `c = p - q`。

对固定的 `p` 和 `c`：
- 将 `p` 个奇数放入 `c` 个连续段，等价于将 `p` 个奇数分成 `c` 组（每组至少 1 个），有 `C(p-1, c-1)` 种方案（隔板法）。
- 将 `c` 个连续奇数段嵌入 `n` 个位置（非连续地），等价于在 `n - p` 个偶数位置中插入 `c` 个奇数段，方案数 = `C(n-p+1, c)`（其中 `n-p+1` 是偶数"间隙"数包括两端）... 

实际上这个组合计数比较复杂，直接用 DP 更简单。

**简单 DP：**

`dp[i][last_odd]` = 处理完前 `i` 个元素，有 `j` 个偶数对，最后元素是否为奇数。

由于状态包含 j，用 `dp[i][j][0/1]`，i 可以用滚动数组。

`dp[j][0]` = j 个偶数对，最后元素为偶数
`dp[j][1]` = j 个偶数对，最后元素为奇数

## Python 代码实现

### 方法一：动态规划

```python
class Solution:
    def countOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7
        odd = (m + 1) // 2   # 1..m 中奇数个数
        even = m // 2         # 1..m 中偶数个数
        
        # dp[j][parity] = 处理了若干元素，已有 j 个偶数对，最后元素奇偶性
        # parity: 0=偶数, 1=奇数
        # k <= n-1
        
        if k > n - 1:
            return 0
        
        # dp[j][p]：j 个偶数乘积对数，最后元素奇偶性 p
        dp = [[0, 0] for _ in range(k + 1)]
        # 初始（第一个元素）
        dp[0][0] = even  # 第一个元素为偶数，0 对
        dp[0][1] = odd   # 第一个元素为奇数，0 对
        
        for i in range(1, n):
            new_dp = [[0, 0] for _ in range(k + 1)]
            for j in range(k + 1):
                # 前 i 个元素，j 个偶数对，最后是偶数或奇数
                # 加入偶数
                # 当前最后是偶数，前一个是偶数 -> 偶数对 +1
                if j >= 1:
                    new_dp[j][0] = (new_dp[j][0] + dp[j-1][0] * even) % MOD
                # 当前最后是偶数，前一个是奇数 -> 偶数对 +1
                if j >= 1:
                    new_dp[j][0] = (new_dp[j][0] + dp[j-1][1] * even) % MOD
                # 加入奇数
                # 当前最后是奇数，前一个是偶数 -> 偶数对 +1
                if j >= 1:
                    new_dp[j][1] = (new_dp[j][1] + dp[j-1][0] * odd) % MOD
                # 当前最后是奇数，前一个是奇数 -> 偶数对不变（两奇数乘积为奇数）
                new_dp[j][1] = (new_dp[j][1] + dp[j][1] * odd) % MOD
            dp = new_dp
        
        return (dp[k][0] + dp[k][1]) % MOD
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 两数乘积为偶数当且仅当至少一个为偶数；两奇数乘积才为奇数。
2. DP 状态：当前偶数对数量 + 最后元素奇偶性。
3. 转移时，加入新元素会影响偶数对数量（若前一个为奇数且当前为奇数，不增加偶数对；其余情况增加 1）。

## 易错点

1. 两个相邻元素的乘积为偶数（+1 偶数对）的条件：至少一个为偶数，即"前偶后任意"或"前奇后偶"。
2. "前奇后奇"不增加偶数对。
3. 偶数对数量的范围是 0 到 k，初始化和转移时注意边界。
