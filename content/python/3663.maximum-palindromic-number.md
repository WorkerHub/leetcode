## 题目描述

给你一个整数 `n`，用其各位数字（每个数字最多使用一次）构造最大的回文数，返回该回文数。若无法构造，返回 -1。

**示例 1：**

```
输入：n = 1234567891234
输出：9318813
解释：使用数字1,2,3,4,5,6,7,8,9,1,2,3,4，构造最大回文数
```

**示例 2：**

```
输入：n = 1
输出：1
```

**提示：**

- `1 <= n <= 10^18`

## 解题思路

贪心：

1. 统计 n 各位数字的出现次数
2. 对每个数字，成对使用（放在回文数的两端）
3. 剩余出现次数为奇数的数字中，选最大的放在中间
4. 从大到小构造回文

## Python 代码实现

### 方法一：贪心构造（推荐）

```python
class Solution:
    def maximumPalindrome(self, n: int) -> int:
        from collections import Counter
        freq = Counter(str(n))

        half = []
        middle = -1  # 放在中间的数字

        for d in range(9, -1, -1):
            c = freq.get(str(d), 0)
            pairs = c // 2
            half.extend([str(d)] * pairs)
            if c % 2 == 1 and (middle == -1 or d > middle):
                middle = d

        if not half and middle == -1:
            return -1

        half_str = ''.join(half)
        mid_str = str(middle) if middle != -1 else ''
        palindrome = half_str + mid_str + half_str[::-1]

        return int(palindrome) if palindrome else -1
```

### 方法二：字符频率计算

```python
class Solution:
    def maximumPalindrome(self, n: int) -> int:
        digits = sorted(str(n), reverse=True)
        from collections import Counter
        freq = Counter(digits)

        left_part = []
        middle = ''

        for d in '9876543210':
            count = freq[d]
            if count >= 2:
                left_part.append(d * (count // 2))
            if count % 2 == 1 and not middle:
                middle = d

        left = ''.join(left_part)
        result = left + middle + left[::-1]

        return int(result) if result else -1
```

## 复杂度分析

- 时间复杂度：O(log n)，n 的位数
- 空间复杂度：O(log n)

## 关键点总结

1. 成对数字放两端，奇数出现时取最大的放中间
2. 从大到小贪心，确保构造最大的回文
3. 前半部分反转即为后半部分

## 易错点

1. 前导零问题：0 可以作为中间或末尾，不能在最高位
2. 若所有数字只出现一次，只能用一个数字构成单位回文
3. 中间数字只能有一个（最大的奇数出现次数的数字）
