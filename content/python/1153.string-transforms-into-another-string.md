## 题目描述

给定两个长度相同的字符串 `str1` 和 `str2`,判断是否可以通过若干次转换将 `str1` 转换为 `str2`。

在一次转换中,你可以将 `str1` 中所有出现的某个字符转换为任何其他小写字母。

如果可以将 `str1` 转换为 `str2`,返回 `true`,否则返回 `false`。

**示例 1:**

```
输入: str1 = "aabcc", str2 = "ccdee"
输出: true
解释: 
先将 'c' 转换为 'e',得到 "aabee"
然后将 'b' 转换为 'd',得到 "aadee"
最后将 'a' 转换为 'c',得到 "ccdee"
```

**示例 2:**

```
输入: str1 = "leetcode", str2 = "codeleet"
输出: false
解释: 无法进行转换
```

**提示:**
- `1 <= str1.length == str2.length <= 10^4`
- `str1` 和 `str2` 只包含小写字母

## 解题思路

这道题的核心在于理解字符映射关系和循环依赖:

**关键观察 1: 映射一致性**
- 如果 `str1[i]` 和 `str1[j]` 是相同字符,那么 `str2[i]` 和 `str2[j]` 也必须相同
- 即: 同一个字符只能映射到一个目标字符

**关键观察 2: 循环依赖问题**
- 考虑 `str1 = "ab"`, `str2 = "ba"`
- `a -> b`, `b -> a` 形成循环
- 需要一个临时字符来打破循环,但如果所有26个字母都被使用,就无法转换

**关键观察 3: 特殊情况**
- 如果 `str1 == str2`,直接返回 `true`
- 如果 `str2` 使用了全部26个字母,且 `str1 != str2`,则无法转换(没有临时字符)

**解法步骤:**
1. 建立 `str1` 到 `str2` 的字符映射关系
2. 检查映射是否一致(一对一或多对一)
3. 检查是否存在循环且 `str2` 使用了全部26个字母

## Python 代码实现

### 方法一: 哈希表映射(推荐)

```python
class Solution:
    def canConvert(self, str1: str, str2: str) -> bool:
        """
        使用哈希表检查字符映射关系
        """
        # 特殊情况: 两个字符串相同
        if str1 == str2:
            return True
        
        # 建立 str1 到 str2 的映射
        mapping = {}
        
        for c1, c2 in zip(str1, str2):
            # 检查映射一致性
            if c1 in mapping:
                if mapping[c1] != c2:
                    # 同一个字符映射到不同字符,无法转换
                    return False
            else:
                mapping[c1] = c2
        
        # 检查 str2 中不同字符的个数
        # 如果 str2 使用了全部 26 个字母,且 str1 != str2
        # 则无法找到临时字符来打破可能的循环
        if len(set(str2)) == 26:
            return False
        
        return True
```

### 方法二: 详细注释版

```python
class Solution:
    def canConvert(self, str1: str, str2: str) -> bool:
        """
        详细解释版本
        """
        # Case 1: 如果两个字符串完全相同,不需要任何转换
        if str1 == str2:
            return True
        
        # Case 2: 建立映射关系并检查一致性
        char_map = {}
        
        for i in range(len(str1)):
            c1, c2 = str1[i], str2[i]
            
            if c1 in char_map:
                # 如果 c1 已经有映射,检查是否一致
                if char_map[c1] != c2:
                    # str1 中的同一个字符对应 str2 中的不同字符
                    # 这是不可能的,返回 False
                    return False
            else:
                # 建立新的映射关系
                char_map[c1] = c2
        
        # Case 3: 检查是否有足够的临时字符
        # 如果 str2 使用了全部 26 个字母
        # 那么没有临时字符可用来打破循环
        # 例如: str1 = "ab", str2 = "ba"
        # 我们需要: a -> temp, b -> a, temp -> b
        # 但如果 str2 已经使用了所有字母,就没有 temp 可用
        unique_chars_in_str2 = len(set(str2))
        
        if unique_chars_in_str2 == 26:
            # str2 使用了全部 26 个字母,无法转换
            return False
        
        return True
```

### 方法三: 使用集合优化

```python
class Solution:
    def canConvert(self, str1: str, str2: str) -> bool:
        """
        使用集合优化检查
        """
        if str1 == str2:
            return True
        
        # 建立映射字典
        transform = {}
        for c1, c2 in zip(str1, str2):
            if transform.setdefault(c1, c2) != c2:
                return False
        
        # 检查 str2 的不同字符数
        return len(set(str2)) < 26
```

## 复杂度分析

**时间复杂度**: O(n)
- n 为字符串长度
- 需要遍历字符串一次建立映射
- `set(str2)` 的时间复杂度为 O(n)

**空间复杂度**: O(1)
- 映射字典最多存储 26 个字符
- `set(str2)` 最多包含 26 个字符
- 都是常数级别空间

```
str1 = "leetcode"

映射关系:

str1 = "ab"
str2 = "ba"

映射关系:

可以用临时字符 c: a->c, b->a, c->b
```

**示例 4: 循环且不能转换**
```
如果 str2 使用了全部 26 个字母
且存在循环,则无法找到临时字符
无法转换
```

## 关键点总结

1. 字符映射必须一致: 一个字符只能映射到一个目标字符
2. 如果 `str1 == str2`,直接返回 `true`
3. 如果 `str2` 使用了全部 26 个字母,且 `str1 != str2`,返回 `false`
4. 检查映射冲突: 同一字符映射到不同字符
5. 临时字符的作用: 打破循环依赖

## 易错点

1. 忘记检查 `str1 == str2` 的特殊情况
2. 没有理解为什么 `str2` 使用全部26个字母时无法转换
3. 混淆映射方向,应该是 `str1 -> str2`
4. 忘记检查映射一致性
5. 认为循环依赖总是无法解决(实际上有临时字符时可以解决)
