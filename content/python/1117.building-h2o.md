## 题目描述

现在有两种线程，氧 `oxygen` 和氢 `hydrogen`，你的目标是组织这两种线程来产生水分子。

存在一个屏障（barrier）使得每个线程必须等候直到一个完整的水分子能够被产生出来。

氢和氧线程会被分别给予 `releaseHydrogen` 和 `releaseOxygen` 方法来允许它们突破屏障。

这些线程应该三三成组突破屏障并能够组成一个水分子。你必须保证产生一个氧分子的前后，有两个氢分子被产生出来。

我们不要求线程能够知道将要组成的分子是谁。

线程将会从输入字符串中的不同位置被传入，从而产生分子 `H2O`。

**示例 1:**

```
输入: water = "HOH"
输出: "HHO"
解释: "HOH" 和 "OHH" 也是可接受的答案。
```

**示例 2:**

```
输入: water = "OOHHHH"
输出: "HHOHHO"
解释: "HOHHHO", "OHHHHO", "HHOHOH", "HOHHOH", "OHHHOH", "HHOOHH", "HOHOHH" 和 "OHHOHH" 也是可接受的答案。
```

**提示:**

- `3 * n == water.length`
- `1 <= n <= 20`
- `water[i] == 'O' | 'H'`
- 输入字符串 `water` 中的 'H' 总数将会是 `2 * n` 。
- 输入字符串 `water` 中的 'O' 总数将会是 `n` 。

## 解题思路

这是一个经典的线程同步问题，核心思想是：
1. 需要保证每次释放的氧氢比例是 1:2
2. 使用信号量或锁来控制线程的执行顺序
3. 确保每次恰好有 2 个氢线程和 1 个氧线程组成一个水分子

关键观察：
- 氢原子需要等待：如果已经有 2 个氢原子在等待，后续的氢原子应该阻塞
- 氧原子需要等待：直到有 2 个氢原子准备好
- 每产生一个完整的 H2O 后，重置计数器

## Python 代码实现

### 方法一：使用信号量（推荐）

```python
from threading import Semaphore

class H2O:
    def __init__(self):
        # 氢信号量，初始值为2，表示可以同时有2个氢线程通过
        self.h_sem = Semaphore(2)
        # 氧信号量，初始值为0，表示初始时氧线程需要等待
        self.o_sem = Semaphore(0)
        # 用于确保一个完整水分子产生后才能开始下一个
        self.barrier = Semaphore(0)
        
    def hydrogen(self, releaseHydrogen: 'Callable[[], None]') -> None:
        # 获取氢信号量（最多2个氢可以同时进入）
        self.h_sem.acquire()
        
        # releaseHydrogen() 输出 "H"
        releaseHydrogen()
        
        # 释放氧信号量，告诉氧线程已经有一个氢准备好了
        self.o_sem.release()
        
        # 等待整个水分子构建完成
        self.barrier.acquire()
        
    def oxygen(self, releaseOxygen: 'Callable[[], None]') -> None:
        # 等待2个氢原子准备好（需要获取2次氧信号量）
        self.o_sem.acquire()
        self.o_sem.acquire()
        
        # releaseOxygen() 输出 "O"
        releaseOxygen()
        
        # 释放屏障，让2个氢线程继续
        self.barrier.release()
        self.barrier.release()
        
        # 释放氢信号量，允许下一组氢原子进入
        self.h_sem.release()
        self.h_sem.release()
```

### 方法二：使用锁和条件变量

```python
from threading import Lock, Condition

class H2O:
    def __init__(self):
        self.h_count = 0  # 当前等待的氢原子数量
        self.o_count = 0  # 当前等待的氧原子数量
        self.lock = Lock()
        self.h_cond = Condition(self.lock)  # 氢原子的条件变量
        self.o_cond = Condition(self.lock)  # 氧原子的条件变量
        
    def hydrogen(self, releaseHydrogen: 'Callable[[], None]') -> None:
        with self.lock:
            # 等待直到可以释放氢（当前氢原子数小于2）
            while self.h_count >= 2:
                self.h_cond.wait()
            
            self.h_count += 1
            releaseHydrogen()
            
            # 如果凑够了2个氢和1个氧，通知氧线程
            if self.h_count == 2 and self.o_count == 1:
                # 重置计数器
                self.h_count = 0
                self.o_count = 0
                # 唤醒等待的氢和氧线程
                self.h_cond.notify_all()
                self.o_cond.notify()
            
    def oxygen(self, releaseOxygen: 'Callable[[], None]') -> None:
        with self.lock:
            # 等待直到有2个氢原子准备好
            while self.h_count < 2 or self.o_count >= 1:
                self.o_cond.wait()
            
            self.o_count += 1
            releaseOxygen()
            
            # 如果凑够了2个氢和1个氧，重置并唤醒
            if self.h_count == 2 and self.o_count == 1:
                self.h_count = 0
                self.o_count = 0
                self.h_cond.notify_all()
                self.o_cond.notify()
```

## 复杂度分析

**方法一（信号量）：**
- 时间复杂度：O(n)，其中 n 是水分子的数量，每个线程只执行一次
- 空间复杂度：O(1)，只使用常数个信号量

**方法二（锁和条件变量）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **信号量的使用**：氢信号量控制最多2个氢原子进入，氧信号量用于氢原子通知氧原子
2. **屏障机制**：确保一个完整的水分子产生后才能开始下一个循环
3. **同步顺序**：2个氢 → 1个氧 → 释放屏障 → 下一轮
4. **线程安全**：使用信号量或锁保证线程间的正确同步

## 易错点

1. **信号量初始值设置错误**：氢信号量应为2，氧信号量应为0
2. **忘记释放信号量**：每个 acquire 必须对应一个 release，否则会死锁
3. **屏障释放次数错误**：必须释放2次屏障（对应2个氢线程）
4. **条件变量使用不当**：在使用条件变量时必须持有对应的锁
