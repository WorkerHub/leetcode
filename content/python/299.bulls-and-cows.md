## 题目描述

你在和朋友一起玩猜数字（Bulls and Cows）游戏，游戏规则如下：

写出一个秘密数字，并请朋友猜这个数字是多少。朋友每猜测一次，你就会给他一个包含下述信息的提示：

- 猜测数字中有多少位属于数字和确切位置都猜对了（称为 "Bulls"，公牛）
- 有多少位属于数字猜对了但是位置不对（称为 "Cows"，奶牛）

也就是说，这次猜测中有多少位非公牛数字可以通过重新排列转换成公牛数字。

给你一个秘密数字 secret 和朋友猜测的数字 guess，请你返回对朋友这次猜测的提示。

提示的格式为 "xAyB"，x 是公牛个数，y 是奶牛个数，A 表示公牛，B 表示奶牛。

**示例 1：**
```
输入：secret = "1807", guess = "7810"
输出："1A3B"
解释：数字和位置都对（公牛）用 '|' 连接，数字猜对位置不对（奶牛）用 ' ' 标出。
"1807"
  |
"7810"
```

**示例 2：**
```
输入：secret = "1123", guess = "0111"
输出："1A1B"
解释：朋友猜测数中的第一个 1 是公牛，第二个或第三个 1 可被视为奶牛。
```

**提示：**
- 1 <= secret.length, guess.length <= 1000
- secret.length == guess.length
- secret 和 guess 仅由数字组成

## 解题思路

这道题是经典的字符串匹配问题，关键在于区分 Bulls 和 Cows。

**核心思路：**
1. **Bulls（公牛）**：位置和数字都相同
2. **Cows（奶牛）**：数字相同但位置不同

**算法步骤：**
1. 第一遍遍历：找出所有 Bulls（位置和数字都匹配）
2. 第二遍遍历：对于不是 Bulls 的位置，统计 Cows
   - 记录 secret 中每个数字的出现次数
   - 记录 guess 中每个数字的出现次数
   - Cows = min(secret中的次数, guess中的次数)

**优化方向：**
- 一次遍历完成
- 使用数组代替哈希表（数字只有 0-9）

## Python 代码实现

### 方法一：两次遍历（推荐，最清晰）

```python
class Solution:
    def getHint(self, secret: str, guess: str) -> str:
        """
        两次遍历，逻辑清晰
        时间复杂度：O(n)
        空间复杂度：O(1)（数字只有 0-9，固定空间）
        """
        bulls = 0
        secret_counts = [0] * 10  # 0-9 的计数
        guess_counts = [0] * 10
        
        # 第一遍：统计 Bulls 和剩余数字的频率
        for i in range(len(secret)):
            if secret[i] == guess[i]:
                bulls += 1
            else:
                # 不是 Bull 的位置，记录频率
                secret_counts[int(secret[i])] += 1
                guess_counts[int(guess[i])] += 1
        
        # 第二遍：统计 Cows
        cows = 0
        for i in range(10):
            # 对于每个数字，取 secret 和 guess 中较小的出现次数
            cows += min(secret_counts[i], guess_counts[i])
        
        return f"{bulls}A{cows}B"
```

### 方法二：一次遍历

```python
class Solution:
    def getHint(self, secret: str, guess: str) -> str:
        """
        一次遍历完成
        """
        bulls = cows = 0
        secret_counts = [0] * 10
        guess_counts = [0] * 10
        
        for i in range(len(secret)):
            s = int(secret[i])
            g = int(guess[i])
            
            if s == g:
                bulls += 1
            else:
                # 检查之前 guess 中是否有当前 secret 的数字
                if secret_counts[g] > 0:
                    cows += 1
                    secret_counts[g] -= 1
                else:
                    guess_counts[g] += 1
                
                # 检查之前 secret 中是否有当前 guess 的数字
                if guess_counts[s] > 0:
                    cows += 1
                    guess_counts[s] -= 1
                else:
                    secret_counts[s] += 1
        
        return f"{bulls}A{cows}B"
```

### 方法三：使用哈希表

```python
from collections import Counter

class Solution:
    def getHint(self, secret: str, guess: str) -> str:
        """
        使用 Counter 简化计数
        """
        bulls = 0
        secret_chars = []
        guess_chars = []
        
        # 第一遍：找 Bulls，记录非 Bull 的字符
        for i in range(len(secret)):
            if secret[i] == guess[i]:
                bulls += 1
            else:
                secret_chars.append(secret[i])
                guess_chars.append(guess[i])
        
        # 统计 Cows
        secret_counter = Counter(secret_chars)
        guess_counter = Counter(guess_chars)
        
        cows = 0
        for digit in guess_counter:
            if digit in secret_counter:
                cows += min(secret_counter[digit], guess_counter[digit])
        
        return f"{bulls}A{cows}B"
```

### 方法四：简洁版

```python
class Solution:
    def getHint(self, secret: str, guess: str) -> str:
        """
        Python 简洁写法
        """
        bulls = sum(s == g for s, g in zip(secret, guess))
        
        # 统计所有匹配的数字（包括位置匹配和不匹配）
        secret_counts = [0] * 10
        guess_counts = [0] * 10
        
        for s, g in zip(secret, guess):
            secret_counts[int(s)] += 1
            guess_counts[int(g)] += 1
        
        # 总匹配数 - Bulls = Cows
        total_matches = sum(min(secret_counts[i], guess_counts[i]) for i in range(10))
        cows = total_matches - bulls
        
        return f"{bulls}A{cows}B"
```

### 方法五：一次遍历优化版

```python
class Solution:
    def getHint(self, secret: str, guess: str) -> str:
        """
        一次遍历，使用单个数组优化
        """
        bulls = cows = 0
        counts = [0] * 10  # secret 为正，guess 为负
        
        for i in range(len(secret)):
            s = int(secret[i])
            g = int(guess[i])
            
            if s == g:
                bulls += 1
            else:
                # secret[i] 之前在 guess 中出现过（counts[s] < 0）
                if counts[s] < 0:
                    cows += 1
                counts[s] += 1
                
                # guess[i] 之前在 secret 中出现过（counts[g] > 0）
                if counts[g] > 0:
                    cows += 1
                counts[g] -= 1
        
        return f"{bulls}A{cows}B"
```

## 复杂度分析

### 所有方法：

**时间复杂度：** O(n)
- n 是字符串长度
- 遍历字符串一次或两次
- 统计数字频率：O(10) = O(1)

**空间复杂度：** O(1)
- 数字只有 0-9，固定空间
- 数组大小为 10，常量空间

```
第一步：找 Bulls（位置和数字都匹配）
位置：  0  1  2  3
secret: 1  8  0  7
guess:  7  8  1  0
匹配：     ✓        
Bulls = 1（位置 1 的 '8'）

第二步：统计剩余数字的频率
非 Bull 位置：
secret: 1  0  7  → 计数：1:1, 0:1, 7:1
guess:  7  1  0  → 计数：7:1, 1:1, 0:1

第三步：计算 Cows
数字 1: min(1, 1) = 1
数字 0: min(1, 1) = 1
数字 7: min(1, 1) = 1
Cows = 1 + 1 + 1 = 3

结果："1A3B"
```

示例 2：`secret = "1123", guess = "0111"`

```
第一步：找 Bulls
位置：  0  1  2  3
secret: 1  1  2  3
guess:  0  1  1  1
匹配：     ✓        
Bulls = 1（位置 1 的 '1'）

第二步：统计剩余数字的频率
非 Bull 位置：
secret: 1  2  3  → 计数：1:1, 2:1, 3:1
guess:  0  1  1  → 计数：0:1, 1:2

第三步：计算 Cows
数字 1: min(1, 2) = 1

数字 3: min(1, 0) = 0

```

## 关键点总结

1. **Bulls 优先**：先统计位置和数字都匹配的 Bulls
2. **Cows 计算**：对于非 Bulls 的位置，统计数字出现次数的最小值
3. **不重复计数**：Bulls 的位置不参与 Cows 的计算
4. **固定空间**：数字只有 0-9，使用数组比哈希表更高效
5. **一次遍历优化**：可以在一次遍历中同时计算 Bulls 和 Cows

## 易错点

1. **Bulls 和 Cows 重复计算**
   ```python
   # 错误：Bulls 位置也参与 Cows 计算
   for i in range(len(secret)):
       secret_counts[int(secret[i])] += 1
       guess_counts[int(guess[i])] += 1
   # 这样会把 Bulls 也算进去
   
   # 正确：只统计非 Bulls 位置
   if secret[i] == guess[i]:
       bulls += 1
   else:
       secret_counts[int(secret[i])] += 1
       guess_counts[int(guess[i])] += 1
   ```

2. **Cows 计算错误**
   ```python
   # 错误：直接相加
   cows = sum(secret_counts[i] + guess_counts[i] for i in range(10))
   
   # 正确：取最小值
   cows = sum(min(secret_counts[i], guess_counts[i]) for i in range(10))
   ```

3. **字符串格式错误**
   ```python
   # 错误：拼接顺序或格式错误
   return f"{cows}B{bulls}A"  # 顺序反了
   return f"{bulls} A {cows} B"  # 有多余空格
   
   # 正确：xAyB 格式
   return f"{bulls}A{cows}B"
   ```

4. **索引类型错误**
   ```python
   # 错误：忘记转换为整数
   secret_counts[secret[i]] += 1  # secret[i] 是字符串
   
   # 正确：转换为整数
   secret_counts[int(secret[i])] += 1
   ```

5. **一次遍历时的逻辑错误**
   ```python
   # 错误：顺序不对，可能重复计数
   if counts[s] < 0:
       cows += 1
   counts[s] += 1
   counts[g] -= 1
   if counts[g] > 0:
       cows += 1
   # counts[g] 已经被修改，判断不正确
   
   # 正确：先判断再修改
   if counts[s] < 0:
       cows += 1
   counts[s] += 1
   if counts[g] > 0:
       cows += 1
   counts[g] -= 1
   ```
