## 题目描述

给定一个字符串 `s`，返回其通过重新排列组合后所有可能的回文字符串，并去除重复的组合。

如果不能形成任何回文排列，则返回一个空列表。

**示例 1：**
```
输入: s = "aabb"
输出: ["abba", "baab"]
```

**示例 2：**
```
输入: s = "abc"
输出: []
```

**提示：**
- `1 <= s.length <= 16`
- `s` 只包含小写英文字母

## 解题思路

这道题是"回文排列 I"的进阶版，不仅要判断能否组成回文，还要生成所有可能的回文排列。

**关键观察：**
1. 回文串的特点：左半部分 + 中心字符（可选）+ 右半部分（左半部分的镜像）
2. 只需要生成左半部分的所有排列，然后镜像即可
3. 如果有奇数次的字符，它必须放在中间

**算法步骤：**

1. **预处理：检查是否能组成回文**
   - 统计字符频率
   - 出现奇数次的字符不能超过 1 个
   
2. **构建左半部分**
   - 所有字符频率除以 2
   - 保存奇数次的字符作为中心

3. **回溯生成排列**
   - 对左半部分的字符进行全排列
   - 每个排列加上中心字符和镜像得到回文串

4. **去重**
   - 使用回溯剪枝避免重复排列

## Python 代码实现

### 方法一：回溯 + 剪枝（推荐）⭐

```python
from collections import Counter

class Solution:
    def generatePalindromes(self, s: str) -> List[str]:
        # 统计字符频率
        count = Counter(s)
        
        # 检查是否能组成回文
        odd_chars = [ch for ch, freq in count.items() if freq % 2 == 1]
        if len(odd_chars) > 1:
            return []
        
        # 确定中心字符（如果有）
        center = odd_chars[0] if odd_chars else ''
        
        # 构建左半部分的字符列表
        half = []
        for ch, freq in count.items():
            half.extend([ch] * (freq // 2))
        
        # 回溯生成所有排列
        result = []
        used = [False] * len(half)
        
        def backtrack(path: List[str]):
            if len(path) == len(half):
                # 构造回文：左半部分 + 中心 + 右半部分（镜像）
                left = ''.join(path)
                palindrome = left + center + left[::-1]
                result.append(palindrome)
                return
            
            for i in range(len(half)):
                # 剪枝：跳过已使用的字符
                if used[i]:
                    continue
                
                # 剪枝：跳过重复字符（关键优化）
                if i > 0 and half[i] == half[i - 1] and not used[i - 1]:
                    continue
                
                used[i] = True
                path.append(half[i])
                backtrack(path)
                path.pop()
                used[i] = False
        
        # 排序以便去重
        half.sort()
        backtrack([])
        
        return result
```

### 方法二：使用字典计数

```python
from collections import Counter

class Solution:
    def generatePalindromes(self, s: str) -> List[str]:
        count = Counter(s)
        
        # 检查能否组成回文
        odd_count = sum(1 for freq in count.values() if freq % 2 == 1)
        if odd_count > 1:
            return []
        
        # 找中心字符和左半部分
        center = ''
        half_chars = []
        
        for ch, freq in count.items():
            if freq % 2 == 1:
                center = ch
            half_chars.extend([ch] * (freq // 2))
        
        # 回溯生成排列
        result = []
        half_chars.sort()
        
        def backtrack(path: List[str], remaining: dict):
            if len(path) == len(half_chars):
                left = ''.join(path)
                result.append(left + center + left[::-1])
                return
            
            for ch in set(remaining.keys()):
                if remaining[ch] > 0:
                    remaining[ch] -= 1
                    path.append(ch)
                    backtrack(path, remaining)
                    path.pop()
                    remaining[ch] += 1
        
        # 构建剩余字符计数
        remaining = Counter(half_chars)
        backtrack([], remaining)
        
        return result
```

### 方法三：itertools 库（简化版）

```python
from collections import Counter
from itertools import permutations

class Solution:
    def generatePalindromes(self, s: str) -> List[str]:
        count = Counter(s)
        
        # 检查能否组成回文
        odd_chars = [ch for ch, freq in count.items() if freq % 2 == 1]
        if len(odd_chars) > 1:
            return []
        
        center = odd_chars[0] if odd_chars else ''
        
        # 构建左半部分
        half = []
        for ch, freq in count.items():
            half.extend([ch] * (freq // 2))
        
        # 生成所有排列并去重
        perms = set(permutations(half))
        
        result = []
        for perm in perms:
            left = ''.join(perm)
            result.append(left + center + left[::-1])
        
        return result
```

### 方法四：优化的回溯（使用字符计数）

```python
from collections import Counter

class Solution:
    def generatePalindromes(self, s: str) -> List[str]:
        count = Counter(s)
        
        # 检查并找中心字符
        center = ''
        for ch, freq in count.items():
            if freq % 2 == 1:
                if center:  # 已经有一个奇数频率字符
                    return []
                center = ch
        
        # 准备左半部分字符计数
        half_count = {}
        for ch, freq in count.items():
            half = freq // 2
            if half > 0:
                half_count[ch] = half
        
        # 回溯
        result = []
        total_len = sum(half_count.values())
        
        def backtrack(path: List[str]):
            if len(path) == total_len:
                left = ''.join(path)
                result.append(left + center + left[::-1])
                return
            
            for ch in half_count:
                if half_count[ch] > 0:
                    half_count[ch] -= 1
                    path.append(ch)
                    backtrack(path)
                    path.pop()
                    half_count[ch] += 1
        
        backtrack([])
        return result
```

## 复杂度分析

### 方法一、二、四（回溯）
- **时间复杂度**：O((n/2)!)
  - 生成左半部分的全排列
  - n 是字符串长度，左半部分长度约为 n/2
  - 全排列的时间复杂度是阶乘级别
  
- **空间复杂度**：O(n)
  - 递归栈深度 O(n/2)
  - 存储结果 O(结果数量)

### 方法三（itertools）
- **时间复杂度**：O((n/2)!)，同上
- **空间复杂度**：O((n/2)!)，生成所有排列的集合

## 图解示例

以 `s = "aabb"` 为例：

```
1. 统计频率:
   a: 2, b: 2
   
2. 检查回文条件:
   奇数次字符: 0 个 ✓
   中心字符: '' (空)
   
3. 构建左半部分:
   a 出现 2 次 → 左半部分取 1 个 a
   b 出现 2 次 → 左半部分取 1 个 b
   half = ['a', 'b']
   
4. 生成左半部分的全排列:
   排列 1: ['a', 'b'] → "ab" + "" + "ba" = "abba"
   排列 2: ['b', 'a'] → "ba" + "" + "ab" = "baab"
   
5. 结果: ["abba", "baab"]
```

以 `s = "aabbc"` 为例：

```
1. 统计频率:
   a: 2, b: 2, c: 1
   
2. 检查回文条件:
   奇数次字符: 1 个 (c) ✓
   中心字符: 'c'
   
3. 构建左半部分:
   a → 1 个, b → 1 个
   half = ['a', 'b']
   
4. 生成排列:
   排列 1: "ab" + "c" + "ba" = "abcba"
   排列 2: "ba" + "c" + "ab" = "bacab"
   
5. 结果: ["abcba", "bacab"]
```

## 关键点总结

1. **回文构造**：左半部分 + 中心 + 右半部分（镜像）
2. **预处理检查**：出现奇数次的字符不能超过 1 个
3. **优化思路**：
   - 只需生成左半部分的排列
   - 排序 + 剪枝避免重复
4. **去重技巧**：
   - 排序后，跳过相同且前一个未使用的字符
   - 或使用 set 去重（但效率较低）
5. **镜像操作**：`left[::-1]` 生成右半部分

## 易错点

1. **忘记排序**：必须先排序再回溯，否则去重剪枝失效
2. **去重条件错误**：
   ```python
   # 正确
   if i > 0 and half[i] == half[i-1] and not used[i-1]:
       continue
   
   # 错误：会漏掉一些排列
   if i > 0 and half[i] == half[i-1]:
       continue
   ```
3. **中心字符处理**：有奇数次字符时要记得加到中间
4. **频率除以 2**：左半部分的字符数是总频率的一半
5. **空字符串**：如果没有奇数次字符，center 应该是空字符串 `''`
