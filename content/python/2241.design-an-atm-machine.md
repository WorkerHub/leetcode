## 题目描述

设计一个 ATM 机，支持以下面额的钞票：`20, 50, 100, 200, 500`。初始时机器为空。

实现 `ATM` 类：
- `ATM()`：初始化 ATM。
- `deposit(banknotesCount: List[int])`：存入各面额钞票，`banknotesCount[i]` 是第 `i` 种面额的数量（顺序 20, 50, 100, 200, 500）。
- `withdraw(amount: int) -> List[int]`：取款 `amount`，优先使用**面额最大**的钞票，返回各面额使用数量。若无法恰好取出，返回 `[-1]`（不修改机器状态）。

**示例：**
```
输入：["ATM", "deposit", "withdraw", "deposit", "withdraw", "withdraw"]
       [[], [[0,0,1,2,1]], [600], [[0,1,0,1,1]], [600], [550]]
输出：[null, null, [0,0,1,0,1], null, [-1], [0,1,0,0,1]]
```

## 解题思路

ATM 维护各面额的钞票数量。

**存款**：直接累加。
**取款**：贪心地优先使用大面额（500 -> 200 -> 100 -> 50 -> 20），对每种面额取尽可能多（不超过剩余金额和库存）。若最终总金额恰好等于 `amount`，成功并更新库存；否则返回 `[-1]`。

## 代码实现

### 方法一：贪心取款（推荐）

```python
from typing import List

class ATM:
    def __init__(self):
        self.denominations = [20, 50, 100, 200, 500]
        self.counts = [0] * 5  # 各面额的钞票数量

    def deposit(self, banknotesCount: List[int]) -> None:
        for i in range(5):
            self.counts[i] += banknotesCount[i]

    def withdraw(self, amount: int) -> List[int]:
        used = [0] * 5
        remaining = amount

        # 从大面额到小面额贪心取款
        for i in range(4, -1, -1):
            denom = self.denominations[i]
            # 最多取 min(库存, 能整除的最大数)
            take = min(self.counts[i], remaining // denom)
            used[i] = take
            remaining -= take * denom

        if remaining != 0:
            return [-1]  # 无法恰好取出

        # 更新库存
        for i in range(5):
            self.counts[i] -= used[i]

        return used
```

### 方法二：使用字典（更易理解）

```python
from typing import List

class ATM:
    def __init__(self):
        self.bills = {500: 0, 200: 0, 100: 0, 50: 0, 20: 0}
        self.order = [500, 200, 100, 50, 20]

    def deposit(self, banknotesCount: List[int]) -> None:
        denoms = [20, 50, 100, 200, 500]
        for d, cnt in zip(denoms, banknotesCount):
            self.bills[d] += cnt

    def withdraw(self, amount: int) -> List[int]:
        used = {}
        rem = amount
        for d in self.order:
            take = min(self.bills[d], rem // d)
            used[d] = take
            rem -= take * d

        if rem != 0:
            return [-1]

        # 更新库存
        for d in self.order:
            self.bills[d] -= used[d]

        # 按 [20,50,100,200,500] 顺序返回
        return [used[d] for d in [20, 50, 100, 200, 500]]
```

## 复杂度分析

- deposit：O(1)，固定 5 种面额。
- withdraw：O(1)，固定 5 种面额。
- 空间：O(1)，存储 5 个计数器。

## 关键点总结

1. 贪心：优先使用最大面额，尽可能多取。
2. 取款前先模拟，确认可以取出再更新库存（避免部分取款后失败）。
3. 面额数组逆序遍历（500 -> 20）。

## 易错点

- 取款失败时不更新库存，需要先用临时变量保存使用量，确认成功后再扣减。
- `take = min(counts[i], remaining // denom)` 不能用 `remaining // denom` 超过库存。
