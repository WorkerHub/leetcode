## 题目描述

给你一个链表的头节点 `head`，每个节点包含一个整数值。

在每对相邻节点之间，插入一个新节点，新节点的值等于这两个相邻节点值的**最大公约数（GCD）**。

返回插入后的链表头节点。

**示例 1：**
```
输入：head = [18,6,10,3]
输出：[18,6,6,2,10,2,3]
解释：
- gcd(18, 6) = 6，插入 6
- gcd(6, 10) = 2，插入 2
- gcd(10, 3) = 1，插入 1，即 [18,6,6,2,10,1,3]
```

**示例 2：**
```
输入：head = [7]
输出：[7]
解释：只有一个节点，不需要插入
```

**提示：**
- 链表节点数 n 在 [1, 5000] 之间
- `1 <= Node.val <= 1000`

## 解题思路

遍历链表，对每对相邻节点 `(cur, next)` 计算 GCD，然后在它们之间插入新节点。

步骤：
1. 从 `head` 开始遍历
2. 对当前节点 `cur` 和 `cur.next`，计算 `gcd(cur.val, cur.next.val)`
3. 创建新节点，插入到 `cur` 和 `cur.next` 之间
4. 移动 `cur` 到原来的 `cur.next`（跳过刚插入的节点）

## Python 代码实现

### 方法一：直接遍历链表（推荐）

```python
from math import gcd
from typing import Optional

# 链表节点定义
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def insertGreatestCommonDivisors(self, head: Optional[ListNode]) -> Optional[ListNode]:
        cur = head
        while cur and cur.next:
            # 计算当前节点和下一节点的 GCD
            g = gcd(cur.val, cur.next.val)
            # 创建新节点
            new_node = ListNode(g)
            # 插入：cur -> new_node -> cur.next
            new_node.next = cur.next
            cur.next = new_node
            # 移动到原来的下一个节点（跳过刚插入的节点）
            cur = new_node.next
        return head
```

### 方法二：先转换为列表再重建

```python
from math import gcd
from typing import Optional, List

class Solution:
    def insertGreatestCommonDivisors(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 提取链表所有值
        vals = []
        cur = head
        while cur:
            vals.append(cur.val)
            cur = cur.next

        # 构建新值列表（原始值 + GCD 插值）
        new_vals = []
        for i in range(len(vals)):
            new_vals.append(vals[i])
            if i + 1 < len(vals):
                new_vals.append(gcd(vals[i], vals[i + 1]))

        # 根据新值列表重建链表
        dummy = ListNode(0)
        cur = dummy
        for v in new_vals:
            cur.next = ListNode(v)
            cur = cur.next

        return dummy.next
```

## 复杂度分析

- 时间复杂度：O(n × log(max_val))，其中 n 为节点数，log(max_val) 为求 GCD 的时间（辗转相除法）
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 链表插入：`new_node.next = cur.next; cur.next = new_node`，顺序不能颠倒
2. 遍历时要跳过刚插入的节点：`cur = new_node.next`
3. Python 内置 `math.gcd()` 可直接计算最大公约数
4. 只有一个节点时不需要插入，`while cur and cur.next` 自然处理

## 易错点

1. 插入节点后，`cur` 应移动到**原来的** `cur.next`（即 `new_node.next`），而不是 `new_node`
2. 链接节点时顺序很重要：先设置 `new_node.next`，再修改 `cur.next`
3. 边界情况：链表只有一个节点时直接返回 `head`
