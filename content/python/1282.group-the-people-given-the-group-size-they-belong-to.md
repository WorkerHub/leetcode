## 题目描述

有 `n` 个人被分成数量未知的组，每个人都被标记为一个**从 0 到 n-1** 的唯一 ID。

给你一个整数数组 `groupSizes`，其中 `groupSizes[i]` 是第 `i` 个人所在的组的规模。请你返回每个人所在组的情况，每个人在**且仅在一个组**中，且同一组内恰好包含 `groupSizes[i]` 个人。

返回一个列表，其中每个元素都是一个含有组内成员 ID 的列表，你可以按**任意顺序**返回这些列表。

**示例 1：**

```
输入：groupSizes = [3,3,3,3,3,1,3]
输出：[[5],[0,1,2],[3,4,6]]
解释：
- 第 5 个人的组大小为 1，所以该人独自成组：[5]
- 所有组大小为 3 的人需要 3 人一组：[0,1,2] 和 [3,4,6]
```

**示例 2：**

```
输入：groupSizes = [2,1,3,3,3,2]
输出：[[1],[0,5],[2,3,4]]
```

**提示：**

- `groupSizes.length == n`
- `1 <= n <= 500`
- `1 <= groupSizes[i] <= n`

---

## 解题思路

这道题的关键洞察是：**所有要求同样组大小的人，可以被依次放入组中**。

**贪心策略：**
1. 用一个哈希表（字典），键为"组的大小"，值为"当前正在凑齐的组的成员列表"。
2. 遍历每个人，将其放入对应大小的临时组中。
3. 一旦某个临时组的人数恰好达到该组要求的大小，将这个组加入结果，并清空临时组，等待下一组。

**为什么这样做是正确的？**
- 题目保证每个人都能被完整地分组（即数组合法），所以贪心地"凑满就输出"不会产生遗留成员。
- 不需要考虑谁和谁搭配更优，只要凑满人数就成一组。

**图解（以 groupSizes = [3,3,3,3,3,1,3] 为例）：**

```
遍历到 i=0, groupSizes[0]=3: 临时组{3}: [0]
遍历到 i=1, groupSizes[1]=3: 临时组{3}: [0,1]
遍历到 i=2, groupSizes[2]=3: 临时组{3}: [0,1,2] -> 凑满! 输出[0,1,2], 清空
遍历到 i=3, groupSizes[3]=3: 临时组{3}: [3]
遍历到 i=4, groupSizes[4]=3: 临时组{3}: [3,4]
遍历到 i=5, groupSizes[5]=1: 临时组{1}: [5] -> 凑满! 输出[5], 清空
遍历到 i=6, groupSizes[6]=3: 临时组{3}: [3,4,6] -> 凑满! 输出[3,4,6], 清空

最终结果：[[0,1,2],[5],[3,4,6]]
```

## Python 代码实现

### 方法一：哈希表 + 贪心（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupThePeople(self, groupSizes: List[int]) -> List[List[int]]:
        # 键：组的大小；值：当前正在凑组的成员列表
        temp = defaultdict(list)
        result = []

        for i, size in enumerate(groupSizes):
            temp[size].append(i)  # 将第 i 个人放入大小为 size 的临时组

            # 如果临时组人数恰好达到要求的大小，则将该组加入结果
            if len(temp[size]) == size:
                result.append(temp[size][:])  # 用切片复制，避免引用问题
                temp[size] = []               # 清空临时组，开始凑下一组

        return result
```

### 方法二：普通字典（不使用 defaultdict）

```python
from typing import List

class Solution:
    def groupThePeople(self, groupSizes: List[int]) -> List[List[int]]:
        temp = {}   # 普通字典
        result = []

        for i, size in enumerate(groupSizes):
            # 如果该大小的临时组还不存在，则初始化为空列表
            if size not in temp:
                temp[size] = []

            temp[size].append(i)

            if len(temp[size]) == size:
                result.append(temp[size])  # 直接加入（此时不再修改这个列表）
                del temp[size]             # 删除旧键，下次创建全新的列表

        return result
```

### 方法三：先分组再切割（直观易懂）

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupThePeople(self, groupSizes: List[int]) -> List[List[int]]:
        # 第一步：按组大小将所有人聚集在一起
        by_size = defaultdict(list)
        for i, size in enumerate(groupSizes):
            by_size[size].append(i)

        # 第二步：对每种组大小，将人员列表切割成若干完整的组
        result = []
        for size, people in by_size.items():
            # 每 size 个人切一组
            for start in range(0, len(people), size):
                result.append(people[start:start + size])

        return result
```

**第三种方法的思路：**
- 先把所有要求相同组大小的人放在一起。
- 再用步长为 `size` 的切片，将大列表切成若干小组。
- 例如：8 个人都要求组大小为 4，则切成 [0..3] 和 [4..7] 两组。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一/二（贪心） | O(n) | O(n) |
| 方法三（先分组后切割） | O(n) | O(n) |

- **时间复杂度 O(n)**：只需遍历 `groupSizes` 一次（或两次），每次操作为 O(1)。
- **空间复杂度 O(n)**：哈希表和结果列表共存储 n 个元素。

## 关键点总结

1. 核心是"**凑满即输出**"的贪心策略，不需要关心谁和谁配对，只要人数到了就是一组。
2. `defaultdict(list)` 是处理"字典中键对应列表"场景的标准工具，避免了手动判断键是否存在。
3. 方法三的"先汇总后切割"思路更清晰，适合初学者理解；方法一的"边遍历边输出"效率相同但更省内存（因为不需要先存下所有人）。
4. 题目保证输入合法，所以遍历结束时 `temp` 中不会有未凑满的组。
5. `enumerate` 同时获取索引和值，是遍历时需要索引的标准 Python 写法。

---

## 易错点

1. **列表引用问题（方法一）**：`result.append(temp[size])` 后若直接 `temp[size] = []` 重置，由于 Python 列表是引用类型，原来加入 result 的那个列表对象不受影响；但如果用 `temp[size].clear()`，则会清空已经加入 result 的列表！方法一中用切片 `temp[size][:]` 或直接赋值新列表 `temp[size] = []` 均安全。
2. **初始化乘积时的单位元**：这里不涉及，但类似初始化问题很常见，注意列表初始化用 `[]`，数字乘积初始化用 `1`，数字求和初始化用 `0`。
3. **组大小是每人属于那个组的大小，不是总分组数**：`groupSizes[i]` 表示第 i 个人所在组的规模，不是第 i 组的大小，注意理解题意。
