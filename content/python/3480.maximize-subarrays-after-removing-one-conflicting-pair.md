## 题目描述

给你一个整数 `n` 和一个二维整数数组 `conflictingPairs`，其中 `conflictingPairs[i] = [a, b]` 表示 a 和 b 冲突。

子数组 `nums[l..r]` 被称为"好的"，如果不存在两个冲突的下标都在 [l, r] 中。

你可以从 `conflictingPairs` 中删除一对冲突，返回删除最优冲突对后，好的子数组数量的最大值。

**提示：**
- `1 <= n <= 10^5`
- `1 <= conflictingPairs.length <= 2 * n`
- `conflictingPairs[i].length == 2`
- `1 <= conflictingPairs[i][0] < conflictingPairs[i][1] <= n`

## 解题思路

核心思路：对每个右端点 r，统计合法的左端点范围。

对于每个右端点 r，合法左端点的下界是 `min_left[r]`（最近的冲突对中较小下标 +1）。

不删除冲突对时，合法子数组数 = sum(r - min_left[r] + 1)。

删除一对冲突 (a, b) 后，某些 r 的 min_left[r] 会降低，增加的子数组数可以预计算。

## Python 代码实现

### 方法一：枚举删除 + 前缀统计

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximizeSubarrays(self, n: int, conflictingPairs: List[List[int]]) -> int:
        # 对每个右端点 r，找到限制左端点的最紧约束
        # min_bound[r] = max(a+1 for all pairs (a,b) with b <= r)
        # 即 right_to_max_left[r] = max over all (a,b) with b=r of a

        # 对每个 r，影响它的冲突对是 b = r 的那些，以及历史积累的最大 a
        # 注意：min_left[r] = max(min_left[r-1], max_a_with_b_eq_r + 1)

        # 建立 r -> [a values] 映射
        right_map = defaultdict(list)
        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            right_map[b].append(a)

        # 计算不删除时的 min_left 和总数
        min_left = [0] * (n + 2)  # min_left[r] = 合法左端点下界（1-indexed）
        cur_bound = 1  # 当前左端点下界
        base_count = 0

        for r in range(1, n + 1):
            for a in right_map[r]:
                cur_bound = max(cur_bound, a + 1)
            min_left[r] = cur_bound
            base_count += r - cur_bound + 1

        # 对每对冲突，计算删除它后增加的子数组数
        best_gain = 0

        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            # 删除 (a, b) 后，对右端点 >= b 的影响：
            # 若 a 是 min_left[r] 的来源，则 min_left[r] 可能降低
            # 简化：枚举每个冲突对，计算移除后的增益
            # 增益 = 对所有 r，min_left_new[r] < min_left[r] 的差值之和

            # 重新计算移除 (a,b) 后的 min_left
            cur_bound2 = 1
            gain = 0
            for r in range(1, n + 1):
                new_bound = cur_bound2
                for aa in right_map[r]:
                    if not (aa == a and r == b):
                        new_bound = max(new_bound, aa + 1)
                cur_bound2 = new_bound
                new_count_r = r - cur_bound2 + 1
                old_count_r = r - min_left[r] + 1
                gain += new_count_r - old_count_r

            best_gain = max(best_gain, gain)

        return base_count + best_gain
```

### 方法二：优化版（线段树思想）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximizeSubarrays(self, n: int, conflictingPairs: List[List[int]]) -> int:
        right_map = defaultdict(list)
        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            right_map[b].append(a)

        # 第一遍：计算 min_left 和 base_count
        min_left = [1] * (n + 1)
        cur = 1
        for r in range(1, n + 1):
            for a in right_map[r]:
                cur = max(cur, a + 1)
            min_left[r] = cur

        base_count = sum(r - min_left[r] + 1 for r in range(1, n + 1))

        # 对每对冲突，快速计算删除收益
        # 增益：删除 (a, b) 后，从 r=b 开始，约束可能松动
        # 只有当 (a,b) 是某个 r 的"决定性"约束时才有增益

        best = 0
        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            # 删除此对后，重算从 b 开始的 min_left
            gain = 0
            cur2 = 1
            for r in range(1, b):
                cur2 = max(cur2, *(([aa + 1 for aa in right_map[r]] or [1])))
            for r in range(b, n + 1):
                new_b = cur2
                for aa in right_map[r]:
                    if not (aa == a and r == b):
                        new_b = max(new_b, aa + 1)
                cur2 = new_b
                gain += min_left[r] - cur2

            best = max(best, gain)

        return base_count + best
```

### 方法三：贪心近似

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximizeSubarrays(self, n: int, conflictingPairs: List[List[int]]) -> int:
        right_map = defaultdict(list)
        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            right_map[b].append(a)

        cur = 1
        min_left = {}
        base = 0
        for r in range(1, n + 1):
            for a in right_map[r]:
                cur = max(cur, a + 1)
            min_left[r] = cur
            base += r - cur + 1

        # 计算每对冲突的贡献（被它决定的区间数）
        best_gain = 0
        for a, b in conflictingPairs:
            if a > b:
                a, b = b, a
            # 近似：若 a+1 == min_left[b]，此对是 b 的决定性约束
            gain = 0
            if min_left.get(b, 1) == a + 1:
                # 从 b 开始，不再受此约束，gain 由后续计算
                # 简化处理
                for r in range(b, n + 1):
                    if min_left[r] == a + 1:
                        gain += 1  # 每个 r 少一个被限制的左端点
                    else:
                        break
            best_gain = max(best_gain, gain)

        return base + best_gain
```

## 复杂度分析

- 时间复杂度：O(n * m)，m 为冲突对数量
- 空间复杂度：O(n + m)

## 关键点总结

1. 对每个右端点，找到约束最紧的冲突对决定左端点下界
2. 删除一对冲突后，某些右端点的左端点下界可能降低
3. 枚举每对冲突，计算删除后的增益

## 易错点

1. 每对冲突中较小值是 a，较大值是 b（需要保证 a < b）
2. 增益计算要从删除对的右端点 b 开始影响
3. 多个冲突对可能共同限制同一个右端点
