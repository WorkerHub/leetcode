## 题目描述

给定一棵二叉树的根节点 `root`，返回最深叶子节点的最近公共祖先。

叶子节点是树中没有子节点的节点。

一个节点的深度是它到根节点的距离。

最深叶子节点的最近公共祖先是包含所有最深叶子节点的最小子树的根节点。

**示例 1:**

```
输入: root = [3,5,1,6,2,0,8,null,null,7,4]
输出: [2,7,4]
解释: 最深叶子节点是7和4，它们的最近公共祖先是节点2。
```

**示例 2:**

```
输入: root = [1]
输出: [1]
```

**示例 3:**

```
输入: root = [0,1,3,null,2]
输出: [2]
```

## 解题思路

核心思路是找到最深的叶子节点，然后找它们的最近公共祖先（LCA）。

关键观察：
1. 需要知道每个子树的最大深度
2. 如果左右子树深度相同，当前节点就是LCA
3. 如果左子树更深，LCA在左子树
4. 如果右子树更深，LCA在右子树

算法步骤：
1. 后序遍历，返回(节点，深度)
2. 比较左右子树深度
3. 根据深度关系确定LCA

## Python 代码实现

### 方法一：一次DFS（推荐）

```python
from typing import Optional, Tuple

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode]) -> Tuple[Optional[TreeNode], int]:
            """
            返回 (最深叶子的LCA, 深度)
            """
            if not node:
                return (None, 0)
            
            # 递归处理左右子树
            left_lca, left_depth = dfs(node.left)
            right_lca, right_depth = dfs(node.right)
            
            # 如果左右子树深度相同，当前节点是LCA
            if left_depth == right_depth:
                return (node, left_depth + 1)
            # 如果左子树更深，LCA在左子树
            elif left_depth > right_depth:
                return (left_lca, left_depth + 1)
            # 如果右子树更深，LCA在右子树
            else:
                return (right_lca, right_depth + 1)
        
        lca, _ = dfs(root)
        return lca
```

### 方法二：两次遍历

```python
class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        # 第一次遍历：找到最大深度
        def get_max_depth(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return max(get_max_depth(node.left), get_max_depth(node.right)) + 1
        
        max_depth = get_max_depth(root)
        
        # 第二次遍历：找LCA
        def find_lca(node: Optional[TreeNode], depth: int) -> Optional[TreeNode]:
            if not node or depth == max_depth:
                return node
            
            left = find_lca(node.left, depth + 1)
            right = find_lca(node.right, depth + 1)
            
            # 如果左右都找到了最深节点，当前节点是LCA
            if left and right:
                return node
            # 否则返回找到的那一个
            return left if left else right
        
        return find_lca(root, 1)
```

### 方法三：使用全局变量

```python
class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        self.lca = None
        self.max_depth = 0
        
        def dfs(node: Optional[TreeNode], depth: int) -> int:
            """返回当前子树的最大深度"""
            if not node:
                return depth
            
            self.max_depth = max(self.max_depth, depth)
            
            left_depth = dfs(node.left, depth + 1)
            right_depth = dfs(node.right, depth + 1)
            
            # 如果左右深度都等于最大深度，当前节点是LCA
            if left_depth == right_depth == self.max_depth:
                self.lca = node
            
            return max(left_depth, right_depth)
        
        dfs(root, 0)
        return self.lca
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈深度，h为树高

## 关键点总结

1. **后序遍历**：必须先知道子树信息才能判断当前节点
2. **深度比较**：左右深度相同时，当前节点就是LCA
3. **返回值设计**：同时返回节点和深度信息
4. **一次遍历优化**：方法一只需一次DFS，效率最高

## 易错点

1. **深度定义混淆**：
   - 根节点深度为0还是1？
   - 空节点深度为0还是-1？
   - 本题中保持一致即可

2. **LCA判断错误**：
   ```python
   # 错误：只有一个子树有最深叶子时，不应该返回当前节点
   if left_depth > 0 or right_depth > 0:
       return node
   
   # 正确：左右深度相等才是LCA
   if left_depth == right_depth:
       return node
   ```

3. **返回值混淆**：要区分返回的是LCA节点还是深度

## 图解示例

```
示例: root = [3,5,1,6,2,0,8,null,null,7,4]

        3 (depth=0)
       / \
      5   1 (depth=1)
     / \ / \
    6  2 0  8 (depth=2)
      / \
     7   4 (depth=3) ← 最深叶子

分析：
- 节点7的深度: 3
- 节点4的深度: 3
- 它们的LCA: 节点2

DFS过程：
1. dfs(7) → (7, 3)
2. dfs(4) → (4, 3)
3. dfs(2) → left_depth=3, right_depth=3 → (2, 4) ✓
4. dfs(5) → left_depth=2, right_depth=4 → (2, 5)
```
