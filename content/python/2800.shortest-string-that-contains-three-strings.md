## 题目描述

给你三个字符串 `a`、`b` 和 `c`，返回最短的字符串，使得 `a`、`b` 和 `c` 都是其子字符串。

如果有多个答案，返回字典序最小的一个。

**示例 1：**
```
输入：a = "abc", b = "bca", c = "aaa"
输出："aaabca"
```

**示例 2：**
```
输入：a = "ab", b = "ba", c = "aba"
输出："aba"
```

**提示：**
- `1 <= a.length, b.length, c.length <= 100`

## 解题思路

枚举三个字符串的所有 **排列组合**（6 种），对每种顺序，依次合并两个字符串（找最大重叠后缀/前缀），取最短且字典序最小的结果。

**合并函数 `merge(s, t)`**：找 s 的最长后缀 = t 的前缀，拼接后返回。

## Python 代码实现

### 方法一：枚举排列（推荐）

```python
from itertools import permutations

class Solution:
    def minimumString(self, a: str, b: str, c: str) -> str:
        def merge(s: str, t: str) -> str:
            # 将 t 合并到 s 之后（最大重叠）
            if t in s:
                return s  # t 已在 s 中
            for i in range(min(len(s), len(t)), 0, -1):
                if s.endswith(t[:i]):
                    return s + t[i:]
            return s + t

        ans = None
        for perm in permutations([a, b, c]):
            # 依次合并三个字符串
            merged = merge(merge(perm[0], perm[1]), perm[2])
            if ans is None or len(merged) < len(ans) or (len(merged) == len(ans) and merged < ans):
                ans = merged

        return ans
```

## 复杂度分析

- 时间复杂度：O(L^2)，L 为字符串总长度（合并操作）
- 空间复杂度：O(L)

## 关键点总结

1. 枚举 6 种排列，分别合并，取最优
2. 合并时检查 t 是否已是 s 的子串（优化）
3. 最长公共前后缀保证最大重叠

## 易错点

1. 先判断 t 是否已在 s 中（此时无需扩展）
2. 同长度时选字典序较小的
