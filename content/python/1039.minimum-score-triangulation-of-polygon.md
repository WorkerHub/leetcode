## 题目描述

你有一个凸的 `n` 边形，其每个顶点都有一个整数值。给定一个整数数组 `values`，其中 `values[i]` 是第 `i` 个顶点的值（顺时针顺序）。

假设将多边形 **剖分** 为 `n - 2` 个三角形。对于每个三角形，该三角形的值是顶点值的 **乘积**，三角剖分的分数是所有 `n - 2` 个三角形的值之和。

返回你能得到的最低分。

**示例 1：**
```
输入：values = [1,2,3]
输出：6
解释：多边形已经三角化，唯一三角形的值是 6。
```

**示例 2：**
```
输入：values = [3,7,4,5]
输出：144
解释：有两种三角剖分，值分别为：
3*7*5 + 4*5*7 = 245
3*4*5 + 3*4*7 = 144
最小值是 144。
```

**示例 3：**
```
输入：values = [1,3,1,4,1,5]
输出：13
解释：最小分数三角剖分的得分为 1*1*3 + 1*1*4 + 1*1*5 + 1*1*1 = 13。
```

**提示：**
- `n == values.length`
- `3 <= n <= 50`
- `1 <= values[i] <= 100`

## 解题思路

这是一道经典的 **区间动态规划** 问题，类似于 **矩阵链乘法**。

**核心思想：**

对于一个多边形，我们可以选择任意一条边作为基准边，然后枚举第三个顶点来形成三角形，将多边形分成两个更小的部分。

**动态规划定义：**

设 `dp[i][j]` 表示由顶点 `i` 到顶点 `j`（包含 i 和 j）形成的多边形的最小三角剖分分数。

**状态转移方程：**

对于区间 `[i, j]`，我们固定边 `(i, j)`，然后枚举中间点 `k`（`i < k < j`）：

```
dp[i][j] = min(dp[i][k] + dp[k][j] + values[i] * values[k] * values[j])
```

其中 `k` 是 `i` 和 `j` 之间的任意顶点。

**边界条件：**
- 当区间长度小于 3 时（即 `j - i < 2`），无法形成三角形，分数为 0

**遍历顺序：**
- 按区间长度从小到大遍历
- 对于每个长度，遍历所有可能的起点

## Python 代码实现

### 方法一：区间 DP（自底向上）

```python
from typing import List

class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        """
        使用区间 DP 求最小三角剖分分数
        
        Args:
            values: 多边形顶点的值
            
        Returns:
            最小三角剖分分数
        """
        n = len(values)
        
        # dp[i][j] 表示顶点 i 到 j 形成的多边形的最小剖分分数
        dp = [[0] * n for _ in range(n)]
        
        # 按区间长度遍历
        for length in range(3, n + 1):  # 区间长度从 3 开始
            for i in range(n - length + 1):
                j = i + length - 1  # 区间右端点
                
                dp[i][j] = float('inf')
                
                # 枚举中间顶点 k，形成三角形 (i, k, j)
                for k in range(i + 1, j):
                    # 三角形 (i, k, j) 的分数 + 左右两部分的最小分数
                    score = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
                    dp[i][j] = min(dp[i][j], score)
        
        # 返回整个多边形的最小剖分分数
        return dp[0][n - 1]
```

### 方法二：记忆化递归（自顶向下）

```python
from typing import List
from functools import lru_cache

class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        """
        使用记忆化递归求解
        
        Args:
            values: 多边形顶点的值
            
        Returns:
            最小三角剖分分数
        """
        n = len(values)
        
        @lru_cache(maxsize=None)
        def dfs(i: int, j: int) -> int:
            """
            计算顶点 i 到 j 形成的多边形的最小剖分分数
            
            Args:
                i: 起始顶点
                j: 结束顶点
                
            Returns:
                最小剖分分数
            """
            # 边界条件：少于 3 个顶点无法形成三角形
            if j - i < 2:
                return 0
            
            min_score = float('inf')
            
            # 枚举中间顶点 k
            for k in range(i + 1, j):
                # 三角形 (i, k, j) + 左侧 + 右侧
                score = values[i] * values[k] * values[j] + dfs(i, k) + dfs(k, j)
                min_score = min(min_score, score)
            
            return min_score
        
        return dfs(0, n - 1)
```

### 方法三：优化的 DP（使用字典）

```python
from typing import List

class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        """
        使用字典存储 DP 状态，避免初始化大数组
        """
        memo = {}
        
        def dp(i: int, j: int) -> int:
            """计算 [i, j] 区间的最小剖分分数"""
            # 边界条件
            if j - i < 2:
                return 0
            
            # 查找缓存
            if (i, j) in memo:
                return memo[(i, j)]
            
            # 计算最小值
            result = float('inf')
            for k in range(i + 1, j):
                score = values[i] * values[k] * values[j] + dp(i, k) + dp(k, j)
                result = min(result, score)
            
            memo[(i, j)] = result
            return result
        
        return dp(0, len(values) - 1)
```

### 方法四：简化的迭代 DP

```python
from typing import List

class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        """
        简化的迭代 DP 实现
        """
        n = len(values)
        dp = [[0] * n for _ in range(n)]
        
        # 从小区间到大区间
        for gap in range(2, n):  # gap 是区间跨度
            for i in range(n - gap):
                j = i + gap
                dp[i][j] = min(
                    dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
                    for k in range(i + 1, j)
                )
        
        return dp[0][n - 1]
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n³)
  - 外层循环遍历区间长度：O(n)
  - 中层循环遍历起点：O(n)
  - 内层循环枚举中间点：O(n)
  - 总共：O(n³)

- **空间复杂度**：O(n²)
  - 需要 n×n 的 DP 数组或缓存

## 图解示例

以 `values = [3,7,4,5]` 为例：

```
多边形顶点：
    7(1)
   /    \
  /      \
3(0)     4(2)
  \      /
   \    /
    5(3)

可能的剖分方式：

方式 1：选择顶点 1 作为中间点
三角形：(0,1,3) 和 (1,2,3)
分数：3*7*5 + 7*4*5 = 105 + 140 = 245

方式 2：选择顶点 2 作为中间点
三角形：(0,1,2) 和 (0,2,3)
分数：3*7*4 + 3*4*5 = 84 + 60 = 144 ✓

最小分数：144
```

DP 表构建过程（length=3 时）：
```
dp[0][2] = values[0] * values[1] * values[2] = 3*7*4 = 84
dp[1][3] = values[1] * values[2] * values[3] = 7*4*5 = 140
```

DP 表构建过程（length=4 时）：
```
dp[0][3] = min(
    dp[0][1] + dp[1][3] + values[0]*values[1]*values[3],  // k=1: 0 + 140 + 105 = 245
    dp[0][2] + dp[2][3] + values[0]*values[2]*values[3]   // k=2: 84 + 0 + 60 = 144
) = 144
```

## 关键点总结

1. **问题本质**：区间 DP，类似矩阵链乘法
2. **状态定义**：`dp[i][j]` 表示区间 `[i, j]` 的最小剖分分数
3. **状态转移**：枚举中间点 k，将问题分解为两个子问题
4. **遍历顺序**：按区间长度从小到大，保证子问题已经计算
5. **边界条件**：少于 3 个顶点无法形成三角形，分数为 0

## 易错点

1. **区间长度的起始值**：必须从 3 开始，因为至少需要 3 个顶点形成三角形
2. **循环范围**：中间点 k 的范围是 `(i+1, j)`，不包括端点
3. **初始化**：`dp[i][j]` 要初始化为无穷大，而不是 0
4. **遍历顺序**：自底向上时必须先计算小区间，再计算大区间
5. **返回值**：返回 `dp[0][n-1]`，不是 `dp[0][n]`
