## 题目描述

给你一个字符串数组 `words`，每个字符串长度相同，为 `n`。

字符串 `word` 的 **差值数组** 定义为长度为 `n - 1` 的整数数组，其中 `diff[i] = word[i + 1] - word[i]`（字符对应的下标差）。

例如，`"adc"` 的差值数组是 `[3, -2]`。

数组 `words` 中只有一个字符串的差值数组与其他字符串的不同，请找到该字符串并返回。

**示例 1：**
```
输入：words = ["adc","wzy","abc"]
输出："abc"
解释："adc" 差值数组 [3,-2]，"wzy" 差值数组 [18,-23]，"abc" 差值数组 [1,1]。
```

**示例 2：**
```
输入：words = ["aaa","bob","ccc","ddd"]
输出："bob"
```

**提示：**
- `3 <= words.length <= 100`
- `n == words[i].length`
- `2 <= n <= 20`
- `words[i]` 仅由小写英文字母组成

## 解题思路

计算每个字符串的差值数组（元组形式），用哈希表统计每种差值数组出现的次数，返回只出现一次的那个差值数组对应的字符串。

## 代码实现

### 方法一：哈希表统计（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def oddString(self, words: List[str]) -> str:
        def diff(word: str) -> tuple:
            """计算字符串的差值数组（元组）"""
            return tuple(ord(word[i + 1]) - ord(word[i]) for i in range(len(word) - 1))

        # 统计每种差值数组出现次数
        count = Counter(diff(w) for w in words)

        # 找出差值数组只出现一次的字符串
        for w in words:
            if count[diff(w)] == 1:
                return w

        return ""
```

### 方法二：分组找独特值

```python
from typing import List

class Solution:
    def oddString(self, words: List[str]) -> str:
        def get_diff(word: str) -> tuple:
            return tuple(ord(word[i + 1]) - ord(word[i]) for i in range(len(word) - 1))

        diffs = [get_diff(w) for w in words]

        # 找出与众不同的差值数组
        # 因为只有一个不同的，比较前两个就能确定哪个是多数
        if diffs[0] == diffs[1]:
            # 前两个相同，不同的在后面
            target = diffs[0]
            for i, (d, w) in enumerate(zip(diffs, words)):
                if d != target:
                    return w
        else:
            # 前两个不同，第三个决定哪个是多数
            if diffs[0] == diffs[2]:
                return words[1]  # diffs[1] 是独特的
            else:
                return words[0]  # diffs[0] 是独特的

        return ""
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(m * n)（m 为单词数） | O(m * n) |
| 分组 | O(m * n) | O(m * n) |

## 关键点总结

1. 差值数组用元组表示，可作为哈希表的键
2. 只有一个字符串的差值不同，其余所有字符串差值相同
3. 比较前三个元素可以快速确定多数差值

## 易错点

- 差值是字符编码之差，不是字符本身
- 元组用作字典键时需要可哈希（Python 元组天然可哈希）
