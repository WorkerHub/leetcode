## 题目描述

给你一个字符串 `s`（只含 `0` 和 `1`）和整数 `k`，每次操作可以将 `s` 中的 `0` 改为 `1` 或 `1` 改为 `0`，最多操作 `k` 次。

返回所有不同的可能结果字符串数量。

**示例 1：**

```
输入：s = "10", k = 1
输出：3
解释：可得"10"（不操作），"00"（改1→0），"11"（改0→1），共3种不同结果
```

**示例 2：**

```
输入：s = "00", k = 2
输出：3
解释：可得"00","01","10","11"，共4种，但有些可能重复
```

**提示：**

- `1 <= s.length <= 100`
- `0 <= k <= s.length`

## 解题思路

对字符串 `s`，每个位置可以改或不改，改变的位数最多为 `k`。

所有可能的结果字符串 = 与 `s` 的汉明距离 <= k 的字符串集合（在可改的范围内）。

汉明距离恰好为 j（0 <= j <= k）的字符串数 = `C(n, j)`（选 j 个位置取反）。

总数 = `sum(C(n, j) for j in range(min(k, n) + 1))`。

## Python 代码实现

### 方法一：组合数求和（推荐）

```python
from math import comb

class Solution:
    def countStrings(self, s: str, k: int) -> int:
        n = len(s)
        total = sum(comb(n, j) for j in range(min(k, n) + 1))
        return total
```

### 方法二：迭代计算

```python
class Solution:
    def countStrings(self, s: str, k: int) -> int:
        n = len(s)
        from math import comb
        return sum(comb(n, j) for j in range(k + 1) if j <= n)
```

## 复杂度分析

- 时间复杂度：O(k)
- 空间复杂度：O(1)

## 关键点总结

1. 距离 s 汉明距离 <= k 的字符串总数 = sum C(n, j) for j=0 to min(k,n)
2. 每个距离 j 对应 C(n,j) 种字符串
3. 每个字符串唯一（不同翻转位置组合得到不同结果）

## 易错点

1. k 可能超过 n，需取 min(k, n)
2. 结果可能很大，视题意是否需要取模
3. 不同的翻转组合一定得到不同的字符串（翻转是唯一确定的）
