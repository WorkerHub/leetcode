## 题目描述

给你一个 `m x n` 的矩阵 `grid`，每个元素为正整数。

你从某个单元格出发，每次可以向右或向下移动若干步（不能向左或向上）。每次移动的得分为目标单元格的值减去当前单元格的值。

返回在移动过程中可以得到的 **最大** 总得分。总得分可以为负数。

**示例 1：**
```
输入：grid = [[9,5,7,3],[8,9,6,1],[6,7,14,3],[2,5,3,1]]
输出：9
解释：从 (0,1)=5 出发，移到 (2,2)=14，得分 14-5=9
```

**提示：**
- `1 <= m, n <= 1000`
- `1 <= grid[i][j] <= 10^5`

## 解题思路

注意得分是终点值减起点值（路径上中间节点不影响得分，因为得分会相互抵消）。

即：得分 = grid[r2][c2] - grid[r1][c1]，其中 (r1,c1) 在 (r2,c2) 的左上方（r1<=r2, c1<=c2）。

所以需要找到在 (r2,c2) 左上方的最小值，与 grid[r2][c2] 的差值最大。

DP：`dp[i][j]` = 从矩阵左上角到 (i,j) 的最小值（可以从任意位置出发，所以是 (i,j) 左上方所有值的最小）。

答案 = max(grid[i][j] - dp[i][j]) 对所有 (i,j)，但不能起点终点相同。

## Python 代码实现

### 方法一：DP 维护左上最小值（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')

        # dp[i][j] = grid[0..i][0..j] 范围内（不含 (i,j) 本身）的最小值
        # 即可以作为起点的最小值
        dp = [[INF] * n for _ in range(m)]

        ans = float('-inf')
        for i in range(m):
            for j in range(n):
                # 当前格子作为终点，起点为左上方的最小值
                min_above = INF
                if i > 0:
                    min_above = min(min_above, dp[i-1][j])
                if j > 0:
                    min_above = min(min_above, dp[i][j-1])
                # dp[i][j] = min(起点最小值, grid[i][j] 本身)
                if min_above < INF:
                    ans = max(ans, grid[i][j] - min_above)
                dp[i][j] = min(min_above, grid[i][j]) if min_above < INF else grid[i][j]
                if i > 0 or j > 0:
                    dp[i][j] = min(dp[i][j], grid[i][j])

        return ans
```

### 方法二：更清晰的 DP

```python
from typing import List

class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # min_val[i][j] = 从 (0,0) 出发可到达 (i,j) 的左上方的最小值
        min_val = [[float('inf')] * n for _ in range(m)]
        ans = float('-inf')

        for i in range(m):
            for j in range(n):
                # 从左或上传递最小值
                if i > 0:
                    min_val[i][j] = min(min_val[i][j], min_val[i-1][j], grid[i-1][j])
                if j > 0:
                    min_val[i][j] = min(min_val[i][j], min_val[i][j-1], grid[i][j-1])
                if min_val[i][j] < float('inf'):
                    ans = max(ans, grid[i][j] - min_val[i][j])

        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 路径得分 = 终点值 - 起点值（中间节点抵消）
2. 只需找终点左上方的最小起点值
3. DP 递推左上最小值

## 易错点

1. 注意起点和终点不能相同
2. 传递最小值时要同时考虑格子本身的值
