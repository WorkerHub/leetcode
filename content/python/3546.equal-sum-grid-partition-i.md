## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`，将其沿某条水平线或垂直线分割成两个非空部分，使得两部分的元素之和相等。判断是否存在这样的分割方式。

**示例 1：**

```
输入：grid = [[1,2],[3,4]]
输出：false
解释：总和为 10，无法等分为 5+5（水平/垂直切割都不行）。
```

**示例 2：**

```
输入：grid = [[1,2,3],[3,2,1]]
输出：true
解释：水平切割：上半部分 [1,2,3]=6，下半部分 [3,2,1]=6，总和相等。
```

**提示：**
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 100`

## 解题思路

计算前缀行和和前缀列和，枚举所有可能的水平切割和垂直切割位置。

- 水平切割位置 `i`：上半部分是第 `0` 到 `i` 行，下半部分是第 `i+1` 到 `m-1` 行
- 垂直切割位置 `j`：左半部分是第 `0` 到 `j` 列，右半部分是第 `j+1` 到 `n-1` 列

## Python 代码实现

### 方法一：前缀和枚举（推荐）

```python
from typing import List

class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)

        # 检查水平切割
        row_prefix = 0
        for i in range(m - 1):
            row_prefix += sum(grid[i])
            if row_prefix * 2 == total:
                return True

        # 检查垂直切割
        col_prefix = 0
        for j in range(n - 1):
            col_prefix += sum(grid[r][j] for r in range(m))
            if col_prefix * 2 == total:
                return True

        return False
```

### 方法二：预计算前缀和

```python
from typing import List

class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)

        # 前缀行和
        row_sums = [sum(grid[i]) for i in range(m)]
        prefix_row = 0
        for i in range(m - 1):
            prefix_row += row_sums[i]
            if 2 * prefix_row == total:
                return True

        # 前缀列和
        col_sums = [sum(grid[r][j] for r in range(m)) for j in range(n)]
        prefix_col = 0
        for j in range(n - 1):
            prefix_col += col_sums[j]
            if 2 * prefix_col == total:
                return True

        return False
```

## 复杂度分析

- 时间复杂度：O(m * n)，计算前缀和
- 空间复杂度：O(m + n)，存储行列和

## 关键点总结

1. 枚举所有 `m-1` 个水平切割位置和 `n-1` 个垂直切割位置
2. 若某切割处的前缀和等于总和的一半，则合法
3. 使用乘 2 代替除以 2，避免浮点数问题

## 易错点

1. 切割后两部分必须非空，所以行切割索引 `0` 到 `m-2`，列切割索引 `0` 到 `n-2`
2. 检查 `2 * prefix == total`，等价于 `prefix == total / 2`（避免小数）
3. 总和为奇数时，水平/垂直切割均不可能（但此时 `2 * prefix != total` 自然不满足）
