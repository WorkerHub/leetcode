## 题目描述

字符串被编码成一个矩阵（`encodedText`），按**斜线**方向读取（从左上到右下的斜线），然后按行拼接成字符串。

现在给你编码后的字符串 `encodedText` 和矩阵的**行数** `rows`，返回原始字符串 `originalText`。

**编码过程：**
- 原始字符串按行填入 `rows x cols` 矩阵
- 按每条斜线（从左上到右下）读取字符

**解码过程：** 反过来——给定编码字符串，还原原始字符串（沿斜线放回字符，去掉末尾空格）。

**提示：**
- `0 <= encodedText.length <= 10^6`
- `1 <= rows <= 1000`
- `encodedText.length % rows == 0`

## 解题思路

1. 由 `encodedText.length` 和 `rows` 计算矩阵列数 `cols = len(encodedText) // rows`
2. 将 `encodedText` 还原为矩阵（按行填充）
3. 按列从上到下读取每列（原始字符串是按列读的，不是按斜线）

**等等**，重新理解题意：
- 原始字符串按列（竖向）填入矩阵
- 按行读出得到 `encodedText`
- 解码：按列读出矩阵，去掉末尾空格

实际上是：按行写入后，按**对角线**读出编码字符串。逆过来是按行填入后按列读出。

## 代码实现

### 方法一：重建矩阵后读列（推荐）

```python
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        if rows == 1:
            return encodedText.rstrip()

        n = len(encodedText)
        cols = n // rows

        # 将 encodedText 按行还原为矩阵（行主序）
        matrix = []
        for i in range(rows):
            matrix.append(list(encodedText[i * cols:(i + 1) * cols]))

        # 按对角线（左上到右下）读取字符
        # 对角线起点：(0, 0), (0, 1), ..., (0, cols-1)
        result = []
        for start_col in range(cols):
            r, c = 0, start_col
            while r < rows and c < cols:
                result.append(matrix[r][c])
                r += 1
                c += 1

        return ''.join(result).rstrip()
```

### 方法二：索引计算（不建矩阵）

```python
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        if rows == 1:
            return encodedText.rstrip()

        cols = len(encodedText) // rows
        result = []

        # 枚举每条对角线的起始列
        for start_col in range(cols):
            r, c = 0, start_col
            while r < rows and c < cols:
                # 矩阵 (r, c) 对应 encodedText 中的索引 r * cols + c
                result.append(encodedText[r * cols + c])
                r += 1
                c += 1

        return ''.join(result).rstrip()
```

## 复杂度分析

- 时间复杂度：O(n)，n 为 encodedText 长度
- 空间复杂度：O(n)，结果字符串

## 关键点总结

1. 矩阵大小：`rows x cols`，`cols = len(encodedText) // rows`
2. 编码是按行主序存储，解码按对角线读取
3. 末尾的空格需要去掉（`rstrip()`）

## 易错点

- 当 `rows == 1` 时，矩阵只有一行，直接返回（去掉末尾空格）
- 对角线方向：从 `(r, c)` 到 `(r+1, c+1)`
- `rstrip()` 只去掉末尾空格，不去掉内部空格
