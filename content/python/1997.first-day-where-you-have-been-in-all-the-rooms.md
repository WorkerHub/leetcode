## 题目描述

你需要访问 `n` 个房间，编号 `0` 到 `n-1`。每天访问规则：
- 若当天是**奇数次**访问某房间，下次访问 `nextVisit[i]`（之前已访问的房间）
- 若当天是**偶数次**访问某房间，下次访问 `(i+1) % n`（下一个房间）

你从 0 号房间开始，第 0 次访问（算偶数次，所以第 1 次前往 1 号）。

返回你第一次进入**每个**房间的最早日期（第 0 天到达 0 号），结果对 `10^9+7` 取余。

**提示：**
- `n == nextVisit.length`
- `2 <= n <= 10^5`
- `0 <= nextVisit[i] <= i`

---

## 解题思路

### 核心思想：DP + 前缀和

设 `dp[i]` = **第一次**到达房间 `i` 的日期（天数）。

从 `dp[0] = 0` 开始，推算 `dp[i+1]`：

到达 `i` 后（第一次，奇数次），下一步去 `nextVisit[i]`（第 j 天），到达后需要再次离开 `nextVisit[i]`（偶数次）前往 `i`，这段时间 = `dp[i] - dp[nextVisit[i]]`（从 nextVisit[i] 到达 i 的距离）。

推导：
```
dp[i+1] = dp[i]        // 第一次到达 i（奇数次访问）
         + 1           // 前往 nextVisit[i]
         + (dp[i] - dp[nextVisit[i]])  // 再回到 i
         + 1           // 前往 i+1（偶数次访问）
         = 2*dp[i] - dp[nextVisit[i]] + 2
```

## 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def firstDayBeenInAllRooms(self, nextVisit: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nextVisit)
        dp = [0] * n

        for i in range(n - 1):
            # dp[i+1] = 2*dp[i] - dp[nextVisit[i]] + 2 (mod)
            dp[i + 1] = (2 * dp[i] - dp[nextVisit[i]] + 2) % MOD

        return dp[n - 1]
```

### 方法二：注释详解版

```python
from typing import List

class Solution:
    def firstDayBeenInAllRooms(self, nextVisit: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nextVisit)
        # dp[i] = 第一次到达房间 i 的日期
        dp = [0] * n

        for i in range(n - 1):
            j = nextVisit[i]  # 从 i 回退到 j
            # 第一次到 i 是第 dp[i] 天（奇数次），去 j，再从 j 返回到 i
            # 从 j 返回到 i 所需天数 = dp[i] - dp[j]（之前花的时间）
            # 再从 i 前往 i+1 需 1 天
            # dp[i+1] = dp[i] + 1 + (dp[i] - dp[j]) + 1
            #         = 2*dp[i] - dp[j] + 2
            dp[i + 1] = (2 * dp[i] - dp[j] + 2) % MOD

        return dp[n - 1]
```

## 关键点总结

1. `nextVisit[i] <= i`，因此每次回退不会越界
2. 状态转移：`dp[i+1] = 2*dp[i] - dp[nextVisit[i]] + 2`
3. 取模注意：减法后需加 MOD 防止负数（Python 取模自动处理）

---

## 易错点

- Python 的 `%` 运算对负数结果仍然正确，不需要手动 `+ MOD`
- `dp[0] = 0`（第 0 天在房间 0）
