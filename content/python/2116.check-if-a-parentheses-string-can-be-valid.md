## 题目描述

一个括号字符串是只由 `'('` 和 `')'` 组成的**非空**字符串。如果它是有效括号字符串，则：

- 它是 `()`
- 它可以写成 `AB`（A 与 B 连接），A 和 B 都是有效括号字符串。
- 它可以写成 `(A)`，A 是有效括号字符串。

给你一个括号字符串 `s` 和一个字符串 `locked`，两者长度相同。`locked` 是只含 `'0'` 和 `'1'` 的字符串：

- `locked[i] = '1'`：不能改变 `s[i]`
- `locked[i] = '0'`：可以将 `s[i]` 改为 `'('` 或 `')'`

如果可以使 `s` 变成有效括号字符串，返回 `true`，否则返回 `false`。

**示例：**
```
输入：s = "))()))", locked = "010100"
输出：true
解释：locked[1]='0', locked[3]='0'，可以将 s[1] 改为 '('，s[3] 改为 '('，得到 "()(())"。
```

**提示：**
- `1 <= s.length <= 10^5`
- `locked.length == s.length`
- `s[i]` 为 `'('` 或 `')'`
- `locked[i]` 为 `'0'` 或 `'1'`

## 解题思路

**贪心：双向扫描**

奇数长度的字符串一定不合法（括号字符串长度必须为偶数）。

**从左到右扫描：** 维护"未匹配左括号的最小和最大可能数量"（lo 和 hi）。
- 遇到 locked 为 '0'（可以任意）：lo-1（变成')'消耗一个左括号）, hi+1（变成'('增加一个左括号）。
- 遇到固定 '('：lo+1, hi+1。
- 遇到固定 ')'：lo-1, hi-1。
- 若 hi < 0（左括号不够匹配右括号），不合法。
- lo 不能为负，取 max(lo, 0)（可以用 '0' 括号来"重置"）。
- 最终 lo == 0 则合法。

## 代码实现

### 方法一：贪心区间法（推荐）

```python
class Solution:
    def canBeValid(self, s: str, locked: str) -> bool:
        n = len(s)
        # 长度为奇数，一定不合法
        if n % 2 == 1:
            return False

        # 从左到右：维护 lo（未匹配左括号最小数）和 hi（最大数）
        lo = hi = 0
        for i in range(n):
            if locked[i] == '0':
                lo -= 1  # 当作 ')' 时消耗
                hi += 1  # 当作 '(' 时增加
            elif s[i] == '(':
                lo += 1
                hi += 1
            else:  # s[i] == ')'
                lo -= 1
                hi -= 1
            if hi < 0:
                return False  # 右括号太多，无法匹配
            lo = max(lo, 0)  # lo 不能为负

        return lo == 0
```

### 方法二：双栈法

```python
class Solution:
    def canBeValid(self, s: str, locked: str) -> bool:
        n = len(s)
        if n % 2 == 1:
            return False

        # open_stack: 固定 '(' 的下标
        # free_stack: locked='0' 的下标（可任意使用）
        open_stack = []
        free_stack = []

        for i in range(n):
            if locked[i] == '0':
                free_stack.append(i)
            elif s[i] == '(':
                open_stack.append(i)
            else:  # 固定 ')'
                if open_stack:
                    open_stack.pop()  # 优先用固定 '(' 匹配
                elif free_stack:
                    free_stack.pop()  # 用可变位置匹配
                else:
                    return False

        # 剩余固定 '(' 必须用可变位置匹配（且位置必须在 '(' 右边）
        while open_stack and free_stack:
            if open_stack[-1] > free_stack[-1]:
                return False  # 可变位置在 '(' 左边，无法匹配
            open_stack.pop()
            free_stack.pop()

        return len(open_stack) == 0
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心区间 | O(n) | O(1) |
| 双栈法 | O(n) | O(n) |

## 关键点总结

1. 奇数长度字符串直接返回 false。
2. 贪心区间法：维护未匹配左括号的数量范围 `[lo, hi]`，hi < 0 时不合法，最终 lo == 0 合法。
3. 双栈法：先用固定左括号匹配固定右括号，再用可变位置；最后剩余固定左括号需要在其右侧找可变位置匹配。

## 易错点

- 贪心法中 `lo = max(lo, 0)` 很关键：lo 不能为负，因为可变位置可以被设为任何值来补充。
- 双栈法中匹配剩余左括号时，需保证可变位置在左括号**右边**（下标更大）。
