## 题目描述

给你一个数组 `points`，其中 `points[i] = [xi, yi]` 表示一个点的坐标。同时给你一个数组 `queries`，其中 `queries[j] = [xj, yj, rj]` 表示一个圆心为 `(xj, yj)`，半径为 `rj` 的圆。

对于每个查询，计算 **在圆内部或边上** 的点的数目，并返回结果数组 `answer`。

**示例：**
```
输入：points = [[1,3],[3,3],[5,3],[2,2]], queries = [[2,3,1],[4,3,1],[1,1,2]]
输出：[3,2,2]
```

**提示：**
- `1 <= points.length <= 500`
- `1 <= queries.length <= 500`
- 坐标范围 `0 <= xi, yi, xj, yj <= 500`
- `1 <= rj <= 500`

## 解题思路

**暴力枚举**：对每个查询，遍历所有点，判断每个点是否在圆内或圆上。

判断条件：`(xi - xj)^2 + (yi - yj)^2 <= rj^2`（避免浮点误差，用平方比较）

数据量较小（各最多 500），暴力 O(n * m) 可接受。

## 代码实现

### 方法一：暴力枚举（推荐，因数据量小）

```python
from typing import List

class Solution:
    def countPoints(self, points: List[List[int]], queries: List[List[int]]) -> List[int]:
        answer = []
        for xj, yj, rj in queries:
            count = 0
            for xi, yi in points:
                # 使用距离平方避免浮点误差
                if (xi - xj) ** 2 + (yi - yj) ** 2 <= rj ** 2:
                    count += 1
            answer.append(count)
        return answer
```

### 方法二：列表推导式（简化代码）

```python
from typing import List

class Solution:
    def countPoints(self, points: List[List[int]], queries: List[List[int]]) -> List[int]:
        return [
            sum(
                (xi - xj) ** 2 + (yi - yj) ** 2 <= rj ** 2
                for xi, yi in points
            )
            for xj, yj, rj in queries
        ]
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为点的数量，m 为查询数量
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. 判断点在圆内使用距离平方，避免开方带来的浮点误差
2. 数据量小（各 500），暴力枚举完全可行
3. 利用 Python 的列表推导式可以写出非常简洁的代码

## 易错点

- 条件是 `<=`（在圆内或边上），不是严格小于
- 用平方比较而非开方，避免浮点精度问题
