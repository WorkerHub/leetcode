## 题目描述

不使用任何内建的哈希表库设计一个哈希映射（HashMap）。

实现 `MyHashMap` 类：

- `MyHashMap()` 用空映射初始化对象
- `void put(int key, int value)` 向 HashMap 插入一个键值对 `(key, value)`。如果 `key` 已经存在于映射中，则更新其对应的值 `value`
- `int get(int key)` 返回特定的 `key` 所映射的 `value`；如果映射中不包含 `key` 的映射，返回 `-1`
- `void remove(key)` 如果映射中存在 `key` 的映射，则移除 `key` 和它所对应的 `value`

**示例：**
```
输入：
["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]
[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]
输出：
[null, null, null, 1, -1, null, 1, null, -1]

解释：
MyHashMap myHashMap = new MyHashMap();
myHashMap.put(1, 1); // myHashMap = [[1,1]]
myHashMap.put(2, 2); // myHashMap = [[1,1], [2,2]]
myHashMap.get(1);    // 返回 1，myHashMap = [[1,1], [2,2]]
myHashMap.get(3);    // 返回 -1（未找到），myHashMap = [[1,1], [2,2]]
myHashMap.put(2, 1); // myHashMap = [[1,1], [2,1]]（更新已有的值）
myHashMap.get(2);    // 返回 1，myHashMap = [[1,1], [2,1]]
myHashMap.remove(2); // 移除键为 2 的数据，myHashMap = [[1,1]]
myHashMap.get(2);    // 返回 -1（未找到），myHashMap = [[1,1]]
```

**提示：**
- `0 <= key, value <= 10^6`
- 最多调用 `10^4` 次 `put`、`get` 和 `remove` 方法

## 解题思路

这道题是 705 题（设计 HashSet）的升级版，需要存储键值对而不仅仅是键。

**核心差异：**
- HashSet 只存储键（key）
- HashMap 存储键值对（key-value）

**设计方案：**

1. **数组方案**：使用数组索引作为 key，数组值作为 value
   - 优点：O(1) 时间复杂度
   - 缺点：空间浪费严重（需要 10^6 空间）

2. **链地址法**：数组 + 链表
   - 每个桶存储 (key, value) 对的列表
   - 哈希冲突时，同一桶内多个键值对

3. **开放寻址法**：线性探测
   - 冲突时查找下一个空位
   - 删除操作需要特殊标记

## Python 代码实现

### 方法一：链地址法（推荐）⭐⭐

```python
class MyHashMap:
    """
    链地址法：数组 + 链表存储键值对
    """
    def __init__(self):
        self.buckets = 1009  # 使用质数减少冲突
        # 每个桶存储 [(key, value), ...] 列表
        self.table = [[] for _ in range(self.buckets)]
    
    def _hash(self, key: int) -> int:
        """哈希函数"""
        return key % self.buckets
    
    def put(self, key: int, value: int) -> None:
        """插入或更新键值对"""
        hash_key = self._hash(key)
        
        # 查找 key 是否已存在
        for i, (k, v) in enumerate(self.table[hash_key]):
            if k == key:
                # 更新已存在的 key
                self.table[hash_key][i] = (key, value)
                return
        
        # key 不存在，添加新键值对
        self.table[hash_key].append((key, value))
    
    def get(self, key: int) -> int:
        """获取 key 对应的 value"""
        hash_key = self._hash(key)
        
        # 在对应桶中查找
        for k, v in self.table[hash_key]:
            if k == key:
                return v
        
        return -1  # 未找到
    
    def remove(self, key: int) -> None:
        """移除 key 及其对应的 value"""
        hash_key = self._hash(key)
        
        # 查找并删除
        for i, (k, v) in enumerate(self.table[hash_key]):
            if k == key:
                self.table[hash_key].pop(i)
                return
```

### 方法二：使用字典优化链表

```python
class MyHashMap:
    """
    使用字典作为桶，更符合 Python 风格
    """
    def __init__(self):
        self.buckets = 1000
        self.table = [dict() for _ in range(self.buckets)]
    
    def _hash(self, key: int) -> int:
        return key % self.buckets
    
    def put(self, key: int, value: int) -> None:
        hash_key = self._hash(key)
        self.table[hash_key][key] = value
    
    def get(self, key: int) -> int:
        hash_key = self._hash(key)
        return self.table[hash_key].get(key, -1)
    
    def remove(self, key: int) -> None:
        hash_key = self._hash(key)
        if key in self.table[hash_key]:
            del self.table[hash_key][key]
```

### 方法三：固定数组（空间换时间）

```python
class MyHashMap:
    """
    直接使用固定大小数组
    适用于 key 范围已知的情况
    """
    def __init__(self):
        # -1 表示未设置
        self.data = [-1] * 1000001
    
    def put(self, key: int, value: int) -> None:
        self.data[key] = value
    
    def get(self, key: int) -> int:
        return self.data[key]
    
    def remove(self, key: int) -> None:
        self.data[key] = -1
```

### 方法四：链表节点实现（完整版）

```python
class ListNode:
    """链表节点，存储键值对"""
    def __init__(self, key: int = -1, value: int = -1):
        self.key = key
        self.value = value
        self.next = None

class MyHashMap:
    """
    使用真正的链表节点
    """
    def __init__(self):
        self.buckets = 1000
        # 使用哨兵节点简化操作
        self.table = [ListNode() for _ in range(self.buckets)]
    
    def _hash(self, key: int) -> int:
        return key % self.buckets
    
    def put(self, key: int, value: int) -> None:
        hash_key = self._hash(key)
        current = self.table[hash_key]
        
        # 遍历链表查找 key
        while current.next:
            if current.next.key == key:
                # 更新已存在的 key
                current.next.value = value
                return
            current = current.next
        
        # 未找到，添加到链表末尾
        current.next = ListNode(key, value)
    
    def get(self, key: int) -> int:
        hash_key = self._hash(key)
        current = self.table[hash_key].next
        
        while current:
            if current.key == key:
                return current.value
            current = current.next
        
        return -1
    
    def remove(self, key: int) -> None:
        hash_key = self._hash(key)
        current = self.table[hash_key]
        
        # 找到要删除节点的前驱节点
        while current.next:
            if current.next.key == key:
                current.next = current.next.next
                return
            current = current.next
```

## 复杂度分析

**方法一、二、四（链地址法）：**
- 时间复杂度：
  - 平均：O(n/b)，n 是键值对数量，b 是桶数量
  - 最坏：O(n)，所有元素哈希到同一桶
- 空间复杂度：O(n + b)

**方法三（固定数组）：**
- 时间复杂度：O(1) 所有操作
- 空间复杂度：O(max_key) = O(10^6)

## 关键点总结

1. **键值对存储**：使用元组 `(key, value)` 或自定义节点
2. **更新逻辑**：put 操作需要区分插入和更新
3. **查找优化**：使用哈希函数快速定位桶
4. **删除处理**：链表删除需要找到前驱节点
5. **哨兵节点**：简化链表头部操作

## 易错点

1. **忘记更新**：put 操作时，key 已存在需要更新而不是新增
2. **返回值错误**：get 操作未找到应返回 -1（不是 0）
3. **删除不存在的 key**：remove 操作需要先检查 key 是否存在
4. **哈希冲突处理**：同一桶内可能有多个不同的 key
5. **链表操作**：删除节点时要正确处理指针
