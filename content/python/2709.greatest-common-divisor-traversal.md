## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，你可以在数组中的数字之间自由移动，前提是你可以移动的两个数字之间 **最大公因数大于 1**。

如果可以从任意数字出发，按照上述规则 **遍历数组中的所有数字**，则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：nums = [2,3,6]
输出：true
解释：从 2 出发，gcd(2,6)=2>1，可到达 6；gcd(3,6)=3>1，可到达 3。全部连通。
```

**示例 2：**
```
输入：nums = [3,9,5]
输出：false
解释：5 与 3、9 之间 gcd 均为 1，不能到达 5。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**并查集 + 质因数分解**：

两个数之间 gcd > 1 意味着它们有公共质因数。将每个数与其所有质因数连接到并查集中：

1. 分解每个数的质因数
2. 将该数与其每个质因数在并查集中合并
3. 最终检查所有数是否在同一连通分量

这样避免了两两比较（O(n^2)），转为利用质因数作为桥梁。

## Python 代码实现

### 方法一：并查集 + 质因数（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1

class Solution:
    def canTraverseAllPairs(self, nums: List[int]) -> bool:
        n = len(nums)
        if n == 1:
            return True

        # 节点 0..n-1 表示 nums 中的数，n..n+MAX 表示质因数
        MAX = max(nums)
        uf = UnionFind(n + MAX + 1)

        for i, num in enumerate(nums):
            # 分解质因数
            d = 2
            temp = num
            while d * d <= temp:
                if temp % d == 0:
                    # 将数 i 与质因数 d 合并（质因数偏移 n）
                    uf.union(i, n + d)
                    while temp % d == 0:
                        temp //= d
                d += 1
            if temp > 1:
                uf.union(i, n + temp)

        # 检查所有数是否在同一连通分量
        root = uf.find(0)
        return all(uf.find(i) == root for i in range(n))
```

### 方法二：预处理最小质因数（线性筛）

```python
from typing import List

class Solution:
    def canTraverseAllPairs(self, nums: List[int]) -> bool:
        n = len(nums)
        if n == 1:
            return True

        MAX = max(nums)
        # 线性筛预处理最小质因数
        spf = list(range(MAX + 1))
        for i in range(2, int(MAX**0.5) + 1):
            if spf[i] == i:  # i 是质数
                for j in range(i*i, MAX+1, i):
                    if spf[j] == j:
                        spf[j] = i

        parent = list(range(n + MAX + 1))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        for i, num in enumerate(nums):
            temp = num
            while temp > 1:
                p = spf[temp]
                union(i, n + p)
                while temp % p == 0:
                    temp //= p

        root = find(0)
        return all(find(i) == root for i in range(n))
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(max(nums)))，每个数分解质因数
- 空间复杂度：O(n + max(nums))，并查集大小

## 关键点总结

1. 将质因数作为桥梁节点，避免两两比较
2. 并查集高效维护连通性
3. 数组长度为 1 时特判，直接返回 true

## 易错点

1. 质因数节点需要偏移 n，与数组元素节点区分
2. 数组中可能有 1，1 没有质因数，会孤立（若有 1 且 n>1，直接返回 false）
3. 注意 MAX 取 max(nums)，不能固定常数
