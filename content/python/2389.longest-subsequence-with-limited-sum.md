## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，和一个长度为 `m` 的整数数组 `queries`。

返回一个长度为 `m` 的数组 `answer`，其中 `answer[i]` 是 `nums` 中元素之和**不超过** `queries[i]` 的**子序列的最大长度**。

**注意：** 子序列是由数组删去某些元素（也可以不删）且不改变剩余元素位置得到的序列。

**示例 1：**
```
输入：nums = [4,5,2,1], queries = [3,10,21]
输出：[2,3,4]
解释：
- queries[0]=3：选 [2,1]，和为 3，长度为 2
- queries[1]=10：选 [4,2,1]，和为 7，长度为 3
- queries[2]=21：选全部，和为 12，长度为 4
```

**提示：**
- `n == nums.length`
- `m == queries.length`
- `1 <= n, m <= 1000`
- `1 <= nums[i], queries[i] <= 10^6`

## 解题思路

**贪心 + 排序 + 前缀和 + 二分：**

要使子序列最长且和不超过 `q`，应贪心选最小的若干元素。因此：

1. 对 `nums` 排序，计算前缀和 `prefix`。
2. 对每个 `query`，用二分查找找 `prefix` 中 `<= query` 的最大下标，该下标就是最大长度。

## 代码实现

### 方法一：排序 + 前缀和 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def answerQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        # 排序后计算前缀和
        nums.sort()
        prefix = []
        s = 0
        for x in nums:
            s += x
            prefix.append(s)
        
        result = []
        for q in queries:
            # 找最多能取多少个元素使得和 <= q
            # bisect_right 返回插入位置，即 <= q 的元素个数
            idx = bisect.bisect_right(prefix, q)
            result.append(idx)
        
        return result
```

### 方法二：暴力模拟

```python
from typing import List

class Solution:
    def answerQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        nums.sort()  # 排序，贪心选小的
        result = []
        
        for q in queries:
            total = 0
            count = 0
            for x in nums:
                if total + x <= q:
                    total += x
                    count += 1
                else:
                    break
            result.append(count)
        
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+二分 | O(n log n + m log n) | O(n) |
| 暴力模拟 | O(n log n + mn) | O(1) |

## 关键点总结

1. 贪心：要使元素个数最多，应优先选最小的元素。
2. 排序后计算前缀和，每次查询只需二分一次。
3. `bisect_right(prefix, q)` 直接给出答案（有多少个前缀和 `<= q`）。

## 易错点

- 必须先排序再计算前缀和，否则贪心不成立。
- 使用 `bisect_right` 而不是 `bisect_left`，因为允许等于 `q`。
- 前缀和数组从 `nums[0]` 开始，不包含 0，所以返回的下标即为长度。
