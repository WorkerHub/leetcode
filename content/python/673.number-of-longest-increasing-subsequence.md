## 题目描述

给定一个未排序的整数数组 nums，返回最长递增子序列的个数。

**注意：** 这个数列必须是严格递增的。

**示例 1：**
```
输入：nums = [1,3,5,4,7]
输出：2
解释：有两个最长递增子序列，长度为4：[1,3,5,7] 和 [1,3,4,7]
```

**示例 2：**
```
输入：nums = [2,2,2,2,2]
输出：5
解释：最长递增子序列的长度为1，有5个子序列（每个元素单独构成）
```

**提示：**
- 1 <= nums.length <= 2000
- -10^6 <= nums[i] <= 10^6

## 解题思路

这是经典的最长递增子序列(LIS)问题的变体，不仅要找长度，还要计数。

**核心思想：**
在 LIS 的基础上，增加一个计数数组。

**状态定义：**
- `dp[i]`：以 nums[i] 结尾的最长递增子序列长度
- `count[i]`：以 nums[i] 结尾的最长递增子序列个数

**状态转移：**
对于每个 i，遍历 j < i：
- 如果 nums[j] < nums[i]：
  - 如果 dp[j] + 1 > dp[i]：找到更长的，更新 dp[i] 和 count[i]
  - 如果 dp[j] + 1 == dp[i]：长度相同，累加 count[i]

**算法流程：**
1. 初始化 dp 和 count 数组
2. 双重循环计算 dp 和 count
3. 找到最大长度
4. 累加所有最大长度对应的 count

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def findNumberOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        
        # dp[i]: 以nums[i]结尾的最长递增子序列长度
        dp = [1] * n
        # count[i]: 以nums[i]结尾的最长递增子序列个数
        count = [1] * n
        
        for i in range(1, n):
            for j in range(i):
                if nums[j] < nums[i]:
                    if dp[j] + 1 > dp[i]:
                        # 发现更长的递增子序列
                        dp[i] = dp[j] + 1
                        count[i] = count[j]
                    elif dp[j] + 1 == dp[i]:
                        # 发现长度相同的递增子序列
                        count[i] += count[j]
        
        # 找到最长长度
        max_len = max(dp)
        
        # 累加所有最长长度的计数
        return sum(count[i] for i in range(n) if dp[i] == max_len)
```

### 方法二：带注释的详细版本

```python
class Solution:
    def findNumberOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n      # 最长递增子序列长度
        count = [1] * n   # 对应长度的个数
        
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    # nums[i] 可以接在 nums[j] 后面
                    new_len = dp[j] + 1
                    
                    if new_len > dp[i]:
                        # 找到更长的递增子序列
                        dp[i] = new_len
                        count[i] = count[j]  # 继承j的计数
                    elif new_len == dp[i]:
                        # 长度相同，累加方案数
                        count[i] += count[j]
        
        # 统计结果
        max_len = max(dp)
        result = 0
        for i in range(n):
            if dp[i] == max_len:
                result += count[i]
        
        return result
```

### 方法三：优化空间（使用字典）

```python
class Solution:
    def findNumberOfLIS(self, nums: List[int]) -> int:
        # 字典存储：长度 -> (该长度的LIS个数)
        from collections import defaultdict
        
        # dp[i] = (长度, 个数)
        dp = {}
        
        for num in nums:
            # 找到小于num的最大长度
            max_len = 0
            max_count = 1
            
            for key in dp:
                if key < num:
                    length, cnt = dp[key]
                    if length > max_len:
                        max_len = length
                        max_count = cnt
                    elif length == max_len:
                        max_count += cnt
            
            new_len = max_len + 1
            if num not in dp:
                dp[num] = (new_len, max_count)
            else:
                old_len, old_count = dp[num]
                if new_len > old_len:
                    dp[num] = (new_len, max_count)
                elif new_len == old_len:
                    dp[num] = (old_len, old_count + max_count)
        
        # 找最大长度和对应计数
        max_len = max(length for length, _ in dp.values())
        return sum(cnt for length, cnt in dp.values() if length == max_len)
```

## 复杂度分析

**方法一和方法二：**
- 时间复杂度：O(n²)，双重循环
- 空间复杂度：O(n)

**方法三：**
- 时间复杂度：O(n²)，最坏情况
- 空间复杂度：O(n)

## 关键点总结

1. **状态扩展**：在LIS基础上增加计数维度
2. **计数累加**：长度相同时累加，长度更大时重置
3. **最终统计**：收集所有最大长度位置的计数
4. **初始化**：每个元素自己构成长度为1的子序列
5. **严格递增**：条件是 nums[j] < nums[i]，不是 <=

## 易错点

1. **计数重置**：找到更长序列时要重置计数，不是累加
2. **最终统计**：要遍历所有dp[i]==max_len的位置
3. **初始值**：dp和count都初始化为1
4. **边界条件**：空数组、单元素数组等
5. **相等处理**：nums[j] == nums[i] 时不能转移
