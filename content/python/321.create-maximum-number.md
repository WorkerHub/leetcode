## 题目描述

给定长度分别为 `m` 和 `n` 的两个数组，其元素由 `0-9` 构成，表示两个自然数各位上的数字。现在从这两个数组中选出 `k (k <= m + n)` 个数字拼接成一个新的数字，要求从同一个数组中取出的数字保持其在原数组中的相对顺序。

求满足该条件的最大数。结果返回一个表示该最大数的长度为 `k` 的数组。

注意: 你应该尽可能地优化算法的时间和空间复杂度。

**示例 1:**

```
输入:
nums1 = [3, 4, 6, 5]
nums2 = [9, 1, 2, 5, 8, 3]
k = 5
输出:
[9, 8, 6, 5, 3]
```

**示例 2:**

```
输入:
nums1 = [6, 7]
nums2 = [6, 0, 4]
k = 5
输出:
[6, 7, 6, 0, 4]
```

**示例 3:**

```
输入:
nums1 = [3, 9]
nums2 = [8, 9]
k = 3
输出:
[9, 8, 9]
```

## 解题思路

这道题的核心思想是**分治 + 贪心 + 单调栈**：

1. **分解子问题**：从 `nums1` 中选 `i` 个数，从 `nums2` 中选 `k-i` 个数，其中 `max(0, k-n) <= i <= min(k, m)`
2. **单调栈求最大子序列**：对于每个数组，使用单调栈求出保持相对顺序的最大子序列
3. **合并两个序列**：将两个最大子序列按字典序合并成最大结果
4. **枚举所有情况**：遍历所有可能的分配方案，取最大值

关键算法：
- **单调栈**：从一个数组中选出 `k` 个数字，保持相对顺序且字典序最大
- **归并比较**：合并两个序列时，每次选择当前最大的元素

## Python 代码实现

### 方法一：单调栈 + 贪心合并（推荐）⭐

```python
from typing import List

class Solution:
    def maxNumber(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        """
        主函数：枚举所有可能的分配方案
        """
        m, n = len(nums1), len(nums2)
        result = []
        
        # 枚举从 nums1 中取 i 个数的所有情况
        for i in range(k + 1):
            # 确保方案合法：nums1 能取 i 个，nums2 能取 k-i 个
            if i <= m and k - i <= n:
                # 从两个数组中分别取出最大子序列
                sub1 = self.maxSubsequence(nums1, i)
                sub2 = self.maxSubsequence(nums2, k - i)
                # 合并两个子序列
                merged = self.merge(sub1, sub2)
                # 更新最大结果
                if merged > result:
                    result = merged
        
        return result
    
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        """
        使用单调栈从 nums 中选出 k 个数，保持相对顺序且字典序最大
        """
        if k == 0:
            return []
        
        stack = []
        drop = len(nums) - k  # 需要丢弃的元素个数
        
        for num in nums:
            # 当前数字比栈顶大，且还有丢弃配额，则弹出栈顶
            while stack and stack[-1] < num and drop > 0:
                stack.pop()
                drop -= 1
            stack.append(num)
        
        # 返回前 k 个元素（可能还没丢弃够）
        return stack[:k]
    
    def merge(self, nums1: List[int], nums2: List[int]) -> List[int]:
        """
        合并两个序列，每次选择字典序更大的序列的首元素
        """
        result = []
        i, j = 0, 0
        
        while i < len(nums1) and j < len(nums2):
            # 比较从当前位置开始的剩余部分，选择更大的
            if nums1[i:] > nums2[j:]:
                result.append(nums1[i])
                i += 1
            else:
                result.append(nums2[j])
                j += 1
        
        # 添加剩余元素
        result.extend(nums1[i:])
        result.extend(nums2[j:])
        
        return result
```

### 方法二：优化的合并比较

```python
from typing import List

class Solution:
    def maxNumber(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        m, n = len(nums1), len(nums2)
        result = [0] * k
        
        for i in range(k + 1):
            if i <= m and k - i <= n:
                sub1 = self.maxSubsequence(nums1, i)
                sub2 = self.maxSubsequence(nums2, k - i)
                merged = self.merge(sub1, sub2)
                result = max(result, merged)
        
        return result
    
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        if k == 0:
            return []
        
        stack = []
        to_pop = len(nums) - k
        
        for num in nums:
            while stack and stack[-1] < num and to_pop > 0:
                stack.pop()
                to_pop -= 1
            stack.append(num)
        
        return stack[:k]
    
    def merge(self, nums1: List[int], nums2: List[int]) -> List[int]:
        """
        优化的合并：使用索引比较，避免重复切片
        """
        result = []
        
        while nums1 or nums2:
            # 选择字典序更大的序列
            if nums1 > nums2:
                result.append(nums1[0])
                nums1 = nums1[1:]
            else:
                result.append(nums2[0])
                nums2 = nums2[1:]
        
        return result
```

## 复杂度分析

**方法一：单调栈 + 贪心合并**

- **时间复杂度**：O(k * (m + n)^2)
  - 外层枚举 k 种分配方案：O(k)
  - 单调栈构造子序列：O(m + n)
  - 合并两个序列：O((m + n)^2)，因为每次比较切片需要 O(m + n)
  
- **空间复杂度**：O(k)
  - 栈和结果数组的空间

**方法二优化后**：通过索引比较可以将合并优化到 O(k)，总时间复杂度降为 O(k * (m + n))

## 关键点总结

1. **分治思想**：将问题分解为从两个数组各取若干个数的子问题
2. **单调栈**：维护递减栈来构造最大子序列
3. **贪心合并**：比较两个序列的剩余部分，选择字典序更大的
4. **边界条件**：确保 `i` 和 `k-i` 都在合法范围内
5. **字典序比较**：Python 中列表可以直接比较字典序

## 易错点

1. **分配方案遗漏**：要确保 `max(0, k-n) <= i <= min(k, m)`，防止越界
2. **单调栈边界**：需要精确控制丢弃的元素个数
3. **合并时的比较**：不能简单比较首元素，要比较整个剩余序列
   - 例如 `[6, 7]` 和 `[6, 0, 4]`，虽然首元素相同，但 `[6, 7]` 更大
4. **空序列处理**：`k = 0` 或某个数组取 0 个元素的情况
5. **切片性能**：频繁切片会影响性能，可以用索引优化
