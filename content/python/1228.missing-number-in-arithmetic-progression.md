## 题目描述

在一个等差数列中有一个数字被移除，请你找出并返回这个被移除的数字。

给定一个由 `n` 个整数组成的数组 `arr`，这些整数原本是一个等差数列（即相邻两数之差都相等），但有一个数字被移除了（不是首尾的数字）。

请返回被移除的那个数字。

**示例 1：**

```
输入：arr = [5,7,11,13]
输出：9
解释：原来的数组是 [5,7,9,11,13]。
```

**示例 2：**

```
输入：arr = [15,13,12]
输出：14
解释：原来的数组是 [15,14,13,12]。
```

**提示：**

- `3 <= arr.length <= 1000`
- `0 <= arr[i] <= 10^5`
- 给定的数组保证是一个等差数列，且恰好缺少一个数字

## 解题思路

这道题有多种解法，从暴力到优化。

**核心观察：**

等差数列的性质：
- 如果没有缺失，公差 `d = (arr[n-1] - arr[0]) / n`
- 缺失一个数后，公差变成了原来的两倍出现一次

**方法对比：**

1. **数学法**：计算期望公差，遍历找缺失位置
2. **二分查找**：找到第一个不满足公差的位置
3. **求和法**：期望和 - 实际和 = 缺失值

## Python 代码实现

### 方法一：数学法（推荐）⭐

```python
from typing import List

class Solution:
    def missingNumber(self, arr: List[int]) -> int:
        """
        计算理论公差，遍历找缺失位置
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(arr)
        
        # 计算理论公差（如果没有缺失）
        # 总共应该有 n+1 个数，所以公差是总差值除以 n
        diff = (arr[-1] - arr[0]) // n
        
        # 遍历数组，找到第一个不符合公差的位置
        for i in range(n - 1):
            expected = arr[i] + diff
            if arr[i + 1] != expected:
                return expected
        
        # 理论上不会到这里
        return arr[0]
```

### 方法二：求和法

```python
from typing import List

class Solution:
    def missingNumber(self, arr: List[int]) -> int:
        """
        等差数列求和公式：sum = n * (首项 + 末项) / 2
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(arr)
        
        # 计算完整等差数列的和（n+1 个元素）
        # 首项 arr[0]，末项 arr[-1]，共 n+1 项
        expected_sum = (n + 1) * (arr[0] + arr[-1]) // 2
        
        # 计算当前数组的实际和
        actual_sum = sum(arr)
        
        # 差值就是缺失的数字
        return expected_sum - actual_sum
```

### 方法三：二分查找（优化）

```python
from typing import List

class Solution:
    def missingNumber(self, arr: List[int]) -> int:
        """
        二分查找缺失位置
        
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        n = len(arr)
        diff = (arr[-1] - arr[0]) // n
        
        left, right = 0, n - 1
        
        while left < right:
            mid = (left + right) // 2
            
            # 检查 mid 位置的期望值
            expected = arr[0] + mid * diff
            
            if arr[mid] == expected:
                # mid 之前都是正确的，缺失在右边
                left = mid + 1
            else:
                # mid 或其左边有缺失
                right = mid
        
        # left 是缺失位置，返回期望值
        return arr[0] + left * diff
```

### 方法四：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def missingNumber(self, arr: List[int]) -> int:
        """
        数学法详细解释
        """
        n = len(arr)
        
        # 步骤1：计算理论公差
        # 如果数组完整，应该有 n+1 个元素
        # 公差 = (末项 - 首项) / 项数
        # 注意：这里项数应该是 n（因为缺失了一个）
        total_diff = arr[-1] - arr[0]
        common_diff = total_diff // n
        
        # 步骤2：检查每个相邻元素对
        for i in range(n - 1):
            # 计算期望的下一个值
            expected_next = arr[i] + common_diff
            actual_next = arr[i + 1]
            
            # 如果实际值不等于期望值
            if actual_next != expected_next:
                # 缺失的就是期望值
                return expected_next
        
        # 特殊情况：缺失在最后（理论上不会发生）
        return arr[-1] + common_diff
```

## 复杂度分析

**方法一（数学法）：**
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(1)

**方法二（求和法）：**
- **时间复杂度**：O(n)，需要计算 sum
- **空间复杂度**：O(1)

**方法三（二分查找）：**
- **时间复杂度**：O(log n)，最优解
- **空间复杂度**：O(1)

## 关键点总结

1. **公差计算**：`d = (arr[n-1] - arr[0]) / n`
2. **处理负公差**：等差数列可以递减
3. **整除运算**：Python 中 `//` 是整除
4. **等差数列性质**：`arr[i] = arr[0] + i * d`
5. **多种解法**：数学、求和、二分各有优劣

## 易错点

1. **公差计算错误**：
   - 错误：`d = (arr[-1] - arr[0]) / (n - 1)`
   - 正确：`d = (arr[-1] - arr[0]) / n`（因为缺了一个数）

2. **忘记处理负数**：
   - 公差可以是负数（递减数列）
   - 使用 `//` 整除对负数也适用

3. **边界情况**：
   - 数组长度为 3 的情况
   - 缺失在开头或结尾（题目保证不会）

4. **整除 vs 除法**：
   - Python 3 中 `/` 返回浮点数
   - 应该使用 `//` 整除

5. **求和溢出**（其他语言）：
   - Python 整数无限精度，不用担心
   - 其他语言注意溢出
