## 题目描述

给你一个整数数组 `nums`。「数组值」定义为所有满足 `0 <= i < nums.length-1` 的 `|nums[i] - nums[i+1]|` 之和。

你可以选择任意子数组 `nums[i..j]`（`i < j`，包含两端），并将其反转。你只能执行这个操作一次（也可以不执行）。

请你返回执行该操作后的最大数组值。

**示例 1：**
```
输入：nums = [2,3,1,5,4]
输出：10
解释：通过翻转子数组 [3,1,5]，数组变成 [2,5,1,3,4]，数组值为 10。
```

**示例 2：**
```
输入：nums = [2,4,9,24,2,1,10]
输出：68
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

**关键数学分析：**

翻转子数组 `nums[l..r]` 后，只有 `l-1` 与 `l` 之间，以及 `r` 与 `r+1` 之间的绝对值差会改变，其余位置不变。

**原始数组值：**`S = sum(|nums[i] - nums[i+1]|)`

翻转 `[l, r]` 后，变化量 `delta = 新贡献 - 旧贡献`：
- 去掉：`|nums[l-1] - nums[l]|`（左边界贡献，如果 `l > 0`）
- 去掉：`|nums[r] - nums[r+1]|`（右边界贡献，如果 `r < n-1`）
- 加上：`|nums[l-1] - nums[r]|`（翻转后左边界）
- 加上：`|nums[l] - nums[r+1]|`（翻转后右边界）

因此：`delta = |nums[l-1] - nums[r]| + |nums[l] - nums[r+1]| - |nums[l-1] - nums[l]| - |nums[r] - nums[r+1]|`

**目标：** 最大化 `delta`，即最大化：
`|nums[l-1] - nums[r]| + |nums[l] - nums[r+1]|`

**用绝对值展开分析：**

设 `a = nums[l-1]`, `b = nums[l]`, `c = nums[r]`, `d = nums[r+1]`。

我们要最大化 `|a - c| + |b - d| - |a - b| - |c - d|`。

展开 `|a - c|` 时有 4 种情况（`+a-c`, `-a+c` 各两种），总共 `2^4 = 16` 种组合，但最终有效的只有：
- `max(0, (a-b) + (d-c))` 这种类型
- 需要遍历枚举所有 `(a, b)` 对和 `(c, d)` 对，用单调维护最大最小值

**算法（贪心 + 四种情形枚举）：**

将 `|a - c| + |b - d|` 展开后，最大化公式可以转化为维护四个量的最大值：
- `max(a + b)` 与 `min(c + d)` 的差
- `max(a - b)` 与 `min(c - d)` 的差
- `max(-a + b)` 与 `min(-c + d)` 的差
- `max(-a - b)` 与 `min(-c - d)` 的差

## Python 代码实现

### 方法一：贪心 + 数学分析（O(n)，推荐）

```python
from typing import List

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 计算原始数组值
        base = sum(abs(nums[i] - nums[i + 1]) for i in range(n - 1))
        
        # 最大增益
        gain = 0
        
        # 情形 1：翻转包含端点的子数组（l=0 或 r=n-1）
        # 翻转 [0, r]：去掉 |nums[r] - nums[r+1]|，加上 |nums[0] - nums[r+1]|
        for r in range(1, n - 1):
            gain = max(gain,
                       abs(nums[0] - nums[r + 1]) - abs(nums[r] - nums[r + 1]))
        # 翻转 [l, n-1]：去掉 |nums[l-1] - nums[l]|，加上 |nums[l-1] - nums[n-1]|
        for l in range(1, n - 1):
            gain = max(gain,
                       abs(nums[n - 1] - nums[l - 1]) - abs(nums[l] - nums[l - 1]))
        
        # 情形 2：翻转中间子数组（0 < l <= r < n-1）
        # 需要最大化 |a-c| + |b-d| - |a-b| - |c-d|
        # 其中 a=nums[l-1], b=nums[l], c=nums[r], d=nums[r+1]
        # 等价于最大化 max(a+b, -a-b, a-b, -a+b) + max(-(c+d), c+d, -(c-d), c-d)
        # 用四个变量分别维护 (a+b), (a-b), (-a+b), (-a-b) 的最大值
        # 和 (c+d), (c-d), (-c+d), (-c-d) 的最小值
        
        # 遍历所有相邻对，枚举四种符号组合
        INF = float('inf')
        for sign1, sign2 in [(1, 1), (1, -1), (-1, 1), (-1, -1)]:
            max_ab = -INF   # max(sign1 * a + sign2 * b)
            min_cd = INF    # min(sign1 * c + sign2 * d)
            for i in range(n - 1):
                a, b = nums[i], nums[i + 1]
                val = sign1 * a + sign2 * b
                max_ab = max(max_ab, val)
                min_cd = min(min_cd, val)
                # 此时 [l-1]=某个位置, [r+1]=i+1
                # 需要 l-1 < r, 即遍历时先更新 max_ab（作为 a,b），再用之前的 min_cd（作为 c,d）
            # 上面写法有问题，需要前后分离遍历
        
        # 修正：正确做法是前缀维护 max(sign1*a + sign2*b)，后缀维护 min(sign1*c + sign2*d)
        gain2 = 0
        for sign1, sign2 in [(1, 1), (1, -1), (-1, 1), (-1, -1)]:
            max_val = -INF
            for i in range(n - 1):
                a, b = nums[i], nums[i + 1]
                # (c, d) = (nums[i], nums[i+1])，(a, b) 是之前的某对
                # 当前的 (c, d) 贡献：-sign1*c - sign2*d
                gain2 = max(gain2, max_val - sign1 * a - sign2 * b)
                # 更新：将当前的 (a, b) 加入 max_val
                max_val = max(max_val, sign1 * a + sign2 * b)
        
        return base + max(gain, gain2)
```

### 方法二：暴力枚举（O(n^2)，适合理解）

```python
from typing import List

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)
        
        def array_value(arr):
            return sum(abs(arr[i] - arr[i + 1]) for i in range(len(arr) - 1))
        
        base = array_value(nums)
        result = base
        
        # 枚举所有翻转区间 [l, r]
        for l in range(n):
            for r in range(l + 1, n):
                # 翻转 [l, r]
                nums[l:r + 1] = nums[l:r + 1][::-1]
                result = max(result, array_value(nums))
                # 复原
                nums[l:r + 1] = nums[l:r + 1][::-1]
        
        return result
```

### 方法三：优化的贪心（清晰版本）

```python
from typing import List

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 原始值
        total = sum(abs(nums[i] - nums[i + 1]) for i in range(n - 1))
        
        best_gain = 0
        
        # 情形 1：翻转包含第一个或最后一个元素的子数组
        for i in range(1, n - 1):
            # 翻转 [0, i]：影响边 (i, i+1)，新边 (0, i+1)
            best_gain = max(best_gain,
                            abs(nums[0] - nums[i + 1]) - abs(nums[i] - nums[i + 1]))
            # 翻转 [i, n-1]：影响边 (i-1, i)，新边 (i-1, n-1)
            best_gain = max(best_gain,
                            abs(nums[n - 1] - nums[i - 1]) - abs(nums[i] - nums[i - 1]))
        
        # 情形 2：翻转中间部分
        # 对于相邻对 (a, b) = (nums[l-1], nums[l]) 和 (c, d) = (nums[r], nums[r+1])
        # 增益 = |a-c| + |b-d| - |a-b| - |c-d|
        # 去掉 |a-b| 和 |c-d|，最大化 |a-c| + |b-d|
        # = max(a,b) - min(a,b) 等价于将 [min(a,b), max(a,b)] 区间与另一对比较
        # 关键：若区间 [min(a,b), max(a,b)] 和 [min(c,d), max(c,d)] 不相交，增益 > 0
        
        # 枚举所有相邻对，用四个符号组合
        INF = float('inf')
        for s1, s2 in [(1, 1), (1, -1), (-1, 1), (-1, -1)]:
            cur_max = -INF
            for i in range(n - 1):
                a, b = nums[i], nums[i + 1]
                # 当前 (c,d) = (a, b)，之前维护的 max 对应 (a', b')
                best_gain = max(best_gain, cur_max - s1 * a - s2 * b)
                # 将当前作为新的 (a', b') 候选
                cur_max = max(cur_max, s1 * a + s2 * b)
        
        return total + best_gain
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/三（贪心） | O(n) | O(1) |
| 方法二（暴力） | O(n^2) | O(n) |

## 关键点总结

1. 翻转子数组只影响两个端点处的边，其余边不变
2. 增益公式 `|a-c| + |b-d| - |a-b| - |c-d|` 是核心
3. 端点情形（包含第一个或最后一个元素）可以直接枚举 O(n)
4. 中间情形需要用四种符号组合枚举最大值差
5. 整体思路：数学化简 + 贪心维护最大/最小值

## 易错点

1. 增益计算时注意区分"边界翻转"和"中间翻转"两种情形
2. 中间情形中维护 `cur_max` 时，必须在计算 `best_gain` 之后再更新（先用后更新）
3. 答案不能小于原始值（不翻转时 gain=0）
