## 题目描述

给你一个整数数组 `nums`。如果数字 `x` 满足下述条件，则认为该数字是**孤独数字**：

- `nums` 中有且仅有一个 `x`。
- 至少有一个整数在 `nums` 中**不存在**，且该整数与 `x` 的绝对差值为 1（即 `x-1` 或 `x+1` 不在 `nums` 中）。

返回 `nums` 中的**所有**孤独数字。顺序不限。

**示例 1：**
```
输入：nums = [10,6,5,8]
输出：[10,8]
解释：
- 10 只出现一次，且 9 和 11 都不在 nums 中，故 10 是孤独数字。
- 8 只出现一次，且 7 不在 nums 中，故 8 是孤独数字（9 在不在均可）。
- 6 只出现一次，但 5 在 nums 中，故 6 不是孤独数字。
- 5 只出现一次，但 6 在 nums 中，故 5 不是孤独数字。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`

## 解题思路

**哈希表计数**

用 Counter 统计每个数的出现次数。对每个数 x，若满足：
1. `count[x] == 1`（只出现一次）。
2. `count[x-1] == 0` 且 `count[x+1] == 0`（相邻整数都不存在）。

则 x 是孤独数字。

## 代码实现

### 方法一：Counter（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findLonely(self, nums: List[int]) -> List[int]:
        count = Counter(nums)
        result = []
        for x, cnt in count.items():
            # x 只出现一次，且 x-1 和 x+1 都不在 nums 中
            if cnt == 1 and count[x - 1] == 0 and count[x + 1] == 0:
                result.append(x)
        return result
```

### 方法二：排序后双指针

```python
from typing import List

class Solution:
    def findLonely(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        result = []
        for i in range(n):
            # 检查 nums[i] 是否孤独
            # 1. 只出现一次（与前后不同）
            is_unique = (i == 0 or nums[i] != nums[i-1]) and (i == n-1 or nums[i] != nums[i+1])
            # 2. 相邻整数不存在
            no_neighbor = (i == 0 or nums[i] - nums[i-1] > 1) and (i == n-1 or nums[i+1] - nums[i] > 1)
            if is_unique and no_neighbor:
                result.append(nums[i])
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter | O(n) | O(n) |
| 排序 | O(n log n) | O(1) |

## 关键点总结

1. Counter 默认对不存在的键返回 0，所以 `count[x-1] == 0` 等同于 x-1 不在 nums 中。
2. 两个条件：出现次数为 1 且相邻整数不存在。
3. 排序方法利用有序数组的特性，O(1) 额外空间。

## 易错点

- `count[x-1] == 0` 和 `x-1 not in count` 等价（Counter 的默认值为 0）。
- 孤独数字只需 `x-1` 或 `x+1` **至少一个**不存在（题目说"至少有一个"，即只要有一个不存在即可，但实际上两个都不存在才满足条件，因为 x 只出现一次，若有相邻数存在则不满足）。

等等，重新阅读题目：
- 孤独数字：只出现一次，**且**相邻整数（x-1 或 x+1）**都不在** nums 中。
