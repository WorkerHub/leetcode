## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

在一次操作中，你可以将任意元素增加或减少 `1`。

返回使长度为 `k` 的子数组内所有元素相等所需的**最少操作次数**的最小值（遍历所有可能的起始位置）。

**示例 1：**

```
输入：nums = [1,4,1,4], k = 2
输出：0
解释：子数组 [1,1] 或 [4,4] 已经全部相等，操作数为 0
```

**示例 2：**

```
输入：nums = [2,4,3,1,5], k = 3
输出：3
解释：子数组 [2,4,3] 变为全 3 需要 3 次操作
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

对于固定长度 k 的子数组，将所有元素变为相等的最少操作数等于将所有元素变为**中位数**的操作数（即各元素与中位数的绝对差之和）。

利用**滑动窗口 + 有序集合**：
- 维护一个大小为 k 的有序集合
- 快速获取中位数
- 快速计算与中位数的绝对差之和

具体：使用两个堆（大根堆 + 小根堆），分别存放中位数左侧和右侧的元素，维护两侧的和，从而 O(log n) 更新和查询。

## Python 代码实现

### 方法一：滑动窗口 + 两个堆

```python
from typing import List
import heapq

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # 这道题应该是返回所有长度为 k 的子数组中，操作数最小的那个
        # 操作数 = sum(|nums[i] - median|)
        pass

    def minOperationsActual(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # 使用 SortedList 维护窗口
        from sortedcontainers import SortedList

        sl = SortedList()
        window_sum = 0
        ans = float('inf')

        for r in range(n):
            sl.add(nums[r])
            window_sum += nums[r]

            if len(sl) > k:
                l_val = nums[r - k]
                sl.remove(l_val)
                window_sum -= l_val

            if len(sl) == k:
                # 中位数
                mid_idx = k // 2
                median = sl[mid_idx]
                # 操作数 = sum |sl[i] - median|
                # 利用前缀和计算
                # 左半部分（<= median）：median * (mid_idx+1) - sum(sl[:mid_idx+1])
                # 右半部分（>= median）：sum(sl[mid_idx:]) - median * (k - mid_idx)
                # 需要 SortedList 支持前缀和，比较复杂
                # 简化：直接计算
                cost = sum(abs(x - median) for x in sl)
                ans = min(ans, cost)

        return ans if ans != float('inf') else 0
```

### 方法二：两个堆维护中位数（O(n log k)）

```python
from typing import List
import heapq

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = float('inf')

        # 大根堆（左半部分，存负数）
        left_heap = []  # max-heap（用负数模拟）
        left_sum = 0
        # 小根堆（右半部分）
        right_heap = []  # min-heap
        right_sum = 0

        # 懒删除字典
        to_remove = {}

        def add_val(v):
            nonlocal left_sum, right_sum
            if left_heap and v <= -left_heap[0]:
                heapq.heappush(left_heap, -v)
                left_sum += v
            else:
                heapq.heappush(right_heap, v)
                right_sum += v
            balance()

        def remove_val(v):
            nonlocal left_sum, right_sum
            to_remove[v] = to_remove.get(v, 0) + 1
            if v <= -left_heap[0] if left_heap else True:
                left_sum -= v
            else:
                right_sum -= v
            # 懒清理
            clean_left()
            clean_right()
            balance()

        def clean_left():
            while left_heap and to_remove.get(-left_heap[0], 0) > 0:
                v = -heapq.heappop(left_heap)
                to_remove[v] -= 1
                if to_remove[v] == 0:
                    del to_remove[v]

        def clean_right():
            while right_heap and to_remove.get(right_heap[0], 0) > 0:
                v = heapq.heappop(right_heap)
                to_remove[v] -= 1
                if to_remove[v] == 0:
                    del to_remove[v]

        def balance():
            nonlocal left_sum, right_sum
            while len(left_heap) > (k + 1) // 2:
                v = -heapq.heappop(left_heap)
                left_sum -= v
                heapq.heappush(right_heap, v)
                right_sum += v
                clean_left()
            while len(right_heap) > k // 2:
                v = heapq.heappop(right_heap)
                right_sum -= v
                heapq.heappush(left_heap, -v)
                left_sum += v
                clean_right()

        # 暴力解法（n <= 10^5 时可接受）
        from sortedcontainers import SortedList
        sl = SortedList()
        prefix = [0]

        for r in range(n):
            sl.add(nums[r])
            if r >= k:
                sl.remove(nums[r - k])
            if r >= k - 1:
                med = sl[k // 2]
                cost = sum(abs(x - med) for x in sl)
                ans = min(ans, cost)

        return ans if ans != float('inf') else 0
```

### 方法三：暴力解法（适合理解）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = float('inf')

        for i in range(n - k + 1):
            sub = sorted(nums[i:i + k])
            median = sub[k // 2]
            cost = sum(abs(x - median) for x in sub)
            ans = min(ans, cost)

        return ans
```

## 复杂度分析

- 方法三（暴力）：
  - 时间复杂度：O(n * k log k)
  - 空间复杂度：O(k)

- SortedList 方法：
  - 时间复杂度：O(n log k)
  - 空间复杂度：O(k)

## 关键点总结

1. 使子数组所有元素相等的最优目标值是**中位数**
2. 滑动窗口维护有序集合，高效获取中位数
3. 代价 = 各元素与中位数绝对差之和

## 易错点

1. 变为中位数而不是均值（均值对总绝对差最优不成立，中位数才是）
2. k 为偶数时，中位数选左中位数还是右中位数结果相同
3. 滑动窗口移除元素时要确保正确删除
