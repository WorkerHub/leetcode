## 题目描述

给定一个 DataFrame `animals`，以方法链的方式：
1. 筛选体重超过 100 kg 的动物
2. 只保留 `name` 列
3. 按 `name` 降序排列

**示例：**
```
输入：animals DataFrame

输出：体重 > 100 的动物名字，按名字降序
```

## Python 代码实现

### 方法一：方法链（推荐）

```python
import pandas as pd

def findHeavyAnimals(animals: pd.DataFrame) -> pd.DataFrame:
    return (animals[animals['weight'] > 100]
            [['name']]
            .sort_values('name', ascending=False))
```

### 方法二：逐步操作

```python
import pandas as pd

def findHeavyAnimals(animals: pd.DataFrame) -> pd.DataFrame:
    # 过滤
    heavy = animals[animals['weight'] > 100]
    # 选列
    names = heavy[['name']]
    # 排序
    return names.sort_values('name', ascending=False)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序操作
- 空间复杂度：O(n)

## 关键点总结

1. 方法链：连续调用多个方法，代码更简洁
2. `df[df['col'] > val]` 过滤行
3. `df.sort_values('col', ascending=False)` 降序排列
