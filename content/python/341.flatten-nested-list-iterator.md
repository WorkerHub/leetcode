## 题目描述

给你一个嵌套的整数列表 `nestedList`。每个元素要么是一个整数，要么是一个列表；该列表的元素也可能是整数或者是其他列表。请你实现一个迭代器将其扁平化，使之能够遍历这个列表中的所有整数。

实现扁平迭代器类 `NestedIterator`：

- `NestedIterator(List<NestedInteger> nestedList)` 用嵌套列表 `nestedList` 初始化迭代器。
- `int next()` 返回嵌套列表的下一个整数。
- `boolean hasNext()` 如果仍然存在待迭代的整数，返回 `true`；否则，返回 `false`。

你的代码将会用下述伪代码检测：

```
initialize iterator with nestedList
res = []
while iterator.hasNext()
    append iterator.next() to the end of res
return res
```

如果 `res` 与预期的扁平化列表匹配，那么你的代码将会被判为正确。

**示例 1：**
```
输入：nestedList = [[1,1],2,[1,1]]
输出：[1,1,2,1,1]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,1,2,1,1]。
```

**示例 2：**
```
输入：nestedList = [1,[4,[6]]]
输出：[1,4,6]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,4,6]。
```

**提示：**
- `1 <= nestedList.length <= 500`
- 嵌套列表中的整数值在范围 `[-10^6, 10^6]` 内

**接口定义：**
```python
# """
# This is the interface that allows for creating nested lists.
# You should not implement it, or speculate about its implementation
# """
class NestedInteger:
    def isInteger(self) -> bool:
        """
        @return True if this NestedInteger holds a single integer, rather than a nested list.
        """
    
    def getInteger(self) -> int:
        """
        @return the single integer that this NestedInteger holds, if it holds a single integer
        Return None if this NestedInteger holds a nested list
        """
    
    def getList(self) -> [NestedInteger]:
        """
        @return the nested list that this NestedInteger holds, if it holds a nested list
        Return None if this NestedInteger holds a single integer
        """
```

## 解题思路

这道题的核心是将嵌套结构扁平化。有两种主要思路：

**思路1：预处理法（一次性扁平化）**
在初始化时就递归遍历整个嵌套列表，将所有整数提取到一个普通列表中。后续的 `next()` 和 `hasNext()` 只需要遍历这个扁平列表即可。

**思路2：惰性求值法（使用栈）**
不在初始化时扁平化，而是使用栈来模拟递归过程。每次调用 `hasNext()` 时，确保栈顶是一个整数（如果栈顶是列表，就展开它）。这种方法更符合迭代器的设计理念，在处理大规模数据时更节省内存。

**核心观察：**
1. 嵌套列表的结构类似于树，每个 `NestedInteger` 可以看作是一个节点
2. 如果是整数，就是叶子节点；如果是列表，就是内部节点
3. 扁平化就是对这棵树进行深度优先遍历（DFS）

## Python 代码实现

### 方法一：预处理法（推荐新手）

```python
class NestedIterator:
    def __init__(self, nestedList: [NestedInteger]):
        # 在初始化时就将所有整数提取出来
        self.nums = []
        self.index = 0
        
        # 递归扁平化嵌套列表
        def flatten(nested_list):
            for item in nested_list:
                if item.isInteger():
                    # 如果是整数，直接添加
                    self.nums.append(item.getInteger())
                else:
                    # 如果是列表，递归处理
                    flatten(item.getList())
        
        flatten(nestedList)
    
    def next(self) -> int:
        # 返回当前整数并移动指针
        result = self.nums[self.index]
        self.index += 1
        return result
    
    def hasNext(self) -> bool:
        # 检查是否还有未遍历的整数
        return self.index < len(self.nums)
```

**时间复杂度：**
- 初始化：O(n)，n 是所有整数的总数
- next()：O(1)
- hasNext()：O(1)

**空间复杂度：** O(n)，存储扁平化后的数组

### 方法二：惰性求值（栈实现）⭐

```python
class NestedIterator:
    def __init__(self, nestedList: [NestedInteger]):
        # 使用栈存储待处理的元素
        # 逆序入栈，确保正序出栈
        self.stack = nestedList[::-1]
    
    def next(self) -> int:
        # hasNext() 保证了栈顶一定是整数
        return self.stack.pop().getInteger()
    
    def hasNext(self) -> bool:
        # 不断展开栈顶元素，直到栈顶是整数或栈为空
        while self.stack:
            top = self.stack[-1]  # 查看栈顶
            
            if top.isInteger():
                # 栈顶是整数，返回 True
                return True
            
            # 栈顶是列表，需要展开
            self.stack.pop()  # 移除栈顶列表
            # 将列表中的元素逆序入栈
            self.stack.extend(top.getList()[::-1])
        
        # 栈为空，没有更多元素
        return False
```

**时间复杂度：**
- 初始化：O(1)
- next()：O(1)
- hasNext()：均摊 O(1)，每个元素最多被压栈和出栈各一次

**空间复杂度：** O(h)，h 是嵌套的最大深度

### 方法三：使用生成器（Python 特色）

```python
class NestedIterator:
    def __init__(self, nestedList: [NestedInteger]):
        # 使用生成器函数扁平化
        def flatten(nested_list):
            for item in nested_list:
                if item.isInteger():
                    yield item.getInteger()
                else:
                    # 递归展开
                    yield from flatten(item.getList())
        
        # 创建生成器对象
        self.gen = flatten(nestedList)
        self.next_val = None
        # 预先获取第一个值
        self._advance()
    
    def _advance(self):
        try:
            self.next_val = next(self.gen)
        except StopIteration:
            self.next_val = None
    
    def next(self) -> int:
        result = self.next_val
        self._advance()
        return result
    
    def hasNext(self) -> bool:
        return self.next_val is not None
```

## 复杂度分析

| 方法 | 初始化 | next() | hasNext() | 空间复杂度 |
|------|--------|--------|-----------|------------|
| 预处理法 | O(n) | O(1) | O(1) | O(n) |
| 栈实现 | O(1) | O(1) | 均摊 O(1) | O(h) |
| 生成器 | O(1) | 均摊 O(1) | O(1) | O(h) |

其中 n 是所有整数的总数，h 是嵌套的最大深度。

## 图解示例

以 `[[1,1],2,[1,1]]` 为例，栈实现的过程：

```
初始化栈（逆序）：
stack = [[1,1], 2, [1,1]]

第一次 hasNext():
  栈顶 [1,1] 是列表，展开
  stack = [1, 1, 2, [1,1]]
  栈顶 1 是整数，返回 true

第一次 next(): 返回 1
  stack = [1, 2, [1,1]]

第二次 hasNext():
  栈顶 1 是整数，返回 true

第二次 next(): 返回 1
  stack = [2, [1,1]]

第三次 hasNext():
  栈顶 2 是整数，返回 true

第三次 next(): 返回 2
  stack = [[1,1]]

第四次 hasNext():
  栈顶 [1,1] 是列表，展开
  stack = [1, 1]
  栈顶 1 是整数，返回 true

...依此类推
```

## 关键点总结

1. **理解接口**：需要根据 `NestedInteger` 接口来判断和获取数据
2. **栈的逆序**：为了保证正确的顺序，列表元素需要逆序入栈
3. **惰性求值**：栈实现是真正的迭代器模式，按需展开
4. **递归结构**：嵌套列表本质是递归定义的数据结构
5. **均摊复杂度**：hasNext() 虽然可能执行多步，但均摊下来是 O(1)

## 易错点

1. **栈的顺序**：忘记逆序入栈，导致输出顺序错误
   ```python
   # 错误：
   self.stack.extend(top.getList())
   
   # 正确：
   self.stack.extend(top.getList()[::-1])
   ```

2. **hasNext() 职责**：hasNext() 不仅要判断，还要确保栈顶是整数
   ```python
   # 错误：只判断栈是否为空
   def hasNext(self):
       return len(self.stack) > 0
   
   # 正确：要展开列表直到栈顶是整数
   def hasNext(self):
       while self.stack:
           if self.stack[-1].isInteger():
               return True
           self.stack.pop()
           self.stack.extend(...)
       return False
   ```

3. **空列表处理**：嵌套列表中可能有空列表 `[]`
   ```python
   # 应该能正确处理 [[], 1, []]
   # 空列表展开后不添加任何元素到栈
   ```

4. **接口调用**：不要在整数上调用 `getList()`，不要在列表上调用 `getInteger()`
