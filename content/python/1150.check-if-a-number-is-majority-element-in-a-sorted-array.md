## 题目描述

给定一个按非递减顺序排序的整数数组 `nums` 和一个整数 `target`,如果 `target` 是数组中的主要元素,则返回 `true`,否则返回 `false`。

数组中的主要元素是指出现次数严格大于 `nums.length / 2` 的元素。

**示例 1:**

```
输入: nums = [2,4,5,5,5,5,5,6,6], target = 5
输出: true
解释: 值 5 出现了 5 次,数组长度为 9。
因此,5 是主要元素,因为 5 > 9/2 为真。
```

**示例 2:**

```
输入: nums = [10,100,101,101], target = 101
输出: false
解释: 值 101 出现了 2 次,数组长度为 4。
因此,101 不是主要元素,因为 2 > 4/2 为假。
```

**提示:**
- `1 <= nums.length <= 1000`
- `1 <= nums[i], target <= 10^9`
- `nums` 已按非递减顺序排序

## 解题思路

由于数组已经排序,可以利用这个特性优化解法:

**核心观察:**
- 如果一个元素是主要元素,它必须出现超过 n/2 次
- 在有序数组中,如果某元素出现超过 n/2 次,那么从该元素第一次出现的位置 `left` 开始,向右移动 `n//2` 个位置,仍然是该元素

**解法思路:**
1. 使用二分查找找到 `target` 第一次出现的位置 `left`
2. 检查位置 `left + n//2` 是否也是 `target`
3. 如果是,说明 `target` 至少出现了 `n//2 + 1` 次,是主要元素

## Python 代码实现

### 方法一: 二分查找(推荐)

```python
from typing import List

class Solution:
    def isMajorityElement(self, nums: List[int], target: int) -> bool:
        """
        使用二分查找找到目标值第一次出现的位置
        然后检查 n//2 位置之后是否仍是该元素
        """
        n = len(nums)
        # 二分查找 target 第一次出现的位置
        left = self.findFirst(nums, target)
        
        # target 不存在于数组中
        if left == -1:
            return False
        
        # 检查从 left 开始,向右移动 n//2 个位置是否还是 target
        # 如果是,说明 target 至少出现了 n//2 + 1 次
        return left + n // 2 < n and nums[left + n // 2] == target
    
    def findFirst(self, nums: List[int], target: int) -> int:
        """二分查找目标值第一次出现的位置"""
        left, right = 0, len(nums) - 1
        result = -1
        
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                result = mid  # 记录位置
                right = mid - 1  # 继续向左查找
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```

### 方法二: 计数法(简单直观)

```python
from typing import List

class Solution:
    def isMajorityElement(self, nums: List[int], target: int) -> bool:
        """
        直接统计 target 出现的次数
        """
        count = nums.count(target)
        return count > len(nums) // 2
```

### 方法三: 使用 bisect 模块

```python
from typing import List
import bisect

class Solution:
    def isMajorityElement(self, nums: List[int], target: int) -> bool:
        """
        使用 Python 标准库的二分查找
        """
        n = len(nums)
        # bisect_left 返回 target 第一次出现的位置
        left = bisect.bisect_left(nums, target)
        
        # 检查 target 是否存在且是否为主要元素
        return left + n // 2 < n and nums[left + n // 2] == target
```

## 复杂度分析

**方法一: 二分查找**
- 时间复杂度: O(log n),二分查找的时间复杂度
- 空间复杂度: O(1),只使用常数额外空间

**方法二: 计数法**
- 时间复杂度: O(n),需要遍历整个数组统计次数
- 空间复杂度: O(1)

**方法三: bisect 模块**
- 时间复杂度: O(log n)
- 空间复杂度: O(1)

## 关键点总结

1. 利用数组已排序的特性,使用二分查找优化
2. 主要元素的判断: 出现次数 > n//2
3. 如果元素出现超过一半,从第一次出现位置向右移动 n//2 位置仍是该元素
4. 边界条件: `left + n//2 < n` 防止数组越界
5. Python 的 `bisect` 模块提供了高效的二分查找实现

## 易错点

1. 忘记检查数组越界: `left + n//2 < n`
2. 混淆 `>` 和 `>=`: 主要元素是严格大于 n/2,不是大于等于
3. 二分查找时忘记查找第一次出现的位置
4. 使用 `bisect_right` 而不是 `bisect_left`
5. 整数除法: 使用 `//` 而不是 `/`
