## 题目描述

给你一个下标从 **0** 开始的 `m x n` 整数矩阵 `grid` 和一个整数 `k`。你从起点 `(0, 0)` 出发，每一步只能往 **右** 或者往 **下**，直到到达终点 `(m - 1, n - 1)`。

返回路径和被 `k` **整除** 的路径数目，由于答案可能很大，返回答案对 `10^9 + 7` **取余** 的结果。

**示例 1：**
```
输入：grid = [[5,2,4],[3,0,5],[0,7,2]], k = 3
输出：2
```

**示例 2：**
```
输入：grid = [[0,0]], k = 5
输出：1
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 5 * 10^4`
- `1 <= m * n <= 10^5`
- `0 <= grid[i][j] <= 100`
- `1 <= k <= 50`

## 解题思路

**动态规划：**

`dp[i][j][r]` = 到达 `(i, j)` 时，路径和模 `k` 等于 `r` 的路径数目。

**转移方程：**
- 从 `(i-1, j)` 或 `(i, j-1)` 到达 `(i, j)`
- 到达时路径和模 `k` 变为 `(r + grid[i][j]) % k`

**初始条件：** `dp[0][0][grid[0][0] % k] = 1`

**优化空间：** 可以用滚动数组（只保留当前行）。

## 代码实现

### 方法一：三维 DP（推荐）

```python
from typing import List

class Solution:
    def numberOfPaths(self, grid: List[List[int]], k: int) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])

        # dp[i][j][r] = 到达 (i,j) 路径和 mod k = r 的路径数
        dp = [[[0] * k for _ in range(n)] for _ in range(m)]
        dp[0][0][grid[0][0] % k] = 1

        # 初始化第一行
        for j in range(1, n):
            for r in range(k):
                prev_r = (r - grid[0][j] % k + k) % k
                dp[0][j][r] = dp[0][j - 1][prev_r]

        # 初始化第一列
        for i in range(1, m):
            for r in range(k):
                prev_r = (r - grid[i][0] % k + k) % k
                dp[i][0][r] = dp[i - 1][0][prev_r]

        # 填充其余位置
        for i in range(1, m):
            for j in range(1, n):
                for r in range(k):
                    prev_r = (r - grid[i][j] % k + k) % k
                    dp[i][j][r] = (dp[i - 1][j][prev_r] + dp[i][j - 1][prev_r]) % MOD

        return dp[m - 1][n - 1][0]
```

### 方法二：空间优化（滚动数组）

```python
from typing import List

class Solution:
    def numberOfPaths(self, grid: List[List[int]], k: int) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])

        # 只保留当前行
        prev = [[0] * k for _ in range(n)]
        prev[0][grid[0][0] % k] = 1
        for j in range(1, n):
            for r in range(k):
                prev_r = (r - grid[0][j] % k + k) % k
                prev[j][r] = prev[j - 1][prev_r]

        for i in range(1, m):
            cur = [[0] * k for _ in range(n)]
            for r in range(k):
                prev_r = (r - grid[i][0] % k + k) % k
                cur[0][r] = prev[0][prev_r]
            for j in range(1, n):
                for r in range(k):
                    prev_r = (r - grid[i][j] % k + k) % k
                    cur[j][r] = (prev[j][prev_r] + cur[j - 1][prev_r]) % MOD
            prev = cur

        return prev[n - 1][0]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三维 DP | O(m * n * k) | O(m * n * k) |
| 滚动数组 | O(m * n * k) | O(n * k) |

## 关键点总结

1. 状态包含路径和模 k 的余数，将问题转化为余数 DP
2. 逆推前驱余数：`prev_r = (r - grid[i][j]) % k`（注意加 k 防止负数）
3. 答案是 `dp[m-1][n-1][0]`（余数为 0 的路径数）

## 易错点

- 取模时防止负数：`(r - v % k + k) % k`
- 初始化第一行和第一列要单独处理
- 答案对 10^9+7 取模
