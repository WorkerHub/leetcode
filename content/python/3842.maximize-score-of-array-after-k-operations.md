## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。你可以执行以下操作恰好 `k` 次：
1. 选择数组中的一个元素 `nums[i]`，将其加入得分。
2. 将 `nums[i]` 替换为 `ceil(nums[i] / 3)`。

返回执行 `k` 次操作后的最大总得分。

**示例 1：**

```
输入：nums = [10, 10, 10, 10, 10], k = 5
输出：50
解释：每次选最大值 10，得分 10*5=50（每次替换后 10->4->2->1->1）。
```

**示例 2：**

```
输入：nums = [1, 10, 3, 3, 3], k = 3
输出：17
解释：选 10，得 10，替换为 4；再选 10（变成 4）... 三次操作总分 17。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^5`

## 解题思路

贪心：每次选当前最大的元素加入得分。使用**最大堆**维护当前最大元素。

每次操作：
1. 弹出堆顶（最大值）加入得分。
2. 将其除以 3（向上取整）后重新入堆。

## Python 代码实现

### 方法一：最大堆贪心（推荐）

```python
from typing import List
import heapq
import math

class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        # Python 只有最小堆，用负数模拟最大堆
        heap = [-x for x in nums]
        heapq.heapify(heap)

        score = 0
        for _ in range(k):
            val = -heapq.heappop(heap)
            score += val
            # 替换为 ceil(val / 3)
            new_val = math.ceil(val / 3)
            heapq.heappush(heap, -new_val)

        return score
```

### 方法二：手动实现 ceil 避免浮点

```python
from typing import List
import heapq

class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        heap = [-x for x in nums]
        heapq.heapify(heap)

        score = 0
        for _ in range(k):
            val = -heapq.heappop(heap)
            score += val
            # ceil(val / 3) = (val + 2) // 3
            new_val = (val + 2) // 3
            heapq.heappush(heap, -new_val)

        return score
```

## 复杂度分析

- 时间复杂度：O(n + k log n)，建堆 O(n)，k 次堆操作各 O(log n)
- 空间复杂度：O(n)，堆

## 关键点总结

1. 贪心策略：每次选最大值，保证 k 次操作的总得分最大。
2. `ceil(val / 3) = (val + 2) // 3`，用整数运算避免浮点误差。
3. Python 用负数模拟最大堆是常用技巧。

## 易错点

1. `math.ceil(val / 3)` 存在浮点精度问题，推荐用 `(val + 2) // 3`。
2. 替换后的值需要重新入堆，不要遗漏。
3. k 次操作中每次都从堆中取最大值，不是从原数组。
