## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，它们的长度都是 `n`。

每次操作，你可以选择一个下标 `i`（0 <= i < n），将 `nums1[i]` 加上 `k`，同时将 `nums2[i]` 减去 `k`；或者将 `nums1[i]` 减去 `k`，同时将 `nums2[i]` 加上 `k`。

如果可以使 `nums1` 和 `nums2` 的元素和相等，返回最少操作次数；否则返回 `-1`。

**示例 1：**

```
输入：nums1 = [4,3,1,4], nums2 = [1,3,7,1], k = 3
输出：2
```

**示例 2：**

```
输入：nums1 = [3,8,5,2], nums2 = [2,4,1,6], k = 1
输出：-1
```

**提示：**

- `n == nums1.length == nums2.length`
- `2 <= n <= 10^5`
- `0 <= nums1[i], nums2[i] <= 10^9`
- `0 <= k <= 10^5`

## 解题思路

设 diff[i] = nums1[i] - nums2[i]。每次操作将某位置的 diff[i] 增加或减少 2k。

目标：使 sum(diff) = 0，即通过每次 ±2k 的调整使总差值为 0。

若 k = 0：若 sum(diff) == 0 则返回 0，否则返回 -1。

若 k > 0：sum(diff) 必须能被 2k 整除（diff[i] 只能是 2k 的倍数调整）。调整的方向由 diff[i] 决定：增加 diff 需 diff[i] < 0，减少 diff 需 diff[i] > 0。最少操作次数 = abs(sum_positive_diff) / (2k)。

## Python 代码实现

### 方法一：差值分析（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int], k: int) -> int:
        if k == 0:
            return 0 if nums1 == nums2 else -1

        total_increase = 0  # 需要增加 diff 的总量
        total_decrease = 0  # 需要减少 diff 的总量

        for a, b in zip(nums1, nums2):
            diff = a - b
            if diff % (2 * k) != 0:
                # 无法通过整数次操作使该位置差值变为某目标值
                # 每次操作改变 ±2k，diff 必须是 2k 的倍数（目标 diff 之差）
                pass
            # 若 diff > 0，需要减小（对 nums1 减 k，nums2 加 k）
            if diff > 0:
                if diff % k != 0:
                    return -1
                total_decrease += diff // k
            elif diff < 0:
                if (-diff) % k != 0:
                    return -1
                total_increase += (-diff) // k

        if total_increase != total_decrease:
            return -1

        return total_increase // 2
```

### 方法二：直接计算

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int], k: int) -> int:
        if k == 0:
            return 0 if all(a == b for a, b in zip(nums1, nums2)) else -1

        ops = 0
        for a, b in zip(nums1, nums2):
            d = a - b
            if d % k != 0:
                return -1
            if d > 0:
                ops += d // k
            # d < 0 的操作与 d > 0 的操作对应，总量必须平衡

        # 实际需要验证正操作和负操作平衡（贡献相消）
        pos = sum((a-b)//k for a,b in zip(nums1,nums2) if a > b and (a-b)%k==0)
        neg = sum((b-a)//k for a,b in zip(nums1,nums2) if b > a and (b-a)%k==0)

        # 验证所有差都能被 k 整除
        for a, b in zip(nums1, nums2):
            if (a - b) % k != 0:
                return -1

        if pos != neg:
            return -1
        return pos
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作对某位置的 (nums1[i] - nums2[i]) 增加或减少 2k
2. 要使总差为 0，所有位置的差值调整必须平衡
3. 若某位置差值不是 k 的倍数，则无解

## 易错点

1. k = 0 时特殊处理：只有 nums1 == nums2 才能返回 0
2. diff % k != 0 时直接返回 -1
3. 增量操作次数和减量操作次数必须相等（一次操作影响两个方向）
