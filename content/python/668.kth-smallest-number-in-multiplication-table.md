## 题目描述

在一个 m × n 的乘法表中，找出第 k 小的数。

乘法表中的数是由 i × j 生成的，其中 1 <= i <= m 且 1 <= j <= n。

**示例 1：**
```
输入：m = 3, n = 3, k = 5
输出：3
解释：
乘法表：
1  2  3
2  4  6
3  6  9

第5小的数是3
```

**示例 2：**
```
输入：m = 2, n = 3, k = 6
输出：6
解释：
乘法表：
1  2  3
2  4  6

第6小的数是6
```

**提示：**
- 1 <= m, n <= 3 × 10^4
- 1 <= k <= m × n

## 解题思路

直接生成整个乘法表会超时（m×n 可能达到 10^9）。需要使用二分查找。

**核心思想：**
1. 第 k 小的数一定在 [1, m×n] 范围内
2. 对于任意数 x，可以快速计算乘法表中 <= x 的数的个数
3. 使用二分查找找到最小的 x，使得 <= x 的数的个数 >= k

**计算小于等于 x 的数的个数：**
- 对于第 i 行（i × 1, i × 2, ..., i × n）
- 小于等于 x 的数有 min(x // i, n) 个
- 遍历所有行求和

**算法流程：**
1. 二分范围：left=1, right=m×n
2. 计算 mid 在表中的排名
3. 如果排名 >= k，说明答案 <= mid
4. 否则答案 > mid
5. 最终找到恰好排名为 k 的数

## Python 代码实现

### 方法一：二分查找（推荐）⭐

```python
class Solution:
    def findKthNumber(self, m: int, n: int, k: int) -> int:
        def count_less_equal(x: int) -> int:
            """计算乘法表中小于等于x的数的个数"""
            count = 0
            for i in range(1, m + 1):
                # 第i行中小于等于x的数：min(x // i, n)
                count += min(x // i, n)
            return count
        
        # 二分查找
        left, right = 1, m * n
        
        while left < right:
            mid = (left + right) // 2
            if count_less_equal(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        return left
```

### 方法二：优化的二分查找

```python
class Solution:
    def findKthNumber(self, m: int, n: int, k: int) -> int:
        def count_less_equal(x: int) -> int:
            """优化：从小的维度开始遍历"""
            count = 0
            # 确保遍历较小的维度
            if m > n:
                for j in range(1, n + 1):
                    count += min(x // j, m)
            else:
                for i in range(1, m + 1):
                    count += min(x // i, n)
            return count
        
        left, right = 1, m * n
        
        while left < right:
            mid = left + (right - left) // 2
            if count_less_equal(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        return left
```

### 方法三：带验证的版本

```python
class Solution:
    def findKthNumber(self, m: int, n: int, k: int) -> int:
        def count_less_equal(x: int) -> int:
            count = 0
            for i in range(1, m + 1):
                count += min(x // i, n)
            return count
        
        def is_in_table(x: int) -> bool:
            """验证x是否在乘法表中"""
            for i in range(1, m + 1):
                if x % i == 0 and x // i <= n:
                    return True
            return False
        
        left, right = 1, m * n
        
        while left < right:
            mid = (left + right) // 2
            if count_less_equal(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        # 确保返回的数在乘法表中
        while not is_in_table(left):
            left -= 1
        
        return left
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(m × log(m×n))，二分 log(m×n) 次，每次计数需要 O(m)
- 空间复杂度：O(1)

**优化：**
- 如果 m > n，遍历 n 行，复杂度降为 O(min(m,n) × log(m×n))

## 图解示例

以 m=3, n=3, k=5 为例：

```
乘法表：
1  2  3
2  4  6
3  6  9

排序后：1, 2, 2, 3, 3, 4, 6, 6, 9
第5小的数是3

二分过程：
left=1, right=9

mid=5:
  count(5) = min(5/1,3) + min(5/2,3) + min(5/3,3)
           = 3 + 2 + 1 = 6 >= 5
  right = 5

mid=3:
  count(3) = min(3/1,3) + min(3/2,3) + min(3/3,3)
           = 3 + 1 + 1 = 5 >= 5
  right = 3

mid=2:
  count(2) = min(2/1,3) + min(2/2,3) + min(2/3,3)
           = 2 + 1 + 0 = 3 < 5
  left = 3

返回 3
```

## 关键点总结

1. **二分查找**：在值域上二分，不是在索引上
2. **计数技巧**：快速计算小于等于某个值的元素个数
3. **边界条件**：找到第一个满足条件的值
4. **优化方向**：遍历较小的维度减少计算
5. **验证答案**：最终结果必须在乘法表中（但通常不需要显式验证）

## 易错点

1. **重复计数**：乘法表中有重复数字，但计数时会自动包含
2. **边界判断**：count(mid) >= k 时应该 right=mid，不是 mid-1
3. **整数溢出**：m×n 可能很大，但在 Python 中不是问题
4. **答案验证**：二分的结果可能不在表中（极少情况）
5. **循环条件**：使用 left < right，最后返回 left
