## 题目描述

给你一个下标从 **0** 开始且长度为 **3** 的整数数组 `amount`，其中 `amount[0]`、`amount[1]` 和 `amount[2]` 分别表示需要填充冷水、温水和热水的杯子数量。每秒钟，你可以：
- 选择**两种**不同类型的水，各填充一杯。
- 或者选择**一种**水，填充一杯。

返回将所有杯子填满所需的**最少秒数**。

**示例 1：**
```
输入：amount = [1,4,2]
输出：4
解释：第 1 秒：温水+热水；第 2 秒：温水+热水；第 3 秒：冷水+温水；第 4 秒：温水。
```

**示例 2：**
```
输入：amount = [5,4,4]
输出：7
```

**提示：**
- `amount.length == 3`
- `0 <= amount[i] <= 100`

## 解题思路

**贪心：**
每次选择最多的两种水各填充一杯，这样可以最高效地减少总量。

**数学公式：**
设三个量排序后为 `a <= b <= c`：
- 若 `c >= a + b`：答案为 `c`（最大的超过另两者之和，独立处理剩余）。
- 否则：答案为 `ceil((a + b + c) / 2)`。

## 代码实现

### 方法一：贪心公式（推荐）

```python
from typing import List
import math

class Solution:
    def fillCups(self, amount: List[int]) -> int:
        amount.sort()
        a, b, c = amount
        
        if c >= a + b:
            return c  # 最大的足够大，单独处理剩余
        else:
            return math.ceil((a + b + c) / 2)
```

### 方法二：模拟贪心

```python
from typing import List
import heapq

class Solution:
    def fillCups(self, amount: List[int]) -> int:
        time = 0
        # 用最大堆模拟
        heap = [-x for x in amount if x > 0]
        heapq.heapify(heap)
        
        while len(heap) >= 2:
            a = -heapq.heappop(heap)
            b = -heapq.heappop(heap)
            a -= 1
            b -= 1
            if a > 0:
                heapq.heappush(heap, -a)
            if b > 0:
                heapq.heappush(heap, -b)
            time += 1
        
        # 剩余的单独处理
        if heap:
            time += -heap[0]
        
        return time
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心公式 | O(1) | O(1) |
| 模拟 | O(max(amount) * log 3) | O(1) |

## 关键点总结

1. 每次同时减少两种数量最大的杯子，是最优策略。
2. 若最大值 >= 其余之和，只需等最大值被消耗完（需 c 秒）。
3. 否则，总需要 `ceil(total / 2)` 秒。

## 易错点

- 向上取整用 `math.ceil` 或 `(total + 1) // 2`。
- 注意 `c >= a + b` 的特殊情况要单独处理。
