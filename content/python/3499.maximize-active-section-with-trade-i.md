## 题目描述

给你一个二进制字符串 `s`（只含 '0' 和 '1'）。

你可以进行一次操作：将某个连续的全 '1' 段（长度至少为 1）转换为全 '0'，同时将紧邻该段的左边或右边的全 '0' 段（长度至少为 1）转换为全 '1'。

返回操作后 '1' 的最大数量。如果无法进行操作（即不存在满足条件的段对），返回原字符串中 '1' 的数量。

**示例：**

```
输入：s = "01"
输出：1
```

**示例 2：**

```
输入：s = "0100"
输出：4
解释：将 s[1]='1' 变 '0'，将 s[0]='0'(或s[2..3])变 '1'
```

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

将字符串分段，找到所有连续的 '0' 段和 '1' 段。

操作：选一个 '1' 段，将其转为 '0'，然后将相邻的 '0' 段（左或右）转为 '1'。

净变化 = 相邻 '0' 段长度 - 当前 '1' 段长度。

贪心：找净变化最大的操作（即 相邻 '0' 段尽量长，'1' 段尽量短）。

## Python 代码实现

### 方法一：分段枚举（推荐）

```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        n = len(s)
        total_ones = s.count('1')

        # 将字符串分成交替的段 (char, length)
        segments = []
        i = 0
        while i < n:
            c = s[i]
            j = i
            while j < n and s[j] == c:
                j += 1
            segments.append((c, j - i))
            i = j

        # 寻找最优操作：
        # 找相邻的 (0-段, 1-段, 0-段) 或 (0-段, 1-段) 的情况
        # 操作：把中间的 1-段变为 0，把左或右的 0-段变为 1
        # 净变化 = max(左0-段长度, 右0-段长度) - 当前1-段长度

        best_gain = 0
        m = len(segments)

        for i in range(m):
            if segments[i][0] == '1':
                ones_len = segments[i][1]
                # 检查左边的 0 段
                left_zeros = segments[i - 1][1] if i > 0 and segments[i - 1][0] == '0' else 0
                # 检查右边的 0 段
                right_zeros = segments[i + 1][1] if i + 1 < m and segments[i + 1][0] == '0' else 0

                gain = max(left_zeros, right_zeros) - ones_len
                best_gain = max(best_gain, gain)

        return total_ones + best_gain
```

### 方法二：双指针

```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        n = len(s)
        total_ones = s.count('1')

        # 找所有段
        segs = []
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            segs.append((s[i], j - i))
            i = j

        best = 0
        for idx, (c, length) in enumerate(segs):
            if c == '1':
                # 左边 0 段
                lz = segs[idx - 1][1] if idx > 0 and segs[idx - 1][0] == '0' else 0
                # 右边 0 段
                rz = segs[idx + 1][1] if idx + 1 < len(segs) and segs[idx + 1][0] == '0' else 0
                best = max(best, max(lz, rz) - length)

        return total_ones + max(0, best)
```

### 方法三：滑动窗口（0段-1段-0段）

```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        total = s.count('1')
        n = len(s)
        best_gain = 0

        i = 0
        # 找每个 pattern: 0+1+0 or 01 or 10
        while i < n:
            # 找连续 0
            if s[i] == '0':
                j = i
                while j < n and s[j] == '0':
                    j += 1
                left_zeros = j - i
                # 找连续 1
                if j < n:
                    k = j
                    while k < n and s[k] == '1':
                        k += 1
                    ones_count = k - j
                    # 找右边 0
                    if k < n and s[k] == '0':
                        l = k
                        while l < n and s[l] == '0':
                            l += 1
                        right_zeros = l - k
                        # 可以把 1 段换为 0，把最大的 0 段换为 1
                        gain = max(left_zeros, right_zeros) - ones_count
                        best_gain = max(best_gain, gain)
                    else:
                        # 只有左边 0 段
                        gain = left_zeros - ones_count
                        best_gain = max(best_gain, gain)
                i = j
            else:
                # 找连续 1，检查右边
                j = i
                while j < n and s[j] == '1':
                    j += 1
                ones_count = j - i
                if j < n and s[j] == '0':
                    k = j
                    while k < n and s[k] == '0':
                        k += 1
                    right_zeros = k - j
                    gain = right_zeros - ones_count
                    best_gain = max(best_gain, gain)
                i = j

        return total + max(0, best_gain)
```

## 复杂度分析

- 时间复杂度：O(n)，分段和遍历
- 空间复杂度：O(n)，存储段信息

## 关键点总结

1. 将字符串分段，找 1-段 和相邻 0-段
2. 操作净变化 = max(左0段, 右0段) - 1段
3. 贪心选净变化最大的操作

## 易错点

1. 1-段可能在字符串开头或结尾，相邻段不一定存在
2. 净变化可能为负（不进行操作更好），取 max(0, best_gain)
3. 操作后总 1 数 = 原来 1 数 + 净变化
