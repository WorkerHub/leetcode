## 题目描述

你和朋友玩一个叫做「翻转游戏」的游戏。游戏规则如下：

给你一个字符串 currentState，其中只包含 '+' 和 '-'。你和朋友轮流将连续的两个 "++" 反转成 "--"。当一方无法进行有效的翻转时便意味着游戏结束，另一方获胜。

请你写出一个函数来计算出第一次翻转后，字符串所有的可能状态。

**示例 1：**
```
输入：currentState = "++++"
输出：["--++","+--+","++--"]
```

**示例 2：**
```
输入：currentState = "+"
输出：[]
```

**提示：**
- 1 <= currentState.length <= 500
- currentState[i] 不是 '+' 就是 '-'

## 解题思路

这是一道简单的字符串模拟题，思路很直接：

1. 遍历字符串，找到所有连续的 "++"
2. 将每个 "++" 翻转成 "--"，生成新状态
3. 收集所有可能的新状态

**实现要点：**
- 需要检查位置 i 和 i+1 是否都是 '+'
- 字符串是不可变的，需要转换为列表或使用切片
- 注意边界条件：字符串长度小于 2 时无法翻转

## Python 代码实现

### 方法一：暴力遍历（推荐）

```python
from typing import List

class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> List[str]:
        """
        遍历所有位置，找到 ++ 就翻转
        时间复杂度：O(n^2)，n 是字符串长度
        空间复杂度：O(n)
        """
        result = []
        
        # 遍历每个可能的翻转位置
        for i in range(len(currentState) - 1):
            # 检查当前位置和下一位置是否都是 '+'
            if currentState[i] == '+' and currentState[i + 1] == '+':
                # 翻转：将 ++ 变成 --
                new_state = currentState[:i] + '--' + currentState[i + 2:]
                result.append(new_state)
        
        return result
```

### 方法二：列表操作

```python
from typing import List

class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> List[str]:
        """
        使用列表操作，更灵活
        """
        result = []
        s = list(currentState)  # 转换为列表
        
        for i in range(len(s) - 1):
            if s[i] == '+' and s[i + 1] == '+':
                # 翻转
                s[i] = s[i + 1] = '-'
                result.append(''.join(s))
                # 恢复状态
                s[i] = s[i + 1] = '+'
        
        return result
```

### 方法三：一行代码

```python
from typing import List

class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> List[str]:
        """
        Python 简洁写法
        """
        return [
            currentState[:i] + '--' + currentState[i + 2:]
            for i in range(len(currentState) - 1)
            if currentState[i:i + 2] == '++'
        ]
```

### 方法四：使用 replace（注意陷阱）

```python
from typing import List

class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> List[str]:
        """
        使用 replace 的方法（需要注意只替换一次）
        """
        result = []
        idx = 0
        
        while True:
            # 从当前位置查找 ++
            idx = currentState.find('++', idx)
            if idx == -1:
                break
            
            # 只替换这一个 ++
            new_state = currentState[:idx] + '--' + currentState[idx + 2:]
            result.append(new_state)
            idx += 1
        
        return result
```

### 方法五：正则表达式

```python
from typing import List
import re

class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> List[str]:
        """
        使用正则表达式查找所有 ++
        """
        result = []
        
        # 找到所有 ++ 的位置
        for match in re.finditer(r'\+\+', currentState):
            i = match.start()
            new_state = currentState[:i] + '--' + currentState[i + 2:]
            result.append(new_state)
        
        return result
```

## 复杂度分析

### 方法一、二、三、四：

**时间复杂度：** O(n^2)
- 外层循环遍历 n-1 个位置：O(n)
- 每次生成新字符串需要 O(n)
- 总时间复杂度：O(n^2)

**空间复杂度：** O(n)
- 结果列表最多包含 n-1 个字符串
- 每个字符串长度为 n
- 总空间：O(n^2)，但不计入输出空间的话是 O(n)

### 方法五（正则表达式）：

**时间复杂度：** O(n^2)
- 正则查找：O(n)
- 生成新字符串：O(n)
- 总体：O(n^2)

**空间复杂度：** O(n)

## 关键点总结

1. **遍历范围**：注意是 `range(len(s) - 1)`，因为需要检查两个字符
2. **字符串不可变**：Python 字符串不可变，需要用切片或转列表
3. **精确匹配**：只翻转连续的 "++"，不能只有一个 '+'
4. **所有可能性**：要找出所有位置的翻转结果，不是只找一个
5. **边界条件**：长度小于 2 的字符串无法翻转，返回空列表

## 易错点

1. **遍历范围错误**
   ```python
   # 错误：会越界
   for i in range(len(currentState)):
       if currentState[i] == '+' and currentState[i + 1] == '+':
   
   # 正确：只遍历到倒数第二个
   for i in range(len(currentState) - 1):
   ```

2. **只找一个结果**
   ```python
   # 错误：找到第一个就返回
   for i in range(len(currentState) - 1):
       if currentState[i:i+2] == '++':
           return [currentState[:i] + '--' + currentState[i+2:]]
   
   # 正确：要找所有可能
   result = []
   for i in range(len(currentState) - 1):
       if currentState[i:i+2] == '++':
           result.append(currentState[:i] + '--' + currentState[i+2:])
   return result
   ```

3. **字符串拼接错误**
   ```python
   # 错误：索引范围错误
   new_state = currentState[:i] + '--' + currentState[i+1:]
   
   # 正确：应该从 i+2 开始（因为要替换两个字符）
   new_state = currentState[:i] + '--' + currentState[i+2:]
   ```

4. **使用 replace 的陷阱**
   ```python
   # 错误：replace 会替换所有的 ++
   new_state = currentState.replace('++', '--')
   # "++++" 会变成 "----"，而不是我们要的每次只替换一个
   
   # 正确：使用切片精确控制替换位置
   new_state = currentState[:i] + '--' + currentState[i+2:]
   ```
