## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`，从某个格子出发，按顺序访问值为 1, 2, 3, ..., k 的格子（k 是 grid 中的最大值），每次移动只能走到相邻（上下左右）的格子。判断是否存在这样一条路径。

**示例 1：**

```
输入：grid = [[1,2],[4,3]]
输出：true
解释：路径 1(0,0) -> 2(0,1) -> 3(1,1) -> 4(1,0)，每步相邻，值依次为 1,2,3,4。
```

**示例 2：**

```
输入：grid = [[1,3],[2,4]]
输出：false
解释：无法从 1 依次到 2,3,4，因为 1(0,0) 和 2(1,0) 相邻，但 2(1,0) 和 3(0,1) 不相邻。
```

**提示：**
- `1 <= m, n <= 15`
- `1 <= grid[i][j] <= m*n`
- grid 是 1 到 m*n 的排列

## 解题思路

找值 1 到 k 的格子位置，依次检查相邻值是否相邻（曼哈顿距离为 1）。

只需检查：对所有 `v` 从 1 到 k-1，值为 v 和 v+1 的格子是否四连通相邻（行列差绝对值之和为 1）。

## Python 代码实现

### 方法一：直接检查相邻性（推荐）

```python
from typing import List

class Solution:
    def isPathCover(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        k = m * n

        # 找每个值对应的位置
        pos = {}
        for r in range(m):
            for c in range(n):
                pos[grid[r][c]] = (r, c)

        # 检查相邻值是否在相邻格子
        for v in range(1, k):
            r1, c1 = pos[v]
            r2, c2 = pos[v + 1]
            if abs(r1 - r2) + abs(c1 - c2) != 1:
                return False

        return True
```

### 方法二：回溯（通用解法）

```python
from typing import List

class Solution:
    def isPathCover(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        k = m * n

        # 方法一更简洁，但这里给出回溯框架
        pos = {}
        for r in range(m):
            for c in range(n):
                pos[grid[r][c]] = (r, c)

        def backtrack(v, r, c):
            if v == k + 1:
                return True
            if pos.get(v) != (r, c):
                return False
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    if backtrack(v + 1, nr, nc):
                        return True
            return v == k  # 到达最后一个值

        # 从值 1 的位置出发
        sr, sc = pos[1]
        return backtrack(1, sr, sc)
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历所有格子找位置
- 空间复杂度：O(m * n)，位置哈希表

## 关键点总结

1. 只需检查相邻值（v 和 v+1）的格子是否四连通相邻
2. 曼哈顿距离为 1 表示相邻
3. 路径唯一确定（从 1 到 k），只需验证相邻性

## 易错点

1. 验证的是格子四连通（上下左右），而非八方向
2. 值的范围是 1 到 m*n（题目保证是排列）
3. 只需验证相邻值之间的关系，不需要回溯
