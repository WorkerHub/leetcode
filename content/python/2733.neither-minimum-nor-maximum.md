## 题目描述

给你一个整数数组 `nums`，其中包含 **不同** 的正整数。

返回数组中既不是 **最小值** 也不是 **最大值** 的任意数，如果不存在这样的数，返回 `-1`。

**示例 1：**
```
输入：nums = [3,2,1,4]
输出：2
解释：最小值 1，最大值 4。2 或 3 都满足条件。
```

**示例 2：**
```
输入：nums = [1,2]
输出：-1
解释：只有两个元素，不存在满足条件的数。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `nums` 中所有值不同

## 解题思路

如果数组长度 < 3，返回 -1。否则返回排序后的第二个元素（既非最小也非最大）。

## Python 代码实现

### 方法一：排序（推荐）

```python
from typing import List

class Solution:
    def findNonMinOrMax(self, nums: List[int]) -> int:
        if len(nums) < 3:
            return -1
        # 排序后第二个既非最小也非最大
        nums.sort()
        return nums[1]
```

### 方法二：直接找最小最大后排除

```python
from typing import List

class Solution:
    def findNonMinOrMax(self, nums: List[int]) -> int:
        if len(nums) < 3:
            return -1
        mn, mx = min(nums), max(nums)
        for x in nums:
            if x != mn and x != mx:
                return x
        return -1
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n)，空间复杂度 O(1)

## 关键点总结

1. 长度小于 3 时不可能存在满足条件的数
2. 只需找一个介于最小值和最大值之间的数

## 易错点

1. 题目说元素各不相同，所以不用担心最小值等于最大值的情况
2. 返回任意一个满足条件的数即可
