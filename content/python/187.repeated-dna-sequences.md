## 题目描述

DNA 序列由一系列核苷酸组成，缩写为 `'A'`、`'C'`、`'G'` 和 `'T'`。

例如，`"ACGAATTCCG"` 是一个 DNA 序列。

在研究 DNA 时，识别 DNA 中的重复序列非常有用。

给定一个表示 DNA 序列的字符串 `s`，返回所有在 DNA 分子中出现不止一次的长度为 `10` 的序列（子字符串）。你可以按任意顺序返回答案。

**示例 1：**
```
输入：s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
输出：["AAAAACCCCC","CCCCCAAAAA"]
```

**示例 2：**
```
输入：s = "AAAAAAAAAAAAA"
输出：["AAAAAAAAAA"]
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 `'A'`、`'C'`、`'G'` 或 `'T'`

## 解题思路

这道题的核心是找出所有**重复出现**的长度为 10 的子串。

### 基本思路

使用**滑动窗口 + 哈希表**：
1. 用滑动窗口遍历所有长度为 10 的子串
2. 用哈希表记录每个子串出现的次数
3. 返回出现次数大于 1 的子串

### 优化思路

由于 DNA 只有 4 种字符（A, C, G, T），可以用**位运算**优化：
- 用 2 位二进制表示一个字符：A=00, C=01, G=10, T=11
- 10 个字符只需要 20 位（一个整数）
- 比较整数比比较字符串快得多

## Python 代码实现

### 方法一：哈希表 + 滑动窗口（推荐新手）⭐

```python
from typing import List

class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        """
        使用哈希表记录所有长度为 10 的子串
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(s)
        if n < 10:
            return []
        
        # 记录每个子串出现的次数
        seen = {}
        result = []
        
        # 滑动窗口遍历所有长度为 10 的子串
        for i in range(n - 9):
            substring = s[i:i+10]
            seen[substring] = seen.get(substring, 0) + 1
            
            # 第一次重复时加入结果（避免重复添加）
            if seen[substring] == 2:
                result.append(substring)
        
        return result
```

### 方法二：使用集合优化（简洁版）

```python
from typing import List

class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        """
        使用两个集合：一个记录见过的，一个记录重复的
        """
        if len(s) < 10:
            return []
        
        seen = set()      # 已经见过的子串
        repeated = set()  # 重复出现的子串
        
        for i in range(len(s) - 9):
            substring = s[i:i+10]
            if substring in seen:
                repeated.add(substring)
            else:
                seen.add(substring)
        
        return list(repeated)
```

### 方法三：位运算优化（进阶）⭐

```python
from typing import List

class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        """
        使用位运算将字符串编码为整数
        时间复杂度：O(n)
        空间复杂度：O(n)，但实际占用更小
        """
        if len(s) < 10:
            return []
        
        # 字符到数字的映射
        char_to_num = {'A': 0, 'C': 1, 'G': 2, 'T': 3}
        
        seen = set()
        repeated = set()
        
        # 计算第一个窗口的哈希值
        hash_value = 0
        for i in range(10):
            hash_value = (hash_value << 2) | char_to_num[s[i]]
        seen.add(hash_value)
        
        # 滑动窗口
        mask = (1 << 20) - 1  # 保留低 20 位（10 个字符 * 2 位）
        for i in range(1, len(s) - 9):
            # 移除最高位的字符，添加新字符
            hash_value = ((hash_value << 2) & mask) | char_to_num[s[i+9]]
            
            if hash_value in seen:
                repeated.add(hash_value)
            else:
                seen.add(hash_value)
        
        # 将哈希值转回字符串
        num_to_char = {0: 'A', 1: 'C', 2: 'G', 3: 'T'}
        result = []
        for hash_val in repeated:
            chars = []
            for _ in range(10):
                chars.append(num_to_char[hash_val & 3])
                hash_val >>= 2
            result.append(''.join(reversed(chars)))
        
        return result
```

### 方法四：Counter 统计（最简洁）

```python
from typing import List
from collections import Counter

class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        """
        使用 Counter 统计所有子串
        最简洁的 Python 风格
        """
        if len(s) < 10:
            return []
        
        # 生成所有长度为 10 的子串
        substrings = [s[i:i+10] for i in range(len(s) - 9)]
        
        # 统计出现次数
        counter = Counter(substrings)
        
        # 返回出现次数 > 1 的子串
        return [seq for seq, count in counter.items() if count > 1]
```

## 复杂度分析

**方法一、二、四：**
- **时间复杂度**：O(n × L)，其中 n 是字符串长度，L = 10 是子串长度。需要遍历 n - 9 个子串，每次提取子串需要 O(L)。
- **空间复杂度**：O(n × L)，最坏情况下所有子串都不同。

**方法三（位运算）：**
- **时间复杂度**：O(n)，只需要位运算，不需要提取子串。
- **空间复杂度**：O(n)，存储整数比存储字符串节省空间。

## 关键点总结

1. **滑动窗口**：固定窗口大小为 10，每次移动一位
2. **去重处理**：使用集合或判断 `count == 2` 来避免重复添加
3. **位运算优化**：将字符编码为 2 位二进制，加速比较
4. **哈希表应用**：记录子串出现次数，快速查找重复
5. **Python 技巧**：利用 Counter、列表推导式简化代码

## 易错点

1. **重复添加结果**：一个子串可能出现 3 次以上，但只应添加到结果一次
   ```python
   # 错误写法
   if substring in seen:
       result.append(substring)  # ❌ 可能重复添加
   
   # 正确写法
   if seen[substring] == 2:
       result.append(substring)  # ✅ 只在第二次出现时添加
   ```

2. **字符串长度检查**：如果字符串长度小于 10，直接返回空列表
   ```python
   if len(s) < 10:
       return []
   ```

3. **窗口边界**：循环范围是 `range(n - 9)`，而不是 `range(n)`
   ```python
   for i in range(len(s) - 9):  # ✅ 正确
   for i in range(len(s)):      # ❌ 会越界
   ```

4. **位运算的掩码**：需要用掩码保留低 20 位
   ```python
   mask = (1 << 20) - 1  # 0xFFFFF
   hash_value = ((hash_value << 2) & mask) | new_char
   ```
