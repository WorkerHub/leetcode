## 题目描述

给你一个整数数组 `piles`，`piles[i]` 是第 `i` 堆石子的数量，以及整数 `k`，代表操作次数。

每次操作：选择任一石子堆，移走其中一半（向下取整）的石子。

请你返回 `k` 次操作后剩余石子的**最小总数**。

**示例 1：**
```
输入：piles = [5, 4, 9], k = 2
输出：12
解释：操作 1：选 9，移走 4，剩 [5, 4, 5]；操作 2：选 5，移走 2，剩 [3, 4, 5]，总数 12
```

**提示：**
- `1 <= piles.length <= 10^5`
- `1 <= piles[i] <= 10^4`
- `1 <= k <= 10^5`

---

## 解题思路

### 核心思想：贪心 + 最大堆

每次操作应选最大的石子堆，可以减少最多的石子（贪心）。

使用最大堆（Python 中用负数模拟）：
1. 弹出最大值 `x`
2. 减少 `floor(x/2)`：剩余 `ceil(x/2)`
3. 将 `ceil(x/2)` 重新入堆

重复 k 次，最后求堆的总和。

---

## 代码实现

### 方法一：最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def minStoneSum(self, piles: List[int], k: int) -> int:
        # Python 只有最小堆，用负数模拟最大堆
        heap = [-x for x in piles]
        heapq.heapify(heap)

        for _ in range(k):
            x = -heapq.heappop(heap)  # 取最大值
            # 移走 floor(x/2) 个，剩余 ceil(x/2) = (x+1)//2
            remain = (x + 1) // 2
            heapq.heappush(heap, -remain)

        return -sum(heap)
```

### 方法二：计数数组（利用值域有限）

```python
from typing import List

class Solution:
    def minStoneSum(self, piles: List[int], k: int) -> int:
        MAX_VAL = 10**4 + 1
        count = [0] * MAX_VAL
        total = 0

        for x in piles:
            count[x] += 1
            total += x

        # 从大到小贪心处理
        ptr = MAX_VAL - 1
        for _ in range(k):
            while count[ptr] == 0:
                ptr -= 1
            # 处理最大值 ptr
            removed = ptr // 2
            total -= removed
            count[ptr] -= 1
            remain = ptr - removed
            count[remain] += 1

        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（堆） | O((n+k) log n) | O(n) |
| 方法二（计数） | O(n + k * MAX) | O(MAX) |

---

## 关键点总结

1. 贪心策略：每次对最大堆操作，减少量最大
2. 操作后剩余 = `ceil(x/2) = (x+1)//2`
3. 利用值域有限（≤ 10^4）时，计数数组可以 O(1) 查找最大值

---

## 易错点

- Python 的 heapq 是最小堆，需要取负值模拟最大堆
- 剩余 = `ceil(x/2)` = `(x+1)//2`，不是 `x//2`
