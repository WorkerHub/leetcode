## 题目描述

给定 `n` 个节点（编号 0 到 n-1）和双向带权边列表 `edges`，其中 `edges[i] = [u, v, w]`。求从节点 `0` 到节点 `n-1` 的最短路径，若不可达返回 `-1`。

**示例 1：**
```
输入：n = 4, edges = [[0,1,1],[1,2,2],[2,3,1],[0,3,10]]
输出：4
解释：路径 0->1->2->3，代价 1+2+1=4，比直接 0->3 的代价 10 小。
```

**示例 2：**
```
输入：n = 3, edges = [[0,1,5],[1,2,5]]
输出：10
```

**提示：**
- `2 <= n <= 300`
- `0 <= edges.length <= n*(n-1)/2`
- `1 <= w <= 100`

## 解题思路

标准的无向图最短路问题，使用 Dijkstra 算法。

由于边是双向的，建图时每条边要添加两个方向。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minCostPath(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))  # 双向边

        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0
        heap = [(0, 0)]  # (代价, 节点)

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            if u == n - 1:
                return d
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        return -1 if dist[n-1] == INF else dist[n-1]
```

### 方法二：Floyd-Warshall（适合小图）

```python
from typing import List

class Solution:
    def minCostPath(self, n: int, edges: List[List[int]]) -> int:
        INF = float('inf')
        dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            dist[i][i] = 0
        for u, v, w in edges:
            dist[u][v] = min(dist[u][v], w)
            dist[v][u] = min(dist[v][u], w)

        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        return -1 if dist[0][n-1] == INF else dist[0][n-1]
```

## 复杂度分析

- 时间复杂度：Dijkstra O((n + m) log n)；Floyd O(n^3)
- 空间复杂度：O(n + m)

## 关键点总结

1. 双向边需要在邻接表中添加两个方向
2. Dijkstra 适用于稀疏图，Floyd 适用于稠密小图
3. 不可达时返回 -1

## 易错点

1. 不要忘记添加反向边（双向边）
2. 惰性删除：弹出堆时检查 `d > dist[u]`
