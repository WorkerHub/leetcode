## 题目描述

给你一个整数数组 `start` 和一个整数 `d`，以及一个整数 `m`。

对于每个下标 i，可以选择一个整数 `x[i]`，满足 `start[i] <= x[i] <= start[i] + d`。

从 m 个下标（0 到 m-1）中各选一个 `x[i]`，要求所有选中的 `x[i]` 互不相同（严格不等）。

返回 `min(x[0], x[1], ..., x[m-1])` 的最大可能值。如果无法选出 m 个不同值，返回 -1。

**示例：**

```
输入：start = [2,3,1], d = 2, m = 2
输出：3
解释：选 x[0]=4, x[1]=3，min=3
```

**提示：**
- `1 <= m <= start.length <= 10^5`
- `0 <= start[i] <= 10^9`
- `0 <= d <= 10^9`

## 解题思路

二分答案：二分 min 值 `v`，判断是否可以从前 m 个区间各选一个 >= v 的不同整数。

可行性判断（贪心）：
- 每个区间可选 [start[i], start[i]+d] 且选的值 >= v
- 即可选范围为 [max(start[i], v), start[i]+d]
- 贪心：将区间按右端点排序，用最小的可用值填充

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, start: List[int], d: int, m: int) -> int:
        n = len(start)

        def feasible(v):
            """判断能否使所有 x[i] >= v 且互不相同"""
            # 对每个区间，可选范围是 [max(start[i], v), start[i] + d]
            intervals = []
            for i in range(m):
                lo = max(start[i], v)
                hi = start[i] + d
                if lo > hi:
                    return False  # 区间为空
                intervals.append((hi, lo))  # (右端点, 左端点)

            # 按右端点排序，贪心分配最小可用值
            intervals.sort()
            used = set()

            for hi, lo in intervals:
                # 在 [lo, hi] 中找最小未使用的整数
                val = lo
                while val in used and val <= hi:
                    val += 1
                if val > hi:
                    return False
                used.add(val)

            return True

        # 二分答案
        lo, hi = min(start), max(s + d for s in start[:m])

        if not feasible(lo):
            return -1

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：贪心优化（排序后直接分配）

```python
from typing import List

class Solution:
    def maxScore(self, start: List[int], d: int, m: int) -> int:

        def check(v):
            # 各区间右端点从小到大排序，贪心分配最小值
            rights = sorted(start[i] + d for i in range(m))
            # 用 v, v+1, v+2, ... 依次尝试分配
            cur = v
            for right in rights:
                # 需要在 [max(start_i, v), right] 中选一个值
                # 贪心：用当前最小可用值 cur
                if cur > right:
                    return False
                cur += 1  # 下一个值
            return True

        # 实际上每个区间的左端点也要满足 >= start[i]
        # 修正：需要按 (start[i], start[i]+d) 配对

        def feasible(v):
            # 生成 (右端点, 左端点) 对，按右端点排序
            pairs = sorted((start[i] + d, max(start[i], v)) for i in range(m))
            cur_val = v
            for right, left in pairs:
                if cur_val < left:
                    cur_val = left
                if cur_val > right:
                    return False
                cur_val += 1
            return True

        lo = min(start[:m])
        hi = max(start[i] + d for i in range(m))

        if not feasible(lo):
            return -1

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法三：直接贪心（不二分）

```python
from typing import List

class Solution:
    def maxScore(self, start: List[int], d: int, m: int) -> int:
        # 排序后贪心，找最优分配
        intervals = sorted((start[i], start[i] + d) for i in range(m))

        # 从最小可能的 min 值开始，贪心向右
        # 使用右端点排序后，从小到大分配递增值
        pairs = sorted((s + d, s) for s, _ in intervals)

        def check(v):
            cur = v
            for right, left in sorted((start[i] + d, max(start[i], v)) for i in range(m)):
                if cur < max(left, cur):
                    cur = max(left, cur)
                if cur > right:
                    return False
                cur += 1
            return True

        lo, hi = min(s for s, _ in intervals), max(e for _, e in intervals)

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo if check(lo) else -1
```

## 复杂度分析

- 时间复杂度：O(m log m * log(d))，二分 * 排序
- 空间复杂度：O(m)

## 关键点总结

1. 二分答案：枚举最小值 v
2. 贪心分配：按右端点排序，从小到大贪心分配递增整数
3. 当前可分配值 cur，遇到左端点约束时右移

## 易错点

1. 贪心时 cur 要从 max(left, cur) 开始，不能低于区间左端点
2. 二分上界：最大区间的右端点
3. 先检查 lo 是否可行，不可行直接返回 -1
