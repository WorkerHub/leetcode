## 题目描述

给定编号从 `0` 到 `n - 1` 的 `n` 个节点和一个无向边列表（每条边都是一对节点），请编写一个函数来计算无向图中连通分量的数目。

**示例 1:**

```
输入: n = 5, edges = [[0, 1], [1, 2], [3, 4]]
输出: 2
解释:
  0 --- 1     3
        |     |
        2     4
```

**示例 2:**

```
输入: n = 5, edges = [[0, 1], [1, 2], [2, 3], [3, 4]]
输出: 1
解释:
  0 --- 1 --- 2 --- 3 --- 4
```

**提示:**

- `1 <= n <= 2000`
- `0 <= edges.length <= 5000`
- `edges[i].length == 2`
- `0 <= ai <= bi < n`
- `ai != bi`
- `edges` 中不会出现重复的边

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题求无向图的**连通分量数目**，有三种经典解法：

### 思路一：并查集（Union-Find）

- 初始时每个节点自成一个集合，共 `n` 个连通分量
- 遍历每条边 `(u, v)`，合并 `u` 和 `v` 所在的集合
- 每次成功合并，连通分量数减 1
- 最终返回剩余的连通分量数

**优势**：代码简洁，适合动态添加边的场景

### 思路二：深度优先搜索（DFS）

- 使用邻接表存储图
- 遍历所有节点，对未访问的节点进行 DFS
- 每次 DFS 遍历一个连通分量
- DFS 次数即为连通分量数

### 思路三：广度优先搜索（BFS）

- 类似 DFS，但使用队列进行层次遍历
- 每次 BFS 遍历一个连通分量

## Python 代码实现

### 方法一：并查集（推荐）⭐

```python
from typing import List

class UnionFind:
    """并查集数据结构"""
    
    def __init__(self, n: int):
        self.parent = list(range(n))  # 初始时每个节点的父节点是自己
        self.rank = [1] * n  # 秩（树的高度）
        self.count = n  # 连通分量数
    
    def find(self, x: int) -> int:
        """查找 x 的根节点（带路径压缩）"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        """合并 x 和 y 所在的集合"""
        root_x = self.find(x)
        root_y = self.find(y)
        
        # 已经在同一集合
        if root_x == root_y:
            return False
        
        # 按秩合并：将矮树连到高树下
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
        
        self.count -= 1  # 连通分量数减 1
        return True
    
    def get_count(self) -> int:
        """返回连通分量数"""
        return self.count

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        uf = UnionFind(n)
        
        # 遍历所有边，合并节点
        for u, v in edges:
            uf.union(u, v)
        
        return uf.get_count()
```

### 方法二：深度优先搜索（DFS）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        visited = set()
        count = 0
        
        def dfs(node: int):
            """深度优先遍历一个连通分量"""
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    dfs(neighbor)
        
        # 遍历所有节点
        for i in range(n):
            if i not in visited:
                dfs(i)
                count += 1  # 每次 DFS 发现一个新的连通分量
        
        return count
```

### 方法三：广度优先搜索（BFS）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        visited = set()
        count = 0
        
        def bfs(start: int):
            """广度优先遍历一个连通分量"""
            queue = deque([start])
            visited.add(start)
            
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
        
        # 遍历所有节点
        for i in range(n):
            if i not in visited:
                bfs(i)
                count += 1
        
        return count
```

### 方法四：简化版并查集

```python
from typing import List

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        parent = list(range(n))
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        # 合并所有边
        for u, v in edges:
            root_u, root_v = find(u), find(v)
            if root_u != root_v:
                parent[root_u] = root_v
        
        # 统计根节点数量
        return sum(find(i) == i for i in range(n))
```

## 复杂度分析

**方法一：并查集**

- **时间复杂度**：O(E * α(n))
  - E：边的数量
  - α(n)：阿克曼函数的反函数，近似常数
  
- **空间复杂度**：O(n)
  - parent 和 rank 数组

**方法二/三：DFS/BFS**

- **时间复杂度**：O(n + E)
  - 遍历所有节点和边
  
- **空间复杂度**：O(n + E)
  - 邻接表 + visited 集合 + 递归栈/队列

## 关键点总结

1. **并查集适用场景**：动态连通性问题，需要频繁合并和查询
2. **路径压缩优化**：在 `find` 中将节点直接连到根节点
3. **按秩合并优化**：将矮树连到高树下，避免退化成链
4. **DFS/BFS 思想**：每次遍历发现一个连通分量
5. **图的表示**：邻接表适合稀疏图，邻接矩阵适合稠密图

## 易错点

1. **图的构建**：无向图要双向添加边 `graph[u].append(v)` 和 `graph[v].append(u)`
2. **并查集初始化**：`parent[i] = i`，每个节点初始时自成一个集合
3. **统计连通分量**：
   - 并查集：初始 `count = n`，每次合并减 1
   - DFS/BFS：每次新的遍历 `count + 1`
4. **路径压缩**：递归写法更简洁，迭代写法需要两遍循环
5. **孤立节点**：没有边的节点也算一个连通分量
