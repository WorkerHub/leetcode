## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是回文。

返回符合要求的**最少分割次数**。

**示例 1：**
```
输入: s = "aab"
输出: 1
解释: 只需一次分割就可将 s 分割成 ["aa","b"] 这样两个回文子串。
```

**示例 2：**
```
输入: s = "a"
输出: 0
```

**示例 3：**
```
输入: s = "ab"
输出: 1
```

**提示：**
- `1 <= s.length <= 2000`
- `s` 仅由小写英文字母组成

## 解题思路

这道题是 [131. 分割回文串](https://leetcode.com/problems/palindrome-partitioning/) 的进阶版，要求的是**最少分割次数**而不是所有方案。

### 核心思想：动态规划

定义 `dp[i]` 表示字符串前 `i` 个字符的最少分割次数。

### 状态转移：

对于位置 `i`，如果 `s[j:i]` 是回文串，那么：
```
dp[i] = min(dp[i], dp[j] + 1)
```

特殊情况：如果 `s[0:i]` 整体是回文串，则 `dp[i] = 0`（不需要分割）。

### 优化策略：

1. **预处理回文判断**：使用 DP 预先计算所有子串是否为回文
2. **中心扩展优化**：在计算 dp 的同时判断回文，减少空间

### 算法步骤：

1. 预处理：计算 `is_palindrome[i][j]` 表示 `s[i:j+1]` 是否为回文
2. 初始化：`dp[i] = i`（最坏情况，每个字符都分割）
3. 状态转移：枚举所有可能的分割点
4. 返回 `dp[n]`

## Python 代码实现

### 方法一：DP + 预处理回文（推荐）⭐

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        
        # 预处理：判断所有子串是否为回文
        is_palindrome = [[False] * n for _ in range(n)]
        
        # 单字符是回文
        for i in range(n):
            is_palindrome[i][i] = True
        
        # 长度为 2 的子串
        for i in range(n - 1):
            is_palindrome[i][i + 1] = (s[i] == s[i + 1])
        
        # 长度 >= 3 的子串
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                is_palindrome[i][j] = (s[i] == s[j] and is_palindrome[i + 1][j - 1])
        
        # DP：计算最少分割次数
        # dp[i] 表示 s[0:i] 的最少分割次数
        dp = [float('inf')] * (n + 1)
        dp[0] = -1  # 空字符串，分割次数为 -1（方便计算）
        
        for i in range(1, n + 1):
            # 如果 s[0:i] 整体是回文，不需要分割
            if is_palindrome[0][i - 1]:
                dp[i] = 0
            else:
                # 枚举分割点
                for j in range(1, i):
                    # 如果 s[j:i] 是回文
                    if is_palindrome[j][i - 1]:
                        dp[i] = min(dp[i], dp[j] + 1)
        
        return dp[n]
```

### 方法二：一维 DP 优化版

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        
        # 预处理回文
        is_palindrome = [[False] * n for _ in range(n)]
        
        for i in range(n):
            is_palindrome[i][i] = True
        
        for i in range(n - 1):
            is_palindrome[i][i + 1] = (s[i] == s[i + 1])
        
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                is_palindrome[i][j] = (s[i] == s[j] and is_palindrome[i + 1][j - 1])
        
        # dp[i] 表示 s[0:i+1] 的最少分割次数
        dp = [i for i in range(n)]
        
        for i in range(n):
            # 整体是回文
            if is_palindrome[0][i]:
                dp[i] = 0
                continue
            
            # 枚举分割点
            for j in range(i):
                if is_palindrome[j + 1][i]:
                    dp[i] = min(dp[i], dp[j] + 1)
        
        return dp[n - 1]
```

### 方法三：中心扩展 + DP（空间优化）

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        dp = [i for i in range(n)]
        
        for i in range(n):
            # 以 i 为中心的奇数长度回文
            left, right = i, i
            while left >= 0 and right < n and s[left] == s[right]:
                if left == 0:
                    dp[right] = 0
                else:
                    dp[right] = min(dp[right], dp[left - 1] + 1)
                left -= 1
                right += 1
            
            # 以 i, i+1 为中心的偶数长度回文
            left, right = i, i + 1
            while left >= 0 and right < n and s[left] == s[right]:
                if left == 0:
                    dp[right] = 0
                else:
                    dp[right] = min(dp[right], dp[left - 1] + 1)
                left -= 1
                right += 1
        
        return dp[n - 1]
```

### 方法四：记忆化搜索（DFS + 缓存）

```python
from functools import lru_cache

class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        
        # 预处理回文
        is_palindrome = [[False] * n for _ in range(n)]
        
        for i in range(n):
            is_palindrome[i][i] = True
        
        for i in range(n - 1):
            is_palindrome[i][i + 1] = (s[i] == s[i + 1])
        
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                is_palindrome[i][j] = (s[i] == s[j] and is_palindrome[i + 1][j - 1])
        
        @lru_cache(None)
        def dfs(start):
            # 到达末尾
            if start == n:
                return -1
            
            # 整体是回文
            if is_palindrome[start][n - 1]:
                return 0
            
            min_cuts = float('inf')
            for end in range(start, n):
                if is_palindrome[start][end]:
                    min_cuts = min(min_cuts, dfs(end + 1) + 1)
            
            return min_cuts
        
        return dfs(0)
```

### 方法五：暴力回溯（会超时，仅供理解）

```python
class Solution:
    def minCut(self, s: str) -> int:
        def is_palindrome(sub):
            return sub == sub[::-1]
        
        self.min_cuts = len(s) - 1
        
        def backtrack(start, cuts):
            if start == len(s):
                self.min_cuts = min(self.min_cuts, cuts)
                return
            
            # 剪枝：如果当前已经超过最优解，停止
            if cuts >= self.min_cuts:
                return
            
            for i in range(start, len(s)):
                if is_palindrome(s[start:i + 1]):
                    backtrack(i + 1, cuts + (1 if i + 1 < len(s) else 0))
        
        backtrack(0, 0)
        return self.min_cuts
```

## 复杂度分析

设字符串长度为 n。

### 方法一：DP + 预处理
- **时间复杂度**：O(n^2)
  - 预处理回文：O(n^2)
  - DP 计算：O(n^2)
- **空间复杂度**：O(n^2)，回文数组 + DP 数组

### 方法三：中心扩展 + DP
- **时间复杂度**：O(n^2)，每个中心最多扩展 n 次
- **空间复杂度**：O(n)，只需 DP 数组

## 关键点总结

1. **DP 定义**：`dp[i]` 表示前 `i` 个字符的最少分割次数
2. **状态转移**：枚举所有分割点，选择最小值
3. **回文预处理**：避免重复判断，提高效率
4. **初始化技巧**：`dp[0] = -1` 或 `dp[i] = i`（最坏情况）
5. **优化空间**：中心扩展法可以省略回文数组

## 易错点

1. **DP 初始值错误**
   ```python
   # 错误：初始化为 0
   dp = [0] * (n + 1)
   
   # 正确：初始化为最坏情况
   dp = [i for i in range(n)]
   ```

2. **索引错误**
   ```python
   # 注意 dp[i] 对应 s[0:i]
   # is_palindrome[i][j] 对应 s[i:j+1]
   ```

3. **边界条件**
   ```python
   # 整体是回文时，分割次数为 0
   if is_palindrome[0][i - 1]:
       dp[i] = 0
   ```

4. **回文判断范围**
   ```python
   # 错误：范围错误
   if is_palindrome[j][i]:
   
   # 正确：注意索引对应
   if is_palindrome[j][i - 1]:
   ```

5. **最优化剪枝**
   ```python
   # 回溯时要剪枝，否则超时
   if cuts >= self.min_cuts:
       return
   ```
