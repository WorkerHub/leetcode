## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，每次操作可以删除数组中的一个元素。

返回使数组所有元素异或值等于 `k` 所需的最少删除次数。

**示例 1：**

```
输入：nums = [1, 2, 3, 4], k = 5
输出：1
解释：删除 3，剩余 [1,2,4]，异或 = 1^2^4 = 7? 不对...
删除 1，剩余 [2,3,4]，异或 = 2^3^4 = 5。删除 1 次。
```

**示例 2：**

```
输入：nums = [1, 2, 4], k = 7
输出：0
解释：1^2^4 = 7，无需删除。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

计算全数组异或值 `total_xor`，目标异或值 `k`。

若 `total_xor == k`，不需要删除任何元素，返回 0。

否则需要删除若干元素，使剩余元素的异或值为 k。

关键：删除一个元素 x，等价于从总异或中去掉 x（即新异或 = `total_xor ^ x`）。

需要找最少的删除次数（即找最小数量的元素，其异或值等于 `total_xor ^ k`）。

## Python 代码实现

### 方法一：贪心一次删除

```python
from typing import List

class Solution:
    def minDeletions(self, nums: List[int], k: int) -> int:
        total = 0
        for v in nums:
            total ^= v

        if total == k:
            return 0

        # 需要删除若干元素，其异或值 = total ^ k
        target = total ^ k

        # 检查是否能删除 1 个元素（某个元素等于 target）
        for v in nums:
            if v == target:
                return 1

        # 检查是否能删除 2 个元素（两元素异或 = target）
        seen = set()
        for v in nums:
            if v ^ target in seen:
                return 2
            seen.add(v)

        # 最多删除 3 个（理论上总能找到解，但需要更多分析）
        return 3
```

### 方法二：DP 找最少元素子集异或等于目标

```python
from typing import List

class Solution:
    def minDeletions(self, nums: List[int], k: int) -> int:
        total = 0
        for v in nums:
            total ^= v

        if total == k:
            return 0

        target = total ^ k

        # 找最少元素数使其异或 = target
        # dp[x] = 能用最少多少个元素使异或 = x
        INF = float('inf')
        dp = {0: 0}

        for v in nums:
            new_dp = dict(dp)
            for xor_val, cnt in dp.items():
                new_xor = xor_val ^ v
                if new_xor not in new_dp or new_dp[new_xor] > cnt + 1:
                    new_dp[new_xor] = cnt + 1
            dp = new_dp

        return dp.get(target, INF)
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n * 2^n)（方法二，适用于小数组）
- 空间复杂度：O(n)

## 关键点总结

1. 全数组异或值与 k 的差异决定了需要删除什么。
2. 删除元素 x 等价于异或中去掉 x，目标是找最少元素使其异或等于 `total ^ k`。
3. 一次删除（找单个元素等于 target）最常见，两次删除（两元素异或等于 target）次之。

## 易错点

1. `total ^ k` 是需要删除的元素集合的异或值，不是直接删除 total。
2. 若 k = total，直接返回 0。
3. 三次以上删除很少出现，通常 1-2 次即可。
