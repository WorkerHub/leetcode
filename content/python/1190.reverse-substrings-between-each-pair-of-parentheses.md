## 题目描述

给出一个字符串 `s`（仅含有小写英文字母和括号）。

请你按照从括号内到外的顺序，逐层反转每对匹配括号中的字符串，并返回最终的结果。

注意，您的结果中不应包含任何括号。

**示例 1：**
```
输入：s = "(abcd)"
输出："dcba"
```

**示例 2：**
```
输入：s = "(u(love)i)"
输出："iloveu"
解释：先反转子字符串 "love" ，然后反转整个字符串。
```

**示例 3：**
```
输入：s = "(ed(et(oc))el)"
输出："leetcode"
解释：先反转子字符串 "oc" ，接着反转 "etco" ，然后反转整个字符串。
```

**提示：**
- `1 <= s.length <= 2000`
- `s` 中只有小写英文字母和括号
- 题目测试用例确保所有括号都是匹配的

## 解题思路

这道题的关键在于处理嵌套的括号，需要从内层到外层逐步反转。

**核心思路：**

1. **栈的应用**：使用栈来处理嵌套的括号结构。

2. **处理流程**：
   - 遇到普通字符，加入当前字符串
   - 遇到左括号 `(`，将当前字符串压入栈，开始新的一层
   - 遇到右括号 `)`，反转当前字符串，弹出栈顶字符串并拼接

3. **反转时机**：每遇到一个右括号，就反转当前层的字符串。

## Python 代码实现

### 方法一：栈 + 字符串反转（推荐）⭐

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        """
        使用栈处理括号的嵌套结构
        """
        stack = []
        current = []
        
        for char in s:
            if char == '(':
                # 遇到左括号，将当前字符串压入栈，开始新的一层
                stack.append(current)
                current = []
            elif char == ')':
                # 遇到右括号，反转当前字符串
                current.reverse()
                # 弹出上一层的字符串并拼接
                if stack:
                    current = stack.pop() + current
            else:
                # 普通字符，加入当前字符串
                current.append(char)
        
        return ''.join(current)
```

### 方法二：栈 + 字符串切片

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        """
        使用字符串而非列表，利用 Python 字符串切片
        """
        stack = ['']
        
        for char in s:
            if char == '(':
                # 将空字符串压入栈，开始新的一层
                stack.append('')
            elif char == ')':
                # 弹出当前层的字符串并反转
                top = stack.pop()
                # 反转后拼接到上一层
                stack[-1] += top[::-1]
            else:
                # 普通字符，拼接到栈顶字符串
                stack[-1] += char
        
        return stack[0]
```

### 方法三：递归解法

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        """
        递归处理括号
        """
        def helper(s: str, start: int) -> tuple:
            """
            返回：(处理后的字符串, 下一个要处理的位置)
            """
            result = []
            i = start
            
            while i < len(s):
                if s[i] == '(':
                    # 递归处理内层括号
                    sub_str, next_pos = helper(s, i + 1)
                    # 将递归结果反转后加入
                    result.append(sub_str[::-1])
                    i = next_pos
                elif s[i] == ')':
                    # 当前层结束，返回结果
                    return ''.join(result), i + 1
                else:
                    # 普通字符
                    result.append(s[i])
                    i += 1
            
            return ''.join(result), i
        
        return helper(s, 0)[0]
```

### 方法四：O(n) 时间复杂度优化解法

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        """
        使用配对信息，避免多次反转
        时间复杂度：O(n)
        """
        n = len(s)
        # 记录每个括号的配对位置
        pair = [0] * n
        stack = []
        
        # 第一步：找到所有括号的配对关系
        for i, char in enumerate(s):
            if char == '(':
                stack.append(i)
            elif char == ')':
                j = stack.pop()
                pair[i] = j
                pair[j] = i
        
        # 第二步：遍历字符串，遇到括号就跳转到配对位置
        result = []
        i = 0
        direction = 1  # 1 表示向右，-1 表示向左
        
        while i < n:
            if s[i] in '()':
                # 遇到括号，跳转到配对位置并改变方向
                i = pair[i]
                direction = -direction
            else:
                # 普通字符，加入结果
                result.append(s[i])
            
            i += direction
        
        return ''.join(result)
```

## 复杂度分析

**方法一、二、三：**
- **时间复杂度**：O(n²)，最坏情况下需要多次反转字符串
- **空间复杂度**：O(n)，栈的空间

**方法四：**
- **时间复杂度**：O(n)，只遍历字符串两次
- **空间复杂度**：O(n)，存储配对信息和结果

## 关键点总结

1. **栈的应用**：栈非常适合处理嵌套的括号结构
2. **反转时机**：遇到右括号时反转当前层的字符串
3. **层级关系**：每对括号代表一个层级，需要正确处理嵌套关系
4. **优化思路**：方法四通过预处理配对关系，避免了多次反转
5. **方向控制**：在 O(n) 解法中，通过方向变量控制遍历顺序

## 易错点

1. **忘记初始化栈**：栈应该初始化为包含一个空字符串或空列表
2. **反转后忘记拼接**：反转后要和上一层的字符串拼接
3. **括号不匹配**：虽然题目保证括号匹配，但实际应用中要注意
4. **字符串不可变**：Python 字符串是不可变的，使用列表效率更高
5. **索引越界**：在方法四中，要注意边界条件
