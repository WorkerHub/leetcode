## 题目描述

给你两个整数数组 `lane1` 和 `lane2`，代表两条车道上的硬币分布（正数表示硬币，负数表示障碍/损失）。

你驾驶一辆车，从两条车道的最左边出发，可以：
- 在同一车道前进
- 换到另一条车道（只能整体换，不能在中间某位置换）

同时你最多只能换一次车道，且只能整体换（从某个位置开始换到另一条）。

**实际简化理解**：你在 lane1 走前 `i` 步，再换到 lane2 走剩余步骤（或整个在 lane1，或整个在 lane2），最大化总硬币。

**示例：**

```
输入：lane1 = [1,-1,-1,1], lane2 = [-1,1,1,-1]
输出：5
解释：在 lane1 走前 1 个（得1），换到 lane2 走后 3 个（得1+1-1=1）... 
```

**提示：**
- `1 <= lane1.length == lane2.length <= 10^5`
- `-10^3 <= lane1[i], lane2[i] <= 10^3`

## 解题思路

DP：定义 `dp[i][j]` 为走到位置 i，在车道 j（0 或 1），且最多换一次车道的最大收益。

状态：
- `dp0[i][j]`：走到位置 i，在车道 j，还没换过车道的最大收益
- `dp1[i][j]`：走到位置 i，在车道 j，已经换过一次车道的最大收益

转移：
- 不换道：`dp0[i][j] = dp0[i-1][j] + lanes[j][i]`
- 换道（第一次）：`dp1[i][j] = dp0[i-1][1-j] + lanes[j][i]`
- 已换道后继续：`dp1[i][j] = dp1[i-1][j] + lanes[j][i]`

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxCoins(self, lane1: List[int], lane2: List[int]) -> int:
        n = len(lane1)
        lanes = [lane1, lane2]
        NEG_INF = float('-inf')

        # dp_no_switch[j]: 在车道 j，未换过车道的最大收益
        # dp_switched[j]: 在车道 j，已换过一次车道的最大收益
        dp_ns = [NEG_INF, NEG_INF]  # 未换道
        dp_sw = [NEG_INF, NEG_INF]  # 已换道

        # 初始：从任意车道开始（位置 0）
        dp_ns[0] = lanes[0][0]
        dp_ns[1] = lanes[1][0]
        # 初始位置换道：从车道 0 换到 1，或 1 换到 0（在位置 0 换道，等于直接在另一车道）
        dp_sw[0] = lanes[0][0]  # 初始就在车道 0（相当于换道后在 0）
        dp_sw[1] = lanes[1][0]

        ans = max(dp_ns[0], dp_ns[1], dp_sw[0], dp_sw[1])

        for i in range(1, n):
            new_ns = [NEG_INF, NEG_INF]
            new_sw = [NEG_INF, NEG_INF]

            for j in range(2):
                # 继续在车道 j（未换道）
                if dp_ns[j] != NEG_INF:
                    new_ns[j] = max(new_ns[j], dp_ns[j] + lanes[j][i])

                # 在位置 i 换道（第一次）：从 1-j 换到 j
                if dp_ns[1 - j] != NEG_INF:
                    new_sw[j] = max(new_sw[j], dp_ns[1 - j] + lanes[j][i])

                # 已换道后继续在车道 j
                if dp_sw[j] != NEG_INF:
                    new_sw[j] = max(new_sw[j], dp_sw[j] + lanes[j][i])

            dp_ns, dp_sw = new_ns, new_sw
            ans = max(ans, max(dp_ns), max(dp_sw))

        return ans
```

### 方法二：四状态 DP

```python
from typing import List

class Solution:
    def maxCoins(self, lane1: List[int], lane2: List[int]) -> int:
        n = len(lane1)
        NEG_INF = float('-inf')

        # 状态：(当前车道, 是否已换道)
        # dp[j][s]: 在车道 j，换道状态 s（0=未换，1=已换）
        dp = [[NEG_INF] * 2 for _ in range(2)]

        # 初始化
        dp[0][0] = lane1[0]
        dp[1][0] = lane2[0]

        ans = max(lane1[0], lane2[0])

        for i in range(1, n):
            new_dp = [[NEG_INF] * 2 for _ in range(2)]
            v = [lane1[i], lane2[i]]

            for j in range(2):
                # 继续不换道
                if dp[j][0] != NEG_INF:
                    new_dp[j][0] = max(new_dp[j][0], dp[j][0] + v[j])
                # 此时换道（第一次）
                if dp[1-j][0] != NEG_INF:
                    new_dp[j][1] = max(new_dp[j][1], dp[1-j][0] + v[j])
                # 已换道后继续
                if dp[j][1] != NEG_INF:
                    new_dp[j][1] = max(new_dp[j][1], dp[j][1] + v[j])

            dp = new_dp
            for j in range(2):
                for s in range(2):
                    if dp[j][s] != NEG_INF:
                        ans = max(ans, dp[j][s])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（滚动数组）

## 关键点总结

1. 两个状态维度：当前车道 + 是否已换道
2. 换道只能发生一次，换道后状态从"未换"转为"已换"
3. 目标：最大化总收益

## 易错点

1. 初始可以在任意车道出发（都是"未换道"状态）
2. 在位置 0 就可以"换道"（选择从另一个车道开始）
3. 答案要取所有状态中的最大值
