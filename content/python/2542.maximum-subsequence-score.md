## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，两者长度都是 `n`，以及一个正整数 `k`。

你必须从 `nums1` 中选出一个长度为 `k` 的 **子序列**（可以是任意 k 个下标）。

对于选出的下标集合 `S`（大小为 k），得分定义为：
- `sum(nums1[S]) * min(nums2[S])`
- 即选中的 nums1 值之和乘以选中的 nums2 值中的最小值

返回能得到的 **最大得分**。

**示例 1：**

```
输入：nums1 = [1,3,3,2], nums2 = [2,1,3,3], k = 3
输出：12
解释：选下标 0,2,3，score = (1+3+2) * min(2,3,3) = 6 * 2 = 12。
```

**提示：**

- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `0 <= nums1[i], nums2[i] <= 10^5`
- `1 <= k <= n`

## 解题思路

**贪心 + 最小堆**：

枚举 `nums2` 中的最小值（按 nums2 降序枚举，保证最小值为当前枚举位置的 nums2 值）。

维护一个大小为 k 的最小堆，存储当前选中的 nums1 值。当枚举到位置 i 时：
- 将 nums1[i] 加入堆，若堆大小超过 k，弹出最小值
- 当堆大小 == k 时，计算得分 = 堆中元素和 * nums2[i]

## Python 代码实现

### 方法一：贪心 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxScore(self, nums1: List[int], nums2: List[int], k: int) -> int:
        # 按 nums2 降序排列
        pairs = sorted(zip(nums1, nums2), key=lambda x: -x[1])

        # 最小堆维护大小为 k 的 nums1 子集
        heap = []
        cur_sum = 0
        ans = 0

        for n1, n2 in pairs:
            # 加入当前 n1
            heapq.heappush(heap, n1)
            cur_sum += n1

            # 维护堆大小为 k
            if len(heap) > k:
                cur_sum -= heapq.heappop(heap)

            # 此时 n2 是当前选中元素中的最小 nums2 值
            if len(heap) == k:
                ans = max(ans, cur_sum * n2)

        return ans
```

### 方法二：排序后枚举最小值

```python
from typing import List
import heapq

class Solution:
    def maxScore(self, nums1: List[int], nums2: List[int], k: int) -> int:
        n = len(nums1)
        # 按 nums2 降序，枚举每个位置作为 min(nums2[S])
        indices = sorted(range(n), key=lambda i: -nums2[i])

        min_heap = []  # 最小堆
        total = 0
        best = 0

        for i in indices:
            heapq.heappush(min_heap, nums1[i])
            total += nums1[i]

            if len(min_heap) > k:
                total -= heapq.heappop(min_heap)

            if len(min_heap) == k:
                # nums2[i] 是所有已选中下标中 nums2 的最小值（因为按降序枚举）
                best = max(best, total * nums2[i])

        return best
```

## 复杂度分析

- 时间复杂度：O(n log n + n log k)，排序 + 堆操作
- 空间复杂度：O(k)，堆的大小

## 关键点总结

1. 按 nums2 降序枚举，保证当前枚举位置的 nums2 是"最小值"
2. 最小堆维护大小为 k 的 nums1 子集，并保持其和最大
3. 贪心：在 nums2 最小值固定时，nums1 的和越大得分越高

## 易错点

1. 堆中保留最大的 k 个 nums1 值（弹出最小的）
2. 只在堆大小等于 k 时才计算得分
3. 当前枚举位置的 nums2 作为最小值（降序枚举保证正确性）
