## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

**示例 1：**
```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**
```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 解题思路

这是一道经典的动态规划题目，核心在于理解"不能偷相邻房屋"的约束。

**核心思想：**

对于每个房屋，我们有两个选择：
1. 偷这间房：那么不能偷前一间房，金额 = 当前房 + 前两间房的最大金额
2. 不偷这间房：金额 = 前一间房的最大金额

我们选择两者中的较大值。

**状态定义：**
- `dp[i]`：到第 i 间房为止能偷到的最大金额

**状态转移方程：**
```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

**解释：**
- `dp[i-1]`：不偷第 i 间房，金额等于前 i-1 间房的最大金额
- `dp[i-2] + nums[i]`：偷第 i 间房，加上前 i-2 间房的最大金额

**初始状态：**
- `dp[0] = nums[0]`：只有一间房，偷它
- `dp[1] = max(nums[0], nums[1])`：两间房，偷金额大的那间

## Python 代码实现

### 方法一：动态规划（标准解法）⭐

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        """
        动态规划求解打家劫舍问题
        dp[i] 表示到第 i 间房为止能偷到的最大金额
        """
        if not nums:
            return 0
        
        n = len(nums)
        
        # 特殊情况处理
        if n == 1:
            return nums[0]
        
        # 初始化 dp 数组
        dp = [0] * n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])
        
        # 状态转移
        for i in range(2, n):
            # 偷第 i 间房或不偷，取最大值
            dp[i] = max(dp[i-1], dp[i-2] + nums[i])
        
        return dp[n-1]
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)

### 方法二：动态规划 + 空间优化（推荐）⭐⭐

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        """
        空间优化版本：只需要记录前两个状态
        """
        if not nums:
            return 0
        
        n = len(nums)
        
        if n == 1:
            return nums[0]
        
        # 只需要两个变量存储前两个状态
        prev2 = nums[0]  # dp[i-2]
        prev1 = max(nums[0], nums[1])  # dp[i-1]
        
        for i in range(2, n):
            current = max(prev1, prev2 + nums[i])
            prev2 = prev1
            prev1 = current
        
        return prev1
```

**时间复杂度：** O(n)  
**空间复杂度：** O(1)

### 方法三：更简洁的空间优化版本

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        """
        最简洁的实现
        """
        prev = curr = 0
        
        for num in nums:
            # temp = curr
            # curr = max(curr, prev + num)
            # prev = temp
            # 使用 Python 的多重赋值简化
            prev, curr = curr, max(curr, prev + num)
        
        return curr
```

**时间复杂度：** O(n)  
**空间复杂度：** O(1)

### 方法四：递归 + 记忆化（理解用）

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        """
        递归 + 记忆化（自顶向下的动态规划）
        """
        memo = {}
        
        def dp(i):
            """计算从第 i 间房到最后能偷到的最大金额"""
            # 边界条件
            if i >= len(nums):
                return 0
            
            # 记忆化：避免重复计算
            if i in memo:
                return memo[i]
            
            # 选择偷或不偷第 i 间房
            # 偷：nums[i] + dp(i+2)
            # 不偷：dp(i+1)
            result = max(dp(i + 1), nums[i] + dp(i + 2))
            memo[i] = result
            
            return result
        
        return dp(0)
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)（递归栈 + memo）

## 图解示例

**示例：nums = [2, 7, 9, 3, 1]**

```
房屋：   2    7    9    3    1
索引：   0    1    2    3    4

dp 数组计算过程：
dp[0] = 2                           (只能偷第 0 间)
dp[1] = max(2, 7) = 7               (偷第 0 或 1 间)
dp[2] = max(7, 2+9) = 11            (不偷 9 或 偷 9)
dp[3] = max(11, 7+3) = 11           (不偷 3 或 偷 3)
dp[4] = max(11, 11+1) = 12          (不偷 1 或 偷 1)

最优策略：偷 0、2、4 号房屋 → 2 + 9 + 1 = 12
```

**决策树：**
```
                    [2,7,9,3,1]
                   /           \
            偷2(+2)              不偷2(+0)
            /     \              /        \
     [9,3,1]     [7,9,3,1]   [7,9,3,1]  ...
     偷9(+9)      不偷7        偷7(+7)
        |           |             |
     [3,1]       [9,3,1]       [9,3,1]
     ...          偷9            ...
                   |
                [3,1]
                 偷1
                  |
                 12
```

## 关键点总结

1. **动态规划三要素**：
   - 状态定义：`dp[i]` 表示到第 i 间房的最大金额
   - 状态转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
   - 初始状态：`dp[0]` 和 `dp[1]`

2. **空间优化技巧**：
   - 每次只需要前两个状态
   - 使用滚动变量代替数组
   - 降低空间复杂度从 O(n) 到 O(1)

3. **边界情况处理**：
   - 空数组：返回 0
   - 单个元素：返回该元素
   - 两个元素：返回较大值

4. **Python 多重赋值**：
   - `prev, curr = curr, max(curr, prev + num)`
   - 同时更新多个变量，避免临时变量

5. **选择问题本质**：
   - 每个位置都有"选"或"不选"两种决策
   - 当前决策受前面决策的约束
   - 典型的动态规划问题

## 易错点

1. **状态转移方程理解错误**：
   - 错误：`dp[i] = dp[i-1] + nums[i]`（忘记选择）
   - 正确：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

2. **初始状态设置错误**：
   - 错误：`dp[1] = nums[1]`
   - 正确：`dp[1] = max(nums[0], nums[1])`

3. **空间优化时的更新顺序**：
   - 错误：先更新 prev，再更新 curr（会覆盖）
   - 正确：使用临时变量或多重赋值

4. **边界条件遗漏**：
   - 忘记检查空数组
   - 忘记处理单元素情况

5. **索引越界**：
   - `dp[i-2]` 要求 i >= 2
   - 需要特殊处理 i=0 和 i=1
