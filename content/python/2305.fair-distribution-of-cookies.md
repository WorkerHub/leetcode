## 题目描述

给你一个整数数组 `cookies`，其中 `cookies[i]` 表示第 `i` 个袋子中饼干的数目。另给你一个整数 `k`，表示等待分发饼干的孩子数目。

所有饼干袋需要分发给 `k` 个孩子，每个孩子至少分发一个袋子，每个袋子**只能**分发给一个孩子。对某个孩子分发的饼干数目为该孩子收到的**所有袋子**的饼干数量之和。

每个孩子的**不公平程度**是该孩子分发到的最多饼干数，而最大不公平程度是所有孩子中最大的不公平程度。返回所有分发方案中，最大不公平程度的**最小值**。

**示例 1：**
```
输入：cookies = [8,15,10,20,8], k = 2
输出：31
解释：一种最优方案是 [8,15,8] 和 [10,20]，不公平程度为 31 和 30，最大为 31。
```

**示例 2：**
```
输入：cookies = [6,1,3,2,2,4,1,2], k = 3
输出：7
```

**提示：**
- `2 <= cookies.length <= 8`
- `1 <= cookies[i] <= 10^5`
- `2 <= k <= cookies.length`

## 解题思路

**方法一：回溯（暴力枚举）**

由于 `cookies.length <= 8`，可以枚举每个袋子分给哪个孩子，通过剪枝加速搜索。

**方法二：状态压缩 DP**

将 cookies 的每个子集分配给一个孩子，用 DP 求解：
- `dp[i][mask]` 表示前 `i` 个孩子分配了 `mask` 对应的袋子时，最大不公平程度的最小值。
- 枚举子集转移。

## 代码实现

### 方法一：回溯（推荐）

```python
from typing import List

class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        distribute = [0] * k  # 每个孩子当前分配到的饼干数
        self.ans = float('inf')

        def backtrack(idx: int):
            if idx == len(cookies):
                self.ans = min(self.ans, max(distribute))
                return
            
            seen = set()  # 剪枝：避免重复分配给等量的孩子
            for i in range(k):
                if distribute[i] in seen:
                    continue
                seen.add(distribute[i])
                distribute[i] += cookies[idx]
                # 剪枝：当前最大值已超过答案，不必继续
                if max(distribute) < self.ans:
                    backtrack(idx + 1)
                distribute[i] -= cookies[idx]
        
        backtrack(0)
        return self.ans
```

### 方法二：状态压缩 DP

```python
from typing import List

class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        n = len(cookies)
        total = 1 << n
        
        # 预计算每个子集的饼干总量
        subset_sum = [0] * total
        for mask in range(total):
            for i in range(n):
                if mask >> i & 1:
                    subset_sum[mask] += cookies[i]
        
        # dp[i][mask]：前 i 个孩子分配 mask 对应袋子时，最大不公平程度的最小值
        INF = float('inf')
        dp = [[INF] * total for _ in range(k + 1)]
        dp[0][0] = 0
        
        for i in range(1, k + 1):
            for mask in range(total):
                # 枚举 mask 的所有子集 sub 分给第 i 个孩子
                sub = mask
                while sub > 0:
                    prev = mask ^ sub  # 剩余分给前 i-1 个孩子
                    if dp[i - 1][prev] != INF:
                        dp[i][mask] = min(dp[i][mask],
                                          max(dp[i - 1][prev], subset_sum[sub]))
                    sub = (sub - 1) & mask
        
        return dp[k][total - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 回溯 | O(k^n)（剪枝后实际更快） | O(n + k) |
| 状压 DP | O(k * 3^n) | O(k * 2^n) |

## 关键点总结

1. 数据规模小（n<=8），回溯和状压 DP 均可接受。
2. 回溯中剪枝：若当前分配已超过答案，无需继续递归。
3. 状压 DP 枚举子集时使用 `sub = (sub - 1) & mask` 遍历 mask 的所有非空子集。

## 易错点

- 回溯中忘记恢复状态（`distribute[i] -= cookies[idx]`）。
- 状压 DP 中子集枚举的边界：`sub = mask` 开始，`sub > 0` 结束，不包含空集。
