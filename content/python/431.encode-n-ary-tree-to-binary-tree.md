## 题目描述

设计一个算法，可以将 N 叉树编码为二叉树，并能将该二叉树解码为原 N 叉树。一个 N 叉树是指每个节点都有不超过 N 个孩子节点的有根树。类似地，一个二叉树是指每个节点都有不超过 2 个孩子节点的有根树。你的编码 / 解码算法的实现没有限制，你只需要保证一个 N 叉树可以编码为一个二叉树且该二叉树可以解码回原始 N 叉树即可。

**示例 1：**

![](https://assets.leetcode.com/uploads/2018/10/12/narytreeexample.png)

```
输入：root = [1,null,3,2,4,null,5,6]
输出：[1,null,3,2,4,null,5,6]
```

**示例 2：**
```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

**示例 3：**
```
输入：root = []
输出：[]
```

**提示：**
- N 叉树的高度小于或等于 1000
- 节点总数在范围 `[0, 10^4]` 内
- 不要使用类成员 / 全局变量 / 静态变量来存储状态。你的编码和解码算法应是无状态的。

## 解题思路

这道题要求设计 N 叉树到二叉树的编码和解码算法。核心思想是使用"左孩子右兄弟"表示法。

**关键观察：**
1. 二叉树只有两个指针，而 N 叉树可能有多个子节点
2. 可以使用二叉树的左指针存储第一个孩子
3. 使用二叉树的右指针存储下一个兄弟节点
4. 这种表示法称为"左孩子右兄弟"（Left-Child Right-Sibling）

**编码规则：**
- N 叉树节点的第一个孩子 → 二叉树的左孩子
- N 叉树节点的其他孩子 → 二叉树的右兄弟链

**示例：**
```
N叉树：
    1
  / | \
 3  2  4
/ \
5  6

转换后的二叉树：
    1
   /
  3
 / \
5   2
 \   \
  6   4
```

## Python 代码实现

### 方法一：左孩子右兄弟表示法 ⭐ 推荐

```python
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Codec:
    def encode(self, root: 'Node') -> TreeNode:
        """编码：N叉树 -> 二叉树"""
        if not root:
            return None
        
        # 创建二叉树根节点
        binary_root = TreeNode(root.val)
        
        # 如果没有子节点，直接返回
        if not root.children:
            return binary_root
        
        # 第一个孩子放在左边
        binary_root.left = self.encode(root.children[0])
        
        # 其他孩子形成右兄弟链
        current = binary_root.left
        for i in range(1, len(root.children)):
            current.right = self.encode(root.children[i])
            current = current.right
        
        return binary_root
    
    def decode(self, root: TreeNode) -> 'Node':
        """解码：二叉树 -> N叉树"""
        if not root:
            return None
        
        # 创建 N 叉树根节点
        n_ary_root = Node(root.val, [])
        
        # 左孩子是第一个子节点
        current = root.left
        
        # 遍历右兄弟链，收集所有子节点
        while current:
            n_ary_root.children.append(self.decode(current))
            current = current.right
        
        return n_ary_root
```

### 方法二：迭代版本

```python
from collections import deque

class Codec:
    def encode(self, root: 'Node') -> TreeNode:
        """编码：N叉树 -> 二叉树（迭代）"""
        if not root:
            return None
        
        binary_root = TreeNode(root.val)
        queue = deque([(root, binary_root)])
        
        while queue:
            n_node, b_node = queue.popleft()
            
            if not n_node.children:
                continue
            
            # 第一个孩子
            first_child = TreeNode(n_node.children[0].val)
            b_node.left = first_child
            queue.append((n_node.children[0], first_child))
            
            # 其他孩子
            current = first_child
            for i in range(1, len(n_node.children)):
                sibling = TreeNode(n_node.children[i].val)
                current.right = sibling
                queue.append((n_node.children[i], sibling))
                current = sibling
        
        return binary_root
    
    def decode(self, root: TreeNode) -> 'Node':
        """解码：二叉树 -> N叉树（迭代）"""
        if not root:
            return None
        
        n_ary_root = Node(root.val, [])
        queue = deque([(root, n_ary_root)])
        
        while queue:
            b_node, n_node = queue.popleft()
            
            # 遍历左孩子和所有右兄弟
            current = b_node.left
            while current:
                child = Node(current.val, [])
                n_node.children.append(child)
                queue.append((current, child))
                current = current.right
        
        return n_ary_root
```

### 方法三：简化递归版

```python
class Codec:
    def encode(self, root: 'Node') -> TreeNode:
        if not root:
            return None
        
        node = TreeNode(root.val)
        
        if root.children:
            node.left = self.encode(root.children[0])
            
            sibling = node.left
            for child in root.children[1:]:
                sibling.right = self.encode(child)
                sibling = sibling.right
        
        return node
    
    def decode(self, root: TreeNode) -> 'Node':
        if not root:
            return None
        
        node = Node(root.val, [])
        
        child = root.left
        while child:
            node.children.append(self.decode(child))
            child = child.right
        
        return node
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是节点数量
  - 编码和解码都需要访问每个节点一次
- 空间复杂度：
  - 递归版本：O(h)，h 是树的高度（递归栈）
  - 迭代版本：O(w)，w 是树的最大宽度（队列）

## 关键点总结

1. **左孩子右兄弟**：这是 N 叉树转二叉树的经典方法
2. **编码规则**：左指针存第一个孩子，右指针存下一个兄弟
3. **递归结构**：编码和解码都可以用递归优雅实现
4. **无损转换**：这种转换是可逆的，不会丢失信息
5. **指针理解**：理解二叉树的两个指针如何表示 N 个孩子

## 易错点

1. **空节点处理**：编码和解码都要处理空树的情况
2. **第一个孩子**：第一个孩子要单独处理，放在左边
3. **兄弟链遍历**：其他孩子要形成右兄弟链，用 while 遍历
4. **children 初始化**：解码时要初始化空的 children 列表
5. **递归顺序**：要先处理左孩子，再处理右兄弟
