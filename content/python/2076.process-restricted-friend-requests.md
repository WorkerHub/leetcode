## 题目描述

给你 `n` 个人，编号 0 到 `n-1`，以及一个数组 `restrictions`，`restrictions[i] = [xi, yi]` 表示 `xi` 和 `yi` **不能**成为朋友（直接或间接）。

再给你一个数组 `requests`，`requests[j] = [ui, vi]` 表示请求 `ui` 和 `vi` 成为朋友。

对于每个请求，判断是否**可以接受**（即接受后不违反任何限制）。已接受的请求永久生效，未接受的丢弃。

返回布尔值数组，`true` 表示接受该请求。

**示例：**
```
输入：n = 3, restrictions = [[0,1]], requests = [[0,2],[2,1]]
输出：[true,false]
解释：接受 [0,2] 后 0 和 2 是朋友；请求 [2,1] 若接受则 0,2,1 都连通，违反 [0,1] 限制
```

**提示：**
- `2 <= n <= 1000`
- `0 <= restrictions.length <= 1000`
- `1 <= requests.length <= 1000`

## 解题思路

**并查集（Union-Find）：**

对每个请求，先暂时合并，然后检查是否违反任何限制（两个互相限制的人是否在同一集合中）。若违反，则拒绝请求并撤销合并；否则接受并保留。

## 代码实现

### 方法一：并查集 + 临时合并验证（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1

    def connected(self, x, y):
        return self.find(x) == self.find(y)

class Solution:
    def friendRequests(self, n: int, restrictions: List[List[int]],
                       requests: List[List[int]]) -> List[bool]:
        uf = UnionFind(n)
        result = []

        for u, v in requests:
            # 如果已经在同一集合，接受（不影响限制）
            if uf.connected(u, v):
                result.append(True)
                continue

            # 获取 u 和 v 的代表元素
            pu, pv = uf.find(u), uf.find(v)

            # 检查合并后是否违反限制
            violated = False
            for x, y in restrictions:
                px, py = uf.find(x), uf.find(y)
                # 合并后，pu 和 pv 所在集合的所有节点会连通
                # 如果 (x 在 u 集合 且 y 在 v 集合) 或 (x 在 v 集合 且 y 在 u 集合)，违反
                if (px == pu and py == pv) or (px == pv and py == pu):
                    violated = True
                    break

            if violated:
                result.append(False)
            else:
                uf.union(u, v)
                result.append(True)

        return result
```

### 方法二：备份并查集后恢复（更通用）

```python
from typing import List
import copy

class Solution:
    def friendRequests(self, n: int, restrictions: List[List[int]],
                       requests: List[List[int]]) -> List[bool]:
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py

        result = []
        for u, v in requests:
            # 备份状态
            backup = parent[:]
            union(u, v)

            # 检查是否违反限制
            ok = all(find(x) != find(y) for x, y in restrictions)

            if ok:
                result.append(True)
            else:
                parent[:] = backup  # 恢复
                result.append(False)

        return result
```

## 复杂度分析

- 时间复杂度：O(Q * R * alpha(n))，Q 为请求数，R 为限制数
- 空间复杂度：O(n)

## 关键点总结

1. 对每个请求，临时合并后验证所有限制
2. 验证限制：对每个 `(x, y)` 限制，若 `find(x) == find(y)` 则违反
3. 违反时撤销合并（备份或通过代表元素判断）

## 易错点

- 必须对每个请求独立判断（不是批量处理）
- 备份方法更简单但空间稍大
- 代表元素判断方法需要确保比较的是**合并前**的代表元素
