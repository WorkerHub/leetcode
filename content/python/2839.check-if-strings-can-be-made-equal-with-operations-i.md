## 题目描述

给你两个长度为 4 的字符串 `s1` 和 `s2`。

一次操作可以交换 `s1[0]` 和 `s1[2]`，或交换 `s1[1]` 和 `s1[3]`。

判断通过若干次操作后，`s1` 是否能变为 `s2`。

**示例 1：**
```
输入：s1 = "abcd", s2 = "cdab"
输出：true
解释：交换 s1[0] 和 s1[2]，再交换 s1[1] 和 s1[3]：abcd -> cbad -> cdab
```

**示例 2：**
```
输入：s1 = "abcd", s2 = "dacb"
输出：false
```

**提示：**
- `s1.length == s2.length == 4`
- 字符串只包含小写字母

## 解题思路

字符串长度固定为 4，每次操作只能交换奇数位（0,2）或偶数位（1,3）。

**关键观察：** 操作只能在相同奇偶性的位置之间交换：
- 下标 0 和 2（偶数位）：{s1[0], s1[2]} 可以互换
- 下标 1 和 3（奇数位）：{s1[1], s1[3]} 可以互换

因此，s1 可变为 s2 的条件是：
- {s1[0], s1[2]} == {s2[0], s2[2]}（偶数位集合相同）
- {s1[1], s1[3]} == {s2[1], s2[3]}（奇数位集合相同）

## Python 代码实现

### 方法一：集合比较（推荐）

```python
class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        # 偶数位（下标 0, 2）的字符集合必须相同
        even_match = sorted([s1[0], s1[2]]) == sorted([s2[0], s2[2]])
        # 奇数位（下标 1, 3）的字符集合必须相同
        odd_match = sorted([s1[1], s1[3]]) == sorted([s2[1], s2[3]])
        return even_match and odd_match
```

### 方法二：排序比较

```python
class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        # 偶数位可以互换，奇数位可以互换
        return (sorted([s1[0], s1[2]]) == sorted([s2[0], s2[2]]) and
                sorted([s1[1], s1[3]]) == sorted([s2[1], s2[3]]))
```

### 方法三：计数器比较

```python
from collections import Counter

class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        even1 = Counter([s1[0], s1[2]])
        even2 = Counter([s2[0], s2[2]])
        odd1 = Counter([s1[1], s1[3]])
        odd2 = Counter([s2[1], s2[3]])
        return even1 == even2 and odd1 == odd2
```

## 复杂度分析

- 时间复杂度：O(1)，字符串长度固定为 4
- 空间复杂度：O(1)

## 关键点总结

1. 操作只在偶数位（0,2）或奇数位（1,3）之间交换
2. 判断条件：偶数位字符集合相同且奇数位字符集合相同
3. `sorted()` 或 `Counter()` 都可以比较集合是否相同

## 易错点

1. 字符是多重集合（可以有重复字符），不是集合，所以要用排序或 Counter 比较，不能用 set
2. 偶数位下标是 0, 2（不是 0, 1）；奇数位下标是 1, 3（不是 2, 3）
