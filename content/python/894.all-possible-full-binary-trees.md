## 题目描述

满二叉树 是一类二叉树，其中每个节点恰好有 0 或 2 个子节点。

返回包含 n 个节点的所有可能满二叉树的列表。答案中每棵树的每个节点都必须符合 Node.val == 0 。

**提示：**
- 1 <= n <= 20

## 解题思路

递归 + 记忆化：
- n 为偶数时无解
- n = 1 时返回单节点
- 否则枚举左子树节点数 i，右子树节点数 n-1-i

## Python 代码实现

```python
class Solution:
    def allPossibleFBT(self, n: int) -> List[TreeNode]:
        from functools import lru_cache
        
        @lru_cache(None)
        def build(n):
            if n == 1:
                return [TreeNode(0)]
            
            if n % 2 == 0:
                return []
            
            result = []
            for i in range(1, n, 2):
                # 左子树 i 个节点，右子树 n-1-i 个节点
                for left in build(i):
                    for right in build(n - 1 - i):
                        root = TreeNode(0)
                        root.left = left
                        root.right = right
                        result.append(root)
            
            return result
        
        return build(n)
```

## 复杂度分析

- **时间复杂度**：O(2^n)，第n个卡特兰数
- **空间复杂度**：O(2^n)

## 关键点总结

1. **满二叉树性质**：节点数必须是奇数
2. **递归构造**：枚举左右子树大小
3. **记忆化**：避免重复计算
