## 题目描述

请你实现一个类 `SubrectangleQueries`，它的构造函数的参数是一个 `rows x cols` 的矩形（这里用整数矩阵表示），并支持以下两种操作：

**1. `updateSubrectangle(int row1, int col1, int row2, int col2, int newValue)`**

用 `newValue` 更新以 `(row1, col1)` 为左上角、`(row2, col2)` 为右下角的子矩形中的所有值。

**2. `getValue(int row, int col)`**

返回矩形中坐标 `(row, col)` 的当前值。

**示例：**

```
输入：
["SubrectangleQueries","getValue","updateSubrectangle","getValue","getValue","updateSubrectangle","getValue","getValue"]
[[[1,2,1],[4,3,4],[3,2,1],[1,1,1]],[0,2],[0,0,3,2,5],[0,2],[3,1],[1,1,2,1,10],[1,1],[2,1]]
输出：
[null,1,null,5,5,null,10,5]
```

**提示：**
- `rows, cols <= 100`
- `0 <= row1 <= row2 < rows`
- `0 <= col1 <= col2 < cols`
- `1 <= newValue, rectangle[i][j] <= 10^9`
- 最多调用 `500` 次 `updateSubrectangle` 和 `getValue`

---

## 解题思路

**方法一：直接更新矩阵**
- `updateSubrectangle`：遍历子矩形内所有位置并更新值。
- `getValue`：直接返回矩阵对应位置的值。
- 简单直接，更新 O((r2-r1+1)*(c2-c1+1))，查询 O(1)。

**方法二：记录更新操作，查询时逆序查找**
- 不直接修改矩阵，而是记录每次更新操作（row1, col1, row2, col2, newValue）。
- `getValue(row, col)`：逆序遍历所有更新操作，找到第一个覆盖该点的更新，返回其值；若无则返回初始矩阵的值。
- 适合更新频繁、查询少的场景：更新 O(1)，查询 O(次数)。

## Python 代码实现

### 方法一：直接原地更新（推荐，简单直观）

```python
from typing import List

class SubrectangleQueries:

    def __init__(self, rectangle: List[List[int]]):
        self.matrix = rectangle  # 直接引用矩阵

    def updateSubrectangle(self, row1: int, col1: int, row2: int, col2: int, newValue: int) -> None:
        # 遍历子矩形，更新所有位置
        for r in range(row1, row2 + 1):
            for c in range(col1, col2 + 1):
                self.matrix[r][c] = newValue

    def getValue(self, row: int, col: int) -> int:
        # 直接返回当前值
        return self.matrix[row][col]
```

### 方法二：惰性更新（记录操作，查询时逆序查找）

```python
from typing import List

class SubrectangleQueries:

    def __init__(self, rectangle: List[List[int]]):
        self.matrix = rectangle      # 初始矩阵（只读）
        self.updates = []            # 记录所有更新操作

    def updateSubrectangle(self, row1: int, col1: int, row2: int, col2: int, newValue: int) -> None:
        # 记录操作，不立即修改矩阵
        self.updates.append((row1, col1, row2, col2, newValue))

    def getValue(self, row: int, col: int) -> int:
        # 逆序查找最近一次覆盖 (row, col) 的更新
        for r1, c1, r2, c2, val in reversed(self.updates):
            if r1 <= row <= r2 and c1 <= col <= c2:
                return val  # 找到最近的覆盖，返回新值

        # 没有更新操作覆盖该点，返回初始值
        return self.matrix[row][col]
```

### 方法三：方法一的 Pythonic 写法（使用切片）

```python
from typing import List
import copy

class SubrectangleQueries:

    def __init__(self, rectangle: List[List[int]]):
        # 深拷贝防止外部修改影响内部状态
        self.matrix = copy.deepcopy(rectangle)

    def updateSubrectangle(self, row1: int, col1: int, row2: int, col2: int, newValue: int) -> None:
        for r in range(row1, row2 + 1):
            # 利用切片赋值，用 newValue 填充整行的指定列范围
            self.matrix[r][col1:col2 + 1] = [newValue] * (col2 - col1 + 1)

    def getValue(self, row: int, col: int) -> int:
        return self.matrix[row][col]
```

## 复杂度分析

| 方法 | updateSubrectangle | getValue | 空间 |
|------|-------------------|----------|------|
| 直接更新 | O(rows * cols) | O(1) | O(rows * cols) |
| 惰性更新 | O(1) | O(更新次数) | O(更新次数) |

- 方法一适合查询频繁、更新少的场景。
- 方法二适合更新频繁、查询少的场景。
- 本题数据范围较小（rows, cols <= 100，操作 <= 500），两种方法都可通过。

---

## 关键点总结

1. 两种设计权衡：**立即更新**（查询快）vs **惰性更新**（更新快）。
2. 惰性更新的关键是**逆序**查找更新记录，因为最新的更新优先级最高。
3. 对于点 `(row, col)` 是否在子矩形内的判断：`r1 <= row <= r2 and c1 <= col <= c2`。
4. 如果 `__init__` 传入的是引用，要注意外部修改可能影响内部状态，必要时深拷贝。

---

## 易错点

- **下标包含边界**：子矩形从 `(row1, col1)` 到 `(row2, col2)` 均包含，循环要用 `range(row1, row2 + 1)`。
- **惰性更新要逆序**：`reversed(self.updates)` 保证找到的是最近的更新操作。
- **初始矩阵的引用**：Python 列表是引用类型，若不想修改原矩阵，需要深拷贝（方法三中使用了 `copy.deepcopy`）。
