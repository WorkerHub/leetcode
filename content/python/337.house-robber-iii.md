## 题目描述

小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，我们称之为 `root`。

除了 `root` 之外，每栋房子有且只有一个"父"房子与之相连。一番侦察之后，聪明的小偷意识到"这个地方的所有房屋的排列类似于一棵二叉树"。如果**两个直接相连的房子在同一天晚上被打劫**，房屋将自动报警。

给定二叉树的 `root`。返回**在不触动警报的情况下**，小偷能够盗取的最高金额。

**示例 1:**

```
输入: root = [3,2,3,null,3,null,1]
输出: 7
解释: 小偷一晚能够盗取的最高金额 3 + 3 + 1 = 7
     3
    / \
   2   3
    \   \ 
     3   1
```

**示例 2:**

```
输入: root = [3,4,5,1,3,null,1]
输出: 9
解释: 小偷一晚能够盗取的最高金额 4 + 5 = 9
     3
    / \
   4   5
  / \   \ 
 1   3   1
```

**提示:**

- 树的节点数在 `[1, 10^4]` 范围内
- `0 <= Node.val <= 10^4`

## 解题思路

这道题是 **House Robber** 系列的树版本，使用**树形 DP**求解。

### 核心思想

对于每个节点，有两种选择：
1. **抢劫当前节点**：不能抢劫子节点，只能抢劫孙子节点
2. **不抢劫当前节点**：可以选择抢劫或不抢劫子节点

### 状态定义

对于每个节点，返回一个二元组 `(rob, not_rob)`：
- `rob`：抢劫当前节点能获得的最大金额
- `not_rob`：不抢劫当前节点能获得的最大金额

### 状态转移

设左子树返回 `(left_rob, left_not_rob)`，右子树返回 `(right_rob, right_not_rob)`：

1. **抢劫当前节点**：
   ```python
   rob = node.val + left_not_rob + right_not_rob
   ```

2. **不抢劫当前节点**：
   ```python
   not_rob = max(left_rob, left_not_rob) + max(right_rob, right_not_rob)
   ```

## Python 代码实现

### 方法一：树形 DP（推荐）⭐

```python
from typing import Optional, Tuple

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        """
        树形 DP：返回 (抢劫当前节点, 不抢劫当前节点) 的最大金额
        """
        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            # 空节点
            if not node:
                return 0, 0
            
            # 递归处理左右子树
            left_rob, left_not_rob = dfs(node.left)
            right_rob, right_not_rob = dfs(node.right)
            
            # 抢劫当前节点：不能抢劫子节点
            rob = node.val + left_not_rob + right_not_rob
            
            # 不抢劫当前节点：可以选择抢劫或不抢劫子节点
            not_rob = max(left_rob, left_not_rob) + max(right_rob, right_not_rob)
            
            return rob, not_rob
        
        rob_root, not_rob_root = dfs(root)
        return max(rob_root, not_rob_root)
```

### 方法二：记忆化递归（朴素思路）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        """
        记忆化递归：直接计算每个节点的最大金额
        """
        memo = {}
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            
            if node in memo:
                return memo[node]
            
            # 方案 1: 抢劫当前节点
            rob_current = node.val
            if node.left:
                rob_current += dfs(node.left.left) + dfs(node.left.right)
            if node.right:
                rob_current += dfs(node.right.left) + dfs(node.right.right)
            
            # 方案 2: 不抢劫当前节点
            not_rob_current = dfs(node.left) + dfs(node.right)
            
            # 取最大值
            memo[node] = max(rob_current, not_rob_current)
            return memo[node]
        
        return dfs(root)
```

### 方法三：暴力递归（会超时）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        """
        暴力递归：没有记忆化，会有大量重复计算
        """
        if not root:
            return 0
        
        # 方案 1: 抢劫当前节点
        rob_current = root.val
        if root.left:
            rob_current += self.rob(root.left.left) + self.rob(root.left.right)
        if root.right:
            rob_current += self.rob(root.right.left) + self.rob(root.right.right)
        
        # 方案 2: 不抢劫当前节点
        not_rob_current = self.rob(root.left) + self.rob(root.right)
        
        return max(rob_current, not_rob_current)
```

### 方法四：使用字典存储状态

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        """
        使用字典明确存储 rob 和 not_rob 状态
        """
        def dfs(node: Optional[TreeNode]) -> dict:
            if not node:
                return {'rob': 0, 'not_rob': 0}
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            # 抢劫当前节点
            rob = node.val + left['not_rob'] + right['not_rob']
            
            # 不抢劫当前节点
            not_rob = max(left['rob'], left['not_rob']) + max(right['rob'], right['not_rob'])
            
            return {'rob': rob, 'not_rob': not_rob}
        
        result = dfs(root)
        return max(result['rob'], result['not_rob'])
```

## 复杂度分析

**方法一：树形 DP**

- **时间复杂度**：O(n)
  - 每个节点访问一次
  
- **空间复杂度**：O(h)
  - h：树的高度，递归栈的空间

**方法二：记忆化递归**

- **时间复杂度**：O(n)
  - 每个节点计算一次，记忆化避免重复
  
- **空间复杂度**：O(n)
  - memo 字典 + 递归栈

**方法三：暴力递归**

- **时间复杂度**：O(2^n)
  - 大量重复计算，会超时
  
- **空间复杂度**：O(h)
  - 递归栈

## 关键点总结

1. **树形 DP**：后序遍历，自底向上传递状态
2. **状态定义**：每个节点返回 `(rob, not_rob)` 两个状态
3. **状态转移**：
   - 抢当前 = 当前值 + 不抢子节点
   - 不抢当前 = max(抢子节点, 不抢子节点)
4. **后序遍历**：先处理子树，再处理当前节点
5. **记忆化优化**：避免重复计算子问题

## 易错点

1. **忘记返回两个状态**：只返回一个值会丢失信息

2. **状态转移错误**：
   - 抢当前：必须用 `left_not_rob` 和 `right_not_rob`
   - 不抢当前：可以用 `max(left_rob, left_not_rob)`

3. **空节点处理**：返回 `(0, 0)` 而不是 `None`

4. **最终结果**：要取 `max(rob_root, not_rob_root)`

5. **方法二的孙子节点**：要检查子节点是否存在再访问孙子节点

## 图解示例

示例 1：`root = [3,2,3,null,3,null,1]`

```
     3
    / \
   2   3
    \   \ 
     3   1

后序遍历过程：

1. 节点 3 (左子树的右子节点):
   rob = 3, not_rob = 0

2. 节点 2:
   left = (0, 0)
   right = (3, 0)
   rob = 2 + 0 + 0 = 2
   not_rob = max(0, 0) + max(3, 0) = 3
   返回 (2, 3)

3. 节点 1 (右子树的右子节点):
   rob = 1, not_rob = 0

4. 节点 3 (右子节点):
   left = (0, 0)
   right = (1, 0)
   rob = 3 + 0 + 0 = 3
   not_rob = max(0, 0) + max(1, 0) = 1
   返回 (3, 1)

5. 根节点 3:
   left = (2, 3)
   right = (3, 1)
   rob = 3 + 3 + 1 = 7
   not_rob = max(2, 3) + max(3, 1) = 3 + 3 = 6
   返回 (7, 6)

结果: max(7, 6) = 7
```
