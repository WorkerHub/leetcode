## 题目描述

Alice 和 Bob 在玩一个字符串游戏。Alice 从字符串 `word = "a"` 开始。

每一轮，Alice 将 `word` 中每个字符替换为其在字母表中的**下一个字符**（'z' 之后循环到 'a'），并将结果追加到 `word` 末尾。

例如：
- 第 0 轮：`word = "a"`
- 第 1 轮：`word = "ab"`
- 第 2 轮：`word = "abbc"`
- 第 3 轮：`word = "abbcbccd"`

给你一个整数 `k`，返回 `word` 中第 `k` 个字符（1 索引）。

**示例 1：**
```
输入：k = 5
输出：'b'
解释：第3轮后 word = "abbcbccd"，第5个字符是 'b'
```

**示例 2：**
```
输入：k = 10
输出：'c'
```

**提示：**
- `1 <= k <= 500`

## 解题思路

**方法一（模拟）：** 由于 `k <= 500`，直接模拟字符串的生成过程，每轮字符串长度翻倍，直到长度 >= k 为止。

**方法二（位运算/递归）：** 
- 第 `k` 个字符（1 索引）的值等于 `k-1` 的二进制表示中 `1` 的个数（popcount）对应的字母偏移量，即 `chr(ord('a') + bin(k-1).count('1'))`。
- 原理：每次生成时，位置 `i`（0 索引）的字符由 `i` 的二进制中有多少个 1 决定。

## Python 代码实现

### 方法一：模拟（直观）

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        word = "a"
        # 每轮字符串翻倍，直到长度足够
        while len(word) < k:
            # 将每个字符变成下一个字符，追加到末尾
            next_part = "".join(chr((ord(c) - ord('a') + 1) % 26 + ord('a')) for c in word)
            word += next_part
        return word[k - 1]
```

### 方法二：位运算（推荐）

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        # 第 k 个字符（1 索引）对应的偏移量等于 k-1 的二进制中 1 的个数
        offset = bin(k - 1).count('1')
        return chr(ord('a') + offset)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(k)，最多生成长度为 O(k) 的字符串
- 空间复杂度：O(k)，存储字符串

**方法二：**
- 时间复杂度：O(log k)，计算二进制中 1 的个数
- 空间复杂度：O(1)

## 关键点总结

1. 字符串每轮翻倍，但下标 `i`（0 索引）处的字符只与 `i` 的二进制位中 1 的个数有关。
2. 规律：位置 0 对应 'a'（0个1），位置 1 对应 'b'（1个1），位置 2 对应 'b'，位置 3 对应 'c'，以此类推。
3. `bin(k-1).count('1')` 是 Python 中计算 popcount 的简洁方式。

## 易错点

1. 注意 `k` 是 1 索引，转换为 0 索引时需减 1。
2. 模拟时字符 'z' 之后循环到 'a'，需要取模。
3. 位运算方法中偏移量不会超过 9（因为 k <= 500 < 2^9），不会超出 26 个字母。
