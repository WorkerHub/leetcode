## 题目描述

给你一个整数数组 `nums`，统计最大元素只出现一次的子数组数目。

**示例 1：**

```
输入：nums = [1, 3, 2, 3, 3]
输出：6
解释：最大元素是 3，只有那些包含恰好一个 3 的子数组满足。
[1,3], [3,2], [1,3,2], [3], [3,2,3]中 3 出现两次...
需要仔细统计。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：6
解释：3 只出现一次，所有包含 3 的子数组都满足条件。
包含 3 的子数组：[3], [2,3], [1,2,3] 共 3 个。
不包含 3 的子数组：[1], [2], [1,2] 共 3 个，这些最大元素不是全局最大 3。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

全局最大值为 `max_val`，统计满足以下条件的子数组：
- 子数组中 `max_val` 恰好出现 1 次（子数组的最大元素唯一）。

对每个 max_val 出现的位置 `pos[i]`，统计以 `pos[i]` 为最大值位置（唯一出现）的子数组数目：
- 左端：`pos[i-1] + 1` 到 `pos[i]`（不含 pos[i-1]，否则有两个 max_val）。
- 右端：`pos[i]` 到 `pos[i+1] - 1`（不含 pos[i+1]，否则有两个 max_val）。

数量 = `(pos[i] - prev_pos) * (next_pos - pos[i])`。

## Python 代码实现

### 方法一：统计 max_val 位置（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        max_val = max(nums)

        # 找所有 max_val 的位置
        positions = [i for i, v in enumerate(nums) if v == max_val]

        count = 0
        for idx, pos in enumerate(positions):
            # 左边界：上一个 max_val 位置之后（或数组起始）
            left_bound = positions[idx - 1] + 1 if idx > 0 else 0
            # 右边界：下一个 max_val 位置之前（或数组末尾）
            right_bound = positions[idx + 1] - 1 if idx < len(positions) - 1 else n - 1

            # 子数组左端选择范围：[left_bound, pos]，右端选择范围：[pos, right_bound]
            left_choices = pos - left_bound + 1
            right_choices = right_bound - pos + 1
            count += left_choices * right_choices

        return count
```

### 方法二：枚举（小数据验证）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        max_val = max(nums)
        count = 0

        for l in range(n):
            max_count = 0
            for r in range(l, n):
                if nums[r] == max_val:
                    max_count += 1
                if max_count == 1:
                    count += 1
                elif max_count > 1:
                    break

        return count
```

## 复杂度分析

- 时间复杂度：O(n)（方法一）；O(n^2)（方法二）
- 空间复杂度：O(k)，k 为 max_val 出现次数

## 关键点总结

1. 找全局最大值的所有出现位置。
2. 对每个位置，计算以该位置为唯一最大值的子数组数量（乘法原理）。
3. 左右范围由相邻的最大值位置决定。

## 易错点

1. 子数组必须只包含恰好一个最大值，不是零个。
2. 左右范围的边界计算需仔细（含端点）。
