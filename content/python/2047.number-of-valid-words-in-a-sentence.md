## 题目描述

句子仅由小写字母、数字（0-9）、连字符（-）、标点符号（!.、,）和空格（ ）组成。每个句子可以根据空格分解为若干 token，确定**有效单词**的数目。

**有效单词**满足以下条件：
1. 仅由小写字母、连字符和标点组成（不含数字）
2. 最多一个标点符号，且如果有，在 token 末尾
3. 最多一个连字符，且两侧必须均是小写字母

**示例 1：**
```
输入：sentence = "cat and  in the -1"
输出：3
解释："cat","and","in","the" 中，"-1" 含数字无效，"-" 左侧无字母无效，"in","the","and","cat" 有效，但 "and " 中空分隔后 "and" 有效，共3个...
```

**提示：**
- `1 <= sentence.length <= 1000`
- 句子仅含题目描述的字符

## 解题思路

分割句子，对每个 token 验证是否满足有效单词条件：
1. 不含数字
2. 最多一个标点，且在末尾
3. 连字符最多一个，且左右都是字母

## 代码实现

### 方法一：逐 token 验证（推荐）

```python
class Solution:
    def countValidWords(self, sentence: str) -> int:
        def is_valid(token: str) -> bool:
            if not token:
                return False  # 空 token 无效

            n = len(token)
            hyphen_count = 0

            for i, c in enumerate(token):
                if c.isdigit():
                    return False  # 含数字无效
                elif c in '!.,':
                    # 标点只能出现在末尾
                    if i != n - 1:
                        return False
                elif c == '-':
                    hyphen_count += 1
                    if hyphen_count > 1:
                        return False  # 超过一个连字符
                    # 连字符两侧必须是小写字母
                    if i == 0 or i == n - 1:
                        return False  # 在首尾则一侧无字母
                    if not token[i - 1].isalpha() or not token[i + 1].isalpha():
                        return False
                # 小写字母直接跳过

            return True

        return sum(is_valid(token) for token in sentence.split(' '))
```

### 方法二：正则表达式

```python
import re

class Solution:
    def countValidWords(self, sentence: str) -> int:
        # 有效 token 的正则：可选的小写字母序列，可选的连字符（两侧字母），可选的末尾标点
        pattern = re.compile(r'^[a-z]*([a-z]-[a-z])?[a-z]*[!.,]?$')

        count = 0
        for token in sentence.split(' '):
            if token and pattern.match(token):
                count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O(n)，n 为句子长度
- 空间复杂度：O(n)，split 结果

## 关键点总结

1. 用 `split(' ')` 分割（不是 `split()`），保留空串（连续空格产生）
2. 空 token 不是有效单词
3. 连字符条件：只有一个，且 `i > 0` 且 `i < n-1` 且两侧是字母

## 易错点

- 使用 `split(' ')` 而不是 `split()`，因为题目说以空格分隔（多个空格会产生空 token）
- 空串（由多个连续空格产生）是无效单词
- 连字符在末尾（`i == n-1`）也是无效的（右侧无字母）
