## 题目描述

你想观看障碍赛。给你一个下标从 0 开始的整数数组 `obstacles`，长度为 `n`。

对于每个下标 `i`（从 0 到 n-1），返回 `ans[i]`：以 `obstacles[i]` 结尾的**最长非递减子序列**的长度（只考虑 `obstacles[0..i]`）。

**示例 1：**
```
输入：obstacles = [1, 2, 3, 2]
输出：[1, 2, 3, 3]
```

**示例 2：**
```
输入：obstacles = [2, 2, 1]
输出：[1, 2, 1]
```

**提示：**
- `n == obstacles.length`，`1 <= n <= 10^5`
- `1 <= obstacles[i] <= 10^7`

---

## 解题思路

### 核心思想：LIS 的变体（最长非递减子序列）+ 二分

本题是 **最长非递减子序列（LIS 允许相等）**，对每个位置需要结果。

使用类似 LIS 的耐心排序（patience sorting）：
- 维护一个 `tails` 数组，`tails[i]` 是长度为 `i+1` 的非递减子序列的末尾最小值
- 对每个元素 `x`，用**二分查找**找到 `tails` 中第一个 **严格大于** `x` 的位置 `pos`
  - 若不存在，则 `x` 可以追加到末尾
  - 否则用 `x` 更新 `tails[pos]`
- `ans[i] = pos + 1`

## 代码实现

### 方法一：二分 + tails 数组（推荐）

```python
from typing import List
import bisect

class Solution:
    def longestObstacleCourseAtEachPosition(self, obstacles: List[int]) -> List[int]:
        n = len(obstacles)
        ans = [0] * n
        tails = []  # tails[k] = 长度为 k+1 的最优子序列的末尾最小值

        for i, x in enumerate(obstacles):
            # 找第一个严格大于 x 的位置（允许等于，故找 >x 的第一个位置）
            pos = bisect.bisect_right(tails, x)
            # 当前 x 能组成长度为 pos+1 的非递减子序列
            ans[i] = pos + 1
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x

        return ans
```

### 方法二：手写二分（对比学习）

```python
from typing import List

class Solution:
    def longestObstacleCourseAtEachPosition(self, obstacles: List[int]) -> List[int]:
        n = len(obstacles)
        ans = [0] * n
        tails = []

        def bisect_right(arr, x):
            """找第一个 > x 的位置"""
            lo, hi = 0, len(arr)
            while lo < hi:
                mid = (lo + hi) // 2
                if arr[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo

        for i, x in enumerate(obstacles):
            pos = bisect_right(tails, x)
            ans[i] = pos + 1
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x

        return ans
```

## 关键点总结

1. 非递减子序列（允许相等）等价于 LIS 变体
2. 使用 `bisect_right(tails, x)` 找第一个严格大于 x 的位置
3. LIS（严格递增）用 `bisect_left`；非递减用 `bisect_right`

---

## 易错点

- 非递减（允许 =）用 `bisect_right`；严格递增用 `bisect_left`
- 更新 `tails[pos] = x`（不是 `tails[pos] = min(...)`）
