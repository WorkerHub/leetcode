## 题目描述

给你一个整数数组 nums，找出并返回所有该数组中不同的递增子序列，递增子序列中至少有两个元素。你可以按任意顺序返回答案。

数组中可能含有重复元素，如出现两个整数相等，也可以视作递增序列的一种特殊情况。

**示例 1：**
```
输入：nums = [4,6,7,7]
输出：[[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]
```

**示例 2：**
```
输入：nums = [4,4,3,2,1]
输出：[[4,4]]
```

**提示：**
- 1 <= nums.length <= 15
- -100 <= nums[i] <= 100

## 解题思路

这是一道回溯 + 去重的经典题目。

### 核心思想

1. **回溯框架**：
   - 从每个位置开始，尝试选择后续的元素
   - 只选择大于等于当前最后一个元素的数
   - 长度 >= 2 时加入结果

2. **去重策略**：
   - 同一层不能选择相同的数字（避免重复子序列）
   - 使用 set 记录当前层已使用的数字
   - 不同于排列问题，这里不需要排序

3. **递增条件**：
   - 新选择的数 >= 当前路径的最后一个数
   - 空路径时可以选择任意数

4. **关键区别**：
   - 与子集问题的区别：有递增限制
   - 与组合问题的区别：需要去重但不能排序
   - 去重在同一层，不同层可以重复

## Python 代码实现

### 方法一：回溯 + 层内去重（推荐）

```python
from typing import List

class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        """
        回溯 + 层内去重
        
        时间复杂度：O(n * 2^n)
        空间复杂度：O(n)
        """
        result = []
        path = []
        
        def backtrack(start: int):
            # 如果路径长度 >= 2，加入结果
            if len(path) >= 2:
                result.append(path[:])
            
            # 当前层使用过的数字（去重）
            used = set()
            
            # 从 start 开始选择
            for i in range(start, len(nums)):
                # 剪枝：同一层不能使用相同的数字
                if nums[i] in used:
                    continue
                
                # 剪枝：必须递增（或相等）
                if path and nums[i] < path[-1]:
                    continue
                
                # 选择
                path.append(nums[i])
                used.add(nums[i])
                
                # 递归
                backtrack(i + 1)
                
                # 撤销选择
                path.pop()
        
        backtrack(0)
        return result
```

### 方法二：回溯 + 全局去重

```python
class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        """
        回溯 + 使用 set 全局去重
        
        时间复杂度：O(n * 2^n)
        空间复杂度：O(n * 2^n)
        """
        result = set()
        path = []
        
        def backtrack(start: int):
            if len(path) >= 2:
                result.add(tuple(path))
            
            for i in range(start, len(nums)):
                # 递增条件
                if path and nums[i] < path[-1]:
                    continue
                
                path.append(nums[i])
                backtrack(i + 1)
                path.pop()
        
        backtrack(0)
        return [list(seq) for seq in result]
```

### 方法三：位掩码枚举

```python
class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        """
        枚举所有子序列，筛选递增的
        
        时间复杂度：O(2^n * n)
        空间复杂度：O(2^n * n)
        """
        n = len(nums)
        result = set()
        
        # 枚举所有子序列
        for mask in range(1, 1 << n):
            subseq = []
            for i in range(n):
                if mask & (1 << i):
                    subseq.append(nums[i])
            
            # 检查是否递增且长度 >= 2
            if len(subseq) >= 2:
                is_increasing = True
                for i in range(1, len(subseq)):
                    if subseq[i] < subseq[i - 1]:
                        is_increasing = False
                        break
                
                if is_increasing:
                    result.add(tuple(subseq))
        
        return [list(seq) for seq in result]
```

### 方法四：优化的回溯（提前剪枝）

```python
class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        """
        优化的回溯，提前剪枝
        
        时间复杂度：O(n * 2^n)
        空间复杂度：O(n)
        """
        result = []
        
        def backtrack(start: int, path: List[int]):
            if len(path) >= 2:
                result.append(path[:])
            
            # 剪枝：剩余元素不足
            if start >= len(nums):
                return
            
            used = set()
            for i in range(start, len(nums)):
                # 层内去重
                if nums[i] in used:
                    continue
                
                # 递增检查
                if path and nums[i] < path[-1]:
                    continue
                
                used.add(nums[i])
                path.append(nums[i])
                backtrack(i + 1, path)
                path.pop()
        
        backtrack(0, [])
        return result
```

## 复杂度分析

**方法一、四：**
- **时间复杂度**：O(n × 2^n)
  - 最多 2^n 个子序列
  - 每个子序列需要 O(n) 时间复制

- **空间复杂度**：O(n)
  - 递归栈深度 O(n)
  - path 数组 O(n)
  - used 集合 O(n)

**方法二：**
- **时间复杂度**：O(n × 2^n)
- **空间复杂度**：O(n × 2^n)
  - 需要存储所有结果在 set 中

**方法三：**
- **时间复杂度**：O(2^n × n)
- **空间复杂度**：O(2^n × n)

## 关键点总结

1. **层内去重**：使用 set 记录当前层使用过的数字
2. **递增条件**：新元素 >= 路径最后一个元素
3. **不能排序**：排序会改变相对顺序，影响结果
4. **长度限制**：至少 2 个元素
5. **回溯模板**：选择 -> 递归 -> 撤销

## 易错点

1. **去重方式错误**
   - 不能用排序 + 跳过相邻重复（会改变顺序）
   - 必须用层内 set 去重

2. **递增条件**
   - 是 >= 不是 >
   - 相等也算递增序列

3. **used 位置**
   - used 应该在每层递归中创建
   - 不是全局的 used

4. **结果添加时机**
   - 长度 >= 2 就可以添加
   - 不用等到遍历结束

5. **索引范围**
   - backtrack(i + 1) 不是 backtrack(start + 1)
   - 确保选择的是后续元素
