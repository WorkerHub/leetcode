## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，如果存在 `i < j` 且 `nums[j] - nums[i] > 0`，返回所有满足条件的 `nums[j] - nums[i]` 的最大差值；否则返回 `-1`。

**示例 1：**
```
输入：nums = [7,1,5,4]
输出：4
解释：最大差值为 nums[2] - nums[1] = 5 - 1 = 4
```

**示例 2：**
```
输入：nums = [9,4,3,2]
输出：-1
解释：不存在满足条件的 i 和 j
```

**提示：**
- `2 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`

## 解题思路

维护前缀最小值。遍历数组时，对每个元素 `nums[j]`，用当前最小值 `min_val` 计算差值。若差值 > 0，更新最大差值。

这与股票买卖问题（LeetCode 121）的思路完全相同。

## 代码实现

### 方法一：前缀最小值（推荐）

```python
from typing import List

class Solution:
    def maximumDifference(self, nums: List[int]) -> int:
        min_val = nums[0]  # 记录当前遍历过的最小值
        max_diff = -1      # 默认返回 -1

        for j in range(1, len(nums)):
            if nums[j] > min_val:
                # 存在 nums[j] - min_val > 0 的情况
                max_diff = max(max_diff, nums[j] - min_val)
            else:
                # 更新最小值
                min_val = min(min_val, nums[j])

        return max_diff
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def maximumDifference(self, nums: List[int]) -> int:
        n = len(nums)
        max_diff = -1

        # 枚举所有 i < j 的数对
        for i in range(n):
            for j in range(i + 1, n):
                if nums[j] > nums[i]:
                    max_diff = max(max_diff, nums[j] - nums[i])

        return max_diff
```

### 方法三：一行写法

```python
from typing import List

class Solution:
    def maximumDifference(self, nums: List[int]) -> int:
        ans = -1
        mn = nums[0]
        for x in nums[1:]:
            if x > mn:
                ans = max(ans, x - mn)
            mn = min(mn, x)
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀最小值 | O(n) | O(1) |
| 暴力枚举 | O(n^2) | O(1) |

## 关键点总结

1. 维护前缀最小值，对每个新元素计算差值
2. 当 `nums[j] <= min_val` 时更新最小值（但此时差值 <= 0 不满足条件）
3. 只需要在差值严格大于 0 时更新答案

## 易错点

- 题目要求差值严格大于 0，等于 0 不算（即不能 `i == j` 时 `nums[i] == nums[j]`）
- 不能用单次 `max - min` 代替，因为要求 `i < j`（需要前缀最小，不是全局最小）
