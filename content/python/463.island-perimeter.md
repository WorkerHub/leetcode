## 题目描述

给定一个 `row x col` 的二维网格地图 `grid`，其中：`grid[i][j] = 1` 表示陆地，`grid[i][j] = 0` 表示水域。

网格中的格子水平和垂直方向相连（对角线方向不相连）。整个网格被水完全包围，但其中恰好有一个岛屿（或者说，一个或多个表示陆地的格子相连组成的岛屿）。

岛屿中没有"湖"（"湖" 指水域在岛屿内部且不和岛屿周围的水相连）。格子是边长为 1 的正方形。网格为长方形，且宽度和高度均不超过 100。计算这个岛屿的周长。

**示例 1：**
```
输入：grid = [[0,1,0,0],
              [1,1,1,0],
              [0,1,0,0],
              [1,1,0,0]]
输出：16
解释：它的周长是下面图片中的 16 个黄色的边：
```

**示例 2：**
```
输入：grid = [[1]]
输出：4
```

**示例 3：**
```
输入：grid = [[1,0]]
输出：4
```

**提示：**
- `row == grid.length`
- `col == grid[i].length`
- `1 <= row, col <= 100`
- `grid[i][j]` 为 0 或 1
- 网格中恰好只有一个岛屿

## 解题思路

计算岛屿周长的关键是理解：**每个陆地格子的周长贡献 = 4 - 相邻陆地格子数**。

**核心观察：**
1. 一个单独的陆地格子周长为 4
2. 每与一个陆地格子相邻，周长减少 1（因为共享边）
3. 只需遍历所有陆地格子，统计其贡献的边数

**计算方法：**
- 方法 1：每个陆地格子贡献 4 条边，然后减去相邻陆地格子导致的重复边
- 方法 2：直接统计每个陆地格子的对外边数（上下左右四个方向）

## Python 代码实现

### 方法一：统计相邻陆地（推荐）⭐

```python
from typing import List

class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        perimeter = 0
        
        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == 1:  # 是陆地
                    # 初始贡献 4 条边
                    perimeter += 4
                    
                    # 检查上方是否有陆地
                    if i > 0 and grid[i-1][j] == 1:
                        perimeter -= 2  # 共享一条边，上下各减 1
                    
                    # 检查左方是否有陆地
                    if j > 0 and grid[i][j-1] == 1:
                        perimeter -= 2  # 共享一条边，左右各减 1
        
        return perimeter
```

**优点：** 
- 只检查上方和左方，避免重复计算
- 每条共享边减 2（两个格子各减 1）

### 方法二：直接统计对外边

```python
from typing import List

class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        perimeter = 0
        
        # 四个方向：上、下、左、右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == 1:  # 是陆地
                    # 检查四个方向
                    for di, dj in directions:
                        ni, nj = i + di, j + dj
                        
                        # 边界外或者是水域，贡献 1 条边
                        if ni < 0 or ni >= rows or nj < 0 or nj >= cols or grid[ni][nj] == 0:
                            perimeter += 1
        
        return perimeter
```

**优点：** 思路直观，直接统计每条对外的边

### 方法三：DFS（过度设计，仅供参考）

```python
from typing import List

class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        visited = set()
        
        def dfs(i, j):
            if i < 0 or i >= rows or j < 0 or j >= cols or grid[i][j] == 0:
                return 1  # 边界或水域，贡献 1 条边
            
            if (i, j) in visited:
                return 0  # 已访问，不贡献边
            
            visited.add((i, j))
            
            # 递归四个方向
            perimeter = 0
            perimeter += dfs(i-1, j)  # 上
            perimeter += dfs(i+1, j)  # 下
            perimeter += dfs(i, j-1)  # 左
            perimeter += dfs(i, j+1)  # 右
            
            return perimeter
        
        # 找到第一个陆地格子开始 DFS
        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == 1:
                    return dfs(i, j)
        
        return 0
```

**注意：** 本题不需要 DFS，此方法仅展示另一种思路

### 方法四：数学公式（最简洁）

```python
from typing import List

class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        land = 0  # 陆地格子数
        neighbors = 0  # 相邻陆地对数
        
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == 1:
                    land += 1
                    
                    # 只检查右方和下方，避免重复计算
                    if i < len(grid) - 1 and grid[i+1][j] == 1:
                        neighbors += 1
                    if j < len(grid[0]) - 1 and grid[i][j+1] == 1:
                        neighbors += 1
        
        # 周长 = 陆地总边数 - 共享边数 * 2
        return land * 4 - neighbors * 2
```

**公式：** `perimeter = land * 4 - neighbors * 2`

## 复杂度分析

**所有方法：**
- 时间复杂度：O(m × n)，m 和 n 分别是网格的行数和列数
- 空间复杂度：
  - 方法一、二、四：O(1)
  - 方法三（DFS）：O(m × n)，visited 集合

## 关键点总结

1. **周长贡献公式：** 每个陆地格子 = 4 - 相邻陆地数
2. **避免重复计算：** 只检查一半方向（上+左 或 右+下）
3. **边界判断：** 网格边界视为对外边
4. **数学公式：** `perimeter = land * 4 - neighbors * 2`
5. **无需 DFS/BFS：** 本题只需简单遍历，不需要图算法

## 易错点

1. **重复计算共享边：** 检查四个方向会重复计算
   ```python
   # 错误：会重复减共享边
   for di, dj in [(-1,0), (1,0), (0,-1), (0,1)]:
       if grid[ni][nj] == 1:
           perimeter -= 1  # 每条边会被减两次
   
   # 正确：只检查两个方向
   if i > 0 and grid[i-1][j] == 1:
       perimeter -= 2
   if j > 0 and grid[i][j-1] == 1:
       perimeter -= 2
   ```

2. **边界条件：** 忘记检查数组越界
   ```python
   # 错误：可能越界
   if grid[i-1][j] == 1:
   
   # 正确：先检查边界
   if i > 0 and grid[i-1][j] == 1:
   ```

3. **初始周长：** 每个陆地格子初始是 4，不是 0
   ```python
   # 错误
   perimeter = 0
   if 是陆地:
       perimeter += 1  # 应该是 4
   
   # 正确
   if grid[i][j] == 1:
       perimeter += 4
   ```

4. **理解题意：** 题目保证只有一个岛屿，无需处理多个岛屿的情况
