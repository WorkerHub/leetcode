## 题目描述

给你一个字符串数组 `words`，找出并返回 `length(words[i]) * length(words[j])` 的最大值，并且这两个单词不含有公共字母。如果不存在这样的两个单词，返回 `0`。

**示例 1：**
```
输入：words = ["abcw","baz","foo","bar","xtfn","abcdef"]
输出：16 
解释：这两个单词为 "abcw", "xtfn"。
```

**示例 2：**
```
输入：words = ["a","ab","abc","d","cd","bcd","abcd"]
输出：4 
解释：这两个单词为 "ab", "cd"。
```

**示例 3：**
```
输入：words = ["a","aa","aaa","aaaa"]
输出：0 
解释：不存在这样的两个单词。
```

**提示：**
- `2 <= words.length <= 1000`
- `1 <= words[i].length <= 1000`
- `words[i]` 仅包含小写字母

## 解题思路

### 核心问题

如何快速判断两个单词是否有公共字母？

### 方法对比

| 方法 | 判断公共字母 | 时间复杂度 |
|------|-------------|-----------|
| 暴力 | 双重循环比较字符 | O(n² × L²) |
| 集合 | set交集 | O(n² × L) |
| 位运算 | 位掩码 | O(n² + nL) |

### 位运算优化⭐

使用一个整数的26位表示26个字母：
- 第i位为1表示该单词包含字母i
- 两个单词无公共字母 ⟺ mask1 & mask2 == 0

## Python 代码实现

### 方法一：位运算（推荐）⭐

```python
from typing import List

class Solution:
    def maxProduct(self, words: List[str]) -> int:
        n = len(words)
        
        # 为每个单词计算位掩码
        masks = [0] * n
        for i, word in enumerate(words):
            for char in word:
                masks[i] |= 1 << (ord(char) - ord('a'))
        
        max_prod = 0
        
        # 枚举所有单词对
        for i in range(n):
            for j in range(i + 1, n):
                # 无公共字母
                if masks[i] & masks[j] == 0:
                    max_prod = max(max_prod, len(words[i]) * len(words[j]))
        
        return max_prod
```

### 方法二：位运算 + 哈希优化

```python
from typing import List

class Solution:
    def maxProduct(self, words: List[str]) -> int:
        # 使用字典存储：{位掩码: 最大长度}
        # 相同位掩码的单词只保留最长的
        mask_to_len = {}
        
        for word in words:
            mask = 0
            for char in word:
                mask |= 1 << (ord(char) - ord('a'))
            
            # 更新该掩码对应的最大长度
            mask_to_len[mask] = max(mask_to_len.get(mask, 0), len(word))
        
        max_prod = 0
        
        # 枚举所有掩码对
        masks = list(mask_to_len.keys())
        for i in range(len(masks)):
            for j in range(i + 1, len(masks)):
                if masks[i] & masks[j] == 0:
                    max_prod = max(max_prod, 
                                   mask_to_len[masks[i]] * mask_to_len[masks[j]])
        
        return max_prod
```

### 方法三：使用集合

```python
from typing import List

class Solution:
    def maxProduct(self, words: List[str]) -> int:
        word_sets = [set(word) for word in words]
        max_prod = 0
        
        for i in range(len(words)):
            for j in range(i + 1, len(words)):
                # 两个集合无交集
                if not word_sets[i] & word_sets[j]:
                    max_prod = max(max_prod, len(words[i]) * len(words[j]))
        
        return max_prod
```

### 方法四：带详细注释

```python
from typing import List

class Solution:
    def maxProduct(self, words: List[str]) -> int:
        """
        位运算优化
        
        核心思想：
        1. 用26位整数表示单词包含的字母
        2. 位掩码为0表示无公共字母
        3. 枚举所有单词对找最大乘积
        
        位掩码示例：
        "abc" -> ...000000111 (第0,1,2位为1)
        "def" -> ...000111000 (第3,4,5位为1)
        两者与运算 = 0，无公共字母
        """
        n = len(words)
        
        # 步骤1：计算每个单词的位掩码
        masks = []
        for word in words:
            mask = 0
            for char in word:
                # 将对应位设置为1
                bit_pos = ord(char) - ord('a')
                mask |= (1 << bit_pos)
            masks.append(mask)
        
        # 步骤2：枚举所有单词对
        max_product = 0
        for i in range(n):
            for j in range(i + 1, n):
                # 检查是否有公共字母
                if masks[i] & masks[j] == 0:
                    product = len(words[i]) * len(words[j])
                    max_product = max(max_product, product)
        
        return max_product
```

## 复杂度分析

**位运算方法：**
- 时间复杂度：O(n² + n×L)，L是平均单词长度
- 空间复杂度：O(n)

**集合方法：**
- 时间复杂度：O(n² × L)
- 空间复杂度：O(n × L)

## 关键点总结

1. **位掩码**：用整数的26位表示26个字母
2. **位运算**：
   - 设置位：`mask |= 1 << i`
   - 检查交集：`mask1 & mask2 == 0`
3. **优化**：相同掩码只保留最长单词
4. **位运算优势**：O(1)判断是否有公共字母

## 易错点

1. **位运算错误**：`1 << i` 不要写成 `2 ** i`
2. **字符转位置**：`ord(char) - ord('a')`
3. **枚举范围**：j从i+1开始，避免重复
4. **初始值**：max_prod初始化为0
