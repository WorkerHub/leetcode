## 题目描述

从整数 1 开始，移除所有包含数字 9 的整数，例如 9、19、29...

这样，就获得了一个新的整数序列：1, 2, 3, 4, 5, 6, 7, 8, 10, 11, ...

给定正整数 `n`，返回新序列中的第 `n` 个数字。

**示例 1:**

```
输入：n = 9
输出：10
解释：新序列为 1, 2, 3, 4, 5, 6, 7, 8, 10, 11, ...
第 9 个数字是 10
```

**示例 2:**

```
输入：n = 10
输出：11
```

**提示:**
- `1 <= n <= 8 × 10^8`

## 题目描述

这是一道非常巧妙的**进制转换**问题。

### 核心观察

移除包含数字 9 的整数后，剩下的数字只使用 **0-8** 这 9 个数字。

这不就是**九进制**吗？

**关键洞察：**

- 新序列：1, 2, 3, 4, 5, 6, 7, 8, 10, 11, 12, ...
- 对应关系：相当于把十进制的 n 转换为九进制

### 转换过程

例如 n = 9：
- 十进制 9 转换为九进制：10（因为九进制没有 9）
- 所以新序列的第 9 个数是 10

例如 n = 10：
- 十进制 10 转换为九进制：11
- 所以新序列的第 10 个数是 11

### 数学原理

**原序列（十进制）**：1, 2, 3, ..., 9, 10, 11, ...
**新序列（九进制表示）**：1, 2, 3, ..., 8, 10, 11, ...

本质上，新序列就是把十进制的索引转换为九进制表示。

## Python 代码实现

### 方法一：进制转换（推荐）⭐

```python
class Solution:
    def newInteger(self, n: int) -> int:
        """
        将 n 转换为九进制
        """
        if n == 0:
            return 0
        
        result = 0
        base = 1
        
        while n > 0:
            # 取 n 除以 9 的余数
            result += (n % 9) * base
            n //= 9
            base *= 10
        
        return result
```

### 方法二：递归实现

```python
class Solution:
    def newInteger(self, n: int) -> int:
        """
        递归版本的进制转换
        """
        if n == 0:
            return 0
        
        # 递归转换高位，当前位是 n % 9
        return self.newInteger(n // 9) * 10 + n % 9
```

### 方法三：使用内置函数（最简洁）

```python
class Solution:
    def newInteger(self, n: int) -> int:
        """
        Python 内置的进制转换 + 字符串处理
        """
        # 将 n 转换为九进制字符串
        result = ""
        while n > 0:
            result = str(n % 9) + result
            n //= 9
        
        return int(result) if result else 0
```

### 方法四：numpy 进制转换（仅供参考）

```python
import numpy as np

class Solution:
    def newInteger(self, n: int) -> int:
        """
        使用 numpy 进行进制转换
        """
        # 转换为九进制字符串
        base9 = np.base_repr(n, 9)
        # 转换回十进制整数（但数字本身是九进制表示）
        return int(base9)
```

### 方法五：一行代码

```python
class Solution:
    def newInteger(self, n: int) -> int:
        """
        一行实现
        """
        return int(str(int(str(n), 9))[:-1]) if n else 0
        # 更简洁的版本：
        # 实际上就是进制转换
```

**实际最简洁的一行代码：**

```python
class Solution:
    def newInteger(self, n: int) -> int:
        result = ""
        while n:
            result = str(n % 9) + result
            n //= 9
        return int(result or 0)
```

## 复杂度分析

### 方法一：进制转换
- **时间复杂度**：O(log₉ n)，n 最多有 log₉ n 位
- **空间复杂度**：O(1)，只使用常量空间

### 方法二：递归
- **时间复杂度**：O(log₉ n)
- **空间复杂度**：O(log₉ n)，递归栈深度

### 方法三：字符串
- **时间复杂度**：O(log₉ n)
- **空间复杂度**：O(log₉ n)，存储字符串

## 关键点总结

1. **本质是进制转换**：十进制转九进制
2. **为什么是九进制**：因为只使用 0-8 这 9 个数字
3. **转换方法**：不断除以 9 取余数
4. **数字含义**：结果的每一位都在 0-8 范围内
5. **边界处理**：n = 0 时返回 0

## 易错点

1. **理解题意**：
   ```
   不是找第 n 个不包含 9 的数
   而是移除所有包含 9 的数后的第 n 个
   ```

2. **进制转换方向**：
   ```python
   # 正确：从低位到高位构建
   result += (n % 9) * base
   base *= 10
   
   # 或者：字符串拼接
   result = str(n % 9) + result
   ```

3. **除法和取余**：
   ```python
   n % 9   # 当前位的数字
   n //= 9 # 继续处理更高位
   ```

4. **递归终止条件**：
   ```python
   if n == 0:
       return 0
   ```

5. **返回类型**：
   ```python
   # 如果用字符串拼接，最后要转回整数
   return int(result)
   ```

**进制转换模板：**

```python
# 将十进制 n 转换为 k 进制
def to_base_k(n, k):
    if n == 0:
        return "0"
    
    result = ""
    while n > 0:
        result = str(n % k) + result
        n //= k
    
    return result
```

**常见问题：**

Q: 为什么是九进制而不是其他进制？
A: 因为移除了数字 9，只剩下 0-8 这 9 个数字。

Q: 如果移除的是数字 5 呢？

Q: 递归和循环哪个更好？
