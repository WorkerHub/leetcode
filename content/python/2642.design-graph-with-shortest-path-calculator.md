## 题目描述

给你一个有 `n` 个节点的有向带权图，节点编号 0 到 `n-1`，初始边由 `edges` 给出（`edges[i] = [from, to, cost]`）。

实现以下操作：
- `addEdge(edge)`：添加一条有向边
- `shortestPath(node1, node2)`：返回 `node1` 到 `node2` 的最短路径，不可达返回 -1

**示例：**
```
Graph g = new Graph(4, [[0,2,5],[0,1,2],[1,2,1],[3,0,3]])
g.shortestPath(3, 2)  -> 6（3->0->1->2 = 3+2+1）
g.addEdge([1,3,4])
g.shortestPath(3, 2)  -> 6（路径不变）
```

**数据范围：**
- 1 <= n <= 100
- 0 <= edges.length <= n * (n - 1)
- 1 <= cost <= 10^6

## 解题思路

每次查询都使用 Dijkstra 算法：
- 维护邻接表
- `addEdge` 直接添加到邻接表
- `shortestPath` 从 `node1` 出发运行 Dijkstra，返回到 `node2` 的最短距离

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Graph:
    def __init__(self, n: int, edges: List[List[int]]):
        self.n = n
        # 邻接表：adj[u] = [(v, cost), ...]
        self.adj = [[] for _ in range(n)]
        for u, v, w in edges:
            self.adj[u].append((v, w))

    def addEdge(self, edge: List[int]) -> None:
        u, v, w = edge
        self.adj[u].append((v, w))

    def shortestPath(self, node1: int, node2: int) -> int:
        # Dijkstra 从 node1 出发
        INF = float('inf')
        dist = [INF] * self.n
        dist[node1] = 0
        heap = [(0, node1)]  # (距离, 节点)

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue  # 过时的条目
            if u == node2:
                return d
            for v, w in self.adj[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        return -1 if dist[node2] == INF else dist[node2]
```

### 方法二：Floyd-Warshall（适用于频繁查询）

```python
from typing import List

class Graph:
    def __init__(self, n: int, edges: List[List[int]]):
        INF = float('inf')
        self.n = n
        # dist[i][j]: i 到 j 的最短距离
        self.dist = [[INF] * n for _ in range(n)]
        for i in range(n):
            self.dist[i][i] = 0
        for u, v, w in edges:
            self.dist[u][v] = min(self.dist[u][v], w)
        # 初始化 Floyd-Warshall
        self._floyd()

    def _floyd(self):
        n = self.n
        d = self.dist
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if d[i][k] + d[k][j] < d[i][j]:
                        d[i][j] = d[i][k] + d[k][j]

    def addEdge(self, edge: List[int]) -> None:
        u, v, w = edge
        # 更新所有经过 u->v 的路径
        n = self.n
        d = self.dist
        if d[u][v] <= w:
            return
        d[u][v] = w
        for i in range(n):
            for j in range(n):
                if d[i][u] + w + d[v][j] < d[i][j]:
                    d[i][j] = d[i][u] + w + d[v][j]

    def shortestPath(self, node1: int, node2: int) -> int:
        d = self.dist[node1][node2]
        return -1 if d == float('inf') else d
```

## 复杂度分析

- 方法一：addEdge O(1)，shortestPath O((n+m) log n)
- 方法二：初始化 O(n^3)，addEdge O(n^2)，shortestPath O(1)

## 关键点总结

1. 动态添加边时，可以每次重新运行 Dijkstra（简单）
2. Floyd-Warshall 预计算全对最短路，适合频繁查询
3. Dijkstra 使用最小堆优化

## 易错点

1. Dijkstra 中跳过已过时的堆条目（`d > dist[u]`）
2. 自环初始化为 0
3. 添加边后 Floyd-Warshall 需要更新所有受影响的路径
