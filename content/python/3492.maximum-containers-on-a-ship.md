## 题目描述

一艘船有 `n * n` 个货柜格，每个格最多放一个容量为 1 的集装箱。船的最大载重为 `w` 千克，每个集装箱重 1 千克。

返回船上能放置的最大集装箱数量。

**示例 1：**

```
输入：n = 3, w = 5
输出：5
解释：船有 3*3=9 个格，最多放 9 个箱，但载重限制为 5，故答案为 5
```

**示例 2：**

```
输入：n = 3, w = 10
输出：9
解释：载重 10 >= 9（总格数），故全放满，答案为 9
```

**提示：**
- `1 <= n <= 10^3`
- `1 <= w <= 10^6`

## 解题思路

船的总格数为 `n * n`，最大集装箱数受两个限制：
1. 格数限制：最多 n * n 个
2. 载重限制：最多 w 个（每箱重 1 千克）

答案 = min(n * n, w)

## Python 代码实现

### 方法一：直接计算（推荐）

```python
class Solution:
    def maxContainers(self, n: int, w: int) -> int:
        return min(n * n, w)
```

### 方法二：条件判断

```python
class Solution:
    def maxContainers(self, n: int, w: int) -> int:
        total_slots = n * n
        if w >= total_slots:
            return total_slots
        return w
```

### 方法三：数学推导

```python
class Solution:
    def maxContainers(self, n: int, w: int) -> int:
        # 最大格数
        max_by_slots = n ** 2
        # 最大载重
        max_by_weight = w
        # 取最小值
        return min(max_by_slots, max_by_weight)
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 答案受两个约束：格数和载重
2. 取两个约束的最小值
3. 每个集装箱重量相同（1 千克）

## 易错点

1. n * n 可能超出 int 范围（Python 中不会，其他语言需注意）
2. 每箱重 1 千克，直接对比 n*n 和 w
