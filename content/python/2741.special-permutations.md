## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，它包含 `n` 个 **互不相同** 的正整数。

如果排列 `perm` 满足对所有 `0 <= i < n-1`，`perm[i]` 能 **整除** `perm[i+1]` 或 `perm[i+1]` 能整除 `perm[i]`，则称为 **特殊排列**。

返回特殊排列的数目（对 `10^9 + 7` 取模）。

**示例 1：**
```
输入：nums = [2,3,6]
输出：2
解释：[3,6,2] 和 [2,6,3] 是特殊排列
```

**示例 2：**
```
输入：nums = [1,4,3]
输出：2
```

**提示：**
- `2 <= nums.length <= 14`
- `1 <= nums[i] <= 10^9`

## 解题思路

**状压 DP**：`dp[mask][i]` = 已选择的元素集合为 `mask`，且最后一个元素为 `nums[i]` 的特殊排列数量。

转移：若 `nums[j] % nums[i] == 0` 或 `nums[i] % nums[j] == 0`，则可以从状态 `(mask without j, j)` 转移到 `(mask, i)`。

## Python 代码实现

### 方法一：状压 DP（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def specialPerm(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)

        @lru_cache(maxsize=None)
        def dp(mask: int, last: int) -> int:
            # 已选集合为 mask，最后选的是 nums[last]
            if mask == (1 << n) - 1:
                return 1
            res = 0
            for i in range(n):
                if mask >> i & 1:
                    continue  # 已选
                # 检查 nums[i] 与 nums[last] 的整除关系
                if nums[i] % nums[last] == 0 or nums[last] % nums[i] == 0:
                    res += dp(mask | (1 << i), i)
            return res % MOD

        ans = 0
        for i in range(n):
            ans = (ans + dp(1 << i, i)) % MOD
        return ans
```

### 方法二：迭代状压 DP

```python
from typing import List

class Solution:
    def specialPerm(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        full = (1 << n) - 1
        # dp[mask][i] = 选了 mask，最后是 i 的方案数
        dp = [[0] * n for _ in range(1 << n)]

        for i in range(n):
            dp[1 << i][i] = 1

        for mask in range(1, 1 << n):
            for last in range(n):
                if not (mask >> last & 1):
                    continue
                if dp[mask][last] == 0:
                    continue
                for nxt in range(n):
                    if mask >> nxt & 1:
                        continue
                    if nums[nxt] % nums[last] == 0 or nums[last] % nums[nxt] == 0:
                        dp[mask | (1 << nxt)][nxt] = (dp[mask | (1 << nxt)][nxt] + dp[mask][last]) % MOD

        return sum(dp[full]) % MOD
```

## 复杂度分析

- 时间复杂度：O(2^n * n^2)
- 空间复杂度：O(2^n * n)

## 关键点总结

1. n <= 14，状压 DP 总状态 2^14 * 14 = 229376
2. 转移条件是相邻元素整除关系
3. 枚举最后一个元素的位置作为起点

## 易错点

1. 初始化时每个元素单独作为第一个元素
2. `full = (1<<n)-1` 表示全选
