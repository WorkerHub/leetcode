## 题目描述

给定两个大小相等的数组 nums1 和 nums2，nums1 相对于 nums2 的优势可以用满足 nums1[i] > nums2[i] 的索引 i 的数目来描述。

返回 nums1 的任意排列，使其相对于 nums2 的优势最大化。

**示例 1：**
```
输入：nums1 = [2,7,11,15], nums2 = [1,10,4,11]
输出：[2,11,7,15]
```

**示例 2：**
```
输入：nums1 = [12,24,8,32], nums2 = [13,25,32,11]
输出：[24,32,8,12]
```

**提示：**
- 1 <= nums1.length <= 10^5
- nums2.length == nums1.length
- 0 <= nums1[i], nums2[i] <= 10^9

## 解题思路

这是经典的"田忌赛马"问题。

**贪心策略：**
1. 对 nums1 排序
2. 对 nums2 的索引按值排序
3. 对于 nums2 中每个值：
   - 如果 nums1 有更大的值，用最小的那个（节省资源）
   - 否则用 nums1 最小的值（反正也赢不了）

## Python 代码实现

### 方法一：贪心 + 双指针（推荐）⭐

```python
class Solution:
    def advantageCount(self, nums1: List[int], nums2: List[int]) -> List[int]:
        from collections import deque
        
        n = len(nums1)
        nums1.sort()
        
        # nums2 的索引按值排序
        sorted_nums2 = sorted(enumerate(nums2), key=lambda x: x[1])
        
        result = [0] * n
        left, right = 0, n - 1
        nums1_deque = deque(nums1)
        
        # 从大到小处理 nums2
        for i in range(n - 1, -1, -1):
            idx, val = sorted_nums2[i]
            
            # 如果 nums1 最大值能赢，用它
            if nums1_deque[-1] > val:
                result[idx] = nums1_deque.pop()
            # 否则用最小值（反正赢不了）
            else:
                result[idx] = nums1_deque.popleft()
        
        return result
```

### 方法二：简化版

```python
class Solution:
    def advantageCount(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1.sort()
        sorted_nums2 = sorted(enumerate(nums2), key=lambda x: x[1])
        
        result = [0] * len(nums1)
        left, right = 0, len(nums1) - 1
        
        for i in range(len(nums2) - 1, -1, -1):
            idx, val = sorted_nums2[i]
            if nums1[right] > val:
                result[idx] = nums1[right]
                right -= 1
            else:
                result[idx] = nums1[left]
                left += 1
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. **田忌赛马**：能赢就用刚好能赢的，赢不了就用最弱的
2. **双指针**：维护 nums1 的最大和最小可用值
3. **排序技巧**：对索引排序保持原始位置信息
