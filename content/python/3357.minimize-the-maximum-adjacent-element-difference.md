## 题目描述

给你一个整数数组 `nums`，其中部分元素为 `-1`（表示缺失值）。

你可以将每个 `-1` 替换为任意正整数。

最小化替换后数组中**相邻元素差的最大绝对值**。

返回该最小化后的最大相邻差。

**提示：**
- `2 <= nums.length <= 10^5`
- `-1 <= nums[i] <= 10^9`

## 解题思路

**二分答案 + 贪心验证：**

答案具有单调性：若最大差值为 `d` 可行，则 `d+1` 也可行。

二分答案 `d`，然后验证是否存在一种替换方案，使得所有相邻差 <= d。

**验证 `check(d)`：**

关注 `-1` 的连续段：两端被非 `-1` 值包围（或在数组端点）。

对于两个相邻的非 `-1` 值 `a` 和 `b`，中间有 `k` 个 `-1`，需要用 k 个值填充 `[a, b]` 之间，使相邻差 <= d。

- 若 k = 0（直接相邻）：需要 `|a - b| <= d`。
- 若 k >= 1：可以用 `ceil((k+1) 段)` 步跨越 `|a-b|` 的距离，每步最多 d。条件：`|a - b| <= (k + 1) * d`，即 `d >= ceil(|a-b| / (k+1))`。

实际上更复杂，还需要考虑端点（数组的第一个或最后一个元素是 -1 时，可以自由设置）。

**简化分析：**

对每段 `-1` 的处理：
- 若 `-1` 段被 `a` 和 `b` 夹住（k 个 `-1`）：最小化最大差 = `ceil(|a-b| / (k+1))`。
- 若 `-1` 段在数组端点（只有一侧有值 `a`）：可以任意设置，不约束差。

二分的下界：可能是最小 0，上界：最大的相邻非 `-1` 差值。

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List
import math

class Solution:
    def minDifference(self, nums: List[int]) -> int:
        n = len(nums)
        
        # 收集所有相邻非 -1 值对，以及中间 -1 的数量
        # 同时处理边界 -1 段
        
        def check(d):
            """判断最大相邻差是否可以 <= d"""
            i = 0
            while i < n:
                if nums[i] == -1:
                    i += 1
                    continue
                # 找到下一个非 -1 值
                j = i + 1
                while j < n and nums[j] == -1:
                    j += 1
                
                if j < n:
                    # [i, j] 之间有 j-i-1 个 -1
                    gap = j - i  # 步数
                    diff = abs(nums[j] - nums[i])
                    # 需要 diff <= gap * d
                    if diff > gap * d:
                        return False
                i = j
            return True
        
        # 特殊情况：全是 -1
        if all(x == -1 for x in nums):
            return 0
        
        # 所有相邻非 -1 差的最大值
        non_neg = [x for x in nums if x != -1]
        max_val = max(non_neg)
        
        lo, hi = 0, max_val
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))，二分 * 验证
- 空间复杂度：O(1)

## 关键点总结

1. 对每段 `-1`（被两个非 `-1` 值 `a` 和 `b` 夹住，中间 `k` 个 `-1`），需要 `|a-b| <= (k+1) * d`。
2. 二分答案 `d`，验证所有段是否满足条件。
3. 端点的 `-1` 段（只有一侧有值）不构成约束（可以自由设置）。

## 易错点

1. 端点的 `-1` 不需要考虑（左端或右端的 `-1` 段自由设置）。
2. `gap = j - i`（步数，而非 -1 的数量 j-i-1）。
3. 若所有元素都是 `-1`，答案为 0。
