## 题目描述

这里有 `n` 门不同的在线课程，按从 `1` 到 `n` 编号。给你一个数组 `courses`，其中 `courses[i] = [duration_i, lastDay_i]` 表示第 `i` 门课将会持续 `duration_i` 天，并且必须在不晚于 `lastDay_i` 的时候完成。

你的学期从第 1 天开始。且不能同时修读两门及两门以上的课程。

返回你最多可以修读的课程数目。

**示例 1：**

```
输入：courses = [[100, 200], [200, 1300], [1000, 1250], [2000, 3200]]
输出：3
解释：
这里一共有 4 门课程，但是你最多可以修 3 门：
首先，修第 1 门课，耗费 100 天，在第 100 天完成，在第 200 天前完成。
然后，修第 3 门课，耗费 1000 天，在第 1100 天完成，在第 1250 天前完成。
最后，修第 2 门课，耗费 200 天，在第 1300 天完成，在第 1300 天前完成。
第 4 门课不能修，因为它会在第 3300 天完成，超过了 3200 天的截止时间。
```

**示例 2：**

```
输入：courses = [[1,2]]
输出：1
```

**示例 3：**

```
输入：courses = [[3,2],[4,3]]
输出：0
```

**提示：**
- `1 <= courses.length <= 10^4`
- `1 <= duration_i, lastDay_i <= 10^4`

## 解题思路

这是一个经典的贪心 + 堆（优先队列）问题。

**核心思想：**

1. **按截止时间排序**：优先考虑截止时间早的课程，确保有机会完成更多课程
2. **贪心选择**：尽可能选择持续时间短的课程，为后续课程留出更多时间
3. **反悔机制**：使用最大堆，如果当前课程无法在截止时间前完成，考虑替换掉之前选择的持续时间最长的课程

**算法步骤：**

1. 将课程按截止时间升序排序
2. 维护一个最大堆，存储已选课程的持续时间
3. 维护当前已用时间 `current_time`
4. 遍历每门课程：
   - 假设选择这门课，加入堆中，更新时间
   - 如果完成时间超过截止时间：
     - 从堆中弹出持续时间最长的课程（可能是刚加入的）
     - 回退时间
   - 这样保证了堆中的课程数量最多，且都能在截止时间前完成

**为什么这个贪心策略是正确的？**

- 排序保证了我们按时间线考虑课程
- 堆的反悔机制允许我们用短课程替换长课程
- 每次替换都保证课程数量不减少，总时间更优

## Python 代码实现

### 方法一：贪心 + 最大堆（推荐）

```python
import heapq
from typing import List

class Solution:
    def scheduleCourse(self, courses: List[List[int]]) -> int:
        """
        计算最多可以修读的课程数目
        
        参数:
            courses: 课程列表，每个元素为 [持续时间, 截止时间]
        
        返回:
            最多可修读的课程数
        """
        # 按截止时间升序排序
        courses.sort(key=lambda x: x[1])
        
        # 最大堆（Python heapq 是最小堆，存负数实现最大堆）
        max_heap = []
        current_time = 0
        
        for duration, deadline in courses:
            # 尝试选择这门课
            current_time += duration
            heapq.heappush(max_heap, -duration)  # 负数实现最大堆
            
            # 如果超过截止时间，移除持续时间最长的课程
            if current_time > deadline:
                # 弹出持续时间最长的课程
                longest = -heapq.heappop(max_heap)
                current_time -= longest
        
        # 堆的大小就是能修读的课程数
        return len(max_heap)
```

**时间复杂度：** O(n log n)，排序 O(n log n) + 堆操作 O(n log n)  
**空间复杂度：** O(n)，堆的空间

### 方法二：更直观的写法

```python
class Solution:
    def scheduleCourse(self, courses: List[List[int]]) -> int:
        """
        更直观的实现，显式判断是否需要移除
        """
        courses.sort(key=lambda x: x[1])
        
        max_heap = []
        total_time = 0
        
        for duration, deadline in courses:
            # 假设选择这门课
            total_time += duration
            heapq.heappush(max_heap, -duration)
            
            # 检查是否超时
            if total_time > deadline:
                # 移除持续时间最长的课程（可能是刚加入的）
                removed = -heapq.heappop(max_heap)
                total_time -= removed
                # 如果移除的是刚加入的，相当于不选这门课
                # 如果移除的是之前的，相当于用短课程替换长课程
        
        return len(max_heap)
```

### 方法三：使用内置 heapq（更 Pythonic）

```python
from heapq import heappush, heappop

class Solution:
    def scheduleCourse(self, courses: List[List[int]]) -> int:
        """使用 heapq 模块的函数，代码更简洁"""
        courses.sort(key=lambda c: c[1])
        
        heap = []  # 最大堆（存负值）
        time = 0
        
        for dur, end in courses:
            time += dur
            heappush(heap, -dur)
            
            if time > end:
                time += heappop(heap)  # heap 存的是负值，加上就是减去
        
        return len(heap)
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n log n)
  - 排序：O(n log n)
  - 每门课最多入堆、出堆一次：O(n log n)
- 空间复杂度：O(n)，堆的大小最多为 n

## 图解示例

以示例 1 为例：`courses = [[100,200], [200,1300], [1000,1250], [2000,3200]]`

```
步骤 0：排序后
courses = [[100,200], [1000,1250], [200,1300], [2000,3200]]
          （按截止时间排序）

步骤 1：处理 [100, 200]
time = 100, heap = [-100]
100 <= 200 ✓ 可以选择

步骤 2：处理 [1000, 1250]
time = 1100, heap = [-1000, -100]
1100 <= 1250 ✓ 可以选择

步骤 3：处理 [200, 1300]
time = 1300, heap = [-1000, -100, -200]
1300 <= 1300 ✓ 可以选择

步骤 4：处理 [2000, 3200]
time = 3300, heap = [-1000, -100, -200, -2000]
3300 > 3200 ✗ 超时了！
弹出最长的 2000: time = 1300, heap = [-1000, -100, -200]

最终：heap 大小 = 3，选择了 [100,200], [1000,1250], [200,1300]
```

**为什么不选 [2000, 3200]？**

```
如果选择 [2000, 3200]，时间会达到 3300，超过截止时间 3200
移除持续时间最长的课程（2000），时间回到 1300
相当于没选这门课，保持之前的最优状态
```

## 关键点总结

1. **按截止时间排序**：这是贪心策略的基础，确保时间顺序正确
2. **最大堆的使用**：快速找到并移除持续时间最长的课程
3. **反悔机制**：允许用短课程替换长课程，保证最优解
4. **Python heapq 技巧**：存储负数实现最大堆
5. **贪心正确性**：排序 + 反悔机制保证了全局最优

## 易错点

1. **排序关键字错误**：必须按截止时间排序，而不是持续时间
   ```python
   # 错误
   courses.sort(key=lambda x: x[0])
   # 正确
   courses.sort(key=lambda x: x[1])
   ```

2. **最大堆实现**：Python heapq 是最小堆，需要存负数
   ```python
   # 正确
   heappush(heap, -duration)
   longest = -heappop(heap)
   ```

3. **忘记更新时间**：移除课程后要减去时间
   ```python
   if time > deadline:
       removed = -heappop(heap)
       time -= removed  # 不要忘记这一步
   ```

4. **边界情况**：课程为空、所有课程都无法完成等

5. **理解反悔**：弹出的可能是刚加入的课程（相当于不选），也可能是之前的课程（替换）

## 扩展思考

**为什么按截止时间排序，而不是按持续时间？**

反例：`courses = [[5, 10], [4, 6]]`

按持续时间排序：选 [4, 6]，然后 [5, 10]，时间 9，都可以完成，共 2 门
按截止时间排序：选 [4, 6]，然后 [5, 10]，时间 9，都可以完成，共 2 门

看起来一样？再看这个例子：`courses = [[5, 5], [4, 6]]`

按持续时间排序：先 [4, 6]，时间 4，再 [5, 5]？时间 9 > 5，失败，只能选 1 门
按截止时间排序：先 [5, 5]，时间 5，再 [4, 6]？时间 9 > 6，弹出 [5, 5]，只选 [4, 6]，1 门

实际上这个例子两种方法都是 1 门，但按截止时间排序配合反悔机制能保证全局最优。

关键在于：**截止时间早的课程，如果不在早期完成，后面就没机会了**。
