## 题目描述

我们有 n 种不同的贴纸，每个贴纸上都有一个小写英文单词。

你想要拼写出给定的字符串 target，方法是从收集的贴纸中切割单个字母并重新排列它们。

返回你需要的最小贴纸数量。如果任务不可能，返回 -1。

**示例：**
```
输入：stickers = ["with","example","science"], target = "thehat"
输出：3
解释：
使用2个"with"贴纸和1个"example"贴纸
从"with"中切出"th"和"h"
从"example"中切出"e"和"a"
```

## Python 代码实现

### 方法一：记忆化搜索

```python
from typing import List
from collections import Counter

class Solution:
    def minStickers(self, stickers: List[str], target: str) -> int:
        # 统计每个贴纸的字母频率
        sticker_counts = [Counter(s) for s in stickers]
        memo = {}
        
        def dfs(remain):
            if not remain:
                return 0
            if remain in memo:
                return memo[remain]
            
            remain_count = Counter(remain)
            result = float('inf')
            
            for sticker in sticker_counts:
                # 如果贴纸不包含 remain 的第一个字母，跳过
                if remain[0] not in sticker:
                    continue
                
                # 使用这个贴纸后剩余的字母
                new_remain = []
                for char in remain:
                    if sticker[char] > 0:
                        sticker[char] -= 1
                    else:
                        new_remain.append(char)
                
                if len(new_remain) < len(remain):
                    sub_result = dfs(''.join(new_remain))
                    if sub_result != -1:
                        result = min(result, 1 + sub_result)
            
            memo[remain] = result if result != float('inf') else -1
            return memo[remain]
        
        return dfs(target)
```

## 复杂度分析

- 时间复杂度：O(2^n * m)，n 是 target 长度，m 是贴纸数量
- 空间复杂度：O(2^n)

## 关键点总结

1. 使用记忆化搜索避免重复计算
2. 剪枝优化：跳过不包含当前字母的贴纸
3. 统计字母频率
