## 题目描述

请设计一个类，使该类的构造函数能够接收一个字符串数组。然后实现一个方法，该方法能够分别接收两个单词 `word1` 和 `word2`，并返回列表中这两个单词之间的最短距离。

您的方法将被以不同的参数调用多次。

**示例：**
```
假设 wordsDict = ["practice", "makes", "perfect", "coding", "makes"]

输入: word1 = "coding", word2 = "practice"
输出: 3

输入: word1 = "makes", word2 = "coding"
输出: 1
```

**注意：** 你可以假设 word1 和 word2 都在列表中。

## 解题思路

这道题是 [LeetCode 243](https://leetcode.com/problems/shortest-word-distance/) 的扩展，关键区别是**需要多次查询**。

**核心思想：**
- 由于需要多次查询，每次都遍历整个数组会超时
- 应该在构造函数中**预处理**，把每个单词的所有位置存储起来
- 查询时，只需要在两个位置列表中找最小距离

**关键观察：**
1. 预处理：用哈希表存储每个单词的所有出现位置
2. 查询：两个有序数组找最小差值，使用双指针
3. 时间换空间：构造时 O(n)，查询时 O(m+k)，其中 m、k 是两个单词出现的次数

**双指针查找最小距离：**
- 两个有序数组 positions1 和 positions2
- 使用两个指针 i、j，初始都指向数组开头
- 计算当前距离，然后移动较小的指针
- 这样可以在 O(m+k) 时间内找到最小距离

## Python 代码实现

### 方法一：哈希表 + 双指针（推荐）⭐

```python
from typing import List
from collections import defaultdict

class WordDistance:
    """
    预处理 + 双指针查询
    构造函数时间复杂度：O(n)，n 是数组长度
    shortest 方法时间复杂度：O(m+k)，m、k 是两个单词的出现次数
    空间复杂度：O(n)，存储所有单词的位置
    """
    
    def __init__(self, wordsDict: List[str]):
        # 哈希表：单词 -> 位置列表
        self.locations = defaultdict(list)
        
        # 预处理：记录每个单词的所有位置
        for i, word in enumerate(wordsDict):
            self.locations[word].append(i)
    
    def shortest(self, word1: str, word2: str) -> int:
        # 获取两个单词的位置列表
        positions1 = self.locations[word1]
        positions2 = self.locations[word2]
        
        # 双指针找最小距离
        min_distance = float('inf')
        i, j = 0, 0
        
        while i < len(positions1) and j < len(positions2):
            # 计算当前距离
            min_distance = min(min_distance, abs(positions1[i] - positions2[j]))
            
            # 移动较小的指针
            if positions1[i] < positions2[j]:
                i += 1
            else:
                j += 1
        
        return min_distance

```

### 方法二：暴力查询（不推荐，但易理解）

```python
from typing import List
from collections import defaultdict

class WordDistance:
    """
    预处理 + 暴力查询
    shortest 方法时间复杂度：O(m*k)，对于多次查询效率低
    """
    
    def __init__(self, wordsDict: List[str]):
        self.locations = defaultdict(list)
        for i, word in enumerate(wordsDict):
            self.locations[word].append(i)
    
    def shortest(self, word1: str, word2: str) -> int:
        positions1 = self.locations[word1]
        positions2 = self.locations[word2]
        
        # 暴力枚举所有组合
        min_distance = float('inf')
        for pos1 in positions1:
            for pos2 in positions2:
                min_distance = min(min_distance, abs(pos1 - pos2))
        
        return min_distance
```

### 方法三：优化的双指针（更简洁）

```python
from typing import List
from collections import defaultdict

class WordDistance:
    """
    优化后的双指针实现
    """
    
    def __init__(self, wordsDict: List[str]):
        self.word_positions = defaultdict(list)
        for idx, word in enumerate(wordsDict):
            self.word_positions[word].append(idx)
    
    def shortest(self, word1: str, word2: str) -> int:
        list1 = self.word_positions[word1]
        list2 = self.word_positions[word2]
        
        min_dist = float('inf')
        i = j = 0
        
        while i < len(list1) and j < len(list2):
            min_dist = min(min_dist, abs(list1[i] - list2[j]))
            
            # 优化：如果差值为 1，不可能更小，直接返回
            if min_dist == 1:
                return 1
            
            # 移动指针
            if list1[i] < list2[j]:
                i += 1
            else:
                j += 1
        
        return min_dist
```

### 方法四：使用 bisect 优化（Python 特色）

```python
from typing import List
from collections import defaultdict
import bisect

class WordDistance:
    """
    使用二分查找优化
    shortest 方法时间复杂度：O(m * log k) 或 O(k * log m)
    """
    
    def __init__(self, wordsDict: List[str]):
        self.locations = defaultdict(list)
        for i, word in enumerate(wordsDict):
            self.locations[word].append(i)
    
    def shortest(self, word1: str, word2: str) -> int:
        positions1 = self.locations[word1]
        positions2 = self.locations[word2]
        
        min_distance = float('inf')
        
        # 对于 positions1 中的每个位置，在 positions2 中二分查找最接近的位置
        for pos1 in positions1:
            # 找到 positions2 中 >= pos1 的第一个位置
            idx = bisect.bisect_left(positions2, pos1)
            
            # 检查该位置
            if idx < len(positions2):
                min_distance = min(min_distance, abs(positions2[idx] - pos1))
            
            # 检查前一个位置
            if idx > 0:
                min_distance = min(min_distance, abs(positions2[idx - 1] - pos1))
        
        return min_distance
```

## 复杂度分析

| 方法 | 构造函数 | shortest 方法 | 空间复杂度 | 说明 |
|------|---------|--------------|-----------|------|
| 暴力查询 | O(n) | O(m*k) | O(n) | 多次查询效率低 |
| 双指针 | O(n) | O(m+k) | O(n) | 推荐，最优解 |
| 二分查找 | O(n) | O(m*log k) | O(n) | Python 特色，但不如双指针 |

其中 n 是数组长度，m 和 k 是两个单词的出现次数。

## 关键点总结

1. **预处理思想**：多次查询的问题，通常需要预处理来优化
2. **哈希表存储**：用 defaultdict(list) 存储每个单词的所有位置
3. **双指针技巧**：两个有序数组找最小差值的经典算法
4. **时间权衡**：构造时花费 O(n)，每次查询只需 O(m+k)
5. **提前返回**：如果距离已经是 1，可以直接返回（不会有更小的）

## 易错点

1. **忘记预处理**：如果每次查询都遍历整个数组，会超时
2. **双指针移动**：要移动值较小的指针，而不是随机移动
3. **位置列表为空**：题目保证单词在列表中，所以不需要处理
4. **初始化哈希表**：使用 defaultdict(list) 避免 KeyError
5. **绝对值计算**：计算距离时要用 abs()，虽然可以优化掉
