## 题目描述

给定一个表示代码片段的字符串，你需要实现一个验证器来验证代码片段是否有效。

有效代码片段必须遵守以下规则：
1. 代码必须被有效的闭合标签包裹
2. 闭合标签必须严格匹配
3. TAG_NAME只包含大写字母，长度在[1,9]之间
4. 支持CDATA段

## Python 代码实现

```python
class Solution:
    def isValid(self, code: str) -> bool:
        """
        使用栈验证标签匹配
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        stack = []
        i = 0
        
        while i < len(code):
            # 如果栈空且不是以<开始，无效
            if not stack and i > 0:
                return False
            
            # 处理CDATA
            if code[i:i+9] == '<![CDATA[':
                if not stack:
                    return False
                j = i + 9
                i = code.find(']]>', j)
                if i < 0:
                    return False
                i += 3
                continue
            
            # 处理标签
            if code[i] == '<':
                # 闭合标签
                if i + 1 < len(code) and code[i+1] == '/':
                    j = code.find('>', i)
                    if j < 0:
                        return False
                    tag_name = code[i+2:j]
                    if not stack or stack[-1] != tag_name:
                        return False
                    stack.pop()
                    i = j + 1
                # 开始标签
                else:
                    j = code.find('>', i)
                    if j < 0:
                        return False
                    tag_name = code[i+1:j]
                    if not (1 <= len(tag_name) <= 9 and tag_name.isupper() and tag_name.isalpha()):
                        return False
                    stack.append(tag_name)
                    i = j + 1
            else:
                i += 1
        
        return not stack
```

## 关键点总结

1. **栈匹配**：使用栈验证标签配对
2. **CDATA处理**：特殊字符段
3. **边界检查**：标签名长度和字符限制
