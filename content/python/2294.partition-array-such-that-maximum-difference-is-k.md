## 题目描述

给你一个整数数组 `nums` 和整数 `k`。

你需要将 `nums` 划分为若干个子序列，每个子序列中最大值与最小值之差不超过 `k`。

返回划分所需的**最少子序列数量**。

注意：子序列不要求是连续的，可以从任意位置抽取元素组成子序列。

**示例 1：**
```
输入：nums = [3,6,1,2,5], k = 2
输出：2
解释：[1,2,3] 差值 2，[5,6] 差值 1。
```

**示例 2：**
```
输入：nums = [1,2,3], k = 1
输出：2
解释：[1,2] 和 [3]，或 [1] 和 [2,3]。
```

## 解题思路

**贪心 + 排序：**

将 `nums` 排序后，贪心地将连续元素放入同一子序列：从第一个元素开始，尽量将后续元素加入当前子序列，直到某元素与当前子序列最小值之差超过 `k`，则开启新子序列。

贪心正确性：排序后相邻元素之差最小，将尽可能多的连续元素放在一起可以最少化子序列数。

## 代码实现

### 方法一：排序贪心（推荐）

```python
from typing import List

class Solution:
    def partitionArray(self, nums: List[int], k: int) -> int:
        nums.sort()
        count = 1           # 至少一个子序列
        start = nums[0]     # 当前子序列的最小值

        for num in nums[1:]:
            if num - start > k:
                # 当前元素不能放入当前子序列，开新序列
                count += 1
                start = num  # 新子序列从当前元素开始

        return count
```

### 方法二：更明确的写法

```python
from typing import List

class Solution:
    def partitionArray(self, nums: List[int], k: int) -> int:
        nums.sort()
        ans = 0
        i = 0
        n = len(nums)

        while i < n:
            ans += 1
            min_val = nums[i]
            # 将所有不超过 min_val + k 的元素放入当前子序列
            while i < n and nums[i] - min_val <= k:
                i += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序。
- 空间复杂度：O(1)（不计排序空间）。

## 关键点总结

1. 排序后，同一子序列的元素在排好序的数组中必然连续（贪心最优）。
2. 每个子序列以当前最小值 `start` 为基准，尽量延伸到 `start + k`。
3. 遇到超出范围的元素，另起一个子序列。

## 易错点

- 子序列不需要连续，但排序后连续选取是最优策略。
- 注意是最大值与最小值之差 `<= k`，不是严格小于。
