## 题目描述

给你一个整数数组 `nums`，以及两个整数 `start` 和 `goal`。

每次操作可以：
- 从 `nums` 中选一个数 `x`
- 将当前值做 `+x`、`-x` 或 `^ x`（异或）操作

操作中途的值必须在 `[0, 1000]` 范围内，否则不合法。

返回从 `start` 到 `goal` 的最少操作次数，若无法到达返回 `-1`。

**示例 1：**
```
输入：nums = [2,4,12], start = 2, goal = 12
输出：2
解释：2^2=0, 0+12=12
```

**提示：**
- `1 <= nums.length <= 1000`
- `-1000 <= nums[i] <= 1000`
- `0 <= start, goal <= 1000`

## 解题思路

**BFS（最短路）：** 从 `start` 出发，每次用 `nums` 中所有数做 3 种操作，找到 `goal` 的最短步数。

**关键：** 中间值不需要在 `[0, 1000]` 范围内（题目说操作中途的值必须在 `[0, 1000]`），但 `goal` 可以不在此范围（因为操作后如果等于 goal 就立即返回，不需要继续）。

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumOperations(self, nums: List[int], start: int, goal: int) -> int:
        visited = set([start])
        queue = deque([(start, 0)])

        while queue:
            val, steps = queue.popleft()

            for x in nums:
                for new_val in [val + x, val - x, val ^ x]:
                    if new_val == goal:
                        return steps + 1
                    # 只有在 [0, 1000] 范围内的中间值才能继续
                    if 0 <= new_val <= 1000 and new_val not in visited:
                        visited.add(new_val)
                        queue.append((new_val, steps + 1))

        return -1
```

### 方法二：BFS + 访问数组优化

```python
from typing import List
from collections import deque

class Solution:
    def minimumOperations(self, nums: List[int], start: int, goal: int) -> int:
        if start == goal:
            return 0

        visited = [False] * 1001
        visited[start] = True
        queue = deque([start])
        steps = 0

        while queue:
            steps += 1
            for _ in range(len(queue)):
                val = queue.popleft()
                for x in nums:
                    for new_val in (val + x, val - x, val ^ x):
                        if new_val == goal:
                            return steps
                        if 0 <= new_val <= 1000 and not visited[new_val]:
                            visited[new_val] = True
                            queue.append(new_val)

        return -1
```

## 复杂度分析

- 时间复杂度：O(1001 * |nums|)，每个值最多访问一次，对每个值枚举所有操作
- 空间复杂度：O(1001)，访问数组

## 关键点总结

1. BFS 保证最少操作次数
2. 中间值超出 `[0, 1000]` 时跳过（不入队），但若等于 `goal` 直接返回
3. `goal` 可以超出 `[0, 1000]`，但必须是操作的直接结果

## 易错点

- 检查 `new_val == goal` 需要在范围检查**之前**（goal 可能超出 `[0, 1000]`）
- 负数结果（`val - x` 可能为负）不能入队但可能等于 goal
