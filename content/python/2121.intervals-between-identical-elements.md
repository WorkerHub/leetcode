## 题目描述

给你一个下标从 **0** 开始的数组 `arr`。

`arr[i]` 对应的**间距之和**等于所有 `j` 满足 `arr[j] == arr[i]` 的 `|i - j|` 之和。

返回长度与 `arr` 相同的数组 `intervals`，其中 `intervals[i]` 是 `arr[i]` 的间距之和。

**示例：**
```
输入：arr = [2,1,3,1,2,3,3]
输出：[4,2,7,2,4,4,5]
解释：
- i=0 (值2)：|0-4|=4
- i=1 (值1)：|1-3|=2
- i=3 (值1)：|3-1|=2
- i=4 (值2)：|4-0|=4
- i=2 (值3)：|2-5|+|2-6|=3+4=7
- i=5 (值3)：|5-2|+|5-6|=3+1=4
- i=6 (值3)：|6-2|+|6-5|=4+1=5
```

**提示：**
- `1 <= arr.length <= 10^5`

## 解题思路

**前缀和优化**

对每个值，收集其所有出现位置 `positions = [p0, p1, ..., pk]`。

对于位置 `positions[i]`，其间距之和 = 左侧所有位置到 `positions[i]` 的距离 + 右侧所有位置到 `positions[i]` 的距离。

- 左侧：设前 i 个位置的下标之和为 `prefix[i]`，距离之和 = `i * positions[i] - prefix[i]`。
- 右侧：设后 (k-i) 个位置下标之和为 `suffix[i]`，距离之和 = `suffix[i] - (k - i) * positions[i]`。

合并后用前缀和 O(n) 计算。

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def getDistances(self, arr: List[int]) -> List[int]:
        n = len(arr)
        # 收集每个值的出现下标
        pos_map = defaultdict(list)
        for i, v in enumerate(arr):
            pos_map[v].append(i)

        result = [0] * n

        for positions in pos_map.values():
            k = len(positions)
            # 计算前缀和
            prefix = [0] * (k + 1)
            for j in range(k):
                prefix[j + 1] = prefix[j] + positions[j]

            for j in range(k):
                p = positions[j]
                # 左侧 j 个位置贡献
                left = j * p - prefix[j]
                # 右侧 (k-1-j) 个位置贡献
                right = (prefix[k] - prefix[j + 1]) - (k - 1 - j) * p
                result[p] = left + right

        return result
```

### 方法二：双向遍历（无显式前缀和数组）

```python
from typing import List
from collections import defaultdict

class Solution:
    def getDistances(self, arr: List[int]) -> List[int]:
        pos_map = defaultdict(list)
        for i, v in enumerate(arr):
            pos_map[v].append(i)

        result = [0] * len(arr)

        for positions in pos_map.values():
            # 从左到右，累加左侧距离
            running_sum = 0
            count = 0
            for j, p in enumerate(positions):
                result[p] += j * p - running_sum
                running_sum += p

            # 从右到左，累加右侧距离
            running_sum = 0
            count = len(positions)
            for j in range(count - 1, -1, -1):
                p = positions[j]
                result[p] += running_sum - (count - 1 - j) * p
                running_sum += p

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(n) |

## 关键点总结

1. 分组处理：同值的下标放一组，组内计算间距之和。
2. 利用前缀和将 O(k^2) 的暴力变为 O(k)。
3. 左侧贡献 = `j * p - prefix[j]`，右侧贡献 = `suffix - (k-1-j) * p`。

## 易错点

- 下标从 0 开始，前缀和的起始值为 0，计算时要注意偏移。
- 结果数组 `result[p]` 用的是原始下标 p，不是在 positions 中的序号 j。
