## 题目描述

给你一个整数数组 `nums` 和两个整数 `k` 与 `x`。

对于 `nums` 中每个长度为 `k` 的子数组，计算该子数组的 **x-sum**：
- 统计子数组中每个数字的出现次数。
- 选出出现次数最多的 `x` 个不同数字（若出现次数相同，选数值较大的）。
- x-sum 是这 `x` 个数字的 **出现次数 * 数字值** 之和。
- 若子数组中不同数字少于 `x` 个，则 x-sum 是所有数字的贡献之和。

返回所有长度为 `k` 的子数组的 x-sum 数组。

**示例：**
```
输入：nums = [1,1,2,2,3,4,2,3], k = 6, x = 2
输出：[6, 10, 12]
解释：[1,1,2,2,3,4]：freq={1:2,2:2,3:1,4:1}，top2按(freq,val)降序：(2,2),(2,1)，x-sum=2*2+2*1=6
     [1,2,2,3,4,2]：freq={2:3,1:1,3:1,4:1}，top2：(3,2),(1,4)，x-sum=3*2+1*4=10
     [2,2,3,4,2,3]：freq={2:3,3:2,4:1}，top2：(3,2),(2,3)，x-sum=3*2+2*3=12
```

**提示：**
- `nums.length <= 50`
- `1 <= x <= k <= nums.length`
- `1 <= nums[i] <= 50`

## 解题思路

由于数据范围很小（n <= 50），可以直接用暴力方法：对每个长度为 k 的子数组，统计频率，排序后取前 x 个，计算 x-sum。

## Python 代码实现

### 方法一：暴力模拟（推荐，适合小数据）

```python
from typing import List
from collections import Counter

class Solution:
    def findXSum(self, nums: List[int], k: int, x: int) -> List[int]:
        n = len(nums)
        result = []
        
        for i in range(n - k + 1):
            # 统计子数组 nums[i..i+k-1] 中每个数的出现次数
            window = nums[i:i + k]
            freq = Counter(window)
            
            # 按 (频率降序, 数值降序) 排序，取前 x 个
            top_x = sorted(freq.items(), key=lambda item: (item[1], item[0]), reverse=True)[:x]
            
            # 计算 x-sum
            x_sum = sum(val * cnt for val, cnt in top_x)
            result.append(x_sum)
        
        return result
```

### 方法二：滑动窗口（适合大数据量时使用）

```python
from typing import List
from collections import Counter

class Solution:
    def findXSum(self, nums: List[int], k: int, x: int) -> List[int]:
        n = len(nums)
        result = []
        freq = Counter()
        
        def compute_xsum():
            # 取出现频率前 x 的数字（相同频率取数值大的）
            top = sorted(freq.items(), key=lambda p: (p[1], p[0]), reverse=True)[:x]
            return sum(v * c for v, c in top)
        
        # 初始化第一个窗口
        for i in range(k):
            freq[nums[i]] += 1
        result.append(compute_xsum())
        
        # 滑动窗口
        for i in range(1, n - k + 1):
            # 移出最左元素
            out = nums[i - 1]
            freq[out] -= 1
            if freq[out] == 0:
                del freq[out]
            # 加入新元素
            freq[nums[i + k - 1]] += 1
            result.append(compute_xsum())
        
        return result
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n * k * log k)，每个子数组统计+排序
- 空间复杂度：O(k)

**方法二：**
- 时间复杂度：O(n * k * log k)，排序部分仍是 O(k log k)；若用堆维护则可优化
- 空间复杂度：O(k)

## 关键点总结

1. x-sum 是出现次数 top-x 的数字的 `出现次数 * 数值` 之和。
2. 排序键：先按频率降序，频率相同时按数值降序。
3. 本题数据范围小（n <= 50），暴力即可。

## 易错点

1. 排序时既要考虑频率也要考虑数值，两者都需要降序。
2. 若不同数字总数 < x，则全取（自然 sorted[:x] 会取全部）。
3. x-sum 是 `freq * val` 的求和，不是单纯频率或数值之和。
