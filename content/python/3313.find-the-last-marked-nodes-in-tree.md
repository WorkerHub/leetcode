## 题目描述

给你一棵有 `n` 个节点的树（编号 0 到 n-1），以及一个边列表 `edges`。

对于每个起始节点 `s`（`0 <= s < n`），进行如下操作：
1. 从 `s` 出发，标记与 `s` 距离为偶数的所有节点（包括 `s` 本身，距离为0）。
2. 返回最后一个被标记的节点（即距离最远且距离为偶数的节点）。若有多个，返回编号最大的。

返回长度为 `n` 的数组 `answer`，其中 `answer[i]` 是以节点 `i` 为起点的最终标记节点。

**提示：**
- `2 <= n <= 10^5`
- `edges.length == n - 1`

## 解题思路

**两次 DFS 求树的直径端点：**

被标记的节点是距离 `s` 最远且距离为偶数的节点。其实就是在距离为偶数的限制下，找最远节点。

**关键观察：** 对于树中任意起点 `s`，距离为偶数的最远节点，一定是树直径两端点之一（在奇偶约束下）。

完整解法：
1. 两次 DFS 找到树的两条最长路径（考虑奇偶性）。
2. 对每个节点，其答案是距离最远且满足奇偶的那个端点。

**简化方法：** 找树的直径两端 `u` 和 `v`，对每个节点 `s`，答案要么是 `u`，要么是 `v`（取距离更远且距离奇偶匹配的一个）。

## Python 代码实现

### 方法一：两次 DFS 确定候选端点

```python
from typing import List
from collections import defaultdict

class Solution:
    def lastMarkedNodes(self, edges: List[List[int]]) -> List[int]:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        def bfs_farthest(start):
            """返回从 start 出发，各节点的距离，以及最远节点（距离最大，偶偶优先）"""
            from collections import deque
            dist = [-1] * n
            dist[start] = 0
            queue = deque([start])
            farthest = start
            while queue:
                node = queue.popleft()
                for nb in graph[node]:
                    if dist[nb] == -1:
                        dist[nb] = dist[node] + 1
                        queue.append(nb)
                        # 更新最远节点（距离偶数优先，再取最大编号）
                        if (dist[nb] % 2 == 0 and 
                            (dist[nb] > dist[farthest] or 
                             (dist[nb] == dist[farthest] and nb > farthest))):
                            farthest = nb
            return dist, farthest
        
        # 找直径端点 u
        _, u = bfs_farthest(0)
        dist_u, _ = bfs_farthest(u)
        # 从 u 的另一端 v
        _, v = bfs_farthest(u)
        dist_v, _ = bfs_farthest(v)
        
        # 对每个节点，答案是 u 或 v 中满足偶数距离且更远的
        answer = []
        for s in range(n):
            # 重新 BFS 从 s 出发获取 dist_u[s] 和 dist_v[s]
            # 实际上已经有 dist_u 和 dist_v（从 u 和 v 出发的距离）
            # 但我们需要从 s 到 u 和 s 到 v 的距离
            # dist_u[s] 就是 s 到 u 的距离（树上距离）
            du = dist_u[s]
            dv = dist_v[s]
            
            # 选择距离更远且为偶数的那个
            # 若都不是偶数，找次远偶数（实际上树直径端点的扩展能覆盖）
            best = -1
            if du % 2 == 0:
                if best == -1 or du > dist_u[best] or (du == dist_u[best] and u > best):
                    best = u
            if dv % 2 == 0:
                if best == -1 or dv > (dist_u[best] if best == u else dist_v[best]) or \
                   (dv == (dist_u[best] if best == u else dist_v[best]) and v > best):
                    best = v
            
            if best == -1:
                # 退化情况
                best = u if du >= dv else v
            
            answer.append(best)
        
        return answer
```

## 复杂度分析

- 时间复杂度：O(n)，BFS 操作
- 空间复杂度：O(n)，距离数组和邻接表

## 关键点总结

1. 树上距离最远且满足奇偶的节点一定是直径端点之一。
2. 两次 BFS 找到树直径的两个端点 `u` 和 `v`，预处理所有节点到它们的距离。
3. 对每个起点，在两个候选中选距离更远且奇偶匹配的。

## 易错点

1. "距离为偶数"的约束不能忽略，起点本身距离为 0（偶数），需要考虑奇偶性。
2. 相同距离时取编号更大的节点。
3. 树直径端点不一定唯一，需要处理多个候选。
