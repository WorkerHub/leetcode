## 题目描述

给你一个字符串 `s`，它由数字（`'0'` - `'9'`）和 `'#'` 组成。我们希望按下述规则将 `s` 映射为一些小写英文字符：

- 字符（`'a'` - `'i'`）分别用（`'1'` - `'9'`）表示
- 字符（`'j'` - `'z'`）分别用（`'10#'` - `'26#'`）表示

返回映射之后形成的新字符串。

题目数据保证映射始终唯一。

示例 1：
```
输入：s = "10#11#12"
输出："jkab"
解释："j" -> "10#" , "k" -> "11#" , "a" -> "1" , "b" -> "2"
```

示例 2：
```
输入：s = "1326#"
输出："acz"
```

示例 3：
```
输入：s = "25#"
输出："y"
```

提示：
- `1 <= s.length <= 1000`
- `s` 只包含数字和 `'#'` 字符
- `s` 是映射始终存在的有效字符串

## 解题思路

这道题的关键是识别两种模式：
1. 单个数字 `'1'-'9'` 映射到 `'a'-'i'`
2. 两位数字 + `'#'`（如 `'10#'`）映射到 `'j'-'z'`

### 思路一：从右向左遍历
从右向左遍历字符串，遇到 `'#'` 就取前面两位数字，否则取一位数字。

### 思路二：从左向右遍历
从左向右遍历，检查当前位置后面第二个字符是否为 `'#'`。

## Python 代码实现

### 方法一：从右向左（推荐）⭐

```python
class Solution:
    def freqAlphabets(self, s: str) -> str:
        result = []
        i = len(s) - 1
        
        while i >= 0:
            # 如果当前是 '#'，取前面两位数字
            if s[i] == '#':
                num = int(s[i-2:i])
                result.append(chr(ord('a') + num - 1))
                i -= 3
            else:
                # 单个数字
                num = int(s[i])
                result.append(chr(ord('a') + num - 1))
                i -= 1
        
        # 反转结果（因为是从右向左处理的）
        return ''.join(reversed(result))
```

### 方法二：从左向右

```python
class Solution:
    def freqAlphabets(self, s: str) -> str:
        result = []
        i = 0
        
        while i < len(s):
            # 检查后面第二个位置是否有 '#'
            if i + 2 < len(s) and s[i + 2] == '#':
                # 取两位数字
                num = int(s[i:i+2])
                result.append(chr(ord('a') + num - 1))
                i += 3
            else:
                # 单个数字
                num = int(s[i])
                result.append(chr(ord('a') + num - 1))
                i += 1
        
        return ''.join(result)
```

### 方法三：正则表达式

```python
import re

class Solution:
    def freqAlphabets(self, s: str) -> str:
        # 替换所有 数字# 模式
        def replace_match(match):
            num = int(match.group(0)[:-1])  # 去掉 '#'
            return chr(ord('a') + num - 1)
        
        # 先处理两位数 + '#' 的情况
        s = re.sub(r'\d{2}#', replace_match, s)
        
        # 再处理单个数字
        result = []
        for char in s:
            if char.isdigit():
                result.append(chr(ord('a') + int(char) - 1))
            else:
                result.append(char)
        
        return ''.join(result)
```

### 方法四：Python 简洁写法

```python
class Solution:
    def freqAlphabets(self, s: str) -> str:
        # 替换策略：先替换长的模式，再替换短的
        for i in range(26, 0, -1):
            if i > 9:
                s = s.replace(f"{i}#", chr(ord('a') + i - 1))
            else:
                s = s.replace(str(i), chr(ord('a') + i - 1))
        return s
```

### 方法五：栈

```python
class Solution:
    def freqAlphabets(self, s: str) -> str:
        stack = []
        
        for char in s:
            stack.append(char)
            
            # 检查栈顶是否形成 数字数字# 模式
            if len(stack) >= 3 and stack[-1] == '#':
                stack.pop()  # 移除 '#'
                digit2 = stack.pop()
                digit1 = stack.pop()
                num = int(digit1 + digit2)
                stack.append(chr(ord('a') + num - 1))
        
        # 处理剩余的单个数字
        result = []
        for item in stack:
            if item.isdigit():
                result.append(chr(ord('a') + int(item) - 1))
            else:
                result.append(item)
        
        return ''.join(result)
```

## 复杂度分析

### 方法一、二
- 时间复杂度：O(n)，遍历一次字符串
- 空间复杂度：O(n)，存储结果

### 方法三
- 时间复杂度：O(n)，正则替换
- 空间复杂度：O(n)

### 方法四
- 时间复杂度：O(26n) = O(n)，26 次替换操作
- 空间复杂度：O(n)

## 关键点总结

1. 识别两种模式：单数字和双数字+#
2. 从右向左处理可以直接判断是否为 '#'
3. 从左向右需要向前看两位
4. 使用 `chr(ord('a') + num - 1)` 转换数字到字母
5. 字符串替换是最简洁的方法

## 易错点

1. 数字到字母的转换公式错误（应该是 `num - 1`）
2. 从右向左遍历后忘记反转结果
3. 边界检查不完整（检查 `i + 2 < len(s)`）
4. 忘记处理 '#' 字符（在栈方法中）

## 图解示例

以 s = "10#11#12" 为例（从左向右）：

```
位置 0: s[0:2] = "10", s[2] = '#'
  → 匹配 "10#"，转换为 'j'，i 移动到 3

位置 6: s[6] = "1", i+2 >= len(s)
  → 单个数字，转换为 'a'，i 移动到 7

位置 7: s[7] = "2"
  → 单个数字，转换为 'b'，i 移动到 8

结果："jkab"
```
