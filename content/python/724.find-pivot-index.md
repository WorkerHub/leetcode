## 题目描述

给你一个整数数组 `nums`，请计算数组的 **中心下标**。

数组 **中心下标** 是数组的一个下标，其左侧所有元素相加的和等于右侧所有元素相加的和。

如果中心下标位于数组最左端，那么左侧数之和视为 `0`，因为在下标的左侧不存在元素。这一点对于中心下标位于数组最右端同样适用。

如果数组有多个中心下标，应该返回 **最靠近左边** 的那一个。如果数组不存在中心下标，返回 `-1`。

**示例 1：**

```
输入：nums = [1,7,3,6,5,6]
输出：3
解释：
中心下标是 3 。
左侧数之和 sum = nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11 ，
右侧数之和 sum = nums[4] + nums[5] = 5 + 6 = 11 ，二者相等。
```

**示例 2：**

```
输入：nums = [1,2,3]
输出：-1
解释：
数组中不存在满足此条件的中心下标。
```

**示例 3：**

```
输入：nums = [2,1,-1]
输出：0
解释：
中心下标是 0 。
左侧数之和 sum = 0 ，（下标 0 左侧不存在元素），
右侧数之和 sum = nums[1] + nums[2] = 1 + -1 = 0 。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

## 解题思路

**核心思想：前缀和**

利用前缀和的性质，对于索引 `i`：
- 左侧和 = `prefix_sum[i]`
- 右侧和 = `total_sum - prefix_sum[i] - nums[i]`
- 如果相等，则 `i` 是中心索引

**优化：**
不需要额外数组，用一个变量维护左侧和即可。

## Python 代码实现

### 方法一：前缀和（推荐）⭐

```python
from typing import List

class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        """
        使用前缀和思想
        """
        total = sum(nums)
        left_sum = 0
        
        for i, num in enumerate(nums):
            # 右侧和 = 总和 - 左侧和 - 当前值
            right_sum = total - left_sum - num
            
            if left_sum == right_sum:
                return i
            
            # 更新左侧和
            left_sum += num
        
        return -1
```

### 方法二：详细注释版

```python
class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        # 计算数组总和
        total_sum = sum(nums)
        
        # 左侧和初始化为 0
        left_sum = 0
        
        # 遍历每个位置
        for i in range(len(nums)):
            # 计算右侧和：总和 - 左侧和 - 当前元素
            right_sum = total_sum - left_sum - nums[i]
            
            # 检查是否为中心索引
            if left_sum == right_sum:
                return i
            
            # 将当前元素加入左侧和
            left_sum += nums[i]
        
        # 没有找到中心索引
        return -1
```

### 方法三：公式推导

```python
class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        """
        推导：left_sum = right_sum
        即：left_sum = total - left_sum - nums[i]
        即：2 * left_sum = total - nums[i]
        即：left_sum = (total - nums[i]) / 2
        """
        total = sum(nums)
        left_sum = 0
        
        for i, num in enumerate(nums):
            # 检查是否满足条件
            if 2 * left_sum == total - num:
                return i
            left_sum += num
        
        return -1
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历两次数组（一次求和，一次查找）
- **空间复杂度：** O(1)

## 图解示例

以 `nums = [1,7,3,6,5,6]` 为例：

```
索引:    0  1  2  3  4  5
数组:   [1, 7, 3, 6, 5, 6]
总和:   28

i=0: left=0, right=27  (0≠27)  ✗
i=1: left=1, right=20  (1≠20)  ✗
i=2: left=8, right=17  (8≠17)  ✗
i=3: left=11, right=11 (11=11) ✓ 返回 3

验证:
左侧: 1 + 7 + 3 = 11
右侧: 5 + 6 = 11
```

## 关键点总结

1. **前缀和思想**：维护左侧和，右侧和可以通过总和计算
2. **空间优化**：不需要额外数组，一个变量即可
3. **边界处理**：左右端点的和视为 0
4. **返回最左**：从左到右遍历，第一个满足条件的就是答案
5. **数学变换**：可以转化为 `2 * left_sum == total - nums[i]`

## 易错点

1. **边界情况**：数组只有一个元素时，左右和都是 0
2. **计算顺序**：要先判断再更新 `left_sum`
3. **右侧和计算**：是 `total - left_sum - nums[i]`，不要漏减 `nums[i]`
4. **负数处理**：数组中有负数时逻辑不变
5. **返回值**：没找到返回 -1，不是 0
