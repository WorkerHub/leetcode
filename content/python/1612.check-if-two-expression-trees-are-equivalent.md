## 题目描述

**二叉表达式树**是一种表达数学表达式的二叉树。二叉表达式树的每个节点是 `+` 运算符（加法）或变量（小写英文字母）。

给你两棵二叉表达式树的根节点，如果这两棵树所表示的表达式**等价**，则返回 `true`，否则返回 `false`。

两棵树等价：对于所有变量的任意赋值，两棵树的值都相等。

**注意：** 只含加法运算，交换律和结合律都成立，所以只需比较每个变量出现的**净次数**（可以相互抵消）。

**示例：**
```
输入：root1 = [x], root2 = [x]
输出：true

输入：root1 = [+,a,+,null,null,b,c], root2 = [+,+,b,a,c]
输出：true
（a+b+c = a+b+c）
```

## 解题思路

由于只有加法运算，两棵树等价当且仅当每个变量的出现**次数相同**。

**方法：**
1. 对每棵树进行 DFS，统计每个变量叶节点的出现次数
2. 比较两棵树的变量计数是否完全相同

## 代码实现

### 方法一：DFS 统计变量频次（推荐）

```python
from collections import defaultdict

class Node:
    def __init__(self, val=' ', left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def checkEquivalence(self, root1: Node, root2: Node) -> bool:
        def count_vars(node: Node, freq: dict):
            """DFS 统计所有变量叶节点的出现次数"""
            if not node:
                return
            if node.val != '+':
                # 叶节点，是变量
                freq[node.val] += 1
            else:
                count_vars(node.left, freq)
                count_vars(node.right, freq)
        
        freq1 = defaultdict(int)
        freq2 = defaultdict(int)
        count_vars(root1, freq1)
        count_vars(root2, freq2)
        
        return freq1 == freq2
```

### 方法二：差分计数（一次 DFS）

```python
from collections import defaultdict

class Solution:
    def checkEquivalence(self, root1: Node, root2: Node) -> bool:
        diff = defaultdict(int)
        
        def traverse(node: Node, sign: int):
            """sign=+1 表示加上这棵树的贡献，sign=-1 表示减去"""
            if not node:
                return
            if node.val != '+':
                diff[node.val] += sign
            else:
                traverse(node.left, sign)
                traverse(node.right, sign)
        
        traverse(root1, 1)   # 加上 root1 的贡献
        traverse(root2, -1)  # 减去 root2 的贡献
        
        # 所有差值为 0 则等价
        return all(v == 0 for v in diff.values())
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 统计 | O(m + n) | O(26) = O(1) |
| 差分计数 | O(m + n) | O(26) = O(1) |

m, n 分别为两棵树的节点数。变量只有 26 个小写字母，空间 O(1)。

## 关键点总结

1. 只有加法运算，加法满足交换律和结合律，只需比较变量频次
2. DFS 遍历叶节点（变量），内部节点（`+`）不计入统计
3. 差分法更优雅：一次遍历即可完成比较

## 易错点

- 内部节点是 `+`，不是变量，不应该计入频次
- 注意两棵树都要完整遍历，不能只遍历其中一棵
- 变量只有小写字母（最多 26 种），可以用数组代替字典
