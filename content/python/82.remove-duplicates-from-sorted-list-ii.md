## 题目描述

给定一个已排序的链表的头 `head`，删除原始链表中所有重复数字的节点，只留下不同的数字。返回已排序的链表。

**示例 1：**
```
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

**示例 2：**
```
输入：head = [1,1,1,2,3]
输出：[2,3]
```

**提示：**
- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序排列

## 解题思路

**核心思想：** 使用虚拟头节点 + 双指针，一旦发现重复节点，就跳过所有相同值的节点。

**关键观察：**
1. 与第83题不同，本题要删除所有重复的节点，而不是保留一个
2. 需要虚拟头节点，因为头节点也可能被删除
3. 需要一个前驱指针指向最后一个不重复的节点

**算法流程：**
1. 创建虚拟头节点 `dummy`，指向 `head`
2. 使用 `prev` 指针指向虚拟头节点，`curr` 指针指向 `head`
3. 遍历链表，如果 `curr.val == curr.next.val`，说明有重复
4. 继续移动 `curr` 跳过所有相同值的节点
5. `prev.next` 指向跳过后的节点
6. 如果没有重复，`prev` 和 `curr` 都正常移动

## Python 代码实现

### 方法一：虚拟头节点 + 双指针（推荐）

```python
from typing import Optional

# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 创建虚拟头节点
        dummy = ListNode(0, head)
        prev = dummy  # prev 指向最后一个不重复的节点
        
        while head:
            # 检查是否有重复
            if head.next and head.val == head.next.val:
                # 跳过所有相同值的节点
                while head.next and head.val == head.next.val:
                    head = head.next
                # 删除所有重复节点
                prev.next = head.next
            else:
                # 没有重复，prev 正常移动
                prev = prev.next
            
            # head 移动到下一个节点
            head = head.next
        
        return dummy.next
```

### 方法二：递归

```python
from typing import Optional

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 递归终止条件
        if not head or not head.next:
            return head
        
        # 如果当前节点与下一个节点值相同
        if head.val == head.next.val:
            # 跳过所有相同值的节点
            while head.next and head.val == head.next.val:
                head = head.next
            # 递归处理剩余部分（注意：当前节点也要跳过）
            return self.deleteDuplicates(head.next)
        else:
            # 当前节点不重复，递归处理下一个节点
            head.next = self.deleteDuplicates(head.next)
            return head
```

### 方法三：一次遍历（简化版）

```python
from typing import Optional

class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        curr = dummy
        
        while curr.next and curr.next.next:
            # 如果下两个节点值相同
            if curr.next.val == curr.next.next.val:
                val = curr.next.val
                # 跳过所有相同值的节点
                while curr.next and curr.next.val == val:
                    curr.next = curr.next.next
            else:
                curr = curr.next
        
        return dummy.next
```

## 复杂度分析

**方法一（迭代）：**
- 时间复杂度：O(n)，每个节点最多访问一次
- 空间复杂度：O(1)

**方法二（递归）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归调用栈

## 关键点总结

1. **虚拟头节点**：处理头节点可能被删除的情况
2. **prev 指针**：指向最后一个确定保留的节点
3. **跳过逻辑**：发现重复时，要跳过所有相同值的节点（包括第一个）
4. **移动时机**：只有确定不重复时，prev 才移动

## 易错点

1. **删除不完全**：发现重复后，要删除所有相同值的节点，不能保留一个
2. **prev 移动时机**：只有在确定节点不重复时才移动 prev
3. **边界条件**：空链表或单节点链表要特殊处理
