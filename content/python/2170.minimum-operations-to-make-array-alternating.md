## 题目描述

给你一个下标从 **0** 开始的数组 `nums`，包含 `n` 个正整数。

如果满足下述条件，则称数组是**交替数组**：
- 奇数下标处的元素相等。
- 偶数下标处的元素相等。
- 奇数下标和偶数下标处的元素**不同**。

每次操作可以选择任意下标并将该位置的元素改为**任意值**。

返回使数组变成交替数组所需的**最少操作次数**。

**示例：**
```
输入：nums = [3,1,3,2,4,3]
输出：3
解释：将 [3,1,3,2,4,3] 改为 [3,1,3,1,3,1]：修改 nums[3]=1，nums[4]=3，nums[5]=1，共3次。
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**贪心：统计频率，选最优两个值**

目标：奇数下标全为某个值 `a`，偶数下标全为某个值 `b`，且 `a != b`。

最少操作 = n - （最多可以保留的元素数）。

对奇数/偶数下标分别统计最高频值和次高频值，然后贪心：
- 若最高频的奇数值 != 最高频的偶数值，直接选这两个，保留数最多。
- 若最高频的奇数值 == 最高频的偶数值，则必须其中一个选次高频。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        # 统计偶数下标和奇数下标的频率
        even_cnt = Counter(nums[::2])   # 偶数下标
        odd_cnt = Counter(nums[1::2])   # 奇数下标

        def top2(cnt: Counter):
            # 返回频率最高和次高的 (值, 频率) 对
            items = cnt.most_common(2)
            if len(items) == 0:
                return (0, 0), (0, 0)
            if len(items) == 1:
                return items[0], (0, 0)
            return items[0], items[1]

        (ev1, ef1), (ev2, ef2) = top2(even_cnt)
        (ov1, of1), (ov2, of2) = top2(odd_cnt)

        # 贪心：选择可以保留最多元素的方案
        if ev1 != ov1:
            keep = ef1 + of1
        else:
            # 选偶数最高频 + 奇数次高频，或偶数次高频 + 奇数最高频
            keep = max(ef1 + of2, ef2 + of1)

        return n - keep
```

### 方法二：完整枚举 top2

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        even_cnt = Counter(nums[i] for i in range(0, n, 2))
        odd_cnt = Counter(nums[i] for i in range(1, n, 2))

        # 获取频率最高的前两个
        even_top = even_cnt.most_common(2)
        odd_top = odd_cnt.most_common(2)

        # 补全到两个元素（方便后续统一处理）
        while len(even_top) < 2:
            even_top.append((-1, 0))
        while len(odd_top) < 2:
            odd_top.append((-1, 0))

        ev1, ef1 = even_top[0]
        ev2, ef2 = even_top[1]
        ov1, of1 = odd_top[0]
        ov2, of2 = odd_top[1]

        if ev1 != ov1:
            keep = ef1 + of1
        else:
            keep = max(ef1 + of2, ef2 + of1)

        return n - keep
```

## 关键点总结

1. 分别统计偶数/奇数下标的频率，取前两高频。
2. 若最高频的两个值不同，直接各选最高频，保留最多元素。
3. 若最高频值相同，二选一只能退而求其次，选两种方案中更优的。

## 易错点

- 当奇数或偶数下标元素为空时（n=1），需要处理空 Counter。
- 最高频值相同时，需要比较两种方案（偶高+奇次 vs 偶次+奇高）。
