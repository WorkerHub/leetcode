## 题目描述

给你一个正整数数组 `arr`，请你计算所有可能的**奇数长度子数组**的和。

子数组是数组中连续的一部分。

**示例 1：**
```
输入：arr = [1,4,2,5,3]
输出：58
解释：所有奇数长度子数组的和为：
[1] = 1, [4] = 4, [2] = 2, [5] = 5, [3] = 3, [1,4,2] = 7, [4,2,5] = 11, [2,5,3] = 10, [1,4,2,5,3] = 15，总和 = 58
```

## 解题思路

### 方法一：枚举所有奇数长度子数组

枚举所有起点 `i` 和奇数长度 `l`（1, 3, 5, ...），计算子数组和。

### 方法二：数学方法（统计每个元素的贡献）

`arr[i]` 被包含在多少个奇数长度子数组中？

- 左边有 `i` 个元素，右边有 `n-1-i` 个元素
- 包含 `arr[i]` 的子数组：左端选 `[0, i]`，右端选 `[i, n-1]`
- 总子数组数 = `(i+1) * (n-i)`
- 其中奇数长度的子数组数 = `ceil(total / 2) = (total + 1) // 2`

## 代码实现

### 方法一：枚举（推荐，简单）

```python
from typing import List

class Solution:
    def sumOddLengthSubarrays(self, arr: List[int]) -> int:
        n = len(arr)
        total = 0
        for i in range(n):
            for length in range(1, n - i + 1, 2):  # 奇数长度
                total += sum(arr[i:i+length])
        return total
```

### 方法二：前缀和（优化枚举）

```python
from typing import List

class Solution:
    def sumOddLengthSubarrays(self, arr: List[int]) -> int:
        n = len(arr)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + arr[i]

        total = 0
        for i in range(n):
            for length in range(1, n - i + 1, 2):
                total += prefix[i+length] - prefix[i]
        return total
```

### 方法三：数学方法（O(N)）

```python
from typing import List

class Solution:
    def sumOddLengthSubarrays(self, arr: List[int]) -> int:
        n = len(arr)
        total = 0
        for i, x in enumerate(arr):
            # arr[i] 所在子数组：左端在 [0,i]，右端在 [i, n-1]
            # 总共 (i+1)*(n-i) 个子数组
            # 奇数长度的有 ((i+1)*(n-i) + 1) // 2 个
            total += x * ((i + 1) * (n - i) + 1) // 2
        return total
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N^2) | O(1) |
| 方法二 | O(N^2) | O(N) |
| 方法三 | O(N) | O(1) |

## 关键点总结

1. 枚举所有起点和奇数长度，直接求和（O(N^3) 朴素，O(N^2) 用前缀和）
2. 数学方法：每个元素的贡献次数 = 奇数长度子数组包含它的次数
3. `(total + 1) // 2` 是 total 个整数中奇数个的数量

## 易错点

- 奇数长度步长为 2（`range(1, n-i+1, 2)`）
- 数学公式中 total = `(i+1) * (n-i)`，奇数长度数 = `(total + 1) // 2`
