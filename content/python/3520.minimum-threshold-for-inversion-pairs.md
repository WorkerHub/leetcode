## 题目描述

给定一个整数数组 `nums` 和整数 `k`。定义"阈值为 t 的逆序对"：对于 `i < j`，若 `nums[i] - nums[j] >= t`（即差值达到阈值），则 `(i, j)` 是一个逆序对。求最小的阈值 `t`，使得数组中阈值为 `t` 的逆序对数量恰好为 `k`。

**示例 1：**

```
输入：nums = [2, 1, 3], k = 1
输出：1
解释：阈值 t=1 时，逆序对 (0,1) 满足 2-1=1>=1，共1对。
```

**示例 2：**

```
输入：nums = [3, 2, 1], k = 3
输出：1
解释：阈值 t=1：(0,1), (0,2), (1,2) 共3对。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= n*(n-1)/2`

## 解题思路

二分答案 + 有序集合统计逆序对数。

关键观察：阈值 `t` 越小，满足条件的逆序对越多（单调性）。

二分 `t`：
- 对于给定 `t`，统计满足 `nums[i] - nums[j] >= t` 的对数
- 使用归并排序或有序集合统计满足条件的逆序对数

对于给定 `t`，统计逆序对：
- 从右向左遍历，维护有序集合
- 对于 `nums[i]`，查询集合中小于等于 `nums[i] - t` 的元素个数

二分范围：`t` 从 `1` 到 `max(nums) - min(nums)`。

## Python 代码实现

### 方法一：二分 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minimumThreshold(self, nums: List[int], k: int) -> int:
        n = len(nums)

        def count_pairs(t):
            # 统计满足 nums[i] - nums[j] >= t (i < j) 的对数
            sl = SortedList()
            count = 0
            for i in range(n - 1, -1, -1):
                # 找 sl 中 <= nums[i] - t 的元素数量
                threshold = nums[i] - t
                count += sl.bisect_right(threshold)
                sl.add(nums[i])
            return count

        # 二分答案
        lo, hi = 1, max(nums) - min(nums)
        if hi == 0:
            return 0

        ans = hi
        while lo <= hi:
            mid = (lo + hi) // 2
            if count_pairs(mid) >= k:
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1

        return ans
```

### 方法二：二分 + 归并排序统计逆序对

```python
from typing import List

class Solution:
    def minimumThreshold(self, nums: List[int], k: int) -> int:
        n = len(nums)

        def merge_count(arr, t):
            if len(arr) <= 1:
                return arr, 0
            mid = len(arr) // 2
            left, lc = merge_count(arr[:mid], t)
            right, rc = merge_count(arr[mid:], t)
            count = lc + rc
            # 统计跨左右的逆序对：left[i] - right[j] >= t
            j = 0
            for x in left:
                while j < len(right) and x - right[j] >= t:
                    j += 1
                count += j
            # 归并
            merged = []
            i = j = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i])
                    i += 1
                else:
                    merged.append(right[j])
                    j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged, count

        lo = 1
        hi = max(nums) - min(nums)
        if hi == 0:
            return 0

        ans = hi
        while lo <= hi:
            mid = (lo + hi) // 2
            _, cnt = merge_count(list(nums), mid)
            if cnt >= k:
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n * log(max_diff))，二分 O(log(max_diff)) 次，每次统计 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 逆序对数量随阈值 t 单调递减，满足二分条件
2. 对于固定 t，用有序集合或归并排序统计逆序对
3. 二分的范围是 `[1, max - min]`

## 易错点

1. 二分时寻找满足"对数 >= k"的最小阈值
2. 归并排序统计逆序对时，两指针方向需要正确
3. 当所有元素相等时（max == min），阈值无意义
