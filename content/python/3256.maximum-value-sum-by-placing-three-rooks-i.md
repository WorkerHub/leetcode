## 题目描述

给你一个 `m x n` 的整数矩阵 `board`，在其中放置**三个**车（rooks），使得任意两车不在同一行或同一列。

返回三个车所在格子的**最大值之和**。

**示例 1：**
```
输入：board = [[-3,1,1,1],[-3,1,1,1],[-3,1,1,1],[-3,1,1,1]]
输出：5
```

**示例 2：**
```
输入：board = [[1,2,3],[4,5,6],[7,8,9]]
输出：26
```

**提示：**
- `3 <= m == board.length <= 100`
- `3 <= n == board[0].length <= 100`
- `-10^9 <= board[i][j] <= 10^9`

## 解题思路

枚举中间行 `j`（第二个车的行），对于每行，找出所有列中最大的三个值。

然后对每种列组合（i行取col_i，j行取col_j，k行取col_k），选择使三列互不相同的最大组合。

优化：对每行只保留最大的 3 个值（因为三行选三列，每行最多用到前3大的列）。

枚举中间行的每一列，分别查找前面行和后面行中与当前列不冲突的最大值。

## Python 代码实现

### 方法一：枚举中间行 + 前缀/后缀最优（推荐）

```python
from typing import List

class Solution:
    def maximumValueSum(self, board: List[List[int]]) -> int:
        m, n = len(board), len(board[0])
        
        # 对每行，保留最大的 3 个 (value, col) 对
        def top3(row):
            vals = sorted([(board[row][c], c) for c in range(n)], reverse=True)
            return vals[:3]
        
        rows_top3 = [top3(r) for r in range(m)]
        
        # 预计算：prefix_best[i] = 前 i 行（0..i-1）中，可选的最优 (val, col)（前3个）
        # suffix_best[i] = 后面行（i+1..m-1）中，可选的最优（前3个）
        # 实际上只需要每行的 top3
        
        ans = float('-inf')
        
        # 枚举两个行（行 r1 < r2 < r3）
        # 为了效率，枚举中间行 r2
        # 预计算前缀最优（前 r2 行的 top3）
        
        # 简单方法：枚举 r1, r2，从后面找最好的 r3
        # O(m^2 * 9)（每行最多考虑 3 个列）
        
        # 前缀 top3（考虑 0..i 行）
        prefix = []
        for r in range(m):
            if r == 0:
                prefix.append(rows_top3[r])
            else:
                # 合并前一行和当前行的 top3
                combined = sorted(prefix[-1] + rows_top3[r], reverse=True)
                prefix.append(combined[:3])
        
        # 后缀 top3（考虑 i..m-1 行）
        suffix = [None] * m
        for r in range(m - 1, -1, -1):
            if r == m - 1:
                suffix[r] = rows_top3[r]
            else:
                combined = sorted(suffix[r + 1] + rows_top3[r], reverse=True)
                suffix[r] = combined[:3]
        
        # 枚举中间行 r2，以及 r2 的列 c2
        for r2 in range(1, m - 1):
            for v2, c2 in rows_top3[r2]:
                # 从前 r2-1 行找最好的（不含列 c2）
                for v1, c1 in prefix[r2 - 1]:
                    if c1 == c2:
                        continue
                    # 从后 r2+1 行找最好的（不含 c1, c2）
                    for v3, c3 in suffix[r2 + 1]:
                        if c3 != c1 and c3 != c2:
                            ans = max(ans, v1 + v2 + v3)
                            break
                    break  # 只需最大的 v1
        
        # 更精确的枚举
        ans = float('-inf')
        for r2 in range(1, m - 1):
            for v2, c2 in rows_top3[r2]:
                for v1, c1 in prefix[r2 - 1]:
                    if c1 == c2:
                        continue
                    for v3, c3 in suffix[r2 + 1]:
                        if c3 != c1 and c3 != c2:
                            ans = max(ans, v1 + v2 + v3)
                            break  # 找到最大的不冲突值
                    break  # 找到最大的不冲突 v1 后退出
        
        return ans
```

### 方法二：暴力枚举（适合小数据）

```python
from typing import List
from itertools import combinations

class Solution:
    def maximumValueSum(self, board: List[List[int]]) -> int:
        m, n = len(board), len(board[0])
        ans = float('-inf')
        
        for r1, r2, r3 in combinations(range(m), 3):
            for c1, c2, c3 in combinations(range(n), 3):
                s = board[r1][c1] + board[r2][c2] + board[r3][c3]
                ans = max(ans, s)
                # 也考虑其他列排列
            # 枚举所有列排列
            for c1 in range(n):
                for c2 in range(n):
                    if c2 == c1: continue
                    for c3 in range(n):
                        if c3 == c1 or c3 == c2: continue
                        ans = max(ans, board[r1][c1] + board[r2][c2] + board[r3][c3])
        
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(m * 27)，空间复杂度 O(m * 3)
- 方法二：时间复杂度 O(C(m,3) * n^3)，不推荐

## 关键点总结

1. 每行只保留前 3 大的值，因为 3 行选 3 个不同列，每行最多用到前 3 名
2. 前缀和后缀维护前/后若干行的最优候选
3. 枚举中间行，在前缀和后缀中找不冲突的最优值

## 易错点

1. 三个车必须在不同行且不同列
2. 每行的 top3 需要记录列号，用于冲突检测
