## 题目描述

给你两个链表 `list1` 和 `list2`，链表的下标从 `0` 开始。

将 `list1` 中下标从 `a` 到 `b` 的节点（含端点）删除，并将 `list2` 插入到被删除节点的位置。

返回修改后的 `list1`。

**示例：**
```
输入：list1 = [0,1,2,3,4,5], a = 3, b = 4, list2 = [1000000,1000001,1000002]
输出：[0,1,2,1000000,1000001,1000002,5]
```

## 解题思路

1. 遍历 `list1`，找到第 `a-1` 个节点（`a` 前的最后一个节点）
2. 找到第 `b+1` 个节点（`b` 后的第一个节点）
3. 将 `a-1` 节点的 `next` 指向 `list2` 头
4. 遍历 `list2` 到末尾
5. 将 `list2` 末尾的 `next` 指向 `b+1` 节点

## 代码实现

### 方法一：单次遍历（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeInBetween(self, list1: ListNode, a: int, b: int, list2: ListNode) -> ListNode:
        # 找到第 a-1 个节点
        node_a = list1
        for _ in range(a - 1):
            node_a = node_a.next
        
        # 找到第 b+1 个节点
        node_b = node_a
        for _ in range(b - a + 2):  # 从 a-1 走 b-a+2 步到达 b+1
            node_b = node_b.next
        
        # 连接 list2
        node_a.next = list2
        
        # 找到 list2 的末尾
        tail = list2
        while tail.next:
            tail = tail.next
        
        tail.next = node_b
        
        return list1
```

### 方法二：用下标追踪

```python
class Solution:
    def mergeInBetween(self, list1: ListNode, a: int, b: int, list2: ListNode) -> ListNode:
        prev = None
        curr = list1
        idx = 0
        
        node_before_a = None  # 第 a-1 个节点
        node_after_b = None   # 第 b+1 个节点
        
        while curr:
            if idx == a - 1:
                node_before_a = curr
            if idx == b + 1:
                node_after_b = curr
                break
            curr = curr.next
            idx += 1
        
        # 找 list2 末尾
        tail = list2
        while tail.next:
            tail = tail.next
        
        node_before_a.next = list2
        tail.next = node_after_b
        
        return list1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单次遍历 | O(m + n) | O(1) |

m 为 list1 长度，n 为 list2 长度。

## 关键点总结

1. 需要找到两个关键节点：第 `a-1` 个（插入点前驱）和第 `b+1` 个（插入点后继）
2. 找 list2 末尾，然后连接到 `b+1` 节点
3. 注意不要在连接过程中提前断开链表

## 易错点

- 从 `a-1` 节点再走 `b-a+2` 步到达 `b+1`（不是 `b+1` 步）
- 先找到所有节点再进行连接，避免链表断裂
- 如果 `a = 0`，需要特殊处理（但题目保证 `a >= 1`）
