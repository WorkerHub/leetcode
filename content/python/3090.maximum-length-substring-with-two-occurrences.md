## 题目描述

给你一个字符串 `s`，返回满足条件的最长子字符串的长度：子字符串中每个字符最多出现 2 次。

**示例 1：**
```
输入：s = "bcbbbcba"
输出：4
解释："bcbb" 不满足（b 出现 3 次），"bcba" 满足，长度 4
```

**示例 2：**
```
输入：s = "aaaa"
输出：2
```

**提示：**
- `2 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

滑动窗口：维护一个窗口，保证窗口内每个字符最多出现 2 次。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from collections import defaultdict

class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        freq = defaultdict(int)
        left = 0
        ans = 0

        for right in range(len(s)):
            freq[s[right]] += 1

            # 若当前字符超过 2 次，收缩左边界
            while freq[s[right]] > 2:
                freq[s[left]] -= 1
                left += 1

            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：暴力枚举（n <= 100 时）

```python
from collections import Counter

class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        n = len(s)
        ans = 0
        for i in range(n):
            freq = Counter()
            for j in range(i, n):
                freq[s[j]] += 1
                if max(freq.values()) > 2:
                    break
                ans = max(ans, j - i + 1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，滑动窗口每个字符最多进出一次
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 滑动窗口维护"每字符最多 2 次"的约束
2. 当某字符超过 2 次，移动左边界直到满足约束
3. 窗口大小的最大值即为答案

## 易错点

1. 收缩左边界时循环条件：while 当前字符 > 2（不是任意字符 > 2）
2. 更新答案在收缩之后
