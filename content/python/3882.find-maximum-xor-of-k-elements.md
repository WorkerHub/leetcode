## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，从 `nums` 中选出恰好 `k` 个元素（可重复选），使它们的异或值最大。

返回该最大异或值。

**示例 1：**

```
输入：nums = [1, 2, 3], k = 2
输出：3
解释：选 1 和 2，异或 = 3。
```

**示例 2：**

```
输入：nums = [5, 4], k = 3
输出：5
解释：选 5, 4, 5（k=3，可重复），异或 = 5^4^5 = 4。
或选 5, 5, 4，异或 = 4。或选 4, 4, 5，异或 = 5。最大为 5。
```

**提示：**
- `1 <= k <= 10^5`
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^9`

## 解题思路

若 k 为偶数，可以选同一元素两次（自身异或为 0），因此可以自由选择哪些元素参与异或。若 k 为奇数，等价于选奇数个元素的最大异或（偶数对互消为 0）。

简化：
- 若 k 为奇数：找最大异或值（从 nums 中选任意奇数个，贪心选最大值）。
- 若 k 为偶数：对于有效的偶数选择，XOR 可以是 0 或任意可达值。

实际上，若可以重复选：
- k=1：直接取 max(nums)。
- k 为偶数：可以选一个元素两次（消去），相当于 k-2 个，最终等效于 k mod 2。
- 若 k 为奇数：等效于选 1 个元素，取 max(nums)。
- 若 k 为偶数：等效于选 2 个不同元素的最大异或。

## Python 代码实现

### 方法一：分析奇偶性（推荐）

```python
from typing import List

class Solution:
    def maxXor(self, nums: List[int], k: int) -> int:
        if k % 2 == 1:
            # 奇数个：等效于选 1 个（其余偶数对消），最大为 max(nums)
            return max(nums)
        else:
            # 偶数个：等效于选 2 个（其余偶数对消），最大两元素异或
            # 用字典树或暴力找最大异或
            best = 0
            for i in range(len(nums)):
                for j in range(i, len(nums)):
                    best = max(best, nums[i] ^ nums[j])
            return best
```

### 方法二：字典树（Trie）优化最大异或

```python
from typing import List

class Trie:
    def __init__(self):
        self.children = {}

    def insert(self, num):
        node = self
        for i in range(29, -1, -1):
            bit = (num >> i) & 1
            if bit not in node.children:
                node.children[bit] = Trie()
            node = node.children[bit]

    def max_xor(self, num):
        node = self
        result = 0
        for i in range(29, -1, -1):
            bit = (num >> i) & 1
            want = 1 - bit  # 期望的相反位
            if want in node.children:
                result |= (1 << i)
                node = node.children[want]
            elif bit in node.children:
                node = node.children[bit]
        return result


class Solution:
    def maxXor(self, nums: List[int], k: int) -> int:
        if k % 2 == 1:
            return max(nums)
        # 偶数：找两元素最大异或
        trie = Trie()
        for v in nums:
            trie.insert(v)
        best = 0
        for v in nums:
            best = max(best, trie.max_xor(v))
        return best
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一）；O(n * 30)（方法二 Trie）
- 空间复杂度：O(n * 30)（Trie）

## 关键点总结

1. 奇偶性决定策略：奇数 k 等效于选 1 个，偶数 k 等效于选 2 个（其余两两抵消）。
2. 最大单元素 = max(nums)；最大两元素异或用 Trie 在 O(n) 内求解。
3. 可以重复选是关键，使偶数对自消。

## 易错点

1. 重复选同一元素两次 XOR = 0，偶数对全部消去。
2. 最终只剩 k mod 2 个有效元素影响结果。
