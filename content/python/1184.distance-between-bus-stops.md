## 题目描述

一辆公交车有 `n` 个站点,编号从 `0` 到 `n-1`,形成一个环形路线。

给定一个长度为 `n` 的数组 `distance`,其中 `distance[i]` 表示站点 `i` 到站点 `(i+1) % n` 之间的距离。

公交车可以沿顺时针和逆时针两个方向行驶。

返回从起点 `start` 到终点 `destination` 的最短距离。

**示例 1:**

```
输入: distance = [1,2,3,4], start = 0, destination = 1
输出: 1
解释: 从 0 到 1 顺时针距离是 1,逆时针距离是 9,最短距离是 1
```

**示例 2:**

```
输入: distance = [1,2,3,4], start = 0, destination = 2
输出: 3
解释: 从 0 到 2 顺时针距离是 3,逆时针距离是 7,最短距离是 3
```

**示例 3:**

```
输入: distance = [1,2,3,4], start = 0, destination = 3
输出: 4
解释: 从 0 到 3 顺时针距离是 6,逆时针距离是 4,最短距离是 4
```

**提示:**
- `1 <= n <= 10^4`
- `distance.length == n`
- `0 <= start, destination < n`
- `0 <= distance[i] <= 10^4`

## 解题思路

由于路线是环形的,从起点到终点有两条路径:
1. 顺时针方向
2. 逆时针方向

**核心观察:**
- 顺时针距离 + 逆时针距离 = 总距离
- 只需计算其中一个方向的距离,另一个可以用总距离减去得到
- 返回两者中较小的值

**解法步骤:**
1. 确保 `start < destination`,便于计算
2. 计算顺时针距离: 从 `start` 到 `destination-1` 的距离之和
3. 计算总距离: 数组所有元素之和
4. 逆时针距离 = 总距离 - 顺时针距离
5. 返回较小值

## Python 代码实现

### 方法一: 双指针累加(推荐)

```python
from typing import List

class Solution:
    def distanceBetweenBusStops(self, distance: List[int], start: int, destination: int) -> int:
        """
        分别计算顺时针和逆时针距离,返回较小值
        """
        # 确保 start < destination,简化计算
        if start > destination:
            start, destination = destination, start
        
        # 计算顺时针距离: start -> destination
        clockwise = sum(distance[start:destination])
        
        # 计算总距离
        total = sum(distance)
        
        # 逆时针距离 = 总距离 - 顺时针距离
        counterclockwise = total - clockwise
        
        # 返回较小值
        return min(clockwise, counterclockwise)
```

### 方法二: 一次遍历

```python
from typing import List

class Solution:
    def distanceBetweenBusStops(self, distance: List[int], start: int, destination: int) -> int:
        """
        一次遍历同时计算两个方向的距离
        """
        if start > destination:
            start, destination = destination, start
        
        clockwise = 0  # 顺时针距离
        total = 0      # 总距离
        
        for i in range(len(distance)):
            total += distance[i]
            # 如果在 start 到 destination 之间,累加到顺时针距离
            if start <= i < destination:
                clockwise += distance[i]
        
        # 逆时针距离
        counterclockwise = total - clockwise
        
        return min(clockwise, counterclockwise)
```

### 方法三: 更简洁的写法

```python
from typing import List

class Solution:
    def distanceBetweenBusStops(self, distance: List[int], start: int, destination: int) -> int:
        """
        使用 Python 切片的简洁写法
        """
        # 确保 start < destination
        start, destination = min(start, destination), max(start, destination)
        
        # 顺时针距离
        clockwise = sum(distance[start:destination])
        
        # 逆时针距离
        counterclockwise = sum(distance) - clockwise
        
        return min(clockwise, counterclockwise)
```

### 方法四: 不交换 start 和 destination

```python
from typing import List

class Solution:
    def distanceBetweenBusStops(self, distance: List[int], start: int, destination: int) -> int:
        """
        不交换起点和终点的版本
        """
        total = sum(distance)
        
        # 计算从 start 到 destination 的距离
        # 注意要处理环形
        dist = 0
        i = start
        while i != destination:
            dist += distance[i]
            i = (i + 1) % len(distance)
        
        # 返回较小值
        return min(dist, total - dist)
```

## 复杂度分析

**时间复杂度**: O(n)
- n 为站点数量
- 需要遍历数组计算总距离和顺时针距离

**空间复杂度**: O(1)
- 只使用常数个变量存储结果

## 图解示例

**示例: distance = [1,2,3,4], start = 0, destination = 2**

```
环形路线:
    0 --1--> 1 --2--> 2 --3--> 3 --4--> 0
    
顺时针(0 -> 2):
    0 --1--> 1 --2--> 2
    距离 = 1 + 2 = 3

逆时针(0 -> 2):
    0 <--4-- 3 <--3-- 2
    距离 = 4 + 3 = 7

最短距离 = min(3, 7) = 3
```

## 关键点总结

1. 环形路线有两条路径: 顺时针和逆时针
2. 两条路径距离之和等于总距离
3. 交换起点和终点简化计算(确保 start < destination)
4. 使用切片 `distance[start:destination]` 计算区间和
5. 逆时针距离 = 总距离 - 顺时针距离

## 易错点

1. 忘记环形路线的特性,只考虑单方向
2. 切片范围错误: 应该是 `[start:destination]` 不包括 destination
3. 没有考虑 `start > destination` 的情况
4. 混淆顺时针和逆时针的计算方式
5. 边界情况: `start == destination` 时距离为 0
