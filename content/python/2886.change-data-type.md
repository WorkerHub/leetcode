## 题目描述

给定一个 DataFrame `students`，将 `grade` 列的数据类型从 float 转换为 int。

**示例：**
```
输入：grade 列为 float（如 3.0, 2.0, 4.0）

输出：grade 列为 int（如 3, 2, 4）
```

## Python 代码实现

### 方法一：astype（推荐）

```python
import pandas as pd

def changeDatatype(students: pd.DataFrame) -> pd.DataFrame:
    students['grade'] = students['grade'].astype(int)
    return students
```

### 方法二：转换为 int64

```python
import pandas as pd

def changeDatatype(students: pd.DataFrame) -> pd.DataFrame:
    return students.astype({'grade': int})
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（新列）

## 关键点总结

1. `df['col'].astype(dtype)` 转换列数据类型
2. `df.astype({'col': dtype})` 批量转换
3. float -> int 会截断小数部分（不四舍五入）

## 易错点

1. float -> int 截断，不是四舍五入：3.9 -> 3
2. 含有 NaN 的 float 列不能直接转为 int，需要先处理 NaN
