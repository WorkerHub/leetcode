## 题目描述

给你一个字符串 `s`。

若字符串 `t` 中对所有 `i`，`t[i] != t[n-1-i]`（即无任何位置构成回文对），则称 `t` 为"反回文"字符串。

每次操作可以将 `s` 的某个字符替换为另一个小写字母。返回使 `s` 变为反回文字符串所需的最少操作次数；若不可能，返回 -1。

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

反回文要求：对所有位置 `i`，`s[i] != s[n-1-i]`。

**关键观察：**
- 若 `n` 为奇数，中间位置 `s[n//2]` 与自身相等，无法满足反回文，**直接返回 -1**。
- 对于每对 `(i, n-1-i)`，若两个字符相同，至少修改其中一个。

**贪心策略：**
统计每对 `(s[i], s[n-1-i])` 中相同字符对的数量，以及这些对中各字符的频率。对于每对相同字符 `(c, c)`，必须修改其中一个。

我们需要修改最少次数，且修改后的字符不能与对方相同，也不能使修改后的字符在另一对中造成新的冲突。

贪心：对于每对相同字符，将其改为与对方不同的字符（尽量使用另一个字母消化重复）。

## Python 代码实现

### 方法一：统计贪心（推荐）

```python
from collections import Counter

class Solution:
    def makeAntiPalindrome(self, s: str) -> int:
        n = len(s)

        # 奇数长度，中间字符自身配对，不可能反回文
        if n % 2 == 1:
            return -1

        # 统计每对 (i, n-1-i) 中相同的情况
        # 对每对字符，若相同，需要修改
        # 统计 26 个字母在所有"相同配对"中的出现次数
        pair_count = Counter()  # pair_count[c] = 字符 c 在相同配对中出现的次数（每对计 2 次）

        same_pairs = 0  # 相同字符的配对数
        for i in range(n // 2):
            a, b = s[i], s[n - 1 - i]
            if a == b:
                same_pairs += 1
                pair_count[a] += 1

        # 贪心：对于每种字符 c，其在相同配对中出现 pair_count[c] 次
        # 每对 (c, c) 中，一个改为其他字母
        # 最优：将出现最多的相同字符改为不同字母
        # 若某字母出现超过 n//4 次（四分之一，因为一对占 2 个位置），必然无法全部避免
        # 实际上，只要最大配对字符数 <= n//2，就可以通过修改解决

        # 需要修改的次数 = same_pairs（每对相同配对修改一个）
        # 但修改后不能与对方相同 → 修改成任意不同字符即可

        # 特殊情况：若某字母出现 > n//2 次（超过一半），修改后无法避免冲突
        # （但每个字符在字符串中最多出现 n 次，这里指配对中）

        # 实际分析：最多的字符若在配对中出现 > n//2，无解
        if pair_count and max(pair_count.values()) > n // 2:
            return -1

        return same_pairs
```

### 方法二：更精确的贪心

```python
from collections import Counter

class Solution:
    def makeAntiPalindrome(self, s: str) -> int:
        n = len(s)
        if n % 2 == 1:
            return -1

        half = n // 2
        # 统计每对位置
        pair_same = Counter()  # 相同配对中字母出现次数
        ops = 0

        for i in range(half):
            a, b = s[i], s[n - 1 - i]
            if a == b:
                ops += 1
                pair_same[a] += 1

        # 若某字母出现次数超过 half，即使全都修改也无法使每对不同
        if pair_same and max(pair_same.values()) > half:
            return -1

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（26 个字母）

## 关键点总结

1. 奇数长度必然返回 -1
2. 每对相同配对至少修改一个，最少操作数 = 相同配对数
3. 若某字母占据超过一半的配对位置，无解

## 易错点

1. 奇数长度判断是必要的第一步
2. 修改后的字符只需与对方不同，不需要满足其他约束
