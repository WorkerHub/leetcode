## 题目描述

给定一个由不同正整数组成的数组 `nums`，返回 `nums` 中最大连通组件的大小。

如果两个或更多数字之间存在任何公因数大于 1，则这些数字可以连通。

**示例 1：**
```
输入：nums = [4,6,15,35]
输出：4
解释：
4 和 6 有公因数 2
6 和 15 有公因数 3
15 和 35 有公因数 5
因此，这 4 个数字形成一个连通组件
```

**示例 2：**
```
输入：nums = [20,50,9,63]
输出：2
解释：
20 和 50 有公因数 2 和 5
9 和 63 有公因数 3 和 9
因此，最大连通组件大小为 2
```

**示例 3：**
```
输入：nums = [2,3,6,7,4,12,21,39]
输出：8
解释：所有数字都通过某些公因数连通
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 10^5`
- `nums` 中所有值都不同

## 解题思路

这道题的核心是找连通组件，关键在于如何定义"连通"：两个数有大于 1 的公因数就连通。

**核心思想：**

1. **并查集（Union-Find）**：这是解决连通性问题的经典数据结构
   - 将有公因数的数字合并到同一个集合
   - 最后统计最大集合的大小

2. **质因数分解**：不需要两两比较所有数字
   - 对每个数字进行质因数分解
   - 将数字与其所有质因数建立连接
   - 拥有相同质因数的数字会被连接在一起

3. **优化策略**：
   - 不需要找出所有因数，只需要质因数
   - 使用并查集的路径压缩和按秩合并优化

**算法流程：**
1. 初始化并查集
2. 对每个数字进行质因数分解
3. 将数字与其每个质因数连接（合并到同一集合）
4. 统计每个集合的大小，返回最大值

## Python 代码实现

### 方法一：并查集 + 质因数分解（推荐）⭐

```python
from typing import List
from collections import defaultdict

class UnionFind:
    """并查集数据结构"""
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        """查找根节点，带路径压缩"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        """合并两个集合，按秩合并"""
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return
        
        # 按秩合并
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1

class Solution:
    def largestComponentSize(self, nums: List[int]) -> int:
        """
        使用并查集找最大连通组件
        
        思路：
        1. 对每个数字进行质因数分解
        2. 将数字与其质因数在并查集中连接
        3. 统计最大连通组件大小
        """
        # 初始化并查集
        max_num = max(nums)
        uf = UnionFind(max_num + 1)
        
        # 对每个数字进行质因数分解
        for num in nums:
            # 获取所有质因数
            primes = self.get_prime_factors(num)
            # 将数字与第一个质因数连接
            # 然后将所有质因数相互连接
            for i in range(len(primes) - 1):
                uf.union(primes[i], primes[i + 1])
            # 将数字本身与第一个质因数连接
            if primes:
                uf.union(num, primes[0])
        
        # 统计每个连通组件的大小
        count = defaultdict(int)
        for num in nums:
            root = uf.find(num)
            count[root] += 1
        
        # 返回最大值
        return max(count.values())
    
    def get_prime_factors(self, n):
        """获取 n 的所有质因数"""
        factors = []
        
        # 处理因数 2
        if n % 2 == 0:
            factors.append(2)
            while n % 2 == 0:
                n //= 2
        
        # 处理奇数因数，从 3 开始
        i = 3
        while i * i <= n:
            if n % i == 0:
                factors.append(i)
                while n % i == 0:
                    n //= i
            i += 2
        
        # 如果 n 大于 1，说明 n 本身是质数
        if n > 1:
            factors.append(n)
        
        return factors
```

### 方法二：优化的并查集（使用字典）

```python
class Solution:
    def largestComponentSize(self, nums: List[int]) -> int:
        """
        使用字典实现的并查集，更节省空间
        """
        parent = {}
        
        def find(x):
            """查找根节点"""
            if x not in parent:
                parent[x] = x
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            """合并两个集合"""
            root_x, root_y = find(x), find(y)
            if root_x != root_y:
                parent[root_x] = root_y
        
        # 对每个数字进行质因数分解并合并
        for num in nums:
            k = num
            # 处理因数 2
            if k % 2 == 0:
                union(num, 2)
                while k % 2 == 0:
                    k //= 2
            
            # 处理奇数因数
            i = 3
            while i * i <= k:
                if k % i == 0:
                    union(num, i)
                    while k % i == 0:
                        k //= i
                i += 2
            
            # k 本身是质数
            if k > 1:
                union(num, k)
        
        # 统计每个连通组件的大小
        count = defaultdict(int)
        for num in nums:
            root = find(num)
            count[root] += 1
        
        return max(count.values()) if count else 0
```

### 方法三：埃氏筛 + 并查集（预处理优化）

```python
class Solution:
    def largestComponentSize(self, nums: List[int]) -> int:
        """
        使用埃拉托斯特尼筛法预处理质数
        适合多次查询的场景
        """
        max_num = max(nums)
        parent = list(range(max_num + 1))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            parent[find(x)] = find(y)
        
        # 埃氏筛：对每个质数，将其所有倍数连接
        sieve = [True] * (max_num + 1)
        sieve[0] = sieve[1] = False
        
        for i in range(2, int(max_num ** 0.5) + 1):
            if sieve[i]:
                # i 是质数，将 i 的所有倍数标记
                for j in range(i * i, max_num + 1, i):
                    sieve[j] = False
                    union(i, j)
        
        # 对每个数字进行因数分解并连接
        for num in nums:
            k = num
            for i in range(2, int(k ** 0.5) + 1):
                if k % i == 0:
                    union(num, i)
                    while k % i == 0:
                        k //= i
            if k > 1:
                union(num, k)
        
        # 统计
        count = defaultdict(int)
        for num in nums:
            count[find(num)] += 1
        
        return max(count.values())
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(N√M + Nα(M))
  - N 是数组长度，M 是数组中的最大值
  - 质因数分解：O(√M) 每个数字
  - 并查集操作：O(α(M))，α 是阿克曼函数的反函数，几乎为常数
- **空间复杂度**：O(M)，并查集需要 O(M) 空间

**方法二：**
- **时间复杂度**：O(N√M + Nα(N))
- **空间复杂度**：O(N + K)，K 是不同质因数的个数

**方法三：**
- **时间复杂度**：O(M log log M + N√M)，埃氏筛需要 O(M log log M)
- **空间复杂度**：O(M)

## 关键点总结

1. **并查集的应用**：连通性问题的标准解法，需要掌握路径压缩和按秩合并
2. **质因数分解**：不需要找所有因数，只需质因数即可建立连接
3. **优化技巧**：只需要遍历到 √n 即可完成质因数分解
4. **数据结构选择**：数组实现快但占空间，字典实现省空间
5. **统计技巧**：使用哈希表统计每个根节点的出现次数

## 易错点

1. **并查集初始化**：要初始化到 max(nums) + 1，而不是 len(nums)
2. **质因数分解边界**：容易忘记处理剩余的大质数（n > 1 的情况）
3. **合并策略**：不能直接合并数字本身，要通过质因数建立连接
4. **空数组处理**：要检查 nums 是否为空
5. **重复质因数**：质因数分解时要去除重复，只保留一个
