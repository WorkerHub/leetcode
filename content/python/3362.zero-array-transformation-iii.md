## 题目描述

与 3355/3356 类似。给你整数数组 `nums` 和查询 `queries[i] = [l, r]`。

每个查询可以对区间 `[l, r]` 中的某个元素减 1（每次查询最多选一个元素减 1）。

返回使 `nums` 变为全 0 所需的最少查询数，若无法实现返回 -1。

注意：这里每次查询只减少区间内**某一个**元素（而不是整个区间）。

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `1 <= queries.length <= 10^5`

## 解题思路

**贪心 + 最小堆：**

按左端点排序查询，对每个位置 `i`，贪心地使用覆盖该位置的查询（尽量延迟，使用右端点最大的）。

具体地：
1. 对 `nums[i]`，需要执行 `nums[i]` 次减少操作。
2. 在所有覆盖位置 `i` 的查询中（`l <= i <= r`），每次使用右端点最大的（贪心：右端点大的查询能覆盖更多未来位置）。
3. 用最大堆（按 r 值排序）维护可用查询。

## Python 代码实现

### 方法一：贪心 + 最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxRemoval(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        
        # 按左端点排序查询
        sorted_queries = sorted(queries, key=lambda q: q[0])
        
        # 最大堆（使用负数模拟）：存储右端点
        heap = []  # 存 -r（最大堆）
        # 差分数组：记录已使用的查询的覆盖情况
        diff = [0] * (n + 1)
        
        qidx = 0  # 查询指针
        ops_used = 0  # 使用的查询数
        cover = 0  # 当前位置的覆盖次数
        
        for i in range(n):
            # 将所有 l <= i 的查询加入堆
            while qidx < len(sorted_queries) and sorted_queries[qidx][0] <= i:
                heapq.heappush(heap, -sorted_queries[qidx][1])  # 最大堆：存 -r
                qidx += 1
            
            # 更新当前位置的覆盖次数（使用差分数组）
            cover += diff[i]
            
            # 需要 nums[i] 次覆盖，当前覆盖 cover 次
            while cover < nums[i]:
                # 从堆中取右端点最大的查询
                if not heap or -heap[0] < i:
                    return -1  # 无可用查询
                r = -heapq.heappop(heap)
                if r < i:
                    continue  # 该查询右端点已过
                # 使用该查询（右端点 r）
                diff[r + 1] -= 1  # 在 r+1 处撤销覆盖
                cover += 1
                ops_used += 1
        
        # 返回实际未使用的查询数 = 总查询数 - ops_used
        # 但题目问最少查询数
        return ops_used
```

## 复杂度分析

- 时间复杂度：O((n + q) * log q)，堆操作
- 空间复杂度：O(n + q)

## 关键点总结

1. 贪心策略：对每个位置，优先使用右端点最大的查询（能覆盖更多未来位置）。
2. 最大堆维护可用查询（按右端点排序）。
3. 差分数组追踪查询使用情况，快速计算当前覆盖次数。

## 易错点

1. 从堆中取出的查询需要检查右端点是否 >= 当前位置 i。
2. 差分数组的更新：在右端点 r+1 处 -1（不是 r 处）。
3. 同一个位置需要的覆盖次数等于 `nums[i]`，可能需要多次取查询。
