## 题目描述

给定两个字符串 a 和 b，寻找重复叠加字符串 a 的最小次数，使得字符串 b 成为叠加后的字符串的子串。如果不存在则返回 -1。

**示例 1：**
```
输入：a = "abcd", b = "cdabcdab"
输出：3
解释：重复叠加 a 三次得到 "abcdabcdabcd"，此时 b 是其子串
```

**示例 2：**
```
输入：a = "a", b = "aa"
输出：2
```

**提示：**
- 1 <= a.length <= 10^4
- 1 <= b.length <= 10^4
- a 和 b 由小写英文字母组成

## 解题思路

重复 a 直到长度足够包含 b。

**关键观察：**
1. 至少需要重复 ceil(len(b) / len(a)) 次
2. 最多需要重复 ceil(len(b) / len(a)) + 2 次

## Python 代码实现

### 方法一：暴力模拟

```python
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        # 计算最少需要重复的次数
        min_repeat = -(-len(b) // len(a))  # 向上取整
        
        # 尝试 min_repeat 和 min_repeat + 1 次
        for repeat in [min_repeat, min_repeat + 1]:
            if b in a * repeat:
                return repeat
        
        return -1
```

### 方法二：优化版本

```python
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        # 最少重复次数
        min_repeat = (len(b) - 1) // len(a) + 1
        
        # 尝试不同的重复次数
        for i in range(2):
            if b in a * (min_repeat + i):
                return min_repeat + i
        
        return -1
```

## 复杂度分析

- 时间复杂度：O((n+m) * m)，n 是 a 的长度，m 是 b 的长度
- 空间复杂度：O(n * k)，k 是重复次数

## 关键点总结

1. 计算最少需要的重复次数
2. 最多只需要多重复1-2次
3. 使用字符串的 in 操作检查子串

## 易错点

1. 重复次数计算错误
2. 没有考虑边界情况
3. 字符串过长导致内存问题
