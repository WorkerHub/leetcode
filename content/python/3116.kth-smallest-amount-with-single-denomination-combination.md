## 题目描述

给你一个整数数组 `coins` 表示不同面额的硬币，以及一个整数 `k`。

你有无限量的每种面额的硬币。但是，你 **不能** 组合使用不同面额的硬币。

返回使用 **单一面额** 硬币可以凑出的金额中第 `k` 小的金额。

**示例 1：**
```
输入：coins = [3,6,9], k = 3
输出：9
解释：可凑出的金额（升序）：3,6,9,12,... -> 第 3 小是 9
```

**示例 2：**
```
输入：coins = [5,2], k = 7
输出：12
解释：可凑出金额：2,4,5,6,8,10,12,... -> 第 7 小是 12
```

**提示：**
- `1 <= coins.length <= 15`
- `1 <= coins[i] <= 25`
- `1 <= k <= 2 * 10^9`
- `coins` 中元素互不相同

## 解题思路

二分答案：二分在 `[1, k * min(coins)]` 范围内找最小的 `x`，使得不超过 `x` 的合法金额数 >= k。

计算不超过 `x` 的合法金额数：每种面额 `c` 贡献 `x // c` 个（即 c, 2c, ..., floor(x/c)*c）。但不同面额可能有重叠（如 3 和 6 都包含 6 的倍数），需要用容斥原理去重。

容斥原理：枚举 coins 的所有非空子集，子集的 LCM 的倍数数量 = x // lcm。子集大小为奇数时加，偶数时减。

## Python 代码实现

### 方法一：二分 + 容斥（推荐）

```python
from typing import List
from math import lcm
from itertools import combinations

class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        # 去除冗余：若 a 是 b 的倍数，a 可以去掉
        coins = list(set(coins))
        # 进一步：去除被其他硬币覆盖的
        filtered = []
        for c in coins:
            if not any(c % d == 0 for d in coins if d != c):
                filtered.append(c)
        coins = filtered

        n = len(coins)

        def count(x: int) -> int:
            # 容斥：不超过 x 的合法金额数
            res = 0
            for r in range(1, n + 1):
                for subset in combinations(coins, r):
                    lc = subset[0]
                    for v in subset[1:]:
                        lc = lcm(lc, v)
                        if lc > x:
                            break
                    else:
                        if r % 2 == 1:
                            res += x // lc
                        else:
                            res -= x // lc
            return res

        # 二分答案
        lo, hi = 1, k * min(coins)
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：位掩码枚举子集

```python
from typing import List
from math import gcd

class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        n = len(coins)

        def lcm(a, b):
            return a * b // gcd(a, b)

        def count(x: int) -> int:
            res = 0
            for mask in range(1, 1 << n):
                lc = 1
                bits = bin(mask).count('1')
                for i in range(n):
                    if mask >> i & 1:
                        lc = lcm(lc, coins[i])
                        if lc > x:
                            break
                else:
                    if bits % 2 == 1:
                        res += x // lc
                    else:
                        res -= x // lc
            return res

        lo, hi = 1, k * min(coins)
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(2^n * log(k * min_coin))，n <= 15，二分 O(log) 次，每次容斥 O(2^n)
- 空间复杂度：O(n)

## 关键点总结

1. 不能混用面额，每个合法金额是某一个硬币面额的正整数倍
2. 用容斥原理统计不超过 x 的合法金额总数
3. 二分答案找第 k 小

## 易错点

1. LCM 可能溢出（Python 无整数溢出问题）
2. 容斥时若 LCM > x，该子集贡献为 0
