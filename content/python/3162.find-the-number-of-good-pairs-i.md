## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，以及整数 `k`。

如果 `nums1[i]` 能被 `nums2[j] * k` 整除，则称 `(i, j)` 是一个 **好数对**。

返回好数对的数量。

**示例 1：**
```
输入：nums1 = [1,3,4], nums2 = [1,3,4], k = 1
输出：5
解释：(0,0),(1,0),(1,1),(2,0),(2,2) 都满足 nums1[i] % (nums2[j]*k) == 0
```

**提示：**
- `1 <= nums1.length, nums2.length <= 50`
- `1 <= nums1[i], nums2[j] <= 50`
- `1 <= k <= 50`

## 解题思路

暴力枚举所有 (i, j) 对，检查 `nums1[i] % (nums2[j] * k) == 0`。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        ans = 0
        for a in nums1:
            for b in nums2:
                if a % (b * k) == 0:
                    ans += 1
        return ans
```

### 方法二：利用因子

```python
from typing import List

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        return sum(
            1
            for a in nums1
            for b in nums2
            if (b * k) != 0 and a % (b * k) == 0
        )
```

## 复杂度分析

- 时间复杂度：O(n * m)，n、m 为数组长度
- 空间复杂度：O(1)

## 关键点总结

1. 条件是 nums1[i] 被 nums2[j]*k 整除
2. 暴力枚举即可（数据范围小）

## 易错点

1. 注意 nums2[j] * k 可能为 0（题目保证 >= 1）
2. 整除判断用 % 运算
