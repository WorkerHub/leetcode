## 题目描述

给你字符串 `initialCurrency`，初始金额 `1.0`。

两天内进行货币转换：
- 第一天：使用 `pairs1` 中的汇率 `rates1` 进行转换。
- 第二天：使用 `pairs2` 中的汇率 `rates2` 进行转换。

每天可以进行任意次单步转换（直接相连的货币对之间），但每步只能沿一条边转换一次。

返回最终 `finalCurrency` 的最大金额。

**提示：**
- 每天可以从源货币出发，通过多步转换到达目标货币。
- 汇率图可以有多条路径。

## 解题思路

**两次图 DFS/BFS：**

1. 第一天：从 `initialCurrency` 出发，通过 `pairs1/rates1` 的汇率图，计算能到达的每种货币的最大金额。

2. 第二天：从第一天到达的每种货币出发，通过 `pairs2/rates2` 的汇率图，计算能到达 `finalCurrency` 的最大金额。

对汇率图，同一货币对可能可以正反转换（但除法汇率需要处理）。

**转换图是无向的（a -> b 也可以 b -> a，汇率互倒）**，使用乘法汇率。

## Python 代码实现

### 方法一：DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxAmount(self, initialCurrency: str, pairs1: List[List[str]], 
                  rates1: List[float], pairs2: List[List[str]], 
                  rates2: List[float], finalCurrency: str) -> float:
        
        def build_graph(pairs, rates):
            graph = defaultdict(list)
            for i, (a, b) in enumerate(pairs):
                graph[a].append((b, rates[i]))
                graph[b].append((a, 1.0 / rates[i]))
            return graph
        
        def max_reachable(graph, start, amount):
            """DFS 找从 start 出发，能到达的每种货币的最大金额"""
            best = {start: amount}
            stack = [(start, amount)]
            visited = {start}
            
            while stack:
                curr, amt = stack.pop()
                for next_curr, rate in graph[curr]:
                    new_amt = amt * rate
                    if next_curr not in best or new_amt > best[next_curr]:
                        best[next_curr] = new_amt
                        if next_curr not in visited:
                            visited.add(next_curr)
                            stack.append((next_curr, new_amt))
            
            return best
        
        g1 = build_graph(pairs1, rates1)
        g2 = build_graph(pairs2, rates2)
        
        # 第一天：从 initialCurrency 出发
        day1_amounts = max_reachable(g1, initialCurrency, 1.0)
        
        # 第二天：从第一天的每种货币出发
        best_final = 0.0
        for currency, amount in day1_amounts.items():
            day2_amounts = max_reachable(g2, currency, amount)
            if finalCurrency in day2_amounts:
                best_final = max(best_final, day2_amounts[finalCurrency])
        
        return best_final
```

## 复杂度分析

- 时间复杂度：O(V1 * E2)，V1 是第一天可达货币数，E2 是第二天边数
- 空间复杂度：O(V1 + V2)

## 关键点总结

1. 汇率图是无向的（双向转换，互为倒数）。
2. 第一天找从初始货币出发的所有最大金额。
3. 第二天从第一天每个可达货币出发，找到达目标货币的最大金额。

## 易错点

1. 反向转换汇率 = 1/rate，不要遗漏。
2. DFS 中同一货币可以多次更新（找更大金额），需要允许重复访问。
3. 第一天结束后，可能从多种货币出发第二天，都需要尝试。
