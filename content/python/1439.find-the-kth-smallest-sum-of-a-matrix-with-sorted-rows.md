## 题目描述

给你一个 `m x n` 的矩阵 `mat`，以及一个整数 `k`，矩阵中的每一行都以非递减顺序排列。

你可以从每一行中选出 1 个元素形成一个数组。返回所有可能数组中的第 `k` 个最小数组和。

**示例 1：**
```
输入：mat = [[1,3,11],[2,4,6]], k = 5
输出：7
解释：从每行选一个元素的所有可能数组和为：
[1+2, 1+4, 1+6, 3+2, 3+4, 3+6, 11+2, 11+4, 11+6]
= [3, 5, 7, 5, 7, 9, 13, 15, 17]
排序后：[3, 5, 5, 7, 7, 9, 13, 15, 17]
第 5 小的是 7。
```

**示例 2：**
```
输入：mat = [[1,3,11],[2,4,6]], k = 9
输出：17
```

**示例 3：**
```
输入：mat = [[1,10],[2,15],[3,25]], k = 3
输出：23
解释：[1+2+3, 1+2+25, 1+15+3] = [6, 28, 19]，前三小为 [6, 19, 28]，第 3 小为 23。
```

**提示：**
- `m == mat.length`
- `n == mat[0].length`
- `1 <= m, n <= 40`
- `1 <= mat[i][j] <= 5000`
- `1 <= k <= min(200, n^m)`
- `mat[i]` 是按非递减顺序排列的

## 解题思路

**核心思路：逐行合并，维护前 k 小的和**

将问题分解：先只考虑前 1 行，和就是第 1 行各元素；再合并第 2 行，和就是前 1 行每个值加上第 2 行每个值...

**逐行合并步骤：**
1. 初始 `candidates = [row[0]]`（第 1 行第 1 个元素）。
2. 对于每一新行，将 `candidates` 中每个值与新行每个值相加，得到新的候选集合。
3. 对新候选集合排序，只保留前 `k` 个（因为之后只需第 k 小）。
4. 重复直到所有行处理完。

**为什么只保留前 k 个？**  
每次合并只需最终前 k 小的值，中间步骤中超过 k 的值不可能成为最终答案。

**使用最小堆优化合并：**  
可以用最小堆每次取出当前最小的和，推入其相邻的候选，类似 dijkstra。

## Python 代码实现

### 方法一：逐行合并 + 排序保留前 k（推荐）

```python
from typing import List

class Solution:
    def kthSmallest(self, mat: List[List[int]], k: int) -> int:
        # 初始候选集合：第一行前 k 个元素
        candidates = sorted(mat[0])[:k]

        for row_idx in range(1, len(mat)):
            row = mat[row_idx]
            new_candidates = []

            # 将当前候选集中每个值与新行每个值相加
            for s in candidates:
                for val in row:
                    new_candidates.append(s + val)

            # 排序并保留前 k 个最小值
            new_candidates.sort()
            candidates = new_candidates[:k]

        return candidates[k - 1]
```

### 方法二：最小堆优化合并（更高效）

```python
from typing import List
import heapq

class Solution:
    def kthSmallest(self, mat: List[List[int]], k: int) -> int:
        m, n = len(mat), len(mat[0])

        def merge_two_rows(row1: List[int], row2: List[int]) -> List[int]:
            """
            合并两行，返回前 k 个最小和。
            使用最小堆：初始状态 (row1[0]+row2[0], 0, 0)
            每次取出最小，推入相邻状态（下一列）。
            """
            # 堆元素：(和, row1的下标, row2的下标)
            heap = [(row1[0] + row2[0], 0, 0)]
            visited = {(0, 0)}
            result = []

            while heap and len(result) < k:
                s, i, j = heapq.heappop(heap)
                result.append(s)

                # 扩展 row1 的下一个（i+1）
                if i + 1 < len(row1) and (i + 1, j) not in visited:
                    heapq.heappush(heap, (row1[i + 1] + row2[j], i + 1, j))
                    visited.add((i + 1, j))

                # 扩展 row2 的下一个（j+1）
                if j + 1 < len(row2) and (i, j + 1) not in visited:
                    heapq.heappush(heap, (row1[i] + row2[j + 1], i, j + 1))
                    visited.add((i, j + 1))

            return result

        # 逐行合并
        current = mat[0]
        for row_idx in range(1, m):
            current = merge_two_rows(current, mat[row_idx])

        return current[k - 1]
```

### 方法三：方法一的简化版（Python 一行合并）

```python
from typing import List

class Solution:
    def kthSmallest(self, mat: List[List[int]], k: int) -> int:
        import functools

        def merge(row1, row2):
            # 合并两行，返回前 k 小的和
            result = sorted(a + b for a in row1 for b in row2)
            return result[:k]

        # 使用 reduce 逐行合并
        return functools.reduce(merge, mat)[k - 1]
```

## 复杂度分析

- **方法一：**
  - 时间复杂度：O(m * k * n * log(kn))，每行合并时产生 k*n 个候选值，排序取前 k。
  - 空间复杂度：O(k*n)。
- **方法二（堆优化）：**
  - 时间复杂度：O(m * k * log k)，每行合并最多取 k 个元素，每次堆操作 O(log k)。
  - 空间复杂度：O(k)。

## 图解示例

```
mat = [[1,3,11],[2,4,6]], k=5

第一行：candidates = [1, 3, 11] -> 取前 k=5 个 -> [1, 3, 11]

合并第二行 [2, 4, 6]：
  1+2=3, 1+4=5, 1+6=7
  3+2=5, 3+4=7, 3+6=9
  11+2=13, 11+4=15, 11+6=17
  全部：[3,5,7,5,7,9,13,15,17]
  排序：[3,5,5,7,7,9,13,15,17]
  保留前 5：[3,5,5,7,7]

第 k=5 小 = candidates[4] = 7
```

## 关键点总结

1. 逐行合并是分治的思想，每次合并两个有序数组的所有组合之和的前 k 小。
2. 只保留前 k 个候选值是关键剪枝：合并时超过 k 的值不可能成为最终第 k 小。
3. 方法三利用 `functools.reduce` 将逐行合并压缩为一行，Python 函数式编程的优雅体现。
4. 方法二的堆优化在 k 小、n 大时效率更高。

## 易错点

- 初始候选集合应只取第一行的前 k 个（已排序），而非全部。
- `candidates[k-1]` 而非 `candidates[k]`（下标从 0 开始）。
- 合并两行时注意生成的候选数量可能很大（k*n），需要排序后截断。
