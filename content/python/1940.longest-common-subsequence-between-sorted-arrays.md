## 题目描述

给你一个整数数组列表 `arrays`，其中每个数组均已**升序排列**，请你找出出现在**所有数组**中的**最长公共子序列**，并返回该子序列。

**示例 1：**
```
输入：arrays = [[1,3,4],[1,4,7,9]]
输出：[1,4]
```

**示例 2：**
```
输入：arrays = [[2,3,6,8],[1,2,3,5,6,7,10],[2,4,6,8]]
输出：[2,6]
```

**提示：**
- `2 <= arrays.length <= 100`
- `1 <= arrays[i].length <= 100`
- `1 <= arrays[i][j] <= 100`，`arrays[i]` 中元素互不相同
- `arrays[i]` 已升序排列

---

## 解题思路

### 核心思想：计数 + 取交集

由于每个数组中元素互不相同，且值域为 `[1, 100]`，可以统计每个元素出现的数组数量，等于总数组数量的元素即为公共元素。

由于原数组已升序排列，结果也按升序输出。

---

## 代码实现

### 方法一：计数数组（推荐）

```python
from typing import List

class Solution:
    def longestCommomSubsequence(self, arrays: List[List[int]]) -> List[int]:
        m = len(arrays)
        # 统计每个值出现在多少个数组中
        count = [0] * 101

        for arr in arrays:
            for x in arr:
                count[x] += 1

        # 出现在所有数组中的元素（按升序）
        return [v for v in range(1, 101) if count[v] == m]
```

### 方法二：集合交集

```python
from typing import List
from functools import reduce

class Solution:
    def longestCommomSubsequence(self, arrays: List[List[int]]) -> List[int]:
        # 求所有数组的集合交集
        common = reduce(lambda a, b: a & b, (set(arr) for arr in arrays))
        # 按升序返回
        return sorted(common)
```

### 方法三：多路归并（利用有序性）

```python
from typing import List

class Solution:
    def longestCommomSubsequence(self, arrays: List[List[int]]) -> List[int]:
        # 逐数组取交集（利用数组有序性）
        result = set(arrays[0])
        for arr in arrays[1:]:
            result &= set(arr)
        return sorted(result)
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（计数） | O(n * k) | O(100) = O(1) |
| 方法二（集合交集） | O(n * k) | O(k) |

n 为数组数量，k 为单个数组平均长度。

---

## 关键点总结

1. 由于值域小（1~100）且每个数组中元素唯一，统计出现次数等于 m 即为公共元素
2. 集合求交集是 Python 中最简洁的写法
3. 结果天然有序（值从 1 到 100 遍历）

---

## 易错点

- 注意 `reduce` 中初始值处理
- `sorted(common)` 确保返回升序结果
