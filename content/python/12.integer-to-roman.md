## 题目描述

罗马数字包含以下七种字符：`I`，`V`，`X`，`L`，`C`，`D` 和 `M`。

```
字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

例如，罗马数字 2 写做 `II`，即为两个并列的 1。12 写做 `XII`，即为 `X + II`。27 写做 `XXVII`，即为 `XX + V + II`。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V` (5) 和 `X` (10) 的左边，来表示 4 和 9。
- `X` 可以放在 `L` (50) 和 `C` (100) 的左边，来表示 40 和 90。
- `C` 可以放在 `D` (500) 和 `M` (1000) 的左边，来表示 400 和 900。

给你一个整数，将其转为罗马数字。

**示例 1：**
```
输入：num = 3
输出："III"
```

**示例 2：**
```
输入：num = 4
输出："IV"
```

**示例 3：**
```
输入：num = 9
输出："IX"
```

**示例 4：**
```
输入：num = 58
输出："LVIII"
解释：L = 50, V = 5, III = 3
```

**示例 5：**
```
输入：num = 1994
输出："MCMXCIV"
解释：M = 1000, CM = 900, XC = 90, IV = 4
```

**提示：**
- `1 <= num <= 3999`

## 解题思路

核心思想：从大到小枚举所有可能的罗马数字（包括特殊组合），依次减去对应的值。

关键观察：
1. 罗马数字由 7 个基本符号 + 6 个特殊组合构成
2. 从最大的值开始减，每次尽可能多地使用当前符号
3. 贪心策略：每次选择不超过 num 的最大罗马数字

## Python 代码实现

### 方法一：贪心法（推荐）

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        # 按从大到小的顺序列出所有可能的值和符号
        values = [1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]
        symbols = ["M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"]
        
        result = []
        
        # 从最大的值开始
        for i in range(len(values)):
            value = values[i]
            symbol = symbols[i]
            
            # 当前值能用几次
            while num >= value:
                num -= value
                result.append(symbol)
        
        return ''.join(result)
```

### 方法二：使用元组列表

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        # 使用元组列表存储值和符号的对应关系
        value_symbols = [
            (1000, 'M'), (900, 'CM'), (500, 'D'), (400, 'CD'),
            (100, 'C'), (90, 'XC'), (50, 'L'), (40, 'XL'),
            (10, 'X'), (9, 'IX'), (5, 'V'), (4, 'IV'), (1, 'I')
        ]
        
        result = []
        for value, symbol in value_symbols:
            # 计算当前符号需要的个数
            count = num // value
            if count:
                result.append(symbol * count)
                num %= value
        
        return ''.join(result)
```

### 方法三：硬编码法（空间换时间）

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        # 分别处理千位、百位、十位、个位
        thousands = ["", "M", "MM", "MMM"]
        hundreds = ["", "C", "CC", "CCC", "CD", "D", "DC", "DCC", "DCCC", "CM"]
        tens = ["", "X", "XX", "XXX", "XL", "L", "LX", "LXX", "LXXX", "XC"]
        ones = ["", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX"]
        
        return (thousands[num // 1000] + 
                hundreds[(num % 1000) // 100] + 
                tens[(num % 100) // 10] + 
                ones[num % 10])
```

### 方法四：递归法

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        value_symbols = [
            (1000, 'M'), (900, 'CM'), (500, 'D'), (400, 'CD'),
            (100, 'C'), (90, 'XC'), (50, 'L'), (40, 'XL'),
            (10, 'X'), (9, 'IX'), (5, 'V'), (4, 'IV'), (1, 'I')
        ]
        
        for value, symbol in value_symbols:
            if num >= value:
                # 递归处理剩余部分
                return symbol + self.intToRoman(num - value)
        
        return ""
```

## 复杂度分析

**方法一、二、四：**
- 时间复杂度：O(1)，最多循环 13 次（固定的符号数量）
- 空间复杂度：O(1)

**方法三：**
- 时间复杂度：O(1)，直接索引
- 空间复杂度：O(1)，预定义的数组

## 关键点总结

1. **包含特殊组合**：6 个特殊的减法组合（IV, IX, XL, XC, CD, CM）必须包含在映射表中
2. **贪心策略**：从大到小选择，每次选最大的可用符号
3. **顺序很重要**：必须按值从大到小排列
4. **不需要回溯**：贪心策略保证了最优解

## 易错点

1. **遗漏特殊组合**：必须包含 6 个减法情况（4, 9, 40, 90, 400, 900）
2. **顺序错误**：必须从大到小枚举，否则会得到错误结果
3. **重复使用**：某些符号可能需要使用多次，如 `3 = III`
4. **边界情况**：
   - `num = 1`：最小值
   - `num = 3999`：最大值，`MMMCMXCIX`
