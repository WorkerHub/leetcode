## 题目描述

你会得到一个字符串 text。你应该把它分成 k 个子字符串 (subtext1, subtext2, ..., subtextk)，要求满足:
- subtexti 是非空字符串
- 所有子字符串的连接等于 text (即 subtext1 + subtext2 + ... + subtextk == text)
- 对于所有 1 <= i <= k，都有 subtexti == subtextk - i + 1

返回k可能的最大值。

**示例 1：**
```
输入：text = "ghiabcdefhelloadamhelloabcdefghi"
输出：7
解释：我们可以把字符串拆分成 "(ghi)(abcdef)(hello)(adam)(hello)(abcdef)(ghi)"。
```

**示例 2：**
```
输入：text = "merchant"
输出：1
解释：我们可以把字符串拆分成 "(merchant)"。
```

**示例 3：**
```
输入：text = "antaprezatepzapreanta"
输出：11
解释：我们可以把字符串拆分成 "(a)(nt)(a)(pre)(za)(tep)(za)(pre)(a)(nt)(a)"。
```

**提示：**
- 1 <= text.length <= 1000
- text 仅由小写英文字符组成

## 解题思路

这道题要求将字符串分成回文对称的块，使得块数最多。

**核心思想：**

1. **贪心策略**：
   - 从两端开始匹配，尽早匹配成功
   - 一旦左右两端找到相同的子串，立即切分
   - 这样能最大化块数

2. **双指针方法**：
   - 左指针从字符串开始位置向右
   - 右指针从字符串结束位置向左
   - 逐渐扩展子串长度，直到左右子串相等

3. **递归/迭代**：
   - 找到匹配后，递归处理剩余部分
   - 或者用循环迭代处理

4. **为什么贪心正确**：
   - 越早切分，剩余部分能切分的可能性越多
   - 如果等待更长的匹配，可能会减少总块数
   - 例如："aa" 切成 "(a)(a)" 比 "(aa)" 更优

## Python 代码实现

### 方法一：递归 + 贪心 ⭐

```python
class Solution:
    def longestDecomposition(self, text: str) -> int:
        """
        递归实现，贪心地从两端匹配
        时间复杂度：O(n^2)
        空间复杂度：O(n) 递归栈
        """
        n = len(text)
        
        # 基础情况：空字符串
        if n == 0:
            return 0
        
        # 尝试从两端匹配
        for length in range(1, n // 2 + 1):
            left_chunk = text[:length]
            right_chunk = text[n - length:]
            
            # 如果匹配成功
            if left_chunk == right_chunk:
                # 递归处理中间部分，加上当前的两个块
                return 2 + self.longestDecomposition(text[length:n - length])
        
        # 无法匹配，整个字符串作为一个块
        return 1 if n > 0 else 0
```

### 方法二：迭代 + 双指针 ⭐ 推荐

```python
class Solution:
    def longestDecomposition(self, text: str) -> int:
        """
        迭代实现，避免递归开销
        时间复杂度：O(n^2)
        空间复杂度：O(1)
        """
        count = 0
        left = 0
        right = len(text) - 1
        
        while left <= right:
            # 尝试不同的长度
            length = 1
            while left + length - 1 < right - length + 1:
                # 检查左右子串是否相等
                if text[left:left + length] == text[right - length + 1:right + 1]:
                    count += 2
                    left += length
                    right -= length
                    break
                length += 1
            else:
                # 没有找到匹配，剩余部分作为一个块
                if left <= right:
                    count += 1
                break
        
        return count
```

### 方法三：递归 + 记忆化

```python
from functools import lru_cache

class Solution:
    def longestDecomposition(self, text: str) -> int:
        """
        带记忆化的递归
        """
        @lru_cache(maxsize=None)
        def helper(s: str) -> int:
            if not s:
                return 0
            
            n = len(s)
            # 贪心：尝试最短的匹配
            for i in range(1, n // 2 + 1):
                if s[:i] == s[n - i:]:
                    return 2 + helper(s[i:n - i])
            
            # 整个字符串是一个块
            return 1
        
        return helper(text)
```

### 方法四：优化的迭代（使用哈希）

```python
class Solution:
    def longestDecomposition(self, text: str) -> int:
        """
        使用滚动哈希优化字符串比较
        时间复杂度：O(n)
        """
        def rolling_hash(s: str) -> int:
            """计算字符串哈希值"""
            return hash(s)
        
        count = 0
        n = len(text)
        left = 0
        right = n - 1
        
        while left <= right:
            found = False
            for length in range(1, (right - left) // 2 + 1):
                left_str = text[left:left + length]
                right_str = text[right - length + 1:right + 1]
                
                if left_str == right_str:
                    count += 2
                    left += length
                    right -= length
                    found = True
                    break
            
            if not found:
                if left <= right:
                    count += 1
                break
        
        return count
```

### 方法五：使用辅助函数

```python
class Solution:
    def longestDecomposition(self, text: str) -> int:
        """
        提取辅助函数，代码更清晰
        """
        def decompose(s: str) -> int:
            """分解字符串，返回最大块数"""
            if not s:
                return 0
            
            length = len(s)
            
            # 贪心寻找最短匹配
            for i in range(1, length // 2 + 1):
                if s[:i] == s[-i:]:
                    # 找到匹配，递归处理中间部分
                    return 2 + decompose(s[i:-i])
            
            # 无匹配，整个作为一块
            return 1
        
        return decompose(text)
```

## 复杂度分析

**时间复杂度**：O(n²)
- 外层循环：O(n)
- 内层每次字符串比较：O(n)
- 总共：O(n²)

**空间复杂度**：
- 迭代：O(1)
- 递归：O(n)，递归栈深度

## 关键点总结

1. **贪心策略**：越早切分越好，最大化块数
2. **双向匹配**：从字符串两端同时匹配
3. **递归思想**：找到匹配后递归处理剩余部分
4. **边界条件**：
   - 空字符串返回 0
   - 无法匹配时返回 1
5. **优化方向**：使用滚动哈希可以优化到 O(n)

## 易错点

1. **边界处理**：
   - `left <= right` 判断条件
   - 中间剩余部分为空的情况

2. **长度范围**：
   - 匹配长度最多到 `n // 2`
   - 不能超过中点

3. **字符串切片**：
   - 左边：`text[left:left + length]`
   - 右边：`text[right - length + 1:right + 1]`

4. **递归终止**：
   - 空字符串返回 0
   - 非空但无匹配返回 1

5. **重复计数**：
   - 找到匹配后加 2，不是 1
