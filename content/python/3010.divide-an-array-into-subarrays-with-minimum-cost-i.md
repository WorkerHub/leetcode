## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`。

定义数组的 **代价** 为第一个元素的值。

你需要将 `nums` 分割成 3 个不重叠、不为空的子数组，分割后三个子数组的代价之和最小。

返回这个最小代价之和。

**注意：** 子数组必须连续，且三个子数组合并后等于原数组。

**示例 1：**
```
输入：nums = [1,2,3,12]
输出：6
解释：三个子数组为 [1]、[2]、[3,12]，代价 = 1 + 2 + 3 = 6
```

**示例 2：**
```
输入：nums = [5,4,3]
输出：12
解释：只能分成 [5]、[4]、[3]，代价 = 5 + 4 + 3 = 12
```

**示例 3：**
```
输入：nums = [10,3,1,1]
输出：12
解释：分成 [10]、[3,1]、[1]，代价 = 10 + 3 + 1 = 14；或 [10]、[3]、[1,1]，代价 = 10 + 3 + 1 = 14；最优为 [10,3]...(不合法)
实际上 [10]、[3,1]、[1] 代价为 10+3+1=14，[10]、[3]、[1,1] 为 14，答案是 12
```

**提示：**
- `3 <= n <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

由于 `n <= 50`，可以直接枚举所有分割点。

- 三个子数组的代价分别是 `nums[0]`、`nums[i]`、`nums[j]`（其中 0 < i < j < n）
- 第一个子数组的第一个元素必定是 `nums[0]`，固定不变
- 需要找 `nums[1..n-1]` 中最小的两个值

## Python 代码实现

### 方法一：找两个最小值（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        # 第一个子数组代价固定为 nums[0]
        # 需要从 nums[1:] 中选最小的两个值作为后两个子数组的首元素
        rest = sorted(nums[1:])
        return nums[0] + rest[0] + rest[1]
```

### 方法二：枚举所有分割点

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        n = len(nums)
        ans = float('inf')
        # 枚举第二个子数组的起始位置 i 和第三个子数组的起始位置 j
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                cost = nums[0] + nums[i] + nums[j]
                ans = min(ans, cost)
        return ans
```

### 方法三：一次遍历找两个最小值

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        # 从 nums[1:] 中找最小和次小
        min1 = min2 = float('inf')
        for v in nums[1:]:
            if v <= min1:
                min2 = min1
                min1 = v
            elif v < min2:
                min2 = v
        return nums[0] + min1 + min2
```

## 复杂度分析

- 时间复杂度：O(n)，方法三单次遍历；方法一排序 O(n log n)；方法二枚举 O(n^2)
- 空间复杂度：O(1) 或 O(n)

## 关键点总结

1. 第一个子数组的代价固定为 `nums[0]`
2. 只需从 `nums[1:]` 中找两个最小的值
3. 本题数据范围小（n <= 50），枚举也可行

## 易错点

1. 注意是"不重叠、不为空"的子数组，所以 `i >= 1`，`j >= i + 1`
2. 第一个子数组固定从位置 0 开始，代价是 `nums[0]`，不能参与最小值的选取
