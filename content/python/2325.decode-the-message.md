## 题目描述

给你字符串 `key` 和 `message`，分别表示一个加密密钥和一段加密消息。

解密规则：
1. 使用 `key` 中 26 个英文小写字母**第一次出现的顺序**作为替换表的原字母顺序。
2. 将替换表中的字母与 `a-z` 依次对应（第一个新字母对应 `a`，第二个对应 `b`，等等）。
3. 对 `message` 中每个字母，用替换表解密（空格保持不变）。

**示例 1：**
```
输入：key = "the quick brown fox jumps over the lazy dog", message = "vkbs bs t suepuv"
输出："this is a secret"
```

**提示：**
- `26 <= key.length <= 2000`
- `key` 由英文小写字母和空格组成，且至少包含 26 个英文小写字母
- `1 <= message.length <= 2000`
- `message` 由英文小写字母和空格组成

## 解题思路

1. 遍历 `key`，按第一次出现顺序收集 26 个不同字母，构建解密映射表。
2. 第 `i` 个（从 0 起）收集到的字母，对应密文中的 `chr(ord('a') + i)`。
3. 遍历 `message`，将每个字母按映射表替换。

## 代码实现

### 方法一：哈希表（推荐）

```python
class Solution:
    def decodeMessage(self, key: str, message: str) -> str:
        # 构建解密映射：密文字母 -> 明文字母
        mapping = {}
        idx = 0  # 当前明文字母的序号
        
        for c in key:
            if c != ' ' and c not in mapping:
                mapping[c] = chr(ord('a') + idx)
                idx += 1
                if idx == 26:
                    break  # 26 个字母已全部映射完毕
        
        # 解密消息
        result = []
        for c in message:
            if c == ' ':
                result.append(' ')
            else:
                result.append(mapping[c])
        
        return ''.join(result)
```

### 方法二：使用 str.translate

```python
class Solution:
    def decodeMessage(self, key: str, message: str) -> str:
        # 从 key 中按顺序提取不重复字母
        seen = set()
        order = []
        for c in key:
            if c != ' ' and c not in seen:
                seen.add(c)
                order.append(c)
        
        # 构建翻译表：密文字母 -> 明文字母
        # str.maketrans(from_str, to_str) 创建字符映射
        from_str = ''.join(order)
        to_str = 'abcdefghijklmnopqrstuvwxyz'
        table = str.maketrans(from_str, to_str)
        
        return message.translate(table)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表 | O(|key| + |message|) | O(1)（映射表大小固定为 26） |
| str.translate | O(|key| + |message|) | O(1) |

## 关键点总结

1. 按 `key` 中字母**第一次出现**的顺序建立映射，不是按字母表顺序。
2. 空格保持不变，不参与映射。
3. `str.maketrans` + `str.translate` 是 Python 处理字符替换的利器。

## 易错点

- `key` 中可能包含空格，要跳过。
- 同一字母在 `key` 中可能多次出现，只取第一次。
