## 题目描述

给你一个整数数组 `nums`，如果从 `nums` 中删除一个子数组后，剩余元素严格递增，则称该子数组为递增可删除子数组。

返回 `nums` 中递增可删除子数组的总数目。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

枚举左端点 l（0 到 n）：
- l = 0：左段为空，右段（从 r+1 开始）必须严格递增
- l > 0：左段 nums[0..l-1] 必须严格递增，连接处 nums[l-1] < nums[r+1]

对每个左端点 l，找最小的 r 使得删除 nums[l..r] 后合法。

预处理：
- `pre[l]`：nums[0..l-1] 是否严格递增（即前 l 个元素递增）
- 找最长的严格递增前缀长度 `left_end`
- 找最长的严格递增后缀起始位置 `right_start`

用双指针：枚举 l，对每个 l 找最小的 r（用二分）。

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List
import bisect

class Solution:
    def incremovableSubarrayCount(self, nums: List[int]) -> int:
        n = len(nums)

        # 找最长严格递增前缀
        # pre_end: 最大的 i 使得 nums[0..i] 严格递增
        pre_end = 0
        while pre_end + 1 < n and nums[pre_end] < nums[pre_end + 1]:
            pre_end += 1

        # 若整个数组严格递增
        if pre_end == n - 1:
            return n * (n + 1) // 2

        ans = 0

        # 枚举左端点 l（删除子数组起始位置）
        # l = 0: 左段为空，只需右段严格递增
        # l 从 0 到 pre_end + 1（l > pre_end+1 时左段不再递增）

        # j: 后缀严格递增的起始下标
        # 初始 j = n（后缀为空）
        j = n

        for l in range(pre_end + 2):  # l in [0, pre_end+1]
            # 对于当前 l，找最小的 r 使得后缀 nums[r+1..n-1] 严格递增
            # 且若 l > 0，nums[l-1] < nums[r+1]

            # 调整 j 使得 nums[j..n-1] 严格递增且 nums[l-1] < nums[j]（若 l > 0）
            if l == 0:
                # 左段为空，右段需严格递增（自然找最长后缀的起始）
                # 找最大的 j 使 nums[j..n-1] 严格递增
                # 但我们要找合法的最小 r = j - 1，即 r in [l-1, j-1] 都合法
                # 每个 r 在 [l-1, j-1] 范围内合法
                pass

            # 用双指针：j 从 n 开始递减
            # 对于 l，找满足条件的最小 r
            # 合法条件：删除 [l, r]，剩余 nums[0..l-1] + nums[r+1..n-1] 严格递增
            # 需要：nums[r+1..n-1] 严格递增 + nums[l-1] < nums[r+1]（若两者都存在）

            # 调整 j 向右移动（随 l 增大）
            if l > 0:
                while j > l and (j == n or nums[l - 1] < nums[j]):
                    if j < n and (j == 0 or nums[j - 1] >= nums[j]):
                        break
                    j -= 1
                # 实际用更清晰的逻辑

            pass

        # 简洁版实现
        # 找后缀递增的起始位置
        suf_start = n - 1
        while suf_start > 0 and nums[suf_start - 1] < nums[suf_start]:
            suf_start -= 1

        ans = 0
        # 枚举左端点 l，右端点 r 从 l 到 n-1
        # 左段 [0, l-1] 必须严格递增
        for l in range(pre_end + 2):
            if l == 0:
                # 左段为空，r 从 l 到 n-1，但后缀需递增
                # 后缀 [r+1, n-1] 从 suf_start 开始是递增的
                # r >= suf_start - 1 就可以（后缀从 suf_start 开始）
                ans += n - max(l, suf_start - 1 + 1) + 1
                # 即 r in [l-1, n-1] 满足后缀递增的 r 数量
                # r >= suf_start - 1: r+1 >= suf_start
                # 也就是 r in [suf_start-1, n-1]，共 n - suf_start + 1 个
                # 但 l=0 时删除 [0, r]，r 从 0 到 n-1
                ans = 0  # 重新计算
                break

        # 使用正确的双指针实现
        ans = 0
        j = n  # j 表示：nums[j..n-1] 严格递增，j 初始为 n（空后缀）
        # 同时维护 j 使得 nums[l-1] < nums[j]（l>0 时）

        # 先找后缀递增的分界点
        # j_global: 最小的 j 使 nums[j..n-1] 严格递增
        j_global = n - 1
        while j_global > 0 and nums[j_global - 1] < nums[j_global]:
            j_global -= 1

        for l in range(pre_end + 2):
            # 找最小的 r 使得合法（r >= l - 1，左段 [0,l-1] 递增）
            # 合法：后缀 [r+1,n-1] 递增 AND nums[l-1] < nums[r+1]（若 l>0 且 r<n-1）

            # 用二分找最小的 r+1 = mid 使 nums[mid..n-1] 递增且（l>0 => nums[l-1] < nums[mid]）
            # 最小的 r+1：先找后缀从 j_global 开始递增，再检查连接条件

            # 简化：j 从上一次的 j 开始，不断减小直到条件不满足
            # 这里用二分查找更清晰
            lo, hi = l, n
            while lo < hi:
                mid_r = (lo + hi) // 2  # 尝试 r = mid_r
                # 检查 r+1=mid_r+1 到 n-1 是否严格递增
                r_plus1 = mid_r + 1
                valid_suf = r_plus1 >= j_global  # 后缀从 j_global 开始递增
                # 或者 r_plus1 == n（后缀为空）
                valid_suf = valid_suf or r_plus1 >= n
                valid_connect = (l == 0 or r_plus1 >= n or nums[l - 1] < nums[r_plus1])
                if valid_suf and valid_connect:
                    hi = mid_r
                else:
                    lo = mid_r + 1
            # lo 是最小的 r，r in [lo, n-1] 都合法
            ans += n - lo

        return ans
```

### 方法二：正确的双指针实现

```python
from typing import List

class Solution:
    def incremovableSubarrayCount(self, nums: List[int]) -> int:
        n = len(nums)

        # 找最长严格递增前缀末尾 pre_end
        pre_end = 0
        while pre_end + 1 < n and nums[pre_end] < nums[pre_end + 1]:
            pre_end += 1

        if pre_end == n - 1:
            return n * (n + 1) // 2

        # 找最长严格递增后缀起始 suf_start
        suf_start = n - 1
        while suf_start > 0 and nums[suf_start - 1] < nums[suf_start]:
            suf_start -= 1

        ans = 0
        # 枚举左端点 l（0 到 pre_end+1）
        j = suf_start  # 初始后缀起始
        for l in range(pre_end + 2):
            # 对于左端点 l，right 端点 r 必须满足:
            # 1. r >= l - 1（删除至少 1 个元素）
            # 2. nums[r+1..n-1] 严格递增
            # 3. 若 l > 0 且 r < n-1: nums[l-1] < nums[r+1]

            # 找最小的 r 满足条件 2 和 3
            # r+1 必须 >= suf_start（使后缀递增）
            # 若 l > 0：r+1 必须满足 nums[r+1] > nums[l-1]（在后缀中用二分）

            if l == 0:
                min_r = suf_start - 1  # r+1 = suf_start
            else:
                # 在 [suf_start, n] 中找第一个 > nums[l-1] 的位置
                import bisect
                pos = bisect.bisect_right([nums[k] for k in range(suf_start, n)], nums[l - 1])
                min_r = suf_start + pos - 1

            # r 的范围：[max(l-1, min_r), n-1]
            r_lo = max(l - 1, min_r)
            if r_lo <= n - 1:
                ans += n - r_lo

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，双指针 + 二分
- 空间复杂度：O(1)

## 关键点总结

1. 预处理最长递增前缀和后缀
2. 枚举左端点 l（只需枚举前缀末尾之前的位置）
3. 对每个 l，用二分找满足条件的最小右端点 r

## 易错点

1. 整个数组递增时所有子数组都合法，共 n*(n+1)/2 个
2. 枚举 l 的范围：0 到 pre_end+1（超过此范围左段不再递增）
3. 连接条件和后缀递增条件需要同时满足
