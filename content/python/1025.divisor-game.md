## 题目描述

爱丽丝和鲍勃一起玩游戏，他们轮流行动。爱丽丝先手开局。

最初，黑板上有一个数字 `n`。在每个玩家的回合，玩家需要执行以下操作：

- 选出任一 `x`，满足 `0 < x < n` 且 `n % x == 0`。
- 用 `n - x` 替换黑板上的数字 `n`。

如果玩家无法执行这些操作，就会输掉游戏。

只有在爱丽丝在游戏中取得胜利时才返回 `true`。假设两个玩家都以最佳状态参与游戏。

**示例 1：**
```
输入：n = 2
输出：true
解释：爱丽丝选择 1，鲍勃无法进行操作。
```

**示例 2：**
```
输入：n = 3
输出：false
解释：爱丽丝选择 1，鲍勃也选择 1，然后爱丽丝无法进行操作。
```

**提示：**
- `1 <= n <= 1000`

## 解题思路

这是一道经典的博弈论问题。

**数学规律**：
- n为偶数时，Alice必胜
- n为奇数时，Alice必败

**证明**：
1. **奇数的因子只能是奇数**
   - 奇数 - 奇数 = 偶数
   - Alice面对奇数n，只能选奇数x，得到偶数n-x给Bob
   
2. **偶数至少有因子1**
   - 偶数 - 1 = 奇数
   - Bob面对偶数，可以选1，得到奇数给Alice

3. **归纳法**：
   - n=1时，Alice无操作，必败
   - n=2时，Alice选1，Bob面对1，Alice必胜
   - 奇数必败，偶数必胜

**动态规划思路**：
- `dp[i]` = Alice面对i时是否必胜
- `dp[i] = true` 如果存在一个移动使对手必败

## Python 代码实现

### 方法一：数学规律（推荐）⭐⭐⭐

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        """
        数学规律：n为偶数时Alice必胜
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        return n % 2 == 0
```

### 方法二：动态规划

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        """
        动态规划求解博弈问题
        时间复杂度：O(n²)
        空间复杂度：O(n)
        """
        # dp[i] 表示面对i时先手是否必胜
        dp = [False] * (n + 1)
        
        # 边界：面对1时先手必败（无法操作）
        dp[1] = False
        
        # 从2开始计算
        for i in range(2, n + 1):
            # 尝试所有可能的移动
            for x in range(1, i):
                # x必须是i的因子
                if i % x == 0:
                    # 如果存在一个移动使对手必败，则当前必胜
                    if not dp[i - x]:
                        dp[i] = True
                        break
        
        return dp[n]
```

### 方法三：记忆化搜索

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        """
        记忆化递归
        时间复杂度：O(n²)
        空间复杂度：O(n)
        """
        memo = {}
        
        def can_win(num: int) -> bool:
            """判断面对num时先手是否必胜"""
            if num in memo:
                return memo[num]
            
            # 基础情况
            if num == 1:
                return False
            
            # 尝试所有可能的移动
            for x in range(1, num):
                if num % x == 0:
                    # 如果存在一个移动使对手必败
                    if not can_win(num - x):
                        memo[num] = True
                        return True
            
            # 所有移动都让对手必胜，则当前必败
            memo[num] = False
            return False
        
        return can_win(n)
```

### 方法四：详细分析版

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        """
        详细推导过程
        
        手工推导小规模情况：
        n=1: Alice无法操作 → False
        n=2: Alice选1，Bob面对1 → True
        n=3: Alice只能选1，Bob面对2（必胜）→ False
        n=4: Alice可选1或2
             选2：Bob面对2（必胜）→ 不选
             选1：Bob面对3（必败）→ True
        ...
        
        规律：偶数True，奇数False
        """
        # 直接返回规律
        return n % 2 == 0
        
        # 或者用DP验证规律
        if n == 1:
            return False
        
        dp = [False] * (n + 1)
        
        for i in range(2, n + 1):
            # 对于当前数i，尝试所有因子
            for x in range(1, i):
                if i % x == 0 and not dp[i - x]:
                    dp[i] = True
                    break
        
        return dp[n]
```

## 图解示例

```

n=2: 因子{1}
  Alice选1 → n=1 → Bob面对False → Alice胜 → True

n=3: 因子{1}
  Alice选1 → n=2 → Bob面对True → Bob胜 → False

n=4: 因子{1,2}
  Alice选1 → n=3 → Bob面对False → Alice胜 → True
  Alice选2 → n=2 → Bob面对True → Bob胜
  
n=5: 因子{1}
  Alice选1 → n=4 → Bob面对True → Bob胜 → False

规律：2✓ 3✗ 4✓ 5✗ 6✓ 7✗ 8✓ ...
      偶数必胜，奇数必败
```

## 关键点总结

1. **博弈论基础**：先手必胜当且仅当存在一步使后手必败
2. **数学规律**：偶数必胜，奇数必败
3. **奇偶性分析**：
   - 奇数的因子都是奇数
   - 奇数 - 奇数 = 偶数
4. **DP状态定义**：`dp[i]` = 面对i时先手是否必胜
5. **状态转移**：`dp[i] = true` 如果存在x使`dp[i-x] = false`

## 易错点

1. **博弈论理解**：先手必胜不是说每步都赢，而是存在必胜策略
2. **状态转移**：要找到至少一个使对手必败的移动
3. **边界条件**：n=1时无法操作，先手必败
4. **规律证明**：需要理解奇偶性的传递
5. **因子遍历**：只遍历真因子，不包括n本身
