## 题目描述

给定一个目标字符串 target 和一个字符串数组 dictionary，找出 target 的最短缩写，使得它不会与 dictionary 中的任何字符串的缩写冲突。

缩写规则同 408 题。

**示例：**
```
输入：target = "apple", dictionary = ["blade"]
输出："a4"
解释："apple" 可以缩写为 "5", "a4", "ap3", "app2", "appl1", "apple"
     "blade" 可以缩写为 "5", "b4", "bl3", "bla2", "blad1", "blade"
     "a4" 是最短的且不与 "blade" 冲突
```

## 解题思路

这是一道困难题，需要枚举所有可能的缩写并验证。

核心思路：
1. 生成所有可能的缩写
2. 验证每个缩写是否与 dictionary 中的单词冲突
3. 选择最短的有效缩写

## Python 代码实现

### 方法一：回溯 + 验证

```python
from typing import List

class Solution:
    def minAbbreviation(self, target: str, dictionary: List[str]) -> str:
        """
        回溯生成所有缩写，找最短的不冲突的
        """
        # 过滤掉长度不同的单词
        dictionary = [word for word in dictionary if len(word) == len(target)]
        
        if not dictionary:
            return str(len(target))
        
        def is_valid_abbr(word: str, abbr: str) -> bool:
            """验证 abbr 是否是 word 的有效缩写"""
            i = j = 0
            while j < len(abbr):
                if abbr[j].isdigit():
                    if abbr[j] == '0':
                        return False
                    num = 0
                    while j < len(abbr) and abbr[j].isdigit():
                        num = num * 10 + int(abbr[j])
                        j += 1
                    i += num
                else:
                    if i >= len(word) or word[i] != abbr[j]:
                        return False
                    i += 1
                    j += 1
            return i == len(word)
        
        def is_unique(abbr: str) -> bool:
            """检查缩写是否与字典中的单词冲突"""
            for word in dictionary:
                if is_valid_abbr(word, abbr):
                    return False
            return True
        
        min_abbr = target
        
        def backtrack(index: int, abbr: str, count: int):
            """
            index: 当前处理到的位置
            abbr: 当前缩写
            count: 连续数字计数
            """
            nonlocal min_abbr
            
            if index == len(target):
                if count > 0:
                    abbr += str(count)
                if len(abbr) < len(min_abbr) and is_unique(abbr):
                    min_abbr = abbr
                return
            
            # 剪枝：当前长度已经不优
            current_len = len(abbr) + (1 if count > 0 else 0) + (len(target) - index)
            if current_len >= len(min_abbr):
                return
            
            # 选择1：缩写当前字符
            backtrack(index + 1, abbr, count + 1)
            
            # 选择2：保留当前字符
            new_abbr = abbr + (str(count) if count > 0 else "") + target[index]
            backtrack(index + 1, new_abbr, 0)
        
        backtrack(0, "", 0)
        return min_abbr
```

## 复杂度分析

- **时间复杂度**：O(2^n * m * n)
  - 生成 2^n 种缩写
  - 验证每个缩写需要 O(m * n)
  
- **空间复杂度**：O(n)

## 关键点总结

1. 过滤长度不同的单词
2. 回溯生成所有缩写
3. 验证缩写的唯一性
4. 剪枝优化
