## 题目描述

给你两个**非递增**整数数组 `nums1` 和 `nums2`，数组下标均从 0 开始。

如果满足 `0 <= i <= j <= nums2.length - 1` 且 `nums1[i] <= nums2[j]`，则称 `(i, j)` 为一个**有效数对**，并定义距离为 `j - i`。

返回所有有效数对 `(i, j)` 中的**最大距离**，若不存在有效数对则返回 0。

**示例 1：**
```
输入：nums1 = [55,30,5,4,2], nums2 = [100,20,10,10,5]
输出：2
```

**示例 2：**
```
输入：nums1 = [2,2,2], nums2 = [10,10,1]
输出：1
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`

## 解题思路

**方法一（双指针）**：利用两个数组都非递增的性质。

用两个指针 i 和 j，初始都在 0：
- 若 `nums1[i] <= nums2[j]`，则 `(i, j)` 是有效数对，更新最大距离，j 右移
- 否则，i 右移（i 不能大于 j）

**方法二（二分查找）**：对每个 i，在 `nums2[i:]` 中二分查找最后一个 >= `nums1[i]` 的位置。

## 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def maxDistance(self, nums1: List[int], nums2: List[int]) -> int:
        i, j = 0, 0
        max_dist = 0
        m, n = len(nums1), len(nums2)

        while i < m and j < n:
            if nums1[i] <= nums2[j]:
                # 有效数对，更新最大距离
                max_dist = max(max_dist, j - i)
                j += 1
            else:
                # 不满足条件，i 右移
                i += 1
                if i > j:
                    j = i  # j 不能小于 i

        return max_dist
```

### 方法二：二分查找

```python
import bisect
from typing import List

class Solution:
    def maxDistance(self, nums1: List[int], nums2: List[int]) -> int:
        max_dist = 0
        n = len(nums2)

        for i in range(len(nums1)):
            # 在 nums2[i:] 中找最后一个 >= nums1[i] 的位置
            # nums2 非递增，反转后变非递减，用 bisect_right
            # 或直接在 [i, n) 范围内二分查找
            lo, hi = i, n - 1
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if nums2[mid] >= nums1[i]:
                    lo = mid
                else:
                    hi = mid - 1
            if nums2[lo] >= nums1[i]:
                max_dist = max(max_dist, lo - i)

        return max_dist
```

## 复杂度分析

- **方法一（双指针）**：O(m + n) 时间，O(1) 空间
- **方法二（二分）**：O(m * log n) 时间，O(1) 空间

## 关键点总结

1. 双指针利用两数组的单调性，每次移动其中一个指针
2. 注意 j 不能小于 i（有效对要求 i <= j）
3. 二分查找在 nums2 的非递增序列上找最右侧的合法位置

## 易错点

- 双指针法中，i 超过 j 时要将 j 追上 i，否则距离可能为负
- 二分法中，在 `[i, n-1]` 范围内查找，起点是 i（不是 0）
