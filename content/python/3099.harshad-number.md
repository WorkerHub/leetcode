## 题目描述

如果一个整数能被其各位数字之和整除，则称其为 Harshad 数。

给你一个整数 `x`，若 `x` 是 Harshad 数，返回其各位数字之和；否则返回 -1。

**示例 1：**
```
输入：x = 18
输出：9
解释：各位数字之和 = 1+8 = 9，18 % 9 = 0，是 Harshad 数，返回 9
```

**示例 2：**
```
输入：x = 23
输出：-1
解释：各位数字之和 = 2+3 = 5，23 % 5 != 0，返回 -1
```

**提示：**
- `1 <= x <= 100`

## Python 代码实现

### 方法一：字符串转换（推荐）

```python
class Solution:
    def sumOfTheDigitsOfHarshadNumber(self, x: int) -> int:
        digit_sum = sum(int(d) for d in str(x))
        return digit_sum if x % digit_sum == 0 else -1
```

### 方法二：数学计算

```python
class Solution:
    def sumOfTheDigitsOfHarshadNumber(self, x: int) -> int:
        s = 0
        tmp = x
        while tmp:
            s += tmp % 10
            tmp //= 10
        return s if x % s == 0 else -1
```

## 复杂度分析

- 时间复杂度：O(log x)，位数
- 空间复杂度：O(1)

## 关键点总结

1. 计算各位数字之和
2. 判断 x 能否被该和整除

## 易错点

1. 返回的是各位数字之和，不是 True/False
2. 若不是 Harshad 数返回 -1
