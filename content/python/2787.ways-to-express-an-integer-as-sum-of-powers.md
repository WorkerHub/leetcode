## 题目描述

给你两个 **正整数** `n` 和 `x`，返回将 `n` 表示成若干 **不同正整数** 的 `x` 次幂之和的方案数（对 `10^9 + 7` 取模）。

即找出满足 `n = a1^x + a2^x + ... + ak^x` 的所有方案，其中 `a1, a2, ..., ak` 互不相同。

**示例 1：**
```
输入：n = 10, x = 2
输出：1
解释：10 = 1^2 + 3^2（其他组合如 1+9=1+3^2 即同一种）
```

**示例 2：**
```
输入：n = 4, x = 1
输出：2
解释：4 = 4 = 1+3
```

**提示：**
- `1 <= n <= 300`
- `1 <= x <= 5`

## 解题思路

**0-1 背包**：每个正整数的 x 次幂作为物品，容量为 n，求填满容量的方案数。

预处理所有 `i^x <= n` 的正整数，然后跑 0-1 背包（每个数只用一次）。

## Python 代码实现

### 方法一：0-1 背包（推荐）

```python
class Solution:
    def numberOfWays(self, n: int, x: int) -> int:
        MOD = 10**9 + 7
        # 生成所有 <= n 的 x 次幂
        powers = []
        i = 1
        while i**x <= n:
            powers.append(i**x)
            i += 1

        # 0-1 背包：dp[j] = 和为 j 的方案数
        dp = [0] * (n + 1)
        dp[0] = 1
        for pw in powers:
            for j in range(n, pw - 1, -1):  # 倒序，保证每个数用一次
                dp[j] = (dp[j] + dp[j - pw]) % MOD

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^(1/x) * n)，幂次数约 n^(1/x)
- 空间复杂度：O(n)

## 关键点总结

1. 每个数只能用一次，0-1 背包倒序枚举
2. 物品是所有 `i^x <= n` 的正整数幂

## 易错点

1. 每个正整数只能用一次（不是完全背包）
2. 倒序遍历 dp 数组
