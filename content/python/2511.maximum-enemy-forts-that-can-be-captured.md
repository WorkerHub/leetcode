## 题目描述

给你一个长度为 `n` 的整数数组 `forts`，其中 `forts[i]` 为：
- `1`：你自己的要塞
- `-1`：敌人的要塞
- `0`：空地

每次移动，你需要选择一个 **你自己的要塞**（值为 1），然后向左或向右移动，路过若干空地（值为 0），最终到达**另一个你自己的要塞或任意敌人要塞**。路过的空地上的敌人要塞数目即为此次捕获的数量。

返回你能够捕获的 **敌人要塞** 的最大数目。如果无法捕获任何敌人要塞，返回 `0`。

**示例 1：**

```
输入：forts = [1, 0, 0, -1, 0, 0, 0, 0, 1]
输出：0
解释：从位置 0 移到 3，经过空地，但 -1 是终点，路过的空地上没有敌人要塞。
```

**示例 2：**

```
输入：forts = [0, 0, 1, -1]
输出：0
```

**提示：**

- `1 <= forts.length <= 1000`
- `-1 <= forts[i] <= 1`

## 解题思路

遍历数组，找到相邻的 1 和 -1（或 -1 和 1），中间全为 0 的区间长度即为本次移动能经过的空地数。

注意：经过的是空地（值为 0），捕获的是路过空地上的敌军，但题目实际是：从 1 走到 -1（或反向），中间只有 0，则"被捕获的敌方阵地"就是经过的空地数。

实际理解：计算每对相邻的 (1, -1) 或 (-1, 1)（中间全为 0）之间的 0 的数量，取最大值。

## Python 代码实现

### 方法一：双指针遍历（推荐）

```python
from typing import List

class Solution:
    def captureForts(self, forts: List[int]) -> int:
        n = len(forts)
        ans = 0
        i = 0
        while i < n:
            if forts[i] != 0:
                # 找到一个非零位置（1 或 -1），向右寻找下一个非零位置
                j = i + 1
                while j < n and forts[j] == 0:
                    j += 1
                if j < n and forts[i] + forts[j] == 0:
                    # forts[i] 和 forts[j] 一个为 1，一个为 -1
                    # 中间全为 0，数量为 j - i - 1
                    ans = max(ans, j - i - 1)
                i = j
            else:
                i += 1
        return ans
```

### 方法二：枚举所有非零对

```python
from typing import List

class Solution:
    def captureForts(self, forts: List[int]) -> int:
        # 记录所有非零位置
        positions = [i for i, v in enumerate(forts) if v != 0]
        ans = 0
        for k in range(len(positions) - 1):
            i, j = positions[k], positions[k + 1]
            # 一个为 1，一个为 -1，中间有 j-i-1 个空地
            if forts[i] + forts[j] == 0:
                ans = max(ans, j - i - 1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，线性扫描数组
- 空间复杂度：O(1)（方法一）或 O(n)（方法二）

## 关键点总结

1. 只考虑相邻的 1 和 -1（中间全为 0），不需要考虑非相邻的情况
2. 两端值之和为 0，说明一个是 1 一个是 -1
3. 空地数 = 右端位置 - 左端位置 - 1

## 易错点

1. 移动时中间必须全是 0，不能有其他 1 或 -1 隔断
2. 不是统计 -1 的数量，而是统计中间 0 的数量
3. 1 到 -1 和 -1 到 1 都是有效移动方向
