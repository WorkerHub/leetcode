## 题目描述

给你一个下标从 0 开始的整数数组 `scores`，表示股票的分数。

你可以选择一个**线性股票**：即选出一些下标 `i1 < i2 < ... < ik`，满足对所有相邻的选中下标 `ij` 和 `ij+1`，有：

`scores[ij+1] - scores[ij] == ij+1 - ij`（等差等间距）

等价地：`scores[i] - i` 为常数。

返回所有可能的线性股票中，分数之和的**最大值**。

**示例 1：**
```
输入：scores = [2, 4, 3, 5]
输出：9
解释：
选下标 0, 1, 3：scores = [2, 4, 5]
scores[i] - i：2-0=2, 4-1=3, 5-3=2...不满足
选下标 0, 3：scores[0]-0=2, scores[3]-3=2，满足
选下标 1, 2：scores[1]-1=3, scores[2]-2=1，不满足
最优：选下标 1 和 3，scores[1]-1=3, scores[3]-3=2...
实际：选 scores[2]=3, scores[3]=5，3-2=1, 5-3=2...
```

**示例 2：**
```
输入：scores = [2, 1, 2, 3, 2, 1]
输出：6
```

**提示：**
- `1 <= scores.length <= 10^5`
- `1 <= scores[i] <= 10^8`

## 解题思路

**核心变换：**

条件 `scores[ij+1] - scores[ij] == ij+1 - ij` 等价于 `scores[i] - i == 常数`。

因此，将每个元素变换为 `v = scores[i] - i`，问题变为：

找 `v` 值相同的所有下标的 `scores[i]` 之和的最大值。

**方法：** 用哈希表按 `scores[i] - i` 分组，每组求和，取最大值。

## Python 代码实现

### 方法一：哈希表分组（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxScore(self, scores: List[int]) -> int:
        # 按 scores[i] - i 分组，求各组之和
        group_sum = defaultdict(int)
        for i, s in enumerate(scores):
            group_sum[s - i] += s

        return max(group_sum.values())
```

### 方法二：Counter + 显式构建

```python
from typing import List

class Solution:
    def maxScore(self, scores: List[int]) -> int:
        d = {}
        for i, s in enumerate(scores):
            key = s - i
            d[key] = d.get(key, 0) + s

        return max(d.values())
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，哈希表存储

## 关键点总结

1. 线性条件 `scores[j] - scores[i] == j - i` 等价于 `scores[i] - i == 常数`
2. 变换后的问题：找相同键值的分数之和最大
3. 哈希表 O(n) 解决

## 易错点

1. 注意键是 `scores[i] - i`（可能为负数），哈希表可以处理负键
2. 分组累加的是 `scores[i]`（原始分数），不是 `scores[i] - i`
