## 题目描述

返回所有长度为 `n` 且满足其每两个连续位上的数字之间的差的绝对值为 `k` 的**非负整数**。

请注意，**除了**数字 `0` 本身之外，答案中的每个数字都**不能**有前导零。例如，`01` 是无效的，但 `0` 是有效的。

你可以按**任何顺序**返回答案。

**示例 1：**
```
输入：n = 3, k = 7
输出：[181,292,707,818,929]
解释：注意，070 不是一个有效的数字，因为它有前导零。
```

**示例 2：**
```
输入：n = 2, k = 1
输出：[10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]
```

**提示：**
- `2 <= n <= 9`
- `0 <= k <= 9`

## 解题思路

这道题要求生成长度为 n 的数字，相邻位数字差的绝对值为 k。

**核心思想：**
1. 从第一位数字开始（1-9，不能为 0），逐位构建
2. 对于当前位数字 d，下一位可以是 d+k 或 d-k（如果在 0-9 范围内）
3. 使用 BFS 或 DFS（回溯）生成所有满足条件的数字

**特殊情况：**
- n = 1 时，返回 [0, 1, 2, ..., 9]
- k = 0 时，所有位数字相同

## Python 代码实现

### 方法一：BFS（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        # 特殊情况：n = 1
        if n == 1:
            return list(range(10))
        
        # BFS：队列存储 (当前数字, 当前长度)
        queue = deque([(i, 1) for i in range(1, 10)])
        result = []
        
        while queue:
            num, length = queue.popleft()
            
            # 如果已经达到长度 n
            if length == n:
                result.append(num)
                continue
            
            # 获取当前数字的最后一位
            last_digit = num % 10
            
            # 尝试添加下一位数字
            # 下一位可以是 last_digit + k
            if last_digit + k <= 9:
                queue.append((num * 10 + last_digit + k, length + 1))
            
            # 下一位可以是 last_digit - k
            # 注意：k = 0 时，+k 和 -k 相同，只添加一次
            if k != 0 and last_digit - k >= 0:
                queue.append((num * 10 + last_digit - k, length + 1))
        
        return result
```

### 方法二：DFS（回溯）

```python
from typing import List

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        # 特殊情况
        if n == 1:
            return list(range(10))
        
        result = []
        
        def dfs(num, length):
            """从 num 开始构建，当前长度为 length"""
            # 达到目标长度
            if length == n:
                result.append(num)
                return
            
            # 获取最后一位数字
            last_digit = num % 10
            
            # 尝试添加 last_digit + k
            if last_digit + k <= 9:
                dfs(num * 10 + last_digit + k, length + 1)
            
            # 尝试添加 last_digit - k（k = 0 时避免重复）
            if k != 0 and last_digit - k >= 0:
                dfs(num * 10 + last_digit - k, length + 1)
        
        # 从每个非零数字开始
        for i in range(1, 10):
            dfs(i, 1)
        
        return result
```

### 方法三：迭代构建

```python
from typing import List

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        # 特殊情况
        if n == 1:
            return list(range(10))
        
        # 从第一位开始：1-9
        current = list(range(1, 10))
        
        # 逐位构建
        for _ in range(n - 1):
            next_level = []
            for num in current:
                last_digit = num % 10
                
                # 添加 last_digit + k
                if last_digit + k <= 9:
                    next_level.append(num * 10 + last_digit + k)
                
                # 添加 last_digit - k
                if k != 0 and last_digit - k >= 0:
                    next_level.append(num * 10 + last_digit - k)
            
            current = next_level
        
        return current
```

### 方法四：生成器版本

```python
from typing import List

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        def generate(num, remaining):
            """生成器：生成所有满足条件的数字"""
            if remaining == 0:
                yield num
                return
            
            last_digit = num % 10
            
            # 下一位是 last_digit + k
            if last_digit + k <= 9:
                yield from generate(num * 10 + last_digit + k, remaining - 1)
            
            # 下一位是 last_digit - k
            if k != 0 and last_digit - k >= 0:
                yield from generate(num * 10 + last_digit - k, remaining - 1)
        
        # 特殊情况
        if n == 1:
            return list(range(10))
        
        # 从 1-9 开始生成
        result = []
        for i in range(1, 10):
            result.extend(generate(i, n - 1))
        
        return result
```

### 方法五：字符串拼接

```python
from typing import List

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        if n == 1:
            return list(range(10))
        
        result = []
        
        def dfs(num_str):
            """使用字符串构建"""
            if len(num_str) == n:
                result.append(int(num_str))
                return
            
            last_digit = int(num_str[-1])
            
            # 添加 last_digit + k
            if last_digit + k <= 9:
                dfs(num_str + str(last_digit + k))
            
            # 添加 last_digit - k
            if k != 0 and last_digit - k >= 0:
                dfs(num_str + str(last_digit - k))
        
        # 从每个非零数字开始
        for i in range(1, 10):
            dfs(str(i))
        
        return result
```

## 复杂度分析

### 方法一/二/三
- **时间复杂度**：O(2^n)，每位最多有 2 个选择
- **空间复杂度**：O(2^n)，存储结果和队列/递归栈

## 关键点总结

1. **逐位构建**：从第一位开始，每次添加一位
2. **避免前导零**：第一位从 1 开始，不是 0
3. **k = 0 特殊处理**：避免重复添加相同数字
4. **边界检查**：下一位数字必须在 0-9 范围内
5. **BFS vs DFS**：两种方法都可行，BFS 更直观

## 易错点

1. **n = 1**：特殊情况，包括 0
2. **k = 0**：+k 和 -k 相同，只添加一次
3. **前导零**：第一位不能是 0
4. **范围检查**：next_digit 必须在 [0, 9] 内
5. **重复问题**：k = 0 时要特别注意
