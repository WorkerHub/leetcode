## 题目描述

给你一个正整数 `n`，找到**最小**的正整数 `x`，使得 `x` 的各位数字之积等于 `n`。

如果不存在这样的整数，返回 "-1"。

返回字符串形式。

**示例 1：**
```
输入：n = 36
输出："49"
解释：4*9=36，最小的是 49（比 69, 99, 94, 36... 都小吗？36 本身各位积=18，不是36）
```

**示例 2：**
```
输入：n = 100
输出："-1"
解释：没有数字积等于 100（因为 100=4×25，25 不是 2-9 的整数次幂组合）
```

**提示：**
- `1 <= n <= 10^18`

## 解题思路

**贪心：** 将 n 分解为 2-9 的因子（从 9 开始向 2 贪心），位数越少越好，当位数相同时数字越小越好。

**算法：**
1. 如果 n == 1，答案是 "1"
2. 从 9 到 2，尽量用大数字（减少位数），贪心分解：
   - 若 n % d == 0，则用 d，n /= d，记录 d
   - 直到 n 变为 1
3. 如果最后 n > 1（如 n 是质数且 > 9 如 11），返回 "-1"
4. 将收集的数字**从小到大**排序（使数值最小），拼接成字符串

为什么从 9 开始？减少位数。
为什么排序？位数相同时，小数在前使整体数值最小（如 [2,9] 排成 "29" < "92"）。

## Python 代码实现

### 方法一：贪心分解（推荐）

```python
class Solution:
    def smallestNumber(self, n: int) -> str:
        if n == 1:
            return "1"

        digits = []
        # 从 9 到 2 贪心分解（优先大因子以减少位数）
        for d in range(9, 1, -1):
            while n % d == 0:
                digits.append(d)
                n //= d

        if n > 1:
            return "-1"  # 无法分解为 2-9 的因子

        # 排序（从小到大）以获得最小数值
        digits.sort()
        return ''.join(map(str, digits))
```

### 方法二：带注释的详细版

```python
class Solution:
    def smallestNumber(self, n: int) -> str:
        if n == 1:
            return "1"

        result = []

        # 从 9 到 2 依次尝试整除
        for d in range(9, 1, -1):
            while n % d == 0:
                result.append(str(d))  # 记录因子
                n //= d               # 更新 n

        # 若 n > 1，说明有无法分解的质因子（> 9）
        if n > 1:
            return "-1"

        # 将因子从小到大排序（使组合的数最小）
        result.sort()
        return ''.join(result)
```

## 复杂度分析

- 时间复杂度：O(log n × 8)，最多分解 O(log n) 次（每次除以 2 至少减半），共 8 种因子
- 空间复杂度：O(log n)，最多 O(log n) 个因子（全为 2）

## 关键点总结

1. 只用 2-9 的因子分解 n（数字只有 1-9，1 不算有意义的因子）
2. 从 9 到 2 贪心分解：大因子用少的数字表示相同的积
3. 排序得到最小整数：小数在高位

## 易错点

1. n=1 时特殊处理，返回 "1"
2. 分解后若 n > 1，说明 n 有 > 9 的质因子，返回 "-1"
3. 排序是从小到大（升序），不是降序
