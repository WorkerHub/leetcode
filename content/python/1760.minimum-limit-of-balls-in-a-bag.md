## 题目描述

给你一个整数数组 `nums`，其中 `nums[i]` 表示第 `i` 个袋子里球的数目。同时给你一个整数 `maxOperations`。

你可以执行如下操作**至多** `maxOperations` 次：
- 选择任意一个袋子，并将袋子里的球分到 2 个新的袋子中，每个袋子里都有**正整数**个球。例如，一个装有 5 个球的袋子可以分成装有 1 个和 4 个球的袋子，或者装有 2 个和 3 个球的袋子。

你的开销是单个袋子里球数目的**最大值**，你想要**最小化**开销。

请你返回进行上述操作后的最小开销。

**示例 1：**
```
输入：nums = [9], maxOperations = 2
输出：3
解释：将装有 9 个球的袋子分成装有 3 个和 6 个球的袋子，再分成 3+3+3，开销为 3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= maxOperations <= 10^9`
- `1 <= nums[i] <= 10^9`

## 解题思路

二分答案：对开销（即最大球数上限）进行二分。

检验函数：对于给定上限 `limit`，将每个袋子 `nums[i]` 分割到不超过 `limit` 所需的操作数为 `ceil(nums[i] / limit) - 1 = (nums[i] - 1) // limit`。

若总操作数 <= `maxOperations`，则 `limit` 可行。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List
import math

class Solution:
    def minimumSize(self, nums: List[int], maxOperations: int) -> int:
        def can_achieve(limit: int) -> bool:
            """判断开销上限 limit 是否可行"""
            ops = 0
            for x in nums:
                # 将 x 分成若干个 <= limit 的袋子，需要 ceil(x/limit)-1 次操作
                ops += (x - 1) // limit
                if ops > maxOperations:
                    return False
            return True
        
        # 二分答案范围 [1, max(nums)]
        left, right = 1, max(nums)
        
        while left < right:
            mid = (left + right) // 2
            if can_achieve(mid):
                right = mid  # 尝试更小的上限
            else:
                left = mid + 1
        
        return left
```

### 方法二：使用 math.ceil

```python
from typing import List
import math

class Solution:
    def minimumSize(self, nums: List[int], maxOperations: int) -> int:
        def ops_needed(limit: int) -> int:
            return sum(math.ceil(x / limit) - 1 for x in nums)
        
        left, right = 1, max(nums)
        while left < right:
            mid = (left + right) // 2
            if ops_needed(mid) <= maxOperations:
                right = mid
            else:
                left = mid + 1
        
        return left
```

## 复杂度分析

- **时间复杂度**：O(n log(max_val))，二分 O(log(max_val))，每次检验 O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 二分答案（最大球数上限）
2. 检验函数：计算需要多少次操作将所有袋子分到不超过限制
3. `ceil(x/limit) - 1 = (x-1)//limit` 是关键公式

## 易错点

- 整除操作：`(x - 1) // limit` 等价于 `ceil(x / limit) - 1`
- 二分范围：左端 1，右端 `max(nums)`
