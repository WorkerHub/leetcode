## 题目描述

给你一个整数数组 `nums`，其中每个元素为 1、2 或 3。

一次操作中，你可以将数组中的任意元素替换为 1、2 或 3 中的任意值。

返回使 `nums` **非递减**（不包含下降）所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [2,1,3,2,1]
输出：3
解释：将第 1、3、4 个元素分别改成 2、2、2，得到 [2,2,2,2,2]
```

**示例 2：**
```
输入：nums = [1,3,2,1,3,3]
输出：2
解释：改第 2、3 个元素为 3，得到 [1,3,3,3,3,3]，或其他方案
```

**提示：**
- `1 <= nums.length <= 100`
- `nums[i]` 为 1、2 或 3

## 解题思路

最少操作次数 = n - (最长非递减子序列长度)

因为保留最长的非递减子序列，其余位置全部替换，操作次数最少。

**方法 1：LIS（最长非递减子序列）**
- 等价于找最长非递减子序列（LIS 的变体，允许相等）
- 由于只有 1, 2, 3 三种值，可以用 DP 直接求

**方法 2：DP**
- `dp[i][v]` = 以 `nums[i]` 结尾且最终值为 v（1, 2, 3）的最长非递减子序列长度
- 最终答案 = `max(dp[n-1][1..3])`

## Python 代码实现

### 方法一：LIS 变体（推荐）

```python
from typing import List
import bisect

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        # 找最长非递减子序列（允许相等）
        # 等价于 LIS（patience sorting）允许相等版本
        tails = []  # 记录各长度 LIS 的最小末尾值

        for x in nums:
            # 找第一个 > x 的位置（允许等于，用 bisect_right）
            pos = bisect.bisect_right(tails, x)
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x

        lis_len = len(tails)
        return len(nums) - lis_len
```

### 方法二：动态规划（直观）

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        # dp[v] = 以值 v 结尾的最长非递减子序列长度，v in {1, 2, 3}
        dp = [0, 0, 0]  # dp[0]=以1结尾, dp[1]=以2结尾, dp[2]=以3结尾

        for x in nums:
            v = x - 1  # 转换为 0-indexed
            # dp[v] = 1 + max(dp[0..v])
            best = max(dp[:v + 1])  # 以 <= x 结尾的最长子序列
            dp[v] = best + 1

        return n - max(dp)
```

### 方法三：简洁 DP

```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        # d[i] = 以值 i+1（1,2,3）结尾的最长非递减子序列长度
        d = [0, 0, 0]
        for x in nums:
            d[x-1] = max(d[:x]) + 1  # 取 <= x 的最大值 + 1
        return len(nums) - max(d)
```

## 复杂度分析

- 方法一：时间 O(n log n)，空间 O(n)
- 方法二/三：时间 O(n)（内层只有 3 个值，视为常数），空间 O(1)

## 关键点总结

1. 最少操作 = n - 最长非递减子序列长度
2. 因为值只有 1、2、3，DP 状态只有 3 个，时间 O(n)
3. `max(d[:x])` 取前 x 个状态的最大值（值 <= x 的最长子序列）

## 易错点

1. 非递减（允许相等）不是严格递增，LIS 用 `bisect_right`
2. 更新时 `d[x-1]` 依赖的是 `d[:x]`（不包括 `d[x-1]` 本身，避免同值多次使用）
3. 实际上同值多次使用是允许的（非递减），所以方法三的 `d[:x]` 包含 `d[x-1]` 也对，需验证
