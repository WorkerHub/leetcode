## 题目描述

一个序列的 宽度 定义为该序列中最大元素和最小元素的差值。

给你一个整数数组 nums ，返回 nums 的所有非空 子序列 的 宽度之和 。由于答案可能非常大，请返回对 10^9 + 7 取余 后的结果。

**提示：**
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^5

## 解题思路

**数学方法：**
1. 排序后，nums[i] 作为最大值的子序列有 2^i 个
2. nums[i] 作为最小值的子序列有 2^(n-1-i) 个
3. 贡献：nums[i] × (2^i - 2^(n-1-i))

## Python 代码实现

```python
class Solution:
    def sumSubseqWidths(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        nums.sort()
        n = len(nums)
        
        # 预计算 2 的幂
        pow2 = [1] * n
        for i in range(1, n):
            pow2[i] = (pow2[i-1] * 2) % MOD
        
        result = 0
        for i in range(n):
            # nums[i] 作为最大值的贡献 - 作为最小值的贡献
            result = (result + nums[i] * (pow2[i] - pow2[n-1-i])) % MOD
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)，存储2的幂

## 关键点总结

1. **排序**：简化最大最小值的计算
2. **数学推导**：每个元素的贡献
3. **预计算**：2的幂次避免重复计算
