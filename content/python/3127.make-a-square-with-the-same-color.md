## 题目描述

给你一个 `3 x 3` 的矩阵 `grid`，每个元素为 `'B'`（黑色）或 `'W'`（白色）。

在一次操作中，你可以将任意一个格子改变颜色。

如果你可以在 **一次或零次** 操作后，使 `grid` 中存在一个全为相同颜色的 `2 x 2` 子矩阵，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：grid = [["B","W","B"],["B","W","B"],["B","W","B"]]
输出：false
```

**示例 2：**
```
输入：grid = [["B","W","B"],["W","W","W"],["B","W","B"]]
输出：true
```

**提示：**
- `grid.length == grid[0].length == 3`

## 解题思路

枚举所有 4 个可能的 2x2 子矩阵（左上角坐标为 (0,0), (0,1), (1,0), (1,1)），对每个 2x2 子矩阵统计黑白数量，若某种颜色有至少 3 个（即最多改 1 个格子就能全同色），则返回 true。

## Python 代码实现

### 方法一：枚举 2x2 子矩阵（推荐）

```python
from typing import List

class Solution:
    def canMakeSquare(self, grid: List[List[str]]) -> bool:
        for r in range(2):
            for c in range(2):
                # 统计 2x2 子矩阵的颜色分布
                cells = [
                    grid[r][c], grid[r][c+1],
                    grid[r+1][c], grid[r+1][c+1]
                ]
                b = cells.count('B')
                w = cells.count('W')
                # 最多改 1 个格子，即至少 3 个同色
                if b >= 3 or w >= 3:
                    return True
        return False
```

### 方法二：更简洁

```python
from typing import List

class Solution:
    def canMakeSquare(self, grid: List[List[str]]) -> bool:
        for i in range(2):
            for j in range(2):
                s = grid[i][j] + grid[i][j+1] + grid[i+1][j] + grid[i+1][j+1]
                if s.count('B') >= 3 or s.count('W') >= 3:
                    return True
        return False
```

## 复杂度分析

- 时间复杂度：O(1)，矩阵大小固定为 3x3
- 空间复杂度：O(1)

## 关键点总结

1. 3x3 矩阵中 2x2 子矩阵只有 4 个
2. 一次操作可以改变 1 个格子，因此 4 个格子中有 3 个同色即可
3. 完全枚举即可

## 易错点

1. 是 >= 3 而不是 == 4（已经全同色也满足，可以 0 次操作）
2. 只有 4 个 2x2 子矩阵，不要遗漏
