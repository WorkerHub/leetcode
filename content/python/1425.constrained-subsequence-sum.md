## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回 **非空** 子序列元素和的最大值，子序列需满足：子序列中每两个 **相邻** 的整数 `nums[i]` 和 `nums[j]`，它们在原数组中的下标 `i` 和 `j` 满足 `i < j` 且 `j - i <= k`。

数组的子序列定义为：将数组中的若干元素去掉后（可以不去掉，但是不能改变剩余元素的顺序），所得到的结果。

**示例 1：**

```
输入：nums = [10,2,-10,5,20], k = 2
输出：37
解释：子序列为 [10, 2, 5, 20]（下标 0,1,3,4，相邻元素下标差均 <= 2）
```

**示例 2：**

```
输入：nums = [-1,-2,-3], k = 1
输出：-1
解释：子序列只能取一个元素，取最大值 -1。
```

**示例 3：**

```
输入：nums = [10,-2,-10,-5,20], k = 2
输出：23
解释：子序列为 [10, -2, -5, 20]
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

### 动态规划 + 单调双端队列

**DP 定义：** `dp[i]` = 以 `nums[i]` 结尾的满足约束的子序列的最大和。

**转移方程：**

```
dp[i] = nums[i] + max(0, max(dp[i-k], dp[i-k+1], ..., dp[i-1]))
```

解释：
- `nums[i]` 必选（以它结尾）
- 前一个元素可以不选（最大值取 0）或在下标 `[i-k, i-1]` 中选一个最大的 `dp[j]`
- 取 `max(0, max(dp[i-k..i-1]))` 是因为如果所有前驱都是负数，不如只取 `nums[i]` 本身

**问题转化：** 需要维护一个长度为 `k` 的窗口内的最大值，经典的单调双端队列（滑动窗口最大值）问题。

**单调队列维护：**

用双端队列 `dq` 存储下标，保持 `dp[dq[0]] >= dp[dq[1]] >= ...`（队首最大）：
- 新元素 `dp[i]` 入队前，从队尾弹出所有 `dp[dq[-1]] <= dp[i]` 的元素
- 从队首弹出所有下标 `< i - k` 的元素（超出窗口）

**最终答案：** `max(dp)`

### 为什么不是普通堆？

堆（优先队列）每次操作 O(log n)，而单调队列是 O(1) 均摊，性能更好。

## Python 代码实现

### 方法一：DP + 单调双端队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def constrainedSubsetSum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        # 单调双端队列：存储下标，队首对应最大 dp 值
        dq = deque()

        for i in range(n):
            # 队首元素已超出窗口 [i-k, i-1]，弹出
            while dq and dq[0] < i - k:
                dq.popleft()

            # 当前 dp[i] = nums[i] + max(0, 窗口内最大 dp 值)
            # 若队列不空，队首即为窗口内最大 dp 值
            dp[i] = nums[i] + (max(0, dp[dq[0]]) if dq else 0)

            # 维护单调性：从队尾弹出所有 dp 值 <= dp[i] 的元素
            while dq and dp[dq[-1]] <= dp[i]:
                dq.pop()

            dq.append(i)

        return max(dp)
```

### 方法二：DP + 最大堆

```python
from typing import List
import heapq

class Solution:
    def constrainedSubsetSum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        # 最大堆：存储 (-dp[j], j)（Python 的 heapq 是最小堆，用负值模拟最大堆）
        heap = []

        for i in range(n):
            # 惰性删除：弹出所有超出窗口的元素
            while heap and heap[0][1] < i - k:
                heapq.heappop(heap)

            # 当前最大 dp 值
            max_prev = -heap[0][0] if heap else 0
            dp[i] = nums[i] + max(0, max_prev)

            heapq.heappush(heap, (-dp[i], i))

        return max(dp)
```

**注意：** 堆的惰性删除可能不准确（堆顶可能是已过期元素但尚未被弹出的内部元素）。需要在使用堆顶之前先清理过期元素。上面代码已处理。

### 方法三：O(nk) 暴力 DP（理解思路，会超时）

```python
from typing import List

class Solution:
    def constrainedSubsetSum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = nums[:]  # 至少取 nums[i] 本身

        for i in range(n):
            # 查找前 k 个位置中的最大 dp 值
            for j in range(max(0, i - k), i):
                dp[i] = max(dp[i], dp[j] + nums[i])

        return max(dp)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单调双端队列 | O(n) | O(n) |
| 最大堆 | O(n log n) | O(n) |
| 暴力 DP | O(nk) | O(n) |

单调双端队列是最优解，每个元素最多入队和出队一次，均摊 O(1)。

## 图解示例

以 `nums = [10, 2, -10, 5, 20], k = 2` 为例：

```
i=0: dq=[], dp[0] = 10+0 = 10, dq=[0]
i=1: 队首0未过期, dp[1] = 2+max(0,10)=12, 12>10 所以弹出0, dq=[1]
i=2: 队首1未过期, dp[2] = -10+max(0,12)=2, 2<12 直接加入, dq=[1,2]
i=3: 队首1未过期（3-2=1，1>=1）, dp[3]=5+max(0,12)=17, 弹出2（dp[2]=2<=17）,弹出1（dp[1]=12<=17）, dq=[3]
i=4: 队首3未过期（4-2=2，3>=2）, dp[4]=20+max(0,17)=37, 弹出3（17<=37）, dq=[4]

dp = [10, 12, 2, 17, 37]
max(dp) = 37 ✓
```

## 关键点总结

1. `dp[i] = nums[i] + max(0, 窗口[i-k, i-1]内的最大dp值)`
2. 取 max(0,...) 是允许子序列从 nums[i] 重新开始（不继承负数前缀）
3. 单调双端队列维护窗口最大值：队首最大，队尾最小，从队尾弹出不够大的元素
4. 双端队列从队首弹出超出窗口的元素，从队尾维护单调性

## 易错点

1. 新元素入队前，先处理队首（弹出过期元素），再用队首值更新 dp[i]，最后入队
2. 入队条件：弹出队尾所有 `dp[dq[-1]] <= dp[i]` 的元素（等号也弹出，维护严格递减）
3. `dp[i]` 的初始值是 `nums[i]`（非空子序列，至少包含自身）
