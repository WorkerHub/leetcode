## 题目描述

给你一个二进制字符串 `s`，如果一个子字符串中 `'1'` 的数量**大于等于** `'0'` 数量的**平方**，则称该子字符串为**主导子串**。

返回 `s` 中主导子串的数量。

**示例 1：**
```
输入：s = "00011"
输出：5
```

**示例 2：**
```
输入：s = "101101"
输出：16
```

**提示：**
- `1 <= s.length <= 4 * 10^4`

## 解题思路

枚举 0 的个数 `z`（0 到 sqrt(n)），对每个 `z`：
- 找出所有恰好包含 `z` 个 0 的子串，且其中 1 的数量 >= z^2
- 利用前缀和快速计算

由于 `z` 最多约 200（sqrt(4*10^4) ≈ 200），总时间 O(n * sqrt(n))。

对于 z=0 的情况（全 1 子串），直接统计连续 1 的段。

## Python 代码实现

### 方法一：枚举 0 的个数（推荐）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        # 预处理 0 的位置
        zeros = [-1]  # 哨兵
        for i, c in enumerate(s):
            if c == '0':
                zeros.append(i)
        zeros.append(n)  # 哨兵
        
        ans = 0
        
        # 枚举子串中 0 的个数 z
        # z = 0：子串全是 1
        # 统计每段连续 1 的数量 k，贡献 k*(k+1)//2
        cnt1 = 0
        for c in s:
            if c == '1':
                cnt1 += 1
                ans += cnt1  # 以当前位结尾的全 1 子串数
            else:
                cnt1 = 0
        
        # z >= 1：枚举子串中有 z 个 0
        # zeros 存储所有 0 的位置（不含哨兵）
        zero_pos = [i for i, c in enumerate(s) if c == '0']
        m = len(zero_pos)
        
        # 前缀 1 的数量
        ones = [0] * (n + 1)
        for i in range(n):
            ones[i + 1] = ones[i] + (1 if s[i] == '1' else 0)
        
        def count_ones(l, r):
            # 区间 [l, r] 中 1 的数量
            return ones[r + 1] - ones[l]
        
        for z in range(1, m + 1):
            if z * z > n:
                break
            # 枚举子串恰好包含 z 个 0
            # z 个 0 的范围：[zero_pos[i], zero_pos[i+z-1]] 为第 i 组
            for i in range(m - z + 1):
                left_zero = zero_pos[i]
                right_zero = zero_pos[i + z - 1]
                
                # 子串左端范围：(zero_pos[i-1], left_zero]（如果 i>0 则排除前一个0）
                left_min = zero_pos[i - 1] + 1 if i > 0 else 0
                # 子串右端范围：[right_zero, zero_pos[i+z] - 1]（如果后面有0则不包含）
                right_max = zero_pos[i + z] - 1 if i + z < m else n - 1
                
                # 需要：1 的数量 >= z^2
                # 1 的数量 = 右端 - 左端 + 1 - z
                # 需要右端 - 左端 + 1 - z >= z^2
                # 右端 - 左端 >= z^2 + z - 1
                
                # 左端从 left_min 到 left_zero，右端从 right_zero 到 right_max
                # 对于固定左端 l，最小右端 r_min 满足 r - l >= z^2 + z - 1
                # r_min = max(right_zero, l + z^2 + z - 1)
                
                need = z * z + z - 1  # 需要 r - l >= need
                
                for l in range(left_min, left_zero + 1):
                    r_min = max(right_zero, l + need)
                    if r_min > right_max:
                        continue
                    ans += right_max - r_min + 1
        
        return ans
```

### 方法二：简化暴力（小数据）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        ans = 0
        for i in range(n):
            ones = 0
            zeros = 0
            for j in range(i, n):
                if s[j] == '1':
                    ones += 1
                else:
                    zeros += 1
                if ones >= zeros * zeros:
                    ans += 1
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n * sqrt(n))，空间复杂度 O(n)
- 方法二：时间复杂度 O(n^2)，仅适合小数据

## 关键点总结

1. 枚举 0 的数量 z（最多 sqrt(n) 种有意义的 z）
2. 对每个 z，枚举包含恰好 z 个 0 的子串组
3. 用前缀和快速统计满足条件的右端点数量

## 易错点

1. z=0 需要单独处理（全 1 子串）
2. 内层循环中边界计算需要仔细
