## 题目描述

街道用字符串 `hamsters` 表示，`H` 表示仓鼠，`.` 表示空格。每个水桶放在空格处，可以喂相邻（左右）的仓鼠。

每只仓鼠至少需要一个专用水桶（一个桶只能喂一只仓鼠）。

返回喂饱所有仓鼠所需的**最少水桶数**。如果无法喂饱所有仓鼠，返回 `-1`。

**示例 1：**
```
输入：hamsters = "H..H"
输出：2
解释：在索引 1 和 2 分别放一个桶
```

**示例 2：**
```
输入：hamsters = "HHH"
输出：-1
解释：中间的 H 两侧都是 H，无法放桶
```

**提示：**
- `1 <= hamsters.length <= 10^5`

## 解题思路

**贪心：** 从左到右遍历，对每只仓鼠：

1. 优先在其**右侧**放桶（因为右侧的桶可能还能帮助下一只仓鼠）
2. 如果右侧不能放（越界或是 `H`），尝试左侧
3. 如果两侧都不能放，返回 `-1`
4. 放桶后，跳过被该桶覆盖的位置

**关键：** 贪心地优先选右侧，使一个桶尽可能服务更多仓鼠。

## 代码实现

### 方法一：贪心右优先（推荐）

```python
class Solution:
    def minimumBuckets(self, hamsters: str) -> int:
        s = list(hamsters)
        n = len(s)
        ans = 0

        for i in range(n):
            if s[i] == 'H':
                if i + 1 < n and s[i + 1] == '.':
                    # 优先在右侧放桶，标记已使用
                    s[i + 1] = '#'
                    ans += 1
                elif i - 1 >= 0 and s[i - 1] == '.':
                    # 右侧不行，尝试左侧
                    s[i - 1] = '#'
                    ans += 1
                else:
                    # 两侧都无法放桶
                    return -1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(n)，将字符串转为列表方便修改

## 关键点总结

1. 贪心策略：优先在仓鼠右侧放桶，使桶尽可能服务更多仓鼠
2. 使用标记（`#`）记录已放桶的位置
3. 无法放桶（两侧都不是 `.`）时直接返回 -1

## 易错点

- 优先选右侧而不是左侧：如果优先选左侧，遇到 `H.H` 时会放两个桶（各用左侧），而右优先只需一个桶
- 放桶后的位置要标记，防止被下一只仓鼠重复使用
