## 题目描述

有 `n` 个人排队买票，第 `i` 个人想买 `tickets[i]` 张票。每轮每人最多买 1 张票（从队首开始），如果还需要买票就回到队尾，否则离队。

返回下标为 `k` 的人买完票所需的**秒数**（每次买票花 1 秒）。

**示例 1：**
```
输入：tickets = [2,3,2], k = 2
输出：6
解释：队列模拟：[2,3,2]->[1,3,2]->[1,2,2]->[1,2,1]->[0,2,1]->[0,1,1]->[买完返回]
实际到 k=2 时花了 6 秒
```

**提示：**
- `n == tickets.length`
- `1 <= n <= 100`
- `1 <= tickets[i] <= 100`
- `0 <= k < n`

## 解题思路

**数学方法（推荐）：** 不需要模拟，直接计算。

第 `k` 个人需要买 `tickets[k]` 轮，对于其他人：
- 在 k 之前的人（下标 `i < k`）：在第 k 个人买完前，每人最多买 `tickets[k]` 张
- 在 k 之后的人（下标 `i > k`）：每人最多买 `tickets[k] - 1` 张（在第 k 个人买完最后一张之前）

**总时间** = `sum(min(tickets[i], tickets[k]) for i <= k)` + `sum(min(tickets[i], tickets[k]-1) for i > k)`

## 代码实现

### 方法一：数学公式（推荐）

```python
from typing import List

class Solution:
    def timeRequiredToBuy(self, tickets: List[int], k: int) -> int:
        n = len(tickets)
        target = tickets[k]
        total = 0

        for i in range(n):
            if i <= k:
                total += min(tickets[i], target)
            else:
                total += min(tickets[i], target - 1)

        return total
```

### 方法二：队列模拟

```python
from typing import List
from collections import deque

class Solution:
    def timeRequiredToBuy(self, tickets: List[int], k: int) -> int:
        queue = deque(range(len(tickets)))
        time = 0

        while True:
            idx = queue.popleft()
            tickets[idx] -= 1
            time += 1

            if idx == k and tickets[idx] == 0:
                return time

            if tickets[idx] > 0:
                queue.append(idx)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学公式 | O(n) | O(1) |
| 模拟 | O(n * max_tickets) | O(n) |

## 关键点总结

1. 数学方法：k 之前的人最多买 `tickets[k]` 张，k 之后的人最多买 `tickets[k]-1` 张
2. 使用 `min` 防止超过实际需求量
3. k 本身买满 `tickets[k]` 张

## 易错点

- k 之后的人（下标 > k）是 `tickets[k] - 1`，因为第 k 个人在轮到队尾的人之前就买完了
- 数组下标 `i <= k`（包含 k 本身）用 `tickets[k]`
