## 题目描述

在 NBA 季后赛中，我们总是安排较强的队伍对战较弱的队伍，如 1 号队伍对战 n 号队伍，2 号队伍对战 n-1 号队伍。

请根据给定的正整数 n，输出所有的比赛对阵。每轮比赛后，获胜的队伍将进入下一轮，直到产生最终的冠军。

请以字符串的形式返回最终的对阵结果。

**示例 1：**
```
输入：n = 4
输出："((1,4),(2,3))"
解释：
第一轮：(1,4),(2,3)
第二轮：((1,4),(2,3))
```

**示例 2：**
```
输入：n = 8
输出："(((1,8),(4,5)),((2,7),(3,6)))"
解释：
第一轮：(1,8),(2,7),(3,6),(4,5)
第二轮：((1,8),(4,5)),((2,7),(3,6))
第三轮：(((1,8),(4,5)),((2,7),(3,6)))
```

**提示：**
- n 是 2 的幂次方，范围在 [2, 2^12] 之间

## 解题思路

这是一个模拟淘汰赛对阵的问题，关键在于理解配对规则和递归结构。

**核心思想：**
1. 每轮比赛都是最强对最弱：第 i 名对战第 n-i+1 名
2. 使用列表存储当前轮次的所有队伍
3. 每轮比赛后，队伍数量减半
4. 重复配对直到只剩一支队伍

**算法流程：**
1. 初始化：将所有队伍编号存入列表
2. 模拟每轮比赛：
   - 最强和最弱配对
   - 将配对结果存入新列表
3. 重复直到只剩一个元素

## Python 代码实现

### 方法一：迭代模拟（推荐）

```python
class Solution:
    def findContestMatch(self, n: int) -> str:
        # 初始化队伍列表，每支队伍用字符串表示
        teams = [str(i) for i in range(1, n + 1)]
        
        # 每轮比赛，队伍数量减半
        while len(teams) > 1:
            next_round = []
            # 最强和最弱配对
            for i in range(len(teams) // 2):
                # 第i强的队伍对战第i弱的队伍
                match = f"({teams[i]},{teams[len(teams) - 1 - i]})"
                next_round.append(match)
            teams = next_round
        
        # 返回最终结果
        return teams[0]
```

### 方法二：递归实现

```python
class Solution:
    def findContestMatch(self, n: int) -> str:
        # 初始化队伍列表
        teams = [str(i) for i in range(1, n + 1)]
        return self.simulate(teams)
    
    def simulate(self, teams: list) -> str:
        # 递归终止条件：只剩一支队伍
        if len(teams) == 1:
            return teams[0]
        
        # 本轮配对
        next_round = []
        for i in range(len(teams) // 2):
            match = f"({teams[i]},{teams[len(teams) - 1 - i]})"
            next_round.append(match)
        
        # 递归处理下一轮
        return self.simulate(next_round)
```

### 方法三：简洁版本

```python
class Solution:
    def findContestMatch(self, n: int) -> str:
        # 初始化
        teams = list(map(str, range(1, n + 1)))
        
        # 模拟每轮比赛
        while len(teams) > 1:
            teams = [f"({teams[i]},{teams[-1-i]})" 
                     for i in range(len(teams) // 2)]
        
        return teams[0]
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n log n)
  - 共有 log n 轮比赛
  - 每轮需要处理 O(n) 个字符
- 空间复杂度：O(n)
  - 需要存储队伍列表
  - 字符串拼接会产生额外空间

## 图解示例

以 n = 8 为例：

```
初始：[1, 2, 3, 4, 5, 6, 7, 8]

第一轮配对：
1 vs 8 → (1,8)
2 vs 7 → (2,7)
3 vs 6 → (3,6)
4 vs 5 → (4,5)
结果：[(1,8), (2,7), (3,6), (4,5)]

第二轮配对：
(1,8) vs (4,5) → ((1,8),(4,5))
(2,7) vs (3,6) → ((2,7),(3,6))
结果：[((1,8),(4,5)), ((2,7),(3,6))]

第三轮配对：
((1,8),(4,5)) vs ((2,7),(3,6))
结果：(((1,8),(4,5)),((2,7),(3,6)))
```

## 关键点总结

1. 理解淘汰赛的配对规则：最强对最弱
2. 使用列表存储每轮的比赛结果
3. 每轮比赛后队伍数量减半
4. 字符串拼接要注意括号的使用
5. 循环终止条件是只剩一支队伍

## 易错点

1. 配对索引错误，没有正确实现最强对最弱
2. 忘记更新队伍列表，导致死循环
3. 括号格式错误，没有正确嵌套
4. 初始化时索引从0开始而不是1
