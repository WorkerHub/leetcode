## 题目描述

给你一个由**不重复**正整数组成的数组 `nums`，另给你一个二维整数数组 `operations`，`operations[i] = [original, replaced]` 表示将 `nums` 中出现的 `original` 替换为 `replaced`。

按顺序执行所有操作，保证每次操作执行时 `original` 存在于 `nums` 中，且 `replaced` 不存在于 `nums` 中（操作前）。

返回所有操作执行完后的数组。

**示例 1：**
```
输入：nums = [1,2,4,6], operations = [[1,3],[4,7],[6,19]]
输出：[3,2,7,19]
```

**示例 2：**
```
输入：nums = [1,2], operations = [[1,3],[2,1],[3,2]]
输出：[2,1]
```

## 解题思路

**哈希表记录值到下标的映射：**

直接在 `nums` 上模拟替换效率低（每次都要搜索 O(n)）。

用哈希表 `pos` 记录每个值对应的下标，替换时：
1. 查 `pos[original]` 得到下标 `i`。
2. `nums[i] = replaced`。
3. 更新 `pos`：删除 `original`，添加 `pos[replaced] = i`。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class Solution:
    def arrayChange(self, nums: List[int], operations: List[List[int]]) -> List[int]:
        # 建立 值 -> 下标 的映射
        pos = {v: i for i, v in enumerate(nums)}

        for original, replaced in operations:
            idx = pos[original]
            nums[idx] = replaced
            del pos[original]
            pos[replaced] = idx

        return nums
```

### 方法二：直接哈希映射（不修改数组）

```python
from typing import List

class Solution:
    def arrayChange(self, nums: List[int], operations: List[List[int]]) -> List[int]:
        # 跟踪每个初始值最终被替换为什么
        mapping = {}
        for original, replaced in reversed(operations):
            # 反向处理：确定每个 original 最终的替换结果
            mapping[original] = mapping.get(replaced, replaced)

        return [mapping.get(v, v) for v in nums]
```

## 复杂度分析

- 时间复杂度：O(n + q)，建表 O(n)，每次操作 O(1)。
- 空间复杂度：O(n)，哈希表大小。

## 关键点总结

1. 哈希表 `pos` 维护 值 -> 下标 映射，O(1) 查找替换位置。
2. 每次替换后及时更新哈希表：删旧键，加新键。
3. 方法二反向映射：每个初始值最终被替换为什么，用 O(q) 预处理后 O(n) 应用。

## 易错点

- 不能直接在数组上线性搜索（O(n) per operation，总体 O(nq)），数据量大时超时。
- 方法二反向处理时，`mapping[original] = mapping.get(replaced, replaced)`：若 `replaced` 还会被替换，则跟踪链式替换。
