## 题目描述

`n` 个机器人在 1D 轨道上移动，给你数组 `positions`（位置）、`healths`（血量）和字符串 `directions`（方向 'L'/'R'）。

机器人向指定方向以同样速度移动，当两个机器人相撞（一个向右，另一个向左）时，血量较少的机器人消失，血量较多的血量减 1（血量相同则两个都消失）。

返回所有碰撞结束后，按初始下标排序的幸存机器人血量数组。

**示例：**
```
输入：positions=[5,4,3,2,1], healths=[2,17,9,15,10], directions="RRRRR"
输出：[2,17,9,15,10]（同方向不碰撞）
```

**提示：**
- `1 <= n <= 10^5`

## 解题思路

**栈模拟**：

1. 按位置排序处理机器人
2. 用栈维护当前向右行进的机器人
3. 遇到向左的机器人，与栈顶（向右）碰撞：
   - 栈顶血量更大：栈顶血量减 1，当前机器人消失
   - 栈顶血量更小：栈顶消失，当前机器人继续与新栈顶碰撞
   - 血量相等：两个都消失

## Python 代码实现

### 方法一：栈模拟（推荐）

```python
from typing import List

class Solution:
    def survivedRobotsHealths(self, positions: List[int], healths: List[int], directions: str) -> List[int]:
        n = len(positions)
        # 按位置排序，记录原始下标
        robots = sorted(range(n), key=lambda i: positions[i])

        stack = []  # 存放向右移动机器人的原始下标
        result = {}  # 幸存机器人：下标 -> 血量

        for i in robots:
            if directions[i] == 'R':
                stack.append(i)
            else:
                # 当前向左，与栈中向右的碰撞
                h = healths[i]
                while stack and h > 0:
                    top = stack[-1]
                    if healths[top] > h:
                        # 栈顶胜，血量减 1
                        healths[top] -= 1
                        h = 0
                    elif healths[top] < h:
                        # 当前机器人胜，栈顶消失
                        stack.pop()
                        h -= 1
                    else:
                        # 同归于尽
                        stack.pop()
                        h = 0
                if h > 0:
                    # 当前向左机器人幸存
                    result[i] = h

        # 向右未碰撞的机器人
        for i in stack:
            result[i] = healths[i]

        # 按原始下标顺序返回
        return [result[i] for i in range(n) if i in result]
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(n)

## 关键点总结

1. 按位置排序后才能正确模拟碰撞
2. 栈维护向右移动的机器人，向左的机器人与栈顶碰撞
3. 注意 healths 数组的修改（需要原地更新）

## 易错点

1. 碰撞后需继续检查（while 循环），直到栈为空或当前机器人消亡
2. 最终栈中剩余（向右）和未入栈的向左幸存者都要输出
