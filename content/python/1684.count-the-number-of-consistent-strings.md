## 题目描述

给你一个由不同字符组成的字符串 `allowed` 和一个字符串数组 `words`。如果一个字符串的每一个字符都在 `allowed` 中，就称这个字符串是**一致字符串**。

请你返回 `words` 数组中**一致字符串**的数目。

**示例 1：**
```
输入：allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
输出：2
解释：字符串 "aaab" 和 "baa" 是一致字符串，因为它们只包含字符 'a' 和 'b'
```

**示例 2：**
```
输入：allowed = "abc", words = ["a","b","c","ab","ac","bc","abc"]
输出：7
解释：所有字符串都是一致的
```

**提示：**
- `1 <= words.length <= 10^4`
- `1 <= allowed.length <= 26`
- `1 <= words[i].length <= 10`
- `allowed` 中的字符**互不相同**
- `words[i]` 和 `allowed` 只包含小写英文字母

## 解题思路

判断一个字符串的所有字符是否都在 `allowed` 中，有两种主要方法：

**方法一：哈希集合**
将 `allowed` 的字符放入集合，遍历每个单词的每个字符，检查是否都在集合中。

**方法二：位运算**
将 `allowed` 编码为一个 32 位整数（每个字母对应一个二进制位），对每个单词也做相同编码，用按位与检查是否是子集。

## 代码实现

### 方法一：哈希集合（推荐，直观）

```python
from typing import List

class Solution:
    def countConsistentStrings(self, allowed: str, words: List[str]) -> int:
        # 将 allowed 转为集合，O(1) 查找
        allowed_set = set(allowed)
        count = 0
        for word in words:
            # 检查单词的每个字符是否都在 allowed 中
            if all(c in allowed_set for c in word):
                count += 1
        return count
```

### 方法二：位运算

```python
from typing import List

class Solution:
    def countConsistentStrings(self, allowed: str, words: List[str]) -> int:
        # 将 allowed 编码为位掩码
        allowed_mask = 0
        for c in allowed:
            allowed_mask |= (1 << (ord(c) - ord('a')))

        count = 0
        for word in words:
            # 将单词编码为位掩码
            word_mask = 0
            for c in word:
                word_mask |= (1 << (ord(c) - ord('a')))
            # 如果 word_mask 是 allowed_mask 的子集，则该单词一致
            # 子集关系：(word_mask & allowed_mask) == word_mask
            if (word_mask & allowed_mask) == word_mask:
                count += 1

        return count
```

### 方法三：Python 简洁写法

```python
from typing import List

class Solution:
    def countConsistentStrings(self, allowed: str, words: List[str]) -> int:
        allowed_set = set(allowed)
        # 使用 issubset 或集合运算
        return sum(set(word).issubset(allowed_set) for word in words)
```

## 复杂度分析

**方法一（哈希集合）：**
- 时间复杂度：O(n * m)，n 为 words 数量，m 为单词平均长度
- 空间复杂度：O(|allowed|)，集合大小

**方法二（位运算）：**
- 时间复杂度：O(n * m)，同上
- 空间复杂度：O(1)，只用整数存储

## 关键点总结

1. 哈希集合方法直观，时间复杂度相同，推荐用于面试
2. 位运算方法常数因子更小，实际速度更快
3. 子集关系判断：`(A & B) == A` 说明 A 是 B 的子集（A 的所有位都包含在 B 中）
4. Python 中 `set.issubset()` 是最简洁的写法

## 易错点

1. 位运算中注意 `(word_mask & allowed_mask) == word_mask`，不是等于 `allowed_mask`
2. 字符到位下标的转换：`ord(c) - ord('a')`，得到 0-25 的索引
