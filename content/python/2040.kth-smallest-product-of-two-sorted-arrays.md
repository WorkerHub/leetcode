## 题目描述

给你两个**从小到大排序**的整数数组 `nums1` 和 `nums2`，以及一个整数 `k`。

从两个数组各选一个元素组成乘积，返回第 `k` 小的乘积。

**示例 1：**
```
输入：nums1 = [2,5], nums2 = [3,4], k = 2
输出：8
解释：所有乘积：[6,8,10,15]，第2小为 8
```

**示例 2：**
```
输入：nums1 = [-4,-2,0,3], nums2 = [2,4], k = 6
输出：0
```

**提示：**
- `1 <= nums1.length, nums2.length <= 5 * 10^4`
- `-10^5 <= nums1[i], nums2[i] <= 10^5`
- `1 <= k <= nums1.length * nums2.length`

## 解题思路

**二分答案：** 二分查找乘积值 `x`，统计小于等于 `x` 的乘积对数，找到使该数量 >= k 的最小 `x`。

**统计 `nums1[i] * nums2[j] <= x` 的对数：**
- 对于正数 `nums1[i] > 0`：`nums2[j] <= x / nums1[i]`，二分查找 `nums2` 中 <= `x/nums1[i]` 的个数
- 对于负数 `nums1[i] < 0`：乘以负数不等号反向，`nums2[j] >= x / nums1[i]`
- 对于 `nums1[i] == 0`：乘积为 0，若 `x >= 0` 则全部满足（m 对），否则 0 对

## 代码实现

### 方法一：二分答案 + 分类讨论（推荐）

```python
from typing import List
import bisect

class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        m, n = len(nums1), len(nums2)

        def count_le(x: int) -> int:
            # 统计 nums1[i] * nums2[j] <= x 的对数
            total = 0
            for a in nums1:
                if a > 0:
                    # nums2[j] <= x / a，二分查找 <= floor(x/a) 的个数
                    # 使用 x // a 有精度问题，改用 x / a 的 bisect_right
                    # 实际比较：a * b <= x => b <= x / a
                    # 注意整数除法问题
                    total += bisect.bisect_right(nums2, x // a) if x >= 0 else bisect.bisect_left(nums2, -((-x - 1) // a + 1))
                elif a < 0:
                    # nums2[j] >= x / a（注意不等号反向），二分查找 >= ceil(x/a) 的个数
                    total += n - bisect.bisect_left(nums2, -((-x) // (-a)))
                else:
                    # a == 0，乘积为 0
                    if x >= 0:
                        total += n
            return total

        # 更简洁的实现，使用浮点数比较有风险，改用精确整数计算
        def count_le_v2(mid: int) -> int:
            cnt = 0
            for a in nums1:
                if a > 0:
                    # a * b <= mid <=> b <= mid / a
                    # 使用 Python 的整数除法（向下取整）
                    # 但当 mid 为负时需要注意
                    if mid >= 0:
                        cnt += bisect.bisect_right(nums2, mid // a)
                    else:
                        # mid < 0, a > 0: b <= mid/a < 0
                        # 等价于 b <= -((-mid + a - 1) // a) = -(ceil(-mid/a))
                        cnt += bisect.bisect_right(nums2, -((-mid + a - 1) // a))
                elif a < 0:
                    if mid >= 0:
                        # a < 0, mid >= 0: b >= mid/a（负数），即 b >= ceil(mid/a)
                        # mid/a <= 0，b >= 负数等价于 b >= ceil(mid/a)
                        # ceil(mid/a) = -(-mid // (-a)) when a < 0
                        cnt += n - bisect.bisect_left(nums2, -(mid // (-a)))
                    else:
                        # a < 0, mid < 0: a * b <= mid, b >= mid/a > 0
                        cnt += n - bisect.bisect_left(nums2, (-mid + (-a) - 1) // (-a))
                else:
                    if mid >= 0:
                        cnt += n
            return cnt

        # 二分答案范围
        lo, hi = -10**10, 10**10
        while lo < hi:
            mid = (lo + hi) // 2
            if count_le_v2(mid) >= k:
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：简化版二分（用浮点数辅助）

```python
from typing import List
import bisect

class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        n2 = len(nums2)

        def count(x: int) -> int:
            cnt = 0
            for a in nums1:
                if a == 0:
                    if x >= 0:
                        cnt += n2
                elif a > 0:
                    # a * b <= x => b <= x/a
                    cnt += bisect.bisect_right(nums2, x // a) if x >= 0 else n2 - bisect.bisect_left(nums2, (x - a + 1) // a)
                else:
                    # a < 0: a * b <= x => b >= x/a (不等号翻转)
                    if x < 0:
                        # x/a > 0（负/负=正），取上整
                        threshold = -((-x) // (-a))
                        cnt += n2 - bisect.bisect_left(nums2, threshold)
                    else:
                        # x >= 0, a < 0: x/a <= 0，取上整（向0方向）
                        threshold = -(x // (-a))
                        cnt += n2 - bisect.bisect_left(nums2, threshold)
            return cnt

        lo, hi = int(-1e10), int(1e10)
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 复杂度分析

- 时间复杂度：O((m + n) * log(V))，V 为值域范围（约 10^10）
- 空间复杂度：O(1)

## 关键点总结

1. 二分乘积值 `x`，统计 ≤ x 的乘积对数
2. 分正负零三种情况讨论（乘法不等号在乘以负数时翻转）
3. 整数除法向下取整的特性：负数除法需要特别处理

## 易错点

- 负数的整数除法不同于数学除法（Python 向下取整，C++ 向零取整）
- 二分范围要足够大：最小乘积约 `-10^10`，最大约 `10^10`
- 对 `a == 0` 单独处理
