## 题目描述

一个机器人在 `width x height` 的网格上行走（坐标从 `(0,0)` 到 `(width-1, height-1)`）。机器人初始在 `(0,0)` 朝向东（右）。

实现 `Robot` 类：
- `Robot(width, height)`：初始化机器人
- `step(num)`：机器人向前走 `num` 步（碰到边界右转 90 度）
- `getPos()`：返回当前位置 `[x, y]`
- `getDir()`：返回当前方向（`"North"`, `"East"`, `"South"`, `"West"`）

**示例：**
```
输入：["Robot","step","step","getPos","getDir","step","step","step","getDir"]
     [[6,3],[2],[2],[],[],[2],[1],[4],[]]
输出：[null,null,null,[4,0],"East",null,null,null,"South"]
```

**提示：**
- `2 <= width, height <= 100`
- `1 <= num <= 10^5`
- `step`, `getPos`, `getDir` 调用次数不超过 `10^4`

## 解题思路

网格外周长为 `2*(width+height-2)`，走完一圈回到原位。

**关键：** 记录当前在边界上的位置（按顺时针从 `(0,0)` 出发的步数），避免模拟每一步。

边界路径（顺时针）：
1. 底边向东：`(0,0)` 到 `(width-1,0)`，共 `width-1` 步
2. 右边向北：`(width-1,0)` 到 `(width-1,height-1)`，共 `height-1` 步
3. 顶边向西：`(width-1,height-1)` 到 `(0,height-1)`，共 `width-1` 步
4. 左边向南：`(0,height-1)` 到 `(0,0)`，共 `height-1` 步

## 代码实现

### 方法一：周长取模（推荐）

```python
class Robot:

    def __init__(self, width: int, height: int):
        self.w = width
        self.h = height
        self.perimeter = 2 * (width + height - 2)
        self.pos = 0  # 在边界路径上的位置（按顺时针步数）
        self.at_origin = True  # 是否还在起点（未移动过）

        # 预计算边界上每个位置的坐标和方向
        # 路径：(0,0)->E->(w-1,0)->N->(w-1,h-1)->W->(0,h-1)->S->(0,0)
        self.path = []
        self.dirs = []
        x, y = 0, 0
        # 底边向东
        for i in range(width - 1):
            self.path.append((i, 0))
            self.dirs.append("East")
        # 右边向北
        for i in range(height - 1):
            self.path.append((width - 1, i))
            self.dirs.append("North")
        # 顶边向西
        for i in range(width - 1):
            self.path.append((width - 1 - i, height - 1))
            self.dirs.append("West")
        # 左边向南
        for i in range(height - 1):
            self.path.append((0, height - 1 - i))
            self.dirs.append("South")

    def step(self, num: int) -> None:
        if self.at_origin:
            self.at_origin = False
        self.pos = (self.pos + num) % self.perimeter

    def getPos(self):
        return list(self.path[self.pos])

    def getDir(self) -> str:
        if self.at_origin:
            return "East"
        return self.dirs[self.pos]
```

### 方法二：数学计算（不预存路径）

```python
class Robot:

    def __init__(self, width: int, height: int):
        self.w = width
        self.h = height
        self.perimeter = 2 * (width + height - 2)
        self.pos = 0
        self.moved = False

    def step(self, num: int) -> None:
        self.moved = True
        self.pos = (self.pos + num) % self.perimeter

    def getPos(self):
        w, h = self.w, self.h
        p = self.pos
        if p < w:
            return [p, 0]
        p -= w - 1
        if p < h:
            return [w - 1, p]
        p -= h - 1
        if p < w:
            return [w - 1 - p, h - 1]
        p -= w - 1
        return [0, h - 1 - p]

    def getDir(self) -> str:
        if not self.moved:
            return "East"
        p = self.pos
        w, h = self.w, self.h
        if p == 0:
            return "South"  # 在 (0,0) 朝向是来时方向（从南来）
        if p < w - 1:
            return "East"
        if p < w - 1 + h - 1:
            return "North"
        if p < 2 * (w - 1) + h - 1:
            return "West"
        return "South"
```

## 复杂度分析

- 构造：O(perimeter)
- step：O(1)
- getPos/getDir：O(1)

## 关键点总结

1. 将步数取模周长，避免逐步模拟
2. 边界路径按顺时针方向预计算
3. 起点特殊处理：机器人未移动时方向为 East

## 易错点

- 机器人在 `(0,0)` 且未移动时，方向是 "East"（初始方向）
- 机器人移动后回到 `(0,0)`，方向是 "South"（从左侧走来）
- 预计算路径时要确保顺序正确（顺时针）
