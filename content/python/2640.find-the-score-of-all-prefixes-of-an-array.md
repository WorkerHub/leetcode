## 题目描述

给你一个下标从 0 开始长度为 `n` 的整数数组 `nums`。定义前缀 `nums[0..i]` 的分数为 `nums[i] + max(nums[0..i])`。

返回一个长度为 `n` 的数组 `ans`，其中 `ans[i]` 是前缀 `nums[0..i]` 的分数。

**示例 1：**
```
输入：nums = [2,3,7,5,10]
输出：[4,6,14,12,20]
解释：
- ans[0] = 2 + max(2) = 4
- ans[1] = 3 + max(2,3) = 6
- ans[2] = 7 + max(2,3,7) = 14
- ans[3] = 5 + max(2,3,7,5) = 12
- ans[4] = 10 + max(2,3,7,5,10) = 20
```

**示例 2：**
```
输入：nums = [1,1,2,4,8,16]
输出：[2,2,4,8,16,32]
```

**数据范围：**
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^9

## 解题思路

线性扫描：维护一个前缀最大值 `max_so_far`，每次将当前元素加上前缀最大值得到分数。

## Python 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def findPrefixScore(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = []
        max_so_far = 0
        for x in nums:
            max_so_far = max(max_so_far, x)  # 更新前缀最大值
            ans.append(x + max_so_far)        # 分数 = 当前值 + 前缀最大值
        return ans
```

### 方法二：使用 itertools.accumulate

```python
from typing import List
import itertools

class Solution:
    def findPrefixScore(self, nums: List[int]) -> List[int]:
        # accumulate 默认求前缀和，传入 max 函数求前缀最大值
        prefix_max = list(itertools.accumulate(nums, max))
        return [x + m for x, m in zip(nums, prefix_max)]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 前缀最大值可以用单变量维护，无需数组
2. 分数 = 当前值 + 前缀最大值（前缀最大值包含当前元素）

## 易错点

1. `max(nums[0..i])` 包含当前元素，所以先更新 `max_so_far`，再计算分数
