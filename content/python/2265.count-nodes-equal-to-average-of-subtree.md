## 题目描述

给你一棵二叉树的根节点 `root`，返回满足以下条件的节点数量：

该节点的值**等于**以该节点为根的子树中所有节点值的**平均值**（向下取整）。

**示例 1：**
```
输入：root = [4,8,5,0,1,null,6]
输出：5
解释：
- 节点4：子树和=24，个数=6，平均=4，等于节点值。
- 节点8：子树和=9，个数=3，平均=3，不等于8。
- 节点5：子树和=11，个数=2，平均=5，等于5。
- 节点0：子树和=0，个数=1，平均=0，等于0。
- 节点1：子树和=1，个数=1，平均=1，等于1。
- 节点6：子树和=6，个数=1，平均=6，等于6。
共5个节点满足条件。
```

## 解题思路

DFS 后序遍历：对每个节点，递归计算其子树的节点总和与节点个数，然后判断 `val == total_sum // count`。

## 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def averageOfSubtree(self, root: Optional[TreeNode]) -> int:
        self.ans = 0

        def dfs(node: Optional[TreeNode]):
            """返回 (子树节点总和, 子树节点个数)"""
            if not node:
                return 0, 0

            left_sum, left_cnt = dfs(node.left)
            right_sum, right_cnt = dfs(node.right)

            total_sum = left_sum + right_sum + node.val
            total_cnt = left_cnt + right_cnt + 1

            # 判断节点值是否等于子树平均值（向下取整）
            if node.val == total_sum // total_cnt:
                self.ans += 1

            return total_sum, total_cnt

        dfs(root)
        return self.ans
```

### 方法二：返回元组（无需全局变量）

```python
from typing import Optional, Tuple

class Solution:
    def averageOfSubtree(self, root: Optional[TreeNode]) -> int:
        def dfs(node) -> Tuple[int, int, int]:
            """返回 (满足条件的节点数, 子树总和, 子树节点数)"""
            if not node:
                return 0, 0, 0

            lc, ls, ln = dfs(node.left)
            rc, rs, rn = dfs(node.right)

            ts = ls + rs + node.val
            tn = ln + rn + 1
            count = lc + rc + (1 if node.val == ts // tn else 0)

            return count, ts, tn

        return dfs(root)[0]
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，h 为树高，递归栈深度。

## 关键点总结

1. 后序遍历：先递归子节点，再计算当前节点的子树信息。
2. 每个节点返回 (子树总和, 子树节点数)，向上传递合并。
3. 平均值向下取整：`total_sum // total_count`。

## 易错点

- 每个节点本身也计入子树（`total_cnt = left + right + 1`）。
- 整数除法向下取整（Python `//`），不能用浮点数 `/`。
