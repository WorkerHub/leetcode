## 题目描述

给定一个二叉树的根节点 `root`，请按照以下规则将二叉树打印成一个二维字符串数组。

返回的数组的行数应该等于给定二叉树的高度，列数应该总是 `2^height - 1`，其中 `height` 是树的高度。返回数组中的每个位置初始化为空字符串 `""`。按照上述规则填充返回数组，使得：

- 根节点应该被放置在第一行的正中间位置。
- 如果当前节点在第 `r` 行第 `c` 列，那么它的左子节点应该被放置在第 `r+1` 行第 `c - 2^(height-r-1)` 列，它的右子节点应该被放置在第 `r+1` 行第 `c + 2^(height-r-1)` 列。
- 这个过程持续进行，直到所有的节点都被放置完成。
- 任何空位应该包含空字符串 `""`。

**示例 1:**

```
输入：root = [1,2]
输出：
[["","1",""],
 ["2","",""]]
```

**示例 2:**

```
输入：root = [1,2,3,null,4]
输出：
[["","","","1","","",""],
 ["","2","","","","3",""],
 ["","","4","","","",""]]
```

**提示:**
- 树中节点数在范围 `[1, 2^10]` 内
- `-99 <= Node.val <= 99`
- 树的深度在范围 `[1, 10]` 内

## 解题思路

这道题需要将二叉树按特定格式输出到二维数组。关键步骤：

### 核心步骤

1. **计算树的高度**：决定数组的行数
2. **计算数组宽度**：`width = 2^height - 1`
3. **初始化二维数组**：所有位置初始化为空字符串
4. **填充节点**：按照位置计算公式填充

### 位置计算公式

对于在第 `row` 行、列范围 `[left, right]` 的节点：
- **当前节点位置**：`col = (left + right) // 2`
- **左子节点**：在 `row+1` 行，列范围 `[left, col-1]`
- **右子节点**：在 `row+1` 行，列范围 `[col+1, right]`

### 两种遍历方式

1. **DFS（深度优先）**：递归填充
2. **BFS（广度优先）**：层序遍历填充

## Python 代码实现

### 方法一：DFS 递归（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def printTree(self, root: Optional[TreeNode]) -> List[List[str]]:
        """
        使用 DFS 递归填充二维数组
        """
        # 1. 计算树的高度
        def get_height(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return 1 + max(get_height(node.left), get_height(node.right))
        
        height = get_height(root)
        
        # 2. 计算数组宽度
        width = (1 << height) - 1  # 2^height - 1
        
        # 3. 初始化二维数组
        result = [[""] * width for _ in range(height)]
        
        # 4. DFS 填充节点
        def fill(node: Optional[TreeNode], row: int, left: int, right: int):
            """
            在二维数组中填充节点
            node: 当前节点
            row: 当前行
            left, right: 当前列的范围
            """
            if not node:
                return
            
            # 计算当前节点的列位置（中间位置）
            col = (left + right) // 2
            
            # 填充当前节点
            result[row][col] = str(node.val)
            
            # 递归填充左子树
            fill(node.left, row + 1, left, col - 1)
            
            # 递归填充右子树
            fill(node.right, row + 1, col + 1, right)
        
        # 从根节点开始填充
        fill(root, 0, 0, width - 1)
        
        return result
```

### 方法二：BFS 层序遍历

```python
from collections import deque

class Solution:
    def printTree(self, root: Optional[TreeNode]) -> List[List[str]]:
        """
        使用 BFS 层序遍历填充
        """
        # 计算高度
        def get_height(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return 1 + max(get_height(node.left), get_height(node.right))
        
        height = get_height(root)
        width = (1 << height) - 1
        
        # 初始化结果数组
        result = [[""] * width for _ in range(height)]
        
        # BFS 队列：(节点, 行, 左边界, 右边界)
        queue = deque([(root, 0, 0, width - 1)])
        
        while queue:
            node, row, left, right = queue.popleft()
            
            if not node:
                continue
            
            # 计算列位置
            col = (left + right) // 2
            
            # 填充当前节点
            result[row][col] = str(node.val)
            
            # 左子节点入队
            if node.left:
                queue.append((node.left, row + 1, left, col - 1))
            
            # 右子节点入队
            if node.right:
                queue.append((node.right, row + 1, col + 1, right))
        
        return result
```

### 方法三：位运算优化计算

```python
class Solution:
    def printTree(self, root: Optional[TreeNode]) -> List[List[str]]:
        """
        使用位运算优化位置计算
        """
        def get_height(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            return 1 + max(get_height(node.left), get_height(node.right))
        
        height = get_height(root)
        width = (1 << height) - 1
        result = [[""] * width for _ in range(height)]
        
        def fill(node: Optional[TreeNode], row: int, col: int, offset: int):
            """
            row: 当前行
            col: 当前列
            offset: 子节点的偏移量（2^(height-row-1)）
            """
            if not node:
                return
            
            # 填充当前节点
            result[row][col] = str(node.val)
            
            # 计算下一层的偏移量
            next_offset = offset // 2
            
            # 填充左右子树
            if node.left:
                fill(node.left, row + 1, col - offset, next_offset)
            if node.right:
                fill(node.right, row + 1, col + offset, next_offset)
        
        # 根节点在第0行，中间位置，初始偏移量为 2^(height-1)
        fill(root, 0, width // 2, 1 << (height - 2) if height > 1 else 0)
        
        return result
```

## 复杂度分析

### 方法一：DFS 递归
- **时间复杂度**：O(h × 2^h)
  - 计算高度：O(n)
  - 填充数组：O(h × 2^h)，遍历所有数组位置
- **空间复杂度**：O(h × 2^h)
  - 结果数组
  - 递归栈深度 O(h)

### 方法二：BFS 层序遍历
- **时间复杂度**：O(h × 2^h)
- **空间复杂度**：O(h × 2^h)
  - 结果数组
  - 队列最多存储一层的节点 O(2^h)

### 方法三：位运算优化
- **时间复杂度**：O(h × 2^h)
- **空间复杂度**：O(h × 2^h)

## 关键点总结

1. **高度计算**：递归计算树的高度，决定行数
2. **宽度公式**：`width = 2^height - 1`
3. **位置计算**：使用二分思想，当前节点在 `[left, right]` 的中间
4. **递归范围**：左子树 `[left, col-1]`，右子树 `[col+1, right]`
5. **空节点处理**：默认初始化为空字符串，不需要特殊处理

## 易错点

1. **高度定义**：
   ```python
   # 注意：单个节点的高度是1，不是0
   def get_height(node):
       if not node:
           return 0
       return 1 + max(get_height(node.left), get_height(node.right))
   ```

2. **宽度计算**：
   ```python
   # 2^height - 1，不是 2^(height-1)
   width = (1 << height) - 1  # 位运算：1 << h 等于 2^h
   ```

3. **列位置计算**：
   ```python
   # 使用整数除法
   col = (left + right) // 2  # 不是 /
   ```

4. **递归边界**：
   ```python
   # 左子树的右边界是 col-1，不是 col
   fill(node.left, row + 1, left, col - 1)
   # 右子树的左边界是 col+1
   fill(node.right, row + 1, col + 1, right)
   ```

5. **数组初始化**：
   ```python
   # 每一行都要初始化
   result = [[""] * width for _ in range(height)]
   # 不能用：result = [[""]*width]*height  # 这会创建相同的引用
   ```

**常见问题：**

Q: 为什么宽度是 `2^h - 1`？
A: 完全二叉树的最后一层有 `2^(h-1)` 个节点，按照间隔规则需要 `2^h - 1` 列。

Q: 如何理解位置计算公式？
A: 本质是二分法，每次将当前范围对半分，左边给左子树，右边给右子树。

Q: DFS 和 BFS 哪个更好？
A: 都可以，DFS 代码更简洁，BFS 更符合层序遍历的思维。
