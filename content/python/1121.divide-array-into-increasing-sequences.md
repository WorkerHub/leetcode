## 题目描述

给定一个非递减整数数组 `nums` 和整数 `K`，判断是否可以将该数组分成一个或多个长度至少为 `K` 的不相交的递增子序列。

**示例 1:**

```
输入: nums = [1,2,2,3,3,4,4], K = 3
输出: true
解释: 
数组可以分成两个子序列 [1,2,3,4] 和 [2,3,4]。
```

**示例 2:**

```
输入: nums = [5,6,6,7,8], K = 3
输出: false
解释:
无法分成长度至少为3的递增子序列。
```

**提示:**

- `1 <= K <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- 数组 `nums` 按非递减顺序排列

## 解题思路

这是一道贪心 + 数学问题，关键在于找到分组的限制条件。

核心观察：
1. 数组已经排序，相同数字会连续出现
2. 每个递增序列中，相同的数字最多出现1次
3. 如果某个数字出现了 `freq` 次，那么至少需要 `freq` 个不同的序列
4. 如果需要 `m` 个序列，总元素个数必须 >= `m * K`

**关键推理**：
- 假设数字 x 出现了 `max_freq` 次（所有数字中出现次数最多的）
- 那么至少需要 `max_freq` 个不同的序列
- 每个序列长度至少为 K
- 所以总元素个数必须 >= `max_freq * K`

判断条件：`len(nums) >= max_freq * K`

## Python 代码实现

### 方法一：统计最大频率（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def canDivideIntoSubsequences(self, nums: List[int], K: int) -> bool:
        # 统计每个数字出现的次数
        count = Counter(nums)
        
        # 找出出现次数最多的数字的频率
        max_freq = max(count.values())
        
        # 判断条件：总长度 >= 最大频率 * K
        return len(nums) >= max_freq * K
```

### 方法二：一次遍历统计

```python
class Solution:
    def canDivideIntoSubsequences(self, nums: List[int], K: int) -> bool:
        n = len(nums)
        max_freq = 1  # 当前数字的最大出现次数
        curr_count = 1  # 当前数字的出现次数
        
        # 遍历数组，统计连续相同数字的最大次数
        for i in range(1, n):
            if nums[i] == nums[i - 1]:
                curr_count += 1
                max_freq = max(max_freq, curr_count)
            else:
                curr_count = 1
        
        # 判断是否可以分成足够的序列
        return n >= max_freq * K
```

### 方法三：数学公式直接判断

```python
class Solution:
    def canDivideIntoSubsequences(self, nums: List[int], K: int) -> bool:
        # 找出最大频率
        max_freq = 0
        i = 0
        n = len(nums)
        
        while i < n:
            j = i
            # 统计相同元素的个数
            while j < n and nums[j] == nums[i]:
                j += 1
            max_freq = max(max_freq, j - i)
            i = j
        
        return len(nums) >= max_freq * K
```

## 复杂度分析

**方法一（Counter）：**
- 时间复杂度：O(n)，遍历数组统计频率
- 空间复杂度：O(n)，Counter需要存储所有不同的数字

**方法二（一次遍历）：**
- 时间复杂度：O(n)，只需遍历一次
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. **贪心思想**：出现次数最多的数字决定了最少需要多少个序列
2. **数学推导**：如果需要 m 个长度为 K 的序列，总长度至少是 m * K
3. **数组有序**：相同数字连续出现，便于统计
4. **必要充分条件**：`n >= max_freq * K` 既是必要条件也是充分条件

## 易错点

1. **理解题意**：递增子序列中每个元素必须严格大于前一个，相同数字不能在同一序列中

2. **混淆递增和非递减**：
   - 递增：1 < 2 < 3（严格大于）
   - 非递减：1 <= 2 <= 3（可以相等）
   - 本题要求递增，所以相同数字必须分到不同序列

3. **忽略最大频率的意义**：
   ```python
   # 错误思路：认为只要总长度够就行
   return len(nums) >= K  # 错误
   
   # 正确：考虑最大频率的限制
   return len(nums) >= max_freq * K  # 正确
   ```

4. **边界情况**：
   - 所有元素相同：`nums = [1,1,1,1,1]`, `K = 2`
     - max_freq = 5，需要 5 * 2 = 10 个元素，但只有 5 个，返回 false
   - 所有元素不同：max_freq = 1，只要 `len(nums) >= K` 即可
