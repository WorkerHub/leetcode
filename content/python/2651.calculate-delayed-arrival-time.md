## 题目描述

给你一个正整数 `arrivalTime` 表示以 24 小时制表示的到达时间（小时），以及另一个正整数 `delayedTime` 表示延误的小时数。返回延误后的到达时间（0 到 23 之间）。

**示例 1：**
```
输入：arrivalTime = 15, delayedTime = 5
输出：20
```

**示例 2：**
```
输入：arrivalTime = 13, delayedTime = 48
输出：13
解释：延误 48 小时，13 + 48 = 61，61 % 24 = 13
```

**数据范围：**
- 1 <= arrivalTime <= 23
- 1 <= delayedTime <= 24

## 解题思路

直接计算 `(arrivalTime + delayedTime) % 24`。

## Python 代码实现

### 方法一：取模（推荐）

```python
class Solution:
    def findDelayedArrivalTime(self, arrivalTime: int, delayedTime: int) -> int:
        return (arrivalTime + delayedTime) % 24
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 24 小时制循环，用模运算处理跨天的情况

## 易错点

1. 延误可能超过 24 小时，需要取模而非仅判断是否超过 24
