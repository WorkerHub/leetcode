## 题目描述

给定整数数组 `nums`，可以对数组进行若干次操作：每次选择相邻的两个元素，将较小的那个删除（或替换成两者之差）。目标是使最终留下的最后一个元素尽可能大。

**示例 1：**
```
输入：nums = [3,1,2]
输出：3
解释：3 是最大元素，通过删除 1 和 2 可保留 3。
```

**示例 2：**
```
输入：nums = [2,3,1,5,4]
输出：5
解释：最大值为 5，可通过操作将其他元素消除。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**贪心分析：**

每次操作将较小的元素删除，等价于保留较大的元素。最终留下的元素是在一系列"胜者"中最后存活的那个。

关键观察：
- 如果数组中有一个元素，它能"打败"（大于等于）其左边的所有元素，那么它可以一直向左扩展，最终成为候选答案。
- 最大元素总能存活到最后（它可以打败任何相邻元素）。
- 答案就是数组的最大值。

实际上，每次操作：选相邻两元素，将小的删去（大的留下），类似于锦标赛。最终存活的必然是整个数组的最大值（它能打败任何元素）。

## Python 代码实现

### 方法一：直接返回最大值（推荐）

```python
from typing import List

class Solution:
    def maxElement(self, nums: List[int]) -> int:
        # 每次删除较小的相邻元素，最大值总能存活
        return max(nums)
```

### 方法二：模拟验证

```python
from typing import List

class Solution:
    def maxElement(self, nums: List[int]) -> int:
        # 贪心：每次将当前前缀的最大值向右扩展
        # 若 nums[i] >= 当前最大值，则更新最大值
        # 最大值始终能击败前面所有元素
        result = nums[0]
        for x in nums:
            result = max(result, x)
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作保留较大的相邻元素
2. 全局最大值可以打败任何相邻元素，最终必然存活
3. 答案即数组最大值

## 易错点

1. 不要想复杂，每次取相邻两者最大，全局最大必胜
2. 无需实际模拟操作过程
