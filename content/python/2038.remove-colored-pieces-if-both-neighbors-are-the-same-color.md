## 题目描述

总共有 `n` 个颜色片段排成一列，每个颜色要么是 `'A'` 要么是 `'B'`。

Alice 和 Bob 轮流移除颜色片段，Alice 先手。Alice 只能移除颜色为 `'A'` 的片段，Bob 只能移除颜色为 `'B'` 的片段。条件：
- 被移除片段的**两侧邻居**（如果存在）颜色相同（如 `AAA` 中间的 `A`）

谁无法操作则输。Alice 先手，若 Alice 必赢返回 `true`，否则 `false`。

**示例 1：**
```
输入：colors = "AAABABB"
输出：true
```

**示例 2：**
```
输入：colors = "AA"
输出：false
```

**提示：**
- `1 <= colors.length <= 10^5`
- `colors[i]` 是 `'A'` 或 `'B'`

## 解题思路

**关键观察：**
1. Alice 的操作不影响 Bob 可以移除的 `B`（两类操作互不干扰）
2. Alice 能移除 `A` 的次数 = 连续 `A` 序列中，长度为 `l` 的序列有 `l - 2` 个可移除位置（对 `l >= 3` 的情况）
3. 同理 Bob 能移除 `B` 的次数

**结论：** Alice 的可操作次数和 Bob 的可操作次数是独立的，互不影响。

因此：Alice 赢 `<=>` Alice 的可操作次数 > Bob 的可操作次数

## 代码实现

### 方法一：统计连续段（推荐）

```python
class Solution:
    def winnerOfGame(self, colors: str) -> bool:
        alice_moves = 0
        bob_moves = 0
        n = len(colors)
        i = 0

        while i < n:
            j = i
            # 找当前颜色的连续段
            while j < n and colors[j] == colors[i]:
                j += 1
            length = j - i
            if colors[i] == 'A':
                alice_moves += max(0, length - 2)  # AAA 可移除1个，AAAA 可移除2个，...
            else:
                bob_moves += max(0, length - 2)
            i = j

        return alice_moves > bob_moves
```

### 方法二：迭代统计（等价写法）

```python
class Solution:
    def winnerOfGame(self, colors: str) -> bool:
        alice = bob = 0

        for i in range(1, len(colors) - 1):
            # 当前位置两侧邻居均为同色，且当前颜色对应玩家可操作
            if colors[i - 1] == colors[i] == colors[i + 1]:
                if colors[i] == 'A':
                    alice += 1
                else:
                    bob += 1

        return alice > bob
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. Alice 和 Bob 的操作完全独立，不相互影响
2. 一个长度为 `l` 的连续同色段有 `max(0, l - 2)` 个可移除位置
3. Alice 先手赢 = Alice 可操作次数严格大于 Bob（先手有利，但需要至少比 Bob 多一步）

## 易错点

- 条件是两侧邻居**都是同色**，不是任一侧相同
- Alice 赢需要**严格大于** Bob（等于时 Bob 跟随策略，最终 Alice 先无棋可走）
