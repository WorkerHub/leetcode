## 题目描述

给你一个整数数组 `nums`，可以将数组中的元素拼接成字符串后组成一个整数。请你通过重新排列 `nums` 中元素的顺序，返回能够拼接成的 **最大整数**（以字符串形式返回）。

**示例 1：**

```
输入：nums = [10, 2]
输出："210"
```

**示例 2：**

```
输入：nums = [3, 30, 34, 5, 9]
输出："9534330"
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`

## 解题思路

贪心策略：对于两个数 a 和 b，比较 ab（a 在前）和 ba（b 在前）哪个更大。若 ab > ba，则 a 应排在 b 前面。

使用自定义比较器对数组排序。注意结果中若所有数字均为 0，应返回 "0"。

## Python 代码实现

### 方法一：自定义排序（推荐）

```python
from typing import List
import functools

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        # 自定义比较：若 a+b > b+a，则 a 排在前面
        def compare(a, b):
            if a + b > b + a:
                return -1
            elif a + b < b + a:
                return 1
            else:
                return 0

        # 转换为字符串后排序
        strs = [str(x) for x in nums]
        strs.sort(key=functools.cmp_to_key(compare))
        result = ''.join(strs)

        # 处理全 0 的情况
        return '0' if result[0] == '0' else result
```

### 方法二：直接用乘法比较

```python
from typing import List
import functools

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        strs = list(map(str, nums))

        # 比较两个字符串拼接后哪个更大
        strs.sort(key=functools.cmp_to_key(
            lambda a, b: (1 if a+b < b+a else -1)
        ))

        result = ''.join(strs)
        # 避免返回 "000...0"
        return result if result[0] != '0' else '0'
```

## 复杂度分析

- 时间复杂度：O(n log n * L)，其中 L 是数字的平均位数，排序时每次比较需 O(L)
- 空间复杂度：O(n)，存储字符串列表

## 关键点总结

1. 核心思路：用拼接后的字符串大小来定义排序顺序，而不是直接比较数值
2. 字符串比较天然支持逐位比较，符合贪心要求
3. 所有元素为 0 时，结果应为 "0" 而不是 "00...0"

## 易错点

1. 不能直接按数字大小排序，例如 [3, 30] 应排成 "330" 而非 "303"
2. 全 0 输入需特殊处理，避免输出 "000"
3. `functools.cmp_to_key` 是 Python 3 中使用自定义比较器的标准方法
