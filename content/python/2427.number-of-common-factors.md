## 题目描述

给你两个正整数 `a` 和 `b`，返回 `a` 和 `b` 的 **公因子** 的数目。

如果 `x` 可以同时整除 `a` 和 `b`，则认为 `x` 是 `a` 和 `b` 的一个 **公因子**。

**示例 1：**
```
输入：a = 12, b = 6
输出：4
解释：12 和 6 的公因子有 1、2、3、6。
```

**示例 2：**
```
输入：a = 25, b = 30
输出：2
解释：25 和 30 的公因子有 1、5。
```

**提示：**
- `1 <= a, b <= 1000`

## 解题思路

公因子一定是最大公约数（GCD）的因子。因此：
1. 先求 `g = gcd(a, b)`
2. 统计 `g` 的因子个数（即 `1` 到 `g` 中能整除 `g` 的数）

也可以直接枚举 `1` 到 `min(a, b)`，检查能否同时整除 `a` 和 `b`。

## 代码实现

### 方法一：求 GCD 后枚举因子（推荐）

```python
import math

class Solution:
    def commonFactors(self, a: int, b: int) -> int:
        g = math.gcd(a, b)  # 最大公约数
        # 统计 g 的因子个数
        count = 0
        for i in range(1, g + 1):
            if g % i == 0:
                count += 1
        return count
```

### 方法二：直接枚举（简单直接）

```python
class Solution:
    def commonFactors(self, a: int, b: int) -> int:
        # 枚举 1 到 min(a, b)，检查是否同时整除 a 和 b
        return sum(1 for i in range(1, min(a, b) + 1) if a % i == 0 and b % i == 0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| GCD + 枚举 | O(sqrt(g) + log(min(a,b))) | O(1) |
| 直接枚举 | O(min(a, b)) | O(1) |

方法一可以进一步优化：只枚举到 `sqrt(g)`，每次找到因子 `i` 时，同时计入 `g/i`（若 `g/i != i`）。

## 关键点总结

1. 公因子一定是 GCD 的因子
2. 先求 GCD 可以减少枚举范围

## 易错点

- 枚举到 `g`（包含），不是 `g - 1`
- `a = b` 时，GCD = a，因子个数就是 a 的因子数
