## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，初始时你站在下标 `0` 处。

从下标 `i` 跳到下标 `j` 的条件：
- `i < j`，且 `nums[i] <= nums[j]`，且 `i` 和 `j` 之间没有任何 `nums[k]`（`i < k < j`）满足 `nums[i] <= nums[k]`（即 `j` 是 `i` 右边第一个 `>= nums[i]` 的位置，跳过所有严格更小的）。
- `i < j`，且 `nums[i] > nums[j]`，且 `i` 和 `j` 之间没有任何 `nums[k]`（`i < k < j`）满足 `nums[k] < nums[j]`（即 `j` 是 `i` 右边第一个严格小于且无更小值阻挡的）。

每次跳跃花费 `costs[j]`，返回跳到最后一个下标的最小花费。

## 解题思路

**单调栈建边 + DP：**

先用单调栈确定可以跳到的下标对（有向边），再跑 DP（最短路）。

两类边：
1. **非递减跳跃**：用单调递减栈，找每个位置右边第一个 `>=` 自己的位置。
2. **递减跳跃**：用单调递增栈，找每个位置右边第一个比自己小的位置。

然后 `dp[j] = min(dp[i] + costs[j])` 对所有从 `i` 可以跳到 `j` 的边。

## 代码实现

### 方法一：单调栈 + DP（推荐）

```python
from typing import List
import math

class Solution:
    def minCost(self, nums: List[int], costs: List[int]) -> int:
        n = len(nums)
        dp = [math.inf] * n
        dp[0] = 0

        # 建图（两类边）
        # 用单调栈同步计算 dp

        # 处理第一类边：i -> j，nums[i] <= nums[j]，中间无 >= nums[i] 的值
        # 等价：j 是 i 右边"下一个更大或相等"的位置
        # 单调递减栈
        stack = []
        for j in range(n):
            while stack and nums[stack[-1]] <= nums[j]:
                i = stack.pop()
                dp[j] = min(dp[j], dp[i] + costs[j])
            if stack:
                # stack[-1] > nums[j]，还需要第二类边处理
                pass
            stack.append(j)

        # 处理第二类边：i -> j，nums[i] > nums[j]，中间无 < nums[j] 的值
        # 等价：j 是 i 右边"下一个更小"的位置
        # 单调递增栈
        stack = []
        for j in range(n):
            while stack and nums[stack[-1]] > nums[j]:
                i = stack.pop()
                dp[j] = min(dp[j], dp[i] + costs[j])
            stack.append(j)

        return dp[n - 1]
```

### 方法二：合并两次单调栈

```python
from typing import List
import math

class Solution:
    def minCost(self, nums: List[int], costs: List[int]) -> int:
        n = len(nums)
        dp = [math.inf] * n
        dp[0] = 0

        # 第一类边：单调递减栈（找右边第一个 >= 自己的）
        stk = []
        for j in range(n):
            # 弹出所有值 <= nums[j] 的栈顶（它们能跳到 j）
            while stk and nums[stk[-1]] <= nums[j]:
                dp[j] = min(dp[j], dp[stk.pop()] + costs[j])
            stk.append(j)

        # 第二类边：单调递增栈（找右边第一个 < 自己的）
        stk = []
        for j in range(n):
            # 弹出所有值 > nums[j] 的栈顶（它们能跳到 j）
            while stk and nums[stk[-1]] > nums[j]:
                dp[j] = min(dp[j], dp[stk.pop()] + costs[j])
            stk.append(j)

        return dp[n - 1]
```

## 复杂度分析

- 时间复杂度：O(n)，两次单调栈各 O(n)。
- 空间复杂度：O(n)，dp 数组和栈。

## 关键点总结

1. 跳跃规则等价于两类"下一个更大/更小"问题，用单调栈 O(n) 建边。
2. 两类边分别用单调递减栈和单调递增栈处理。
3. DP 更新：当栈顶被弹出时，更新目标位置的 dp 值。

## 易错点

- 两类边分别处理，不要混淆：递减栈处理 `<=` 关系，递增栈处理 `>` 关系。
- `dp[0] = 0`（起点无花费），`dp[j] += costs[j]`（到达 j 时加上花费）。
