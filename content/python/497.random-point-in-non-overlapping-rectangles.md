## 题目描述

给定一个由非重叠的轴对齐矩形的数组 rects，其中 rects[i] = [ai, bi, xi, yi] 表示 (ai, bi) 是第 i 个矩形的左下角点，(xi, yi) 是第 i 个矩形的右上角点。设计一个算法来随机挑选一个被某一矩形覆盖的整数点。矩形周边上的点也算做是被矩形覆盖。所有满足要求的点必须等概率被返回。

在给定的矩形覆盖的空间内的任何整数点都有可能被返回。

请注意，整数点是具有整数坐标的点。

实现 Solution 类:
- Solution(int[][] rects) 用给定的矩形数组 rects 初始化对象。
- int[] pick() 返回一个随机的整数点 [u, v] 在给定的矩形所覆盖的空间内。

**示例 1：**
```
输入：
["Solution", "pick", "pick", "pick", "pick", "pick"]
[[[[-2, -2, 1, 1], [2, 2, 4, 6]]], [], [], [], [], []]
输出：
[null, [1, -2], [1, -1], [-1, -2], [-2, -2], [0, 0]]

解释：
Solution solution = new Solution([[-2, -2, 1, 1], [2, 2, 4, 6]]);
solution.pick(); // 返回 [1, -2]
solution.pick(); // 返回 [1, -1]
solution.pick(); // 返回 [-1, -2]
solution.pick(); // 返回 [-2, -2]
solution.pick(); // 返回 [0, 0]
```

**提示：**
- 1 <= rects.length <= 100
- rects[i].length == 4
- -10^9 <= ai < xi <= 10^9
- -10^9 <= bi < yi <= 10^9
- xi - ai <= 2000
- yi - bi <= 2000
- 所有的矩形不重叠
- pick 最多被调用 10^4 次

## 解题思路

这道题的核心是实现等概率的随机选择。

### 核心思想

1. **权重随机**：
   - 每个矩形的点数不同
   - 点数多的矩形被选中的概率应该更大
   - 使用前缀和 + 二分查找实现权重随机

2. **两步随机**：
   - 第一步：根据点数权重随机选择一个矩形
   - 第二步：在选中的矩形内随机选择一个点

3. **点数计算**：
   - 矩形 [a, b, x, y] 包含的整数点数：
   - `(x - a + 1) * (y - b + 1)`

4. **前缀和优化**：
   - 预计算每个矩形的点数前缀和
   - 使用二分查找快速定位矩形

## Python 代码实现

### 方法一：前缀和 + 二分查找（推荐）

```python
from typing import List
import random
import bisect

class Solution:
    def __init__(self, rects: List[List[int]]):
        """
        预处理前缀和
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        self.rects = rects
        self.prefix_sum = []
        total = 0
        
        # 计算每个矩形的点数前缀和
        for x1, y1, x2, y2 in rects:
            # 矩形包含的整数点数
            count = (x2 - x1 + 1) * (y2 - y1 + 1)
            total += count
            self.prefix_sum.append(total)
        
        self.total_points = total

    def pick(self) -> List[int]:
        """
        随机选择一个点
        
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        # 随机选择一个点的序号（1 到 total_points）
        target = random.randint(1, self.total_points)
        
        # 二分查找该点所在的矩形
        idx = bisect.bisect_left(self.prefix_sum, target)
        
        # 计算在该矩形内的偏移
        x1, y1, x2, y2 = self.rects[idx]
        
        # 该矩形内的点数
        points_in_rect = (x2 - x1 + 1) * (y2 - y1 + 1)
        
        # 该矩形的起始序号
        start = self.prefix_sum[idx] - points_in_rect + 1
        
        # 在矩形内的偏移（0-based）
        offset = target - start
        
        # 计算具体坐标
        width = x2 - x1 + 1
        dx = offset % width
        dy = offset // width
        
        return [x1 + dx, y1 + dy]
```

### 方法二：直接随机矩形和点

```python
class Solution:
    def __init__(self, rects: List[List[int]]):
        """
        预处理权重
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        self.rects = rects
        self.weights = []
        
        for x1, y1, x2, y2 in rects:
            count = (x2 - x1 + 1) * (y2 - y1 + 1)
            self.weights.append(count)

    def pick(self) -> List[int]:
        """
        使用 random.choices 权重随机
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 根据权重随机选择一个矩形
        rect = random.choices(self.rects, weights=self.weights)[0]
        x1, y1, x2, y2 = rect
        
        # 在矩形内随机选择一个点
        x = random.randint(x1, x2)
        y = random.randint(y1, y2)
        
        return [x, y]
```

### 方法三：优化的前缀和（手动二分）

```python
class Solution:
    def __init__(self, rects: List[List[int]]):
        self.rects = rects
        self.prefix = []
        total = 0
        
        for a, b, x, y in rects:
            total += (x - a + 1) * (y - b + 1)
            self.prefix.append(total)

    def pick(self) -> List[int]:
        # 随机一个数
        rand = random.randint(0, self.prefix[-1] - 1)
        
        # 手动二分查找
        left, right = 0, len(self.prefix) - 1
        while left < right:
            mid = (left + right) // 2
            if self.prefix[mid] <= rand:
                left = mid + 1
            else:
                right = mid
        
        idx = left
        a, b, x, y = self.rects[idx]
        
        # 计算矩形内的偏移
        prev = self.prefix[idx - 1] if idx > 0 else 0
        offset = rand - prev
        
        width = x - a + 1
        return [a + offset % width, b + offset // width]
```

## 复杂度分析

**方法一、三：前缀和 + 二分**
- **初始化时间复杂度**：O(n)
  - 计算前缀和
  
- **pick 时间复杂度**：O(log n)
  - 二分查找矩形
  
- **空间复杂度**：O(n)
  - 存储前缀和数组

**方法二：权重随机**
- **初始化时间复杂度**：O(n)
  
- **pick 时间复杂度**：O(n)
  - random.choices 内部是 O(n)
  
- **空间复杂度**：O(n)

## 关键点总结

1. **权重随机**：点数多的矩形被选中概率大
2. **前缀和优化**：快速定位矩形
3. **二分查找**：O(log n) 查找
4. **坐标计算**：offset 转换为 (x, y)
5. **等概率保证**：每个点被选中的概率相同

## 易错点

1. **点数计算**
   - 是 (x2 - x1 + 1) * (y2 - y1 + 1)
   - 不要忘记 +1

2. **随机范围**
   - random.randint(1, total) 或 random.randint(0, total - 1)
   - 要与前缀和的定义一致

3. **二分查找**
   - bisect_left vs bisect_right
   - 根据前缀和的定义选择

4. **offset 计算**
   - 需要减去前一个矩形的点数
   - 第一个矩形特殊处理

5. **坐标转换**
   - offset % width 是 x 偏移
   - offset // width 是 y 偏移
