## 题目描述

给你一个整数数组 `nums`，请你求出乘积为正数的最长子数组的长度。

一个数组的乘积为正数，是指数组中所有整数的乘积是正整数。

请注意，空数组的乘积被认定为 1，而 1 是正整数。另外，你不能选择 0 作为起始位置，因为任何包含 0 的乘积为 0。

**示例 1：**
```
输入：nums = [1,-2,-3,4]
输出：4
解释：所有整数的乘积为 24
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

### 动态规划

定义：
- `pos[i]`：以 `nums[i]` 结尾、乘积为正的最长子数组长度
- `neg[i]`：以 `nums[i]` 结尾、乘积为负的最长子数组长度

**状态转移：**
- 若 `nums[i] > 0`：正 * 正 = 正，负 * 正 = 负
  - `pos[i] = pos[i-1] + 1`
  - `neg[i] = neg[i-1] + 1 if neg[i-1] > 0 else 0`
- 若 `nums[i] < 0`：正 * 负 = 负，负 * 负 = 正
  - `pos[i] = neg[i-1] + 1 if neg[i-1] > 0 else 0`
  - `neg[i] = pos[i-1] + 1`
- 若 `nums[i] == 0`：`pos[i] = neg[i] = 0`（重置）

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def getMaxLen(self, nums: List[int]) -> int:
        n = len(nums)
        pos = 0   # 以当前位置结尾，乘积为正的最长子数组
        neg = 0   # 以当前位置结尾，乘积为负的最长子数组
        ans = 0

        for num in nums:
            if num > 0:
                pos, neg = pos + 1, neg + 1 if neg > 0 else 0
            elif num < 0:
                pos, neg = neg + 1 if neg > 0 else 0, pos + 1
            else:
                pos, neg = 0, 0  # 遇到 0，重置
            ans = max(ans, pos)

        return ans
```

### 方法二：前缀乘积符号 + 哈希

```python
from typing import List

class Solution:
    def getMaxLen(self, nums: List[int]) -> int:
        # 记录每个前缀乘积的符号第一次出现的位置
        # 正数前缀：+1，负数前缀：-1，遇到0重置
        first_neg = -1  # 第一个负数前缀的位置
        ans = 0
        neg_count = 0  # 前缀中负数的个数
        start = 0      # 当前有效段的起始位置

        for i, num in enumerate(nums):
            if num == 0:
                # 重置
                start = i + 1
                neg_count = 0
                first_neg = -1
            elif num < 0:
                neg_count += 1
                if neg_count == 1:
                    first_neg = i
                if neg_count % 2 == 0:
                    ans = max(ans, i - start + 1)
                else:
                    ans = max(ans, i - first_neg - 1)
            else:
                if neg_count % 2 == 0:
                    ans = max(ans, i - start + 1)
                else:
                    ans = max(ans, i - first_neg - 1)

        return ans
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. `pos` 和 `neg` 分别记录以当前元素结尾的正乘积和负乘积子数组长度
2. 遇到 0 两者都重置
3. 负数时 pos 和 neg 互换（乘以负数改变符号）

## 易错点

- `neg + 1 if neg > 0 else 0`：若之前没有负乘积子数组，乘以正数后负乘积为 0，不是 1
- 遇到负数时，`pos` 更新依赖旧的 `neg`，要注意更新顺序（用临时变量或同时赋值）
