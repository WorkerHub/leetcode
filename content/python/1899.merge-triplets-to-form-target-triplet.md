## 题目描述

给你一个二维整数数组 `triplets`，其中 `triplets[i] = [ai, bi, ci]` 是第 i 个三元组。

同时给你一个整数数组 `target = [x, y, z]`。

**合并操作**：选择两个下标 i 和 j（i != j），并将 `triplets[i]` 更新为 `[max(ai, aj), max(bi, bj), max(ci, cj)]`。

你可以执行任意次合并操作。若可以使某个三元组等于 `target`，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：triplets = [[2,5,3],[1,8,4],[1,7,5]], target = [2,7,5]
输出：true
解释：合并第一个和第三个三元组：[max(2,1),max(5,7),max(3,5)] = [2,7,5] = target
```

**示例 2：**
```
输入：triplets = [[1,3,4],[2,5,8]], target = [2,5,5]
输出：false
```

**提示：**
- `1 <= triplets.length <= 10^5`
- `triplets[i].length == target.length == 3`
- `1 <= ai, bi, ci <= 1000`
- `target.length == 3`
- `1 <= x, y, z <= 1000`

## 解题思路

**贪心**：

关键观察：合并操作是取逐元素最大值。若某个三元组的某个分量**超过** target 对应分量，则合并后该分量会超过 target，永远无法等于 target。

因此：
1. 过滤掉所有分量超过 target 的三元组（这些三元组不能参与合并）
2. 将剩余三元组合并（取逐元素最大值）
3. 检查合并结果是否等于 target

## 代码实现

### 方法一：贪心过滤（推荐）

```python
from typing import List

class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        x, y, z = target
        # 合并所有不超过 target 的三元组
        merged = [0, 0, 0]

        for a, b, c in triplets:
            # 如果任一分量超过 target 对应值，跳过该三元组
            if a <= x and b <= y and c <= z:
                merged[0] = max(merged[0], a)
                merged[1] = max(merged[1], b)
                merged[2] = max(merged[2], c)

        return merged == target
```

### 方法二：集合标记（等价方法）

```python
from typing import List

class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        x, y, z = target
        # 记录哪些位置已经被满足
        found = set()

        for a, b, c in triplets:
            # 跳过任何分量超过目标的三元组
            if a > x or b > y or c > z:
                continue
            # 标记哪些位置与 target 相等
            if a == x:
                found.add(0)
            if b == y:
                found.add(1)
            if c == z:
                found.add(2)

        # 三个位置都被满足
        return len(found) == 3
```

### 方法三：简洁函数式

```python
from typing import List
from functools import reduce

class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        x, y, z = target
        # 过滤后合并
        valid = [t for t in triplets if t[0] <= x and t[1] <= y and t[2] <= z]
        if not valid:
            return target == [0, 0, 0]
        result = reduce(lambda a, b: [max(a[i], b[i]) for i in range(3)], valid)
        return result == target
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历一次
- **空间复杂度**：O(1)

## 关键点总结

1. 合并操作是取逐元素最大值，因此任何分量超过 target 的三元组都会"污染"结果
2. 只选分量不超过 target 的三元组参与合并
3. 检查合并后是否恰好等于 target（不能少，也不能多）

## 易错点

- 过滤条件是「三个分量都不超过对应 target」，任意一个超过就要排除
- 合并结果要**等于** target，而不仅仅是每个分量 <= target
