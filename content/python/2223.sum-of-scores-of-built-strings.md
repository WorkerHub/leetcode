## 题目描述

给你一个下标从 0 开始、长度为 `n` 的字符串 `s`。

对于每个下标 `i`（`0 <= i < n`），**得分** 定义为：从 `s[i]` 开始的后缀 `s[i..n-1]` 与 `s` 本身的最长公共前缀长度。

返回所有下标的得分之和。

**示例 1：**
```
输入：s = "babab"
输出：9
解释：
- i=0: "babab" vs "babab"，公共前缀长5，得分5。
- i=1: "abab" vs "babab"，公共前缀长0，得分0。
- i=2: "bab" vs "babab"，公共前缀长3，得分3。
- i=3: "ab" vs "babab"，公共前缀长0，得分0。
- i=4: "b" vs "babab"，公共前缀长1，得分1。
总和 = 9。
```

**示例 2：**
```
输入：s = "azbazbzaz"
输出：14
```

## 解题思路

这正是 **Z 函数（Z-array）** 的定义：

`Z[i]` = 字符串 `s[i..]` 与 `s[0..]` 的最长公共前缀长度。

特殊地，`Z[0] = n`（整个字符串自身）。

答案 = `sum(Z)` = `Z[0] + Z[1] + ... + Z[n-1]` = `n + sum(Z[1..n-1])`。

**Z 函数算法（线性时间）：**
- 维护一个"Z-box"区间 `[l, r]`，表示当前已知的最右公共前缀匹配区间。
- 对每个 i，利用之前的 Z 值加速计算。

## 代码实现

### 方法一：Z 函数（推荐）

```python
class Solution:
    def sumScores(self, s: str) -> int:
        n = len(s)

        # 计算 Z 函数
        z = [0] * n
        z[0] = n  # s[0..] 与 s 的公共前缀是整个 s
        l, r = 0, 0  # Z-box 的左右边界

        for i in range(1, n):
            if i < r:
                # 利用已知的 Z 值初始化
                z[i] = min(r - i, z[i - l])
            # 扩展匹配
            while i + z[i] < n and s[z[i]] == s[i + z[i]]:
                z[i] += 1
            # 更新 Z-box
            if i + z[i] > r:
                l, r = i, i + z[i]

        return sum(z)
```

### 方法二：暴力（适合理解，O(n^2)）

```python
class Solution:
    def sumScores(self, s: str) -> int:
        n = len(s)
        total = 0
        for i in range(n):
            # 计算 s[i..] 与 s 的最长公共前缀
            j = 0
            while i + j < n and s[j] == s[i + j]:
                j += 1
            total += j
        return total
```

## 复杂度分析

**方法一（Z 函数）：**
- 时间复杂度：O(n)，Z 函数线性时间。
- 空间复杂度：O(n)，Z 数组。

**方法二（暴力）：**
- 时间复杂度：O(n^2)，会 TLE。
- 空间复杂度：O(1)。

## 关键点总结

1. 这道题就是求 Z 函数的所有值之和（包括 Z[0] = n）。
2. Z 函数可以 O(n) 时间计算，核心是维护 Z-box 区间 `[l, r]`。
3. Z-box 表示当前最右的已匹配区间，用于避免重复计算。

## 易错点

- `Z[0]` 定义为 `n`（整个字符串），不是 0，需手动设置。
- Z-box 更新条件：`i + z[i] > r` 时更新 `l = i, r = i + z[i]`。
- Z-box 初始时 `l = r = 0`，第一个 i=1 时若 i >= r（1 >= 0 成立），不使用历史值，直接扩展。
