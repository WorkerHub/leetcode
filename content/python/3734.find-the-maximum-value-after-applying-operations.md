## 题目描述

给定整数数组 `nums`，可以对数组元素执行以下操作：
- 选择任意一个子数组 `[l, r]`，将该范围内所有元素与某个值 `x` 进行按位与（AND），使得该范围的 OR（按位或）最大化。

求经过若干次操作后，数组所有元素按位或（OR）的最大值。

（本题为简化版：求数组中选若干元素进行 OR 运算的最大值，每次操作可将某段元素与某常数 AND）

**示例 1：**
```
输入：nums = [3,2,1]
输出：3
解释：3 = 011，2 = 010，1 = 001，OR 最大为 3。
```

**示例 2：**
```
输入：nums = [7,12,9]
输出：15
解释：7=0111, 12=1100, 9=1001，OR 为 7|12|9 = 15。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

对于"选子数组 AND 后最大化 OR"类问题，核心思路是：

通过对子数组中元素做 AND 操作，可以将该范围的 OR 等效地扩展某些位。

**贪心/DP 思路：**
- 遍历所有可能的子数组，对每个子数组计算连续 AND 的前缀，将结果累入全局 OR。
- 用滑动窗口维护不同 AND 值的集合（最多 log(max_val) 种），求其 OR 的最大值。

**核心：** 对任意子数组 `[l..r]`，其 AND 值集合大小为 O(log max_val)，可以用集合迭代更新。

## Python 代码实现

### 方法一：滑动窗口维护 AND 集合（推荐）

```python
from typing import List

class Solution:
    def maxValue(self, nums: List[int]) -> int:
        # 对每个右端点，维护所有以该点结尾的子数组的 AND 值集合
        # 由于 AND 只会让位数减少，集合大小 O(log max_val)
        ans = 0
        # cur_set: 以当前位置结尾的所有子数组的 AND 值集合
        cur_set = set()

        for x in nums:
            # 新集合：当前元素本身，以及之前所有子数组 AND 上当前元素
            new_set = {x}
            for prev in cur_set:
                new_set.add(prev & x)
            cur_set = new_set

            # 统计当前所有 AND 值的最大 OR 贡献
            for v in cur_set:
                ans |= v

        return ans
```

### 方法二：枚举（O(n^2)，适合小数组）

```python
from typing import List

class Solution:
    def maxValue(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0

        for l in range(n):
            cur_and = nums[l]
            for r in range(l, n):
                cur_and &= nums[r]
                ans |= cur_and

        return ans
```

## 复杂度分析

- 时间复杂度：方法一 O(n log max_val)，每个位置的 AND 集合大小为 O(log max_val)
- 空间复杂度：O(log max_val)

## 关键点总结

1. 子数组 AND 值的集合随右端点移动时，大小不超过 O(log max_val)（每次 AND 至少少一个 1 位）
2. 所有可能的子数组 AND 值的总 OR 即为答案
3. 滑动窗口维护 AND 集合是处理"子数组 AND"问题的标准方法

## 易错点

1. AND 集合需要包含单元素本身（子数组长度为 1）
2. 每步更新时用新集合替换，不要直接修改旧集合
