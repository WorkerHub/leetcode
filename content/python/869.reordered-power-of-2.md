## 题目描述

给定正整数 n ，我们按任何顺序（包括原始顺序）将数字重新排序，注意其前导数字不能为零。

如果我们可以通过上述方式得到 2 的幂，返回 true；否则，返回 false。

**示例 1：**
```
输入：n = 1
输出：true
```

**示例 2：**
```
输入：n = 10
输出：false
```

**提示：**
- 1 <= n <= 10^9

## 解题思路

**关键观察：**
- 2 的幂最多到 2^29（10^9 范围内）
- 检查 n 的数字计数是否与某个 2 的幂相同

## Python 代码实现

### 方法一：计数比较（推荐）⭐

```python
class Solution:
    def reorderedPowerOf2(self, n: int) -> bool:
        from collections import Counter
        
        count_n = Counter(str(n))
        
        # 检查所有 2 的幂（10^9 范围内）
        for i in range(30):
            if Counter(str(1 << i)) == count_n:
                return True
        
        return False
```

### 方法二：排序比较

```python
class Solution:
    def reorderedPowerOf2(self, n: int) -> bool:
        sorted_n = sorted(str(n))
        
        for i in range(30):
            if sorted(str(1 << i)) == sorted_n:
                return True
        
        return False
```

## 复杂度分析

- **时间复杂度**：O(log²n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **计数比较**：使用 Counter 比较数字出现次数
2. **范围确定**：2^30 > 10^9，最多检查 30 个
3. **排序技巧**：排序后比较也可以
