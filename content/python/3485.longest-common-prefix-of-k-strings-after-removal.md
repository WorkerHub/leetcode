## 题目描述

给你一个字符串数组 `words` 和一个整数 `k`。

对于每个下标 i，从 `words` 中删除 `words[i]` 后，返回剩余字符串中出现次数最多（即在至少 k 个字符串中出现）的最长公共前缀的长度。

返回一个数组 `answer`，`answer[i]` 是删除 `words[i]` 后的结果。

**示例：**

```
输入：words = ["jump","run","run","jump","run"], k = 2
输出：[3,4,4,3,4]
```

**提示：**
- `1 <= words.length <= 10^5`
- `1 <= k <= words.length`
- `1 <= words[i].length <= 10^4`

## 解题思路

字典树（Trie）：在 Trie 中插入所有单词，每个节点维护通过该节点的单词数。

删除 words[i] 后，某个前缀的"深度"（满足 count >= k 的最深节点深度）可能减少。

具体：
1. 建 Trie，每个节点存 count（通过该节点的单词数）
2. 对每个 i，从 Trie 中临时删除 words[i]（count - 1），重新查询最长公共前缀深度

## Python 代码实现

### 方法一：Trie + 计数（推荐）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.count = 0  # 经过此节点的单词数

class Solution:
    def longestCommonPrefix(self, words: List[str], k: int) -> List[int]:
        root = TrieNode()

        def insert(word):
            node = root
            for c in word:
                if c not in node.children:
                    node.children[c] = TrieNode()
                node = node.children[c]
                node.count += 1

        def remove(word):
            node = root
            for c in word:
                node = node.children[c]
                node.count -= 1

        def query(k_val):
            """返回出现次数 >= k_val 的最长公共前缀长度"""
            node = root
            depth = 0
            while node.children:
                # 找唯一一个 count >= k_val 的子节点
                found = None
                for c, child in node.children.items():
                    if child.count >= k_val:
                        found = child
                        break
                if found is None:
                    break
                # 如果有多个满足条件的子节点，前缀不唯一，停止
                cnt = sum(1 for c, child in node.children.items() if child.count >= k_val)
                if cnt > 1:
                    break
                node = found
                depth += 1
            return depth

        # 插入所有单词
        for w in words:
            insert(w)

        answer = []
        for w in words:
            remove(w)
            answer.append(query(k))
            insert(w)  # 恢复

        return answer
```

### 方法二：预计算 + 差分优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestCommonPrefix(self, words: List[str], k: int) -> List[int]:
        n = len(words)

        # 统计每个前缀出现次数
        prefix_count = defaultdict(int)
        for w in words:
            for length in range(1, len(w) + 1):
                prefix_count[w[:length]] += 1

        # 对每个 i，删除 words[i] 后，其所有前缀 count - 1
        # 找最长的 prefix 使得 count >= k

        def max_prefix_len_after_remove(i):
            w = words[i]
            max_len = 0
            for length in range(1, len(w) + 1):
                p = w[:length]
                cnt = prefix_count[p] - 1  # 删除 w 后
                if cnt >= k:
                    # 还需要检查这个前缀是否是"最长公共前缀"的延伸
                    max_len = length
                else:
                    break
            return max_len

        # 全局最长公共前缀（不删除时）
        # 对每个 i，最长公共前缀要么缩短，要么不变

        # 先找全局最长公共前缀路径
        # 对 words[i]，检查其前缀是否决定了全局最长公共前缀

        answer = []
        for i in range(n):
            answer.append(max_prefix_len_after_remove(i))

        return answer
```

### 方法三：Trie 优化（避免重复恢复）

```python
from typing import List

class Solution:
    def longestCommonPrefix(self, words: List[str], k: int) -> List[int]:
        # 建 Trie
        trie = {}
        count = {}

        def insert(word):
            node = trie
            path = []
            for c in word:
                if c not in node:
                    node[c] = {}
                node = node[c]
                key = id(node)
                count[key] = count.get(key, 0) + 1
                path.append(key)
            return path

        def get_lcp(k_val):
            node = trie
            depth = 0
            while True:
                valid = [(c, child) for c, child in node.items()
                         if count.get(id(child), 0) >= k_val]
                if len(valid) != 1:
                    break
                node = valid[0][1]
                depth += 1
            return depth

        paths = []
        for w in words:
            paths.append(insert(w))

        answer = []
        for i, w in enumerate(words):
            # 临时减少 words[i] 路径上的计数
            for key in paths[i]:
                count[key] -= 1
            answer.append(get_lcp(k))
            for key in paths[i]:
                count[key] += 1

        return answer
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为单词数，L 为最长单词长度
- 空间复杂度：O(n * L)，Trie 存储空间

## 关键点总结

1. Trie 节点维护经过该节点的单词数 count
2. 删除操作：将 words[i] 路径上所有节点的 count - 1
3. 查询：从根出发，找唯一 count >= k 的路径深度

## 易错点

1. 查询时若某节点有多个子节点的 count >= k，公共前缀分叉，停止
2. 删除后要恢复，避免影响后续查询
3. count >= k（至少 k 个），不是恰好 k 个
