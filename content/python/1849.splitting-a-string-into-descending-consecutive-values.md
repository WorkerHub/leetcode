## 题目描述

给你一个仅含数字的字符串 `s`，请你将它分割成若干**子字符串**，使得每个子字符串对应的整数值比前一个子字符串的整数值恰好大 1 且满足严格递减（即每个子字符串的值比前一个小 1）。

返回是否可以完成这样的分割，并且需要至少 3 个子字符串。

**注意：** 前导零也是有效的（如 "050" 合法）。

**示例 1：**
```
输入：s = "1234579"
输出：false
```

**示例 2：**
```
输入：s = "050043"
输出：true
解释：s = "05" + "004" + "3"，值分别为 5, 4, 3
```

**提示：**
- `1 <= s.length <= 20`

## 解题思路

**回溯**：尝试枚举第一段的切割位置，确定第一个数值后，递归判断剩余字符串能否切割为连续递减的序列（每次减 1）。

由于字符串最长 20 位，数值最大为 10^20，需要用 int（Python 自动支持大整数）。

优化：若当前期望的下一个值 <= 0，则无法继续；若剩余字符串全部作为下一个数且等于期望值，则成功。

## 代码实现

### 方法一：回溯枚举（推荐）

```python
class Solution:
    def splitString(self, s: str) -> bool:
        def backtrack(index: int, prev: int, count: int) -> bool:
            """
            index: 当前处理到的位置
            prev: 上一个数值
            count: 已切割的子字符串数量
            """
            if index == len(s):
                return count >= 3  # 至少 3 个子字符串

            for end in range(index + 1, len(s) + 1):
                curr = int(s[index:end])
                if curr == prev - 1:
                    # 当前值比上一个恰好小 1，继续
                    if backtrack(end, curr, count + 1):
                        return True
                elif curr < prev - 1:
                    # 当前值已经太小，后续值只会更小（数字前缀越长值越大）
                    break
            return False

        n = len(s)
        # 枚举第一个子字符串的结束位置
        for first_end in range(1, n):
            first_val = int(s[:first_end])
            if backtrack(first_end, first_val + 1, 1):
                return True
        return False
```

### 方法二：DFS 精简版

```python
class Solution:
    def splitString(self, s: str) -> bool:
        def dfs(i: int, prev: int, cnt: int) -> bool:
            if i == len(s):
                return cnt >= 3
            # 当前值最多取剩余所有字符（避免太长导致值过大）
            for j in range(i + 1, len(s) + 1):
                val = int(s[i:j])
                if val == prev - 1:
                    if dfs(j, val, cnt + 1):
                        return True
                elif val < prev - 1:
                    break
            return False

        for i in range(1, len(s)):
            if dfs(i, int(s[:i]) + 1, 1):
                return True
        return False
```

## 复杂度分析

- **时间复杂度**：O(n^2)，每次回溯最多枚举 O(n) 种切割方式，深度最多 n
- **空间复杂度**：O(n)，递归栈深度

## 关键点总结

1. 确定第一个数后，后续每个数固定为前一个减 1，只需判断能否匹配
2. 当前值 < 期望值时可以 break（随着字符串末尾延伸，值只会增大）
3. 至少需要 3 个子字符串

## 易错点

- 不是严格递减，而是每次恰好减 1
- Python int 支持任意大整数，无需担心溢出
- 最后一段可以到字符串末尾，end 的范围是 `range(index+1, len(s)+1)`
