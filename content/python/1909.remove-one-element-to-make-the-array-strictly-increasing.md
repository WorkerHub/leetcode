## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，如果 **恰好删除一个** 元素后，剩余元素能构成一个**严格递增**的数组，则返回 `true`；否则返回 `false`。如果数组本身已经是严格递增的，则无需删除任何元素，直接返回 `true`。

**示例 1：**
```
输入：nums = [1, 2, 10, 5, 7]
输出：true
解释：删除 nums[2] = 10，剩余 [1, 2, 5, 7] 严格递增
```

**示例 2：**
```
输入：nums = [2, 3, 1, 2]
输出：false
```

**示例 3：**
```
输入：nums = [1, 1, 1]
输出：false
```

**提示：**
- `2 <= nums.length <= 10^3`
- `1 <= nums[i] <= 10^3`

---

## 解题思路

### 核心思想：找到违规位置后尝试删除两种情况

遍历数组，找到第一个违反严格递增条件的位置 `i`（即 `nums[i] >= nums[i+1]`）。

此时只有两种可能的删除选择：
1. 删除索引 `i` 处的元素
2. 删除索引 `i+1` 处的元素

如果删除后任意一种结果使数组严格递增，返回 `true`。

若整个数组扫描完未发现违规，则直接返回 `true`。

## 代码实现

### 方法一：找违规位置 + 验证删除（推荐）

```python
from typing import List

class Solution:
    def canBeIncreasing(self, nums: List[int]) -> bool:

        def is_strictly_increasing(arr: List[int], skip: int) -> bool:
            """判断跳过 skip 位置后，数组是否严格递增"""
            prev = float('-inf')
            for i, x in enumerate(arr):
                if i == skip:
                    continue
                if x <= prev:
                    return False
                prev = x
            return True

        n = len(nums)
        # 找第一个违规位置
        for i in range(n - 1):
            if nums[i] >= nums[i + 1]:
                # 尝试删除 i 或 i+1
                return is_strictly_increasing(nums, i) or \
                       is_strictly_increasing(nums, i + 1)

        # 没有违规位置，原数组已严格递增
        return True
```

### 方法二：简洁双指针写法

```python
from typing import List

class Solution:
    def canBeIncreasing(self, nums: List[int]) -> bool:

        def check(skip: int) -> bool:
            """跳过 skip 索引，检验剩余数组是否严格递增"""
            prev = -1  # 上一个有效元素的索引
            for i in range(len(nums)):
                if i == skip:
                    continue
                if prev != -1 and nums[i] <= nums[prev]:
                    return False
                prev = i
            return True

        for i in range(len(nums) - 1):
            if nums[i] >= nums[i + 1]:
                return check(i) or check(i + 1)

        return True
```

### 方法三：暴力枚举（对比学习）

```python
from typing import List

class Solution:
    def canBeIncreasing(self, nums: List[int]) -> bool:
        n = len(nums)

        def is_increasing_without(skip: int) -> bool:
            # 构造删除指定元素后的新数组并判断
            arr = [nums[j] for j in range(n) if j != skip]
            return all(arr[k] < arr[k + 1] for k in range(len(arr) - 1))

        for i in range(n):
            if is_increasing_without(i):
                return True
        return False
```

## 关键点总结

1. 最多只会出现一个"违规位置"，找到后只需验证两种删除方案
2. 无需真正删除元素，用 `skip` 参数跳过对应索引即可
3. 若数组本身无违规位置，直接返回 `true`

---

## 易错点

- 找到第一个违规位置 `i` 后，应尝试删除 `i` 和 `i+1` 两个位置，不能只删一个
- 注意循环找到违规位置后立即 `return`，不要继续扫描（因为已经最多删一个）
