## 题目描述

给你一个字符串 `s`，每次操作可以将字符串的第一个字符或最后一个字符删除。

返回使字符串第一个字符和最后一个字符相等所需的最少操作次数。如果已相等则返回 0。

**示例 1：**

```
输入：s = "abca"
输出：0
解释：s[0]='a' == s[-1]='a'，无需操作。
```

**示例 2：**

```
输入：s = "abcd"
输出：2
解释：删除 'd'：s="abc"，首='a' != 末='c'；
再删除 'a'：s="bc"，首='b' != 末='c'；
或删除 'd' 再删除 'c'：s="ab"，首='a' != 末='b'...
删除 'd'：s="abc"，再删除 'c'：s="ab"，a!=b（2次）；
删除 'a'：s="bcd"，再删除 'd'：s="bc"，b!=c（2次）；
删除 'd' 再删除 'a'... 难道最少要 3 次？
```

**提示：**
- `2 <= s.length <= 100`
- `s` 仅由小写英文字母组成

## 解题思路

双指针：
1. 若 `s[left] == s[right]`，返回操作次数。
2. 否则，可以删除 left 端（操作数 +1，left++）或 right 端（操作数 +1，right--）。
3. 贪心：比较 `s[left+1] == s[right]` 和 `s[left] == s[right-1]`，选代价小的。

实际上，枚举所有可能的 (left, right) 找最小操作数。

## Python 代码实现

### 方法一：枚举（推荐）

```python
class Solution:
    def minOperations(self, s: str) -> int:
        n = len(s)
        # 枚举最终的 (left, right) 使 s[left] == s[right]，最小化 left + (n-1-right)
        ans = n  # 最坏情况：删到只剩 1 个字符

        for left in range(n):
            for right in range(left + 1, n):  # left < right 保证至少 2 个字符
                if s[left] == s[right]:
                    ops = left + (n - 1 - right)  # 删除前 left 个和后 (n-1-right) 个
                    ans = min(ans, ops)

        # 若字符串只剩 1 个字符（left == right-1 且中间没有相等的对）
        # 最少操作 = n - 1（删到 1 个字符）？不对，单字符首末相同
        # 特殊情况：字符串长度 1 时首 = 末
        ans = min(ans, n - 1)  # 删到只剩 1 个字符，操作 n-1 次

        return ans
```

### 方法二：双指针贪心

```python
class Solution:
    def minOperations(self, s: str) -> int:
        left, right = 0, len(s) - 1
        ops = 0

        while left < right and s[left] != s[right]:
            # 删左或删右，选使之后更快收敛的方案
            if s[left + 1] == s[right] or (left + 1 < right and s[left + 1] != s[right - 1]):
                # 删左端
                left += 1
            else:
                # 删右端
                right -= 1
            ops += 1

        return ops if left < right else ops + 1
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一）；O(n)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 最终需要找一对 `(left, right)` 使 `s[left] == s[right]`，操作数 = left + (n-1-right)。
2. 枚举所有合法 (left, right) 取最小操作数。
3. 特殊情况：只剩 1 个字符时首尾相同，代价 n-1。

## 易错点

1. 必须保证 left < right（至少 2 个字符时才有首末的区别）。
2. 只剩 1 个字符时也满足条件（n-1 次操作）。
