## 题目描述

给你一个整数数组 `team`（只含 `0` 和 `1`）和整数 `dist`。

数组表示站成一排的人，`0` 表示"鬼"，`1` 表示"人"。

每个"鬼"可以抓住**一个**距离不超过 `dist` 的"人"（即 `|i - j| <= dist`），且每个"人"只能被一个"鬼"抓住。

返回"鬼"最多能抓住几个"人"。

**示例 1：**
```
输入：team = [0,1,0,1,0], dist = 3
输出：2
```

**示例 2：**
```
输入：team = [1], dist = 1
输出：0
```

**提示：**
- `1 <= team.length <= 10^5`
- `0 <= dist <= team.length`

---

## 解题思路

### 核心思想：贪心双指针

将"鬼"和"人"的位置分别提取，用双指针贪心：
- 指针 `g` 指向当前"鬼"，指针 `p` 指向当前"人"
- 若 `|ghost[g] - person[p]| <= dist`，则配对，两指针都向前移动
- 否则，位置较小的一方前进（跳过无法配对的元素）

## 代码实现

### 方法一：贪心双指针（推荐）

```python
from typing import List

class Solution:
    def catchMaximumAmountofPeople(self, team: List[int], dist: int) -> int:
        ghosts = [i for i, x in enumerate(team) if x == 0]
        persons = [i for i, x in enumerate(team) if x == 1]

        count = 0
        g = p = 0  # 双指针

        while g < len(ghosts) and p < len(persons):
            if abs(ghosts[g] - persons[p]) <= dist:
                # 配对成功
                count += 1
                g += 1
                p += 1
            elif ghosts[g] < persons[p]:
                # 鬼的位置更靠左，后面的人只会更远
                g += 1
            else:
                # 人的位置更靠左，后面的鬼只会更远
                p += 1

        return count
```

### 方法二：同上，更详细的注释版

```python
from typing import List

class Solution:
    def catchMaximumAmountofPeople(self, team: List[int], dist: int) -> int:
        # 分别提取鬼和人的位置索引
        ghosts = []
        persons = []
        for i, v in enumerate(team):
            if v == 0:
                ghosts.append(i)
            else:
                persons.append(i)

        result = 0
        gi, pi = 0, 0

        while gi < len(ghosts) and pi < len(persons):
            g_pos = ghosts[gi]
            p_pos = persons[pi]

            if abs(g_pos - p_pos) <= dist:
                # 鬼 gi 抓住 人 pi
                result += 1
                gi += 1
                pi += 1
            elif g_pos < p_pos:
                # 鬼在人的左边太远，当前鬼无法抓后面的人，移动鬼指针
                gi += 1
            else:
                # 人在鬼的左边太远，当前人无法被后面的鬼抓，移动人指针
                pi += 1

        return result
```

## 关键点总结

1. 提取位置后用双指针贪心，最优配对时使用最近的可用"人"
2. 当前鬼（或人）位置更小且差距超 dist，则该鬼（或人）只能跳过
3. 贪心正确性：就近配对不会错过更优方案

---

## 易错点

- 条件 `abs(g - p) <= dist`，注意是 `<=`（不是 `<`）
- 两种"跳过"方向要分清：鬼太靠左跳过鬼，人太靠左跳过人
