## 题目描述

一个程序最初打算将一个正整数数组保存到一个字符串中，每个整数之间用逗号分隔，但忘记添加逗号了。

给你一个数字字符串 `s` 和一个整数 `k`，请你返回**所有**可能的将字符串 `s` 恢复成一个数组的方案数，满足：

- 数组中每个元素的值在 `[1, k]` 范围内
- 数组中每个元素都不含前导零（即数字不能以 '0' 开头，除非数字本身就是 0，但本题要求值在 [1,k] 内，所以 0 不合法）

答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：s = "1000", k = 10000
输出：1
解释：唯一的方案是 [1000]
```

**示例 2：**

```
输入：s = "1000", k = 10
输出：0
解释：无法将 "1000" 恢复为元素 <= 10 的数组（1000 > 10，而 [1, 0, 0, 0] 和 [10, 00] 含有前导零或 0）
```

**示例 3：**

```
输入：s = "1317", k = 2000
输出：8
解释：可能的方案有 [1317],[131,7],[13,17],[13,1,7],[1,317],[1,31,7],[1,3,17],[1,3,1,7]
```

**提示：**

- `1 <= k <= 10^9`
- `1 <= s.length <= 10^5`

## 解题思路

### 动态规划

定义 `dp[i]` 表示将前 `i` 个字符（`s[0..i-1]`）完整分割为合法数组的方案数。

**初始状态：** `dp[0] = 1`（空字符串对应空数组，1 种方案）

**状态转移：** 对于位置 `i`（1-indexed），枚举最后一个数字是 `s[j..i-1]`（即从位置 `j` 到 `i-1`）：
- 若 `s[j] == '0'`，跳过（前导零不合法）
- 若 `int(s[j..i-1]) > k`，跳过（超出范围）
- 若 `int(s[j..i-1]) >= 1`，则 `dp[i] += dp[j]`

**优化剪枝：**

1. `k` 最多 10 位，所以最后一个数字的长度最多为 `len(str(k))`，无需从 0 枚举到 i
2. 一旦 `int(s[j..i-1]) > k`，可以提前 break（因为继续往左扩展只会更大）

### 转移方向优化

由于 `k <= 10^9`（最多 10 位数字），每次最多往前看 10 位，所以总时间复杂度为 O(n * log10(k))。

## Python 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        MOD = 10**9 + 7
        n = len(s)
        # dp[i]：将 s[0..i-1] 分割为合法数组的方案数
        dp = [0] * (n + 1)
        dp[0] = 1  # 空字符串，1 种方案

        # k 的位数，决定最后一个数字的最大长度
        max_len = len(str(k))

        for i in range(1, n + 1):
            # 枚举最后一个数字 s[j..i-1]，其长度为 i-j
            for length in range(1, min(max_len, i) + 1):
                j = i - length  # 最后一个数字的起始位置
                segment = s[j:i]

                # 不允许前导零（数字不能以 '0' 开头）
                if segment[0] == '0':
                    break  # 更短的长度也会有前导零（因为 j 更大，s[j]='0'）
                    # 注意：这里 break 是因为我们从长到短枚举，前导零说明这段无效
                    # 实际上应该 continue，因为更短的长度 s[j'] 不一定是 '0'
                    # 重新思考：我们从 length=1 到 max_len，j 从大到小
                    # s[j]='0' 意味着这段有前导零，continue 跳过

                # 实际上应该用 continue，因为不同长度对应不同的 j（起始位置）
                # 一旦 s[j]='0'，这种 length 不合法，但其他 length 可能合法

                # 检查数值范围
                num = int(segment)
                if num < 1 or num > k:
                    # num > k：继续增大 length 数值只会更大，可以 break
                    if num > k:
                        break
                    continue  # num < 1 不可能（因为已排除前导零且 segment 非空）

                dp[i] = (dp[i] + dp[j]) % MOD

        return dp[n]
```

### 方法一（修正版，清晰逻辑）

```python
class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        MOD = 10**9 + 7
        n = len(s)
        dp = [0] * (n + 1)
        dp[0] = 1

        # k 的字符串长度，最后一个数字不超过这么多位
        max_digits = len(str(k))

        for i in range(1, n + 1):
            # 从 i 向左枚举，最后一个数字的长度从 1 到 max_digits
            for length in range(1, min(max_digits, i) + 1):
                j = i - length
                # 检查前导零
                if s[j] == '0':
                    # 这个 length 对应的数字有前导零，不合法
                    # 但注意：只有当 length > 1 时才算前导零
                    # length == 1 时，s[j] = '0'，数值为 0，不在 [1,k] 内，也不合法
                    continue

                # 将字符串转换为整数
                num = int(s[j:i])

                # 如果超出 k，更长的数字更大，直接 break
                if num > k:
                    break

                # num 在 [1, k] 内，累加方案数
                dp[i] = (dp[i] + dp[j]) % MOD

        return dp[n]
```

### 方法二：记忆化递归（自顶向下）

```python
from functools import lru_cache

class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        MOD = 10**9 + 7
        n = len(s)
        max_digits = len(str(k))

        @lru_cache(maxsize=None)
        def dp(i: int) -> int:
            """返回将 s[i..n-1] 分割为合法数组的方案数"""
            if i == n:
                return 1  # 已到达字符串末尾，找到一种方案

            result = 0
            # 枚举从位置 i 开始的数字，长度为 1 到 max_digits
            for length in range(1, min(max_digits, n - i) + 1):
                j = i + length
                segment = s[i:j]

                # 前导零检查
                if segment[0] == '0':
                    continue

                num = int(segment)
                if num > k:
                    break  # 更长只会更大

                result = (result + dp(j)) % MOD

            return result

        return dp(0)
```

## 复杂度分析

设 `n = len(s)`，`D = len(str(k))`（k 的位数，最多 10）。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n * D) | O(n) |
| 记忆化递归 | O(n * D) | O(n) |

## 图解示例

以 `s = "1317", k = 2000` 为例：

```
dp[0] = 1（空字符串）
dp[1]：s[0:1]="1"，1 in [1,2000]，dp[1] += dp[0] = 1
dp[2]：s[1:2]="3"，dp[2]+=dp[1]=1；s[0:2]="13"，dp[2]+=dp[0]=1；dp[2]=2
dp[3]：s[2:3]="1"，+=dp[2]=2；s[1:3]="31"，+=dp[1]=1；s[0:3]="131"，+=dp[0]=1；dp[3]=4
dp[4]：s[3:4]="7"，+=dp[3]=4；s[2:4]="17"，+=dp[2]=2；s[1:4]="317"，+=dp[1]=1；s[0:4]="1317"，+=dp[0]=1；dp[4]=8
```

答案 `dp[4] = 8` ✓

## 关键点总结

1. `dp[i]` 定义为前 `i` 个字符的分割方案数，`dp[0] = 1`
2. 枚举最后一个数字时，最多往前看 `len(str(k))` 位
3. 遇到前导零直接 `continue`
4. 遇到数值超过 k 直接 `break`（更长的数字一定更大）
5. 每步取模防溢出

## 易错点

1. `break` 和 `continue` 的使用：超出 k 用 `break`，前导零用 `continue`
2. `dp[0] = 1` 的意义：空字符串对应 1 种方案（空数组）
3. 数字不能有前导零，但 `s[j]='0'` 且 length=1 时，数值为 0，也不在 [1,k] 内
