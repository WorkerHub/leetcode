## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，如果一个子数组中 **相等** 元素对的数目 >= `k`，则该子数组是 **好子数组**。

返回 `nums` 中好子数组的数目。

注意，两个元素 `nums[i]` 和 `nums[j]` 构成一对，当且仅当 `i != j` 且 `nums[i] == nums[j]`，不要求 `i < j`。

**示例 1：**

```
输入：nums = [1,1,1,1,1], k = 10
输出：1
解释：唯一的好子数组是整个数组，相等对数 = C(5,2) = 10。
```

**示例 2：**

```
输入：nums = [3,1,4,3,2,2,4], k = 2
输出：4
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

**滑动窗口（双指针）**：

维护窗口 [left, right] 内的相等对数 `pairs`。

右端加入 nums[right]（其在窗口内已有 cnt 个相同元素）：`pairs += cnt`。

若 `pairs >= k`，则 [left, right] 及所有包含它的子数组（即 left 向右移动更少的位置）都是好子数组，统计 `left` 可以移动的范围。

移动左端：减少 nums[left] 的计数，`pairs -= cnt - 1`，左移直到 `pairs < k`，统计答案。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGood(self, nums: List[int], k: int) -> int:
        n = len(nums)
        freq = defaultdict(int)
        pairs = 0
        ans = 0
        left = 0

        for right in range(n):
            # 加入 nums[right]，新增对数等于当前窗口内相同元素的数量
            pairs += freq[nums[right]]
            freq[nums[right]] += 1

            # 当 pairs >= k 时，[left, right] 是好子数组
            # 且 [0, right], [1, right], ..., [left, right] 都可能是好子数组
            # 移动左端，直到 pairs < k，统计此时 left 左边的所有子数组
            while pairs >= k:
                freq[nums[left]] -= 1
                pairs -= freq[nums[left]]
                left += 1

            # left 是使 pairs < k 的最左位置
            # [0, right], [1, right], ..., [left-1, right] 都是好子数组
            ans += left

        return ans
```

### 方法二：暴力 O(n²)（用于验证）

```python
from typing import List
from collections import Counter

class Solution:
    def countGood(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            cnt = Counter()
            pairs = 0
            for j in range(i, n):
                pairs += cnt[nums[j]]
                cnt[nums[j]] += 1
                if pairs >= k:
                    ans += 1
        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(n)，双指针各最多移动 n 次
- 方法二时间复杂度：O(n²)
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 添加元素时，新增的对数等于窗口内已有相同元素数
2. 移除元素时，减少的对数等于移除后窗口内剩余相同元素数
3. 当 pairs >= k 时，左端 [0..left-1] 开头的子数组都满足条件

## 易错点

1. 统计的是有序对（i < j），但由于对称性，与无序对数量相同
2. 移动左端时，先减少计数再更新 pairs（注意操作顺序）
3. `ans += left` 统计的是以 right 结尾的好子数组数目
