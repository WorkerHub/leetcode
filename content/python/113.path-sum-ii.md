## 题目描述

给你二叉树的根节点 `root` 和一个整数目标和 `targetSum`，找出所有从根节点到叶子节点路径总和等于给定目标和的路径。

**叶子节点**是指没有子节点的节点。

**示例 1：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]
```

**示例 2：**

```
输入：root = [1,2,3], targetSum = 5
输出：[]
```

**示例 3：**

```
输入：root = [1,2], targetSum = 0
输出：[]
```

**提示：**

- 树中节点总数在范围 `[0, 5000]` 内
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`

## 解题思路

这道题是第 112 题的进阶版，不仅要判断是否存在路径，还要找出所有满足条件的路径。

### 核心思路

这是一道典型的**回溯**问题：
1. 需要记录从根节点到当前节点的路径
2. 到达叶子节点时，判断路径和是否等于目标值
3. 如果满足条件，将路径加入结果集
4. 回溯时要恢复状态（移除当前节点）

### 关键要点

1. **路径记录**：使用列表记录当前路径上的所有节点值
2. **回溯操作**：递归返回前要移除当前节点（恢复状态）
3. **深拷贝**：加入结果集时要复制路径，不能直接引用
4. **叶子节点判断**：只在叶子节点处检查路径和

## Python 代码实现

### 方法一：DFS + 回溯（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        result = []  # 存储所有满足条件的路径
        path = []    # 当前路径
        
        def dfs(node: Optional[TreeNode], remaining: int) -> None:
            """
            DFS + 回溯
            node: 当前节点
            remaining: 剩余目标和（targetSum - 已访问节点的和）
            """
            if not node:
                return
            
            # 将当前节点加入路径
            path.append(node.val)
            remaining -= node.val
            
            # 到达叶子节点，检查路径和
            if not node.left and not node.right:
                if remaining == 0:
                    # 找到一条满足条件的路径，加入结果集
                    # 注意：要复制路径，不能直接引用
                    result.append(path[:])
            else:
                # 继续递归左右子树
                dfs(node.left, remaining)
                dfs(node.right, remaining)
            
            # 回溯：移除当前节点，恢复状态
            path.pop()
        
        dfs(root, targetSum)
        return result
```

### 方法二：DFS + 回溯（累加版本）

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        result = []
        path = []
        
        def dfs(node: Optional[TreeNode], current_sum: int) -> None:
            """
            current_sum: 当前路径和
            """
            if not node:
                return
            
            # 添加当前节点到路径
            path.append(node.val)
            current_sum += node.val
            
            # 叶子节点：检查路径和
            if not node.left and not node.right:
                if current_sum == targetSum:
                    result.append(path[:])
            
            # 递归遍历子树
            dfs(node.left, current_sum)
            dfs(node.right, current_sum)
            
            # 回溯
            path.pop()
        
        dfs(root, 0)
        return result
```

### 方法三：DFS（不显式回溯）

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        
        def dfs(node: Optional[TreeNode], remaining: int, path: List[int]) -> None:
            """
            每次递归传递新的路径列表，不需要显式回溯
            """
            # 叶子节点
            if not node.left and not node.right:
                if remaining == node.val:
                    result.append(path + [node.val])
                return
            
            # 递归左子树
            if node.left:
                dfs(node.left, remaining - node.val, path + [node.val])
            
            # 递归右子树
            if node.right:
                dfs(node.right, remaining - node.val, path + [node.val])
        
        dfs(root, targetSum, [])
        return result
```

### 方法四：BFS（层序遍历）

```python
from collections import deque

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        # 队列存储 (节点, 当前路径和, 当前路径)
        queue = deque([(root, root.val, [root.val])])
        
        while queue:
            node, current_sum, path = queue.popleft()
            
            # 叶子节点：检查路径和
            if not node.left and not node.right:
                if current_sum == targetSum:
                    result.append(path)
                continue
            
            # 左子树
            if node.left:
                queue.append((
                    node.left,
                    current_sum + node.left.val,
                    path + [node.left.val]
                ))
            
            # 右子树
            if node.right:
                queue.append((
                    node.right,
                    current_sum + node.right.val,
                    path + [node.right.val]
                ))
        
        return result
```

### 方法五：迭代 + 栈

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        # 栈存储 (节点, 剩余目标和, 当前路径)
        stack = [(root, targetSum - root.val, [root.val])]
        
        while stack:
            node, remaining, path = stack.pop()
            
            # 叶子节点
            if not node.left and not node.right:
                if remaining == 0:
                    result.append(path)
                continue
            
            # 右子树（先压栈，后访问）
            if node.right:
                stack.append((
                    node.right,
                    remaining - node.right.val,
                    path + [node.right.val]
                ))
            
            # 左子树（后压栈，先访问）
            if node.left:
                stack.append((
                    node.left,
                    remaining - node.left.val,
                    path + [node.left.val]
                ))
        
        return result
```

## 复杂度分析

### 方法一、二（DFS + 回溯）

- **时间复杂度**：O(n²)
  - 遍历所有节点：O(n)
  - 每次找到路径时复制路径：O(h)，h 为树高
  - 最坏情况下所有路径都满足条件：O(n²)
- **空间复杂度**：O(h)，递归调用栈和路径列表

### 方法三、四、五

- **时间复杂度**：O(n²)，同上
- **空间复杂度**：O(n)，每个节点都会创建新的路径列表

### 回溯过程详解：

```
dfs(5):
  path = [5]
  dfs(4):
    path = [5, 4]
    dfs(11):
      path = [5, 4, 11]
      dfs(7):
        path = [5, 4, 11, 7]  # 叶子节点，sum != 22
        path.pop() -> [5, 4, 11]  # 回溯
      dfs(2):
        path = [5, 4, 11, 2]  # 叶子节点，sum == 22，加入结果
        path.pop() -> [5, 4, 11]  # 回溯
      path.pop() -> [5, 4]  # 回溯
    path.pop() -> [5]  # 回溯
  dfs(8):
    ... 类似过程
```

## 关键点总结

1. **回溯模板**：添加节点 -> 递归 -> 移除节点，这是回溯的标准模板
2. **深拷贝路径**：`result.append(path[:])` 或 `result.append(list(path))`
3. **叶子节点判断**：只在叶子节点处检查和添加路径
4. **路径构建方式**：
   - 方法一、二：使用全局 path，需要回溯
   - 方法三：传递新列表，不需要回溯（但空间开销大）
5. **DFS vs BFS**：DFS 更自然，BFS 也可以但代码更复杂

## 易错点

1. **忘记深拷贝**：
   ```python
   # 错误：直接引用 path
   result.append(path)  # 所有路径都会变成最后一条
   
   # 正确：复制路径
   result.append(path[:])
   ```

2. **忘记回溯**：
   ```python
   # 错误：没有 pop 操作
   path.append(node.val)
   dfs(node.left)
   dfs(node.right)
   # 缺少 path.pop()
   
   # 正确：
   path.append(node.val)
   dfs(node.left)
   dfs(node.right)
   path.pop()  # 回溯
   ```

3. **在非叶子节点处添加路径**：
   ```python
   # 错误：在任意节点处检查
   if current_sum == targetSum:
       result.append(path[:])
   
   # 正确：只在叶子节点处检查
   if not node.left and not node.right:
       if current_sum == targetSum:
           result.append(path[:])
   ```

4. **路径为空的情况**：要检查 `node` 是否为 `None`

5. **空树处理**：空树应返回空列表 `[]` 而不是 `[[]]`
