## 题目描述

给你一个字符串数组 `words`，每个字符串仅包含小写字母，且每个字符串中**每个字母最多出现一次**。

如果两个字符串满足以下条件之一，则它们可以**加入同一个组**：

- 它们的字符集完全相同。
- 一个字符串可以通过**替换一个字符**（不能是已有字母）得到另一个，或通过**添加/删除一个字符**得到另一个。

两个字符串**在同一组**当且仅当存在一系列操作可以从一个得到另一个（传递性）。

返回数组：`[groups_count, max_group_size]`。

**提示：**
- `1 <= words.length <= 2 * 10^4`
- `1 <= words[i].length <= 26`
- `words[i]` 中每个字母最多出现一次

## 解题思路

**位运算 + 并查集**

将每个字符串用 26 位掩码表示（每位表示对应字母是否出现）。

两个字符串在同一组，当且仅当它们的掩码满足以下之一：
1. **相同**（完全相同的字符集）。
2. **相差一位**（一个是另一个的子集，相差 1 个字符 → 添加/删除）。
3. **交换一位**（一个清掉一位，另一个加上一位，总位数相同 → 替换）。

条件 2：`popcount(mask1 XOR mask2) == 1`。
条件 3：`popcount(mask1 XOR mask2) == 2` 且 `popcount(mask1) == popcount(mask2)`。

用哈希表 `{mask: words_index}` 存储已出现的掩码。对每个字符串，枚举其掩码的所有"邻居"（加/删/替换一位），用并查集合并。

## 代码实现

### 方法一：并查集 + 位运算（推荐）

```python
from typing import List

class Solution:
    def groupStrings(self, words: List[str]) -> List[int]:
        # 并查集
        parent = list(range(len(words)))
        size = [1] * len(words)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return
            if size[px] < size[py]:
                px, py = py, px
            parent[py] = px
            size[px] += size[py]

        # 建立 mask -> 字符串下标的映射
        mask_to_idx = {}
        masks = []
        for i, word in enumerate(words):
            mask = 0
            for c in word:
                mask |= 1 << (ord(c) - ord('a'))
            masks.append(mask)
            if mask in mask_to_idx:
                union(i, mask_to_idx[mask])
            else:
                mask_to_idx[mask] = i

        for i, mask in enumerate(masks):
            # 枚举添加一位
            for bit in range(26):
                if not (mask >> bit & 1):
                    new_mask = mask | (1 << bit)
                    if new_mask in mask_to_idx:
                        union(i, mask_to_idx[new_mask])

            # 枚举删除一位
            for bit in range(26):
                if mask >> bit & 1:
                    new_mask = mask ^ (1 << bit)
                    if new_mask in mask_to_idx:
                        union(i, mask_to_idx[new_mask])

            # 枚举替换一位（删除一位再添加一位）
            for bit in range(26):
                if mask >> bit & 1:
                    removed = mask ^ (1 << bit)
                    for bit2 in range(26):
                        if not (removed >> bit2 & 1):
                            new_mask = removed | (1 << bit2)
                            if new_mask in mask_to_idx:
                                union(i, mask_to_idx[new_mask])

        # 统计组数和最大组大小
        group_sizes = {}
        for i in range(len(words)):
            root = find(i)
            group_sizes[root] = group_sizes.get(root, 0) + 1

        return [len(group_sizes), max(group_sizes.values())]
```

### 方法二：优化（减少枚举）

```python
from typing import List

class Solution:
    def groupStrings(self, words: List[str]) -> List[int]:
        parent = list(range(len(words)))
        rank = [0] * len(words)

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a, b):
            a, b = find(a), find(b)
            if a == b:
                return
            if rank[a] < rank[b]:
                a, b = b, a
            parent[b] = a
            if rank[a] == rank[b]:
                rank[a] += 1

        mask_map = {}
        masks = []
        for i, w in enumerate(words):
            m = sum(1 << (ord(c) - 97) for c in w)
            masks.append(m)
            if m in mask_map:
                union(i, mask_map[m])
            else:
                mask_map[m] = i

        for i, m in enumerate(masks):
            for b in range(26):
                # 删除/添加一位
                nm = m ^ (1 << b)
                if nm in mask_map:
                    union(i, mask_map[nm])
                # 替换：删除 b，添加另一位（用减法避免内循环）
                if m >> b & 1:
                    base = m ^ (1 << b)
                    for b2 in range(26):
                        if not (base >> b2 & 1):
                            nm2 = base | (1 << b2)
                            if nm2 in mask_map:
                                union(i, mask_map[nm2])

        from collections import Counter
        cnt = Counter(find(i) for i in range(len(words)))
        return [len(cnt), max(cnt.values())]
```

## 关键点总结

1. 字符串用位掩码表示（每个字母最多出现一次，恰好对应 26 位）。
2. 三种操作对应掩码变换：相同、差一位（添加/删除）、交换一位（替换）。
3. 并查集合并所有可连通的字符串。

## 易错点

- 枚举替换时，先删除一位，再枚举添加另一位（注意不能加在已有位上）。
- 同一掩码可能对应多个字符串，需要处理。
