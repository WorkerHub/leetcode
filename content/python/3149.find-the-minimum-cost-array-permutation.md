## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 是 `[0, n-1]` 的排列。

定义置换 `perm` 的 **花费** 为：`sum(abs(perm[i] - nums[perm[i-1]]) for i in range(n))`（下标循环，`perm[-1] = perm[n-1]`）。

返回花费最小的字典序最小的置换。

**提示：**
- `2 <= n <= 14`

## 解题思路

状压 DP：`dp[mask][last]` = 已选了 `mask` 中的元素，最后一个元素为 `last` 时的最小花费（不含与起点的连接花费）。

由于 `perm[0]` 固定为 0（字典序最小的约束），从 0 出发枚举所有排列。

最终答案加上从最后一个元素回到 0 的花费，即 `abs(0 - nums[last])`。

## Python 代码实现

### 方法一：状压 DP（推荐）

```python
from typing import List

class Solution:
    def findPermutation(self, nums: List[int]) -> List[int]:
        n = len(nums)
        INF = float('inf')

        # dp[mask][last] = 选了 mask 中的元素，最后一个是 last，的最小花费
        # 固定 perm[0] = 0
        dp = [[INF] * n for _ in range(1 << n)]
        dp[1][0] = 0  # 只选了 0，最后是 0，花费 0
        parent = [[-1] * n for _ in range(1 << n)]

        for mask in range(1, 1 << n):
            for last in range(n):
                if not (mask >> last & 1):
                    continue
                if dp[mask][last] == INF:
                    continue
                # 添加下一个元素 nxt
                for nxt in range(n):
                    if mask >> nxt & 1:
                        continue
                    new_mask = mask | (1 << nxt)
                    # 花费：|nxt - nums[last]|
                    cost = dp[mask][last] + abs(nxt - nums[last])
                    if cost < dp[new_mask][nxt]:
                        dp[new_mask][nxt] = cost
                        parent[new_mask][nxt] = last

        full = (1 << n) - 1
        # 找最小花费（加上回到起点的花费）
        min_cost = INF
        best_last = -1
        for last in range(n):
            total = dp[full][last] + abs(0 - nums[last])
            if total < min_cost:
                min_cost = total
                best_last = last

        # 回溯路径（字典序最小）
        path = []
        mask = full
        cur = best_last
        while cur != -1:
            path.append(cur)
            prev = parent[mask][cur]
            mask ^= (1 << cur)
            cur = prev
        path.reverse()
        return path
```

### 方法二：递归 + 记忆化

```python
from typing import List
from functools import lru_cache

class Solution:
    def findPermutation(self, nums: List[int]) -> List[int]:
        n = len(nums)

        @lru_cache(maxsize=None)
        def dp(mask: int, last: int) -> int:
            if mask == (1 << n) - 1:
                return abs(0 - nums[last])  # 回到起点
            res = float('inf')
            for nxt in range(n):
                if not (mask >> nxt & 1):
                    cost = abs(nxt - nums[last]) + dp(mask | (1 << nxt), nxt)
                    res = min(res, cost)
            return res

        # 重建路径
        path = [0]
        mask = 1
        last = 0
        while mask != (1 << n) - 1:
            best = float('inf')
            best_nxt = -1
            for nxt in range(n):
                if not (mask >> nxt & 1):
                    cost = abs(nxt - nums[last]) + dp(mask | (1 << nxt), nxt)
                    if cost < best or (cost == best and nxt < best_nxt):
                        best = cost
                        best_nxt = nxt
            path.append(best_nxt)
            mask |= (1 << best_nxt)
            last = best_nxt
        return path
```

## 复杂度分析

- 时间复杂度：O(2^n * n^2)
- 空间复杂度：O(2^n * n)

## 关键点总结

1. n <= 14，可以用状压 DP
2. 固定起点为 0（字典序最小）
3. 回溯路径时，相同花费选字典序最小的下一个元素

## 易错点

1. 花费包含最后一个元素到起点的花费（循环）
2. 字典序最小要在回溯路径时贪心选择
