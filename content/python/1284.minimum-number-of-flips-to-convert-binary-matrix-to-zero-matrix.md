## 题目描述

给你一个 `m x n` 的二进制矩阵 `mat`。

每一步，你可以选择一个单元格并将它**反转**（反转的意思是 0 变 1，1 变 0）。如果你反转了一个单元格，那么它的**上、下、左、右四个相邻单元格**也会同时被反转。

请你返回将矩阵 `mat` 转化为**全零矩阵**的**最少翻转次数**，如果无法转化，返回 `-1`。

**示例 1：**

```
输入：mat = [[0,0],[0,1]]
输出：3
解释：
一共有三种方法可以将矩阵转化为全零矩阵
翻转 (1,0): [[0,0],[1,0]] -> 翻转 (0,1): [[0,1],[1,1]] -> 翻转 (1,1): [[0,0],[0,0]]
```

**示例 2：**

```
输入：mat = [[0]]
输出：0
```

**示例 3：**

```
输入：mat = [[1,0,0],[1,0,0]]
输出：-1
解释：该矩阵无法转化为全零矩阵
```

**提示：**

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 3`
- `mat[i][j]` 是 0 或 1

---

## 解题思路

### 状态压缩 + BFS（广度优先搜索）

这道题的关键约束是：**矩阵最大只有 3×3=9 个单元格**。

**核心思想：将矩阵编码为整数（状态压缩），然后用 BFS 寻找最短路径。**

**为什么可以用 BFS？**
- 每一步翻转操作是"一步"，最终目标是到达"全零矩阵"。
- BFS 从初始状态出发，逐步扩展所有可能的下一状态，第一次到达全零状态时的步数即为最少翻转次数。
- 这本质上是在**状态图**中寻找最短路径。

**状态压缩：**
- m×n 的矩阵有 m*n 个格子，每格是 0 或 1。
- 可以用一个整数的若干位来表示矩阵：第 `i*n+j` 位表示位置 `(i,j)` 的值。
- 3×3 矩阵最多 9 位，整数最大为 2^9 - 1 = 511，状态空间极小。

**翻转操作的位运算实现：**
- 翻转某个单元格 `(i,j)` 及其邻居，就是将整数的对应位异或 1（XOR）。
- 对每个格子预计算"翻转掩码"（flip_mask）：该掩码中，格子 `(i,j)` 及其上下左右邻居对应的位均为 1。
- 翻转操作：`new_state = state XOR flip_mask`

**BFS 过程：**
1. 初始状态：将初始矩阵编码为整数。
2. 目标状态：0（全零矩阵）。
3. 每步操作：对 m*n 个格子逐一应用翻转掩码，得到所有可能的下一状态。
4. 用集合记录已访问状态，避免重复搜索。
5. 第一次到达状态 0 时返回步数；若 BFS 结束未到达，返回 -1。

## Python 代码实现

### 方法一：BFS + 状态压缩（推荐）

```python
from collections import deque
from typing import List

class Solution:
    def minFlips(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])

        # 将初始矩阵编码为整数
        # 第 i*n+j 位表示 mat[i][j]
        initial = 0
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 1:
                    initial |= (1 << (i * n + j))

        # 如果初始矩阵已经全零，直接返回 0
        if initial == 0:
            return 0

        # 预计算每个格子的翻转掩码
        # 翻转 (i,j) 会影响 (i,j) 本身及其上下左右
        flip_masks = []
        for i in range(m):
            for j in range(n):
                mask = 1 << (i * n + j)  # 格子 (i,j) 本身
                # 遍历四个方向
                for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n:
                        mask |= (1 << (ni * n + nj))  # 相邻格子
                flip_masks.append(mask)

        # BFS：从初始状态开始，寻找到达状态 0 的最短路径
        visited = {initial}
        queue = deque([(initial, 0)])  # (当前状态, 当前步数)

        while queue:
            state, steps = queue.popleft()

            # 尝试翻转每个格子
            for mask in flip_masks:
                new_state = state ^ mask  # 翻转操作：XOR

                if new_state == 0:
                    return steps + 1  # 到达全零状态

                if new_state not in visited:
                    visited.add(new_state)
                    queue.append((new_state, steps + 1))

        # BFS 结束未到达全零状态，返回 -1
        return -1
```

### 方法二：DFS + 最短路径（记忆化，用于对比）

```python
from typing import List

class Solution:
    def minFlips(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])

        # 将矩阵编码为整数
        def encode(matrix: List[List[int]]) -> int:
            state = 0
            for i in range(m):
                for j in range(n):
                    if matrix[i][j] == 1:
                        state |= (1 << (i * n + j))
            return state

        # 执行翻转操作，返回新状态
        def flip(state: int, pos: int) -> int:
            i, j = pos // n, pos % n
            mask = 1 << pos  # 当前格子
            for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    mask |= (1 << (ni * n + nj))
            return state ^ mask

        initial = encode(mat)

        if initial == 0:
            return 0

        # BFS（代码结构更清晰的写法）
        from collections import deque
        dist = {initial: 0}
        queue = deque([initial])

        while queue:
            state = queue.popleft()
            for pos in range(m * n):
                new_state = flip(state, pos)
                if new_state not in dist:
                    dist[new_state] = dist[state] + 1
                    if new_state == 0:
                        return dist[new_state]
                    queue.append(new_state)

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS + 状态压缩 | O(2^(m*n) * m*n) | O(2^(m*n)) |

- **状态总数**：最多 2^(m*n) 个，对于 3×3 矩阵为 2^9 = 512 个状态。
- **每个状态**：有 m*n 种翻转操作，即 9 次操作。
- **总时间**：O(512 * 9) ≈ O(4608)，极快。
- **空间**：存储 visited 集合和队列，最多 O(2^(m*n)) = O(512)。

即使在最坏情况下，这道题的状态空间非常小，BFS 可以高效解决。

**状态编码（位 0~3 对应格子 (0,0), (0,1), (1,0), (1,1)）：**

```
初始状态：mat[1][1]=1，对应位 3（1*2+1=3）
initial = 0b1000 = 8

目标状态：0b0000 = 0
```

**翻转掩码（2×2 矩阵）：**

```
flip_masks[0] (翻转(0,0))：影响(0,0),(0,1),(1,0) -> 0b0111 = 7
flip_masks[1] (翻转(0,1))：影响(0,1),(0,0),(1,1) -> 0b1011 = 11

flip_masks[3] (翻转(1,1))：影响(1,1),(0,1),(1,0) -> 0b1110 = 14
```

```
初始：queue=[(8,0)], visited={8}

步数=1，继续 BFS...（省略中间步骤）

```

## 关键点总结

1. **状态压缩**：用整数的二进制位表示矩阵状态，是处理"小规模矩阵"问题的经典技巧。
2. **BFS 求最短路**：当每步操作代价相同（均为 1）时，BFS 能保证第一次到达目标状态时的步数最少。
3. **翻转 = XOR**：对某位取反（0->1, 1->0）正好对应异或操作（XOR 1）。
4. **状态空间有限**：m,n<=3，矩阵最多 9 个格子，状态数最多 2^9=512，BFS 完全可行。
5. **预计算翻转掩码**：提前计算每个格子对应的掩码，避免在 BFS 中重复计算邻居。

---

## 易错点

1. **初始状态已为 0**：要在开始 BFS 之前检查，否则会直接进入循环。
2. **掩码计算**：翻转格子 `(i,j)` 时，掩码要包含 `(i,j)` 自身，不只是邻居！
3. **BFS vs DFS**：这里必须用 BFS（而非 DFS），因为需要找最少步数，DFS 只能找到一个可行解而非最优解。
4. **visited 集合的时机**：应在将状态加入队列时就标记为已访问，而不是在弹出时标记，否则同一状态可能被多次加入队列。
5. **n 的含义**：在状态压缩中，格子 `(i,j)` 对应的位是 `i*n+j`（`n` 是列数，不是行数）。
