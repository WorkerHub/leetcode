## 题目描述

学校的自助午餐提供圆形和方形的三明治，分别用数字 `0` 和 `1` 表示。所有学生站在一个队列里，每个学生要么喜欢圆形的，要么喜欢方形的。

餐厅里三明治的数量与学生的数量相同。所有三明治都放在一个**栈**里，每一轮：
- 如果队列最前面的学生**喜欢**栈顶的三明治，那么会拿走它并离开队列
- 否则，这名学生**不喜欢**栈顶三明治，他会离开队列的最前面并回到队尾

这个过程持续到队列里所有学生都不喜欢栈顶的三明治为止（此时没有人吃午餐了）。

返回无法吃午餐的学生数量。

**示例 1：**
```
输入：students = [1,1,0,0], sandwiches = [0,1,0,1]
输出：0
解释：
前两轮：学生1（喜欢1）在队首，但栈顶是0，学生轮到队尾
第三轮：学生0（喜欢0）喜欢栈顶0，拿走，队列变为[1,1,0]
以此类推，最终所有人都能吃到
```

**示例 2：**
```
输入：students = [1,1,1,0,0,1], sandwiches = [1,1,0,0,1,1]
输出：3
```

**提示：**
- `1 <= students.length, sandwiches.length <= 100`
- `students[i]` 为 `0` 或 `1`
- `sandwiches[i]` 为 `0` 或 `1`

## 解题思路

**关键观察：** 学生可以无限次循环到队尾，所以只要队列中还有喜欢栈顶三明治的学生，总能吃到。

当且仅当队列中没有任何学生喜欢当前栈顶三明治时，过程停止。

所以可以直接用计数法：统计喜欢 0 和喜欢 1 的学生各有多少人，然后从栈顶开始依次"分配"，只要某种三明治的计数为 0，就停止，返回剩余学生总数。

## 代码实现

### 方法一：计数法（推荐）

```python
from typing import List

class Solution:
    def countStudents(self, students: List[int], sandwiches: List[int]) -> int:
        # 统计喜欢 0 和喜欢 1 的学生数量
        count = [0, 0]
        for s in students:
            count[s] += 1

        # 按栈顺序依次分配三明治
        for sandwich in sandwiches:
            if count[sandwich] == 0:
                # 没有学生喜欢当前三明治，停止
                break
            count[sandwich] -= 1

        # 剩余无法吃到的学生数
        return count[0] + count[1]
```

### 方法二：模拟队列（直观）

```python
from typing import List
from collections import deque

class Solution:
    def countStudents(self, students: List[int], sandwiches: List[int]) -> int:
        queue = deque(students)
        stack = sandwiches[:]  # 栈顶在索引 0

        # 记录连续未能匹配的次数
        consecutive_fail = 0

        while queue and consecutive_fail < len(queue):
            if queue[0] == stack[0]:
                # 队首学生喜欢栈顶三明治，成功匹配
                queue.popleft()
                stack.pop(0)
                consecutive_fail = 0
            else:
                # 不喜欢，学生移到队尾
                queue.append(queue.popleft())
                consecutive_fail += 1

        return len(queue)
```

## 复杂度分析

**方法一（计数）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法二（模拟）：**
- 时间复杂度：O(n^2)，最坏情况下每个学生循环 n 次
- 空间复杂度：O(n)

## 关键点总结

1. 学生可以反复排到队尾，所以顺序不影响结果，只有"人数"重要
2. 只要还有喜欢当前类型三明治的学生，就可以继续分配
3. 方法一的计数思路是本题最优解，O(n) 时间

## 易错点

1. 不需要真正模拟队列，计数法更高效且正确
2. 停止条件：当前栈顶三明治对应类型的学生计数为 0
3. 方法二中 `consecutive_fail` 的初始化和重置很重要，避免死循环
