## 题目描述

给定一个整数 num，返回它的十六进制字符串表示。对于负整数，我们通常使用补码运算方法。

注意：
1. 十六进制中所有字母（a-f）都必须是小写。
2. 十六进制字符串中不能包含多余的前导零。如果要转化的数为 0，那么以单个字符 '0' 来表示；对于其他情况，十六进制字符串中的第一个字符将不会是 0 字符。
3. 给定的数确保在 32 位有符号整数范围内。
4. 不能使用任何由库提供的将数字直接转换或格式化为十六进制的方法。

**示例 1：**
```
输入：num = 26
输出："1a"
```

**示例 2：**
```
输入：num = -1
输出："ffffffff"
```

**提示：**
- -2^31 <= num <= 2^31 - 1

## 解题思路

这道题要求将整数转换为十六进制字符串，关键是处理负数的补码表示。

核心知识点：
1. 十六进制每位可以表示 4 个二进制位（0-15）
2. 负数使用补码表示：在 32 位系统中，-1 的补码是 0xFFFFFFFF
3. 可以通过位运算每次取出最低 4 位

算法流程：
1. 特殊处理：num = 0 直接返回 "0"
2. 处理负数：在 Python 中，负数需要转换为 32 位补码形式
3. 每次取最低 4 位转换为十六进制字符
4. 右移 4 位，继续处理
5. 反转结果字符串

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def toHex(self, num: int) -> str:
        """
        使用位运算，每次取最低 4 位
        """
        if num == 0:
            return "0"
        
        # 处理负数：转换为 32 位补码
        # Python 中负数的二进制是无限长的，需要截取低 32 位
        if num < 0:
            num = num & 0xFFFFFFFF  # 与运算取低 32 位
        
        # 十六进制字符映射
        hex_chars = "0123456789abcdef"
        result = []
        
        while num:
            # 取最低 4 位（0-15）
            digit = num & 0xF  # 相当于 num % 16
            result.append(hex_chars[digit])
            # 右移 4 位
            num >>= 4
        
        # 反转结果（因为是从低位到高位处理的）
        return ''.join(reversed(result))
```

### 方法二：除法取余

```python
class Solution:
    def toHex(self, num: int) -> str:
        """
        使用除法和取余，类似十进制转换
        """
        if num == 0:
            return "0"
        
        # 处理负数：32 位补码
        if num < 0:
            num = num & 0xFFFFFFFF
        
        hex_chars = "0123456789abcdef"
        result = []
        
        while num:
            result.append(hex_chars[num % 16])
            num //= 16
        
        return ''.join(reversed(result))
```

### 方法三：固定 8 位处理

```python
class Solution:
    def toHex(self, num: int) -> str:
        """
        32 位整数最多 8 个十六进制字符
        固定处理 8 次，去除前导零
        """
        if num == 0:
            return "0"
        
        # 处理负数
        if num < 0:
            num = num & 0xFFFFFFFF
        
        hex_chars = "0123456789abcdef"
        result = []
        
        # 32 位 = 8 个十六进制字符
        for _ in range(8):
            result.append(hex_chars[num & 0xF])
            num >>= 4
            if num == 0:  # 提前终止
                break
        
        return ''.join(reversed(result))
```

### 方法四：递归实现

```python
class Solution:
    def toHex(self, num: int) -> str:
        """
        递归实现
        """
        if num == 0:
            return "0"
        
        # 处理负数
        if num < 0:
            num = num & 0xFFFFFFFF
        
        hex_chars = "0123456789abcdef"
        
        def convert(n: int) -> str:
            if n == 0:
                return ""
            return convert(n >> 4) + hex_chars[n & 0xF]
        
        return convert(num)
```

### 方法五：列表推导式（简洁版）

```python
class Solution:
    def toHex(self, num: int) -> str:
        """
        使用列表推导式的简洁实现
        """
        if num == 0:
            return "0"
        
        if num < 0:
            num = num & 0xFFFFFFFF
        
        hex_chars = "0123456789abcdef"
        result = []
        
        while num:
            result.append(hex_chars[num & 0xF])
            num >>= 4
        
        return ''.join(result[::-1])
```

  - 结果字符串最多 8 个字符
  - 常数级别的额外空间

### 位运算过程（num = 26）：

```
初始：num = 26 = 0x1A

第 1 次：
  num & 0xF = 0x1A & 0xF = 10 (0xA) -> 'a'
  num >>= 4: num = 1

第 2 次：
  num & 0xF = 0x1 & 0xF = 1 -> '1'
  num >>= 4: num = 0

反转：['a', '1'] -> "1a"
```

## 关键点总结

1. **负数处理**：
   - Python 中负数的二进制表示是无限长的（以 1 开头）
   - 使用 `num & 0xFFFFFFFF` 获取低 32 位
   - 这相当于将负数转换为无符号 32 位整数

2. **位运算技巧**：
   - `num & 0xF`：取最低 4 位（相当于 num % 16）
   - `num >>= 4`：右移 4 位（相当于 num //= 16）
   - `0xF` 的二进制是 `1111`，可以提取低 4 位

3. **字符映射**：
   - 使用字符串 "0123456789abcdef" 作为映射表
   - 索引 0-15 对应十六进制字符

4. **反转结果**：
   - 从低位到高位处理，需要反转
   - 可以用 `reversed()`、`[::-1]` 或提前反向构建

## 易错点

1. **负数处理**：
   - 错误：直接使用负数进行位运算
   - 正确：先转换为 32 位补码形式

2. **字符大小写**：
   - 题目要求小写字母（a-f）
   - 不能使用大写（A-F）

3. **前导零**：
   - 0 应该返回 "0" 而不是空字符串
   - 其他情况不应该有前导零

4. **禁止使用内置函数**：
   - 不能使用 `hex()`、`format()` 等库函数
   - 要手动实现转换逻辑

5. **Python 特殊性**：
   - Python 的整数没有位数限制
   - 负数的右移行为与其他语言不同
   - 必须手动处理 32 位限制
