## 题目描述

你总共需要上 `n` 门课，课程编号依次为 `0` 到 `n-1`。

给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]` 表示如果你想学课程 `bi`，你**必须**先学课程 `ai`。（先修课关系为直接或间接的）

给你一个数组 `queries`，其中 `queries[j] = [uj, vj]`，请你判断课程 `uj` 是否是课程 `vj` 的先修课。

注意：题目给出的先修课关系是**传递**的。如果课程 a 是课程 b 的先修课，课程 b 是课程 c 的先修课，那么课程 a 也是课程 c 的先修课。

请你返回一个布尔数组 `answer`，其中 `answer[j]` 是第 `j` 个查询的答案。

**示例 1：**
```
输入：n = 2, prerequisites = [[1,0]], queries = [[0,1],[1,0]]
输出：[false, true]
解释：课程 0 不是课程 1 的先修课，但课程 1 是课程 0 的先修课。
```

**示例 2：**
```
输入：n = 2, prerequisites = [[1,0],[0,1]], queries = [[1,0],[1,1]]
输出：[true, true]
```

**示例 3：**
```
输入：n = 3, prerequisites = [[1,2],[1,0],[2,0]], queries = [[1,0],[1,2]]
输出：[true, true]
```

**提示：**
- `2 <= n <= 100`
- `0 <= prerequisite.length <= (n * (n-1) / 2)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `ai != bi`
- 每组先修课关系 `[ai, bi]` 都是唯一的
- `1 <= queries.length <= 10^4`
- `queries[j].length == 2`
- `0 <= uj, vj <= n-1`

## 解题思路

**问题本质：有向图的传递闭包**

求图的传递闭包，即判断任意两点 (u, v) 是否存在从 u 到 v 的有向路径。

**方法一：Floyd-Warshall 算法（推荐）**

Floyd-Warshall 是求所有点对之间可达性（传递闭包）的经典算法：

`reachable[i][j] = True` 表示从节点 i 可以到达节点 j。

```
初始化：根据 prerequisites 直接设置 reachable[a][b] = True
更新：对每个中间节点 k：
  若 reachable[i][k] 且 reachable[k][j]，则 reachable[i][j] = True
```

三层循环后，`reachable` 就是完整的传递闭包。

**方法二：对每个节点做 BFS/DFS**

从每个节点出发做 BFS，记录所有可达节点，预处理后 O(1) 回答查询。

## Python 代码实现

### 方法一：Floyd-Warshall 传递闭包（推荐）

```python
from typing import List

class Solution:
    def checkIfPrerequisite(self, n: int, prerequisites: List[List[int]],
                            queries: List[List[int]]) -> List[bool]:
        # reachable[i][j] 表示节点 i 是否可以到达节点 j
        reachable = [[False] * n for _ in range(n)]

        # 初始化直接先修课关系
        for a, b in prerequisites:
            reachable[a][b] = True

        # Floyd-Warshall：枚举所有中间节点
        for k in range(n):           # 中间节点
            for i in range(n):       # 起点
                for j in range(n):   # 终点
                    # 若 i 能到 k，且 k 能到 j，则 i 能到 j
                    if reachable[i][k] and reachable[k][j]:
                        reachable[i][j] = True

        # 回答每个查询
        return [reachable[u][v] for u, v in queries]
```

### 方法二：BFS 预处理（每个节点做一次 BFS）

```python
from typing import List
from collections import deque

class Solution:
    def checkIfPrerequisite(self, n: int, prerequisites: List[List[int]],
                            queries: List[List[int]]) -> List[bool]:
        # 构建邻接表
        graph = [[] for _ in range(n)]
        for a, b in prerequisites:
            graph[a].append(b)

        # reachable[i] 是从节点 i 出发可以到达的所有节点
        reachable = [set() for _ in range(n)]

        def bfs(start: int) -> None:
            """从 start 节点做 BFS，记录所有可达节点"""
            queue = deque([start])
            visited = {start}
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        reachable[start].add(neighbor)
                        queue.append(neighbor)

        # 对每个节点做 BFS
        for i in range(n):
            bfs(i)

        # 回答查询
        return [v in reachable[u] for u, v in queries]
```

### 方法三：拓扑排序 + 传递闭包

```python
from typing import List
from collections import deque

class Solution:
    def checkIfPrerequisite(self, n: int, prerequisites: List[List[int]],
                            queries: List[List[int]]) -> List[bool]:
        # 构建图和入度
        graph = [[] for _ in range(n)]
        in_degree = [0] * n
        for a, b in prerequisites:
            graph[a].append(b)
            in_degree[b] += 1

        # reachable[i] 存储节点 i 的所有先修课（包括传递的）
        # 注意：这里存"谁能到 i"，即 i 的所有先修课
        pre_set = [set() for _ in range(n)]
        for a, b in prerequisites:
            pre_set[b].add(a)

        # 拓扑排序（Kahn 算法）
        queue = deque([i for i in range(n) if in_degree[i] == 0])
        while queue:
            node = queue.popleft()
            for neighbor in graph[node]:
                # neighbor 的先修课 = neighbor 的直接先修课 + node 的所有先修课 + node 本身
                pre_set[neighbor].add(node)
                pre_set[neighbor] |= pre_set[node]
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)

        # 回答查询：u 是 v 的先修课 <=> u 在 pre_set[v] 中
        return [u in pre_set[v] for u, v in queries]
```

## 复杂度分析

**方法一（Floyd-Warshall）：**
- 时间复杂度：O(n^3 + Q)，n 为课程数，Q 为查询数
- 空间复杂度：O(n^2)，传递闭包矩阵

**方法二（BFS）：**
- 时间复杂度：O(n × (n + E) + Q)，E 为边数
- 空间复杂度：O(n^2)，每个节点的可达集合

## 关键点总结

1. 问题本质是图的**传递闭包**，Floyd-Warshall 是最简洁的解法
2. Floyd-Warshall 三层循环中，k（中间节点）必须在最外层
3. 预处理后，每次查询 O(1) 回答，适合大量查询场景
4. n ≤ 100，O(n^3) 完全够用

## 易错点

- Floyd-Warshall 中，`k` 必须在**最外层**循环，否则结果不正确
- 初始化只设置直接先修课，Floyd-Warshall 会自动推导传递关系
- 方法三中，`pre_set[v]` 存的是 v 的先修课，所以查询是 `u in pre_set[v]`
