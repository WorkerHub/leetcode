## 题目描述

给你一个整数数组 `nums`，找到最长的连续子数组，使得子数组中所有元素的异或值不为 0。

返回该最长子数组的长度。

**示例 1：**

```
输入：nums = [1, 2, 3, 4]
输出：4
解释：1^2^3^4 = 4 ≠ 0，整个数组满足条件。
```

**示例 2：**

```
输入：nums = [1, 2, 1, 2]
输出：3
解释：[1,2,1] 异或 = 1^2^1 = 2 ≠ 0，[2,1,2] 异或 = 2^1^2 = 1 ≠ 0，最长为 3。
注意 [1,2,1,2] 异或 = 0，不满足。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

使用**前缀异或**：`prefix[i] = nums[0] ^ nums[1] ^ ... ^ nums[i-1]`。

子数组 `[l, r]` 的异或值 = `prefix[r+1] ^ prefix[l]`。

要找最长的 `[l, r]` 使异或值 ≠ 0，即 `prefix[r+1] ≠ prefix[l]`。

用哈希表记录每个前缀异或值第一次出现的位置，对每个 r，找最早的 l 使 `prefix[l] ≠ prefix[r+1]`。

## Python 代码实现

### 方法一：前缀异或 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def maxLengthSubarrayNonZeroXor(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = 0
        # first_seen[x] = 前缀异或值 x 第一次出现的位置
        first_seen = {0: 0}
        ans = 0

        for i in range(n):
            prefix ^= nums[i]
            # 子数组 [j, i] 异或值 = prefix ^ first_seen_prefix[j]
            # 要最大化 i - j + 1，找最早的 j 使 prefix[j] != prefix[i+1]
            if prefix not in first_seen:
                first_seen[prefix] = i + 1
            # 找第一个不等于 prefix 的前缀异或（即 prefix[0..j-1] != prefix）
            # 枚举：若有不同前缀，最早的那个给最长子数组
            # 简化：最长子数组 = i+1 - min(j 使 prefix[j] != prefix)
            # = 若 prefix != first_prefix: i+1 - 0
            # = 若 prefix == first_prefix: 需要第二早的不同前缀

            # 更简单：ans = max(ans, i + 1 - first_occurrence_of_same_prefix)
            # 若 prefix(i+1) == prefix(0)=0，则整个数组异或为 0，需找其他范围

            pass

        # 重新实现
        prefix = 0
        first_seen = {0: 0}
        ans = 0

        for i in range(1, n + 1):
            prefix ^= nums[i - 1]
            if prefix != 0:
                ans = max(ans, i)  # [0, i-1] 的异或 = prefix ≠ 0
            # 找最早的 j 使 prefix[j] ≠ prefix[i]
            if prefix in first_seen:
                # [first_seen[prefix], i-1] 异或 = 0，跳过
                # 最长非零异或子数组不包含这段
                pass
            else:
                first_seen[prefix] = i

        return ans
```

### 方法二：简化版

```python
from typing import List

class Solution:
    def maxLengthSubarrayNonZeroXor(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] ^ nums[i]

        # 找最长 [l, r] 使 prefix[r+1] ^ prefix[l] != 0
        # 等价于 prefix[r+1] != prefix[l]
        # 贪心：对每个 r+1，找最早的 l 使 prefix[l] != prefix[r+1]

        first_seen = {}
        ans = 0

        for i in range(n + 1):
            p = prefix[i]
            if p not in first_seen:
                first_seen[p] = i

        for i in range(1, n + 1):
            p = prefix[i]
            # 最长子数组：找最早的 l 使 prefix[l] != p
            # 若 first_seen 中最早的 != p，就是 0
            if prefix[0] != p:
                ans = max(ans, i - 0)
            elif len(first_seen) > 1:
                # 找第二早的不同前缀
                for j in range(1, i + 1):
                    if prefix[j] != p:
                        ans = max(ans, i - j)
                        break

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，前缀数组

## 关键点总结

1. 前缀异或将子数组异或值转化为两个前缀值的异或。
2. 不等于 0 的条件等价于两端前缀值不同。
3. 若整个数组异或 ≠ 0，答案为 n；否则从两端各尝试去掉一个元素。

## 易错点

1. 若全数组异或为 0，最长子数组最多为 n-1（去掉第一个或最后一个，让异或变非零）。
2. 若整个数组异或 ≠ 0，直接返回 n。
