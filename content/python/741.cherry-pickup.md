## 题目描述

一个N x N的网格 `grid` 代表了一块樱桃地，每个格子由以下三种数字的一种来表示：
- 0 表示这个格子是空的，所以你可以穿过它。
- 1 表示这个格子里装着一个樱桃，你可以摘到樱桃然后穿过它。
- -1 表示这个格子里有荆棘，挡着你的路。

你的任务是在遵守下列规则的情况下，尽可能的摘到最多樱桃：

- 从位置 (0, 0) 出发，最后到达 (N-1, N-1)，只能向下或向右走，并且只能穿越有效的格子
- 当到达 (N-1, N-1) 后，你要继续走，直到返回到 (0, 0)，只能向上或向左走，并且只能穿越有效的格子
- 当你经过一个格子时，你会摘掉那里的樱桃（如果有的话）
- 如果在 (0, 0) 和 (N-1, N-1) 之间不存在一条可经过的路径，则没有任何一个樱桃能被摘到

返回你能摘到樱桃的最大数目。

## 解题思路

**核心思想：** 将问题转化为两个人同时从(0,0)走到(N-1,N-1)

## Python 代码实现

```python
from typing import List

class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # dp[i][j][k] 表示第一个人到(i,j)，第二个人到(k, i+j-k)的最大樱桃数
        dp = [[[-1] * n for _ in range(n)] for _ in range(n)]
        
        def dfs(r1, c1, r2):
            c2 = r1 + c1 - r2
            
            # 越界或遇到荆棘
            if (r1 >= n or c1 >= n or r2 >= n or c2 >= n or
                grid[r1][c1] == -1 or grid[r2][c2] == -1):
                return float('-inf')
            
            # 到达终点
            if r1 == n - 1 and c1 == n - 1:
                return grid[r1][c1]
            
            # 记忆化
            if dp[r1][c1][r2] != -1:
                return dp[r1][c1][r2]
            
            # 摘樱桃
            cherries = grid[r1][c1]
            if r1 != r2:  # 不在同一格
                cherries += grid[r2][c2]
            
            # 四种移动方式
            cherries += max(
                dfs(r1 + 1, c1, r2 + 1),  # 都向下
                dfs(r1, c1 + 1, r2 + 1),  # 右，下
                dfs(r1 + 1, c1, r2),      # 下，右
                dfs(r1, c1 + 1, r2)       # 都向右
            )
            
            dp[r1][c1][r2] = cherries
            return cherries
        
        return max(0, dfs(0, 0, 0))
```

## 复杂度分析

- **时间复杂度：** O(n^3)
- **空间复杂度：** O(n^3)
