## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个正整数 `x`。

从 `nums[0]` 出发，可以跳到任何后续位置 `j`（`i < j`）。每次跳跃得分为 `nums[j]`，但若 `nums[i]` 和 `nums[j]` 奇偶性不同，还需支付代价 `x`。

初始得分为 `nums[0]`，返回最大得分。

**示例 1：**
```
输入：nums = [2,3,6,1,9,2], x = 5
输出：13
解释：2+6+9-5=12? 或 2+6+2-5=5? 让我看看: 2,3,6 → 2+3-5+6=6, 2+6+9=17-5(奇偶切换)=12,试 2+6+2=10, 2+3+9=14-5-5=4
正确: 从2->6(同偶,+6)->9(切换,-5+9)->... 2+6+9-5=12, 或 2+3-5+9-5=4, 或直接2->9=2+9-5=6
```

**示例 2：**
```
输入：nums = [2,4,6,8], x = 3
输出：20
```

**提示：**
- `2 <= nums.length <= 10^5`

## 解题思路

**DP**：维护两个状态：
- `dp_even`：到达偶数位置的最大得分
- `dp_odd`：到达奇数位置的最大得分

对每个 `nums[i]`：
- 若 `nums[i]` 为偶数：`dp_even = max(dp_even, dp_odd - x) + nums[i]`
- 若 `nums[i]` 为奇数：`dp_odd = max(dp_odd, dp_even - x) + nums[i]`

初始：`dp_even` 或 `dp_odd` 根据 `nums[0]` 的奇偶性初始化。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int], x: int) -> int:
        INF = float('-inf')
        # 初始化：从 nums[0] 出发
        if nums[0] % 2 == 0:
            dp_even, dp_odd = nums[0], INF
        else:
            dp_even, dp_odd = INF, nums[0]

        for i in range(1, len(nums)):
            val = nums[i]
            if val % 2 == 0:
                # 来自偶数（不付费）或奇数（付费 x）
                dp_even = max(dp_even, dp_odd - x) + val
            else:
                # 来自奇数（不付费）或偶数（付费 x）
                dp_odd = max(dp_odd, dp_even - x) + val

        return max(dp_even, dp_odd)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. DP 按奇偶性分两个状态
2. 奇偶切换需支付代价 x
3. 初始状态只设置 nums[0] 对应奇偶的 dp

## 易错点

1. 初始时另一个奇偶状态为负无穷（不可达）
2. 更新时 max 操作对 INF - x 也有效（结果仍为 INF 级别的负数，不影响最终答案）
