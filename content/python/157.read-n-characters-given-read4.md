## 题目描述

给你一个文件，并且该文件只能通过给定的 `read4` 方法来读取，请实现一个方法使其能够使 `read` 方法读取 `n` 个字符。

**read4 方法：**

API `read4` 可以从文件中读取 4 个连续的字符，并且将它们写入缓存数组 `buf4` 中。

返回值为实际读取的字符个数。

注意 `read4()` 自身拥有文件指针，很像 C 语言中的 `FILE *fp`。

read4 的定义：

```
参数类型: char[] buf4
返回类型: int

注意: buf4[] 是目标缓存区不是源缓存区，read4 的返回结果将会复制到 buf4[] 当中。
```

下列是一些使用 `read4` 的例子：

```
File file("abcde"); // 文件名为 "abcde"， 初始文件指针 (fp) 指向 'a'
char[] buf4 = new char[4]; // 创建一个缓存区使其能容纳足够的字符
read4(buf4); // read4 返回 4。现在 buf4 = ['a','b','c','d']，fp 指向 'e'
read4(buf4); // read4 返回 1。现在 buf4 = ['e']，fp 指向文件末尾
read4(buf4); // read4 返回 0。现在 buf4 = []，fp 指向文件末尾
```

**read 方法：**

通过使用 `read4` 方法，实现 `read` 方法。该方法可以从文件中读取 n 个字符并将其存储到缓存数组 `buf` 中。您不能直接操作文件。

返回值为实际读取的字符个数。

read 的定义：

```
参数类型: char[] buf, int n
返回类型: int

注意: buf[] 是目标缓存区不是源缓存区，你需要将结果写入 buf[] 中。
```

**示例 1：**
```
输入：file = "abc", n = 4
输出：3
解释：当执行你的 read 方法后，buf 需要包含 "abc"。文件一共 3 个字符，因此返回 3。
注意 "abc" 是文件的内容，不是 buf 的内容，buf 是你需要写入结果的目标缓存区。
```

**示例 2：**
```
输入：file = "abcde", n = 5
输出：5
解释：当执行你的 read 方法后，buf 需要包含 "abcde"。文件共 5 个字符，因此返回 5。
```

**示例 3：**
```
输入：file = "abcdABCD1234", n = 12
输出：12
解释：当执行你的 read 方法后，buf 需要包含 "abcdABCD1234"。文件一共 12 个字符，因此返回 12。
```

**提示：**
- 1 <= file.length <= 500
- file 由英文字母和数字组成
- 1 <= n <= 1000

## 解题思路

这是一道 API 设计题，核心是如何利用 `read4` 来实现 `read(n)`。

**关键观察：**

1. `read4` 每次读取 4 个字符（或更少，如果文件剩余字符不足 4 个）
2. 我们需要读取 n 个字符，可能需要多次调用 `read4`
3. 最后一次调用 `read4` 可能读取的字符数超过所需，需要截断

**算法流程：**

1. 创建一个临时缓冲区 `buf4`，用于接收 `read4` 的结果
2. 循环调用 `read4`，每次最多读取 4 个字符
3. 将读取的字符复制到目标缓冲区 `buf` 中
4. 如果已经读取了 n 个字符，或者文件已经读完，则停止
5. 返回实际读取的字符数

**边界情况：**
- 文件长度小于 n：返回文件实际长度
- 文件长度大于等于 n：返回 n
- n 不是 4 的倍数：最后一次读取需要截断

## Python 代码实现

### 方法一：循环调用 read4（推荐）⭐

```python
"""
The read4 API is already defined for you.

    @param buf4, List[str]: a list of characters
    @return an integer
    def read4(buf4: List[str]) -> int:

# Below is an example of how the read4 API can be called.
file = File("abcdefghijk") # File is "abcdefghijk", initially file pointer (fp) points to 'a'
buf4 = ['' for _ in range(4)]
read4(buf4) # read4 returns 4. Now buf4 = ['a','b','c','d'], fp points to 'e'
read4(buf4) # read4 returns 4. Now buf4 = ['e','f','g','h'], fp points to 'i'
read4(buf4) # read4 returns 3. Now buf4 = ['i','j','k',...], fp points to end of file
"""

class Solution:
    def read(self, buf: List[str], n: int) -> int:
        """
        使用 read4 读取 n 个字符
        时间复杂度：O(n)
        空间复杂度：O(1)，只使用了固定大小的 buf4
        """
        total_read = 0  # 已经读取的总字符数
        buf4 = [''] * 4  # 临时缓冲区
        
        # 当还需要读取字符时，继续循环
        while total_read < n:
            # 调用 read4 读取最多 4 个字符
            count = read4(buf4)
            
            # 如果 read4 返回 0，说明文件已经读完
            if count == 0:
                break
            
            # 计算本次应该复制的字符数
            # 不能超过剩余需要读取的字符数 n - total_read
            # 也不能超过实际读取的字符数 count
            chars_to_copy = min(count, n - total_read)
            
            # 将字符从 buf4 复制到 buf
            for i in range(chars_to_copy):
                buf[total_read] = buf4[i]
                total_read += 1
            
            # 如果 read4 返回的字符数少于 4，说明文件已经读完
            if count < 4:
                break
        
        return total_read
```

### 方法二：简化版本

```python
class Solution:
    def read(self, buf: List[str], n: int) -> int:
        """
        简化代码，使用切片操作
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        total_read = 0
        buf4 = [''] * 4
        
        while total_read < n:
            count = read4(buf4)
            
            # 文件读完
            if count == 0:
                break
            
            # 计算需要复制的字符数
            chars_to_copy = min(count, n - total_read)
            
            # 使用切片复制
            buf[total_read:total_read + chars_to_copy] = buf4[:chars_to_copy]
            total_read += chars_to_copy
            
            # 文件读完
            if count < 4:
                break
        
        return total_read
```

### 方法三：更紧凑的实现

```python
class Solution:
    def read(self, buf: List[str], n: int) -> int:
        """
        更紧凑的实现方式
        """
        idx = 0  # buf 中的当前索引
        
        while idx < n:
            buf4 = [''] * 4
            count = read4(buf4)
            
            # 没有更多字符可读
            if count == 0:
                break
            
            # 复制字符到 buf
            for i in range(min(count, n - idx)):
                buf[idx] = buf4[i]
                idx += 1
        
        return idx
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是需要读取的字符数。最多调用 read4 ⌈n/4⌉ 次
- 空间复杂度：O(1)，只使用了固定大小为 4 的临时缓冲区

## 图解示例

假设文件内容为 "abcdefghijk"（11 个字符），n = 10

```
调用过程：

第 1 次调用 read4:
buf4 = ['a','b','c','d']  count = 4
复制到 buf[0:4]
total_read = 4

第 2 次调用 read4:
buf4 = ['e','f','g','h']  count = 4
复制到 buf[4:8]
total_read = 8

第 3 次调用 read4:
buf4 = ['i','j','k','...']  count = 3（文件只剩 3 个字符）
但我们只需要 2 个字符（n - total_read = 10 - 8 = 2）
只复制 buf4[0:2] 到 buf[8:10]
total_read = 10

返回 10
```

## 关键点总结

1. **read4 特性**：每次最多读 4 个字符，返回实际读取数
2. **循环条件**：`total_read < n` 且 `read4` 还能读到字符
3. **字符数计算**：取 `min(count, n - total_read)`，避免超出需求
4. **终止条件**：`read4` 返回 0 或小于 4，或者已读够 n 个字符
5. **索引管理**：正确维护目标缓冲区 `buf` 的写入位置

## 易错点

1. **未处理 n 大于文件长度的情况**：应该返回文件实际长度
2. **未处理最后一次读取超出需求的情况**：需要用 `min(count, n - total_read)` 截断
3. **忘记检查 read4 返回值**：返回 0 时应该停止读取
4. **buf4 重用问题**：每次调用 read4 前不需要清空 buf4，因为 read4 会覆盖
5. **边界条件**：n = 0 时直接返回 0（虽然题目保证 n >= 1）
