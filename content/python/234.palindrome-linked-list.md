## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**
```
输入：head = [1,2]
输出：false
```

**提示：**
- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：** 你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

## 解题思路

判断链表是否为回文，有多种方法，从简单到优化：

**方法思路：**

1. **数组辅助**：将链表值复制到数组，用双指针判断（空间 O(n)）
2. **栈辅助**：利用栈的后进先出特性（空间 O(n)）
3. **快慢指针 + 反转**：找到中点，反转后半部分，比较（空间 O(1)）⭐
4. **递归**：利用递归的回溯特性（空间 O(n)，递归栈）

**最优解思路（快慢指针 + 反转）：**

1. 使用快慢指针找到链表中点
2. 反转后半部分链表
3. 比较前半部分和反转后的后半部分
4. 恢复链表（可选）

## Python 代码实现

### 方法一：数组辅助（最简单）

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        """
        将链表值复制到数组，使用双指针判断
        """
        # 将链表值存入数组
        vals = []
        current = head
        while current:
            vals.append(current.val)
            current = current.next
        
        # 双指针判断回文
        left, right = 0, len(vals) - 1
        while left < right:
            if vals[left] != vals[right]:
                return False
            left += 1
            right -= 1
        
        return True
```

### 方法二：快慢指针 + 反转（推荐，O(1) 空间）⭐

```python
class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        """
        快慢指针找中点 + 反转后半部分链表
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if not head or not head.next:
            return True
        
        # 步骤 1：使用快慢指针找到中点
        slow = fast = head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        
        # slow 现在指向中点（或中点的前一个节点）
        # 反转后半部分链表
        second_half = self.reverse(slow.next)
        
        # 步骤 2：比较前半部分和反转后的后半部分
        first_half = head
        second_half_copy = second_half  # 保存用于恢复
        
        result = True
        while result and second_half:
            if first_half.val != second_half.val:
                result = False
            first_half = first_half.next
            second_half = second_half.next
        
        # 步骤 3：恢复链表（可选）
        slow.next = self.reverse(second_half_copy)
        
        return result
    
    def reverse(self, head: ListNode) -> ListNode:
        """
        反转链表
        """
        prev = None
        current = head
        while current:
            next_node = current.next
            current.next = prev
            prev = current
            current = next_node
        return prev
```

### 方法三：快慢指针 + 反转（简化版，不恢复链表）

```python
class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        """
        不恢复链表的简化版本
        """
        if not head or not head.next:
            return True
        
        # 找到中点
        slow = fast = head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        
        # 反转后半部分
        second = slow.next
        slow.next = None  # 断开链表
        
        # 反转
        prev = None
        while second:
            next_node = second.next
            second.next = prev
            prev = second
            second = next_node
        
        # 比较
        first, second = head, prev
        while second:  # 后半部分可能比前半部分短
            if first.val != second.val:
                return False
            first = first.next
            second = second.next
        
        return True
```

### 方法四：递归（巧妙但空间 O(n)）

```python
class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        """
        递归方法：利用递归的回溯特性
        """
        self.front_pointer = head
        
        def recursively_check(current_node):
            if current_node is not None:
                # 递归到链表末尾
                if not recursively_check(current_node.next):
                    return False
                # 回溯时比较
                if self.front_pointer.val != current_node.val:
                    return False
                # 前指针向前移动
                self.front_pointer = self.front_pointer.next
            return True
        
        return recursively_check(head)
```

### 方法五：栈辅助

```python
class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        """
        使用栈存储后半部分，利用栈的后进先出特性
        """
        if not head or not head.next:
            return True
        
        # 找到中点
        slow = fast = head
        stack = []
        
        # 将前半部分入栈
        while fast and fast.next:
            stack.append(slow.val)
            slow = slow.next
            fast = fast.next.next
        
        # 如果是奇数长度，跳过中间节点
        if fast:
            slow = slow.next
        
        # 比较后半部分和栈中元素
        while slow:
            if slow.val != stack.pop():
                return False
            slow = slow.next
        
        return True
```

## 复杂度分析

**方法一（数组辅助）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要存储所有节点值

**方法二（快慢指针 + 反转）：**
- 时间复杂度：O(n)，需要遍历链表两次
- 空间复杂度：O(1)，只用了常数个指针

**方法四（递归）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归栈深度为 n

## 关键点总结

1. **快慢指针找中点**：fast 走两步，slow 走一步，slow 到达中点
2. **反转链表**：经典的三指针反转法
3. **比较技巧**：只需比较后半部分的长度（奇数长度时后半部分较短）
4. **空间优化**：O(1) 空间的关键是原地修改链表
5. **恢复链表**：面试时可以询问是否需要恢复原链表

## 易错点

1. **中点判断**：
   ```python
   # 对于奇数长度 [1,2,3,2,1]，slow 应该停在 3
   # 对于偶数长度 [1,2,2,1]，slow 应该停在第一个 2
   
   # 正确写法
   while fast.next and fast.next.next:
       slow = slow.next
       fast = fast.next.next
   ```

2. **比较长度**：后半部分可能比前半部分短，用后半部分的长度控制循环
   ```python
   while second:  # 用 second 控制，不是 first
       if first.val != second.val:
           return False
       first = first.next
       second = second.next
   ```

3. **空链表和单节点**：需要特殊处理
   ```python
   if not head or not head.next:
       return True
   ```

4. **反转链表时保存头节点**：如果需要恢复，要保存反转后的头节点

5. **递归方法的变量**：需要用类变量保存前指针
