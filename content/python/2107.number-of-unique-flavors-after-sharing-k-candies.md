## 题目描述

给你一个整数数组 `candies` 和一个整数 `k`。

你打算和你的弟弟分享糖果。他会选择一段**连续**的 `k` 块糖果（即 `candies[i]` 到 `candies[i+k-1]`），其余的糖果你来吃。

返回你能获得的**最多不同口味**糖果数量。

**示例：**
```
输入：candies = [1,2,2,3,4,3,3], k = 3
输出：3
解释：
- 弟弟选 candies[1..3] = [2,2,3]，你吃 [1,4,3]，3 种口味。
- 其他选法均不优于此。
```

**提示：**
- `1 <= candies.length <= 10^5`
- `1 <= candies[i] <= 10^5`
- `0 <= k <= candies.length`

## 解题思路

**滑动窗口**

维护一个大小为 `k` 的窗口（弟弟的糖果），统计窗口外的不同口味数。

- 初始化：窗口在 `[0, k-1]`，你的糖果是 `[k, n-1]`。
- 滑动窗口向右：
  - 窗口右边界加入新元素（该元素从你的集合中移出）。
  - 窗口左边界移出旧元素（该元素加回你的集合）。
- 每次统计你的集合大小。

## 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def shareCandies(self, candies: List[int], k: int) -> int:
        n = len(candies)
        if k == 0:
            return len(set(candies))

        # 统计所有糖果的频次
        cnt = Counter(candies)
        # 初始窗口 [0, k-1]，先从 cnt 中减去
        window = Counter(candies[:k])
        for flavor, freq in window.items():
            cnt[flavor] -= freq
            if cnt[flavor] == 0:
                del cnt[flavor]

        # 初始：窗口 [0, k-1]，你的糖果是剩余部分
        ans = len(cnt)

        # 滑动窗口
        for i in range(k, n):
            # 窗口右边界加入 candies[i]（从你的糖果中移除）
            cnt[candies[i]] -= 1
            if cnt[candies[i]] == 0:
                del cnt[candies[i]]

            # 窗口左边界移出 candies[i-k]（加回你的糖果）
            cnt[candies[i - k]] = cnt.get(candies[i - k], 0) + 1

            ans = max(ans, len(cnt))

        return ans
```

### 方法二：两个计数器

```python
from typing import List
from collections import defaultdict

class Solution:
    def shareCandies(self, candies: List[int], k: int) -> int:
        n = len(candies)
        # yours: 你拥有的糖果口味计数
        yours = defaultdict(int)
        for c in candies:
            yours[c] += 1

        # 初始窗口为空（等效于 k=0 情况的起点）
        window = defaultdict(int)
        ans = 0

        for i in range(n):
            # 窗口加入右侧元素 candies[i]
            window[candies[i]] += 1
            yours[candies[i]] -= 1
            if yours[candies[i]] == 0:
                del yours[candies[i]]

            # 窗口超过 k 时，移出左侧元素
            if i >= k:
                left = candies[i - k]
                window[left] -= 1
                if window[left] == 0:
                    del window[left]
                yours[left] = yours.get(left, 0) + 1

            # 窗口大小恰好为 k 时记录答案
            if i >= k - 1:
                ans = max(ans, len(yours))

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(n) |

## 关键点总结

1. 维护"你的糖果"口味计数，每次滑动窗口动态更新。
2. 窗口右侧新加元素从"你的集合"中移除；左侧移出元素归还给"你的集合"。
3. 用字典长度统计不同口味数，删除频次为 0 的键保证准确性。

## 易错点

- `k == 0` 边界：弟弟不选任何糖果，你拥有所有糖果的口味数。
- 更新计数后记得删除频次为 0 的键，否则 `len(cnt)` 会偏大。
