## 题目描述

句子 `s` 由小写字母和数字组成，单词之间用单个空格隔开。

请判断句子中的**数字**是否**严格递增**（即每个数字都比前一个大）。如果是，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "1 box has 3 blue 4 red 6 green and 12 boxes"
输出：true
```

**示例 2：**
```
输入：s = "hello world 5 x 5"
输出：false
解释：有两个 5，不是严格递增
```

**提示：**
- `3 <= s.length <= 200`
- `s` 由小写字母、空格和数字组成
- `s` 中至少有一个数字
- `s` 中的数字不含前导零
- `s` 中所有数字在 `[1, 100]` 范围内

## 解题思路

分割字符串，提取所有数字，检查是否严格递增。

## 代码实现

### 方法一：split + isdigit（推荐）

```python
class Solution:
    def areNumbersAscending(self, s: str) -> bool:
        prev = -1  # 上一个数字（初始化为最小值）
        for token in s.split():
            if token.isdigit():  # 判断当前 token 是否全为数字
                num = int(token)
                if num <= prev:
                    return False  # 不是严格递增
                prev = num
        return True
```

### 方法二：正则表达式提取

```python
import re

class Solution:
    def areNumbersAscending(self, s: str) -> bool:
        # 提取所有数字
        numbers = [int(x) for x in re.findall(r'\d+', s)]
        # 检查严格递增
        return all(numbers[i] < numbers[i + 1] for i in range(len(numbers) - 1))
```

### 方法三：zip 检查

```python
class Solution:
    def areNumbersAscending(self, s: str) -> bool:
        nums = []
        for token in s.split():
            if token.isdigit():
                nums.append(int(token))

        # 使用 zip 检查相邻两数
        return all(a < b for a, b in zip(nums, nums[1:]))
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1) 或 O(k)，k 为数字个数

## 关键点总结

1. `split()` 分割后用 `isdigit()` 判断 token 是否为数字
2. 严格递增：每个数字严格大于前一个
3. 数字可以是多位数（如 `12`），不是单个数字字符

## 易错点

- 数字不含前导零，`isdigit()` 方法对纯数字 token 有效
- 注意是**严格递增**（不能相等）
- 句子中可能没有数字（题目保证至少有一个，但代码要健壮）
