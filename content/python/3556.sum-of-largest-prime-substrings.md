## 题目描述

给定一个由数字组成的字符串 `s`，找出其所有子字符串（转换为数字后）中的质数，返回最大的 3 个不同质数之和。若不足 3 个不同的质数子串，返回所有不同质数子串的和。

**示例 1：**

```
输入：s = "12345"
输出：163
解释：质数子串有：2, 3, 5, 23, 1234... 
     最大的3个不同质数：5, 23, ... 
     实际：找所有数字子串中的质数，取最大的3个。
```

**示例 2：**

```
输入：s = "111"
输出：11
解释：质数子串：11（唯一的质数）。不足3个，返回11。
```

**提示：**
- `1 <= s.length <= 10`
- `s` 只含数字

## 解题思路

由于字符串长度很短（≤10），所有子串数量为 O(n^2) = 最多 55 个子串。枚举所有子串，转换为整数，判断是否为质数，收集不同的质数，排序后取最大的 3 个求和。

质数判断：对每个数字，试除 2 到 sqrt(n) 判断。

注意：前导零的子串（如 "01"）转换后等于 1，不是质数；"0" 也不是质数。

## Python 代码实现

### 方法一：枚举子串 + 质数判断（推荐）

```python
from math import isqrt

class Solution:
    def sumOfLargestPrimes(self, s: str) -> int:
        def is_prime(n):
            if n < 2:
                return False
            if n == 2:
                return True
            if n % 2 == 0:
                return False
            for i in range(3, isqrt(n) + 1, 2):
                if n % i == 0:
                    return False
            return True

        n = len(s)
        primes = set()

        for i in range(n):
            for j in range(i+1, n+1):
                num = int(s[i:j])
                if is_prime(num):
                    primes.add(num)

        # 取最大的 3 个不同质数求和
        sorted_primes = sorted(primes, reverse=True)
        return sum(sorted_primes[:3])
```

### 方法二：使用 sympy（适合大数据）

```python
from math import isqrt

class Solution:
    def sumOfLargestPrimes(self, s: str) -> int:
        def is_prime(n):
            if n < 2:
                return False
            for i in range(2, isqrt(n) + 1):
                if n % i == 0:
                    return False
            return True

        n = len(s)
        primes = set()

        # 枚举所有非空子串
        for length in range(1, n+1):
            for start in range(n - length + 1):
                sub = s[start:start+length]
                num = int(sub)
                # 跳过有前导零的子串（转换后值相同，但避免重复）
                if str(num) == sub or len(sub) == 1:
                    if is_prime(num):
                        primes.add(num)

        top3 = sorted(primes, reverse=True)[:3]
        return sum(top3)
```

## 复杂度分析

- 时间复杂度：O(n^2 * sqrt(10^n))，n 为字符串长度，最多 10
- 空间复杂度：O(n^2)，存储所有质数子串

## 关键点总结

1. 字符串长度 <= 10，枚举所有 O(n^2) 个子串
2. 将子串转为整数后判断是否为质数
3. 取不同质数中最大的 3 个求和

## 易错点

1. 前导零子串如 "01"、"001" 等转换为整数后与 "1"、"1" 相同，需要去重（用集合）
2. 数字 `0` 和 `1` 不是质数
3. 不足 3 个质数时，返回已找到的所有质数之和
