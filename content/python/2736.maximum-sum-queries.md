## 题目描述

给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2`，以及查询数组 `queries`，其中 `queries[i] = [xi, yi]`。

对于第 `i` 个查询，在所有满足 `nums1[j] >= xi` 且 `nums2[j] >= yi` 的下标 `j` 中，找到 `nums1[j] + nums2[j]` 的最大值。如果不存在，返回 -1。

**示例：**
```
输入：nums1 = [4,3,1,2], nums2 = [2,4,9,5], queries = [[4,1],[1,3],[2,5]]
输出：[6,10,7]
```

**提示：**
- `nums1.length == nums2.length == n`
- `1 <= n <= 10^5`
- `1 <= nums1[i], nums2[i] <= 10^9`
- `1 <= queries.length <= 10^5`

## 解题思路

**离线处理 + 单调栈**：

1. 将查询和数组元素都按 `nums1[j]`（或 `xi`）降序排列
2. 从大到小处理 xi，将满足 `nums1[j] >= xi` 的元素加入结构
3. 在已加入的元素中，查询满足 `nums2[j] >= yi` 的最大 `nums1[j] + nums2[j]`
4. 维护单调栈：按 `nums2` 升序，同时保持 `sum` 单调递减（确保对任意 yi 都能快速二分）

## Python 代码实现

### 方法一：离线处理 + 单调栈 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def maximumSumQueries(self, nums1: List[int], nums2: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums1)
        # 将 (nums1[i], nums2[i]) 按 nums1 降序排列
        pairs = sorted(zip(nums1, nums2), reverse=True)
        # 查询按 xi 降序排列，记录原始下标
        sorted_queries = sorted(enumerate(queries), key=lambda x: -x[1][0])

        ans = [-1] * len(queries)
        # 单调栈：存 (nums2[j], sum)，按 nums2 递增，sum 递减
        # 这样对于给定 yi，用二分找第一个 nums2 >= yi 的位置，其 sum 最大
        stack = []  # (nums2, nums1+nums2)，单调栈（nums2 增，sum 减）
        ptr = 0

        for qi, (x, y) in sorted_queries:
            # 将所有 nums1[j] >= x 的元素加入栈
            while ptr < n and pairs[ptr][0] >= x:
                a, b = pairs[ptr]
                s = a + b
                # 维护单调栈：若栈顶 sum <= s，弹出（因为 b 更大且 sum 更大，栈顶无用）
                while stack and stack[-1][1] <= s:
                    stack.pop()
                # 若栈顶 nums2 >= b，不入栈（已有更好选择）
                if not stack or stack[-1][0] < b:
                    stack.append((b, s))
                ptr += 1

            # 在栈中二分找第一个 nums2 >= y 的位置
            if stack:
                # 找第一个 b >= y：stack 按 b 升序
                lo, hi = 0, len(stack) - 1
                pos = -1
                while lo <= hi:
                    mid = (lo + hi) // 2
                    if stack[mid][0] >= y:
                        pos = mid
                        lo = mid + 1  # 找最右侧满足条件（sum 最小），但 sum 单调递减，最右侧 sum 最小
                    else:
                        hi = mid - 1
                # 实际上要找满足 b >= y 的最大 sum，即栈中第一个 b >= y 对应的 sum（sum 递减，b 越小 sum 越大）
                # 二分找最小的 idx 使得 stack[idx][0] >= y
                lo, hi = 0, len(stack)
                while lo < hi:
                    mid = (lo + hi) // 2
                    if stack[mid][0] >= y:
                        hi = mid
                    else:
                        lo = mid + 1
                if lo < len(stack):
                    ans[qi] = stack[lo][1]

        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n + q)

## 关键点总结

1. 离线按 x 降序处理，保证处理查询时已有所有满足 `nums1 >= x` 的元素
2. 单调栈按 nums2 升序、sum 降序，支持二分查询
3. 二分找满足 `nums2 >= y` 中最小索引，对应最大 sum

## 易错点

1. 单调栈维护方向容易搞反
2. 二分的边界和含义要清晰
