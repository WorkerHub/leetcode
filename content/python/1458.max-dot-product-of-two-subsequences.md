## 题目描述

给你两个数组 `nums1` 和 `nums2`。

请你返回 `nums1` 和 `nums2` 中两个长度相同的**非空子序列**的最大**点积**。

数组的**子序列**是从数组中删除某些元素（可能一个都不删除）后剩余元素构成的序列。如果顺序不变，还可以不删除任何元素。

**点积**的定义是：给定两个子序列 `a` 和 `b`，对应位置的元素相乘后求和：`sum(a[i] * b[i])`。

**示例 1：**
```
输入：nums1 = [2,1,-2,5], nums2 = [3,0,-6]
输出：18
解释：取 nums1 的子序列 [2,-2,5] 和 nums2 的子序列 [3,-6,5] 的子序列...
     实际最优：nums1[3]=5, nums2[2]=... 让我们看正确示例
     最大点积：取 nums1=[2,5], nums2=[3,0]... 不对
     答案是选 nums1[0]=2, nums2[0]=3 对应乘积 6
     以及 nums1[3]=5, nums2[2]=-6 乘积 -30... 不选
     实际答案：选 nums1[-2]=nums1[2] 和 nums2[-6]=nums2[2]，乘积 (-2)*(-6)=12
              加上 nums1[5]=nums1[3] 和... 这里 nums1 取 [2,-2,5]，nums2 取 [3,-6,...]
              最优选 [2,5] 和 [3,0] -> 6+0=6，或者直接选 [5] -> 5*?
     实际答案 18 是：nums1[1]=2 * nums2[1]=3 = 6，nums1[3]=5 * nums2[?]=...
```
注：题目示例输出 18，表示选 nums1=[2,-2,5] 和 nums2=[3,-6,0] 的某种组合

**示例 2：**
```
输入：nums1 = [3,-2], nums2 = [2,-6,7]
输出：21
解释：取 nums1[0]=3 和 nums2[2]=7，点积 = 21。
```

**示例 3：**
```
输入：nums1 = [-1,-1], nums2 = [1,1]
输出：-1
解释：子序列必须非空，最小损失选 nums1[0]*nums2[0] = -1。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 500`
- `-1000 <= nums1[i], nums2[i] <= 1000`

## 解题思路

**动态规划**

定义 `dp[i][j]` 为 `nums1` 前 `i` 个元素和 `nums2` 前 `j` 个元素中，非空子序列的最大点积。

**状态转移：**

对于每个 `(i, j)` 位置：
1. **配对**：将 `nums1[i-1]` 与 `nums2[j-1]` 配对（必须选，至少选这一对）
   - 仅选这一对：`nums1[i-1] * nums2[j-1]`
   - 在前面已有配对基础上追加：`dp[i-1][j-1] + nums1[i-1] * nums2[j-1]`（前提是 dp[i-1][j-1] > 0，否则还不如不加）
   - 合并：`max(nums1[i-1] * nums2[j-1], dp[i-1][j-1] + nums1[i-1] * nums2[j-1])`
2. **跳过 nums1[i-1]**：`dp[i-1][j]`
3. **跳过 nums2[j-1]**：`dp[i][j-1]`

综合：
```
dp[i][j] = max(
    nums1[i-1] * nums2[j-1],
    dp[i-1][j-1] + nums1[i-1] * nums2[j-1],
    dp[i-1][j],
    dp[i][j-1]
)
```

**初始化：** `dp[i][j]` = `-inf`（表示不可达/非法）

因为子序列必须非空，初始状态都是非法的，通过转移方程填入合法值。

## Python 代码实现

### 方法一：二维 DP（推荐）

```python
from typing import List

class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)

        # dp[i][j] 表示 nums1[:i] 和 nums2[:j] 的非空子序列最大点积
        # 初始化为负无穷（表示无合法子序列）
        NEG_INF = float('-inf')
        dp = [[NEG_INF] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 当前配对的乘积
                product = nums1[i - 1] * nums2[j - 1]

                # 选择1：仅使用当前配对（新的起点）
                dp[i][j] = product

                # 选择2：在之前的最优基础上追加当前配对
                if dp[i - 1][j - 1] != NEG_INF:
                    dp[i][j] = max(dp[i][j], dp[i - 1][j - 1] + product)

                # 选择3：跳过 nums1[i-1]（不配对）
                if dp[i - 1][j] != NEG_INF:
                    dp[i][j] = max(dp[i][j], dp[i - 1][j])

                # 选择4：跳过 nums2[j-1]（不配对）
                if dp[i][j - 1] != NEG_INF:
                    dp[i][j] = max(dp[i][j], dp[i][j - 1])

        return dp[m][n]
```

### 方法二：简化版 DP（统一处理负无穷）

```python
from typing import List

class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        NEG_INF = float('-inf')

        # 使用 max(...) 时，NEG_INF + x 仍为 NEG_INF，需谨慎
        # 这里用一个技巧：dp[i-1][j-1] 取 max(dp[i-1][j-1], 0) 来处理
        dp = [[NEG_INF] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                product = nums1[i - 1] * nums2[j - 1]
                # max(dp[i-1][j-1], 0)：如果之前的最大点积为负，不如从头开始
                prev = dp[i - 1][j - 1] if dp[i - 1][j - 1] != NEG_INF else 0
                dp[i][j] = max(
                    prev + product,                  # 追加当前配对
                    dp[i - 1][j] if dp[i - 1][j] != NEG_INF else NEG_INF,  # 跳过 i
                    dp[i][j - 1] if dp[i][j - 1] != NEG_INF else NEG_INF   # 跳过 j
                )

        return dp[m][n]
```

### 方法三：空间优化版（滚动数组）

```python
from typing import List

class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        NEG_INF = float('-inf')

        # 只保留两行，节省空间
        prev = [NEG_INF] * (n + 1)

        for i in range(1, m + 1):
            curr = [NEG_INF] * (n + 1)
            for j in range(1, n + 1):
                product = nums1[i - 1] * nums2[j - 1]

                # 取 prev[j-1] 和 0 的最大值（负数不如不选）
                best_prev = max(prev[j - 1], 0) if prev[j - 1] != NEG_INF else 0
                curr[j] = best_prev + product

                if prev[j] != NEG_INF:
                    curr[j] = max(curr[j], prev[j])      # 跳过 nums1[i-1]
                if curr[j - 1] != NEG_INF:
                    curr[j] = max(curr[j], curr[j - 1])  # 跳过 nums2[j-1]

            prev = curr

        return prev[n]
```

## 复杂度分析

- 时间复杂度：O(m × n)，两层循环
- 空间复杂度：O(m × n)（方法一）或 O(n)（方法三）

## 关键点总结

1. DP 定义：`dp[i][j]` 是 nums1 前 i 个和 nums2 前 j 个的非空子序列最大点积
2. 转移来源：配对当前元素 / 跳过 nums1 当前元素 / 跳过 nums2 当前元素
3. 配对时：`max(0, dp[i-1][j-1]) + product` 等价于"如果之前的结果有利则累加，否则从头开始"
4. 初始化为 `-inf` 表示没有合法子序列（必须通过配对才能产生合法值）

## 易错点

- 子序列必须**非空**，所以初始值不能是 0（用 `-inf` 表示无效）
- 当 `dp[i-1][j-1]` 为负时，强行叠加会更差，用 `max(dp[i-1][j-1], 0)` 处理
- 与最长公共子序列(LCS)的 DP 结构类似，可以对比学习
