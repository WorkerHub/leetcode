## 题目描述

给你一个下标从 0 开始且长度为 `n` 的整数数组 `nums`，以及一个整数 `k`。

**分割操作：**
- 将 `nums` 分成两个**非空**子数组 `left` 和 `right`，使得 `left` 中所有元素和等于 `right` 中所有元素和（都等于 `total / 2`）

在执行分割前，可以**最多**将 `nums` 中 `k` 个下标之一的元素改为 `k`（只能修改一个元素，改为 `k`）。

返回你能得到的最多分割方式数。

**示例 1：**
```
输入：nums = [2,-1,2], k = 3
输出：1
解释：将 nums[0] 改为 3，得 [3,-1,2]，总和为4，在 index 1 处分割各为2
```

**提示：**
- `n == nums.length`
- `2 <= n <= 10^5`
- `-10^5 <= nums[i], k <= 10^5`

## 解题思路

**不修改元素时：** 计算前缀和，若 `prefix[i] == total / 2`，则 `i` 是合法分割点。

**修改位置 `i` 处的元素（改为 `k`）时：**
- 差值 `delta = k - nums[i]`
- 总和变为 `total + delta`
- 若 `(total + delta)` 为奇数，则不存在合法分割
- 新的分割条件：`prefix[j] == (total + delta) / 2`
  - 若 `j < i`：原始前缀和 `prefix[j]` 不变，条件变为 `prefix[j] == target`
  - 若 `j >= i`：分割点包含了被修改的位置，前缀和变化了 `delta`，条件变为 `prefix[j] + delta == target`，即 `prefix[j] == target - delta`

对每个修改位置 `i`，快速查询合法分割点数：用哈希表存储 `i` 左侧和右侧的前缀和频次。

## 代码实现

### 方法一：哈希表 + 枚举修改位置（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def waysToPartition(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total = sum(nums)

        # 计算前缀和数组（prefix[i] = nums[0..i-1] 的和，prefix[0]=0）
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 不修改任何元素时，统计合法分割点数
        # 合法条件：prefix[i] == total // 2，且 total 为偶数，1 <= i <= n-1
        ans = 0
        if total % 2 == 0:
            half = total // 2
            for i in range(1, n):
                if prefix[i] == half:
                    ans += 1

        # 枚举修改位置 j（将 nums[j] 改为 k）
        # left_count[v]：prefix[1..j] 中等于 v 的个数
        # right_count[v]：prefix[j+1..n-1] 中等于 v 的个数
        left_cnt = defaultdict(int)
        right_cnt = defaultdict(int)

        # 初始化：right_cnt 存 prefix[1..n-1]
        for i in range(1, n):
            right_cnt[prefix[i]] += 1

        for j in range(n):
            delta = k - nums[j]
            new_total = total + delta

            if new_total % 2 == 0:
                target = new_total // 2
                # 分割点在 j 左侧（前缀和不变）：prefix[i] == target
                # 分割点在 j+1 到 n-1（前缀和含 delta）：prefix[i] == target - delta
                cur = left_cnt[target] + right_cnt[target - delta]
                ans = max(ans, cur)

            # 将 prefix[j+1] 从 right_cnt 移到 left_cnt
            right_cnt[prefix[j + 1]] -= 1
            left_cnt[prefix[j + 1]] += 1

        return ans
```

### 方法二：分离前缀和统计

```python
from typing import List
from collections import Counter

class Solution:
    def waysToPartition(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        total = prefix[n]

        # 不修改时的答案
        base = sum(1 for i in range(1, n) if total % 2 == 0 and prefix[i] == total // 2)
        ans = base

        # 枚举修改位置
        left = Counter()
        right = Counter(prefix[1:n])

        for j in range(n):
            delta = k - nums[j]
            new_total = total + delta
            if new_total % 2 == 0:
                t = new_total // 2
                cur = left[t] + right[t - delta]
                ans = max(ans, cur)
            # 移动分界点
            right[prefix[j + 1]] -= 1
            left[prefix[j + 1]] += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，枚举修改位置和哈希查询
- 空间复杂度：O(n)，哈希表存储前缀和频次

## 关键点总结

1. 将修改位置 `j` 后的分割点分为左侧（不受修改影响）和右侧（前缀和偏移 `delta`）
2. 用左右两个计数器动态维护，右移分界点
3. 不修改的情况作为初始答案单独计算

## 易错点

- 分割点范围是 `1` 到 `n-1`（非空子数组）
- `delta = k - nums[j]`（新值减旧值）
- 右侧分割点条件是 `prefix[i] == target - delta`（而不是 `target`）
