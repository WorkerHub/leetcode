## 题目描述

给你一个下标从 **0** 开始、大小为 `m x n` 的二维矩阵 `grid`，请你求解大小同样为 `m x n` 的答案矩阵 `answer`。

对于每个 `(r, c)` 的位置，`answer[r][c]` 的值为：
- `grid` 中左上对角线方向（不含 `(r, c)` 本身）的不同值数目
- 减去右下对角线方向（不含 `(r, c)` 本身）的不同值数目

返回答案矩阵 `answer`。

**示例：**
```
输入：grid = [[1,2,3],[3,1,5],[3,2,1]]
输出：[[1,1,0],[1,0,1],[0,1,1]]
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 100`

## 解题思路

对每个对角线（左上方向和右下方向）分别统计不同值数量：
1. 遍历每个位置 `(r, c)`，沿左上方向（`r-1, c-1`, `r-2, c-2`, ...）收集集合
2. 沿右下方向（`r+1, c+1`, `r+2, c+2`, ...）收集集合
3. 两集合大小之差即为答案

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def differenceOfDistinctValues(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        answer = [[0] * n for _ in range(m)]

        for r in range(m):
            for c in range(n):
                # 统计左上方向不同值
                top_left = set()
                i, j = r - 1, c - 1
                while i >= 0 and j >= 0:
                    top_left.add(grid[i][j])
                    i -= 1
                    j -= 1

                # 统计右下方向不同值
                bottom_right = set()
                i, j = r + 1, c + 1
                while i < m and j < n:
                    bottom_right.add(grid[i][j])
                    i += 1
                    j += 1

                answer[r][c] = abs(len(top_left) - len(bottom_right))

        return answer
```

### 方法二：按对角线预处理

```python
from typing import List
from collections import defaultdict

class Solution:
    def differenceOfDistinctValues(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        answer = [[0] * n for _ in range(m)]

        # 按对角线处理（同一对角线上 r - c 相同）
        for diag in range(-(m-1), n):
            # 收集该对角线上的所有格子（从左上到右下顺序）
            cells = []
            for r in range(m):
                c = r - diag
                if 0 <= c < n:
                    cells.append((r, c))

            # 前缀集合：cells[i] 左上方的不同值数
            prefix = set()
            prefix_sizes = []
            for r, c in cells:
                prefix_sizes.append(len(prefix))
                prefix.add(grid[r][c])

            # 后缀集合：cells[i] 右下方的不同值数
            suffix = set()
            suffix_sizes = []
            for r, c in reversed(cells):
                suffix_sizes.append(len(suffix))
                suffix.add(grid[r][c])
            suffix_sizes.reverse()

            for k, (r, c) in enumerate(cells):
                answer[r][c] = abs(prefix_sizes[k] - suffix_sizes[k])

        return answer
```

## 复杂度分析

- 方法一：时间复杂度 O(m * n * min(m, n))，空间复杂度 O(min(m, n))
- 方法二：时间复杂度 O(m * n)，空间复杂度 O(min(m, n))

## 关键点总结

1. 同一对角线上所有格子的 `r - c` 值相同
2. 方法二利用前缀集合和后缀集合，每条对角线只需两次遍历
3. 结果取绝对值

## 易错点

1. 不含当前位置 `(r, c)` 本身
2. 遍历范围注意边界
