## 题目描述

给你一个整数数组 `prices` 和一个整数 `k`，其中 `prices[i]` 是某支给定的股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 `k` 笔交易。也就是说，你最多可以买 `k` 次，卖 `k` 次。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**
```
输入：k = 2, prices = [2,4,1]
输出：2
解释：在第 1 天 (股票价格 = 2) 的时候买入，在第 2 天 (股票价格 = 4) 的时候卖出，这笔交易所能获得利润 = 4-2 = 2。
```

**示例 2：**
```
输入：k = 2, prices = [3,2,6,5,0,3]
输出：7
解释：在第 2 天 (股票价格 = 2) 的时候买入，在第 3 天 (股票价格 = 6) 的时候卖出, 这笔交易所能获得利润 = 6-2 = 4。
     随后，在第 5 天 (股票价格 = 0) 的时候买入，在第 6 天 (股票价格 = 3) 的时候卖出, 这笔交易所能获得利润 = 3-0 = 3。
     总利润 = 4 + 3 = 7。
```

**提示：**
- `1 <= k <= 100`
- `1 <= prices.length <= 1000`
- `0 <= prices[i] <= 1000`

## 解题思路

这是股票买卖系列问题中最难的一道，是**动态规划**的经典应用。

### 核心思想

定义状态：
- `dp[i][j][0]`：第 `i` 天，已完成 `j` 笔交易，当前**不持有**股票的最大利润
- `dp[i][j][1]`：第 `i` 天，已完成 `j` 笔交易，当前**持有**股票的最大利润

**说明：**
- 完成一笔交易的定义：买入 + 卖出算一笔完整交易
- 我们在**买入时**计数交易次数

### 状态转移方程

```
dp[i][j][0] = max(dp[i-1][j][0], dp[i-1][j][1] + prices[i])
              不动              卖出

dp[i][j][1] = max(dp[i-1][j][1], dp[i-1][j-1][0] - prices[i])
              不动              买入（交易次数+1）
```

### 边界条件

- `dp[0][0][0] = 0`：第 0 天，未交易，不持有股票，利润为 0
- `dp[0][0][1] = -prices[0]`：第 0 天，买入股票
- 其他状态初始化为负无穷（不可能的状态）

### 特殊优化

当 `k >= n/2` 时（n 是天数），相当于可以无限次交易，退化为"买卖股票的最佳时机 II"问题，可以用贪心算法优化。

## Python 代码实现

### 方法一：三维 DP（标准解法）⭐

```python
from typing import List

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        """
        三维动态规划
        时间复杂度：O(n * k)
        空间复杂度：O(n * k)
        """
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        
        # 特殊情况：k 很大时，相当于无限次交易
        if k >= n // 2:
            return self.maxProfitUnlimited(prices)
        
        # dp[i][j][0/1]: 第i天，完成j笔交易，不持有/持有股票
        dp = [[[0, 0] for _ in range(k + 1)] for _ in range(n)]
        
        # 初始化第 0 天
        for j in range(k + 1):
            dp[0][j][0] = 0
            dp[0][j][1] = -prices[0]
        
        # 状态转移
        for i in range(1, n):
            for j in range(k + 1):
                # 不持有股票：昨天就不持有 或 今天卖出
                dp[i][j][0] = max(dp[i-1][j][0], dp[i-1][j][1] + prices[i])
                
                # 持有股票：昨天就持有 或 今天买入
                if j > 0:
                    dp[i][j][1] = max(dp[i-1][j][1], dp[i-1][j-1][0] - prices[i])
                else:
                    dp[i][j][1] = dp[i-1][j][1]
        
        # 最后一天，不持有股票的最大利润
        return dp[n-1][k][0]
    
    def maxProfitUnlimited(self, prices: List[int]) -> int:
        """无限次交易的贪心算法"""
        profit = 0
        for i in range(1, len(prices)):
            if prices[i] > prices[i-1]:
                profit += prices[i] - prices[i-1]
        return profit
```

### 方法二：空间优化版（推荐）⭐

```python
from typing import List

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        """
        优化空间复杂度到 O(k)
        时间复杂度：O(n * k)
        空间复杂度：O(k)
        """
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        
        # k 很大时优化
        if k >= n // 2:
            profit = 0
            for i in range(1, n):
                profit += max(0, prices[i] - prices[i-1])
            return profit
        
        # buy[j]: 完成第 j 笔交易，持有股票的最大利润
        # sell[j]: 完成第 j 笔交易，不持有股票的最大利润
        buy = [-prices[0]] * (k + 1)
        sell = [0] * (k + 1)
        
        for i in range(1, n):
            for j in range(k, 0, -1):  # 从后往前更新，避免覆盖
                sell[j] = max(sell[j], buy[j] + prices[i])
                buy[j] = max(buy[j], sell[j-1] - prices[i])
        
        return sell[k]
```

### 方法三：使用负无穷初始化（更严谨）

```python
from typing import List

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        """
        使用负无穷初始化不可能的状态
        """
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        if k >= n // 2:
            return sum(max(0, prices[i] - prices[i-1]) for i in range(1, n))
        
        # 初始化
        buy = [-float('inf')] * (k + 1)
        sell = [0] * (k + 1)
        
        for price in prices:
            for j in range(k, 0, -1):
                sell[j] = max(sell[j], buy[j] + price)
                buy[j] = max(buy[j], sell[j-1] - price)
        
        return sell[k]
```

### 方法四：通用模板（便于理解）

```python
from typing import List

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        """
        通用股票问题模板
        """
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        
        # k 过大时优化
        if k >= n // 2:
            max_profit = 0
            for i in range(1, n):
                if prices[i] > prices[i-1]:
                    max_profit += prices[i] - prices[i-1]
            return max_profit
        
        # dp[j][0]: 完成 j 笔交易，不持有股票
        # dp[j][1]: 完成 j 笔交易，持有股票
        dp = [[0, -prices[0]] for _ in range(k + 1)]
        
        for i in range(1, n):
            # 从后往前更新，避免状态覆盖
            for j in range(k, 0, -1):
                dp[j][0] = max(dp[j][0], dp[j][1] + prices[i])
                dp[j][1] = max(dp[j][1], dp[j-1][0] - prices[i])
        
        return dp[k][0]
```

## 复杂度分析

**优化后的解法：**
- **时间复杂度**：O(n × k)，其中 n 是天数，k 是交易次数
- **空间复杂度**：O(k)，只需要两个长度为 k+1 的数组

**特殊情况（k >= n/2）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **状态定义**：区分"持有"和"不持有"两种状态
2. **交易计数**：在买入时增加交易次数（或在卖出时，保持一致即可）
3. **边界优化**：k >= n/2 时退化为无限次交易
4. **空间优化**：只需要一维数组，从后往前更新
5. **初始化**：不可能的状态用负无穷表示

## 易错点

1. **交易次数计数错误**：买入和卖出要在同一个时机计数
   ```python
   # 在买入时计数
   buy[j] = max(buy[j], sell[j-1] - price)
   # 而不是 sell[j-1]
   ```

2. **更新顺序错误**：必须从后往前更新，避免状态覆盖
   ```python
   for j in range(k, 0, -1):  # ✅ 从大到小
   for j in range(1, k+1):    # ❌ 会覆盖之前的状态
   ```

3. **初始化错误**：第 0 天买入股票的利润是 `-prices[0]`，不是 0
   ```python
   buy = [-prices[0]] * (k + 1)  # ✅
   buy = [0] * (k + 1)           # ❌
   ```

4. **忘记处理 k 过大的情况**：会导致 TLE（超时）
   ```python
   if k >= n // 2:
       return self.maxProfitUnlimited(prices)
   ```

5. **返回错误的状态**：应该返回不持有股票的状态
   ```python
   return sell[k]  # ✅
   return buy[k]   # ❌
   ```
