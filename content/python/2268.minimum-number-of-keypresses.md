## 题目描述

给你一个字符串 `s`，你需要重新设计手机键盘（类似旧手机 T9 输入法），将 26 个字母分配到 `1-9` 的 9 个键位上，每个键位至少分配 1 个字母（键位按需分配，没有上限）。

输入 `s` 中的每个字符，按键次数等于该字符在其对应键位上的序号（第 1 个字母按 1 次，第 2 个按 2 次，以此类推）。

返回输入整个字符串 `s` 所需的**最少总按键次数**。

**示例 1：**
```
输入：s = "aabbccddeeffgghhiiiiii"
输出：24
解释：将出现次数最多的字母排在每个键的第1位。
```

**示例 2：**
```
输入：s = "xyzxyzxyzxyz"
输出：12
```

## 解题思路

**贪心：** 统计每个字母的出现频次，按频次降序排列。最多出现的 9 个字母放在各键的第 1 位（按 1 次），次多的 9 个放在第 2 位（按 2 次），以此类推。

具体：排序后，第 `i` 个字母（0-indexed）放在第 `i // 9 + 1` 次按键的位置，贡献 `freq[i] * (i // 9 + 1)`。

## 代码实现

### 方法一：频次排序贪心（推荐）

```python
from collections import Counter

class Solution:
    def minimumKeypresses(self, s: str) -> int:
        # 统计每个字母频次，降序排列
        freqs = sorted(Counter(s).values(), reverse=True)

        total = 0
        for i, freq in enumerate(freqs):
            # 第 i 个字母在第 (i // 9 + 1) 次按键的位置
            total += freq * (i // 9 + 1)

        return total
```

### 方法二：详细注释版

```python
from collections import Counter

class Solution:
    def minimumKeypresses(self, s: str) -> int:
        # 统计26个字母出现次数（可能有字母未出现，不影响）
        count = Counter(s)
        # 按频次降序排列
        freqs = sorted(count.values(), reverse=True)

        ans = 0
        for rank, freq in enumerate(freqs):
            # rank 0-8: 第1次按键（按1次）
            # rank 9-17: 第2次按键（按2次）
            # rank 18-25: 第3次按键（按3次）
            presses = rank // 9 + 1
            ans += presses * freq

        return ans
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26) = O(n)，统计频次 O(n)，排序 O(1)（最多26个字母）。
- 空间复杂度：O(26) = O(1)。

## 关键点总结

1. 贪心：频次越高的字母放在按键次数越少的位置（第 1 位）。
2. 9 个键，每键最多分配字母无上限。出现最多的 9 个字母各占一个键的第 1 位，按 1 次。
3. 第 `rank` 个（0-indexed）字母的按键次数为 `rank // 9 + 1`。

## 易错点

- 共 9 个键，不是 10 个（1-9）。
- 按频次从大到小排序，保证高频字母按键次数少。
