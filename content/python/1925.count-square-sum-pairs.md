## 题目描述

给你一个整数 `n`，请你返回满足以下条件的整数对 `(a, b)` 的数目：

- `1 <= a <= b <= n`
- `a^2 + b^2 = c^2`（即 `a`, `b`, `c` 构成一个毕达哥拉斯三元组）

**注意：** 满足条件的 `c` 不要求 ≤ n。

**示例 1：**
```
输入：n = 5
输出：1
解释：唯一满足条件的是 (3, 4)，3² + 4² = 25 = 5²
```

**示例 2：**
```
输入：n = 10
输出：4
解释：(3,4), (6,8), (5,12 不满足), (6,8)...共 4 对
```

**提示：**
- `1 <= n <= 250`

---

## 解题思路

### 核心思想：暴力枚举 + 判断完全平方数

由于 `n <= 250`，可以直接枚举所有满足 `a <= b` 的对 `(a, b)`，检查 `a² + b²` 是否是完全平方数。

**判断完全平方数：** `int(sqrt(x)) ** 2 == x` 或用整数开方判断。

---

## 代码实现

### 方法一：暴力枚举（推荐，简单直接）

```python
import math

class Solution:
    def countPairs(self, n: int) -> int:
        count = 0
        for a in range(1, n + 1):
            for b in range(a, n + 1):
                s = a * a + b * b
                root = int(math.isqrt(s))
                # 判断 s 是否是完全平方数
                if root * root == s:
                    count += 1
        return count
```

### 方法二：哈希集合（预计算平方数）

```python
class Solution:
    def countPairs(self, n: int) -> int:
        # 预计算所有可能的完全平方数（最大为 2n²）
        squares = set(i * i for i in range(1, 2 * n + 1))

        count = 0
        for a in range(1, n + 1):
            for b in range(a, n + 1):
                if a * a + b * b in squares:
                    count += 1
        return count
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n²) | O(1) |
| 方法二 | O(n²) | O(n) |

---

## 关键点总结

1. n 很小（≤ 250），O(n²) 暴力枚举完全可行
2. `math.isqrt(x)` 返回 x 的整数平方根（Python 3.8+），比 `int(math.sqrt(x))` 更精确
3. 判断完全平方数：`isqrt(x) ** 2 == x`

---

## 易错点

- 使用 `math.sqrt` 时可能有浮点精度问题，推荐使用 `math.isqrt`
- 注意 `a <= b` 而非 `a < b`（允许 a = b）
