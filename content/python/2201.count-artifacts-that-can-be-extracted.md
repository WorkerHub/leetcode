## 题目描述

给你一个 `n x n` 的整数矩阵表示一块土地，另有一个下标从 0 开始、大小为 `k` 的二维整数数组 `artifacts`，其中 `artifacts[i] = [r1i, c1i, r2i, c2i]` 表示第 `i` 个神器在矩形区域内（左上角 `(r1i, c1i)`，右下角 `(r2i, c2i)`）。

还给你一个下标从 0 开始、大小为 `m` 的二维整数数组 `dig`，其中 `dig[j] = [rj, cj]` 表示在位置 `(rj, cj)` 进行了挖掘。

当神器所覆盖的所有格子都被挖掘后，该神器就被完整提取出来。返回你可以提取的神器数量。

**示例 1：**
```
输入：n = 2, artifacts = [[0,0,0,0],[0,1,1,1]], dig = [[0,0],[0,1]]
输出：1
解释：第0个神器只覆盖(0,0)，已挖，可提取。第1个神器覆盖3格，只挖了2格，不能提取。
```

**示例 2：**
```
输入：n = 2, artifacts = [[0,0,1,1]], dig = [[0,0],[0,1],[1,0],[1,1]]
输出：1
```

**提示：**
- `1 <= n <= 1000`
- `1 <= artifacts.length, dig.length <= min(n^2, 10^5)`
- `artifacts[i].length == 4`
- `0 <= r1i, c1i, r2i, c2i <= n - 1`
- `r1i <= r2i, c1i <= c2i`

## 解题思路

核心思路：将已挖掘的位置存入哈希集合，对每个神器遍历其覆盖的所有格子，判断是否全部在哈希集合中。

由于神器的总面积不超过 `n^2`，且 `n <= 1000`，直接枚举每个神器覆盖的格子即可。

**算法步骤：**
1. 将 `dig` 中所有位置转为集合 `dug`。
2. 遍历每个神器，枚举其矩形内所有格子。
3. 若所有格子都在 `dug` 中，计数加 1。

## 代码实现

### 方法一：哈希集合模拟（推荐）

```python
from typing import List

class Solution:
    def digArtifacts(self, n: int, artifacts: List[List[int]], dig: List[List[int]]) -> int:
        # 将挖掘位置存入集合，便于 O(1) 查询
        dug = set()
        for r, c in dig:
            dug.add((r, c))

        ans = 0
        for r1, c1, r2, c2 in artifacts:
            extracted = True
            # 枚举神器覆盖的每个格子
            for r in range(r1, r2 + 1):
                for c in range(c1, c2 + 1):
                    if (r, c) not in dug:
                        extracted = False
                        break
                if not extracted:
                    break
            if extracted:
                ans += 1
        return ans
```

### 方法二：统计每个神器已挖格子数

```python
from typing import List
from collections import defaultdict

class Solution:
    def digArtifacts(self, n: int, artifacts: List[List[int]], dig: List[List[int]]) -> int:
        # 预计算每个神器的总格子数和所在区域
        # 用字典记录每个格子属于哪个神器
        cell_to_artifact = {}
        total = []  # 每个神器的总格子数

        for idx, (r1, c1, r2, c2) in enumerate(artifacts):
            count = (r2 - r1 + 1) * (c2 - c1 + 1)
            total.append(count)
            for r in range(r1, r2 + 1):
                for c in range(c1, c2 + 1):
                    cell_to_artifact[(r, c)] = idx

        # 统计每个神器已被挖掘的格子数
        dug_count = defaultdict(int)
        for r, c in dig:
            if (r, c) in cell_to_artifact:
                dug_count[cell_to_artifact[(r, c)]] += 1

        # 判断每个神器是否完整提取
        ans = sum(1 for i in range(len(artifacts)) if dug_count[i] == total[i])
        return ans
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(k + A)，k 为挖掘点数量，A 为所有神器的总面积（不超过 n^2）。
- 空间复杂度：O(k)，哈希集合存储挖掘点。

**方法二：**
- 时间复杂度：O(A + m)，A 为神器总面积，m 为 dig 大小。
- 空间复杂度：O(A + m)。

## 关键点总结

1. 将挖掘位置转为哈希集合是提升效率的关键。
2. 神器总面积受 n^2 限制，枚举格子不会超时。
3. 方法一代码简洁，早终止（break）优化了常数。

## 易错点

- 忘记神器坐标是闭区间（包括 r2 和 c2）。
- 直接用列表查询会导致 O(k) 的查询复杂度，需用集合。
