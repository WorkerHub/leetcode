## 题目描述

给定一个根为 root 的二叉树，每个节点的深度是 该节点到根的最短距离 。

返回包含原始树中所有 最深节点 的 最小子树 。

如果一个节点在 整个树 的任意节点之间具有最大的深度，则该节点是 最深的 。

一个节点的 子树 是该节点加上它的所有后代的集合。

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：我们返回值为 2 的节点，在图中用黄色标记。
在图中用蓝色标记的是树的最深的节点。
注意，节点 6、0 和 8 也是叶节点，但是它们的深度是 2 ，而节点 7 和 4 的深度是 3 。
```

**示例 2：**
```
输入：root = [1]
输出：[1]
```

**示例 3：**
```
输入：root = [0,1,3,null,2]
输出：[2]
```

**提示：**
- 树中节点的数量在 [1, 500] 范围内
- 0 <= Node.val <= 500
- 每个节点的值都是 独一无二 的

## 解题思路

**核心观察：**
- 最深节点的最小子树 = 最深节点的最近公共祖先（LCA）

**算法思路：**
1. DFS 计算每个节点的深度
2. 对于每个节点，返回其子树中最深节点的深度
3. 如果左右子树最深深度相同，当前节点就是 LCA
4. 否则返回更深的那个子树

## Python 代码实现

### 方法一：DFS（推荐）⭐

```python
class Solution:
    def subtreeWithAllDeepest(self, root: TreeNode) -> TreeNode:
        def dfs(node):
            """返回 (最深深度, 包含所有最深节点的子树根)"""
            if not node:
                return (0, None)
            
            left_depth, left_node = dfs(node.left)
            right_depth, right_node = dfs(node.right)
            
            # 左右深度相同，当前节点是答案
            if left_depth == right_depth:
                return (left_depth + 1, node)
            # 左子树更深
            elif left_depth > right_depth:
                return (left_depth + 1, left_node)
            # 右子树更深
            else:
                return (right_depth + 1, right_node)
        
        return dfs(root)[1]
```

### 方法二：两次 DFS

```python
class Solution:
    def subtreeWithAllDeepest(self, root: TreeNode) -> TreeNode:
        # 第一次 DFS：找最大深度
        def max_depth(node):
            if not node:
                return 0
            return 1 + max(max_depth(node.left), max_depth(node.right))
        
        # 第二次 DFS：找 LCA
        def dfs(node, depth, max_d):
            if not node or depth == max_d:
                return node
            
            left = dfs(node.left, depth + 1, max_d)
            right = dfs(node.right, depth + 1, max_d)
            
            if left and right:
                return node
            return left or right
        
        max_d = max_depth(root)
        return dfs(root, 1, max_d)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **LCA 问题**：最深节点的最近公共祖先
2. **一次 DFS**：同时计算深度和查找节点
3. **返回值设计**：返回 (深度, 节点)
