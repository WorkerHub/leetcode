## 题目描述

给你一个字符串 `s` 和一个 **正** 整数 `k`。

从字符串 `s` 中选出一组满足下列条件且 **不重叠** 的子字符串：

- 每个子字符串的长度 **至少** 为 `k`。
- 每个子字符串是一个 **回文串**。

返回最优方案中能选择的子字符串的 **最大** 数目。

**子字符串** 是字符串中一段连续的字符序列。

**示例 1：**
```
输入：s = "abaccdbbd", k = 3
输出：2
解释：选出 2 个不重叠回文子串 "aba"（长度 3）和 "dbbd"（长度 4）。
```

**示例 2：**
```
输入：s = "adbcda", k = 2
输出：0
解释：没有长度至少为 2 的回文子串。
```

**提示：**
- `1 <= k <= s.length <= 2000`
- `s` 只包含小写英文字母

## 解题思路

**贪心 + DP 预处理：**

**贪心策略：** 尽早结束当前选中的回文子串（选最短的满足条件的回文子串），这样后面留出更多空间。

**步骤：**
1. 预处理 `dp[i][j]` = `s[i..j]` 是否为回文串（O(n^2)）
2. 用 `f[i]` = 从 `s[0..i-1]` 中选出的最大回文子串数
3. 转移：对每个位置 `j`，若 `s[j-k+1..j]` 是长度 k 的回文串，则 `f[j+1] = max(f[j+1], f[j-k+1] + 1)`
   - 也需要考虑 `f[j+1] = f[j]`（不选以 j 结尾的子串）

等效实现：
- `dp[i][j]` 判断回文
- 贪心 + 记忆化

## 代码实现

### 方法一：DP 预处理 + 贪心（推荐）

```python
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)

        # 预处理 is_palindrome[i][j] 表示 s[i..j] 是否为回文
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j]:
                    is_pal[i][j] = (j - i <= 2) or is_pal[i + 1][j - 1]

        # f[i] = s[0..i-1] 中选出的最大非重叠回文子串数
        f = [0] * (n + 1)

        for i in range(1, n + 1):
            f[i] = f[i - 1]  # 不以 i-1 结尾的方案
            # 尝试以 i-1 为右端点，长度 >= k 的最短回文子串
            for left in range(i - k, -1, -1):
                if is_pal[left][i - 1]:
                    f[i] = max(f[i], f[left] + 1)
                    break  # 贪心：选最短的（最早结束的），尽快终止

        return f[n]
```

### 方法二：只枚举长度恰好为 k 的回文（优化）

```python
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)

        # Manacher 算法或简单 DP 判断回文
        # 简单方法：dp[i][j]
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j]:
                    is_pal[i][j] = (j - i < 2) or is_pal[i + 1][j - 1]

        f = [0] * (n + 1)

        for i in range(k, n + 1):
            f[i] = f[i - 1]
            # 尝试选长度为 k 和 k+1 的回文（奇偶各一个）
            for length in [k, k + 1]:
                if i - length >= 0 and is_pal[i - length][i - 1]:
                    f[i] = max(f[i], f[i - length] + 1)

        return f[n]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP + 贪心 | O(n^2) | O(n^2) |

## 关键点总结

1. 贪心：尽早（从右端最近的）选最短的满足条件的回文
2. DP 预处理所有子串是否为回文，O(n^2) 时间
3. 注意：只需考虑长度 k 和 k+1 的回文（任何更长的都包含一个 k 或 k+1 的回文核心）

## 易错点

- 贪心时选最短的（最早结束），不是最长的
- 只需枚举长度 k 和 k+1（奇偶）就够了，不需要枚举所有长度
