## 题目描述

有两只老鼠和 `n` 块奶酪，第 `i` 块奶酪被老鼠一号吃掉的得分为 `reward1[i]`，被老鼠二号吃掉的得分为 `reward2[i]`。老鼠一号必须恰好吃 `k` 块奶酪，老鼠二号吃剩下的。

返回这种方案下的最大得分。

**示例 1：**
```
输入：reward1 = [1,1,3,4], reward2 = [4,4,1,1], k = 2
输出：15
解释：老鼠一号吃第 2,3 块（得分 3+4=7），老鼠二号吃第 0,1 块（得分 4+4=8），总分 15
```

**示例 2：**
```
输入：reward1 = [1,1], reward2 = [1,1], k = 2
输出：2
```

**数据范围：**
- 1 <= n == reward1.length == reward2.length <= 10^5
- 1 <= reward2[i], reward1[i] <= 1000
- 0 <= k <= n

## 解题思路

贪心：先假设所有奶酪都由老鼠二号吃，基础得分为 `sum(reward2)`。然后需要从中选 `k` 块给老鼠一号，每换一块的收益为 `reward1[i] - reward2[i]`。

为了最大化总分，应该选择 `reward1[i] - reward2[i]` 最大的 `k` 块给老鼠一号。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def miceAndCheese(self, reward1: List[int], reward2: List[int], k: int) -> int:
        # 基础得分：全给老鼠二号
        base = sum(reward2)
        # 计算换给老鼠一号的额外收益
        diff = sorted([r1 - r2 for r1, r2 in zip(reward1, reward2)], reverse=True)
        # 选前 k 个收益最大的换给老鼠一号
        return base + sum(diff[:k])
```

### 方法二：使用堆（适用于 k 较小时）

```python
from typing import List
import heapq

class Solution:
    def miceAndCheese(self, reward1: List[int], reward2: List[int], k: int) -> int:
        base = sum(reward2)
        # 找前 k 大的 (reward1[i] - reward2[i])
        # 使用最小堆维护 k 个最大差值
        heap = []
        for r1, r2 in zip(reward1, reward2):
            heapq.heappush(heap, r1 - r2)
            if len(heap) > k:
                heapq.heappop(heap)
        return base + sum(heap)
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n log k)，空间复杂度 O(k)

## 关键点总结

1. 将问题转化为：所有都给二号，然后选 k 个换给一号
2. 换的收益是差值 `reward1[i] - reward2[i]`
3. 贪心选差值最大的 k 个

## 易错点

1. 差值可能为负，但仍然要选 k 个（即使所有差值都是负的）
2. k=0 时不换任何，结果就是 sum(reward2)
3. k=n 时全给一号，结果就是 sum(reward1)
