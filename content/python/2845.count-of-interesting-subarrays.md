## 题目描述

给你一个下标从 0 开始的整数数组 `nums`，以及整数 `modulo` 和 `k`。

如果满足以下条件，则子数组 `nums[l..r]` 是一个**有趣子数组**：

设 `cnt` 为 `nums[l..r]` 中满足 `nums[i] % modulo == k` 的下标数量，则 `cnt % modulo == k`。

返回有趣子数组的数量。

**示例 1：**
```
输入：nums = [3,2,4], modulo = 2, k = 1
输出：3
解释：满足 nums[i] % 2 == 1 的下标：0（nums[0]=3），结果 cnt % 2 == k
子数组 [3]：cnt=1，1%2=1=k ✓
子数组 [3,2]：cnt=1，1%2=1=k ✓
子数组 [3,2,4]：cnt=1，1%2=1=k ✓
子数组 [2]：cnt=0，0%2=0≠1 ✗
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= modulo <= 10^9`
- `0 <= k < modulo`

## 解题思路

**前缀和 + 哈希表（类似两数之和的前缀和技巧）：**

设 `prefix[i]` = 前 i 个元素中满足 `nums[j] % modulo == k` 的个数。

对于子数组 `[l, r]`，`cnt = prefix[r+1] - prefix[l]`。

条件：`cnt % modulo == k`，即 `(prefix[r+1] - prefix[l]) % modulo == k`。

等价于：`prefix[r+1] % modulo == (prefix[l] + k) % modulo`（对 modulo 取模后）。

**算法：** 遍历时维护 `prefix % modulo` 的频次哈希表，对每个新的前缀和值查找有多少之前的前缀和满足条件。

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from collections import defaultdict
from typing import List

class Solution:
    def countInterestingSubarrays(self, nums: List[int], modulo: int, k: int) -> int:
        n = len(nums)
        # cnt_mod[v] = 前缀和 mod modulo 等于 v 的次数
        cnt_mod = defaultdict(int)
        cnt_mod[0] = 1  # 空前缀，前缀和为 0

        prefix = 0
        ans = 0

        for x in nums:
            # 更新前缀和（只关心模 modulo 的值）
            if x % modulo == k:
                prefix = (prefix + 1) % modulo

            # 找满足条件的之前的前缀和
            # 需要 (prefix - prev_prefix) % modulo == k
            # 即 prev_prefix % modulo == (prefix - k + modulo) % modulo
            need = (prefix - k + modulo) % modulo
            ans += cnt_mod[need]

            # 记录当前前缀和
            cnt_mod[prefix] += 1

        return ans
```

### 方法二：带详细注释

```python
from collections import defaultdict
from typing import List

class Solution:
    def countInterestingSubarrays(self, nums: List[int], modulo: int, k: int) -> int:
        freq = defaultdict(int)
        freq[0] = 1  # 前缀和为 0（对应空前缀，下标 i=-1）

        pre = 0   # 当前前缀中满足条件的元素数（模 modulo）
        ans = 0

        for num in nums:
            # 如果当前元素满足 num % modulo == k，前缀计数加 1
            pre = (pre + (1 if num % modulo == k else 0)) % modulo

            # 我们需要：(pre - prev_pre) % modulo == k
            # 即 prev_pre % modulo == (pre - k + modulo) % modulo
            target = (pre - k + modulo) % modulo
            ans += freq[target]

            # 记录当前前缀和的频次
            freq[pre] += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(modulo)，哈希表最多存 modulo 个不同的余数值

## 关键点总结

1. 前缀和计数只关心模 modulo 的值
2. 利用模运算性质：`(a - b) % m == k` 等价于 `a % m == (b + k) % m`
3. 哈希表维护之前所有前缀和模 modulo 的频次

## 易错点

1. `(prefix - k + modulo) % modulo` 中的 `+ modulo` 防止负数取模
2. 空前缀的初始化：`freq[0] = 1`（前缀和为 0 出现一次）
3. 注意先查找满足条件的 `prev_prefix`，再记录当前 `prefix`（防止同一位置重复计数）
