## 题目描述

给你一个字符串 `s` 和一个正整数 `k`。

若一个子字符串满足：
- 元音个数和辅音个数相等
- 元音个数 * 辅音个数可以被 `k` 整除

则称它为 **美丽子字符串**。

返回字符串 `s` 中美丽子字符串的数目。

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `1 <= k <= 1000`

## 解题思路

设子串长度为 2m（元音=辅音=m），条件 m^2 % k == 0。

设 `d = k / gcd(k, m)`，则 m^2 % k == 0 等价于 m % (k / gcd(k,m)) == 0，更等价于 m 是 `sqrt_k / gcd(sqrt_k, m)` 的倍数……

正确分析：m^2 % k == 0，令 `g = gcd(m, k)`，则 m = g * (m/g)，k = g * (k/g)，条件变为 g * (m/g)^2 % (k/g) == 0，即 (m/g)^2 % (k/g) == 0，需要 (k/g) | (m/g)^2。

实际简化：枚举所有满足 m^2 % k == 0 的 m 值（m 在 1 到 n/2 之间），对每个这样的 m（子串长度 2m），用前缀和 + 哈希表统计。

利用前缀和技巧：将元音记为 +1，辅音记为 -1，子串 [l, r] 的元音数 = 辅音数 等价于前缀和 prefix[r+1] - prefix[l] = 0，且长度 r-l+1 = 2m 被适当的 2m 整除。

## Python 代码实现

### 方法一：枚举有效 m + 前缀和 + 哈希表（推荐）

```python
from math import gcd
from collections import defaultdict

class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(s)

        # 计算满足 m^2 % k == 0 的最小正整数 p（最小有效周期）
        # 等价：找最小 p 使得 p^2 % k == 0
        # p 即为所有合法 m 的公因子，每个合法 m 是 p 的倍数
        p = 1
        while p * p % k != 0:
            p += 1
        # 每个合法的 m 是 p 的倍数

        # 前缀差：元音+1，辅音-1
        # prefix[i] = sum of (1 if vowel else -1) for s[0..i-1]
        # 子串 [l, r] 中元音=辅音 <=> prefix[r+1] - prefix[l] = 0
        # 子串长度 2m，m 是 p 的倍数

        # 对于固定 p，子串长度 2m = 2*p, 4*p, ...
        # 等价：子串长度必须是 2p 的倍数
        # 即 (r+1 - l) % (2*p) == 0，且 prefix[r+1] == prefix[l]

        # 用哈希表统计 (prefix_val, (index) % (2p)) 出现的次数
        # 对每个 i，若 (prefix[i], i % (2p)) 在哈希表中出现过，累加计数

        period = 2 * p
        cnt = defaultdict(int)
        prefix = 0
        ans = 0
        cnt[(0, 0)] = 1  # prefix[0]=0, 0%(2p)=0

        for i in range(1, n + 1):
            prefix += 1 if s[i - 1] in vowels else -1
            key = (prefix, i % period)
            ans += cnt[key]
            cnt[key] += 1

        return ans
```

### 方法二：暴力枚举（小数据验证）

```python
class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(s)
        ans = 0
        for l in range(n):
            v = 0
            for r in range(l, n):
                v += 1 if s[r] in vowels else 0
                length = r - l + 1
                c = length - v
                if v == c and v * c % k == 0:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(k))，其中 sqrt(k) 是求最小周期 p 的时间
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. m^2 % k == 0 的最小 m 记为 p，所有合法 m 都是 p 的倍数
2. 子串长度必须是 2p 的倍数，利用模运算限制
3. 哈希表 key = (前缀差值, 下标 % 2p)，当两个位置 key 相同时，它们之间的子串满足条件

## 易错点

1. p 的计算：从 1 开始找第一个满足 p^2 % k == 0 的 p
2. 哈希表中初始条件：(prefix[0]=0, 0%period=0) 计数为 1
3. key 中需要同时包含前缀值和下标模值
