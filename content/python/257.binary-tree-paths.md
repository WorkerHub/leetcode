## 题目描述

给你一个二叉树的根节点 `root`，按任意顺序，返回所有从根节点到叶子节点的路径。

叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
解释：
    1
   / \
  2   3
   \
    5
```

**示例 2：**

```
输入：root = [1]
输出：["1"]
```

**提示：**
- 树中节点的数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

这是一道经典的树的遍历问题，需要找出所有从根到叶子的路径。

核心思想：
1. 使用深度优先搜索（DFS）遍历树
2. 维护当前路径
3. 当到达叶子节点时，将路径加入结果
4. 回溯到父节点，继续探索其他路径

关键点：
- 叶子节点：左右子节点都为空
- 路径格式：使用 "->" 连接节点值
- 回溯：在递归返回时需要恢复状态

## Python 代码实现

### 方法一：DFS + 回溯（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        """
        深度优先搜索 + 回溯
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if not root:
            return []
        
        result = []
        
        def dfs(node: TreeNode, path: List[str]):
            """
            node: 当前节点
            path: 从根到当前节点的路径
            """
            # 将当前节点加入路径
            path.append(str(node.val))
            
            # 如果是叶子节点，记录路径
            if not node.left and not node.right:
                result.append("->".join(path))
            else:
                # 递归遍历左子树
                if node.left:
                    dfs(node.left, path)
                # 递归遍历右子树
                if node.right:
                    dfs(node.right, path)
            
            # 回溯：移除当前节点
            path.pop()
        
        dfs(root, [])
        return result
```

### 方法二：DFS + 字符串拼接

```python
from typing import List, Optional

class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        """
        直接拼接字符串，不需要回溯
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if not root:
            return []
        
        result = []
        
        def dfs(node: TreeNode, path: str):
            """
            node: 当前节点
            path: 从根到当前节点的路径字符串
            """
            # 如果是叶子节点
            if not node.left and not node.right:
                result.append(path + str(node.val))
                return
            
            # 非叶子节点，继续拼接路径
            path += str(node.val) + "->"
            
            if node.left:
                dfs(node.left, path)
            if node.right:
                dfs(node.right, path)
        
        dfs(root, "")
        return result
```

### 方法三：BFS（层序遍历）

```python
from typing import List, Optional
from collections import deque

class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        """
        广度优先搜索
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if not root:
            return []
        
        result = []
        # 队列存储 (节点, 路径字符串)
        queue = deque([(root, str(root.val))])
        
        while queue:
            node, path = queue.popleft()
            
            # 如果是叶子节点
            if not node.left and not node.right:
                result.append(path)
                continue
            
            # 将子节点和路径加入队列
            if node.left:
                queue.append((node.left, path + "->" + str(node.left.val)))
            if node.right:
                queue.append((node.right, path + "->" + str(node.right.val)))
        
        return result
```

### 方法四：递归分治

```python
from typing import List, Optional

class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        """
        递归分治：分别获取左右子树的路径，然后拼接
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if not root:
            return []
        
        # 叶子节点
        if not root.left and not root.right:
            return [str(root.val)]
        
        paths = []
        
        # 获取左子树的所有路径
        left_paths = self.binaryTreePaths(root.left)
        for path in left_paths:
            paths.append(str(root.val) + "->" + path)
        
        # 获取右子树的所有路径
        right_paths = self.binaryTreePaths(root.right)
        for path in right_paths:
            paths.append(str(root.val) + "->" + path)
        
        return paths
```

### 方法五：一行递归（Python 特色）

```python
from typing import List, Optional

class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        """
        简洁的递归写法
        """
        if not root:
            return []
        if not root.left and not root.right:
            return [str(root.val)]
        
        return [str(root.val) + "->" + path 
                for subtree in (root.left, root.right) if subtree
                for path in self.binaryTreePaths(subtree)]
```

## 复杂度分析

所有方法的复杂度相同：
- 时间复杂度：O(n)，需要访问每个节点一次
- 空间复杂度：O(n)，递归栈或队列的空间，最坏情况下（链状树）为 O(n)

## 图解示例

以 `root = [1,2,3,null,5]` 为例：

```
树结构：
    1
   / \
  2   3
   \
    5

DFS 遍历过程：
1. 访问节点 1，path = ["1"]
   ├─ 访问节点 2，path = ["1", "2"]
   │  ├─ 左子树为空
   │  └─ 访问节点 5，path = ["1", "2", "5"]
   │     └─ 叶子节点！记录 "1->2->5"
   │     └─ 回溯到节点 2
   └─ 回溯到节点 1
   └─ 访问节点 3，path = ["1", "3"]
      └─ 叶子节点！记录 "1->3"

结果：["1->2->5", "1->3"]
```

```
BFS 遍历过程：
初始队列：[(1, "1")]

第1步：
  出队：(1, "1")
  入队：(2, "1->2"), (3, "1->3")

第2步：
  出队：(2, "1->2")
  入队：(5, "1->2->5")
  
  出队：(3, "1->3")
  是叶子，记录 "1->3"

第3步：
  出队：(5, "1->2->5")
  是叶子，记录 "1->2->5"

结果：["1->3", "1->2->5"]
```

## 关键点总结

1. **叶子节点判断**：左右子节点都为空时才是叶子
2. **路径维护**：使用数组或字符串维护当前路径
3. **回溯技巧**：使用数组时需要 pop()，使用字符串拼接不需要回溯
4. **DFS vs BFS**：两种方法都可以，DFS 更常用
5. **路径格式**：使用 "->" 连接节点值

## 易错点

1. **忘记判断叶子节点**
   ```python
   # 错误：只要节点存在就记录
   if node:
       result.append(path)
   
   # 正确：只有叶子节点才记录
   if not node.left and not node.right:
       result.append(path)
   ```

2. **回溯忘记 pop**
   ```python
   # 错误：没有回溯
   path.append(str(node.val))
   if node.left:
       dfs(node.left, path)
   # 缺少 path.pop()
   
   # 正确：记得回溯
   path.append(str(node.val))
   if node.left:
       dfs(node.left, path)
   if node.right:
       dfs(node.right, path)
   path.pop()  # 回溯
   ```

3. **路径格式错误**
   ```python
   # 错误：会产生多余的 "->"
   path = str(node.val) + "->"
   
   # 正确：只在非叶子节点时添加 "->"
   if not node.left and not node.right:
       result.append(path + str(node.val))
   else:
       path += str(node.val) + "->"
   ```

4. **空树处理**
   ```python
   # 记得处理 root 为 None 的情况
   if not root:
       return []
   ```
