## 题目描述

给你两个字符串 `s` 和 `sub`，以及一个二维字符串数组 `mappings`，其中 `mappings[i] = [old_i, new_i]` 表示可以将 `sub` 中的字符 `old_i` 替换为 `new_i`。

如果在将 `sub` 中所有字符（可能零次或多次）进行上述替换操作之后，`sub` 是 `s` 的一个子字符串，则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：s = "fool3e7bar", sub = "leet", mappings = [["e","3"],["t","7"],["t","8"]]
输出：true
解释：将 sub 中的 'e' 替换为 '3'，'t' 替换为 '7'，得到 "l3e7" 不对，"l337" 也不对，
实际上 "leet" -> "l3e7" 是将第1个'e'替换为'3'，第2个't'替换为'7'，得到 "l3e7" = s[3..6]，返回 true。
```

**示例 2：**
```
输入：s = "fooleetbar", sub = "f00l", mappings = [["o","0"]]
输出：false
解释：字符 '0' 不在 sub 中，无法替换。
```

**提示：**
- `1 <= sub.length <= s.length <= 5000`
- `0 <= mappings.length <= 1000`
- `mappings[i].length == 2`
- `old_i != new_i`
- `s` 和 `sub` 由英文字母、数字和特殊符号组成

## 解题思路

**核心思想：**
预处理每个字符可以被替换为哪些字符，构建替换集合。然后枚举 `s` 中所有起始位置，检查从该位置开始的子串是否能与 `sub` 匹配。

**算法步骤：**
1. 构建哈希表 `can[c]` 表示 `sub` 中字符 `c` 可以替换为的字符集合（包含 `c` 本身）。
2. 枚举 `s` 中每个起始位置 `i`，逐字符检查 `s[i+j]` 是否在 `can[sub[j]]` 中。
3. 若所有字符均匹配，返回 `true`。

## 代码实现

### 方法一：哈希表预处理 + 枚举（推荐）

```python
from typing import List

class Solution:
    def matchReplacement(self, s: str, sub: str, mappings: List[List[str]]) -> bool:
        # 构建替换映射：每个字符可以替换为哪些字符
        can = {}
        for c in sub:
            if c not in can:
                can[c] = {c}  # 字符本身也算合法
        for old, new in mappings:
            if old in can:
                can[old].add(new)

        n, m = len(s), len(sub)
        # 枚举 s 中所有可能的起始位置
        for i in range(n - m + 1):
            matched = True
            for j in range(m):
                # 检查 s[i+j] 是否在 sub[j] 的替换集合中
                if s[i + j] not in can[sub[j]]:
                    matched = False
                    break
            if matched:
                return True
        return False
```

### 方法二：使用集合数组优化

```python
from typing import List

class Solution:
    def matchReplacement(self, s: str, sub: str, mappings: List[List[str]]) -> bool:
        # 对 sub 中每个位置的字符构建可接受字符集
        can = []
        for c in sub:
            can.append({c})
        
        # 填充替换规则
        for old, new in mappings:
            for i, c in enumerate(sub):
                if c == old:
                    can[i].add(new)
        
        n, m = len(s), len(sub)
        for i in range(n - m + 1):
            # 检查从位置 i 开始是否能匹配
            if all(s[i + j] in can[j] for j in range(m)):
                return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n * m + k) | O(m + k) |
| 方法二 | O(n * m + k) | O(m * k) |

其中 n = len(s)，m = len(sub)，k = len(mappings)。

## 关键点总结

1. 预处理替换关系为集合，避免每次匹配都遍历 mappings。
2. 每个字符的替换集合必须包含字符本身（不替换也是合法的）。
3. 只统计 sub 中出现的字符的替换集合，避免无用计算。

## 易错点

- 忘记将字符本身加入可替换集合中。
- 边界处理：`i` 的范围为 `range(n - m + 1)`，避免越界。
