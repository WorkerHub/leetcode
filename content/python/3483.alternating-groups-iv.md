## 题目描述

给你一个整数数组 `colors`（环形），其中每个元素为 0 或 1，以及一个二维整数数组 `queries`。

每个查询 `queries[i] = [type, size]`：
- `type = 1`：翻转 `colors[size]`（0 变 1，1 变 0）
- `type = 2`：返回数组中长度恰好为 `size` 的交替组的数量（交替组是连续的颜色交替变化的子数组，首尾相连视为环形）

**提示：**
- `3 <= colors.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

维护每个位置是否与前一个位置不同（差分数组 `diff[i] = 1 if colors[i] != colors[i-1] else 0`）。

一个长度为 k 的交替组从位置 i 开始，要求 `diff[i+1], ..., diff[i+k-1]` 全为 1（环形）。

等价于：统计差分数组中"连续 1 的段"，计算长度 >= k-1 的段有多少段以及各段的贡献。

翻转操作会改变最多 2 个 diff 值。

## Python 代码实现

### 方法一：维护差分 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        n = len(colors)

        # diff[i] = 1 if colors[i] != colors[(i-1+n)%n]
        diff = [0] * n
        for i in range(n):
            diff[i] = 1 if colors[i] != colors[(i - 1 + n) % n] else 0

        # 找所有连续 1 的段（在环形中）
        # 用有序集合记录所有 diff[i] = 0 的位置（段的分隔符）
        # 每段的长度 = 两个相邻 0 位置之差 - 1

        zeros = SortedList()
        for i in range(n):
            if diff[i] == 0:
                zeros.add(i)

        def seg_len(zero_pos):
            """从 zero_pos 开始的连续 1 段的长度"""
            idx = zeros.index(zero_pos)
            next_zero = zeros[(idx + 1) % len(zeros)]
            if next_zero > zero_pos:
                return next_zero - zero_pos - 1
            else:
                return n - zero_pos - 1 + next_zero

        # 对长度为 k 的查询，交替组数 = sum(max(0, seg_len - (k-2)) for each seg)
        # 因为一段长度为 L 的连续 1 可以产生 L - (k-2) 个长度为 k-1 的交替组
        # 等价于：长度为 k 的交替组数量

        # 预处理：统计所有段长度的贡献（复杂，这里给出框架）

        results = []
        for q in queries:
            if q[0] == 1:
                # 翻转操作
                pos = q[1]
                colors[pos] ^= 1
                # 更新 diff[pos] 和 diff[(pos+1)%n]
                for idx in [pos, (pos + 1) % n]:
                    new_diff = 1 if colors[idx] != colors[(idx - 1 + n) % n] else 0
                    if diff[idx] != new_diff:
                        if new_diff == 0:
                            zeros.add(idx)
                        else:
                            zeros.remove(idx)
                        diff[idx] = new_diff
            else:
                # 查询长度为 k 的交替组数
                k = q[1]
                count = 0
                if len(zeros) == 0:
                    # 全是 1：整个数组是一个环形交替组
                    count = n
                else:
                    seen = set()
                    for z in zeros:
                        l = seg_len(z)
                        if l >= k - 1:
                            count += l - (k - 2)
                results.append(count)

        return results
```

### 方法二：线段树维护段信息

```python
from typing import List

class Solution:
    def numberOfAlternatingGroups(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        n = len(colors)

        # 差分数组
        diff = [1 if colors[i] != colors[(i - 1 + n) % n] else 0 for i in range(n)]

        # 暴力计算（用于小数据）
        def count_groups(k):
            cnt = 0
            # 扩展数组处理环形
            extended = diff * 2
            # 统计长度 >= k-1 的连续 1 段
            # 每个长度为 L 的段贡献 max(0, L - k + 2) 个组
            i = 0
            while i < n:
                if extended[i] == 1:
                    j = i
                    while j < 2 * n and extended[j] == 1:
                        j += 1
                    seg = j - i
                    if seg >= k - 1 and i < n:
                        # 段从 i 到 j-1，有效起点在 [i, i + seg - (k-1)]
                        contrib = min(seg - k + 2, n - i)
                        if contrib > 0:
                            cnt += contrib
                    i = j
                else:
                    i += 1
            return cnt

        results = []
        for q in queries:
            if q[0] == 1:
                pos = q[1]
                colors[pos] ^= 1
                for idx in [pos, (pos + 1) % n]:
                    diff[idx] = 1 if colors[idx] != colors[(idx - 1 + n) % n] else 0
            else:
                results.append(count_groups(q[1]))

        return results
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，q 为查询数量
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组：`diff[i] = 1` 表示 i 和 i-1 颜色不同
2. 交替组等价于差分数组中连续 1 的段
3. 翻转操作最多影响相邻 2 个 diff 值
4. 用有序集合维护 diff=0 的位置，快速计算段长度

## 易错点

1. 环形数组：diff[0] 对应 colors[0] 和 colors[n-1]
2. 长度为 k 的交替组需要差分数组中连续 k-1 个 1
3. 翻转后要更新 diff[pos] 和 diff[(pos+1)%n] 两个位置
