## 题目描述

给定一个整数数组,返回其非空子数组(连续元素)的最大和,你可以选择删除其中最多一个元素。

**示例 1:**

```
输入: arr = [1,-2,0,3]
输出: 4
解释: 可以选择子数组 [1, -2, 0, 3],删除 -2,得到 [1, 0, 3],和为 4
```

**示例 2:**

```
输入: arr = [1,-2,-2,3]
输出: 3
解释: 直接选择子数组 [3],和为 3
```

**示例 3:**

```
输入: arr = [-1,-1,-1,-1]
输出: -1
解释: 最终的子数组不能为空,所以选择 [-1],和为 -1
```

**提示:**
- `1 <= arr.length <= 10^5`
- `-10^4 <= arr[i] <= 10^4`

## 解题思路

这道题是经典的最大子数组和问题(Kadane算法)的变形。

**核心思想:**
使用动态规划,维护两个状态:
1. `dp0[i]`: 以 `i` 结尾的子数组的最大和(不删除任何元素)
2. `dp1[i]`: 以 `i` 结尾的子数组的最大和(删除了一个元素)

**状态转移:**
- `dp0[i] = max(dp0[i-1] + arr[i], arr[i])`
  - 要么延续前面的子数组,要么重新开始

- `dp1[i] = max(dp1[i-1] + arr[i], dp0[i-1])`
  - 要么延续前面已删除一个元素的子数组
  - 要么删除当前元素(即使用 `dp0[i-1]` 跳过当前元素)

**最终答案:**
- `max(max(dp0), max(dp1))`

## Python 代码实现

### 方法一: 动态规划(推荐)

```python
from typing import List

class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        """
        使用两个 dp 数组分别记录不删除和删除一个元素的最大和
        """
        n = len(arr)
        
        # dp0[i]: 以 i 结尾,不删除元素的最大子数组和
        # dp1[i]: 以 i 结尾,删除一个元素的最大子数组和
        dp0 = [0] * n
        dp1 = [0] * n
        
        # 初始化
        dp0[0] = arr[0]
        dp1[0] = 0  # 第一个元素不能删除(子数组不能为空)
        
        # 记录最大值
        max_sum = arr[0]
        
        for i in range(1, n):
            # 不删除元素: 要么延续,要么重新开始
            dp0[i] = max(dp0[i - 1] + arr[i], arr[i])
            
            # 删除一个元素: 
            # 1. 延续之前删除一个元素的结果
            # 2. 删除当前元素(使用之前不删除的结果)
            dp1[i] = max(dp1[i - 1] + arr[i], dp0[i - 1])
            
            # 更新最大值
            max_sum = max(max_sum, dp0[i], dp1[i])
        
        return max_sum
```

### 方法二: 空间优化版

```python
from typing import List

class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        """
        空间优化,只使用两个变量
        """
        n = len(arr)
        
        # no_delete: 不删除元素的最大和
        # one_delete: 删除一个元素的最大和
        no_delete = arr[0]
        one_delete = 0
        
        max_sum = arr[0]
        
        for i in range(1, n):
            # 更新 one_delete 要在 no_delete 之前
            # 因为新的 one_delete 需要用到旧的 no_delete
            one_delete = max(one_delete + arr[i], no_delete)
            no_delete = max(no_delete + arr[i], arr[i])
            
            max_sum = max(max_sum, no_delete, one_delete)
        
        return max_sum
```

### 方法三: 更清晰的变量命名

```python
from typing import List

class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        """
        使用更清晰的变量名
        """
        n = len(arr)
        
        # 当前位置结尾的最大和(未删除)
        max_ending_without_delete = arr[0]
        # 当前位置结尾的最大和(已删除一个)
        max_ending_with_delete = 0
        
        result = arr[0]
        
        for i in range(1, n):
            # 先更新已删除的情况
            # 选项1: 继续之前已删除的子数组
            # 选项2: 删除当前元素
            new_with_delete = max(
                max_ending_with_delete + arr[i],
                max_ending_without_delete
            )
            
            # 更新未删除的情况
            # 选项1: 继续之前的子数组
            # 选项2: 从当前元素重新开始
            new_without_delete = max(
                max_ending_without_delete + arr[i],
                arr[i]
            )
            
            max_ending_with_delete = new_with_delete
            max_ending_without_delete = new_without_delete
            
            result = max(result, max_ending_without_delete, max_ending_with_delete)
        
        return result
```

### 方法四: Kadane算法变形(从两个方向)

```python
from typing import List

class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        """
        从两个方向分别计算 Kadane 算法
        """
        n = len(arr)
        
        # forward[i]: 从左到右,以 i 结尾的最大子数组和
        forward = [0] * n
        forward[0] = arr[0]
        for i in range(1, n):
            forward[i] = max(forward[i - 1] + arr[i], arr[i])
        
        # backward[i]: 从右到左,以 i 开始的最大子数组和
        backward = [0] * n
        backward[n - 1] = arr[n - 1]
        for i in range(n - 2, -1, -1):
            backward[i] = max(backward[i + 1] + arr[i], arr[i])
        
        # 不删除任何元素的最大和
        result = max(forward)
        
        # 删除一个元素的最大和
        # 删除位置 i,连接 forward[i-1] 和 backward[i+1]
        for i in range(1, n - 1):
            result = max(result, forward[i - 1] + backward[i + 1])
        
        return result
```

## 复杂度分析

**方法一/二/三:**
- 时间复杂度: O(n),遍历数组一次
- 空间复杂度: O(1),只使用常数个变量(方法二/三)或 O(n)(方法一)

**方法四:**
- 时间复杂度: O(n)
- 空间复杂度: O(n),需要两个辅助数组

## 图解示例

**示例: arr = [1, -2, 0, 3]**

```
索引:     0   1   2   3
元素:     1  -2   0   3

dp0:     1  -1   0   3
         ↑   ↑   ↑   ↑
        从1  继续 重新 继续
        开始 或重新 开始

dp1:     0   1   1   4
         ↑   ↑   ↑   ↑
        不能 删-2  继续 继续
        删除 或延续

最大值 = max(dp0, dp1) = 4
解释: [1, -2, 0, 3] 删除 -2 得到 [1, 0, 3]
```

## 关键点总结

1. 维护两个状态: 不删除和删除一个元素
2. `dp1[i]` 的转移: 删除当前元素或延续之前的删除状态
3. 空间优化: 只需要两个变量即可
4. 这是 Kadane 算法的变形
5. 注意子数组不能为空,至少包含一个元素

## 易错点

1. 忘记子数组不能为空的限制
2. 状态转移方程写错,特别是 `dp1` 的转移
3. 空间优化时变量更新顺序错误
4. 初始化错误: `dp1[0]` 应该是 0(第一个元素不能删)
5. 最终答案忘记同时考虑 `dp0` 和 `dp1`
6. 全是负数的情况处理错误
