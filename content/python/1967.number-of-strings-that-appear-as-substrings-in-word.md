## 题目描述

给你一个字符串数组 `patterns` 和一个字符串 `word`，统计 `patterns` 中有多少字符串是 `word` 的子字符串，并返回该数目。

**示例 1：**
```
输入：patterns = ["a","abc","bc","d"], word = "abc"
输出：3
解释："a" 是子串，"abc" 是子串，"bc" 是子串，"d" 不是子串
```

**示例 2：**
```
输入：patterns = ["a","b","c"], word = "aaaaabbbbb"
输出：2
解释："a" 和 "b" 是子串，"c" 不是
```

**提示：**
- `1 <= patterns.length <= 100`
- `1 <= patterns[i].length <= 100`
- `1 <= word.length <= 100`

---

## 解题思路

### 核心思想：直接使用 Python in 运算符

对每个 `pattern`，检查它是否在 `word` 中，即 `pattern in word`。

---

## 代码实现

### 方法一：in 运算符（推荐）

```python
from typing import List

class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        return sum(p in word for p in patterns)
```

### 方法二：str.find 方法

```python
from typing import List

class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        count = 0
        for p in patterns:
            if word.find(p) != -1:
                count += 1
        return count
```

### 方法三：str.count 方法

```python
from typing import List

class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        # word.count(p) > 0 表示 p 是 word 的子串
        return sum(1 for p in patterns if word.count(p) > 0)
```

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(sum(|p| * |word|)) | O(1) |

---

## 关键点总结

1. Python 的 `in` 运算符对字符串进行子串检查
2. `sum(p in word for p in patterns)` 是最简洁的 Python 写法
