## 题目描述

给定一个整数数组 `nums`。每次操作可以选择一个子数组，将其所有元素乘以 `-1`（取反）。求使数组所有元素之和为正数（> 0）所需的最少操作次数。如果无法实现，返回 `-1`。

**示例 1：**

```
输入：nums = [-1, -2, -3]
输出：1
解释：取反整个数组 -> [1, 2, 3]，和为 6 > 0。
```

**示例 2：**

```
输入：nums = [1, -2, 1]
输出：1
解释：取反 [-2] -> [1, 2, 1]，和为 4 > 0。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

贪心思路：
1. 每次操作取反一个子数组，可以将负数区段变为正数
2. 贪心地找最大的连续负数段取反，收益最大
3. 使用前缀和分析取反后的和变化

关键观察：每次取反子数组 `[i, j]`，总和变化量为 `-2 * sum(nums[i:j+1])`。想让总和增加，需要 `sum(nums[i:j+1]) < 0`，即取反负数子数组。

贪心策略：每次找最小（最负）的子数组和取反，每次操作收益最大。

## Python 代码实现

### 方法一：贪心取反最大负和子数组（推荐）

```python
from typing import List

class Solution:
    def makePositive(self, nums: List[int]) -> int:
        total = sum(nums)
        if total > 0:
            return 0

        # 找最小子数组和（最负的连续子数组）并取反
        # Kadane's 算法找最小子数组和
        ops = 0
        arr = list(nums)

        while sum(arr) <= 0:
            # 找最小子数组和
            min_sum = float('inf')
            min_start = min_end = 0
            cur_sum = 0
            start = 0

            for i, x in enumerate(arr):
                cur_sum += x
                if cur_sum < min_sum:
                    min_sum = cur_sum
                    min_start = start
                    min_end = i
                if cur_sum > 0:
                    cur_sum = 0
                    start = i + 1

            if min_sum >= 0:
                return -1  # 所有子数组和都 >= 0，无法增加总和

            # 取反最小子数组
            for i in range(min_start, min_end + 1):
                arr[i] = -arr[i]
            ops += 1

            if ops > len(arr):  # 防止死循环
                return -1

        return ops
```

### 方法二：统计负数个数贪心

```python
from typing import List

class Solution:
    def makePositive(self, nums: List[int]) -> int:
        # 统计前缀和为负的位置，每次操作消除一段负前缀
        n = len(nums)
        total = sum(nums)

        if total > 0:
            return 0

        # 如果所有元素之和 <= 0 且全为非负，则不可能
        if all(x >= 0 for x in nums):
            return -1 if total <= 0 else 0

        # 贪心：每次找最负的连续段取反
        ops = 0
        arr = list(nums)
        MAX_OPS = 2 * n

        for _ in range(MAX_OPS):
            if sum(arr) > 0:
                return ops
            # 找当前最小子数组和
            min_val = 0
            min_end = -1
            min_start_candidate = 0
            cur = 0
            cur_start = 0
            min_actual_start = 0

            for i in range(n):
                cur += arr[i]
                if cur < min_val:
                    min_val = cur
                    min_end = i
                    min_actual_start = cur_start
                if cur > 0:
                    cur = 0
                    cur_start = i + 1

            if min_end == -1:
                return -1

            for i in range(min_actual_start, min_end + 1):
                arr[i] = -arr[i]
            ops += 1

        return -1
```

## 复杂度分析

- 时间复杂度：O(n^2)，最多 O(n) 次操作，每次 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每次取反最大负和子数组，最大化收益
2. 使用 Kadane 算法变体找最小子数组和
3. 若所有子数组和均 >= 0 但总和 <= 0，返回 -1

## 易错点

1. 全零数组：总和为 0，不是正数，但无法取反变大（返回 -1）
2. 需要防止死循环，设置最大操作次数限制
3. 取反后可能产生新的负数区段
