## 题目描述

Alice 和 Bob 共用一个无向图，图中有 `n` 个节点和三种边：
- 类型 1（仅 Alice 可用）
- 类型 2（仅 Bob 可用）
- 类型 3（Alice 和 Bob 都可用）

请你在确保 Alice 和 Bob 都能完全遍历整个图（即图对两人都连通）的前提下，移除**最多数目**的边，返回可移除的最大边数。若无法实现，返回 -1。

**提示：**
- `1 <= n <= 10^5`
- `1 <= edges.length <= min(10^5, n*(n-1)/2)`

## 解题思路

### 并查集（贪心 + DSU）

**策略：** 优先添加类型 3 的边（两人共用，效率最高），然后分别为 Alice 和 Bob 添加类型 1、2 的边。

**步骤：**
1. 用两个并查集（Alice 和 Bob 各一个），先加所有类型 3 边（同时更新两个 DSU）
2. 再为 Alice 加类型 1 边，为 Bob 加类型 2 边
3. 若某条边两端已连通（在对应 DSU 中），则该边可以移除
4. 最后检查两个 DSU 是否都已连通（组件数为 1）

## 代码实现

### 方法一：双并查集（推荐）

```python
from typing import List

class Solution:
    def maxNumEdgesToRemove(self, n: int, edges: List[List[int]]) -> int:
        # 并查集
        class DSU:
            def __init__(self, n):
                self.parent = list(range(n + 1))
                self.rank = [0] * (n + 1)
                self.components = n

            def find(self, x):
                while self.parent[x] != x:
                    self.parent[x] = self.parent[self.parent[x]]
                    x = self.parent[x]
                return x

            def union(self, x, y):
                px, py = self.find(x), self.find(y)
                if px == py:
                    return False  # 已连通，边可以移除
                if self.rank[px] < self.rank[py]:
                    px, py = py, px
                self.parent[py] = px
                if self.rank[px] == self.rank[py]:
                    self.rank[px] += 1
                self.components -= 1
                return True  # 新增连接

            def is_connected(self):
                return self.components == 1

        alice = DSU(n)
        bob = DSU(n)
        removed = 0

        # 优先处理类型 3 边（两人共用）
        for t, u, v in edges:
            if t == 3:
                a = alice.union(u, v)
                b = bob.union(u, v)
                if not a and not b:
                    removed += 1  # 两个 DSU 都不需要这条边

        # 处理类型 1（仅 Alice）和类型 2（仅 Bob）
        for t, u, v in edges:
            if t == 1:
                if not alice.union(u, v):
                    removed += 1
            elif t == 2:
                if not bob.union(u, v):
                    removed += 1

        # 检查是否都连通
        if alice.is_connected() and bob.is_connected():
            return removed
        return -1
```

## 复杂度分析

- **时间复杂度**：O(E * α(N))，E 为边数，α 为反阿克曼函数（近似 O(1)）
- **空间复杂度**：O(N)

## 关键点总结

1. 类型 3 边优先添加，一条边同时服务两人（最高效）
2. 若某条边对两人都无贡献（两端已在同一连通分量），直接移除
3. 最后检查两个 DSU 是否都连通

## 易错点

- 类型 3 边：只要对 Alice 或 Bob 任意一个有用，就不能移除（必须两个都无用才移除）
- 两个 DSU 都要达到完全连通，缺一不可
