## 题目描述

给你一个整数数组 `ribbons` 和一个整数 `k`，数组中第 i 个元素表示第 i 条绳子的长度。对绳子进行切割，每次切割将一条绳子分为两段（可以扔掉剩余的），至少需要得到 k 段**等长**的绳子，返回这些绳子的**最大长度**。若无法得到 k 段，返回 0。

**示例 1：**
```
输入：ribbons = [9,7,5], k = 3
输出：5
解释：将 9 切为 [5,4]，将 7 切为 [5,2]，不用切 5，得到 3 段长度为 5 的绳子
```

**示例 2：**
```
输入：ribbons = [7,5,9], k = 4
输出：4
```

**提示：**
- `1 <= ribbons.length <= 10^5`
- `1 <= ribbons[i] <= 10^5`
- `1 <= k <= 10^9`

## 解题思路

**二分查找**：对答案（绳子长度）进行二分查找。

给定长度 `mid`，能切出的段数为 `sum(ribbon // mid for ribbon in ribbons)`，若段数 >= k，则 `mid` 可行。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def maxLength(self, ribbons: List[int], k: int) -> int:
        def can_cut(length: int) -> bool:
            """判断能否切出至少 k 段长度为 length 的绳子"""
            return sum(r // length for r in ribbons) >= k

        lo, hi = 1, max(ribbons)
        result = 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_cut(mid):
                result = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return result
```

### 方法二：二分查找（左闭右开）

```python
from typing import List

class Solution:
    def maxLength(self, ribbons: List[int], k: int) -> int:
        lo, hi = 1, max(ribbons) + 1
        while lo < hi:
            mid = (lo + hi) // 2
            if sum(r // mid for r in ribbons) >= k:
                lo = mid + 1
            else:
                hi = mid
        return lo - 1
```

## 复杂度分析

- **时间复杂度**：O(n * log(max_ribbon))，二分查找 O(log(max)) 次，每次验证 O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 对答案（长度）二分，而非对下标二分
2. 验证函数：段数 = `sum(r // length for r in ribbons)`，与 k 比较
3. 注意：若无法切出 k 段（即使长度为 1 也不够），返回 0（初始 result = 0）

## 易错点

- 最长不超过 max(ribbons)（不能比最长的绳子还长）
- 若 `sum(r // 1 for r in ribbons) < k`，连最短的都无法满足，直接返回 0
