## 题目描述

给你一棵二叉树的根节点 root，请你返回这棵树中最长连续序列的长度。

连续序列是指从父节点到子节点的路径，序列中的值依次递增 1。例如，1-2-3-4 是一个连续序列，但 1-2-4 不是。

注意：这个序列可以是递增的，且必须是父节点到子节点的方向。

**示例 1：**
```
输入：root = [1,null,3,2,4,null,null,null,5]
输出：3
解释：树中最长连续序列是 3-4-5，所以返回 3。
     1
      \
       3
      / \
     2   4
          \
           5
```

**示例 2：**
```
输入：root = [2,null,3,2,null,1]
输出：2
解释：树中最长连续序列是 2-3，所以返回 2。
     2
      \
       3
      /
     2
    /
   1
注意：虽然有 2-3-2 路径，但它不是连续递增的。
```

**提示：**
- 树中节点数在范围 [1, 3 * 10^4] 内
- -3 * 10^4 <= Node.val <= 3 * 10^4

## 解题思路

这道题要求找最长的连续递增序列，关键点：
1. 序列必须是从父节点到子节点
2. 每个节点的值要比父节点大 1
3. 路径可以在任意节点开始和结束

**方法对比：**

| 方法 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| DFS（自顶向下） | 传递当前长度 | 简单直观 | 需要全局变量 |
| DFS（自底向上） | 返回当前长度 | 逻辑清晰 | 稍复杂 |

**核心思路（自顶向下）：**
1. 从根节点开始遍历
2. 如果子节点值 = 父节点值 + 1，长度加 1
3. 否则，重新开始计数（长度为 1）
4. 记录遍历过程中的最大长度

## Python 代码实现

### 方法一：DFS 自顶向下（推荐）

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def longestConsecutive(self, root: TreeNode) -> int:
        """
        DFS 自顶向下
        时间复杂度：O(n)
        空间复杂度：O(h)，h 是树的高度
        """
        self.max_length = 0
        
        def dfs(node: TreeNode, parent_val: int, current_length: int) -> None:
            """
            node: 当前节点
            parent_val: 父节点的值
            current_length: 到当前节点的连续序列长度
            """
            if not node:
                return
            
            # 如果当前节点值 = 父节点值 + 1，长度加 1
            if node.val == parent_val + 1:
                current_length += 1
            else:
                # 否则重新开始
                current_length = 1
            
            # 更新最大长度
            self.max_length = max(self.max_length, current_length)
            
            # 递归处理左右子树
            dfs(node.left, node.val, current_length)
            dfs(node.right, node.val, current_length)
        
        dfs(root, float('-inf'), 0)
        return self.max_length
```

### 方法二：DFS 自底向上

```python
class Solution:
    def longestConsecutive(self, root: TreeNode) -> int:
        """
        DFS 自底向上
        返回以当前节点结尾的最长连续序列长度
        """
        self.max_length = 0
        
        def dfs(node: TreeNode) -> int:
            """
            返回以当前节点结尾的最长连续序列长度
            """
            if not node:
                return 0
            
            # 递归处理左右子树
            left_length = dfs(node.left)
            right_length = dfs(node.right)
            
            # 当前节点的最长连续序列长度（默认为 1）
            current_length = 1
            
            # 如果左子节点连续，更新长度
            if node.left and node.left.val == node.val + 1:
                current_length = max(current_length, left_length + 1)
            
            # 如果右子节点连续，更新长度
            if node.right and node.right.val == node.val + 1:
                current_length = max(current_length, right_length + 1)
            
            # 更新全局最大长度
            self.max_length = max(self.max_length, current_length)
            
            # 返回以当前节点结尾的最长长度
            return current_length
        
        dfs(root)
        return self.max_length
```

### 方法三：不使用全局变量

```python
class Solution:
    def longestConsecutive(self, root: TreeNode) -> int:
        """
        不使用全局变量，通过返回值传递
        """
        def dfs(node: TreeNode, parent_val: int, current_length: int) -> int:
            """
            返回包含当前子树的最长连续序列长度
            """
            if not node:
                return current_length
            
            # 计算当前长度
            if node.val == parent_val + 1:
                current_length += 1
            else:
                current_length = 1
            
            # 递归处理左右子树，取最大值
            left_max = dfs(node.left, node.val, current_length)
            right_max = dfs(node.right, node.val, current_length)
            
            return max(current_length, left_max, right_max)
        
        if not root:
            return 0
        return dfs(root, float('-inf'), 0)
```

### 方法四：迭代法（使用栈）

```python
class Solution:
    def longestConsecutive(self, root: TreeNode) -> int:
        """
        使用栈实现迭代版本
        """
        if not root:
            return 0
        
        max_length = 0
        # 栈中存储：(节点, 父节点值, 当前长度)
        stack = [(root, float('-inf'), 0)]
        
        while stack:
            node, parent_val, current_length = stack.pop()
            
            # 计算当前长度
            if node.val == parent_val + 1:
                current_length += 1
            else:
                current_length = 1
            
            max_length = max(max_length, current_length)
            
            # 将子节点加入栈
            if node.left:
                stack.append((node.left, node.val, current_length))
            if node.right:
                stack.append((node.right, node.val, current_length))
        
        return max_length
```

### 方法五：BFS（层序遍历）

```python
from collections import deque

class Solution:
    def longestConsecutive(self, root: TreeNode) -> int:
        """
        使用 BFS（层序遍历）
        """
        if not root:
            return 0
        
        max_length = 0
        # 队列中存储：(节点, 父节点值, 当前长度)
        queue = deque([(root, float('-inf'), 0)])
        
        while queue:
            node, parent_val, current_length = queue.popleft()
            
            # 计算当前长度
            if node.val == parent_val + 1:
                current_length += 1
            else:
                current_length = 1
            
            max_length = max(max_length, current_length)
            
            # 将子节点加入队列
            if node.left:
                queue.append((node.left, node.val, current_length))
            if node.right:
                queue.append((node.right, node.val, current_length))
        
        return max_length
```

## 复杂度分析

### 所有方法：

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** 
- DFS 递归：O(h)，h 是树的高度
  - 平衡树：O(log n)
  - 最坏情况（链式）：O(n)
- 迭代/BFS：O(w)，w 是树的最大宽度
  - 完全二叉树：O(n/2) = O(n)

## 图解示例

示例 1：`root = [1,null,3,2,4,null,null,null,5]`

```
树结构：
     1
      \
       3
      / \
     2   4
          \
           5

DFS 遍历过程：
1. 从 1 开始，长度 = 1
2. 访问 3：3 ≠ 1+1，重新开始，长度 = 1
3. 访问 2：2 ≠ 3+1，重新开始，长度 = 1
4. 回到 3，访问 4：4 = 3+1，长度 = 2
5. 访问 5：5 = 4+1，长度 = 3

最长连续序列：3 → 4 → 5，长度 = 3
```

示例 2：`root = [2,null,3,2,null,1]`

```
树结构：
     2
      \
       3
      /
     2
    /
   1

DFS 遍历过程：
1. 从 2 开始，长度 = 1
2. 访问 3：3 = 2+1，长度 = 2
3. 访问 2：2 ≠ 3+1，重新开始，长度 = 1
4. 访问 1：1 ≠ 2+1，重新开始，长度 = 1

最长连续序列：2 → 3，长度 = 2
注意：虽然路径是 2-3-2，但 2 ≠ 3+1，所以不连续
```

## 关键点总结

1. **连续定义**：子节点值必须等于父节点值 + 1
2. **方向限制**：只能从父到子，不能从子到父
3. **起点任意**：连续序列可以从任意节点开始
4. **重新计数**：不连续时长度重置为 1
5. **全局最大值**：需要记录整个遍历过程中的最大长度

## 易错点

1. **忘记重置长度**
   ```python
   # 错误：不连续时没有重置
   if node.val == parent_val + 1:
       current_length += 1
   # 忘记 else 分支
   
   # 正确：不连续时重置为 1
   else:
       current_length = 1
   ```

2. **初始值设置错误**
   ```python
   # 错误：初始长度为 0
   dfs(root, root.val, 0)
   
   # 正确：初始长度为 0，但父节点值设为特殊值
   dfs(root, float('-inf'), 0)
   # 或者初始长度为 1
   ```

3. **比较条件错误**
   ```python
   # 错误：判断相等
   if node.val == parent_val:
       current_length += 1
   
   # 正确：判断等于父节点 + 1
   if node.val == parent_val + 1:
       current_length += 1
   ```

4. **忘记更新最大值**
   ```python
   # 错误：只在叶子节点更新
   if not node.left and not node.right:
       self.max_length = max(self.max_length, current_length)
   
   # 正确：每个节点都要更新
   self.max_length = max(self.max_length, current_length)
   ```

5. **方法二中的比较对象**
   ```python
   # 错误：比较父节点
   if node.val == parent_val + 1:
   
   # 正确：方法二中应该比较子节点
   if node.left and node.left.val == node.val + 1:
   ```
