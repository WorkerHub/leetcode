## 题目描述

给你一个 **非负** 整数 `num`，如果存在某个 **非负** 整数 `k` 满足 `k + reverse(k) = num`，则返回 `true`，否则返回 `false`。

`reverse(k)` 是将 `k` 各位数字反转所得到的整数。

**示例 1：**
```
输入：num = 181
输出：true
解释：k = 140，reverse(140) = 041 = 41，140 + 41 = 181。
```

**示例 2：**
```
输入：num = 17
输出：false
```

**提示：**
- `0 <= num <= 10^5`

## 解题思路

直接枚举 `k` 从 `0` 到 `num`，检查 `k + reverse(k) == num`。

由于 `k + reverse(k) >= k`，所以 `k <= num`，枚举范围是 `[0, num]`。

注意：`k + reverse(k)` 是偶数（因为 `k` 和 `reverse(k)` 的各位数字之和相同，所以它们的奇偶性相同），若 `num` 是奇数直接返回 `false`（虽然实际不一定，但从约束看的确如此）。

等等，实际上这不一定成立，所以还是枚举。

## 代码实现

### 方法一：枚举（推荐）

```python
class Solution:
    def sumIsAddedOrReversed(self, num: int) -> bool:
        for k in range(num + 1):
            if k + int(str(k)[::-1]) == num:
                return True
        return False
```

### 方法二：数学优化（减少枚举）

```python
class Solution:
    def sumIsAddedOrReversed(self, num: int) -> bool:
        def reverse_num(x: int) -> int:
            return int(str(x)[::-1])

        # k <= num/2 或 k >= num/2，实际上 k + rev(k) >= k，所以 k <= num
        # 但 rev(k) >= 0，所以 k <= num
        # 若 k > num，则 k + rev(k) > num，不可能等于 num
        for k in range(num + 1):
            if k + reverse_num(k) == num:
                return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 | O(num * log(num)) | O(1) |

`num <= 10^5`，枚举 10^5 个值，每次 O(5) 操作，总体 O(5 * 10^5) = O(5 * 10^5)，可接受。

## 关键点总结

1. 枚举 k 从 0 到 num，检查是否满足条件
2. 字符串反转后转整数，自动去除前导零
3. `num` 为 0 时，`k = 0` 满足条件

## 易错点

- 枚举范围包含 0（`k = 0`，`reverse(0) = 0`，`0 + 0 = 0`）
- 字符串反转处理前导零
