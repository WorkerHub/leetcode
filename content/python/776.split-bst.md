## 题目描述

给定一棵二叉搜索树（BST）的根节点和一个整数值 `target`，将 BST 分割成两棵子树，使得一棵子树中所有节点的值都小于或等于目标值，另一棵子树中所有节点的值都大于目标值。

返回结果数组，包含两棵子树的根节点。

**示例:**
```
输入: root = [4,2,6,1,3,5,7], target = 2
输出: [[2,1],[4,3,6,null,null,5,7]]
```

## 解题思路

使用递归处理。对于当前节点：
- 如果值 <= target，左子树全部属于左侧结果，递归处理右子树
- 如果值 > target，右子树全部属于右侧结果，递归处理左子树

## Python 代码实现

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def splitBST(self, root: TreeNode, target: int) -> List[TreeNode]:
        if not root:
            return [None, None]
        
        if root.val <= target:
            # 左子树全部属于左侧
            left, right = self.splitBST(root.right, target)
            root.right = left
            return [root, right]
        else:
            # 右子树全部属于右侧
            left, right = self.splitBST(root.left, target)
            root.left = right
            return [left, root]
```

## 复杂度分析

- **时间复杂度：** O(h)，h 是树的高度
- **空间复杂度：** O(h)，递归栈

## 关键点总结

1. **BST 性质**
2. **递归分割**
3. **连接处理**
