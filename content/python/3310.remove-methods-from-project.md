## 题目描述

给你一个整数 `n` 表示项目中方法的数目（编号 0 到 n-1），以及一个二维数组 `invocations`，其中 `invocations[i] = [a, b]` 表示方法 `a` 调用了方法 `b`。

已知方法 `k` 存在 bug。如果一个方法**只能从有 bug 的方法到达**（即无法从未受感染的方法到达），则它也被认为是有 bug 的。

返回项目中所有**无 bug 方法**的列表（顺序任意）。

**示例 1：**
```
输入：n = 4, k = 1, invocations = [[1,2],[0,1],[3,2]]
输出：[0, 1, 3]
解释：方法 2 只能从方法 1（有 bug）到达，所以方法 2 也是有 bug 的
```

**示例 2：**
```
输入：n = 5, k = 0, invocations = [[1,2],[0,2],[0,1],[3,4]]
输出：[3, 4]
解释：方法 0 感染了 1, 2；方法 3, 4 没有被感染
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= k <= n-1`
- `0 <= invocations.length <= 2 * 10^4`

## 解题思路

1. **找出所有从 k 可达的方法**：从节点 `k` 开始 BFS/DFS，找出所有可达节点，记为"疑似有 bug"集合 `suspicious`。

2. **检查是否有外部调用**：遍历所有边，若存在某条边 `(a, b)` 中 `a` 不在 `suspicious` 中但 `b` 在 `suspicious` 中，说明有非 bug 方法调用了 `suspicious` 中的方法，该方法不应被移除。

3. **若无外部调用**：移除整个 `suspicious` 集合，返回其余方法。

4. **若有外部调用**：不移除任何方法（无法安全移除），返回所有 `0` 到 `n-1`。

## Python 代码实现

### 方法一：BFS + 检验（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def remainingMethods(self, n: int, k: int, invocations: List[List[int]]) -> List[int]:
        # 构建邻接表（有向图）
        graph = defaultdict(list)
        for a, b in invocations:
            graph[a].append(b)
        
        # BFS 找出从 k 可达的所有节点（疑似有 bug）
        suspicious = set()
        queue = deque([k])
        suspicious.add(k)
        while queue:
            node = queue.popleft()
            for neighbor in graph[node]:
                if neighbor not in suspicious:
                    suspicious.add(neighbor)
                    queue.append(neighbor)
        
        # 检查是否有非 bug 方法调用了 suspicious 中的方法
        for a, b in invocations:
            if a not in suspicious and b in suspicious:
                # 存在外部调用，无法移除，返回全部方法
                return list(range(n))
        
        # 可以安全移除，返回非 bug 方法
        return [i for i in range(n) if i not in suspicious]
```

### 方法二：DFS 实现

```python
from typing import List
from collections import defaultdict

class Solution:
    def remainingMethods(self, n: int, k: int, invocations: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for a, b in invocations:
            graph[a].append(b)
        
        # DFS 找所有从 k 可达的节点
        suspicious = set()
        def dfs(node):
            suspicious.add(node)
            for nb in graph[node]:
                if nb not in suspicious:
                    dfs(nb)
        
        dfs(k)
        
        # 检查外部调用
        for a, b in invocations:
            if a not in suspicious and b in suspicious:
                return list(range(n))
        
        return [i for i in range(n) if i not in suspicious]
```

## 复杂度分析

- 时间复杂度：O(n + m)，`m` 为边数，BFS/DFS 和遍历边各一次
- 空间复杂度：O(n + m)，邻接表和 visited 集合

## 关键点总结

1. 核心思路分两步：先找到 "bug 传播范围"，再验证是否可以安全移除。
2. 若有任何"干净方法"调用了"疑似方法"，则不能移除任何方法。
3. 有向图中的可达性用 BFS/DFS 即可解决。

## 易错点

1. 图是有向图，只能从调用方到被调用方传播。
2. 检查外部调用时，条件是 `a not in suspicious and b in suspicious`，方向不能颠倒。
3. 若整个图都是从 `k` 可达的，返回空数组（全部方法都有 bug）。
