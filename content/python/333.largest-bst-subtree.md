## 题目描述

给定一个二叉树，找到其中最大的二叉搜索树（BST）子树，并返回该子树的节点数。

**注意:**

- 子树必须包含其所有后代。
- BST 的定义：左子树的所有节点值小于根节点值，右子树的所有节点值大于根节点值，且左右子树也必须是 BST。

**示例 1:**

```
输入: 
    10
    / \
   5  15
  / \   \ 
 1   8   7

输出: 3
解释: 高亮部分为最大的 BST 子树。
     返回值 3 是这个子树的节点数。
      5
     / \
    1   8
```

**示例 2:**

```
输入:
    10
    / \
   5  15
  /     
 1   

输出: 3
```

**提示:**

- 树中节点数目在范围 `[0, 10^4]` 内
- `-10^4 <= Node.val <= 10^4`

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题的核心是**自底向上**传递信息，判断每个子树是否为 BST。

### 核心思想

1. **后序遍历**：先处理左右子树，再处理当前节点
2. **返回信息**：每个节点需要返回：
   - `is_bst`：是否为 BST
   - `size`：子树节点数
   - `min_val`：子树最小值
   - `max_val`：子树最大值
3. **BST 判断条件**：
   - 左子树是 BST 且左子树最大值 < 当前节点值
   - 右子树是 BST 且右子树最小值 > 当前节点值
4. **更新最大值**：遍历过程中更新全局最大 BST 节点数

## Python 代码实现

### 方法一：后序遍历（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def largestBSTSubtree(self, root: Optional[TreeNode]) -> int:
        """
        后序遍历：自底向上传递信息
        """
        self.max_size = 0
        
        def dfs(node):
            """
            返回 (is_bst, size, min_val, max_val)
            """
            # 空节点
            if not node:
                return True, 0, float('inf'), float('-inf')
            
            # 递归处理左右子树
            left_is_bst, left_size, left_min, left_max = dfs(node.left)
            right_is_bst, right_size, right_min, right_max = dfs(node.right)
            
            # 判断当前树是否为 BST
            if left_is_bst and right_is_bst and left_max < node.val < right_min:
                # 是 BST
                size = left_size + right_size + 1
                self.max_size = max(self.max_size, size)
                
                # 返回当前子树的信息
                # 最小值：左子树最小值或当前值
                # 最大值：右子树最大值或当前值
                return True, size, min(left_min, node.val), max(right_max, node.val)
            else:
                # 不是 BST
                return False, 0, 0, 0
        
        dfs(root)
        return self.max_size
```

### 方法二：使用命名元组（更清晰）

```python
from typing import Optional, NamedTuple

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class BSTInfo(NamedTuple):
    """BST 信息"""
    is_bst: bool
    size: int
    min_val: int
    max_val: int

class Solution:
    def largestBSTSubtree(self, root: Optional[TreeNode]) -> int:
        """
        使用命名元组，代码更清晰
        """
        self.max_size = 0
        
        def dfs(node) -> BSTInfo:
            # 空节点
            if not node:
                return BSTInfo(True, 0, float('inf'), float('-inf'))
            
            # 递归处理左右子树
            left = dfs(node.left)
            right = dfs(node.right)
            
            # 判断当前树是否为 BST
            if left.is_bst and right.is_bst and left.max_val < node.val < right.min_val:
                # 是 BST
                size = left.size + right.size + 1
                self.max_size = max(self.max_size, size)
                
                return BSTInfo(
                    True,
                    size,
                    min(left.min_val, node.val),
                    max(right.max_val, node.val)
                )
            else:
                # 不是 BST
                return BSTInfo(False, 0, 0, 0)
        
        dfs(root)
        return self.max_size
```

### 方法三：暴力解法（不推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def largestBSTSubtree(self, root: Optional[TreeNode]) -> int:
        """
        暴力解法：对每个节点判断以它为根的树是否为 BST
        时间复杂度 O(n^2)
        """
        def count_nodes(node):
            """统计节点数"""
            if not node:
                return 0
            return 1 + count_nodes(node.left) + count_nodes(node.right)
        
        def is_bst(node, min_val=float('-inf'), max_val=float('inf')):
            """判断是否为 BST"""
            if not node:
                return True
            
            if not (min_val < node.val < max_val):
                return False
            
            return (is_bst(node.left, min_val, node.val) and
                    is_bst(node.right, node.val, max_val))
        
        def dfs(node):
            """遍历所有节点，找最大 BST"""
            if not node:
                return 0
            
            # 如果当前子树是 BST，计算节点数
            if is_bst(node):
                return count_nodes(node)
            
            # 否则，递归检查左右子树
            return max(dfs(node.left), dfs(node.right))
        
        return dfs(root)
```

## 复杂度分析

**方法一/二：后序遍历**

- **时间复杂度**：O(n)
  - 每个节点访问一次
  
- **空间复杂度**：O(h)
  - h：树的高度，递归栈的空间

**方法三：暴力解法**

- **时间复杂度**：O(n^2)
  - 对每个节点都判断一次是否为 BST（O(n)），共 n 个节点
  
- **空间复杂度**：O(h)
  - 递归栈的空间

## 关键点总结

1. **后序遍历**：先处理子树，再处理当前节点
2. **信息传递**：每个节点返回 `(is_bst, size, min_val, max_val)`
3. **BST 判断**：
   - 左右子树都是 BST
   - `left_max < node.val < right_min`
4. **边界值处理**：
   - 空节点：`min_val = inf`，`max_val = -inf`
   - 叶子节点：`min_val = max_val = node.val`
5. **全局变量**：使用 `self.max_size` 记录最大值

## 易错点

1. **空节点的最小最大值**：
   - 正确：`min_val = inf`，`max_val = -inf`
   - 错误：`min_val = -inf`，`max_val = inf`（会导致判断错误）

2. **BST 判断条件**：
   - 正确：`left_max < node.val < right_min`
   - 错误：`left_max <= node.val <= right_min`（BST 不允许相等）

3. **最小最大值的更新**：
   - 最小值：`min(left_min, node.val)`（不是 `left_min`）
   - 最大值：`max(right_max, node.val)`（不是 `right_max`）

4. **非 BST 的返回值**：返回 `(False, 0, 0, 0)` 即可，后面的值不重要

5. **全局最大值更新时机**：只在当前子树是 BST 时更新
