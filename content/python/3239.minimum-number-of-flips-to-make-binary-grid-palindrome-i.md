## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。你可以翻转任意格子的值（0 变 1 或 1 变 0）。

如果矩阵每一行和每一列都是回文序列，则称矩阵为**回文矩阵**。

返回使矩阵成为回文矩阵的**最少翻转次数**。

**示例 1：**
```
输入：grid = [[1,0],[0,1]]
输出：2
```

**示例 2：**
```
输入：grid = [[0,1],[0,1],[0,0]]
输出：2
```

**提示：**
- `m == grid.length`
- `n == grid[0].length`
- `1 <= m, n <= 5`
- `grid[i][j]` 为 0 或 1

## 解题思路

每行和每列都要是回文。

- 每行回文：`grid[i][j] == grid[i][n-1-j]`
- 每列回文：`grid[i][j] == grid[m-1-i][j]`

同时，四个对应位置 `(i,j), (i,n-1-j), (m-1-i,j), (m-1-i,n-1-j)` 必须相同。

对每组四个位置，统计其中 1 的数量 `c`，翻转次数 = `min(c, 4-c)`（变为全 1 或全 0 的最小代价）。

中间行/列特殊处理（对称中心）。

## Python 代码实现

### 方法一：四格分组（推荐）

```python
from typing import List

class Solution:
    def minFlips(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0
        
        # 处理四元组 (i, j), (i, n-1-j), (m-1-i, j), (m-1-i, n-1-j)
        for i in range(m // 2):
            for j in range(n // 2):
                c = (grid[i][j] + grid[i][n-1-j] +
                     grid[m-1-i][j] + grid[m-1-i][n-1-j])
                ans += min(c, 4 - c)
        
        # 如果 m 是奇数，处理中间行
        if m % 2 == 1:
            mid_row = m // 2
            for j in range(n // 2):
                # grid[mid_row][j] 和 grid[mid_row][n-1-j] 需要相同
                if grid[mid_row][j] != grid[mid_row][n-1-j]:
                    ans += 1
        
        # 如果 n 是奇数，处理中间列
        if n % 2 == 1:
            mid_col = n // 2
            for i in range(m // 2):
                # grid[i][mid_col] 和 grid[m-1-i][mid_col] 需要相同
                if grid[i][mid_col] != grid[m-1-i][mid_col]:
                    ans += 1
        
        # 如果 m 和 n 都是奇数，中心格子不需要翻转（自身对称）
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 行列同时回文要求四个对称位置相同
2. 奇数行/列需要单独处理中间行/列（只需两个位置相同）
3. 最中心的格子（m、n 都是奇数时）自动满足

## 易错点

1. 中间行和中间列需要单独处理
2. 四格翻转：使 0 全相同的最小代价是 min(c, 4-c)
