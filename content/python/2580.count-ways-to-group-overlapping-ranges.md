## 题目描述

给你一个二维整数数组 `ranges`，其中 `ranges[i] = [starti, endi]` 表示 `[starti, endi]` 范围内的所有整数都属于第 `i` 个分组。

你需要把这些范围分成 **两组**（每个范围 **恰好** 属于一组），两个范围 **不能** 同时满足：
- 都在同一组
- 这两个范围有重叠或相接（有公共整数，或一个结束恰好是另一个开始的前一个）

返回合法的分组方案数（对 10^9 + 7 取模）。

**示例 1：**

```
输入：ranges = [[6,10],[5,15]]
输出：2
解释：两个范围重叠，必须在不同组，有 2 种方案。
```

**示例 2：**

```
输入：ranges = [[1,3],[10,20],[2,5],[4,8]]
输出：4
解释：合并重叠后有两个独立组，每组可选 {0,1}，方案 2*2=4。
```

**提示：**

- `1 <= ranges.length <= 10^5`
- `0 <= starti <= endi <= 10^9`

## 解题思路

**合并区间**：将重叠或相接的范围合并，统计连通分量数 k。

每个连通分量（合并后的区间组）可以独立选择放在第 0 组或第 1 组，贡献 2 的因子。

答案 = 2^k（对 10^9 + 7 取模）。

## Python 代码实现

### 方法一：排序合并区间（推荐）

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def countWays(self, ranges: List[List[int]]) -> int:
        ranges.sort()
        k = 0  # 连通分量数（合并后的区间数）
        cur_end = -1

        for start, end in ranges:
            if start > cur_end + 1:
                # 新的独立区间（不与当前区间重叠或相接）
                k += 1
                cur_end = end
            else:
                # 与当前区间重叠或相接，合并
                cur_end = max(cur_end, end)

        return pow(2, k, MOD)
```

### 方法二：贪心合并

```python
from typing import List

MOD = 10**9 + 7

class Solution:
    def countWays(self, ranges: List[List[int]]) -> int:
        ranges.sort(key=lambda x: x[0])
        groups = 0
        max_end = -1

        for s, e in ranges:
            if s > max_end + 1:
                groups += 1
            max_end = max(max_end, e)

        return pow(2, groups, MOD)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 重叠或相接的范围必须在同一组
2. 连通分量数 k = 合并后的区间数
3. 每个连通分量独立选组，答案 = 2^k

## 易错点

1. "相接"定义：end + 1 == start 也算相接（有公共整数相邻）
2. 更新 cur_end 时取 max（合并后端点可能更大）
3. 取模要用快速幂：`pow(2, k, MOD)`
