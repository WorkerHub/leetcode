## 题目描述

给你一个下标从 0 开始、长度为 `n` 的二维整数数组 `variables`，其中 `variables[i] = [ai, bi, ci, mi]`，以及一个整数 `target`。

若 `((ai^bi % 10)^ci) % mi == target`，则下标 `i` 是 **好下标**。

返回所有好下标。

**示例 1：**
```
输入：variables = [[2,3,3,10],[3,3,3,1],[6,1,1,4]], target = 2
输出：[0,2]
```

**示例 2：**
```
输入：variables = [[39,3,1000,1000]], target = 17
输出：[]
```

**提示：**
- `1 <= variables.length <= 100`
- `variables[i].length == 4`
- `2 <= ai <= 1000`
- `1 <= bi <= 10^5`
- `1 <= ci <= 10^5`
- `1 <= mi <= 1000`
- `0 <= target <= 10^9`

## 解题思路

按照公式直接计算：
1. 计算 `a^b % 10`（注意 b 可能很大，用快速幂）
2. 计算 `(步骤1结果)^c % m`（c 可能很大，用快速幂）
3. 检查是否等于 target

## Python 代码实现

### 方法一：快速幂（推荐）

```python
from typing import List

class Solution:
    def getGoodIndices(self, variables: List[List[int]], target: int) -> List[int]:
        result = []
        for i, (a, b, c, m) in enumerate(variables):
            # 步骤 1：a^b % 10
            step1 = pow(a, b, 10)
            # 步骤 2：step1^c % m
            step2 = pow(step1, c, m)
            if step2 == target:
                result.append(i)
        return result
```

### 方法二：手动实现快速幂

```python
from typing import List

class Solution:
    def getGoodIndices(self, variables: List[List[int]], target: int) -> List[int]:
        def fast_pow(base, exp, mod):
            result = 1
            base %= mod
            while exp > 0:
                if exp % 2 == 1:
                    result = result * base % mod
                base = base * base % mod
                exp //= 2
            return result

        return [i for i, (a, b, c, m) in enumerate(variables)
                if fast_pow(fast_pow(a, b, 10), c, m) == target]
```

## 复杂度分析

- 时间复杂度：O(n * log(max(b,c)))，每个变量的快速幂计算
- 空间复杂度：O(1)（不计结果数组）

## 关键点总结

1. Python 内置 `pow(base, exp, mod)` 实现了快速幂，高效且安全
2. 两次快速幂：先对 10 取模，再对 m 取模
3. 中间结果已经是 `a^b % 10`（0-9 之间），第二步以此为底数

## 易错点

1. 第一步模 10（不是模 m），因为公式是 `(a^b % 10)^c % m`
2. b 和 c 都可能很大（10^5），必须用快速幂
3. target 可以是任意非负整数，但结果在 [0, m-1] 范围内
