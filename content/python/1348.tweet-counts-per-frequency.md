## 题目描述

请你实现一个能够支持以下两种方法的推文计数类 `TweetCounts`：

**1. `recordTweet(tweetName, time)`**

记录推文发布情况：用户 `tweetName` 在 `time`（以**秒**为单位）时刻发布了一条推文。

**2. `getTweetCountsPerFrequency(freq, tweetName, startTime, endTime)`**

返回从开始时间 `startTime`（以秒为单位）到结束时间 `endTime`（以秒为单位）内，每隔 `freq` 时间段中指定用户 `tweetName` 发布推文的次数。

- `freq` 的值为 `"minute"`、`"hour"` 或 `"day"`，分别表示每**分钟**、每**小时**和每**天**的时间间隔。
- 第一个时间段始终从 `startTime` 开始，按照 `freq` 划分，最后一个时间段的结束时间可能大于 `endTime`。

**示例：**
```
输入：
["TweetCounts","recordTweet","recordTweet","recordTweet","getTweetCountsPerFrequency","getTweetCountsPerFrequency","recordTweet","getTweetCountsPerFrequency"]
[[],["tweet3",0],["tweet3",60],["tweet3",10],["minute","tweet3",0,59],["minute","tweet3",0,60],["tweet3",120],["hour","tweet3",0,210]]

输出：
[null,null,null,null,[2],[2,1],[null],[4]]
```

**提示：**
- `0 <= time, startTime, endTime <= 10^9`
- `0 <= endTime - startTime <= 10^4`
- 每个测试用例最多有 `10^4` 次 `recordTweet` 调用。
- 每个测试用例最多有 `10^4` 次 `getTweetCountsPerFrequency` 调用。

## 解题思路

**数据结构设计：**

使用字典 `tweets` 存储每个用户的推文时间列表：
```
tweets = {tweetName: [time1, time2, ...]}
```

**`getTweetCountsPerFrequency` 算法：**

1. 将 `freq` 转换为秒数：minute=60，hour=3600，day=86400
2. 计算时间段数量：`(endTime - startTime) // delta + 1`
3. 对该用户的所有推文时间，判断属于哪个时间段：`(time - startTime) // delta`
4. 累加对应时间段的计数

**优化思路：** 如果推文时间列表已排序，可以用二分查找缩小遍历范围。

## Python 代码实现

### 方法一：哈希表 + 列表（推荐）

```python
from collections import defaultdict
from typing import List

class TweetCounts:

    def __init__(self):
        # 存储每个用户的推文时间列表
        self.tweets = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        """记录推文"""
        self.tweets[tweetName].append(time)

    def getTweetCountsPerFrequency(self, freq: str, tweetName: str,
                                   startTime: int, endTime: int) -> List[int]:
        """获取每个时间段的推文数"""
        # 将 freq 转换为秒数
        delta = {'minute': 60, 'hour': 3600, 'day': 86400}[freq]
        
        # 时间段数量
        n = (endTime - startTime) // delta + 1
        result = [0] * n
        
        # 统计每个时间段的推文数
        for t in self.tweets[tweetName]:
            if startTime <= t <= endTime:
                # 属于第几个时间段
                idx = (t - startTime) // delta
                result[idx] += 1
        
        return result
```

### 方法二：记录时排序，查询时二分（优化版）

```python
from collections import defaultdict
from typing import List
import bisect

class TweetCounts:

    def __init__(self):
        # 保持每个用户的推文时间有序（方便二分查找）
        self.tweets = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        """记录推文，保持有序插入"""
        # bisect.insort 保持列表有序
        bisect.insort(self.tweets[tweetName], time)

    def getTweetCountsPerFrequency(self, freq: str, tweetName: str,
                                   startTime: int, endTime: int) -> List[int]:
        """获取每个时间段的推文数（利用有序列表优化）"""
        delta = {'minute': 60, 'hour': 3600, 'day': 86400}[freq]
        n = (endTime - startTime) // delta + 1
        result = [0] * n
        
        times = self.tweets[tweetName]
        
        # 二分查找 startTime 和 endTime 的范围
        lo = bisect.bisect_left(times, startTime)
        hi = bisect.bisect_right(times, endTime)
        
        # 只遍历在 [startTime, endTime] 范围内的推文
        for t in times[lo:hi]:
            idx = (t - startTime) // delta
            result[idx] += 1
        
        return result
```

### 方法三：详细注释版（便于新手理解）

```python
from collections import defaultdict
from typing import List

class TweetCounts:

    def __init__(self):
        """初始化：使用字典存储每个用户的推文时间"""
        # key: tweetName (str), value: 推文时间列表
        self.data = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        """记录一条推文"""
        self.data[tweetName].append(time)

    def getTweetCountsPerFrequency(self, freq: str, tweetName: str,
                                   startTime: int, endTime: int) -> List[int]:
        """
        统计指定用户在 [startTime, endTime] 内每个时间段的推文数
        
        时间段划分（以 startTime 为起点，每 delta 秒一段）：
        - 第0段：[startTime, startTime + delta)
        - 第1段：[startTime + delta, startTime + 2*delta)
        - ...
        - 第k段：[startTime + k*delta, startTime + (k+1)*delta)
        """
        # 时间段长度（秒）
        freq_map = {
            'minute': 60,
            'hour': 60 * 60,        # 3600
            'day': 60 * 60 * 24     # 86400
        }
        delta = freq_map[freq]
        
        # 总时间段数
        total_segments = (endTime - startTime) // delta + 1
        result = [0] * total_segments
        
        # 遍历该用户的所有推文时间
        for t in self.data.get(tweetName, []):
            # 只处理在 [startTime, endTime] 范围内的推文
            if startTime <= t <= endTime:
                # 该推文属于第几个时间段
                segment_index = (t - startTime) // delta
                result[segment_index] += 1
        
        return result
```

### 方法四：使用 SortedList（有序容器，查询效率最高）

```python
from collections import defaultdict
from typing import List

# 需要安装 sortedcontainers 库（LeetCode 默认支持）
# from sortedcontainers import SortedList

# 如果没有 sortedcontainers，用普通列表也可以
class TweetCounts:

    def __init__(self):
        self.tweets = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        self.tweets[tweetName].append(time)

    def getTweetCountsPerFrequency(self, freq: str, tweetName: str,
                                   startTime: int, endTime: int) -> List[int]:
        import bisect
        
        delta = {'minute': 60, 'hour': 3600, 'day': 86400}[freq]
        n = (endTime - startTime) // delta + 1
        result = [0] * n
        
        times = self.tweets[tweetName]
        
        for t in times:
            if startTime <= t <= endTime:
                result[(t - startTime) // delta] += 1
        
        return result
```

## 复杂度分析

| 方法 | recordTweet | getTweetCountsPerFrequency | 空间 |
|------|-------------|---------------------------|------|
| 方法一/三 | O(1) | O(k)（k为该用户推文数） | O(总推文数) |
| 方法二 | O(log k) | O(m + n)（m为范围内推文数） | O(总推文数) |

其中：
- k：某用户总推文数
- m：[startTime, endTime] 范围内该用户的推文数
- n：时间段数量

## 关键点总结

1. 核心：用哈希表存储每个用户的推文时间列表
2. 时间段计算：`(t - startTime) // delta` 得到推文属于哪个时间段（从 0 开始索引）
3. 时间段总数：`(endTime - startTime) // delta + 1`
4. 方法二利用有序列表和二分查找，在推文数量很大时更高效

## 易错点

1. 时间段数量计算：`(endTime - startTime) // delta + 1`（+1 是因为包含两端）
2. 时间段索引：`(t - startTime) // delta`，是相对于 `startTime` 的偏移，不是绝对时间
3. 过滤范围：只处理 `startTime <= t <= endTime` 的推文（包含两端）
4. `freq` 到秒数的映射别写错：minute=60, hour=3600, day=86400

## 使用示例

```python
# 示例演示
tc = TweetCounts()
tc.recordTweet("tweet3", 0)   # 记录推文
tc.recordTweet("tweet3", 60)
tc.recordTweet("tweet3", 10)

# 查询 0-59 秒内每分钟的推文数
result1 = tc.getTweetCountsPerFrequency("minute", "tweet3", 0, 59)
print(result1)  # [2]  （时间0和10都在第0段 [0, 60)）

# 查询 0-60 秒内每分钟的推文数
result2 = tc.getTweetCountsPerFrequency("minute", "tweet3", 0, 60)
print(result2)  # [2, 1]  （0和10在第0段，60在第1段）
```
