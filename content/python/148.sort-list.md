## 题目描述

给你链表的头结点 `head`，请将其按升序排列并返回排序后的链表。

**示例 1：**

```
输入: head = [4,2,1,3]
输出: [1,2,3,4]
```

**示例 2：**

```
输入: head = [-1,5,3,4,0]
输出: [-1,0,3,4,5]
```

**示例 3：**

```
输入: head = []
输出: []
```

**提示：**

- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

**进阶：** 你可以在 `O(n log n)` 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

## 解题思路

这道题要求 O(n log n) 的时间复杂度，常见的排序算法中符合要求的有：
- 归并排序
- 堆排序
- 快速排序

对于链表，归并排序是最佳选择，因为：
1. 链表不支持随机访问，快速排序效率低
2. 链表的合并操作非常高效，适合归并排序
3. 可以实现 O(1) 的空间复杂度（自底向上）

**归并排序思路：**

采用分治策略：
1. **分割**：找到链表中点，将链表分成两半
2. **递归**：对两个子链表分别排序
3. **合并**：将两个有序链表合并成一个有序链表

## Python 代码实现

### 方法一：自顶向下归并排序（递归，推荐理解）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        # 基础情况：空链表或单节点
        if not head or not head.next:
            return head
        
        # 1. 找到链表中点，分割成两半
        mid = self.get_middle(head)
        right_head = mid.next
        mid.next = None  # 断开链表
        
        # 2. 递归排序两个子链表
        left = self.sortList(head)
        right = self.sortList(right_head)
        
        # 3. 合并两个有序链表
        return self.merge(left, right)
    
    def get_middle(self, head: ListNode) -> ListNode:
        """快慢指针找中点"""
        slow = head
        fast = head.next  # fast 从 head.next 开始，确保左半部分较短
        
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        return slow
    
    def merge(self, l1: ListNode, l2: ListNode) -> ListNode:
        """合并两个有序链表"""
        dummy = ListNode(0)
        curr = dummy
        
        while l1 and l2:
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        # 连接剩余部分
        curr.next = l1 if l1 else l2
        
        return dummy.next
```

### 方法二：自底向上归并排序（迭代，O(1) 空间）

```python
class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
        
        # 1. 计算链表长度
        length = 0
        node = head
        while node:
            length += 1
            node = node.next
        
        dummy = ListNode(0, head)
        
        # 2. 自底向上归并，子链表长度从 1, 2, 4, 8... 递增
        size = 1
        while size < length:
            curr = dummy.next
            tail = dummy
            
            while curr:
                # 分割出第一个长度为 size 的子链表
                left = curr
                right = self.split(left, size)
                # 分割出第二个长度为 size 的子链表
                curr = self.split(right, size)
                
                # 合并两个子链表
                tail = self.merge_and_connect(left, right, tail)
            
            size *= 2
        
        return dummy.next
    
    def split(self, head: ListNode, size: int) -> ListNode:
        """分割出长度为 size 的链表，返回剩余部分的头节点"""
        if not head:
            return None
        
        for i in range(1, size):
            if not head.next:
                break
            head = head.next
        
        rest = head.next
        head.next = None
        return rest
    
    def merge_and_connect(self, l1: ListNode, l2: ListNode, tail: ListNode) -> ListNode:
        """合并 l1 和 l2，连接到 tail 后面，返回合并后的尾节点"""
        curr = tail
        
        while l1 and l2:
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        curr.next = l1 if l1 else l2
        
        # 移动到尾节点
        while curr.next:
            curr = curr.next
        
        return curr
```

### 方法三：简化版（使用库函数，不推荐但好理解）

```python
class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        # 1. 将链表转换为数组
        arr = []
        curr = head
        while curr:
            arr.append(curr.val)
            curr = curr.next
        
        # 2. 排序数组
        arr.sort()
        
        # 3. 重建链表
        dummy = ListNode(0)
        curr = dummy
        for val in arr:
            curr.next = ListNode(val)
            curr = curr.next
        
        return dummy.next

# 注意：方法三空间复杂度 O(n)，不符合进阶要求
```

## 复杂度分析

**方法一：自顶向下归并排序**

- 时间复杂度：O(n log n)
  - 递归深度：log n
  - 每层合并：O(n)
- 空间复杂度：O(log n)
  - 递归调用栈的深度

**方法二：自底向上归并排序**

- 时间复杂度：O(n log n)
  - 外层循环：log n 次（size: 1, 2, 4, ...）
  - 每次循环合并：O(n)
- 空间复杂度：O(1)
  - 只使用常数个指针变量

**方法三：转数组排序**

- 时间复杂度：O(n log n) - 取决于排序算法
- 空间复杂度：O(n) - 数组存储

## 图解示例

以 `head = [4,2,1,3]` 为例（自顶向下）：

```
原链表: 4 -> 2 -> 1 -> 3

第一次分割:
左: 4 -> 2
右: 1 -> 3

递归左半部分:
  分割: 4 | 2
  合并: 2 -> 4

递归右半部分:
  分割: 1 | 3
  合并: 1 -> 3

最终合并:
  2 -> 4  和  1 -> 3
  结果: 1 -> 2 -> 3 -> 4
```

自底向上过程：

```
原始: 4 -> 2 -> 1 -> 3

size = 1:
  合并 (4) 和 (2) -> 2 -> 4
  合并 (1) 和 (3) -> 1 -> 3
  结果: 2 -> 4 -> 1 -> 3

size = 2:
  合并 (2->4) 和 (1->3) -> 1 -> 2 -> 3 -> 4
  结果: 1 -> 2 -> 3 -> 4
```

## 关键点总结

1. **归并排序是链表排序的最佳选择**：
   - 不需要随机访问
   - 合并操作高效
   - 稳定排序

2. **找中点技巧**：
   - 快慢指针：slow 每次走一步，fast 走两步
   - fast 从 head.next 开始，保证左半部分不会比右半部分长

3. **两种实现方式**：
   - 自顶向下（递归）：代码简洁，空间 O(log n)
   - 自底向上（迭代）：空间 O(1)，满足进阶要求

4. **合并有序链表**：
   - 是归并排序的核心操作
   - 使用虚拟头节点简化代码

5. **断链操作**：
   - 分割时必须断开连接：`mid.next = None`
   - 避免形成环或访问错误区域

## 易错点

1. **找中点时的边界**：
   - `fast` 从 `head.next` 开始，而不是 `head`
   - 确保分割后左右两部分长度合理

2. **断链操作**：
   - 分割后必须 `mid.next = None`
   - 否则会导致无限递归或错误合并

3. **空链表处理**：
   - 递归基础情况：`if not head or not head.next`
   - 合并时处理 l1 或 l2 为空的情况

4. **自底向上的复杂度**：
   - split 函数要正确断开链表
   - merge_and_connect 要返回正确的尾节点

5. **合并后的连接**：
   - 确保 tail 正确连接到合并后的链表
   - 更新 tail 到新的尾部
