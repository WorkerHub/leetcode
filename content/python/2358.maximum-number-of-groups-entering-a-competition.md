## 题目描述

给你一个正整数数组 `grades`，表示学生的成绩。你需要将学生分成若干组，规则如下：
- 第 `i` 组（1 索引）的**学生人数**必须**严格大于**前一组。
- 第 `i` 组的**成绩总和**必须**严格大于**前一组。

返回可以组成的**最多组数**。

**示例 1：**
```
输入：grades = [10,6,12,7,3,5]
输出：3
解释：可以分成 3 组：[3]，[5,6]，[7,10,12]，成绩总和为 3 < 11 < 29，人数为 1 < 2 < 3。
```

**示例 2：**
```
输入：grades = [8,8]
输出：1
```

**提示：**
- `1 <= grades.length <= 10^5`
- `1 <= grades[i] <= 10^5`

## 解题思路

**贪心：** 若分成 k 组，组的人数至少为 1, 2, 3, ..., k，总人数至少为 `k*(k+1)/2`。

只需找最大的 k 使得 `k*(k+1)/2 <= n`。

**为什么满足人数条件就能满足成绩条件？**
将 grades 排序后，按 1, 2, 3, ..., k 人依次分配。每组取的是剩余最小的几个成绩。由于人数递增且每人成绩 >= 1，总和也会递增（多一个正数）。

## 代码实现

### 方法一：数学公式（推荐）

```python
from typing import List
import math

class Solution:
    def maximumGroups(self, grades: List[int]) -> int:
        n = len(grades)
        # 找最大 k 使得 k*(k+1)/2 <= n
        # k^2 + k - 2n = 0，k = (-1 + sqrt(1 + 8n)) / 2
        k = int((-1 + math.sqrt(1 + 8 * n)) / 2)
        # 验证并调整（浮点误差）
        while (k + 1) * (k + 2) // 2 <= n:
            k += 1
        return k
```

### 方法二：贪心模拟

```python
from typing import List

class Solution:
    def maximumGroups(self, grades: List[int]) -> int:
        grades.sort()
        groups = 0
        students_used = 0
        group_size = 1
        
        while students_used + group_size <= len(grades):
            groups += 1
            students_used += group_size
            group_size += 1
        
        return groups
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学公式 | O(1) | O(1) |
| 贪心模拟 | O(sqrt(n)) | O(1) |

## 关键点总结

1. 关键洞察：只需要组的人数满足递增即可，将排序后的成绩依次分配，成绩总和条件自然满足。
2. 最大 k 满足三角数 `k*(k+1)/2 <= n`，用数学公式或循环求解。

## 易错点

- 数学公式求解 k 时，浮点计算可能存在误差，需要验证 k 和 k+1。
