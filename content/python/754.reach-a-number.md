## 题目描述

在一根无限长的数轴上，你站在 `0` 的位置。终点在 `target` 的位置。

你可以做一些数量的移动 `numMoves`：

- 每次移动，你可以选择向左或向右移动。
- 第 `i` 次移动（从索引 1 开始，到索引 `numMoves`），在选择的方向上走 `i` 步。

给定整数 `target`，返回到达目标所需的最小移动次数（即最小 `numMoves`）。

**示例 1:**
```
输入: target = 2
输出: 3
解释:
第一次移动，从 0 到 1 。
第二次移动，从 1 到 -1 。
第三次移动，从 -1 到 2 。
```

**示例 2:**
```
输入: target = 3
输出: 2
解释:
第一次移动，从 0 到 1 。
第二次移动，从 1 到 3 。
```

**提示：**
- `-10^9 <= target <= 10^9`
- `target != 0`

## 解题思路

这道题的关键是找到数学规律。

**核心观察：**

1. **对称性：** 到达 -target 和到达 target 的步数相同，所以可以只考虑 target > 0 的情况

2. **和的分解：** 第 n 步时，如果所有步都向右走，总和为 `sum = 1 + 2 + 3 + ... + n = n(n+1)/2`

3. **改变方向的效果：** 如果将第 i 步的方向从右改为左，总和会减少 `2*i`

4. **关键规律：**
   - 如果 `sum >= target` 且 `sum - target` 是偶数，那么 n 步就够了
   - 因为我们可以找到一个步骤 i，使得改变它的方向后，sum - 2*i = target
   - 这要求 sum - target = 2*i，即 sum - target 必须是偶数

**算法流程：**
1. 取 target 的绝对值
2. 找到最小的 n，使得 `n(n+1)/2 >= target`
3. 如果 `sum - target` 是偶数，返回 n
4. 否则继续增加 n，直到 `sum - target` 是偶数

## Python 代码实现

### 方法一：数学规律（推荐）⭐

```python
class Solution:
    def reachNumber(self, target: int) -> int:
        # 由于对称性，只需考虑正数
        target = abs(target)
        
        # 找到最小的 n，使得 1+2+...+n >= target
        n = 0
        total = 0
        
        while total < target:
            n += 1
            total += n
        
        # 如果 sum - target 是偶数，直接返回
        # 否则继续增加步数
        while (total - target) % 2 != 0:
            n += 1
            total += n
        
        return n
```

### 方法二：使用二分查找优化

```python
class Solution:
    def reachNumber(self, target: int) -> int:
        target = abs(target)
        
        # 使用二分查找找到最小的 n，使得 n(n+1)/2 >= target
        left, right = 0, target
        
        while left < right:
            mid = (left + right) // 2
            if mid * (mid + 1) // 2 < target:
                left = mid + 1
            else:
                right = mid
        
        n = left
        total = n * (n + 1) // 2
        
        # 调整到 (sum - target) 为偶数
        while (total - target) % 2 != 0:
            n += 1
            total += n
        
        return n
```

### 方法三：数学公式（最优化）⭐

```python
import math

class Solution:
    def reachNumber(self, target: int) -> int:
        target = abs(target)
        
        # 直接计算满足 n(n+1)/2 >= target 的最小 n
        # 解方程 n^2 + n - 2*target >= 0
        # n >= (-1 + sqrt(1 + 8*target)) / 2
        n = math.ceil((-1 + math.sqrt(1 + 8 * target)) / 2)
        
        total = n * (n + 1) // 2
        
        # 调整到 (sum - target) 为偶数
        diff = total - target
        
        # 如果 diff 是奇数，需要增加步数
        if diff % 2 == 1:
            # 如果 n 是偶数，需要加 1 步（奇数）
            # 如果 n 是奇数，需要加 2 步（奇数+偶数）
            if n % 2 == 0:
                n += 1
            else:
                n += 2
        
        return n
```

### 方法四：详细注释版（易理解）

```python
class Solution:
    def reachNumber(self, target: int) -> int:
        # 利用对称性，将问题简化为只考虑正数
        target = abs(target)
        
        # 步骤 1: 找到最小的 n，使得前 n 个自然数的和 >= target
        # sum = 1 + 2 + 3 + ... + n = n(n+1)/2
        step = 0
        total = 0
        
        # 一直向右走，直到总和 >= target
        while total < target:
            step += 1
            total += step
        
        # 步骤 2: 检查 (total - target) 是否为偶数
        # 如果是偶数，说明可以通过改变某一步的方向来达到 target
        # 例如：total = 10, target = 6, diff = 4
        # 我们可以将第 2 步改为向左，这样 total - 2*2 = 10 - 4 = 6
        
        # 如果 diff 是奇数，我们需要继续走
        # 继续走的原因：
        # - 如果下一步 step+1 是偶数，diff 变成奇数+偶数=奇数（仍然是奇数）
        # - 如果下一步 step+1 是奇数，diff 变成奇数+奇数=偶数（变成偶数了！）
        # 所以最多再走 2 步就能让 diff 变成偶数
        
        while (total - target) % 2 != 0:
            step += 1
            total += step
        
        return step
```

## 复杂度分析

**方法一：迭代**
- **时间复杂度：** O(√target)，需要大约 √(2*target) 步
- **空间复杂度：** O(1)

**方法二：二分查找**
- **时间复杂度：** O(log target)，二分查找部分是 O(log target)，调整部分最多 2 步
- **空间复杂度：** O(1)

**方法三：数学公式**
- **时间复杂度：** O(1)，直接计算
- **空间复杂度：** O(1)

## 关键点总结

1. **对称性：** 利用对称性简化问题
2. **等差数列求和：** sum = n(n+1)/2
3. **奇偶性分析：** 关键是理解为什么 (sum - target) 必须是偶数
4. **改变方向的效果：** 改变第 i 步的方向会使总和减少 2*i
5. **最多额外 2 步：** 如果 diff 是奇数，最多再走 2 步就能变成偶数

## 易错点

1. **忘记取绝对值：** target 可能是负数
2. **奇偶性判断：** 没有理解为什么需要 (sum - target) 是偶数
3. **无限循环：** while 循环的条件要正确
4. **数学公式精度：** 使用 ceil 函数时注意浮点数精度
5. **边界情况：** target = 1, 2, 3 等小值要测试
