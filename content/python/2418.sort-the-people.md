## 题目描述

给你一个字符串数组 `names`，和一个由 **互不相同** 的正整数组成的数组 `heights`。两个数组的长度均为 `n`。

对于每个下标 `i`，`names[i]` 和 `heights[i]` 表示第 `i` 个人的名字和身高。

请按身高 **降序** 顺序返回对应的名字数组 `names`。

**示例 1：**
```
输入：names = ["Mary","John","Emma"], heights = [180,165,170]
输出：["Mary","Emma","John"]
解释：Mary 最高，Emma 第二高，John 第三高。
```

**示例 2：**
```
输入：names = ["Alice","Bob","Bob"], heights = [155,185,150]
输出：["Bob","Alice","Bob"]
```

**提示：**
- `n == names.length == heights.length`
- `1 <= n <= 10^3`
- `1 <= heights[i] <= 10^5`
- `1 <= names[i].length <= 20`
- `heights[i]` 中的值 **互不相同**

## 解题思路

将 `(身高, 名字)` 组合后按身高降序排序，返回名字列表。

## 代码实现

### 方法一：zip + sorted（推荐）

```python
from typing import List

class Solution:
    def sortPeople(self, names: List[str], heights: List[int]) -> List[str]:
        # 将名字和身高配对，按身高降序排序，提取名字
        return [name for _, name in sorted(zip(heights, names), reverse=True)]
```

### 方法二：哈希表 + 排序

```python
from typing import List

class Solution:
    def sortPeople(self, names: List[str], heights: List[int]) -> List[str]:
        # 身高到名字的映射（题目保证身高互不相同）
        height_to_name = {h: n for h, n in zip(heights, names)}
        # 身高降序排序
        sorted_heights = sorted(heights, reverse=True)
        return [height_to_name[h] for h in sorted_heights]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| zip + sorted | O(n log n) | O(n) |
| 哈希表 | O(n log n) | O(n) |

## 关键点总结

1. 利用 `zip` 将两个数组打包为 `(height, name)` 对
2. 按身高降序排序（`reverse=True`）
3. 提取排序后的名字列表

## 易错点

- 按身高降序，不是升序
- `zip(heights, names)` 中把 height 放前面，因为元组比较时先比第一个元素
