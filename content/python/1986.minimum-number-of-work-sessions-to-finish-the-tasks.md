## 题目描述

给你一个整数数组 `tasks`，其中 `tasks[i]` 表示第 `i` 个任务的持续时间，以及整数 `sessionTime`，表示每次工作阶段的最长时间。

你需要完成所有任务，且每个工作阶段内的任务总时间不超过 `sessionTime`。

返回完成所有任务所需的**最少工作阶段数**。

**提示：**
- `1 <= n <= 14`
- `1 <= tasks[i] <= 10`
- `max(tasks[i]) <= sessionTime <= 15`

---

## 解题思路

### 核心思想：状态压缩 DP

`n <= 14`，用二进制 bitmask 表示哪些任务已完成。

`dp[mask]` = 完成 `mask` 中所有任务所需的最少阶段数，同时维护 `rem[mask]` = 完成 `mask` 中任务后**当前阶段剩余时间**。

**转移**：枚举下一个要加入的任务 `i`：
- 若当前阶段剩余够放任务 `i`：`rem[mask | (1<<i)] = rem[mask] - tasks[i]`，阶段数不变
- 否则开新阶段：`rem[mask | (1<<i)] = sessionTime - tasks[i]`，阶段数 +1

---

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minSessions(self, tasks: List[int], sessionTime: int) -> int:
        n = len(tasks)
        total = 1 << n
        INF = float('inf')

        # dp[mask] = 完成 mask 中所有任务的最少阶段数
        # rem[mask] = 在最少阶段下当前阶段的剩余时间（尽量大，贪心）
        dp = [INF] * total
        rem = [0] * total
        dp[0] = 1
        rem[0] = sessionTime

        for mask in range(total):
            if dp[mask] == INF:
                continue
            for i in range(n):
                if mask >> i & 1:
                    continue  # 任务 i 已完成
                new_mask = mask | (1 << i)
                if rem[mask] >= tasks[i]:
                    # 当前阶段可以容纳任务 i
                    if dp[mask] < dp[new_mask] or (dp[mask] == dp[new_mask] and rem[mask] - tasks[i] > rem[new_mask]):
                        dp[new_mask] = dp[mask]
                        rem[new_mask] = rem[mask] - tasks[i]
                else:
                    # 需要开新阶段
                    new_sessions = dp[mask] + 1
                    new_rem = sessionTime - tasks[i]
                    if new_sessions < dp[new_mask] or (new_sessions == dp[new_mask] and new_rem > rem[new_mask]):
                        dp[new_mask] = new_sessions
                        rem[new_mask] = new_rem

        return dp[total - 1]
```

### 方法二：子集枚举 DP（枚举合法子集）

```python
from typing import List

class Solution:
    def minSessions(self, tasks: List[int], sessionTime: int) -> int:
        n = len(tasks)
        total = 1 << n

        # 预处理：valid[mask] = mask 中所有任务可在一个阶段完成
        valid = [False] * total
        for mask in range(total):
            s = 0
            for i in range(n):
                if mask >> i & 1:
                    s += tasks[i]
            valid[mask] = (s <= sessionTime)

        # dp[mask] = 完成 mask 中所有任务的最少阶段数
        INF = float('inf')
        dp = [INF] * total
        dp[0] = 0

        for mask in range(1, total):
            # 枚举 mask 的所有子集
            sub = mask
            while sub:
                if valid[sub]:
                    dp[mask] = min(dp[mask], dp[mask ^ sub] + 1)
                sub = (sub - 1) & mask

        return dp[total - 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(2^n * n) | O(2^n) |
| 方法二 | O(3^n)（子集枚举） | O(2^n) |

---

## 关键点总结

1. `n <= 14` 决定用状态压缩 DP
2. 方法一逐任务扩展，维护剩余时间贪心最大化
3. 方法二枚举子集，判断子集是否合法（能在一个阶段内完成）

---

## 易错点

- 方法一中需要同时考虑阶段数更少或阶段数相同但剩余时间更多两种更新条件
- 方法二子集枚举用 `sub = (sub - 1) & mask` 遍历所有子集
