## 题目描述

给你一个正整数数组 `nums`，找出 `[1, max(nums)]` 范围内最大的不在数组中的整数。若不存在，返回 -1。

**示例 1：**

```
输入：nums = [1,2,4]
输出：3
解释：范围[1,4]内缺失的最大数是3
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：-1
解释：[1,4]内没有缺失的数
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

建立集合，从 `max(nums)` 向下查找第一个不在集合中的正整数。

## Python 代码实现

### 方法一：集合 + 从大到小查找（推荐）

```python
from typing import List

class Solution:
    def largestMissing(self, nums: List[int]) -> int:
        num_set = set(nums)
        max_val = max(nums)
        for x in range(max_val, 0, -1):
            if x not in num_set:
                return x
        return -1
```

### 方法二：排序后查找

```python
from typing import List

class Solution:
    def largestMissing(self, nums: List[int]) -> int:
        num_set = set(nums)
        max_val = max(nums)
        for x in range(max_val - 1, 0, -1):
            if x not in num_set:
                return x
        return -1
```

## 复杂度分析

- 时间复杂度：O(n + max_val)
- 空间复杂度：O(n)

## 关键点总结

1. 从最大值向下找，第一个缺失的即为答案
2. 集合查找 O(1)
3. 若所有整数都存在，返回 -1

## 易错点

1. 查找范围是 `[1, max(nums)]`（不包含 max+1）
2. 从最大值往下找，不是从最小往上找
3. `max(nums)` 本身也可能是缺失的（不，它在数组中）
