## 题目描述

给你一个偶数长度的字符串 `s` 和两个整数 `a` 和 `b`。

你可以对 `s` 执行以下两种操作任意次、任意顺序：
1. 将 `s` 中**所有奇数下标**的字符都加 `a`（加法操作针对字符的数字值，范围 0-9 循环）
2. 将字符串 `s` 向右**旋转** `b` 位（即右移 b 位）

请返回通过执行以上操作可以得到的**字典序最小**的字符串。

**提示：**
- `2 <= s.length <= 100`
- `s` 只包含数字
- `1 <= a <= 9`
- `1 <= b <= s.length - 1`

## 解题思路

由于操作可以无限执行，但状态空间有限，可以用**BFS** 枚举所有可达状态，找到字典序最小的字符串。

**状态空间大小：** 
- 奇数位字符加 a 最多有 10 种不同状态（加 10 次回到原始）
- 旋转有 n/gcd(b, n) 种不同状态
- 总状态数 = O(10 * n) 是有限的

## 代码实现

### 方法一：BFS 枚举所有状态（推荐）

```python
from collections import deque

class Solution:
    def findLexSmallestString(self, s: str, a: int, b: int) -> str:
        visited = set()
        queue = deque([s])
        visited.add(s)
        ans = s
        
        while queue:
            curr = queue.popleft()
            
            # 更新答案
            if curr < ans:
                ans = curr
            
            # 操作 1：对奇数下标字符加 a
            lst = list(curr)
            for i in range(1, len(lst), 2):
                lst[i] = str((int(lst[i]) + a) % 10)
            next1 = ''.join(lst)
            
            # 操作 2：旋转 b 位
            next2 = curr[-b:] + curr[:-b]
            
            for nxt in (next1, next2):
                if nxt not in visited:
                    visited.add(nxt)
                    queue.append(nxt)
        
        return ans
```

### 方法二：枚举旋转次数和加法次数

```python
class Solution:
    def findLexSmallestString(self, s: str, a: int, b: int) -> str:
        n = len(s)
        ans = s
        
        # 旋转的唯一位置数由 gcd(b, n) 决定
        # 枚举所有旋转后的字符串
        curr = s
        seen_rotations = set()
        
        while curr not in seen_rotations:
            seen_rotations.add(curr)
            
            # 对当前旋转位置，枚举所有加法次数
            temp = curr
            for _ in range(10):  # 加 10 次回到原始（加法周期为 10）
                if temp < ans:
                    ans = temp
                # 对奇数位加 a
                lst = list(temp)
                for i in range(1, n, 2):
                    lst[i] = str((int(lst[i]) + a) % 10)
                temp = ''.join(lst)
            
            # 旋转 b 位
            curr = curr[-b:] + curr[:-b]
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS | O(n^2 * 10) = O(n^2) | O(n^2) |
| 枚举 | O(n * 10) = O(n) | O(n) |

## 关键点总结

1. 状态空间有限，BFS 可以枚举所有可达状态
2. 加法操作周期为 10（加 10 次循环），旋转操作周期为 n/gcd(b,n)
3. BFS 天然避免重复访问已见状态
4. 方法二更高效：固定旋转位置后，枚举所有加法次数

## 易错点

- 加法只作用于**奇数下标**（1, 3, 5, ...），不是偶数下标
- 旋转是向右旋转 b 位：`s[-b:] + s[:-b]`
- 字符是 0-9 的数字，加法需要取模：`(int(c) + a) % 10`
