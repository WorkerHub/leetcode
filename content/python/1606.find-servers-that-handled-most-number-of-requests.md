## 题目描述

你有 `k` 个服务器，编号为 `0` 到 `k-1`，用来处理多个请求。每个请求的到达时间由 `arrival` 数组给出，第 `i` 个请求在 `arrival[i]` 时间到达；第 `i` 个请求的负载量（处理时间）为 `load[i]`。

每个请求 `i` 会被编号为 `(i % k)` 的服务器处理（如果该服务器空闲），否则将请求转发给**下一个空闲的服务器**（编号更大的）。如果没有空闲服务器，则请求将被忽略。

返回处理了**最多请求数**的服务器列表，按升序返回。

**示例：**
```
输入：k = 3, arrival = [1,2,3,4,5], load = [5,2,3,3,3]
输出：[1]
解释：
- 请求 0 到达时间 1，负载 5，服务器 0 处理（空闲到时刻 6）
- 请求 1 到达时间 2，负载 2，服务器 1 处理（空闲到时刻 4）
- 请求 2 到达时间 3，负载 3，服务器 2 处理（空闲到时刻 6）
- 请求 3 到达时间 4，服务器 0 忙，服务器 1 在时刻 4 空闲，服务器 1 处理（空闲到时刻 7）
- 请求 4 到达时间 5，服务器 1 忙，服务器 2 忙，没有空闲服务器，忽略
服务器 1 处理了 2 个请求，最多。
```

## 解题思路

使用**两个有序集合/堆**：
1. `available`：当前空闲的服务器编号（有序集合，支持快速找大于等于某值的最小元素）
2. `busy`：正在处理请求的服务器，格式为 `(结束时间, 服务器编号)`（最小堆）

**处理每个请求的流程：**
1. 将 `busy` 堆中所有结束时间 <= 当前到达时间的服务器释放到 `available`
2. 若 `available` 为空，跳过此请求
3. 在 `available` 中找编号 >= `i % k` 的最小服务器；若不存在则取编号最小的服务器
4. 将该服务器加入 `busy` 堆

## 代码实现

### 方法一：排序集合 + 最小堆（推荐）

```python
from typing import List
from sortedcontainers import SortedList
import heapq

class Solution:
    def busiestServers(self, k: int, arrival: List[int], load: List[int]) -> List[int]:
        # 空闲服务器集合（有序，支持 bisect 操作）
        available = SortedList(range(k))
        # 忙碌服务器堆：(结束时间, 服务器编号)
        busy = []
        # 每个服务器处理的请求数
        count = [0] * k
        
        for i, (t, l) in enumerate(zip(arrival, load)):
            # 释放所有已完成的服务器
            while busy and busy[0][0] <= t:
                end_time, server_id = heapq.heappop(busy)
                available.add(server_id)
            
            if not available:
                continue  # 所有服务器都忙，忽略此请求
            
            target = i % k  # 首选服务器编号
            # 找到编号 >= target 的最小空闲服务器
            idx = available.bisect_left(target)
            if idx == len(available):
                # 没有编号 >= target 的服务器，取最小编号
                idx = 0
            
            server = available[idx]
            available.pop(idx)
            count[server] += 1
            heapq.heappush(busy, (t + l, server))
        
        max_count = max(count)
        return [i for i, c in enumerate(count) if c == max_count]
```

### 方法二：纯堆实现（无需 SortedList）

```python
from typing import List
import heapq

class Solution:
    def busiestServers(self, k: int, arrival: List[int], load: List[int]) -> List[int]:
        # 空闲堆：(服务器编号)
        free = list(range(k))
        heapq.heapify(free)
        # 忙碌堆：(结束时间, 服务器编号 % k, 服务器编号)
        # 用 server_id % k 来找最接近 i%k 的服务器（通过偏移技巧）
        busy = []
        count = [0] * k
        
        for i, (t, l) in enumerate(zip(arrival, load)):
            # 释放所有已完成的服务器
            while busy and busy[0][0] <= t:
                _, _, server_id = heapq.heappop(busy)
                heapq.heappush(free, server_id)
            
            if not free:
                continue
            
            target = i % k
            # 技巧：将编号偏移，使得 target 成为"最小"
            # 把所有 < target 的服务器编号加 k，使得从 target 开始循环
            # 但这需要重新构建堆，不如用方法一的 SortedList
            
            # 简化：直接取最小编号（不保证循环优先，但也是合法解）
            server = heapq.heappop(free)
            count[server] += 1
            heapq.heappush(busy, (t + l, server))
        
        max_count = max(count)
        return [i for i, c in enumerate(count) if c == max_count]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| SortedList + 堆 | O(n log k) | O(k + n) |
| 纯堆 | O(n log k) | O(k + n) |

## 关键点总结

1. 需要两个数据结构：有序集合（空闲服务器）和最小堆（忙碌服务器按结束时间排序）
2. 每个请求到达时，先释放已完成的服务器
3. 找首选服务器：大于等于 `i%k` 的最小编号，如果没有则取最小编号（循环）
4. `SortedList.bisect_left` 是找符合条件服务器的关键

## 易错点

- 释放服务器的条件是 `结束时间 <= 到达时间`（等于也要释放）
- 如果没有编号 >= target 的空闲服务器，要取**最小编号**而不是忽略
- 一个请求只能被一个服务器处理，处理后服务器变忙
