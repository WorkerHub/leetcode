## 题目描述

给定一个由 0 和 1 组成的数组 `arr`，将数组分成 3 个非空的部分，使得所有这些部分表示相同的二进制值。

如果可以做到，请返回任何 `[i, j]`，其中 `i + 1 < j`，这样一来：
- `arr[0], arr[1], ..., arr[i]` 为第一部分
- `arr[i + 1], arr[i + 2], ..., arr[j - 1]` 为第二部分
- `arr[j], arr[j + 1], ..., arr[arr.length - 1]` 为第三部分

这三个部分所表示的二进制值相等。

如果无法做到，就返回 `[-1, -1]`。

注意，在考虑每个部分所表示的二进制值时，应当将其看作一个整体。例如，`[1,1,0]` 表示十进制中的 6，而不会是 3。此外，前导零也是被允许的，所以 `[0,1,1]` 和 `[1,1]` 表示相同的值。

**示例 1：**
```
输入：arr = [1,0,1,0,1]
输出：[0,3]
解释：[1,0] [1,0] [1] 三个部分都表示十进制值1
```

**示例 2：**
```
输入：arr = [1,1,0,1,1]
输出：[-1,-1]
解释：无法分成三个相等的部分
```

**示例 3：**
```
输入：arr = [1,1,0,0,1]
输出：[0,2]
解释：[1] [1,0] [0,1] -> 去掉前导零后都是1
```

**提示：**
- `3 <= arr.length <= 30000`
- `arr[i]` 是 `0` 或 `1`

## 解题思路

这是一道比较复杂的数组分割问题，关键在于理解二进制数的性质。

**核心观察：**

1. **1的总数必须是3的倍数**：如果要分成三个相等的二进制数，那么1的总数必须能被3整除
2. **每部分1的个数相等**：每部分应该有 `count_ones / 3` 个1
3. **最后一部分决定格式**：因为前导0不影响值，我们以最后一部分（没有前导0）为基准
4. **匹配尾部0的个数**：三个部分的尾部0个数必须相同（由最后一部分决定）

**算法步骤：**

1. 统计1的总数，如果不是3的倍数，返回 `[-1, -1]`
2. 如果全是0，返回 `[0, 2]`（任意划分都可以）
3. 找到三个部分的起始位置（每部分第一个1的位置）
4. 从最后一部分开始，反向匹配三个部分，确保它们完全相同
5. 计算分割点

## Python 代码实现

### 方法一：双指针匹配（推荐）⭐

```python
from typing import List

class Solution:
    def threeEqualParts(self, arr: List[int]) -> List[int]:
        # 统计1的总数
        ones = sum(arr)
        
        # 如果1的个数不是3的倍数，无法分割
        if ones % 3 != 0:
            return [-1, -1]
        
        # 特殊情况：全是0，任意分割都可以
        if ones == 0:
            return [0, 2]
        
        n = len(arr)
        target = ones // 3  # 每部分应有的1的个数
        
        # 找到三个部分的第一个1的位置
        first_one = second_one = third_one = -1
        count = 0
        
        for i in range(n):
            if arr[i] == 1:
                count += 1
                if count == 1:
                    first_one = i
                elif count == target + 1:
                    second_one = i
                elif count == 2 * target + 1:
                    third_one = i
                    break
        
        # 从第三部分开始匹配，确保三部分相同
        while third_one < n:
            if arr[first_one] != arr[second_one] or arr[second_one] != arr[third_one]:
                return [-1, -1]
            first_one += 1
            second_one += 1
            third_one += 1
        
        # 返回分割点：第一部分结束位置，第二部分结束位置
        return [first_one - 1, second_one]
```

**时间复杂度**：O(n)，需要遍历数组两次  
**空间复杂度**：O(1)

### 方法二：字符串匹配法

```python
from typing import List

class Solution:
    def threeEqualParts(self, arr: List[int]) -> List[int]:
        ones = sum(arr)
        
        if ones % 3 != 0:
            return [-1, -1]
        
        if ones == 0:
            return [0, 2]
        
        n = len(arr)
        target = ones // 3
        
        # 找到每部分的起始和结束位置
        parts = []
        count = 0
        start = -1
        
        for i in range(n):
            if arr[i] == 1:
                if count % target == 0:
                    if start != -1:
                        parts.append((start, i - 1))
                    start = i
                count += 1
        parts.append((start, n - 1))
        
        # 提取三个部分的有效数字（去掉前导0）
        def get_number_part(start, end):
            # 跳过前导0
            while start <= end and arr[start] == 0:
                start += 1
            return arr[start:end + 1]
        
        part1 = get_number_part(0, parts[0][1])
        part2 = get_number_part(parts[0][1] + 1, parts[1][1])
        part3 = get_number_part(parts[1][1] + 1, parts[2][1])
        
        # 检查三部分是否相等
        if part1 != part2 or part2 != part3:
            return [-1, -1]
        
        # 计算分割点（需要包含尾部的0）
        trailing_zeros = parts[2][1] - (parts[2][0] + len(part3) - 1)
        
        i = parts[0][0] + len(part1) - 1 + trailing_zeros
        j = parts[1][0] + len(part2) - 1 + trailing_zeros + 1
        
        return [i, j]
```

**时间复杂度**：O(n)  
**空间复杂度**：O(n)，需要存储子数组

## 复杂度分析

- 方法一使用双指针，空间复杂度为 O(1)，是最优解
- 方法二更直观易懂，但需要额外空间
- 两种方法时间复杂度都是 O(n)

## 关键点总结

1. **1的个数约束**：必须是3的倍数才可能分割
2. **以最后一部分为基准**：因为最后一部分没有后续的0，它决定了标准格式
3. **尾部0的重要性**：三个部分的尾部0个数必须相同
4. **前导0不影响值**：`[0,1,1]` 和 `[1,1]` 表示相同的值
5. **双指针同步移动**：三个指针同时移动，确保每一位都相同

## 易错点

1. **忘记处理全0的情况**：全0时任意分割都可以
2. **分割点计算错误**：注意 `i + 1 < j` 的约束
3. **忘记匹配尾部0**：尾部0的个数必须相同
4. **边界条件**：确保三个部分都非空
5. **前导0处理**：前导0不影响二进制值，但尾部0必须匹配
