## 题目描述

给定一个日期,以三个整数 `day`,`month` 和 `year` 的形式返回这一天是星期几。

返回值应该是这几个值中的一个: `"Sunday"`, `"Monday"`, `"Tuesday"`, `"Wednesday"`, `"Thursday"`, `"Friday"`, `"Saturday"`。

**示例 1:**

```
输入: day = 31, month = 8, year = 2019
输出: "Saturday"
```

**示例 2:**

```
输入: day = 18, month = 7, year = 1999
输出: "Sunday"
```

**示例 3:**

```
输入: day = 15, month = 8, year = 1993
输出: "Sunday"
```

**提示:**
- 给定的日期一定是 `1971` 年到 `2100` 年之间的有效日期
- `1971年1月1日` 是星期五

## 解题思路

这道题有多种解法:

**方法1: 使用 Python datetime 库(最简单)**
- 直接调用标准库获取星期几

**方法2: 蔡勒公式(Zeller's Congruence)**
- 数学公式计算星期几
- 适合不使用库的情况

**方法3: 从基准日期累加**
- 从 1971年1月1日(星期五)开始累加天数
- 计算经过的总天数,然后模 7

## Python 代码实现

### 方法一: datetime 库(推荐)

```python
from datetime import datetime

class Solution:
    def dayOfTheWeek(self, day: int, month: int, year: int) -> str:
        """
        使用 Python 标准库 datetime
        """
        weeks = ["Monday", "Tuesday", "Wednesday", "Thursday", 
                 "Friday", "Saturday", "Sunday"]
        
        # 创建日期对象
        date = datetime(year, month, day)
        
        # weekday() 返回 0-6,0 表示星期一
        return weeks[date.weekday()]
```

### 方法二: 蔡勒公式

```python
class Solution:
    def dayOfTheWeek(self, day: int, month: int, year: int) -> str:
        """
        使用蔡勒公式计算星期几
        """
        weeks = ["Sunday", "Monday", "Tuesday", "Wednesday", 
                 "Thursday", "Friday", "Saturday"]
        
        # 蔡勒公式中,1月和2月要看作上一年的13月和14月
        if month < 3:
            month += 12
            year -= 1
        
        # 世纪
        century = year // 100
        # 年份
        year_of_century = year % 100
        
        # 蔡勒公式
        # w = (d + 2*m + 3*(m+1)/5 + y + y/4 - y/100 + y/400 + 1) % 7
        week = (day + 2 * month + 3 * (month + 1) // 5 + 
                year_of_century + year_of_century // 4 - 
                century // 4 + century // 2 + 1) % 7
        
        return weeks[week]
```

### 方法三: 从基准日期累加

```python
class Solution:
    def dayOfTheWeek(self, day: int, month: int, year: int) -> str:
        """
        从 1971年1月1日(星期五)开始累加天数
        """
        weeks = ["Sunday", "Monday", "Tuesday", "Wednesday", 
                 "Thursday", "Friday", "Saturday"]
        
        # 每月天数(非闰年)
        days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 计算从 1971年1月1日 到给定日期的总天数
        total_days = 0
        
        # 累加年份的天数
        for y in range(1971, year):
            if self.isLeapYear(y):
                total_days += 366
            else:
                total_days += 365
        
        # 累加月份的天数
        for m in range(1, month):
            total_days += days_in_month[m - 1]
            # 如果是闰年的2月之后,要加1天
            if m == 2 and self.isLeapYear(year):
                total_days += 1
        
        # 累加天数
        total_days += day
        
        # 1971年1月1日是星期五(索引5)
        # 加上经过的天数,模7得到星期几
        week_index = (5 + total_days) % 7
        
        return weeks[week_index]
    
    def isLeapYear(self, year: int) -> bool:
        """判断是否是闰年"""
        return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```

### 方法四: 简化的累加方法

```python
class Solution:
    def dayOfTheWeek(self, day: int, month: int, year: int) -> str:
        """
        简化版本的累加方法
        """
        weeks = ["Sunday", "Monday", "Tuesday", "Wednesday", 
                 "Thursday", "Friday", "Saturday"]
        
        # 每月天数
        month_days = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        # 计算总天数
        days = 0
        
        # 累加完整年份的天数
        for y in range(1971, year):
            days += 366 if (y % 400 == 0 or (y % 4 == 0 and y % 100 != 0)) else 365
        
        # 累加当年已过月份的天数
        for m in range(1, month):
            days += month_days[m]
        
        # 闰年2月多一天
        if month > 2 and (year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)):
            days += 1
        
        # 加上当月天数
        days += day
        
        # 1971-01-01 是星期五,索引为 5
        return weeks[(4 + days) % 7]
```

## 复杂度分析

**方法一: datetime 库**
- 时间复杂度: O(1),库函数内部实现
- 空间复杂度: O(1)

**方法二: 蔡勒公式**
- 时间复杂度: O(1),纯数学计算
- 空间复杂度: O(1)

**方法三/四: 累加法**
- 时间复杂度: O(year - 1971),需要遍历年份
- 空间复杂度: O(1)

## 关键点总结

1. **datetime 库方法**: 最简单直接,实际开发中推荐
2. **蔡勒公式**: 数学方法,不依赖库
3. **累加法**: 容易理解,从已知日期累加
4. **闰年判断**: `(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)`
5. **基准日期**: 1971年1月1日是星期五

## 易错点

1. 闰年判断错误: 要同时考虑 4、100、400 的整除关系
2. 月份天数错误: 注意闰年2月有29天
3. 蔡勒公式中 1月和 2月的特殊处理
4. 星期数组的索引对应关系
5. 累加天数时忘记考虑闰年
6. datetime.weekday() 返回 0-6,0 是星期一
