## 题目描述

给你一个**非递减**有序整数数组 `nums`。

请你建立并返回一个整数数组 `result`，它跟 `nums` 长度相同，且 `result[i]` 等于 `nums` 中所有元素和 `nums[i]` 的**绝对差之和**。

换句话说，`result[i]` 等于 `sum(|nums[i]-nums[j]|)`，其中 `0 <= j < nums.length` 且 `j != i`。

**示例 1：**
```
输入：nums = [2,3,5]
输出：[4,3,5]
解释：
result[0] = |2-2| + |2-3| + |2-5| = 0 + 1 + 3 = 4
result[1] = |3-2| + |3-3| + |3-5| = 1 + 0 + 2 = 3
result[2] = |5-2| + |5-3| + |5-5| = 3 + 2 + 0 = 5
```

**示例 2：**
```
输入：nums = [1,4,6,8,10]
输出：[24,15,13,15,21]
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
- `nums` 按**非递减**顺序排列

## 解题思路

暴力做法是 O(n^2)，对每个位置遍历所有其他位置求绝对差之和。数组已排序，可以利用前缀和优化到 O(n)。

对于位置 `i`，设左边有 `i` 个元素（索引 0 到 i-1），右边有 `n-1-i` 个元素：
- 左边的元素都 <= nums[i]：贡献 = `i * nums[i] - prefix[i]`
- 右边的元素都 >= nums[i]：贡献 = `(suffix[i]) - (n-1-i) * nums[i]`

其中 `prefix[i]` = nums[0] + ... + nums[i-1]，`suffix[i]` = nums[i+1] + ... + nums[n-1]。

用总和 `total` 和前缀和 `pre` 可以快速计算：
- 右侧总和 = `total - pre - nums[i]`
- `result[i] = i*nums[i] - pre + (total - pre - nums[i]) - (n-1-i)*nums[i]`

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def getSumAbsoluteDifferences(self, nums: List[int]) -> List[int]:
        n = len(nums)
        total = sum(nums)
        result = []
        pre = 0  # nums[0..i-1] 的前缀和

        for i, x in enumerate(nums):
            # 左边 i 个元素，都 <= x，贡献 i*x - pre
            left = i * x - pre
            # 右边 n-1-i 个元素，都 >= x
            right_sum = total - pre - x  # 右边元素之和
            right = right_sum - (n - 1 - i) * x
            result.append(left + right)
            pre += x  # 更新前缀和

        return result
```

### 方法二：显式构建前缀和数组

```python
from typing import List

class Solution:
    def getSumAbsoluteDifferences(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 构建前缀和数组，prefix[i] 表示 nums[0..i-1] 之和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        total = prefix[n]
        result = []

        for i in range(n):
            # 左侧：i 个元素，索引 0..i-1
            left_sum = prefix[i]          # 左侧元素之和
            left_count = i
            left = left_count * nums[i] - left_sum

            # 右侧：n-1-i 个元素，索引 i+1..n-1
            right_sum = total - prefix[i + 1]  # 右侧元素之和
            right_count = n - 1 - i
            right = right_sum - right_count * nums[i]

            result.append(left + right)

        return result
```

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历即可
- **空间复杂度**：O(n)（方法二），O(1) 额外空间（方法一，不计结果数组）

## 关键点总结

1. 数组已排序，左边元素 <= 当前元素，右边元素 >= 当前元素，绝对值可以去掉
2. 前缀和将求和操作降为 O(1)
3. 左侧贡献 = `左侧元素个数 * nums[i] - 左侧元素总和`
4. 右侧贡献 = `右侧元素总和 - 右侧元素个数 * nums[i]`

## 易错点

1. 边界处理：`i=0` 时左侧贡献为 0，`i=n-1` 时右侧贡献为 0
2. 索引与前缀和数组下标的对应关系，容易差一
3. 注意 `prefix[i]` 的定义：是 `nums[0..i-1]` 的和，不包含 `nums[i]`
