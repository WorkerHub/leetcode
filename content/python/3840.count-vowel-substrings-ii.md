## 题目描述

给你一个字符串 `word`，统计包含所有五个元音字母（'a', 'e', 'i', 'o', 'u'）且仅由元音字母组成的子串数目。

**示例 1：**

```
输入：word = "aeiouu"
输出：2
解释：包含所有五个元音的子串：
- "aeiou"（下标 0-4）
- "aeiouu"（下标 0-5）
共 2 个。
```

**示例 2：**

```
输入：word = "unicornarihan"
输出：0
```

**提示：**
- `1 <= word.length <= 2 * 10^5`
- `word` 仅由小写英文字母组成

## 解题思路

**双指针/滑动窗口**技巧（at-least 转化）：

统计"恰好包含 5 种元音"的子串数 = "至少包含 5 种元音" - "至少包含 6 种元音"（但元音只有 5 种，所以 "至少 6 种" = 0）。

不对，应该是：统计全为元音且包含所有 5 种元音的子串。

策略：
1. 找到所有全由元音组成的极大连续段。
2. 在每个极大段内，用滑动窗口统计包含所有 5 种元音的子串数。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')
        n = len(word)
        count = 0

        # 遍历所有全为元音的极大段
        i = 0
        while i < n:
            if word[i] not in vowels:
                i += 1
                continue

            # 找到极大元音段的右端
            j = i
            while j < n and word[j] in vowels:
                j += 1

            # 在 word[i:j] 内统计包含所有 5 种元音的子串数
            seg = word[i:j]
            m = len(seg)
            from collections import Counter

            # 双指针：统计以每个右端结尾的满足条件子串
            left = 0
            freq = Counter()
            distinct = 0

            for right in range(m):
                c = seg[right]
                if freq[c] == 0:
                    distinct += 1
                freq[c] += 1

                # 收缩左端，保持恰好包含 5 种
                while distinct == 5:
                    count += m - right  # 以 right 结尾，左端从 left 到 right-4 都合法
                    # 移除左端
                    lc = seg[left]
                    freq[lc] -= 1
                    if freq[lc] == 0:
                        distinct -= 1
                    left += 1

            i = j

        return count
```

### 方法二：at-least 转化

```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')

        def at_least_k_vowels(k):
            """统计全由元音组成且包含至少 k 种不同元音的子串数"""
            from collections import defaultdict
            freq = defaultdict(int)
            distinct = 0
            count = 0
            left = 0
            n = len(word)

            for right in range(n):
                if word[right] not in vowels:
                    # 重置窗口
                    freq.clear()
                    distinct = 0
                    left = right + 1
                    continue
                c = word[right]
                if freq[c] == 0:
                    distinct += 1
                freq[c] += 1

                while distinct >= k:
                    count += n - right
                    lc = word[left]
                    freq[lc] -= 1
                    if freq[lc] == 0:
                        distinct -= 1
                    left += 1

            return count

        # 恰好 5 种 = 至少 5 种 - 至少 6 种（= 0，因为只有 5 种元音）
        return at_least_k_vowels(5)
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各移动 n 次
- 空间复杂度：O(1)，元音种类固定为 5

## 关键点总结

1. "恰好 5 种" = 至少 5 种 - 至少 6 种（6 种 = 0）。
2. 遇到非元音字符时，窗口必须重置（子串只能包含元音）。
3. 双指针的外层循环统计以右端 right 为结尾的满足条件子串数。

## 易错点

1. 非元音字符会截断合法子串，遇到时需重置窗口。
2. `count += n - right` 而不是 `+= right - left + 1`（方法不同，需确认逻辑）。
3. 方法一统计时注意收缩方向和计数逻辑。
