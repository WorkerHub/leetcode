## 题目描述

给你一个整数数组 `nums` 和两个整数 `limit` 和 `goal`。数组 `nums` 每次操作前有一个限制 `limit`，该限制是每个元素的**绝对值**的最大值，即 `|nums[i]| <= limit`。

请你在不改变现有元素的前提下，向数组中添加元素，使得：
1. 每个新增元素的绝对值不超过 `limit`
2. 数组中所有元素的和等于 `goal`

返回需要添加的**最少元素数目**。

**示例 1：**
```
输入：nums = [1,-1,1], limit = 3, goal = -4
输出：2
解释：当前和为 1，目标和为 -4，差值为 5。每次最多补 3，需要 ceil(5/3) = 2 次
```

**示例 2：**
```
输入：nums = [1,-10,9,1], limit = 100, goal = 0
输出：1
解释：当前和为 1，目标和为 0，差值为 1。添加一个 -1 即可
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= limit <= 10^6`
- `-limit <= nums[i] <= limit`
- `-10^9 <= goal <= 10^9`

## 解题思路

当前数组的和为 `current_sum`，目标和为 `goal`，差值为 `diff = abs(goal - current_sum)`。

每次添加一个元素，其绝对值最大为 `limit`，即每次最多弥补 `limit` 的差值。

所以最少需要添加 `ceil(diff / limit)` 个元素。

使用 Python 的整数除法向上取整：`(diff + limit - 1) // limit`，或者 `math.ceil(diff / limit)`。

## 代码实现

### 方法一：数学贪心（推荐）

```python
from typing import List
import math

class Solution:
    def minElements(self, nums: List[int], limit: int, goal: int) -> int:
        current_sum = sum(nums)
        diff = abs(goal - current_sum)
        # 每次最多弥补 limit，向上取整
        return math.ceil(diff / limit)
```

### 方法二：整数向上取整（避免浮点误差）

```python
from typing import List

class Solution:
    def minElements(self, nums: List[int], limit: int, goal: int) -> int:
        current_sum = sum(nums)
        diff = abs(goal - current_sum)
        # 整数向上取整公式：(a + b - 1) // b
        return (diff + limit - 1) // limit
```

## 复杂度分析

- **时间复杂度**：O(n)，计算数组总和需要遍历一次
- **空间复杂度**：O(1)

## 关键点总结

1. 差值 = `abs(goal - sum(nums))`
2. 每次最多弥补 `limit` 的差值（贪心：每次加入绝对值为 `limit` 的元素）
3. 向上取整：`(diff + limit - 1) // limit` 比 `math.ceil` 更稳健，避免浮点问题
4. 差值可能为 0，返回 0

## 易错点

1. 差值要取绝对值，`goal - current_sum` 可能是负数
2. 使用整数向上取整避免浮点精度问题（当 diff 很大时）
3. 如果 `diff = 0`，无需添加任何元素，返回 0
