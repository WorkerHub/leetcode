## 题目描述

与 3048 相同题意，但 `n` 和 `m` 扩大到 `5 * 10^5`，需要更高效算法。

**提示：**
- `1 <= n <= 5 * 10^5`
- `1 <= m <= 5 * 10^5`

## 解题思路

二分答案 + 贪心 + 堆。

对固定时间 T，验证是否可行：

**贪心思路：**
- 从后往前遍历 `changeIndices[0..T-1]`
- 每次遇到下标 `i = changeIndices[t] - 1`，若 `i` 未被标记：
  - 若我们决定在时刻 `t` 标记 `i`，则需要在 `t` 之前有 `nums[i]` 个空闲时刻做减 1 操作
  - 使用最大堆贪心：总是选择 `nums[i]` 最大的下标先处理（让大需求早消耗）

等价于：从后往前扫，用最大堆维护当前"已决定要在未来某时刻标记"的下标的 `nums[i]` 值，空闲时刻优先消耗堆顶（最大值）。

## Python 代码实现

### 方法一：二分 + 最大堆贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def earliestSecondToMarkIndices(self, nums: List[int], changeIndices: List[int]) -> int:
        n = len(nums)
        m = len(changeIndices)

        def check(T: int) -> bool:
            # 从后往前贪心
            # free：当前可用的"空闲操作"次数（用于减 1）
            # heap：最大堆（存负值），记录待处理的下标的 nums 值
            free = 0
            heap = []  # 最大堆（取负）
            total_dec = 0  # 总减 1 需求（选中标记的下标的 nums 之和）
            marked = [False] * n

            for t in range(T - 1, -1, -1):
                idx = changeIndices[t] - 1
                if not marked[idx]:
                    marked[idx] = True
                    # 尝试将 idx 加入标记计划
                    heapq.heappush(heap, -nums[idx])
                    total_dec += nums[idx]

                    # 若总减 1 需求 > 可用空闲，移除代价最大的（退而求其次）
                    while total_dec > free and heap:
                        total_dec += heapq.heappop(heap)  # 减去最大值（取反后加）

                else:
                    free += 1  # 此时刻可以做减 1

            return len(heap) == n  # 所有下标都被标记

        lo, hi = n, m
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo if lo <= m and check(lo) else -1
```

### 方法二：修正版

```python
from typing import List
import heapq

class Solution:
    def earliestSecondToMarkIndices(self, nums: List[int], changeIndices: List[int]) -> int:
        n = len(nums)
        m = len(changeIndices)

        def check(T: int) -> bool:
            # 贪心：从后往前
            # 对每个时刻：
            # - 若 changeIndices[t] 的下标 i 首次出现（反向看是"最后出现"），
            #   考虑是否在此处标记 i（需要 nums[i] 个空闲时刻在它之前）
            # - 否则，此时刻是空闲的（free += 1）

            heap = []  # 最大堆（用于选择最优调度）
            free = 0
            cnt = 0  # 已决定标记的下标数

            seen = set()
            for t in range(T - 1, -1, -1):
                idx = changeIndices[t] - 1
                if idx not in seen:
                    seen.add(idx)
                    # 将此下标的需求加入候选
                    heapq.heappush(heap, -nums[idx])
                    free -= nums[idx]  # 预先"借"走 nums[idx] 个空闲
                    cnt += 1

                    # 若空闲不足，取消代价最大的候选
                    if free < 0:
                        cost = -heapq.heappop(heap)
                        free += cost + 1  # 返还 cost 个空闲，并且该时刻变成 free
                        cnt -= 1
                else:
                    free += 1  # 此时刻空闲

            return cnt == n

        lo, hi = 1, m
        ans = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(m log(n + m))，二分 O(log m)，每次验证 O(m log n)
- 空间复杂度：O(n + m)

## 关键点总结

1. 二分答案 + 贪心是此类问题的标准做法
2. 从后往前贪心：空闲时刻用于减 1，遇到新下标考虑是否标记
3. 最大堆：若资源不足，优先放弃代价最大的标记（最优化）

## 易错点

1. 当 `free < 0` 时，需要取消代价最大的标记，并恢复对应的资源
2. 从后往前时，"首次遇到"等价于正向时的"最后出现"
3. 每个下标只考虑一次（set 去重）
