## 题目描述

给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2`。

你需要从 `nums1` 中移除 `n/2` 个元素，再从 `nums2` 中移除 `n/2` 个元素。移除之后，将两个数组的剩余元素合并为一个集合。

返回合并后集合的最大长度。

**示例 1：**
```
输入：nums1 = [1,2,3,4,5,6], nums2 = [2,3,2,3,2,3]
输出：5
```

**示例 2：**
```
输入：nums1 = [1,2,3,4], nums2 = [1,2,3,4]
输出：4
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 2 * 10^4`
- `n` 是偶数
- `1 <= nums1[i], nums2[i] <= 10^9`

## 解题思路

贪心策略：

1. 计算 `nums1` 和 `nums2` 各自的独特元素集合
2. 将仅在 `nums1` 中的元素优先保留到 `nums1`（不浪费独特性）
3. 将仅在 `nums2` 中的元素优先保留到 `nums2`
4. 两者共有的元素，优先保留到未满的那一侧

每个数组保留 `n/2` 个元素，尽量选择独特的元素，最大化集合大小。

## Python 代码实现

### 方法一：贪心 + 集合（推荐）

```python
from typing import List

class Solution:
    def maximumSetSize(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        half = n // 2

        set1 = set(nums1)
        set2 = set(nums2)

        # 仅在 nums1 中的元素
        only1 = set1 - set2
        # 仅在 nums2 中的元素
        only2 = set2 - set1
        # 两者共有的元素
        common = set1 & set2

        # nums1 保留的独特元素数量（先尽量选仅在 nums1 中的）
        keep1 = min(len(only1), half)
        # nums2 保留的独特元素数量（先尽量选仅在 nums2 中的）
        keep2 = min(len(only2), half)

        # 剩余配额可以用于共有元素
        remain1 = half - keep1  # nums1 还能选多少
        remain2 = half - keep2  # nums2 还能选多少

        # 从共有元素中分配
        common_take = min(len(common), remain1 + remain2)

        return keep1 + keep2 + common_take
```

### 方法二：更直观的贪心

```python
from typing import List

class Solution:
    def maximumSetSize(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        half = n // 2

        s1, s2 = set(nums1), set(nums2)

        # nums1 中独有的元素（优先选）
        unique1 = s1 - s2
        # nums2 中独有的元素（优先选）
        unique2 = s2 - s1
        # 公共元素
        both = s1 & s2

        # 从 nums1 选：先选独有的，再用剩余配额选公共的
        take1_unique = min(len(unique1), half)
        take1_common = min(len(both), half - take1_unique)

        # 从 nums2 选：先选独有的，再用剩余配额选已被 nums1 选了的公共元素
        take2_unique = min(len(unique2), half)
        # nums2 剩余配额可以从公共元素中选（排除 nums1 已选的）
        remaining_common = len(both) - take1_common
        take2_common = min(remaining_common, half - take2_unique)

        return take1_unique + take1_common + take2_unique + take2_common
```

## 复杂度分析

- 时间复杂度：O(n)，构建集合 O(n)，集合操作 O(n)
- 空间复杂度：O(n)，存储集合

## 关键点总结

1. 每个数组各移除一半，即各保留一半
2. 集合大小最大化 = 选出尽量多的不同元素
3. 独有元素优先保留，公共元素按剩余配额分配
4. 两个数组的配额独立计算

## 易错点

1. 注意 `n` 是偶数，`n/2` 是整除
2. 公共元素的分配需要考虑两个数组各自的剩余配额
3. 集合的差集和交集运算结果是新的集合，不改变原集合
