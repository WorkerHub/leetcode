## 题目描述

给你一个数字字符串 `s`，统计有多少个子字符串（连续字符）满足：子字符串代表的数字能被其**最后一位数字**整除。

**示例 1：**

```
输入：s = "12936"
输出：11
解释：计数所有满足条件的子串
```

**示例 2：**

```
输入：s = "24"
输出：4
解释：子串 "2","4","24","4" 中，"2"被2整除，"4"被4整除，"24"被4整除，"4"被4整除
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含数字字符

## 解题思路

对于每个末尾位置 j，末尾数字为 d = s[j]。需要统计以 j 结尾、以 s[i] 开头（i <= j）的子串，满足 s[i..j] 整除 d。

设 `dp[j][r]` = 以位置 j 结尾、子串对 d 取模余数为 r 的子串数（d = int(s[j])）。

转移：`s[i..j] mod d = (s[i..j-1] * 10 + s[j]) mod d`

- 若以 j-1 结尾，余数为 r' 的子串数为 dp[j-1][r']
- 则加上 s[j] 后，余数变为 `(r' * 10 + d) mod d`

等等，d 是 s[j]，每次 j 改变时 d 也改变，状态不能直接复用。

**按末尾数字分情况**：对每个数字 d（1-9），分别统计末尾为 d 的子串数量。

对末尾是 d 的位置 j，dp[d][j][r] = 以位置 j 结尾、值 mod d = r 的子串数。

## Python 代码实现

### 方法一：DP 按末尾数字分组

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        ans = 0

        # 对每个末尾位置 j（末尾数字 d = int(s[j])）
        # dp_d[r] = 以当前位置结尾、值 mod d = r 的子串数
        # 对每个 d，维护独立的 dp 数组

        # dp[d][r]: 以当前字符结尾，值 mod d = r 的子串数
        # d in 1..9, r in 0..d-1

        # 每个 d 有独立的状态，需要在扫描 s 时同时维护

        # dp_counts[d][r]: 对数字 d，以当前位置（某个结尾是 d 的位置）之前某位置开始的子串，mod d = r 的数量
        # 这很复杂，因为 d 不断变化

        # 简化方法：对 d=1..9，对每个以 d 结尾的位置 j，暴力统计
        for j in range(n):
            d = int(s[j])
            if d == 0:
                # 子串不能被 0 整除（或者题目保证 s 中没有 0？）
                continue
            # 暴力：统计以 j 结尾的所有子串
            val = 0
            power = 1
            for i in range(j, -1, -1):
                val = (int(s[i]) * power + val) % d
                if val == 0:
                    ans += 1
                power = power * 10 % d

        return ans
```

### 方法二：DP 优化（对每个 d 维护余数计数）

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        ans = 0

        # 对每个 d (1-9)，维护：
        # remainder_count[d][r] = 以当前位置之前某处开始的子串，值 mod d = r 的数量
        # 当新字符 s[j] 来时：
        #   若 int(s[j]) == d，统计 remainder_count[d][0]（即子串能被 d 整除）
        #   然后更新：所有旧子串末尾加上 s[j]，余数 r' -> (r' * 10 + int(s[j])) mod d
        #   加上只有 s[j] 本身的子串：余数 = int(s[j]) mod d

        # 对每个 d，维护 remainder_count
        rem_count = [[0] * d_val for d_val in range(10)]  # 占位

        # 重新：只对 1-9 有效
        # rem_cnt[d] 是一个数组，size = d，rem_cnt[d][r] = 以当前位置结尾且 mod d = r 的子串数

        # 处理方式：对每个 d，当 j 处字符改变时更新 rem_cnt[d]

        # 对 d 的更新：rem_cnt[d][new_r] = sum(rem_cnt[d][r] for r: (r*10+s[j]) mod d == new_r)
        # 但这对每个 d 都需要 O(d) 更新

        # 初始化
        rem_cnts = {d: [0] * d for d in range(1, 10)}

        for j in range(n):
            c = int(s[j])
            if c == 0:
                # 跳过末尾为 0 的情况
                for d in range(1, 10):
                    new_rem = [0] * d
                    for r in range(d):
                        new_rem[(r * 10 + 0) % d] += rem_cnts[d][r]
                    new_rem[0 % d] += 1  # 单个字符 "0"
                    rem_cnts[d] = new_rem
                continue

            # 更新所有 d 的余数计数
            for d in range(1, 10):
                new_rem = [0] * d
                for r in range(d):
                    new_rem[(r * 10 + c) % d] += rem_cnts[d][r]
                # 加上单个字符 s[j]
                new_rem[c % d] += 1
                rem_cnts[d] = new_rem

            # 统计以 j 结尾（末尾为 c）的合法子串
            ans += rem_cnts[c][0]

        return ans
```

## 复杂度分析

- 方法一（暴力）：O(n^2)
- 方法二（DP）：O(n * 9 * 9) = O(n)
- 空间复杂度：O(9^2) = O(1)

## 关键点总结

1. 对每个末尾数字 d，维护以当前位置结尾、值 mod d = r 的子串数
2. 转移：新来字符 c，旧余数 r -> 新余数 (r*10+c) mod d
3. 当末尾字符为 d 时，计数 rem_cnts[d][0]（整除的子串数）

## 易错点

1. 每个 d 有独立的余数状态，不能混用
2. 每次处理字符时，要先更新所有 d 的状态，再统计
3. 末尾为 0 的子串：0 不能作为除数，需要特殊处理
