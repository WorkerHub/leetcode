## 题目描述

Alice 玩下述游戏，她从 `0` 开始：
- 抽取数字 `1 ~ maxPts` 中的一个，加到她的分数上
- 当分数小于 `k` 时继续抽取，否则停止
- Alice 的目标是得分不超过 `n`

如果 Alice 获胜的概率在 `10^-5` 的范围内，则返回这个概率。

## Python 代码实现

```python
class Solution:
    def new21Game(self, n: int, k: int, maxPts: int) -> float:
        if k == 0 or n >= k + maxPts - 1:
            return 1.0
        
        dp = [0.0] * (n + 1)
        dp[0] = 1.0
        window_sum = 1.0
        
        for i in range(1, n + 1):
            dp[i] = window_sum / maxPts
            
            if i < k:
                window_sum += dp[i]
            
            if i >= maxPts:
                window_sum -= dp[i - maxPts]
        
        return sum(dp[k:])
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **概率DP**：dp[i] 表示得分为i的概率
2. **滑动窗口**：优化概率累加
3. **边界条件**：k=0 或 n 足够大时必胜
