## 题目描述

一群朋友在度假期间会相互借钱。比如，小爱同学支付了小新同学的午餐共计 10 美元。如果小明同学支付了小爱同学的出租车钱共计 5 美元。我们可以用一个三元组 `(x, y, z)` 表示一次交易，表示 `x` 借给 `y` 共计 `z` 美元。用 `0, 1, 2` 表示小爱同学、小新同学和小明同学（`0, 1, 2` 为朋友的 ID），交易记录为 `[[0, 1, 10], [2, 0, 5]]`。

给定一群人之间的交易记录列表，计算能够还清所有债务的最小次数。

**注意：**
1. 一次交易会以三元组 `(x, y, z)` 表示，并有 `x ≠ y` 且 `z > 0`。
2. 人的标识从 0 开始，可能不连续。

**示例 1：**
```
输入：transactions = [[0,1,10],[2,0,5]]
输出：2
解释：
人物 0 给人物 1 共计 10 美元。
人物 2 给人物 0 共计 5 美元。

需要两次交易。一种方式是人物 1 分别给人物 0 和人物 2 各 5 美元。
```

**示例 2：**
```
输入：transactions = [[0,1,10],[1,0,1],[1,2,5],[2,0,5]]
输出：1
解释：
人物 0 给人物 1 共计 10 美元。
人物 1 给人物 0 共计 1 美元。
人物 1 给人物 2 共计 5 美元。
人物 2 给人物 0 共计 5 美元。

因此，人物 1 只需要给人物 0 共计 4 美元，所有的债务即可还清。
```

**提示：**
- `1 <= transactions.length <= 8`
- `transactions[i].length == 3`
- `0 <= fromi, toi < 12`
- `fromi != toi`
- `1 <= amounti <= 100`

## 解题思路

这是一道经典的**账务平衡问题**，本质是图论中的**多商品流问题**，但规模较小可用回溯求解。

**核心观察：**
1. 先计算每个人的净债务（收入 - 支出）
2. 净债务为正表示别人欠他钱，为负表示他欠别人钱
3. 问题转化为：用最少的交易次数使所有净债务归零

**关键性质：**
- 如果有 n 个人有非零债务，最多需要 n-1 次交易就能平衡
- 目标是找到更少的交易次数

**算法思路：**
1. 计算每个人的净债务
2. 过滤掉净债务为 0 的人（已平衡）
3. 使用回溯法尝试不同的配对方式
4. 每次配对使一个或两个人的债务归零

**优化策略：**
- 如果两个人的净债务相反（一正一负且绝对值相等），一次交易即可抵消
- 优先处理能完全抵消的配对

## Python 代码实现

### 方法一：回溯法（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def minTransfers(self, transactions: List[List[int]]) -> int:
        # 步骤 1：计算每个人的净债务
        balance = defaultdict(int)
        for from_p, to_p, amount in transactions:
            balance[from_p] -= amount  # from_p 支出
            balance[to_p] += amount    # to_p 收入
        
        # 步骤 2：过滤掉净债务为 0 的人
        debts = [b for b in balance.values() if b != 0]
        
        # 步骤 3：回溯求解最少交易次数
        def backtrack(idx):
            # 跳过已平衡的人
            while idx < len(debts) and debts[idx] == 0:
                idx += 1
            
            # 所有人都已平衡
            if idx == len(debts):
                return 0
            
            min_transfers = float('inf')
            
            # 尝试与后面的人配对
            for i in range(idx + 1, len(debts)):
                # 只配对相反符号的债务（一个欠钱，一个要钱）
                if debts[idx] * debts[i] < 0:
                    # 配对：idx 给 i 转账（或反之）
                    debts[i] += debts[idx]  # 合并债务
                    
                    # 递归处理下一个人
                    min_transfers = min(min_transfers, 1 + backtrack(idx + 1))
                    
                    # 回溯
                    debts[i] -= debts[idx]
            
            return min_transfers
        
        return backtrack(0)
```

**核心技巧：**
- `debts[i] += debts[idx]`：将 idx 的债务转移给 i
- `debts[idx] * debts[i] < 0`：确保一正一负才配对

### 方法二：优化回溯（优先完全抵消）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minTransfers(self, transactions: List[List[int]]) -> int:
        # 计算净债务
        balance = defaultdict(int)
        for from_p, to_p, amount in transactions:
            balance[from_p] -= amount
            balance[to_p] += amount
        
        debts = [b for b in balance.values() if b != 0]
        n = len(debts)
        
        # 优化：优先处理能完全抵消的配对
        def backtrack(idx):
            while idx < n and debts[idx] == 0:
                idx += 1
            
            if idx == n:
                return 0
            
            min_count = float('inf')
            
            for i in range(idx + 1, n):
                if debts[idx] * debts[i] < 0:
                    # 保存原值
                    original = debts[i]
                    debts[i] += debts[idx]
                    
                    # 如果完全抵消，优先选择（剪枝）
                    if debts[i] == 0:
                        min_count = min(min_count, 1 + backtrack(idx + 1))
                    else:
                        min_count = min(min_count, 1 + backtrack(idx + 1))
                    
                    # 回溯
                    debts[i] = original
            
            return min_count
        
        return backtrack(0)
```

### 方法三：状态压缩 DP（理论最优）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minTransfers(self, transactions: List[List[int]]) -> int:
        # 计算净债务
        balance = defaultdict(int)
        for from_p, to_p, amount in transactions:
            balance[from_p] -= amount
            balance[to_p] += amount
        
        debts = [b for b in balance.values() if b != 0]
        n = len(debts)
        
        # dp[mask] 表示平衡 mask 对应的人所需的最少交易数
        # 预处理：哪些子集可以内部平衡（总和为 0）
        can_balance = [False] * (1 << n)
        for mask in range(1 << n):
            total = sum(debts[i] for i in range(n) if mask & (1 << i))
            can_balance[mask] = (total == 0)
        
        # DP
        dp = [float('inf')] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == float('inf'):
                continue
            
            # 找到第一个未处理的人
            first = -1
            for i in range(n):
                if not (mask & (1 << i)):
                    first = i
                    break
            
            if first == -1:
                continue
            
            # 尝试将 first 与其他未处理的人组成子集
            for sub in range(1 << n):
                if mask & sub == 0 and (sub & (1 << first)) and can_balance[sub]:
                    # sub 是可以内部平衡的子集
                    people_count = bin(sub).count('1')
                    dp[mask | sub] = min(dp[mask | sub], dp[mask] + people_count - 1)
        
        return dp[(1 << n) - 1]
```

**注意：** 状态压缩 DP 实现复杂，实际面试中回溯法更实用

## 复杂度分析

**方法一（回溯）：**
- 时间复杂度：O(n!)，最坏情况下尝试所有配对
- 空间复杂度：O(n)，递归栈

**方法二（优化回溯）：**
- 时间复杂度：O(n!)，但剪枝后实际更快
- 空间复杂度：O(n)

**方法三（状态压缩 DP）：**
- 时间复杂度：O(3^n)，枚举子集
- 空间复杂度：O(2^n)

**实际应用：** 由于 `n <= 12`（净债务人数），回溯法完全可行

## 关键点总结

1. **净债务计算：** 收入 - 支出，简化问题
2. **只关心非零债务：** 过滤掉已平衡的人
3. **回溯配对：** 尝试不同的债务合并方式
4. **符号相反才配对：** 一正一负才能抵消
5. **优化剪枝：** 优先处理能完全抵消的配对

## 易错点

1. **忘记过滤零债务：** 包含已平衡的人会影响结果
   ```python
   # 错误
   debts = list(balance.values())
   
   # 正确
   debts = [b for b in balance.values() if b != 0]
   ```

2. **配对条件错误：** 允许同号债务配对
   ```python
   # 错误：同号也配对，无法抵消
   for i in range(idx + 1, n):
       debts[i] += debts[idx]
   
   # 正确：只配对异号
   if debts[idx] * debts[i] < 0:
       debts[i] += debts[idx]
   ```

3. **回溯忘记恢复：** 修改 debts 后必须回溯
   ```python
   # 错误
   debts[i] += debts[idx]
   backtrack(idx + 1)
   # 缺少恢复
   
   # 正确
   debts[i] += debts[idx]
   backtrack(idx + 1)
   debts[i] -= debts[idx]  # 回溯
   ```

4. **理解题意：** 最少交易次数 ≠ 最少金额，是次数
