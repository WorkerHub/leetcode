## 题目描述

给你一个整数数组 `ranks` 和一个字符数组 `suits`，各自长度为 5。代表 5 张扑克牌。

返回最佳的扑克手牌名称：
- **"Flush"**（同花）：5 张牌花色相同。
- **"Three of a Kind"**（三条）：至少有 3 张牌点数相同。
- **"Pair"**（对子）：至少有 2 张牌点数相同。
- **"High Card"**（高牌）：其他情况。

按上述顺序检查，返回最高等级的手牌名称。

**示例 1：**
```
输入：ranks = [13,2,3,1,9], suits = ['a','a','a','a','a']
输出："Flush"
```

**示例 2：**
```
输入：ranks = [4,4,2,4,4], suits = ['d','a','a','b','c']
输出："Three of a Kind"
```

**提示：**
- `ranks.length == suits.length == 5`
- `1 <= ranks[i] <= 13`
- `'a' <= suits[i] <= 'd'`
- 每张牌都是独一无二的

## 解题思路

按优先级依次检查：
1. 若 5 张花色相同 -> Flush。
2. 若某点数出现 >= 3 次 -> Three of a Kind。
3. 若某点数出现 >= 2 次 -> Pair。
4. 否则 -> High Card。

## 代码实现

### 方法一：计数判断（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def bestHand(self, ranks: List[int], suits: List[str]) -> str:
        # 检查同花
        if len(set(suits)) == 1:
            return "Flush"
        
        # 统计点数频率
        rank_count = Counter(ranks)
        max_count = max(rank_count.values())
        
        if max_count >= 3:
            return "Three of a Kind"
        elif max_count >= 2:
            return "Pair"
        else:
            return "High Card"
```

### 方法二：显式判断

```python
from typing import List

class Solution:
    def bestHand(self, ranks: List[int], suits: List[str]) -> str:
        # 同花判断
        if suits.count(suits[0]) == 5:
            return "Flush"
        
        # 点数计数
        freq = {}
        for r in ranks:
            freq[r] = freq.get(r, 0) + 1
        
        vals = sorted(freq.values(), reverse=True)
        
        if vals[0] >= 3:
            return "Three of a Kind"
        if vals[0] >= 2:
            return "Pair"
        return "High Card"
```

|------|-----------|-----------|

## 关键点总结

1. 按优先级从高到低判断：同花 > 三条 > 对子 > 高牌。
2. 同花：5 张花色相同（`len(set(suits)) == 1`）。
3. 三条：某点数出现 >= 3 次；对子：某点数出现 >= 2 次。

## 易错点

- 注意题目只有这 4 种手牌类型，不需要考虑满贯、顺子等。
- 三条包含"四张相同"的情况（`>= 3` 而不是 `== 3`）。
