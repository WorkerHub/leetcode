## 题目描述

设计一个简单的银行系统，实现以下操作：
- `Bank(balance)`：初始化银行，`balance[i]` 是账户 `i+1` 的初始余额（账户编号从 1 开始）
- `transfer(account1, account2, money)`：从账户 1 转账 `money` 到账户 2。若任一账户不存在或余额不足，返回 `false`；否则转账并返回 `true`
- `deposit(account, money)`：向账户存入 `money`。若账户不存在，返回 `false`；否则存款并返回 `true`
- `withdraw(account, money)`：从账户取出 `money`。若账户不存在或余额不足，返回 `false`；否则取款并返回 `true`

**示例：**
```
输入：["Bank","withdraw","transfer","deposit","transfer","withdraw"]
      [[10,100,20,50,30],[3,10],[5,1,20],[5,20],[3,4,15],[10,50]]
输出：[null,true,true,true,false,false]
```

**提示：**
- `n == balance.length`
- `1 <= n, account, account1, account2 <= 10^5`
- `0 <= balance[i], money <= 10^12`

## 解题思路

直接模拟，维护 `balance` 数组，每次操作先验证账户合法性和余额充足性，再更新余额。

## 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Bank:

    def __init__(self, balance: List[int]):
        self.n = len(balance)
        self.balance = [0] + balance  # 1-indexed，balance[0] 不用

    def transfer(self, account1: int, account2: int, money: int) -> bool:
        # 检查账户合法性和余额
        if account1 > self.n or account2 > self.n:
            return False
        if self.balance[account1] < money:
            return False
        self.balance[account1] -= money
        self.balance[account2] += money
        return True

    def deposit(self, account: int, money: int) -> bool:
        if account > self.n:
            return False
        self.balance[account] += money
        return True

    def withdraw(self, account: int, money: int) -> bool:
        if account > self.n:
            return False
        if self.balance[account] < money:
            return False
        self.balance[account] -= money
        return True
```

### 方法二：使用辅助函数减少重复

```python
from typing import List

class Bank:

    def __init__(self, balance: List[int]):
        self.balance = [0] + balance[:]  # 1-indexed

    def _valid(self, account: int) -> bool:
        return 1 <= account < len(self.balance)

    def transfer(self, account1: int, account2: int, money: int) -> bool:
        if not (self._valid(account1) and self._valid(account2)):
            return False
        if self.balance[account1] < money:
            return False
        self.balance[account1] -= money
        self.balance[account2] += money
        return True

    def deposit(self, account: int, money: int) -> bool:
        if not self._valid(account):
            return False
        self.balance[account] += money
        return True

    def withdraw(self, account: int, money: int) -> bool:
        if not self._valid(account):
            return False
        if self.balance[account] < money:
            return False
        self.balance[account] -= money
        return True
```

## 复杂度分析

- 每次操作时间复杂度：O(1)
- 空间复杂度：O(n)，余额数组

## 关键点总结

1. 账户编号从 1 开始，用偏移处理索引
2. 每次操作都需要检查账户是否在 `[1, n]` 范围内
3. `withdraw` 和 `transfer` 还需检查余额是否充足

## 易错点

- 账户编号 `account <= n`（不是 `< n`）
- `transfer` 需要同时验证两个账户，且 `account1` 余额充足
- 注意 `money` 可达 `10^12`，用整型即可（Python 自动处理大整数）
