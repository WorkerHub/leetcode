## 题目描述

给你整数 `zero`，`one`，`low` 和 `high`，我们从空字符串开始构造一个字符串，每次操作可以在字符串末尾添加：

- `zero` 个 `'0'`
- `one` 个 `'1'`

返回长度在 `[low, high]` 之间的 **好字符串** 的数量。

结果取 `10^9 + 7` 的余数。

**示例 1：**
```
输入：low = 3, high = 3, zero = 1, one = 1
输出：8
解释：长度为 3 的字符串有 8 个（000、001、010、011、100、101、110、111）。
```

**示例 2：**
```
输入：low = 2, high = 3, zero = 1, one = 2
输出：5
```

**提示：**
- `1 <= low <= high <= 10^5`
- `1 <= zero, one <= low`

## 解题思路

**动态规划：**

`dp[i]` = 能构造出长度恰好为 `i` 的字符串的方案数。

**转移方程：**
- 若 `i >= zero`：`dp[i] += dp[i - zero]`（末尾添加 zero 个 0）
- 若 `i >= one`：`dp[i] += dp[i - one]`（末尾添加 one 个 1）

**初始条件：** `dp[0] = 1`（空字符串一种）

**答案：** `sum(dp[low..high])`

## 代码实现

### 方法一：线性 DP（推荐）

```python
class Solution:
    def countGoodStrings(self, low: int, high: int, zero: int, one: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i] = 构造长度为 i 的字符串的方案数
        dp = [0] * (high + 1)
        dp[0] = 1  # 空字符串

        for i in range(1, high + 1):
            if i >= zero:
                dp[i] = (dp[i] + dp[i - zero]) % MOD
            if i >= one:
                dp[i] = (dp[i] + dp[i - one]) % MOD

        return sum(dp[low:high + 1]) % MOD
```

### 方法二：记忆化递归

```python
from functools import lru_cache

class Solution:
    def countGoodStrings(self, low: int, high: int, zero: int, one: int) -> int:
        MOD = 10 ** 9 + 7

        @lru_cache(maxsize=None)
        def dp(length: int) -> int:
            """构造长度恰好为 length 的字符串的方案数"""
            if length == 0:
                return 1
            if length < 0:
                return 0
            return (dp(length - zero) + dp(length - one)) % MOD

        return sum(dp(i) for i in range(low, high + 1)) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 线性 DP | O(high) | O(high) |
| 记忆化递归 | O(high) | O(high) |

## 关键点总结

1. DP 状态是当前字符串长度，每次可加 `zero` 或 `one`
2. 类似爬楼梯问题，但每次可跨不同步数
3. 答案是 `dp[low]` 到 `dp[high]` 的和

## 易错点

- 初始化 `dp[0] = 1`（空字符串是起点）
- 取模要在每次加法后立即进行
- 求和时也要取模
