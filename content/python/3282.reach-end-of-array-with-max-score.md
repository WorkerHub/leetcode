## 题目描述

给你一个整数数组 `nums`，从下标 `0` 开始，每次可以跳到任意位置 `j`（`j > i`），得分 `(j - i) * nums[i]`。

返回跳到 `n-1`（数组末尾）的**最大总得分**。

**示例 1：**
```
输入：nums = [1,3,1,5]
输出：9
解释：0->1 得 1*1=1, 1->3 得 2*3=6, 共7；或 0->3 得 3*1=3, 共3；或 0->1, 1->3 得 1+6=7；最大是 0->1->3: 1*1+2*3=7 不对
0->3: 3*1=3
0->1->3: 1*3+2*1=5
0->2->3: 2*1+1*5=7
0->1->2->3: 1*3+1*1+1*5=9 -> 最大9
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

贪心：每次跳跃的得分是 `(j-i) * nums[i]`，取决于起跳点的值。

观察：从位置 i 跳到 j，然后从 j 跳到 k，得分 `(j-i)*nums[i] + (k-j)*nums[j]`。
若直接从 i 跳到 k，得分 `(k-i)*nums[i]`。

当 `nums[j] > nums[i]` 时，经过 j 可以获得更高分：差值 = `(k-j)*(nums[j]-nums[i]) > 0`。
当 `nums[j] <= nums[i]` 时，不如直接跳过 j。

贪心：只在遇到"局部最大值"（比前一个跳点大的位置）时跳一步，否则继续。

更准确：从 i 出发，只有遇到比 `nums[i]` 更大的位置 j 才跳过去，否则一直等到最后。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def findMaximumScore(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        max_val = nums[0]  # 当前的"有效起跳值"
        prev = 0           # 上次跳跃的位置
        
        for i in range(1, n):
            if nums[i] > max_val:
                # 在 prev 到 i 之间，用 max_val 计算得分
                ans += (i - prev) * max_val
                prev = i
                max_val = nums[i]
        
        # 最后从 prev 跳到 n-1
        ans += (n - 1 - prev) * max_val
        
        return ans
```

### 方法二：前缀最大值

```python
from typing import List

class Solution:
    def findMaximumScore(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        cur_max = 0
        
        for i in range(n - 1):
            cur_max = max(cur_max, nums[i])
            ans += cur_max  # 每步贡献 cur_max（等价于 1 * cur_max）
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：只在遇到更大值时才跳跃
2. 等价转化：总得分 = sum(nums[i] * 1) 其中 nums[i] 是到位置 i+1 前的最大值
3. 方法二更简洁：逐步累加前缀最大值

## 易错点

1. 最后必须到达 n-1，要计算最后一段的得分
2. 方法二的正确性：每次移动 1 步，用前缀最大值作为乘数
