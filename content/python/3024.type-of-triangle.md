## 题目描述

给你一个整数数组 `nums`，长度为 3，表示三角形的三条边长。

根据三条边判断三角形类型：
- `"equilateral"`：等边三角形（三边相等）
- `"isosceles"`：等腰三角形（恰好两边相等）
- `"scalene"`：不等边三角形（三边各不相同）
- `"none"`：不能构成三角形

**示例 1：**
```
输入：nums = [3,3,3]
输出："equilateral"
```

**示例 2：**
```
输入：nums = [3,4,5]
输出："scalene"
```

**提示：**
- `nums.length == 3`
- `1 <= nums[i] <= 100`

## 解题思路

1. 先判断是否构成三角形：三角形不等式，任意两边之和 > 第三边
2. 若能构成，再判断类型：等边、等腰（非等边）、不等边

## Python 代码实现

### 方法一：排序后判断（推荐）

```python
from typing import List

class Solution:
    def triangleType(self, nums: List[int]) -> str:
        nums.sort()
        a, b, c = nums

        # 判断是否构成三角形（排序后只需检查 a+b > c）
        if a + b <= c:
            return "none"

        # 判断类型
        if a == b == c:
            return "equilateral"
        elif a == b or b == c:
            return "isosceles"
        else:
            return "scalene"
```

### 方法二：使用 set 判断

```python
from typing import List

class Solution:
    def triangleType(self, nums: List[int]) -> str:
        a, b, c = sorted(nums)

        if a + b <= c:
            return "none"

        unique = len(set(nums))
        if unique == 1:
            return "equilateral"
        elif unique == 2:
            return "isosceles"
        else:
            return "scalene"
```

## 复杂度分析

- 时间复杂度：O(1)，数组长度固定为 3
- 空间复杂度：O(1)

## 关键点总结

1. 三角形不等式：任意两边之和 > 第三边（排序后只需检查最小两边之和 > 最大边）
2. 等边三角形：三边相等（不同值数量为 1）
3. 等腰三角形：恰好两边相等（不同值数量为 2）
4. 不等边三角形：三边各不同（不同值数量为 3）

## 易错点

1. 三角形不等式用 `<=` 判断不合法（等号时不构成三角形）
2. 等腰三角形包含所有有两边相等的情况，但排除等边三角形
