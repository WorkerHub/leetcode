## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

**交换**操作：交换 `nums` 中两个**相邻**元素。

若数组中**最小**元素（若有多个，取最左边的）位于数组**第一个**位置，且数组中**最大**元素（若有多个，取最右边的）位于数组**最后一个**位置，则认为该数组是**有效**的。

返回使数组有效所需的**最少交换次数**。

**示例 1：**
```
输入：nums = [3,4,5,5,3,1]
输出：6
解释：最小值为 1（下标 5），最大值为 5（最右边的，下标 3）。
先将最大值移到末尾：nums[3] 与 nums[4] 交换，再与 nums[5] 交换，共 2 次；
再将最小值移到开头：需要 4 次。共 6 次。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**贪心：**
1. 找最小值的最左位置 `min_idx`，需要 `min_idx` 次交换将其移到开头。
2. 找最大值的最右位置 `max_idx`，需要 `(n-1) - max_idx` 次交换将其移到末尾。
3. 若 `min_idx < max_idx`（最小值在最大值左边），两者操作互不影响，答案为二者之和。
4. 若 `min_idx > max_idx`（最小值在最大值右边），先移最大值到末尾会影响最小值的位置（最小值左移一位），反之亦然。需要减 1。

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minimumSwaps(self, nums: List[int], ) -> int:
        n = len(nums)
        
        # 找最小值的最左下标
        min_val = min(nums)
        min_idx = nums.index(min_val)
        
        # 找最大值的最右下标
        max_val = max(nums)
        max_idx = n - 1 - nums[::-1].index(max_val)
        
        # 移动最小值到开头需要的步数
        steps_min = min_idx
        # 移动最大值到末尾需要的步数
        steps_max = (n - 1) - max_idx
        
        # 若最小值在最大值左边，两者独立
        # 若最小值在最大值右边，移动其中一个会影响另一个，需要减 1
        if min_idx < max_idx:
            return steps_min + steps_max
        else:
            return steps_min + steps_max - 1
```

### 方法二：详细版

```python
from typing import List

class Solution:
    def minimumSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        min_val = min(nums)
        max_val = max(nums)
        
        # 最小值最左下标
        min_pos = 0
        for i in range(n):
            if nums[i] == min_val:
                min_pos = i
                break
        
        # 最大值最右下标
        max_pos = n - 1
        for i in range(n - 1, -1, -1):
            if nums[i] == max_val:
                max_pos = i
                break
        
        cost = min_pos + (n - 1 - max_pos)
        
        # 若 min 在 max 右侧（需要交叉操作），减 1
        if min_pos > max_pos:
            cost -= 1
        
        return cost
```

## 关键点总结

1. 最小值移到头部的代价与最大值移到尾部的代价通常可以独立计算。
2. 当最小值在最大值右侧时，移动最大值会把最小值"带向左"一步，实际节省 1 次操作。
3. 找最小值取最左，找最大值取最右（题目要求）。

## 易错点

- 最大值取最右（用从右开始的 `index`），最小值取最左。
- 减 1 的条件是 `min_idx > max_idx`（最小值在最大值右侧，操作有重叠）。
