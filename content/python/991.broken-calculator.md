## 题目描述

在显示着数字 `startValue` 的坏计算器上，我们可以执行以下两种操作：

- **双倍（Double）**：将显示屏上的数字乘以 2
- **减一（Decrement）**：将显示屏上的数字减 1

给定两个整数 `startValue` 和 `target`。返回使用上述操作从 `startValue` 得到 `target` 所需的最小操作数。

**示例 1：**

```
输入：startValue = 2, target = 3
输出：2
解释：先进行双倍操作得到 4，然后减一得到 3
```

**示例 2：**

```
输入：startValue = 5, target = 8
输出：2
解释：先减一得到 4，然后双倍得到 8
```

**示例 3：**

```
输入：startValue = 3, target = 10
输出：3
解释：先双倍得到 6，再双倍得到 12，最后减一两次得到 10
```

**提示：**

- `1 <= startValue, target <= 10^9`

## 解题思路

这道题的关键是**逆向思考**。

**为什么要逆向？**

如果正向思考（从 startValue 到 target），我们有两个选择：乘 2 或减 1。这样会产生大量的分支，难以找到最优解。

但如果**逆向思考**（从 target 到 startValue），我们的操作变成：
- 除以 2（对应正向的乘 2）
- 加 1（对应正向的减 1）

**贪心策略：**

从 target 逆推到 startValue：
1. 如果 target <= startValue，只能一直加 1（正向是减 1）
2. 如果 target 是偶数，除以 2 一定比加 1 更优
3. 如果 target 是奇数，必须先加 1 变成偶数，然后除以 2

**为什么这样是最优的？**

- 除以 2 比加 1 更快地缩小差距
- 奇数无法除以 2，所以加 1 变偶数是唯一选择
- 当 target <= startValue 时，无法再除以 2，只能加 1

## Python 代码实现

### 方法一：逆向贪心（推荐）⭐

```python
class Solution:
    def brokenCalc(self, startValue: int, target: int) -> int:
        """
        从 target 逆推到 startValue
        时间复杂度：O(log target)
        空间复杂度：O(1)
        """
        operations = 0
        
        # 从 target 逆推到 startValue
        while target > startValue:
            if target % 2 == 0:
                # target 是偶数，除以 2
                target //= 2
            else:
                # target 是奇数，加 1（正向是减 1）
                target += 1
            operations += 1
        
        # 如果 target < startValue，需要加 (startValue - target) 次
        operations += startValue - target
        
        return operations
```

### 方法二：简化写法

```python
class Solution:
    def brokenCalc(self, startValue: int, target: int) -> int:
        """
        更简洁的写法
        """
        operations = 0
        
        while target > startValue:
            operations += 1
            if target % 2 == 1:
                target += 1
            else:
                target //= 2
        
        return operations + startValue - target
```

### 方法三：位运算优化

```python
class Solution:
    def brokenCalc(self, startValue: int, target: int) -> int:
        """
        使用位运算判断奇偶性
        """
        operations = 0
        
        while target > startValue:
            if target & 1:  # 奇数（最低位为 1）
                target += 1
            else:  # 偶数
                target >>= 1  # 右移 1 位相当于除以 2
            operations += 1
        
        return operations + startValue - target
```

### 方法四：递归写法（教学用）

```python
class Solution:
    def brokenCalc(self, startValue: int, target: int) -> int:
        """
        递归写法（不推荐，仅用于理解）
        """
        # 基础情况
        if startValue >= target:
            return startValue - target
        
        # 如果 target 是偶数，除以 2
        if target % 2 == 0:
            return 1 + self.brokenCalc(startValue, target // 2)
        else:
            # 如果 target 是奇数，加 1
            return 1 + self.brokenCalc(startValue, target + 1)
```

## 复杂度分析

**方法一、二、三（推荐）：**
- 时间复杂度：O(log target)，每次除以 2，最多 log(target) 次
- 空间复杂度：O(1)

**方法四：**
- 时间复杂度：O(log target)
- 空间复杂度：O(log target)，递归栈深度

## 关键点总结

1. **逆向思考**：从 target 到 startValue 比从 startValue 到 target 简单得多
2. **贪心选择**：偶数必除以 2，奇数必加 1
3. **边界处理**：当 target <= startValue 时，只能加（正向减）
4. **数学本质**：这是一个数学问题，不是搜索问题
5. **位运算优化**：`target & 1` 判断奇偶，`target >>= 1` 除以 2

## 易错点

1. **正向思考陷阱**：正向思考会导致复杂的分支判断
2. **忘记最后的加法**：当 target < startValue 时，需要加上 `startValue - target`
3. **奇偶判断**：必须先判断奇偶，再决定操作
4. **边界条件**：startValue == target 时，返回 0

## 图解示例

以 `startValue = 5, target = 8` 为例：

**正向思考（复杂）：**
```
5 → 10 (×2) → 9 (-1) → 8 (-1)  3步
5 → 4 (-1) → 8 (×2)             2步 ✓
```

**逆向思考（简单）：**
```
8 → 4 (÷2)  因为8是偶数
4 ← 5       差1，需要加1次（正向减1）
总共：1 + 1 = 2步
```

再看 `startValue = 3, target = 10`：

```
逆向：
10 → 5 (÷2)   偶数，除以2
5 → 6 (+1)    奇数，加1
6 → 3 (÷2)    偶数，除以2
3 = 3         到达目标
总共：3步
```

**数学证明：**

为什么逆向贪心是最优的？

1. **偶数除以 2**：假设 target 是偶数，如果先加 1，得到 target+1（奇数），然后必须再加 1 得到 target+2，再除以 2 得到 (target+2)/2。这需要 3 步才能到达 (target+2)/2。而直接除以 2 到 target/2 只需 1 步，显然后者更优。

2. **奇数加 1**：奇数无法除以 2，所以加 1 是唯一选择。

3. **target <= startValue**：无法除以 2 使其更小，只能加。
