## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，请你找到**最左边**的中间位置 `middleIndex`（下标从 0 开始）。

中间位置定义：`middleIndex` 左侧所有元素之和等于右侧所有元素之和。若 `middleIndex` 在最左边，则左侧之和视为 0；若在最右边，则右侧之和视为 0。

若找不到返回 `-1`，否则返回最左边的中间位置下标。

**示例 1：**
```
输入：nums = [2,3,-1,8,4]
输出：3
解释：nums[3]=8，左边之和=2+3+(-1)=4，右边之和=4
```

**示例 2：**
```
输入：nums = [1,-1,4]
输出：2
```

**提示：**
- `1 <= nums.length <= 100`
- `-1000 <= nums[i] <= 1000`

---

## 解题思路

### 核心思想：前缀和

计算总和 `total`，从左向右扫描，维护左侧前缀和 `left_sum`，判断 `left_sum == total - left_sum - nums[i]`。

---

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def findMiddleIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left_sum = 0

        for i, x in enumerate(nums):
            # 右侧和 = total - left_sum - nums[i]
            if left_sum == total - left_sum - x:
                return i
            left_sum += x

        return -1
```

### 方法二：前缀和数组

```python
from typing import List

class Solution:
    def findMiddleIndex(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        total = prefix[n]
        for i in range(n):
            left = prefix[i]
            right = total - prefix[i + 1]
            if left == right:
                return i

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(1) |
| 方法二 | O(n) | O(n) |

---

## 关键点总结

1. 左侧和 + 当前值 + 右侧和 = 总和
2. 条件：`left_sum == total - left_sum - nums[i]`，即 `2 * left_sum + nums[i] == total`
3. 从左到右找最左边满足条件的位置

---

## 易错点

- 下标从 0 开始，最左端左侧和为 0（空集）
- 注意判断后再更新 `left_sum`，不要先更新
