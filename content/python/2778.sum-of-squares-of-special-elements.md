## 题目描述

给你一个下标从 **1** 开始的整数数组 `nums`，长度为 `n`。

如果位置 `i`（`1 <= i <= n`）满足 `n % i == 0`，则称 `nums[i]` 为 **特殊元素**。

返回所有特殊元素的平方和。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：21
解释：n=4，整除4的i：1,2,4，特殊元素 nums[1]=1, nums[2]=2, nums[4]=4，平方和 1+4+16=21
```

**示例 2：**
```
输入：nums = [2,7,1,19,18,3]
输出：63
```

**提示：**
- `1 <= nums.length <= 50`

## 解题思路

枚举所有 `i`（1-indexed），若 `n % i == 0` 则将 `nums[i-1]^2` 加入答案。

## Python 代码实现

### 方法一：枚举（推荐）

```python
from typing import List

class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:
        n = len(nums)
        # 注意 nums 是 1-indexed，但 Python 数组是 0-indexed
        return sum(nums[i - 1] ** 2 for i in range(1, n + 1) if n % i == 0)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 下标从 1 开始，检查 `n % i == 0`
2. Python 数组下标需要 `-1` 转换

## 易错点

1. 注意题目是 1-indexed（`i` 从 1 到 n），但 Python 列表是 0-indexed
