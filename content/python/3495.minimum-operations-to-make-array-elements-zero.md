## 题目描述

给你一个二维整数数组 `queries`，其中 `queries[i] = [l, r]`。

对于每个查询，你需要将区间 [l, r] 内所有数字变为 0。

每次操作可以选择任意整数 x，将 x 变为 `floor(x / 2)`（向下取整）。

返回每个查询所需的最少操作总数。

**示例：**

```
输入：queries = [[1,4],[2,6]]
输出：[4,7]
解释：
查询[1,4]：1->0(1次),2->0(2次),3->0(2次),4->0(3次) 但实际...
```

**提示：**
- `1 <= queries.length <= 10^5`
- `queries[i].length == 2`
- `1 <= l <= r <= 10^6`

## 解题思路

将 x 变为 0 需要的操作次数 = `floor(log2(x)) + 1`（即 x 的二进制长度）。

例如：1->0: 1次，2->1->0: 2次，3->1->0: 2次，4->2->1->0: 3次。

预处理每个数字到 0 的操作次数，用前缀和快速计算区间总操作数。

注意：`floor(log2(x)) + 1 = len(bin(x)) - 2`（Python 中）。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List
import math

class Solution:
    def minOperations(self, queries: List[List[int]]) -> List[int]:
        # 每个数 x 变为 0 的操作次数 = x 的二进制长度
        # ops(x) = floor(log2(x)) + 1 for x >= 1, ops(0) = 0
        MAX_VAL = 10 ** 6 + 1

        ops = [0] * MAX_VAL
        for x in range(1, MAX_VAL):
            ops[x] = x.bit_length()  # floor(log2(x)) + 1

        # 前缀和
        prefix = [0] * MAX_VAL
        for x in range(1, MAX_VAL):
            prefix[x] = prefix[x - 1] + ops[x]

        result = []
        for l, r in queries:
            result.append(prefix[r] - prefix[l - 1])

        return result
```

### 方法二：分段计算（利用 bit_length 规律）

```python
from typing import List

class Solution:
    def minOperations(self, queries: List[List[int]]) -> List[int]:
        # bit_length 为 k 的数范围：[2^(k-1), 2^k - 1]
        # 每个这样的数需要 k 次操作

        def range_ops(l, r):
            """计算 [l, r] 的总操作数"""
            if l > r:
                return 0
            total = 0
            k = 1
            lo, hi = 1, 1
            while lo <= r:
                hi = (1 << k) - 1  # 2^k - 1
                # [lo, hi] 内的数 bit_length 为 k
                a = max(l, lo)
                b = min(r, hi)
                if a <= b:
                    total += k * (b - a + 1)
                lo = hi + 1
                k += 1
            return total

        return [range_ops(l, r) for l, r in queries]
```

### 方法三：位运算优化

```python
from typing import List

class Solution:
    def minOperations(self, queries: List[List[int]]) -> List[int]:
        MAX = 10 ** 6

        # 构建前缀和（bit_length）
        prefix = [0] * (MAX + 2)
        for x in range(1, MAX + 1):
            prefix[x] = prefix[x - 1] + x.bit_length()

        return [prefix[r] - prefix[l - 1] for l, r in queries]
```

## 复杂度分析

- 时间复杂度：O(M + q)，M 为值域大小，q 为查询数量
- 空间复杂度：O(M)

## 关键点总结

1. x -> 0 的操作次数 = x 的二进制位数 = `x.bit_length()`
2. 前缀和预处理，O(1) 回答区间查询
3. Python 内置的 `bit_length()` 方法直接计算二进制长度

## 易错点

1. `bit_length()` 对 0 返回 0，对正整数返回 floor(log2(x)) + 1
2. 前缀和范围要覆盖 r 的最大值
3. 区间求和 = prefix[r] - prefix[l-1]（包含 l 和 r）
