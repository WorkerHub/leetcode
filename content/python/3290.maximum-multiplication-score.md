## 题目描述

给你一个长度为 4 的整数数组 `a` 和一个整数数组 `b`（长度至少为 4）。

从 `b` 中选 4 个下标 `i0 < i1 < i2 < i3`，计算 `a[0] * b[i0] + a[1] * b[i1] + a[2] * b[i2] + a[3] * b[i3]`。

返回该表达式的**最大值**。

**示例 1：**
```
输入：a = [3,2,5,6], b = [2,-6,4,-5,-3,2,-7]
输出：26
```

**示例 2：**
```
输入：a = [-1,4,5,-2], b = [-5,-1,-3,-2,-4]
输出：-1
```

**提示：**
- `b.length >= 4`
- `-10^5 <= a[i], b[j] <= 10^5`

## 解题思路

动态规划：`dp[j][k]` = 从 `b[0..j]` 中选了第 `k` 个（0-indexed）b 元素时的最大值。

`dp[k]` = 已选了 k 个 b 元素的最大乘积和。

转移：`dp[k] = max(dp[k], dp[k-1] + a[k-1] * b[j])`（选 b[j] 作为第 k 个选择）。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, a: List[int], b: List[int]) -> int:
        # dp[k] = 已从 b 中选了 k 个，最大乘积和
        INF = float('-inf')
        dp = [INF] * 5
        dp[0] = 0
        
        for bj in b:
            # 从后往前更新，避免同一个 bj 被选两次
            for k in range(3, -1, -1):
                if dp[k] != INF:
                    val = dp[k] + a[k] * bj
                    if val > dp[k + 1]:
                        dp[k + 1] = val
        
        return dp[4]
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxScore(self, a: List[int], b: List[int]) -> int:
        n = len(b)
        
        @lru_cache(maxsize=None)
        def dp(j, k):
            # 从 b[j..] 中选剩余 4-k 个，已选 k 个
            if k == 4:
                return 0
            if j == n:
                return float('-inf')
            # 选 b[j]
            take = a[k] * b[j] + dp(j + 1, k + 1)
            # 不选 b[j]
            skip = dp(j + 1, k)
            return max(take, skip)
        
        return dp(0, 0)
```

## 复杂度分析

- 时间复杂度：O(4 * n) = O(n)
- 空间复杂度：O(1)（方法一）或 O(4n)（方法二）

## 关键点总结

1. 固定选 4 个，从后往前更新 DP 避免重复
2. dp[k] 表示已选了 k 个的最大值（0-indexed）
3. 只需遍历一次 b 数组

## 易错点

1. 更新顺序要从后往前（k 从大到小），避免同一 b[j] 被选多次
2. 初始 dp[0] = 0，其余为负无穷
