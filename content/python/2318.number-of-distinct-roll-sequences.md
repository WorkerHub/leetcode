## 题目描述

给你一个整数 `n`，返回掷骰子 `n` 次后，得到的**不同**骰子序列的数量（**模** `10^9 + 7`）。

两个序列不同是指至少有一个位置的值不同。

骰子的值为 1 到 6，且满足以下约束：
- 每次骰子的值不能与**上一次相同**。
- 每次骰子的值不能与**上上次相同**（若存在）。
- 骰子的 GCD（最大公因数）必须为 1（即相邻两次值互质）。

**示例 1：**
```
输入：n = 4
输出：184
```

**示例 2：**
```
输入：n = 2
输出：22
```

**提示：**
- `1 <= n <= 10^4`

## 解题思路

**动态规划：**
定义 `dp[i][prev][pprev]` 为第 `i` 次骰子，上一次为 `prev`，上上次为 `pprev` 时的序列数。

但三维状态太复杂，由于骰子值为 1-6，可以定义 `dp[prev][pprev]` 为当前步中，上一次为 `prev`、上上次为 `pprev` 时的方案数，滚动更新。

**状态转移：**
新掷出值 `cur` 需满足：
1. `cur != prev`
2. `cur != pprev`（若存在）
3. `gcd(cur, prev) == 1`

## 代码实现

### 方法一：滚动 DP（推荐）

```python
from math import gcd

class Solution:
    def distinctSequences(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        faces = range(1, 7)
        
        # dp[prev][pprev]: 上一次为 prev，上上次为 pprev 的方案数
        # pprev = 0 表示不存在上上次
        dp = [[0] * 7 for _ in range(7)]
        
        # 初始化：第一次可以是 1-6 中任意值
        for f in faces:
            dp[f][0] = 1
        
        for _ in range(n - 1):
            new_dp = [[0] * 7 for _ in range(7)]
            for prev in range(1, 7):
                for pprev in range(7):
                    if dp[prev][pprev] == 0:
                        continue
                    for cur in faces:
                        # 约束条件
                        if cur == prev:
                            continue
                        if cur == pprev:
                            continue
                        if gcd(cur, prev) != 1:
                            continue
                        new_dp[cur][prev] = (new_dp[cur][prev] + dp[prev][pprev]) % MOD
            dp = new_dp
        
        ans = 0
        for prev in range(1, 7):
            for pprev in range(7):
                ans = (ans + dp[prev][pprev]) % MOD
        return ans
```

### 方法二：记忆化搜索

```python
from math import gcd
from functools import lru_cache

class Solution:
    def distinctSequences(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        faces = range(1, 7)

        @lru_cache(maxsize=None)
        def dp(step, prev, pprev):
            # step: 还剩多少步，prev: 上次值，pprev: 上上次值(0表示无)
            if step == 0:
                return 1
            ans = 0
            for cur in faces:
                if cur == prev or cur == pprev:
                    continue
                if gcd(cur, prev) != 1:
                    continue
                ans = (ans + dp(step - 1, cur, prev)) % MOD
            return ans

        # 第一次可以是任意值
        ans = 0
        for first in faces:
            ans = (ans + dp(n - 1, first, 0)) % MOD
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滚动 DP | O(n * 6^2 * 6) = O(n) | O(6^2) |
| 记忆化搜索 | O(n * 6 * 7 * 6) | O(n * 6 * 7) |

## 关键点总结

1. 三个约束：不等于上一个、不等于上上个、与上一个互质。
2. 由于 6*6 = 36 个状态，每步只有常数个转移，整体是 O(n)。
3. 使用滚动数组将空间从 O(n) 降至 O(1)（不含缓存）。

## 易错点

- 互质条件是与**上一次**互质，不是与上上次。
- `pprev = 0` 表示没有上上次，需要特殊处理（0 不等于任何骰子值，所以约束 `cur != pprev` 在 pprev=0 时恒成立）。
