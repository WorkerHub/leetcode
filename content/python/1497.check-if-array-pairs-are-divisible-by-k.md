## 题目描述

给你一个整数数组 `arr` 和一个整数 `k`，其中 `arr` 的长度是**偶数**。

请你判断能否将数组中的所有元素配对，且**每对元素的和**都能被 `k` 整除。

若可以，请返回 `True`；否则，返回 `False`。

**示例 1：**

```
输入：arr = [1,2,3,4,5,10,6,7,8,9], k = 5
输出：true
解释：配对 (1,9),(2,8),(3,7),(4,6),(5,10)，每对和分别是 10,10,10,10,15，均可被 5 整除。
```

**示例 2：**

```
输入：arr = [1,2,3,4,5,6], k = 7
输出：true
解释：配对 (1,6),(2,5),(3,4)，和为 7,7,7，均可被 7 整除。
```

**示例 3：**

```
输入：arr = [1,2,3,4,5,6], k = 10
输出：false
解释：没有任何一种配对方式使所有对的和能被 10 整除。
```

**提示：**

- `arr.length == 2 * n`，`1 <= n <= 10^5`
- `1 <= k <= 10^5`
- `-10^9 <= arr[i] <= 10^9`

## 解题思路

**核心思想：余数互补配对**

若两个数 `a + b` 能被 `k` 整除，则 `(a % k + b % k) % k == 0`。

设 `r = a % k`（取非负余数），则 `b` 的余数必须为 `(k - r) % k`（注意 `r=0` 时，互补余数也是 0）。

**算法：**

1. 统计每个余数的出现次数（注意处理负数取模）。
2. 检查：
   - 余数为 0 的数必须是偶数个（自己和自己配对）。
   - 对于余数 `r`（1 <= r < k/2），余数 `r` 的数量必须等于余数 `k-r` 的数量。
   - 若 k 为偶数，余数为 `k/2` 的数也必须是偶数个（自己和自己配对）。

**负数取模的处理：**

Python 中，`-1 % 5 == 4`（Python 的取模结果符号与除数相同），因此 Python 的 `%` 运算已经保证了非负余数，无需特殊处理。但在其他语言（如 C++/Java）中，`-1 % 5 == -1`，需要加 k 再取模。

## Python 代码实现

### 方法一：余数统计 + 互补验证（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def canArrange(self, arr: List[int], k: int) -> bool:
        # 统计每个余数的频率
        # Python 的 % 返回非负余数（-1 % 5 = 4）
        remainder_count = defaultdict(int)
        for num in arr:
            r = num % k
            remainder_count[r] += 1

        # 检查余数为 0 的数量是否为偶数（必须两两配对）
        if remainder_count[0] % 2 != 0:
            return False

        # 检查余数 r 和余数 k-r 的数量是否相等
        for r in range(1, k // 2 + 1):
            if remainder_count[r] != remainder_count[k - r]:
                return False

        # 若 k 为偶数，余数为 k//2 的数量必须是偶数（因为 k-k//2 == k//2）
        # 注意：上面循环中 r == k//2 时，k-r == k//2，即自己和自己比较
        # remainder_count[k//2] == remainder_count[k//2] 恒成立，
        # 但必须额外判断其数量为偶数！上面的循环漏掉了这个判断。
        # 修正：k 为偶数时，单独检查余数 k//2
        if k % 2 == 0 and remainder_count[k // 2] % 2 != 0:
            return False

        return True
```

### 方法二：更简洁的循环（分情况讨论）

```python
from typing import List
from collections import Counter

class Solution:
    def canArrange(self, arr: List[int], k: int) -> bool:
        # 统计余数频率
        count = Counter(num % k for num in arr)

        for r in range(k):
            if r == 0:
                # 余数为 0 的数量必须为偶数
                if count[0] % 2 != 0:
                    return False
            elif r * 2 == k:
                # k 为偶数，余数恰好为 k/2 的数量必须为偶数
                if count[r] % 2 != 0:
                    return False
            elif r < k - r:
                # 互补余数数量必须相等，只遍历 r < k-r 的部分，避免重复
                if count[r] != count[k - r]:
                    return False

        return True
```

### 方法三：排序 + 双指针

```python
from typing import List

class Solution:
    def canArrange(self, arr: List[int], k: int) -> bool:
        # 按余数排序
        arr.sort(key=lambda x: x % k)

        # 双指针：左右指针向中间靠拢
        left, right = 0, len(arr) - 1

        while left < right:
            # 计算两端数的余数之和
            sum_rem = (arr[left] % k + arr[right] % k) % k
            if sum_rem != 0:
                return False
            left += 1
            right -= 1

        return True
```

### 方法四：哈希表 + 原地消除

```python
from typing import List
from collections import defaultdict

class Solution:
    def canArrange(self, arr: List[int], k: int) -> bool:
        freq = defaultdict(int)

        # 统计每个余数的需求
        for num in arr:
            r = num % k
            # 检查是否存在配对
            complement = (k - r) % k
            if freq[complement] > 0:
                # 找到配对，消除
                freq[complement] -= 1
            else:
                # 记录当前余数等待配对
                freq[r] += 1

        # 若所有余数都被消除，返回 True
        return all(v == 0 for v in freq.values())
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（推荐） | O(n + k) | O(k) |
| 方法二 | O(n + k) | O(k) |
| 方法三（排序） | O(n log n) | O(1) |
| 方法四（哈希） | O(n) | O(k) |

- 方法一/二/四 均为 O(n)，推荐
- 方法三排序略慢，但思路清晰

## 关键点总结

1. **余数互补**：`a + b` 能被 `k` 整除，当且仅当 `(a%k + b%k) % k == 0`，即余数互补。
2. **特殊情况**：
   - 余数 0：只能与余数 0 配对，数量必须为偶数。
   - 余数 k/2（k 为偶数）：只能与余数 k/2 配对，数量必须为偶数。
3. **Python 负数取模**：`(-1) % 5 == 4`，Python 保证结果非负，无需额外处理。
4. **只检查 r < k-r 的部分**：避免重复验证（r 和 k-r 是同一对，只需检查一次）。

## 易错点

- **负数余数**：C++/Java 中 `-7 % 5 == -2`，需要加 k 再取模：`(-7 % k + k) % k`。Python 中不需要。
- **k 为偶数时的 k/2 特判**：方法一的循环 `range(1, k//2+1)` 包含了 `r == k//2`，此时 `k-r == r`，`remainder_count[r] == remainder_count[r]` 恒成立，但没有检查数量是否为偶数，需要额外判断。
- **k=1 的情况**：所有数余数都是 0，数量为偶数（题目保证数组长度为偶数），可以配对。
