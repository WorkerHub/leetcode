## 题目描述

单词的**缩写**需要遵循 `<起始字母><省略字母的数量><结尾字母>` 这样的格式。

以下是一些单词缩写的范例：

```
a) it                      --> it    (没有缩写)
     1
b) d|o|g                   --> d1g
              1    1  1
     1---5----0----5--8
c) i|nternationalizatio|n  --> i18n
              1
     1---5----0
d) l|ocalizatio|n          --> l10n
```

假设你有一个字典和一个单词，请你判断该单词的**所有可能的缩写**。

返回答案时，你的答案需要按字典序排序。

**示例 1：**
```
输入：word = "word"
输出：["4","3d","2r1","2rd","1o2","1o1d","1or1","1ord","w3","w2d","w1r1","w1rd","wo2","wo1d","wor1","word"]
```

**示例 2：**
```
输入：word = "a"
输出：["1","a"]
```

**提示：**
- `1 <= word.length <= 15`
- `word` 仅由小写英文字母组成

## 解题思路

每个字符有两种选择：
1. **保留**：直接加入结果
2. **缩写**：计数，连续缩写的字符合并为一个数字

这是一个典型的**回溯**问题，也可以用**位运算**枚举。

### 方法对比

| 方法 | 说明 | 时间复杂度 |
|------|------|-----------|
| 回溯 | DFS遍历所有可能 | O(2^n × n) |
| 位运算 | 枚举所有子集 | O(2^n × n) |

## Python 代码实现

### 方法一：回溯（推荐）⭐

```python
from typing import List

class Solution:
    def generateAbbreviations(self, word: str) -> List[str]:
        result = []
        
        def backtrack(pos: int, path: str, count: int):
            """
            pos: 当前处理的位置
            path: 当前构建的缩写
            count: 当前连续缩写的字符数
            """
            if pos == len(word):
                # 如果还有未添加的计数，加上
                result.append(path + (str(count) if count > 0 else ''))
                return
            
            # 选择1：缩写当前字符
            backtrack(pos + 1, path, count + 1)
            
            # 选择2：保留当前字符
            # 先加上之前的计数（如果有），再加当前字符
            new_path = path + (str(count) if count > 0 else '') + word[pos]
            backtrack(pos + 1, new_path, 0)
        
        backtrack(0, '', 0)
        return result
```

### 方法二：位运算

```python
from typing import List

class Solution:
    def generateAbbreviations(self, word: str) -> List[str]:
        n = len(word)
        result = []
        
        # 枚举所有可能的掩码
        for mask in range(1 << n):
            abbr = []
            count = 0
            
            for i in range(n):
                # 第 i 位为 1：缩写
                if mask & (1 << i):
                    count += 1
                # 第 i 位为 0：保留
                else:
                    if count > 0:
                        abbr.append(str(count))
                        count = 0
                    abbr.append(word[i])
            
            # 最后可能还有计数
            if count > 0:
                abbr.append(str(count))
            
            result.append(''.join(abbr))
        
        return result
```

### 方法三：带详细注释的回溯

```python
from typing import List

class Solution:
    def generateAbbreviations(self, word: str) -> List[str]:
        """
        回溯生成所有缩写
        
        核心思想：
        - 每个字符有两种选择：保留 或 缩写
        - 连续缩写的字符计数合并
        
        例如 "word":
        - 全保留: "word"
        - 全缩写: "4"
        - 部分: "w3", "w2d", "1ord", ...
        """
        result = []
        
        def dfs(index: int, current: str, abbr_count: int):
            """
            index: 当前处理的字符位置
            current: 当前已构建的字符串
            abbr_count: 当前连续缩写的字符数
            """
            # 递归终止：处理完所有字符
            if index == len(word):
                # 如果还有未写入的缩写计数，加上
                if abbr_count > 0:
                    current += str(abbr_count)
                result.append(current)
                return
            
            # 选择1：缩写当前字符
            # 计数加1，字符串不变
            dfs(index + 1, current, abbr_count + 1)
            
            # 选择2：保留当前字符
            # 先写入之前的缩写计数（如果有），再加当前字符
            next_str = current
            if abbr_count > 0:
                next_str += str(abbr_count)
            next_str += word[index]
            
            dfs(index + 1, next_str, 0)
        
        dfs(0, '', 0)
        return result
```

### 方法四：位运算详细版

```python
from typing import List

class Solution:
    def generateAbbreviations(self, word: str) -> List[str]:
        n = len(word)
        result = []
        
        # 枚举 [0, 2^n) 的所有数字
        for mask in range(1 << n):
            abbr = []
            abbr_count = 0
            
            for i in range(n):
                # 检查第 i 位是否为 1
                if mask & (1 << i):
                    # 缩写第 i 个字符
                    abbr_count += 1
                else:
                    # 保留第 i 个字符
                    # 先加缩写计数（如果有）
                    if abbr_count > 0:
                        abbr.append(str(abbr_count))
                        abbr_count = 0
                    # 再加字符本身
                    abbr.append(word[i])
            
            # 处理剩余的缩写计数
            if abbr_count > 0:
                abbr.append(str(abbr_count))
            
            result.append(''.join(abbr))
        
        return result
```

## 复杂度分析

- 时间复杂度：O(2^n × n)，生成 2^n 个结果，每个需要 O(n) 构建
- 空间复杂度：O(2^n × n)，存储所有结果

## 关键点总结

1. **两种选择**：每个字符保留或缩写
2. **计数合并**：连续缩写的字符合并为一个数字
3. **回溯模板**：标准的决策树遍历
4. **位运算枚举**：用二进制表示所有可能
5. **注意计数**：递归结束时可能还有未写入的计数

## 易错点

1. **计数处理**：
   - 递归结束时要检查是否还有计数
   - 保留字符前要先写入计数
2. **位运算**：第 i 位对应第 i 个字符
3. **字符串拼接**：使用列表join效率更高
4. **边界情况**：空字符串、单字符
