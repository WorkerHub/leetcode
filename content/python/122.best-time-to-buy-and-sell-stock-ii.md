## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候最多只能持有一股股票。你也可以先购买，然后在同一天出售。

返回你能获得的最大利润。

**示例 1：**

```
输入：prices = [7,1,5,3,6,4]
输出：7
解释：在第 2 天（股票价格 = 1）的时候买入，在第 3 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4 。
     随后，在第 4 天（股票价格 = 3）的时候买入，在第 5 天（股票价格 = 6）的时候卖出, 这笔交易所能获得利润 = 6 - 3 = 3 。
     总利润为 4 + 3 = 7 。
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：4
解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天 （股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4 。
     总利润为 4 。
```

**示例 3：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 交易无法获得正利润，所以不参与交易可以获得最大利润，最大利润为 0 。
```

**提示：**

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 解题思路

这道题是 [121. 买卖股票的最佳时机](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) 的进阶版本，允许进行多次交易。

**核心思想：**

1. **贪心策略**：只要今天价格比昨天高，就在昨天买入今天卖出
2. **累加所有上涨利润**：将所有上涨区间的利润累加
3. **动态规划**：定义持有/不持有股票的状态

**关键观察：**

- 可以进行无限次交易，所以可以把握每一次上涨机会
- 连续上涨时，可以分多次交易，总利润 = 最高点 - 最低点
- 例如：1 -> 2 -> 3，可以 (3-1) 也可以 (2-1)+(3-2)，结果相同

## Python 代码实现

### 方法一：贪心算法（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        profit = 0
        
        # 只要今天价格比昨天高，就进行交易
        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]
        
        return profit
```

### 方法二：贪心算法（简化版）

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        return sum(max(0, prices[i] - prices[i-1]) for i in range(1, len(prices)))
```

### 方法三：动态规划

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0
        
        # dp[i][0] 表示第 i 天不持有股票的最大利润
        # dp[i][1] 表示第 i 天持有股票的最大利润
        dp = [[0, 0] for _ in range(n)]
        
        # 初始化
        dp[0][0] = 0              # 第 0 天不持有
        dp[0][1] = -prices[0]     # 第 0 天持有
        
        for i in range(1, n):
            # 不持有：昨天不持有 或 今天卖出
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            # 持有：昨天持有 或 今天买入（可以多次交易，所以基于昨天不持有的利润）
            dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
        
        return dp[n-1][0]
```

### 方法四：动态规划 + 空间优化

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 不持有股票的最大利润
        not_hold = 0
        # 持有股票的最大利润
        hold = -prices[0]
        
        for i in range(1, len(prices)):
            # 先保存旧值
            new_not_hold = max(not_hold, hold + prices[i])
            new_hold = max(hold, not_hold - prices[i])
            
            not_hold = new_not_hold
            hold = new_hold
        
        return not_hold
```

### 方法五：找波峰波谷

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if len(prices) <= 1:
            return 0
        
        profit = 0
        i = 0
        n = len(prices)
        
        while i < n - 1:
            # 找到波谷（局部最小值）
            while i < n - 1 and prices[i] >= prices[i + 1]:
                i += 1
            valley = prices[i]
            
            # 找到波峰（局部最大值）
            while i < n - 1 and prices[i] <= prices[i + 1]:
                i += 1
            peak = prices[i]
            
            # 累加利润
            profit += peak - valley
        
        return profit
```

## 复杂度分析

**方法一、二：贪心算法**
- 时间复杂度：O(n)，只需要遍历一次数组
- 空间复杂度：O(1)，只使用常量额外空间

**方法三：动态规划**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法四：DP + 空间优化**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法五：波峰波谷**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **贪心本质**：累加所有上涨区间的利润
2. **多次交易**：可以在同一天买入卖出，相当于不操作
3. **状态转移差异**：与 121 题的区别在于买入时基于 `dp[i-1][0]` 而不是 0
4. **等价性**：连续上涨时，分多次交易和一次交易利润相同
5. **简洁实现**：贪心算法代码最简洁，效率最高

## 易错点

1. **理解多次交易**：可以进行无限次交易，但同时最多持有一股
2. **贪心正确性**：要理解为什么累加所有上涨利润是正确的
3. **DP 状态转移**：买入时是 `dp[i-1][0] - prices[i]` 而不是 `-prices[i]`
4. **边界条件**：只有一天时，无法交易，返回 0
5. **价格下跌**：下跌时不操作，利润为 0

## 图解示例

```
prices = [7, 1, 5, 3, 6, 4]

价格变化：
7 -> 1: 下跌，不操作
1 -> 5: 上涨，买入 1 卖出 5，利润 = 4
5 -> 3: 下跌，不操作
3 -> 6: 上涨，买入 3 卖出 6，利润 = 3
6 -> 4: 下跌，不操作

总利润 = 4 + 3 = 7

等价于：
差价累加：(5-1) + (6-3) = 4 + 3 = 7
```

## 为什么贪心算法是正确的？

```
连续上涨的情况：
prices = [1, 2, 3, 4, 5]

方案一：一次交易
买入 1，卖出 5，利润 = 5 - 1 = 4

方案二：多次交易
(2-1) + (3-2) + (4-3) + (5-4) = 1 + 1 + 1 + 1 = 4

两种方案利润相同！

数学证明：
(b-a) + (c-b) + (d-c) = d - a

所以，可以把每一次上涨都当作一次交易来累加。
```

## 与 121 题的对比

| 特性 | 121 题 | 122 题 |
|------|--------|--------|
| 交易次数 | 最多 1 次 | 无限次 |
| 贪心策略 | 找最低点买入，最高点卖出 | 累加所有上涨利润 |
| DP 买入状态 | `dp[i][1] = max(dp[i-1][1], -prices[i])` | `dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])` |
| 最优解法 | 一次遍历 | 贪心算法 |
