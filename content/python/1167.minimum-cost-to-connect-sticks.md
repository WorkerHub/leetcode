## 题目描述

你有一些长度为正整数的木棍，这些长度以数组 `sticks` 的形式给出，其中 `sticks[i]` 是第 `i` 根木棍的长度。

你可以通过支付 `x + y` 的成本将任意两根长度为 `x` 和 `y` 的木棍连接成一根木棍。你必须连接所有的木棍，直到剩下一根木棍。

返回以这种方式将所有给定的木棍连接成一根木棍的最小成本。

示例 1：

```
输入：sticks = [2,4,3]
输出：14
解释：从 sticks = [2,4,3] 开始。
1. 连接 2 和 3，成本为 2 + 3 = 5。现在 sticks = [5,4]。
2. 连接 5 和 4，成本为 5 + 4 = 9。现在 sticks = [9]。
所有木棍已经连接成一根，总成本为 5 + 9 = 14。
```

示例 2：

```
输入：sticks = [1,8,3,5]
输出：30
解释：从 sticks = [1,8,3,5] 开始。
1. 连接 1 和 3，成本为 1 + 3 = 4。现在 sticks = [4,8,5]。
2. 连接 4 和 5，成本为 4 + 5 = 9。现在 sticks = [9,8]。
3. 连接 9 和 8，成本为 9 + 8 = 17。现在 sticks = [17]。
总成本为 4 + 9 + 17 = 30。
```

示例 3：

```
输入：sticks = [5]
输出：0
解释：只有一根木棍，不需要连接，成本为 0。
```

提示：

- `1 <= sticks.length <= 10^4`
- `1 <= sticks[i] <= 10^4`

## 解题思路

这是一道经典的贪心算法问题，类似于哈夫曼编码的思想。

**核心观察：**

1. 每次连接两根木棍的成本是它们长度之和
2. 连接后的木棍可能还会参与后续的连接
3. 较短的木棍应该先连接，这样它们的长度被累加的次数更少

**贪心策略：**

每次选择两根最短的木棍进行连接，这样可以保证总成本最小。

**算法步骤：**

1. 使用最小堆存储所有木棍长度
2. 每次从堆中取出两根最短的木棍
3. 计算连接成本并累加
4. 将连接后的木棍放回堆中
5. 重复直到只剩一根木棍

## Python 代码实现

### 方法一：最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def connectSticks(self, sticks: List[int]) -> int:
        """
        使用最小堆贪心选择最短的木棍
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        # 边界情况：只有一根木棍
        if len(sticks) <= 1:
            return 0
        
        # 构建最小堆
        heapq.heapify(sticks)
        
        total_cost = 0
        
        # 每次取出两根最短的木棍
        while len(sticks) > 1:
            # 取出两根最短的
            first = heapq.heappop(sticks)
            second = heapq.heappop(sticks)
            
            # 计算连接成本
            cost = first + second
            total_cost += cost
            
            # 将连接后的木棍放回堆中
            heapq.heappush(sticks, cost)
        
        return total_cost
```

### 方法二：简化版最小堆

```python
from typing import List
import heapq

class Solution:
    def connectSticks(self, sticks: List[int]) -> int:
        """简化代码，逻辑更清晰"""
        if len(sticks) <= 1:
            return 0
        
        heapq.heapify(sticks)
        cost = 0
        
        while len(sticks) > 1:
            # 一次性取出两根并连接
            combined = heapq.heappop(sticks) + heapq.heappop(sticks)
            cost += combined
            heapq.heappush(sticks, combined)
        
        return cost
```

### 方法三：优先队列（等价实现）

```python
from typing import List
from queue import PriorityQueue

class Solution:
    def connectSticks(self, sticks: List[int]) -> int:
        """
        使用 PriorityQueue 替代 heapq
        """
        if len(sticks) <= 1:
            return 0
        
        pq = PriorityQueue()
        for stick in sticks:
            pq.put(stick)
        
        total_cost = 0
        while pq.qsize() > 1:
            first = pq.get()
            second = pq.get()
            cost = first + second
            total_cost += cost
            pq.put(cost)
        
        return total_cost
```

### 方法四：排序方法（会超时，仅供理解）

```python
from typing import List

class Solution:
    def connectSticks(self, sticks: List[int]) -> int:
        """
        暴力方法：每次排序找最小的两根
        
        时间复杂度：O(n^2 log n)
        会超时
        """
        if len(sticks) <= 1:
            return 0
        
        total_cost = 0
        
        while len(sticks) > 1:
            sticks.sort()
            first = sticks.pop(0)
            second = sticks.pop(0)
            cost = first + second
            total_cost += cost
            sticks.append(cost)
        
        return total_cost
```

## 复杂度分析

**方法一（最小堆）：**
- 时间复杂度：`O(n log n)`
  - 建堆：O(n)
  - n-1 次操作，每次 pop 和 push 都是 O(log n)
  - 总共：O(n) + O(n log n) = O(n log n)
- 空间复杂度：`O(n)`，堆的空间

**方法四（排序）：**
- 时间复杂度：`O(n^2 log n)`
  - n-1 次操作，每次排序 O(n log n)
  - 总共：O(n^2 log n)
- 空间复杂度：`O(1)`

堆方法明显更优。

## 关键点总结

1. **贪心策略**：每次选择最短的两根木棍连接，可以保证总成本最小

2. **哈夫曼编码思想**：这道题的本质就是哈夫曼树的构建过程

3. **最小堆优势**：可以高效地维护和获取最小元素

4. **成本累加**：连接后的木棍会参与后续连接，所以短的木棍要先连接

5. **边界处理**：只有一根木棍时，成本为 0

## 易错点

1. **忘记放回堆**：
   ```python
   # 错误：连接后没有放回堆
   cost = heappop(sticks) + heappop(sticks)
   total_cost += cost
   
   # 正确：要把连接后的木棍放回去
   heappush(sticks, cost)
   ```

2. **循环条件错误**：
   ```python
   # 错误：应该是大于 1
   while len(sticks) > 0:
   
   # 正确：剩一根就停止
   while len(sticks) > 1:
   ```

3. **边界情况遗漏**：
   ```python
   # 应该处理只有一根木棍的情况
   if len(sticks) <= 1:
       return 0
   ```

4. **成本计算错误**：
   ```python
   # 错误：只累加了连接的两根
   total_cost += first + second
   # 然后又：heappush(sticks, first + second)
   
   # 正确：计算一次即可
   cost = first + second
   total_cost += cost
   heappush(sticks, cost)
   ```

5. **使用最大堆**：Python 的 heapq 是最小堆，不要搞反了
