## 题目描述

给你一个整数数组 `nums`，请你找出 `nums` 所有**非空子集**的按位或运算的最大值，并返回按位或运算结果等于最大值的**子集数目**。

如果数组 `a` 可以由数组 `b` 删除一些（或不删除）元素后得到，则 `a` 是 `b` 的一个子集。

**示例 1：**
```
输入：nums = [3,1]
输出：2
解释：子集按位或最大值为 3，有两个子集：[3] 和 [3,1]
```

**示例 2：**
```
输入：nums = [2,2,2]
输出：7
解释：所有非空子集的按位或都为 2，共 7 个非空子集
```

**提示：**
- `1 <= nums.length <= 16`
- `1 <= nums[i] <= 10^5`

## 解题思路

- 所有元素的按位或就是最大可能值（因为只能通过 OR 增加位，不能减少）
- 枚举所有 `2^n - 1` 个非空子集，统计按位或等于最大值的子集数

由于 `n <= 16`，枚举 `2^16 = 65536` 个子集完全可行。

## 代码实现

### 方法一：位掩码枚举（推荐）

```python
from typing import List

class Solution:
    def countMaxOrSubsets(self, nums: List[int]) -> int:
        n = len(nums)
        # 计算最大按位或（所有元素 OR 的结果）
        max_or = 0
        for num in nums:
            max_or |= num

        count = 0
        # 枚举所有非空子集（掩码从 1 到 2^n - 1）
        for mask in range(1, 1 << n):
            cur_or = 0
            for i in range(n):
                if mask >> i & 1:
                    cur_or |= nums[i]
            if cur_or == max_or:
                count += 1

        return count
```

### 方法二：回溯（DFS）

```python
from typing import List

class Solution:
    def countMaxOrSubsets(self, nums: List[int]) -> int:
        # 最大按位或
        max_or = 0
        for num in nums:
            max_or |= num

        count = [0]

        def dfs(idx: int, cur: int):
            if idx == len(nums):
                if cur == max_or:
                    count[0] += 1
                return
            dfs(idx + 1, cur | nums[idx])  # 包含 nums[idx]
            dfs(idx + 1, cur)              # 不包含 nums[idx]

        dfs(0, 0)
        # 减去空集（cur = 0 且 max_or > 0 时不计）
        # 实际上 dfs 包含了空集（cur=0），但空集对应 max_or=0 才等，通常不等
        # 更安全：从 idx=0 开始，要求非空子集
        # 重新写确保非空
        count[0] = 0

        def dfs2(idx: int, cur: int, size: int):
            if idx == len(nums):
                if size > 0 and cur == max_or:
                    count[0] += 1
                return
            dfs2(idx + 1, cur | nums[idx], size + 1)
            dfs2(idx + 1, cur, size)

        dfs2(0, 0, 0)
        return count[0]
```

### 方法三：动态规划计数

```python
from typing import List
from collections import defaultdict

class Solution:
    def countMaxOrSubsets(self, nums: List[int]) -> int:
        # dp[v] = 按位或结果为 v 的非空子集数
        dp = defaultdict(int)

        for num in nums:
            # 新加入 num 后，每个旧子集可以加入 num 形成新子集
            new_dp = defaultdict(int)
            # 单独包含 num 的子集
            new_dp[num] += 1
            for v, cnt in dp.items():
                new_dp[v | num] += cnt  # 旧子集 + num
                new_dp[v] += cnt        # 旧子集不加 num

            dp = new_dp

        max_or = max(dp.keys())
        return dp[max_or]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 位掩码枚举 | O(2^n * n) | O(1) |
| 回溯 | O(2^n) | O(n) |
| DP 计数 | O(2^n * n)（最坏） | O(2^n) |

## 关键点总结

1. 最大按位或 = 所有元素的 OR（无法超过这个值）
2. `n <= 16` 使枚举所有子集可行
3. 回溯法代码简洁，每次选择包含或不包含当前元素

## 易错点

- 子集必须是非空的（跳过掩码为 0 的情况）
- 最大按位或是所有元素 OR 的结果，不需要单独分析
