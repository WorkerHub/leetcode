## 题目描述

给你一个在 X-Y 平面上的点构成的数据结构，你需要支持两种操作：

1. **`add(point)`**：向数据结构中添加一个新点 `point = [x, y]`（允许重复）
2. **`count(point)`**：统计以 `point` 为一个角点，在 X-Y 平面中**轴对齐**（即边平行于坐标轴）的正方形数目。如果正方形中有重复点，则每次出现都要单独计数。

**示例：**
```
输入：
["DetectSquares", "add", "add", "add", "count", "count", "add", "count"]
[[], [[3,10]], [[11,2]], [[3,2]], [[11,10]], [[14,8]], [[11,2]], [[11,10]]]
输出：
[null, null, null, null, 1, 0, null, 2]
```

**提示：**
- `point.length == 2`
- `0 <= x, y <= 1000`
- `add` 和 `count` 的调用次数 **总计** 不超过 5000 次

## 解题思路

对于 `count(point)` 查询，以 `point = (px, py)` 为一个角，正方形另一个对角点为 `(x, y)` 满足：
- `x != px`
- `|x - px| == |y - py|`（正方形边长相等）

枚举对角点 `(x, y)`，然后查找另外两个角点 `(px, y)` 和 `(x, py)` 是否存在。

**数据结构：**
- 用 `Counter` 记录每个点的出现次数
- 用集合记录所有不重复的点（用于枚举）

## 代码实现

### 方法一：哈希表枚举对角点（推荐）

```python
from collections import defaultdict, Counter

class DetectSquares:

    def __init__(self):
        self.point_count = Counter()  # 记录每个点的出现次数
        self.x_to_ys = defaultdict(set)  # 按 x 坐标索引所有 y 坐标

    def add(self, point: list) -> None:
        x, y = point
        self.point_count[(x, y)] += 1
        self.x_to_ys[x].add(y)

    def count(self, point: list) -> int:
        px, py = point
        result = 0

        # 枚举与 point 同 x 坐标的所有点 (px, y)
        for y in self.x_to_ys[px]:
            if y == py:
                continue  # 正方形边长必须大于0
            side = abs(y - py)  # 正方形边长

            # 枚举两种可能：对角点在左或在右
            for dx in (side, -side):
                x = px + dx
                # 需要存在 (x, py) 和 (x, y)
                result += (self.point_count[(x, py)] *
                           self.point_count[(x, y)] *
                           self.point_count[(px, y)])

        return result
```

### 方法二：二维计数数组（利用坐标范围小）

```python
class DetectSquares:

    def __init__(self):
        # 坐标范围 0..1000，使用二维计数数组
        self.cnt = [[0] * 1001 for _ in range(1001)]
        self.points = []  # 保存所有添加的点（允许重复）

    def add(self, point: list) -> None:
        x, y = point
        self.cnt[x][y] += 1
        self.points.append((x, y))

    def count(self, point: list) -> int:
        px, py = point
        result = 0

        # 枚举所有已添加的点作为对角点
        seen = set()
        for x, y in self.points:
            if x == px or abs(x - px) != abs(y - py):
                continue  # 不满足正方形条件
            if (x, y) in seen:
                continue
            seen.add((x, y))

            # 正方形的四个角：(px,py), (x,y), (px,y), (x,py)
            result += self.cnt[x][y] * self.cnt[px][y] * self.cnt[x][py]

        return result
```

## 复杂度分析

| 方法 | add | count | 空间 |
|------|-----|-------|------|
| 方法一（哈希表） | O(1) | O(n)，n 为不同 y 坐标数 | O(n) |
| 方法二（数组） | O(1) | O(n)，n 为总点数 | O(M^2)，M=1001 |

## 关键点总结

1. 固定一个角点，枚举同 x 坐标的点作为第二个角点，确定边长
2. 然后计算另外两个角点的存在数量的乘积（处理重复点）
3. 对角点有左右两种情况，都需要枚举

## 易错点

- `y == py` 时边长为 0，不是合法正方形，需跳过
- 重复点的处理：乘以各角点的出现次数
- 枚举对角点时要考虑两侧（`px + side` 和 `px - side`）
