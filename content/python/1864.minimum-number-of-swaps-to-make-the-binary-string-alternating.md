## 题目描述

给你一个二进制字符串 `s`，返回使 `s` 变成**交替字符串**所需的**最少交换次数**（可以交换任意两个位置的字符）。

**交替字符串**是没有相邻字符相同的字符串，如 `"010101"` 或 `"101010"`。

若无法实现，返回 -1。

**示例 1：**
```
输入：s = "111000"
输出：1
```

**示例 2：**
```
输入：s = "010"
输出：0
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 为 `'0'` 或 `'1'`

## 解题思路

**贪心**：

交替字符串有两种形式：
- 以 `0` 开头：`0101...`
- 以 `1` 开头：`1010...`

当字符串长度为偶数时，两种形式中 0 和 1 数量各占一半；当长度为奇数时，较多的字符放在奇数位（0-indexed）。

**可行性**：0 和 1 的数量差不超过 1（奇数长度时差为 1，偶数长度时差为 0）。

**交换次数**：将当前字符串与目标字符串比较，错位的 0 和 1 可以两两交换。设目标字符串中，当前位置应为 1 但实际为 0 的位置数为 `wrong`，每次交换可以修复 2 个错误（一个 0 应为 1，一个 1 应为 0），所以交换次数 = `wrong`（因为 wrong_0 == wrong_1）。

## 代码实现

### 方法一：贪心统计（推荐）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        n = len(s)
        cnt0 = s.count('0')
        cnt1 = n - cnt0

        # 0 和 1 数量差超过 1，无法构成交替字符串
        if abs(cnt0 - cnt1) > 1:
            return -1

        def count_swaps(target_start: str) -> int:
            """计算使字符串变为以 target_start 开头的交替串所需的交换次数"""
            mismatches = 0
            for i, ch in enumerate(s):
                expected = target_start if i % 2 == 0 else ('1' if target_start == '0' else '0')
                if ch != expected:
                    mismatches += 1
            # mismatches 必然是偶数（不符合的 0 和 1 各半），交换次数为 mismatches // 2
            return mismatches // 2

        if cnt0 == cnt1:
            # 两种目标都可行，取最小
            return min(count_swaps('0'), count_swaps('1'))
        elif cnt0 > cnt1:
            # 只能以 0 开头
            return count_swaps('0')
        else:
            # 只能以 1 开头
            return count_swaps('1')
```

### 方法二：简洁版

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        n = len(s)
        ones = s.count('1')
        zeros = n - ones

        if abs(ones - zeros) > 1:
            return -1

        def swaps(start: int) -> int:
            # start=1 表示以1开头，统计位置不符的个数
            wrong = sum(1 for i in range(n) if (i % 2 == 0) != (start == 0) and s[i] != str((i + start) % 2))
            # 更简洁：统计偶数位不符合预期的个数
            wrong = sum(1 for i in range(0, n, 2) if s[i] != str(start))
            return wrong  # wrong == 错位1的个数 == 错位0的个数，交换次数 = wrong

        if ones > zeros:
            return swaps(1)
        elif zeros > ones:
            return swaps(0)
        else:
            return min(swaps(0), swaps(1))
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 交替字符串只有两种形式，分别计算交换次数取最小
2. 每次交换能修复 2 个位置的错误，所以交换次数 = 错位数 // 2
3. 错位的 0 和 1 必然相等（因为总数量不变）

## 易错点

- 判断可行性：`abs(cnt0 - cnt1) > 1` 时返回 -1
- 奇数长度时，只有一种可行的目标（多的字符放偶数位）
