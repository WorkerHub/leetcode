## 题目描述

给你两个整数 `lo` 和 `hi`，以及一个字符串前缀 `prefix` 和后缀 `suffix`。

返回在 `[lo, hi]` 范围内，十进制字符串表示同时以 `prefix` 开头且以 `suffix` 结尾的整数数目。

**示例 1：**

```
输入：lo = 1, hi = 100, prefix = "1", suffix = "0"
输出：1
解释：只有 10 满足以 "1" 开头且以 "0" 结尾。
```

**示例 2：**

```
输入：lo = 1, hi = 1000, prefix = "2", suffix = "2"
输出：2
解释：2 和 22 满足条件（22 以 "2" 开头且以 "2" 结尾）。
```

**提示：**
- `1 <= lo <= hi <= 10^9`
- `1 <= prefix.length, suffix.length <= 5`

## 解题思路

枚举所有满足前缀和后缀条件的整数：
1. 前缀固定了数字的高位，后缀固定了数字的低位。
2. 枚举"中间部分"的位数，从而生成候选数字。
3. 对每个候选数字，检查是否在 `[lo, hi]` 范围内。

由于 `hi <= 10^9`，最多 10 位，枚举空间有限。

## Python 代码实现

### 方法一：枚举中间部分（推荐）

```python
class Solution:
    def countNumbers(self, lo: int, hi: int, prefix: str, suffix: str) -> int:
        count = 0
        p_len = len(prefix)
        s_len = len(suffix)
        max_len = len(str(hi))

        for total_len in range(max(p_len, s_len, p_len + s_len - 1), max_len + 1):
            # 中间部分长度
            mid_len = total_len - p_len - s_len

            if mid_len < 0:
                # 前缀和后缀有重叠，需要验证重叠部分是否一致
                overlap = p_len + s_len - total_len
                # 前缀末尾 overlap 个字符与后缀前 overlap 个字符必须相同
                if prefix[-overlap:] == suffix[:overlap]:
                    # 合并后的数字
                    num_str = prefix + suffix[overlap:]
                    if len(num_str) == total_len:
                        num = int(num_str)
                        if lo <= num <= hi:
                            count += 1
            else:
                # 枚举中间部分
                if mid_len == 0:
                    num_str = prefix + suffix
                    if len(num_str) == total_len:
                        num = int(num_str)
                        if lo <= num <= hi:
                            count += 1
                else:
                    # 中间可以是 0 到 10^mid_len - 1
                    for mid in range(10 ** mid_len):
                        mid_str = str(mid).zfill(mid_len)
                        num_str = prefix + mid_str + suffix
                        num = int(num_str)
                        if lo <= num <= hi:
                            count += 1

        return count
```

### 方法二：直接枚举 lo 到 hi（暴力，适用于小范围）

```python
class Solution:
    def countNumbers(self, lo: int, hi: int, prefix: str, suffix: str) -> int:
        count = 0
        for num in range(lo, hi + 1):
            s = str(num)
            if s.startswith(prefix) and s.endswith(suffix):
                count += 1
        return count
```

## 复杂度分析

- 时间复杂度：O((hi - lo + 1))（暴力）；O(10^mid_len * max_len)（方法一，最坏 O(10^5)）
- 空间复杂度：O(1)

## 关键点总结

1. 前缀和后缀可能有重叠，需要特殊处理。
2. 枚举中间部分的所有可能，生成候选数字后检查范围。
3. 数字长度有限（最多 10 位），枚举范围可控。

## 易错点

1. 前缀和后缀可能重叠，重叠部分需一致才合法。
2. 中间部分长度可以为 0（前缀直接拼接后缀）。
3. 注意前导零：前缀不含前导零（因为是整数的字符串表示）。
