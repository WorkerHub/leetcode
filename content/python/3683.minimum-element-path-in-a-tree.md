## 题目描述

给你一棵有 `n` 个节点的树，每个节点有权值 `vals[i]`，以及若干查询 `queries[j] = [u, v]`，返回从 `u` 到 `v` 路径上的最小节点权值。

**示例 1：**

```
输入：n = 5, edges = [[0,1],[0,2],[1,3],[1,4]], 
     vals = [3,1,2,4,5], queries = [[3,4],[2,3]]
输出：[1,1]
解释：
3→1→4：min(4,1,5)=1
2→0→1→3：min(2,3,1,4)=1
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= vals[i] <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

LCA（最近公共祖先）+ 路径最小值。

用 sparse table（倍增法）在 O(n log n) 预处理后，每次查询 O(log n)。

## Python 代码实现

### 方法一：LCA + 路径最小值（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumPathValue(self, n: int, edges: List[List[int]],
                          vals: List[int], queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        LOG = 17
        parent = [[-1] * n for _ in range(LOG)]
        min_val = [[float('inf')] * n for _ in range(LOG)]
        depth = [0] * n

        # BFS 建树
        from collections import deque
        visited = [False] * n
        visited[0] = True
        queue = deque([0])
        order = []

        while queue:
            node = queue.popleft()
            order.append(node)
            for nb in graph[node]:
                if not visited[nb]:
                    visited[nb] = True
                    parent[0][nb] = node
                    min_val[0][nb] = min(vals[node], vals[nb])
                    depth[nb] = depth[node] + 1
                    queue.append(nb)

        # 倍增
        for k in range(1, LOG):
            for v in range(n):
                p = parent[k - 1][v]
                if p == -1:
                    parent[k][v] = -1
                    min_val[k][v] = float('inf')
                else:
                    parent[k][v] = parent[k - 1][p]
                    min_val[k][v] = min(min_val[k - 1][v], min_val[k - 1][p])

        def lca_min(u, v):
            result = min(vals[u], vals[v])
            if depth[u] < depth[v]:
                u, v = v, u
            # 对齐深度
            diff = depth[u] - depth[v]
            for k in range(LOG):
                if (diff >> k) & 1:
                    result = min(result, min_val[k][u])
                    u = parent[k][u]
            if u == v:
                return result
            for k in range(LOG - 1, -1, -1):
                if parent[k][u] != parent[k][v]:
                    result = min(result, min_val[k][u], min_val[k][v])
                    u = parent[k][u]
                    v = parent[k][v]
            result = min(result, min_val[0][u], min_val[0][v])
            return result

        return [lca_min(u, v) for u, v in queries]
```

### 方法二：DFS 暴力（小数据）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumPathValue(self, n: int, edges: List[List[int]],
                          vals: List[int], queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def find_path(u, v):
            visited = {u}
            stack = [(u, [vals[u]])]
            while stack:
                node, path = stack.pop()
                if node == v:
                    return min(path)
                for nb in graph[node]:
                    if nb not in visited:
                        visited.add(nb)
                        stack.append((nb, path + [vals[nb]]))
            return float('inf')

        return [find_path(u, v) for u, v in queries]
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)（方法一），O(n * q)（方法二）
- 空间复杂度：O(n log n)

## 关键点总结

1. LCA 找路径，倍增法高效
2. 倍增时同时维护路径最小值
3. 查询时沿 LCA 路径提取最小值

## 易错点

1. 路径最小值包含路径两端点
2. 对齐深度时累积路径最小值
3. `min_val[k][v]` 表示从 v 向上走 `2^k` 步路径上的最小值
