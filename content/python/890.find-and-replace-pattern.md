## 题目描述

给定一个字符串列表 words 和一个字符串 pattern，返回 words 中与 pattern 匹配的所有字符串。

如果存在字母的排列 p ，使得将 pattern 中的每个字母 x 替换为 p(x) 之后，我们就得到了 word，那么单词 word 与 pattern 匹配。

**提示：**
- 1 <= pattern.length <= 20
- 1 <= words.length <= 50
- words[i].length == pattern.length
- pattern 和 words[i] 都是小写英文字母

## 解题思路

检查每个 word 是否与 pattern 有相同的映射模式。

## Python 代码实现

```python
class Solution:
    def findAndReplacePattern(self, words: List[str], pattern: str) -> List[str]:
        def match(word):
            if len(word) != len(pattern):
                return False
            
            map1, map2 = {}, {}
            for w, p in zip(word, pattern):
                if w in map1:
                    if map1[w] != p:
                        return False
                else:
                    map1[w] = p
                
                if p in map2:
                    if map2[p] != w:
                        return False
                else:
                    map2[p] = w
            
            return True
        
        return [word for word in words if match(word)]
```

### 简洁版

```python
class Solution:
    def findAndReplacePattern(self, words: List[str], pattern: str) -> List[str]:
        def normalize(word):
            mapping = {}
            return [mapping.setdefault(c, len(mapping)) for c in word]
        
        pattern_normalized = normalize(pattern)
        return [word for word in words if normalize(word) == pattern_normalized]
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 是单词数，m 是单词长度
- **空间复杂度**：O(m)

## 关键点总结

1. **双向映射**：word → pattern 和 pattern → word
2. **归一化**：转换为数字模式
3. **检查一致性**：映射必须一一对应
