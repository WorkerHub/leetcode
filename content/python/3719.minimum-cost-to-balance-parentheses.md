## 题目描述

给定一个只包含 `'('` 和 `')'` 的字符串 `s`，每次操作可以将一个 `'('` 变为 `')'` 或将 `')'` 变为 `'('`，代价为 1。返回使字符串变为有效括号序列的最小代价。

若字符串长度为奇数，直接返回 `-1`。

**示例 1：**
```
输入：s = "))(("
输出：2
解释：将两个 ')' 改为 '(' 或将两个 '(' 改为 ')' 都需要 2 次操作。
     或者：将 s[0] 改为 '(' 并将 s[3] 改为 ')'，代价 2，得到 "()()"。
```

**示例 2：**
```
输入：s = "()"
输出：0
解释：已经是有效括号序列。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 `'('` 或 `')'`

## 解题思路

贪心 + 数学。

首先统计左括号数 `left` 和右括号数 `right`（`left + right = n`）。

**有效括号序列的条件：**
1. 总长度为偶数（`n` 为偶数）
2. 左括号数等于右括号数（`left == right == n/2`）

若 `n` 为奇数，返回 `-1`。

若 `left != right`：需要将多余的括号转换。设 `diff = abs(left - right)`，需要转换 `diff // 2` 个括号（每次转换一个多余的变为另一种，使两者各增减 1，差缩小 2）。

但仅保证括号数量相等还不够，还需要保证括号序列本身有效（任何前缀中左括号不少于右括号）。

用贪心计算：遍历字符串，维护当前未匹配的左括号数 `open`：
- 遇到 `'('`：`open += 1`
- 遇到 `')'`：若 `open > 0`，匹配一个，`open -= 1`；否则需要一次操作

最终 `open` 剩余的未匹配左括号也需要操作，每次操作消除 2 个（一对未匹配的 `(` 配对为 `()`）。

## Python 代码实现

### 方法一：贪心计数（推荐）

```python
class Solution:
    def minCost(self, s: str) -> int:
        n = len(s)
        if n % 2 == 1:
            return -1

        # 统计不平衡的括号
        # open: 当前多余的未匹配 '('
        # close: 当前多余的未匹配 ')'
        open_count = 0
        close_count = 0

        for c in s:
            if c == '(':
                open_count += 1
            else:
                if open_count > 0:
                    open_count -= 1  # 与前一个 '(' 匹配
                else:
                    close_count += 1  # 多余的 ')'

        # open_count 个多余的 '(' 和 close_count 个多余的 ')'
        # 每次操作可以消除 2 个（将一个 ')' 改为 '(' 消除一个多余的 ')' 并增加一个多余的 '('，
        # 但这里可以认为：每次修改使不平衡减少 2）
        # 正确的操作次数 = ceil(open_count / 2) + ceil(close_count / 2)
        # 注意：open_count 和 close_count 均为偶数（若 n 为偶数）

        return (open_count + close_count) // 2
```

### 方法二：数学简化

```python
class Solution:
    def minCost(self, s: str) -> int:
        n = len(s)
        if n % 2 == 1:
            return -1

        left = s.count('(')
        right = s.count(')')

        # 需要将 abs(left - right) // 2 个括号转换方向
        # 但还需要确保序列有效
        # 简化：最优操作数 = (多余左括号 + 多余右括号) / 2
        # 用栈方法计算多余括号
        stack = 0
        extra = 0
        for c in s:
            if c == '(':
                stack += 1
            elif stack > 0:
                stack -= 1
            else:
                extra += 1  # 多余右括号

        # stack = 多余左括号，extra = 多余右括号
        # 每次操作减少 2 个不平衡（将一个多余左改为右，或多余右改为左）
        return (stack + extra) // 2
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 奇数长度必然无法平衡，直接返回 -1
2. 贪心：遍历时维护未匹配的左括号计数，遇到右括号优先匹配
3. 最终多余的左括号和右括号各需要 `x/2` 次操作（每次消除 2 个不平衡）

## 易错点

1. 仅靠总数量相等不够，需要考虑顺序的有效性
2. 最终操作次数 = `(open + close) / 2`，而非 `open + close`
