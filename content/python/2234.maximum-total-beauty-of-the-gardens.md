## 题目描述

Alice 是一位园丁，她有 `n` 个花园。第 `i` 个花园目前种有 `flowers[i]` 朵花。

Alice 可以植入**额外** `newFlowers` 朵花（分配到任意花园，可以是 0 朵）。

花园的**美丽值**定义如下：
- 每个花园种有**至少** `target` 朵花，可得 `full` 分（称为"完整花园"）。
- 所有花园中**最少朵数**的那个花园贡献 `partial * min_flowers` 分（其中 `min_flowers` 是所有非完整花园中的最小值）。

返回额外种花后 **所有花园的最大美丽值**。

**示例 1：**
```
输入：flowers = [1,3,1,1], newFlowers = 7, target = 6, full = 12, partial = 1
输出：14
```

**示例 2：**
```
输入：flowers = [2,4,5,3], newFlowers = 10, target = 5, full = 2, partial = 6
输出：30
```

## 解题思路

**排序 + 二分查找 + 贪心。**

将 `flowers` 排序，枚举"完整花园"的数量 `j`（将最大的 j 个花园都填满，共消耗 `cost_full[j]` 朵花）。

剩余花 `newFlowers - cost_full[j]` 分配给前 n-j 个花园，尽量平均提高最小值（贪心：优先提升最小值，使 `partial * min_value` 最大）。

用前缀和计算"将前 i 个花园都提升到某个值 m 所需花数"，二分查找最大可行的 `m`。

## 代码实现

### 方法一：排序 + 二分（推荐）

```python
from typing import List
import bisect
from itertools import accumulate

class Solution:
    def maximumBeauty(self, flowers: List[int], newFlowers: int, target: int, full: int, partial: int) -> int:
        flowers.sort()
        n = len(flowers)

        # 将超过 target 的花园截断为 target
        for i in range(n):
            flowers[i] = min(flowers[i], target)

        # 前缀和：prefix[i] = sum(flowers[0..i-1])
        prefix = [0] + list(accumulate(flowers))

        # cost_full[j]：将最大的 j 个花园填满所需额外花数
        # 最大的 j 个是 flowers[n-j..n-1]
        cost_full = [0] * (n + 1)
        for j in range(1, n + 1):
            # 花园 flowers[n-j] 需要填到 target
            needed = target - flowers[n - j]
            cost_full[j] = cost_full[j - 1] + needed

        ans = 0

        # 枚举完整花园的数量 j（0 到 n）
        for j in range(n + 1):
            remaining = newFlowers - cost_full[j]
            if remaining < 0:
                break  # 花不够，停止（j 越大越贵）

            # 前 n-j 个花园（flowers[0..n-j-1]）用 remaining 朵花提升最小值
            cnt = n - j  # 非完整花园数量
            if cnt == 0:
                # 全部完整
                ans = max(ans, j * full)
                continue

            # 二分：找最大的 m 使前 cnt 个花园都能达到 m，且不超过 target-1
            # 花费 = m * cnt - prefix[cnt]（若 m >= flowers[i]）
            # 实际上需考虑已有花数
            # 用二分找最大 m 使花费 <= remaining
            lo, hi = flowers[0], target - 1

            # 计算将前 cnt 个花园全部提升到 m 所需花数
            def cost_to_m(m):
                # 找第一个 >= m 的位置
                pos = bisect.bisect_left(flowers, m, 0, cnt)
                # [0, pos-1] 的花园需要从 flowers[i] 提升到 m
                return m * pos - prefix[pos]

            # 二分最大 m
            while lo < hi:
                mid = (lo + hi + 1) // 2
                if cost_to_m(mid) <= remaining:
                    lo = mid
                else:
                    hi = mid - 1

            m = lo
            if cost_to_m(m) <= remaining:
                beauty = j * full + partial * m
                ans = max(ans, beauty)

        return ans
```

### 方法二：简化版（同思路）

```python
from typing import List
import bisect

class Solution:
    def maximumBeauty(self, flowers: List[int], newFlowers: int, target: int, full: int, partial: int) -> int:
        flowers.sort()
        n = len(flowers)
        flowers = [min(f, target) for f in flowers]

        # 前缀和
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + flowers[i]

        ans = 0
        cost = 0  # 从右往左将花园填满的累计花费

        for j in range(n + 1):
            # j 个完整花园（最右边的 j 个）
            rem = newFlowers - cost
            if rem < 0:
                break
            left = n - j

            if left == 0:
                ans = max(ans, j * full)
            else:
                # 前 left 个花园用 rem 朵花，最大化最小值
                lo, hi = 0, target - 1
                while lo < hi:
                    mid = (lo + hi + 1) // 2
                    p = bisect.bisect_left(flowers, mid, 0, left)
                    if mid * p - pre[p] <= rem:
                        lo = mid
                    else:
                        hi = mid - 1

                p = bisect.bisect_left(flowers, lo, 0, left)
                if lo * p - pre[p] <= rem:
                    ans = max(ans, j * full + partial * lo)

            # 下一轮：将 flowers[n-j-1] 填满
            if j < n:
                cost += target - flowers[n - j - 1]

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 枚举 j（n 次），每次二分 O(log n)。
- 空间复杂度：O(n)，前缀和数组。

## 关键点总结

1. 枚举完整花园数量，剩余花用于最大化非完整花园的最小值。
2. 贪心：将非完整花园平均提升（提升最低的优先），二分查找最大可行最小值。
3. 排序后可以高效计算"提升到 m 所需花数"：二分找到第一个 >= m 的位置，批量计算差值之和。

## 易错点

- 原有花数超过 target 的花园不需要额外花，且直接算作完整。
- 前 cnt 个花园中已有 >= m 的部分不需要额外花，二分时只对小于 m 的部分计算。
