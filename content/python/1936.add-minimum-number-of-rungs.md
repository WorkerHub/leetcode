## 题目描述

给你一个**严格递增**的整数数组 `rungs`，代表梯子上现有踏板的高度，以及整数 `dist`，代表你每次最多能爬升的高度。

你从高度 0 开始，需要到达梯子的最高踏板（`rungs` 最后一个元素）。如果两个相邻踏板（或起点 0 与第一个踏板）之间的距离超过 `dist`，你需要在中间**加踏板**。

返回达到最高踏板所需添加的**最少踏板数**。

**示例 1：**
```
输入：rungs = [1, 3, 5, 10], dist = 2
输出：2
解释：起点 0 到 1：距离 1 ≤ 2，无需添加
1 到 3：距离 2 ≤ 2，无需添加
3 到 5：距离 2 ≤ 2，无需添加
5 到 10：距离 5，需要添加 2 个踏板（如在 7 和 9）
```

**示例 2：**
```
输入：rungs = [3, 6, 8, 10], dist = 3
输出：0
```

**提示：**
- `1 <= rungs.length <= 10^5`
- `1 <= rungs[i] <= 10^9`
- `1 <= dist <= 10^9`
- `rungs` 严格递增

---

## 解题思路

### 核心思想：贪心 - 间隔除以 dist 向上取整

对于相邻两个位置之间的距离 `gap`，需要添加的踏板数为 `ceil(gap / dist) - 1`（即把间隔均分，每段不超过 dist）。

使用整数运算：`(gap - 1) // dist` 等价于 `ceil(gap / dist) - 1`。

---

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List
import math

class Solution:
    def addRungs(self, rungs: List[int], dist: int) -> int:
        result = 0
        prev = 0  # 从高度 0 开始

        for rung in rungs:
            gap = rung - prev
            if gap > dist:
                # 需要添加的踏板数
                result += (gap - 1) // dist
            prev = rung

        return result
```

### 方法二：使用 math.ceil（更直观）

```python
from typing import List
import math

class Solution:
    def addRungs(self, rungs: List[int], dist: int) -> int:
        result = 0
        prev = 0

        for rung in rungs:
            gap = rung - prev
            if gap > dist:
                # ceil(gap / dist) - 1：需要添加的踏板数
                result += math.ceil(gap / dist) - 1
            prev = rung

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n) | O(1) |
| 方法二 | O(n) | O(1) |

## 关键点总结

1. 只需考虑相邻踏板之间的间距，独立处理每段
2. 间距 `gap`，每段最多 `dist`：需要 `ceil(gap/dist) - 1` 个新踏板
3. `(gap - 1) // dist` 是 `ceil(gap/dist) - 1` 的整数等价（当 gap > 0）

---

## 易错点

- 注意从高度 0 出发，不是从 `rungs[0]` 出发
- 当 `gap <= dist` 时不需要添加踏板
- `(gap - 1) // dist`：`gap-1` 避免 gap 是 dist 整数倍时多算一个
