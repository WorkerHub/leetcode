## 题目描述

给你一个数组 `items`，其中 `items[i] = [type_i, color_i, name_i]`，描述第 `i` 件物品的类型、颜色及名称。

另给你一条表示为两个字符串 `ruleKey` 和 `ruleValue` 的检索规则。

如果第 `i` 件物品能满足下述条件之一，则认为该物品与给定的检索规则**匹配**：
- `ruleKey == "type"` 且 `ruleValue == type_i`。
- `ruleKey == "color"` 且 `ruleValue == color_i`。
- `ruleKey == "name"` 且 `ruleValue == name_i`。

统计并返回**匹配检索规则的物品数目**。

**示例：**
```
输入：items = [["phone","blue","pixel"],["computer","silver","lenovo"],["phone","gold","iphone"]], ruleKey = "color", ruleValue = "silver"
输出：1
```

**提示：**
- `1 <= items.length <= 10^4`

## 解题思路

根据 `ruleKey` 确定检查的是第几个字段（0/1/2），然后统计该字段等于 `ruleValue` 的物品数。

## 代码实现

### 方法一：映射 + 统计（推荐）

```python
from typing import List

class Solution:
    def countMatches(self, items: List[List[str]], ruleKey: str, ruleValue: str) -> int:
        # ruleKey 到下标的映射
        key_idx = {"type": 0, "color": 1, "name": 2}
        idx = key_idx[ruleKey]
        
        return sum(1 for item in items if item[idx] == ruleValue)
```

### 方法二：显式判断

```python
from typing import List

class Solution:
    def countMatches(self, items: List[List[str]], ruleKey: str, ruleValue: str) -> int:
        count = 0
        for t, c, n in items:
            if ruleKey == "type" and t == ruleValue:
                count += 1
            elif ruleKey == "color" and c == ruleValue:
                count += 1
            elif ruleKey == "name" and n == ruleValue:
                count += 1
        return count
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 用字典将 ruleKey 映射到列表索引
2. 统计匹配数量

## 易错点

- 三种 ruleKey 对应索引 0、1、2
