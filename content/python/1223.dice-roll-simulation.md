## 题目描述

有一个骰子模拟器会每次投掷的时候生成一个 1 到 6 的随机数。

不过我们在使用它时有个约束，就是使得投掷骰子时，连续掷出数字 `i` 的次数不能超过 `rollMax[i]`（`i` 从 1 开始编号）。

现在，给你一个整数数组 `rollMax` 和一个整数 `n`，请你来计算掷 `n` 次骰子可得到的不同点数序列的数量。

假如两个序列中至少有一个元素不同，就认为这两个序列是不同的。由于答案可能很大，所以请返回结果对 `10^9 + 7` 取模后的值。

**示例 1：**

```
输入：n = 2, rollMax = [1,1,2,2,2,3]
输出：34
解释：我们掷 2 次骰子，如果没有约束的话，共有 6 * 6 = 36 种可能的组合。但是根据 rollMax 数组，数字 1 和 2 最多连续出现一次，所以不会出现序列 (1,1) 和 (2,2)，因此答案是 36 - 2 = 34。
```

**示例 2：**

```
输入：n = 2, rollMax = [1,1,1,1,1,1]
输出：30
```

**示例 3：**

```
输入：n = 3, rollMax = [1,1,1,2,2,3]
输出：181
```

**提示：**

- `1 <= n <= 5000`
- `rollMax.length == 6`
- `1 <= rollMax[i] <= 15`

## 解题思路

这是一道**动态规划**难题，需要同时追踪投掷次数和连续出现的次数。

**核心思想：**

定义状态 `dp[i][j][k]`：
- `i`：投掷了 i 次骰子
- `j`：最后一次掷出的点数是 j（1-6）
- `k`：点数 j 连续出现了 k 次

状态转移：
- 如果下一次掷出的是不同的点数，连续次数重置为 1
- 如果下一次掷出的是相同的点数，连续次数 +1（需要检查是否超过 rollMax）

**优化思路：**

由于需要追踪连续次数，可以简化为二维 DP：
- `dp[i][j]`：投掷 i 次，最后一次是点数 j 的所有合法序列数量
- 但还需要记录连续次数，所以实际是三维

## Python 代码实现

### 方法一：三维 DP（标准解法）⭐

```python
from typing import List

class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        """
        三维动态规划
        
        时间复杂度：O(n * 6 * maxRoll)
        空间复杂度：O(n * 6 * maxRoll)
        """
        MOD = 10**9 + 7
        
        # dp[i][j][k] 表示投掷 i 次，最后一次是点数 j，连续出现 k 次的序列数量
        # j: 0-5 对应点数 1-6
        # k: 1 到 rollMax[j]
        max_roll = max(rollMax)
        dp = [[[0] * (max_roll + 1) for _ in range(6)] for _ in range(n + 1)]
        
        # 初始化：第一次投掷，每个点数都可能出现，连续次数为 1
        for j in range(6):
            dp[1][j][1] = 1
        
        # 状态转移
        for i in range(2, n + 1):
            for j in range(6):  # 当前投掷的点数
                for last in range(6):  # 上一次的点数
                    for k in range(1, rollMax[last] + 1):  # 上一次的连续次数
                        if last == j:
                            # 投掷相同的点数，连续次数 +1
                            if k + 1 <= rollMax[j]:
                                dp[i][j][k + 1] = (dp[i][j][k + 1] + dp[i - 1][last][k]) % MOD
                        else:
                            # 投掷不同的点数，连续次数重置为 1
                            dp[i][j][1] = (dp[i][j][1] + dp[i - 1][last][k]) % MOD
        
        # 统计所有可能的情况
        result = 0
        for j in range(6):
            for k in range(1, rollMax[j] + 1):
                result = (result + dp[n][j][k]) % MOD
        
        return result
```

### 方法二：优化的二维 DP

```python
from typing import List

class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        """
        优化版本：减少一维空间
        
        时间复杂度：O(n * 6 * maxRoll)
        空间复杂度：O(6 * maxRoll)
        """
        MOD = 10**9 + 7
        max_roll = 15  # 题目限制最大连续次数
        
        # dp[j][k]：当前最后一次是点数 j，连续出现 k 次
        dp = [[0] * (max_roll + 1) for _ in range(6)]
        
        # 初始化
        for j in range(6):
            dp[j][1] = 1
        
        # 投掷 n-1 次（第一次已初始化）
        for i in range(2, n + 1):
            new_dp = [[0] * (max_roll + 1) for _ in range(6)]
            
            for j in range(6):  # 当前点数
                for last in range(6):  # 上一次的点数
                    for k in range(1, rollMax[last] + 1):
                        if last == j and k + 1 <= rollMax[j]:
                            new_dp[j][k + 1] = (new_dp[j][k + 1] + dp[last][k]) % MOD
                        elif last != j:
                            new_dp[j][1] = (new_dp[j][1] + dp[last][k]) % MOD
            
            dp = new_dp
        
        # 计算结果
        result = 0
        for j in range(6):
            for k in range(1, rollMax[j] + 1):
                result = (result + dp[j][k]) % MOD
        
        return result
```

### 方法三：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        """
        记忆化递归（自顶向下）
        
        时间复杂度：O(n * 6 * maxRoll)
        空间复杂度：O(n * 6 * maxRoll)
        """
        MOD = 10**9 + 7
        
        @lru_cache(None)
        def dp(remaining: int, last_num: int, consecutive: int) -> int:
            """
            remaining: 还需要投掷多少次
            last_num: 上一次投掷的点数（0-5 对应 1-6，-1 表示还没开始）
            consecutive: 当前点数连续出现的次数
            """
            # 基础情况：没有剩余投掷次数
            if remaining == 0:
                return 1
            
            total = 0
            
            # 尝试投掷每个点数
            for num in range(6):
                if num == last_num:
                    # 投掷相同的点数
                    if consecutive < rollMax[num]:
                        total += dp(remaining - 1, num, consecutive + 1)
                        total %= MOD
                else:
                    # 投掷不同的点数
                    total += dp(remaining - 1, num, 1)
                    total %= MOD
            
            return total
        
        return dp(n, -1, 0)
```

### 方法四：详细注释版（新手友好）

```python
from typing import List

class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        """
        详细解释三维 DP 的思路
        """
        MOD = 10**9 + 7
        
        # 创建 DP 表
        # dp[投掷次数][点数][连续次数]
        # 例如：dp[5][2][3] 表示投掷5次，最后一次是点数3（索引2），连续出现3次
        max_consecutive = max(rollMax)
        dp = [[[0] * (max_consecutive + 1) for _ in range(6)] for _ in range(n + 1)]
        
        # 初始化：第一次投掷
        # 每个点数都可能出现一次
        for dice_value in range(6):  # 0-5 代表点数 1-6
            dp[1][dice_value][1] = 1
        
        # 动态规划：从第2次投掷到第n次
        for roll_count in range(2, n + 1):
            # 当前这次投掷的点数
            for current_dice in range(6):
                # 考虑上一次的所有可能状态
                for previous_dice in range(6):
                    # 上一次该点数连续出现的次数
                    for prev_consecutive in range(1, rollMax[previous_dice] + 1):
                        # 情况1：这次投掷和上次相同
                        if current_dice == previous_dice:
                            new_consecutive = prev_consecutive + 1
                            # 检查是否超过限制
                            if new_consecutive <= rollMax[current_dice]:
                                dp[roll_count][current_dice][new_consecutive] += dp[roll_count - 1][previous_dice][prev_consecutive]
                                dp[roll_count][current_dice][new_consecutive] %= MOD
                        else:
                            # 情况2：这次投掷和上次不同，连续次数重置为1
                            dp[roll_count][current_dice][1] += dp[roll_count - 1][previous_dice][prev_consecutive]
                            dp[roll_count][current_dice][1] %= MOD
        
        # 统计答案：所有投掷n次的合法序列
        answer = 0
        for dice_value in range(6):
            for consecutive_count in range(1, rollMax[dice_value] + 1):
                answer += dp[n][dice_value][consecutive_count]
                answer %= MOD
        
        return answer
```

## 复杂度分析

**方法一（三维 DP）：**

- **时间复杂度**：O(n × 6 × 6 × maxRoll) = O(n × maxRoll)
  - 三层循环：投掷次数、当前点数、上一次点数、连续次数
  
- **空间复杂度**：O(n × 6 × maxRoll)

**方法二（优化 DP）：**

- **时间复杂度**：O(n × 6 × 6 × maxRoll)
- **空间复杂度**：O(6 × maxRoll) = O(maxRoll)

示例 1：`n = 2, rollMax = [1,1,2,2,2,3]`

```
rollMax[0] = 1: 点数1最多连续1次
rollMax[1] = 1: 点数2最多连续1次
...

第一次投掷：
dp[1][0][1] = 1  (投1次，点数1，连续1次)
dp[1][1][1] = 1  (投1次，点数2，连续1次)

第二次投掷：
点数1后面：
  - 可以投 2,3,4,5,6（不能再投1，因为rollMax[0]=1）

  - 可以投 1,3,4,5,6（不能再投2，因为rollMax[1]=1）
...

不合法的序列：(1,1), (2,2)
合法序列数：36 - 2 = 34
```

## 关键点总结

1. **三维状态**：投掷次数、点数、连续次数
2. **状态转移**：区分相同点数和不同点数
3. **边界检查**：连续次数不能超过 rollMax
4. **取模运算**：防止溢出
5. **空间优化**：可以滚动数组优化到二维

## 易错点

1. **状态定义混淆**：
   - 要清楚每一维代表什么
   - 索引从 0 开始还是从 1 开始

2. **初始化错误**：
   - 第一次投掷时，每个点数连续次数都是 1
   - 不要忘记初始化

3. **转移条件**：
   - 相同点数：检查 k+1 是否超过限制
   - 不同点数：连续次数重置为 1

4. **取模时机**：
   - 每次加法后都要取模
   - 不要只在最后取模

5. **边界情况**：
   - n = 1 时的特殊处理
   - rollMax 全为 1 的情况
