## 题目描述

给你一个字符串 `s` 和一个整数 `k`，需要将 `s` 分成 `k` 个非空子字符串。

对于一个字符串，如果它可以通过修改若干字符使其成为长度为 `d` 的半回文串（`d` 是该字符串长度的因数，且 `d < len`），则该字符串是半回文串。更正式地，字符串 `t` 是半回文串，如果存在因子 `d`（`1 <= d < len(t)`，`d | len(t)`），使得 `t[0], t[d], t[2d], ...` 形成回文串，`t[1], t[d+1], t[2d+1], ...` 形成回文串，...，`t[d-1], t[2d-1], ...` 形成回文串（共 `d` 个子序列都是回文串）。

返回将 `s` 分成 `k` 个子字符串并使所有子字符串都成为半回文串所需的 **最少修改次数**。

**示例 1：**
```
输入：s = "abcac", k = 2
输出：1
```

**示例 2：**
```
输入：s = "abdefgabc", k = 4
输出：3
```

**提示：**
- `2 <= s.length <= 200`
- `1 <= k <= s.length / 2`
- `s` 只含小写英文字母

## 解题思路

区间 DP：设 `dp[i][j]` 为将 `s[0..i-1]` 分成 `j` 段半回文串的最少修改次数。

预处理 `cost[l][r]`：将 `s[l..r]` 变为半回文串的最少修改次数。对每个因子 d，计算使各序列成为回文串的代价（两端字符不同则需修改）。

`cost[l][r]` 对长度 `len = r-l+1` 的所有合法因子 `d` 取最小值。

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def minimumChanges(self, s: str, k: int) -> int:
        n = len(s)

        # 预计算将子串 s[l..r] 变成半回文串的最少修改数
        cost = [[0] * n for _ in range(n)]

        for l in range(n):
            for r in range(l + 1, n):
                length = r - l + 1
                best = float('inf')
                # 枚举因子 d（1 <= d < length，且 d | length）
                for d in range(1, length):
                    if length % d != 0:
                        continue
                    # 对每个偏移 offset in [0, d)，
                    # 计算使 s[l+offset], s[l+offset+d], ... 成为回文的修改数
                    changes = 0
                    for offset in range(d):
                        # 提取子序列
                        seq = [s[l + offset + t * d] for t in range(length // d)]
                        # 计算使 seq 成为回文的最少修改（贪心：两端不同则改一个）
                        lo, hi = 0, len(seq) - 1
                        while lo < hi:
                            if seq[lo] != seq[hi]:
                                changes += 1
                            lo += 1
                            hi -= 1
                    best = min(best, changes)
                cost[l][r] = best

        # dp[i][j]: 将 s[0..i-1] 分成 j 段的最少修改数
        INF = float('inf')
        dp = [[INF] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        for i in range(1, n + 1):
            for j in range(1, k + 1):
                # 最后一段为 s[p..i-1]，需长度至少为 2（半回文串长度 >= 2）
                for p in range(j - 1, i - 1):  # p 从 j-1 到 i-2
                    if dp[p][j - 1] == INF:
                        continue
                    if i - 1 - p < 1:  # 子串长度至少 2
                        continue
                    if i - p < 2:
                        continue
                    dp[i][j] = min(dp[i][j], dp[p][j - 1] + cost[p][i - 1])

        return dp[n][k]
```

## 复杂度分析

- 时间复杂度：O(n^3 + n^2 * D)，D 为因子个数（约 O(sqrt(n))），预处理 O(n^3)，DP 转移 O(n^2 * k)
- 空间复杂度：O(n^2)，cost 和 dp 数组

## 关键点总结

1. 半回文串定义：存在因子 d，使得按步长 d 分成的每组子序列都是回文串
2. 预计算 cost 数组后，DP 转移清晰
3. 因子枚举：对每个子串长度找所有真因子

## 易错点

1. 半回文串要求 `d < len`（因子严格小于长度）
2. 子串长度 1 时不能成为半回文串（无合法因子）
3. DP 初始化 dp[0][0] = 0，其余为无穷大
