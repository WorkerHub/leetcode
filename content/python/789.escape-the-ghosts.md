## 题目描述

你在进行一个简化版的吃豆人游戏。你从 `[0, 0]` 点开始出发，你的目的地是 `target = [xtarget, ytarget]`。地图上有若干鬼魂，第 `i` 个鬼魂从 `ghosts[i] = [xi, yi]` 出发。

每一轮，你和所有鬼魂可以同时向上、下、左、右四个方向移动，每次移动一个单位距离。如果你可以在任意鬼魂到达目标之前到达目标（鬼魂可以和你同时到达目标），则返回 `true`；否则返回 `false`。

你和鬼魂都采用**曼哈顿距离**的方式移动，即每次只能沿着坐标轴方向移动一个单位。

**示例 1：**
```
输入: ghosts = [[1,0],[0,3]], target = [0,1]
输出: true
解释: 
你可以直接到达目标 (0, 1)，距离为 1。
鬼魂 1 从 (1, 0) 到 (0, 1) 的距离为 2。
鬼魂 2 从 (0, 3) 到 (0, 1) 的距离为 2。
你可以在鬼魂之前到达目标。
```

**示例 2：**
```
输入: ghosts = [[1,0]], target = [2,0]
输出: false
解释: 
你需要到达 (2, 0)，距离为 2。
鬼魂从 (1, 0) 到 (2, 0) 的距离为 1。
鬼魂会先到达目标，你无法逃脱。
```

**示例 3：**
```
输入: ghosts = [[2,0]], target = [1,0]
输出: false
解释: 
鬼魂可以和你同时到达目标，返回 false。
```

**提示：**
- `1 <= ghosts.length <= 100`
- `ghosts[i].length == 2`
- `-10^4 <= xi, yi <= 10^4`
- 同一位置可能有多个鬼魂
- `target.length == 2`
- `-10^4 <= xtarget, ytarget <= 10^4`

## 解题思路

这道题看起来像是路径搜索问题，但实际上可以通过**贪心 + 数学**的思想简化。

**关键观察：**

1. **曼哈顿距离是最优路径**：
   - 从点 `(x1, y1)` 到点 `(x2, y2)` 的曼哈顿距离是 `|x1 - x2| + |y1 - y2|`
   - 无论怎么走，最短步数就是曼哈顿距离

2. **贪心策略**：
   - 你和鬼魂都会选择最短路径前往目标
   - 如果有任意鬼魂到目标的距离 <= 你到目标的距离，你就无法逃脱
   - 因为鬼魂可以直接沿最短路径去目标点"守株待兔"

3. **不需要考虑复杂路径**：
   - 不需要 BFS/DFS，不需要考虑绕路
   - 只需要比较你和所有鬼魂到目标的曼哈顿距离

**结论：**
只要所有鬼魂到目标的距离都严格大于你到目标的距离，你就能逃脱。

## Python 代码实现

### 方法一：曼哈顿距离比较（推荐）

```python
from typing import List

class Solution:
    def escapeGhosts(self, ghosts: List[List[int]], target: List[int]) -> bool:
        """
        计算你和所有鬼魂到目标的曼哈顿距离，比较即可
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 计算你到目标的距离（从原点 [0, 0] 出发）
        my_distance = abs(target[0]) + abs(target[1])
        
        # 检查每个鬼魂到目标的距离
        for ghost_x, ghost_y in ghosts:
            ghost_distance = abs(target[0] - ghost_x) + abs(target[1] - ghost_y)
            
            # 如果有任意鬼魂距离 <= 你的距离，无法逃脱
            if ghost_distance <= my_distance:
                return False
        
        return True
```

### 方法二：使用辅助函数

```python
from typing import List

class Solution:
    def escapeGhosts(self, ghosts: List[List[int]], target: List[int]) -> bool:
        """
        使用辅助函数计算曼哈顿距离
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        def manhattan_distance(point1: List[int], point2: List[int]) -> int:
            """计算两点之间的曼哈顿距离"""
            return abs(point1[0] - point2[0]) + abs(point1[1] - point2[1])
        
        # 你的起点
        my_position = [0, 0]
        
        # 你到目标的距离
        my_distance = manhattan_distance(my_position, target)
        
        # 检查所有鬼魂
        for ghost in ghosts:
            if manhattan_distance(ghost, target) <= my_distance:
                return False
        
        return True
```

### 方法三：使用 all() 函数简化

```python
from typing import List

class Solution:
    def escapeGhosts(self, ghosts: List[List[int]], target: List[int]) -> bool:
        """
        使用 Python 的 all() 函数简化代码
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        # 你到目标的距离
        my_distance = abs(target[0]) + abs(target[1])
        
        # 检查所有鬼魂的距离是否都大于你的距离
        return all(
            abs(target[0] - gx) + abs(target[1] - gy) > my_distance
            for gx, gy in ghosts
        )
```

## 复杂度分析

### 所有方法
- **时间复杂度：** O(n)，其中 n 是鬼魂的数量，需要遍历所有鬼魂
- **空间复杂度：** O(1)，只使用常数额外空间

## 关键点总结

1. **贪心思想**：你和鬼魂都会选择最短路径，不需要考虑复杂的路径规划
2. **曼哈顿距离**：在网格中，曼哈顿距离就是最短步数
3. **守株待兔策略**：如果鬼魂能先到达或同时到达目标，它可以直接去目标等你
4. **比较大小**：只需要比较距离，不需要真正模拟移动过程
5. **严格大于**：鬼魂距离必须严格大于你的距离，相等也算无法逃脱

## 易错点

1. **边界条件**：鬼魂和你同时到达目标算失败（距离相等时返回 `false`）
2. **起点错误**：你的起点是 `[0, 0]`，不是其他位置
3. **距离计算**：曼哈顿距离是 `|x1 - x2| + |y1 - y2|`，不是欧几里得距离
4. **过度思考**：不需要考虑拦截、绕路等复杂策略，直接比较距离即可
5. **短路判断**：只要发现一个鬼魂距离 <= 你的距离，就可以立即返回 `false`
