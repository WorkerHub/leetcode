## 题目描述

给你一个句子 `text`（字符串），句子的格式满足以下条件：

1. 第一个单词的首字母大写，其余单词全部小写
2. 每个单词由单个空格分隔

请你重新排列 `text` 中的单词，使所有单词按其长度的升序排列；如果两个单词的长度相同，则保持其在原句子中的相对顺序（即稳定排序）。

返回新的句子，其中第一个单词的首字母大写，其余单词全部小写。

**示例 1：**
```
输入：text = "Leetcode is cool"
输出："Is cool leetcode"
解释：句子中共有 3 个单词，长度分别为 8、2、4。
     按长度升序排列："is"(2) -> "cool"(4) -> "leetcode"(8)
     第一个单词首字母大写："Is cool leetcode"
```

**示例 2：**
```
输入：text = "Keep calm and code on"
输出："On and keep calm code"
解释："and"(3) = "and"(3)，保持原顺序（and 在 code 之前）... 不对，让我重新看示例
实际按长度："On"(2) -> "and"(3) -> "keep"(4) -> "calm"(4) -> "code"(4)
```

**示例 3：**
```
输入：text = "To be or not to be"
输出："To be or to be not"
```

**提示：**
- `text` 只包含大写和小写英文字母以及空格
- `text` 中至少有一个单词
- `text` 的单词之间只有单个空格
- 第一个单词的首字母大写，其余均为小写

## 解题思路

步骤拆解：

1. **全部转小写**：题目保证第一个单词首字母大写，先把整句转小写，便于统一处理
2. **分割单词**：`text.split()` 得到单词列表
3. **稳定排序**：按单词长度排序，Python 的 `sorted` 是稳定排序，相同长度保持原顺序
4. **还原首字母大写**：将排序后列表的第一个单词首字母大写
5. **拼接结果**：`" ".join(words)` 拼成句子

## Python 代码实现

### 方法一：稳定排序（推荐）

```python
class Solution:
    def arrangeWords(self, text: str) -> str:
        # 第一步：全部转小写，消除首字母大写的影响
        text = text.lower()

        # 第二步：分割句子得到单词列表
        words = text.split()

        # 第三步：按单词长度稳定排序（Python sorted 是稳定的）
        words.sort(key=lambda w: len(w))

        # 第四步：第一个单词首字母大写
        words[0] = words[0].capitalize()

        # 第五步：拼接结果
        return " ".join(words)
```

### 方法二：利用元组排序（保证稳定性更显式）

```python
class Solution:
    def arrangeWords(self, text: str) -> str:
        # 分割并转小写
        words = text.lower().split()

        # 用 (长度, 原始下标) 作为排序键，显式保证相同长度按原顺序
        words = sorted(words, key=lambda x: (len(x),))

        # 首字母大写并拼接
        return " ".join(words).capitalize()
        # 注意：str.capitalize() 会将第一个字母大写，其余全部小写
```

### 方法三：手动实现过程（帮助理解）

```python
class Solution:
    def arrangeWords(self, text: str) -> str:
        # 分割句子，第一个单词转小写（其他已经是小写）
        words = text.split()
        words[0] = words[0].lower()  # 将第一个单词转小写

        # 按长度稳定排序
        # Python 内置 sort/sorted 保证稳定性
        sorted_words = sorted(words, key=len)

        # 拼接：第一个单词首字母大写
        result = " ".join(sorted_words)
        return result[0].upper() + result[1:]
```

## 复杂度分析

- 时间复杂度：O(n log n)，n 为单词数量，排序的时间复杂度
- 空间复杂度：O(n)，存储单词列表

## 关键点总结

1. 先统一转小写，再排序，最后处理首字母大写
2. Python 的 `sort` 和 `sorted` 都是**稳定排序**（TimSort），相同键值保持原顺序
3. `capitalize()` 将字符串第一个字母大写，其余转小写；`title()` 则每个单词首字母大写
4. `" ".join(list)` 是 Python 拼接字符串列表的标准方式

## 易错点

- 不要忘记先将第一个单词转为小写，否则排序时大写字母的 ASCII 值更小会影响结果
- `capitalize()` 作用于整个字符串时，只将第一个字符大写，其余全变小写，符合题目要求
- 注意 `sort` 修改原列表，`sorted` 返回新列表，本题两种都可以用
