## 题目描述

给你两个整数数组 `servers` 和 `tasks`（下标从 0 开始）：
- `servers[i]` 是第 i 台服务器的权重
- `tasks[j]` 是第 j 个任务所需的处理时间

服务器和任务按编号从小到大处理。在时间 `j`（j 从 0 开始），任务 j 到达。若有空闲服务器，分配给权重最小（相同则编号最小）的空闲服务器；否则等待最早释放的服务器。

返回每个任务分配的服务器编号数组。

**示例：**
```
输入：servers = [3,3,2], tasks = [1,2,3,2,1,2]
输出：[2,2,0,2,1,2]
```

## 解题思路

使用两个最小堆：
- `free_heap`：空闲服务器，按 (weight, index) 排序
- `busy_heap`：繁忙服务器，按 (finish_time, weight, index) 排序

对每个任务 j：
1. 将所有完成时间 <= j 的繁忙服务器移到空闲堆
2. 若空闲堆不为空，取最优空闲服务器分配
3. 若空闲堆为空，取最早完成的服务器（无论时间）分配

## 代码实现

### 方法一：双堆模拟（推荐）

```python
import heapq
from typing import List

class Solution:
    def assignTasks(self, servers: List[int], tasks: List[int]) -> List[int]:
        n_servers = len(servers)
        n_tasks = len(tasks)

        # 空闲服务器堆：(weight, index)
        free_heap = [(servers[i], i) for i in range(n_servers)]
        heapq.heapify(free_heap)

        # 繁忙服务器堆：(finish_time, weight, index)
        busy_heap = []

        result = [0] * n_tasks

        for j in range(n_tasks):
            time = j  # 当前时间

            # 将完成时间 <= j 的服务器释放到空闲堆
            while busy_heap and busy_heap[0][0] <= time:
                ft, w, idx = heapq.heappop(busy_heap)
                heapq.heappush(free_heap, (w, idx))

            if free_heap:
                # 有空闲服务器，分配最优的
                w, idx = heapq.heappop(free_heap)
                result[j] = idx
                heapq.heappush(busy_heap, (time + tasks[j], w, idx))
            else:
                # 无空闲服务器，等待最早完成的
                ft, w, idx = heapq.heappop(busy_heap)
                result[j] = idx
                heapq.heappush(busy_heap, (ft + tasks[j], w, idx))

        return result
```

### 方法二：使用 time 变量跳跃

```python
import heapq
from typing import List

class Solution:
    def assignTasks(self, servers: List[int], tasks: List[int]) -> List[int]:
        free = [(w, i) for i, w in enumerate(servers)]
        heapq.heapify(free)
        busy = []
        result = []

        for j, task in enumerate(tasks):
            t = max(j, busy[0][0] if busy and not free else j)
            # 将已完成的服务器移到 free
            while busy and busy[0][0] <= max(j, t):
                ft, w, i = heapq.heappop(busy)
                heapq.heappush(free, (w, i))

            if free:
                w, i = heapq.heappop(free)
                result.append(i)
                heapq.heappush(busy, (j + task, w, i))
            else:
                ft, w, i = heapq.heappop(busy)
                result.append(i)
                heapq.heappush(busy, (ft + task, w, i))

        return result
```

## 复杂度分析

- **时间复杂度**：O((n + m) log n)，n 为服务器数，m 为任务数
- **空间复杂度**：O(n + m)

## 关键点总结

1. 两个堆：空闲堆按优先级（权重、编号），繁忙堆按完成时间
2. 每个任务到来时，先释放已完成的服务器，再分配
3. 若无空闲服务器，直接取繁忙堆堆顶（最早完成的），在其完成时间后开始任务

## 易错点

- 任务到来时间为 j，若没有空闲服务器，任务需等到最早完成时间
- 等待时（busy_heap 取出），任务开始时间为 ft（最早完成时间），而非 j
