## 题目描述

给你一个仅由小写英文字母组成的字符串 `s`。

如果字符串 `t` 是 `s` 的子序列，且 `t` 中每个字母的出现次数相同，则称 `t` 是 `s` 的一个 **好子序列**。

返回 `s` 中好子序列（非空）的数目（对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：s = "aabb"
输出：11
解释：好子序列包括每个字母各取 1 个（C(2,1)*C(2,1)=4）、各取 2 个（C(2,2)*C(2,2)=1）和单字母子序列（C(2,1)+C(2,2)=3+1=4+C(2,1)+C(2,2)...）共 11 个。
```

**示例 2：**

```
输入：s = "leet"
输出：12
```

**提示：**

- `1 <= s.length <= 10^4`
- `s` 只包含小写英文字母

## 解题思路

统计每个字母的出现频次 `cnt[c]`。好子序列需要每种出现的字母各选相同数目 k（k 从 1 到 min(cnt)）。

对于固定的 k，好子序列数 = 乘积 ∏ C(cnt[c], k)，其中 c 遍历所有出现的字母。

对 k 从 1 到 max(cnt) 求和，当某字母的 cnt[c] < k 时该项为 0（跳过）。

注意单字母子序列（只含一种字母的子序列）要加入（此时只需该字母的 C(cnt[c], k)）。

实际上：答案 = sum over k from 1 to max_freq: product of C(cnt[c], k) for all c where cnt[c] >= k。

## Python 代码实现

### 方法一：枚举 k + 组合数（推荐）

```python
from collections import Counter
import math

MOD = 10**9 + 7

class Solution:
    def countGoodSubsequences(self, s: str) -> int:
        cnt = Counter(s)
        max_freq = max(cnt.values())
        freq_list = list(cnt.values())

        # 预计算阶乘和逆元
        max_n = len(s) + 1
        fact = [1] * (max_n + 1)
        for i in range(1, max_n + 1):
            fact[i] = fact[i-1] * i % MOD
        inv_fact = [1] * (max_n + 1)
        inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
        for i in range(max_n - 1, -1, -1):
            inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

        def comb(n, r):
            if r < 0 or r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n-r] % MOD

        ans = 0
        for k in range(1, max_freq + 1):
            # 每种字母选 k 个，乘积
            product = 1
            valid = False
            for f in freq_list:
                if f >= k:
                    product = product * comb(f, k) % MOD
                    valid = True
                else:
                    product = 0
                    break
            if valid and product:
                ans = (ans + product) % MOD

        return ans
```

### 方法二：只考虑出现过的字母的频次

```python
from collections import Counter

MOD = 10**9 + 7

class Solution:
    def countGoodSubsequences(self, s: str) -> int:
        cnt = Counter(s)
        freq_vals = sorted(cnt.values())
        max_f = freq_vals[-1]

        max_n = len(s) + 1
        fact = [1] * (max_n + 1)
        for i in range(1, max_n + 1):
            fact[i] = fact[i-1] * i % MOD
        inv_fact = [1] * (max_n + 1)
        inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
        for i in range(max_n - 1, -1, -1):
            inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

        def comb(n, r):
            if r > n:
                return 0
            return fact[n] * inv_fact[r] % MOD * inv_fact[n-r] % MOD

        ans = 0
        for k in range(1, max_f + 1):
            prod = 1
            for f in freq_vals:
                if f < k:
                    prod = 0
                    break
                prod = prod * comb(f, k) % MOD
            ans = (ans + prod) % MOD

        return ans
```

## 复杂度分析

- 时间复杂度：O(max_freq * 26)，枚举 k 和所有字母
- 空间复杂度：O(|s|)，预计算阶乘

## 关键点总结

1. 好子序列的条件：出现的每个字母各取相同数量 k
2. 固定 k 后，方案数 = 每个字母的 C(cnt, k) 之积
3. 若某字母频次 < k，则该 k 无贡献（乘积为 0）

## 易错点

1. k 要从 1 到所有字母中出现次数最大值遍历
2. 只要有任一字母的频次 < k 就跳过，不需要枚举后续
3. 预计算逆元时注意范围足够大
