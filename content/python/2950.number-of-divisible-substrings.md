## 题目描述

每个字母对应一个数字：`a-i` 对应 1，`j-r` 对应 2，`s-z` 对应 3。

给你一个字符串 `word`，统计满足以下条件的子字符串数目：每个字符对应的数字之和能被子字符串的长度整除。

**示例 1：**
```
输入：word = "swt"
输出：3
解释：
"s"=3, 3/1=3, 可整除
"w"=2, 2/1=2, 可整除
"t"=3, 3/1=3, 可整除
"sw"=3+2=5, 5/2 不可整除
"wt"=2+3=5, 5/2 不可整除
"swt"=3+2+3=8, 8/3 不可整除
答案：3
```

**示例 2：**
```
输入：word = "aa"
输出：3
解释：a=1，"a"=1, 1/1=1; "a"=1; "aa"=2, 2/2=1
答案：3
```

**提示：**
- `1 <= word.length <= 2000`
- `word` 只含小写字母

## 解题思路

对每个数字值 t（t = 1, 2, 3），统计所有字符 digit=t 的子串（sum = t * len），可整除的条件是 t * len % len == 0，即 sum % len == 0（即 t 整除 len 的条件恒成立！）

等等，更准确地说：子串 [l, r] 的 sum = sum of digit(s[i]) for i in [l,r]，长度 = r-l+1。
条件：sum % len == 0，即 sum = k * len for some integer k。

这等价于 sum/len 为整数，即平均值为整数。

枚举每个平均值 t（1, 2, 3），统计 sum = t * len 的子串数目，即 sum - t * len = 0，等价于 prefix_sum(r+1) - prefix_sum(l) - t*(r-l+1) = 0。

设 `a[i] = digit(s[i]) - t`，则条件变为 prefix_a[r+1] - prefix_a[l] = 0，即用前缀和+哈希表统计。

## Python 代码实现

### 方法一：枚举平均值 + 前缀和（推荐）

```python
from collections import defaultdict

class Solution:
    def countDivisibleSubstrings(self, word: str) -> int:
        # 字母到数字的映射
        def digit(c):
            idx = ord(c) - ord('a')
            return idx // 9 + 1  # a-i:1, j-r:2, s-z:3

        n = len(word)
        digits = [digit(c) for c in word]
        ans = 0

        # 枚举平均值 t = 1, 2, 3
        for t in range(1, 4):
            # a[i] = digits[i] - t
            # 统计前缀和为 0 的对数（prefix[r+1] == prefix[l]）
            cnt = defaultdict(int)
            cnt[0] = 1
            prefix = 0
            for d in digits:
                prefix += d - t
                ans += cnt[prefix]
                cnt[prefix] += 1

        return ans
```

### 方法二：暴力枚举

```python
class Solution:
    def countDivisibleSubstrings(self, word: str) -> int:
        def digit(c):
            return (ord(c) - ord('a')) // 9 + 1

        n = len(word)
        ans = 0
        for l in range(n):
            total = 0
            for r in range(l, n):
                total += digit(word[r])
                if total % (r - l + 1) == 0:
                    ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(3n) = O(n)，枚举三个平均值，每次 O(n)
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 平均值只可能是 1, 2, 3（因为 digits[i] 只有这三个值）
2. 对每个候选平均值 t，转化为前缀和相等问题
3. 哈希表统计前缀和，O(n) 完成一次扫描

## 易错点

1. 字母到数字：a-i 是 1，j-r 是 2，s-z 是 3（每组 9 个）
2. 转化技巧：`digit(s[i]) - t`，前缀和为 0 等价于平均值为 t
3. 哈希表初始化 cnt[0] = 1（空前缀）
