## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `k`。

你的 **得分** 从 **0** 开始。

每次操作，你必须：
1. 选择一个下标 `i`（`0 <= i < n`）
2. 将 `nums[i]` 加到你的得分中
3. 将 `nums[i]` 替换为 `ceil(nums[i] / 3)`

最多执行 `k` 次操作，返回可以得到的 **最大** 得分。

**示例 1：**

```
输入：nums = [10,10,10,10,10], k = 5
输出：50
解释：每次选不同的元素，每次得 10，共得 50。
```

**示例 2：**

```
输入：nums = [1,10,3,3,3], k = 3
输出：17
解释：选 10，得 10；替换为 4；选 4，得 4；替换为 2；选 10 → 选 3 → ...最优序列得分 17。
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

**贪心 + 最大堆**：每次选取当前最大的元素加入得分，然后将其替换为 `ceil(值 / 3)`，重新放入堆。

重复 k 次。注意 k 可以很大，但元素很快变为 1，之后每次得 1 分可以优化。

## Python 代码实现

### 方法一：最大堆（推荐）

```python
from typing import List
import heapq
import math

class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        # Python 的 heapq 是最小堆，取负值实现最大堆
        heap = [-x for x in nums]
        heapq.heapify(heap)
        score = 0

        for _ in range(k):
            val = -heapq.heappop(heap)
            score += val
            # 替换为 ceil(val / 3)
            new_val = math.ceil(val / 3)
            heapq.heappush(heap, -new_val)

        return score
```

### 方法二：使用整数向上取整

```python
from typing import List
import heapq

class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        # 整数向上取整：ceil(a/b) = (a + b - 1) // b
        heap = [-x for x in nums]
        heapq.heapify(heap)
        score = 0

        for _ in range(k):
            val = -heapq.heappop(heap)
            score += val
            # ceil(val / 3) = (val + 2) // 3
            heapq.heappush(heap, -((val + 2) // 3))

        return score
```

## 复杂度分析

- 时间复杂度：O(k log n)，每次堆操作 O(log n)，共 k 次
- 空间复杂度：O(n)，堆的大小

## 关键点总结

1. 贪心策略：每次选最大元素，这样得分最大化
2. `ceil(val / 3)` 的整数实现：`(val + 2) // 3`
3. Python 最大堆：将元素取负后使用 `heapq`

## 易错点

1. `math.ceil(val / 3)` 可能因浮点精度有误，推荐用 `(val + 2) // 3`
2. k 可能很大（10^9），但每个元素最多 log_3(10^9) ≈ 19 次后变为 1
3. 取负值实现最大堆时，pop 后要取负才是真实值
