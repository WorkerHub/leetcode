## 题目描述

给你一个下标从 **0** 开始的字符串 `word` 和一个字符 `ch`。找出 `ch` 在 `word` 中的**第一次出现**的下标 `i`，将 `word` 中从下标 `0` 到下标 `i`（含）之间的子字符串**反转**，然后返回结果字符串。

若 `ch` 不存在于 `word` 中，则直接返回 `word`。

**示例 1：**
```
输入：word = "abcdefd", ch = 'd'
输出："dcbaefd"
解释：'d' 第一次出现在下标 3，反转 word[0..3] = "abcd" → "dcba"
```

**示例 2：**
```
输入：word = "xyxzxe", ch = 'z'
输出："zxyxxe"
```

**提示：**
- `1 <= word.length <= 250`
- `word` 由小写英文字母组成
- `ch` 为小写英文字母

---

## 解题思路

### 核心思想：找第一次出现的位置，反转前缀

用 `str.find` 找第一次出现的下标 `i`，若不存在（返回 -1）则直接返回原字符串，否则翻转 `word[:i+1]` 拼接 `word[i+1:]`。

---

## 代码实现

### 方法一：Python 切片（推荐）

```python
class Solution:
    def reversePrefix(self, word: str, ch: str) -> str:
        i = word.find(ch)
        if i == -1:
            return word
        # 反转前缀 word[0..i]，拼接后缀 word[i+1:]
        return word[:i + 1][::-1] + word[i + 1:]
```

### 方法二：双指针反转

```python
class Solution:
    def reversePrefix(self, word: str, ch: str) -> str:
        i = word.find(ch)
        if i == -1:
            return word
        # 转为列表，双指针反转
        chars = list(word)
        lo, hi = 0, i
        while lo < hi:
            chars[lo], chars[hi] = chars[hi], chars[lo]
            lo += 1
            hi -= 1
        return ''.join(chars)
```

### 方法三：列表操作

```python
class Solution:
    def reversePrefix(self, word: str, ch: str) -> str:
        if ch not in word:
            return word
        idx = word.index(ch)  # 第一次出现的下标
        # 构造结果
        prefix = list(word[:idx + 1])
        prefix.reverse()
        return ''.join(prefix) + word[idx + 1:]
```

## 关键点总结

1. `str.find(ch)` 返回第一次出现的下标，不存在返回 -1
2. Python 切片 `[::-1]` 直接反转字符串
3. 反转范围是 `[0, i]`（含 i），后缀 `[i+1:]` 不变

---

## 易错点

- 反转的范围包含 `ch` 所在下标（`word[:i+1]`），不要遗漏
- `word.find` 不存在时返回 -1，注意判断
