## 题目描述

给你两个整数数组 `nums` 和 `cost`，以及一个整数 `k`。

将数组 `nums` 分成若干个非空子数组。第 j 个子数组（从 0 开始）的代价为：

`cost[j] * (nums 中在该子数组第一个元素之前的所有元素之和 + k * j)`

返回最小总代价。

**示例：**

```
输入：nums = [1,2,3], cost = [10,3,1], k = 2
输出：14
解释：
分成 [1] 和 [2,3]：
子数组0：cost[0] * (0 + 2*0) = 10*0 = 0
子数组1：cost[1] * (1 + 2*1) = 3*3 = 9
不对，需要更仔细理解题意...
```

**提示：**
- `1 <= nums.length == cost.length <= 1000`
- `1 <= nums[i], cost[i] <= 10^6`
- `1 <= k <= 10^9`

## 解题思路

DP：`dp[i]` = 将 nums[0..i-1] 分成若干子数组的最小代价。

设分割点为 j（子数组从 j 到 i-1），该子数组是第 t 个子数组，其代价 = cost[t] * (prefix_sum[j] + k * t)。

难点：每个子数组的代价与其所在的位置（第几个子数组）相关，需要同时追踪子数组编号。

状态：`dp[i][t]` = 前 i 个元素分成 t 个子数组的最小代价。

## Python 代码实现

### 方法一：二维 DP

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int], cost: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # dp[i][t] = nums[0..i-1] 分成 t 个子数组的最小代价
        # t 最多为 n
        # dp[0][0] = 0
        # dp[i][t] = min(dp[j][t-1] + cost[t-1] * (prefix[j] + k * (t-1)))
        #            for j in 0..i-1 (子数组为 nums[j..i-1])

        # 注意：cost 数组的索引对应子数组编号（0-indexed）
        # 第 t 个子数组（1-indexed）用 cost[t-1]

        dp = [[INF] * (n + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        for t in range(1, n + 1):
            for i in range(t, n + 1):
                for j in range(t - 1, i):
                    # 第 t 个子数组为 nums[j..i-1]
                    # 前 j 个元素已分成 t-1 个子数组
                    prev = dp[j][t - 1]
                    if prev == INF:
                        continue
                    c = cost[t - 1] * (prefix[j] + k * (t - 1))
                    dp[i][t] = min(dp[i][t], prev + c)

        return min(dp[n][t] for t in range(1, n + 1))
```

### 方法二：空间优化 DP

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int], cost: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 滚动数组：prev[j] = dp[j][t-1]
        prev = [INF] * (n + 1)
        prev[0] = 0

        ans = INF

        for t in range(1, n + 1):
            curr = [INF] * (n + 1)
            for i in range(t, n + 1):
                for j in range(t - 1, i):
                    if prev[j] == INF:
                        continue
                    c = cost[t - 1] * (prefix[j] + k * (t - 1))
                    curr[i] = min(curr[i], prev[j] + c)

            prev = curr
            if prev[n] != INF:
                ans = min(ans, prev[n])

        return ans
```

### 方法三：优化内层（前缀最小值）

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int], cost: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # dp[i][t] = min over j of (dp[j][t-1] + cost[t-1] * (prefix[j] + k*(t-1)))
        # = cost[t-1] * k*(t-1) + min over j of (dp[j][t-1] + cost[t-1] * prefix[j])

        # 固定 t：cost[t-1] 和 k*(t-1) 是常数
        # 对每个 i，dp[i][t] = const + min_{j < i} (dp[j][t-1] + cost[t-1] * prefix[j])

        prev = [INF] * (n + 1)
        prev[0] = 0
        ans = INF

        for t in range(1, n + 1):
            curr = [INF] * (n + 1)
            c = cost[t - 1]
            base = c * k * (t - 1)

            # 维护 min_val = min_{j=t-1..i-1} (prev[j] + c * prefix[j])
            min_val = INF

            for i in range(t, n + 1):
                j = i - 1
                if prev[j] != INF:
                    min_val = min(min_val, prev[j] + c * prefix[j])
                if min_val != INF:
                    curr[i] = base + min_val

            prev = curr
            if prev[n] != INF:
                ans = min(ans, prev[n])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，优化版 O(n^2)（每层 t 的复杂度为 O(n)）
- 空间复杂度：O(n)，滚动数组

## 关键点总结

1. 二维 DP：`dp[i][t]` 表示前 i 个元素分成 t 个子数组的最小代价
2. 代价公式：第 t 个子数组（0-indexed t-1）的代价 = `cost[t-1] * (prefix[j] + k*(t-1))`
3. 内层优化：固定 t 后，系数 cost[t-1] 是常数，可以预先提取

## 易错点

1. 子数组编号从 0 开始，但 dp 中 t 从 1 开始（第 t 个子数组）
2. 代价中 `k * (t-1)` 是 0-indexed 的子数组编号
3. 前缀和 prefix[j] 是前 j 个元素的和（不包含第 j 个子数组的元素）
