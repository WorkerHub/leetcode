## 题目描述

给你一个整数数组 `nums` 和一个整数数组 `queries`，两者均从 0 开始下标。

每次查询 `queries[i]`，若数组非空，则从 `nums` 中移除第一个或最后一个元素，条件是：被移除的元素严格大于 `queries[i]`。

如果无法从任一端移除元素，则停止处理。

返回可以处理的最多查询数量。

**示例 1：**
```
输入：nums = [2,3,2], queries = [0,3,1,2]
输出：3
```

**示例 2：**
```
输入：nums = [3,4,3], queries = [3,2,5]
输出：2
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= queries.length <= 1000`
- `0 <= nums[i], queries[i] <= 10^9`

## 解题思路

区间 DP：设 `dp[i][j]` 为当 `nums` 的剩余部分是 `nums[i..j]` 时，能处理的最多查询数。

但题目是顺序处理查询，需要考虑查询的顺序。

换一种角度：设 `dp[i][j][k]` = 当 `nums` 剩余 `[i, j]`，处理到查询 `queries[k]` 时，能否成功。

更简单的：枚举处理了前 `q` 个查询后，`nums` 的状态是 `[l, r]`（从左删了 `l` 个，从右删了 `n-1-r` 个）。

`dp[l][r]` = 使用 `nums[l..r]` 能处理的最多查询数（从查询序列的对应位置开始）。

实际上，经过 `q` 次操作，共移除了 `q` 个元素，左边移除了 `a` 个，右边移除了 `q-a` 个，所以剩余 `nums[a..n-1-(q-a)]`。

设 `dp[l][r]` = 从 `nums[l..r]` 开始，能处理的最多查询（查询顺序已由 `l` 和 `r` 确定：已处理 `l + (n-1-r)` 个查询）。

## Python 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumProcessableQueries(self, nums: List[int], queries: List[int]) -> int:
        n = len(nums)
        m = len(queries)

        @lru_cache(maxsize=None)
        def dp(l: int, r: int) -> int:
            # 已处理的查询数
            processed = l + (n - 1 - r)
            if processed >= m:
                return 0  # 所有查询已处理完

            q = queries[processed]

            result = 0
            # 从左端移除 nums[l]（需要 nums[l] > q）
            if nums[l] > q:
                result = max(result, 1 + dp(l + 1, r))
            # 从右端移除 nums[r]（需要 nums[r] > q）
            if nums[r] > q:
                result = max(result, 1 + dp(l, r - 1))

            return result

        return dp(0, n - 1)
```

### 方法二：带终止条件优化

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumProcessableQueries(self, nums: List[int], queries: List[int]) -> int:
        n = len(nums)
        m = len(queries)

        @lru_cache(maxsize=None)
        def dp(l: int, r: int) -> int:
            # 已处理查询数 = 从左移除的 l 个 + 从右移除的 (n-1-r) 个
            k = l + (n - 1 - r)
            if k >= m:
                # 所有查询都已处理
                return 0

            q = queries[k]
            res = 0

            if l <= r:  # 数组非空
                if nums[l] > q:
                    res = max(res, 1 + dp(l + 1, r))
                if nums[r] > q and l != r:  # 避免重复计算
                    res = max(res, 1 + dp(l, r - 1))
                elif nums[r] > q:
                    res = max(res, 1 + dp(l + 1, r))  # l == r 时两端相同

            return res

        return dp(0, n - 1)
```

## 复杂度分析

- 时间复杂度：O(n^2 * 1)，状态数 O(n^2)，每个状态 O(1)
- 空间复杂度：O(n^2)，记忆化存储

## 关键点总结

1. 状态 `(l, r)` 唯一确定了已处理的查询数 `l + (n-1-r)`
2. 不需要显式传入查询索引，由 `l` 和 `r` 隐式确定
3. 每个状态只有两种选择：从左移除或从右移除

## 易错点

1. `l == r` 时左右端是同一元素，需要避免重复处理
2. 当 `k >= m` 时，查询已用完，但这意味着所有查询都处理了，直接返回 0（已处理数不增加）
3. 实际上函数返回值是"从当前状态还能额外处理的查询数"，而不是总处理数
