## 题目描述

给你一个整数数组 `nums` 和两个整数 `k`（操作次数）和 `numOperations`。

每次操作可以将数组中某个元素加 1 或减 1（每个元素最多操作 `numOperations` 次，总共最多 `k` 次）。

返回操作后数组中某个元素的**最大频率**（某个值出现的最多次数）。

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= k <= 10^5`
- `0 <= numOperations <= nums.length`
- `1 <= nums[i] <= 10^9`

注意：每个元素最多改变 numOperations 次（总操作次数 k 次）... 再读：k 和 numOperations 的语义需要确认。

实际上：每次操作将某个元素 +1 或 -1，总共最多执行 k 次操作，且对同一个元素最多执行 numOperations 次操作。目标是最大化某个值 v 的出现频率。

## 解题思路

**排序 + 滑动窗口：**

对某个目标值 v，将尽量多的元素通过操作变成 v：
- 对于数组中值为 x 的元素，变成 v 需要 `|x - v|` 次操作，且不超过 numOperations 次（即 `|x - v| <= numOperations`）。
- 总操作次数不超过 k。

排序后，对每个元素 `nums[i]` 作为目标值，用滑动窗口找最大窗口，使得：
1. 窗口中所有元素 x 满足 `|x - nums[i]| <= numOperations`（每个元素变成 nums[i] 的操作次数不超过 numOperations）。
2. 窗口中所有元素变成 nums[i] 的总操作次数不超过 k（即 `sum(nums[i] - x for x in window) <= k`，因为排序后 nums[i] >= 所有 x）。

使用前缀和计算窗口内的总操作次数。

## Python 代码实现

### 方法一：排序 + 滑动窗口 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maxFrequency(self, nums: List[int], k: int, numOperations: int) -> int:
        nums.sort()
        n = len(nums)
        
        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]
        
        ans = 1
        l = 0
        
        for r in range(n):
            target = nums[r]
            
            # 约束1：窗口内每个元素变成 target 的步骤 <= numOperations
            # 即 target - nums[l] <= numOperations
            while target - nums[l] > numOperations:
                l += 1
            
            # 窗口 [l, r]，总操作次数 = target * (r-l+1) - sum(nums[l..r])
            total_ops = target * (r - l + 1) - (prefix[r+1] - prefix[l])
            
            if total_ops <= k:
                ans = max(ans, r - l + 1)
            else:
                # 收缩左指针直到满足总操作约束
                # 用二分找满足条件的最大窗口
                lo, hi = l, r
                while lo < hi:
                    mid = (lo + hi) // 2
                    ops = target * (r - mid + 1) - (prefix[r+1] - prefix[mid])
                    if ops <= k:
                        hi = mid
                    else:
                        lo = mid + 1
                ans = max(ans, r - lo + 1)
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 每次二分
- 空间复杂度：O(n)，前缀和

## 关键点总结

1. 排序后，以每个元素为目标值，利用排序的单调性用滑动窗口。
2. 双重约束：每个元素变化不超过 numOperations，总操作不超过 k。
3. 前缀和快速计算窗口内所有元素到目标值的总操作次数。

## 易错点

1. 两个约束（per-element 和 total），需要同时满足。
2. 排序后目标值 = nums[r]（最大值），窗口内所有元素都 <= target，总操作 = target * size - sum。
3. 滑动窗口 + 二分的组合：先用 numOperations 约束收缩，再用 k 约束找最大窗口。
