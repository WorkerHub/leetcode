## 题目描述

给你一个整数数组 `nums`，定义一个子序列为 **好子序列** 当且仅当子序列中任意两个相邻元素满足后一个 >= 前一个（非递减）。

返回好子序列的数量，结果对 `10^9 + 7` 取模。（注意：空子序列和单元素子序列也是好的）

**示例 1：**

```
输入：nums = [1,2,1]
输出：6
解释：[], [1], [2], [1], [1,2], [2,1]? [1,1]? 
实际：所有非递减子序列
```

**示例 2：**

```
输入：nums = [1,1,1]
输出：8
解释：2^3 = 8（全部子序列均为好子序列）
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

DP + 哈希表：

`dp[v]` = 以值 `v` 结尾的好子序列数量。

对每个元素 `nums[i] = v`：
- 它可以接在所有值 <= v 的子序列后面
- `dp[v] += sum(dp[u] for u <= v) + 1`（+1 代表单独构成子序列）

但计算 `sum(dp[u] for u <= v)` 需要前缀和，可以用树状数组优化。

简化：`dp[v] += dp[v] + 1`（将 v 添加到已有的以 v 结尾的序列，或开始新序列）

实际上对每个值，`dp[v] = dp[v] * 2 + (所有以小于v结尾的dp和)`，但一般题目简化为：

对每个 `v`，`dp[v] = (dp[v] + 1) * 2 - 1`（加上自身），用前缀和维护。

## Python 代码实现

### 方法一：DP + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        # dp[v] = 以值 v 结尾的非递减子序列数量
        dp = defaultdict(int)

        for v in nums:
            # 以 v 结尾的子序列 = 在所有以 <= v 结尾的子序列后面加 v，或单独 v
            # 简化：以 v 结尾的可以接在 v 后面（已有的以 v 结尾的序列再加一个 v）
            # 也可以接在更小值后面
            # dp[v] += sum(dp[u] for u <= v) + 1
            # 由于题目简化（只按值不按下标），用以下方式：
            dp[v] = (dp[v] + 1) % MOD  # 新子序列或已有子序列延伸
            # 若要加上所有比v小的，需树状数组
            # 这里简化版：只考虑相同值可以连接

        # 答案 = sum(dp.values()) + 1 (空子序列)
        return (sum(dp.values()) + 1) % MOD
```

### 方法二：完整 DP（树状数组）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        # dp[v] = 以 v 为最后一个元素的好子序列数
        dp = defaultdict(int)
        prefix = defaultdict(int)  # prefix[v] = sum(dp[u] for u <= v)

        # 离散化
        vals = sorted(set(nums))
        rank = {v: i for i, v in enumerate(vals)}

        # 树状数组
        N = len(vals)
        bit = [0] * (N + 1)

        def update(i, delta):
            i += 1
            while i <= N:
                bit[i] = (bit[i] + delta) % MOD
                i += i & (-i)

        def query(i):
            i += 1
            s = 0
            while i > 0:
                s = (s + bit[i]) % MOD
                i -= i & (-i)
            return s

        ans = 1  # 空子序列
        for v in nums:
            r = rank[v]
            # 以 v 结尾：在所有以 <= v 结尾的后面加 v，或单独开始
            cnt = (query(r) + 1) % MOD
            delta = (cnt - dp[r]) % MOD
            dp[r] = cnt
            update(r, delta)
            ans = (ans + delta) % MOD  # 新增的以 v 结尾的子序列

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)（树状数组），O(n)（简化版）
- 空间复杂度：O(n)

## 关键点总结

1. DP 核心：以 v 结尾的子序列数 = 以 <= v 结尾的子序列数之和 + 1
2. 树状数组维护前缀和，快速查询
3. 注意每个值对应的 dp 可能被多次更新

## 易错点

1. 包含空子序列时答案需 +1
2. 树状数组下标从 1 开始
3. 同一值的多次出现需累加
