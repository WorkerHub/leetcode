## 题目描述

给你一个整数数组 `nums`，返回所有非空子序列的和的 **按位或**（bitwise OR）。

子序列是从数组中删去某些元素（也可以不删去）得到的不改变顺序的数组，这里我们关注所有非空子序列。

**示例 1：**

```
输入：nums = [2, 1, 0, 3]
输出：7
解释：子序列的所有可能的和为 0, 1, 2, 3, 4, 5, 6，按位或为 7。
```

**示例 2：**

```
输入：nums = [0, 0, 0]
输出：0
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

**关键观察**：所有子序列和的 OR，等价于计算哪些 bit 位可以被某个子序列的和"覆盖"。

数学结论：所有可能的子序列和的按位 OR，等于 `(总和) | (总和 - 1) | ... | 0` 中的若干值，但更简洁的观察是：

**前缀和的 OR 即为答案**。原因：
- 前缀和 0, a[0], a[0]+a[1], ..., a[0]+...+a[n-1] 包含了"取前 k 项"的所有和
- 对于任意子序列，其和 <= 总和，且可以通过逐步加元素来覆盖各 bit

实际上，OR 等于将所有元素累加过程中每一步的 OR，即前缀和的 OR 能覆盖答案的所有高位。加上每个单独元素的贡献，最终等于 OR(所有前缀和)。

## Python 代码实现

### 方法一：前缀和 OR（推荐）

```python
from typing import List

class Solution:
    def subsequenceSumOr(self, nums: List[int]) -> int:
        # 所有子序列和的 OR = 所有前缀和（含 0）的 OR
        result = 0
        prefix_sum = 0
        for num in nums:
            prefix_sum += num
            result |= prefix_sum
        # 还需要 OR 上每个单独元素
        for num in nums:
            result |= num
        return result
```

### 方法二：直接累积 OR

```python
from typing import List

class Solution:
    def subsequenceSumOr(self, nums: List[int]) -> int:
        # 维护当前所有可达和的 OR
        # 初始状态：空集合，和为 0
        result = 0
        running_or = 0

        for num in nums:
            # 新加入 num，所有之前的和都可以再加上 num
            # running_or | (running_or + num) 近似，但精确做法是累加前缀和
            running_or += num
            result |= running_or
            result |= num

        return result
```

## 复杂度分析

- 时间复杂度：O(n)，只需一次遍历
- 空间复杂度：O(1)，只用常数额外空间

## 关键点总结

1. 子序列和的 OR 具有单调性：前缀和的 OR 覆盖了最高位的所有贡献
2. 每个元素本身（单元素子序列）的值也要参与 OR
3. 总和最大为 n * 10^9 ≈ 10^14，需要注意 Python 支持大整数

## 易错点

1. 不要遗漏单元素子序列的贡献（单个 nums[i]）
2. 不需要枚举所有 2^n 个子序列，利用前缀和性质可以 O(n) 解决
3. 空子序列的和为 0，不影响 OR 结果（0 | x = x）
