## 题目描述

给你一个下标从 0 开始的二进制字符串 `s`，其中 `s[i]` 为 `'0'` 表示第 i 栋建筑是公寓，`'1'` 表示写字楼。

你需要选择 3 栋建筑，使得它们的下标**严格递增**，且相邻建筑的类型**不同**（即必须交替出现 `010` 或 `101`）。

返回满足条件的选法数量。

**示例 1：**
```
输入：s = "001101"
输出：6
解释：满足条件的三元组下标：(0,2,3),(0,2,4),(0,3,4),(1,2,3),(1,2,4),(1,3,4)。
```

**示例 2：**
```
输入：s = "11100"
输出：0
```

## 解题思路

遍历中间建筑（索引 j），分别统计：
- 左侧中 `s[i] != s[j]` 的数量（`left_diff`）
- 右侧中 `s[k] != s[j]` 的数量（`right_diff`）

以 j 为中间建筑的方案数 = `left_diff * right_diff`。

可以在遍历时维护以下计数：
- `c0`：已遍历位置中 `'0'` 的数量
- `c1`：已遍历位置中 `'1'` 的数量
- `c01`：`'01'` 子串的数量（以 `j` 当前位为结尾的 `01`）
- `c10`：`'10'` 子串的数量

从左向右遍历，每遇到 `'0'`：`c010 += c10`，`c01 += c1`，`c0 += 1`。
每遇到 `'1'`：`c101 += c01`，`c10 += c0`，`c1 += 1`。

## 代码实现

### 方法一：前缀计数（推荐）

```python
class Solution:
    def numberOfWays(self, s: str) -> int:
        # c0, c1: 已遍历的 '0' 和 '1' 数量
        # c01: 以当前位置结尾的 '01' 子序列数
        # c10: 以当前位置结尾的 '10' 子序列数
        c0 = c1 = c01 = c10 = 0
        ans = 0

        for ch in s:
            if ch == '0':
                # 新的 '010'：每个 c10 都能和这个 '0' 组成
                ans += c10
                # 新的 '01'：每个 c1 都能和这个 '0' 组成
                c01 += c1
                c0 += 1
            else:  # ch == '1'
                # 新的 '101'：每个 c01 都能和这个 '1' 组成
                ans += c01
                # 新的 '10'：每个 c0 都能和这个 '1' 组成
                c10 += c0
                c1 += 1

        return ans
```

### 方法二：前缀和 + 枚举中间元素

```python
class Solution:
    def numberOfWays(self, s: str) -> int:
        n = len(s)
        # 前缀中 0 的数量
        prefix0 = [0] * (n + 1)
        prefix1 = [0] * (n + 1)
        for i, ch in enumerate(s):
            prefix0[i + 1] = prefix0[i] + (1 if ch == '0' else 0)
            prefix1[i + 1] = prefix1[i] + (1 if ch == '1' else 0)

        ans = 0
        for j in range(1, n - 1):
            if s[j] == '0':
                # 左侧 1 的数量 * 右侧 1 的数量
                left1 = prefix1[j]
                right1 = prefix1[n] - prefix1[j + 1]
                ans += left1 * right1
            else:
                # 左侧 0 的数量 * 右侧 0 的数量
                left0 = prefix0[j]
                right0 = prefix0[n] - prefix0[j + 1]
                ans += left0 * right0

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)（方法一），O(n)（方法二）。

## 关键点总结

1. 只有 `010` 和 `101` 两种合法模式。
2. 枚举中间元素，左侧异类数量 * 右侧异类数量 = 以该元素为中间的方案数。
3. 方法一动态维护状态，空间更优。

## 易错点

- 三元组下标严格递增，用前缀和/动态计数统计左右元素数量。
- 注意中间元素是 `'0'` 时左右需要 `'1'`，反之亦然。
