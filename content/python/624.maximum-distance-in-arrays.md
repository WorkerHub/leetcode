## 题目描述

给定 `m` 个数组，每个数组都已经按照升序排列。现在你需要从两个不同的数组中各选择一个数字，使得这两个数字之间的距离最大。两个数字 `a` 和 `b` 之间的距离定义为它们差的绝对值 `|a - b|`。

返回最大距离。

**示例 1：**

```
输入：arrays = [[1,2,3],[4,5],[1,2,3]]
输出：4
解释：
可以选择 arrays[0] 的 1 和 arrays[1] 的 5，距离为 |1-5| = 4。
或选择 arrays[2] 的 1 和 arrays[1] 的 5，距离也是 4。
```

**示例 2：**

```
输入：arrays = [[1],[1]]
输出：0
```

**提示：**
- `m == arrays.length`
- `2 <= m <= 10^5`
- `1 <= arrays[i].length <= 500`
- `-10^4 <= arrays[i][j] <= 10^4`
- `arrays[i]` 按升序排列
- 所有数组中最多有 `10^5` 个整数

## 解题思路

由于每个数组都是升序排列的，所以：
- 每个数组的最小值是第一个元素 `arrays[i][0]`
- 每个数组的最大值是最后一个元素 `arrays[i][-1]`

要使距离最大，我们需要选择一个数组的最大值和另一个数组的最小值。

**关键观察：**
1. 距离只能在不同数组之间计算
2. 每个数组已排序，只需考虑首尾元素
3. 最大距离只可能是某个数组的最大值减去另一个数组的最小值

**贪心策略：**
- 维护到目前为止遇到的全局最小值和全局最大值
- 对于当前数组，计算：
  - 当前数组最大值 - 全局最小值
  - 全局最大值 - 当前数组最小值
- 更新全局最大距离
- 更新全局最小值和最大值

为什么这样是正确的？因为我们逐个处理数组，当处理到数组 `i` 时：
- 全局最小值和最大值来自之前的数组（保证了不同数组）
- 当前数组的首尾元素与之前的极值组合，能产生最大距离

## Python 代码实现

### 方法一：一次遍历贪心（推荐）

```python
from typing import List

class Solution:
    def maxDistance(self, arrays: List[List[int]]) -> int:
        """
        计算不同数组元素之间的最大距离
        
        参数:
            arrays: m 个升序数组
        
        返回:
            最大距离
        """
        # 初始化全局最小值和最大值（使用第一个数组）
        global_min = arrays[0][0]
        global_max = arrays[0][-1]
        max_distance = 0
        
        # 从第二个数组开始遍历
        for i in range(1, len(arrays)):
            current_min = arrays[i][0]
            current_max = arrays[i][-1]
            
            # 计算当前数组与之前数组的最大距离
            # 情况1：当前最大值 - 之前最小值
            distance1 = abs(current_max - global_min)
            # 情况2：之前最大值 - 当前最小值
            distance2 = abs(global_max - current_min)
            
            # 更新最大距离
            max_distance = max(max_distance, distance1, distance2)
            
            # 更新全局最小值和最大值
            global_min = min(global_min, current_min)
            global_max = max(global_max, current_max)
        
        return max_distance
```

**时间复杂度：** O(m)，m 是数组个数，只需遍历一次  
**空间复杂度：** O(1)，只使用常数额外空间

### 方法二：简化版（无绝对值）

```python
class Solution:
    def maxDistance(self, arrays: List[List[int]]) -> int:
        """
        简化版本，利用升序特性去掉绝对值
        """
        min_val = arrays[0][0]
        max_val = arrays[0][-1]
        result = 0
        
        for i in range(1, len(arrays)):
            # 由于数组升序，最大值总是在最后，最小值总是在开头
            # 所以不需要绝对值，直接相减即可
            result = max(result, 
                        arrays[i][-1] - min_val,  # 当前最大 - 之前最小
                        max_val - arrays[i][0])   # 之前最大 - 当前最小
            
            # 更新全局极值
            min_val = min(min_val, arrays[i][0])
            max_val = max(max_val, arrays[i][-1])
        
        return result
```

### 方法三：暴力解法（仅用于对比）

```python
class Solution:
    def maxDistance(self, arrays: List[List[int]]) -> int:
        """
        暴力解法：枚举所有数组对
        时间复杂度 O(m^2)，不推荐但易于理解
        """
        max_dist = 0
        
        # 枚举所有数组对
        for i in range(len(arrays)):
            for j in range(i + 1, len(arrays)):
                # 数组 i 的最小值和数组 j 的最大值
                dist1 = abs(arrays[i][0] - arrays[j][-1])
                # 数组 i 的最大值和数组 j 的最小值
                dist2 = abs(arrays[i][-1] - arrays[j][0])
                # 更新最大距离
                max_dist = max(max_dist, dist1, dist2)
        
        return max_dist
```

**时间复杂度：** O(m^2)  
**空间复杂度：** O(1)

## 复杂度分析

**方法一、二（推荐）：**
- 时间复杂度：O(m)，m 是数组个数，只需遍历一次所有数组
- 空间复杂度：O(1)，只使用常数个变量

**方法三（暴力）：**
- 时间复杂度：O(m^2)，需要枚举所有数组对
- 空间复杂度：O(1)

以示例 1 为例：`arrays = [[1,2,3],[4,5],[1,2,3]]`

```
初始化（使用第一个数组 [1,2,3]）：
global_min = 1
global_max = 3
max_distance = 0

步骤 1：处理数组 [4,5]
current_min = 4, current_max = 5
计算距离：

步骤 2：处理数组 [1,2,3]
current_min = 1, current_max = 3

  - distance1 = |3 - 1| = 2
  - distance2 = |5 - 1| = 4

```

## 关键点总结

1. **利用升序特性**：每个数组的最小值和最大值分别在首尾
2. **贪心思想**：全局最大距离只可能来自某个数组的极值与另一个数组的极值
3. **遍历顺序重要**：从第二个数组开始，确保比较的是不同数组
4. **维护全局极值**：边遍历边更新全局最小值和最大值
5. **无需绝对值**：由于是最大值减最小值，结果总是非负的

## 易错点

1. **使用同一个数组**：题目要求从不同数组中选择，不能从同一个数组选两个数
2. **忘记更新全局极值**：每处理一个数组后，要更新 global_min 和 global_max
3. **更新顺序错误**：应该先计算距离，再更新全局极值（否则可能使用同一数组）
4. **边界情况**：当只有两个数组时也要正确处理
5. **符号问题**：虽然题目要求绝对值，但由于都是最大减最小，可以省略
