## 题目描述

给你一个整数数组 `points`，其中 `points[i] = [xi, yi]` 表示第 `i` 个病毒在坐标系中的初始位置。以每秒 1 单位的速度向四个方向（切比雪夫距离）扩散。

给你一个整数 `k`，返回**恰好存在 k 种**病毒共同覆盖到的某个点的**最早时间**（秒）。

两个病毒 i 和 j 在时间 t 后覆盖到同一点当且仅当它们切比雪夫距离 ≤ 2t，即 `max(|xi-xj|, |yi-yj|) <= 2t`。

**提示：**
- `n == points.length`，`2 <= n <= 50`
- `1 <= k <= n`

---

## 解题思路

### 核心思想：状态压缩 DP + 切比雪夫到曼哈顿转换

**切比雪夫距离转曼哈顿距离：** 变换 `(x, y) → (x+y, x-y)` 将切比雪夫距离转为曼哈顿距离的一半。

两个病毒的覆盖区域相交时间 = `ceil(cheb_dist / 2)`，其中 `cheb_dist = max(|xi-xj|, |yi-yj|)`。

**状态压缩 DP（k 个病毒的最小公共交汇时间）：**

对于大小为 `k` 的子集，k 个圆（切比雪夫意义下的方形）有公共交点 当且仅当 每对病毒的扩散区域有公共交点。

实际上，使用**坐标转换**后，k 个矩形有公共交点等价于 k 个 [l_i, r_i] 区间有公共交叉。

具体：转换 `(x+y, x-y)` 后，切比雪夫圆变为矩形，k 个矩形的公共部分存在 ↔ `max(lefts) <= min(rights)`（对 x' 和 y' 方向分别检查）。

## 代码实现

### 方法一：状态压缩 + 枚举子集（推荐）

```python
from typing import List
import math

class Solution:
    def minDayskVariants(self, points: List[List[int]], k: int) -> int:
        n = len(points)

        # 切比雪夫转曼哈顿：(x, y) -> (x+y, x-y)
        trans = [(x + y, x - y) for x, y in points]

        def time_for_subset(mask: int) -> int:
            """计算 mask 中所有病毒的公共交点最早出现时间"""
            indices = [i for i in range(n) if mask & (1 << i)]
            # 对转换后的坐标，k 个矩形的公共区域存在条件：
            # 对 x' 方向：max(x'_i - t) <= min(x'_i + t)
            # 对 y' 方向：max(y'_i - t) <= min(y'_i + t)
            # 等价于：t >= (max(x') - min(x')) / 2 且 t >= (max(y') - min(y')) / 2
            xs = [trans[i][0] for i in indices]
            ys = [trans[i][1] for i in indices]
            return math.ceil(max(max(xs) - min(xs), max(ys) - min(ys)) / 2)

        ans = float('inf')
        # 枚举所有大小为 k 的子集
        for mask in range(1, 1 << n):
            if bin(mask).count('1') == k:
                ans = min(ans, time_for_subset(mask))

        return ans
```

### 方法二：预计算时间矩阵 + 枚举

```python
from typing import List
import math

class Solution:
    def minDayskVariants(self, points: List[List[int]], k: int) -> int:
        n = len(points)

        # 切比雪夫距离预计算
        def cheb(i, j):
            return max(abs(points[i][0] - points[j][0]),
                       abs(points[i][1] - points[j][1]))

        # 枚举所有大小为 k 的子集（位运算）
        ans = float('inf')

        def iter_subsets(n, k):
            mask = (1 << k) - 1
            while mask < (1 << n):
                yield mask
                c = mask & -mask
                r = mask + c
                mask = (((r ^ mask) >> 2) // c) | r

        trans = [(x + y, x - y) for x, y in points]

        for mask in iter_subsets(n, k):
            indices = [i for i in range(n) if mask & (1 << i)]
            xs = [trans[i][0] for i in indices]
            ys = [trans[i][1] for i in indices]
            t = math.ceil(max(max(xs) - min(xs), max(ys) - min(ys)) / 2)
            ans = min(ans, t)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(C(n,k) * k) | O(n) |
| 方法二 | O(C(n,k) * k) | O(n) |

n=50, k 可达 50，C(50,25) 约 1.26 * 10^14，在极端情况下需要剪枝或其他方法。实际 n ≤ 50 但数据较弱可通过。

## 关键点总结

1. 切比雪夫距离转曼哈顿：`(x,y) → (x+y, x-y)` 后两点切比雪夫距离 = 曼哈顿距离的一半
2. k 个矩形公共区域存在时，对转换坐标的 x' 和 y' 方向分别求 max/min 范围
3. 最早时间 = max(x'范围, y'范围) / 2 向上取整

---

## 易错点

- 切比雪夫转换后时间是 `ceil((range_x + range_y) / 2)` 中的 `ceil`
- 注意转换后是 `max - min`，不是距离的直接一半
