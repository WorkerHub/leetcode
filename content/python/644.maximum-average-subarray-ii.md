## 题目描述

给定一个包含 n 个整数的数组 nums 和一个整数 k，找出长度大于等于 k 的连续子数组的最大平均值，并返回这个值。答案的计算误差在 10^-5 以内即可接受。

**示例 1:**
```
输入: nums = [1,12,-5,-6,50,3], k = 4
输出: 12.75000
解释: 
- 长度为 4 时,最大平均值为 (12-5-6+50)/4 = 51/4 = 12.75
- 长度为 5 时,最大平均值为 (12-5-6+50+3)/5 = 54/5 = 10.8
- 长度为 6 时,最大平均值为 (1+12-5-6+50+3)/6 = 55/6 = 9.16667
因此返回 12.75
```

**示例 2:**
```
输入: nums = [5], k = 1
输出: 5.00000
```

**提示:**
- n == nums.length
- 1 <= k <= n <= 10^4
- -10^4 <= nums[i] <= 10^4

## 解题思路

这道题的核心难点在于:长度不固定,需要在所有长度 >= k 的子数组中找最大平均值。

**关键观察:**
1. 如果一个平均值 avg 是可以达到的,那么小于 avg 的值也一定可以达到
2. 这种单调性提示我们可以用二分查找

**二分查找思路:**
- 二分答案 mid(表示平均值)
- 对于每个 mid,判断是否存在长度 >= k 的子数组,其平均值 >= mid
- 判断方法:将每个元素减去 mid,问题转化为是否存在和 >= 0 的子数组

**如何判断存在和 >= 0 的子数组:**
1. 计算前缀和数组 preSum
2. 对于每个位置 i >= k,维护 preSum[0...i-k] 的最小值
3. 如果 preSum[i] - minPreSum >= 0,说明存在满足条件的子数组

**为什么这样做:**
- 子数组 [j, i] 的和 = preSum[i] - preSum[j-1]
- 要使和最大,需要 preSum[j-1] 尽可能小
- 同时要保证 i - j + 1 >= k,即 j >= i - k + 1

## Python 代码实现

### 方法一:二分查找 + 前缀和(推荐)

```python
from typing import List

class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        def check(mid: float) -> bool:
            """检查是否存在长度>=k的子数组,平均值>=mid"""
            # 将每个元素减去mid
            n = len(nums)
            preSum = [0] * (n + 1)
            
            # 计算前缀和
            for i in range(n):
                preSum[i + 1] = preSum[i] + nums[i] - mid
            
            # 维护前k个位置的最小前缀和
            minPre = 0
            
            # 从位置k开始检查
            for i in range(k, n + 1):
                # 更新最小前缀和(可以选择的左边界)
                if i > k:
                    minPre = min(minPre, preSum[i - k])
                
                # 如果存在满足条件的子数组
                if preSum[i] - minPre >= 0:
                    return True
            
            return False
        
        # 二分查找答案
        left, right = min(nums), max(nums)
        
        # 精度要求10^-5
        while right - left > 1e-5:
            mid = (left + right) / 2
            if check(mid):
                left = mid
            else:
                right = mid
        
        return left
```

### 方法二:优化版本

```python
from typing import List

class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        def check(avg: float) -> bool:
            """检查是否存在平均值>=avg的长度>=k的子数组"""
            n = len(nums)
            cur_sum = 0
            
            # 先计算前k个元素的和
            for i in range(k):
                cur_sum += nums[i] - avg
            
            if cur_sum >= 0:
                return True
            
            # 前缀和的最小值
            min_pre_sum = 0
            pre_sum = 0
            
            # 从k开始向后滑动
            for i in range(k, n):
                cur_sum += nums[i] - avg
                pre_sum += nums[i - k] - avg
                min_pre_sum = min(min_pre_sum, pre_sum)
                
                # 当前和减去最小前缀和
                if cur_sum >= min_pre_sum:
                    return True
            
            return False
        
        # 二分搜索
        left, right = min(nums), max(nums)
        
        while right - left > 1e-5:
            mid = (left + right) / 2
            if check(mid):
                left = mid
            else:
                right = mid
        
        return left
```

## 复杂度分析

**方法一:**
- 时间复杂度: O(n * log(max - min) / ε),其中 ε = 10^-5 是精度要求
  - 二分查找次数约为 log((max - min) / ε)
  - 每次 check 函数需要 O(n) 时间
- 空间复杂度: O(n),需要存储前缀和数组

**方法二:**
- 时间复杂度: O(n * log(max - min) / ε)
- 空间复杂度: O(1),只使用常数额外空间

## 关键点总结

1. **二分答案**: 利用平均值的单调性,二分搜索最大平均值
2. **问题转化**: 将"平均值 >= mid"转化为"和 >= 0"(减去 mid 后)
3. **前缀和优化**: 使用前缀和快速计算子数组的和
4. **维护最小值**: 维护可选左边界的最小前缀和,使子数组和最大
5. **精度控制**: 浮点数二分需要注意精度,通常用 1e-5 或 1e-6

## 易错点

1. **边界条件**: 注意子数组长度必须 >= k,不是恰好等于 k
2. **精度问题**: 浮点数比较要考虑精度,用 `right - left > 1e-5` 而不是 `left != right`
3. **前缀和索引**: preSum[i] 表示前 i 个元素的和,注意下标对应关系
4. **最小值更新时机**: minPre 只能从 preSum[0...i-k] 中选,保证子数组长度 >= k
