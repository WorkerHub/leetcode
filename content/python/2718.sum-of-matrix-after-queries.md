## 题目描述

给你一个整数 `n` 和一个下标从 **0** 开始的二维数组 `queries`，其中 `queries[i] = [type, index, val]`。

初始时，有一个 `n x n` 的零矩阵。对每个查询：
- 若 `type == 0`，将第 `index` 行所有元素设置为 `val`
- 若 `type == 1`，将第 `index` 列所有元素设置为 `val`

返回所有查询执行完后矩阵的元素之和。

**示例：**
```
输入：n = 3, queries = [[0,0,1],[1,2,2],[0,2,3],[1,0,4]]
输出：23
```

**提示：**
- `1 <= n <= 10^4`
- `1 <= queries.length <= 5 * 10^4`

## 解题思路

**逆序处理 + 哈希集合**：

从最后一个查询往前处理，后面的查询会覆盖前面的结果。

- 维护已被覆盖的行集合 `seen_rows` 和列集合 `seen_cols`
- 逆序遍历查询，若当前行/列已被后续查询覆盖，跳过
- 若行 `r` 未被覆盖：该行的贡献 = `val * (n - |seen_cols|)`（未被列覆盖的格子数）
- 若列 `c` 未被覆盖：该列的贡献 = `val * (n - |seen_rows|)`（未被行覆盖的格子数）

## Python 代码实现

### 方法一：逆序处理（推荐）

```python
from typing import List

class Solution:
    def matrixSumQueries(self, n: int, queries: List[List[int]]) -> int:
        seen_rows = set()
        seen_cols = set()
        ans = 0

        # 逆序处理，后面的查询优先级更高
        for qtype, index, val in reversed(queries):
            if qtype == 0:  # 行操作
                if index not in seen_rows:
                    # 该行中，未被列操作覆盖的格子数
                    ans += val * (n - len(seen_cols))
                    seen_rows.add(index)
            else:  # 列操作
                if index not in seen_cols:
                    # 该列中，未被行操作覆盖的格子数
                    ans += val * (n - len(seen_rows))
                    seen_cols.add(index)

        return ans
```

## 复杂度分析

- 时间复杂度：O(q)，q 为查询数量
- 空间复杂度：O(n)，行列集合大小

## 关键点总结

1. 后续查询会覆盖前面的结果，逆序处理确保每行/列只计算一次
2. 行 `r` 的贡献：`val * (n - 已覆盖列数)`，因为列操作会覆盖行中的某些格子
3. 同理，列 `c` 的贡献：`val * (n - 已覆盖行数)`

## 易错点

1. 行列操作会互相影响（行操作的贡献减去已被列覆盖的部分）
2. 同一行/列的重复操作，只取最后一次（先遇到的，即逆序中最先出现的）
