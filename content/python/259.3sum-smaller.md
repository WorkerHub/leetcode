## 题目描述

给定一个长度为 n 的整数数组 `nums` 和一个目标值 `target`，找出 `nums` 中满足以下条件的三元组 `(i, j, k)` 的数量：

- `0 <= i < j < k < n`
- `nums[i] + nums[j] + nums[k] < target`

**示例 1：**

```
输入：nums = [-2,0,1,3], target = 2
输出：2
解释：满足条件的三元组为：
[-2,0,1] 因为 (-2) + 0 + 1 = -1 < 2
[-2,0,3] 因为 (-2) + 0 + 3 = 1 < 2
```

**示例 2：**

```
输入：nums = [], target = 0
输出：0
```

**示例 3：**

```
输入：nums = [0], target = 0
输出：0
```

**提示：**
- `n == nums.length`
- `0 <= n <= 3500`
- `-100 <= nums[i] <= 100`
- `-100 <= target <= 100`

## 解题思路

这道题是经典的"三数之和"问题的变种，不需要找具体的三元组，只需要统计数量。

核心思想：
1. 先对数组排序
2. 固定第一个数，用双指针寻找另外两个数
3. 由于数组有序，可以快速统计满足条件的组合数

关键观察：
- 排序后，如果 `nums[i] + nums[left] + nums[right] < target`
- 那么 `left` 和 `left+1, left+2, ..., right-1` 之间的所有数都满足条件
- 可以一次性统计 `right - left` 个三元组

## Python 代码实现

### 方法一：排序 + 双指针（推荐）⭐

```python
from typing import List

class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        """
        排序 + 双指针
        时间复杂度：O(n^2)
        空间复杂度：O(1) 或 O(log n)，取决于排序算法
        """
        n = len(nums)
        if n < 3:
            return 0
        
        # 排序
        nums.sort()
        count = 0
        
        # 固定第一个数
        for i in range(n - 2):
            # 双指针寻找另外两个数
            left, right = i + 1, n - 1
            
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                
                if total < target:
                    # 如果和小于目标值
                    # 那么 left 和 [left+1, right-1] 之间的所有数都满足条件
                    count += right - left
                    left += 1
                else:
                    # 和太大，缩小右边界
                    right -= 1
        
        return count
```

### 方法二：详细注释版本

```python
from typing import List

class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        """
        带详细解释的双指针方法
        """
        n = len(nums)
        if n < 3:
            return 0
        
        nums.sort()
        count = 0
        
        for i in range(n - 2):
            left = i + 1
            right = n - 1
            
            while left < right:
                current_sum = nums[i] + nums[left] + nums[right]
                
                if current_sum < target:
                    # 关键点：如果 nums[i] + nums[left] + nums[right] < target
                    # 由于数组有序，nums[left] < nums[left+1] < ... < nums[right]
                    # 所以 nums[i] + nums[left] + nums[j] 对于所有 j ∈ [left+1, right] 都 < target
                    # 这样就有 (right - left) 个满足条件的三元组
                    count += right - left
                    # 移动左指针，继续寻找
                    left += 1
                else:
                    # 和太大，需要减小，移动右指针
                    right -= 1
        
        return count
```

### 方法三：暴力解法（用于对比）

```python
from typing import List

class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        """
        暴力枚举所有三元组
        时间复杂度：O(n^3)
        空间复杂度：O(1)
        不推荐，仅用于理解题意
        """
        n = len(nums)
        count = 0
        
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[i] + nums[j] + nums[k] < target:
                        count += 1
        
        return count
```

### 方法四：排序 + 二分查找

```python
from typing import List
import bisect

class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        """
        排序 + 二分查找
        时间复杂度：O(n^2 log n)
        空间复杂度：O(1)
        """
        n = len(nums)
        if n < 3:
            return 0
        
        nums.sort()
        count = 0
        
        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                # 寻找满足 nums[i] + nums[j] + nums[k] < target 的最大 k
                # 即 nums[k] < target - nums[i] - nums[j]
                target_val = target - nums[i] - nums[j]
                
                # 二分查找第一个 >= target_val 的位置
                k = bisect.bisect_left(nums, target_val, j + 1, n)
                
                # [j+1, k-1] 范围内的数都满足条件
                count += k - j - 1
        
        return count
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：O(n^2)，排序 O(n log n) + 双重循环 O(n^2)
- 空间复杂度：O(1) 或 O(log n)

**方法三（暴力）：**
- 时间复杂度：O(n^3)
- 空间复杂度：O(1)

**方法四（二分查找）：**
- 时间复杂度：O(n^2 log n)
- 空间复杂度：O(1)

## 图解示例

以 `nums = [-2,0,1,3], target = 2` 为例：

```
排序后：nums = [-2, 0, 1, 3]
索引：         0   1  2  3

i=0, nums[i]=-2:
  left=1(0), right=3(3)
  sum = -2 + 0 + 3 = 1 < 2 ✓
  → 有 (3-1) = 2 个三元组：
    [-2, 0, 1]: -2 + 0 + 1 = -1 < 2 ✓
    [-2, 0, 3]: -2 + 0 + 3 = 1 < 2 ✓
  → count = 2, left = 2
  
  left=2(1), right=3(3)
  sum = -2 + 1 + 3 = 2 >= 2 ✗
  → right = 2
  
  left=2, right=2, 循环结束

i=1, nums[i]=0:
  left=2(1), right=3(3)
  sum = 0 + 1 + 3 = 4 >= 2 ✗
  → right = 2
  
  left=2, right=2, 循环结束

最终结果：count = 2
```

详细解释为什么 `count += right - left`：

```
当 i=0, left=1, right=3 时：
nums[i] + nums[left] + nums[right] = -2 + 0 + 3 = 1 < 2

因为数组有序：
- nums[2] = 1 < nums[3] = 3
- 所以 nums[0] + nums[1] + nums[2] = -2 + 0 + 1 = -1 < 1 < 2

即：从 left 到 right-1 的所有位置都可以和 nums[i], nums[left] 组成满足条件的三元组
共有 right - left = 3 - 1 = 2 个
```

## 关键点总结

1. **排序是关键**：排序后可以使用双指针优化
2. **双指针技巧**：左右指针根据和的大小调整
3. **计数优化**：利用有序性质，一次性统计多个三元组
4. **不需要去重**：题目只要求统计数量，不需要返回具体三元组
5. **公式理解**：`count += right - left` 是核心

## 易错点

1. **理解计数公式**
   ```python
   # 错误：只统计当前一个
   if total < target:
       count += 1
   
   # 正确：统计所有满足条件的
   if total < target:
       count += right - left
   ```

2. **循环边界**
   ```python
   # 错误：i 可以到 n-1
   for i in range(n):
   
   # 正确：至少要留两个位置给 left 和 right
   for i in range(n - 2):
   ```

3. **指针移动方向**
   ```python
   # 当 sum < target 时，要增大和，移动 left
   if total < target:
       count += right - left
       left += 1  # 向右移动
   else:
       right -= 1  # 向左移动
   ```

4. **边界条件**
   ```python
   # 数组长度小于 3 时，无法组成三元组
   if n < 3:
       return 0
   ```

```python
# k数之和小于 target 的通用模板
def kSumSmaller(nums, k, target):
    nums.sort()
    
    def helper(start, k, target):
        if k == 2:
            # 双指针
            count = 0
            left, right = start, len(nums) - 1
            while left < right:
                if nums[left] + nums[right] < target:
                    count += right - left
                    left += 1
                else:
                    right -= 1
            return count
        
        # k > 2，固定第一个数，递归
        count = 0
        for i in range(start, len(nums) - k + 1):
            count += helper(i + 1, k - 1, target - nums[i])
        return count
    
    return helper(0, k, target)
```
