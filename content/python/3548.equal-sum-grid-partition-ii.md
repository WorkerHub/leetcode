## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`，将其沿某条水平线或垂直线分割成两个非空部分，使得两部分的元素之和相等。本题与 3546 的区别是允许将切割线上的某一行/列中的某个元素移到另一侧（额外操作），判断是否可能实现等分。

**示例 1：**

```
输入：grid = [[1,3],[2,4]]
输出：true
解释：总和为 10，需要 5+5。水平切割：[1,3]=4，[2,4]=6，差为2。
     可以将第2行的元素 2 移到上半部分，使 4+2=6，6-2=4... 
     或切割线上元素可贡献到任一侧。
```

**提示：**
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 10^5`

## 解题思路

与 3546 不同，允许额外将切割线上的某个元素移到另一侧。

枚举所有切割位置（水平和垂直），对每个切割位置：
1. 计算两侧和
2. 若两侧和相等，直接返回 true
3. 若两侧差为 `d = |sum_top - sum_bottom|`，检查切割线上是否存在值为 `d/2` 的元素（若 d 为偶数）

用哈希集合存储切割线上的元素值，O(1) 查询。

## Python 代码实现

### 方法一：前缀和 + 哈希集合（推荐）

```python
from typing import List

class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)

        # 检查水平切割（在行 i 和 i+1 之间，行 i 是切割线）
        # 枚举切割线为第 i 行
        row_prefix = 0
        for i in range(m):
            row_prefix += sum(grid[i])
            if i < m - 1:
                # 切割：上半为 0..i，下半为 i+1..m-1
                top = row_prefix
                bottom = total - row_prefix
                if top == bottom:
                    return True
                # 尝试将切割线（第 i 行）的某个元素移到另一侧
                diff = abs(top - bottom)
                if diff % 2 == 0:
                    half_diff = diff // 2
                    # 若 top > bottom，需从切割线（第 i 行）移 half_diff 到下半
                    # 或从下一行（第 i+1 行）移元素到上半
                    cut_row_vals = set(grid[i]) | set(grid[i+1])
                    if half_diff in cut_row_vals:
                        return True

        # 检查垂直切割
        col_prefix = 0
        for j in range(n):
            col_prefix += sum(grid[r][j] for r in range(m))
            if j < n - 1:
                left = col_prefix
                right = total - col_prefix
                if left == right:
                    return True
                diff = abs(left - right)
                if diff % 2 == 0:
                    half_diff = diff // 2
                    cut_col_vals = set(grid[r][j] for r in range(m)) | set(grid[r][j+1] for r in range(m))
                    if half_diff in cut_col_vals:
                        return True

        return False
```

### 方法二：更精确的边界处理

```python
from typing import List

class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)

        # 水平切割：在切割位置 i（0 到 m-2）
        # 上半 = 前 i+1 行，下半 = 后 m-i-1 行
        prefix_rows = []
        s = 0
        for i in range(m):
            s += sum(grid[i])
            prefix_rows.append(s)

        for i in range(m - 1):
            top = prefix_rows[i]
            bottom = total - top
            if top == bottom:
                return True
            diff = top - bottom  # 可正可负
            # 移动切割线附近一个元素（grid[i] 或 grid[i+1] 中的某个值 v）
            # 移动 v 会改变差值 2v
            # 若从上到下移 v：新 top = top - v，新 diff = (top-v) - (bottom+v) = diff - 2v
            # 若从下到上移 v：新 diff = diff + 2v
            # 需要新 diff = 0，即 v = diff / 2（从较大侧移出）
            if diff % 2 == 0:
                target = diff // 2  # 正值：从上半移出
                for val in grid[i]:
                    if val == target:
                        return True
                target2 = -diff // 2  # 正值：从下半移出
                for val in grid[i+1]:
                    if val == target2:
                        return True

        # 垂直切割
        prefix_cols = []
        s = 0
        for j in range(n):
            s += sum(grid[r][j] for r in range(m))
            prefix_cols.append(s)

        for j in range(n - 1):
            left = prefix_cols[j]
            right = total - left
            if left == right:
                return True
            diff = left - right
            if diff % 2 == 0:
                target = diff // 2
                for r in range(m):
                    if grid[r][j] == target:
                        return True
                target2 = -diff // 2
                for r in range(m):
                    if grid[r][j+1] == target2:
                        return True

        return False
```

## 复杂度分析

- 时间复杂度：O(m * n)，枚举所有切割位置
- 空间复杂度：O(m + n)

## 关键点总结

1. 枚举水平和垂直切割位置
2. 检查是否可以通过移动切割线附近一个元素实现等分
3. 移动元素 v 后差值改变 2v，需要找到切割线上值为 `|diff|/2` 的元素

## 易错点

1. 差值必须为偶数才可能找到合适的移动元素
2. 只允许移动切割线相邻的一行/列中的元素
3. 移动方向：从较大侧移出，目标值为 `diff/2`（正数）
