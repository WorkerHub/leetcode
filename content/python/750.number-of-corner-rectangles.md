## 题目描述

给定一个只包含 0 和 1 的网格，找出其中由 1 形成的角矩形的数量。

一个角矩形是由四个不同的 1 在网格的四个不同位置形成的轴对称的形状。

## Python 代码实现

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCornerRectangles(self, grid: List[List[int]]) -> int:
        count = 0
        m, n = len(grid), len(grid[0])
        
        for r1 in range(m):
            for r2 in range(r1 + 1, m):
                # 统计两行中同时为 1 的列数
                matches = 0
                for c in range(n):
                    if grid[r1][c] == 1 and grid[r2][c] == 1:
                        matches += 1
                
                # 从 matches 个列中选 2 个
                count += matches * (matches - 1) // 2
        
        return count
```

## 复杂度分析

- 时间复杂度：O(m^2 * n)
- 空间复杂度：O(1)

## 关键点总结

1. 枚举所有行对
2. 统计两行中同时为1的列数
3. 使用组合数学计算矩形数量
