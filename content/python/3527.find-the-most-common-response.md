## 题目描述

给定一个二维字符串数组 `responses`，其中 `responses[i]` 是第 `i` 个调查对象的回答列表。对每个调查对象，先对其回答去重，再统计所有调查对象中每个回答的出现频率（每个调查对象最多贡献一次）。返回出现频率最高的回答；若有并列，返回字典序最小的。

**示例 1：**

```
输入：responses = [["good","bad","good"],["bad","ok"],["ok","ok","good"]]
输出："good"
解释：
对象1去重：{good, bad}
对象2去重：{bad, ok}
对象3去重：{ok, good}
统计：good出现2次，bad出现2次，ok出现2次
字典序最小的最高频回答：bad
```

**示例 2：**

```
输入：responses = [["y","n"],["y","y"],["n"]]
输出："y"
```

**提示：**
- `1 <= responses.length <= 1000`
- `1 <= responses[i].length <= 1000`
- 回答只含小写字母

## 解题思路

1. 对每个调查对象的回答列表去重（转为集合）
2. 统计所有去重后回答的频率（哈希表计数）
3. 找到最高频率，在最高频回答中选字典序最小的

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findCommonResponse(self, responses: List[List[str]]) -> str:
        count = Counter()
        for resp in responses:
            # 去重后统计
            unique = set(resp)
            for word in unique:
                count[word] += 1

        # 找最高频率
        max_freq = max(count.values())
        # 在最高频回答中找字典序最小的
        candidates = [word for word, freq in count.items() if freq == max_freq]
        return min(candidates)
```

### 方法二：排序后选择

```python
from typing import List
from collections import defaultdict

class Solution:
    def findCommonResponse(self, responses: List[List[str]]) -> str:
        freq = defaultdict(int)
        for resp in responses:
            for word in set(resp):
                freq[word] += 1

        # 按频率降序、字典序升序排序
        best = max(freq.keys(), key=lambda w: (freq[w], -ord(w[0])))
        # 更正：需要频率最高且字典序最小
        max_freq = max(freq.values())
        return min(w for w, f in freq.items() if f == max_freq)
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为调查对象数，m 为每个回答列表的平均长度
- 空间复杂度：O(n * m)，存储所有唯一回答

## 关键点总结

1. 每个调查对象的回答先去重，再统计频率
2. 同频率时选字典序最小的字符串
3. Python 的 `min()` 函数对字符串默认按字典序比较

## 易错点

1. 去重是对每个调查对象独立的（不是全局去重）
2. 相同回答同一对象只贡献一次频率
3. 并列时选字典序最小（`min` 不是 `max`）
