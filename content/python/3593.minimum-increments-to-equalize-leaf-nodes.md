## 题目描述

给定一棵有根树（根为节点 0），每条边有权值。从根到叶子节点的路径长度（所有边权之和）称为该叶子的深度值。通过对边的权值进行递增操作（每次将某条边的权值 +1），使得所有叶子节点的路径长度相等。求最少的总递增量。

**示例 1：**

```
输入：n = 4, edges = [[0,1,1],[1,2,2],[1,3,3]]
输出：1
解释：叶子 2 深度=3，叶子 3 深度=4，需要将边 (1,2) 权值 +1，总增量=1。
```

**提示：**
- `2 <= n <= 10^5`
- `edges[i] = [u, v, w]`
- `1 <= w <= 10^4`

## 解题思路

贪心 + DFS：
- 目标是让所有叶子到根的路径长度相等
- 最优目标值是所有叶子路径长度的最大值（只能增不能减）
- 对每个非叶子节点，其所有子树的叶子需要达到同一最大深度
- 贪心：在每个内部节点处，用最大子树叶子深度来"对齐"其他子树

DFS 返回当前子树叶子的最大深度值，并累计所有叶子达到最大深度所需的增量。

具体：
- 对每个节点，DFS 返回子节点中叶子的最大路径长度（包含到该节点的边权）
- 在当前节点处，各子树的最大叶子深度差之和即为该层需要的增量

## Python 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minIncrements(self, n: int, edges: List[List[int]]) -> int:
        # 建图
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        ans = 0

        def dfs(node, parent):
            nonlocal ans
            children_max_depths = []
            for child, weight in graph[node]:
                if child == parent:
                    continue
                child_max = dfs(child, node)
                children_max_depths.append(child_max + weight)

            if not children_max_depths:
                # 叶子节点，深度为 0（相对当前）
                return 0

            # 内部节点：所有子树对齐到最大深度
            max_depth = max(children_max_depths)
            for d in children_max_depths:
                ans += max_depth - d  # 增量

            return max_depth

        dfs(0, -1)
        return ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minIncrements(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # 迭代后序 DFS
        stack = [(0, -1, False)]
        depth = [0] * n  # 每个节点子树叶子的最大相对深度
        ans = 0

        while stack:
            node, parent, visited = stack.pop()
            if visited:
                # 处理 node
                children_depths = []
                for child, weight in graph[node]:
                    if child == parent:
                        continue
                    children_depths.append(depth[child] + weight)
                if children_depths:
                    max_d = max(children_depths)
                    ans += sum(max_d - d for d in children_depths)
                    depth[node] = max_d
                # 叶子则 depth[node] 保持 0
            else:
                stack.append((node, parent, True))
                for child, weight in graph[node]:
                    if child != parent:
                        stack.append((child, node, False))

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈或迭代栈

## 关键点总结

1. 只能增不能减，目标对齐最大叶子深度
2. DFS 后序：先得到所有子树的最大叶子深度，再在父节点处对齐
3. 每个内部节点处，增量 = sum(max_depth - child_depth for each child)

## 易错点

1. 边是无向的，DFS 时避免回到父节点
2. 叶子节点返回深度 0（相对自身），不能返回路径总和
3. 边权需要加到子节点返回的深度上
