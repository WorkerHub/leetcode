## 题目描述

给你一个整数数组 `nums`。

**因子得分**定义为数组中所有元素的 **LCM（最小公倍数）** 乘以 **GCD（最大公因数）**。

你可以最多删除数组中的**一个元素**（也可以不删除）。

返回操作后可以获得的最大因子得分。

**示例：**
```
输入：nums = [2, 4, 8, 16]
输出：64
解释：不删除任何元素，GCD = 2，LCM = 16，得分 = 32。
     删除 2，GCD=4，LCM=16，得分=64（最大）
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^9`

## 解题思路

数组长度 <= 100，可以枚举删除哪个元素（或不删除），计算剩余数组的 GCD 和 LCM，取最大因子得分。

由于 LCM 可能很大，但 Python 整数可以处理大数，不用担心溢出。

也可以用前缀和后缀的方式优化：
- `prefix_gcd[i]` = `nums[0..i-1]` 的 GCD
- `suffix_gcd[i]` = `nums[i+1..n-1]` 的 GCD

删除下标 `k` 后的 GCD = `gcd(prefix_gcd[k], suffix_gcd[k])`，LCM 同理。

## Python 代码实现

### 方法一：暴力枚举（推荐，数据小）

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        def lcm(a, b):
            return a * b // gcd(a, b)
        
        def array_gcd(arr):
            return reduce(gcd, arr)
        
        def array_lcm(arr):
            return reduce(lcm, arr)
        
        n = len(nums)
        best = 0
        
        # 不删除
        best = max(best, array_gcd(nums) * array_lcm(nums))
        
        # 删除第 i 个元素
        for i in range(n):
            remaining = nums[:i] + nums[i+1:]
            if remaining:
                best = max(best, array_gcd(remaining) * array_lcm(remaining))
        
        return best
```

### 方法二：前缀/后缀 GCD 和 LCM

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        
        def lcm(a, b):
            return a * b // gcd(a, b)
        
        # 前缀 GCD 和 LCM
        prefix_gcd = [0] * (n + 1)
        prefix_lcm = [1] * (n + 1)
        for i in range(n):
            prefix_gcd[i+1] = gcd(prefix_gcd[i], nums[i]) if prefix_gcd[i] else nums[i]
            prefix_lcm[i+1] = lcm(prefix_lcm[i], nums[i])
        
        # 后缀 GCD 和 LCM
        suffix_gcd = [0] * (n + 1)
        suffix_lcm = [1] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_gcd[i] = gcd(suffix_gcd[i+1], nums[i]) if suffix_gcd[i+1] else nums[i]
            suffix_lcm[i] = lcm(suffix_lcm[i+1], nums[i])
        
        best = 0
        # 不删除
        best = max(best, prefix_gcd[n] * prefix_lcm[n])
        
        # 删除第 i 个
        for i in range(n):
            g = gcd(prefix_gcd[i], suffix_gcd[i+1]) if prefix_gcd[i] and suffix_gcd[i+1] else (prefix_gcd[i] or suffix_gcd[i+1])
            l = lcm(prefix_lcm[i], suffix_lcm[i+1])
            best = max(best, g * l)
        
        return best
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n^2 * log(max_val))，枚举 n 个位置，每次计算 GCD/LCM
- 空间复杂度：O(n)

**方法二：**
- 时间复杂度：O(n * log(max_val))
- 空间复杂度：O(n)

## 关键点总结

1. 因子得分 = GCD * LCM。
2. 枚举删除哪个元素（或不删），取最大值。
3. 前缀/后缀 GCD 和 LCM 可以 O(1) 查询删除某元素后的结果。

## 易错点

1. 删除元素后数组可能为空（n=1 时，删除后为空，不合法）。本题 `n >= 1`，但删除后为空数组的得分不好定义，跳过即可。
2. LCM 需要用 `a * b // gcd(a, b)` 计算，注意 Python 整数可以处理大数。
3. 前缀/后缀的初始值：GCD 初始为 0（gcd(0, x) = x），LCM 初始为 1（lcm(1, x) = x）。
