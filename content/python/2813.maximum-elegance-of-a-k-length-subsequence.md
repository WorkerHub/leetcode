## 题目描述

给你一个长度为 `n` 的二维整数数组 `items`，`items[i] = [profit_i, category_i]`，以及一个整数 `k`。

从 `items` 中选择一个长度为 `k` 的子序列（不一定连续），最大化**优雅度**：

**优雅度** = `total_profit + distinct_categories^2`

其中 `total_profit` 是选择的 k 个 item 的利润之和，`distinct_categories` 是选中 item 中不同类别的数量。

**示例 1：**
```
输入：items = [[3,2],[5,1],[10,1]], k = 2
输出：17
解释：选择 [5,1] 和 [10,1]，total_profit=15，distinct=1，优雅度=15+1=16；
或选择 [3,2] 和 [10,1]，total_profit=13，distinct=2，优雅度=13+4=17
```

**示例 2：**
```
输入：items = [[3,1],[3,3],[2,2],[5,2],[3,3]], k = 3
输出：19
```

**提示：**
- `1 <= k <= n <= 10^5`
- `1 <= profit_i <= 10^9`
- `1 <= category_i <= n`

## 解题思路

**贪心 + 反悔策略（Greedy with Undo）：**

1. **按利润降序排序**，先选利润最高的 k 个 item
2. 然后考虑是否通过"换出重复类别的 item，换入新类别的 item"来增加 distinct_categories

**详细思路：**
- 先选利润最高的 k 个 item，记录当前 total_profit 和类别集合
- 对于剩余的（按利润降序排列的）item，如果它引入一个新类别：
  - 考虑将已选 k 个中**利润最小且类别重复**的 item 换出
  - 换入这个新类别 item（利润可能更低，但增加了 distinct）
  - 如果换后优雅度更大，则执行换
- 用最小堆维护"可以被换出的重复类别 item 的利润"

## Python 代码实现

### 方法一：排序 + 贪心反悔（推荐）

```python
import heapq
from typing import List

class Solution:
    def findMaximumElegance(self, items: List[List[int]], k: int) -> int:
        # 按利润降序排序
        items.sort(key=lambda x: -x[0])

        total_profit = 0
        categories = set()
        # 存储已选且类别重复的 item 的利润（可被替换的）
        duplicate_profits = []  # 最小堆

        # 先选利润最高的 k 个
        for i in range(k):
            profit, cat = items[i]
            total_profit += profit
            if cat in categories:
                # 类别重复，加入"可替换"堆
                heapq.heappush(duplicate_profits, profit)
            else:
                categories.add(cat)

        best = total_profit + len(categories) ** 2

        # 考虑剩余的 item（利润比已选的低）
        for i in range(k, len(items)):
            profit, cat = items[i]
            if cat in categories:
                # 引入已有类别，不会增加 distinct，跳过（利润还更低）
                continue
            if not duplicate_profits:
                # 没有可替换的重复 item，跳过
                continue
            # 换出利润最小的重复类别 item，换入当前新类别 item
            removed = heapq.heappop(duplicate_profits)
            total_profit += profit - removed
            categories.add(cat)
            best = max(best, total_profit + len(categories) ** 2)

        return best
```

### 方法二：带详细注释

```python
import heapq
from typing import List

class Solution:
    def findMaximumElegance(self, items: List[List[int]], k: int) -> int:
        # 按利润降序，优先选利润高的
        items.sort(reverse=True, key=lambda x: x[0])

        total = 0
        seen = set()         # 已选类别
        dup_heap = []        # 可被替换的重复类别 item 利润（最小堆）

        # 初始选择：利润最高的 k 个
        for j in range(k):
            p, c = items[j]
            total += p
            if c in seen:
                heapq.heappush(dup_heap, p)  # 重复类别，可能被换出
            else:
                seen.add(c)

        ans = total + len(seen) ** 2

        # 遍历剩余 item，尝试引入新类别
        for j in range(k, len(items)):
            p, c = items[j]
            # 只有引入新类别且有可替换的重复 item 时才有意义
            if c not in seen and dup_heap:
                # 换出重复类别中利润最低的
                old_p = heapq.heappop(dup_heap)
                total += p - old_p  # 利润变化（可能为负）
                seen.add(c)
                # 更新最优答案
                ans = max(ans, total + len(seen) ** 2)
                # 注意：引入的新 item 不加入 dup_heap（它是新类别，不重复）

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和堆操作各 O(n log n)
- 空间复杂度：O(n)，集合和堆的空间

## 关键点总结

1. 先选利润最高的 k 个，再考虑"用新类别替换重复类别中利润最低的"
2. 关键洞察：后续的 item 利润 <= 已选 item 的利润，但引入新类别能使 distinct^2 增加
3. 只有当新 item 是新类别且存在可替换的重复类别 item 时，才考虑替换
4. 用最小堆高效获取"利润最低的重复类别 item"

## 易错点

1. 只有引入**新类别**才有可能增加 distinct，已有类别的 item（利润更低）跳过
2. 没有可替换的重复 item 时不能替换（distinct 不变，利润减少，得不偿失）
3. 替换后的 total_profit 可能比初始低，但 distinct^2 增加可能补偿
