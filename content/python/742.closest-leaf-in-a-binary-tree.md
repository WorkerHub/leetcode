## 题目描述

给定一个二叉树的根节点 `root`，以及一个整数值 `k`，返回树中距离值为 `k` 的节点最近的叶子节点。

这里，距离最近意味着从节点 `k` 到叶子节点的路径中边的数量最少。同时，如果有多个最近的叶子节点，返回任意一个即可。

注意：节点 `k` 本身可能是一个叶子节点，在这种情况下距离为 0。

**示例 1：**
```
输入：root = [1, 3, 2], k = 1
输出：2
解释：叶子节点是 2 和 3，距离节点 1 最近的叶子节点是 2。
```

**示例 2：**
```
输入：root = [1], k = 1
输出：1
解释：最近的叶子节点是根节点本身。
```

**示例 3：**
```
输入：root = [1,2,3,4,null,null,null,5,null,6], k = 2
输出：3
```

**提示：**
- 树中节点的数量在范围 `[1, 1000]` 内
- `1 <= Node.val <= 1000`
- 保证树中存在值为 `k` 的节点

## 解题思路

这道题的关键在于：我们需要找到距离目标节点 `k` 最近的叶子节点，而这个叶子节点可能在目标节点的子树中，也可能在目标节点的祖先节点的其他子树中。

**核心策略：**

1. **将树转换为无向图**：由于我们需要从目标节点向上遍历到父节点，再向下到其他子树，因此需要建立双向连接
2. **使用 BFS 从目标节点开始搜索**：BFS 能保证找到的第一个叶子节点就是距离最近的
3. **分两步走**：
   - 第一步：DFS 遍历树，找到值为 `k` 的节点，同时建立父子双向映射
   - 第二步：从目标节点开始 BFS，找到第一个叶子节点

## Python 代码实现

### 方法一：图 + BFS（推荐）⭐

```python
from typing import Optional
from collections import deque, defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findClosestLeaf(self, root: Optional[TreeNode], k: int) -> int:
        # 步骤1：构建图（节点之间的双向连接）
        graph = defaultdict(list)
        
        def build_graph(node, parent=None):
            """DFS 构建无向图"""
            if not node:
                return None
            
            # 建立双向连接
            if parent:
                graph[node].append(parent)
                graph[parent].append(node)
            
            build_graph(node.left, node)
            build_graph(node.right, node)
            
            return node
        
        # 步骤2：找到值为 k 的目标节点
        def find_node(node, target):
            """DFS 查找目标节点"""
            if not node:
                return None
            if node.val == target:
                return node
            return find_node(node.left, target) or find_node(node.right, target)
        
        # 构建图
        build_graph(root)
        
        # 找到目标节点
        start_node = find_node(root, k)
        
        # 步骤3：从目标节点开始 BFS 查找最近的叶子节点
        queue = deque([start_node])
        visited = {start_node}
        
        while queue:
            node = queue.popleft()
            
            # 检查是否是叶子节点
            if node in graph and len(graph[node]) == 1 and node != root:
                # 非根节点且只有一个邻居（父节点），说明是叶子
                return node.val
            elif node == root and not node.left and not node.right:
                # 根节点本身是叶子
                return node.val
            elif node != root and not node.left and not node.right:
                # 普通叶子节点
                return node.val
            
            # 遍历所有邻居
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        return -1  # 不会到达这里

```

### 方法二：优化版（更简洁的叶子判断）

```python
class Solution:
    def findClosestLeaf(self, root: Optional[TreeNode], k: int) -> int:
        graph = defaultdict(list)
        
        # 构建图并同时记录所有叶子节点
        leaves = set()
        
        def dfs_build(node, parent=None):
            if not node:
                return
            
            # 判断是否是叶子
            if not node.left and not node.right:
                leaves.add(node)
            
            # 建立双向连接
            if parent:
                graph[node].append(parent)
                graph[parent].append(node)
            
            dfs_build(node.left, node)
            dfs_build(node.right, node)
        
        # 查找目标节点
        def find_target(node):
            if not node:
                return None
            if node.val == k:
                return node
            return find_target(node.left) or find_target(node.right)
        
        dfs_build(root)
        start = find_target(root)
        
        # BFS 查找最近的叶子
        queue = deque([start])
        visited = {start}
        
        while queue:
            node = queue.popleft()
            
            # 检查是否是叶子节点
            if node in leaves:
                return node.val
            
            # 扩展邻居
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        return -1
```

## 复杂度分析

### 方法一和方法二
- **时间复杂度**：O(n)，其中 n 是树中节点的数量
  - 构建图需要 O(n)
  - 查找目标节点需要 O(n)
  - BFS 最坏情况需要 O(n)
- **空间复杂度**：O(n)
  - 图的存储需要 O(n)
  - BFS 队列和访问集合需要 O(n)

## 关键点总结

1. **树转图**：将树结构转换为无向图，支持双向遍历（向上到父节点，向下到子节点）
2. **BFS 保证最短距离**：第一个遇到的叶子节点必然是距离最近的
3. **叶子节点判断**：`not node.left and not node.right`
4. **访问标记**：使用 visited 集合避免重复访问节点

## 易错点

1. **叶子节点判断**：需要正确判断什么是叶子节点（没有左右子节点）
2. **目标节点本身是叶子**：需要特殊处理，距离为 0
3. **图的构建**：需要建立双向连接，不能只记录父到子的单向连接
4. **重复访问**：BFS 时必须使用 visited 集合，否则会陷入死循环
