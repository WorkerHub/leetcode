## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，请你求出每个长度为 `k` 的子数组的美丽值。子数组的美丽值定义为：若该子数组中有至少 `x` 个负整数，则美丽值为第 `x` 小的负整数；否则为 0。

返回长度为 `n - k + 1` 的数组，其中第 `i` 个元素是下标从 `i` 开始的子数组的美丽值。

**示例 1：**
```
输入：nums = [1,-1,-3,-2,3], k = 3, x = 2
输出：[-1,-2,-2]
解释：
- [1,-1,-3]：第2小负数是 -1
- [-1,-3,-2]：第2小负数是 -2
- [-3,-2,3]：第2小负数是 -2
```

**数据范围：**
- n == nums.length
- 1 <= n <= 10^5
- 1 <= k <= n
- 1 <= x <= k
- -50 <= nums[i] <= 50

## 解题思路

由于 `nums[i]` 在 `[-50, 50]` 范围内，使用频次数组维护窗口内的元素分布。

滑动窗口：维护一个大小为 `k` 的窗口，用长度为 101 的频次数组记录各值的出现次数。查询第 `x` 小负数时，从 -50 开始累加频次，找到累计恰好达到 `x` 的值。

## Python 代码实现

### 方法一：滑动窗口 + 频次数组（推荐）

```python
from typing import List

class Solution:
    def getSubarrayBeauty(self, nums: List[int], k: int, x: int) -> List[int]:
        # 频次数组，下标 i 对应值 i - 50（-50 到 50）
        freq = [0] * 101  # freq[i] 对应值 i-50
        OFFSET = 50

        # 初始化前 k 个元素
        for i in range(k):
            freq[nums[i] + OFFSET] += 1

        def find_x_smallest_negative() -> int:
            """找第 x 小的负数，若不存在返回 0"""
            count = 0
            for val in range(-50, 0):  # 只看负数
                count += freq[val + OFFSET]
                if count >= x:
                    return val
            return 0

        ans = [find_x_smallest_negative()]

        for i in range(k, len(nums)):
            # 添加新元素
            freq[nums[i] + OFFSET] += 1
            # 移除旧元素
            freq[nums[i - k] + OFFSET] -= 1
            ans.append(find_x_smallest_negative())

        return ans
```

### 方法二：使用 SortedList（通用方法）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def getSubarrayBeauty(self, nums: List[int], k: int, x: int) -> List[int]:
        window = SortedList()
        ans = []

        for i, num in enumerate(nums):
            window.add(num)
            if i >= k:
                window.remove(nums[i - k])
            if i >= k - 1:
                # 找第 x 小的负数
                if len([v for v in window if v < 0]) >= x:
                    negatives = [v for v in window if v < 0]
                    ans.append(negatives[x - 1])
                else:
                    ans.append(0)

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n * 50)，空间复杂度 O(1)（频次数组固定大小）
- 方法二：时间复杂度 O(n log k)，空间复杂度 O(k)

## 关键点总结

1. 元素范围 [-50, 50]，频次数组大小固定
2. 滑动窗口维护频次，加入新元素、移除旧元素各 O(1)
3. 查找第 x 小负数只遍历 [-50, 0)，固定 50 次

## 易错点

1. 只统计负数（< 0），0 不算负数
2. 偏移量处理：`val + OFFSET` 将 [-50, 50] 映射到 [0, 100]
3. 至少需要 x 个负数才有美丽值，否则返回 0
