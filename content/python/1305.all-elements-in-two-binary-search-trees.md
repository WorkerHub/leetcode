## 题目描述

给你 `root1` 和 `root2` 这两棵二叉搜索树。请你返回一个列表，其中包含两棵树中的所有整数并按升序排序。

示例 1：
```
输入：root1 = [2,1,4], root2 = [1,0,3]
输出：[0,1,1,2,3,4]
```

示例 2：
```
输入：root1 = [1,null,8], root2 = [8,1]
输出：[1,1,8,8]
```

提示：
- 每棵树的节点数在 `[0, 5000]` 范围内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这道题要合并两棵二叉搜索树的所有元素并排序。利用 BST 的性质：中序遍历得到的是有序序列。

### 思路一：中序遍历 + 归并排序（推荐）
1. 对两棵树分别进行中序遍历，得到两个有序数组
2. 使用双指针归并两个有序数组

### 思路二：遍历 + 排序
1. 遍历两棵树，收集所有节点值
2. 对收集的值进行排序

### 思路三：迭代中序遍历 + 归并
使用栈进行迭代中序遍历，同时归并结果。

## Python 代码实现

### 方法一：中序遍历 + 归并（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def getAllElements(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> List[int]:
        # 中序遍历获取有序数组
        def inorder(root: Optional[TreeNode]) -> List[int]:
            if not root:
                return []
            return inorder(root.left) + [root.val] + inorder(root.right)
        
        # 归并两个有序数组
        def merge(arr1: List[int], arr2: List[int]) -> List[int]:
            result = []
            i, j = 0, 0
            
            while i < len(arr1) and j < len(arr2):
                if arr1[i] <= arr2[j]:
                    result.append(arr1[i])
                    i += 1
                else:
                    result.append(arr2[j])
                    j += 1
            
            # 添加剩余元素
            result.extend(arr1[i:])
            result.extend(arr2[j:])
            
            return result
        
        # 获取两个有序数组
        list1 = inorder(root1)
        list2 = inorder(root2)
        
        # 归并
        return merge(list1, list2)
```

### 方法二：简化版（遍历 + 排序）

```python
from typing import List, Optional

class Solution:
    def getAllElements(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> List[int]:
        result = []
        
        # DFS 收集所有节点值
        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                return
            result.append(node.val)
            dfs(node.left)
            dfs(node.right)
        
        dfs(root1)
        dfs(root2)
        
        # 排序
        return sorted(result)
```

### 方法三：迭代中序遍历 + 归并

```python
from typing import List, Optional

class Solution:
    def getAllElements(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> List[int]:
        # 迭代中序遍历
        def inorder_iterative(root: Optional[TreeNode]) -> List[int]:
            result = []
            stack = []
            current = root
            
            while current or stack:
                # 一直向左走
                while current:
                    stack.append(current)
                    current = current.left
                
                # 访问节点
                current = stack.pop()
                result.append(current.val)
                
                # 转向右子树
                current = current.right
            
            return result
        
        # 获取两个有序数组并归并
        list1 = inorder_iterative(root1)
        list2 = inorder_iterative(root2)
        
        # 使用双指针归并
        result = []
        i, j = 0, 0
        
        while i < len(list1) and j < len(list2):
            if list1[i] <= list2[j]:
                result.append(list1[i])
                i += 1
            else:
                result.append(list2[j])
                j += 1
        
        result.extend(list1[i:])
        result.extend(list2[j:])
        
        return result
```

### 方法四：Python 简洁写法

```python
from typing import List, Optional

class Solution:
    def getAllElements(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> List[int]:
        # 中序遍历
        def inorder(node: Optional[TreeNode], arr: List[int]) -> None:
            if node:
                inorder(node.left, arr)
                arr.append(node.val)
                inorder(node.right, arr)
        
        arr1, arr2 = [], []
        inorder(root1, arr1)
        inorder(root2, arr2)
        
        # 使用 sorted 归并
        return sorted(arr1 + arr2)
```

## 复杂度分析

### 方法一：中序遍历 + 归并
- 时间复杂度：O(m + n)，其中 m 和 n 分别是两棵树的节点数
  - 中序遍历：O(m) + O(n)
  - 归并：O(m + n)
- 空间复杂度：O(m + n)，存储两个有序数组

### 方法二：遍历 + 排序
- 时间复杂度：O((m + n) log(m + n))，排序的时间复杂度
- 空间复杂度：O(m + n)

### 方法三：迭代中序遍历
- 时间复杂度：O(m + n)
- 空间复杂度：O(h1 + h2 + m + n)，其中 h1 和 h2 是树的高度（栈空间）

## 关键点总结

1. 利用 BST 的性质：中序遍历得到有序序列
2. 归并两个有序数组比直接排序更高效
3. 可以选择递归或迭代实现中序遍历
4. Python 的 sorted 函数底层使用 Timsort，对部分有序数据优化很好

## 易错点

1. 忘记 BST 中序遍历的性质，直接排序（虽然能过但不是最优）
2. 归并时边界条件处理不当
3. 中序遍历的递归顺序错误（应该是 左-根-右）
4. 忘记处理空树的情况

```
    2            1
   / \          / \

中序遍历：
Tree 1: [1, 2, 4]
Tree 2: [0, 1, 3]

归并过程：
i=0, j=0: arr1[0]=1, arr2[0]=0 → 选 0 → [0]
i=0, j=1: arr1[0]=1, arr2[1]=1 → 选 1 → [0,1]

```
