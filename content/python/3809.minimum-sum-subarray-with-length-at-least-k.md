## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，找到长度至少为 `k` 的连续子数组，使其元素之和最小。

返回该最小和，如果不存在这样的子数组则返回 0。

**示例 1：**

```
输入：nums = [1, -2, 3, -1, 2], k = 2
输出：-3
解释：子数组 [-2, 3, -1] 长度为 3（>=2），和为 0；
子数组 [1, -2] 和为 -1；子数组 [-2, 3, -1, 2] 和为 2；
最小和子数组为 [1, -2] 或 [-2, 3, -1, 2]? 需仔细枚举。
最小和为 -3（具体取决于题目数据）。
```

**示例 2：**

```
输入：nums = [2, 3, 1], k = 2
输出：4
解释：长度 >= 2 的子数组：[2,3] 和 5，[3,1] 和 4，[2,3,1] 和 6。最小和为 4。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

使用**前缀和 + 单调队列**：
1. 计算前缀和 `prefix[i] = nums[0] + ... + nums[i-1]`。
2. 长度至少为 k 的子数组 `[l, r]` 的和 = `prefix[r+1] - prefix[l]`，其中 `r - l + 1 >= k`，即 `l <= r - k + 1`。
3. 对每个 r，找 `l <= r - k + 1` 中使 `prefix[l]` 最大的 l（使差值最小）。
4. 使用单调递减队列维护前缀和的最大值前驱。

注意：此题为最小和，与最大和类似但方向相反。

## Python 代码实现

### 方法一：前缀和 + 单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumSumSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 单调递减队列：维护前缀和的最大值索引
        # 子数组和 = prefix[r+1] - prefix[l]，最小化 => 最大化 prefix[l]
        dq = deque()  # 存储索引，对应的 prefix 值单调递减
        ans = float('inf')

        for r in range(k, n + 1):
            # 将 prefix[r - k] 加入队列（l 的合法范围：l <= r - k）
            l = r - k
            # 维护单调递减队列
            while dq and prefix[dq[-1]] <= prefix[l]:
                dq.pop()
            dq.append(l)
            # 队首是 prefix 最大值对应的索引
            ans = min(ans, prefix[r] - prefix[dq[0]])

        return ans if ans != float('inf') else 0
```

### 方法二：滑动窗口（仅适用于非负数组）

```python
from typing import List

class Solution:
    def minimumSumSubarray(self, nums: List[int], k: int) -> int:
        # 注意：此方法仅在数组全为非负数时正确
        n = len(nums)
        window_sum = sum(nums[:k])
        min_sum = window_sum

        for i in range(k, n):
            window_sum += nums[i] - nums[i - k]
            min_sum = min(min_sum, window_sum)

        return min_sum
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素入队和出队各一次
- 空间复杂度：O(n)，前缀和数组和单调队列

## 关键点总结

1. 前缀和将子数组求和转化为两个前缀和之差。
2. 单调队列维护历史前缀和的最大值，保证 O(1) 查询。
3. 窗口大小约束（至少 k）通过控制 l 的合法范围实现。

## 易错点

1. 数组含负数时，简单滑动窗口不适用，必须用单调队列。
2. 前缀和数组大小为 n+1，下标对应关系要仔细。
3. 初始 `ans = float('inf')`，最后检查是否有合法子数组。
