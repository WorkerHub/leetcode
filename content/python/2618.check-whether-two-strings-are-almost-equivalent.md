## 题目描述

给你两个字符串 `word1` 和 `word2`，每个字符串的长度均为 `n`。

如果两个字符串中每种字符出现频次的差的绝对值最多为 3，则认为这两个字符串**几乎等价**。

若 `word1` 和 `word2` 几乎等价，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：word1 = "aaaa", word2 = "bccb"
输出：false
解释：字符 a 在 word1 中出现 4 次，在 word2 中出现 0 次，差为 4 > 3
```

**示例 2：**
```
输入：word1 = "abcdeef", word2 = "abaaacc"
输出：true
解释：每种字符频次差均 <= 3
```

**数据范围：**
- n == word1.length == word2.length
- 1 <= n <= 100
- word1 和 word2 只含小写英文字母

## 解题思路

统计两个字符串中每个字母的出现频次，检查每种字母的频次差的绝对值是否都不超过 3。

## Python 代码实现

### 方法一：Counter 比较（推荐）

```python
from collections import Counter

class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        cnt1 = Counter(word1)
        cnt2 = Counter(word2)
        # 遍历所有出现的字符
        for c in set(cnt1) | set(cnt2):
            if abs(cnt1[c] - cnt2[c]) > 3:
                return False
        return True
```

### 方法二：差值数组

```python
class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        diff = [0] * 26
        for c in word1:
            diff[ord(c) - ord('a')] += 1
        for c in word2:
            diff[ord(c) - ord('a')] -= 1
        return all(abs(d) <= 3 for d in diff)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串
- 空间复杂度：O(1)，最多 26 个字母

## 关键点总结

1. 只需统计 26 个小写字母的频次差
2. Counter 的默认值为 0，访问不存在的键不会报错

## 易错点

1. 需要检查两个字符串的并集字符，不能只检查一个字符串的字符
2. 差值取绝对值
