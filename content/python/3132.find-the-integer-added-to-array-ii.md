## 题目描述

给你两个整数数组 `nums1` 和 `nums2`。

从 `nums1` 中移除两个元素，然后给剩余元素加上整数 `x`，使其与 `nums2` 相同（不计顺序）。

返回满足条件的 **最小** 非负整数 `x`，保证答案存在。

**示例 1：**
```
输入：nums1 = [4,20,16,12,8], nums2 = [14,18,10]
输出：-2
解释：移除 4 和 20，剩余 [16,12,8]，加 -2 得 [14,10,6]，不对。
实际：移除 4 和 20，剩余 [16,12,8]，加 2 得 [18,14,10]，与 nums2 相同。答案 x=2。
```

**提示：**
- `3 <= nums1.length <= 200`
- `nums1.length - 2 == nums2.length`

## 解题思路

排序后，枚举从 `nums1` 中移除哪两个元素（最多 3 种情况：移除最小的两个中的某个组合）。

关键观察：排序后，`nums2` 的最小值一定对应 `nums1` 排序后第 1、2 或 3 个元素（因为移除了两个元素）。枚举 x = min(nums2) - nums1[i]（i=0,1,2），然后验证用双指针是否能匹配。

## Python 代码实现

### 方法一：枚举 + 双指针验证（推荐）

```python
from typing import List

class Solution:
    def minimumAddedInteger(self, nums1: List[int], nums2: List[int]) -> int:
        nums1.sort()
        nums2.sort()

        def check(x: int) -> bool:
            # 验证 nums1 中是否能移除 2 个元素后加 x 等于 nums2
            j = 0
            removed = 0
            for i in range(len(nums1)):
                if j < len(nums2) and nums1[i] + x == nums2[j]:
                    j += 1
                else:
                    removed += 1
                    if removed > 2:
                        return False
            return j == len(nums2)

        # 枚举 x（nums2[0] 对应 nums1[0], nums1[1], 或 nums1[2]）
        candidates = [nums2[0] - nums1[i] for i in range(3)]
        candidates.sort()

        for x in candidates:
            if check(x):
                return x
        return -1
```

### 方法二：枚举移除的两个元素

```python
from typing import List
from itertools import combinations

class Solution:
    def minimumAddedInteger(self, nums1: List[int], nums2: List[int]) -> int:
        nums1.sort()
        nums2.sort()
        n1 = len(nums1)

        ans = float('inf')
        for i, j in combinations(range(n1), 2):
            remain = [nums1[k] for k in range(n1) if k != i and k != j]
            x = nums2[0] - remain[0]
            if all(r + x == t for r, t in zip(remain, nums2)):
                if abs(x) < abs(ans) or (abs(x) == abs(ans) and x < ans):
                    ans = x
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 线性验证
- 空间复杂度：O(1)

## 关键点总结

1. 排序后，`nums2[0]` 对应 `nums1` 排序后前 3 个元素之一
2. 枚举 3 种候选 x，用双指针验证
3. 返回最小满足条件的 x

## 易错点

1. 只枚举前 3 个候选，因为最多移除 2 个最小元素
2. 验证时用双指针，不匹配计入 removed
