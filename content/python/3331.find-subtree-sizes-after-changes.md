## 题目描述

给你一棵有 `n` 个节点的树（根为 0），每个节点 `i` 有一个字符 `s[i]`。

执行以下操作：对每个节点 `v`（从 1 到 n-1），找 `v` 的祖先中**距离 v 最近**且字符与 `v` 相同的祖先 `u`，若存在，将 `v` 从当前父节点改为 `u`（重新挂载）。

返回操作后每个节点的子树大小（包含自身）。

**提示：**
- `2 <= n <= 10^5`
- `s` 只含小写英文字母

## 解题思路

**DFS + 哈希表维护祖先字符：**

按 DFS 顺序（先处理父节点，再处理子节点）进行，维护一个哈希表 `last[c]` 表示当前 DFS 路径上，字符为 `c` 的最近祖先节点。

1. 进入节点 `v` 时：
   - 查找 `last[s[v]]`，若存在，则 `v` 的新父节点是 `last[s[v]]`，更新子树大小关系。
   - 将 `v` 的字符加入哈希表 `last[s[v]] = v`（覆盖旧值）。

2. 离开节点 `v` 时：恢复哈希表（回溯）。

3. 子树大小的计算：在回溯时，将子节点的子树大小加到父节点上。

**关键点：** 操作后，`v` 的子节点仍然是原来的子节点，只是 `v` 自身被挂到了新的父节点下。

## Python 代码实现

### 方法一：DFS + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findSubtreeSizes(self, parent: List[int], s: str) -> List[int]:
        n = len(s)
        
        # 构建子节点列表
        children = defaultdict(list)
        for i in range(1, n):
            children[parent[i]].append(i)
        
        size = [1] * n  # 每个节点初始大小为 1
        new_parent = parent[:]  # 操作后的父节点
        last = {}  # last[c] = 当前路径上字符 c 的最近祖先
        
        def dfs(node):
            prev = last.get(s[node])
            last[s[node]] = node
            
            # 若 node 有字符相同的祖先，重新挂载
            if node != 0 and prev is not None:
                new_parent[node] = prev
            
            for child in children[node]:
                dfs(child)
                # 子节点的子树大小加到其（新）父节点上
                # 注意：子节点可能已经重新挂载，但其子树的处理在 dfs(child) 中完成
            
            # 恢复 last（回溯）
            if prev is not None:
                last[s[node]] = prev
            else:
                del last[s[node]]
        
        import sys
        sys.setrecursionlimit(200000)
        dfs(0)
        
        # 重新计算子树大小（基于 new_parent）
        # 按 DFS 序逆序累加
        size2 = [1] * n
        # 需要确定新的拓扑顺序
        # 由于新树的结构，可以用逆 DFS 序累加
        
        # 方法：先做一次原树 DFS 得到 DFS 序，然后按逆序用 new_parent 累加
        order = []
        def dfs2(node):
            order.append(node)
            for child in children[node]:
                dfs2(child)
        dfs2(0)
        
        # 重置并重新挂载
        # 按原 DFS 序（确保父先于子），用 new_parent 累加
        for node in reversed(order):
            if node != 0:
                size2[new_parent[node]] += size2[node]
        
        return size2
```

## 复杂度分析

- 时间复杂度：O(n)，DFS 两次
- 空间复杂度：O(n)

## 关键点总结

1. DFS 中维护当前路径上每个字符的最近祖先，进入时更新，回溯时恢复。
2. 每个节点重新挂载后，子树结构不变，只是自身的父节点改变。
3. 子树大小需要在新的父子关系下重新计算。

## 易错点

1. 回溯时必须恢复哈希表 `last` 的状态（否则会影响兄弟节点的路径）。
2. 节点 0（根节点）没有父节点，不需要重新挂载。
3. 新父节点关系下，子树大小要按逆 DFS 序累加。
