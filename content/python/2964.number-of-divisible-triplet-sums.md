## 题目描述

给你一个整数数组 `nums` 和一个整数 `d`，返回满足以下条件的三元组 `(i, j, k)` 的数目（`0 <= i < j < k < n`），其中 `(nums[i] + nums[j] + nums[k]) % d == 0`。

**示例 1：**
```
输入：nums = [3,3,4,7,8], d = 5
输出：3
```

**示例 2：**
```
输入：nums = [3,3,3], d = 3
输出：1
```

**提示：**
- `3 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`
- `1 <= d <= 10^9`

## 解题思路

枚举中间下标 j，对于每个 j：
- 左侧统计：`nums[i] % d` 各余数的出现次数（i < j）
- 需要找 `nums[k]` 使得 `(nums[j] + nums[k]) % d + (nums[i] % d) == 0 (mod d)`
  即 `(nums[i] + nums[j] + nums[k]) % d == 0`
  即 `nums[k] % d == (d - (nums[i] + nums[j]) % d) % d`

实际上更高效：枚举 j，左侧用哈希表存 `nums[i] % d` 的计数，右侧枚举 k 或预处理。

n <= 1000，O(n^2) 暴力也可以，枚举 i < j，用哈希表统计 (nums[i]+nums[j])%d，再用哈希表统计 k 的余数。

## Python 代码实现

### 方法一：枚举中间元素 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def divisibleTripletCount(self, nums: List[int], d: int) -> int:
        n = len(nums)
        ans = 0

        # 枚举 j，左边用哈希表存 nums[i]%d 的计数
        for j in range(1, n - 1):
            # 右侧：统计 nums[k]%d 的需求
            # left[r] = i < j 中 nums[i]%d == r 的个数
            left = defaultdict(int)
            for i in range(j):
                left[nums[i] % d] += 1

            for k in range(j + 1, n):
                need = (d - (nums[j] + nums[k]) % d) % d
                ans += left[need]

        return ans
```

### 方法二：暴力三重循环（最直接）

```python
from typing import List

class Solution:
    def divisibleTripletCount(self, nums: List[int], d: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if (nums[i] + nums[j] + nums[k]) % d == 0:
                        ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一，枚举 j 和 k，左侧哈希表预建）；O(n^3)（方法二）
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 枚举 j，左侧哈希表存余数，右侧枚举 k 查询
2. 需要的余数 = `(d - (nums[j]+nums[k])%d) % d`
3. n <= 1000 时 O(n^2) 完全可行，O(n^3) 可能略慢但也在范围内

## 易错点

1. need = `(d - x) % d`，当 x == 0 时取余要得到 0，不是 d
2. 枚举中间 j 的范围是 [1, n-2]（需要有左侧和右侧元素）
3. 左侧哈希表在每次 j 更新时需要重置（若不重置需要累加）
