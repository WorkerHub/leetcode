## 题目描述

列表 `arr` 由在范围 `[1, n]` 中的所有整数组成，并按严格递增排序。请你对 `arr` 应用下述算法：

- 从左到右，删除第一个数字，然后每隔一个数字删除一个，直到到达列表末尾。
- 重复上面的步骤，但这次是从右到左。也就是，删除最右侧的数字，然后剩下的数字每隔一个删除一个。
- 不断重复这两步，从左到右和从右到左交替进行，直到只剩下一个数字。

给你整数 `n`，返回 `arr` 最后剩下的数字。

**示例 1:**

```
输入：n = 9
输出：6
解释：
arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]
arr = [2, 4, 6, 8]
arr = [2, 6]
arr = [6]
```

**示例 2:**

```
输入：n = 1
输出：1
```

**提示:**

- `1 <= n <= 10^9`

## 解题思路

本题数据范围很大（10^9），不能直接模拟，需要找到数学规律。

### 核心思想：维护首元素

**关键观察：**

1. 我们只需要追踪**首元素的位置**和**步长**
2. 每次操作后：
   - 剩余元素数量减半
   - 步长翻倍
   - 首元素可能发生变化

**首元素何时变化？**

- **从左到右**：首元素一定被删除，首元素变为下一个
- **从右到左**：
  - 如果剩余元素数量是奇数，首元素被删除
  - 如果剩余元素数量是偶数，首元素不变

**算法流程：**

```
初始化:
- head = 1 (首元素)
- step = 1 (步长)
- remaining = n (剩余元素数量)
- left_to_right = True (从左到右)

while remaining > 1:
    if left_to_right or remaining % 2 == 1:
        head += step  # 首元素移动
    step *= 2
    remaining //= 2
    left_to_right = not left_to_right

return head
```

### 递归思路

也可以用递归求解：
- `f(n)` 表示从左到右消除后剩下的数
- `g(n)` 表示从右到左消除后剩下的数
- 找到它们之间的关系

## Python 代码实现

### 方法一：迭代维护首元素（推荐）⭐

```python
class Solution:
    def lastRemaining(self, n: int) -> int:
        """
        迭代维护首元素位置
        时间复杂度: O(log n)
        空间复杂度: O(1)
        """
        head = 1  # 当前序列的首元素
        step = 1  # 相邻元素之间的间隔
        remaining = n  # 剩余元素数量
        left_to_right = True  # 当前方向
        
        while remaining > 1:
            # 首元素何时更新：
            # 1. 从左到右：首元素一定被删除
            # 2. 从右到左且剩余元素为奇数：首元素被删除
            if left_to_right or remaining % 2 == 1:
                head += step
            
            # 更新状态
            step *= 2  # 步长翻倍
            remaining //= 2  # 剩余元素减半
            left_to_right = not left_to_right  # 改变方向
        
        return head
```

### 方法二：递归（优雅但稍慢）

```python
class Solution:
    def lastRemaining(self, n: int) -> int:
        """
        递归求解
        时间复杂度: O(log n)
        空间复杂度: O(log n) - 递归栈
        """
        return self.leftToRight(n)
    
    def leftToRight(self, n: int) -> int:
        """从左到右消除"""
        if n == 1:
            return 1
        # 从左到右消除后，剩下的是原序列的偶数位
        # 从右到左消除 n//2，结果需要 *2
        return 2 * self.rightToLeft(n // 2)
    
    def rightToLeft(self, n: int) -> int:
        """从右到左消除"""
        if n == 1:
            return 1
        # 从右到左消除，如果 n 是奇数，首元素被删除
        if n % 2 == 1:
            return 2 * self.leftToRight(n // 2)
        else:
            return 2 * self.leftToRight(n // 2) - 1
```

### 方法三：数学公式（最优雅）

```python
class Solution:
    def lastRemaining(self, n: int) -> int:
        """
        利用镜像对称性质
        时间复杂度: O(log n)
        空间复杂度: O(1)
        """
        head = 1
        remaining = n
        step = 1
        left = True
        
        while remaining > 1:
            # 从左到右，或从右到左但剩余奇数个
            if left or remaining % 2 == 1:
                head += step
            
            remaining //= 2
            step *= 2
            left = not left
        
        return head
```

### 方法四：纯递归公式

```python
class Solution:
    def lastRemaining(self, n: int) -> int:
        """
        递归公式
        """
        if n == 1:
            return 1
        # 从左到右消除，结果是从右到左消除 n//2 的结果 * 2
        return 2 * (1 + n // 2 - self.lastRemaining(n // 2))
```

## 复杂度分析

**时间复杂度：** O(log n)
- 每次操作后剩余元素减半
- 最多需要 log n 次操作

**空间复杂度：** 
- 迭代：O(1)
- 递归：O(log n) - 递归调用栈

## 关键点总结

1. **不能暴力模拟**：n 可达 10^9，必须找数学规律
2. **追踪首元素**：只需要知道首元素和步长
3. **步长倍增**：每次操作后步长翻倍
4. **首元素更新规则**：从左到右必更新，从右到左看奇偶
5. **元素数量减半**：每次操作后剩余元素减半

## 易错点

1. **初始值错误**：head 初始为 1，不是 0
2. **更新条件**：从右到左时要判断奇偶
3. **步长计算**：步长每次乘以 2
4. **方向切换**：每次操作后方向反转
5. **递归终止条件**：n == 1 时返回 1

## 图解示例

```
n = 9, arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]

第 1 轮（从左到右）:
删除: 1, 3, 5, 7, 9
剩余: [2, 4, 6, 8]
head = 2, step = 2, remaining = 4

第 2 轮（从右到左）:
删除: 8, 4
剩余: [2, 6]
head = 2, step = 4, remaining = 2
(从右到左，偶数个元素，head 不变)

第 3 轮（从左到右）:
删除: 2
剩余: [6]
head = 6, step = 8, remaining = 1

结果: 6
```

**状态变化表：**

| 轮次 | 方向 | head | step | remaining | 更新 head? |

| 0    | -    | 1    | 1    | 9         | -         |
| 1    | L→R  | 2    | 2    | 4         | ✓ (L→R)   |
| 2    | R→L  | 2    | 4    | 2         | ✗ (偶数)  |
| 3    | L→R  | 6    | 8    | 1         | ✓ (L→R)   |
