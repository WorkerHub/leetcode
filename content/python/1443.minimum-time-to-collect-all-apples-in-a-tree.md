## 题目描述

给你一棵有 `n` 个节点的无向树，节点编号从 `0` 到 `n-1`，以及一个整数数组 `hasApple`（大小为 `n`），其中 `hasApple[i] = true` 代表节点 `i` 有一个苹果。

你将以节点 `0` 为根节点，求得从节点 `0` 出发，收集所有苹果，并回到节点 `0` 所需要的**最少时间**（秒）。

无向边用 `edges` 数组给出，`edges[i] = [fromi, toi]` 表示节点 `fromi` 和 `toi` 之间有一条双向边。

每走一条边（不论方向），需要花费 **1 秒**。

**示例 1：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,true,false,true,true,false]
输出：8
解释：路径 0->1->5->1->4->1->0->2->3->2->0 花费8秒（去+回各算一次）
     最优路径：0->1->4->1->5->1->0->2->3->2->0，花费10？
     实际答案是8，选择路径0->1->4->1->5->1->0->2->3->2->0用了10步
     注：节点3没有苹果，节点6没有苹果，优化后答案为8
```

**示例 2：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,true,false,false,true,false]
输出：6
```

**示例 3：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,false,false,false,false,false]
输出：0
```

**提示：**
- `1 <= n <= 10^5`
- `edges.length == n - 1`
- `0 <= fromi, toi <= n - 1`
- `fromi != toi`
- `hasApple.length == n`

## 解题思路

**DFS 后序遍历：**

从根节点（0）做 DFS，对每个子树计算：从子树根节点出发收集该子树内所有苹果并返回所需时间。

**关键观察：**
- 若某子树内没有苹果，不需要走这棵子树，时间贡献为 0。
- 若某子树内有苹果，必须走到该子树并回来，时间贡献为 `子树内部时间 + 2`（来回各 1 秒）。

**递推公式（对节点 u，从父节点 parent 调用）：**
```
dfs(u) = sum(dfs(v) + 2 for v in children(u) if dfs(v) > 0 or hasApple[v])
```

即：若子节点 v 的子树需要访问（子树有苹果或 v 本身有苹果），则加上 `dfs(v) + 2`。

## Python 代码实现

### 方法一：DFS 递归（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        # 建邻接表（无向图）
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def dfs(node: int, parent: int) -> int:
            """
            返回从 node 收集其子树所有苹果并回到 node 所需时间
            parent 用于避免回头访问
            """
            total_time = 0

            for child in graph[node]:
                if child == parent:
                    continue  # 不回到父节点

                child_time = dfs(child, node)

                # 如果子树需要访问（子树内部需要时间，或子节点本身有苹果）
                if child_time > 0 or hasApple[child]:
                    total_time += child_time + 2  # +2 是去该子节点再回来的时间

            return total_time

        return dfs(0, -1)
```

### 方法二：BFS（广度优先搜索，从叶子向根累加）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        if n == 1:
            return 0

        # 建邻接表，并记录每个节点的度数
        graph = defaultdict(list)
        degree = [0] * n
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
            degree[u] += 1
            degree[v] += 1

        # 拓扑排序（从叶子到根）
        # 时间贡献数组，time[i] = 访问节点 i 子树所需时间（不含去 i 的时间）
        time = [0] * n
        queue = deque()

        # 将所有叶子节点（度为1且不是根）加入队列
        for i in range(1, n):  # 跳过根节点 0
            if degree[i] == 1:
                queue.append(i)

        visited = [False] * n
        visited[0] = True

        while queue:
            node = queue.popleft()
            visited[node] = True

            # 找到父节点（度数>1 且未访问）
            parent = -1
            for neighbor in graph[node]:
                if not visited[neighbor]:
                    parent = neighbor
                    break

            if parent == -1:
                continue

            # 若当前节点需要访问（自身有苹果或子树有苹果）
            if hasApple[node] or time[node] > 0:
                time[parent] += time[node] + 2

            degree[parent] -= 1
            if degree[parent] == 1 and parent != 0:
                queue.append(parent)

        return time[0]
```

### 方法三：DFS 迭代（显式栈）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 用显式栈模拟 DFS，记录 (节点, 父节点, 是否已处理子节点)
        # 用 time 数组记录每个节点的贡献时间
        time = [0] * n
        stack = [(0, -1)]
        order = []  # 记录 DFS 后序遍历顺序
        parent_map = [-1] * n

        # 先按 DFS 顺序遍历，记录后序序列
        visited = [False] * n
        visited[0] = True
        while stack:
            node, par = stack.pop()
            order.append((node, par))
            for child in graph[node]:
                if not visited[child]:
                    visited[child] = True
                    parent_map[child] = node
                    stack.append((child, node))

        # 从后往前（后序）计算时间
        for node, par in reversed(order):
            if par == -1:
                continue
            if hasApple[node] or time[node] > 0:
                time[par] += time[node] + 2

        return time[0]
```

## 复杂度分析

- **时间复杂度：** O(n)，每个节点和边各访问一次。
- **空间复杂度：** O(n)，邻接表和递归栈深度。

## 图解示例

```
n=7, hasApple=[F,F,T,F,T,T,F]

树结构：
        0
       / \
      1   2
     / \ / \
    4  5 3  6

DFS 从 0 出发：

dfs(4, 1): 无子节点，hasApple[4]=True，返回 0（自身有苹果，由父节点计入）
dfs(5, 1): 无子节点，hasApple[5]=True，返回 0
dfs(1, 0):
  child=4: dfs(4)=0，hasApple[4]=T -> total += 0+2 = 2
  child=5: dfs(5)=0，hasApple[5]=T -> total += 0+2 = 2
  total = 4，返回 4

dfs(3, 2): 无子节点，hasApple[3]=F，返回 0
dfs(6, 2): 无子节点，hasApple[6]=F，返回 0
dfs(2, 0):
  child=3: dfs(3)=0，hasApple[3]=F -> 不计入
  child=6: dfs(6)=0，hasApple[6]=F -> 不计入
  但 hasApple[2]=T！
  child=3 时：dfs(3)=0，hasApple[3]=F，不加
  总时间 = 0，但根节点调用时 hasApple[2]=T...
  
dfs(0, -1):
  child=1: dfs(1)=4 > 0 -> total += 4+2 = 6
  child=2: dfs(2)=0，hasApple[2]=T -> total += 0+2 = 2
  total = 8

返回 8，正确！
```

## 关键点总结

1. 后序 DFS：先处理子节点，再汇总到父节点，典型的树形 DP 思路。
2. 判断是否需要访问子树：`child_time > 0`（子树内有苹果）或 `hasApple[child]`（子节点本身有苹果）。
3. 来回时间 `+2`：每条边来回各走一次，固定贡献 2 秒。
4. 根节点不需要额外加 2（已包含在每个子树的贡献中）。

## 易错点

- 将根节点的时间也加 2（根节点不需要来回，起点和终点）。
- 只判断 `hasApple[child]` 而忘记 `child_time > 0`（子树深处有苹果但中间节点没苹果）。
- 建图时使用有向图而非无向图，导致遍历不完整。
