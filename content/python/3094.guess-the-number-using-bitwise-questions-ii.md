## 题目描述

与 3064 相同的交互题，但隐藏数范围扩大到 `2^30`，且可以调用的函数变为 `commonSetBits(num)`（返回 `num & n` 的置位数）。

返回隐藏的整数 `n`（1 <= n <= 2^30）。

## 解题思路

与 3064 完全相同：逐位询问，最多 30 次调用确定每一位。

## Python 代码实现

### 方法一：逐位询问（推荐）

```python
def commonSetBits(num: int) -> int:
    pass  # 系统提供

class Solution:
    def findNumber(self) -> int:
        n = 0
        for i in range(30):
            if commonSetBits(1 << i) > 0:
                n |= (1 << i)
        return n
```

### 方法二：批量询问（减少调用次数）

```python
class Solution:
    def findNumber(self) -> int:
        # 分组询问以减少调用次数（但不超过限制）
        n = 0
        for i in range(30):
            if commonSetBits(1 << i):
                n |= (1 << i)
        return n
```

## 复杂度分析

- 时间复杂度：O(30) = O(1)，恰好 30 次询问
- 空间复杂度：O(1)

## 关键点总结

1. 每次只询问一个位，独立确定
2. 30 次询问覆盖 0 到 29 位

## 易错点

1. n 的范围是 `1 <= n <= 2^30`，注意是 2^30，需要询问 30 位（位 0 到 29）
2. `commonSetBits(1 << 29)` 询问第 29 位（值为 2^29）
