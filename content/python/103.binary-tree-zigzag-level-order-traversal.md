## 题目描述

给你二叉树的根节点 `root`，返回其节点值的**锯齿形层序遍历**。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

**示例 1：**
```
    3
   / \
  9  20
    /  \
   15   7
```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[20,9],[15,7]]

**示例 2：**
输入：root = [1]
输出：[[1]]

**示例 3：**
输入：root = []
输出：[]

**提示：**
- 树中节点数目在范围 [0, 2000] 内
- -100 <= Node.val <= 100

## 解题思路

锯齿形层序遍历本质上还是**BFS 层序遍历**，只是每层的输出方向交替变化。

**解决方案：**
1. **方法一**：BFS + 奇偶层标记，偶数层反转结果
2. **方法二**：BFS + 双端队列，交替从两端取元素
3. **方法三**：普通 BFS，用标志位控制插入顺序

**推荐方法一**：简单直观，易于理解。

## Python 代码实现

### 方法一：BFS + 层级标记（推荐）⭐

```python
from typing import Optional, List
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        """锯齿形层序遍历 - BFS + 奇偶层标记"""
        if not root:
            return []
        
        result = []
        queue = deque([root])
        left_to_right = True  # 标记当前层的遍历方向
        
        while queue:
            level_size = len(queue)
            level_vals = []
            
            for _ in range(level_size):
                node = queue.popleft()
                level_vals.append(node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 根据方向决定是否反转
            if left_to_right:
                result.append(level_vals)
            else:
                result.append(level_vals[::-1])  # 反转列表
            
            left_to_right = not left_to_right  # 切换方向
        
        return result
```

### 方法二：BFS + 双端队列插入

```python
from typing import Optional, List
from collections import deque

class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        """使用双端队列控制插入方向"""
        if not root:
            return []
        
        result = []
        queue = deque([root])
        left_to_right = True
        
        while queue:
            level_size = len(queue)
            level_vals = deque()  # 使用双端队列
            
            for _ in range(level_size):
                node = queue.popleft()
                
                # 根据方向选择插入端
                if left_to_right:
                    level_vals.append(node.val)
                else:
                    level_vals.appendleft(node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            result.append(list(level_vals))
            left_to_right = not left_to_right
        
        return result
```

### 方法三：DFS + 层级标记

```python
from typing import Optional, List

class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        """DFS 递归实现"""
        result = []
        
        def dfs(node: Optional[TreeNode], level: int):
            if not node:
                return
            
            if len(result) == level:
                result.append([])
            
            # 偶数层（从0开始）从左到右，奇数层从右到左
            if level % 2 == 0:
                result[level].append(node.val)
            else:
                result[level].insert(0, node.val)  # 插入到开头
            
            dfs(node.left, level + 1)
            dfs(node.right, level + 1)
        
        dfs(root, 0)
        return result
```

## 复杂度分析

**方法一/二：BFS**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，队列最多存储一层节点

**方法三：DFS**
- 时间复杂度：O(n²)，最坏情况下每层都要 insert(0, val)，时间复杂度 O(n)
- 空间复杂度：O(n)，递归栈 + 结果数组

## 关键点总结

1. **本质是 BFS**：在标准层序遍历基础上加入方向控制
2. **方向切换**：用布尔值标记，每层结束后取反
3. **反转方式**：
   - 简单：收集完再反转 `[::-1]`
   - 高效：使用双端队列控制插入方向
4. **层数判断**：第 0 层从左到右，第 1 层从右到左

## 易错点

1. **方向初始化**：第一层（层号0）应该从左到右
2. **反转时机**：在添加到结果前反转，而不是添加后
3. **DFS insert 性能**：insert(0) 在列表开头插入效率较低 O(n)
