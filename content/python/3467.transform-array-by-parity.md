## 题目描述

给你一个整数数组 `nums`。

将 `nums` 变换为另一个数组：将所有奇数替换为 1，将所有偶数替换为 0，然后将结果数组排序。

返回变换后的数组。

**示例 1：**

```
输入：nums = [4,3,2,1]
输出：[0,0,1,1]
解释：4->0, 3->1, 2->0, 1->1，排序后 [0,0,1,1]
```

**示例 2：**

```
输入：nums = [1,5,2,4,3]
输出：[0,0,1,1,1]
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 解题思路

统计奇数个数（即 1 的个数），偶数个数（即 0 的个数），然后构造结果数组（先放所有 0，再放所有 1）。

## Python 代码实现

### 方法一：计数（推荐）

```python
from typing import List

class Solution:
    def transformArray(self, nums: List[int]) -> List[int]:
        # 统计奇数个数
        odd_count = sum(1 for x in nums if x % 2 == 1)
        even_count = len(nums) - odd_count

        # 构造结果：先 even_count 个 0，再 odd_count 个 1
        return [0] * even_count + [1] * odd_count
```

### 方法二：先变换再排序

```python
from typing import List

class Solution:
    def transformArray(self, nums: List[int]) -> List[int]:
        transformed = [x % 2 for x in nums]  # 奇数变 1，偶数变 0
        return sorted(transformed)
```

### 方法三：一行写法

```python
from typing import List

class Solution:
    def transformArray(self, nums: List[int]) -> List[int]:
        return sorted(n % 2 for n in nums)
```

## 复杂度分析

- 方法一：O(n)
- 方法二：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 奇数变 1，偶数变 0：等价于 `x % 2`
2. 排序后必然是先所有 0，再所有 1
3. 无需真正排序，只需统计 0 和 1 的个数

## 易错点

1. 奇数变 1，偶数变 0（不是反过来）
2. 结果排序：0 在前，1 在后（升序）
