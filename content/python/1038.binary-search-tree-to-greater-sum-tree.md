## 题目描述

给定一个二叉搜索树的根节点 `root`，请将它转换为累加树（Greater Sum Tree），使每个节点 `node` 的新值等于原树中大于或等于 `node.val` 的所有节点值之和。

提醒一下，二叉搜索树满足下列约束条件：
- 节点的左子树仅包含键小于节点键的节点
- 节点的右子树仅包含键大于节点键的节点
- 左右子树也必须是二叉搜索树

**示例 1：**
```
输入：[4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]
```

**示例 2：**
```
输入：root = [0,null,1]
输出：[1,null,1]
```

**提示：**
- 树中的节点数在 `[1, 100]` 范围内
- `0 <= Node.val <= 100`
- 树中的所有值均不重复

**注意**：该题目与 538 题相同：https://leetcode.com/problems/convert-bst-to-greater-tree/

## 解题思路

这道题的关键是利用 **二叉搜索树的性质** 和 **反向中序遍历**。

**核心思想：**

1. **BST 的中序遍历**：按升序访问所有节点（左 → 根 → 右）
2. **反向中序遍历**：按降序访问所有节点（右 → 根 → 左）
3. **累加求和**：在反向中序遍历过程中，维护一个累加和，每访问一个节点就更新其值

**算法流程：**

1. 初始化累加和 `sum = 0`
2. 按照 **右 → 根 → 左** 的顺序遍历
3. 对于每个节点：
   - 先递归处理右子树（访问所有比当前节点大的节点）
   - 将累加和加到当前节点的值上
   - 更新累加和
   - 再递归处理左子树

**为什么用反向中序遍历？**

因为我们需要从大到小累加，而反向中序遍历正好是从大到小访问 BST 的所有节点。

## Python 代码实现

### 方法一：递归实现（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def bstToGst(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用递归进行反向中序遍历
        
        Args:
            root: 二叉搜索树的根节点
            
        Returns:
            转换后的累加树的根节点
        """
        self.sum = 0  # 累加和
        
        def reverse_inorder(node: Optional[TreeNode]) -> None:
            """
            反向中序遍历：右 → 根 → 左
            """
            if not node:
                return
            
            # 先遍历右子树（访问更大的节点）
            reverse_inorder(node.right)
            
            # 处理当前节点
            self.sum += node.val  # 累加当前节点值
            node.val = self.sum   # 更新节点值为累加和
            
            # 再遍历左子树
            reverse_inorder(node.left)
        
        reverse_inorder(root)
        return root
```

### 方法二：迭代实现（使用栈）

```python
from typing import Optional

class Solution:
    def bstToGst(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用栈进行迭代的反向中序遍历
        
        Args:
            root: 二叉搜索树的根节点
            
        Returns:
            转换后的累加树的根节点
        """
        stack = []
        node = root
        total = 0
        
        # 反向中序遍历的迭代实现
        while stack or node:
            # 一直向右走到底
            while node:
                stack.append(node)
                node = node.right
            
            # 处理栈顶节点
            node = stack.pop()
            total += node.val
            node.val = total
            
            # 转向左子树
            node = node.left
        
        return root
```

### 方法三：Morris 遍历（O(1) 空间）

```python
from typing import Optional

class Solution:
    def bstToGst(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用 Morris 遍历实现 O(1) 空间复杂度
        
        Morris 遍历通过修改树的结构来避免使用栈
        """
        total = 0
        node = root
        
        while node:
            if not node.right:
                # 右子树为空，直接处理当前节点
                total += node.val
                node.val = total
                node = node.left
            else:
                # 找到右子树中的最左节点（中序前驱）
                successor = node.right
                while successor.left and successor.left != node:
                    successor = successor.left
                
                if not successor.left:
                    # 建立临时连接
                    successor.left = node
                    node = node.right
                else:
                    # 恢复树结构，处理当前节点
                    successor.left = None
                    total += node.val
                    node.val = total
                    node = node.left
        
        return root
```

### 方法四：简洁的闭包写法

```python
from typing import Optional

class Solution:
    def bstToGst(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用闭包简化代码
        """
        def dfs(node: Optional[TreeNode], total: int) -> int:
            """
            返回包含当前节点及其左子树的累加和
            
            Args:
                node: 当前节点
                total: 从右子树传来的累加和
                
            Returns:
                包含当前子树的总累加和
            """
            if not node:
                return total
            
            # 先处理右子树，获得累加和
            total = dfs(node.right, total)
            
            # 更新当前节点
            total += node.val
            node.val = total
            
            # 处理左子树
            return dfs(node.left, total)
        
        dfs(root, 0)
        return root
```

## 复杂度分析

### 方法一、二、四：递归/迭代
- **时间复杂度**：O(n)，其中 n 是树中节点的数量，需要访问每个节点一次
- **空间复杂度**：
  - 递归：O(h)，h 是树的高度，最坏情况 O(n)（退化为链表）
  - 迭代：O(h)，栈的空间

### 方法三：Morris 遍历
- **时间复杂度**：O(n)，虽然有些边会被访问两次，但仍是线性时间
- **空间复杂度**：O(1)，只使用常数额外空间

## 关键点总结

1. **BST 性质**：利用中序遍历有序的特性
2. **反向遍历**：从大到小遍历，正好符合累加的需求
3. **累加和维护**：用一个变量记录已访问节点的和
4. **遍历顺序**：右 → 根 → 左（反向中序）
5. **空间优化**：可以用 Morris 遍历实现 O(1) 空间

## 易错点

1. **遍历顺序错误**：容易写成正常的中序遍历（左 → 根 → 右），导致结果错误
2. **累加和更新时机**：要先加上当前节点值，再更新节点值
3. **返回值**：不要忘记返回 root
4. **空节点处理**：要正确处理空节点的情况
5. **Morris 遍历的复杂性**：Morris 遍历需要找的是右子树的最左节点，而非左子树的最右节点
