## 题目描述

有一棵根节点为节点 0 的**家族树**，树中有 `n` 个节点，节点编号为 `0` 到 `n - 1`。给你一个下标从 0 开始的整数数组 `parents`，其中 `parents[i]` 是节点 `i` 的父节点。由于节点 0 是根节点，`parents[0] == -1`。

另给你一个下标从 0 开始的整数数组 `nums`，其中 `nums[i]` 是节点 `i` 对应的遗传值。树中所有节点的遗传值互不相同，且都是 `1` 到 `n` 之间的整数。

节点 `i` 的**子树**中所有节点（包含节点 `i` 自身）遗传值组成的集合为 `geneticSet(i)`。

节点 `i` 的**最小缺失遗传值**定义为 `geneticSet(i)` 中不存在的最小正整数。

请你返回一个长度为 `n` 的数组 `ans`，其中 `ans[i]` 是节点 `i` 的最小缺失遗传值。

**示例 1：**
```
输入：parents = [-1,0,0,2], nums = [1,2,3,4]
输出：[5,1,1,1]
```

**提示：**
- `n == parents.length == nums.length`
- `2 <= n <= 10^5`
- `0 <= parents[i] <= n - 1`（对于 i != 0）
- `parents[0] == -1`
- `1 <= nums[i] <= n`
- `nums[i]` 互不相同

## 解题思路

**关键观察：**
- 只有包含值 `1` 的子树，其答案才可能大于 `1`；其他节点的答案都是 `1`
- 找到值为 `1` 的节点，从该节点开始向上遍历到根节点的路径上的节点，需要维护一个不断扩大的遗传值集合
- 从包含 `1` 的最小子树开始，逐步扩大到其父节点的子树，用一个全局变量 `miss` 从 1 开始向上找缺失值

**算法流程：**
1. 找到 `nums[node] == 1` 的节点
2. 从该节点沿路径向上直到根节点，每到一个节点就将其子树所有值加入集合
3. 每次加入后更新 `miss`（最小缺失遗传值），记录到 `ans`
4. 路径外的所有节点答案都是 `1`

## 代码实现

### 方法一：DFS + 从含1的节点向上遍历（推荐）

```python
from typing import List

class Solution:
    def smallestMissingValueSubtree(self, parents: List[int], nums: List[int]) -> List[int]:
        n = len(parents)
        # 构建子节点列表
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)

        ans = [1] * n  # 默认答案为 1

        # 找到值为 1 的节点
        node_with_1 = -1
        for i in range(n):
            if nums[i] == 1:
                node_with_1 = i
                break

        if node_with_1 == -1:
            return ans  # 没有值为1的节点，所有答案都是1

        # 用 DFS 收集子树中的遗传值
        visited = set()

        def dfs(node: int):
            # 将当前节点及其子树的所有遗传值加入集合
            if node in visited:
                return
            visited.add(node)
            # 标记该节点的遗传值
            # 注意：我们用 visited 同时存节点，需要区分
            pass

        # 重新设计：用 node_visited 记录已处理节点，genetic_set 记录遗传值
        node_visited = [False] * n
        genetic_set = set()

        def collect(node: int):
            # 递归收集子树遗传值
            if node_visited[node]:
                return
            node_visited[node] = True
            genetic_set.add(nums[node])
            for child in children[node]:
                collect(child)

        miss = 1  # 当前缺失的最小值
        cur = node_with_1

        # 沿着路径向上遍历
        while cur != -1:
            collect(cur)  # 收集当前子树所有值
            # 更新 miss
            while miss in genetic_set:
                miss += 1
            ans[cur] = miss
            cur = parents[cur]  # 移动到父节点

        return ans
```

### 方法二：迭代式 DFS（避免递归栈溢出）

```python
from typing import List

class Solution:
    def smallestMissingValueSubtree(self, parents: List[int], nums: List[int]) -> List[int]:
        n = len(parents)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)

        ans = [1] * n
        node_visited = [False] * n
        genetic_set = set()

        node_with_1 = nums.index(1) if 1 in nums else -1
        if node_with_1 == -1:
            return ans

        def collect_iterative(start: int):
            # 迭代 DFS 收集子树遗传值
            stack = [start]
            while stack:
                node = stack.pop()
                if node_visited[node]:
                    continue
                node_visited[node] = True
                genetic_set.add(nums[node])
                for child in children[node]:
                    if not node_visited[child]:
                        stack.append(child)

        miss = 1
        cur = node_with_1

        while cur != -1:
            collect_iterative(cur)
            while miss in genetic_set:
                miss += 1
            ans[cur] = miss
            cur = parents[cur]

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点最多被访问一次
- 空间复杂度：O(n)，递归栈和遗传值集合

## 关键点总结

1. 只有值为 `1` 的节点的祖先链上，答案才可能大于 `1`
2. 从含 `1` 的节点沿路径向上，每次扩大子树范围
3. `miss` 是单调递增的，不需要每次从头扫描
4. 用 `node_visited` 避免重复处理子树节点

## 易错点

- 如果树中不存在值为 `1` 的节点，所有答案均为 `1`
- 递归可能导致栈溢出（n=10^5），建议用迭代 DFS
- `parents[0] == -1` 需要特殊处理循环终止
