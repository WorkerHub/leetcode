## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，表示弹珠的初始位置。同时给你两个长度相同的整数数组 `moveFrom` 和 `moveTo`，表示移动操作（将 `moveFrom[i]` 位置的所有弹珠移到 `moveTo[i]` 位置）。

执行所有操作后，返回所有弹珠所在的不同位置，按升序排列。

**示例 1：**
```
输入：nums = [1,6,7,8], moveFrom = [1,7,2], moveTo = [2,9,5]
输出：[5,6,8,9]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= moveFrom.length <= 10^5`

## 解题思路

使用集合维护所有弹珠位置。对每次操作：
- 若 `from != to`，从集合中移除 `from`，加入 `to`
- 若 `from == to`，不操作

最终排序集合返回。

## Python 代码实现

### 方法一：集合模拟（推荐）

```python
from typing import List

class Solution:
    def relocateMarbles(self, nums: List[int], moveFrom: List[int], moveTo: List[int]) -> List[int]:
        positions = set(nums)  # 当前所有弹珠位置

        for src, dst in zip(moveFrom, moveTo):
            if src != dst:
                positions.discard(src)
                positions.add(dst)

        return sorted(positions)
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，排序 O(n log n)，操作 O(q)
- 空间复杂度：O(n)

## 关键点总结

1. 集合自动处理重复位置
2. `src == dst` 时不需要操作
3. 最终排序返回

## 易错点

1. 注意多个弹珠可能在同一位置，集合处理这种情况（集合中只记录位置，不记录数量）
2. `discard` 不会报错（若元素不存在）
