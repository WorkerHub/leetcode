## 题目描述

给你一个整数数组 `nums`。每一步操作，删除所有满足 `nums[i-1] > nums[i]` 的 `nums[i]`（即同一步中所有符合条件的元素同时删除）。

返回使数组变成**非递减**所需的步数。

**示例 1：**
```
输入：nums = [5,3,4,4,7,3,6,11,8,5,11]
输出：3
```

**示例 2：**
```
输入：nums = [4,5,7,7,13]
输出：0
```

## 解题思路

**单调栈 DP：**

每个元素 `nums[i]` 被删除是因为左侧某个比它大的元素。定义 `dp[i]` 为 `nums[i]` 在第几步被删除（0 表示不会被删）。

用单调递减栈从左到右遍历：
- 当栈顶 `< nums[i]` 时（栈顶会被删除），弹出栈顶。
- `dp[i] = max(dp[i], dp[top] + 1)`（当前栈顶被当前元素挡住，如果栈顶还没被删，则当前元素在栈顶被删后的下一步才能被前面更大的元素删）。

最终答案为 `max(dp)`。

## 代码实现

### 方法一：单调栈 DP（推荐）

```python
from typing import List

class Solution:
    def totalSteps(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * n  # dp[i] 表示 nums[i] 被删除的步数
        stack = []    # 单调递减栈，存下标

        for i in range(n):
            cur_dp = 0
            while stack and nums[stack[-1]] <= nums[i]:
                # 栈顶被 nums[i] 右侧遮挡（等待被删），先被 nums[i] 吸收
                cur_dp = max(cur_dp, dp[stack.pop()])
            if stack:
                # 栈顶 > nums[i]，nums[i] 会在某步被删
                # nums[i] 至少需要等到 cur_dp + 1 步才被删
                dp[i] = cur_dp + 1
            stack.append(i)

        return max(dp)
```

### 方法二：模拟（暴力，用于验证）

```python
from typing import List

class Solution:
    def totalSteps(self, nums: List[int]) -> int:
        steps = 0
        while True:
            to_delete = set()
            for i in range(1, len(nums)):
                if nums[i - 1] > nums[i]:
                    to_delete.add(i)
            if not to_delete:
                break
            nums = [nums[i] for i in range(len(nums)) if i not in to_delete]
            steps += 1
        return steps
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，每个元素入栈出栈各一次。
- 空间复杂度：O(n)，栈和 dp 数组。

**方法二：**
- 时间复杂度：O(n^2)，每步最坏 O(n)，最多 n 步。

## 关键点总结

1. `dp[i]` 记录第 `i` 个元素在第几步被删（0 表示不删）。
2. 单调栈弹出时，被弹出元素的删除步数传递给当前元素。
3. 若栈为空（左侧无更大元素），`nums[i]` 不会被删，`dp[i] = 0`。

## 易错点

- `cur_dp = max(cur_dp, dp[stack.pop()])`：需要取弹出的所有栈顶 dp 值的最大值。
- `dp[i] = cur_dp + 1`：只有栈非空（左侧有更大值）时才设置。
- 答案是 `max(dp)` 而非 `sum(dp)`。
