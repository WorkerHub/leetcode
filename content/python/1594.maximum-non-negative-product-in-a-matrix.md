## 题目描述

给你一个 `m x n` 矩阵 `grid`，矩阵中的每个元素可以是负数、零或正数。

你需要从左上角 `(0, 0)` 走到右下角 `(m-1, n-1)`，每步只能向右或向下。

路径上所有元素之积称为该路径的乘积。返回路径乘积中的**最大非负积**，对 `10^9 + 7` 取模。如果最大非负积为负数，返回 `-1`。

**示例 1：**
```
输入：grid = [[-1,-2,-3],[-2,-3,-3],[-3,-3,-2]]
输出：-1
解释：所有路径的乘积都是负数。
```

**示例 2：**
```
输入：grid = [[1,-2,1],[1,-2,1],[3,-4,1]]
输出：8
```

**提示：**
- `1 <= m, n <= 15`
- `-4 <= grid[i][j] <= 4`

## 解题思路

### 动态规划（同时维护最大值和最小值）

路径中有负数，负负得正可能使乘积变大，因此需要同时追踪：
- `dp_max[i][j]`：到达 `(i,j)` 的最大乘积
- `dp_min[i][j]`：到达 `(i,j)` 的最小乘积（负数绝对值最大的负数）

**状态转移：**
设 `x = grid[i][j]`，来源为上方或左方：
- 若 `x >= 0`：`max = max(up_max, left_max) * x`，`min = min(up_min, left_min) * x`
- 若 `x < 0`：`max = min(up_min, left_min) * x`，`min = max(up_max, left_max) * x`

## 代码实现

### 方法一：DP 同时维护最大最小值（推荐）

```python
from typing import List

class Solution:
    def maxProductPath(self, grid: List[List[int]]) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])

        # dp_max, dp_min 分别存最大和最小乘积
        dp_max = [[0] * n for _ in range(m)]
        dp_min = [[0] * n for _ in range(m)]

        dp_max[0][0] = dp_min[0][0] = grid[0][0]

        # 初始化第一行
        for j in range(1, n):
            dp_max[0][j] = dp_min[0][j] = dp_max[0][j-1] * grid[0][j]

        # 初始化第一列
        for i in range(1, m):
            dp_max[i][0] = dp_min[i][0] = dp_max[i-1][0] * grid[i][0]

        # 状态转移
        for i in range(1, m):
            for j in range(1, n):
                x = grid[i][j]
                # 来自上方和左方的候选值
                candidates = [
                    dp_max[i-1][j] * x,
                    dp_min[i-1][j] * x,
                    dp_max[i][j-1] * x,
                    dp_min[i][j-1] * x,
                ]
                dp_max[i][j] = max(candidates)
                dp_min[i][j] = min(candidates)

        ans = dp_max[m-1][n-1]
        return -1 if ans < 0 else ans % MOD
```

### 方法二：滚动数组优化空间

```python
from typing import List

class Solution:
    def maxProductPath(self, grid: List[List[int]]) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])

        # 使用两行滚动
        prev_max = [0] * n
        prev_min = [0] * n
        prev_max[0] = prev_min[0] = grid[0][0]
        for j in range(1, n):
            prev_max[j] = prev_min[j] = prev_max[j-1] * grid[0][j]

        for i in range(1, m):
            cur_max = [0] * n
            cur_min = [0] * n
            cur_max[0] = cur_min[0] = prev_max[0] * grid[i][0]
            for j in range(1, n):
                x = grid[i][j]
                cands = [prev_max[j]*x, prev_min[j]*x, cur_max[j-1]*x, cur_min[j-1]*x]
                cur_max[j] = max(cands)
                cur_min[j] = min(cands)
            prev_max, prev_min = cur_max, cur_min

        ans = prev_max[n-1]
        return -1 if ans < 0 else ans % MOD
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：方法一 O(M * N)，方法二 O(N)

## 关键点总结

1. 同时维护最大值和最小值，应对负数乘负数
2. 每个状态取四种候选（来自两个方向 × 最大最小）的最大/最小
3. 最终答案取右下角最大值，若为负返回 -1，否则取模

## 易错点

- 取模只在最终结果非负时进行（不能边计算边取模，负数会失效）
- 负数乘以最小值（负数）得到最大值，逻辑不能弄反
