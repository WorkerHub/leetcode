## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

如果一个整数 `x` 在 `nums` 的每个长度为 `k` 的**连续子数组**中，最多出现**一次**（包括不出现），则称 `x` 为**几乎缺失**的整数。

返回所有几乎缺失整数中的**最大值**。如果不存在这样的整数，返回 -1。

**示例 1：**

```
输入：nums = [3,9,2,1,7], k = 3
输出：9
解释：
长度 3 的子数组：[3,9,2],[9,2,1],[2,1,7]
9 在 [3,9,2] 中出现 1 次，其他子数组不包含 9，满足条件
```

**示例 2：**

```
输入：nums = [3,3,3,3], k = 2
输出：-1
解释：所有长度 2 的子数组中，3 出现 2 次，不满足
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`
- `1 <= k <= nums.length`

## 解题思路

枚举 nums 中所有不同的值，检查每个值在所有长度为 k 的子数组中是否最多出现一次。

对于每个值 x，若在某个长度 k 的子数组中出现 >= 2 次，则 x 不满足条件。

## Python 代码实现

### 方法一：枚举值 + 检查每个子数组

```python
from typing import List

class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = -1

        for x in set(nums):
            valid = True
            # 检查每个长度 k 的子数组
            for i in range(n - k + 1):
                sub = nums[i: i + k]
                if sub.count(x) >= 2:
                    valid = False
                    break
            if valid:
                ans = max(ans, x)

        return ans
```

### 方法二：滑动窗口计数

```python
from typing import List
from collections import Counter

class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        n = len(nums)

        distinct_vals = set(nums)
        ans = -1

        for x in distinct_vals:
            # 检查 x 在每个长度 k 的子数组中是否最多出现 1 次
            # 用滑动窗口统计
            window_count = 0
            for i in range(k):
                if nums[i] == x:
                    window_count += 1

            valid = window_count <= 1

            for i in range(1, n - k + 1):
                if nums[i - 1] == x:
                    window_count -= 1
                if nums[i + k - 1] == x:
                    window_count += 1
                if window_count >= 2:
                    valid = False
                    break

            if valid:
                ans = max(ans, x)

        return ans
```

### 方法三：特殊情况优化

```python
from typing import List

class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        n = len(nums)

        if k == 1:
            # 每个长度 1 的子数组只有一个元素，任何值最多出现 1 次
            return max(nums)

        if k == n:
            # 只有一个子数组（整个数组），只有出现恰好 1 次的值满足
            from collections import Counter
            freq = Counter(nums)
            candidates = [x for x, cnt in freq.items() if cnt == 1]
            return max(candidates) if candidates else -1

        # 通用情况
        ans = -1
        for x in set(nums):
            valid = all(nums[i:i+k].count(x) <= 1 for i in range(n-k+1))
            if valid:
                ans = max(ans, x)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举值 * 滑动窗口
- 空间复杂度：O(n)

## 关键点总结

1. 几乎缺失：在**每个**长度 k 的子数组中最多出现 1 次
2. 对每个不同值检查所有子数组
3. 找满足条件的最大值

## 易错点

1. 是每个子数组中最多 1 次，不是整个数组中最多 1 次
2. k=1 时所有值都满足（每个子数组只有 1 个元素）
3. 不存在满足条件的值时返回 -1
