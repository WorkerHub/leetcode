## 题目描述

给你一个整数数组 `nums`。

如果一组数字 `(i, j)` 满足 `nums[i] == nums[j]` 且 `i < j`，就可以认为这是一组好数对。

返回好数对的数目。

**示例 1：**
```
输入：nums = [1,2,3,1,1,3]
输出：4
解释：有4组好数对，分别是 (0,3), (0,4), (3,4), (2,5)
```

**示例 2：**
```
输入：nums = [1,1,1,1]
输出：6
解释：数组中的每组数字都是好数对
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

### 方法一：暴力双重循环

对所有 `i < j` 的组合检查 `nums[i] == nums[j]`，时间复杂度 O(N^2)。

### 方法二：哈希表计数（推荐）

遍历数组，用哈希表记录每个数字出现的次数。当遇到数字 `x` 时，之前已有 `count[x]` 个相同数字，可以与当前数字组成 `count[x]` 个好数对。

**数学原理：** 若某个数字出现 `k` 次，则能组成 `k*(k-1)/2` 对好数对。

## 代码实现

### 方法一：暴力枚举

```python
from typing import List

class Solution:
    def numIdenticalPairs(self, nums: List[int]) -> int:
        count = 0
        n = len(nums)
        # 枚举所有 (i, j) 对，i < j
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] == nums[j]:
                    count += 1
        return count
```

### 方法二：哈希表一次遍历（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def numIdenticalPairs(self, nums: List[int]) -> int:
        count = defaultdict(int)
        ans = 0
        for num in nums:
            # 当前数字之前出现了 count[num] 次，可以形成 count[num] 个好数对
            ans += count[num]
            count[num] += 1
        return ans
```

### 方法三：数学公式（计数后一次计算）

```python
from typing import List
from collections import Counter

class Solution:
    def numIdenticalPairs(self, nums: List[int]) -> int:
        # 统计每个数字出现次数
        cnt = Counter(nums)
        # 每个数字 v 出现 k 次，贡献 k*(k-1)//2 对
        return sum(k * (k - 1) // 2 for k in cnt.values())
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（暴力） | O(N^2) | O(1) |
| 方法二（哈希表） | O(N) | O(N) |
| 方法三（数学） | O(N) | O(N) |

## 关键点总结

1. 一次遍历时，碰到重复数字就累加之前见过的相同数字数量
2. 数学公式：k 个相同数字能组成 `C(k,2) = k*(k-1)/2` 对
3. `Counter` 是统计频次的利器

## 易错点

- 方法一中 j 的范围是 `range(i+1, n)` 而不是 `range(i, n)`（避免 i=j 的情况）
- 方法二中要先 `ans += count[num]` 再 `count[num] += 1`，顺序不能颠倒
