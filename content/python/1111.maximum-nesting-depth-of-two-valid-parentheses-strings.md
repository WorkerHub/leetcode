## 题目描述

一个括号字符串是有效的，当且仅当：

- 它是空字符串
- 它可以被写成 `AB`（`A` 与 `B` 连接），其中 `A` 和 `B` 都是有效字符串
- 它可以被写成 `(A)`，其中 `A` 是有效字符串

有效括号字符串 `seq` 的嵌套深度定义为 `seq` 中嵌套的括号对数量的最大值。例如 `"(()())"` 的嵌套深度为 `2`，而 `"()()"` 的嵌套深度为 `1`。

给定一个有效的括号字符串 `seq`，将其分成两个不相交的子序列 `A` 和 `B`，使得：

- `A` 和 `B` 都是有效括号字符串
- `max(depth(A), depth(B))` 是最小可能的值

返回长度为 `seq.length` 的答案数组 `answer`，使用 `0` 和 `1` 填充，其中：

- `answer[i] = 0` 如果 `seq[i]` 属于子序列 `A`
- `answer[i] = 1` 如果 `seq[i]` 属于子序列 `B`

**示例 1：**
```
输入：seq = "(()())"
输出：[0,1,1,1,1,0]
解释：
A = "()()"，深度为 1
B = "()"，深度为 1
max(depth(A), depth(B)) = 1
```

**示例 2：**
```
输入：seq = "()(())()"
输出：[0,0,0,1,1,0,1,1]
解释：
A = "()()"，深度为 1
B = "(())"，深度为 2
max(depth(A), depth(B)) = 2（实际上有更优解）
```

**提示：**
- `1 <= seq.size <= 10000`
- `seq` 只包含 `'('` 和 `')'`

## 解题思路

这道题的关键是理解如何**均匀分配嵌套深度**，使得两个子序列的最大深度尽可能小。

**核心思想：**

1. **嵌套深度的计算**：
   - 遍历括号字符串
   - 遇到 `'('` 深度加 1
   - 遇到 `')'` 深度减 1
   - 当前深度就是嵌套层数

2. **最优分配策略**：
   - 将相同深度的括号对**交替分配**给 A 和 B
   - 如果当前深度是偶数，分配给 A（标记为 0）
   - 如果当前深度是奇数，分配给 B（标记为 1）
   - 这样可以保证两个子序列的深度大致相等

3. **为什么交替分配是最优的**：
   - 假设原序列的最大深度是 `d`
   - 交替分配后，两个子序列的最大深度约为 `⌈d/2⌉`
   - 这是理论上的最优解

## Python 代码实现

### 方法一：按深度奇偶性分配（推荐）

```python
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        answer = []
        depth = 0  # 当前深度
        
        for char in seq:
            if char == '(':
                # 左括号：先增加深度，再分配
                depth += 1
                # 深度为奇数分配给 B（1），偶数分配给 A（0）
                answer.append(depth % 2)
            else:  # char == ')'
                # 右括号：先分配，再减少深度
                answer.append(depth % 2)
                depth -= 1
        
        return answer
```

### 方法二：按索引奇偶性分配（简化版）

```python
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        # 观察：可以简单地按索引的奇偶性分配
        # 索引为偶数的分配给 A，奇数的分配给 B
        return [i % 2 if char == '(' else (i + 1) % 2 
                for i, char in enumerate(seq)]
```

### 方法三：栈模拟（直观理解）

```python
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        answer = []
        depth = 0
        
        for char in seq:
            if char == '(':
                # 当前深度的括号分配给哪个组
                # 偶数深度 -> A(0)，奇数深度 -> B(1)
                answer.append(depth % 2)
                depth += 1
            else:
                depth -= 1
                answer.append(depth % 2)
        
        return answer
```

### 方法四：更直观的写法

```python
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        result = []
        level = 0
        
        for bracket in seq:
            if bracket == '(':
                # 将当前层的左括号分配
                result.append(level % 2)
                level += 1
            else:
                level -= 1
                # 将当前层的右括号分配（与对应的左括号在同一组）
                result.append(level % 2)
        
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是字符串的长度，只需遍历一次
- 空间复杂度：O(1)，不计算返回值的空间，只使用常数额外空间

以 `seq = "(()())"` 为例：

索引:  0   1   2   3   4   5

处理过程：

位置1: '(' -> depth=1 -> 2, 分配 2%2=0

位置3: '(' -> depth=1 -> 2, 分配 2%2=0

实际运行：

位置1: '(' -> depth变为2, 分配 2%2=0

位置3: '(' -> depth变为2, 分配 2%2=0
位置4: ')' -> 分配 2%2=0, depth变为1
位置5: ')' -> 分配 1%2=1, depth变为0

## 关键点总结

1. **深度的含义**：表示当前位置的括号嵌套层数
2. **交替分配策略**：相邻的嵌套层分配给不同的组
3. **奇偶性的应用**：使用模 2 运算实现交替
4. **左右括号的处理差异**：
   - 左括号：先分配再增加深度（或先增加再分配）
   - 右括号：先减少深度再分配（或先分配再减少）
   - 两种顺序会影响结果，但都是正确的
5. **多解问题**：这道题有多个正确答案，只要满足最优性即可

## 易错点

1. **深度更新时机**：
   - 左括号是先更新深度还是先分配
   - 右括号是先更新深度还是先分配
   - 两者必须配对一致

2. **奇偶性反转**：
   - 使用 `depth % 2` 还是 `(depth + 1) % 2`
   - 不同的写法会得到互补的结果，但都正确

3. **边界情况**：
   - 空字符串（题目保证长度至少为 1）
   - 单层嵌套 `"()"`
   - 多层嵌套 `"((()))"`

4. **理解题意**：
   - 子序列是保持相对顺序的，不是子串
   - 分配后两个子序列必须都是有效括号串
