## 题目描述

给你一个整数数组 `height`，表示山的高度，以及一个整数 `threshold`。

如果山 `i`（`i != 0`）的前一座山的高度**严格大于** `threshold`，则称山 `i` 为**稳定的山**。

返回所有稳定山的下标，以任意顺序返回。

**示例 1：**
```
输入：height = [1,2,3,4,5], threshold = 2
输出：[3,4]
解释：
- 山 3：前一座山高度 3 > 2，稳定
- 山 4：前一座山高度 4 > 2，稳定
```

**示例 2：**
```
输入：height = [10,1,10,1,10], threshold = 3
输出：[1,3]
```

**提示：**
- `2 <= height.length <= 100`
- `1 <= height[i] <= 100`
- `1 <= threshold <= 100`

## 解题思路

遍历数组，对每个 i >= 1，检查 `height[i-1] > threshold`，若是则 i 是稳定的山。

## Python 代码实现

### 方法一：线性遍历（推荐）

```python
from typing import List

class Solution:
    def stableMountains(self, height: List[int], threshold: int) -> List[int]:
        result = []
        for i in range(1, len(height)):
            if height[i - 1] > threshold:
                result.append(i)
        return result
```

### 方法二：列表推导

```python
from typing import List

class Solution:
    def stableMountains(self, height: List[int], threshold: int) -> List[int]:
        return [i for i in range(1, len(height)) if height[i - 1] > threshold]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为结果数量

## 关键点总结

1. 稳定条件：前一座山高度严格大于 threshold
2. 从 i=1 开始遍历（i=0 无前山）
3. 返回满足条件的下标

## 易错点

1. 是严格大于（`>`），不是大于等于
2. 第 0 个山没有前山，不可能是稳定的山
