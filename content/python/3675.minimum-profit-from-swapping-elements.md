## 题目描述

给你两个整数数组 `profit` 和 `loss`（长度相同），以及整数 `k`。你可以交换 `profit[i]` 和 `loss[j]`（任意 i、j）最多 `k` 次。

目标是最大化 `sum(profit) - sum(loss)`。

**示例 1：**

```
输入：profit = [5,2,1], loss = [8,3,4], k = 2
输出：4
解释：交换 profit[0]=5 与 loss[0]=8 后，再交换 profit[1]=2 与 loss[2]=4
结果：profit=[8,3,1], loss=[5,2,4], 和差 = 12-11=1? 需重新计算
```

**提示：**

- `1 <= profit.length == loss.length <= 10^5`
- `1 <= k <= profit.length`

## 解题思路

贪心：每次交换应最大化收益变化。

交换 `profit[i]` 和 `loss[j]` 后，变化量 = `(loss[j] - profit[i]) - (profit[i] - loss[j]) = 2 * (loss[j] - profit[i])`（若 loss[j] > profit[i]）。

实际上，`sum(profit) - sum(loss)` 变化为：原 profit 增加 loss[j]-profit[i]，原 loss 增加 profit[i]-loss[j]。

变化量 = `2 * (loss[j] - profit[i])`。

贪心：选 k 对使 `loss[j] - profit[i]` 最大。即 loss 最大的 k 个与 profit 最小的 k 个交换（若收益为正）。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, profit: List[int], loss: List[int], k: int) -> int:
        base = sum(profit) - sum(loss)
        # 贪心：对每次交换，选最大的 (loss[j] - profit[i])
        # 即 loss 从大到小，profit 从小到大配对
        # 每次交换增益 = 2 * (loss[j] - profit[i])（若 > 0 才交换）

        sorted_loss = sorted(loss, reverse=True)
        sorted_profit = sorted(profit)

        for i in range(k):
            gain = 2 * (sorted_loss[i] - sorted_profit[i])
            if gain > 0:
                base += gain
            else:
                break  # 后续增益更小，不再交换

        return base
```

### 方法二：全部枚举 k 次

```python
from typing import List
import heapq

class Solution:
    def maxProfit(self, profit: List[int], loss: List[int], k: int) -> int:
        # 使用堆：profit 最小堆，loss 最大堆
        profit_heap = sorted(profit)
        loss_heap = sorted(loss, reverse=True)

        base = sum(profit) - sum(loss)
        for i in range(k):
            if loss_heap[i] > profit_heap[i]:
                base += 2 * (loss_heap[i] - profit_heap[i])
            else:
                break

        return base
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：每次交换选最优对（loss 最大 vs profit 最小）
2. 只有增益 > 0 时才值得交换
3. 最多交换 k 次

## 易错点

1. 负增益不应执行（直接 break）
2. 每次交换后，两个数组的元素都变了，需重新排序（或一次性选 k 个最优对）
3. 贪心预排序：选最大的 k 个差值对
