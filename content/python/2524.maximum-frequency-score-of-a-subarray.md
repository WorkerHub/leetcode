## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

子数组的 **频率分数** 定义为：子数组中每个 **不同** 元素的出现次数的幂次方之和。

正式地，若子数组中元素 x 出现 freq 次，则其贡献为 `x^freq`，频率分数 = 所有不同元素贡献之和（对 `10^9 + 7` 取模）。

返回长度恰好为 `k` 的子数组的 **最大频率分数**。

**示例 1：**

```
输入：nums = [1,1,1,2,1,2], k = 3
输出：5
解释：子数组 [2,1,2] 的频率分数 = 2^2 + 1^1 = 5。
```

**示例 2：**

```
输入：nums = [1,1,1,1,1,1], k = 4
输出：1
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

**滑动窗口 + 维护当前分数**。

对于长度为 k 的滑动窗口，维护当前频率分数。当窗口向右滑动时：
- 右端加入元素 x（频率从 freq 变为 freq+1）：分数变化 = x^(freq+1) - x^freq = x^freq * (x - 1)
- 左端移出元素 y（频率从 freq 变为 freq-1）：分数变化 = y^(freq-1) - y^freq = -y^(freq-1) * (y - 1)

使用模运算维护分数，注意减法取模。

## Python 代码实现

### 方法一：滑动窗口维护分数（推荐）

```python
from typing import List
from collections import defaultdict

MOD = 10**9 + 7

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        freq = defaultdict(int)
        score = 0

        # 初始化前 k 个元素的窗口
        for i in range(k):
            x = nums[i]
            # 分数变化：x^(freq+1) - x^freq
            score = (score + pow(x, freq[x] + 1, MOD) - pow(x, freq[x], MOD)) % MOD
            freq[x] += 1

        ans = score

        # 滑动窗口
        for i in range(k, n):
            # 右端加入 nums[i]
            x = nums[i]
            score = (score + pow(x, freq[x] + 1, MOD) - pow(x, freq[x], MOD)) % MOD
            freq[x] += 1

            # 左端移出 nums[i-k]
            y = nums[i - k]
            score = (score - pow(y, freq[y], MOD) + pow(y, freq[y] - 1, MOD)) % MOD
            freq[y] -= 1

            ans = max(ans, score)

        return ans
```

### 方法二：暴力枚举（用于验证小规模）

```python
from typing import List
from collections import Counter

MOD = 10**9 + 7

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n - k + 1):
            window = nums[i:i+k]
            cnt = Counter(window)
            score = sum(pow(x, f, MOD) for x, f in cnt.items()) % MOD
            ans = max(ans, score)

        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(n log M)，pow 操作 O(log M)，M 为元素最大值
- 方法二时间复杂度：O(n * k)，暴力枚举
- 空间复杂度：O(k)，频率哈希表

## 关键点总结

1. 滑动窗口维护频率，每次更新分数时只需调整变化的部分
2. 加入/移出元素时的分数变化：x^(f+1) - x^f 或 x^(f-1) - x^f
3. 减法取模时要加 MOD 避免负数：`(a - b + MOD) % MOD`

## 易错点

1. 模运算下的减法要加 MOD，防止结果为负
2. `pow(x, 0, MOD) = 1`，频率为 0 时贡献为 1（不是 0）
3. 窗口大小严格为 k，不是 <= k
