## 题目描述

你是产品经理，目前正在带领一个团队开发新的产品。不幸的是，你的产品的最新版本没有通过质量检测。由于每个版本都是基于之前的版本开发的，所以错误的版本之后的所有版本都是错误的。

假设你有 n 个版本 [1, 2, ..., n]，你想找出导致之后所有版本出错的第一个错误的版本。

你可以通过调用 `bool isBadVersion(version)` 接口来判断版本号 version 是否在单元测试中出错。实现一个函数来查找第一个错误的版本。你应该尽量减少对调用 API 的次数。

**示例 1：**
```
输入: n = 5, bad = 4
输出: 4
解释:
调用 isBadVersion(3) -> false 
调用 isBadVersion(5) -> true 
调用 isBadVersion(4) -> true
所以，4 是第一个错误的版本。
```

**示例 2：**
```
输入: n = 1, bad = 1
输出: 1
```

**提示：**
- 1 <= bad <= n <= 2^31 - 1

## 解题思路

这是一道经典的二分查找问题。

### 问题分析

版本序列有这样的特点：
- 第一个错误版本之前的所有版本都是正确的
- 第一个错误版本及之后的所有版本都是错误的

形式化表示：`[good, good, ..., good, bad, bad, ..., bad]`

我们要找的是第一个 bad 的位置。

### 二分查找思路

1. 定义搜索范围 `[left, right]`，初始为 `[1, n]`
2. 计算中点 `mid`，调用 `isBadVersion(mid)`
3. 如果 `isBadVersion(mid) == True`：
   - mid 是错误版本，第一个错误可能是 mid 或在 mid 左侧
   - 搜索范围缩小到 `[left, mid]`
4. 如果 `isBadVersion(mid) == False`：
   - mid 是正确版本，第一个错误一定在 mid 右侧
   - 搜索范围缩小到 `[mid+1, right]`
5. 重复直到找到第一个错误版本

### 注意事项

1. 防止整数溢出：`mid = left + (right - left) // 2`
2. 边界条件：确保循环能正确终止
3. 返回值：最后 left 指向第一个错误版本

### 方法一：标准二分查找（推荐）

```python
class Solution:
    def firstBadVersion(self, n: int) -> int:
        """
        二分查找第一个错误版本
        """
        left, right = 1, n
        
        while left < right:
            # 防止整数溢出
            mid = left + (right - left) // 2
            
            if isBadVersion(mid):
                # mid 是错误版本，第一个错误可能是 mid 或在左侧
                right = mid
            else:
                # mid 是正确版本，第一个错误在右侧
                left = mid + 1
        
        # 循环结束时 left == right，指向第一个错误版本
        return left
```

### 方法二：另一种二分模板

```python
class Solution:
    def firstBadVersion(self, n: int) -> int:
        """
        使用闭区间 [left, right] 的二分查找
        """
        left, right = 1, n
        result = n
        
        while left <= right:
            mid = left + (right - left) // 2
            
            if isBadVersion(mid):
                # 记录当前错误版本，继续向左找
                result = mid
                right = mid - 1
            else:
                # mid 正确，向右找
                left = mid + 1
        
        return result
```

### 方法三：Python 风格写法

```python
class Solution:
    def firstBadVersion(self, n: int) -> int:
```

### 方法四：详细注释版（便于理解）

```python
class Solution:
    def firstBadVersion(self, n: int) -> int:
        """
        详细解释每一步的二分查找
        """
        # 初始化搜索范围
        left = 1      # 最小版本号
        right = n     # 最大版本号
        
        # 当搜索范围大于 1 时继续查找
        while left < right:
            # 计算中点（防止溢出的写法）
            mid = left + (right - left) // 2
            
            # 检查中点版本是否是错误版本
            if isBadVersion(mid):
                # 情况 1: mid 是错误版本
                # 那么第一个错误版本 <= mid
                # 搜索范围缩小到 [left, mid]
                # 注意：不能是 mid-1，因为 mid 可能就是第一个错误版本
                right = mid
            else:
                # 情况 2: mid 是正确版本
                # 那么第一个错误版本 > mid
                # 搜索范围缩小到 [mid+1, right]
                left = mid + 1
        
        # 循环结束时，left == right
        # 这个位置就是第一个错误版本
        return left
```

### 方法五：递归版本（不推荐，仅供学习）

```python
class Solution:
    def firstBadVersion(self, n: int) -> int:
        """
        递归实现二分查找
        """
        def binary_search(left, right):
            if left >= right:
                return left
            
            mid = left + (right - left) // 2
            
            if isBadVersion(mid):
                return binary_search(left, mid)
            else:
                return binary_search(mid + 1, right)
        
        return binary_search(1, n)
```

## 复杂度分析

**时间复杂度：** O(log n)
- 每次将搜索范围减半
- 最多需要 log n 次查找

**空间复杂度：** O(1)
- 只使用常数额外空间（迭代版本）
- 递归版本：O(log n) 栈空间

**API 调用次数：** O(log n)
- 每次迭代调用一次 isBadVersion
- 总共最多 log n 次调用

## 关键点总结

1. **二分查找模板**：这是"查找第一个满足条件的位置"的经典模板
2. **边界更新**：
   - `isBadVersion(mid) == True`：`right = mid`（不是 mid-1）
   - `isBadVersion(mid) == False`：`left = mid + 1`
3. **循环条件**：`while left < right`，退出时 `left == right`
4. **防止溢出**：使用 `left + (right - left) // 2`
5. **返回值**：最后 left（或 right）就是答案

## 易错点

1. **整数溢出**（在某些语言中）
   ```python
   # 可能溢出（C++/Java 等语言）
   mid = (left + right) // 2
   
   # 安全的写法
   mid = left + (right - left) // 2
   
   # Python 中整数不会溢出，两种写法都可以
   ```

2. **边界更新错误**
   ```python
   # 错误：可能错过第一个错误版本
   if isBadVersion(mid):
       right = mid - 1  # 错误！
   
   # 正确：mid 可能就是第一个错误版本
   if isBadVersion(mid):
       right = mid  # 正确
   ```

3. **循环条件错误**
   ```python
   # 如果使用 left <= right，需要不同的边界更新逻辑
   while left <= right:
       ...
   
   # 推荐使用 left < right，逻辑更清晰
   while left < right:
       ...
   ```

4. **返回值错误**
   ```python
   # 错误：返回 mid（循环结束后 mid 的值不确定）
   return mid
   
   # 正确：返回 left 或 right（此时它们相等）
   return left
   ```

## 学习建议

1. **理解二分查找的本质**：
   - 在有序序列中快速定位目标
   - 每次将搜索范围减半

2. **掌握二分查找模板**：
   - 查找确定值：`while left <= right`
   - 查找第一个满足条件的位置：`while left < right`
   - 查找最后一个满足条件的位置：`while left < right`

3. **注意边界处理**：
   - 什么时候用 `mid`，什么时候用 `mid+1` 或 `mid-1`
   - 循环退出条件
   - 返回值是 left 还是 right

4. **练习建议**：
   - 先理解题目的有序性质
   - 手动模拟二分查找过程
   - 实现代码并测试边界情况

5. **常见应用场景**：
   - 在有序数组中查找元素
   - 查找第一个/最后一个满足条件的位置
   - 最小化最大值/最大化最小值问题
   - 答案在某个范围内的搜索问题
