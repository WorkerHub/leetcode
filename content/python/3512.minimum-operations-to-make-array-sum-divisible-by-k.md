## 题目描述

给定一个整数数组 `nums` 和正整数 `k`。每次操作可以将数组中任意一个元素减少 `1`。求最少操作次数，使得数组所有元素之和能被 `k` 整除。

**示例 1：**

```
输入：nums = [3, 9, 7], k = 5
输出：4
解释：数组和为 19，19 mod 5 = 4，需减少 4，操作 4 次。
```

**示例 2：**

```
输入：nums = [4, 1], k = 6
输出：5
解释：数组和为 5，5 mod 6 = 5，需减少 5，操作 5 次。
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`

## 解题思路

数学直接求解：
1. 计算数组总和 `s`
2. 计算 `r = s % k`
3. 如果 `r == 0`，数组和已能被 `k` 整除，返回 `0`
4. 否则，需要减少 `r`，即操作 `r` 次

每次操作将某个元素减 1，相当于总和减 1，因此最少操作次数就是 `s % k`。

## Python 代码实现

### 方法一：直接数学计算（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        s = sum(nums)
        return s % k
```

### 方法二：逐步减少

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        s = sum(nums)
        ops = 0
        # 每次减少1，直到能被 k 整除
        while s % k != 0:
            s -= 1
            ops += 1
        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，计算数组和
- 空间复杂度：O(1)

## 关键点总结

1. 最少操作次数 = 总和对 `k` 取余的结果
2. 只需减少（不能增加），所以答案是 `sum % k`
3. Python 的 `sum()` 内置函数一行即可求解

## 易错点

1. 注意只能减少不能增加，所以不能用 `(k - s % k) % k`（那是增加操作的答案）
2. 当总和已整除 `k` 时，`s % k == 0`，返回 `0`
