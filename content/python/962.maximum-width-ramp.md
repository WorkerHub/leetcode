## 题目描述

给定一个整数数组 `nums`，坡是元组 `(i, j)`，其中 `i < j` 且 `nums[i] <= nums[j]`。这样的坡的宽度为 `j - i`。

找出 `nums` 中的最大宽度的坡，如果不存在，返回 0。

**示例 1：**
```
输入：nums = [6,0,8,2,1,5]
输出：4
解释：
最大宽度的坡为 (i, j) = (1, 5): nums[1] = 0 且 nums[5] = 5。
```

**示例 2：**
```
输入：nums = [9,8,1,0,1,9,4,0,4,1]
输出：7
解释：
最大宽度的坡为 (i, j) = (2, 9): nums[2] = 1 且 nums[9] = 1。
```

**提示：**
- `2 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 5 * 10^4`

## 解题思路

这道题要求找到满足 `i < j` 且 `nums[i] <= nums[j]` 的最大 `j - i`。

**核心思想：**
1. 暴力法是枚举所有 (i, j) 对，时间复杂度 O(n²)
2. 优化方法：使用单调栈 + 逆序遍历
3. 关键观察：对于每个 j，我们希望找到最小的 i 使得 nums[i] <= nums[j]

**单调栈方法：**
1. **第一遍遍历**：从左到右构建单调递减栈，存储可能的左端点
   - 只保留那些可能成为最优解左端点的索引
   - 如果 nums[i] >= 栈顶元素，说明 i 永远不如栈顶优，因为栈顶索引更小且值也更小
2. **第二遍遍历**：从右到左遍历，寻找每个位置能匹配的最小索引
   - 对于每个 j，不断弹出栈顶，直到栈顶元素大于 nums[j]
   - 每次弹出时更新最大宽度

## Python 代码实现

### 方法一：单调栈（推荐）⭐

```python
from typing import List

class Solution:
    def maxWidthRamp(self, nums: List[int]) -> int:
        n = len(nums)
        stack = []
        
        # 第一遍：构建单调递减栈（存储索引）
        for i in range(n):
            # 只保留可能成为左端点的索引
            if not stack or nums[i] < nums[stack[-1]]:
                stack.append(i)
        
        max_width = 0
        
        # 第二遍：从右向左遍历，寻找最大宽度
        for j in range(n - 1, -1, -1):
            # 尽可能多地弹出满足条件的左端点
            while stack and nums[stack[-1]] <= nums[j]:
                i = stack.pop()
                max_width = max(max_width, j - i)
        
        return max_width
```

### 方法二：排序 + 贪心

```python
from typing import List

class Solution:
    def maxWidthRamp(self, nums: List[int]) -> int:
        # 将元素和索引一起排序
        # 按值升序排序，值相同时按索引升序
        sorted_pairs = sorted((num, i) for i, num in enumerate(nums))
        
        max_width = 0
        min_index = float('inf')
        
        # 遍历排序后的数组
        for num, i in sorted_pairs:
            # 当前索引与之前见过的最小索引的差值
            if i > min_index:
                max_width = max(max_width, i - min_index)
            # 更新最小索引
            min_index = min(min_index, i)
        
        return max_width
```

### 方法三：后缀最大值数组

```python
from typing import List

class Solution:
    def maxWidthRamp(self, nums: List[int]) -> int:
        n = len(nums)
        
        # suffix_max[i] 表示从 i 到末尾的最大值
        suffix_max = [0] * n
        suffix_max[-1] = nums[-1]
        
        for i in range(n - 2, -1, -1):
            suffix_max[i] = max(nums[i], suffix_max[i + 1])
        
        max_width = 0
        left = 0
        
        # 双指针：left 为左端点，right 为右端点
        for right in range(n):
            # 如果 nums[left] > suffix_max[right]，说明从 left 开始不可能有解
            while left < right and nums[left] > suffix_max[right]:
                left += 1
            
            max_width = max(max_width, right - left)
        
        return max_width
```

### 方法四：暴力法（理解用）

```python
from typing import List

class Solution:
    def maxWidthRamp(self, nums: List[int]) -> int:
        n = len(nums)
        max_width = 0
        
        # 枚举所有可能的 (i, j) 对
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] <= nums[j]:
                    max_width = max(max_width, j - i)
        
        return max_width
```

### 方法五：优化暴力（剪枝）

```python
from typing import List

class Solution:
    def maxWidthRamp(self, nums: List[int]) -> int:
        n = len(nums)
        max_width = 0
        
        for i in range(n):
            # 剪枝：如果剩余长度不足以超过当前最大宽度，直接退出
            if n - i <= max_width:
                break
            
            # 从后往前找第一个满足条件的 j
            for j in range(n - 1, i, -1):
                if nums[i] <= nums[j]:
                    max_width = max(max_width, j - i)
                    break  # 找到了就不用继续找更小的 j
        
        return max_width
```

## 复杂度分析

### 方法一：单调栈
- **时间复杂度**：O(n)，两次遍历，每个元素最多入栈出栈一次
- **空间复杂度**：O(n)，栈空间

### 方法二：排序
- **时间复杂度**：O(n log n)，排序的时间
- **空间复杂度**：O(n)，排序数组空间

### 方法三：后缀最大值
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，后缀数组空间

### 方法四：暴力
- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **单调栈应用**：用于维护可能的最优左端点集合
2. **逆序遍历**：从右向左遍历时，能找到每个右端点的最优左端点
3. **贪心思想**：对于每个右端点，越小的左端点越好
4. **栈的性质**：单调递减栈保证了从栈底到栈顶索引递增，值递减
5. **优化思路**：避免枚举所有 (i, j) 对，通过预处理降低复杂度

## 易错点

1. **栈的单调性**：应该是单调递减，不是递增
2. **遍历方向**：第二遍必须从右向左遍历
3. **更新时机**：在弹出栈元素时更新答案，而不是遍历结束后
4. **边界情况**：数组长度为 2 的情况
5. **栈的判断**：构建栈时是 `<` 不是 `<=`，因为相等值可以保留
