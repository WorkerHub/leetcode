## 题目描述

给定一个字符串 s，根据字符出现的频率对其进行降序排序。一个字符出现的频率是它出现在字符串中的次数。

返回已排序的字符串。如果有多个答案，返回其中任何一个。

**示例 1:**

```
输入: s = "tree"
输出: "eert"
解释: 'e' 出现两次，'r' 和 't' 都只出现一次。
因此 'e' 必须出现在 'r' 和 't' 之前。此外，"eetr" 也是一个有效的答案。
```

**示例 2:**

```
输入: s = "cccaaa"
输出: "aaaccc"
解释: 'c' 和 'a' 都出现三次。此外，"aaaccc" 也是有效的答案。
注意 "cacaca" 是不正确的，因为相同的字母必须放在一起。
```

**示例 3:**

```
输入: s = "Aabb"
输出: "bbAa"
解释: 此外，"bbaA" 也是一个有效的答案，但 "Aabb" 是不正确的。
注意 'A' 和 'a' 被认为是两种不同的字符。
```

**提示:**

- 1 <= s.length <= 5 * 10^5
- s 由大小写英文字母和数字组成

## 解题思路

这道题的核心是**统计频率**和**按频率排序**。

**解决方案：**

1. **哈希表 + 排序**：统计频率，然后排序
2. **桶排序**：按频率分桶，从高频到低频收集
3. **堆排序**：使用最大堆按频率排序
4. **Python 特色方法**：使用 Counter 和内置排序

## Python 代码实现

### 方法一：Counter + 排序（推荐，最简洁）

```python
from collections import Counter

class Solution:
    def frequencySort(self, s: str) -> str:
        """
        使用 Counter 统计频率，然后排序
        时间复杂度: O(n log n)
        空间复杂度: O(n)
        """
        # 统计每个字符的频率
        counter = Counter(s)
        
        # 按频率降序排序，然后拼接
        result = []
        for char, freq in counter.most_common():
            result.append(char * freq)
        
        return ''.join(result)
```

### 方法二：桶排序（时间复杂度最优）

```python
from collections import defaultdict

class Solution:
    def frequencySort(self, s: str) -> str:
        """
        桶排序，按频率分桶
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        # 统计频率
        freq_map = defaultdict(int)
        for char in s:
            freq_map[char] += 1
        
        # 创建桶：索引表示频率，值是该频率的字符列表
        max_freq = max(freq_map.values())
        buckets = [[] for _ in range(max_freq + 1)]
        
        for char, freq in freq_map.items():
            buckets[freq].append(char)
        
        # 从高频到低频收集结果
        result = []
        for freq in range(max_freq, 0, -1):
            for char in buckets[freq]:
                result.append(char * freq)
        
        return ''.join(result)
```

### 方法三：堆排序

```python
from collections import Counter
import heapq

class Solution:
    def frequencySort(self, s: str) -> str:
        """
        使用最大堆排序
        时间复杂度: O(n log k)，k 是不同字符数
        空间复杂度: O(n)
        """
        # 统计频率
        counter = Counter(s)
        
        # 创建最大堆（Python 是最小堆，所以使用负数）
        max_heap = [(-freq, char) for char, freq in counter.items()]
        heapq.heapify(max_heap)
        
        # 从堆中取出并构建结果
        result = []
        while max_heap:
            freq, char = heapq.heappop(max_heap)
            result.append(char * (-freq))
        
        return ''.join(result)
```

### 方法四：手动排序

```python
class Solution:
    def frequencySort(self, s: str) -> str:
        """
        手动统计和排序
        """
        # 统计频率
        freq_map = {}
        for char in s:
            freq_map[char] = freq_map.get(char, 0) + 1
        
        # 转换为列表并排序
        freq_list = [(char, freq) for char, freq in freq_map.items()]
        freq_list.sort(key=lambda x: x[1], reverse=True)
        
        # 构建结果
        result = []
        for char, freq in freq_list:
            result.append(char * freq)
        
        return ''.join(result)
```

### 方法五：Python 一行式

```python
from collections import Counter

class Solution:
    def frequencySort(self, s: str) -> str:
        """Python 简洁写法"""
        return ''.join(char * freq for char, freq in Counter(s).most_common())
```

## 复杂度分析

**方法一（Counter + 排序）：**
- 时间复杂度：O(n + k log k)，n 是字符串长度，k 是不同字符数
- 空间复杂度：O(n)

**方法二（桶排序）：**
- 时间复杂度：O(n)，线性时间
- 空间复杂度：O(n)

**方法三（堆排序）：**
- 时间复杂度：O(n + k log k)
- 空间复杂度：O(n)

## 关键点总结

1. **频率统计**：使用 Counter 或哈希表
2. **排序策略**：按频率降序排序
3. **字符重复**：使用 `char * freq` 生成重复字符
4. **桶排序优化**：利用频率范围有限的特点
5. **稳定性不要求**：相同频率的字符顺序任意

## 易错点

1. **忘记重复字符**：
   ```python
   # 错误：只添加字符一次
   result.append(char)
   
   # 正确：重复添加
   result.append(char * freq)
   ```

2. **排序方向错误**：
   ```python
   # 错误：升序排序
   freq_list.sort(key=lambda x: x[1])
   
   # 正确：降序排序
   freq_list.sort(key=lambda x: x[1], reverse=True)
   ```

3. **堆的负数处理**：
   - Python 的 heapq 是最小堆
   - 要实现最大堆需要使用负数

4. **字符串拼接效率**：
   ```python
   # 低效：反复创建新字符串
   result = ""
   for char in chars:
       result += char
   
   # 高效：使用列表 + join
   result = []
   for char in chars:
       result.append(char)
   return ''.join(result)
   ```

## 学习建议

1. **Counter 的使用**：
   - `most_common()` 返回频率最高的元素
   - `most_common(k)` 返回前 k 个
   - 这是 Python 处理频率问题的标准工具

2. **桶排序思想**：
   - 当数据范围有限时，桶排序可以达到 O(n)
   - 理解桶排序的适用场景

3. **堆的应用**：
   - 适合 Top K 问题
   - Python 使用负数实现最大堆

4. **字符串处理**：
   - `''.join(list)` 比反复 `+=` 效率高
   - `char * n` 可以快速生成重复字符

5. **性能对比**：
   - 桶排序：O(n)，最快
   - Counter + sort：O(n log k)，代码最简洁
   - 堆排序：O(n log k)，适合流式数据
