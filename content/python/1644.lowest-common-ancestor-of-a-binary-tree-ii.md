## 题目描述

给定一棵二叉树的根节点 `root` 和两个节点 `p` 和 `q`，返回节点 `p` 和 `q` 的最近公共祖先（LCA）。**节点 `p` 或 `q` 可能不在树中**，若其中一个不在树中，则返回 `None`。

**与 LCA I 的区别：** 原题 236 保证两个节点都在树中；本题不保证，若任一节点不在树中应返回 `None`。

## 解题思路

标准 LCA（236 题）的解法在 p 或 q 不在树中时会错误返回非 None。

**改进：** 需要额外检查 p 和 q 是否都在树中。

**方法：**
1. DFS 同时统计找到 p 和 q 的次数
2. 若 p 或 q 不在树中，返回 None

## 代码实现

### 方法一：DFS + 计数标记（推荐）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        found = [0]  # 记录找到 p 和 q 的数量
        
        def dfs(node: TreeNode) -> TreeNode:
            if not node:
                return None
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            # 若当前节点是 p 或 q，计数加 1
            if node == p or node == q:
                found[0] += 1
                # 注意：还需要检查子树中是否有另一个节点
                # 如果 left 或 right 已找到 LCA，返回它
                if left or right:
                    return left or right
                return node
            
            # 若左右子树各找到一个，当前节点是 LCA
            if left and right:
                return node
            
            return left or right
        
        result = dfs(root)
        return result if found[0] == 2 else None
```

### 方法二：两次 DFS（先检查存在性）

```python
class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        def contains(node: TreeNode, target: TreeNode) -> bool:
            if not node:
                return False
            if node == target:
                return True
            return contains(node.left, target) or contains(node.right, target)
        
        # 先检查 p 和 q 是否在树中
        if not contains(root, p) or not contains(root, q):
            return None
        
        # 标准 LCA
        def lca(node: TreeNode) -> TreeNode:
            if not node or node == p or node == q:
                return node
            left = lca(node.left)
            right = lca(node.right)
            if left and right:
                return node
            return left or right
        
        return lca(root)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 单次 DFS | O(n) | O(h) |
| 两次 DFS | O(n) | O(h) |

## 关键点总结

1. 与标准 LCA 的区别：需要确认 p 和 q 都在树中
2. 用 `found` 计数器：DFS 结束后若 found < 2，说明有节点不在树中
3. 两次 DFS 方法更直观，但效率略低

## 易错点

- 节点本身可能是另一个节点的祖先，此时不能提前返回，需要继续遍历子树
- `found[0]` 必须在 DFS 完成后才能判断，不能在中途返回时就判断
