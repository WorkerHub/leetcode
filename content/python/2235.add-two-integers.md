## 题目描述

给你两个整数 `num1` 和 `num2`，返回这两个整数的和。

**示例 1：**
```
输入：num1 = 12, num2 = 5
输出：17
```

**示例 2：**
```
输入：num1 = -10, num2 = 4
输出：-6
```

**提示：**
- `-100 <= num1, num2 <= 100`

## 解题思路

直接返回两数之和。这道题考查的是最基础的加法运算，适合入门练习。

## 代码实现

### 方法一：直接相加（推荐）

```python
class Solution:
    def sum(self, num1: int, num2: int) -> int:
        return num1 + num2
```

### 方法二：位运算（不使用 + 号）

```python
class Solution:
    def sum(self, num1: int, num2: int) -> int:
        # 位运算模拟加法（面试知识点）
        # Python 整数无限精度，需要处理负数的补码
        MASK = 0xFFFFFFFF  # 32位掩码
        MAX = 0x7FFFFFFF   # 32位最大正整数

        while num2 != 0:
            carry = (num1 & num2) << 1  # 进位
            num1 = (num1 ^ num2) & MASK  # 无进位加法
            num2 = carry & MASK

        # 处理负数（Python 整数是补码表示）
        return num1 if num1 <= MAX else ~(num1 ^ MASK)
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(1)。
- 空间复杂度：O(1)。

**方法二：**
- 时间复杂度：O(1)，循环次数不超过 32 次。
- 空间复杂度：O(1)。

## 关键点总结

1. 这是一道入门题，直接返回 `num1 + num2`。
2. 方法二用位运算模拟加法，是经典的面试考点（不使用算术加法）。
3. 异或运算完成无进位加法，与运算找出进位位，左移处理进位。

## 易错点

- 方法二中 Python 整数是任意精度，不会溢出，但需要用掩码模拟 32 位整数的溢出行为。
- 负数在 Python 中的补码需要特殊处理。
