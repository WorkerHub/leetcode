## 题目描述

给你两个长度为 `n` 的字符串 `source` 和 `target`，以及字符数组 `original` 和 `changed`，整数数组 `cost`，其中每次操作可以将字符 `original[i]` 转换为 `changed[i]`，代价为 `cost[i]`。

返回将 `source` 转换为 `target` 的最少总代价，若不可能则返回 -1。

**示例 1：**
```
输入：source = "abcd", target = "acbe", original = ["a","b","c","c","e","d"], changed = ["b","c","b","e","b","e"], cost = [2,5,5,1,2,20]
输出：28
```

**提示：**
- `1 <= source.length == target.length <= 10^5`
- `source, target` 只含小写字母
- `1 <= original.length == changed.length == cost.length <= 2000`
- `original[i], changed[i]` 是小写字母

## 解题思路

将字符 'a'-'z' 看作 26 个节点，操作看作有向边。问题变为：对 source 中每个字符，找到转换为 target 中对应字符的最短路。

用 Floyd-Warshall 预计算所有字符对之间的最短路（26 x 26），然后对每个位置查询即可。

## Python 代码实现

### 方法一：Floyd-Warshall（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, source: str, target: str, original: List[str], changed: List[str], cost: List[int]) -> int:
        INF = float('inf')
        # dist[i][j] = 将字符 i 转换为字符 j 的最小代价
        dist = [[INF] * 26 for _ in range(26)]
        for i in range(26):
            dist[i][i] = 0

        # 初始化边
        for o, c, w in zip(original, changed, cost):
            u = ord(o) - ord('a')
            v = ord(c) - ord('a')
            dist[u][v] = min(dist[u][v], w)

        # Floyd-Warshall
        for k in range(26):
            for i in range(26):
                for j in range(26):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        # 计算总代价
        total = 0
        for s, t in zip(source, target):
            if s == t:
                continue
            u, v = ord(s) - ord('a'), ord(t) - ord('a')
            if dist[u][v] == INF:
                return -1
            total += dist[u][v]

        return total
```

### 方法二：Dijkstra（每个源字符跑一次）

```python
from typing import List
import heapq

class Solution:
    def minimumCost(self, source: str, target: str, original: List[str], changed: List[str], cost: List[int]) -> int:
        INF = float('inf')
        graph = [[] for _ in range(26)]
        for o, c, w in zip(original, changed, cost):
            u = ord(o) - ord('a')
            v = ord(c) - ord('a')
            graph[u].append((v, w))

        def dijkstra(src: int):
            dist = [INF] * 26
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in graph[u]:
                    if dist[u] + w < dist[v]:
                        dist[v] = dist[u] + w
                        heapq.heappush(heap, (dist[v], v))
            return dist

        # 预计算所有需要的源字符的最短路
        needed_chars = set(ord(s) - ord('a') for s in source)
        all_dist = {}
        for c in needed_chars:
            all_dist[c] = dijkstra(c)

        total = 0
        for s, t in zip(source, target):
            if s == t:
                continue
            u, v = ord(s) - ord('a'), ord(t) - ord('a')
            d = all_dist[u][v]
            if d == INF:
                return -1
            total += d

        return total
```

## 复杂度分析

- 时间复杂度：O(26^3 + n)，Floyd 预计算 O(26^3)，遍历字符串 O(n)
- 空间复杂度：O(26^2)，距离矩阵

## 关键点总结

1. 字符转换问题转化为图的最短路
2. 字母只有 26 个，Floyd-Warshall 代价极低（26^3 = 17576）
3. 每个位置独立查询，不同位置之间无依赖

## 易错点

1. 同一对字符可能有多条边（取最小），初始化时用 min
2. source[i] == target[i] 时代价为 0，无需转换
3. 某对字符不可达时，整体返回 -1
