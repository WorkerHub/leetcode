## 题目描述

给你一个字符串 `message` 和一个正整数 `limit`。

你需要根据 `limit` 将 `message` **分割** 成一个或多个 **部分**。每个部分的结尾都是 `"<a/b>"`，其中 `"b"` 用分割出来的总数 **替换**，`"a"` 用当前部分的下标 **替换**（下标从 `1` 开始），除了 `"<a/b>"` 以外的部分，每个部分的长度都不应该超过 `limit`。

如果按照上述条件无法分割 `message`，则返回一个空数组。

**示例 1：**
```
输入：message = "this is really a very awesome message", limit = 9
输出：["thi<1/14>","s i<2/14>","s r<3/14>","eal<4/14>","ly <5/14>","a v<6/14>","ery<7/14>"," aw<8/14>","eso<9/14>","me<10/14>"," m<11/14>","es<12/14>","sa<13/14>","ge<14/14>"]
```

**提示：**
- `1 <= message.length <= 10^4`
- `message` 只含英文小写字母和 `' '`
- `1 <= limit <= 10^4`

## 解题思路

**二分查找总份数 k：**

给定总份数 k，检查是否能在每份不超过 limit 字符的前提下分割完 message。

对于 k 份：
- 每份的尾缀是 `"<i/k>"`，长度为 `len(str(i)) + len(str(k)) + 3`（`<`、`/`、`>`各1个）
- 每份剩余可用于 message 的字符数 = `limit - suffix_len`

若所有份数的可用字符总数 >= `len(message)` 且每份至少有 1 个字符（即 `limit - suffix_len >= 1`），则 k 份可行。

**二分查找最小可行的 k。**

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def splitMessage(self, message: str, limit: int) -> List[str]:
        n = len(message)

        def check(k: int) -> bool:
            """检查分成 k 份是否可行"""
            total_chars = 0
            k_len = len(str(k))
            for i in range(1, k + 1):
                i_len = len(str(i))
                # 后缀 "<i/k>" 的长度 = i_len + k_len + 3
                suffix_len = i_len + k_len + 3
                avail = limit - suffix_len
                if avail <= 0:
                    return False
                total_chars += avail
            return total_chars >= n

        # 二分查找最小的 k
        lo, hi = 1, n  # k 最少 1 份，最多 n 份（每份 1 个字符）
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1

        k = lo
        if not check(k):
            return []

        # 构造分割结果
        result = []
        pos = 0  # message 的当前位置
        k_len = len(str(k))

        for i in range(1, k + 1):
            i_len = len(str(i))
            suffix = f"<{i}/{k}>"
            avail = limit - len(suffix)
            part_msg = message[pos:pos + avail]
            result.append(part_msg + suffix)
            pos += avail

        return result
```

### 方法二：线性枚举（适合小数据）

```python
from typing import List

class Solution:
    def splitMessage(self, message: str, limit: int) -> List[str]:
        n = len(message)

        for k in range(1, n + 1):
            k_str = str(k)
            total_avail = 0
            valid = True
            for i in range(1, k + 1):
                suffix_len = len(str(i)) + len(k_str) + 3
                avail = limit - suffix_len
                if avail <= 0:
                    valid = False
                    break
                total_avail += avail
            if valid and total_avail >= n:
                # 构造结果
                result = []
                pos = 0
                for i in range(1, k + 1):
                    suffix = f"<{i}/{k}>"
                    avail = limit - len(suffix)
                    result.append(message[pos:pos + avail] + suffix)
                    pos += avail
                return result

        return []
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(n log n) | O(n) |
| 线性枚举 | O(n^2) | O(n) |

## 关键点总结

1. 二分答案 k（总份数），检查可行性
2. 后缀长度依赖 i 和 k 的位数，需逐份计算
3. 所有份的可用字符总和 >= n，且每份 avail >= 1

## 易错点

- 后缀格式 `<i/k>` 的长度 = `len(str(i)) + len(str(k)) + 3`
- 若 `limit <= len("<1/1>")` 即 limit 太小，可能无法分割
