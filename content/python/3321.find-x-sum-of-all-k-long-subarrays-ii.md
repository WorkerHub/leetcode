## 题目描述

与 3318 相同，但数据范围更大：`nums.length <= 10^5`，需要高效解法。

给你整数数组 `nums`，整数 `k` 和 `x`。对每个长度为 `k` 的子数组计算 x-sum（选频率最高的 x 种数字，同频选数值大的）。

**提示：**
- `1 <= x <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**双堆维护 top-x：**

维护两个堆：
- `top`：大小为 x 的最大堆（按 `(freq, val)` 排序），包含贡献 x-sum 的元素。
- `bot`：其余元素的最小堆。

滑动窗口移动时：
1. 加入新元素：更新频率，调整它在 top 或 bot 中的位置，同时维护 x-sum。
2. 移出旧元素：更新频率，调整位置，维护 x-sum。
3. 保持 top 大小为 `min(x, 不同元素个数)`。

Python 中使用 `SortedList`（来自 `sortedcontainers`）或用两个堆模拟。

**简化实现：** 用 `SortedList` 维护按 `(freq, val)` 排序的所有元素，x-sum 就是最大的 x 个元素的贡献。

## Python 代码实现

### 方法一：SortedList（推荐）

```python
from typing import List
from collections import defaultdict
from sortedcontainers import SortedList

class Solution:
    def findXSum(self, nums: List[int], k: int, x: int) -> List[int]:
        n = len(nums)
        freq = defaultdict(int)
        # 有序列表按 (freq, val) 排序（升序）
        sl = SortedList(key=lambda item: (item[1], item[0]))
        # 每个元素是 (val, freq)
        # x_sum: 当前 top-x 的贡献
        x_sum = 0
        result = []
        
        # 辅助：从 SortedList 中取最后 x 个元素的贡献
        def compute():
            total = 0
            for i in range(min(x, len(sl))):
                v, f = sl[-(i+1)]
                total += v * f
            return total
        
        # 由于 SortedList 每次操作 O(log n)，compute() O(x)，总时间 O(nk) 仍可能超时
        # 改为维护增量式的 x_sum
        
        # 重新实现：维护 x_sum 增量
        freq2 = defaultdict(int)
        sl2 = SortedList()  # 元素是 (freq, val)，升序
        x_sum2 = 0
        
        def add(val, in_top):
            nonlocal x_sum2
            if in_top:
                x_sum2 += val
        
        def remove_val(val, cur_freq):
            nonlocal x_sum2
            # 先从 sl2 中移除 (cur_freq, val)
            sl2.remove((cur_freq, val))
        
        # 维护：sl2 的最后 x 个元素就是 top-x
        # 当元素频率变化时，更新 sl2 和 x_sum2
        
        def in_top(val, freq_val):
            """判断 (freq_val, val) 是否在 top-x 中"""
            idx = sl2.bisect_left((freq_val, val))
            return idx >= len(sl2) - x  # 在末尾 x 个位置中
        
        def update_xsum_add(val, old_freq, new_freq):
            nonlocal x_sum2
            # 先移除旧的
            if old_freq > 0:
                sl2.remove((old_freq, val))
                if in_top_check(old_freq, val, before_remove=True):
                    x_sum2 -= val * old_freq
            # 加入新的
            sl2.add((new_freq, val))
            if in_top_check(new_freq, val, before_remove=False):
                x_sum2 += val * new_freq
        
        # 实现复杂，改用直接每次计算
        # 对于竞赛，使用 SortedList + 直接计算最后 x 个
        
        freq3 = defaultdict(int)
        sl3 = SortedList()  # 存 (freq, val)
        cur_sum = 0
        res = []
        
        def get_xsum():
            total = 0
            for i in range(1, min(x, len(sl3)) + 1):
                f, v = sl3[-i]
                total += f * v
            return total
        
        def add_num(val):
            f = freq3[val]
            if f > 0:
                sl3.remove((f, val))
            freq3[val] += 1
            sl3.add((freq3[val], val))
        
        def remove_num(val):
            f = freq3[val]
            sl3.remove((f, val))
            freq3[val] -= 1
            if freq3[val] > 0:
                sl3.add((freq3[val], val))
            else:
                del freq3[val]
        
        # 初始化第一个窗口
        for i in range(k):
            add_num(nums[i])
        res.append(get_xsum())
        
        # 滑动
        for i in range(1, n - k + 1):
            remove_num(nums[i - 1])
            add_num(nums[i + k - 1])
            res.append(get_xsum())
        
        return res
```

## 复杂度分析

- 时间复杂度：O(n * (log n + x))，每次滑动 O(log n)，计算 xsum O(x)
- 空间复杂度：O(n)

## 关键点总结

1. `SortedList` 维护 `(freq, val)` 对，支持 O(log n) 的插入/删除。
2. x-sum 是 SortedList 末尾最大 x 个元素的 `freq * val` 之和。
3. 每次窗口滑动：移出旧元素（更新频率）、加入新元素（更新频率），各需两次 SortedList 操作。

## 易错点

1. 频率变化时需先移除旧的 `(freq, val)`，再加入新的 `(new_freq, val)`。
2. 频率降为 0 时，从字典中删除该元素，避免无效键。
3. `SortedList` 按 `(freq, val)` 升序，取末尾的 x 个就是最大的 x 个。
