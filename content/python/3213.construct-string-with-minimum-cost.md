## 题目描述

给你一个字符串 `target`、一个字符串数组 `words` 和一个整数数组 `costs`，其中 `costs[i]` 表示选用 `words[i]` 的花费。

你需要用 `words` 中的字符串**拼接**得到 `target`，每次可以选用 `words[i]` 附加到当前字符串末尾，花费 `costs[i]`。

返回构造 `target` 所需的**最小总花费**。若无法构造，返回 `-1`。

**示例 1：**
```
输入：target = "abcdef", words = ["abdef","abc","d","def","ef"], costs = [100,1,1,10,5]
输出：7
解释：选 "abc"（花费1） + "d"（花费1） + "ef"（花费5）= 7
```

**示例 2：**
```
输入：target = "aaaa", words = ["z","zz","zzz"], costs = [1,10,100]
输出：-1
```

**提示：**
- `1 <= target.length <= 5 * 10^4`
- `1 <= words.length <= 5 * 10^4`
- `1 <= words[i].length <= target.length`
- `words[i]` 和 `target` 只含小写字母

## 解题思路

经典字符串 DP + 字典树优化：

- `dp[i]` 表示构造 `target[0..i-1]` 的最小花费
- 转移：`dp[i] = min(dp[j] + cost)` 其中 `words[k] == target[j..i-1]`
- 暴力转移 O(n^2 * m) 会超时

优化：用**字典树（Trie）**存储所有 words，并记录每个单词结尾的最小 cost。从每个位置 `i` 开始向右匹配字典树，找到所有能覆盖到的终止节点。

## Python 代码实现

### 方法一：字典树 + DP（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, target: str, words: List[str], costs: List[int]) -> int:
        # 构建字典树
        # 每个节点：{char: node_idx}，并记录该位置的最小 cost
        trie = [{}]       # trie[i] = {char: child_idx}
        min_cost = [0]    # min_cost[i] = 该节点作为单词结尾的最小花费（0表示不是结尾）
        
        for word, cost in zip(words, costs):
            node = 0
            for c in word:
                if c not in trie[node]:
                    trie.append({})
                    min_cost.append(0)
                    trie[node][c] = len(trie) - 1
                node = trie[node][c]
            # 更新最小花费
            if min_cost[node] == 0:
                min_cost[node] = cost
            else:
                min_cost[node] = min(min_cost[node], cost)
        
        n = len(target)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(n):
            if dp[i] == INF:
                continue
            # 从位置 i 开始，沿字典树向右匹配
            node = 0
            for j in range(i, n):
                c = target[j]
                if c not in trie[node]:
                    break
                node = trie[node][c]
                if min_cost[node] > 0:
                    dp[j + 1] = min(dp[j + 1], dp[i] + min_cost[node])
        
        return dp[n] if dp[n] != INF else -1
```

### 方法二：哈希表 + DP（简化版，适合中等数据量）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumCost(self, target: str, words: List[str], costs: List[int]) -> int:
        # 按长度分组，哈希查找
        word_map = defaultdict(lambda: float('inf'))
        for word, cost in zip(words, costs):
            word_map[word] = min(word_map[word], cost)
        
        n = len(target)
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(n):
            if dp[i] == INF:
                continue
            for j in range(i + 1, n + 1):
                sub = target[i:j]
                if sub in word_map:
                    dp[j] = min(dp[j], dp[i] + word_map[sub])
        
        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 方法一（字典树）：时间复杂度 O(n^2 + L)，L 为所有 words 总长度；空间复杂度 O(L)
- 方法二（哈希）：时间复杂度 O(n^2)，但字符串哈希有常数开销

## 关键点总结

1. 字典树从每个起点向右扩展，避免重复计算前缀
2. 同一个单词可能有多个 cost，只保留最小值
3. dp[0] = 0 为初始状态

## 易错点

1. 字典树中同一节点的 cost 可能更新多次，要保留最小值
2. 无法构造时返回 -1 而非 0
