## 题目描述

给定一个整数数组 `arr`，每次操作可以选择一个回文子数组 `arr[i], arr[i+1], ..., arr[j]`（其中 `i <= j`），并将其从数组中移除。

注意，移除子数组后，左右两侧的元素会向中间移动填补空缺。

返回移除数组中所有数字所需的最少操作次数。

**示例 1：**

```
输入：arr = [1,2]
输出：2
解释：每个元素都不是回文，需要分别移除，因此需要 2 次操作。
```

**示例 2：**

```
输入：arr = [1,3,4,1,5]
输出：3
解释：
- 移除 [4]，剩余 [1,3,1,5]
- 移除 [1,3,1]，剩余 [5]
- 移除 [5]
总共 3 次操作。
```

**提示：**

- `1 <= arr.length <= 100`
- `1 <= arr[i] <= 20`

## 解题思路

这是一道经典的**区间动态规划**问题。

**核心思想：**

定义 `dp[i][j]` 表示移除子数组 `arr[i:j+1]`（包含 `arr[j]`）所需的最少操作次数。

**状态转移：**

1. **基础情况**：
   - 单个元素：`dp[i][i] = 1`，一个元素本身是回文，需要 1 次操作
   - 空区间：`dp[i][j] = 0`（当 `i > j` 时）

2. **两端元素相同**（`arr[i] == arr[j]`）：
   - 如果 `i + 1 == j`：两个相同元素构成回文，`dp[i][j] = 1`
   - 否则：可以把 `arr[i]` 和 `arr[j]` 与中间的元素一起考虑
     - 如果中间能形成回文，三者可以一起移除
     - `dp[i][j] = dp[i+1][j-1]`（将两端与中间合并）

3. **分割情况**：
   - 将区间 `[i, j]` 分成两部分 `[i, k]` 和 `[k+1, j]`
   - `dp[i][j] = min(dp[i][k] + dp[k+1][j])` 对所有 `k` 取最小值

**关键观察：**
- 当 `arr[i] == arr[j]` 时，两端可能与中间形成更大的回文
- 需要枚举所有可能的分割点，取最小值
- 区间 DP 通常按长度从小到大递推

## Python 代码实现

### 方法一：区间动态规划（推荐）⭐

```python
class Solution:
    def minimumMoves(self, arr: List[int]) -> int:
        n = len(arr)
        # dp[i][j] 表示移除 arr[i:j+1] 所需的最少操作次数
        dp = [[0] * n for _ in range(n)]
        
        # 初始化：单个元素需要 1 次操作
        for i in range(n):
            dp[i][i] = 1
        
        # 按区间长度递推（从小到大）
        for length in range(2, n + 1):  # 区间长度 2 到 n
            for i in range(n - length + 1):
                j = i + length - 1  # 右端点
                
                # 默认值：将 arr[i] 单独移除，剩余部分递归处理
                dp[i][j] = 1 + dp[i+1][j] if i + 1 <= j else 1
                
                # 两端元素相同的情况
                if arr[i] == arr[j]:
                    if i + 1 == j:
                        # 只有两个元素，构成回文，1 次操作
                        dp[i][j] = 1
                    else:
                        # 两端与中间合并
                        dp[i][j] = dp[i+1][j-1]
                
                # 尝试所有分割点
                for k in range(i, j):
                    dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j])
        
        return dp[0][n-1]
```

### 方法二：记忆化递归

使用递归 + 记忆化实现区间 DP，代码更简洁。

```python
class Solution:
    def minimumMoves(self, arr: List[int]) -> int:
        from functools import lru_cache
        
        @lru_cache(None)
        def dp(i: int, j: int) -> int:
            # 区间为空
            if i > j:
                return 0
            # 单个元素
            if i == j:
                return 1
            
            # 两端元素相同
            if arr[i] == arr[j]:
                if i + 1 == j:
                    return 1  # 只有两个相同元素
                else:
                    res = dp(i + 1, j - 1)  # 两端与中间合并
            else:
                res = float('inf')
            
            # 尝试所有分割点
            for k in range(i, j):
                res = min(res, dp(i, k) + dp(k + 1, j))
            
            return res
        
        return dp(0, len(arr) - 1)
```

### 方法三：优化版本（处理边界）

```python
class Solution:
    def minimumMoves(self, arr: List[int]) -> int:
        n = len(arr)
        dp = [[float('inf')] * n for _ in range(n)]
        
        # 单个元素初始化
        for i in range(n):
            dp[i][i] = 1
        
        # 两个元素初始化
        for i in range(n - 1):
            dp[i][i+1] = 1 if arr[i] == arr[i+1] else 2
        
        # 区间长度从 3 开始
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                # 两端相同，尝试合并
                if arr[i] == arr[j]:
                    dp[i][j] = dp[i+1][j-1]
                
                # 尝试分割
                for k in range(i, j):
                    dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j])
        
        return dp[0][n-1]
```

## 复杂度分析

- **时间复杂度**：O(n³)
  - 外层循环枚举区间长度：O(n)
  - 内层循环枚举起点和终点：O(n²)
  - 最内层循环枚举分割点：O(n)
  - 总计 O(n³)

- **空间复杂度**：O(n²)
  - DP 数组大小为 n × n

## 关键点总结

1. **区间 DP 模板**：按长度递推，从小区间到大区间
2. **状态定义**：`dp[i][j]` 表示区间 `[i, j]` 的答案
3. **两端相同的优化**：当 `arr[i] == arr[j]` 时，可以与中间合并
4. **分割策略**：枚举所有分割点 `k`，取最小值
5. **初始化**：单个元素为 1，空区间为 0

## 易错点

1. **区间边界**：注意 `i + 1 > j - 1` 的情况（中间为空）
2. **初始化顺序**：必须先处理小区间，再处理大区间
3. **两端相同时的处理**：不能遗漏 `dp[i+1][j-1]` 的情况
4. **分割点范围**：`k` 的范围是 `[i, j)`，注意不包含 `j`
5. **默认值设置**：`dp[i][j]` 初始化时可以设为 `1 + dp[i+1][j]`

## 图解示例

以 `arr = [1,3,4,1,5]` 为例：

```
步骤 1：初始化单个元素
dp[0][0] = 1, dp[1][1] = 1, ..., dp[4][4] = 1

步骤 2：计算长度为 2 的区间
dp[0][1]: arr[0]=1, arr[1]=3 不同 → 2
dp[1][2]: arr[1]=3, arr[2]=4 不同 → 2
dp[2][3]: arr[2]=4, arr[3]=1 不同 → 2
dp[3][4]: arr[3]=1, arr[4]=5 不同 → 2

步骤 3：计算长度为 3 的区间
dp[0][2]: 分割 → min(dp[0][0]+dp[1][2], dp[0][1]+dp[2][2]) = min(3, 3) = 3
dp[1][3]: arr[1]=3, arr[3]=1 不同 → 分割 → 3
dp[2][4]: 分割 → 3

步骤 4：计算长度为 4 的区间
dp[0][3]: arr[0]=1, arr[3]=1 相同 → dp[1][2] = 2

步骤 5：计算长度为 5 的区间
dp[0][4]: 分割 → min(dp[0][3]+dp[4][4], ...) = min(3, ...) = 3
```
