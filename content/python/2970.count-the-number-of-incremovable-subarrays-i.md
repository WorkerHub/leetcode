## 题目描述

给你一个整数数组 `nums`，如果从 `nums` 中删除一个子数组后，剩余元素（保持原来的相对顺序拼接在一起）严格递增，则称该子数组为 **递增可删除子数组**。

返回 `nums` 中递增可删除子数组的总数目。

**示例 1：**
```
输入：nums = [1,2,3,4]
输出：10
解释：所有子数组都满足条件，共 10 个
```

**示例 2：**
```
输入：nums = [6,5,7,8]
输出：7
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

枚举所有子数组（l, r），删除后检查剩余部分是否严格递增。

剩余部分为 `nums[0..l-1]` + `nums[r+1..n-1]`，需要：
1. `nums[0..l-1]` 严格递增
2. `nums[r+1..n-1]` 严格递增
3. 若 l > 0 且 r < n-1，则 `nums[l-1] < nums[r+1]`

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def incremovableSubarrayCount(self, nums: List[int]) -> int:
        n = len(nums)

        def is_valid(l: int, r: int) -> bool:
            # 删除 nums[l..r] 后检查剩余是否严格递增
            remaining = nums[:l] + nums[r + 1:]
            for i in range(len(remaining) - 1):
                if remaining[i] >= remaining[i + 1]:
                    return False
            return True

        ans = 0
        for l in range(n):
            for r in range(l, n):
                if is_valid(l, r):
                    ans += 1
        return ans
```

### 方法二：预处理前后缀递增

```python
from typing import List

class Solution:
    def incremovableSubarrayCount(self, nums: List[int]) -> int:
        n = len(nums)

        # pre[i]: nums[0..i] 是否严格递增
        pre = [True] * n
        for i in range(1, n):
            pre[i] = pre[i - 1] and nums[i - 1] < nums[i]

        # suf[i]: nums[i..n-1] 是否严格递增
        suf = [True] * n
        for i in range(n - 2, -1, -1):
            suf[i] = suf[i + 1] and nums[i] < nums[i + 1]

        ans = 0
        for l in range(n):
            if l > 0 and not pre[l - 1]:
                break  # 左侧已不是递增，无法继续
            for r in range(l, n):
                if r < n - 1 and not suf[r + 1]:
                    continue  # 右侧不是递增
                if l > 0 and r < n - 1 and nums[l - 1] >= nums[r + 1]:
                    continue  # 连接处不满足
                ans += 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一，方法二均如此）
- 空间复杂度：O(n)

## 关键点总结

1. 三个条件：左段递增、右段递增、连接处递增
2. 枚举所有 (l, r) 对，n <= 50 时 O(n^2) 完全够用
3. 空段（全部删除）也算：l=0, r=n-1

## 易错点

1. 删除整个数组后剩余为空，空数组视为严格递增（有效）
2. l > 0 时才有左段，r < n-1 时才有右段
3. 连接条件 `nums[l-1] < nums[r+1]` 仅在两段都存在时才需要检查
