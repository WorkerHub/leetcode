## 题目描述

给定一个字符串 `s`，你可以通过在字符串前面添加字符将其转换为回文串。找到并返回可以用这种方式转换的最短回文串。

**示例 1：**

```
输入：s = "aacecaaa"
输出："aaacecaaa"
```

**示例 2：**

```
输入：s = "abcd"
输出："dcbabcd"
```

**提示：**

- `0 <= s.length <= 5 * 10^4`
- `s` 仅由小写英文字母组成

## 解题思路

这道题的核心是找到从字符串开头开始的最长回文子串，然后将剩余部分反转后添加到前面。

**核心思想：**

1. **找最长回文前缀**：找到从 `s[0]` 开始的最长回文子串
2. **构造结果**：将不在回文前缀中的后缀反转，添加到 `s` 前面

**示例分析：**

```
s = "aacecaaa"
最长回文前缀 = "aacecaa"（长度 7）
剩余后缀 = "a"
结果 = "a" 的反转 + s = "a" + "aacecaaa" = "aaacecaaa"
```

**关键问题：** 如何高效找到最长回文前缀？

**多种方法：**
1. **暴力法**：逐个检查每个前缀是否为回文（O(N²)）
2. **KMP 算法**：利用 `s + "#" + reverse(s)` 的最长公共前后缀
3. **双指针 + 哈希**：使用滚动哈希快速判断回文
4. **Manacher 算法**：专门用于回文检测

## Python 代码实现

### 方法一：KMP 算法（推荐）⭐

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        if not s:
            return s
        
        # 构造新字符串：s + "#" + reverse(s)
        # "#" 防止原串和反串匹配
        new_s = s + "#" + s[::-1]
        
        # 计算 KMP 的 next 数组（最长公共前后缀）
        n = len(new_s)
        next_arr = [0] * n
        j = 0
        
        for i in range(1, n):
            # 回退到可以匹配的位置
            while j > 0 and new_s[i] != new_s[j]:
                j = next_arr[j - 1]
            
            # 当前字符匹配
            if new_s[i] == new_s[j]:
                j += 1
            
            next_arr[i] = j
        
        # next_arr[-1] 就是最长回文前缀的长度
        palindrome_len = next_arr[-1]
        
        # 将不在回文前缀中的后缀反转后加到前面
        suffix = s[palindrome_len:]
        return suffix[::-1] + s
```

### 方法二：双指针 + 递归（易理解）

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        if not s:
            return s
        
        # 找到最长回文前缀
        end = len(s) - 1
        for i in range(len(s)):
            if self.is_palindrome(s, 0, end):
                break
            end -= 1
        
        # 将后缀反转后加到前面
        suffix = s[end + 1:]
        return suffix[::-1] + s
    
    def is_palindrome(self, s: str, left: int, right: int) -> bool:
        """判断 s[left:right+1] 是否为回文"""
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True
```

### 方法三：滚动哈希（高效）

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        if not s:
            return s
        
        n = len(s)
        base = 31
        mod = 10**9 + 7
        
        # 正向哈希和反向哈希
        forward_hash = 0
        reverse_hash = 0
        power = 1
        palindrome_end = 0
        
        for i in range(n):
            # 正向哈希：从左到右
            forward_hash = (forward_hash * base + ord(s[i])) % mod
            # 反向哈希：从右到左
            reverse_hash = (reverse_hash + ord(s[i]) * power) % mod
            power = (power * base) % mod
            
            # 如果正向和反向哈希相等，说明 s[0:i+1] 是回文
            if forward_hash == reverse_hash:
                palindrome_end = i
        
        # 构造结果
        suffix = s[palindrome_end + 1:]
        return suffix[::-1] + s
```

### 方法四：暴力法（供对比学习）

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        """从最长前缀开始尝试"""
        n = len(s)
        
        # 从最长可能的回文前缀开始检查
        for i in range(n, -1, -1):
            if s[:i] == s[:i][::-1]:  # 检查是否为回文
                suffix = s[i:]
                return suffix[::-1] + s
        
        return s
```

## 复杂度分析

**方法一（KMP）：**

- **时间复杂度：** O(N)，构造字符串 O(N) + KMP O(N)
- **空间复杂度：** O(N)，需要存储新字符串和 next 数组

**方法二（双指针）：**

- **时间复杂度：** O(N²)，最坏情况检查 N 次，每次 O(N)
- **空间复杂度：** O(1)

**方法三（滚动哈希）：**

- **时间复杂度：** O(N)
- **空间复杂度：** O(1)
- **注意：** 存在哈希冲突的极小概率

**方法四（暴力）：**

- **时间复杂度：** O(N²)
- **空间复杂度：** O(N)，字符串切片和反转

## 关键点总结

1. **问题转化**：最短回文串 → 找最长回文前缀
2. **KMP 应用**：`s + "#" + reverse(s)` 的最长公共前后缀 = 最长回文前缀
3. **滚动哈希**：高效判断回文，正向和反向哈希值相等
4. **字符串操作**：熟练使用切片、反转、拼接
5. **边界情况**：空字符串、全回文、无回文前缀

## 易错点

1. **KMP 构造字符串时忘记分隔符**：
   ```python
   # 错误：没有 "#" 分隔
   new_s = s + s[::-1]  # 可能导致错误匹配
   # 正确：使用分隔符
   new_s = s + "#" + s[::-1]
   ```

2. **回文前缀长度计算错误**：
   ```python
   # 错误：使用 next_arr[-1] - 1
   palindrome_len = next_arr[-1] - 1
   # 正确：直接使用 next_arr[-1]
   palindrome_len = next_arr[-1]
   ```

3. **滚动哈希溢出**：
   ```python
   # 错误：不取模
   forward_hash = forward_hash * base + ord(s[i])
   # 正确：每步都取模
   forward_hash = (forward_hash * base + ord(s[i])) % mod
   ```

4. **边界情况遗漏**：
   ```python
   # 空字符串
   s = ""  # 应返回 ""
   # 全回文
   s = "aba"  # 应返回 "aba"
   # 无回文前缀
   s = "abcd"  # 应返回 "dcbabcd"
   ```

5. **字符串拼接顺序错误**：
   ```python
   # 错误：反转加在后面
   return s + suffix[::-1]
   # 正确：反转加在前面
   return suffix[::-1] + s
   ```
