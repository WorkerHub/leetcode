## 题目描述

给你一个二维数组 `points` 和字符串 `s`，其中 `points[i]` 表示第 i 个点的坐标，`s[i]` 表示第 i 个点的标签。

以原点为中心的正方形的 **半边长** 定义为从原点到正方形边的距离（切比雪夫距离）。

如果一个正方形内包含的点中，每个标签最多出现一次，则称该正方形是 **有效** 的。

返回有效正方形中包含的 **最多** 点数。

**提示：**
- `1 <= points.length <= 10^5`
- `0 <= |xi|, |yi| <= 10^9`

## 解题思路

每个点到原点的切比雪夫距离为 `max(|xi|, |yi|)`。正方形半边长 r 包含所有切比雪夫距离 <= r 的点。

二分答案 r：对于给定的 r，检查切比雪夫距离 <= r 的点中是否有重复标签。

具体：将点按切比雪夫距离排序，从小到大枚举，维护已选标签集合，若出现重复则当前半径无效。

## Python 代码实现

### 方法一：排序 + 标签检查（推荐）

```python
from typing import List

class Solution:
    def maxPointsInsideSquare(self, points: List[List[int]], s: str) -> int:
        n = len(points)
        # 计算每个点的切比雪夫距离
        dist = [max(abs(x), abs(y)) for x, y in points]

        # 按距离排序
        order = sorted(range(n), key=lambda i: dist[i])

        seen = set()
        ans = 0
        i = 0
        while i < n:
            # 找出所有距离相同的点（同一层）
            j = i
            cur_dist = dist[order[i]]
            while j < n and dist[order[j]] == cur_dist:
                j += 1
            # 检查这一层的标签是否有重复或与已选冲突
            layer = [s[order[k]] for k in range(i, j)]
            if len(set(layer)) < len(layer) or any(c in seen for c in layer):
                break  # 有重复，停止
            seen.update(layer)
            ans += j - i
            i = j

        return ans
```

### 方法二：二分

```python
from typing import List

class Solution:
    def maxPointsInsideSquare(self, points: List[List[int]], s: str) -> int:
        n = len(points)
        dist = [max(abs(x), abs(y)) for x, y in points]

        def valid(r: int) -> bool:
            seen = set()
            for i in range(n):
                if dist[i] <= r:
                    if s[i] in seen:
                        return False
                    seen.add(s[i])
            return True

        # 找最大有效 r
        vals = sorted(set(dist))
        lo, hi = 0, len(vals) - 1
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if valid(vals[mid]):
                lo = mid
            else:
                hi = mid - 1

        if not vals or not valid(vals[0]):
            return 0
        r = vals[lo]
        return sum(1 for d in dist if d <= r)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 切比雪夫距离 = max(|x|, |y|)
2. 正方形包含所有切比雪夫距离 <= r 的点
3. 有效正方形要求每个标签最多出现一次
4. 按距离分层扫描，同层若有重复标签就停止

## 易错点

1. 同距离的点必须同时包含或排除，不能部分
2. 切比雪夫距离不是欧氏距离
