## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，返回数组中唯一的 k-diff 数对的数量。

一个 **k-diff 数对** 是一个整数对 `(nums[i], nums[j])`，满足以下条件：

- `0 <= i, j < nums.length`
- `i != j`
- `|nums[i] - nums[j]| == k`

注意，`|val|` 表示 `val` 的绝对值。

**示例 1：**
```
输入: nums = [3,1,4,1,5], k = 2
输出: 2
解释: 数组中有两个 2-diff 数对：(1, 3) 和 (3, 5)
虽然输入中有两个 1，但我们只应该返回唯一数对的数量
```

**示例 2：**
```
输入: nums = [1,2,3,4,5], k = 1
输出: 4
解释: 数组中有四个 1-diff 数对：(1, 2), (2, 3), (3, 4) 和 (4, 5)
```

**示例 3：**
```
输入: nums = [1,3,1,5,4], k = 0
输出: 1
解释: 数组中有一个 0-diff 数对：(1, 1)
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^7 <= nums[i] <= 10^7`
- `0 <= k <= 10^7`

## 解题思路

这道题要求找出唯一的 k-diff 数对。关键是理解"唯一"的含义和 k 的特殊情况。

**关键观察：**

1. **唯一性**：数对 `(a, b)` 和 `(b, a)` 被视为同一个数对
2. **k = 0 的特殊情况**：需要找重复出现的数字
3. **k > 0 的一般情况**：对于每个数 `x`，找 `x + k` 或 `x - k` 是否存在

**解题策略：**

### 策略一：哈希表法（最优）

- 使用一个集合 `vis` 记录已经遍历过的数字
- 使用另一个集合 `ans` 记录数对中较小的值
- 对于每个数 `x`：
  - 如果 `x - k` 在 `vis` 中，将 `x - k` 加入 `ans`
  - 如果 `x + k` 在 `vis` 中，将 `x` 加入 `ans`
- 返回 `ans` 的大小

**时间复杂度**：O(n)  
**空间复杂度**：O(n)

### 策略二：排序 + 双指针

- 先对数组排序
- 使用双指针 `i` 和 `j` 遍历
- 根据 `nums[j] - nums[i]` 与 `k` 的大小关系移动指针
- 使用集合去重

**时间复杂度**：O(n log n)  
**空间复杂度**：O(1) 或 O(n)（取决于去重方式）

## Python 代码实现

### 方法一：哈希表法（推荐）

```python
from typing import List

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        """
        使用哈希表记录已遍历的数字和唯一数对
        时间复杂度 O(n)，空间复杂度 O(n)
        """
        ans = set()  # 存储唯一数对（存储较小值）
        vis = set()  # 存储已遍历的数字
        
        for x in nums:
            # 检查 x - k 是否已经遍历过
            if x - k in vis:
                ans.add(x - k)  # 数对是 (x-k, x)，存储较小值 x-k
            
            # 检查 x + k 是否已经遍历过
            if x + k in vis:
                ans.add(x)  # 数对是 (x, x+k)，存储较小值 x
            
            # 将当前数字加入已遍历集合
            vis.add(x)
        
        return len(ans)
```

### 方法二：使用 Counter 处理 k=0 的情况

```python
from typing import List
from collections import Counter

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        """
        使用 Counter 统计频率
        特别适合 k=0 的情况
        """
        if k < 0:
            return 0
        
        counter = Counter(nums)
        
        if k == 0:
            # k=0 时，找出现次数 >= 2 的数字
            return sum(1 for count in counter.values() if count >= 2)
        else:
            # k>0 时，对每个唯一数字，检查 num+k 是否存在
            return sum(1 for num in counter if num + k in counter)
```

### 方法三：排序 + 双指针

```python
from typing import List

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        """
        排序后使用双指针
        时间复杂度 O(n log n)，空间复杂度 O(1)
        """
        nums.sort()
        n = len(nums)
        ans = set()  # 使用集合去重
        
        i, j = 0, 1
        
        while i < n and j < n:
            if i == j:
                # i 和 j 不能指向同一个元素
                j += 1
                continue
            
            diff = nums[j] - nums[i]
            
            if diff == k:
                # 找到一个数对
                ans.add((nums[i], nums[j]))
                i += 1
                j += 1
            elif diff < k:
                # 差值太小，j 右移增大差值
                j += 1
            else:
                # 差值太大，i 右移减小差值
                i += 1
        
        return len(ans)
```

### 方法四：详细注释版（适合初学者）

```python
from typing import List

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        """
        最详细的实现，包含每个步骤的解释
        """
        # 用于存储唯一的 k-diff 数对
        # 我们只存储数对中较小的值，避免重复
        unique_pairs = set()
        
        # 用于存储已经遍历过的数字
        visited = set()
        
        # 遍历数组中的每个数字
        for current_num in nums:
            # 情况 1: 检查 current_num - k 是否已经遍历过
            # 如果是，说明找到一个数对 (current_num - k, current_num)
            # 差值 = current_num - (current_num - k) = k
            if current_num - k in visited:
                # 将较小的值加入结果集
                unique_pairs.add(current_num - k)
            
            # 情况 2: 检查 current_num + k 是否已经遍历过
            # 如果是，说明找到一个数对 (current_num, current_num + k)
            # 差值 = (current_num + k) - current_num = k
            if current_num + k in visited:
                # 将较小的值加入结果集
                unique_pairs.add(current_num)
            
            # 将当前数字标记为已遍历
            visited.add(current_num)
        
        # 返回唯一数对的数量
        return len(unique_pairs)
```

### 方法五：处理边界情况

```python
from typing import List
from collections import Counter

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        """
        完整处理所有边界情况
        """
        # 边界情况：k < 0 无效
        if k < 0:
            return 0
        
        # 统计每个数字的出现次数
        count = Counter(nums)
        result = 0
        
        # 遍历所有唯一的数字
        for num in count:
            if k == 0:
                # k=0 时，需要找重复的数字
                # 只有出现次数 >= 2 才能形成数对 (num, num)
                if count[num] >= 2:
                    result += 1
            else:
                # k>0 时，检查 num+k 是否存在
                # 只需检查一个方向，避免重复计数
                if num + k in count:
                    result += 1
        
        return result
```

## 复杂度分析

### 方法一：哈希表法
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(n)，两个集合最多存储 n 个元素

### 方法二：Counter 法
- **时间复杂度**：O(n)，Counter 统计 + 遍历唯一值
- **空间复杂度**：O(n)，Counter 存储

### 方法三：排序 + 双指针
- **时间复杂度**：O(n log n)，排序主导
- **空间复杂度**：O(n)，集合去重

**推荐使用方法一或方法二**，时间复杂度最优。

## 关键点总结

1. **唯一性处理**：使用集合 `set` 自动去重
2. **双向检查**：对于每个数 `x`，检查 `x-k` 和 `x+k`
3. **只存储较小值**：避免 `(a, b)` 和 `(b, a)` 重复
4. **k=0 特殊处理**：找重复元素
5. **边界条件**：k < 0 无效，直接返回 0

## 易错点

1. **重复计数**
   ```python
   # 错误：会重复计数 (a, b) 和 (b, a)
   for i in range(n):
       for j in range(n):
           if abs(nums[i] - nums[j]) == k:
               count += 1
   
   # 正确：只存储较小的值
   if x - k in vis:
       ans.add(x - k)  # 存储较小的值
   ```

2. **忘记处理 k=0 的情况**
   ```python
   # k=0 时需要找重复元素
   if k == 0:
       return sum(1 for count in counter.values() if count >= 2)
   ```

3. **双指针 i 和 j 相等**
   ```python
   # 错误：没有检查 i == j
   diff = nums[j] - nums[i]
   
   # 正确：确保 i != j
   if i == j:
       j += 1
       continue
   ```

4. **负数 k 的处理**
   ```python
   # 应该提前返回
   if k < 0:
       return 0
   ```
