## 题目描述

给你一个下标从 **0** 开始的整数数组 `mapping`，它表示一个十进制数的映射规则，`mapping[i] = j` 表示这个规则下，数字 `i` 映射为 `j`。

另外给你一个整数数组 `nums`，请你将 `nums` 中每个数按照 `mapping` 规则映射后得到的值从小到大排序，相等的映射值保持**原始下标顺序**（稳定排序）。

返回排序后的 `nums`。

**示例 1：**
```
输入：mapping = [8,9,4,0,2,1,3,5,7,6], nums = [991,338,38]
输出：[338,38,991]
解释：
- 991 映射为 668（9→6, 9→6, 1→9）
- 338 映射为 007 = 7（3→0, 3→0, 8→7）
- 38 映射为 07 = 7（3→0, 8→7）
007 < 07 < 668，所以 338 < 38 < 991。
```

**提示：**
- `mapping.length == 10`
- `0 <= mapping[i] <= 9`
- `1 <= nums.length <= 3 * 10^4`
- `0 <= nums[i] < 10^9`

## 解题思路

**逐位映射 + 稳定排序**

对每个数字，逐位提取其十进制数字，用 `mapping` 进行替换，重新组合成映射后的数值。然后以此为排序键进行稳定排序。

Python 的 `sorted` 是稳定排序，可以用 `(mapped_val, original_index)` 作为排序键保证稳定性。

## 代码实现

### 方法一：逐位映射 + sorted（推荐）

```python
from typing import List

class Solution:
    def sortJumbled(self, mapping: List[int], nums: List[int]) -> List[int]:
        def get_mapped(x: int) -> int:
            # 将 x 每一位按 mapping 规则替换
            if x == 0:
                return mapping[0]
            result = 0
            factor = 1
            while x > 0:
                digit = x % 10
                result += mapping[digit] * factor
                factor *= 10
                x //= 10
            return result

        # 稳定排序：key 为映射值，Python sorted 自动保持相等元素的原始顺序
        return sorted(nums, key=get_mapped)
```

### 方法二：字符串转换法

```python
from typing import List

class Solution:
    def sortJumbled(self, mapping: List[int], nums: List[int]) -> List[int]:
        def get_mapped(x: int) -> int:
            # 用字符串转换，逐字符映射
            s = str(x)
            mapped_str = ''.join(str(mapping[int(c)]) for c in s)
            return int(mapped_str)

        return sorted(nums, key=get_mapped)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 逐位映射 | O(n * d * log n)，d 为最大位数 | O(n) |
| 字符串转换 | O(n * d * log n) | O(n) |

## 关键点总结

1. 对每个数逐位替换，重新组合得到映射值。
2. 用映射值作为排序键，Python `sorted` 天然稳定。
3. 特殊处理 `x = 0`：直接返回 `mapping[0]`。

## 易错点

- 数字 `0` 的特殊处理：不能进入 `while x > 0` 的循环，需单独判断。
- 字符串方法中，`int('07')` = `7`，不会有前导零问题（整数本身无前导零）。
- 排序稳定性：Python `sorted` 默认稳定，不需要额外处理。
