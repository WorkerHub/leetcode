## 题目描述

给你一个类：

```python
class Foo:
    def first(self): print("first")
    def second(self): print("second")
    def third(self): print("third")
```

三个不同的线程 A、B、C 将会共用一个 `Foo` 实例。

- 线程 A 将会调用 `first()` 方法
- 线程 B 将会调用 `second()` 方法
- 线程 C 将会调用 `third()` 方法

请设计修改程序，以确保 `second()` 方法在 `first()` 方法之后被执行，`third()` 方法在 `second()` 方法之后被执行。

**注意：**
- 尽管输入中的数字似乎隐含了顺序，但是我们并不保证线程在操作系统中的调度顺序
- 你看到的输入格式主要是为了确保测试的全面性

**示例 1：**
```
输入：nums = [1,2,3]
输出："firstsecondthird"
解释：
有三个线程会被异步启动。输入 [1,2,3] 表示线程 A 将会调用 first() 方法，线程 B 将会调用 second() 方法，线程 C 将会调用 third() 方法。正确的输出是 "firstsecondthird"。
```

**示例 2：**
```
输入：nums = [1,3,2]
输出："firstsecondthird"
解释：
输入 [1,3,2] 表示线程 A 将会调用 first() 方法，线程 C 将会调用 third() 方法，线程 B 将会调用 second() 方法。正确的输出是 "firstsecondthird"。
```

## 解题思路

这道题的核心是**线程同步**，需要确保三个方法按照固定顺序执行，无论线程的调度顺序如何。

**常用的同步机制：**

1. **锁（Lock）+ 条件变量**：使用锁保护共享状态
2. **事件（Event）**：一个线程等待另一个线程设置事件
3. **信号量（Semaphore）**：控制资源访问的计数器
4. **屏障（Barrier）**：多个线程在某个点同步

**解题思路：**
- 使用标志变量记录执行状态
- `first()` 执行后通知 `second()`
- `second()` 执行后通知 `third()`

## Python 代码实现

### 方法一：使用 Lock 和 Event（推荐）

```python
from threading import Lock, Event

class Foo:
    def __init__(self):
        # 创建两个事件，分别表示 first 和 second 是否完成
        self.first_done = Event()
        self.second_done = Event()

    def first(self, printFirst: 'Callable[[], None]') -> None:
        # 打印 "first"
        printFirst()
        # 设置 first_done 事件，通知 second 可以执行
        self.first_done.set()

    def second(self, printSecond: 'Callable[[], None]') -> None:
        # 等待 first_done 事件被设置
        self.first_done.wait()
        # 打印 "second"
        printSecond()
        # 设置 second_done 事件，通知 third 可以执行
        self.second_done.set()

    def third(self, printThird: 'Callable[[], None]') -> None:
        # 等待 second_done 事件被设置
        self.second_done.wait()
        # 打印 "third"
        printThird()
```

### 方法二：使用信号量（Semaphore）

```python
from threading import Semaphore

class Foo:
    def __init__(self):
        # 初始化两个信号量，初始值为 0（不可用）
        self.sem_second = Semaphore(0)
        self.sem_third = Semaphore(0)

    def first(self, printFirst: 'Callable[[], None]') -> None:
        # 打印 "first"
        printFirst()
        # 释放信号量，允许 second 执行
        self.sem_second.release()

    def second(self, printSecond: 'Callable[[], None]') -> None:
        # 获取信号量，如果 first 还没执行完会阻塞
        self.sem_second.acquire()
        # 打印 "second"
        printSecond()
        # 释放信号量，允许 third 执行
        self.sem_third.release()

    def third(self, printThird: 'Callable[[], None]') -> None:
        # 获取信号量，如果 second 还没执行完会阻塞
        self.sem_third.acquire()
        # 打印 "third"
        printThird()
```

### 方法三：使用 Lock 和条件变量

```python
from threading import Lock, Condition

class Foo:
    def __init__(self):
        self.lock = Lock()
        self.condition = Condition(self.lock)
        self.step = 0  # 当前执行到第几步

    def first(self, printFirst: 'Callable[[], None]') -> None:
        with self.condition:
            # 打印 "first"
            printFirst()
            # 更新状态
            self.step = 1
            # 通知所有等待的线程
            self.condition.notify_all()

    def second(self, printSecond: 'Callable[[], None]') -> None:
        with self.condition:
            # 等待 step 变为 1
            while self.step < 1:
                self.condition.wait()
            # 打印 "second"
            printSecond()
            # 更新状态
            self.step = 2
            # 通知所有等待的线程
            self.condition.notify_all()

    def third(self, printThird: 'Callable[[], None]') -> None:
        with self.condition:
            # 等待 step 变为 2
            while self.step < 2:
                self.condition.wait()
            # 打印 "third"
            printThird()
```

### 方法四：使用 Lock（简单粗暴）

```python
from threading import Lock

class Foo:
    def __init__(self):
        # 创建两个锁，并提前锁定
        self.lock_second = Lock()
        self.lock_third = Lock()
        self.lock_second.acquire()
        self.lock_third.acquire()

    def first(self, printFirst: 'Callable[[], None]') -> None:
        # 打印 "first"
        printFirst()
        # 释放 lock_second，允许 second 执行
        self.lock_second.release()

    def second(self, printSecond: 'Callable[[], None]') -> None:
        # 尝试获取 lock_second，会阻塞直到 first 释放它
        self.lock_second.acquire()
        # 打印 "second"
        printSecond()
        # 释放 lock_third，允许 third 执行
        self.lock_third.release()

    def third(self, printThird: 'Callable[[], None]') -> None:
        # 尝试获取 lock_third，会阻塞直到 second 释放它
        self.lock_third.acquire()
        # 打印 "third"
        printThird()
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(1)，每个方法只执行一次，常数时间
- 空间复杂度：O(1)，只使用常数个同步原语

## 关键点总结

1. **线程同步的必要性**：多线程环境下，不能假设执行顺序
2. **Event 的工作原理**：
   - `wait()`：阻塞当前线程，直到事件被设置
   - `set()`：设置事件，唤醒所有等待的线程
3. **Semaphore 的工作原理**：
   - `acquire()`：计数器减 1，如果为 0 则阻塞
   - `release()`：计数器加 1，唤醒等待的线程
4. **Lock 的预锁定技巧**：先 `acquire()` 锁定，后续线程调用时会阻塞
5. **Condition 变量**：结合锁和条件判断，更灵活但也更复杂

## 易错点

1. **死锁风险**：不正确的锁顺序可能导致死锁
2. **竞态条件**：没有正确同步可能导致输出顺序错误
3. **忘记释放资源**：Lock 或 Semaphore 没有释放会导致永久阻塞
4. **条件判断错误**：使用 Condition 时，必须用 while 而不是 if 判断条件
5. **Event 的重复使用**：Event 一旦 set 就一直保持，不会自动重置

## 学习建议

1. **理解同步原语的区别**：
   - **Lock（互斥锁）**：保证同一时间只有一个线程访问资源
   - **Event（事件）**：一对多的通知机制
   - **Semaphore（信号量）**：控制资源访问的计数器
   - **Condition（条件变量）**：配合锁使用，支持复杂条件判断

2. **掌握使用场景**：
   - 简单的顺序控制：Event 或 Semaphore
   - 资源互斥访问：Lock
   - 复杂的条件同步：Condition

3. **避免常见错误**：
   - 死锁：确保锁的获取和释放顺序正确
   - 饥饿：确保所有线程都有机会执行
   - 竞态条件：正确使用同步机制

4. **调试技巧**：
   - 打印线程 ID 和执行顺序
   - 使用日志记录关键同步点
   - 多次运行测试，观察不同调度下的行为

5. **扩展练习**：
   - 实现 N 个线程的顺序执行
   - 处理异常情况（某个线程抛出异常）
   - 添加超时机制（防止永久等待）

6. **实际应用**：
   - 生产者-消费者模式
   - 读者-写者问题
   - 哲学家就餐问题
   - 线程池的任务调度
