## 题目描述

给你一个整数数组 `heights`，其中 `heights[i]` 是第 `i` 栋楼的高度。

Alice 在楼 `a`，Bob 在楼 `b`。他们可以从当前楼向右移动到更高的楼（`heights[j] > heights[i]`，j > i）。

对于每个查询 `(a, b)`，返回 Alice 和 Bob 能共同到达的最左边的楼的下标，若不存在则返回 -1。

**示例：**
```
输入：heights = [6,4,8,5,2,7], queries = [[0,1],[0,3],[2,4],[3,4],[2,2]]
输出：[2,5,-1,5,2]
```

**提示：**
- `1 <= n <= 5 * 10^4`
- `1 <= heights[i] <= 10^9`
- `1 <= queries.length <= 5 * 10^4`
- `0 <= queries[i][0], queries[i][1] <= n-1`

## 解题思路

对于查询 (a, b)，不失一般性设 a <= b：
- 若 a == b：答案是 a
- 若 heights[a] < heights[b]：Alice 可直接去 b（b 更高），答案是 b
- 否则（heights[a] >= heights[b]）：需要找 b 右边第一个比 heights[a] 更高的楼

对第三种情况，需要高效查询"从位置 b 开始，第一个高于 heights[a] 的位置"。

**离线处理 + 单调栈 + 堆**：

将查询按右端点 b 排序，用单调栈维护右侧更高的楼，用堆处理悬挂查询。

## Python 代码实现

### 方法一：离线处理 + 单调栈 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def leftmostBuildingQueries(self, heights: List[int], queries: List[List[int]]) -> List[int]:
        n = len(heights)
        ans = [-1] * len(queries)

        # 将 a, b 标准化：a <= b
        processed = []
        for idx, (a, b) in enumerate(queries):
            if a > b:
                a, b = b, a
            if a == b or heights[a] < heights[b]:
                # 直接可以解答
                ans[idx] = b
            else:
                # 需要找 b 右边第一个 > heights[a] 的位置
                processed.append((b, heights[a], idx))

        # 按 b 排序（右端点）
        processed.sort()

        # 用最小堆 (min_height_needed, query_idx)
        heap = []  # 需要找到高度 > min_height_needed 的最左位置
        ptr = 0

        # 维护单调递减栈的同时，从左到右扫描
        # 用单调栈（从右到左）找每个位置右边第一个更高的
        # 但此处用在线扫描：从左到右，当遍历到位置 i 时，
        # 检查堆中所有 heights[i] > heap[0][0] 的查询

        j = 0
        for i in range(n):
            # 将所有 b == i 的查询加入堆
            while j < len(processed) and processed[j][0] == i:
                b_idx, min_h, qidx = processed[j]
                heapq.heappush(heap, (min_h, qidx))
                j += 1

            # 当前楼 i 的高度为 heights[i]，检查能否满足堆中的查询
            while heap and heap[0][0] < heights[i]:
                min_h, qidx = heapq.heappop(heap)
                ans[qidx] = i

        return ans
```

### 方法二：暴力（适合小数据验证）

```python
from typing import List

class Solution:
    def leftmostBuildingQueries(self, heights: List[int], queries: List[List[int]]) -> List[int]:
        n = len(heights)
        ans = []
        for a, b in queries:
            if a > b:
                a, b = b, a
            if a == b or heights[a] < heights[b]:
                ans.append(b)
                continue
            # 找 b 右边第一个 > max(heights[a], heights[b]) = heights[a] 的
            need = heights[a]
            found = -1
            for k in range(b + 1, n):
                if heights[k] > need:
                    found = k
                    break
            ans.append(found)
        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，离线排序和堆操作
- 空间复杂度：O(n + q)

## 关键点总结

1. 标准化查询：始终让 a <= b
2. 简单情况（a==b 或 heights[a] < heights[b]）直接回答
3. 困难情况：找 b 右边第一个高度 > heights[a] 的楼
4. 离线处理：按 b 排序，从左到右扫描楼，用最小堆管理悬挂查询

## 易错点

1. 需要高度**严格大于** heights[a]（不是 >= ）
2. 离线处理需要按右端点 b 添加查询，当扫描到 i > b 时才处理
3. 堆按 min_height_needed 排序，每次扫描到更高的楼时弹出满足条件的查询
