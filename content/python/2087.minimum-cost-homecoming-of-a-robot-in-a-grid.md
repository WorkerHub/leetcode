## 题目描述

给你一个 `m x n` 的网格，机器人从 `startPos` 出发，要到达 `homePos`，途中每次移动到相邻单元格的代价为 `rowCosts[row]` 或 `colCosts[col]`（到达目标行/列时支付）。

返回机器人回家的**最小代价**。

**提示：**
- 移动到某一行的代价是 `rowCosts[row]`，移动到某一列的代价是 `colCosts[col]`
- 机器人不需要按最短路径走，但贪心地走最短路径是最优的

**示例：**
```
输入：startPos = [1,0], homePos = [2,3], rowCosts = [5,4,3], colCosts = [8,2,6,7]
输出：18
解释：(1,0)→(1,1)→(1,2)→(1,3)→(2,3)
代价 = 2+6+7+3 = 18
```

## 解题思路

**贪心：** 最优路径一定是**最短路径**（曼哈顿距离路径），绕路只会增加不必要的代价。

- 行方向：从 `startPos[0]` 到 `homePos[0]`，按方向逐行移动，累加路过各行的代价（不含起始行）
- 列方向：从 `startPos[1]` 到 `homePos[1]`，按方向逐列移动，累加路过各列的代价（不含起始列）

**证明：** 任何绕路都会经过某些行/列两次，而 `rowCosts` 和 `colCosts` 均为非负数，绕路不会更优。

## 代码实现

### 方法一：贪心直接计算（推荐）

```python
from typing import List

class Solution:
    def minCost(self, startPos: List[int], homePos: List[int],
                rowCosts: List[int], colCosts: List[int]) -> int:
        r1, c1 = startPos
        r2, c2 = homePos
        cost = 0

        # 行方向移动：从 r1 到 r2（不含 r1，包含 r2）
        if r1 < r2:
            cost += sum(rowCosts[r1 + 1: r2 + 1])
        else:
            cost += sum(rowCosts[r2: r1])

        # 列方向移动：从 c1 到 c2（不含 c1，包含 c2）
        if c1 < c2:
            cost += sum(colCosts[c1 + 1: c2 + 1])
        else:
            cost += sum(colCosts[c2: c1])

        return cost
```

### 方法二：逐步累加

```python
from typing import List

class Solution:
    def minCost(self, startPos: List[int], homePos: List[int],
                rowCosts: List[int], colCosts: List[int]) -> int:
        r1, c1 = startPos
        r2, c2 = homePos
        cost = 0

        # 按步移动行
        r = r1
        while r != r2:
            r += 1 if r < r2 else -1
            cost += rowCosts[r]

        # 按步移动列
        c = c1
        while c != c2:
            c += 1 if c < c2 else -1
            cost += colCosts[c]

        return cost
```

## 复杂度分析

- 时间复杂度：O(|r2-r1| + |c2-c1|)，正比于曼哈顿距离
- 空间复杂度：O(1)

## 关键点总结

1. 最优路径就是曼哈顿最短路径，不需要考虑绕路
2. 代价只计算到达的行/列，不计算出发行/列
3. 行和列的移动代价独立累加

## 易错点

- 代价计算：到达行 `r` 时支付 `rowCosts[r]`，**不包括起始行**
- 切片方向：向下移动用 `rowCosts[r1+1:r2+1]`，向上用 `rowCosts[r2:r1]`
