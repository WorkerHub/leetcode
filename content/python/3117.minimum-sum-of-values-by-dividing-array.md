## 题目描述

给你两个数组 `nums` 和 `andValues`，长度分别为 `n` 和 `m`。

将 `nums` 划分为 `m` 个 **非空** 连续子数组，第 `i` 个子数组的按位与（AND）等于 `andValues[i]`。

每个子数组的 **代价** 是子数组中最后一个元素的值，最小化所有子数组代价之和。若无法完成划分，返回 `-1`。

**提示：**
- `1 <= n <= 10^4`
- `1 <= m <= min(n, 10)`
- `1 <= andValues[i] < 2^17`
- `1 <= nums[i] < 2^17`

## 解题思路

动态规划：`dp[i][j]` 表示将 `nums[0..i-1]` 划分为 `j` 段，且满足前 j 段约束的最小代价。

关键优化：对固定的右端点 `i` 和段数 `j`，前缀 AND 随左端点向右移动单调不增（AND 值只能越来越小）。可以二分找出满足 `AND(nums[l..i]) == andValues[j-1]` 的左端点范围 `[lo, hi]`。

## Python 代码实现

### 方法一：DP + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def minimumValueSum(self, nums: List[int], andValues: List[int]) -> int:
        n, m = len(nums), len(andValues)
        INF = float('inf')

        # dp[j][i] 表示用 j 段覆盖 nums[0..i-1] 的最小代价
        # 转移：dp[j][i] = min(dp[j-1][k-1] + nums[i-1]) for valid k
        # 其中 AND(nums[k-1..i-1]) == andValues[j-1]

        # 使用滚动数组优化
        prev = [INF] * (n + 1)
        prev[0] = 0  # 0 段覆盖 0 个元素，代价为 0

        for j in range(1, m + 1):
            target = andValues[j - 1]
            curr = [INF] * (n + 1)

            # 对每个右端点 i（1-indexed），找满足条件的左端点范围
            for i in range(j, n - m + j + 1):
                # 计算 AND(nums[l-1..i-1]) == target 的 l 范围
                # AND 随 l 增大单调不增，随 l 减小单调不增
                # 找最大的 l_min 使 AND = target，最小的 l_max
                # 二分：AND(nums[l..i]) >= target 的最左 l
                # 使用前缀 AND 计算

                # 直接线性扫描（O(n) per j）
                and_val = nums[i - 1]
                for l in range(i - 1, -1, -1):
                    if l < i - 1:
                        and_val &= nums[l]
                    if and_val < target:
                        break
                    if and_val == target and prev[l] < INF:
                        curr[i] = min(curr[i], prev[l] + nums[i - 1])

            prev = curr

        return prev[n] if prev[n] < INF else -1
```

### 方法二：带备忘录的递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumValueSum(self, nums: List[int], andValues: List[int]) -> int:
        n, m = len(nums), len(andValues)
        INF = float('inf')

        @lru_cache(maxsize=None)
        def dp(i: int, j: int, cur_and: int) -> int:
            # 从 nums[i] 开始，需要完成第 j 段，当前段的 AND 为 cur_and
            if j == m:
                return 0 if i == n else INF
            if i == n:
                return INF
            cur_and &= nums[i]
            target = andValues[j]
            if cur_and < target:
                return INF  # AND 只会更小，不可能再等于 target
            res = INF
            if cur_and == target:
                # 以 nums[i] 作为第 j 段的末尾
                nxt = dp(i + 1, j + 1, (1 << 17) - 1)
                if nxt < INF:
                    res = nums[i] + nxt
            # 继续扩展第 j 段
            res = min(res, dp(i + 1, j, cur_and))
            return res

        ans = dp(0, 0, (1 << 17) - 1)
        return ans if ans < INF else -1
```

## 复杂度分析

- 时间复杂度：O(n^2 * m)，备忘录方法状态数 O(n * m * V)，V = 2^17
- 空间复杂度：O(n * m * V)

## 关键点总结

1. 按位与随着区间扩大单调不增
2. 对每段的右端点，可以二分确定左端点的有效范围
3. 记忆化搜索中，当前 AND < target 时可提前剪枝

## 易错点

1. AND 初始值应为全 1（`(1 << 17) - 1`）
2. 无法满足时返回 -1
