## 题目描述

给你两个非空链表来代表两个非负整数。数字最高位位于链表开始位置。它们的每个节点只存储一位数字。将这两数相加会返回一个新的链表。

你可以假设除了数字 0 之外，这两个数字都不会以零开头。

**示例 1:**

```
输入: l1 = [7,2,4,3], l2 = [5,6,4]
输出: [7,8,0,7]
解释: 7243 + 564 = 7807
```

**示例 2:**

```
输入: l1 = [2,4,3], l2 = [5,6,4]
输出: [8,0,7]
```

**示例 3:**

```
输入: l1 = [0], l2 = [0]
输出: [0]
```

**提示:**

- 链表的长度范围为 [1, 100]
- 0 <= Node.val <= 9
- 题目数据保证列表表示的数字不含前导零

**进阶:** 如果输入链表不能修改该如何处理？换句话说，不能对列表中的节点进行翻转。

## 解题思路

这道题是 [2. Add Two Numbers](https://leetcode.com/problems/add-two-numbers/) 的变体，区别在于：
- 第 2 题：数字低位在前，可以直接从头开始相加
- 本题：数字高位在前，需要从低位开始相加

**解决方案：**

1. **栈方法（推荐）**：
   - 使用两个栈分别存储两个链表的节点值
   - 从栈顶（低位）开始相加
   - 处理进位，构建结果链表

2. **反转链表法**：
   - 先反转两个链表
   - 按照第 2 题的方法相加
   - 再反转结果链表

3. **递归法**：
   - 先对齐两个链表（补齐短链表）
   - 递归相加，返回进位

**核心思想：** 无论哪种方法，都需要**从低位到高位**进行加法运算。

## Python 代码实现

### 方法一：栈方法（推荐，符合进阶要求）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        """
        使用栈实现，不修改原链表
        时间复杂度: O(max(m, n))
        空间复杂度: O(m + n)
        """
        # 将链表值压入栈
        stack1, stack2 = [], []
        
        while l1:
            stack1.append(l1.val)
            l1 = l1.next
        
        while l2:
            stack2.append(l2.val)
            l2 = l2.next
        
        # 从栈顶开始相加（从低位到高位）
        carry = 0
        head = None
        
        while stack1 or stack2 or carry:
            val1 = stack1.pop() if stack1 else 0
            val2 = stack2.pop() if stack2 else 0
            
            total = val1 + val2 + carry
            carry = total // 10
            digit = total % 10
            
            # 头插法构建结果链表
            new_node = ListNode(digit)
            new_node.next = head
            head = new_node
        
        return head
```

### 方法二：反转链表法

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        """
        反转链表后相加
        时间复杂度: O(max(m, n))
        空间复杂度: O(1)
        """
        # 反转两个链表
        l1 = self.reverseList(l1)
        l2 = self.reverseList(l2)
        
        # 相加（类似第 2 题）
        dummy = ListNode(0)
        current = dummy
        carry = 0
        
        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            
            total = val1 + val2 + carry
            carry = total // 10
            digit = total % 10
            
            current.next = ListNode(digit)
            current = current.next
            
            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next
        
        # 反转结果链表
        return self.reverseList(dummy.next)
    
    def reverseList(self, head: ListNode) -> ListNode:
        """反转链表"""
        prev = None
        current = head
        
        while current:
            next_node = current.next
            current.next = prev
            prev = current
            current = next_node
        
        return prev
```

### 方法三：递归法（先对齐再相加）

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        """
        递归实现
        时间复杂度: O(max(m, n))
        空间复杂度: O(max(m, n)) - 递归栈
        """
        # 获取链表长度
        len1 = self.getLength(l1)
        len2 = self.getLength(l2)
        
        # 对齐两个链表（在短链表前面补 0）
        if len1 < len2:
            l1 = self.padList(l1, len2 - len1)
        elif len2 < len1:
            l2 = self.padList(l2, len1 - len2)
        
        # 递归相加
        result_node, carry = self.addHelper(l1, l2)
        
        # 如果有进位，在最前面加一个节点
        if carry:
            new_head = ListNode(carry)
            new_head.next = result_node
            return new_head
        
        return result_node
    
    def getLength(self, head: ListNode) -> int:
        """获取链表长度"""
        length = 0
        while head:
            length += 1
            head = head.next
        return length
    
    def padList(self, head: ListNode, count: int) -> ListNode:
        """在链表前面补 0"""
        for _ in range(count):
            new_node = ListNode(0)
            new_node.next = head
            head = new_node
        return head
    
    def addHelper(self, l1: ListNode, l2: ListNode) -> tuple:
        """
        递归相加，返回 (结果节点, 进位)
        """
        if not l1 and not l2:
            return None, 0
        
        # 递归处理后续节点
        next_node, carry = self.addHelper(l1.next, l2.next)
        
        # 计算当前位
        total = l1.val + l2.val + carry
        digit = total % 10
        new_carry = total // 10
        
        # 创建当前节点
        current = ListNode(digit)
        current.next = next_node
        
        return current, new_carry
```

### 方法四：Python 简化版（仅用于理解）

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        """
        先转为数字，相加后再转回链表
        不推荐：大数会溢出，仅用于理解题意
        """
        # 链表转数字
        num1 = num2 = 0
        while l1:
            num1 = num1 * 10 + l1.val
            l1 = l1.next
        while l2:
            num2 = num2 * 10 + l2.val
            l2 = l2.next
        
        # 相加
        total = num1 + num2
        
        # 数字转链表
        if total == 0:
            return ListNode(0)
        
        head = None
        while total:
            digit = total % 10
            total //= 10
            new_node = ListNode(digit)
            new_node.next = head
            head = new_node
        
        return head
```

## 复杂度分析

**方法一（栈）：**
- 时间复杂度：O(max(m, n))，m 和 n 分别是两个链表的长度
- 空间复杂度：O(m + n)，需要两个栈

**方法二（反转链表）：**
- 时间复杂度：O(max(m, n))
- 空间复杂度：O(1)，只需要常量空间（但会修改原链表）

**方法三（递归）：**
- 时间复杂度：O(max(m, n))
- 空间复杂度：O(max(m, n))，递归调用栈

## 图解示例

以 l1 = [7,2,4,3], l2 = [5,6,4] 为例（方法一）：

```
l1: 7 -> 2 -> 4 -> 3  (表示 7243)
l2: 5 -> 6 -> 4       (表示 564)

步骤 1: 压栈
stack1: [7, 2, 4, 3]
stack2: [5, 6, 4]

步骤 2: 从栈顶开始相加（从低位到高位）

第 1 步: 3 + 4 = 7, carry = 0
  result: 7

第 2 步: 4 + 6 = 10, carry = 1
  result: 0 -> 7

第 3 步: 2 + 5 + 1 = 8, carry = 0
  result: 8 -> 0 -> 7

第 4 步: 7 + 0 = 7, carry = 0
  result: 7 -> 8 -> 0 -> 7

最终结果: [7, 8, 0, 7] (表示 7807)
```

## 关键点总结

1. **栈的应用**：通过栈实现"反向访问"，不修改原链表
2. **头插法**：构建结果链表时使用头插法，避免再次反转
3. **进位处理**：与第 2 题相同，注意最高位的进位
4. **边界条件**：两个链表长度不同、最后的进位等
5. **空间权衡**：栈方法需要额外空间，但不修改原链表

## 易错点

1. **忘记处理最后的进位**：
   ```python
   # 错误：循环结束后忘记检查 carry
   while stack1 or stack2:
       ...
   
   # 正确：循环条件包含 carry
   while stack1 or stack2 or carry:
       ...
   ```

2. **链表构建顺序**：
   - 使用头插法：`new_node.next = head`
   - 确保结果链表的顺序正确

3. **空链表处理**：
   ```python
   # 正确处理空栈
   val1 = stack1.pop() if stack1 else 0
   val2 = stack2.pop() if stack2 else 0
   ```

4. **反转链表的副作用**：
   - 方法二会修改原链表
   - 如果不允许修改，必须使用栈或先复制链表
