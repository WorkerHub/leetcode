## 题目描述

给你一个数组 `nums`，对于其中每个元素 `nums[i]`，请你统计数组中比它小的所有数字的数目。

换而言之，对于每个 `nums[i]` 你必须计算出有效的 `j` 的数量，其中 `j` 满足 `j != i` **且** `nums[j] < nums[i]`。

以数组形式返回答案。

**示例 1：**
```
输入：nums = [8,1,2,2,3]
输出：[4,0,1,1,3]
解释：
  对于 nums[0]=8，存在 4 个比它小的数字（1,2,2,3）。
  对于 nums[1]=1，不存在比它小的数字。
  对于 nums[2]=2，存在 1 个比它小的数字（1）。
  对于 nums[3]=2，存在 1 个比它小的数字（1）。
  对于 nums[4]=3，存在 3 个比它小的数字（1,2,2）。
```

**示例 2：**
```
输入：nums = [6,5,4,8]
输出：[2,1,0,3]
```

**示例 3：**
```
输入：nums = [7,7,7,7]
输出：[0,0,0,0]
```

**提示：**
- `2 <= nums.length <= 500`
- `0 <= nums[i] <= 100`

## 解题思路

**三种思路：**

1. **暴力法**：对每个元素，遍历整个数组统计比它小的数量。O(N^2)，小数据可用。

2. **排序 + 哈希表**：
   - 将 nums 排序，排序后第一次出现的位置就是"比它小的数字数量"（因为前面的数都比它小）。
   - 用哈希表存储每个值对应的"比它小的数量"，然后映射回原数组。
   - O(N log N) 时间，O(N) 空间。

3. **计数排序**（利用值域 0~100）：
   - 统计每个值的出现次数。
   - 累加前缀和：`prefix[v]` = 小于 v 的数字总数。
   - 直接映射原数组。
   - O(N + M) 时间（M=101），O(M) 空间。

## Python 代码实现

### 方法一：暴力法（最直观）

```python
from typing import List

class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = []
        for i in range(n):
            count = 0
            for j in range(n):
                if j != i and nums[j] < nums[i]:
                    count += 1
            result.append(count)
        return result
```

### 方法二：排序 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        # 排序后，每个元素第一次出现的位置即为"比它小的数字数量"
        sorted_nums = sorted(nums)
        
        # 建立值 -> 比它小的数字数量 的映射
        rank = {}
        for i, v in enumerate(sorted_nums):
            if v not in rank:
                rank[v] = i  # 第一次出现的下标 = 前面有多少个比它小的数
        
        # 映射回原数组
        return [rank[v] for v in nums]
```

**解释：**
- `sorted_nums = [1, 2, 2, 3, 8]`（对示例一）
- `rank = {1: 0, 2: 1, 3: 3, 8: 4}`
  - 1 在下标 0 出现，前面 0 个数，比 1 小的有 0 个
  - 2 在下标 1 第一次出现，前面 1 个数（1），比 2 小的有 1 个
  - 3 在下标 3 出现，前面 3 个数（1,2,2），比 3 小的有 3 个
  - 8 在下标 4 出现，前面 4 个数，比 8 小的有 4 个

### 方法三：计数排序（值域 0~100 时最优）

```python
from typing import List

class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        # 计数数组（值域 0~100）
        count = [0] * 102  # 多开两格防止越界
        for v in nums:
            count[v] += 1
        
        # 计算前缀和：prefix[v] = 小于 v 的数字数量
        # 累加：count[0] 不变，count[1] += count[0]，...
        for v in range(1, 102):
            count[v] += count[v - 1]
        
        # count[v] 现在表示 <= v 的数字数量
        # 比 v 小的数字数量 = count[v-1]（v > 0 时），或 0（v == 0 时）
        return [count[v - 1] if v > 0 else 0 for v in nums]
```

### 方法四：Python 一行写法

```python
from typing import List

class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        return [sum(x < v for x in nums) for v in nums]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 暴力法 | O(N^2) | O(1) |
| 排序 + 哈希表 | O(N log N) | O(N) |
| 计数排序 | O(N + M) | O(M) |
| 一行写法 | O(N^2) | O(1) |

## 关键点总结

1. **排序后第一次出现的位置 = 比它小的数量**：这是因为排序后，位置 i 意味着前面有 i 个数都比它小（或相等但更早出现）。
2. **哈希表只记录第一次出现**：相同的值比它小的数量相同，只记录一次即可。
3. **计数排序前缀和**：利用值域有界（0~100），可以 O(N+M) 解决，比排序更快。
4. **Python `sum(x < v for x in nums)` 写法**：利用布尔值的数值特性（True=1, False=0），简洁但 O(N^2)。

## 易错点

- 排序时注意是创建新的排序数组（`sorted(nums)`），不是原地排序，原数组需要保留。
- 计数排序中，比 v 小的数量 = 前缀和到 v-1 处（不是 v 处），注意 v=0 时特判返回 0。
- `rank` 哈希表只记录每个值"第一次出现"的位置（用 `if v not in rank`），不然相同的值会被覆盖为后面的位置。
