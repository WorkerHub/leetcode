## 题目描述

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 `1`。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

**示例 1：**
```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

**示例 2：**
```
输入：heights = [2,4]
输出：4
```

**提示：**
- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

## 解题思路

**核心思想：** 使用单调栈，对于每个柱子，找到它左右两边第一个比它低的柱子，计算以该柱子为高度的最大矩形面积。

**关键观察：**
1. 对于柱子 `i`，以它为高度的最大矩形宽度 = 右边界 - 左边界 - 1
2. 左边界：左边第一个比它低的柱子位置
3. 右边界：右边第一个比它低的柱子位置
4. 使用单调栈可以高效找到左右边界

**算法流程：**
1. 维护一个单调递增栈（存储索引）
2. 遍历每个柱子，如果当前柱子比栈顶柱子低，说明找到了栈顶柱子的右边界
3. 弹出栈顶，计算以栈顶柱子为高度的矩形面积
4. 左边界是新的栈顶，右边界是当前柱子
5. 在数组末尾添加高度为 0 的哨兵，确保所有柱子都被处理

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        # 添加哨兵，确保所有柱子都能被弹出
        heights = [0] + heights + [0]
        stack = []  # 单调递增栈，存储索引
        max_area = 0
        
        for i in range(len(heights)):
            # 当前柱子比栈顶柱子低，计算栈顶柱子的面积
            while stack and heights[i] < heights[stack[-1]]:
                h = heights[stack.pop()]  # 弹出的柱子高度
                # 宽度 = 右边界 - 左边界 - 1
                w = i - stack[-1] - 1
                max_area = max(max_area, h * w)
            
            stack.append(i)
        
        return max_area
```

### 方法二：单调栈（不添加哨兵）

```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        stack = []  # 单调递增栈
        max_area = 0
        
        for i in range(len(heights)):
            # 当前柱子比栈顶柱子低
            while stack and heights[i] < heights[stack[-1]]:
                h = heights[stack.pop()]
                # 如果栈为空，说明左边没有比它低的，宽度是 i
                w = i if not stack else i - stack[-1] - 1
                max_area = max(max_area, h * w)
            
            stack.append(i)
        
        # 处理栈中剩余的柱子
        while stack:
            h = heights[stack.pop()]
            w = len(heights) if not stack else len(heights) - stack[-1] - 1
            max_area = max(max_area, h * w)
        
        return max_area
```

### 方法三：暴力解法（对比学习）

```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        max_area = 0
        n = len(heights)
        
        # 对每个柱子，找左右边界
        for i in range(n):
            # 向左找第一个比 heights[i] 低的
            left = i
            while left > 0 and heights[left - 1] >= heights[i]:
                left -= 1
            
            # 向右找第一个比 heights[i] 低的
            right = i
            while right < n - 1 and heights[right + 1] >= heights[i]:
                right += 1
            
            # 计算面积
            width = right - left + 1
            max_area = max(max_area, heights[i] * width)
        
        return max_area
```

## 复杂度分析

**方法一（单调栈）：**
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈的空间

**方法三（暴力）：**
- 时间复杂度：O(n^2)，对每个柱子需要向左右扩展
- 空间复杂度：O(1)

## 关键点总结

1. **单调栈应用**：维护单调递增栈，找左右边界
2. **哨兵技巧**：在两端添加高度为0的哨兵，简化边界处理
3. **宽度计算**：`w = right - left - 1`，其中 left 是栈中前一个元素
4. **面积计算时机**：当遇到更低的柱子时，计算栈顶柱子的面积

## 易错点

1. **栈中存储索引**：不是存储高度，因为需要计算宽度
2. **宽度计算**：`i - stack[-1] - 1`，不是 `i - stack.pop()`
3. **边界处理**：添加哨兵可以避免复杂的边界判断
4. **栈空判断**：弹出后栈可能为空，需要特殊处理
