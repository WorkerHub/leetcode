## 题目描述

给你一个正整数数组 `nums`，请你将每个整数的各位数字 **分离** 出来，并按照 `nums` 中出现的顺序，将它们排列成一个新数组（维持每个整数内部各位数字的相对顺序）。

返回分离后的新数组。

**示例 1：**

```
输入：nums = [13, 25, 83, 77]
输出：[1, 3, 2, 5, 8, 3, 7, 7]
```

**示例 2：**

```
输入：nums = [7, 1, 3, 9]
输出：[7, 1, 3, 9]
```

**提示：**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`

## 解题思路

对每个数字转为字符串，按位分拆后转为整数，添加到结果数组中。

## Python 代码实现

### 方法一：字符串展开（推荐）

```python
from typing import List

class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        result = []
        for num in nums:
            # 将数字转为字符串，逐位分离
            for ch in str(num):
                result.append(int(ch))
        return result
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        return [int(ch) for num in nums for ch in str(num)]
```

## 复杂度分析

- 时间复杂度：O(n * d)，d 为最大数字的位数（最多 5 位）
- 空间复杂度：O(n * d)，输出数组

## 关键点总结

1. 将每个数字按字符串拆分，保持数组顺序和位数顺序
2. Python 列表推导式可以一行完成
3. 注意每个数字各位的顺序（高位在前）

## 易错点

1. 保持位数顺序：高位（最高有效位）排在前面
2. 每个数拆分后的各位都加入结果，不去重
3. 单位数字不需要拆分
