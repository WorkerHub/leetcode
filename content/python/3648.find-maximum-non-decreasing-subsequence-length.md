## 题目描述

给你一个整数数组 `nums`，返回最长的非递减子序列的长度。

子序列是通过从数组中删除部分元素（可以为空，且保持其余元素的顺序不变）而得到的序列。

**示例 1：**

```
输入：nums = [1,3,2,4,5]
输出：4
解释：[1,3,4,5] 或 [1,2,4,5]，长度4
```

**示例 2：**

```
输入：nums = [5,4,3,2,1]
输出：1
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

经典 LIS（最长非递减子序列）问题，使用 patience sorting（二分查找优化）。

维护一个数组 `tails`，`tails[i]` 表示长度为 `i+1` 的非递减子序列的最小末尾元素。

对每个 `nums[j]`，在 `tails` 中找第一个大于 `nums[j]` 的位置（非递减，用 `bisect_right`），替换它。

## Python 代码实现

### 方法一：二分查找优化（推荐）

```python
from typing import List
import bisect

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []
        for x in nums:
            # 非递减：找第一个 > x 的位置替换
            pos = bisect.bisect_right(tails, x)
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x
        return len(tails)
```

### 方法二：动态规划（O(n^2)）

```python
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n
        for i in range(1, n):
            for j in range(i):
                if nums[j] <= nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(n log n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 非递减用 `bisect_right`（允许相等），严格递增用 `bisect_left`
2. `tails` 数组始终有序，长度就是答案
3. 替换不改变 `tails` 长度，追加才增加长度

## 易错点

1. 非递减与严格递增对应不同的 bisect 函数
2. `bisect_right` 找的是插入点（第一个大于 x 的位置）
3. `tails` 不是实际的子序列，仅记录末尾最小值
