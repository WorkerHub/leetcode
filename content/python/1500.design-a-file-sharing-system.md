## 题目描述

我们需要设计一个文件共享系统，用户可以上传/下载文件的某些数据块。该文件只有一个，被分成了 `m` 个**数据块**，编号从 `1` 到 `m`。

实现 `FileSharing` 类：

- `FileSharing(int m)`：用文件的 `m` 个数据块数量初始化该对象。
- `int join(int[] ownedChunks)`：一个新用户加入系统，已经拥有某些数据块 `ownedChunks`。系统分配给该用户**最小的可用**用户 ID（从 1 开始）。返回该用户 ID。
- `void leave(int userID)`：用户 `userID` 离开系统，释放其占用的用户 ID 和所有数据块。
- `int[] request(int userID, int chunkID)`：用户 `userID` 请求数据块 `chunkID`。返回拥有该数据块的**所有用户 ID**（有序），若有用户拥有该块，则用户 `userID` 也会获得该数据块（加入自己的集合）。若无人拥有，返回空数组。

**示例：**

```python
fs = FileSharing(4)
fs.join([])         # 返回 1（用户1没有任何数据块）
fs.join([2])        # 返回 2（用户2拥有数据块2）
fs.join([1, 3])     # 返回 3（用户3拥有数据块1和3）
fs.request(1, 3)    # 返回 [3]（用户3有块3），用户1也获得块3
fs.request(2, 2)    # 返回 [2]（用户2有块2），用户2已有无需变化
fs.leave(1)         # 用户1离开
fs.request(2, 1)    # 返回 []（无人有块1）
fs.leave(2)
fs.join([2])        # 返回 1（用户ID 1 被复用，最小可用）
```

**提示：**

- `1 <= m <= 10^5`
- `0 <= ownedChunks.length <= min(100, m)`
- `1 <= ownedChunks[i] <= m`
- `1 <= chunkID <= m`
- `userID` 是一个有效的、当前在系统中的用户
- 每次调用 `join` 时最多有 `10^4` 个用户在系统中
- 最多调用 `10^4` 次 `join`、`leave` 和 `request`

## 解题思路

**数据结构设计：**

1. **用户 ID 管理**：
   - 需要分配"最小可用 ID"，天然适合使用**最小堆**。
   - 当用户离开时，将其 ID 放回堆中。
   - 若堆为空，则分配一个新的递增 ID（`max_id += 1`）。

2. **数据块拥有者记录**：
   - `chunk_to_users[chunkID]`：有序集合（`SortedList`）或普通集合，记录拥有该块的所有用户。
   - 也需要 `user_to_chunks[userID]`：记录该用户拥有的所有数据块（用于 `leave` 时清理）。

3. **join 操作**：
   - 从堆中获取最小 ID（或生成新 ID）。
   - 将 `ownedChunks` 注册到 `chunk_to_users` 中。
   - 更新 `user_to_chunks`。

4. **leave 操作**：
   - 将用户从其所有 `chunk_to_users` 集合中移除。
   - 清空 `user_to_chunks[userID]`。
   - 将 `userID` 放回最小堆。

5. **request 操作**：
   - 获取 `chunk_to_users[chunkID]` 的有序用户列表。
   - 若非空，将 `userID` 加入该集合，并更新 `user_to_chunks[userID]`。
   - 返回排序后的用户列表。

## Python 代码实现

### 方法一：最小堆 + 哈希表（推荐）

```python
import heapq
from collections import defaultdict
from typing import List

class FileSharing:

    def __init__(self, m: int):
        self.m = m
        # 最小堆，存储可用的用户 ID
        self.available_ids = []
        # 下一个新用户 ID（若堆为空时使用）
        self.next_id = 1
        # chunk_to_users[chunk_id] = 有序用户集合
        self.chunk_to_users = defaultdict(set)
        # user_to_chunks[user_id] = 该用户拥有的数据块集合
        self.user_to_chunks = defaultdict(set)

    def join(self, ownedChunks: List[int]) -> int:
        # 获取最小可用用户 ID
        if self.available_ids:
            user_id = heapq.heappop(self.available_ids)
        else:
            user_id = self.next_id
            self.next_id += 1

        # 注册数据块
        for chunk in ownedChunks:
            self.chunk_to_users[chunk].add(user_id)
            self.user_to_chunks[user_id].add(chunk)

        return user_id

    def leave(self, userID: int) -> None:
        # 从所有拥有的数据块中移除该用户
        for chunk in self.user_to_chunks[userID]:
            self.chunk_to_users[chunk].discard(userID)

        # 清空该用户的数据块记录
        del self.user_to_chunks[userID]

        # 将用户 ID 归还到可用堆
        heapq.heappush(self.available_ids, userID)

    def request(self, userID: int, chunkID: int) -> List[int]:
        # 获取拥有该数据块的所有用户（排序）
        owners = sorted(self.chunk_to_users[chunkID])

        # 若有人拥有该块，userID 也获得该块
        if owners:
            self.chunk_to_users[chunkID].add(userID)
            self.user_to_chunks[userID].add(chunkID)

        return owners
```

### 方法二：使用 SortedList 优化 request（快速有序查询）

```python
import heapq
from collections import defaultdict
from typing import List

# 需要安装 sortedcontainers
# pip install sortedcontainers
try:
    from sortedcontainers import SortedList
except ImportError:
    # 降级为普通 list，request 时排序
    SortedList = None

class FileSharing:

    def __init__(self, m: int):
        self.available_ids = []
        self.next_id = 1
        # 使用 SortedList 保证 chunk_to_users 有序
        self.chunk_to_users = defaultdict(SortedList if SortedList else list)
        self.user_to_chunks = defaultdict(set)

    def join(self, ownedChunks: List[int]) -> int:
        if self.available_ids:
            user_id = heapq.heappop(self.available_ids)
        else:
            user_id = self.next_id
            self.next_id += 1

        for chunk in ownedChunks:
            if SortedList:
                self.chunk_to_users[chunk].add(user_id)
            else:
                self.chunk_to_users[chunk].append(user_id)
                self.chunk_to_users[chunk].sort()
            self.user_to_chunks[user_id].add(chunk)

        return user_id

    def leave(self, userID: int) -> None:
        for chunk in self.user_to_chunks[userID]:
            if SortedList:
                self.chunk_to_users[chunk].discard(userID)
            else:
                if userID in self.chunk_to_users[chunk]:
                    self.chunk_to_users[chunk].remove(userID)

        del self.user_to_chunks[userID]
        heapq.heappush(self.available_ids, userID)

    def request(self, userID: int, chunkID: int) -> List[int]:
        owners = list(self.chunk_to_users[chunkID])
        if not SortedList:
            owners = sorted(owners)

        if owners:
            if SortedList:
                self.chunk_to_users[chunkID].add(userID)
            else:
                if userID not in self.chunk_to_users[chunkID]:
                    self.chunk_to_users[chunkID].append(userID)
                    self.chunk_to_users[chunkID].sort()
            self.user_to_chunks[userID].add(chunkID)

        return owners
```

### 方法三：简化版（使用 sorted set，不依赖 sortedcontainers）

```python
import heapq
from collections import defaultdict
from typing import List

class FileSharing:

    def __init__(self, m: int):
        self.heap = []       # 最小堆，管理可复用 ID
        self.next_id = 1     # 下一个新 ID
        # chunk_owners: chunk_id -> set of user_ids
        self.chunk_owners = defaultdict(set)
        # user_chunks: user_id -> set of chunk_ids
        self.user_chunks = defaultdict(set)

    def join(self, ownedChunks: List[int]) -> int:
        # 取最小可用 ID
        uid = heapq.heappop(self.heap) if self.heap else self.next_id
        if uid == self.next_id:
            self.next_id += 1

        # 注册拥有的数据块
        for c in ownedChunks:
            self.chunk_owners[c].add(uid)
        self.user_chunks[uid] = set(ownedChunks)

        return uid

    def leave(self, userID: int) -> None:
        # 从各数据块中注销
        for c in self.user_chunks.pop(userID, []):
            self.chunk_owners[c].discard(userID)
        # 归还 ID
        heapq.heappush(self.heap, userID)

    def request(self, userID: int, chunkID: int) -> List[int]:
        owners = sorted(self.chunk_owners[chunkID])
        if owners:
            # 用户 userID 也获得该块
            self.chunk_owners[chunkID].add(userID)
            self.user_chunks[userID].add(chunkID)
        return owners
```

## 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `join` | O(c log u) | c = ownedChunks 长度，u = 当前用户数 |
| `leave` | O(c log u) | c = 用户拥有的块数 |
| `request` | O(u log u) | 排序 owners，u 为拥有该块的用户数 |

- 空间复杂度：O(u * c + m)，u 为用户数，c 为每用户平均块数，m 为总块数

## 关键点总结

1. **最小堆复用 ID**：保证每次 `join` 返回最小可用 ID，`leave` 时将 ID 归还堆中。
2. **双向映射**：`chunk_owners`（块→用户集合）和 `user_chunks`（用户→块集合）相互补充，支持高效的增删查操作。
3. **leave 清理**：离开时必须同时从所有 `chunk_owners` 中移除该用户，以及清除 `user_chunks` 中的条目。
4. **request 的幂等性**：若 `userID` 已拥有该块，加入集合不影响结果（集合自动去重）。

## 易错点

- **ID 复用顺序**：离开的用户 ID 必须能被再次分配，且始终返回最小可用 ID。
- **request 中先记录后更新**：先把当前 `owners` 列表记录下来（不含 `userID`），再更新集合（加入 `userID`），否则 `userID` 可能出现在返回列表中。
- **leave 时的清理**：忘记从 `chunk_owners` 中移除用户，会导致后续 `request` 返回已离开的用户。
- **新 ID 的生成逻辑**：需要判断堆是否为空，若为空才递增 `next_id`。
