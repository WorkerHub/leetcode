## 题目描述

给定一个字符串数组 `words`。将其分成若干连续组，每组中的字符串首字母和末尾字母相同（即每组的第一个字符串的首字母等于最后一个字符串的末尾字母）。求满足条件的分组方式数量，对 `10^9 + 7` 取模。

**示例：**

```
输入：words = ["ab", "bc", "ca"]
输出：2
解释：分法1：["ab","bc","ca"] 一组，首字母 'a'，末尾字母 'a'，满足。
     分法2：["ab"] + ["bc","ca"]，["ab"] 首='a'尾='b'，不满足。
     ...
```

**提示：**
- `1 <= words.length <= 10^5`
- `1 <= words[i].length <= 10`

## 解题思路

动态规划。

`dp[i]` = 将 `words[0..i-1]` 分成若干合法组的方案数。

对每个右端点 `i`，枚举起点 `j`，若 `words[j..i-1]` 构成合法组（`words[j][0] == words[i-1][-1]`），则 `dp[i] += dp[j]`。

合法组条件：`words[j][0] == words[i-1][-1]`（起点首字母 = 终点末字母）。

用哈希表按首字母分组，快速找所有合法起点。

## Python 代码实现

### 方法一：哈希表 + DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodDivisions(self, words: List[str]) -> int:
        MOD = 10 ** 9 + 7
        n = len(words)
        # dp[i] = words[0..i-1] 的合法分组数
        dp = [0] * (n + 1)
        dp[0] = 1

        # first_char_dp[c] = 所有 dp[j] 的和，其中 words[j][0] == c
        # 当计算 dp[i] 时，合法起点 j 满足 words[j][0] == words[i-1][-1]
        # dp[i] = sum(dp[j]) for j where words[j][0] == words[i-1][-1]

        # 但 words[j][0] 是第 j 个单词的首字母，j 从 0 到 i-1
        # 分割点 j 表示 words[0..j-1] 已处理，当前组从 j 开始到 i-1
        # 所以分割点 j 对应的起始单词是 words[j]

        # 实时维护 first_char_sum[c] = sum of dp[j] where words[j][0] == c
        first_char_sum = defaultdict(int)
        # j = 0 时，没有单词，dp[0] = 1，不对应任何单词的首字母
        # j >= 1 时，words[j] 的首字母是 words[j][0]

        # 重新定义：分割在位置 j 表示 words[0..j-1] 已分好组，从 j 开始新组
        # dp[i] = sum(dp[j]) for j in [0..i-1] where words[j][0] == words[i-1][-1]
        # 初始：dp[0] = 1（空数组，0 个组）

        first_char_sum[words[0][0]] += dp[0]  # j=0, words[0][0] 是第一组的首字母

        for i in range(1, n + 1):
            last_char = words[i-1][-1]  # 当前组末尾字母
            dp[i] = first_char_sum[last_char] % MOD

            if i < n:
                first_char_sum[words[i][0]] = (first_char_sum[words[i][0]] + dp[i]) % MOD

        return dp[n]
```

### 方法二：暴力 DP

```python
from typing import List

class Solution:
    def countGoodDivisions(self, words: List[str]) -> int:
        MOD = 10 ** 9 + 7
        n = len(words)
        dp = [0] * (n + 1)
        dp[0] = 1

        for i in range(1, n + 1):
            for j in range(i):
                if words[j][0] == words[i-1][-1]:
                    dp[i] = (dp[i] + dp[j]) % MOD

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 合法组条件：起始单词首字母 = 末尾单词末字母
2. 用哈希表按首字母维护 dp 前缀和，O(1) 查询
3. 状态转移：`dp[i] = sum(dp[j] where words[j][0] == words[i-1][-1])`

## 易错点

1. 合法组不能为空（每组至少一个单词）
2. 哈希表维护的是 `dp[j]` 的和，按 `words[j][0]`（第 j 组起始单词首字母）分类
3. 分割点 j 对应起始单词 `words[j]`，终止单词 `words[i-1]`
