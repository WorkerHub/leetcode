## 题目描述

在由 1 x 1 方格组成的 N x N 网格 `grid` 中，每个 1 x 1 方块由 `/`、`\` 或空格构成。这些字符会将方块划分为一些共享边的区域。

（请注意，反斜杠字符是转义的，因此 `\` 用 `"\\"` 表示。）

返回区域的数目。

**示例 1：**
```
输入：
[
  " /",
  "/ "
]
输出：2
解释：2x2 网格如下：
```

**示例 2：**
```
输入：
[
  " /",
  "  "
]
输出：1
解释：2x2 网格如下：
```

**示例 3：**
```
输入：
[
  "\\/",
  "/\\"
]
输出：4
解释：（回想一下，因为 \ 字符是转义的，所以 "\\/" 表示 \/，而 "/\\" 表示 /\。）
2x2 网格如下：
```

**示例 4：**
```
输入：
[
  "/\\",
  "\\/"
]
输出：5
解释：（回想一下，因为 \ 字符是转义的，所以 "/\\" 表示 /\，而 "\\/" 表示 \/。）
2x2 网格如下：
```

**示例 5：**
```
输入：
[
  "//",
  "/ "
]
输出：3
解释：2x2 网格如下：
```

**提示：**
- `1 <= grid.length == grid[0].length <= 30`
- `grid[i][j]` 是 `/`、`\`、或 ` `

## 解题思路

这道题的关键是将每个 1x1 的方格进一步细分，然后使用并查集或 DFS/BFS 来统计连通区域的数量。

**核心思想：**
1. 将每个 1x1 方格分成 4 个小三角形区域（上、右、下、左）
2. 根据方格中的字符（`/`、`\`、空格）来决定哪些小三角形是连通的
3. 使用并查集合并连通的区域，最后统计不同的连通分量数

**细分方法：**
```
将每个方格分为 4 部分：
    0
  -----
3 |   | 1
  -----
    2
```

- 空格：4 个区域全部连通
- `/`：0 和 3 连通，1 和 2 连通
- `\`：0 和 1 连通，2 和 3 连通

**相邻方格的连接：**
- 当前方格的右侧区域(1) 与右边方格的左侧区域(3) 连通
- 当前方格的下侧区域(2) 与下边方格的上侧区域(0) 连通

## Python 代码实现

### 方法一：并查集（推荐）⭐

```python
from typing import List

class Solution:
    def regionsBySlashes(self, grid: List[str]) -> int:
        n = len(grid)
        # 每个格子分成 4 个小三角形，总共 n*n*4 个区域
        parent = list(range(n * n * 4))
        
        def find(x):
            """查找根节点（带路径压缩）"""
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            """合并两个集合"""
            root_x = find(x)
            root_y = find(y)
            if root_x != root_y:
                parent[root_x] = root_y
        
        # 遍历每个格子
        for i in range(n):
            for j in range(n):
                # 当前格子的 4 个区域编号
                base = (i * n + j) * 4
                
                # 根据字符连接格子内的区域
                if grid[i][j] == ' ':
                    # 空格：4 个区域全部连通
                    union(base, base + 1)
                    union(base + 1, base + 2)
                    union(base + 2, base + 3)
                elif grid[i][j] == '/':
                    # /：上(0)和左(3)连通，右(1)和下(2)连通
                    union(base, base + 3)
                    union(base + 1, base + 2)
                else:  # '\\'
                    # \：上(0)和右(1)连通，下(2)和左(3)连通
                    union(base, base + 1)
                    union(base + 2, base + 3)
                
                # 连接相邻格子
                # 与右边格子连接
                if j < n - 1:
                    right_base = (i * n + j + 1) * 4
                    union(base + 1, right_base + 3)  # 当前右侧 -> 右边左侧
                
                # 与下边格子连接
                if i < n - 1:
                    down_base = ((i + 1) * n + j) * 4
                    union(base + 2, down_base)  # 当前下侧 -> 下边上侧
        
        # 统计不同的根节点数量
        return sum(find(i) == i for i in range(n * n * 4))
```

### 方法二：DFS（图放大法）

```python
from typing import List

class Solution:
    def regionsBySlashes(self, grid: List[str]) -> int:
        n = len(grid)
        # 将每个格子放大 3 倍，用 0/1 表示
        g = [[0] * (n * 3) for _ in range(n * 3)]
        
        # 根据原始网格填充放大后的网格
        for i in range(n):
            for j in range(n):
                if grid[i][j] == '/':
                    g[i * 3][j * 3 + 2] = 1
                    g[i * 3 + 1][j * 3 + 1] = 1
                    g[i * 3 + 2][j * 3] = 1
                elif grid[i][j] == '\\':
                    g[i * 3][j * 3] = 1
                    g[i * 3 + 1][j * 3 + 1] = 1
                    g[i * 3 + 2][j * 3 + 2] = 1
        
        def dfs(x, y):
            """深度优先搜索标记连通区域"""
            if x < 0 or x >= n * 3 or y < 0 or y >= n * 3 or g[x][y] != 0:
                return
            g[x][y] = 1  # 标记为已访问
            dfs(x + 1, y)
            dfs(x - 1, y)
            dfs(x, y + 1)
            dfs(x, y - 1)
        
        # 统计连通区域数量
        regions = 0
        for i in range(n * 3):
            for j in range(n * 3):
                if g[i][j] == 0:
                    dfs(i, j)
                    regions += 1
        
        return regions
```

### 方法三：BFS

```python
from typing import List
from collections import deque

class Solution:
    def regionsBySlashes(self, grid: List[str]) -> int:
        n = len(grid)
        # 将每个格子放大 3 倍
        g = [[0] * (n * 3) for _ in range(n * 3)]
        
        # 填充放大后的网格
        for i in range(n):
            for j in range(n):
                if grid[i][j] == '/':
                    g[i * 3][j * 3 + 2] = 1
                    g[i * 3 + 1][j * 3 + 1] = 1
                    g[i * 3 + 2][j * 3] = 1
                elif grid[i][j] == '\\':
                    g[i * 3][j * 3] = 1
                    g[i * 3 + 1][j * 3 + 1] = 1
                    g[i * 3 + 2][j * 3 + 2] = 1
        
        def bfs(start_x, start_y):
            """广度优先搜索标记连通区域"""
            queue = deque([(start_x, start_y)])
            g[start_x][start_y] = 1
            
            while queue:
                x, y = queue.popleft()
                for dx, dy in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n * 3 and 0 <= ny < n * 3 and g[nx][ny] == 0:
                        g[nx][ny] = 1
                        queue.append((nx, ny))
        
        # 统计连通区域
        regions = 0
        for i in range(n * 3):
            for j in range(n * 3):
                if g[i][j] == 0:
                    bfs(i, j)
                    regions += 1
        
        return regions
```

## 复杂度分析

### 方法一：并查集
- **时间复杂度**：O(n² × α(n²))，其中 α 是阿克曼函数的反函数，几乎是常数
- **空间复杂度**：O(n²)，并查集数组空间

### 方法二/三：DFS/BFS
- **时间复杂度**：O(n²)，需要遍历 3n × 3n 的网格
- **空间复杂度**：O(n²)，放大后的网格空间

## 关键点总结

1. **问题转化**：将斜线切割问题转化为连通区域统计问题
2. **细分策略**：每个格子分成 4 个小三角形，或将格子放大 3 倍
3. **并查集优势**：不需要额外的网格空间，直接在抽象层面处理连通性
4. **图放大法**：更直观，易于理解，但空间占用较大
5. **边界处理**：注意相邻格子之间的连接关系

## 易错点

1. **字符转义**：`\` 在字符串中需要写成 `"\\"`
2. **区域编号**：并查集方法中，4 个小三角形的编号规则要统一
3. **连接关系**：`/` 和 `\` 的连接规则容易混淆
4. **放大比例**：图放大法至少要放大 3 倍才能正确表示斜线
5. **索引计算**：计算相邻格子的索引时容易出错
