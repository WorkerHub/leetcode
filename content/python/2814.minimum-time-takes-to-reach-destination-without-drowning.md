## 题目描述

给你一个 `n x m` 的网格 `land`，每个格子为以下之一：
- `'S'`：起点（左上区域某处）
- `'D'`：终点
- `'.'`：空地
- `'*'`：水（初始时就是水）
- `'X'`：障碍物（永久阻挡）

每一秒，水会从当前所有水格子向上下左右四个方向扩散（不能穿越障碍物 `'X'`）。同一秒内，你可以移动到相邻的非水非障碍格子。

如果你站在某个格子，且该格子在下一秒会变成水，则你不安全（你在扩散前就要移走）。

返回到达终点 `'D'` 所需的最少时间，若不可能则返回 `-1`。

**提示：**
- `2 <= n, m <= 50`
- `land` 只包含 `'S'`、`'D'`、`'.'`、`'*'`、`'X'`

## 解题思路

**双重 BFS：**

1. **水的扩散 BFS：** 以所有初始水格为源，BFS 计算每个格子被水淹没的时间 `flood[i][j]`（-1 表示永不被淹没）
2. **人的移动 BFS：** 从起点 `S` 出发，BFS 找到到达终点 `D` 的最短路径，条件是：到达某格子的时间 < 该格子被淹没的时间

**关键约束：** 到达格子 `(nx, ny)` 的时间为 `t+1`，需要 `flood[nx][ny] == -1 or t+1 < flood[nx][ny]`（到达时还未被淹没）

## Python 代码实现

### 方法一：双重 BFS（推荐）

```python
from collections import deque
from typing import List

class Solution:
    def minimumSeconds(self, land: List[List[str]]) -> int:
        n, m = len(land), len(land[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        # 找起点、终点，以及所有初始水格
        start = end = None
        water_sources = []
        for i in range(n):
            for j in range(m):
                if land[i][j] == 'S':
                    start = (i, j)
                elif land[i][j] == 'D':
                    end = (i, j)
                elif land[i][j] == '*':
                    water_sources.append((i, j))

        # 步骤 1：BFS 计算各格子被水淹没的时间
        flood = [[-1] * m for _ in range(n)]
        dq = deque()
        for r, c in water_sources:
            flood[r][c] = 0
            dq.append((r, c))

        while dq:
            x, y = dq.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and flood[nx][ny] == -1 and land[nx][ny] != 'X':
                    flood[nx][ny] = flood[x][y] + 1
                    dq.append((nx, ny))

        # 步骤 2：BFS 找人的最短路径
        sr, sc = start
        er, ec = end

        # 检查起点和终点是否有效
        # 注意：起点在时间 0，如果起点被水淹（flood[sr][sc] == 0），直接返回 -1
        if flood[sr][sc] == 0:
            return -1
        # 终点永远不会被水淹（flood[er][ec] == -1 或足够大）

        visited = [[-1] * m for _ in range(n)]
        visited[sr][sc] = 0
        dq = deque([(sr, sc, 0)])  # (行, 列, 时间)

        while dq:
            x, y, t = dq.popleft()
            if x == er and y == ec:
                return t
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if (0 <= nx < n and 0 <= ny < m
                        and visited[nx][ny] == -1
                        and land[nx][ny] != 'X'
                        and land[nx][ny] != '*'):
                    nt = t + 1
                    # 到达时该格子未被水淹
                    if flood[nx][ny] == -1 or nt < flood[nx][ny]:
                        visited[nx][ny] = nt
                        dq.append((nx, ny, nt))

        return -1
```

### 方法二：带详细注释

```python
from collections import deque
from typing import List

class Solution:
    def minimumSeconds(self, land: List[List[str]]) -> int:
        n, m = len(land), len(land[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        # 初始化
        start = end = None
        flood_time = [[float('inf')] * m for _ in range(n)]
        water_q = deque()

        for i in range(n):
            for j in range(m):
                c = land[i][j]
                if c == 'S':
                    start = (i, j)
                elif c == 'D':
                    end = (i, j)
                elif c == '*':
                    flood_time[i][j] = 0
                    water_q.append((i, j))
                elif c == 'X':
                    flood_time[i][j] = float('inf')  # 障碍永不被淹

        # 水的 BFS 扩散
        while water_q:
            x, y = water_q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and flood_time[nx][ny] == float('inf') and land[nx][ny] != 'X':
                    flood_time[nx][ny] = flood_time[x][y] + 1
                    water_q.append((nx, ny))

        # 人的 BFS
        sr, sc = start
        er, ec = end
        if flood_time[sr][sc] == 0:  # 起点立刻被淹
            return -1

        visited = [[False] * m for _ in range(n)]
        visited[sr][sc] = True
        person_q = deque([(sr, sc, 0)])

        while person_q:
            x, y, t = person_q.popleft()
            if x == er and y == ec:
                return t
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                nt = t + 1
                if (0 <= nx < n and 0 <= ny < m
                        and not visited[nx][ny]
                        and land[nx][ny] not in ('X', '*')
                        and nt < flood_time[nx][ny]):  # 到达时未被淹
                    visited[nx][ny] = True
                    person_q.append((nx, ny, nt))

        return -1
```

## 复杂度分析

- 时间复杂度：O(n × m)，两次 BFS 各 O(n × m)
- 空间复杂度：O(n × m)，flood_time 数组和访问数组

## 关键点总结

1. 先用多源 BFS 计算水的扩散时间
2. 人到达某格子的时间必须**严格小于**水到达该格子的时间
3. 起点被水淹（time=0）时直接返回 -1
4. 终点 D 即使被水淹也可以到达（只要到达时间 < 被淹时间）

## 易错点

1. 判断条件是 `nt < flood_time[nx][ny]`（严格小于），不是 `<=`
2. 障碍物 `X` 既不能被人走，也不会被水淹
3. 初始水格 `*` 人也不能走
