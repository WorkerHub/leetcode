## 题目描述

Alice 手中有一把牌，她想要重新排列这些牌，分成若干组，使每一组的大小都是 `groupSize`，并且由 `groupSize` 张 **连续** 的牌组成。

给你一个整数数组 `hand` 其中 `hand[i]` 是写在第 `i` 张牌上的 **值**。

如果她可能重新排列这些牌，返回 `true`；否则，返回 `false`。

## Python 代码实现

```python
from typing import List
from collections import Counter

class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        if len(hand) % groupSize != 0:
            return False
        
        count = Counter(hand)
        
        for card in sorted(count):
            if count[card] > 0:
                num_groups = count[card]
                
                for i in range(groupSize):
                    if count[card + i] < num_groups:
                        return False
                    count[card + i] -= num_groups
        
        return True
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心**：从最小的牌开始组成顺子
2. **计数**：使用Counter统计每张牌的数量
3. **连续性**：检查连续 groupSize 张牌

## 学习建议

1. **贪心策略**：从小到大处理
2. **Counter应用**：频率统计
