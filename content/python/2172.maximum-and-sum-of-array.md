## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和整数 `numSlots`，满足 `2 * numSlots >= n`。

将数组中 `n` 个整数放入 `numSlots` 个槽中，每个槽**最多放 2 个整数**。

放置整数的**与和**定义为每个整数与其所在槽编号的**按位与**之和（槽编号从 1 到 numSlots）。

返回所有放置方案中的**最大与和**。

**提示：**
- `n == nums.length`
- `1 <= numSlots <= 9`
- `1 <= n <= 2 * numSlots`
- `1 <= nums[i] <= 15`

## 解题思路

**状态压缩 DP**

每个槽最多放 2 个，用**三进制**表示每个槽的状态（0 个、1 个、2 个）。

`numSlots <= 9`，状态数 = `3^9 = 19683`，完全可行。

`dp[state]` = 在当前槽使用状态 `state` 下，已放置前 k 个数字的最大与和。

k = 状态中各位之和（1 的个数之和，即已放多少个数）。

转移：枚举将 `nums[k]` 放入哪个槽（0 到 numSlots-1），若该槽未满（位 < 2），则将该位 +1，更新 dp。

## 代码实现

### 方法一：三进制状态 DP（推荐）

```python
from typing import List
import math

class Solution:
    def maximumANDSum(self, nums: List[int], numSlots: int) -> int:
        n = len(nums)
        total_states = 3 ** numSlots
        dp = [0] * total_states

        # 预计算每个状态的"已放数字数" = 状态中各位的三进制数字之和
        def count_placed(state: int) -> int:
            count = 0
            s = state
            for _ in range(numSlots):
                count += s % 3
                s //= 3
            return count

        ans = 0
        for state in range(total_states):
            k = count_placed(state)
            if k >= n:
                continue
            # 尝试将 nums[k] 放入某个槽
            val = nums[k]
            s = state
            for slot in range(numSlots):
                digit = s % 3
                s //= 3
                if digit < 2:
                    # 槽 slot+1 未满，放入 nums[k]
                    new_state = state + (3 ** slot)
                    gain = val & (slot + 1)
                    if dp[state] + gain > dp[new_state]:
                        dp[new_state] = dp[state] + gain
                        ans = max(ans, dp[new_state])

        return ans
```

### 方法二：递归记忆化

```python
from typing import List
from functools import lru_cache

class Solution:
    def maximumANDSum(self, nums: List[int], numSlots: int) -> int:
        n = len(nums)

        @lru_cache(maxsize=None)
        def dp(state: int) -> int:
            # 计算当前已放数字数
            k = sum((state // (3**i)) % 3 for i in range(numSlots))
            if k == n:
                return 0
            val = nums[k]
            best = 0
            for i in range(numSlots):
                digit = (state // (3**i)) % 3
                if digit < 2:
                    new_state = state + (3**i)
                    best = max(best, (val & (i+1)) + dp(new_state))
            return best

        return dp(0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三进制 DP | O(3^slots * slots) | O(3^slots) |

3^9 = 19683，slots <= 9，完全可行。

## 关键点总结

1. 三进制状态：每个槽 0/1/2 个数字，共 3^numSlots 个状态。
2. 状态中已放数字数 = 各位三进制数字之和（因为每放一个数，某位从 0->1 或 1->2）。
3. 转移：枚举将下一个数字放入哪个未满的槽，加上 `val & slot_no`。

## 易错点

- 槽编号从 1 开始（第 i 个槽编号为 i+1）。
- 三进制位的读取：第 i 槽的状态 = `(state // 3^i) % 3`。
