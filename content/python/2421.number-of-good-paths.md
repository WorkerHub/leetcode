## 题目描述

给你一棵 `n` 个节点的树（连通无向无环图），节点编号从 `0` 到 `n - 1`，且恰好有 `n - 1` 条边。

给你一个长度为 `n` 下标从 **0** 开始的整数数组 `vals`，分别表示每个节点的值。同时给你一个二维整数数组 `edges`，其中 `edges[i] = [ai, bi]` 表示节点 `ai` 和 `bi` 之间有一条 **无向** 边。

一条 **好路径** 需满足以下条件：

1. 开始节点和结束节点的值 **相同**。
2. 开始节点和结束节点之间的所有节点值都 **小于等于** 开始节点的值（也就是说，开始和结束节点的值应该是路径上 **最大** 的值）。

返回不同好路径的数目。

注意：单个节点的路径也算作好路径。

**提示：**
- `n == vals.length`
- `1 <= n <= 3 * 10^4`
- `0 <= vals[i] <= 10^5`
- `2 <= edges.length == n - 1`

## 解题思路

**并查集 + 按值排序**：

关键思想：将边按照两端节点的最大值排序，逐步加入节点。

1. 将所有节点按值排序，按值从小到大处理
2. 对当前值 `v`，将所有值 `<= v` 的节点对应的边加入并查集
3. 统计同一连通分量中，值等于 `v` 的节点数量 `cnt`
4. 这 `cnt` 个节点中，任意两个节点的路径都是好路径（路径上最大值为 v，且两端值相等）
5. 好路径数 += `cnt * (cnt - 1) / 2`（加上 n 个单节点路径）

**为什么正确？** 处理值 `v` 时，连通分量内只有值 <= v 的节点，所以两端值为 v 的路径上所有节点值 <= v，满足好路径条件。

## 代码实现

### 方法一：并查集 + 按值排序（推荐）

```python
from typing import List
from collections import defaultdict

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> None:
        px, py = self.find(x), self.find(y)
        if px == py:
            return
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1

class Solution:
    def numberOfGoodPaths(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        # 建立邻接表
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 按节点值分组
        val_to_nodes = defaultdict(list)
        for i, v in enumerate(vals):
            val_to_nodes[v].append(i)

        uf = UnionFind(n)
        # 已激活（加入并查集）的节点集合
        activated = set()
        ans = n  # 每个单节点本身是好路径

        for val in sorted(val_to_nodes.keys()):
            # 激活当前值的所有节点，并连接值 <= val 的相邻节点
            for node in val_to_nodes[val]:
                activated.add(node)
                for neighbor in adj[node]:
                    if neighbor in activated:
                        uf.union(node, neighbor)

            # 统计同一连通分量中值等于 val 的节点数量
            root_count = defaultdict(int)
            for node in val_to_nodes[val]:
                root = uf.find(node)
                root_count[root] += 1

            # 每组 cnt 个同值节点，好路径数为 C(cnt, 2)
            for cnt in root_count.values():
                ans += cnt * (cnt - 1) // 2

        return ans
```

### 方法二：边按最大值排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def numberOfGoodPaths(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        parent = list(range(n))
        size = [[vals[i], 1] for i in range(n)]  # [最大值, 该最大值的节点数]

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return 0
            # 合并时处理路径计数
            if size[px][0] < size[py][0]:
                px, py = py, px
            count = 0
            if size[px][0] == size[py][0]:
                count = size[px][1] * size[py][1]
                size[px][1] += size[py][1]
            parent[py] = px
            return count

        # 按边的最大节点值排序
        edges.sort(key=lambda e: max(vals[e[0]], vals[e[1]]))
        ans = n  # 每个节点自身

        for u, v in edges:
            ans += union(u, v)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 + 排序 | O(n log n * alpha(n)) | O(n) |

## 关键点总结

1. 按节点值从小到大处理，保证处理值 v 时连通分量内只有 <= v 的节点
2. 同一连通分量中值等于 v 的节点两两构成好路径
3. C(cnt, 2) = cnt*(cnt-1)/2 是组合数公式

## 易错点

- 单个节点的路径也算，初始答案为 n
- 只连接「已激活」的相邻节点（邻居值必须 <= 当前值）
