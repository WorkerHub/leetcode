## 题目描述

给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 `true`。`#` 代表退格字符。

**注意**：如果对空文本输入退格字符，文本继续为空。

**示例 1:**
```
输入: s = "ab#c", t = "ad#c"
输出: true
解释: s 和 t 都会变成 "ac"。
```

**示例 2:**
```
输入: s = "ab##", t = "c#d#"
输出: true
解释: s 和 t 都会变成 ""。
```

**示例 3:**
```
输入: s = "a#c", t = "b"
输出: false
解释: s 会变成 "c"，但 t 仍然是 "b"。
```

**提示:**
- `1 <= s.length, t.length <= 200`
- `s` 和 `t` 只含有小写字母以及字符 `'#'`

**进阶：**
你能用 `O(n)` 的时间复杂度和 `O(1)` 的空间复杂度解决该问题吗？

## 解题思路

### 方法一：栈模拟
使用栈模拟退格操作。

### 方法二：双指针（进阶）
从后向前遍历，跳过被退格的字符。

## Python 代码实现

### 方法一：栈（推荐）⭐

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        def build(string):
            """使用栈模拟退格操作"""
            stack = []
            for char in string:
                if char != '#':
                    stack.append(char)
                elif stack:
                    stack.pop()
            return ''.join(stack)
        
        return build(s) == build(t)
```

### 方法二：双指针 O(1) 空间

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        def next_valid_char(string, index):
            """找到下一个有效字符的索引"""
            backspace = 0
            while index >= 0:
                if string[index] == '#':
                    backspace += 1
                elif backspace > 0:
                    backspace -= 1
                else:
                    return index
                index -= 1
            return -1
        
        i, j = len(s) - 1, len(t) - 1
        
        while i >= 0 or j >= 0:
            i = next_valid_char(s, i)
            j = next_valid_char(t, j)
            
            # 两个都到达末尾
            if i < 0 and j < 0:
                return True
            # 一个到达末尾，另一个没有
            if i < 0 or j < 0:
                return False
            # 字符不相等
            if s[i] != t[j]:
                return False
            
            i -= 1
            j -= 1
        
        return True
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

### 方法二：
- **时间复杂度**：O(n + m)
- **空间复杂度**：O(1)

## 关键点总结

1. **栈模拟**：简单直观
2. **双指针**：从后向前，跳过被删除的字符
3. **退格计数**：记录需要跳过的字符数

## 易错点

1. **空栈退格**：栈为空时不能 pop
2. **双指针边界**：索引可能为负
3. **同时到达末尾**：都为 -1 才相等
