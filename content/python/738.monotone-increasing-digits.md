## 题目描述

当且仅当每个相邻位数上的数字 `x` 和 `y` 满足 `x <= y` 时，我们称这个整数是**单调递增**的。

给定一个整数 `n`，返回 **小于或等于** `n` 的最大数字，且数字呈 **单调递增**。

**示例 1：**

```
输入：n = 10
输出：9
```

**示例 2：**

```
输入：n = 1332
输出：1299
```

**示例 3：**

```
输入：n = 332
输出：299
```

## 解题思路

**贪心策略：**
从左到右找到第一个下降的位置，将该位置-1，后面全部填9。

## Python 代码实现

```python
class Solution:
    def monotoneIncreasingDigits(self, n: int) -> int:
        s = list(str(n))
        i = 1
        
        # 找到第一个下降位置
        while i < len(s) and s[i - 1] <= s[i]:
            i += 1
        
        # 如果已经单调递增
        if i == len(s):
            return n
        
        # 向前找到需要-1的位置
        while i > 0 and s[i - 1] > s[i]:
            s[i - 1] = str(int(s[i - 1]) - 1)
            i -= 1
        
        # 后面全部填9
        for j in range(i + 1, len(s)):
            s[j] = '9'
        
        return int(''.join(s))
```

## 复杂度分析

- **时间复杂度：** O(log n)
- **空间复杂度：** O(log n)

## 关键点总结

1. **贪心思想**：尽可能保持高位
2. **向前回溯**：连续相等时要回溯
3. **后缀填9**：最大化结果
