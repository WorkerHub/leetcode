## 题目描述

给你一个整数数组 `nums`，如果 `nums` 是一个 **好** 数组，则返回 `true`，否则返回 `false`。

**好数组** 的定义：
- 存在一个正整数 `n` 使得 `nums` 是通过重排 `[1, n, n, n, ..., n]`（`n` 出现 `n` 次，1 出现 1 次）组成的，即包含 1 至 n 的所有整数，其中 n 出现了 n 次。

等价地：`nums` 排序后应为 `[1, n, n, ..., n]`（1 个 1，n 个 n）。

**示例 1：**
```
输入：nums = [2,1,3]
输出：false
```

**示例 2：**
```
输入：nums = [1,3,3,3]
输出：true
解释：n=3，[1,3,3,3] 是好数组
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`

## 解题思路

从数组长度推断 n：n 出现 n 次，加 1 个 1，总长度为 n+1，所以 `n = len(nums) - 1`。

验证：`nums` 排序后应为 `[1] + [n] * n`。

## Python 代码实现

### 方法一：计数验证（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def isGood(self, nums: List[int]) -> bool:
        n = len(nums) - 1  # 推断 n
        cnt = Counter(nums)
        # 必须：1 出现 1 次，n 出现 n 次，无其他元素
        return (cnt[1] == 1 and cnt[n] == n and
                len(cnt) == (2 if n != 1 else 1))
```

### 方法二：排序验证

```python
from typing import List

class Solution:
    def isGood(self, nums: List[int]) -> bool:
        n = len(nums) - 1
        return sorted(nums) == [1] + [n] * n
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(n)

## 关键点总结

1. 数组长度 = n + 1，所以 n = len(nums) - 1
2. 排序后必须是 `[1, n, n, ..., n]`
3. 注意 n=1 时 1 和 n 相同，数组为 `[1, 1]`

## 易错点

1. n=1 时特殊：`[1, 1]` 是好数组（1 出现 1 次，n=1 出现 1 次，但 1 == n）
2. 方法一中 `len(cnt) == 2` 但 n=1 时 len(cnt) == 1
