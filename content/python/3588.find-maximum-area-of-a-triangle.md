## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`。从矩阵中选择三个单元格，构成一个三角形，要求三个单元格中至少有两个在同一行或同一列，且三个单元格的横纵坐标两两不完全相同（即构成非退化三角形）。

三角形的面积 = (底 * 高) / 2。两个在同一行的点，底 = |col1 - col2|，高 = |row3 - row1|（第三个点到该行的行距）。

返回可以构成的三角形的最大面积乘以 2（即 底 * 高 的最大值）。若无法构成三角形返回 0。

**示例 1：**

```
输入：grid = [[1,2],[3,4]]
输出：4
解释：选 (0,0),(0,1),(1,0)：底=1（同行），高=1，面积*2=1。
     选 (0,0),(0,1),(1,1)：底=1，高=1，面积*2=1。
     最大底*高=4（见其他组合）。
```

**提示：**
- `1 <= m, n <= 1000`
- `1 <= grid[i][j] <= 10^6`

## 解题思路

对于三角形面积最大化，若底边在同一行，面积 = 底 * 高 / 2。要最大化 底 * 高：
- 底 = 同行两点列距，最大为 n-1（选最左和最右列）
- 高 = 第三点到该行的最大行距，即该行与顶行或底行的距离

贪心策略：
1. 对每一行，记录该行中最左列和最右列（列值最小和最大的位置）
2. 对每一列，记录该列中最上行和最下行（行值最小和最大的位置）
3. 枚举同行两点（列距最大），找不同行的第三点（行距最大）

实际上，贪心：对每行记录最小列和最大列，对每列记录最小行和最大行。枚举所有组合。

## Python 代码实现

### 方法一：贪心枚举行/列端点（推荐）

```python
from typing import List

class Solution:
    def maxArea(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 每行的最小列和最大列
        row_min_col = [n] * m
        row_max_col = [-1] * m
        # 每列的最小行和最大行
        col_min_row = [m] * n
        col_max_row = [-1] * n

        for r in range(m):
            for c in range(n):
                row_min_col[r] = min(row_min_col[r], c)
                row_max_col[r] = max(row_max_col[r], c)
                col_min_row[c] = min(col_min_row[c], r)
                col_max_row[c] = max(col_max_row[c], r)

        ans = 0

        # 枚举同行两点（底为列距），第三点在不同行
        for r in range(m):
            base = row_max_col[r] - row_min_col[r]  # 同行最大列距
            if base == 0:
                continue
            # 高 = 第三点到 r 行的最大行距
            # 最远行是 row 0 或 row m-1
            height = max(r, m - 1 - r)
            ans = max(ans, base * height)

        # 枚举同列两点（底为行距），第三点在不同列
        for c in range(n):
            base = col_max_row[c] - col_min_row[c]  # 同列最大行距
            if base == 0:
                continue
            height = max(c, n - 1 - c)
            ans = max(ans, base * height)

        return ans
```

### 方法二：哈希表记录行列范围

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxArea(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 每行有哪些列
        row_cols = defaultdict(list)
        col_rows = defaultdict(list)

        for r in range(m):
            for c in range(n):
                row_cols[r].append(c)
                col_rows[c].append(r)

        ans = 0

        for r in range(m):
            cols = row_cols[r]
            if len(cols) < 2:
                continue
            base = max(cols) - min(cols)
            # 所有其他行
            for r2 in range(m):
                if r2 != r:
                    height = abs(r2 - r)
                    ans = max(ans, base * height)

        # 同理枚举列
        for c in range(n):
            rows = col_rows[c]
            if len(rows) < 2:
                continue
            base = max(rows) - min(rows)
            for c2 in range(n):
                if c2 != c:
                    height = abs(c2 - c)
                    ans = max(ans, base * height)

        return ans
```

## 复杂度分析

- 时间复杂度：O(m*n)，方法一预处理后 O(m+n) 枚举
- 空间复杂度：O(m+n)，存储行列端点

## 关键点总结

1. 三角形底在同一行时，面积 = 底 * 高 / 2，最大化 底 * 高
2. 同行最大底 = 该行最右列 - 最左列
3. 最大高 = 第三点到该行的最大行距，即行 0 或行 m-1 处
4. 同理对列方向枚举

## 易错点

1. 面积乘以 2 避免浮点，返回 底 * 高 而非面积
2. 底为 0 时（只有一个不同列）不能构成三角形，跳过
3. 第三点可以在任意不同行/列的位置，取最远距离
