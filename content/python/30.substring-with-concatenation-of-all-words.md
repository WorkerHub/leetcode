## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`。`words` 中所有字符串长度相同。

`s` 中的串联子串是指一个包含 `words` 中所有字符串以任意顺序排列连接起来的子串。

返回所有串联子串在 `s` 中的开始索引。

**示例 1：**
```
输入：s = "barfoothefoobarman", words = ["foo","bar"]
输出：[0,9]
解释：
从索引 0 开始的子串是 "barfoo"，是 ["bar","foo"] 的一个排列
从索引 9 开始的子串是 "foobar"，是 ["foo","bar"] 的一个排列
```

**示例 2：**
```
输入：s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
输出：[]
```

**提示：**
- `1 <= s.length <= 10^4`
- `1 <= words.length <= 5000`
- `1 <= words[i].length <= 30`
- `words[i]` 和 `s` 由小写英文字母组成

## 解题思路

核心思想：滑动窗口 + 哈希表

关键观察：
1. 每个单词长度相同
2. 窗口大小固定：单词长度 × 单词数量
3. 用哈希表记录单词出现次数

## Python 代码实现

```python
from typing import List
from collections import Counter

class Solution:
    def findSubstring(self, s: str, words: List[str]) -> List[int]:
        if not s or not words:
            return []
        
        word_len = len(words[0])
        word_count = len(words)
        total_len = word_len * word_count
        
        # 统计 words 中每个单词的出现次数
        word_freq = Counter(words)
        result = []
        
        # 遍历每个可能的起始位置
        for i in range(len(s) - total_len + 1):
            # 提取子串并分割成单词
            seen = {}
            j = 0
            while j < word_count:
                word_start = i + j * word_len
                word = s[word_start:word_start + word_len]
                
                if word in word_freq:
                    seen[word] = seen.get(word, 0) + 1
                    if seen[word] > word_freq[word]:
                        break
                else:
                    break
                j += 1
            
            # 所有单词都匹配
            if j == word_count:
                result.append(i)
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n × m)，n 为字符串长度，m 为单词数量
- 空间复杂度：O(m)

## 关键点总结

1. **滑动窗口**：固定大小的窗口
2. **哈希表**：记录单词频率
3. **单词分割**：按固定长度分割

## 易错点

1. **边界检查**：窗口是否越界
2. **频率匹配**：单词出现次数要完全匹配
