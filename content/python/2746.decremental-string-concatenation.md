## 题目描述

给你一个下标从 **0** 开始的字符串数组 `words`，初始字符串 `str0 = words[0]`。

对 `i` 从 1 到 n-1，依次执行：让 `stri` 等于将 `stri-1` 和 `words[i]` 合并的字符串，合并时，若 `stri-1` 的末尾与 `words[i]` 的开头相同，则重叠的那个字符只保留一次。

返回 `strn-1` 的最小可能长度。

**示例 1：**
```
输入：words = ["aa","ab","bc"]
输出：4
解释："aa" + "ab" = "aab"（共享'a'），"aab" + "bc" = "aabc"（共享'b'），长度 4
```

**示例 2：**
```
输入：words = ["ab","b"]
输出：2
解释："ab" + "b" = "ab"（共享'b'），长度 2
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 1000`

## 解题思路

**DP**：定义 `dp[i][a][b]` = 处理前 `i+1` 个单词时，合并结果的最短长度，且第 `i` 个单词的开头字符为 `a`，末尾字符为 `b`。

但每个单词开头和末尾固定，所以 `dp[i]` 只需记录当前字符串的末尾字符（开头从第 0 个单词开始传递）。

实际上关键是：每次拼接是否能在末尾和下一个单词开头共享一个字符。

更简化：`dp[(first, last)]` = 已拼接字符串的最短长度（`first` 是第一个字符，`last` 是最后一个字符）。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def minimizeConcatenatedLength(self, words: List[str]) -> int:
        # dp[(first, last)] = 以 first 开头、last 结尾的最短拼接长度
        # 初始：第一个单词
        w0 = words[0]
        dp = {(w0[0], w0[-1]): len(w0)}

        for i in range(1, len(words)):
            w = words[i]
            wf, wl = w[0], w[-1]
            wlen = len(w)
            new_dp = {}

            for (f, l), length in dp.items():
                # 拼接 w 到末尾
                # 若 l == wf，末尾与 w 开头重叠，长度 +wlen-1
                # 否则长度 +wlen
                overlap = 1 if l == wf else 0
                new_len = length + wlen - overlap
                key = (f, wl)
                if key not in new_dp or new_dp[key] > new_len:
                    new_dp[key] = new_len

        return min(new_dp.values())
```

## 复杂度分析

- 时间复杂度：O(n * 26^2)，每步最多 676 个状态
- 空间复杂度：O(26^2)

## 关键点总结

1. 状态仅需记录（开头字符，末尾字符），不需要保存完整字符串
2. 拼接时若末尾 == 下个单词开头，长度减 1

## 易错点

1. 开头字符从整个拼接字符串的开头算，不是当前单词的开头
2. 每步状态数不超过 26*26=676，不会爆炸
