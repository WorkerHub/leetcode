## 题目描述

给你一个大小为 `n` 下标从 **0** 开始的整数数组 `nums` 和一个正整数 `k`。

对于 `k <= i < n - k` 之间的一个下标 `i`，如果它的 **前** `k` 个元素 **非递增** 且 **后** `k` 个元素 **非递减**，则认为下标 `i` 是 **好下标**。

换言之，需要 `nums[i - 1] >= nums[i - 2] >= ... >= nums[i - k]` 以及 `nums[i + 1] <= nums[i + 2] <= ... <= nums[i + k]`。

返回一个整数数组，该数组按 **递增顺序** 包含所有好下标。

**示例 1：**
```
输入：nums = [2,1,1,1,3,4,1], k = 2
输出：[2,3]
解释：下标 2：前 2 个元素 [2,1] 非递增，后 2 个元素 [1,3] 非递减，是好下标。
```

**示例 2：**
```
输入：nums = [2,1,1,2], k = 2
输出：[]
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= k <= n / 2`

## 解题思路

**预计算前缀数组：**
- `dec[i]`：从 `i` 向左连续非递增的长度（`nums[i] <= nums[i-1]` 时延伸）
- `inc[i]`：从 `i` 向右连续非递减的长度（`nums[i] <= nums[i+1]` 时延伸）

对于下标 `i`（`k <= i < n-k`）：
- 若 `dec[i-1] >= k`（位置 `i-1` 向左有 k 个非递增）且 `inc[i+1] >= k`（位置 `i+1` 向右有 k 个非递减），则 `i` 是好下标

## 代码实现

### 方法一：预计算非递增/非递减长度（推荐）

```python
from typing import List

class Solution:
    def goodIndices(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        # dec[i] = 以 i 结尾的非递增子数组的最大长度
        dec = [1] * n
        for i in range(1, n):
            if nums[i] <= nums[i - 1]:
                dec[i] = dec[i - 1] + 1

        # inc[i] = 以 i 开头的非递减子数组的最大长度
        inc = [1] * n
        for i in range(n - 2, -1, -1):
            if nums[i] <= nums[i + 1]:
                inc[i] = inc[i + 1] + 1

        # 找好下标
        ans = []
        for i in range(k, n - k):
            # i 前面 k 个非递增：需要 dec[i-1] >= k
            # i 后面 k 个非递减：需要 inc[i+1] >= k
            if dec[i - 1] >= k and inc[i + 1] >= k:
                ans.append(i)

        return ans
```

### 方法二：暴力检查（对比学习，超时）

```python
from typing import List

class Solution:
    def goodIndices(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        ans = []

        for i in range(k, n - k):
            # 检查前 k 个是否非递增
            prev_ok = all(nums[i - j] <= nums[i - j - 1] for j in range(k - 1))
            # 检查后 k 个是否非递减
            next_ok = all(nums[i + j] <= nums[i + j + 1] for j in range(1, k))
            if prev_ok and next_ok:
                ans.append(i)

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 预计算 | O(n) | O(n) |
| 暴力检查 | O(n * k) | O(1) |

## 关键点总结

1. 预计算 `dec[i]`（以 i 结尾的非递增长度）和 `inc[i]`（以 i 开头的非递减长度）
2. 好下标 i 的条件：`dec[i-1] >= k` 且 `inc[i+1] >= k`
3. 两次 O(n) 遍历，完成预计算

## 易错点

- 检查的是 `dec[i-1]` 而非 `dec[i]`（i 本身不算前 k 个）
- 非递增是 `<=`（允许相等），非递减也是 `<=`
