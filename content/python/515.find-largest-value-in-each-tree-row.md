## 题目描述

给定一棵二叉树的根节点 `root`，请找出每一层的最大值。

**示例 1：**
```
输入：root = [1,3,2,5,3,null,9]
输出：[1,3,9]
解释：
          1
         / \
        3   2
       / \   \
      5   3   9
```

**示例 2：**
```
输入：root = [1,2,3]
输出：[1,3]
```

**提示：**
- 树中节点数目在范围 `[0, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 解题思路

这道题要求找每层的最大值，典型的层序遍历问题。

### 解法对比：
- **BFS**：层序遍历，每层记录最大值
- **DFS**：深度优先，记录每层的最大值

## Python 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```python
from typing import List, Optional
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        """
        BFS 层序遍历
        时间复杂度：O(n)，空间复杂度：O(w)，w 是最大宽度
        """
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            max_val = float('-inf')  # 每层的最大值
            
            for _ in range(level_size):
                node = queue.popleft()
                max_val = max(max_val, node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            result.append(max_val)
        
        return result
```

### 方法二：DFS（递归）

```python
class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        """
        DFS 深度优先搜索
        时间复杂度：O(n)，空间复杂度：O(h)
        """
        if not root:
            return []
        
        result = []
        
        def dfs(node, depth):
            if not node:
                return
            
            # 如果是新的一层，添加当前值
            if depth == len(result):
                result.append(node.val)
            else:
                # 更新当前层的最大值
                result[depth] = max(result[depth], node.val)
            
            # 递归左右子树
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        
        dfs(root, 0)
        return result
```

### 方法三：使用 max() 和列表推导

```python
class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        """
        简化的 BFS
        时间复杂度：O(n)，空间复杂度：O(w)
        """
        if not root:
            return []
        
        result = []
        queue = [root]
        
        while queue:
            # 当前层的所有节点值
            result.append(max(node.val for node in queue))
            
            # 生成下一层的节点列表
            queue = [child for node in queue 
                     for child in (node.left, node.right) if child]
        
        return result
```

## 复杂度分析

### BFS：
- **时间复杂度**：O(n)
- **空间复杂度**：O(w)，w 是树的最大宽度

### DFS：
- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 是树的高度

## 关键点总结

1. **BFS 模板**：使用队列，按层遍历
2. **DFS 技巧**：用深度索引直接访问结果数组
3. **初始值**：每层最大值初始化为 `-inf`
4. **空树处理**：返回空列表
5. **Python 技巧**：列表推导简化代码

## 易错点

1. **空树**：要特判 root is None
2. **负数**：初始化为 `-inf` 而非 0
3. **深度索引**：DFS 中深度从 0 开始
4. **队列大小**：BFS 中要先记录 len(queue)
