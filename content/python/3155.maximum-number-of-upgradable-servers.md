## 题目描述

给你四个整数数组 `count`、`upgrade`、`sell`、`money`，长度均为 `n`，分别表示 n 个数据中心的信息：
- `count[i]`：第 i 个数据中心的服务器数量
- `upgrade[i]`：升级一台服务器的花费
- `sell[i]`：卖出一台服务器获得的收益
- `money[i]`：初始资金

对每个数据中心，可以卖出若干服务器换取资金，然后用资金升级其他服务器，目标是使升级服务器数量最多。

返回数组 `answer`，`answer[i]` 为第 i 个数据中心最多能升级的服务器数量。

**提示：**
- `1 <= n <= 10^5`

## 解题思路

对每个数据中心，设卖出 s 台服务器，剩余 count[i] - s 台可以升级，资金 = money[i] + s * sell[i]，可升级数 = min(count[i] - s, (money[i] + s * sell[i]) // upgrade[i])。

二分 s 或直接推导：要最大化升级数，设升级数为 u，则需要 u * upgrade[i] <= money[i] + s * sell[i]，且 s + u <= count[i]。

直接枚举 u，或二分 u。

## Python 代码实现

### 方法一：二分 u（推荐）

```python
from typing import List

class Solution:
    def maxUpgradableServers(
        self,
        count: List[int],
        upgrade: List[int],
        sell: List[int],
        money: List[int]
    ) -> List[int]:
        ans = []
        for i in range(len(count)):
            c, u, s, m = count[i], upgrade[i], sell[i], money[i]
            # 二分能升级的服务器数量
            lo, hi = 0, c
            while lo < hi:
                mid = (lo + hi + 1) // 2
                # 升级 mid 台，需要卖出 sell_num 台
                # cost = mid * u，资金 m + sell_num * s >= cost
                # sell_num = max(0, ceil((mid * u - m) / s)) if s > 0
                cost = mid * u
                if cost <= m:
                    sell_num = 0
                else:
                    sell_num = (cost - m + s - 1) // s  # 向上取整
                if sell_num + mid <= c:
                    lo = mid
                else:
                    hi = mid - 1
            ans.append(lo)
        return ans
```

### 方法二：数学直接计算

```python
from typing import List

class Solution:
    def maxUpgradableServers(
        self,
        count: List[int],
        upgrade: List[int],
        sell: List[int],
        money: List[int]
    ) -> List[int]:
        ans = []
        for c, u, s, m in zip(count, upgrade, sell, money):
            # 设升级 x 台：x * u <= m + (c - x) * s (卖剩余全部)
            # x * u <= m + c * s - x * s
            # x * (u + s) <= m + c * s
            # x <= (m + c * s) / (u + s)
            x = min(c, (m + c * s) // (u + s))
            ans.append(x)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法二），O(n log c)（方法一）
- 空间复杂度：O(1)

## 关键点总结

1. 卖出最多台后用所有资金升级，则最大升级数 = min(c, (m + c*s) // (u+s))
2. 设卖出 count - x 台，升级 x 台

## 易错点

1. 注意整数除法向下取整
2. 答案不超过 count[i]
