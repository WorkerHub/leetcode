## 题目描述

给你一个二维整数数组 `items`，其中 `items[i] = [price_i, weight_i]`，表示第 `i` 件物品的价格和重量。同时给你一个整数 `capacity` 表示背包容量。

你可以将每件物品 **整体** 或 **部分** 放入背包。放入部分时，若放入重量 `w`，则获得价格 `price_i * w / weight_i`。

返回可以装入背包的 **最大总价格**。若无法装满，返回放入所有物品的最大总价格（即不要求恰好装满）。实际上每件物品 **可以** 部分装入，返回能达到的最大总价格（精确到小数，但实际上返回 double 或按要求取整）。

**示例 1：**

```
输入：items = [[1,2],[5,7],[3,6]], capacity = 8
输出：10.666...
```

**示例 2：**

```
输入：items = [[10,2],[5,4]], capacity = 2
输出：10
```

**提示：**

- `1 <= items.length <= 10^5`
- `items[i].length == 2`
- `1 <= price_i, weight_i <= 10^4`
- `1 <= capacity <= 10^9`

## 解题思路

**贪心**：经典的分数背包问题（Fractional Knapsack）。

按单位价格（price / weight）降序排列物品，依次尽量多地放入，最后一件物品可以部分放入。

## Python 代码实现

### 方法一：贪心排序（推荐）

```python
from typing import List

class Solution:
    def maxPrice(self, items: List[List[int]], capacity: int) -> float:
        # 按单位价格降序排列
        items.sort(key=lambda x: x[0] / x[1], reverse=True)

        total_price = 0.0
        remaining = capacity

        for price, weight in items:
            if remaining <= 0:
                break
            if weight <= remaining:
                # 整件放入
                total_price += price
                remaining -= weight
            else:
                # 部分放入
                total_price += price * remaining / weight
                remaining = 0

        return total_price
```

### 方法二：更简洁的版本

```python
from typing import List

class Solution:
    def maxPrice(self, items: List[List[int]], capacity: int) -> float:
        # 单位价格降序
        items.sort(key=lambda x: -x[0] / x[1])

        ans = 0.0
        cap = capacity
        for p, w in items:
            if cap == 0:
                break
            take = min(w, cap)
            ans += p * take / w
            cap -= take

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（排序可原地）

## 关键点总结

1. 分数背包贪心：优先选单位价格最高的物品
2. 最后一件物品可以按比例部分放入
3. 排序后线性扫描，代码简洁

## 易错点

1. 背包容量可以不装满（物品总重量可能 < capacity），此时全部放入
2. 部分放入时，价格按重量比例计算：`price * take / weight`
3. 不是经典 0/1 背包，这里可以分割物品
