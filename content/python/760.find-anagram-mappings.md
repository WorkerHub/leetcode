## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，其中 `nums2` 是 `nums1` 的一个变位词（anagram）。

变位词是指两个数组包含相同的元素，但顺序可能不同。

找到一个索引映射数组 `P`，使得 `nums1[i] = nums2[P[i]]`，对于所有 `0 <= i < nums1.length`。

返回数组 `P`。

**示例 1:**
```
输入: nums1 = [12,28,46,32,50], nums2 = [50,12,32,46,28]
输出: [1,4,3,2,0]
解释: P[0] = 1，因为 nums1[0] = 12 对应 nums2[1] = 12
      P[1] = 4，因为 nums1[1] = 28 对应 nums2[4] = 28
      P[2] = 3，因为 nums1[2] = 46 对应 nums2[3] = 46
      P[3] = 2，因为 nums1[3] = 32 对应 nums2[2] = 32
      P[4] = 0，因为 nums1[4] = 50 对应 nums2[0] = 50
```

**示例 2:**
```
输入: nums1 = [84,46], nums2 = [46,84]
输出: [1,0]
```

**提示:**
- `nums1.length == nums2.length`
- `1 <= nums1.length <= 100`
- `0 <= nums1[i], nums2[i] <= 10^5`

## 解题思路

这是一道简单的哈希表应用题。

**核心思想：**
1. 构建 nums2 的值到索引的映射
2. 对于 nums1 中的每个元素，在映射中查找对应的索引

**注意：** 如果有重复元素，需要特殊处理。

## Python 代码实现

### 方法一：哈希表（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def anagramMappings(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 构建 nums2 的值到索引列表的映射
        # 使用列表处理重复值
        index_map = defaultdict(list)
        for i, num in enumerate(nums2):
            index_map[num].append(i)
        
        # 对于每个 nums1 中的元素，找到对应的索引
        result = []
        for num in nums1:
            # 取出对应值的一个索引并移除（处理重复值）
            result.append(index_map[num].pop())
        
        return result
```

### 方法二：简单哈希表（无重复值时）

```python
class Solution:
    def anagramMappings(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 构建 nums2 的值到索引的映射
        index_map = {num: i for i, num in enumerate(nums2)}
        
        # 查找每个 nums1 中元素对应的索引
        return [index_map[num] for num in nums1]
```

### 方法三：使用 enumerate

```python
class Solution:
    def anagramMappings(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 构建反向索引
        index_map = {v: i for i, v in enumerate(nums2)}
        
        # 生成结果
        result = []
        for num in nums1:
            result.append(index_map[num])
        
        return result
```

### 方法四:处理重复值的完整版本

```python
class Solution:
    def anagramMappings(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 使用字典存储每个值在 nums2 中的所有索引
        value_to_indices = {}
        
        for i, num in enumerate(nums2):
            if num not in value_to_indices:
                value_to_indices[num] = []
            value_to_indices[num].append(i)
        
        # 为了处理重复值，使用指针记录当前使用到第几个索引
        used = {num: 0 for num in value_to_indices}
        
        result = []
        for num in nums1:
            # 获取当前应该使用的索引
            idx = used[num]
            result.append(value_to_indices[num][idx])
            # 移动指针
            used[num] += 1
        
        return result
```

### 方法五：一行解法

```python
class Solution:
    def anagramMappings(self, nums1: List[int], nums2: List[int]) -> List[int]:
        return [nums2.index(num) for num in nums1]
```

## 复杂度分析

**方法一：哈希表（带列表）**
- **时间复杂度：** O(n)，其中 n 是数组长度
- **空间复杂度：** O(n)，哈希表空间

**方法二：简单哈希表**
- **时间复杂度：** O(n)
- **空间复杂度：** O(n)

**方法五：一行解法**
- **时间复杂度：** O(n^2)，每次 index 调用是 O(n)
- **空间复杂度：** O(1)，不计结果数组

## 关键点总结

1. **哈希表应用：** 使用哈希表快速查找
2. **重复值处理：** 使用列表或指针处理重复值
3. **索引映射：** 理解题目要求的映射关系
4. **时间优化：** 预处理映射比每次查找更高效
5. **Python 特性：** 利用字典推导式和列表推导式简化代码

## 易错点

1. **重复值：** 如果数组有重复值，简单映射可能不够
2. **索引顺序：** 要返回的是 nums2 中的索引，不是 nums1
3. **边界情况：** 空数组、单元素数组要正确处理
4. **性能问题：** 使用 index 方法会导致 O(n^2) 复杂度
5. **映射方向：** 要建立 nums2 的映射，不是 nums1
