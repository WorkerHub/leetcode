## 题目描述

给你两个字符串 `word1` 和 `word2`，你需要执行恰好一次操作：选择 `word1` 的某个下标 `i` 和 `word2` 的某个下标 `j`，交换 `word1[i]` 和 `word2[j]`。

如果操作后 `word1` 和 `word2` 中不同字符的数目相同，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：word1 = "ac", word2 = "b"
输出：false
```

**示例 2：**

```
输入：word1 = "abcc", word2 = "aab"
输出：true
解释：交换 word1[2]='c' 和 word2[0]='a'，word1 变为 "abac"（3种），word2 变为 "cab"（3种）。
```

**提示：**

- `1 <= word1.length, word2.length <= 10^5`
- `word1` 和 `word2` 只包含小写英文字母

## 解题思路

枚举交换的字符对 (c1, c2)，即从 word1 中取出字符 c1，放入 word2，同时将 word2 的 c2 放入 word1。

对每对 (c1, c2)（26*26 种），计算交换后两个字符串的不同字符数，检查是否相等。

## Python 代码实现

### 方法一：枚举 + 频次哈希（推荐）

```python
from collections import Counter

class Solution:
    def isItPossible(self, word1: str, word2: str) -> bool:
        cnt1 = Counter(word1)
        cnt2 = Counter(word2)

        for c1 in list(cnt1.keys()):
            for c2 in list(cnt2.keys()):
                # 模拟交换 word1 中的 c1 和 word2 中的 c2
                # word1 减少 c1，增加 c2
                # word2 减少 c2，增加 c1
                cnt1[c1] -= 1
                if cnt1[c1] == 0:
                    del cnt1[c1]
                cnt1[c2] = cnt1.get(c2, 0) + 1

                cnt2[c2] -= 1
                if cnt2[c2] == 0:
                    del cnt2[c2]
                cnt2[c1] = cnt2.get(c1, 0) + 1

                if len(cnt1) == len(cnt2):
                    return True

                # 恢复
                cnt1[c2] -= 1
                if cnt1[c2] == 0:
                    del cnt1[c2]
                cnt1[c1] = cnt1.get(c1, 0) + 1

                cnt2[c1] -= 1
                if cnt2[c1] == 0:
                    del cnt2[c1]
                cnt2[c2] = cnt2.get(c2, 0) + 1

        return False
```

### 方法二：直接枚举 26*26 种可能

```python
from collections import Counter

class Solution:
    def isItPossible(self, word1: str, word2: str) -> bool:
        freq1 = Counter(word1)
        freq2 = Counter(word2)
        d1 = len(freq1)
        d2 = len(freq2)

        for c1 in 'abcdefghijklmnopqrstuvwxyz':
            if c1 not in freq1:
                continue
            for c2 in 'abcdefghijklmnopqrstuvwxyz':
                if c2 not in freq2:
                    continue
                if c1 == c2:
                    # 交换相同字符，不同字符数不变
                    if d1 == d2:
                        return True
                    continue

                # 计算交换后 word1 的不同字符数
                new_d1 = d1
                if freq1[c1] == 1:
                    new_d1 -= 1  # c1 从 word1 消失
                if c2 not in freq1:
                    new_d1 += 1  # c2 新加入 word1

                # 计算交换后 word2 的不同字符数
                new_d2 = d2
                if freq2[c2] == 1:
                    new_d2 -= 1  # c2 从 word2 消失
                if c1 not in freq2:
                    new_d2 += 1  # c1 新加入 word2

                if new_d1 == new_d2:
                    return True

        return False
```

## 复杂度分析

- 时间复杂度：O(|word1| + |word2| + 26²)，枚举最多 676 对字符
- 空间复杂度：O(26)，频率计数器

## 关键点总结

1. 枚举交换的字符对 (c1, c2)，共 26*26 = 676 种
2. 当 c1 == c2 时，两个字符串的不同字符数不变
3. 交换后不同字符数的变化只取决于 c1/c2 在各自字符串中的出现次数

## 易错点

1. c1 == c2 的情况需单独处理（计数不变）
2. 交换后若 c1 在 word2 原来就存在，则 word2 的不同字符数不增加
3. 枚举的是字符对，不是下标对，26*26 种足够
