## 题目描述

给你一个**二进制字符串** `s`。

每次操作：选择字符串中**任意**的 `'10'` 子串，将其变为 `'01'`（即把 `'1'` 向右移动一位）。

返回可以执行操作的**最大次数**。

**示例 1：**
```
输入：s = "1001101"
输出：4
```

**示例 2：**
```
输入：s = "00111"
输出：0
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 `'0'` 或 `'1'`

## 解题思路

贪心：每个 `'1'` 最终会移到其右侧的某个位置。对于每个 `'1'`，它能移动的步数等于其右侧（在下一个 `'1'` 之前）的 `'0'` 的个数。

关键：每次遇到一个 `'0'`，前面所有未被阻挡的 `'1'` 都可以向右移动一步，贡献等于当前 `'1'` 的数量。

具体做法：从左向右遍历，维护当前遇到的 `'1'` 的数量，每遇到 `'0'` 就加上当前 `'1'` 的数量。

## Python 代码实现

### 方法一：贪心计数（推荐）

```python
class Solution:
    def maxOperations(self, s: str) -> int:
        ans = 0
        ones = 0  # 当前已见到的 '1' 数量
        for c in s:
            if c == '1':
                ones += 1
            else:
                # 遇到 '0'，前面所有 '1' 都可以向右移动一次
                ans += ones
        return ans
```

### 方法二：分段计数

```python
class Solution:
    def maxOperations(self, s: str) -> int:
        # 将 '1' 的个数 * 该 '1' 后面的 '0' 段数
        ans = 0
        i = 0
        n = len(s)
        while i < n:
            if s[i] == '1':
                # 统计连续 '1' 的数量
                cnt1 = 0
                while i < n and s[i] == '1':
                    cnt1 += 1
                    i += 1
                # 统计后面 '0' 的数量
                cnt0 = 0
                while i < n and s[i] == '0':
                    cnt0 += 1
                    i += 1
                ans += cnt1 * cnt0
            else:
                i += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每遇到一个 `'0'`，前面所有 `'1'` 各向右移动一步，共 `ones` 次操作
2. 等价于：每个 `'1'` 移动的步数 = 其后面（直到下一个 `'1'`）的 `'0'` 数量
3. 分段法：每组连续 `'1'`（共 `cnt1` 个）后面跟 `cnt0` 个 `'0'`，贡献 `cnt1 * cnt0`

## 易错点

1. 方法一中，`'1'` 之间的 `'0'` 不影响已记录的 `ones`，因为 `'1'` 只能向右移动
2. 注意是"每次"操作只移动一步，但最终统计总操作次数
