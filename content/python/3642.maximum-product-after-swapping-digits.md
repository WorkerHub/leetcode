## 题目描述

给你两个非负整数 `num1` 和 `num2`，你可以交换 `num1` 的某个数位和 `num2` 的某个数位（最多一次），使得 `num1 * num2` 最大化。

返回最大乘积。

**示例 1：**

```
输入：num1 = 123, num2 = 456
输出：624
解释：交换 num1 的 1 和 num2 的 4，得到 num1=423, num2=156，乘积=66088
或交换 num1 的 3 和 num2 的 6，得到 num1=126, num2=453，乘积=57078
最大是不交换时：123*456=56088，或者...需要枚举
```

**示例 2：**

```
输入：num1 = 11, num2 = 99
输出：891
解释：交换 num1 的 1 和 num2 的 9，得到 91*19=1729... 需要找最优
```

**提示：**

- `1 <= num1, num2 <= 10^9`

## 解题思路

枚举所有可能的交换（num1 的每位和 num2 的每位），计算每种交换后的乘积，取最大值。也可以不交换（0次操作）。

由于每个数最多 10 位，总共最多 100 种交换，直接枚举即可。

## Python 代码实现

### 方法一：枚举所有交换（推荐）

```python
class Solution:
    def maxProduct(self, num1: int, num2: int) -> int:
        s1, s2 = list(str(num1)), list(str(num2))
        ans = num1 * num2  # 不交换的情况

        for i in range(len(s1)):
            for j in range(len(s2)):
                # 交换 s1[i] 和 s2[j]
                s1[i], s2[j] = s2[j], s1[i]
                product = int(''.join(s1)) * int(''.join(s2))
                ans = max(ans, product)
                # 换回来
                s1[i], s2[j] = s2[j], s1[i]

        return ans
```

### 方法二：贪心分析

```python
class Solution:
    def maxProduct(self, num1: int, num2: int) -> int:
        # 贪心：将 num1 最小位换成 num2 最大位（或反之）
        # 但贪心不总是最优，还是枚举更安全
        s1, s2 = list(str(num1)), list(str(num2))
        ans = num1 * num2

        for i in range(len(s1)):
            for j in range(len(s2)):
                s1[i], s2[j] = s2[j], s1[i]
                ans = max(ans, int(''.join(s1)) * int(''.join(s2)))
                s1[i], s2[j] = s2[j], s1[i]

        return ans
```

## 复杂度分析

- 时间复杂度：O(d1 * d2 * (d1 + d2))，d1、d2 为位数，最多 10*10*20 = 2000
- 空间复杂度：O(d1 + d2)

## 关键点总结

1. 枚举所有交换位置，O(100) 次
2. 不交换也是合法操作
3. 字符串操作便于按位处理

## 易错点

1. 注意恢复现场（交换后要换回来）
2. 包含不交换的情况（初始化为 num1 * num2）
3. 前导零问题：交换后可能产生前导零（题目若不允许需特判）
