## 题目描述

给你一个 **0** 下标的字符串 `s`，将 `s` 中的所有 **元音字母** 按 **非递减** 顺序排序，辅音字母保持原位，返回结果字符串。

元音字母：`a, e, i, o, u, A, E, I, O, U`

**示例 1：**
```
输入：s = "lYmpH"
输出："lYmpH"
解释：没有元音字母，不变
```

**示例 2：**
```
输入：s = "lEEtcOde"
输出："lEEtcOde"
解释：元音 E,E,O,e 排序后仍然是 E,E,O,e（非递减），结果不变
Wait: 按 ASCII 排序 E,E,O,e → E,E,O,e，"lEEtcOde" 不变
```

**示例 3：**
```
输入：s = "IceCreAm"
输出："AceCreIm"
```

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

提取所有元音的位置和值，对值排序后填回对应位置。

## Python 代码实现

### 方法一：提取排序填回（推荐）

```python
class Solution:
    def sortVowels(self, s: str) -> str:
        vowels = set('aeiouAEIOU')
        chars = list(s)
        # 找所有元音的位置和值
        positions = [i for i, c in enumerate(chars) if c in vowels]
        values = sorted(chars[i] for i in positions)  # 按 ASCII 升序
        # 填回排序后的元音
        for i, pos in enumerate(positions):
            chars[pos] = values[i]
        return ''.join(chars)
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序元音）
- 空间复杂度：O(n)

## 关键点总结

1. 提取元音，排序，按原位置填回
2. 排序按 ASCII 顺序（大写字母 < 小写字母）

## 易错点

1. 大小写字母分别处理（`'A' < 'a'` 在 ASCII 中）
2. 辅音字母位置不变
