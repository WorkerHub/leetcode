## 题目描述

给你一个正整数 `n`，请你找出符合条件的最小整数，其由重新排列 `n` 中存在的每位数字组成，并且其值大于 `n`。如果不存在这样的正整数，则返回 `-1`。

注意，返回的整数应当是一个 **32 位整数**，如果存在满足题意的答案，但不是 32 位整数，同样返回 `-1`。

**示例 1：**
```
输入：n = 12
输出：21
```

**示例 2：**
```
输入：n = 21
输出：-1
```

**示例 3：**
```
输入：n = 12443322
输出：13222344
```

**提示：**
- `1 <= n <= 2^31 - 1`

## 解题思路

这道题本质上是求**下一个排列**（Next Permutation），与 LeetCode 31 题相同。

核心思想：
1. 将数字转换为数组（字符串）
2. 从右向左找到第一个递减的位置 i（即 `nums[i] < nums[i+1]`）
3. 从右向左找到第一个大于 `nums[i]` 的位置 j
4. 交换 `nums[i]` 和 `nums[j]`
5. 将 i 后面的部分反转（变为升序）
6. 检查结果是否溢出

算法步骤：
1. **找到交换位置**：从右向左找第一个 `nums[i] < nums[i+1]`
   - 如果找不到，说明整个数字是降序，不存在下一个更大的排列
2. **找到交换对象**：从右向左找第一个 `nums[j] > nums[i]`
3. **交换**：交换 `nums[i]` 和 `nums[j]`
4. **反转**：反转 i+1 到末尾的部分
5. **验证**：检查结果是否在 32 位整数范围内

## Python 代码实现

### 方法一：下一个排列算法（推荐）⭐

```python
class Solution:
    def nextGreaterElement(self, n: int) -> int:
        """
        下一个排列算法
        
        时间复杂度：O(log n)，数字的位数
        空间复杂度：O(log n)，转换为列表
        """
        # 将数字转换为字符数组
        digits = list(str(n))
        length = len(digits)
        
        # 步骤1：从右向左找到第一个递减的位置 i
        i = length - 2
        while i >= 0 and digits[i] >= digits[i + 1]:
            i -= 1
        
        # 如果找不到，说明是降序排列，返回 -1
        if i == -1:
            return -1
        
        # 步骤2：从右向左找到第一个大于 digits[i] 的位置 j
        j = length - 1
        while j > i and digits[j] <= digits[i]:
            j -= 1
        
        # 步骤3：交换 digits[i] 和 digits[j]
        digits[i], digits[j] = digits[j], digits[i]
        
        # 步骤4：反转 i+1 到末尾的部分
        digits[i + 1:] = digits[i + 1:][::-1]
        
        # 转换回整数
        result = int(''.join(digits))
        
        # 步骤5：检查是否在 32 位整数范围内
        if result > 2**31 - 1:
            return -1
        
        return result
```

### 方法二：使用双指针反转

```python
class Solution:
    def nextGreaterElement(self, n: int) -> int:
        """
        使用双指针进行反转
        
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        digits = list(str(n))
        n_len = len(digits)
        
        # 找到第一个递减位置
        i = n_len - 2
        while i >= 0 and digits[i] >= digits[i + 1]:
            i -= 1
        
        if i == -1:
            return -1
        
        # 找到要交换的位置
        j = n_len - 1
        while digits[j] <= digits[i]:
            j -= 1
        
        # 交换
        digits[i], digits[j] = digits[j], digits[i]
        
        # 使用双指针反转 i+1 到末尾
        left, right = i + 1, n_len - 1
        while left < right:
            digits[left], digits[right] = digits[right], digits[left]
            left += 1
            right -= 1
        
        result = int(''.join(digits))
        
        return result if result <= 2**31 - 1 else -1
```

### 方法三：简洁版本

```python
class Solution:
    def nextGreaterElement(self, n: int) -> int:
        """
        简洁版本
        
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        s = list(str(n))
        
        # 从右向左找第一个递减位置
        i = len(s) - 2
        while i >= 0 and s[i] >= s[i + 1]:
            i -= 1
        
        if i < 0:
            return -1
        
        # 从右向左找第一个大于 s[i] 的位置
        j = len(s) - 1
        while s[j] <= s[i]:
            j -= 1
        
        # 交换并反转
        s[i], s[j] = s[j], s[i]
        s[i + 1:] = reversed(s[i + 1:])
        
        res = int(''.join(s))
        return res if res < 2**31 else -1
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(d)，其中 d 是数字的位数（d = log₁₀n）
  - 找递减位置：O(d)
  - 找交换位置：O(d)
  - 反转：O(d)
- **空间复杂度**：O(d)，存储数字的字符数组

## 关键点总结

1. **下一个排列算法**：这是一个经典算法，需要熟练掌握
2. **从右向左**：找递减位置和交换位置都是从右向左
3. **反转操作**：交换后需要反转后半部分，使其变为最小
4. **边界情况**：降序排列时返回 -1
5. **溢出检查**：结果需要在 32 位整数范围内

## 易错点

1. **比较符号**：
   - 找递减位置：`digits[i] >= digits[i+1]`（注意是 >=）
   - 找交换位置：`digits[j] <= digits[i]`（注意是 <=）
2. **循环条件**：
   - 第一个循环：`i >= 0`
   - 第二个循环：`j > i`
3. **降序判断**：
   - 当 i == -1 时，说明整个数字是降序
4. **反转范围**：
   - 只反转 `i+1` 到末尾，不包括 i
5. **溢出处理**：
   - 需要检查 `result <= 2^31 - 1`
   - 不要忘记这个边界检查
