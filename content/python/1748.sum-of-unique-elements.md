## 题目描述

给你一个整数数组 `nums`。数组中唯一元素是那些只出现**恰好一次**的元素。

请你返回 `nums` 中唯一元素的**和**。

**示例 1：**
```
输入：nums = [1,2,3,2]
输出：4
解释：唯一元素为 1 和 3，和为 4
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

用哈希表（Counter）统计每个元素的出现次数，将出现次数为 1 的元素求和。

## 代码实现

### 方法一：Counter 统计（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def sumOfUnique(self, nums: List[int]) -> int:
        count = Counter(nums)
        # 将出现次数为 1 的元素求和
        return sum(v for v, cnt in count.items() if cnt == 1)
```

### 方法二：排序 + 手动统计

```python
from typing import List

class Solution:
    def sumOfUnique(self, nums: List[int]) -> int:
        total = 0
        seen_once = set()    # 只出现一次的元素
        seen_more = set()    # 出现多次的元素
        
        for x in nums:
            if x not in seen_more:
                if x in seen_once:
                    # 第二次出现，移出 seen_once
                    seen_once.remove(x)
                    seen_more.add(x)
                else:
                    seen_once.add(x)
        
        return sum(seen_once)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，哈希表存储

## 关键点总结

1. 统计频率后过滤出现次数为 1 的元素
2. Counter 是处理频率问题的利器

## 易错点

- 注意是出现次数"恰好为 1"，不是"至多一次"
