## 题目描述

存在一个只含字符 `'X'`、`'+'` 和 `'-'` 的操作字符串数组 `operations`，变量 `X` 初始值为 `0`。

每步操作的含义：
- `"++X"` 或 `"X++"` 表示 `X` 自增 1
- `"--X"` 或 `"X--"` 表示 `X` 自减 1

返回执行所有操作后 `X` 的最终值。

**示例 1：**
```
输入：operations = ["--X","X++","X++"]
输出：1
解释：-1 + 1 + 1 = 1
```

**示例 2：**
```
输入：operations = ["++X","++X","X++"]
输出：3
```

**提示：**
- `1 <= operations.length <= 100`
- `operations[i]` 是 `"++X"`、`"X++"`、`"--X"` 或 `"X--"` 之一

## 解题思路

直接统计加法操作次数减去减法操作次数即可。所有操作都只有加1或减1两种，只需判断操作字符串中是 `'+'` 还是 `'-'`（各出现2次）。

## 代码实现

### 方法一：直接统计（推荐）

```python
from typing import List

class Solution:
    def finalValueAfterOperations(self, operations: List[str]) -> int:
        # 统计加法次数减减法次数
        result = 0
        for op in operations:
            if '+' in op:
                result += 1  # ++X 或 X++ 均使 X 加 1
            else:
                result -= 1  # --X 或 X-- 均使 X 减 1
        return result
```

### 方法二：模拟执行

```python
from typing import List

class Solution:
    def finalValueAfterOperations(self, operations: List[str]) -> int:
        X = 0  # 变量初始值为 0
        for op in operations:
            if op in ("++X", "X++"):
                X += 1  # 自增操作
            else:
                X -= 1  # 自减操作（"--X" 或 "X--"）
        return X
```

### 方法三：函数式写法

```python
from typing import List

class Solution:
    def finalValueAfterOperations(self, operations: List[str]) -> int:
        # 利用 '+' 出现则 +1，'-' 出现则 -1 的规律
        return sum(1 if '+' in op else -1 for op in operations)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有操作
- 空间复杂度：O(1)，常数空间

## 关键点总结

1. 四种操作本质只有两类：`+1` 和 `-1`
2. 只需检查操作字符串中是否包含 `'+'` 即可区分
3. 最终结果 = 加法次数 - 减法次数

## 易错点

- 不需要真的解析变量名，只需关注运算符
- 操作字符串长度固定为 3，中间字符直接判断即可
