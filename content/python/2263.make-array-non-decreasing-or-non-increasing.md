## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

在一次操作中，可以选择一个下标 `i` 并将 `nums[i]` 替换为任意正整数。

返回使 `nums` 变为**非递减**或**非递增**所需的最少操作数。

**示例 1：**
```
输入：nums = [3,2,4,5,0]
输出：1
解释：将 0 变为 1（或其他值），使 [3,2,4,5,1] 非递增，需要更改1个。
```

**示例 2：**
```
输入：nums = [2,2,3,4]
输出：0
```

## 解题思路

最少操作数 = 数组长度 - 最长非递减子序列长度（LIS 的变体），取非递减和非递增的最小值。

**使非递减**：保留最长非递减子序列（LIS），替换其余 = n - len(LIS)。

**使非递增**：保留最长非递增子序列，等价于反转后求 LIS。

LIS 可用二分查找实现 O(n log n)。

## 代码实现

### 方法一：LIS + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def convertArray(self, nums: List[int]) -> int:
        def lis_length(arr: List[int]) -> int:
            """计算最长非递减子序列长度"""
            tails = []
            for x in arr:
                # 找第一个 > x 的位置（允许等于，故用 bisect_right）
                pos = bisect.bisect_right(tails, x)
                if pos == len(tails):
                    tails.append(x)
                else:
                    tails[pos] = x
            return len(tails)

        n = len(nums)
        # 最少操作 = n - 最长合法子序列长度
        # 非递减：最长非递减子序列
        non_dec = n - lis_length(nums)
        # 非递增：等价于反转后的最长非递减子序列
        non_inc = n - lis_length(nums[::-1])

        return min(non_dec, non_inc)
```

### 方法二：DP（O(n^2)）

```python
from typing import List

class Solution:
    def convertArray(self, nums: List[int]) -> int:
        n = len(nums)

        def min_ops_for(target):
            """最少操作数，使数组变为 target（'inc' 或 'dec'）"""
            # 等价于 n - 最长满足序列长度
            dp = [1] * n
            for i in range(1, n):
                for j in range(i):
                    if target == 'inc' and nums[j] <= nums[i]:
                        dp[i] = max(dp[i], dp[j] + 1)
                    elif target == 'dec' and nums[j] >= nums[i]:
                        dp[i] = max(dp[i], dp[j] + 1)
            return n - max(dp)

        return min(min_ops_for('inc'), min_ops_for('dec'))
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n log n)，二分 LIS。
- 空间复杂度：O(n)，tails 数组。

**方法二（DP）：**
- 时间复杂度：O(n^2)。
- 空间复杂度：O(n)。

## 关键点总结

1. 问题转化：最少操作 = n - 最长合法子序列。
2. 对"非递减"求最长非递减子序列；对"非递增"等价于反转后求非递减。
3. LIS 用二分 O(n log n) 实现，`bisect_right` 允许等号（非严格递增）。

## 易错点

- 非递减允许等号（`<=`），LIS 中用 `bisect_right` 而非 `bisect_left`。
- 非递增等价于原数组反转后的非递减（不是取负值）。
