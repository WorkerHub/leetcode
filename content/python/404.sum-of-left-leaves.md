## 题目描述

给定二叉树的根节点 root，返回所有左叶子之和。

**示例 1：**
```
    3
   / \
  9  20
    /  \
   15   7

输入：root = [3,9,20,null,null,15,7]
输出：24
解释：在这个二叉树中，有两个左叶子，分别是 9 和 15，所以返回 24
```

**示例 2：**
```
输入：root = [1]
输出：0
```

**提示：**
- 节点数在 [1, 1000] 范围内
- -1000 <= Node.val <= 1000

## 解题思路

这道题的关键是理解什么是"左叶子"：
- 叶子节点：没有左右子节点的节点
- 左叶子：是其父节点的左子节点，且本身是叶子节点

核心思路：
1. 遍历二叉树的所有节点
2. 判断当前节点的左子节点是否是叶子节点
3. 如果是，累加其值
4. 递归处理左右子树

解决方案：
- **方法一（推荐）**：递归（DFS）
- **方法二**：迭代（BFS/DFS）
- **方法三**：Morris 遍历

## Python 代码实现

### 方法一：递归（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        """
        递归求解：判断左子节点是否为叶子节点
        """
        if not root:
            return 0
        
        total = 0
        
        # 检查左子节点是否为叶子节点
        if root.left:
            # 左子节点存在且没有子节点，说明是左叶子
            if not root.left.left and not root.left.right:
                total += root.left.val
            else:
                # 左子节点不是叶子，继续递归
                total += self.sumOfLeftLeaves(root.left)
        
        # 递归处理右子树（右子树中也可能有左叶子）
        total += self.sumOfLeftLeaves(root.right)
        
        return total
```

### 方法二：递归（简洁版）

```python
from typing import Optional

class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        """
        更简洁的递归写法
        """
        def dfs(node: Optional[TreeNode], is_left: bool) -> int:
            """
            node: 当前节点
            is_left: 当前节点是否为其父节点的左子节点
            """
            if not node:
                return 0
            
            # 如果是左叶子节点，返回其值
            if is_left and not node.left and not node.right:
                return node.val
            
            # 递归处理左右子树
            return dfs(node.left, True) + dfs(node.right, False)
        
        return dfs(root, False)
```

### 方法三：迭代（DFS 栈）

```python
from typing import Optional

class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        """
        使用栈进行迭代 DFS
        """
        if not root:
            return 0
        
        stack = [root]
        total = 0
        
        while stack:
            node = stack.pop()
            
            # 检查左子节点是否为叶子
            if node.left:
                if not node.left.left and not node.left.right:
                    total += node.left.val
                else:
                    stack.append(node.left)
            
            # 右子节点入栈（不是左叶子，但可能包含左叶子）
            if node.right:
                stack.append(node.right)
        
        return total
```

### 方法四：迭代（BFS 队列）

```python
from typing import Optional
from collections import deque

class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        """
        使用队列进行 BFS 层序遍历
        """
        if not root:
            return 0
        
        queue = deque([root])
        total = 0
        
        while queue:
            node = queue.popleft()
            
            # 检查左子节点
            if node.left:
                if not node.left.left and not node.left.right:
                    # 是左叶子
                    total += node.left.val
                else:
                    # 不是叶子，继续遍历
                    queue.append(node.left)
            
            # 右子节点
            if node.right:
                queue.append(node.right)
        
        return total
```

### 方法五：Morris 遍历（空间优化）

```python
from typing import Optional

class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        """
        Morris 遍历：O(1) 空间复杂度
        """
        total = 0
        current = root
        
        while current:
            if not current.left:
                # 没有左子树，移动到右子树
                current = current.right
            else:
                # 找到左子树的最右节点
                predecessor = current.left
                while predecessor.right and predecessor.right != current:
                    predecessor = predecessor.right
                
                if not predecessor.right:
                    # 建立线索
                    predecessor.right = current
                    
                    # 检查左子节点是否为叶子
                    if not current.left.left and not current.left.right:
                        total += current.left.val
                    
                    current = current.left
                else:
                    # 恢复树结构
                    predecessor.right = None
                    current = current.right
        
        return total
```

## 复杂度分析

### 方法一、二：递归

- **时间复杂度**：O(n)
  - 需要遍历所有节点一次
  
- **空间复杂度**：O(h)
  - h 是树的高度，递归栈的深度
  - 最坏情况（链表）：O(n)
  - 平衡树：O(log n)

### 方法三、四：迭代

- **时间复杂度**：O(n)
  - 遍历所有节点
  
- **空间复杂度**：O(n)
  - 栈或队列最多存储 O(n) 个节点

### 方法五：Morris 遍历

- **时间复杂度**：O(n)
  - 每个节点最多访问两次
  
- **空间复杂度**：O(1)
  - 不使用额外的栈或队列

## 关键点总结

1. **左叶子的定义**：
   - 必须是其父节点的左子节点
   - 必须是叶子节点（无左右子节点）
   
2. **判断逻辑**：
   - 在父节点处判断其左子节点是否为叶子
   - 不能在节点自身判断，因为节点不知道自己是左还是右

3. **遍历方式**：
   - 任何遍历方式都可以（前序、中序、后序、层序）
   - 关键是在每个节点检查其左子节点

4. **边界条件**：
   - 空树返回 0
   - 只有根节点返回 0（根节点不是任何节点的左子节点）

## 易错点

1. **概念混淆**：
   - 错误：认为所有叶子节点都是左叶子
   - 正确：只有是父节点左子节点的叶子节点才是左叶子

2. **判断位置**：
   - 错误：在当前节点判断自己是否是左叶子
   - 正确：在父节点判断左子节点是否是叶子

3. **右子树遗漏**：
   - 错误：只递归左子树
   - 正确：右子树也要递归（右子树中可能有左叶子）

4. **根节点处理**：
   - 根节点本身不可能是左叶子
   - 但根节点的左子节点可能是左叶子
