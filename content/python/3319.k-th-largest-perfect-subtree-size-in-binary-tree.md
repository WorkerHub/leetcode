## 题目描述

给你一棵二叉树的根节点 `root` 和一个整数 `k`。

**完美子树**：一棵子树是完美的，当且仅当它是满二叉树（所有叶节点在同一层，且每个非叶节点都有两个子节点）。

返回二叉树中第 `k` 大的完美子树的节点数量。若不存在第 `k` 大的完美子树，返回 `-1`。

**示例：**
```
输入：root = [5,3,6,5,2,5,7,1,8,null,null,6,8], k = 2
输出：3
解释：完美子树的大小有 [1,1,1,1,1,3,7,3]，排序后第2大是3
```

**提示：**
- 树的节点数在 `[1, 2000]` 之间
- `1 <= k <= 1024`
- `1 <= node.val <= 2000`

## 解题思路

**DFS 后序遍历：**

对每个节点，判断以它为根的子树是否是完美二叉树：
- 空节点：大小为 0，是完美树。
- 叶节点：大小为 1，是完美树。
- 非叶节点：若左右子树都是完美树，且大小相等（完美树才能保证左右高度相同），则以该节点为根的子树也是完美树，大小为 `left_size + right_size + 1`。

收集所有完美子树的大小，排序后返回第 k 大的。

## Python 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def kthLargestPerfectSubtree(self, root: Optional[TreeNode], k: int) -> int:
        perfect_sizes = []
        
        def dfs(node) -> int:
            """
            返回以 node 为根的子树大小（若是完美树），否则返回 -1
            """
            if node is None:
                return 0
            
            left_size = dfs(node.left)
            right_size = dfs(node.right)
            
            # 若左或右子树不是完美树，或大小不相等，则当前子树也不是完美树
            if left_size == -1 or right_size == -1 or left_size != right_size:
                return -1
            
            # 当前子树是完美树
            size = left_size + right_size + 1
            perfect_sizes.append(size)
            return size
        
        dfs(root)
        
        if len(perfect_sizes) < k:
            return -1
        
        # 返回第 k 大
        perfect_sizes.sort(reverse=True)
        return perfect_sizes[k - 1]
```

### 方法二：使用 heapq 找第 k 大

```python
from typing import Optional
import heapq

class Solution:
    def kthLargestPerfectSubtree(self, root: Optional[TreeNode], k: int) -> int:
        perfect_sizes = []
        
        def dfs(node):
            if node is None:
                return 0
            
            l = dfs(node.left)
            r = dfs(node.right)
            
            if l == -1 or r == -1 or l != r:
                return -1
            
            size = l + r + 1
            perfect_sizes.append(size)
            return size
        
        dfs(root)
        
        if len(perfect_sizes) < k:
            return -1
        
        # 使用堆找第 k 大
        return heapq.nlargest(k, perfect_sizes)[-1]
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS O(n) + 排序 O(n log n)
- 空间复杂度：O(n)，递归栈和收集数组

## 关键点总结

1. 完美二叉树（满二叉树）：所有叶节点在同一层，非叶节点都有两个子节点。
2. 判断完美树的关键：左右子树都是完美树，且大小相等（保证高度相同）。
3. 大小为 `2^h - 1`，其中 `h` 是树的高度；但只需判断左右子树大小是否相等即可推断。

## 易错点

1. 大小相等不等于完美，还需要左右子树本身也是完美树（递归验证）。
2. `-1` 作为"不是完美树"的标记，需要与有效大小区分（树节点数 >= 1，不会返回 -1 与实际混淆）。
3. 单个节点（叶节点）也是完美树，大小为 1。
