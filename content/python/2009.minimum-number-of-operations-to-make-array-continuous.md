## 题目描述

给你一个整数数组 `nums`，每次操作可以选择数组中**任意一个**元素，将其变为**任意整数**。

如果满足以下条件之一，数组是**连续的**：
- 数组中所有元素都**互不相同**
- 数组中最大值和最小值的差等于 `nums.length - 1`

请你返回使 `nums` **变为连续**所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [4,2,5,3]
输出：0
解释：已经连续 [2,3,4,5]
```

**示例 2：**
```
输入：nums = [1,2,3,5,6]
输出：1
解释：将 5 或 6 改为 4
```

**示例 3：**
```
输入：nums = [1,10,100,1000]
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键观察：** 最终连续数组的形式是 `[x, x+1, ..., x+n-1]`（共 `n` 个不同整数）。操作次数 = `n - (保留的原始元素个数)`，所以要**最大化保留的元素数量**。

**算法：**
1. 对 `nums` 去重并排序，得到 `sorted_unique`
2. 对于每个可能的起始值 `x = sorted_unique[i]`，终止值为 `x + n - 1`
3. 用二分查找找到 `[x, x+n-1]` 范围内有多少个 `sorted_unique` 的元素
4. 保留元素数 = 该范围内的元素数，最少操作 = `n - 最大保留数`

## 代码实现

### 方法一：排序去重 + 滑动窗口（推荐）

```python
from typing import List
import bisect

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        # 去重并排序
        unique = sorted(set(nums))
        m = len(unique)

        max_keep = 0  # 最多可以保留的元素数
        right = 0  # 滑动窗口右指针

        for left in range(m):
            # 窗口为 [unique[left], unique[left] + n - 1]
            window_end = unique[left] + n - 1
            # 移动右指针找到窗口右边界
            while right < m and unique[right] <= window_end:
                right += 1
            # 当前窗口内的元素数为 right - left
            max_keep = max(max_keep, right - left)

        return n - max_keep
```

### 方法二：二分查找

```python
from typing import List
import bisect

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        unique = sorted(set(nums))
        m = len(unique)

        max_keep = 0

        for i in range(m):
            # 以 unique[i] 为窗口起始点
            window_end = unique[i] + n - 1
            # 二分查找：找到第一个 > window_end 的位置
            pos = bisect.bisect_right(unique, window_end)
            # 窗口内有效元素数 = pos - i
            max_keep = max(max_keep, pos - i)

        return n - max_keep
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n log n)，去重排序 | O(n) |
| 二分查找 | O(n log n) | O(n) |

## 关键点总结

1. 目标数组是 `n` 个连续不同整数组成的集合 `{x, x+1, ..., x+n-1}`
2. 最优起始值 `x` 一定是原数组某个元素（枚举所有可能的起始值）
3. 保留最多原始元素，等价于找最大滑动窗口内的去重元素数
4. 先去重再排序，窗口大小固定为 `n`

## 易错点

- 必须先**去重**再排序，因为重复元素占多个位置但最终只能保留一个
- 操作次数 = `n - max_keep`（n 是原数组长度，包含重复）
- 窗口大小是 `n`（原数组长度），不是去重后的长度
