## 题目描述

在考场里，有 n 个座位排成一行，编号为 0 到 n - 1 。

当学生进入考场后，他必须坐在离最近的人最远的那个座位。如果有多个这样的座位，他会坐在编号最小的座位上。（另外，如果考场里没有人，那么学生就坐在 0 号座位上。）

设计一个模拟所述考场的类：

- `ExamRoom(int n)`：用座位数量 n 初始化考场对象。
- `int seat()`：返回下一个学生将会坐的座位编号。
- `void leave(int p)`：指定坐在座位 p 的学生离开。题目保证座位 p 上有学生。

**示例 1：**
```
输入：
["ExamRoom","seat","seat","seat","seat","leave","seat"]
[[10],[],[],[],[],[4],[]]
输出：
[null,0,9,4,2,null,5]
解释：
ExamRoom(10) -> null
seat() -> 0，没有人在考场里，学生坐在 0 号座位。
seat() -> 9，学生最远离 0 号座位（距离为 9），所以坐在 9 号座位。
seat() -> 4，学生坐在 0 和 9 之间，距离两边都是 4。
seat() -> 2，学生坐在 0 和 4 之间，距离为 2。
leave(4) -> null
seat() -> 5，学生坐在 0 和 9 之间，距离为 5。
```

**提示：**
- 1 <= n <= 10^9
- 最多调用 10^4 次 seat 和 leave 操作
- 保证调用 leave(p) 时，座位 p 上有学生

## 解题思路

这是一道**设计题**，需要动态维护座位的占用情况。

**核心问题：**
1. 如何快速找到"离最近的人最远"的座位？
2. 如何高效处理学生入座和离开？

**关键观察：**
1. **空考场**：第一个学生坐在位置 0
2. **两端座位**：距离是 `pos` 或 `n - 1 - pos`
3. **中间座位**：距离是 `(right - left) // 2`
4. **维护有序集合**：需要知道所有已占用座位的位置

**算法策略：**

**方法一思路（有序列表）：**
- 用有序列表存储所有已占座位
- `seat()`：遍历相邻座位，找到最大间隔的中点
- `leave(p)`：从列表中删除 p

**方法二思路（堆优化）：**
- 用堆维护所有间隔段
- 每次取出最大间隔的中点
- 需要处理堆中的失效段

## Python 代码实现

### 方法一：有序列表（推荐）⭐

```python
class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.students = []  # 有序列表存储已占座位
    
    def seat(self) -> int:
        # 如果考场为空，坐在 0 号位置
        if not self.students:
            self.students.append(0)
            return 0
        
        # 计算最大距离和对应座位
        max_dist = self.students[0]  # 坐在最左边的距离
        seat_pos = 0
        
        # 检查相邻学生之间的间隔
        for i in range(len(self.students) - 1):
            left = self.students[i]
            right = self.students[i + 1]
            # 中点位置和到最近人的距离
            dist = (right - left) // 2
            if dist > max_dist:
                max_dist = dist
                seat_pos = left + dist
        
        # 检查最右边的座位
        if self.n - 1 - self.students[-1] > max_dist:
            seat_pos = self.n - 1
        
        # 插入新座位（保持有序）
        import bisect
        bisect.insort(self.students, seat_pos)
        
        return seat_pos
    
    def leave(self, p: int) -> None:
        self.students.remove(p)
```

**代码说明：**
- `students` 有序存储已占座位
- `seat()`：遍历所有间隔，找最大距离的中点
- `leave(p)`：直接删除
- 使用 `bisect.insort` 保持有序插入

### 方法二：手动二分插入（不使用 bisect）

```python
class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.students = []
    
    def seat(self) -> int:
        if not self.students:
            self.students.append(0)
            return 0
        
        max_dist = self.students[0]
        seat_pos = 0
        
        for i in range(len(self.students) - 1):
            left, right = self.students[i], self.students[i + 1]
            dist = (right - left) // 2
            if dist > max_dist:
                max_dist = dist
                seat_pos = left + dist
        
        if self.n - 1 - self.students[-1] > max_dist:
            seat_pos = self.n - 1
        
        # 手动二分查找插入位置
        left, right = 0, len(self.students)
        while left < right:
            mid = (left + right) // 2
            if self.students[mid] < seat_pos:
                left = mid + 1
            else:
                right = mid
        self.students.insert(left, seat_pos)
        
        return seat_pos
    
    def leave(self, p: int) -> None:
        self.students.remove(p)
```

### 方法三：使用有序集合 (SortedList)

```python
from sortedcontainers import SortedList

class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.students = SortedList()
    
    def seat(self) -> int:

            self.students.add(0)
            return 0
        
        max_dist = self.students[0]
        seat_pos = 0
        
        for i in range(len(self.students) - 1):
            left, right = self.students[i], self.students[i + 1]
            dist = (right - left) // 2
            if dist > max_dist:
                max_dist = dist
                seat_pos = left + dist
        
        if self.n - 1 - self.students[-1] > max_dist:
            seat_pos = self.n - 1
        
        self.students.add(seat_pos)
        return seat_pos

        self.students.remove(p)
```

**代码说明：**
- 使用第三方库 `sortedcontainers`
- 自动维护有序性，性能更好

### 方法四：优化版（提前计算）

```python
class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.students = []
    
    def seat(self) -> int:
        if not self.students:
            self.students.append(0)
            return 0
        
        # 候选座位列表：(距离, 座位编号)
        candidates = []
        
        # 最左边
        candidates.append((self.students[0], 0))
        
        # 中间
        for i in range(len(self.students) - 1):
            left, right = self.students[i], self.students[i + 1]
            dist = (right - left) // 2
            candidates.append((dist, left + dist))
        
        # 最右边
        candidates.append((self.n - 1 - self.students[-1], self.n - 1))
        
        # 选择距离最大的，距离相同选编号最小的
        max_dist, seat_pos = max(candidates)
        
        import bisect
        bisect.insort(self.students, seat_pos)
        return seat_pos
    
    def leave(self, p: int) -> None:
        self.students.remove(p)
```

## 复杂度分析

### 方法一、二：
- **seat() 时间复杂度**：O(n)，遍历所有学生 + O(n) 插入。
- **leave() 时间复杂度**：O(n)，查找并删除。
- **空间复杂度**：O(n)，存储学生位置。

### 方法三：SortedList
- **seat() 时间复杂度**：O(n)，遍历 + O(log n) 插入。
- **leave() 时间复杂度**：O(log n)。
- **空间复杂度**：O(n)。

## 关键点总结

1. **有序维护**：使用有序列表存储座位，方便查找间隔
2. **三种情况**：最左边、中间、最右边座位的距离计算不同
3. **距离计算**：
   - 左边：`students[0]`
   - 中间：`(right - left) // 2`
   - 右边：`n - 1 - students[-1]`
4. **保持有序**：使用 `bisect.insort` 或手动二分插入
5. **贪心选择**：选择最大距离，距离相同选编号最小

## 易错点

1. **边界情况**：空考场时返回 0

2. **距离计算错误**：
   ```python
   # ❌ 错误：中间座位距离应该是间隔的一半
   dist = right - left
   
   # ✅ 正确
   dist = (right - left) // 2
   ```

3. **座位选择错误**：距离相同时应该选编号最小的
   - 通过遍历顺序自然满足（从左到右）

4. **忘记保持有序**：插入时必须保持 students 有序

5. **最右边距离**：是 `n - 1 - students[-1]` 不是 `n - students[-1]`
