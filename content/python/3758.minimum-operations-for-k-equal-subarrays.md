## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可以将数组中任意一个元素增加或减少 1，求使数组中存在 `k` 个相等元素所需的最少操作次数。

**示例 1：**
```
输入：nums = [1,2,3,4,5], k = 3
输出：2
解释：目标使 3 个元素相等。将 1,2,3 都变为 2，操作：|1-2|+|3-2|=2。
```

**示例 2：**
```
输入：nums = [5,5,5], k = 3
输出：0
解释：已经有 3 个相等元素。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= nums.length`

## 解题思路

排序后，枚举将哪 `k` 个元素变为相等。

对于排序后的 `k` 个连续元素，最优的目标值是中位数。代价 = 各元素到中位数的绝对差之和，可用前缀和 O(1) 计算。

滑动窗口枚举所有大小为 `k` 的子数组，取最小代价。

## Python 代码实现

### 方法一：滑动窗口 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)

        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]

        ans = float('inf')

        for l in range(n - k + 1):
            r = l + k - 1
            mid = l + k // 2  # 中位数下标

            # 计算 [l, r] 内所有元素到 nums[mid] 的绝对差之和
            # 左半部分 [l, mid-1] 各元素 < nums[mid]
            # 右半部分 [mid+1, r] 各元素 > nums[mid]

            # 左半部分代价
            left_count = mid - l
            left_sum = prefix[mid] - prefix[l]
            cost_left = nums[mid] * left_count - left_sum

            # 右半部分代价
            right_count = r - mid
            right_sum = prefix[r+1] - prefix[mid+1]
            cost_right = right_sum - nums[mid] * right_count

            ans = min(ans, cost_left + cost_right)

        return ans
```

### 方法二：暴力枚举（小数组）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        ans = float('inf')

        for l in range(n - k + 1):
            window = nums[l:l+k]
            median = window[k // 2]
            cost = sum(abs(x - median) for x in window)
            ans = min(ans, cost)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序加线性扫描
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 排序后，相等的最优目标值是中位数
2. 滑动窗口枚举连续 k 个元素，前缀和 O(1) 计算代价
3. 代价公式：左半部分 `median * count_left - sum_left`，右半部分对称

## 易错点

1. 中位数选择：`l + k // 2` 对奇偶长度均正确
2. 前缀和数组偏移一位：`prefix[i+1] = prefix[i] + nums[i]`
