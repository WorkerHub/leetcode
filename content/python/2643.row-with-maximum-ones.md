## 题目描述

给你一个大小为 `m x n` 的二进制矩阵 `grid`，找出具有最多 1 的行，返回该行的下标和该行中 1 的数量，若多行有相同的 1 的数量，返回下标最小的行。

**示例 1：**
```
输入：grid = [[0,1],[1,0]]
输出：[0,1]
解释：两行都有 1 个 1，返回下标较小的第 0 行
```

**示例 2：**
```
输入：grid = [[0,0,0],[0,1,1]]
输出：[1,2]
```

**数据范围：**
- m == grid.length
- n == grid[0].length
- 1 <= m, n <= 100
- grid[i][j] 为 0 或 1

## 解题思路

遍历每一行，统计 1 的个数，维护最大值和对应行下标。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def rowAndMaximumOnes(self, grid: List[List[int]]) -> List[int]:
        best_row = 0
        best_count = 0
        for i, row in enumerate(grid):
            cnt = sum(row)  # 二进制行中 1 的个数即为 sum
            if cnt > best_count:
                best_count = cnt
                best_row = i
        return [best_row, best_count]
```

### 方法二：max 函数

```python
from typing import List

class Solution:
    def rowAndMaximumOnes(self, grid: List[List[int]]) -> List[int]:
        # 用 max 找最多 1 的行，同数量时保留下标最小的
        # 注意：max 默认取最大值，若相等取后出现的（需要额外处理）
        best_count = -1
        best_row = 0
        for i, row in enumerate(grid):
            cnt = sum(row)
            if cnt > best_count:
                best_count = cnt
                best_row = i
        return [best_row, best_count]
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 矩阵元素为 0 或 1，`sum(row)` 即为 1 的个数
2. 同数量时取下标最小的，用 `>` 而非 `>=`

## 易错点

1. 同 1 数量时返回下标最小的行，更新条件用 `>`
