## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，每次操作可以将任意元素增加 1 或减少 1，共可以操作 `k` 次。

返回操作后 `nums` 中**频率最高**的元素的最大频率。

**示例 1：**
```
输入：nums = [1,2,6,4], k = 3
输出：3
解释：将 nums[2]=6 改为 3（操作 3 次），得 [1,2,3,4] 或将 1,2 各加到 4，得 3 个 4
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^14`

## 解题思路

排序后，使用滑动窗口。

固定目标值为某个 nums[r]（排序后），窗口内的元素都变为 nums[r]，代价 = sum(nums[r] - nums[i]) for i in window = nums[r] * len(window) - sum(nums[i] in window)。

用前缀和快速计算窗口内的代价，若代价 > k 则收缩左端。

## Python 代码实现

### 方法一：排序 + 滑动窗口 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = 1
        left = 0

        for right in range(n):
            # 窗口 [left, right]，全部变为中位数，代价最小
            # 但实际上目标值应该是中位数，使总代价最小
            # 用二分查找找最左合法 left

            # 代价计算：以中位数为目标
            # 实际上：目标值是中位数 nums[mid]
            # 左侧代价 = nums[mid] * (mid - left + 1) - sum(nums[left..mid])
            # 右侧代价 = sum(nums[mid..right]) - nums[mid] * (right - mid + 1)
            # 总代价可能超过 k

            # 简化：以 nums[right] 为目标（所有都增大到 right）
            # 代价 = nums[right] * (right - left + 1) - (prefix[right+1] - prefix[left])
            while nums[right] * (right - left + 1) - (prefix[right + 1] - prefix[left]) > k:
                left += 1

            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：二分查找（验证对比）

```python
from typing import List
import bisect

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        def cost(l, r):
            # 将 [l, r] 中所有元素变为中位数的代价
            mid = (l + r) // 2
            # 左侧变大，右侧变小
            c_left = nums[mid] * (mid - l + 1) - (prefix[mid + 1] - prefix[l])
            c_right = (prefix[r + 1] - prefix[mid + 1]) - nums[mid] * (r - mid)
            return c_left + c_right

        ans = 1
        for right in range(n):
            # 二分找最左的 left 使 cost(left, right) <= k
            lo, hi = 0, right
            while lo < hi:
                mid = (lo + hi) // 2
                if cost(mid, right) <= k:
                    hi = mid
                else:
                    lo = mid + 1
            ans = max(ans, right - lo + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 滑动窗口/二分
- 空间复杂度：O(n)，前缀和

## 关键点总结

1. 排序后，目标值选中位数代价最小（L1 最优化）
2. 滑动窗口：以 nums[right] 为目标（对于右端单调扩展）的简化策略也是正确的
3. 前缀和快速计算区间总和，O(1) 计算代价

## 易错点

1. 以 nums[right] 为目标（所有变大）：代价计算用 nums[right] * len - sum
2. 实际最优是以中位数为目标，但滑动窗口中单调性保证以 nums[right] 为目标也正确
3. k 可以很大（10^14），用 int 即可（Python 无溢出）
