## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

从数组中选择长度为 `2k` 的子序列，将其分为两半（前 k 个和后 k 个），计算两半各自的 XOR 值的 OR。

返回所有可能选择中这个值的**最大值**。

**示例 1：**
```
输入：nums = [2,6,7], k = 1
输出：5
解释：选 [2,7]，XOR(2) OR XOR(7) = 2 OR 7 = 7；选 [6,7]，6 OR 7 = 7；选 [2,6]，2 OR 6 = 6；最大是 7？
```

**提示：**
- `2 <= nums.length <= 400`
- `1 <= k <= nums.length / 2`
- `1 <= nums[i] < 2^7`

## 解题思路

DP：

`left[i]` = 从 `nums[0..i]` 中选 k 个元素的所有可能 XOR 值集合（以 i 结尾最右的）。

更准确：`left[i][j]` = 从 `nums[0..i]` 中选 j 个元素的所有可能 XOR 值集合。

`right[i][j]` = 从 `nums[i..n-1]` 中选 j 个元素的所有可能 XOR 值集合。

对每个分割点 i，取 `left[i][k]` 中的值和 `right[i+1][k]` 中的值，求 OR 的最大值。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int], k: int) -> int:
        n = len(nums)
        
        # left_dp[i] = set of XOR values obtainable by choosing exactly k elements from nums[0..i]
        # 用二维：left_dp[i][j] = nums[0..i] 中选 j 个元素的 XOR 值集合
        
        # 由于 nums[i] < 128，XOR 值也 < 128
        # 用 bitmask 表示 XOR 值集合（128 位）
        
        # left_dp[i][j]: set of possible XOR values
        # 状态：(i, j, xor_val)
        
        # 简化：left[i] = (前 i+1 个元素中选 k 个的所有 XOR 值集合)
        # 分步计算
        
        # dp[j][xor] = True if can choose j from nums[0..i] to get XOR xor
        
        MAX_XOR = 128
        
        # 从左到右计算 left_xors[i] = nums[0..i] 中选 k 个的 XOR 集合
        left_xors = [set() for _ in range(n)]
        
        # dp[j] = set of XOR values using j elements from nums[0..i]
        dp = [set() for _ in range(k + 1)]
        dp[0].add(0)
        
        for i in range(n):
            new_dp = [set() for _ in range(k + 1)]
            for j in range(min(i + 1, k) + 1):
                for xor in dp[j]:
                    new_dp[j].add(xor)  # 不选 nums[i]
                    if j < k:
                        new_dp[j + 1].add(xor ^ nums[i])  # 选 nums[i]
            dp = new_dp
            left_xors[i] = dp[k].copy()
        
        # 从右到左计算 right_xors[i] = nums[i..n-1] 中选 k 个的 XOR 集合
        right_xors = [set() for _ in range(n)]
        dp = [set() for _ in range(k + 1)]
        dp[0].add(0)
        
        for i in range(n - 1, -1, -1):
            new_dp = [set() for _ in range(k + 1)]
            for j in range(min(n - i, k) + 1):
                for xor in dp[j]:
                    new_dp[j].add(xor)
                    if j < k:
                        new_dp[j + 1].add(xor ^ nums[i])
            dp = new_dp
            right_xors[i] = dp[k].copy()
        
        # 枚举分割点，找最大 OR
        ans = 0
        for i in range(k - 1, n - k):
            for lx in left_xors[i]:
                for rx in right_xors[i + 1]:
                    ans = max(ans, lx | rx)
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * k * MAX_XOR + n * MAX_XOR^2)
- 空间复杂度：O(n * MAX_XOR)

## 关键点总结

1. 分别计算前缀和后缀的 XOR 值集合
2. 枚举分割点，取两边 XOR 集合中 OR 最大的组合
3. 由于 XOR 值 < 128，集合大小有限

## 易错点

1. 注意集合的更新方式（不能边遍历边修改）
2. 分割点 i 需满足左边至少 k 个，右边至少 k 个
