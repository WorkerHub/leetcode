## 题目描述

给你一个数组 `pairs`，其中 `pairs[i] = [xi, yi]`，且满足：
- `pairs` 中没有重复元素
- `xi < yi`

设 `ways` 为满足下面条件的有根树的数目：
- 树所包含的节点集合为 `1` 到 `n`
- `pairs[i] = [xi, yi]` 出现在 `pairs` 中当且仅当 `xi` 是 `yi` 的祖先，或者 `yi` 是 `xi` 的祖先

注意：构造出来的树不一定是二叉树。

若 `ways == 0`，返回 `0`；若 `ways == 1`，返回 `1`；否则返回 `2`。

**提示：**
- `1 <= pairs.length <= 10^5`
- `1 <= xi < yi <= 500`

## 解题思路

关键性质：
1. 在有根树中，节点 `u` 和 `v` 互为祖先后代当且仅当其中一个的邻居集合（含自身）包含另一个的邻居集合
2. 设 `deg[u]` 为 u 的度数（在 pairs 图中的邻居数 + 1 算上自身）
3. 对每条边 `(u, v)`，`deg[u] <= deg[v]` 意味着 u 是 v 的后代
4. 若 `deg[u] == deg[v]`，则两者可以互换（有多种构造方式）
5. 若邻居集合不存在包含关系，则无解

**算法**：
1. 建立邻接表，统计每个节点的邻居（含自身）
2. 找根节点（唯一一个与所有其他节点都有边的节点，度数最大）
3. 对每条边 `(u, v)`（u 度数 <= v），检查 u 的邻居集合是否 v 邻居集合的子集
4. 若子集且度数相等，说明有多解

## 代码实现

### 方法一：邻接表 + 集合包含判断

```python
from typing import List
from collections import defaultdict

class Solution:
    def checkWays(self, pairs: List[List[int]]) -> int:
        # 建立邻接表（节点的邻居集合，含自身）
        adj = defaultdict(set)
        for u, v in pairs:
            adj[u].add(v)
            adj[v].add(u)
        
        # 加上自身
        for node in adj:
            adj[node].add(node)
        
        n_nodes = len(adj)
        
        # 检查是否存在根节点（与所有其他节点均相邻的节点）
        # 根节点的度数 = n_nodes（含自身）
        has_root = any(len(adj[u]) == n_nodes for u in adj)
        if not has_root:
            return 0
        
        result = 1  # 假设恰好一种构造方式
        
        # 对每条边 (u, v)，确保度数小的是后代
        for u, v in pairs:
            # 让 u 是度数较小的
            if len(adj[u]) > len(adj[v]):
                u, v = v, u
            
            # u 的邻居集合必须是 v 的邻居集合的子集（含自身）
            if not adj[u].issubset(adj[v]):
                return 0
            
            # 如果度数相等，说明 u 和 v 可以互换，有多种方式
            if len(adj[u]) == len(adj[v]):
                result = 2
        
        return result
```

### 方法二：排序优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def checkWays(self, pairs: List[List[int]]) -> int:
        adj = defaultdict(set)
        for u, v in pairs:
            adj[u].add(v)
            adj[v].add(u)
        for node in list(adj.keys()):
            adj[node].add(node)
        
        n = len(adj)
        nodes = sorted(adj.keys(), key=lambda x: len(adj[x]))
        
        # 找根节点（度数等于节点总数的节点）
        if len(adj[nodes[-1]]) != n:
            return 0
        
        result = 1
        for u, v in pairs:
            if len(adj[u]) > len(adj[v]):
                u, v = v, u
            if not adj[u] <= adj[v]:
                return 0
            if len(adj[u]) == len(adj[v]):
                result = 2
        
        return result
```

## 复杂度分析

- **时间复杂度**：O(p * n)，p 为 pairs 数量，n 为节点数，集合子集检查 O(min(deg_u, deg_v))
- **空间复杂度**：O(p + n)

## 关键点总结

1. 每个节点的邻居集合（含自身）代表其祖先-后代关系
2. 父节点的邻居集合包含子节点的邻居集合
3. 若度数相等说明父子可互换，有多种构造方式

## 易错点

- 邻居集合要包含自身节点
- 根节点必须与所有其他节点均相邻
