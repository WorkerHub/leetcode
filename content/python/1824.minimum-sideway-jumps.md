## 题目描述

给你一个长度为 `n+1` 的整数数组 `obstacles`，其中 `obstacles[i]` 表示第 `i` 条跑道在第 `i` 个点有一个障碍物（`0` 表示没有障碍物）。

青蛙从第 0 点的第 2 条跑道出发，目标是到达第 n 点。规则：
- 沿当前跑道不变地向前一点（不跳跃），花费 0 次跳跃
- 跳到同一点的另一条跑道，花费 1 次跳跃（但不能跳到有障碍物的跑道）

返回到达第 n 点的**最少侧跳次数**。

**示例 1：**
```
输入：obstacles = [0,1,2,3,0]
输出：2
```

**示例 2：**
```
输入：obstacles = [0,1,1,3,3,0]
输出：0
```

**提示：**
- `2 <= obstacles.length <= 5 * 10^5`
- `1 <= obstacles[i] <= 3`
- `obstacles[0] == obstacles[n] == 0`

## 解题思路

**动态规划**：`dp[i][j]` 表示到达第 i 个点、处于第 j 条跑道（j=1,2,3）时的最少跳跃次数。

状态转移：
1. **直行**：`dp[i][j] = dp[i-1][j]`（若第 j 条在第 i 点无障碍）
2. **侧跳**：在当前点，从无障碍的跑道跳到其他无障碍的跑道，代价 +1

贪心优化：在每个点，先按直行更新，然后对有障碍的跑道设置无穷大，再对无障碍的跑道取其他跑道的最小值 +1。

## 代码实现

### 方法一：DP + 贪心（推荐）

```python
from typing import List

class Solution:
    def minSideJumps(self, obstacles: List[int]) -> int:
        INF = float('inf')
        # dp[j] 表示当前在第 j 条跑道的最少跳跃次数（j=0,1,2 对应跑道 1,2,3）
        dp = [1, 0, 1]  # 起点在跑道 2（索引 1），跑道 1 和 3 需要 1 次跳跃

        for i in range(1, len(obstacles)):
            obs = obstacles[i] - 1  # 转为 0-indexed（-1 表示没有障碍）
            if obs >= 0:
                dp[obs] = INF  # 有障碍的跑道不可到达

            # 侧跳：从当前点的最小代价 + 1 更新其他跑道
            min_dp = min(dp)
            for j in range(3):
                if obstacles[i] != j + 1:  # 无障碍的跑道
                    dp[j] = min(dp[j], min_dp + 1)

        return min(dp)
```

### 方法二：逐步模拟（含详细注释）

```python
from typing import List

class Solution:
    def minSideJumps(self, obstacles: List[int]) -> int:
        INF = float('inf')
        # dp[0], dp[1], dp[2] 分别对应跑道 1, 2, 3
        dp = [1, 0, 1]

        n = len(obstacles) - 1
        for i in range(1, n + 1):
            obs_lane = obstacles[i]  # 当前点有障碍的跑道（1-indexed，0 表示无）

            # 第一步：将有障碍的跑道设为不可达
            if obs_lane > 0:
                dp[obs_lane - 1] = INF

            # 第二步：计算当前点最小跳跃次数
            min_val = min(dp)

            # 第三步：所有无障碍跑道都可以通过侧跳到达
            for j in range(3):
                if j != obs_lane - 1:  # 无障碍跑道
                    dp[j] = min(dp[j], min_val + 1)

        return min(dp)
```

## 复杂度分析

- **时间复杂度**：O(n)，每个点常数时间处理（跑道数固定为 3）
- **空间复杂度**：O(1)，只使用长度为 3 的 dp 数组

## 关键点总结

1. dp 只需维护当前点的 3 条跑道状态，无需二维数组
2. 每个点先标记障碍，再用全局最小值 +1 更新其他跑道
3. 侧跳操作在同一点完成，不移动到下一点

## 易错点

- 处理顺序：先将障碍跑道设为 INF，再计算最小值更新其他跑道
- 侧跳代价 +1 更新时，要确保目标跑道无障碍
