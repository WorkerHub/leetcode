## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，还有一个整数 `key`，该整数在数组中**频繁出现**。

同时给你一个整数数组（不是 `nums` 的元素），`target`。

**目标**：统计 `nums` 中紧接着 `key` 之后出现的不同整数，找出出现次数最多的那个。

具体来说：找出 `target` 值，使得 `target` 在 `nums` 中恰好出现在 `key` 的后面（即 `nums[i] == key` 且 `nums[i+1] == target`）的次数最多。

返回出现次数最多的那个 `target`。

**示例 1：**
```
输入：nums = [1,100,200,1,100], key = 1
输出：100
解释：1 后面跟着 100 出现了 2 次（索引 0→1 和 3→4），200 只出现 1 次。
```

**示例 2：**
```
输入：nums = [2,2,2,2,3], key = 2
输出：2
解释：2 后面跟着 2 出现了 3 次。
```

**提示：**
- `2 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`
- `key` 是 `nums` 中的一个数

## 解题思路

**哈希表计数**

遍历数组，当 `nums[i] == key` 时，统计 `nums[i+1]` 的出现次数，最后返回出现次数最多的那个值。

## 代码实现

### 方法一：Counter（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def mostFrequent(self, nums: List[int], key: int) -> int:
        # 统计紧跟在 key 之后的元素频次
        cnt = Counter()
        for i in range(len(nums) - 1):
            if nums[i] == key:
                cnt[nums[i + 1]] += 1
        # 返回频次最高的元素
        return cnt.most_common(1)[0][0]
```

### 方法二：字典手动计数

```python
from typing import List

class Solution:
    def mostFrequent(self, nums: List[int], key: int) -> int:
        freq = {}
        for i in range(len(nums) - 1):
            if nums[i] == key:
                nxt = nums[i + 1]
                freq[nxt] = freq.get(nxt, 0) + 1
        # 找频次最大的 key
        return max(freq, key=freq.get)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Counter | O(n) | O(n) |
| 字典 | O(n) | O(n) |

## 关键点总结

1. 遍历时要注意边界：`i` 最多到 `len(nums) - 2`，避免越界。
2. 只统计 `nums[i] == key` 时，`nums[i+1]` 的频次。
3. `Counter.most_common(1)` 直接返回最高频元素。

## 易错点

- 循环范围应是 `range(len(nums) - 1)`，不然会越界访问 `nums[i+1]`。
- 题目保证答案唯一，不需要处理并列情况。
