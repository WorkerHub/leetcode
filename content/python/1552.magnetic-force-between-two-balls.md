## 题目描述

在代号为 C-137 的地球上，Rick 发现如果将两个 `position[i]` 位置放置磁力球，则它们之间的磁力为 `|position[i] - position[j]|`。

给你一个整数数组 `position` 和整数 `m`，将 `m` 个球放在 `position` 的 `m` 个位置，使得任意两球之间最小磁力**最大化**，返回这个最大化的最小磁力。

**示例 1：**
```
输入：position = [1,2,3,4,7], m = 3
输出：3
解释：将3个球放在 1, 4, 7，最小磁力 = 3
```

**提示：**
- `2 <= position.length <= 10^5`
- `1 <= position[i] <= 10^9`
- `2 <= m <= position.length`

## 解题思路

### 二分答案

**二分的对象：** 最小磁力值 `d`（候选答案）。

**check(d)：** 判断是否能放 m 个球，使得相邻球之间距离 >= d。

贪心验证：排序后，从最左边开始放球，每次尽可能放在满足距离 >= d 的最左位置。

若能放下 m 个球，则 `d` 可行，尝试更大的 `d`。

## 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
from typing import List

class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()
        n = len(position)

        def can_place(min_dist: int) -> bool:
            """判断最小间距为 min_dist 时能否放 m 个球"""
            count = 1  # 第一个球放在 position[0]
            last = position[0]
            for i in range(1, n):
                if position[i] - last >= min_dist:
                    count += 1
                    last = position[i]
                    if count == m:
                        return True
            return count >= m

        # 二分范围：[1, (position[-1] - position[0]) // (m-1)]
        lo, hi = 1, (position[-1] - position[0]) // (m - 1)
        while lo < hi:
            mid = (lo + hi + 1) // 2  # 上取整
            if can_place(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

### 方法二：完整二分写法

```python
from typing import List

class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()
        n = len(position)

        def check(d: int) -> bool:
            cnt = 1
            prev = position[0]
            for pos in position[1:]:
                if pos - prev >= d:
                    cnt += 1
                    prev = pos
            return cnt >= m

        lo, hi = 1, position[-1] - position[0]
        ans = 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## 复杂度分析

- **时间复杂度**：O(N log N + N log D)，D = max_pos - min_pos
- **空间复杂度**：O(1)（排序不计）

## 关键点总结

1. 二分答案模板：二分"最小磁力"，贪心验证是否可行
2. 贪心验证：从左到右尽可能早地放球（每次找第一个满足距离的位置）
3. 二分上界：`(position[-1] - position[0]) // (m - 1)`（均匀分配时的间距）

## 易错点

- 二分时使用上取整 `(lo + hi + 1) // 2` 避免死循环（求最大可行值时）
- check 函数初始放一个球在 `position[0]`，count 从 1 开始
