## 题目描述

给你一个下标从 **0** 开始的整数数组 `usageLimits`，其中 `usageLimits[i]` 表示值 `i` 可以使用的最大次数。

将非负整数划分成组，满足：
1. 每组的整数各不相同
2. 第 `j` 组（从 1 开始）的长度严格大于第 `j-1` 组

返回可以创建的 **最大组数**。

**示例 1：**
```
输入：usageLimits = [1,2,5]
输出：3
解释：第1组[0]长1，第2组[1,2]长2，第3组[1,2,2,2,2]不对
```

**提示：**
- `1 <= usageLimits.length <= 10^5`
- `1 <= usageLimits[i] <= 10^9`

## 解题思路

**二分 + 贪心验证**：二分答案 `k`（组数），验证是否可以创建 k 组。

对于 k 组，长度分别为 1, 2, ..., k，总需求 = `k*(k+1)/2`。

将 `usageLimits` 排序后，贪心分配：长度需求大的组优先从使用限制多的值中取。

具体验证：排序后从小到大，第 i 个值最多贡献 `min(usageLimits[i], k)` 次（因为每组最多用 1 次某个值，k 组最多用 k 次），检查是否能满足总需求。

## Python 代码实现

### 方法一：二分 + 贪心验证（推荐）

```python
from typing import List

class Solution:
    def maxIncreasingGroups(self, usageLimits: List[int]) -> int:
        usageLimits.sort()
        n = len(usageLimits)

        def canForm(k: int) -> bool:
            # 检查是否能创建 k 组（长度 1,2,...,k，总需求 k*(k+1)/2）
            # 排序后贪心：第 i 个值最多使用 min(usageLimits[i], k) 次
            total = k * (k + 1) // 2
            available = sum(min(u, k) for u in usageLimits)
            return available >= total

        # 二分最大组数
        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if canForm(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

### 方法二：贪心直接求解

```python
from typing import List

class Solution:
    def maxIncreasingGroups(self, usageLimits: List[int]) -> int:
        usageLimits.sort()
        ans = 0
        surplus = 0  # 多余的使用次数

        for u in usageLimits:
            surplus += u
            # 如果多余次数 >= 下一组所需长度 (ans + 1)
            if surplus >= ans + 1:
                surplus -= (ans + 1)
                ans += 1

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)
- 方法二：时间复杂度 O(n log n)（排序）
- 空间复杂度：O(1)

## 关键点总结

1. 排序后贪心，使用限制多的值灵活支持多个组
2. 方法二维护"结余"：当结余 >= 下一组长度时，创建新组

## 易错点

1. 每组的整数各不相同（同一组内不重复）
2. 组内整数可以在不同组之间共用（不同组可以有相同整数）
