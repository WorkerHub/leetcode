## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的字母异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

**示例 1：**
```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的字母异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的字母异位词。
```

**示例 2：**
```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的字母异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的字母异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的字母异位词。
```

**提示：**
- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

## 解题思路

这道题要求找到所有字母异位词的位置。核心思想是使用滑动窗口 + 哈希表。

**关键观察：**
1. 字母异位词意味着字符频率相同
2. 窗口大小固定为 `len(p)`
3. 使用滑动窗口维护当前窗口的字符频率

**算法流程：**
1. 统计 `p` 的字符频率
2. 使用固定大小的滑动窗口遍历 `s`
3. 维护窗口内的字符频率
4. 当窗口频率与 `p` 的频率相同时，记录起始位置

## Python 代码实现

### 方法一：滑动窗口 + 哈希表 ⭐ 推荐

```python
from typing import List
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        result = []
        p_len = len(p)
        s_len = len(s)
        
        if s_len < p_len:
            return result
        
        # 统计 p 的字符频率
        p_count = Counter(p)
        # 窗口字符频率
        window_count = Counter()
        
        # 初始化窗口
        for i in range(p_len):
            window_count[s[i]] += 1
        
        # 检查第一个窗口
        if window_count == p_count:
            result.append(0)
        
        # 滑动窗口
        for i in range(p_len, s_len):
            # 加入右边的字符
            window_count[s[i]] += 1
            
            # 移除左边的字符
            left_char = s[i - p_len]
            window_count[left_char] -= 1
            if window_count[left_char] == 0:
                del window_count[left_char]
            
            # 检查是否匹配
            if window_count == p_count:
                result.append(i - p_len + 1)
        
        return result
```

### 方法二：数组计数（更快）

```python
from typing import List

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        result = []
        p_len = len(p)
        s_len = len(s)
        
        if s_len < p_len:
            return result
        
        # 使用数组代替哈希表（只有26个字母）
        p_count = [0] * 26
        window_count = [0] * 26
        
        # 统计 p 的字符频率
        for char in p:
            p_count[ord(char) - ord('a')] += 1
        
        # 初始化窗口
        for i in range(p_len):
            window_count[ord(s[i]) - ord('a')] += 1
        
        # 检查第一个窗口
        if window_count == p_count:
            result.append(0)
        
        # 滑动窗口
        for i in range(p_len, s_len):
            # 加入右边的字符
            window_count[ord(s[i]) - ord('a')] += 1
            # 移除左边的字符
            window_count[ord(s[i - p_len]) - ord('a')] -= 1
            
            # 检查是否匹配
            if window_count == p_count:
                result.append(i - p_len + 1)
        
        return result
```

### 方法三：优化版（减少比较次数）

```python
from typing import List

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        result = []
        p_len = len(p)
        s_len = len(s)
        
        if s_len < p_len:
            return result
        
        p_count = [0] * 26
        window_count = [0] * 26
        
        for char in p:
            p_count[ord(char) - ord('a')] += 1
        
        # 记录有多少个字符频率匹配
        match_count = 0
        
        for i in range(s_len):
            # 加入右边的字符
            right_idx = ord(s[i]) - ord('a')
            window_count[right_idx] += 1
            
            if window_count[right_idx] == p_count[right_idx]:
                match_count += 1
            elif window_count[right_idx] == p_count[right_idx] + 1:
                match_count -= 1
            
            # 如果窗口大小超过 p_len，移除左边的字符
            if i >= p_len:
                left_idx = ord(s[i - p_len]) - ord('a')
                window_count[left_idx] -= 1
                
                if window_count[left_idx] == p_count[left_idx]:
                    match_count += 1
                elif window_count[left_idx] == p_count[left_idx] - 1:
                    match_count -= 1
            
            # 如果所有字符频率都匹配
            if match_count == 26:
                result.append(i - p_len + 1)
        
        return result
```

## 复杂度分析

**方法一：Counter**
- 时间复杂度：O(n)，n 是字符串 s 的长度
  - 滑动窗口遍历一次
  - Counter 比较是 O(26) = O(1)
- 空间复杂度：O(1)，固定26个字母

**方法二：数组**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法三：优化版**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 `s = "cbaebabacd", p = "abc"` 为例：

```
p = "abc" 的字符频率：
a: 1, b: 1, c: 1

滑动窗口过程：
窗口1: "cba" -> {c:1, b:1, a:1} ✓ 匹配，索引0
窗口2: "bae" -> {b:1, a:1, e:1} ✗
窗口3: "aeb" -> {a:1, e:1, b:1} ✗
窗口4: "eba" -> {e:1, b:1, a:1} ✗
窗口5: "bab" -> {b:2, a:1} ✗
窗口6: "aba" -> {a:2, b:1} ✗
窗口7: "bac" -> {b:1, a:1, c:1} ✓ 匹配，索引6
窗口8: "acd" -> {a:1, c:1, d:1} ✗

结果：[0, 6]
```

## 关键点总结

1. **滑动窗口**：固定大小的窗口，O(1) 时间移动
2. **字符频率**：使用哈希表或数组记录频率
3. **窗口更新**：加入右边字符，移除左边字符
4. **快速比较**：数组比较比 Counter 更快
5. **优化技巧**：用 match_count 减少比较次数

## 易错点

1. **窗口大小**：窗口大小固定为 `len(p)`
2. **索引计算**：起始索引是 `i - p_len + 1`
3. **初始窗口**：要先处理第一个窗口
4. **频率为0**：Counter 中频率为0的key要删除
5. **边界情况**：s 比 p 短时直接返回空列表
