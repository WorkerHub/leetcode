## 题目描述

给你两个字符串数组 `words1` 和 `words2`，返回在两个数组中都**恰好出现一次**的单词数目。

**示例：**
```
输入：words1 = ["leetcode","is","amazing","as","is"], words2 = ["amazing","leetcode","is"]
输出：2
解释：
- "leetcode" 在 words1 出现 1 次，在 words2 出现 1 次 → 满足
- "amazing" 在 words1 出现 1 次，在 words2 出现 1 次 → 满足
- "is" 在 words1 出现 2 次 → 不满足
```

**提示：**
- `1 <= words1.length, words2.length <= 1000`
- `1 <= words1[i].length, words2[i].length <= 10`

## 解题思路

用 `Counter` 统计每个单词在两个数组中的出现次数，然后统计两个 Counter 中频次都为 1 的单词。

## 代码实现

### 方法一：Counter 计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countWords(self, words1: List[str], words2: List[str]) -> int:
        c1 = Counter(words1)
        c2 = Counter(words2)

        # 统计在两个数组中均恰好出现 1 次的单词数
        return sum(1 for w in c1 if c1[w] == 1 and c2[w] == 1)
```

### 方法二：集合交集

```python
from typing import List
from collections import Counter

class Solution:
    def countWords(self, words1: List[str], words2: List[str]) -> int:
        c1 = Counter(words1)
        c2 = Counter(words2)

        # 各自恰好出现 1 次的集合取交集
        once1 = {w for w, cnt in c1.items() if cnt == 1}
        once2 = {w for w, cnt in c2.items() if cnt == 1}

        return len(once1 & once2)
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 和 m 分别是两个数组的长度
- 空间复杂度：O(n + m)，存储两个 Counter

## 关键点总结

1. 分别统计两个数组中各单词的出现次数
2. 找出两边出现次数**都为 1** 的单词
3. `Counter` 对不存在的键返回 0，`c2[w]` 即使 w 不在 c2 中也安全

## 易错点

- 注意：不是找两数组的公共单词，而是两数组中各**恰好出现 1 次**的公共单词
- 如果 w 不在 c2 中，`c2[w] == 0 != 1`，自然不被计入
