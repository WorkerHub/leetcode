## 题目描述

有一棵根节点为 `1` 的 `n` 个节点的无向树。这棵树的节点编号为 `1` 到 `n`。

给你一个整数 `n`，另外还有一个空数组 `queries`，该数组包含若干次查询，每次查询给定一个节点编号 `v`，将以 `v` 为根的子树中的所有节点取反（0 变 1，1 变 0）。

所有节点初始值为 0。

处理所有 `queries` 后，返回值为 1 的节点数目。

**树的结构：** 对于每个节点 `v`，其左子节点为 `2v`，右子节点为 `2v+1`（满二叉树）。

**提示：**
- `1 <= n <= 10^5`
- `1 <= queries.length <= 10^5`
- `1 <= queries[i] <= n`

## 解题思路

**统计每个节点被取反的次数：**

对于每次查询 `v`，以 `v` 为根的子树中所有节点都被取反一次。

**关键观察：** 节点 `u` 在以 `v` 为根的子树中，等价于 `v` 是 `u` 的祖先（或 `u = v`）。

**方法：** 对每个节点 `u`，统计 `queries` 中有多少个 `v` 是 `u` 的祖先（含自身）。若次数为奇数，则最终值为 1。

计数方式：先统计每个 query 节点被查询的次数，然后 DFS 时从根到叶子方向传递计数。

## 代码实现

### 方法一：DFS 传递计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def numberOfNodes(self, n: int, queries: List[int]) -> int:
        # 统计每个 query 节点被查询的次数
        query_count = Counter(queries)
        ans = 0

        # DFS，flip_count 表示当前路径上累积的取反次数
        def dfs(node: int, flips: int) -> None:
            nonlocal ans
            if node > n:
                return
            # 当前节点被取反的总次数
            flips += query_count.get(node, 0)
            if flips % 2 == 1:
                ans += 1
            dfs(2 * node, flips)      # 左子节点
            dfs(2 * node + 1, flips)  # 右子节点

        dfs(1, 0)
        return ans
```

### 方法二：BFS 层序遍历

```python
from typing import List
from collections import Counter, deque

class Solution:
    def numberOfNodes(self, n: int, queries: List[int]) -> int:
        query_count = Counter(queries)
        ans = 0

        # BFS，(节点编号, 当前翻转次数)
        queue = deque([(1, 0)])

        while queue:
            node, flips = queue.popleft()
            if node > n:
                continue
            flips += query_count.get(node, 0)
            if flips % 2 == 1:
                ans += 1
            queue.append((2 * node, flips))
            queue.append((2 * node + 1, flips))

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS | O(n + q) | O(n + q) |
| BFS | O(n + q) | O(n + q) |

## 关键点总结

1. 节点 `u` 的最终值 = 祖先路径上所有 query 次数之和的奇偶性
2. DFS 时从上到下传递翻转次数，O(n) 完成所有节点的判断
3. 满二叉树中，节点 v 的子节点为 2v 和 2v+1

## 易错点

- DFS 中要用非局部变量（`nonlocal ans`）更新答案
- 查询次数可能 > 1，同一节点被多次查询要累计
