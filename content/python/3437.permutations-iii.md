## 题目描述

给你一个正整数 `n`，生成 `[1, n]` 的所有**无相邻元素相差为 1**（即没有两个相邻元素之差的绝对值为 1）的排列。

返回所有满足条件的排列，按字典序排列。

**示例 1：**

```
输入：n = 3
输出：[[1,3,2],[2,3,1],[3,1,2],[3,2,1]]... 需要验证
等等，[1,3,2]：|1-3|=2, |3-2|=1 不满足
实际：[2,1,3] -> |2-1|=1 不满足...
```

**示例 2：**

```
输入：n = 4
输出：[[1,3,1,...], ...]
```

**提示：**
- `1 <= n <= 8`

## 解题思路

回溯法：生成 [1, n] 的所有排列，过滤掉相邻差为 1 的情况。

在回溯时，选择下一个元素时提前剪枝：若当前最后一个元素是 `last`，则不能选 `last-1` 或 `last+1`。

## Python 代码实现

### 方法一：回溯 + 剪枝（推荐）

```python
from typing import List

class Solution:
    def permute(self, n: int) -> List[List[int]]:
        result = []
        used = [False] * (n + 1)
        current = []

        def backtrack():
            if len(current) == n:
                result.append(current[:])
                return

            for num in range(1, n + 1):
                if used[num]:
                    continue
                # 剪枝：与上一个元素差不能为 1
                if current and abs(current[-1] - num) == 1:
                    continue
                used[num] = True
                current.append(num)
                backtrack()
                current.pop()
                used[num] = False

        backtrack()
        return result
```

### 方法二：生成全排列后过滤

```python
from typing import List
from itertools import permutations

class Solution:
    def permute(self, n: int) -> List[List[int]]:
        result = []

        for perm in permutations(range(1, n + 1)):
            valid = True
            for i in range(len(perm) - 1):
                if abs(perm[i] - perm[i + 1]) == 1:
                    valid = False
                    break
            if valid:
                result.append(list(perm))

        return sorted(result)
```

### 方法三：递归生成（更清晰）

```python
from typing import List

class Solution:
    def permute(self, n: int) -> List[List[int]]:
        result = []

        def bt(path, remaining):
            if not remaining:
                result.append(path[:])
                return
            for v in sorted(remaining):
                if path and abs(path[-1] - v) == 1:
                    continue
                path.append(v)
                remaining.remove(v)
                bt(path, remaining)
                remaining.add(v)
                path.pop()

        bt([], set(range(1, n + 1)))
        return result
```

## 复杂度分析

- 时间复杂度：O(n! * n)，生成所有排列并检验
- 空间复杂度：O(n)，递归深度

## 关键点总结

1. 回溯时提前剪枝：当前末尾元素与候选元素差为 1 时跳过
2. 按字典序生成（从 1 到 n 依次尝试）结果自然有序
3. 相比先生成再过滤，回溯剪枝效率更高

## 易错点

1. 条件是相邻差的绝对值为 1（不是等于 1），注意用 `abs()`
2. 只限制**相邻**元素，不是所有元素对
3. n=1 时只有一个排列 [1]，满足条件
