## 题目描述

给你一个 `m x n` 的字符矩阵 `box`，表示一个侧放的箱子。`box[i][j]` 为：
- `'#'` 表示石头
- `'*'` 表示固定障碍物
- `'.'` 表示空位

箱子旋转 90 度（顺时针），石头会因重力向下落。将箱子顺时针旋转 90 度后，石头因重力落到最低处（障碍物阻挡）。

返回旋转后的矩阵。

**示例：**
```
输入：box = [["#",".","#"]]
输出：[["."],["#"],["#"]]
```

## 解题思路

**两步操作**：

1. **重力模拟**：对每行，石头向右移动（因为旋转后向下等价于旋转前向右）。用双指针：`empty` 指向最右侧的空位，从右往左扫描，遇到石头就移到 `empty` 位置，遇到障碍物重置 `empty`。

2. **矩阵旋转**：顺时针旋转 90 度后，`matrix[j][m-1-i]` = 原来的 `matrix[i][j]`（m 为原矩阵行数）。

## 代码实现

### 方法一：先重力后旋转（推荐）

```python
from typing import List

class Solution:
    def rotateTheBox(self, box: List[List[str]]) -> List[List[str]]:
        m, n = len(box), len(box[0])

        # 第一步：模拟重力（石头向右落）
        for row in box:
            empty = n - 1  # 空位指针，从右往左
            for j in range(n - 1, -1, -1):
                if row[j] == '#':
                    # 将石头移到最右的空位
                    row[j] = '.'
                    row[empty] = '#'
                    empty -= 1
                elif row[j] == '*':
                    # 遇到障碍物，更新空位指针
                    empty = j - 1

        # 第二步：顺时针旋转 90 度
        # 旋转后矩阵大小为 n x m
        result = [[None] * m for _ in range(n)]
        for i in range(m):
            for j in range(n):
                result[j][m - 1 - i] = box[i][j]

        return result
```

### 方法二：分离步骤（含详细注释）

```python
from typing import List

class Solution:
    def rotateTheBox(self, box: List[List[str]]) -> List[List[str]]:
        m, n = len(box), len(box[0])

        # 对每行模拟重力
        for i in range(m):
            empty = n - 1
            for j in range(n - 1, -1, -1):
                if box[i][j] == '*':
                    empty = j - 1  # 障碍物左侧重新开始
                elif box[i][j] == '#':
                    box[i][j], box[i][empty] = box[i][empty], box[i][j]
                    empty -= 1

        # 顺时针旋转：新矩阵 [j][m-1-i] = 旧矩阵 [i][j]
        return [[box[m - 1 - i][j] for i in range(m)] for j in range(n)]
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)，结果矩阵

## 关键点总结

1. 重力方向是箱子的"右"（因为旋转后变为"下"），从右往左扫描每行
2. 障碍物会重置空位指针到其左侧
3. 顺时针旋转公式：`result[j][m-1-i] = box[i][j]`

## 易错点

- 重力是向右（旋转前的方向），不是向下
- 旋转后矩阵大小为 n x m（行列互换）
- 遇到障碍物时，空位指针更新为 `j - 1`（障碍物不能越过）
