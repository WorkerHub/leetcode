## 题目描述

有台奇怪的打印机有以下两个特殊要求：

1. 打印机每次只能打印由**同一个字符**组成的序列。
2. 每次可以在从起始到结束的任意位置打印新字符，并且会覆盖掉原来已有的字符。

给你一个字符串 `s`，你的任务是计算这个打印机打印它需要的最少打印次数。

**示例 1:**

```
输入：s = "aaabbb"
输出：2
解释：首先打印 "aaa"，然后打印 "bbb"
```

**示例 2:**

```
输入：s = "aba"
输出：2
解释：首先打印 "aaa"，然后在第二个位置打印 "b" 覆盖掉原来的字符 'a'
```

**提示:**
- `1 <= s.length <= 100`
- `s` 由小写英文字母组成

## 解题思路

这是一道经典的**区间 DP** 问题。

### 核心思想

定义 `dp[i][j]`：打印字符串 `s[i:j+1]` 所需的最少次数。

**状态转移：**

1. **基础情况**：单个字符只需打印一次，`dp[i][i] = 1`

2. **相同首尾**：如果 `s[i] == s[j]`
   - 可以在打印 `s[i:j]` 时一起打印 `s[j]`
   - `dp[i][j] = dp[i][j-1]`

3. **不同首尾**：枚举分割点 k
   - `dp[i][j] = min(dp[i][k] + dp[k+1][j])` for k in range(i, j)

## Python 代码实现

### 方法一：区间 DP（推荐）⭐

```python
class Solution:
    def strangePrinter(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        
        # 从右往左，从下往上填表
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                # 最坏情况：每个字符打印一次
                dp[i][j] = dp[i][j - 1] + 1
                
                # 如果首尾相同，可以一起打印
                if s[i] == s[j]:
                    dp[i][j] = dp[i][j - 1]
                
                # 尝试分割
                for k in range(i, j):
                    dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j])
        
        return dp[0][n - 1]
```

### 方法二：记忆化搜索

```python
class Solution:
    def strangePrinter(self, s: str) -> int:
        from functools import lru_cache
        
        @lru_cache(None)
        def dp(i, j):
            if i > j:
                return 0
            if i == j:
                return 1
            
            result = dp(i, j - 1) + 1
            
            for k in range(i, j):
                if s[k] == s[j]:
                    result = min(result, dp(i, k) + dp(k + 1, j - 1))
            
            return result
        
        return dp(0, len(s) - 1)
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：子问题是区间
2. **首尾相同**：可以优化
3. **分割策略**：枚举所有可能

## 易错点

1. DP 初始化
2. 循环顺序
3. 边界条件
