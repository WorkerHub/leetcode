## 题目描述

给你 `n` 种金属、`k` 台机器，以及制造每种合金需要每种金属的数量。

每台机器 `i` 制造 1 单位合金需要 `composition[i][j]` 个第 j 种金属。

你有 `stock[j]` 个第 j 种金属，可以以 `cost[j]` 的价格购买额外的第 j 种金属，预算为 `budget`。

每次只能用**一台机器**制造合金。返回能制造的**最多合金数量**。

**示例 1：**
```
输入：n = 3, k = 2, budget = 15,
composition = [[1,1,1],[1,1,10]],
stock = [0,0,0],
cost = [1,2,3]
输出：2
解释：用机器 0：每个合金需 1+1+1=3 种金属，花费 1+2+3=6，预算 15 可造 2 个（花费 12）
```

**提示：**
- `1 <= n, k <= 100`
- `0 <= budget <= 10^8`
- `1 <= composition[i][j], cost[j] <= 100`
- `0 <= stock[j] <= 10^8`

## 解题思路

**二分答案：** 二分制造数量 `mid`，检查能否用某台机器在预算内制造 `mid` 个合金。

对于机器 i 制造 `mid` 个合金：
- 第 j 种金属需要 `composition[i][j] * mid` 个
- 现有 `stock[j]` 个，还需要购买 `max(0, composition[i][j] * mid - stock[j])` 个
- 购买费用 = `sum(max(0, need - stock[j]) * cost[j])`

若费用 <= budget，则可行。

## Python 代码实现

### 方法一：二分答案（推荐）

```python
from typing import List

class Solution:
    def maxNumberOfAlloys(self, n: int, k: int, budget: int,
                          composition: List[List[int]],
                          stock: List[int], cost: List[int]) -> int:

        def can_make(amount: int) -> bool:
            """检查能否用任意一台机器制造 amount 个合金"""
            for machine in composition:
                total_cost = 0
                feasible = True
                for j in range(n):
                    need = machine[j] * amount
                    extra = max(0, need - stock[j])
                    total_cost += extra * cost[j]
                    if total_cost > budget:
                        feasible = False
                        break
                if feasible:
                    return True
            return False

        # 二分查找最大数量
        lo, hi = 0, 10**9  # 理论最大值
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_make(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

### 方法二：带注释的详细版

```python
from typing import List

class Solution:
    def maxNumberOfAlloys(self, n: int, k: int, budget: int,
                          composition: List[List[int]],
                          stock: List[int], cost: List[int]) -> int:

        def feasible(amount: int) -> bool:
            for i in range(k):
                cost_total = 0
                ok = True
                for j in range(n):
                    # 制造 amount 个需要的第 j 种金属
                    needed = composition[i][j] * amount
                    # 超出库存的部分需要购买
                    shortage = needed - stock[j]
                    if shortage > 0:
                        cost_total += shortage * cost[j]
                    if cost_total > budget:
                        ok = False
                        break
                if ok:
                    return True
            return False

        lo, hi = 1, max(
            # 最乐观估计：全用最便宜的金属和最多库存
            (stock[0] + budget) // max(composition[i][0] for i in range(k))
            for _ in [0]
        )
        # 简单上界
        hi = 2 * 10**8

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo if feasible(lo) else 0
```

## 复杂度分析

- 时间复杂度：O(n × k × log(max_ans))，二分 O(log max_ans) 次，每次检查 O(nk)
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案：单调性——能造 x 个，也能造 < x 个
2. 每次检查：枚举每台机器，计算购买费用是否 <= budget
3. 上界可以估算：最多 `(max_stock + budget / min_cost) / min_composition`

## 易错点

1. 二分时使用 `mid = (lo + hi + 1) // 2`（向上取整）防止死循环
2. 检查时对每台机器独立计算，找到任一可行的即返回 true
3. `amount = 0` 时总是可行（不需要任何材料），但一般二分从 1 开始
