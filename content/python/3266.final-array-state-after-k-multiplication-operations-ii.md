## 题目描述

与 3264 相同，但数据范围更大：
- `1 <= nums.length <= 10^4`
- `1 <= k <= 10^9`
- `1 <= multiplier <= 10^6`

结果对 `10^9 + 7` 取模。

## 解题思路

直接模拟 k 次操作会超时（k 最大 10^9）。

关键观察：
1. 前若干次操作，最小值会快速增大，直到所有元素大小相近
2. 一旦所有元素大小相同（模 multiplier 的某种周期），每一轮 n 次操作会对所有元素各乘一次 multiplier（以轮次为单位）

具体步骤：
1. 用最小堆模拟，直到所有元素最大与最小之比 < multiplier（约 n * log(max/min / n) 次操作）
2. 之后，剩余的 k 次操作形成完整轮次，每轮 n 次，每个元素额外乘 multiplier^floor 或 multiplier^ceil 次
3. 用快速幂计算

## Python 代码实现

### 方法一：堆模拟 + 快速幂（推荐）

```python
from typing import List
import heapq

class Solution:
    def getFinalState(self, nums: List[int], k: int, multiplier: int) -> List[int]:
        MOD = 10**9 + 7
        n = len(nums)
        
        if multiplier == 1:
            return [x % MOD for x in nums]
        
        # 使用最小堆模拟
        heap = [(v, i) for i, v in enumerate(nums)]
        heapq.heapify(heap)
        
        result = nums[:]
        
        # 第一阶段：模拟直到所有元素均衡
        # 一旦最大值 <= 最小值 * multiplier，进入均衡状态
        # 最多模拟 n * ceil(log_multiplier(max/min)) 步
        
        ops = 0
        while ops < k:
            min_val, min_idx = heap[0]
            # 检查是否均衡
            max_val = max(result)
            if max_val <= min_val * multiplier:
                break
            val, idx = heapq.heappop(heap)
            result[idx] = val * multiplier
            heapq.heappush(heap, (val * multiplier, idx))
            ops += 1
        
        remaining = k - ops
        if remaining == 0:
            return [x % MOD for x in result]
        
        # 第二阶段：均衡后按顺序处理
        # 重新按(值, 下标)排序
        order = sorted(range(n), key=lambda i: (result[i], i))
        
        # remaining 次操作，前 remaining % n 个按顺序多乘一次
        base_power = remaining // n  # 每个元素至少乘 multiplier^base_power 次
        extra = remaining % n        # 前 extra 个（排序后）再多乘一次
        
        for rank, i in enumerate(order):
            exp = base_power + (1 if rank < extra else 0)
            result[i] = result[i] % MOD * pow(multiplier, exp, MOD) % MOD
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n log n * log(max_val) + n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先模拟直到均衡（所有元素值相近），再按数学公式批量计算
2. 均衡后，排序靠前的元素多乘一次
3. 快速幂计算大指数的取模结果

## 易错点

1. multiplier = 1 时直接返回（不会改变）
2. 均衡阶段模拟次数不能太多，要有合理的退出条件
3. 快速幂的取模不要忘记
