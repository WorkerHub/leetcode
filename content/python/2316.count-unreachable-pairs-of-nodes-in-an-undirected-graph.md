## 题目描述

给你一个整数 `n`，表示一个**无向图**中的节点数目，节点编号从 `0` 到 `n - 1`。同时给你一个二维整数数组 `edges`，其中 `edges[i] = [a_i, b_i]` 表示节点 `a_i` 和 `b_i` 之间存在一条**无向**边。

请你返回**无法互相到达**的不同**点对数目**。

**示例 1：**
```
输入：n = 7, edges = [[0,2],[0,5],[2,4],[1,6],[5,4]]
输出：14
解释：共有 3 个连通分量，大小分别为 {0,2,4,5}、{1,6}、{3}。
14 = 4*2 + 4*1 + 2*1 = 8+4+2 = 14
```

**提示：**
- `1 <= n <= 10^5`
- `0 <= edges.length <= 2 * 10^5`

## 解题思路

计算各连通分量的大小，若分量大小为 `[s1, s2, ..., sk]`，则不可达点对数为：
`total_pairs - sum(s_i * (s_i - 1) / 2)`

即总点对数减去可达点对数。等价地，遍历每个分量时，用"之前所有分量的节点总数"乘以当前分量大小累加。

## 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, n: int, edges: List[List[int]]) -> int:
        parent = list(range(n))
        size = [1] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩
                x = parent[x]
            return x

        def union(x, y):
            rx, ry = find(x), find(y)
            if rx == ry:
                return
            if size[rx] < size[ry]:
                rx, ry = ry, rx
            parent[ry] = rx
            size[rx] += size[ry]

        for a, b in edges:
            union(a, b)

        ans = 0
        prev = 0  # 之前遍历的连通分量总节点数
        visited = set()
        for i in range(n):
            root = find(i)
            if root not in visited:
                visited.add(root)
                ans += prev * size[root]
                prev += size[root]

        return ans
```

### 方法二：DFS 计算连通分量

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        visited = [False] * n
        components = []

        def dfs(node):
            stack = [node]
            cnt = 0
            while stack:
                cur = stack.pop()
                if visited[cur]:
                    continue
                visited[cur] = True
                cnt += 1
                for nb in graph[cur]:
                    if not visited[nb]:
                        stack.append(nb)
            return cnt

        for i in range(n):
            if not visited[i]:
                components.append(dfs(i))

        # 计算不可达点对数
        ans = 0
        prev = 0
        for sz in components:
            ans += prev * sz
            prev += sz

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 | O((n + m) * alpha(n)) | O(n) |
| DFS | O(n + m) | O(n + m) |

其中 m 为边数。

## 关键点总结

1. 不可达点对 = 不同连通分量之间的节点对数。
2. 若连通分量大小为 `s1, s2, ...`，不可达对数为 `sum(si * sj)` 其中 i != j，等价于 `prev * si` 累加。
3. 利用并查集高效找连通分量及大小。

## 易错点

- 答案可能超出 int 范围（n 最大 10^5），Python 自动处理大整数，其他语言需用 long。
- 并查集中要正确维护 size 数组，合并时只更新根节点的 size。
