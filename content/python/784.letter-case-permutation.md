## 题目描述

给定一个字符串 `s`，通过将字符串 `s` 中的每个字母转变大小写，我们可以获得一个新的字符串。

返回所有可能得到的字符串集合。以任意顺序返回输出。

**示例 1：**
```
输入：s = "a1b2"
输出：["a1b2","a1B2","A1b2","A1B2"]
```

**示例 2：**
```
输入：s = "3z4"
输出：["3z4","3Z4"]
```

**提示：**
- 1 <= s.length <= 12
- s 由小写英文字母、大写英文字母和数字组成

## 解题思路

这是一个典型的**回溯**问题，也可以用**位运算**或**迭代**方法解决。核心思想是：

1. **遍历字符串**：对于每个字符，判断是字母还是数字
2. **字母有两种选择**：保持原样或转换大小写
3. **数字只有一种选择**：保持不变
4. **递归/迭代生成所有组合**

假设字符串中有 k 个字母，最终会生成 2^k 个字符串。

**三种解法思路：**
- **回溯法**：递归枚举每个字母的大小写情况
- **迭代法**：从空集合开始，每遇到一个字母就把现有结果翻倍
- **位运算法**：用二进制的每一位表示字母的大小写选择

## Python 代码实现

### 方法一：回溯法（推荐，最直观）

```python
from typing import List

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        result = []
        
        def backtrack(index: int, path: List[str]):
            # 递归终止条件：遍历完所有字符
            if index == len(s):
                result.append(''.join(path))
                return
            
            char = s[index]
            
            if char.isalpha():
                # 字母：尝试小写
                path.append(char.lower())
                backtrack(index + 1, path)
                path.pop()
                
                # 字母：尝试大写
                path.append(char.upper())
                backtrack(index + 1, path)
                path.pop()
            else:
                # 数字：直接添加
                path.append(char)
                backtrack(index + 1, path)
                path.pop()
        
        backtrack(0, [])
        return result
```

### 方法二：迭代法（Python特色，简洁）

```python
from typing import List

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        result = ['']
        
        for char in s:
            if char.isalpha():
                # 遇到字母，将现有结果翻倍：一份加小写，一份加大写
                result = [prev + c for prev in result for c in [char.lower(), char.upper()]]
            else:
                # 遇到数字，直接添加
                result = [prev + char for prev in result]
        
        return result
```

### 方法三：位运算法（高效）

```python
from typing import List

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        # 找出所有字母的索引
        letters = [(i, c) for i, c in enumerate(s) if c.isalpha()]
        n = len(letters)
        result = []
        
        # 用位掩码枚举所有可能：0表示小写，1表示大写
        for mask in range(1 << n):  # 2^n 种组合
            chars = list(s)
            for i in range(n):
                index, char = letters[i]
                if mask & (1 << i):
                    chars[index] = char.upper()
                else:
                    chars[index] = char.lower()
            result.append(''.join(chars))
        
        return result
```

### 方法四：BFS队列法

```python
from typing import List
from collections import deque

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        queue = deque([''])
        
        for char in s:
            size = len(queue)
            for _ in range(size):
                current = queue.popleft()
                
                if char.isalpha():
                    # 字母：添加两种情况
                    queue.append(current + char.lower())
                    queue.append(current + char.upper())
                else:
                    # 数字：只添加一种
                    queue.append(current + char)
        
        return list(queue)
```

## 复杂度分析

设字符串长度为 n，其中有 k 个字母。

- **时间复杂度：** O(n × 2^k)
  - 生成 2^k 个字符串
  - 每个字符串长度为 n
  
- **空间复杂度：** O(n × 2^k)
  - 存储所有结果
  - 回溯法的递归栈深度为 O(n)

## 关键点总结

1. **识别问题类型**：排列组合问题，每个字母有两种状态
2. **回溯三要素**：选择列表（大小写）、路径（当前字符串）、结束条件（遍历完成）
3. **迭代思想**：可以从空字符串开始，逐步扩展
4. **位运算优化**：用二进制位表示每个字母的大小写选择
5. **字符判断**：使用 `isalpha()` 判断字母，`isdigit()` 判断数字

## 易错点

1. **忘记处理数字**：数字不需要转换，直接添加
2. **大小写转换**：使用 `lower()` 和 `upper()` 方法，不要手动ASCII转换
3. **重复结果**：如果原字符串同时包含大小写，要注意去重（本题不需要）
4. **空字符串**：题目保证 `s.length >= 1`，但要注意边界
