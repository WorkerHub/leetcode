## 题目描述

给你一个由小写英文字母组成的字符串 `s`，每次操作可以将任意一个字符替换为其他字符。将 `s` 变成回文串所需的最少操作次数，且结果在所有方案中字典序最小。

返回操作后的字符串。

**示例 1：**
```
输入：s = "egcfe"
输出："efcfe"
解释：将 'g' 改为 'f' 得到回文串 "efcfe"
```

**示例 2：**
```
输入：s = "abcd"
输出："abba"
```

**示例 3：**
```
输入：s = "seven"
输出："neven"
解释：改 s[0] 为 'n'，得到 "neven"
```

**数据范围：**
- 1 <= s.length <= 1000

## 解题思路

贪心双指针：对每对对称位置 `(i, n-1-i)`：
- 若两字符相同，不需要操作
- 若不同，将**较大的那个**替换为**较小的那个**（这样字典序最小且只需一次操作）

## Python 代码实现

### 方法一：双指针贪心（推荐）

```python
class Solution:
    def makeSmallestPalindrome(self, s: str) -> str:
        arr = list(s)
        n = len(s)
        left, right = 0, n - 1

        while left < right:
            if arr[left] != arr[right]:
                # 将较大的替换为较小的（字典序最小）
                smaller = min(arr[left], arr[right])
                arr[left] = arr[right] = smaller
            left += 1
            right -= 1

        return ''.join(arr)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（字符数组）

## 关键点总结

1. 双指针从两端向中间，每次处理一对对称位置
2. 贪心：取两者中较小的字符，同时满足回文和字典序最小
3. 奇数长度时中间字符无需处理

## 易错点

1. 必须将两端都改为较小值，而非较大值
2. 奇数长度时中间位置跳过
