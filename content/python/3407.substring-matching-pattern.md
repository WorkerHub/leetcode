## 题目描述

给你一个字符串 `s` 和一个模式字符串 `p`，其中 `p` 恰好包含一个 `'*'`。

`'*'` 可以匹配任意字符序列（包括空序列）。

如果 `p` 可以匹配 `s` 的某个子字符串，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：s = "leetcode", p = "ee*e"
输出：true
解释：p 中 '*' 匹配空字符串，"eee" 可以在 s 中找到
等等，"ee" + "" + "e" = "eee"，但 s 中有 "eet"，所以 "ee*e" 匹配 "eete"（'*' 匹配 't'）
```

**示例 2：**

```
输入：s = "car", p = "c*v"
输出：false
```

**示例 3：**

```
输入：s = "luck", p = "u*"
输出：true
```

**提示：**
- `1 <= s.length <= 50`
- `1 <= p.length <= 50`
- `p` 恰好包含一个 `'*'`
- `s` 和 `p` 只包含小写英文字母和 `'*'`

## 解题思路

将模式 `p` 按 `'*'` 分为前缀 `prefix` 和后缀 `suffix`。

需要在 `s` 中找到一个子串，使得：
1. 该子串以 `prefix` 开头
2. 该子串以 `suffix` 结尾
3. 前缀和后缀没有重叠（即子串长度 >= len(prefix) + len(suffix)）

逐个尝试 `s` 中所有可能的起始位置即可。

## Python 代码实现

### 方法一：分割模式串逐位检查（推荐）

```python
class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        # 按 '*' 分割模式串
        star_idx = p.index('*')
        prefix = p[:star_idx]   # '*' 前面的部分
        suffix = p[star_idx + 1:]  # '*' 后面的部分

        # 枚举 s 中前缀的起始位置
        n = len(s)
        lp = len(prefix)
        ls = len(suffix)

        for i in range(n - lp - ls + 1):
            # 检查从 i 开始是否匹配 prefix
            if s[i: i + lp] == prefix:
                # 检查在 prefix 结束后，s 的剩余部分是否以 suffix 结尾
                remaining_start = i + lp
                remaining = s[remaining_start:]
                if remaining.endswith(suffix):
                    return True

        return False
```

### 方法二：使用 find 和 endswith

```python
class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        star_idx = p.index('*')
        prefix = p[:star_idx]
        suffix = p[star_idx + 1:]

        # 找前缀在 s 中的位置
        start = s.find(prefix)
        if start == -1:
            return False

        # 在前缀之后的部分中找后缀
        after_prefix = s[start + len(prefix):]
        return after_prefix.endswith(suffix)
```

### 方法三：正则表达式（简洁版）

```python
import re

class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        # 将 '*' 替换为正则的 '.*'
        pattern = re.escape(p).replace(r'\*', '.*')
        # 在 s 中搜索匹配的子串
        return bool(re.search(pattern, s))
```

## 复杂度分析

- 方法一：
  - 时间复杂度：O(n * (lp + ls))，n 为 s 的长度
  - 空间复杂度：O(lp + ls)

- 方法二：
  - 时间复杂度：O(n)
  - 空间复杂度：O(n)

## 关键点总结

1. `'*'` 匹配任意长度（含空）的字符串，所以只需要 prefix 出现在 suffix 之前
2. 在 prefix 找到之后，只需要检查后续部分是否以 suffix 结尾
3. 前缀和后缀不能重叠：要求 `start + len(prefix) + len(suffix) <= len(s)`，Python 的 `endswith` 自动处理这点

## 易错点

1. 前缀和后缀可以都为空（`p = "*"`），此时任何字符串都匹配
2. 方法二中，find 只找第一个匹配，但 `'*'` 具有贪心性，第一个 prefix 位置就足够（因为越靠前匹配，后缀有更多空间）
3. 注意 suffix 为空时，`endswith("")` 返回 True
