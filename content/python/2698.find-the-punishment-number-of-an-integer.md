## 题目描述

给你一个正整数 `n`，若 `i^2` 的字符串表示可以被分割为若干子字符串（连续数字），使得这些子字符串的整数值之和等于 `i`，则 `i` 满足条件（即 `i` 是"惩罚数"的组成部分）。

返回 `[1, n]` 范围内所有满足条件的整数的平方和，称为**惩罚数**。

**示例 1：**
```
输入：n = 10
输出：182
解释：满足条件的 i = 1, 9, 10：
  1^2 = 1，分割为 [1]，和 = 1 = i
  9^2 = 81，分割为 [8,1]，和 = 9 = i
  10^2 = 100，分割为 [10,0] 或 [1,0,0]，和 = 10 = i
1 + 81 + 100 = 182
```

**数据范围：**
- 1 <= n <= 1000

## 解题思路

对每个 `i`，用回溯判断 `i^2` 的字符串是否存在一种分割，使各部分整数之和等于 `i`。

## Python 代码实现

### 方法一：回溯验证（推荐）

```python
class Solution:
    def punishmentNumber(self, n: int) -> int:
        def can_partition(s: str, target: int) -> bool:
            """判断字符串 s 是否可以分割使各部分之和等于 target"""
            def backtrack(idx: int, remaining: int) -> bool:
                if idx == len(s):
                    return remaining == 0
                for j in range(idx + 1, len(s) + 1):
                    num = int(s[idx:j])
                    if num > remaining:
                        break  # 剪枝：数值超过剩余目标
                    if backtrack(j, remaining - num):
                        return True
                return False

            return backtrack(0, target)

        total = 0
        for i in range(1, n + 1):
            if can_partition(str(i * i), i):
                total += i * i

        return total
```

### 方法二：递归简化版

```python
class Solution:
    def punishmentNumber(self, n: int) -> int:
        def check(s: str, i: int, target: int) -> bool:
            if i == len(s):
                return target == 0
            for j in range(i + 1, len(s) + 1):
                val = int(s[i:j])
                if val <= target and check(s, j, target - val):
                    return True
            return False

        return sum(i * i for i in range(1, n + 1) if check(str(i * i), 0, i))
```

## 复杂度分析

- 时间复杂度：O(n * 2^L)，L 为 `i^2` 的位数（最多 7 位），实际很快
- 空间复杂度：O(L)，递归深度

## 关键点总结

1. 对每个 `i`，验证 `i^2` 的字符串是否可分割使和等于 `i`
2. 回溯：枚举每个分割点，递归验证剩余部分
3. 剪枝：当前数值超过剩余目标时提前截止

## 易错点

1. 分割后的子字符串是连续的，不能跳跃
2. 0 开头的子字符串（如 "00"）代表 0，是合法的
3. 注意最后要返回平方和，不是满足条件的个数
