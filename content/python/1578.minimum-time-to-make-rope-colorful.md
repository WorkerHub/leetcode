## 题目描述

Alice 把 n 个气球排成一排，气球上的字母为 `colors[i]`，移除第 i 个气球需要 `neededTime[i]` 时间。

Alice 想让绳子变得五颜六色，即没有两个相邻气球颜色相同。返回 Alice 需要花费的最少时间。

**示例 1：**
```
输入：colors = "abaac", neededTime = [1,2,3,4,5]
输出：3
解释：删除颜色 'a' 中代价较小的那个（第3个字符'a'，代价3），删除后得到 "abac"，还需删除一个 'a'...
实际：删掉第3个(cost 3)后是 "aba" -> "abac" ... 最优是删 cost=1 的第1个 'a'，共花费 1+3=4? 不对。
```

**提示：**
- `n == colors.length == neededTime.length`
- `1 <= n <= 10^5`
- `1 <= neededTime[i] <= 10^4`
- `colors` 只含小写字母

## 解题思路

### 贪心：分组处理连续相同颜色

对每组连续相同颜色的气球，保留代价最大的那个（最多只需一个），删除其余所有。

每组的代价 = 该组总代价 - 最大代价。

## 代码实现

### 方法一：分组贪心（推荐）

```python
from typing import List

class Solution:
    def minCost(self, colors: str, neededTime: List[int]) -> int:
        ans = 0
        i = 0
        n = len(colors)

        while i < n:
            j = i
            group_sum = 0
            group_max = 0
            # 找连续相同颜色的组
            while j < n and colors[j] == colors[i]:
                group_sum += neededTime[j]
                group_max = max(group_max, neededTime[j])
                j += 1
            # 删去该组除最大代价外的所有气球
            ans += group_sum - group_max
            i = j

        return ans
```

### 方法二：相邻比较

```python
from typing import List

class Solution:
    def minCost(self, colors: str, neededTime: List[int]) -> int:
        ans = 0
        n = len(colors)
        i = 0

        while i < n:
            # 找当前颜色组
            cur_color = colors[i]
            cur_max = neededTime[i]
            cur_sum = neededTime[i]
            i += 1
            while i < n and colors[i] == cur_color:
                cur_sum += neededTime[i]
                cur_max = max(cur_max, neededTime[i])
                i += 1
            ans += cur_sum - cur_max

        return ans
```

### 方法三：itertools.groupby（Pythonic）

```python
from typing import List
from itertools import groupby

class Solution:
    def minCost(self, colors: str, neededTime: List[int]) -> int:
        ans = 0
        idx = 0
        for _, group in groupby(colors):
            size = sum(1 for _ in group)
            times = neededTime[idx:idx+size]
            ans += sum(times) - max(times)
            idx += size
        return ans
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)（方法一/二）

## 关键点总结

1. 同色气球只保留代价最大的，其余全删
2. 每组费用 = 组总代价 - 组最大代价
3. 不同颜色组独立处理

## 易错点

- 要保留代价**最大**的（最贵的值得保留），删去代价较小的
- 不同颜色组之间不存在删除关系
