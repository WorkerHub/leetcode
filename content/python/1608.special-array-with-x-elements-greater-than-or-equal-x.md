## 题目描述

给你一个非负整数数组 `nums`。如果存在一个数 `x`，使得 `nums` 中恰好有 `x` 个元素**大于或等于** `x`，那么就称 `nums` 是一个**特殊数组**，`x` 是该数组的**特征值**。

注意 `x` **不必**是 `nums` 的中的元素。

如果数组是特殊数组，返回它的特征值 `x`。否则，返回 `-1`。可以证明特征值 `x` 是唯一的。

**示例 1：**
```
输入：nums = [3,5]
输出：2
解释：有 2 个元素（3 和 5）大于等于 2。
```

**示例 2：**
```
输入：nums = [0,4,3,0,4]
输出：3
解释：有 3 个元素大于等于 3（4, 3, 4）。
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 解题思路

`x` 的范围是 `[0, n]`（n 为数组长度）：
- `x = 0` 时，0 个元素 >= 0？但 >= 0 的元素肯定有 n 个，所以 x=0 只有当 n=0 时成立
- `x = n` 时，要求 n 个元素都 >= n

**方法一：暴力枚举**：枚举 x 从 0 到 n，统计大于等于 x 的元素数量

**方法二：排序 + 二分查找**：排序后，用二分查找统计大于等于 x 的元素数量（即后缀长度）

## 代码实现

### 方法一：暴力枚举（推荐，数据量小）

```python
from typing import List

class Solution:
    def specialArray(self, nums: List[int]) -> int:
        n = len(nums)
        # x 的范围是 [0, n]
        for x in range(n + 1):
            # 统计大于等于 x 的元素数量
            count = sum(1 for num in nums if num >= x)
            if count == x:
                return x
        return -1
```

### 方法二：排序 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def specialArray(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        
        for x in range(n + 1):
            # 二分查找第一个 >= x 的位置
            # 大于等于 x 的元素数量 = n - 该位置
            pos = bisect.bisect_left(nums, x)
            count = n - pos
            if count == x:
                return x
        
        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2) | O(1) |
| 排序 + 二分 | O(n log n) | O(1) |

由于 `n <= 100`，两种方法都很快。

## 关键点总结

1. `x` 的取值范围是 `[0, n]`，因为不可能有超过 n 个元素
2. 枚举每个 x，统计大于等于 x 的元素个数
3. 排序后利用二分查找 `bisect_left(nums, x)` 快速统计 >= x 的元素数
4. 题目保证答案唯一（或不存在），无需处理多个答案

## 易错点

- `x` 的上界是 `n`（包含），不是 `n-1`
- 统计时是"大于等于 x"，不是"大于 x"，所以用 `bisect_left` 而不是 `bisect_right`
- 找不到合法 `x` 时返回 `-1`
