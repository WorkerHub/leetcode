## 题目描述

给定一个字符串 `s` 和整数 `k`，通过删除字符使字符串中不同字符的种数不超过 `k`，求最少需要删除多少个字符。

**示例 1：**

```
输入：s = "aabcaba", k = 2
输出：3
解释：字符频率：a=4, b=2, c=1。删除所有 c（1个）还不够，k=2时保留 a 和 b，删除所有 c，共1个。
     等等，{a:4, b:2, c:1}，保留频率最高的 k=2 种（a和b），删除其余（c: 1个），答案为 1。
```

**示例 2：**

```
输入：s = "abc", k = 1
输出：2
解释：保留出现次数最多的1种字符（a/b/c各1次，任选），删除另外2个字符，答案为2。
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= k <= 26`

## 解题思路

贪心策略：
1. 统计每个字符的出现频率
2. 按频率升序排列，优先删除频率最低的字符
3. 删除频率最低的字符（将其全部删除），直到剩余字符种数 <= k

## Python 代码实现

### 方法一：计数 + 排序贪心（推荐）

```python
from collections import Counter

class Solution:
    def minDeletion(self, s: str, k: int) -> int:
        cnt = Counter(s)
        if len(cnt) <= k:
            return 0

        # 按频率升序排列
        freqs = sorted(cnt.values())

        deletions = 0
        # 删除频率最低的字符，直到剩余 k 种
        chars_to_delete = len(cnt) - k
        for i in range(chars_to_delete):
            deletions += freqs[i]

        return deletions
```

### 方法二：堆实现

```python
from collections import Counter
import heapq

class Solution:
    def minDeletion(self, s: str, k: int) -> int:
        cnt = Counter(s)
        distinct = len(cnt)
        if distinct <= k:
            return 0

        # 最小堆，每次取最小频率字符删除
        heap = list(cnt.values())
        heapq.heapify(heap)

        deletions = 0
        while distinct > k:
            deletions += heapq.heappop(heap)
            distinct -= 1

        return deletions
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26) = O(n)，统计字符 + 排序（字符集大小为 26）
- 空间复杂度：O(26) = O(1)，字符计数

## 关键点总结

1. 贪心：优先删除出现次数少的字符种类（代价最小）
2. 要删除某种字符必须删除该字符的所有出现（不能只删一部分）
3. 需要删除 `distinct - k` 种字符

## 易错点

1. 删除整个字符种类（不是只删一个）
2. 若已有 <= k 种字符，无需操作，返回 0
3. 排序后取前 `distinct - k` 个频率之和
