## 题目描述

给你一个由数字 0 到 9 组成的字符串 `num`。

一次操作中，你可以删除 `num` 中**任意一个**数字。

使 `num` 能被 25 整除所需的**最少操作数**是多少？（结果中可以有前导零，空字符串代表 0，0 是 25 的倍数）

**示例 1：**
```
输入：num = "2245047"
输出：2
解释：删掉下标 2、3 的 '5' 和 '0'，得到 "22447"？不对，需要整除 25
删掉某两个数字，使剩余数字（按原顺序）能被 25 整除
如 "2247" 能被 25 整除？不对，"22450" 被 25 整除，删一个 '7' 和... 等等
num = "2245047"，找最少删除使能被 25 整除
能被 25 整除的数末尾是：00, 25, 50, 75
```

**示例 2：**
```
输入：num = "2908305"
输出：3
```

**提示：**
- `1 <= num.length <= 100`
- `num` 只包含数字 0-9
- `num` 中至少有一个 '0'

## 解题思路

能被 25 整除的数末尾两位为：00, 25, 50, 75。

**贪心：** 对每种末尾（"00", "25", "50", "75"），从字符串**右端**开始找这两个字符，计算需要删除的字符数（即跳过的字符数）。

**算法：**
1. 对每种结尾 (c1, c2)（从右到左：末尾是 c2，倒数第二是 c1）
2. 从右向左扫描：先找 c2，再找 c1
3. 删除的字符数 = 跳过的字符数（即在 c2 右边的字符 + 在 c1 和 c2 之间的字符）
4. 还要删去最终剩余数字前面的字符（保留以 c1 结尾之前的部分），不需要删除前面的，前导零也可以

**特殊情况：** 结果为 0（所有数字都删除），需要 `len(num) - 1` 次操作（保留 1 个 '0'）。

## Python 代码实现

### 方法一：枚举末尾两位（推荐）

```python
class Solution:
    def minimumOperations(self, num: str) -> int:
        n = len(num)
        ans = n - 1  # 最坏情况：删到只剩一个 '0'（代表 0，被 25 整除）

        # 枚举末尾两位
        for suffix in ["00", "25", "50", "75"]:
            c2, c1 = suffix[1], suffix[0]  # c2 是最后一位，c1 是倒数第二位

            # 从右向左找 c2
            j = n - 1
            while j >= 0 and num[j] != c2:
                j -= 1

            if j < 0:
                continue  # 找不到 c2

            # 从 j-1 向左找 c1
            i = j - 1
            while i >= 0 and num[i] != c1:
                i -= 1

            if i < 0:
                continue  # 找不到 c1

            # 删除的字符数：
            # - j 右边（不包含 j）的字符：n - 1 - j 个
            # - j 和 i 之间（不包含 j）的字符：j - 1 - i 个
            # 总删除 = (n - 1 - j) + (j - 1 - i) = n - 2 - i
            delete_count = (n - 1 - j) + (j - 1 - i)
            ans = min(ans, delete_count)

        return ans
```

### 方法二：更直观的实现

```python
class Solution:
    def minimumOperations(self, num: str) -> int:
        n = len(num)
        ans = n - 1  # 保留一个 '0'

        for target in ("00", "25", "50", "75"):
            # 从右向左找 target[1]（末尾字符）
            j = n - 1
            while j >= 0 and num[j] != target[1]:
                j -= 1
            if j < 0:
                continue
            # 在 j 左边找 target[0]
            i = j - 1
            while i >= 0 and num[i] != target[0]:
                i -= 1
            if i < 0:
                continue
            # 需要删除的数量
            ops = (n - 1 - j) + (j - i - 1)  # j 右边的 + i 和 j 之间的
            ans = min(ans, ops)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每种末尾最多扫描 n 个字符，共 4 种末尾
- 空间复杂度：O(1)

## 关键点总结

1. 被 25 整除的数末尾只有 4 种：00, 25, 50, 75
2. 从右向左贪心地找末尾两位字符（保留尽量多的字符）
3. 最坏情况：删到只剩 "0"（n-1 次操作）

## 易错点

1. 注意特殊情况：全部删除变成 0（题目说 0 是 25 的倍数），默认 ans = n-1
2. 末尾是 "00" 时需要两个 '0'，注意不能重复使用同一个 '0'
3. 删除计数公式：i 和 j 之间的字符数 = j - i - 1，j 右边的字符数 = n - 1 - j
