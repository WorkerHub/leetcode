## 题目描述

给你一个下标从 **0** 开始的字符串 `s` 和一个单词字典 `dictionary`。你需要将 `s` 分割成若干 **互不重叠** 且每个部分都在 `dictionary` 中的子字符串。`s` 中额外的字符不需要属于任何子字符串。

请你采取最优策略分割 `s`，使剩余字符（不属于任何子字符串）的数目最少，并返回剩余字符的最少数目。

**示例 1：**
```
输入：s = "leetscode", dictionary = ["leet","code","leetcode"]
输出：1
解释："leetscode" → "leet" + s(1个) + "code"，剩余 1 个字符 's'
```

**示例 2：**
```
输入：s = "sayhelloworld", dictionary = ["hello","world"]
输出：3
解释："sayhelloworld" → say(3个) + "hello" + "world"，剩余 3 个字符
```

**提示：**
- `1 <= s.length <= 50`
- `1 <= dictionary.length <= 50`
- `1 <= dictionary[i].length <= 50`

## 解题思路

**动态规划**：定义 `dp[i]` 为处理前 `i` 个字符时的最少剩余字符数。

转移方程：
- 跳过第 `i` 个字符：`dp[i+1] = dp[i] + 1`
- 对所有以 `s[i]` 结尾且在字典中的子串 `s[j..i]`：`dp[i+1] = min(dp[i+1], dp[j])`

## Python 代码实现

### 方法一：动态规划 + 哈希集合（推荐）

```python
from typing import List

class Solution:
    def minExtraChar(self, s: str, dictionary: List[str]) -> int:
        n = len(s)
        word_set = set(dictionary)  # 转为集合加速查找
        # dp[i] 表示处理 s[0..i-1] 后的最少剩余字符数
        dp = [0] * (n + 1)

        for i in range(1, n + 1):
            # 选择：不匹配 s[i-1]，它作为剩余字符
            dp[i] = dp[i - 1] + 1
            # 尝试以 s[i-1] 结尾的所有子串
            for j in range(i):
                if s[j:i] in word_set:
                    dp[i] = min(dp[i], dp[j])

        return dp[n]
```

### 方法二：动态规划 + 字典树

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def minExtraChar(self, s: str, dictionary: List[str]) -> int:
        # 构建字典树
        root = TrieNode()
        for word in dictionary:
            node = root
            for ch in word:
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]
            node.is_end = True

        n = len(s)
        dp = [0] * (n + 1)

        for i in range(1, n + 1):
            dp[i] = dp[i - 1] + 1
            # 从 i 往前在字典树中匹配
            node = root
            for j in range(i - 1, -1, -1):
                ch = s[j]
                if ch not in node.children:
                    break
                node = node.children[ch]
                if node.is_end:
                    # s[j..i-1] 在字典中
                    dp[i] = min(dp[i], dp[j])

        return dp[n]
```

## 复杂度分析

- 方法一：时间复杂度 O(n^2 * L)（L 为单词最大长度，字符串切片），空间复杂度 O(n + m*L)
- 方法二：时间复杂度 O(n^2 + m*L)，空间复杂度 O(m*L)（m 为字典大小）

## 关键点总结

1. DP 定义中 `dp[i]` 对应前 `i` 个字符，初始 `dp[0] = 0`
2. 每个位置有两种选择：跳过当前字符或匹配一个字典单词
3. 字典树可以优化查询效率，避免重复字符串切片

## 易错点

1. 切片 `s[j:i]` 对应从下标 `j` 到 `i-1`
2. 默认值应为 `dp[i-1] + 1`（跳过当前字符）
