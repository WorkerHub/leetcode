## 题目描述

用以太网线缆将 `n` 台计算机连接成一个网络，计算机的编号从 `0` 到 `n-1`。

线缆用 `connections` 表示，其中 `connections[i] = [a, b]` 表示第 `i` 条线缆连接了计算机 `a` 和 `b`。

网络中的任何一台计算机都可以通过网络**直接或者间接**访问同一个网络中其他任意一台计算机。

给你这个计算机网络的初始布线 `connections`，你可以拔开任意两台直连计算机之间的线缆，并用它来连接一对未直连的计算机。

请你计算并返回使所有计算机都连通所需的**最少操作次数**。如果不可能，则返回 `-1`。

**示例 1：**

```
输入：n = 4, connections = [[0,1],[0,2],[1,2]]
输出：1
解释：拔下 [1,2] 连接 [3,?] 即可
```

**示例 2：**

```
输入：n = 6, connections = [[0,1],[0,2],[0,3],[1,2],[1,3]]
输出：2
```

**示例 3：**

```
输入：n = 6, connections = [[0,1],[0,2],[0,3],[1,2]]
输出：-1
解释：线缆数量不足，无法连通所有计算机
```

**提示：**

- `1 <= n <= 10^5`
- `1 <= connections.length <= min(n*(n-1)/2, 10^5)`
- `connections[i].length == 2`
- `0 <= connections[i][0], connections[i][1] < n`
- 没有重复的连接

## 解题思路

**关键观察：**

1. **线缆数量检查**：要将 n 台计算机连成一个连通网络，至少需要 n-1 条线缆。如果 `len(connections) < n-1`，直接返回 -1。

2. **最少操作次数**：

   设当前网络有 k 个连通分量（即 k 个独立的小网络），要将它们合并为 1 个，需要 **k-1** 次操作。

   每次操作：从某个有多余线缆的连通分量拔下一条，连接两个分量，使分量数减少 1。

   保证有足够线缆的条件：`len(connections) >= n-1`（第 1 步已检验）。

3. **如何求连通分量数**：使用**并查集（Union-Find）**。

**并查集解题流程：**

```
初始化：每台计算机自成一个分量，共 n 个分量
遍历 connections：
    若两台计算机不在同一分量，合并它们，分量数 -1
最终分量数 k 即为答案 k-1
```

## Python 代码实现

### 方法一：并查集（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))  # 每个节点的父节点，初始指向自己
        self.rank = [0] * n           # 按秩合并
        self.count = n                # 连通分量数
    
    def find(self, x: int) -> int:
        # 路径压缩：将路径上所有节点直接连接到根
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        # 合并 x 和 y 所在的连通分量
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False  # 已在同一分量，无需合并
        # 按秩合并，保持树的平衡
        if self.rank[root_x] < self.rank[root_y]:
            root_x, root_y = root_y, root_x
        self.parent[root_y] = root_x
        if self.rank[root_x] == self.rank[root_y]:
            self.rank[root_x] += 1
        self.count -= 1
        return True

class Solution:
    def makeConnected(self, n: int, connections: List[List[int]]) -> int:
        # 线缆不足，无法连通所有计算机
        if len(connections) < n - 1:
            return -1
        
        uf = UnionFind(n)
        for a, b in connections:
            uf.union(a, b)
        
        # 连通分量数 - 1 即为所需操作次数
        return uf.count - 1
```

### 方法二：DFS 求连通分量数

```python
from typing import List
from collections import defaultdict

class Solution:
    def makeConnected(self, n: int, connections: List[List[int]]) -> int:
        if len(connections) < n - 1:
            return -1
        
        # 构建邻接表
        graph = defaultdict(list)
        for a, b in connections:
            graph[a].append(b)
            graph[b].append(a)
        
        visited = set()
        
        def dfs(node):
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    dfs(neighbor)
        
        # 统计连通分量数
        components = 0
        for i in range(n):
            if i not in visited:
                dfs(i)
                components += 1
        
        return components - 1
```

### 方法三：BFS 求连通分量数

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def makeConnected(self, n: int, connections: List[List[int]]) -> int:
        if len(connections) < n - 1:
            return -1
        
        # 构建邻接表
        graph = defaultdict(list)
        for a, b in connections:
            graph[a].append(b)
            graph[b].append(a)
        
        visited = [False] * n
        components = 0
        
        for start in range(n):
            if not visited[start]:
                # BFS 遍历整个连通分量
                queue = deque([start])
                visited[start] = True
                while queue:
                    node = queue.popleft()
                    for neighbor in graph[node]:
                        if not visited[neighbor]:
                            visited[neighbor] = True
                            queue.append(neighbor)
                components += 1
        
        return components - 1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 | O((n+E) * α(n)) | O(n) |
| DFS/BFS | O(n + E) | O(n + E) |

其中 E 为边数，α(n) 是反阿克曼函数（极小，近似 O(1)）。

## 关键点总结

1. **必要条件**：线缆数 >= n-1，否则无解
2. **最少操作数 = 连通分量数 - 1**（每次操作减少一个分量）
3. 并查集是求连通分量数的高效工具
4. 路径压缩 + 按秩合并使并查集接近 O(1) 每次操作

## 易错点

1. **先判断线缆数量**：在做并查集之前先检查 `len(connections) < n-1`，直接返回 -1
2. **连通分量数减 1**：k 个分量需要 k-1 次操作，不要返回 k
3. **DFS 递归深度**：n 最大 10^5，Python 默认递归深度不足，DFS 可能栈溢出；建议使用 BFS 或并查集
