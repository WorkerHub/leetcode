## 题目描述

给你整数 `n` 表示有 `n` 门课程，编号从 1 到 `n`。给你一个数组 `relations`，`relations[j] = [prevCourse, nextCourse]`，表示课程 `prevCourse` 必须在课程 `nextCourse` 之前完成。

`time[i]` 表示完成第 `i` 门课程所需的月数。

在任意时刻，你可以同时修读任意门课程，但条件是该课程的所有前置课程均已完成。

返回完成所有课程所需的**最少月数**。

**示例 1：**
```
输入：n = 3, relations = [[1,3],[2,3]], time = [3,2,5]
输出：8
解释：课程 1(3月) 和 2(2月) 并行，完成后修 3(5月)，共 8 月
```

**提示：**
- `1 <= n <= 5 * 10^4`
- `0 <= relations.length <= min(n * (n-1) / 2, 5 * 10^4)`
- `time.length == n`
- `1 <= time[i] <= 10^4`

## 解题思路

**拓扑排序 + DP：**

定义 `dp[i]` = 完成课程 `i` 的最早时间（包含完成 i 所需的时间）

**状态转移：**
- `dp[i] = max(dp[prev] for prev in prerequisites[i]) + time[i]`（等所有前置课程完成后，再用 time[i] 完成）

**拓扑排序确保按依赖顺序处理，答案为 `max(dp)`**

## 代码实现

### 方法一：拓扑排序 + DP（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def minimumTime(self, n: int, relations: List[List[int]], time: List[int]) -> int:
        # 构建图（1-indexed）
        graph = [[] for _ in range(n + 1)]
        in_degree = [0] * (n + 1)

        for prev, nxt in relations:
            graph[prev].append(nxt)
            in_degree[nxt] += 1

        # dp[i] = 完成课程 i 的最早时间
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = time[i - 1]  # 无前置时直接等于 time[i]

        # 拓扑排序（BFS）
        queue = deque()
        for i in range(1, n + 1):
            if in_degree[i] == 0:
                queue.append(i)

        while queue:
            node = queue.popleft()
            for nxt in graph[node]:
                # 更新 nxt 的完成时间
                dp[nxt] = max(dp[nxt], dp[node] + time[nxt - 1])
                in_degree[nxt] -= 1
                if in_degree[nxt] == 0:
                    queue.append(nxt)

        return max(dp[1:])
```

### 方法二：记忆化 DFS

```python
from typing import List
import sys
sys.setrecursionlimit(100000)

class Solution:
    def minimumTime(self, n: int, relations: List[List[int]], time: List[int]) -> int:
        # 构建反向图（后继 -> 前驱）
        prereqs = [[] for _ in range(n + 1)]
        for prev, nxt in relations:
            prereqs[nxt].append(prev)

        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(i: int) -> int:
            # 完成课程 i 的最早时间
            if not prereqs[i]:
                return time[i - 1]
            return max(dp(p) for p in prereqs[i]) + time[i - 1]

        return max(dp(i) for i in range(1, n + 1))
```

## 复杂度分析

- 时间复杂度：O(V + E)，拓扑排序
- 空间复杂度：O(V + E)

## 关键点总结

1. 拓扑排序确保处理节点时所有前驱已处理
2. `dp[i]` 在所有前驱的完成时间基础上加上自身时间
3. 并行执行：取所有前驱中最晚完成的（max），而非求和

## 易错点

- 初始化 `dp[i] = time[i-1]`（无前置课程时即为 time）
- 更新时：`dp[nxt] = max(dp[nxt], dp[node] + time[nxt-1])`（多个前驱取最大）
- 答案是 `max(dp)`，不是某个特定节点
