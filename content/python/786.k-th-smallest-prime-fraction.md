## 题目描述

给定一个按递增顺序排序的数组 `arr`，数组中的元素均为质数。同时给定一个整数 `k`。

对于每对满足 `0 <= i < j < arr.length` 的 `i` 和 `j`，可以得到分数 `arr[i] / arr[j]`。

返回第 `k` 个最小的分数，以长度为 2 的整数数组 `[arr[i], arr[j]]` 的形式返回。

**示例 1：**
```
输入：arr = [1,2,3,5], k = 3
输出：[2,5]
解释：已构造好的分数,排序后如下所示: 
1/5, 1/3, 2/5, 1/2, 3/5, 2/3
很明显第三个最小的分数是 2/5
```

**示例 2：**
```
输入：arr = [1,7], k = 1
输出：[1,7]
```

**提示：**
- 2 <= arr.length <= 1000
- 1 <= arr[i] <= 3 × 10^4
- arr[0] == 1
- arr[i] 是一个质数，i > 0
- arr 中的所有数字互不相同且按严格递增顺序排序
- 1 <= k <= arr.length × (arr.length - 1) / 2

## 解题思路

这道题有多种解法，从暴力到优化：

**观察1：** 数组已排序，分数 arr[i]/arr[j] (i<j) 的特点：
- 分子越小、分母越大，分数越小
- 每一行（固定分子）从左到右递减
- 每一列（固定分母）从上到下递增

**三种解法思路：**

1. **暴力法 + 排序**：生成所有分数，排序后取第k个（会超时）
2. **最小堆**：利用有序性，用堆逐步找出前k小的分数
3. **二分查找**：二分答案，统计小于等于某个值的分数个数

## Python 代码实现

### 方法一：最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        # 堆中存储 (分数值, 分子索引, 分母索引)
        heap = []
        
        # 初始化：将每个分子与最大分母组成的分数入堆
        # 这些是每行的最小值
        for i in range(n - 1):
            heapq.heappush(heap, (arr[i] / arr[-1], i, n - 1))
        
        # 弹出k-1次，第k次弹出的就是答案
        for _ in range(k - 1):
            _, i, j = heapq.heappop(heap)
            # 将同一分子、下一个分母的分数入堆
            if j - 1 > i:
                heapq.heappush(heap, (arr[i] / arr[j - 1], i, j - 1))
        
        # 第k个最小的分数
        _, i, j = heapq.heappop(heap)
        return [arr[i], arr[j]]
```

### 方法二：二分查找（最优）

```python
from typing import List

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        left, right = 0.0, 1.0
        
        while True:
            mid = (left + right) / 2
            count = 0  # 小于等于mid的分数个数
            max_frac = 0.0  # 小于等于mid的最大分数
            p, q = 0, 1  # 记录最大分数的分子分母
            j = 1
            
            # 对每个分子arr[i]，找有多少个分母使得arr[i]/arr[j] <= mid
            for i in range(n - 1):
                # arr[i]/arr[j] <= mid  =>  arr[j] >= arr[i]/mid
                while j < n and arr[i] > mid * arr[j]:
                    j += 1
                
                count += n - j
                
                if j < n and max_frac < arr[i] / arr[j]:
                    max_frac = arr[i] / arr[j]
                    p, q = i, j
            
            if count == k:
                return [arr[p], arr[q]]
            elif count < k:
                left = mid
            else:
                right = mid
```

### 方法三：暴力法 + 排序（会超时，仅供学习）

```python
from typing import List

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        fractions = []
        n = len(arr)
        
        # 生成所有分数
        for i in range(n):
            for j in range(i + 1, n):
                fractions.append((arr[i] / arr[j], arr[i], arr[j]))
        
        # 排序
        fractions.sort()
        
        # 返回第k个
        return [fractions[k - 1][1], fractions[k - 1][2]]
```

## 复杂度分析

设数组长度为 n。

**最小堆方法：**
- **时间复杂度：** O(k × log n)，最多k次堆操作
- **空间复杂度：** O(n)，堆的大小

**二分查找方法：**
- **时间复杂度：** O(n × log(max - min))，二分次数×每次统计
- **空间复杂度：** O(1)

**暴力方法：**
- **时间复杂度：** O(n² × log n²)
- **空间复杂度：** O(n²)

## 关键点总结

1. **利用有序性**：数组已排序，每行每列的分数也有序
2. **堆的初始化**：从每行最小值开始（每个分子配最大分母）
3. **堆的扩展**：弹出(i,j)后，将(i, j-1)加入堆
4. **二分技巧**：二分答案值，统计小于等于它的分数个数
5. **双指针优化**：在二分中用双指针统计，避免重复计算

## 易错点

1. **堆的初始化**：要从每个分子的最小分数开始（配最大分母）
2. **边界条件**：j-1 > i 才能继续添加，避免分子≥分母
3. **二分终止**：当count == k时返回，而不是left==right
4. **精度问题**：浮点数比较要注意精度

```
堆过程：

第3小是 1/2... 
实际第3小是 2/5
```
