## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，这个数组中至多有 `50` 个不同的值。另有 `m` 个顾客的订单，其中 `quantity[i]` 是第 `i` 位顾客订购的数量。

对于每位顾客，分配给他们的整数必须**相同**（同一种类），且**数量足够**。

请你判断是否可以同时满足**所有顾客**的订单。

**提示：**
- `n <= 10^5`
- `m <= 10`（顾客数量很少）
- `quantity[i] <= 10^5`

## 解题思路

由于顾客数 `m <= 10`，可以用**状态压缩 DP**。

**关键观察：** 不同整数的值不重要，只关心每种整数的数量（`count_values`）。

**DP 定义：** `dp[mask]` = 当前已满足 `mask` 中的顾客子集是否可行。

**状态转移：** 对于每种整数数量 `cnt`，尝试用它满足某个顾客子集 `sub`（`sub` 的总需求 <= cnt）。

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def canDistribute(self, nums: List[int], quantity: List[int]) -> bool:
        m = len(quantity)
        
        # 统计每种整数的数量
        count_values = sorted(Counter(nums).values(), reverse=True)
        
        # 预计算每个子集的总需求
        subset_sum = [0] * (1 << m)
        for mask in range(1, 1 << m):
            # 找最低位的顾客
            lsb = (mask & -mask).bit_length() - 1
            subset_sum[mask] = subset_sum[mask ^ (1 << lsb)] + quantity[lsb]
        
        # dp[mask] = 能否满足 mask 中所有顾客的需求
        dp = [False] * (1 << m)
        dp[0] = True  # 空集可以满足
        
        for cnt in count_values:
            # 对当前整数数量 cnt，更新 dp
            # 从大到小遍历避免重复使用（每种整数只用一次）
            for mask in range((1 << m) - 1, -1, -1):
                if not dp[mask]:
                    continue
                # 枚举 mask 的补集中的子集 sub，尝试用 cnt 满足 sub
                sub = (1 << m) - 1 - mask  # mask 的补集
                while sub:
                    if subset_sum[sub] <= cnt:
                        dp[mask | sub] = True
                    sub = (sub - 1) & ((1 << m) - 1 - mask)  # 枚举补集的子集
        
        return dp[(1 << m) - 1]
```

### 方法二：回溯（DFS）

```python
from typing import List
from collections import Counter

class Solution:
    def canDistribute(self, nums: List[int], quantity: List[int]) -> bool:
        count_values = sorted(Counter(nums).values(), reverse=True)
        quantity.sort(reverse=True)  # 大需求优先，剪枝更有效
        
        def backtrack(idx: int, counts: List[int]) -> bool:
            if idx == len(quantity):
                return True
            seen = set()
            for i, cnt in enumerate(counts):
                if cnt in seen:
                    continue
                if cnt >= quantity[idx]:
                    seen.add(cnt)
                    counts[i] -= quantity[idx]
                    if backtrack(idx + 1, counts):
                        return True
                    counts[i] += quantity[idx]
            return False
        
        return backtrack(0, list(count_values))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 状态压缩 DP | O(k * 3^m) | O(2^m) |
| 回溯 | O(k^m) 最坏 | O(k + m) |

k 为不同值的数量（最多 50），m <= 10。

## 关键点总结

1. m <= 10，适合状态压缩 DP（2^10 = 1024）
2. 预处理每个子集的总需求量
3. 枚举每个已满足子集的补集的子集（三进制枚举，总量 3^m）
4. 回溯方法用剪枝（大需求优先，去重）也很高效

## 易错点

- DP 从大到小遍历 mask，避免同一整数被多次使用
- 子集枚举技巧：`sub = (sub - 1) & complement` 枚举补集的所有子集
- 回溯中对相同数量的整数去重（`seen` 集合）
