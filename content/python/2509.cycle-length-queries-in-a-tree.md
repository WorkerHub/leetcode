## 题目描述

给你一棵 `n` 个节点的 **完全二叉树**，节点编号为 1 到 n（根节点为 1）。对于节点 v：
- 左孩子为 `2v`
- 右孩子为 `2v + 1`
- 父节点为 `v // 2`

给你一个长度为 `q` 的二维数组 `queries`，其中 `queries[i] = [a, b]`。

对每个查询，如果在节点 `a` 和 `b` 之间添加一条边，会形成一个环。请返回该环的长度（即环中边的数目）。

**示例：**

```
输入：n = 3, queries = [[5, 3], [6, 1]]
输出：[4, 3]
解释：
- 添加 5-3 边，形成环 5→2→1→3→5（3条已有边 + 1条新边），长度为 4。
- 添加 6-1 边，形成环 6→3→1→6，长度为 3。
```

**提示：**

- `2 <= n <= 10^18`
- `1 <= queries.length <= 10^5`
- `1 <= queries[i][0], queries[i][1] <= n`

## 解题思路

**求完全二叉树中两节点的 LCA（最近公共祖先）**。

环的长度 = dist(a, LCA) + dist(b, LCA) + 1（新添加的边）。

在完全二叉树中：
- 深度(v) = v.bit_length() - 1
- 将 a 和 b 不断除以 2 向上移动，直到它们相等，即找到 LCA

dist(a, LCA) = 深度(a) - 深度(LCA) = 上移步数。

## Python 代码实现

### 方法一：同步上移找 LCA（推荐）

```python
from typing import List

class Solution:
    def cycleLengthQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        ans = []
        for a, b in queries:
            steps = 1  # 新添加的边计 1
            # 将深度较深的节点向上移动，直到 a == b（找到 LCA）
            while a != b:
                if a > b:
                    a //= 2
                else:
                    b //= 2
                steps += 1
            ans.append(steps)
        return ans
```

### 方法二：利用位长度计算深度

```python
from typing import List

class Solution:
    def cycleLengthQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        def lca_dist(a: int, b: int) -> int:
            # 返回从 a 到 b 经过 LCA 的路径总边数
            dist = 0
            while a != b:
                # 深度较大的节点先上移
                if a > b:
                    a >>= 1
                else:
                    b >>= 1
                dist += 1
            return dist

        return [lca_dist(a, b) + 1 for a, b in queries]
```

## 复杂度分析

- 每次查询时间复杂度：O(log n)，上移步数不超过树的高度
- 总时间复杂度：O(q * log n)
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 完全二叉树中，父节点 = 节点编号 // 2，利用整数除法快速上移
2. 找 LCA：深度大的节点先上移，直到两节点相等
3. 环长 = 两节点到 LCA 的距离之和 + 1（新边）

## 易错点

1. n 可以达到 10^18，不能用数组存树，要利用编号关系计算
2. 环长包含新添加的那条边，记得 +1
3. 上移时要选深度更大（编号更大）的节点，保证正确性
