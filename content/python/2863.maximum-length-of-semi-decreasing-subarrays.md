## 题目描述

给你一个整数数组 `nums`。

如果子数组的**第一个元素严格大于最后一个元素**，则该子数组被称为**半递减子数组**。

返回所有半递减子数组中，长度的最大值。如果不存在，返回 0。

**示例 1：**
```
输入：nums = [7,6,5,4,3,2,1,6,10,11]
输出：8
解释：子数组 [7,6,5,4,3,2,1,6] 长度 8，7 > 6 ✓
```

**示例 2：**
```
输入：nums = [57,55,50,60,61,58,63,59,64,60,63]
输出：6
解释：最长的半递减子数组...
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**关键：** 对每个位置 j（作为子数组末尾），找最远的起点 i（i < j，nums[i] > nums[j]）。

**优化：** 维护一个从左到右的单调递减栈：
- 将比当前元素大的所有元素下标入栈（维护潜在的"更大起点"）
- 对每个 j，答案候选 = j - stack[i]（栈底是最远的大起点）

但更简单的方法：
1. 找每个位置 j 时，最优的起点 i 是**最早**（下标最小）且 `nums[i] > nums[j]` 的位置
2. 从后往前遍历右端点 j，同时维护从左端开始的"降序前缀"最大值（前缀最大值下标）

**正确思路：**
- 单调栈（从栈底到栈顶严格递减）存储左侧的"候选起点"
- 从右向左扫描，对每个元素 nums[j]，弹出栈中所有 <= nums[j] 的元素（它们不可能是最远起点），剩余的栈顶就是最近的比 nums[j] 大的位置

等等，题目要的是最长，所以想要最远的起点（下标最小的 i）。

**正确算法：**
1. 从左到右建立严格递减的单调栈（存下标）
2. 从右到左遍历每个 j，弹出栈中 `nums[i] <= nums[j]` 的元素（它们作为右端点已不如 j 远），找到最远的合法 i

实际上，更简洁的做法：
- 对每个 j，最优起点是满足 `nums[i] > nums[j]` 的最小 i
- 预处理：`left_min[j]` = 满足 `nums[i] > nums[j]` 的最小 i 的下标（二分查找）

## Python 代码实现

### 方法一：单调栈（推荐）

```python
from typing import List

class Solution:
    def maxSubarrayLength(self, nums: List[int]) -> int:
        n = len(nums)
        # 从左到右构建严格递减的单调栈（存下标）
        stack = []
        for i in range(n):
            if not stack or nums[stack[-1]] > nums[i]:
                stack.append(i)
            # 如果相等或更大，不加（我们只要严格递减的）

        # 修正：实际上应该是前缀最大值从右到左匹配
        # 重新建栈：存满足 nums[i] > nums[j] 的最远 i
        stack = []
        # 构建严格递减栈（每个元素加入时，它比右边的都大）
        for i in range(n):
            if not stack or nums[stack[-1]] > nums[i]:
                stack.append(i)

        ans = 0
        # 从右向左遍历 j
        for j in range(n - 1, -1, -1):
            # 弹出所有 nums[i] <= nums[j] 的（不满足 nums[i] > nums[j]）
            while stack and nums[stack[-1]] <= nums[j]:
                stack.pop()
            if stack:
                ans = max(ans, j - stack[0])  # 最远起点是栈底

        return ans
```

### 方法二：正确的单调栈实现

```python
from typing import List

class Solution:
    def maxSubarrayLength(self, nums: List[int]) -> int:
        n = len(nums)
        # 从左到右建单调递减栈（严格）
        stk = []
        for i in range(n):
            if not stk or nums[stk[-1]] > nums[i]:
                stk.append(i)

        ans = 0
        # 从右到左，对每个 j 找最远的合法 i
        for j in range(n - 1, -1, -1):
            while stk and nums[stk[-1]] <= nums[j]:
                stk.pop()
            if stk:
                # stk[0] 是满足 nums[i] > nums[j] 的最远起点
                ans = max(ans, j - stk[0])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，单调栈

## 关键点总结

1. 单调递减栈记录左侧所有潜在起点（严格递减）
2. 从右向左遍历末尾位置，弹出不满足条件的起点
3. 栈底（最远位置）是最优起点

## 易错点

1. 条件是严格大于（nums[i] > nums[j]），等号不算
2. 弹出条件：`nums[stack[-1]] <= nums[j]`（不满足大于）
3. 答案是 `j - stk[0]`（使用栈底，最远起点）
