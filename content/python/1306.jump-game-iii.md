## 题目描述

这里有一个非负整数数组 `arr`，你最开始位于该数组的起始下标 `start` 处。当你位于下标 `i` 处时，你可以跳到 `i + arr[i]` 或者 `i - arr[i]`。

请你判断自己是否能够跳到对应元素值为 `0` 的任意下标处。

注意，不管是什么情况下，你都无法跳到数组之外。

示例 1：
```
输入：arr = [4,2,3,0,3,1,2], start = 5
输出：true
解释：
到达值为 0 的下标 3 有以下可能方案：
下标 5 -> 下标 4 -> 下标 1 -> 下标 3
下标 5 -> 下标 6 -> 下标 4 -> 下标 1 -> 下标 3
```

示例 2：
```
输入：arr = [4,2,3,0,3,1,2], start = 0
输出：true
解释：
到达值为 0 的下标 3 有以下可能方案：
下标 0 -> 下标 4 -> 下标 1 -> 下标 3
```

示例 3：
```
输入：arr = [3,0,2,1,2], start = 2
输出：false
解释：无法到达值为 0 的下标 1 处。
```

提示：
- `1 <= arr.length <= 5 * 10^4`
- `0 <= arr[i] < arr.length`
- `0 <= start < arr.length`

## 解题思路

这道题本质上是一个图的可达性问题。每个下标是一个节点，从下标 i 可以跳到 i+arr[i] 或 i-arr[i]，形成了有向边。

关键点：
1. 需要判断从起点 start 能否到达值为 0 的任意位置
2. 需要避免无限循环（访问已经访问过的节点）
3. 可以使用 BFS 或 DFS 来解决

### 思路一：BFS（广度优先搜索）
使用队列进行层序遍历，标记已访问的节点，检查是否能到达值为 0 的位置。

### 思路二：DFS（深度优先搜索）
使用递归或栈进行深度优先搜索，同样需要标记已访问节点。

## Python 代码实现

### 方法一：BFS（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        visited = set()
        queue = deque([start])
        visited.add(start)
        
        while queue:
            index = queue.popleft()
            
            # 找到值为 0 的位置
            if arr[index] == 0:
                return True
            
            # 计算两个可能的跳跃位置
            next_indices = [index + arr[index], index - arr[index]]
            
            for next_index in next_indices:
                # 检查边界和是否已访问
                if 0 <= next_index < n and next_index not in visited:
                    visited.add(next_index)
                    queue.append(next_index)
        
        return False
```

### 方法二：DFS 递归

```python
from typing import List

class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        visited = set()
        
        def dfs(index: int) -> bool:
            # 越界或已访问
            if index < 0 or index >= n or index in visited:
                return False
            
            # 标记已访问
            visited.add(index)
            
            # 找到目标
            if arr[index] == 0:
                return True
            
            # 尝试两个方向
            return dfs(index + arr[index]) or dfs(index - arr[index])
        
        return dfs(start)
```

### 方法三：DFS 迭代（使用栈）

```python
from typing import List

class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        visited = set()
        stack = [start]
        
        while stack:
            index = stack.pop()
            
            # 检查是否已访问或越界
            if index < 0 or index >= n or index in visited:
                continue
            
            # 找到目标
            if arr[index] == 0:
                return True
            
            # 标记已访问
            visited.add(index)
            
            # 添加两个可能的下一步
            stack.append(index + arr[index])
            stack.append(index - arr[index])
        
        return False
```

### 方法四：原地标记（空间优化）

```python
from typing import List
from collections import deque

class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        queue = deque([start])
        
        while queue:
            index = queue.popleft()
            
            # 越界检查
            if index < 0 or index >= n:
                continue
            
            # 找到目标
            if arr[index] == 0:
                return True
            
            # 已访问过（标记为负数）
            if arr[index] < 0:
                continue
            
            # 计算下一步
            val = arr[index]
            arr[index] = -arr[index]  # 标记为已访问
            
            queue.append(index + val)
            queue.append(index - val)
        
        return False
```

## 复杂度分析

### 方法一、二、三
- 时间复杂度：O(n)，每个节点最多访问一次
- 空间复杂度：O(n)，visited 集合和队列/栈/递归栈

### 方法四（原地标记）
- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列空间，但不需要额外的 visited 集合

## 关键点总结

1. 这是一个图的可达性问题，需要使用 BFS 或 DFS
2. 必须标记已访问节点，防止无限循环
3. 每个位置有两个可能的跳跃方向：前进和后退
4. 注意边界检查，不能跳出数组范围
5. BFS 找到的是最短路径，DFS 可能更早找到答案（取决于路径）

## 易错点

1. 忘记标记已访问节点，导致无限循环
2. 边界检查不完整（只检查了一个方向）
3. 提前返回条件写错（应该是 arr[index] == 0）
4. 原地标记时，忘记保存原始值就修改了 arr[index]

## 图解示例

以 arr = [4,2,3,0,3,1,2], start = 5 为例：

```
数组：[4, 2, 3, 0, 3, 1, 2]
索引： 0  1  2  3  4  5  6

从 start = 5 开始（值为 1）：
- 可以跳到 5+1=6 或 5-1=4

从 6（值为 2）：
- 可以跳到 6+2=8（越界）或 6-2=4

从 4（值为 3）：
- 可以跳到 4+3=7（越界）或 4-3=1

从 1（值为 2）：
- 可以跳到 1+2=3 或 1-2=-1（越界）

从 3（值为 0）：
- 找到目标！返回 True

路径：5 → 6 → 4 → 1 → 3
或：  5 → 4 → 1 → 3
```
