## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个正整数 `k`。

你可以进行以下操作任意次：选择一个大小为 `k` 的 **非空子数组**，将该子数组中每个元素减去 1。

返回是否可以使 `nums` 中所有元素都等于 0。

**示例 1：**
```
输入：nums = [2,2,3,1,1,0], k = 3
输出：true
```

**示例 2：**
```
输入：nums = [1,3,1,1], k = 2
输出：false
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`
- `1 <= k <= nums.length`

## 解题思路

**差分数组贪心**：从左到右，当到达位置 `i` 时，当前"累积减少量"为 `dec`。

- 若 `nums[i] - dec < 0`：该位置已被减少超过其值，返回 false
- 若 `nums[i] - dec > 0`：需要从位置 `i` 开始新增 `nums[i] - dec` 次操作（子数组 `[i..i+k-1]`），若 `i + k - 1 >= n` 则返回 false
- 若 `nums[i] - dec == 0`：不需要新操作

用差分数组记录操作的结束位置，及时更新 `dec`。

## Python 代码实现

### 方法一：差分数组 + 贪心（推荐）

```python
from typing import List

class Solution:
    def checkArray(self, nums: List[int], k: int) -> bool:
        n = len(nums)
        dec = 0  # 当前累积减少量
        diff = [0] * (n + 1)  # 差分数组

        for i in range(n):
            dec += diff[i]  # 加上在位置 i 结束的操作
            cur = nums[i] + dec  # 实际剩余值（注意 dec 是负数）
            # 简化：dec 记录的是正的减少量
            cur = nums[i] - (-dec)
            # 重新用正数表示
            pass

        # 重新实现
        dec = 0
        diff = [0] * (n + 1)
        for i in range(n):
            dec += diff[i]
            remaining = nums[i] - dec
            if remaining < 0:
                return False
            if remaining > 0:
                # 需要从 i 开始操作 remaining 次
                if i + k > n:
                    return False
                dec += remaining
                diff[i + k] -= remaining  # 在 i+k 处取消这些操作
        return True
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：遇到不足的位置立即补充操作（从当前位置开始）
2. 差分数组高效维护累积操作量
3. 子数组结束位置超出边界时返回 false

## 易错点

1. `remaining < 0` 时说明过度减少，返回 false
2. 差分在 `i + k` 处减去，对应操作范围 `[i, i+k-1]` 恰好长度 k
