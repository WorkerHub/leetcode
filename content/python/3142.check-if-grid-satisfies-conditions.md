## 题目描述

给你一个大小为 `m x n` 的二维矩阵 `grid`。

如果矩阵满足以下所有条件，返回 `true`；否则返回 `false`：
- 同一列中所有元素相等
- 相邻两列（`grid[i][j]` 和 `grid[i][j+1]`）不相等

**示例 1：**
```
输入：grid = [[1],[2],[3]]
输出：false（每列只有一列，列内所有元素当然相等，但没有相邻列需要比较，所以返回 true？
实际题意：同列相等，相邻列不等。
```

**示例 2：**
```
输入：grid = [[1,0],[0,1]]
输出：false（第一列 [1,0] 不相等）
```

**提示：**
- `1 <= m, n <= 10`
- `0 <= grid[i][j] <= 9`

## 解题思路

遍历每列，检查该列所有元素是否与第一行的值相同；再检查相邻列第一行值是否不同（两列的代表值不同即可）。

## Python 代码实现

### 方法一：逐列检查（推荐）

```python
from typing import List

class Solution:
    def satisfiesConditions(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        for j in range(n):
            # 检查第 j 列所有元素相同
            col_val = grid[0][j]
            for i in range(1, m):
                if grid[i][j] != col_val:
                    return False
            # 检查相邻列不同
            if j > 0 and grid[0][j] == grid[0][j - 1]:
                return False

        return True
```

### 方法二：一行代码

```python
from typing import List

class Solution:
    def satisfiesConditions(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        # 每列所有元素相等
        for j in range(n):
            if len(set(grid[i][j] for i in range(m))) > 1:
                return False
        # 相邻列不同
        for j in range(n - 1):
            if grid[0][j] == grid[0][j + 1]:
                return False
        return True
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 同列等值：只需检查每列所有元素与 grid[0][j] 相同
2. 相邻列不等：只需比较第一行的值

## 易错点

1. 两个条件都要满足
2. 相邻列比较的是各列的统一值（任意行都行，因为列已经统一）
