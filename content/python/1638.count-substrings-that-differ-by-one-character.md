## 题目描述

给你两个字符串 `s` 和 `t`，找出 `s` 的非空子串和 `t` 的非空子串构成的字符串对的数目，满足：两个子串**恰好只有 1 个字符不同**。

**示例：**
```
输入：s = "aba", t = "baba"
输出：6
```

**提示：**
- `1 <= s.length, t.length <= 100`

## 解题思路

**方法一：枚举所有子串对**（O(m^2 * n^2 * min(m,n))，暴力）

**方法二：枚举不同字符的位置**（O(m * n * min(m,n))）
- 枚举 s 中的位置 i 和 t 中的位置 j
- 若 `s[i] != t[j]`，则以 (i, j) 为唯一不同字符，向两侧扩展相同字符

**方法三：动态规划**（O(m * n)）

## 代码实现

### 方法一：枚举不同字符位置（推荐）

```python
class Solution:
    def countSubstrings(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        ans = 0
        
        # 枚举 s[i] 和 t[j] 作为唯一不同的字符位置
        for i in range(m):
            for j in range(n):
                if s[i] != t[j]:
                    # 向左扩展：s[i-k..i-1] == t[j-k..j-1]
                    left = 0
                    while i - left - 1 >= 0 and j - left - 1 >= 0 and s[i-left-1] == t[j-left-1]:
                        left += 1
                    
                    # 向右扩展：s[i+1..i+k] == t[j+1..j+k]
                    right = 0
                    while i + right + 1 < m and j + right + 1 < n and s[i+right+1] == t[j+right+1]:
                        right += 1
                    
                    # 以 (i,j) 为唯一不同字符的子串数 = (left+1) * (right+1)
                    ans += (left + 1) * (right + 1)
        
        return ans
```

### 方法二：动态规划

```python
class Solution:
    def countSubstrings(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        ans = 0
        
        # pre[i][j] = s[0..i] 和 t[0..j] 的最长公共后缀长度
        # suf[i][j] = s[i..m-1] 和 t[j..n-1] 的最长公共前缀长度
        
        # 计算最长公共后缀
        pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i-1] == t[j-1]:
                    pre[i][j] = pre[i-1][j-1] + 1
                else:
                    pre[i][j] = 0
        
        # 计算最长公共前缀
        suf = [[0] * (n + 2) for _ in range(m + 2)]
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if s[i] == t[j]:
                    suf[i][j] = suf[i+1][j+1] + 1
                else:
                    suf[i][j] = 0
        
        # 枚举不同字符位置 (i, j)
        for i in range(m):
            for j in range(n):
                if s[i] != t[j]:
                    ans += (pre[i][j] + 1) * (suf[i+1][j+1] + 1)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举不同位置 | O(m * n * min(m,n)) | O(1) |
| DP | O(m * n) | O(m * n) |

## 关键点总结

1. 核心思路：枚举唯一不同的字符位置 (i, j)，向两侧扩展相同字符
2. 向左 left 步，向右 right 步，子串数 = (left+1) * (right+1)
3. DP 预计算最长公共前/后缀，将时间从 O(m*n*k) 优化到 O(m*n)

## 易错点

- 扩展时注意边界：不能超出字符串范围
- 只有当 `s[i] != t[j]` 时才作为唯一不同位置
- 子串数是 (left+1) * (right+1)，加 1 是因为包含只有这一个不同字符的子串
