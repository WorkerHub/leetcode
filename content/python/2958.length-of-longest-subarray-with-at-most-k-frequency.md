## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，返回满足以下条件的最长子数组的长度：
- 子数组中每个元素出现的频率至多为 `k`。

**示例 1：**
```
输入：nums = [1,2,3,1,2,3,1,2], k = 2
输出：6
解释：子数组 [1,2,3,1,2,3] 中 1,2,3 各出现 2 次，满足条件
```

**示例 2：**
```
输入：nums = [1,2,1,2,1,2,1,2], k = 1
输出：2
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

滑动窗口：维护窗口 [left, right]，哈希表记录窗口内各元素的频率。

当有元素频率超过 k 时，收缩左端直到频率恢复 <= k。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarrayLength(self, nums: List[int], k: int) -> int:
        freq = defaultdict(int)
        left = 0
        ans = 0

        for right in range(len(nums)):
            freq[nums[right]] += 1
            # 若当前元素超频，收缩左端
            while freq[nums[right]] > k:
                freq[nums[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：使用 Counter

```python
from typing import List
from collections import Counter

class Solution:
    def maxSubarrayLength(self, nums: List[int], k: int) -> int:
        freq = Counter()
        left = 0
        ans = 0

        for right, x in enumerate(nums):
            freq[x] += 1
            while freq[x] > k:
                freq[nums[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各最多遍历 n 次
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 滑动窗口：右端扩展，违反条件时收缩左端
2. 每次只有 nums[right] 可能超频（其他元素频率不变），所以只需检查 nums[right]
3. 收缩直到 nums[right] 的频率恢复 <= k

## 易错点

1. 收缩时要减少 nums[left] 的频率，不是减少 nums[right]
2. while 循环而不是 if：可能需要收缩多次
3. 答案取最大长度，在每次右端扩展后更新
