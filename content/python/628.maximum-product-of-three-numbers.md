## 题目描述

给你一个整型数组 `nums`，在数组中找出由三个数组成的最大乘积，并输出这个乘积。

**示例 1：**

```
输入：nums = [1,2,3]
输出：6
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：24
```

**示例 3：**

```
输入：nums = [-1,-2,-3]
输出：-6
```

**提示：**

- `3 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

## 解题思路

**关键观察：**最大乘积只可能来自：
1. **三个最大的正数**
2. **两个最小的负数 × 一个最大的正数**（负负得正）

**核心方法：**
- 排序后比较 `nums[-1] * nums[-2] * nums[-3]` 和 `nums[0] * nums[1] * nums[-1]`
- 或一次遍历找出最大三个和最小两个

## Python 代码实现

### 方法一：排序（推荐）⭐

```python
from typing import List

class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        """
        排序后比较两种情况
        
        时间复杂度：O(n log n)
        空间复杂度：O(1)
        """
        nums.sort()
        # 情况1：三个最大数
        # 情况2：两个最小数 × 最大数
        return max(nums[-1] * nums[-2] * nums[-3], 
                   nums[0] * nums[1] * nums[-1])
```

### 方法二：线性扫描（最优）⭐⭐

```python
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        """
        一次遍历找出最大三个和最小两个
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        import sys
        
        # 初始化最大的三个数
        max1 = max2 = max3 = -sys.maxsize
        # 初始化最小的两个数
        min1 = min2 = sys.maxsize
        
        for num in nums:
            # 更新最大三个
            if num > max1:
                max3, max2, max1 = max2, max1, num
            elif num > max2:
                max3, max2 = max2, num
            elif num > max3:
                max3 = num
            
            # 更新最小两个
            if num < min1:
                min2, min1 = min1, num
            elif num < min2:
                min2 = num
        
        return max(max1 * max2 * max3, min1 * min2 * max1)
```

## 复杂度分析

- **方法一**：O(n log n) 时间，O(1) 空间
- **方法二**：O(n) 时间，O(1) 空间

## 关键点总结

1. **负数特性**：两个负数相乘变正数
2. **只需比较两种情况**：三个最大 vs 两小一大
3. **排序简化思考**：直观易理解
4. **线性扫描优化**：O(n) 时间复杂度
