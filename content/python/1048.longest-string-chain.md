## 题目描述

给出一个单词数组 `words`，其中每个单词都由小写英文字母组成。

如果我们可以**在 `wordA` 的任何地方添加一个字母**使其变成 `wordB`，那么我们认为 `wordA` 是 `wordB` 的**前身**。

- 例如，`"abc"` 是 `"abac"` 的前身，而 `"cba"` 不是 `"bcad"` 的前身

**词链**是单词 `[word_1, word_2, ..., word_k]` 组成的序列，`k >= 1`，其中 `word_1` 是 `word_2` 的前身，`word_2` 是 `word_3` 的前身，依此类推。一个单词链的**长度**为 `k`。

从给定单词列表 `words` 中选择单词组成词链，返回**词链的最大可能长度**。

**示例 1：**

```
输入：words = ["a","b","ba","bca","bda","bdca"]
输出：4
解释：最长单词链之一为 ["a","ba","bda","bdca"]
```

**示例 2：**

```
输入：words = ["xbc","pcxbcf","xb","cxbc","pcxbc"]
输出：5
解释：所有的单词都可以放入单词链 ["xb", "xbc", "cxbc", "pcxbc", "pcxbcf"]
```

**示例 3：**

```
输入：words = ["abcd","dbqca"]
输出：1
解释：字典中任意两个单词都不是另一个的前身，所以最长单词链长度为 1
```

**提示：**

- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 16`
- `words[i]` 仅由小写英文字母组成

## 解题思路

这道题的核心是寻找**最长递增子序列**的变种，可以使用**动态规划**求解。

**关键观察：**
1. 如果 `wordA` 是 `wordB` 的前身，那么 `len(wordB) = len(wordA) + 1`
2. 我们可以通过删除 `wordB` 中的某个字符来检查是否能得到 `wordA`
3. 词链具有最优子结构：最长词链的子链也是最长的

**动态规划思路：**

定义 `dp[word]` 表示**以 `word` 结尾的最长词链长度**。

状态转移：
- 对于每个单词 `word`，尝试删除其中的每个字符得到 `prev`
- 如果 `prev` 在字典中存在，则 `dp[word] = max(dp[word], dp[prev] + 1)`
- 初始值：`dp[word] = 1`（每个单词本身构成长度为 1 的词链）

**关键优化：按长度排序**

为了保证 `dp[prev]` 在计算 `dp[word]` 时已经计算完毕，我们需要**按照单词长度从小到大处理**。

**算法流程：**
1. 按照单词长度从小到大排序
2. 使用哈希表 `dp` 存储每个单词的最长词链长度
3. 遍历每个单词，尝试删除每个字符：
   - 如果删除后的单词存在于 `dp` 中，更新当前单词的 `dp` 值
4. 返回所有 `dp` 值中的最大值

## Python 代码实现

### 方法一：动态规划 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def longestStrChain(self, words: List[str]) -> int:
        # 按照单词长度从小到大排序
        words.sort(key=len)
        
        # dp[word] 表示以 word 结尾的最长词链长度
        dp = {}
        
        # 遍历每个单词
        for word in words:
            # 初始值：当前单词本身构成长度为 1 的词链
            dp[word] = 1
            
            # 尝试删除当前单词的每个字符
            for i in range(len(word)):
                # 删除第 i 个字符后得到的前身单词
                prev = word[:i] + word[i + 1:]
                
                # 如果前身单词存在，更新当前单词的最长词链长度
                if prev in dp:
                    dp[word] = max(dp[word], dp[prev] + 1)
        
        # 返回所有单词中最长的词链长度
        return max(dp.values())
```

### 方法二：动态规划 + 集合优化

```python
from typing import List

class Solution:
    def longestStrChain(self, words: List[str]) -> int:
        # 按照单词长度排序
        words.sort(key=len)
        
        # 使用集合快速查找单词是否存在
        word_set = set(words)
        dp = {}
        max_length = 1
        
        for word in words:
            dp[word] = 1
            
            # 尝试删除每个字符
            for i in range(len(word)):
                prev = word[:i] + word[i + 1:]
                
                # 如果前身单词存在于集合中
                if prev in word_set and prev in dp:
                    dp[word] = max(dp[word], dp[prev] + 1)
            
            # 实时更新最大长度，避免最后再遍历
            max_length = max(max_length, dp[word])
        
        return max_length
```

### 方法三：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def longestStrChain(self, words: List[str]) -> int:
        word_set = set(words)
        
        @lru_cache(None)
        def dfs(word: str) -> int:
            # 尝试删除每个字符，找到最长的前身链
            max_chain = 1
            
            for i in range(len(word)):
                prev = word[:i] + word[i + 1:]
                
                if prev in word_set:
                    max_chain = max(max_chain, dfs(prev) + 1)
            
            return max_chain
        
        # 对每个单词尝试作为词链的终点
        return max(dfs(word) for word in words)
```

### 方法四：按长度分组优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestStrChain(self, words: List[str]) -> int:
        # 按照长度分组
        groups = defaultdict(set)
        for word in words:
            groups[len(word)].add(word)
        
        dp = {}
        max_length = 1
        
        # 按照长度从小到大处理
        for length in sorted(groups.keys()):
            for word in groups[length]:
                dp[word] = 1
                
                # 只需要在长度为 length - 1 的组中查找前身
                for i in range(len(word)):
                    prev = word[:i] + word[i + 1:]
                    
                    if prev in groups[length - 1]:
                        dp[word] = max(dp[word], dp[prev] + 1)
                
                max_length = max(max_length, dp[word])
        
        return max_length
```

## 复杂度分析

### 方法一：动态规划 + 哈希表（推荐）
- **时间复杂度：** `O(n * L²)`
  - 排序：`O(n log n)`
  - 遍历每个单词：`O(n)`
  - 对每个单词，删除每个字符：`O(L)`，每次创建新字符串：`O(L)`
  - 总时间：`O(n log n + n * L²)`，其中 `L` 是单词的平均长度
- **空间复杂度：** `O(n)` - 哈希表存储所有单词的 `dp` 值

### 方法二：动态规划 + 集合优化
- **时间复杂度：** `O(n * L²)` - 与方法一相同
- **空间复杂度：** `O(n)` - 需要额外的集合存储单词

### 方法三：记忆化递归
- **时间复杂度：** `O(n * L²)` - 每个单词最多计算一次
- **空间复杂度：** `O(n * L)` - 递归调用栈 + 记忆化缓存

### 方法四：按长度分组优化
- **时间复杂度：** `O(n * L²)` - 与方法一相同
- **空间复杂度：** `O(n)` - 分组存储所有单词

## 关键点总结

1. **动态规划思想**：问题具有最优子结构，适合用 DP 求解
2. **排序优化**：按照长度排序确保计算顺序正确
3. **哈希表加速**：使用哈希表快速查找前身单词
4. **字符串操作**：通过删除字符来检查前身关系
5. **状态定义**：`dp[word]` 表示以 `word` 结尾的最长词链长度

## 易错点

1. **忘记排序**
   ```python
   # 错误：不排序可能导致 dp[prev] 未计算
   for word in words:
       dp[word] = 1
       for i in range(len(word)):
           prev = word[:i] + word[i + 1:]
           if prev in dp:
               dp[word] = max(dp[word], dp[prev] + 1)
   
   # 正确：先按长度排序
   words.sort(key=len)
   ```

2. **字符串切片错误**
   ```python
   # 错误：删除第 i 个字符的方式
   prev = word[:i] + word[i:]  # 这样没有删除任何字符
   
   # 正确：跳过第 i 个字符
   prev = word[:i] + word[i + 1:]
   ```

3. **初始值设置**
   ```python
   # 错误：不初始化可能导致 KeyError
   if prev in dp:
       dp[word] = dp[prev] + 1
   
   # 正确：先初始化为 1
   dp[word] = 1
   if prev in dp:
       dp[word] = max(dp[word], dp[prev] + 1)
   ```

4. **返回值错误**
   ```python
   # 错误：dp 是字典，不能直接返回
   return dp
   
   # 正确：返回最大值
   return max(dp.values())
   ```
