## 题目描述

给你一个整数数组 `windows`（初始窗口列表）和一个整数数组 `queries`。

对于每个 `query`，将对应的窗口移动到列表的最前面。

返回所有 `queries` 处理完后的窗口列表。

**示例 1：**
```
输入：windows = [1,2,3], queries = [3,3,2]
输出：[2,3,1]
```

**示例 2：**
```
输入：windows = [1,2,3], queries = [4,1,3]
输出：[3,1,2]
注意：4 不在 windows 中，忽略。
```

**提示：**
- `1 <= windows.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

维护一个有序集合，每次将查询到的元素移到最前面。

由于每次操作后元素仍在列表中（只是位置变化），可以：
1. 记录哪些元素被"提前"过（用一个集合和一个前缀列表）
2. 最终结果 = 按查询反向顺序去重的元素 + 原始列表中未被查询的元素

## Python 代码实现

### 方法一：逆序处理（推荐）

```python
from typing import List

class Solution:
    def simulationResult(self, windows: List[int], queries: List[int]) -> List[int]:
        window_set = set(windows)
        
        # 逆序处理 queries，后出现的先放前面
        # 最终顺序：最后一次被 query 的先，然后是从未被 query 的
        result = []
        seen = set()
        
        # 从后往前遍历 queries，去重（只保留每个元素最后一次被查询的位置）
        for q in reversed(queries):
            if q in window_set and q not in seen:
                seen.add(q)
                result.append(q)
        
        # 加入未被查询的窗口（保持原顺序）
        for w in windows:
            if w not in seen:
                result.append(w)
        
        return result
```

### 方法二：直接模拟（效率较低）

```python
from typing import List

class Solution:
    def simulationResult(self, windows: List[int], queries: List[int]) -> List[int]:
        from collections import OrderedDict
        
        # 用有序字典模拟
        od = {w: None for w in windows}
        
        for q in queries:
            if q in od:
                # 移到最前面
                del od[q]
                od = {q: None, **od}
        
        return list(od.keys())
```

## 复杂度分析

- 方法一：时间复杂度 O(n + m)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n * m)（字典重建），不推荐

## 关键点总结

1. 逆序处理 queries：后被查询的优先级最高（最终在前面）
2. 对每个 query 去重，只保留最后一次出现
3. 原始 windows 中未被查询的保持相对顺序

## 易错点

1. query 中可能有不在 windows 中的元素，需要过滤
2. 同一个窗口多次被查询，只保留最后一次的位置
