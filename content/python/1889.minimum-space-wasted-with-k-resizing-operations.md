## 题目描述

你有一个数组 `nums` 和一个数字 k。数组代表内存使用情况，必须为每个元素分配内存，分配量必须 >= 当前使用量，且每次分配量必须相同（由最大值决定）。

可以进行 k 次**调整大小**操作（每次调整改变为当前段的最大值），返回最少浪费的内存。

**浪费量** = 分配量 - 使用量之和。

**示例：**
```
输入：nums = [10,20,15,30,20], k = 2
输出：15
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= k <= nums.length - 1`

## 解题思路

**动态规划**：

将 nums 分成 k+1 段（最多 k 次调整），每段的浪费量为 `(max - nums[i]) * len` 中的 sum，即 `max * len - sum`。

`dp[i][j]` = 前 i 个元素，进行了 j 次调整（分成 j+1 段）的最小浪费量。

`dp[i][j] = min(dp[p][j-1] + max(nums[p..i-1]) * (i-p) - sum(nums[p..i-1]))` for p in [j, i]

预计算区间最大值和前缀和加速。

## 代码实现

### 方法一：DP + 预计算（推荐）

```python
from typing import List

class Solution:
    def minSpaceWastedKResizing(self, nums: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')

        # 预计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 预计算区间最大值
        interval_max = [[0] * n for _ in range(n)]
        for i in range(n):
            interval_max[i][i] = nums[i]
            for j in range(i + 1, n):
                interval_max[i][j] = max(interval_max[i][j - 1], nums[j])

        # dp[j][i] = 前 i 个元素，调整 j 次的最小浪费
        dp = [[INF] * (n + 1) for _ in range(k + 2)]
        dp[0][0] = 0

        # 不调整时（0 次调整，1 段）
        for i in range(1, n + 1):
            max_val = max(nums[:i])
            total = sum(nums[:i])
            dp[0][i] = max_val * i - total

        # j 次调整
        for j in range(1, k + 1):
            for i in range(j + 1, n + 1):
                for p in range(j, i):
                    # 最后一段为 nums[p..i-1]
                    seg_max = interval_max[p][i - 1]
                    seg_sum = prefix[i] - prefix[p]
                    waste = seg_max * (i - p) - seg_sum
                    if dp[j - 1][p] != INF:
                        dp[j][i] = min(dp[j][i], dp[j - 1][p] + waste)

        return dp[k][n]
```

### 方法二：滚动数组优化

```python
from typing import List

class Solution:
    def minSpaceWastedKResizing(self, nums: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # prev[i] = 上一次调整后，前 i 个元素的最小浪费
        prev = [INF] * (n + 1)
        prev[0] = 0
        # 初始化 0 次调整
        for i in range(1, n + 1):
            mx = max(nums[:i])
            prev[i] = mx * i - prefix[i]

        for j in range(1, k + 1):
            curr = [INF] * (n + 1)
            for i in range(1, n + 1):
                mx = 0
                for p in range(i, 0, -1):
                    mx = max(mx, nums[p - 1])
                    seg_sum = prefix[i] - prefix[p - 1]
                    waste = mx * (i - p + 1) - seg_sum
                    if prev[p - 1] != INF:
                        curr[i] = min(curr[i], prev[p - 1] + waste)
            prev = curr

        return prev[n]
```

## 复杂度分析

- **时间复杂度**：O(k * n^2)，k 次调整，每次 O(n^2)
- **空间复杂度**：O(n^2)（预计算区间最大值）

## 关键点总结

1. 将问题转化为将数组分成 k+1 段，每段浪费量为 `max * len - sum`
2. 用前缀和快速计算区间和，用预计算快速获取区间最大值
3. DP 枚举每段的起点，取最小总浪费

## 易错点

- k 次调整意味着分成 k+1 段
- 每段的浪费量是 `max * len - sum`（不是 max - min）
