## 题目描述

给你一个用字符串表示的正整数 `num`，请你以字符串形式返回 **不含尾随零** 的整数 `num`。

**示例 1：**
```
输入：num = "51230100"
输出："512301"
解释：整数 "51230100" 有 2 个尾随零，移除后为 "512301"。
```

**示例 2：**
```
输入：num = "123"
输出："123"
解释：没有尾随零，直接返回 "123"。
```

**提示：**
- `1 <= num.length <= 1000`
- `num` 仅由数字 `0` 到 `9` 组成
- `num` 不含前导零

## 解题思路

直接使用字符串的 `rstrip` 方法去掉末尾的 `'0'` 字符，或从末尾手动遍历找到最后一个非零字符的位置进行切片。

## Python 代码实现

### 方法一：rstrip（推荐）

```python
class Solution:
    def removeTrailingZeros(self, num: str) -> str:
        # rstrip('0') 移除字符串右侧所有 '0' 字符
        return num.rstrip('0')
```

### 方法二：手动切片

```python
class Solution:
    def removeTrailingZeros(self, num: str) -> str:
        # 从末尾找到第一个非 '0' 的位置
        i = len(num) - 1
        while i >= 0 and num[i] == '0':
            i -= 1
        return num[:i + 1]
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(n)，返回新字符串

## 关键点总结

1. `rstrip` 专门用于去除右侧指定字符，非常简洁
2. 题目保证输入不含前导零，所以结果不可能为空字符串

## 易错点

1. `rstrip('0')` 只去除末尾的 `'0'`，不影响中间的 `'0'`
2. 不要混淆 `strip`（两端）、`lstrip`（左端）、`rstrip`（右端）
