## 题目描述

给定一个整数数组 `nums` 和整数 `k`。称一个子数组"质数差平衡"，如果子数组中任意两个质数之差的绝对值不超过 `k`。返回满足条件的子数组数量。

**示例 1：**

```
输入：nums = [1,2,3], k = 1
输出：6
解释：所有子数组 [1],[2],[3],[1,2],[2,3],[1,2,3]。
     [1,2,3] 中质数为 2,3，差=1<=1，满足。共 6 个。
```

**示例 2：**

```
输入：nums = [2,3,5,7], k = 1
输出：4
解释：[2],[3],[5],[7] 满足（单个质数或无质数）。
     [2,3] 差=1<=1 满足。[3,5] 差=2>1 不满足，其他含两个质数的子数组均不满足。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

关键观察：子数组平衡的条件是子数组内所有质数两两之差 <= k，等价于 max(质数) - min(质数) <= k。

使用滑动窗口维护当前窗口内质数的最大值和最小值：
1. 预处理：用埃拉托色尼筛法判断每个数是否为质数
2. 维护窗口内质数的有序集合或单调队列
3. 若 max - min > k，缩短左边界

对每个右端点 j，找到最小的左端点 l，使得 [l..j] 满足条件，则贡献 l 个子数组（左端点可以从 0 到 l）。

## Python 代码实现

### 方法一：滑动窗口 + 有序列表（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 埃氏筛
        MAX_VAL = max(nums) + 1 if nums else 2
        is_prime = [True] * (MAX_VAL + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(MAX_VAL**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, MAX_VAL + 1, i):
                    is_prime[j] = False

        # 滑动窗口
        sl = SortedList()  # 存储窗口内的质数
        left = 0
        ans = 0

        for right in range(n):
            if is_prime[nums[right]]:
                sl.add(nums[right])
            # 收缩左边界
            while sl and sl[-1] - sl[0] > k:
                if is_prime[nums[left]]:
                    sl.remove(nums[left])
                left += 1
            ans += right - left + 1

        return ans
```

### 方法二：滑动窗口 + 单调双端队列

```python
from typing import List
from collections import deque

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        MAX_VAL = max(nums) + 1 if nums else 2
        is_prime = [True] * (MAX_VAL + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(MAX_VAL**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, MAX_VAL + 1, i):
                    is_prime[j] = False

        # 维护质数的最大最小双端队列
        max_dq = deque()  # 单调递减（存下标）
        min_dq = deque()  # 单调递增（存下标）
        left = 0
        ans = 0

        for right in range(n):
            if is_prime[nums[right]]:
                # 更新最大队列
                while max_dq and nums[max_dq[-1]] <= nums[right]:
                    max_dq.pop()
                max_dq.append(right)
                # 更新最小队列
                while min_dq and nums[min_dq[-1]] >= nums[right]:
                    min_dq.pop()
                min_dq.append(right)

            # 收缩左边界，使 max - min <= k
            while max_dq and min_dq and nums[max_dq[0]] - nums[min_dq[0]] > k:
                if max_dq[0] == left:
                    max_dq.popleft()
                if min_dq[0] == left:
                    min_dq.popleft()
                left += 1

            ans += right - left + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)（SortedList 插入），O(n) 滑动窗口
- 空间复杂度：O(n + MAX_VAL)，筛法数组

## 关键点总结

1. 质数最大差 = max(质数) - min(质数) <= k 是平衡条件
2. 滑动窗口：右端点固定时，找最小合法左端点
3. 子数组计数：右端点 j，左端点范围 [left, j]，贡献 j-left+1

## 易错点

1. 非质数元素不影响平衡条件，只关注质数
2. 窗口内无质数时条件自动满足
3. 收缩左边界时，同时维护两个队列的队首
