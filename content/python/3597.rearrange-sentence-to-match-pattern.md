## 题目描述

给定一个句子字符串 `sentence`（单词用空格分隔）和一个模式字符串 `pattern`（单词用空格分隔）。重新排列 `sentence` 中的单词，使其满足 `pattern` 的模式。模式匹配规则：若 `pattern` 中两个位置的单词相同，则 `sentence` 对应位置的单词也应相同；若不同，则对应单词也应不同。

返回满足条件的重排结果（任意一个合法答案），若无法满足则返回空字符串。

**示例 1：**

```
输入：sentence = "I love leetcode", pattern = "a b a"
输出："I love I" 或 "leetcode love leetcode"
解释：a->I, b->love, a->I（第一个和第三个单词相同）。
```

**示例 2：**

```
输入：sentence = "hello world", pattern = "a a"
输出：""
解释：sentence 有两个不同单词，无法匹配 pattern = "a a"。
```

**提示：**
- `1 <= sentence.length, pattern.length <= 200`
- 单词只含小写字母

## 解题思路

将问题转化为单词同构（isomorphic words）：
1. 分别将 `sentence` 和 `pattern` 的单词列表归一化（词序编号化）
2. 比较两者的编号序列是否相同

归一化：`[a, b, a]` -> `[0, 1, 0]`，`[x, y, x]` -> `[0, 1, 0]`，两者归一化结果相同则匹配。

若匹配，按 pattern 的映射关系，将 sentence 的单词重新排列。

## Python 代码实现

### 方法一：归一化同构匹配（推荐）

```python
class Solution:
    def rearrangeSentence(self, sentence: str, pattern: str) -> str:
        s_words = sentence.split()
        p_words = pattern.split()

        if len(s_words) != len(p_words):
            return ""

        def normalize(words):
            mapping = {}
            result = []
            idx = 0
            for w in words:
                if w not in mapping:
                    mapping[w] = idx
                    idx += 1
                result.append(mapping[w])
            return result, mapping

        s_norm, s_map = normalize(s_words)
        p_norm, p_map = normalize(p_words)

        # 检查归一化序列是否相同
        if s_norm != p_norm:
            return ""

        # 构建 pattern 单词 -> sentence 单词 的映射
        # p_map: pattern_word -> 编号
        # s_map: sentence_word -> 编号（同编号的单词对应）
        # 构建编号 -> sentence_word 的反查
        num_to_s = {}
        for w, idx in s_map.items():
            num_to_s[idx] = w

        # 按 pattern 顺序重构
        result = []
        for pw in p_words:
            p_idx = p_map[pw]
            result.append(num_to_s[p_idx])

        return " ".join(result)
```

### 方法二：哈希双向映射

```python
class Solution:
    def rearrangeSentence(self, sentence: str, pattern: str) -> str:
        s_words = sentence.split()
        p_words = pattern.split()

        if len(s_words) != len(p_words):
            return ""

        n = len(s_words)

        # 建立 pattern 到 sentence 的映射，并检查一致性
        p_to_s = {}  # pattern 单词 -> sentence 单词
        s_to_p = {}  # sentence 单词 -> pattern 单词（避免多对一）

        for sw, pw in zip(s_words, p_words):
            if pw in p_to_s and p_to_s[pw] != sw:
                return ""  # 同一 pattern 单词对应不同 sentence 单词
            if sw in s_to_p and s_to_p[sw] != pw:
                return ""  # 同一 sentence 单词对应不同 pattern 单词
            p_to_s[pw] = sw
            s_to_p[sw] = pw

        # 按 pattern 顺序重构
        return " ".join(p_to_s[pw] for pw in p_words)
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为单词数，L 为单词平均长度
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 本质是同构字符串（isomorphic strings）问题的单词版
2. 需要双向映射：pattern->sentence 和 sentence->pattern
3. 一对一映射，不允许多对一或一对多

## 易错点

1. 只检查 pattern->sentence 不够，还需检查 sentence->pattern（避免一对多）
2. 单词数不同时直接返回空
3. 构建结果时按 pattern 的顺序，不是 sentence 的顺序
