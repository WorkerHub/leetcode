## 题目描述

给你一个整数数组 `nums` 和整数 `k`，可以将数组中的任意 `k` 个元素取反（乘以 -1）。返回操作后的最大子数组乘积（对 `10^9 + 7` 取模）。

**示例 1：**

```
输入：nums = [-1,-2,-3], k = 1
输出：6
解释：取反 -1→1，数组[1,-2,-3]，最大子数组乘积为1或6（取反-2→[1,2,-3]乘积2，取反-3→[1,-2,3]乘积3，取反-1→[1,-2,-3]乘积6）
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `0 <= k <= nums.length`

## 解题思路

DP：`dp_max[i][j]` = 在前 `i` 个元素中用了 `j` 次取反，以 `i` 结尾的最大乘积。

状态 `dp_max[i][j]` 和 `dp_min[i][j]`（最小乘积，因为负×负=正）。

复杂度 O(n^2 * k)，需要优化。

贪心思路：将绝对值最小的负数取反（若取反数为奇数），或将绝对值最小的正数取反（若还需再取反一次以保持偶数次）。

但要结合子数组求最大乘积，问题更复杂。

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)

        # dp_max[j] = 用了 j 次取反，以当前元素结尾的最大乘积
        # dp_min[j] = 用了 j 次取反，以当前元素结尾的最小乘积
        INF = float('inf')
        dp_max = [-INF] * (k + 1)
        dp_min = [INF] * (k + 1)

        ans = -INF

        for x in nums:
            new_max = [-INF] * (k + 1)
            new_min = [INF] * (k + 1)

            for j in range(k + 1):
                # 不取反 x
                # 接在之前序列后面
                if dp_max[j] != -INF:
                    new_max[j] = max(new_max[j], dp_max[j] * x)
                    new_min[j] = min(new_min[j], dp_min[j] * x)
                # 重新开始（只有 x 自己）
                new_max[j] = max(new_max[j], x)
                new_min[j] = min(new_min[j], x)

                # 取反 x（j 增加 1）
                if j + 1 <= k:
                    neg_x = -x
                    if dp_max[j] != -INF:
                        new_max[j + 1] = max(new_max[j + 1], dp_max[j] * neg_x)
                        new_min[j + 1] = min(new_min[j + 1], dp_min[j] * neg_x)
                    new_max[j + 1] = max(new_max[j + 1], neg_x)
                    new_min[j + 1] = min(new_min[j + 1], neg_x)

                ans = max(ans, new_max[j] % MOD)

            dp_max = new_max
            dp_min = new_min

        return ans % MOD
```

### 方法二：贪心（无子数组约束的简化版）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        # 贪心：取反绝对值最小的负数或最小的正数
        nums.sort(key=lambda x: abs(x))
        for i in range(k):
            nums[i] = -nums[i]
        # 求最大子数组乘积
        # （简化处理）
        max_p = min_p = 1
        ans = max(nums)
        for x in nums:
            max_p, min_p = max(x, max_p * x, min_p * x), min(x, max_p * x, min_p * x)
            ans = max(ans, max_p)
        return ans % MOD
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 子数组乘积 DP 需要同时维护最大和最小值（负负得正）
2. 取反操作在 DP 中通过增加取反计数处理
3. 每次 DP 转移需要枚举取反当前元素或不取反

## 易错点

1. 乘积可能很大，取模时注意负数处理
2. 最小乘积也要维护（可能成为最大乘积的来源）
3. 子数组可以从任意位置开始（重新开始选项）
