## 题目描述

给你一个整数 `n`，请你返回所有 `0 < numerator < denominator <= n` 且是**最简分数**的分数列表。

最简分数要求分子和分母的**最大公约数（GCD）等于 1**。

可以以任意顺序返回答案。

**示例 1：**
```
输入：n = 2
输出：["1/2"]
解释：1/2 是唯一满足条件的最简分数，因为 gcd(1,2) = 1。
```

**示例 2：**
```
输入：n = 3
输出：["1/2","1/3","2/3"]
```

**示例 3：**
```
输入：n = 4
输出：["1/2","1/3","1/4","2/3","3/4"]
解释：2/4 不是最简分数，因为 gcd(2,4) = 2。
```

**示例 4：**
```
输入：n = 1
输出：[]
解释：不存在满足条件的分数（分子必须严格小于分母且 > 0）。
```

**提示：**
- `1 <= n <= 100`

## 解题思路

**暴力枚举 + GCD 判断：**

枚举所有满足 `1 <= numerator < denominator <= n` 的分数对，判断 `gcd(numerator, denominator) == 1` 即为最简分数。

**GCD（最大公约数）：** Python 3.5+ 提供 `math.gcd(a, b)` 函数，直接调用即可。

**时间复杂度：** O(n² * log n)，外层两重循环 O(n²)，每次 gcd 计算 O(log n)（欧几里得算法）。

## Python 代码实现

### 方法一：双重循环 + math.gcd（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def simplifiedFractions(self, n: int) -> List[str]:
        result = []
        for denominator in range(2, n + 1):
            for numerator in range(1, denominator):
                # 判断是否为最简分数（gcd 为 1）
                if gcd(numerator, denominator) == 1:
                    result.append(f"{numerator}/{denominator}")
        return result
```

### 方法二：列表推导式（简洁版）

```python
from typing import List
from math import gcd

class Solution:
    def simplifiedFractions(self, n: int) -> List[str]:
        return [
            f"{num}/{den}"
            for den in range(2, n + 1)
            for num in range(1, den)
            if gcd(num, den) == 1
        ]
```

### 方法三：手写欧几里得算法（不依赖 math 库）

```python
from typing import List

class Solution:
    def simplifiedFractions(self, n: int) -> List[str]:
        def gcd(a: int, b: int) -> int:
            """欧几里得算法求最大公约数"""
            while b:
                a, b = b, a % b
            return a

        result = []
        for den in range(2, n + 1):
            for num in range(1, den):
                if gcd(num, den) == 1:
                    result.append(f"{num}/{den}")
        return result
```

### 方法四：使用 fractions 模块

```python
from typing import List
from fractions import Fraction

class Solution:
    def simplifiedFractions(self, n: int) -> List[str]:
        seen = set()
        result = []

        for den in range(2, n + 1):
            for num in range(1, den):
                # Fraction 自动化简，利用唯一性去重
                f = Fraction(num, den)
                if f not in seen:
                    seen.add(f)
                    if f.numerator == num and f.denominator == den:
                        # 化简后与原分数相同，说明是最简分数
                        result.append(f"{num}/{den}")

        return result
```

**注意：** 方法四较为间接，推荐方法一或方法二。

## 复杂度分析

- **时间复杂度：** O(n² log n)，双重循环 O(n²)，每次 `gcd` 调用 O(log n)。
- **空间复杂度：** O(1)（不计输出列表）。

## 图解示例

```
n = 4

枚举：
  den=2: num=1, gcd(1,2)=1 -> "1/2"
  den=3: num=1, gcd(1,3)=1 -> "1/3"
         num=2, gcd(2,3)=1 -> "2/3"
  den=4: num=1, gcd(1,4)=1 -> "1/4"
         num=2, gcd(2,4)=2 -> 跳过（非最简）
         num=3, gcd(3,4)=1 -> "3/4"

结果：["1/2","1/3","2/3","1/4","3/4"]
```

## 关键点总结

1. 最简分数 = 分子分母互质 = `gcd(分子, 分母) == 1`。
2. 欧几里得算法（辗转相除法）是计算 GCD 的经典算法，时间复杂度 O(log min(a,b))。
3. Python 的 `math.gcd(a, b)` 已足够高效，无需手写。
4. f-string `f"{num}/{den}"` 是 Python 3.6+ 格式化字符串的推荐方式。

## 易错点

- 条件应为 `0 < num < den <= n`，而非 `1 <= num <= den`（分子严格小于分母）。
- 枚举顺序：外层枚举分母，内层枚举分子（`num < den`），确保分数 `< 1`。
- `n=1` 时没有有效分数，直接返回空列表（循环不会执行，自然处理）。
