## 题目描述

给你一个下标从 0 开始的 `m x n` 整数矩阵 `grid`。你的初始位置在左上角 `(0, 0)`, 终点是右下角 `(m-1, n-1)`。

每步可以向右或向下移动，从 `(i, j)` 出发最多可以移动 `grid[i][j]` 步。

返回到达终点所需访问的最少单元格数目，若无法到达则返回 -1。

**示例 1：**
```
输入：grid = [[3,4,2,1],[4,2,3,1],[2,1,0,0],[2,4,0,0]]
输出：4
```

**示例 2：**
```
输入：grid = [[3,4,2,1],[4,2,1,1],[2,1,1,0],[3,4,0,0]]
输出：3
```

**数据范围：**
- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 10^5
- 1 <= m * n <= 10^5
- 0 <= grid[i][j] <= 10^5

## 解题思路

BFS + 有序集合优化：

BFS 按步数（访问格数）分层，使用有序集合维护每行/每列中尚未访问的下标，从当前格 `(i, j)` 出发：
- 向右：访问同行 `j+1` 到 `j+grid[i][j]` 中所有未访问格
- 向下：访问同列 `i+1` 到 `i+grid[i][j]` 中所有未访问格

用 `SortedList` 按列维护每行的未访问格，按行维护每列的未访问格，批量删除已访问格。

## Python 代码实现

### 方法一：BFS + SortedList（推荐）

```python
from typing import List
from collections import deque
from sortedcontainers import SortedList

class Solution:
    def minimumVisitedCells(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if m == 1 and n == 1:
            return 1

        # row_sets[i] = 第 i 行中还未访问的列下标集合
        row_sets = [SortedList(range(n)) for _ in range(m)]
        # col_sets[j] = 第 j 列中还未访问的行下标集合
        col_sets = [SortedList(range(m)) for _ in range(n)]

        # 初始位置 (0,0) 已访问
        row_sets[0].remove(0)
        col_sets[0].remove(0)

        queue = deque([(0, 0)])
        steps = 1

        while queue:
            steps += 1
            for _ in range(len(queue)):
                i, j = queue.popleft()
                d = grid[i][j]

                # 向右移动：同行，列从 j+1 到 j+d
                to_visit = []
                idx = row_sets[i].bisect_left(j + 1)
                while idx < len(row_sets[i]) and row_sets[i][idx] <= j + d:
                    nj = row_sets[i][idx]
                    if i == m - 1 and nj == n - 1:
                        return steps
                    to_visit.append((i, nj))
                    col_sets[nj].remove(i)
                    idx += 1
                for _, nj in to_visit:
                    row_sets[i].remove(nj)
                    queue.append((i, nj))

                # 向下移动：同列，行从 i+1 到 i+d
                to_visit = []
                idx = col_sets[j].bisect_left(i + 1)
                while idx < len(col_sets[j]) and col_sets[j][idx] <= i + d:
                    ni = col_sets[j][idx]
                    if ni == m - 1 and j == n - 1:
                        return steps
                    to_visit.append((ni, j))
                    row_sets[ni].remove(j)
                    idx += 1
                for ni, _ in to_visit:
                    col_sets[j].remove(ni)
                    queue.append((ni, j))

        return -1
```

### 方法二：动态规划（DP + 堆优化）

```python
from typing import List
import heapq

class Solution:
    def minimumVisitedCells(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        INF = float('inf')
        dp = [[INF] * n for _ in range(m)]
        dp[0][0] = 1

        # row_heaps[i] 是第 i 行的 (dp值, 列下标) 最小堆
        row_heaps = [[] for _ in range(m)]
        col_heaps = [[] for _ in range(n)]

        for i in range(m):
            for j in range(n):
                # 从行堆和列堆中获取最小步数
                while row_heaps[i] and row_heaps[i][0][1] < j:
                    heapq.heappop(row_heaps[i])
                if row_heaps[i]:
                    dp[i][j] = min(dp[i][j], row_heaps[i][0][0] + 1)

                while col_heaps[j] and col_heaps[j][0][1] < i:
                    heapq.heappop(col_heaps[j])
                if col_heaps[j]:
                    dp[i][j] = min(dp[i][j], col_heaps[j][0][0] + 1)

                if dp[i][j] < INF:
                    # 当前格可达，向行堆和列堆中加入可达范围
                    heapq.heappush(row_heaps[i], (dp[i][j], j + grid[i][j]))
                    heapq.heappush(col_heaps[j], (dp[i][j], i + grid[i][j]))

        return dp[m-1][n-1] if dp[m-1][n-1] < INF else -1
```

## 复杂度分析

- 方法一：时间复杂度 O(mn log(mn))
- 方法二：时间复杂度 O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. BFS 按层展开保证最短路
2. 用有序集合避免重复访问，批量删除
3. DP + 堆优化：每个格子只从堆顶（最优前驱）转移

## 易错点

1. 向右和向下分开处理，不能斜向移动
2. SortedList 删除操作要注意索引变化
3. 初始格 (0,0) 算 1 步
