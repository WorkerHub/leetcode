## 题目描述

给你两个字符串 `word1` 和 `word2`。

如果一个整数数组下标序列 `indices` 满足以下条件，则它被称为**有效序列**：
- `indices` 的长度等于 `word2` 的长度。
- 对于所有的 `i`（`0 <= i < word2.length`），`word1[indices[i]] == word2[i]`，**至多有一个** `i` 例外，此例外处 `word1[indices[i]] + 1 == word2[i]`（字母表中相邻的下一个字母）。
- `indices` 严格递增。

返回字典序最小的有效序列，若不存在则返回空数组。

**示例 1：**
```
输入：word1 = "vbcca", word2 = "abc"
输出：[0, 1, 2]
解释：indices[0] = 0（'v' 对应 'a'... 等等，具体参考题意）
```

**提示：**
- `1 <= word1.length, word2.length <= 3 * 10^5`

## 解题思路

**贪心 + 预处理：**

1. 预处理：从右向左计算 `suffix[i]` 表示从 `word1[i:]` 开始，最多能匹配 `word2` 从某位置开始的多少字符（后缀匹配）。具体地，`suffix[i]` 表示 `word1[i:]` 能从右向左匹配 `word2` 末尾多少个字符。

2. 贪心：从左向右遍历 `word1`，尽量让前面的下标越小越好（字典序最小），且前缀部分完全匹配 `word2` 前若干字符。

3. 当前位置可以作为"允许差一个"的特殊位置，若 `word1[i]+1 == word2[j]` 且后缀从 `i+1` 开始能匹配剩余的 `word2[j+1:]`，则可以在此处使用一次特例。

## Python 代码实现

### 方法一：贪心 + 后缀预处理（推荐）

```python
from typing import List

class Solution:
    def validSequence(self, word1: str, word2: str) -> List[int]:
        n, m = len(word1), len(word2)
        
        # suffix[i] 表示从 word1[i] 往后，能从 word2 末尾往前匹配多少个字符
        # 即 word1[i..n-1] 从右到左匹配 word2 末尾的最大匹配数
        suffix = [0] * (n + 1)
        j = m - 1
        for i in range(n - 1, -1, -1):
            if j >= 0 and word1[i] == word2[j]:
                suffix[i] = suffix[i + 1] + 1
                j -= 1
            else:
                suffix[i] = suffix[i + 1]
        
        result = []
        j = 0  # 当前需要匹配 word2[j]
        used_exception = False  # 是否已使用特例
        
        for i in range(n):
            if j == m:
                break
            if word1[i] == word2[j]:
                # 完全匹配，直接加入
                result.append(i)
                j += 1
            elif not used_exception:
                # 检查是否可以在此处使用特例（差一个字母）
                # word1[i] + 1 == word2[j] 且后续能匹配剩余
                if (ord(word2[j]) - ord(word1[i]) == 1 and
                        suffix[i + 1] >= m - j - 1):
                    result.append(i)
                    j += 1
                    used_exception = True
        
        if j == m:
            return result
        return []
```

## 复杂度分析

- 时间复杂度：O(n + m)，预处理后缀数组和一次遍历各是线性时间
- 空间复杂度：O(n)，后缀数组的空间

## 关键点总结

1. 后缀预处理是关键，提前知道每个位置之后能匹配多少 `word2` 末尾的字符。
2. 贪心地尽量选最小的下标，保证字典序最小。
3. 特例（差一个字母）只能使用一次，需要在满足后续能匹配的前提下尽早使用。

## 易错点

1. 特例的条件：`word1[i]` 的下一个字母等于 `word2[j]`，而不是前一个。
2. 后缀预处理时从右向左匹配，注意边界条件。
3. 需要判断 `suffix[i+1] >= m - j - 1` 确保后续字符能被覆盖。
