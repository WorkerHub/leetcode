## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums` 和一个整数 `threshold`。

找出满足以下条件的最长子数组的长度：
1. 子数组的第一个元素必须是偶数
2. 子数组中相邻元素的奇偶性不同（交替奇偶）
3. 子数组的所有元素都 <= `threshold`

**示例 1：**
```
输入：nums = [3,2,5,4], threshold = 5
输出：3
解释：子数组 [2,5,4]，起始偶数，交替奇偶，全 <= 5
```

**示例 2：**
```
输入：nums = [1,2], threshold = 2
输出：1
解释：只有 [2] 满足（长度1）
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

枚举每个偶数作为起点，向后延伸，检查奇偶交替且 <= threshold 的条件，统计最大长度。

## Python 代码实现

### 方法一：枚举起点（推荐）

```python
from typing import List

class Solution:
    def longestAlternatingSubarray(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            # 起点必须是偶数且 <= threshold
            if nums[i] % 2 != 0 or nums[i] > threshold:
                continue
            # 从 i 向后延伸
            length = 1
            for j in range(i + 1, n):
                # 奇偶交替且 <= threshold
                if nums[j] > threshold or nums[j] % 2 == nums[j - 1] % 2:
                    break
                length += 1
            ans = max(ans, length)

        return ans
```

### 方法二：滑动窗口

```python
from typing import List

class Solution:
    def longestAlternatingSubarray(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        ans = 0
        i = 0
        while i < n:
            if nums[i] % 2 != 0 or nums[i] > threshold:
                i += 1
                continue
            j = i + 1
            while j < n and nums[j] <= threshold and nums[j] % 2 != nums[j-1] % 2:
                j += 1
            ans = max(ans, j - i)
            i = j  # 从 j 重新找新起点
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)（方法二），O(n^2)（方法一，最坏情况）
- 空间复杂度：O(1)

## 关键点总结

1. 起点必须是偶数
2. 相邻元素奇偶性不同（交替）
3. 所有元素 <= threshold

## 易错点

1. 同时满足三个条件
2. 注意子数组长度为 1 时也合法（只要起点是偶数且 <= threshold）
