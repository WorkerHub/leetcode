## 题目描述

给你一个整数数组 `nums` 和整数 `threshold`。

若两个元素 `a` 和 `b` 满足 `lcm(a, b) <= threshold`，则在它们之间连一条边。

返回这样构成的图的**连通分量数**。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= threshold <= 10^5`

## 解题思路

**并查集 + 枚举因子：**

关键观察：`lcm(a, b) <= threshold` 当且仅当存在公因子 d，使得 `a = d * p`，`b = d * q`（p, q 互质），且 `d * p * q <= threshold`。

**枚举公倍数：** 对每个 d（从 1 到 threshold），枚举 threshold 以内的 d 的倍数，这些倍数中在 nums 中出现的元素都可以通过 d 连通。

具体：对每个 d，找所有 `d, 2d, 3d, ...` 中在 nums 中出现的元素，将它们用并查集合并。

因为：若 `a = pd` 且 `b = qd`（p <= q），则 `lcm(a, b) = d * p * q / gcd(p,q)`。为了保证 `lcm(a, b) <= threshold`，不一定所有 d 的倍数都满足，但枚举连通性时，若两个数都是 d 的倍数且它们的 lcm <= threshold，才连边。

**简化方法：** 对每个 d，枚举 d 的所有倍数（1*d, 2*d, ..., floor(threshold/d)*d），找连续的两个倍数（都在 nums 中），计算它们的 lcm。若 lcm <= threshold，则连边。

由于相邻倍数 `d*k` 和 `d*(k+1)` 的 lcm = d * k * (k+1)，这可能大于 threshold，但步骤 d 的最小公倍数 = d（当两个数都是 d 时，lcm = d），所以同一个 d 的所有倍数之间的最小公倍数的上界需要仔细分析。

**实用方法：** 对每个 `d`，将 nums 中所有 d 的倍数连接到第一个出现的倍数（`union(first[d], x)`）。

## Python 代码实现

### 方法一：并查集 + 枚举因子（推荐）

```python
from typing import List

class Solution:
    def countComponents(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        present = set(nums)
        
        # 并查集
        parent = list(range(threshold + 1))
        rank = [0] * (threshold + 1)
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1
        
        # 对每个 d，将 d 的所有倍数（在 nums 中的）连通
        for d in range(1, threshold + 1):
            first = -1
            for multiple in range(d, threshold + 1, d):
                if multiple in present:
                    if first == -1:
                        first = multiple
                    else:
                        union(first, multiple)
        
        # 统计连通分量：只考虑 nums 中的元素
        roots = set(find(x) for x in nums)
        return len(roots)
```

## 复杂度分析

- 时间复杂度：O(threshold * log(threshold))，调和级数
- 空间复杂度：O(threshold)

## 关键点总结

1. 通过枚举公约数 d，将所有 d 的倍数（出现在 nums 中的）连通。
2. 并查集合并操作实现连通性。
3. 最终统计 nums 中元素的不同根节点数即为连通分量数。

## 易错点

1. 只有 nums 中的元素才是节点，其他不参与连通分量计数。
2. 枚举的倍数范围是 `[d, threshold]`（不超过 threshold）。
3. 对同一个 d，第一个出现的倍数作为"根"，后续连到它。
