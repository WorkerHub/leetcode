## 题目描述

Alice 用旧手机发短信，按键对应的字母：
- 2: abc（最多3次）
- 3: def（最多3次）
- ...
- 7: pqrs（最多4次）
- 8: tuv（最多3次）
- 9: wxyz（最多4次）

给你一个按键序列字符串 `pressedKeys`，返回 Alice 可能发送的**不同信息数量**，对 `10^9 + 7` 取模。

**示例 1：**
```
输入：pressedKeys = "22233"
输出：8
解释："22" 可以是 "aa" 或 "b"，"33" 可以是 "dd" 或 "e"，"3" 是 "d"。共8种。
```

**示例 2：**
```
输入：pressedKeys = "222222222222222222222222222222222"
输出：10
```

## 解题思路

**分段动态规划：** 将按键序列按相同字符分段，每段独立计算可能的字母数量，各段结果相乘。

对一段连续相同字符（长度 n，可组合 2 或 3 个，7 和 9 可组合 2-4 个）：
- 设 `f(n)` 为将 n 个相同按键分组（每组 1-3 或 1-4 个）的方案数。
- 对于最多 3 个：`f(n) = f(n-1) + f(n-2) + f(n-3)`（每组取 1、2 或 3 个）。
- 对于最多 4 个（7 和 9）：`f(n) = f(n-1) + f(n-2) + f(n-3) + f(n-4)`。

## 代码实现

### 方法一：动态规划（推荐）

```python
from itertools import groupby

class Solution:
    def countTexts(self, pressedKeys: str) -> int:
        MOD = 10 ** 9 + 7
        # 可组合4个的键：7和9
        four_keys = {'7', '9'}
        ans = 1

        # 对连续相同字符分组
        for key, group in groupby(pressedKeys):
            n = len(list(group))
            max_group = 4 if key in four_keys else 3

            # dp[i] = 前 i 个按键的方案数
            dp = [0] * (n + 1)
            dp[0] = 1
            for i in range(1, n + 1):
                for j in range(1, min(max_group, i) + 1):
                    dp[i] = (dp[i] + dp[i - j]) % MOD

            ans = ans * dp[n] % MOD

        return ans
```

### 方法二：预计算 + 快速查表

```python
class Solution:
    def countTexts(self, pressedKeys: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(pressedKeys)

        # dp3[i]: 连续 i 个只能1-3组合的方案数
        # dp4[i]: 连续 i 个可以1-4组合的方案数
        dp3 = [0] * (n + 1)
        dp4 = [0] * (n + 1)
        dp3[0] = dp4[0] = 1

        for i in range(1, n + 1):
            dp3[i] = (dp3[i-1] + (dp3[i-2] if i>=2 else 0) + (dp3[i-3] if i>=3 else 0)) % MOD
            dp4[i] = (dp4[i-1] + (dp4[i-2] if i>=2 else 0) + (dp4[i-3] if i>=3 else 0) + (dp4[i-4] if i>=4 else 0)) % MOD

        ans = 1
        i = 0
        while i < n:
            j = i
            while j < n and pressedKeys[j] == pressedKeys[i]:
                j += 1
            length = j - i
            if pressedKeys[i] in ('7', '9'):
                ans = ans * dp4[length] % MOD
            else:
                ans = ans * dp3[length] % MOD
            i = j

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历一次字符串并计算 DP。
- 空间复杂度：O(n)，DP 数组。

## 关键点总结

1. 将连续相同字符分段，每段独立计算方案数，各段乘积为总答案。
2. 7 和 9 键可组合 1-4 个，其余键可组合 1-3 个。
3. DP 递推：`f(i) = f(i-1) + f(i-2) + f(i-3)` 或 `f(i-1) + f(i-2) + f(i-3) + f(i-4)`。

## 易错点

- 7 和 9 键对应 pqrs 和 wxyz，各 4 个字母，可以连按 1-4 次。
- 其余键（2-6, 8）对应 3 个字母，可以连按 1-3 次。
- 注意取模运算，最终结果对 `10^9 + 7` 取模。
