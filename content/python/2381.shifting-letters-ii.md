## 题目描述

给你一个字符串 `s` 和一个二维整数数组 `shifts`，其中 `shifts[i] = [start_i, end_i, direction_i]`。

对于每次移位操作，将字符串中 `[start_i, end_i]` 范围内的字母向前（`direction_i == 1`，向后）或向后（`direction_i == 0`，向前）移动一位。

所有移位操作**同时**作用，返回最终的字符串。

注意：`'a'` 向后移变成 `'z'`，`'z'` 向前移变成 `'a'`（环形）。

**示例 1：**
```
输入：s = "abc", shifts = [[0,1,0],[1,2,1]]
输出："ace"
解释：[0,1] 向后移：a->z, b->a；[1,2] 向前移：b->c, c->d。
合并：a=a(-1)=z->不对... 实际 a 向后移（direction=0）是 a->z。
注：direction=1 向前（字母表顺序，a->b），direction=0 向后（b->a）。
```

**提示：**
- `1 <= s.length, shifts.length <= 5 * 10^4`
- `0 <= start_i <= end_i < s.length`
- `direction_i` 为 `0` 或 `1`

## 解题思路

**差分数组：**
对每个位置，计算所有区间操作的总移位量（正数向前移，负数向后移），用差分数组实现区间加法，然后对每个位置取模 26 得到最终偏移量。

## 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        n = len(s)
        diff = [0] * (n + 1)  # 差分数组
        
        for start, end, direction in shifts:
            delta = 1 if direction == 1 else -1
            diff[start] += delta
            diff[end + 1] -= delta
        
        # 前缀和得到每个位置的总移位量
        result = []
        total_shift = 0
        for i in range(n):
            total_shift += diff[i]
            # 计算新字符
            new_ord = (ord(s[i]) - ord('a') + total_shift) % 26
            result.append(chr(ord('a') + new_ord))
        
        return ''.join(result)
```

### 方法二：前缀和

```python
from typing import List

class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        n = len(s)
        delta = [0] * (n + 1)
        
        for l, r, d in shifts:
            v = 1 if d == 1 else -1
            delta[l] += v
            delta[r + 1] -= v
        
        ans = []
        cur = 0
        for i, c in enumerate(s):
            cur += delta[i]
            new_c = (ord(c) - ord('a') + cur % 26 + 26) % 26
            ans.append(chr(ord('a') + new_c))
        
        return ''.join(ans)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 差分数组 | O(n + m) | O(n) |

其中 m 为 shifts 长度。

## 关键点总结

1. 差分数组 + 前缀和实现区间加法，O(m + n) 处理所有操作。
2. 移位取模 26 时，Python 的 `%` 对负数也返回非负结果，无需额外处理。
3. `direction == 1` 向前（+1），`direction == 0` 向后（-1）。

## 易错点

- Python 的 `%` 运算对负数安全（如 `-1 % 26 == 25`），但其他语言需要 `(cur % 26 + 26) % 26`。
- 差分数组大小为 `n + 1`（多出一位用于右边界处理）。
