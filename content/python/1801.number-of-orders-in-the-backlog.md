## 题目描述

给你一个二维整数数组 `orders`，其中每个 `orders[i] = [price, amount, orderType]` 表示第 `i` 笔订单：
- `price` 是该订单的价格
- `amount` 是该订单的数量
- `orderType` 为 `0` 表示这是一笔买单，为 `1` 表示这是一笔卖单

所有订单按照给定顺序处理。积压订单（backlog）最初是空的。处理每一笔订单时：
- 如果是买单（orderType == 0），则价格最低的卖单可以与其匹配
- 如果是卖单（orderType == 1），则价格最高的买单可以与其匹配

返回积压订单中买单和卖单的总数量，由于数字可能很大，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：orders = [[10,5,0],[15,2,1],[25,1,1],[30,4,0],[2,3,1]]
输出：6
```

**示例 2：**
```
输入：orders = [[7,1000000000,1],[15,3,0],[5,999999995,0],[5,1,1]]
输出：999999984
```

**提示：**
- `1 <= orders.length <= 10^5`
- `orders[i].length == 3`
- `1 <= price <= 10^9`
- `1 <= amount <= 10^9`
- `orderType` 为 `0` 或 `1`

## 解题思路

使用两个堆来维护积压订单：
- **买单堆**：最大堆（用负数模拟），存储当前积压的买单，堆顶为价格最高的买单
- **卖单堆**：最小堆，存储当前积压的卖单，堆顶为价格最低的卖单

对于每笔新订单：
1. 如果是买单，尝试与卖单堆堆顶匹配（卖单价格 <= 买单价格才能成交）
2. 如果是卖单，尝试与买单堆堆顶匹配（买单价格 >= 卖单价格才能成交）
3. 匹配后如有剩余，加入对应积压堆

## 代码实现

### 方法一：双堆模拟（推荐）

```python
import heapq
from typing import List

class Solution:
    def getNumberOfBacklogOrders(self, orders: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        # 买单最大堆（用负价格模拟）
        buy_heap = []
        # 卖单最小堆
        sell_heap = []

        for price, amount, order_type in orders:
            if order_type == 0:
                # 处理买单：尝试与价格最低的卖单匹配
                while amount > 0 and sell_heap and sell_heap[0][0] <= price:
                    sell_price, sell_amount = heapq.heappop(sell_heap)
                    if sell_amount <= amount:
                        # 卖单全部成交
                        amount -= sell_amount
                    else:
                        # 卖单部分成交，剩余推回堆
                        heapq.heappush(sell_heap, (sell_price, sell_amount - amount))
                        amount = 0
                if amount > 0:
                    # 未完全成交，加入买单积压堆（用负价格实现最大堆）
                    heapq.heappush(buy_heap, (-price, amount))
            else:
                # 处理卖单：尝试与价格最高的买单匹配
                while amount > 0 and buy_heap and -buy_heap[0][0] >= price:
                    buy_price, buy_amount = heapq.heappop(buy_heap)
                    buy_price = -buy_price  # 还原为正数
                    if buy_amount <= amount:
                        # 买单全部成交
                        amount -= buy_amount
                    else:
                        # 买单部分成交，剩余推回堆
                        heapq.heappush(buy_heap, (-buy_price, buy_amount - amount))
                        amount = 0
                if amount > 0:
                    # 未完全成交，加入卖单积压堆
                    heapq.heappush(sell_heap, (price, amount))

        # 统计积压订单总数
        total = 0
        for _, amount in buy_heap:
            total = (total + amount) % MOD
        for _, amount in sell_heap:
            total = (total + amount) % MOD
        return total
```

### 方法二：字典+堆（处理相同价格合并）

```python
import heapq
from collections import defaultdict
from typing import List

class Solution:
    def getNumberOfBacklogOrders(self, orders: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        # 用字典记录每个价格的积压数量
        buy_dict = defaultdict(int)
        sell_dict = defaultdict(int)
        buy_heap = []   # 最大堆（存负价格）
        sell_heap = []  # 最小堆

        for price, amount, order_type in orders:
            if order_type == 0:
                # 买单：与卖单匹配
                while amount > 0 and sell_heap and sell_heap[0] <= price:
                    sp = sell_heap[0]
                    traded = min(amount, sell_dict[sp])
                    amount -= traded
                    sell_dict[sp] -= traded
                    if sell_dict[sp] == 0:
                        heapq.heappop(sell_heap)
                        del sell_dict[sp]
                if amount > 0:
                    if buy_dict[-price] == 0:
                        heapq.heappush(buy_heap, -price)
                    buy_dict[-price] += amount
            else:
                # 卖单：与买单匹配
                while amount > 0 and buy_heap and -buy_heap[0] >= price:
                    bp = buy_heap[0]  # 负价格
                    traded = min(amount, buy_dict[bp])
                    amount -= traded
                    buy_dict[bp] -= traded
                    if buy_dict[bp] == 0:
                        heapq.heappop(buy_heap)
                        del buy_dict[bp]
                if amount > 0:
                    if sell_dict[price] == 0:
                        heapq.heappush(sell_heap, price)
                    sell_dict[price] += amount

        total = sum(buy_dict.values()) + sum(sell_dict.values())
        return total % MOD
```

## 复杂度分析

- **时间复杂度**：O(n log n)，每笔订单最多执行一次堆的插入和删除，每次 O(log n)
- **空间复杂度**：O(n)，堆中最多存储 n 笔积压订单

## 关键点总结

1. 买单用最大堆，卖单用最小堆，方便快速找到最优匹配对象
2. Python 的 `heapq` 只支持最小堆，模拟最大堆需要存负值
3. 成交时需要处理部分成交的情况，将剩余量推回堆
4. 最终结果需要对 10^9 + 7 取模

## 易错点

- 忘记对结果取模
- 使用负价格模拟最大堆时，取出后要还原为正数再比较
- 部分成交后未将剩余量正确推回堆
