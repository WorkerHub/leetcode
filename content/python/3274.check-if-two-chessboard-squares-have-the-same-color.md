## 题目描述

给你两个字符串 `coordinate1` 和 `coordinate2`，表示国际象棋棋盘上的两个格子（如 "a1"、"h8"）。

如果两个格子颜色相同，返回 `true`；否则返回 `false`。

棋盘格子的颜色规则：列从 a 到 h（a=1, b=2, ..., h=8），行从 1 到 8，(列号+行号) 为偶数时为一种颜色，奇数时为另一种颜色。

**示例 1：**
```
输入：coordinate1 = "a1", coordinate2 = "h3"
输出：false
解释：a1=(1+1)=2偶，h3=(8+3)=11奇，颜色不同
```

**示例 2：**
```
输入：coordinate1 = "a1", coordinate2 = "c3"
输出：true
```

**提示：**
- `coordinate1.length == coordinate2.length == 2`
- 第一个字符是 'a' 到 'h' 的字母
- 第二个字符是 '1' 到 '8' 的数字

## 解题思路

计算每个格子的"颜色值"（列号+行号 的奇偶性），相同奇偶性颜色相同。

## Python 代码实现

### 方法一：计算奇偶性（推荐）

```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        def color(coord):
            # 列：a=1, b=2, ..., h=8
            col = ord(coord[0]) - ord('a') + 1
            row = int(coord[1])
            return (col + row) % 2
        
        return color(coordinate1) == color(coordinate2)
```

### 方法二：异或判断

```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        # 颜色相同 <=> (col1+row1) 和 (col2+row2) 奇偶性相同
        # <=> (col1+row1+col2+row2) 为偶数
        # <=> (col1 XOR col2 XOR row1 XOR row2) 的 LSB 为 0
        
        def parity(coord):
            return (ord(coord[0]) + int(coord[1])) % 2
        
        return parity(coordinate1) == parity(coordinate2)
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 棋盘颜色由 (列号 + 行号) 的奇偶性决定
2. 两格颜色相同 = 两格奇偶性相同
3. 用 `ord(c) - ord('a')` 将字母转为数字

## 易错点

1. 列从 'a' 开始，行从 '1' 开始，都是 1 到 8
2. (a=1，行=1) 的和为 2，是偶数
