## 题目描述

给你一个字符串 `s`，如果可以将它分割成三个**非空**回文子字符串，则返回 `true`，否则返回 `false`。

也就是说，如果存在三个下标 `i`、`j`，满足 `1 <= i < j < s.length - 1`（即三段都非空），且 `s[0..i-1]`、`s[i..j]`、`s[j+1..]` 都是回文串，则返回 `true`。

**示例 1：**
```
输入：s = "abcbdd"
输出：true
解释："a" + "bcb" + "dd"，三段都是回文
```

**示例 2：**
```
输入：s = "bcbddxy"
输出：false
```

**提示：**
- `1 <= s.length <= 2000`

## 解题思路

**预处理所有子串是否为回文**（区间 DP），然后枚举两个分割点。

预处理：`is_pal[i][j]` 表示 `s[i..j]` 是否为回文串，用区间 DP O(n^2) 预处理。

枚举：枚举所有分割点 `(i, j)`，判断三段是否均为回文。

## 代码实现

### 方法一：区间 DP 预处理 + 枚举（推荐）

```python
class Solution:
    def checkPartitioning(self, s: str) -> bool:
        n = len(s)
        
        # 预处理：is_pal[i][j] 表示 s[i..j] 是否为回文
        is_pal = [[False] * n for _ in range(n)]
        
        # 长度为 1 的子串都是回文
        for i in range(n):
            is_pal[i][i] = True
        
        # 长度为 2 的子串
        for i in range(n - 1):
            is_pal[i][i + 1] = (s[i] == s[i + 1])
        
        # 长度 >= 3 的子串
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                is_pal[i][j] = (s[i] == s[j]) and is_pal[i + 1][j - 1]
        
        # 枚举两个分割点（三段各非空）
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                # s[0..i-1], s[i..j-1], s[j..n-1]
                if is_pal[0][i - 1] and is_pal[i][j - 1] and is_pal[j][n - 1]:
                    return True
        
        return False
```

### 方法二：Manacher 算法（更快）

```python
class Solution:
    def checkPartitioning(self, s: str) -> bool:
        n = len(s)
        
        # Manacher 算法预处理
        # 在字符间插入 '#'
        t = '#' + '#'.join(s) + '#'
        m = len(t)
        p = [0] * m  # p[i] 是以 t[i] 为中心的回文半径
        
        c = r = 0
        for i in range(m):
            if i < r:
                p[i] = min(r - i, p[2 * c - i])
            while i - p[i] - 1 >= 0 and i + p[i] + 1 < m and t[i - p[i] - 1] == t[i + p[i] + 1]:
                p[i] += 1
            if i + p[i] > r:
                c, r = i, i + p[i]
        
        # 转换：原字符串 s[l..r] 对应 t[2l+1..2r+1]，中心在 t[l+r+1]，半径 >= r-l+1
        def is_palindrome(l, r):
            # 转为 t 的索引：中心 = l + r + 1，需要半径 >= r - l + 1
            center = l + r + 1  # t 中的中心索引（0-indexed）
            return p[center] >= r - l + 1
        
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                if is_palindrome(0, i - 1) and is_palindrome(i, j - 1) and is_palindrome(j, n - 1):
                    return True
        
        return False
```

## 复杂度分析

- **方法一**：时间 O(n^2)，空间 O(n^2)
- **方法二**：时间 O(n^2)（枚举分割点），空间 O(n)

## 关键点总结

1. 预处理所有子串的回文性，避免重复计算
2. 枚举两个分割点，三段均非空的条件是 `1 <= i < j < n`

## 易错点

- 分割点的范围：三段都非空，第一段 `s[0..i-1]` 长度 >= 1，第三段 `s[j..n-1]` 长度 >= 1
- 区间 DP 的顺序：先按长度由小到大
