## 题目描述

给定一个字符串 s，返回 s 中不同的非空回文子序列个数。答案可能很大，返回对 10^9 + 7 取模的结果。

**示例：**
```
输入：s = "bccb"
输出：6
解释：6个不同的非空回文子序列分别为："b", "c", "bb", "cc", "bcb", "bccb"
```

## Python 代码实现

```python
class Solution:
    def countPalindromicSubsequences(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        
        # dp[i][j] 表示 s[i:j+1] 中不同回文子序列的个数
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n):
            dp[i][i] = 1
        
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                if s[i] == s[j]:
                    dp[i][j] = dp[i+1][j-1] * 2
                    
                    # 找到内部相同字符的位置
                    left = i + 1
                    right = j - 1
                    
                    while left <= right and s[left] != s[i]:
                        left += 1
                    while left <= right and s[right] != s[i]:
                        right -= 1
                    
                    if left > right:
                        dp[i][j] += 2
                    elif left == right:
                        dp[i][j] += 1
                    else:
                        dp[i][j] -= dp[left+1][right-1]
                else:
                    dp[i][j] = dp[i+1][j] + dp[i][j-1] - dp[i+1][j-1]
                
                dp[i][j] = (dp[i][j] + MOD) % MOD
        
        return dp[0][n-1]
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 使用区间DP
2. 分情况讨论首尾字符是否相同
3. 处理重复的子序列
