## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，返回**单调对**的数量。

单调对 `(arr1, arr2)` 满足：
- `arr1` 是非递减数组，`arr2` 是非递增数组
- `arr1[i] + arr2[i] == nums[i]`（对所有 0 <= i < n）
- `0 <= arr1[i], arr2[i]`

由于答案可能很大，返回对 `10^9 + 7` 取模的结果。

**示例 1：**
```
输入：nums = [2,3,2]
输出：4
```

**示例 2：**
```
输入：nums = [5,5,5,5]
输出：126
```

**提示：**
- `1 <= n <= 2000`
- `1 <= nums[i] <= 50`

## 解题思路

设 `arr1[i] = x`，则 `arr2[i] = nums[i] - x`，其中 `0 <= x <= nums[i]`。

条件：`arr1` 非递减（`x[i] >= x[i-1]`），`arr2` 非递增（`nums[i] - x[i] >= nums[i-1] - x[i-1]`，即 `x[i] - x[i-1] <= nums[i] - nums[i-1]`）。

综合：`x[i-1] <= x[i] <= x[i-1] + (nums[i] - nums[i-1])`（当 `nums[i] >= nums[i-1]`），若 `nums[i] < nums[i-1]` 则 `x[i] >= x[i-1] - (nums[i-1] - nums[i])` 且 `x[i] <= nums[i]`。

等价简化：只要满足 `arr1[i] - arr1[i-1] <= nums[i] - nums[i-1]`，即 `arr1` 的增量 `d[i] = arr1[i] - arr1[i-1]` 满足 `0 <= d[i] <= nums[i] - nums[i-1]`（当差为正），否则 `nums[i] - nums[i-1] <= d[i] <= 0`（当差为负）。

DP：`dp[i][x]` = 前 i 个位置，`arr1[i] = x` 的方案数。前缀和优化。

## Python 代码实现

### 方法一：DP + 前缀和（推荐）

```python
from typing import List

class Solution:
    def countOfPairs(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        max_val = max(nums)
        
        # dp[x] = arr1[i] = x 的方案数
        dp = [1] * (max_val + 1)
        # 初始：dp[x] = 1 for 0 <= x <= nums[0]，其余 0
        dp = [0] * (max_val + 1)
        for x in range(nums[0] + 1):
            dp[x] = 1
        
        for i in range(1, n):
            new_dp = [0] * (max_val + 1)
            # arr1[i] = y，arr1[i-1] = x，需要 x <= y，且 y - x <= nums[i] - nums[i-1]
            # 等价：max(0, y - (nums[i] - nums[i-1])) <= x <= y（当差>=0）
            # 或：y <= x <= y + (nums[i-1] - nums[i])（当差<0，但x<=nums[i-1]）
            
            # 实际约束：x <= y 且 (nums[i] - x) <= (nums[i-1] - ... ，即 arr2 非增)
            # arr2[i] >= arr2[i-1] => nums[i] - y >= nums[i-1] - x => x >= y + nums[i-1] - nums[i]
            # 综合：max(0, y - (nums[i] - nums[i-1])) <= x <= y
            # 前提 y <= nums[i]
            
            # 用前缀和优化
            prefix = [0] * (max_val + 2)
            for x in range(max_val + 1):
                prefix[x + 1] = (prefix[x] + dp[x]) % MOD
            
            diff = nums[i] - nums[i - 1]
            for y in range(nums[i] + 1):
                # x 的范围：max(0, y - diff) <= x <= y (如果diff >= 0)
                # 如果 diff < 0: y - diff > y，约束变为 y - diff <= x <= y，但 y-diff > y，所以无解？
                # 不对：x >= y + nums[i-1] - nums[i] = y - diff
                # diff = nums[i] - nums[i-1]，x >= y - diff
                # 若 diff < 0，则 -diff > 0，x >= y - diff > y，与 x <= y 矛盾，可能无解
                
                lo = max(0, y - diff)
                hi = min(y, nums[i - 1])  # x <= nums[i-1]
                if lo > hi:
                    continue
                new_dp[y] = (prefix[hi + 1] - prefix[lo]) % MOD
            
            dp = new_dp
        
        return sum(dp) % MOD
```

## 复杂度分析

- 时间复杂度：O(n * max_val)
- 空间复杂度：O(max_val)

## 关键点总结

1. 问题转化为：选 arr1[i] 的值，满足递增约束
2. 额外约束：arr1[i] - arr1[i-1] <= nums[i] - nums[i-1]
3. 前缀和优化内层求和，从 O(n * max_val^2) 降至 O(n * max_val)

## 易错点

1. 约束推导要仔细：arr1 非递减且 arr2 非递增
2. x 的上界是 min(y, nums[i-1])，不只是 y
