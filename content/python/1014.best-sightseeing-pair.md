## 题目描述

给你一个正整数数组 `values`，其中 `values[i]` 表示第 `i` 个观光景点的评分，并且两个景点 `i` 和 `j` 之间的距离为 `j - i`。

一对景点 `(i < j)` 组成的观光组合的得分为 `values[i] + values[j] + i - j`，也就是景点的评分之和减去它们两者之间的距离。

返回一对观光景点能取得的最高分。

**示例 1：**
```
输入：values = [8,1,5,2,6]
输出：11
解释：i = 0, j = 2, values[0] + values[2] + 0 - 2 = 8 + 5 + 0 - 2 = 11
```

**示例 2：**
```
输入：values = [1,2]
输出：2
```

**提示：**
- `2 <= values.length <= 5 * 10^4`
- `1 <= values[i] <= 1000`

## 解题思路

**核心观察**：将得分公式重组
- 原公式：`values[i] + values[j] + i - j`
- 重组：`(values[i] + i) + (values[j] - j)`

**关键发现**：
- 对于每个j，我们需要找到之前的最大的 `values[i] + i`
- 这样就可以O(1)时间计算当前的最大得分

**算法步骤**：
1. 维护变量max_i表示之前遇到的最大 `values[i] + i`
2. 对每个j，计算 `max_i + values[j] - j`
3. 更新全局最大值和max_i

## Python 代码实现

### 方法一：一次遍历（推荐）⭐

```python
from typing import List

class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        """
        动态规划优化到O(1)空间
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        max_score = 0
        max_i = values[0] + 0  # values[i] + i 的最大值
        
        for j in range(1, len(values)):
            # 计算以j为右端点的最大得分
            max_score = max(max_score, max_i + values[j] - j)
            
            # 更新max_i（values[i] + i的最大值）
            max_i = max(max_i, values[j] + j)
        
        return max_score
```

### 方法二：详细注释版

```python
class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        """
        公式分解：
        得分 = values[i] + values[j] + i - j
             = (values[i] + i) + (values[j] - j)
        
        对于每个j，维护之前的max(values[i] + i)
        """
        n = len(values)
        result = 0
        
        # 初始化：第一个景点作为左端点的贡献
        left_max = values[0] + 0
        
        # 从第二个景点开始遍历，作为右端点
        for j in range(1, n):
            # 当前景点作为右端点的贡献
            right_contribution = values[j] - j
            
            # 计算以j为右端点的最大得分
            current_score = left_max + right_contribution
            result = max(result, current_score)
            
            # 更新左端点的最大贡献
            # 当前景点也可能成为未来某对的左端点
            left_contribution = values[j] + j
            left_max = max(left_max, left_contribution)
        
        return result
```

### 方法三：动态规划思路

```python
class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        """
        DP思路：
        dp[j] = 以j为右端点的最大得分
        dp[j] = max(values[i] + i + values[j] - j) for all i < j
        
        优化：维护max(values[i] + i)即可
        """
        max_score = 0
        max_left = values[0]  # max(values[i] + i)
        
        for j in range(1, len(values)):
            # 以j为右端点的最大得分
            max_score = max(max_score, max_left + values[j] - j)
            
            # 更新max_left
            max_left = max(max_left, values[j] + j)
        
        return max_score
```

### 方法四：暴力法（超时，用于理解）

```python
class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        """
        暴力法：枚举所有配对
        时间复杂度：O(n²)
        空间复杂度：O(1)
        
        仅用于理解题意，会超时
        """
        n = len(values)
        max_score = 0
        
        for i in range(n - 1):
            for j in range(i + 1, n):
                score = values[i] + values[j] + i - j
                max_score = max(max_score, score)
        
        return max_score
```

## 关键点总结

1. **公式变换**：将得分公式拆分为两部分独立计算
2. **贪心思想**：维护左端点的最大贡献值
3. **一次遍历**：通过公式变换实现O(n)时间
4. **状态维护**：只需维护max(values[i] + i)
5. **边界处理**：从索引1开始遍历

## 易错点

1. **公式理解**：要正确理解得分公式的含义
2. **变量更新顺序**：先计算得分，再更新max_i
3. **初始值设置**：max_i初始为values[0]，不是0
4. **遍历起点**：从索引1开始，因为需要配对
5. **符号正负**：注意j的系数是负数
