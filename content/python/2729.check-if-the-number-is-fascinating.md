## 题目描述

给你一个三位数整数 `n`，如果将 `n`、`2*n`、`3*n` 拼接在一起，结果包含 1 到 9 的每个数字 **恰好一次**，则称 `n` 为 **迷人数字**。

返回如果 `n` 是迷人数字则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：n = 192
输出：true
解释：192 + 384 + 576 = "192384576"，包含 1-9 各一次
```

**示例 2：**
```
输入：n = 100
输出：false
解释：拼接结果为 "100200300"，包含 0，且 1 出现了多次
```

**提示：**
- `100 <= n <= 999`

## 解题思路

拼接三个数字的字符串，检查是否恰好包含 `'1'` 到 `'9'` 各一次（不含 `'0'`）。

## Python 代码实现

### 方法一：字符串拼接 + 集合（推荐）

```python
class Solution:
    def isFascinating(self, n: int) -> bool:
        # 拼接 n、2n、3n 的字符串
        s = str(n) + str(2 * n) + str(3 * n)
        # 检查长度为 9，且包含 '1'-'9' 各一次（无重复，无'0'）
        return len(s) == 9 and set(s) == set('123456789')
```

### 方法二：Counter 验证

```python
from collections import Counter

class Solution:
    def isFascinating(self, n: int) -> bool:
        s = str(n) + str(2 * n) + str(3 * n)
        cnt = Counter(s)
        # 长度9，每个1-9出现一次，不含0
        return (len(s) == 9 and
                '0' not in cnt and
                all(cnt[str(i)] == 1 for i in range(1, 10)))
```

## 复杂度分析

- 时间复杂度：O(1)（数字位数固定最多 9 位）
- 空间复杂度：O(1)

## 关键点总结

1. 拼接后长度必须为 9（三个三位数的拼接，但 2n/3n 可能是 4 位数时要注意）
2. 不能含 `'0'`
3. `'1'` 到 `'9'` 各出现恰好一次

## 易错点

1. 先检查长度为 9，可以快速排除 2n 或 3n 超过三位数的情况
2. 结果中不应包含 0，用集合比较即可
