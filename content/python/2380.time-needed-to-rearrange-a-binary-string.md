## 题目描述

给你一个二进制字符串 `s`，每**一秒**，所有的 `"01"` **同时**被替换为 `"10"`（即所有 `0` 向右移，或所有 `1` 向左移）。

返回使 `s` 变成所有 `1` 都在所有 `0` 之前所需的秒数。

**示例 1：**
```
输入：s = "0110101"
输出：4
```

**示例 2：**
```
输入：s = "11100"
输出：0
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 为 `'0'` 或 `'1'`

## 解题思路

**方法一：模拟**
每秒将所有 `01` 同时替换为 `10`，直到字符串有序。

**方法二：动态规划**
设 `dp[i]` 为第 `i` 个字符（0-indexed）变到正确位置所需的最大时间。

对于 `s[i] = '0'`：`dp[i] = 0`（0 不需要移动）。
对于 `s[i] = '1'`：`dp[i] = 0`（如果右边没有 0）。
对于 `s[i] = '1'` 且右边有 `0`：需要经历若干秒，但每个 `1` 最多移动 `cnt_zeros`（右边 0 的个数）步。

更直接地：答案为所有 `s[i]='1'` 中，其右边 `0` 的数量的最大值（考虑"连续 1 块"的加速效应）。

## 代码实现

### 方法一：模拟（推荐，直观）

```python
class Solution:
    def secondsToRemoveOccurrences(self, s: str) -> int:
        seconds = 0
        while '01' in s:
            # 同时替换所有 "01" 为 "10"
            new_s = list(s)
            i = 0
            while i < len(s) - 1:
                if s[i] == '0' and s[i + 1] == '1':
                    new_s[i] = '1'
                    new_s[i + 1] = '0'
                    i += 2  # 跳过，防止重复处理
                else:
                    i += 1
            s = ''.join(new_s)
            seconds += 1
        return seconds
```

### 方法二：动态规划

```python
class Solution:
    def secondsToRemoveOccurrences(self, s: str) -> int:
        n = len(s)
        # dp[i]：到第 i 个字符所需的时间
        # 若 s[i] == '0' 且 s[i-1] == '1'：此时 s[i] 会向左移
        # dp[i] = dp[i-1] + 1 if... else dp[i-1]
        
        # 另一种思路：直接数每个 1 需要跨越的 0 数量，考虑连续 1 的情况
        
        ans = 0
        zeros = 0  # 当前位置前面的 0 的个数
        
        for i in range(n):
            if s[i] == '0':
                zeros += 1
            elif zeros > 0:
                # 此 1 需要移过 zeros 个 0
                # 但连续的 1 一起移动，实际时间 = max(prev_time + 1, zeros)
                ans = max(ans + 1, zeros)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(n^2) | O(n) |
| DP | O(n) | O(1) |

## 关键点总结

1. 模拟方法直观但每轮需要 O(n)，最多 O(n) 轮，总计 O(n^2)。
2. DP 方法：每个 1 需要移过其左侧所有 0，但相邻 1 可以"接力"（不需要额外时间）。
3. `ans = max(ans + 1, zeros)`：`ans + 1` 是前一个 1 已经走了 ans 秒，再加一秒；`zeros` 是至少要走 zeros 步。

## 易错点

- 模拟时必须同时替换所有 `01`，不能逐个替换（否则结果不正确）。
- DP 中连续 1 的关键：前一个 1 用了 `ans` 秒，当前 1 跟着走，只需 `ans + 1` 秒，但也要至少 `zeros` 秒。
