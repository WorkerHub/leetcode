## 题目描述

在一个 10^6 x 10^6 的网格中，每个网格上方格的坐标为 `(x, y)`。

现在从源方格 `source = [sx, sy]` 开始出发，意图赶往目标方格 `target = [tx, ty]`。数组 `blocked` 是封锁的方格列表，其中每个 `blocked[i] = [xi, yi]` 表示坐标为 `(xi, yi)` 的方格是禁止通行的。

每次移动，都可以走到网格中在四个方向上相邻的方格，只要该方格不在给出的封锁列表 `blocked` 上。同时，不允许走出网格。

只有在可以通过一系列的移动从源方格 `source` 到达目标方格 `target` 时才返回 `true`。否则，返回 `false`。

**示例 1：**
```
输入：blocked = [[0,1],[1,0]], source = [0,0], target = [0,2]
输出：false
解释：从源方格无法到达目标方格，因为我们无法在网格中移动。无法向北或者向东移动是因为方格禁止通行。无法向南或者向西移动是因为不能走出网格。
```

**示例 2：**
```
输入：blocked = [], source = [0,0], target = [999999,999999]
输出：true
解释：因为没有方格被封锁，所以一定可以到达目标方格。
```

**提示：**
- `0 <= blocked.length <= 200`
- `blocked[i].length == 2`
- `0 <= xi, yi < 10^6`
- `source.length == target.length == 2`
- `0 <= sx, sy, tx, ty < 10^6`
- `source != target`
- 题目数据保证 `source` 和 `target` 不在封锁列表内

## 解题思路

这道题的难点在于网格非常大（10^6 x 10^6），直接 BFS/DFS 会超时。但关键洞察是：**封锁方格最多只有 200 个**。

**核心思想：**

1. **有限封锁的启发**：200 个障碍物最多能围成的区域是有限的
2. **最大包围面积**：以角落为支点，200 个障碍物能围成的最大面积约为 200 × 199 / 2 ≈ 19900
3. **突破包围圈**：如果从 source 出发访问的节点数超过这个阈值，说明没有被包围
4. **双向检查**：需要同时检查 source 和 target 是否被包围

**算法流程：**

1. 从 source 开始 BFS，如果能访问超过 19900 个节点或到达 target，则 source 未被包围
2. 从 target 开始 BFS，如果能访问超过 19900 个节点或到达 source，则 target 未被包围
3. 只有两者都未被包围时才能相互到达

**为什么是 19900？**

假设障碍物在角落形成 45° 对角线：
```
# # # ... (n 个)
#
#
...
```
这种排列能围成的最大面积是三角形：1 + 2 + ... + (n-1) = n(n-1)/2
对于 n=200，面积约为 19900。

## Python 代码实现

### 方法一：双向 BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def isEscapePossible(self, blocked: List[List[int]], source: List[int], target: List[int]) -> bool:
        """
        使用双向 BFS 判断是否可达
        
        Args:
            blocked: 封锁的方格列表
            source: 起点坐标
            target: 终点坐标
            
        Returns:
            是否可以从 source 到达 target
        """
        if not blocked:
            return True
        
        # 将 blocked 转换为集合以加快查找
        blocked_set = set(map(tuple, blocked))
        
        # 计算最大可能的包围面积
        max_area = len(blocked) * (len(blocked) - 1) // 2
        
        def bfs(start: List[int], end: List[int]) -> bool:
            """
            从 start 开始 BFS，检查是否能到达 end 或突破包围
            
            Returns:
                True 表示未被包围（可能到达 end 或访问节点超过阈值）
            """
            queue = deque([tuple(start)])
            visited = {tuple(start)}
            
            while queue and len(visited) <= max_area:
                x, y = queue.popleft()
                
                # 如果到达目标，说明可达
                if [x, y] == end:
                    return True
                
                # 四个方向移动
                for dx, dy in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                    nx, ny = x + dx, y + dy
                    
                    # 检查边界、是否访问过、是否被封锁
                    if (0 <= nx < 10**6 and 0 <= ny < 10**6 and 
                        (nx, ny) not in visited and 
                        (nx, ny) not in blocked_set):
                        visited.add((nx, ny))
                        queue.append((nx, ny))
            
            # 如果访问的节点数超过最大包围面积，说明突破了包围
            return len(visited) > max_area
        
        # 双向检查：source 和 target 都必须未被包围
        return bfs(source, target) and bfs(target, source)
```

### 方法二：DFS 实现

```python
from typing import List

class Solution:
    def isEscapePossible(self, blocked: List[List[int]], source: List[int], target: List[int]) -> bool:
        """
        使用 DFS 判断是否可达
        
        Args:
            blocked: 封锁的方格列表
            source: 起点坐标
            target: 终点坐标
            
        Returns:
            是否可以从 source 到达 target
        """
        if not blocked:
            return True
        
        blocked_set = set(map(tuple, blocked))
        max_area = len(blocked) * (len(blocked) - 1) // 2
        
        def dfs(x: int, y: int, end: List[int], visited: set) -> bool:
            """
            深度优先搜索
            
            Returns:
                True 表示到达目标或突破包围
            """
            # 到达目标
            if [x, y] == end:
                return True
            
            # 访问节点数超过阈值，突破包围
            if len(visited) > max_area:
                return True
            
            # 标记访问
            visited.add((x, y))
            
            # 四个方向探索
            for dx, dy in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                nx, ny = x + dx, y + dy
                
                if (0 <= nx < 10**6 and 0 <= ny < 10**6 and 
                    (nx, ny) not in visited and 
                    (nx, ny) not in blocked_set):
                    if dfs(nx, ny, end, visited):
                        return True
            
            return False
        
        # 双向检查
        visited1 = set()
        visited2 = set()
        
        return (dfs(source[0], source[1], target, visited1) and 
                dfs(target[0], target[1], source, visited2))
```

### 方法三：优化的 BFS（更清晰的逻辑）

```python
from typing import List
from collections import deque

class Solution:
    def isEscapePossible(self, blocked: List[List[int]], source: List[int], target: List[int]) -> bool:
        """
        优化的 BFS 实现，逻辑更清晰
        """
        if not blocked:
            return True
        
        blocked_set = set(map(tuple, blocked))
        # 使用更保守的阈值
        threshold = len(blocked) * len(blocked)
        
        def check(start: List[int], end: List[int]) -> int:
            """
            检查从 start 能否到达 end 或突破包围
            
            Returns:
                0: 被包围
                1: 突破包围但未到达终点
                2: 到达终点
            """
            queue = deque([tuple(start)])
            visited = {tuple(start)}
            
            while queue:
                # 访问节点数超过阈值，说明突破包围
                if len(visited) > threshold:
                    return 1
                
                x, y = queue.popleft()
                
                # 到达终点
                if x == end[0] and y == end[1]:
                    return 2
                
                for dx, dy in [(0, 1), (1, 0), (0, -1), (-1, 0)]:
                    nx, ny = x + dx, y + dy
                    
                    if (0 <= nx < 10**6 and 0 <= ny < 10**6 and 
                        (nx, ny) not in visited and 
                        (nx, ny) not in blocked_set):
                        visited.add((nx, ny))
                        queue.append((nx, ny))
            
            return 0  # 被包围
        
        # 从 source 检查
        result1 = check(source, target)
        if result1 == 0:
            return False  # source 被包围
        if result1 == 2:
            return True  # 直接到达 target
        
        # source 突破包围但未到达 target，需要检查 target 是否被包围
        result2 = check(target, source)
        return result2 > 0  # target 也需要未被包围
```

## 复杂度分析

- **时间复杂度**：O(n²)，其中 n 是 blocked 的长度（最多 200）。最坏情况下访问 O(n²) 个节点
- **空间复杂度**：O(n²)，visited 集合和队列的空间

## 关键点总结

1. **问题转化**：超大网格 + 有限障碍物 → 包围圈检测问题
2. **数学分析**：计算最大可能的包围面积作为阈值
3. **双向检查**：必须同时验证起点和终点都未被包围
4. **优化技巧**：使用集合加速障碍物查找
5. **边界处理**：注意网格边界 [0, 10^6)

## 易错点

1. **单向检查不够**：只检查 source 是否被包围是不够的，target 也可能被包围
2. **阈值设置**：阈值过小可能误判，过大会超时
3. **坐标范围**：注意是 [0, 10^6)，不是 [0, 10^6]
4. **集合转换**：blocked 要转换为集合（tuple），提高查找效率
5. **空 blocked**：要特别处理 blocked 为空的情况
