## 题目描述

共有 `n` 名小伙伴围坐成一圈，按顺时针方向从 `1` 到 `n` 编号。从第 `1` 号小伙伴开始数数，每数到第 `k` 个就淘汰，然后从下一个人重新开始数数，直到只剩一个人。

返回最后剩下的那个人的编号。这是经典的**约瑟夫环问题**。

**示例 1：**
```
输入：n = 5, k = 2
输出：3
```

**示例 2：**
```
输入：n = 6, k = 5
输出：1
```

**提示：**
- `1 <= k <= n <= 500`

## 解题思路

**约瑟夫环递推公式**：

设 `f(n, k)` 为 n 人游戏、每第 k 个淘汰时，最终胜者的位置（0-indexed）：
- 递推：`f(1, k) = 0`，`f(n, k) = (f(n-1, k) + k) % n`
- 最终结果转为 1-indexed：`f(n, k) + 1`

**模拟法**：用列表或队列模拟整个淘汰过程。

## 代码实现

### 方法一：约瑟夫环递推公式（推荐，O(n) 时间）

```python
class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        # 约瑟夫环递推：f(n, k) = (f(n-1, k) + k) % n
        pos = 0  # 1人时，胜者在位置 0
        for i in range(2, n + 1):
            pos = (pos + k) % i
        return pos + 1  # 转为 1-indexed
```

### 方法二：队列模拟（直观易懂）

```python
from collections import deque

class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        # 初始化队列，按顺序放入 1 到 n
        q = deque(range(1, n + 1))
        while len(q) > 1:
            # 数到第 k 个：将前 k-1 个人移到队尾
            for _ in range(k - 1):
                q.append(q.popleft())
            q.popleft()  # 淘汰第 k 个人
        return q[0]
```

## 复杂度分析

- **方法一（递推）**：
  - 时间复杂度：O(n)
  - 空间复杂度：O(1)
- **方法二（模拟）**：
  - 时间复杂度：O(n * k)，每轮移动 k-1 次
  - 空间复杂度：O(n)

## 关键点总结

1. 约瑟夫环是经典数论题，递推公式是标准解法
2. 递推从 1 人（胜者位置 0）开始，每次扩展到 i 人，位置偏移 k 并取模
3. 最终结果加 1 转为题目要求的 1-indexed

## 易错点

- 递推得到的位置是 0-indexed，返回时需要加 1
- 模拟法中每轮先将 k-1 人移到队尾，再弹出第 k 个人
