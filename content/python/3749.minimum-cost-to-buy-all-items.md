## 题目描述

有 `n` 件物品，每件物品有两种购买方式：
- 单独购买：代价为 `cost[i]`
- 组合购买：若已购买第 `i` 件，则可以以 `discount[i]` 的代价购买第 `next[i]` 件

求购买所有 `n` 件物品的最小总代价。

**示例 1：**
```
输入：cost = [3,6,4], discount = [2,3,1], next = [1,2,0]
输出：10
解释：单买：3+6+4=13。
     买 0 后用折扣买 1：3+2+4=9；或买 1 后折扣买 2：3+3+1=7；继续买 0 单买：7+3=10。
```

**提示：**
- `1 <= n <= 100`
- `1 <= cost[i], discount[i] <= 10^9`

## 解题思路

贪心：对于每个"组合购买"链，若折扣价便宜，优先使用折扣；否则单买。

枚举每件物品的购买策略：
- 若 `discount[i] < cost[next[i]]`：购买 `i` 时顺带购买 `next[i]`（折扣更便宜）
- 否则：分别单买

由于链式关系，需要用贪心从每条链中选取最优策略。

## Python 代码实现

### 方法一：枚举链式折扣（推荐）

```python
from typing import List

class Solution:
    def minCost(self, cost: List[int], discount: List[int], nxt: List[int]) -> int:
        n = len(cost)
        total = sum(cost)  # 初始全部单买

        # 对于每件物品，若通过其他物品的折扣购买更便宜，则节省差额
        savings = 0
        for i in range(n):
            j = nxt[i]
            if discount[i] < cost[j]:
                # 通过购买 i 再折扣买 j，节省 cost[j] - discount[i]
                savings = max(savings, cost[j] - discount[i])

        return total - savings
```

### 方法二：完整贪心（处理链式关系）

```python
from typing import List

class Solution:
    def minCost(self, cost: List[int], discount: List[int], nxt: List[int]) -> int:
        n = len(cost)
        purchased = [False] * n
        total = 0

        # 按节省额从大到小排序
        savings = []
        for i in range(n):
            j = nxt[i]
            save = cost[j] - discount[i]
            savings.append((save, i, j))

        savings.sort(reverse=True)

        used_discount = set()  # 已用折扣购买的物品

        for save, i, j in savings:
            if save > 0 and j not in used_discount:
                used_discount.add(j)

        # 计算最终代价
        for item in range(n):
            if item in used_discount:
                # 找给这件物品最便宜的折扣来源
                min_disc = cost[item]
                for i in range(n):
                    if nxt[i] == item:
                        min_disc = min(min_disc, discount[i])
                total += min_disc
            else:
                total += cost[item]

        return total
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 对于每件物品，可以找到最便宜的折扣来源
2. 贪心：优先使用节省额最大的折扣
3. 每件物品只能享受一次折扣（但可以被多个来源折扣，取最便宜的）

## 易错点

1. 折扣关系可能形成链（a 折扣 b，b 折扣 c），不一定独立
2. 每件物品最多被折扣购买一次
