## 题目描述

给你一个二叉树的根结点 `root`，请你设计算法计算二叉树的**垂序遍历**序列。

对位于 `(row, col)` 的每个结点而言，其左右子结点分别位于 `(row + 1, col - 1)` 和 `(row + 1, col + 1)` 。树的根结点位于 `(0, 0)` 。

二叉树的**垂序遍历**从最左边的列开始直到最右边的列结束，按列索引每一列上的所有结点，形成一个按出现位置从上到下排序的有序列表。如果同行同列上有多个结点，则按结点的值从小到大进行排序。

返回二叉树的**垂序遍历**序列。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/01/28/vtree1.jpg)

```
输入：root = [3,9,20,null,null,15,7]
输出：[[9],[3,15],[20],[7]]
解释：
列 -1：只有结点 9
列 0：只有结点 3 和 15，按从上到下顺序
列 1：只有结点 20
列 2：只有结点 7
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/28/vtree2.jpg)

```
输入：root = [1,2,3,4,5,6,7]
输出：[[4],[2],[1,5,6],[3],[7]]
解释：
列 -2：只有结点 4
列 -1：只有结点 2
列 0：结点 1、5 和 6，按从上到下顺序
列 1：只有结点 3
列 2：只有结点 7
```

**提示：**
- 树中结点数目总数在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

### 核心概念

- **列号（column）**：根节点列号为 0，左子树列号 -1，右子树列号 +1
- **行号（row）**：根节点行号为 0，子节点行号 +1

### 方法对比

| 方法 | 特点 | 是否需要排序 |
|------|------|-------------|
| BFS | 自然保证从上到下 | 不需要按行排序 |
| DFS | 需要记录行号 | 需要按行排序 |

## Python 代码实现

### 方法一：BFS（推荐）⭐

```python
from typing import Optional, List
from collections import deque, defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        # 字典存储每一列的节点值
        column_table = defaultdict(list)
        
        # BFS队列：(节点, 列号)
        queue = deque([(root, 0)])
        
        while queue:
            node, col = queue.popleft()
            
            # 记录当前列的节点值
            column_table[col].append(node.val)
            
            # 左子树：列号 -1
            if node.left:
                queue.append((node.left, col - 1))
            
            # 右子树：列号 +1
            if node.right:
                queue.append((node.right, col + 1))
        
        # 按列号排序，返回结果
        return [column_table[col] for col in sorted(column_table.keys())]
```

### 方法二：DFS + 排序

```python
from typing import Optional, List
from collections import defaultdict

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        # 字典存储：{列号: [(行号, 节点值)]}
        column_table = defaultdict(list)
        
        def dfs(node: Optional[TreeNode], row: int, col: int):
            if not node:
                return
            
            # 记录节点的行号和值
            column_table[col].append((row, node.val))
            
            # 递归左右子树
            dfs(node.left, row + 1, col - 1)
            dfs(node.right, row + 1, col + 1)
        
        dfs(root, 0, 0)
        
        # 按列号排序，每一列内部按行号排序
        result = []
        for col in sorted(column_table.keys()):
            # 按行号排序
            column_table[col].sort()
            result.append([val for row, val in column_table[col]])
        
        return result
```

### 方法三：BFS + 记录范围

```python
from typing import Optional, List
from collections import deque

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        # 使用字典存储每一列
        column_dict = {}
        min_col, max_col = 0, 0
        
        queue = deque([(root, 0)])
        
        while queue:
            node, col = queue.popleft()
            
            # 更新列范围
            min_col = min(min_col, col)
            max_col = max(max_col, col)
            
            # 记录节点
            if col not in column_dict:
                column_dict[col] = []
            column_dict[col].append(node.val)
            
            if node.left:
                queue.append((node.left, col - 1))
            if node.right:
                queue.append((node.right, col + 1))
        
        # 按列号顺序返回
        return [column_dict[col] for col in range(min_col, max_col + 1)]
```

### 方法四：带详细注释的版本

```python
from typing import Optional, List
from collections import deque, defaultdict

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        """
        二叉树垂序遍历（BFS 方法）
        
        核心思想：
        1. 使用 BFS 遍历二叉树
        2. 为每个节点分配列号
        3. 按列号分组，BFS 自动保证同列内从上到下
        
        为什么用 BFS？
        - BFS 天然按层遍历，保证从上到下的顺序
        - 不需要额外记录行号和排序
        """
        # 空树直接返回
        if not root:
            return []
        
        # 使用字典存储每一列的节点值
        # key: 列号, value: 节点值列表
        column_table = defaultdict(list)
        
        # BFS 队列
        # 每个元素是 (节点, 列号) 的元组
        queue = deque([(root, 0)])
        
        # BFS 遍历
        while queue:
            node, col = queue.popleft()
            
            # 将节点值加入对应的列
            column_table[col].append(node.val)
            
            # 左子节点：列号 -1
            if node.left:
                queue.append((node.left, col - 1))
            
            # 右子节点：列号 +1
            if node.right:
                queue.append((node.right, col + 1))
        
        # 按列号从小到大排序，返回结果
        return [column_table[col] for col in sorted(column_table.keys())]
```

## 复杂度分析

**BFS 方法：**
- 时间复杂度：O(n log n)，n 是节点数，排序列号需要 O(k log k)，k 是列数
- 空间复杂度：O(n)，队列和字典的空间

**DFS 方法：**
- 时间复杂度：O(n log n)，需要对每一列排序
- 空间复杂度：O(n)，递归栈和字典的空间

## 关键点总结

1. **列号计算**：左子树 -1，右子树 +1
2. **BFS vs DFS**：
   - BFS：自然保证从上到下
   - DFS：需要记录行号并排序
3. **使用 defaultdict**：简化代码，不需要检查键是否存在
4. **排序**：最后按列号排序
5. **空树处理**：返回空列表

## 易错点

1. **忘记排序**：列号可能是负数，要按从小到大排序
2. **BFS vs DFS**：DFS 需要额外排序，容易遗漏
3. **列号范围**：可能是负数，不能用数组索引
4. **空树**：要特殊处理
5. **同列节点顺序**：BFS 自动保证，DFS 需要按行号排序
