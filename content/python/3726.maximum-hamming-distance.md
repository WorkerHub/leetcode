## 题目描述

给定整数数组 `nums`，找出数组中任意两个元素的最大汉明距离（即两个整数的二进制表示中，对应位不同的个数）。

**示例 1：**
```
输入：nums = [4,14,2]
输出：2
解释：
4 = 0100, 14 = 1110, 2 = 0010
hammingDist(4,14) = 2, hammingDist(4,2) = 1, hammingDist(14,2) = 3
最大为 3。
```

**示例 2：**
```
输入：nums = [3,17,8]
输出：4
```

**提示：**
- `2 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^9`

## 解题思路

**暴力方法：** 枚举所有对，计算汉明距离，时间 O(n^2)。

**优化方法：** 利用位运算逐位分析。

对于第 `b` 位（0 到 29），若某些数在该位为 1，某些为 0，则在该位对总汉明距离有贡献。最大汉明距离等于所有位中，对于某一对 `(i,j)` 不同的位数之和的最大值。

实际上对于 n 较小的情况，直接 O(n^2) 暴力即可。

对于 n 较大的情况，可以贪心：找一对数，使得它们在尽可能多的位上不同。这可以通过"逐位寻找最优组合"来做，但不如直接枚举。

## Python 代码实现

### 方法一：暴力枚举（简洁，适合 n<=10^4）

```python
from typing import List

class Solution:
    def maxHammingDistance(self, nums: List[int]) -> int:
        n = len(nums)
        max_dist = 0

        for i in range(n):
            for j in range(i + 1, n):
                # 计算汉明距离：两数异或后统计 1 的个数
                xor = nums[i] ^ nums[j]
                dist = bin(xor).count('1')
                max_dist = max(max_dist, dist)

        return max_dist
```

### 方法二：位统计优化

```python
from typing import List

class Solution:
    def maxHammingDistance(self, nums: List[int]) -> int:
        n = len(nums)
        max_bits = 30
        # 对每一位统计有多少个数在该位为 1 和为 0
        # 最大汉明距离 <= 在所有位都不同时的位数
        # 实际上还是需要枚举对，但对于特定模式可以优化

        # 对小规模数据直接暴力
        max_dist = 0
        for i in range(n):
            for j in range(i + 1, n):
                xor = nums[i] ^ nums[j]
                max_dist = max(max_dist, bin(xor).count('1'))

        return max_dist
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max_val))，枚举对并计算汉明距离
- 空间复杂度：O(1)

## 关键点总结

1. 汉明距离 = 两数异或后的 popcount（置位数量）
2. Python 中 `bin(x).count('1')` 等价于 `x.bit_count()`（Python 3.10+）
3. 对于大规模数据可以考虑启发式策略或位向量优化

## 易错点

1. 注意 `bin(x).count('1')` 而非 `bin(x ^ y).count('1')`（要先异或）
2. 最大值可以是 30 位（`10^9 < 2^30`）
