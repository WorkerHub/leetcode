## 题目描述

给你一个数组 `rooms`，其中 `rooms[i] = [roomId, size]` 表示一个房间。

另给你 `queries` 数组，其中 `queries[j] = [preferred, minSize]` 表示一次查询：找到 ID 最接近 `preferred` 且大小 >= `minSize` 的房间（若有多个等距的 ID，返回较小的那个）。

返回每次查询的结果数组。

**示例：**
```
输入：rooms = [[2,2],[1,2],[3,2]], queries = [[3,1],[3,3],[5,2]]
输出：[3,-1,3]
```

## 解题思路

**离线查询 + 有序集合**：

按查询的 `minSize` 从大到小排序，按房间的 `size` 从大到小排序。

对每个查询，将所有 size >= minSize 的房间的 ID 插入有序集合（SortedList），然后在有序集合中二分查找最接近 `preferred` 的 ID。

## 代码实现

### 方法一：离线排序 + SortedList（推荐）

```python
from sortedcontainers import SortedList
from typing import List

class Solution:
    def closestRoom(self, rooms: List[List[int]], queries: List[List[int]]) -> List[int]:
        # 对查询加上原始下标，并按 minSize 降序排列
        sorted_queries = sorted(enumerate(queries), key=lambda x: -x[1][1])
        # 房间按 size 降序排列
        sorted_rooms = sorted(rooms, key=lambda x: -x[1])

        sl = SortedList()  # 存储当前可用的房间 ID（有序）
        room_ptr = 0
        n_rooms = len(sorted_rooms)
        result = [-1] * len(queries)

        for q_idx, (preferred, min_size) in sorted_queries:
            # 将所有 size >= min_size 的房间加入 SortedList
            while room_ptr < n_rooms and sorted_rooms[room_ptr][1] >= min_size:
                sl.add(sorted_rooms[room_ptr][0])
                room_ptr += 1

            if not sl:
                result[q_idx] = -1
                continue

            # 二分查找最接近 preferred 的 ID
            pos = sl.bisect_left(preferred)
            best = -1
            best_diff = float('inf')

            # 检查 pos 和 pos-1 两个候选
            for idx in [pos, pos - 1]:
                if 0 <= idx < len(sl):
                    diff = abs(sl[idx] - preferred)
                    if diff < best_diff or (diff == best_diff and sl[idx] < best):
                        best_diff = diff
                        best = sl[idx]

            result[q_idx] = best

        return result
```

### 方法二：暴力（仅用于理解，会 TLE）

```python
from typing import List

class Solution:
    def closestRoom(self, rooms: List[List[int]], queries: List[List[int]]) -> List[int]:
        result = []
        for preferred, min_size in queries:
            best = -1
            best_diff = float('inf')
            for room_id, size in rooms:
                if size >= min_size:
                    diff = abs(room_id - preferred)
                    if diff < best_diff or (diff == best_diff and room_id < best):
                        best_diff = diff
                        best = room_id
            result.append(best)
        return result
```

## 复杂度分析

- **方法一（离线 + SortedList）**：
  - 时间复杂度：O((n + q) log n)，排序和有序集合操作
  - 空间复杂度：O(n + q)
- **方法二（暴力）**：
  - 时间复杂度：O(n * q)

## 关键点总结

1. 离线处理：将查询按 minSize 降序，与按 size 降序的房间同步处理
2. 随着查询 minSize 减小，符合条件的房间只增不减，单调加入有序集合
3. 二分查找有序集合中最接近目标的值，检查左右两个候选

## 易错点

- 等距离时取 ID 较小的，比较时需要同时比较差值和 ID 大小
- pos 可能越界，需要检查 0 <= idx < len(sl)
