## 题目描述

给你一个二进制字符串 `s` 和一个整数 `k`。

如果所有长度为 `k` 的二进制字符串都是 `s` 的子串，请返回 `True`，否则请返回 `False`。

**示例 1：**
```
输入：s = "00110110", k = 2
输出：true
解释：长度为 2 的二进制串共有 4 种："00", "01", "10", "11"，它们全部是 s 的子串。
```

**示例 2：**
```
输入：s = "0110", k = 1
输出：true
解释：长度为 1 的二进制串共有 2 种："0", "1"，它们全部是 s 的子串。
```

**示例 3：**
```
输入：s = "0110", k = 2
输出：false
解释：长度为 2 的二进制串共有 4 种，而 s 只有 "01"、"11"、"10"，缺少 "00"。
```

**提示：**
- `1 <= s.length <= 5 * 10^5`
- `s[i]` 不是 `'0'` 就是 `'1'`
- `1 <= k <= 20`

## 解题思路

长度为 k 的二进制字符串共有 `2^k` 种，我们需要检查 s 中是否包含全部这些子串。

**方法一：滑动窗口 + 哈希集合**

用滑动窗口遍历 s 中所有长度为 k 的子串，存入集合中。最后检查集合大小是否等于 `2^k`。

**方法二：位运算优化（滚动哈希）**

将每个二进制子串转为整数（利用位运算滚动更新），减少重复计算：
- 新窗口 = `((旧窗口 << 1) | 新字符) & ((1 << k) - 1)`

将所有整数存入布尔数组，最后检查是否全部出现。

## Python 代码实现

### 方法一：滑动窗口 + 集合（推荐，直观）

```python
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        n = len(s)
        need = 1 << k  # 需要 2^k 种子串

        # 字符串长度不够包含所有子串，直接返回 False
        if n - k + 1 < need:
            return False

        seen = set()
        for i in range(n - k + 1):
            # 截取长度为 k 的子串并加入集合
            sub = s[i:i + k]
            seen.add(sub)
            # 提前终止：已经找到所有子串
            if len(seen) == need:
                return True

        return len(seen) == need
```

### 方法二：位运算滚动哈希（优化版）

```python
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        n = len(s)
        need = 1 << k  # 2^k

        if n - k + 1 < need:
            return False

        # 用布尔数组代替集合，节省空间
        got = [False] * need
        # 掩码：保留低 k 位
        mask = need - 1
        # 计算第一个窗口的值
        cur = int(s[:k], 2)
        got[cur] = True
        count = 1  # 已找到的不同子串数

        for i in range(k, n):
            # 滚动更新：移出最高位，加入新字符
            cur = ((cur << 1) | int(s[i])) & mask

            if not got[cur]:
                got[cur] = True
                count += 1
                if count == need:
                    return True

        return count == need
```

### 方法三：Python 一行写法（简洁）

```python
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        # 直接用集合推导式，Pythonic 写法
        return len({s[i:i+k] for i in range(len(s) - k + 1)}) == (1 << k)
```

## 复杂度分析

**方法一（集合）：**
- 时间复杂度：O(n × k)，每次截取子串 O(k)，共 O(n) 次
- 空间复杂度：O(2^k × k)，集合中存储字符串

**方法二（位运算）：**
- 时间复杂度：O(n)，每次滚动更新 O(1)
- 空间复杂度：O(2^k)，布尔数组

## 关键点总结

1. 长度为 k 的二进制串共 `2^k` 种，这是目标数量
2. 字符串长度不足 `2^k + k - 1` 时，直接返回 False（不够放所有子串）
3. 位运算滚动哈希：`cur = ((cur << 1) | new_bit) & mask`，每次 O(1) 更新
4. 布尔数组代替集合可以减少哈希开销

## 易错点

- 注意 k 最大为 20，`2^20 = 1,048,576`，布尔数组的大小是可接受的
- 集合中存字符串时，Python 字符串比较是 O(k)，总体 O(n×k)；位运算版本降到 O(n)
- 提前终止优化很重要：找到所有子串后立即返回
