## 题目描述

给定一个同义词列表 synonyms，其中 synonyms[i] = [si, ti] 表示 si 和 ti 是同义词。

同时给定一个句子 text。

返回所有可能的同义句子，按字典序排序。

**示例 1:**

```
输入:
synonyms = [["happy","joy"],["sad","sorrow"],["joy","cheerful"]]
text = "I am happy today but was sad yesterday"
输出:
[
  "I am cheerful today but was sad yesterday",
  "I am cheerful today but was sorrow yesterday",
  "I am happy today but was sad yesterday",
  "I am happy today but was sorrow yesterday",
  "I am joy today but was sad yesterday",
  "I am joy today but was sorrow yesterday"
]
```

**示例 2:**

```
输入:
synonyms = [["happy","joy"],["cheerful","glad"]]
text = "I am happy today but was sad yesterday"
输出:
[
  "I am happy today but was sad yesterday",
  "I am joy today but was sad yesterday"
]
```

**提示:**

- 0 <= synonyms.length <= 10
- synonyms[i].length == 2
- synonyms[i][0] != synonyms[i][1]
- 所有单词只包含最多 10 个英文字母
- text 是一个由最多 10 个单词组成的句子，单词之间用单个空格分隔

## 解题思路

这道题的核心是利用并查集（Union-Find）或深度优先搜索（DFS）来找出所有同义词组，然后通过回溯生成所有可能的句子。

**核心思想：**

1. 同义词具有传递性：如果 A 和 B 是同义词，B 和 C 是同义词，那么 A 和 C 也是同义词
2. 使用并查集将所有互为同义词的单词归为一组
3. 对句子中的每个单词，如果它有同义词，就生成所有可能的替换
4. 使用回溯法生成所有可能的句子组合

**算法流程：**

1. 使用并查集将同义词分组
2. 为每个单词收集其所有同义词（同一组内的所有单词）
3. 分割句子为单词列表
4. 使用回溯法生成所有可能的组合
5. 对结果排序并返回

## Python 代码实现

### 方法一：并查集 + 回溯（推荐）

```python
from typing import List

class Solution:
    def generateSentences(self, synonyms: List[List[str]], text: str) -> List[str]:
        # 并查集的父节点映射
        parent = {}
        
        # 查找根节点（带路径压缩）
        def find(x: str) -> str:
            if x not in parent:
                parent[x] = x
            if parent[x] != x:
                parent[x] = find(parent[x])  # 路径压缩
            return parent[x]
        
        # 合并两个集合
        def union(x: str, y: str) -> None:
            root_x = find(x)
            root_y = find(y)
            if root_x != root_y:
                parent[root_x] = root_y
        
        # 构建并查集
        for word1, word2 in synonyms:
            union(word1, word2)
        
        # 为每个单词收集其所有同义词
        synonym_groups = {}
        all_words = set()
        for word1, word2 in synonyms:
            all_words.add(word1)
            all_words.add(word2)
        
        # 将同一组的单词归类
        from collections import defaultdict
        groups = defaultdict(set)
        for word in all_words:
            root = find(word)
            groups[root].add(word)
        
        # 为每个单词构建同义词列表（排序以保证字典序）
        synonym_map = {}
        for group_words in groups.values():
            sorted_words = sorted(group_words)
            for word in sorted_words:
                synonym_map[word] = sorted_words
        
        # 分割句子
        words = text.split()
        results = []
        
        # 回溯生成所有可能的句子
        def backtrack(index: int, current: List[str]) -> None:
            if index == len(words):
                results.append(' '.join(current))
                return
            
            word = words[index]
            # 如果单词有同义词，尝试所有同义词
            if word in synonym_map:
                for synonym in synonym_map[word]:
                    current.append(synonym)
                    backtrack(index + 1, current)
                    current.pop()
            else:
                # 没有同义词，直接使用原词
                current.append(word)
                backtrack(index + 1, current)
                current.pop()
        
        backtrack(0, [])
        return sorted(results)  # 按字典序排序
```

### 方法二：DFS 构建同义词组 + 回溯

```python
from typing import List
from collections import defaultdict

class Solution:
    def generateSentences(self, synonyms: List[List[str]], text: str) -> List[str]:
        # 构建同义词图
        graph = defaultdict(set)
        for word1, word2 in synonyms:
            graph[word1].add(word2)
            graph[word2].add(word1)
        
        # 使用 DFS 找出每个连通分量（同义词组）
        visited = set()
        synonym_map = {}
        
        def dfs(word: str, group: set) -> None:
            if word in visited:
                return
            visited.add(word)
            group.add(word)
            for neighbor in graph[word]:
                dfs(neighbor, group)
        
        # 找出所有同义词组
        for word in graph:
            if word not in visited:
                group = set()
                dfs(word, group)
                sorted_group = sorted(group)
                for w in group:
                    synonym_map[w] = sorted_group
        
        # 分割句子
        words = text.split()
        results = []
        
        # 回溯生成所有可能的句子
        def backtrack(index: int, current: List[str]) -> None:
            if index == len(words):
                results.append(' '.join(current))
                return
            
            word = words[index]
            if word in synonym_map:
                for synonym in synonym_map[word]:
                    backtrack(index + 1, current + [synonym])
            else:
                backtrack(index + 1, current + [word])
        
        backtrack(0, [])
        return sorted(results)
```

### 方法三：简化版（直接回溯）

```python
from typing import List
from collections import defaultdict

class Solution:
    def generateSentences(self, synonyms: List[List[str]], text: str) -> List[str]:
        # 构建邻接表
        graph = defaultdict(set)
        for a, b in synonyms:
            graph[a].add(b)
            graph[b].add(a)
        
        # 获取某个单词的所有同义词（包括自己）
        def get_synonyms(word: str) -> List[str]:
            if word not in graph:
                return [word]
            
            visited = set()
            stack = [word]
            synonyms_set = set()
            
            while stack:
                current = stack.pop()
                if current in visited:
                    continue
                visited.add(current)
                synonyms_set.add(current)
                for neighbor in graph[current]:
                    if neighbor not in visited:
                        stack.append(neighbor)
            
            return sorted(synonyms_set)
        
        words = text.split()
        # 为每个位置生成可能的单词列表
        all_options = []
        for word in words:
            all_options.append(get_synonyms(word))
        
        # 生成所有组合
        results = []
        
        def backtrack(index: int, current: List[str]) -> None:
            if index == len(words):
                results.append(' '.join(current))
                return
            
            for word in all_options[index]:
                backtrack(index + 1, current + [word])
        
        backtrack(0, [])
        return sorted(results)
```

## 复杂度分析

**方法一：并查集 + 回溯**

- 时间复杂度：O(N * α(N) + M * K^W)
  - N 是同义词对的数量，α(N) 是反阿克曼函数（并查集操作）
  - M 是句子中的单词数
  - K 是平均每个单词的同义词数量
  - W 是句子长度
  - K^W 是生成的句子数量
- 空间复杂度：O(N + K^W)，存储并查集和结果

**方法二：DFS + 回溯**

- 时间复杂度：O(N + M * K^W)
  - DFS 建图需要 O(N)
- 空间复杂度：O(N + K^W)

**方法三：简化版**

- 时间复杂度：O(M * N + M * K^W)
  - 每个单词都需要遍历图找同义词
- 空间复杂度：O(N + K^W)

## 关键点总结

1. 同义词具有传递性，需要用并查集或 DFS 找出所有连通的同义词组
2. 使用回溯法生成所有可能的句子组合
3. 注意结果需要按字典序排序
4. 每个同义词组内的单词也要排序，以保证生成的句子按字典序
5. 没有同义词的单词直接保留原词

## 易错点

1. 忘记同义词的传递性
   - 错误：只考虑直接的同义词对
   - 正确：使用并查集或 DFS 找出所有间接的同义词关系
2. 忘记对结果排序
   - 题目要求按字典序返回，必须排序
3. 同义词组内没有排序
   - 会导致最终结果的顺序不正确
4. 忘记单词本身也是它的一个"同义词"选项
5. 空间优化时重复计算同义词组
   - 应该提前计算好每个单词的同义词列表
