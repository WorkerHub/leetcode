## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

**示例 1:**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2:**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3:**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4:**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

**提示:**

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]`

## 解题思路

本题是经典的**栈应用**问题，也可以用递归解决。

### 核心思想

**使用栈处理嵌套结构：**

1. 遇到数字：累积数字（可能是多位数）
2. 遇到 `[`：将当前的数字和字符串压栈，重置状态
3. 遇到 `]`：弹栈，将当前字符串重复 k 次，拼接到栈顶字符串
4. 遇到字母：累积到当前字符串

**栈中存储的内容：**
- 数字：表示重复次数
- 字符串：表示当前层级的字符串

### 思路对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 栈 | 直观，易理解 | 需要两个栈 |
| 递归 | 代码简洁 | 理解稍难 |

## Python 代码实现

### 方法一：双栈（推荐）⭐

```python
class Solution:
    def decodeString(self, s: str) -> str:
        """
        使用两个栈：一个存数字，一个存字符串
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        stack_num = []  # 存储重复次数
        stack_str = []  # 存储字符串
        num = 0  # 当前数字
        result = ""  # 当前字符串
        
        for char in s:
            if char.isdigit():
                # 累积数字（可能是多位数）
                num = num * 10 + int(char)
            elif char == '[':
                # 将当前状态压栈
                stack_num.append(num)
                stack_str.append(result)
                # 重置状态
                num = 0
                result = ""
            elif char == ']':
                # 弹出栈顶
                repeat_times = stack_num.pop()
                prev_str = stack_str.pop()
                # 重复当前字符串并拼接
                result = prev_str + result * repeat_times
            else:
                # 累积字母
                result += char
        
        return result
```

### 方法二：单栈（优化）

```python
class Solution:
    def decodeString(self, s: str) -> str:
        """
        使用单个栈存储 (重复次数, 当前字符串) 元组
        """
        stack = []
        num = 0
        result = ""
        
        for char in s:
            if char.isdigit():
                num = num * 10 + int(char)
            elif char == '[':
                # 压栈
                stack.append((num, result))
                num = 0
                result = ""
            elif char == ']':
                # 弹栈并处理
                repeat_times, prev_str = stack.pop()
                result = prev_str + result * repeat_times
            else:
                result += char
        
        return result
```

### 方法三：递归

```python
class Solution:
    def decodeString(self, s: str) -> str:
        """
        递归解码
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        self.index = 0
        return self.decode(s)
    
    def decode(self, s: str) -> str:
        result = ""
        num = 0
        
        while self.index < len(s):
            char = s[self.index]
            
            if char.isdigit():
                num = num * 10 + int(char)
                self.index += 1
            elif char == '[':
                self.index += 1  # 跳过 '['
                # 递归解码括号内的内容
                sub_str = self.decode(s)
                result += sub_str * num
                num = 0
            elif char == ']':
                self.index += 1  # 跳过 ']'
                return result
            else:
                result += char
                self.index += 1
        
        return result
```

### 方法四：正则表达式（创意解法）

```python
import re

class Solution:
    def decodeString(self, s: str) -> str:
        """
        使用正则表达式递归替换
        不推荐，仅供学习
        """
        # 匹配 数字[字母]
        pattern = r'(\d+)\[([a-z]+)\]'
        
        while '[' in s:
            s = re.sub(pattern, lambda m: int(m.group(1)) * m.group(2), s)
        
        return s
```

### 方法五：迭代器实现

```python
class Solution:
    def decodeString(self, s: str) -> str:
        """
        使用迭代器
        """
        def helper(it):
            result = ""
            num = 0
            
            for char in it:
                if char.isdigit():
                    num = num * 10 + int(char)
                elif char == '[':
                    result += helper(it) * num
                    num = 0
                elif char == ']':
                    return result
                else:
                    result += char
            
            return result
        
        return helper(iter(s))
```

## 复杂度分析

**时间复杂度：** O(n * k)
- n 是字符串长度
- k 是最大重复次数
- 最坏情况下每个字符可能被重复 k 次

**空间复杂度：** O(n)
- 栈的深度取决于嵌套层数
- 最坏情况下所有字符都在栈中

## 关键点总结

1. **栈的应用**：处理嵌套结构的标准方法
2. **多位数处理**：数字可能是多位的，需要累积
3. **状态管理**：需要保存当前的数字和字符串
4. **字符串拼接**：Python 字符串不可变，大量拼接会影响性能
5. **递归思维**：嵌套结构天然适合递归

## 易错点

1. **多位数字**：`10[a]` 不是 `1` 和 `0[a]`
2. **嵌套处理**：`3[a2[c]]` 需要正确处理内层
3. **字母在数字前**：`abc3[cd]` 中 `abc` 不重复
4. **栈的内容**：要保存之前的字符串，不是只保存括号内的
5. **返回时机**：遇到 `]` 时返回当前结果

```
处理过程:

字符 '3': num=3
字符 '[': 压栈 (3, ""), num=0, result=""
字符 'a': result="a"
字符 '2': num=2
字符 '[': 压栈 (2, "a"), num=0, result=""
字符 'c': result="c"
字符 ']': 弹栈 (2, "a"), result="a" + "c"*2 = "acc"
字符 ']': 弹栈 (3, ""), result="" + "acc"*3 = "accaccacc"

栈的变化:
[] → [(3,"")] → [(3,""), (2,"a")] → [(3,"")] → []

结果: "accaccacc"
```
