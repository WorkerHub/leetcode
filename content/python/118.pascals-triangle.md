## 题目描述

给定一个非负整数 `numRows`，生成杨辉三角的前 `numRows` 行。

在杨辉三角中，每个数是它左上方和右上方的数的和。

**示例 1：**

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2：**

```
输入：numRows = 1
输出：[[1]]
```

**提示：**

- `1 <= numRows <= 30`

## 解题思路

杨辉三角（Pascal's Triangle）是一个经典的数学结构，具有以下规律：

1. 每行的第一个和最后一个数字都是 1
2. 其他位置的数字等于上一行对应位置和前一个位置的数字之和
3. 第 n 行有 n 个数字（从 1 开始计数）

**核心思想：**

- 使用动态规划思想，当前行依赖上一行的结果
- 每次生成新行时，除了首尾的 1，中间的数字由上一行相邻两数相加得到

**数学公式：**

```
triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]
```

其中 `1 <= j < i`

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        # 初始化结果数组
        triangle = []
        
        for i in range(numRows):
            # 创建当前行，初始化为全 1
            row = [1] * (i + 1)
            
            # 计算中间的值（除了首尾）
            for j in range(1, i):
                row[j] = triangle[i-1][j-1] + triangle[i-1][j]
            
            # 将当前行添加到结果中
            triangle.append(row)
        
        return triangle
```

### 方法二：基于上一行构建

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        if numRows == 0:
            return []
        
        triangle = [[1]]  # 第一行
        
        for i in range(1, numRows):
            # 获取上一行
            prev_row = triangle[-1]
            
            # 构建当前行
            row = [1]  # 行首为 1
            
            # 中间的值
            for j in range(len(prev_row) - 1):
                row.append(prev_row[j] + prev_row[j + 1])
            
            row.append(1)  # 行尾为 1
            triangle.append(row)
        
        return triangle
```

### 方法三：数学公式（组合数）

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = []
        
        for i in range(numRows):
            row = []
            for j in range(i + 1):
                # 使用组合数公式 C(i, j)
                if j == 0 or j == i:
                    row.append(1)
                else:
                    # C(i, j) = C(i, j-1) * (i - j + 1) / j
                    row.append(row[j-1] * (i - j + 1) // j)
            triangle.append(row)
        
        return triangle
```

### 方法四：简洁的 Python 实现

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = [[1]]
        
        for _ in range(1, numRows):
            # 在上一行前后各加一个 0，然后错位相加
            prev = [0] + triangle[-1] + [0]
            row = [prev[i] + prev[i+1] for i in range(len(prev) - 1)]
            triangle.append(row)
        
        return triangle
```

### 方法五：递归（不推荐，仅用于理解）

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        if numRows == 1:
            return [[1]]
        
        # 递归获取前 n-1 行
        triangle = self.generate(numRows - 1)
        
        # 构建第 n 行
        prev_row = triangle[-1]
        row = [1]
        for i in range(len(prev_row) - 1):
            row.append(prev_row[i] + prev_row[i + 1])
        row.append(1)
        
        triangle.append(row)
        return triangle
```

## 复杂度分析

**方法一、二、四：动态规划**
- 时间复杂度：O(numRows²)，需要生成 1 + 2 + ... + numRows = numRows × (numRows + 1) / 2 个数字
- 空间复杂度：O(1)，不计算返回值的空间

**方法三：数学公式**
- 时间复杂度：O(numRows²)
- 空间复杂度：O(1)

**方法五：递归**
- 时间复杂度：O(numRows²)
- 空间复杂度：O(numRows)，递归调用栈

## 关键点总结

1. **边界条件**：每行的首尾都是 1
2. **递推关系**：`triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]`
3. **索引处理**：第 i 行有 i+1 个元素（从 0 开始计数）
4. **Python 技巧**：利用列表推导式和切片操作简化代码
5. **组合数性质**：杨辉三角的每个数字等于组合数 C(n, k)

## 易错点

1. **索引越界**：计算中间值时要注意索引范围 `1 <= j < i`
2. **行数混淆**：第 i 行有 i+1 个元素，不要搞混
3. **初始化错误**：忘记初始化首尾为 1
4. **空输入**：虽然题目保证 `numRows >= 1`，但要有防御性编程意识
5. **整数除法**：使用组合数时要用整数除法 `//`

## 杨辉三角的性质

1. **对称性**：每一行都是对称的
2. **组合数**：第 n 行第 k 个数是组合数 C(n, k)
3. **斐波那契数列**：斜线上的数字之和是斐波那契数列
4. **二项式系数**：(a + b)^n 展开式的系数
5. **奇偶性**：可以用来研究数论问题
