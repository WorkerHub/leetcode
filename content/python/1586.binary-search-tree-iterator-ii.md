## 题目描述

实现二叉搜索树迭代器类 `BSTIterator`，该类具有以下功能：
- `BSTIterator(root)`：初始化
- `hasNext()`：若存在下一个（升序）节点返回 True
- `next()`：返回下一个节点的值（移动到下一节点）
- `hasPrev()`：若存在上一个（升序）节点返回 True
- `prev()`：返回上一个节点的值（移动到上一节点）

## 解题思路

### 方法一：中序遍历 + 双指针

先做完整的中序遍历得到有序数组，然后用指针在数组上前后移动。

**缺点：** 需要 O(N) 预处理和空间，但实现简单。

### 方法二：栈模拟 + 历史列表

用栈实现中序遍历的迭代器（懒加载），同时维护已访问的节点历史，用指针支持 `prev`。

## 代码实现

### 方法一：中序遍历 + 数组（推荐，简单）

```python
class BSTIterator:
    def __init__(self, root: 'Optional[TreeNode]'):
        # 中序遍历得到有序数组
        self.nodes = []
        self._inorder(root)
        self.idx = -1  # 当前指针（-1 表示还未开始）

    def _inorder(self, node):
        if not node:
            return
        self._inorder(node.left)
        self.nodes.append(node.val)
        self._inorder(node.right)

    def hasNext(self) -> bool:
        return self.idx + 1 < len(self.nodes)

    def next(self) -> int:
        self.idx += 1
        return self.nodes[self.idx]

    def hasPrev(self) -> bool:
        return self.idx - 1 >= 0

    def prev(self) -> int:
        self.idx -= 1
        return self.nodes[self.idx]
```

### 方法二：栈 + 历史列表（空间优化版）

```python
class BSTIterator:
    def __init__(self, root: 'Optional[TreeNode]'):
        self.stack = []
        self.visited = []  # 已访问节点的历史
        self.idx = -1
        self._push_left(root)

    def _push_left(self, node):
        while node:
            self.stack.append(node)
            node = node.left

    def hasNext(self) -> bool:
        return self.idx + 1 < len(self.visited) or len(self.stack) > 0

    def next(self) -> int:
        self.idx += 1
        if self.idx < len(self.visited):
            return self.visited[self.idx]
        # 从栈中取出下一个节点
        node = self.stack.pop()
        self.visited.append(node.val)
        self._push_left(node.right)
        return node.val

    def hasPrev(self) -> bool:
        return self.idx - 1 >= 0

    def prev(self) -> int:
        self.idx -= 1
        return self.visited[self.idx]
```

## 复杂度分析

| 方法 | next/prev 时间 | 空间 |
|------|---------------|------|
| 方法一 | O(1) | O(N) |
| 方法二 | next 均摊 O(1) | O(H + N)（H为树高，N已访问） |

## 关键点总结

1. 方法一预计算最简单，空间 O(N)
2. 方法二懒加载，`next` 均摊 O(1)，`prev` O(1)
3. 用 `idx` 指针在历史数组中前后移动实现双向迭代

## 易错点

- `prev` 移动指针到 `idx-1`，返回的是 `nodes[idx-1]`（移动后的位置）
- `next` 和 `prev` 都是"先移动指针，再返回当前值"
