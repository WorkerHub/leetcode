## 题目描述

给你一个 `n` 个节点的**有向图**（每个节点最多有一条出边），节点从 `0` 到 `n-1` 编号。

给你一个长度为 `n` 的整数数组 `edges`，其中 `edges[i]` 表示节点 `i` 有一条到 `edges[i]` 的有向边。如果没有出边，则 `edges[i] == -1`。

给你两个节点 `node1` 和 `node2`，返回节点 `x` 的**最小**下标（满足从 `node1` 和 `node2` 出发都能到达 `x`），且使 `max(dist1[x], dist2[x])` 最小。若有多个答案，返回最小下标。若不存在则返回 `-1`。

**提示：**
- `n == edges.length`
- `2 <= n <= 10^5`
- `-1 <= edges[i] < n`
- `node1 != node2`

## 解题思路

1. 分别从 `node1` 和 `node2` 出发，用 BFS/DFS 求各节点的距离数组 `dist1` 和 `dist2`。
2. 遍历所有节点，找使 `max(dist1[x], dist2[x])` 最小的节点下标。

注意：图中每个节点最多一条出边，路径是一条链（可能有环），可以直接线性遍历。

## 代码实现

### 方法一：线性遍历求距离（推荐）

```python
from typing import List

class Solution:
    def closestMeetingNode(self, edges: List[int], node1: int, node2: int) -> int:
        n = len(edges)
        INF = float('inf')

        def get_dist(start: int) -> List[int]:
            dist = [INF] * n
            d = 0
            cur = start
            while cur != -1 and dist[cur] == INF:
                dist[cur] = d
                d += 1
                cur = edges[cur]
            return dist

        dist1 = get_dist(node1)
        dist2 = get_dist(node2)

        ans = -1
        min_max = INF
        for x in range(n):
            if dist1[x] != INF and dist2[x] != INF:
                cur_max = max(dist1[x], dist2[x])
                if cur_max < min_max or (cur_max == min_max and x < ans):
                    min_max = cur_max
                    ans = x

        return ans
```

### 方法二：BFS 版本

```python
from typing import List
from collections import deque

class Solution:
    def closestMeetingNode(self, edges: List[int], node1: int, node2: int) -> int:
        n = len(edges)
        INF = float('inf')

        def bfs(start):
            dist = [INF] * n
            dist[start] = 0
            q = deque([start])
            while q:
                cur = q.popleft()
                nxt = edges[cur]
                if nxt != -1 and dist[nxt] == INF:
                    dist[nxt] = dist[cur] + 1
                    q.append(nxt)
            return dist

        dist1 = bfs(node1)
        dist2 = bfs(node2)

        ans = -1
        best = INF
        for x in range(n):
            m = max(dist1[x], dist2[x])
            if m < best:
                best = m
                ans = x

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 线性遍历 | O(n) | O(n) |
| BFS | O(n) | O(n) |

## 关键点总结

1. 每个节点最多一条出边，路径是一条简单链（加上可能的环），线性遍历即可。
2. 分别从两个起点出发求距离，再枚举所有节点找最优。
3. 多个答案取下标最小的（枚举顺序从小到大，严格小于时更新）。

## 易错点

- 环的处理：到达已访问节点时停止（`dist[cur] == INF` 才继续）。
- "最小下标"：遍历顺序已从 0 到 n-1，用严格小于 `<` 更新 ans。
