## 题目描述

给你一个整数数组 `nums`，请你创建一个满足以下条件的二维数组：
- 二维数组应该只包含 `nums` 中的元素。
- 每行中的元素是互不相同的。
- 二维数组的行数应尽可能少。

返回满足上述要求的二维数组。如果存在多种答案，任意一种都可以接受。

**示例 1：**
```
输入：nums = [1,3,4,1,2,3,1]
输出：[[1,3,4,2],[1,3],[1]]
解释：每行元素互不相同，且行数最少
```

**示例 2：**
```
输入：nums = [1,2,3,4]
输出：[[4,3,2,1]]
解释：所有元素不重复，放一行即可
```

**数据范围：**
- 1 <= nums.length <= 200
- 1 <= nums[i] <= nums.length

## 解题思路

贪心：遍历 `nums`，对每个数字，将它放到第一个还没有该数字的行中。若所有行都有该数字，则新开一行。

使用计数数组记录每个数字已经放入的行数，那么第 `cnt[x]` 行就是该数字应该放的行（从 0 开始计数）。

## Python 代码实现

### 方法一：计数贪心（推荐）

```python
from typing import List

class Solution:
    def findMatrix(self, nums: List[int]) -> List[List[int]]:
        result = []
        # cnt[x] 表示数字 x 已经出现的次数（即应该放到第几行）
        cnt = {}

        for x in nums:
            row = cnt.get(x, 0)  # x 应该放到第 row 行
            if row == len(result):
                result.append([])  # 新开一行
            result[row].append(x)
            cnt[x] = row + 1  # 更新计数

        return result
```

### 方法二：集合判断

```python
from typing import List

class Solution:
    def findMatrix(self, nums: List[int]) -> List[List[int]]:
        result = []
        row_sets = []  # 每行的元素集合，用于快速判断是否存在

        for x in nums:
            placed = False
            for i, s in enumerate(row_sets):
                if x not in s:
                    result[i].append(x)
                    s.add(x)
                    placed = True
                    break
            if not placed:
                result.append([x])
                row_sets.append({x})

        return result
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(n)
- 方法二：时间复杂度 O(n * 行数)，行数最多为最大频率，空间复杂度 O(n)

## 关键点总结

1. 答案的行数等于 `nums` 中最大元素频率
2. 每个数字第 k 次出现就放到第 k 行（0-indexed）
3. 计数数组可以直接定位该放哪行

## 易错点

1. 不能任意分配，需要保证行数最少
2. 方法一中 `cnt[x]` 记录的是"下一次应放的行号"
