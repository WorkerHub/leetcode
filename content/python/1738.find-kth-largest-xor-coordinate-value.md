## 题目描述

给你一个二维矩阵 `matrix` 和一个整数 `k`，矩阵大小为 `m x n`，由非负整数组成。

矩阵中坐标 `(a, b)` 的**值**可由对所有满足 `0 <= i <= a < m` 且 `0 <= j <= b < n` 的元素执行异或运算得到：
```
value(a, b) = XOR of matrix[i][j] for all (i, j) with i <= a and j <= b
```

请你找出 `matrix` 中的第 `k` 个**最大值**（`k` 的值从 `1` 开始）。

**示例 1：**
```
输入：matrix = [[5,2],[1,6]], k = 1
输出：7
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 1000`
- `0 <= matrix[i][j] <= 10^6`
- `1 <= k <= m * n`

## 解题思路

先用二维前缀异或预处理：
```
prefix[i][j] = matrix[0..i][0..j] 的所有元素异或
             = prefix[i-1][j] ^ prefix[i][j-1] ^ prefix[i-1][j-1] ^ matrix[i][j]
```

然后求所有 `prefix[i][j]` 中第 `k` 大的值，可以用排序或快速选择。

## 代码实现

### 方法一：二维前缀异或 + 排序（推荐）

```python
from typing import List

class Solution:
    def kthLargestValue(self, matrix: List[List[int]], k: int) -> int:
        m, n = len(matrix), len(matrix[0])
        
        # 构建二维前缀异或
        # 在原矩阵上操作，节省空间
        prefix = [[0] * (n + 1) for _ in range(m + 1)]
        
        all_values = []
        
        for i in range(m):
            for j in range(n):
                # 前缀异或公式
                prefix[i + 1][j + 1] = (prefix[i][j + 1] ^
                                         prefix[i + 1][j] ^
                                         prefix[i][j] ^
                                         matrix[i][j])
                all_values.append(prefix[i + 1][j + 1])
        
        # 找第 k 大
        all_values.sort(reverse=True)
        return all_values[k - 1]
```

### 方法二：最小堆（维护大小为 k 的堆）

```python
from typing import List
import heapq

class Solution:
    def kthLargestValue(self, matrix: List[List[int]], k: int) -> int:
        m, n = len(matrix), len(matrix[0])
        
        # 构建前缀异或（原地）
        for i in range(m):
            for j in range(n):
                xor_val = matrix[i][j]
                if i > 0:
                    xor_val ^= matrix[i - 1][j]
                if j > 0:
                    xor_val ^= matrix[i][j - 1]
                if i > 0 and j > 0:
                    xor_val ^= matrix[i - 1][j - 1]
                matrix[i][j] = xor_val
        
        # 用最小堆维护前 k 大
        heap = []
        for i in range(m):
            for j in range(n):
                heapq.heappush(heap, matrix[i][j])
                if len(heap) > k:
                    heapq.heappop(heap)
        
        return heap[0]
```

## 复杂度分析

- **方法一**：时间 O(mn log(mn))，空间 O(mn)
- **方法二**：时间 O(mn log k)，空间 O(k)

## 关键点总结

1. 二维前缀异或公式：`prefix[i][j] = prefix[i-1][j] ^ prefix[i][j-1] ^ prefix[i-1][j-1] ^ matrix[i][j]`
2. 计算出所有前缀异或值后，求第 k 大

## 易错点

- 二维前缀异或公式中，需要用异或三个邻居，与前缀和公式类比但用异或替代加法
