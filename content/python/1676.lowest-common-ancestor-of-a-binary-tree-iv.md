## 题目描述

给你一棵二叉树的根节点 `root` 和一个节点数组 `nodes`，返回这些节点的**最近公共祖先（LCA）**。

节点数组 `nodes` 中的所有值在树中都是**唯一**的，且都在树中存在。

## 解题思路

将 `nodes` 存入一个集合，然后用 DFS 找所有节点的 LCA：

**DFS 递归：**
- 若当前节点在 `nodes` 集合中，直接返回当前节点（不必再深入，因为后代肯定在它下面）
- 递归处理左右子树
- 若左右子树都找到节点，当前节点是 LCA
- 否则返回非空的那一侧

**正确性：** 由于 `nodes` 中所有节点都在树中，且集合节点不需要逐一找，只需找最高公共祖先。

## 代码实现

### 方法一：DFS + 集合（推荐）

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, nodes: List[TreeNode]) -> TreeNode:
        node_set = set(nodes)
        
        def dfs(node: TreeNode) -> Optional[TreeNode]:
            if not node:
                return None
            
            # 若当前节点在目标集合中，直接返回（其后代不需要再找）
            if node in node_set:
                return node
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            # 左右都找到，当前节点是 LCA
            if left and right:
                return node
            
            return left or right
        
        return dfs(root)
```

### 方法二：值集合（更通用）

```python
from typing import Optional, List

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, nodes: List[TreeNode]) -> TreeNode:
        target_vals = {node.val for node in nodes}
        
        def dfs(node: TreeNode) -> Optional[TreeNode]:
            if not node:
                return None
            if node.val in target_vals:
                return node
            left = dfs(node.left)
            right = dfs(node.right)
            if left and right:
                return node
            return left or right
        
        return dfs(root)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS | O(n) | O(n) |

## 关键点总结

1. 与双节点 LCA 本质相同，只是目标是多个节点
2. 找到目标节点后直接返回，不再深入（后代肯定在其下）
3. 若左右子树各有目标节点，当前节点就是 LCA

## 易错点

- 找到目标节点后要直接返回，不能继续遍历（否则会漏掉某些情况）
- 所有节点都在树中，不需要检查节点是否存在
