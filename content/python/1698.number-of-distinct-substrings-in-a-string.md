## 题目描述

给你一个字符串 `s`，请你返回 `s` 中**不同子字符串**的数目。

子字符串是字符串中的一个连续字符序列。

**示例 1：**
```
输入：s = "aabbaba"
输出：21
解释：共有 21 个不同的子字符串："a", "aa", "aab", "aabb", "aabba", "aabbab", "aabbaba", "ab", "abb", "abba", "abbab", "abbaba", "b", "ba", "bab", "baba", "bb", "bba", "bbab", "bbaba", "aba"
```

**示例 2：**
```
输入：s = "abcdefg"
输出：28
解释：所有长度从 1 到 7 的子串都不相同，共 7+6+5+4+3+2+1 = 28 个
```

**提示：**
- `1 <= s.length <= 500`
- `s` 仅包含小写英文字母

## 解题思路

**方法一（暴力 + 集合）：** 枚举所有子串，用集合去重，直接统计大小。对于 n <= 500，时间复杂度 O(n^3) 或 O(n^2)（哈希集合插入均摊 O(length)）可以通过。

**方法二（字典树 Trie）：** 从每个位置出发，将以该位置开始的所有后缀逐字符插入 Trie 树。每次插入新节点时，计数加一（代表发现了一个新的不同子串）。

**方法三（后缀数组）：** 构建后缀数组 SA 和 LCP 数组，答案为 `n*(n+1)/2 - sum(LCP)`。

## 代码实现

### 方法一：集合暴力（推荐，简单直接）

```python
class Solution:
    def countDistinct(self, s: str) -> int:
        n = len(s)
        substrings = set()
        for i in range(n):
            for j in range(i + 1, n + 1):
                substrings.add(s[i:j])
        return len(substrings)
```

### 方法二：字典树

```python
class TrieNode:
    def __init__(self):
        self.children = {}

class Solution:
    def countDistinct(self, s: str) -> int:
        n = len(s)
        root = TrieNode()
        count = 0

        for i in range(n):
            # 从位置 i 开始，将后缀逐字符插入 Trie
            node = root
            for j in range(i, n):
                c = s[j]
                if c not in node.children:
                    # 发现新子串（新节点）
                    node.children[c] = TrieNode()
                    count += 1
                node = node.children[c]

        return count
```

### 方法三：后缀数组（了解，n <= 500 时可用）

```python
class Solution:
    def countDistinct(self, s: str) -> int:
        n = len(s)
        # 构建所有后缀并排序
        suffixes = sorted(range(n), key=lambda i: s[i:])

        # 计算相邻后缀的最长公共前缀（LCP）
        def lcp(i, j):
            count = 0
            while i < n and j < n and s[i] == s[j]:
                count += 1
                i += 1
                j += 1
            return count

        # 总子串数 = n*(n+1)//2，减去所有相邻后缀的 LCP 之和
        total = n * (n + 1) // 2
        for k in range(len(suffixes) - 1):
            total -= lcp(suffixes[k], suffixes[k + 1])

        return total
```

## 复杂度分析

**方法一（集合）：**
- 时间复杂度：O(n^3)（子串哈希）或 O(n^2) 均摊
- 空间复杂度：O(n^2)，集合存储所有子串

**方法二（字典树）：**
- 时间复杂度：O(n^2)，每个字符插入 Trie 最多 n 次
- 空间复杂度：O(n^2)，Trie 节点数量

**方法三（后缀数组）：**
- 时间复杂度：O(n^2 log n)（简单实现）
- 空间复杂度：O(n)

## 关键点总结

1. 方法一最简单，n <= 500 时完全够用
2. 字典树方法：每插入一个新节点即代表发现一个新的不同子串
3. 后缀数组方法利用公式：不同子串数 = 总子串数 - LCP 之和
4. 根据数据范围选择方法：本题 n <= 500，三种方法均可

## 易错点

1. 子串的定义是"连续序列"，空字符串通常不算
2. 方法三中 LCP 数组的计算需要额外注意索引，直接比较后缀字符串更安全
3. 集合存字符串会占用较多内存，但对 n <= 500 没有影响
