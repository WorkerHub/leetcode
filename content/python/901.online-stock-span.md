## 题目描述

设计一个算法收集某些股票的每日报价，并返回该股票当日价格的跨度。

当日股票价格的跨度被定义为股票价格小于或等于今天价格的最大连续日数（从今天开始往回数，包括今天）。

例如，如果未来7天股票的价格是 `[100, 80, 60, 70, 60, 75, 85]`，那么股票跨度将是 `[1, 1, 1, 2, 1, 4, 6]`。

实现 `StockSpanner` 类：
- `StockSpanner()` 初始化类
- `int next(int price)` 给出今天股票的价格，返回该股票当日价格的跨度

**示例 1：**
```
输入：
["StockSpanner", "next", "next", "next", "next", "next", "next", "next"]
[[], [100], [80], [60], [70], [60], [75], [85]]
输出：
[null, 1, 1, 1, 2, 1, 4, 6]

解释：
StockSpanner stockSpanner = new StockSpanner();
stockSpanner.next(100); // 返回 1
stockSpanner.next(80);  // 返回 1
stockSpanner.next(60);  // 返回 1
stockSpanner.next(70);  // 返回 2
stockSpanner.next(60);  // 返回 1
stockSpanner.next(75);  // 返回 4，因为截止今天的最后 4 个价格 (包括今天的价格 75) 都小于或等于今天的价格。
stockSpanner.next(85);  // 返回 6
```

**提示：**
- 1 <= price <= 10^5
- 最多调用 next 方法 10^4 次

## 解题思路

这是一道经典的单调栈问题。核心思想是：
1. 对于每个价格，我们需要找到它左边有多少个连续的价格小于或等于它
2. 使用单调递减栈来维护价格和对应的跨度
3. 栈中存储 `(价格, 跨度)` 元组

**算法流程：**
1. 维护一个单调递减栈，栈中存储 `(price, span)` 对
2. 当新价格来临时，初始化跨度为 1
3. 弹出所有小于等于当前价格的元素，并累加它们的跨度
4. 将当前价格和累计跨度压入栈
5. 返回跨度值

**关键观察：**
- 如果当前价格大于等于栈顶价格，说明栈顶对应的天数都可以被当前天包含
- 栈顶元素的跨度已经计算好了，可以直接累加，不需要逐个遍历

## Python 代码实现

### 方法一：单调栈（推荐）⭐

```python
class StockSpanner:
    def __init__(self):
        # 单调递减栈，存储 (价格, 跨度)
        self.stack = []

    def next(self, price: int) -> int:
        span = 1  # 当前天的跨度至少为 1
        
        # 弹出所有小于等于当前价格的元素
        while self.stack and self.stack[-1][0] <= price:
            # 累加被弹出元素的跨度
            span += self.stack.pop()[1]
        
        # 将当前价格和跨度压入栈
        self.stack.append((price, span))
        
        return span
```

### 方法二：单调栈（记录索引版本）

```python
class StockSpanner:
    def __init__(self):
        # 存储所有价格
        self.prices = []
        # 单调递减栈，存储索引
        self.stack = []

    def next(self, price: int) -> int:
        # 记录当前索引
        index = len(self.prices)
        self.prices.append(price)
        
        # 弹出所有小于等于当前价格的索引
        while self.stack and self.prices[self.stack[-1]] <= price:
            self.stack.pop()
        
        # 计算跨度
        if not self.stack:
            # 栈为空，说明所有之前的价格都小于等于当前价格
            span = index + 1
        else:
            # 跨度 = 当前索引 - 栈顶索引
            span = index - self.stack[-1]
        
        self.stack.append(index)
        return span
```

### 方法三：暴力法（用于理解，不推荐）

```python
class StockSpanner:
    def __init__(self):
        self.prices = []

    def next(self, price: int) -> int:
        self.prices.append(price)
        span = 1
        
        # 从后往前遍历
        for i in range(len(self.prices) - 2, -1, -1):
            if self.prices[i] <= price:
                span += 1
            else:
                break
        
        return span
```

## 复杂度分析

**方法一（单调栈）：**
- 时间复杂度：
  - 单次 `next()` 操作：O(1) 均摊时间
  - 每个元素最多入栈和出栈各一次，所以 n 次操作总时间为 O(n)
- 空间复杂度：O(n)，栈中最多存储 n 个元素

**方法三（暴力法）：**
- 时间复杂度：O(n)，每次可能需要遍历所有历史价格
- 空间复杂度：O(n)，存储所有价格

## 关键点总结

1. **单调栈的应用**：维护单调递减栈来快速查找左侧连续小于等于当前值的元素
2. **跨度累加**：利用栈中已计算的跨度值，避免重复计算
3. **均摊时间复杂度**：虽然单次操作可能弹出多个元素，但每个元素只会入栈和出栈各一次
4. **两种实现方式**：可以存储 `(价格, 跨度)` 或者存储索引，各有优劣
5. **栈的意义**：栈顶到栈底的价格严格递减，形成了一个"阶梯"结构

## 易错点

1. **跨度初始化**：跨度初始值应该是 1（包括今天），不是 0
2. **弹出条件**：是 `<=` 不是 `<`，等于当前价格的也要弹出
3. **空栈处理**：栈为空时，跨度应该是从开始到现在的所有天数
4. **数据结构选择**：必须使用栈，不能用队列或其他结构
5. **边界情况**：第一个价格的跨度永远是 1
