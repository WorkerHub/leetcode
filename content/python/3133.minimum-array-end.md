## 题目描述

给你两个整数 `n` 和 `x`。构造一个长度为 `n` 的数组 `nums`，满足：
- `nums[0] = x`
- `nums[i] < nums[i+1]`（严格递增）
- 对所有 `i`，`nums[0] AND nums[1] AND ... AND nums[i] == x`（所有元素的 AND 等于 x）

返回 `nums[n-1]` 的 **最小** 可能值。

**示例 1：**
```
输入：n = 3, x = 4
输出：6
解释：[4,5,6] -> 4&5&6 = 4
```

**示例 2：**
```
输入：n = 2, x = 7
输出：15
解释：[7,15] -> 7&15 = 7
```

**提示：**
- `1 <= n <= 10^8`
- `1 <= x <= 10^8`

## 解题思路

要使 AND 始终为 x，每个元素的所有 x 对应的 1 位必须也为 1。x 的 0 位可以自由变化。

问题等价于：在 x 的 0 位上填入 0 到 n-1（n-1 的二进制表示），找最小的 `nums[n-1]`。

具体地，将 n-1 的二进制位依次嵌入 x 的 0 位（从低位到高位），得到 `nums[n-1]`。

## Python 代码实现

### 方法一：位填充（推荐）

```python
class Solution:
    def minEnd(self, n: int, x: int) -> int:
        # 将 n-1 的各位嵌入 x 的零位中
        result = x
        val = n - 1  # 需要嵌入的值
        bit = 0      # x 的当前检查位

        while val > 0:
            # 找 x 的下一个 0 位
            while (result >> bit) & 1:
                bit += 1
            # 将 val 的最低位嵌入 result 的第 bit 位
            if val & 1:
                result |= (1 << bit)
            val >>= 1
            bit += 1

        return result
```

### 方法二：枚举（小数据验证用）

```python
class Solution:
    def minEnd(self, n: int, x: int) -> int:
        cur = x
        for _ in range(n - 1):
            cur = (cur + 1) | x  # 下一个数：先加 1，再与 x 按位或，保证 AND 不变
        return cur
```

## 复杂度分析

- 时间复杂度：O(log n * log x)，位操作
- 空间复杂度：O(1)

## 关键点总结

1. 所有元素的 AND = x，意味着 x 的 1 位在所有元素中都为 1
2. 下一个合法数 = (cur + 1) | x（在 x 的 0 位上递增）
3. 最后一个数等价于将 n-1 的二进制嵌入 x 的 0 位

## 易错点

1. n 较大时不能暴力枚举，需要位填充技巧
2. 嵌入时从 n-1 的低位开始，对应 x 的低位 0
