## 题目描述

给定编号从 `0` 到 `n-1` 的 `n` 个节点和一个无向边列表（每条边都是一对节点），判断这些边是否能够形成一个有效的树。

树的定义：
- 包含 n 个节点的连通图
- 恰好有 n-1 条边
- 无环

**示例 1：**
```
输入: n = 5, edges = [[0,1], [0,2], [0,3], [1,4]]
输出: true
```

**示例 2：**
```
输入: n = 5, edges = [[0,1], [1,2], [2,3], [1,3], [1,4]]
输出: false
```

**提示：**
- `1 <= n <= 2000`
- `0 <= edges.length <= 5000`
- `edges[i].length == 2`
- `0 <= ai, bi < n`
- `ai != bi`
- 不存在重复的边

## 解题思路

判断一个无向图是否为树，需要满足两个条件：

1. **连通性**：所有节点都连通
2. **无环性**：图中没有环

根据树的性质，还可以得出：
- 对于 n 个节点的树，必须恰好有 n-1 条边
- 如果边数不等于 n-1，直接返回 false

常见的三种解法：
1. **并查集（Union-Find）**：检测环和连通性
2. **DFS（深度优先搜索）**：检测环和连通性
3. **BFS（广度优先搜索）**：检测环和连通性

## Python 代码实现

### 方法一：并查集（推荐）⭐

```python
class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        # 树必须有 n-1 条边
        if len(edges) != n - 1:
            return False
        
        # 初始化并查集
        parent = list(range(n))
        
        def find(x: int) -> int:
            """查找根节点，路径压缩优化"""
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            """合并两个集合，如果已在同一集合则返回 False（有环）"""
            root_x = find(x)
            root_y = find(y)
            
            if root_x == root_y:
                return False  # 已在同一集合，形成环
            
            parent[root_x] = root_y
            return True
        
        # 遍历所有边，尝试合并
        for u, v in edges:
            if not union(u, v):
                return False  # 发现环
        
        # 能执行到这里，说明没有环且边数正确（n-1条边）
        # 此时必然是连通的树
        return True
```

### 方法二：DFS（深度优先搜索）

```python
class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        # 树必须有 n-1 条边
        if len(edges) != n - 1:
            return False
        
        # 构建邻接表
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # DFS 检测环和连通性
        visited = set()
        
        def dfs(node: int, parent: int) -> bool:
            """DFS 遍历，parent 是父节点，用于避免回到父节点"""
            visited.add(node)
            
            for neighbor in graph[node]:
                if neighbor == parent:
                    continue  # 跳过父节点
                
                if neighbor in visited:
                    return False  # 访问到已访问节点，说明有环
                
                if not dfs(neighbor, node):
                    return False
            
            return True
        
        # 从节点 0 开始 DFS
        if not dfs(0, -1):
            return False
        
        # 检查是否所有节点都被访问（连通性）
        return len(visited) == n
```

### 方法三：BFS（广度优先搜索）

```python
from collections import deque

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        # 树必须有 n-1 条边
        if len(edges) != n - 1:
            return False
        
        # 构建邻接表
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # BFS 遍历
        visited = set([0])
        queue = deque([0])
        
        while queue:
            node = queue.popleft()
            
            for neighbor in graph[node]:
                if neighbor in visited:
                    continue
                
                visited.add(neighbor)
                queue.append(neighbor)
        
        # 检查是否所有节点都被访问
        return len(visited) == n
```

### 方法四：简化版（边数判断 + BFS）

```python
from collections import deque

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        # 快速判断：树必须有 n-1 条边
        if len(edges) != n - 1:
            return False
        
        # 只需检查连通性即可（边数已确保无环）
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # BFS 检查连通性
        visited = {0}
        queue = deque([0])
        
        while queue:
            node = queue.popleft()
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        return len(visited) == n
```

## 复杂度分析

### 方法一（并查集）
- **时间复杂度**：O(n + E⋅α(n))，其中 E 是边数，α(n) 是阿克曼函数的反函数，几乎为常数
- **空间复杂度**：O(n)，存储并查集数组

### 方法二、三、四（DFS/BFS）
- **时间复杂度**：O(n + E)，遍历所有节点和边
- **空间复杂度**：O(n + E)，存储图的邻接表和访问记录

## 关键点总结

1. **树的判定条件**：n 个节点的树必须满足恰好有 n-1 条边、连通、无环
2. **边数快速判断**：先判断边数是否为 n-1，可以快速排除大部分情况
3. **并查集适用性**：并查集天然适合处理连通性和环检测问题
4. **DFS/BFS 记录父节点**：在无向图中用 DFS 检测环时，需要记录父节点避免回头
5. **优化技巧**：如果边数已经是 n-1，只需检查连通性即可（无需额外检测环）

## 易错点

1. **忘记判断边数**：必须先判断 `len(edges) != n - 1`
2. **DFS 回到父节点**：在无向图中，邻居包含父节点，需要跳过父节点
3. **连通性检查**：即使没有环，也需要检查是否所有节点都连通
4. **并查集的环检测**：如果两个节点已在同一集合，再连边就形成环
5. **空图处理**：n=1, edges=[] 是有效的树

2. **掌握并查集**：这是处理图连通性问题的经典数据结构，建议熟练掌握
