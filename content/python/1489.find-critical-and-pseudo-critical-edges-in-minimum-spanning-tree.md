## 题目描述

给你一个 `n` 个节点的带权无向图，节点编号从 `0` 到 `n-1`。

图用 `edges` 表示，其中 `edges[i] = [u, v, weight]` 代表一条从节点 `u` 到节点 `v` 权值为 `weight` 的无向边。

请你找出所有的**关键边**和**伪关键边**，并分别将其以列表形式返回。

- **关键边**：若从图中删去该边，最小生成树（MST）的权值和会增大，或者无法形成 MST，则该边为关键边。
- **伪关键边**：若该边可以出现在某棵 MST 中，但并非所有 MST 中都有它（即它不是关键边），则该边为伪关键边。

**示例 1：**

```
输入：n = 5, edges = [[0,1,1],[1,2,1],[2,3,2],[0,3,2],[0,4,3],[3,4,3],[1,4,6]]
输出：[[0,1],[2,3,4,5]]
```

**示例 2：**

```
输入：n = 4, edges = [[0,1,1],[1,2,1],[0,2,1]]
输出：[[],[0,1,2]]
```

**提示：**

- `2 <= n <= 100`
- `1 <= edges.length <= min(200, n*(n-1)/2)`
- `edges[i].length == 3`
- `0 <= fromi, toi < n`
- `1 <= weighti <= 1000`
- 所有边不重复，且两端点不同。

## 解题思路

**核心思想：枚举每条边，用 Kruskal 算法验证。**

首先求出原始 MST 的权值 `base_weight`，然后对每条边 `e`：

1. **判断是否为关键边**：删去边 `e`，重新跑 Kruskal。若新 MST 权值大于 `base_weight` 或图变得不连通，则 `e` 是关键边。

2. **判断是否为伪关键边**：强制将边 `e` 加入（合并其两端点），再对剩余边跑 Kruskal。若得到的权值等于 `base_weight`，则 `e` 是伪关键边。

**并查集（Union-Find）** 是 Kruskal 的核心数据结构，支持高效的合并和查询操作。

**算法流程：**

```
1. 对所有边按权值排序（保留原始索引）
2. 用 Kruskal 求原始 MST 权值 base_weight
3. 对每条边 i：
   a. 删去边 i，跑 Kruskal，若结果 != base_weight → 关键边
   b. 若不是关键边，强制加入边 i，跑 Kruskal，若结果 == base_weight → 伪关键边
```

**Kruskal 算法回顾：**

- 将所有边按权值从小到大排序
- 依次考虑每条边，若它连接的两个节点不在同一连通分量中，则将其加入 MST
- 使用并查集判断连通性并合并

## Python 代码实现

### 方法一：枚举 + Kruskal + 并查集（推荐）

```python
from typing import List

class Solution:
    def findCriticalAndPseudoCriticalEdges(self, n: int, edges: List[List[int]]) -> List[List[int]]:
        # 保留原始索引，以便最终返回正确的边编号
        indexed_edges = [(w, u, v, i) for i, (u, v, w) in enumerate(edges)]
        indexed_edges.sort()  # 按权值排序

        def make_uf(n):
            """初始化并查集"""
            parent = list(range(n))
            rank = [0] * n
            return parent, rank

        def find(parent, x):
            """路径压缩"""
            if parent[x] != x:
                parent[x] = find(parent, parent[x])
            return parent[x]

        def union(parent, rank, x, y):
            """按秩合并，返回是否成功合并（原本不连通）"""
            rx, ry = find(parent, x), find(parent, y)
            if rx == ry:
                return False
            if rank[rx] < rank[ry]:
                rx, ry = ry, rx
            parent[ry] = rx
            if rank[rx] == rank[ry]:
                rank[rx] += 1
            return True

        def kruskal(n, edges_list, skip_idx=-1, force_edge=None):
            """
            运行 Kruskal 算法
            skip_idx:   要跳过的边的原始索引（用于验证关键边）
            force_edge: 强制加入的边 (u, v, w)（用于验证伪关键边）
            返回 (MST权值, 连通边数)
            """
            parent, rank = make_uf(n)
            total_weight = 0
            edge_count = 0

            # 若有强制边，先加入
            if force_edge is not None:
                w, u, v = force_edge
                union(parent, rank, u, v)
                total_weight += w
                edge_count += 1

            # 按排序后的顺序加边
            for w, u, v, idx in edges_list:
                if idx == skip_idx:
                    continue
                if union(parent, rank, u, v):
                    total_weight += w
                    edge_count += 1

            return total_weight, edge_count

        # 求原始 MST 权值
        base_weight, base_count = kruskal(n, indexed_edges)

        critical = []
        pseudo_critical = []

        for w, u, v, i in indexed_edges:
            # 1. 判断关键边：删去该边后 MST 权值变大或不连通
            skip_weight, skip_count = kruskal(n, indexed_edges, skip_idx=i)
            if skip_count < n - 1 or skip_weight > base_weight:
                critical.append(i)
                continue

            # 2. 判断伪关键边：强制加入后 MST 权值不变
            force_weight, _ = kruskal(n, indexed_edges, force_edge=(w, u, v))
            if force_weight == base_weight:
                pseudo_critical.append(i)

        # 按原始索引排序（题目不要求，但更规范）
        critical.sort()
        pseudo_critical.sort()
        return [critical, pseudo_critical]
```

### 方法二：预处理优化版（更清晰的结构）

```python
from typing import List

class Solution:
    def findCriticalAndPseudoCriticalEdges(self, n: int, edges: List[List[int]]) -> List[List[int]]:
        m = len(edges)
        # 将边信息扩展为 (u, v, w, original_index)
        new_edges = [[u, v, w, i] for i, (u, v, w) in enumerate(edges)]
        new_edges.sort(key=lambda x: x[2])  # 按权值排序

        class UnionFind:
            def __init__(self, n):
                self.parent = list(range(n))
                self.rank = [0] * n
                self.cnt = n  # 连通分量数量

            def find(self, x):
                if self.parent[x] != x:
                    self.parent[x] = self.find(self.parent[x])
                return self.parent[x]

            def union(self, x, y):
                px, py = self.find(x), self.find(y)
                if px == py:
                    return False
                if self.rank[px] < self.rank[py]:
                    px, py = py, px
                self.parent[py] = px
                if self.rank[px] == self.rank[py]:
                    self.rank[px] += 1
                self.cnt -= 1
                return True

            def connected(self):
                return self.cnt == 1

        def get_mst_weight(skip=-1, pre_u=-1, pre_v=-1, pre_w=0):
            """
            计算 MST 权值
            skip:         跳过的边索引（-1 表示不跳过）
            pre_u, pre_v: 强制加入的边（-1 表示不强制）
            pre_w:        强制加入边的权值
            """
            uf = UnionFind(n)
            weight = 0
            # 强制加入边
            if pre_u != -1:
                uf.union(pre_u, pre_v)
                weight += pre_w
            for j, (u, v, w, idx) in enumerate(new_edges):
                if j == skip:
                    continue
                if uf.union(u, v):
                    weight += w
            # 不连通时返回无穷大
            return weight if uf.connected() else float('inf')

        base = get_mst_weight()

        critical = []
        pseudo = []
        for i, (u, v, w, orig_idx) in enumerate(new_edges):
            # 关键边：删去后 MST 权值增大或不连通
            if get_mst_weight(skip=i) > base:
                critical.append(orig_idx)
            # 伪关键边：强制加入后权值等于 base
            elif get_mst_weight(pre_u=u, pre_v=v, pre_w=w) == base:
                pseudo.append(orig_idx)

        critical.sort()
        pseudo.sort()
        return [critical, pseudo]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一/二 | O(m^2 * alpha(n)) | O(n) |

- `m` 为边数，`n` 为节点数，`alpha` 为反阿克曼函数（近似常数）
- 对每条边都跑两次 Kruskal，每次 Kruskal 是 O(m * alpha(n))
- 总体 O(m^2 * alpha(n))，由于 m <= 200，实际运行很快

## 关键点总结

1. **保留原始索引**：排序后边的顺序变化，必须记录原始位置以返回正确编号。
2. **关键边判断**：删去该边后 MST 权值严格增大，或图变得不连通（权值返回无穷大）。
3. **伪关键边判断**：强制加入该边（先合并两端），再跑剩余 Kruskal，权值等于原始 MST 即可。
4. **并查集路径压缩 + 按秩合并**：保证接近 O(1) 的单次操作。
5. **不连通的处理**：删边后若图不连通，连通边数 < n-1，需要特判。

## 易错点

- **原始索引丢失**：排序时必须携带原始索引，否则无法返回正确答案。
- **强制加入边的顺序**：必须先加强制边，再跑剩余 Kruskal，否则结果不正确。
- **不连通的判断**：仅检查权值不够，需同时检查是否成功构建 n-1 条边的树。
- **边的去重**：题目保证无重边，但排序后相同权值的边处理需小心。
