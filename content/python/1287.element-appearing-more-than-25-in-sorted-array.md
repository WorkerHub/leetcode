## 题目描述

给你一个非递减的整数数组，已知**恰好有一个整数**在数组中出现的频率超过 **25%**（即出现次数超过 `n/4` 次，其中 `n` 是数组长度）。

请你找到并返回该整数。

**示例 1：**

```
输入：arr = [1,2,2,6,6,6,6,7,10]
输出：6
解释：
n = 9，n/4 = 2.25
6 出现了 4 次，4 > 2.25，所以 6 是答案。
```

**示例 2：**

```
输入：arr = [1,1]
输出：1
解释：n=2，n/4=0.5，1 出现 2 次 > 0.5
```

**提示：**

- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 10^5`

---

## 解题思路

题目告诉我们数组**已经有序（非递减排列）**，并且**恰好有一个**元素出现频率超过 25%。这两个条件让我们可以设计比暴力更高效的解法。

### 思路一：暴力计数（Counter）

直接统计每个元素的出现次数，找到出现次数 > n/4 的元素。时间 O(n)，利用了题目保证"有且仅有一个"的结论，无需排序利用。

### 思路二：利用有序性（候选位置法）

**关键洞察**：在一个长度为 `n` 的有序数组中，如果某元素出现次数超过 `n/4`，那么这个元素一定**占据了某个"四分位点"位置**。

具体来说，三个四分位点位置是：`n//4`、`n//2`、`3*n//4`。

**证明**：若元素 x 出现次数 > n/4，则 x 在有序数组中形成一段连续的区间，长度 > n/4。将数组分为 4 段（0~n/4, n/4~n/2, n/2~3n/4, 3n/4~n），若 x 的区间长度 > n/4，它不可能完全避开所有三个四分位点（因为四个段的间隔最多为 n/4，而 x 的区间更长）。

所以，只需检查三个候选位置 `arr[n//4]`、`arr[n//2]`、`arr[3*n//4]`，验证哪个出现次数 > n/4 即为答案。

### 思路三：利用有序性（跨度检查法）

对于有序数组，若 `arr[i] == arr[i + n//4]`，则 arr[i] 至少出现 `n//4 + 1` 次（从位置 i 到 i+n//4，共 n//4+1 个），超过 n/4，满足条件。

因此，遍历所有有效位置 i，找到第一个满足 `arr[i] == arr[i + n//4]` 的即为答案。

## Python 代码实现

### 方法一：Counter 计数（直接暴力）

```python
from collections import Counter
from typing import List

class Solution:
    def findSpecialInteger(self, arr: List[int]) -> int:
        n = len(arr)
        count = Counter(arr)  # 统计每个元素的出现次数

        for num, cnt in count.items():
            if cnt * 4 > n:   # cnt > n/4 等价于 cnt*4 > n（避免浮点数）
                return num

        return -1  # 题目保证有答案，不会到达此处
```

### 方法二：候选位置法（利用有序性，O(log n)）

```python
import bisect
from typing import List

class Solution:
    def findSpecialInteger(self, arr: List[int]) -> int:
        n = len(arr)
        # 三个四分位点，任何出现 > 25% 的元素必然包含其中至少一个
        candidates = [arr[n // 4], arr[n // 2], arr[3 * n // 4]]

        for c in candidates:
            # 使用二分查找统计 c 的出现次数
            left = bisect.bisect_left(arr, c)    # c 第一次出现的位置
            right = bisect.bisect_right(arr, c)  # c 最后一次出现位置的下一个
            count = right - left                  # 出现次数

            if count * 4 > n:   # count > n/4
                return c

        return -1
```

**示例演示（arr = [1,2,2,6,6,6,6,7,10]，n=9）：**

```
候选位置：
  n//4 = 2 -> arr[2] = 2
  n//2 = 4 -> arr[4] = 6
  3*n//4 = 6 -> arr[6] = 6

检验 c=2：bisect_left=1, bisect_right=3, count=2, 2*4=8 <= 9，不满足
检验 c=6：bisect_left=3, bisect_right=7, count=4, 4*4=16 > 9，满足！返回 6
```

### 方法三：跨度检查法（O(n)，代码最简）

```python
from typing import List

class Solution:
    def findSpecialInteger(self, arr: List[int]) -> int:
        n = len(arr)
        span = n // 4  # 跨度：若 arr[i]==arr[i+span]，则该元素出现次数 > n/4

        # 遍历每个可以"向后跨 span 步"的位置
        for i in range(n - span):
            if arr[i] == arr[i + span]:
                return arr[i]

        return -1
```

**为什么跨度法正确？**

- `span = n // 4`，则 `span + 1 > n/4`（因为 `n//4 + 1 > n/4` 对所有正整数 n 成立）。
- 若 `arr[i] == arr[i + span]`，由于数组有序，arr[i] 在位置 i 到 i+span 之间均相同，共 `span + 1 > n/4` 个，满足条件。
- 题目保证有且仅有一个满足条件的元素，所以第一次找到的就是答案。

### 方法四：线性扫描计数（O(n)，不使用 Counter）

```python
from typing import List

class Solution:
    def findSpecialInteger(self, arr: List[int]) -> int:
        n = len(arr)
        threshold = n // 4  # 出现次数需要严格超过 threshold

        count = 1  # 当前元素的连续出现次数

        for i in range(1, n):
            if arr[i] == arr[i - 1]:
                count += 1          # 与前一个相同，计数加 1
                if count > threshold:
                    return arr[i]   # 已超过 n/4，返回答案
            else:
                count = 1           # 新元素出现，重置计数

        # 处理只有一个元素或最后一段的情况
        return arr[0]
```

**注意**：方法四利用了数组有序的特性，相同元素连续出现，可以用一次遍历计数。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 备注 |
|------|-----------|-----------|------|
| Counter 计数 | O(n) | O(n) | 额外哈希表 |
| 候选位置法 | O(log n) | O(1) | 最优，利用有序性 |
| 跨度检查法 | O(n) | O(1) | 代码最简 |
| 线性扫描 | O(n) | O(1) | 有序数组专用 |

候选位置法虽然理论上最优（O(log n)），但实际上对于本题的数据范围（n <= 10^4），O(n) 方法也完全够用。

## 关键点总结

1. **有序数组的四分位点性质**：出现频率超过 25% 的元素必然出现在三个四分位点（`n//4`, `n//2`, `3n//4`）之一，这是解题的核心洞察。
2. **跨度检查的等价性**：`arr[i] == arr[i + n//4]` 意味着该元素至少出现 `n//4 + 1 > n/4` 次。
3. **整数避免浮点**：用 `count * 4 > n` 代替 `count > n / 4`，避免浮点数比较的精度问题。
4. **二分查找计数**：`bisect_right(arr, x) - bisect_left(arr, x)` 是在有序数组中统计 x 出现次数的标准 O(log n) 方法。

---

## 易错点

1. **threshold 的计算**：出现次数需"严格超过 n/4"（>），用 `count * 4 > n` 而非 `count * 4 >= n`。
2. **跨度检查的范围**：循环范围是 `range(n - span)`，不是 `range(n)`，否则 `i + span` 会越界。
3. **方法三的假设**：跨度法假设数组有序，若数组无序则此方法错误。
4. **线性扫描的边界**：方法四处理最后一段时需要注意，若最后一段数量超过 threshold 但循环在最后一个元素时结束，需要在循环后处理。（简化版：方法四的最后 `return arr[0]` 可以处理仅有一个元素的情况，但一般情况下答案会在循环中找到。）
