## 题目描述

给你一个整数数组 `nums` 和正整数 `k`。

返回长度能被 `k` 整除的非空子数组的**最大元素和**。

**示例：**
```
输入：nums = [1, 2, 3, 4, 5], k = 2
输出：14
解释：子数组 [1,2,3,4] 长度为4，和为10；[1,2,3,4,5] 不合法；[3,4,5] 长度3不被2整除；
      实际上 [2,3,4,5] 长度4，和14最大
```

**提示：**
- `1 <= nums.length <= 2 * 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

**前缀和 + 哈希表：**

设前缀和 `prefix[i] = nums[0] + ... + nums[i-1]`（prefix[0] = 0）。

子数组 `nums[l..r]`（长度 `r-l+1`）的和 = `prefix[r+1] - prefix[l]`。

长度被 k 整除：`r+1 - l` 被 k 整除，即 `r+1 ≡ l (mod k)`，即 `(r+1) % k == l % k`。

对每个位置 `j`（前缀和下标），找所有 `i < j` 且 `i % k == j % k` 的 `prefix[i]` 的最小值（最小化减数），使 `prefix[j] - prefix[i]` 最大。

用哈希表 `min_prefix[r]` = 对应 `r % k == r` 的所有前缀和的最小值。

## Python 代码实现

### 方法一：前缀和 + 哈希表（推荐）

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        INF = float('inf')
        
        # min_prefix[r] = 同余 r mod k 的所有前缀和中的最小值
        min_prefix = {}
        prefix = 0
        
        # 初始：prefix[0] = 0，余数 0 mod k = 0
        min_prefix[0] = 0  # 余数 0 对应前缀和最小值为 0
        
        best = -INF
        
        for i in range(n):
            prefix += nums[i]
            r = (i + 1) % k  # 前缀和 prefix[i+1] 的下标 i+1 的余数
            
            # 找与 r 同余的最小前缀和
            if r in min_prefix:
                best = max(best, prefix - min_prefix[r])
            
            # 更新 min_prefix[r]
            if r not in min_prefix or prefix < min_prefix[r]:
                min_prefix[r] = prefix
        
        return best if best != -INF else -1
```

### 方法二：利用数组（固定余数范围）

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        
        # min_pref[r] = 余数为 r 的前缀和最小值
        min_pref = [float('inf')] * k
        min_pref[0] = 0  # prefix[0] = 0，余数 0
        
        prefix = 0
        best = float('-inf')
        
        for i in range(n):
            prefix += nums[i]
            r = (i + 1) % k
            if min_pref[r] != float('inf'):
                best = max(best, prefix - min_pref[r])
            min_pref[r] = min(min_pref[r], prefix)
        
        return best
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(k)，余数数组

## 关键点总结

1. 子数组长度被 k 整除 <=> 左端点和右端点（前缀和下标）模 k 相同。
2. 对每个右端点（前缀和下标 j），找同余的最小前缀和，使差值最大。
3. 初始化：`min_pref[0] = 0`（对应空前缀，允许从头开始的子数组）。

## 易错点

1. 前缀和下标从 0 到 n，`prefix[j]` 对应子数组 `nums[0..j-1]`。
2. 初始化 `min_pref[0] = 0`（`prefix[0] = 0`，余数 `0 % k = 0`）。
3. 子数组必须非空（前缀和下标 `j > i`，`j - i >= 1`，且 `j - i` 被 k 整除）。
