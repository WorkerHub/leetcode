## 题目描述

给你一个大小为 m x n 的矩阵 mat 和一个整数阈值 threshold。

请你返回元素总和小于或等于阈值的正方形区域的最大边长；如果没有这样的正方形区域，则返回 0 。

示例 1：

```
输入：mat = [[1,1,3,2,4,3,2],[1,1,3,2,4,3,2],[1,1,3,2,4,3,2]], threshold = 4
输出：2
解释：总和小于或等于 4 的正方形的最大边长为 2，如图所示。
```

示例 2：

```
输入：mat = [[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2]], threshold = 1
输出：0
```

提示：

- m == mat.length
- n == mat[i].length
- 1 <= m, n <= 300
- 0 <= mat[i][j] <= 10^4
- 0 <= threshold <= 10^5

## 解题思路

这道题可以使用二维前缀和 + 二分查找来解决。

### 核心思路：

1. **二维前缀和**：快速计算任意矩形区域的和
2. **二分查找**：在可能的边长范围内二分查找最大边长
3. **验证**：对于给定边长，检查是否存在满足条件的正方形

### 前缀和公式：

对于左上角 (r1, c1)，右下角 (r2, c2) 的矩形，其元素和为：
```
sum = prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]
```

## Python 代码实现

### 方法一：二维前缀和 + 遍历（推荐）

```python
from typing import List

class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])
        
        # 构建二维前缀和数组
        prefix = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                prefix[i][j] = mat[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
        
        def get_sum(r1: int, c1: int, r2: int, c2: int) -> int:
            """获取矩形区域的和"""
            return prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]
        
        max_len = 0
        
        # 遍历所有可能的正方形
        for i in range(m):
            for j in range(n):
                # 从当前最大边长+1开始尝试
                for length in range(max_len + 1, min(m - i, n - j) + 1):
                    if get_sum(i, j, i + length - 1, j + length - 1) <= threshold:
                        max_len = length
                    else:
                        break  # 边长越大，和越大，可以提前退出
        
        return max_len
```

### 方法二：二维前缀和 + 二分查找

```python
from typing import List

class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])
        
        # 构建二维前缀和
        prefix = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                prefix[i][j] = mat[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
        
        def check(length: int) -> bool:
            """检查是否存在边长为length的正方形满足条件"""
            for i in range(length, m + 1):
                for j in range(length, n + 1):
                    total = prefix[i][j] - prefix[i-length][j] - prefix[i][j-length] + prefix[i-length][j-length]
                    if total <= threshold:
                        return True
            return False
        
        # 二分查找最大边长
        left, right = 0, min(m, n)
        result = 0
        
        while left <= right:
            mid = (left + right) // 2
            if check(mid):
                result = mid
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```

## 复杂度分析

### 方法一：
- 时间复杂度：O(m * n * min(m,n))，构建前缀和 O(m*n)，遍历所有正方形
- 空间复杂度：O(m * n)，前缀和数组

### 方法二：
- 时间复杂度：O(m * n * log(min(m,n)))，二分查找次数 * 每次验证的时间
- 空间复杂度：O(m * n)

## 关键点总结

1. 二维前缀和是处理矩阵区域和问题的标准技巧
2. 前缀和的边界处理：通常添加一行一列的0
3. 二分查找可以优化遍历过程
4. 注意边长的最大值是 min(m, n)

## 易错点

1. 前缀和数组的下标容易出错
2. 矩形区域和的计算公式容易记错
3. 二分查找的边界条件处理
4. 忘记正方形边长不能超过矩阵尺寸
