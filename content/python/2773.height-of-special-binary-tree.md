## 题目描述

给你一棵二叉树的根节点 `root`，树中每个节点要么是 **叶子节点**，要么有 **两个子节点**。如果一个节点的两个子节点其中一个是叶子，另一个不是叶子，则该节点为 **特殊节点**。

返回树的 **特殊高度**：从根到最深叶子节点经过的特殊节点数量的最大值。

**示例：**
```
输入：root = [1,2,3,null,null,4,null,null,5]
输出：1
```

**提示：**
- `1 <= 树中节点数 <= 10^5`

## 解题思路

DFS 遍历树，对每个节点检查是否为特殊节点（一个子节点是叶子，另一个不是），如果是则计数 +1，向下递归。

## Python 代码实现

### 方法一：DFS（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def heightOfTree(self, root: Optional[TreeNode]) -> int:
        def is_leaf(node):
            return node and not node.left and not node.right

        def dfs(node) -> int:
            if not node or is_leaf(node):
                return 0
            left_height = dfs(node.left)
            right_height = dfs(node.right)
            # 检查是否为特殊节点：一子为叶，另一子不是叶
            is_special = (is_leaf(node.left) and not is_leaf(node.right)) or \
                         (is_leaf(node.right) and not is_leaf(node.left))
            bonus = 1 if is_special else 0
            return bonus + max(left_height, right_height)

        return dfs(root)
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树高

## 关键点总结

1. 特殊节点：两个子节点中恰好一个是叶子
2. 特殊高度是路径上特殊节点的计数

## 易错点

1. 叶子节点定义：没有子节点
2. 只有两个子节点都是非叶子或都是叶子时，不算特殊节点
