## 题目描述

给你一个非负整数（不含前导零）的链表表示，将这个数**乘以 2**，并返回结果链表。

**示例 1：**
```
输入：head = [1,8,9]
输出：[3,7,8]
解释：189 * 2 = 378
```

**示例 2：**
```
输入：head = [9,9,9]
输出：[1,9,9,8]
解释：999 * 2 = 1998（有进位，头部新增节点）
```

**提示：**
- 链表节点数 n 在 [1, 10^4] 之间
- `0 <= Node.val <= 9`
- 链表不含前导零（除非只有一个节点值为 0）

## 解题思路

链表从高位到低位存储数字，乘以 2 需要从低位（链表尾部）开始处理进位。

**方法 1：使用栈**
- 将链表节点值压入栈（从高位到低位）
- 从栈顶（低位）开始逐位乘以 2 并处理进位
- 从后往前修改节点值，若最终有进位则在头部插入新节点

**方法 2：反转链表**
- 翻转链表，从低位到高位处理
- 处理完后再翻转回来

**方法 3：递归**
- 递归到链表末尾，返回进位值

## Python 代码实现

### 方法一：使用栈（推荐）

```python
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def doubleIt(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 收集所有节点值到栈
        stack = []
        cur = head
        while cur:
            stack.append(cur.val)
            cur = cur.next

        # 从低位（栈顶）开始计算
        carry = 0
        cur = None  # 从尾部开始构建结果

        while stack or carry:
            val = (stack.pop() if stack else 0) * 2 + carry
            carry = val // 10
            val = val % 10
            node = ListNode(val)
            node.next = cur
            cur = node

        return cur
```

### 方法二：递归处理进位（优雅）

```python
from typing import Optional

class Solution:
    def doubleIt(self, head: Optional[ListNode]) -> Optional[ListNode]:
        def double(node: Optional[ListNode]) -> int:
            """递归乘以 2，返回当前节点的进位"""
            if node is None:
                return 0
            doubled = node.val * 2 + double(node.next)
            node.val = doubled % 10
            return doubled // 10

        carry = double(head)
        if carry:
            # 有进位，在头部插入新节点
            new_head = ListNode(carry)
            new_head.next = head
            return new_head
        return head
```

### 方法三：反转链表法

```python
from typing import Optional

class Solution:
    def doubleIt(self, head: Optional[ListNode]) -> Optional[ListNode]:
        def reverse(node: Optional[ListNode]) -> Optional[ListNode]:
            """反转链表"""
            prev = None
            while node:
                nxt = node.next
                node.next = prev
                prev = node
                node = nxt
            return prev

        # 翻转，从低位处理
        head = reverse(head)
        cur = head
        carry = 0
        while cur:
            val = cur.val * 2 + carry
            carry = val // 10
            cur.val = val % 10
            if cur.next is None and carry:
                cur.next = ListNode(carry)
                carry = 0
            cur = cur.next

        # 翻转回来
        return reverse(head)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历链表两次
- 空间复杂度：O(n)（方法一用栈），O(n)（方法二递归调用栈），O(1)（方法三）

## 关键点总结

1. 乘以 2 需要从低位开始，处理进位
2. 递归方法很优雅：先递归到末尾，返回进位，再修改当前节点
3. 最终如果 carry != 0，需要在链表头部插入新节点

## 易错点

1. 处理最高位的进位：最后如果 carry > 0，需要新建节点插入头部
2. 方法三需要两次翻转，注意翻转函数的正确性
3. 递归方法中函数返回的是进位，不是节点
