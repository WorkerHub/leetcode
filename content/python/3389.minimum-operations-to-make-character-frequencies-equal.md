## 题目描述

给你一个由小写英文字母组成的字符串 `s`，每次操作可以删除字符串中的任意一个字符。

返回使字符串中每种字母出现频率相等所需的**最少操作次数**。

**示例：**
```
输入：s = "aab"
输出：1
解释：删除一个 'a'，使 a、b 各出现 1 次。
```

**提示：**
- `1 <= s.length <= 2 * 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

**枚举目标频率 + 贪心：**

最终每种出现的字母频率相同。设目标频率为 `target`，统计各字母的频率数组 `freq[]`（只考虑出现过的字母）。

对于每个可能的目标频率 `target`（从 0 到 `max_freq`），计算需要多少次删除：
- 频率 > target 的字母：删多余部分，代价 = `freq[c] - target`
- 频率 < target 的字母：不能增加，只能全删，代价 = `freq[c]`（若 target > 0 时不想要这种字母）

等等，操作只有"删除"，所以：
- 若 `freq[c] > target`：删除 `freq[c] - target` 次
- 若 `freq[c] < target`：无法增加到 target，所以要么全删（代价 `freq[c]`），要么 target 不能超过 `freq[c]`

合法的 target 必须使所有保留的字母频率恰好等于 target（不能低于 target）。

实际上，target 可以是 0（全删）到 max_freq 中的任意值。对于每个 target：
- 代价 = sum of `freq[c]` if `freq[c] < target` (全删这些字母，因为无法增加) + sum of `(freq[c] - target)` if `freq[c] > target` (削减多余)

## Python 代码实现

### 方法一：枚举目标频率（推荐）

```python
from collections import Counter

class Solution:
    def minimumOperations(self, s: str) -> int:
        freq = sorted(Counter(s).values())  # 各字母的频率（升序）
        n = len(freq)
        total = sum(freq)
        
        best = total  # 最差情况：全删（target = 0）
        
        # 枚举目标频率：可以是 freq 数组中的某个值，或者 freq[i] - 1（使 i 号字母也被删掉）
        candidates = set(freq) | {f - 1 for f in freq} | {0}
        
        for target in candidates:
            if target < 0:
                continue
            cost = 0
            for f in freq:
                if f < target:
                    # 不能达到 target，需要全删
                    cost += f
                elif f > target:
                    # 削减到 target
                    cost += f - target
                # f == target：不需要操作
            best = min(best, cost)
        
        return best
```

### 方法二：前缀和优化（O(n)）

```python
from collections import Counter

class Solution:
    def minimumOperations(self, s: str) -> int:
        freq = sorted(Counter(s).values())
        n = len(freq)
        
        if n == 0:
            return 0
        
        # 前缀和：prefix[i] = freq[0] + ... + freq[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + freq[i]
        
        total = prefix[n]
        best = total  # 全删代价
        
        # 对于目标频率 target = freq[i]：
        # - freq[0..i-1] 全删（因为都 < target）
        # - freq[i..n-1] 削减到 target
        for i in range(n):
            target = freq[i]
            # 前 i 个字母全删
            cost_delete = prefix[i]
            # 后 n-i 个字母削减到 target
            cost_trim = (prefix[n] - prefix[i]) - target * (n - i)
            best = min(best, cost_delete + cost_trim)
            
            # 也考虑 target = freq[i] - 1（让第 i 个字母也被处理）
            if target - 1 >= 0:
                t2 = target - 1
                # 前 i+1 个字母全删（freq[0..i] 都 <= target < t2 不对）
                # 实际上 freq[i] = target，target-1 < target，所以第 i 个字母也需全删
                cost_del2 = prefix[i + 1]
                cost_trim2 = (prefix[n] - prefix[i + 1]) - t2 * (n - i - 1) if n - i - 1 > 0 else 0
                best = min(best, cost_del2 + cost_trim2)
        
        return best
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(26 * 26)，字母种数最多 26，候选目标频率最多 52 个
- 空间复杂度：O(26)

**方法二：**
- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(n)

## 关键点总结

1. 只能删除字符，不能增加，因此目标频率只能是现有频率中的某个值或者 0。
2. 对于低于目标频率的字母，只能全删（无法增加）。
3. 枚举每种可能的目标频率（包括 `freq[i]` 和 `freq[i]-1`），取最小代价。

## 易错点

1. 目标频率为 0 时，代价是删除所有字符（极端情况）。
2. 目标频率必须使得所有保留的字母都能达到该频率（只能削减，不能增加）。
3. 注意 `freq[i] - 1` 也要考虑，因为可能让一部分字母恰好被全删。
