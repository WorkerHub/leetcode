## 题目描述

你有一块巧克力条，它由一些小块组成，每个小块都有它对应的甜度 `sweetness[i]`。

你打算和 `k` 个朋友一起分享这块巧克力，所以你需要将巧克力分成 `k + 1` 块。每一块都由一些连续的小块组成。

为了公平起见，你将会吃总甜度最小的一块，并想要最大化这个最小值。

返回你能得到的最大总甜度。

示例 1：
```
输入：sweetness = [1,2,3,4,5,6,7,8,9], k = 5
输出：6
解释：你可以把巧克力分成 [1,2,3], [4,5], [6], [7], [8], [9]。
```

示例 2：
```
输入：sweetness = [5,6,7,8,9,1,2,3,4], k = 8
输出：1
解释：只有一种办法可以把巧克力分成 9 块。
```

示例 3：
```
输入：sweetness = [1,2,2,1,2,2,1,2,2], k = 2
输出：5
解释：你可以把巧克力分成 [1,2,2], [1,2,2], [1,2,2]。
```

提示：
- `0 <= k < sweetness.length <= 10^4`
- `1 <= sweetness[i] <= 10^5`

## 解题思路

这道题是经典的"最大化最小值"问题，使用二分查找来解决。

核心思路：
1. 如果我们能将巧克力分成 k+1 块，每块甜度至少为 x，那么对于任何小于 x 的值 y，我们也一定能做到
2. 这说明答案具有单调性，可以用二分查找

二分搜索的范围：
- 左边界：数组中的最小值（最坏情况下只能拿到一块）
- 右边界：数组总和除以 k+1（平均分配）

判断条件：
- 给定一个甜度值 mid，贪心地从左到右切分
- 每当累积和 >= mid 时，就切一刀
- 如果能切出至少 k+1 块，说明 mid 可行

## Python 代码实现

### 方法一：二分查找 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maximizeSweetness(self, sweetness: List[int], k: int) -> int:
        """
        使用二分查找寻找最大的最小甜度
        
        Args:
            sweetness: 每块的甜度数组
            k: 朋友的数量
            
        Returns:
            能得到的最大总甜度
        """
        # 定义二分查找的范围
        left = min(sweetness)  # 最小可能：只拿到最小的一块
        right = sum(sweetness) // (k + 1)  # 最大可能：平均分配
        
        while left < right:
            # 注意：这里用 right = mid，所以 mid 要向上取整
            mid = (left + right + 1) // 2
            
            # 判断是否能分出至少 k+1 块，每块甜度至少为 mid
            if self._canDivide(sweetness, k + 1, mid):
                # 可以做到，尝试更大的值
                left = mid
            else:
                # 做不到，降低要求
                right = mid - 1
        
        return left
    
    def _canDivide(self, sweetness: List[int], pieces: int, minSweet: int) -> bool:
        """
        判断能否分成 pieces 块，每块甜度至少为 minSweet
        
        Args:
            sweetness: 甜度数组
            pieces: 需要的块数
            minSweet: 最小甜度要求
            
        Returns:
            是否可行
        """
        count = 0  # 已经分出的块数
        current_sum = 0  # 当前块的甜度和
        
        for sweet in sweetness:
            current_sum += sweet
            
            # 如果当前块达到要求，就切一刀
            if current_sum >= minSweet:
                count += 1
                current_sum = 0
                
                # 提前返回优化
                if count >= pieces:
                    return True
        
        return count >= pieces
```

### 方法二：更清晰的写法

```python
from typing import List

class Solution:
    def maximizeSweetness(self, sweetness: List[int], k: int) -> int:
        """
        二分查找的另一种写法
        """
        def can_divide(min_sweetness: int) -> bool:
            """检查能否分成 k+1 块，每块至少 min_sweetness"""
            chunks = 0
            current = 0
            
            for s in sweetness:
                current += s
                if current >= min_sweetness:
                    chunks += 1
                    current = 0
            
            return chunks >= k + 1
        
        # 二分查找
        left, right = min(sweetness), sum(sweetness) // (k + 1)
        result = left
        
        while left <= right:
            mid = (left + right) // 2
            
            if can_divide(mid):
                result = mid
                left = mid + 1  # 尝试更大的值
            else:
                right = mid - 1  # 降低要求
        
        return result
```

### 方法三：使用 bisect 库

```python
from typing import List

class Solution:
    def maximizeSweetness(self, sweetness: List[int], k: int) -> int:
        """
        利用 Python 的 bisect 库简化二分查找
        """
        def can_divide(min_sweetness: int) -> bool:
            chunks = 0
            current = 0
            for s in sweetness:
                current += s
                if current >= min_sweetness:
                    chunks += 1
                    current = 0
            return chunks >= k + 1
        
        # 找到最大的满足条件的值
        left = min(sweetness)
        right = sum(sweetness) // (k + 1) + 1
        
        # 二分查找边界
        while left < right:
            mid = (left + right + 1) // 2
            if can_divide(mid):
                left = mid
            else:
                right = mid - 1
        
        return left
```

### 方法四：暴力 DP（不推荐，会超时）

```python
from typing import List

class Solution:
    def maximizeSweetness(self, sweetness: List[int], k: int) -> int:
        """
        动态规划方法（仅用于理解，会超时）
        dp[i][j] 表示前 i 块分成 j 份时，最小块的最大甜度
        """
        n = len(sweetness)
        if k >= n:
            return 0
        
        # 前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + sweetness[i]
        
        # dp[i][j] 表示前 i 块分成 j 份的最大最小值
        dp = [[0] * (k + 2) for _ in range(n + 1)]
        
        for i in range(1, n + 1):
            dp[i][1] = prefix[i]
        
        for i in range(2, n + 1):
            for j in range(2, min(i, k + 2) + 1):
                for p in range(j - 1, i):
                    # 在位置 p 切一刀
                    last_piece = prefix[i] - prefix[p]
                    dp[i][j] = max(dp[i][j], min(dp[p][j-1], last_piece))
        
        return dp[n][k + 1]
```

## 复杂度分析

**方法一和方法二（推荐）：**
- 时间复杂度：O(n × log(sum))，其中 n 是数组长度，sum 是数组总和
  - 二分查找：O(log(sum / (k+1)))
  - 每次判断：O(n)
- 空间复杂度：O(1)

**方法四（DP）：**
- 时间复杂度：O(n² × k)
- 空间复杂度：O(n × k)

## 关键点总结

1. 识别"最大化最小值"问题 → 使用二分查找
2. 二分的本质：寻找满足条件的最大值
3. 贪心判断：从左到右切分，每当累积和达到要求就切一刀
4. 注意二分查找的边界条件和中点计算方式
5. 优化：提前返回，避免不必要的计算

## 易错点

1. 二分查找的边界设置错误
2. 中点计算方式错误：应该用 `(left + right + 1) // 2` 避免死循环
3. 判断函数逻辑错误：忘记重置 current_sum
4. 右边界设置过大：应该是 `sum / (k+1)` 而不是 `sum`
5. 没有考虑 k = 0 的情况（只需要分成 1 块）
