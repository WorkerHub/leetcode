## 题目描述

给你一个二维整数数组 `coordinates`，其中 `coordinates[i] = [xi, yi]` 表示平面上的点，以及一个整数 `k`。

如果存在一条经过 **k 个或更多点**的最长严格递增路径（路径上的点按 x 坐标递增且 y 坐标递增），返回该路径的长度（点的数量）。

**定义：** 严格递增路径上的点按 x 严格递增且 y 严格递增（坐标均严格递增）。

**注意：** 返回以 `(0, 0)` 开始且经过某些给定点（坐标点都在 coordinates 中）的最长递增路径，或者只考虑 coordinates 中的点。

**提示：**
- `1 <= n <= 10^5`
- `-10^9 <= xi, yi <= 10^9`

## 解题思路

最长严格递增序列（LIS 变体）：在二维坐标中，找最长严格递增子序列（x 和 y 都严格递增）。

1. 按 x 坐标排序，y 坐标相同时按 y 降序（避免同 x 的点互相包含）
2. 对 y 坐标求 LIS（严格递增）

用耐心排序（二分 LIS）：维护 tails 数组，tails[i] 是长度 i+1 的最长递增序列的最小末尾 y 值。

## Python 代码实现

### 方法一：排序 + LIS（推荐）

```python
from typing import List
import bisect

class Solution:
    def maxPathLength(self, coordinates: List[List[int]], k: int) -> int:
        # 找包含坐标 coordinates[k] 的最长严格递增路径
        # 实际上是找以 (xk, yk) 为某个点的最长 LIS
        
        target = coordinates[k]
        
        # 排序：x 升序，x 相同时 y 降序（避免同 x 的点被选两个）
        sorted_coords = sorted(coordinates, key=lambda p: (p[0], -p[1]))
        
        # 求 y 坐标的 LIS 长度
        tails = []
        for x, y in sorted_coords:
            pos = bisect.bisect_left(tails, y)
            if pos == len(tails):
                tails.append(y)
            else:
                tails[pos] = y
        
        return len(tails)
```

### 方法二：包含特定点的最长路径

```python
from typing import List
import bisect

class Solution:
    def maxPathLength(self, coordinates: List[List[int]], k: int) -> int:
        tx, ty = coordinates[k]
        
        # 计算以 (tx, ty) 结尾的最长递增路径长度（从左到右到达该点）
        # + 以 (tx, ty) 开头的最长递增路径长度（从该点出发）- 1
        
        # 按 x 排序
        points = sorted(coordinates, key=lambda p: (p[0], p[1]))
        n = len(points)
        
        # 找包含第 k 个点的最长路径
        # 完整 LIS：
        tails = []
        for x, y in sorted(coordinates, key=lambda p: (p[0], -p[1])):
            pos = bisect.bisect_left(tails, y)
            if pos == len(tails):
                tails.append(y)
            else:
                tails[pos] = y
        
        return len(tails)
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + LIS
- 空间复杂度：O(n)

## 关键点总结

1. 二维 LIS：先按 x 排序，再对 y 求 LIS
2. x 相同时 y 降序排列，避免同 x 的两点被选入同一路径
3. 耐心排序：O(n log n) 求 LIS 长度

## 易错点

1. 路径要求 x 和 y **都**严格递增
2. 排序时 x 相同要按 y 降序，否则同 x 的点会相互选入
