## 题目描述

实现支持下列接口的「快照数组」- SnapshotArray：

- `SnapshotArray(int length)` - 初始化一个与指定长度相等的类数组的数据结构。初始时，每个元素都等于 0。
- `void set(index, val)` - 会将指定索引 index 处的元素设置为 val。
- `int snap()` - 获取该数组的快照，并返回快照的编号 snap_id（快照号是调用 snap() 的总次数减去 1）。
- `int get(index, snap_id)` - 根据指定的 snap_id 选择快照，并返回该快照指定索引 index 的值。

**示例：**
```
输入：["SnapshotArray","set","snap","set","get"]
     [[3],[0,5],[],[0,6],[0,0]]
输出：[null,null,0,null,5]
解释：
SnapshotArray snapshotArr = new SnapshotArray(3);
snapshotArr.set(0,5);  // 令 array[0] = 5
snapshotArr.snap();    // 获取快照，返回 snap_id = 0
snapshotArr.set(0,6);
snapshotArr.get(0,0);  // 获取 snap_id = 0 的快照中 array[0] 的值，返回 5
```

**提示：**
- 1 <= length <= 50000
- 最多进行 50000 次 set，snap 和 get 调用
- 0 <= index < length
- 0 <= snap_id < (调用 snap() 的总次数)
- 0 <= val <= 10^9

## 解题思路

这道题需要实现一个支持快照的数组，关键是如何高效存储历史版本。

**方案对比：**

1. **朴素方法**（不推荐）：
   - 每次 snap() 都复制整个数组
   - 空间复杂度：O(length × snap次数)
   - 会超时和超内存

2. **优化方法**（推荐）：
   - 只记录每次 set 操作的变化
   - 使用字典或列表记录每个位置的修改历史
   - 对于每个索引，维护 (snap_id, value) 对
   - get 时使用二分查找找到对应版本的值

**核心思想：**

1. **数据结构设计**：
   - `history[index]` 存储索引 index 的修改历史
   - 历史记录格式：[(snap_id, value), ...]
   - 按 snap_id 有序存储

2. **set 操作**：
   - 记录当前快照版本下的修改
   - 如果同一快照版本多次修改，更新最后一次的值

3. **snap 操作**：
   - 只需递增快照版本号
   - 不需要复制数组

4. **get 操作**：
   - 在 history[index] 中二分查找 <= snap_id 的最大版本
   - 如果找不到，返回初始值 0

## Python 代码实现

### 方法一：使用字典 + 二分查找 ⭐

```python
import bisect
from typing import List

class SnapshotArray:
    def __init__(self, length: int):
        """
        初始化数组
        时间复杂度：O(length)
        """
        # 每个索引维护一个修改历史列表 [(snap_id, value)]
        self.history = [[] for _ in range(length)]
        # 当前快照版本号
        self.snap_id = 0
    
    def set(self, index: int, val: int) -> None:
        """
        设置值，记录在当前快照版本
        时间复杂度：O(1)
        """
        h = self.history[index]
        # 如果当前快照版本已经有修改，更新值
        if h and h[-1][0] == self.snap_id:
            h[-1] = (self.snap_id, val)
        else:
            # 否则添加新记录
            h.append((self.snap_id, val))
    
    def snap(self) -> int:
        """
        创建快照
        时间复杂度：O(1)
        """
        self.snap_id += 1
        return self.snap_id - 1
    
    def get(self, index: int, snap_id: int) -> int:
        """
        获取指定快照版本的值
        时间复杂度：O(log S)，S 为该索引的修改次数
        """
        h = self.history[index]
        
        # 二分查找 <= snap_id 的最大版本
        # 使用 bisect_right 找到第一个大于 snap_id 的位置
        pos = bisect.bisect_right(h, (snap_id, float('inf')))
        
        # 如果 pos == 0，说明没有 <= snap_id 的记录，返回初始值 0
        if pos == 0:
            return 0
        
        # 返回找到的版本的值
        return h[pos - 1][1]
```

### 方法二：手写二分查找

```python
class SnapshotArray:
    def __init__(self, length: int):
        self.history = [[(0, 0)] for _ in range(length)]  # 初始化为版本0值为0
        self.snap_id = 0
    
    def set(self, index: int, val: int) -> None:
        h = self.history[index]
        if h[-1][0] == self.snap_id:
            h[-1] = (self.snap_id, val)
        else:
            h.append((self.snap_id, val))
    
    def snap(self) -> int:
        self.snap_id += 1
        return self.snap_id - 1
    
    def get(self, index: int, snap_id: int) -> int:
        """手写二分查找"""
        h = self.history[index]
        left, right = 0, len(h) - 1
        result = 0
        
        # 找到 <= snap_id 的最大版本
        while left <= right:
            mid = (left + right) // 2
            if h[mid][0] <= snap_id:
                result = h[mid][1]
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```

### 方法三：使用字典（空间换时间）

```python
class SnapshotArray:
    def __init__(self, length: int):
        """使用字典存储，每个索引的每个版本都有记录"""
        self.array = {}  # {(index, snap_id): value}
        self.snap_id = 0
        self.current = {}  # {index: value} 当前版本的值
    
    def set(self, index: int, val: int) -> None:
        self.current[index] = val
    
    def snap(self) -> int:
        # 保存当前版本的所有修改
        for index, val in self.current.items():
            self.array[(index, self.snap_id)] = val
        self.current.clear()
        self.snap_id += 1
        return self.snap_id - 1
    
    def get(self, index: int, snap_id: int) -> int:
        # 从 snap_id 向前查找最近的修改
        for sid in range(snap_id, -1, -1):
            if (index, sid) in self.array:
                return self.array[(index, sid)]
        return 0
```

### 方法四：优化的列表版本

```python
class SnapshotArray:
    def __init__(self, length: int):
        # 每个位置存储 {snap_id: value}
        self.data = [{0: 0} for _ in range(length)]
        self.snap_id = 0
    
    def set(self, index: int, val: int) -> None:
        self.data[index][self.snap_id] = val
    
    def snap(self) -> int:
        self.snap_id += 1
        return self.snap_id - 1
    
    def get(self, index: int, snap_id: int) -> int:
        # 从 snap_id 向前找最近的记录
        d = self.data[index]
        while snap_id >= 0:
            if snap_id in d:
                return d[snap_id]
            snap_id -= 1
        return 0
```

## 复杂度分析

**方法一（推荐）：**
- 初始化：O(length)
- set：O(1) 均摊
- snap：O(1)
- get：O(log S)，S 为该索引的修改次数
- 空间复杂度：O(S × length)，S 为平均修改次数

**方法三（字典）：**
- get：O(snap_id)，最坏情况需要遍历所有版本
- 不推荐，查询效率低

## 关键点总结

1. **惰性快照**：不在 snap 时复制数组，而是记录修改
2. **版本控制**：每个索引维护修改历史
3. **二分查找**：在有序的版本历史中快速查找
4. **空间优化**：只存储变化，不存储完整数组
5. **同版本合并**：同一快照版本多次修改只保留最后一次

## 易错点

1. **初始值处理**：
   - get 查找不到时应返回 0
   - 可以在初始化时添加 (0, 0)

2. **同版本多次 set**：
   - 需要更新而不是追加
   - 检查最后一条记录的 snap_id

3. **二分查找边界**：
   - 找 <= snap_id 的最大版本
   - 注意 bisect_right 的用法

4. **snap_id 递增**：
   - snap 返回的是当前 ID，然后 +1
   - 不要搞反

5. **索引越界**：
   - 题目保证了 index 和 snap_id 合法
