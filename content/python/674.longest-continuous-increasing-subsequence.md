## 题目描述

给定一个未经排序的整数数组 nums，找到最长且连续递增的子序列，并返回该序列的长度。

**连续递增的子序列** 是指子序列中的元素在原数组中是连续的。

**示例 1：**
```
输入：nums = [1,3,5,4,7]
输出：3
解释：最长连续递增序列是 [1,3,5], 长度为3。
尽管 [1,3,5,7] 也是递增序列, 但它不是连续的，因为 5 和 7 在原数组中被 4 分隔。
```

**示例 2：**
```
输入：nums = [2,2,2,2,2]
输出：1
解释：最长连续递增序列是 [2], 长度为1。
```

**提示：**
- 1 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9

## 解题思路

这是一道简单的一次遍历题，比普通的最长递增子序列(LIS)简单很多。

**核心思想：**
遍历数组，维护当前连续递增序列的长度。

**算法流程：**
1. 初始化当前长度和最大长度都为1
2. 从第二个元素开始遍历
3. 如果当前元素大于前一个元素，长度+1
4. 否则，重置当前长度为1
5. 更新最大长度

## Python 代码实现

### 方法一：一次遍历（推荐）⭐

```python
from typing import List

class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        max_len = 1
        current_len = 1
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                current_len += 1
                max_len = max(max_len, current_len)
            else:
                current_len = 1
        
        return max_len
```

### 方法二：滑动窗口

```python
class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        
        max_len = 1
        start = 0
        
        for end in range(1, n):
            # 如果不连续递增，移动起点
            if nums[end] <= nums[end - 1]:
                start = end
            
            # 更新最大长度
            max_len = max(max_len, end - start + 1)
        
        return max_len
```

### 方法三：动态规划

```python
class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        n = len(nums)
        dp = [1] * n  # dp[i]: 以nums[i]结尾的最长连续递增子序列长度
        
        for i in range(1, n):
            if nums[i] > nums[i - 1]:
                dp[i] = dp[i - 1] + 1
        
        return max(dp)
```

### 方法四：简洁写法

```python
class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        max_len = current = 1
        
        for i in range(1, len(nums)):
            current = current + 1 if nums[i] > nums[i - 1] else 1
            max_len = max(max_len, current)
        
        return max_len
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：
  - 方法一、二、四：O(1)
  - 方法三：O(n)，使用了dp数组

## 图解示例

以 nums = [1,3,5,4,7] 为例：

```
索引:     0  1  2  3  4
nums:    [1, 3, 5, 4, 7]
current: [1, 2, 3, 1, 2]
max_len:  1  2  3  3  3

遍历过程：
i=0: current=1, max_len=1

i=1: 3>1 ✓
     current=2, max_len=2

i=2: 5>3 ✓
     current=3, max_len=3

i=3: 4<5 ✗
     current=1, max_len=3

i=4: 7>4 ✓
     current=2, max_len=3

返回 max_len=3
```

## 关键点总结

1. **连续性**：必须是原数组中连续的元素
2. **一次遍历**：只需要从左到右扫描一次
3. **状态重置**：遇到非递增元素时重置当前长度
4. **实时更新**：每次递增都要更新最大长度
5. **边界情况**：空数组、单元素、全部相同等

## 易错点

1. **初始值**：max_len 和 current 都应初始化为1
2. **更新时机**：应该在每次比较后都更新max_len
3. **严格递增**：是 >，不是 >=
4. **空数组处理**：需要特判
5. **单元素**：单个元素长度为1，不是0
