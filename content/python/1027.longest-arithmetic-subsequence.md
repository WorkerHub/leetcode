## 题目描述

给你一个整数数组 `nums`，返回 `nums` 中最长等差数列的长度。

回忆一下，`nums` 的子序列是一个列表 `nums[i1], nums[i2], ..., nums[ik]`，且 `0 <= i1 < i2 < ... < ik <= nums.length - 1`。并且如果 `seq[i+1] - seq[i]`（`0 <= i < seq.length - 1`）的值都相同，那么序列 `seq` 是等差的。

**示例 1：**
```
输入：nums = [3,6,9,12]
输出：4
解释：整个数组是公差为 3 的等差数列。
```

**示例 2：**
```
输入：nums = [9,4,7,2,10]
输出：3
解释：最长的等差子序列是 [4,7,10]。
```

**示例 3：**
```
输入：nums = [20,1,15,3,10,5,8]
输出：4
解释：最长的等差子序列是 [20,15,10,5]。
```

**提示：**
- `2 <= nums.length <= 1000`
- `0 <= nums[i] <= 500`

## 解题思路

这道题是一道经典的动态规划问题，关键在于如何定义状态和状态转移。

**核心思想：**
1. 对于等差数列，关键信息是公差（difference）
2. 我们需要记录以每个位置结尾、不同公差的等差子序列长度
3. 使用哈希表来存储 `(位置, 公差) -> 长度` 的映射关系

**算法流程：**
1. 创建一个数组 `dp`，其中 `dp[i]` 是一个字典
2. `dp[i][d]` 表示以 `nums[i]` 结尾、公差为 `d` 的最长等差子序列长度
3. 对于每个位置 `i`，遍历之前的所有位置 `j`（`j < i`）
4. 计算公差 `d = nums[i] - nums[j]`
5. 如果 `dp[j]` 中存在公差 `d`，则 `dp[i][d] = dp[j][d] + 1`
6. 否则 `dp[i][d] = 2`（当前两个元素形成长度为 2 的等差数列）
7. 记录所有状态中的最大值

**关键观察：**
- 任意两个数都可以构成长度为 2 的等差数列
- 公差可以是负数、零或正数
- 使用哈希表可以高效存储和查询不同公差的状态

## Python 代码实现

### 方法一：动态规划 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def longestArithSeqLength(self, nums: List[int]) -> int:
        """
        使用动态规划求解最长等差子序列
        dp[i][d] 表示以 nums[i] 结尾、公差为 d 的最长等差子序列长度
        """
        n = len(nums)
        # dp[i] 是一个字典，存储以 nums[i] 结尾的不同公差对应的长度
        dp = [defaultdict(int) for _ in range(n)]
        max_length = 2  # 至少有两个元素可以组成等差数列
        
        for i in range(n):
            for j in range(i):
                # 计算公差
                diff = nums[i] - nums[j]
                
                # 如果 dp[j][diff] 存在，说明之前已经有这个公差的序列
                # 否则当前两个元素形成长度为 2 的序列
                if diff in dp[j]:
                    dp[i][diff] = dp[j][diff] + 1
                else:
                    dp[i][diff] = 2
                
                # 更新最大长度
                max_length = max(max_length, dp[i][diff])
        
        return max_length
```

**优化说明：**
- 时间复杂度：O(n²)，需要遍历所有数对
- 空间复杂度：O(n²)，最坏情况下每对元素都有不同的公差
- 使用 `defaultdict` 简化代码，避免判断键是否存在

### 方法二：简化版（直接使用字典）

```python
from typing import List

class Solution:
    def longestArithSeqLength(self, nums: List[int]) -> int:
        """
        不使用 defaultdict 的版本
        """
        n = len(nums)
        dp = [{} for _ in range(n)]
        max_length = 2
        
        for i in range(n):
            for j in range(i):
                diff = nums[i] - nums[j]
                
                # 显式检查键是否存在
                if diff in dp[j]:
                    dp[i][diff] = dp[j][diff] + 1
                else:
                    dp[i][diff] = 2
                
                max_length = max(max_length, dp[i][diff])
        
        return max_length
```

### 方法三：使用单一哈希表优化空间（进阶）

```python
from typing import List

class Solution:
    def longestArithSeqLength(self, nums: List[int]) -> int:
        """
        使用 (索引, 公差) 作为键的单一哈希表
        """
        # dp[(i, d)] 表示以索引 i 结尾、公差为 d 的最长等差子序列长度
        dp = {}
        max_length = 2
        
        for i in range(len(nums)):
            for j in range(i):
                diff = nums[i] - nums[j]
                
                # 检查是否可以延续从 j 结尾、公差为 diff 的序列
                if (j, diff) in dp:
                    dp[(i, diff)] = dp[(j, diff)] + 1
                else:
                    dp[(i, diff)] = 2
                
                max_length = max(max_length, dp[(i, diff)])
        
        return max_length
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度：** O(n²)
  - 外层循环遍历 n 个位置
  - 内层循环对于每个位置 i，遍历前面的 i 个位置
  - 总共约 n²/2 次操作
  - 哈希表的查找和插入是 O(1)

- **空间复杂度：** O(n²)
  - 最坏情况下，每对不同的数都会产生不同的公差
  - n 个位置，每个位置最多存储 n 个不同的公差
  - 实际使用空间通常小于 O(n²)

**方法三：**
- **时间复杂度：** O(n²)，与方法一相同
- **空间复杂度：** O(n²)，使用单一字典存储所有状态

## 图解示例

以 `nums = [20,1,15,3,10,5,8]` 为例：

```
索引:  0   1   2   3   4   5   6
值:   20   1  15   3  10   5   8

处理过程：
i=2, j=0: diff = 15-20 = -5, dp[2][-5] = 2
i=3, j=1: diff = 3-1 = 2, dp[3][2] = 2
i=4, j=0: diff = 10-20 = -10, dp[4][-10] = 2
i=4, j=2: diff = 10-15 = -5, dp[4][-5] = dp[2][-5] + 1 = 3
i=5, j=0: diff = 5-20 = -15, dp[5][-15] = 2
i=5, j=2: diff = 5-15 = -10, dp[5][-10] = 2
i=5, j=4: diff = 5-10 = -5, dp[5][-5] = dp[4][-5] + 1 = 4  ⭐

最长等差子序列：[20, 15, 10, 5]，公差 = -5，长度 = 4
```

## 关键点总结

1. **状态定义：** `dp[i][d]` 表示以位置 i 结尾、公差为 d 的最长等差子序列长度
2. **状态转移：** 当前位置可以接在任何之前公差相同的序列后面
3. **哈希表应用：** 使用字典存储不同公差的状态，实现高效查询
4. **初始化：** 任意两个数都能形成长度为 2 的等差数列
5. **公差范围：** 公差可以是 [-500, 500] 范围内的任意整数

## 易错点

1. **忘记初始化长度为 2：** 当 `dp[j]` 中不存在公差 d 时，应该设置为 2 而不是 1
   ```python
   # 错误
   dp[i][diff] = dp[j].get(diff, 1) + 1
   
   # 正确
   dp[i][diff] = dp[j].get(diff, 1) + 1  # 如果不存在则为 1+1=2
   # 或者
   if diff in dp[j]:
       dp[i][diff] = dp[j][diff] + 1
   else:
       dp[i][diff] = 2
   ```

2. **边界条件：** 数组长度至少为 2，任何数组都至少有长度为 2 的等差子序列

3. **公差为 0：** 所有相同的数构成公差为 0 的等差数列，需要正确处理

4. **空间优化陷阱：** 不能简单地用滚动数组优化，因为每个位置都依赖前面所有位置

5. **遍历顺序：** 必须从左到右遍历，确保 `dp[j]` 在使用前已经计算
