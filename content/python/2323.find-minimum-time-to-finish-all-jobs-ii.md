## 题目描述

给你两个下标从 **0** 开始的整数数组 `jobs` 和 `workers`，长度均为 `n`。`jobs[i]` 是第 `i` 份工作需要的时间，`workers[j]` 是第 `j` 名工人每天可以完成的工作量（即工人的生产力）。

每份工作应由**恰好一名**工人完成。完成第 `i` 份工作需要 `ceil(jobs[i] / workers[j])` 天。

返回所有工作中最少需要的**最大天数**（即完成所有工作所需的天数的最大值的最小可能值）。

**示例 1：**
```
输入：jobs = [5,2,4], workers = [1,7,5]
输出：2
解释：将 jobs[2]=4 分配给 workers[1]=7，需要 ceil(4/7)=1 天；
     jobs[0]=5 分配给 workers[2]=5，需要 ceil(5/5)=1 天；
     jobs[1]=2 分配给 workers[0]=1，需要 ceil(2/1)=2 天；最大值为 2。
```

**提示：**
- `n == jobs.length == workers.length`
- `1 <= n <= 10^5`
- `1 <= jobs[i], workers[j] <= 10^9`

## 解题思路

**贪心：将最大的工作分配给最强的工人。**

排序后，将 `jobs[n-1]` 分配给 `workers[n-1]`，`jobs[n-2]` 分配给 `workers[n-2]`，以此类推（大工作配大工人），可以最小化最大天数。

**证明：**
若存在交叉分配（大工作配小工人，小工作配大工人），交换后不会变差（可以用交换论证法证明）。

## 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List
import math

class Solution:
    def minimumTime(self, jobs: List[int], workers: List[int]) -> int:
        jobs.sort()
        workers.sort()
        
        ans = 0
        for j, w in zip(jobs, workers):
            # 完成工作 j 需要 ceil(j/w) 天
            days = math.ceil(j / w)
            ans = max(ans, days)
        
        return ans
```

### 方法二：手动向上取整

```python
from typing import List

class Solution:
    def minimumTime(self, jobs: List[int], workers: List[int]) -> int:
        jobs.sort()
        workers.sort()
        
        ans = 0
        for j, w in zip(jobs, workers):
            # 向上取整：(j + w - 1) // w
            days = (j + w - 1) // w
            ans = max(ans, days)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 贪心 | O(n log n) | O(1) |

## 关键点总结

1. 贪心策略：大工作配大工人，最优匹配。
2. 向上取整可用 `math.ceil` 或 `(a + b - 1) // b`。
3. 对 jobs 和 workers 分别排序后，同索引配对。

## 易错点

- 向上取整用 `math.ceil(j/w)` 时，如果 j 和 w 都是整数，Python 3 的除法会产生浮点数，`ceil` 一般没问题；但为了精确，推荐用整数算法 `(j + w - 1) // w`。
