## 题目描述

给你一个无向图，该图由 `n` 个节点（编号从 `1` 到 `n`）和 `edges` 数组组成，其中 `edges[i] = [u_i, v_i]` 表示节点 `u_i` 和 `v_i` 之间有一条边（可能有重复边）。

同时给你一个整数数组 `queries`，对于第 `j` 次查询，返回满足下述条件的**点对**数目：
- 对于点对 `(a, b)`，满足 `a < b`
- 与 `a` **或** `b` 相连的边数**严格大于** `queries[j]`

**注意**：两个节点之间可能有多条边，多条边也都算作与对应节点相连。

返回一个数组 `answers`，其中 `answers[j]` 是第 `j` 次查询的结果。

**提示：**
- `1 <= n <= 2 * 10^4`
- `1 <= edges.length <= 10^5`

## 解题思路

对于点对 `(a, b)`，与 `a` 或 `b` 相连的边数 = `deg[a] + deg[b] - cnt(a, b)`，其中 `cnt(a, b)` 是 `a` 和 `b` 之间的重复边数（被计数两次，需减去）。

**双指针**：
1. 对所有节点的度数排序
2. 对每个查询，用双指针统计 `deg[a] + deg[b] > queries[j]` 的点对数（过多了，需要减去因重复边被误算的）
3. 对重复边中 `deg[a] + deg[b] > queries[j]` 但 `deg[a] + deg[b] - cnt(a,b) <= queries[j]` 的点对，减去多算的

## 代码实现

### 方法一：双指针 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, n: int, edges: List[List[int]], queries: List[int]) -> List[int]:
        # 统计每个节点的度数
        deg = [0] * (n + 1)
        # 统计每条重复边的数量
        edge_cnt = defaultdict(int)
        
        for u, v in edges:
            deg[u] += 1
            deg[v] += 1
            key = (min(u, v), max(u, v))
            edge_cnt[key] += 1
        
        # 排序后的度数数组
        sorted_deg = sorted(deg[1:n + 1])
        
        def count_pairs_greater(threshold):
            """统计 sorted_deg[i] + sorted_deg[j] > threshold 的点对数 (i < j)"""
            count = 0
            left, right = 0, n - 1
            while left < right:
                if sorted_deg[left] + sorted_deg[right] > threshold:
                    count += right - left  # left 与 left+1..right 都满足
                    right -= 1
                else:
                    left += 1
            return count
        
        ans = []
        for q in queries:
            # 先统计 deg[a] + deg[b] > q 的点对
            total = count_pairs_greater(q)
            
            # 减去被多算的（因重复边）
            for (u, v), cnt in edge_cnt.items():
                if deg[u] + deg[v] > q and deg[u] + deg[v] - cnt <= q:
                    total -= 1
            
            ans.append(total)
        
        return ans
```

### 方法二：对查询排序优化

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, n: int, edges: List[List[int]], queries: List[int]) -> List[int]:
        deg = [0] * (n + 1)
        edge_cnt = defaultdict(int)
        
        for u, v in edges:
            deg[u] += 1
            deg[v] += 1
            edge_cnt[(min(u, v), max(u, v))] += 1
        
        sorted_deg = sorted(deg[1:n + 1])
        
        import bisect
        
        # 预计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + sorted_deg[i]
        
        ans = []
        for q in queries:
            total = 0
            left, right = 0, n - 1
            while left < right:
                if sorted_deg[left] + sorted_deg[right] > q:
                    total += right - left
                    right -= 1
                else:
                    left += 1
            
            for (u, v), cnt in edge_cnt.items():
                if deg[u] + deg[v] > q >= deg[u] + deg[v] - cnt:
                    total -= 1
            
            ans.append(total)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O((n + |edges|) * |queries|)
- **空间复杂度**：O(n + |edges|)

## 关键点总结

1. 点对与 a 或 b 相连的边数 = `deg[a] + deg[b] - cnt(a,b)`（重复边减一次）
2. 先用双指针统计 `deg[a] + deg[b] > q` 的点对，再修正重复边的影响
3. 排序度数后双指针效率高

## 易错点

- 重复边需要减去 `cnt(a,b)` 而不是 1
- 修正时的条件：原来满足（`> q`）但减去重边后不满足（`<= q`）的要减去
