## 题目描述

你的任务是用最少次数的操作将初始全 0 数组变成 `nums`。

每次操作可以：
1. 将某个元素加 1
2. 将整个数组所有元素乘以 2

求最少操作次数。

**示例 1：**
```
输入：nums = [1,5]
输出：5
解释：[0,0] +1 -> [0,1] *2 -> [0,2] +1 -> [0,3] *2 -> [0,6] +1... 这样不对，应该反向思考。
```

**解题示例（从目标反向）：**
```
[1,5]
/2: [0,2]（5不整除，先-1=4，[0,4]再/2不对...）
```

## 解题思路

### 反向思维 + 位运算

从目标数组**反向操作**：
- 整体除以 2（对应乘以 2 的逆操作）：若所有数都是偶数
- 某个数减 1（对应加 1 的逆操作）：若某个数是奇数

**更直观的方法：** 分析每个数的二进制表示
- 每个数 `nums[i]` 需要 `popcount(nums[i])` 次 "+1" 操作（对应二进制中 1 的个数）
- 乘以 2 的次数 = 所有数中最高位的位置（即 `max(nums).bit_length() - 1`）

**原因：** 乘以 2 相当于左移1位，最大数需要做的左移次数就是总的乘以2次数。

总操作数 = `sum(popcount(x) for x in nums) + (max_bits - 1)`（若 max > 0）。

## 代码实现

### 方法一：位运算分析（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # +1 操作次数 = 所有数的二进制中 1 的总数
        add_ops = sum(bin(x).count('1') for x in nums)
        # *2 操作次数 = 最大数的位长 - 1（即最大数需要左移的次数）
        max_val = max(nums)
        mul_ops = max_val.bit_length() - 1 if max_val > 0 else 0
        return add_ops + mul_ops
```

### 方法二：模拟反向操作

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        ans = 0
        while any(x > 0 for x in nums):
            # 若有奇数，先全部减去奇数部分（"+1" 的逆操作）
            for i in range(len(nums)):
                if nums[i] % 2 == 1:
                    nums[i] -= 1
                    ans += 1
            # 若所有数都是偶数且不全为 0，整体除以 2
            if any(x > 0 for x in nums):
                for i in range(len(nums)):
                    nums[i] //= 2
                ans += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(N * log(max)) | O(1) |
| 方法二 | O(N * log(max)) | O(1) |

## 关键点总结

1. 乘以 2 是全局操作，所有数同时执行，次数由最大数的二进制位长决定
2. 加 1 是单个操作，次数等于每个数二进制中 1 的个数之和
3. 反向思维：从目标倒推到全零数组

## 易错点

- `*2` 操作只算一次（全数组），不是 N 次
- 若所有数都为 0，不需要任何操作
