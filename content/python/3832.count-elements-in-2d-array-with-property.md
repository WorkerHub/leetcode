## 题目描述

给你一个 `m x n` 的二维整数数组 `grid` 和一个整数 `k`，统计满足以下条件的元素对 `(grid[r1][c1], grid[r2][c2])` 的数目：
- `r1 < r2`（在不同行）
- `grid[r1][c1]` 和 `grid[r2][c2]` 之差的绝对值等于 `k`

**示例 1：**

```
输入：grid = [[1, 2, 3], [2, 3, 4]], k = 1
输出：6
解释：满足条件的元素对有：
(1,2), (2,3), (3,4) 各两对来自不同行...
```

**示例 2：**

```
输入：grid = [[1]], k = 1
输出：0
```

**提示：**
- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 100`
- `0 <= k <= 100`

## 解题思路

枚举所有跨行的元素对：
1. 对每对 `(r1, r2)` 满足 `r1 < r2`，枚举 `c1` 和 `c2`。
2. 检查 `|grid[r1][c1] - grid[r2][c2]| == k`。

优化：对每行用哈希表统计频率，两行之间的满足条件对数可以快速计算。

## Python 代码实现

### 方法一：哈希表优化（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countPairs(self, grid: List[List[int]], k: int) -> int:
        m = len(grid)
        count = 0

        # 对每对行 (r1, r2)
        for r1 in range(m):
            for r2 in range(r1 + 1, m):
                cnt1 = Counter(grid[r1])
                cnt2 = Counter(grid[r2])
                for v, c in cnt1.items():
                    # 找 v + k 或 v - k 在第 r2 行中的个数
                    count += c * cnt2[v + k]
                    if k > 0:  # 避免重复计算 k=0 的情况
                        count += c * cnt2[v - k]

        return count
```

### 方法二：暴力枚举

```python
from typing import List

class Solution:
    def countPairs(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        count = 0

        # 枚举所有跨行元素对
        for r1 in range(m):
            for r2 in range(r1 + 1, m):
                for c1 in range(n):
                    for c2 in range(n):
                        if abs(grid[r1][c1] - grid[r2][c2]) == k:
                            count += 1

        return count
```

## 复杂度分析

- 时间复杂度：
  - 方法一：O(m^2 * max_val)，每对行的哈希表查询
  - 方法二：O(m^2 * n^2)，暴力四重循环
- 空间复杂度：O(max_val)（方法一）；O(1)（方法二）

## 关键点总结

1. 跨行限制 `r1 < r2` 是关键约束，不是列约束。
2. 哈希表将行内查询从 O(n) 降到 O(1)。
3. `k = 0` 时 `v + k == v - k`，需避免重复计数。

## 易错点

1. `abs(a - b) == k` 等价于 `a - b == k` 或 `a - b == -k`，即 `b = a + k` 或 `b = a - k`。
2. k = 0 时只计一次（两者相等），避免乘以 2。
3. 注意行下标 r1 < r2，不是任意两行。
