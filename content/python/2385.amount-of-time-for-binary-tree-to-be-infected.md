## 题目描述

给你一棵二叉树（根节点为 `root`）和一个整数 `start`，表示感染从值为 `start` 的节点开始扩散。

每一分钟，感染会从已感染的节点扩散到其所有**未感染**的邻居（父节点、左子节点、右子节点）。

返回整棵树被感染所需要的分钟数。

**示例 1：**
```
输入：root = [1,5,3,null,4,10,6,9,2], start = 3
输出：4
```

**示例 2：**
```
输入：root = [1], start = 1
输出：0
```

**提示：**
- 树中节点数目在范围 `[1, 10^5]` 内
- `1 <= Node.val <= 10^5`
- 每个节点的值互不相同
- `1 <= start <= 10^5`
- `start` 在树中存在

## 解题思路

**方法：DFS 转图 + BFS 扩散**

1. 先将二叉树转换为无向图（用哈希表存储邻接关系）。
2. 从 `start` 节点开始 BFS，统计扩散到所有节点所需的层数。

**方法二：纯 DFS（不建图）**

在 DFS 过程中：
- 计算每个子树的深度。
- 若 `start` 在左子树，则右子树的感染时间 = 右子树深度 + 经过根节点的距离。
- 综合所有子树求最大感染时间。

## 代码实现

### 方法一：建图 + BFS（推荐）

```python
from typing import Optional
from collections import defaultdict, deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        # 建立无向图（邻接表）
        graph = defaultdict(list)
        
        def build_graph(node, parent):
            if not node:
                return
            if parent:
                graph[node.val].append(parent.val)
                graph[parent.val].append(node.val)
            build_graph(node.left, node)
            build_graph(node.right, node)
        
        build_graph(root, None)
        
        # BFS 从 start 扩散
        visited = {start}
        queue = deque([start])
        time = -1  # 初始时刻 start 已感染，时间从 -1 开始
        
        while queue:
            time += 1
            for _ in range(len(queue)):
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
        
        return time
```

### 方法二：DFS 一次遍历

```python
from typing import Optional

class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        self.ans = 0
        
        def dfs(node):
            """
            返回当前子树的深度（正数）。
            如果子树中包含 start，返回负数（绝对值为 start 到该节点的距离）。
            """
            if not node:
                return 0
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            if node.val == start:
                # 当前节点是 start，子树中最大深度就是向下感染时间
                self.ans = max(abs(left), abs(right))
                return -1  # 距离 start 为 1（向上）
            elif left < 0 or right < 0:
                # start 在某个子树中
                dist = abs(left) if left < 0 else abs(right)  # start 到当前节点距离
                other = right if left < 0 else left           # 另一侧子树深度
                # 另一侧感染时间 = dist + other
                self.ans = max(self.ans, dist + other)
                return -(dist + 1)  # 继续向上传递距离
            else:
                # start 不在此子树，返回深度
                return max(left, right) + 1
        
        dfs(root)
        return self.ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 建图+BFS | O(n) | O(n) |
| DFS一次 | O(n) | O(n)（递归栈） |

## 关键点总结

1. 二叉树感染问题：需要向父节点传播，所以需要建无向图或记录父节点。
2. BFS 的层数即为感染时间，初始时间为 -1（因为第 0 分钟 start 已感染）。
3. DFS 方法：用负数区分"含 start 的子树"和"普通子树"，一次遍历求解。

## 易错点

- BFS 初始 `time = -1`，因为 start 节点已感染，不需要花时间。
- DFS 方法中返回负数的绝对值才是距离，要用 `abs()`。
- 建图时需要双向连接（父->子，子->父）。
