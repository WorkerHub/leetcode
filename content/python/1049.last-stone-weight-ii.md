## 题目描述

有一堆石头，用整数数组 `stones` 表示。其中 `stones[i]` 表示第 `i` 块石头的重量。

每一回合，从中选出**任意两块石头**，然后将它们一起粉碎。假设石头的重量分别为 `x` 和 `y`，且 `x <= y`。那么粉碎的结果如下：

- 如果 `x == y`，那么两块石头都会被完全粉碎
- 如果 `x != y`，那么重量为 `x` 的石头将会被完全粉碎，而重量为 `y` 的石头新重量为 `y - x`

最后，**最多只会剩下一块石头**。返回此石头**最小的可能重量**。如果没有石头剩下，就返回 `0`。

**示例 1：**

```
输入：stones = [2,7,4,1,8,1]
输出：1
解释：
组合 2 和 4，得到 2，所以数组转化为 [2,7,1,8,1]，
组合 7 和 8，得到 1，所以数组转化为 [2,1,1,1]，
组合 2 和 1，得到 1，所以数组转化为 [1,1,1]，
组合 1 和 1，得到 0，所以数组转化为 [1]，这就是最优值。
```

**示例 2：**

```
输入：stones = [31,26,33,21,40]
输出：5
```

**提示：**

- `1 <= stones.length <= 30`
- `1 <= stones[i] <= 100`

## 解题思路

这道题乍一看是模拟问题，但实际上是一个经典的**0-1 背包问题**或**子集划分问题**。

**关键观察：**

1. 每次粉碎两块石头，结果是它们的差值，这个过程可以看作是**给石头分配正负号**
2. 假设最后剩余的石头是正的，那么整个过程可以看作：
   - 将石头分为两组，一组为正，一组为负
   - 最终结果 = 正组总和 - 负组总和

**问题转化：**

设石头总重量为 `sum`，正组重量为 `pos`，负组重量为 `neg`，则：
- `pos + neg = sum`
- `pos - neg = result`（我们要最小化这个值）

由上面两式可得：
- `pos = (sum + result) / 2`
- `neg = (sum - result) / 2`

因为 `pos >= neg`（正组至少等于负组），所以：
- `pos >= sum / 2`

**目标：** 找到一个子集，其和尽可能接近但不超过 `sum / 2`，这样 `result = sum - 2 * pos` 最小。

这就是经典的**0-1 背包问题**：在容量为 `sum / 2` 的背包中，尽可能装满石头。

**动态规划思路：**

定义 `dp[i]` 表示**能否凑出重量为 `i` 的子集**（或能凑出的最大重量）。

状态转移：
- 对于每块石头 `stone`：
  - 如果选择这块石头：`dp[i] = dp[i - stone] or True`
  - 如果不选：保持原状态

最终答案：`sum - 2 * max(dp)`，其中 `max(dp)` 是不超过 `sum / 2` 的最大重量。

## Python 代码实现

### 方法一：动态规划（0-1 背包）

```python
from typing import List

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        total = sum(stones)
        target = total // 2
        
        # dp[i] 表示能否凑出重量为 i 的子集
        dp = [False] * (target + 1)
        dp[0] = True  # 重量为 0 总是可以凑出（不选任何石头）
        
        # 遍历每块石头
        for stone in stones:
            # 从后向前遍历，避免重复使用同一块石头
            for i in range(target, stone - 1, -1):
                dp[i] = dp[i] or dp[i - stone]
        
        # 找到不超过 target 的最大重量
        for i in range(target, -1, -1):
            if dp[i]:
                # 一组重量为 i，另一组重量为 total - i
                return total - 2 * i
        
        return 0
```

### 方法二：动态规划（记录最大重量）

```python
from typing import List

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        total = sum(stones)
        target = total // 2
        
        # dp[i] 表示容量为 i 时能凑出的最大重量
        dp = [0] * (target + 1)
        
        for stone in stones:
            # 从后向前遍历
            for i in range(target, stone - 1, -1):
                dp[i] = max(dp[i], dp[i - stone] + stone)
        
        # dp[target] 是不超过 target 的最大重量
        return total - 2 * dp[target]
```

### 方法三：使用集合记录所有可能的和

```python
from typing import List

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        total = sum(stones)
        
        # possible 记录所有可能凑出的重量
        possible = {0}
        
        for stone in stones:
            # 对于每个已有的和，加上当前石头得到新的和
            new_sums = set()
            for s in possible:
                new_sums.add(s + stone)
            possible.update(new_sums)
        
        # 找到最接近 total / 2 的和
        target = total // 2
        for i in range(target, -1, -1):
            if i in possible:
                return total - 2 * i
        
        return 0
```

### 方法四：集合优化写法

```python
from typing import List

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        total = sum(stones)
        
        # 使用集合记录所有可能的和
        dp = {0}
        
        for stone in stones:
            # 使用集合推导式生成新的和
            dp = {s + stone for s in dp} | dp
        
        # 找到最接近但不超过 total / 2 的和
        return min(abs(total - 2 * s) for s in dp)
```

### 方法五：二维 DP（便于理解）

```python
from typing import List

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        n = len(stones)
        total = sum(stones)
        target = total // 2
        
        # dp[i][j] 表示前 i 块石头能否凑出重量 j
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        
        # 初始化：重量为 0 总是可以凑出
        for i in range(n + 1):
            dp[i][0] = True
        
        # 状态转移
        for i in range(1, n + 1):
            stone = stones[i - 1]
            for j in range(target + 1):
                # 不选第 i 块石头
                dp[i][j] = dp[i - 1][j]
                # 选第 i 块石头
                if j >= stone:
                    dp[i][j] = dp[i][j] or dp[i - 1][j - stone]
        
        # 找到不超过 target 的最大重量
        for j in range(target, -1, -1):
            if dp[n][j]:
                return total - 2 * j
        
        return 0
```

## 复杂度分析

### 方法一、二：一维 DP（推荐）
- **时间复杂度：** `O(n * sum / 2)` = `O(n * S)`
  - `n` 是石头数量
  - `S` 是石头总重量
  - 遍历每块石头 `O(n)`，内层遍历 `O(sum / 2)`
- **空间复杂度：** `O(sum / 2)` = `O(S)` - 一维 DP 数组

### 方法三、四：集合记录
- **时间复杂度：** `O(n * 可能和的数量)`
  - 最坏情况下可能和的数量为 `O(sum)`
  - 总时间：`O(n * sum)`
- **空间复杂度：** `O(sum)` - 集合存储所有可能的和

### 方法五：二维 DP
- **时间复杂度：** `O(n * sum / 2)` = `O(n * S)`
- **空间复杂度：** `O(n * sum / 2)` = `O(n * S)` - 二维数组（可优化为一维）

## 关键点总结

1. **问题转化**：石头粉碎问题 → 子集划分问题 → 0-1 背包问题
2. **动态规划**：使用 DP 找到最接近 `sum / 2` 的子集和
3. **空间优化**：二维 DP 可以优化为一维（滚动数组）
4. **倒序遍历**：一维 DP 必须从后向前遍历，避免重复使用
5. **数学关系**：`result = sum - 2 * max_sum`，其中 `max_sum <= sum / 2`

## 易错点

1. **正序遍历导致重复使用**
   ```python
   # 错误：正序遍历会导致同一块石头被使用多次
   for i in range(stone, target + 1):
       dp[i] = dp[i] or dp[i - stone]
   
   # 正确：倒序遍历
   for i in range(target, stone - 1, -1):
       dp[i] = dp[i] or dp[i - stone]
   ```

2. **目标值计算错误**
   ```python
   # 错误：目标是 sum，而不是 sum / 2
   target = total
   
   # 正确：目标是 sum / 2
   target = total // 2
   ```

3. **结果计算错误**
   ```python
   # 错误：直接返回最大和
   return dp[target]
   
   # 正确：返回差值
   return total - 2 * dp[target]
   ```

4. **边界条件遗漏**
   ```python
   # 错误：没有初始化 dp[0] = True
   dp = [False] * (target + 1)
   
   # 正确：初始化 dp[0] = True
   dp = [False] * (target + 1)
   dp[0] = True
   ```

5. **集合更新方式错误**
   ```python
   # 错误：在遍历集合时修改集合
   for s in possible:
       possible.add(s + stone)
   
   # 正确：先生成新集合，再更新
   new_sums = set()
   for s in possible:
       new_sums.add(s + stone)
   possible.update(new_sums)
   ```
