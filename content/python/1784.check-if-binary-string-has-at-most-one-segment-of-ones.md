## 题目描述

给你一个二进制字符串 `s`，该字符串**不含前导零**。

如果 `s` 中**最多**只含有一段连续的 `'1'`，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "1001"
输出：false
解释：1 出现了两段：s[0] 和 s[2..3]
```

**示例 2：**
```
输入：s = "110"
输出：true
```

**提示：**
- `1 <= s.length <= 100`
- `s[i]` 为 `'0'` 或 `'1'`
- `s[0]` 为 `'1'`

## 解题思路

如果字符串中存在"01"子串（即先出现 0 再出现 1），则说明有至少两段连续的 1。

因为字符串不含前导零，所以第一个字符必为 1，如果后续又出现了 1，必然是经过了 0 之后，即存在"01"。

直接检查字符串是否包含 `"01"` 子串即可。

## 代码实现

### 方法一：检查子串（推荐，一行）

```python
class Solution:
    def checkOnesSegment(self, s: str) -> bool:
        # 若存在 "01"，说明 1 在 0 之后又出现，有至少两段 1
        return "01" not in s
```

### 方法二：计数连续段

```python
class Solution:
    def checkOnesSegment(self, s: str) -> bool:
        # 统计由 '1' 组成的连续段数量
        segments = 0
        in_ones = False

        for c in s:
            if c == '1' and not in_ones:
                segments += 1
                in_ones = True
            elif c == '0':
                in_ones = False

        return segments <= 1
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)

## 关键点总结

1. 不含前导零意味着字符串以 `'1'` 开头
2. 若后续再出现 `'1'`（在某个 `'0'` 之后），必然包含 `"01"` 子串
3. 一行代码 `"01" not in s` 即可解决

## 易错点

1. 注意不含前导零是关键条件，否则逻辑不成立
2. 全 1 字符串（如 "111"）也满足条件，返回 `true`
3. 检查 `"01"` 而非 `"10"`，因为 `"10"` 只说明有 0 在 1 后面，不代表有两段 1
