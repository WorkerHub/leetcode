## 题目描述

给你一个字符串 `s`，你需要将其分割为若干子串，每个子串的代价为其中重复字符的数目（同一字符出现超过 1 次的次数之和）。

返回将 `s` 分割为任意多个子串时的最小总代价。

**示例 1：**

```
输入：s = "abaac"
输出：1
解释：分割为 ["ab", "aac"]：
- "ab" 代价 = 0（无重复）
- "aac" 代价 = 1（'a' 重复 1 次）
总代价 1。
```

**示例 2：**

```
输入：s = "abc"
输出：0
解释：整个字符串无重复，代价 0。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

动态规划：
- `dp[i]` = 将 `s[0..i-1]` 分割的最小代价。
- 对每个位置 j（切割点），`dp[i] = min(dp[j] + cost(s[j..i-1]))` for j in [0, i]。
- `cost(s[j..i-1])` = 子串中重复字符的总数。

优化：当当前子串无重复字符时代价为 0，在出现重复时切割或承担代价。

贪心观察：若子串无重复，可以尽量延伸；出现重复时必须承担代价或切割。

## Python 代码实现

### 方法一：DP + 滑动窗口（推荐）

```python
class Solution:
    def minimumCost(self, s: str) -> int:
        n = len(s)
        # dp[i] = s[0..i-1] 的最小分割代价
        dp = [0] * (n + 1)

        for i in range(1, n + 1):
            dp[i] = float('inf')
            # 枚举分割点 j，子串为 s[j..i-1]
            freq = {}
            cost = 0
            for j in range(i - 1, -1, -1):
                c = s[j]
                if c in freq:
                    cost += freq[c]  # freq[c] 表示 c 已出现的次数，再加一个重复
                freq[c] = freq.get(c, 0) + 1
                # 子串 s[j..i-1] 的代价为 cost
                dp[i] = min(dp[i], dp[j] + cost)

        return dp[n]
```

### 方法二：贪心（无重复时不分割）

```python
class Solution:
    def minimumCost(self, s: str) -> int:
        # 贪心：尽量延长无重复子串，出现重复时从上一次相同字符位置后切割
        n = len(s)
        dp = [0] * (n + 1)
        last_seen = {}

        for i in range(n):
            c = s[i]
            if c in last_seen:
                # c 在当前子串中出现过，必须承担代价或从上次切割
                # dp[i+1] = min(dp[i+1], dp[last_seen[c]+1] + cost)
                # 暂时用简单实现
                pass
            last_seen[c] = i
            dp[i + 1] = dp[i]  # 不分割，代价由后面统计

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一）；可以用启发式优化到 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 子串代价 = 子串中重复字符出现的额外次数之和。
2. DP 枚举所有分割点，取最小代价。
3. 从右向左扩展子串时，维护频率表可以 O(1) 更新代价。

## 易错点

1. 代价计算：每次加入新字符 c，代价增加 `freq[c]`（已出现次数），不是 `freq[c] - 1`。
2. DP 初始化 `dp[0] = 0`，表示空串代价为 0。
