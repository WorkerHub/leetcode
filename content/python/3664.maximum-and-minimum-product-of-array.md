## 题目描述

给你一个整数数组 `nums`，找到其中两个元素（可以相同下标），使得它们的乘积最大或最小。返回 `[max_product, min_product]`。

**示例 1：**

```
输入：nums = [-1,-3,2,4]
输出：[8,-12]
解释：最大乘积：2*4=8，最小乘积：-3*4=-12
```

**示例 2：**

```
输入：nums = [5,2,-4,-3]
输出：[15,-20]
```

**提示：**

- `2 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

最大乘积来自：
- 两个最大正数
- 两个最小负数（绝对值最大）

最小乘积来自：
- 最大正数 × 最小负数（绝对值最大的负数）
- 最小负数 × 最大正数

排序后取首尾比较。

## Python 代码实现

### 方法一：排序取首尾（推荐）

```python
from typing import List

class Solution:
    def maxAndMinProduct(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)

        # 最大乘积：最大两数或最小两数（负数）
        max_product = max(nums[0] * nums[1], nums[-1] * nums[-2])

        # 最小乘积：最小数 × 最大数（异号相乘）
        min_product = min(nums[0] * nums[-1], nums[0] * nums[1], nums[-1] * nums[-2])

        return [max_product, min_product]
```

### 方法二：只需最大最小值

```python
from typing import List

class Solution:
    def maxAndMinProduct(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        # 最大乘积候选
        candidates = [
            nums[0] * nums[1],    # 两最小（可能都是负数，乘积为正）
            nums[-1] * nums[-2],  # 两最大
        ]
        max_p = max(candidates)
        min_p = min(
            nums[0] * nums[-1],   # 最小 × 最大（最可能一正一负）
            nums[0] * nums[1],
            nums[-1] * nums[-2],
        )
        return [max_p, min_p]
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(1)

## 关键点总结

1. 最大乘积来自两最大正数或两最小负数
2. 最小乘积通常来自最小负数 × 最大正数
3. 排序后只需考虑首尾两端元素

## 易错点

1. 全正数时最小乘积是最小两数之积
2. 全负数时最大乘积是绝对值最大两数之积（两负相乘为正最大）
3. 混合正负时需要综合考虑
