## 题目描述

这是一道**交互题**。

有一个隐藏数组 `arr`，只包含 `1` 和 `-1`，且有**严格多数**元素（超过 n/2 个）相同。

你可以使用 `reader.query(a, b, c, d)` 查询，返回 `arr[a] * arr[b] * arr[c] * arr[d]` 的乘积（+1 或 -1）。

用最多 `4 * n` 次查询找出多数元素的下标（若多数为 1，返回任意下标；若多数为 -1，返回任意下标）。

## 解题思路

### 利用乘积判断相对关系

**核心思想：**
- `query(0, 1, 2, i)` 对比 `arr[0]*arr[1]*arr[2]*arr[i]`
- `query(0, 1, 2, 3)` 是基准值
- 若 `arr[i] == arr[3]`，则 `query(0,1,2,i) == query(0,1,2,3)`

这样可以将所有元素分为"与 arr[3] 相同"和"与 arr[3] 不同"两类，哪类更多哪类就是多数。

## 代码实现

### 方法一：对比基准法（推荐）

```python
class Solution:
    def guessMajority(self, reader: 'ArrayReader') -> int:
        n = reader.length()
        base = reader.query(0, 1, 2, 3)

        # 统计与 arr[3] 相同 vs 不同的元素
        same_as_3 = [3]  # 下标 3 本身与自身相同
        diff_from_3 = []

        # 下标 0, 1, 2 需要特殊处理（不能用 (0,1,2,i) 中的 i=0,1,2）
        # query(0, 1, 3, i) vs base query(0, 1, 2, 3)
        # arr[0]*arr[1]*arr[3]*arr[i] vs arr[0]*arr[1]*arr[2]*arr[3]
        # 结果相同 iff arr[i] == arr[2]

        # 先处理 i=0, 1, 2
        # 比较 arr[0] 与 arr[3]
        val = reader.query(1, 2, 3, 0)  # arr[1]*arr[2]*arr[3]*arr[0]
        # 此为 base * arr[0] / arr[3] ... 不对，用另一种方式
        # 改用 (0,1,2,3) 对比 (1,2,3,i): 后者 = arr[1]*arr[2]*arr[3]*arr[i]
        # base / query(1,2,3,i) = arr[0] / arr[i]... 这在整数域不好处理

        # 正确做法：基准为 query(0,1,2,3)，比较 query(0,1,2,i) 与 base
        # i=0,1,2 不能直接用（有重复），用不同的固定三元组
        for i in range(4, n):
            val = reader.query(0, 1, 2, i)
            if val == base:
                same_as_3.append(i)
            else:
                diff_from_3.append(i)

        # 处理 i=0,1,2: 用 query(1,2,3,0) 与 query(0,1,2,3) 的关系
        # query(1,2,3,0) = arr[1]*arr[2]*arr[3]*arr[0] = base（因为 query(0,1,2,3)=arr[0]*arr[1]*arr[2]*arr[3]）
        # 所以 query(1,2,3,0) 恒等于 base，无法用这种方式区分0
        # 换用: 比较 arr[0] 与 arr[1]
        # query(0,1,2,3): v0*v1*v2*v3
        # query(0,2,3,i) 与 query(1,2,3,i) 之比 = v0/v1

        # 实用做法：分别用不包含该下标的四元组
        q0 = reader.query(1, 2, 3, 4) if n > 4 else reader.query(1, 2, 3, 4 % n)
        q1 = reader.query(0, 2, 3, 4) if n > 4 else reader.query(0, 2, 3, 4 % n)
        q2 = reader.query(0, 1, 3, 4) if n > 4 else reader.query(0, 1, 3, 4 % n)

        # q0 = arr[1]*arr[2]*arr[3]*arr[4]
        # query(0,1,2,3) * q0 = arr[0]*arr[1]^2*arr[2]^2*arr[3]^2*arr[4] = arr[0]*arr[4]
        # 这依然复杂，建议参考标准题解

        # 简单实现：仅用于演示思路
        if len(same_as_3) > len(diff_from_3):
            return same_as_3[0]
        else:
            return diff_from_3[0] if diff_from_3 else -1
```

### 方法二：完整正确实现

```python
class Solution:
    def guessMajority(self, reader: 'ArrayReader') -> int:
        n = reader.length()
        # 基准：query(0,1,2,3)
        base = reader.query(0, 1, 2, 3)
        same = [3]  # 与 arr[3] 相同的下标
        diff = []   # 与 arr[3] 不同的下标

        # 对 i >= 4，用 query(0,1,2,i) 与 base 比较
        for i in range(4, n):
            if reader.query(0, 1, 2, i) == base:
                same.append(i)
            else:
                diff.append(i)

        # 对 i=0,1,2，分别排除一个下标
        # 比较 arr[0]: query(1,2,3,4) vs query(0,2,3,4)
        # 相等 iff arr[0] == arr[1]，再结合 arr[1] 与 arr[3] 的关系推断 arr[0]
        # 更简单：query(0,1,2,3) / query(1,2,3,4) = arr[0]/arr[4]
        # 这在 +-1 域即乘法：query(0,1,2,3) * query(1,2,3,4) = arr[0]*arr[1]^2*arr[2]^2*arr[3]^2*arr[4] = arr[0]*arr[4]
        # 所以 arr[0] == arr[4] iff query(0,1,2,3)*query(1,2,3,4) == 1
        if n > 4:
            q = reader.query(1, 2, 3, 4)
            if base * q == 1:  # arr[0] == arr[4]
                # arr[4] 在 same 中则 arr[0] 与 arr[3] 同，否则不同
                if 4 in same:
                    same.append(0)
                else:
                    diff.append(0)
            else:
                if 4 in same:
                    diff.append(0)
                else:
                    same.append(0)

            q = reader.query(0, 2, 3, 4)
            if base * q == 1:
                if 4 in same:
                    same.append(1)
                else:
                    diff.append(1)
            else:
                if 4 in same:
                    diff.append(1)
                else:
                    same.append(1)

            q = reader.query(0, 1, 3, 4)
            if base * q == 1:
                if 4 in same:
                    same.append(2)
                else:
                    diff.append(2)
            else:
                if 4 in same:
                    diff.append(2)
                else:
                    same.append(2)

        if len(same) >= len(diff):
            return same[0]
        else:
            return diff[0]
```

## 复杂度分析

- **查询次数**：O(N)，约 n+3 次
- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. 核心：乘积结果相同 iff 最后一个元素与 `arr[3]` 相同
2. 特殊处理前 3 个下标，利用乘积的性质推断
3. 最终比较两组大小，返回多数组的任意下标

## 易错点

- 前 3 个下标不能直接用 `query(0,1,2,i)` 比较（会有重复下标）
- 需要额外的查询来确定 `arr[0]`, `arr[1]`, `arr[2]` 与多数的关系
