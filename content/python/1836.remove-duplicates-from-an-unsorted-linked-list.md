## 题目描述

给你一个未排序的链表的头节点 `head`，删除链表中值出现**不止一次**的所有节点，返回处理后的链表（链表可能为空）。

**示例 1：**
```
输入：head = [1,2,3,2]
输出：[1,3]
```

**示例 2：**
```
输入：head = [2,1,1,2]
输出：[]
```

**提示：**
- 链表中节点个数在 `[1, 10^5]` 范围内
- `1 <= Node.val <= 10^5`

## 解题思路

**两次遍历**：
1. 第一次遍历统计每个值出现的次数
2. 第二次遍历删除出现次数 > 1 的节点

使用哑节点（dummy node）简化头节点的处理。

## 代码实现

### 方法一：哈希表 + 两次遍历（推荐）

```python
from collections import Counter
from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def deleteDuplicatesUnsorted(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 第一次遍历：统计每个值的出现次数
        freq = Counter()
        node = head
        while node:
            freq[node.val] += 1
            node = node.next

        # 第二次遍历：删除出现次数 > 1 的节点
        dummy = ListNode(0)
        dummy.next = head
        prev, curr = dummy, head

        while curr:
            if freq[curr.val] > 1:
                prev.next = curr.next  # 跳过当前节点
            else:
                prev = curr  # 保留当前节点，移动 prev
            curr = curr.next

        return dummy.next
```

### 方法二：哈希集合标记后删除

```python
from typing import Optional

class Solution:
    def deleteDuplicatesUnsorted(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 统计频率
        freq = {}
        cur = head
        while cur:
            freq[cur.val] = freq.get(cur.val, 0) + 1
            cur = cur.next

        # 构建新链表，只保留出现一次的节点
        dummy = ListNode(0)
        tail = dummy
        cur = head
        while cur:
            if freq[cur.val] == 1:
                tail.next = cur
                tail = tail.next
            cur = cur.next
        tail.next = None  # 防止旧链表残留指针
        return dummy.next
```

## 复杂度分析

- **时间复杂度**：O(n)，两次线性遍历
- **空间复杂度**：O(n)，哈希表存储频率

## 关键点总结

1. 链表未排序，不能只比较相邻节点，需要先统计全局频率
2. 哑节点简化头节点可能被删除的处理
3. 方法二构建新链表，注意最后要断开 `tail.next`

## 易错点

- 删除节点时只移动 curr，不移动 prev（prev 指向的是已确认保留的节点）
- 方法二构建新链表时，最后节点的 next 可能还指向旧链表的后续节点，需要置 None
