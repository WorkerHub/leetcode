## 题目描述

与 3025 相同题意，但 `n` 扩大到 `1500`，需要 O(n^2) 算法。

给你 `n x 2` 的点坐标数组，找满足条件的 (Alice, Bob) 对数：Alice 在左上，Bob 在右下，矩形内无其他点。

**提示：**
- `2 <= n <= 1500`
- `0 <= xi, yi <= 4 * 10^9`

## 解题思路

排序优化到 O(n^2)：

1. 将点按 `x` 升序，`x` 相同则按 `y` 降序排序
2. 枚举 Alice（左上角点 `i`）
3. 对于固定的 Alice `(x1, y1)`，枚举所有满足 `x2 >= x1` 且 `y2 <= y1` 的 Bob 点 `j`
4. 当我们从左到右（x 增大方向）枚举 Bob 时，维护一个"最大 y2"（在有效范围内）
5. 若当前 Bob 的 `y2` 大于之前所有 Bob 的 `y2`（在 `[y2, y1]` 范围内），则此 Bob 满足条件

**贪心关键：** 对固定的 Alice，按 y 降序枚举 Bob，若当前 Bob 的 y 值是目前最大的（且 <= y1），则矩形内没有其他更高的点，合法。

## Python 代码实现

### 方法一：排序 + O(n^2) 枚举（推荐）

```python
from typing import List

class Solution:
    def numberOfPairs(self, points: List[List[int]]) -> int:
        # 按 x 升序，x 相同按 y 降序
        points.sort(key=lambda p: (p[0], -p[1]))
        n = len(points)
        ans = 0

        for i in range(n):
            x1, y1 = points[i]
            max_y = float('-inf')  # 记录已见过的最大 y2

            for j in range(i + 1, n):
                x2, y2 = points[j]
                # Bob 必须满足 x2 >= x1（排序后自然满足）且 y2 <= y1
                if y2 > y1:
                    continue

                # 如果 y2 > max_y（之前没有更高的合法点挡住），则合法
                if y2 > max_y:
                    ans += 1
                    max_y = y2

        return ans
```

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def numberOfPairs(self, points: List[List[int]]) -> int:
        # 按 x 升序排序，x 相同时 y 降序
        # 这样保证对于固定的 Alice(i)，后续点的 x >= x1
        points.sort(key=lambda p: (p[0], -p[1]))
        n = len(points)
        ans = 0

        for i in range(n):
            x1, y1 = points[i]
            # max_y 记录"在 j > i 且 y2 <= y1 的点中，已见过的最大 y2"
            # 若新的 y2 大于 max_y，说明矩形 [x1,x2] x [y2,y1] 内不存在其他点
            # （因为任何更高的合法点 y > y2 都在 x <= x2 的范围内，但 y > y2 意味着不在矩形内）
            # 注意：x 相同时 y 降序，所以同 x 的点中 y 最大的先出现
            max_y = float('-inf')

            for j in range(i + 1, n):
                x2, y2 = points[j]

                # 必须满足 y2 <= y1（Alice 在上方，Bob 在下方或同高）
                if y2 > y1:
                    continue

                # y2 必须严格大于 max_y，保证矩形内无其他点
                # 原因：若之前有点 k（i < k < j）满足 x1 <= xk <= x2，y2 <= yk <= y1
                # 则 yk >= y2 > max_y（矛盾，因为 max_y >= yk），所以不存在这样的 k
                if y2 > max_y:
                    ans += 1
                    max_y = y2

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，双重循环
- 空间复杂度：O(1)（排序原地）

## 关键点总结

1. 关键排序：x 升序，x 相同时 y 降序
2. 固定 Alice，枚举 Bob 时维护最大 y2
3. 当前 Bob 的 y2 > max_y 时，矩形内必然无其他合法点

## 易错点

1. `max_y` 初始值为 `-inf`，不是 `y2_of_Alice`
2. 判断时用的是 `y2 > max_y`（严格大于），保证无遮挡
3. 排序时 x 相同按 y 降序，确保同 x 的更高点先被"拦截"
