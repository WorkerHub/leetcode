## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，你可以从某个格子出发，每次移动到相邻的四个方向（上下左右）的格子之一，但只能移动到值**严格更大**的格子。

返回从任意格子出发可以走的**严格递增路径的数目**。由于答案可能很大，返回对 `10^9 + 7` 取模的结果。

注意：每条路径长度至少为 1（单格子路径也算）。

**示例 1：**
```
输入：grid = [[1,1],[3,4]]
输出：8
解释：共有 8 条严格递增路径：[1],[1],[3],[4],[1,3],[1,4],[1,3,4],[1,4]
```

**提示：**
- `m == grid.length`，`n == grid[i].length`
- `1 <= m, n <= 1000`
- `1 <= grid[i][j] <= 10^6`

## 解题思路

**记忆化 DFS：**
定义 `dp[i][j]` 为以 `(i, j)` 为起点的严格递增路径数。

- 若已计算则直接返回。
- 否则，枚举四个方向，若邻格值严格大于当前格，则可以延伸路径。
- `dp[i][j] = 1 + sum(dp[ni][nj] for valid neighbors)`。

最终答案为所有 `dp[i][j]` 之和。

## 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def countPaths(self, grid: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        @lru_cache(maxsize=None)
        def dp(i: int, j: int) -> int:
            # 以 (i, j) 为起点的严格递增路径数
            count = 1  # 单格子路径
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] > grid[i][j]:
                    count = (count + dp(ni, nj)) % MOD
            return count

        return sum(dp(i, j) for i in range(m) for j in range(n)) % MOD
```

### 方法二：拓扑排序（按值排序）

```python
from typing import List

class Solution:
    def countPaths(self, grid: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        # 将所有格子按值排序（从小到大处理，从小格出发）
        cells = sorted((grid[i][j], i, j) for i in range(m) for j in range(n))
        
        dp = [[1] * n for _ in range(m)]  # 每个格子至少 1 条路径（自身）
        
        for val, i, j in cells:
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                # 若邻格值更小，则当前格可以从邻格延伸过来
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] < val:
                    dp[i][j] = (dp[i][j] + dp[ni][nj]) % MOD
        
        return sum(dp[i][j] for i in range(m) for j in range(n)) % MOD
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 记忆化 DFS | O(m * n) | O(m * n) |
| 拓扑排序 | O(m * n * log(m*n)) | O(m * n) |

## 关键点总结

1. DAG（有向无环图）上的 DP：严格递增保证图是 DAG，无需处理环。
2. 每个格子的路径数 = 1（自身）+ 所有可延伸邻格的路径数之和。
3. 拓扑排序方法从小值开始处理，确保依赖关系正确。

## 易错点

- 是**严格**递增，等值邻格不能移动。
- 答案是所有起点路径数之和，不只是从某个固定起点。
