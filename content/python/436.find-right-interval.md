## 题目描述

给你一个区间数组 `intervals`，其中 `intervals[i] = [starti, endi]`，且每个 `starti` 都不同。

区间 `i` 的右侧区间可以记作区间 `j`，并满足 `startj >= endi`，且 `startj` 最小化。注意 `i` 可能等于 `j`。

返回一个由每个区间 `i` 的右侧区间在 `intervals` 中对应下标组成的数组。如果某个区间 `i` 不存在对应的右侧区间，则下标 `i` 处的值设为 `-1`。

**示例 1：**
```
输入：intervals = [[1,2]]
输出：[-1]
解释：集合中只有一个区间，所以输出-1。
```

**示例 2：**
```
输入：intervals = [[3,4],[2,3],[1,2]]
输出：[-1,0,1]
解释：对于 [3,4] ，没有满足条件的"右侧"区间。
对于 [2,3] ，区间[3,4]具有最小的"右"起点;
对于 [1,2] ，区间[2,3]具有最小的"右"起点。
```

**示例 3：**
```
输入：intervals = [[1,4],[2,3],[3,4]]
输出：[-1,2,-1]
解释：对于区间 [1,4] 和 [3,4] ，没有满足条件的"右侧"区间。
对于 [2,3] ，区间 [3,4] 有最小的"右"起点。
```

**提示：**
- `1 <= intervals.length <= 2 * 10^4`
- `intervals[i].length == 2`
- `-10^6 <= starti <= endi <= 10^6`
- 每个区间的起点都不相同

## 解题思路

这道题要求找到每个区间的"右侧区间"，即起点大于等于当前区间终点的最小起点区间。

**关键观察：**
1. 右侧区间的起点 >= 当前区间的终点
2. 要找起点最小的那个
3. 可以先按起点排序，然后用二分查找

**算法流程：**
1. 记录每个区间的原始索引
2. 按起点排序
3. 对每个区间，用二分查找找到起点 >= 其终点的最小区间
4. 返回原始索引

## Python 代码实现

### 方法一：排序 + 二分查找 ⭐ 推荐

```python
from typing import List
import bisect

class Solution:
    def findRightInterval(self, intervals: List[List[int]]) -> List[int]:
        n = len(intervals)
        
        # 创建 (起点, 原始索引) 的列表并排序
        starts = sorted((interval[0], i) for i, interval in enumerate(intervals))
        
        result = []
        
        for interval in intervals:
            end = interval[1]
            
            # 二分查找：找到第一个起点 >= end 的区间
            # bisect_left 返回插入位置
            idx = bisect.bisect_left(starts, (end, 0))
            
            if idx < n:
                result.append(starts[idx][1])
            else:
                result.append(-1)
        
        return result
```

### 方法二：双指针

```python
from typing import List

class Solution:
    def findRightInterval(self, intervals: List[List[int]]) -> List[int]:
        n = len(intervals)
        
        # 按起点排序，记录原始索引
        start_sorted = sorted((interval[0], i) for i, interval in enumerate(intervals))
        # 按终点排序，记录原始索引
        end_sorted = sorted((interval[1], i) for i, interval in enumerate(intervals))
        
        result = [-1] * n
        j = 0
        
        # 遍历按终点排序的区间
        for end, i in end_sorted:
            # 找到第一个起点 >= end 的区间
            while j < n and start_sorted[j][0] < end:
                j += 1
            
            if j < n:
                result[i] = start_sorted[j][1]
        
        return result
```

### 方法三：暴力解法（超时，仅用于理解）

```python
from typing import List

class Solution:
    def findRightInterval(self, intervals: List[List[int]]) -> List[int]:
        n = len(intervals)
        result = []
        
        for i in range(n):
            end = intervals[i][1]
            min_start = float('inf')
            right_idx = -1
            
            # 遍历所有区间，找到起点最小的右侧区间
            for j in range(n):
                start = intervals[j][0]
                if start >= end and start < min_start:
                    min_start = start
                    right_idx = j
            
            result.append(right_idx)
        
        return result
```

### 方法四：哈希表 + 二分

```python
from typing import List
import bisect

class Solution:
    def findRightInterval(self, intervals: List[List[int]]) -> List[int]:
        # 建立起点到索引的映射
        start_to_idx = {interval[0]: i for i, interval in enumerate(intervals)}
        
        # 所有起点排序
        starts = sorted(start_to_idx.keys())
        
        result = []
        
        for interval in intervals:
            end = interval[1]
            
            # 二分查找第一个 >= end 的起点
            idx = bisect.bisect_left(starts, end)
            
            if idx < len(starts):
                result.append(start_to_idx[starts[idx]])
            else:
                result.append(-1)
        
        return result
```

## 复杂度分析

**方法一：排序 + 二分**
- 时间复杂度：O(n log n)
  - 排序：O(n log n)
  - 每次二分查找：O(log n)，共 n 次
- 空间复杂度：O(n)，存储排序后的数组

**方法二：双指针**
- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

**方法三：暴力**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 图解示例

以 `intervals = [[3,4],[2,3],[1,2]]` 为例：

```
原始区间（索引）：
0: [3,4]
1: [2,3]
2: [1,2]

按起点排序：
[1,2] (索引2)
[2,3] (索引1)
[3,4] (索引0)

查找过程：
- 区间0 [3,4]，end=4
  查找 start >= 4：无 → -1

- 区间1 [2,3]，end=3
  查找 start >= 3：找到[3,4] → 索引0

- 区间2 [1,2]，end=2
  查找 start >= 2：找到[2,3] → 索引1

结果：[-1, 0, 1]
```

## 关键点总结

1. **二分查找应用**：在有序数组中查找第一个满足条件的元素
2. **索引映射**：排序后要保留原始索引
3. **bisect_left**：Python 的 bisect_left 返回插入位置
4. **边界处理**：查找结果可能不存在，返回 -1
5. **双指针优化**：按终点遍历，按起点查找

## 易错点

1. **索引保存**：排序后要记录原始索引
2. **bisect 使用**：bisect_left 和 bisect_right 的区别
3. **边界检查**：二分查找结果可能越界
4. **重复起点**：题目保证起点不重复，简化了问题
5. **自己可以是右侧**：区间可以是自己的右侧区间（i 可以等于 j）
