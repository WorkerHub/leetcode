## 题目描述

给你一个整数数组 `nums` 和一个非负整数 `k`，返回满足以下条件的不同元素对 `(a, b)` 的数目（`a != b`，不考虑顺序），使得 `|a - b| <= k`。

**示例 1：**

```
输入：nums = [1, 2, 2, 3], k = 1
输出：2
解释：不同元素对为 (1,2)（差为 1）和 (2,3)（差为 1），共 2 对。
注意 (2,2) 不算，因为要求 a != b（不同值）。
```

**示例 2：**

```
输入：nums = [1, 3, 5], k = 2
输出：2
解释：(1,3) 差为 2，(3,5) 差为 2，共 2 对。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

去重后排序，用双指针统计满足条件的不同值对：
1. 对 nums 去重并排序，得到有序不重复数组 `vals`。
2. 双指针：对每个右指针 `r`，找最小的左指针 `l` 使得 `vals[r] - vals[l] <= k`。
3. 以 `r` 为右端，合法的左端点数量为 `r - l`（不含 r 自身）。

## Python 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def countDistinctPairs(self, nums: List[int], k: int) -> int:
        # 去重并排序
        vals = sorted(set(nums))
        n = len(vals)
        count = 0
        left = 0

        for right in range(n):
            # 移动左指针，使 vals[right] - vals[left] <= k
            while vals[right] - vals[left] > k:
                left += 1
            # 以 right 为右端的合法对数（不含 right 自身）
            count += right - left

        return count
```

### 方法二：哈希表

```python
from typing import List

class Solution:
    def countDistinctPairs(self, nums: List[int], k: int) -> int:
        vals = sorted(set(nums))
        count = 0

        for i in range(len(vals)):
            for j in range(i + 1, len(vals)):
                if vals[j] - vals[i] <= k:
                    count += 1
                else:
                    break  # 已排序，后面的差更大

        return count
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序；O(n) 双指针
- 空间复杂度：O(n)，去重集合

## 关键点总结

1. 先去重，问题转化为有序不重复数组中的配对问题。
2. 双指针在有序数组上高效统计满足差值约束的对数。
3. 因为去重，每对 `(i, j)` 代表不同值，无需额外判断。

## 易错点

1. 要求不同值的对（`a != b`），先去重再计数。
2. 双指针的计数 `right - left` 不含 right 本身，因为配对要求 i < j。
3. 差值是 `vals[right] - vals[left]`，因为已排序，右端减左端总为非负。
