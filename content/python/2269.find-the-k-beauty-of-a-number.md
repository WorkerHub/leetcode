## 题目描述

整数 `num` 的 **k 美丽值** 定义为 `num` 的所有长度为 `k` 的子字符串中能**整除** `num` 的数量（去掉前导零的子字符串为 0 时，不整除任何非零数）。

给你整数 `num` 和 `k`，返回 `num` 的 k 美丽值。

**示例 1：**
```
输入：num = 240, k = 2
输出：2
解释：子串 "24", "40"。24 整除 240？240/24=10，整除。40 整除 240？240/40=6，整除。共2个。
```

**示例 2：**
```
输入：num = 430043, k = 2
输出：2
```

## 解题思路

将 `num` 转为字符串，用滑动窗口枚举所有长度为 k 的子字符串，转为整数后检查是否整除 `num`（注意 0 不能整除）。

## 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def divisorSubstrings(self, num: int, k: int) -> int:
        s = str(num)
        count = 0
        for i in range(len(s) - k + 1):
            sub = int(s[i:i + k])
            # 子字符串不为0，且能整除 num
            if sub != 0 and num % sub == 0:
                count += 1
        return count
```

### 方法二：Python 一行

```python
class Solution:
    def divisorSubstrings(self, num: int, k: int) -> int:
        s = str(num)
        return sum(
            1 for i in range(len(s) - k + 1)
            if (sub := int(s[i:i+k])) != 0 and num % sub == 0
        )
```

## 复杂度分析

- 时间复杂度：O(n)，n 为 `num` 的位数。
- 空间复杂度：O(n)，字符串转换。

## 关键点总结

1. 枚举所有长度为 k 的子字符串（字符串切片）。
2. 子字符串转整数，检查是否为 0（0 不能作除数），以及是否整除 `num`。
3. Python 的海象运算符 `:=` 简化了方法二。

## 易错点

- 子字符串为 `"00"` 时，`int("00") = 0`，不整除任何非零数，需过滤 `sub == 0` 的情况。
- `num % sub == 0` 检查整除，注意取模而非取商。
