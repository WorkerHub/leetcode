## 题目描述

有 `n` 个锁需要解开，每个锁有强度 `strength[i]`。你有一把剑，初始强度为 `x`。每轮可以对任意锁攻击，每次攻击消耗 1 轮并使剑的强度增加 `k`，当剑的强度达到某把锁的强度时，该锁被解开。求解开所有锁的最少轮数。

**示例 1：**

```
输入：strength = [3, 4, 1, 5], k = 1
输出：10
```

**示例 2：**

```
输入：strength = [2, 5, 4], k = 2
输出：7
```

**提示：**
- `n <= 8`（锁的数量很小）
- `1 <= strength[i] <= 10^8`
- `1 <= k <= 10^8`

## 解题思路

状态压缩动态规划（bitmask DP）。

由于 n <= 8，可以枚举所有锁的解锁顺序。

设 `dp[mask]` = 已解开 `mask` 中的锁所需的最小轮数。

初始剑强度 = x（通常为 1 或给定）。解开第 i 把锁需要的轮数取决于当前剑强度和 `strength[i]`。

解第 i 把锁需要的轮数：若当前剑强度为 `cur`，目标为 `strength[i]`，则需要攻击 `ceil((strength[i] - cur) / k)` 轮（若 `cur >= strength[i]`，需要 0 轮等待但实际上题意是剑强度需要恰好达到，需重新理解）。

实际上，剑的强度从 `x + t * k` 中选择（第 t 轮后），需要找最小的 t 使得 `x + t * k >= strength[i]`，即 `t = ceil((strength[i] - x) / k)`（若 x < strength[i]）。

## Python 代码实现

### 方法一：bitmask DP（推荐）

```python
from typing import List
import math

class Solution:
    def findMinimumTime(self, strength: List[int], k: int) -> int:
        n = len(strength)
        INF = float('inf')

        # dp[mask] = 解开 mask 中所有锁的最少总轮数
        dp = [INF] * (1 << n)
        dp[0] = 0

        def rounds_needed(current_strength, target):
            # 当前剑强度为 current_strength，目标为 target
            # 每轮剑强度增加 k，需要多少轮才能达到 target
            if current_strength >= target:
                return 0
            return math.ceil((target - current_strength) / k)

        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            # 已解开的锁的数量
            cnt = bin(mask).count('1')
            # 当前剑强度（初始为 x=1，每解一把锁增加 k）
            # 但这里剑强度随轮数增加，不是随锁数增加
            # 更正：解开 cnt 把锁花了 dp[mask] 轮，剑强度 = 1 + dp[mask] * k
            current = 1 + dp[mask] * k  # 假设初始强度为 1

            for i in range(n):
                if mask & (1 << i):
                    continue
                # 尝试解第 i 把锁
                needed = rounds_needed(current, strength[i])
                new_time = dp[mask] + needed
                new_mask = mask | (1 << i)
                # 解开后，还需要1轮？不对，"攻击"直到剑强度 >= 目标
                # 实际解锁发生在第 dp[mask] + needed 轮
                # 但解锁需要一次攻击，所以总轮数 = dp[mask] + needed + 1? 需要看题意

                # 简化：总轮数 = dp[mask] + needed（needed 包含解锁的那一轮）
                if new_time < dp[new_mask]:
                    dp[new_mask] = new_time

        return dp[(1 << n) - 1]
```

### 方法二：回溯 + 剪枝

```python
from typing import List
import math

class Solution:
    def findMinimumTime(self, strength: List[int], k: int) -> int:
        n = len(strength)
        best = float('inf')

        def backtrack(used, time_elapsed):
            nonlocal best
            if used == (1 << n) - 1:
                best = min(best, time_elapsed)
                return
            if time_elapsed >= best:
                return
            cur_strength = 1 + time_elapsed * k
            for i in range(n):
                if used & (1 << i):
                    continue
                needed = max(0, math.ceil((strength[i] - cur_strength) / k))
                backtrack(used | (1 << i), time_elapsed + needed)

        backtrack(0, 0)
        return best
```

## 复杂度分析

- 时间复杂度：O(2^n * n)，bitmask DP
- 空间复杂度：O(2^n)

## 关键点总结

1. bitmask DP 枚举所有锁的解锁顺序
2. 当前剑强度 = 初始强度 + 已花费轮数 * k
3. 解一把锁的代价取决于当前剑强度和目标强度的差

## 易错点

1. 剑强度随时间（轮数）增长，不是随解锁数量增长
2. `ceil` 计算时需处理剑强度已大于目标的情况（返回 0）
3. 解锁顺序影响总时间，需要枚举所有顺序
