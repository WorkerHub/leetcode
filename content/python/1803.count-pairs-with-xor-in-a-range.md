## 题目描述

给你一个整数数组 `nums`（下标从 0 开始）以及两个整数 `low` 和 `high`，返回 **漂亮数对** 的数目。

**漂亮数对** 是一个形如 `(i, j)` 的数对，其中 `0 <= i < j < nums.length` 且 `low <= (nums[i] XOR nums[j]) <= high`。

**示例 1：**
```
输入：nums = [1,4,2,7], low = 2, high = 6
输出：6
```

**示例 2：**
```
输入：nums = [9,8,4,2,1], low = 5, high = 14
输出：8
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 2 * 10^4`
- `1 <= low <= high <= 2 * 10^4`

## 解题思路

**字典树（Trie）+ 前缀计数**

转化问题：`low <= x XOR y <= high` 等价于 `countLess(high+1) - countLess(low)`，其中 `countLess(limit)` 表示 XOR 值严格小于 `limit` 的数对数量。

对于 `countLess(limit)`：逐位从高位到低位分析，当前位为 `b`：
- 如果 `b = 1`：与 `x` 当前位相同的数，XOR 结果为 0 < 1，则这些数全部满足，直接统计；与 `x` 当前位不同的数，XOR 结果为 1，继续深入
- 如果 `b = 0`：只有 XOR 结果为 0 的情况才可能继续（结果为 1 则超出限制）

用字典树维护已插入的数，每插入一个新数就查询已有数中与其 XOR 在范围内的数量。

## 代码实现

### 方法一：字典树（推荐）

```python
from typing import List

class Trie:
    def __init__(self):
        self.children = [None, None]
        self.count = 0  # 经过该节点的数字个数

    def insert(self, num: int) -> None:
        node = self
        for i in range(14, -1, -1):  # 处理 15 位（nums[i] <= 2*10^4 < 2^15）
            bit = (num >> i) & 1
            if not node.children[bit]:
                node.children[bit] = Trie()
            node = node.children[bit]
            node.count += 1

    def count_less(self, num: int, limit: int) -> int:
        """统计已插入的数与 num XOR 后严格小于 limit 的数量"""
        node = self
        result = 0
        for i in range(14, -1, -1):
            num_bit = (num >> i) & 1
            limit_bit = (limit >> i) & 1
            if limit_bit == 1:
                # XOR 该位为 0 时，结果一定小于 limit（该位为 1）
                # 选择与 num_bit 相同的子节点，XOR 结果为 0
                same_bit = num_bit
                if node.children[same_bit]:
                    result += node.children[same_bit].count
                # 继续走 XOR 结果为 1 的方向（与 num_bit 不同的子节点）
                diff_bit = 1 - num_bit
                if not node.children[diff_bit]:
                    break
                node = node.children[diff_bit]
            else:
                # limit 该位为 0，只能走 XOR 结果为 0 的方向
                same_bit = num_bit
                if not node.children[same_bit]:
                    break
                node = node.children[same_bit]
        return result


class Solution:
    def countPairs(self, nums: List[int], low: int, high: int) -> int:
        trie = Trie()
        result = 0
        for num in nums:
            # 计算当前 num 与已有数中 XOR 在 [low, high] 范围内的数量
            result += trie.count_less(num, high + 1) - trie.count_less(num, low)
            trie.insert(num)
        return result
```

### 方法二：暴力枚举（对比理解）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], low: int, high: int) -> int:
        result = 0
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                xor_val = nums[i] ^ nums[j]
                if low <= xor_val <= high:
                    result += 1
        return result
        # 时间复杂度 O(n^2)，数据量大时会超时
```

## 复杂度分析

- **方法一（字典树）**：
  - 时间复杂度：O(n * log(max_val))，每次插入和查询都是 O(log(max_val)) = O(15)
  - 空间复杂度：O(n * log(max_val))，字典树节点数
- **方法二（暴力）**：
  - 时间复杂度：O(n^2)
  - 空间复杂度：O(1)

## 关键点总结

1. 将区间查询转化为两次前缀查询之差：`[low, high]` = `[0, high+1)` - `[0, low)`
2. 字典树从高位到低位构建，每个节点维护经过的数字数量
3. 查询时，若 limit 当前位为 1，可以直接累加 XOR 为 0 的那一侧的计数
4. 按顺序插入，保证每对数对只统计一次

## 易错点

- 位数范围：`2 * 10^4 < 2^15 = 32768`，需要处理 15 位
- `count_less` 查询的是**严格小于** limit，所以上界用 `high + 1`
- 字典树节点的 count 代表经过该节点的数字个数，非叶节点也需要计数
