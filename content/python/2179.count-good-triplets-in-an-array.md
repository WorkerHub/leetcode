## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，它们是 `[0, 1, ..., n-1]` 的排列。

**好三元组**：三个**不同**的下标 `(x, y, z)`，满足：
- `pos1[x] < pos1[y] < pos1[z]`（在 nums1 中的相对顺序）
- `pos2[x] < pos2[y] < pos2[z]`（在 nums2 中的相对顺序）

其中 `pos1[v]` 和 `pos2[v]` 分别是 `v` 在 `nums1` 和 `nums2` 中的位置。

返回好三元组的数目。

**提示：**
- `n == nums1.length == nums2.length`
- `3 <= n <= 10^5`

## 解题思路

**树状数组（BIT）**

将 nums1 视为"标准顺序"（把 nums1[i] -> nums2 中的位置 pos2[nums1[i]]）。

构造新数组 `a`，使得 `a[i] = pos2[nums1[i]]`，即按 nums1 顺序排列，每个元素记录在 nums2 中的位置。

问题转化为：在数组 `a` 中，找所有三元组 `(i, j, k)` 满足 `i < j < k` 且 `a[i] < a[j] < a[k]`（即三维递增子序列数目，等价于 LIS 计数问题的扩展）。

**对每个元素 a[j] 作为中间值：**
- 左侧比 a[j] 小的元素数量 `left_less`：在 `a[0..j-1]` 中 < a[j] 的个数，用 BIT 查询前缀和。
- 右侧比 a[j] 大的元素数量 `right_greater`：在 `a[j+1..n-1]` 中 > a[j] 的个数 = `(n-1-j) - (a[0..j+1..n-1] 中 <= a[j] 的个数)`。

贡献 = `left_less * right_greater`，累加所有 j 的贡献。

## 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List

class Solution:
    def goodTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        # pos2[v] = v 在 nums2 中的位置
        pos2 = [0] * n
        for i, v in enumerate(nums2):
            pos2[v] = i

        # 将 nums1 转换为 pos2 序列
        a = [pos2[v] for v in nums1]

        # 树状数组（BIT）
        bit = [0] * (n + 1)

        def update(i: int):
            i += 1  # 1-indexed
            while i <= n:
                bit[i] += 1
                i += i & (-i)

        def query(i: int) -> int:
            i += 1  # 1-indexed
            total = 0
            while i > 0:
                total += bit[i]
                i -= i & (-i)
            return total

        ans = 0
        # 从右到左遍历，维护"右侧已处理的元素"
        right_bit = [0] * (n + 1)

        def update_right(i: int):
            i += 1
            while i <= n:
                right_bit[i] += 1
                i += i & (-i)

        def query_right(i: int) -> int:
            i += 1
            total = 0
            while i > 0:
                total += right_bit[i]
                i -= i & (-i)
            return total

        # 先遍历一遍计算 left_less 和 right_greater
        # 使用一个 BIT 从左到右遍历，另一个从右到左
        left_less = [0] * n
        for i in range(n):
            left_less[i] = query(a[i] - 1) if a[i] > 0 else 0
            update(a[i])

        # 重置 BIT
        right_greater = [0] * n
        bit2 = [0] * (n + 1)

        def upd2(i: int):
            i += 1
            while i <= n:
                bit2[i] += 1
                i += i & (-i)

        def qry2(i: int) -> int:
            i += 1
            s = 0
            while i > 0:
                s += bit2[i]
                i -= i & (-i)
            return s

        for i in range(n - 1, -1, -1):
            # 右侧大于 a[i] 的个数 = 右侧已处理数量 - 右侧 <= a[i] 的个数
            total_right = n - 1 - i
            le = qry2(a[i])  # 右侧 <= a[i] 的个数
            right_greater[i] = total_right - le
            upd2(a[i])

        for j in range(n):
            ans += left_less[j] * right_greater[j]

        return ans
```

### 方法二：简洁合并版

```python
from typing import List

class Solution:
    def goodTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        pos2 = {v: i for i, v in enumerate(nums2)}
        a = [pos2[v] for v in nums1]

        bit = [0] * (n + 1)

        def add(x):
            x += 1
            while x <= n:
                bit[x] += 1
                x += x & -x

        def prefix(x):
            x += 1
            s = 0
            while x > 0:
                s += bit[x]
                x -= x & -x
            return s

        ans = 0
        prefix_less = []
        for v in a:
            prefix_less.append(prefix(v - 1) if v > 0 else 0)
            add(v)

        bit[:] = [0] * (n + 1)
        suffix_greater = []
        for i in range(n - 1, -1, -1):
            total = n - 1 - i
            le = prefix(a[i])
            suffix_greater.append(total - le)
            add(a[i])
        suffix_greater.reverse()

        return sum(l * r for l, r in zip(prefix_less, suffix_greater))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 树状数组 | O(n log n) | O(n) |

## 关键点总结

1. 转化问题：将两个排列合并为一个序列 a，统计 a 中的"三维递增子序列"数。
2. 对每个中间值，左侧更小数 * 右侧更大数 = 该中间值的贡献。
3. 树状数组查询前缀数量，O(log n) 每次操作。

## 易错点

- 转化时确保 `a[i] = pos2[nums1[i]]`，即 nums1 中第 i 个元素在 nums2 中的位置。
- 两次 BIT 遍历方向相反（一次从左到右，一次从右到左）。
