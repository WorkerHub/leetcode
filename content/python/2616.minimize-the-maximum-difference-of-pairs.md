## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `p`。请从 `nums` 中找到 `p` 个下标对，每个下标对对应数值之差的绝对值最大化可以最小到多少。

注意：同一个下标只能使用一次。

返回 `p` 个下标对所能获得的差值最大值的最小值。

**示例 1：**
```
输入：nums = [10,1,2,7,1,3], p = 2
输出：1
解释：选下标对 (1,4) 差值 0，(2,5) 差值 1，最大差值为 1
```

**示例 2：**
```
输入：nums = [4,2,1,2], p = 1
输出：0
```

**数据范围：**
- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^9
- 0 <= p <= (nums.length)/2

## 解题思路

二分答案 + 贪心验证：

二分最大差值 `mid`，验证能否找到 `p` 个不重叠的下标对，每对差值 <= `mid`。

验证时，先对数组排序，然后贪心：从左到右扫描，若 `nums[i+1] - nums[i] <= mid`，则取这对（`i` 和 `i+1`），计数加 1，跳过下一个（`i += 2`）；否则 `i += 1`。

排序后相邻元素差最小，贪心取相邻对是最优的。

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minimizeMax(self, nums: List[int], p: int) -> int:
        if p == 0:
            return 0
        nums.sort()
        n = len(nums)

        def can_find_p_pairs(max_diff):
            # 贪心：从左到右，尽可能多地配对
            count = 0
            i = 0
            while i < n - 1:
                if nums[i + 1] - nums[i] <= max_diff:
                    count += 1
                    i += 2  # 跳过已配对的两个元素
                    if count == p:
                        return True
                else:
                    i += 1
            return count >= p

        # 二分差值
        lo, hi = 0, nums[-1] - nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if can_find_p_pairs(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### 方法二：显式版本

```python
from typing import List

class Solution:
    def minimizeMax(self, nums: List[int], p: int) -> int:
        nums.sort()
        n = len(nums)

        def check(diff):
            pairs = 0
            i = 0
            while i + 1 < n:
                if nums[i + 1] - nums[i] <= diff:
                    pairs += 1
                    i += 2
                else:
                    i += 1
            return pairs >= p

        left, right = 0, nums[-1] - nums[0]
        while left < right:
            mid = (left + right) // 2
            if check(mid):
                right = mid
            else:
                left = mid + 1
        return left
```

## 复杂度分析

- 时间复杂度：O(n log n + n log M)，n 为数组长度，M 为最大差值
- 空间复杂度：O(log n)（排序递归栈）

## 关键点总结

1. 二分最大差值，转化为可行性验证
2. 排序后相邻元素差最小，贪心配对从左到右
3. 配对后跳过两个元素，不能重叠使用

## 易错点

1. p=0 时直接返回 0
2. 二分上界取 `nums[-1] - nums[0]`（排序后的最大差值）
3. 贪心时只能取相邻对（排序后相邻差最小）
