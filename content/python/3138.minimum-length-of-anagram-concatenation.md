## 题目描述

给你一个字符串 `s`，它由某个字符串 `t` 的异位词（即 t 的某个排列）重复拼接而成。

返回 `t` 可能的 **最小** 长度。

**示例 1：**
```
输入：s = "abba"
输出：2
解释：t = "ab"，s = "ab" + "ba"（都是 "ab" 的异位词）。
```

**示例 2：**
```
输入：s = "cdef"
输出：4
解释：t = "cdef"，整个字符串就是一段。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

t 的长度必须是 len(s) 的因子。对每个因子 d，将 s 切分为长度为 d 的块，验证所有块的字符频率是否相同（即都是同一个字符串的异位词）。

取最小的满足条件的 d 作为答案。

## Python 代码实现

### 方法一：枚举因子（推荐）

```python
from collections import Counter

class Solution:
    def minAnagramLength(self, s: str) -> int:
        n = len(s)

        def check(d: int) -> bool:
            # 验证以 d 为块长度切分后所有块字符频率相同
            if n % d != 0:
                return False
            base = Counter(s[:d])
            for i in range(d, n, d):
                if Counter(s[i:i+d]) != base:
                    return False
            return True

        for d in range(1, n + 1):
            if n % d == 0 and check(d):
                return d
        return n
```

### 方法二：优化版本

```python
from collections import Counter

class Solution:
    def minAnagramLength(self, s: str) -> int:
        n = len(s)
        total = Counter(s)

        for d in range(1, n + 1):
            if n % d != 0:
                continue
            k = n // d  # 块数
            # 每个字符的频率必须被 k 整除
            if all(v % k == 0 for v in total.values()):
                # 进一步验证每块字符频率相同
                block = Counter(s[:d])
                valid = True
                for i in range(d, n, d):
                    if Counter(s[i:i+d]) != block:
                        valid = False
                        break
                if valid:
                    return d
        return n
```

## 复杂度分析

- 时间复杂度：O(n * d(n))，d(n) 为 n 的因子数，通常很小
- 空间复杂度：O(n)

## 关键点总结

1. t 的长度必须是 len(s) 的因子
2. 切分后每块必须与第一块的字符频率完全相同
3. 从小到大枚举因子，找到第一个满足条件的

## 易错点

1. 必须是因子，不能是任意长度
2. 验证时每块频率必须与第一块完全相同（不只是频率整除）
