## 题目描述

在一个单线程 CPU 上，我们按照一定顺序执行 n 个函数。每个函数都有唯一的 ID，范围是 0 到 n-1。

函数调用存储在一个日志中，格式为 "{function_id}:{"start" | "end"}:{timestamp}"。

例如："0:start:3" 表示 ID 为 0 的函数在时间戳 3 开始执行。

给定日志列表 logs，返回每个函数的独占时间。

**示例 1：**
```
输入：n = 2, logs = ["0:start:0","1:start:2","1:end:5","0:end:6"]
输出：[3,4]
解释：
函数 0 在时间戳 0 开始，在时间戳 6 结束，执行了 7 个时间单位
函数 1 在时间戳 2 开始，在时间戳 5 结束，执行了 4 个时间单位
函数 0 的独占时间 = 7 - 4 = 3
函数 1 的独占时间 = 4
```

**提示：**
- 1 <= n <= 100
- 1 <= logs.length <= 500
- 0 <= function_id < n
- 0 <= timestamp <= 10^9
- 两个 start 事件之间不会有相同的时间戳

## 解题思路

使用栈来模拟函数调用过程。

**核心思想：**
1. 栈存储当前正在执行的函数
2. 遇到 start，将函数入栈
3. 遇到 end，将函数出栈并计算独占时间

## Python 代码实现

### 方法一：栈模拟（推荐）

```python
from typing import List

class Solution:
    def exclusiveTime(self, n: int, logs: List[str]) -> List[int]:
        result = [0] * n
        stack = []
        prev_time = 0
        
        for log in logs:
            func_id, action, timestamp = log.split(':')
            func_id, timestamp = int(func_id), int(timestamp)
            
            if action == 'start':
                if stack:
                    # 当前栈顶函数的执行时间累加
                    result[stack[-1]] += timestamp - prev_time
                stack.append(func_id)
                prev_time = timestamp
            else:  # end
                # 函数结束，累加时间（包含当前时间点）
                result[stack.pop()] += timestamp - prev_time + 1
                prev_time = timestamp + 1
        
        return result
```

## 复杂度分析

- 时间复杂度：O(m)，m 是日志数量
- 空间复杂度：O(n)，栈的大小

## 关键点总结

1. 使用栈跟踪当前执行的函数
2. 注意 end 时间点是包含在内的
3. 每次操作后更新 prev_time

## 易错点

1. end 时间计算错误（忘记 +1）
2. 没有正确处理嵌套调用
3. prev_time 更新时机错误
