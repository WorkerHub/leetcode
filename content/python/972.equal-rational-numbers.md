## 题目描述

给定两个字符串 `s` 和 `t`，每一个字符串代表一个非负有理数，只有当它们表示相同的数字时才返回 `true`。字符串中可以使用括号来表示有理数的循环部分。

**有理数**可以用三种形式之一表示：
- `<IntegerPart>`（例如 0、12、123）
- `<IntegerPart><.><NonRepeatingPart>`（例如 0.5、2.12、2.0001）
- `<IntegerPart><.><NonRepeatingPart><(><RepeatingPart><)>`（例如 0.1(6)、0.9(9)、0.00(1212)）

**示例 1：**
```
输入：s = "0.(52)", t = "0.5(25)"
输出：true
解释：因为 "0.(52)" 代表 0.52525252...，而 "0.5(25)" 代表 0.52525252525.....，则这两个字符串表示相同的数字。
```

**示例 2：**
```
输入：s = "0.1666(6)", t = "0.166(66)"
输出：true
```

**示例 3：**
```
输入：s = "0.9(9)", t = "1."
输出：true
解释：
"0.9(9)" 代表 0.999999999... 永远重复，等于 1。
```

**提示：**
- 每个部分仅由数字组成
- 整数部分 `<IntegerPart>` 不会以零开头（零本身除外）
- `1 <= <IntegerPart>.length <= 4`
- `0 <= <NonRepeatingPart>.length <= 4`
- `1 <= <RepeatingPart>.length <= 4`

## 解题思路

这道题需要比较两个有理数字符串是否相等，难点在于处理循环小数。

**核心思想：**
1. 将字符串解析为：整数部分 + 非循环小数部分 + 循环小数部分
2. 将有理数转换为分数形式进行比较
3. 或者计算足够精度的小数值进行比较

**数学原理：**
- 0.(6) = 6/9 = 2/3
- 0.1(6) = 1/10 + 6/90 = 1/10 + 1/15 = 1/6
- 0.9(9) = 9/9 = 1

**方法选择：**
- 方法一：使用 Python 的 `fractions.Fraction` 模块
- 方法二：计算高精度小数值
- 方法三：手动转换为分数

## Python 代码实现

### 方法一：使用 Fraction 模块（推荐）⭐

```python
from fractions import Fraction

class Solution:
    def isRationalEqual(self, s: str, t: str) -> bool:
        def parse(s):
            """将字符串解析为 Fraction"""
            # 查找括号位置
            i = s.find('(')
            
            if i == -1:
                # 没有循环部分
                return Fraction(s) if s else Fraction(0)
            
            # 有循环部分
            # 整数部分 + 小数非循环部分
            base = s[:i]
            # 循环部分
            repeat = s[i+1:-1]
            
            # 非循环小数位数
            decimal_len = len(base) - base.find('.') - 1 if '.' in base else 0
            # 循环部分长度
            repeat_len = len(repeat)
            
            # 计算分数
            # 例如：0.1(23) = 0.1 + 0.0(23)
            #     = 1/10 + 23/(99*10)
            
            # 基础部分
            numerator = int(base.replace('.', ''))
            denominator = 10 ** (len(base) - base.find('.') - 1) if '.' in base else 1
            
            # 循环部分
            repeat_num = int(repeat)
            repeat_denom = (10 ** repeat_len - 1) * (10 ** decimal_len)
            
            return Fraction(numerator, denominator) + Fraction(repeat_num, repeat_denom)
        
        return parse(s) == parse(t)
```

### 方法二：高精度小数比较

```python
class Solution:
    def isRationalEqual(self, s: str, t: str) -> bool:
        def to_decimal(s, precision=20):
            """将字符串转换为高精度小数"""
            i = s.find('(')
            
            if i == -1:
                return float(s)
            
            # 基础部分
            base = s[:i]
            # 循环部分
            repeat = s[i+1:-1]
            
            # 将循环部分重复足够多次
            decimal = base + repeat * precision
            
            return float(decimal)
        
        # 比较精度
        return abs(to_decimal(s) - to_decimal(t)) < 1e-9
```

### 方法三：手动计算分数

```python
from math import gcd

class Solution:
    def isRationalEqual(self, s: str, t: str) -> bool:
        def to_fraction(s):
            """将字符串转换为最简分数 (numerator, denominator)"""
            i = s.find('(')
            
            if i == -1:
                # 没有循环部分
                if '.' not in s:
                    return (int(s), 1)
                parts = s.split('.')
                num = int(parts[0] + parts[1])
                denom = 10 ** len(parts[1])
                g = gcd(num, denom)
                return (num // g, denom // g)
            
            # 有循环部分
            base = s[:i]
            repeat = s[i+1:-1]
            
            # 非循环部分
            if '.' in base:
                int_part, dec_part = base.split('.')
                non_repeat_len = len(dec_part)
            else:
                int_part = base
                dec_part = ''
                non_repeat_len = 0
            
            repeat_len = len(repeat)
            
            # 计算分子和分母
            # 例如：0.1(23)
            # = (123 - 1) / (990)
            # = 122 / 990
            
            full_num = int(int_part + dec_part + repeat)
            base_num = int(int_part + dec_part) if dec_part else int(int_part)
            
            numerator = full_num - base_num
            denominator = (10 ** (non_repeat_len + repeat_len)) - (10 ** non_repeat_len)
            
            g = gcd(numerator, denominator)
            return (numerator // g, denominator // g)
        
        return to_fraction(s) == to_fraction(t)
```

## 复杂度分析

### 方法一：Fraction
- **时间复杂度**：O(n)，n 是字符串长度
- **空间复杂度**：O(1)

### 方法二：高精度
- **时间复杂度**：O(n × p)，p 是精度
- **空间复杂度**：O(n × p)

1. **字符串解析**：正确提取各个部分

3. **精度问题**：浮点数比较精度
4. **特殊情况**：0.9(9) = 1
5. **分母为0**：要避免除零错误
