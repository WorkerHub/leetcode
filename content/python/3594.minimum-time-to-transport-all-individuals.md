## 题目描述

有 `n` 个人需要从河的一岸运送到另一岸，使用一艘船，每次最多运 `k` 人。每次运送有时间花费，取决于本次运送的人的组合（给定时间矩阵或规则）。船必须来回（去程和返程），目标是将所有人运到对岸的最少总时间。

**示例：**

```
输入：n = 4, k = 2, times = [[1,2],[3,4],[5,6],[7,8]]
输出：最少时间（具体取决于题目细节）
```

**提示：**
- `1 <= n <= 20`
- `1 <= k <= n`
- 时间由某种规则给定

## 解题思路

经典状态压缩 DP（Bitmask DP）：

状态：`dp[mask]` = 将 `mask` 所表示的人集合运到对岸的最少时间。

转移：枚举 `mask` 的所有大小 <= k 的子集 `group`，表示本次运送的人，需要：
1. 去程花费（运送 group 到对岸）
2. 返程花费（最小的单人返回时间，若还有人未运送）

具体地，定义往返一次的花费由子集的最慢的人决定（典型过桥问题模型）。

初始：dp[0] = 0，目标：dp[(1<<n)-1]

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, n: int, k: int, time: List[List[int]]) -> int:
        # time[i] = [left_to_right, right_wait, right_to_left, left_wait]
        # 过桥时间（左到右），等待时间，返回时间（右到左），等待时间
        # 每次选 k 人过桥，花费最慢者的过桥时间，返回一人（选返回最快的已在对岸的人）

        INF = float('inf')
        full = (1 << n) - 1
        dp = [INF] * (full + 1)
        dp[0] = 0

        # 预计算每个人的过桥时间和返回时间
        # 假设 time[i] = [forward_time, backward_time]

        def get_subsets(mask, size):
            # 生成 mask 中所有大小为 size 的子集
            result = []
            def bt(cur, cnt, start):
                if cnt == size:
                    result.append(cur)
                    return
                remaining = bin(mask >> start).count('1')
                if cnt + remaining < size:
                    return
                for i in range(start, n):
                    if mask >> i & 1:
                        bt(cur | (1 << i), cnt + 1, i + 1)
            bt(0, 0, 0)
            return result

        # 所有人集合在右岸时可以返回的最小时间
        # right_mask 表示已在右岸的人

        for mask in range(full + 1):
            if dp[mask] == INF:
                continue
            remaining = full ^ mask  # 还未过河的人
            if remaining == 0:
                continue

            # 枚举本次运送的组（remaining 中大小 <= k 的非空子集）
            # 为简化，枚举大小恰好为 min(k, popcount(remaining))
            send_size = min(k, bin(remaining).count('1'))
            groups = get_subsets(remaining, send_size)

            for group in groups:
                # 去程花费：组中最慢者
                forward = max(time[i][0] for i in range(n) if group >> i & 1)
                new_mask = mask | group

                if new_mask == full:
                    # 全部运送完毕
                    dp[full] = min(dp[full], dp[mask] + forward)
                else:
                    # 需要有人返回（从 new_mask 中选最快的）
                    backward = min(time[i][1] for i in range(n) if new_mask >> i & 1)
                    dp[new_mask] = min(dp[new_mask], dp[mask] + forward + backward)

        return dp[full]
```

### 方法二：枚举所有子集优化

```python
from typing import List

class Solution:
    def minimumTime(self, n: int, k: int, time: List[List[int]]) -> int:
        full = (1 << n) - 1
        INF = float('inf')
        dp = [INF] * (full + 1)
        dp[0] = 0

        for mask in range(full):
            if dp[mask] == INF:
                continue
            remaining = full ^ mask
            # 枚举 remaining 的所有非空子集，大小 <= k
            sub = remaining
            while sub:
                if bin(sub).count('1') <= k:
                    # 去程
                    fwd = max(time[i][0] for i in range(n) if sub >> i & 1)
                    new_mask = mask | sub
                    if new_mask == full:
                        dp[full] = min(dp[full], dp[mask] + fwd)
                    else:
                        bwd = min(time[i][1] for i in range(n) if new_mask >> i & 1)
                        dp[new_mask] = min(dp[new_mask], dp[mask] + fwd + bwd)
                sub = (sub - 1) & remaining

        return dp[full]
```

## 复杂度分析

- 时间复杂度：O(3^n * n)，枚举所有子集的子集
- 空间复杂度：O(2^n)

## 关键点总结

1. 状态 dp[mask] = 将 mask 对应人运到对岸的最少时间
2. 去程选 <= k 人，花费最慢者时间
3. 返程需要选一人返回，选已过河者中最快的
4. 最终状态为 dp[full]

## 易错点

1. 最后一组无需返程（全部运完后不需要人返回）
2. 子集枚举使用 `sub = (sub-1) & remaining` 技巧
3. 返程人选自已在对岸的集合（包括本次运过去的）
