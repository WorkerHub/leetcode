## 题目描述

给你一个整数数组 `houses` 表示一条街上房屋的位置，以及整数 `k`，请你用 `k` 个邮筒覆盖所有房屋，使所有房屋到最近邮筒的**总距离最小**。

邮筒可以放在**任意**位置，不必和房屋位置一样，但必须放在某个整数坐标上。

返回最小的总距离之和。测试数据保证答案在 32 位有符号整数范围内。

**示例 1：**

```
输入：houses = [1,4,8,10,20], k = 3
输出：5
解释：将邮筒分别放在位置 3，9 和 20（或 10）。
- 位置 3: 距离 [1,4] 各自最近，总距离 |1-3|+|4-3|=2+1=3
- 位置 9: 距离 [8,10] 最近，总距离 |8-9|+|10-9|=1+1=2
- 位置 20: 距离 [20] 最近，总距离 0
总计: 5
```

**示例 2：**

```
输入：houses = [2,3,5,12,18], k = 2
输出：9
解释：邮筒放在 3 和 14（或 12/18 之间）。
```

**提示：**
- `1 <= k <= houses.length <= 100`
- `1 <= houses[i] <= 10^4`

---

## 解题思路

**核心思想：动态规划 + 中位数定理**

**中位数定理：** 对于一组点，将一个邮筒放在它们的**中位数**位置时，总距离最小。

**预处理：** 先计算 `cost[i][j]`——将一个邮筒覆盖 `houses[i..j]` 时的最小总距离（邮筒放在中位数位置）。

**DP 定义：** `dp[i][j]` = 用 `i` 个邮筒覆盖前 `j` 个房子的最小总距离。

**状态转移：** 枚举最后一个邮筒覆盖的范围 `[p+1, j]`：
```
dp[i][j] = min(dp[i-1][p] + cost[p+1][j]) for all p in [i-1, j-1]
```

**计算 cost[i][j]：**
排序后，`houses[i..j]` 的中位数是 `houses[(i+j)//2]`，总距离为：
```
sum(|houses[t] - houses[mid]| for t in [i, j])
```
可以利用前缀和 O(1) 计算，或直接 O(n^2) 预处理。

## Python 代码实现

### 方法一：区间预处理 + DP（推荐）

```python
from typing import List

class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()  # 排序是使用中位数定理的前提
        n = len(houses)

        # 预处理 cost[i][j]：用一个邮筒覆盖 houses[i..j] 的最小距离
        cost = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                # 邮筒放在中位数位置，总距离 = 对称求和
                mid = (i + j) // 2
                for t in range(i, j + 1):
                    cost[i][j] += abs(houses[t] - houses[mid])

        INF = float('inf')
        # dp[i][j]：用 i 个邮筒覆盖前 j 个房子（下标 0..j-1）的最小距离
        dp = [[INF] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0  # 0 个邮筒覆盖 0 个房子，距离为 0

        for i in range(1, k + 1):
            for j in range(i, n + 1):
                # 枚举最后一个邮筒覆盖 houses[p..j-1]
                for p in range(i - 1, j):
                    if dp[i - 1][p] < INF:
                        dp[i][j] = min(dp[i][j], dp[i - 1][p] + cost[p][j - 1])

        return dp[k][n]
```

### 方法二：前缀和优化 cost 计算

```python
from typing import List

class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()
        n = len(houses)

        # 前缀和用于快速计算区间和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + houses[i]

        def interval_cost(i: int, j: int) -> int:
            """计算将一个邮筒放在 houses[i..j] 中位数位置的最小总距离"""
            mid = (i + j) // 2
            m = houses[mid]
            # 左半部分：[i, mid-1]，到 m 的距离 = mid*m - sum(houses[i..mid-1])
            left = mid * m - (prefix[mid] - prefix[i])
            # 右半部分：[mid+1, j]，到 m 的距离 = sum(houses[mid+1..j]) - (j-mid)*m
            right = (prefix[j + 1] - prefix[mid + 1]) - (j - mid) * m
            return left + right

        INF = float('inf')
        dp = [[INF] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0

        for i in range(1, k + 1):
            for j in range(i, n + 1):
                for p in range(i - 1, j):
                    if dp[i - 1][p] < INF:
                        dp[i][j] = min(dp[i][j], dp[i - 1][p] + interval_cost(p, j - 1))

        return dp[k][n]
```

### 方法三：带记忆化的递归（自顶向下）

```python
from typing import List
from functools import lru_cache

class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()
        n = len(houses)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + houses[i]

        def interval_cost(i: int, j: int) -> int:
            mid = (i + j) // 2
            m = houses[mid]
            left = mid * m - (prefix[mid] - prefix[i])
            right = (prefix[j + 1] - prefix[mid + 1]) - (j - mid) * m
            return left + right

        @lru_cache(maxsize=None)
        def dp(mailboxes: int, start: int) -> int:
            """用 mailboxes 个邮筒覆盖 houses[start..n-1] 的最小距离"""
            if mailboxes == 0:
                return 0 if start == n else float('inf')
            if start == n:
                return 0  # 房子都覆盖了，剩余邮筒不放
            if mailboxes >= n - start:
                return 0  # 邮筒足够多，每个房子放一个，距离为 0

            best = float('inf')
            for end in range(start, n):
                # 最后一个邮筒覆盖 houses[start..end]
                c = interval_cost(start, end)
                rest = dp(mailboxes - 1, end + 1)
                best = min(best, c + rest)

            return best

        return dp(k, 0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 区间预处理 + DP | O(k * n^2) | O(k * n + n^2) |
| 前缀和优化 | O(k * n^2) | O(k * n) |
| 记忆化递归 | O(k * n^2) | O(k * n) |

- n=100, k=100 时：100 * 100^2 = 1,000,000，完全可行。

## 关键点总结

1. **中位数定理**：一维空间中，将邮筒放在一组点的中位数位置时，总距离最小。
2. 先排序，再用 DP 枚举每个邮筒的覆盖范围。
3. `cost[i][j]` 的计算：排序后中位数是 `houses[(i+j)//2]`，用前缀和 O(1) 计算区间总距离。
4. DP 状态转移：枚举最后一个邮筒的覆盖起点 `p`，`dp[i][j] = min(dp[i-1][p] + cost[p][j-1])`。

---

## 易错点

- **必须先排序**：中位数定理在无序数组中不适用，排序是前提。
- **DP 下标对齐**：`dp[i][j]` 表示 `i` 个邮筒覆盖**前 j 个**（下标 0 到 j-1）房子，`cost[p][j-1]` 表示第 p 到 j-1 个（0 起）房子。
- **中位数位置**：`(i+j)//2` 是正确的中位数下标（向下取整），奇偶长度均适用。
