## 题目描述

给你一个下标从 **0** 开始的二维整数数组 `peaks`，其中 `peaks[i] = [x_i, y_i]` 表示山的峰值在坐标 `(x_i, y_i)`。山可以由等腰三角形描述，其中山峰为 `(x, y)`，底部区间为 `[x - y, x + y]`。

如果山 `j` 完全在山 `i` 的底部区间内（即 `x_j - y_j >= x_i - y_i` 且 `x_j + y_j <= x_i + y_i`），则山 `j` 对山 `i` **不可见**（被山 i 覆盖）。

返回**可见山**的数目。

**示例 1：**
```
输入：peaks = [[2,2],[6,3],[5,4]]
输出：2
解释：山 [6,3] 底部区间 [3,9]，山 [5,4] 底部区间 [1,9]，后者覆盖前者，所以 [6,3] 不可见。
```

**提示：**
- `1 <= peaks.length <= 10^5`
- `peaks[i].length == 2`
- `1 <= x_i, y_i <= 5 * 10^4`

## 解题思路

**将每座山转化为区间 `[x-y, x+y]`，问题转化为：计算有多少区间不被任何其他区间完全覆盖。**

**算法：**
1. 将区间按左端点升序、右端点降序排序。
2. 扫描，维护当前最大右端点 `max_right`：
   - 若当前区间完全在 `max_right` 之内，则被覆盖，不可见。
   - 否则可见，更新 `max_right`。
3. 注意：区间完全相同时，两座山互相覆盖，都不可见（或者说只算一个）。

实际上，如果两个区间相同，则互相覆盖，都不应该被计入可见。

## 代码实现

### 方法一：排序 + 扫描（推荐）

```python
from typing import List

class Solution:
    def visibleMountains(self, peaks: List[List[int]]) -> int:
        # 转化为区间
        intervals = [(x - y, x + y) for x, y in peaks]
        # 按左端点升序，左端点相同则右端点降序
        intervals.sort(key=lambda t: (t[0], -t[1]))
        
        visible = 0
        max_right = float('-inf')
        i = 0
        n = len(intervals)
        
        while i < n:
            l, r = intervals[i]
            # 统计有多少个区间与 intervals[i] 完全相同
            j = i
            while j < n and intervals[j] == (l, r):
                j += 1
            count = j - i  # 重复区间数量
            
            # 检查是否被前面的区间覆盖
            if r > max_right:
                # 若重复出现超过 1 次，则互相覆盖，都不可见
                if count == 1:
                    visible += 1
                max_right = r
            # r <= max_right：被前面的区间覆盖，不可见
            
            i = j
        
        return visible
```

### 方法二：直接排序后扫描

```python
from typing import List

class Solution:
    def visibleMountains(self, peaks: List[List[int]]) -> int:
        segs = sorted((x - y, x + y) for x, y in peaks)
        n = len(segs)
        ans = 0
        max_r = float('-inf')
        
        for i in range(n):
            l, r = segs[i]
            # 跳过被覆盖的
            if r <= max_r:
                continue
            # 检查是否与下一个重复
            if i + 1 < n and segs[i + 1] == (l, r):
                # 重复，都不可见
                max_r = r
                continue
            ans += 1
            max_r = r
        
        return ans
```

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序扫描 | O(n log n) | O(n) |

## 关键点总结

1. 山转化为底部区间后，问题等价于区间可见性。
2. 排序后扫描，维护最大右端点来判断覆盖。
3. 完全相同的区间互相覆盖，都不可见（需要特殊处理）。

## 易错点

- 区间 A 包含 B 的条件：`A.left <= B.left` 且 `A.right >= B.right`。
- 完全相同的区间（重复出现）都不可见，需要单独检查。
