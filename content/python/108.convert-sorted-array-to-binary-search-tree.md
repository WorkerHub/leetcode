## 题目描述

给你一个整数数组 `nums`，其中元素已经按升序排列，请你将其转换为一棵平衡二叉搜索树。

**平衡二叉树**是指该树所有节点的左右子树的深度相差不超过 1。

**示例 1：**

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,5,null,-3,null,9] 也将被视为正确答案
```

**示例 2：**

```
输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按严格递增顺序排列

## 解题思路

这道题结合了二叉搜索树（BST）和平衡树的概念，核心思路是利用**有序数组 + 二分法**。

**关键观察**：
1. 二叉搜索树的中序遍历结果是有序的
2. 要构造平衡二叉搜索树，需要让左右子树的节点数量尽可能相等
3. 取有序数组的中间元素作为根节点，左半部分构造左子树，右半部分构造右子树
4. 这样可以保证每个节点的左右子树高度差不超过 1

**算法流程**：
1. 选择数组的中间元素作为根节点
2. 递归地将中间元素左边的部分构造成左子树
3. 递归地将中间元素右边的部分构造成右子树
4. 返回根节点

**为什么这样能保证平衡**：
- 每次都选择中间元素，左右两边的元素数量最多相差 1
- 递归地在每个子树中也选择中间元素
- 最终得到的树左右子树高度差不会超过 1

## Python 代码实现

### 方法一：递归 + 中序分割（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def build(left: int, right: int) -> Optional[TreeNode]:
            """
            使用索引范围构建平衡二叉搜索树
            left: 左边界（包含）
            right: 右边界（包含）
            """
            # 递归终止条件：区间为空
            if left > right:
                return None
            
            # 选择中间位置的元素作为根节点
            # 如果有两个中间元素，选择偏左的（也可以选择偏右的）
            mid = (left + right) // 2
            
            # 创建根节点
            root = TreeNode(nums[mid])
            
            # 递归构建左子树和右子树
            root.left = build(left, mid - 1)
            root.right = build(mid + 1, right)
            
            return root
        
        return build(0, len(nums) - 1)
```

### 方法二：递归 + 数组切片（易理解版）

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        # 递归终止条件：数组为空
        if not nums:
            return None
        
        # 找到中间位置
        mid = len(nums) // 2
        
        # 创建根节点
        root = TreeNode(nums[mid])
        
        # 递归构建左子树和右子树
        root.left = self.sortedArrayToBST(nums[:mid])
        root.right = self.sortedArrayToBST(nums[mid+1:])
        
        return root
```

### 方法三：选择中间偏右的元素

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def build(left: int, right: int) -> Optional[TreeNode]:
            if left > right:
                return None
            
            # 选择中间偏右的元素作为根节点
            # 对于偶数长度的数组，会选择右边的中间元素
            mid = (left + right + 1) // 2
            
            root = TreeNode(nums[mid])
            root.left = build(left, mid - 1)
            root.right = build(mid + 1, right)
            
            return root
        
        return build(0, len(nums) - 1)
```

### 方法四：迭代法（使用栈）

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        
        # 栈中存储 (节点, 左边界, 右边界)
        mid = len(nums) // 2
        root = TreeNode(nums[mid])
        stack = [(root, 0, len(nums) - 1)]
        
        while stack:
            node, left, right = stack.pop()
            mid = (left + right) // 2
            
            # 处理左子树
            if left <= mid - 1:
                left_mid = (left + mid - 1) // 2
                node.left = TreeNode(nums[left_mid])
                stack.append((node.left, left, mid - 1))
            
            # 处理右子树
            if mid + 1 <= right:
                right_mid = (mid + 1 + right) // 2
                node.right = TreeNode(nums[right_mid])
                stack.append((node.right, mid + 1, right))
        
        return root
```

## 复杂度分析

### 方法一、三、四

- **时间复杂度**：O(n)，其中 n 是数组的长度。每个元素都需要创建一个节点。
- **空间复杂度**：O(log n)，递归调用栈的深度为树的高度，平衡二叉树的高度是 O(log n)。

### 方法二

- **时间复杂度**：O(n log n)，虽然每个节点只访问一次，但每次递归都创建了新的数组切片。
- **空间复杂度**：O(n log n)，数组切片会创建新的数组副本。

## 关键点总结

1. **利用有序性**：数组已排序，中序遍历的结果就是原数组
2. **二分思想**：每次选择中间元素，保证左右子树平衡
3. **索引优于切片**：使用索引范围比切片数组效率更高
4. **中间元素选择**：
   - `(left + right) // 2`：选择中间偏左
   - `(left + right + 1) // 2`：选择中间偏右
   - 两种方式都能得到平衡树，只是结构可能不同
5. **递归模板**：这是分治算法的经典应用

## 易错点

1. **边界条件**：递归终止条件是 `left > right` 而不是 `left >= right`
2. **中间位置计算**：要注意整数除法，确保索引不越界
3. **切片性能**：方法二虽然代码简洁，但性能较差，面试时要说明
4. **平衡理解**：要理解平衡二叉树的定义（高度差 ≤ 1）
5. **多解情况**：这道题可能有多个正确答案，只要满足平衡性即可
