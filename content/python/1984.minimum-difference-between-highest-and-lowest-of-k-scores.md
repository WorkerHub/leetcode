## 题目描述

给你一个整数数组 `nums` 和整数 `k`。从 `nums` 中选择 `k` 个数，使这 k 个数中**最大值和最小值的差**最小。

返回这个**最小差值**。

**示例 1：**
```
输入：nums = [90], k = 1
输出：0
```

**示例 2：**
```
输入：nums = [9,4,1,7], k = 2
输出：2
解释：选 {7,9} 差为 2，选 {4,7} 差为 3，选 {1,4} 差为 3
```

**提示：**
- `1 <= k <= nums.length <= 1000`
- `0 <= nums[i] <= 10^5`

---

## 解题思路

### 核心思想：排序 + 滑动窗口

为了让 k 个数的最大值和最小值差最小，这 k 个数应该是**有序数组中连续的 k 个**（极差等于 `nums[i+k-1] - nums[i]`）。

排序后枚举每个起始位置 `i`，取 `nums[i+k-1] - nums[i]` 的最小值。

---

## 代码实现

### 方法一：排序 + 滑动窗口（推荐）

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        ans = float('inf')
        for i in range(n - k + 1):
            # 连续 k 个元素的最大差
            ans = min(ans, nums[i + k - 1] - nums[i])
        return ans
```

### 方法二：Python 一行

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        nums.sort()
        # 用 min 和 zip 求所有长度 k 的窗口差
        return min(b - a for a, b in zip(nums, nums[k - 1:]))
```

### 方法三：手动维护最小差

```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        if k == 1:
            return 0
        nums.sort()
        ans = nums[k - 1] - nums[0]
        for i in range(1, len(nums) - k + 1):
            diff = nums[i + k - 1] - nums[i]
            if diff < ans:
                ans = diff
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n log n) | O(1) |
| 方法二 | O(n log n) | O(n) |

---

## 关键点总结

1. 排序后，极差最小的 k 个数一定是连续段
2. 枚举所有长度 k 的窗口，取最小差

---

## 易错点

- `k == 1` 时答案为 0（单个数字差为 0）
- 下标范围：`i + k - 1 <= n - 1`，即 `i <= n - k`
