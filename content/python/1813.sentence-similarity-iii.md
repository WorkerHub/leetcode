## 题目描述

一个句子是由若干单词组成的字符串，单词之间用单个空格分隔，没有前导或尾随空格。

如果两个句子 `sentence1` 和 `sentence2` 满足以下条件之一，则它们是**相似的**：
- 它们相同
- `sentence1`（或 `sentence2`）在某个地方插入一个任意句子后，等于 `sentence2`（或 `sentence1`）

换句话说，`sentence1` 和 `sentence2` 都是某一个更长句子的前缀加后缀。

**示例 1：**
```
输入：sentence1 = "My name is Haley", sentence2 = "My Haley"
输出：true
```

**示例 2：**
```
输入：sentence1 = "of", sentence2 = "A lot of words"
输出：false
```

**提示：**
- 两个句子均由小写和大写英文字母及空格组成

## 解题思路

**双指针**：将两个句子各自分割为单词列表。从前向后匹配前缀，从后向前匹配后缀，若前后缀加起来覆盖了较短句子的所有单词，则相似。

具体步骤：
1. 分割两个句子得到 words1 和 words2，令较短的为 s，较长的为 l
2. 用双指针 i（从左）和 j（从右）在 l 上匹配 s 的前后缀
3. 若 i + j >= len(s)，说明 s 完全被覆盖，返回 True

## 代码实现

### 方法一：双指针匹配前后缀（推荐）

```python
class Solution:
    def areSentencesSimilar(self, sentence1: str, sentence2: str) -> bool:
        words1 = sentence1.split()
        words2 = sentence2.split()

        # 令 s 为较短句子，l 为较长句子
        if len(words1) > len(words2):
            words1, words2 = words2, words1
        s, l = words1, words2

        i = 0  # 从左匹配的指针
        j = 0  # 从右匹配的指针（表示已从右匹配的个数）

        # 从左匹配前缀
        while i < len(s) and s[i] == l[i]:
            i += 1

        # 从右匹配后缀
        while j < len(s) - i and s[len(s) - 1 - j] == l[len(l) - 1 - j]:
            j += 1

        # 若 i+j 覆盖了 s 的所有单词，则相似
        return i + j >= len(s)
```

### 方法二：deque 双端队列

```python
from collections import deque

class Solution:
    def areSentencesSimilar(self, sentence1: str, sentence2: str) -> bool:
        d1 = deque(sentence1.split())
        d2 = deque(sentence2.split())

        # 匹配前缀
        while d1 and d2 and d1[0] == d2[0]:
            d1.popleft()
            d2.popleft()

        # 匹配后缀
        while d1 and d2 and d1[-1] == d2[-1]:
            d1.pop()
            d2.pop()

        # 其中一个队列为空，说明另一个可以插入中间
        return not d1 or not d2
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 和 m 为两句子的单词数
- **空间复杂度**：O(n + m)，存储分割后的单词列表

## 关键点总结

1. 转化为单词列表后，问题变为：较短列表能否由较长列表的前缀和后缀拼接而成
2. 双指针分别从两端向中间匹配，前后缀不重叠
3. deque 方法更直观：逐步消去相同前缀和后缀，若较短句子被完全消去则相似

## 易错点

- 前后缀匹配时不能重叠：`while j < len(s) - i` 条件保证了这一点
- 不需要句子等长才能相似，较短的可以完全包含在较长的前后缀中
