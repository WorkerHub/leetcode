## 题目描述

给你一个下标从 0 开始长度为 `n` 的整数数组 `nums`。对每个下标 `i`，`arr[i]` 等于 `nums` 中与 `i` 不同下标且值等于 `nums[i]` 的其他下标 `j` 的绝对差之和，即 `arr[i] = sum(|i - j|)`（对所有 `j != i` 且 `nums[j] == nums[i]`）。

返回数组 `arr`。

**示例 1：**
```
输入：nums = [1,3,1,1,2]
输出：[5,0,3,4,0]
解释：
- arr[0] = |0-2|+|0-3| = 5
- arr[1] = 0（只有一个 3）
- arr[2] = |2-0|+|2-3| = 3
- arr[3] = |3-0|+|3-2| = 4
- arr[4] = 0（只有一个 2）
```

**示例 2：**
```
输入：nums = [0,5,3]
输出：[0,0,0]
```

**数据范围：**
- 1 <= n <= 10^5
- 0 <= nums[i] <= 10^9

## 解题思路

前缀和优化：

对每个值，将其所有出现位置收集起来，设为有序数组 `indices = [i0, i1, ..., im]`。

对位置 `indices[k]`，其与其他位置的绝对差之和可以用前缀和计算：
- 左侧贡献：`indices[k] * k - prefix[k]`
- 右侧贡献：`(prefix[m] - prefix[k]) - indices[k] * (m - k)`

其中 `prefix[k] = sum(indices[0..k-1])`。

## Python 代码实现

### 方法一：哈希表 + 前缀和（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def distance(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n
        # 按值分组，收集同值元素的下标
        groups = defaultdict(list)
        for i, x in enumerate(nums):
            groups[x].append(i)

        for val, indices in groups.items():
            m = len(indices)
            if m == 1:
                continue  # 只有一个，距离为 0
            # 构建前缀和
            prefix = [0] * (m + 1)
            for j, idx in enumerate(indices):
                prefix[j + 1] = prefix[j] + idx

            for k, idx in enumerate(indices):
                # 左侧：k 个元素，各距离之和
                left = idx * k - prefix[k]
                # 右侧：(m-1-k) 个元素，各距离之和
                right = (prefix[m] - prefix[k + 1]) - idx * (m - 1 - k)
                ans[idx] = left + right

        return ans
```

### 方法二：两次扫描

```python
from typing import List
from collections import defaultdict

class Solution:
    def distance(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n
        groups = defaultdict(list)
        for i, x in enumerate(nums):
            groups[x].append(i)

        for indices in groups.values():
            m = len(indices)
            # 第一次扫描：从左向右，计算前缀贡献
            prefix_sum = 0
            for k, idx in enumerate(indices):
                ans[idx] += idx * k - prefix_sum
                prefix_sum += idx

            # 第二次扫描：从右向左，计算后缀贡献
            suffix_sum = 0
            for k in range(m - 1, -1, -1):
                idx = indices[k]
                right_count = m - 1 - k
                ans[idx] += suffix_sum - idx * right_count
                suffix_sum += idx

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有分组
- 空间复杂度：O(n)，存储分组和前缀和

## 关键点总结

1. 分组处理，每组独立计算
2. 绝对差之和用前缀和优化为 O(n)
3. 对第 k 个位置：左侧贡献 = `idx * k - prefix[k]`，右侧贡献 = `suffix - idx * right_count`

## 易错点

1. 注意前缀和的下标对齐
2. 只有一个元素的组答案为 0，无需计算
3. 下标可能很大，用 long 类型（Python 无需担心）
