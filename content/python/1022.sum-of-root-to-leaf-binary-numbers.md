## 题目描述

给你一个二叉树的根节点 `root`，树中每个节点的值只有 `0` 或 `1`。每一条从根节点到叶节点的路径都代表一个从最高有效位开始的二进制数。

- 例如，如果路径为 `0 -> 1 -> 1 -> 0 -> 1`，那么这可以表示为 `01101`，也就是十进制的 `13`。

对于树中的每一片叶子，我们都要找出从根节点到该叶子节点的路径所表示的数字。

返回这些数字之和。题目数据保证答案是一个 32 位整数。

**示例 1：**

```
输入：root = [1,0,1,0,1,0,1]
输出：22
解释：(100) + (101) + (110) + (111) = 4 + 5 + 6 + 7 = 22
```

**示例 2：**

```
输入：root = [0]
输出：0
```

**提示：**

- 树中节点的数目在范围 `[1, 1000]` 内
- `Node.val` 仅为 `0` 或 `1`

## 解题思路

这道题的核心思想是**深度优先搜索（DFS）**遍历二叉树，同时记录从根节点到当前节点的路径所形成的二进制数。

**关键观察：**

1. 每条从根到叶子的路径代表一个二进制数
2. 当我们从父节点移动到子节点时，相当于二进制数左移一位（乘以 2），然后加上当前节点的值
3. 例如：如果父节点的值是 `5`（二进制 `101`），当前节点值为 `1`，那么当前路径值为 `5 * 2 + 1 = 11`（二进制 `1011`）

**算法流程：**

1. 使用 DFS 遍历树，同时传递当前路径形成的数值
2. 对于每个节点，更新当前数值：`current_value = parent_value * 2 + node.val`
3. 如果到达叶子节点，将该路径的值累加到结果中
4. 递归处理左右子树

## Python 代码实现

### 方法一：递归 DFS（推荐）⭐

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        """
        使用递归 DFS 计算所有根到叶子路径的二进制数之和
        """
        def dfs(node: Optional[TreeNode], current_value: int) -> int:
            """
            递归函数
            node: 当前节点
            current_value: 从根到当前节点父节点的路径值
            返回: 当前子树所有路径的和
            """
            if not node:
                return 0
            
            # 更新当前路径的值：左移一位（乘2）+ 当前节点值
            current_value = current_value * 2 + node.val
            
            # 如果是叶子节点，返回当前路径的值
            if not node.left and not node.right:
                return current_value
            
            # 递归计算左右子树的和
            left_sum = dfs(node.left, current_value)
            right_sum = dfs(node.right, current_value)
            
            return left_sum + right_sum
        
        return dfs(root, 0)
```

**代码说明：**
- 时间复杂度：O(n)，其中 n 是树中节点的数量，每个节点访问一次
- 空间复杂度：O(h)，其中 h 是树的高度，递归栈的深度

### 方法二：迭代 DFS（使用栈）

```python
from typing import Optional

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        """
        使用栈实现迭代 DFS
        """
        if not root:
            return 0
        
        total_sum = 0
        # 栈中存储 (节点, 当前路径值) 的元组
        stack = [(root, 0)]
        
        while stack:
            node, current_value = stack.pop()
            
            # 更新当前路径值
            current_value = current_value * 2 + node.val
            
            # 如果是叶子节点，累加到总和
            if not node.left and not node.right:
                total_sum += current_value
            
            # 将子节点加入栈（先右后左，保证左子树先处理）
            if node.right:
                stack.append((node.right, current_value))
            if node.left:
                stack.append((node.left, current_value))
        
        return total_sum
```

**代码说明：**
- 时间复杂度：O(n)
- 空间复杂度：O(h)，栈的最大深度为树的高度

### 方法三：位运算优化（简洁版）

```python
from typing import Optional

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        """
        使用位运算简化代码
        """
        def dfs(node: Optional[TreeNode], val: int) -> int:
            if not node:
                return 0
            
            # 左移一位并加上当前值，等价于 val * 2 + node.val
            val = (val << 1) | node.val
            
            # 叶子节点直接返回值
            if not node.left and not node.right:
                return val
            
            # 返回左右子树的和
            return dfs(node.left, val) + dfs(node.right, val)
        
        return dfs(root, 0)
```

**代码说明：**
- `val << 1` 等价于 `val * 2`（左移一位）
- `| node.val` 等价于 `+ node.val`（因为最后一位是 0）
- 代码更简洁，但可读性稍差

### 方法四：BFS（层序遍历）

```python
from typing import Optional
from collections import deque

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        """
        使用 BFS 层序遍历
        """
        if not root:
            return 0
        
        total_sum = 0
        queue = deque([(root, 0)])  # (节点, 当前路径值)
        
        while queue:
            node, current_value = queue.popleft()
            
            # 更新当前路径值
            current_value = current_value * 2 + node.val
            
            # 如果是叶子节点，累加到总和
            if not node.left and not node.right:
                total_sum += current_value
            
            # 将子节点加入队列
            if node.left:
                queue.append((node.left, current_value))
            if node.right:
                queue.append((node.right, current_value))
        
        return total_sum
```

**代码说明：**
- 使用队列实现 BFS
- 时间复杂度：O(n)
- 空间复杂度：O(w)，其中 w 是树的最大宽度

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 递归 DFS | O(n) | O(h) |
| 迭代 DFS | O(n) | O(h) |
| 位运算优化 | O(n) | O(h) |
| BFS | O(n) | O(w) |

其中：
- n 是树中节点的数量
- h 是树的高度（最坏情况下 h = n，平衡树时 h = log n）
- w 是树的最大宽度（最坏情况下 w = n/2）

**路径分析：**

2. 路径 1 -> 0 -> 1：二进制 `101` = 十进制 `5`
3. 路径 1 -> 1 -> 0：二进制 `110` = 十进制 `6`

## 关键点总结

1. **路径值计算公式**：`current_value = parent_value * 2 + node.val`，这是将二进制数左移一位并加上新位的核心操作
2. **叶子节点判断**：只有在叶子节点才累加路径值，避免重复计算
3. **DFS 遍历**：可以使用递归或迭代实现，递归代码更简洁
4. **位运算技巧**：`(val << 1) | node.val` 可以替代 `val * 2 + node.val`
5. **边界处理**：空节点返回 0，单节点树直接返回节点值

## 易错点

1. **忘记判断叶子节点**：必须在叶子节点才累加值，否则会重复计算中间节点
   ```python
   # 错误写法
   if node:
       total_sum += current_value  # 会累加所有节点！
   
   # 正确写法
   if not node.left and not node.right:
       total_sum += current_value  # 只累加叶子节点
   ```

2. **初始值传递错误**：起始时应传递 0，而不是 root.val
   ```python
   # 错误
   dfs(root, root.val)  # 重复计算了根节点
   
   # 正确
   dfs(root, 0)  # 在函数内部计算
   ```

3. **空树处理**：虽然题目保证至少有一个节点，但良好的习惯是处理空树情况
   ```python
   if not root:
       return 0
   ```

4. **整数溢出**：题目保证答案在 32 位整数范围内，但如果树很深，中间计算可能溢出（Python 自动处理大整数，无需担心）
