## 题目描述

给你一个整数数组 `nums`。

对于 `i < j`，若 `j - i != nums[j] - nums[i]`，则称 `(i, j)` 是一个**坏对**。

返回所有坏对的数量。

**示例：**
```
输入：nums = [4, 1, 3, 3]
输出：5
解释：共6对，好对为 (0,1)：1-0=1=1-4? 不对... 
j-i != nums[j]-nums[i]
(0,1): 1 != 1-4=-3, bad
...
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**好对的条件：** `j - i == nums[j] - nums[i]`，变形为 `nums[j] - j == nums[i] - i`。

定义 `key[i] = nums[i] - i`，则好对 `(i, j)` 当且仅当 `key[i] == key[j]`。

**方案：** 统计所有好对数，用总对数减去得坏对数。

好对数 = `sum(C(cnt, 2))` 对每个 `key` 值，`cnt` 是该值出现的次数。

总对数 = `C(n, 2) = n*(n-1)//2`。

## Python 代码实现

### 方法一：哈希表统计（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def countBadPairs(self, nums: List[int]) -> int:
        n = len(nums)
        total_pairs = n * (n - 1) // 2
        
        # 计算每个 key = nums[i] - i 的出现次数
        keys = Counter(nums[i] - i for i in range(n))
        
        # 好对数 = sum(C(cnt, 2)) for each key
        good_pairs = sum(cnt * (cnt - 1) // 2 for cnt in keys.values())
        
        return total_pairs - good_pairs
```

### 方法二：直接计算

```python
from typing import List
from collections import defaultdict

class Solution:
    def countBadPairs(self, nums: List[int]) -> int:
        n = len(nums)
        freq = defaultdict(int)
        bad = 0
        
        for i, x in enumerate(nums):
            key = x - i
            # i 之前与 key 不同的数有 i - freq[key] 个，都形成坏对
            bad += i - freq[key]
            freq[key] += 1
        
        return bad
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表操作
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 好对 `(i, j)` 等价于 `nums[i] - i == nums[j] - j`，即差相同。
2. 坏对数 = 总对数 - 好对数。
3. 用哈希表统计每个差值的频率，计算好对数用组合数。

## 易错点

1. `key = nums[i] - i`（而不是 `nums[i] + i`）。
2. 总对数 = `n*(n-1)//2`（组合数 C(n,2)）。
3. 好对数 = 每组 key 内的组合数之和。
