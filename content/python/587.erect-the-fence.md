## 题目描述

给定平面上的一些点，求凸包。凸包是包含所有点的最小凸多边形。

**示例：**
```
输入：points = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]
输出：[[1,1],[2,0],[4,2],[3,3],[2,4]]
```

**提示：**
- `1 <= points.length <= 3000`
- `points[i].length == 2`
- `0 <= xi, yi <= 10^4`
- 所有点互不相同

## 解题思路

使用Graham扫描算法或Jarvis步进算法求凸包。

## Python 代码实现

### 方法一：Graham扫描（推荐）⭐

```python
from typing import List

class Solution:
    def outerTrees(self, points: List[List[int]]) -> List[List[int]]:
        """
        Graham扫描算法
        
        时间复杂度：O(n log n)
        空间复杂度：O(n)
        """
        def cross(o, a, b):
            """计算叉积"""
            return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
        
        points = sorted(points)
        if len(points) <= 1:
            return points
        
        # 构建下凸包
        lower = []
        for p in points:
            while len(lower) >= 2 and cross(lower[-2], lower[-1], p) < 0:
                lower.pop()
            lower.append(p)
        
        # 构建上凸包
        upper = []
        for p in reversed(points):
            while len(upper) >= 2 and cross(upper[-2], upper[-1], p) < 0:
                upper.pop()
            upper.append(p)
        
        # 合并并去重
        return list(map(list, set(map(tuple, lower[:-1] + upper[:-1]))))
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. **凸包算法**：Graham扫描
2. **叉积**：判断点的位置关系
3. **排序**：按x坐标排序
