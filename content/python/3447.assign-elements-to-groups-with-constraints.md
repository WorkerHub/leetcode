## 题目描述

给你两个整数数组 `groups` 和 `elements`。

第 i 组 `groups[i]` 需要被分配一个"代表元素"，要求该代表元素是 `groups[i]` 的**因子**。如果 `elements` 中存在 `groups[i]` 的因子，则该组的代表元素是 `elements` 中下标**最小**的那个因子。否则代表元素缺失（用 -1 表示）。

返回数组 `assigned`，其中 `assigned[i]` 是第 i 组的代表元素在 `elements` 中的**下标**（如果存在），否则为 -1。

**示例 1：**

```
输入：groups = [8,4,3,2,4], elements = [4,2,1]
输出：[0,0,2,1,0]
解释：
- 8 的因子在 elements 中：4(下标0), 2(下标1), 1(下标2)，取最小下标 0
- 4 的因子：4(0), 2(1), 1(2)，取 0
- 3 的因子：1(2)，取 2
- 2 的因子：2(1), 1(2)，取 1
- 4 同上，取 0
```

**提示：**
- `1 <= groups.length <= 10^5`
- `1 <= elements.length <= 10^5`
- `1 <= groups[i] <= 10^5`
- `1 <= elements[i] <= 10^5`

## 解题思路

对于每个 `groups[i]`，需要找 `elements` 中**最早出现**的 `groups[i]` 的因子。

预处理：构建因子到元素最小下标的映射。

对每个 `elements[j]`，它的所有倍数 `elements[j], 2*elements[j], ...` 都能被 `elements[j]` 整除，所以如果某个 `groups[i]` 是 `elements[j]` 的倍数，那么 `elements[j]` 是 `groups[i]` 的因子。

方法：
1. 对每个元素值 `v = elements[j]`，用**最小下标哈希表** `val_to_idx[v] = min(val_to_idx[v], j)`
2. 对每个 `groups[i]`，枚举其所有因子，找在 `val_to_idx` 中出现且下标最小的

但枚举因子需要 O(sqrt(g))，总复杂度 O(n * sqrt(max_g))。

另一种方法：对每个 `elements[j]` 的值 v，标记它能覆盖的倍数（筛法）。

## Python 代码实现

### 方法一：筛法（推荐）

```python
from typing import List

class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        MAX_VAL = max(max(groups), max(elements)) + 1

        # val_to_idx[v] = elements 中值为 v 的最小下标（若不存在则 inf）
        val_to_idx = [float('inf')] * MAX_VAL
        for j, v in enumerate(elements):
            if v < MAX_VAL:
                val_to_idx[v] = min(val_to_idx[v], j)

        # best[g] = groups[i]=g 时，elements 中 g 的因子的最小下标
        best = [float('inf')] * MAX_VAL

        # 筛法：对每个 v，标记其所有倍数
        for v in range(1, MAX_VAL):
            if val_to_idx[v] == float('inf'):
                continue
            idx = val_to_idx[v]
            # v 的倍数：v, 2v, 3v, ...
            multiple = v
            while multiple < MAX_VAL:
                best[multiple] = min(best[multiple], idx)
                multiple += v

        result = []
        for g in groups:
            if g < MAX_VAL and best[g] < float('inf'):
                result.append(best[g])
            else:
                result.append(-1)

        return result
```

### 方法二：直接枚举因子

```python
from typing import List
import math

class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        # 建立值到最小下标的映射
        val_to_idx = {}
        for j, v in enumerate(elements):
            if v not in val_to_idx:
                val_to_idx[v] = j

        result = []
        for g in groups:
            best_idx = -1
            # 枚举 g 的所有因子
            i = 1
            while i * i <= g:
                if g % i == 0:
                    if i in val_to_idx:
                        idx = val_to_idx[i]
                        if best_idx == -1 or idx < best_idx:
                            best_idx = idx
                    if i != g // i and (g // i) in val_to_idx:
                        idx = val_to_idx[g // i]
                        if best_idx == -1 or idx < best_idx:
                            best_idx = idx
                i += 1
            result.append(best_idx)

        return result
```

## 复杂度分析

- 方法一（筛法）：
  - 时间复杂度：O(MAX_VAL * log(MAX_VAL))，调和级数
  - 空间复杂度：O(MAX_VAL)

- 方法二（枚举因子）：
  - 时间复杂度：O(n * sqrt(max_g))
  - 空间复杂度：O(n)

## 关键点总结

1. 筛法：对每个出现在 elements 中的值 v，标记其所有倍数
2. 每个 groups[i] 直接查表得到最优元素下标
3. 筛法时间复杂度优于逐一枚举因子

## 易错点

1. 要找元素在 elements 中的最小下标（而不是最小值）
2. 同一值 v 可能在 elements 中多次出现，取最小下标
3. MAX_VAL 要设为 max(groups + elements) + 1
