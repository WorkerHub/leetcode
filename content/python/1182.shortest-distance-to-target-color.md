## 题目描述

[LeetCode 1182. Shortest Distance To Target Color](https://leetcode.com/problems/shortest-distance-to-target-color/)

给定一个数组 `colors`，其中 `colors[i]` 是颜色 `1`、`2` 或 `3`。

再给定一些查询 `queries`，每个查询包含两个整数 `i` 和 `c`，返回从索引 `i` 到目标颜色 `c` 的最短距离。如果没有找到目标颜色，返回 `-1`。

**示例 1:**

```
输入: colors = [1,1,2,1,3,2,2,3,3], queries = [[1,3],[2,2],[6,1]]
输出: [3,0,3]
解释: 
距离索引 1 最近的颜色 3 在索引 4，距离为 3。
距离索引 2 最近的颜色 2 就是自己，距离为 0。
距离索引 6 最近的颜色 1 在索引 3，距离为 3。
```

**示例 2:**

```
输入: colors = [1,2], queries = [[0,3]]
输出: [-1]
解释: 数组中没有颜色 3。
```

**提示:**

- `1 <= colors.length <= 5 * 10^4`
- `1 <= colors[i] <= 3`
- `1 <= queries.length <= 5 * 10^4`
- `queries[i].length == 2`
- `0 <= queries[i][0] < colors.length`
- `1 <= queries[i][1] <= 3`

## 解题思路

这道题需要高效地处理多个查询，核心思想是**预处理**，避免每次查询都重新搜索。

**关键观察**：
1. 颜色只有 3 种（1, 2, 3），可以为每种颜色单独处理
2. 对于每个位置，我们需要知道最近的各种颜色位置
3. 预处理可以用动态规划：从左到右扫描一次，从右到左扫描一次

**算法流程（动态规划）**：
1. 创建两个数组：`left[i][c]` 和 `right[i][c]`
   - `left[i][c]`：从左边最近的颜色 c 到位置 i 的距离
   - `right[i][c]`：从右边最近的颜色 c 到位置 i 的距离
2. 对于每个查询 `(i, c)`，答案是 `min(left[i][c], right[i][c])`

## Python 代码实现

### 方法一：动态规划预处理（推荐）

```python
from typing import List

class Solution:
    def shortestDistanceColor(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        """
        使用动态规划预处理每个位置到各种颜色的最短距离
        """
        n = len(colors)
        INF = float('inf')
        
        # left[i][c] 表示位置 i 左边（包括 i）最近的颜色 c 的距离
        left = [[INF] * 4 for _ in range(n)]  # 颜色是 1, 2, 3，索引 0 不使用
        # right[i][c] 表示位置 i 右边（包括 i）最近的颜色 c 的距离
        right = [[INF] * 4 for _ in range(n)]
        
        # 从左向右扫描
        for i in range(n):
            # 当前位置的颜色
            color = colors[i]
            
            if i == 0:
                left[i][color] = 0
            else:
                # 继承上一个位置的距离
                for c in range(1, 4):
                    if left[i - 1][c] != INF:
                        left[i][c] = left[i - 1][c] + 1
                # 当前位置的颜色距离为 0
                left[i][color] = 0
        
        # 从右向左扫描
        for i in range(n - 1, -1, -1):
            color = colors[i]
            
            if i == n - 1:
                right[i][color] = 0
            else:
                # 继承下一个位置的距离
                for c in range(1, 4):
                    if right[i + 1][c] != INF:
                        right[i][c] = right[i + 1][c] + 1
                # 当前位置的颜色距离为 0
                right[i][color] = 0
        
        # 处理查询
        result = []
        for i, c in queries:
            dist = min(left[i][c], right[i][c])
            result.append(dist if dist != INF else -1)
        
        return result
```

### 方法二：记录每种颜色的位置 + 二分查找

```python
from typing import List
from collections import defaultdict
import bisect

class Solution:
    def shortestDistanceColor(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        """
        记录每种颜色的所有位置，使用二分查找
        """
        # 记录每种颜色出现的所有位置
        color_positions = defaultdict(list)
        for i, color in enumerate(colors):
            color_positions[color].append(i)
        
        result = []
        
        for idx, color in queries:
            if color not in color_positions:
                result.append(-1)
                continue
            
            positions = color_positions[color]
            
            # 二分查找插入位置
            pos = bisect.bisect_left(positions, idx)
            
            min_dist = float('inf')
            
            # 检查左边的位置
            if pos > 0:
                min_dist = min(min_dist, abs(idx - positions[pos - 1]))
            
            # 检查右边的位置
            if pos < len(positions):
                min_dist = min(min_dist, abs(idx - positions[pos]))
            
            result.append(min_dist if min_dist != float('inf') else -1)
        
        return result
```

### 方法三：暴力查找（用于对比）

```python
from typing import List

class Solution:
    def shortestDistanceColor(self, colors: List[int], queries: List[List[int]]) -> List[int]:
        """
        对每个查询暴力搜索，适合查询数量少的情况
        """
        result = []
        
        for idx, target_color in queries:
            min_dist = float('inf')
            
            # 向左搜索
            for i in range(idx, -1, -1):
                if colors[i] == target_color:
                    min_dist = min(min_dist, idx - i)
                    break
            
            # 向右搜索
            for i in range(idx, len(colors)):
                if colors[i] == target_color:
                    min_dist = min(min_dist, i - idx)
                    break
            
            result.append(min_dist if min_dist != float('inf') else -1)
        
        return result
```

## 复杂度分析

### 方法一（动态规划）：
- 时间复杂度：O(n + q)
  - n 为 colors 数组长度，需要扫描两次
  - q 为查询数量，每个查询 O(1)
- 空间复杂度：O(n)，需要存储 left 和 right 数组

### 方法二（二分查找）：
- 时间复杂度：O(n + q * log n)
  - 预处理需要 O(n)
  - 每个查询需要 O(log n) 的二分查找
- 空间复杂度：O(n)，存储颜色位置

### 方法三（暴力）：
- 时间复杂度：O(q * n)，每个查询最坏需要扫描整个数组
- 空间复杂度：O(1)，只用常数空间

## 关键点总结

1. **预处理思想**：当查询数量很多时，预处理可以大幅提升效率
2. **双向扫描**：从左到右和从右到左各扫描一次，得到双向的最短距离
3. **二分查找**：记录位置后可以用二分查找快速定位
4. **空间换时间**：方法一和方法二都是典型的空间换时间策略
5. **数据范围小**：颜色只有 3 种，可以直接用数组而不是字典

## 易错点

1. **初始化为无穷大**：用 `float('inf')` 表示没有找到颜色
2. **数组索引**：颜色是 1, 2, 3，如果用数组存储要注意索引映射
3. **边界处理**：第一个和最后一个位置需要特殊处理
4. **二分查找边界**：使用 bisect 后要检查左右两个位置
5. **返回 -1**：找不到颜色时要返回 -1，不是无穷大
