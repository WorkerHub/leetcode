## 题目描述

现有函数 `printNumber` 可以用一个整数参数调用，并输出该整数到控制台。

- 例如，调用 `printNumber(7)` 将会输出 `7` 到控制台。

给你类 `ZeroEvenOdd` 的一个实例，该类中有三个函数：`zero`、`even` 和 `odd`。`ZeroEvenOdd` 的相同实例将会传递给三个不同线程：

- 线程 A：调用 `zero()` ，只输出 `0`
- 线程 B：调用 `even()` ，只输出偶数
- 线程 C：调用 `odd()` ，只输出奇数

修改给出的类，以输出序列 `"010203040506..."` ，其中序列的长度必须为 `2n`。

**示例 1:**
```
输入：n = 2
输出："0102"
解释：三条线程异步执行，其中一个调用 zero()，另一个调用 even()，最后一个调用 odd()。正确的输出为 "0102"。
```

**示例 2:**
```
输入：n = 5
输出："0102030405"
```

## 解题思路

这道题需要协调三个线程的执行顺序，输出规律是：
- 0 → 1 → 0 → 2 → 0 → 3 → 0 → 4 → ...
- 即：zero 和奇偶数交替，奇偶数本身也交替

**核心思想：**
1. zero 线程执行 2n 次（每个数字前都有 0）
2. odd 线程执行 n 次（输出 1, 3, 5, ...）
3. even 线程执行 n 次（输出 2, 4, 6, ...）

**执行顺序：**
```
zero → odd → zero → even → zero → odd → zero → even → ...
```

**使用信号量控制：**
- `zero_sem`：控制 zero 的执行
- `odd_sem`：控制 odd 的执行
- `even_sem`：控制 even 的执行

## Python 代码实现

### 方法一：使用信号量（推荐）

```python
from threading import Semaphore

class ZeroEvenOdd:
    def __init__(self, n: int):
        self.n = n
        # zero 初始可执行，odd 和 even 需要等待
        self.zero_sem = Semaphore(1)
        self.odd_sem = Semaphore(0)
        self.even_sem = Semaphore(0)
        
    def zero(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(self.n):
            self.zero_sem.acquire()  # 获取 zero 信号量
            printNumber(0)            # 打印 0
            
            # 根据当前轮次判断释放 odd 还是 even
            if i % 2 == 0:  # 第 0, 2, 4... 次，下一个应该是奇数
                self.odd_sem.release()
            else:  # 第 1, 3, 5... 次，下一个应该是偶数
                self.even_sem.release()
    
    def even(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(2, self.n + 1, 2):  # 2, 4, 6, ...
            self.even_sem.acquire()  # 等待 even 信号量
            printNumber(i)            # 打印偶数
            self.zero_sem.release()   # 释放 zero 信号量
    
    def odd(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1, 2):  # 1, 3, 5, ...
            self.odd_sem.acquire()   # 等待 odd 信号量
            printNumber(i)            # 打印奇数
            self.zero_sem.release()   # 释放 zero 信号量
```

### 方法二：使用锁

```python
from threading import Lock

class ZeroEvenOdd:
    def __init__(self, n: int):
        self.n = n
        self.zero_lock = Lock()
        self.odd_lock = Lock()
        self.even_lock = Lock()
        # odd 和 even 初始锁定
        self.odd_lock.acquire()
        self.even_lock.acquire()
        
    def zero(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(self.n):
            self.zero_lock.acquire()
            printNumber(0)
            
            # 交替释放 odd 和 even
            if i % 2 == 0:
                self.odd_lock.release()
            else:
                self.even_lock.release()
    
    def even(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(2, self.n + 1, 2):
            self.even_lock.acquire()
            printNumber(i)
            self.zero_lock.release()
    
    def odd(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1, 2):
            self.odd_lock.acquire()
            printNumber(i)
            self.zero_lock.release()
```

### 方法三：使用条件变量

```python
from threading import Condition

class ZeroEvenOdd:
    def __init__(self, n: int):
        self.n = n
        self.cond = Condition()
        self.flag = 0  # 0: zero, 1: odd, 2: even
        self.num = 1   # 当前要打印的数字
        
    def zero(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(self.n):
            with self.cond:
                # 等待 flag == 0
                while self.flag != 0:
                    self.cond.wait()
                printNumber(0)
                # 根据当前数字奇偶性决定下一个 flag
                self.flag = 1 if self.num % 2 == 1 else 2
                self.cond.notify_all()
    
    def even(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(2, self.n + 1, 2):
            with self.cond:
                # 等待 flag == 2
                while self.flag != 2:
                    self.cond.wait()
                printNumber(self.num)
                self.num += 1
                self.flag = 0
                self.cond.notify_all()
    
    def odd(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1, 2):
            with self.cond:
                # 等待 flag == 1
                while self.flag != 1:
                    self.cond.wait()
                printNumber(self.num)
                self.num += 1
                self.flag = 0
                self.cond.notify_all()
```

## 复杂度分析

**时间复杂度：** O(n)
- 每个线程执行次数为 O(n)

**空间复杂度：** O(1)
- 只使用固定的同步对象

## 关键点总结

1. **理解输出规律：** zero 和 奇/偶 交替，奇偶本身也交替
2. **信号量的初始状态：** zero_sem=1，其他=0
3. **奇偶判断：** 根据循环次数的奇偶性决定释放哪个信号量
4. **循环范围：** odd 是 1,3,5...；even 是 2,4,6...

## 易错点

1. **奇偶判断错误：** `i % 2 == 0` 时下一个应该是奇数（因为 i 从 0 开始）
2. **循环次数不对：** zero 循环 n 次，odd 和 even 各循环 ⌈n/2⌉ 和 ⌊n/2⌋ 次
3. **信号量释放错误：** odd/even 执行完要释放 zero_sem
4. **条件变量使用：** 必须用 while 而不是 if 检查条件
