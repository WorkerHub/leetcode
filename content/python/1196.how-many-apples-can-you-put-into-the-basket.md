## 题目描述

你有一些苹果和一个可以承载 `5000` 单位重量的篮子。

给定一个整数数组 `weight`，其中 `weight[i]` 是第 `i` 个苹果的重量，返回你可以放入篮子的最大苹果数量。

**示例 1：**
```
输入：weight = [100,200,150,1000]
输出：4
解释：所有 4 个苹果都可以装进篮子，因为它们的重量总和为 1450。
```

**示例 2：**
```
输入：weight = [900,950,800,1000,700,800]
输出：5
解释：6 个苹果的总重量超过了 5000，所以我们选择任意 5 个，它们的总重量不超过 5000。
```

**提示：**
- `1 <= weight.length <= 10^3`
- `1 <= weight[i] <= 10^3`

## 解题思路

这是一个典型的贪心问题，目标是在总重量不超过 5000 的前提下，装入尽可能多的苹果。

**核心思路：**

1. **贪心策略**：要装入更多的苹果，应该优先选择重量较轻的苹果。

2. **算法流程**：
   - 将苹果按重量从小到大排序
   - 依次将苹果放入篮子
   - 当篮子剩余容量不足时停止

3. **正确性证明**：
   - 假设最优解中包含某个重苹果而不包含某个轻苹果
   - 用轻苹果替换重苹果后，总重量更小，可能装入更多苹果
   - 因此贪心策略是最优的

## Python 代码实现

### 方法一：排序 + 贪心（推荐）⭐

```python
from typing import List

class Solution:
    def maxNumberOfApples(self, weight: List[int]) -> int:
        """
        贪心算法：优先选择重量最轻的苹果
        """
        # 按重量从小到大排序
        weight.sort()
        
        total_weight = 0
        count = 0
        
        # 依次尝试装入苹果
        for w in weight:
            if total_weight + w <= 5000:
                total_weight += w
                count += 1
            else:
                # 篮子已满，停止
                break
        
        return count
```

### 方法二：一行代码版本

```python
from typing import List
from itertools import accumulate

class Solution:
    def maxNumberOfApples(self, weight: List[int]) -> int:
        """
        使用 itertools.accumulate 计算累积和
        """
        weight.sort()
        return sum(w <= 5000 for w in accumulate(weight))
```

### 方法三：使用 bisect 查找

```python
from typing import List
from itertools import accumulate
import bisect

class Solution:
    def maxNumberOfApples(self, weight: List[int]) -> int:
        """
        使用二分查找找到临界点
        """
        weight.sort()
        cumsum = list(accumulate(weight))
        
        # 找到第一个超过 5000 的位置
        pos = bisect.bisect_right(cumsum, 5000)
        
        return pos
```

### 方法四：不使用额外空间

```python
from typing import List

class Solution:
    def maxNumberOfApples(self, weight: List[int]) -> int:
        """
        原地排序，节省空间
        """
        weight.sort()
        
        total = 0
        for i, w in enumerate(weight):
            total += w
            if total > 5000:
                return i
        
        # 所有苹果都可以装入
        return len(weight)
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(n log n)，其中 n 是苹果的数量，主要是排序的时间
- **空间复杂度**：O(log n)，排序所需的栈空间（Python 使用 Timsort）

**方法二、三：**
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)，accumulate 会创建新列表

**方法四：**
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)，原地排序

## 关键点总结

1. **贪心思想**：优先选择重量最小的苹果
2. **排序的必要性**：必须先排序才能应用贪心策略
3. **提前终止**：一旦超重就立即停止，避免无效计算
4. **边界情况**：所有苹果的总重量可能不超过 5000
5. **累积和的应用**：可以使用 `accumulate` 简化代码

## 易错点

1. **忘记排序**：直接遍历会导致错误结果
2. **边界判断**：判断 `total_weight + w <= 5000` 而非 `< 5000`
3. **提前返回**：如果所有苹果都能装入，不要忘记返回总数
4. **溢出问题**：虽然 Python 不存在整数溢出，但其他语言要注意
5. **修改原数组**：如果不能修改原数组，需要复制后再排序
