## 题目描述

有一个特殊的键盘，所有的键都排列在单行上。给定一个长度为 `26` 的字符串 `keyboard`，表示键盘的布局（从索引 `0` 到 `25` 按顺序排列）。最初，你的手指在索引 `0` 处。要输入一个字符，你必须将手指移动到该字符所需的索引位置。从索引 `i` 移动到索引 `j` 所需的时间是 `|i - j|`。

你想输入一个字符串 `word`。编写一个函数，计算用一根手指输入该字符串需要多少时间。

示例 1：

```
输入：keyboard = "abcdefghijklmnopqrstuvwxyz", word = "cba"
输出：4
解释：
索引从 0 移动到 2 输入 'c' 需要 2 个单位时间
索引从 2 移动到 1 输入 'b' 需要 1 个单位时间
索引从 1 移动到 0 输入 'a' 需要 1 个单位时间
总时间 = 2 + 1 + 1 = 4
```

示例 2：

```
输入：keyboard = "pqrstuvwxyzabcdefghijklmno", word = "leetcode"
输出：73
```

提示：

- `keyboard.length == 26`
- `keyboard` 包含每个英文小写字母恰好一次，且顺序可以不同
- `1 <= word.length <= 10^4`
- `word[i]` 是英文小写字母

## 解题思路

这是一道简单的模拟题，核心是计算移动距离的累加。

**关键观察：**

1. 需要快速查找每个字符在键盘上的位置（索引）
2. 每次移动的时间是当前位置到目标位置的绝对值差
3. 累加所有移动时间即可

**算法步骤：**

1. 使用哈希表建立字符到索引的映射
2. 初始化当前位置为 0
3. 遍历 word 中的每个字符：
   - 查找字符的索引位置
   - 计算移动时间（绝对值差）
   - 更新当前位置
4. 返回总时间

## Python 代码实现

### 方法一：哈希表（推荐）

```python
class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        """
        使用哈希表存储字符位置，快速查找
        
        时间复杂度：O(n)，n 是 word 的长度
        空间复杂度：O(26) = O(1)
        """
        # 建立字符到索引的映射
        char_to_index = {char: i for i, char in enumerate(keyboard)}
        
        current_pos = 0  # 当前手指位置
        total_time = 0  # 总时间
        
        for char in word:
            # 查找目标字符的位置
            target_pos = char_to_index[char]
            # 计算移动时间
            total_time += abs(current_pos - target_pos)
            # 更新当前位置
            current_pos = target_pos
        
        return total_time
```

### 方法二：使用 index 方法

```python
class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        """
        直接使用字符串的 index 方法查找位置
        
        时间复杂度：O(n * 26) = O(n)
        空间复杂度：O(1)
        """
        current_pos = 0
        total_time = 0
        
        for char in word:
            # 查找字符在 keyboard 中的索引
            target_pos = keyboard.index(char)
            total_time += abs(current_pos - target_pos)
            current_pos = target_pos
        
        return total_time
```

### 方法三：函数式编程风格

```python
from functools import reduce

class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        """
        使用 reduce 实现累加
        """
        char_to_index = {char: i for i, char in enumerate(keyboard)}
        
        def accumulate(acc, char):
            time, pos = acc
            new_pos = char_to_index[char]
            return (time + abs(pos - new_pos), new_pos)
        
        result, _ = reduce(accumulate, word, (0, 0))
        return result
```

### 方法四：简化版（一行代码）

```python
class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        """
        极简代码，但可读性较差
        """
        pos_map = {c: i for i, c in enumerate(keyboard)}
        positions = [0] + [pos_map[c] for c in word]
        return sum(abs(positions[i] - positions[i-1]) for i in range(1, len(positions)))
```

## 复杂度分析

**方法一（哈希表）：**
- 时间复杂度：`O(26 + n) = O(n)`
  - 建立哈希表：O(26)
  - 遍历 word：O(n)
- 空间复杂度：`O(26) = O(1)`，哈希表固定大小

**方法二（index 方法）：**
- 时间复杂度：`O(n * 26) = O(n)`
  - 每次 index 查找最坏 O(26)
  - 遍历 word：O(n)
- 空间复杂度：`O(1)`

方法一更优，因为查找是 O(1) 而不是 O(26)。

## 关键点总结

1. **预处理优化**：提前建立字符到索引的映射，避免重复查找

2. **状态维护**：需要维护当前手指位置，用于计算下次移动距离

3. **绝对值计算**：移动距离是索引差的绝对值

4. **初始位置**：手指初始在索引 0 处

5. **累加思想**：每次移动的时间累加到总时间

## 易错点

1. **忘记更新位置**：
   ```python
   # 错误：忘记更新 current_pos
   for char in word:
       total_time += abs(current_pos - char_to_index[char])
       # 忘记：current_pos = char_to_index[char]
   ```

2. **初始位置错误**：
   ```python
   # 错误：初始位置不是 -1 或其他值
   current_pos = -1
   
   # 正确：初始位置是 0
   current_pos = 0
   ```

3. **绝对值遗漏**：
   ```python
   # 错误：可能得到负数
   total_time += current_pos - target_pos
   
   # 正确：使用绝对值
   total_time += abs(current_pos - target_pos)
   ```

4. **重复建表**：
   ```python
   # 错误：在循环内建立映射
   for char in word:
       char_to_index = {c: i for i, c in enumerate(keyboard)}
   
   # 正确：在循环外建立一次
   ```

5. **边界情况**：word 为空时应返回 0（虽然题目保证 length >= 1）
