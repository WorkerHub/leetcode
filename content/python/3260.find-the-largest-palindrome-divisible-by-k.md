## 题目描述

给你两个正整数 `n` 和 `k`，找出能被 `k` 整除的最大 `n` 位回文整数（字符串形式）。

如果不存在，返回 `""`。

**示例 1：**
```
输入：n = 3, k = 5
输出："595"
解释：595 能被 5 整除，是最大的 3 位回文数。
```

**示例 2：**
```
输入：n = 1, k = 4
输出："8"
```

**示例 3：**
```
输入：n = 5, k = 6
输出："89898"
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= k <= 9`

## 解题思路

由于 k 只有 1-9，对不同 k 分析：

回文数由前半部分决定，后半部分是前半的镜像。

对于不同的 k：
- k=1: 任何数，最大 n 位回文是 `9...9`
- k=2: 末位必须为偶数（0,2,4,6,8），n 位回文末位=首位，首位不能为0
- k=5: 末位为0或5，首位不为0，最大选9开头...
- k=3: 各位数字和能被3整除
- k=4, k=7, k=8, k=9: 需要具体分析

对每个 k，贪心地从最高位开始，尽量选 9，同时保证最终数能被 k 整除。

由于回文数由前 ceil(n/2) 位决定，枚举前半部分（贪心从大到小）。

## Python 代码实现

### 方法一：贪心构造（推荐）

```python
class Solution:
    def largestPalindrome(self, n: int, k: int) -> str:
        # 对每个 k，构造最大 n 位能被 k 整除的回文数
        # 回文数由前 half = ceil(n/2) 位决定
        # 贪心：从高位到低位，尽量选 9
        
        half = (n + 1) // 2
        
        # 从最大的前半部分开始，逐渐减小，找到第一个使回文数能被 k 整除的
        # 前半从 10^(half-1) * 9... 开始枚举，但 10^(half-1) 可能很大
        
        # 对 k = 1, 3, 7, 9：与数字和有关（mod性质）
        # 对 k = 2, 4, 5, 8：与低位有关（直接构造）
        
        # 简化：由于 k <= 9，可以用数字 DP 或贪心
        
        # 数字 DP：对前 half 个数字，从高到低贪心选择 0-9，
        # 同时维护当前回文数 mod k 的余数
        
        # 回文数 P 的 mod k = f(前半部分)
        # 第 i 位（0-indexed 从高到低）对 P 的贡献：
        # 位置 i 和位置 n-1-i（如果不是中间位）分别贡献 10^(n-1-i) + 10^i
        # 中间位（n 为奇数时）贡献 10^(n//2)
        
        # 预计算每个位置对 P mod k 的权重
        pos_weight = []
        for i in range(half):
            if i == n - 1 - i:
                # 中间位
                w = pow(10, i, k)
            else:
                w = (pow(10, i, k) + pow(10, n - 1 - i, k)) % k
            pos_weight.append(w)
        
        # 贪心 + 回溯（DFS）
        digits = [9] * half
        
        def calc_mod():
            return sum(digits[i] * pos_weight[i] for i in range(half)) % k
        
        # 从最高位尝试从 9 到 0
        def greedy(pos, current_mod):
            if pos == half:
                return current_mod == 0
            
            # 首位不能为 0
            start = 1 if pos == 0 else 0
            for d in range(9, start - 1, -1):
                new_mod = (current_mod + d * pos_weight[pos]) % k
                digits[pos] = d
                if greedy(pos + 1, new_mod):
                    return True
            return False
        
        if not greedy(0, 0):
            return ""
        
        # 构造回文数
        s = ''.join(map(str, digits))
        if n % 2 == 1:
            return s + s[-2::-1]
        else:
            return s + s[::-1]
```

## 复杂度分析

- 时间复杂度：O(10 * ceil(n/2))（每位最多尝试 10 次）
- 空间复杂度：O(n)

## 关键点总结

1. 回文数由前半部分唯一决定
2. 每一位对总数 mod k 的贡献可以预计算
3. 贪心从高位到低位，每位尽量选 9

## 易错点

1. 首位不能为 0
2. n 为奇数时中间位只贡献一次
3. 某些 k 和 n 组合可能无解（如 n=1, k=7，只有 1-9 中 7 满足，但最大是 7）
