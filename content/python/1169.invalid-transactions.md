## 题目描述

如果满足以下任一情况，交易可能无效：

- 交易金额超过 `$1000`
- 或者，它和另一个城市中同名的另一笔交易相隔不超过 `60` 分钟（包含 60 分钟）

每个交易字符串 `transactions[i]` 由用逗号分隔的值组成，分别表示交易的名字，时间（以分钟计），金额以及城市。

给你一份交易清单 `transactions`，返回可能无效的交易列表。你可以按任何顺序返回答案。

示例 1：

```
输入：transactions = ["alice,20,800,mtv","alice,50,100,beijing"]
输出：["alice,20,800,mtv","alice,50,100,beijing"]
解释：第一笔交易是无效的，因为第二笔交易和它间隔不超过 60 分钟、名字相同且发生在不同的城市。同样，第二笔交易也是无效的。
```

示例 2：

```
输入：transactions = ["alice,20,800,mtv","alice,50,1200,mtv"]
输出：["alice,50,1200,mtv"]
```

示例 3：

```
输入：transactions = ["alice,20,800,mtv","bob,50,1200,mtv"]
输出：["bob,50,1200,mtv"]
```

提示：

- `transactions.length <= 1000`
- 每笔交易 `transactions[i]` 按 `"{name},{time},{amount},{city}"` 的格式进行记录
- 每个交易名称由小写英文字母组成，长度在 `1` 到 `10` 之间
- 每个交易时间为整数，范围在 `0` 到 `1000` 之间
- 每笔交易金额为整数，范围在 `0` 到 `2000` 之间
- 每个交易城市由小写英文字母组成，长度在 `1` 到 `10` 之间

## 解题思路

**核心逻辑：**

1. 金额超过 1000 的交易直接标记为无效
2. 对于每笔交易，检查是否存在同名、不同城市、时间差不超过 60 的其他交易

**算法步骤：**

1. 解析每笔交易的信息
2. 按名字分组，方便查找同名交易
3. 对每笔交易检查两个条件
4. 使用集合去重（避免重复添加）

## Python 代码实现

```python
from typing import List
from collections import defaultdict

class Solution:
    def invalidTransactions(self, transactions: List[str]) -> List[str]:
        """
        检查无效交易
        
        时间复杂度：O(n^2)
        空间复杂度：O(n)
        """
        # 解析交易
        parsed = []
        for i, t in enumerate(transactions):
            name, time, amount, city = t.split(',')
            parsed.append((name, int(time), int(amount), city, i))
        
        # 按名字分组
        name_group = defaultdict(list)
        for item in parsed:
            name_group[item[0]].append(item)
        
        invalid = set()
        
        for name, time, amount, city, idx in parsed:
            # 条件1：金额超过 1000
            if amount > 1000:
                invalid.add(idx)
            
            # 条件2：检查同名的其他交易
            for other_name, other_time, other_amount, other_city, other_idx in name_group[name]:
                if other_idx != idx and other_city != city and abs(time - other_time) <= 60:
                    invalid.add(idx)
                    invalid.add(other_idx)
        
        return [transactions[i] for i in invalid]
```

## 复杂度分析

- 时间复杂度：`O(n^2)`，最坏情况所有交易同名
- 空间复杂度：`O(n)`

## 关键点总结

1. 解析字符串获取字段
2. 按名字分组优化查找
3. 使用集合去重
4. 两个条件都要检查

## 易错点

1. 忘记检查金额超过 1000 的情况
2. 时间差应该用绝对值
3. 重复添加相同的交易到结果中
4. 相同城市的交易不算无效
