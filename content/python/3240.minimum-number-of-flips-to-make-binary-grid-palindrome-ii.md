## 题目描述

与 3239 题相同的矩阵回文要求，但增加了额外条件：**矩阵中 1 的总数必须能被 4 整除**。

返回满足条件的最少翻转次数。

**示例 1：**
```
输入：grid = [[1,0],[0,1]]
输出：4
```

**示例 2：**
```
输入：grid = [[0,1,0],[0,1,0],[0,0,0]]
输出：3
```

**提示：**
- `m == grid.length`
- `n == grid[0].length`
- `2 <= m, n <= 500`
- `grid[i][j]` 为 0 或 1

## 解题思路

在 3239 的基础上，还需保证 1 的总数能被 4 整除。

四格分组后，每组选择全 0 或全 1（各贡献 0 或 4 个 1）。
中间行（m 奇数）和中间列（n 奇数）的配对，各贡献 0 或 2 个 1。
中心格（m、n 均奇数）贡献 0 或 1 个 1。

步骤：
1. 先处理四格分组（贡献 0 或 4，模4余0）
2. 处理中间行/列配对，按贪心选择
3. 若总 1 数量模 4 不为 0，调整中间行/列配对

## Python 代码实现

### 方法一：贪心分层处理（推荐）

```python
from typing import List

class Solution:
    def minFlips(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0
        ones_mod4 = 0  # 当前 1 的数量模 4
        
        # 第一步：处理四格分组
        for i in range(m // 2):
            for j in range(n // 2):
                c = (grid[i][j] + grid[i][n-1-j] +
                     grid[m-1-i][j] + grid[m-1-i][n-1-j])
                if c == 0 or c == 4:
                    # 已经相同，不需要翻转
                    ones_mod4 = (ones_mod4 + (4 if c == 4 else 0)) % 4
                elif c == 2:
                    # 有两种方案：全0（翻2次）或全1（翻2次）
                    # 先暂定全0（贡献0个1），后续根据需要调整
                    ans += 2
                    # 暂不更新 ones_mod4，后续可以选择全1（调整代价为0，因为翻转次数不变）
                    # 记录这种情况
                else:
                    # c == 1 or c == 3：翻转成全0或全1需要 min(c,4-c) 次
                    # 但选择哪个会影响 1 的数量
                    # 贪心：选翻转次数少的，如果次数相同选能让 ones_mod4 更好的
                    if c == 1:
                        ans += 1  # 翻为全0，贡献0个1
                    else:  # c == 3
                        ans += 1  # 翻为全1，贡献4个1
                        ones_mod4 = (ones_mod4 + 4) % 4
        
        # 第二步：处理中间行（m 奇数）
        mid_row_diff_count = 0  # 中间行不同的对数
        if m % 2 == 1:
            mid_row = m // 2
            for j in range(n // 2):
                if grid[mid_row][j] != grid[mid_row][n-1-j]:
                    mid_row_diff_count += 1
                    ans += 1
                else:
                    ones_mod4 = (ones_mod4 + 2 * grid[mid_row][j]) % 4
        
        # 第三步：处理中间列（n 奇数）
        mid_col_diff_count = 0
        if n % 2 == 1:
            mid_col = n // 2
            for i in range(m // 2):
                if grid[i][mid_col] != grid[m-1-i][mid_col]:
                    mid_col_diff_count += 1
                    ans += 1
                else:
                    ones_mod4 = (ones_mod4 + 2 * grid[i][mid_col]) % 4
        
        # 第四步：处理中心格（m 和 n 都是奇数）
        if m % 2 == 1 and n % 2 == 1:
            center = grid[m // 2][n // 2]
            if ones_mod4 != 0:
                # 翻转中心格
                if ones_mod4 == 2:
                    ans += 1  # 翻转1次
                # 如果 ones_mod4 == 1 or 3，无法只靠中心格修复，需要多操作
        
        # 简化：如果 ones_mod4 != 0，贪心修复
        if ones_mod4 == 2:
            if m % 2 == 1 and n % 2 == 1:
                ans += 1  # 翻转中心格
            else:
                ans += 2  # 需要翻转某个配对
        
        return ans
```

### 方法二：精确贪心

```python
from typing import List

class Solution:
    def minFlips(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0
        diff = 0  # 1的总数的"余量"（需要模4为0）
        
        for i in range(m // 2):
            for j in range(n // 2):
                vals = [grid[i][j], grid[i][n-1-j], grid[m-1-i][j], grid[m-1-i][n-1-j]]
                c = sum(vals)
                ans += min(c, 4 - c)
                # 翻转后1的数量：c为偶数选0或4，c为奇数选最近的偶数
                best = 4 if c >= 2 else 0
                diff = (diff + best) % 4
        
        # 中间行
        if m % 2:
            mid = m // 2
            for j in range(n // 2):
                a, b = grid[mid][j], grid[mid][n-1-j]
                if a != b:
                    ans += 1
                    # 翻为相同，贪心选1（贡献2个1，对mod4有影响）
                    diff = (diff + 2) % 4
        
        # 中间列
        if n % 2:
            mid = n // 2
            for i in range(m // 2):
                a, b = grid[i][mid], grid[m-1-i][mid]
                if a != b:
                    ans += 1
                    diff = (diff + 2) % 4
        
        # 中心格
        if m % 2 and n % 2:
            center = grid[m//2][n//2]
            diff = (diff + center) % 4
            # 如果 diff != 0，翻转中心格
            if diff != 0:
                ans += 1
        elif diff != 0:
            # 调整某个中间行/列配对
            ans += 2
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 四格组的 1 数量对 4 取模为 0，不影响总数的模 4
2. 中间行/列的配对每次贡献 0 或 2 个 1
3. 中心格贡献 0 或 1 个 1，可用于微调

## 易错点

1. 四格组翻转后选全 0 还是全 1 会影响最终 1 数量
2. 中间行和中间列的处理逻辑不同
3. 需要仔细处理 m 和 n 的奇偶性
