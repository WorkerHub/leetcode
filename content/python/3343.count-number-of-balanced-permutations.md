## 题目描述

给你一个数字字符串 `num`。

如果一个字符串的奇数位数字之和等于偶数位数字之和（1 索引），则称该字符串是**平衡的**。

返回 `num` 的**排列**中平衡字符串的数量，对 `10^9 + 7` 取模。

**提示：**
- `2 <= num.length <= 80`
- `num` 只含 '0' 到 '9'

## 解题思路

**动态规划 + 组合数学：**

设数字总和为 `total`，若 `total` 为奇数则无解（返回 0）。

设偶数位总和 = 奇数位总和 = `total // 2`（目标）。

设 `n = len(num)`，奇数位有 `ceil(n/2)` 个，偶数位有 `floor(n/2)` 个（1 索引）。

**方案：**
- 从 `num` 的所有数字中，选 `ceil(n/2)` 个放到奇数位，其余放到偶数位。
- 奇数位的数字和为 `total // 2`。

**DP：**
`dp[j][s]` = 从已处理的数字中选了 `j` 个、数字和为 `s` 的方案数。

最终：`dp[ceil(n/2)][total//2]` 即为满足条件的选取方案数。

但还需要处理重复数字（相同数字的全排列不重复计数）：
- 各数字可以有多个，放到奇数位和偶数位的方案需要考虑重复。
- 奇数位 `ceil(n/2)` 个位置，有 `j_i` 个数字 `i` 放在奇数位：这些位置的排列数 = `ceil(n/2)! / product(j_i!)`。
- 偶数位同理。

**完整方案：** 预处理组合数，用 DP 计算。

## Python 代码实现

### 方法一：DP + 组合数（推荐）

```python
from collections import Counter
from math import factorial

class Solution:
    def countBalancedPermutations(self, num: str) -> int:
        MOD = 10**9 + 7
        n = len(num)
        digits = [int(c) for c in num]
        total = sum(digits)
        
        if total % 2 != 0:
            return 0
        
        target = total // 2
        cnt = Counter(digits)  # 每个数字的出现次数
        
        # 奇数位个数：ceil(n/2) = (n+1)//2
        # 偶数位个数：floor(n/2) = n//2
        odd_len = (n + 1) // 2
        even_len = n // 2
        
        # 预计算阶乘和逆阶乘
        max_n = n + 1
        fact = [1] * max_n
        for i in range(1, max_n):
            fact[i] = fact[i-1] * i % MOD
        
        inv_fact = [1] * max_n
        inv_fact[max_n - 1] = pow(fact[max_n - 1], MOD - 2, MOD)
        for i in range(max_n - 2, -1, -1):
            inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
        
        # dp[j][s] = 选了 j 个数字放奇数位，数字和为 s 的方案数（考虑重复的处理）
        # 使用多重集合组合：每个数字 d 出现 cnt[d] 次，选其中 k 个放奇数位
        # 方案数 = product of C(cnt[d], k_d) for each digit d
        
        # dp[j][s] 初始化
        dp = [[0] * (target + 1) for _ in range(odd_len + 1)]
        dp[0][0] = 1
        
        for d in range(10):
            c = cnt[d]
            if c == 0:
                continue
            # 对每个数字 d，可以选 0 到 min(c, odd_len) 个放奇数位
            # 从后往前（背包思路）
            # 但这里不是标准背包，需要分别枚举
            new_dp = [[0] * (target + 1) for _ in range(odd_len + 1)]
            for j in range(odd_len + 1):
                for s in range(target + 1):
                    if dp[j][s] == 0:
                        continue
                    # 选 k 个数字 d 放奇数位（0 <= k <= min(c, odd_len-j)，s+k*d <= target）
                    for k in range(min(c, odd_len - j) + 1):
                        ns = s + k * d
                        if ns > target:
                            break
                        # 从 c 个 d 中选 k 个：C(c, k)
                        ways = inv_fact[k] * inv_fact[c - k] % MOD * fact[c] % MOD
                        new_dp[j + k][ns] = (new_dp[j + k][ns] + dp[j][s] * ways) % MOD
            dp = new_dp
        
        # dp[odd_len][target] 是将各数字分配的方案数
        # 再乘以排列方案：奇数位有 odd_len 个位置，放 j_d 个数字 d
        # 排列数 = odd_len! / product(j_d!) * even_len! / product((cnt[d]-j_d)!)
        # 实际上 dp 中已经计算了 product of C(cnt[d], k_d)，即 product of cnt[d]! / (k_d! * (cnt[d]-k_d)!)
        # 乘以 odd_len! 和 even_len! 即可（扣掉分母中的 cnt[d]!）
        
        # 最终答案 = dp[odd_len][target] * odd_len! * even_len! / product(cnt[d]!)
        # 但 dp 中已经包含了 C(cnt[d], k_d) = cnt[d]! / (k_d! * (cnt[d]-k_d)!)
        # 所以 dp[odd_len][target] 已是最终方案数 * product(1/(k_d! * (cnt_d-k_d)!))
        # 需要乘以 odd_len! * even_len!
        
        result = dp[odd_len][target] * fact[odd_len] % MOD * fact[even_len] % MOD
        return result
```

## 复杂度分析

- 时间复杂度：O(10 * odd_len * target)，其中 target <= 9*80 = 720
- 空间复杂度：O(odd_len * target)

## 关键点总结

1. 总和为奇数时无解。
2. DP 枚举每个数字分配多少个到奇数位，使用组合数 C(cnt[d], k)。
3. 最终乘以奇偶位各自的排列数（阶乘）。

## 易错点

1. 组合数计算：`C(c, k) = fact[c] * inv_fact[k] * inv_fact[c-k] % MOD`。
2. `odd_len = (n+1)//2`（奇数位更多），`even_len = n//2`。
3. 答案需要乘以 `odd_len! * even_len!`（位置排列）。
