## 题目描述

序列化是将数据结构或对象转换为一系列位的过程，以便它可以存储在文件或内存缓冲区中，或通过网络连接链路传输，以便稍后在同一个或另一个计算机环境中重建。

设计一个算法来序列化和反序列化二叉搜索树。对序列化/反序列化算法的工作方式没有限制。你只需确保二叉搜索树可以序列化为字符串，并且可以将该字符串反序列化为最初的二叉搜索树。

编码的字符串应尽可能紧凑。

**示例 1:**

```
输入: root = [2,1,3]
输出: [2,1,3]
```

**示例 2:**

```
输入: root = []
输出: []
```

**提示:**

- 树中节点数范围是 [0, 10^4]
- 0 <= Node.val <= 10^4
- 题目数据保证输入的树是一棵二叉搜索树

## 解题思路

这道题是 [297. Serialize and Deserialize Binary Tree](https://leetcode.com/problems/serialize-and-deserialize-binary-tree/) 的特化版本，但由于是**二叉搜索树（BST）**，可以利用其特性进行优化。

**BST 的特性：**
1. 左子树所有节点 < 根节点 < 右子树所有节点
2. 中序遍历是有序的
3. 前序/后序遍历可以唯一确定 BST

**优化方案：**

与普通二叉树不同，BST 只需要**前序遍历**就能唯一重建，不需要使用空值标记（null）。

**方法对比：**
1. **方法一（利用 BST 特性）**：只存储前序遍历，反序列化时利用 BST 性质重建
2. **方法二（通用方法）**：与 297 题相同，使用空值标记
3. **方法三（后序遍历）**：利用后序遍历重建 BST

## Python 代码实现

### 方法一：前序遍历 + BST 性质（推荐）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Codec:
    """
    使用前序遍历序列化，利用 BST 性质反序列化
    不需要存储 null 标记，空间最优
    """
    
    def serialize(self, root: TreeNode) -> str:
        """
        前序遍历序列化
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        result = []
        
        def preorder(node):
            if not node:
                return
            result.append(str(node.val))
            preorder(node.left)
            preorder(node.right)
        
        preorder(root)
        return ','.join(result)
    
    def deserialize(self, data: str) -> TreeNode:
        """
        利用 BST 性质重建树
        时间复杂度: O(n)
        空间复杂度: O(n)
        """
        if not data:
            return None
        
        vals = list(map(int, data.split(',')))
        self.index = 0
        
        def build(min_val, max_val):
            """
            在 [min_val, max_val] 范围内构建子树
            """
            if self.index >= len(vals):
                return None
            
            val = vals[self.index]
            
            # 如果当前值不在范围内，说明不属于当前子树
            if val < min_val or val > max_val:
                return None
            
            # 创建节点
            self.index += 1
            node = TreeNode(val)
            
            # 左子树：值在 [min_val, val) 范围内
            node.left = build(min_val, val)
            # 右子树：值在 (val, max_val] 范围内
            node.right = build(val, max_val)
            
            return node
        
        return build(float('-inf'), float('inf'))
```

### 方法二：后序遍历（逆序构建）

```python
class Codec:
    """
    使用后序遍历，从右到左构建
    """
    
    def serialize(self, root: TreeNode) -> str:
        """后序遍历序列化"""
        result = []
        
        def postorder(node):
            if not node:
                return
            postorder(node.left)
            postorder(node.right)
            result.append(str(node.val))
        
        postorder(root)
        return ','.join(result)
    
    def deserialize(self, data: str) -> TreeNode:
        """从后向前构建 BST"""
        if not data:
            return None
        
        vals = list(map(int, data.split(',')))
        self.index = len(vals) - 1
        
        def build(min_val, max_val):
            if self.index < 0:
                return None
            
            val = vals[self.index]
            
            if val < min_val or val > max_val:
                return None
            
            # 从后向前，所以先处理右子树
            self.index -= 1
            node = TreeNode(val)
            
            # 注意顺序：后序是左右根，所以反向是根右左
            node.right = build(val, max_val)
            node.left = build(min_val, val)
            
            return node
        
        return build(float('-inf'), float('inf'))
```

### 方法三：通用方法（与 297 题相同）

```python
class Codec:
    """
    使用 null 标记的通用方法
    适用于任何二叉树，但不是最优
    """
    
    def serialize(self, root: TreeNode) -> str:
        """前序遍历，使用 # 表示 null"""
        result = []
        
        def preorder(node):
            if not node:
                result.append('#')
                return
            result.append(str(node.val))
            preorder(node.left)
            preorder(node.right)
        
        preorder(root)
        return ','.join(result)
    
    def deserialize(self, data: str) -> TreeNode:
        """根据序列化字符串重建树"""
        vals = iter(data.split(','))
        
        def build():
            val = next(vals)
            if val == '#':
                return None
            
            node = TreeNode(int(val))
            node.left = build()
            node.right = build()
            return node
        
        return build()
```

### 方法四：迭代版本

```python
class Codec:
    """
    迭代实现序列化和反序列化
    """
    
    def serialize(self, root: TreeNode) -> str:
        """迭代前序遍历"""
        if not root:
            return ""
        
        result = []
        stack = [root]
        
        while stack:
            node = stack.pop()
            result.append(str(node.val))
            # 先右后左，保证前序遍历
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        
        return ','.join(result)
    
    def deserialize(self, data: str) -> TreeNode:
        """迭代构建 BST"""
        if not data:
            return None
        
        vals = list(map(int, data.split(',')))
        root = TreeNode(vals[0])
        stack = [root]
        
        for i in range(1, len(vals)):
            node = TreeNode(vals[i])
            
            # 找到合适的父节点
            if vals[i] < stack[-1].val:
                # 作为左子节点
                stack[-1].left = node
            else:
                # 找到第一个比当前值小的节点
                parent = None
                while stack and stack[-1].val < vals[i]:
                    parent = stack.pop()
                parent.right = node
            
            stack.append(node)
        
        return root
```

## 复杂度分析

**方法一（前序遍历 + BST 性质）：**
- 序列化时间复杂度：O(n)
- 反序列化时间复杂度：O(n)
- 空间复杂度：O(n)
- **优点**：不需要存储 null，空间最优

**方法二（后序遍历）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- **优点**：思路独特，利用后序遍历的逆序

**方法三（通用方法）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- **缺点**：需要存储 null 标记，空间不够优

## 关键点总结

1. **BST 特性利用**：前序遍历可以唯一确定 BST
2. **范围限制**：利用 [min_val, max_val] 判断节点归属
3. **无需 null 标记**：比通用方法更省空间
4. **递归构建**：通过范围限制自然划分左右子树
5. **索引管理**：使用全局索引跟踪当前处理位置

## 易错点

1. **范围判断错误**：
   ```python
   # 错误：使用 <= 和 >=
   if val <= min_val or val >= max_val:
       return None
   
   # 正确：使用 < 和 >
   if val < min_val or val > max_val:
       return None
   ```

2. **索引更新时机**：
   - 必须在创建节点后立即更新索引
   - 不能在判断后才更新

3. **递归顺序**：
   - 前序：先左后右
   - 后序反向：先右后左
   - 顺序错误会导致树结构错误

4. **边界条件**：
   - 空树的处理
   - 只有一个节点的处理
   - 链状树的处理
