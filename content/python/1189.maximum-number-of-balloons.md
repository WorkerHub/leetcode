## 题目描述

给你一个字符串 `text`，你需要使用 `text` 中的字母来拼凑尽可能多的单词 "balloon"（气球）。

字符串 `text` 中的每个字母最多只能被使用一次。请你返回最多可以拼凑出多少个单词 "balloon"。

**示例 1：**
```
输入：text = "nlaebolko"
输出：1
```

**示例 2：**
```
输入：text = "loonbalxballpoon"
输出：2
```

**示例 3：**
```
输入：text = "leetcode"
输出：0
```

**提示：**
- `1 <= text.length <= 10^4`
- `text` 全部由小写英文字母组成

## 解题思路

这道题的核心是统计字符频次，然后计算可以组成多少个 "balloon"。

**核心观察：**

1. 单词 "balloon" 包含：
   - `b` 出现 1 次
   - `a` 出现 1 次
   - `l` 出现 2 次
   - `o` 出现 2 次
   - `n` 出现 1 次

2. **关键点**：`l` 和 `o` 各需要 2 个，其他字母各需要 1 个。

3. **计算方法**：
   - 统计 `text` 中每个字母的出现次数
   - 对于 `b`、`a`、`n`，可以组成的数量就是它们的出现次数
   - 对于 `l`、`o`，可以组成的数量是它们出现次数的一半（向下取整）
   - 最终结果是所有字母可组成数量的最小值

## Python 代码实现

### 方法一：哈希表计数（推荐）⭐

```python
from typing import Counter

class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        """
        使用 Counter 统计字符频次
        """
        # 统计所有字符的出现次数
        count = Counter(text)
        
        # 计算每个字母可以组成多少个 "balloon"
        # 注意：'l' 和 'o' 需要除以 2，因为它们在 "balloon" 中出现 2 次
        return min(
            count['b'],
            count['a'],
            count['l'] // 2,
            count['o'] // 2,
            count['n']
        )
```

### 方法二：手动计数

```python
class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        """
        手动统计每个字母的出现次数
        """
        # 初始化计数器
        b_count = a_count = l_count = o_count = n_count = 0
        
        # 遍历字符串，统计需要的字母
        for char in text:
            if char == 'b':
                b_count += 1
            elif char == 'a':
                a_count += 1
            elif char == 'l':
                l_count += 1
            elif char == 'o':
                o_count += 1
            elif char == 'n':
                n_count += 1
        
        # 返回最小值（注意 l 和 o 需要除以 2）
        return min(b_count, a_count, l_count // 2, o_count // 2, n_count)
```

### 方法三：使用字典

```python
class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        """
        使用字典统计，更加灵活
        """
        # 统计字符频次
        freq = {}
        for char in text:
            freq[char] = freq.get(char, 0) + 1
        
        # "balloon" 中每个字母需要的数量
        needed = {'b': 1, 'a': 1, 'l': 2, 'o': 2, 'n': 1}
        
        # 计算每个字母可以组成多少个 "balloon"
        min_count = float('inf')
        for char, need in needed.items():
            # 获取该字母的实际数量
            available = freq.get(char, 0)
            # 计算可以组成多少个
            min_count = min(min_count, available // need)
        
        return min_count if min_count != float('inf') else 0
```

### 方法四：一行代码（Python 特色）

```python
from collections import Counter

class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        """
        精简版本
        """
        c = Counter(text)
        return min(c['b'], c['a'], c['l']//2, c['o']//2, c['n'])
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，其中 n 是字符串 `text` 的长度，需要遍历一次字符串
- **空间复杂度**：O(1)，虽然使用了哈希表，但只存储 "balloon" 相关的字母，常数空间

## 关键点总结

1. **字符频次统计**：使用 `Counter` 或手动计数都可以
2. **注意字母出现次数**：`l` 和 `o` 在 "balloon" 中各出现 2 次
3. **取最小值**：瓶颈在于出现次数最少的字母
4. **整除运算**：对于 `l` 和 `o`，使用整除 `//` 而不是普通除法
5. **边界处理**：如果某个字母不存在，`Counter` 会返回 0

## 易错点

1. **忘记 l 和 o 需要 2 个**：这是最容易出错的地方，必须除以 2
2. **使用除法而非整除**：应该用 `//` 而不是 `/`
3. **没有考虑字母不存在的情况**：使用 `Counter` 时，不存在的字母会返回 0，这是安全的
4. **计算最大值而非最小值**：应该取最小值，因为是瓶颈
5. **忽略其他字母**：虽然 `text` 包含其他字母，但我们只关心 "balloon" 中的字母
