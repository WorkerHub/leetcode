## 题目描述

给你两个字符串 `s1` 和 `s2`，写一个函数来判断 `s2` 是否包含 `s1` 的排列。如果是，返回 `true`；否则，返回 `false`。

换句话说，`s1` 的排列之一是 `s2` 的**子串**。

**示例 1：**
```
输入：s1 = "ab", s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列之一（"ba"）
```

**示例 2：**
```
输入：s1 = "ab", s2 = "eidboaoo"
输出：false
```

**提示：**
- `1 <= s1.length, s2.length <= 10^4`
- `s1` 和 `s2` 仅包含小写字母

## 解题思路

使用滑动窗口 + 字符计数。

核心思想：
- 维护一个长度为 len(s1) 的滑动窗口
- 比较窗口内的字符频率与 s1 的字符频率

## Python 代码实现

### 方法一：滑动窗口 + Counter（推荐）⭐

```python
from collections import Counter

class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        """
        滑动窗口 + 字符计数
        
        时间复杂度：O(n)
        空间复杂度：O(1)，字符集大小固定
        """
        len1, len2 = len(s1), len(s2)
        if len1 > len2:
            return False
        
        count1 = Counter(s1)
        count2 = Counter(s2[:len1])
        
        if count1 == count2:
            return True
        
        for i in range(len1, len2):
            # 添加新字符
            count2[s2[i]] += 1
            # 移除旧字符
            count2[s2[i - len1]] -= 1
            if count2[s2[i - len1]] == 0:
                del count2[s2[i - len1]]
            
            if count1 == count2:
                return True
        
        return False
```

### 方法二：数组计数

```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        """
        使用数组计数（更快）
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if len(s1) > len(s2):
            return False
        
        # 统计字符频率
        count = [0] * 26
        for i in range(len(s1)):
            count[ord(s1[i]) - ord('a')] -= 1
            count[ord(s2[i]) - ord('a')] += 1
        
        if all(c == 0 for c in count):
            return True
        
        # 滑动窗口
        for i in range(len(s1), len(s2)):
            count[ord(s2[i]) - ord('a')] += 1
            count[ord(s2[i - len(s1)]) - ord('a')] -= 1
            
            if all(c == 0 for c in count):
                return True
        
        return False
```

### 方法三：优化匹配

```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        """
        维护匹配的字符数量
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if len(s1) > len(s2):
            return False
        
        s1_count = [0] * 26
        s2_count = [0] * 26
        
        for c in s1:
            s1_count[ord(c) - ord('a')] += 1
        
        for i in range(len(s2)):
            s2_count[ord(s2[i]) - ord('a')] += 1
            
            if i >= len(s1):
                s2_count[ord(s2[i - len(s1)]) - ord('a')] -= 1
            
            if s1_count == s2_count:
                return True
        
        return False
```

## 复杂度分析

- **时间复杂度**：O(n)，n 是 s2 的长度
- **空间复杂度**：O(1)，字符集大小固定（26个字母）

## 关键点总结

1. **滑动窗口**：固定窗口大小为 len(s1)
2. **字符计数**：比较字符频率
3. **优化技巧**：使用数组代替哈希表
