## 题目描述

给你一个字符串 `s`。

每次操作，找到 `s` 中当前**字典序最小**的字符，删除所有该字符的**第一次出现**（即每次删除一个，如果有多个相同字符则每次只删一个）。

**实际规则：** 每次操作删除 `s` 中最小字符的第一个出现位置处的字符。重复直到 `s` 为空，返回最后一次操作前的字符串（即最后一次删除前的状态）。

重新理解：返回执行操作后，**最后一轮**操作开始前的字符串。

具体来说：每轮从剩余字符串中找最小字符，删除所有该字符的某种出现。最终返回最后一轮操作开始时的字符串。

**正确题意：** 每轮删除当前字符串中所有最小字母（一轮删除所有相同的最小字母）。返回最后一轮操作前的字符串。

**示例 1：**
```
输入：s = "aabcbbca"
输出："bbca"
```

**示例 2：**
```
输入：s = "aa"
输出："aa"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

每轮删除所有最小字符的全部出现。最后一轮删除某个字符后字符串为空。

关键：最后一轮操作删除的是出现次数最多的那个字符（若有并列，删除字典序最大的）。

等价地，出现次数最多的字符是最后被删除的。

返回"最后一轮操作开始时的字符串"= 最后被删除的字符在原字符串中的所有位置对应的字符序列。

具体来说，找出现次数最多（若并列则取字典序最大）的字符，返回原字符串中所有非该字符的字符被删除后，该字符最后一轮操作前的状态（就是原字符串中该字符出现的位置之前的子字符串）。

**正确分析：**
- 计算每个字符的频率
- 最大频率对应的字符是最后被删除的
- 最后一轮操作开始时的字符串 = 原字符串中该字符所有位置之前（包括该字符）的子字符串保留其他字符

实际上最简单的理解：最后一轮前的字符串，是原字符串中出现次数等于最大频率的字符（所有这样的字符的最后出现之后的部分去掉）。

最终正确结论：返回原字符串中所有出现次数等于最大频率的字符的最后一次出现之前（含）的所有字符。

## Python 代码实现

### 方法一：按频率分析（推荐）

```python
from collections import Counter

class Solution:
    def lastNonEmptyString(self, s: str) -> str:
        freq = Counter(s)
        max_freq = max(freq.values())

        # 找出所有出现次数等于最大频率的字符
        # 这些字符在最后一轮一起被删除
        # 最后一轮前的字符串包含：
        # - 这些字符的所有出现（各 max_freq 个）
        # - 其他字符（已被前几轮删除）

        # 最后一轮操作前，字符串为这些字符的出现
        # 即原字符串中保留"出现次数 == max_freq"的字符的最后出现位置

        # 在原字符串中，每个出现次数等于 max_freq 的字符
        # 取其最后一次出现的位置
        max_freq_chars = {c for c, v in freq.items() if v == max_freq}

        # 找每个最大频率字符最后出现的位置
        last_pos = {}
        for i, c in enumerate(s):
            if c in max_freq_chars:
                last_pos[c] = i

        # 结果：原字符串中位置 <= max(last_pos.values()) 的字符，
        # 但只保留出现次数 == max_freq 的字符
        # 实际上：取所有 last_pos 中的最大位置，
        # 结果是原字符串从 0 到该位置的子串中只保留 max_freq_chars 的字符

        cutoff = max(last_pos.values())
        return ''.join(c for c in s[:cutoff+1] if c in max_freq_chars)
```

### 方法二：直接模拟

```python
from collections import Counter

class Solution:
    def lastNonEmptyString(self, s: str) -> str:
        freq = Counter(s)
        max_freq = max(freq.values())
        # 最大频率字符集合
        target = {c for c, f in freq.items() if f == max_freq}

        # 模拟：每轮删除最小字符的所有出现
        # 最后一轮就是删除目标字符集中最小的那个（但实际上这些字符同时在最后被删除）
        # 返回最后一轮前：只含 target 字符的字符串（按原顺序）

        # 找每个 target 字符最后一次出现的最大位置
        last_idx = max(i for i, c in enumerate(s) if c in target)
        return ''.join(c for i, c in enumerate(s) if c in target and i <= last_idx)
```

## 复杂度分析

- 时间复杂度：O(n)，统计频率和一次遍历
- 空间复杂度：O(n)

## 关键点总结

1. 出现次数最多的字符在最后一轮被删除
2. 若多个字符同时达到最大频率，它们都在最后一轮被删除
3. 最后一轮前的字符串 = 原字符串中最大频率字符的所有出现（截止到最后一次出现位置）

## 易错点

1. 题目问的是"最后一轮操作前"的字符串，不是操作后
2. 保留字符的顺序与原字符串一致
