## 题目描述

给你一棵 `n` 个节点的无向树，节点编号为 `0` 到 `n - 1`，其中节点 `0` 是首都。每辆车的座位数为 `seats`。

每个非首都城市都要向首都报到，所有车辆都沿树的边移动（只走最短路）。返回所有车辆到达首都所需的最少燃油量（每辆车行驶一条边消耗一单位燃油）。

每个城市有一辆车，人可以在途中换乘（同一时刻在同一节点可以聚集，然后用更少的车）。

**提示：**
- `1 <= n <= 10^5`
- `1 <= seats <= 10^5`

## 解题思路

**贪心 + 树形 DFS：**

对每条边，计算通过该边的人数，向上取整除以 `seats` 得到需要的车辆数（燃油量）。

对于以节点 `u` 为根的子树：
- 子树中所有人都要经过边 `(parent(u), u)` 前往首都
- 所需车辆数 = `ceil(subtree_size(u) / seats)`
- 消耗燃油 = 该车辆数

**DFS 返回子树大小，统计每条边的燃油消耗。**

## 代码实现

### 方法一：DFS（推荐）

```python
from typing import List
from collections import defaultdict
import math

class Solution:
    def minimumFuelCost(self, roads: List[List[int]], seats: int) -> int:
        n = len(roads) + 1
        adj = defaultdict(list)
        for u, v in roads:
            adj[u].append(v)
            adj[v].append(u)

        self.fuel = 0

        def dfs(node: int, parent: int) -> int:
            """返回以 node 为根的子树中的人数"""
            people = 1  # 当前城市一个人

            for neighbor in adj[node]:
                if neighbor != parent:
                    sub_people = dfs(neighbor, node)
                    people += sub_people
                    # 通过边 (node, neighbor) 需要的车辆数
                    self.fuel += math.ceil(sub_people / seats)

            return people

        dfs(0, -1)
        return self.fuel
```

### 方法二：BFS（叶子到根方向）

```python
from typing import List
from collections import defaultdict, deque
import math

class Solution:
    def minimumFuelCost(self, roads: List[List[int]], seats: int) -> int:
        n = len(roads) + 1
        adj = defaultdict(list)
        degree = [0] * n
        for u, v in roads:
            adj[u].append(v)
            adj[v].append(u)
            degree[u] += 1
            degree[v] += 1

        if n == 1:
            return 0

        # 从叶子向根汇聚
        people = [1] * n
        fuel = 0
        queue = deque(i for i in range(1, n) if degree[i] == 1)

        while queue:
            node = queue.popleft()
            for neighbor in adj[node]:
                if degree[neighbor] > 0:
                    fuel += math.ceil(people[node] / seats)
                    people[neighbor] += people[node]
                    degree[neighbor] -= 1
                    if neighbor != 0 and degree[neighbor] == 1:
                        queue.append(neighbor)
                    break

        return fuel
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS | O(n) | O(n) |
| BFS | O(n) | O(n) |

## 关键点总结

1. 每条边的燃油消耗 = `ceil(经过此边的人数 / seats)`
2. DFS 返回子树大小，统计每条非根边的燃油
3. 根节点 0 不消耗燃油（起点在首都的不算）

## 易错点

- 只有从非首都节点到首都的边才消耗燃油，根节点本身不消耗
- 向上取整：`math.ceil(p / seats)` 或 `(p + seats - 1) // seats`
