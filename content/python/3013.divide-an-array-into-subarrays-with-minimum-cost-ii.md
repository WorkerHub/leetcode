## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums`，以及两个正整数 `k` 和 `dist`。

定义数组的 **代价** 为第一个元素的值。

你需要将 `nums` 分割成恰好 `k` 个不重叠、不为空的子数组，且需要满足：第 2 至第 k 个子数组的起始下标之差不超过 `dist`（即第 2 个子数组起始下标 `i2` 和第 k 个子数组起始下标 `ik` 满足 `ik - i2 <= dist`）。

返回 k 个子数组的代价之和的最小值。

**示例 1：**
```
输入：nums = [1,3,2,6,4,2], k = 3, dist = 3
输出：5
```

**示例 2：**
```
输入：nums = [10,1,2,2,2,1], k = 4, dist = 3
输出：15
```

**提示：**
- `3 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`
- `3 <= k <= n`
- `k - 2 <= dist <= n - 2`

## 解题思路

- 第一个子数组代价固定为 `nums[0]`
- 需要从 `nums[1..n-1]` 中选 `k-1` 个位置作为剩余 `k-1` 个子数组的起点
- 约束：选的 `k-1` 个位置中，最小下标 `i2` 和最大下标 `ik` 满足 `ik - i2 <= dist`
- 目标：选出的 `k-1` 个位置对应的 `nums` 值之和最小

等价于：在滑动窗口 `[i, i + dist]` 内，选出 `k-1` 个最小值（`i` 从 1 到 `n - dist - 1`）。

使用两个有序集合（SortedList）维护窗口内的最小 `k-1` 个值：
- `small`：当前最小的 `k-1` 个值
- `large`：其余值

## Python 代码实现

### 方法一：滑动窗口 + 有序集合（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minimumCost(self, nums: List[int], k: int, dist: int) -> int:
        n = len(nums)
        # 需要选 k-1 个值，窗口大小为 dist+1（下标范围 [l, l+dist]）
        # 第一个子数组固定为 nums[0]

        # small 维护窗口内最小的 k-1 个值，large 维护其余较大值
        small = SortedList()  # 最小的 k-1 个值（有序）
        large = SortedList()  # 较大的值（有序）
        small_sum = 0

        def push_small(val):
            nonlocal small_sum
            small.add(val)
            small_sum += val

        def push_large(val):
            large.add(val)

        def balance():
            """保持 small 的大小恰好为 k-1"""
            nonlocal small_sum
            while len(small) > k - 1:
                # small 过大，移出最大值到 large
                val = small[-1]
                small.remove(val)
                small_sum -= val
                large.add(val)
            while len(small) < k - 1 and large:
                # small 不足，从 large 移入最小值
                val = large[0]
                large.remove(val)
                push_small(val)

        # 初始化窗口 [1, dist+1]（共 dist+1 个元素）
        for i in range(1, dist + 2):
            if i < n:
                push_large(nums[i])
        balance()

        ans = float('inf')
        if len(small) == k - 1:
            ans = nums[0] + small_sum

        # 滑动窗口：移入 i+dist+1，移出 i
        for i in range(1, n - dist - 1):
            # 移出 nums[i]（下标 i 离开窗口）
            val_out = nums[i]
            if val_out in small:
                small.remove(val_out)
                small_sum -= val_out
            else:
                large.remove(val_out)

            # 移入 nums[i + dist + 1]
            new_val = nums[i + dist + 1]
            push_large(new_val)
            balance()

            if len(small) == k - 1:
                ans = min(ans, nums[0] + small_sum)

        return ans
```

### 方法二：使用 heapq 的近似版（简化思路）

```python
from typing import List
import heapq

class Solution:
    def minimumCost(self, nums: List[int], k: int, dist: int) -> int:
        # 枚举第二个分割点 i2（起始下标范围 [1, n-k+1]）
        # 第 k 个分割点 ik 的范围 [i2, i2+dist]，且 ik <= n-1
        # 在 [i2, min(i2+dist, n-1)] 中选 k-2 个最小值
        # 总代价 = nums[0] + nums[i2] + 这 k-2 个最小值之和
        n = len(nums)
        ans = float('inf')

        for i2 in range(1, n - k + 2):
            window = nums[i2:min(i2 + dist + 1, n)]
            if len(window) < k - 1:
                continue
            # 选 k-1 个最小值（包含 nums[i2]）
            smallest = heapq.nsmallest(k - 1, window)
            ans = min(ans, nums[0] + sum(smallest))

        return ans
```

## 复杂度分析

- 方法一时间复杂度：O(n log n)，滑动窗口 + 有序集合操作均为 O(log n)
- 方法二时间复杂度：O(n * dist * log(dist))，枚举 + 堆排序，可能超时
- 空间复杂度：O(n)

## 关键点总结

1. 窗口大小为 `dist + 1`（下标 `[i2, i2 + dist]`）
2. 用两个有序集合动态维护最小 `k-1` 个值及其和
3. 滑动时先移出旧元素，再移入新元素，最后 `balance` 保持大小

## 易错点

1. `small` 的大小必须恰好为 `k-1`，不足或过多时需要调整
2. 滑动窗口的下标边界要仔细处理
3. SortedList 的 `remove` 是 O(log n)，不是 O(1)
