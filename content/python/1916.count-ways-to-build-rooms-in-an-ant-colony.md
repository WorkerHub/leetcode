## 题目描述

你是一只蚂蚁，负责为蚁群建造新家。给你一个下标从 **0** 开始、大小为 `n` 的整数数组 `prevRoom`，其中 `prevRoom[i]` 是在建造房间 `i` 之前必须先建造的房间（`prevRoom[0] = -1` 表示房间 `0` 是第一个建造的，即根节点）。

返回你可以建造所有房间的**不同顺序的数目**，结果对 `10^9 + 7` 取余。

**示例 1：**
```
输入：prevRoom = [-1, 0, 0]
输出：2
解释：可以是 [0,1,2] 或 [0,2,1]
```

**示例 2：**
```
输入：prevRoom = [-1, 0, 1, 2]
输出：1
解释：只能是 [0,1,2,3]（链状树）
```

**提示：**
- `2 <= n <= 10^5`

---

## 解题思路

### 核心思想：树形 DP + 组合数学

设 `dp[v]` 为以 `v` 为根的子树中，所有节点的合法建造顺序数。

设 `v` 的子树大小为 `size[v]`，子节点为 `c1, c2, ..., ck`。

合并时，需要将子节点的顺序**交错排列**，条件是每个子树内部顺序相对固定。

合并公式：
```
dp[v] = dp[c1] * dp[c2] * ... * dp[ck] * C(size[c1]+size[c2]+..., size[c1]) * ...
      = (size[v] - 1)! / (size[c1]! / dp_product * ...)
```

更简洁：

```
dp[v] = (size[v] - 1)! * product(dp[ci]) / product(size[ci]!)
```

即：子树中 `size[v]-1` 个非根节点的排列，乘以各子树的排列方式，除以各子树大小的阶乘。

## 代码实现

### 方法一：树形 DP + 逆元（推荐）

```python
from typing import List
import sys

sys.setrecursionlimit(200000)

class Solution:
    def waysToBuildRooms(self, prevRoom: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(prevRoom)

        # 构建树（邻接表）
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[prevRoom[i]].append(i)

        # 预计算阶乘和逆元
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        # 费马小定理求逆元
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        # 树形 DP（迭代后序遍历）
        size = [1] * n
        dp = [1] * n

        # 使用栈进行后序遍历（避免递归栈溢出）
        order = []
        stack = [0]
        while stack:
            v = stack.pop()
            order.append(v)
            for c in children[v]:
                stack.append(c)

        # 从叶子到根计算 dp 和 size
        for v in reversed(order):
            for c in children[v]:
                # 合并子树 c 到 v：
                # dp[v] *= dp[c] * inv_fact[size[c]] * fact[size[v] - 1] / fact[size[v] - 1 - size[c]]
                # 等价于：每合并一个子树，乘以组合数 C(size[v]-1, size[c])
                size[v] += size[c]
                dp[v] = dp[v] * dp[c] % MOD * inv_fact[size[c]] % MOD

            # 最终乘以 (size[v]-1)!
            dp[v] = dp[v] * fact[size[v] - 1] % MOD

        return dp[0]
```

### 方法二：递归 DFS（逻辑更清晰，注意栈深）

```python
from typing import List
import sys

sys.setrecursionlimit(200000)

class Solution:
    def waysToBuildRooms(self, prevRoom: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(prevRoom)

        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[prevRoom[i]].append(i)

        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        size = [0] * n
        dp = [0] * n

        def dfs(v: int) -> None:
            size[v] = 1
            dp[v] = 1
            for c in children[v]:
                dfs(c)
                size[v] += size[c]
                # 合并子树：乘以 dp[c] / size[c]!
                dp[v] = dp[v] * dp[c] % MOD * inv_fact[size[c]] % MOD
            # 乘以 (size[v]-1)!
            dp[v] = dp[v] * fact[size[v] - 1] % MOD

        dfs(0)
        return dp[0]
```

## 关键点总结

1. 核心公式：`dp[v] = (size[v]-1)! * prod(dp[c] / size[c]!)`
2. 使用费马小定理预计算逆元，避免模除运算
3. 迭代后序遍历避免递归栈溢出（n 最大 10^5）

---

## 易错点

- 递归深度可能超限，推荐使用迭代版本
- 逆元计算：`inv_fact[i] = inv_fact[i+1] * (i+1) % MOD`，需从大往小推
