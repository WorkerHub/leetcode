## 题目描述

给定一个整数数组 `nums` 和整数 `k`。从数组中选取两个不重叠的子序列（可为空），使得它们的元素和均等于 `k`，且两个子序列元素乘积之积最大。返回满足条件的最大乘积，若不存在返回 `-1`。

**示例 1：**

```
输入：nums = [1, 2, 3, 4], k = 4
输出：6
解释：子序列1 = [1,3]（和为4，积为3），子序列2 = [4]（和为4，积为4），乘积 = 3*4 = 12。
     或子序列1 = [4]，子序列2 = [1,3]。
```

**示例 2：**

```
输入：nums = [2, 2], k = 4
输出：4
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 1000`

## 解题思路

动态规划 + 哈希表。

状态定义：
- `dp[mask]` 表示使用 `mask` 所指定的子集，能否凑出和为 `k` 以及最大乘积

由于元素可以分为两组（两个不重叠子序列），可以先用 DP 计算所有子集中和为 `k` 的最大乘积，然后再枚举两个不重叠子集。

更高效的做法：
1. 用哈希表 `dp_left[i]` 记录使用前 `i` 个元素，和为 `k` 时的最大乘积
2. 用哈希表 `dp_right[i]` 记录使用后 `n-i` 个元素，和为 `k` 时的最大乘积
3. 枚举分割点，取 `dp_left[i] * dp_right[i]` 的最大值

## Python 代码实现

### 方法一：DP 枚举所有子集

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # 对每个子集，计算和与乘积
        # 找所有和为 k 的子集，记录其乘积
        # 然后枚举两个不重叠的子集

        # dp_sum[mask] = mask 对应子集的元素和
        # dp_prod[mask] = mask 对应子集的元素乘积
        # 但 n<=100，mask 不可行，改用 DP

        # dp[i][s] = 使用前 i 个元素，选出若干元素和为 s 时的最大乘积集合
        # 记录前半段和后半段的状态

        # 前缀 DP：dp_l[i][s] = 考虑前 i 个元素，选出和为 s 的子序列的最大乘积
        INF = float('inf')
        # dp[s] = 能达到和 s 时的最大乘积（-INF 表示不可达）
        # 选 0 个元素时，和为 0，乘积为 1（空集乘积定义为 1）

        def build_dp(arr):
            # 返回 dp，dp[s] = 子集和为 s 的最大乘积
            dp = {0: 1}  # 空集：和为0，积为1
            for x in arr:
                new_dp = dict(dp)
                for s, prod in dp.items():
                    ns = s + x
                    np_ = prod * x
                    if ns not in new_dp or new_dp[ns] < np_:
                        new_dp[ns] = np_
                dp = new_dp
            return dp

        # 分割点：前 i 个元素和后 n-i 个元素
        best = -1
        for split in range(n + 1):
            dp_left = build_dp(nums[:split])
            dp_right = build_dp(nums[split:])
            if k in dp_left and k in dp_right:
                best = max(best, dp_left[k] * dp_right[k])

        return best
```

### 方法二：前缀 DP + 后缀 DP

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # prefix_dp[i] = 使用 nums[0:i] 的子集，和为 k 时的最大乘积
        # suffix_dp[i] = 使用 nums[i:n] 的子集，和为 k 时的最大乘积

        def compute_dp_list(arr):
            # 返回每个前缀位置的 dp 字典列表
            dp = {0: 1}
            result = [dict(dp)]
            for x in arr:
                new_dp = dict(dp)
                for s, prod in dp.items():
                    ns = s + x
                    np_ = prod * x
                    if ns not in new_dp or new_dp[ns] < np_:
                        new_dp[ns] = np_
                dp = new_dp
                result.append(dict(dp))
            return result

        prefix = compute_dp_list(nums)
        suffix = compute_dp_list(nums[::-1])[::-1]

        best = -1
        for i in range(n + 1):
            # 前 i 个元素用 prefix[i]，后 n-i 个元素用 suffix[i]
            if k in prefix[i] and k in suffix[i]:
                best = max(best, prefix[i][k] * suffix[i][k])

        return best
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)，每个分割点 O(n * k) 的 DP
- 空间复杂度：O(n * k)，DP 表

## 关键点总结

1. 两个不重叠子序列可以通过枚举分割点来保证不重叠
2. 前缀 DP 和后缀 DP 分别计算左右两部分的最优解
3. 空集的乘积定义为 1，和为 0

## 易错点

1. 空集乘积为 1，需要在初始化时体现
2. 两个子序列必须不重叠（不能共享元素）
3. 乘积可能很大，Python 中无需担心溢出
