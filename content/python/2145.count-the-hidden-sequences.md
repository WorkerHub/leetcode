## 题目描述

给你一个整数数组 `differences`，其中 `differences[i] = hidden[i+1] - hidden[i]`，`hidden` 是一个长度为 `differences.length + 1` 的隐藏数组。

已知 `lower <= hidden[i] <= upper`，返回满足条件的隐藏数组数量。

**示例 1：**
```
输入：differences = [1,-3,4], lower = 1, upper = 6
输出：2
解释：可能的 hidden 数组为 [3,4,1,5] 和 [4,5,2,6]，共 2 个。
```

**示例 2：**
```
输入：differences = [3,-4,5,1,-2], lower = -4, upper = 6
输出：4
```

**提示：**
- `n == differences.length`
- `1 <= n <= 10^5`
- `-10^5 <= differences[i] <= 10^5`
- `-10^5 <= lower <= upper <= 10^5`

## 解题思路

**前缀和 + 滑动窗口思维**

设 `hidden[0] = x`，则 `hidden[i] = x + prefix[i]`（前缀和）。

约束：`lower <= x + prefix[i] <= upper` 对所有 i 成立。

即：`lower - prefix[i] <= x <= upper - prefix[i]` 对所有 i 成立。

因此 x 的范围为：`max(lower - prefix[i]) <= x <= min(upper - prefix[i])`

x 的有效个数 = `max(0, min_upper - max_lower + 1)`。

## 代码实现

### 方法一：前缀和求范围（推荐）

```python
from typing import List

class Solution:
    def numberOfArrays(self, differences: List[int], lower: int, upper: int) -> int:
        # 计算前缀和（hidden[i] - hidden[0]）
        prefix = 0
        min_prefix = 0
        max_prefix = 0

        for d in differences:
            prefix += d
            min_prefix = min(min_prefix, prefix)
            max_prefix = max(max_prefix, prefix)

        # x = hidden[0] 的范围
        # x + min_prefix >= lower -> x >= lower - min_prefix
        # x + max_prefix <= upper -> x <= upper - max_prefix
        x_lo = lower - min_prefix
        x_hi = upper - max_prefix

        return max(0, x_hi - x_lo + 1)
```

### 方法二：显式计算所有前缀和

```python
from typing import List

class Solution:
    def numberOfArrays(self, differences: List[int], lower: int, upper: int) -> int:
        prefix = [0] * (len(differences) + 1)
        for i, d in enumerate(differences):
            prefix[i + 1] = prefix[i] + d

        min_p = min(prefix)
        max_p = max(prefix)

        # x + min_p >= lower -> x >= lower - min_p
        # x + max_p <= upper -> x <= upper - max_p
        lo = lower - min_p
        hi = upper - max_p
        return max(0, hi - lo + 1)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(1) |

## 关键点总结

1. 设首元素为 x，隐藏数组所有值均可用 `x + prefix[i]` 表示。
2. 约束转化为对 x 的上下界约束，有效 x 的个数即答案。
3. 只需记录最小和最大前缀和，O(1) 空间。

## 易错点

- 前缀和包含 `prefix[0] = 0`（对应 hidden[0] = x 本身）。
- 结果可能为 0（没有合法的 x），要用 `max(0, ...)`。
