## 题目描述

给定整数数组 `arr` 和正整数 `k`，数组可以分成 `k` 个子序列（下标模 k 相同的元素组成一组）：
- 组 0：`arr[0], arr[k], arr[2k], ...`
- 组 1：`arr[1], arr[k+1], arr[2k+1], ...`
- ...

每次操作可以将数组中任意一个元素更改为任意值。求使每组子序列都是**非递减**的最少操作次数。

**示例 1：**
```
输入：arr = [5,4,3,2,1], k = 1
输出：4
解释：所有元素在同一组，需要使 [5,4,3,2,1] 非递减，最少改 4 个（保留最大的）。
```

**示例 2：**
```
输入：arr = [4,1,5,2,6,2], k = 2
输出：0
解释：组 0：[4,5,6] 已非递减；组 1：[1,2,2] 已非递减，不需操作。
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^9`
- `1 <= k <= arr.length`

## 解题思路

对每组子序列独立求解：最少改多少个元素使子序列非递减。

**关键观察：** 最少改的元素数 = 子序列长度 - 最长非递减子序列（LIS，非严格递增/非递减）的长度。

求最长非递减子序列可以用二分查找，时间 O(m log m)，m 为组的长度。

对所有 k 组求和即为答案。

## Python 代码实现

### 方法一：LIS（最长非递减子序列，推荐）

```python
from typing import List
import bisect

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        def lis_non_decreasing(nums: List[int]) -> int:
            """
            求最长非递减子序列长度（patience sorting）
            非递减：允许相等，即 a[i] <= a[j]
            """
            tails = []  # 维护各长度的最小尾元素
            for x in nums:
                # 找第一个 > x 的位置（保留 x，非严格递增用 bisect_right）
                pos = bisect.bisect_right(tails, x)
                if pos == len(tails):
                    tails.append(x)
                else:
                    tails[pos] = x
            return len(tails)

        total_ops = 0
        for start in range(k):
            group = arr[start::k]  # 组 start 的元素
            total_ops += len(group) - lis_non_decreasing(group)

        return total_ops
```

### 方法二：朴素 DP（适合小数组）

```python
from typing import List

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        def lis_len(nums: List[int]) -> int:
            n = len(nums)
            dp = [1] * n
            for i in range(n):
                for j in range(i):
                    if nums[j] <= nums[i]:
                        dp[i] = max(dp[i], dp[j] + 1)
            return max(dp)

        total = 0
        for start in range(k):
            group = arr[start::k]
            total += len(group) - lis_len(group)
        return total
```

## 复杂度分析

- 时间复杂度：O(n log n)，每组 LIS 为 O(m log m)，总计 O(n log n)
- 空间复杂度：O(n/k)，每组的 tails 数组

## 关键点总结

1. 最少修改次数 = 总长度 - 最长非递减子序列长度
2. 非递减（允许相等）的 LIS 使用 `bisect_right`
3. 各组独立求解，结果求和

## 易错点

1. 非递减 LIS（允许相等）与严格递增 LIS 的二分方向不同（`bisect_right` vs `bisect_left`）
2. `arr[start::k]` 是 Python 的切片语法，直接获取每组元素
