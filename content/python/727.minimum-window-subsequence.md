## 题目描述

给定字符串 s1 和 s2，找出 s1 中最短的（连续）子串 window，使得 s2 是 window 的子序列。如果没有这样的窗口，返回空字符串 ""。

**示例：**
```
输入：s1 = "abcdebdde", s2 = "bde"
输出："bcde"
```

## Python 代码实现

```python
class Solution:
    def minWindow(self, s1: str, s2: str) -> str:
        m, n = len(s1), len(s2)
        i, j = 0, 0
        min_len = float('inf')
        result = ""
        
        while i < m:
            if s1[i] == s2[j]:
                j += 1
                if j == n:
                    # 找到一个窗口，向左收缩
                    end = i + 1
                    j -= 1
                    while j >= 0:
                        if s1[i] == s2[j]:
                            j -= 1
                        i -= 1
                    i += 1
                    j += 1
                    
                    if end - i < min_len:
                        min_len = end - i
                        result = s1[i:end]
                    
                    j = 0
            i += 1
        
        return result
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 先向右扩展找到完整子序列
2. 再向左收缩找到最小窗口
3. 记录最小窗口
