## 题目描述

给你一个整数数组 `nums`（下标从 0 开始）、一个目标元素 `target` 和一个特殊下标 `start`。

计算每个 `nums[i] == target` 的 `|i - start|` 值，返回这些值中的最小值。

**保证** `target` 在 `nums` 中存在。

**示例 1：**
```
输入：nums = [1,2,3,4,5], target = 5, start = 3
输出：1
```

**示例 2：**
```
输入：nums = [1], target = 1, start = 0
输出：0
```

## 解题思路

遍历数组，找到所有值等于 target 的下标，计算它们与 start 的距离，返回最小值。

## 代码实现

### 方法一：线性扫描（推荐）

```python
from typing import List

class Solution:
    def getMinDistance(self, nums: List[int], target: int, start: int) -> int:
        min_dist = float('inf')
        for i, val in enumerate(nums):
            if val == target:
                min_dist = min(min_dist, abs(i - start))
        return min_dist
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def getMinDistance(self, nums: List[int], target: int, start: int) -> int:
        return min(abs(i - start) for i, val in enumerate(nums) if val == target)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只需一次遍历，找所有等于 target 的位置，计算到 start 的距离
2. 题目保证 target 存在，所以最小值一定存在

## 易错点

- 使用绝对值 `abs(i - start)`，不是简单的 `i - start`
