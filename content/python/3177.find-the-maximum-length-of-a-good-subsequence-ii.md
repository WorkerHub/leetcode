## 题目描述

与 3176 题相同，但 `k` 的范围更大：
- `1 <= nums.length <= 10^5`
- `0 <= k <= min(nums.length, 10^3)`

需要 O(n * k) 的算法。

## 解题思路

与 3176 方法二相同，使用哈希表优化。

对每个新元素 `x`：
- 接在相同值后：`dp[x][j] + 1`
- 接在不同值后：`global_best[j-1] + 1`

但需要注意"不同值"排除自身：若 `global_best[j-1]` 是由值为 x 的子序列贡献的，则接上 x 后不应算不同，会导致重复计算。

需要额外维护 `global_second[j]`（全局最优中，不是来自值 x 的最优）。

## Python 代码实现

### 方法一：哈希表 + 全局最优与次优（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        # best[v][j]: 值为 v 结尾，有 j 处不同时的最优
        best = defaultdict(lambda: [0] * (k + 1))
        # top1, top2: 全局最优和次优（用于排除自身值的贡献）
        top1 = [0] * (k + 1)  # 最优值
        top1_val = [None] * (k + 1)  # 最优对应的数值
        top2 = [0] * (k + 1)  # 次优值

        ans = 0
        for x in nums:
            # 先计算当前 x 可以达到的新最优
            new_best = [0] * (k + 1)
            for j in range(k + 1):
                # 接在相同值（x）之后
                new_best[j] = best[x][j] + 1
                # 接在不同值之后（需要排除 x 自身的贡献）
                if j > 0:
                    if top1_val[j - 1] != x:
                        new_best[j] = max(new_best[j], top1[j - 1] + 1)
                    else:
                        new_best[j] = max(new_best[j], top2[j - 1] + 1)

            # 更新 best[x]
            for j in range(k + 1):
                if new_best[j] > best[x][j]:
                    best[x][j] = new_best[j]

            # 更新全局最优
            for j in range(k + 1):
                v = best[x][j]
                if v > top1[j]:
                    if top1_val[j] != x:
                        top2[j] = top1[j]
                    top1[j] = v
                    top1_val[j] = x
                elif v > top2[j] and top1_val[j] != x:
                    top2[j] = v
                ans = max(ans, v)

        return ans
```

### 方法二：简化版（略慢但清晰）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        # dp[v][j]: 以值 v 结尾、不同数恰好为 j 的最长子序列
        dp = defaultdict(lambda: [0] * (k + 1))
        # global_max[j]: 不同数恰好为 j 的全局最优
        g = [0] * (k + 2)

        ans = 0
        for x in nums:
            old = dp[x][:]  # 旧值
            for j in range(k, -1, -1):
                # 接在相同值后
                dp[x][j] = old[j] + 1
                # 接在不同值后（j > 0）
                if j > 0:
                    dp[x][j] = max(dp[x][j], g[j - 1] + 1)
            for j in range(k + 1):
                g[j] = max(g[j], dp[x][j])
                ans = max(ans, dp[x][j])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(V * k + k)，V 为不同值数量

## 关键点总结

1. 哈希表记录每个值结尾的 DP 状态
2. 全局最优需要维护最优和次优，以正确处理"不同值"的情况
3. 每次更新后同步更新全局最优

## 易错点

1. 接在"不同值"后需排除自身贡献（使用次优值）
2. 更新顺序：先用旧值计算新值，再更新全局
