## 题目描述

给定一个非空的非负整数数组 nums，数组的度的定义是指数组里任一元素出现频数的最大值。

你的任务是找到与 nums 拥有相同大小的度的最短连续子数组，返回其长度。

**示例：**
```
输入：nums = [1,2,2,3,1]
输出：2
解释：
度是 2，因为 1 和 2 都出现了 2 次
最短子数组是 [2,2]，长度为 2
```

## Python 代码实现

### 方法一：哈希表

```python
from typing import List
from collections import defaultdict

class Solution:
    def findShortestSubArray(self, nums: List[int]) -> int:
        # 记录每个数字的出现次数、首次出现位置、最后出现位置
        count = defaultdict(int)
        first = {}
        last = {}
        
        for i, num in enumerate(nums):
            count[num] += 1
            if num not in first:
                first[num] = i
            last[num] = i
        
        # 找到度
        degree = max(count.values())
        
        # 找到最短子数组
        min_len = len(nums)
        for num, freq in count.items():
            if freq == degree:
                min_len = min(min_len, last[num] - first[num] + 1)
        
        return min_len
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 记录每个元素的首尾位置
2. 找到出现次数最多的元素
3. 比较所有最高频元素的跨度
