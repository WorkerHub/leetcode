## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，你需要选出一个子集，使得子集中所有元素的乘积最大，且子集中的元素数目恰好为 `k`。

返回最大乘积（模 `10^9 + 7`）。

**示例 1：**

```
输入：nums = [1, 2, 3, 4], k = 2
输出：12
解释：选 {3, 4}，乘积 = 12。
```

**示例 2：**

```
输入：nums = [-1, -2, -3, 4], k = 3
输出：24
解释：选 {-1, -2, -3} 的乘积为 -6；
选 {-2, -3, 4} 乘积为 24。最大乘积为 24。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

含负数时，乘积的最大值需要考虑负负得正。

贪心策略：
1. 将 nums 排序。
2. 分析负数个数和正数个数：
   - 若 k 个数的乘积为正：选最大的 k 个数，或适当包含偶数个负数。
   - 关键：从排序数组的两端（最大正数和最大绝对值负数）选取。
3. 使用 DP 处理含 0 和负数的复杂情况。

## Python 代码实现

### 方法一：排序 + 贪心选取（推荐）

```python
from typing import List

class Solution:
    def maximumProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        nums.sort()
        n = len(nums)

        # 尝试从左端（最小/绝对值最大负数）和右端（最大正数）选 k 个
        # 用双指针枚举包含几个负数
        best = None
        left, right = 0, n - 1
        selected = k

        # 简化：枚举从右端取 r 个、从左端取 k-r 个（0 <= r <= k）
        # 并确保负数个数为偶数（乘积为正）或必须取奇数个负数
        def product(arr):
            res = 1
            for x in arr:
                res = (res * x) % MOD
            return res

        for r in range(k + 1):
            l = k - r
            if l > n - r:  # 左端取 l 个，右端取 r 个，需 l + r <= n
                continue
            # 从左端取 l 个（nums[0..l-1]），从右端取 r 个（nums[n-r..n-1]）
            if l + r > n:
                continue
            chosen = nums[:l] + nums[n - r:] if r > 0 else nums[:l]
            if len(chosen) != k:
                continue
            prod = 1
            for x in chosen:
                prod = (prod * x) % MOD
            # 注意：负数乘积可能为负，Python 取模会处理
            if best is None or prod > best:
                best = prod

        return best if best is not None else 0
```

### 方法二：DP（处理含 0 的情况）

```python
from typing import List

class Solution:
    def maximumProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        nums.sort()
        n = len(nums)

        # dp[i][j] = 从前 i 个元素中选 j 个的最大乘积（考虑符号）
        # 维护最大值和最小值（负数相乘可能变最大）
        # dp_max[i][j] 和 dp_min[i][j]
        INF = float('inf')
        dp_max = [[-INF] * (k + 1) for _ in range(n + 1)]
        dp_min = [[INF] * (k + 1) for _ in range(n + 1)]
        dp_max[0][0] = 1
        dp_min[0][0] = 1

        for i in range(1, n + 1):
            v = nums[i - 1]
            for j in range(k + 1):
                # 不选第 i 个元素
                dp_max[i][j] = dp_max[i - 1][j]
                dp_min[i][j] = dp_min[i - 1][j]
                # 选第 i 个元素
                if j >= 1 and dp_max[i - 1][j - 1] != -INF:
                    cand_max = dp_max[i - 1][j - 1] * v
                    cand_min = dp_min[i - 1][j - 1] * v
                    dp_max[i][j] = max(dp_max[i][j], cand_max, cand_min)
                    dp_min[i][j] = min(dp_min[i][j], cand_max, cand_min)

        return dp_max[n][k] % MOD
```

## 复杂度分析

- 时间复杂度：O(n * k)（方法二 DP）；O(k^2)（方法一枚举）
- 空间复杂度：O(n * k)（方法二）；O(k)（方法一）

## 关键点总结

1. 含负数时需要同时维护 DP 的最大值和最小值。
2. 负数与负数相乘可以得到正数（最大值），因此不能只追踪最大值。
3. 贪心从两端选取时，需要枚举从左端取几个。

## 易错点

1. 含 0 时乘积可能为 0，需小心处理。
2. Python 的取模对负数仍然非负，但比较大小时用原始值。
3. 初始状态 `dp[0][0] = 1` 表示空子集乘积为 1。
