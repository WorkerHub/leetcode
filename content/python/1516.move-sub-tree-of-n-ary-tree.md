## 题目描述

给你一棵以节点 `root` 为根的 N 叉树，以及两个节点 `p` 和 `q`。

将 `p` 所在子树移动到 `q` 下面（`q` 成为 `p` 的父节点），要求：
- 如果 `p` 已经是 `q` 的直接子节点，不做任何操作
- 如果 `q` 在 `p` 的子树中：先将 `q` 提升，然后再移动 `p`

返回移动后的树根节点。

**提示：**
- 树中节点数在 `[2, 1000]` 范围内
- 节点值各不相同

## 解题思路

### DFS + 父节点记录

关键步骤：
1. 找到 `p` 的父节点 `p_parent` 和 `q` 的父节点 `q_parent`
2. 判断 `q` 是否在 `p` 的子树中（若是，需要特殊处理）
3. 从 `p_parent` 的子节点列表中移除 `p`
4. 若 `q` 在 `p` 子树中，还需从 `p` 的子节点中移除 `q`，并让 `p` 的原父位置改为 `q`
5. 将 `p` 加入 `q` 的子节点

## 代码实现

### 方法一：DFS 处理父节点（推荐）

```python
class Solution:
    def moveSubTree(self, root: 'Node', p: 'Node', q: 'Node') -> 'Node':
        # 如果 p 已经是 q 的直接子节点，无需操作
        if p in q.children:
            return root

        # 找父节点：返回 {节点: 父节点}
        parent = {}

        def dfs(node, par):
            parent[node] = par
            for child in node.children:
                dfs(child, node)

        # 使用虚拟根节点处理 p 是根的情况
        dummy = Node(0, [root])
        dfs(dummy, None)

        p_parent = parent[p]
        q_parent = parent[q]

        # 判断 q 是否在 p 的子树中
        def in_subtree(node, target):
            if node == target:
                return True
            return any(in_subtree(child, target) for child in node.children)

        q_in_p = in_subtree(p, q)

        if q_in_p:
            # 从 p 的子节点中移除 q
            p.children.remove(q)
            # p_parent 用 q 替换 p
            idx = p_parent.children.index(p)
            p_parent.children[idx] = q
            # q 的子节点中用 p 替换（或直接 append）
            # q 的子节点增加 p
            q.children.append(p)
        else:
            # 从 p_parent 移除 p
            p_parent.children.remove(p)
            # 将 p 加入 q 的子节点
            q.children.append(p)

        # 如果 dummy 只有一个子节点，返回它
        return dummy.children[0]
```

### 方法二：迭代 BFS 找父节点

```python
from collections import deque

class Solution:
    def moveSubTree(self, root: 'Node', p: 'Node', q: 'Node') -> 'Node':
        if p in q.children:
            return root

        dummy = Node(0, [root])
        parent = {dummy: None}
        queue = deque([dummy])
        while queue:
            node = queue.popleft()
            for child in node.children:
                parent[child] = node
                queue.append(child)

        p_parent = parent[p]
        q_parent = parent[q]

        # 判断 q 是否在 p 子树中
        def in_subtree(node, target):
            stack = [node]
            while stack:
                cur = stack.pop()
                if cur == target:
                    return True
                stack.extend(cur.children)
            return False

        q_in_p = in_subtree(p, q)

        if q_in_p:
            p.children.remove(q)
            idx = p_parent.children.index(p)
            p_parent.children[idx] = q
            q.children.append(p)
        else:
            p_parent.children.remove(p)
            q.children.append(p)

        return dummy.children[0]
```

## 复杂度分析

- **时间复杂度**：O(N)，DFS/BFS 遍历整棵树
- **空间复杂度**：O(N)，父节点字典和递归栈

## 关键点总结

1. 用虚拟根节点（dummy）统一处理 p 是根节点的情况
2. 需要判断 `q` 是否在 `p` 的子树中，这决定了不同的处理逻辑
3. 操作时注意维护父节点关系

## 易错点

- 不判断 `q` 是否已经是 `p` 的直接子节点（提前返回）
- 忽略 `p` 是树根的特殊情况（用 dummy 节点解决）
