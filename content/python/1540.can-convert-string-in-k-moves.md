## 题目描述

给你两个字符串 `s` 和 `t`，你的目标是通过最多 `k` 次移动，将 `s` 转换为 `t`。

每次移动可以选择 `s` 的一个位置 `i`，将 `s[i]` 循环右移 1 位（`a -> b, ..., z -> a`）。每次移动必须选取不同的位置。

如果能在 `k` 次移动内完成，返回 `True`，否则返回 `False`。

**示例 1：**
```
输入：s = "input", t = "ouput", k = 9
输出：true
```

**示例 2：**
```
输入：s = "abc", t = "bcd", k = 10
输出：false
解释：每个字符都需要右移1次，需要3次不同位置，但这3次都是在第一轮...需要重新考虑。
```

**提示：**
- `1 <= s.length, t.length <= 10^5`
- `0 <= k <= 10^9`

## 解题思路

### 关键分析

如果 `len(s) != len(t)`，直接返回 False。

对每个位置 `i`，需要的移动次数 `d = (ord(t[i]) - ord(s[i])) % 26`。

- 若 `d == 0`，不需要操作
- 若 `d > 0`，需要一次**特定的移动次数**为 `d` 的操作

**约束：** 每次操作都必须用不同的位置，但多个位置可以在**不同轮次**使用相同步数。

若步数 `d` 需要用第 `c` 次（`d` 已经被用了 `c-1` 次），则实际需要的移动步数为 `d + 26 * (c - 1)`（在第 c 轮相同步数中）。

用计数数组 `cnt[d]` 记录步数 `d` 已被用了多少次，实际需要 `d + 26 * cnt[d]` 步，需要 `<= k`。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
class Solution:
    def canConvertString(self, s: str, t: str, k: int) -> bool:
        if len(s) != len(t):
            return False

        # cnt[d] 记录步数 d 已经使用的次数
        cnt = [0] * 26

        for cs, ct in zip(s, t):
            d = (ord(ct) - ord(cs)) % 26
            if d == 0:
                continue  # 不需要操作
            # 实际需要的移动步数
            actual = d + 26 * cnt[d]
            if actual > k:
                return False
            cnt[d] += 1

        return True
```

### 方法二：更详细的写法

```python
from collections import defaultdict

class Solution:
    def canConvertString(self, s: str, t: str, k: int) -> bool:
        if len(s) != len(t):
            return False

        # 统计每种步数需要几次
        count = defaultdict(int)
        for cs, ct in zip(s, t):
            diff = (ord(ct) - ord(cs)) % 26
            if diff != 0:
                count[diff] += 1

        # 对每种步数 d，第 i 次（1-indexed）需要 d + 26*(i-1) 步
        for d, times in count.items():
            # 最后一次需要 d + 26*(times-1) 步
            if d + 26 * (times - 1) > k:
                return False

        return True
```

## 复杂度分析

- **时间复杂度**：O(N)，遍历字符串
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 步数相同的位置不能在同一轮（同一 `k` 值）操作，要用不同轮次
2. 步数为 `d` 的第 `c` 次操作，实际消耗 `k` 的量为 `d + 26*(c-1)`
3. 只要最大实际消耗 `<= k` 即可

## 易错点

- `d=0` 的情况不需要任何操作，要跳过
- 实际消耗公式：`d + 26 * (已用次数)`（0-indexed 是 cnt[d]，1-indexed 是 times-1）
