## 题目描述

给你三个整数 `n`、`x` 和 `y`。

有 `n` 名表演者参加一个活动，活动有 `x` 个舞台。每名表演者必须在某一个舞台上表演，同一舞台可以有多名表演者。

每个舞台的得分是该舞台的**表演者数量**，若该数量不超过 `y`，则得分为表演者数量；否则得分为 `y`（即 `min(表演者数, y)`）。

活动的总分是所有**有表演者的舞台**的得分之和。

返回总分恰好为 `s`（对 `10^9+7` 取模）的方案数，其中 `1 <= s <= min(n*y, x*y)`。

实际上题目要求返回所有可能的 `(s, 方案数)` 对... 重新读一下：实际上要输出一个数组 `count`，其中 `count[s]` 是总分为 `s` 的方案数，对每个 `1 <= s <= n*y`。

**提示：**
- `1 <= n, x, y <= 300`

## 解题思路

**计数 DP + 组合数学：**

将问题分解：
1. 选择使用 `k` 个舞台（`1 <= k <= min(n, x)`）。
2. 将 `n` 名表演者分配到 `k` 个已选舞台（有序分配到无标签舞台 -> 需要考虑分组方式）。

**分步计算：**

- `f(k, s)` = 恰好用 `k` 个舞台，且总分恰好为 `s` 的分配方案数（舞台已经指定）。
- 最终答案 = `C(x, k) * f(k, s)` 求和（选 k 个舞台乘以在这 k 个舞台上的分配方案数）。

**`f(k, s)` 的计算：**
- `f(k, s)` = 将 `n` 名表演者分配到 `k` 个不同（有标号）舞台，每个舞台至少一人，得分恰好为 `s`。
- 得分 = sum of `min(cnt_i, y)` for each stage `i`。
- DP：`dp[stage][performers][score]`，但维度太高。

**换另一个 DP 视角：**

`g[j][s]` = 将 `n` 名表演者分配到 `j` 个已标号舞台（每个舞台至少1人），总分为 `s` 的方案数。

转移：在第 `j` 个舞台放 `c`（`1 <= c <= n`）名表演者，得分贡献 `min(c, y)`：
`g[j][s] += g[j-1][s - min(c,y)] * C(remaining, c)`

最终：`answer[s] = sum over k of C(x, k) * g[k][s]`

等价地，`g` 可以用 2D DP：`dp[performers_used][score]`，每次枚举当前舞台使用几个人。

## Python 代码实现

### 方法一：DP + 组合数学

```python
from typing import List

class Solution:
    def numberOfWays(self, n: int, x: int, y: int) -> List[int]:
        MOD = 10**9 + 7
        
        # 预计算组合数 C[n][k]
        max_n = n + 1
        C = [[0] * max_n for _ in range(max_n)]
        C[0][0] = 1
        for i in range(1, max_n):
            C[i][0] = 1
            for j in range(1, i + 1):
                C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD
        
        max_score = min(n, x) * y  # 最大可能总分
        # result[s] 是总分为 s 的方案数（s 从 1 开始）
        result = [0] * (max_score + 1)
        
        # dp[i][s] = 恰好使用 i 个（有标号）舞台，分配了某些表演者，总分为 s 的方案数
        # 同时跟踪使用的表演者数
        # 三维 DP：dp[stages][performers][score]
        # dp[j][p][s] = 分配了 p 名表演者到 j 个有标号舞台（每个至少1），总分为 s 的方案数
        
        # 初始化
        # dp[0][0][0] = 1（0个舞台，0个表演者，总分0）
        # 状态：(已用舞台数, 已分配表演者数, 当前总分)
        
        # 由于 stages <= min(n, x) <= 300，performers <= n <= 300，score <= 300*300 太大
        # 改变思路：只关心 stage 和 score，performers 通过 C 消掉
        
        # dp2[j][s] = j 个有标号舞台，n 名表演者全部分配，总分 s，每舞台至少1人的方案数
        # 不对，不需要全分配... 题目说每名表演者必须在某一舞台表演，所以 n 名全分配
        
        # 重新：dp[j][s] = n 名表演者分配到 j 个有标号舞台（每个至少1），总分为 s 的方案数
        # 每个舞台放 c_i 人（c_i >= 1），sum(c_i) = n，sum(min(c_i,y)) = s
        
        # 逐个舞台加入
        # dp[j][s] = sum_{c=1}^{n} C(remaining_after_j-1_stages, c) * dp[j-1][s - min(c,y)]
        # 但 remaining 依赖于已分配的人数，需要第三维
        
        # 三维 DP
        INF = float('inf')
        # dp[j][p][s] = 分配了 p 名表演者到 j 个有标号舞台，总分 s，每舞台至少1人
        max_stages = min(n, x)
        
        # 用滚动数组：prev[p][s]，cur[p][s]
        # 初始：0个舞台，0人，0分：1
        prev = [[0] * (max_score + 1) for _ in range(n + 1)]
        prev[0][0] = 1
        
        for j in range(1, max_stages + 1):
            cur = [[0] * (max_score + 1) for _ in range(n + 1)]
            for p in range(j - 1, n + 1):  # 已用了 p 名
                for s in range(max_score + 1):
                    if prev[p][s] == 0:
                        continue
                    # 第 j 个舞台放 c 名（c >= 1）
                    for c in range(1, n - p + 1):
                        ns = s + min(c, y)
                        if ns > max_score:
                            break
                        cur[p + c][ns] = (cur[p + c][ns] + prev[p][s] * C[n - p][c]) % MOD
            
            # 将 cur[n][*] 贡献到 result（j 个舞台，恰好用了 n 名）
            for s in range(1, max_score + 1):
                result[s] = (result[s] + C[x][j] * cur[n][s]) % MOD
            
            prev = cur
        
        return result[1:]  # 返回 s=1 到 max_score 的结果
```

## 复杂度分析

- 时间复杂度：O(min(n,x) * n^2 * min(n*y, x*y))，三维 DP
- 空间复杂度：O(n * min(n*y, x*y))

## 关键点总结

1. 使用三维 DP `dp[stages][performers][score]`，逐个舞台计算分配方案。
2. 组合数预处理（帕斯卡三角）加速 `C(n, k)` 查询。
3. 最终乘以 `C(x, k)` 表示从 `x` 个舞台中选 `k` 个的方案数。

## 易错点

1. 舞台数量限制：最多 `min(n, x)` 个舞台同时有人（不能超过 n 个人分到 n 个舞台）。
2. `min(c, y)` 是得分贡献，不是 c 本身。
3. 每个舞台至少 1 人（空舞台不计分）。
