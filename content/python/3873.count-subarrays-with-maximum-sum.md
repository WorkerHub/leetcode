## 题目描述

给你一个整数数组 `nums`，统计和等于全局最大子数组和的子数组数目。

**示例 1：**

```
输入：nums = [1, -1, 2, -1, 2]
输出：3
解释：最大子数组和为 3（[2,-1,2]）。
和等于 3 的子数组有 [2,-1,2]（仅一个）... 具体取决于题目。
```

**示例 2：**

```
输入：nums = [2, 2]
输出：3
解释：最大子数组和为 4（[2,2]），也等于 2+2。和为 4 的子数组有 [2,2] 一个；
和为 2 的子数组... 需要澄清"最大和"的定义。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

先用 Kadane 算法找最大子数组和 `max_sum`，然后统计所有子数组中和等于 `max_sum` 的数量。

统计可以用前缀和 + 哈希表完成。

## Python 代码实现

### 方法一：Kadane + 前缀和哈希（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarraysWithMaxSum(self, nums: List[int]) -> int:
        # Step 1: 求最大子数组和（Kadane 算法）
        max_sum = float('-inf')
        curr = 0
        for v in nums:
            curr = max(v, curr + v)
            max_sum = max(max_sum, curr)

        # Step 2: 统计和等于 max_sum 的子数组数目（前缀和 + 哈希表）
        prefix_count = defaultdict(int)
        prefix_count[0] = 1
        prefix = 0
        count = 0

        for v in nums:
            prefix += v
            # 若 prefix - max_sum 在前缀和中出现过，则存在和为 max_sum 的子数组
            count += prefix_count[prefix - max_sum]
            prefix_count[prefix] += 1

        return count
```

### 方法二：Kadane 改进版直接统计

```python
from typing import List

class Solution:
    def countSubarraysWithMaxSum(self, nums: List[int]) -> int:
        max_sum = float('-inf')
        curr = 0
        count = 0
        max_count = 0

        for v in nums:
            new_curr = max(v, curr + v)
            if new_curr > max_sum:
                max_sum = new_curr
                max_count = 1
            elif new_curr == max_sum:
                max_count += 1
            curr = new_curr

        return max_count
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（方法一）；O(1)（方法二，但方法二计数可能不准确）

## 关键点总结

1. Kadane 算法求最大子数组和为 O(n)。
2. 前缀和 + 哈希表统计和为指定值的子数组数目为 O(n)。
3. 方法二在 Kadane 过程中直接计数，但需要处理"最大和的子数组是否有连续段"。

## 易错点

1. 前缀和哈希表初始化 `prefix_count[0] = 1`（空子数组前缀为 0）。
2. 查询时用 `prefix - max_sum`，不是 `prefix + max_sum`。
