## 题目描述

给你一个长度为 `n` 的整数数组 `nums`，每次操作可以将某个元素增加或减少 1（代价为 1）。

你希望通过若干次操作，使所有元素相等，且相等的值为 **回文数**（即十进制表示下正读反读都一样）。

返回达到此目标的最少总代价。

**示例 1：**
```
输入：nums = [1,2,3,4,5]
输出：6
解释：将所有元素变为 3（回文数），代价=|1-3|+|2-3|+|3-3|+|4-3|+|5-3|=2+1+0+1+2=6
```

**示例 2：**
```
输入：nums = [10,12,13,14,15]
输出：11
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

最小化 `sum |nums[i] - x|` 当 x 为回文数时，最优目标值是中位数附近的回文数。

步骤：
1. 排序找中位数
2. 在中位数附近找最近的回文数（向左和向右各找一个）
3. 计算两个候选回文数的代价，取最小值

判断回文数：字符串翻转比较。

## Python 代码实现

### 方法一：中位数 + 寻找最近回文数（推荐）

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        def is_palindrome(x: int) -> bool:
            s = str(x)
            return s == s[::-1]

        def cost(target: int) -> int:
            return sum(abs(x - target) for x in nums)

        nums.sort()
        median = nums[len(nums) // 2]

        # 向左找最近的回文数
        left = median
        while not is_palindrome(left):
            left -= 1

        # 向右找最近的回文数
        right = median
        while not is_palindrome(right):
            right += 1

        return min(cost(left), cost(right))
```

### 方法二：枚举附近回文数

```python
from typing import List

class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        def is_palindrome(x: int) -> bool:
            return str(x) == str(x)[::-1]

        def cost(target: int) -> int:
            return sum(abs(x - target) for x in nums)

        nums.sort()
        mid = nums[len(nums) // 2]

        # 搜索范围：中位数附近
        best = float('inf')
        # 回文数间距不超过 10（1-9位数的回文数间距分析）
        # 安全起见搜索 +-1000 范围
        for x in range(max(1, mid - 1000), mid + 1001):
            if is_palindrome(x):
                best = min(best, cost(x))

        return best
```

## 复杂度分析

- 时间复杂度：O(n log n + D * n)，D 为搜索范围大小
- 空间复杂度：O(1)

## 关键点总结

1. 目标值是中位数附近的回文数（使绝对值之和最小，中位数是最优解）
2. 向左向右各找一个最近的回文数，取代价最小的
3. 最近的回文数距离中位数不超过几十步（实际很近）

## 易错点

1. 目标值必须是正整数回文数（x >= 1）
2. 中位数可能本身就是回文数，代价为 0（不用找其他的）
3. 向两侧都要检查，因为左右距离不一定相同
