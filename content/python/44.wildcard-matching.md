## 题目描述

给定一个字符串 `s` 和一个字符模式 `p`，实现一个支持 `'?'` 和 `'*'` 的通配符匹配。

- `'?'` 可以匹配任何单个字符
- `'*'` 可以匹配任意字符串（包括空字符串）

两个字符串完全匹配才算匹配成功。

**示例 1：**
```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串
```

**示例 2：**
```
输入：s = "aa", p = "*"
输出：true
解释：'*' 可以匹配任意字符串
```

**示例 3：**
```
输入：s = "cb", p = "?a"
输出：false
解释：'?' 可以匹配 'c', 但第二个 'a' 无法匹配 'b'
```

**提示：**
- `0 <= s.length, p.length <= 2000`
- `s` 仅由小写英文字母组成
- `p` 仅由小写英文字母、`'?'` 或 `'*'` 组成

## 解题思路

**方法对比：**
1. **动态规划**：dp[i][j] 表示 s[0:i] 与 p[0:j] 是否匹配
2. **贪心 + 双指针**：记录 * 的位置，回溯匹配

## Python 代码实现

### 方法一：动态规划

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        
        # 空字符串匹配空模式
        dp[0][0] = True
        
        # 处理 p 以 * 开头的情况
        for j in range(1, n + 1):
            if p[j - 1] == '*':
                dp[0][j] = dp[0][j - 1]
        
        # 填表
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == '*':
                    # * 匹配 0 个或多个字符
                    dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
                elif p[j - 1] == '?' or s[i - 1] == p[j - 1]:
                    # ? 或字符匹配
                    dp[i][j] = dp[i - 1][j - 1]
        
        return dp[m][n]
```

### 方法二：贪心双指针

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        i, j = 0, 0
        star_idx, match = -1, 0
        
        while i < len(s):
            # 字符匹配或 ?
            if j < len(p) and (p[j] == '?' or s[i] == p[j]):
                i += 1
                j += 1
            # 遇到 *
            elif j < len(p) and p[j] == '*':
                star_idx = j
                match = i
                j += 1
            # 不匹配，回溯到上一个 *
            elif star_idx != -1:
                j = star_idx + 1
                match += 1
                i = match
            else:
                return False
        
        # 检查剩余的 p 是否全是 *
        while j < len(p) and p[j] == '*':
            j += 1
        
        return j == len(p)
```

## 复杂度分析

**动态规划：**
- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

**贪心：**
- 时间复杂度：O(m × n)（最坏情况）
- 空间复杂度：O(1)

## 关键点总结

1. **`*` 的处理**：可以匹配 0 个或多个字符
2. **贪心策略**：记录 * 的位置，需要时回溯
3. **剩余模式**：最后检查剩余的 p 是否全是 *

## 易错点

1. **初始化**：p 开头的 * 可以匹配空串
2. **回溯**：贪心方法需要正确处理回溯
