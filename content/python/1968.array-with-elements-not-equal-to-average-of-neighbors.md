## 题目描述

给你一个长度为 `n` 的下标从 0 开始的数组 `nums`，其中 **n** 是奇数，且 `nums` 中所有整数各不相同。

你希望将 `nums` 重新排列，使得每个索引 `i` 处的元素满足：`nums[i] != (nums[i-1] + nums[i+1]) / 2`（即不等于相邻两元素的平均值）。

返回任意一个满足条件的数组（保证有解）。

**示例 1：**
```
输入：nums = [1, 2, 3, 4, 5]
输出：[1, 2, 4, 5, 3]（或其他合法答案）
```

**提示：**
- `3 <= n <= 10^5`，n 为奇数
- `nums` 中整数各不相同

---

## 解题思路

### 核心思想：排序 + 交错放置

将数组排序后，将前半部分（小的数）放在偶数位，后半部分（大的数）放在奇数位（或反过来）：

**排序后**：`[small, ..., mid, ..., large]`

**交错**：偶数位放 small，奇数位放 large：
- 位置 0, 2, 4, ...：`nums[0], nums[1], ...`（前半小数）
- 位置 1, 3, 5, ...：`nums[half], nums[half+1], ...`（后半大数）

这样相邻的小数和大数不会使中间的值恰好等于平均值（因为三个值来自不同的"档次"）。

---

## 代码实现

### 方法一：排序 + 交错（推荐）

```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        half = (n + 1) // 2

        result = []
        # 交错放置：先放前半（小的），再放后半（大的）
        # 偶数位：前半，奇数位：后半
        for i in range(half):
            result.append(nums[i])
            if i + half < n:
                result.append(nums[i + half])

        return result
```

### 方法二：原地交换（先排序后交换相邻）

```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        nums.sort()
        # 交换相邻的奇数位和偶数位（步长为 2）
        for i in range(1, len(nums) - 1, 2):
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
        return nums
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n log n) | O(n) |
| 方法二 | O(n log n) | O(1) |

---

## 关键点总结

1. 排序后交错放置，确保相邻元素来自不同"档次"（大/小）
2. 方法二交换奇数位的相邻元素，产生"峰谷"模式

---

## 易错点

- 注意 n 为奇数，前半长度 = `(n+1)//2`，后半 = `n//2`
- 方法二的交换步长为 2，每次交换 `nums[i]` 和 `nums[i+1]`（i 从 1 开始）
