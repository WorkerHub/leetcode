## 题目描述

一个迷宫有 `n` 个房间，`corridors[i] = [room1, room2]` 表示两个房间之间有走廊（无向图）。

如果三个房间 `a, b, c`（两两不同）满足：
- a-b 有走廊
- b-c 有走廊
- a-c 有走廊

则称 `(a, b, c)` 是一个**环形三元组**（三角形）。

返回迷宫中环形三元组的数目。

**示例：**
```
输入：n = 5, corridors = [[1,2],[5,2],[4,1],[2,4],[3,1],[3,4]]
输出：2
```

**提示：**
- `2 <= n <= 1000`
- `1 <= corridors.length <= 5 * 10^4`

## 解题思路

枚举每条边 `(u, v)`，统计同时与 `u` 和 `v` 相邻的节点数（即它们的共同邻居数），这些节点与 `(u, v)` 形成三角形。

但每个三角形会被计算 3 次（三条边各一次），所以最后除以 3。

**优化：** 使用邻接表集合，共同邻居 = `adj[u] & adj[v]`。

## 代码实现

### 方法一：集合求交集（推荐）

```python
from typing import List

class Solution:
    def numberOfPaths(self, n: int, corridors: List[List[int]]) -> int:
        # 构建邻接集合
        adj = [set() for _ in range(n + 1)]
        for u, v in corridors:
            adj[u].add(v)
            adj[v].add(u)

        count = 0
        for u, v in corridors:
            # 共同邻居数 = 形成三角形的数量（对每条边）
            count += len(adj[u] & adj[v])

        # 每个三角形被计算了 3 次
        return count // 3
```

### 方法二：位运算加速（适用于 n 较小时）

```python
from typing import List

class Solution:
    def numberOfPaths(self, n: int, corridors: List[List[int]]) -> int:
        # 用列表推导优化
        adj = [set() for _ in range(n + 1)]
        for u, v in corridors:
            adj[u].add(v)
            adj[v].add(u)

        total = sum(len(adj[u] & adj[v]) for u, v in corridors) // 3
        return total
```

## 复杂度分析

- 时间复杂度：O(E * sqrt(E))，每条边求集合交集
- 空间复杂度：O(n + E)

## 关键点总结

1. 枚举每条边，统计共同邻居数（即三角形中的第三个节点数）
2. 每个三角形被计数 3 次（三条边各一次），最后除以 3
3. 使用集合交集 `&` 快速计算共同邻居

## 易错点

- 除以 3（不是 2）：三角形 `(a, b, c)` 对应三条边 `(a,b)`, `(b,c)`, `(a,c)`，每条边都会找到第三个节点
- 节点编号从 1 开始
