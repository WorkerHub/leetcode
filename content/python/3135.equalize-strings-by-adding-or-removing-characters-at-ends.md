## 题目描述

给你两个字符串 `initial` 和 `target`。

每次操作可以在字符串的 **开头或结尾** 添加或删除一个字符。

返回将 `initial` 变为 `target` 所需的 **最少** 操作次数。

**示例 1：**
```
输入：initial = "abcde", target = "bcd"
输出：2
解释：删除开头 'a' 和结尾 'e'。
```

**示例 2：**
```
输入：initial = "abcde", target = "xyz"
输出：8
解释：删除 "abcde" 5 次，添加 "xyz" 3 次。
```

**提示：**
- `1 <= initial.length, target.length <= 5 * 10^4`

## 解题思路

最少操作数 = len(initial) + len(target) - 2 * LCS_prefix_suffix

这里的 LCS 是特殊的：需要找 `target` 的某个 **连续子串** 同时是 `initial` 的某个 **连续子串**（且这两个子串分别从两个字符串的某个位置到结尾/开头连续）。

实际上：操作只能从两端增删，因此最优策略是保留 initial 中的某段 `initial[l..r]` 不动，然后通过在两端增删来匹配。保留的段必须是 target 的某个连续子串。因此答案 = (l) + (n-1-r) + 添加 target 中不在保留段的部分。

更简单的理解：找 initial 和 target 的最长公共 **子串**（而非子序列），设长度为 lcs_len，答案 = len(initial) - lcs_len + len(target) - lcs_len。

## Python 代码实现

### 方法一：二分 + 滚动哈希（推荐）

```python
class Solution:
    def minOperations(self, initial: str, target: str) -> int:
        # 找 initial 和 target 的最长公共子串
        # 二分长度 + 滚动哈希
        n, m = len(initial), len(target)

        def check(length: int) -> bool:
            # 检查是否存在长度为 length 的公共子串
            MOD = (1 << 61) - 1
            BASE = 131
            # 计算 target 所有长度为 length 的子串哈希
            power = pow(BASE, length, MOD)
            h = 0
            for c in target[:length]:
                h = (h * BASE + ord(c)) % MOD
            hashes = {h}
            for i in range(length, m):
                h = (h * BASE - ord(target[i - length]) * power + ord(target[i])) % MOD
                hashes.add(h)
            # 检查 initial 中是否有匹配
            h = 0
            for c in initial[:length]:
                h = (h * BASE + ord(c)) % MOD
            if h in hashes:
                return True
            for i in range(length, n):
                h = (h * BASE - ord(initial[i - length]) * power + ord(initial[i])) % MOD
                if h in hashes:
                    return True
            return False

        lo, hi = 0, min(n, m)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1

        lcs_len = lo
        return (n - lcs_len) + (m - lcs_len)
```

### 方法二：DP 求最长公共子串（小数据）

```python
class Solution:
    def minOperations(self, initial: str, target: str) -> int:
        n, m = len(initial), len(target)
        # dp[i][j] = 以 initial[i-1] 和 target[j-1] 结尾的公共子串长度
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        max_len = 0
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if initial[i - 1] == target[j - 1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                    max_len = max(max_len, dp[i][j])
        return (n - max_len) + (m - max_len)
```

## 复杂度分析

- 时间复杂度：O((n+m) log(min(n,m)))，二分 + 滚动哈希
- 空间复杂度：O(n+m)

## 关键点总结

1. 操作只在两端，等价于保留中间某段，找两串最长公共子串
2. 答案 = len(initial) + len(target) - 2 * 最长公共子串长度
3. 二分 + 滚动哈希高效求最长公共子串

## 易错点

1. 注意是公共子串（连续），不是公共子序列
2. 哈希可能碰撞，可用双哈希提高正确率
