## 题目描述

袋子中装有一些物品，每个物品上印有数字 `1`、`0` 或 `-1`。

给你四个非负整数 `numOnes`、`numZeros`、`numNegOnes` 和 `k`。

袋子中共有 `numOnes` 个印有 `1` 的物品、`numZeros` 个印有 `0` 的物品和 `numNegOnes` 个印有 `-1` 的物品。设 `s` 是从袋子中挑出 `k` 个物品后的数字总和，返回可以得到的 **最大** `s`。

**示例 1：**

```
输入：numOnes = 3, numZeros = 2, numNegOnes = 0, k = 2
输出：2
解释：选 2 个 1，总和 = 2。
```

**示例 2：**

```
输入：numOnes = 3, numZeros = 2, numNegOnes = 0, k = 4
输出：3
解释：选 3 个 1 和 1 个 0，总和 = 3。
```

**提示：**

- `0 <= numOnes, numZeros, numNegOnes <= 50`
- `0 <= k <= numOnes + numZeros + numNegOnes`

## 解题思路

**贪心**：优先选 1，其次选 0，最后迫不得已选 -1。

- 取 `min(k, numOnes)` 个 1
- 剩余数量从 0 中取 `min(remaining, numZeros)` 个
- 还不够从 -1 中取

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def kItemsWithMaximumSum(self, numOnes: int, numZeros: int, numNegOnes: int, k: int) -> int:
        # 优先选 1
        take_ones = min(k, numOnes)
        k -= take_ones

        # 其次选 0（不影响总和，但消耗名额）
        take_zeros = min(k, numZeros)
        k -= take_zeros

        # 最后选 -1
        take_neg = k  # 剩余必须从 -1 中选

        return take_ones - take_neg
```

### 方法二：直接计算

```python
class Solution:
    def kItemsWithMaximumSum(self, numOnes: int, numZeros: int, numNegOnes: int, k: int) -> int:
        if k <= numOnes:
            # k 个全取 1
            return k
        elif k <= numOnes + numZeros:
            # 全部 1 都取，剩余取 0
            return numOnes
        else:
            # 全部 1 和 0 都取，剩余取 -1
            neg = k - numOnes - numZeros
            return numOnes - neg
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：按 1 > 0 > -1 的优先级选取
2. 选 0 不改变总和，但必须消耗选取名额
3. 最终总和 = 选 1 的数量 - 选 -1 的数量

## 易错点

1. 0 虽然不贡献价值，但必须在 1 选完后才选（不能跳过）
2. k 保证 <= 总物品数，所以最后不够时必定从 -1 中取
3. 结果直接是 `ones_count - neg_count`，不需要加零的数量
