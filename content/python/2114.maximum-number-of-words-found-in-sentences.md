## 题目描述

一个**句子**由若干**单词**组成，单词之间用**单个空格**分隔，句子开头和结尾没有多余空格。

给你一个字符串数组 `sentences`，其中 `sentences[i]` 是第 `i` 个句子。请你返回所有句子中**单词数最多**的那一个句子的单词数。

**示例 1：**
```
输入：sentences = ["alice and bob love leetcode", "i think so too", "this is great thanks very much"]
输出：6
解释：最后一个句子有 6 个单词。
```

**提示：**
- `1 <= sentences.length <= 100`
- `1 <= sentences[i].length <= 100`
- `sentences[i]` 仅由小写字母和空格组成
- 单词间恰好一个空格

## 解题思路

单词数 = 空格数 + 1。

统计每个句子中空格数（或直接用 `split()` 得到单词列表），取最大值。

## 代码实现

### 方法一：统计空格（推荐简洁）

```python
from typing import List

class Solution:
    def mostWordsFound(self, sentences: List[str]) -> int:
        # 空格数 + 1 = 单词数，取最大值
        return max(s.count(' ') + 1 for s in sentences)
```

### 方法二：split 分词

```python
from typing import List

class Solution:
    def mostWordsFound(self, sentences: List[str]) -> int:
        # 按空格分割后统计列表长度
        return max(len(s.split()) for s in sentences)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 统计空格 | O(n * m) | O(1) |
| split 分词 | O(n * m) | O(m)（临时列表） |

n 为句子数，m 为平均句子长度。

## 关键点总结

1. 空格数 + 1 = 单词数，利用题目"单词间恰好一个空格"的条件。
2. Python `str.split()` 默认按空白分割，返回单词列表，直接取 `len` 即可。

## 易错点

- 使用 `split()` 时若句子首尾有额外空格会影响结果，本题题目保证没有，但实际开发中需注意。
