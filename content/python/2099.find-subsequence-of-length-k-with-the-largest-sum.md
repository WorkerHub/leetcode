## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回长度为 `k` 的子序列，其元素和**最大**。

子序列的元素必须**按原始数组的顺序**排列。

**示例：**
```
输入：nums = [2,1,3,3], k = 2
输出：[3,3]
解释：和最大的长度2子序列是 [3,3]（下标 2 和 3）
```

**提示：**
- `1 <= nums.length <= 1000`
- `-10^5 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

**排序取前 k 大，按原顺序输出：**

1. 对 `(值, 下标)` 排序，取值最大的 k 个元素
2. 按原下标排序，返回对应的值

## 代码实现

### 方法一：排序 + 下标（推荐）

```python
from typing import List

class Solution:
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        # 对 (值, 下标) 排序，取最大的 k 个
        indexed = sorted(enumerate(nums), key=lambda x: x[1], reverse=True)
        top_k = indexed[:k]

        # 按原始下标排序，保持顺序
        top_k.sort(key=lambda x: x[0])

        return [v for _, v in top_k]
```

### 方法二：堆（适合大数据）

```python
from typing import List
import heapq

class Solution:
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        # 用最小堆维护前 k 大元素（(值, 下标)）
        heap = []
        for i, v in enumerate(nums):
            heapq.heappush(heap, (v, i))
            if len(heap) > k:
                heapq.heappop(heap)

        # 按下标排序
        heap.sort(key=lambda x: x[1])
        return [v for v, _ in heap]
```

### 方法三：Python 简洁写法

```python
from typing import List

class Solution:
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        indices = sorted(range(len(nums)), key=lambda i: -nums[i])[:k]
        return [nums[i] for i in sorted(indices)]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 | O(n log n) | O(n) |
| 堆 | O(n log k) | O(k) |

## 关键点总结

1. 找最大的 k 个值（可能有重复），按原下标顺序输出
2. 排序 + 取前 k + 按下标重排，三步解决
3. 有重复值时，下标不同的元素也是不同的子序列元素

## 易错点

- 不能只排序值，还要记录下标（保持原顺序）
- 有重复值时，每个下标是独立的（`enumerate` 保证）
- 最终返回按原数组顺序排列的值，不是按大小排列
