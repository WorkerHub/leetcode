## 题目描述

定义函数 `f(s)` 为字符串 `s` 中字典序最小字符出现的频率。

例如，若 `s = "dcce"`，那么 `f(s) = 2`，因为字典序最小字符是 `"c"`，它出现了 2 次。

给定两个字符串数组 `queries` 和 `words`，请返回一个整数数组 `answer`，其中每个 `answer[i]` 是满足 `f(queries[i]) < f(W)` 的 `words` 中单词数量。

示例 1：

```
输入：queries = ["cbd"], words = ["zaaaz"]
输出：[1]
解释：f("cbd") = 1，f("zaaaz") = 3，1 < 3，所以输出 [1]
```

示例 2：

```
输入：queries = ["bbb","cc"], words = ["a","aa","aaa","aaaa"]
输出：[1,2]
解释：f("bbb") = 3，f("cc") = 2
f("a") = 1，f("aa") = 2，f("aaa") = 3，f("aaaa") = 4
对于 "bbb"：只有 "aaaa" 满足 f("bbb") < f("aaaa")
对于 "cc"："aaa" 和 "aaaa" 都满足
```

## 解题思路

**核心步骤：**

1. 实现函数 `f(s)`：找出字典序最小字符的出现次数
2. 预处理 `words` 数组，计算每个单词的 `f` 值并排序
3. 对每个 query，使用二分查找统计满足条件的 words 数量

## Python 代码实现

```python
from typing import List
import bisect

class Solution:
    def numSmallerByFrequency(self, queries: List[str], words: List[str]) -> List[int]:
        """
        二分查找优化
        
        时间复杂度：O((n+m) * k + n log n)
        空间复杂度：O(n)
        """
        def f(s: str) -> int:
            """计算最小字符的频率"""
            min_char = min(s)
            return s.count(min_char)
        
        # 计算 words 的 f 值并排序
        word_f = sorted([f(w) for w in words])
        
        # 对每个 query 使用二分查找
        result = []
        for q in queries:
            q_f = f(q)
            # 找到第一个大于 q_f 的位置
            idx = bisect.bisect_right(word_f, q_f)
            # idx 右边的所有元素都满足条件
            result.append(len(word_f) - idx)
        
        return result
```

## 复杂度分析

- 时间复杂度：`O((n+m)k + n log n + m log n)`
  - n 是 words 长度，m 是 queries 长度，k 是平均字符串长度
- 空间复杂度：`O(n)`

## 关键点总结

1. 实现 `f(s)` 函数：找最小字符和计数
2. 预处理并排序 words 的 f 值
3. 二分查找优化查询

## 易错点

1. 混淆 bisect_left 和 bisect_right
2. 计数时忘记用 len(word_f) - idx
