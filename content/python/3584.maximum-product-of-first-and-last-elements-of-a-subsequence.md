## 题目描述

给定一个整数数组 `nums` 和整数 `m`。找出长度为 `m` 的子序列（保持相对顺序），使得子序列的第一个元素和最后一个元素的乘积最大化。返回该最大乘积。

**示例 1：**

```
输入：nums = [1, -1, 1, -2], m = 3
输出：2
解释：子序列 [1, -1, -2]：首 * 尾 = 1 * (-2) = -2
     子序列 [1, 1, -2]：1 * (-2) = -2
     子序列 [-1, 1, -2]：(-1) * (-2) = 2。最大为 2。
```

**示例 2：**

```
输入：nums = [1, 2, 3], m = 2
输出：6
```

**提示：**
- `2 <= m <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

枚举子序列的第一个元素 `nums[i]` 和最后一个元素 `nums[j]`（`i < j`，且 `j - i >= m - 1`）。

乘积 = `nums[i] * nums[j]`，要最大化这个乘积。

对每个右端点 `j`（从 `m-1` 开始），左端点 `i` 的范围是 `[0, j-m+1]`。

乘积最大值取决于 `nums[j]` 的正负：
- `nums[j] > 0`：选左端范围内最大的 `nums[i]`
- `nums[j] < 0`：选左端范围内最小的 `nums[i]`
- `nums[j] == 0`：乘积为 0

维护滑动窗口的最大值和最小值，或用前缀最大/最小值。

## Python 代码实现

### 方法一：前缀最大最小值（推荐）

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int], m: int) -> int:
        n = len(nums)
        result = float('-inf')

        # 对每个右端点 j（j >= m-1），左端点在 [0, j-m+1]
        # 维护 [0, j-m+1] 范围内的最大值和最小值

        # 前缀最大最小值
        prefix_max = [float('-inf')] * n
        prefix_min = [float('inf')] * n
        prefix_max[0] = prefix_min[0] = nums[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i-1], nums[i])
            prefix_min[i] = min(prefix_min[i-1], nums[i])

        for j in range(m - 1, n):
            left_max = prefix_max[j - m + 1]
            left_min = prefix_min[j - m + 1]
            result = max(result, nums[j] * left_max, nums[j] * left_min)

        return result
```

### 方法二：滑动窗口最大最小值

```python
from typing import List
from collections import deque

class Solution:
    def maxProduct(self, nums: List[int], m: int) -> int:
        n = len(nums)
        # 枚举右端点，维护左端点的滑动窗口最大最小值
        max_dq = deque()  # 单调递减（最大值）
        min_dq = deque()  # 单调递增（最小值）
        result = float('-inf')

        for j in range(n):
            left_bound = j - m + 1  # 左端点上限
            if left_bound > 0:
                # 将 left_bound-1 加入队列
                add_idx = left_bound - 1
                while max_dq and nums[max_dq[-1]] <= nums[add_idx]:
                    max_dq.pop()
                max_dq.append(add_idx)
                while min_dq and nums[min_dq[-1]] >= nums[add_idx]:
                    min_dq.pop()
                min_dq.append(add_idx)
            elif left_bound == 0:
                # 第一次：只有 nums[0]
                max_dq.append(0)
                min_dq.append(0)

            if j >= m - 1:
                cur_max = nums[max_dq[0]] if max_dq else float('-inf')
                cur_min = nums[min_dq[0]] if min_dq else float('inf')
                result = max(result, nums[j] * cur_max, nums[j] * cur_min)

        return result
```

## 复杂度分析

- 时间复杂度：O(n)，前缀最大最小值
- 空间复杂度：O(n)

## 关键点总结

1. 枚举右端点 j，左端点范围为 `[0, j-m+1]`
2. 乘积最大值需要考虑 nums[j] 的符号，选左端的最大或最小值
3. 前缀最大最小值 O(n) 预处理，查询 O(1)

## 易错点

1. 左端点范围是 `[0, j-m+1]`（不是 `[0, j-1]`），需要中间有 `m-2` 个元素间距
2. 当 `nums[j] < 0` 时，乘积最大需要选最小的（最负的）左端元素
3. 两种候选（最大 * nums[j] 和 最小 * nums[j]）都需要比较
