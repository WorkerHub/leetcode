## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，找到包含 `k` 个连续整数（值域上连续，不是位置上连续）的子数组的最大和。

即找到最大的子数组和，使得该子数组包含 `k` 个连续值（如 `[3, 5, 4]` 包含值 3, 4, 5，是连续的）。

**示例 1：**

```
输入：nums = [1, 4, 2, 3, 5], k = 3
输出：12
解释：包含值 {3,4,5} 的子数组中，[4,2,3,5] 的和最大（2+3+4+5... 需具体分析）。
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

枚举所有 k 个连续值的区间 `[v, v+k-1]`：
1. 找 nums 中属于 `[v, v+k-1]` 的所有元素，这些元素需要在数组中的一个连续子数组内。
2. 实际上，需要找最长的包含这 k 个值的子数组，并计算其和。

关键：不必包含全部 k 个值，只需子数组中出现的值满足覆盖连续 k 个值的要求。

## Python 代码实现

### 方法一：枚举连续值区间（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        # 对每个起始值 v，找包含 {v, v+1, ..., v+k-1} 的最优子数组
        n = len(nums)

        # 记录每个值在 nums 中出现的位置
        pos = defaultdict(list)
        for i, v in enumerate(nums):
            pos[v].append(i)

        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        ans = float('-inf')
        # 枚举所有可能的连续 k 个值的起始值
        all_vals = set(nums)
        for v in all_vals:
            if v + k - 1 not in all_vals:
                continue
            # 检查 v 到 v+k-1 是否都在 nums 中
            required = set(range(v, v + k))
            if not required.issubset(all_vals):
                continue

            # 找包含所有这些值的最短（或最大和）子数组
            # 找每个值在 nums 中的位置，取覆盖所有值的连续区间
            all_positions = []
            for u in required:
                all_positions.extend(pos[u])
            all_positions.sort()

            # 用滑动窗口找包含所有 k 个值的最大和子数组
            # 简化：找满足条件的所有子数组中和最大的
            # 略复杂，先用暴力验证

        return ans if ans != float('-inf') else 0
```

### 方法二：哈希表 + 前缀和

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 对每对 (l, r)，检查 nums[l..r] 是否包含某个连续 k 个值
        # 暴力方法（小数据）
        ans = float('-inf')
        for l in range(n):
            vals = set()
            xor = 0
            for r in range(l, n):
                vals.add(nums[r])
                # 检查 vals 是否包含连续 k 个值
                for v in vals:
                    if all(v + i in vals for i in range(k)):
                        ans = max(ans, prefix[r + 1] - prefix[l])
                        break

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * k)（暴力）；O(n log n)（优化版）
- 空间复杂度：O(n)

## 关键点总结

1. 枚举所有可能的 k 个连续值的集合，找覆盖该集合的最大子数组和。
2. 前缀和快速计算子数组和。
3. 优化方案：记录每个值的位置，用滑动窗口找最大和。

## 易错点

1. 连续值是指值域上连续（如 3,4,5），不是位置上连续。
2. 子数组可以包含额外的值（不仅仅是 k 个连续值）。
