## 题目描述

给你一个字符串 `s`，将该字符串中的大写字母转换成相同的小写字母，返回新的字符串。

**示例 1：**

```
输入：s = "Hello"
输出："hello"
```

**示例 2：**

```
输入：s = "here"
输出："here"
```

**示例 3：**

```
输入：s = "LOVELY"
输出："lovely"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 由 ASCII 字符集中的可打印字符组成

## 解题思路

这是一道字符串基础题，主要考察字符串处理和字符转换。

**核心思想：**
- 大写字母 A-Z 的 ASCII 码范围是 65-90
- 小写字母 a-z 的 ASCII 码范围是 97-122
- 大写字母转小写：ASCII 码值 + 32

**多种实现方式：**
1. 使用 Python 内置方法 `lower()`
2. 使用 ASCII 码转换
3. 使用字符映射

## Python 代码实现

### 方法一：内置方法（推荐）⭐

```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        """
        使用 Python 内置的 lower() 方法
        最简洁、最高效的方式
        """
        return s.lower()
```

### 方法二：ASCII 码转换

```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        """
        通过 ASCII 码转换实现
        大写字母 A-Z: 65-90
        小写字母 a-z: 97-122
        差值为 32
        """
        result = []
        
        for char in s:
            # 判断是否为大写字母
            if 'A' <= char <= 'Z':
                # 转换为小写：ASCII 码 + 32
                result.append(chr(ord(char) + 32))
            else:
                # 保持原样
                result.append(char)
        
        return ''.join(result)
```

### 方法三：使用 ASCII 码值判断

```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        """
        直接使用 ASCII 码值判断
        """
        result = []
        
        for char in s:
            ascii_val = ord(char)
            # 65-90 是大写字母 A-Z
            if 65 <= ascii_val <= 90:
                result.append(chr(ascii_val + 32))
            else:
                result.append(char)
        
        return ''.join(result)
```

### 方法四：列表推导式

```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        """
        使用列表推导式，代码更简洁
        """
        return ''.join([
            chr(ord(char) + 32) if 'A' <= char <= 'Z' else char
            for char in s
        ])
```

### 方法五：位运算优化

```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        """
        使用位运算
        大写字母和小写字母的 ASCII 码差异在第 6 位（从右往左数）
        通过 | 32 可以将大写转小写
        """
        result = []
        
        for char in s:
            if 'A' <= char <= 'Z':
                # 位运算：或上 0b100000 (32)
                result.append(chr(ord(char) | 32))
            else:
                result.append(char)
        
        return ''.join(result)
```

## 复杂度分析

### 所有方法：
- **时间复杂度：** O(n)，需要遍历字符串的每个字符
- **空间复杂度：** O(n)，需要创建新的字符串存储结果

## 图解示例

以 "Hello" 为例：

```
原字符串: H    e    l    l    o
ASCII码:  72   101  108  108  111
         (大写)(小写)(小写)(小写)(小写)

处理逻辑:
H (72) -> 是大写 -> 72 + 32 = 104 -> h
e (101) -> 是小写 -> 保持不变 -> e
l (108) -> 是小写 -> 保持不变 -> l
l (108) -> 是小写 -> 保持不变 -> l
o (111) -> 是小写 -> 保持不变 -> o

结果字符串: h    e    l    l    o
```

## 关键点总结

1. **ASCII 码规律**：大写字母和对应小写字母的 ASCII 码差值为 32
2. **字符判断**：可以用 `'A' <= char <= 'Z'` 或 `65 <= ord(char) <= 90` 判断大写字母
3. **字符转换**：`chr()` 和 `ord()` 函数实现字符与 ASCII 码的相互转换
4. **位运算技巧**：`ord(char) | 32` 可以将大写字母转为小写
5. **Python 特性**：实际应用中直接使用 `lower()` 最简洁高效

## 易错点

1. **忘记处理非字母字符**：数字、符号等应保持不变
2. **字符串不可变**：Python 中字符串不可变，需要创建新字符串
3. **ASCII 码范围**：只有 A-Z 需要转换，不要误转其他字符
4. **位运算的适用范围**：位运算 `| 32` 只对大写字母有效，对小写字母和其他字符可能产生错误
5. **空字符串处理**：题目保证长度至少为 1，但实际编程中要注意
