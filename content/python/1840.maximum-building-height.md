## 题目描述

在一座城市里，你需要建 `n` 座建筑。建筑的高度约束如下：
- 第一座建筑高度为 0
- 任意两座相邻建筑的高度差绝对值不超过 1
- 某些建筑有额外约束：`restrictions[i] = [idi, maxHeighti]` 表示第 `idi` 座建筑的高度不超过 `maxHeighti`

返回所有建筑的最大可能高度。

**示例：**
```
输入：n = 5, restrictions = [[2,1],[4,1]]
输出：2
```

## 解题思路

**两遍贪心传播**：

1. 将 restrictions 按建筑 ID 排序，并加入起点 (1, 0) 和终点 (n, INF)
2. **从左到右传播**：位置 i 的高度受左侧约束：`restrictions[i].maxH = min(restrictions[i].maxH, restrictions[i-1].maxH + (restrictions[i].id - restrictions[i-1].id))`
3. **从右到左传播**：位置 i 的高度受右侧约束：`restrictions[i].maxH = min(restrictions[i].maxH, restrictions[i+1].maxH + (restrictions[i+1].id - restrictions[i].id))`
4. 相邻两个约束点之间，最大高度在中点达到。设左端点 `(id1, h1)` 和右端点 `(id2, h2)`，则区间中最大高度为 `(h1 + h2 + (id2 - id1)) // 2`

## 代码实现

### 方法一：两遍传播 + 区间计算（推荐）

```python
from typing import List

class Solution:
    def maxBuilding(self, n: int, restrictions: List[List[int]]) -> int:
        # 加入终点约束（无限制，但最大高度受位置限制）
        restrictions.append([n, n - 1])
        # 加入起点约束
        restrictions.insert(0, [1, 0])
        restrictions.sort()

        m = len(restrictions)

        # 从左到右传播约束
        for i in range(1, m):
            diff = restrictions[i][0] - restrictions[i - 1][0]
            restrictions[i][1] = min(restrictions[i][1], restrictions[i - 1][1] + diff)

        # 从右到左传播约束
        for i in range(m - 2, -1, -1):
            diff = restrictions[i + 1][0] - restrictions[i][0]
            restrictions[i][1] = min(restrictions[i][1], restrictions[i + 1][1] + diff)

        # 计算每段区间的最大高度
        ans = 0
        for i in range(m - 1):
            id1, h1 = restrictions[i]
            id2, h2 = restrictions[i + 1]
            # 区间最大高度：从两端爬升，在中点相遇
            peak = (h1 + h2 + (id2 - id1)) // 2
            ans = max(ans, peak)

        return ans
```

### 方法二：仅用排序传播（注释详细版）

```python
from typing import List

class Solution:
    def maxBuilding(self, n: int, restrictions: List[List[int]]) -> int:
        # 处理约束，添加边界
        restr = [[1, 0]] + sorted(restrictions) + [[n, n - 1]]
        m = len(restr)

        # 正向传播：左侧限制
        for i in range(1, m):
            gap = restr[i][0] - restr[i - 1][0]
            restr[i][1] = min(restr[i][1], restr[i - 1][1] + gap)

        # 反向传播：右侧限制
        for i in range(m - 2, -1, -1):
            gap = restr[i + 1][0] - restr[i][0]
            restr[i][1] = min(restr[i][1], restr[i + 1][1] + gap)

        ans = 0
        for i in range(m - 1):
            # 两个约束点之间的峰值：(h1 + h2 + dist) // 2
            dist = restr[i + 1][0] - restr[i][0]
            peak = (restr[i][1] + restr[i + 1][1] + dist) // 2
            ans = max(ans, peak)

        return ans
```

## 复杂度分析

- **时间复杂度**：O(m log m)，排序 restrictions
- **空间复杂度**：O(m)，排序后的约束列表

## 关键点总结

1. 双向传播将每个约束点的高度上界压缩到可行范围
2. 相邻两约束点间，最大高度 = `(h1 + h2 + distance) // 2`（从两端各自爬升相遇）
3. 加入 (1, 0) 作为起点约束，加入 (n, n-1) 作为终点的松弛约束

## 易错点

- 终点约束高度上界不是无穷大，而是 `n-1`（从起点高度 0 最多爬升 n-1）
- 区间峰值公式推导：`h1 + x = h2 + (d - x)` → `x = (h2 - h1 + d) / 2`，峰值 = `h1 + x`
