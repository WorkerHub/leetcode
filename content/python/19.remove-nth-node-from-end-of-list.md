## 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**
```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**
```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**
```
输入：head = [1,2], n = 1
输出：[1]
```

**提示：**
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶：** 你能尝试使用一趟扫描实现吗？

## 解题思路

**核心思想：双指针（快慢指针）**

关键观察：
1. 倒数第 n 个节点 = 正数第 (L - n + 1) 个节点（L 为链表长度）
2. 要删除一个节点，需要找到它的前一个节点

**方法对比：**
- 方法一：先遍历计算长度，再找到目标节点（两次遍历）
- 方法二：双指针一次遍历（推荐）

**双指针技巧：**
1. 快指针先走 n 步
2. 快慢指针同时走，直到快指针到末尾
3. 此时慢指针指向倒数第 n 个节点的前一个节点

## Python 代码实现

### 方法一：双指针（推荐）

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        # 使用哑节点简化边界处理
        dummy = ListNode(0, head)
        fast = slow = dummy
        
        # 快指针先走 n 步
        for _ in range(n):
            fast = fast.next
        
        # 快慢指针同时移动
        while fast.next:
            fast = fast.next
            slow = slow.next
        
        # 删除倒数第 n 个节点
        slow.next = slow.next.next
        
        return dummy.next
```

### 方法二：计算长度法（两次遍历）

```python
class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        # 计算链表长度
        length = 0
        current = head
        while current:
            length += 1
            current = current.next
        
        # 哑节点
        dummy = ListNode(0, head)
        current = dummy
        
        # 找到倒数第 n 个节点的前一个节点
        # 它是正数第 (length - n) 个节点
        for _ in range(length - n):
            current = current.next
        
        # 删除节点
        current.next = current.next.next
        
        return dummy.next
```

### 方法三：递归法

```python
class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        def helper(node: ListNode) -> int:
            """返回当前节点是倒数第几个"""
            if not node:
                return 0
            
            # 递归到末尾
            count = helper(node.next) + 1
            
            # 如果下一个节点是倒数第 n 个，删除它
            if count == n + 1:
                node.next = node.next.next
            
            return count
        
        # 使用哑节点处理删除头节点的情况
        dummy = ListNode(0, head)
        helper(dummy)
        return dummy.next
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(L)，L 为链表长度，只遍历一次
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(L)，需要遍历两次
- 空间复杂度：O(1)

**方法三：**
- 时间复杂度：O(L)
- 空间复杂度：O(L)，递归调用栈

## 图解示例

以 `head = [1,2,3,4,5], n = 2` 为例：

```
初始状态：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
fast
slow

快指针先走 2 步：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
slow          fast

同时移动到 fast.next 为 null：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
              slow          fast

删除 slow.next (节点 4)：
dummy -> 1 -> 2 -> 3 -> 5 -> null
```

## 关键点总结

1. **哑节点技巧**：避免单独处理删除头节点的情况
2. **双指针间距**：快指针先走 n 步，保持间距为 n
3. **停止条件**：`fast.next == null`，此时 slow 指向待删除节点的前一个
4. **删除操作**：`slow.next = slow.next.next`

## 易错点

1. **边界情况**：删除头节点（倒数第 L 个节点）
   - 使用哑节点可以优雅处理
2. **快指针移动次数**：应该移动 n 次，不是 n+1 次
3. **停止条件**：是 `fast.next`，不是 `fast`
4. **链表为空**：题目保证至少有一个节点
5. **n 的范围**：题目保证 `1 <= n <= sz`，所以 n 一定合法
