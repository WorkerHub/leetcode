## 题目描述

给你一棵 `n` 个节点的树（编号 0 到 n-1），另有 `edges[i] = [ai, bi]` 表示无向边。

给你一个二维整数数组 `queries`，`queries[j] = [node1j, node2j, node3j]`。

对于每个查询，找到节点 `node3j` 到 `node1j-node2j` 路径上**任意节点**的**最短距离**，返回那个路径上的节点（若有多个最近点，返回编号最小的）。

对每个查询返回答案，组成结果数组。

## 解题思路

**LCA（最近公共祖先）+ 距离计算：**

1. 对每个查询 `(n1, n2, n3)`，路径 `n1 -> n2` 上的节点是 LCA 路径上的所有节点。
2. `n3` 到路径上某点 `v` 的距离 = `dist(n3, v)`。
3. 枚举路径 `n1->n2` 上的所有节点（通过 LCA 分解），找距 `n3` 最近的。

**简化方法：** `n3` 到路径 `n1->n2` 上的最近点就是 `LCA(n1, n3)`、`LCA(n2, n3)`、以及 `LCA(n1, n2)` 中最靠近 `n3` 的（深度最深）的那个。

具体：路径 `n1 -> n2` 上与 `n3` 最近的节点是以下三者中深度最大的：
- `LCA(n1, n2)`
- `LCA(n1, n3)`
- `LCA(n2, n3)`

## 代码实现

### 方法一：LCA + 深度比较（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def closestNode(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        # 建树
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS 计算深度和父节点（用于 LCA）
        depth = [-1] * n
        parent = [-1] * n
        depth[0] = 0

        from collections import deque
        queue = deque([0])
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    parent[v] = u
                    queue.append(v)

        def lca(u, v):
            """计算 u 和 v 的最近公共祖先"""
            while depth[u] > depth[v]:
                u = parent[u]
            while depth[v] > depth[u]:
                v = parent[v]
            while u != v:
                u = parent[u]
                v = parent[v]
            return u

        ans = []
        for n1, n2, n3 in query:
            # 路径 n1->n2 上与 n3 最近的节点
            # 候选：lca(n1,n2), lca(n1,n3), lca(n2,n3)
            candidates = [lca(n1, n2), lca(n1, n3), lca(n2, n3)]
            # 取深度最大的（最靠近叶子的，离 n3 最近）
            best = max(candidates, key=lambda x: depth[x])
            ans.append(best)

        return ans
```

### 方法二：二进制提升 LCA（更高效）

```python
from typing import List
from collections import defaultdict, deque
import math

class Solution:
    def closestNode(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        LOG = max(1, math.ceil(math.log2(n + 1)))
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        depth = [0] * n
        up = [[-1] * n for _ in range(LOG)]

        # BFS 初始化
        queue = deque([0])
        visited = [False] * n
        visited[0] = True
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    depth[v] = depth[u] + 1
                    up[0][v] = u
                    queue.append(v)

        up[0][0] = 0
        for k in range(1, LOG):
            for v in range(n):
                up[k][v] = up[k-1][up[k-1][v]]

        def lca(u, v):
            if depth[u] < depth[v]:
                u, v = v, u
            diff = depth[u] - depth[v]
            for k in range(LOG):
                if (diff >> k) & 1:
                    u = up[k][u]
            if u == v:
                return u
            for k in range(LOG - 1, -1, -1):
                if up[k][u] != up[k][v]:
                    u = up[k][u]
                    v = up[k][v]
            return up[0][u]

        return [max([lca(n1,n2), lca(n1,n3), lca(n2,n3)], key=lambda x: depth[x])
                for n1, n2, n3 in query]
```

## 复杂度分析

**方法一：**
- 预处理：O(n)，BFS。
- 每次查询：O(n)，朴素 LCA。
- 总体：O(n + q * n)。

**方法二（二进制提升）：**
- 预处理：O(n log n)。
- 每次查询：O(log n)。

## 关键点总结

1. 路径 `n1 -> n2` 上与 `n3` 最近的节点是三个 LCA 中深度最大的。
2. 三个候选：`LCA(n1,n2)`、`LCA(n1,n3)`、`LCA(n2,n3)`。
3. 深度最大即离 `n3` 最近（在路径上最"低"）。

## 易错点

- 朴素 LCA 需要先将两节点提升到同一深度，再同步向上。
- 三个 LCA 候选中取深度最大的（`max by depth`）。
