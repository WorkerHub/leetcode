## 题目描述

给定整数数组 `nums`，可以将数组中的任意子数组替换为该子数组的和（合并操作）。求合并若干次操作后，非递减数组的最大长度。

本题是某个简单版本的困难扩展。

**示例 1：**
```
输入：nums = [5,2,3,1]
输出：3
解释：合并 [5,2]->7，数组变为 [7,3,1]，再合并 [3,1]->4，变为 [7,4]，长度 2。
     或合并 [2,3,1]->6，变为 [5,6]，非递减，长度 2。
     或合并 [5,2,3]->10，变为 [10,1]，非递减？10>1 不是，再合并为 [11]，长度 1。
     更好：[5,2,3,1] -> [5,2,4] -> [5,6]，长度 2。
     实际能得到的最大长度需要更仔细分析。
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 10^6`

## 解题思路

动态规划 + 线段树/单调队列优化。

设 `dp[i]` 为以某段以 `i` 结尾的合并块为最后一块时，能形成的最长非递减数组长度。

`prefix[i]` 为前缀和。

设最后一个合并块为 `[j+1, i]`（值为 `prefix[i] - prefix[j]`），则需要：
- 前面的最后一块的值 <= `prefix[i] - prefix[j]`，即上一块的和 <= 当前块的和。
- `dp[i] = max(dp[j] + 1)` 对所有满足条件的 `j`。

用线段树优化查询。

## Python 代码实现

### 方法一：DP + 线段树（推荐）

```python
from typing import List

class Solution:
    def findMaximumLength(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]

        # dp[i]: 以前 i 个元素为结尾（按合并块划分）的最长非递减数组长度
        # last_val[i]: dp[i] 对应的最后一块的值（用于后续比较）
        dp = [0] * (n + 1)
        last_val = [0] * (n + 1)

        # 维护单调队列或线段树
        # 简化：O(n^2) DP
        for i in range(1, n + 1):
            for j in range(0, i):
                block_val = prefix[i] - prefix[j]
                if last_val[j] <= block_val:
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
                        last_val[i] = block_val

        return max(dp)
```

### 方法二：贪心（基础版本）

```python
from typing import List

class Solution:
    def findMaximumLength(self, nums: List[int]) -> int:
        n = len(nums)
        # 贪心：从左到右，每次尽量找最短的合并块使其满足非递减
        result = []
        i = 0
        cur_min = 0  # 当前合并块的和下限

        while i < n:
            cur_sum = 0
            j = i
            while j < n:
                cur_sum += nums[j]
                if cur_sum >= cur_min:
                    break
                j += 1
            result.append(cur_sum)
            cur_min = cur_sum
            i = j + 1

        return len(result)
```

## 复杂度分析

- 时间复杂度：方法一 O(n^2)；线段树优化 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. DP 状态：以第 `i` 个位置为结尾的最长非递减合并数组的长度和最后块的值
2. 前缀和快速计算合并块的值
3. 线段树维护"前缀和 <= 某阈值的最大 dp 值"

## 易错点

1. 更新 `last_val[i]` 时，若多个 `j` 都能转移，取使 `dp[i]` 最大的（同时 `last_val[i]` 应尽量小）
2. 初始状态：`dp[0] = 0, last_val[0] = 0`
