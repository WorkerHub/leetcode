## 题目描述

给定一个会议时间安排的数组 `intervals`，每个会议时间都会包括开始和结束的时间 `intervals[i] = [starti, endi]`，请你判断一个人是否能够参加这里面的全部会议。

**示例 1：**

```
输入：intervals = [[0,30],[5,10],[15,20]]
输出：false
解释：存在重叠的会议时间
```

**示例 2：**

```
输入：intervals = [[7,10],[2,4]]
输出：true
解释：没有重叠的会议时间
```

**提示：**
- `0 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti < endi <= 10^6`

## 解题思路

这是一道经典的区间问题。要判断一个人能否参加所有会议，关键是检查是否存在时间冲突。

核心思想：
1. 将所有会议按照开始时间排序
2. 检查相邻的两个会议是否有重叠
3. 如果前一个会议的结束时间大于后一个会议的开始时间，说明有冲突

关键观察：
- 排序后，只需要检查相邻会议即可
- 如果相邻会议都不冲突，那么整体就不冲突

## Python 代码实现

### 方法一：排序 + 遍历（推荐）⭐

```python
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        """
        排序后检查相邻会议是否冲突
        时间复杂度：O(n log n)
        空间复杂度：O(1) 或 O(n)，取决于排序算法
        """
        # 边界情况：空数组或只有一个会议
        if len(intervals) <= 1:
            return True
        
        # 按照会议开始时间排序
        intervals.sort(key=lambda x: x[0])
        
        # 检查相邻会议是否有重叠
        for i in range(1, len(intervals)):
            # 如果前一个会议的结束时间 > 当前会议的开始时间，说明冲突
            if intervals[i-1][1] > intervals[i][0]:
                return False
        
        return True
```

### 方法二：排序 + 简化版本

```python
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        """
        使用 all() 函数简化判断
        """
        if not intervals:
            return True
        
        intervals.sort()
        
        # 使用 all() 检查所有相邻会议都不冲突
        return all(intervals[i-1][1] <= intervals[i][0] 
                   for i in range(1, len(intervals)))
```

### 方法三：使用 zip 函数（Python 特色）

```python
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        """
        利用 zip 函数同时遍历相邻元素
        """
        if not intervals:
            return True
        
        intervals.sort()
        
        # zip(intervals, intervals[1:]) 创建相邻会议对
        return all(prev[1] <= curr[0] 
                   for prev, curr in zip(intervals, intervals[1:]))
```

### 方法四：暴力解法（用于对比学习）

```python
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        """
        暴力检查所有会议对
        时间复杂度：O(n^2)
        空间复杂度：O(1)
        """
        n = len(intervals)
        
        # 检查每一对会议是否冲突
        for i in range(n):
            for j in range(i + 1, n):
                # 判断两个区间是否重叠
                if self.isOverlap(intervals[i], intervals[j]):
                    return False
        
        return True
    
    def isOverlap(self, a: List[int], b: List[int]) -> bool:
        """判断两个区间是否重叠"""
        # 两个区间重叠的条件：
        # a 的开始时间 < b 的结束时间 AND b 的开始时间 < a 的结束时间
        return a[0] < b[1] and b[0] < a[1]
```

## 复杂度分析

**方法一（排序 + 遍历）：**
- 时间复杂度：O(n log n)，主要是排序的时间
- 空间复杂度：O(1) 或 O(log n)，取决于排序算法的实现

**方法四（暴力解法）：**
- 时间复杂度：O(n^2)，需要检查所有会议对
- 空间复杂度：O(1)

## 图解示例

以 `intervals = [[0,30],[5,10],[15,20]]` 为例：

```
排序前：
会议1: |==========================| [0, 30]
会议2:      |====|                   [5, 10]
会议3:               |====|          [15, 20]
         0    5   10   15   20   30

排序后顺序不变，检查：
- 会议1结束(30) > 会议2开始(5) → 冲突！
```

再看 `intervals = [[7,10],[2,4]]`：

```
排序前：
会议1:        |==|                   [7, 10]
会议2:  |==|                         [2, 4]
       0  2  4  7  10

排序后：
会议2:  |==|                         [2, 4]
会议1:        |==|                   [7, 10]
       0  2  4  7  10

检查：会议2结束(4) <= 会议1开始(7) → 无冲突！
```

## 关键点总结

1. **排序是关键**：按开始时间排序后，问题简化为检查相邻区间
2. **区间重叠判断**：前一个结束时间 > 后一个开始时间表示重叠
3. **时间复杂度优化**：排序方法 O(n log n) 优于暴力 O(n^2)
4. **边界条件**：注意处理空数组和单个会议的情况
5. **Python 技巧**：善用 `all()`、`zip()` 等函数简化代码

## 易错点

1. **重叠条件判断错误**
   ```python
   # 错误：使用 >= 会错误地认为刚好衔接的会议也冲突
   if intervals[i-1][1] >= intervals[i][0]:
       return False
   
   # 正确：使用 > ，允许前一个会议结束时下一个会议开始
   if intervals[i-1][1] > intervals[i][0]:
       return False
   ```

2. **忘记排序**
   ```python
   # 错误：没有排序就直接检查相邻会议
   for i in range(1, len(intervals)):
       if intervals[i-1][1] > intervals[i][0]:
           return False
   
   # 正确：先排序
   intervals.sort(key=lambda x: x[0])
   for i in range(1, len(intervals)):
       if intervals[i-1][1] > intervals[i][0]:
           return False
   ```

3. **空数组处理**：记得处理空数组的情况，应该返回 `True`

4. **区间的定义**：理解题目中的区间是左闭右开还是左闭右闭
