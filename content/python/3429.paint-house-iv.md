## 题目描述

有 `n` 栋房子排成一行，需要用 `k` 种颜色之一给每栋房子涂色。相邻房子**不能**涂相同颜色。

给你一个 `n x k` 的代价矩阵 `cost`，其中 `cost[i][j]` 是将第 `i` 栋房子涂第 `j` 种颜色的代价。

额外限制：第一栋和最后一栋房子必须涂**相同的颜色**。

返回满足条件的最小总代价。如果不可能，返回 -1。

**示例 1：**

```
输入：n = 3, cost = [[1,2,3],[1,4,6],[26,1,19]]
输出：10
解释：涂第 0,1,2 栋房子颜色为 0,2,0，代价 1+6+26... 不对
实际最优：颜色 1,0,1，代价 2+1+1=4... 
```

**提示：**
- `2 <= n <= 1000`
- `k == cost[0].length`
- `2 <= k <= 1000`
- `1 <= cost[i][j] <= 10^5`

## 解题思路

设第一栋和最后一栋都涂颜色 `c`，需要找涂色方案使总代价最小。

对每种颜色 `c`，枚举所有满足约束的涂色方案。

**优化**：使用 DP，但同时从两端向中间推进：
- `dp_left[i][j]` = 前 i+1 栋房子，第 i 栋涂颜色 j，第 0 栋涂颜色 c 的最小代价
- `dp_right[i][j]` = 后 (n-i) 栋房子，第 i 栋涂颜色 j，第 n-1 栋涂颜色 c 的最小代价

但枚举每个颜色 c 需要 O(k * n * k) 时间，总复杂度 O(k^2 * n)。

**更优方案**：不枚举固定颜色，直接 DP：
- `left[i][j]` = 从左到第 i 栋，第 i 栋涂颜色 j 的最小代价（不限第 0 栋颜色）
- `right[i][j]` = 从右到第 i 栋，第 i 栋涂颜色 j 的最小代价（不限第 n-1 栋颜色）

但需要第一和最后一栋颜色相同，所以枚举颜色 c，取 left[mid][c'] + right[mid+1][c'] 等。

实际上，对称 DP：左半部分和右半部分从两端向中间推进。

## Python 代码实现

### 方法一：双向 DP（推荐）

```python
from typing import List

class Solution:
    def minCost(self, n: int, cost: List[List[int]]) -> int:
        k = len(cost[0])
        INF = float('inf')

        # dp_left[j] = 第 0 栋涂颜色 j，从左涂到当前位置的最小代价
        # dp_right[j] = 第 n-1 栋涂颜色 j，从右涂到当前位置的最小代价
        # 最终：对每种颜色 c，取 dp_left 在中间某位置为 c' 时的最优 + dp_right...

        # 方案：对每个固定颜色 c（第 0 和第 n-1 栋），分别做 DP
        # left_dp[i][j]: 第 0 到 i 栋，第 0 栋涂 c，第 i 栋涂 j 的最小代价
        # 时间 O(n * k^2)，可优化为 O(n * k)（用最小/次小值）

        # 枚举第 0 栋颜色 c
        ans = INF

        for c in range(k):
            # 左侧 DP：从第 0 栋（颜色 c）到第 n//2 栋
            # left[j] = 涂到某位置，该位置颜色为 j 的最小代价
            left = [INF] * k
            left[c] = cost[0][c]

            for i in range(1, n // 2 + (1 if n % 2 == 1 else 0)):
                new_left = [INF] * k
                min1, min2 = INF, INF
                min1_idx = -1
                for j in range(k):
                    if left[j] < min1:
                        min2 = min1
                        min1 = left[j]
                        min1_idx = j
                    elif left[j] < min2:
                        min2 = left[j]

                for j in range(k):
                    if j == min1_idx:
                        prev_min = min2
                    else:
                        prev_min = min1
                    if prev_min < INF:
                        new_left[j] = prev_min + cost[i][j]
                left = new_left

            # 右侧 DP：从第 n-1 栋（颜色 c）到第 n//2 栋（或中间）
            right = [INF] * k
            right[c] = cost[n - 1][c]

            for i in range(n - 2, n // 2 - 1, -1):
                new_right = [INF] * k
                min1, min2 = INF, INF
                min1_idx = -1
                for j in range(k):
                    if right[j] < min1:
                        min2 = min1
                        min1 = right[j]
                        min1_idx = j
                    elif right[j] < min2:
                        min2 = right[j]

                for j in range(k):
                    if j == min1_idx:
                        prev_min = min2
                    else:
                        prev_min = min1
                    if prev_min < INF:
                        new_right[j] = prev_min + cost[i][j]
                right = new_right

            # 合并：在中间连接，颜色不同
            mid = n // 2
            if n % 2 == 1:
                # 中间节点已在 left 中
                # right 到 mid+1，left 到 mid，连接处颜色不同
                for j1 in range(k):
                    for j2 in range(k):
                        if j1 != j2 and left[j1] < INF and right[j2] < INF:
                            ans = min(ans, left[j1] + right[j2])
            else:
                for j1 in range(k):
                    for j2 in range(k):
                        if j1 != j2 and left[j1] < INF and right[j2] < INF:
                            ans = min(ans, left[j1] + right[j2])

        return ans if ans < INF else -1
```

### 方法二：全局 DP（不固定起始颜色）

```python
from typing import List

class Solution:
    def minCost(self, n: int, cost: List[List[int]]) -> int:
        k = len(cost[0])
        INF = float('inf')

        # left[j] = 从第 0 栋到当前，当前涂颜色 j 的最小代价（第 0 栋颜色任意）
        # 但需要记录第 0 栋颜色
        # 状态：(当前涂色, 第 0 栋涂色) -> 代价，太多状态

        # 简单暴力：枚举所有颜色 c
        ans = INF
        for c in range(k):
            dp = [INF] * k
            dp[c] = cost[0][c]

            for i in range(1, n):
                new_dp = [INF] * k
                # 最小和次小值优化
                sorted_vals = sorted(range(k), key=lambda x: dp[x])
                m1_idx, m2_idx = sorted_vals[0], sorted_vals[1]

                for j in range(k):
                    prev = dp[m1_idx] if j != m1_idx else dp[m2_idx]
                    if prev < INF:
                        new_dp[j] = prev + cost[i][j]
                dp = new_dp

            if dp[c] < INF:
                ans = min(ans, dp[c])

        return ans if ans < INF else -1
```

## 复杂度分析

- 方法二：
  - 时间复杂度：O(k * n * k) = O(n * k^2)，用最小/次小值优化为 O(n * k)
  - 空间复杂度：O(k)

## 关键点总结

1. 第一和最后一栋必须同色，枚举这个颜色后分别做 DP
2. 最小/次小值优化：O(k^2) 转移优化为 O(k)
3. 相邻不同色约束在转移时体现

## 易错点

1. 枚举颜色 c 后，最终只取 `dp[c]`（第 n-1 栋必须也是颜色 c）
2. 最小/次小值优化时，不能选和当前颜色相同的前一位置
3. 当 k=1 时（只有一种颜色），不可能满足相邻不同色，返回 -1
