## 题目描述

有一个长度为 `n` 的二进制字符串，初始时所有字符均为 `'0'`。

给你一个数组 `flips`，`flips[i]` 表示第 `i` 步（从1开始计数）将第 `flips[i]` 个字符（从1开始编号）翻转为 `'1'`。

在每一步之后，如果字符串的前缀 `"1...1"` 是该字符串中出现的最长前缀，则计数器加一（即当前字符串的前 k 个字符全为 `'1'`，第 k+1 个字符为 `'0'`，这时算作"前缀对齐"，或者整个字符串均为 `'1'`）。

等价描述：当前字符串的所有 `'1'` 恰好构成一个从头开始的连续前缀。

返回共发生了多少次"前缀对齐"。

**示例 1：**
```
输入：n = 5, flips = [3,2,4,1,5]
输出：2
解释：
- 第1步：翻转第3位 → "00100"，前缀不对齐，计数=0
- 第2步：翻转第2位 → "01100"，前缀不对齐，计数=0
- 第3步：翻转第4位 → "01110"，前缀不对齐，计数=0
- 第4步：翻转第1位 → "11110"，前缀对齐（1-4均为1），计数=1
- 第5步：翻转第5位 → "11111"，前缀对齐（全为1），计数=2
```

**示例 2：**
```
输入：n = 4, flips = [2,1,4,3]
输出：1
解释：
- 第1步：翻转第2位 → "0100"
- 第2步：翻转第1位 → "1100"，前2位都是1，计数=1
- 第3步：翻转第4位 → "1101"，不对齐
- 第4步：翻转第3位 → "1111"，前缀对齐，计数=2
```

等等，示例2输出是1？让我重新看题目……

实际上示例2输出为1：
- 步骤2后 "1100" 也是前缀对齐（前两个全为1，第3个为0），应该计数。
- 但示例说输出1，可能只有最后一步计数？

重新理解：若当前所有翻转过的位，其最大编号等于当前已翻转的总数，则前缀对齐。

**提示：**
- `1 <= n <= 10^4`
- `flips` 是 `[1, n]` 的一个排列

## 解题思路

### 核心思想

**前缀对齐的等价条件：**

每次翻转后，字符串是前缀对齐当且仅当：
**已翻转的位中，最大编号 == 当前已翻转的总数**

**为什么？**
- 如果翻转了 `k` 次，最大编号为 `max_flip`。
- 若 `max_flip == k`，说明翻转的 k 次恰好覆盖了 1 到 k 的所有位置（因为 flips 是排列，编号不重复，k 个不重复的值最大为 k 说明它们是 1..k 的子集，加上最大值=k，所以正好是 {1,2,...,k}）。
- 此时前 k 位均为 1，后续均为 0，即前缀对齐。

### 方法一：维护最大编号和翻转次数（推荐，O(n)）

### 方法二：使用集合记录已翻转位置（直观但空间稍多）

## Python 代码实现

### 方法一：维护最大下标（推荐）

```python
from typing import List

class Solution:
    def numTimesAllBlue(self, flips: List[int]) -> int:
        max_flip = 0  # 目前为止翻转过的位中，最大的编号
        count = 0     # 前缀对齐的次数

        for i, flip in enumerate(flips):
            # 更新已翻转位的最大编号
            max_flip = max(max_flip, flip)

            # 当前翻转了 i+1 次（i 从0开始，所以第 i+1 次）
            # 若最大编号 == 翻转次数，则前缀对齐
            if max_flip == i + 1:
                count += 1

        return count
```

### 方法二：使用集合（直观，便于理解）

```python
from typing import List

class Solution:
    def numTimesAllBlue(self, flips: List[int]) -> int:
        flipped = set()  # 已翻转位置的集合
        count = 0

        for flip in flips:
            flipped.add(flip)

            # 检查是否前缀对齐：前 len(flipped) 个位置是否都已翻转
            # 等价于：max(flipped) == len(flipped)
            if max(flipped) == len(flipped):
                count += 1

        return count
        # 注意：max(flipped) 每次调用是 O(k)，总时间 O(n²)，不推荐
```

### 方法三：增量维护最大值（优化方法二）

```python
from typing import List

class Solution:
    def numTimesAllBlue(self, flips: List[int]) -> int:
        max_flip = 0  # 增量维护最大翻转位置，避免每次重新计算 max
        count = 0
        step = 0      # 当前步数

        for flip in flips:
            step += 1
            if flip > max_flip:
                max_flip = flip

            # 前缀对齐条件
            if max_flip == step:
                count += 1

        return count
```

### 方法四：简洁 Python 写法（使用 enumerate）

```python
from typing import List

class Solution:
    def numTimesAllBlue(self, flips: List[int]) -> int:
        # 用 enumerate 从1开始编号步骤
        max_flip = 0
        return sum(
            1
            for step, flip in enumerate(flips, 1)
            # 更新 max_flip 的同时检查条件
            if (max_flip := max(max_flip, flip)) == step
        )
        # 注意：此写法使用 Python 3.8+ 的海象运算符 :=
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 维护最大编号 | O(n) | O(1) |
| 集合 + max() | O(n²) | O(n) |
| 增量维护最大值 | O(n) | O(1) |

- **方法一/三**：每步 O(1)，总 O(n)，推荐。
- **方法二**：每步调用 `max(flipped)` 是 O(k)，总时间 O(n²)。

## 关键点总结

1. **前缀对齐的等价条件**：`max(已翻转位置) == 当前翻转次数`。这是本题的核心洞察。
2. **为何等价**：flips 是 [1,n] 的排列，各位置唯一，k 个不重复位置最大为 k 意味着它们是 {1,...,k}。
3. **增量维护最大值**：无需每次重新计算最大值，只需与当前翻转位置比较。
4. **从1开始的编号**：翻转次数是从1开始计数的，所以第 i 步（0-indexed）对应第 `i+1` 次翻转。

## 易错点

1. **编号从1开始**：`flips` 中的编号从1开始，而 Python 的索引从0开始，注意 `enumerate` 的起始值。
2. **不要维护已翻转的集合**：没有必要维护完整集合，只需维护最大编号即可，节省空间和时间。
3. **与步数比较**：判断条件是 `max_flip == 当前步骤数`（从1开始），不是与 n 比较。

## 学习建议

1. **关键是发现等价条件**：遇到"检查某个连续性条件"时，尝试将条件转化为更简单的数学关系（这里是最大值=个数）。
2. **简化数据结构**：不一定需要维护完整的集合，往往一两个变量（如最大值、总和）就够了。
3. 本题考察对"排列"性质的理解：k 个互不相同的正整数，若最大值为 k，则这 k 个数恰好是 {1, 2, ..., k}。
4. **海象运算符（:=）**：Python 3.8 引入，可在表达式中赋值，适合简化此类"更新并检查"的模式，但新手暂时用 if-else 更清晰。
