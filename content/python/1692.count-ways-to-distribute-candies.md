## 题目描述

有 `n` 颗糖，现在你想把这 `n` 颗糖**分配**到 `k` 个袋子里，每个袋子**至少有一颗糖**，而且每种分配方案都是独一无二的。

即使两个袋子里的糖数量相同，它们也被认为是不同的（袋子有标号）。两种分配方案不同当且仅当至少有一个袋子的糖数不同。

请你返回将 `n` 颗糖分配到 `k` 个袋子里的**方案数**，对 `10^9 + 7` 取余。

**注意：** 这是把 `n` 个**不同**的糖放入 `k` 个有标号的袋子，每袋至少一颗——即第二类 Stirling 数 S(n, k) 乘以 k!。或者，这是把 n 个相同糖（或题目含义）分到 k 个不同袋子的问题。

实际上，本题是将 n 颗**相同**糖分配到 k 个**有区别**的袋子中，每袋至少 1 颗，即经典的**隔板法**，答案为 C(n-1, k-1)。

但根据原题数据范围 `1 <= k <= n <= 1000`，并且答案要对 1e9+7 取模，本题采用 DP：
- `dp[i][j]` = 将前 `i` 颗糖分到 `j` 个袋子（每袋至少 1 颗）的方案数
- 等价于第二类 Stirling 数乘以 j!（若糖不同），或组合数（若糖相同）

结合题目实际（根据 LeetCode 1692 原题）：将 n 颗**不同**糖分配到 k 个**有序**袋子，每袋至少 1 颗，答案为 S(n,k) * k!（k! 倍的第二类 Stirling 数）。

**提示：**
- `1 <= k <= n <= 1000`

## 解题思路

本题实际是求将 n 个**不同**元素分配到 k 个**有标签**的非空子集中的方案数。

设 `dp[i][j]` 为将前 `i` 颗糖（从 1 到 i）分到 `j` 个袋子（每袋至少 1 颗）的方案数。

第 `i` 颗糖有两种选择：
1. 自己成为第 `j` 个新袋子（独自一袋），前 `i-1` 颗糖分到 `j-1` 个袋子：`dp[i-1][j-1]`
2. 放进已有的 `j` 个袋子之一：`j * dp[i-1][j]`

状态转移：`dp[i][j] = dp[i-1][j-1] + j * dp[i-1][j]`

初始条件：`dp[0][0] = 1`，`dp[i][0] = 0`（i>0）。

## 代码实现

### 方法一：二维 DP（推荐）

```python
class Solution:
    def waysToDistribute(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[i][j]：将 i 颗不同糖分到 j 个有标签的非空袋子的方案数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 1  # 0 颗糖放入 0 个袋子，1 种方案

        for i in range(1, n + 1):
            for j in range(1, k + 1):
                # 第 i 颗糖单独成一袋（前 i-1 颗放入 j-1 袋）
                dp[i][j] = dp[i - 1][j - 1]
                # 第 i 颗糖放入已有的 j 袋之一
                dp[i][j] = (dp[i][j] + j * dp[i - 1][j]) % MOD

        return dp[n][k]
```

### 方法二：滚动数组优化空间

```python
class Solution:
    def waysToDistribute(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        # 使用滚动数组，只保留上一行
        prev = [0] * (k + 1)
        prev[0] = 1  # dp[0][0] = 1

        for i in range(1, n + 1):
            curr = [0] * (k + 1)
            for j in range(1, min(i, k) + 1):
                # 来自 dp[i-1][j-1]
                curr[j] = prev[j - 1]
                # 来自 j * dp[i-1][j]
                curr[j] = (curr[j] + j * prev[j]) % MOD
            prev = curr

        return prev[k]
```

## 复杂度分析

- **时间复杂度**：O(n * k)，两重循环
- **空间复杂度**：O(n * k)（方法一），O(k)（方法二）

## 关键点总结

1. 核心状态转移：每颗新糖要么自成一袋，要么放入已有的某袋
2. `dp[i][j] = dp[i-1][j-1] + j * dp[i-1][j]`
3. 这个递推式就是第二类 Stirling 数乘以排列数的递推
4. 取模操作要在每步计算后进行，防止溢出

## 易错点

1. 糖是**不同**的（有编号），不是相同的糖，不能用组合数直接计算
2. 放入已有袋子时的系数是 `j`（j 个袋子都可以放），不是 1
3. `j` 的上界是 `min(i, k)`，不能超过糖的数量
