## 题目描述

给你一个下标从 0 开始、长度为 `n` 的整数数组 `nums` 和一个整数 `k`。

每次操作，你可以选择两个相邻元素 `nums[i]` 和 `nums[i+1]`，将 `nums[i]` 替换为 `nums[i] & nums[i+1]`，然后删除 `nums[i+1]`。

最多执行 `k` 次操作。

返回执行操作后，数组 **按位或** 的最小可能值。

**示例 1：**
```
输入：nums = [3,5,3,2,7], k = 2
输出：3
```

**示例 2：**
```
输入：nums = [7,3,5], k = 2
输出：3
```

**提示：**
- `1 <= n <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k < n`

## 解题思路

贪心 + 位运算。

我们希望最终数组的 OR 值尽可能小，即尽量消除高位的 1。

**关键观察：** 每次操作将相邻两个元素 AND 后缩减为一个，最多 `k` 次操作意味着我们可以将最多 `k+1` 个连续元素合并为 1 个。

最终数组是原数组的若干不相交"段"的 AND，每段的贡献是该段所有元素的 AND。

**贪心策略（从高位到低位）：**

从最高位开始，尝试将目标 OR 中该位清零：
- 检查：如果把所有使该位为 1 的元素都通过 AND 操作消除（归并到其他元素中），最多需要多少次操作？
- 若需要操作数 <= k，则可以清零该位，更新目标

等价于：贪心地找满足"连续段覆盖所有该位为 1 的元素"所需的最少段数（每段合并消耗 len-1 次操作）。

## Python 代码实现

### 方法一：贪心按位处理（推荐）

```python
from typing import List

class Solution:
    def minOrAfterOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        # 从最高位到最低位，贪心地尝试清零每一位
        for bit in range(29, -1, -1):
            # 尝试将 ans 的第 bit 位设为 0，检验是否可行
            # target_mask 是目前确定的高位掩码（加上当前尝试清零的位不保留）
            target = ans  # 当前已确定的目标（不包含 bit 位）

            # 检查：用 k 次操作能否使所有元素 AND 后在 target 掩码的基础上第 bit 位为 0
            # 即：能否用最多 k 次操作，使最终数组每个元素在 target 位置上均满足？

            # 实际检验方法：
            # 对于掩码 mask = target | (1 << bit)，
            # 统计需要多少次合并才能让所有"连续 AND 不为 0 的段"被合并
            mask = target | (1 << bit)
            # 统计需要的操作次数
            ops = 0
            cur_and = (1 << 30) - 1  # 全 1
            for x in nums:
                cur_and &= x
                if cur_and & mask == 0:
                    # 当前段的 AND 在 mask 的位上全为 0
                    # 重新开始新段
                    cur_and = (1 << 30) - 1
                    ops += 1

            # ops 是可以独立存在的段数
            # 需要合并的段：从 n 个元素，合并成 ops 段，需要 n - ops 次操作
            if n - ops <= k:
                # 可以清零第 bit 位
                pass  # ans 不加第 bit 位
            else:
                # 无法清零，保留第 bit 位
                ans |= (1 << bit)

        return ans
```

### 方法二：更清晰的实现

```python
from typing import List

class Solution:
    def minOrAfterOperations(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for bit in range(29, -1, -1):
            # 检验能否在已确定的高位基础上，第 bit 位为 0
            mask = ans | (1 << bit)

            # 计算在约束 mask 下，最少需要多少段（贪心合并）
            # 只要当前段的 AND 在 mask 的某位不为 0，就继续合并
            # 当 AND & mask == 0 时，该段可以结束
            groups = 0
            cur = ~0  # 全 1（按位全 1）
            for x in nums:
                cur &= x
                if (cur & mask) == 0:
                    groups += 1
                    cur = ~0  # 重置

            # 需要操作数 = n - groups
            if n - groups <= k:
                pass  # 成功清零 bit 位
            else:
                ans |= (1 << bit)  # 无法清零，保留

        return ans
```

## 复杂度分析

- 时间复杂度：O(30 * n)，对每一位扫描一次数组
- 空间复杂度：O(1)

## 关键点总结

1. 贪心从高位到低位逐位确定答案
2. 对于每一位，检验是否可以通过 <= k 次操作清零
3. 利用 AND 的单调性：连续合并后 AND 只会减少（位数只减不增）

## 易错点

1. `cur = ~0` 在 Python 中是 -1，应使用 `(1 << 30) - 1` 作为全 1 掩码
2. `groups` 统计的是段数，所需操作数为 `n - groups`
3. 每位的检验需要包含已确定的高位掩码 `ans`
