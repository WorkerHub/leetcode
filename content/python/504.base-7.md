## 题目描述

给定一个整数 `num`，将其转化为 **7 进制**，并以字符串形式输出。

**示例 1：**
```
输入：num = 100
输出："202"
```

**示例 2：**
```
输入：num = -7
输出："-10"
```

**提示：**
- `-10^7 <= num <= 10^7`

## 解题思路

这是一道经典的进制转换题目。核心是理解**除基取余法**。

### 核心原理：
将十进制数转换为 n 进制的方法：
1. 不断除以 n，取余数
2. 余数从后往前组成结果
3. 直到商为 0

### 算法流程：
1. 处理特殊情况：`num == 0` 直接返回 "0"
2. 处理负数：记录符号，转为正数处理
3. 循环除以 7，收集余数
4. 反转余数序列，拼接成字符串
5. 添加符号（如果是负数）

### 示例演示（num = 100）：
```
100 ÷ 7 = 14 ... 2  → 余数 2
14  ÷ 7 = 2  ... 0  → 余数 0
2   ÷ 7 = 0  ... 2  → 余数 2

从下往上读余数：202
```

## Python 代码实现

### 方法一：循环除基取余（标准算法）⭐

```python
class Solution:
    def convertToBase7(self, num: int) -> str:
        """
        除基取余法，标准进制转换算法
        时间复杂度：O(log n)，空间复杂度：O(log n)
        """
        # 特殊情况
        if num == 0:
            return "0"
        
        # 处理负数
        negative = num < 0
        num = abs(num)
        
        # 收集余数
        digits = []
        while num > 0:
            digits.append(str(num % 7))
            num //= 7
        
        # 反转并拼接
        result = ''.join(reversed(digits))
        
        # 添加负号
        return '-' + result if negative else result
```

### 方法二：递归实现

```python
class Solution:
    def convertToBase7(self, num: int) -> str:
        """
        递归实现进制转换
        时间复杂度：O(log n)，空间复杂度：O(log n)
        """
        # 基础情况
        if num == 0:
            return "0"
        if num < 0:
            return "-" + self.convertToBase7(-num)
        if num < 7:
            return str(num)
        
        # 递归：先处理高位，再拼接当前位
        return self.convertToBase7(num // 7) + str(num % 7)
```

### 方法三：使用内置函数（Python 特色）

```python
class Solution:
    def convertToBase7(self, num: int) -> str:
        """
        利用 Python 内置的进制转换思想
        时间复杂度：O(log n)，空间复杂度：O(log n)
        """
        if num == 0:
            return "0"
        
        negative = num < 0
        num = abs(num)
        
        result = ""
        while num:
            result = str(num % 7) + result
            num //= 7
        
        return "-" + result if negative else result
```

### 方法四：通用进制转换函数

```python
class Solution:
    def convertToBase7(self, num: int) -> str:
        """
        通用的进制转换函数
        可以轻松改为其他进制
        """
        return self.convertToBase(num, 7)
    
    def convertToBase(self, num: int, base: int) -> str:
        """
        将 num 转换为 base 进制
        """
        if num == 0:
            return "0"
        
        negative = num < 0
        num = abs(num)
        
        digits = "0123456789ABCDEF"  # 支持到16进制
        result = []
        
        while num:
            result.append(digits[num % base])
            num //= base
        
        if negative:
            result.append('-')
        
        return ''.join(reversed(result))
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(log₇n) = O(log n)
  - 每次除以 7，循环次数为 log₇n
- **空间复杂度**：O(log n)
  - 存储结果字符串或递归栈深度

## 关键点总结

1. **除基取余法**：进制转换的标准算法
2. **余数顺序**：余数从后往前组成结果（需要反转）
3. **负数处理**：先处理符号，再转换绝对值
4. **零的特殊处理**：0 在任何进制下都是 "0"
5. **通用性**：算法可以推广到任意进制

## 易错点

1. **忘记处理 0**：0 是特殊情况，直接返回 "0"
2. **负数符号位置**：负号应该在最前面，不是最后面
3. **余数顺序错误**：忘记反转，导致结果颠倒
4. **整数除法**：Python3 中使用 `//`，不是 `/`
5. **边界值**：注意题目范围，避免溢出（虽然 Python 不会溢出）

## 图解示例

```
2. 转为正数：num = 100

   100 ÷ 7 = 14 余 2  → digits = ['2']

4. 反转：['2', '0', '2'] → "202"
5. 添加负号："-202"
```
