## 题目描述

给你两个互质正整数 `primeOne` 和 `primeTwo`（保证互质）。

你可以无限次使用 `primeOne` 和 `primeTwo` 作为货币单位，返回**无法**被这两种货币单位凑出的最大金额。

即，返回最大的整数，使得它无法表示为 `a * primeOne + b * primeTwo`（a, b >= 0 的非负整数）。

**示例 1：**
```
输入：primeOne = 2, primeTwo = 5
输出：3
解释：可以凑出 0,2,4,5,6,7,8,...，但 1 和 3 不能凑出，最大为 3
```

**示例 2：**
```
输入：primeOne = 5, primeTwo = 7
输出：23
```

**提示：**
- `1 <= primeOne, primeTwo <= 10^9`
- `primeOne * primeTwo <= 10^15`
- `gcd(primeOne, primeTwo) == 1`（互质）

## 解题思路

这是著名的**鸡块数问题（Frobenius coin problem）**。

两个互质正整数 a 和 b，能凑出的最大不可凑数（Frobenius number）= `a * b - a - b`。

公式直接计算。

## Python 代码实现

### 方法一：Frobenius 公式（推荐）

```python
class Solution:
    def mostExpensiveItem(self, primeOne: int, primeTwo: int) -> int:
        # Frobenius number for two coprime integers a, b = a*b - a - b
        return primeOne * primeTwo - primeOne - primeTwo
```

### 方法二：验证公式（暴力验证小数据）

```python
class Solution:
    def mostExpensiveItem(self, primeOne: int, primeTwo: int) -> int:
        # 暴力验证（仅用于小数据）
        if primeOne * primeTwo > 10**6:
            return primeOne * primeTwo - primeOne - primeTwo

        can_make = set()
        for a in range(primeTwo):
            for b in range(primeOne):
                val = a * primeOne + b * primeTwo
                if val <= primeOne * primeTwo:
                    can_make.add(val)

        ans = 0
        for x in range(1, primeOne * primeTwo):
            if x not in can_make:
                ans = x
        return ans
```

## 复杂度分析

- 时间复杂度：O(1)，直接计算公式
- 空间复杂度：O(1)

## 关键点总结

1. Frobenius coin problem：两个互质整数 a, b 的最大不可表示数 = a*b - a - b
2. 直接套公式，无需 DP 或枚举
3. 互质（gcd=1）是公式成立的前提条件

## 易错点

1. 公式 `a*b - a - b`，不是 `a*b - 1`
2. 结果 >= 1（a,b >= 2 时，a*b-a-b >= 1）
3. 不需要验证，题目保证互质
