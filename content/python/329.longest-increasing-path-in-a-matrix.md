## 题目描述

给定一个 `m x n` 整数矩阵 `matrix`，找出其中**最长递增路径**的长度。

对于每个单元格，你可以往上，下，左，右四个方向移动。你**不能**在对角线方向上移动或移动到边界外（即不允许环绕）。

**示例 1:**

```
输入：matrix = [[9,9,4],[6,6,8],[2,1,1]]
输出：4
解释：最长递增路径为 [1, 2, 6, 9]。
```

**示例 2:**

```
输入：matrix = [[3,4,5],[3,2,6],[2,2,1]]
输出：4
解释：最长递增路径是 [3, 4, 5, 6]。注意不允许在对角线方向上移动。
```

**示例 3:**

```
输入：matrix = [[1]]
输出：1
```

**提示:**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 200`
- `0 <= matrix[i][j] <= 2^31 - 1`

## 解题思路

这道题有两种经典解法：**记忆化 DFS** 和**拓扑排序**。

### 思路一：记忆化深度优先搜索（推荐）

1. **DFS 搜索**：从每个格子出发，向四个方向 DFS，找到最长递增路径
2. **记忆化优化**：用 `memo[i][j]` 记录从 `(i, j)` 出发的最长路径长度，避免重复计算
3. **递归关系**：`memo[i][j] = max(dfs(邻居)) + 1`（邻居值必须大于当前值）

**为什么不会形成环？**
- 因为路径必须严格递增，不可能从某个点出发再回到自己

### 思路二：拓扑排序

1. **构建有向图**：如果 `matrix[i][j] < matrix[x][y]`，则 `(i,j) -> (x,y)` 有一条边
2. **计算入度**：每个节点的入度 = 有多少个邻居比它小
3. **BFS 拓扑排序**：
   - 从入度为 0 的节点开始（最小值节点）
   - 每次移除一层，路径长度 +1
   - 层数即为最长路径长度

## Python 代码实现

### 方法一：记忆化 DFS（推荐）⭐

```python
from typing import List

class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        """
        记忆化深度优先搜索
        """
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        memo = [[0] * n for _ in range(m)]  # 记忆化数组
        
        def dfs(i: int, j: int) -> int:
            """
            从 (i, j) 出发的最长递增路径长度
            """
            # 已经计算过，直接返回
            if memo[i][j] != 0:
                return memo[i][j]
            
            # 初始长度为 1（只包含自己）
            max_length = 1
            
            # 四个方向
            directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
            
            for dx, dy in directions:
                x, y = i + dx, j + dy
                
                # 检查边界和递增条件
                if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                    # 递归搜索邻居，取最大值
                    max_length = max(max_length, dfs(x, y) + 1)
            
            # 记录结果
            memo[i][j] = max_length
            return max_length
        
        # 从每个格子出发，找全局最大值
        result = 0
        for i in range(m):
            for j in range(n):
                result = max(result, dfs(i, j))
        
        return result
```

### 方法二：拓扑排序（BFS）

```python
from typing import List
from collections import deque

class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        """
        拓扑排序：从最小值开始，逐层剥离
        """
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # 计算每个格子的入度（有多少个邻居比它小）
        in_degree = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                for dx, dy in directions:
                    x, y = i + dx, j + dy
                    if 0 <= x < m and 0 <= y < n and matrix[x][y] < matrix[i][j]:
                        in_degree[i][j] += 1
        
        # 将入度为 0 的格子加入队列（最小值）
        queue = deque()
        for i in range(m):
            for j in range(n):
                if in_degree[i][j] == 0:
                    queue.append((i, j))
        
        # BFS 拓扑排序
        path_length = 0
        
        while queue:
            path_length += 1
            size = len(queue)
            
            # 处理当前层的所有节点
            for _ in range(size):
                i, j = queue.popleft()
                
                # 遍历邻居
                for dx, dy in directions:
                    x, y = i + dx, j + dy
                    
                    # 如果邻居更大，减少其入度
                    if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                        in_degree[x][y] -= 1
                        
                        # 入度为 0，加入队列
                        if in_degree[x][y] == 0:
                            queue.append((x, y))
        
        return path_length
```

### 方法三：简化版记忆化 DFS

```python
from typing import List
from functools import lru_cache

class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        """
        使用 @lru_cache 装饰器简化记忆化
        """
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        
        @lru_cache(None)
        def dfs(i: int, j: int) -> int:
            """从 (i, j) 出发的最长递增路径"""
            max_length = 1
            
            for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                x, y = i + dx, j + dy
                if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                    max_length = max(max_length, dfs(x, y) + 1)
            
            return max_length
        
        return max(dfs(i, j) for i in range(m) for j in range(n))
```

## 复杂度分析

**方法一：记忆化 DFS**

- **时间复杂度**：O(m * n)
  - 每个格子最多计算一次（记忆化）
  - 每次计算遍历 4 个方向
  
- **空间复杂度**：O(m * n)
  - memo 数组 + 递归栈

**方法二：拓扑排序**

- **时间复杂度**：O(m * n)
  - 计算入度：O(m * n)
  - BFS 遍历：每个格子最多入队一次
  
- **空间复杂度**：O(m * n)
  - in_degree 数组 + 队列

## 关键点总结

1. **记忆化必不可少**：没有记忆化会导致大量重复计算，超时
2. **严格递增保证无环**：不需要 visited 数组标记访问状态
3. **拓扑排序思想**：从最小值开始，逐层剥离，层数即为最长路径
4. **四个方向遍历**：使用方向数组 `directions` 简化代码
5. **全局最大值**：需要从每个格子出发尝试，取最大值

## 易错点

1. **忘记记忆化**：纯 DFS 会超时
2. **边界检查**：`0 <= x < m and 0 <= y < n`
3. **递增条件**：`matrix[x][y] > matrix[i][j]`（严格大于）
4. **初始值设置**：
   - 记忆化 DFS：`max_length = 1`（至少包含自己）
   - memo 初始化为 0（表示未计算）
5. **拓扑排序的入度定义**：
   - 本题：有多少个邻居**比它小**（而不是常规的有多少条入边）
