## 题目描述

给你一个整数数组 `nums`，每次操作可以将数组中的一个元素加 1 或减 1（不能为负数）。返回使数组成为回文数组所需的最少操作次数。

**示例 1：**

```
输入：nums = [1,2,3,2,1]
输出：0
解释：已经是回文
```

**示例 2：**

```
输入：nums = [1,2,3,4,5]
输出：4
解释：将 1→3（+2）, 5→3（-2）, 2→4? 最优：对称位置取平均或中位数
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

双指针贪心：对对称位置 `(left, right)` 使两者相等，代价为 `|nums[left] - nums[right]|`。

对每对对称位置，将较小的改为较大的（代价最小：取较大值使两者相等，代价 = 差值）。

等价于：对每对 `(left, right)`，最优使它们相等，代价 = `|nums[left] - nums[right]|`。

## Python 代码实现

### 方法一：双指针（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        ops = 0
        while left < right:
            ops += abs(nums[left] - nums[right])
            left += 1
            right -= 1
        return ops
```

### 方法二：配对求差

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        return sum(abs(nums[i] - nums[n - 1 - i]) for i in range(n // 2))
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 回文数组：`nums[i] == nums[n-1-i]`
2. 每对对称位置独立处理，代价为差值的绝对值
3. 双指针从两端向中间

## 易错点

1. 中间元素（n 为奇数时）不需要调整
2. 操作数 = 差值的绝对值（取较大值或较小值都是相同代价）
3. 不需要实际修改数组
