## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `target`。

返回满足 `0 <= i < j < n` 且 `nums[i] + nums[j] < target` 的下标对 `(i, j)` 的数量。

**示例 1：**
```
输入：nums = [-1,1,2,3,1], target = 2
输出：3
解释：满足条件的对：(0,1): -1+1=0 < 2，(0,2): -1+2=1 < 2，(0,4): -1+1=0 < 2
```

**示例 2：**
```
输入：nums = [-6,2,5,-2,-7,-1,3], target = -2
输出：10
```

**提示：**
- `1 <= nums.length <= 50`
- `-50 <= nums[i] <= 50`
- `-50 <= target <= 50`

## 解题思路

本题数据量小（n <= 50），暴力枚举 O(n^2) 即可。

**双指针优化（推荐学习）：**
1. 排序后用双指针
2. 左指针 `l = 0`，右指针 `r = n-1`
3. 若 `nums[l] + nums[r] < target`，则 l..r-1 都满足（共 r-l 对），l++
4. 否则 r--

## Python 代码实现

### 方法一：暴力枚举（简单）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], target: int) -> int:
        n = len(nums)
        count = 0
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] < target:
                    count += 1
        return count
```

### 方法二：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        count = 0
        l, r = 0, n - 1

        while l < r:
            if nums[l] + nums[r] < target:
                # nums[l] + nums[l+1..r] 都 < target（因为 nums[r] 是最大）
                count += r - l
                l += 1
            else:
                # nums[l] + nums[r] >= target，需要减小 r
                r -= 1

        return count
```

### 方法三：排序 + 二分查找

```python
import bisect
from typing import List

class Solution:
    def countPairs(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        count = 0

        for i in range(n):
            # 找第一个使 nums[i] + nums[j] >= target 的 j
            # 即 nums[j] >= target - nums[i]
            limit = bisect.bisect_left(nums, target - nums[i], i + 1)
            # i+1 到 limit-1 的所有 j 都满足
            count += limit - i - 1

        return count
```

## 复杂度分析

- 方法一：时间 O(n^2)，空间 O(1)
- 方法二：时间 O(n log n)，空间 O(1)（排序额外空间）
- 方法三：时间 O(n log n)，空间 O(1)

## 关键点总结

1. 数据量小时暴力 O(n^2) 足够
2. 双指针解法：排序后，找到合适对后一次性计数 `r - l` 对
3. 双指针要求数组有序，利用单调性快速排除

## 易错点

1. 双指针中，`nums[l] + nums[r] < target` 时 count += `r - l`（不是 r - l + 1，因为不包括 l 自身）
2. 注意是严格小于（<），不是小于等于（<=）
3. 排序后下标关系改变，统计对数时用计数而非记录下标
