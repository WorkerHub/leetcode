## 题目描述

给你一个 `m x n` 的矩阵 `mat`，其中每一行的元素都已经按递增顺序排好序。

请你找出所有行中最小的公共元素。

如果矩阵中没有这样的公共元素，就请返回 `-1`。

**示例 1：**
```
输入：mat = [[1,2,3,4,5],[2,4,5,8,10],[3,5,7,9,11],[1,3,5,7,9]]
输出：5
```

**示例 2：**
```
输入：mat = [[1,2,3],[2,3,4],[2,3,5]]
输出：2
```

**提示：**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 500`
- `1 <= mat[i][j] <= 10^4`
- `mat[i]` 已按递增顺序排序

## 解题思路

这道题要求找出所有行的公共元素中最小的一个，可以利用行已排序的特点。

**核心思路：**

1. **方法选择**：
   - **哈希表计数**：统计每个元素出现的次数，找出现次数等于行数的最小元素
   - **二分查找**：遍历第一行，对每个元素在其他行中二分查找

2. **哈希表方法**：
   - 遍历所有元素，统计每个元素出现的行数
   - 找出现次数等于 `m` 的最小元素

3. **二分查找方法**：
   - 遍历第一行的每个元素
   - 在其他行中二分查找该元素
   - 如果所有行都包含该元素，直接返回（因为第一行已排序）

## Python 代码实现

### 方法一：哈希表计数（推荐）⭐

```python
from typing import List
from collections import Counter

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        """
        使用哈希表统计每个元素出现的次数
        """
        m = len(mat)  # 行数
        count = Counter()
        
        # 统计所有元素出现的次数
        for row in mat:
            for num in row:
                count[num] += 1
        
        # 找出现次数等于行数的最小元素
        result = float('inf')
        for num, freq in count.items():
            if freq == m:
                result = min(result, num)
        
        return result if result != float('inf') else -1
```

### 方法二：二分查找

```python
from typing import List
import bisect

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        """
        遍历第一行，对每个元素在其他行中二分查找
        """
        m, n = len(mat), len(mat[0])
        
        # 遍历第一行的每个元素
        for num in mat[0]:
            # 检查该元素是否在所有其他行中
            found = True
            for i in range(1, m):
                # 在第 i 行中二分查找 num
                idx = bisect.bisect_left(mat[i], num)
                if idx == len(mat[i]) or mat[i][idx] != num:
                    found = False
                    break
            
            # 如果在所有行中都找到了，返回该元素
            if found:
                return num
        
        return -1
```

### 方法三：优化的哈希表（使用集合交集）

```python
from typing import List

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        """
        使用集合交集找公共元素
        """
        # 将第一行转换为集合
        common = set(mat[0])
        
        # 与其他行求交集
        for i in range(1, len(mat)):
            common &= set(mat[i])
        
        # 返回最小的公共元素
        return min(common) if common else -1
```

### 方法四：计数优化版

```python
from typing import List

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        """
        只统计可能是公共元素的数字
        """
        m = len(mat)
        count = {}
        
        # 只遍历第一行
        for num in mat[0]:
            count[num] = 1
        
        # 遍历其他行
        for i in range(1, m):
            for num in mat[i]:
                # 只统计在第一行出现过的元素
                if num in count:
                    count[num] += 1
        
        # 找出现次数等于行数的最小元素
        for num in sorted(count.keys()):
            if count[num] == m:
                return num
        
        return -1
```

### 方法五：多指针法

```python
from typing import List

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        """
        使用多指针同时遍历所有行
        """
        m, n = len(mat), len(mat[0])
        pointers = [0] * m  # 每行的指针
        
        while True:
            # 找到所有指针指向的最大值
            max_val = max(mat[i][pointers[i]] for i in range(m))
            
            # 检查是否所有行的当前值都等于 max_val
            all_equal = True
            for i in range(m):
                # 移动指针直到 >= max_val
                while pointers[i] < n and mat[i][pointers[i]] < max_val:
                    pointers[i] += 1
                
                # 检查是否越界
                if pointers[i] >= n:
                    return -1
                
                # 检查是否等于 max_val
                if mat[i][pointers[i]] != max_val:
                    all_equal = False
                    break
            
            # 如果所有行都相等，返回该值
            if all_equal:
                return max_val
```

## 复杂度分析

**方法一：哈希表计数**
- **时间复杂度**：O(m × n)，遍历所有元素
- **空间复杂度**：O(m × n)，存储哈希表

**方法二：二分查找**
- **时间复杂度**：O(n × m × log n)，遍历第一行的 n 个元素，对每个元素在 m-1 行中二分查找
- **空间复杂度**：O(1)

**方法三：集合交集**
- **时间复杂度**：O(m × n)
- **空间复杂度**：O(n)，存储集合

**方法五：多指针**
- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m)，存储指针数组

## 关键点总结

1. **利用排序特性**：每一行都已排序，可以使用二分查找
2. **哈希表计数**：统计每个元素出现的次数是最直观的方法
3. **提前返回**：在二分查找方法中，第一个找到的就是最小的
4. **集合操作**：Python 的集合交集操作非常高效
5. **多指针技巧**：同时遍历多个数组是常见的技巧

## 易错点

1. **忘记检查元素存在性**：二分查找后要检查 `mat[i][idx] == num`
2. **边界条件**：二分查找的索引可能越界
3. **最小值判断**：要返回最小的公共元素，不是任意一个
4. **空集合处理**：如果没有公共元素，要返回 -1
5. **计数条件**：只有出现次数等于行数 `m` 才是公共元素
