## 题目描述

给你一个下标从 **0** 开始的字符串 `s`，判断 **半重复** 子字符串的最大长度。

**半重复**字符串是指：字符串中 **最多有一对** 相邻字符是相等的。

**示例 1：**
```
输入：s = "52233"
输出：4
解释："5223" 中有一对相邻相等字符 "22"，满足半重复；"52233" 中有两对，不满足。
```

**示例 2：**
```
输入：s = "5494"
输出：4
解释：没有相邻相等字符，整个字符串满足条件。
```

**示例 3：**
```
输入：s = "1111111"
输出：2
解释：最长半重复子串长度为 2，如 "11"。
```

**提示：**
- `1 <= s.length <= 50`
- `s` 只包含数字字符

## 解题思路

**滑动窗口**：维护左右指针 `left` 和 `right`，以及窗口内相邻相等字符对的数量 `pairs`。

当 `pairs > 1` 时，移动左指针缩小窗口，直到 `pairs <= 1`。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def longestSemiRepetitiveSubstring(self, s: str) -> int:
        n = len(s)
        ans = 1
        pairs = 0  # 窗口内相邻相等字符对的数量
        left = 0

        for right in range(1, n):
            if s[right] == s[right - 1]:
                pairs += 1
            # 当超过 1 对时，移动左指针
            while pairs > 1:
                if s[left] == s[left + 1]:
                    pairs -= 1
                left += 1
            ans = max(ans, right - left + 1)

        return ans
```

### 方法二：记录最后一对的位置

```python
class Solution:
    def longestSemiRepetitiveSubstring(self, s: str) -> int:
        n = len(s)
        ans = 1
        left = 0
        last_pair = -1  # 上一对相邻相等字符的右端位置

        for right in range(1, n):
            if s[right] == s[right - 1]:
                if last_pair != -1:
                    # 已经有一对了，左端移到上一对之后
                    left = last_pair
                last_pair = right
            ans = max(ans, right - left + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 半重复 = 最多一对相邻相等字符
2. 滑动窗口保持窗口内 `pairs <= 1`
3. 方法二更简洁：记录上一对位置，遇到第二对时将左端移到上一对位置

## 易错点

1. `pairs` 计数在右指针移动时增加，左指针移动时需检查是否减少
2. 移动左指针时，检查 `s[left] == s[left+1]` 才使 `pairs -= 1`
