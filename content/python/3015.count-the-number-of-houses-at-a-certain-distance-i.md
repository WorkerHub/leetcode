## 题目描述

给你三个正整数 `n`、`x` 和 `y`。

在一个城市中，有从 1 到 n 编号的 `n` 所房屋，以及 `n-1` 条街道：
- 街道 `i`（1 <= i <= n-1）连接房屋 `i` 和 `i+1`（形成一条链）
- 同时，还有一条额外街道连接 `x` 和 `y`

`result[k]` 表示可以通过 **恰好 k 条** 街道到达的有序房屋对数 `(house1, house2)`（可以 house1 < house2，也可 > ，视为不同对）。

返回数组 `result`，其中 `result[i]`（1-indexed）为距离恰好为 `i` 的有序对数。

**示例 1：**
```
输入：n = 3, x = 1, y = 3
输出：[6,0,0]
```

**示例 2：**
```
输入：n = 5, x = 2, y = 4
输出：[10,8,2,0,0]
```

**提示：**
- `2 <= n <= 100`
- `1 <= x, y <= n`

## 解题思路

数据范围小（n <= 100），直接对每个节点做 BFS，计算到所有其他节点的最短距离，更新结果数组。

建图：
- 链式边：`1-2-3-...-n`
- 额外边：`x-y`

对每个节点做 BFS，统计到其他节点的距离，对于距离 `d`，`result[d-1] += 1`（有序对，双向计数）。

## Python 代码实现

### 方法一：BFS 枚举（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def countOfPairs(self, n: int, x: int, y: int) -> List[int]:
        # 建图（节点编号 1 到 n）
        graph = defaultdict(set)
        for i in range(1, n):
            graph[i].add(i + 1)
            graph[i + 1].add(i)
        # 额外连接 x 和 y
        if x != y:
            graph[x].add(y)
            graph[y].add(x)

        result = [0] * n  # result[k-1] 为距离 k 的有序对数

        for start in range(1, n + 1):
            # BFS 求最短距离
            dist = {start: 0}
            queue = deque([start])
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in dist:
                        dist[neighbor] = dist[node] + 1
                        queue.append(neighbor)

            # 统计
            for end, d in dist.items():
                if end != start and d <= n - 1:
                    result[d - 1] += 1

        return result
```

### 方法二：Floyd-Warshall（适合小图）

```python
from typing import List

class Solution:
    def countOfPairs(self, n: int, x: int, y: int) -> List[int]:
        INF = float('inf')
        # 初始化距离矩阵（1-indexed）
        dist = [[INF] * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            dist[i][i] = 0
        for i in range(1, n):
            dist[i][i + 1] = dist[i + 1][i] = 1
        if x != y:
            dist[x][y] = dist[y][x] = 1

        # Floyd-Warshall
        for k in range(1, n + 1):
            for i in range(1, n + 1):
                for j in range(1, n + 1):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]

        result = [0] * n
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                if i != j and dist[i][j] <= n - 1:
                    result[dist[i][j] - 1] += 1

        return result
```

## 复杂度分析

- BFS 版本时间复杂度：O(n^2)，每个节点做一次 BFS
- Floyd-Warshall 时间复杂度：O(n^3)，n <= 100 完全可行
- 空间复杂度：O(n^2)

## 关键点总结

1. 图是链 + 一条额外边，结构简单
2. BFS 找最短路，然后统计各距离的有序对数
3. 有序对意味着 `(i, j)` 和 `(j, i)` 分别计数

## 易错点

1. 有序对：`i` 到 `j` 和 `j` 到 `i` 算两对
2. `x == y` 时额外边是自环，不影响图结构
3. 结果数组长度为 `n`（最大距离不超过 n-1）
