## 题目描述

给你数字 `k`，请你返回和为 `k` 的斐波那契数字的最少数目，其中，每个斐波那契数字都可以被使用多次。

斐波那契数列定义如下：

- `F1 = 1`
- `F2 = 1`
- `Fn = Fn-1 + Fn-2`（n > 2）

数据保证对于给定的 `k`，一定能找到可行解。

**示例 1：**

```
输入：k = 7
输出：2
解释：斐波那契数列为 1, 1, 2, 3, 5, 8, 13, ...
     7 = 2 + 5
```

**示例 2：**

```
输入：k = 10
输出：2
解释：10 = 2 + 8
```

**示例 3：**

```
输入：k = 19
输出：3
解释：19 = 1 + 5 + 13
```

**提示：**

- `1 <= k <= 10^9`

## 解题思路

### 贪心策略：每次取不超过 k 的最大斐波那契数

**为什么贪心有效？**

斐波那契数列有一个重要性质（Zeckendorf 定理）：任何正整数都可以唯一表示为若干个不连续的斐波那契数之和（每个斐波那契数最多用一次）。

贪心算法：每次取不超过 k 的最大斐波那契数，然后 k 减去该数，重复直到 k = 0。

这类似于零钱兑换问题，但斐波那契数有特殊结构，使得贪心算法最优（不像普通面值的硬币需要 DP）。

**贪心正确性简证：**

设 `F[i]` 是不超过 k 的最大斐波那契数。若不选 `F[i]`，则需要用 `F[i-1]` 及更小的斐波那契数凑出 k。由于 `F[i-1] + F[i-2] = F[i]`（即两个较小数相加才等于一个较大数），用更小的数凑出同样的值需要更多个数，所以贪心选择最大数是最优的。

### 算法步骤

1. 预先生成所有不超过 k 的斐波那契数
2. 从最大的斐波那契数开始贪心选取
3. 每次减去能用的最大斐波那契数，计数 +1
4. 重复直到 k = 0

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        # 生成所有不超过 k 的斐波那契数
        fibs = [1, 1]
        while fibs[-1] + fibs[-2] <= k:
            fibs.append(fibs[-1] + fibs[-2])

        # 贪心：每次取不超过 k 的最大斐波那契数
        count = 0
        while k > 0:
            # 找最大的不超过 k 的斐波那契数
            # 由于 fibs 已排序，从右向左找第一个 <= k 的
            while fibs[-1] > k:
                fibs.pop()
            k -= fibs[-1]
            count += 1

        return count
```

### 方法二：贪心（更简洁，使用二分查找）

```python
import bisect
from typing import List

class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        # 生成足够多的斐波那契数（k <= 10^9，F44 ≈ 1.13 * 10^9）
        fibs = [1, 1]
        while fibs[-1] < 10**9:
            fibs.append(fibs[-1] + fibs[-2])

        count = 0
        while k > 0:
            # 用二分查找找到最大的不超过 k 的斐波那契数的下标
            idx = bisect.bisect_right(fibs, k) - 1
            k -= fibs[idx]
            count += 1

        return count
```

### 方法三：递归贪心（代码最简洁）

```python
class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        # 找最大的不超过 k 的斐波那契数
        def largest_fib(n: int) -> int:
            a, b = 1, 1
            while b <= n:
                a, b = b, a + b
            return a  # 返回 a，因为此时 b > n

        if k == 0:
            return 0
        # 贪心递归：取最大斐波那契数，递归处理余数
        return 1 + self.findMinFibonacciNumbers(k - largest_fib(k))
```

## 复杂度分析

设 `k <= 10^9`，斐波那契数列在 10^9 以内约有 44 个数。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(log^2 k) | O(log k) |
| 二分贪心 | O(log k * log(log k)) | O(log k) |
| 递归贪心 | O(log^2 k) | O(log k)（递归栈）|

注：贪心步数最多约 O(log k) 次（每步至少减去约一半），每次找最大斐波那契数 O(log k)。

## 关键点总结

1. 贪心策略：每次取不超过 k 的**最大**斐波那契数
2. 贪心有效性基于 Zeckendorf 定理：每个正整数可以唯一表示为不连续斐波那契数之和
3. 10^9 以内斐波那契数最多 44 个，步数非常少
4. 不需要 DP，贪心直接得到最优解

## 易错点

1. 斐波那契数列从 F1=1, F2=1 开始，注意不要漏掉重复的 1
2. `bisect_right(fibs, k) - 1` 找到最大的不超过 k 的位置，注意边界
3. 不要误以为这是零钱兑换（需要DP），斐波那契数的特殊结构使贪心有效

## 图解示例

以 `k = 19` 为例：

```
斐波那契数列：1, 1, 2, 3, 5, 8, 13, 21, ...
不超过 19 的最大值：13
k = 19 - 13 = 6，计数 = 1

不超过 6 的最大值：5
k = 6 - 5 = 1，计数 = 2

不超过 1 的最大值：1
k = 1 - 1 = 0，计数 = 3

答案：3（13 + 5 + 1 = 19）
```
