## 题目描述

给定两个字符串 `s` 和 `t`，它们只包含小写字母。

字符串 `t` 由字符串 `s` 随机重排，然后在随机位置添加一个字母。

请找出在 `t` 中被添加的字母。

**示例 1:**

```
输入：s = "abcd", t = "abcde"
输出："e"
解释：'e' 是那个被添加的字母。
```

**示例 2:**

```
输入：s = "", t = "y"
输出："y"
```

**提示:**

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` 和 `t` 只包含小写字母

## 解题思路

本题有多种巧妙的解法，从暴力到优雅。

### 核心思想

字符串 `t` 比 `s` 多一个字符，找出这个字符的方法：

1. **统计字符频次**：比较两个字符串中每个字符的出现次数
2. **排序比较**：排序后逐位比较
3. **求和相减**：ASCII 码求和后相减
4. **异或运算**：利用异或的性质（最优雅）⭐

### 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 哈希表 | O(n) | O(1) | 直观 |
| 排序 | O(n log n) | O(1) | 简单但慢 |
| 求和 | O(n) | O(1) | 巧妙 |
| 异或 | O(n) | O(1) | 最优雅 |

## Python 代码实现

### 方法一：Counter 计数（最直观）

```python
from collections import Counter

class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        使用 Counter 统计字符频次
        时间复杂度: O(n)
        空间复杂度: O(1) - 最多 26 个字母
        """
        counter_s = Counter(s)
        counter_t = Counter(t)
        
        # 找到 t 中多出的字符
        diff = counter_t - counter_s
        return list(diff.keys())[0]
```

### 方法二：求和相减（巧妙）⭐

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        利用 ASCII 码求和相减
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        # t 的所有字符 ASCII 码之和 - s 的所有字符 ASCII 码之和
        diff = sum(ord(c) for c in t) - sum(ord(c) for c in s)
        return chr(diff)
```

### 方法三：异或运算（最优雅）⭐⭐⭐

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        利用异或运算的性质：
        - a ^ a = 0
        - a ^ 0 = a
        - 异或满足交换律和结合律
        
        将 s 和 t 的所有字符异或，相同的字符会抵消，剩下的就是多出的字符
        
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        result = 0
        
        # 对 s 中的所有字符进行异或
        for char in s:
            result ^= ord(char)
        
        # 对 t 中的所有字符进行异或
        for char in t:
            result ^= ord(char)
        
        return chr(result)
```

### 方法四：异或运算（一行版本）

```python
from functools import reduce
from operator import xor

class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        使用 reduce 和 xor 实现异或
        """
        return chr(reduce(xor, map(ord, s + t)))
```

### 方法五：排序比较

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        排序后逐位比较
        时间复杂度: O(n log n)
        空间复杂度: O(1)
        """
        s_sorted = sorted(s)
        t_sorted = sorted(t)
        
        # 逐位比较
        for i in range(len(s)):
            if s_sorted[i] != t_sorted[i]:
                return t_sorted[i]
        
        # 如果前面都相同，说明多出的字符在最后
        return t_sorted[-1]
```

### 方法六：数组计数

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        """
        使用数组统计字符频次
        时间复杂度: O(n)
        空间复杂度: O(1) - 固定 26 个字母
        """
        counts = [0] * 26
        
        # 统计 t 中的字符
        for char in t:
            counts[ord(char) - ord('a')] += 1
        
        # 减去 s 中的字符
        for char in s:
            counts[ord(char) - ord('a')] -= 1
        
        # 找到计数为 1 的字符
        for i in range(26):
            if counts[i] == 1:
                return chr(i + ord('a'))
```

## 复杂度分析

### 最优解（异或）

**时间复杂度：** O(n)
- 需要遍历两个字符串各一次
- 每个字符的异或操作是 O(1)

**空间复杂度：** O(1)
- 只使用一个整数变量存储异或结果

## 关键点总结

1. **异或的性质**：`a ^ a = 0`，`a ^ 0 = a`，相同的元素会抵消
2. **求和相减**：ASCII 码之差等于多出字符的 ASCII 码
3. **Counter 妙用**：Counter 支持减法运算
4. **位运算应用**：异或在查找唯一元素问题中非常有效
5. **空间优化**：虽然有多种方法，异或和求和不需要额外空间

## 易错点

1. **空字符串情况**：s 可能为空，t 只有一个字符
2. **返回类型**：返回字符串，不是字符的 ASCII 码
3. **排序方法的边界**：多出的字符可能在任何位置
4. **异或的理解**：需要理解为什么异或可以找到唯一元素

## 图解示例

### 异或运算过程

```
s = "abcd"
t = "abcde"

步骤 1: 对 s 中所有字符异或
result = 0
result ^= ord('a') = 97
result ^= ord('b') = 97 ^ 98 = 3
result ^= ord('c') = 3 ^ 99 = 96
result ^= ord('d') = 96 ^ 100 = 4

步骤 2: 对 t 中所有字符异或
result ^= ord('a') = 4 ^ 97 = 101
result ^= ord('b') = 101 ^ 98 = 3
result ^= ord('c') = 3 ^ 99 = 96
result ^= ord('d') = 96 ^ 100 = 4
result ^= ord('e') = 4 ^ 101 = 105

步骤 3: 转换回字符
chr(105) = 'e'

原理：s 和 t 的公共字符在异或中抵消，剩下的就是多出的 'e'
```

### 求和相减过程

```
s = "abcd"
sum(s) = 97 + 98 + 99 + 100 = 394

t = "abcde"
sum(t) = 97 + 98 + 99 + 100 + 101 = 495

diff = 495 - 394 = 101
chr(101) = 'e'
```
