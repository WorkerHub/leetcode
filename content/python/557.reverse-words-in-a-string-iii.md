## 题目描述

给定一个字符串 `s`，你需要反转字符串中每个单词的字符顺序，同时仍保留空格和单词的初始顺序。

**示例 1：**
```
输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"
```

**示例 2：**
```
输入：s = "Mr Ding"
输出："rM gniD"
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `s` 包含可打印的 ASCII 字符
- `s` 不包含任何开头或结尾空格
- `s` 里至少有一个词
- `s` 中的所有单词都用一个空格隔开

## 解题思路

这是一道简单的字符串处理题，需要反转每个单词内部的字符，但保持单词的顺序。

核心思想：
1. 按空格分割字符串，得到单词列表
2. 反转每个单词
3. 用空格重新连接

## Python 代码实现

### 方法一：split + 反转（推荐）⭐

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        """
        使用 split 和字符串反转
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        return ' '.join(word[::-1] for word in s.split())
```

### 方法二：双指针

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        """
        使用双指针找到每个单词的边界
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        result = []
        left = 0
        
        for right in range(len(s)):
            # 遇到空格或到达末尾，反转单词
            if s[right] == ' ':
                result.append(s[left:right][::-1])
                result.append(' ')
                left = right + 1
        
        # 处理最后一个单词
        result.append(s[left:][::-1])
        
        return ''.join(result)
```

### 方法三：转换为列表原地反转

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        """
        转换为列表进行原地反转
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        chars = list(s)
        n = len(chars)
        
        def reverse(left: int, right: int) -> None:
            """反转 chars[left:right+1]"""
            while left < right:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1
        
        # 找到每个单词并反转
        start = 0
        for i in range(n):
            if chars[i] == ' ':
                reverse(start, i - 1)
                start = i + 1
        
        # 反转最后一个单词
        reverse(start, n - 1)
        
        return ''.join(chars)
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，需要遍历整个字符串
- **空间复杂度**：O(n)，存储结果字符串

## 关键点总结

1. **Python 特性**：使用切片 `[::-1]` 反转字符串
2. **split 方法**：按空格分割字符串
3. **join 方法**：用空格连接单词列表
4. **列表推导式**：简洁地处理每个单词
5. **一行代码**：方法一展示了 Python 的简洁性

## 易错点

1. **理解题意**：反转每个单词内部，不是反转整个字符串
2. **空格处理**：保持单词之间的空格
3. **边界情况**：最后一个单词需要单独处理
4. **单词定义**：单词是由空格分隔的字符序列
