## 题目描述

给定一个字符串 `word` 和整数 `k`。你可以选择字符串中任意一段连续子串，将其中所有字符向后移动一位（'a'->'b', 'b'->'c', ..., 'z'->'a'），操作 `k` 次，使得最终字符串字典序最小。返回结果字符串。

**示例 1：**

```
输入：word = "zb", k = 3
输出："ab"
解释：将 'z' 变为 'a'（操作1），'a' 无需再变，得 "ab"。
     注意：每次操作增加一位，'z' 需要操作才能变成 'a'（循环）。
     实际：k=3 次，每次可选一个连续区间做 +1 操作。
```

**示例 2：**

```
输入：word = "ac", k = 2
输出："aa"
```

**提示：**
- `1 <= word.length <= 100`
- `1 <= k <= 100`

## 解题思路

贪心：对于每个字符，若操作 k 次足够将其变为 'a'（即 `26 - ord(c) + ord('a') <= k`，即把字符减到 'a' 所需步骤），则变为 'a'；否则尽量减小（+k 次后取最小）。

但操作是选区间 +1（不是 -1），需要重新理解：每次操作将某个区间中的每个字符向后移一位（+1 mod 26）。

贪心策略：每次选择最靠左的、尽可能减小的位置操作。但由于 +1 操作，实际上字符只会增大（或循环回 'a'）。

重新理解：字符 +k 次后的值为 `(c - 'a' + k) % 26`，选择 k 次操作的区间，使字典序最小。实际上每个字符可以选择被包含在 0 到 k 次操作中，每次包含给字符 +1。

## Python 代码实现

### 方法一：贪心对每个字符独立操作（推荐）

```python
class Solution:
    def smallestString(self, word: str, k: int) -> str:
        n = len(word)
        chars = list(word)

        # 对每个字符，判断能否通过 k 次操作将其减小
        # +1 循环：字符 c 操作 m 次后变为 (c + m) % 26
        # 要使结果最小，对每个字符找最优的操作次数

        # 贪心：尽可能多地给字符 +1 使其变为 'a'（即绕一圈）
        # 从左到右，贪心地减小字符

        remaining = k
        i = 0
        while remaining > 0 and i < n:
            c = ord(chars[i]) - ord('a')
            # 将 chars[i] 变为 'a' 需要 (26 - c) % 26 次操作
            steps_to_a = (26 - c) % 26
            if steps_to_a == 0:
                # 已经是 'a'，跳过
                i += 1
                continue
            if remaining >= steps_to_a:
                chars[i] = 'a'
                remaining -= steps_to_a
                i += 1
            else:
                # 不够变成 'a'，但可以+remaining 次，字符变大，不如不操作
                # 操作会让字符变大，不是最优
                # 但对于当前字符，不操作（保持原样），继续下一个
                # 贪心：若不能变成 'a'，不操作当前字符
                break

        return ''.join(chars)
```

### 方法二：枚举选择区间

```python
class Solution:
    def smallestString(self, word: str, k: int) -> str:
        chars = list(word)
        n = len(chars)

        # 贪心：对每个位置，尽量使用操作将其变为 'a'
        ops = k
        for i in range(n):
            if ops == 0:
                break
            c = ord(chars[i]) - ord('a')
            # 需要多少步能变成 'a'
            steps = (26 - c) % 26
            if steps == 0:
                continue  # 已经是 'a'
            if ops >= steps:
                chars[i] = 'a'
                ops -= steps
            else:
                # 操作 ops 次，字符变大（非最优），放弃操作此字符
                # 将剩余操作全部用于此字符（使其尽量小），但结果大于 'a'
                # 由于 +1 循环，ops 步后字符值 = (c + ops) % 26
                # 这可能更大，不如不操作
                break

        return ''.join(chars)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(n)，字符列表

## 关键点总结

1. 字符 +1 操作是循环的（'z' -> 'a'）
2. 贪心：优先将字符变为 'a'（绕圈需要 `26 - c` 步）
3. 若操作次数不足以将当前字符变为 'a'，则不操作（因为 +k 会使字符变大）

## 易错点

1. 操作是 +1（字符增大），不是 -1（字符减小）
2. 字符已为 'a' 时步数为 0，需特殊处理
3. 剩余操作数用完后停止
