## 题目描述

序列化是指将一个数据结构转化为位序列的过程，因此可以将其存储在文件中或内存缓冲区中，以便稍后在相同或不同的计算机环境中恢复结构。

设计一个序列化和反序列化 N 叉树的算法。一个 N 叉树是指每个节点都有不超过 N 个孩子节点的有根树。序列化 / 反序列化算法的算法实现没有限制。你只需要保证 N 叉树可以被序列化为一个字符串并且该字符串可以被反序列化成原树结构即可。

**示例 1：**

![](https://assets.leetcode.com/uploads/2018/10/12/narytreeexample.png)

```
输入：root = [1,null,3,2,4,null,5,6]
输出：[1,null,3,2,4,null,5,6]
```

**示例 2：**
```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

**示例 3：**
```
输入：root = []
输出：[]
```

**提示：**
- 树的节点数在范围 `[0, 10^4]` 内
- `0 <= Node.val <= 10^4`
- N 叉树的高度小于或等于 1000
- 不要使用类成员 / 全局变量 / 静态变量来存储状态。你的序列化和反序列化算法应是无状态的。

## 解题思路

这道题要求设计 N 叉树的序列化和反序列化算法。关键是如何编码树的结构信息。

**核心思想：**
1. 序列化时需要记录每个节点的值和子节点数量
2. 可以使用前序遍历或层序遍历
3. 使用特殊标记来分隔节点和子节点列表

**常用方案：**

**方案一：前序遍历 + 子节点数量**
- 格式：`值 子节点数 [子节点1] [子节点2] ...`
- 例如：`1 3 3 0 2 0 4 0` 表示根节点1有3个子节点

**方案二：层序遍历 + null 分隔**
- 使用 null 标记每层的结束
- 类似二叉树的层序遍历

**方案三：括号表示法**
- 格式：`值[子树1][子树2]...`
- 例如：`1[3[5][6]][2][4]`

## Python 代码实现

### 方法一：前序遍历 + 子节点数量 ⭐ 推荐

```python
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []

class Codec:
    def serialize(self, root: 'Node') -> str:
        """编码：将树转为字符串"""
        if not root:
            return ""
        
        result = []
        
        def dfs(node):
            if not node:
                return
            
            # 记录节点值和子节点数量
            result.append(str(node.val))
            result.append(str(len(node.children)))
            
            # 递归处理所有子节点
            for child in node.children:
                dfs(child)
        
        dfs(root)
        return ','.join(result)
    
    def deserialize(self, data: str) -> 'Node':
        """解码：将字符串转为树"""
        if not data:
            return None
        
        tokens = data.split(',')
        self.index = 0
        
        def dfs():
            if self.index >= len(tokens):
                return None
            
            # 读取节点值和子节点数量
            val = int(tokens[self.index])
            self.index += 1
            
            children_count = int(tokens[self.index])
            self.index += 1
            
            # 创建节点
            node = Node(val, [])
            
            # 递归构建所有子节点
            for _ in range(children_count):
                node.children.append(dfs())
            
            return node
        
        return dfs()
```

### 方法二：层序遍历

```python
from collections import deque

class Codec:
    def serialize(self, root: 'Node') -> str:
        if not root:
            return ""
        
        result = []
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            result.append(str(node.val))
            result.append(str(len(node.children)))
            
            for child in node.children:
                queue.append(child)
        
        return ','.join(result)
    
    def deserialize(self, data: str) -> 'Node':
        if not data:
            return None
        
        tokens = data.split(',')
        root = Node(int(tokens[0]), [])
        
        queue = deque([root])
        index = 2  # 跳过根节点的值和子节点数
        
        while queue:
            node = queue.popleft()
            # tokens[index-1] 是当前节点的子节点数量
            children_count = int(tokens[index - 1])
            
            for _ in range(children_count):
                val = int(tokens[index])
                child = Node(val, [])
                node.children.append(child)
                queue.append(child)
                index += 2  # 跳过值和子节点数
        
        return root
```

### 方法三：括号表示法

```python
class Codec:
    def serialize(self, root: 'Node') -> str:
        if not root:
            return ""
        
        def dfs(node):
            if not node:
                return ""
            
            # 节点值
            s = str(node.val)
            
            # 如果有子节点，用括号包围
            if node.children:
                s += '['
                s += ','.join(dfs(child) for child in node.children)
                s += ']'
            
            return s
        
        return dfs(root)
    
    def deserialize(self, data: str) -> 'Node':
        if not data:
            return None
        
        self.index = 0
        
        def dfs():
            if self.index >= len(data):
                return None
            
            # 读取节点值
            val = 0
            while self.index < len(data) and data[self.index].isdigit():
                val = val * 10 + int(data[self.index])
                self.index += 1
            
            node = Node(val, [])
            
            # 如果有左括号，说明有子节点
            if self.index < len(data) and data[self.index] == '[':
                self.index += 1  # 跳过 '['
                
                while self.index < len(data) and data[self.index] != ']':
                    node.children.append(dfs())
                    # 跳过逗号
                    if self.index < len(data) and data[self.index] == ',':
                        self.index += 1
                
                self.index += 1  # 跳过 ']'
            
            return node
        
        return dfs()
```

### 方法四：使用 JSON（Python 特色）

```python
import json

class Codec:
    def serialize(self, root: 'Node') -> str:
        def to_dict(node):
            if not node:
                return None
            return {
                'val': node.val,
                'children': [to_dict(child) for child in node.children]
            }
        
        return json.dumps(to_dict(root))
    
    def deserialize(self, data: str) -> 'Node':
        def from_dict(d):
            if d is None:
                return None
            node = Node(d['val'], [])
            node.children = [from_dict(child) for child in d['children']]
            return node
        
        return from_dict(json.loads(data))
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是节点数量
  - 序列化：需要访问每个节点一次
  - 反序列化：需要创建每个节点一次
- 空间复杂度：O(n)
  - 存储序列化字符串：O(n)
  - 递归栈空间：O(h)，h 是树的高度

## 关键点总结

1. **编码方案设计**：需要同时编码节点值和结构信息（子节点数量）
2. **前序遍历**：递归处理根节点和所有子节点
3. **索引管理**：反序列化时需要维护当前读取位置
4. **子节点数量**：记录子节点数量是恢复树结构的关键
5. **边界处理**：空树要特殊处理

## 易错点

1. **索引越界**：反序列化时要检查索引是否超出范围
2. **子节点数量**：必须在序列化时记录，反序列化时读取
3. **递归终止**：空节点要正确处理
4. **分隔符选择**：避免与节点值冲突
5. **状态管理**：不能使用全局变量，应该使用实例变量或闭包
