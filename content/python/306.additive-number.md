## 题目描述

**累加数**是一个字符串，组成它的数字可以形成累加序列。

一个有效的**累加序列**必须**至少**包含 3 个数。除了最开始的两个数以外，序列中的每个后续数字必须是它之前两个数字之和。

给你一个只包含数字 `'0'-'9'` 的字符串，编写一个算法来判断给定输入是否是**累加数**。如果是，返回 `true` ；否则，返回 `false` 。

**说明**：累加序列里的数，除数字 0 之外，**不会**以 0 开头，所以不会出现 `1, 2, 03` 或者 `1, 02, 3` 的情况。

**示例 1：**
```
输入："112358"
输出：true 
解释：累加序列为: 1, 1, 2, 3, 5, 8
     1 + 1 = 2, 1 + 2 = 3, 2 + 3 = 5, 3 + 5 = 8
```

**示例 2：**
```
输入："199100199"
输出：true 
解释：累加序列为: 1, 99, 100, 199
     1 + 99 = 100, 99 + 100 = 199
```

**示例 3：**
```
输入："0235813"
输出：false
```

**提示：**
- `1 <= num.length <= 35`
- `num` 仅由数字（`0` - `9`）组成

## 解题思路

这是一道典型的**回溯**问题。核心思路是：

1. **枚举前两个数**：
   - 前两个数确定后，后续的数都是固定的
   - 第一个数的长度：1 到 n/2
   - 第二个数的长度：1 到 (n - len1) / 2

2. **验证累加序列**：
   - 从第三个数开始，每个数必须等于前两个数之和
   - 如果能匹配到字符串末尾，返回 true

3. **剪枝条件**：
   - 数字不能以 0 开头（除了数字 0 本身）
   - 前两个数的长度和不能超过字符串长度的 2/3

## Python 代码实现

### 方法一：回溯（推荐）⭐

```python
class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        n = len(num)
        
        # 枚举第一个数的长度
        for i in range(1, n):
            # 第一个数不能以 0 开头（除非是 0）
            if num[0] == '0' and i > 1:
                break
            
            # 枚举第二个数的长度
            for j in range(i + 1, n):
                # 第二个数不能以 0 开头（除非是 0）
                if num[i] == '0' and j - i > 1:
                    break
                
                # 获取前两个数
                num1 = int(num[:i])
                num2 = int(num[i:j])
                
                # 验证从第三个数开始的累加序列
                if self.is_valid(num, j, num1, num2):
                    return True
        
        return False
    
    def is_valid(self, num: str, start: int, num1: int, num2: int) -> bool:
        """
        从 start 位置开始验证累加序列
        num1 和 num2 是前两个数
        """
        # 如果已经到达字符串末尾，说明验证成功
        if start == len(num):
            return True
        
        # 计算下一个数应该是多少
        next_num = num1 + num2
        next_str = str(next_num)
        
        # 检查字符串是否以 next_str 开头
        if not num[start:].startswith(next_str):
            return False
        
        # 递归验证后续序列
        return self.is_valid(num, start + len(next_str), num2, next_num)
```

### 方法二：迭代版本

```python
class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        n = len(num)
        
        # 枚举第一个数的长度
        for i in range(1, n):
            if num[0] == '0' and i > 1:
                break
            
            # 枚举第二个数的长度
            for j in range(i + 1, n):
                if num[i] == '0' and j - i > 1:
                    break
                
                num1 = int(num[:i])
                num2 = int(num[i:j])
                
                # 迭代验证
                start = j
                while start < n:
                    next_num = num1 + num2
                    next_str = str(next_num)
                    
                    # 检查是否匹配
                    if not num[start:].startswith(next_str):
                        break
                    
                    # 更新位置和数字
                    start += len(next_str)
                    num1, num2 = num2, next_num
                
                # 如果到达末尾，说明是累加数
                if start == n:
                    return True
        
        return False
```

### 方法三：字符串操作优化

```python
class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        def add_strings(s1: str, s2: str) -> str:
            """字符串形式的加法，避免大数溢出"""
            result = []
            carry = 0
            i, j = len(s1) - 1, len(s2) - 1
            
            while i >= 0 or j >= 0 or carry:
                digit1 = int(s1[i]) if i >= 0 else 0
                digit2 = int(s2[j]) if j >= 0 else 0
                
                total = digit1 + digit2 + carry
                result.append(str(total % 10))
                carry = total // 10
                
                i -= 1
                j -= 1
            
            return ''.join(reversed(result))
        
        def is_valid(num1: str, num2: str, start: int) -> bool:
            """验证从 start 开始的累加序列"""
            while start < len(num):
                next_str = add_strings(num1, num2)
                
                if not num[start:].startswith(next_str):
                    return False
                
                start += len(next_str)
                num1, num2 = num2, next_str
            
            return True
        
        n = len(num)
        
        for i in range(1, n):
            if num[0] == '0' and i > 1:
                break
            
            for j in range(i + 1, n):
                if num[i] == '0' and j - i > 1:
                    break
                
                if is_valid(num[:i], num[i:j], j):
                    return True
        
        return False
```

### 方法四：带详细注释的版本

```python
class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        """
        判断字符串是否是累加数
        
        思路：
        1. 枚举前两个数的所有可能组合
        2. 对每种组合，验证是否能形成累加序列
        """
        n = len(num)
        
        # 第一个数的长度最多到 n//2
        # 因为至少要有 3 个数，第三个数长度至少为 1
        for len1 in range(1, n // 2 + 1):
            # 不能以 0 开头（除非就是 "0"）
            if num[0] == '0' and len1 > 1:
                break
            
            # 第二个数的长度
            for len2 in range(1, n - len1):
                # 第二个数也不能以 0 开头
                if num[len1] == '0' and len2 > 1:
                    break
                
                # 提取前两个数
                first = int(num[:len1])
                second = int(num[len1:len1 + len2])
                
                # 验证累加序列
                if self.check(num, len1 + len2, first, second):
                    return True
        
        return False
    
    def check(self, num: str, start: int, first: int, second: int) -> bool:
        """
        检查从 start 位置开始是否能形成累加序列
        
        参数：
        - num: 原字符串
        - start: 当前检查位置
        - first: 前一个数
        - second: 当前数
        """
        # 已经检查到末尾，成功
        if start == len(num):
            return True
        
        # 计算第三个数
        third = first + second
        third_str = str(third)
        
        # 检查剩余字符串是否以 third_str 开头
        if num[start:start + len(third_str)] != third_str:
            return False
        
        # 递归检查后续部分
        return self.check(num, start + len(third_str), second, third)
```

## 复杂度分析

- 时间复杂度：O(n^3)
  - 外层两个循环：O(n^2)
  - 验证累加序列：O(n)
- 空间复杂度：O(n)，递归栈的深度

## 关键点总结

1. **枚举前两个数**：前两个数确定后，后续序列唯一确定
2. **剪枝优化**：
   - 不能以 0 开头（除了数字 0）
   - 第一个数长度最多 n/2
3. **验证方法**：递归或迭代都可以
4. **大数处理**：Python 的 int 自动处理大数，其他语言可能需要字符串加法
5. **边界条件**：至少需要 3 个数

## 易错点

1. **前导零处理**：`"0235813"` 中 `02` 是非法的
2. **单个 0 是合法的**：`"101"` 中第一个数可以是 `"0"`
3. **长度限制**：第一个数最长 n/2，第二个数最长 (n - len1)
4. **字符串匹配**：使用 `startswith` 而不是直接比较
5. **递归终止条件**：`start == len(num)` 表示成功
