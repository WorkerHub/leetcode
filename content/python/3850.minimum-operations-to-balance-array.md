## 题目描述

给你一个整数数组 `nums`，每次操作可以选择数组中的任意一个元素加 1 或减 1。

返回使数组中所有元素相等所需的最少操作次数。

**示例 1：**

```
输入：nums = [1, 2, 3]
输出：2
解释：将所有元素变为 2：|1-2| + |2-2| + |3-2| = 1 + 0 + 1 = 2。
```

**示例 2：**

```
输入：nums = [1, 10, 2, 9]
输出：16
解释：最优目标值为 5 或 6：|1-5|+|10-5|+|2-5|+|9-5|=4+5+3+4=16。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

使所有元素相等的最少操作次数 = 以**中位数**为目标值时，各元素与中位数的绝对差之和。

数学证明：目标值为中位数时，绝对差之和最小。

## Python 代码实现

### 方法一：排序取中位数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        nums.sort()
        median = nums[len(nums) // 2]
        return sum(abs(x - median) for x in nums)
```

### 方法二：前缀和优化

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        # 中位数
        mid = n // 2
        median = nums[mid]

        # 左半部分（<=中位数）：每个元素要加 (median - x)
        # 右半部分（>=中位数）：每个元素要减 (x - median)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 左半：median * (mid+1) - prefix[mid+1]
        left_ops = median * (mid + 1) - prefix[mid + 1]
        # 右半：(prefix[n] - prefix[mid]) - median * (n - mid)
        right_ops = (prefix[n] - prefix[mid]) - median * (n - mid)

        return left_ops + right_ops
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（方法一）；O(n)（方法二，前缀和）

## 关键点总结

1. 使所有元素相等的最优目标是中位数，这是绝对值优化的经典结论。
2. 奇数长度数组的中位数是唯一的（`n//2`），偶数长度时两个中间值都可以。
3. 前缀和优化可以将 O(n) 的求和简化为 O(1)。

## 易错点

1. 中位数位置 `n//2`（排序后），偶数长度时也可以取 `(n-1)//2`（结果相同）。
2. 不要取均值（非整数时不适用，且不是最优解）。
