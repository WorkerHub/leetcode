## 题目描述

给你一个披萨，它由 `3n` 片不同大小的部分组成，披萨的各部分沿顺时针方向分配，你和另外两位朋友将共同享用这块披萨，每人取 `n` 片。

游戏规则如下：
1. 你挑一片披萨。
2. 你顺时针方向的朋友从剩下的部分中挑与你的相邻的一片（另一朋友被跳过）。
3. 你逆时针方向的朋友从剩下的部分中挑取与你的相邻的一片（另一朋友被跳过）。
4. 重复步骤 1-3，直到没有披萨剩下。

你的目标是尽量挑到最大总量的披萨。

**请你返回你最终可以获得的最大披萨总量。**

**示例 1：**
```
输入：slices = [1,2,3,4,5,6]
输出：10
解释：选择 4，则 2 和 6 被吃掉。再选择 1，则 1 的相邻被吃掉（空）。再选 5。总共 4+1+5=10？
等等，实际上是：选 4（相邻 3 和 5 被吃掉）→ 剩 [1,2,6]（环形，但要按顺序）…

实际答案：选下标2（值3）→ 两边吃掉1（值2）和5（值4）；再选下标5（值6）→ 两边...
实际最优：选 index 4（值5）→ 3和6被吃→剩[1,2,4]环→选4→2和1被吃→剩[]→选... 

答案为 10（选择 1,3,5 位置的元素）
```

**示例 2：**
```
输入：slices = [8,9,8,6,1,1]
输出：16
```

**提示：**
- `3 * n == slices.length`
- `1 <= n <= 500`
- `1 <= slices[i] <= 1000`

## 解题思路

### 核心思想：转化为"环形数组中不相邻选 n 个元素最大和"

**问题转化：**

每次你选一片 `slices[i]` 后，相邻的 `slices[i-1]` 和 `slices[i+1]` 会被其他人取走，无法再选。
因此，**你选的 n 片之间不能相邻**（任意两片之间至少间隔1片）。

这等价于：从长度 `3n` 的**环形数组**中，选 `n` 个**互不相邻**的元素，使总和最大。

**线性 vs 环形处理：**

环形数组的不相邻选取：与"打家劫舍II"相同，分两种情况：
- 情况1：不选第1个元素，从 `slices[1..3n-1]` 中选 n 个不相邻元素。
- 情况2：不选最后一个元素，从 `slices[0..3n-2]` 中选 n 个不相邻元素。
- 两种情况取最大值。

**线性动态规划（从数组中选 k 个不相邻元素最大和）：**

设 `dp[i][j]` = 从前 `i` 个元素中选 `j` 个不相邻元素的最大和。

状态转移：
- 不选第 i 个：`dp[i][j] = dp[i-1][j]`
- 选第 i 个（则 i-1 不能选）：`dp[i][j] = dp[i-2][j-1] + slices[i-1]`

`dp[i][j] = max(dp[i-1][j], dp[i-2][j-1] + slices[i-1])`

### 方法一：动态规划（推荐）

### 方法二：贪心 + 最大堆（选 n 次最大值，移除相邻）

## Python 代码实现

### 方法一：DP（推荐，O(n²)）

```python
from typing import List

class Solution:
    def maxSizeSlices(self, slices: List[int]) -> int:
        n = len(slices) // 3  # 需要选的片数
        m = len(slices)       # 总片数 3n

        def max_sum_no_adjacent(arr, k):
            """
            从线性数组 arr 中选 k 个不相邻元素，返回最大和
            dp[i][j] = 前 i 个元素中选 j 个不相邻元素的最大和
            """
            size = len(arr)
            # dp[i][j]：前 i 个元素中选 j 个不相邻元素的最大和
            # 初始化：0 个元素或选 0 个时，和为 0
            # 为避免 i-2 越界，dp 大小设为 (size+2) × (k+1)
            dp = [[0] * (k + 1) for _ in range(size + 2)]

            for i in range(1, size + 1):
                for j in range(1, k + 1):
                    # 不选第 i 个
                    not_take = dp[i-1][j]
                    # 选第 i 个（上一个不能选第 i-1）
                    take = dp[i-2][j-1] + arr[i-1]
                    dp[i][j] = max(not_take, take)

            return dp[size][k]

        # 情况1：不选第1个，从 slices[1..] 中选
        case1 = max_sum_no_adjacent(slices[1:], n)
        # 情况2：不选最后1个，从 slices[..m-2] 中选
        case2 = max_sum_no_adjacent(slices[:m-1], n)

        return max(case1, case2)
```

### 方法二：DP（空间优化版）

```python
from typing import List

class Solution:
    def maxSizeSlices(self, slices: List[int]) -> int:
        n = len(slices) // 3
        m = len(slices)

        def solve(arr):
            """从线性数组中选 n 个不相邻元素的最大和"""
            size = len(arr)
            # 滚动数组优化空间
            # prev2[j]: dp[i-2][j], prev1[j]: dp[i-1][j]
            prev2 = [0] * (n + 1)
            prev1 = [0] * (n + 1)

            for i in range(1, size + 1):
                curr = [0] * (n + 1)
                for j in range(1, n + 1):
                    curr[j] = max(prev1[j], prev2[j-1] + arr[i-1])
                prev2 = prev1
                prev1 = curr

            return prev1[n]

        return max(solve(slices[1:]), solve(slices[:-1]))
```

### 方法三：贪心 + 最大堆（等效解法）

```python
from typing import List
import heapq

class Solution:
    def maxSizeSlices(self, slices: List[int]) -> int:
        """
        贪心思路：
        每次选当前最大的元素，选后把它和相邻两个替换为一个虚拟元素（值为选到的元素
        减去两边的值），允许"反悔"：如果选这个虚拟元素，等效于取消上次选择，改选两边。
        重复 n 次，得到最优选择。
        这是经典的"带反悔的贪心"（与 hdu1509 类似）。
        """
        def greedy(arr):
            size = len(arr)
            # 用双向链表模拟（方便删除中间节点）
            # 用列表和 prev/next 指针模拟
            vals = list(arr)
            prev_idx = [(i - 1) % size for i in range(size)]
            next_idx = [(i + 1) % size for i in range(size)]
            removed = [False] * size

            # 最大堆（Python 用负值模拟最大堆）
            heap = [(-vals[i], i) for i in range(size)]
            heapq.heapify(heap)

            result = 0
            picks = n  # 需要选 n 次

            while picks > 0:
                # 取当前最大值
                while heap and (removed[heap[0][1]] or -heap[0][0] != vals[heap[0][1]]):
                    heapq.heappop(heap)

                neg_val, idx = heapq.heappop(heap)
                val = -neg_val
                result += val

                # 将当前节点替换为"反悔节点"：值 = val - left_val - right_val
                left = prev_idx[idx]
                right = next_idx[idx]
                # 反悔节点的值
                new_val = vals[left] + vals[right] - val
                vals[idx] = new_val
                heapq.heappush(heap, (-new_val, idx))

                # 删除左右节点（逻辑删除）
                removed[left] = True
                removed[right] = True

                # 更新链表指针
                left_left = prev_idx[left]
                right_right = next_idx[right]
                prev_idx[idx] = left_left
                next_idx[idx] = right_right
                next_idx[left_left] = idx
                prev_idx[right_right] = idx

                picks -= 1

            return result

        # 对两种情况取最大（处理环形）
        # 情况1：固定排除第0个元素
        # 情况2：固定排除最后一个元素
        # 但贪心方法直接在环上操作，取两种情况的最大值
        return max(greedy(slices[1:] + [0]), greedy(slices[:-1] + [0]))
        # 注意：贪心方法复杂度 O(n log n)，但实现较复杂，推荐 DP 方法
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP（标准） | O(n²) | O(n²) |
| DP（空间优化） | O(n²) | O(n) |
| 贪心 + 堆 | O(n log n) | O(n) |

- **DP**：两次 `solve` 函数，每次 O(m × n) = O(3n × n) = O(n²)。
- **贪心**：n 次堆操作，每次 O(log(3n)) = O(log n)，总 O(n log n)。

## 关键点总结

1. **问题转化**：选 n 片使得任意两片不相邻，等价于"环形数组选 n 个不相邻元素最大和"。
2. **环形转线性**：拆分为两种情况（包含/不包含首元素），分别对线性数组求解，取最大值。
3. **DP 状态**：`dp[i][j]` = 前 i 个中选 j 个不相邻的最大和，状态转移清晰。
4. **空间优化**：注意 `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，可用滚动数组优化空间。
5. **贪心 + 反悔堆**：更高效但实现复杂，属于高阶技巧。

## 易错点

1. **环形处理**：不能直接对整个数组做线性 DP，必须分为两种情况（去掉首/尾）分别求解。
2. **dp 初始化**：`dp[0][j] = 0`（选0个时和为0），`dp[i][0] = 0`（选0个时和为0），要正确初始化。
3. **i-2 越界**：计算 `dp[i-2][j-1]` 时，i=1 会导致 `i-2 = -1`，需要添加偏移量或特殊处理（方法一中 `dp` 大小为 size+2，从下标1开始）。
4. **选 n 个 vs 选最多 n 个**：本题规则保证恰好选 n 片，且题目等价于求恰好选 n 个不相邻元素的最大和。
