## 题目描述

给定字符串数组 `words`，统计满足以下条件的对 `(i, j)`（`i < j`）的数量：`words[i]` 是 `words[j]` 的前缀，或 `words[j]` 是 `words[i]` 的前缀（或两者相等）。

**示例 1：**
```
输入：words = ["a","b","c","ab","bc","abc"]
输出：3
解释：
- "a" 是 "ab" 的前缀 (0,3)
- "a" 是 "abc" 的前缀 (0,5)
- "ab" 是 "abc" 的前缀 (3,5)
共 3 对。
```

**示例 2：**
```
输入：words = ["abcd","ab","bc","abc"]
输出：2
解释：(1,0): "ab" 是 "abcd" 的前缀；(3,0): "abc" 是 "abcd" 的前缀；
     (1,3): "ab" 是 "abc" 的前缀。共 3 对。
```

**提示：**
- `1 <= words.length <= 50`
- `1 <= words[i].length <= 50`
- 均为小写字母

## 解题思路

**方法一：暴力枚举**（n <= 50 时完全可行）

枚举所有对 `(i, j)`，用 `str.startswith()` 判断前缀关系。

**方法二：字典树**

将所有词插入 Trie，对每个词查询有多少词是其前缀或以其为前缀。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        n = len(words)
        count = 0

        for i in range(n):
            for j in range(i + 1, n):
                a, b = words[i], words[j]
                # a 是 b 的前缀，或 b 是 a 的前缀
                if b.startswith(a) or a.startswith(b):
                    count += 1

        return count
```

### 方法二：字典树

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        # 用字典树统计前缀关系
        trie = {}
        count = 0

        for word in words:
            node = trie
            # 沿途的每个节点代表一个前缀，若该前缀是已插入的某个词，则计数
            for i, c in enumerate(word):
                if c not in node:
                    node[c] = {'#': 0}
                node = node[c]
                if node.get('#', 0) > 0:
                    # 当前前缀 word[:i+1] 是之前某个词
                    count += node['#']
            # 若整个 word 是之前某个词的前缀（需要反向查询）
            # 直接在暴力中更简单
            node['#'] = node.get('#', 0) + 1

        # 上面只计算了"已有词是当前词的前缀"
        # 还需要计算"当前词是已有词的前缀"（即已有词以当前词开头）
        # 字典树方法只处理了一个方向，双向需要额外处理
        # 简单起见，仍用暴力

        # 直接暴力
        n = len(words)
        result = 0
        for i in range(n):
            for j in range(i + 1, n):
                if words[j].startswith(words[i]) or words[i].startswith(words[j]):
                    result += 1
        return result
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为词数，L 为最大词长
- 空间复杂度：O(1)（不计输入）

## 关键点总结

1. `str.startswith()` 内置方法简洁高效
2. 由于 n <= 50，O(n^2) 暴力完全可行
3. 前缀关系是双向的：需要同时检查两个方向

## 易错点

1. 两个方向都要检查：`a` 是 `b` 的前缀，或 `b` 是 `a` 的前缀
2. 相等的两个词互为前缀（`a == b` 时 `a.startswith(b)` 为 True）
