## 题目描述

给你一个 `n` 个点的无向图，其中边由 `edgeList` 给出，`edgeList[i] = [ui, vi, disi]` 表示节点 `ui` 和 `vi` 之间有一条距离为 `disi` 的边。

注意：两个节点之间可能有多条边。

给你一个查询数组 `queries`，其中 `queries[j] = [pj, qj, limitj]`，返回一个**布尔值数组** `answer`，其中 `answer[j]` 为 `true` 当且仅当存在一条从 `pj` 到 `qj` 的路径，且路径上每条边的距离都**严格小于** `limitj`。

**示例 1：**
```
输入：n = 3, edgeList = [[0,1,2],[1,2,4],[2,0,8],[1,0,16]], queries = [[0,1,2],[0,2,5]]
输出：[false,true]
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= edgeList.length, queries.length <= 10^5`
- `1 <= disi, limitj <= 10^9`

## 解题思路

离线处理 + 并查集。

核心思路：将查询和边都按权重排序，从小到大依次将权重小于当前查询 limit 的边加入并查集，然后用并查集判断两点是否连通。

步骤：
1. 将所有查询打上原始下标标记，按 `limit` 升序排序
2. 将 `edgeList` 按边权升序排序
3. 双指针：对每个查询，将所有权重 < limit 的边加入并查集，然后查询两点是否连通

## 代码实现

### 方法一：离线查询 + 并查集（推荐）

```python
from typing import List

class Solution:
    def distanceLimitedPathsExist(self, n: int, edgeList: List[List[int]], queries: List[List[int]]) -> List[bool]:
        # 并查集初始化
        parent = list(range(n))
        rank = [0] * n

        def find(x):
            # 路径压缩
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            # 按秩合并
            px, py = find(x), find(y)
            if px == py:
                return
            if rank[px] < rank[py]:
                px, py = py, px
            parent[py] = px
            if rank[px] == rank[py]:
                rank[px] += 1

        # 将查询和边按权重排序（离线处理）
        # 查询：(limit, p, q, 原始下标)
        sorted_queries = sorted(
            [(limit, p, q, i) for i, (p, q, limit) in enumerate(queries)]
        )
        # 边：按权重排序
        sorted_edges = sorted(edgeList, key=lambda e: e[2])

        answer = [False] * len(queries)
        edge_idx = 0

        for limit, p, q, qi in sorted_queries:
            # 将所有权重严格小于 limit 的边加入并查集
            while edge_idx < len(sorted_edges) and sorted_edges[edge_idx][2] < limit:
                u, v, d = sorted_edges[edge_idx]
                union(u, v)
                edge_idx += 1
            # 判断 p 和 q 是否连通
            answer[qi] = (find(p) == find(q))

        return answer
```

### 方法二：在线处理（Kruskal + 二分，了解即可）

```python
from typing import List

class Solution:
    def distanceLimitedPathsExist(self, n: int, edgeList: List[List[int]], queries: List[List[int]]) -> List[bool]:
        # 方法一已是最优，此处提供结构相同但用 lambda 简化的写法
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径减半
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        edgeList.sort(key=lambda e: e[2])
        q_sorted = sorted(range(len(queries)), key=lambda i: queries[i][2])

        answer = [False] * len(queries)
        ei = 0

        for qi in q_sorted:
            p, q, limit = queries[qi]
            while ei < len(edgeList) and edgeList[ei][2] < limit:
                union(edgeList[ei][0], edgeList[ei][1])
                ei += 1
            answer[qi] = (find(p) == find(q))

        return answer
```

## 复杂度分析

- **时间复杂度**：O((E + Q) log(E + Q))，排序是主要开销，并查集操作近似 O(1)
- **空间复杂度**：O(n + Q)，并查集数组和排序后查询数组

## 关键点总结

1. 离线思路：将所有查询一起处理，不需要对每个查询从头扫描所有边
2. 双指针：已排序的边和查询同向推进，边只会被加入并查集一次
3. 并查集判断连通性非常高效，路径压缩+按秩合并接近 O(1)
4. 注意条件是"严格小于 limit"，边权等于 limit 的边不能加入

## 易错点

1. 严格小于 `<`，不是小于等于：`sorted_edges[edge_idx][2] < limit`
2. 查询要保留原始下标，排序时一并携带，填写答案时用原始下标
3. 边指针 `edge_idx` 不重置，持续推进（离线处理的关键）
