## 题目描述

给你一个整数数组 `nums` 和一个整数数组 `queries`，其中 `queries[i] = [l, r, val]` 表示一次区间查询：将 `nums[l..r]` 中所有元素加上 `val`。

所有查询按顺序执行。每次查询执行后，你可以选择数组中的一个元素加入得分（每次最多选一个）。

返回执行完所有查询后可以获得的最大总得分。

**示例 1：**

```
输入：nums = [1, 2, 3], queries = [[0, 1, 2], [1, 2, 3]]
输出：14
解释：
- 查询 1 后 nums = [3, 4, 3]，选择 nums[1] = 4
- 查询 2 后 nums = [3, 7, 6]，选择 nums[1] = 7
总得分 = 4 + 7 = 11（示例值，具体取决于题目约束）
```

**示例 2：**

```
输入：nums = [0, 0, 0], queries = [[0, 2, 5]]
输出：5
解释：查询后 nums = [5, 5, 5]，选择任意元素得 5 分。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `0 <= l <= r < nums.length`
- `1 <= val <= 10^4`

## 解题思路

本题结合了区间更新和每轮最优选择。

核心思路：
1. 使用**差分数组**高效处理区间加法操作，O(1) 更新，O(n) 还原。
2. 每次查询后，需要找到当前数组的最大值，使用**线段树**维护区间最大值，支持区间加和全局最大查询，均为 O(log n)。
3. 每次查询后贪心选择当前最大元素加入得分。

## Python 代码实现

### 方法一：线段树（推荐）

```python
from typing import List

class SegTree:
    def __init__(self, n):
        self.n = n
        # 线段树节点存储最大值，lazy 存储延迟更新量
        self.tree = [0] * (4 * n)
        self.lazy = [0] * (4 * n)

    def build(self, arr, node, start, end):
        if start == end:
            self.tree[node] = arr[start]
        else:
            mid = (start + end) // 2
            self.build(arr, 2 * node, start, mid)
            self.build(arr, 2 * node + 1, mid + 1, end)
            self.tree[node] = max(self.tree[2 * node], self.tree[2 * node + 1])

    def push_down(self, node):
        if self.lazy[node] != 0:
            # 将延迟更新传递给子节点
            for child in [2 * node, 2 * node + 1]:
                self.tree[child] += self.lazy[node]
                self.lazy[child] += self.lazy[node]
            self.lazy[node] = 0

    def update(self, node, start, end, l, r, val):
        # 区间 [l, r] 加 val
        if r < start or end < l:
            return
        if l <= start and end <= r:
            self.tree[node] += val
            self.lazy[node] += val
            return
        self.push_down(node)
        mid = (start + end) // 2
        self.update(2 * node, start, mid, l, r, val)
        self.update(2 * node + 1, mid + 1, end, l, r, val)
        self.tree[node] = max(self.tree[2 * node], self.tree[2 * node + 1])

    def query_max(self):
        # 返回全局最大值（根节点）
        return self.tree[1]


class Solution:
    def maximumPoints(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        seg = SegTree(n)
        seg.build(nums, 1, 0, n - 1)

        total = 0
        for l, r, val in queries:
            # 区间 [l, r] 加 val
            seg.update(1, 0, n - 1, l, r, val)
            # 贪心：选当前最大值
            total += seg.query_max()

        return total
```

### 方法二：暴力模拟（适用于小数据）

```python
from typing import List

class Solution:
    def maximumPoints(self, nums: List[int], queries: List[List[int]]) -> int:
        arr = nums[:]
        total = 0

        for l, r, val in queries:
            # 暴力更新区间
            for i in range(l, r + 1):
                arr[i] += val
            # 选最大值
            total += max(arr)

        return total
```

## 复杂度分析

- 时间复杂度：
  - 方法一：O((n + q) log n)，线段树建树 O(n log n)，每次查询 O(log n)
  - 方法二：O(n * q)，暴力遍历，适合小数据量
- 空间复杂度：O(n)，线段树额外空间

## 关键点总结

1. 区间更新 + 全局最大查询是线段树的经典应用场景。
2. 懒惰传播（lazy propagation）是线段树高效处理区间更新的关键。
3. 每次查询后贪心选最大值，因为没有跨查询的约束。

## 易错点

1. 线段树节点下标从 1 开始，数组下标从 0 开始，注意对应关系。
2. `push_down` 操作在查询和更新前都要调用。
3. 建树时需要正确初始化叶节点。
