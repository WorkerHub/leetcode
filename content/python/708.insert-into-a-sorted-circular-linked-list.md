## 题目描述

给定一个循环链表的一个节点，这个循环链表是按升序排列的。请你向这个链表中插入一个新元素 `insertVal`，使得这个链表仍然是循环升序的。

给定的节点可以是链表中的任意一个单节点，并且不一定是链表中的最小元素。

如果有多个插入位置，你可以选择其中任意一个位置插入新的值，插入后整个链表仍然保持有序。

如果链表为空（给定的节点为 `null`），你需要创建一个循环有序链表并返回这个新节点。否则，请返回原先给定的节点。

**示例 1：**

```
输入：head = [3,4,1], insertVal = 2
输出：[3,4,1,2]
解释：在上图中，有一个包含三个元素的循环有序链表，你获得值为 3 的节点的指针，我们需要向表中插入元素 2。新插入的节点应该在 1 和 3 之间，插入之后，整个链表如上图所示，最后返回节点 3。
```

**示例 2：**

```
输入：head = [], insertVal = 1
输出：[1]
解释：链表为空，创建一个循环有序链表并返回这个新节点。
```

**示例 3：**

```
输入：head = [1], insertVal = 0
输出：[1,0]
```

**提示：**
- `0 <= Number of Nodes <= 5 * 10^4`
- `-10^6 <= Node.val <= 10^6`
- `-10^6 <= insertVal <= 10^6`

## 解题思路

这道题要在循环升序链表中插入新节点。关键是找到正确的插入位置。

**插入位置有三种情况：**

1. **常规情况**：`prev.val <= insertVal <= curr.val`
   - 新值在当前位置的前后节点之间

2. **边界情况**：`prev.val > curr.val`（链表的最大值和最小值交界处）
   - 如果 `insertVal >= prev.val`（新值是新的最大值或接近最大值）
   - 或者 `insertVal <= curr.val`（新值是新的最小值或接近最小值）
   - 都应该插入在此处

3. **特殊情况**：所有节点值相同
   - 可以插入在任意位置

**算法流程：**
1. 处理空链表：创建自循环节点
2. 处理单节点：插入并形成循环
3. 遍历链表找插入位置
4. 如果遍历一圈未找到，说明所有值相同，插入在起始位置

## Python 代码实现

### 方法一：遍历查找插入位置（推荐）⭐

```python
class Node:
    def __init__(self, val=None, next=None):
        self.val = val
        self.next = next

class Solution:
    def insert(self, head: 'Node', insertVal: int) -> 'Node':
        # 创建新节点
        new_node = Node(insertVal)
        
        # 情况1: 链表为空
        if not head:
            new_node.next = new_node  # 自循环
            return new_node
        
        # 情况2: 链表只有一个节点
        if head.next == head:
            head.next = new_node
            new_node.next = head
            return head
        
        # 情况3: 链表有多个节点，遍历查找插入位置
        prev = head
        curr = head.next
        
        while True:
            # 情况3.1: 找到合适的插入位置（常规情况）
            if prev.val <= insertVal <= curr.val:
                break
            
            # 情况3.2: 在最大值和最小值之间插入
            # prev.val > curr.val 说明 prev 是最大值，curr 是最小值
            if prev.val > curr.val:
                # insertVal 大于等于最大值，或小于等于最小值
                if insertVal >= prev.val or insertVal <= curr.val:
                    break
            
            # 继续遍历
            prev = curr
            curr = curr.next
            
            # 情况3.3: 遍历一圈回到起点，说明所有节点值相同
            if prev == head:
                break
        
        # 插入新节点
        prev.next = new_node
        new_node.next = curr
        
        return head
```

### 方法二：简化版（更清晰的逻辑）

```python
class Solution:
    def insert(self, head: 'Node', insertVal: int) -> 'Node':
        new_node = Node(insertVal)
        
        # 空链表
        if not head:
            new_node.next = new_node
            return new_node
        
        prev = head
        curr = head.next
        to_insert = False
        
        while True:
            # 检查是否应该在 prev 和 curr 之间插入
            if prev.val <= insertVal <= curr.val:
                to_insert = True
            elif prev.val > curr.val:
                # 到达循环链表的边界（最大值->最小值）
                if insertVal >= prev.val or insertVal <= curr.val:
                    to_insert = True
            
            # 插入节点
            if to_insert:
                prev.next = new_node
                new_node.next = curr
                return head
            
            # 移动指针
            prev = curr
            curr = curr.next
            
            # 遍历一圈回到起点，所有值相同
            if prev == head:
                break
        
        # 所有节点值相同，插入在任意位置
        prev.next = new_node
        new_node.next = curr
        return head
```

### 方法三：找最大值节点优化

```python
class Solution:
    def insert(self, head: 'Node', insertVal: int) -> 'Node':
        new_node = Node(insertVal)
        
        if not head:
            new_node.next = new_node
            return new_node
        
        # 找到最大值节点（或最大->最小的边界）
        curr = head
        while True:
            # 找到插入位置
            if curr.val <= insertVal <= curr.next.val:
                break
            
            # 找到边界位置（最大->最小）
            if curr.val > curr.next.val:
                # 新值是新的最大值或最小值
                if insertVal >= curr.val or insertVal <= curr.next.val:
                    break
            
            curr = curr.next
            
            # 回到起点，所有值相同
            if curr == head:
                break
        
        # 插入节点
        new_node.next = curr.next
        curr.next = new_node
        
        return head
```

## 复杂度分析

- **时间复杂度：** O(n)，最坏情况需要遍历整个链表
- **空间复杂度：** O(1)，只使用常数额外空间

## 关键点总结

1. **三种插入情况**：常规位置、边界位置、所有值相同
2. **循环链表的特点**：没有明确的头尾，需要通过值的大小关系判断边界
3. **边界识别**：`prev.val > curr.val` 表示到达最大->最小的边界
4. **遍历终止条件**：回到起始节点表示遍历一圈
5. **空链表处理**：创建自循环节点

## 易错点

1. **忘记处理空链表**：需要创建自循环节点
2. **死循环问题**：必须有终止条件（回到起点）
3. **边界判断错误**：要同时检查 `insertVal >= prev.val` 和 `insertVal <= curr.val`
4. **单节点链表**：需要特殊处理，确保形成正确的循环
5. **所有值相同的情况**：遍历一圈未找到插入位置时，应插入在任意位置
