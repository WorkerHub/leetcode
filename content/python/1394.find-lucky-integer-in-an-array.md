## 题目描述

在整数数组中，如果一个整数的出现频次和它的数值大小相等，我们就称这个整数为「幸运数」。

给你一个整数数组 `arr`，请你从中找出并返回一个幸运数。

- 如果数组中存在多个幸运数，只需返回**最大**的那个。
- 如果数组中不含幸运数，则返回 **-1**。

**示例 1：**

```
输入：arr = [2,2,3,4]
输出：2
解释：数组中唯一的幸运数是 2，因为数值 2 的出现频次也是 2。
```

**示例 2：**

```
输入：arr = [1,2,2,3,3,3]
输出：3
解释：1、2、3 均为幸运数，最大的是 3。
```

**示例 3：**

```
输入：arr = [2,2,2,3,3]
输出：-1
解释：不存在幸运数。2 的频次是 3，3 的频次是 2，都不相等。
```

**提示：**

- `1 <= arr.length <= 500`
- `1 <= arr[i] <= 500`

## 解题思路

**方法一（哈希表）：** 统计每个数字的出现频率，然后找出所有满足"值 == 频率"的数字，返回最大值。

**方法二（排序）：** 排序后，相同的数字连续排列，可以用双指针统计频率，或配合 `groupby`。

Python 的 `collections.Counter` 可以一行统计所有元素的频率，非常方便。

## Python 代码实现

### 方法一：Counter 哈希表（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def findLucky(self, arr: List[int]) -> int:
        # 统计每个数字的出现频率
        count = Counter(arr)
        result = -1
        # 找出所有满足 值 == 频率 的数字，取最大值
        for num, freq in count.items():
            if num == freq:
                result = max(result, num)
        return result
```

### 方法二：一行写法（Python 精简版）

```python
from typing import List
from collections import Counter

class Solution:
    def findLucky(self, arr: List[int]) -> int:
        count = Counter(arr)
        # 过滤出所有幸运数，若列表为空则返回 -1
        lucky_nums = [num for num, freq in count.items() if num == freq]
        return max(lucky_nums) if lucky_nums else -1
```

### 方法三：排序 + 统计

```python
from typing import List

class Solution:
    def findLucky(self, arr: List[int]) -> int:
        arr.sort()  # 排序后相同元素连续
        result = -1
        i = 0
        while i < len(arr):
            num = arr[i]
            # 找到 num 出现的次数（连续段的长度）
            j = i
            while j < len(arr) and arr[j] == num:
                j += 1
            freq = j - i  # num 出现了 freq 次
            if num == freq:
                result = max(result, num)
            i = j  # 跳到下一个不同的数
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（Counter） | O(n) | O(n) |
| 方法二（一行写法） | O(n) | O(n) |
| 方法三（排序） | O(n log n) | O(1) |

## 关键点总结

1. `Counter(arr)` 一步统计所有元素频率，是解决频率问题的最便捷工具
2. "幸运数"的判断条件：`num == freq`，即数值等于出现次数
3. 遍历所有幸运数取最大值，用 `max()` 或手动维护 `result` 变量
4. 若没有幸运数，返回 -1

## 易错点

- 初始化 `result = -1`（题目要求无幸运数时返回 -1），不要初始化为 0 或空
- 注意 `max(lucky_nums) if lucky_nums else -1` 的判断，若直接写 `max([])` 会报错
- 方法三中统计频率时，要用"段长度"而非其他方式，注意 `j - i` 才是频率
