## 题目描述

给你一个整数数组 `nums`，返回出现 **最频繁** 的偶数元素。

如果存在多个满足条件的元素，只需要返回 **最小** 的一个。如果不存在偶数元素，返回 `-1`。

**示例 1：**
```
输入：nums = [0,1,2,2,4,4,1]
输出：2
解释：偶数元素有 0、2 和 4，出现次数分别为 1、2 和 2。最频繁的偶数元素是 2 和 4，返回较小的 2。
```

**示例 2：**
```
输入：nums = [4,4,4,9,2,4]
输出：4
解释：偶数元素只有 2 和 4，4 出现 4 次，2 出现 1 次，返回 4。
```

**示例 3：**
```
输入：nums = [29,47,21,41,13,37,25,7]
输出：-1
解释：不存在偶数元素，返回 -1。
```

**提示：**
- `1 <= nums.length <= 2000`
- `0 <= nums[i] <= 10^5`

## 解题思路

使用哈希表统计每个偶数的出现次数，然后找出频率最高且值最小的偶数。

**步骤：**
1. 遍历数组，统计偶数的频率
2. 遍历哈希表，找出频率最大的偶数（相同频率取较小值）
3. 若无偶数返回 -1

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def mostFrequentEven(self, nums: List[int]) -> int:
        # 统计所有偶数的频率
        count = Counter(x for x in nums if x % 2 == 0)

        if not count:
            return -1  # 没有偶数

        # 找频率最高且值最小的偶数
        # 按 (-频率, 值) 排序，取第一个
        return min(count, key=lambda x: (-count[x], x))
```

### 方法二：哈希表 + 遍历

```python
from typing import List

class Solution:
    def mostFrequentEven(self, nums: List[int]) -> int:
        freq = {}
        # 统计偶数频率
        for x in nums:
            if x % 2 == 0:
                freq[x] = freq.get(x, 0) + 1

        if not freq:
            return -1

        ans = -1
        max_freq = 0

        # 找频率最大且值最小的偶数
        for val, cnt in freq.items():
            if cnt > max_freq or (cnt == max_freq and val < ans):
                max_freq = cnt
                ans = val

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表计数 | O(n) | O(n) |
| 哈希表遍历 | O(n) | O(n) |

## 关键点总结

1. 只统计偶数的频率，奇数直接忽略
2. 相同频率时返回较小值，利用排序键 `(-频率, 值)` 实现
3. 若没有偶数，返回 -1

## 易错点

- 注意 0 也是偶数，不要遗漏
- 相同频率时取较小值，而不是较大值
