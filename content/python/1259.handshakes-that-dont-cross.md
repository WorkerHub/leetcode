## 题目描述

有 numPeople 个人站成一圈，每个人恰好和另一个人握手，所以总共有 numPeople / 2 次握手。

返回所有握手方式中，没有任何两次握手交叉的方案数。由于答案可能非常大，请返回答案模 10^9 + 7 的结果。

**示例 1:**

```
输入: numPeople = 4
输出: 2
解释: 有两种方式：
方式 1: [(1,2),(3,4)]
方式 2: [(2,3),(4,1)]
```

**示例 2:**

```
输入: numPeople = 6
输出: 5
```

**示例 3:**

```
输入: numPeople = 8
输出: 14
```

**提示:**

- 2 <= numPeople <= 1000
- numPeople 是偶数

## 解题思路

这道题是经典的卡特兰数（Catalan Number）问题的变体。

**核心思想：**

想象 numPeople 个人围成一个圆圈，编号为 0 到 numPeople-1。我们选择编号为 0 的人，他必须和某个人握手，假设和编号为 k 的人握手（k 必须是奇数，因为要保证两边的人数都是偶数）。

这样一来，圆圈被分成两部分：
- 0 到 k 之间有 k 个人
- k 到 0（绕一圈）之间有 numPeople - k - 1 个人

为了不交叉，这两部分内部的握手必须独立进行。

**动态规划递推公式：**

设 dp[n] 表示 n 个人不交叉握手的方案数，则：

```
dp[n] = sum(dp[i] * dp[n-i-2]) for i in range(0, n, 2)
```

其中 i 是第一个人（编号0）左边的人数（包括他握手的对象）。

**卡特兰数性质：**

dp[n] 实际上是第 n/2 个卡特兰数。卡特兰数的通项公式为：

```
C(n) = C(2n, n) / (n + 1)
```

或者递推公式：

```
C(0) = 1
C(n) = sum(C(i) * C(n-1-i)) for i in range(n)
```

## Python 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 10**9 + 7
        n = numPeople
        
        # dp[i] 表示 i 个人不交叉握手的方案数
        dp = [0] * (n + 1)
        dp[0] = 1  # 0 个人，1 种方案（什么都不做）
        
        # 只有偶数个人才能完成握手
        for i in range(2, n + 1, 2):
            # 假设编号为 0 的人和编号为 k 的人握手
            # k 必须是奇数（1, 3, 5, ...），这样两边的人数才是偶数
            for k in range(1, i, 2):
                # 左边有 k-1 个人，右边有 i-k-1 个人
                left = k - 1
                right = i - k - 1
                dp[i] = (dp[i] + dp[left] * dp[right]) % MOD
        
        return dp[n]
```

### 方法二：卡特兰数递推

```python
class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 10**9 + 7
        n = numPeople // 2  # 转换为卡特兰数的 n
        
        # catalan[i] 表示第 i 个卡特兰数
        catalan = [0] * (n + 1)
        catalan[0] = 1
        
        for i in range(1, n + 1):
            for j in range(i):
                catalan[i] = (catalan[i] + catalan[j] * catalan[i - 1 - j]) % MOD
        
        return catalan[n]
```

### 方法三：卡特兰数公式法（组合数学）

```python
class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 10**9 + 7
        n = numPeople // 2
        
        # 计算组合数 C(2n, n)
        def mod_inverse(a: int, mod: int) -> int:
            """计算 a 在模 mod 下的逆元（使用费马小定理）"""
            return pow(a, mod - 2, mod)
        
        # 计算 C(2n, n)
        numerator = 1
        denominator = 1
        
        for i in range(1, n + 1):
            numerator = (numerator * (n + i)) % MOD
            denominator = (denominator * i) % MOD
        
        # C(2n, n) / (n + 1)
        result = (numerator * mod_inverse(denominator, MOD)) % MOD
        result = (result * mod_inverse(n + 1, MOD)) % MOD
        
        return result
```

### 方法四：记忆化递归

```python
from functools import lru_cache

class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 10**9 + 7
        
        @lru_cache(maxsize=None)
        def dp(n: int) -> int:
            """计算 n 个人不交叉握手的方案数"""
            if n == 0:
                return 1
            if n % 2 == 1:
                return 0  # 奇数人无法完成握手
            
            result = 0
            # 编号 0 的人和编号 k 的人握手
            for k in range(1, n, 2):
                left = k - 1
                right = n - k - 1
                result = (result + dp(left) * dp(right)) % MOD
            
            return result
        
        return dp(numPeople)
```

## 复杂度分析

**方法一：动态规划**

- 时间复杂度：O(n^2)
  - 外层循环 O(n)
  - 内层循环 O(n)
- 空间复杂度：O(n)，dp 数组

**方法二：卡特兰数递推**

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

**方法三：卡特兰数公式法**

- 时间复杂度：O(n log MOD)
  - 计算组合数需要 O(n)
  - 求逆元使用快速幂需要 O(log MOD)
- 空间复杂度：O(1)

**方法四：记忆化递归**

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)，递归栈和缓存

```
编号 0 和编号 1 握手：左边 0 人，右边 4 人
  dp[0] * dp[4] = 1 * 2 = 2

编号 0 和编号 3 握手：左边 2 人，右边 2 人
  dp[2] * dp[2] = 1 * 1 = 1

编号 0 和编号 5 握手：左边 4 人，右边 0 人
  dp[4] * dp[0] = 2 * 1 = 2

总计：2 + 1 + 2 = 5
```

## 关键点总结

1. 这是卡特兰数的经典应用，dp[n] = 第 n/2 个卡特兰数
2. 问题的关键是理解为什么要分成两部分：选定一个人握手后，圆圈被分割
3. 递推公式：`dp[n] = sum(dp[i] * dp[n-i-2])`
4. 注意模运算，每一步都要取模
5. 卡特兰数的其他应用：
   - 括号匹配
   - 二叉树数量
   - 出栈序列
   - 多边形三角剖分

## 易错点

1. 忘记取模
   - 每次乘法和加法后都要取模
2. 循环边界错误
   - k 必须是奇数（1, 3, 5, ...）
   - 循环应该是 `range(1, i, 2)`
3. 初始值设置错误
   - dp[0] = 1（0 个人有 1 种方案）
   - dp[2] = 1（2 个人有 1 种方案）
4. 没有处理奇数情况
   - 奇数个人无法完成握手，应返回 0
5. 组合数计算时的溢出
   - 要在计算过程中取模，不能等到最后
