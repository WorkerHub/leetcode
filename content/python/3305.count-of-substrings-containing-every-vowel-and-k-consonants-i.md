## 题目描述

给你一个字符串 `word` 和一个非负整数 `k`。

返回 `word` 的子字符串中，包含全部 5 个元音字母（`a`、`e`、`i`、`o`、`u`）**且恰好有 `k` 个辅音字母**的子字符串数目。

元音字母：`a, e, i, o, u`；其余小写字母为辅音字母。

**示例 1：**
```
输入：word = "aeioqq", k = 1
输出：2
解释：包含全部元音且恰好1个辅音的子串为："aeiou" 和 "aeioq"（等等，需具体验证）
```

**示例 2：**
```
输入：word = "aeiou", k = 0
输出：1
```

**提示：**
- `5 <= word.length <= 250`
- `word` 只含小写英文字母
- `0 <= k <= word.length - 5`

## 解题思路

**滑动窗口（at_least 转化）：**

计算"至少 k 个辅音且包含所有元音"的子串数，减去"至少 k+1 个辅音且包含所有元音"的子串数，得到恰好 k 个辅音的子串数。

**辅助函数 `at_least(k)`**：
- 使用滑动窗口，维护一个包含所有 5 个元音、且辅音数目 >= k 的窗口。
- 对于每个右端点 `r`，找最小的左端点 `l` 使窗口满足条件，则右端点固定时，`[0..l]` 都是合法左端点，贡献 `l + 1` 个子串。

**答案 = `at_least(k) - at_least(k+1)`**

## Python 代码实现

### 方法一：滑动窗口 + at_least 转化（推荐）

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        vowels = set('aeiou')
        
        def at_least(min_k: int) -> int:
            """统计包含所有元音且辅音数 >= min_k 的子串数"""
            count = 0
            vowel_cnt = {}  # 各元音的出现次数
            consonant_cnt = 0  # 辅音数量
            l = 0
            
            for r in range(len(word)):
                # 右指针扩展
                c = word[r]
                if c in vowels:
                    vowel_cnt[c] = vowel_cnt.get(c, 0) + 1
                else:
                    consonant_cnt += 1
                
                # 收缩左指针直到窗口不再满足条件
                while len(vowel_cnt) == 5 and consonant_cnt >= min_k:
                    count += len(word) - r  # 右端点往右延伸都合法
                    lc = word[l]
                    if lc in vowels:
                        vowel_cnt[lc] -= 1
                        if vowel_cnt[lc] == 0:
                            del vowel_cnt[lc]
                    else:
                        consonant_cnt -= 1
                    l += 1
            
            return count
        
        return at_least(k) - at_least(k + 1)
```

### 方法二：暴力枚举（适合小数据）

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        vowels = set('aeiou')
        n = len(word)
        count = 0
        
        for i in range(n):
            vowel_set = set()
            consonant = 0
            for j in range(i, n):
                c = word[j]
                if c in vowels:
                    vowel_set.add(c)
                else:
                    consonant += 1
                # 检查是否满足条件
                if len(vowel_set) == 5 and consonant == k:
                    count += 1
                elif consonant > k:
                    break  # 辅音超出，后续不可能满足
        
        return count
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，两次滑动窗口各 O(n)
- 空间复杂度：O(1)，哈希表最多 5 个键

**方法二：**
- 时间复杂度：O(n^2)，双重循环
- 空间复杂度：O(1)

## 关键点总结

1. `恰好k个` = `至少k个` - `至少k+1个`，这个转化是滑动窗口处理"恰好"问题的标准技巧。
2. 固定右端点时，满足条件的左端点形成一段连续区间，可以直接计数。
3. 由于 `word.length <= 250`，暴力 O(n^2) 也可通过。

## 易错点

1. 元音哈希表需要删除计数为 0 的键，以正确判断是否 5 种元音都存在。
2. `at_least` 函数的收缩逻辑：只在窗口完全满足条件时才计数并收缩。
3. 收缩时加的是 `len(word) - r`（右端点可以继续往右延伸）。
