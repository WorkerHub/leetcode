## 题目描述

我们定义，在以下情况时，单词的大写用法是正确的：

- 全部字母都是大写，比如 `"USA"`
- 单词中所有字母都不是大写，比如 `"leetcode"`
- 如果单词不只含有一个字母，只有首字母大写， 比如 `"Google"`

给你一个字符串 `word`。如果大写用法正确，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：word = "USA"
输出：true
```

**示例 2：**
```
输入：word = "FlaG"
输出：false
```

**提示：**
- `1 <= word.length <= 100`
- `word` 由小写和大写英文字母组成

## 解题思路

判断三种合法情况：
1. 全大写
2. 全小写
3. 首字母大写，其余小写

## Python 代码实现

### 方法一：使用内置函数（推荐）⭐

```python
class Solution:
    def detectCapitalUse(self, word: str) -> bool:
        """
        利用 Python 字符串方法
        时间复杂度：O(n)，空间复杂度：O(1)
        """
        return word.isupper() or word.islower() or word.istitle()
```

### 方法二：逐一判断

```python
class Solution:
    def detectCapitalUse(self, word: str) -> bool:
        """
        手动判断三种情况
        时间复杂度：O(n)，空间复杂度：O(1)
        """
        # 情况1：全大写
        if word == word.upper():
            return True
        # 情况2：全小写
        if word == word.lower():
            return True
        # 情况3：首字母大写
        if word[0].isupper() and word[1:] == word[1:].lower():
            return True
        
        return False
```

### 方法三：计数大写字母

```python
class Solution:
    def detectCapitalUse(self, word: str) -> bool:
        """
        统计大写字母数量
        时间复杂度：O(n)，空间复杂度：O(1)
        """
        upper_count = sum(1 for c in word if c.isupper())
        
        # 全大写 或 全小写 或 只有首字母大写
        return upper_count == len(word) or \
               upper_count == 0 or \
               (upper_count == 1 and word[0].isupper())
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **Python 字符串方法**：
   - `isupper()`：全大写
   - `islower()`：全小写
   - `istitle()`：首字母大写

2. **三种合法情况**：全大写 / 全小写 / 首字母大写

## 易错点

1. **单字母**：单个大写字母是合法的
2. **istitle()**：要求每个单词首字母大写（如果有空格）
3. **空字符串**：题目保证长度 >= 1
