## 题目描述

给你两个整数 `n` 和 `k`。

构造一个由 `n` 个**不同**正整数组成的数组，使得数组中任意两个元素之和都不等于 `k`。

返回这样的数组中**最小可能的数组元素之和**。

**示例 1：**
```
输入：n = 5, k = 4
输出：18
解释：数组 [1,2,4,5,6] 满足条件，和 = 18
注意 [1,2] 和为 3 ≠ 4，[1,3] 和为 4（不能同时选），选 [1,2,4,5,6] 避开 (1,3) 对
```

**示例 2：**
```
输入：n = 2, k = 6
输出：3
解释：数组 [1,2] 满足条件，和 = 3
```

**提示：**
- `1 <= n, k <= 50`

## 解题思路

**贪心：** 尽量选最小的正整数，但要避免选出两个数之和为 k 的情况。

**分析：** 若选了 x，则不能选 k-x（当 k-x > 0 且 k-x != x 时）。

**策略：** 从 1 开始依次尝试加入，若某数与已选数配对等于 k，则跳过。

**更简洁的分析：**
- 对于 `i < k/2`，`i` 和 `k-i` 不能同时选
- 所以先选 `1, 2, ..., min(k//2 - 1, n)` 个（这些数互不配对，且都 < k/2）
  - 实际上：先选 1 到 `k//2 - 1`（如果 n 够的话），其中没有两个和等于 k
  - 但还需要验证：1 和 2 的和 = 3，只要 3 ≠ k 就可以
- 如果还需要更多数，从 `k//2 + 1` 开始选（跳过 k//2 和 k - k//2 可能的配对）

实际上更简单：
- 从 1 开始贪心选，维护一个 "已选集合"
- 对每个候选数 i，若 k-i 已在集合中，跳过；否则加入

## Python 代码实现

### 方法一：贪心选最小值（推荐）

```python
class Solution:
    def minimumSum(self, n: int, k: int) -> int:
        chosen = set()
        total = 0
        num = 1

        while len(chosen) < n:
            # 若 k - num 已在集合中，跳过 num
            if k - num not in chosen:
                chosen.add(num)
                total += num
            num += 1

        return total
```

### 方法二：数学推导（O(1)）

```python
class Solution:
    def minimumSum(self, n: int, k: int) -> int:
        # 可以选 1, 2, ..., k//2（共 k//2 个）而不产生配对
        # 若 n <= k//2，直接选 1..n，和 = n*(n+1)/2
        # 否则，先选 1..k//2，再从 k 开始选 k, k+1, ..., k+(n-k//2-1)
        half = k // 2
        if n <= half:
            return n * (n + 1) // 2
        else:
            # 先选 1..half，剩下 n-half 个从 k 开始选
            remaining = n - half
            # 前 half 个的和
            sum1 = half * (half + 1) // 2
            # 从 k 开始选 remaining 个：k, k+1, ..., k+remaining-1
            sum2 = remaining * k + remaining * (remaining - 1) // 2
            return sum1 + sum2
```

## 复杂度分析

- 方法一：时间 O(n + k)，空间 O(n)
- 方法二：时间 O(1)，空间 O(1)

## 关键点总结

1. 贪心：从最小正整数开始选，跳过会产生配对的数
2. 关键约束：若 i 和 k-i 不能同时选
3. 数学解法：1~k//2 中的数互不配对（相邻两数之和 < k），超出后从 k 开始选

## 易错点

1. 当 `k - num == num`（即 `num = k/2`，k 为偶数）时，`k//2 * 2 = k`，两个相同数不能选（但数组元素各不相同），所以 k 为偶数时 k//2 也不能选
2. 方法二的分界：half = k//2，可选范围是 [1, half]，不包含 half+1...k-1
