## 题目描述

给你两个长度为 `n` 的整数数组 `cost` 和 `time`，分别表示第 `i` 个画家粉刷 **1 面** 墙所需费用和时间。

你雇佣其中一个画家粉刷一面墙时，其他所有画家可以 **免费** 粉刷墙（免费画家同时工作，每个免费画家每单位时间粉刷 1 面墙）。

返回粉刷 `n` 面墙的 **最低费用**。

**示例 1：**
```
输入：cost = [1,2,3,2], time = [1,2,3,2]
输出：3
解释：雇佣画家 3（费用2，时间2），同时免费画家粉刷 2 面；雇佣画家 2（费用1，时间1），再免费 1 面。总费用 3
```

**提示：**
- `1 <= n <= 500`
- `cost.length == time.length == n`

## 解题思路

**DP**：雇佣第 `i` 个画家（费用 `cost[i]`，时间 `time[i]`）时，同时可免费粉刷 `time[i]` 面墙。

设 `dp[j]` = 还需要粉刷 `j` 面墙的最小费用。

当雇佣画家 `i` 时：选择它就能覆盖 `time[i] + 1` 面墙（本人1面 + 免费 time[i] 面），支付 `cost[i]`。

这本质是 **0-1 背包**：每个画家是一个物品，重量 = `time[i] + 1`，价值 = `cost[i]`，背包容量 = `n`，求装满容量 `n` 的最小价值。

## Python 代码实现

### 方法一：0-1 背包（推荐）

```python
from typing import List

class Solution:
    def paintWalls(self, cost: List[int], time: List[int]) -> int:
        n = len(cost)
        # dp[j] 表示还剩 j 面墙要刷的最小费用，初始 dp[0]=0，其余无穷大
        INF = float('inf')
        dp = [0] + [INF] * n  # dp[0..n]

        for i in range(n):
            # 倒序枚举（0-1 背包），雇佣画家 i 覆盖 time[i]+1 面墙
            for j in range(n, 0, -1):
                # 覆盖 min(j, time[i]+1) 面墙，剩余 max(j - time[i] - 1, 0)
                prev = max(j - time[i] - 1, 0)
                if dp[prev] < INF:
                    dp[j] = min(dp[j], dp[prev] + cost[i])

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 雇佣画家 i 可覆盖 `time[i] + 1` 面墙（+1 是画家本身）
2. 转化为 0-1 背包问题
3. 倒序枚举避免重复使用同一画家

## 易错点

1. 覆盖墙数是 `time[i] + 1`，不要忘记 +1
2. `max(j - time[i] - 1, 0)` 防止下标越界
