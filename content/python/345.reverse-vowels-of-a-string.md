## 题目描述

给你一个字符串 `s`，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，且可能以大小写两种形式出现不止一次。

**示例 1：**
```
输入：s = "hello"
输出："holle"
```

**示例 2：**
```
输入：s = "leetcode"
输出："leotcede"
```

**提示：**
- `1 <= s.length <= 3 * 10^5`
- `s` 由可打印的 ASCII 字符组成

## 解题思路

这道题是第 344 题（反转字符串）的变形，区别在于只反转元音字母。

**核心思想：**
使用双指针，从两端向中间移动，只有当两个指针都指向元音字母时才进行交换。

**算法流程：**
1. 定义元音字母集合（包含大小写）
2. 左指针从左往右找元音，右指针从右往左找元音
3. 当两个指针都找到元音时，交换它们
4. 继续移动指针，直到两指针相遇

**时间复杂度：** O(n)
**空间复杂度：** O(n)，因为 Python 字符串不可变，需要转换为列表

## Python 代码实现

### 方法一：双指针（标准解法）⭐

```python
class Solution:
    def reverseVowels(self, s: str) -> str:
        # 定义元音字母集合（包含大小写）
        vowels = set('aeiouAEIOU')
        
        # 将字符串转为列表（Python 字符串不可变）
        chars = list(s)
        
        # 双指针
        left, right = 0, len(chars) - 1
        
        while left < right:
            # 左指针向右移动，直到找到元音
            while left < right and chars[left] not in vowels:
                left += 1
            
            # 右指针向左移动，直到找到元音
            while left < right and chars[right] not in vowels:
                right -= 1
            
            # 交换两个元音字母
            chars[left], chars[right] = chars[right], chars[left]
            
            # 移动指针
            left += 1
            right -= 1
        
        # 转回字符串
        return ''.join(chars)
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

### 方法二：简化版（合并判断）

```python
class Solution:
    def reverseVowels(self, s: str) -> str:
        vowels = set('aeiouAEIOU')
        chars = list(s)
        left, right = 0, len(chars) - 1
        
        while left < right:
            # 如果左边不是元音，左指针右移
            if chars[left] not in vowels:
                left += 1
            # 如果右边不是元音，右指针左移
            elif chars[right] not in vowels:
                right -= 1
            # 两边都是元音，交换并移动
            else:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1
        
        return ''.join(chars)
```

### 方法四：栈实现

```python
class Solution:
    def reverseVowels(self, s: str) -> str:
        vowels = set('aeiouAEIOU')
        chars = list(s)
        
        # 收集所有元音字母及其位置
        vowel_chars = []
        vowel_positions = []
        
        for i, char in enumerate(chars):
            if char in vowels:
                vowel_chars.append(char)
                vowel_positions.append(i)
        
        # 反转元音字母
        vowel_chars.reverse()
        
        # 放回原位置
        for i, pos in enumerate(vowel_positions):
            chars[pos] = vowel_chars[i]
        
        return ''.join(chars)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |

## 关键点总结

1. **元音集合**：使用 set 存储元音字母，O(1) 查找
2. **大小写**：要同时考虑大小写元音
3. **双指针**：两个指针都找到元音才交换
4. **字符串不可变**：Python 需要先转为 list
5. **边界条件**：left < right 防止越界

## 易错点

1. **忘记大小写**
   ```python
   # 错误：只包含小写
   vowels = set('aeiou')
   
   # 正确：包含大小写
   vowels = set('aeiouAEIOU')
   ```

2. **没有检查 left < right**
   ```python
   # 错误：可能导致指针越界
   while left < right and chars[left] not in vowels:
       left += 1
   # 此时 left 可能 >= right
   
   # 正确：每次都检查
   while left < right and chars[left] not in vowels:
       left += 1
   while left < right and chars[right] not in vowels:
       right -= 1
   ```

3. **字符串直接修改**
   ```python
   # 错误：字符串不可变
   s[0] = 'a'  # TypeError
   
   # 正确：转为列表
   chars = list(s)
   chars[0] = 'a'
   s = ''.join(chars)
   ```

4. **集合查询效率**
   ```python
   # 不推荐：列表查询 O(n)
   vowels = ['a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U']
   if char in vowels:  # O(n) 查询
   
   # 推荐：集合查询 O(1)
   vowels = set('aeiouAEIOU')
   if char in vowels:  # O(1) 查询
   ```

5. **交换后忘记移动指针**
   ```python
   # 错误：可能导致死循环
   if chars[left] in vowels and chars[right] in vowels:
       chars[left], chars[right] = chars[right], chars[left]
       # 忘记移动指针
   
   # 正确：
   else:
       chars[left], chars[right] = chars[right], chars[left]
       left += 1
       right -= 1
   ```
