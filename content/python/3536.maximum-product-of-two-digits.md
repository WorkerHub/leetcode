## 题目描述

给定一个整数 `n`，将其各位数字提取出来，找出其中最大的两个数字，返回它们的乘积。

**示例 1：**

```
输入：n = 31
输出：3
解释：数字有 3 和 1，乘积为 3*1 = 3。
```

**示例 2：**

```
输入：n = 22
输出：4
解释：数字有 2 和 2，乘积为 2*2 = 4。
```

**示例 3：**

```
输入：n = 124
输出：8
解释：数字有 1, 2, 4，最大两个为 2 和 4，乘积为 8。
```

**提示：**
- `10 <= n <= 10^9`（保证至少有两位数字）

## 解题思路

提取 `n` 的所有数字，排序后取最大的两个相乘。

## Python 代码实现

### 方法一：提取数字后排序（推荐）

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        # 提取所有数字
        digits = [int(d) for d in str(n)]
        # 排序取最大两个
        digits.sort(reverse=True)
        return digits[0] * digits[1]
```

### 方法二：维护最大和次大值

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        first = second = 0  # 最大和次大数字
        while n > 0:
            d = n % 10
            n //= 10
            if d >= first:
                second = first
                first = d
            elif d > second:
                second = d
        return first * second
```

## 复杂度分析

- 时间复杂度：O(log n)，提取数字位数
- 空间复杂度：O(log n)（方法一），O(1)（方法二）

## 关键点总结

1. 将整数转为字符串后提取各位数字
2. 只需找最大的两个数字即可
3. 方法二用两个变量维护最大和次大，空间更优

## 易错点

1. 注意数字可能有多个相同的最大值（如 `n = 99`，答案为 81）
2. 方法二中更新次大值的条件是 `d >= first` 时先更新次大
3. 题目保证 `n >= 10`，至少有两位数字
