## 题目描述

给你一个下标从 **0** 开始的二维整数数组 `brackets`，其中 `brackets[i] = [upper_i, percent_i]`，表示第 `i` 个税级的上限是 `upper_i`，征税百分比是 `percent_i`。税级按上限从低到高排序（在满足 `0 < i < brackets.length` 的条件下，`upper_{i-1} < upper_i`）。

税款计算方式如下：
- 不超过 `upper_0` 的收入按税率 `percent_0` 征税。
- 在 `upper_{i-1}` 到 `upper_i` 之间的收入按税率 `percent_i` 征税。

给你一个整数 `income` 表示你的总收入，返回你需要缴纳的税款总额。答案与真实值误差不超过 `10^-5` 时视为正确。

**示例 1：**
```
输入：brackets = [[3,50],[7,10],[12,25]], income = 10
输出：2.65
解释：
- [0,3]：3 * 50% = 1.50
- (3,7]：4 * 10% = 0.40
- (7,10]：3 * 25% = 0.75
总税款 = 1.50 + 0.40 + 0.75 = 2.65
```

**示例 2：**
```
输入：brackets = [[1,0],[4,25],[5,50]], income = 2
输出：0.25
```

**提示：**
- `1 <= brackets.length <= 100`
- `1 <= upper_i <= 1000`
- `0 <= percent_i <= 100`
- `0 <= income <= 1000`

## 解题思路

直接模拟税级计算过程：
- 依次遍历每个税级区间。
- 计算当前税级内需缴税的金额（取当前收入与税级上限的较小值与前一税级上限的差）。
- 乘以对应税率累加即可。

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def calculateTax(self, brackets: List[List[int]], income: int) -> float:
        tax = 0.0
        prev_upper = 0  # 上一个税级的上限

        for upper, percent in brackets:
            # 当前税级内的应税收入
            taxable = min(income, upper) - prev_upper
            if taxable <= 0:
                break  # 收入已低于当前税级下限，不再计算
            tax += taxable * percent / 100
            prev_upper = upper
        
        return tax
```

### 方法二：逐区间累加（更易理解）

```python
from typing import List

class Solution:
    def calculateTax(self, brackets: List[List[int]], income: int) -> float:
        tax = 0.0
        prev = 0  # 上一税级的上限

        for upper, rate in brackets:
            if income <= prev:
                break
            # 在当前区间 (prev, upper] 中的应税收入
            amount = min(income, upper) - prev
            tax += amount * rate / 100.0
            prev = upper
        
        return tax
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(n) | O(1) |

其中 n 为税级数量。

## 关键点总结

1. 每个税级的应税金额为 `min(income, upper) - prev_upper`。
2. 若收入已低于当前区间下限，可提前退出循环。
3. 税率是百分比，需除以 100 换算为小数。

## 易错点

- 忘记将税率除以 100。
- 区间下限是上一税级的上限，而非 0。
