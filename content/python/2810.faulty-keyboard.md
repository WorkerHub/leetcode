## 题目描述

你的键盘坏了，每当你输入字符 `'i'` 时，会把当前屏幕上的内容**翻转**（反转字符串）。其他字符正常显示在屏幕末尾。

给你一个字符串 `s`，返回最终屏幕上显示的内容。

**示例 1：**
```
输入：s = "string"
输出："rtsng"
解释：
输入 's' -> "s"
输入 't' -> "st"
输入 'r' -> "str"
输入 'i' -> 翻转 -> "rts"
输入 'n' -> "rtsn"
输入 'g' -> "rtsnig"... 等等

更正：
输入 'i' 后翻转 "str" -> "rts"
输入 'n' -> "rtsn"
输入 'g' -> "rtsnig"
不对，再看：题目中 'i' 翻转整个当前内容
```

**示例 2：**
```
输入：s = "poiinter"
输出："ponter"
解释：
p -> "p"
o -> "po"
i -> 翻转 -> "op"
i -> 翻转 -> "po"
n -> "pon"
t -> "pont"
e -> "ponte"
r -> "ponter"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

直接模拟：
- 维护一个当前字符串 `result`
- 遍历 `s` 的每个字符：
  - 如果是 `'i'`，翻转 `result`
  - 否则，追加到 `result` 末尾
- 返回最终的 `result`

由于字符串长度最多 100，直接模拟即可。

**优化思路（可选）：** 用一个标志位 `reversed_flag` 记录当前是否处于翻转状态，避免实际翻转操作。如果处于翻转状态，插入字符时插到头部而不是尾部。但由于数据量小，没有必要优化。

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
class Solution:
    def finalString(self, s: str) -> str:
        result = []
        for ch in s:
            if ch == 'i':
                result.reverse()  # 翻转当前内容
            else:
                result.append(ch)  # 追加字符
        return ''.join(result)
```

### 方法二：使用 deque 优化（了解即可）

```python
from collections import deque

class Solution:
    def finalString(self, s: str) -> str:
        # 用 deque 模拟，通过翻转方向标志位避免实际翻转
        dq = deque()
        is_reversed = False  # 当前是否处于翻转状态

        for ch in s:
            if ch == 'i':
                is_reversed = not is_reversed  # 切换翻转状态
            else:
                if is_reversed:
                    dq.appendleft(ch)  # 翻转状态下，加到头部
                else:
                    dq.append(ch)  # 正常状态下，加到尾部

        result = ''.join(dq)
        if is_reversed:
            return result[::-1]  # 最终如果是翻转状态，需要翻转输出
        return result
```

### 方法三：Python 字符串操作（最简洁）

```python
class Solution:
    def finalString(self, s: str) -> str:
        result = ""
        for ch in s:
            if ch == 'i':
                result = result[::-1]  # 字符串翻转
            else:
                result += ch
        return result
```

## 复杂度分析

- 时间复杂度：O(n^2)，每次翻转需要 O(n) 时间，共可能翻转 O(n) 次（方法一/三）；方法二为 O(n)
- 空间复杂度：O(n)，存储结果

## 关键点总结

1. `'i'` 翻转整个当前字符串，其他字符追加到末尾
2. 使用列表模拟字符串可以提高效率（列表 `reverse()` 是原地操作，O(n)）
3. 方法二用 deque + 方向标志位可以将每次翻转优化为 O(1)

## 易错点

1. 只有字符 `'i'` 触发翻转，不是 `'I'`（大写），要注意大小写
2. 翻转的是当前整个屏幕内容，不只是最后几个字符
3. 方法三中字符串 `+=` 在 Python 中每次创建新对象，效率低于列表
