## 题目描述

给定一棵有 `n` 个节点的加权树，节点权重为 `weight[i]`。"加权中位节点"是指：从该节点出发，所有子树的权重之和不超过总权重的一半。换句话说，找到重心节点（考虑权重）。

给定若干查询，每次查询一个节点 `v`，将 `weight[v]` 更新后，求新的加权中位节点。

**提示：**
- `1 <= n <= 10^5`
- 1 <= queries.length <= 10^5`

## 解题思路

树的重心（加权版本）：找到一个节点，使得删掉该节点后，最大子树的权重之和不超过总权重的一半。

基本算法：
1. 计算总权重 W
2. 从根节点出发，贪心地移向"最重"的子树
3. 直到当前节点的最重子树权重 <= W/2

支持更新的版本需要树上数据结构（如 HLD + 线段树）。

## Python 代码实现

### 方法一：DFS 找重心（基础版，不含更新）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findWeightedMedian(self, n: int, edges: List[List[int]],
                            weight: List[int], queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def find_centroid(weights):
            total = sum(weights)

            # 计算子树权重
            subtree_weight = list(weights)
            parent = [-1] * n
            order = []

            stack = [(0, -1)]
            visited = set([0])
            while stack:
                u, p = stack.pop()
                order.append(u)
                parent[u] = p
                for v in graph[u]:
                    if v not in visited:
                        visited.add(v)
                        stack.append((v, u))

            for u in reversed(order):
                if parent[u] != -1:
                    subtree_weight[parent[u]] += subtree_weight[u]

            # 找重心
            for u in order:
                # 检查 u 是否是重心
                max_part = total - subtree_weight[u]  # 父侧权重
                for v in graph[u]:
                    if v != parent[u]:
                        max_part = max(max_part, subtree_weight[v])
                if max_part <= total / 2:
                    return u
            return 0

        # 处理查询（每次更新后重新计算）
        w = list(weight)
        result = []
        for v, new_w in queries:
            w[v] = new_w
            result.append(find_centroid(w))

        return result
```

### 方法二：贪心移动找重心

```python
from typing import List
from collections import defaultdict

class Solution:
    def findWeightedMedian(self, n: int, edges: List[List[int]],
                            weight: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        subtree_weight = list(weight)
        parent = [-1] * n
        total = sum(weight)

        # BFS/DFS 建立子树权重
        order = []
        visited = {0}
        stack = [(0, -1)]
        while stack:
            u, p = stack.pop()
            order.append(u)
            parent[u] = p
            for v in graph[u]:
                if v not in visited:
                    visited.add(v)
                    stack.append((v, u))

        for u in reversed(order):
            if parent[u] != -1:
                subtree_weight[parent[u]] += subtree_weight[u]

        # 贪心找重心：从根出发，移向最重子树
        curr = 0
        while True:
            # 找最重子树
            best_child = -1
            best_weight = 0
            for v in graph[curr]:
                if v != parent[curr] and subtree_weight[v] > best_weight:
                    best_weight = subtree_weight[v]
                    best_child = v
            if best_weight * 2 <= total:
                break
            parent[best_child] = -1  # 现在 best_child 是新的根
            curr = best_child

        return curr
```

## 复杂度分析

- 时间复杂度：O(n)，DFS + 贪心移动
- 空间复杂度：O(n)

## 关键点总结

1. 树的重心：最大子树权重 <= 总权重/2
2. 贪心：从任意节点出发，向最重的子树移动，直到到达重心
3. 带更新时，需要维护动态数据结构

## 易错点

1. 重心可能有两个相邻节点，需要都检查
2. 删除一个节点后有多个"子树"：各个子节点的子树 + 父侧（总权重 - 当前子树权重）
3. 移动方向：向权重超过总权重一半的子树移动
