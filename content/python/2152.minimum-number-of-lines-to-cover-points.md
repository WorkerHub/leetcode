## 题目描述

给你一个二维整数数组 `points`，其中 `points[i] = [xi, yi]`。

返回覆盖所有点所需的**最少直线数量**。

**注意：** 直线是无限延伸的，点在直线上表示可以被覆盖。

**提示：**
- `1 <= points.length <= 10`
- `-100 <= xi, yi <= 100`
- 所有点互不相同

## 解题思路

**位运算 DP + 枚举直线**

n <= 10，点集用位掩码表示。

**枚举直线：** 先枚举所有可能的直线（过两个点的直线，以及只有一个点时的特殊直线）。每条直线对应一个覆盖点的掩码。

**DP：** 用 `dp[mask]` 表示覆盖点集 mask 所需的最少直线数。从 `dp[0] = 0` 出发，尝试在覆盖集合中加入一条直线（覆盖该直线上的所有点）。

由于 n 很小，也可以直接 BFS/迭代枚举。

## 代码实现

### 方法一：位 DP（推荐）

```python
from typing import List

class Solution:
    def minimumLines(self, points: List[List[int]]) -> int:
        n = len(points)
        if n == 1:
            return 1

        # 预处理每条直线覆盖的点集
        line_masks = []
        # 枚举所有两点对确定直线
        for i in range(n):
            for j in range(i + 1, n):
                mask = 0
                for k in range(n):
                    # 判断点 k 是否在过 i, j 的直线上
                    xi, yi = points[i]
                    xj, yj = points[j]
                    xk, yk = points[k]
                    # 共线判断：(yj-yi)*(xk-xi) == (yk-yi)*(xj-xi)
                    if (yj - yi) * (xk - xi) == (yk - yi) * (xj - xi):
                        mask |= 1 << k
                line_masks.append(mask)

        full = (1 << n) - 1
        INF = float('inf')
        dp = [INF] * (full + 1)
        dp[0] = 0

        for mask in range(full + 1):
            if dp[mask] == INF:
                continue
            # 找最低未覆盖的点
            lowest = -1
            for bit in range(n):
                if not (mask >> bit & 1):
                    lowest = bit
                    break
            if lowest == -1:
                continue
            # 枚举覆盖 lowest 的直线
            for lmask in line_masks:
                if lmask >> lowest & 1:
                    new_mask = mask | lmask
                    dp[new_mask] = min(dp[new_mask], dp[mask] + 1)

        return dp[full]
```

### 方法二：暴力枚举（更简单）

```python
from typing import List

class Solution:
    def minimumLines(self, points: List[List[int]]) -> int:
        n = len(points)

        def on_line(p1, p2, p):
            # 判断 p 是否在过 p1, p2 的直线上
            (x1, y1), (x2, y2), (x, y) = p1, p2, p
            return (y2 - y1) * (x - x1) == (y - y1) * (x2 - x1)

        def get_line_mask(i, j):
            mask = 0
            for k in range(n):
                if on_line(points[i], points[j], points[k]):
                    mask |= 1 << k
            return mask

        # 收集所有可能的直线掩码
        lines = set()
        for i in range(n):
            for j in range(i + 1, n):
                lines.add(get_line_mask(i, j))
        lines = list(lines)

        full = (1 << n) - 1
        dp = [float('inf')] * (full + 1)
        dp[0] = 0

        for s in range(full):
            if dp[s] == float('inf'):
                continue
            first_zero = next(b for b in range(n) if not (s >> b & 1))
            for lm in lines:
                if lm >> first_zero & 1:
                    ns = s | lm
                    dp[ns] = min(dp[ns], dp[s] + 1)

        return dp[full]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 位 DP | O(2^n * n^2) | O(2^n) |

n <= 10，2^10 = 1024，完全可接受。

## 关键点总结

1. 预处理所有可能的直线（通过两点确定），存储覆盖的点集掩码。
2. 位 DP：`dp[mask]` = 覆盖点集 mask 的最少直线数。
3. 共线判断用叉积：`(y2-y1)*(x-x1) == (y-y1)*(x2-x1)`（避免除法）。

## 易错点

- n=1 时只需 1 条直线（任意直线过该点）。
- 共线判断避免除法，用叉积（整数运算无浮点误差）。
