## 题目描述

给你一个字符串 `s` 和一个整数 `k`。

如果长度为 `k` 的子字符串满足以下条件，则称其为**特殊子字符串**：
- 所有字符相同（即由 k 个相同字符组成）
- 该字符在整个字符串 s 中**恰好**出现 k 次

如果存在这样的特殊子字符串，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：s = "aaabaaa", k = 3
输出：true
解释：s[0:3] = "aaa"，且 'a' 在 s 中恰好出现... 等等，'a' 出现了 6 次，不是 3 次
```

**示例 2：**

```
输入：s = "abc", k = 2
输出：false
```

**提示：**
- `1 <= s.length <= 100`
- `1 <= k <= s.length`
- `s` 只包含小写字母

## 解题思路

遍历所有长度为 k 的子字符串，检查：
1. 所有字符相同（即 `len(set(sub)) == 1`）
2. 该字符在 s 中恰好出现 k 次

## Python 代码实现

### 方法一：枚举子串（推荐）

```python
from collections import Counter

class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        freq = Counter(s)
        n = len(s)

        for i in range(n - k + 1):
            sub = s[i: i + k]
            # 检查所有字符相同
            if len(set(sub)) == 1:
                c = sub[0]
                # 检查该字符在 s 中恰好出现 k 次
                if freq[c] == k:
                    return True

        return False
```

### 方法二：按字符统计连续段

```python
from collections import Counter

class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        freq = Counter(s)

        # 对每个字符，检查是否有长度恰为 k 的连续段，且该字符总出现 k 次
        i = 0
        n = len(s)

        while i < n:
            c = s[i]
            j = i
            while j < n and s[j] == c:
                j += 1
            seg_len = j - i

            if seg_len == k and freq[c] == k:
                return True

            i = j

        return False
```

### 方法三：一行写法

```python
from collections import Counter

class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        freq = Counter(s)
        return any(
            len(set(s[i:i+k])) == 1 and freq[s[i]] == k
            for i in range(len(s) - k + 1)
        )
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集大小常数）

## 关键点总结

1. 两个条件：连续 k 个相同字符 + 该字符总出现恰好 k 次
2. 第一个条件等价于：子串全是同一个字符
3. 用 Counter 预处理频率，O(1) 查询

## 易错点

1. 不是字符出现 k 次就行，还需要 k 个字符**连续**出现
2. 如果字符总出现次数是 k 但不是连续的，不满足条件
3. 注意区分"子串中字符相同"和"字符总频率为 k"
