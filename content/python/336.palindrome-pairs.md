## 题目描述

给定一组**互不相同**的单词，找出所有**不同**的索引对 `(i, j)`，使得列表中的两个单词，`words[i] + words[j]`，可拼接成回文串。

**示例 1:**

```
输入：words = ["abcd","dcba","lls","s","sssll"]
输出：[[0,1],[1,0],[3,2],[2,4]]
解释：可拼接成的回文串为 ["dcbaabcd","abcddcba","slls","llssssll"]
```

**示例 2:**

```
输入：words = ["bat","tab","cat"]
输出：[[0,1],[1,0]]
解释：可拼接成的回文串为 ["battab","tabbat"]
```

**示例 3:**

```
输入：words = ["a",""]
输出：[[0,1],[1,0]]
```

**提示:**

- `1 <= words.length <= 5000`
- `0 <= words[i].length <= 300`
- `words[i]` 由小写英文字母组成

## 解题思路

暴力解法是 O(n² * k)，其中 n 是单词数，k 是单词长度。我们需要优化。

### 核心思想

对于单词 `s`，如果 `s + t` 是回文串，则：
1. **情况 1**：`s` 的某个前缀是回文，`t` 是 `s` 剩余部分的翻转
2. **情况 2**：`s` 的某个后缀是回文，`t` 是 `s` 剩余部分的翻转
3. **情况 3**：`s` 本身是回文，`t` 是空串或者空串是回文

### 算法思路

1. **构建哈希表**：将所有单词及其索引存入哈希表
2. **遍历每个单词**：
   - 将单词分成前缀和后缀
   - **情况 1**：如果前缀是回文，查找后缀的翻转是否存在
   - **情况 2**：如果后缀是回文，查找前缀的翻转是否存在
3. **去重**：避免重复的配对

## Python 代码实现

### 方法一：哈希表 + 枚举分割点（推荐）⭐

```python
from typing import List

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        """
        哈希表 + 枚举分割点
        """
        # 构建单词到索引的映射
        word_dict = {word: i for i, word in enumerate(words)}
        result = []
        
        for i, word in enumerate(words):
            # 枚举所有分割点
            for j in range(len(word) + 1):
                # 分割成前缀和后缀
                prefix = word[:j]
                suffix = word[j:]
                
                # 情况 1: 前缀是回文，查找后缀的翻转
                if self.is_palindrome(prefix):
                    reversed_suffix = suffix[::-1]
                    if reversed_suffix in word_dict and word_dict[reversed_suffix] != i:
                        result.append([word_dict[reversed_suffix], i])
                
                # 情况 2: 后缀是回文，查找前缀的翻转
                # 注意：j != len(word) 避免重复（当 j == len(word) 时，suffix 为空，会和情况 1 重复）
                if j != len(word) and self.is_palindrome(suffix):
                    reversed_prefix = prefix[::-1]
                    if reversed_prefix in word_dict and word_dict[reversed_prefix] != i:
                        result.append([i, word_dict[reversed_prefix]])
        
        return result
    
    def is_palindrome(self, s: str) -> bool:
        """判断字符串是否为回文"""
        return s == s[::-1]
```

### 方法二：优化的回文判断

```python
from typing import List

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        """
        优化回文判断，使用双指针
        """
        word_dict = {word: i for i, word in enumerate(words)}
        result = []
        
        for i, word in enumerate(words):
            for j in range(len(word) + 1):
                prefix = word[:j]
                suffix = word[j:]
                
                # 情况 1
                if self.is_palindrome_two_pointers(prefix):
                    reversed_suffix = suffix[::-1]
                    if reversed_suffix in word_dict and word_dict[reversed_suffix] != i:
                        result.append([word_dict[reversed_suffix], i])
                
                # 情况 2
                if j != len(word) and self.is_palindrome_two_pointers(suffix):
                    reversed_prefix = prefix[::-1]
                    if reversed_prefix in word_dict and word_dict[reversed_prefix] != i:
                        result.append([i, word_dict[reversed_prefix]])
        
        return result
    
    def is_palindrome_two_pointers(self, s: str) -> bool:
        """双指针判断回文"""
        left, right = 0, len(s) - 1
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True
```

### 方法三：字典树（Trie）解法

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.word_index = -1  # 单词索引
        self.palindrome_suffixes = []  # 以当前节点为前缀的回文后缀索引

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        """
        字典树解法（更高效）
        """
        root = TrieNode()
        
        # 构建字典树（插入翻转的单词）
        for i, word in enumerate(words):
            self.insert(root, word[::-1], i)
        
        result = []
        
        # 查找配对
        for i, word in enumerate(words):
            self.search(root, word, i, result)
        
        return result
    
    def insert(self, root: TrieNode, word: str, index: int):
        """插入翻转的单词到字典树"""
        node = root
        for j, char in enumerate(word):
            # 如果剩余部分是回文，记录当前单词索引
            if word[j:] == word[j:][::-1]:
                node.palindrome_suffixes.append(index)
            
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        
        node.word_index = index
        node.palindrome_suffixes.append(index)
    
    def search(self, root: TrieNode, word: str, index: int, result: List[List[int]]):
        """查找配对"""
        node = root
        
        for j, char in enumerate(word):
            # 情况 1: 匹配到一个完整单词，且剩余部分是回文
            if node.word_index != -1 and node.word_index != index:
                if word[j:] == word[j:][::-1]:
                    result.append([index, node.word_index])
            
            if char not in node.children:
                return
            
            node = node.children[char]
        
        # 情况 2: word 全部匹配完
        # 找到所有以当前节点为前缀的回文后缀
        for suffix_index in node.palindrome_suffixes:
            if suffix_index != index:
                result.append([index, suffix_index])
```

### 方法四：暴力解法（会超时）

```python
from typing import List

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        """
        暴力解法：O(n² * k)
        """
        result = []
        n = len(words)
        
        for i in range(n):
            for j in range(n):
                if i != j:
                    combined = words[i] + words[j]
                    if combined == combined[::-1]:
                        result.append([i, j])
        
        return result
```

## 复杂度分析

**方法一/二：哈希表**

- **时间复杂度**：O(n * k²)
  - n：单词数
  - k：单词平均长度
  - 每个单词枚举 k 个分割点，每次判断回文 O(k)
  
- **空间复杂度**：O(n * k)
  - 哈希表存储所有单词

**方法三：字典树**

- **时间复杂度**：O(n * k²)
  - 构建字典树：O(n * k²)
  - 查找：O(n * k²)
  
- **空间复杂度**：O(n * k)
  - 字典树的空间

**方法四：暴力解法**

- **时间复杂度**：O(n² * k)
  - 双层循环 O(n²)，每次判断回文 O(k)
  
- **空间复杂度**：O(1)

## 关键点总结

1. **核心思想**：将单词分成前缀和后缀，分别判断回文
2. **两种情况**：
   - 前缀是回文，找后缀的翻转
   - 后缀是回文，找前缀的翻转
3. **去重技巧**：`j != len(word)` 避免重复
4. **哈希表优化**：O(1) 查找翻转的单词
5. **字典树优化**：适合大量单词的场景

## 易错点

1. **重复配对**：
   - 情况 2 需要 `j != len(word)` 避免重复
   - 当 `j == len(word)` 时，suffix 为空，会和情况 1 重复

2. **自身配对**：
   - 要检查 `word_dict[reversed_suffix] != i`
   - 避免一个单词和自己配对

3. **空字符串处理**：
   - 空字符串是回文
   - 空字符串可以和任何回文单词配对

4. **索引顺序**：
   - `[word_dict[reversed_suffix], i]`：reversed_suffix 在前
   - `[i, word_dict[reversed_prefix]]`：i 在前

5. **回文判断**：确保回文判断函数正确

```
对于 "lls" (索引 2)：
  
分割点 j=0: prefix="", suffix="lls"

  - suffix 是回文 ✓
  - prefix 翻转 = "sll"，不在字典中
```
