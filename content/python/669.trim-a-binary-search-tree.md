## 题目描述

给定一个二叉搜索树的根节点 root 和一个区间 [low, high]，修剪这棵树，使得所有节点的值都在 [low, high] 中。

修剪树不应该改变保留在树中的元素的相对结构（即如果没有被移除，原有的父子关系应当保留）。

可以证明，存在唯一的答案。

返回修剪后的二叉搜索树的根节点。

**示例 1：**
```
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
```

**示例 2：**
```
输入：root = [3,0,4,null,2,null,null,1], low = 1, high = 3
输出：[3,2,null,1]
```

**提示：**
- 树中节点数在 [1, 10^4] 范围内
- 0 <= Node.val <= 10^4
- 树中每个节点的值都是唯一的
- root 是合法的二叉搜索树
- 0 <= low <= high <= 10^4

## 解题思路

利用二叉搜索树的性质，可以高效地进行修剪。

**BST性质：**
- 左子树所有节点 < 根节点 < 右子树所有节点

**修剪策略：**
1. 如果 root.val < low，整个左子树都不符合要求，只需修剪右子树
2. 如果 root.val > high，整个右子树都不符合要求，只需修剪左子树
3. 如果 low <= root.val <= high，递归修剪左右子树

**算法流程：**
1. 如果节点为空，返回 None
2. 如果节点值 < low，返回修剪后的右子树
3. 如果节点值 > high，返回修剪后的左子树
4. 否则，递归修剪左右子树，返回当前节点

## Python 代码实现

### 方法一：递归（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:
        if not root:
            return None
        
        # 当前节点值小于low，整个左子树都小于low，只保留右子树
        if root.val < low:
            return self.trimBST(root.right, low, high)
        
        # 当前节点值大于high，整个右子树都大于high，只保留左子树
        if root.val > high:
            return self.trimBST(root.left, low, high)
        
        # 当前节点在范围内，递归修剪左右子树
        root.left = self.trimBST(root.left, low, high)
        root.right = self.trimBST(root.right, low, high)
        
        return root
```

### 方法二：迭代方式

```python
class Solution:
    def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:
        if not root:
            return None
        
        # 找到符合范围的根节点
        while root and (root.val < low or root.val > high):
            if root.val < low:
                root = root.right
            else:
                root = root.left
        
        if not root:
            return None
        
        # 修剪左子树：移除所有小于low的节点
        node = root
        while node.left:
            if node.left.val < low:
                node.left = node.left.right
            else:
                node = node.left
        
        # 修剪右子树：移除所有大于high的节点
        node = root
        while node.right:
            if node.right.val > high:
                node.right = node.right.left
            else:
                node = node.right
        
        return root
```

### 方法三：带注释的详细版本

```python
class Solution:
    def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:
        def trim(node):
            """递归修剪节点"""
            if not node:
                return None
            
            if node.val < low:
                # 节点值太小，抛弃左子树和当前节点
                # 右子树可能有符合条件的节点
                return trim(node.right)
            
            if node.val > high:
                # 节点值太大，抛弃右子树和当前节点
                # 左子树可能有符合条件的节点
                return trim(node.left)
            
            # 节点值在范围内，保留节点，递归处理子树
            node.left = trim(node.left)
            node.right = trim(node.right)
            return node
        
        return trim(root)
```

## 复杂度分析

**方法一：递归**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树的高度，递归栈空间

**方法二：迭代**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 root = [3,0,4,null,2,null,null,1], low = 1, high = 3 为例：

```
原始树：
      3
     / \
    0   4
     \
      2
     /
    1

修剪过程：
1. 节点3：在[1,3]内，保留，修剪左右子树
2. 节点0：< 1，抛弃，返回右子树（节点2）
3. 节点2：在[1,3]内，保留，修剪左右子树
4. 节点1：在[1,3]内，保留
5. 节点4：> 3，抛弃，返回左子树（null）

结果树：
    3
   /
  2
 /
1
```

## 关键点总结

1. **BST性质应用**：节点小于low则整个左子树都小于low
2. **递归简洁**：每个节点只需判断自己的值，子树递归处理
3. **返回值处理**：可能返回子树的根，不一定是原节点
4. **边界情况**：空节点直接返回，根节点也可能被修剪
5. **结构保持**：修剪后仍是BST，相对关系不变

## 易错点

1. **忘记返回子树**：当前节点不符合时，要返回修剪后的子树
2. **左右子树混淆**：小于low返回右子树，大于high返回左子树
3. **忘记递归处理**：符合条件的节点也要递归处理其子树
4. **修改原树**：直接修改原树，不需要新建节点
5. **空指针处理**：修剪后子节点可能为空
