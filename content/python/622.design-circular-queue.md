## 题目描述

设计你的循环队列实现。循环队列是一种线性数据结构，其操作表现基于 FIFO（先进先出）原则，并且队尾被连接在队首之后以形成一个循环。它也被称为"环形缓冲器"。

循环队列的一个好处是我们可以利用这个队列之前用过的空间。在一个普通队列里，一旦一个队列满了，我们就不能插入下一个元素，即使在队列前面仍有空间。但是使用循环队列，我们能使用这些空间去存储新的值。

你的实现应该支持如下操作：

- `MyCircularQueue(k)`: 构造器，设置队列长度为 k。
- `Front`: 从队首获取元素。如果队列为空，返回 -1。
- `Rear`: 获取队尾元素。如果队列为空，返回 -1。
- `enQueue(value)`: 向循环队列插入一个元素。如果成功插入则返回真。
- `deQueue()`: 从循环队列中删除一个元素。如果成功删除则返回真。
- `isEmpty()`: 检查循环队列是否为空。
- `isFull()`: 检查循环队列是否已满。

**示例：**

```
MyCircularQueue circularQueue = new MyCircularQueue(3);
circularQueue.enQueue(1);  // 返回 true
circularQueue.enQueue(2);  // 返回 true
circularQueue.enQueue(3);  // 返回 true
circularQueue.enQueue(4);  // 返回 false，队列已满
circularQueue.Rear();  // 返回 3
circularQueue.isFull();  // 返回 true
circularQueue.deQueue();  // 返回 true
circularQueue.enQueue(4);  // 返回 true
circularQueue.Rear();  // 返回 4
```

**提示：**

- 所有的值都在 0 至 1000 的范围内
- 操作数将在 1 至 1000 的范围内
- 请不要使用内置的队列库

## 解题思路

**核心思想：使用数组 + 双指针**

关键点：
1. **头尾指针**：`front` 和 `rear` 指针
2. **循环逻辑**：`(index + 1) % capacity`
3. **判空/满**：需要区分空和满的状态

**区分空满的方法：**
- 方法一：使用计数器 `count`
- 方法二：浪费一个空间（`(rear + 1) % capacity == front` 表示满）
- 方法三：使用标志位

## Python 代码实现

### 方法一：使用计数器（推荐）⭐

```python
class MyCircularQueue:
    def __init__(self, k: int):
        """
        使用数组 + 计数器实现
        
        时间复杂度：所有操作 O(1)
        空间复杂度：O(k)
        """
        self.queue = [0] * k
        self.capacity = k
        self.front = 0
        self.rear = -1
        self.count = 0

    def enQueue(self, value: int) -> bool:
        """插入元素"""
        if self.isFull():
            return False
        
        self.rear = (self.rear + 1) % self.capacity
        self.queue[self.rear] = value
        self.count += 1
        return True

    def deQueue(self) -> bool:
        """删除元素"""
        if self.isEmpty():
            return False
        
        self.front = (self.front + 1) % self.capacity
        self.count -= 1
        return True

    def Front(self) -> int:
        """获取队首元素"""
        if self.isEmpty():
            return -1
        return self.queue[self.front]

    def Rear(self) -> int:
        """获取队尾元素"""
        if self.isEmpty():
            return -1
        return self.queue[self.rear]

    def isEmpty(self) -> bool:
        """检查是否为空"""
        return self.count == 0

    def isFull(self) -> bool:
        """检查是否已满"""
        return self.count == self.capacity
```

### 方法二：浪费一个空间

```python
class MyCircularQueue:
    def __init__(self, k: int):
        """
        浪费一个空间来区分空满
        实际可用空间为 k-1
        """
        self.queue = [0] * (k + 1)  # 多分配一个空间
        self.capacity = k + 1
        self.front = 0
        self.rear = 0

    def enQueue(self, value: int) -> bool:
        if self.isFull():
            return False
        
        self.queue[self.rear] = value
        self.rear = (self.rear + 1) % self.capacity
        return True

    def deQueue(self) -> bool:
        if self.isEmpty():
            return False
        
        self.front = (self.front + 1) % self.capacity
        return True

    def Front(self) -> int:
        if self.isEmpty():
            return -1
        return self.queue[self.front]

    def Rear(self) -> int:
        if self.isEmpty():
            return -1
        return self.queue[(self.rear - 1 + self.capacity) % self.capacity]

    def isEmpty(self) -> bool:
        return self.front == self.rear

    def isFull(self) -> bool:
        return (self.rear + 1) % self.capacity == self.front
```

### 方法三：使用链表

```python
class Node:
    def __init__(self, value, next_node=None):
        self.value = value
        self.next = next_node

class MyCircularQueue:
    def __init__(self, k: int):
        """
        使用链表实现
        
        时间复杂度：O(1)
        空间复杂度：O(k)
        """
        self.capacity = k
        self.count = 0
        self.head = None
        self.tail = None

    def enQueue(self, value: int) -> bool:
        if self.isFull():
            return False
        
        new_node = Node(value)
        if self.isEmpty():
            self.head = self.tail = new_node
        else:
            self.tail.next = new_node
            self.tail = new_node
        
        self.count += 1
        return True

    def deQueue(self) -> bool:
        if self.isEmpty():
            return False
        
        self.head = self.head.next
        self.count -= 1
        return True

    def Front(self) -> int:
        if self.isEmpty():
            return -1
        return self.head.value

    def Rear(self) -> int:
        if self.isEmpty():
            return -1
        return self.tail.value

    def isEmpty(self) -> bool:
        return self.count == 0

    def isFull(self) -> bool:
        return self.count == self.capacity
```

## 复杂度分析

### 所有方法
- **时间复杂度**：所有操作均为 O(1)
- **空间复杂度**：O(k)

## 关键点总结

1. **循环索引**：使用取模运算 `(index + 1) % capacity`
2. **区分空满**：使用计数器最简单直观
3. **边界处理**：队列为空时返回 -1
4. **初始化**：注意 `rear` 的初始值（-1 或 0）
5. **Rear 的计算**：方法二中需要 `(rear - 1 + capacity) % capacity`

## 易错点

1. **忘记取模**：
   ```python
   # ❌ 错误：没有循环
   self.rear += 1
   
   # ✅ 正确
   self.rear = (self.rear + 1) % self.capacity
   ```

2. **空满判断错误**：
   ```python
   # ❌ 方法二中的错误：rear == front 既可能是空也可能是满
   # 需要浪费一个空间来区分
   ```

3. **Rear 索引计算**：
   ```python
   # ❌ 错误：rear 指向下一个要插入的位置
   return self.queue[self.rear]
   
   # ✅ 正确：返回上一个位置
   return self.queue[(self.rear - 1 + self.capacity) % self.capacity]
   ```

4. **初始化 rear**：
   - 方法一：rear = -1（指向队尾元素）
   - 方法二：rear = 0（指向下一个插入位置）

## 学习建议

**新手学习路径：**

1. **理解循环队列**：
   - 队列满时不能浪费前面的空间
   - 使用数组 + 双指针实现循环

2. **掌握取模运算**：
   ```python
   # 循环递增
   index = (index + 1) % capacity
   
   # 循环递减
   index = (index - 1 + capacity) % capacity
   ```

3. **空满判断的三种方法**：
   - 计数器：最简单，推荐
   - 浪费空间：经典方法
   - 标志位：需要额外变量

4. **推荐方法**：
   - 初学者：方法一（计数器），最容易理解
   - 进阶：方法二，理解浪费空间的技巧
   - 扩展：方法三，掌握链表实现

5. **测试用例**：
   ```python
   q = MyCircularQueue(3)
   q.enQueue(1)  # True, [1]
   q.enQueue(2)  # True, [1,2]
   q.enQueue(3)  # True, [1,2,3]

   ```
