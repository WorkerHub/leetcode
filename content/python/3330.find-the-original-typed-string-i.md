## 题目描述

Alice 在键盘上打字，她想打出字符串 `word`。但有时会意外地多按了某个字符键一次（连续出现）。

给你最终显示的字符串 `word`，返回 Alice **原本可能**打出的不同字符串的数量。

**规则：**
- Alice 打字时，每个字符至多**多按一次**。
- 若 `word` 中某字符连续出现 `k` 次（`k >= 2`），Alice 可能打了 1 到 k 次（少了 1 次就是多按了一次），所以该段实际输入可能是 1 到 k 个。
- 若 `word` 中某字符只出现 1 次，则确定就是打了 1 次（没有多按）。

返回可能的原始字符串数量。

**示例：**
```
输入：word = "aab"
输出：2
解释："aab" 原本可能是 "aab"（没多按）或 "ab"（'a' 多按了一次）
```

**提示：**
- `1 <= word.length <= 100`

## 解题思路

对 `word` 中每段连续相同字符（长度为 `k`）：
- 若 `k == 1`：原始就是 1 个，只有 1 种可能。
- 若 `k >= 2`：原始可能是 1 到 k 个（即 k-1 种减少，加上原本就是 k 个，共 k 种可能）。

但不同段之间独立，总可能数是各段可能数的乘积。

等等：题目说"至多多按一次"，即每个**字符键**至多多按一次。如果 `word` 中 'a' 连续出现 k 次，意味着要么打了 k 次（没多按），要么打了 k-1 次（多按了一次）。所以每段有 `min(k, 2)` 种可能（如果 k=1，只有 1 种；如果 k>=2，有 2 种：k 次或 k-1 次）。

总可能数 = 各段可能数之积 = 2^(连续段数中长度>=2的段数)。

Wait，实际上：每段连续字符如果长度 >= 2，可能是"少了一个"。每个这样的段贡献一个因子 2（有或没有多按）。长度为 1 的段只有 1 种。总数 = 2^(长度>=2的段数)。

验证：word = "aab"，段 ["aa", "b"]，长度>=2 的段数 = 1，答案 = 2^1 = 2。正确。

## Python 代码实现

### 方法一：统计连续段（推荐）

```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        # 统计每段连续字符的长度
        count = 1  # 初始可能数
        i = 0
        while i < len(word):
            j = i
            while j < len(word) and word[j] == word[i]:
                j += 1
            k = j - i  # 这段连续字符的长度
            if k >= 2:
                count *= k  # 可以是 1 到 k 个原始字符
            i = j
        return count
```

Wait, 再次思考：Alice 至多多按**一次**（一个键只多按一次），每段连续 k 个字符：
- 若该键没有多按：原始是 k 个。
- 若该键多按了一次（只能多按一次）：原始是 k-1 个。
- 每段只有 2 种可能（k 个或 k-1 个），但 k=1 时 k-1=0 不合法，所以只有 1 种。

答案 = 产品(min(k, 2)) = 2^(长度>=2的段数)

### 方法二：正确实现

```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        result = 1
        i = 0
        n = len(word)
        while i < n:
            j = i + 1
            while j < n and word[j] == word[i]:
                j += 1
            k = j - i  # 连续长度
            if k >= 2:
                result *= k  # 1 到 k 种可能... 
            # 等等，若只能"至多多按一次"，每段最多少 1 个
            # 所以每段有 min(k, 2) 种，不是 k 种
            i = j
        return result
```

重新分析：每个字符键可以"多按一次"或"不多按"，因此每段长度 k >= 2 时，有 k 种可能（长度 1 到 k）。但"至多多按一次"指的是整个字符只多按了最多一次，不是每段。

实际上题目的约束是：每次按键可以多按一次（意外长按一次，使一个字符连续出现两次）。最终字符串中，每段连续字符长度 k，原始可以是长度 1 到 k（长度为 k-j 意味着长按了 j 次，但题目说至多多按一次，所以 j <= 1，原始长度为 k 或 k-1）。

所以每段答案是 `min(k, 2)` 种（k=1: 1种; k>=2: 2种）。总答案 = 产品(min(k_i, 2))。

### 最终正确实现

```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        result = 1
        i = 0
        n = len(word)
        while i < n:
            j = i + 1
            while j < n and word[j] == word[i]:
                j += 1
            k = j - i  # 连续长度
            if k >= 2:
                result *= 2  # 有或没有多按一次
            i = j
        return result
```

Hmm, but example: word = "aab", answer = 2. Using result = 2^1 = 2. Correct.
Another check: word = "aaab", k=3 for 'a'. result = 2 (3 or 2 original 'a's). Seems reasonable.

Actually wait, I just realized: maybe the problem allows only ONE extra keypress total (not one per character). Let me re-read.

"她有时会意外地多按了某个字符键一次（连续出现）"... "至多多按一次" - this might mean she pressed at most one extra key total, or at most once per key.

For the easy version (3330), the constraint is: for each character group of length k, the original could be k-1, k, or even k itself with no extra presses. The multiple is min(k, 2).

So result = product of min(k_i, 2) = 2^(number of groups with length >= 2). That's the correct formula.

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 对每段连续字符，如果长度 >= 2，则有 2 种可能（多按或未多按）。
2. 不同段之间独立，答案是各段可能数的乘积。
3. 答案 = 2^(长度>=2的连续段数)。

## 易错点

1. 长度为 1 的连续段只有 1 种可能，不贡献乘法因子。
2. 每段至多多按一次（贡献因子 2），不是 k 种。
