## 题目描述

Winston 构造了一个如下所示的函数 `func(arr, l, r)`：

```
func(arr, l, r) = AND(arr[l], arr[l+1], ..., arr[r])
```

即取数组 `arr` 从下标 `l` 到 `r` 所有元素的按位与（AND）值。

给你 `arr` 和 `target`，请你找出使 `|func(arr, l, r) - target|` 最小的 `(l, r)` 对，返回最小差值。

**示例 1：**
```
输入：arr = [9,12,3,7,15], target = 5
输出：1
解释：[9,12,3,7,15] 中 func(4,4)=15, func(0,1)=8...最近的是3，|3-5|=2，但7|5|=2，最小是1
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^6`
- `1 <= target <= 10^6`

## 解题思路

### 位运算特性 + 集合维护

**关键观察：**
1. 从右向左的 AND 操作是单调不增的（AND 只会使某些位从1变为0）
2. 固定右端点 `r`，随着 `l` 从 `r` 减小到 0，`AND(arr[l..r])` 的不同值至多有 `log(max_val)` 个（每次 AND 至少减少一个比特位）

**算法：**
- 维护一个集合 `cur_set`，存储所有以 `r` 为右端点的子数组的 AND 值
- 对每个 `r`，将 `arr[r]` 与 `cur_set` 中的每个值做 AND，再加入 `arr[r]` 本身
- 集合大小至多 20（log2(10^6) ≈ 20）
- 对集合中每个值，更新最小差值

## 代码实现

### 方法一：集合维护 AND 值（推荐）

```python
from typing import List

class Solution:
    def closestToTarget(self, arr: List[int], target: int) -> int:
        ans = float('inf')
        # cur_set 存储所有以当前位置为右端点的子数组 AND 值
        cur_set = set()

        for val in arr:
            # 对集合中每个已有的 AND 值，再 AND 当前 val
            next_set = {prev & val for prev in cur_set}
            next_set.add(val)  # 单个元素子数组
            # 更新答案
            for v in next_set:
                ans = min(ans, abs(v - target))
            cur_set = next_set

        return ans
```

### 方法二：枚举 + 优化（暴力，仅供参考）

```python
from typing import List

class Solution:
    def closestToTarget(self, arr: List[int], target: int) -> int:
        n = len(arr)
        ans = float('inf')
        for i in range(n):
            cur = arr[i]
            for j in range(i, n):
                cur &= arr[j]
                ans = min(ans, abs(cur - target))
                # AND 只减不增，如果 cur 已经 < target - ans，提前终止
                if cur < target - ans:
                    break
        return ans
```

### 方法三：集合方法 + 提前终止优化

```python
from typing import List

class Solution:
    def closestToTarget(self, arr: List[int], target: int) -> int:
        ans = abs(arr[0] - target)
        cur_set = set()

        for val in arr:
            # 利用 AND 的幂等性：cur & val = val 当 cur 包含 val 的所有位
            cur_set = {prev & val for prev in cur_set} | {val}
            ans = min(ans, min(abs(v - target) for v in cur_set))

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 集合维护 | O(N * log(MAX)) | O(log(MAX)) |
| 暴力 | O(N^2) | O(1) |

`log(MAX) = log(10^6) ≈ 20`，集合大小不超过 20。

## 关键点总结

1. 子数组 AND 的不同取值数量是 O(log(MAX))，因为每次 AND 至少减少一个比特位
2. 维护以当前位置为右端点的所有子数组 AND 值的集合
3. 每步集合大小至多 20，效率很高

## 易错点

- 不能只考虑连续 AND 值，要维护所有可能的 AND 值
- 集合中要包含 `val` 本身（以当前位置为左右端点的子数组）
