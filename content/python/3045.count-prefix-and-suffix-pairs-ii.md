## 题目描述

与 3042 相同题意，但 `words.length` 扩大到 `10^5`，`words[i].length` 扩大到 `10^5`，需要高效算法。

返回满足 `i < j` 且 `words[i]` 同时是 `words[j]` 的前缀和后缀的下标对数量。

**提示：**
- `1 <= words.length <= 10^5`
- `1 <= words[i].length <= 10^5`
- 所有 `words[i]` 长度之和 <= `5 * 10^5`

## 解题思路

**Z 函数 / KMP 思路：**

对于字符串 `s`，检查某个前缀 `p = s[:l]` 是否同时也是后缀，等价于检查 `s` 的 Z 函数中 `z[n-l] >= l`（即 `s[n-l:]` 的最长公共前缀 >= l）。

**高效方法 - Z 函数 Trie：**

将每个字符串 `s` 和其反转 `s[::-1]` 构建一对字符进行存储。

更简单的方法：构建一个字典树，存储"字符对 `(s[i], s[n-1-i])`"序列，其中 n 是字符串长度。

对于 `words[j]`，其能被 `words[i]` 作为前后缀的条件是：在构建的字典树中，`words[i]` 的字符对序列是 `words[j]` 的字符对序列的前缀。

将每个字符串转化为 `zip(s, reversed(s))`，变为字符对序列，然后用 Trie 统计前缀匹配数量。

## Python 代码实现

### 方法一：Z 函数 Trie（推荐）

```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.count = 0  # 以此节点结尾的字符串数量

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        root = TrieNode()
        ans = 0

        for word in words:
            n = len(word)
            # 将 word 转为字符对序列 (word[i], word[n-1-i])
            # 长度为 n 的字符对序列
            node = root
            ans += node.count  # 空字符串是所有字符串的前后缀（不算）

            for i in range(n):
                pair = (word[i], word[n - 1 - i])
                if pair not in node.children:
                    node.children[pair] = TrieNode()
                node = node.children[pair]
                ans += node.count  # 以此为前缀且长度 <= n 的字符串数

            node.count += 1

        return ans
```

### 方法二：滚动哈希

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        MOD = (1 << 61) - 1
        BASE = 131

        def hash_pair_seq(word: str):
            """将字符对序列转为哈希值序列"""
            n = len(word)
            # 字符对 (word[i], word[n-1-i]) 编码为 word[i] * 130 + word[n-1-i]
            hashes = []
            h = 0
            pw = 1
            for i in range(n):
                c1 = ord(word[i]) - ord('a') + 1
                c2 = ord(word[n-1-i]) - ord('a') + 1
                val = c1 * 130 + c2
                h = (h + val * pw) % MOD
                pw = pw * BASE % MOD
                hashes.append(h)
            return hashes

        # 用哈希表存储前缀哈希值
        # prefix_hash_count[h] = 已见过的哈希值为 h 的字符串数量
        prefix_count = defaultdict(int)
        ans = 0

        for word in words:
            hashes = hash_pair_seq(word)
            # 查询：已见过的字符串中，哪些是当前字符串的前后缀
            for h in hashes:
                ans += prefix_count[h]
            # 当前字符串加入
            prefix_count[hashes[-1]] += 1

        return ans
```

## 复杂度分析

- Trie 方法：O(总字符数)，每个字符对操作 O(1)
- 空间复杂度：O(总字符数 * 26^2)（字典树节点）

## 关键点总结

1. 核心思想：将字符串转为字符对序列 `(s[i], s[n-1-i])`，则前缀关系转为字符对序列的前缀关系
2. 字典树（Trie）高效统计前缀匹配数
3. 每个单词查询 Trie 中已有前缀数，再将自身插入

## 易错点

1. 字符对的构造：第 i 个字符对是 `(word[i], word[n-1-i])`，而不是 `(word[i], word[i])`
2. 只有长度 <= 当前字符串长度的字符串才可能是其前后缀
3. 注意 Trie 中 `count` 在节点处更新的时机（必须在查询完成后再插入）
