## 题目描述

字符串 `s` 的长度为 `n`，另给你一个整数 `k` 和字符 `fill`。

将字符串 `s` 从左到右分成若干组，每组大小为 `k`。如果最后一组不足 `k` 个字符，用 `fill` 字符补齐到大小 `k`。

返回分组后的字符串数组。

**示例 1：**
```
输入：s = "abcdefghi", k = 3, fill = 'x'
输出：["abc","def","ghi"]
```

**示例 2：**
```
输入：s = "abcdefghij", k = 3, fill = 'x'
输出：["abc","def","ghi","jxx"]
```

**提示：**
- `1 <= s.length <= 100`
- `s` 仅由小写英文字母组成
- `1 <= k <= 100`
- `fill` 为小写英文字母

## 解题思路

先将字符串用 `fill` 补齐到 k 的倍数，再按 k 分割。

## 代码实现

### 方法一：补齐后分割（推荐）

```python
from typing import List

class Solution:
    def divideString(self, s: str, k: int, fill: str) -> List[str]:
        # 计算需要补多少个 fill
        remainder = len(s) % k
        if remainder != 0:
            s += fill * (k - remainder)
        # 按 k 分割
        return [s[i:i+k] for i in range(0, len(s), k)]
```

### 方法二：逐步分组

```python
from typing import List

class Solution:
    def divideString(self, s: str, k: int, fill: str) -> List[str]:
        result = []
        n = len(s)
        i = 0
        while i < n:
            group = s[i:i+k]
            # 若最后一组不足 k 个，用 fill 补齐
            if len(group) < k:
                group += fill * (k - len(group))
            result.append(group)
            i += k
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 补齐后分割 | O(n) | O(n) |

## 关键点总结

1. 先补齐字符串到 k 的倍数，再分割，思路最清晰。
2. `remainder = len(s) % k`，若不为 0 则需补 `k - remainder` 个字符。
3. 分割用列表推导式 `[s[i:i+k] for i in range(0, len(s), k)]`。

## 易错点

- 若 `len(s) % k == 0` 则不需要补充。
- `fill` 是单个字符，补充时要重复 `k - remainder` 次。
