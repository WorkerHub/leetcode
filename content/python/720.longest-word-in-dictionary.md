## 题目描述

给出一个字符串数组 `words` 组成的一本英语词典。返回 `words` 中最长的一个单词，该单词是由 `words` 词典中其他单词逐步添加一个字母组成。

若其中有多个可行的答案，则返回答案中字典序最小的单词。若无答案，则返回空字符串。

**示例 1：**

```
输入：words = ["w","wo","wor","worl","world"]
输出："world"
解释：单词"world"可由"w", "wo", "wor", 和 "worl"逐步添加一个字母组成。
```

**示例 2：**

```
输入：words = ["a","banana","app","appl","ap","apply","apple"]
输出："apple"
解释："apply" 和 "apple" 都能由词典中的单词组成。但是 "apple" 的字典序小于 "apply"
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 30`
- 所有输入的字符串 `words[i]` 都只包含小写字母

## 解题思路

**核心思想：**
- 使用集合存储所有单词
- 检查每个单词的所有前缀是否都在集合中

**算法流程：**
1. 将所有单词加入集合
2. 遍历单词，检查其所有前缀
3. 保留最长且字典序最小的

## Python 代码实现

### 方法一：哈希集合（推荐）⭐

```python
from typing import List

class Solution:
    def longestWord(self, words: List[str]) -> str:
        words_set = set(words)
        words.sort()  # 排序保证字典序
        
        result = ""
        
        for word in words:
            # 检查所有前缀是否都在集合中
            if all(word[:k] in words_set for k in range(1, len(word))):
                if len(word) > len(result):
                    result = word
        
        return result
```

### 方法二：Trie 树

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False

class Solution:
    def longestWord(self, words: List[str]) -> str:
        # 构建 Trie
        root = TrieNode()
        for word in words:
            node = root
            for char in word:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
            node.is_word = True
        
        # DFS 查找最长单词
        self.result = ""
        
        def dfs(node: TrieNode, path: str):
            if len(path) > len(self.result) or (len(path) == len(self.result) and path < self.result):
                self.result = path
            
            for char in sorted(node.children.keys()):
                child = node.children[char]
                if child.is_word:
                    dfs(child, path + char)
        
        dfs(root, "")
        return self.result
```

## 复杂度分析

- **时间复杂度：** O(n × L)，n 是单词数，L 是平均长度
- **空间复杂度：** O(n × L)

## 关键点总结

1. 排序保证字典序
2. 检查所有前缀
3. 更新最长结果
