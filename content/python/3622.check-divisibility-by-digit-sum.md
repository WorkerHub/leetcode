## 题目描述

给你一个正整数 `n`，如果 `n` 能被其各位数字之和整除，返回 `true`；否则返回 `false`。

**示例 1：**

```
输入：n = 18
输出：true
解释：1 + 8 = 9，18 % 9 == 0
```

**示例 2：**

```
输入：n = 12
输出：true
解释：1 + 2 = 3，12 % 3 == 0
```

**示例 3：**

```
输入：n = 11
输出：false
解释：1 + 1 = 2，11 % 2 != 0
```

**提示：**

- `1 <= n <= 10^5`

## 解题思路

计算 `n` 的各位数字之和，然后判断 `n` 是否能被该和整除即可。

注意：各位数字之和不会为 0（因为 `n >= 1`）。

## Python 代码实现

### 方法一：字符串转换（推荐）

```python
class Solution:
    def isDivisible(self, n: int) -> bool:
        digit_sum = sum(int(c) for c in str(n))
        return n % digit_sum == 0
```

### 方法二：取模运算

```python
class Solution:
    def isDivisible(self, n: int) -> bool:
        digit_sum = 0
        temp = n
        while temp > 0:
            digit_sum += temp % 10
            temp //= 10
        return n % digit_sum == 0
```

## 复杂度分析

- 时间复杂度：O(log n)，处理每一位数字
- 空间复杂度：O(1)

## 关键点总结

1. 哈沙德数（Harshad Number）：能被各位数字之和整除的数
2. 各位之和至少为 1（因为 n >= 1）
3. Python 字符串切割方式直观简洁

## 易错点

1. 不要担心除以 0，n >= 1 时各位和 >= 1
2. 注意是各位数字之和，不是数字本身
