## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回 `nums` 的子数组中元素的最大公因数等于 `k` 的子数组数目。

**子数组** 是数组中一个连续的非空序列。

**示例 1：**
```
输入：nums = [9,3,1,2,6,3], k = 3
输出：4
解释：gcd([9,3]) = 3，gcd([3,1,2,6,3]) ... 不对
实际：gcd([9,3]) = 3，gcd([3]) = 3，gcd([6,3]) = 3，gcd([3]) = 3（最后一个3），共4个。
```

**示例 2：**
```
输入：nums = [4], k = 7
输出：0
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i], k <= 10^9`

## 解题思路

**枚举所有子数组：**

对每个起点 `i`，从 `i` 向右扩展，维护当前子数组的 GCD。

- 初始化 `cur_gcd = nums[i]`
- 每次加入 `nums[j]` 后更新 `cur_gcd = gcd(cur_gcd, nums[j])`
- 若 `cur_gcd == k`，答案加一
- 若 `cur_gcd < k`（GCD 单调不增），提前终止

## 代码实现

### 方法一：暴力枚举 + GCD（推荐）

```python
from typing import List
import math

class Solution:
    def subarrayGCD(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            cur_gcd = 0
            for j in range(i, n):
                cur_gcd = math.gcd(cur_gcd, nums[j])
                if cur_gcd == k:
                    ans += 1
                elif cur_gcd < k:
                    break  # GCD 只会减小，不可能再等于 k

        return ans
```

### 方法二：优化（利用 GCD 状态数少的特性）

```python
from typing import List
import math
from collections import defaultdict

class Solution:
    def subarrayGCD(self, nums: List[int], k: int) -> int:
        ans = 0
        # prev_gcds: {gcd_value: 该 gcd 对应的子数组数量（以某位置结尾）}
        prev_gcds = defaultdict(int)

        for x in nums:
            # 只有 k 的倍数才有可能使 GCD 变为 k
            if x % k != 0:
                prev_gcds = defaultdict(int)
                continue

            new_gcds = defaultdict(int)
            new_gcds[x] += 1  # 单个元素 x

            for g, cnt in prev_gcds.items():
                new_g = math.gcd(g, x)
                new_gcds[new_g] += cnt

            ans += new_gcds[k]
            prev_gcds = new_gcds

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2 * log(max_val)) | O(1) |
| 优化方法 | O(n * log(max_val)) | O(log(max_val)) |

注：以某位置结尾的子数组的 GCD 值不超过 log(max_val) 种，因此优化方法更高效。

## 关键点总结

1. GCD 是单调不增的（子数组越长，GCD 越小或不变）
2. 若当前 GCD 已小于 k，后续不可能再等于 k，提前终止
3. 必须先确认 `nums[i]` 是 k 的倍数，否则含 `nums[i]` 的子数组 GCD 不可能等于 k

## 易错点

- `cur_gcd` 初始化为 0 而非 nums[i]，第一步 `gcd(0, nums[i]) = nums[i]`
- 剪枝：`cur_gcd < k` 时终止，但 `cur_gcd > k` 时不能终止（GCD 可能后续减小到 k）
