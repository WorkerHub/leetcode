## 题目描述

此题为 LeetCode Premium 题目。

给定一个整数数组 `nums`，请返回数组中**最小元素的各位数字之和**的奇偶性。

如果和是**奇数**，返回 `1`；如果和是**偶数**，返回 `0`。

**示例 1:**
```
输入：nums = [34,23,1,24,75,33,54,8]
输出：0
解释：最小元素是 1，其各位数字之和 = 1（奇数），但题目要求返回奇偶性的反转（0表示偶，1表示奇）
实际上根据题目描述，1 是奇数，应返回 1
```

**示例 2:**
```
输入：nums = [99,77,33,66,55]
输出：1
解释：最小元素是 33，各位数字之和 = 3 + 3 = 6（偶数），返回 0
实际应该是偶数返回 0
```

**注意**：题目描述可能存在歧义，根据实际测试用例确定规则。

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 99`

## 解题思路

这道题分为两个步骤：

1. **找到数组中的最小值**
2. **计算最小值的各位数字之和**
3. **判断和的奇偶性**

### 算法流程

1. 使用 `min()` 找到数组最小值
2. 将最小值转换为字符串或使用数学方法提取各位数字
3. 求和并判断奇偶性

## Python 代码实现

### 方法一：字符串转换（推荐）

```python
from typing import List

class Solution:
    def sumOfDigits(self, nums: List[int]) -> int:
        # 找到最小值
        min_num = min(nums)
        
        # 计算各位数字之和
        digit_sum = sum(int(digit) for digit in str(min_num))
        
        # 返回奇偶性：0表示偶数，1表示奇数
        # 根据题目要求，可能需要返回相反值
        return 1 - (digit_sum % 2)  # 如果是奇数，返回0；偶数返回1
```

### 方法二：数学方法

```python
from typing import List

class Solution:
    def sumOfDigits(self, nums: List[int]) -> int:
        # 找到最小值
        min_num = min(nums)
        
        # 用数学方法计算各位数字之和
        digit_sum = 0
        while min_num > 0:
            digit_sum += min_num % 10
            min_num //= 10
        
        # 返回奇偶性的反转
        return 1 - (digit_sum % 2)
```

### 方法三：lambda + map

```python
from typing import List

class Solution:
    def sumOfDigits(self, nums: List[int]) -> int:
        # 找最小值并计算数字和
        digit_sum = sum(map(int, str(min(nums))))
        
        # 返回奇偶性
        return 1 - (digit_sum % 2)
```

### 方法四：直接计算奇偶性

```python
from typing import List

class Solution:
    def sumOfDigits(self, nums: List[int]) -> int:
        # 一行解决
        return (sum(int(d) for d in str(min(nums))) + 1) % 2
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n + log m)
  - 找最小值：O(n)
  - 计算数字和：O(log m)，m 是最小值的大小
  - 总体：O(n)
- **空间复杂度**：O(1) 或 O(log m)
  - 方法一（字符串）：O(log m)
  - 方法二（数学）：O(1)

## 关键点总结

1. **找最小值**：使用 Python 内置 `min()` 函数
2. **数字拆分**：字符串方法简洁，数学方法空间更优
3. **奇偶判断**：`num % 2` 返回 0（偶）或 1（奇）
4. **奇偶性反转**：`1 - (num % 2)` 或 `(num + 1) % 2`
5. **题目歧义**：注意根据实际测试用例确定返回值含义

## 易错点

1. **理解错题意**：搞混返回 0/1 的含义（奇还是偶）
2. **整数除法**：Python3 中 `//` 是整数除法，`/` 是浮点除法
3. **字符串转换**：`str(num)` 会将负数的符号也包含进去（本题保证正数）
4. **空数组**：题目保证 `nums.length >= 1`
5. **单位数**：最小值可能是个位数，注意边界
