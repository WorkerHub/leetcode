## 题目描述

给你一个整数数组 `nums`，对每个整数，将其"加密"：把所有数字替换为该数中最大的数字。

返回所有加密整数的总和。

**示例 1：**
```
输入：nums = [1,2,3]
输出：6
解释：1 → 1，2 → 2，3 → 3，总和 6
```

**示例 2：**
```
输入：nums = [10,21,316]
输出：66
解释：10 → 11，21 → 22，316 → 666，总和 699
```

**提示：**
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 1000`

## 解题思路

对每个整数：
1. 找出最大数字 `d`
2. 构造同等位数的全 `d` 组成的数（如 `316` → `d=6` → `666`）
3. 全 `d` 数 = `d * (10^位数 - 1) / 9`，或 `d` 重复 `位数` 次

## Python 代码实现

### 方法一：字符串操作（推荐）

```python
from typing import List

class Solution:
    def sumOfEncryptedInt(self, nums: List[int]) -> int:
        def encrypt(n: int) -> int:
            s = str(n)
            d = max(s)  # 最大数字字符
            return int(d * len(s))

        return sum(encrypt(x) for x in nums)
```

### 方法二：数学计算

```python
from typing import List

class Solution:
    def sumOfEncryptedInt(self, nums: List[int]) -> int:
        def encrypt(n: int) -> int:
            digits = []
            while n > 0:
                digits.append(n % 10)
                n //= 10
            max_d = max(digits)
            # 构造同位数的全 max_d 的数
            result = 0
            for _ in digits:
                result = result * 10 + max_d
            return result

        return sum(encrypt(x) for x in nums)
```

## 复杂度分析

- 时间复杂度：O(n * L)，L 为数字位数（最多 4 位）
- 空间复杂度：O(1)

## 关键点总结

1. 找最大数字后，构造同位数的全最大数字的数
2. Python 字符串操作简洁：`d * len(s)` 重复字符 `d` 共 `len(s)` 次

## 易错点

1. 最大数字是**数字字符**中的最大（0-9），不是数值本身
2. 位数与原数相同
