## 题目描述

给定一个排序的整数数组 `nums`，其中元素的范围在闭区间 `[lower, upper]` 当中，返回不包含在数组中的缺失区间。

**示例 1：**
```
输入：nums = [0, 1, 3, 50, 75], lower = 0, upper = 99
输出：[[2,2],[4,49],[51,74],[76,99]]
解释：返回的区间是：
[2,2]
[4,49]
[51,74]
[76,99]
```

**示例 2：**
```
输入：nums = [-1], lower = -1, upper = -1
输出：[]
解释：没有缺失的区间，因为没有被覆盖的数字。
```

**提示：**
- -10^9 <= lower <= upper <= 10^9
- 0 <= nums.length <= 100
- lower <= nums[i] <= upper
- nums 中的所有值互不相同

## 解题描述

这道题要求找出 [lower, upper] 范围内，不在 nums 数组中的所有缺失区间。

**核心思路：**

1. **遍历数组**，检查相邻元素之间的间隙
2. **特殊处理**：
   - 第一个元素前的间隙（从 lower 到 nums[0] - 1）
   - 相邻元素之间的间隙
   - 最后一个元素后的间隙（从 nums[-1] + 1 到 upper）

3. **间隙判断**：
   - 如果前一个数 + 1 < 后一个数，说明有缺失区间
   - 缺失区间为 [前一个数 + 1, 后一个数 - 1]

**算法流程：**

1. 初始化 prev = lower - 1（虚拟的前一个数）
2. 遍历 nums + [upper + 1]（添加虚拟的后一个数）
3. 对于每个当前数 curr：
   - 如果 prev + 1 < curr，存在缺失区间 [prev + 1, curr - 1]
   - 更新 prev = curr

## Python 代码实现

### 方法一：一次遍历（推荐）⭐

```python
from typing import List

class Solution:
    def findMissingRanges(self, nums: List[int], lower: int, upper: int) -> List[List[int]]:
        """
        一次遍历找到所有缺失区间
        时间复杂度：O(n)，其中 n 是数组长度
        空间复杂度：O(1)，不计入结果数组
        """
        result = []
        
        # prev 表示前一个已处理的数字
        # 初始化为 lower - 1，便于处理第一个元素前的间隙
        prev = lower - 1
        
        # 在数组末尾添加 upper + 1，统一处理最后的间隙
        for curr in nums + [upper + 1]:
            # 检查是否有缺失区间
            if prev + 1 < curr:
                # 缺失区间的起点
                start = prev + 1
                # 缺失区间的终点
                end = curr - 1
                
                # 添加缺失区间
                result.append([start, end])
            
            # 更新 prev
            prev = curr
        
        return result
```

### 方法二：分段处理（更清晰）

```python
class Solution:
    def findMissingRanges(self, nums: List[int], lower: int, upper: int) -> List[List[int]]:
        """
        分段处理：前部、中间、后部
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        result = []
        n = len(nums)
        
        # 特殊情况：空数组
        if n == 0:
            return [[lower, upper]]
        
        # 1. 处理第一个元素前的间隙
        if nums[0] > lower:
            result.append([lower, nums[0] - 1])
        
        # 2. 处理相邻元素之间的间隙
        for i in range(1, n):
            if nums[i] - nums[i - 1] > 1:
                result.append([nums[i - 1] + 1, nums[i] - 1])
        
        # 3. 处理最后一个元素后的间隙
        if nums[-1] < upper:
            result.append([nums[-1] + 1, upper])
        
        return result
```

### 方法三：辅助函数版本

```python
class Solution:
    def findMissingRanges(self, nums: List[int], lower: int, upper: int) -> List[List[int]]:
        """
        使用辅助函数格式化区间
        """
        def add_range(result: List[List[int]], start: int, end: int) -> None:
            """添加缺失区间到结果中"""
            if start <= end:
                result.append([start, end])
        
        result = []
        prev = lower - 1
        
        for i in range(len(nums)):
            curr = nums[i]
            # 添加 prev+1 到 curr-1 的缺失区间
            add_range(result, prev + 1, curr - 1)
            prev = curr
        
        # 添加最后的缺失区间
        add_range(result, prev + 1, upper)
        
        return result
```

### 方法四：字符串格式版本（如果题目要求返回字符串）

```python
class Solution:
    def findMissingRanges(self, nums: List[int], lower: int, upper: int) -> List[str]:
        """
        返回字符串格式的缺失区间
        格式：单个数字 "x"，区间 "x->y"
        """
        def format_range(start: int, end: int) -> str:
            """格式化区间为字符串"""
            if start == end:
                return str(start)
            else:
                return f"{start}->{end}"
        
        result = []
        prev = lower - 1
        
        for curr in nums + [upper + 1]:
            if prev + 1 <= curr - 1:
                result.append(format_range(prev + 1, curr - 1))
            prev = curr
        
        return result
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是数组长度，需要遍历数组一次
- 空间复杂度：O(1)，不计入结果数组的空间

## 图解示例

示例 1：nums = [0, 1, 3, 50, 75], lower = 0, upper = 99

```
lower = 0                                    upper = 99

|   |       |               |       |                |
    
缺失区间：
1. nums[0]=0 前：无缺失（0 == lower）
2. 0 和 1 之间：无缺失（连续）
3. 1 和 3 之间：[2, 2]
4. 3 和 50 之间：[4, 49]
5. 50 和 75 之间：[51, 74]

```

```
lower = -1, upper = -1, nums = [-1]

```

## 关键点总结

1. **虚拟边界**：使用 prev = lower - 1 和 添加 upper + 1 简化边界处理
2. **间隙判断**：prev + 1 < curr 表示有缺失区间
3. **区间表示**：缺失区间为 [prev + 1, curr - 1]
4. **边界情况**：空数组、单元素数组、完全覆盖等
5. **统一处理**：通过添加虚拟边界，统一处理所有情况

## 易错点

1. **边界处理**：
   - 忘记处理第一个元素前的间隙
   - 忘记处理最后一个元素后的间隙
2. **间隙判断条件**：
   - 应该是 `prev + 1 < curr`，不是 `prev < curr`
   - 缺失区间是 `[prev + 1, curr - 1]`
3. **空数组**：nums 为空时，整个 [lower, upper] 都是缺失区间
4. **单点区间**：start == end 时也是有效的缺失区间
5. **完全覆盖**：nums 恰好覆盖 [lower, upper] 时返回空列表
