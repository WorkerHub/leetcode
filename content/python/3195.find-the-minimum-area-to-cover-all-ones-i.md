## 题目描述

给你一个二进制矩阵 `grid`，找到包含所有值为 1 的格子的 **最小面积矩形**（边平行于坐标轴）。

返回该矩形的面积。**保证矩阵中至少有一个 1。**

**示例 1：**
```
输入：grid = [[0,1,0],[1,0,1]]
输出：6
解释：包含所有 1 的最小矩形为第0-1行、第0-2列，面积 = 2 * 3 = 6
```

**示例 2：**
```
输入：grid = [[1,0],[0,1]]
输出：4
```

**提示：**
- `1 <= m, n <= 1000`
- `grid[i][j] == 0 or 1`

## 解题思路

找所有 1 的行范围 [min_r, max_r] 和列范围 [min_c, max_c]，面积 = (max_r - min_r + 1) * (max_c - min_c + 1)。

## Python 代码实现

### 方法一：边界扫描（推荐）

```python
from typing import List

class Solution:
    def minimumArea(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        min_r = m
        max_r = -1
        min_c = n
        max_c = -1

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    min_r = min(min_r, i)
                    max_r = max(max_r, i)
                    min_c = min(min_c, j)
                    max_c = max(max_c, j)

        return (max_r - min_r + 1) * (max_c - min_c + 1)
```

### 方法二：使用生成器

```python
from typing import List

class Solution:
    def minimumArea(self, grid: List[List[int]]) -> int:
        ones = [(i, j) for i in range(len(grid)) for j in range(len(grid[0])) if grid[i][j] == 1]
        rows = [i for i, j in ones]
        cols = [j for i, j in ones]
        return (max(rows) - min(rows) + 1) * (max(cols) - min(cols) + 1)
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 找所有 1 的行和列的最小/最大值
2. 面积 = 行范围长度 * 列范围长度

## 易错点

1. 行列范围都是闭区间，长度要 +1
2. 保证至少有一个 1，无需处理边界情况
