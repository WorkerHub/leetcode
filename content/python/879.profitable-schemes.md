## 题目描述

集团里有 n 名员工，他们可以完成各种各样的工作创造利润。

第 i 种工作会产生 profit[i] 的利润，它要求 group[i] 名成员共同参与。如果成员参与了其中一项工作，就不能参与另一项工作。

工作的任何至少产生 minProfit 利润的子集称为盈利计划 。并且工作的成员总数最多为 n 。

有多少种计划可以选择？因为答案很大，所以 返回结果模 10^9 + 7 的值。

**提示：**
- 1 <= n <= 100
- 0 <= minProfit <= 100
- 1 <= group.length <= 100
- 1 <= group[i] <= 100
- profit.length == group.length
- 0 <= profit[i] <= 100

## 解题思路

**三维DP：**
- `dp[i][j][k]` = 前 i 个工作，使用 j 个员工，利润至少为 k 的方案数

## Python 代码实现

```python
class Solution:
    def profitableSchemes(self, n: int, minProfit: int, group: List[int], profit: List[int]) -> int:
        MOD = 10**9 + 7
        m = len(group)
        
        # dp[i][j] = 使用 i 个员工，利润至少为 j 的方案数
        dp = [[0] * (minProfit + 1) for _ in range(n + 1)]
        dp[0][0] = 1
        
        for g, p in zip(group, profit):
            # 从后往前遍历，避免重复使用
            for i in range(n, g - 1, -1):
                for j in range(minProfit, -1, -1):
                    # 新利润，最多到 minProfit
                    new_profit = min(minProfit, j + p)
                    dp[i][new_profit] = (dp[i][new_profit] + dp[i - g][j]) % MOD
        
        return sum(dp[i][minProfit] for i in range(n + 1)) % MOD
```

## 复杂度分析

- **时间复杂度**：O(m × n × minProfit)
- **空间复杂度**：O(n × minProfit)

## 关键点总结

1. **DP状态设计**：使用员工数和利润两个维度
2. **利润上限**：超过 minProfit 都算达标
3. **倒序遍历**：避免重复使用同一工作
