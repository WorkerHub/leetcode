## 题目描述

给你一个长度为 `n` 的二进制数组 `nums`，整数 `k` 和整数 `maxChanges`。

每次操作：
1. **变更：** 将 `nums[aliceIndex]`（Alice 当前位置的相邻位置）变为 1（最多 `maxChanges` 次）
2. **移动：** Alice 从 `aliceIndex` 移动到相邻格，若相邻格为 1，则拾起（变为 0）

Alice 拾起 k 个 1，返回最少操作次数。

**提示：**
- `2 <= n <= 10^5`
- `0 <= nums[i] <= 1`
- `1 <= k <= 10^5`
- `0 <= maxChanges <= 10^5`

## 解题思路

分析 Alice 在位置 `aliceIndex` 时：
1. 首先可以利用 `maxChanges` 次变更，在 2 步内拾起一个 1（移动到相邻 + 拾起，共 2 步；或直接在当前位置变更并拾起，1 步）
2. 其次可以利用周围已有的 1（在距离 1 内），0 步移动就能拾起
3. 最后需要移动到更远的 1 处

贪心策略：枚举 Alice 的初始位置，对于每个位置：
- 先拾起相邻的最多 3 个 1（1 的位置）
- 用 `maxChanges` 变更（每次 2 步）
- 剩余的 1 从最近的位置开始拾起

最终用滑动窗口在"1 的位置"数组上维护中位数，计算移动代价。

## Python 代码实现

### 方法一：枚举起始位置 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def minimumMoves(self, nums: List[int], k: int, maxChanges: int) -> int:
        n = len(nums)
        ones = [i for i, x in enumerate(nums) if x == 1]
        m = len(ones)

        # 1 的前缀和（用于计算区间内所有 1 的位置之和）
        prefix = [0] * (m + 1)
        for i in range(m):
            prefix[i + 1] = prefix[i] + ones[i]

        def cost_window(l, r, mid):
            """计算 ones[l..r] 中所有元素移动到 ones[mid] 的总距离"""
            # 左半：ones[l..mid]
            cnt_left = mid - l + 1
            sum_left = prefix[mid + 1] - prefix[l]
            left_cost = ones[mid] * cnt_left - sum_left

            # 右半：ones[mid..r]
            cnt_right = r - mid + 1
            sum_right = prefix[r + 1] - prefix[mid]
            right_cost = sum_right - ones[mid] * cnt_right

            return left_cost + right_cost

        ans = float('inf')

        # 枚举 Alice 起始位置
        for start in range(n):
            # 计算在 start 位置能直接拾起几个 1（距离 0 或 1）
            free = sum(1 for d in [-1, 0, 1] if 0 <= start + d < n and nums[start + d] == 1)
            free = min(free, k)

            # 通过变更拾起
            change_pick = min(maxChanges, k - free)
            remaining = k - free - change_pick
            total_cost = change_pick * 2

            if remaining <= 0:
                ans = min(ans, total_cost)
                continue

            # 需要从更远的位置拾起 remaining 个 1
            # 找 ones 中离 start 最近的 remaining 个 1（不包括已拾取的）
            # 这部分用滑动窗口计算

            # 简化：此处用 O(m) 的方式对每个起始点计算
            # 实际上应枚举窗口，使用中位数最优化
            # 为简化实现，枚举所有可能的窗口中心

            # 在 ones 中找到 start 的位置（二分）
            import bisect
            pos = bisect.bisect_left(ones, start)

            # 用大小为 remaining 的滑动窗口在 ones 上滑动
            if remaining > m:
                continue  # 无法拾起足够的 1

            for window_start in range(m - remaining + 1):
                window_end = window_start + remaining - 1
                mid = (window_start + window_end) // 2
                # 总移动距离 = 从 start 到 ones[mid] + ones[window_start..window_end] 到 ones[mid]
                move_to_mid = abs(start - ones[mid])
                spread_cost = cost_window(window_start, window_end, mid)
                ans = min(ans, total_cost + move_to_mid + spread_cost)

        return ans
```

### 方法二：滑动窗口优化（O(n + m log m)）

```python
from typing import List
import bisect

class Solution:
    def minimumMoves(self, nums: List[int], k: int, maxChanges: int) -> int:
        ones = [i for i, x in enumerate(nums) if x == 1]
        m = len(ones)

        if m == 0 and k == 0:
            return 0

        prefix = [0] * (m + 1)
        for i in range(m):
            prefix[i + 1] = prefix[i] + ones[i]

        def window_cost(l, r, mid_idx):
            cnt_l = mid_idx - l + 1
            cost_l = ones[mid_idx] * cnt_l - (prefix[mid_idx + 1] - prefix[l])
            cnt_r = r - mid_idx + 1
            cost_r = (prefix[r + 1] - prefix[mid_idx]) - ones[mid_idx] * cnt_r
            return cost_l + cost_r

        ans = float('inf')
        n = len(nums)

        # 枚举 Alice 起始位置
        for si in range(n):
            # 附近最多 3 个可用的 1
            near = [si + d for d in (-1, 0, 1) if 0 <= si + d < n and nums[si + d]]
            free = min(len(near), k)
            need_change = min(maxChanges, k - free)
            need_window = k - free - need_change
            base = need_change * 2

            if need_window <= 0:
                ans = min(ans, base)
                continue
            if need_window > m:
                continue

            # 在 ones 中滑动窗口大小为 need_window，中心索引 mid
            for l in range(m - need_window + 1):
                r = l + need_window - 1
                mid = (l + r) // 2
                cost = base + abs(si - ones[mid]) + window_cost(l, r, mid)
                ans = min(ans, cost)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * m)，枚举起始位置和窗口
- 优化：O((n + m) log m)，使用双指针
- 空间复杂度：O(m)

## 关键点总结

1. 贪心：先用相邻 1，再用变更，最后移动到更远的 1
2. 滑动窗口在 1 的位置数组上移动，以中位数为集合中心最优
3. 前缀和快速计算区间元素到中位数的距离和

## 易错点

1. "变更"操作每次 2 步（移动 + 拾起），不是 1 步
2. 附近的 1 最多 3 个（距离 <= 1），只需 0 或 1 步
3. 滑动窗口的中心是中位数（最小化总移动距离）
