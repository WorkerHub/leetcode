## 题目描述

给你一个整数数组 `nums`，将 `nums` 中的所有偶数元素移动到数组的前面，后跟所有奇数元素。

返回满足此条件的 **任一数组** 作为答案。

**示例 1：**
```
输入：nums = [3,1,2,4]
输出：[2,4,3,1]
解释：[4,2,3,1]、[2,4,1,3] 和 [4,2,1,3] 也会被视作正确答案。
```

**示例 2：**
```
输入：nums = [0]
输出：[0]
```

**提示：**
- `1 <= nums.length <= 5000`
- `0 <= nums[i] <= 5000`

## 解题思路

这道题要求将偶数元素移到前面，奇数元素移到后面，顺序不重要。有多种解法：

1. **双指针法（原地交换）**：使用两个指针，一个从前往后找奇数，一个从后往前找偶数，然后交换
2. **新数组法**：遍历一遍，偶数放前面，奇数放后面
3. **排序法**：使用自定义排序规则
4. **双指针填充法**：两次遍历，第一次填充偶数，第二次填充奇数

## Python 代码实现

### 方法一：双指针原地交换（推荐 ⭐）

```python
from typing import List

class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        # 左指针指向下一个应该放偶数的位置
        # 右指针指向下一个应该放奇数的位置
        left, right = 0, len(nums) - 1
        
        while left < right:
            # 如果左边是奇数，右边是偶数，交换
            if nums[left] % 2 > nums[right] % 2:
                nums[left], nums[right] = nums[right], nums[left]
            
            # 如果左边是偶数，左指针右移
            if nums[left] % 2 == 0:
                left += 1
            
            # 如果右边是奇数，右指针左移
            if nums[right] % 2 == 1:
                right -= 1
        
        return nums
```

**优化版本：**

```python
from typing import List

class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        left, right = 0, len(nums) - 1
        
        while left < right:
            # 左指针找到第一个奇数
            while left < right and nums[left] % 2 == 0:
                left += 1
            
            # 右指针找到第一个偶数
            while left < right and nums[right] % 2 == 1:
                right -= 1
            
            # 交换奇数和偶数
            if left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1
        
        return nums
```

### 方法二：新数组法（最简单）

```python
from typing import List

class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        # 先放所有偶数，再放所有奇数
        return [x for x in nums if x % 2 == 0] + [x for x in nums if x % 2 == 1]
```

### 方法三：单指针原地调整

```python
from typing import List

class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        # j 指向下一个偶数应该放的位置
        j = 0
        
        for i in range(len(nums)):
            # 如果当前元素是偶数，与 j 位置交换
            if nums[i] % 2 == 0:
                nums[i], nums[j] = nums[j], nums[i]
                j += 1
        
        return nums
```

### 方法四：使用排序

```python
from typing import List

class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        # 按照奇偶性排序，偶数(% 2 == 0)在前
        return sorted(nums, key=lambda x: x % 2)
```

## 复杂度分析

**方法一：双指针原地交换**
- 时间复杂度：O(n)，只需要遍历一遍数组
- 空间复杂度：O(1)，原地修改

**方法二：新数组法**
- 时间复杂度：O(n)，需要遍历两次数组
- 空间复杂度：O(n)，需要额外的数组空间

**方法三：单指针原地调整**
- 时间复杂度：O(n)，遍历一遍数组
- 空间复杂度：O(1)，原地修改

**方法四：使用排序**
- 时间复杂度：O(n log n)，排序的时间复杂度
- 空间复杂度：O(n)，排序需要额外空间

## 关键点总结

1. **双指针技巧**：从两端向中间扫描，找到需要交换的位置
2. **奇偶判断**：使用 `x % 2` 判断，偶数为 0，奇数为 1
3. **原地修改**：可以在 O(1) 空间内完成
4. **顺序不重要**：题目只要求偶数在前，奇数在后，不要求保持原有顺序
5. **多种解法**：可以用双指针、单指针、新数组、排序等多种方法

## 易错点

1. **边界条件**：注意 `left < right` 的判断，避免越界
2. **指针移动时机**：在双指针法中，要确保交换后指针正确移动
3. **空数组或单元素**：虽然题目保证 `length >= 1`，但要注意单元素情况
4. **判断条件**：`nums[left] % 2 > nums[right] % 2` 可以简化判断逻辑
