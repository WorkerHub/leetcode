## 题目描述

字符串的移位是指将字符串中每个字母按照字母表的顺序向某个方向移动固定的步数。例如，将 "abc" 移位 1 步得到 "bcd"，移位 2 步得到 "cde"。

给定一个字符串列表，将相同移位序列的所有字符串分组在一起。你可以按任意顺序返回答案。

**示例 1：**
```
输入: strings = ["abc","bcd","acef","xyz","az","ba","a","z"]
输出: [["acef"],["a","z"],["abc","bcd","xyz"],["az","ba"]]
```

**示例 2：**
```
输入: strings = ["a"]
输出: [["a"]]
```

**提示：**
- 1 <= strings.length <= 200
- 1 <= strings[i].length <= 50
- strings[i] 由小写英文字母组成

## 解题思路

这道题的核心是找到一个**规范化的表示方法**，使得同一移位序列的字符串有相同的特征。

**核心思想：**
- 两个字符串属于同一移位序列，当且仅当它们相邻字符间的"距离"序列相同
- 例如 "abc" 和 "xyz"：
  - "abc": b-a=1, c-b=1 → [1, 1]
  - "xyz": y-x=1, z-y=1 → [1, 1]
  - 它们有相同的距离序列，属于同一组

**关键观察：**
1. **距离序列**：相邻字符的距离差，如 "abc" → (1,1)，"az" → (25)
2. **循环性**：字母表是循环的，'z' 到 'a' 的距离是 1
3. **单字符特殊情况**：单个字符的字符串应该独立分组

**算法设计：**
1. 计算每个字符串的距离序列作为哈希键
2. 使用哈希表将相同距离序列的字符串分组
3. 返回哈希表的所有值

## Python 代码实现

### 方法一：距离序列哈希（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        """
        使用相邻字符距离序列作为哈希键
        时间复杂度：O(n * k)，n 是字符串数量，k 是平均字符串长度
        空间复杂度：O(n * k)
        """
        groups = defaultdict(list)
        
        for s in strings:
            # 计算距离序列
            key = self.getKey(s)
            groups[key].append(s)
        
        return list(groups.values())
    
    def getKey(self, s: str) -> tuple:
        """
        计算字符串的距离序列
        返回元组作为哈希键
        """
        if len(s) == 1:
            return ()  # 单字符返回空元组
        
        distances = []
        for i in range(1, len(s)):
            # 计算相邻字符的距离（处理循环）
            distance = (ord(s[i]) - ord(s[i-1])) % 26
            distances.append(distance)
        
        return tuple(distances)
```

### 方法二：规范化到 'a' 开头（另一种思路）

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        """
        将每个字符串规范化为以 'a' 开头的形式
        时间复杂度：O(n * k)
        空间复杂度：O(n * k)
        """
        groups = defaultdict(list)
        
        for s in strings:
            # 规范化：将第一个字符移位到 'a'
            key = self.normalize(s)
            groups[key].append(s)
        
        return list(groups.values())
    
    def normalize(self, s: str) -> str:
        """
        将字符串规范化为以 'a' 开头
        """
        if not s:
            return ""
        
        # 计算需要移动的步数（使第一个字符变成 'a'）
        shift = ord(s[0]) - ord('a')
        
        # 对每个字符执行反向移位
        normalized = []
        for char in s:
            new_char = chr((ord(char) - shift) % 26 + ord('a'))
            normalized.append(new_char)
        
        return ''.join(normalized)
```

### 方法三：优化的距离序列（字符串拼接）

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        """
        使用字符串表示距离序列
        时间复杂度：O(n * k)
        空间复杂度：O(n * k)
        """
        groups = defaultdict(list)
        
        for s in strings:
            key = self.getSignature(s)
            groups[key].append(s)
        
        return list(groups.values())
    
    def getSignature(self, s: str) -> str:
        """
        生成字符串的特征签名
        使用逗号分隔的距离序列
        """
        if len(s) <= 1:
            return ""
        
        signature = []
        for i in range(1, len(s)):
            # 计算距离并处理负数情况
            diff = (ord(s[i]) - ord(s[i-1]) + 26) % 26
            signature.append(str(diff))
        
        return ','.join(signature)
```

### 方法四：使用列表推导式（Pythonic）

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        """
        Python 简洁写法
        """
        def getKey(s):
            # 单字符特殊处理
            if len(s) == 1:
                return ()
            # 计算相邻字符距离
            return tuple((ord(s[i]) - ord(s[i-1])) % 26 for i in range(1, len(s)))
        
        groups = defaultdict(list)
        for s in strings:
            groups[getKey(s)].append(s)
        
        return list(groups.values())
```

### 方法五：处理边界情况的完整版本

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        """
        完整处理各种边界情况
        """
        if not strings:
            return []
        
        groups = defaultdict(list)
        
        for s in strings:
            # 空字符串处理
            if not s:
                groups[('empty',)].append(s)
                continue
            
            # 单字符处理
            if len(s) == 1:
                groups[('single',)].append(s)
                continue
            
            # 计算距离序列
            key = tuple(
                (ord(s[i]) - ord(s[i-1]) + 26) % 26 
                for i in range(1, len(s))
            )
            groups[key].append(s)
        
        return list(groups.values())
```

## 复杂度分析

所有方法的复杂度类似：
- **时间复杂度**：O(n * k)，其中 n 是字符串数量，k 是平均字符串长度
- **空间复杂度**：O(n * k)，存储所有字符串和哈希表

## 图解示例

**示例 1：strings = ["abc","bcd","acef","xyz","az","ba","a","z"]**

```
计算每个字符串的距离序列：

"abc":  b-a=1, c-b=1        → (1, 1)
"bcd":  c-b=1, d-c=1        → (1, 1)
"xyz":  y-x=1, z-y=1        → (1, 1)

"acef": c-a=2, e-c=2, f-e=1 → (2, 2, 1)

"az":   z-a=25              → (25,)
"ba":   a-b=(1-2+26)%26=25  → (25,)

"a":    单字符              → ()
"z":    单字符              → ()

分组结果：
  (1, 1):    ["abc", "bcd", "xyz"]
  (2, 2, 1): ["acef"]
  (25,):     ["az", "ba"]
  ():        ["a", "z"]
```

**为什么 "az" 和 "ba" 是同一组？**
```
"az": a → z 是向前移动 25 步（或向后移动 1 步）
"ba": b → a 是向前移动 25 步（或向后移动 1 步）

它们的移位模式相同！
```

## 关键点总结

1. **距离序列**：相邻字符的距离差是判断移位序列的关键
2. **循环处理**：使用 `% 26` 处理字母表的循环性
3. **元组作为键**：列表不可哈希，要转换成元组
4. **单字符处理**：单字符串应该独立分组（或根据题意处理）
5. **defaultdict**：简化分组代码，避免判断键是否存在

## 易错点

1. **负数处理**：`(ord(s[i]) - ord(s[i-1])) % 26` 可能是负数，要加 26
2. **单字符**：忘记特殊处理单字符字符串
3. **列表作为键**：列表不可哈希，要转成元组
4. **空字符串**：虽然题目说长度 >= 1，但良好的习惯是处理空字符串
5. **距离计算**：要理解 "az" 的距离是 25，不是 -1

**常见追问：**
- Q: 为什么 "az" 和 "ba" 是同一组？
