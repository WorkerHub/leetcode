## 题目描述

给你一个字符串 `s`，一个字符串 `chars` 和一个整数数组 `vals`，两者长度相同。字符串 `chars` 中的第 `i` 个字符的价值为 `vals[i]`，其余字符的价值为其在字母表中的位置（`a` 的价值为 1，`b` 的价值为 2，以此类推）。

子字符串的代价是其中所有字符价值的总和。返回字符串 `s` 的所有子字符串中的最大代价。

**示例 1：**
```
输入：s = "adaa", chars = "d", vals = [-1000]
输出：2
解释：字符 d 价值 -1000，其他字母价值为字母序号
子串 "aa" 代价 = 1+1 = 2
```

**示例 2：**
```
输入：s = "abc", chars = "abc", vals = [-1,-1,-1]
输出：0
解释：所有字符价值为 -1，空子串代价为 0
```

**数据范围：**
- 1 <= s.length <= 10^5
- s 只含小写英文字母
- 1 <= chars.length == vals.length <= 26

## 解题思路

Kadane 算法（最大子数组和）：

1. 先构建每个字符对应的价值映射
2. 将字符串 `s` 转化为价值数组
3. 对价值数组使用 Kadane 算法求最大子数组和

Kadane 算法核心：维护当前最大子数组和 `cur`，若 `cur < 0` 则重置为 0（空子串代价为 0，所以结果不小于 0）。

## Python 代码实现

### 方法一：Kadane 算法（推荐）

```python
from typing import List

class Solution:
    def maximumCostSubstring(self, s: str, chars: str, vals: List[int]) -> int:
        # 构建字符价值映射：默认为字母序号
        cost = {chr(ord('a') + i): i + 1 for i in range(26)}
        # 覆盖自定义价值
        for c, v in zip(chars, vals):
            cost[c] = v

        # Kadane 算法求最大子数组和
        ans = 0
        cur = 0
        for c in s:
            cur += cost[c]
            if cur < 0:
                cur = 0  # 负数代价直接重置，相当于从空子串开始
            ans = max(ans, cur)

        return ans
```

### 方法二：显式转化价值数组

```python
from typing import List

class Solution:
    def maximumCostSubstring(self, s: str, chars: str, vals: List[int]) -> int:
        # 构建价值映射
        val_map = {}
        for c, v in zip(chars, vals):
            val_map[c] = v

        def get_val(c):
            return val_map.get(c, ord(c) - ord('a') + 1)

        # 转化为价值数组
        values = [get_val(c) for c in s]

        # Kadane 算法
        max_sum = 0
        cur_sum = 0
        for v in values:
            cur_sum = max(0, cur_sum + v)
            max_sum = max(max_sum, cur_sum)

        return max_sum
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)，仅用常数额外空间（价值映射大小固定为 26）

## 关键点总结

1. 将字符串问题转化为最大子数组和问题
2. Kadane 算法是求最大子数组和的经典线性算法
3. 空子串代价为 0，因此结果不小于 0

## 易错点

1. 需要先设置默认字母序号，再用 `chars/vals` 覆盖
2. 允许空子串，初始答案为 0
3. `cur < 0` 时重置为 0 而非跳过当前字符
