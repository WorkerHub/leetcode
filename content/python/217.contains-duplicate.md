## 题目描述

给你一个整数数组 `nums`。如果任一值在数组中出现 **至少两次**，返回 `true`；如果数组中每个元素互不相同，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1]
输出：true
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：false
```

**示例 3：**

```
输入：nums = [1,1,1,3,3,4,3,2,4,2]
输出：true
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这是一道简单题，主要考察基础数据结构的使用。

**核心思想：**

判断数组中是否有重复元素，本质上是检查是否有两个相同的值。

**多种解法：**

1. **哈希集合**：遍历数组，将元素加入集合，如果已存在则返回 true
2. **排序**：排序后检查相邻元素是否相同
3. **集合长度**：将数组转为集合，比较长度是否变化
4. **字典计数**：统计每个元素出现次数（过度设计）

## Python 代码实现

### 方法一：哈希集合（推荐）⭐

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        """使用集合检测重复"""
        seen = set()
        for num in nums:
            if num in seen:
                return True
            seen.add(num)
        return False
```

### 方法二：集合长度比较（最简洁）

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        """集合会自动去重"""
        return len(nums) != len(set(nums))
```

### 方法三：排序后检查

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        """排序后相同元素会相邻"""
        nums.sort()
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                return True
        return False
```

### 方法四：使用 Counter（过度设计）

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        """计数器统计频率"""
        from collections import Counter
        counter = Counter(nums)
        # 检查是否有元素出现次数 > 1
        return any(count > 1 for count in counter.values())
```

### 方法五：One-liner（炫技版）

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return len(nums) > len(set(nums))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希集合（方法一） | O(N) | O(N) | 最优时间，平均情况最快 |
| 集合长度（方法二） | O(N) | O(N) | 代码最简洁 |
| 排序（方法三） | O(N log N) | O(1) 或 O(N) | 时间慢但空间可能更优 |
| Counter（方法四） | O(N) | O(N) | 功能过剩 |

**推荐：** 方法二（集合长度比较），代码简洁且性能优秀

## 关键点总结

1. **集合特性**：自动去重，可用于检测重复
2. **提前返回**：方法一遇到重复立即返回，不需遍历全部
3. **空间换时间**：使用 O(N) 空间换取 O(N) 时间
4. **排序思想**：排序后重复元素相邻，便于检测
5. **Python 特性**：灵活使用内置数据结构简化代码

## 易错点

1. **集合创建开销**：
   ```python
   # 注意：set(nums) 本身就是 O(N) 时间
   # 以下两种写法性能接近
   return len(nums) != len(set(nums))  # 创建完整集合
   # vs
   seen = set()
   for num in nums:  # 可能提前返回
       if num in seen:
           return True
   ```

2. **排序修改原数组**：
   ```python
   # 如果不能修改原数组
   sorted_nums = sorted(nums)  # 创建新数组
   # 如果可以修改
   nums.sort()  # 原地排序
   ```

3. **空数组处理**：
   ```python
   # 题目保证 nums.length >= 1，但自测时注意
   nums = []  # 应返回 False
   ```

4. **集合的 in 操作**：
   ```python
   # 正确：集合的 in 是 O(1)
   if num in seen:
   # 错误：列表的 in 是 O(N)
   if num in seen_list:
   ```

5. **性能误区**：
   ```python
   # 认为方法一更快，实际上方法二更简洁且性能相当
   # 方法一优势：找到重复立即返回
   # 方法二优势：代码极简
   ```

## 图解示例

```
示例：nums = [1,2,3,1]

方法一（哈希集合）：
遍历过程：
num=1: seen={} → seen={1}
num=2: seen={1} → seen={1,2}
num=3: seen={1,2} → seen={1,2,3}
num=1: seen={1,2,3}，1 已存在，返回 True

方法二（集合长度）：
nums = [1,2,3,1]
set(nums) = {1,2,3}
len(nums) = 4
len(set(nums)) = 3
4 != 3，返回 True

方法三（排序）：
排序前：[1,2,3,1]
排序后：[1,1,2,3]
检查相邻：nums[1] == nums[0]，返回 True
```

   ```python
   def find_duplicates(nums):
       seen = set()
       duplicates = set()
       for num in nums:
           if num in seen:
               duplicates.add(num)
           seen.add(num)
       return list(duplicates)
   ```
