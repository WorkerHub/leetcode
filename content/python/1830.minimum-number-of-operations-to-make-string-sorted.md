## 题目描述

给你一个字符串 `s`，每次操作：找到最大的 `i` 使得 `s[i] < s[i+1]`，将 `s[i]` 与所有 `s[j]`（`j > i` 且 `s[j] == s[i+1]` 的所有 j 的最小值）交换，然后对 `s[i+1:]` 进行升序排列。

重复操作直到字符串完全降序排列，返回操作次数对 `10^9+7` 取余。

**示例 1：**
```
输入：s = "cba"
输出：5
```

**示例 2：**
```
输入：s = "aabb"
输出：2
```

## 解题思路

本题等价于：求字符串 `s` 的字典序排名（在所有相同字符的排列中排第几），也就是比 `s` 字典序小的排列数量。

**计算逆序数/排名公式**（使用组合数学）：

对于字符串的每个位置 `i`，计算比 `s[i]` 小的字符个数（在 `s[i:]` 中），设为 `smaller`，那后缀 `s[i+1:]` 的排列数为 `len(s[i:])-1` 的多重全排列数。这类似于将字符串转为混合进制数。

具体公式：
设后缀 `s[i:]` 有 `m = len(s) - i` 个字符，各字符频率为 `c[ch]`，则排名贡献为：
`smaller * (m-1)! / (c[s[0]]! * c[s[1]]! * ... * c[s[25]]!)`（乘以模逆元）

## 代码实现

### 方法一：组合数学（推荐）

```python
MOD = 10 ** 9 + 7

class Solution:
    def makeStringSorted(self, s: str) -> int:
        n = len(s)
        # 预计算阶乘和逆阶乘
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        from collections import Counter
        cnt = Counter(s)

        result = 0
        # 当前后缀的多重排列分母（各字符频率的阶乘之积）
        # 维护 inv_denom = 1 / (cnt[a]! * cnt[b]! * ... )
        inv_denom = 1
        for c in cnt.values():
            inv_denom = inv_denom * inv_fact[c] % MOD

        for i in range(n):
            ch = s[i]
            m = n - i  # 后缀长度
            # 比 ch 小的字符个数
            smaller = sum(v for k, v in cnt.items() if k < ch)
            # 贡献：smaller * (m-1)! * inv_denom
            result = (result + smaller * fact[m - 1] % MOD * inv_denom) % MOD

            # 更新 cnt：移除 s[i]
            # inv_denom 中 cnt[ch]! 变为 (cnt[ch]-1)!，需要乘以 cnt[ch] 的逆元（即除以 cnt[ch]）
            inv_denom = inv_denom * cnt[ch] % MOD  # 因为 inv_fact[k-1] = inv_fact[k] * k
            cnt[ch] -= 1
            if cnt[ch] == 0:
                del cnt[ch]

        return result
```

### 方法二：直接计算每位贡献

```python
from collections import Counter

MOD = 10 ** 9 + 7

class Solution:
    def makeStringSorted(self, s: str) -> int:
        n = len(s)
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD

        def mod_inv(x: int) -> int:
            return pow(x, MOD - 2, MOD)

        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1

        result = 0
        for i in range(n):
            idx = ord(s[i]) - ord('a')
            m = n - i

            # 比 s[i] 小的字符总数
            smaller = sum(cnt[:idx])

            # (m-1)! / prod(cnt[j]! for j in 0..25)
            perm = fact[m - 1]
            for c in cnt:
                perm = perm * pow(fact[c], MOD - 2, MOD) % MOD

            result = (result + smaller * perm) % MOD
            cnt[idx] -= 1

        return result
```

## 复杂度分析

- **时间复杂度**：O(n * 26)，每个字符处理时遍历 26 个字母
- **空间复杂度**：O(n)，阶乘数组

## 关键点总结

1. 操作次数等于字符串在所有排列中的字典序排名（从 1 到全排列数）
2. 每一位的贡献：比当前字符小的字符数 × 后缀的多重排列数
3. 用费马小定理求模逆元，实现模意义下的除法

## 易错点

- 多重全排列数需要除以每个字符频率的阶乘
- 维护 inv_denom 时，移除字符 ch 后，cnt[ch]! 变为 (cnt[ch]-1)!，需乘以 cnt[ch]
