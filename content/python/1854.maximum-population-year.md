## 题目描述

给你一个二维整数数组 `logs`，其中 `logs[i] = [birthi, deathi]` 表示第 i 个人的出生年份和死亡年份（人在 `[birthi, deathi - 1]` 期间是存活的）。

年份范围为 1950 到 2050。

返回**人口最多**的年份，若有多个相同，返回**最小**的那个年份。

**示例：**
```
输入：logs = [[1993,1999],[2000,2010]]
输出：1993
```

## 解题思路

**差分数组**：

在出生年份 +1，死亡年份 -1（每个人存活在 `[birth, death-1]`）。

对差分数组求前缀和得到每年的人口数，找最大值对应的年份。

年份范围 1950 到 2050，长度 101，可以用小数组。

## 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def maximumPopulation(self, logs: List[List[int]]) -> int:
        # 差分数组，下标 0 对应 1950 年
        diff = [0] * 102  # 多两位防止越界

        for birth, death in logs:
            diff[birth - 1950] += 1
            diff[death - 1950] -= 1  # 死亡年份不算存活

        max_pop = 0
        cur_pop = 0
        best_year = 1950

        for i in range(101):
            cur_pop += diff[i]
            if cur_pop > max_pop:
                max_pop = cur_pop
                best_year = 1950 + i

        return best_year
```

### 方法二：直接计数（暴力）

```python
from typing import List

class Solution:
    def maximumPopulation(self, logs: List[List[int]]) -> int:
        count = [0] * 101  # 下标 i 对应 1950+i 年

        for birth, death in logs:
            for year in range(birth, death):
                count[year - 1950] += 1

        max_pop = max(count)
        return 1950 + count.index(max_pop)
```

## 复杂度分析

- **方法一（差分）**：O(n + 101) = O(n) 时间，O(1) 空间
- **方法二（暴力）**：O(n * 100) 时间，O(1) 空间

## 关键点总结

1. 差分数组处理区间加减问题，高效处理大量区间
2. 人在 `[birth, death-1]` 存活，所以 `diff[death - 1950] -= 1`（而不是 `death + 1`）
3. 若有相同最大人口，`index` 方法自动返回最小年份（第一个最大值的位置）

## 易错点

- 存活年份是 `[birth, death-1]`，不包含死亡年份
- 下标偏移：用 `year - 1950` 映射到数组下标
