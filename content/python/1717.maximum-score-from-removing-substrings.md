## 题目描述

给你一个字符串 `s` 和两个整数 `x` 和 `y`。你可以执行下面两种操作任意次：
- 删除子字符串 `"ab"` 并得到 `x` 分
- 删除子字符串 `"ba"` 并得到 `y` 分

请返回对 `s` 字符串执行上面操作若干次能得到的最大得分。

**示例 1：**
```
输入：s = "cdbcbbaaabab", x = 4, y = 5
输出：19
```

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= x, y <= 10^4`
- `s` 仅由小写英文字母组成

## 解题思路

贪心：先删分值高的子字符串，再删分值低的子字符串。

用栈模拟删除过程：
1. 确定高分目标（`"ab"` 还是 `"ba"`），优先删除
2. 第一遍扫描删高分字符串，第二遍扫描删低分字符串
3. 每次删一个字符时，检查栈顶是否与当前字符构成目标子字符串

## 代码实现

### 方法一：栈模拟两遍（推荐）

```python
class Solution:
    def maximumGain(self, s: str, x: int, y: int) -> int:
        # 确定高分和低分的目标子字符串
        if x >= y:
            high, low = "ab", "ba"
            high_score, low_score = x, y
        else:
            high, low = "ba", "ab"
            high_score, low_score = y, x
        
        total = 0
        
        # 第一遍：删除高分字符串
        stack = []
        for c in s:
            if stack and stack[-1] == high[0] and c == high[1]:
                stack.pop()
                total += high_score
            else:
                stack.append(c)
        
        # 第二遍：在剩余字符中删除低分字符串
        remaining = stack
        stack = []
        for c in remaining:
            if stack and stack[-1] == low[0] and c == low[1]:
                stack.pop()
                total += low_score
            else:
                stack.append(c)
        
        return total
```

### 方法二：封装删除函数

```python
class Solution:
    def maximumGain(self, s: str, x: int, y: int) -> int:
        def remove_and_score(text: str, target: str, score: int):
            """用栈删除所有目标子字符串，返回（得分，剩余字符列表）"""
            total = 0
            stack = []
            for c in text:
                if stack and stack[-1] == target[0] and c == target[1]:
                    stack.pop()
                    total += score
                else:
                    stack.append(c)
            return total, stack
        
        if x >= y:
            score1, rest = remove_and_score(s, "ab", x)
            score2, _ = remove_and_score(rest, "ba", y)
        else:
            score1, rest = remove_and_score(s, "ba", y)
            score2, _ = remove_and_score(rest, "ab", x)
        
        return score1 + score2
```

## 复杂度分析

- **时间复杂度**：O(n)，两次线性扫描
- **空间复杂度**：O(n)，栈空间

## 关键点总结

1. 贪心：高分操作先做，不会影响低分操作的执行
2. 用栈模拟删除：遇到目标子字符串就弹栈并计分
3. 两遍处理即可覆盖所有情况

## 易错点

- 先做高分操作再做低分操作，顺序不能错
- 栈模拟时，只需检查栈顶和当前字符是否构成目标串
