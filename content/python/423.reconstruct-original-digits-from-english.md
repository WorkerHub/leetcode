## 题目描述

给你一个字符串 `s`，其中包含字母顺序打乱的用英文单词表示的若干数字（`0-9`）。按升序返回原始的数字。

**示例 1：**
```
输入：s = "owoztneoer"
输出："012"
```

**示例 2：**
```
输入：s = "fviefuro"
输出："45"
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 `["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"]` 中的一个
- `s` 保证是一个符合题目要求的字符串

**数字的英文表示：**
- 0: zero
- 1: one
- 2: two
- 3: three
- 4: four
- 5: five
- 6: six
- 7: seven
- 8: eight
- 9: nine

## 解题思路

这道题的关键是找到每个数字的唯一标识字符，然后按照特定顺序提取。

**关键观察：**
1. 某些数字包含独特的字母，可以唯一识别：
   - `z` 只出现在 zero (0)
   - `w` 只出现在 two (2)
   - `u` 只出现在 four (4)
   - `x` 只出现在 six (6)
   - `g` 只出现在 eight (8)

2. 去除上述数字后，剩余数字中又有新的唯一字母：
   - `f` 在去除 four 后只出现在 five (5)
   - `s` 在去除 six 后只出现在 seven (7)
   - `h` 在去除 eight 后只出现在 three (3)

3. 最后剩下的：
   - `i` 在去除 five, six, eight 后只出现在 nine (9)
   - `o` 在去除 zero, two, four 后只出现在 one (1)

**算法流程：**
1. 统计所有字符的出现次数
2. 按照特定顺序提取数字（先提取有唯一字符的）
3. 每提取一个数字，就从计数中减去该数字单词的所有字母
4. 按升序构造结果

## Python 代码实现

### 方法一：贪心 + 哈希表 ⭐ 推荐

```python
from collections import Counter

class Solution:
    def originalDigits(self, s: str) -> str:
        # 统计每个字符的出现次数
        count = Counter(s)
        
        # 存储每个数字出现的次数
        digits = [0] * 10
        
        # 第一轮：提取有唯一字符的数字
        digits[0] = count['z']  # zero
        digits[2] = count['w']  # two
        digits[4] = count['u']  # four
        digits[6] = count['x']  # six
        digits[8] = count['g']  # eight
        
        # 第二轮：去除第一轮数字后，提取新的唯一字符数字
        digits[3] = count['h'] - digits[8]  # three (去除eight)
        digits[5] = count['f'] - digits[4]  # five (去除four)
        digits[7] = count['s'] - digits[6]  # seven (去除six)
        
        # 第三轮：提取剩余数字
        digits[9] = count['i'] - digits[5] - digits[6] - digits[8]  # nine
        digits[1] = count['o'] - digits[0] - digits[2] - digits[4]  # one
        
        # 按升序构造结果
        result = []
        for i in range(10):
            result.append(str(i) * digits[i])
        
        return ''.join(result)
```

### 方法二：详细注释版

```python
from collections import Counter

class Solution:
    def originalDigits(self, s: str) -> str:
        # 统计字符频率
        char_count = Counter(s)
        
        # 每个数字的英文单词
        words = ["zero", "one", "two", "three", "four", 
                "five", "six", "seven", "eight", "nine"]
        
        # 存储每个数字出现的次数
        digit_count = [0] * 10
        
        # 按照特定顺序提取（有唯一字符的先提取）
        # 顺序：0, 2, 4, 6, 8, 3, 5, 7, 9, 1
        order = [
            (0, 'z'),  # zero 中的 z 是唯一的
            (2, 'w'),  # two 中的 w 是唯一的
            (4, 'u'),  # four 中的 u 是唯一的
            (6, 'x'),  # six 中的 x 是唯一的
            (8, 'g'),  # eight 中的 g 是唯一的
            (3, 'h'),  # three 中的 h（去除8后）
            (5, 'f'),  # five 中的 f（去除4后）
            (7, 's'),  # seven 中的 s（去除6后）
            (9, 'i'),  # nine 中的 i（去除5,6,8后）
            (1, 'o'),  # one 中的 o（去除0,2,4后）
        ]
        
        for digit, unique_char in order:
            # 通过唯一字符确定数字出现次数
            digit_count[digit] = char_count[unique_char]
            
            # 从字符计数中减去该数字单词的所有字符
            for char in words[digit]:
                char_count[char] -= digit_count[digit]
        
        # 构造结果（按升序）
        result = []
        for digit in range(10):
            result.append(str(digit) * digit_count[digit])
        
        return ''.join(result)
```

### 方法三：简洁版

```python
from collections import Counter

class Solution:
    def originalDigits(self, s: str) -> str:
        c = Counter(s)
        d = [0] * 10
        
        # 顺序很重要
        d[0] = c['z']
        d[2] = c['w']
        d[4] = c['u']
        d[6] = c['x']
        d[8] = c['g']
        d[3] = c['h'] - d[8]
        d[5] = c['f'] - d[4]
        d[7] = c['s'] - d[6]
        d[9] = c['i'] - d[5] - d[6] - d[8]
        d[1] = c['o'] - d[0] - d[2] - d[4]
        
        return ''.join(str(i) * d[i] for i in range(10))
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是字符串长度
  - 统计字符频率：O(n)
  - 计算数字次数：O(1)（固定10个数字）
  - 构造结果：O(n)
- 空间复杂度：O(1)
  - Counter 最多存储26个字母
  - digits 数组固定大小

## 关键点总结

1. **唯一字符识别**：找到每个数字的唯一标识字符是关键
2. **提取顺序**：必须先提取有唯一字符的，再提取依赖其他数字的
3. **字符消除**：提取一个数字后，要从计数中减去其所有字母
4. **数学推导**：利用字符出现次数的数学关系推导数字个数
5. **结果排序**：最后按升序输出（0-9 的顺序）

## 易错点

1. **提取顺序错误**：必须按照依赖关系提取，顺序不能乱
2. **字符计数遗漏**：提取数字后忘记减去对应单词的字符
3. **减法错误**：nine 需要减去 5, 6, 8 三个数字中 i 的个数
4. **结果顺序**：题目要求升序，不能按提取顺序输出
5. **边界情况**：空字符串、单个数字等特殊情况

