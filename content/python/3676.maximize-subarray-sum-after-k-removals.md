## 题目描述

给你一个整数数组 `nums` 和整数 `k`，可以从数组中删除最多 `k` 个元素（可以选择任意位置），使得剩余数组的最大子数组和最大化。

返回最大化后的最大子数组和。

**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4], k = 1
输出：11
解释：删除 -5 后，最大子数组为 [4,-1,2,1,4]，和为10... 或删除-2，[1,-3,4,-1,2,1]? 
最优：删除一个负数使子数组更长
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `0 <= k <= nums.length`

## 解题思路

DP + 堆：

`dp[i][j]` = 在前 `i` 个元素中，以 `nums[i]` 结尾，删除了 `j` 个元素的最大子数组和。

但二维 DP 复杂度高。

贪心思路：最优策略是删除子数组内最小的 k 个负数。

贪心 + 单调队列：枚举右端点，维护删除 k 个最小元素后的最大子数组和。

## Python 代码实现

### 方法一：DP + 堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = float('-inf')

        # dp[j] = 删除 j 个元素，以当前位置结尾的最大子数组和
        # 使用 n+1 个堆来维护
        # 简化：枚举子数组，删除最小的 k 个元素

        # 前缀最小堆方法
        # 维护以 i 结尾，最多删 k 个元素的最大子数组和
        dp = [float('-inf')] * (k + 2)
        dp[0] = 0  # 删除 0 个元素，和为 0

        for i in range(n):
            new_dp = [float('-inf')] * (k + 2)
            for j in range(k + 1):
                if dp[j] != float('-inf'):
                    # 将 nums[i] 加入
                    new_dp[j] = max(new_dp[j], dp[j] + nums[i])
                    # 删除 nums[i]
                    if j + 1 <= k:
                        new_dp[j + 1] = max(new_dp[j + 1], dp[j])
            # 可以重新开始（以 nums[i] 为起点）
            new_dp[0] = max(new_dp[0], nums[i])
            dp = new_dp
            ans = max(ans, max(dp[:k + 1]))

        return ans
```

### 方法二：暴力枚举（小数据）

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = float('-inf')

        for i in range(n):
            sub = []
            for j in range(i, n):
                sub.append(nums[j])
                # 删除最小的 min(k, len(sub)) 个负数
                sorted_sub = sorted(sub)
                to_keep = sub[:]
                deletable = [x for x in sorted_sub if x < 0][:k]
                remaining_sum = sum(sub) - sum(deletable)
                ans = max(ans, remaining_sum)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * k)（DP），O(n^3 log n)（暴力）
- 空间复杂度：O(k)

## 关键点总结

1. DP 状态：以 i 结尾，已删除 j 个元素的最大子数组和
2. 转移：加入当前元素（不删），或删除当前元素（删除数 +1）
3. 可以重新开始（子数组长度从 1 开始）

## 易错点

1. 可以删除子数组内任意位置的元素，不只是端点
2. 需要维护"开始新子数组"的选项
3. 删除元素后子数组仍连续（删除的元素不在子数组内的连续约束下）
