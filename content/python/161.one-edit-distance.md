## 题目描述

给定两个字符串 `s` 和 `t`，如果它们的编辑距离为 1，则返回 `true`，否则返回 `false`。

字符串 s 和字符串 t 之间的编辑距离为 1 有三种可能的情况：
- 往 s 中插入恰好一个字符得到 t
- 从 s 中删除恰好一个字符得到 t
- 在 s 中用一个不同的字符替换恰好一个字符得到 t

**示例 1：**
```
输入：s = "ab", t = "acb"
输出：true
解释：可以将 'c' 插入字符串 s 来得到 t。
```

**示例 2：**
```
输入：s = "", t = ""
输出：false
解释：无法从空字符串变为另一个空字符串。
```

**示例 3：**
```
输入：s = "a", t = ""
输出：true
```

**示例 4：**
```
输入：s = "", t = "A"
输出：true
```

**提示：**
- 0 <= s.length, t.length <= 10^4
- s 和 t 由小写字母、大写字母和数字组成

## 解题思路

这道题要求判断两个字符串的编辑距离是否恰好为 1，注意是**恰好为 1**，不是小于等于 1。

**关键观察：**

1. **长度关系**：
   - 如果 `|len(s) - len(t)| > 1`，编辑距离必然大于 1，返回 false
   - 如果 `len(s) == len(t)`，只能是替换操作
   - 如果 `len(s) + 1 == len(t)` 或 `len(s) == len(t) + 1`，是插入或删除操作

2. **遍历策略**：
   - 同时遍历两个字符串
   - 遇到第一个不同字符时：
     - 长度相同：跳过这个字符，后续必须完全相同（替换）
     - 长度不同：跳过长字符串的字符，后续必须完全相同（插入/删除）
   - 如果发现第二个不同字符，返回 false

3. **边界情况**：
   - 两个空字符串：编辑距离为 0，返回 false
   - 两个完全相同的字符串：编辑距离为 0，返回 false

## Python 代码实现

### 方法一：一次遍历（推荐）⭐

```python
class Solution:
    def isOneEditDistance(self, s: str, t: str) -> bool:
        """
        一次遍历判断是否为编辑距离 1
        时间复杂度：O(n)，其中 n 是较短字符串的长度
        空间复杂度：O(1)
        """
        ns, nt = len(s), len(t)
        
        # 确保 s 是较短的字符串，简化后续逻辑
        if ns > nt:
            return self.isOneEditDistance(t, s)
        
        # 长度差大于 1，不可能是编辑距离 1
        if nt - ns > 1:
            return False
        
        # 遍历较短的字符串
        for i in range(ns):
            if s[i] != t[i]:
                # 找到第一个不同的字符
                if ns == nt:
                    # 长度相同：替换操作
                    # 后续字符必须完全相同
                    return s[i + 1:] == t[i + 1:]
                else:
                    # 长度不同：删除/插入操作
                    # s 的后续字符应该等于 t 跳过当前字符后的字符
                    return s[i:] == t[i + 1:]
        
        # 所有字符都相同
        # 只有当长度差为 1 时才是编辑距离 1（在末尾插入/删除）
        # 如果长度相同且所有字符都相同，编辑距离为 0
        return ns + 1 == nt
```

### 方法二：双指针（更直观）

```python
class Solution:
    def isOneEditDistance(self, s: str, t: str) -> bool:
        """
        双指针法，分别从前后遍历
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        ns, nt = len(s), len(t)
        
        # 长度差大于 1
        if abs(ns - nt) > 1:
            return False
        
        # 长度相同且字符串相同，编辑距离为 0
        if ns == nt and s == t:
            return False
        
        # 长度差为 0，需要恰好一次替换
        if ns == nt:
            diff_count = 0
            for i in range(ns):
                if s[i] != t[i]:
                    diff_count += 1
                    if diff_count > 1:
                        return False
            return diff_count == 1
        
        # 长度差为 1，需要恰好一次插入/删除
        # 确保 s 是较短的字符串
        if ns > nt:
            s, t = t, s
            ns, nt = nt, ns
        
        i = 0  # s 的指针
        j = 0  # t 的指针
        found_diff = False
        
        while i < ns and j < nt:
            if s[i] != t[j]:
                if found_diff:
                    return False
                found_diff = True
                j += 1  # 跳过 t 中的字符（删除操作）
            else:
                i += 1
                j += 1
        
        return True
```

### 方法三：分情况讨论

```python
class Solution:
    def isOneEditDistance(self, s: str, t: str) -> bool:
        """
        分三种情况讨论：替换、插入、删除
        """
        ns, nt = len(s), len(t)
        
        # 情况 1：长度相同，检查是否恰好一个字符不同（替换）
        if ns == nt:
            return sum(c1 != c2 for c1, c2 in zip(s, t)) == 1
        
        # 情况 2：s 比 t 短 1，检查删除 t 中一个字符能否得到 s
        if ns + 1 == nt:
            for i in range(nt):
                # 尝试删除 t[i]
                if s == t[:i] + t[i + 1:]:
                    return True
            return False
        
        # 情况 3：t 比 s 短 1，检查删除 s 中一个字符能否得到 t
        if nt + 1 == ns:
            for i in range(ns):
                # 尝试删除 s[i]
                if t == s[:i] + s[i + 1:]:
                    return True
            return False
        
        # 其他情况，长度差 >= 2
        return False
```

### 方法四：优化的一次遍历

```python
class Solution:
    def isOneEditDistance(self, s: str, t: str) -> bool:
        """
        优化版本，代码更简洁
        """
        ns, nt = len(s), len(t)
        
        # 确保 s 不长于 t
        if ns > nt:
            return self.isOneEditDistance(t, s)
        
        # 长度差 > 1 或完全相同
        if nt - ns > 1 or s == t:
            return False
        
        # 查找第一个不同的位置
        for i in range(ns):
            if s[i] != t[i]:
                # 长度相同：替换
                if ns == nt:
                    return s[i + 1:] == t[i + 1:]
                # 长度不同：插入/删除
                else:
                    return s[i:] == t[i + 1:]
        
        # 没有不同字符，说明 s 是 t 的前缀，且长度差为 1
        return True
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是较短字符串的长度，最多遍历一次
- 空间复杂度：O(1)（方法一、二、四）或 O(n)（方法三，字符串切片）

## 关键点总结

1. **长度差判断**：首先通过长度差快速排除不可能的情况
2. **确保 s 较短**：交换 s 和 t 可以简化代码逻辑
3. **找第一个不同位置**：一旦找到，根据长度关系判断后续
4. **恰好为 1**：注意是恰好编辑距离 1，不是小于等于 1
5. **完全相同情况**：编辑距离为 0，应该返回 false

## 易错点

1. **完全相同的字符串**：编辑距离为 0，应返回 false，不是 true
2. **空字符串**：两个空字符串编辑距离为 0，返回 false
3. **长度判断**：要考虑 `nt - ns > 1` 的情况
4. **替换和插入混淆**：长度相同是替换，长度差 1 是插入/删除
5. **边界情况**：末尾插入/删除的情况，所有字符都相同但长度差 1
