## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，长度均为 `n`。

你可以执行若干次操作：每次操作选择下标 `i`（0 <= i < n-1），交换 `nums1[i]` 和 `nums2[i]`。

你希望最后满足：对所有 `i`（0 <= i < n-1），`nums1[i] <= nums1[n-1]` 且 `nums2[i] <= nums2[n-1]`。

换句话说，`nums1[n-1]` 和 `nums2[n-1]` 分别是 `nums1` 和 `nums2` 的最大值。

返回所需的最少操作次数，若不可能则返回 -1。

**示例 1：**
```
输入：nums1 = [3,2,2], nums2 = [3,3,3]
输出：1
```

**示例 2：**
```
输入：nums1 = [1,2,2,1,1,1], nums2 = [1,1,1,3,3,3]
输出：4
```

**提示：**
- `1 <= n <= 1000`
- `1 <= nums1[i], nums2[i] <= 10^9`

## 解题思路

最后一个位置（n-1）只有两种情况：
1. 不交换 nums1[n-1] 和 nums2[n-1]：目标 max1 = nums1[n-1]，max2 = nums2[n-1]
2. 交换 nums1[n-1] 和 nums2[n-1]：目标 max1 = nums2[n-1]，max2 = nums1[n-1]

对于每种情况，遍历 0 到 n-2 的每个位置 i：
- 若 nums1[i] <= max1 且 nums2[i] <= max2：无需操作
- 若 nums2[i] <= max1 且 nums1[i] <= max2：交换，操作数 +1
- 否则不可行，返回 -1

取两种情况中操作数最少的。

## Python 代码实现

### 方法一：枚举末尾元素的两种情况（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)

        def calc(max1: int, max2: int) -> int:
            # 计算在目标 max1, max2 下的最少操作数
            ops = 0
            for i in range(n - 1):
                a, b = nums1[i], nums2[i]
                if a <= max1 and b <= max2:
                    # 无需操作
                    continue
                elif b <= max1 and a <= max2:
                    # 需要交换
                    ops += 1
                else:
                    return float('inf')  # 不可行
            return ops

        # 情况 1：不交换末尾
        res1 = calc(nums1[n - 1], nums2[n - 1])
        # 情况 2：交换末尾（末尾操作也算 1 次）
        res2 = calc(nums2[n - 1], nums1[n - 1])
        if res2 != float('inf'):
            res2 += 1  # 末尾交换本身算一次操作

        ans = min(res1, res2)
        return ans if ans != float('inf') else -1
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        INF = float('inf')

        def check(m1, m2):
            ops = 0
            for i in range(n - 1):
                a, b = nums1[i], nums2[i]
                if a <= m1 and b <= m2:
                    pass
                elif a <= m2 and b <= m1:
                    ops += 1
                else:
                    return INF
            return ops

        r1 = check(nums1[n-1], nums2[n-1])
        r2 = check(nums2[n-1], nums1[n-1])
        if r2 < INF:
            r2 += 1
        ans = min(r1, r2)
        return -1 if ans == INF else ans
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)

## 关键点总结

1. 末尾元素只有"交换"或"不交换"两种状态，枚举这两种情况
2. 对于中间每个位置，贪心判断是否需要交换
3. 若既不能不交换也不能交换，则不可行

## 易错点

1. 末尾交换本身算一次操作（计入 res2 的基础上 +1）
2. 当中间位置两种状态都不满足时，返回 -1
3. 两种情况都取最小值后再判断是否为 -1
