## 题目描述

给你一个整数数组 `start` 和一个整数 `d`，对于每个下标 `i`，你可以从区间 `[start[i], start[i] + d]` 中选一个整数。

返回从所有区间各选一个整数后，**所有所选整数的最小差值的最大值**（最小两相邻整数差的最大值）。

**示例 1：**
```
输入：start = [6,0,3], d = 2
输出：4
解释：选 8, 0, 4（或其他），排序后 0, 4, 8，最小差为 4
```

**示例 2：**
```
输入：start = [2,6,13,13], d = 5
输出：5
```

**提示：**
- `2 <= start.length <= 10^5`
- `0 <= d <= 10^9`
- `0 <= start[i] <= 10^9`

## 解题思路

**二分答案**：二分最小差值 `ans`，检查是否可行。

检查：排序后贪心，对每个区间从左到右，选尽可能小但满足与前一个选的数差 >= ans 的整数。

具体：排序 start 后，贪心地从 start[0] 开始选，每次选满足条件的最小值。

## Python 代码实现

### 方法一：二分 + 贪心检验（推荐）

```python
from typing import List

class Solution:
    def maxPossibleScore(self, start: List[int], d: int) -> int:
        start.sort()
        n = len(start)
        
        def can_achieve(min_gap):
            # 贪心：从第一个区间选最小值
            prev = start[0]
            for i in range(1, n):
                # 下一个选的值必须 >= prev + min_gap
                # 且在 [start[i], start[i] + d] 内
                nxt = max(start[i], prev + min_gap)
                if nxt > start[i] + d:
                    return False
                prev = nxt
            return True
        
        lo, hi = 0, (start[-1] + d - start[0]) // (n - 1)
        
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_achieve(mid):
                lo = mid
            else:
                hi = mid - 1
        
        return lo
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))
- 空间复杂度：O(1)

## 关键点总结

1. 二分最小差值，贪心检验
2. 贪心：对每个区间，选满足距离约束的最小值
3. 排序后便于贪心处理

## 易错点

1. 二分上界是 `(max - min) / (n-1)`
2. 贪心时若最小可选值超过区间右端，则不可行
