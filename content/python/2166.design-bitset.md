## 题目描述

设计一个支持下列操作的位集 Bitset：

- `Bitset(size)` 初始化一个大小为 `size` 的位集，所有位为 0。
- `fix(idx)` 将下标 `idx` 处的位设置为 1，若已为 1 则不变。
- `unfix(idx)` 将下标 `idx` 处的位设置为 0，若已为 0 则不变。
- `flip()` 翻转所有位（0 变 1，1 变 0）。
- `all()` 所有位是否全为 1。
- `one()` 是否至少有一位为 1。
- `count()` 返回 1 的个数。
- `toString()` 返回位集的字符串表示。

**提示：**
- `1 <= size <= 10^5`
- 总操作次数不超过 `10^5`

## 解题思路

**位集 + 翻转标记**

- 用数组 `bits` 存储位集（0 或 1）。
- 维护 `cnt`（1 的个数）。
- 维护 `flipped` 标志：表示是否需要翻转（lazy flip）。
  - 当 `flipped = True` 时，实际值为 `1 - bits[i]`。
  - `fix/unfix` 操作时，根据 `flipped` 调整对 `bits` 的操作。

## 代码实现

### 方法一：位集 + 翻转标记（推荐）

```python
class Bitset:
    def __init__(self, size: int):
        self.size = size
        self.bits = bytearray(size)  # 初始全 0
        self.cnt = 0         # 当前 1 的个数（未考虑翻转）
        self.flipped = False # 是否全局翻转

    def fix(self, idx: int) -> None:
        # 设置 idx 为 1（考虑翻转状态）
        # 逻辑上设为 1：若 flipped，则 bits[idx] 应为 0（实际值 = 1-0 = 1）
        target = 0 if self.flipped else 1
        if self.bits[idx] != target:
            self.bits[idx] = target
            self.cnt += 1

    def unfix(self, idx: int) -> None:
        # 设置 idx 为 0（考虑翻转状态）
        # 逻辑上设为 0：若 flipped，则 bits[idx] 应为 1
        target = 1 if self.flipped else 0
        if self.bits[idx] != target:
            self.bits[idx] = target
            self.cnt -= 1

    def flip(self) -> None:
        # 切换翻转标记，1 的个数变为 size - cnt
        self.flipped = not self.flipped
        self.cnt = self.size - self.cnt

    def all(self) -> bool:
        return self.cnt == self.size

    def one(self) -> bool:
        return self.cnt > 0

    def count(self) -> int:
        return self.cnt

    def toString(self) -> str:
        if self.flipped:
            return ''.join('0' if b else '1' for b in self.bits)
        else:
            return ''.join(str(b) for b in self.bits)
```

### 方法二：简单位数组（不用翻转优化）

```python
class Bitset:
    def __init__(self, size: int):
        self.size = size
        self.bits = [0] * size

    def fix(self, idx: int) -> None:
        self.bits[idx] = 1

    def unfix(self, idx: int) -> None:
        self.bits[idx] = 0

    def flip(self) -> None:
        self.bits = [1 - b for b in self.bits]

    def all(self) -> bool:
        return all(b == 1 for b in self.bits)

    def one(self) -> bool:
        return any(b == 1 for b in self.bits)

    def count(self) -> int:
        return sum(self.bits)

    def toString(self) -> str:
        return ''.join(map(str, self.bits))
```

## 复杂度分析

| 方法 | fix/unfix/flip/all/one/count | toString |
|------|------------------------------|----------|
| 优化版（翻转标记） | O(1) | O(n) |
| 简单版 | flip O(n)，其余 O(n) | O(n) |

## 关键点总结

1. 翻转标记（lazy flip）将 `flip()` 从 O(n) 优化到 O(1)。
2. 有翻转标记时，`fix/unfix` 需要根据 `flipped` 决定实际存储值。
3. 维护 `cnt`（1 的个数），使 `all()/one()/count()` 都是 O(1)。

## 易错点

- `flip` 后 `cnt` 变为 `size - cnt`，不是简单取反。
- `toString` 时，若 `flipped = True`，需要对每个 bit 取反输出。
