## 题目描述

给你一个 `m x n` 二进制矩阵 `grid`。

一次操作可以选择**任意一个** 1 并将其变成 0。

若矩阵中**不存在两个相邻的** 1（相邻指水平或垂直方向），则认为矩阵合法。

返回使矩阵合法所需的**最少操作次数**。

**示例：**
```
输入：grid = [[1,1,0],[0,1,1],[1,1,1]]
输出：3
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `grid[i][j] == 0 or 1`

## 解题思路

**二分图最大匹配（匈牙利算法）**

将矩阵中所有为 1 的位置作为节点，相邻的两个 1 之间连边。

将矩阵按棋盘染色（(i+j) 为偶的格子染白色，奇数格子染黑色），则所有边都连接一个白色节点和一个黑色节点（因为相邻格子的 (i+j) 奇偶性不同）。

**结论：** 问题等价于二分图中的最大独立集的补集，即二分图的**最大匹配数**。

根据 König 定理：二分图的最大独立集 = n - 最大匹配数，最少操作数 = 最大匹配数。

用匈牙利算法求二分图最大匹配。

## 代码实现

### 方法一：匈牙利算法（推荐）

```python
from typing import List

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 建图：相邻 1 之间连边（只考虑白色节点到黑色节点的边）
        # 白色：(i+j) 为偶，黑色：(i+j) 为奇
        adj = {}  # 白色节点 -> 相邻黑色节点列表
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1 and (i + j) % 2 == 0:
                    adj[(i, j)] = []
                    for di, dj in [(0,1),(0,-1),(1,0),(-1,0)]:
                        ni, nj = i + di, j + dj
                        if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                            adj[(i, j)].append((ni, nj))

        # 匈牙利算法求最大匹配
        match = {}  # 黑色节点 -> 匹配的白色节点

        def dfs(u, visited):
            for v in adj[u]:
                if v not in visited:
                    visited.add(v)
                    # v 未匹配或 v 的匹配可以重新分配
                    if v not in match or dfs(match[v], visited):
                        match[v] = u
                        return True
            return False

        result = 0
        for u in adj:
            visited = set()
            if dfs(u, visited):
                result += 1

        return result
```

### 方法二：BFS 增广路（Hopcroft-Karp 算法）

```python
from typing import List
from collections import deque

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        whites = []
        adj = {}

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1 and (i + j) % 2 == 0:
                    whites.append((i, j))
                    neighbors = []
                    for di, dj in [(0,1),(0,-1),(1,0),(-1,0)]:
                        ni, nj = i + di, j + dj
                        if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                            neighbors.append((ni, nj))
                    adj[(i, j)] = neighbors

        match_black = {}  # 黑色节点 -> 匹配的白色节点

        def try_augment(u, visited):
            for v in adj.get(u, []):
                if v not in visited:
                    visited.add(v)
                    if v not in match_black or try_augment(match_black[v], visited):
                        match_black[v] = u
                        return True
            return False

        ans = 0
        for u in whites:
            if try_augment(u, set()):
                ans += 1
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 匈牙利 | O(V * E) | O(V + E) |

V = 矩阵中 1 的个数，E = 相邻 1 的对数。

## 关键点总结

1. 矩阵按棋盘染色，相邻的 1 构成二分图。
2. 最少操作数 = 二分图最大匹配数（König 定理）。
3. 匈牙利算法：对每个白色节点尝试找增广路。

## 易错点

- 只需对白色节点枚举（或只枚举一侧），不要重复计算。
- `visited` 集合每次 DFS 都要重新初始化，防止路径重叠。
