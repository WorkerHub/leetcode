## 题目描述

给你二叉树的根节点 `root`，此外树的每个节点的值要么是 `0`，要么是 `1`。

返回移除了所有不包含 `1` 的子树的原二叉树。

节点 `node` 的子树为 `node` 本身加上所有 `node` 的后代。

**示例 1:**
```
输入: root = [1,null,0,0,1]
输出: [1,null,0,null,1]
```

**示例 2:**
```
输入: root = [1,0,1,0,0,0,1]
输出: [1,null,1,null,1]
```

**示例 3:**
```
输入: root = [1,1,0,1,1,0,1,0]
输出: [1,1,0,1,1,null,1]
```

**提示:**
- 树中节点的数目在范围 `[1, 200]` 内
- `Node.val` 为 `0` 或 `1`

## 解题思路

使用后序遍历（左右根），递归判断子树是否包含 1。

**递归逻辑：**
1. 递归处理左右子树
2. 如果子树不包含 1，则置为 None
3. 判断当前节点及其子树是否包含 1

## Python 代码实现

### 方法一：后序遍历（推荐）⭐

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def pruneTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def contains_one(node):
            """判断以 node 为根的子树是否包含 1"""
            if not node:
                return False
            
            # 递归处理左右子树
            left_has_one = contains_one(node.left)
            right_has_one = contains_one(node.right)
            
            # 如果左子树不包含 1，删除它
            if not left_has_one:
                node.left = None
            
            # 如果右子树不包含 1，删除它
            if not right_has_one:
                node.right = None
            
            # 当前子树包含 1 的条件：
            # 1. 当前节点值为 1，或
            # 2. 左子树包含 1，或
            # 3. 右子树包含 1
            return node.val == 1 or left_has_one or right_has_one
        
        # 如果整棵树都不包含 1，返回 None
        return root if contains_one(root) else None
```

### 方法二：简洁版本

```python
from typing import Optional

class Solution:
    def pruneTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        
        root.left = self.pruneTree(root.left)
        root.right = self.pruneTree(root.right)
        
        # 如果当前节点值为 0 且左右子树都为空，删除当前节点
        if root.val == 0 and not root.left and not root.right:
            return None
        
        return root
```

## 复杂度分析

- **时间复杂度**：O(n)，访问每个节点一次
- **空间复杂度**：O(h)，递归栈深度

## 关键点总结

1. **后序遍历**：先处理子树，再处理根
2. **递归返回**：返回处理后的子树
3. **删除条件**：值为 0 且没有子树

## 易错点

1. **遍历顺序**：必须是后序，不能前序
2. **None 处理**：空节点直接返回 None
3. **根节点**：整棵树可能都被删除
