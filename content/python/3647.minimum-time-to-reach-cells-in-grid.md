## 题目描述

给你一个 `m x n` 的矩阵 `grid`，`grid[i][j]` 表示到达该单元格的最早时刻。你从 `(0,0)` 在时刻 `0` 出发，每次可以向上下左右移动，每步耗时 1。若到达 `(i,j)` 时时刻 < `grid[i][j]`，则需等待到 `grid[i][j]` 后再进入，进入时刻为 `grid[i][j]`（或之后）。

返回到达 `(m-1, n-1)` 的最短时间，若不可达返回 -1。

**示例 1：**

```
输入：grid = [[0,1,3,2],[5,1,2,5],[4,3,8,6]]
输出：7
```

**提示：**

- `m == grid.length`
- `n == grid[0].length`
- `2 <= m, n <= 1000`
- `0 <= grid[i][j] <= 10^5`
- `grid[0][0] == 0`

## 解题思路

Dijkstra 变体（最短路）：

状态为 `(当前时刻, 行, 列)`，从 `(0, 0, 0)` 出发。

到达 `(ni, nj)` 的时刻 = `max(当前时刻 + 1, grid[ni][nj])`。

若等待后奇偶性不对（可能需要多等一步来回），需特殊处理：
- 若 `grid[ni][nj] - (当前时刻 + 1)` 为奇数，实际到达时刻需 +1（来回一步）

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
from typing import List
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 特判：起点周围都无法在时刻1到达（被卡住）
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while heap:
            t, r, c = heapq.heappop(heap)
            if t > dist[r][c]:
                continue
            if r == m - 1 and c == n - 1:
                return t
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    # 到达时刻
                    arrive = t + 1
                    if arrive < grid[nr][nc]:
                        # 需要等待，等待时来回走，保证奇偶性
                        wait = grid[nr][nc] - arrive
                        arrive = grid[nr][nc] + (wait % 2)
                    if arrive < dist[nr][nc]:
                        dist[nr][nc] = arrive
                        heapq.heappush(heap, (arrive, nr, nc))

        return dist[m - 1][n - 1] if dist[m - 1][n - 1] != float('inf') else -1
```

### 方法二：BFS（等权近似）

```python
from typing import List
from collections import deque

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        # 使用优先队列（同 Dijkstra）
        import heapq
        heap = [(0, 0, 0)]
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]

        while heap:
            t, r, c = heapq.heappop(heap)
            if r == m-1 and c == n-1:
                return t
            if t > dist[r][c]:
                continue
            for dr, dc in dirs:
                nr, nc = r+dr, c+dc
                if 0 <= nr < m and 0 <= nc < n:
                    nt = t + 1
                    if nt < grid[nr][nc]:
                        diff = grid[nr][nc] - nt
                        nt = grid[nr][nc] + diff % 2
                    if nt < dist[nr][nc]:
                        dist[nr][nc] = nt
                        heapq.heappush(heap, (nt, nr, nc))
        return -1
```

## 复杂度分析

- 时间复杂度：O(m * n * log(m * n))
- 空间复杂度：O(m * n)

## 关键点总结

1. 等待时奇偶性：若当前时刻到达时机过早，来回走一步（+1 时间）来匹配奇偶
2. 初始判断：若 `(0,1)` 和 `(1,0)` 都在时刻 > 1 才能进入，则不可达
3. Dijkstra 保证按时刻最小先处理

## 易错点

1. 奇偶调整：`wait % 2` 决定是否多等一步
2. 特判起点附近不可达的情况
3. 距离初始化为无穷大
