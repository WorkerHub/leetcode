## 题目描述

给你一个按**非递减顺序**排列的整数数组 `nums`。

请你判断是否能在将 `nums` 分割成**一个或多个子序列**的同时满足下述**两个**条件：

- 每个子序列都是一个**连续递增序列**（即，每个整数恰好比前一个整数大 1）。
- 所有子序列的长度**至少**为 3。

如果可以完成上述分割，则返回 `true`；否则，返回 `false`。

**示例 1:**

```
输入：nums = [1,2,3,3,4,5]
输出：true
解释：nums 可以分割成以下子序列：
[1, 2, 3, 3, 4, 5] --> 1, 2, 3
                       3, 4, 5
```

**示例 2:**

```
输入：nums = [1,2,3,3,4,4,5,5]
输出：true
解释：nums 可以分割成以下子序列：
[1, 2, 3, 3, 4, 4, 5, 5] --> 1, 2, 3, 4, 5
                             3, 4, 5
```

**示例 3:**

```
输入：nums = [1,2,3,4,4,5]
输出：false
解释：无法将 nums 分割成长度至少为 3 的连续递增子序列。
```

**提示:**
- `1 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`
- `nums` 按**非递减顺序**排列

## 解题思路

这是一道经典的**贪心算法**题。核心思想是：

### 贪心策略

对于当前数字 `num`，有两种选择：

1. **追加到已有子序列**：优先将 `num` 追加到以 `num-1` 结尾的子序列后面
2. **开始新子序列**：如果无法追加，尝试开始一个新的子序列 `[num, num+1, num+2]`

### 为什么这样是贪心的？

- 优先追加可以避免浪费已有的子序列
- 只有在无法追加时才开始新序列，确保数字利用效率最高

### 数据结构

使用两个哈希表：

1. **freq**：记录每个数字剩余的可用次数
2. **need**：记录需要某个数字的子序列数量（即以 `num-1` 结尾、需要 `num` 的子序列）

### 算法流程

1. 统计所有数字的频率
2. 遍历数组中的每个数字 `num`：
   - 如果 `num` 已用完，跳过
   - 如果存在需要 `num` 的子序列，追加到该子序列（need[num] -= 1, need[num+1] += 1）
   - 否则，尝试开始新子序列 `[num, num+1, num+2]`（检查 num+1 和 num+2 是否可用）
   - 如果都不行，返回 False

## Python 代码实现

### 方法一：贪心 + 哈希表（推荐）⭐

```python
from typing import List
from collections import Counter

class Solution:
    def isPossible(self, nums: List[int]) -> bool:
        """
        贪心算法：优先追加到已有子序列
        """
        # freq[i]：数字 i 剩余的可用次数
        freq = Counter(nums)
        
        # need[i]：需要数字 i 的子序列数量（以 i-1 结尾的子序列）
        need = Counter()
        
        for num in nums:
            # 如果当前数字已用完，跳过
            if freq[num] == 0:
                continue
            
            # 情况1：追加到已有子序列
            if need[num] > 0:
                need[num] -= 1      # 减少需要 num 的子序列数
                need[num + 1] += 1  # 增加需要 num+1 的子序列数
                freq[num] -= 1      # 使用一个 num
            
            # 情况2：开始新子序列 [num, num+1, num+2]
            elif freq[num + 1] > 0 and freq[num + 2] > 0:
                freq[num] -= 1
                freq[num + 1] -= 1
                freq[num + 2] -= 1
                need[num + 3] += 1  # 这个新子序列接下来需要 num+3
            
            # 情况3：无法处理，返回 False
            else:
                return False
        
        return True
```

### 方法二：贪心 + 详细注释版

```python
from collections import defaultdict

class Solution:
    def isPossible(self, nums: List[int]) -> bool:
        """
        贪心算法详细版
        """
        # 统计每个数字的频率
        freq = defaultdict(int)
        for num in nums:
            freq[num] += 1
        
        # 记录需要某个数字的子序列数量
        need = defaultdict(int)
        
        for num in nums:
            # 当前数字已经用完
            if freq[num] == 0:
                continue
            
            # 策略1：优先追加到已有的子序列
            if need[num] > 0:
                # 有子序列需要 num，追加上去
                need[num] -= 1
                # 追加后，这个子序列接下来需要 num+1
                need[num + 1] += 1
                # 使用一个 num
                freq[num] -= 1
            
            # 策略2：无法追加，尝试开始新子序列
            elif freq[num + 1] > 0 and freq[num + 2] > 0:
                # 可以组成 [num, num+1, num+2]
                freq[num] -= 1
                freq[num + 1] -= 1
                freq[num + 2] -= 1
                # 这个新子序列接下来需要 num+3
                need[num + 3] += 1
            
            # 策略3：既不能追加，也不能开始新子序列
            else:
                return False
        
        return True
```

### 方法三：优先队列（堆）

```python
from collections import defaultdict
import heapq

class Solution:
    def isPossible(self, nums: List[int]) -> bool:
        """
        使用堆维护每个子序列的结尾
        """
        # chains[num]：以 num 结尾的子序列的长度（最小堆）
        chains = defaultdict(list)
        
        for num in nums:
            # 如果有以 num-1 结尾的子序列，追加到最短的那个
            if chains[num - 1]:
                length = heapq.heappop(chains[num - 1])
                heapq.heappush(chains[num], length + 1)
            else:
                # 开始新子序列
                heapq.heappush(chains[num], 1)
        
        # 检查所有子序列的长度是否 >= 3
        for num in chains:
            for length in chains[num]:
                if length < 3:
                    return False
        
        return True
```

## 复杂度分析

### 方法一/二：贪心 + 哈希表
- **时间复杂度**：O(n)
  - 统计频率：O(n)
  - 遍历数组：O(n)
  - 哈希表操作：O(1)
- **空间复杂度**：O(n)，存储频率和需求

### 方法三：堆
- **时间复杂度**：O(n log n)，堆操作
- **空间复杂度**：O(n)，存储堆

## 关键点总结

1. **贪心策略**：优先追加到已有子序列，避免浪费
2. **两个哈希表**：freq 记录剩余，need 记录需求
3. **新子序列条件**：必须能凑出至少 3 个连续数字
4. **顺序处理**：按数组顺序处理，利用非递减特性
5. **need 的含义**：以某个数字结尾、需要下一个数字的子序列数量

## 易错点

1. **freq 和 need 的区别**：
   ```python
   # freq：数字剩余的可用次数
   # need：需要某个数字的子序列数量
   ```

2. **追加时的更新**：
   ```python
   # 追加 num 到子序列后
   need[num] -= 1      # 不再需要 num
   need[num + 1] += 1  # 接下来需要 num+1
   freq[num] -= 1      # 使用了一个 num
   ```

3. **新子序列的条件**：
   ```python
   # 必须同时满足：num+1 和 num+2 都可用
   if freq[num + 1] > 0 and freq[num + 2] > 0:
   ```

4. **跳过已用完的数字**：
   ```python
   if freq[num] == 0:
       continue
   ```

5. **判断顺序**：
   ```python
   # 必须先尝试追加，再尝试新建
   # 这是贪心的关键
   if need[num] > 0:
       # 追加
   elif ...:
       # 新建
   ```
