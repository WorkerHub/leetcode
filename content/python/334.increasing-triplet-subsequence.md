## 题目描述

给你一个整数数组 `nums`，判断这个数组中是否存在长度为 `3` 的递增子序列。

如果存在这样的三元组下标 `(i, j, k)` 且满足 `i < j < k`，使得 `nums[i] < nums[j] < nums[k]`，返回 `true`；否则，返回 `false`。

**示例 1:**

```
输入：nums = [1,2,3,4,5]
输出：true
解释：任何 i < j < k 的三元组都满足题意
```

**示例 2:**

```
输入：nums = [5,4,3,2,1]
输出：false
解释：不存在满足题意的三元组
```

**示例 3:**

```
输入：nums = [2,1,5,0,4,6]
输出：true
解释：三元组 (0, 2, 5) 满足题意，因为 nums[0] < nums[2] < nums[5]
```

**提示:**

- `1 <= nums.length <= 5 * 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

**进阶：** 你能实现时间复杂度为 `O(n)`，空间复杂度为 `O(1)` 的解决方案吗？

## 解题思路

这道题的核心是**贪心算法**，维护两个变量：最小值和第二小值。

### 核心思想

1. **维护两个变量**：
   - `first`：当前遇到的最小值
   - `second`：比 `first` 大的最小值
   
2. **贪心策略**：
   - 如果 `num > second`，找到了递增三元组
   - 如果 `num > first`，更新 `second = num`
   - 否则，更新 `first = num`

3. **为什么这样是对的？**
   - 我们只需要找到**任意一个**递增三元组
   - 保持 `first` 和 `second` 尽可能小，能增加找到第三个数的机会

### 关键理解

- 即使 `first` 在 `second` 之后被更新，也不影响结果
- 因为之前的 `first` 和 `second` 关系已经建立
- 新的 `first` 只是为了后续找到更好的三元组

## Python 代码实现

### 方法一：贪心算法（推荐）⭐

```python
from typing import List

class Solution:
    def increasingTriplet(self, nums: List[int]) -> bool:
        """
        贪心算法：维护最小值和第二小值
        """
        first = second = float('inf')
        
        for num in nums:
            if num <= first:
                # 更新最小值
                first = num
            elif num <= second:
                # 更新第二小值
                second = num
            else:
                # 找到了第三个数，num > second > first
                return True
        
        return False
```

### 方法二:详细注释版（便于理解）

```python
from typing import List

class Solution:
    def increasingTriplet(self, nums: List[int]) -> bool:
        """
        贪心算法：保持 first 和 second 尽可能小
        """
        # first: 当前遇到的最小值
        # second: 比 first 大的最小值
        first = float('inf')
        second = float('inf')
        
        for num in nums:
            # 情况 1: num 比 first 小或相等
            # 更新 first，寻找更小的起点
            if num <= first:
                first = num
            
            # 情况 2: num 在 first 和 second 之间
            # 更新 second，我们有了更好的 (first, second) 对
            elif num <= second:
                second = num
            
            # 情况 3: num 大于 second
            # 找到了递增三元组！
            else:
                return True
        
        # 遍历完没找到
        return False
```

### 方法三：动态规划（O(n) 时间，O(n) 空间）

```python
from typing import List

class Solution:
    def increasingTriplet(self, nums: List[int]) -> bool:
        """
        动态规划：记录每个位置左边的最小值和右边的最大值
        """
        n = len(nums)
        if n < 3:
            return False
        
        # left_min[i]: nums[0...i] 的最小值
        left_min = [0] * n
        left_min[0] = nums[0]
        for i in range(1, n):
            left_min[i] = min(left_min[i-1], nums[i])
        
        # right_max[i]: nums[i...n-1] 的最大值
        right_max = [0] * n
        right_max[n-1] = nums[n-1]
        for i in range(n-2, -1, -1):
            right_max[i] = max(right_max[i+1], nums[i])
        
        # 检查是否存在 left_min[i] < nums[i] < right_max[i]
        for i in range(1, n-1):
            if left_min[i-1] < nums[i] < right_max[i+1]:
                return True
        
        return False
```

### 方法四：暴力解法（O(n^3)，会超时）

```python
from typing import List

class Solution:
    def increasingTriplet(self, nums: List[int]) -> bool:
        """
        暴力解法：三层循环
        """
        n = len(nums)
        
        for i in range(n-2):
            for j in range(i+1, n-1):
                for k in range(j+1, n):
                    if nums[i] < nums[j] < nums[k]:
                        return True
        
        return False
```

## 复杂度分析

**方法一/二：贪心算法**

- **时间复杂度**：O(n)
  - 遍历数组一次
  
- **空间复杂度**：O(1)
  - 只使用两个变量

**方法三：动态规划**

- **时间复杂度**：O(n)
  - 三次遍历数组
  
- **空间复杂度**：O(n)
  - 两个辅助数组

**方法四：暴力解法**

- **时间复杂度**：O(n^3)
  - 三层循环
  
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心思想**：保持 `first` 和 `second` 尽可能小
2. **为什么可以更新 first？**
   - 即使 `first` 在 `second` 之后更新，之前的 `(first, second)` 关系依然有效
   - 新的 `first` 只是为了后续找到更好的三元组
3. **三种情况**：
   - `num <= first`：更新 first
   - `first < num <= second`：更新 second
   - `num > second`：找到答案
4. **初始值**：`first = second = inf`，确保第一个元素能更新 `first`
5. **不需要记录索引**：只需判断存在性，不需要返回具体索引

## 易错点

1. **条件判断顺序**：
   - 必须先判断 `num <= first`
   - 再判断 `num <= second`
   - 最后判断 `num > second`
   
2. **等号的处理**：
   - `num <= first` 和 `num <= second` 都要用 `<=`
   - 确保相等时也能正确更新

3. **初始值设置**：
   - 必须设为 `float('inf')`
   - 不能设为 `nums[0]`（会导致逻辑错误）

4. **理解 first 的更新**：
   - 很多人会困惑：`first` 在 `second` 之后更新，索引顺序不对怎么办？
   - 答案：我们只需要找到**任意一个**三元组，不需要是第一个

5. **边界情况**：`nums` 长度小于 3 时直接返回 `false`（方法一已隐含处理）

## 图解示例

示例 3：`nums = [2,1,5,0,4,6]`

```
初始: first = inf, second = inf

i=0, num=2:
  2 <= inf → first = 2
  状态: first=2, second=inf

i=1, num=1:
  1 <= 2 → first = 1
  状态: first=1, second=inf

i=2, num=5:
  5 > 1 且 5 <= inf → second = 5
  状态: first=1, second=5

i=3, num=0:
  0 <= 1 → first = 0
  状态: first=0, second=5
  注意：虽然 first 更新了，但之前的 (1, 5) 关系依然存在

i=4, num=4:
  4 > 0 且 4 <= 5 → second = 4
  状态: first=0, second=4

i=5, num=6:
  6 > 4 → 找到答案！
  三元组: (1, 5, 6) 或 (0, 4, 6) 或其他
  返回 true
```
