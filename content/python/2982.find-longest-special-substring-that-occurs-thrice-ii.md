## 题目描述

给你一个字符串 `s`，找到最长的**特殊子字符串**（只由单一字母重复组成），该子字符串至少出现三次。

若不存在，返回 -1。

**提示：**
- `3 <= s.length <= 5 * 10^5`
- `s` 只含小写英文字母

## 解题思路

与 I 相同，但 n 达到 5*10^5，需要高效算法。

将字符串按字符拆分为连续段，对每个字符统计各长度出现次数。

对于字符 ch 的各段长度列表（降序），对于长度 k 的查询，能提供的出现次数来自长度 >= k 的段：
- 长度为 L 的段对长度 k 的贡献为 L - k + 1

用二分查找或直接排序统计。

## Python 代码实现

### 方法一：统计连续段 + 二分（推荐）

```python
from collections import defaultdict
import bisect

class Solution:
    def maximumLength(self, s: str) -> int:
        n = len(s)

        # 统计每个字符的连续段长度
        run_lengths = defaultdict(list)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            run_lengths[s[i]].append(j - i)
            i = j

        def count_occurrences(lengths: list, k: int) -> int:
            # 统计长度为 k 的特殊子串在所有段中的总出现次数
            # 每段长度 L 贡献 max(0, L - k + 1) 次
            return sum(max(0, L - k + 1) for L in lengths)

        ans = -1
        for ch, lengths in run_lengths.items():
            # 对长度 k 用二分查找最大的满足 count >= 3 的 k
            lo, hi = 1, max(lengths)
            while lo <= hi:
                mid = (lo + hi) // 2
                if count_occurrences(lengths, mid) >= 3:
                    ans = max(ans, mid)
                    lo = mid + 1
                else:
                    hi = mid - 1

        return ans
```

### 方法二：直接排序统计（无需二分）

```python
from collections import defaultdict

class Solution:
    def maximumLength(self, s: str) -> int:
        run_lengths = defaultdict(list)
        i = 0
        while i < len(s):
            j = i
            while j < len(s) and s[j] == s[i]:
                j += 1
            run_lengths[s[i]].append(j - i)
            i = j

        ans = -1
        for ch, lengths in run_lengths.items():
            # 对每段排序，统计长度 k 的出现次数
            lengths.sort(reverse=True)
            # 枚举最大可能长度
            if not lengths:
                continue
            for k in range(max(lengths), 0, -1):
                cnt = sum(max(0, L - k + 1) for L in lengths)
                if cnt >= 3:
                    ans = max(ans, k)
                    break

        return ans
```

## 复杂度分析

- 时间复杂度：O(n + 26 * L * log(L))，L 为最长连续段，总体接近 O(n log n)
- 空间复杂度：O(n)，存储段长度

## 关键点总结

1. 将字符串拆分为连续相同字符的段，记录各段长度
2. 对每个字符，二分查找最大的 k 使得该字符的长度 k 子串出现 >= 3 次
3. 每段长度 L 对长度 k 的贡献 = max(0, L-k+1)

## 易错点

1. 不同字符的段独立统计（'a' 的段不贡献 'b' 的计数）
2. 出现次数跨多个段累加
3. 最优 k 满足单调性（k 越大，出现次数越少），可用二分
