## 题目描述

给你两个长度为 `n` 下标从 0 开始的整数数组 `nums1` 和 `nums2`。

每秒，对于所有下标 `0 <= i < n`，`nums1[i]` 的值增加 `nums2[i]`。

完成上述变化之后，你可以执行以下操作：
- 选择一个下标 `i`，并让 `nums1[i]` 变为 0。

允许你在任意时刻执行上述操作，返回使 `nums1` 元素之和小于等于 `x` 所需的**最少操作次数**。如果无法实现，返回 `-1`。

**示例 1：**
```
输入：nums1 = [1,2,3], nums2 = [1,2,3], x = 4
输出：3
解释：
t=0: 操作 i=2，nums1=[1,2,0]，sum=3<=4 不行？等等
实际上操作后增加时 sum 还会增加
```

**示例 2：**
```
输入：nums1 = [1,2,3], nums2 = [0,0,0], x = 4
输出：1
解释：操作任意一次即可
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^3`
- `0 <= nums1[i] <= 10^3`
- `0 <= nums2[i] <= 10^3`
- `0 <= x <= 10^6`

## 解题思路

**关键分析：**

假设我们最终执行了 t 次操作（在第 1 秒到第 t 秒各操作一次），且选择了一组下标 S。

在 t 秒后，第 i 个元素的贡献为：
- 若 i 在操作集中（在第 k 秒被归零），则它贡献 `(t - k) * nums2[i]`（归零后继续增长了 t-k 秒）
- 若 i 不在操作集中，则它贡献 `nums1[i] + t * nums2[i]`

**动态规划：**

枚举操作次数 t（0 到 n）：
- 必须在 t 步内将 `sum(nums1) + t * sum(nums2)` 减少到 x 以下
- 对于已选 t 个下标，最优策略是让"总减少量"最大
- 减少量 = `sum(nums1[i] + (t - rank_i) * nums2[i])`，其中 rank_i 是第 i 次操作的排名

可以证明：应该按 `nums2[i]` 从小到大排序，然后用 DP 计算选 j 个元素能减少的最大值。

**DP 定义：** `dp[j]` = 选 j 个元素，最大可减少量（在 j 次操作后）

**转移：** 对每个元素 (a, b) = (nums1[i], nums2[i])，按 b 排序，`dp[j] = max(dp[j], dp[j-1] + a + j * b)`

## Python 代码实现

### 方法一：排序 + 动态规划（推荐）

```python
from typing import List

class Solution:
    def minimumTime(self, nums1: List[int], nums2: List[int], x: int) -> int:
        n = len(nums1)
        sum1 = sum(nums1)
        sum2 = sum(nums2)

        # 按 nums2 升序排序，贪心地处理
        pairs = sorted(zip(nums2, nums1))  # (b, a) 按 b 排序

        # dp[j] 表示从前 i 个元素中选 j 个，可以减少的最大值
        # 在第 t 秒操作时，若第 j 个选中的元素按时间排序排在第 j 位
        # 则其贡献的减少量为 a + j * b（因为它是 j 步中最后一个被零化的）
        dp = [0] * (n + 1)

        for i, (b, a) in enumerate(pairs):
            # 从后往前更新，避免重复使用同一元素
            for j in range(i + 1, 0, -1):
                dp[j] = max(dp[j], dp[j - 1] + a + j * b)

        # 枚举操作次数 t
        for t in range(n + 1):
            # t 次操作后，总值 = sum1 + t * sum2 - dp[t]
            if sum1 + t * sum2 - dp[t] <= x:
                return t

        return -1
```

### 方法二：带详细注释的版本

```python
from typing import List

class Solution:
    def minimumTime(self, nums1: List[int], nums2: List[int], x: int) -> int:
        n = len(nums1)
        sum1 = sum(nums1)
        sum2 = sum(nums2)

        # 若初始和已满足条件（0 次操作）
        if sum1 <= x:
            return 0

        # 按 nums2 从小到大排序
        # 直觉：nums2 大的元素被晚清零，可以减少更多增长量
        pairs = sorted(zip(nums2, nums1))

        # dp[j] = 选 j 个元素（按最优顺序），能减少的最大值
        dp = [0] * (n + 1)

        for rank, (b, a) in enumerate(pairs):
            # rank 从 0 开始，1-indexed 排名为 rank+1
            # 逆序更新（0/1 背包模板）
            for j in range(rank + 1, 0, -1):
                # 选当前元素作为第 j 个操作：减少量 = a（初始值）+ j * b（增长减少）
                dp[j] = max(dp[j], dp[j - 1] + a + j * b)

        for t in range(n + 1):
            # t 秒后总值 = (sum1 + t * sum2) - dp[t]
            # dp[t] 是 t 次操作最多能减少的量
            if sum1 + t * sum2 - dp[t] <= x:
                return t

        return -1
```

## 复杂度分析

- 时间复杂度：O(n^2)，外层遍历 n 个元素，内层 DP 最多 n 次更新
- 空间复杂度：O(n)，DP 数组

## 关键点总结

1. 按 `nums2` 排序后，排在第 j 位被清零的元素能减少 `a + j * b`
2. 核心思想：操作次数少的元素（先被清零）`nums2` 要小，留更多增长给晚清零的
3. DP 使用 0/1 背包思想，逆序更新防止重复选择
4. 枚举操作次数 t，检查 `sum1 + t * sum2 - dp[t] <= x`

## 易错点

1. 排序方向：必须按 nums2 升序，而不是降序
2. DP 更新顺序：必须从大到小（避免同一元素被选多次）
3. 初始检查 `sum1 <= x` 时直接返回 0
