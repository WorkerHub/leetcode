## 题目描述

给你两个正整数 `n` 和 `limit`。

将 `n` 颗糖果分给 3 个小朋友，每个小朋友至多获得 `limit` 颗糖果，求分配方案数。

**示例 1：**
```
输入：n = 5, limit = 2
输出：3
```

**示例 2：**
```
输入：n = 3, limit = 3
输出：10
```

**提示：**
- `1 <= n <= 50`
- `1 <= limit <= 50`

## 解题思路

数据范围小（n, limit <= 50），直接三重循环暴力枚举每个小朋友分别得到多少颗。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        count = 0
        for a in range(min(n, limit) + 1):
            for b in range(min(n - a, limit) + 1):
                c = n - a - b
                # 第三个小朋友得到 c 颗
                if 0 <= c <= limit:
                    count += 1
        return count
```

### 方法二：数学公式（容斥）

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def C2(x: int) -> int:
            return x * (x - 1) // 2 if x >= 2 else 0

        return (C2(n + 2)
                - 3 * C2(n - limit + 1)
                + 3 * C2(n - 2 * limit)
                - C2(n - 3 * limit - 1))
```

## 复杂度分析

- 时间复杂度：O(limit^2)，两层循环
- 空间复杂度：O(1)

## 关键点总结

1. 枚举前两个小朋友的分配，第三个自动确定
2. 三个条件：a in [0, limit]，b in [0, limit]，c = n-a-b in [0, limit]
3. 数学方法用容斥原理，O(1) 计算

## 易错点

1. 第三个小朋友的糖果数可能为负或超过 limit，需要检查
2. 各小朋友最少 0 颗（可以一颗不得）
