## 题目描述

给你一个 `m x n` 的矩阵 `grid`，以及一个修改列表 `mods`，其中 `mods[i] = [r, c, val]` 表示将 `grid[r][c]` 改为 `val`。

应用所有修改后，判断矩阵中每一行和每一列是否都包含唯一的元素（即每行所有元素互不相同，每列所有元素互不相同）。

**示例 1：**

```
输入：grid = [[1,2],[3,4]], mods = []
输出：true
```

**示例 2：**

```
输入：grid = [[1,2],[1,3]], mods = []
输出：false
解释：第0列有两个1
```

**提示：**

- `1 <= m, n <= 100`
- `1 <= grid[i][j] <= 10^6`

## 解题思路

1. 应用所有修改
2. 检查每行是否有重复元素
3. 检查每列是否有重复元素

## Python 代码实现

### 方法一：直接模拟 + 集合检验（推荐）

```python
from typing import List
import copy

class Solution:
    def checkUniqueness(self, grid: List[List[int]], mods: List[List[int]]) -> bool:
        g = copy.deepcopy(grid)
        m, n = len(g), len(g[0])

        # 应用修改
        for r, c, val in mods:
            g[r][c] = val

        # 检查每行
        for i in range(m):
            if len(set(g[i])) != n:
                return False

        # 检查每列
        for j in range(n):
            col = [g[i][j] for i in range(m)]
            if len(set(col)) != m:
                return False

        return True
```

### 方法二：Counter 检验

```python
from typing import List
from collections import Counter
import copy

class Solution:
    def checkUniqueness(self, grid: List[List[int]], mods: List[List[int]]) -> bool:
        g = [row[:] for row in grid]
        for r, c, val in mods:
            g[r][c] = val

        m, n = len(g), len(g[0])
        for row in g:
            if max(Counter(row).values()) > 1:
                return False
        for j in range(n):
            col = [g[i][j] for i in range(m)]
            if max(Counter(col).values()) > 1:
                return False
        return True
```

## 复杂度分析

- 时间复杂度：O(m * n + len(mods))
- 空间复杂度：O(m * n)

## 关键点总结

1. 先应用所有修改，再统一检验
2. 集合大小等于元素数则无重复
3. 行列分开检验

## 易错点

1. 深拷贝 grid，不修改原始数据
2. 修改按顺序依次应用
3. 行长度为 n，列长度为 m
