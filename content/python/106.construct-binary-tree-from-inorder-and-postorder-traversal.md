## 题目描述

给定两个整数数组 `inorder` 和 `postorder`，其中 `inorder` 是二叉树的中序遍历，`postorder` 是同一棵树的后序遍历，请构造并返回这颗二叉树。

**示例 1：**

```
输入：inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出：[3,9,20,null,null,15,7]
```

**示例 2：**

```
输入：inorder = [-1], postorder = [-1]
输出：[-1]
```

**提示：**

- `1 <= inorder.length <= 3000`
- `postorder.length == inorder.length`
- `-3000 <= inorder[i], postorder[i] <= 3000`
- `inorder` 和 `postorder` 都由不同的值组成
- `postorder` 中每一个值都在 `inorder` 中
- `inorder` 保证是树的中序遍历
- `postorder` 保证是树的后序遍历

## 解题思路

这道题与第 105 题非常相似，只是把前序遍历换成了后序遍历。核心思路是理解中序遍历和后序遍历的特点：

1. **中序遍历**：左子树 -> 根节点 -> 右子树
2. **后序遍历**：左子树 -> 右子树 -> 根节点

**关键观察**：
- 后序遍历的最后一个元素一定是根节点（与前序遍历的第一个元素相对应）
- 在中序遍历中找到根节点的位置后，其左边都是左子树的节点，右边都是右子树的节点
- 根据左子树节点的数量，可以在后序遍历中划分出左子树和右子树的部分

**算法流程**：
1. 从后序遍历中取出最后一个元素作为根节点
2. 在中序遍历中找到根节点的位置
3. 根据位置计算左子树的节点数量
4. 递归构造左子树和右子树
5. 返回根节点

**与第 105 题的区别**：
- 第 105 题：前序遍历取第一个元素，先构建左子树后构建右子树
- 第 106 题：后序遍历取最后一个元素，先构建右子树后构建左子树（或者调整索引）

## Python 代码实现

### 方法一：递归 + 哈希表（推荐）⭐

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> Optional[TreeNode]:
        # 构建中序遍历值到索引的映射
        inorder_map = {val: idx for idx, val in enumerate(inorder)}
        
        def build(in_left: int, in_right: int, post_left: int, post_right: int) -> Optional[TreeNode]:
            """
            递归构建二叉树
            in_left, in_right: 中序遍历的左右边界
            post_left, post_right: 后序遍历的左右边界
            """
            # 递归终止条件
            if in_left > in_right:
                return None
            
            # 后序遍历的最后一个节点就是根节点
            root_val = postorder[post_right]
            root = TreeNode(root_val)
            
            # 在中序遍历中找到根节点的位置
            in_root_index = inorder_map[root_val]
            
            # 计算左子树的节点数量
            left_subtree_size = in_root_index - in_left
            
            # 递归构建左子树
            # 中序遍历：[in_left, in_root_index-1]
            # 后序遍历：[post_left, post_left+left_subtree_size-1]
            root.left = build(
                in_left,
                in_root_index - 1,
                post_left,
                post_left + left_subtree_size - 1
            )
            
            # 递归构建右子树
            # 中序遍历：[in_root_index+1, in_right]
            # 后序遍历：[post_left+left_subtree_size, post_right-1]
            root.right = build(
                in_root_index + 1,
                in_right,
                post_left + left_subtree_size,
                post_right - 1
            )
            
            return root
        
        # 开始递归构建
        return build(0, len(inorder) - 1, 0, len(postorder) - 1)
```

### 方法二：递归 + 数组切片（易理解版）

```python
class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> Optional[TreeNode]:
        # 递归终止条件
        if not inorder or not postorder:
            return None
        
        # 后序遍历的最后一个元素是根节点
        root_val = postorder[-1]
        root = TreeNode(root_val)
        
        # 在中序遍历中找到根节点的位置
        mid_index = inorder.index(root_val)
        
        # 递归构建左子树和右子树
        # 左子树：中序遍历的左半部分，后序遍历的前 mid_index 个
        root.left = self.buildTree(inorder[:mid_index], postorder[:mid_index])
        # 右子树：中序遍历的右半部分，后序遍历去掉左子树和根节点
        root.right = self.buildTree(inorder[mid_index+1:], postorder[mid_index:-1])
        
        return root
```

### 方法三：递归（从后向前构建）

```python
class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> Optional[TreeNode]:
        # 使用哈希表存储中序遍历的索引
        inorder_map = {val: idx for idx, val in enumerate(inorder)}
        # 后序遍历的当前索引（从后向前）
        self.post_idx = len(postorder) - 1
        
        def build(in_left: int, in_right: int) -> Optional[TreeNode]:
            # 递归终止条件
            if in_left > in_right:
                return None
            
            # 取后序遍历的当前节点作为根节点
            root_val = postorder[self.post_idx]
            root = TreeNode(root_val)
            
            # 在中序遍历中找到根节点位置
            in_root_index = inorder_map[root_val]
            
            # 后序遍历索引向前移动
            self.post_idx -= 1
            
            # 注意：后序遍历是 左-右-根，所以从后向前是 根-右-左
            # 因此要先构建右子树，再构建左子树
            root.right = build(in_root_index + 1, in_right)
            root.left = build(in_left, in_root_index - 1)
            
            return root
        
        return build(0, len(inorder) - 1)
```

## 复杂度分析

### 方法一和方法三

- **时间复杂度**：O(n)，其中 n 是树中的节点数。每个节点都会被访问一次。
- **空间复杂度**：O(n)，哈希表需要存储 n 个节点的映射关系，递归调用栈的深度最坏情况下为 O(n)。

### 方法二

- **时间复杂度**：O(n²)，每次递归都需要切片数组和查找索引。
- **空间复杂度**：O(n²)，切片会创建新的数组副本。

## 关键点总结

1. **后序遍历特点**：最后一个元素是根节点，这是与前序遍历的主要区别
2. **索引计算**：后序遍历的索引划分要特别注意，右子树的结束位置是 `post_right - 1`
3. **构建顺序**：方法三中要注意从后向前遍历时要先构建右子树再构建左子树
4. **哈希表优化**：与第 105 题一样，使用哈希表可以将查找时间从 O(n) 降到 O(1)
5. **模板通用性**：掌握这个模板后，可以轻松应对所有二叉树重建问题

## 易错点

1. **后序遍历取值位置**：要取最后一个元素而不是第一个
2. **右子树索引**：后序遍历右子树的结束索引是 `post_right - 1`，因为 `post_right` 是根节点
3. **方法三构建顺序**：从后向前时要先构建右子树，这与直觉不同，容易出错
4. **边界条件**：递归的终止条件要检查 `in_left > in_right` 而不是等于
5. **数组为空**：要处理空数组的情况
