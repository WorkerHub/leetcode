## 题目描述

给你两个字符串 `word1` 和 `word2`。你需要按下述方式构造一个新字符串 `merge`：如果 `word1` 或 `word2` 非空，选择下面选项之一继续操作：
- 如果 `word1` 非空，将 `word1[0]` 追加到 `merge` 末尾，并将其从 `word1` 中删除。
- 如果 `word2` 非空，将 `word2[0]` 追加到 `merge` 末尾，并将其从 `word2` 中删除。

返回你可以构造的**字典序最大**的 `merge`。

**示例 1：**
```
输入：word1 = "cabaa", word2 = "bcaaa"
输出："cbcabaaaaa"
```

**提示：**
- `1 <= word1.length, word2.length <= 3000`

## 解题思路

贪心：每次从两个字符串的当前头部选择字典序更大的字符加入结果。

若两个头部字符相同，则比较剩余字符串的字典序，选字典序更大的那个字符串的头部字符。

## 代码实现

### 方法一：双指针贪心（推荐）

```python
class Solution:
    def largestMerge(self, word1: str, word2: str) -> str:
        result = []
        i, j = 0, 0
        
        while i < len(word1) and j < len(word2):
            # 比较两个字符串从当前位置开始的字典序
            if word1[i:] >= word2[j:]:
                result.append(word1[i])
                i += 1
            else:
                result.append(word2[j])
                j += 1
        
        # 追加剩余部分
        result.append(word1[i:])
        result.append(word2[j:])
        
        return ''.join(result)
```

### 方法二：使用两个指针显式比较

```python
class Solution:
    def largestMerge(self, word1: str, word2: str) -> str:
        result = []
        p1, p2 = 0, 0
        n1, n2 = len(word1), len(word2)
        
        while p1 < n1 and p2 < n2:
            # 逐字符比较找到第一个不同的位置
            if word1[p1] > word2[p2]:
                result.append(word1[p1])
                p1 += 1
            elif word1[p1] < word2[p2]:
                result.append(word2[p2])
                p2 += 1
            else:
                # 当前字符相同，比较后续字符串
                if word1[p1:] >= word2[p2:]:
                    result.append(word1[p1])
                    p1 += 1
                else:
                    result.append(word2[p2])
                    p2 += 1
        
        result.append(word1[p1:])
        result.append(word2[p2:])
        
        return ''.join(result)
```

## 复杂度分析

- **时间复杂度**：O((m + n) * max(m, n))，字符串比较最坏情况 O(min(m,n))
- **空间复杂度**：O(m + n)，结果字符串

## 关键点总结

1. 每次选字典序较大的字符串的头部字符
2. 当头部字符相同时，比较剩余字符串的字典序
3. Python 字符串比较直接支持字典序比较

## 易错点

- 当两个字符串字典序相同时（如都以 "aa" 开头），选哪个都一样
