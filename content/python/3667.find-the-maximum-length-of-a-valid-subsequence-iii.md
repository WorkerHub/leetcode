## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，找到最长的子序列，使得相邻元素之和模 `k` 的值相同（即所有相邻对的 `(a + b) % k` 相等）。

返回该子序列的最大长度。

**示例 1：**

```
输入：nums = [1,2,3,4,5], k = 2
输出：5
解释：[1,2,3,4,5]，相邻和模2：(1+2)%2=1,(2+3)%2=1,(3+4)%2=1,(4+5)%2=1，全为1
```

**示例 2：**

```
输入：nums = [1,4,2,3,1,4], k = 3
输出：4
解释：[1,4,1,4]，相邻和模3：(1+4)%3=2，全为2
```

**提示：**

- `2 <= nums.length <= 10^3`
- `1 <= nums[i] <= 10^7`
- `1 <= k <= 10^3`

## 解题思路

DP：枚举目标余数 `r`（0 到 k-1）。

对每个目标余数 `r`，找最长子序列使得相邻元素之和 mod k = r。

`dp[r][v]` = 以余数 `v` 结尾、所有相邻和模 k = r 的最长子序列。

对新元素 `nums[j]`，其余数为 `nums[j] % k`，可以接在所有以余数 `(r - nums[j] % k + k) % k` 结尾的序列后面。

## Python 代码实现

### 方法一：枚举目标余数（推荐）

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 1

        for r in range(k):
            # dp[v] = 相邻和模k=r，以余数v结尾的最长子序列
            dp = [0] * k
            for x in nums:
                xmod = x % k
                # 需要前一个元素的余数 prev 满足 (prev + xmod) % k = r
                prev = (r - xmod + k) % k
                dp[xmod] = max(dp[xmod], dp[prev] + 1)
                ans = max(ans, dp[xmod])

        return ans
```

### 方法二：2D DP

```python
from typing import List

class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        # dp[r][v] = 目标余数r，以余数v结尾的最长子序列
        dp = [[0] * k for _ in range(k)]
        ans = 1

        for x in nums:
            xmod = x % k
            for r in range(k):
                prev = (r - xmod + k) % k
                if dp[r][prev] > 0 or prev == xmod:
                    dp[r][xmod] = max(dp[r][xmod], dp[r][prev] + 1)
                    ans = max(ans, dp[r][xmod])
                # 单个元素
                dp[r][xmod] = max(dp[r][xmod], 1)
                ans = max(ans, dp[r][xmod])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k^2)

## 关键点总结

1. 枚举目标余数 r，分别计算最优子序列
2. 新元素 `x` 接在余数为 `(r - x%k + k) % k` 的序列后
3. 所有目标余数中取最大值

## 易错点

1. 单个元素构成长度为 1 的子序列，需初始化
2. 余数的范围是 0 到 k-1
3. 负数模 k 在 Python 中自动处理（Python 取模结果非负）
