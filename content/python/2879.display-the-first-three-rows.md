## 题目描述

给定一个 DataFrame `employees`，编写一个解决方案，显示该 DataFrame 的前 3 行。

**示例：**
```
输入：
employees DataFrame 有多行数据

输出：前 3 行
```

## Python 代码实现

### 方法一：head() 方法（推荐）

```python
import pandas as pd

def selectFirstRows(employees: pd.DataFrame) -> pd.DataFrame:
    # df.head(n) 返回前 n 行，默认 5 行
    return employees.head(3)
```

### 方法二：切片

```python
import pandas as pd

def selectFirstRows(employees: pd.DataFrame) -> pd.DataFrame:
    return employees.iloc[:3]
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `df.head(n)` 返回前 n 行
2. `df.iloc[:3]` 用整数位置切片，等效
3. `df.iloc[0:3]` 也可以，包含下标 0, 1, 2
