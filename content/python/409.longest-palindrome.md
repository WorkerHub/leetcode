## 题目描述

给定一个包含大写字母和小写字母的字符串 s，返回通过这些字母构造成的最长的回文串的长度。

在构造过程中，请注意区分大小写。比如 "Aa" 不能当做一个回文字符串。

**示例 1：**
```
输入：s = "abccccdd"
输出：7
解释：我们可以构造的最长的回文串是 "dccaccd"，它的长度是 7。
```

**示例 2：**
```
输入：s = "a"
输出：1
```

**示例 3：**
```
输入：s = "aaaaaccc"
输出：7
```

**提示：**
- 1 <= s.length <= 2000
- s 只由小写和大写英文字母组成

## 解题思路

回文串的特点：
1. 偶数个相同字符可以全部使用（左右对称）
2. 奇数个相同字符可以使用偶数部分 + 1个放中间
3. 最多只能有一个字符出现奇数次并放在中间

贪心策略：
1. 统计每个字符的出现次数
2. 出现偶数次的字符全部使用
3. 出现奇数次的字符使用 count - 1（偶数部分）
4. 如果有奇数次的字符，可以选一个放中间，长度 +1

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from collections import Counter

class Solution:
    def longestPalindrome(self, s: str) -> int:
        """
        统计字符频次，贪心构造回文串
        """
        count = Counter(s)
        length = 0
        has_odd = False
        
        for char, freq in count.items():
            if freq % 2 == 0:
                # 偶数次，全部使用
                length += freq
            else:
                # 奇数次，使用偶数部分
                length += freq - 1
                has_odd = True
        
        # 如果有奇数频次的字符，可以放一个在中间
        if has_odd:
            length += 1
        
        return length
```

### 方法二：简化版

```python
from collections import Counter

class Solution:
    def longestPalindrome(self, s: str) -> int:
        count = Counter(s)
        length = sum(freq // 2 * 2 for freq in count.values())
        # 如果长度小于字符串长度，说明有奇数频次的字符，可以加1
        return length + 1 if length < len(s) else length
```

### 方法三：位运算优化

```python
class Solution:
    def longestPalindrome(self, s: str) -> int:
        """
        使用集合记录出现奇数次的字符
        """
        char_set = set()
        
        for char in s:
            if char in char_set:
                char_set.remove(char)  # 配对成功
            else:
                char_set.add(char)  # 等待配对
        
        # char_set 中剩余的是出现奇数次的字符
        # 长度 = 总长度 - 奇数字符个数 + 1（可以选一个放中间）
        odd_count = len(char_set)
        if odd_count > 0:
            return len(s) - odd_count + 1
        return len(s)
```

## 复杂度分析

- **时间复杂度**：O(n)
  - 遍历字符串一次
  
- **空间复杂度**：O(1)
  - 最多 52 个字母（大小写）

## 关键点总结

1. 回文串的对称性
2. 偶数频次字符全用，奇数频次字符用偶数部分
3. 最多一个字符可以放中间

## 易错点

1. 忘记处理中间字符（+1）
2. 误认为只能有一个奇数频次字符
