## 题目描述

给你一个长桌子，由字符 `'*'`（盘子）和 `'|'`（蜡烛）组成的字符串 `s` 表示。

给你一个查询数组 `queries`，`queries[i] = [left, right]`，表示查询子串 `s[left..right]` 中，在**两个蜡烛之间**的盘子数（盘子必须被蜡烛夹在中间）。

**示例 1：**
```
输入：s = "**|**|***|", queries = [[2,5],[5,9]]
输出：[2,3]
```

**提示：**
- `3 <= s.length <= 10^5`
- `s` 仅由 `'*'` 和 `'|'` 组成
- `1 <= queries.length <= 10^5`

## 解题思路

**预处理（前缀和 + 蜡烛位置）：**
1. `prefix_plates[i]`：`s[0..i-1]` 中盘子的数量（前缀和）
2. `left_candle[i]`：位置 `i` 左边最近的蜡烛位置（含 i）
3. `right_candle[i]`：位置 `i` 右边最近的蜡烛位置（含 i）

对于查询 `[l, r]`：
- 找区间内最左的蜡烛：`lc = right_candle[l]`
- 找区间内最右的蜡烛：`rc = left_candle[r]`
- 若 `lc < rc`：两蜡烛间的盘子数 = `prefix_plates[rc] - prefix_plates[lc + 1]`

## 代码实现

### 方法一：前缀和 + 预计算蜡烛位置（推荐）

```python
from typing import List

class Solution:
    def platesBetweenCandles(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)

        # 前缀盘子数
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (1 if s[i] == '*' else 0)

        # left_candle[i]：i 左边（含 i）最近的蜡烛位置，无则 -1
        left_candle = [-1] * n
        last = -1
        for i in range(n):
            if s[i] == '|':
                last = i
            left_candle[i] = last

        # right_candle[i]：i 右边（含 i）最近的蜡烛位置，无则 n
        right_candle = [n] * n
        nxt = n
        for i in range(n - 1, -1, -1):
            if s[i] == '|':
                nxt = i
            right_candle[i] = nxt

        result = []
        for l, r in queries:
            lc = right_candle[l]  # l 右边最近的蜡烛（区间内的最左蜡烛）
            rc = left_candle[r]   # r 左边最近的蜡烛（区间内的最右蜡烛）

            if lc < rc:
                # 两蜡烛间的盘子数 = prefix[rc] - prefix[lc + 1]
                result.append(prefix[rc] - prefix[lc + 1])
            else:
                result.append(0)  # 区间内没有两个蜡烛

        return result
```

### 方法二：二分查找蜡烛位置

```python
from typing import List
import bisect

class Solution:
    def platesBetweenCandles(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        candles = [i for i in range(n) if s[i] == '|']

        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + (s[i] == '*')

        result = []
        for l, r in queries:
            # 区间内最左蜡烛：第一个 >= l 的蜡烛
            li = bisect.bisect_left(candles, l)
            # 区间内最右蜡烛：最后一个 <= r 的蜡烛
            ri = bisect.bisect_right(candles, r) - 1

            if li <= ri:
                lc, rc = candles[li], candles[ri]
                result.append(prefix[rc] - prefix[lc + 1])
            else:
                result.append(0)

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 预计算数组 | O(n + q) | O(n) |
| 二分查找 | O(n + q log n) | O(n) |

## 关键点总结

1. 预处理蜡烛位置和前缀和，使每次查询 O(1)
2. 区间内"两个蜡烛之间的盘子"等价于找区间内最左和最右蜡烛，计算其间盘子数
3. 若区间内少于 2 个蜡烛，答案为 0

## 易错点

- `lc < rc` 而不是 `lc <= rc`（两个相同位置的蜡烛间没有盘子）
- 前缀和计算盘子数：`prefix[rc] - prefix[lc + 1]`（不包含两端蜡烛）
