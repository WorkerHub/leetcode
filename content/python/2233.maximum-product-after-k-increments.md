## 题目描述

给你一个非负整数数组 `nums` 和一个整数 `k`，每次操作可以选择数组中的一个元素将其**加 1**。

返回执行 `k` 次操作后的数组的最大**乘积**。答案对 `10^9 + 7` 取模。

**示例 1：**
```
输入：nums = [0,4], k = 5
输出：20
解释：0 增加5次变5，5*4=20。
```

**示例 2：**
```
输入：nums = [6,3,3,2], k = 2
输出：216
解释：2次增加：2->3->4，3*3*4*6? 不对... 最优是2->3, 3->4, 乘积3*3*4*6=216。
```

## 解题思路

**贪心：** 每次将最小的元素加 1，使乘积增长最快（均值-方差不等式：各元素越均等，乘积越大）。

使用**最小堆**，每次取出最小值加 1 后放回，重复 k 次。

## 代码实现

### 方法一：最小堆贪心（推荐）

```python
from typing import List
import heapq

class Solution:
    def maximumProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7

        # 建最小堆
        heapq.heapify(nums)

        # 每次将最小元素加1
        for _ in range(k):
            x = heapq.heappop(nums)
            heapq.heappush(nums, x + 1)

        # 计算乘积（取模）
        result = 1
        for x in nums:
            result = (result * x) % MOD

        return result
```

### 方法二：数学优化（批量处理相同最小值）

```python
from typing import List
import heapq

class Solution:
    def maximumProduct(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        heapq.heapify(nums)

        while k > 0:
            min_val = nums[0]
            # 计算有多少个元素等于当前最小值
            # 以及将它们全部提升到下一级需要多少操作
            # 这里直接单步操作也可，但批量更高效
            heapq.heapreplace(nums, min_val + 1)
            k -= 1

        result = 1
        for x in nums:
            result = result * x % MOD
        return result
```

## 复杂度分析

- 时间复杂度：O((n + k) log n)，k 次堆操作，每次 O(log n)。
- 空间复杂度：O(n)，堆。

## 关键点总结

1. 贪心：每次增加最小元素，使整体乘积增量最大。
2. 乘积取模在最后统一计算（也可以逐步取模，但此处整数不大，最后取模即可）。
3. `heapreplace` = `heappop` + `heappush`，更高效。

## 易错点

- 最终乘积要对 `10^9 + 7` 取模。
- 贪心的正确性：每次增加最小值，因为增加较小的数对乘积的乘性增益更大（若最小值为 a，加1后变 (a+1)/a，越小增益越大）。
