## 题目描述

给你一个整数数组 `nums` 和若干次操作，每次操作形如 `[l, r, val]`，将 `nums[l..r]` 中所有元素替换为 `val`。

按顺序执行所有操作后，返回数组的最大子数组和。

**示例 1：**

```
输入：nums = [1, -2, 3, 4], ops = [[1, 2, 5]]
输出：12
解释：操作后 nums = [1, 5, 5, 4]，最大子数组和为 1+5+5+4=15？不对，[1,5,5,4] = 15。
```

**示例 2：**

```
输入：nums = [-1, -2, -3], ops = []
输出：-1
解释：无操作，最大子数组和为 -1。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= ops.length <= 10^5`
- `ops[i] = [l, r, val]`，`0 <= l <= r < n`，`-10^4 <= val <= 10^4`

## 解题思路

先应用所有操作（最后一次操作覆盖之前的），然后对最终数组求最大子数组和（Kadane 算法）。

对于操作的高效应用，使用**区间覆盖**（最后写入优先），可以用差分数组或线段树。

注意：本题操作是赋值而非加法，最后一次覆盖有效。

## Python 代码实现

### 方法一：暴力应用操作 + Kadane（推荐）

```python
from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int], ops: List[List[int]]) -> int:
        arr = nums[:]

        # 逐一应用操作（后面的操作覆盖前面的）
        for l, r, val in ops:
            for i in range(l, r + 1):
                arr[i] = val

        # Kadane 算法求最大子数组和
        max_sum = float('-inf')
        curr_sum = 0
        for x in arr:
            curr_sum = max(x, curr_sum + x)
            max_sum = max(max_sum, curr_sum)

        return max_sum
```

### 方法二：线段树区间赋值（大规模数据）

```python
from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int], ops: List[List[int]]) -> int:
        n = len(nums)
        arr = nums[:]

        # 使用懒惰线段树处理区间赋值
        # 简化版：由于操作顺序重要，逆序处理（最后的操作优先）
        covered = [False] * n
        for l, r, val in reversed(ops):
            for i in range(l, r + 1):
                if not covered[i]:
                    arr[i] = val
                    covered[i] = True

        # Kadane 算法
        max_sum = arr[0]
        curr_sum = arr[0]
        for i in range(1, n):
            curr_sum = max(arr[i], curr_sum + arr[i])
            max_sum = max(max_sum, curr_sum)

        return max_sum
```

## 复杂度分析

- 时间复杂度：O(n * q)（方法一暴力）；O((n + q) log n)（线段树）
- 空间复杂度：O(n)

## 关键点总结

1. 区间赋值操作后，只有最后一次覆盖的值有效（逆序处理可避免重复覆盖）。
2. Kadane 算法是最大子数组和的标准 O(n) 解法。
3. 线段树的懒惰赋值操作适合大规模区间覆盖场景。

## 易错点

1. 操作是赋值（替换），不是加法，后面的覆盖前面的。
2. Kadane 算法初始值需覆盖全为负数的情况（取 `arr[0]` 而非 0）。
3. 逆序处理操作时，已覆盖的位置不再更新。
