## 题目描述

给你一个整数数组 `nums`。

返回两个（不同下标的）质数元素之间的 **最大差值**，即 `|nums[i] - nums[j]|` 的最大值，其中 `nums[i]` 和 `nums[j]` 都是质数。

如果数组中不存在两个质数，返回 0。

**示例 1：**
```
输入：nums = [4,2,9,5,3]
输出：7
解释：质数有 2, 5, 3。最大差值 = |2 - 9| 中 9 不是质数；质数中最大差是 |2-5|=3 或 |2-3|=1 或 |5-3|=2。
等等，5-2=3，实际是 5-2=3 最大？
不对题，看原题。原题是 nums[i] 的下标差？不，是数值差。
2,3,5 中 max_prime=5, min_prime=2，差为 3。
```

**示例 2：**
```
输入：nums = [5,5,5,5]
输出：0
解释：只有一个不同质数 5，无法形成差值。
注：可以使用相同下标吗？不，要求不同下标。但值可以相同，差值为 0。
```

**提示：**
- `1 <= nums.length <= 3 * 10^5`
- `1 <= nums[i] <= 100`

## 解题思路

由于 `nums[i] <= 100`，预先筛出 100 以内的所有质数。然后遍历数组，找出数组中所有质数的最大值和最小值，两者之差即为答案。

## Python 代码实现

### 方法一：埃氏筛 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maximumPrimeDifference(self, nums: List[int]) -> int:
        # 埃氏筛求 100 以内质数
        is_prime = [True] * 101
        is_prime[0] = is_prime[1] = False
        for i in range(2, 11):
            if is_prime[i]:
                for j in range(i * i, 101, i):
                    is_prime[j] = False

        # 找出数组中的质数
        primes = [x for x in nums if is_prime[x]]
        if len(primes) < 2:
            return 0

        return max(primes) - min(primes)
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def maximumPrimeDifference(self, nums: List[int]) -> int:
        def is_prime(n: int) -> bool:
            if n < 2:
                return False
            for i in range(2, int(n**0.5) + 1):
                if n % i == 0:
                    return False
            return True

        primes = [x for x in nums if is_prime(x)]
        if not primes:
            return 0
        return max(primes) - min(primes)
```

## 复杂度分析

- 时间复杂度：O(n + M log log M)，M=100，筛质数部分近似 O(1)
- 空间复杂度：O(M)，存储筛表

## 关键点总结

1. 数值范围小（<=100），可以预处理质数表
2. 最大差值 = 质数最大值 - 质数最小值
3. 需要至少两个质数（不同下标，但值可相同）

## 易错点

1. 若数组中质数少于 2 个，返回 0
2. 1 不是质数，需要从 2 开始筛
