## 题目描述

给你一个整数数组 `nums`，找到元素互不相同的子数组中，元素之和最大的那个，返回该最大和。

**示例 1：**

```
输入：nums = [1, 2, 3, 1, 2]
输出：6
解释：子数组 [1,2,3] 元素各不相同，和为 6。
```

**示例 2：**

```
输入：nums = [1, 1, 1, 1]
输出：1
解释：最长不重复子数组长度为 1，最大和为 1。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**滑动窗口**：维护无重复元素的最大和子数组。

使用双指针 `[left, right]`，当加入 `right` 时出现重复，则移动 `left` 直到无重复。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSubarraySum(self, nums: List[int]) -> int:
        left = 0
        curr_sum = 0
        max_sum = 0
        freq = defaultdict(int)

        for right in range(len(nums)):
            v = nums[right]
            freq[v] += 1
            curr_sum += v

            # 有重复，收缩左端
            while freq[v] > 1:
                lv = nums[left]
                freq[lv] -= 1
                curr_sum -= lv
                left += 1

            max_sum = max(max_sum, curr_sum)

        return max_sum
```

### 方法二：哈希表记录最近位置

```python
from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int]) -> int:
        last_seen = {}
        left = 0
        curr_sum = 0
        max_sum = 0

        for right, v in enumerate(nums):
            if v in last_seen and last_seen[v] >= left:
                # 移动左端到重复位置之后
                while left <= last_seen[v]:
                    curr_sum -= nums[left]
                    left += 1
            curr_sum += v
            last_seen[v] = right
            max_sum = max(max_sum, curr_sum)

        return max_sum
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各移动 n 次
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 滑动窗口维护无重复子数组，右端移入重复元素时收缩左端。
2. 维护当前窗口和 `curr_sum`，每次更新最大和。
3. 方法二利用最近位置直接跳过，避免逐步收缩。

## 易错点

1. 收缩左端时不仅移除最左元素，还需更新 `curr_sum`。
2. `last_seen[v] >= left` 检查重复是否在窗口内。
