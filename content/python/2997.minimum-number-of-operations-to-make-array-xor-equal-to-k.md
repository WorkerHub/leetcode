## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，每次操作可以将 `nums` 中任意元素的任意一个二进制位翻转（0 变 1 或 1 变 0）。

返回使所有元素的按位异或等于 `k` 所需的最少操作次数。

**示例 1：**
```
输入：nums = [2,1,3,4], k = 1
输出：2
解释：2 XOR 1 XOR 3 XOR 4 = 4，需要将 4 变为 1（翻转 2 位）
```

**示例 2：**
```
输入：nums = [2,0,2,0], k = 0
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`
- `0 <= k <= 10^6`

## 解题思路

先计算所有元素的 XOR 值 `xor_all`。目标是使 xor_all == k。

差异位 = `xor_all XOR k`：差异位中每个 1 表示当前 xor_all 与 k 在该位不同，需要翻转。

翻转一位等于一次操作，因此答案 = 差异位的 1 的个数（位计数）。

## Python 代码实现

### 方法一：异或 + 位计数（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        xor_all = 0
        for x in nums:
            xor_all ^= x
        # 需要翻转 xor_all XOR k 中所有为 1 的位
        diff = xor_all ^ k
        return bin(diff).count('1')
```

### 方法二：使用 reduce

```python
from typing import List
from functools import reduce
from operator import xor

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        xor_all = reduce(xor, nums)
        return bin(xor_all ^ k).count('1')
```

## 复杂度分析

- 时间复杂度：O(n)，计算所有元素的 XOR
- 空间复杂度：O(1)

## 关键点总结

1. 所有元素 XOR 的结果只需一次调整：每次操作翻转一位
2. 差异位 = xor_all XOR k，其中 1 的个数就是答案
3. 每次翻转某个元素的一位，等价于翻转 xor_all 的那一位

## 易错点

1. 操作是翻转元素的**一个**位，不是改变整个元素值
2. bin(x).count('1') 统计二进制中 1 的个数（即汉明重量）
3. 可以修改任意元素，所以每次操作都是最优的（独立）
