## 题目描述

给你两个下标从 0 开始的整数数组 `nums1` 和 `nums2`，长度均为 `n`。

如果 `i != j` 且 `|nums1[i] - nums1[j]| + |nums2[i] - nums2[j]|` 的值最小，则下标对 `(i, j)` 称为 **美丽下标对**（其中 `i < j`）。返回字典序最小的美丽下标对。

**示例 1：**
```
输入：nums1 = [1,2,3,2,4], nums2 = [2,3,1,2,3]
输出：[0,3]
解释：(0,3) 对应的曼哈顿距离为 |1-2|+|2-2|=1，是最小值
```

**示例 2：**
```
输入：nums1 = [1,2,4,3,2,3], nums2 = [2,2,1,2,3,2]
输出：[0,1]
```

**数据范围：**
- 2 <= n <= 10^5
- 0 <= nums1[i], nums2[i] <= 10^5

## 解题思路

最近点对问题（曼哈顿距离）：

曼哈顿距离 `|x1-x2| + |y1-y2|` 可以转化为切比雪夫距离：通过坐标变换 `(x, y) -> (x+y, x-y)`，曼哈顿距离变为 `max(|u1-u2|, |v1-v2|)`（切比雪夫距离）。

解法：
1. 坐标变换
2. 对变换后的坐标，使用分治法（类似最近点对问题）求切比雪夫距离最小的点对
3. 若有多对距离相同，返回字典序最小的

也可以使用暴力 O(n^2) 在本题约束下通过（n=10^5 可能需要优化）。

## Python 代码实现

### 方法一：分治求最近点对（推荐）

```python
from typing import List

class Solution:
    def beautifulPair(self, nums1: List[int], nums2: List[int]) -> List[int]:
        n = len(nums1)
        # 构建点集，附带原始下标
        points = [(nums1[i], nums2[i], i) for i in range(n)]

        # 曼哈顿距离
        def dist(i, j):
            return abs(nums1[i] - nums1[j]) + abs(nums2[i] - nums2[j])

        # 分治求最近点对
        def closest_pair(pts):
            # pts 按 x 坐标排序
            if len(pts) <= 3:
                best = (float('inf'), -1, -1)
                for a in range(len(pts)):
                    for b in range(a + 1, len(pts)):
                        ia, ib = pts[a][2], pts[b][2]
                        d = dist(ia, ib)
                        i, j = min(ia, ib), max(ia, ib)
                        if d < best[0] or (d == best[0] and (i, j) < (best[1], best[2])):
                            best = (d, i, j)
                return best

            mid = len(pts) // 2
            mid_x = pts[mid][0]
            left_best = closest_pair(pts[:mid])
            right_best = closest_pair(pts[mid:])

            # 合并
            best = min(left_best, right_best,
                       key=lambda x: (x[0], x[1], x[2]))
            d = best[0]

            # 中间带
            strip = [p for p in pts if abs(p[0] - mid_x) < d]
            strip.sort(key=lambda p: p[1])

            for i in range(len(strip)):
                for j in range(i + 1, len(strip)):
                    if strip[j][1] - strip[i][1] >= d:
                        break
                    ia, ib = strip[i][2], strip[j][2]
                    nd = dist(ia, ib)
                    ni, nj = min(ia, ib), max(ia, ib)
                    if nd < best[0] or (nd == best[0] and (ni, nj) < (best[1], best[2])):
                        best = (nd, ni, nj)

            return best

        points_sorted = sorted(points, key=lambda p: (p[0], p[1]))
        _, i, j = closest_pair(points_sorted)
        return [i, j]
```

### 方法二：暴力（适用于小数据量）

```python
from typing import List

class Solution:
    def beautifulPair(self, nums1: List[int], nums2: List[int]) -> List[int]:
        n = len(nums1)
        min_dist = float('inf')
        ans = [-1, -1]

        for i in range(n):
            for j in range(i + 1, n):
                d = abs(nums1[i] - nums1[j]) + abs(nums2[i] - nums2[j])
                if d < min_dist:
                    min_dist = d
                    ans = [i, j]

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n log^2 n)，空间复杂度 O(n log n)
- 方法二：时间复杂度 O(n^2)，空间复杂度 O(1)

## 关键点总结

1. 最近点对问题用分治法可以 O(n log^2 n) 解决
2. 同等距离时需要返回字典序最小的下标对
3. 注意下标对 (i, j) 需满足 i < j

## 易错点

1. 分治合并时中间带的处理要基于 y 坐标排序
2. 字典序比较：先比 i 再比 j
3. 递归基础情况处理边界
