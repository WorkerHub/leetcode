## 题目描述

有 `n` 个人，每个人的编号为 `0` 到 `n-1`。

给定两个列表：
- `watchedVideos`：`watchedVideos[i]` 是第 `i` 个人观看的视频列表
- `friends`：`friends[i]` 是第 `i` 个人的好友列表

给定整数 `id` 和 `level`，找出 `id` 的第 `level` 级好友（不是第 1 级，也不是第 2 级，而是恰好第 `level` 级）看过的所有视频。

返回这些视频的列表，按观看频率**升序**排列（频率相同时按字母序排列）。

**示例 1：**

```
输入：watchedVideos = [["A","B"],["C"],["B","C"],["D"]], 
     friends = [[1,2],[0,3],[0,3],[1,2]], id = 0, level = 1
输出：["B","C"]
解释：
id = 0 的好友是 1 和 2（第 1 级）
他们看过的视频：C（1次）、B（2次）、C（2次）
整理：B -> 1次，C -> 2次，按频率升序：["B","C"]
```

**示例 2：**

```
输入：watchedVideos = [["A","B"],["C"],["B","C"],["D"]], 
     friends = [[1,2],[0,3],[0,3],[1,2]], id = 0, level = 2
输出：["D"]
解释：id = 0 的第2级好友是 3，他只看了 "D"
```

**提示：**

- `n == watchedVideos.length == friends.length`
- `2 <= n <= 100`
- `1 <= watchedVideos[i].length <= 100`
- `1 <= watchedVideos[i][j].length <= 8`
- `0 <= friends[i].length < n`
- `0 <= friends[i][j] < n`
- `1 <= level < n`
- 如果 `friends[i]` 包含 `j`，那么 `friends[j]` 包含 `i`

## 解题思路

**整体思路：BFS 找第 level 级好友 + 哈希表统计视频频率**

**第一步：BFS 找第 level 级好友**

从 `id` 出发做 BFS，每扩展一层代表好友级别 +1，到达 `level` 层时收集所有节点即为第 `level` 级好友。

**第二步：统计视频频率**

遍历所有第 `level` 级好友，统计他们观看视频的总次数。

**第三步：排序输出**

按频率升序，频率相同按字母序排列。

**BFS 流程图：**

```
id=0, level=2
           0
          / \
level1: 1   2
        |\ /|
level2:  3
```

## Python 代码实现

### 方法一：BFS + 哈希表（推荐）

```python
from typing import List
from collections import deque, Counter

class Solution:
    def watchedVideosByFriends(
        self,
        watchedVideos: List[List[str]],
        friends: List[List[int]],
        id: int,
        level: int
    ) -> List[str]:
        # BFS 找第 level 级好友
        visited = {id}          # 已访问节点，避免重复
        queue = deque([id])     # BFS 队列
        
        for _ in range(level):
            # 每次循环扩展一层
            next_level = deque()
            while queue:
                person = queue.popleft()
                for friend in friends[person]:
                    if friend not in visited:
                        visited.add(friend)
                        next_level.append(friend)
            queue = next_level
        
        # 此时 queue 中存放的是第 level 级好友
        # 统计他们观看视频的频率
        video_count = Counter()
        for person in queue:
            for video in watchedVideos[person]:
                video_count[video] += 1
        
        # 按频率升序，频率相同按字母序排列
        return sorted(video_count.keys(), key=lambda v: (video_count[v], v))
```

### 方法二：BFS（使用集合，代码更清晰）

```python
from typing import List
from collections import deque, Counter

class Solution:
    def watchedVideosByFriends(
        self,
        watchedVideos: List[List[str]],
        friends: List[List[int]],
        id: int,
        level: int
    ) -> List[str]:
        # 初始化：已访问集合，当前层节点集合
        visited = {id}
        current_level = {id}
        
        for _ in range(level):
            next_level = set()
            for person in current_level:
                for friend in friends[person]:
                    if friend not in visited:
                        visited.add(friend)
                        next_level.add(friend)
            current_level = next_level
        
        # 统计第 level 级好友看过的视频频率
        video_count = Counter()
        for person in current_level:
            video_count.update(watchedVideos[person])
        
        # 排序：先按频率，再按字母序
        return sorted(video_count, key=lambda v: (video_count[v], v))
```

## 复杂度分析

- **时间复杂度**：O(n + E + V * log V)
  - BFS：O(n + E)，n 为节点数，E 为边数（好友关系数）
  - 统计视频：O(V)，V 为第 level 级好友看过的视频总数
  - 排序：O(V * log V)
- **空间复杂度**：O(n + V)，visited 集合 O(n)，视频计数哈希表 O(V)

## 关键点总结

1. BFS 天然适合"按层级遍历"的问题，每轮循环扩展一层好友
2. 使用 `visited` 集合避免重复访问（同一个人可能是多个人的好友）
3. `Counter` 是统计频率的利器
4. 排序时用二元组 `(频率, 视频名)` 作为 key，实现多关键字排序

## 易错点

1. **忘记标记 `id` 本人为已访问**：如果不把 `id` 加入 `visited`，可能在 BFS 时绕回自己
2. **BFS 层次混乱**：每次扩展要用新的队列收集下一层，不能在遍历当前层时直接 append 到同一队列
3. **排序方向**：题目要求频率**升序**，别写成降序
