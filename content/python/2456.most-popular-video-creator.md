## 题目描述

给你两个字符串数组 `creators` 和 `ids`，和一个整数数组 `views`，所有数组的长度都是 `n`。平台上第 `i` 个视频：视频创作者为 `creators[i]`，视频 id 为 `ids[i]`，播放量为 `views[i]`。

视频创作者的 **流行度** 是该创作者发布的所有视频的播放量之和。找出流行度 **最高** 的创作者以及该创作者 **播放量最高** 的视频 id。

- 如果多个创作者的流行度相同，返回所有流行度最高的创作者。
- 如果某个创作者的多个视频播放量相同且最高，返回字典序最小的那个 id。

以二维字符串数组的格式返回答案，其中 `answer[i] = [creatori, idi]` 表示流行度最高的创作者及其播放量最高的视频 id。

**提示：**
- `n == creators.length == ids.length == views.length`
- `1 <= n <= 10^5`

## 解题思路

1. 用哈希表统计每个创作者的总播放量和最佳视频
2. 遍历所有视频，更新每个创作者的总播放量
3. 对每个创作者，维护「播放量最高、字典序最小」的视频 id
4. 找出最大总播放量，返回所有满足条件的 (creator, best_video) 对

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def mostPopularCreator(self, creators: List[str], ids: List[str], views: List[int]) -> List[List[str]]:
        # 统计每个创作者的总播放量
        total_views = defaultdict(int)
        # 统计每个创作者的最佳视频（播放量最高，相同时取字典序最小的 id）
        best_video = {}  # {creator: (best_views, best_id)}

        for creator, vid_id, view in zip(creators, ids, views):
            total_views[creator] += view

            if creator not in best_video:
                best_video[creator] = (view, vid_id)
            else:
                cur_view, cur_id = best_video[creator]
                # 更新最佳视频：播放量更高，或相同时取字典序更小的 id
                if view > cur_view or (view == cur_view and vid_id < cur_id):
                    best_video[creator] = (view, vid_id)

        # 找最大总播放量
        max_views = max(total_views.values())

        # 收集所有流行度最高的创作者及其最佳视频
        ans = []
        for creator, tv in total_views.items():
            if tv == max_views:
                ans.append([creator, best_video[creator][1]])

        return ans
```

### 方法二：排序方法

```python
from typing import List
from collections import defaultdict

class Solution:
    def mostPopularCreator(self, creators: List[str], ids: List[str], views: List[int]) -> List[List[str]]:
        total = defaultdict(int)
        best = {}

        for c, v_id, view in zip(creators, ids, views):
            total[c] += view
            # 维护最佳视频
            if c not in best or view > best[c][0] or (view == best[c][0] and v_id < best[c][1]):
                best[c] = (view, v_id)

        max_total = max(total.values())
        return [[c, best[c][1]] for c, t in total.items() if t == max_total]
```

## 关键点总结

1. 两个哈希表：一个统计总播放量，一个维护最佳视频
2. 最佳视频更新条件：播放量更高，或相同时 id 字典序更小
3. 找所有最大流行度的创作者

## 易错点

- 最佳视频中，相同播放量时取字典序更小的 id（`vid_id < cur_id` 而不是 `<=`）
- 返回的是视频 id，不是创作者名字后面跟索引
