## 题目描述

Digitville 中有数字 0 到 n-1，每个数字应该恰好出现一次。但由于错误，数组 `nums`（长度为 n+2）中有两个数字出现了两次，其余出现一次。

返回出现两次的两个数字，顺序不限。

**示例 1：**
```
输入：nums = [0,1,1,0,3]
输出：[0,1]
```

**示例 2：**
```
输入：nums = [7,1,5,4,2,4,7,3,6,0]
输出：[4,7]
```

**提示：**
- `2 <= n <= 100`
- `nums.length == n + 2`
- `0 <= nums[i] < n`
- 恰好两个数字出现两次

## 解题思路

用哈希表统计每个数字出现次数，找出出现两次的数字。

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def getSneakyNumbers(self, nums: List[int]) -> List[int]:
        count = Counter(nums)
        return [x for x, c in count.items() if c == 2]
```

### 方法二：排序查找

```python
from typing import List

class Solution:
    def getSneakyNumbers(self, nums: List[int]) -> List[int]:
        nums.sort()
        result = []
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                result.append(nums[i])
        return result
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 统计频率，找出现 2 次的数字
2. 排序后找相邻相同的数字

## 易错点

1. 题目保证恰好 2 个数重复，不需要其他特殊处理
