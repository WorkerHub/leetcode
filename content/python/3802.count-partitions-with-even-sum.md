## 题目描述

给你一个整数数组 `nums`，你需要将数组划分为两个非空的连续子数组（前缀和后缀）。

返回满足以下条件的划分数目：两个子数组的元素之和都是偶数。

**示例 1：**

```
输入：nums = [2, 4, 6, 8]
输出：3
解释：
- 划分 [2] 和 [4, 6, 8]：和分别为 2（偶数）和 18（偶数），合法。
- 划分 [2, 4] 和 [6, 8]：和分别为 6（偶数）和 14（偶数），合法。
- 划分 [2, 4, 6] 和 [8]：和分别为 12（偶数）和 8（偶数），合法。
共 3 种。
```

**示例 2：**

```
输入：nums = [1, 2, 3]
输出：0
解释：
- 划分 [1] 和 [2, 3]：和分别为 1（奇数）和 5（奇数），不合法。
- 划分 [1, 2] 和 [3]：和分别为 3（奇数）和 3（奇数），不合法。
共 0 种。
```

**提示：**
- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

关键数学观察：
- 两个子数组的和都是偶数，等价于两者之和（即总和）也是偶数。
- 若总和为奇数，则不可能存在两个都是偶数的子数组，直接返回 0。
- 若总和为偶数，任意划分方式都满足：前缀和为偶数 <=> 后缀和 = 总和 - 前缀和也为偶数。

因此只需统计总和为偶数时，前缀和为偶数的划分数目（共 n-1 个划分点）。

## Python 代码实现

### 方法一：前缀和 + 奇偶判断（推荐）

```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        total = sum(nums)
        # 总和为奇数时，不存在合法划分
        if total % 2 == 1:
            return 0

        # 统计前缀和为偶数的划分（不包含最后一个元素，保证后缀非空）
        count = 0
        prefix = 0
        for i in range(len(nums) - 1):
            prefix += nums[i]
            if prefix % 2 == 0:
                count += 1

        return count
```

### 方法二：数学推导简化

```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        total = sum(nums)
        # 总和为奇数，无合法划分
        if total % 2 != 0:
            return 0

        # 奇数个奇数元素会导致总和为奇数，已排除
        # 统计前缀和为偶数的位置数量
        result = 0
        prefix_sum = 0
        for num in nums[:-1]:  # 不包含最后一个，保证后缀非空
            prefix_sum += num
            if prefix_sum % 2 == 0:
                result += 1

        return result
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组两次（一次求总和，一次统计）
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. 两个子数组和都为偶数，充要条件是总和为偶数。
2. 总和为奇数时直接返回 0，无需逐一检查。
3. 只需统计划分点左侧前缀和为偶数的数量。

## 易错点

1. 划分必须保证两个子数组都非空，因此遍历时不含最后一个元素。
2. 不要漏掉总和为奇数的边界判断。
