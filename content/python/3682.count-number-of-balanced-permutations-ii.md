## 题目描述

给你一个数字字符串 `num`，如果一个排列中奇数下标（1-indexed）的数字之和等于偶数下标的数字之和，则称其为 **平衡排列**。

返回 `num` 的不同平衡排列的数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：num = "123"
输出：1
解释：排列"123"：奇位=1+3=4，偶位=2，不平衡；"132"：奇=1+2=3，偶=3，平衡！
实际只有"132"满足，共1种
```

**示例 2：**

```
输入：num = "112"
输出：1
解释：...
```

**提示：**

- `2 <= num.length <= 80`
- `num` 只包含数字 `0-9`

## 解题思路

DP + 组合数：

总和 `S`，若 `S` 为奇数则无解。否则奇数位和 = 偶数位和 = `S/2`。

设 `n` 个数字，奇数位有 `ceil(n/2)` 个，偶数位有 `floor(n/2)` 个。

DP：从 9 到 0，逐位决定有多少个数字放在奇数位，多少个放在偶数位。

考虑重复数字：用组合数 `C(k, j)` 选 j 个放奇数位，`k-j` 个放偶数位，其中 k 是某数字的出现次数。

## Python 代码实现

### 方法一：DP + 组合数（推荐）

```python
from collections import Counter
from math import comb

class Solution:
    def countBalancedPermutations(self, num: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(num)
        total = sum(int(c) for c in num)

        if total % 2 != 0:
            return 0

        target = total // 2
        odd_slots = (n + 1) // 2   # 奇数位槽数
        even_slots = n // 2         # 偶数位槽数

        freq = Counter(num)
        digits = sorted(freq.keys(), reverse=True)

        # dp[(odd_used, odd_sum)] = 方案数
        # 考虑每种数字，选 j 个放奇数位
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dp(idx, odd_used, odd_sum):
            if odd_used > odd_slots or odd_sum > target:
                return 0
            if idx == len(digits):
                even_used = sum(freq[d] for d in digits) - odd_used
                if odd_used == odd_slots and even_used == even_slots and odd_sum == target:
                    return 1
                return 0

            d = digits[idx]
            k = freq[d]
            result = 0
            for j in range(k + 1):
                # j 个放奇数位，k-j 个放偶数位
                odd_after = odd_used + j
                sum_after = odd_sum + d * j
                if odd_after <= odd_slots and sum_after <= target:
                    ways = comb(odd_slots - odd_used, j) * comb(even_slots - (sum(freq[digits[i]] for i in range(idx)) - odd_used), k - j)
                    # 简化：组合数基于剩余槽位
                    result += dp(idx + 1, odd_after, sum_after) * comb(k, j)
                    # 这里组合数需要更精细计算
            return result % MOD

        # 重新实现，更清晰
        # dp[odd_used][odd_sum] 
        dp_table = {(0, 0): 1}
        total_placed = 0

        for d in sorted(freq.keys(), reverse=True):
            k = freq[d]
            new_dp = {}
            for (ou, os), cnt in dp_table.items():
                eu = total_placed - ou  # 已放偶数位的数量
                for j in range(k + 1):
                    nou = ou + j
                    nos = os + d * j
                    neu = eu + (k - j)
                    if nou <= odd_slots and neu <= even_slots and nos <= target:
                        ways = comb(odd_slots - ou, j) * comb(even_slots - eu, k - j)
                        key = (nou, nos)
                        new_dp[key] = (new_dp.get(key, 0) + cnt * ways) % MOD
            dp_table = new_dp
            total_placed += k

        return dp_table.get((odd_slots, target), 0)
```

### 方法二：递推 DP

```python
from collections import Counter
from math import comb

class Solution:
    def countBalancedPermutations(self, num: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(num)
        total = sum(int(c) for c in num)
        if total % 2:
            return 0

        half = total // 2
        odd_cnt = (n + 1) // 2

        freq = Counter(int(c) for c in num)
        dp = {(0, 0): 1}  # (奇数位已用数量, 奇数位当前和)
        placed = 0

        for digit in range(9, -1, -1):
            k = freq.get(digit, 0)
            if k == 0:
                continue
            new_dp = {}
            eu_base = placed  # 到目前已放置元素总数
            for (ou, os), ways in dp.items():
                eu = eu_base - ou
                for j in range(k + 1):
                    nou = ou + j
                    nos = os + digit * j
                    neu = eu + (k - j)
                    if nou <= odd_cnt and neu <= n - odd_cnt and nos <= half:
                        new_ways = ways * comb(odd_cnt - ou, j) * comb(n - odd_cnt - eu, k - j) % MOD
                        new_dp[(nou, nos)] = (new_dp.get((nou, nos), 0) + new_ways) % MOD
            dp = new_dp
            placed += k

        return dp.get((odd_cnt, half), 0)
```

## 复杂度分析

- 时间复杂度：O(n^2 * S)，S 为数字总和
- 空间复杂度：O(n * S)

## 关键点总结

1. 总和为奇数时无解
2. 奇/偶位槽数固定
3. 用 DP + 组合数处理重复数字的分配
4. `C(odd_slots - ou, j) * C(even_slots - eu, k-j)` 计算分配方式数

## 易错点

1. 奇偶位槽数：奇数位 `ceil(n/2)`，偶数位 `floor(n/2)`
2. 组合数需要实时更新可用槽位数
3. 结果只取 `(odd_cnt, half)` 对应的值
