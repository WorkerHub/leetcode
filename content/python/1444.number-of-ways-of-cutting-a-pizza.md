## 题目描述

给你一个 `rows x cols` 大小的矩形披萨，其中每个格子用字符 `'A'`（苹果）或 `'.'`（空格）表示。你需要切 `k-1` 刀将披萨切成 `k` 块，每刀都是水平或垂直的，且每块至少含有一个苹果。

返回切割披萨的方案数，结果对 `10^9 + 7` 取模。

切割时有以下规则：
- 每次切割将当前最上方或最左方的一块分离出去（即总是在"剩余部分"上切）。
- 例如水平切一刀，分出"上方一块"；垂直切一刀，分出"左边一块"。

**示例 1：**
```
输入：pizza = ["A..","AAA","..."], k = 3
输出：3
解释：3 种切割方式（确保每块都有苹果）
```

**示例 2：**
```
输入：pizza = ["A..","AA.","..."], k = 3
输出：1
```

**示例 3：**
```
输入：pizza = ["A..","A..","..."], k = 1
输出：1
```

**提示：**
- `1 <= rows, cols <= 50`
- `rows == pizza.length`
- `cols == pizza[0].length`
- `1 <= k <= 10`
- `pizza[i][j]` 为 `'A'` 或 `'.'`

## 解题思路

**核心工具：二维前缀和**

定义 `suffix[r][c]` 为右下角子矩形（从 `(r,c)` 到 `(rows-1, cols-1)`）中苹果的数量。  
这样可以 O(1) 查询任意右下角子矩形内的苹果数。

**状态设计（记忆化 DFS）：**

`dfs(r, c, remain)` = 从位置 `(r, c)` 开始（即只考虑右下角剩余矩形），还需要切 `remain` 刀（切出 `remain+1` 块），的合法方案数。

**转移：**
1. 水平切：在第 `r` 到 `rows-2` 行的某一行 `nr` 之后切，分出 `[r, nr]` 一块（至少有苹果），递归处理 `dfs(nr+1, c, remain-1)`。
2. 垂直切：在第 `c` 到 `cols-2` 列的某一列 `nc` 之后切，分出 `[c, nc]` 一块（至少有苹果），递归处理 `dfs(r, nc+1, remain-1)`。

**base case：** `remain == 0` 时，若剩余区域有苹果，返回 1，否则返回 0。

## Python 代码实现

### 方法一：记忆化 DFS + 二维后缀和（推荐）

```python
from typing import List
from functools import lru_cache

class Solution:
    def ways(self, pizza: List[str], k: int) -> int:
        MOD = 10 ** 9 + 7
        rows, cols = len(pizza), len(pizza[0])

        # 构建二维后缀和：suffix[r][c] = (r,c) 到 (rows-1, cols-1) 的苹果数
        suffix = [[0] * (cols + 1) for _ in range(rows + 1)]
        for r in range(rows - 1, -1, -1):
            for c in range(cols - 1, -1, -1):
                suffix[r][c] = (
                    (1 if pizza[r][c] == 'A' else 0)
                    + suffix[r + 1][c]
                    + suffix[r][c + 1]
                    - suffix[r + 1][c + 1]
                )

        def apple_count(r1, c1, r2, c2) -> int:
            """计算矩形 (r1,c1) 到 (r2,c2)（含）的苹果数"""
            return (
                suffix[r1][c1]
                - suffix[r2 + 1][c1]
                - suffix[r1][c2 + 1]
                + suffix[r2 + 1][c2 + 1]
            )

        @lru_cache(maxsize=None)
        def dfs(r: int, c: int, remain: int) -> int:
            """
            从 (r,c) 开始的右下角剩余部分，还需切 remain 刀，的方案数
            """
            # base case：不需要再切，检查剩余部分是否有苹果
            if remain == 0:
                return 1 if apple_count(r, c, rows - 1, cols - 1) > 0 else 0

            result = 0

            # 水平切：切割行 nr（分出 [r, nr] 这几行）
            for nr in range(r, rows - 1):
                # 分出的上方块 [r, nr] 必须有苹果
                if apple_count(r, c, nr, cols - 1) > 0:
                    result = (result + dfs(nr + 1, c, remain - 1)) % MOD

            # 垂直切：切割列 nc（分出 [c, nc] 这几列）
            for nc in range(c, cols - 1):
                # 分出的左方块 [c, nc] 必须有苹果
                if apple_count(r, c, rows - 1, nc) > 0:
                    result = (result + dfs(r, nc + 1, remain - 1)) % MOD

            return result

        return dfs(0, 0, k - 1)
```

### 方法二：迭代 DP（三维 DP 表）

```python
from typing import List

class Solution:
    def ways(self, pizza: List[str], k: int) -> int:
        MOD = 10 ** 9 + 7
        rows, cols = len(pizza), len(pizza[0])

        # 构建二维后缀和
        suffix = [[0] * (cols + 1) for _ in range(rows + 1)]
        for r in range(rows - 1, -1, -1):
            for c in range(cols - 1, -1, -1):
                suffix[r][c] = (
                    (1 if pizza[r][c] == 'A' else 0)
                    + suffix[r + 1][c]
                    + suffix[r][c + 1]
                    - suffix[r + 1][c + 1]
                )

        def has_apple(r1, c1, r2, c2) -> bool:
            return (
                suffix[r1][c1]
                - suffix[r2 + 1][c1]
                - suffix[r1][c2 + 1]
                + suffix[r2 + 1][c2 + 1]
            ) > 0

        # dp[cut][r][c] = 从 (r,c) 开始，切了 cut 刀后的方案数
        INF = 0
        dp = [[[0] * cols for _ in range(rows)] for _ in range(k)]

        # 初始化：cut=0（不切，整块）
        for r in range(rows):
            for c in range(cols):
                dp[0][r][c] = 1 if has_apple(r, c, rows - 1, cols - 1) else 0

        # 状态转移
        for cut in range(1, k):
            for r in range(rows):
                for c in range(cols):
                    val = 0
                    # 水平切
                    for nr in range(r, rows - 1):
                        if has_apple(r, c, nr, cols - 1):
                            val = (val + dp[cut - 1][nr + 1][c]) % MOD
                    # 垂直切
                    for nc in range(c, cols - 1):
                        if has_apple(r, c, rows - 1, nc):
                            val = (val + dp[cut - 1][r][nc + 1]) % MOD
                    dp[cut][r][c] = val

        return dp[k - 1][0][0]
```

## 复杂度分析

- **时间复杂度：** O(k * rows * cols * (rows + cols))
  - 状态数 O(k * rows * cols)，每个状态转移 O(rows + cols)。
  - 总计 O(k * rows * cols * (rows + cols)) ≈ O(10 * 50 * 50 * 100) = 2,500,000，可接受。
- **空间复杂度：** O(k * rows * cols)，存储 DP 表或记忆化缓存。

## 关键点总结

1. 二维后缀和：预处理 O(n²)，之后 O(1) 查询任意右下角子矩形的苹果数，是本题的核心工具。
2. 状态 `(r, c, remain)` 描述"从 (r,c) 开始的右下角部分，还剩 remain 刀"，天然地覆盖所有子问题。
3. 每次切割只分离"左/上"部分，剩余部分从 `(nr+1, c)` 或 `(r, nc+1)` 开始，状态不重叠。
4. `lru_cache` 自动完成记忆化，Python 中非常方便。

## 易错点

- 二维后缀和的构建顺序：必须从右下角向左上角计算（反向遍历）。
- 后缀和查询公式：注意加减法正确，避免多算或少算。
- 剩余 `remain` 为 0 时只需检查剩余部分有苹果（不是 1 块）。
- 切割范围：水平切从 `r` 到 `rows-2`（不能到最后一行，否则剩余部分为空）。
