## 题目描述

你被请来给一个高尔夫球场设计一个方案，要求按照树的高度从低到高砍掉所有的树。

给定一个 m x n 的矩阵 forest，其中：
- 0 表示障碍物，无法通过
- 1 表示可以通过的地面
- 大于1的数表示树，数值代表树的高度

你需要从左上角 (0, 0) 开始，按照树的高度从低到高依次砍树。每次只能上下左右移动一步。

返回砍掉所有树需要的最少步数。如果无法砍掉所有树，返回 -1。

**示例 1：**
```
输入：forest = [[1,2,3],[0,0,4],[7,6,5]]
输出：6
解释：按照树的高度从低到高砍树的顺序：2, 3, 4, 5, 6, 7
路径：(0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2) -> (2,1) -> (2,0)
```

**示例 2：**
```
输入：forest = [[1,2,3],[0,0,0],[7,6,5]]
输出：-1
解释：无法到达高度为4的树
```

**示例 3：**
```
输入：forest = [[2,3,4],[3,2,3],[4,3,5]]
输出：8
```

**提示：**
- m == forest.length
- n == forest[i].length
- 1 <= m, n <= 50
- 0 <= forest[i][j] <= 10^9

## 解题思路

这是一道综合性的困难题，结合了排序、BFS和路径规划。

**核心思想：**
1. 收集所有树的位置和高度
2. 按高度排序
3. 依次从当前位置走到下一棵树
4. 累加路径长度

**关键步骤：**
- 使用BFS计算两点之间的最短路径
- 如果某棵树不可达，返回-1

**算法流程：**
1. 遍历矩阵，收集所有树的坐标和高度
2. 按高度排序树的列表
3. 从(0,0)开始，依次BFS到每棵树
4. 累加步数，如果某次BFS失败返回-1

## Python 代码实现

### 方法一：BFS + 排序（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def cutOffTree(self, forest: List[List[int]]) -> int:
        m, n = len(forest), len(forest[0])
        
        # 收集所有树的位置和高度
        trees = []
        for i in range(m):
            for j in range(n):
                if forest[i][j] > 1:
                    trees.append((forest[i][j], i, j))
        
        # 按高度排序
        trees.sort()
        
        def bfs(start_r, start_c, end_r, end_c):
            """BFS计算从(start_r, start_c)到(end_r, end_c)的最短路径"""
            if start_r == end_r and start_c == end_c:
                return 0
            
            queue = deque([(start_r, start_c, 0)])
            visited = {(start_r, start_c)}
            
            while queue:
                r, c, dist = queue.popleft()
                
                for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
                    nr, nc = r + dr, c + dc
                    
                    if 0 <= nr < m and 0 <= nc < n and \
                       (nr, nc) not in visited and forest[nr][nc] != 0:
                        if nr == end_r and nc == end_c:
                            return dist + 1
                        
                        queue.append((nr, nc, dist + 1))
                        visited.add((nr, nc))
            
            return -1  # 无法到达
        
        # 依次砍树
        total_steps = 0
        curr_r, curr_c = 0, 0
        
        for height, tree_r, tree_c in trees:
            steps = bfs(curr_r, curr_c, tree_r, tree_c)
            if steps == -1:
                return -1
            
            total_steps += steps
            curr_r, curr_c = tree_r, tree_c
        
        return total_steps
```

### 方法二：A* 算法优化

```python
import heapq

class Solution:
    def cutOffTree(self, forest: List[List[int]]) -> int:
        m, n = len(forest), len(forest[0])
        
        # 收集树并排序
        trees = []
        for i in range(m):
            for j in range(n):
                if forest[i][j] > 1:
                    trees.append((forest[i][j], i, j))
        trees.sort()
        
        def heuristic(r1, c1, r2, c2):
            """曼哈顿距离作为启发函数"""
            return abs(r1 - r2) + abs(c1 - c2)
        
        def a_star(start_r, start_c, end_r, end_c):
            """A*算法寻找最短路径"""
            if start_r == end_r and start_c == end_c:
                return 0
            
            # 优先队列：(f值, g值, 行, 列)
            pq = [(heuristic(start_r, start_c, end_r, end_c), 0, start_r, start_c)]
            visited = {(start_r, start_c): 0}
            
            while pq:
                f, g, r, c = heapq.heappop(pq)
                
                if r == end_r and c == end_c:
                    return g
                
                # 如果已经找到更好的路径，跳过
                if (r, c) in visited and visited[(r, c)] < g:
                    continue
                
                for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
                    nr, nc = r + dr, c + dc
                    
                    if 0 <= nr < m and 0 <= nc < n and forest[nr][nc] != 0:
                        new_g = g + 1
                        
                        if (nr, nc) not in visited or visited[(nr, nc)] > new_g:
                            visited[(nr, nc)] = new_g
                            new_f = new_g + heuristic(nr, nc, end_r, end_c)
                            heapq.heappush(pq, (new_f, new_g, nr, nc))
            
            return -1
        
        # 依次砍树
        total_steps = 0
        curr_r, curr_c = 0, 0
        
        for height, tree_r, tree_c in trees:
            steps = a_star(curr_r, curr_c, tree_r, tree_c)
            if steps == -1:
                return -1
            total_steps += steps
            curr_r, curr_c = tree_r, tree_c
        
        return total_steps
```

### 方法三：Hadlock算法（更优）

```python
class Solution:
    def cutOffTree(self, forest: List[List[int]]) -> int:
        m, n = len(forest), len(forest[0])
        
        trees = []
        for i in range(m):
            for j in range(n):
                if forest[i][j] > 1:
                    trees.append((forest[i][j], i, j))
        trees.sort()
        
        def hadlock(sr, sc, er, ec):
            """Hadlock算法：优先走向目标的方向"""
            if sr == er and sc == ec:
                return 0
            
            # 分离接近和远离目标的移动
            pq = [(0, 0, sr, sc)]  # (detours, dist, r, c)
            visited = {(sr, sc)}
            
            while pq:
                detours, dist, r, c = heapq.heappop(pq)
                
                for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
                    nr, nc = r + dr, c + dc
                    
                    if 0 <= nr < m and 0 <= nc < n and \
                       forest[nr][nc] != 0 and (nr, nc) not in visited:
                        if nr == er and nc == ec:
                            return dist + 1
                        
                        visited.add((nr, nc))
                        
                        # 判断是否接近目标
                        is_closer = (abs(nr - er) + abs(nc - ec)) < \
                                   (abs(r - er) + abs(c - ec))
                        
                        new_detours = detours if is_closer else detours + 1
                        heapq.heappush(pq, (new_detours, dist + 1, nr, nc))
            
            return -1
        
        total = 0
        r, c = 0, 0
        
        for _, tr, tc in trees:
            d = hadlock(r, c, tr, tc)
            if d < 0:
                return -1
            total += d
            r, c = tr, tc
        
        return total
```

## 复杂度分析

**方法一：BFS**
- 时间复杂度：O(k × m × n)，k为树的数量，每次BFS最坏O(m×n)
- 空间复杂度：O(m × n)

**方法二：A***
- 时间复杂度：O(k × m × n × log(m×n))，优先队列操作
- 空间复杂度：O(m × n)

## 关键点总结

1. **问题分解**：拆分为排序 + 多次最短路径
2. **BFS应用**：计算网格中两点的最短路径
3. **排序策略**：按树的高度排序
4. **可达性检查**：任何一棵树不可达立即返回-1
5. **路径累加**：累加所有BFS的路径长度

## 易错点

1. **起点判断**：起点(0,0)也可能是障碍物
2. **重复访问**：BFS中要使用visited防止重复
3. **排序遗漏**：必须按高度排序，不能按位置
4. **边界检查**：注意矩阵边界
5. **不可达情况**：及时返回-1
