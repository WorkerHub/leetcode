## 题目描述

给定由一些正整数组成的数组 `nums`，返回由其中三个长度组成的、面积不为零的三角形的最大周长。如果不能形成任何面积不为零的三角形，返回 `0`。

**示例 1：**
```
输入：nums = [2,1,2]
输出：5
解释：你可以用三个边长组成一个三角形：1, 2, 2
```

**示例 2：**
```
输入：nums = [1,2,1,10]
输出：0
解释：
你不能用边长 1, 1, 2 来组成三角形。
你不能用边长 1, 1, 10 来组成三角形。
你不能用边长 1, 2, 10 来组成三角形。
因为我们不能用任何三条边长来构成一个面积不为零的三角形，所以返回 0。
```

**提示：**
- `3 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^6`

## 解题思路

这是一道简单的贪心题，核心是**三角形的构成条件**。

### 三角形的成立条件

三条边 `a, b, c` 能构成三角形，当且仅当：
```
a + b > c
a + c > b
b + c > a
```

如果 `a <= b <= c`，那么只需要判断 `a + b > c` 即可（其他两个条件自动满足）。

### 贪心策略

为了得到最大周长：
1. **排序**：将数组从小到大排序
2. **从大到小枚举**：从最大的三个数开始，依次向前尝试
3. **一旦找到符合条件的三角形**：立即返回（因为这是最大周长）

**为什么这样是对的？**
- 排序后，越靠后的数越大，周长越大
- 如果 `nums[i] + nums[i+1] > nums[i+2]` 成立，这三条边能构成三角形
- 这是我们能找到的最大周长（因为从后往前第一次满足条件）

## Python 代码实现

### 方法一：排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        # 从小到大排序
        nums.sort()
        
        # 从最大的三个数开始，从后向前遍历
        for i in range(len(nums) - 3, -1, -1):
            # 检查 nums[i], nums[i+1], nums[i+2] 能否构成三角形
            if nums[i] + nums[i + 1] > nums[i + 2]:
                return nums[i] + nums[i + 1] + nums[i + 2]
        
        # 没有找到符合条件的三角形
        return 0
```

### 方法二：排序 + 逆序遍历（更简洁）

```python
from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort(reverse=True)  # 从大到小排序
        
        # 连续的三个数
        for i in range(len(nums) - 2):
            a, b, c = nums[i], nums[i + 1], nums[i + 2]
            # 最大的是 a，只需判断 b + c > a
            if b + c > a:
                return a + b + c
        
        return 0
```

### 方法三：使用 Python 特性（最简洁）

```python
from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort()
        
        # 使用切片反向遍历相邻的三个数
        for i in range(len(nums) - 1, 1, -1):
            if nums[i - 2] + nums[i - 1] > nums[i]:
                return sum(nums[i - 2:i + 1])
        
        return 0
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序的时间复杂度
- **空间复杂度**：O(log n) 或 O(n)，取决于排序算法的实现

## 图解示例

以 `nums = [3, 6, 2, 3]` 为例：

```
原数组：[3, 6, 2, 3]
排序后：[2, 3, 3, 6]

从后向前检查：
1. [3, 3, 6]：3 + 3 = 6 > 6？ ❌（等于不行）
2. [2, 3, 3]：2 + 3 = 5 > 3？ ✅
   返回 2 + 3 + 3 = 8
```

## 关键点总结

1. **三角形成立条件**：两边之和大于第三边（排序后只需判断最小两边）
2. **贪心思想**：排序后从大到小找，第一个满足的就是最大周长
3. **边界情况**：数组长度小于 3 或没有符合条件的三角形时返回 0
4. **优化技巧**：不需要检查所有组合，只需检查相邻的三个数

## 易错点

1. **三角形条件判断**：
   - 错误：`a + b >= c`（等于不能构成三角形）
   - 正确：`a + b > c`

2. **遍历方向**：
   - 必须从大到小检查，才能保证找到的是最大周长

3. **排序方式**：
   - 可以升序排序后从后往前遍历
   - 也可以降序排序后从前往后遍历
   - 两种方式等价
