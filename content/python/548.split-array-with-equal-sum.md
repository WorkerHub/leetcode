## 题目描述

给定一个有 n 个整数的数组 nums，你需要找到三个索引 i, j, k，满足以下条件：

- 0 < i < j < k < n-1
- 子数组 [0, i-1], [i+1, j-1], [j+1, k-1], [k+1, n-1] 的和相等

如果存在这样的 i, j, k，返回 true，否则返回 false。

**示例 1：**
```
输入：nums = [1,2,1,2,1,2,1]
输出：true
解释：
i = 1, j = 3, k = 5
[1] 和为 1
[1, 2] 和为 3？错误
正确的是：
i = 1, j = 3, k = 5
[1] 和为 1
[1] 和为 1
[1] 和为 1
[1] 和为 1
```

**示例 2：**
```
输入：nums = [1,2,1,2,1,2,1,2,1]
输出：true
```

**示例 3：**
```
输入：nums = [1,1,1,1,1]
输出：false
```

**提示：**
- 3 <= nums.length <= 1000
- -10^6 <= nums[i] <= 10^6

## 解题思路

这道题需要找到三个分割点，将数组分成四个和相等的部分。

**核心思想：**
1. 使用前缀和快速计算任意区间的和
2. 固定中间分割点 j，然后在左右两侧寻找合适的 i 和 k
3. 使用哈希集合存储可能的和，加速查找

**算法流程：**
1. 计算前缀和数组
2. 枚举中间分割点 j（范围：3 到 n-4）
3. 在左侧 [1, j-2] 找所有可能的等和分割点 i
4. 在右侧 [j+2, n-2] 找所有可能的等和分割点 k
5. 检查是否有相同的和

## Python 代码实现

### 方法一：前缀和 + 哈希集合（推荐）

```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int]) -> bool:
        n = len(nums)
        if n < 7:  # 至少需要7个元素才能分成4段
            return False
        
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]
        
        # 枚举中间分割点 j
        for j in range(3, n - 3):
            # 存储左侧可能的等和
            left_sums = set()
            
            # 在左侧找分割点 i，使得 sum[0:i] == sum[i+1:j]
            for i in range(1, j - 1):
                sum1 = prefix[i]  # [0, i-1] 的和
                sum2 = prefix[j] - prefix[i + 1]  # [i+1, j-1] 的和
                
                if sum1 == sum2:
                    left_sums.add(sum1)
            
            # 在右侧找分割点 k，使得 sum[j+1:k] == sum[k+1:n]
            for k in range(j + 2, n - 1):
                sum3 = prefix[k] - prefix[j + 1]  # [j+1, k-1] 的和
                sum4 = prefix[n] - prefix[k + 1]  # [k+1, n-1] 的和
                
                # 如果右侧两段相等，且在左侧找到了相同的和
                if sum3 == sum4 and sum3 in left_sums:
                    return True
        
        return False
```

### 方法二：优化版本

```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int]) -> bool:
        n = len(nums)
        if n < 7:
            return False
        
        # 前缀和
        sums = [0] * (n + 1)
        for i in range(n):
            sums[i + 1] = sums[i] + nums[i]
        
        # 枚举 j
        for j in range(3, n - 3):
            # 左侧可能的和
            left_set = set()
            
            # 枚举 i
            i = 1
            while i <= j - 2:
                # sum(0, i-1)
                left = sums[i]
                # sum(i+1, j-1)
                middle_left = sums[j] - sums[i + 1]
                
                if left == middle_left:
                    left_set.add(left)
                i += 1
            
            # 枚举 k
            k = j + 2
            while k <= n - 2:
                # sum(j+1, k-1)
                middle_right = sums[k] - sums[j + 1]
                # sum(k+1, n-1)
                right = sums[n] - sums[k + 1]
                
                if middle_right == right and middle_right in left_set:
                    return True
                k += 1
        
        return False
```

### 方法三：简洁实现

```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int]) -> bool:
        n = len(nums)
        if n < 7:
            return False
        
        # 计算前缀和
        s = [0]
        for num in nums:
            s.append(s[-1] + num)
        
        # 固定 j
        for j in range(3, n - 3):
            # 左侧等和集合
            left = {s[i] for i in range(1, j - 1) 
                    if s[i] == s[j] - s[i + 1]}
            
            # 检查右侧
            for k in range(j + 2, n - 1):
                if s[k] - s[j + 1] == s[n] - s[k + 1]:
                    if s[k] - s[j + 1] in left:
                        return True
        
        return False
```

## 复杂度分析

- 时间复杂度：O(n^2)
  - 枚举 j：O(n)
  - 对每个 j，枚举 i 和 k：O(n)
- 空间复杂度：O(n)
  - 前缀和数组：O(n)
  - 哈希集合：O(n)

## 关键点总结

1. 使用前缀和快速计算区间和
2. 固定中间分割点 j，分别处理左右两侧
3. 使用哈希集合存储左侧的等和，加速右侧查找
4. 注意边界条件：至少需要7个元素
5. 索引范围要保证每段至少有一个元素

## 易错点

1. 忘记检查数组长度至少为7
2. 索引范围错误，导致某些段为空
3. 前缀和的索引计算错误
4. 没有正确计算各段的和
