## 题目描述

给你一个整数数组 `nums`，按以下规则计算分数：

1. 选择数组中最小的未标记元素（若有相同最小值，选下标最小的）。
2. 将其值加到分数上，并标记它和它左右相邻的元素。
3. 重复步骤 1-2，直到所有元素都被标记。

返回最终的分数。

**示例 1：**

```
输入：nums = [2,1,3,4,5,2]
输出：7
解释：
- 选 nums[1]=1（最小），分数=1，标记下标 0,1,2
- 选 nums[5]=2（剩余最小），分数=1+2=3，标记下标 4,5
- 选 nums[3]=4，分数=3+4=7，标记下标 3
```

**示例 2：**

```
输入：nums = [2,3,5,1,3,2]
输出：5
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`

## 解题思路

**最小堆模拟**：

将 `(值, 下标)` 放入最小堆，每次弹出最小未标记元素，加分并标记相邻。

## Python 代码实现

### 方法一：最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def findScore(self, nums: List[int]) -> int:
        n = len(nums)
        # 最小堆：(值, 下标)
        heap = [(v, i) for i, v in enumerate(nums)]
        heapq.heapify(heap)

        marked = [False] * n
        score = 0

        while heap:
            val, i = heapq.heappop(heap)
            if marked[i]:
                continue
            # 将该元素加入分数
            score += val
            # 标记当前及左右相邻元素
            marked[i] = True
            if i > 0:
                marked[i - 1] = True
            if i < n - 1:
                marked[i + 1] = True

        return score
```

### 方法二：排序模拟

```python
from typing import List

class Solution:
    def findScore(self, nums: List[int]) -> int:
        n = len(nums)
        # 按 (值, 下标) 排序
        indexed = sorted(enumerate(nums), key=lambda x: (x[1], x[0]))

        marked = [False] * n
        score = 0

        for i, val in indexed:
            if marked[i]:
                continue
            score += val
            marked[i] = True
            if i > 0:
                marked[i - 1] = True
            if i < n - 1:
                marked[i + 1] = True

        return score
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作或排序
- 空间复杂度：O(n)

## 关键点总结

1. 每次选最小未标记元素，用最小堆或排序模拟
2. 标记当前元素及左右相邻，后续弹出时跳过已标记
3. 相同值选下标最小：堆中 `(值, 下标)` 自然保证此顺序

## 易错点

1. 堆中弹出时需检查是否已被标记（之前可能被相邻元素的标记操作覆盖）
2. 边界处理：`i=0` 没有左邻，`i=n-1` 没有右邻
3. 标记操作只影响相邻元素，不是整个区间
