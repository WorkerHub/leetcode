## 题目描述

给你一个整数数组 nums 和一个整数 target。

向数组中的每个整数前添加 '+' 或 '-'，然后串联起所有整数，可以构造一个表达式：
- 例如，nums = [2, 1]，可以在 2 之前添加 '+'，在 1 之前添加 '-'，然后串联起来得到表达式 "+2-1"。

返回可以通过上述方法构造的、运算结果等于 target 的不同表达式的数目。

**示例 1：**
```
输入：nums = [1,1,1,1,1], target = 3
输出：5
解释：一共有 5 种方法让最终目标和为 3。
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

**示例 2：**
```
输入：nums = [1], target = 1
输出：1
```

**提示：**
- 1 <= nums.length <= 20
- 0 <= nums[i] <= 1000
- 0 <= sum(nums[i]) <= 1000
- -1000 <= target <= 1000

## 解题思路

这是一道经典的背包问题，可以用回溯或动态规划解决。

### 数学转换

设正数之和为 P，负数之和的绝对值为 N，则：
- P - N = target
- P + N = sum(nums)

两式相加：2P = target + sum(nums)
因此：P = (target + sum(nums)) / 2

**问题转换**：从数组中选取若干数，使其和为 P，有多少种选法？这是一个 0-1 背包问题。

### 核心思想

1. **回溯解法**：
   - 枚举每个数的符号（+ 或 -）
   - 递归计算所有可能的结果
   - 统计等于 target 的方案数

2. **动态规划**：
   - 转换为背包问题
   - dp[i] 表示和为 i 的方案数
   - 遍历每个数，更新 dp 数组

## Python 代码实现

### 方法一：动态规划（0-1背包）推荐

```python
from typing import List

class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        """
        动态规划，转换为背包问题
        
        时间复杂度：O(n * sum)
        空间复杂度：O(sum)
        """
        total = sum(nums)
        
        # 边界情况
        if abs(target) > total or (target + total) % 2 != 0:
            return 0
        
        # 目标和
        P = (target + total) // 2
        
        # dp[i] 表示和为 i 的方案数
        dp = [0] * (P + 1)
        dp[0] = 1  # 和为 0 的方案数为 1
        
        # 遍历每个数
        for num in nums:
            # 从后向前更新（避免重复使用）
            for j in range(P, num - 1, -1):
                dp[j] += dp[j - num]
        
        return dp[P]
```

### 方法二：回溯（DFS + 记忆化）

```python
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        """
        回溯 + 记忆化
        
        时间复杂度：O(n * sum)
        空间复杂度：O(n * sum)
        """
        memo = {}
        
        def dfs(index, current_sum):
            # 到达末尾
            if index == len(nums):
                return 1 if current_sum == target else 0
            
            # 记忆化
            if (index, current_sum) in memo:
                return memo[(index, current_sum)]
            
            # 加号
            count = dfs(index + 1, current_sum + nums[index])
            # 减号
            count += dfs(index + 1, current_sum - nums[index])
            
            memo[(index, current_sum)] = count
            return count
        
        return dfs(0, 0)
```

### 方法三：二维 DP

```python
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        """
        二维 DP
        
        时间复杂度：O(n * sum)
        空间复杂度：O(n * sum)
        """
        n = len(nums)
        total = sum(nums)
        
        if abs(target) > total:
            return 0
        
        # dp[i][j] 表示前 i 个数和为 j 的方案数
        # j 的范围是 [-total, total]，偏移 total 存储
        dp = [[0] * (2 * total + 1) for _ in range(n + 1)]
        dp[0][total] = 1  # 和为 0（偏移后索引为 total）
        
        for i in range(1, n + 1):
            for j in range(-total, total + 1):
                # 加上当前数
                if j - nums[i - 1] + total >= 0:
                    dp[i][j + total] += dp[i - 1][j - nums[i - 1] + total]
                # 减去当前数
                if j + nums[i - 1] + total < 2 * total + 1:
                    dp[i][j + total] += dp[i - 1][j + nums[i - 1] + total]
        
        return dp[n][target + total]
```

### 方法四：纯回溯（无记忆化，慢）

```python
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        """
        纯回溯，适合理解但会超时
        
        时间复杂度：O(2^n)
        空间复杂度：O(n)
        """
        def backtrack(index, current_sum):
            if index == len(nums):
                return 1 if current_sum == target else 0
            
            # 尝试加号和减号
            return (backtrack(index + 1, current_sum + nums[index]) +
                    backtrack(index + 1, current_sum - nums[index]))
        
        return backtrack(0, 0)
```

## 复杂度分析

**方法一：DP**
- **时间复杂度**：O(n × sum)
  - n 个数，每个数更新 sum 个状态
  
- **空间复杂度**：O(sum)
  - 一维 DP 数组

**方法二：回溯 + 记忆化**
- **时间复杂度**：O(n × sum)
  - 状态数：n × sum
  
- **空间复杂度**：O(n × sum)
  - 记忆化字典

**方法四：纯回溯**
- **时间复杂度**：O(2^n)
- **空间复杂度**：O(n)

## 关键点总结

1. **问题转换**：从符号问题转换为背包问题
2. **数学推导**：P = (target + sum) / 2
3. **边界检查**：(target + sum) 必须是偶数且 <= 2 × sum
4. **0-1背包**：每个数只能用一次
5. **倒序更新**：避免重复使用同一个数

## 易错点

1. **边界条件**
   - (target + sum) 必须是偶数
   - abs(target) <= sum
   - 需要提前判断

2. **DP 更新顺序**
   - 必须从后向前更新
   - 避免使用更新后的值

3. **初始化**
   - dp[0] = 1，表示和为 0 有 1 种方案
   - 不要忘记初始化

4. **数学转换**
   - 容易忘记除以 2
   - 容易忘记检查能否整除

5. **记忆化的 key**
   - 使用 (index, current_sum) 作为 key
   - 确保唯一性

   - 更新顺序（倒序）

3. **回溯 vs DP**：
   - 回溯：自顶向下，易理解

   - 使用字典缓存结果
