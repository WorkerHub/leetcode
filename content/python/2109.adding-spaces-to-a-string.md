## 题目描述

给你一个下标从 **0** 开始的字符串 `s`，以及一个下标从 **0** 开始的整数数组 `spaces`，数组中的整数**严格递增**。

在下标 `spaces[i]` 处的字符**之前**插入一个空格。

返回插入所有空格之后的字符串。

**示例 1：**
```
输入：s = "LeetcodeHelpsMeLearn", spaces = [8,13,15]
输出："Leetcode Helps Me Learn"
解释：
- 下标 8 前插入空格："Leetcode HelpsMeLearn"
- 下标 13 前插入空格："Leetcode Helps MeLearn"
- 下标 15 前插入空格："Leetcode Helps Me Learn"
```

**提示：**
- `1 <= s.length <= 3 * 10^5`
- `1 <= spaces.length <= 3 * 10^5`
- `spaces` 中的值严格递增，且均在 `[0, s.length-1]` 内

## 解题思路

**模拟 + 双指针**

遍历字符串，维护一个指针 `j` 指向当前要处理的 `spaces` 数组位置。当当前字符下标等于 `spaces[j]` 时，先加入空格，再加入字符。

**注意：** 不能直接字符串拼接（O(n^2)），应使用列表收集再 `join`（O(n)）。

## 代码实现

### 方法一：列表拼接（推荐）

```python
from typing import List

class Solution:
    def addSpaces(self, s: str, spaces: List[int]) -> str:
        result = []
        j = 0  # spaces 数组的指针
        for i, ch in enumerate(s):
            # 若当前位置需要插入空格
            if j < len(spaces) and i == spaces[j]:
                result.append(' ')
                j += 1
            result.append(ch)
        return ''.join(result)
```

### 方法二：切片拼接

```python
from typing import List

class Solution:
    def addSpaces(self, s: str, spaces: List[int]) -> str:
        # 按 spaces 分割字符串，再用空格连接
        parts = []
        prev = 0
        for pos in spaces:
            parts.append(s[prev:pos])
            prev = pos
        parts.append(s[prev:])
        return ' '.join(parts)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 列表拼接 | O(n) | O(n) |
| 切片拼接 | O(n) | O(n) |

## 关键点总结

1. 使用列表收集字符再 `join`，避免字符串反复拼接造成 O(n^2)。
2. 方法二切片更简洁：按插入位置分段，再用 `' '.join()` 合并。
3. `spaces` 严格递增，可以顺序遍历不需要二分。

## 易错点

- 直接用 `result += ch` 或 `result = result + ch` 在 Python 中是 O(n^2)，应改用列表。
- 切片法中 `prev` 的初始值为 0，最后需要将 `s[prev:]` 也加入 parts。
