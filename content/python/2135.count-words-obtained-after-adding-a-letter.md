## 题目描述

给你两个下标从 **0** 开始的字符串数组 `startWords` 和 `targetWords`。每个字符串只包含**小写英文字母**。

对于 `targetWords` 中的每个字符串，判断它是否可以由 `startWords` 中某个字符串**添加一个字母并重新排列**得到。即 `startWords[i]` 添加一个字母（不重复出现），打乱顺序后能得到 `targetWords[j]`。

返回 `targetWords` 中可以由 `startWords` 中某个字符串生成的字符串数目。

**示例：**
```
输入：startWords = ["ant","act","tack"], targetWords = ["tack","act","acti"]
输出：2
解释：
- "tack" 可由 "act" 加 'k' 得到
- "acti" 可由 "act" 加 'i' 得到
- "act" 长度与 "ant" 相同，但 "ant" 不是 "act" 的子集（差 'c'）
```

**提示：**
- `1 <= startWords.length, targetWords.length <= 5 * 10^4`

## 解题思路

**位运算 + 哈希集合**

用位掩码表示字符串的字符集合（26 位，每位表示某个字母是否存在）。

对于每个 `targetWords[j]`，尝试移除其中每个字符，得到一个新的位掩码，若该掩码在 `startWords` 的掩码集合中，则计数加一。

## 代码实现

### 方法一：位运算 + 集合（推荐）

```python
from typing import List

class Solution:
    def wordCount(self, startWords: List[str], targetWords: List[str]) -> int:
        # 将 startWords 的每个字符集合转为位掩码，存入集合
        start_masks = set()
        for word in startWords:
            mask = 0
            for ch in word:
                mask |= 1 << (ord(ch) - ord('a'))
            start_masks.add(mask)

        ans = 0
        for word in targetWords:
            # 计算 target 的位掩码
            mask = 0
            for ch in word:
                mask |= 1 << (ord(ch) - ord('a'))
            # 尝试移除每一个字符
            for ch in word:
                bit = 1 << (ord(ch) - ord('a'))
                if (mask ^ bit) in start_masks:
                    ans += 1
                    break

        return ans
```

### 方法二：排序字母 + 哈希集合

```python
from typing import List

class Solution:
    def wordCount(self, startWords: List[str], targetWords: List[str]) -> int:
        # 将字符串排序作为规范形式存入集合
        start_set = set()
        for word in startWords:
            start_set.add(tuple(sorted(word)))

        ans = 0
        for word in targetWords:
            sorted_word = sorted(word)
            # 尝试移除每一个字符
            for i in range(len(sorted_word)):
                # 移除第 i 个字符
                candidate = tuple(sorted_word[:i] + sorted_word[i+1:])
                if candidate in start_set:
                    ans += 1
                    break

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 位运算 | O((S + T) * L) | O(S) |
| 排序 | O((S + T) * L^2) | O(S * L) |

S = startWords 数量，T = targetWords 数量，L = 平均单词长度。

## 关键点总结

1. 字符集合用位掩码表示（26 位），允许 O(1) 的集合查找。
2. 对每个 target，枚举删除某个字符后的掩码，查是否在 start 集合中。
3. 位运算：移除字符 c 对应 `mask ^ bit`（因为每个字母不重复，异或等于清位）。

## 易错点

- 每个字母在字符串中最多出现一次（题目约束），所以位掩码有意义。
- 找到第一个满足条件的字符后要 `break`，避免重复计数。
