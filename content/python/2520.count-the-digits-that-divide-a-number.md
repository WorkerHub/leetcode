## 题目描述

给你一个整数 `num`，返回 `num` 中能整除 `num` 的数字的数目。

如果满足 `nums % digit == 0`，则认为 `digit` 能整除 `num`。

**示例 1：**

```
输入：num = 7
输出：1
解释：7 的唯一数字是 7，且 7 % 7 == 0，故结果为 1。
```

**示例 2：**

```
输入：num = 121
输出：2
解释：121 的数字为 1, 2, 1。
      121 % 1 == 0，121 % 2 != 0，121 % 1 == 0。
      能整除的数字有 2 个。
```

**示例 3：**

```
输入：num = 1248
输出：4
解释：1, 2, 4, 8 都能整除 1248。
```

**提示：**

- `1 <= num <= 10^9`

## 解题思路

将数字转为字符串逐位处理，检查每一位数字（排除 0，因为不能被 0 整除）是否能整除 num。

## Python 代码实现

### 方法一：字符串遍历（推荐）

```python
class Solution:
    def countDigits(self, num: int) -> int:
        count = 0
        # 遍历每一位数字
        for ch in str(num):
            d = int(ch)
            # 注意：数字不能为 0（0 不能作除数）
            if d != 0 and num % d == 0:
                count += 1
        return count
```

### 方法二：数学取模遍历

```python
class Solution:
    def countDigits(self, num: int) -> int:
        count = 0
        temp = num
        while temp > 0:
            d = temp % 10  # 取最后一位
            if d != 0 and num % d == 0:
                count += 1
            temp //= 10
        return count
```

## 复杂度分析

- 时间复杂度：O(log num)，位数为 O(log num)
- 空间复杂度：O(1)（方法二），O(log num)（方法一，字符串）

## 关键点总结

1. 数字 0 不能作除数，需跳过
2. 题目保证 num >= 1，所以 num 的各位数字不全为 0
3. 重复数字也分别计算，例如 121 中两个 1 各算一次

## 易错点

1. 数字 0 需要特殊处理，避免除以 0 的错误
2. 重复数字要重复计算，不去重
3. 检查的是 `num % digit == 0`，不是 `digit % num == 0`
