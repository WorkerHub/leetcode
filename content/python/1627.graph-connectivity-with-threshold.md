## 题目描述

有 `n` 座城市，编号为 `1` 到 `n`。如果两个城市的编号 `a` 和 `b` 的**最大公约数 gcd(a, b) > threshold**，则两座城市之间有一条边。

给你一组查询 `queries`，每个查询 `queries[i] = [a, b]`，询问城市 `a` 和 `b` 是否**连通**（可以通过边路径相连）。

返回一个布尔数组，每个元素对应一个查询的答案。

**提示：**
- `2 <= n <= 10^4`
- `0 <= threshold <= n`
- `1 <= a, b <= n`

## 解题思路

**关键观察：** 枚举所有满足 `gcd(a, b) > threshold` 的点对效率太低。

**筛法思想：** 对于每个因数 `d > threshold`，将 d 的所有倍数（`d, 2d, 3d, ...`）都连到同一个并查集中。

**时间复杂度分析：** 类似埃拉托斯特尼筛法，总操作数约为 `n/threshold * n/(threshold+1) + ...`，近似为 `O(n log n / threshold)`。

## 代码实现

### 方法一：并查集 + 筛法（推荐）

```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n + 1))
        self.rank = [0] * (n + 1)
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]
    
    def union(self, x: int, y: int):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
    
    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

class Solution:
    def areConnected(self, n: int, threshold: int, queries: List[List[int]]) -> List[bool]:
        uf = UnionFind(n)
        
        # 对每个 d > threshold，将 d 的所有倍数连接起来
        for d in range(threshold + 1, n + 1):
            # d * 1, d * 2, ..., d * k <= n
            # 将所有倍数连接到 d
            j = 2 * d
            while j <= n:
                uf.union(d, j)
                j += d
        
        # 处理查询
        return [uf.connected(a, b) for a, b in queries]
```

### 方法二：建图 + BFS（内存限制下可能超时）

```python
from typing import List
from collections import defaultdict, deque
import math

class Solution:
    def areConnected(self, n: int, threshold: int, queries: List[List[int]]) -> List[bool]:
        # 建图（效率较低，仅供理解）
        graph = defaultdict(set)
        for a in range(1, n + 1):
            for b in range(a + 1, n + 1):
                if math.gcd(a, b) > threshold:
                    graph[a].add(b)
                    graph[b].add(a)
        
        def bfs_connected(src: int, dst: int) -> bool:
            if src == dst:
                return True
            visited = {src}
            queue = deque([src])
            while queue:
                node = queue.popleft()
                for nei in graph[node]:
                    if nei == dst:
                        return True
                    if nei not in visited:
                        visited.add(nei)
                        queue.append(nei)
            return False
        
        return [bfs_connected(a, b) for a, b in queries]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集+筛法 | O(n log n * α(n)) | O(n) |
| 建图+BFS | O(n^2 + q*n) | O(n^2) |

## 关键点总结

1. 筛法枚举：对每个 `d > threshold`，连接 d 与所有 d 的倍数
2. 若 `gcd(a, b) > threshold`，则 a 和 b 一定通过它们的公因数 d 相连
3. 并查集支持高效的连通性查询
4. 时间复杂度类似调和级数：`sum(n/d for d in range(threshold+1, n+1)) = O(n ln(n/threshold))`

## 易错点

- 枚举从 `threshold + 1` 开始（严格大于 threshold）
- 每个 d 从 `2*d` 开始（`d` 本身不需要与自己合并），依次连到 `d`
- 查询时直接用并查集查连通性，不需要重新建图
