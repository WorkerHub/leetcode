## 题目描述

一位老师正在出一道是非题（True/False）的考试，答案字符串为 `answerKey`，只包含 `'T'` 和 `'F'`。

老师最多可以将 `k` 个答案改变（`'T'` 改为 `'F'` 或 `'F'` 改为 `'T'`）。返回经过最多 `k` 次改变后，答案中最长**连续相同**子字符串的长度。

**示例 1：**
```
输入：answerKey = "TTFF", k = 2
输出：4
解释：把两个 'F' 改为 'T'，得到 "TTTT"
```

**示例 2：**
```
输入：answerKey = "TFFT", k = 1
输出：3
解释：改变第一个或最后一个字符
```

**提示：**
- `n == answerKey.length`
- `1 <= n <= 5 * 10^4`
- `k <= n`
- `answerKey[i]` 是 `'T'` 或 `'F'`

## 解题思路

分别考虑**最多改 k 个 'F' 变为 'T'** 和**最多改 k 个 'T' 变为 'F'** 两种情况，取最大值。

对于每种情况，使用**滑动窗口**：
- 维护窗口 `[left, right]`，保证窗口内少数字符（需要改变的字符）数量 ≤ k
- 当超过 k 个需要改变时，左指针右移
- 更新最大窗口大小

## 代码实现

### 方法一：滑动窗口（推荐）

```python
class Solution:
    def maxConsecutiveAnswers(self, answerKey: str, k: int) -> int:
        def max_window(c: str) -> int:
            # 最多改变 k 个字符 c，返回最长连续相同子串长度
            left = 0
            change_count = 0  # 窗口内需要改变的字符数
            max_len = 0

            for right in range(len(answerKey)):
                if answerKey[right] == c:
                    change_count += 1  # 新加入的字符需要被改变

                # 超出 k 个改变，收缩左边界
                while change_count > k:
                    if answerKey[left] == c:
                        change_count -= 1
                    left += 1

                max_len = max(max_len, right - left + 1)

            return max_len

        # 分别尝试把所有 'T' 改成 'F' 和把所有 'F' 改成 'T'
        return max(max_window('T'), max_window('F'))
```

### 方法二：二分查找 + 前缀和

```python
class Solution:
    def maxConsecutiveAnswers(self, answerKey: str, k: int) -> int:
        n = len(answerKey)

        # 前缀和：prefix_t[i] = answerKey[0..i-1] 中 T 的个数
        prefix_t = [0] * (n + 1)
        prefix_f = [0] * (n + 1)
        for i in range(n):
            prefix_t[i + 1] = prefix_t[i] + (1 if answerKey[i] == 'T' else 0)
            prefix_f[i + 1] = prefix_f[i] + (1 if answerKey[i] == 'F' else 0)

        def can_extend(length: int) -> bool:
            # 检查是否存在长度为 length 的窗口，改变 k 个字符后全相同
            for left in range(n - length + 1):
                right = left + length
                # 将所有 T 改为 F
                t_count = prefix_t[right] - prefix_t[left]
                if t_count <= k:
                    return True
                # 将所有 F 改为 T
                f_count = prefix_f[right] - prefix_f[left]
                if f_count <= k:
                    return True
            return False

        # 二分答案
        lo, hi = 1, n
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_extend(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 二分查找 | O(n log n) | O(n) |

## 关键点总结

1. 分别对 `T` 和 `F` 各运行一次滑动窗口，取最大值
2. 滑动窗口中，维护"需要改变的字符数 ≤ k"的最大窗口
3. 窗口收缩条件：改变数超过 k 时左指针右移

## 易错点

- 需要分别考虑"全部变为 T" 和 "全部变为 F" 两种情况
- 计数的是需要**改变**的字符数（少数字符），不是多数
