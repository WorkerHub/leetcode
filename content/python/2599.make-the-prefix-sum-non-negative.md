## 题目描述

给你一个整数数组 `nums`。你可以进行若干次操作，每次操作将 `nums` 中任一元素移到数组末尾。

返回使 `nums` **前缀和数组中所有元素均非负** 所需的 **最少** 操作次数。

**示例 1：**

```
输入：nums = [2,3,-5,4]
输出：0
解释：前缀和 [2,5,0,4]，已全非负。
```

**示例 2：**

```
输入：nums = [3,-5,-2,6]
输出：1
解释：将 -5 移到末尾：[3,-2,6,-5]，前缀和 [3,1,7,2]，全非负。
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^6 <= nums[i] <= 10^6`

## 解题思路

**贪心 + 最小堆**：

从左到右遍历，维护当前前缀和。当前缀和变为负数时，需要将之前遇到的某个负数移走（移到末尾）。

贪心策略：优先移走 **最小（绝对值最大的负数）** 的元素，这样能最大程度增大前缀和。

用最小堆维护遍历过的负数元素，当前缀和 < 0 时，从堆中弹出最小的负数加回来，操作次数 +1。

## Python 代码实现

### 方法一：贪心 + 最小堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def makePrefSumNonNeg(self, nums: List[int]) -> int:
        heap = []  # 最小堆（存负数，模拟最小堆弹出最小负数）
        prefix = 0
        ops = 0

        for x in nums:
            prefix += x
            if x < 0:
                heapq.heappush(heap, x)  # 存入负数

            # 前缀和为负时，移走最小（最负）的元素
            while prefix < 0 and heap:
                min_neg = heapq.heappop(heap)  # 最小负数（最小值）
                prefix -= min_neg  # 等价于加上 abs(min_neg)
                ops += 1

        return ops
```

### 方法二：分离正负，排序验证

```python
from typing import List

class Solution:
    def makePrefSumNonNeg(self, nums: List[int]) -> int:
        # 与方法一等价，但用排序替代堆（不推荐，O(n^2) 最坏）
        import heapq
        heap = []
        prefix = 0
        ops = 0

        for x in nums:
            if x < 0:
                heapq.heappush(heap, x)
            prefix += x
            # 贪心：每次前缀和 < 0 就移走最大绝对值的负数
            while prefix < 0:
                val = heapq.heappop(heap)
                prefix -= val  # 减去负数 = 加绝对值
                ops += 1

        return ops
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作
- 空间复杂度：O(n)，堆空间

## 关键点总结

1. 贪心：当前缀和为负时，移走当前已遇到的最小（最负）的数
2. 移走某元素等价于撤销其对前缀和的贡献
3. 最小堆存所有遇到的负数，每次弹出最小值

## 易错点

1. 将元素移到末尾意味着不影响后续计算（后续元素顺序不变），贪心正确
2. 只有负数才会使前缀和下降，所以堆中只需存负数
3. `prefix -= min_neg`：由于 `min_neg < 0`，减去负数等于加正数
