## 题目描述

给定一个编码字符串 s。请你找出 解码字符串 并返回解码字符串的第 k 个字符。

编码规则为: k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。

**提示：**
- 2 <= s.length <= 100
- s 只包含小写字母和数字 2 到 9
- s 保证是一个有效的编码字符串
- 1 <= k <= 10^9

## 解题思路

**逆向思维：**
1. 计算解码后的总长度
2. 从后往前逆推第 k 个字符
3. 遇到数字：长度除以该数字
4. 遇到字母且位置匹配：返回

## Python 代码实现

```python
class Solution:
    def decodeAtIndex(self, s: str, k: int) -> str:
        size = 0
        
        # 计算解码后的长度
        for c in s:
            if c.isdigit():
                size *= int(c)
            else:
                size += 1
        
        # 从后往前逆推
        for c in reversed(s):
            k %= size
            
            if k == 0 and c.isalpha():
                return c
            
            if c.isdigit():
                size //= int(c)
            else:
                size -= 1
        
        return ""
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **避免展开**：直接计算长度
2. **逆向处理**：从后往前推导
3. **取模运算**：k % size 处理循环
