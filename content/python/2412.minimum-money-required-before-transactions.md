## 题目描述

给你一个下标从 **0** 开始的二维整数数组 `transactions`，其中 `transactions[i] = [costi, cashbacki]`。

在 **一次** 交易中，你需要先支付 `costi` 的钱，交易完成后，你会收到 `cashbacki` 的返现。返现值比支付金额少，即 `cashbacki < costi`。

设 `money` 为你当前拥有的钱数。在进行任意一次交易之前，必须保证你拥有的金额 **大于等于** `costi`。

**无论你以什么顺序**执行交易，返回能够完成所有交易的 **最少** 起始金额。

**示例 1：**
```
输入：transactions = [[2,1],[5,0],[4,2]]
输出：10
解释：10 >= 5，先执行第 2 笔，剩 5；5 >= 4，执行第 3 笔，剩 3；3 >= 2，执行第 1 笔，剩 2。
```

**示例 2：**
```
输入：transactions = [[3,0],[0,3]]
输出：3
```

## 解题思路

**贪心分析：**

设净损失 `loss[i] = cost[i] - cashback[i]`（每笔交易净消耗的钱）。

**最优顺序：** 将净损失较大的交易排在前面（先做亏得多的）。具体来说：
- 把所有 `cost > cashback` 即 `loss > 0` 的交易排在前面，按 `loss` 降序（等价于 `cashback` 升序）
- `cost <= cashback` 的交易（不亏损）排在后面

**计算最少起始金额：**
按最优顺序排列后，初始金额 = 前缀最大需求。可以推导出：
- 对某个顺序，所需起始金额 = 各步骤执行前余额至少为 `cost[i]` 的最大约束反推

**数学公式：**
设总净损失 `total_loss = sum(cost - cashback for all i where cost > cashback)`

答案 = `total_loss + max over all i of (cost[i] - min(cashback[i], cost[i] - cashback[i]))` ...

实际上更简洁的推导：
- 若将所有亏损交易按 `cashback` 升序排（推迟现金回流），则某一步的最大需求
- 答案 = 总亏损额 + 最大的 `max(cost[i] - cashback[i], cashback[i])` ...

最优解思路：所需资金 = `sum(loss for loss > 0)` + 最大的 `max(cashback[i], cost[i])`（某一笔特别大）

## 代码实现

### 方法一：贪心数学（推荐）

```python
from typing import List

class Solution:
    def minimumMoney(self, transactions: List[List[int]]) -> int:
        # 所有亏损交易的总损失
        total_loss = sum(max(cost - cashback, 0) for cost, cashback in transactions)

        ans = 0
        for cost, cashback in transactions:
            loss = cost - cashback
            if loss > 0:
                # 亏损交易：把它放在最后执行，需要 total_loss - loss + cost
                needed = total_loss - loss + cost
            else:
                # 盈利或不亏交易：放在最后，前面已扣 total_loss，还需 cost
                needed = total_loss + cost
            ans = max(ans, needed)

        return ans
```

### 方法二：排序模拟验证

```python
from typing import List
from itertools import permutations

class Solution:
    def minimumMoney(self, transactions: List[List[int]]) -> int:
        # 仅适合小规模验证
        def simulate(order, start):
            money = start
            for cost, cashback in order:
                if money < cost:
                    return False
                money = money - cost + cashback
            return True

        # 贪心：总损失 + 最坏情况
        total_loss = sum(max(c - cb, 0) for c, cb in transactions)
        ans = 0
        for cost, cashback in transactions:
            loss = cost - cashback
            if loss > 0:
                needed = total_loss - loss + cost
            else:
                needed = total_loss + cost
            ans = max(ans, needed)
        return ans
```

## 关键点总结

1. 总亏损 = 所有净损失之和（只算正的 `cost - cashback`）
2. 对每笔交易，考虑把它放到最后执行时所需的最大起始资金
3. 亏损交易放最后：资金 = 总亏损 - 该笔损失 + 该笔 cost
4. 盈利交易放最后：资金 = 总亏损 + 该笔 cost

## 易错点

- 只有 `cost > cashback` 的交易才算入 `total_loss`
- 盈利交易（`cashback >= cost`）排在最后时，所需资金是 `total_loss + cost`，不是更少
