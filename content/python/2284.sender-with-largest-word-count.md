## 题目描述

给你两个字符串数组 `messages` 和 `senders`，`messages[i]` 是 `senders[i]` 发送的消息。

一个发件人的**单词计数**是其发送的所有消息中的单词总数（按空格分割）。

返回单词计数最多的发件人；若有多个单词计数相同的发件人，返回字典序最大的那一个。

**示例 1：**
```
输入：messages = ["Hello userTwoo I am using LeetCode Messenger","MyName is USER0 and I am a Gamer","Will NOT let you Win","If you can win MAYBE let me know how"],
       senders = ["USER1","USER2","USER3","USER2"]
输出："USER2"
```

## 解题思路

用哈希表统计每个发件人的单词总数，然后遍历找最大值（同时处理字典序）。

## 代码实现

### 方法一：defaultdict 统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def largestWordCount(self, messages: List[str], senders: List[str]) -> str:
        word_count = defaultdict(int)

        for msg, sender in zip(messages, senders):
            word_count[sender] += len(msg.split())

        # 按单词数降序，单词数相同按字典序降序取最大
        best = ""
        best_count = 0
        for sender, cnt in word_count.items():
            if cnt > best_count or (cnt == best_count and sender > best):
                best = sender
                best_count = cnt

        return best
```

### 方法二：max + 自定义 key

```python
from typing import List
from collections import defaultdict

class Solution:
    def largestWordCount(self, messages: List[str], senders: List[str]) -> str:
        word_count = defaultdict(int)
        for msg, sender in zip(messages, senders):
            word_count[sender] += len(msg.split())

        # 用 max，key 是 (单词数, 字典序)，字典序越大越好
        return max(word_count, key=lambda s: (word_count[s], s))
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为消息数，L 为平均单词数（split 操作）。
- 空间复杂度：O(k)，k 为不同发件人数量。

## 关键点总结

1. `msg.split()` 按空格切分，得到单词列表，取其长度。
2. 同值时取字典序最大，用自定义 key `(cnt, sender)` 简洁处理。
3. `max(dict, key=...)` 直接对字典键取最大值。

## 易错点

- 题目要求字典序最大而非最小，注意比较方向。
- `split()` 无参数会处理连续空格，等价于按任意空白字符切分。
