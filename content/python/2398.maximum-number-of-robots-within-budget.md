## 题目描述

给你一个下标从 **0** 开始的整数数组 `chargeTimes` 和 `runningCosts`，分别表示每个机器人的充电时间和运行费用，以及一个整数 `budget`。

运行 `k` 个连续机器人（下标从 `i` 到 `i+k-1`）的总费用为：
```
max(chargeTimes[i..i+k-1]) + k * sum(runningCosts[i..i+k-1])
```

返回在 `budget` 以内可以连续运行的**最多机器人数量**。

**示例 1：**
```
输入：chargeTimes = [3,6,1,3,4], runningCosts = [2,1,3,4,5], budget = 25
输出：3
解释：选机器人 0,1,2：max(3,6,1) + 3*(2+1+3) = 6 + 18 = 24 <= 25
```

**提示：**
- `chargeTimes.length == runningCosts.length == n`
- `1 <= n <= 5 * 10^4`
- `1 <= chargeTimes[i], runningCosts[i] <= 10^5`
- `1 <= budget <= 10^15`

## 解题思路

**二分 + 滑动窗口 + 单调队列：**

1. 二分答案 `k`（机器人数量）。
2. 对于固定的 `k`，用大小为 `k` 的滑动窗口验证是否存在合法方案：
   - 窗口内最大值用**单调递减双端队列**维护。
   - 窗口内 running 费用之和用**前缀和**维护。
3. 若窗口费用 `<= budget`，则 `k` 可行。

**也可以直接用滑动窗口（不二分）**，但二分更直观。

## 代码实现

### 方法一：二分 + 滑动窗口 + 单调队列（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def maximumRobots(self, chargeTimes: List[int],
                      runningCosts: List[int], budget: int) -> int:
        n = len(chargeTimes)
        
        # 前缀和：快速计算区间和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + runningCosts[i]
        
        def check(k):
            """判断窗口大小为 k 是否可行"""
            dq = deque()  # 单调递减队列，存下标
            
            for i in range(n):
                # 维护单调递减队列（保证队首是最大值）
                while dq and chargeTimes[dq[-1]] <= chargeTimes[i]:
                    dq.pop()
                dq.append(i)
                
                # 移除窗口外的元素
                if dq[0] <= i - k:
                    dq.popleft()
                
                # 窗口大小达到 k 时检验
                if i >= k - 1:
                    max_charge = chargeTimes[dq[0]]
                    total_run = prefix[i + 1] - prefix[i - k + 1]
                    if max_charge + k * total_run <= budget:
                        return True
            
            return False
        
        # 二分机器人数量
        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        
        return lo
```

### 方法二：直接滑动窗口（O(n)）

```python
from typing import List
from collections import deque

class Solution:
    def maximumRobots(self, chargeTimes: List[int],
                      runningCosts: List[int], budget: int) -> int:
        n = len(chargeTimes)
        dq = deque()  # 单调递减队列
        ans = 0
        window_sum = 0
        left = 0
        
        for right in range(n):
            # 入窗口
            window_sum += runningCosts[right]
            while dq and chargeTimes[dq[-1]] <= chargeTimes[right]:
                dq.pop()
            dq.append(right)
            
            # 收缩窗口直到满足预算
            while left <= right:
                k = right - left + 1
                max_charge = chargeTimes[dq[0]]
                if max_charge + k * window_sum <= budget:
                    break
                # 移出左端
                window_sum -= runningCosts[left]
                if dq[0] == left:
                    dq.popleft()
                left += 1
            
            ans = max(ans, right - left + 1)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分+滑动窗口 | O(n log n) | O(n) |
| 直接滑动窗口 | O(n) | O(n) |

## 关键点总结

1. 单调递减双端队列维护窗口最大值（O(1) 查询）。
2. 前缀和维护窗口内 runningCosts 之和（O(1) 查询）。
3. 直接滑动窗口：右指针每次右移一步，左指针收缩到满足预算。

## 易错点

- 费用公式：`max_charge + k * sum_running`，注意 k 是窗口大小（要乘上）。
- 单调队列中存**下标**而非值，便于判断是否超出窗口。
- 直接滑动窗口中，窗口左端移出时要同时更新 `window_sum`。
