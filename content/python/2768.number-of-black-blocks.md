## 题目描述

给你两个整数 `m` 和 `n`，以及一个下标从 **0** 开始的二维整数数组 `coordinates`，其中 `coordinates[i] = [x, y]` 表示黑色格子的位置。

矩阵中所有格子初始为白色（除了 `coordinates` 中的格子）。

对每个 2x2 子矩阵，统计其中黑色格子的数目（0、1、2、3、4）。返回长度为 5 的数组 `arr`，其中 `arr[i]` 是包含恰好 `i` 个黑色格子的 2x2 子矩阵数量。

**示例：**
```
输入：m = 3, n = 3, coordinates = [[0,0]]
输出：[3,1,0,0,0]
```

**提示：**
- `2 <= m, n <= 10^5`
- `1 <= coordinates.length <= 10^4`

## 解题思路

每个 2x2 子矩阵的左上角为 `(r, c)`，范围 `0 <= r <= m-2, 0 <= c <= n-2`。

对每个黑色格子 `(x, y)`，它属于至多 4 个 2x2 子矩阵（左上角为 `(x-1,y-1), (x-1,y), (x,y-1), (x,y)`）。

用哈希表统计每个 2x2 子矩阵（用左上角标识）内的黑色格子数，然后统计各计数对应的子矩阵数量。

## Python 代码实现

### 方法一：哈希表统计（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countBlackBlocks(self, m: int, n: int, coordinates: List[List[int]]) -> List[int]:
        # 统计每个 2x2 子矩阵（左上角 (r,c)）中黑色格子数
        block_count = defaultdict(int)

        for x, y in coordinates:
            # 该格子属于左上角为 (r,c) 的 2x2 子矩阵
            for dr in range(2):
                for dc in range(2):
                    r, c = x - dr, y - dc
                    if 0 <= r <= m - 2 and 0 <= c <= n - 2:
                        block_count[(r, c)] += 1

        # 统计结果
        ans = [0] * 5
        for cnt in block_count.values():
            ans[cnt] += 1

        # 0 个黑色格子的 2x2 子矩阵数 = 总数 - 有黑色格子的数
        total_blocks = (m - 1) * (n - 1)
        ans[0] = total_blocks - sum(ans[1:])

        return ans
```

## 复杂度分析

- 时间复杂度：O(k)，k 为黑色格子数
- 空间复杂度：O(k)

## 关键点总结

1. 每个黑色格子最多影响 4 个 2x2 子矩阵
2. 用哈希表记录各子矩阵中黑色格子数
3. 总 2x2 子矩阵数 = `(m-1) * (n-1)`

## 易错点

1. 需要检查 2x2 子矩阵左上角是否在合法范围内
2. ans[0] 通过总数减去有黑色格子的子矩阵数得到
