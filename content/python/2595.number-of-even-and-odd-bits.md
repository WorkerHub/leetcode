## 题目描述

给你一个 **正** 整数 `n`。

用 `even` 表示整数 `n` 的二进制表示中，**偶数** 下标处（0 开始）值为 `1` 的位数。用 `odd` 表示奇数下标处值为 `1` 的位数。

返回整数数组 `[even, odd]`。

**示例 1：**

```
输入：n = 17
输出：[2,0]
解释：17 的二进制为 10001
- 下标 0 和 4 处为 1（偶数下标），even = 2
- 奇数下标处无 1，odd = 0
```

**示例 2：**

```
输入：n = 2
输出：[0,1]
解释：2 的二进制为 10，下标 1 处为 1（奇数下标），odd = 1。
```

**提示：**

- `1 <= n <= 1000`

## 解题思路

直接枚举 `n` 的每一位，判断该位下标的奇偶性，分别统计。

## Python 代码实现

### 方法一：逐位检查（推荐）

```python
from typing import List

class Solution:
    def evenOddBit(self, n: int) -> List[int]:
        even, odd = 0, 0
        idx = 0  # 当前位的下标
        while n:
            bit = n & 1  # 最低位
            if bit == 1:
                if idx % 2 == 0:
                    even += 1
                else:
                    odd += 1
            n >>= 1
            idx += 1
        return [even, odd]
```

### 方法二：位掩码（奇偶分离）

```python
from typing import List

class Solution:
    def evenOddBit(self, n: int) -> List[int]:
        # 偶数位掩码：0b...01010101（下标 0,2,4,...）
        even_mask = 0x5555555555555555  # 64位全1偶数位
        odd_mask  = 0xAAAAAAAAAAAAAAAA  # 64位全1奇数位

        even = bin(n & even_mask).count('1')
        odd  = bin(n & odd_mask).count('1')
        return [even, odd]
```

## 复杂度分析

- 时间复杂度：O(log n)，处理每一位
- 空间复杂度：O(1)

## 关键点总结

1. 下标从 0 开始，最低有效位是下标 0（偶数）
2. 逐位右移，同时递增下标计数器
3. 位掩码法：`0x5555...` 的偶数位全为 1，`0xAAAA...` 的奇数位全为 1

## 易错点

1. 下标是从 **低位** 开始计数（最右边是下标 0）
2. 只有值为 `1` 的位才计数
3. n <= 1000，二进制最多 10 位，不需要考虑太大的掩码
