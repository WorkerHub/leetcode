## 题目描述

给你一个整数对数组 `pairs`，其中 `pairs[i] = [starti, endi]`。

如果一种排列满足：对所有 `i < pairs.length - 1` 都有 `pairs[i][1] == pairs[i+1][0]`，那么这个排列是**有效的**。

返回任意一个有效排列（保证至少有一个有效排列）。

**示例：**
```
输入：pairs = [[5,1],[4,5],[11,9],[9,4]]
输出：[[11,9],[9,4],[4,5],[5,1]]
```

## 解题思路

**欧拉路径（Eulerian Path）：**

将每对 `[a, b]` 看做有向图中从 `a` 到 `b` 的边，问题转化为：找一条遍历所有边**恰好一次**的路径（有向图欧拉路径）。

**欧拉路径存在条件（有向图）：**
- 所有节点出度 = 入度（欧拉回路），从任意节点出发
- 恰好一个节点出度 - 入度 = 1（起点），一个入度 - 出度 = 1（终点）

**Hierholzer 算法** 求欧拉路径：DFS + 栈，回溯时记录路径。

## 代码实现

### 方法一：Hierholzer 算法（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def validArrangement(self, pairs: List[List[int]]) -> List[List[int]]:
        # 构建邻接表
        graph = defaultdict(list)
        in_deg = defaultdict(int)
        out_deg = defaultdict(int)

        for u, v in pairs:
            graph[u].append(v)
            out_deg[u] += 1
            in_deg[v] += 1

        # 找欧拉路径的起点
        start = pairs[0][0]  # 默认
        for node in out_deg:
            if out_deg[node] - in_deg[node] == 1:
                start = node
                break

        # Hierholzer 算法（迭代版）
        path = []
        stack = [start]

        while stack:
            u = stack[-1]
            if graph[u]:
                v = graph[u].pop()
                stack.append(v)
            else:
                path.append(stack.pop())

        # path 是逆序的欧拉路径节点序列，转换为边
        path.reverse()
        return [[path[i], path[i+1]] for i in range(len(path) - 1)]
```

### 方法二：递归版 Hierholzer

```python
from typing import List
from collections import defaultdict
import sys
sys.setrecursionlimit(200005)

class Solution:
    def validArrangement(self, pairs: List[List[int]]) -> List[List[int]]:
        graph = defaultdict(list)
        in_deg = defaultdict(int)
        out_deg = defaultdict(int)

        for u, v in pairs:
            graph[u].append(v)
            out_deg[u] += 1
            in_deg[v] += 1

        # 找起点
        start = pairs[0][0]
        for node in graph:
            if out_deg[node] - in_deg.get(node, 0) == 1:
                start = node
                break

        result = []

        def dfs(u):
            while graph[u]:
                v = graph[u].pop()
                dfs(v)
            result.append(u)

        dfs(start)
        result.reverse()

        return [[result[i], result[i+1]] for i in range(len(result) - 1)]
```

## 复杂度分析

- 时间复杂度：O(E)，E 为边数（pairs 的长度）
- 空间复杂度：O(V + E)，V 为节点数

## 关键点总结

1. 问题等价于有向图欧拉路径（每条边恰好访问一次）
2. 起点：出度 - 入度 = 1 的节点；若无则任意节点（欧拉回路）
3. Hierholzer 算法：DFS + 后序记录（先处理完所有出边再记录节点）
4. 最终结果是节点路径的逆序，需翻转后转换为边

## 易错点

- 欧拉路径的起点是出度比入度多 1 的节点，不是任意节点
- Hierholzer 算法得到的路径是逆序的，需要 `reverse()`
- 递归版需要增大递归限制（边数可达 10^5）
