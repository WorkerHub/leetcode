## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

如果两侧元素**都小于** `nums[i]`，则 `i` 是一个**山峰**（hill）。
如果两侧元素**都大于** `nums[i]`，则 `i` 是一个**山谷**（valley）。

相邻的相同元素视为一组，仅统计整组的中间那个。

返回 `nums` 中山峰和山谷的数量之和。

**示例 1：**
```
输入：nums = [2,4,1,1,6,5]
输出：3
解释：去重后 [2,4,1,6,5]，山峰4和6，山谷1和5... 实际答案3。
```

**示例 2：**
```
输入：nums = [6,6,5,5,4,1]
输出：0
```

**提示：**
- `3 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 解题思路

先对数组去掉相邻重复元素（保留唯一值序列），然后对中间元素（排除首尾）判断是否为山峰或山谷。

## 代码实现

### 方法一：去重后遍历（推荐）

```python
from typing import List

class Solution:
    def countHillValley(self, nums: List[int]) -> int:
        # 去除相邻重复元素
        deduped = [nums[0]]
        for x in nums[1:]:
            if x != deduped[-1]:
                deduped.append(x)

        ans = 0
        # 遍历中间元素（不含首尾）
        for i in range(1, len(deduped) - 1):
            left = deduped[i - 1]
            mid = deduped[i]
            right = deduped[i + 1]
            if left < mid and right < mid:  # 山峰
                ans += 1
            elif left > mid and right > mid:  # 山谷
                ans += 1
        return ans
```

### 方法二：直接在原数组上查找非重复边界

```python
from typing import List

class Solution:
    def countHillValley(self, nums: List[int]) -> int:
        ans = 0
        n = len(nums)

        def find_diff_left(i):
            """找 i 左边第一个与 nums[i] 不同的值"""
            j = i - 1
            while j >= 0 and nums[j] == nums[i]:
                j -= 1
            return nums[j] if j >= 0 else None

        def find_diff_right(i):
            """找 i 右边第一个与 nums[i] 不同的值"""
            j = i + 1
            while j < n and nums[j] == nums[i]:
                j += 1
            return nums[j] if j < n else None

        seen = set()  # 避免重复计算同一组
        for i in range(n):
            # 跳过重复组中非最后一个
            if i < n - 1 and nums[i] == nums[i + 1]:
                continue
            left = find_diff_left(i)
            right = find_diff_right(i)
            if left is None or right is None:
                continue
            if left < nums[i] and right < nums[i]:
                ans += 1
            elif left > nums[i] and right > nums[i]:
                ans += 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(n)，存储去重数组（方法一）。

## 关键点总结

1. 相邻重复元素合并后再判断，是解题关键。
2. 判断山峰：`left < mid` 且 `right < mid`；山谷：`left > mid` 且 `right > mid`。
3. 去重后的首尾元素不算山峰/山谷。

## 易错点

- 忘记先去除相邻重复元素，直接判断会导致重复计数。
- 首元素和尾元素不能成为山峰/山谷（没有两侧）。
