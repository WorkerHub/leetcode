## 题目描述

给你一个正整数 `n`，表示有 `n` 个节点（编号 0 到 n-1）的有向图，以及边数组 `edges`（`edges[i] = [ui, vi, wi]`）和标记节点数组 `marked`。

找出从节点 `s` 到任意 **标记节点** 的 **最短路径** 长度。如果不可达，返回 -1。

**示例 1：**
```
输入：n=4, edges=[[0,1,1],[1,2,3],[2,3,1],[0,3,6]], marked=[2,3], s=0
输出：4
解释：0->1->2 距离 4，0->3 距离 6，最短 4
```

**提示：**
- `2 <= n <= 500`
- `1 <= edges.length <= 10^4`
- `marked.length >= 1`

## 解题思路

从起点 `s` 跑 Dijkstra 单源最短路，然后遍历所有标记节点，返回最小距离。

## Python 代码实现

### 方法一：Dijkstra（推荐）

```python
import heapq
from typing import List
from collections import defaultdict

class Solution:
    def minimumDistance(self, n: int, edges: List[List[int]], s: int, marked: List[int]) -> int:
        # 构建有向图邻接表
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))

        # Dijkstra 从 s 出发
        INF = float('inf')
        dist = [INF] * n
        dist[s] = 0
        heap = [(0, s)]

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(heap, (dist[v], v))

        # 找标记节点中的最短距离
        ans = min(dist[node] for node in marked)
        return ans if ans < INF else -1
```

## 复杂度分析

- 时间复杂度：O((n + E) log n)，E 为边数
- 空间复杂度：O(n + E)

## 关键点总结

1. 标准 Dijkstra 求单源最短路
2. 遍历标记节点取最小距离

## 易错点

1. 注意是有向图，边只有一个方向
2. 答案为 INF 时返回 -1
