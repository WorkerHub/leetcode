## 题目描述

给你一棵二叉树的根节点 `root` ，树中有 `n` 个节点，每个节点都有一个不同于其他节点且处于 `1` 到 `n` 之间的值。

另给你一个由 `n` 个值组成的行程序列 `voyage` ，表示**预期**的二叉树**先序遍历**结果。

通过交换节点的左子树和右子树，可以**翻转**该二叉树中的任意节点。例如，翻转节点 1 的效果如下：

请翻转**最少**的树中节点，使二叉树的**先序遍历**与预期的遍历行程 `voyage` 相匹配。

如果可以，则返回**翻转的**所有节点的值的列表。你可以按任何顺序返回答案。如果不能，则返回列表 `[-1]`。

**示例 1：**
```
输入：root = [1,2], voyage = [2,1]
输出：[-1]
解释：翻转节点无法令先序遍历匹配预期行程。
```

**示例 2：**
```
输入：root = [1,2,3], voyage = [1,3,2]
输出：[1]
解释：交换节点 1 的两个子节点，就能生成匹配的行程 [1,3,2]。
```

**示例 3：**
```
输入：root = [1,2,3], voyage = [1,2,3]
输出：[]
解释：不需要翻转任何节点。
```

**提示：**
- 树中的节点数目为 `n`
- `n == voyage.length`
- `1 <= n <= 100`
- `1 <= Node.val, voyage[i] <= n`
- 树中的所有值**互不相同**
- `voyage` 中的所有值**互不相同**

## 解题思路

这道题要求通过翻转节点（交换左右子树）使得先序遍历与给定序列匹配。

**核心思想：**
1. 使用先序遍历，同时匹配 voyage 序列
2. 对于每个节点，检查其值是否与 voyage 中对应位置匹配
3. 如果左子节点与 voyage 下一个值不匹配，尝试翻转
4. 如果翻转后仍不匹配，返回 `[-1]`

**算法流程：**
1. 维护一个指针 idx，指向 voyage 中当前应该访问的位置
2. 先序遍历树：访问根节点 -> 左子树 -> 右子树
3. 如果当前节点值不匹配，返回失败
4. 如果左子节点不匹配但右子节点匹配，记录翻转并先访问右子树

## Python 代码实现

### 方法一：DFS（推荐）⭐

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flipMatchVoyage(self, root: Optional[TreeNode], voyage: List[int]) -> List[int]:
        self.flipped = []
        self.idx = 0
        
        def dfs(node):
            """返回 True 表示可以匹配"""
            if not node:
                return True
            
            # 检查当前节点是否匹配
            if node.val != voyage[self.idx]:
                return False
            
            self.idx += 1
            
            # 检查左子节点
            if node.left and node.left.val != voyage[self.idx]:
                # 左子节点不匹配，尝试翻转
                self.flipped.append(node.val)
                # 先访问右子树，再访问左子树
                return dfs(node.right) and dfs(node.left)
            
            # 正常顺序：先左后右
            return dfs(node.left) and dfs(node.right)
        
        return self.flipped if dfs(root) else [-1]
```

### 方法二：迭代版本

```python
class Solution:
    def flipMatchVoyage(self, root: Optional[TreeNode], voyage: List[int]) -> List[int]:
        flipped = []
        stack = [root]
        idx = 0
        
        while stack:
            node = stack.pop()
            
            if not node:
                continue
            
            # 检查当前节点是否匹配
            if node.val != voyage[idx]:
                return [-1]
            
            idx += 1
            
            # 如果有左右子节点
            if node.left and node.right:
                # 检查是否需要翻转
                if node.left.val != voyage[idx]:
                    # 需要翻转：先右后左
                    flipped.append(node.val)
                    stack.append(node.left)
                    stack.append(node.right)
                else:
                    # 不需要翻转：先左后右（栈是后进先出）
                    stack.append(node.right)
                    stack.append(node.left)
            elif node.left:
                stack.append(node.left)
            elif node.right:
                stack.append(node.right)
        
        return flipped
```

### 方法三：简化版 DFS

```python
class Solution:
    def flipMatchVoyage(self, root: Optional[TreeNode], voyage: List[int]) -> List[int]:
        self.i = 0
        res = []
        
        def dfs(node):
            if not node:
                return True
            if node.val != voyage[self.i]:
                return False
            self.i += 1
            
            if node.left and node.left.val != voyage[self.i]:
                res.append(node.val)
                node.left, node.right = node.right, node.left
            
            return dfs(node.left) and dfs(node.right)
        
        return res if dfs(root) else [-1]
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，递归栈深度，h 是树高

## 关键点总结

1. **先序遍历**：根 -> 左 -> 右的顺序
2. **贪心策略**：只在必要时翻转（左子节点不匹配时）
3. **索引维护**：用一个指针追踪 voyage 中的位置
4. **提前退出**：一旦发现无法匹配，立即返回 `[-1]`
5. **交换技巧**：翻转就是先访问右子树，再访问左子树

## 易错点

1. **索引越界**：访问 voyage 前要检查索引
2. **翻转条件**：只在左子节点不匹配时翻转
3. **返回值**：失败时返回 `[-1]`，不是空列表
4. **空节点**：空节点直接返回 True
5. **栈顺序**：迭代版本注意栈的后进先出特性
