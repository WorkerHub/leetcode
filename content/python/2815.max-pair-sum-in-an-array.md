## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。请你从 `nums` 中找出和**最大**的一对数，条件是这两个数字的最大数字相同。

最大数字是指该数中各位数字的最大值。例如 34 的最大数字是 4，17 的最大数字是 7。

如果不存在满足要求的数对，则返回 `-1`。

**示例 1：**
```
输入：nums = [51,71,17,24,42]
输出：88
解释：
最大数字相同的对：
(71,17) 最大数字均为 7，和 = 88
(24,42) 最大数字均为 4，和 = 66
答案 = 88
```

**示例 2：**
```
输入：nums = [1,2,3,4]
输出：-1
解释：没有两个数字有相同的最大数字
```

**提示：**
- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`

## 解题思路

对每个数，计算其最大数字（各位最大值），然后按最大数字分组，同组内找最大两数之和。

方法：用哈希表记录每个最大数字对应的最大数值，遍历时更新答案。

## Python 代码实现

### 方法一：哈希表记录最大值（推荐）

```python
from typing import List

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        # max_by_key[d] = 最大数字为 d 的数中，已见过的最大值
        max_by_key = {}
        ans = -1

        for num in nums:
            key = max(int(d) for d in str(num))  # 最大数字
            if key in max_by_key:
                ans = max(ans, max_by_key[key] + num)
                max_by_key[key] = max(max_by_key[key], num)
            else:
                max_by_key[key] = num

        return ans
```

### 方法二：暴力枚举（简单直观）

```python
from typing import List

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        n = len(nums)
        ans = -1

        def max_digit(x: int) -> int:
            """计算整数 x 的最大数字"""
            return max(int(d) for d in str(x))

        for i in range(n):
            for j in range(i + 1, n):
                if max_digit(nums[i]) == max_digit(nums[j]):
                    ans = max(ans, nums[i] + nums[j])

        return ans
```

### 方法三：分组排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSum(self, nums: List[int]) -> int:
        groups = defaultdict(list)
        for num in nums:
            key = max(int(d) for d in str(num))
            groups[key].append(num)

        ans = -1
        for key, vals in groups.items():
            if len(vals) >= 2:
                vals.sort(reverse=True)
                ans = max(ans, vals[0] + vals[1])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n × log10(max_val))，对每个数求最大数字需要 O(log10(val)) 时间
- 空间复杂度：O(1)（方法一，哈希表最多 10 个键）

## 关键点总结

1. 最大数字 = 整数各位中的最大值，可用字符串转换后取 max
2. 同一最大数字的两个数中，和最大 = 取最大的两个数
3. 方法一只需一次遍历，边遍历边更新

## 易错点

1. 注意最大数字是"各位中的最大值"，不是整个数字本身
2. 当没有满足条件的对时返回 -1，初始化 ans = -1 即可
3. `max(int(d) for d in str(num))` 是正确的写法（注意转 int）
