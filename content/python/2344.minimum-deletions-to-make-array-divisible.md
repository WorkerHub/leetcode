## 题目描述

给你两个正整数数组 `nums` 和 `numsDivide`。你可以从 `nums` 中删除任意数目的元素。

请你返回使 `nums` 中**最小**元素可以**整除** `numsDivide` 中**所有**元素的**最少删除次数**，如果无法实现则返回 `-1`。

注意：`a` 整除 `b` 意味着 `b % a == 0`。

**示例 1：**
```
输入：nums = [2,3,2,4,3], numsDivide = [9,6,9,3,15]
输出：2
解释：numsDivide 的 GCD = 3。删除 2 后，最小元素为 3，可整除 GCD。
```

**示例 2：**
```
输入：nums = [4,3,6], numsDivide = [8,2,6,10]
输出：-1
```

**提示：**
- `1 <= nums.length, numsDivide.length <= 10^5`
- `1 <= nums[i], numsDivide[i] <= 10^9`

## 解题思路

**核心观察：**
- `nums` 的最小元素 `v` 能整除 `numsDivide` 中所有元素，当且仅当 `v` 是 `numsDivide` 的 GCD 的因子（`GCD % v == 0`）。
- 先计算 `numsDivide` 的 GCD，记为 `g`。
- 对 `nums` 排序，从小到大找第一个能整除 `g` 的元素，它之前的所有元素都需要删除。

## 代码实现

### 方法一：计算 GCD + 排序（推荐）

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def minOperations(self, nums: List[int], numsDivide: List[int]) -> int:
        # 计算 numsDivide 的 GCD
        g = reduce(gcd, numsDivide)
        
        # 排序 nums
        nums.sort()
        
        # 找第一个能整除 g 的元素，返回其前面的元素数（删除次数）
        for i, x in enumerate(nums):
            if g % x == 0:  # x 能整除 g（x 是 g 的因子）
                return i
        
        return -1
```

### 方法二：不排序直接计数

```python
from typing import List
from math import gcd
from functools import reduce

class Solution:
    def minOperations(self, nums: List[int], numsDivide: List[int]) -> int:
        g = reduce(gcd, numsDivide)
        
        # 找 nums 中最小的能整除 g 的元素
        # 统计比它更小的元素数量
        min_valid = None
        for x in nums:
            if g % x == 0:
                if min_valid is None or x < min_valid:
                    min_valid = x
        
        if min_valid is None:
            return -1
        
        # 删除所有比 min_valid 小的元素
        return sum(1 for x in nums if x < min_valid)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 | O(n log n + m log m) | O(1) |
| 直接计数 | O(n + m log m) | O(1) |

其中 n = len(nums)，m = len(numsDivide)。

## 关键点总结

1. `v` 能整除 numsDivide 中所有元素等价于 `v` 是 numsDivide 的 GCD 的因子。
2. 先算 GCD 减少问题规模，再在 nums 中找最小的 GCD 因子。
3. 删除次数 = 该元素在排序后的位置（即比它小的元素个数）。

## 易错点

- `g % x == 0` 表示 x 是 g 的因子（x 能整除 g），而不是 `x % g == 0`。
- 若 nums 中没有 g 的因子，返回 -1。
