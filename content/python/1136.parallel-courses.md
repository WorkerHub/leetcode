## 题目描述

给你一个整数 `n`，表示编号从 `1` 到 `n` 的 `n` 门课程。另给你一个数组 `relations`，其中 `relations[i] = [prevCoursei, nextCoursei]`，表示课程 `prevCoursei` 必须在课程 `nextCoursei` 之前修读完成（先修课程关系）。

在一个学期内，你可以学习**任意数量**的课程，前提是你已经学完了所有的先修课程。

请你返回学完全部课程所需的**最少**学期数。如果没有办法做到学完全部这些课程的话，就返回 `-1`。

**示例 1：**
```
输入：n = 3, relations = [[1,3],[2,3]]
输出：2
解释：上图展示了课程之间的关系图。
在第一个学期，你可以学习课程 1 和 2。
在第二个学期，你可以学习课程 3。
```

**示例 2：**
```
输入：n = 3, relations = [[1,2],[2,3],[3,1]]
输出：-1
解释：无法学完所有课程，因为存在循环依赖。
```

**提示：**
- `1 <= n <= 5000`
- `1 <= relations.length <= 5000`
- `relations[i].length == 2`
- `1 <= prevCoursei, nextCoursei <= n`
- `prevCoursei != nextCoursei`
- 所有的先修课程对 `[prevCoursei, nextCoursei]` 都是**互不相同**的

## 解题思路

这是一道经典的**拓扑排序**问题，需要找到**最长路径**（即最少学期数）。

### 核心思想

1. 构建**有向图**和**入度数组**
2. 使用 **BFS 拓扑排序**，同时记录层数（学期数）
3. 如果存在环（无法完成所有课程），返回 -1
4. 否则返回 BFS 的层数

### 拓扑排序 vs 最短路径

- 拓扑排序：处理有向无环图（DAG）的依赖关系
- 本题求最少学期数：等价于求图中的**最长路径**（层数）

## Python 代码实现

### 方法一：BFS 拓扑排序（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minimumSemesters(self, n: int, relations: List[List[int]]) -> int:
        # 构建图和入度数组
        graph = defaultdict(list)
        in_degree = [0] * (n + 1)  # 索引 1 到 n
        
        for prev, next in relations:
            graph[prev].append(next)
            in_degree[next] += 1
        
        # 初始化队列：所有入度为 0 的课程（没有先修课程）
        queue = deque()
        for course in range(1, n + 1):
            if in_degree[course] == 0:
                queue.append(course)
        
        # BFS 拓扑排序，记录学期数
        semesters = 0
        studied = 0  # 已学习的课程数
        
        while queue:
            # 当前学期可以学习的课程数量
            size = len(queue)
            semesters += 1
            
            for _ in range(size):
                course = queue.popleft()
                studied += 1
                
                # 更新后续课程的入度
                for next_course in graph[course]:
                    in_degree[next_course] -= 1
                    if in_degree[next_course] == 0:
                        queue.append(next_course)
        
        # 检查是否所有课程都学完了
        return semesters if studied == n else -1
```

### 方法二：DFS + 记忆化（求最长路径）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumSemesters(self, n: int, relations: List[List[int]]) -> int:
        # 构建图
        graph = defaultdict(list)
        for prev, next in relations:
            graph[prev].append(next)
        
        # memo[course] = 从该课程开始的最长路径长度
        memo = {}
        # 访问状态：0-未访问，1-访问中，2-已完成
        state = [0] * (n + 1)
        
        def dfs(course: int) -> int:
            """返回从 course 开始的最长路径，-1 表示有环"""
            if state[course] == 1:
                # 检测到环
                return -1
            if state[course] == 2:
                # 已计算过
                return memo[course]
            
            state[course] = 1  # 标记为访问中
            max_length = 0
            
            for next_course in graph[course]:
                length = dfs(next_course)
                if length == -1:
                    return -1  # 有环
                max_length = max(max_length, length)
            
            state[course] = 2  # 标记为已完成
            memo[course] = max_length + 1
            return memo[course]
        
        # 对每个课程进行 DFS
        result = 0
        for course in range(1, n + 1):
            depth = dfs(course)
            if depth == -1:
                return -1
            result = max(result, depth)
        
        return result
```

### 方法三：Kahn 算法（标准拓扑排序）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minimumSemesters(self, n: int, relations: List[List[int]]) -> int:
        # 构建邻接表和入度数组
        graph = [[] for _ in range(n + 1)]
        in_degree = [0] * (n + 1)
        
        for prev, next in relations:
            graph[prev].append(next)
            in_degree[next] += 1
        
        # BFS
        queue = deque([i for i in range(1, n + 1) if in_degree[i] == 0])
        semesters = 0
        count = 0
        
        while queue:
            semesters += 1
            for _ in range(len(queue)):
                course = queue.popleft()
                count += 1
                
                for neighbor in graph[course]:
                    in_degree[neighbor] -= 1
                    if in_degree[neighbor] == 0:
                        queue.append(neighbor)
        
        return semesters if count == n else -1
```

## 复杂度分析

- **时间复杂度**：O(n + E)，其中 E 是边数（先修关系数）
- **空间复杂度**：O(n + E)，存储图和队列

## 关键点总结

1. **拓扑排序应用**：检测有向图是否有环，求依赖关系的执行顺序
2. **BFS 层次遍历**：每一层代表一个学期，可以并行学习的课程
3. **入度数组**：记录每门课程的先修课程数量
4. **环检测**：如果拓扑排序无法遍历所有节点，说明有环
5. **最长路径**：BFS 的层数即为最少学期数

## 易错点

1. **索引问题**：课程编号从 1 开始，数组大小应为 n+1
2. **环的检测**：必须检查是否所有课程都被访问，未访问的说明有环
3. **队列大小**：每次处理一层时，需要记录当前队列大小，而不是逐个处理
4. **初始化**：所有入度为 0 的课程都应该加入初始队列
5. **返回值**：如果有环返回 -1，否则返回学期数

## 拓扑排序模板

```python
def topological_sort(n, edges):
    # 1. 构建图和入度数组
    graph = defaultdict(list)
    in_degree = [0] * n
    
    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1
    
    # 2. 初始化队列
    queue = deque([i for i in range(n) if in_degree[i] == 0])
    
    # 3. BFS
    result = []
    while queue:
        node = queue.popleft()
        result.append(node)
        
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    # 4. 检查是否有环
    return result if len(result) == n else None
```
