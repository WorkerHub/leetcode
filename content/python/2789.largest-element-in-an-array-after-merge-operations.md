## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。你可以进行以下操作 **任意次**：

选择满足 `nums[i] <= nums[i+1]` 的下标 `i`，将 `nums[i+1]` 替换为 `nums[i] + nums[i+1]`，并删除 `nums[i]`。

返回最终数组中可能存在的 **最大元素**。

**示例 1：**
```
输入：nums = [2,3,7,9,3]
输出：21
解释：合并 2+3=5，再 5+7=12，再 12+9=21，停止
```

**示例 2：**
```
输入：nums = [5,3,3]
输出：11
解释：合并后面的 3+3=6<=5 不成立，改为直接输出最大前缀和？
5: 不能和3合并(5>3), 3<=3可以合并成6，但6>5 ...
实际: nums[1]=3, nums[2]=3, 3<=3可合并: [5,6]，5<=6 可合并: [11]，最大11
```

**提示：**
- `1 <= nums.length <= 10^5`

## 解题思路

**从右向左贪心**：尽可能合并更多元素以得到最大值。

从右向左遍历，维护当前"可以被左侧合并的最大累积值"：
- 若 `nums[i] <= 当前累积值`：合并，累积值 += nums[i]
- 否则：更新答案，重置累积值为 nums[i]（从这里重新开始新段）

最终答案是过程中出现的最大累积值。

## Python 代码实现

### 方法一：从右向左贪心（推荐）

```python
from typing import List

class Solution:
    def maxArrayValue(self, nums: List[int]) -> int:
        n = len(nums)
        cur = nums[-1]  # 当前可累积的值
        ans = cur

        for i in range(n - 2, -1, -1):
            if nums[i] <= cur:
                cur += nums[i]  # 合并
            else:
                cur = nums[i]   # 重新开始
            ans = max(ans, cur)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 从右向左：右侧的大值为左侧的合并提供条件
2. 只要左侧元素 <= 当前累积值，就可以合并
3. 贪心：尽量往左合并，得到最大值

## 易错点

1. 方向很重要：从左向右无法正确模拟所有可能的合并
2. 重置条件：`nums[i] > cur` 时无法合并，从 nums[i] 重新开始
