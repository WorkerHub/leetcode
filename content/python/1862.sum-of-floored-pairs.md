## 题目描述

给你一个整数数组 `nums`，计算所有满足 `0 <= i, j < nums.length` 的 `floor(nums[i] / nums[j])` 之和，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：nums = [2,5,9]
输出：10
```

**示例 2：**
```
输入：nums = [7,7,7,7,7,7,7]
输出：49
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**前缀和 + 枚举除数**：

1. 用 `freq[v]` 统计每个值出现的次数，用 `prefix[v]` 统计 <= v 的元素数量
2. 对每个值 `d`（作为除数），枚举商 `q = 1, 2, 3, ...`：
   - 被除数范围 `[q*d, (q+1)*d - 1]` 内的元素，除以 d 商为 q
   - 该范围内的元素数量为 `prefix[min((q+1)*d-1, max_val)] - prefix[q*d-1]`
   - 贡献为 `freq[d] * q * count`（每个 d 都会被 count 个元素除）

总时间复杂度为 O(max_val * log(max_val))（调和级数）。

## 代码实现

### 方法一：前缀和 + 枚举（推荐）

```python
from typing import List

class Solution:
    def sumOfFlooredPairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        max_val = max(nums)

        # 统计频率
        freq = [0] * (max_val + 2)
        for x in nums:
            freq[x] += 1

        # 计算前缀和（prefix[i] = nums 中 <= i 的元素个数）
        prefix = [0] * (max_val + 2)
        for i in range(1, max_val + 1):
            prefix[i] = prefix[i - 1] + freq[i]

        result = 0
        for d in range(1, max_val + 1):
            if freq[d] == 0:
                continue
            # 枚举商 q
            q = 1
            while q * d <= max_val:
                lo = q * d
                hi = min((q + 1) * d - 1, max_val)
                # [lo, hi] 范围内的元素除以 d 商为 q
                count = prefix[hi] - prefix[lo - 1]
                result = (result + freq[d] * q * count) % MOD
                q += 1

        return result
```

### 方法二：直接枚举（暴力，仅供理解）

```python
from typing import List

class Solution:
    def sumOfFlooredPairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        result = 0
        for a in nums:
            for b in nums:
                result = (result + a // b) % MOD
        return result
        # O(n^2)，n=10^5 时 TLE
```

## 复杂度分析

- **方法一**：
  - 时间复杂度：O(max_val * log(max_val))，调和级数
  - 空间复杂度：O(max_val)

## 关键点总结

1. 不枚举数对，而是枚举"除数 d + 商 q"的组合
2. 商为 q 时被除数在 `[q*d, (q+1)*d-1]` 范围内，用前缀和快速统计
3. 每种 d 的枚举次数为 `max_val/d`，总计调和级数 O(max_val * log(max_val))

## 易错点

- 前缀和需要特别处理 `prefix[lo-1]`，当 lo=1 时 lo-1=0，需要 prefix[0]=0
- 结果取模要在每次循环内进行，防止溢出
