## 题目描述

给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

**示例 1：**
```
输入：strs = ["eat","tea","tan","ate","nat","bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2：**
```
输入：strs = [""]
输出：[[""]]
```

**示例 3：**
```
输入：strs = ["a"]
输出：[["a"]]
```

**提示：**
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 解题思路

核心思想：使用哈希表分组

**分组键的选择：**
1. 排序后的字符串
2. 字符计数（26个字母）

## Python 代码实现

### 方法一：排序（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = defaultdict(list)
        
        for s in strs:
            # 排序后的字符串作为key
            key = ''.join(sorted(s))
            anagrams[key].append(s)
        
        return list(anagrams.values())
```

### 方法二：字符计数

```python
from typing import List
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = defaultdict(list)
        
        for s in strs:
            # 统计每个字符的出现次数
            count = [0] * 26
            for c in s:
                count[ord(c) - ord('a')] += 1
            # 元组可以作为字典的key
            key = tuple(count)
            anagrams[key].append(s)
        
        return list(anagrams.values())
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n × k log k)，n为字符串数量，k为字符串平均长度
- 空间复杂度：O(n × k)

**方法二：**
- 时间复杂度：O(n × k)
- 空间复杂度：O(n × k)

## 关键点总结

1. **哈希分组**：相同特征的字符串分到一组
2. **排序作为key**：简单直接
3. **计数作为key**：时间复杂度更优

## 易错点

1. **字典初始化**：使用 defaultdict(list)
2. **返回格式**：返回 values() 的列表
