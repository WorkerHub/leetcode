## 题目描述

给你二叉树的根节点 `root`，返回它节点值的**前序**遍历。

**示例 1：**
```
输入：root = [1,null,2,3]
输出：[1,2,3]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [1]
输出：[1]
```

**提示：**
- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

## 解题思路

前序遍历（Pre-order Traversal）是二叉树遍历的三种基本方式之一。

**遍历顺序：根 → 左 → 右**

### 三种遍历方式对比：

- **前序遍历**：根 → 左 → 右（本题）
- **中序遍历**：左 → 根 → 右（LeetCode 94）
- **后序遍历**：左 → 右 → 根（LeetCode 145）

### 解法思路：

**方法一：递归**
- 最直观的方法
- 访问根节点 → 递归遍历左子树 → 递归遍历右子树

**方法二：迭代（栈）**
- 使用栈模拟递归过程
- 先压入右子节点，再压入左子节点（保证左子树先被访问）

**方法三：Morris 遍历**
- 不使用额外空间（除了返回数组）
- 通过修改树的结构（建立线索二叉树），遍历后恢复

## Python 代码实现

### 方法一：递归（推荐，最简洁）

```python
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        
        def preorder(node):
            if not node:
                return
            # 前序：根 → 左 → 右
            result.append(node.val)  # 访问根节点
            preorder(node.left)       # 遍历左子树
            preorder(node.right)      # 遍历右子树
        
        preorder(root)
        return result
```

### 方法二：迭代（栈）

```python
from typing import List, Optional

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        result = []
        stack = [root]
        
        while stack:
            # 弹出栈顶节点
            node = stack.pop()
            result.append(node.val)  # 访问节点
            
            # 先压入右子节点，再压入左子节点
            # 这样弹出时左子节点在栈顶，先被访问
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        
        return result
```

### 方法三：迭代（统一风格的栈）

```python
from typing import List, Optional

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        result = []
        stack = [(root, False)]  # (节点, 是否已访问)
        
        while stack:
            node, visited = stack.pop()
            
            if visited:
                # 节点已访问，直接加入结果
                result.append(node.val)
            else:
                # 节点未访问，按照 右 → 左 → 根 的顺序压栈
                # 这样弹出顺序就是 根 → 左 → 右
                if node.right:
                    stack.append((node.right, False))
                if node.left:
                    stack.append((node.left, False))
                stack.append((node, True))  # 标记为已访问
        
        return result
```

### 方法四：Morris 遍历（O(1) 空间）

```python
from typing import List, Optional

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        curr = root
        
        while curr:
            if not curr.left:
                # 没有左子树，访问当前节点，然后移到右子树
                result.append(curr.val)
                curr = curr.right
            else:
                # 找到左子树的最右节点（前驱节点）
                predecessor = curr.left
                while predecessor.right and predecessor.right != curr:
                    predecessor = predecessor.right
                
                if not predecessor.right:
                    # 建立线索
                    result.append(curr.val)  # 前序遍历在这里访问
                    predecessor.right = curr
                    curr = curr.left
                else:
                    # 已经访问过，断开线索
                    predecessor.right = None
                    curr = curr.right
        
        return result
```

### 方法五：一行代码（Python 特色）

```python
from typing import List, Optional

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        return [] if not root else [root.val] + self.preorderTraversal(root.left) + self.preorderTraversal(root.right)
```

## 复杂度分析

### 方法一：递归
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(n)，最坏情况下递归栈深度为 n（链式树）

### 方法二、三：迭代（栈）
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(n)，栈的最大深度

### 方法四：Morris 遍历
- **时间复杂度**：O(n)，每条边最多访问 2 次
- **空间复杂度**：O(1)，不使用额外空间（除了返回数组）

## 关键点总结

1. **遍历顺序**：前序遍历是"根 → 左 → 右"
2. **递归vs迭代**：递归简洁，迭代空间可控
3. **栈的使用**：迭代法中，先压右子节点再压左子节点（栈是后进先出）
4. **Morris遍历**：通过建立线索二叉树实现 O(1) 空间
5. **三种遍历的关系**：只需改变访问根节点的时机，就能实现三种遍历

## 易错点

1. **栈的压入顺序**：要先压右子节点再压左子节点，确保左子树先被访问
2. **空节点判断**：递归和迭代都要先判断节点是否为空
3. **递归栈溢出**：对于极深的树，递归可能栈溢出，迭代更安全
4. **三种遍历混淆**：
   - 前序：根 → 左 → 右
   - 中序：左 → 根 → 右
   - 后序：左 → 右 → 根
5. **Morris遍历的恢复**：要记得断开建立的线索，恢复树的结构
