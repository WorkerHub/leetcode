## 题目描述

给定无向图，边 edges[i] = [ui, vi, cnti] 表示在 ui 和 vi 之间有一条边，被细分为 cnti + 1 个新节点。

从节点 0 开始，最多移动 maxMoves 步，返回可以到达的节点数。

**提示：**
- 0 <= edges.length <= min(n * (n - 1) / 2, 10^4)
- edges[i].length == 3
- 0 <= ui < vi < n
- 没有重复边
- 0 <= cnti <= 10^4
- 0 <= maxMoves <= 10^9
- 1 <= n <= 3000

## 解题思路

**Dijkstra 最短路：**
1. 用 Dijkstra 计算从节点 0 到所有节点的最短距离
2. 统计能到达的原始节点
3. 统计能到达的细分节点（边上的新节点）

## Python 代码实现

```python
class Solution:
    def reachableNodes(self, edges: List[List[int]], maxMoves: int, n: int) -> int:
        import heapq
        from collections import defaultdict
        
        # 构建图
        graph = defaultdict(dict)
        for u, v, cnt in edges:
            graph[u][v] = cnt
            graph[v][u] = cnt
        
        # Dijkstra
        dist = {0: 0}
        heap = [(0, 0)]  # (距离, 节点)
        result = 0
        used_edges = {}
        
        while heap:
            d, node = heapq.heappop(heap)
            
            if d > dist.get(node, float('inf')):
                continue
            
            result += 1  # 原始节点
            
            for nei, cnt in graph[node].items():
                # 从 node 到 nei 边上能到达的新节点数
                available = maxMoves - d
                used = min(available, cnt)
                used_edges[(node, nei)] = used
                
                # 如果能到达 nei
                new_dist = d + cnt + 1
                if new_dist <= maxMoves and new_dist < dist.get(nei, float('inf')):
                    dist[nei] = new_dist
                    heapq.heappush(heap, (new_dist, nei))
        
        # 统计边上的新节点
        for u, v, cnt in edges:
            result += min(cnt, used_edges.get((u, v), 0) + used_edges.get((v, u), 0))
        
        return result
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)，Dijkstra
- **空间复杂度**：O(V + E)

## 关键点总结

1. **Dijkstra**：计算最短距离
2. **边上节点**：细分节点的处理
3. **双向统计**：边是无向的
