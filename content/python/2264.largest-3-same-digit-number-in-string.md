## 题目描述

给你一个字符串 `num`，表示一个大整数。

返回 `num` 中最大的 **3 位相同数字** 的子字符串（即由 3 个相同数字组成的子串），若不存在则返回空字符串 `""`。

**示例 1：**
```
输入：num = "6777133339"
输出："777"
```

**示例 2：**
```
输入：num = "2300019"
输出："000"
```

**示例 3：**
```
输入：num = "42352338"
输出：""
```

## 解题思路

遍历字符串，检查相邻 3 个字符是否相同，若相同则更新最大值。最终返回最大的三个相同数字的子串。

## 代码实现

### 方法一：遍历检查（推荐）

```python
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        ans = ""
        for i in range(len(num) - 2):
            # 检查 num[i], num[i+1], num[i+2] 是否相同
            if num[i] == num[i + 1] == num[i + 2]:
                sub = num[i:i + 3]
                if sub > ans:  # 字典序更大即数值更大
                    ans = sub
        return ans
```

### 方法二：枚举 0-9

```python
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        # 从大到小检查每个数字
        for d in "9876543210":
            if d * 3 in num:
                return d * 3
        return ""
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)。

**方法二：**
- 时间复杂度：O(10n) = O(n)，对每个数字检查是否在字符串中。
- 空间复杂度：O(1)。

## 关键点总结

1. 三位相同数字的子串只有 "000" 到 "999" 共 10 种。
2. 方法二直接从 9 到 0 枚举，返回第一个找到的（最大的）。
3. 字符串比较 `"777" > "555"` 等价于数值比较（因为长度相同）。

## 易错点

- 注意返回的是字符串，不是整数。
- "000" 是合法答案，不能忽略。
