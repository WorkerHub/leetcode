## 题目描述

给你一个整数数组 `arr` 和两个整数 `k` 和 `threshold`。

请你返回长度为 `k` 且平均值大于等于 `threshold` 的**子数组数目**。

**示例 1：**
```
输入：arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4
输出：3
解释：子数组 [2,5,5], [5,5,5] 和 [5,5,8] 的平均值分别为 4, 5 和 6。其他长度为 3 的子数组的平均值都不大于 4。
     所以返回 3。
```

**示例 2：**
```
输入：arr = [11,13,17,23,29,31,7,5,2,3], k = 3, threshold = 5
输出：6
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^4`
- `1 <= k <= arr.length`
- `0 <= threshold <= 10^4`

## 解题思路

**滑动窗口：**

固定长度为 k 的窗口从左向右滑动，维护窗口内元素的和。

- 平均值 >= threshold 等价于 窗口和 >= threshold * k（避免浮点运算）
- 每次窗口右移一位：加入右端新元素，减去左端旧元素

**时间复杂度：** O(n)，每个元素只被加入和移出窗口各一次。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int], k: int, threshold: int) -> int:
        n = len(arr)
        target = threshold * k  # 等价转换：避免除法（浮点数精度问题）
        
        # 初始化第一个窗口
        window_sum = sum(arr[:k])
        count = 1 if window_sum >= target else 0
        
        # 滑动窗口：从第 2 个窗口开始
        for i in range(k, n):
            window_sum += arr[i]       # 加入右端新元素
            window_sum -= arr[i - k]   # 移出左端旧元素
            if window_sum >= target:
                count += 1
        
        return count
```

### 方法二：滑动窗口（双指针写法）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int], k: int, threshold: int) -> int:
        n = len(arr)
        target = threshold * k
        count = 0
        window_sum = 0
        
        for right in range(n):
            window_sum += arr[right]
            
            # 窗口大小达到 k 时开始检查
            if right >= k - 1:
                if window_sum >= target:
                    count += 1
                # 移出窗口最左端的元素（left = right - k + 1）
                window_sum -= arr[right - k + 1]
        
        return count
```

### 方法三：前缀和

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int], k: int, threshold: int) -> int:
        n = len(arr)
        # 构建前缀和数组
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + arr[i]
        
        target = threshold * k
        count = 0
        
        # 枚举所有长度为 k 的子数组 [i, i+k-1]
        for i in range(n - k + 1):
            sub_sum = prefix[i + k] - prefix[i]
            if sub_sum >= target:
                count += 1
        
        return count
```

### 方法四：暴力枚举（便于理解）

```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int], k: int, threshold: int) -> int:
        n = len(arr)
        count = 0
        
        # 枚举所有长度为 k 的子数组
        for i in range(n - k + 1):
            sub_avg = sum(arr[i:i + k]) / k
            if sub_avg >= threshold:
                count += 1
        
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/二（滑动窗口） | O(n) | O(1) |
| 方法三（前缀和） | O(n) | O(n) |
| 方法四（暴力） | O(n * k) | O(1) |

## 图解示例

以 `arr = [2,2,2,2,5,5,5,8], k=3, threshold=4, target=12` 为例：

```
窗口滑动过程：
[2,2,2] -> sum=6  < 12，不计
  [2,2,5] -> sum=9  < 12，不计
    [2,5,5] -> sum=12 >= 12，计数! (+1)
      [5,5,5] -> sum=15 >= 12，计数! (+2)
        [5,5,8] -> sum=18 >= 12，计数! (+3)

结果: 3
```

## 关键点总结

1. 平均值 >= threshold 等价于 窗口和 >= threshold * k，避免浮点数运算
2. 滑动窗口维护固定大小 k 的窗口，每次移动只做一次加法和一次减法
3. 窗口和从第一个窗口开始初始化，后续滑动更新

## 易错点

1. 避免用 `sum(arr[i:i+k]) / k >= threshold`（浮点数精度问题）
2. 初始化第一个窗口时，`arr[:k]` 是前 k 个元素
3. 循环从 `k` 开始（第 k+1 个元素开始，窗口右移一位），到 `n-1`

## 学习建议

1. 固定长度滑动窗口是最基础的滑动窗口类型，先掌握这个再学可变长度
2. 核心操作：加入右端 + 移出左端，O(1) 更新窗口和
3. 用乘法转换代替除法，是处理"平均值"问题的常用技巧
4. 与前缀和方法相比，滑动窗口空间复杂度更优（O(1) vs O(n)）
