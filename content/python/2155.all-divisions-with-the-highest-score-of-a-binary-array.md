## 题目描述

给你一个下标从 **0** 开始的二进制数组 `nums`，数组长度为 `n`。

`nums` 可以按下标 `i`（`0 <= i <= n`）分为两部分：
- 左侧：`nums[0..i-1]`（空数组当 i=0）
- 右侧：`nums[i..n-1]`（空数组当 i=n）

**分割得分** = 左侧 0 的个数 + 右侧 1 的个数。

返回**分割得分最高**的所有下标，可以按任意顺序返回。

**示例：**
```
输入：nums = [0,0,1,0]
输出：[2,4]
解释：
- i=0：0 + (1) = 1
- i=1：1 + (1) = 2
- i=2：2 + (1) = 3（最高）
- i=3：2 + (0) = 2（等等，i=4时右侧为空）
- i=4：3 + 0 = 3（最高）
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `nums[i]` 为 0 或 1

## 解题思路

**前缀和**

预计算：左侧 0 的个数可以用前缀 0 计数，右侧 1 的个数可以用后缀 1 计数。

或者：
- 初始：`left_zeros = 0`，`right_ones = sum(nums)`（全部 1 的个数）。
- 遍历分割点 i（从 0 到 n）：
  - 在 i 处的得分 = `left_zeros + right_ones`。
  - 移动：若 `nums[i] == 0`，`left_zeros += 1`；若 `nums[i] == 1`，`right_ones -= 1`。

## 代码实现

### 方法一：前缀和遍历（推荐）

```python
from typing import List

class Solution:
    def maxScoreIndices(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 初始：左侧 0 个数 = 0，右侧 1 个数 = sum(nums)
        left_zeros = 0
        right_ones = sum(nums)
        max_score = -1
        result = []

        for i in range(n + 1):
            score = left_zeros + right_ones
            if score > max_score:
                max_score = score
                result = [i]
            elif score == max_score:
                result.append(i)
            # 更新：nums[i] 从右侧移到左侧
            if i < n:
                if nums[i] == 0:
                    left_zeros += 1
                else:
                    right_ones -= 1

        return result
```

### 方法二：两遍扫描

```python
from typing import List

class Solution:
    def maxScoreIndices(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # 计算所有分割点的得分
        scores = []
        left_zeros = 0
        right_ones = sum(nums)
        for i in range(n + 1):
            scores.append(left_zeros + right_ones)
            if i < n:
                if nums[i] == 0:
                    left_zeros += 1
                else:
                    right_ones -= 1
        max_score = max(scores)
        return [i for i, s in enumerate(scores) if s == max_score]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(1)（不含结果） |

## 关键点总结

1. 遍历 n+1 个分割点（0 到 n），动态维护左侧 0 数和右侧 1 数。
2. 每次分割点移动时更新计数：nums[i] 从右侧划分到左侧。
3. 记录最大分数和所有达到最大分数的下标。

## 易错点

- 分割点 i 可以是 0（左侧为空）也可以是 n（右侧为空）。
- 更新时机：先计算当前 i 的得分，再根据 `nums[i]` 更新计数。
