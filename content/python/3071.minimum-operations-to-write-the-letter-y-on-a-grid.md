## 题目描述

给你一个 `n x n` 的整数矩阵 `grid`，n 为奇数，元素值为 0、1 或 2。

"Y 形"定义：
- 上半部分对角线：从 `(0,0)` 到 `(n/2, n/2)` 和从 `(0, n-1)` 到 `(n/2, n/2)`
- 竖线：从 `(n/2, n/2)` 到 `(n-1, n/2)`

一次操作可以将任意单元格的值改为 0、1 或 2 中的任意一个。

返回使 Y 形上的所有单元格值相同、Y 形外所有单元格值与 Y 形不同（但外部之间可以不同）的最少操作次数。

**提示：**
- `3 <= n <= 49`
- `n` 为奇数
- `0 <= grid[i][j] <= 2`

## 解题思路

1. 确定 Y 形包含的单元格（上半两条对角线 + 下半竖线）
2. 枚举 Y 形目标值（0, 1, 2），对于每个目标值：
   - 统计 Y 形内需要修改的单元格数（不等于目标值的）
   - 统计 Y 形外需要修改的单元格数（等于目标值的）
3. 取总操作次数最小的方案

## Python 代码实现

### 方法一：枚举目标值（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperationsToWriteY(self, grid: List[List[int]]) -> int:
        n = len(grid)
        mid = n // 2

        # 确定 Y 形单元格
        y_cells = set()

        # 上半两条对角线
        for i in range(mid + 1):
            y_cells.add((i, i))          # 左对角线
            y_cells.add((i, n - 1 - i))  # 右对角线

        # 下半竖线（从中心到底部）
        for i in range(mid, n):
            y_cells.add((i, mid))

        # 统计 Y 形内和 Y 形外的值频率
        y_count = Counter()
        non_y_count = Counter()

        for i in range(n):
            for j in range(n):
                if (i, j) in y_cells:
                    y_count[grid[i][j]] += 1
                else:
                    non_y_count[grid[i][j]] += 1

        y_total = sum(y_count.values())
        non_y_total = sum(non_y_count.values())

        # 枚举 Y 形目标值
        ans = float('inf')
        for target in range(3):
            # Y 形内修改次数：不等于 target 的单元格数
            y_ops = y_total - y_count[target]
            # Y 形外修改次数：等于 target 的单元格数（需要改为其他值）
            # 但题目说外部与内部不同即可，不要求外部互相相同
            # 所以 Y 形外只需修改那些值 == target 的单元格（改为任意其他值）
            non_y_ops = non_y_count[target]
            ans = min(ans, y_ops + non_y_ops)

        return ans
```

### 方法二：简化实现

```python
from typing import List
from collections import Counter

class Solution:
    def minimumOperationsToWriteY(self, grid: List[List[int]]) -> int:
        n = len(grid)
        mid = n // 2

        def is_y(i, j):
            # 判断 (i, j) 是否在 Y 形上
            # 上半左对角线
            if i <= mid and j == i:
                return True
            # 上半右对角线
            if i <= mid and j == n - 1 - i:
                return True
            # 下半竖线
            if i >= mid and j == mid:
                return True
            return False

        y_cnt = Counter(grid[i][j] for i in range(n) for j in range(n) if is_y(i, j))
        non_y_cnt = Counter(grid[i][j] for i in range(n) for j in range(n) if not is_y(i, j))

        y_total = sum(y_cnt.values())
        ans = float('inf')
        for v in range(3):
            ops = (y_total - y_cnt[v]) + non_y_cnt[v]
            ans = min(ans, ops)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵
- 空间复杂度：O(n^2) 或 O(1)（Counter 最多 3 个键）

## 关键点总结

1. Y 形 = 上半两条对角线 + 下半竖线（注意中心点在两条对角线的交叉点）
2. 枚举 Y 形目标值（0, 1, 2），计算总操作数
3. Y 形内操作数 + Y 形外操作数（只需将 Y 形外与 target 相同的改掉）

## 易错点

1. 中心点 `(mid, mid)` 在三条路径上，只计算一次
2. 上半对角线：i 从 0 到 mid（包含 mid）
3. 下半竖线：i 从 mid 到 n-1（包含 mid），避免重复
