## 题目描述

给你一个二维整数数组 `nums`，其中 `nums[i]` 是一个非空正整数数组，且每个 `nums[i]` 中的元素**互不相同**。

返回一个数组，其中包含**在 `nums` 的所有数组中都出现的整数**，按**升序**排列。

**示例 1：**
```
输入：nums = [[3,1,2,4,5],[1,2,3,4],[3,4,5,6]]
输出：[3,4]
```

**示例 2：**
```
输入：nums = [[1,2,3],[4,5,6]]
输出：[]
```

## 解题思路

统计每个整数出现在多少个子数组中，若等于 `len(nums)`，则该整数在所有子数组中都出现。

## 代码实现

### 方法一：计数器（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def intersection(self, nums: List[List[int]]) -> List[int]:
        n = len(nums)
        # 统计每个元素出现在几个子数组中
        count = Counter()
        for arr in nums:
            for x in arr:
                count[x] += 1

        # 出现在所有子数组中的元素，升序排列
        return sorted(k for k, v in count.items() if v == n)
```

### 方法二：集合交集

```python
from typing import List

class Solution:
    def intersection(self, nums: List[List[int]]) -> List[int]:
        # 转为集合，逐步取交集
        result = set(nums[0])
        for arr in nums[1:]:
            result &= set(arr)
        return sorted(result)
```

### 方法三：Python reduce

```python
from typing import List
from functools import reduce

class Solution:
    def intersection(self, nums: List[List[int]]) -> List[int]:
        return sorted(reduce(lambda a, b: set(a) & set(b), nums))
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(sum_of_lengths + k log k)，k 为不同元素数量。
- 空间复杂度：O(unique_elements)。

**方法二：**
- 时间复杂度：O(sum_of_lengths + k log k)。
- 空间复杂度：O(max_array_size)，集合大小。

## 关键点总结

1. 计数法：统计每个元素出现的子数组数，等于总数组数即为公共元素。
2. 集合交集法：Python 的 `&` 运算符直接求两集合交集。
3. 结果需要升序排列。

## 易错点

- 方法一中每个 `nums[i]` 内元素互不相同，不需要去重。
- 最终结果要排序（升序）。
