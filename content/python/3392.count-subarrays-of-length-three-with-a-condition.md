## 题目描述

给你一个整数数组 `nums`，返回长度为 3 且满足以下条件的子数组数量：

子数组 `[a, b, c]` 满足：`a + c == b / 2`（即首尾元素之和等于中间元素的一半）。

换句话说：`2 * (a + c) == b`。

**示例：**
```
输入：nums = [1,2,1,4,1]
输出：1
解释：子数组 [1,2,1] 满足 1+1 = 2/2 = 1，即 2*(1+1) = 4 不等于 2...
     实际上检查 a + c = b/2，即 1 + 1 = 2/2 = 1，成立。
```

**提示：**
- `3 <= nums.length <= 100`
- `-100 <= nums[i] <= 100`

## 解题思路

直接遍历所有长度为 3 的子数组，逐一检验条件即可。

注意：条件 `a + c == b / 2` 等价于 `2 * (a + c) == b`（避免浮点数问题）。

## Python 代码实现

### 方法一：直接遍历（推荐）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        count = 0
        n = len(nums)
        
        for i in range(n - 2):
            a, b, c = nums[i], nums[i + 1], nums[i + 2]
            # 条件：a + c = b / 2，等价于 2*(a+c) = b（避免浮点）
            if 2 * (a + c) == b:
                count += 1
        
        return count
```

### 方法二：列表推导式（简洁版）

```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        return sum(
            2 * (nums[i] + nums[i + 2]) == nums[i + 1]
            for i in range(len(nums) - 2)
        )
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 只需枚举所有长度为 3 的子数组（共 n-2 个）。
2. 条件 `a + c == b / 2` 用整数等价式 `2*(a+c) == b` 避免浮点误差。
3. 代码极其简洁，直接遍历即可。

## 易错点

1. 避免使用 `b / 2`（浮点除法），应用 `2 * (a + c) == b`。
2. 数组长度至少为 3，边界条件：`range(n - 2)`（不是 `range(n - 3)`）。
