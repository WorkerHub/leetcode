## 题目描述

设计一个数据结构，支持对整数数组 `arr` 的**范围频率查询**：

给定查询 `(left, right, value)`，返回 `arr[left..right]` 中 `value` 出现的次数。

**示例：**
```
输入：
arr = [12,33,4,56,22,2,34,33,22,12,34,56]
queries = [[1,2,4],[0,4,5],[1,9,33],[1,9,33]]
输出：[1, 0, 2, 2]
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i], value <= 10^4`
- `0 <= left <= right < arr.length`
- 最多 `10^5` 次查询

## 解题思路

**预处理 + 二分查找：**

用哈希表记录每个值在数组中出现的所有**索引位置**（有序列表）。

查询时，对该值的索引列表，用二分查找找到 `[left, right]` 范围内的索引数量。

**具体步骤：**
1. 构建 `pos[value] = [index1, index2, ...]`（有序）
2. 查询 `(left, right, value)` 时：
   - 在 `pos[value]` 中找 `>= left` 的第一个位置（`bisect_left`）
   - 在 `pos[value]` 中找 `> right` 的第一个位置（`bisect_right`）
   - 二者之差即为频率

## 代码实现

### 方法一：哈希表 + 二分查找（推荐）

```python
from typing import List
from collections import defaultdict
import bisect

class RangeFreqQuery:

    def __init__(self, arr: List[int]):
        # 记录每个值出现的索引列表
        self.pos = defaultdict(list)
        for i, v in enumerate(arr):
            self.pos[v].append(i)

    def query(self, left: int, right: int, value: int) -> int:
        if value not in self.pos:
            return 0
        indices = self.pos[value]
        # 找 >= left 的第一个索引
        lo = bisect.bisect_left(indices, left)
        # 找 > right 的第一个索引
        hi = bisect.bisect_right(indices, right)
        return hi - lo
```

### 方法二：前缀频率数组（适合值域较小时）

```python
from typing import List
from collections import defaultdict

class RangeFreqQuery:

    def __init__(self, arr: List[int]):
        n = len(arr)
        # prefix[v][i] 表示 arr[0..i-1] 中 v 出现的次数
        self.prefix = defaultdict(lambda: [0])
        for v in arr:
            # 只扩展出现过的值的前缀数组
            pass
        # 改用哈希表前缀和
        self.cnt = defaultdict(list)  # cnt[v][i] = arr[0..i-1] 中 v 的出现次数
        freq = defaultdict(int)
        for i, v in enumerate(arr):
            freq[v] += 1
            self.cnt[v].append((i, freq[v]))

    def query(self, left: int, right: int, value: int) -> int:
        import bisect
        if value not in self.cnt:
            return 0
        entries = self.cnt[value]
        # 找 index <= right 的最大计数
        hi_idx = bisect.bisect_right(entries, (right, float('inf'))) - 1
        if hi_idx < 0:
            return 0
        count_right = entries[hi_idx][1]
        # 找 index < left 的最大计数
        lo_idx = bisect.bisect_left(entries, (left, -1)) - 1
        count_left = entries[lo_idx][1] if lo_idx >= 0 else 0
        return count_right - count_left
```

## 关键点总结

1. 预处理：用哈希表存储每个值的索引列表（有序）
2. 查询：二分查找确定 `[left, right]` 范围内的索引数量
3. `bisect_left(indices, left)` 找第一个 `>= left` 的位置
4. `bisect_right(indices, right)` 找第一个 `> right` 的位置

## 易错点

- `bisect_left` vs `bisect_right`：前者找左边界（`>= left`），后者找右边界（`> right`）
- 查询值不存在时直接返回 0
- 索引列表天然有序（按插入顺序），不需要额外排序
