## 题目描述

给你一个下标从 **0** 开始、长度为 `n` 的排列 `nums`。

一个排列的 **半有序** 状态是指 `1` 在排列的开头，`n` 在排列的末尾。每步操作可以交换任意两个 **相邻** 元素。

返回使排列变为半有序所需的 **最少操作次数**。

**示例 1：**
```
输入：nums = [2,1,4,3]
输出：2
解释：[2,1,4,3] -> [1,2,4,3] -> [1,2,3,4]（交换 1 到开头，4 到末尾各 1 次）
Wait: [2,1,4,3]: 1 在位置1，n=4在位置2。
1 移到位置0需要 1 次；4 移到位置3需要 1 次。总共 2 次。
```

**示例 2：**
```
输入：nums = [2,4,1,3]
输出：4
```

**提示：**
- `2 <= n <= 50`
- `1 <= nums[i] <= n`
- `nums` 是一个排列

## 解题思路

分别计算：
- 将 `1` 移到开头（位置 0）的操作次数 = `pos_1`（1 的当前下标）
- 将 `n` 移到末尾（位置 n-1）的操作次数 = `n - 1 - pos_n`

特殊情况：如果 `1` 在 `n` 的右边（`pos_1 > pos_n`），将 `1` 向左移动时会经过 `n` 的位置，此时 `n` 也会相应右移 1，所以总次数需 -1。

## Python 代码实现

### 方法一：直接计算（推荐）

```python
from typing import List

class Solution:
    def semiOrderedPermutation(self, nums: List[int]) -> int:
        n = len(nums)
        pos_1 = nums.index(1)    # 1 的位置
        pos_n = nums.index(n)    # n 的位置

        # 1 移到开头需要 pos_1 次；n 移到末尾需要 n-1-pos_n 次
        steps = pos_1 + (n - 1 - pos_n)

        # 如果 1 在 n 的右边，移动 1 时会推着 n 往右，少一次操作
        if pos_1 > pos_n:
            steps -= 1

        return steps
```

### 方法二：模拟（暴力，适合理解）

```python
from typing import List

class Solution:
    def semiOrderedPermutation(self, nums: List[int]) -> int:
        nums = list(nums)
        n = len(nums)
        ops = 0
        # 将 1 移到开头
        i = nums.index(1)
        while i > 0:
            nums[i], nums[i-1] = nums[i-1], nums[i]
            i -= 1
            ops += 1
        # 将 n 移到末尾
        j = nums.index(n)
        while j < n - 1:
            nums[j], nums[j+1] = nums[j+1], nums[j]
            j += 1
            ops += 1
        return ops
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n)，空间复杂度 O(n)

## 关键点总结

1. 相邻交换的操作次数等于元素移动的距离
2. 当 `1` 在 `n` 右边时，两者的移动路径有重叠，总次数少 1

## 易错点

1. 需要判断 `1` 和 `n` 的相对位置，位置重叠时减 1
2. `nums.index()` 返回第一次出现的下标
