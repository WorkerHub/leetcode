## 题目描述

给你一个整数数组 `nums`，返回可以构成三角形的三元组 `(i, j, k)` 的数量（`i < j < k`）。

三角形条件：任意两边之和大于第三边。排序后只需验证两小边之和大于最大边。

**示例 1：**

```
输入：nums = [2,2,3,4]
输出：3
解释：(2,3,4),(2,3,4),(2,2,3)
```

**示例 2：**

```
输入：nums = [4,2,3,4]
输出：4
```

**提示：**

- `2 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`

## 解题思路

**排序 + 二分查找**：

排序后，对每对 `(i, j)`（`i < j`），最大边为 `nums[j]`，需要 `nums[i] + nums[j] > nums[k]`，但 `k > j`，所以 `nums[k] >= nums[j]`。

更优策略：固定最大边 `nums[k]`，找所有满足 `nums[i] + nums[j] > nums[k]` 的对 `(i, j)`（`i < j < k`）。

对每个 `k`，用双指针在 `[0, k-1]` 中统计满足 `nums[i] + nums[j] > nums[k]` 的对数。

## Python 代码实现

### 方法一：排序 + 双指针（推荐）

```python
from typing import List

class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        count = 0

        for k in range(2, n):
            left, right = 0, k - 1
            while left < right:
                if nums[left] + nums[right] > nums[k]:
                    # [left, right-1] 都和 right 满足条件
                    count += right - left
                    right -= 1
                else:
                    left += 1

        return count
```

### 方法二：排序 + 二分查找

```python
from typing import List
import bisect

class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        count = 0

        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                # 找最大的 k 使得 nums[k] < nums[i] + nums[j]
                target = nums[i] + nums[j]
                k = bisect.bisect_left(nums, target, j + 1, n) - 1
                count += k - j

        return count
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一），O(n^2 log n)（方法二）
- 空间复杂度：O(1)

## 关键点总结

1. 排序后只需验证两小边之和 > 最大边
2. 固定最大边，双指针找满足条件的两小边对
3. 双指针：若 `a[l] + a[r] > target`，则 `a[l..r-1] + a[r]` 都满足

## 易错点

1. 排序是必要的，使得 `a[k] >= a[j] >= a[i]`
2. 双指针缩小右边界：满足条件时 `count += right - left`
3. 元素为 0 时不构成三角形
