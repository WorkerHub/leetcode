## 题目描述

给你一棵二叉树的根节点 `root` ，返回所有**重复的子树**。

对于同一类的重复子树，你只需要返回其中任意**一棵**的根结点即可。

如果两棵树具有**相同的结构**和**相同的结点值**，则认为二者是重复的。

**示例 1:**

```
        1
       / \
      2   3
     /   / \
    4   2   4
       /
      4

输入：root = [1,2,3,4,null,2,4,null,null,4]
输出：[[2,4],[4]]
```

**示例 2:**

```
        2
       / \
      1   1

输入：root = [2,1,1]
输出：[[1]]
```

**示例 3:**

```
        2
       / \
      2   2
     /   /
    3   3

输入：root = [2,2,2,3,null,3,null]
输出：[[2,3],[3]]
```

**提示:**
- 树中的结点数在 `[1, 5000]` 范围内
- `-200 <= Node.val <= 200`

## 解题思路

这道题的核心是如何**识别重复的子树**。需要解决两个关键问题：

1. **如何表示一棵树**？使用序列化方法将树转换为字符串
2. **如何检测重复**？使用哈希表记录每种子树出现的次数

**算法流程：**

1. **后序遍历**：从叶子节点开始向上构建
2. **序列化子树**：将每个子树序列化为唯一的字符串表示
3. **哈希计数**：用哈希表记录每种子树出现的次数
4. **收集结果**：当某种子树第二次出现时，将其根节点加入结果

**序列化方案：**
- 使用后序遍历：`左子树序列化 + 右子树序列化 + 当前节点值`
- 空节点用特殊符号（如 `#`）表示
- 使用分隔符（如 `,`）分隔节点

## Python 代码实现

### 方法一：后序遍历 + 序列化（推荐）⭐

```python
from typing import List, Optional
from collections import defaultdict

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findDuplicateSubtrees(self, root: Optional[TreeNode]) -> List[Optional[TreeNode]]:
        """
        使用后序遍历 + 序列化来识别重复子树
        """
        # 哈希表：序列化字符串 -> 出现次数
        subtree_count = defaultdict(int)
        # 存储结果
        result = []
        
        def serialize(node: Optional[TreeNode]) -> str:
            """
            后序遍历序列化子树
            返回当前子树的序列化字符串
            """
            if not node:
                return "#"
            
            # 后序遍历：左 -> 右 -> 根
            left_serial = serialize(node.left)
            right_serial = serialize(node.right)
            
            # 构建当前子树的序列化字符串
            current_serial = f"{left_serial},{right_serial},{node.val}"
            
            # 记录当前子树出现次数
            subtree_count[current_serial] += 1
            
            # 如果这是第二次出现，加入结果
            # 注意：只在第二次出现时添加，避免重复
            if subtree_count[current_serial] == 2:
                result.append(node)
            
            return current_serial
        
        # 从根节点开始序列化
        serialize(root)
        return result
```

### 方法二：使用元组作为键（更简洁）

```python
from typing import List, Optional
from collections import defaultdict

class Solution:
    def findDuplicateSubtrees(self, root: Optional[TreeNode]) -> List[Optional[TreeNode]]:
        """
        使用元组代替字符串，减少拼接开销
        """
        subtree_count = defaultdict(int)
        result = []
        
        def serialize(node: Optional[TreeNode]) -> tuple:
            """返回子树的元组表示"""
            if not node:
                return None
            
            # 后序遍历
            left_tuple = serialize(node.left)
            right_tuple = serialize(node.right)
            
            # 使用元组表示当前子树
            current_tuple = (node.val, left_tuple, right_tuple)
            
            subtree_count[current_tuple] += 1
            
            if subtree_count[current_tuple] == 2:
                result.append(node)
            
            return current_tuple
        
        serialize(root)
        return result
```

### 方法三：使用 ID 优化（空间优化）

```python
from typing import List, Optional
from collections import defaultdict

class Solution:
    def findDuplicateSubtrees(self, root: Optional[TreeNode]) -> List[Optional[TreeNode]]:
        """
        使用 ID 映射来优化空间
        将每种子树结构映射到一个唯一 ID
        """
        # 子树结构 -> ID
        tree_to_id = defaultdict(lambda: len(tree_to_id))
        # ID -> 出现次数
        id_count = defaultdict(int)
        result = []
        
        def serialize(node: Optional[TreeNode]) -> int:
            """返回子树的 ID"""
            if not node:
                return 0
            
            # 后序遍历
            left_id = serialize(node.left)
            right_id = serialize(node.right)
            
            # 构建当前子树的唯一标识
            current_key = (node.val, left_id, right_id)
            current_id = tree_to_id[current_key]
            
            id_count[current_id] += 1
            
            if id_count[current_id] == 2:
                result.append(node)
            
            return current_id
        
        serialize(root)
        return result
```

## 复杂度分析

### 方法一：后序遍历 + 序列化
- **时间复杂度**：O(n²)
  - 遍历所有节点：O(n)
  - 每个节点的序列化可能需要 O(n)（字符串拼接）
  - 总体：O(n²)
- **空间复杂度**：O(n²)
  - 哈希表存储所有子树的序列化字符串
  - 递归调用栈：O(h)，h 为树高

### 方法二：使用元组
- **时间复杂度**：O(n²)，元组创建和比较也需要时间
- **空间复杂度**：O(n²)，存储元组

### 方法三：使用 ID 优化
- **时间复杂度**：O(n)，每个节点只访问一次
- **空间复杂度**：O(n)，存储 ID 映射

## 关键点总结

1. **后序遍历**：必须从叶子节点开始向上构建，确保子树信息完整
2. **序列化唯一性**：序列化字符串要能唯一表示一棵树的结构和值
3. **去重技巧**：只在第二次出现时加入结果，避免重复添加
4. **数据结构选择**：字符串、元组、ID 各有优劣
5. **空节点处理**：必须标记空节点，否则不同结构可能产生相同序列化

## 易错点

1. **忘记处理空节点**：
   ```python
   # 错误：不标记空节点
   if node.left:
       left = serialize(node.left)
   # 正确：必须标记
   left = serialize(node.left) if node.left else "#"
   ```

2. **重复添加结果**：
   ```python
   # 错误：每次出现都添加
   if subtree_count[serial] > 1:
       result.append(node)
   # 正确：只在第二次添加
   if subtree_count[serial] == 2:
       result.append(node)
   ```

3. **序列化顺序错误**：
   ```python
   # 错误：前序遍历可能导致不同树产生相同序列化
   serial = f"{node.val},{left},{right}"
   # 正确：后序遍历更可靠
   serial = f"{left},{right},{node.val}"
   ```

4. **缺少分隔符**：
   ```python
   # 错误：可能产生歧义
   serial = left + right + str(node.val)
   # 正确：使用分隔符
   serial = f"{left},{right},{node.val}"
   ```

5. **返回值类型**：题目要求返回节点列表，不是序列化字符串
