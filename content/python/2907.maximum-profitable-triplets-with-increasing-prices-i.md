## 题目描述

给你两个下标从 0 开始的整数数组 `prices` 和 `profits`，长度均为 `n`。

找出满足 `prices[i] < prices[j] < prices[k]`（i < j < k）的三元组 `(i, j, k)`，最大化 `profits[i] + profits[j] + profits[k]`。

若不存在满足条件的三元组，返回 `-1`。

**示例 1：**
```
输入：prices = [10,2,3,4], profits = [100,2,7,10]
输出：19
解释：(1,2,3): profits[1]+profits[2]+profits[3]=2+7+10=19
```

**示例 2：**
```
输入：prices = [1,2,3,4,5], profits = [1,5,3,4,6]
输出：15
```

**提示：**
- `3 <= n <= 2000`
- `1 <= prices[i] <= 10^6`
- `1 <= profits[i] <= 10^6`
- `prices` 中元素两两不同

## 解题思路

枚举中间元素 j，需要在 j 左侧找 `prices[i] < prices[j]` 的最大 `profits[i]`，在 j 右侧找 `prices[k] > prices[j]` 的最大 `profits[k]`。

n <= 2000，直接 O(n^2) 预处理：
- `left_max[j]`：j 左侧所有价格严格小于 prices[j] 的最大利润
- `right_max[j]`：j 右侧所有价格严格大于 prices[j] 的最大利润

## Python 代码实现

### 方法一：预处理左右最大值（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], profits: List[int]) -> int:
        n = len(prices)
        # left_max[j]: j 左侧中 prices[i] < prices[j] 的 profits[i] 的最大值
        left_max = [-1] * n
        for j in range(1, n):
            for i in range(j):
                if prices[i] < prices[j]:
                    left_max[j] = max(left_max[j], profits[i])

        # right_max[j]: j 右侧中 prices[k] > prices[j] 的 profits[k] 的最大值
        right_max = [-1] * n
        for j in range(n - 2, -1, -1):
            for k in range(j + 1, n):
                if prices[k] > prices[j]:
                    right_max[j] = max(right_max[j], profits[k])

        # 枚举中间元素
        ans = -1
        for j in range(1, n - 1):
            if left_max[j] != -1 and right_max[j] != -1:
                ans = max(ans, left_max[j] + profits[j] + right_max[j])

        return ans
```

### 方法二：暴力三重循环（便于理解）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], profits: List[int]) -> int:
        n = len(prices)
        ans = -1
        for i in range(n):
            for j in range(i + 1, n):
                if prices[j] <= prices[i]:
                    continue
                for k in range(j + 1, n):
                    if prices[k] > prices[j]:
                        total = profits[i] + profits[j] + profits[k]
                        ans = max(ans, total)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，预处理左右最大值各需 O(n^2)
- 空间复杂度：O(n)，存储左右最大值数组

## 关键点总结

1. 枚举中间元素是解三元组问题的常用技巧
2. 预处理左右最大/最小值，可将三重循环降为两重
3. n <= 2000 时 O(n^2) 完全可行

## 易错点

1. 返回 -1 而非 0，表示不存在合法三元组
2. prices 严格单调递增（严格小于），不能有等号
3. 三元组要求下标 i < j < k 且价格 prices[i] < prices[j] < prices[k]
