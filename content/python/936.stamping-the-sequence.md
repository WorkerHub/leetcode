## 题目描述

你想要用小写字母组成一个目标字符串 target。开始的时候，序列由 target.length 个 '?' 标记组成。

在一步操作中，你可以将邮票（stamp）放在序列上，并将序列中的每个字母替换为 stamp 中的对应字母。

如果可以得到目标字符串，返回能够得到 target 的最多 10 * target.length 个转变的动作序列。

## Python 代码实现

```python
from typing import List

class Solution:
    def movesToStamp(self, stamp: str, target: str) -> List[int]:
        m, n = len(stamp), len(target)
        target = list(target)
        result = []
        stamped = [False] * n
        stamp_count = 0
        
        def can_stamp(pos):
            changed = False
            for i in range(m):
                if target[pos + i] == '?':
                    continue
                if target[pos + i] != stamp[i]:
                    return False
                changed = True
            return changed
        
        def do_stamp(pos):
            nonlocal stamp_count
            for i in range(m):
                if target[pos + i] != '?':
                    target[pos + i] = '?'
                    stamp_count += 1
        
        while stamp_count < n:
            stamped_any = False
            for i in range(n - m + 1):
                if can_stamp(i):
                    do_stamp(i)
                    result.append(i)
                    stamped_any = True
            
            if not stamped_any:
                return []
        
        return result[::-1]
```

## 复杂度分析

- 时间复杂度：O(n^2 * m)
- 空间复杂度：O(n)
