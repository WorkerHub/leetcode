## 题目描述

给你一棵以 `root` 为根的二叉树。

树中的**锯齿形路径**定义：从树中任意一个节点出发，每次选择方向并移动一步（方向可以是左或右），若当前移动方向为右，下一步必须向左，反之亦然。路径方向不断交替，路径内节点不重复。

**锯齿形路径的长度**定义为：路径中经过的节点数 - 1（即边数）。

请你返回给定树中**最长**锯齿形路径的长度。

**示例 1：**
```
       1
      / \
     ?   2
        / \
       3   4
            \
             5
            / \
           6   7
```
```
输入：root = [1,null,1,1,1,null,null,1,1,null,1,null,null,null,1]
输出：3
解释：蓝色节点构成最长锯齿路径（右-左-右），长度为 3。
```

**示例 2：**
```
输入：root = [1,1,1,null,1,null,null,1,1,null,1]
输出：4
```

**示例 3：**
```
输入：root = [1]
输出：0
```

**提示：**
- 树中节点数在 `[1, 50000]` 范围内
- `1 <= Node.val <= 100`

## 解题思路

### 核心思想：DFS 传递方向和当前长度

**关键观察：**
- 锯齿路径要求左右交替转向。
- 对于每个节点，来自不同方向（父节点走左/走右到达此节点）的锯齿长度不同。

**DFS 设计：**
- 对每个节点，维护两个值：
  - `left`：以此节点向左延伸的最长锯齿长度（向左走一步后的连续锯齿边数）
  - `right`：以此节点向右延伸的最长锯齿长度

**状态转移：**
- 若从当前节点向左走到 `node.left`，则 `node.left` 的 `right` 方向可以继续延伸 = `left + 1`。
- 若从当前节点向右走到 `node.right`，则 `node.right` 的 `left` 方向可以继续延伸 = `right + 1`。

## Python 代码实现

### 方法一：DFS 返回左右方向长度（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        self.ans = 0

        def dfs(node):
            """
            返回 (left_len, right_len)：
            - left_len：从 node 向左走后能形成的最长锯齿长度
            - right_len：从 node 向右走后能形成的最长锯齿长度
            """
            if not node:
                return -1, -1   # 空节点，长度-1（方便计算）

            # 递归处理左右子树
            left_left, left_right = dfs(node.left)    # 左子节点的两个方向长度
            right_left, right_right = dfs(node.right)  # 右子节点的两个方向长度

            # 当前节点向左走1步，左子节点的"向右"方向加1（锯齿转向）
            go_left = left_right + 1
            # 当前节点向右走1步，右子节点的"向左"方向加1（锯齿转向）
            go_right = right_left + 1

            # 更新全局最长锯齿路径
            self.ans = max(self.ans, go_left, go_right)

            return go_left, go_right

        dfs(root)
        return self.ans
```

### 方法二：DFS 传入方向和当前长度

```python
from typing import Optional

class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        self.ans = 0

        def dfs(node, direction, length):
            """
            node: 当前节点
            direction: 到达当前节点的方向（'left' 或 'right'）
            length: 到达当前节点时的锯齿路径长度（边数）
            """
            if not node:
                return

            # 更新全局最大值
            self.ans = max(self.ans, length)

            if direction == 'left':
                # 上一步向左走到这里，继续锯齿需要向右走
                dfs(node.right, 'right', length + 1)  # 向右继续锯齿
                dfs(node.left, 'left', 1)             # 向左重新开始
            else:
                # 上一步向右走到这里，继续锯齿需要向左走
                dfs(node.left, 'left', length + 1)    # 向左继续锯齿
                dfs(node.right, 'right', 1)           # 向右重新开始

        # 从根节点出发，尝试向左和向右两个方向
        dfs(root.left, 'left', 1)
        dfs(root.right, 'right', 1)
        return self.ans
```

### 方法三：DFS 简洁版（合并方向为布尔值）

```python
from typing import Optional

class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def dfs(node, go_left, length):
            """
            go_left: True 表示应该向左走（锯齿方向），False 表示应该向右走
            length: 当前锯齿路径已有的边数
            """
            nonlocal ans
            if not node:
                return
            ans = max(ans, length)
            if go_left:
                dfs(node.left, False, length + 1)   # 向左走，下一步向右
                dfs(node.right, True, 1)             # 向右走，锯齿中断，重新计数
            else:
                dfs(node.right, True, length + 1)   # 向右走，下一步向左
                dfs(node.left, False, 1)             # 向左走，锯齿中断，重新计数

        dfs(root, True, 0)    # 从根出发，尝试向左
        dfs(root, False, 0)   # 从根出发，尝试向右
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 返回左右长度 | O(n) | O(h) |
| DFS 传入方向 | O(n) | O(h) |

- **时间复杂度**：O(n)，每个节点访问一次。
- **空间复杂度**：O(h)，h 为树的高度，递归栈深度。最坏情况（链状树）O(n)，平衡树 O(log n)。

## 关键点总结

1. **锯齿路径的核心**：到达某节点时，需要来自"反方向"的走法才能延伸锯齿。
2. **DFS 传状态**：传递"当前走法方向"和"当前路径长度"，每到一个节点更新全局最大值。
3. **中断重新计数**：若走的方向与锯齿方向不符（未能继续锯齿），则长度重置为1（从该步开始新路径）。
4. **全局变量或 nonlocal**：由于需要在递归中更新最大值，使用 `self.ans` 或 `nonlocal ans`。
5. 路径可以从**树中任意节点**出发，不必从根节点出发。

## 易错点

1. **路径不必从根出发**：需要在每个节点处更新全局最大值，而不是只返回根节点的结果。
2. **重新计数时置为1**：当锯齿中断时，新起点到当前节点这条边算1，不是0。
3. **空节点的处理**：方法一中空节点返回 `(-1, -1)`，加1后为0，表示没有路径，这样可以统一处理叶子节点。
4. **方向的语义**：要清楚"向左走"意味着从父节点到左子节点，此时在左子节点处，下一个锯齿步骤应该向右。
