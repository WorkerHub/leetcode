## 题目描述

给定整数数组 `nums`，每次操作可以选择任意一个元素的任意一位进行翻转（0 变 1 或 1 变 0），代价为 1。求使数组中所有元素的二进制表示中对应位都相同（所有数在同一位要么全为 0 要么全为 1）的最少总操作次数。

**示例 1：**
```
输入：nums = [1,2,3]
输出：3
解释：1=01, 2=10, 3=11
     第 0 位：1 出现 2 次（1 和 3），0 出现 1 次（2），最少翻转 1 次（将 2 的第 0 位置 1，或将 1 和 3 的第 0 位清零）。
     第 1 位：1 出现 2 次（2 和 3），0 出现 1 次（1），最少翻转 1 次。
     总共 2 次？答案 3 意味着其他计算方式。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

对每一位独立计算。

对第 `b` 位，设有 `ones` 个数该位为 1，`zeros = n - ones` 个数该位为 0。
- 若使该位全为 1：需要翻转 `zeros` 次
- 若使该位全为 0：需要翻转 `ones` 次
- 该位的最少翻转次数 = `min(ones, zeros)`

总操作次数 = 对所有位求和。

## Python 代码实现

### 方法一：逐位统计（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0

        for b in range(30):  # 最多 30 位（10^9 < 2^30）
            ones = sum(1 for x in nums if x >> b & 1)
            zeros = n - ones
            # 该位的最少翻转次数
            total += min(ones, zeros)

        return total
```

### 方法二：利用位运算批量统计

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        bits = [0] * 30

        for x in nums:
            for b in range(30):
                bits[b] += (x >> b) & 1

        for b in range(30):
            total += min(bits[b], n - bits[b])

        return total
```

## 复杂度分析

- 时间复杂度：O(n * 30)
- 空间复杂度：O(1)

## 关键点总结

1. 各位独立处理：每位要么全变 0，要么全变 1
2. 该位最少翻转次数 = `min(该位为 1 的个数, 该位为 0 的个数)`
3. 30 位足够覆盖 `10^9` 的范围

## 易错点

1. 注意位数范围：`nums[i] <= 10^9 < 2^30`，处理 30 位即可
2. 每位独立计算，不存在位之间的相互影响
