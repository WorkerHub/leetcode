## 题目描述

给你两个数 `hour` 和 `minutes`，请你返回在时钟上，由给出时间的时针和分针组成的较小角度（60 分钟制）。

**示例 1：**
```
输入：hour = 12, minutes = 30
输出：165
```

**示例 2：**
```
输入：hour = 3, minutes = 30
输出：75
```

**示例 3：**
```
输入：hour = 3, minutes = 15
输出：7.5
```

**示例 4：**
```
输入：hour = 4, minutes = 50
输出：155
```

**提示：**
- `1 <= hour <= 12`
- `0 <= minutes <= 59`

## 解题思路

**分针角度计算：**

分针每分钟转 360/60 = **6 度**。
- 分针角度 = `minutes * 6`

**时针角度计算：**

时针每小时转 360/12 = **30 度**，每分钟还会额外转 30/60 = **0.5 度**。
- 时针角度 = `(hour % 12) * 30 + minutes * 0.5`

（取 `hour % 12` 是因为 12 点等同于 0 点）

**夹角计算：**

两针的角度差 `diff = |minute_angle - hour_angle|`

较小角度 = `min(diff, 360 - diff)`（因为两个方向中选较小的那个）

## Python 代码实现

### 方法一：直接计算（推荐）

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        # 分针角度：每分钟 6 度，从 12 点（0度）开始顺时针
        minute_angle = minutes * 6
        
        # 时针角度：每小时 30 度，每分钟额外 0.5 度
        hour_angle = (hour % 12) * 30 + minutes * 0.5
        
        # 计算两针的角度差
        diff = abs(minute_angle - hour_angle)
        
        # 返回较小角度（两个方向中选小的）
        return min(diff, 360 - diff)
```

### 方法二：步骤分解（详细注释版，适合新手）

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        # 第一步：计算分针角度
        # 分针每分钟走 360/60 = 6 度
        # minutes=0 时指向 12（0度），minutes=30 时指向 6（180度）
        minute_angle = minutes * 6.0
        
        # 第二步：计算时针角度
        # 时针每小时走 360/12 = 30 度
        # 但时针不是整点跳跃，而是连续移动
        # 每过 1 分钟，时针额外移动 30/60 = 0.5 度
        # hour % 12 处理 12 点的情况（12 = 0）
        hour_normalized = hour % 12
        hour_angle = hour_normalized * 30.0 + minutes * 0.5
        
        # 第三步：计算角度差，取 [0, 360) 范围内的差值
        diff = abs(minute_angle - hour_angle)
        
        # 第四步：取较小角度（不超过 180 度）
        return min(diff, 360.0 - diff)
```

### 方法三：处理精度问题（精确小数）

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        # 使用分数运算避免浮点精度问题
        # 但题目要求精确到小数点后5位，直接用 float 即可
        
        # 一圈 360 度，时钟一圈 720 分钟（12小时）
        # 时针：每分钟走 360/720 = 0.5 度
        # 分针：每分钟走 360/60 = 6 度
        
        total_minutes = (hour % 12) * 60 + minutes
        
        # 时针角度（从12点顺时针）
        hour_angle = total_minutes * 0.5
        
        # 分针角度（从12点顺时针）
        minute_angle = minutes * 6.0
        
        diff = abs(hour_angle - minute_angle)
        return min(diff, 360 - diff)
```

### 方法四：通用验证版

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        # 时针角度（以12为起点，顺时针）
        # 一圈 12 小时 = 720 分钟，时针每分钟走 0.5 度
        total_min = (hour % 12) * 60 + minutes  # 总分钟数
        h_angle = total_min / 2  # = total_min * 0.5
        
        # 分针角度
        m_angle = minutes * 6  # = minutes / 60 * 360
        
        # 夹角
        angle = abs(h_angle - m_angle)
        
        # 确保结果在 [0, 180] 之间
        if angle > 180:
            angle = 360 - angle
        
        return angle
```

## 图解示例

以 `hour=3, minutes=30` 为例：

```
时钟图（顺时针，12点为0度）：

         12 (0°)
          |
    9 ----+---- 3  (90°)
          |
          6 (180°)

分针位置：minutes=30 -> 指向6点 -> 角度 = 30 * 6 = 180°
时针位置：hour=3, minutes=30 -> 3点半 -> 角度 = 3*30 + 30*0.5 = 90 + 15 = 105°

角度差 = |180 - 105| = 75°
较小角 = min(75, 360-75) = min(75, 285) = 75°

输出：75
```

## 关键点总结

1. 分针角度：`minutes * 6`（每分钟 6 度）
2. 时针角度：`(hour % 12) * 30 + minutes * 0.5`（每小时 30 度，每分钟 0.5 度）
3. 最终取 `min(diff, 360 - diff)` 得到较小角度
4. 注意 hour=12 时需要取模（12 % 12 = 0）

## 易错点

1. 忘记时针随分钟数移动：时针不是整点跳跃，`minutes=30` 时时针在整点和下一整点中间
2. 忘记对 `hour` 取模 12：`hour=12` 时应视为 0 时（即12点是0度）
3. 最终角度应该是 `min(diff, 360-diff)`，不要直接返回 `diff`（可能大于180）
