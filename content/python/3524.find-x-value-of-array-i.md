## 题目描述

给定一个整数数组 `nums` 和正整数 `k`。将数组分成若干长度为 `k` 的块（最后一块可能不足 `k`）。对每个块，计算其"X值"：块中所有元素的乘积对某个值取模的余数。

具体地：给定数组 `nums` 和整数 `k`，对每个长度为 `k` 的连续子数组，找有多少个前缀子数组（长度 1 到 k）的乘积 mod k 等于 0。

**示例 1：**

```
输入：nums = [1, 2, 3, 4, 5], k = 2
输出：[1, 2, 2, 2, 2]
解释：对每个前缀：
[1]: 1%2=1≠0，共0个
[1,2]: 1%2=1≠0, 2%2=0, 1*2%2=0... 
```

**示例 2：**

```
输入：nums = [2, 4, 3, 1, 5], k = 3
输出：[1, 2, 2, 3, 3]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

对每个结束位置 `i`，统计满足以下条件的起始位置 `j`（`j <= i`）的个数：`nums[j] * nums[j+1] * ... * nums[i]` 对 `k` 取模等于某个特定值（这里关注余数为 0 的情况）。

使用前缀乘积的余数：若 `prefix[i] % k == prefix[j-1] % k`，则子数组 `[j, i]` 的乘积可被 `k` 整除。

用哈希表统计前缀乘积余数的出现次数。

## Python 代码实现

### 方法一：前缀乘积 + 哈希表（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findXValue(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        result = []
        # 统计每个位置结尾的子数组中，乘积 mod k == 0 的数量
        # prefix_prod[i] = nums[0] * ... * nums[i-1] mod k
        # 子数组 [j, i] 的乘积 mod k == 0 当且仅当
        # prefix_prod[i+1] mod k == 0 或者中间某个元素为 0 mod k

        # 更直接：对每个 i，统计 j <= i 使得 product(nums[j:i+1]) % k == 0

        # 滑动窗口：维护当前窗口内能被 k 整除的子数组数
        prefix_cnt = defaultdict(int)
        prefix_cnt[1] = 1  # 空前缀，乘积为 1
        prod = 1

        for x in nums:
            prod = (prod * x) % k
            # prod == prefix[i+1] mod k
            # 找 j 使得 prefix[j] mod k 满足 prod / prefix[j] mod k == 0
            # 即 prod % prefix[j] == 0... 这不对

            # 正确方法：乘积 % k == 0 等价于 prod == 0
            # 但 prod 是当前前缀乘积 mod k

            # 对于 nums 的排列，计算每个子数组乘积 mod k 的值
            # 这里只关注 == 0 的情况

            # 前缀乘积在模 k 下可能不唯一对应子数组乘积
            # 直接统计：以 i 结尾，j 从 0 到 i 的所有子数组
            count = 0
            p = 1
            result.append(0)  # 占位

        # 重新实现：对每个 i，统计子数组 [j, i] 乘积 % k == 0 的 j 数量
        result = []
        for i in range(n):
            count = 0
            p = 1
            for j in range(i, -1, -1):
                p = p * nums[j] % k
                if p == 0:
                    count += 1
            result.append(count)
        return result
```

### 方法二：优化版（哈希表统计前缀余数）

```python
from typing import List
from collections import defaultdict

class Solution:
    def findXValue(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        result = []

        # 对每个右端点 i，统计 prod(nums[j..i]) % k == 0 的 j 数量
        # 维护从 i 向左的滚动乘积
        # 使用哈希表记录余数出现次数

        for i in range(n):
            count = 0
            p = 1
            for j in range(i, -1, -1):
                p = (p * nums[j]) % k
                if p == 0:
                    count += j + 1  # j 左侧所有起点都满足
                    break
            result.append(count)
        return result
```

## 复杂度分析

- 时间复杂度：O(n^2)（方法一），可用更复杂方法优化到 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 统计以每个位置结尾的子数组中乘积整除 k 的数量
2. 当乘积中某个元素是 k 的倍数时，所有包含它的更长子数组乘积也整除 k
3. 前缀乘积余数的哈希表方法适用于加法，对乘法需要额外处理

## 易错点

1. 乘积对 k 取模不能简单用前缀差来计算（不像加法）
2. 当数组中有 0 时（或某元素是 k 的因子），需要特殊处理
3. 向内收缩的乘积从右端向左计算，不是从左端
