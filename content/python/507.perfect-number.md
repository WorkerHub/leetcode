## 题目描述

对于一个正整数，如果它和除了它自身以外的所有正因子之和相等，我们称它为 **完美数**。

给定一个整数 `n`，如果是完美数，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：num = 28
输出：true
解释：28 = 1 + 2 + 4 + 7 + 14
1, 2, 4, 7, 和 14 是 28 的所有因子（除了 28 自身）。
```

**示例 2：**
```
输入：num = 7
输出：false
```

**提示：**
- `1 <= num <= 10^8`

## 解题思路

完美数（Perfect Number）是数论中的经典概念。关键是高效地找出所有因子。

### 核心思想：
1. 找出 num 的所有因子（除了 num 自身）
2. 计算这些因子的和
3. 判断和是否等于 num

### 优化技巧：
- **不需要遍历到 num**：因子成对出现，只需遍历到 √num
- 如果 i 是因子，那么 num/i 也是因子
- 注意避免重复计算（当 i = √num 时）

### 数学知识：
- 前几个完美数：6, 28, 496, 8128, 33550336
- 在 10^8 范围内只有 5 个完美数
- 可以直接枚举（最快，但不通用）

## Python 代码实现

### 方法一：遍历到 √n（推荐）⭐

```python
class Solution:
    def checkPerfectNumber(self, num: int) -> bool:
        """
        遍历到 sqrt(num)，找出所有因子
        时间复杂度：O(√n)，空间复杂度：O(1)
        """
        if num <= 1:
            return False
        
        # 因子和，初始为 1（1 总是因子）
        factor_sum = 1
        
        # 只需遍历到 sqrt(num)
        i = 2
        while i * i <= num:
            if num % i == 0:
                # i 是因子
                factor_sum += i
                
                # num/i 也是因子（避免重复）
                if i * i != num:  # i != sqrt(num)
                    factor_sum += num // i
            
            i += 1
        
        return factor_sum == num
```

### 方法二：优化的数学方法

```python
class Solution:
    def checkPerfectNumber(self, num: int) -> bool:
        """
        利用数学性质优化
        时间复杂度：O(√n)，空间复杂度：O(1)
        """
        if num <= 1:
            return False
        
        factor_sum = 1
        
        # 从 2 开始遍历
        for i in range(2, int(num ** 0.5) + 1):
            if num % i == 0:
                factor_sum += i
                # 避免重复计算平方根
                if i != num // i:
                    factor_sum += num // i
        
        return factor_sum == num
```

### 方法三：直接枚举（最快但不通用）

```python
class Solution:
    def checkPerfectNumber(self, num: int) -> bool:
        """
        直接枚举 10^8 内的所有完美数
        时间复杂度：O(1)，空间复杂度：O(1)
        """
        # 10^8 范围内只有 5 个完美数
        perfect_numbers = {6, 28, 496, 8128, 33550336}
        return num in perfect_numbers
```

### 方法四：暴力解法（会超时，仅供理解）

```python
class Solution:
    def checkPerfectNumber(self, num: int) -> bool:
        """
        暴力遍历所有可能的因子
        时间复杂度：O(n)，空间复杂度：O(1)
        """
        if num <= 1:
            return False
        
        factor_sum = 0
        
        # 遍历 1 到 num-1
        for i in range(1, num):
            if num % i == 0:
                factor_sum += i
        
        return factor_sum == num
```

## 复杂度分析

### 方法一、二（√n 遍历）：
- **时间复杂度**：O(√n)
  - 只需遍历到 √n
- **空间复杂度**：O(1)

### 方法三（枚举）：
- **时间复杂度**：O(1)，只是集合查找
- **空间复杂度**：O(1)

### 方法四（暴力）：
- **时间复杂度**：O(n)，会超时
- **空间复杂度**：O(1)

## 关键点总结

1. **因子成对性**：如果 i 是因子，num/i 也是因子
2. **遍历到 √n**：可以大幅减少时间复杂度
3. **避免重复**：当 i = √num 时，只计算一次
4. **边界处理**：1 不是完美数，需要特殊判断
5. **数学优化**：对于特定范围，直接枚举是最快的

## 易错点

1. **重复计算**：i 和 num/i 相等时（num 是完全平方数），只能加一次
2. **边界情况**：num = 1 返回 false
3. **初始值**：factor_sum 初始化为 1（因为 1 总是因子）
4. **遍历范围**：是到 √num，不是 num/2
5. **整数除法**：使用 `//`，不是 `/`

```
i = 3:
  28 % 3 != 0 ✗

  28 % 4 == 0 ✓
  因子：4, 28/4 = 7
  sum = 17 + 4 + 7 = 28

i = 5:
  28 % 5 != 0 ✗

最终 sum = 28 = num ✓ → 完美数
```

## 完美数的数学背景

**欧几里得-欧拉定理**：
- 偶数完美数的形式：2^(p-1) × (2^p - 1)
- 其中 2^p - 1 是梅森素数

**已知的完美数**：
```
6       = 2^1 × (2^2 - 1)
28      = 2^2 × (2^3 - 1)
496     = 2^4 × (2^5 - 1)
8128    = 2^6 × (2^7 - 1)
33550336 = 2^12 × (2^13 - 1)
```

**未解之谜**：
- 是否存在奇数完美数？（至今未知）
- 完美数是否无限多？（相信是，但未证明）
