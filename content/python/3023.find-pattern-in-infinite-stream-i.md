## 题目描述

给你一个二进制数组 `pattern` 和一个无限的二进制流 `stream`。

`stream` 通过 `stream.next()` 方法每次返回 0 或 1。

返回 `pattern` 第一次在 `stream` 中出现的起始下标（0-indexed）。

**示例 1：**
```
输入：pattern = [1,1], stream = [1,1,1,0,1,1]
输出：0
```

**示例 2：**
```
输入：pattern = [0,1], stream = [0,0,0,0,1]
输出：3
```

**提示：**
- `1 <= pattern.length <= 100`
- `pattern` 只包含 0 和 1
- `stream` 无限，保证 `pattern` 会出现在其中

## 解题思路

使用 KMP 算法在无限流中滑动匹配 `pattern`。

维护当前已匹配的前缀长度 `j`，每次读取新字符，用 KMP 失配函数更新 `j`，当 `j == len(pattern)` 时，找到匹配。

## Python 代码实现

### 方法一：KMP 流式匹配（推荐）

```python
from typing import List

# 接口定义（LeetCode 提供）
class InfiniteStream:
    def next(self) -> int:
        pass

class Solution:
    def findPattern(self, stream: 'InfiniteStream', pattern: List[int]) -> int:
        m = len(pattern)

        # 构建 KMP 失配表
        fail = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and pattern[i] != pattern[j]:
                j = fail[j - 1]
            if pattern[i] == pattern[j]:
                j += 1
            fail[i] = j

        # 流式 KMP 匹配
        j = 0
        idx = 0  # 当前读取的字符下标
        while True:
            c = stream.next()
            while j > 0 and c != pattern[j]:
                j = fail[j - 1]
            if c == pattern[j]:
                j += 1
            if j == m:
                # 找到匹配，起始下标为 idx - m + 1
                return idx - m + 1
            idx += 1
```

### 方法二：滑动窗口（适合 pattern 较短时）

```python
from typing import List
from collections import deque

class Solution:
    def findPattern(self, stream: 'InfiniteStream', pattern: List[int]) -> int:
        m = len(pattern)
        window = deque(maxlen=m)

        for i in range(m - 1):
            window.append(stream.next())

        idx = m - 1
        while True:
            window.append(stream.next())
            if list(window) == pattern:
                return idx - m + 1
            idx += 1
```

## 复杂度分析

- KMP 时间复杂度：O(n + m)，n 为找到匹配前读取的字符数，m 为 pattern 长度
- 空间复杂度：O(m)，存储失配表

## 关键点总结

1. KMP 算法适合流式匹配：每次读入一个字符，O(1) 均摊更新状态
2. 失配函数预处理 O(m)，之后匹配每字符 O(1) 均摊
3. `idx - m + 1` 是匹配的起始下标

## 易错点

1. 注意 `idx` 的更新时机：读取后先更新 `idx`，再检查是否匹配
2. KMP 失配表中，`j = fail[j-1]` 是核心回退步骤
