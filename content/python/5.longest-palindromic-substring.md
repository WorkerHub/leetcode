## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**示例 1：**
```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案
```

**示例 2：**
```
输入：s = "cbbd"
输出："bb"
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 解题思路

**方法对比：**
1. **中心扩展**：从每个位置向两边扩展（推荐）
2. **动态规划**：dp[i][j] 表示 s[i:j+1] 是否为回文
3. **Manacher算法**：线性时间复杂度

## Python 代码实现

### 方法一：中心扩展（推荐）

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""
        
        start, max_len = 0, 0
        
        for i in range(len(s)):
            # 奇数长度回文
            len1 = self.expandAroundCenter(s, i, i)
            # 偶数长度回文
            len2 = self.expandAroundCenter(s, i, i + 1)
            
            length = max(len1, len2)
            if length > max_len:
                max_len = length
                start = i - (length - 1) // 2
        
        return s[start:start + max_len]
    
    def expandAroundCenter(self, s: str, left: int, right: int) -> int:
        """从中心向两边扩展"""
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1
```

### 方法二：动态规划

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        if n < 2:
            return s
        
        # dp[i][j] 表示 s[i:j+1] 是否为回文
        dp = [[False] * n for _ in range(n)]
        start, max_len = 0, 1
        
        # 单个字符都是回文
        for i in range(n):
            dp[i][i] = True
        
        # 从长度 2 开始
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                
                if s[i] == s[j]:
                    if length == 2:
                        dp[i][j] = True
                    else:
                        dp[i][j] = dp[i + 1][j - 1]
                
                if dp[i][j] and length > max_len:
                    start = i
                    max_len = length
        
        return s[start:start + max_len]
```

## 复杂度分析

**方法一（中心扩展）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(1)

**方法二（动态规划）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. **中心扩展**：考虑奇数和偶数两种情况
2. **动态规划**：状态转移 dp[i][j] = (s[i] == s[j]) and dp[i+1][j-1]
3. **边界处理**：单字符和双字符

## 易错点

1. **奇偶情况**：回文串有奇数和偶数长度两种
2. **索引计算**：扩展后的起始位置计算
