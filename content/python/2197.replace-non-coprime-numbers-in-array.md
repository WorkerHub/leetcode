## 题目描述

给你一个整数数组 `nums`。请你对数组执行下述操作，**直到数组中不存在相邻的非互质数对**为止：

- 找出任意一对**相邻**的**非互质**数 `nums[i]` 和 `nums[i+1]`（非互质：`gcd(nums[i], nums[i+1]) > 1`）。
- 将它们**替换**为其 LCM（最小公倍数）。

返回替换完成后的结果数组。可以证明结果是**唯一**的。

**示例 1：**
```
输入：nums = [6,4,3,2,7,6,2]
输出：[12,7,6]
解释：
- (6,4)：gcd=2>1，lcm=12，替换→[12,3,2,7,6,2]
- (12,3)：gcd=3>1，lcm=12，替换→[12,2,7,6,2]
- (12,2)：gcd=2>1，lcm=12，替换→[12,7,6,2]
- (6,2)：gcd=2>1，lcm=6，替换→[12,7,6]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

**栈模拟**

用栈维护当前结果。遍历 `nums`，每次将当前数字入栈后，检查栈顶两个元素是否互质：
- 若不互质，弹出两个，将其 LCM 入栈（此时新栈顶可能与 LCM 也不互质，继续检查）。
- 若互质（或栈只有一个元素），停止。

核心：利用栈回溯检查新合并的数与之前的数的关系。

## 代码实现

### 方法一：栈模拟（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def replaceNonCoprimes(self, nums: List[int]) -> List[int]:
        stack = []

        for x in nums:
            stack.append(x)
            # 检查栈顶两元素是否互质
            while len(stack) >= 2:
                a, b = stack[-2], stack[-1]
                g = gcd(a, b)
                if g == 1:
                    break  # 互质，停止
                # 不互质，合并为 LCM
                stack.pop()
                stack.pop()
                stack.append(a * b // g)  # LCM = a * b / gcd(a, b)

        return stack
```

### 方法二：迭代合并（更直观）

```python
from typing import List
from math import gcd

class Solution:
    def replaceNonCoprimes(self, nums: List[int]) -> List[int]:
        result = []
        for x in nums:
            cur = x
            # 与 result 末尾不断合并，直到互质
            while result and gcd(result[-1], cur) > 1:
                top = result.pop()
                g = gcd(top, cur)
                cur = top * cur // g  # LCM
            result.append(cur)
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 栈模拟 | O(n log(max_val)) | O(n) |

每个元素至多入栈一次，合并时 LCM 会变大，最多合并 O(log(max_val)) 次。

## 关键点总结

1. 用栈模拟：新元素入栈后，与栈顶不断合并直到互质。
2. 合并公式：`lcm(a, b) = a * b // gcd(a, b)`。
3. 每次合并后新的 LCM 可能又与更早的元素不互质，用 `while` 循环处理。

## 易错点

- 必须用 `while` 而非 `if`：合并后可能产生新的非互质对，需继续检查。
- LCM 计算：`a * b // gcd(a, b)`（先除后乘防溢出，Python 无溢出但好习惯）。
