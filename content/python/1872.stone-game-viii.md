## 题目描述

Alice 和 Bob 轮流（Alice 先）从一行石子中取石子（至少取 2 个，从最左边取连续若干个）。每次取走后，移走的石子数量加到取走者的分数上。

两人都以**最优策略**游戏，返回 Alice 的分数减 Bob 的分数。

**示例：**
```
输入：stones = [-1,2,-3,4,-5]
输出：5
```

**提示：**
- `n == stones.length`
- `2 <= n <= 10^5`
- `-10^4 <= stones[i] <= 10^4`

## 解题思路

**前缀和 + DP**：

设前缀和 `prefix[i] = stones[0] + ... + stones[i]`，取前 i+1 个石子得 `prefix[i]`。

关键观察：每次取走最左边的若干个（至少 2 个），等价于选一个新的"起点"（第二块起的位置）。

`dp[i]` = 当前玩家从位置 i 开始（已取走 i 个石子，可取 stones[i..n-1]）时，能获得的**净得分**（自己得分 - 对方得分）。

转移：`dp[i] = prefix[i] - dp[i+1]`（取到 i 后，对方面对从 i+1 开始的子问题）

初始：`dp[n-1] = prefix[n-1]`（只剩最后一个位置，只能全取）

答案：从 i=1 到 n-1，Alice 选择使 `prefix[i] - dp[i+1]` 最大的 i。

等价于 `max(prefix[i] - dp[i+1])` for i in [1, n-1]，从右往左维护即可。

class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        n = len(stones)
        # 计算前缀和
        prefix = [0] * n
        prefix[0] = stones[0]
        for i in range(1, n):
            prefix[i] = prefix[i - 1] + stones[i]

        # dp[i] = 当前玩家从 i 开始选择的最优净得分
        # dp[n-1] = prefix[n-1]（只能选全部）
        # dp[i] = max(prefix[i] - dp[i+1], dp[i+1])... 等价于从右往左维护最大值

        # 从右往左：suffix_max = max(prefix[i] - dp[i+1]) for i in [1, n-1]

        prefix = stones[:]
        for i in range(1, n):
            prefix[i] += prefix[i - 1]

        # dp = 当前玩家在 [i, n-1] 上的最优净得分
        # Alice 选择 i（取 stones[0..i]），得 prefix[i]，Bob 面对 [i+1, n-1]
        # Alice 净得 = prefix[i] - dp_bob[i+1]
        # 从右往左：dp[i] = max(prefix[i] - dp[i+1], dp[i+1])
        # 等价于 dp[i] = max(prefix[i], dp[i+1]) - ... 不对

        # 标准推导：
        # 设 f[i] = 从 i 开始先手的最优净得分（先手取 stones[0..i]，后手面对 [i+1, n-1]）
        # f[n-1] = prefix[n-1]
        # f[i] = prefix[i] - f[i+1]... 但 i+1 位置先手可以继续选

        # 实际 dp：
        dp = prefix[-1]
        for i in range(n - 2, 0, -1):
            dp = max(prefix[i] - dp, dp)
        return dp

### 方法二：正确的简洁实现

```python
from typing import List

class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        n = len(stones)
        # 前缀和
        for i in range(1, n):
            stones[i] += stones[i - 1]
        # stones[i] 现在是前缀和

        # dp 表示当前玩家面对 [i..n-1] 时能获得的最大净得分
        # 初始：i = n-1，只能取 stones[n-1]，净得 stones[n-1]
        dp = stones[-1]
        for i in range(n - 2, 0, -1):
            # 当前玩家选择取到 i：自己得 stones[i]，对方面对 [i+1..n-1]
            # 净得 = stones[i] - dp（对方的最优净得分）
            dp = max(dp, stones[i] - dp)
        return dp
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（原地修改 stones 为前缀和）

## 关键点总结

1. 将石子取法转化为：选择一个分界点 i，取 stones[0..i]，后手面对 [i+1..n-1]
2. 净得分 DP：当前玩家选分界点 i，净得 = prefix[i] - 对方最优净得
3. 从右往左更新，dp 维护"从当前位置往后先手的最大净得分"

## 易错点

- 每次至少取 2 个，所以分界点从 i=1 开始（取 stones[0..1] 最少取 2 个）
- dp 的更新是 `max(dp, prefix[i] - dp)`，取较大值
