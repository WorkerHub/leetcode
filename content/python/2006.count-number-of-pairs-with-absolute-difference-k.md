## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回数对 `(i, j)` 的数目，满足 `i < j` 且 `|nums[i] - nums[j]| == k`。

`|x|` 代表 `x` 的绝对值。

**示例 1：**
```
输入：nums = [1,2,2,1], k = 1
输出：4
解释：满足条件的数对：(0,1), (0,2), (3,1), (3,2)，即 |1-2|=1 共4对
```

**示例 2：**
```
输入：nums = [1,3], k = 3
输出：0
```

**示例 3：**
```
输入：nums = [3,2,1,5,4], k = 2
输出：3
解释：|3-1|=2, |3-5|=2, |2-4|=2
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`
- `1 <= k <= 99`

## 解题思路

**方法一（暴力）：** 枚举所有 `i < j` 的数对，判断绝对差是否等于 `k`，时间 O(n^2)。

**方法二（哈希表）：** 遍历每个元素 `x`，查找哈希表中是否存在 `x+k` 或 `x-k`，时间 O(n)。

由于数据规模很小（n ≤ 200），两种方法都可以通过。

## 代码实现

### 方法一：暴力枚举（简单直接）

```python
from typing import List

class Solution:
    def countKDifference(self, nums: List[int], k: int) -> int:
        count = 0
        n = len(nums)
        # 枚举所有 i < j 的数对
        for i in range(n):
            for j in range(i + 1, n):
                if abs(nums[i] - nums[j]) == k:
                    count += 1
        return count
```

### 方法二：哈希表计数（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countKDifference(self, nums: List[int], k: int) -> int:
        count = 0
        freq = defaultdict(int)  # 记录已遍历元素的频次

        for x in nums:
            # 查找是否存在与 x 差绝对值为 k 的元素
            count += freq[x - k]  # x - (x-k) = k
            count += freq[x + k]  # (x+k) - x = k
            freq[x] += 1  # 将当前元素加入哈希表

        return count
```

### 方法三：数组计数（利用值域范围小）

```python
from typing import List

class Solution:
    def countKDifference(self, nums: List[int], k: int) -> int:
        freq = [0] * 101  # nums[i] 在 1..100 范围内
        count = 0

        for x in nums:
            # 查找已有元素中与 x 差为 k 的
            if x - k >= 1:
                count += freq[x - k]
            if x + k <= 100:
                count += freq[x + k]
            freq[x] += 1

        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^2) | O(1) |
| 哈希表 | O(n) | O(n) |
| 数组计数 | O(n) | O(M)，M 为值域大小 |

## 关键点总结

1. `|a - b| == k` 等价于 `a - b == k` 或 `a - b == -k`，即 `b == a-k` 或 `b == a+k`
2. 哈希表方法遍历一遍，先查询再插入，避免重复计数
3. 数据规模小时暴力法也是可行选择

## 易错点

- 方法二中，查询要在插入当前元素**之前**，否则会与自身配对（当 `k=0` 时可能有问题，但题目保证 `k >= 1`）
- 注意 `k=0` 的情况（本题 `k >= 1`，不需要特殊处理）
- 数对要求 `i < j`，哈希表方法天然保证这一点（先查后插）
