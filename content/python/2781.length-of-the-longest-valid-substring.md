## 题目描述

给你一个字符串 `word` 和一个字符串数组 `forbidden`，如果一个字符串不包含 `forbidden` 中的任何字符串作为子字符串，则该字符串为 **有效字符串**。

返回 `word` 的 **最长有效子字符串** 的长度。

**示例 1：**
```
输入：word = "cbaaaabc", forbidden = ["aaa","cb"]
输出：4
解释：有效子串 "aabc" 长度 4（不含 "aaa" 或 "cb"）
```

**提示：**
- `1 <= word.length <= 10^5`
- `1 <= forbidden.length <= 10^5`
- `1 <= forbidden[i].length <= 10`

## 解题思路

**滑动窗口**：由于 forbidden 中字符串长度最多为 10，对每个右端 `right`，只需检查 `word[right-9..right]`（最多 10 个后缀子串）是否在 forbidden 中。

维护左端 `left`，若某个子串在 forbidden 中，将 `left` 更新为该子串起始位置 + 1。

## Python 代码实现

### 方法一：滑动窗口 + 哈希集合（推荐）

```python
from typing import List

class Solution:
    def longestValidSubstring(self, word: str, forbidden: List[str]) -> int:
        forbidden_set = set(forbidden)
        max_len = max(len(f) for f in forbidden)  # 最长禁止串长度（最多10）

        n = len(word)
        ans = 0
        left = 0

        for right in range(n):
            # 检查以 right 结尾、长度不超过 max_len 的所有子串
            for l in range(right, max(left - 1, right - max_len), -1):
                if word[l:right + 1] in forbidden_set:
                    left = l + 1  # 调整左端
                    break
            ans = max(ans, right - left + 1)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n * max_len)，max_len <= 10，实际 O(10n)
- 空间复杂度：O(total_len)，total_len 为所有 forbidden 字符串长度之和

## 关键点总结

1. forbidden 字符串长度最多 10，每次只需检查最后 10 个子串
2. 滑动窗口：遇到禁止串就右移左端
3. 从右往左检查，找到最右边的禁止串，保证 left 尽量小

## 易错点

1. 内层循环需要从右往左（从 right 往左），找到最长的匹配禁止串
2. left 只能右移，不能左移
