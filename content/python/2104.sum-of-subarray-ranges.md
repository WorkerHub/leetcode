## 题目描述

给你一个整数数组 `nums`，`nums` 中一个子数组的**范围**是子数组中最大元素和最小元素的差值。

返回 `nums` 中**所有**子数组范围的**和**。

**示例 1：**
```
输入：nums = [1,2,3]
输出：4
解释：
子数组及其范围：
[1]：范围 = 0
[2]：范围 = 0
[3]：范围 = 0
[1,2]：范围 = 2-1 = 1
[2,3]：范围 = 3-2 = 1
[1,2,3]：范围 = 3-1 = 2
所有范围的和 = 0+0+0+1+1+2 = 4
```

**示例 2：**
```
输入：nums = [1,3,3]
输出：4
```

**提示：**
- `1 <= nums.length <= 1000`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

**方法一（暴力）：** 枚举所有子数组，O(n^2)。

**方法二（单调栈）：** 
范围之和 = 所有子数组最大值之和 - 所有子数组最小值之和。

对于每个元素 `nums[i]`，计算它作为子数组最大值时贡献了多少，再计算它作为最小值时贡献了多少。

利用单调栈找出每个元素作为最大值/最小值的左右边界，即可 O(n) 计算。

设：
- `left_max[i]`：左边第一个比 `nums[i]` 大的下标（作为最大值的左边界）
- `right_max[i]`：右边第一个大于等于 `nums[i]` 的下标（右边界）
- 类似地定义 `left_min[i]`、`right_min[i]`

元素 `nums[i]` 作为最大值的贡献 = `nums[i] * (i - left_max[i]) * (right_max[i] - i)`

## 代码实现

### 方法一：暴力枚举（推荐新手）

```python
from typing import List

class Solution:
    def subArrayRanges(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        for i in range(n):
            min_val = max_val = nums[i]
            for j in range(i + 1, n):
                # 动态更新当前子数组的最大最小值
                min_val = min(min_val, nums[j])
                max_val = max(max_val, nums[j])
                total += max_val - min_val
        return total
```

### 方法二：单调栈 O(n)（推荐优化）

```python
from typing import List

class Solution:
    def subArrayRanges(self, nums: List[int]) -> int:
        n = len(nums)

        def sum_subarray_mins(arr: List[int]) -> int:
            # 计算所有子数组最小值之和
            stack = []
            result = 0
            for i in range(n + 1):
                # 当 i==n 时，弹出所有剩余元素
                while stack and (i == n or arr[stack[-1]] >= arr[i]):
                    mid = stack.pop()
                    left = stack[-1] if stack else -1
                    right = i
                    # mid 作为最小值的子数组数量
                    result += arr[mid] * (mid - left) * (right - mid)
                stack.append(i)
            return result

        def sum_subarray_maxs(arr: List[int]) -> int:
            # 计算所有子数组最大值之和
            stack = []
            result = 0
            for i in range(n + 1):
                while stack and (i == n or arr[stack[-1]] <= arr[i]):
                    mid = stack.pop()
                    left = stack[-1] if stack else -1
                    right = i
                    result += arr[mid] * (mid - left) * (right - mid)
                stack.append(i)
            return result

        # 范围之和 = 最大值之和 - 最小值之和
        return sum_subarray_maxs(nums) - sum_subarray_mins(nums)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力 | O(n^2) | O(1) |
| 单调栈 | O(n) | O(n) |

## 关键点总结

1. 范围之和 = 所有子数组最大值之和 - 所有子数组最小值之和，将问题拆分。
2. 单调栈可以 O(n) 找出每个元素作为极值时覆盖的子数组数。
3. 计算贡献时：`nums[mid] * (mid - left) * (right - mid)`。

## 易错点

- 暴力法中注意 `i` 到 `j` 的范围，子数组长度为 1 时范围为 0。
- 单调栈处理重复元素时需注意边界的严格不等号方向，避免重复计算。
- 单调栈法中 `i == n` 作为哨兵处理剩余元素。
