## 题目描述

给你两个整数 `n` 和 `t`。返回**大于等于 `n` 的最小整数**，使得该整数所有数位的乘积能被 `t` 整除。

**示例：**
```
输入：n = 10, t = 2
输出：12
解释：10 的各位乘积 = 0（含0，乘积为0，0能被任何正整数整除），11的乘积=1，不被2整除；12的乘积=2，被2整除
注意：含有0的数字，乘积为0，0 % t == 0 成立
```

**提示：**
- `1 <= n <= 100`
- `1 <= t <= 10`

## 解题思路

数据范围很小（n <= 100），直接从 n 开始枚举每个整数，计算各位乘积是否能被 t 整除，找到第一个满足的。

注意：若某位数字为 0，则乘积为 0，而 `0 % t == 0` 恒成立（t 不为 0），所以含 0 的数字都满足条件。

## Python 代码实现

### 方法一：枚举（推荐）

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        def digit_product(x):
            prod = 1
            while x > 0:
                prod *= x % 10
                x //= 10
            return prod
        
        x = n
        while True:
            if digit_product(x) % t == 0:
                return x
            x += 1
```

### 方法二：字符串处理

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        x = n
        while True:
            product = 1
            for c in str(x):
                product *= int(c)
            if product % t == 0:
                return x
            x += 1
```

## 复杂度分析

- 时间复杂度：O(答案 - n)，最坏情况下枚举几步即可（因为 t <= 10，两位数或三位数内必有解）
- 空间复杂度：O(1)

## 关键点总结

1. 各位乘积 = 0（含有数字 0 的整数）总能被任何正整数整除。
2. 数据范围极小，直接枚举即可。
3. 答案不会太远（至多在 n + 10 * t 内找到）。

## 易错点

1. 含 0 的数字乘积为 0，`0 % t == 0` 对任何 t > 0 成立，不要特殊处理。
2. 需要从 n 开始（包含 n 本身），不是 n+1。
