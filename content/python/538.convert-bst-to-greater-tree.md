## 题目描述

给定一个二叉搜索树（Binary Search Tree，BST）的根节点 `root`，将其转换为累加树（Greater Tree），使得每个节点的值是原来的节点值加上所有大于它的节点值之和。

提醒一下，二叉搜索树满足以下约束条件：

- 节点的左子树仅包含键小于节点键的节点
- 节点的右子树仅包含键大于节点键的节点
- 左右子树也必须是二叉搜索树

**示例 1：**

![](https://fastly.jsdelivr.net/gh/doocs/leetcode@main/solution/0500-0599/0538.Convert%20BST%20to%20Greater%20Tree/images/tree.png)

```
输入: root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出: [30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]
解释: 
节点 4 的新值 = 4 + 5 + 6 + 7 + 8 = 30
节点 1 的新值 = 1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 = 36
节点 6 的新值 = 6 + 7 + 8 = 21
...
```

**示例 2：**
```
输入: root = [0,null,1]
输出: [1,null,1]
```

**提示：**
- 树中节点数量在 `[0, 10^4]` 范围内
- `-10^4 <= Node.val <= 10^4`
- 树中所有值都是唯一的
- `root` 保证是有效的二叉搜索树

**注意：** 此题与 [LeetCode 1038](https://leetcode.com/problems/binary-search-tree-to-greater-sum-tree/) 相同

## 解题思路

这道题利用了二叉搜索树（BST）的重要性质：**中序遍历结果是升序序列**。

**核心观察：**

1. 中序遍历（左 → 根 → 右）产生升序序列
2. **反向中序遍历**（右 → 根 → 左）产生降序序列
3. 按降序处理节点，可以累加所有大于当前节点的值

**算法思路：**

采用反向中序遍历（右 → 根 → 左），维护一个累加和 `s`：

1. 先访问右子树（所有大于当前节点的值）
2. 更新当前节点：`s += root.val`，然后 `root.val = s`
3. 再访问左子树

这样就能保证每个节点都加上了所有大于它的节点值之和。

**图解示例：**

```
原始 BST:          4
                 /   \
                1     6
               / \   / \
              0   2 5   7
                   \     \
                    3     8

反向中序遍历顺序: 8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → 0

累加过程:
8: s=0+8=8,   新值=8
7: s=8+7=15,  新值=15
6: s=15+6=21, 新值=21
5: s=21+5=26, 新值=26
4: s=26+4=30, 新值=30
3: s=30+3=33, 新值=33
2: s=33+2=35, 新值=35
1: s=35+1=36, 新值=36
0: s=36+0=36, 新值=36

结果 Greater Tree:  30
                   /   \
                 36    21
                / \   /  \
              36  35 26  15
                    \     \
                    33     8
```

## Python 代码实现

### 方法一：递归反向中序遍历（推荐）

```python
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用递归实现反向中序遍历
        时间复杂度 O(n)，空间复杂度 O(h)，h 为树高
        """
        self.s = 0  # 累加和
        
        def dfs(node: Optional[TreeNode]) -> None:
            """反向中序遍历：右 → 根 → 左"""
            if not node:
                return
            
            # 1. 先遍历右子树（所有大于当前节点的值）
            dfs(node.right)
            
            # 2. 处理当前节点
            self.s += node.val  # 累加当前节点值
            node.val = self.s   # 更新节点值为累加和
            
            # 3. 再遍历左子树
            dfs(node.left)
        
        dfs(root)
        return root
```

### 方法二：使用 nonlocal 关键字

```python
from typing import Optional

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用 nonlocal 声明外部变量
        避免使用 self，代码更简洁
        """
        s = 0  # 累加和
        
        def dfs(node: Optional[TreeNode]) -> None:
            nonlocal s  # 声明使用外部变量 s
            if not node:
                return
            
            dfs(node.right)  # 右子树
            s += node.val    # 累加
            node.val = s     # 更新
            dfs(node.left)   # 左子树
        
        dfs(root)
        return root
```

### 方法三：迭代法（Morris 遍历）

```python
from typing import Optional

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        Morris 遍历实现，空间复杂度 O(1)
        不使用递归栈，通过修改树结构实现遍历
        """
        s = 0  # 累加和
        node = root  # 保存根节点用于返回
        
        while root:
            if root.right is None:
                # 右子树为空，处理当前节点
                s += root.val
                root.val = s
                root = root.left
            else:
                # 找到右子树的最左节点
                next_node = root.right
                while next_node.left and next_node.left != root:
                    next_node = next_node.left
                
                if next_node.left is None:
                    # 建立线索，继续遍历右子树
                    next_node.left = root
                    root = root.right
                else:
                    # 已经遍历过右子树，处理当前节点
                    s += root.val
                    root.val = s
                    next_node.left = None  # 恢复树结构
                    root = root.left
        
        return node
```

### 方法四：迭代法（使用栈）

```python
from typing import Optional

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        使用栈实现反向中序遍历
        显式模拟递归过程
        """
        if not root:
            return None
        
        s = 0  # 累加和
        stack = []
        node = root
        
        # 反向中序遍历：右 → 根 → 左
        while stack or node:
            # 一直向右走到底
            while node:
                stack.append(node)
                node = node.right
            
            # 处理栈顶节点
            node = stack.pop()
            s += node.val
            node.val = s
            
            # 转向左子树
            node = node.left
        
        return root
```

### 方法五：详细注释版（适合初学者）

```python
from typing import Optional

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        """
        最详细的实现，包含每个步骤的解释
        """
        # 用于存储累加和的变量
        self.cumulative_sum = 0
        
        def reverse_inorder(node: Optional[TreeNode]) -> None:
            """
            反向中序遍历函数
            遍历顺序：右子树 → 当前节点 → 左子树
            这样可以从大到小访问所有节点
            """
            # 基础情况：空节点直接返回
            if node is None:
                return
            
            # 步骤 1: 递归遍历右子树
            # 右子树包含所有大于当前节点的值
            reverse_inorder(node.right)
            
            # 步骤 2: 处理当前节点
            # 将当前节点值加到累加和中
            self.cumulative_sum += node.val
            
            # 将节点值更新为累加和
            # 这个累加和包含了当前节点及所有大于它的节点的值
            node.val = self.cumulative_sum
            
            # 步骤 3: 递归遍历左子树
            # 左子树包含所有小于当前节点的值
            reverse_inorder(node.left)
        
        # 从根节点开始遍历
        reverse_inorder(root)
        
        # 返回修改后的树的根节点
        return root
```

## 复杂度分析

### 方法一、二：递归法
- **时间复杂度**：O(n)，其中 n 是树中节点的数量，每个节点访问一次
- **空间复杂度**：O(h)，其中 h 是树的高度
  - 最好情况（平衡树）：O(log n)
  - 最坏情况（链状树）：O(n)
  - 空间主要用于递归调用栈

### 方法三：Morris 遍历
- **时间复杂度**：O(n)，每个节点最多访问两次
- **空间复杂度**：O(1)，不使用额外空间，只是临时修改树结构

### 方法四：迭代法（栈）
- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，栈的最大深度为树高

**推荐使用方法一或方法二**，代码简洁且易于理解。如果要求 O(1) 空间，使用方法三。

## 关键点总结

1. **反向中序遍历**：右 → 根 → 左，产生降序序列，是解决此题的核心
2. **BST 性质**：利用二叉搜索树的有序性质
3. **累加和维护**：用一个变量维护从大到小的累加和
4. **原地修改**：直接修改节点值，不需要创建新树
5. **遍历顺序的重要性**：必须先处理较大的值，才能累加到较小的值上

## 易错点

1. **遍历顺序错误**
   ```python
   # 错误：使用正常中序遍历（左 → 根 → 右）
   def dfs(node):
       dfs(node.left)   # 错误：先访问小的值
       s += node.val
       node.val = s
       dfs(node.right)
   
   # 正确：使用反向中序遍历（右 → 根 → 左）
   def dfs(node):
       dfs(node.right)  # 正确：先访问大的值
       s += node.val
       node.val = s
       dfs(node.left)
   ```

2. **累加和的更新顺序**
   ```python
   # 错误：先更新节点值再累加
   node.val = s
   s += node.val  # 错误
   
   # 正确：先累加再更新节点值
   s += node.val
   node.val = s   # 正确
   ```

3. **忘记返回根节点**
   ```python
   # 错误：没有返回值
   def convertBST(self, root):
       dfs(root)
       # 忘记返回
   
   # 正确：返回修改后的根节点
   def convertBST(self, root):
       dfs(root)
       return root
   ```

4. **变量作用域问题**
   ```python
   # 使用 self 时要初始化
   self.s = 0  # 正确
   
   # 使用局部变量需要 nonlocal
   s = 0
   def dfs(node):
       nonlocal s  # 必须声明
   ```
