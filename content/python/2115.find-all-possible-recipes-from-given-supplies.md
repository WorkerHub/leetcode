## 题目描述

你有 `n` 道不同菜的信息。给你字符串数组 `recipes` 和二维字符串数组 `ingredients`。第 `i` 道菜的名字为 `recipes[i]`，如果你有它所有的原料 `ingredients[i]`，就可以**做出**这道菜。一道菜的原料可以是另一道菜。

同时给你字符串数组 `supplies`，包含你初始拥有的所有原料，每种原料**无限量**供应。

返回你可以做出的所有菜。答案的顺序可以任意。

**示例：**
```
输入：recipes = ["bread","sandwich"], ingredients = [["yeast","flour"],["bread","meat"]], supplies = ["yeast","flour","meat"]
输出：["bread","sandwich"]
解释：可以做面包（有yeast和flour），再用面包和肉做三明治。
```

**提示：**
- `n == recipes.length == ingredients.length`
- `1 <= n <= 100`
- `1 <= ingredients[i].length, supplies.length <= 100`
- 字符串仅由小写字母组成

## 解题思路

**拓扑排序**

将菜品之间的依赖关系建图：若菜 B 需要菜 A 作为原料，则 A → B 有一条有向边。

初始可用 = `supplies` 集合。对所有原料在 supplies 中已满足的菜，可以加入队列（入度为 0）。

BFS 拓扑排序：
1. 统计每道菜未满足的原料数（入度）。
2. 将初始 `supplies` 中能直接满足所有原料的菜加入队列。
3. BFS：从队列取出一道菜，标记为可制作，并减少依赖它的菜的入度，若入度变为 0 则加入队列。

## 代码实现

### 方法一：拓扑排序（BFS）（推荐）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findAllRecipes(self, recipes: List[str], ingredients: List[List[str]], supplies: List[str]) -> List[str]:
        # 建图：ingredient -> 依赖它的菜
        graph = defaultdict(list)
        # 每道菜的"未满足原料数"（入度）
        in_degree = {}
        recipe_set = set(recipes)

        for i, recipe in enumerate(recipes):
            in_degree[recipe] = len(ingredients[i])
            for ing in ingredients[i]:
                graph[ing].append(recipe)

        # 初始可用原料加入队列
        queue = deque(supplies)
        available = set(supplies)
        result = []

        while queue:
            item = queue.popleft()
            # 若当前 item 是一道菜，加入结果
            if item in recipe_set:
                result.append(item)
            # 减少依赖 item 的菜的入度
            for dependent in graph[item]:
                in_degree[dependent] -= 1
                if in_degree[dependent] == 0:
                    # 所有原料已满足，可以制作
                    queue.append(dependent)

        return result
```

### 方法二：DFS + 记忆化

```python
from typing import List

class Solution:
    def findAllRecipes(self, recipes: List[str], ingredients: List[List[str]], supplies: List[str]) -> List[str]:
        # 建立菜到原料的映射
        recipe_map = {r: ing for r, ing in zip(recipes, ingredients)}
        available = set(supplies)
        # 0: 未访问, 1: 访问中（检测循环）, 2: 可制作
        state = {}

        def can_make(item: str) -> bool:
            if item in available:
                return True
            if item not in recipe_map:
                return False  # 非菜且不在 supplies 中
            if item in state:
                return state[item] == 2
            state[item] = 1  # 标记为访问中
            for ing in recipe_map[item]:
                if state.get(ing) == 1:  # 循环依赖
                    state[item] = 0
                    return False
                if not can_make(ing):
                    state[item] = 0
                    return False
            state[item] = 2
            available.add(item)
            return True

        return [r for r in recipes if can_make(r)]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS 拓扑排序 | O(V + E) | O(V + E) |
| DFS 记忆化 | O(V + E) | O(V + E) |

## 关键点总结

1. 菜品依赖关系是 DAG，用拓扑排序（BFS）处理依赖链。
2. 初始 supplies 中的原料作为 BFS 的起点（入度为 0）。
3. 每道菜的"入度"是其原料数，原料被满足则入度减一，减为 0 时可制作。

## 易错点

- 循环依赖：若菜 A 的原料需要菜 B，菜 B 又需要菜 A，则两者都无法制作。BFS 拓扑排序天然处理循环（入度永远不为 0，不会进入队列）。
- DFS 方法需要用 visiting 标记避免死循环。
