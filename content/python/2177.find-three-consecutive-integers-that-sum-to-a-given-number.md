## 题目描述

给你一个整数 `num`，返回三个连续整数，它们之和等于 `num`。若存在，返回其中最小的整数（三者升序）；若不存在，返回空数组。

**示例 1：**
```
输入：num = 33
输出：[10,11,12]
解释：10+11+12=33，最小值 10。
```

**示例 2：**
```
输入：num = 4
输出：[]
解释：不存在三个连续整数之和为 4（1+2+3=6，-1+0+1=0，...）。
```

**提示：**
- `0 <= num <= 10^15`

## 解题思路

**数学**

设三个连续整数为 `n-1, n, n+1`，则它们的和为 `3n`。

所以 `num` 必须能被 3 整除，否则返回空数组。

若 `num % 3 == 0`，则 `n = num // 3`，三个整数为 `n-1, n, n+1`。

## 代码实现

### 方法一：数学（推荐）

```python
from typing import List

class Solution:
    def sumOfThree(self, num: int) -> List[int]:
        if num % 3 != 0:
            return []
        n = num // 3
        return [n - 1, n, n + 1]
```

### 方法二：验证版

```python
from typing import List

class Solution:
    def sumOfThree(self, num: int) -> List[int]:
        # 三个连续整数之和 = 3 * 中间数
        if num % 3 != 0:
            return []
        mid = num // 3
        # 验证
        assert (mid - 1) + mid + (mid + 1) == num
        return [mid - 1, mid, mid + 1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学 | O(1) | O(1) |

## 关键点总结

1. `(n-1) + n + (n+1) = 3n`，所以 num 必须被 3 整除。
2. 若整除，中间数 `n = num // 3`，结果为 `[n-1, n, n+1]`。
3. 最简洁的一道数学题，O(1) 解决。

## 易错点

- 注意 `num` 可以很大（10^15），但 Python 整数无溢出问题。
- 返回值是升序的三个整数，最小的是 `n - 1`。
