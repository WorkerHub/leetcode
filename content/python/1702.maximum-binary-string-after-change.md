## 题目描述

给你一个二进制字符串 `binary`，可以无限次执行以下两种操作之一：
- 操作 1：如果字符串包含子字符串 `"00"`，可以将其替换为 `"10"`
- 操作 2：如果字符串包含子字符串 `"10"`，可以将其替换为 `"01"`

返回执行上述操作后可以得到的**最大二进制字符串**。

**示例 1：**
```
输入：binary = "000110"
输出："111011"
```

**示例 2：**
```
输入：binary = "01"
输出："01"
```

**提示：**
- `1 <= binary.length <= 10^5`
- `binary` 只包含 `'0'` 和 `'1'`

## 解题思路

关键观察：
1. 操作 2 可以把 `10` 变成 `01`，本质上是把 `1` 向右移动，不改变 `1` 的数量
2. 操作 1 可以把 `00` 变成 `10`，会增加一个 `1`
3. 最终结果中，最多只有一个 `0`，且这个 `0` 的位置可以通过操作决定

贪心策略：
- 最终字符串形如 `111...1011...1`，即只有一个 `0` 在某个位置
- 前导的 `1` 不能移动（无法改变）
- 从第一个 `0` 开始统计后面所有的 `0` 的数量，最终能把这些 `0` 变成若干个 `1` 加上一个 `0`
- 最后那个 `0` 的位置 = 前导 `1` 的数量 + 后面 `0` 的数量 - 1

## 代码实现

### 方法一：贪心构造（推荐）

```python
class Solution:
    def maximumBinaryString(self, binary: str) -> str:
        n = len(binary)
        
        # 统计第一个0之前有多少个1（前导1不可移动）
        first_zero = binary.find('0')
        
        # 如果没有0，字符串已经是最大的
        if first_zero == -1:
            return binary
        
        # 统计从第一个0开始，后面所有的0的数量
        zero_count = binary.count('0', first_zero)
        
        # 最终结果：前面 first_zero 个1，然后 zero_count-1 个1，然后一个0，最后全是1
        # 唯一的0的位置是 first_zero + zero_count - 1
        result = ['1'] * n
        result[first_zero + zero_count - 1] = '0'
        
        return ''.join(result)
```

### 方法二：模拟思路，手动推导

```python
class Solution:
    def maximumBinaryString(self, binary: str) -> str:
        n = len(binary)
        # 转为列表便于理解
        chars = list(binary)
        
        # 找到第一个0的位置
        first_zero = -1
        for i in range(n):
            if chars[i] == '0':
                first_zero = i
                break
        
        if first_zero == -1:
            return binary
        
        # 统计第一个0之后（包含）的所有0
        zero_count = 0
        for i in range(first_zero, n):
            if chars[i] == '0':
                zero_count += 1
        
        # 构造答案：前 first_zero 个1不变
        # 然后 zero_count-1 个1（由 00 -> 10 操作产生）
        # 最后一个0放在 first_zero + zero_count - 1 处
        # 剩余全是1
        result = ['1'] * n
        result[first_zero + zero_count - 1] = '0'
        
        return ''.join(result)
```

## 复杂度分析

- **时间复杂度**：O(n)，统计和构造均为线性
- **空间复杂度**：O(n)，存储结果字符串

## 关键点总结

1. 前导的 `1` 无法通过任何操作改变位置
2. 后续所有的 `0`（连同夹在其中的 `1`）都可以通过操作合并，最终留下一个 `0`
3. 最终只有一个 `0`，位置在 `first_zero + zero_count - 1`

## 易错点

- 字符串全为 `1` 时直接返回，不要越界访问
- `zero_count` 要从第一个 `0` 的位置开始统计，而不是从头开始
