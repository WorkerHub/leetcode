## 题目描述

给你一个整数 `n`，代表一条街的长度（位置 0 到 n-1），以及一个二维整数数组 `lights`，其中 `lights[i] = [position_i, range_i]`，表示位置 `position_i` 有一盏灯，覆盖范围为左右各 `range_i`（即覆盖 `[position_i - range_i, position_i + range_i]`）。

另有一个整数数组 `requirement`，`requirement[j]` 表示位置 `j` 所需的最低亮度。

如果位置 `j` 的实际亮度（覆盖它的灯的数量）>= `requirement[j]`，则位置 `j` 满足条件。

返回满足条件的位置数量。

**示例：**
```
输入：n = 5, lights = [[0,1],[2,1],[3,2]], requirement = [0,2,1,4,1]
输出：4
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= lights.length <= 10^5`
- `0 <= position_i < n`
- `0 <= range_i <= 10^5`
- `requirement.length == n`

## 解题思路

**差分数组（前缀和）：** 每盏灯对区间 `[l, r]` 的亮度贡献 +1，用差分数组处理区间更新。

1. 初始化差分数组 `diff` 大小为 `n+1`。
2. 对每盏灯：`diff[max(0, pos-r)] += 1`，`diff[min(n, pos+r+1)] -= 1`。
3. 求前缀和得到每个位置的实际亮度。
4. 统计满足 `brightness[j] >= requirement[j]` 的位置数。

## 代码实现

### 方法一：差分数组（推荐）

```python
from typing import List

class Solution:
    def meetRequirement(self, n: int, lights: List[List[int]], requirement: List[int]) -> int:
        # 差分数组
        diff = [0] * (n + 1)

        for pos, rng in lights:
            # 灯覆盖 [pos-rng, pos+rng]，限制在 [0, n-1]
            left = max(0, pos - rng)
            right = min(n - 1, pos + rng)
            diff[left] += 1
            diff[right + 1] -= 1

        # 还原亮度数组（前缀和）
        brightness = 0
        ans = 0
        for i in range(n):
            brightness += diff[i]
            if brightness >= requirement[i]:
                ans += 1

        return ans
```

### 方法二：暴力（对比理解）

```python
from typing import List

class Solution:
    def meetRequirement(self, n: int, lights: List[List[int]], requirement: List[int]) -> int:
        # 暴力：计算每个位置的亮度
        brightness = [0] * n
        for pos, rng in lights:
            for j in range(max(0, pos - rng), min(n, pos + rng + 1)):
                brightness[j] += 1

        return sum(1 for i in range(n) if brightness[i] >= requirement[i])
```

## 复杂度分析

**方法一（差分数组）：**
- 时间复杂度：O(m + n)，m 为灯的数量，n 为街道长度。
- 空间复杂度：O(n)，差分数组。

**方法二（暴力）：**
- 时间复杂度：O(m * max_range + n)，可能超时。
- 空间复杂度：O(n)。

## 关键点总结

1. 区间更新问题用差分数组，O(1) 完成一次区间更新。
2. 对差分数组求前缀和还原每个位置的实际亮度。
3. 注意灯的覆盖范围要限制在 `[0, n-1]` 内。

## 易错点

- 差分数组大小为 `n+1`（最后一个位置需要右边界 `n`）。
- `right + 1` 的 `-1` 操作，若 `right = n-1`，则 `diff[n] -= 1`，需确保数组够大。
