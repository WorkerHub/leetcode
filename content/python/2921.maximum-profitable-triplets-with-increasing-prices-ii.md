## 题目描述

给你两个下标从 0 开始的整数数组 `prices` 和 `profits`，长度均为 `n`。

找出满足 `prices[i] < prices[j] < prices[k]`（i < j < k）的三元组，最大化 `profits[i] + profits[j] + profits[k]`。

若不存在，返回 `-1`。

**示例：**
```
输入：prices = [10,2,3,4], profits = [100,2,7,10]
输出：19
```

**提示：**
- `3 <= n <= 5 * 10^4`
- `1 <= prices[i] <= 5 * 10^4`
- `1 <= profits[i] <= 10^6`
- `prices` 中元素两两不同

## 解题思路

与 2907 题相同，但 n 达到 5 * 10^4，需要 O(n log n) 解法。

使用两个树状数组：
- `left_bit`：维护在价格 < prices[j] 范围内的最大利润
- `right_bit`：维护在价格 > prices[j] 范围内的最大利润

枚举中间元素 j：
1. 从 left_bit 查询价格 < prices[j] 的最大 profits[i]
2. 从 right_bit 查询价格 > prices[j] 的最大 profits[k]
3. 计算三者之和

树状数组存储每个价格对应的最大利润，支持单点更新和前缀最大值查询。

## Python 代码实现

### 方法一：树状数组（推荐）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], profits: List[int]) -> int:
        n = len(prices)
        max_price = max(prices)

        # 树状数组：支持单点更新（取最大），前缀最大值查询
        bit = [0] * (max_price + 2)

        def update(i, val):
            while i <= max_price:
                bit[i] = max(bit[i], val)
                i += i & (-i)

        def query(i):
            # 查询 [1, i] 的最大值
            res = 0
            while i > 0:
                res = max(res, bit[i])
                i -= i & (-i)
            return res

        # left_max[j] = 价格严格小于 prices[j] 且在 j 左侧的最大利润
        left_max = [0] * n
        # 从左到右处理
        left_bit = [0] * (max_price + 2)

        def update_l(i, val):
            while i <= max_price:
                left_bit[i] = max(left_bit[i], val)
                i += i & (-i)

        def query_l(i):
            res = 0
            while i > 0:
                res = max(res, left_bit[i])
                i -= i & (-i)
            return res

        for j in range(n):
            # 查询价格 < prices[j] 的最大利润
            left_max[j] = query_l(prices[j] - 1)
            # 将当前加入
            update_l(prices[j], profits[j])

        # right_max[j] = 价格严格大于 prices[j] 且在 j 右侧的最大利润
        right_max = [0] * n
        right_bit = [0] * (max_price + 2)

        def update_r(i, val):
            # 前缀最大：对"后缀最大"需要逆序
            # 将价格 p 映射到 max_price + 1 - p，使后缀最大变前缀最大
            i = max_price + 1 - i
            while i <= max_price:
                right_bit[i] = max(right_bit[i], val)
                i += i & (-i)

        def query_r(i):
            # 查询价格 > i 的最大值 = 查询映射后 [1, max_price - i] 的最大值
            i = max_price - i
            res = 0
            while i > 0:
                res = max(res, right_bit[i])
                i -= i & (-i)
            return res

        for j in range(n - 1, -1, -1):
            right_max[j] = query_r(prices[j])
            update_r(prices[j], profits[j])

        ans = -1
        for j in range(n):
            if left_max[j] > 0 and right_max[j] > 0:
                ans = max(ans, left_max[j] + profits[j] + right_max[j])

        return ans
```

### 方法二：线段树（标准实现）

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int], profits: List[int]) -> int:
        n = len(prices)
        max_p = max(prices)

        # 线段树（区间最大值）
        tree = [0] * (4 * (max_p + 1))

        def update(node, start, end, idx, val):
            if start == end:
                tree[node] = max(tree[node], val)
                return
            mid = (start + end) // 2
            if idx <= mid:
                update(2 * node, start, mid, idx, val)
            else:
                update(2 * node + 1, mid + 1, end, idx, val)
            tree[node] = max(tree[2 * node], tree[2 * node + 1])

        def query(node, start, end, l, r):
            if r < start or end < l:
                return 0
            if l <= start and end <= r:
                return tree[node]
            mid = (start + end) // 2
            return max(query(2 * node, start, mid, l, r),
                       query(2 * node + 1, mid + 1, end, l, r))

        # 正向遍历得 left_max
        left_max = []
        for j in range(n):
            lm = query(1, 1, max_p, 1, prices[j] - 1) if prices[j] > 1 else 0
            left_max.append(lm)
            update(1, 1, max_p, prices[j], profits[j])

        # 反向遍历得 right_max
        tree2 = [0] * (4 * (max_p + 1))

        def update2(node, start, end, idx, val):
            if start == end:
                tree2[node] = max(tree2[node], val)
                return
            mid = (start + end) // 2
            if idx <= mid:
                update2(2 * node, start, mid, idx, val)
            else:
                update2(2 * node + 1, mid + 1, end, idx, val)
            tree2[node] = max(tree2[2 * node], tree2[2 * node + 1])

        def query2(node, start, end, l, r):
            if r < start or end < l:
                return 0
            if l <= start and end <= r:
                return tree2[node]
            mid = (start + end) // 2
            return max(query2(2 * node, start, mid, l, r),
                       query2(2 * node + 1, mid + 1, end, l, r))

        right_max = [0] * n
        for j in range(n - 1, -1, -1):
            rm = query2(1, 1, max_p, prices[j] + 1, max_p)
            right_max[j] = rm
            update2(1, 1, max_p, prices[j], profits[j])

        ans = -1
        for j in range(n):
            if left_max[j] > 0 and right_max[j] > 0:
                ans = max(ans, left_max[j] + profits[j] + right_max[j])
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log P)，P 为最大价格
- 空间复杂度：O(P)，树状数组/线段树大小

## 关键点总结

1. 树状数组/线段树支持"前缀最大值"查询：不同于区间求和，需要特殊处理
2. 后缀最大值可以通过坐标翻转（`max_price - price`）转换为前缀最大值
3. 枚举中间元素，配合预处理的左右最大利润计算答案

## 易错点

1. 树状数组维护最大值时，更新操作取 max（不是加法）
2. 查询"价格严格小于 p"：查询范围 [1, p-1]
3. profits 非负，初始化为 0 表示"无合法前驱"
