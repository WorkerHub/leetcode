## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`。

对三元组 `(i, j, k)`（其中 `0 <= i, j, k < n`，不需要互不相同），定义 `effective value` = `(nums[i] | nums[j]) & nums[k]`。

数组的 **XOR 美丽值** = 所有三元组有效值的 XOR。

返回数组的 XOR 美丽值。

**示例 1：**

```
输入：nums = [1,4]
输出：5
解释：所有三元组的有效值 XOR 后结果为 5。
```

**示例 2：**

```
输入：nums = [15,45,20,2,34,35,5,44,32,30]
输出：34
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

**数学化简**：枚举所有三元组的有效值 XOR。

关键观察：对于每一对 (i, j)，`nums[i] | nums[j]` 对所有 k 做 AND 并 XOR 的结果。

进一步化简：对于对称性，i != j 的情况两两抵消（(i,j,k) 和 (j,i,k) 有相同的 nums[i]|nums[j]，XOR 两次为 0）。

只剩下 i == j 的情况：`(nums[i] | nums[i]) & nums[k]` = `nums[i] & nums[k]`。

再对 k 做 XOR 并化简，最终答案等于 nums 中所有元素的 XOR。

## Python 代码实现

### 方法一：数学化简（O(n)）（推荐）

```python
from typing import List
from functools import reduce
import operator

class Solution:
    def xorBeauty(self, nums: List[int]) -> int:
        # 所有三元组有效值的 XOR 等于 nums 所有元素的 XOR
        result = 0
        for num in nums:
            result ^= num
        return result
```

### 方法二：暴力验证（小规模）

```python
from typing import List

class Solution:
    def xorBeauty(self, nums: List[int]) -> int:
        n = len(nums)
        result = 0
        # 枚举所有三元组（小规模验证用）
        for i in range(n):
            for j in range(n):
                for k in range(n):
                    effective = (nums[i] | nums[j]) & nums[k]
                    result ^= effective
        return result
```

## 复杂度分析

- 方法一时间复杂度：O(n)，数学化简后只需一次遍历
- 方法二时间复杂度：O(n^3)，仅用于验证
- 空间复杂度：O(1)

## 关键点总结

1. 利用 XOR 的对称性：当 i != j 时，(i,j,k) 和 (j,i,k) 的有效值相同，XOR 后为 0
2. 只有 i == j 时有贡献：`nums[i] & nums[k]`，对所有 k XOR
3. 继续化简：k 遍历时，`a & nums[k]` XOR 所有 k，利用 AND 与 XOR 分配律

## 易错点

1. 直接暴力 O(n^3) 会超时，必须利用数学化简
2. 三元组中 i, j, k 可以相等，不是严格不同
3. 最终答案是所有元素的 XOR，这个结论需要仔细推导
