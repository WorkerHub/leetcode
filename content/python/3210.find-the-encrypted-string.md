## 题目描述

给你一个字符串 `s` 和一个整数 `k`，通过将 `s` 中每个字符替换为其在字母表中**后面第 `k` 个字符**来加密字符串（循环处理）。

返回加密后的字符串。

**示例 1：**
```
输入：s = "dart", k = 3
输出："jxuw"
解释：
d -> g (后3位)... 不对，重新：
'd' + 3 = 'g', 'a' + 3 = 'd', 'r' + 3 = 'u', 't' + 3 = 'w'
输出："gduw"
```

**示例 2：**
```
输入：s = "aaa", k = 1
输出："bbb"
```

**提示：**
- `1 <= s.length <= 100`
- `1 <= k <= 10^4`
- `s` 只包含小写英文字母

## 解题思路

对字符串中每个字符，将其 ASCII 值加上 `k`，再对 26 取模，保证在 a-z 范围内。

## Python 代码实现

### 方法一：逐字符处理（推荐）

```python
class Solution:
    def getEncryptedString(self, s: str, k: int) -> str:
        result = []
        for c in s:
            # 计算在字母表中的位置（0-25）
            pos = ord(c) - ord('a')
            # 向后移动 k 位，循环处理
            new_pos = (pos + k) % 26
            result.append(chr(new_pos + ord('a')))
        return ''.join(result)
```

### 方法二：列表推导式

```python
class Solution:
    def getEncryptedString(self, s: str, k: int) -> str:
        k = k % 26  # 简化 k
        return ''.join(
            chr((ord(c) - ord('a') + k) % 26 + ord('a'))
            for c in s
        )
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(n)，存储结果字符串

## 关键点总结

1. 用 `(pos + k) % 26` 实现循环移位
2. 先将 `k` 对 26 取模可以简化计算

## 易错点

1. k 可能大于 26，需要先取模
2. 字符的位置从 0 开始（'a' = 0, 'z' = 25）
