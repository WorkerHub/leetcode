## 题目描述

二指输入法定制键盘在 `XY` 平面上的布局如下图所示，其中每个大写英文字母都位于某个坐标处：

```
A(0,0) B(0,1) C(0,2) D(0,3) E(0,4) F(0,5)
G(1,0) H(1,1) I(1,2) J(1,3) K(1,4) L(1,5)
M(2,0) N(2,1) O(2,2) P(2,3) Q(2,4) R(2,5)
S(3,0) T(3,1) U(3,2) V(3,3) W(3,4) X(3,5)
Y(4,0) Z(4,1)
```

两根手指的起始位置是零代价的，不计入距离。每次移动手指时，代价为两点的曼哈顿距离：`|row1 - row2| + |col1 - col2|`。

给你一个字符串 `word`，返回使用两根手指输入 `word` 中所有字符的最小移动总距离。

**示例 1：**

```
输入：word = "CAKE"
输出：3
解释：
使用两根手指输入 "CAKE" 的最佳方案之一是：
手指 1 在字母 'C' 上 -> 代价 = 0
手指 1 在字母 'A' 上 -> 代价 = dist('C', 'A') = 2
手指 2 在字母 'K' 上 -> 代价 = 0
手指 2 在字母 'E' 上 -> 代价 = dist('K', 'E') = 1
总代价 = 3
```

**示例 2：**

```
输入：word = "HAPPY"
输出：6
```

**提示：**

- `2 <= word.length <= 300`
- `word` 仅由大写英文字母组成

## 解题思路

**动态规划（DP）**

**状态定义：**

`dp[i][j]` = 已经输入了 `word[0..i]`，其中一只手指在 `word[i]` 上，另一只手指在字母 `j` 上（用 0-25 表示 A-Z，用 26 表示"还未放置"）时的最小总移动距离。

**转移分析：**

对于第 `i+1` 个字符 `word[i+1]`，我们有两种选择：

1. **移动当前手指（在 word[i] 上的手指）**：从 `word[i]` 移到 `word[i+1]`
   - `dp[i+1][j] = min(dp[i+1][j], dp[i][j] + dist(word[i], word[i+1]))`

2. **移动另一只手指（在 j 上的手指）**：从 `j` 移到 `word[i+1]`
   - `dp[i+1][word[i]] = min(..., dp[i][j] + dist(j, word[i+1]))`（另一只手指现在在 word[i]）
   - 当 j = 26（未放置）时，dist = 0

**注意：** 状态压缩为二维：处理第 i 个字符后，一只手在 word[i]，另一只在 j。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def minimumDistance(self, word: str) -> int:
        n = len(word)
        
        def dist(a: int, b: int) -> int:
            # 计算字母 a 和 b 之间的曼哈顿距离
            # 26 表示"未放置"，移动代价为 0
            if a == 26:
                return 0
            row_a, col_a = a // 6, a % 6
            row_b, col_b = b // 6, b % 6
            return abs(row_a - row_b) + abs(col_a - col_b)
        
        # dp[j] 表示：一只手在 word[i]（当前字符），另一只手在字母 j 时的最小代价
        # j = 26 表示另一只手还未放置
        INF = float('inf')
        dp = [INF] * 27
        dp[26] = 0  # 初始状态：两只手都未放置，代价为 0
        
        for i in range(n - 1):
            curr = ord(word[i]) - ord('A')
            nxt = ord(word[i + 1]) - ord('A')
            new_dp = [INF] * 27
            
            for j in range(27):
                if dp[j] == INF:
                    continue
                # 选择1：移动"当前手指"（在 word[i] 上的）去打 word[i+1]
                # 另一只手仍在 j
                cost1 = dp[j] + dist(curr, nxt)
                if cost1 < new_dp[j]:
                    new_dp[j] = cost1
                
                # 选择2：移动"另一只手指"（在 j 上的）去打 word[i+1]
                # 当前手指仍在 word[i]，变为新的"另一只手"
                cost2 = dp[j] + dist(j, nxt)
                if cost2 < new_dp[curr]:
                    new_dp[curr] = cost2
            
            dp = new_dp
        
        return min(dp)
```

### 方法二：记忆化搜索（自顶向下）

```python
from functools import lru_cache

class Solution:
    def minimumDistance(self, word: str) -> int:
        n = len(word)
        
        def dist(a: int, b: int) -> int:
            if a == 26:
                return 0
            return abs(a // 6 - b // 6) + abs(a % 6 - b % 6)
        
        @lru_cache(maxsize=None)
        def dp(i: int, other: int) -> int:
            # 已经输入 word[0..i-1]，下一个要输入 word[i]
            # 一只手在 word[i-1]（或未放置），另一只手在 other
            if i == n:
                return 0
            
            curr_char = ord(word[i]) - ord('A')
            prev_char = ord(word[i - 1]) - ord('A') if i > 0 else 26
            
            # 选择1：移动当前手指到 word[i]
            # 当前手指从 prev_char 移动到 curr_char，另一只手在 other
            move_current = dist(prev_char, curr_char) + dp(i + 1, other)
            
            # 选择2：移动另一只手到 word[i]
            # 另一只手从 other 移动到 curr_char，当前手指停在 prev_char
            move_other = dist(other, curr_char) + dp(i + 1, prev_char)
            
            return min(move_current, move_other)
        
        return dp(0, 26)  # 初始：两只手都未放置
```

### 方法三：完整自底向上 DP（三维状态，更清晰）

```python
class Solution:
    def minimumDistance(self, word: str) -> int:
        n = len(word)
        
        def dist(a: int, b: int) -> int:
            if a == 26 or b == 26:
                return 0
            return abs(a // 6 - b // 6) + abs(a % 6 - b % 6)
        
        # dp[i][j] = 输入到 word[i]，另一只手在 j 时的最小代价
        INF = float('inf')
        
        # 初始化第一个字符
        dp = [INF] * 27
        first = ord(word[0]) - ord('A')
        # 输入第一个字符代价为0，一只手在 word[0]，另一只手在 26（未放置）
        dp[26] = 0
        
        for i in range(1, n):
            curr = ord(word[i]) - ord('A')
            prev = ord(word[i - 1]) - ord('A')
            new_dp = [INF] * 27
            
            for j in range(27):
                if dp[j] == INF:
                    continue
                # 移动当前手（在 prev）去打 curr
                val = dp[j] + dist(prev, curr)
                new_dp[j] = min(new_dp[j], val)
                
                # 移动另一手（在 j）去打 curr，当前手保持在 prev
                val = dp[j] + dist(j, curr)
                new_dp[prev] = min(new_dp[prev], val)
            
            dp = new_dp
        
        return min(dp)
```

## 复杂度分析

- **时间复杂度**：O(n * 27)，n 为 word 长度，每个位置枚举另一只手的 27 种状态
- **空间复杂度**：O(27) = O(1)，滚动数组优化后只需常数空间

## 关键点总结

1. 状态设计：`dp[j]` 表示"一手在当前字符，另一手在 j"的最小代价
2. j=26 代表"另一只手还没有放置"，此时移动代价为 0
3. 每次转移有两种选择：移动"当前手"或移动"另一只手"
4. 键盘布局：字母 x 的坐标为 `(x//6, x%6)`（x 是 0-25 的整数）

## 易错点

1. **键盘布局**：每行 6 个字母（A-F, G-L, M-R, S-X, Y-Z），字母 x 的行为 `x//6`，列为 `x%6`
2. **未放置手指的距离为 0**：初始状态两只手都未放置，第一次放置不计代价
3. **DP 滚动**：必须先用 `new_dp` 保存更新结果，不能在同一个 `dp` 数组上就地更新
