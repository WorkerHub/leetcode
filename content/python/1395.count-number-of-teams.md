## 题目描述

`n` 名士兵站成一排。每位士兵都有一个**独一无二**的评分 `rating`。

每**3**名士兵可以组成一个团队，如果这3个士兵的评分 `(rating[i], rating[j], rating[k])` 满足：

- `rating[i] < rating[j] < rating[k]`，或者
- `rating[i] > rating[j] > rating[k]`

其中 `0 <= i < j < k < n`，则称他们为一个有效团队。

请你返回按上述条件可以组建的**有效团队数**。

**示例 1：**

```
输入：rating = [2,5,3,4,1]
输出：3
解释：我们可以组建三个团队 (2,3,4)、(2,5,3)、(2,5,4)。
```

**示例 2：**

```
输入：rating = [2,1,3]
输出：0
解释：没有有效的团队。
```

**示例 3：**

```
输入：rating = [1,2,3,4]
输出：4
```

**提示：**

- `n == rating.length`
- `3 <= n <= 1000`
- `1 <= rating[i] <= 10^5`
- `rating` 中的元素**互不相同**

## 解题思路

**枚举中间元素 j：** 对于每个位置 j，统计：
- 左侧比 `rating[j]` 小的元素个数 `left_less`
- 左侧比 `rating[j]` 大的元素个数 `left_greater`
- 右侧比 `rating[j]` 小的元素个数 `right_less`
- 右侧比 `rating[j]` 大的元素个数 `right_greater`

则以 j 为中间元素的有效团队数为：
- 递增三元组：`left_less * right_greater`
- 递减三元组：`left_greater * right_less`

**为什么枚举中间元素？** 因为中间元素确定后，左右两侧满足条件的元素可以任意组合，用乘法原理直接计算。

## Python 代码实现

### 方法一：枚举中间元素 O(n^2)（推荐）

```python
from typing import List

class Solution:
    def numTeams(self, rating: List[int]) -> int:
        n = len(rating)
        count = 0

        # 枚举中间元素的位置 j
        for j in range(1, n - 1):
            # 统计左侧比 rating[j] 小/大的元素个数
            left_less = 0     # 左侧比 rating[j] 小的数量
            left_greater = 0  # 左侧比 rating[j] 大的数量
            for i in range(j):
                if rating[i] < rating[j]:
                    left_less += 1
                elif rating[i] > rating[j]:
                    left_greater += 1

            # 统计右侧比 rating[j] 小/大的元素个数
            right_less = 0     # 右侧比 rating[j] 小的数量
            right_greater = 0  # 右侧比 rating[j] 大的数量
            for k in range(j + 1, n):
                if rating[k] > rating[j]:
                    right_greater += 1
                elif rating[k] < rating[j]:
                    right_less += 1

            # 递增三元组：左小 * 右大；递减三元组：左大 * 右小
            count += left_less * right_greater + left_greater * right_less

        return count
```

### 方法二：暴力枚举 O(n^3)（仅用于理解）

```python
from typing import List

class Solution:
    def numTeams(self, rating: List[int]) -> int:
        n = len(rating)
        count = 0
        # 三重循环枚举所有三元组
        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                for k in range(j + 1, n):
                    if rating[i] < rating[j] < rating[k]:
                        count += 1
                    elif rating[i] > rating[j] > rating[k]:
                        count += 1
        return count
```

### 方法三：动态规划（进阶）

```python
from typing import List

class Solution:
    def numTeams(self, rating: List[int]) -> int:
        n = len(rating)
        # inc2[i]: 以 rating[i] 结尾的递增二元组数量
        # dec2[i]: 以 rating[i] 结尾的递减二元组数量
        inc2 = [0] * n
        dec2 = [0] * n
        count = 0

        for j in range(1, n):
            for i in range(j):
                if rating[i] < rating[j]:
                    inc2[j] += 1     # (i,j) 构成递增二元组
                    count += inc2[i] # 以 i 为中间的递增三元组
                elif rating[i] > rating[j]:
                    dec2[j] += 1     # (i,j) 构成递减二元组
                    count += dec2[i] # 以 i 为中间的递减三元组

        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（枚举中间） | O(n^2) | O(1) |
| 方法二（暴力） | O(n^3) | O(1) |
| 方法三（DP） | O(n^2) | O(n) |

n ≤ 1000，O(n^2) 完全满足要求（最多 10^6 次操作）。

## 图解示例

以 `rating = [2,5,3,4,1]` 为例，枚举中间元素 j=1（rating[j]=5）：

```
左侧：[2]，left_less=1（2<5），left_greater=0
右侧：[3,4,1]，right_greater=0（无>5的），right_less=3（3,4,1均<5）

以5为中间的团队数 = 1*0 + 0*3 = 0
```

枚举 j=2（rating[j]=3）：

```
左侧：[2,5]，left_less=1（2<3），left_greater=1（5>3）
右侧：[4,1]，right_greater=1（4>3），right_less=1（1<3）

以3为中间的团队数 = 1*1 + 1*1 = 2
```

## 关键点总结

1. 枚举中间元素 j，利用乘法原理：左边选一个、右边选一个
2. 递增三元组 = `left_less * right_greater`
3. 递减三元组 = `left_greater * right_less`
4. n ≤ 1000 时，O(n^2) 已经足够

## 易错点

- 枚举中间元素时，左侧范围是 `[0, j)`，右侧范围是 `(j, n)`，不要包含 j 本身
- 注意题目说评分互不相同，所以不用处理相等情况
- 递增和递减分别用不同的乘法组合，不要搞混
