## 题目描述

给你一个字符串 `s`，请你将该字符串分割成一个或多个 **子字符串**，使每个子字符串中的字符都是 **唯一** 的。也就是说，在单个子字符串中，字母的出现次数必须是一次。

返回满足要求的 **最少** 子字符串数目。

**示例 1：**
```
输入：s = "abacaba"
输出：4
解释：两种可能的最优方案均会将 s 分割成 4 个子字符串：
- "a","bac","ab","a"
- "ab","a","cab","a"
```

**示例 2：**
```
输入：s = "ssssss"
输出：6
解释：只能将 s 分割成 6 个子字符串，即每个子字符串包含一个字符 's'。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

**贪心思想**：尽可能延长当前子字符串（不到不得已不开启新分区），这样能保证总分区数最少。

**算法步骤：**
1. 维护一个集合 `seen`，记录当前子字符串中出现过的字符
2. 遍历每个字符：
   - 若字符已在 `seen` 中，开启新分区（重置 `seen`，计数加一）
   - 将字符加入 `seen`
3. 最后加一（最后一段子字符串也要计入）

**为什么贪心正确？** 每段尽量长，不会让后面的情况变差（因为新段总是从空集开始）。

## 代码实现

### 方法一：贪心 + 集合（推荐）

```python
class Solution:
    def partitionString(self, s: str) -> int:
        ans = 1       # 至少有一个分区
        seen = set()  # 当前分区中出现过的字符

        for ch in s:
            if ch in seen:
                # 当前字符重复，开启新分区
                ans += 1
                seen = set()  # 重置集合
            seen.add(ch)  # 将字符加入当前分区

        return ans
```

### 方法二：位运算优化（用整数代替集合）

```python
class Solution:
    def partitionString(self, s: str) -> int:
        ans = 1
        mask = 0  # 用 26 位整数表示当前分区中出现过的字母

        for ch in s:
            bit = 1 << (ord(ch) - ord('a'))
            if mask & bit:
                # 当前字符已出现，开启新分区
                ans += 1
                mask = 0
            mask |= bit  # 标记当前字符

        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 + 集合 | O(n) | O(1)（字母集大小固定为 26）|
| 位运算优化 | O(n) | O(1) |

## 关键点总结

1. 贪心：当前分区尽量延长，遇到重复才新开一段
2. 用集合或位掩码追踪当前分区中的字符
3. 初始化 `ans = 1`（空字符串本身算一个分区开始）

## 易错点

- 初始化 `ans = 1` 不是 0，因为最后一段分区不会触发 `ans += 1`
- 位运算方法中，位移量是 `ord(ch) - ord('a')` 而不是 `ord(ch)`
