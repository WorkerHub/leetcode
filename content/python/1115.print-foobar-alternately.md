## 题目描述

给定一个类 `FooBar`，其中有两个方法 `foo` 和 `bar`。两个不同的线程将会共用一个 `FooBar` 实例：

- 线程 A 将会调用 `foo()` 方法
- 线程 B 将会调用 `bar()` 方法

请设计修改程序，以确保 `foobar` 被输出 n 次。

**示例 1:**
```
输入: n = 1
输出: "foobar"
解释: 这里有两个线程被异步启动。其中一个调用 foo() 方法, 另一个调用 bar() 方法，"foobar" 将被输出一次。
```

**示例 2:**
```
输入: n = 2
输出: "foobarfoobar"
解释: "foobar" 将被输出两次。
```

## 解题思路

这是一道多线程同步问题，核心是控制两个线程的执行顺序，确保 `foo` 和 `bar` 交替执行。

**核心思想：**
1. 使用同步机制（锁、信号量等）控制线程执行顺序
2. `foo` 必须在 `bar` 之前执行
3. 每次循环都要保证先 foo 后 bar

**常用方法：**
- 使用 `threading.Lock()` 互斥锁
- 使用 `threading.Semaphore()` 信号量
- 使用 `threading.Event()` 事件标志

## Python 代码实现

### 方法一：使用信号量（推荐）

```python
from threading import Semaphore

class FooBar:
    def __init__(self, n: int):
        self.n = n
        # 信号量初始值：foo_sem=1 表示可以执行，bar_sem=0 表示需要等待
        self.foo_sem = Semaphore(1)
        self.bar_sem = Semaphore(0)

    def foo(self, printFoo: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.foo_sem.acquire()  # 获取 foo 信号量
            printFoo()              # 打印 "foo"
            self.bar_sem.release()  # 释放 bar 信号量，允许 bar 执行

    def bar(self, printBar: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.bar_sem.acquire()  # 等待 bar 信号量（等 foo 执行完）
            printBar()              # 打印 "bar"
            self.foo_sem.release()  # 释放 foo 信号量，允许下一轮 foo 执行
```

### 方法二：使用锁

```python
from threading import Lock

class FooBar:
    def __init__(self, n: int):
        self.n = n
        self.foo_lock = Lock()
        self.bar_lock = Lock()
        self.bar_lock.acquire()  # bar 锁初始为锁定状态

    def foo(self, printFoo: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.foo_lock.acquire()  # 获取 foo 锁
            printFoo()
            self.bar_lock.release()  # 释放 bar 锁

    def bar(self, printBar: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.bar_lock.acquire()  # 等待 bar 锁
            printBar()
            self.foo_lock.release()  # 释放 foo 锁
```

### 方法三：使用 Event

```python
from threading import Event

class FooBar:
    def __init__(self, n: int):
        self.n = n
        self.foo_event = Event()
        self.bar_event = Event()
        self.foo_event.set()  # foo 初始可以执行

    def foo(self, printFoo: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.foo_event.wait()   # 等待 foo 事件
            printFoo()
            self.foo_event.clear()  # 清除 foo 事件
            self.bar_event.set()    # 设置 bar 事件

    def bar(self, printBar: 'Callable[[], None]') -> None:
        for i in range(self.n):
            self.bar_event.wait()   # 等待 bar 事件
            printBar()
            self.bar_event.clear()  # 清除 bar 事件
            self.foo_event.set()    # 设置 foo 事件
```

## 复杂度分析

**时间复杂度：** O(n)
- 每个方法都执行 n 次，每次只有简单的同步操作

**空间复杂度：** O(1)
- 只使用了固定的同步对象

## 关键点总结

1. **信号量 vs 锁：** 信号量可以有计数值，锁只有锁定/未锁定两种状态
2. **初始状态很重要：** foo 应该先执行，所以 foo_sem=1, bar_sem=0
3. **acquire 和 release 配对：** 一个线程 release 的资源由另一个线程 acquire
4. **循环内部同步：** 每次循环都要保证顺序

## 易错点

1. **死锁问题：** 如果两个锁的初始状态都是锁定，会导致死锁
2. **信号量初始值：** 必须正确设置，否则无法保证执行顺序
3. **忘记释放资源：** acquire 后必须 release，否则会阻塞
4. **Event 的 wait/clear/set 顺序：** 必须先 wait，再操作，再 set
