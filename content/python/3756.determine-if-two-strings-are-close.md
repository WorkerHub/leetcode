## 题目描述

给定两个字符串 `word1` 和 `word2`，判断它们是否"接近"（close）。

两个字符串"接近"的条件：
1. 两个字符串的字符集合相同（包含的字母种类完全一样）
2. 两个字符串各字母频率的多重集相同（不要求频率对应的字母相同，只要频率列表相同即可）

本题与 LeetCode 1657 类似，但需要区分不同的判断标准。

**示例 1：**
```
输入：word1 = "abc", word2 = "bca"
输出：true
解释：两者字符集相同（{a,b,c}），频率都是 [1,1,1]，相同。
```

**示例 2：**
```
输入：word1 = "a", word2 = "aa"
输出：false
解释：长度不同，不接近。
```

**示例 3：**
```
输入：word1 = "cabbba", word2 = "abbccc"
输出：true
解释：字符集 {a,b,c} 相同，频率列表 {1,2,3} 相同（只是对应关系不同）。
```

**提示：**
- `1 <= word1.length, word2.length <= 10^5`
- 只含小写字母

## 解题思路

两个条件：
1. `set(word1) == set(word2)`（字符集相同）
2. `sorted(Counter(word1).values()) == sorted(Counter(word2).values())`（频率多重集相同）

## Python 代码实现

### 方法一：Counter 比较（推荐）

```python
from collections import Counter

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        cnt1 = Counter(word1)
        cnt2 = Counter(word2)

        # 条件 1：字符集相同
        if set(cnt1.keys()) != set(cnt2.keys()):
            return False

        # 条件 2：频率的多重集相同
        return sorted(cnt1.values()) == sorted(cnt2.values())
```

### 方法二：位掩码 + 排序

```python
from collections import Counter

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        c1, c2 = Counter(word1), Counter(word2)
        # 字符集用位掩码表示
        mask1 = sum(1 << (ord(c) - ord('a')) for c in c1)
        mask2 = sum(1 << (ord(c) - ord('a')) for c in c2)
        return mask1 == mask2 and sorted(c1.values()) == sorted(c2.values())
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序频率列表
- 空间复杂度：O(1)，字母表大小固定为 26

## 关键点总结

1. 两个条件缺一不可：字符集和频率多重集均需相同
2. 频率多重集比较：排序后对比，不需要知道具体对应关系
3. Python `Counter` 使问题非常简洁

## 易错点

1. 只检查频率排序不够，还需要检查字符集（如 "aa" 和 "bb" 频率相同但字符集不同）
2. 字符集检查用 `.keys()` 的集合
