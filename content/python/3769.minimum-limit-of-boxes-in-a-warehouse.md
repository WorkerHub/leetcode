## 题目描述

给定整数数组 `boxes`（每个盒子的重量）和整数数组 `warehouse`（每个仓库格子的承重上限）。将盒子放入仓库，每个格子最多放一个盒子，只能从左向右放入（通过所有左侧格子才能放入当前格子）。

求使得每个盒子都能被放置的最小化：将所有盒子放完后使用的仓库格子数。（即求最少需要多少格子）

本题与 LeetCode 1760 类似。

**示例 1：**
```
输入：boxes = [1,2,3], warehouse = [1,2,3,4,5]
输出：3
解释：将 3 个盒子分别放入格子 0,1,2，使用 3 个格子。
```

**提示：**
- `1 <= boxes.length <= 10^5`
- `1 <= warehouse.length <= 10^5`
- `1 <= boxes[i], warehouse[i] <= 10^9`

## 解题思路

二分查找：二分"使用的仓库格子数"。

若使用前 `m` 个格子，有效承重为 `min_prefix[i]`（第 `i` 格的有效承重 = `min(warehouse[0..i])`，因为盒子需要穿过所有左侧格子）。

贪心验证：将 `boxes` 从大到小排序，有效承重从大到小匹配，若所有盒子都能被匹配则 `m` 格足够。

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def minimumBoxes(self, boxes: List[int], warehouse: List[int]) -> int:
        n = len(warehouse)
        boxes_sorted = sorted(boxes, reverse=True)

        # 计算有效承重（每格的实际可放重量）
        effective = [0] * n
        effective[0] = warehouse[0]
        for i in range(1, n):
            effective[i] = min(effective[i-1], warehouse[i])

        def can_fit(m: int) -> bool:
            # 使用前 m 格，有效承重从大到小排序
            caps = sorted(effective[:m], reverse=True)
            for i, box in enumerate(boxes_sorted):
                if i >= len(caps) or caps[i] < box:
                    return False
            return True

        lo, hi = len(boxes), n
        if not can_fit(n):
            return -1  # 放不下

        while lo < hi:
            mid = (lo + hi) // 2
            if can_fit(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：贪心直接解

```python
from typing import List

class Solution:
    def minimumBoxes(self, boxes: List[int], warehouse: List[int]) -> int:
        # 计算每格有效承重
        n = len(warehouse)
        effective = warehouse[:]
        for i in range(1, n):
            effective[i] = min(effective[i-1], effective[i])

        # 贪心：从右往左放（让大盒子占据承重大的位置）
        boxes_sorted = sorted(boxes)
        caps_sorted = sorted(effective, reverse=True)

        count = 0
        j = 0
        for cap in caps_sorted:
            if j < len(boxes_sorted) and boxes_sorted[j] <= cap:
                j += 1
                count += 1
            if j == len(boxes_sorted):
                break

        return count if j == len(boxes_sorted) else -1
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序加线性扫描
- 空间复杂度：O(n)

## 关键点总结

1. 每格的有效承重 = 从左到该格的最小承重（盒子需穿越所有左侧格子）
2. 贪心：将最重的盒子放入承重最大的格子
3. 若所有盒子都能被匹配则可行

## 易错点

1. 有效承重是前缀最小值，而非仓库格子本身的承重
2. 若箱子总数超过仓库有效格子数，可能无法全部放下
