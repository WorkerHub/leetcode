## 题目描述

给你三个整数数组 `a`、`b`、`c`。

返回满足 `popcount(a[i] XOR b[j] XOR c[k])` 为偶数的三元组 `(i, j, k)` 的数量。

**注：** `popcount(x)` 表示 x 的二进制表示中 1 的个数。

**示例：**
```
输入：a = [1], b = [2], c = [3]
输出：1
解释：1 XOR 2 XOR 3 = 0，popcount(0) = 0（偶数），满足。
```

**提示：**
- `1 <= a.length, b.length, c.length <= 100`
- `0 <= a[i], b[j], c[k] <= 100`

## 解题思路

暴力枚举所有三元组，计算 XOR 后统计 1 的个数的奇偶性。

优化：`popcount(a XOR b XOR c)` 的奇偶性 = `popcount(a) XOR popcount(b) XOR popcount(c)` 的值。利用异或的性质，先统计每个数组中 popcount 为奇数和偶数的个数，再用组合数学计算。

## Python 代码实现

### 方法一：暴力枚举（推荐）

```python
from typing import List

class Solution:
    def countTriplets(self, a: List[int], b: List[int], c: List[int]) -> int:
        ans = 0
        for x in a:
            for y in b:
                for z in c:
                    if bin(x ^ y ^ z).count('1') % 2 == 0:
                        ans += 1
        return ans
```

### 方法二：利用奇偶性优化

```python
from typing import List

class Solution:
    def countTriplets(self, a: List[int], b: List[int], c: List[int]) -> int:
        # popcount 偶偶偶 和 奇奇偶 等奇偶组合
        def parity(x):
            return bin(x).count('1') % 2

        pa = [parity(x) for x in a]
        pb = [parity(x) for x in b]
        pc = [parity(x) for x in c]

        # 统计奇偶个数
        a0 = pa.count(0); a1 = pa.count(1)
        b0 = pb.count(0); b1 = pb.count(1)
        c0 = pc.count(0); c1 = pc.count(1)

        # popcount(a XOR b XOR c) 偶 当且仅当 parity(a) XOR parity(b) XOR parity(c) = 0
        # 即三者的奇偶性 XOR 为 0（偶偶偶 或 奇奇偶 或 偶奇奇 或 奇偶奇）
        return (a0 * b0 * c0 + a1 * b1 * c0 + a0 * b1 * c1 + a1 * b0 * c1)
```

## 复杂度分析

- 时间复杂度：O(n^3)（暴力），O(n)（优化）
- 空间复杂度：O(1)

## 关键点总结

1. XOR 的 popcount 奇偶性等于各个数 popcount 的 XOR
2. 三个数的奇偶 XOR 为 0：同为偶，或两奇一偶（但注意具体哪种）
3. 用乘法组合奇偶计数

## 易错点

1. popcount 偶数 XOR 偶数 = 偶数，奇数 XOR 奇数 = 偶数，偶 XOR 奇 = 奇
2. 三者奇偶 XOR = 0 的组合：偶偶偶、奇奇偶（顺序任意）共 4 种
