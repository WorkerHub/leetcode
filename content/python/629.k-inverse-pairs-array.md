## 题目描述

给定两个整数 `n` 和 `k`，找出所有包含从 `1` 到 `n` 的数字，且恰好拥有 `k` 个逆序对的不同的数组的个数。

逆序对的定义如下：对于数组的第 `i` 个和第 `j` 个元素，如果满足 `i < j` 且 `a[i] > a[j]`，则其为一个逆序对；否则不是。

由于答案可能很大，返回答案 mod 10^9 + 7。

**示例 1：**

```
输入：n = 3, k = 0
输出：1
解释：
只有数组 [1,2,3] 包含了从 1 到 3 的整数并且恰好拥有 0 个逆序对。
```

**示例 2：**

```
输入：n = 3, k = 1
输出：2
解释：
数组 [1,3,2] 和 [2,1,3] 都有 1 个逆序对。
- [1,3,2]: (3,2) 是逆序对
- [2,1,3]: (2,1) 是逆序对
```

**提示：**
- `1 <= n <= 1000`
- `0 <= k <= 1000`

## 解题思路

这是一道经典的动态规划问题。

**核心思想：**

定义 `dp[i][j]` 表示使用 `1` 到 `i` 的数字，恰好有 `j` 个逆序对的排列数量。

**状态转移：**

当我们在已有的 `i-1` 个数的排列中插入数字 `i` 时：
- 如果插入到最后，不增加逆序对（数字 `i` 最大）
- 如果插入到倒数第二个位置，增加 1 个逆序对
- 如果插入到第一个位置，增加 `i-1` 个逆序对

所以，对于 `dp[i][j]`，我们可以：
- 从 `dp[i-1][j]` 转移（插入到最后，0 个新逆序对）
- 从 `dp[i-1][j-1]` 转移（插入倒数第二，1 个新逆序对）
- ...
- 从 `dp[i-1][j-(i-1)]` 转移（插入到第一个，i-1 个新逆序对）

**状态转移方程：**

```
dp[i][j] = sum(dp[i-1][j-t]) for t in range(0, min(j, i-1) + 1)
```

但这样的时间复杂度是 O(n^2 * k)，需要优化。

**优化：前缀和**

观察到每次都是求连续区间的和，可以使用前缀和优化：

```
dp[i][j] = dp[i][j-1] + dp[i-1][j] - dp[i-1][j-i]（如果 j >= i）
```

这样时间复杂度降为 O(n * k)。

**边界条件：**
- `dp[0][0] = 1`（0 个数，0 个逆序对，只有一种方式：空排列）
- `dp[i][0] = 1`（任何 i 个数，0 个逆序对，只有一种方式：升序排列）

## Python 代码实现

### 方法一：动态规划 + 前缀和优化（推荐）

```python
class Solution:
    def kInversePairs(self, n: int, k: int) -> int:
        """
        计算恰好有 k 个逆序对的排列数量
        
        参数:
            n: 数字范围 1 到 n
            k: 逆序对数量
        
        返回:
            排列数量 mod 10^9+7
        """
        MOD = 10**9 + 7
        
        # dp[i][j] 表示使用 1~i 的数字，有 j 个逆序对的排列数
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        
        # 边界条件
        dp[0][0] = 1
        
        for i in range(1, n + 1):
            dp[i][0] = 1  # 0 个逆序对，只有升序排列
            
            for j in range(1, k + 1):
                # 利用前缀和优化
                dp[i][j] = (dp[i][j-1] + dp[i-1][j]) % MOD
                
                # 减去超出范围的部分
                if j >= i:
                    dp[i][j] = (dp[i][j] - dp[i-1][j-i]) % MOD
        
        return dp[n][k]
```

**时间复杂度：** O(n * k)  
**空间复杂度：** O(n * k)

### 方法二：空间优化到 O(k)

```python
class Solution:
    def kInversePairs(self, n: int, k: int) -> int:
        """
        空间优化版本，使用滚动数组
        """
        MOD = 10**9 + 7
        
        # 只需要两行：当前行和上一行
        prev = [0] * (k + 1)
        curr = [0] * (k + 1)
        prev[0] = 1
        
        for i in range(1, n + 1):
            curr[0] = 1
            
            for j in range(1, k + 1):
                curr[j] = (curr[j-1] + prev[j]) % MOD
                
                if j >= i:
                    curr[j] = (curr[j] - prev[j-i]) % MOD
            
            # 交换
            prev, curr = curr, prev
        
        return prev[k]
```

**时间复杂度：** O(n * k)  
**空间复杂度：** O(k)

### 方法三：未优化的动态规划（便于理解）

```python
class Solution:
    def kInversePairs(self, n: int, k: int) -> int:
        """
        未优化版本，时间复杂度 O(n^2 * k)
        仅用于理解状态转移
        """
        MOD = 10**9 + 7
        dp = [[0] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 1
        
        for i in range(1, n + 1):
            dp[i][0] = 1
            
            for j in range(1, k + 1):
                # 枚举插入位置产生的逆序对数
                for t in range(min(j, i - 1) + 1):
                    dp[i][j] = (dp[i][j] + dp[i-1][j-t]) % MOD
        
        return dp[n][k]
```

## 复杂度分析

**方法一、二（优化后）：**
- 时间复杂度：O(n * k)
- 空间复杂度：O(n * k) 或 O(k)

**方法三（未优化）：**
- 时间复杂度：O(n^2 * k)
- 空间复杂度：O(n * k)

## 图解示例

以 `n = 3, k = 1` 为例：

```
目标：找出 [1,2,3] 的排列中，恰好有 1 个逆序对的数量

动态规划表格：
dp[i][j] = 使用 1~i，有 j 个逆序对的数量

     j=0  j=1  j=2  j=3
i=0   1    0    0    0
i=1   1    0    0    0
i=2   1    1    0    0
i=3   1    2    2    1

解释 dp[3][1] = 2 的计算过程：
- 在 [1,2] 的排列中插入 3：
  - [1,2] 有 0 个逆序对，插入 3 到不同位置：
    * [3,1,2]: 2 个逆序对（超过）
    * [1,3,2]: 1 个逆序对 ✓
    * [1,2,3]: 0 个逆序对
  
  - [2,1] 有 1 个逆序对，插入 3：
    * [3,2,1]: 3 个逆序对（超过）
    * [2,3,1]: 2 个逆序对（超过）
    * [2,1,3]: 1 个逆序对 ✓

结果：[1,3,2] 和 [2,1,3]，共 2 种
```

**前缀和优化过程：**

```
计算 dp[3][1]：
dp[3][1] = dp[3][0] + dp[2][1] - dp[2][1-3]
         = dp[3][0] + dp[2][1]（因为 j-i < 0）
         = 1 + 1
         = 2
```

## 关键点总结

1. **状态定义清晰**：`dp[i][j]` 代表使用前 i 个数，恰好 j 个逆序对
2. **插入理解**：插入数字 i 到不同位置产生不同数量的逆序对
3. **前缀和优化**：将 O(n) 的状态转移优化到 O(1)
4. **取模操作**：每次计算后都要 mod，包括减法（可能为负）
5. **边界条件**：0 个逆序对总是只有 1 种方式（升序）

## 易错点

1. **取模后的负数**：在 Python 中 `-1 % MOD` 会得到正确结果，但其他语言需要注意
   ```python
   # 正确写法
   dp[i][j] = (dp[i][j] - dp[i-1][j-i]) % MOD
   # 或者
   dp[i][j] = (dp[i][j] - dp[i-1][j-i] + MOD) % MOD
   ```

2. **边界判断**：`j >= i` 时才减去 `dp[i-1][j-i]`

3. **初始化**：`dp[0][0] = 1` 和 `dp[i][0] = 1` 都要设置

4. **理解逆序对**：插入到第一个位置产生 `i-1` 个逆序对，不是 `i` 个

5. **空间优化时的数组交换**：要正确交换 prev 和 curr

## 数学推导

**为什么前缀和优化是正确的？**

```
dp[i][j] = sum(dp[i-1][j-t]) for t in [0, min(j, i-1)]

设 S[i][j] = sum(dp[i-1][0..j])（前缀和）

则：
dp[i][j] = S[i-1][j] - S[i-1][max(-1, j-i)]
         = S[i-1][j] - S[i-1][j-i-1]（当 j >= i 时）

而 S[i][j] = S[i][j-1] + dp[i-1][j]

所以：
dp[i][j] = dp[i][j-1] + dp[i-1][j] - dp[i-1][j-i]（当 j >= i）
```
