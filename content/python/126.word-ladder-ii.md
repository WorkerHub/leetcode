## 题目描述

按字典 `wordList` 完成从单词 `beginWord` 到单词 `endWord` 转化，一个表示此过程的转换序列是形如 `beginWord -> s1 -> s2 -> ... -> sk` 的单词序列，并满足：

- 每对相邻的单词之间仅有单个字母不同
- 转换过程中的每个单词 `si`（`1 <= i <= k`）必须是字典 `wordList` 中的单词。注意，`beginWord` 不必是字典 `wordList` 中的单词
- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord`，以及一个字典 `wordList`。请你找出并返回所有从 `beginWord` 到 `endWord` 的**最短转换序列**，如果不存在这样的转换序列，返回一个空列表。每个序列都应该以单词列表 `[beginWord, s1, s2, ..., sk]` 的形式返回。

**示例 1：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出: [["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]
解释: 存在 2 种最短的转换序列：
"hit" -> "hot" -> "dot" -> "dog" -> "cog"
"hit" -> "hot" -> "lot" -> "log" -> "cog"
```

**示例 2：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出: []
解释: endWord "cog" 不在字典 wordList 中，所以不存在符合要求的转换序列。
```

**提示：**
- `1 <= beginWord.length <= 5`
- `endWord.length == beginWord.length`
- `1 <= wordList.length <= 500`
- `wordList[i].length == beginWord.length`
- `beginWord`、`endWord` 和 `wordList[i]` 由小写英文字母组成
- `beginWord != endWord`
- `wordList` 中的所有单词互不相同

## 解题思路

这道题是 [127. 单词接龙](https://leetcode.com/problems/word-ladder/) 的进阶版，不仅要找到最短路径长度，还要**找出所有最短路径**。

核心思路：**BFS 建图 + DFS 回溯**

### 算法步骤：

1. **BFS 阶段**（从 beginWord 出发）：
   - 找到从 beginWord 到每个单词的最短距离
   - 构建一个有向图，记录最短路径上的前驱关系

2. **DFS 回溯阶段**（从 endWord 回溯）：
   - 利用 BFS 建立的前驱关系
   - 从 endWord 反向搜索到 beginWord
   - 收集所有最短路径

### 关键点：

- **双向 BFS 优化**：可以从两端同时搜索，减少搜索空间
- **前驱记录**：记录每个单词在最短路径中的所有前驱节点
- **距离控制**：只记录距离相同层的前驱，确保是最短路径

## Python 代码实现

### 方法一：BFS + DFS（推荐）⭐

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        # endWord 必须在字典中
        word_set = set(wordList)
        if endWord not in word_set:
            return []
        
        # BFS 阶段：构建从 beginWord 到各单词的最短路径图
        # 记录每个单词的前驱节点（可能有多个）
        predecessors = defaultdict(set)
        # 记录每个单词的层数（距离）
        distance = {beginWord: 0}
        
        queue = deque([beginWord])
        found = False
        current_level = 0
        
        while queue and not found:
            current_level += 1
            level_size = len(queue)
            # 本层访问的新节点
            current_level_visited = set()
            
            for _ in range(level_size):
                word = queue.popleft()
                
                # 尝试改变每个位置的字符
                for i in range(len(word)):
                    for c in 'abcdefghijklmnuvwxyz':
                        next_word = word[:i] + c + word[i+1:]
                        
                        if next_word in word_set:
                            # 如果是第一次访问这个词
                            if next_word not in distance:
                                distance[next_word] = current_level
                                current_level_visited.add(next_word)
                                predecessors[next_word].add(word)
                                
                                if next_word == endWord:
                                    found = True
                            # 如果在同一层访问过，说明有多条最短路径
                            elif distance[next_word] == current_level:
                                predecessors[next_word].add(word)
            
            # 将本层新访问的节点加入队列
            queue.extend(current_level_visited)
        
        # 如果找不到 endWord
        if endWord not in distance:
            return []
        
        # DFS 回溯阶段：从 endWord 反向构建所有路径
        result = []
        path = [endWord]
        
        def dfs(word):
            if word == beginWord:
                result.append(path[::-1])
                return
            
            for prev_word in predecessors[word]:
                path.append(prev_word)
                dfs(prev_word)
                path.pop()
        
        dfs(endWord)
        return result
```

### 方法二：双向 BFS + DFS（优化版）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        word_set = set(wordList)
        if endWord not in word_set:
            return []
        
        # 双向 BFS 的两个方向
        forward = {beginWord}
        backward = {endWord}
        word_set.discard(beginWord)
        
        # 记录路径关系：forward 方向时记录后继，backward 方向时记录前驱
        tree = defaultdict(set)
        found = False
        is_forward = True  # 标记当前搜索方向
        
        while forward and not found:
            # 总是从小的一端开始搜索
            if len(forward) > len(backward):
                forward, backward = backward, forward
                is_forward = not is_forward
            
            # 移除本层要访问的单词，避免重复
            word_set -= forward
            next_level = set()
            
            for word in forward:
                for i in range(len(word)):
                    for c in 'abcdefghijklmnopqrstuvwxyz':
                        next_word = word[:i] + c + word[i+1:]
                        
                        if next_word in word_set:
                            next_level.add(next_word)
                            # 根据搜索方向建立连接
                            if is_forward:
                                tree[word].add(next_word)
                            else:
                                tree[next_word].add(word)
                            
                            # 检查是否相遇
                            if next_word in backward:
                                found = True
            
            forward = next_level
        
        if not found:
            return []
        
        # DFS 构建路径
        result = []
        
        def dfs(word, path):
            if word == endWord:
                result.append(path[:])
                return
            
            for next_word in tree[word]:
                path.append(next_word)
                dfs(next_word, path)
                path.pop()
        
        dfs(beginWord, [beginWord])
        return result
```

### 方法三：简化版（容易理解）

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        word_set = set(wordList)
        if endWord not in word_set:
            return []
        
        # 获取相邻单词（只有一个字母不同）
        def get_neighbors(word):
            neighbors = []
            for i in range(len(word)):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    if c != word[i]:
                        new_word = word[:i] + c + word[i+1:]
                        if new_word in word_set:
                            neighbors.append(new_word)
            return neighbors
        
        # BFS 建立层级关系
        layers = defaultdict(set)  # 每个单词的前驱集合
        queue = deque([beginWord])
        visited = {beginWord}
        found = False
        
        while queue and not found:
            next_queue = deque()
            next_visited = set()
            
            while queue:
                word = queue.popleft()
                for neighbor in get_neighbors(word):
                    if neighbor == endWord:
                        found = True
                    
                    if neighbor not in visited:
                        next_visited.add(neighbor)
                        layers[neighbor].add(word)
                        if neighbor not in next_queue:
                            next_queue.append(neighbor)
                    elif neighbor in next_visited:
                        layers[neighbor].add(word)
            
            queue = next_queue
            visited.update(next_visited)
        
        if endWord not in layers and endWord != beginWord:
            return []
        
        # DFS 回溯所有路径
        result = []
        
        def backtrack(word, path):
            if word == beginWord:
                result.append([beginWord] + path)
                return
            
            for prev in layers[word]:
                backtrack(prev, [word] + path)
        
        backtrack(endWord, [])
        return result
```

## 复杂度分析

设单词长度为 L，字典大小为 N。

- **时间复杂度**：O(N * L * 26^L)
  - BFS：O(N * L * 26)，每个单词尝试 L 个位置，每个位置 26 个字母
  - DFS：最坏情况下所有路径，复杂度较高
  
- **空间复杂度**：O(N * L)
  - 存储字典、队列、前驱关系等

## 关键点总结

1. **分两阶段处理**：先 BFS 找最短路径，再 DFS 回溯所有路径
2. **前驱记录**：每个单词记录所有可能的前驱节点
3. **层级控制**：只在同一层级建立前驱关系，保证最短路径
4. **双向 BFS 优化**：从两端搜索可以减少搜索空间
5. **去重处理**：访问过的单词要及时标记

## 易错点

1. **忘记检查 endWord 是否在字典中**
   ```python
   # 必须先检查
   if endWord not in word_set:
       return []
   ```

2. **前驱记录错误**
   ```python
   # 错误：只记录一个前驱
   predecessors[next_word] = word
   
   # 正确：记录所有前驱（用集合）
   predecessors[next_word].add(word)
   ```

3. **层级混淆**
   ```python
   # 必须在同一层内建立前驱关系
   # 使用 current_level_visited 记录本层新访问的节点
   ```

4. **路径反转**：DFS 从 endWord 回溯到 beginWord，最后要反转路径
