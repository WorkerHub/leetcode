## 题目描述

有一个书店老板，他的书店开了 `n` 分钟。每分钟都有一些顾客进入这家商店。

给定两个长度为 `n` 的整数数组 `customers` 和 `grumpy`：
- `customers[i]` 是在第 `i` 分钟进入商店的顾客数量
- 如果 `grumpy[i] = 1`，表示第 `i` 分钟老板生气，所有在那一分钟进入的顾客会不满意
- 如果 `grumpy[i] = 0`，表示第 `i` 分钟老板不生气，所有在那一分钟进入的顾客会满意

书店老板有一个秘密技巧，能让自己连续 `minutes` 分钟不生气，但只能使用一次。

请你返回在这一天内，最多有多少客户能够感到满意。

**示例 1：**
```
输入：customers = [1,0,1,2,1,1,7,5], grumpy = [0,1,0,1,0,1,0,1], minutes = 3
输出：16
解释：书店老板在最后 3 分钟保持不生气。
感到满意的最大客户数量 = 1 + 1 + 1 + 1 + 7 + 5 = 16。
```

**示例 2：**
```
输入：customers = [1], grumpy = [0], minutes = 1
输出：1
```

**提示：**
- `n == customers.length == grumpy.length`
- `1 <= minutes <= n <= 2 * 10^4`
- `0 <= customers[i] <= 1000`
- `grumpy[i] == 0 or 1`

## 解题思路

这道题的关键在于如何最大化满意的顾客数量。我们可以将问题分解为两部分：

1. **基础满意顾客**：老板本来就不生气时的顾客（`grumpy[i] = 0`）
2. **额外满意顾客**：使用技巧后，原本会因老板生气而不满意的顾客变为满意

**核心思路：**
使用滑动窗口找到长度为 `minutes` 的连续时间段，在这个时间段内：
- 如果 `grumpy[i] = 1`（本来生气），使用技巧后能挽回 `customers[i]` 个顾客
- 找到能挽回最多顾客的时间段

**算法流程：**
1. 计算基础满意顾客数（所有 `grumpy[i] = 0` 时的顾客）
2. 使用滑动窗口找到能挽回最多顾客的连续 `minutes` 分钟
3. 返回基础满意顾客 + 最大挽回顾客

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def maxSatisfied(self, customers: List[int], grumpy: List[int], minutes: int) -> int:
        """
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(customers)
        
        # 1. 计算基础满意顾客数（老板不生气时的顾客）
        base_satisfied = sum(customers[i] for i in range(n) if grumpy[i] == 0)
        
        # 2. 计算第一个窗口能挽回的顾客数
        saved = 0
        for i in range(minutes):
            if grumpy[i] == 1:  # 只统计原本会不满意的顾客
                saved += customers[i]
        
        max_saved = saved
        
        # 3. 滑动窗口找到最大挽回数
        for i in range(minutes, n):
            # 窗口右边界加入
            if grumpy[i] == 1:
                saved += customers[i]
            
            # 窗口左边界移出
            if grumpy[i - minutes] == 1:
                saved -= customers[i - minutes]
            
            max_saved = max(max_saved, saved)
        
        return base_satisfied + max_saved
```

### 方法二：简化代码

```python
from typing import List

class Solution:
    def maxSatisfied(self, customers: List[int], grumpy: List[int], minutes: int) -> int:
        """
        更简洁的滑动窗口实现
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        n = len(customers)
        
        # 计算基础满意顾客
        base_satisfied = sum(c * (1 - g) for c, g in zip(customers, grumpy))
        
        # 初始化窗口
        saved = sum(customers[i] * grumpy[i] for i in range(minutes))
        max_saved = saved
        
        # 滑动窗口
        for i in range(minutes, n):
            saved += customers[i] * grumpy[i] - customers[i - minutes] * grumpy[i - minutes]
            max_saved = max(max_saved, saved)
        
        return base_satisfied + max_saved
```

### 方法三：原地修改（不推荐）

```python
from typing import List

class Solution:
    def maxSatisfied(self, customers: List[int], grumpy: List[int], minutes: int) -> int:
        """
        先统计基础满意，再在生气时段找最大窗口和
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        total = 0
        n = len(customers)
        
        # 统计基础满意顾客，并将不生气时的顾客置为 0
        for i in range(n):
            if grumpy[i] == 0:
                total += customers[i]
                customers[i] = 0  # 标记为已统计
        
        # 在生气时段找最大窗口和
        window_sum = sum(customers[:minutes])
        max_increase = window_sum
        
        for i in range(minutes, n):
            window_sum += customers[i] - customers[i - minutes]
            max_increase = max(max_increase, window_sum)
        
        return total + max_increase
```

## 复杂度分析

**时间复杂度：** O(n)
- 遍历数组计算基础满意顾客：O(n)
- 滑动窗口遍历：O(n)
- 总体：O(n)

**空间复杂度：** O(1)
- 只使用常量级额外空间

## 关键点总结

1. **问题分解**：将总满意顾客分为基础满意 + 额外挽回
2. **滑动窗口**：固定长度为 `minutes` 的窗口，找到最大挽回数
3. **只统计生气时段**：在窗口中只累加 `grumpy[i] = 1` 的顾客
4. **一次遍历**：滑动窗口可以在 O(n) 时间内完成

## 易错点

1. **重复统计**：不要将基础满意的顾客再次统计到窗口中
2. **窗口范围**：注意窗口的起始位置和边界条件
3. **理解题意**：技巧只能使用一次，必须连续 `minutes` 分钟
4. **最优位置**：窗口位置不一定在最后，需要遍历所有可能
