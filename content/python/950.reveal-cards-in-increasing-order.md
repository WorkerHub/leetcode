## 题目描述

牌组中的每张卡牌都对应一个唯一的整数。你可以按你想要的顺序对这套卡片进行排序。

最初，所有卡牌都面朝下放在一副牌中。你将重复执行以下步骤，直到所有卡片都显示为止：

1. 取出牌顶的卡片，显示它，然后将其从牌堆中移走。
2. 如果牌堆中仍有牌，则将下一张牌放在牌堆的底部。
3. 如果仍有未显示的卡片，返回步骤 1。否则，停止。

返回能以递增顺序显示卡片的牌组排列。

答案中的第一张牌被认为是牌顶。

## Python 代码实现

```python
from typing import List
from collections import deque

class Solution:
    def deckRevealedIncreasing(self, deck: List[int]) -> List[int]:
        deck.sort()
        n = len(deck)
        result = [0] * n
        
        # 创建索引队列
        queue = deque(range(n))
        
        for card in deck:
            # 取出队首索引
            idx = queue.popleft()
            result[idx] = card
            
            # 如果队列不为空，将队首移到队尾
            if queue:
                queue.append(queue.popleft())
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)
