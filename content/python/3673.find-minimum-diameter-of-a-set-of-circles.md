## 题目描述

给你一组圆，每个圆由圆心 `(x, y)` 和半径 `r` 表示，`circles[i] = [xi, yi, ri]`。你需要找到一个最小的圆，使得其能覆盖所有给定的圆（即所有圆都包含在这个最小圆内）。

返回该最小覆盖圆的直径。

**示例 1：**

```
输入：circles = [[2,1,2],[1,2,2]]
输出：6.0
解释：最小覆盖圆直径为6
```

**提示：**

- `1 <= circles.length <= 100`
- `-10^9 <= xi, yi <= 10^9`
- `1 <= ri <= 10^9`

## 解题思路

**最小覆盖圆问题**（Welzl 算法）：

将每个圆视为"带权点"，需要找一个最小圆覆盖所有圆（圆心到各圆圆心的距离 + 各圆半径 <= 覆盖圆半径）。

等价于找覆盖所有"扩展点集"（圆上所有点）的最小圆。

对每个圆 i，其"最远点"方向相对覆盖圆心不同。实际上问题等价于找最小圆覆盖一组"增大的点"。

简化：将每个圆 `(xi, yi, ri)` 视为到圆心距离加 ri 的约束。

## Python 代码实现

### 方法一：直接枚举（推荐）

```python
from typing import List
import math

class Solution:
    def minimumDiameter(self, circles: List[List[int]]) -> float:
        # 寻找最小覆盖圆：使用模拟退火或直接数学方法
        # 对小规模（n<=100），枚举所有可能的覆盖圆圆心候选

        def dist(x1, y1, x2, y2):
            return math.sqrt((x1 - x2) ** 2 + (y1 - y2) ** 2)

        def covers(cx, cy, r_cover):
            return all(dist(cx, cy, x, y) + ri <= r_cover
                       for x, y, ri in circles)

        def min_enclosing_circle():
            # 对一组点（带半径偏移），求最小覆盖圆
            # 简化：用三点式最小覆盖圆
            # 先处理：将问题转化为求最小覆盖所有扩展圆的圆
            # 枚举圆心候选（所有圆对之间的最优点 + 单圆最远点）

            best_r = float('inf')
            # 候选圆心：所有圆的圆心
            candidates = [(c[0], c[1]) for c in circles]

            for cx, cy in candidates:
                r = max(dist(cx, cy, c[0], c[1]) + c[2] for c in circles)
                best_r = min(best_r, r)

            # 两圆确定的覆盖圆
            n = len(circles)
            for i in range(n):
                for j in range(i + 1, n):
                    # 尝试以两圆最远点为直径的圆
                    x1, y1, r1 = circles[i]
                    x2, y2, r2 = circles[j]
                    # 两个点：(x1,y1) 沿 away from (x2,y2) 延伸 r1
                    # (x2,y2) 沿 away from (x1,y1) 延伸 r2
                    d = dist(x1, y1, x2, y2)
                    if d < 1e-9:
                        continue
                    # 最远点
                    p1x = x1 + r1 * (x1 - x2) / d
                    p1y = y1 + r1 * (y1 - y2) / d
                    p2x = x2 + r2 * (x2 - x1) / d
                    p2y = y2 + r2 * (y2 - y1) / d
                    # 圆心为两最远点的中点
                    cx = (p1x + p2x) / 2
                    cy = (p1y + p2y) / 2
                    r = max(dist(cx, cy, c[0], c[1]) + c[2] for c in circles)
                    best_r = min(best_r, r)

            return best_r * 2

        return minimumDiameter if False else self._solve(circles)

    def _solve(self, circles):
        import math
        def dist(x1, y1, x2, y2):
            return math.sqrt((x1 - x2) ** 2 + (y1 - y2) ** 2)

        best_r = float('inf')
        n = len(circles)
        candidates = [(c[0], c[1]) for c in circles]

        for cx, cy in candidates:
            r = max(dist(cx, cy, c[0], c[1]) + c[2] for c in circles)
            best_r = min(best_r, r)

        for i in range(n):
            for j in range(i + 1, n):
                x1, y1, r1 = circles[i]
                x2, y2, r2 = circles[j]
                d = dist(x1, y1, x2, y2)
                if d < 1e-9:
                    continue
                p1x = x1 + r1 * (x1 - x2) / d
                p1y = y1 + r1 * (y1 - y2) / d
                p2x = x2 + r2 * (x2 - x1) / d
                p2y = y2 + r2 * (y2 - y1) / d
                cx = (p1x + p2x) / 2
                cy = (p1y + p2y) / 2
                r = max(dist(cx, cy, c[0], c[1]) + c[2] for c in circles)
                best_r = min(best_r, r)

        return best_r * 2
```

### 方法二：模拟退火（数值解）

```python
from typing import List
import math
import random

class Solution:
    def minimumDiameter(self, circles: List[List[int]]) -> float:
        def radius_from(cx, cy):
            return max(math.sqrt((cx-x)**2 + (cy-y)**2) + r
                       for x, y, r in circles)

        cx = sum(c[0] for c in circles) / len(circles)
        cy = sum(c[1] for c in circles) / len(circles)
        step = 1e6

        while step > 1e-6:
            for dx, dy in [(1,0),(-1,0),(0,1),(0,-1)]:
                ncx, ncy = cx + dx * step, cy + dy * step
                if radius_from(ncx, ncy) < radius_from(cx, cy):
                    cx, ncy = ncx, ncy
            step *= 0.999

        return radius_from(cx, cy) * 2
```

## 复杂度分析

- 时间复杂度：O(n^3)（枚举方法），O(n * iter)（模拟退火）
- 空间复杂度：O(n)

## 关键点总结

1. 最小覆盖圆由 1、2 或 3 个圆确定
2. 两圆确定时：覆盖圆直径为两圆最远点的距离
3. 候选圆心包括各圆圆心以及两两组合的最优点

## 易错点

1. 最远点方向要取反（从 i 向 j 方向延伸 ri，对 j 向 i 方向延伸 rj）
2. 浮点精度问题
3. 圆心重合时需特殊处理
