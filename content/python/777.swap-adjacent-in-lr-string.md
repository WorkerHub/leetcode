## 题目描述

在一个由 `'L'`, `'R'` 和 `'X'` 三个字符组成的字符串中，进行以下操作：

- 一次移动中，可以将 `'XL'` 替换成 `'LX'`，或者将 `'RX'` 替换成 `'XR'`

给定起始字符串 `start` 和结束字符串 `end`，如果能通过若干次移动将 `start` 转换为 `end`，返回 `true`，否则返回 `false`。

**示例 1:**
```
输入: start = "RXXLRXRXL", end = "XRLXXRRLX"
输出: true
```

## 解题思路

观察规则：
- `'L'` 只能向左移动（XL -> LX）
- `'R'` 只能向右移动（RX -> XR）
- 去掉 `'X'` 后，两个字符串必须相同
- `'L'` 在 end 中的位置不能在 start 中对应位置的右边
- `'R'` 在 end 中的位置不能在 start 中对应位置的左边

## Python 代码实现

```python
class Solution:
    def canTransform(self, start: str, end: str) -> bool:
        # 去掉 X 后必须相同
        if start.replace('X', '') != end.replace('X', ''):
            return False
        
        # 检查位置约束
        i = j = 0
        n = len(start)
        
        while i < n and j < n:
            # 跳过 X
            while i < n and start[i] == 'X':
                i += 1
            while j < n and end[j] == 'X':
                j += 1
            
            # 都到达末尾
            if i == n and j == n:
                return True
            
            # 一个到达末尾
            if i == n or j == n:
                return False
            
            # 字符必须相同
            if start[i] != end[j]:
                return False
            
            # L 只能向左移，不能向右
            if start[i] == 'L' and i < j:
                return False
            
            # R 只能向右移，不能向左
            if start[i] == 'R' and i > j:
                return False
            
            i += 1
            j += 1
        
        return True
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 关键点总结

1. **移动方向：** L 左移，R 右移
2. **字符顺序不变**
3. **位置约束**
