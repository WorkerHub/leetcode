## 题目描述

给定一个字符串 `s`，重新排列字符串，使得任意两个相邻的字符都不相同。

返回 `s` 的任意可能的重新排列。若不可能，返回空字符串 `""`。

**示例 1:**
```
输入: s = "aab"
输出: "aba"
```

**示例 2:**
```
输入: s = "aaab"
输出: ""
```

## 解题思路

使用贪心 + 堆的策略，每次选择出现次数最多的字符（且不同于上一个字符）。

## Python 代码实现

### 方法一：最大堆（推荐）⭐

```python
from collections import Counter
import heapq

class Solution:
    def reorganizeString(self, s: str) -> str:
        # 统计字符频率
        count = Counter(s)
        
        # 如果最高频率超过 (n+1)//2，无法重排
        if max(count.values()) > (len(s) + 1) // 2:
            return ""
        
        # 最大堆（Python 是最小堆，所以用负数）
        heap = [(-freq, char) for char, freq in count.items()]
        heapq.heapify(heap)
        
        result = []
        prev_freq, prev_char = 0, ''
        
        while heap:
            freq, char = heapq.heappop(heap)
            result.append(char)
            
            # 将上一个字符放回堆
            if prev_freq < 0:
                heapq.heappush(heap, (prev_freq, prev_char))
            
            # 更新当前字符（频率-1）
            prev_freq, prev_char = freq + 1, char
        
        return ''.join(result)
```

### 方法二：排序 + 填充

```python
class Solution:
    def reorganizeString(self, s: str) -> str:
        count = Counter(s)
        max_freq = max(count.values())
        
        if max_freq > (len(s) + 1) // 2:
            return ""
        
        # 按频率排序
        chars = sorted(count.keys(), key=lambda x: count[x], reverse=True)
        
        result = [''] * len(s)
        index = 0
        
        # 先填充频率最高的字符
        for char in chars:
            for _ in range(count[char]):
                result[index] = char
                index += 2
                if index >= len(s):
                    index = 1
        
        return ''.join(result)
```

## 复杂度分析

- **时间复杂度：** O(n log k)，k 是不同字符数
- **空间复杂度：** O(k)

## 关键点总结

1. **判断可行性：** 最高频率不能超过 (n+1)//2
2. **贪心策略：** 每次选择频率最高的字符
3. **堆的应用：** 高效地获取最大元素
