## 题目描述

给定长度为 `m` 的行和数组 `rowSum` 和长度为 `n` 的列和数组 `colSum`，构造一个 `m × n` 的非负整数矩阵，使得每行之和等于 `rowSum[i]`，每列之和等于 `colSum[j]`。保证输入合法（`sum(rowSum) == sum(colSum)`）。

**示例 1：**
```
输入：rowSum = [3,8], colSum = [4,7]
输出：[[3,0],[1,7]]
解释：行和：[3,8]，列和：[4,7]，满足条件。
```

**示例 2：**
```
输入：rowSum = [5,7,10], colSum = [8,6,8]
输出：[[0,5,0],[6,1,0],[2,0,8]]
```

**提示：**
- `1 <= m, n <= 50`
- `0 <= rowSum[i], colSum[j] <= 500`
- `sum(rowSum) == sum(colSum)`

## 解题思路

贪心：逐格填充，每个单元格 `(i, j)` 填入 `min(rowSum[i], colSum[j])`，然后更新剩余的行和与列和。

**证明正确性：** 每次取最小值不会导致任一方向"超支"，且总和守恒保证最终一定能填满。

## Python 代码实现

### 方法一：贪心逐格填充（推荐）

```python
from typing import List

class Solution:
    def restoreMatrix(self, rowSum: List[int], colSum: List[int]) -> List[List[int]]:
        m, n = len(rowSum), len(colSum)
        result = [[0] * n for _ in range(m)]

        for i in range(m):
            for j in range(n):
                # 在不超过行剩余和与列剩余和的前提下，尽可能填大
                val = min(rowSum[i], colSum[j])
                result[i][j] = val
                rowSum[i] -= val
                colSum[j] -= val

        return result
```

### 方法二：验证版本

```python
from typing import List

class Solution:
    def restoreMatrix(self, rowSum: List[int], colSum: List[int]) -> List[List[int]]:
        m, n = len(rowSum), len(colSum)
        mat = [[0] * n for _ in range(m)]
        row = rowSum[:]
        col = colSum[:]

        for i in range(m):
            for j in range(n):
                mat[i][j] = min(row[i], col[j])
                row[i] -= mat[i][j]
                col[j] -= mat[i][j]

        # 验证（调试用）
        assert all(r == 0 for r in row)
        assert all(c == 0 for c in col)

        return mat
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)，输出矩阵

## 关键点总结

1. 贪心策略：每次取 `min(rowSum[i], colSum[j])`，将某一方向"消耗完"
2. 保证任何时候行和与列和均非负
3. 由于总和相等，贪心一定能找到合法解

## 易错点

1. 需要原地修改 rowSum 和 colSum（或使用副本）
2. 注意不要把原数组修改掉影响后续
