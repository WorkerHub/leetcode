## 题目描述

给你一个字符串数组 `words`，每个字符串长度为 **2**。

将这些字符串拼接在一起，构造**最长的回文串**（可以使用部分字符串，且可以按任意顺序拼接）。

返回**最长回文串的长度**。

**示例 1：**
```
输入：words = ["lc","cl","gg"]
输出：6
解释："lcgcl" 或 "clggcl" 等，最长为 "lc" + "gg" + "cl" = 6。
```

**示例 2：**
```
输入：words = ["ab","ty","yt","lc","cl","ab"]
输出：8
解释："ty" + "lc" + "cl" + "yt" = 8。
```

**提示：**
- `1 <= words.length <= 10^5`
- `words[i].length == 2`
- `words[i]` 仅由小写英文字母组成

## 解题思路

**贪心 + 计数**

对每个单词 `w`，分两类：
1. `w` 与其反转 `w[::-1]` **不同**（如 `"lc"` 与 `"cl"`）：配对使用，贡献 `min(cnt[w], cnt[w[::-1]]) * 4`。
2. `w` 等于其反转（如 `"gg"`, `"aa"`）：偶数对可对称使用，贡献 `(cnt[w] // 2) * 4`；若有奇数个且还没有中心词，则可以放一个在中间，贡献 +2。

## 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        cnt = Counter(words)
        ans = 0
        has_center = False  # 是否已有一个对称词放在中间

        for w, count in cnt.items():
            rev = w[::-1]
            if w == rev:
                # 回文词（如 "gg"），偶数个配对放两侧
                ans += (count // 2) * 4
                if count % 2 == 1:
                    has_center = True  # 剩下一个可放中间
            elif w < rev:
                # 避免重复处理（只处理字典序小的那个）
                pairs = min(count, cnt.get(rev, 0))
                ans += pairs * 4

        if has_center:
            ans += 2  # 中间放一个回文词

        return ans
```

### 方法二：直接遍历所有词对

```python
from typing import List
from collections import Counter

class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        cnt = Counter(words)
        ans = 0
        used_center = False

        for w in list(cnt.keys()):
            rev = w[::-1]
            if w == rev:
                # 对称词
                pairs = cnt[w] // 2
                ans += pairs * 4
                cnt[w] -= pairs * 2
            elif rev in cnt:
                # 非对称词对
                pairs = min(cnt[w], cnt[rev])
                ans += pairs * 4
                cnt[w] -= pairs
                cnt[rev] -= pairs

        # 找剩余的对称词放中间
        for w, c in cnt.items():
            if w == w[::-1] and c > 0:
                ans += 2
                break

        return ans
```

## 关键点总结

1. 长度为 2 的回文词只有 26 种（aa, bb, ...）。
2. 非对称词（如 "lc" 和 "cl"）必须成对使用，一个在左一个在右。
3. 对称词（如 "gg"）偶数个时全部用，奇数个时多一个放中间。

## 易错点

- 中间只能放一个对称词（回文串中心最多一个），用 `has_center` 标记。
- 遍历时避免重复处理 `(w, rev)` 对（用 `w < rev` 条件或 `w == rev` 判断）。
