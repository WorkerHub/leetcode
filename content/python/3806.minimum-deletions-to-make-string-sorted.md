## 题目描述

给你一个字符串 `s`，你可以删除其中的若干字符。

返回使字符串按非递减顺序排列所需删除的最少字符数。

**示例 1：**

```
输入：s = "aabcd"
输出：0
解释：字符串已经有序，无需删除。
```

**示例 2：**

```
输入：s = "dcba"
输出：3
解释：删除 "dcb" 后剩余 "a"，有序。或者删除任意 3 个，留下 1 个字符。
最长非递减子序列长度为 1，故删除 4-1=3 个。
```

**示例 3：**

```
输入：s = "cbabc"
输出：2
解释：最长非递减子序列为 "abc"，长度为 3，删除 5-3=2 个。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

最少删除数 = 字符串长度 - **最长非递减子序列**的长度。

对于只含小写字母的字符串，可以用动态规划求最长非递减子序列（类似 LIS 问题）。

优化：由于只有 26 个小写字母，可以用**计数 + DP** 在 O(26n) 时间内解决。

`dp[c]` = 以字符 c 结尾的最长非递减子序列长度。

## Python 代码实现

### 方法一：字符计数 DP（推荐）

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        # dp[c] 表示以字符 c 结尾的最长非递减子序列长度
        dp = [0] * 26

        for ch in s:
            c = ord(ch) - ord('a')
            # 以 ch 结尾的最长非递减子序列 = max(dp[0..c]) + 1
            best = max(dp[:c + 1])
            dp[c] = best + 1

        # 最长非递减子序列长度
        longest = max(dp)
        return len(s) - longest
```

### 方法二：二分查找优化（LIS 经典方法）

```python
import bisect

class Solution:
    def minimumDeletions(self, s: str) -> int:
        # 求最长非递减子序列（允许相等）
        # tails[i] 表示长度为 i+1 的非递减子序列的最小末尾元素
        tails = []

        for ch in s:
            # bisect_right 找第一个 > ch 的位置（非递减允许等于）
            pos = bisect.bisect_right(tails, ch)
            if pos == len(tails):
                tails.append(ch)
            else:
                tails[pos] = ch

        return len(s) - len(tails)
```

## 复杂度分析

- 时间复杂度：
  - 方法一：O(26n) = O(n)，对每个字符查 dp 数组前缀最大值
  - 方法二：O(n log n)，二分查找
- 空间复杂度：O(26) = O(1)（方法一）；O(n)（方法二，最坏情况）

## 关键点总结

1. 最少删除 = 总长度 - 最长非递减子序列长度。
2. 字符仅含小写字母时，方法一用 26 大小的数组记录 DP 状态，效率很高。
3. 非递减子序列允许相邻相等，二分查找用 `bisect_right`。

## 易错点

1. 非递减（允许相等）与严格递增的 LIS 不同，二分查找方向不同。
2. 方法一的 `max(dp[:c+1])` 包含 c 本身，因为可以接在相同字符后面。
