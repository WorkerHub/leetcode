## 题目描述

如果我们交换 s[i] 和 s[j]（i 和 j 的奇偶性相同），那么称字符串 s 是特殊等价的。

现在规定，s 的 特殊等价字符串组 是 s 与所有特殊等价字符串的集合。

给定一个字符串数组 words，返回 words 的特殊等价字符串组 数量。

**提示：**
- 1 <= words.length <= 1000
- 1 <= words[i].length <= 20
- words[i] 由小写英文字母组成
- words 中所有字符串的长度都相同

## 解题思路

将奇数位和偶数位分别排序，作为字符串的特征。

## Python 代码实现

```python
class Solution:
    def numSpecialEquivGroups(self, words: List[str]) -> int:
        def signature(word):
            # 奇数位和偶数位分别排序
            even = ''.join(sorted(word[::2]))
            odd = ''.join(sorted(word[1::2]))
            return even + odd
        
        return len(set(signature(word) for word in words))
```

## 复杂度分析

- **时间复杂度**：O(n × m log m)，n 是单词数，m 是单词长度
- **空间复杂度**：O(n × m)

## 关键点总结

1. **奇偶分离**：奇数位和偶数位分别处理
2. **排序特征**：相同特征的为一组
3. **集合去重**：统计不同特征数量
