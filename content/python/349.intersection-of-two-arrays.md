## 题目描述

给定两个数组 `nums1` 和 `nums2`，返回它们的交集。输出结果中的每个元素一定是唯一的。我们可以不考虑输出结果的顺序。

**示例 1：**
```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]
```

**示例 2：**
```
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
解释：[4,9] 也是可接受的。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

## 解题思路

这道题要找两个数组的交集，且结果唯一。

**核心观察：**
- 需要去重
- 不需要保持顺序
- 只需要判断元素是否同时出现在两个数组中

**多种解法：**
1. 集合求交集：最直接
2. 哈希表：遍历一个数组，查询另一个
3. 排序 + 双指针：适合有序或可排序的情况
4. 二分查找：一个排序，另一个二分查找

## Python 代码实现

### 方法一：集合求交集（最简洁）⭐

```python
from typing import List

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # Python 集合的交集运算
        return list(set(nums1) & set(nums2))
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(m + n)

### 方法二：哈希表

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 将 nums1 转为集合
        set1 = set(nums1)
        result = set()
        
        # 遍历 nums2，查找交集
        for num in nums2:
            if num in set1:
                result.add(num)
        
        return list(result)
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(m + n)

### 方法三：排序 + 双指针

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # 排序
        nums1.sort()
        nums2.sort()
        
        result = []
        i, j = 0, 0
        
        while i < len(nums1) and j < len(nums2):
            if nums1[i] < nums2[j]:
                i += 1
            elif nums1[i] > nums2[j]:
                j += 1
            else:
                # 找到交集元素
                if not result or result[-1] != nums1[i]:
                    result.append(nums1[i])
                i += 1
                j += 1
        
        return result
```

**时间复杂度：** O(m log m + n log n)
**空间复杂度：** O(1)，不计结果数组

### 方法四：内置函数（最Pythonic）

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        return list(set(nums1).intersection(set(nums2)))
```

## 关键点总结

1. **去重**：使用 set
2. **集合运算**：`&` 或 `intersection()`
3. **双指针**：需要先排序
4. **时间复杂度**：哈希表 O(n)，排序 O(n log n)

## 易错点

1. **忘记去重**
   ```python
   # 错误：可能有重复
   result = []
   for num in nums2:
       if num in nums1:
           result.append(num)
   
   # 正确：
   result = set()
   for num in nums2:
       if num in set(nums1):
           result.add(num)
   ```

2. **双指针忘记去重**
   ```python
   # 错误：
   if nums1[i] == nums2[j]:
       result.append(nums1[i])
   
   # 正确：
   if nums1[i] == nums2[j]:
       if not result or result[-1] != nums1[i]:
           result.append(nums1[i])
   ```
