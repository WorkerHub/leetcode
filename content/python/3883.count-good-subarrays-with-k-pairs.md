## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，如果一个子数组中相等元素对的数目（即满足 `i < j` 且 `nums[i] == nums[j]` 的对数）不少于 `k`，则称该子数组为"好子数组"。

返回好子数组的数目。

**示例 1：**

```
输入：nums = [3, 1, 4, 3, 2, 2, 4], k = 2
输出：4
解释：满足条件的子数组（相等对数 >= 2）有 4 个。
```

**示例 2：**

```
输入：nums = [1, 1, 1, 1, 1], k = 10
输出：1
解释：只有整个数组的相等对数为 10，满足条件。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

使用**滑动窗口**：
1. 维护窗口内的频率表 `freq`，以及当前窗口内的相等对数 `pairs`。
2. 加入元素 v 时，`pairs += freq[v]`（新增的对数等于 v 已出现的次数）。
3. 当 `pairs >= k` 时，以 `right` 为右端的好子数组数量为 `left`（左端可以从 0 到 left-1 扩展）。
4. 同时找最小左端（使 pairs 恰好 >= k）。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        freq = defaultdict(int)
        pairs = 0
        left = 0
        count = 0

        for right in range(n):
            v = nums[right]
            pairs += freq[v]  # 加入 v 新增的相等对数
            freq[v] += 1

            # 收缩左端，保持最小满足条件的窗口
            while pairs >= k:
                # 以 right 为右端，以 left..right 为左端的都是好子数组
                # 但这里要统计"以 right 为右端的好子数组数"
                # 此时 [left, right] 满足，[0, right] 也满足
                # 更简洁：统计左端 0..left 都满足
                count += left + 1  # 不对，需要重新计算

                # 移除左端
                lv = nums[left]
                freq[lv] -= 1
                pairs -= freq[lv]  # 移除后减少的对数 = 移除前的计数 - 1 = 当前计数
                left += 1

            # 此时 [left, right] 不满足条件（pairs < k）
            # 而 [left-1, right] 满足（若 left > 0）
            # 以 right 为右端，左端可以是 0..left-1 共 left 个
            count += left

        return count
```

### 方法二：更清晰的实现

```python
from typing import List
from collections import defaultdict

class Solution:
    def countGoodSubarrays(self, nums: List[int], k: int) -> int:
        freq = defaultdict(int)
        pairs = 0
        ans = 0
        left = 0

        for right, v in enumerate(nums):
            pairs += freq[v]
            freq[v] += 1

            # 缩减左端直到不满足条件
            while pairs >= k:
                lv = nums[left]
                freq[lv] -= 1
                pairs -= freq[lv]
                left += 1

            # [left, right] 不满足，[left-1, right] 满足
            # 满足条件的左端点：0 到 left-1，共 left 个
            ans += left

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各移动 n 次
- 空间复杂度：O(n)，频率表

## 关键点总结

1. 加入元素 v 时，新增对数 = `freq[v]`（v 在窗口内出现的次数）。
2. 移除左端元素 lv 时，减少对数 = 移除后 lv 的频率 = `freq[lv] - 1`（更新前）。
3. 以 right 为右端的好子数组数量 = 满足条件的左端点个数 = `left`。

## 易错点

1. 收缩左端时，先减少 `freq[lv]`，再从 `pairs` 中减去减少后的频率（不是原频率）。
2. 收缩后 `[left, right]` 不满足，好的左端点是 0 到 left-1。
