## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，请你判断是否可以把这个数组划分成一些由 `k` 个**连续数字**组成的集合。

如果可以，请返回 `True`；否则，返回 `False`。

**示例 1：**

```
输入：nums = [1,2,3,3,4,4,5,6], k = 4
输出：true
解释：数组可以分成 [1,2,3,4] 和 [3,4,5,6]。
```

**示例 2：**

```
输入：nums = [3,2,1,2,3,4,3,4,5,9,10,11], k = 3
输出：true
解释：数组可以分成 [1,2,3] 、[2,3,4] 、[3,4,5] 和 [9,10,11]。
```

**示例 3：**

```
输入：nums = [3,2,1,2,3,4,3,4,5,9,10,11], k = 2
输出：false
解释：[9, 10, 11] 不能分成 3 组 k=2 的集合。
```

**示例 4：**

```
输入：nums = [1,2,3,4], k = 3
输出：false
解释：数组长度不是 k 的倍数。
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= nums.length`

## 解题思路

### 核心思想：贪心

贪心策略：**从最小的数开始，尝试构造包含该数的连续组**。

**为什么贪心是正确的？**

考虑当前未使用的最小数 `x`，`x` 必须出现在某个连续组中。由于 `x` 是最小的，它只能位于该组的起始位置（即组为 `[x, x+1, x+2, ..., x+k-1]`）。因此，每次取最小数并尝试构造从它开始的组，这种贪心策略是最优的。

### 算法步骤

1. **检查总数组长度**：如果 `len(nums) % k != 0`，直接返回 `False`
2. **统计每个数字出现次数**：使用 `Counter`
3. **对所有不同的数字排序**（或用 `SortedDict`/`sorted(Counter)`）
4. **从小到大贪心处理**：
   - 取当前最小的数 `num`（出现次数 > 0）
   - 尝试构造组 `[num, num+1, ..., num+k-1]`
   - 如果任何一个数的出现次数不足，返回 `False`
   - 否则将这 `k` 个数的出现次数各减少 `count[num]`

### 与 846 题的关系

本题与 [846. 一手顺子](https://leetcode.com/problems/hand-of-straights/) 完全相同，只是变量名不同（`k` 和 `groupSize`）。

## Python 代码实现

### 方法一：Counter + 排序贪心（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def isPossibleDivide(self, nums: List[int], k: int) -> bool:
        # 前置条件：总数必须是 k 的倍数
        if len(nums) % k != 0:
            return False

        # 统计每个数字的出现次数
        count = Counter(nums)

        # 对所有不同数字排序，从小到大处理
        for num in sorted(count):
            freq = count[num]  # 当前数字的出现次数

            if freq == 0:
                # 该数字已被之前的操作全部消耗，跳过
                continue

            # 尝试构造以 num 为起点、长度为 k 的连续组
            for i in range(k):
                if count[num + i] < freq:
                    # num+i 的数量不足以匹配，无法构造 freq 个组
                    return False
                count[num + i] -= freq  # 消耗 freq 个 num+i

        return True
```

### 方法二：使用 SortedDict（每次删除用完的数，避免遍历 0 计数）

```python
from typing import List
from sortedcontainers import SortedDict

class Solution:
    def isPossibleDivide(self, nums: List[int], k: int) -> bool:
        if len(nums) % k != 0:
            return False

        # SortedDict 维护有序的计数字典
        count = SortedDict()
        for num in nums:
            count[num] = count.get(num, 0) + 1

        while count:
            # 取出当前最小的数
            start = count.keys()[0]
            freq = count[start]

            # 尝试构造 [start, start+1, ..., start+k-1]
            for i in range(k):
                num = start + i
                if count.get(num, 0) < freq:
                    return False
                count[num] -= freq
                if count[num] == 0:
                    del count[num]  # 删除计数为 0 的键

        return True
```

### 方法三：模拟（便于理解，效率稍低）

```python
from typing import List
from collections import Counter

class Solution:
    def isPossibleDivide(self, nums: List[int], k: int) -> bool:
        if len(nums) % k != 0:
            return False

        count = Counter(nums)
        # 已排序的唯一数字列表
        unique_sorted = sorted(count.keys())

        for num in unique_sorted:
            while count[num] > 0:
                # 每次构造一个从 num 开始的连续组
                for i in range(k):
                    if count[num + i] <= 0:
                        return False
                    count[num + i] -= 1

        return True
```

### 方法四：优化写法（合并循环）

```python
from typing import List
from collections import Counter

class Solution:
    def isPossibleDivide(self, nums: List[int], k: int) -> bool:
        n = len(nums)
        if n % k != 0:
            return False

        count = Counter(nums)

        # sorted(count) 等价于 sorted(count.keys())
        for num in sorted(count):
            c = count[num]
            if c > 0:
                # 需要 c 个从 num 开始的连续组
                for step in range(1, k):
                    count[num + step] -= c
                    if count[num + step] < 0:
                        return False
                # count[num] 自然被消耗，不需要显式处理

        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n log n) | O(n) |
| 方法二（SortedDict） | O(n log n) | O(n) |
| 方法三（模拟） | O(n * k) 最坏 | O(n) |
| 方法四 | O(n log n) | O(n) |

**方法一和方法四**是最优解，时间 O(n log n)（排序主导），空间 O(n)（Counter）。

## 关键点总结

1. **贪心正确性**：最小数只能作为某组的起点，从小到大处理是必要的
2. **前置剪枝**：`len(nums) % k != 0` 时直接返回 `False`，快速排除无效情况
3. **批量处理**：当 `num` 出现 `freq` 次时，需要构造 `freq` 个从 `num` 开始的组，可以一次性减去 `freq`
4. **Counter 默认返回 0**：访问不存在的键时返回 0，不会报错
5. **与 846 题完全相同**：二者本质上是同一道题

## 易错点

- **漏掉 `count[num] == 0` 的跳过逻辑**：如果不跳过计数为 0 的数，会错误地尝试构造组
- **减法后负数判断位置**：有些写法先减再判断，有些先判断再减，两种都可以，但逻辑要一致
- **k = 1 的特殊情况**：每个元素单独成组，总是返回 `True`（代码天然处理）
- **数组长度不是 k 倍数**：必须先检查，避免后续处理出现不必要的错误
