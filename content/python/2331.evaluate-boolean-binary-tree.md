## 题目描述

给你一棵**完整二叉树**的根节点，树中每个节点的值为 `0`、`1`、`2` 或 `3`：
- **叶子节点**的值为 `0` 或 `1`，分别表示 `false` 和 `true`。
- **非叶子节点**的值为 `2` 或 `3`，其中 `2` 表示逻辑**或**，`3` 表示逻辑**与**。

计算根节点的布尔运算值并返回。

**完整二叉树**是指每个非叶子节点恰好有两个子节点。

**示例 1：**
```
输入：root = [2,1,3,null,null,0,1]
输出：true
解释：根为 OR，左子为 1（true），右子为 AND(0, 1)=false，true OR false = true。
```

**提示：**
- 树中节点数量在 `[1, 1000]` 范围内
- `0 <= Node.val <= 3`
- 每个内部节点恰好有两个子节点

## 解题思路

递归求解：
- 若是叶子节点，返回 `node.val == 1`。
- 若是 OR 节点（`val == 2`），返回左右子树结果的 OR。
- 若是 AND 节点（`val == 3`），返回左右子树结果的 AND。

## 代码实现

### 方法一：递归（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def evaluateTree(self, root: Optional[TreeNode]) -> bool:
        # 叶子节点
        if root.left is None:
            return root.val == 1
        
        left = self.evaluateTree(root.left)
        right = self.evaluateTree(root.right)
        
        if root.val == 2:  # OR 运算
            return left or right
        else:              # AND 运算（val == 3）
            return left and right
```

### 方法二：迭代（后序遍历）

```python
from typing import Optional

class Solution:
    def evaluateTree(self, root: Optional[TreeNode]) -> bool:
        stack = []
        node = root
        last = None
        val_map = {}  # 记录每个节点的计算结果
        
        while stack or node:
            if node:
                stack.append(node)
                node = node.left
            else:
                peek = stack[-1]
                if peek.right and last != peek.right:
                    node = peek.right
                else:
                    stack.pop()
                    if peek.left is None:
                        val_map[id(peek)] = (peek.val == 1)
                    elif peek.val == 2:
                        val_map[id(peek)] = val_map[id(peek.left)] or val_map[id(peek.right)]
                    else:
                        val_map[id(peek)] = val_map[id(peek.left)] and val_map[id(peek.right)]
                    last = peek
        
        return val_map[id(root)]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 递归 | O(n) | O(h)（h 为树高） |
| 迭代 | O(n) | O(n) |

## 关键点总结

1. 叶子节点的值直接转换为布尔值（0 -> false, 1 -> true）。
2. 非叶子节点根据 val 决定是 OR 还是 AND 操作。
3. 完整二叉树保证非叶子节点一定有两个子节点，无需处理单子节点情况。

## 易错点

- 叶子节点的判断条件：`node.left is None`（完整二叉树中无左子必无右子）。
- OR 对应 2，AND 对应 3，不要搞反。
