## 题目描述

给你 2 个鸡蛋和 `n` 层楼，找到临界楼层（从该楼层以上扔鸡蛋会碎，以下不会碎）所需的**最少操作次数**（最坏情况下）。

**示例 1：**
```
输入：n = 2
输出：2
```

**示例 2：**
```
输入：n = 100
输出：14
```

**提示：**
- `1 <= n <= 1000`

## 解题思路

**数学分析**：设最少操作次数为 `k`，则 k 次操作能覆盖的最大楼层数为 `k*(k+1)/2`。

最优策略：第 1 次从第 k 层扔，若碎则用第 2 个鸡蛋从 1 到 k-1 逐层扔（共 k-1 次）；若不碎，从第 k+(k-1) 层扔，以此类推。

因此 `k*(k+1)/2 >= n`，求最小 k。

## 代码实现

### 方法一：数学公式（推荐）

```python
import math

class Solution:
    def twoEggDrop(self, n: int) -> int:
        # 求最小 k 使得 k*(k+1)/2 >= n
        # 解方程 k^2 + k - 2n = 0 -> k = (-1 + sqrt(1 + 8n)) / 2
        k = math.ceil((-1 + math.sqrt(1 + 8 * n)) / 2)
        return k
```

### 方法二：动态规划

```python
class Solution:
    def twoEggDrop(self, n: int) -> int:
        # dp[e][f] = e 个鸡蛋 f 层楼最少操作次数（经典蛋落问题）
        INF = float('inf')
        dp = [[INF] * (n + 1) for _ in range(3)]
        for f in range(n + 1):
            dp[1][f] = f   # 1 个鸡蛋时，需逐层检查
        dp[2][0] = 0
        dp[2][1] = 1

        for f in range(2, n + 1):
            # 2 个鸡蛋 f 层
            best = INF
            for x in range(1, f + 1):
                # 从第 x 层扔：碎了用 dp[1][x-1] 次，没碎用 dp[2][f-x] 次
                best = min(best, max(dp[1][x - 1], dp[2][f - x]) + 1)
            dp[2][f] = best

        return dp[2][n]
```

## 复杂度分析

- **方法一（数学）**：O(1)
- **方法二（DP）**：O(n^2)，每层楼枚举所有可能的扔蛋位置

## 关键点总结

1. 2 个鸡蛋时有数学公式：k*(k+1)/2 >= n 的最小 k
2. 最优策略是三角数技巧：每次递减步长（k, k-1, k-2, ...）
3. 经典蛋落问题的通解需要 DP，但特定情况（2 蛋）有公式解

## 易错点

- 数学解中需要向上取整（ceiling），不能直接取整
