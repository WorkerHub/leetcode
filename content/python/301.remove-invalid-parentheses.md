## 题目描述

给你一个由若干括号和字母组成的字符串 `s`，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按**任意顺序**返回。

**示例 1：**
```
输入：s = "()())()"
输出：["(())()","()()()"]
```

**示例 2：**
```
输入：s = "(a)())()"
输出：["(a())()","(a)()()"]
```

**示例 3：**
```
输入：s = ")("
输出：[""]
```

**提示：**
- `1 <= s.length <= 25`
- `s` 由小写英文字母以及括号 `'('` 和 `')'` 组成
- `s` 中至多含 20 个括号

## 解题思路

这道题的核心是找到需要删除的**最小数量**的括号，使得字符串有效。关键点：

1. **先确定需要删除的数量**：
   - 遍历字符串，统计需要删除的左括号和右括号数量
   - 左括号过多：出现了多余的 `(`
   - 右括号过多：出现了无法匹配的 `)`

2. **使用 BFS 或 DFS 生成所有可能的删除方案**：
   - BFS 方法：每次删除一个括号，层层扩展，第一次得到有效字符串时就是最小删除
   - DFS 方法：记录需要删除的左右括号数量，递归尝试删除

3. **去重**：使用 set 存储结果，避免重复

## Python 代码实现

### 方法一：BFS（推荐）⭐

```python
from typing import List
from collections import deque

class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        def is_valid(s: str) -> bool:
            """判断字符串是否有效"""
            count = 0
            for c in s:
                if c == '(':
                    count += 1
                elif c == ')':
                    count -= 1
                    if count < 0:
                        return False
            return count == 0
        
        # BFS：从原字符串开始，每次删除一个括号
        result = []
        visited = {s}  # 去重
        queue = deque([s])
        found = False  # 标记是否找到有效字符串
        
        while queue:
            current = queue.popleft()
            
            # 检查当前字符串是否有效
            if is_valid(current):
                result.append(current)
                found = True
            
            # 如果已经找到有效字符串，就不再继续删除（保证最小删除）
            if found:
                continue
            
            # 尝试删除每个位置的括号
            for i in range(len(current)):
                # 只删除括号
                if current[i] not in '()':
                    continue
                
                # 删除第 i 个字符
                next_s = current[:i] + current[i+1:]
                
                # 去重
                if next_s not in visited:
                    visited.add(next_s)
                    queue.append(next_s)
        
        return result
```

### 方法二：DFS + 剪枝（更优）⭐⭐

```python
from typing import List

class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        # 先计算需要删除的左右括号数量
        left_remove = 0  # 需要删除的左括号数量
        right_remove = 0  # 需要删除的右括号数量
        
        for c in s:
            if c == '(':
                left_remove += 1
            elif c == ')':
                if left_remove > 0:
                    left_remove -= 1
                else:
                    right_remove += 1
        
        result = []
        
        def dfs(index: int, left_count: int, right_count: int, 
                left_rem: int, right_rem: int, path: str):
            """
            index: 当前处理到的字符位置
            left_count: 当前路径中左括号的数量
            right_count: 当前路径中右括号的数量
            left_rem: 还需要删除的左括号数量
            right_rem: 还需要删除的右括号数量
            path: 当前构建的字符串
            """
            # 递归终止条件
            if index == len(s):
                if left_rem == 0 and right_rem == 0:
                    result.append(path)
                return
            
            c = s[index]
            
            # 情况1：删除当前字符（如果是括号且还需要删除）
            if c == '(' and left_rem > 0:
                # 删除左括号
                dfs(index + 1, left_count, right_count, left_rem - 1, right_rem, path)
            if c == ')' and right_rem > 0:
                # 删除右括号
                dfs(index + 1, left_count, right_count, left_rem, right_rem - 1, path)
            
            # 情况2：保留当前字符
            if c != '(' and c != ')':
                # 不是括号，直接加入
                dfs(index + 1, left_count, right_count, left_rem, right_rem, path + c)
            elif c == '(':
                # 保留左括号
                dfs(index + 1, left_count + 1, right_count, left_rem, right_rem, path + c)
            elif right_count < left_count:
                # 保留右括号（但必须保证右括号不超过左括号）
                dfs(index + 1, left_count, right_count + 1, left_rem, right_rem, path + c)
        
        dfs(0, 0, 0, left_remove, right_remove, "")
        
        # 去重
        return list(set(result))
```

### 方法三：DFS + 优化去重

```python
from typing import List

class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        # 计算需要删除的左右括号数量
        left_remove, right_remove = 0, 0
        for c in s:
            if c == '(':
                left_remove += 1
            elif c == ')':
                if left_remove > 0:
                    left_remove -= 1
                else:
                    right_remove += 1
        
        result = []
        
        def dfs(s: str, start: int, left_rem: int, right_rem: int, 
                left_count: int, right_count: int, path: str):
            if left_rem == 0 and right_rem == 0:
                if is_valid(path):
                    result.append(path)
                return
            
            for i in range(start, len(s)):
                # 去重：跳过连续相同的括号
                if i > start and s[i] == s[i-1]:
                    continue
                
                # 剪枝：剩余字符不够删除
                if left_rem + right_rem > len(s) - i:
                    break
                
                # 尝试删除左括号
                if left_rem > 0 and s[i] == '(':
                    dfs(s, i + 1, left_rem - 1, right_rem, left_count, right_count, path)
                
                # 尝试删除右括号
                if right_rem > 0 and s[i] == ')':
                    dfs(s, i + 1, left_rem, right_rem - 1, left_count, right_count, path)
                
                # 保留当前字符
                path += s[i]
                if s[i] == '(':
                    left_count += 1
                elif s[i] == ')':
                    right_count += 1
                
                # 剪枝：右括号已经多于左括号
                if right_count > left_count:
                    break
        
        def is_valid(s: str) -> bool:
            count = 0
            for c in s:
                if c == '(':
                    count += 1
                elif c == ')':
                    count -= 1
                    if count < 0:
                        return False
            return count == 0
        
        dfs(s, 0, left_remove, right_remove, 0, 0, "")
        return result
```

## 复杂度分析

**方法一（BFS）：**
- 时间复杂度：O(2^n)，最坏情况下需要尝试所有删除组合
- 空间复杂度：O(2^n)，队列和 visited 集合的空间

**方法二（DFS）：**
- 时间复杂度：O(2^n)，每个括号有删除和保留两种选择
- 空间复杂度：O(n)，递归栈的深度

## 关键点总结

1. **先计算最小删除数量**：遍历字符串，统计需要删除的左右括号数量
2. **BFS 保证最小删除**：第一次遇到有效字符串时，就是删除最少的方案
3. **DFS 需要预先计算**：通过预先计算删除数量来保证最小删除
4. **剪枝优化**：
   - 右括号数量不能超过左括号数量
   - 跳过连续相同的括号避免重复
5. **去重**：使用 set 或在递归中避免重复

## 易错点

1. **忘记去重**：不同的删除方案可能产生相同的结果
2. **没有保证最小删除**：必须先计算需要删除的数量
3. **剪枝不当**：过度剪枝可能漏掉正确答案
4. **边界条件**：空字符串、全是字母、全是括号等情况
