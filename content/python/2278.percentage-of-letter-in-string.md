## 题目描述

给你一个字符串 `s` 和一个字符 `letter`，返回在 `s` 中等于 `letter` 的字符所占的**百分比**，向下取整。

**示例 1：**
```
输入：s = "foobar", letter = "o"
输出：33
解释："o" 出现 2 次，共 6 个字符，2/6 = 0.333...，向下取整为 33。
```

**示例 2：**
```
输入：s = "jjjj", letter = "k"
输出：0
```

## 解题思路

统计 `letter` 在 `s` 中出现的次数，然后计算 `count * 100 // len(s)`（整数除法向下取整）。

## 代码实现

### 方法一：count + 整除（推荐）

```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        # 统计出现次数，计算百分比（向下取整）
        return s.count(letter) * 100 // len(s)
```

### 方法二：手动统计

```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        count = sum(1 for c in s if c == letter)
        return count * 100 // len(s)
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串统计。
- 空间复杂度：O(1)。

## 关键点总结

1. `str.count(sub)` 统计子串出现次数，O(n)。
2. 百分比计算：`count * 100 // len(s)`，先乘 100 再整除，避免浮点数。
3. 向下取整用 `//` 整数除法。

## 易错点

- 先乘 100 再整除，否则 `count / len(s)` 为浮点数，精度可能有问题。
