## 题目描述

给定一个整数数组 `stones`，其中 `stones[i]` 表示第 `i` 块石头的重量。

每一回合，从中选出两块**最重的**石头，然后将它们一起粉碎。假设石头的重量分别为 `x` 和 `y`，且 `x <= y`。那么粉碎的结果如下：

- 如果 `x == y`，那么两块石头都会被完全粉碎
- 如果 `x != y`，那么重量为 `x` 的石头将会被完全粉碎，而重量为 `y` 的石头新重量为 `y-x`

最后，最多只会剩下一块石头。返回此石头的重量。如果没有石头剩下，就返回 `0`。

**示例 1：**

```
输入：stones = [2,7,4,1,8,1]
输出：1
解释：
先选出 7 和 8，得到 1，所以数组转换为 [2,4,1,1,1]，
再选出 2 和 4，得到 2，所以数组转换为 [2,1,1,1]，
接着选出 2 和 1，得到 1，所以数组转换为 [1,1,1]，
最后选出 1 和 1，得到 0，所以数组转换为 [1]，这就是最后剩下的石头重量。
```

**示例 2：**

```
输入：stones = [1]
输出：1
```

**提示：**

- `1 <= stones.length <= 30`
- `1 <= stones[i] <= 1000`

## 解题思路

这道题的核心思路是**每次都要选择两块最重的石头**，这提示我们需要一个能够快速获取最大值的数据结构。

**关键观察：**
1. 每次操作都需要找到当前最重的两块石头
2. 粉碎后可能产生新的石头（重量为差值），需要放回集合中
3. 这个过程持续到只剩一块或没有石头

**最优解法：最大堆**

使用**最大堆（Max Heap）**可以在 `O(log n)` 时间内获取最大值，非常适合这道题。

Python 的 `heapq` 模块默认是**最小堆**，我们可以通过将所有数字取负数来模拟最大堆：
- 存入堆时：`-stone`
- 取出时：再次取负数恢复原值

**算法流程：**
1. 将所有石头重量取负数后放入最小堆（模拟最大堆）
2. 当堆中有两个或以上元素时：
   - 取出最重的两块石头（堆顶的两个元素）
   - 如果两块石头重量不同，将差值放回堆中
3. 返回最后剩余石头的重量（如果堆为空则返回 0）

## Python 代码实现

### 方法一：最大堆（推荐）

```python
from typing import List
import heapq

class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        # 将所有石头重量取负数，放入最小堆（模拟最大堆）
        heap = [-stone for stone in stones]
        heapq.heapify(heap)
        
        # 当堆中有两个或以上石头时，持续粉碎
        while len(heap) > 1:
            # 取出最重的两块石头（因为是负数，所以是最小的两个）
            first = -heapq.heappop(heap)   # 最重的石头
            second = -heapq.heappop(heap)  # 第二重的石头
            
            # 如果两块石头重量不同，将差值放回堆中
            if first != second:
                heapq.heappush(heap, -(first - second))
        
        # 返回最后剩余的石头重量，如果堆为空则返回 0
        return -heap[0] if heap else 0
```

### 方法二：排序模拟（暴力解法）

```python
from typing import List

class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        # 每次都对数组排序，选择最大的两个石头
        while len(stones) > 1:
            stones.sort()  # 排序
            
            # 取出最重的两块石头
            first = stones.pop()   # 最大的
            second = stones.pop()  # 第二大的
            
            # 如果两块石头重量不同，将差值放回数组
            if first != second:
                stones.append(first - second)
        
        # 返回最后剩余的石头重量
        return stones[0] if stones else 0
```

### 方法三：使用 Python 标准库的优化写法

```python
from typing import List
import heapq

class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        # 将所有石头取负数并建堆
        stones = [-stone for stone in stones]
        heapq.heapify(stones)
        
        # 持续粉碎直到剩余一块或没有石头
        while len(stones) > 1:
            # 一次性取出并计算差值
            diff = heapq.heappop(stones) - heapq.heappop(stones)
            if diff:  # 只有当差值不为 0 时才放回
                heapq.heappush(stones, diff)
        
        return -stones[0] if stones else 0
```

## 复杂度分析

### 方法一：最大堆（推荐）
- **时间复杂度：** `O(n log n)`
  - 建堆：`O(n)`
  - 每次取出和插入操作：`O(log n)`
  - 最多进行 `n-1` 次操作
  - 总时间：`O(n) + O((n-1) log n) = O(n log n)`
- **空间复杂度：** `O(n)` - 堆的空间

### 方法二：排序模拟
- **时间复杂度：** `O(n² log n)`
  - 每次循环都需要排序 `O(n log n)`
  - 最多循环 `n-1` 次
- **空间复杂度：** `O(1)` - 原地修改（不考虑排序的空间）

### 方法三：优化写法
- **时间复杂度：** `O(n log n)` - 与方法一相同
- **空间复杂度：** `O(n)` - 堆的空间

## 图解示例

以 `stones = [2,7,4,1,8,1]` 为例：

```
初始堆（取负数）：[-8, -7, -4, -1, -2, -1]

第 1 回合：
  取出 -8 和 -7 → 石头重量 8 和 7
  差值：8 - 7 = 1
  放回 -1
  堆：[-4, -2, -1, -1, -1]

第 2 回合：
  取出 -4 和 -2 → 石头重量 4 和 2
  差值：4 - 2 = 2
  放回 -2
  堆：[-2, -1, -1, -1]

第 3 回合：
  取出 -2 和 -1 → 石头重量 2 和 1
  差值：2 - 1 = 1
  放回 -1
  堆：[-1, -1, -1]

第 4 回合：
  取出 -1 和 -1 → 石头重量 1 和 1
  差值：1 - 1 = 0
  不放回
  堆：[-1]

结果：剩余石头重量为 1
```

## 关键点总结

1. **数据结构选择**：需要频繁获取最大值，最大堆是最优选择
2. **Python 技巧**：使用负数模拟最大堆，`heapq` 默认是最小堆
3. **边界处理**：最后堆可能为空（所有石头都粉碎完），需要返回 0
4. **优化细节**：差值为 0 时无需放回堆中
5. **时间优化**：堆操作 `O(log n)` 远优于每次排序 `O(n log n)`

## 易错点

1. **忘记处理空堆情况**
   ```python
   # 错误：直接返回 heap[0] 可能导致索引越界
   return -heap[0]
   
   # 正确：先判断堆是否为空
   return -heap[0] if heap else 0
   ```

2. **最大堆实现错误**
   ```python
   # 错误：直接使用 heapq（这是最小堆）
   heapq.heappush(heap, stone)
   
   # 正确：取负数模拟最大堆
   heapq.heappush(heap, -stone)
   ```

3. **取出元素后忘记转换**
   ```python
   # 错误：取出的是负数，需要转换
   first = heapq.heappop(heap)
   
   # 正确：转换为正数
   first = -heapq.heappop(heap)
   ```

4. **相同重量的石头也要处理**
   ```python
   # 正确的逻辑：只有当差值不为 0 时才放回
   if first != second:
       heapq.heappush(heap, -(first - second))
   ```
