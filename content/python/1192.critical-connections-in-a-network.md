## 题目描述

力扣数据中心有 `n` 台服务器，分别按从 `0` 到 `n-1` 的方式进行了编号。它们之间以「服务器到服务器」点对点的形式相互连接组成了一个内部集群，连接是无向的。

从形式上讲，连接可以表示为 `connections`，其中 `connections[i] = [a, b]` 表示服务器 `a` 和 `b` 之间形成连接。任何服务器都可以直接或者间接地通过网络到达任何其他服务器。

关键连接是在该集群中的重要连接，假如我们将它移除，便会导致某些服务器无法访问其他服务器。

请你以任意顺序返回该集群内的所有关键连接。

**示例 1：**
```
输入：n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
输出：[[1,3]]
解释：[[3,1]] 也是正确答案。
```

**示例 2：**
```
输入：n = 2, connections = [[0,1]]
输出：[[0,1]]
```

**提示：**
- `2 <= n <= 10^5`
- `n - 1 <= connections.length <= 10^5`
- `0 <= ai, bi <= n - 1`
- `ai != bi`
- 不存在重复的连接

## 解题思路

这道题是求图中的「桥」（Bridge），也叫「割边」，是图论中的经典问题。

**核心思路：**

1. **桥的定义**：删除该边后，图的连通分量数增加。

2. **Tarjan 算法**：
   - 使用 DFS 遍历图
   - 记录每个节点的访问时间戳 `dfn[u]`
   - 记录从节点 `u` 出发能访问到的最早时间戳 `low[u]`
   - 如果 `low[v] > dfn[u]`，说明 `(u, v)` 是桥

3. **关键概念**：
   - `dfn[u]`：节点 u 被首次访问的时间戳
   - `low[u]`：从 u 或 u 的子孙能够追溯到的最早的栈中节点的时间戳

## Python 代码实现

### 方法一：Tarjan 算法（推荐）⭐

```python
from typing import List
from collections import defaultdict

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        """
        使用 Tarjan 算法找出所有的桥（关键连接）
        """
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)
        
        # dfn[u]: 节点 u 的访问时间戳
        # low[u]: 从 u 或 u 的子孙能访问到的最早时间戳
        dfn = [-1] * n
        low = [-1] * n
        self.time = 0  # 全局时间戳
        result = []
        
        def dfs(u: int, parent: int) -> None:
            """
            DFS 遍历，寻找桥
            :param u: 当前节点
            :param parent: 父节点，避免走回头路
            """
            # 初始化时间戳
            dfn[u] = low[u] = self.time
            self.time += 1
            
            # 遍历所有邻居
            for v in graph[u]:
                # 跳过父节点（避免走回头路）
                if v == parent:
                    continue
                
                if dfn[v] == -1:
                    # v 未访问过，继续 DFS
                    dfs(v, u)
                    
                    # 更新 low[u]：取子节点的最小 low 值
                    low[u] = min(low[u], low[v])
                    
                    # 判断是否为桥
                    # 如果 low[v] > dfn[u]，说明 v 无法回到 u 或更早的节点
                    # 因此 (u, v) 是桥
                    if low[v] > dfn[u]:
                        result.append([u, v])
                else:
                    # v 已访问过，更新 low[u]
                    low[u] = min(low[u], dfn[v])
        
        # 从节点 0 开始 DFS
        dfs(0, -1)
        
        return result
```

### 方法二：带注释的详细版本

```python
from typing import List
from collections import defaultdict

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        # 第一步：构建图的邻接表表示
        graph = defaultdict(list)
        for a, b in connections:
            graph[a].append(b)
            graph[b].append(a)
        
        # 初始化数据结构
        visited = [False] * n  # 标记节点是否访问过
        discovery_time = [0] * n  # 节点的发现时间
        lowest_time = [0] * n  # 从该节点能访问到的最早时间
        parent = [-1] * n  # 记录父节点
        bridges = []  # 存储所有的桥
        time_counter = [0]  # 使用列表作为可变对象，存储时间戳
        
        def dfs_bridge(u):
            """
            DFS 遍历寻找桥
            """
            # 标记为已访问
            visited[u] = True
            # 初始化发现时间和最早时间
            discovery_time[u] = lowest_time[u] = time_counter[0]
            time_counter[0] += 1
            
            # 遍历所有邻居节点
            for v in graph[u]:
                if not visited[v]:
                    # v 未访问，设置父节点并递归
                    parent[v] = u
                    dfs_bridge(v)
                    
                    # 回溯时更新 lowest_time
                    lowest_time[u] = min(lowest_time[u], lowest_time[v])
                    
                    # 检查是否为桥
                    # 条件：子节点 v 无法回到 u 或更早的节点
                    if lowest_time[v] > discovery_time[u]:
                        bridges.append([u, v])
                
                elif v != parent[u]:
                    # v 已访问且不是父节点（发现回边）
                    # 更新 lowest_time
                    lowest_time[u] = min(lowest_time[u], discovery_time[v])
        
        # 从节点 0 开始 DFS（题目保证图是连通的）
        dfs_bridge(0)
        
        return bridges
```

### 方法三：使用类属性的简洁版

```python
from typing import List
from collections import defaultdict

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)
        
        dfn = {}  # 使用字典，未访问的节点不在字典中
        low = {}
        self.timer = 0
        bridges = []
        
        def tarjan(u, parent):
            dfn[u] = low[u] = self.timer
            self.timer += 1
            
            for v in graph[u]:
                if v == parent:
                    continue
                if v not in dfn:
                    tarjan(v, u)
                    low[u] = min(low[u], low[v])
                    if low[v] > dfn[u]:
                        bridges.append([u, v])
                else:
                    low[u] = min(low[u], dfn[v])
        
        tarjan(0, -1)
        return bridges
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(V + E)，其中 V 是节点数，E 是边数。每个节点和每条边都会被访问一次。
- **空间复杂度**：O(V + E)，存储图的邻接表和递归调用栈。

## 关键点总结

1. **Tarjan 算法核心**：通过 DFS 和时间戳判断桥
2. **dfn 和 low 的含义**：dfn 是访问时间，low 是能回溯到的最早时间
3. **桥的判断条件**：`low[v] > dfn[u]` 说明 v 无法绕过 (u,v) 回到 u
4. **避免回头路**：遍历邻居时要跳过父节点
5. **图的表示**：使用邻接表存储无向图

## 易错点

1. **忘记跳过父节点**：会导致误判，必须判断 `v != parent`
2. **重复边的处理**：题目保证没有重复边，但实际应用中要注意
3. **图不连通的情况**：题目保证连通，实际应用中可能需要遍历所有节点
4. **low 值更新顺序**：必须在递归返回后更新
5. **时间戳初始化**：dfn 初始化为 -1 或使用字典判断是否访问过
