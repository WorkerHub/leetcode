## 题目描述

给你一个整数数组 `nums`，请你找出并返回在该数组中仅出现一次的最大整数。如果不存在这样的整数，则返回 `-1`。

**示例 1：**
```
输入：nums = [5,7,3,9,4,9,8,3,1]
输出：8
解释：数组中最大的仅出现一次的整数是 8
```

**示例 2：**
```
输入：nums = [9,9,8,8]
输出：-1
解释：数组中没有仅出现一次的整数
```

**提示：**
- `1 <= nums.length <= 2000`
- `0 <= nums[i] <= 1000`

## 解题思路

这是一道简单的数组统计题，关键是找到只出现一次的数字中的最大值。

### 解题步骤

1. 统计每个数字出现的次数
2. 筛选出只出现一次的数字
3. 返回其中的最大值，如果不存在则返回 -1

## Python 代码实现

### 方法一：哈希表计数（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        # 统计每个数字出现的次数
        count = Counter(nums)
        
        # 找出只出现一次的数字中的最大值
        result = -1
        for num, freq in count.items():
            if freq == 1:
                result = max(result, num)
        
        return result
```

### 方法二：一行代码

```python
from typing import List
from collections import Counter

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        count = Counter(nums)
        # 筛选出只出现一次的数字，取最大值，如果为空则返回 -1
        return max([num for num, freq in count.items() if freq == 1], default=-1)
```

### 方法三：手动计数

```python
from typing import List

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        # 手动统计
        count = {}
        for num in nums:
            count[num] = count.get(num, 0) + 1
        
        # 找最大的只出现一次的数字
        result = -1
        for num, freq in count.items():
            if freq == 1 and num > result:
                result = num
        
        return result
```

### 方法四：排序后统计

```python
from typing import List

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        # 降序排序
        nums.sort(reverse=True)
        n = len(nums)
        
        i = 0
        while i < n:
            # 计算当前数字的出现次数
            j = i
            while j < n and nums[j] == nums[i]:
                j += 1
            
            # 如果只出现一次，返回（因为是降序，第一个满足条件的就是最大的）
            if j - i == 1:
                return nums[i]
            
            i = j
        
        return -1
```

### 方法五：利用数据范围优化

```python
from typing import List

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        # 由于 nums[i] <= 1000，可以用数组计数
        count = [0] * 1001
        
        for num in nums:
            count[num] += 1
        
        # 从大到小查找第一个只出现一次的数字
        for num in range(1000, -1, -1):
            if count[num] == 1:
                return num
        
        return -1
```

## 复杂度分析

### 方法一、二、三（哈希表）

- **时间复杂度**：O(n)，遍历数组统计，再遍历哈希表找最大值
- **空间复杂度**：O(n)，哈希表存储

### 方法四（排序）

- **时间复杂度**：O(n log n)，排序的时间
- **空间复杂度**：O(1) 或 O(n)，取决于排序算法

### 方法五（数组计数）

- **时间复杂度**：O(n + k)，其中 k = 1001
- **空间复杂度**：O(k) = O(1)，固定大小的数组

## 关键点总结

1. **Counter 使用**：Python 的 `collections.Counter` 是统计频次的利器
2. **max 函数的 default 参数**：当序列为空时返回默认值，避免异常
3. **数据范围优化**：当数据范围较小时，可以用数组代替哈希表
4. **排序优化**：降序排序后，第一个满足条件的就是答案
5. **列表推导式**：简洁地筛选和处理数据

## 易错点

1. **空数组处理**：虽然题目保证 `length >= 1`，但如果所有数字都重复，需要返回 -1
2. **初始值设置**：结果初始化为 -1，而非 0（因为 0 可能是有效答案）
3. **频次判断**：只能是 `freq == 1`，而非 `freq <= 1`
4. **max 函数异常**：对空列表调用 `max()` 会抛出异常，需要使用 `default` 参数
5. **数组越界**：方法五中，循环范围应该是 `range(1000, -1, -1)`
