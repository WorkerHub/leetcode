## 题目描述

给定整数数组 `nums`，找出其中和最大的子数组，但该子数组中不能包含**连续的两个零**（即子数组中任意两个相邻元素不能同时为 0）。返回满足条件的子数组最大和。

**示例 1：**
```
输入：nums = [1,0,0,2,3]
输出：6
解释：不能包含连续两个零，所以 [1,0,0,2,3] 不合法。
     子数组 [2,3] 和为 5；[0,2,3] 和为 5；[1,0,2,3]? 0 和 2 不相邻且非连续零... 
     实际 [1,0,2,3] 中没有连续零，和为 6，合法！
```

**示例 2：**
```
输入：nums = [-1,0,0,-1]
输出：0
解释：无法找到满足条件的正和子数组，返回 0（空子数组）或 -1？根据题意取 0。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

动态规划。

定义：
- `dp0[i]`：以 `nums[i]=0` 结尾的满足条件子数组的最大和
- `dp1[i]`：以 `nums[i]!=0`（或任意非零）结尾的满足条件子数组的最大和

转移：
- 若 `nums[i] == 0`：前一个元素不能为 0（否则有连续零），所以 `dp0[i] = dp1[i-1] + 0`
- 若 `nums[i] != 0`：可以接在任何满足条件的子数组后，`dp1[i] = max(dp0[i-1], dp1[i-1]) + nums[i]`

答案 = `max(dp0, dp1, 0)`（0 代表空子数组）

## Python 代码实现

### 方法一：DP（推荐）

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int]) -> int:
        n = len(nums)
        # dp_zero: 以当前位置（值为0）结尾的最大满足条件子数组和
        # dp_nonzero: 以当前位置（值非0或任意）结尾的最大满足条件子数组和
        dp_zero = 0    # 上一个以 0 结尾的最优和
        dp_nonzero = 0 # 上一个以非零结尾的最优和
        ans = 0

        for x in nums:
            if x == 0:
                # 当前为 0，只能接在以非零结尾的子数组后（或单独开始）
                new_zero = dp_nonzero  # 接上之前以非零结尾的子数组
                new_nonzero = dp_nonzero  # 不变（因为当前是 0，不更新非零状态）
                dp_zero = max(0, new_zero)
                dp_nonzero = dp_nonzero  # 保持不变，等下次非零元素更新
                ans = max(ans, dp_zero)
            else:
                # 当前非零，可以接在任何合法子数组后
                new_nonzero = max(dp_zero, dp_nonzero) + x
                dp_nonzero = max(0, new_nonzero)
                ans = max(ans, dp_nonzero)

        return ans
```

### 方法二：简化版 DP

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int]) -> int:
        # last: 上一个元素是否为 0
        # cur_sum: 当前满足条件子数组的和
        n = len(nums)
        ans = 0
        cur_sum = 0
        prev_zero = False

        for x in nums:
            if x == 0:
                if prev_zero:
                    # 连续两个零，子数组中断
                    cur_sum = 0
                else:
                    cur_sum += 0  # 加入当前零
                prev_zero = True
            else:
                cur_sum += x
                prev_zero = False

            cur_sum = max(cur_sum, 0)
            ans = max(ans, cur_sum)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 遇到连续两个零时，当前子数组必须中断
2. 类似 Kadane 算法，维护当前最优子数组和
3. 遇到连续零则重置当前和为 0

## 易错点

1. 单个零可以包含在子数组中，只是连续两个零不行
2. 结果可以为 0（空子数组或所有元素为负）
