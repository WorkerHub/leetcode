## 题目描述

TinyURL 是一种 URL 缩短服务，你输入一个 URL，例如 `https://leetcode.com/problems/design-tinyurl`，它会返回一个短 URL，例如 `http://tinyurl.com/4e9iAk`。

请你设计一个类来编码（encode）和解码（decode）URL。

对于编码/解码算法如何工作没有限制。你只需要保证一个 URL 可以被编码为一个短 URL，并且这个短 URL 可以被解码为原始 URL。

实现 `Solution` 类：

- `Solution()` 初始化系统对象
- `String encode(String longUrl)` 返回给定 `longUrl` 的短 URL
- `String decode(String shortUrl)` 返回给定 `shortUrl` 的原始长 URL。保证给定的 `shortUrl` 是由同一个对象编码的

**示例 1：**
```
输入: url = "https://leetcode.com/problems/design-tinyurl"
输出: "https://leetcode.com/problems/design-tinyurl"

解释:
Solution obj = new Solution();
string tiny = obj.encode(url); // 返回编码后的短 URL
string ans = obj.decode(tiny); // 返回解码后的原始 URL
```

**提示：**
- `1 <= url.length <= 10^4`
- `url` 保证是一个有效的 URL

**注意：** 这是一个配套系统设计问题的编程题目

## 解题思路

这道题是一个系统设计的简化版本，主要考察哈希表的应用和编码设计思维。

**核心思想：**

建立长 URL 和短 URL 之间的双向映射关系。

**常见设计方案：**

### 方案一：自增 ID（最简单）

- 使用一个计数器生成唯一 ID
- 将 ID 作为短 URL 的后缀
- 用哈希表存储 `ID → 长URL` 的映射

**优点：** 实现简单，不会冲突  
**缺点：** ID 可预测，不够安全；容易猜测总量

### 方案二：随机字符串

- 生成随机的 6-8 位字符串
- 检查是否冲突，冲突则重新生成
- 用两个哈希表存储双向映射

**优点：** 不可预测，更安全  
**缺点：** 可能有冲突，需要处理重试逻辑

### 方案三：哈希算法

- 使用 MD5/SHA256 等哈希算法
- 取哈希值的前几位作为短 URL
- 处理哈希冲突

**优点：** 确定性强，相同 URL 生成相同短链接  
**缺点：** 仍可能冲突，需要额外处理

### 方案四：Base62 编码

- 将自增 ID 转换为 Base62 编码（0-9, a-z, A-Z）
- 更短的编码长度

**优点：** 编码更紧凑  
**缺点：** 需要实现 Base62 编解码

## Python 代码实现

### 方法一：自增 ID 法（推荐）

```python
from collections import defaultdict

class Codec:
    """
    使用自增 ID 作为短 URL 的标识
    简单高效，适合面试场景
    """
    def __init__(self):
        # 存储 ID 到长 URL 的映射
        self.url_map = defaultdict(str)
        # 自增计数器
        self.id_counter = 0
        # 短 URL 的域名前缀
        self.base_url = "http://tinyurl.com/"
    
    def encode(self, longUrl: str) -> str:
        """将长 URL 编码为短 URL"""
        # ID 自增
        self.id_counter += 1
        # 使用当前 ID 作为键
        url_id = str(self.id_counter)
        # 存储映射
        self.url_map[url_id] = longUrl
        # 返回短 URL
        return self.base_url + url_id
    
    def decode(self, shortUrl: str) -> str:
        """将短 URL 解码为长 URL"""
        # 从短 URL 中提取 ID（最后一个 '/' 之后的部分）
        url_id = shortUrl.split('/')[-1]
        # 从映射中获取长 URL
        return self.url_map[url_id]
```

### 方法二：随机字符串法

```python
import random
import string

class Codec:
    """
    使用随机字符串作为短 URL 标识
    更安全，不可预测
    """
    def __init__(self):
        # 存储短码到长 URL 的映射
        self.url_map = {}
        # 存储长 URL 到短码的映射（避免重复编码）
        self.reverse_map = {}
        self.base_url = "http://tinyurl.com/"
        # 短码长度
        self.code_length = 6
        # 字符集：数字 + 大小写字母
        self.chars = string.ascii_letters + string.digits
    
    def _generate_code(self) -> str:
        """生成随机短码"""
        while True:
            # 随机生成 6 位字符串
            code = ''.join(random.choices(self.chars, k=self.code_length))
            # 如果不冲突，返回
            if code not in self.url_map:
                return code
    
    def encode(self, longUrl: str) -> str:
        """将长 URL 编码为短 URL"""
        # 如果已经编码过，直接返回
        if longUrl in self.reverse_map:
            return self.base_url + self.reverse_map[longUrl]
        
        # 生成新的短码
        code = self._generate_code()
        
        # 双向映射
        self.url_map[code] = longUrl
        self.reverse_map[longUrl] = code
        
        return self.base_url + code
    
    def decode(self, shortUrl: str) -> str:
        """将短 URL 解码为长 URL"""
        code = shortUrl.split('/')[-1]
        return self.url_map.get(code, "")
```

### 方法三：Base62 编码法

```python
class Codec:
    """
    使用 Base62 编码（更紧凑）
    将自增 ID 转换为 62 进制
    """
    def __init__(self):
        self.url_map = {}
        self.id_counter = 0
        self.base_url = "http://tinyurl.com/"
        # Base62 字符集
        self.charset = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
    
    def _id_to_base62(self, num: int) -> str:
        """将数字转换为 Base62 编码"""
        if num == 0:
            return self.charset[0]
        
        result = []
        while num > 0:
            result.append(self.charset[num % 62])
            num //= 62
        
        return ''.join(reversed(result))
    
    def _base62_to_id(self, code: str) -> int:
        """将 Base62 编码转换为数字"""
        num = 0
        for char in code:
            num = num * 62 + self.charset.index(char)
        return num
    
    def encode(self, longUrl: str) -> str:
        """将长 URL 编码为短 URL"""
        self.id_counter += 1
        # 将 ID 转换为 Base62
        code = self._id_to_base62(self.id_counter)
        # 存储映射
        self.url_map[code] = longUrl
        return self.base_url + code
    
    def decode(self, shortUrl: str) -> str:
        """将短 URL 解码为长 URL"""
        code = shortUrl.split('/')[-1]
        return self.url_map.get(code, "")
```

### 方法四：哈希算法法

```python
import hashlib

class Codec:
    """
    使用 MD5 哈希算法
    相同 URL 生成相同短链接
    """
    def __init__(self):
        self.url_map = {}
        self.base_url = "http://tinyurl.com/"
    
    def encode(self, longUrl: str) -> str:
        """将长 URL 编码为短 URL"""
        # 使用 MD5 哈希
        hash_obj = hashlib.md5(longUrl.encode())
        # 取前 6 位作为短码
        code = hash_obj.hexdigest()[:6]
        
        # 处理哈希冲突
        while code in self.url_map and self.url_map[code] != longUrl:
            # 如果冲突，添加后缀重新哈希
            longUrl += '#'
            hash_obj = hashlib.md5(longUrl.encode())
            code = hash_obj.hexdigest()[:6]
        
        self.url_map[code] = longUrl.rstrip('#')
        return self.base_url + code
    
    def decode(self, shortUrl: str) -> str:
        """将短 URL 解码为长 URL"""
        code = shortUrl.split('/')[-1]
        return self.url_map.get(code, "")
```

### 方法五：详细注释版（适合初学者）

```python
class Codec:
    """
    TinyURL 编码解码器
    使用最简单的自增 ID 方法
    """
    def __init__(self):
        """
        初始化编码器
        - url_map: 存储短码到长 URL 的映射
        - id_counter: 自增计数器，用于生成唯一 ID
        - base_url: 短 URL 的域名前缀
        """
        self.url_map = {}
        self.id_counter = 0
        self.base_url = "http://tinyurl.com/"
    
    def encode(self, longUrl: str) -> str:
        """
        编码：将长 URL 转换为短 URL
        
        步骤：
        1. ID 计数器自增，获得唯一 ID
        2. 将 ID 转换为字符串作为短码
        3. 建立短码到长 URL 的映射
        4. 返回完整的短 URL
        
        示例：
        longUrl = "https://leetcode.com/problems/design-tinyurl"
        id_counter = 0 -> 1
        short_code = "1"
        返回 "http://tinyurl.com/1"
        """
        # 步骤 1: ID 自增
        self.id_counter += 1
        
        # 步骤 2: 生成短码（使用 ID 的字符串形式）
        short_code = str(self.id_counter)
        
        # 步骤 3: 存储映射关系
        self.url_map[short_code] = longUrl
        
        # 步骤 4: 拼接完整的短 URL
        short_url = self.base_url + short_code
        
        return short_url
    
    def decode(self, shortUrl: str) -> str:
        """
        解码：将短 URL 转换为长 URL
        
        步骤：
        1. 从短 URL 中提取短码（最后一个 '/' 后的部分）
        2. 使用短码从映射表中查找长 URL
        3. 返回长 URL
        
        示例：
        shortUrl = "http://tinyurl.com/1"
        提取短码 = "1"
        查找映射 -> "https://leetcode.com/problems/design-tinyurl"
        """
        # 步骤 1: 提取短码
        # 使用 split('/') 分割，取最后一部分
        short_code = shortUrl.split('/')[-1]
        
        # 步骤 2 & 3: 查找并返回长 URL
        long_url = self.url_map[short_code]
        
        return long_url
```

## 复杂度分析

### 方法一：自增 ID 法
- **编码时间复杂度**：O(1)，只需自增和插入哈希表
- **解码时间复杂度**：O(1)，哈希表查找
- **空间复杂度**：O(n)，n 是编码的 URL 数量

### 方法二：随机字符串法
- **编码时间复杂度**：平均 O(1)，极端情况可能需要多次重试
- **解码时间复杂度**：O(1)
- **空间复杂度**：O(n)，需要双向映射

### 方法三：Base62 编码法
- **编码时间复杂度**：O(log n)，Base62 转换
- **解码时间复杂度**：O(1)
- **空间复杂度**：O(n)

### 方法四：哈希算法法
- **编码时间复杂度**：O(k)，k 是 URL 长度（哈希计算）
- **解码时间复杂度**：O(1)
- **空间复杂度**：O(n)

**推荐使用方法一**，简单高效，适合面试场景。

## 关键点总结

1. **哈希表的应用**：建立短码和长 URL 之间的映射关系
2. **唯一性保证**：自增 ID 或随机字符串保证短码唯一
3. **双向映射**：方法二使用两个哈希表，避免重复编码同一个 URL
4. **字符串提取**：使用 `split('/')[-1]` 提取短 URL 的短码部分
5. **编码选择**：Base62 可以生成更短的编码

## 易错点

1. **忘记初始化数据结构**
   ```python
   # 错误：没有初始化
   class Codec:
       def encode(self, longUrl):
           self.id_counter += 1  # AttributeError
   
   # 正确：在 __init__ 中初始化
   def __init__(self):
       self.id_counter = 0
   ```

2. **短码提取错误**
   ```python
   # 错误：没有考虑完整 URL 结构
   code = shortUrl[-1]  # 只取最后一个字符
   
   # 正确：使用 split 提取
   code = shortUrl.split('/')[-1]
   ```

3. **随机字符串冲突处理**
   ```python
   # 错误：不检查冲突
   code = ''.join(random.choices(chars, k=6))
   
   # 正确：循环直到无冲突
   while True:
       code = ''.join(random.choices(chars, k=6))
       if code not in self.url_map:
           break
   ```

4. **忘记返回完整 URL**
   ```python
   # 错误：只返回短码
   return str(self.id_counter)
   
   # 正确：返回完整短 URL
   return self.base_url + str(self.id_counter)
   ```
