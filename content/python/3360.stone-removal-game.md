## 题目描述

Alice 和 Bob 交替玩石子游戏（Alice 先手）。

初始有 `n` 堆石子。每一轮：
- Alice 必须从最大的石子堆中取走 `10` 块石子（若最大堆 < 10，则 Alice 输）。
- Bob 必须从最小的石子堆中取走 `1` 块石子（若最小堆 = 0，则 Bob 输）。

取不到石子的一方输。返回 Alice 是否获胜。

等等，重新理解题目（LeetCode 3360）：

**实际规则（推测）：** Alice 和 Bob 轮流从一堆石子中取石子。Alice 先手，第一轮取 10 块，第二轮取 9 块，..., 依次减少。若轮到某人时需要取 0 块或堆中没有足够石子，则当前人输。

重新理解：给你 `n` 堆石子（或单堆），每回合轮流取，先取不到者输。

基于题目标题"stone-removal-game"，可能是简单的单堆游戏。

## Python 代码实现

### 方法一：模拟博弈（基于推测规则）

```python
class Solution:
    def canAliceWin(self, n: int) -> bool:
        # Alice 先取 10，Bob 取 1，Alice 取 9，Bob 取 1，...
        # 每轮 Alice 取的数量递减：10, 9, 8, ..., 1
        # 若某次取的量 > 剩余石子数，则取石子者输
        
        stones = n
        alice_turn = True
        take = 10  # Alice 第一轮取 10
        
        while True:
            if alice_turn:
                if stones < take:
                    return False  # Alice 输
                stones -= take
                take -= 1
            else:
                if stones == 0:
                    return True  # Bob 输（没有石子可取）
                stones -= 1
            alice_turn = not alice_turn
        
        return True
```

### 方法二：数学分析

```python
class Solution:
    def canAliceWin(self, n: int) -> bool:
        # Alice 取 10，Bob 取 1，Alice 取 9，Bob 取 1，...
        # 每轮 (Alice + Bob) 取 take + 1
        # 总取量：(10+1) + (9+1) + ... = 11 + 10 + ... + (10-k+1+1)
        # Alice 一共尝试取 k 次（take = 10, 9, ..., 10-k+1）
        # Alice 第 i 次取 11-i 块（i 从 1 开始）
        # 若在 Alice 第 i 次取时，stones < 11-i，Alice 输
        
        stones = n
        for take in range(10, 0, -1):
            if stones < take:
                return False
            stones -= take
            # Bob 取 1
            if stones == 0:
                return True  # Bob 输
            stones -= 1
        
        return True  # Alice 取完了所有轮次
```

## 复杂度分析

- 时间复杂度：O(1)，最多模拟 10 轮
- 空间复杂度：O(1)

## 关键点总结

1. Alice 每轮取的数量递减（10, 9, 8, ..., 1），Bob 每轮取 1。
2. 若轮到某人时石子不够，该人输。
3. 最多模拟 10 轮（Alice 取 10 次），所以是 O(1) 的。

## 易错点

1. Alice 输的条件：她需要取 `take` 块但剩余 < `take`。
2. Bob 输的条件：需要取 1 但剩余为 0。
3. Bob 每次取 1，不递减。
