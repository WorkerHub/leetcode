## 题目描述

给你一个下标从 0 开始的整数数组 `nums`。

初始时，`nums` 中所有元素未被选中。

每次操作，你可以选择 `nums` 中的一个元素，将其 +1（可以多次操作同一元素）。

你需要从 `nums` 中选出一些元素，使它们的值构成一个连续的集合（即最终集合中的值两两相差 1，且连续）。

返回最多能选出多少个元素。

**示例 1：**
```
输入：nums = [2,1,5,1,1]
输出：3
解释：选下标 0,1,2，操作后变为 2,2,5；不对，重新想：选下标 1,3,4，值为 1,1,1，可以变为 1,2,3，选 3 个
```

**示例 2：**
```
输入：nums = [1,4,7,10]
输出：4
解释：将所有元素加一些次数使其变为 1,4,7,10 → 不连续；或 1,2,3,4 → 只需将 4 改为 2,3，不行
实际上每个元素只能 +1 最多一次（重读题目）
```

等等，重新读题：每次操作对某个元素 +1，**没有次数限制**，但每个元素只能最终选或不选。被选元素的值（经过操作后）必须是一个连续整数集合。

**正确理解：** 可以对任意元素操作任意次，使其增大，选出一个子集使其构成连续整数序列（相差为 1 的连续值）。

由于可以任意增大，最优策略是：每个元素要么保持原值，要么 +1（多余的 +1 是浪费）。

重读：操作一次使元素 +1，可以多次操作，但关键是选的子集的**最终值**必须是连续的。

由于可以无限增大，实际上每个元素可以变为任意 >= nums[i] 的值。

## 解题思路

排序后，每个元素可以变为 `nums[i]` 或 `nums[i] + 1`（实际上可以更大，但贪心不需要 +2 以上）。

DP：`dp[v]` = 使用值 `v` 结尾的最长连续序列长度。

排序后遍历 `nums`，对每个 `nums[i]`：
- 用 `nums[i]` 本身：`dp[nums[i]] = dp[nums[i]-1] + 1`
- 用 `nums[i] + 1`：`dp[nums[i]+1] = dp[nums[i]] + 1`

## Python 代码实现

### 方法一：排序 + DP（推荐）

```python
from typing import List

class Solution:
    def maxSelectedElements(self, nums: List[int]) -> int:
        nums.sort()
        # dp[v] = 以 v 结尾的连续序列最长长度
        dp = {}
        ans = 1

        for x in nums:
            # 选 x+1（x 变成 x+1）
            dp[x + 1] = dp.get(x, 0) + 1
            # 选 x（x 保持不变）
            dp[x] = dp.get(x - 1, 0) + 1

            ans = max(ans, dp[x+1], dp[x])

        return ans
```

### 方法二：详细注释版

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxSelectedElements(self, nums: List[int]) -> int:
        nums.sort()  # 从小到大排序，保证每个值从小值开始扩展
        dp = defaultdict(int)  # dp[v] = 以 v 结尾的最长连续选择长度
        ans = 0

        for x in nums:
            # 选择将 x 变为 x+1（只需 +1 操作）
            # 则 x+1 可以接在 x 后面，序列长度 +1
            new_val = x + 1
            dp[new_val] = dp[x] + 1

            # 选择 x 保持不变
            # x 可以接在 x-1 后面
            dp[x] = dp[x - 1] + 1

            ans = max(ans, dp[new_val], dp[x])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 每个元素要么用原值 `x`，要么 +1 变为 `x+1`（贪心：不需要 +2 以上）
2. 排序后，小值先处理，保证 DP 转移正确
3. `dp[v]` 表示以 `v` 结尾的连续序列长度（即选了 v-k+1, v-k+2, ..., v 共 k 个）

## 易错点

1. 注意更新顺序：先更新 `dp[x+1]`，再更新 `dp[x]`（避免覆盖影响）
2. 排序是必要的，保证从小到大处理，DP 状态正确
