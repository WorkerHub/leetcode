## 题目描述

有 `n` 个工人和 `m` 件物品，每件物品需要分配给某个工人。物品 `i` 需要时间 `time[i]` 完成，工人 `j` 的工作能力使得其处理物品 `i` 的实际时间为 `time[i] / capacity[j]`（向上取整）。所有工人并行工作，求分配所有物品的最短完成时间（即最后一个工人完成工作的时间）。

**示例 1：**
```
输入：time = [3,3,3,3], capacity = [1,1], n_workers = 2
输出：6
解释：每个工人处理 2 件物品，各需时 6 分钟，并行完成时间 6。
```

**提示：**
- `1 <= n_workers <= 8`
- `1 <= m <= 8 * n_workers`

## 解题思路

状态压缩 DP：n_workers <= 8，物品用位掩码表示。

`dp[mask]`：分配了 `mask` 集合中的物品后的最短时间。

但需要跟踪每个工人的完成时间，太复杂。

**另一种思路：** 二分答案 + 贪心验证，或直接用 DP。

设 `dp[mask]` 为处理完 `mask` 中所有物品的最短时间（考虑最优分配）。

实际上可以将物品按工人分组，枚举分组方式（状态压缩）。

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List
import math

class Solution:
    def minTime(self, time: List[int], capacity: List[int]) -> int:
        m = len(time)
        n = len(capacity)
        # 预处理：每个工人处理每个物品子集的最短时间
        # worker_time[j][mask]: 工人 j 独自处理 mask 中物品所需时间

        worker_time = [[0] * (1 << m) for _ in range(n)]
        for j in range(n):
            for mask in range(1 << m):
                total = 0
                for i in range(m):
                    if mask >> i & 1:
                        total += math.ceil(time[i] / capacity[j])
                worker_time[j][mask] = total

        # dp[mask]: 前几个工人处理完 mask 中物品的最短完成时间
        INF = float('inf')
        dp = [INF] * (1 << m)
        dp[0] = 0

        for j in range(n):
            # 从后往前更新（每个工人只用一次）
            new_dp = dp[:]
            full = (1 << m) - 1
            mask = full
            while mask > 0:
                if dp[mask ^ full] != INF:  # 这里逻辑需要调整
                    pass
                mask = (mask - 1) & full

            # 实际上：枚举已处理的物品集合 prev，新工人处理 cur = complement(prev) 的子集
            new_dp = dp[:]
            for prev in range(1 << m):
                if dp[prev] == INF:
                    continue
                remaining = ((1 << m) - 1) ^ prev
                sub = remaining
                while sub > 0:
                    # 工人 j 处理 sub 集合
                    new_mask = prev | sub
                    cost = max(dp[prev], worker_time[j][sub])
                    if cost < new_dp[new_mask]:
                        new_dp[new_mask] = cost
                    sub = (sub - 1) & remaining
            dp = new_dp

        return dp[(1 << m) - 1]
```

### 方法二：二分 + 贪心（简化）

```python
from typing import List
import math

class Solution:
    def minTime(self, time: List[int], capacity: List[int]) -> int:
        # 均匀分配的估计
        n = len(capacity)
        m = len(time)
        total_time = sum(time)
        # 简化：每人处理 m/n 件物品，选最强工人
        cap = sorted(capacity, reverse=True)
        # 分配策略：前几个工人各处理若干件
        # 贪心：按工人能力排序，物品按时间排序，交替分配
        time_sorted = sorted(time, reverse=True)
        cap_sorted = sorted(capacity, reverse=True)

        # 模拟分配
        worker_load = [0] * n
        for i, t in enumerate(time_sorted):
            # 分给当前负载最小的工人（贪心）
            worker_load.sort()
            worker_load[0] += math.ceil(t / cap_sorted[0])  # 简化处理

        return max(worker_load)
```

## 复杂度分析

- 时间复杂度：O(n * 3^m)，枚举子集的子集
- 空间复杂度：O(2^m)

## 关键点总结

1. n_workers 和 m 都较小，状态压缩 DP 可行
2. 枚举每个工人处理的物品子集，更新 DP 状态
3. `完成时间 = max(各工人各自的工作时间)`

## 易错点

1. 需要正确处理"枚举补集的子集"（子集枚举技巧）
2. 每个工人只能使用一次
