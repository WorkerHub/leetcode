## 题目描述

给定一棵有 `n` 个节点的树，节点值为 `vals[i]`（0 到 9 的数字）。对树的某个连通子树（包含根节点），若该子树中每个数字最多出现一次，则称为"好子树"。好子树的"分数"是其所有节点值的总和。求所有好子树中的最大分数。

**示例 1：**

```
输入：vals = [2, 5, 1, 5, 2], edges = [[0,1],[0,2],[1,3],[1,4]]
输出：14
解释：选取节点 {0,1,2,3} 的子树：2+5+1+5=13，但 5 出现了两次，不好。
     选取 {0,1,2}：2+5+1=8，好子树。
     选取 {0,2,1,3}... 需要找最优。
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= vals[i] <= 9`
- 树是连通的

## 解题思路

树形动态规划 + 位运算。

由于数字范围是 0-9（共 10 个不同值），用 10 位二进制掩码表示已使用的数字集合。

状态：`dp[v][mask]` = 以 v 为根，已使用数字掩码为 `mask` 的好子树的最大分数。

DFS 后序遍历，合并子树：
- 若当前节点值 `d = vals[v]` 已在 `mask` 中，不能包含此节点（但可以包含它的部分子树...）
- 树形 DP 合并时，子树之间的 mask 不能有交集

## Python 代码实现

### 方法一：树形 DP + 位掩码（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxGoodSubtreeScore(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # dp[v] = dict: mask -> 以 v 为根的好子树中，使用数字集合为 mask 的最大分数
        best = 0

        def dfs(v, parent):
            nonlocal best
            d = vals[v]
            bit = 1 << d

            # 初始：只包含节点 v
            # dp = {bit: d}（若 bit 不重复）
            dp = {bit: d}
            best = max(best, d)

            for u in graph[v]:
                if u == parent:
                    continue
                child_dp = dfs(u, v)
                # 合并 dp 和 child_dp
                new_dp = dict(dp)
                for mask1, score1 in dp.items():
                    for mask2, score2 in child_dp.items():
                        if mask1 & mask2 == 0:  # 没有重复数字
                            new_mask = mask1 | mask2
                            new_score = score1 + score2
                            if new_mask not in new_dp or new_dp[new_mask] < new_score:
                                new_dp[new_mask] = new_score
                                best = max(best, new_score)
                dp = new_dp

            return dp

        dfs(0, -1)
        return best
```

### 方法二：简化贪心（近似）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxGoodSubtreeScore(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        # 最优子树包含每个不同数字（0-9）各最多一次
        # 找使总和最大的好子树

        # 贪心：对每个可能的数字集合（2^10 = 1024 种），找能否构成连通子树
        # 对每种掩码，若树中存在连通子树恰好包含这些数字，取这些数字的和

        # 简化：找树中节点值最大且不重复的连通子树
        best_sum = max(vals)

        # 贪心 DFS：从 0 开始，尽量收集不重复的大数字
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def dfs(v, parent, used_digits):
            d = vals[v]
            if d in used_digits:
                return 0
            used_digits = used_digits | {d}
            total = d
            for u in graph[v]:
                if u != parent:
                    total += dfs(u, v, used_digits)
            return total

        for start in range(n):
            s = dfs(start, -1, set())
            best_sum = max(best_sum, s)

        return best_sum
```

## 复杂度分析

- 时间复杂度：O(n * 2^10)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n * 2^10)

## 关键点总结

1. 数字范围 0-9，用 10 位掩码表示数字集合
2. 树形 DP 合并子树时，确保两子树的数字集合没有交集
3. 好子树中每个数字最多出现一次

## 易错点

1. 合并时需要 `mask1 & mask2 == 0`（不能有重叠数字）
2. 包含节点 v 的子树必须以 v 为根（连通性）
3. 数字 0 也可能是节点值，掩码第 0 位表示数字 0
