## 题目描述

给定一个 DataFrame `students`，删除 `name` 列中缺失值（NaN）所在的行。

**示例：**
```
输入：students DataFrame 中部分 name 为空

输出：删除 name 为空的行
```

## Python 代码实现

### 方法一：dropna（推荐）

```python
import pandas as pd

def dropMissingData(students: pd.DataFrame) -> pd.DataFrame:
    # 删除 name 列中有缺失值的行
    return students.dropna(subset='name')
```

### 方法二：布尔索引

```python
import pandas as pd

def dropMissingData(students: pd.DataFrame) -> pd.DataFrame:
    # 保留 name 不为空的行
    return students[students['name'].notna()]
```

### 方法三：notnull

```python
import pandas as pd

def dropMissingData(students: pd.DataFrame) -> pd.DataFrame:
    return students[students['name'].notnull()]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `df.dropna(subset=cols)` 删除指定列中有 NaN 的行
2. `df['col'].notna()` 或 `df['col'].notnull()` 返回布尔序列
3. `subset` 参数可以是字符串（单列）或列表（多列）
