## 题目描述

Excel 表中的单元格以字母-数字的格式表示，如 `A1`、`C4` 等，其中字母表示**列**（A-Z），数字表示**行**（1-100）。

给你一个格式为 `"<col1><row1>:<col2><row2>"` 的字符串 `s`，其中 `<col1>` 代表第一列，`<row1>` 代表第一行，以此类推，返回包含在范围内的单元格列表（按**列优先**，每列内**行递增**排列）。

**示例 1：**
```
输入：s = "K1:L2"
输出：["K1","K2","L1","L2"]
```

**示例 2：**
```
输入：s = "A1:F1"
输出：["A1","B1","C1","D1","E1","F1"]
```

**提示：**
- `s.length == 5`
- `'A' <= s[0] <= s[3] <= 'Z'`
- `'1' <= s[1] <= s[4] <= '9'`
- `s` 对应的格式为 `"<col1><row1>:<col2><row2>"`

## 解题思路

**枚举列和行**

解析字符串得到列范围 `[col1, col2]` 和行范围 `[row1, row2]`，按列优先顺序枚举所有单元格。

## 代码实现

### 方法一：直接枚举（推荐）

```python
from typing import List

class Solution:
    def cellsInRange(self, s: str) -> List[str]:
        col1, row1, col2, row2 = s[0], int(s[1]), s[3], int(s[4])
        result = []
        # 按列优先，列从 col1 到 col2，行从 row1 到 row2
        for c in range(ord(col1), ord(col2) + 1):
            for r in range(row1, row2 + 1):
                result.append(chr(c) + str(r))
        return result
```

### 方法二：列表推导式

```python
from typing import List

class Solution:
    def cellsInRange(self, s: str) -> List[str]:
        col1, row1, col2, row2 = s[0], int(s[1]), s[3], int(s[4])
        return [
            chr(c) + str(r)
            for c in range(ord(col1), ord(col2) + 1)
            for r in range(row1, row2 + 1)
        ]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举 | O((col2-col1+1) * (row2-row1+1)) | O(1)（不计输出） |

## 关键点总结

1. 解析字符串：列是字符（`s[0]`, `s[3]`），行是数字（`s[1]`, `s[4]`）。
2. 按**列优先**（外层循环列，内层循环行）。
3. 用 `ord` 和 `chr` 在字母和数字之间转换。

## 易错点

- 题目要求列优先（先遍历列，再遍历行），不要搞错顺序。
- 注意字符串格式 `"<col1><row1>:<col2><row2>"`，第 2 个字符是 `:` 分隔符。
