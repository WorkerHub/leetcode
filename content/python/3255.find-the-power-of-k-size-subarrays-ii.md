## 题目描述

与 3254 完全相同的问题，但数据范围更大：
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^6`

**示例 1：**
```
输入：nums = [1,2,3,4,3,2,5], k = 3
输出：[3,4,-1,-1,-1]
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= k <= n`

## 解题思路

与 3254 相同的 O(n) 滑动窗口方法，足以处理更大的数据范围。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        cnt = 1  # 以当前位置结尾的最长连续递增长度
        ans = []
        
        for i in range(n):
            if i > 0 and nums[i] == nums[i - 1] + 1:
                cnt += 1
            else:
                cnt = 1
            
            if i >= k - 1:
                ans.append(nums[i] if cnt >= k else -1)
        
        return ans
```

### 方法二：预处理连续递增长度

```python
from typing import List

class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        
        # 预处理：run[i] = 以 i 结尾的最长连续递增（步长1）序列长度
        run = [1] * n
        for i in range(1, n):
            if nums[i] == nums[i - 1] + 1:
                run[i] = run[i - 1] + 1
        
        return [nums[i] if run[i] >= k else -1 for i in range(k - 1, n)]
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（预处理）或 O(1)（方法一）

## 关键点总结

1. 与 3254 完全相同的算法，O(n) 滑动窗口
2. 数据范围增大但算法不变，Python 无需特别优化

## 易错点

1. k=1 时所有子数组的幂都是其自身（单个元素，cnt>=1 恒成立）
2. k=n 时只有一个子数组
