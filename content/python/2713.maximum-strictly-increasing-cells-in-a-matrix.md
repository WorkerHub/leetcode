## 题目描述

给你一个下标从 **1** 开始、大小为 `m x n` 的整数矩阵 `mat`，你可以选择任一单元格作为 **起始单元格**，并从中遍历矩阵。

每一步，你可以移动到 **同行或同列** 的任何其他单元格，但移动的目标单元格的值必须**严格大于**当前单元格的值。

返回你能访问的单元格的 **最大数目**。

**示例 1：**
```
输入：mat = [[3,1],[3,4]]
输出：2
解释：从 (1,1) 出发，移动到 (2,2)（同列且 4 > 3）
```

**示例 2：**
```
输入：mat = [[1,1],[1,1]]
输出：1
解释：无法移动
```

**提示：**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 10^5`
- `1 <= m * n <= 10^5`
- `-10^5 <= mat[i][j] <= 10^5`

## 解题思路

**按值排序 + 动态规划**：

1. 将所有格子按值从小到大排序
2. 对每个格子 `(r, c)`，`dp[r][c]` = 从 `(r, c)` 出发能访问的最大格子数
3. 按值从小到大处理，`dp[r][c] = 1 + max(row_best[r], col_best[c])`（来自同行/同列中比它小的格子的最佳结果）
4. 同值格子需要一起处理（先收集再更新），避免互相影响

## Python 代码实现

### 方法一：按值分组 + DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maxIncreasingCells(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        # 按值分组
        val_map = defaultdict(list)
        for i in range(m):
            for j in range(n):
                val_map[mat[i][j]].append((i, j))

        # row_best[r] = 第 r 行当前最大 dp 值
        row_best = [0] * m
        col_best = [0] * n
        ans = 0

        # 按值从小到大处理
        for val in sorted(val_map.keys()):
            cells = val_map[val]
            # 先计算每个格子的 dp 值（不更新 row_best/col_best，避免同值格子互相影响）
            dp_vals = []
            for r, c in cells:
                dp_vals.append(1 + max(row_best[r], col_best[c]))

            # 再统一更新
            for (r, c), dp_v in zip(cells, dp_vals):
                row_best[r] = max(row_best[r], dp_v)
                col_best[c] = max(col_best[c], dp_v)
                ans = max(ans, dp_v)

        return ans
```

## 复杂度分析

- 时间复杂度：O(m * n * log(m * n))，排序
- 空间复杂度：O(m + n + m*n)

## 关键点总结

1. 按值从小到大处理，确保转移时依赖的是更小的值
2. 同值格子必须一起计算后再更新，防止同值格子间互相依赖
3. 只需维护行最大和列最大，不需要完整 DP 表

## 易错点

1. 同行/同列的同值格子不能互相跳转（需要严格递增）
2. `row_best` 和 `col_best` 记录的是该行/列能到达的最优前驱值
