## 题目描述

沿街有若干房屋，第 `i` 栋房屋的金额为 `nums[i]`。小偷 **最少** 偷窃 `k` 栋房屋，但不能连续偷相邻的两栋。

小偷的 **能力值** = 他实际偷窃的所有房屋中金额的最大值。

返回使小偷能顺利偷窃至少 `k` 栋房屋的 **最小能力值**。

**示例 1：**

```
输入：nums = [2,3,5,9], k = 2
输出：5
解释：能力值为 5 时，可以选 [2,5] 或 [3,5] 等，不相邻且均 <= 5，共 2 栋。
```

**示例 2：**

```
输入：nums = [2,7,9,3,1], k = 2
输出：2
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= (nums.length + 1) / 2`

## 解题思路

**二分答案**：二分能力值（最大金额）cap，验证能力值为 cap 时能否偷 k 栋房屋。

贪心验证：从左到右扫描，若 nums[i] <= cap 且上一栋不是 i-1，则偷这栋（贪心选能偷的最左边的）。统计偷的总数是否 >= k。

## Python 代码实现

### 方法一：二分 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minCapability(self, nums: List[int], k: int) -> int:
        def can_rob(cap: int) -> bool:
            # 贪心：从左到右，遇到 <= cap 的房屋就偷（跳过下一个）
            count = 0
            i = 0
            while i < len(nums):
                if nums[i] <= cap:
                    count += 1
                    i += 2  # 跳过下一个相邻房屋
                else:
                    i += 1
            return count >= k

        lo, hi = min(nums), max(nums)
        while lo < hi:
            mid = (lo + hi) // 2
            if can_rob(mid):
                hi = mid
            else:
                lo = mid + 1

        return lo
```

### 方法二：排序候选值后二分

```python
from typing import List

class Solution:
    def minCapability(self, nums: List[int], k: int) -> int:
        # 候选答案只能是 nums 中的某个值
        candidates = sorted(set(nums))

        def can_rob(cap):
            count = 0
            skip = False
            for num in nums:
                if skip:
                    skip = False
                    continue
                if num <= cap:
                    count += 1
                    skip = True  # 下一个不能偷

            return count >= k

        lo, hi = 0, len(candidates) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if can_rob(candidates[mid]):
                hi = mid
            else:
                lo = mid + 1

        return candidates[lo]
```

## 复杂度分析

- 时间复杂度：O(n log M)，M 为 nums 中的最大值，每次验证 O(n)
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 二分最小能力值，贪心验证能否偷 k 栋
2. 贪心验证：遇到合法房屋立即偷，跳过下一个（不允许连续）
3. 最小化最大值 → 二分单调性

## 易错点

1. 贪心中偷一栋后下一栋必须跳过（不能偷），所以 `i += 2`
2. 二分时找"最小满足条件的值"：`hi = mid` 收缩右边界
3. 二分范围是 [min(nums), max(nums)]
