## 题目描述

给你一个 `m x n` 的矩阵 `grid`，以及一个整数 `k`。按以下规则进行锯齿形遍历：

- 第 `i` 行（从 0 开始）：若 `i % 2 == 0`，从左到右遍历；若 `i % 2 == 1`，从右到左遍历
- 只收集列下标满足 `j % k == 0` 的元素

返回按遍历顺序收集到的元素列表。

**示例 1：**

```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出：[1,3,6,4,7,9]
解释：
第0行（左→右）：取j=0→1，j=2→3
第1行（右→左）：j=2→6，j=0→4
第2行（左→右）：j=0→7，j=2→9
```

**示例 2：**

```
输入：grid = [[1,2],[3,4]], k = 1
输出：[1,2,4,3]
```

**提示：**

- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^5`
- `1 <= k <= n`

## 解题思路

模拟锯齿遍历：

1. 偶数行从左到右，列下标 `0, k, 2k, ...`
2. 奇数行从右到左，先找出所有满足 `j % k == 0` 的列下标，然后反序

关键：奇数行从右到左时，合法列下标是 `{j : j % k == 0, 0 <= j < n}` 的逆序排列。

## Python 代码实现

### 方法一：直接模拟（推荐）

```python
from typing import List

class Solution:
    def zigzagTraversal(self, grid: List[List[int]], k: int) -> List[int]:
        m, n = len(grid), len(grid[0])
        result = []

        for i in range(m):
            # 计算满足 j % k == 0 的所有列下标
            valid_cols = list(range(0, n, k))

            if i % 2 == 0:
                # 偶数行：从左到右
                for j in valid_cols:
                    result.append(grid[i][j])
            else:
                # 奇数行：从右到左
                for j in reversed(valid_cols):
                    result.append(grid[i][j])

        return result
```

### 方法二：列表推导式简化

```python
from typing import List

class Solution:
    def zigzagTraversal(self, grid: List[List[int]], k: int) -> List[int]:
        result = []
        valid_cols = list(range(0, len(grid[0]), k))

        for i, row in enumerate(grid):
            cols = valid_cols if i % 2 == 0 else reversed(valid_cols)
            result.extend(row[j] for j in cols)

        return result
```

## 复杂度分析

- 时间复杂度：O(m * n / k)，遍历所有满足条件的元素
- 空间复杂度：O(m * n / k)，存储结果

## 关键点总结

1. 合法列下标集合只计算一次，奇偶行共用
2. 奇数行反转列下标顺序即可
3. `range(0, n, k)` 简洁生成步长为 k 的列下标

## 易错点

1. `reversed()` 需要传入序列而非生成器，`range` 对象可以直接反转
2. 行从 0 开始，偶数行（0, 2, 4...）从左到右
3. 不要对整行遍历再过滤，直接步长为 k 即可
