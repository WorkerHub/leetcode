## 题目描述

[LeetCode 1209. Remove All Adjacent Duplicates In String II](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string-ii/)

给你一个字符串 `s`，「k 倍重复项删除操作」将会从 `s` 中选择 `k` 个相邻且相等的字母，并删除它们，使被删去的字符串的左侧和右侧连在一起。

你需要对 `s` 重复进行无限次这样的删除操作，直到无法继续为止。

在执行完所有删除操作后，返回最终得到的字符串。

本题答案保证唯一。

**示例 1:**
```
输入：s = "abcd", k = 2
输出："abcd"
解释：没有要删除的内容。
```

**示例 2:**
```
输入：s = "deeedbbcccbdaa", k = 3
输出："aa"
解释： 
先删除 "eee" 和 "ccc"，得到 "ddbbbdaa"
再删除 "bbb"，得到 "dddaa"
最后删除 "ddd"，得到 "aa"
```

**示例 3:**
```
输入：s = "pbbcggttciiippooaais", k = 2
输出："ps"
```

**提示:**
- 1 <= s.length <= 10^5
- 2 <= k <= 10^4
- s 中只含有小写英文字母

## 解题思路

这道题是经典的栈应用问题，需要不断删除连续的 k 个相同字符。

### 核心思想

1. **栈的特性**：后进先出（LIFO），适合处理相邻元素的问题
2. **计数策略**：不仅要存储字符，还要记录连续出现的次数
3. **实时删除**：当某个字符连续出现 k 次时，立即删除

### 算法流程

遍历字符串的每个字符：
1. 如果栈为空或当前字符与栈顶字符不同，将字符和计数 1 入栈
2. 如果当前字符与栈顶字符相同，栈顶计数 +1
3. 如果栈顶计数达到 k，弹出栈顶（删除 k 个字符）
4. 最后将栈中剩余的字符拼接成结果

### 为什么用栈

- **相邻性**：栈顶元素就是当前已处理字符串的最后一个字符
- **回溯性**：删除后，新的相邻字符可能继续形成 k 个重复
- **效率**：入栈、出栈都是 O(1) 操作

## Python 代码实现

### 方法一：栈 + 计数（推荐）

```python
from typing import List

class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        # 栈存储 (字符, 连续出现次数) 的元组
        stack = []
        
        for char in s:
            if stack and stack[-1][0] == char:
                # 当前字符与栈顶字符相同，计数 +1
                stack[-1][1] += 1
                
                # 如果达到 k 次，删除
                if stack[-1][1] == k:
                    stack.pop()
            else:
                # 当前字符与栈顶不同或栈为空，压入新元素
                stack.append([char, 1])
        
        # 构建结果字符串
        result = []
        for char, count in stack:
            result.append(char * count)
        
        return ''.join(result)
```

### 方法二：优化的栈实现

```python
from typing import List

class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        stack = []  # [(字符, 计数)]
        
        for char in s:
            if stack and stack[-1][0] == char:
                # 更新栈顶计数
                stack[-1] = (char, stack[-1][1] + 1)
                # 达到 k 时删除
                if stack[-1][1] == k:
                    stack.pop()
            else:
                stack.append((char, 1))
        
        # 拼接结果
        return ''.join(char * count for char, count in stack)
```

### 方法三：双栈法

```python
from typing import List

class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        # char_stack 存储字符，count_stack 存储对应的计数
        char_stack = []
        count_stack = []
        
        for char in s:
            if char_stack and char_stack[-1] == char:
                # 字符相同，计数 +1
                count_stack[-1] += 1
                if count_stack[-1] == k:
                    # 达到 k，删除
                    char_stack.pop()
                    count_stack.pop()
            else:
                # 新字符入栈
                char_stack.append(char)
                count_stack.append(1)
        
        # 构建结果
        result = []
        for i in range(len(char_stack)):
            result.append(char_stack[i] * count_stack[i])
        
        return ''.join(result)
```

### 方法四：使用列表模拟栈（更 Pythonic）

```python
from typing import List

class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        stack = []
        
        for char in s:
            if stack and stack[-1][0] == char:
                stack[-1][1] += 1
                if stack[-1][1] == k:
                    stack.pop()
            else:
                stack.append([char, 1])
        
        return ''.join(ch * cnt for ch, cnt in stack)
```

## 复杂度分析

### 所有方法

- **时间复杂度**：O(n)
  - 遍历字符串：O(n)
  - 每个字符最多入栈一次，出栈一次：O(n)
  - 构建结果字符串：O(n)
  - 总体：O(n)
  
- **空间复杂度**：O(n)
  - 栈最多存储 n 个元素（最坏情况下没有删除）
  - 结果字符串：O(n)

## 关键点总结

1. **栈 + 计数**：不仅存储字符，还要记录连续出现的次数，这是解决此题的关键

2. **实时删除**：当计数达到 k 时立即删除，而不是遍历完再删除，这样能处理连锁反应

3. **数据结构选择**：
   - 元组 `(char, count)` 或列表 `[char, count]`
   - 列表可变，可以直接修改计数；元组不可变，需要重新赋值

4. **连锁删除**：删除后可能产生新的 k 个重复，栈结构天然支持这种回溯

5. **结果构建**：栈中每个元素的字符要重复 count 次

## 易错点

1. **只存储字符不计数**：如果不记录计数，无法判断何时删除

2. **删除时机错误**：
   - 应该在计数等于 k 时删除，不是大于 k
   - 应该在遍历过程中实时删除，不是最后统一删除

3. **元组不可变**：
   - `stack[-1][1] += 1` 对元组无效，应该用列表或重新赋值
   - 正确写法：`stack[-1] = (char, stack[-1][1] + 1)`

4. **结果拼接**：
   - 栈中每个元素代表一组连续的字符，要重复 count 次
   - 不能直接 join(stack)，要 `char * count`

5. **边界情况**：
   - k = s.length 时，如果所有字符相同，结果为空字符串
   - k = 2 时退化为 1047 题（删除所有相邻重复项）
