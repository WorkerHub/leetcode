## 题目描述

Alice 和 Bob 轮流玩一个游戏，Alice 先手。

有 `n` 块石头排成一排。每块石头都有一个对应的分值 `stones[i]`。

Alice 和 Bob 轮流操作，每次操作时，玩家可以移除行中**最左边**的石头或**最右边**的石头，**并获得剩余所有石头的得分之和**（被移除的石头不计入得分）。

当所有石头被移除后，得分较高的玩家获胜。

假设 Alice 和 Bob 都非常聪明，请你推断出 **Alice 和 Bob 得分的最大差值**。

**示例 1：**
```
输入：stones = [5,3,1,4,2]
输出：6
解释：
- Alice 移除 2，得分 5+3+1+4 = 13；Bob 移除 5，得分 3+1+4 = 8
- Alice 移除 4，得分 3+1 = 4；Bob 移除 3，得分 1
- 差值：(13+4) - (8+1) = 8，不是最优
最优情况：差值为 6
```

**提示：**
- `n == stones.length`
- `2 <= n <= 1000`
- `1 <= stones[i] <= 1000`

## 解题思路

区间 DP。设 `dp[i][j]` 为在 `stones[i..j]` 这段石头中，当前玩家和对手的**得分差值**（当前玩家总分 - 对手总分）的最大值。

当前玩家可以：
1. 移除左端 `stones[i]`，获得 `sum(i+1, j)`，之后对手在 `[i+1, j]` 上最优，贡献 `sum(i+1,j) - dp[i+1][j]`
2. 移除右端 `stones[j]`，获得 `sum(i, j-1)`，之后对手在 `[i, j-1]` 上最优，贡献 `sum(i,j-1) - dp[i][j-1]`

用前缀和快速计算区间和。

最终答案为 `dp[0][n-1]`。

## 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List

class Solution:
    def stoneGameVII(self, stones: List[int]) -> int:
        n = len(stones)
        # 前缀和，prefix[i] = stones[0] + ... + stones[i-1]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + stones[i]

        def range_sum(l, r):
            # 计算 stones[l..r] 的和（包含两端）
            return prefix[r + 1] - prefix[l]

        # dp[i][j]：在 stones[i..j] 中当前玩家比对手多得的分数
        dp = [[0] * n for _ in range(n)]

        # 从短区间到长区间递推
        for length in range(2, n + 1):  # 区间长度
            for i in range(n - length + 1):
                j = i + length - 1
                # 移除左端 stones[i]，获得 sum(i+1, j)
                remove_left = range_sum(i + 1, j) - dp[i + 1][j]
                # 移除右端 stones[j]，获得 sum(i, j-1)
                remove_right = range_sum(i, j - 1) - dp[i][j - 1]
                dp[i][j] = max(remove_left, remove_right)

        return dp[0][n - 1]
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def stoneGameVII(self, stones: List[int]) -> int:
        n = len(stones)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + stones[i]

        def range_sum(l, r):
            return prefix[r + 1] - prefix[l]

        @lru_cache(maxsize=None)
        def dp(i, j):
            # 在 stones[i..j] 中，当前玩家最多能比对手多得多少分
            if i == j:
                return 0  # 只剩一块，移除后得分 0，差值为 0
            # 移除左端
            opt1 = range_sum(i + 1, j) - dp(i + 1, j)
            # 移除右端
            opt2 = range_sum(i, j - 1) - dp(i, j - 1)
            return max(opt1, opt2)

        return dp(0, n - 1)
```

## 复杂度分析

- **时间复杂度**：O(n^2)，需要计算所有区间的 dp 值
- **空间复杂度**：O(n^2)，存储 dp 数组

## 关键点总结

1. 博弈论中"当前玩家和对手的差值"是关键状态设计
2. `dp[i][j] = max(sum(i+1,j) - dp[i+1][j], sum(i,j-1) - dp[i][j-1])`
3. 前缀和 O(1) 计算区间和
4. 最终答案是 `dp[0][n-1]`，即 Alice 和 Bob 的总得分差

## 易错点

1. 当只剩一块石头时（`i == j`），当前玩家移除它后剩余和为 0，`dp[i][i] = 0`
2. 差值可能为负（对方占优），但题目保证 Alice 最优策略下的差值
3. 区间 DP 的循环顺序：先枚举区间长度，再枚举左端点
