## 题目描述

给出一个整数数组 nums 和一个查询数组 queries。

对于第 i 次查询，有 val = queries[i][0] 和 index = queries[i][1]，我们将 nums[index] 加上 val。

返回每次查询之后数组 nums 中偶数值的和。

## Python 代码实现

```python
from typing import List

class Solution:
    def sumEvenAfterQueries(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        even_sum = sum(x for x in nums if x % 2 == 0)
        result = []
        
        for val, idx in queries:
            old_val = nums[idx]
            new_val = old_val + val
            
            # 更新偶数和
            if old_val % 2 == 0:
                even_sum -= old_val
            if new_val % 2 == 0:
                even_sum += new_val
            
            nums[idx] = new_val
            result.append(even_sum)
        
        return result
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)
