## 题目描述

与 3258 相同，但增加了查询：

给你二进制字符串 `s`、整数 `k` 和二维整数数组 `queries`，其中 `queries[i] = [li, ri]`。

对每个查询，返回子字符串 `s[li..ri]` 中满足 k 约束的子字符串数量。

**提示：**
- `1 <= s.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

对每个右端点 `r`，预计算满足 k 约束的最小左端点 `min_left[r]`（用滑动窗口）。

对于查询 `[l, r]`，子字符串的右端从 `l` 到 `r`，对于每个右端 `j`，满足条件的左端范围是 `[max(l, min_left[j]), j]`，计数为 `max(0, j - max(l, min_left[j]) + 1)`。

用前缀和优化：`sum_arr[j]` = `sum(j - min_left[j] + 1 for j = 0..n-1)` 的前缀和，然后查询时用二分找分界点。

## Python 代码实现

### 方法一：前缀和 + 二分（推荐）

```python
from typing import List
import bisect

class Solution:
    def countKConstraintSubstrings(self, s: str, k: int, queries: List[List[int]]) -> List[int]:
        n = len(s)
        
        # 计算每个右端点的最小左端点 min_left[r]
        min_left = [0] * n
        cnt = [0, 0]
        left = 0
        for right in range(n):
            cnt[int(s[right])] += 1
            while cnt[0] > k and cnt[1] > k:
                cnt[int(s[left])] -= 1
                left += 1
            min_left[right] = left
        
        # 前缀和：prefix[i] = sum(j - min_left[j] + 1 for j = 0..i-1)
        # 还需要前缀和 prefix_minleft[i] = sum(min_left[j] for j = 0..i-1)
        prefix = [0] * (n + 1)
        for j in range(n):
            prefix[j + 1] = prefix[j] + (j - min_left[j] + 1)
        
        ans = []
        for l, r in queries:
            # 对区间 [l, r]，对每个右端 j（l <= j <= r）：
            # 左端范围是 [max(l, min_left[j]), j]，计数为 max(0, j - max(l, min_left[j]) + 1)
            
            # 分两段：
            # 1. j 使得 min_left[j] >= l（无约束，满足 j - min_left[j] + 1 个）
            # 2. j 使得 min_left[j] < l（左端被限制为 l，满足 j - l + 1 个）
            
            # min_left 是单调不减的（滑动窗口左端单调右移）
            # 找第一个 j 满足 min_left[j] >= l，用二分
            p = bisect.bisect_left(min_left, l, l, r + 1)
            
            # 对 j in [l, p-1]：min_left[j] < l，计数 j - l + 1
            # sum(j - l + 1 for j = l..p-1) = sum(j for j=l..p-1) - (p-l-1)*l
            # = (p-1+l)*(p-l)//2 - ... 
            cnt1 = p - l
            s1 = cnt1 * (l + p - 1) // 2 - l * cnt1  # sum(j-l for j=l..p-1) = sum(0,1,...,cnt1-1)
            s1 = cnt1 * (cnt1 - 1) // 2 + cnt1  # 重新：j - l + 1 从 1 到 cnt1
            # 等差数列：1 + 2 + ... + cnt1 = cnt1*(cnt1+1)//2
            s1 = cnt1 * (cnt1 + 1) // 2
            
            # 对 j in [p, r]：min_left[j] >= l，直接用前缀和
            s2 = prefix[r + 1] - prefix[p]
            
            ans.append(s1 + s2)
        
        return ans
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 滑动窗口预处理每个右端的最小左端 min_left
2. min_left 单调不减，可以用二分查找
3. 查询分两段用前缀和计算

## 易错点

1. 分界点 p 的计算要用 bisect_left 在 [l, r] 范围内查找
2. 等差数列求和公式要正确
