## 题目描述

二叉树上有 `n` 个节点，按从 `0` 到 `n - 1` 编号，其中节点 `i` 的两个子节点分别是 `leftChild[i]` 和 `rightChild[i]`。

只有**所有**节点都满足下面全部条件，这棵树才是 **有效的二叉树**：
- 节点 `i` 至多有一个父节点
- 树中只有一个根节点（入度为 0 的节点）
- 根节点到每个节点只有一条路径（即没有环）
- 每个节点最多有两个子节点（leftChild 和 rightChild）

如果二叉树有效，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：n = 4, leftChild = [1,-1,3,-1], rightChild = [2,-1,-1,-1]
输出：true
```

**示例 2：**
```
输入：n = 4, leftChild = [1,-1,3,-1], rightChild = [2,3,-1,-1]
输出：false
解释：节点 3 有两个父节点（节点 1 和节点 2）。
```

**示例 3：**
```
输入：n = 2, leftChild = [1,0], rightChild = [-1,-1]
输出：false
解释：节点 0 和节点 1 构成了一个环。
```

**示例 4：**
```
输入：n = 6, leftChild = [1,-1,-1,4,-1,-1], rightChild = [2,-1,-1,5,-1,-1]
输出：false
解释：整棵树不是连通的，即有两棵子树。
```

**提示：**
- `1 <= n <= 10^4`
- `leftChild.length == rightChild.length == n`
- `-1 <= leftChild[i], rightChild[i] <= n - 1`

## 解题思路

有效二叉树需满足以下四个条件：

1. **只有一个根节点**（入度为 0 的节点恰好有且仅有一个）
2. **每个非根节点恰好有一个父节点**（每个节点入度最多为 1）
3. **无环**
4. **所有节点连通**（树是连通的，不能有游离的子树）

**方法一：入度检查 + DFS/BFS 验证**

- 先统计每个节点的入度（作为子节点出现的次数）
- 入度为 0 的节点是候选根节点，有且只能有 1 个
- 如果某节点入度 > 1，直接返回 False
- 从根节点开始 DFS/BFS，统计能访问到的节点数，如果等于 n 则连通

**方法二：并查集**

- 遍历所有 parent→child 的关系
- 每次将 child 与 parent 合并，同时记录每个 child 是否已有父节点（入度检查）
- 最后检查所有节点是否在同一连通分量中

## Python 代码实现

### 方法一：入度检查 + BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        # 统计每个节点的入度（作为子节点出现的次数）
        in_degree = [0] * n
        
        for i in range(n):
            lc = leftChild[i]
            rc = rightChild[i]
            
            if lc != -1:
                in_degree[lc] += 1
                if in_degree[lc] > 1:
                    return False  # 某节点有超过 1 个父节点
            if rc != -1:
                in_degree[rc] += 1
                if in_degree[rc] > 1:
                    return False
        
        # 找根节点（入度为 0）
        roots = [i for i in range(n) if in_degree[i] == 0]
        
        if len(roots) != 1:
            return False  # 根节点必须恰好有 1 个
        
        root = roots[0]
        
        # BFS 从根节点出发，统计可访问节点数
        visited = set()
        queue = deque([root])
        
        while queue:
            node = queue.popleft()
            if node in visited:
                return False  # 有环（不应该发生，因为入度已经检查了，但防御性编程）
            visited.add(node)
            
            lc = leftChild[node]
            rc = rightChild[node]
            
            if lc != -1:
                queue.append(lc)
            if rc != -1:
                queue.append(rc)
        
        # 所有节点都能从根访问到（连通性）
        return len(visited) == n
```

### 方法二：并查集

```python
from typing import List

class Solution:
    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        parent = list(range(n))  # 并查集，初始每个节点是自己的根
        has_parent = [False] * n  # 记录每个节点是否已有父节点
        
        def find(x: int) -> int:
            """路径压缩查找根节点"""
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩（两步跳）
                x = parent[x]
            return x
        
        def union(p: int, c: int) -> bool:
            """
            将节点 c 合并到以 p 为父节点的树中
            返回 False 表示合并失败（c 已有父节点或产生了环）
            """
            if has_parent[c]:
                return False  # c 已经有了一个父节点
            # 检查是否会产生环（p 和 c 已经在同一连通分量中）
            if find(p) == find(c):
                return False  # 合并会形成环
            has_parent[c] = True
            parent[find(c)] = find(p)  # 合并两个集合
            return True
        
        for i in range(n):
            if leftChild[i] != -1:
                if not union(i, leftChild[i]):
                    return False
            if rightChild[i] != -1:
                if not union(i, rightChild[i]):
                    return False
        
        # 检查是否只有一个连通分量
        # 根节点（没有父节点的节点）只能有一个
        root_count = sum(1 for i in range(n) if not has_parent[i])
        return root_count == 1
```

### 方法三：DFS + 入度检查（递归版）

```python
from typing import List

class Solution:
    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        # 统计入度
        in_deg = [0] * n
        for i in range(n):
            if leftChild[i] != -1:
                in_deg[leftChild[i]] += 1
            if rightChild[i] != -1:
                in_deg[rightChild[i]] += 1
        
        # 检查入度
        if any(d > 1 for d in in_deg):
            return False  # 有节点有多个父节点
        
        roots = [i for i in range(n) if in_deg[i] == 0]
        if len(roots) != 1:
            return False  # 根节点数不为 1
        
        # DFS 从根节点出发
        visited = set()
        
        def dfs(node: int) -> bool:
            if node in visited:
                return False  # 有环
            visited.add(node)
            ok = True
            if leftChild[node] != -1:
                ok = ok and dfs(leftChild[node])
            if rightChild[node] != -1:
                ok = ok and dfs(rightChild[node])
            return ok
        
        if not dfs(roots[0]):
            return False
        
        return len(visited) == n  # 所有节点都可到达
```

## 复杂度分析

- 时间复杂度：O(N)。遍历所有节点的左右子节点关系一次（建立入度数组），然后 BFS/DFS 遍历整棵树，总体 O(N)。
- 空间复杂度：O(N)。入度数组、visited 集合或并查集，均为 O(N)。

## 有效二叉树的四个条件分析

| 条件 | 检查方式 |
|------|----------|
| 每个节点最多一个父节点 | 入度数组：每个节点入度 <= 1 |
| 恰好一个根节点 | 入度为 0 的节点恰好 1 个 |
| 无环 | BFS/DFS 中不重复访问节点；或并查集中合并前检查是否已连通 |
| 连通（所有节点都在树中） | BFS/DFS 访问的节点数 == n |

## 关键点总结

1. 验证二叉树需要同时检查四个条件：唯一根节点、无多父节点、无环、连通。
2. 入度检查快速排除多父节点情况，然后 BFS/DFS 从根出发验证连通性和无环性。
3. 并查集方法将"无环"和"无多父"的检查融合进 union 操作中，逻辑紧凑。
4. 注意：`leftChild[i] == rightChild[i]`（不为 -1）的情况也是非法的（左右子节点相同），虽然题目通常不包含这种情况，但严格实现时应考虑。

## 易错点

- 只检查入度不够：入度全 <= 1 且根节点唯一，也可能存在图不连通的情况（有些节点游离在外）。必须加上 BFS/DFS 的连通性检查。
- 注意题目给出的 n 和实际用到的节点数必须一致：BFS 访问数必须等于 n，不能只是"根节点能访问到所有有边的节点"。
- 并查集在 union 前要先检查环（find(p) == find(c)），再检查是否已有父节点，顺序影响结果。
