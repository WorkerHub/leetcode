## 题目描述

**奇妙字符串** 是仅包含前 `10` 个小写字母（`'a'` 到 `'j'`），并且至多有一个字母出现**奇数次**的字符串。

给你一个字符串 `word`，返回 `word` 的**非空子字符串**中**奇妙字符串**的数目。

**示例 1：**
```
输入：word = "aba"
输出：4
解释：4 个奇妙字符串：
- "a"（1 个 'a'）
- "b"（1 个 'b'）
- "aba"（2 个 'a'，1 个 'b'）
- "a"（索引2，1 个 'a'）
```

**示例 2：**
```
输入：word = "aabb"
输出：9
```

**提示：**
- `1 <= word.length <= 10^5`
- `word` 只包含 `'a'` 到 `'j'` 的字母

---

## 解题思路

### 核心思想：位掩码 + 前缀异或

用一个 10 位的二进制数（bitmask）表示各字母出现次数的奇偶性：
- 第 `i` 位为 1 表示第 `i` 个字母出现了奇数次
- 第 `i` 位为 0 表示出现了偶数次

**奇妙字符串的条件：**
1. 所有字母出现次数均为偶数：mask = 0
2. 恰好一个字母出现奇数次：mask 是 2 的幂（只有一位为 1）

**前缀异或技巧：**
设前缀掩码 `prefix[i]` 为 `word[0..i-1]` 的掩码，则子串 `word[l..r]` 的掩码 = `prefix[r+1] XOR prefix[l]`。

满足奇妙条件的子串对 `(l, r)` 需要：
- `prefix[r+1] XOR prefix[l] == 0`，即 `prefix[r+1] == prefix[l]`
- `prefix[r+1] XOR prefix[l]` 是 2 的幂，即只有一位不同

遍历时维护哈希表 `count[mask]`，统计出现过的前缀掩码次数。

## 代码实现

### 方法一：位掩码前缀异或 + 哈希表（推荐）

```python
from collections import defaultdict

class Solution:
    def wonderfulSubstrings(self, word: str) -> int:
        # 记录每种前缀掩码出现的次数
        count = defaultdict(int)
        count[0] = 1  # 空前缀的掩码为 0

        mask = 0
        result = 0

        for ch in word:
            # 更新当前前缀掩码（翻转对应位）
            mask ^= 1 << (ord(ch) - ord('a'))

            # 情况1：所有字母出现次数均为偶数（与之前相同掩码的前缀配对）
            result += count[mask]

            # 情况2：恰好一个字母出现奇数次（与只差一位的掩码配对）
            for i in range(10):
                result += count[mask ^ (1 << i)]

            # 更新当前掩码计数
            count[mask] += 1

        return result
```

### 方法二：数组代替哈希表（优化常数）

```python
class Solution:
    def wonderfulSubstrings(self, word: str) -> int:
        # 共 2^10 = 1024 种掩码
        count = [0] * 1024
        count[0] = 1

        mask = 0
        result = 0

        for ch in word:
            mask ^= 1 << (ord(ch) - ord('a'))

            # 全偶数情况
            result += count[mask]
            # 恰好一个奇数情况
            for i in range(10):
                result += count[mask ^ (1 << i)]

            count[mask] += 1

        return result
```

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(10n) = O(n) | O(2^10) = O(1) |
| 方法二 | O(10n) = O(n) | O(2^10) = O(1) |

## 关键点总结

1. 奇偶性用位掩码表示，XOR 可以翻转奇偶性
2. 子串的掩码 = 前缀 XOR 的差
3. 奇妙条件：掩码为 0 或为 2 的幂（只有 1 位为 1）
4. 遍历时维护前缀掩码计数，每步检查 11 种合法情况

---

## 易错点

- 初始化 `count[0] = 1`（空前缀）不能忘
- 共需检查 11 种情况：1 种全偶 + 10 种恰好一个奇
