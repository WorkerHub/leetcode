## 题目描述

在由 2D 网格表示的校园里，有 `n` 名工人和 `n` 辆自行车，`n <= 10`。

每个工人和每辆自行车的位置都用一对整数 `[x, y]` 表示。

我们需要为每个工人分配一辆自行车。在所有可能的分配方案中，返回使得分配给每个工人的自行车与工人之间的**曼哈顿距离总和**最小的方案的距离总和。

两点 `p1` 和 `p2` 之间的曼哈顿距离为：`|p1.x - p2.x| + |p1.y - p2.y|`。

**示例 1：**
```
输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出：6
解释：
最优分配是工人 0 → 自行车 0，工人 1 → 自行车 1。
总距离 = 3 + 3 = 6。
```

**示例 2：**
```
输入：workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]]
输出：4
解释：
最优分配：
工人 0 → 自行车 0，距离 = 1
工人 1 → 自行车 2，距离 = 1
工人 2 → 自行车 1，距离 = 2
总距离 = 1 + 1 + 2 = 4
```

**提示：**
- `n == workers.length == bikes.length`
- `1 <= n <= 10`
- `workers[i].length == bikes[j].length == 2`
- `0 <= workers[i][0], workers[i][1] < 1000`
- `0 <= bikes[j][0], bikes[j][1] < 1000`
- 所有工人和自行车的位置都不相同

## 解题思路

这道题与 1057 不同，要求的是**最小总距离**，而不是按优先级贪心分配。这是一个**分配问题**，需要穷举所有可能的分配方案。

**方法对比：**
1. **回溯（DFS）**：枚举所有分配方案，记录最小值
2. **状态压缩 DP**：使用位掩码表示自行车的使用状态
3. **记忆化搜索**：DFS + 记忆化避免重复计算

**核心思想：**
- 使用位掩码表示哪些自行车已被分配
- `dp[mask]` 表示在 `mask` 状态下，已分配的工人获得的最小距离和
- 状态转移：枚举下一个工人可以选择的自行车

## Python 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> int:
        """
        时间复杂度：O(2^n × n²)
        空间复杂度：O(2^n)
        """
        n = len(workers)
        
        # 预计算所有距离
        dist = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                dist[i][j] = abs(workers[i][0] - bikes[j][0]) + abs(workers[i][1] - bikes[j][1])
        
        # dp[mask] 表示使用 mask 表示的自行车集合时的最小距离
        # mask 中第 i 位为 1 表示第 i 辆自行车已被使用
        dp = [float('inf')] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == float('inf'):
                continue
            
            # 当前已分配的工人数量（mask 中 1 的个数）
            worker_idx = bin(mask).count('1')
            
            if worker_idx == n:
                continue
            
            # 为下一个工人选择自行车
            for bike_idx in range(n):
                if mask & (1 << bike_idx) == 0:  # 自行车未被使用
                    new_mask = mask | (1 << bike_idx)
                    dp[new_mask] = min(dp[new_mask], dp[mask] + dist[worker_idx][bike_idx])
        
        return dp[(1 << n) - 1]
```

### 方法二：记忆化 DFS

```python
from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> int:
        """
        DFS + 记忆化
        时间复杂度：O(2^n × n²)
        空间复杂度：O(2^n)
        """
        n = len(workers)
        
        # 预计算距离
        dist = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                dist[i][j] = abs(workers[i][0] - bikes[j][0]) + abs(workers[i][1] - bikes[j][1])
        
        memo = {}
        
        def dfs(worker_idx: int, mask: int) -> int:
            """
            worker_idx: 当前要分配的工人索引
            mask: 已使用的自行车位掩码
            返回：剩余工人的最小分配距离
            """
            if worker_idx == n:
                return 0
            
            if mask in memo:
                return memo[mask]
            
            min_dist = float('inf')
            
            # 为当前工人尝试每辆未使用的自行车
            for bike_idx in range(n):
                if mask & (1 << bike_idx) == 0:
                    new_mask = mask | (1 << bike_idx)
                    current_dist = dist[worker_idx][bike_idx] + dfs(worker_idx + 1, new_mask)
                    min_dist = min(min_dist, current_dist)
            
            memo[mask] = min_dist
            return min_dist
        
        return dfs(0, 0)
```

### 方法三：回溯（朴素）

```python
from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> int:
        """
        纯回溯，没有记忆化
        时间复杂度：O(n!)
        空间复杂度：O(n)
        """
        n = len(workers)
        
        def distance(worker, bike):
            return abs(worker[0] - bike[0]) + abs(worker[1] - bike[1])
        
        self.min_dist = float('inf')
        used = [False] * n
        
        def backtrack(worker_idx: int, current_dist: int):
            if worker_idx == n:
                self.min_dist = min(self.min_dist, current_dist)
                return
            
            # 剪枝
            if current_dist >= self.min_dist:
                return
            
            for bike_idx in range(n):
                if not used[bike_idx]:
                    used[bike_idx] = True
                    backtrack(worker_idx + 1, current_dist + distance(workers[worker_idx], bikes[bike_idx]))
                    used[bike_idx] = False
        
        backtrack(0, 0)
        return self.min_dist
```

## 复杂度分析

**方法一：状态压缩 DP**
- 时间复杂度：O(2^n × n²)
  - 状态数：2^n
  - 每个状态枚举 n 个选择
  - 预计算距离：O(n²)
- 空间复杂度：O(2^n)

**方法二：记忆化 DFS**
- 时间复杂度：O(2^n × n²)
- 空间复杂度：O(2^n + n)，记忆化 + 递归栈

**方法三：回溯**
- 时间复杂度：O(n!)，没有记忆化，会重复计算
- 空间复杂度：O(n)，递归栈

## 图解示例

**示例：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]**

```
预计算距离矩阵：
       bike0  bike1
worker0  3      6
worker1  2      3

状态压缩 DP：

mask=00 (没有自行车被使用):
  dp[00] = 0
  
  worker0 选择 bike0 (mask=01):
    dp[01] = 0 + 3 = 3
  worker0 选择 bike1 (mask=10):
    dp[10] = 0 + 6 = 6

mask=01 (bike0 被使用):
  已分配 1 个工人，现在分配 worker1
  worker1 选择 bike1 (mask=11):
    dp[11] = min(inf, 3 + 3) = 6

mask=10 (bike1 被使用):
  worker1 选择 bike0 (mask=11):
    dp[11] = min(6, 6 + 2) = 6

最终答案：dp[11] = 6
```

## 关键点总结

1. **状态压缩**：使用位掩码表示自行车的使用状态
2. **工人顺序**：按顺序分配工人，利用 `popcount(mask)` 确定当前工人
3. **预计算距离**：避免重复计算曼哈顿距离
4. **剪枝优化**：在回溯中提前剪枝

## 易错点

1. **状态表示**：mask 表示的是自行车状态，不是工人状态
2. **工人索引**：`popcount(mask)` 即为当前要分配的工人索引
3. **位运算**：
   - 检查位：`mask & (1 << i)`
   - 设置位：`mask | (1 << i)`
4. **初始化**：`dp[0] = 0`，其他为 `inf`
