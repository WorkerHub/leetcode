## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，每个数组的长度都是 `n`，同时给你一个整数 `diff`，统计满足以下条件的 **数对** `(i, j)` 的数目：

- `0 <= i < j <= n - 1`
- `nums1[i] - nums1[j] <= nums2[i] - nums2[j] + diff`

返回满足条件的数对数目。

**示例 1：**
```
输入：nums1 = [3,2,5], nums2 = [2,2,1], diff = 1
输出：3
```

**提示：**
- `n == nums1.length == nums2.length`
- `2 <= n <= 10^5`
- `-10^4 <= nums1[i], nums2[i] <= 10^4`
- `-10^4 <= diff <= 10^4`

## 解题思路

**变形条件：**
`nums1[i] - nums1[j] <= nums2[i] - nums2[j] + diff`
等价于：`(nums1[i] - nums2[i]) - (nums1[j] - nums2[j]) <= diff`
令 `arr[k] = nums1[k] - nums2[k]`，则条件变为：
`arr[i] - arr[j] <= diff`，即 `arr[i] <= arr[j] + diff`

问题变为：在数组 `arr` 中，找满足 `i < j` 且 `arr[i] <= arr[j] + diff` 的数对数目。

等价于：在 `arr` 中，对每个 `j`，找 `i < j` 且 `arr[i] <= arr[j] + diff` 的 `i` 的数量（逆序对变体）。

**方法：归并排序或树状数组。**

## 代码实现

### 方法一：树状数组（BIT）

```python
from typing import List

class BIT:
    """树状数组，支持单点加和前缀查询"""
    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i: int, delta: int = 1) -> None:
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)

    def query(self, i: int) -> int:
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

    def range_query(self, l: int, r: int) -> int:
        if l > r:
            return 0
        return self.query(r) - self.query(l - 1)

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], diff: int) -> int:
        n = len(nums1)
        # arr[i] = nums1[i] - nums2[i]
        arr = [nums1[i] - nums2[i] for i in range(n)]

        # 坐标压缩
        sorted_vals = sorted(set(arr))
        rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
        m = len(sorted_vals)

        bit = BIT(m)
        ans = 0

        import bisect
        for i in range(n):
            # 找 arr[j] + diff 对应的最大 rank
            # 即在已有元素中，找 <= arr[i] + diff 的个数
            # 注意：已有元素是 arr[0..i-1]（j < i）
            threshold = arr[i] + diff
            # 在 sorted_vals 中找 <= threshold 的最大索引（1-based rank）
            pos = bisect.bisect_right(sorted_vals, threshold)
            ans += bit.query(pos)
            # 将 arr[i] 加入树状数组
            bit.update(rank[arr[i]])

        return ans
```

### 方法二：归并排序

```python
from typing import List

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], diff: int) -> int:
        arr = [nums1[i] - nums2[i] for i in range(len(nums1))]
        self.ans = 0

        def merge_sort(lst):
            if len(lst) <= 1:
                return lst
            mid = len(lst) // 2
            left = merge_sort(lst[:mid])
            right = merge_sort(lst[mid:])

            # 统计跨左右两半的满足条件的数对
            j = 0
            for x in left:
                # 找 right 中 <= x + diff 的元素数量
                while j < len(right) and right[j] <= x + diff:
                    j += 1
                self.ans += j

            # 合并
            result = []
            i = k = 0
            while i < len(left) and k < len(right):
                if left[i] <= right[k]:
                    result.append(left[i])
                    i += 1
                else:
                    result.append(right[k])
                    k += 1
            result.extend(left[i:])
            result.extend(right[k:])
            return result

        merge_sort(arr)
        return self.ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 树状数组 | O(n log n) | O(n) |
| 归并排序 | O(n log n) | O(n) |

## 关键点总结

1. 条件变形：转化为单数组中 `arr[i] <= arr[j] + diff`（i < j）的数对数
2. 遍历 j，用树状数组查询前 j-1 个元素中 <= arr[j]+diff 的个数
3. 坐标压缩将值域映射到 [1, m]

## 易错点

- 按 j 从左到右遍历，先查询再插入（保证 i < j）
- 坐标压缩时，查询用 `bisect_right` 找 <= threshold 的位置
