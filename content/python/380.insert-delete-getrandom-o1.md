## 题目描述

实现 `RandomizedSet` 类：

- `RandomizedSet()` 初始化 `RandomizedSet` 对象
- `bool insert(int val)` 当元素 `val` 不存在时，向集合中插入该项，并返回 `true`；否则，返回 `false`
- `bool remove(int val)` 当元素 `val` 存在时，从集合中移除该项，并返回 `true`；否则，返回 `false`
- `int getRandom()` 随机返回现有集合中的一项（测试用例保证调用此方法时集合中至少存在一个元素）。每个元素应该有相同的概率被返回

你必须实现类的所有函数，并满足每个函数的平均时间复杂度为 `O(1)`。

**示例：**

```
输入：
["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"]
[[], [1], [2], [2], [], [1], [2], []]

输出：
[null, true, false, true, 2, true, false, 2]

解释：
RandomizedSet randomizedSet = new RandomizedSet();
randomizedSet.insert(1);   // 向集合中插入 1，返回 true 表示 1 被成功地插入
randomizedSet.remove(2);   // 返回 false，表示集合中不存在 2
randomizedSet.insert(2);   // 向集合中插入 2，返回 true，集合现在包含 [1,2]
randomizedSet.getRandom(); // getRandom 应随机返回 1 或 2
randomizedSet.remove(1);   // 从集合中移除 1，返回 true，集合现在包含 [2]
randomizedSet.insert(2);   // 2 已在集合中，所以返回 false
randomizedSet.getRandom(); // 由于 2 是集合中唯一的数字，getRandom 总是返回 2
```

**提示：**
- `-2^31 <= val <= 2^31 - 1`
- 最多调用 `insert`、`remove` 和 `getRandom` 函数 `2 * 10^5` 次
- 在调用 `getRandom` 方法时，数据结构中至少存在一个元素

## 解题思路

这道题的核心挑战是：如何在 O(1) 时间内实现随机返回元素。

### 关键观察

- **插入/删除 O(1)**：可以用哈希表
- **随机返回 O(1)**：需要能用索引访问，即数组

### 解决方案：数组 + 哈希表

**数据结构组合**：
- `nums`：存储所有元素（列表）
- `val_to_index`：存储值到索引的映射（字典）

**核心操作**：
1. **insert(val)**：
   - 检查 `val` 是否存在
   - 添加到数组末尾
   - 在字典中记录索引
   
2. **remove(val)**：
   - 检查 `val` 是否存在
   - 将数组最后一个元素移到要删除的位置（覆盖）
   - 更新字典中最后一个元素的索引
   - 删除数组最后一个元素
   - 删除字典中 `val` 的记录
   
3. **getRandom()**：
   - 随机生成索引
   - 返回对应元素

## Python 代码实现

### 方法一：数组 + 哈希表（标准解法）

```python
import random

class RandomizedSet:
    def __init__(self):
        """
        初始化数据结构
        """
        self.nums = []  # 存储元素
        self.val_to_index = {}  # 值 -> 索引
    
    def insert(self, val: int) -> bool:
        """
        插入元素
        时间复杂度：O(1)
        """
        if val in self.val_to_index:
            return False
        
        # 添加到数组末尾
        self.nums.append(val)
        # 记录索引
        self.val_to_index[val] = len(self.nums) - 1
        return True
    
    def remove(self, val: int) -> bool:
        """
        删除元素
        时间复杂度：O(1)
        """
        if val not in self.val_to_index:
            return False
        
        # 获取要删除元素的索引
        idx = self.val_to_index[val]
        # 获取数组最后一个元素
        last_val = self.nums[-1]
        
        # 将最后一个元素移到要删除的位置
        self.nums[idx] = last_val
        self.val_to_index[last_val] = idx
        
        # 删除数组最后一个元素
        self.nums.pop()
        # 删除字典中的记录
        del self.val_to_index[val]
        
        return True
    
    def getRandom(self) -> int:
        """
        随机返回一个元素
        时间复杂度：O(1)
        """
        return random.choice(self.nums)
```

### 方法二：使用 random.randint（更明确）

```python
import random

class RandomizedSet:
    def __init__(self):
        self.nums = []
        self.val_to_index = {}
    
    def insert(self, val: int) -> bool:
        if val in self.val_to_index:
            return False
        
        self.nums.append(val)
        self.val_to_index[val] = len(self.nums) - 1
        return True
    
    def remove(self, val: int) -> bool:
        if val not in self.val_to_index:
            return False
        
        idx = self.val_to_index[val]
        last_val = self.nums[-1]
        
        # 用最后一个元素覆盖要删除的元素
        self.nums[idx] = last_val
        self.val_to_index[last_val] = idx
        
        # 删除最后一个元素
        self.nums.pop()
        del self.val_to_index[val]
        
        return True
    
    def getRandom(self) -> int:
        """
        使用 randint 生成随机索引
        """
        idx = random.randint(0, len(self.nums) - 1)
        return self.nums[idx]
```

### 方法三：简化版（注释更详细）

```python
import random

class RandomizedSet:
    def __init__(self):
        """
        nums: 动态数组，存储所有元素
        val_to_index: 哈希表，存储值到索引的映射
        """
        self.nums = []
        self.val_to_index = {}
    
    def insert(self, val: int) -> bool:
        """
        1. 检查元素是否已存在
        2. 添加到数组末尾
        3. 记录索引到哈希表
        """
        if val in self.val_to_index:
            return False
        
        self.val_to_index[val] = len(self.nums)
        self.nums.append(val)
        return True
    
    def remove(self, val: int) -> bool:
        """
        O(1) 删除的技巧：
        1. 将要删除的元素与数组最后一个元素交换
        2. 删除数组最后一个元素（O(1)）
        3. 更新哈希表
        """
        if val not in self.val_to_index:
            return False
        
        # 要删除元素的索引
        remove_idx = self.val_to_index[val]
        # 数组最后一个元素
        last_element = self.nums[-1]
        # 最后一个元素在哈希表中的索引
        last_idx = self.val_to_index[last_element]
        
        # 交换：将最后一个元素放到要删除的位置
        self.nums[remove_idx] = last_element
        self.val_to_index[last_element] = remove_idx
        
        # 删除数组最后一个元素和哈希表记录
        self.nums.pop()
        del self.val_to_index[val]
        
        return True
    
    def getRandom(self) -> int:
        """
        从数组中随机选择一个元素
        """
        return random.choice(self.nums)
```

## 复杂度分析

### 所有方法
- `insert`：O(1) 平均时间复杂度
- `remove`：O(1) 平均时间复杂度
- `getRandom`：O(1) 时间复杂度
- 空间复杂度：O(n)，n 为元素个数

## 关键点总结

1. **数据结构组合**：数组 + 哈希表，各取所长
2. **O(1) 删除技巧**：用最后一个元素覆盖要删除的元素
3. **哈希表作用**：
   - 快速查找元素是否存在
   - 快速获取元素在数组中的位置
4. **数组作用**：
   - 支持随机访问
   - 通过索引 O(1) 获取元素
5. **删除顺序很重要**：先交换，再删除

## 易错点

1. **删除顺序**：必须先更新哈希表，再删除元素
2. **边界情况**：删除最后一个元素时，不需要交换
3. **索引更新**：交换后要更新最后一个元素的索引
4. **重复插入**：已存在的元素不能重复插入
5. **空集合**：题目保证 `getRandom` 时集合非空，否则要检查

### 示例：insert(1), insert(2), remove(1)

```
初始状态：
nums = []

insert(1):

val_to_index = {2: 0}
```
