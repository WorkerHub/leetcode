## 题目描述

一个人按照下述的饮食计划进行节食：

- 在第 i 天，他将摄入 calories[i] 卡路里的热量
- 每隔 k 天，他需要评估自己的饮食表现

评估方式如下：

- 将这 k 天的卡路里总和记为 T
- 如果 T < lower，得 -1 分
- 如果 T > upper，得 +1 分
- 否则得 0 分

注意，总得分可能是负数。

请你返回按照上述饮食计划进行节食的总得分。

**示例 1:**
```
输入: calories = [1,2,3,4,5], k = 1, lower = 3, upper = 3
输出: 0
解释: 
calories[0] = 1 < lower，得 -1 分
calories[1] = 2 < lower，得 -1 分
calories[2] = 3，得 0 分
calories[3] = 4 > upper，得 +1 分
calories[4] = 5 > upper，得 +1 分
总分 = -1 + (-1) + 0 + 1 + 1 = 0
```

**示例 2:**
```
输入: calories = [3,2], k = 2, lower = 0, upper = 1
输出: 1
解释: 
calories[0] + calories[1] = 5 > upper，得 +1 分
```

**示例 3:**
```
输入: calories = [6,5,0,0], k = 2, lower = 1, upper = 5
输出: 0
解释:
calories[0] + calories[1] = 11 > upper，得 +1 分
calories[1] + calories[2] = 5，得 0 分
calories[2] + calories[3] = 0 < lower，得 -1 分
总分 = 1 + 0 + (-1) = 0
```

**提示:**
- 1 <= k <= calories.length <= 10^5
- 0 <= calories[i] <= 20000
- 0 <= lower <= upper

## 解题思路

这是一道典型的滑动窗口问题。核心思想是：**维护一个大小为 k 的滑动窗口，计算每个窗口的卡路里总和并评分**。

### 核心观察

1. **窗口大小固定**：每个评估周期都是连续的 k 天
2. **窗口滑动**：从第 0 天开始，每次向右滑动一位，直到无法形成完整的 k 天窗口
3. **增量更新**：窗口每次滑动时，可以利用前一个窗口的和，减去移出的元素，加上新进入的元素

### 算法流程

1. 计算第一个窗口（前 k 天）的卡路里总和
2. 根据总和与 lower、upper 的关系计算得分
3. 滑动窗口：
   - 减去窗口左端移出的元素
   - 加上窗口右端新进入的元素
   - 计算新窗口的得分
4. 累加所有窗口的得分

### 关键技巧

使用滑动窗口避免重复计算，时间复杂度从 O(nk) 降低到 O(n)。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List

class Solution:
    def dietPlanPerformance(self, calories: List[int], k: int, lower: int, upper: int) -> int:
        n = len(calories)
        total_points = 0
        
        # 计算第一个窗口的卡路里总和
        window_sum = sum(calories[:k])
        
        # 评估第一个窗口
        if window_sum < lower:
            total_points -= 1
        elif window_sum > upper:
            total_points += 1
        
        # 滑动窗口
        for i in range(k, n):
            # 移除窗口左端的元素，添加窗口右端的元素
            window_sum = window_sum - calories[i - k] + calories[i]
            
            # 评估当前窗口
            if window_sum < lower:
                total_points -= 1
            elif window_sum > upper:
                total_points += 1
        
        return total_points
```

### 方法二：暴力解法（不推荐，用于对比）

```python
from typing import List

class Solution:
    def dietPlanPerformance(self, calories: List[int], k: int, lower: int, upper: int) -> int:
        n = len(calories)
        total_points = 0
        
        # 遍历所有可能的 k 天窗口
        for i in range(n - k + 1):
            # 计算当前窗口的卡路里总和
            window_sum = sum(calories[i:i + k])
            
            # 评估当前窗口
            if window_sum < lower:
                total_points -= 1
            elif window_sum > upper:
                total_points += 1
        
        return total_points
```

### 方法三：使用辅助函数

```python
from typing import List

class Solution:
    def dietPlanPerformance(self, calories: List[int], k: int, lower: int, upper: int) -> int:
        def evaluate(total: int) -> int:
            """评估卡路里总和，返回得分"""
            if total < lower:
                return -1
            elif total > upper:
                return 1
            else:
                return 0
        
        n = len(calories)
        total_points = 0
        window_sum = sum(calories[:k])
        
        # 评估第一个窗口
        total_points += evaluate(window_sum)
        
        # 滑动窗口并评估
        for i in range(k, n):
            window_sum = window_sum - calories[i - k] + calories[i]
            total_points += evaluate(window_sum)
        
        return total_points
```

### 方法四：Python 简洁版

```python
from typing import List

class Solution:
    def dietPlanPerformance(self, calories: List[int], k: int, lower: int, upper: int) -> int:
        # 辅助函数：根据总和计算得分
        score = lambda s: -1 if s < lower else (1 if s > upper else 0)
        
        # 第一个窗口
        window_sum = sum(calories[:k])
        points = score(window_sum)
        
        # 滑动窗口
        for i in range(k, len(calories)):
            window_sum += calories[i] - calories[i - k]
            points += score(window_sum)
        
        return points
```

## 复杂度分析

### 方法一、三、四：滑动窗口
- **时间复杂度**：O(n)，其中 n 是数组长度。只需遍历数组一次，第一个窗口计算需要 O(k)，之后每次滑动是 O(1)
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法二：暴力解法
- **时间复杂度**：O(nk)，需要计算 n-k+1 个窗口，每个窗口计算需要 O(k)
- **空间复杂度**：O(1)

## 图解示例

以 calories = [1,2,3,4,5], k = 1, lower = 3, upper = 3 为例：

```
窗口大小 k = 1，每次评估 1 天

索引:    0   1   2   3   4
卡路里:  1   2   3   4   5
        ↓   ↓   ↓   ↓   ↓
总和:    1   2   3   4   5
评估:   -1  -1   0  +1  +1
        (<3) (<3) (=3) (>3) (>3)

总分 = -1 + (-1) + 0 + 1 + 1 = 0
```

以 calories = [6,5,0,0], k = 2 为例：

```
窗口大小 k = 2

索引:      0  1  2  3
卡路里:    6  5  0  0

窗口1: [6,5]     -> 11 > upper(5) -> +1
窗口2:    [5,0]  -> 5 = upper(5)  ->  0
窗口3:       [0,0] -> 0 < lower(1) -> -1

滑动过程：
window_sum = 6 + 5 = 11 -> +1
window_sum = 11 - 6 + 0 = 5 -> 0
window_sum = 5 - 5 + 0 = 0 -> -1

总分 = 1 + 0 + (-1) = 0
```

## 关键点总结

1. **滑动窗口技巧**：固定大小的窗口问题，使用滑动窗口优化效率
2. **增量更新**：利用前一个窗口的和，通过 "减旧加新" 快速计算新窗口的和
3. **条件判断**：正确处理三种情况（< lower, > upper, 其他）
4. **边界处理**：确保窗口大小为 k，遍历范围是 [0, n-k]
5. **代码简洁**：使用辅助函数或 lambda 表达式简化条件判断

## 易错点

1. **窗口数量错误**：应该有 n-k+1 个窗口，不是 n 个
2. **索引越界**：滑动窗口时要注意 i-k 不能为负，所以从 k 开始遍历
3. **边界条件**：lower 和 upper 可能相等，此时只有等于这个值时得 0 分
4. **累加错误**：忘记减去移出的元素或加上新元素
5. **初始化**：第一个窗口需要单独计算，不能遗漏
