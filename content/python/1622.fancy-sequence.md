## 题目描述

请你实现三个 API，分别用来支持下面的三种操作：

- `append(val)`：将整数 `val` 加入序列末尾
- `addAll(inc)`：将序列中所有元素加上 `inc`
- `multAll(m)`：将序列中所有元素乘以 `m`
- `getIndex(idx)`：获取下标为 `idx` 的元素（0-indexed），若下标越界或序列中没有该元素，返回 `-1`

答案对 `10^9 + 7` 取余。

**提示：**
- 最多调用 `10^5` 次各操作

## 解题思路

核心难点：`addAll` 和 `multAll` 是全局操作，朴素实现时间复杂度 O(n)，会超时。

**懒惰求值（Lazy Evaluation）思想：**

用两个全局变量维护累积的乘法因子 `mult` 和加法因子 `add`：
- 每次 `append(val)` 时，反向计算：将 `val` 转换为"原始值"后存入
- 每次 `getIndex(idx)` 时，用当前的 `mult` 和 `add` 还原真实值

**维护变换：** 设当前变换为 `f(x) = mult * x + add`
- `addAll(inc)`: `add += inc`
- `multAll(m)`: `mult *= m; add *= m`（注意乘法会影响加法部分）
- `append(val)`: 存入 `val` 时，它在未来会被 `f` 作用。为了在 `getIndex` 时能正确还原，存入 `val` 时先用**当前 f 的逆变换**处理，但逆变换需要模逆元

更好的方案：存入时记录当前的 `mult` 和 `add`（即记录变换的快照）。

## 代码实现

### 方法一：记录每个元素加入时的变换参数（推荐）

```python
class Fancy:
    MOD = 10 ** 9 + 7

    def __init__(self):
        self.seq = []         # 存储 (val, mult_at_append, add_at_append)
        self.total_mult = 1   # 累积乘法因子
        self.total_add = 0    # 累积加法因子

    def append(self, val: int) -> None:
        # 记录当前值以及此时的累积变换参数
        self.seq.append((val, self.total_mult, self.total_add))

    def addAll(self, inc: int) -> None:
        self.total_add = (self.total_add + inc) % self.MOD

    def multAll(self, m: int) -> None:
        self.total_mult = self.total_mult * m % self.MOD
        self.total_add = self.total_add * m % self.MOD

    def getIndex(self, idx: int) -> int:
        if idx >= len(self.seq):
            return -1
        val, m0, a0 = self.seq[idx]
        # 追加时值为 val，此时全局变换为 (m0, a0)
        # 之后的全局变换相当于：先做 (m0, a0) 逆变换，再做 (total_mult, total_add)
        # 实际结果：val * (total_mult / m0) + (total_add - a0 * total_mult / m0)
        # 需要模逆元
        inv_m0 = pow(m0, self.MOD - 2, self.MOD)
        result = (val * self.total_mult % self.MOD * inv_m0 % self.MOD
                  + self.total_add - a0 * self.total_mult % self.MOD * inv_m0 % self.MOD)
        return result % self.MOD
```

### 方法二：线段树（支持区间修改）

```python
class Fancy:
    MOD = 10 ** 9 + 7

    def __init__(self):
        # 使用列表存储，懒惰更新
        self.vals = []
        self.add_lazy = 0
        self.mult_lazy = 1

    def append(self, val: int) -> None:
        # 存储时反向计算原始值（使得未来应用变换后得到 val）
        # 未来值 = mult_lazy * raw + add_lazy = val
        # 所以 raw = (val - add_lazy) * inv(mult_lazy)
        inv_mult = pow(self.mult_lazy, self.MOD - 2, self.MOD)
        raw = (val - self.add_lazy) * inv_mult % self.MOD
        self.vals.append(raw)

    def addAll(self, inc: int) -> None:
        self.add_lazy = (self.add_lazy + inc) % self.MOD

    def multAll(self, m: int) -> None:
        self.mult_lazy = self.mult_lazy * m % self.MOD
        self.add_lazy = self.add_lazy * m % self.MOD

    def getIndex(self, idx: int) -> int:
        if idx >= len(self.vals):
            return -1
        return (self.vals[idx] * self.mult_lazy + self.add_lazy) % self.MOD
```

## 复杂度分析

| 操作 | 时间复杂度 |
|------|-----------|
| append | O(1)（含模逆元 O(log MOD)） |
| addAll | O(1) |
| multAll | O(1) |
| getIndex | O(1)（含模逆元 O(log MOD)） |

## 关键点总结

1. 用懒惰求值维护全局的乘法因子和加法因子
2. `append` 时存储"原始值"（逆变换处理），使得 `getIndex` 时只需应用当前变换
3. 模逆元使用费马小定理：`pow(a, MOD-2, MOD)`
4. 每次 `multAll(m)` 时，加法 lazy 也要乘以 m

## 易错点

- `multAll` 时加法 lazy 也要乘以 m（因为加法是在乘法之后）
- 使用模运算时，减法结果可能为负，需要 `% MOD` 确保非负
- 模逆元只在 MOD 为素数且 a 与 MOD 互质时有效（MOD = 10^9+7 是素数）
