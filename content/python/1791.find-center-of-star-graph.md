## 题目描述

有一个无向的**星型图**，由 `n` 个节点组成，节点编号从 `1` 到 `n`。星型图有一个**中心**节点，并恰好有 `n - 1` 条边将中心节点与其他每个节点连接起来。

给你一个二维整数数组 `edges`，其中 `edges[i] = [ui, vi]` 表示在节点 `ui` 和 `vi` 之间存在一条边。请你找出并返回星型图的**中心节点**。

**示例 1：**
```
输入：edges = [[1,2],[2,3],[4,2]]
输出：2
```

**示例 2：**
```
输入：edges = [[1,2],[5,1],[1,3],[1,4]]
输出：1
```

**提示：**
- `3 <= n <= 10^5`
- `edges.length == n - 1`
- `edges[i].length == 2`
- `1 <= ui, vi <= n`
- `ui != vi`
- 题目数据保证是一个有效的星型图

## 解题思路

星型图的中心节点连接所有其他节点，所以它一定出现在每条边中。

只需检查前两条边：中心节点必然同时出现在 `edges[0]` 和 `edges[1]` 中。找两条边的公共节点即可。

## 代码实现

### 方法一：检查前两条边（推荐，O(1)）

```python
from typing import List

class Solution:
    def findCenter(self, edges: List[List[int]]) -> int:
        # 中心节点必须同时出现在前两条边中
        a, b = edges[0]
        c, d = edges[1]
        # 找公共节点
        if a == c or a == d:
            return a
        return b
```

### 方法二：统计度数

```python
from typing import List
from collections import Counter

class Solution:
    def findCenter(self, edges: List[List[int]]) -> int:
        # 统计每个节点的度数，度数为 n-1 的是中心节点
        degree = Counter()
        for u, v in edges:
            degree[u] += 1
            degree[v] += 1
        # 返回度数最大的节点
        return degree.most_common(1)[0][0]
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(1)，只看前两条边
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(n)，遍历所有边
- 空间复杂度：O(n)，存储度数

## 关键点总结

1. 中心节点出现在所有边中，必然出现在前两条边中
2. 前两条边的公共节点就是中心节点
3. 方法一只需 O(1) 时间，无需遍历所有边

## 易错点

1. 不要过度复杂化，只看前两条边就能确定答案
2. 注意 `edges[0] = [a, b]` 中 `a` 或 `b` 可能是中心节点，两者都要检查
