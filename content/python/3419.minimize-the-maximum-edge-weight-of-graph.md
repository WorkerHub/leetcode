## 题目描述

给你一个正整数 `n`，表示图中有 `n` 个节点（编号 0 到 n-1）。还给你一个二维整数数组 `edges`，其中 `edges[i] = [u_i, v_i, w_i]` 表示节点 `u_i` 和 `v_i` 之间有一条权重为 `w_i` 的有向边。

你的目标是找到最小的阈值 `T`，使得只保留权重 `<= T` 的边时，所有节点都能到达节点 `0`（即节点 0 从所有节点可达）。

如果无论如何都不可能，返回 `-1`。

**示例 1：**

```
输入：n = 5, edges = [[1,0,1],[2,0,2],[3,0,3],[4,3,1],[4,2,1]]
输出：2
解释：T=2 时，保留权重 <= 2 的边，所有节点都能到达 0
```

**示例 2：**

```
输入：n = 3, edges = [[0,2,5],[1,2,2],[0,1,3]]
输出：-1
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= edges.length <= 10^5`
- `edges[i].length == 3`
- `0 <= u_i, v_i < n`
- `u_i != v_i`
- `1 <= w_i <= 10^6`

## 解题思路

二分答案：二分权重阈值 `T`，检查只保留权重 `<= T` 的边时，从所有节点能否到达节点 0。

检查方法：对反向图（将所有有向边方向反转），从节点 0 出发做 BFS/DFS，看能否到达所有节点。

二分范围：`[min_weight, max_weight]`

## Python 代码实现

### 方法一：二分 + 反向图 BFS（推荐）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minMaxWeight(self, n: int, edges: List[List[int]], threshold: int) -> int:
        # 构建反向图（按权重分组）
        # 对所有边的权重排序
        edge_weights = sorted(set(e[2] for e in edges))

        if not edge_weights:
            return -1

        # 构建反向邻接表（只存边，二分时动态过滤）
        # 更好的方式：按权重排序后，用二分

        # 检查函数：给定阈值 T，是否所有节点都能到达 0
        def can_reach_all(T):
            # 反向图：从 0 出发，走权重 <= T 的反向边
            rev_graph = defaultdict(list)
            for u, v, w in edges:
                if w <= T:
                    # 原边 u->v，反向边 v->u
                    rev_graph[v].append(u)

            visited = set()
            queue = deque([0])
            visited.add(0)

            while queue:
                node = queue.popleft()
                for neighbor in rev_graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)

            return len(visited) == n

        # 二分查找最小阈值
        left, right = 1, max(e[2] for e in edges)

        if not can_reach_all(right):
            return -1

        while left < right:
            mid = (left + right) // 2
            if can_reach_all(mid):
                right = mid
            else:
                left = mid + 1

        return left
```

### 方法二：排序边 + 逐步添加（类似 Kruskal）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minMaxWeight(self, n: int, edges: List[List[int]], threshold: int) -> int:
        # 按权重排序
        sorted_edges = sorted(edges, key=lambda x: x[2])

        # 反向图（逐步添加边，检查连通性）
        rev_graph = defaultdict(list)
        visited = set()
        reachable = 1  # 从 0 可达的节点数

        def bfs_from_zero():
            nonlocal reachable
            queue = deque([0])
            visited.add(0)
            while queue:
                node = queue.popleft()
                for neighbor in rev_graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        reachable += 1
                        queue.append(neighbor)

        # 初始只有节点 0
        visited.add(0)
        prev_w = 0

        for u, v, w in sorted_edges:
            # 添加反向边 v -> u
            rev_graph[v].append(u)

            # 如果 u 或 v 已在可达集中，可能扩展可达集
            if v in visited and u not in visited:
                # 从 u 出发 BFS（在反向图中）
                queue = deque([u])
                visited.add(u)
                reachable += 1
                while queue:
                    node = queue.popleft()
                    for neighbor in rev_graph[node]:
                        if neighbor not in visited:
                            visited.add(neighbor)
                            reachable += 1
                            queue.append(neighbor)

            if reachable == n:
                return w

        return -1
```

## 复杂度分析

- 方法一（二分 + BFS）：
  - 时间复杂度：O(E log W)，E 为边数，W 为最大权重
  - 空间复杂度：O(E + N)

- 方法二（逐步添加）：
  - 时间复杂度：O(E log E + E * alpha(N))
  - 空间复杂度：O(E + N)

## 关键点总结

1. 二分权重阈值，检查是否所有节点能到达 0
2. 检查时用**反向图**从节点 0 出发做 BFS
3. 反向图：将原有向边 `u->v` 改为 `v->u`，即将"谁能到达 0"转化为"从 0 出发能到谁"

## 易错点

1. 题目要求所有节点到达节点 0（不是从 0 到所有节点），需要反向图
2. 二分时检查 `can_reach_all(max_w)` 是否为 False，此时无解返回 -1
3. 有向图和无向图的处理不同，本题是有向图
