## 题目描述

给定排列 `perm`（包含 0 到 n-1 的排列），每次操作可以选择一个元素放到数组末尾，求使数组升序排列的最少操作次数。

**示例 1：**
```
输入：perm = [2,1,0]
输出：2
解释：将 0 移到末尾：[2,1,0] -> [2,1,0]... 
     移动 1 和 2（2次）后得到 [0,1,2]。
```

**示例 2：**
```
输入：perm = [0,1,2]
输出：0
解释：已经有序，无需操作。
```

**提示：**
- `1 <= perm.length <= 10^5`
- `perm` 是 `[0, n-1]` 的排列

## 解题思路

**贪心 + 后缀判断：**

每次操作将一个元素移到末尾。排好序的目标是 `[0, 1, 2, ..., n-1]`。

关键观察：如果数组的末尾连续 k 个元素已经形成了目标排列的连续后缀 `[n-k, n-k+1, ..., n-1]`，那么这 k 个元素不需要移动。

因此，找到最长的满足条件的后缀长度 `k`：
- 从 `perm[-1]` 开始，向前检查是否形成了 `[..., n-k, n-k+1, ..., n-1]` 的连续递增序列
- 最少操作次数 = `n - k`

## Python 代码实现

### 方法一：从后向前找最长有序后缀（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, perm: List[int]) -> int:
        n = len(perm)
        # 目标：[0, 1, 2, ..., n-1]
        # 从后向前找连续的 n-1, n-2, n-3, ...
        k = 0  # 不需要移动的后缀长度
        expected = n - 1  # 期望看到的值

        for i in range(n - 1, -1, -1):
            if perm[i] == expected:
                k += 1
                expected -= 1
            else:
                break

        return n - k
```

### 方法二：图/置换环方法

```python
from typing import List

class Solution:
    def minOperations(self, perm: List[int]) -> int:
        n = len(perm)
        # 目标位置：元素 v 应该在位置 v
        # 检查 perm[i] 是否在正确位置上（连续后缀）
        # 从最后一个元素开始，检查是否 perm[n-1]==n-1, perm[n-2]==n-2, ...
        fixed = 0
        for i in range(n - 1, -1, -1):
            if perm[i] == i:
                fixed += 1
            else:
                break  # 一旦不连续就停止

        return n - fixed
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 从后向前找最长的连续有序后缀
2. 后缀中已经在正确位置的元素不需要移动
3. 最少操作 = n - 最长有序后缀长度

## 易错点

1. 后缀必须是连续的，不能有间断（一旦中断就停止计数）
2. 空数组和长度为 1 的数组都返回 0
