## 题目描述

未知整数数组 `arr` 是由 `1` 到 `n` 的所有整数组成的一个排列（即只包含 1 到 n 且每个整数恰好出现一次）。

给你一个整数数组 `encoded`，其中 `encoded[i] = arr[i] XOR arr[i + 1]`。此外，`n` 是奇数。

你可以找到数组 `arr` 吗？如果存在的话，返回数组 `arr` 否则返回空数组。

**示例 1：**
```
输入：encoded = [3,1]
输出：[1,2,3]
```

**提示：**
- `3 <= n <= 10^5`
- `n` 是奇数
- `encoded.length == n - 1`

## 解题思路

关键：`n` 为奇数。

设 `total = 1 XOR 2 XOR ... XOR n`。

利用 `encoded[1] XOR encoded[3] XOR ...`（偶数下标的 encoded）：
```
encoded[1] = arr[1] ^ arr[2]
encoded[3] = arr[3] ^ arr[4]
...
```
所有偶数下标的 encoded 之积 = `arr[1] ^ arr[2] ^ arr[3] ^ ... ^ arr[n-1]`（即除 `arr[0]` 外所有元素的异或）

因为 `total = arr[0] ^ arr[1] ^ ... ^ arr[n-1]`，所以：
`arr[0] = total ^ (encoded[1] ^ encoded[3] ^ ...)`

得到 `arr[0]` 后，按 `arr[i+1] = arr[i] ^ encoded[i]` 依次还原。

## 代码实现

### 方法一：数学推导（推荐）

```python
from typing import List

class Solution:
    def decode(self, encoded: List[int]) -> List[int]:
        n = len(encoded) + 1
        
        # 计算 1 XOR 2 XOR ... XOR n
        total = 0
        for i in range(1, n + 1):
            total ^= i
        
        # 计算 encoded[1] XOR encoded[3] XOR ...（偶数索引，跳过 encoded[0]）
        # 这等于 arr[1] ^ arr[2] ^ ... ^ arr[n-1]
        xor_rest = 0
        for i in range(1, n - 1, 2):
            xor_rest ^= encoded[i]
        
        # arr[0] = total ^ xor_rest
        first = total ^ xor_rest
        
        # 依次还原数组
        arr = [first]
        for enc in encoded:
            arr.append(arr[-1] ^ enc)
        
        return arr
```

### 方法二：验证版本（含结果验证）

```python
from typing import List

class Solution:
    def decode(self, encoded: List[int]) -> List[int]:
        n = len(encoded) + 1
        
        # 1 到 n 的 XOR
        total = 0
        for i in range(1, n + 1):
            total ^= i
        
        # encoded 奇数索引（1, 3, 5, ...）的 XOR = arr[1..n-1] 的 XOR
        exclude_first = 0
        for i in range(1, len(encoded), 2):
            exclude_first ^= encoded[i]
        
        arr = [total ^ exclude_first]
        for e in encoded:
            arr.append(arr[-1] ^ e)
        
        # 验证（可选）
        # assert sorted(arr) == list(range(1, n + 1))
        
        return arr
```

## 复杂度分析

- **时间复杂度**：O(n)，线性遍历
- **空间复杂度**：O(n)，存储结果数组

## 关键点总结

1. `n` 为奇数时，偶数索引的 `encoded` 之 XOR 恰好等于除第一个元素外所有元素的 XOR
2. 用总 XOR 减去（异或掉）可以推导出第一个元素
3. 知道第一个元素后，用 `arr[i+1] = arr[i] ^ encoded[i]` 还原所有元素

## 易错点

- `n` 为偶数时此方法不适用（偶数索引 XOR 不能推导第一个元素）
- 注意 `encoded` 的索引从 0 开始，偶数索引的 `encoded` 对应 `encoded[1], encoded[3], ...`
