## 题目描述

给你一个大小为 `m x n` 的矩阵 `grid`，矩阵由若干整数组成，且每一行的数字已按**非递减**顺序排列。

返回矩阵中的**中位数**（矩阵中的元素数量为奇数）。

**示例 1：**
```
输入：grid = [[1,1,2],[2,3,3],[1,3,4]]
输出：2
```

**示例 2：**
```
输入：grid = [[1,1,3,3,4]]
输出：3
```

**提示：**
- `m == grid.length`
- `n == grid[0].length`
- `1 <= m, n <= 500`
- `m * n` 为奇数
- `1 <= grid[i][j] <= 10^6`

## 解题思路

**二分答案：**

1. 中位数 = 第 `(m * n + 1) / 2` 小的数。
2. 对答案进行二分：找最小的 `x`，使得矩阵中 `<= x` 的元素数量 `>= (m*n+1)//2`。
3. 对每一行用 `bisect_right` 统计 `<= x` 的个数，累加得总数。

## 代码实现

### 方法一：二分答案（推荐）

```python
from typing import List
import bisect

class Solution:
    def matrixMedian(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        target = (m * n + 1) // 2  # 中位数排名
        
        # 二分：在值域 [1, 10^6] 上找最小的满足条件的值
        lo, hi = 1, 10**6
        
        while lo < hi:
            mid = (lo + hi) // 2
            # 统计矩阵中 <= mid 的元素个数
            count = sum(bisect.bisect_right(row, mid) for row in grid)
            if count >= target:
                hi = mid
            else:
                lo = mid + 1
        
        return lo
```

### 方法二：展平后排序（暴力，适合小数据）

```python
from typing import List

class Solution:
    def matrixMedian(self, grid: List[List[int]]) -> int:
        # 将所有元素展平并排序
        flat = []
        for row in grid:
            flat.extend(row)
        flat.sort()
        # 返回中间元素
        return flat[len(flat) // 2]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分答案 | O(m * log(max_val) * log(n)) | O(1) |
| 暴力排序 | O(mn log(mn)) | O(mn) |

## 关键点总结

1. 利用每行有序的特性，用 `bisect_right` 快速统计每行中 `<= x` 的个数。
2. 二分答案：在值域上二分，而不是在下标上二分。
3. 中位数是排名第 `(m*n+1)//2` 的元素（因为总元素数为奇数）。

## 易错点

- `target = (m * n + 1) // 2`，是第几小，不是下标（下标需要 -1）。
- 二分终止条件：`lo < hi`，最终返回 `lo`（即满足条件的最小值）。
- 值域为 `[1, 10^6]`，不是下标范围。
