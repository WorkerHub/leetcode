## 题目描述

给你 `n` 个 SQL 表，每张表有 `columns[i]` 列，编号从 `1` 到 `columns[i]`。现在，你需要设计一个类 `SQL`，支持如下操作：

- `SQL(names, columns)`：创建 SQL 对象，以 `names[i]` 为名创建第 `i` 张表，表中有 `columns[i]` 列。
- `insertRow(name, row)`：向名为 `name` 的表中插入一行数据 `row`，行的 ID 从 1 开始自增。
- `deleteRow(name, rowId)`：删除名为 `name` 的表中行 ID 为 `rowId` 的行。
- `selectCell(name, rowId, columnId)`：返回名为 `name` 的表中，行 ID 为 `rowId`、列 ID 为 `columnId` 的值。

**示例：**
```
输入：
["SQL", "insertRow", "selectCell", "insertRow", "deleteRow", "selectCell"]
[
  [["one", "two", "three"], [2, 3, 1]],
  ["two", ["first", "second", "third"]],
  ["two", 1, 2],
  ["two", ["fourth", "fifth", "sixth"]],
  ["two", 1],
  ["two", 2, 2]
]
输出：[null, null, "second", null, null, "fifth"]
```

## 解题思路

用哈希表存储每张表的数据：
- `tables[name]` 是一个字典，key 是行 ID，value 是该行的数据列表
- `next_id[name]` 记录每张表下一个可用的行 ID（行 ID 自增，不因删除而回滚）
- 删除行时只需从字典中删除对应键值对

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class SQL:
    def __init__(self, names: List[str], columns: List[int]):
        # 每张表存储的数据：{表名: {行ID: 行数据}}
        self.tables = {name: {} for name in names}
        # 每张表下一个行 ID
        self.next_id = {name: 1 for name in names}

    def insertRow(self, name: str, row: List[str]) -> None:
        # 插入行，行 ID 为当前自增值
        row_id = self.next_id[name]
        self.tables[name][row_id] = row
        self.next_id[name] += 1  # 自增，不因删除而回退

    def deleteRow(self, name: str, rowId: int) -> None:
        # 删除指定行
        if rowId in self.tables[name]:
            del self.tables[name][rowId]

    def selectCell(self, name: str, rowId: int, columnId: int) -> str:
        # 返回指定行列的值，列 ID 从 1 开始
        return self.tables[name][rowId][columnId - 1]
```

### 方法二：用列表存储（对比学习）

```python
from typing import List

class SQL:
    def __init__(self, names: List[str], columns: List[int]):
        # 使用字典存储表，每行用 (行ID, 数据) 形式的列表存储
        self.data = {}
        self.counters = {}
        for name in names:
            self.data[name] = {}   # {rowId: row_data}
            self.counters[name] = 0

    def insertRow(self, name: str, row: List[str]) -> None:
        self.counters[name] += 1
        self.data[name][self.counters[name]] = row

    def deleteRow(self, name: str, rowId: int) -> None:
        self.data[name].pop(rowId, None)  # 安全删除，不存在也不报错

    def selectCell(self, name: str, rowId: int, columnId: int) -> str:
        return self.data[name][rowId][columnId - 1]
```

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| insertRow | O(1) | O(列数) |
| deleteRow | O(1) | O(1) |
| selectCell | O(1) | O(1) |

## 关键点总结

1. 行 ID 自增，删除后不回滚，所以要单独维护计数器
2. 用哈希表（字典）存储行数据，支持 O(1) 的插入/删除/查找
3. `selectCell` 中列 ID 从 1 开始，访问列表时需减 1

## 易错点

- 列 ID 从 1 开始，不是 0，访问列表元素需要 `columnId - 1`
- 删除行后，行 ID 计数器不应减少，后续插入的行 ID 继续递增
