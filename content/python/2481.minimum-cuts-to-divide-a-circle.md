## 题目描述

给你一个整数 `n`，表示要将一个圆分成 `n` 个相等的扇形，返回所需的 **最小直线切割次数**。

**示例 1：**
```
输入：n = 4
输出：2
解释：用 2 条直径可以切成 4 等份
```

**示例 2：**
```
输入：n = 3
输出：3
解释：需要 3 条从圆心出发的射线，共 3 刀
```

**提示：**
- `1 <= n <= 100`

## 解题思路

**数学规律：**

- `n = 1`：不需要切割，返回 0
- `n` 为偶数：每条直径切两刀（对称），需要 `n / 2` 条直径，返回 `n // 2`
- `n` 为奇数：每条切割线只切一刀（无法穿过圆心对称），需要 `n` 刀，返回 `n`

## 代码实现

### 方法一：数学判断（推荐）

```python
class Solution:
    def numberOfCuts(self, n: int) -> int:
        if n == 1:
            return 0
        if n % 2 == 0:
            return n // 2  # 偶数：每条直径切两份，n/2 条直径
        else:
            return n  # 奇数：每次只切一份
```

### 方法二：更简洁的写法

```python
class Solution:
    def numberOfCuts(self, n: int) -> int:
        # n=1 特殊情况；偶数 n//2；奇数 n
        return 0 if n == 1 else (n // 2 if n % 2 == 0 else n)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学判断 | O(1) | O(1) |

## 关键点总结

1. `n = 1` 时无需切割
2. 偶数 n：通过圆心的直径一刀切两份，共 n/2 刀
3. 奇数 n：每刀只切一份，共 n 刀

## 易错点

- 忘记特判 `n = 1`
- 偶数时误返回 n 而非 n/2
