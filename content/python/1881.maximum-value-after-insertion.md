## 题目描述

给你一个字符串 `n` 表示一个整数（可能为负数），以及一个整数 `x`。

在 `n` 的某个位置插入 `x`，使得结果整数**最大**。返回插入后的整数字符串。

**示例 1：**
```
输入：n = "99", x = 9
输出："999"
```

**示例 2：**
```
输入：n = "-13", x = 2
输出："-123"
```

**提示：**
- `1 <= n.length <= 10^5`
- `1 <= x <= 9`
- n 不含前导零（但可以是负数）

## 解题思路

**贪心**：

- **正数**：找第一个比 x 小的数字位置，在其前插入 x（使高位更大）
- **负数**：找第一个比 x 大的数字位置，在其前插入 x（使负数绝对值更小，即整体更大）

若没找到，则在末尾插入。

## 代码实现

### 方法一：贪心扫描（推荐）

```python
class Solution:
    def maxValue(self, n: str, x: int) -> str:
        is_negative = n[0] == '-'
        digits = n[1:] if is_negative else n
        x_str = str(x)

        insert_pos = len(digits)  # 默认插入末尾
        for i, d in enumerate(digits):
            if (not is_negative and d < x_str) or (is_negative and d > x_str):
                insert_pos = i
                break

        result = digits[:insert_pos] + x_str + digits[insert_pos:]
        return ('-' if is_negative else '') + result
```

### 方法二：逐位判断（明确版）

```python
class Solution:
    def maxValue(self, n: str, x: int) -> str:
        sx = str(x)
        if n[0] != '-':
            # 正数：找第一个比 x 小的位置插入
            for i in range(len(n)):
                if n[i] < sx:
                    return n[:i] + sx + n[i:]
        else:
            # 负数：从第 1 位（跳过 '-'）找第一个比 x 大的位置插入
            for i in range(1, len(n)):
                if n[i] > sx:
                    return n[:i] + sx + n[i:]
        return n + sx
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 正数：贪心在高位插入更大的数（找第一个比 x 小的位置）
2. 负数：贪心在高位插入更小的数（绝对值更小，整体更大）

## 易错点

- 负数的处理：跳过符号位 '-'，从第 1 位开始
- 没有找到合适位置时，插入末尾
