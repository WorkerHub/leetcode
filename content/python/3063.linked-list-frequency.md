## 题目描述

给你一个链表头节点 `head`，返回一个链表，包含链表中每个唯一值的出现频率，结果可以以任意顺序返回。

**示例 1：**
```
输入：head = [1,1,2,1,2,3]
输出：[3,2,1]（1出现3次，2出现2次，3出现1次）
```

**提示：**
- 链表中节点数在 `[1, 10^5]` 范围内
- `1 <= Node.val <= 10^5`

## Python 代码实现

### 方法一：哈希表统计频率（推荐）

```python
from typing import Optional
from collections import Counter

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def frequenciesOfElements(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 统计每个值的频率
        freq = Counter()
        node = head
        while node:
            freq[node.val] += 1
            node = node.next

        # 构建结果链表
        dummy = ListNode(0)
        cur = dummy
        for count in freq.values():
            cur.next = ListNode(count)
            cur = cur.next

        return dummy.next
```

### 方法二：排序后统计（O(n log n)）

```python
from typing import Optional

class Solution:
    def frequenciesOfElements(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 收集所有值
        vals = []
        node = head
        while node:
            vals.append(node.val)
            node = node.next

        # 统计频率
        from collections import Counter
        freq = Counter(vals)

        # 构建链表
        dummy = ListNode(0)
        cur = dummy
        for f in freq.values():
            cur.next = ListNode(f)
            cur = cur.next
        return dummy.next
```

## 复杂度分析

- 时间复杂度：O(n)，遍历链表一次
- 空间复杂度：O(k)，k 为不同值的数量

## 关键点总结

1. Counter 高效统计频率
2. 频率值即为结果链表的节点值
3. 结果顺序任意

## 易错点

1. 返回链表而非列表
2. 结果可以以任意顺序返回
