## 题目描述

给你一个长度为 `n` 的整数数组 `rolls` 和一个整数 `k`，其中 `rolls[i]` 表示第 `i` 次掷骰子的结果（骰子的范围是 `[1, k]`）。

返回**长度最短**且**无法**作为 `rolls` 的子序列的掷骰子结果序列的长度。

**示例 1：**
```
输入：rolls = [4,2,1,2,3,3,2,4,1], k = 4
输出：3
解释：长度 1 的每种结果（1,2,3,4）在 rolls 中都出现过；长度 2 的所有 16 种序列也都能找到；但某些长度 3 的序列无法找到。
```

**示例 2：**
```
输入：rolls = [1,1,2,2], k = 2
输出：2
```

**提示：**
- `n == rolls.length`
- `1 <= n <= 10^5`
- `1 <= rolls[i] <= k <= 10^5`

## 解题思路

**贪心：**

将 rolls 按段划分：每段覆盖所有 k 种点数至少一次。经过 `t` 段后，所有长度为 `t` 的序列都能在 rolls 中找到，但长度 `t+1` 时可能找不到。

**算法：**
1. 用集合 `seen` 记录当前段中出现的点数。
2. 遍历 rolls，将每个点数加入 `seen`。
3. 当 `seen` 包含所有 k 种点数时，表示一段结束，段数 +1，清空 `seen`。
4. 最终答案 = 段数 + 1。

## 代码实现

### 方法一：贪心段计数（推荐）

```python
from typing import List

class Solution:
    def shortestSequence(self, rolls: List[int], k: int) -> int:
        seen = set()
        segments = 0  # 完整覆盖 k 种点数的段数
        
        for x in rolls:
            seen.add(x)
            if len(seen) == k:
                # 当前段覆盖了所有 k 种点数
                segments += 1
                seen.clear()
        
        # 所有长度 <= segments 的序列都能找到
        # 长度 segments + 1 的序列无法全部找到
        return segments + 1
```

### 方法二：带详细注释的版本

```python
from typing import List

class Solution:
    def shortestSequence(self, rolls: List[int], k: int) -> int:
        seen = set()
        ans = 1  # 当前能被 rolls 覆盖的最大序列长度
        
        for x in rolls:
            seen.add(x)
            # 当前段覆盖所有 k 种，ans 增加
            if len(seen) == k:
                ans += 1
                seen.clear()
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心段计数 | O(n) | O(k) |

## 关键点总结

1. 每段覆盖全部 k 种点数后，可保证所有该长度的序列都能找到。
2. t 段能保证长度 t 的所有序列都能出现，因此答案为段数 + 1。
3. 这是一个贪心的覆盖划分问题。

## 易错点

- 段数统计时，当 `seen` 恰好包含 k 种时才结算一段，清空后重新开始。
- 最终剩余的 `seen`（不足一段）不增加段数，但答案仍比段数多 1。
