## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。

每次操作可以选择一行或一列，并对该行/列中的每个值取反（0 变 1，1 变 0）。

判断是否可以通过若干次操作将矩阵变成**全零矩阵**。若可以，返回 `true`；否则返回 `false`。

**示例：**
```
输入：grid = [[0,1,0],[1,0,1],[0,1,0]]
输出：true
解释：翻转第1行变[[0,1,0],[0,1,0],[0,1,0]]，翻转第1列变全零。
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 300`
- `grid[i][j] == 0 or 1`

## 解题思路

**关键观察：** 通过行列翻转将矩阵变全零，等价于每一行都相同（全 0 或全 1，可以统一翻转列处理），进而等价于每一行要么与第一行完全相同，要么是第一行的**位取反**。

**证明：** 
- 先通过行翻转使某些行等于第一行，某些行等于第一行的取反。
- 再通过列翻转（按第一行的值翻转）将所有行变为全零。

**结论：** 对于每一行 `row[i]`，若 `row[i]` 等于 `row[0]` 或等于 `row[0]` 的按位取反，则可行；否则不可行。

## 代码实现

### 方法一：检查行一致性（推荐）

```python
from typing import List

class Solution:
    def removeOnes(self, grid: List[List[int]]) -> bool:
        first_row = grid[0]
        n = len(first_row)
        # 第一行的补（取反）
        complement = [1 - x for x in first_row]

        for row in grid[1:]:
            # 每一行必须等于 first_row 或其取反
            if row != first_row and row != complement:
                return False
        return True
```

### 方法二：用元组比较

```python
from typing import List

class Solution:
    def removeOnes(self, grid: List[List[int]]) -> bool:
        first = tuple(grid[0])
        inv = tuple(1 - x for x in first)
        return all(tuple(row) == first or tuple(row) == inv for row in grid)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 行检查 | O(m * n) | O(n) |

## 关键点总结

1. 关键等价条件：每行要么与第一行相同，要么是第一行的补。
2. 若满足此条件，先翻转不同的行，再翻转值为 1 的列，即可变全零。
3. 对每行的比较时间 O(n)，总时间 O(m*n)。

## 易错点

- 取反是每个元素 `1 - x`，不是 Python 的 `~` 按位取反（`~0 = -1`）。
- 只需和第一行比较，不需要和所有行比较。
