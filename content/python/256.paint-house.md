## 题目描述

假如有一排房子，共 n 个，每个房子可以被粉刷成红色、蓝色或者绿色这三种颜色中的一种。你需要粉刷所有的房子并且使其相邻的两个房子颜色不能相同。

每个房子粉刷成不同颜色的成本是不同的。你需要设计一个方案，使得粉刷所有房子的总成本最低。

**注意：** 所有成本都是正整数。

**示例：**

```
输入：costs = [[17,2,17],[16,16,5],[14,3,19]]
输出：10
解释：
将第 0 个房子粉刷成蓝色，第 1 个房子粉刷成绿色，第 2 个房子粉刷成蓝色。
最低成本: 2 + 5 + 3 = 10
```

**提示：**
- `costs.length == n`
- `costs[i].length == 3`
- `1 <= n <= 100`
- `1 <= costs[i][j] <= 20`

**进阶：** 你能否在 O(1) 的空间复杂度内解决它？

## 解题思路

这是一道经典的动态规划问题，类似于"打家劫舍"系列。

核心思想：
- 状态定义：`dp[i][j]` 表示粉刷到第 i 个房子，且第 i 个房子粉刷成颜色 j 时的最小成本
- 状态转移：第 i 个房子的颜色不能和第 i-1 个房子相同
- 最终答案：`min(dp[n-1][0], dp[n-1][1], dp[n-1][2])`

状态转移方程：
```
dp[i][0] = costs[i][0] + min(dp[i-1][1], dp[i-1][2])  # 粉刷成红色
dp[i][1] = costs[i][1] + min(dp[i-1][0], dp[i-1][2])  # 粉刷成蓝色
dp[i][2] = costs[i][2] + min(dp[i-1][0], dp[i-1][1])  # 粉刷成绿色
```

## Python 代码实现

### 方法一：动态规划（二维 DP）⭐

```python
from typing import List

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        """
        二维 DP 数组
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        if not costs:
            return 0
        
        n = len(costs)
        # dp[i][j] 表示粉刷到第 i 个房子，第 i 个房子颜色为 j 的最小成本
        dp = [[0] * 3 for _ in range(n)]
        
        # 初始化：第一个房子
        dp[0][0] = costs[0][0]  # 红色
        dp[0][1] = costs[0][1]  # 蓝色
        dp[0][2] = costs[0][2]  # 绿色
        
        # 状态转移
        for i in range(1, n):
            # 粉刷成红色：前一个房子只能是蓝色或绿色
            dp[i][0] = costs[i][0] + min(dp[i-1][1], dp[i-1][2])
            # 粉刷成蓝色：前一个房子只能是红色或绿色
            dp[i][1] = costs[i][1] + min(dp[i-1][0], dp[i-1][2])
            # 粉刷成绿色：前一个房子只能是红色或蓝色
            dp[i][2] = costs[i][2] + min(dp[i-1][0], dp[i-1][1])
        
        # 返回最后一个房子三种颜色的最小值
        return min(dp[n-1][0], dp[n-1][1], dp[n-1][2])
```

### 方法二：空间优化（一维 DP）⭐

```python
from typing import List

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        """
        空间优化：只需要保存前一个房子的状态
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if not costs:
            return 0
        
        # prev_red, prev_blue, prev_green 表示前一个房子的最小成本
        prev_red = costs[0][0]
        prev_blue = costs[0][1]
        prev_green = costs[0][2]
        
        for i in range(1, len(costs)):
            # 计算当前房子的最小成本
            curr_red = costs[i][0] + min(prev_blue, prev_green)
            curr_blue = costs[i][1] + min(prev_red, prev_green)
            curr_green = costs[i][2] + min(prev_red, prev_blue)
            
            # 更新为当前状态
            prev_red = curr_red
            prev_blue = curr_blue
            prev_green = curr_green
        
        return min(prev_red, prev_blue, prev_green)
```

### 方法三：原地修改（最优空间）⭐

```python
from typing import List

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        """
        原地修改 costs 数组
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        if not costs:
            return 0
        
        for i in range(1, len(costs)):
            # 直接在原数组上更新
            costs[i][0] += min(costs[i-1][1], costs[i-1][2])
            costs[i][1] += min(costs[i-1][0], costs[i-1][2])
            costs[i][2] += min(costs[i-1][0], costs[i-1][1])
        
        return min(costs[-1])
```

### 方法四：递归 + 记忆化

```python
from typing import List
from functools import lru_cache

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        """
        递归 + 记忆化
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        n = len(costs)
        
        @lru_cache(None)
        def dp(i: int, color: int) -> int:
            """
            返回粉刷到第 i 个房子，第 i 个房子颜色为 color 的最小成本
            color: 0-红色, 1-蓝色, 2-绿色, -1-表示没有限制
            """
            # 边界：粉刷完所有房子
            if i == n:
                return 0
            
            # 如果没有颜色限制（第一个房子）
            if color == -1:
                return min(
                    costs[i][0] + dp(i + 1, 0),
                    costs[i][1] + dp(i + 1, 1),
                    costs[i][2] + dp(i + 1, 2)
                )
            
            # 当前房子不能和上一个房子颜色相同
            min_cost = float('inf')
            for c in range(3):
                if c != color:
                    min_cost = min(min_cost, costs[i][c] + dp(i + 1, c))
            
            return min_cost
        
        return dp(0, -1)
```

### 方法五：通用解法（适用于 k 种颜色）

```python
from typing import List

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        """
        通用解法，可以扩展到 k 种颜色
        时间复杂度：O(n * k^2)，k 为颜色数
        空间复杂度：O(1)
        """
        if not costs:
            return 0
        
        k = len(costs[0])  # 颜色数量
        prev = costs[0][:]
        
        for i in range(1, len(costs)):
            curr = [0] * k
            for j in range(k):
                # 找出除了颜色 j 之外的最小成本
                curr[j] = costs[i][j] + min(prev[p] for p in range(k) if p != j)
            prev = curr
        
        return min(prev)
```

## 复杂度分析

**方法一（二维 DP）：**
- 时间复杂度：O(n)，n 为房子数量
- 空间复杂度：O(n)

**方法二、三（空间优化）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 `costs = [[17,2,17],[16,16,5],[14,3,19]]` 为例：

```
房子:    0        1        2
颜色:  R  B  G   R  B  G   R  B  G
成本: 17  2 17  16 16  5  14  3 19

DP 过程：
初始化: dp[0] = [17, 2, 17]

房子1:
  dp[1][R] = 16 + min(2, 17) = 18
  dp[1][B] = 16 + min(17, 17) = 33
  dp[1][G] = 5 + min(17, 2) = 7
  dp[1] = [18, 33, 7]

房子2:
  dp[2][R] = 14 + min(33, 7) = 21
  dp[2][B] = 3 + min(18, 7) = 10  ← 最小
  dp[2][G] = 19 + min(18, 33) = 37
  dp[2] = [21, 10, 37]

最终答案: min(21, 10, 37) = 10

最优方案：房子0-蓝色(2) → 房子1-绿色(5) → 房子2-蓝色(3)
```

## 关键点总结

1. **DP 状态设计**：需要记录当前房子的颜色，确保相邻房子颜色不同
2. **状态转移**：当前颜色的成本 = 当前粉刷成本 + 前一房子其他颜色的最小成本
3. **空间优化**：只需要保存前一个房子的状态，可优化到 O(1)
4. **原地修改**：可以直接在原数组上修改，进一步优化空间
5. **通用性**：算法可以扩展到 k 种颜色的情况

## 易错点

1. **忘记限制相邻房子颜色不同**
   ```python
   # 错误：没有限制颜色
   dp[i][j] = costs[i][j] + min(dp[i-1])
   
   # 正确：排除相同颜色
   dp[i][0] = costs[i][0] + min(dp[i-1][1], dp[i-1][2])
   ```

2. **原地修改时的顺序**
   ```python
   # 错误：会覆盖需要使用的值
   costs[i][0] += min(costs[i][1], costs[i][2])
   
   # 正确：使用前一行的值
   costs[i][0] += min(costs[i-1][1], costs[i-1][2])
   ```

3. **空间优化时的变量更新**
   ```python
   # 需要先计算所有新值，再统一更新
   curr_red = costs[i][0] + min(prev_blue, prev_green)
   curr_blue = costs[i][1] + min(prev_red, prev_green)
   curr_green = costs[i][2] + min(prev_red, prev_blue)
   # 不能边计算边更新 prev_red
   ```

4. **边界条件**：注意处理只有一个房子的情况
