## 题目描述

给你一个文件夹列表 `paths`，每个 `paths[i]` 表示一个文件夹路径（绝对路径，用字符串列表表示）。

如果两个文件夹（以及它们的子文件夹结构）完全相同，则认为它们是**重复文件夹**，需要**删除**所有重复文件夹（每组重复文件夹中所有的都删掉）。

返回删除后剩余的文件夹路径列表（可以按任意顺序）。

**示例：**
```
输入：paths = [["a"],["c"],["d"],["a","b"],["c","b"],["d","a"]]
输出：[["d"],["d","a"]]
解释：["a","b"] 和 ["c","b"] 子树相同（都是空子树 "b"），均被删除
```

**提示：**
- `1 <= paths.length <= 2 * 10^4`

---

## 解题思路

### 核心思想：字典树 + 序列化子树 + 哈希去重

1. 构建字典树
2. 对每个节点的子树进行**序列化**（递归生成子树的字符串表示）
3. 用哈希表统计每种子树序列化的出现次数
4. 删除出现次数 >= 2 的子树（即重复的）
5. 遍历剩余节点，收集合法路径

## 代码实现

### 方法一：字典树 + 序列化（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def deleteDuplicateFolder(self, paths: List[List[str]]) -> List[List[str]]:
        # 构建字典树
        trie = {}

        for path in paths:
            node = trie
            for folder in path:
                if folder not in node:
                    node[folder] = {}
                node = node[folder]

        # 统计子树序列化字符串的出现次数
        count = defaultdict(int)

        def serialize(node: dict) -> str:
            """序列化以 node 为根的子树"""
            if not node:
                return ''
            # 对子节点按名称排序，构建序列化字符串
            parts = []
            for key in sorted(node.keys()):
                child_serial = serialize(node[key])
                parts.append(f'({key}{child_serial})')
            result = ''.join(parts)
            count[result] += 1
            return result

        serialize(trie)

        # 收集未被删除的路径
        result = []

        def dfs(node: dict, path: List[str], serial_func) -> None:
            for key in sorted(node.keys()):
                child = node[key]
                # 计算子树序列化（已计算过，需要重新获取）
                child_serial = serialize_no_count(child)
                if count[child_serial] >= 2:
                    # 该子树是重复的，跳过
                    continue
                path.append(key)
                result.append(path[:])
                dfs(child, path, serial_func)
                path.pop()

        def serialize_no_count(node: dict) -> str:
            """仅序列化，不计数"""
            if not node:
                return ''
            parts = []
            for key in sorted(node.keys()):
                child_serial = serialize_no_count(node[key])
                parts.append(f'({key}{child_serial})')
            return ''.join(parts)

        dfs(trie, [], serialize_no_count)
        return result
```

### 方法二：优化版（缓存序列化结果）

```python
from typing import List
from collections import defaultdict

class Solution:
    def deleteDuplicateFolder(self, paths: List[List[str]]) -> List[List[str]]:
        # 构建字典树
        trie = {}
        for path in paths:
            node = trie
            for f in path:
                node = node.setdefault(f, {})

        # 计算并缓存每个节点的子树序列化
        count = defaultdict(int)
        serial_cache = {}

        def get_serial(node_id: int, node: dict) -> str:
            if id(node) in serial_cache:
                return serial_cache[id(node)]
            if not node:
                serial_cache[id(node)] = ''
                return ''
            parts = []
            for key in sorted(node.keys()):
                child_serial = get_serial(id(node[key]), node[key])
                parts.append(f'({key}{child_serial})')
            result = ''.join(parts)
            count[result] += 1
            serial_cache[id(node)] = result
            return result

        get_serial(id(trie), trie)

        result = []

        def dfs(node: dict, path: List[str]) -> None:
            for key in sorted(node.keys()):
                child = node[key]
                s = serial_cache[id(child)]
                if s and count[s] >= 2:
                    continue
                path.append(key)
                result.append(path[:])
                dfs(child, path)
                path.pop()

        dfs(trie, [])
        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法二（缓存） | O(n * L * log L) | O(n * L) |

n 为路径数，L 为路径平均长度。

---

## 关键点总结

1. 字典树构建所有路径的层次结构
2. 序列化子树时对子节点名称排序，保证相同结构有相同序列化
3. 出现 ≥ 2 次的序列化对应需要删除的子树

---

## 易错点

- 序列化时子节点必须排序，否则相同结构可能序列化不同
- 空子树（叶节点）序列化为空字符串，不应计数（叶节点不会重复判断）
- 根节点的子树序列化不应计入 count（因为根节点本身不会被删除）
