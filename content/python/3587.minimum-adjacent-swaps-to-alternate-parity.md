## 题目描述

给定一个整数数组 `nums`，通过交换相邻元素，使得数组中奇偶元素交替排列（奇偶奇偶或偶奇偶奇）。求最少的交换次数，若无法实现则返回 `-1`。

**示例 1：**

```
输入：nums = [2, 1, 4, 3]
输出：0
解释：已经是交替排列（偶奇偶奇）。
```

**示例 2：**

```
输入：nums = [2, 4, 1, 3]
输出：1
解释：交换 nums[1] 和 nums[2]：[2,1,4,3]，交替，1次。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

首先判断可行性：奇偶数量决定了目标排列模式。
- 若 n 为偶数：奇偶数量必须各为 n/2
- 若 n 为奇数：奇数可以多一个（偶奇偶...）或偶数多一个（奇偶奇...）

然后计算最少交换次数：
1. 确定目标模式（偶数开头或奇数开头）
2. 计算将奇/偶数移到正确位置的最少相邻交换次数

使用贪心：将每个偶数（或奇数）匹配到其目标位置，计算逆序数（或贪心交换）。

## Python 代码实现

### 方法一：贪心匹配（推荐）

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        odd_count = sum(1 for x in nums if x % 2 != 0)
        even_count = n - odd_count

        # 判断可行性
        if abs(odd_count - even_count) > 1:
            return -1

        def cost(start_with_odd):
            # 计算从 start_with_odd 开始的交替排列所需最少交换
            # 奇数应放在奇数下标，偶数在偶数下标（或反之）
            odd_positions = [i for i, x in enumerate(nums) if x % 2 != 0]
            even_positions = [i for i, x in enumerate(nums) if x % 2 == 0]

            if start_with_odd:
                # 奇数放位置 0, 2, 4, ...
                target_odd = [2*i for i in range(len(odd_positions))]
                target_even = [2*i+1 for i in range(len(even_positions))]
            else:
                # 偶数放位置 0, 2, 4, ...
                target_even = [2*i for i in range(len(even_positions))]
                target_odd = [2*i+1 for i in range(len(odd_positions))]

            if len(odd_positions) != len(target_odd) or len(even_positions) != len(target_even):
                return float('inf')

            # 计算逆序数（贪心移动代价）
            def calc_swaps(positions, targets):
                return sum(abs(positions[i] - targets[i]) for i in range(len(positions)))

            return calc_swaps(odd_positions, target_odd) + calc_swaps(even_positions, target_even)

        result = float('inf')
        if odd_count == even_count or odd_count == even_count + 1:
            result = min(result, cost(True))
        if odd_count == even_count or even_count == odd_count + 1:
            result = min(result, cost(False))

        return result if result != float('inf') else -1
```

### 方法二：模拟相邻交换

```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        odd_count = sum(1 for x in nums if x % 2 != 0)
        even_count = n - odd_count

        if abs(odd_count - even_count) > 1:
            return -1

        def simulate(start_odd):
            arr = list(nums)
            swaps = 0
            for i in range(n):
                expected_odd = (i % 2 == 0) == start_odd
                if (arr[i] % 2 != 0) != expected_odd:
                    j = i + 1
                    while j < n and (arr[j] % 2 != 0) != expected_odd:
                        j += 1
                    if j >= n:
                        return float('inf')
                    while j > i:
                        arr[j], arr[j-1] = arr[j-1], arr[j]
                        swaps += 1
                        j -= 1
            return swaps

        result = float('inf')
        if odd_count >= even_count:
            result = min(result, simulate(True))
        if even_count >= odd_count:
            result = min(result, simulate(False))

        return result if result != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n)（方法一），O(n^2)（方法二）
- 空间复杂度：O(n)

## 关键点总结

1. 奇偶数量差大于 1 时无解
2. 枚举两种目标模式（奇开头或偶开头）
3. 贪心匹配：第 i 个奇数（从左到右）对应目标中第 i 个奇数位置

## 易错点

1. 目标位置的确定：按原顺序贪心匹配（不需要全局最优匹配）
2. 相邻交换的代价 = 元素从当前位置到目标位置的距离（当其他元素按序排列时）
3. 两种目标模式都需要尝试，取较小值
