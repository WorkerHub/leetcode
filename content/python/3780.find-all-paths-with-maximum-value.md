## 题目描述

给定有向无环图（DAG），节点 `0` 到 `n-1`，每个节点有权值 `vals[i]`。找出从节点 `0` 到节点 `n-1` 的所有路径中，路径上节点权值之和最大的路径，返回最大权值和。

**示例 1：**
```
输入：n = 4, edges = [[0,1],[0,2],[1,3],[2,3]], vals = [1,2,3,4]
输出：7
解释：路径 0->1->3：1+2+4=7；路径 0->2->3：1+3+4=8，最大为 8。
```

**示例 2：**
```
输入：n = 3, edges = [[0,1],[1,2]], vals = [3,2,1]
输出：6
解释：唯一路径 0->1->2：3+2+1=6。
```

**提示：**
- `2 <= n <= 10^4`
- `1 <= vals[i] <= 10^4`
- 保证 DAG，存在从 0 到 n-1 的路径

## 解题思路

DAG 上的最长路径（最大权值和），使用记忆化 DFS 或拓扑排序 DP。

`dp[u]`：从节点 `u` 到终点 `n-1` 的最大权值和（包含 `u` 本身）。

转移：`dp[u] = vals[u] + max(dp[v] for (u,v) in edges)`

## Python 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from typing import List
from functools import lru_cache
from collections import defaultdict

class Solution:
    def maxPathValue(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)

        @lru_cache(maxsize=None)
        def dp(u: int) -> int:
            if u == n - 1:
                return vals[u]
            if not graph[u]:
                return float('-inf')  # 死路（无法到达终点）
            return vals[u] + max(dp(v) for v in graph[u])

        result = dp(0)
        return result if result != float('-inf') else -1
```

### 方法二：拓扑排序 DP

```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def maxPathValue(self, n: int, edges: List[List[int]], vals: List[int]) -> int:
        graph = defaultdict(list)
        rev_graph = defaultdict(list)
        in_degree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            rev_graph[v].append(u)
            in_degree[v] += 1

        # 逆向拓扑排序（从终点往起点计算）
        # dp[u]: 从 u 到终点的最大权值和
        dp = [float('-inf')] * n
        dp[n-1] = vals[n-1]

        queue = deque([n-1])  # 从终点开始
        visited = [False] * n
        visited[n-1] = True

        while queue:
            v = queue.popleft()
            for u in rev_graph[v]:
                new_val = vals[u] + dp[v]
                dp[u] = max(dp[u], new_val)
                if not visited[u]:
                    # 检查 u 的所有出边是否已处理
                    if all(visited[w] for w in graph[u]):
                        visited[u] = True
                        queue.append(u)

        return dp[0] if dp[0] != float('-inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. DAG 上最大权值路径用 DP/记忆化 DFS
2. 从终点反向 DP，或从起点正向 DP（记忆化）
3. 无法到达终点的节点标记为 -inf

## 易错点

1. 注意死路（从某节点无法到达终点）的处理
2. `lru_cache` 需要参数可哈希（整数类型即可）
