## 题目描述

给定一个非负索引 `rowIndex`，返回杨辉三角的第 `rowIndex` 行。

在杨辉三角中，每个数是它左上方和右上方的数的和。

**示例 1：**

```
输入：rowIndex = 3
输出：[1,3,3,1]
```

**示例 2：**

```
输入：rowIndex = 0
输出：[1]
```

**示例 3：**

```
输入：rowIndex = 1
输出：[1,1]
```

**提示：**

- `0 <= rowIndex <= 33`

**进阶：**

你可以优化你的算法到 O(rowIndex) 空间复杂度吗？

## 解题思路

这道题是 [118. 杨辉三角](https://leetcode.com/problems/pascals-triangle/) 的进阶版本，要求只返回第 `rowIndex` 行，并且优化空间复杂度。

**核心思想：**

1. **方法一**：生成整个杨辉三角，返回第 rowIndex 行（空间 O(rowIndex²)）
2. **方法二**：只维护两行，当前行和上一行（空间 O(rowIndex)）
3. **方法三**：原地更新一行，从后向前计算（空间 O(rowIndex)）
4. **方法四**：使用组合数公式直接计算（空间 O(rowIndex)）

**关键观察：**

- 第 i 行的第 j 个数可以由第 i-1 行的第 j-1 和第 j 个数相加得到
- 如果从后向前更新，可以原地修改数组，避免覆盖还需要使用的值

## Python 代码实现

### 方法一：从后向前原地更新（推荐）

```python
from typing import List

class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        # 初始化第 0 行
        row = [1]
        
        # 逐行更新
        for i in range(1, rowIndex + 1):
            # 从后向前更新，避免覆盖需要使用的值
            # 先添加一个 1 作为新的末尾
            row.append(1)
            
            # 从倒数第二个位置开始，向前更新
            for j in range(i - 1, 0, -1):
                row[j] = row[j] + row[j - 1]
            
            # row[0] 保持为 1，不需要更新
        
        return row
```

### 方法二：使用两个数组

```python
class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        # 当前行
        prev = [1]
        
        for i in range(1, rowIndex + 1):
            # 创建新行
            curr = [1] * (i + 1)
            
            # 计算中间的值
            for j in range(1, i):
                curr[j] = prev[j - 1] + prev[j]
            
            # 更新 prev
            prev = curr
        
        return prev
```

### 方法三：数学公式（组合数）

```python
class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        row = [1]
        
        # 使用组合数公式 C(n, k) = C(n, k-1) * (n - k + 1) / k
        for k in range(1, rowIndex + 1):
            # C(rowIndex, k) = C(rowIndex, k-1) * (rowIndex - k + 1) / k
            row.append(row[-1] * (rowIndex - k + 1) // k)
        
        return row
```

### 方法四：简洁的原地更新

```python
class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        row = [1]
        
        for i in range(rowIndex):
            # 添加新的末尾元素
            row.append(1)
            # 从后向前更新
            for j in range(len(row) - 2, 0, -1):
                row[j] += row[j - 1]
        
        return row
```

### 方法五：使用列表推导式

```python
class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        row = [1]
        
        for _ in range(rowIndex):
            # 在前后加 0，然后错位相加
            row = [1] + [row[i] + row[i + 1] for i in range(len(row) - 1)] + [1]
        
        return row
```

### 方法六：直接计算（利用对称性）

```python
class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        row = [1] * (rowIndex + 1)
        
        # 只计算前半部分，利用对称性
        for i in range(1, rowIndex // 2 + 1):
            row[i] = row[rowIndex - i] = row[i - 1] * (rowIndex - i + 1) // i
        
        return row
```

## 复杂度分析

**方法一、四、五：原地更新**
- 时间复杂度：O(rowIndex²)，需要迭代 rowIndex 次，每次更新 O(i) 个元素
- 空间复杂度：O(1)，不计返回值的空间

**方法二：两个数组**
- 时间复杂度：O(rowIndex²)
- 空间复杂度：O(rowIndex)，需要额外的数组存储上一行

**方法三、六：数学公式**
- 时间复杂度：O(rowIndex)，只需要遍历一次
- 空间复杂度：O(1)，不计返回值的空间

## 关键点总结

1. **原地更新技巧**：从后向前更新，避免覆盖还需要使用的值
2. **数学优化**：使用组合数公式 C(n, k) = C(n, k-1) × (n - k + 1) / k
3. **对称性利用**：杨辉三角每行是对称的，可以只计算一半
4. **空间优化**：只需要维护一行数据，不需要存储整个三角形
5. **整数除法**：使用 `//` 保证结果是整数

## 易错点

1. **更新顺序**：必须从后向前更新，否则会覆盖还需要的值
2. **索引范围**：更新时要注意索引范围，首尾的 1 不需要更新
3. **整数溢出**：虽然 Python 不会溢出，但其他语言要注意
4. **组合数计算**：要先乘后除，避免精度损失
5. **边界情况**：rowIndex = 0 时返回 [1]

## 图解示例

```
rowIndex = 4，计算过程：

初始：[1]

第 1 次迭代：
  添加 1：[1, 1]
  无需更新中间值

第 2 次迭代：
  添加 1：[1, 1, 1]
  从后向前：row[1] = row[1] + row[0] = 1 + 1 = 2
  结果：[1, 2, 1]

第 3 次迭代：
  添加 1：[1, 2, 1, 1]
  从后向前：row[2] = row[2] + row[1] = 1 + 2 = 3
            row[1] = row[1] + row[0] = 2 + 1 = 3
  结果：[1, 3, 3, 1]

第 4 次迭代：
  添加 1：[1, 3, 3, 1, 1]
  从后向前：row[3] = row[3] + row[2] = 1 + 3 = 4
            row[2] = row[2] + row[1] = 3 + 3 = 6
            row[1] = row[1] + row[0] = 3 + 1 = 4
  结果：[1, 4, 6, 4, 1]
```

## 为什么要从后向前更新？

```
假设当前行是 [1, 3, 3, 1]，要更新为 [1, 4, 6, 4, 1]

从前向后（错误）：
  row[1] = row[0] + row[1] = 1 + 3 = 4  -> [1, 4, 3, 1]
  row[2] = row[1] + row[2] = 4 + 3 = 7  -> [1, 4, 7, 1] （错误！）
  原因：row[1] 已经被修改，导致 row[2] 计算错误

从后向前（正确）：
  row[3] = row[2] + row[3] = 3 + 1 = 4  -> [1, 3, 3, 4]
  row[2] = row[1] + row[2] = 3 + 3 = 6  -> [1, 3, 6, 4]
  row[1] = row[0] + row[1] = 1 + 3 = 4  -> [1, 4, 6, 4]
  原因：每次更新都使用的是旧值
```
