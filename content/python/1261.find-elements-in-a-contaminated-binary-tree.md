## 题目描述

给定一棵二叉树，树中每个节点的值都被改成了 -1（被污染）。

原始的二叉树有以下规则：
- 根节点的值为 `0`
- 如果节点的值为 `x`，且该节点有左子节点，则左子节点的值为 `2 * x + 1`
- 如果节点的值为 `x`，且该节点有右子节点，则右子节点的值为 `2 * x + 2`

现在这棵树被污染了，所有节点的值都变成了 `-1`。

请你实现 `FindElements` 类：

- `FindElements(TreeNode root)`：用被污染的二叉树初始化对象，并恢复原始二叉树
- `bool find(int target)`：判断目标值 `target` 是否存在于恢复后的二叉树中

**示例：**

```
输入：
["FindElements","find","find"]
[[[-1,null,-1]],[1],[2]]

输出：
[null,false,true]

解释：
FindElements findElements = new FindElements([-1,null,-1]); 
findElements.find(1); // 返回 False，恢复后的树为 [0,null,2]
findElements.find(2); // 返回 True
```

**提示：**

- `TreeNode.val == -1`
- 二叉树的高度不超过 20
- 节点数在 `[1, 10^4]` 之间
- `find` 函数的调用次数不超过 `10^4` 次
- `0 <= target <= 10^6`

## 解题思路

这道题的核心是**恢复二叉树的值**并**快速查询**。

**关键观察：**

1. 根节点值为 0
2. 左子节点 = 父节点 * 2 + 1
3. 右子节点 = 父节点 * 2 + 2
4. 这个规则类似于**堆的索引规则**

**解法思路：**

1. **恢复树**：使用 DFS 遍历树，按规则恢复每个节点的值
2. **存储值**：将所有恢复的值存入哈希集合（Set）
3. **查询**：在哈希集合中查找 target，O(1) 时间复杂度

**优化：**
- 也可以不显式修改树的值，只在哈希集合中存储恢复的值

## Python 代码实现

### 方法一：DFS + 哈希集合（推荐）⭐

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class FindElements:
    def __init__(self, root: Optional[TreeNode]):
        # 使用集合存储所有恢复后的值
        self.values = set()
        
        # DFS 恢复树并收集所有值
        def dfs(node: TreeNode, val: int):
            if not node:
                return
            
            # 恢复当前节点的值
            node.val = val
            self.values.add(val)
            
            # 递归处理左右子树
            if node.left:
                dfs(node.left, 2 * val + 1)
            if node.right:
                dfs(node.right, 2 * val + 2)
        
        # 从根节点开始恢复，根节点值为 0
        dfs(root, 0)
    
    def find(self, target: int) -> bool:
        # 在集合中查找目标值
        return target in self.values
```

### 方法二：不修改原树（只存储值）

```python
class FindElements:
    def __init__(self, root: Optional[TreeNode]):
        self.values = set()
        
        # DFS 遍历，只收集恢复后的值，不修改原树
        def dfs(node: TreeNode, val: int):
            if not node:
                return
            
            self.values.add(val)
            
            # 递归左右子树
            dfs(node.left, 2 * val + 1)
            dfs(node.right, 2 * val + 2)
        
        dfs(root, 0)
    
    def find(self, target: int) -> bool:
        return target in self.values
```

### 方法三：BFS 实现

使用队列进行层序遍历恢复树。

```python
from collections import deque

class FindElements:
    def __init__(self, root: Optional[TreeNode]):
        self.values = set()
        
        if not root:
            return
        
        # BFS 恢复树
        queue = deque([(root, 0)])  # (节点, 恢复后的值)
        
        while queue:
            node, val = queue.popleft()
            
            # 恢复节点值
            node.val = val
            self.values.add(val)
            
            # 左子节点
            if node.left:
                queue.append((node.left, 2 * val + 1))
            
            # 右子节点
            if node.right:
                queue.append((node.right, 2 * val + 2))
    
    def find(self, target: int) -> bool:
        return target in self.values
```

### 方法四：Python 简洁写法

```python
class FindElements:
    def __init__(self, root: Optional[TreeNode]):
        self.values = set()
        
        def recover(node, val=0):
            if node:
                self.values.add(val)
                recover(node.left, 2 * val + 1)
                recover(node.right, 2 * val + 2)
        
        recover(root)
    
    def find(self, target: int) -> bool:
        return target in self.values
```

## 复杂度分析

### 初始化（构造函数）

- **时间复杂度**：O(n)，需要遍历所有 n 个节点
- **空间复杂度**：O(n)
  - 哈希集合存储 n 个值：O(n)
  - 递归调用栈深度：O(h)，h 为树的高度，最坏 O(n)

### find 函数

- **时间复杂度**：O(1)，哈希集合查找
- **空间复杂度**：O(1)

## 关键点总结

1. **值恢复规则**：根节点为 0，左子节点 `2*x+1`，右子节点 `2*x+2`
2. **哈希集合**：用于 O(1) 时间查询目标值
3. **DFS/BFS**：两种遍历方式都可以恢复树
4. **不修改原树**：可以选择不修改原树的 val，只在集合中存储恢复的值
5. **堆的索引规则**：这个规则与堆的数组索引规则相同

## 易错点

1. **根节点值**：根节点恢复为 0，而不是 1
2. **递归参数**：传递的是恢复后的值，而不是节点的原始值 -1
3. **空节点检查**：在递归前需要检查节点是否为空
4. **集合初始化**：必须在构造函数中初始化集合
5. **find 返回值**：返回布尔值，而不是节点

## 图解示例

以 `[-1, null, -1]` 为例：

```
原始污染树：
      -1
        \
        -1

恢复后：
       0
        \
         2

值恢复过程：
1. 根节点：val = 0，加入集合 {0}
2. 右子节点：val = 2*0+2 = 2，加入集合 {0, 2}

查询 find(1)：1 不在 {0, 2} 中，返回 False
查询 find(2)：2 在 {0, 2} 中，返回 True
```

```
污染树：
        -1
       /  \
     -1    -1
    /  \
  -1    -1

恢复后：
        0
       /  \
      1    2
     / \
    3   4

集合：{0, 1, 2, 3, 4}
```
