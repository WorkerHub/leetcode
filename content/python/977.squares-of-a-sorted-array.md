## 题目描述

给你一个按**非递减顺序**排序的整数数组 `nums`，返回**每个数字的平方**组成的新数组，要求也按**非递减顺序**排序。

**示例 1：**
```
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后，数组变为 [16,1,0,9,100]
排序后，数组变为 [0,1,9,16,100]
```

**示例 2：**
```
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按**非递减顺序**排序

**进阶：** 请你设计时间复杂度为 `O(n)` 的算法解决本问题。

## 解题思路

### 思路分析

虽然数组已经排序，但平方后可能不再有序。例如：
- 负数的平方会变成正数
- 绝对值较大的负数，平方后会比正数大

**关键观察**：
- 数组平方后，最大值一定在**两端**（最左边或最右边）
- 因为两端的绝对值最大

### 三种解法

1. **暴力法**：平方后排序（不满足 O(n) 要求）
2. **双指针（推荐）**：从两端向中间移动，利用已排序特性
3. **归并思想**：将数组分为负数和非负数两部分，归并

## Python 代码实现

### 方法一：双指针（推荐）⭐

```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = [0] * n  # 结果数组
        
        left, right = 0, n - 1  # 双指针
        pos = n - 1  # 从结果数组的末尾开始填充
        
        # 从两端向中间遍历
        while left <= right:
            left_square = nums[left] ** 2
            right_square = nums[right] ** 2
            
            # 哪个平方值大，就放到结果数组的当前位置
            if left_square > right_square:
                result[pos] = left_square
                left += 1
            else:
                result[pos] = right_square
                right -= 1
            
            pos -= 1
        
        return result
```

### 方法二：暴力法（简单但不优）

```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        # 平方后排序
        return sorted(num ** 2 for num in nums)
```

### 方法三：归并思想（找分界点）

```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        
        # 找到负数和非负数的分界点
        negative_end = -1
        for i in range(n):
            if nums[i] < 0:
                negative_end = i
            else:
                break
        
        # 如果全是非负数
        if negative_end == -1:
            return [num ** 2 for num in nums]
        
        # 如果全是负数
        if negative_end == n - 1:
            return [num ** 2 for num in reversed(nums)]
        
        # 归并两部分
        result = []
        i, j = negative_end, negative_end + 1
        
        while i >= 0 and j < n:
            left_square = nums[i] ** 2
            right_square = nums[j] ** 2
            
            if left_square < right_square:
                result.append(left_square)
                i -= 1
            else:
                result.append(right_square)
                j += 1
        
        # 处理剩余部分
        while i >= 0:
            result.append(nums[i] ** 2)
            i -= 1
        
        while j < n:
            result.append(nums[j] ** 2)
            j += 1
        
        return result
```

### 方法四：使用 Python 内置函数（最简洁）

```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        return sorted(map(lambda x: x * x, nums))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一：双指针 | O(n) | O(n) |
| 方法二：暴力排序 | O(n log n) | O(n) |
| 方法三：归并思想 | O(n) | O(n) |

**说明**：
- 双指针方法是最优解，满足题目进阶要求
- 空间复杂度都是 O(n)，因为需要新数组存储结果

## 图解示例

以 `nums = [-4, -1, 0, 3, 10]` 为例：

```
初始状态：
[-4, -1, 0, 3, 10]
  ↑            ↑
 left        right
 
平方值：16        100
result: [_, _, _, _, 100]  (right 的平方更大)

第二步：
[-4, -1, 0, 3, 10]
  ↑         ↑
 left     right
 
平方值：16        9
result: [_, _, _, 16, 100]  (left 的平方更大)

第三步：
[-4, -1, 0, 3, 10]
      ↑    ↑
    left right
    
平方值：1         9
result: [_, _, 9, 16, 100]

第四步：
[-4, -1, 0, 3, 10]
      ↑  ↑
    left=right
    
平方值：1         0
result: [_, 1, 9, 16, 100]

第五步：
result: [0, 1, 9, 16, 100]  完成！
```

## 关键点总结

1. **利用已排序特性**：不要忽略题目给出的"已排序"这一重要信息
2. **双指针技巧**：从两端向中间，比较绝对值大小
3. **从后向前填充**：因为最大值在两端，所以从结果数组末尾开始填
4. **时间优化**：双指针法可以做到 O(n)，优于排序的 O(n log n)

## 易错点

1. **忘记负数的影响**：
   - 错误思路：以为排序后平方也有序
   - 正确理解：负数平方后会变大

2. **指针移动方向**：
   - 从两端向中间移动
   - 结果数组从后向前填充

3. **边界条件**：
   - 全是正数的情况
   - 全是负数的情况
   - 包含 0 的情况

4. **平方计算**：
   - 可以用 `x ** 2` 或 `x * x`
   - 注意负数平方后是正数
