## 题目描述

城市的 **天际线** 是从远处观看该城市中所有建筑物形成的轮廓的外部轮廓。给你所有建筑物的位置和高度，请返回由这些建筑物形成的 **天际线**。

每个建筑物的几何信息由数组 `buildings` 表示，其中三元组 `buildings[i] = [lefti, righti, heighti]` 表示：

- `lefti` 是第 `i` 座建筑物左边缘的 x 坐标。
- `righti` 是第 `i` 座建筑物右边缘的 x 坐标。
- `heighti` 是第 `i` 座建筑物的高度。

你可以假设所有的建筑都是完美的长方形，在高度为 `0` 的绝对平坦的表面上。

**天际线** 应该表示为由 "关键点" 组成的列表，格式 `[[x1,y1],[x2,y2],...]`，并按 **x 坐标** 进行 **排序**。**关键点是水平线段的左端点**。列表中最后一个点是最右侧建筑物的终点，`y` 坐标始终为 `0`，仅用于标记天际线的终点。此外，任何两个相邻建筑物之间的地面都应被视为天际线轮廓的一部分。

**注意：** 输出天际线中不得有连续的相同高度的水平线。例如 `[...[2 3], [4 5], [7 5], [11 5], [12 7]...]` 是不正确的答案；三条高度为 5 的线应该在最终输出中合并为一个：`[...[2 3], [4 5], [12 7], ...]`

**示例 1：**

```
输入：buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]
输出：[[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]
```

**示例 2：**

```
输入：buildings = [[0,2,3],[2,5,3]]
输出：[[0,3],[5,0]]
```

**提示：**

- `1 <= buildings.length <= 10^4`
- `0 <= lefti < righti <= 2^31 - 1`
- `1 <= heighti <= 2^31 - 1`
- `buildings` 按 `lefti` 非递减顺序排列

## 解题思路

这是一道经典的困难题，考察扫描线算法和数据结构的综合应用。

**核心思想：**

1. **扫描线算法**：将所有建筑的左右边界作为关键事件点
2. **高度维护**：用数据结构（堆/多重集）维护当前最大高度
3. **关键点识别**：当最大高度发生变化时，记录关键点

**算法流程：**

1. **提取事件**：
   - 左边界：`(x, -height, 0)`（负号表示进入事件，优先级高）
   - 右边界：`(x, 0, height)`（离开事件）

2. **排序事件**：
   - 按 x 坐标排序
   - 同一 x 坐标，左边界优先于右边界
   - 同为左边界，高的优先

3. **扫描处理**：
   - 遍历事件，维护当前活跃的建筑高度
   - 当最大高度变化时，记录关键点

4. **去重**：相邻关键点高度相同时合并

## Python 代码实现

### 方法一：扫描线 + 堆（推荐）⭐

```python
class Solution:
    def getSkyline(self, buildings: List[List[int]]) -> List[List[int]]:
        import heapq
        
        # 提取所有事件
        events = []
        for left, right, height in buildings:
            # 左边界：负高度表示进入（优先级高）
            events.append((left, -height, 0))
            # 右边界：0 表示离开
            events.append((right, 0, height))
        
        # 排序事件
        events.sort()
        
        result = []
        # 大顶堆（Python 是小顶堆，用负数模拟）
        heap = [(0, float('inf'))]  # (负高度, 右边界)
        
        for x, neg_h, h in events:
            # 处理离开事件：移除过期的建筑
            while heap[0][1] <= x:
                heapq.heappop(heap)
            
            if neg_h != 0:
                # 进入事件：添加建筑
                heapq.heappush(heap, (neg_h, buildings[len(result)][1]))
            
            # 当前最大高度
            max_height = -heap[0][0]
            
            # 高度变化时记录关键点
            if not result or result[-1][1] != max_height:
                result.append([x, max_height])
        
        return result
```

### 方法二：扫描线 + 多重集（更清晰）

```python
class Solution:
    def getSkyline(self, buildings: List[List[int]]) -> List[List[int]]:
        from collections import defaultdict
        import heapq
        
        # 提取事件
        events = []
        for left, right, height in buildings:
            events.append((left, -height))  # 进入
            events.append((right, height))   # 离开
        
        # 排序：x 坐标，进入优先，高的优先
        events.sort(key=lambda x: (x[0], x[1]))
        
        result = []
        heights = [0]  # 当前活跃的高度（多重集）
        
        i = 0
        while i < len(events):
            curr_x = events[i][0]
            
            # 处理同一 x 坐标的所有事件
            while i < len(events) and events[i][0] == curr_x:
                h = events[i][1]
                if h < 0:
                    # 进入事件
                    heights.append(-h)
                else:
                    # 离开事件
                    heights.remove(h)
                i += 1
            
            # 当前最大高度
            max_height = max(heights)
            
            # 高度变化时记录
            if not result or result[-1][1] != max_height:
                result.append([curr_x, max_height])
        
        return result
```

### 方法四：分治法（理解用）

```python
class Solution:
    def getSkyline(self, buildings: List[List[int]]) -> List[List[int]]:
        if not buildings:
            return []
        if len(buildings) == 1:
            left, right, height = buildings[0]
            return [[left, height], [right, 0]]
        
        # 分治
        mid = len(buildings) // 2
        left_skyline = self.getSkyline(buildings[:mid])
        right_skyline = self.getSkyline(buildings[mid:])
        
        # 合并两个天际线
        return self.merge_skylines(left_skyline, right_skyline)
    
    def merge_skylines(self, left: List[List[int]], right: List[List[int]]) -> List[List[int]]:
        """合并两个天际线"""
        result = []
        h1 = h2 = 0  # 两个天际线当前高度
        i = j = 0
        
        while i < len(left) and j < len(right):
            if left[i][0] < right[j][0]:
                x, h1 = left[i]
                max_h = max(h1, h2)
                i += 1
            elif left[i][0] > right[j][0]:
                x, h2 = right[j]
                max_h = max(h1, h2)
                j += 1
            else:
                x = left[i][0]
                h1, h2 = left[i][1], right[j][1]
                max_h = max(h1, h2)
                i += 1
                j += 1
            
            if not result or result[-1][1] != max_h:
                result.append([x, max_h])
        
        result.extend(left[i:])
        result.extend(right[j:])
        return result
```

## 复杂度分析

**方法一（扫描线 + 堆）：**

- **时间复杂度：** O(N log N)
  - 排序：O(N log N)
  - 每个事件处理：O(log N)（堆操作）
- **空间复杂度：** O(N)

**方法二（扫描线 + 列表）：**

- **时间复杂度：** O(N²)（list.remove 是 O(N)）
- **空间复杂度：** O(N)

**方法四（分治）：**

- **时间复杂度：** O(N log N)
- **空间复杂度：** O(N)

## 关键点总结

1. **扫描线思想**：将二维问题转化为一维事件序列
2. **事件排序**：左边界、右边界的优先级和排序规则
3. **高度维护**：使用堆或有序集合维护当前最大高度
4. **关键点识别**：高度变化时才记录
5. **边界处理**：初始高度 0，最后必须回到 0

## 易错点

1. **事件排序规则错误**：
   ```python
   # 错误：同一 x 时左边界应优先处理
   events.sort()  # 仅按 x 排序不够
   # 正确：需要考虑进入/离开的优先级
   events.sort(key=lambda x: (x[0], x[1]))
   ```

2. **高度去重问题**：
   ```python
   # 错误：直接 remove 可能移除错误的高度
   heights.remove(h)  # 如果有多个相同高度
   # 正确：使用计数或多重集
   ```

3. **相同高度合并**：
   ```python
   # 错误：相同高度不合并
   result.append([x, max_height])
   # 正确：检查是否与上一个高度相同
   if not result or result[-1][1] != max_height:
       result.append([x, max_height])
   ```

4. **堆的删除操作**：
   ```python
   # Python 的 heapq 不支持删除任意元素
   # 需要惰性删除或使用其他数据结构
   ```

5. **边界建筑处理**：
   ```python
   # 忘记处理最后一个建筑的右边界
   ```
