## 题目描述

Alice 和 Bob 用几堆石子在做游戏。几堆石子排成一排，每堆石子都对应一个得分，由数组 `stoneValue` 表示。

Alice 和 Bob 轮流取石子，**Alice 总是先开始**。在每个玩家的回合中，该玩家可以拿走剩下石子中的**前 1、2 或 3 堆**石子。

比赛一直持续到所有石头都被拿走。

每个玩家的最终得分是他所拿到的每堆石子的对应数值之和。每个玩家都试图最大化自己的得分。

如果 Alice 赢了就返回 `"Alice"`，Bob 赢了就返回 `"Bob"`，分数相同返回 `"Tie"`。

**示例 1：**

```
输入：values = [1,2,3,7]
输出："Bob"
解释：Alice 总是会输的，她的最佳选择是拿走前 3 堆，得分 = 6。
Alice = 6，Bob = 7，Bob 赢了。
```

**示例 2：**

```
输入：values = [1,2,3,-9]
输出："Alice"
解释：Alice 必须选择前 3 堆，Alice = 6，Bob = -9，Alice 赢了。
```

**示例 3：**

```
输入：values = [1,2,3,6]
输出："Tie"
解释：Alice 取前 3 堆，得 6；Bob 取最后 1 堆，得 6；平局。
```

**提示：**

- `1 <= stoneValue.length <= 5 * 10^4`
- `-1000 <= stoneValue[i] <= 1000`

## 解题思路

**博弈论 + 动态规划**

**定义 `dp[i]`：** 从第 `i` 堆开始，当前先手玩家相比后手玩家的最大**净优势**（先手得分 - 后手得分）。

**递推关系：**

先手从第 `i` 堆开始，可以取 1、2 或 3 堆：

- 取 1 堆：先手获得 `stoneValue[i]`，剩余从 `i+1` 开始由后手先手
  - 先手净优势 = `stoneValue[i] - dp[i+1]`（后手变先手，取反）
- 取 2 堆：先手获得 `stoneValue[i] + stoneValue[i+1]`，剩余从 `i+2` 开始
  - 先手净优势 = `stoneValue[i] + stoneValue[i+1] - dp[i+2]`
- 取 3 堆：类似
  - 先手净优势 = `sum(stoneValue[i:i+3]) - dp[i+3]`

`dp[i] = max(三种选择的净优势)`

**边界条件：** `dp[n] = 0`（没有石子时净优势为 0）

**最终答案：**

- `dp[0] > 0`：Alice 赢
- `dp[0] < 0`：Bob 赢
- `dp[0] == 0`：平局

## Python 代码实现

### 方法一：DP 从后往前（推荐）

```python
from typing import List

class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)
        # dp[i] 表示从第 i 堆开始先手玩家的净优势（先手得分 - 后手得分）
        dp = [0] * (n + 1)
        # 从后往前计算
        for i in range(n - 1, -1, -1):
            # 先手选取 1、2 或 3 堆，取净优势最大的方案
            best = float('-inf')
            total = 0
            for k in range(1, 4):  # 取 k 堆
                if i + k - 1 < n:
                    total += stoneValue[i + k - 1]
                    # 取了 k 堆后，剩余从 i+k 开始，后手变先手
                    net = total - dp[i + k]
                    best = max(best, net)
            dp[i] = best

        if dp[0] > 0:
            return "Alice"
        elif dp[0] < 0:
            return "Bob"
        else:
            return "Tie"
```

### 方法二：记忆化搜索

```python
from typing import List
from functools import lru_cache

class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)

        @lru_cache(maxsize=None)
        def dp(i: int) -> int:
            """从第 i 堆开始，先手相比后手的最大净优势"""
            if i >= n:
                return 0
            best = float('-inf')
            total = 0
            for k in range(1, 4):  # 取 1、2、3 堆
                if i + k - 1 < n:
                    total += stoneValue[i + k - 1]
                    # 先手取 k 堆后，后手成为新的先手
                    net = total - dp(i + k)
                    best = max(best, net)
            return best

        result = dp(0)
        if result > 0:
            return "Alice"
        elif result < 0:
            return "Bob"
        else:
            return "Tie"
```

### 方法三：空间优化（滚动数组）

```python
from typing import List

class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)
        # 只需保留后三个 dp 值
        dp = [0] * (n + 4)  # 多分配几个位置避免越界

        for i in range(n - 1, -1, -1):
            total = 0
            best = float('-inf')
            for k in range(1, 4):
                if i + k <= n:
                    total += stoneValue[i + k - 1]
                    best = max(best, total - dp[i + k])
            dp[i] = best

        if dp[0] > 0:
            return "Alice"
        elif dp[0] < 0:
            return "Bob"
        else:
            return "Tie"
```

## 复杂度分析

- **时间复杂度 O(n)**：每个位置只计算一次，每次内层循环最多 3 次。
- **空间复杂度 O(n)**（方法一二），O(1) 可以进一步优化（滚动数组只需保留后3个值）。

## 图解示例

以 `stoneValue = [1,2,3,7]` 为例（n=4）：

```
dp[4] = 0

i=3: 只能取1堆(7), best = 7 - dp[4] = 7. dp[3] = 7

i=2: 
  取1堆(3):  3 - dp[3] = 3 - 7 = -4
  取2堆(3+7=10): 10 - dp[4] = 10
  best = 10. dp[2] = 10

i=1:
  取1堆(2):   2 - dp[2] = 2 - 10 = -8
  取2堆(2+3=5): 5 - dp[3] = 5 - 7 = -2
  取3堆(2+3+7=12): 12 - dp[4] = 12
  best = 12. dp[1] = 12

i=0:
  取1堆(1):   1 - dp[1] = 1 - 12 = -11
  取2堆(1+2=3): 3 - dp[2] = 3 - 10 = -7
  取3堆(1+2+3=6): 6 - dp[3] = 6 - 7 = -1
  best = -1. dp[0] = -1

dp[0] = -1 < 0 → 返回 "Bob"
```

## 关键点总结

1. `dp[i]` 的含义：从第 i 堆开始，先手相比后手的最大**净优势**（先手-后手）
2. 递推时用"先手取 k 堆后，净优势 = 取到的分数 - 对方的净优势"
3. 净优势的正负直接给出胜负（>0 先手赢，<0 后手赢，=0 平局）
4. 注意石子值可以为负，不能简单地认为"拿越多越好"

## 易错点

- `dp[i+k]` 表示后手的净优势，需要取负（即先手优势 = 取到分数 - 后手净优势）
- 内层循环要检查 `i + k - 1 < n`，防止越界
- 不要以为选项只有取1堆，要枚举1、2、3堆
- 石子值可为负，贪心（只选正值堆）是错误的，要用 DP
