## 题目描述

给你两个下标从 **0** 开始的整数数组 `nums1` 和 `nums2`，长度均为 `n`，以及两个整数 `k1` 和 `k2`。

你可以对 `nums1` 中的任一元素加 1 或减 1 **至多** `k1` 次，类似地，对 `nums2` 中的任一元素加 1 或减 1 **至多** `k2` 次。最终目标是使 `sum(|nums1[i] - nums2[i]|^2)` 最小化。

返回修改后的**平方差之和的最小值**。

**示例 1：**
```
输入：nums1 = [1,2,3,4], nums2 = [2,10,20,19], k1 = 0, k2 = 0
输出：579
```

**示例 2：**
```
输入：nums1 = [1,10,100,1000], nums2 = [1,10,100,1000], k1 = 1, k2 = 1
输出：0
```

**提示：**
- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `0 <= nums1[i], nums2[i] <= 10^5`
- `0 <= k1, k2 <= 10^9`

## 解题思路

**贪心：**
- 合并 k1 和 k2 为总操作次数 k = k1 + k2（因为可以对任意一方操作，本质上是减小差值 `|nums1[i] - nums2[i]|`）。
- 构建差值数组 `diff[i] = |nums1[i] - nums2[i]|`。
- 贪心策略：每次优先减小最大的差值（使用最大堆）。
- 使用桶排序 + 贪心可以更高效地批量缩减。

## 代码实现

### 方法一：桶排序 + 贪心（推荐）

```python
from typing import List

class Solution:
    def minSumOfSquaredDifferences(self, nums1: List[int], nums2: List[int], k1: int, k2: int) -> int:
        n = len(nums1)
        k = k1 + k2  # 总操作次数
        
        diff = [abs(nums1[i] - nums2[i]) for i in range(n)]
        
        # 桶排序：统计每个差值出现次数
        max_diff = max(diff) if diff else 0
        bucket = [0] * (max_diff + 1)
        for d in diff:
            bucket[d] += 1
        
        # 从最大差值开始，贪心地减小
        cur = max_diff
        while k > 0 and cur > 0:
            # 将 cur 级别的所有差值尽量减到 cur-1
            cnt = bucket[cur]  # 有多少个差值为 cur
            if cnt == 0:
                cur -= 1
                continue
            # 最多能减 min(k, cnt) 个
            reduce = min(k, cnt)
            bucket[cur] -= reduce
            bucket[cur - 1] += reduce
            k -= reduce
            if bucket[cur] == 0:
                cur -= 1
        
        # 计算平方差之和
        return sum(i * i * bucket[i] for i in range(max_diff + 1))
```

### 方法二：最大堆（暴力贪心）

```python
from typing import List
import heapq

class Solution:
    def minSumOfSquaredDifferences(self, nums1: List[int], nums2: List[int], k1: int, k2: int) -> int:
        k = k1 + k2
        diff = [abs(nums1[i] - nums2[i]) for i in range(len(nums1))]
        
        # Python 用负值模拟最大堆
        heap = [-d for d in diff]
        heapq.heapify(heap)
        
        while k > 0 and heap[0] < 0:
            largest = -heapq.heappop(heap)
            second = -heap[0] if heap else 0
            # 一次性将最大差值减到 second 级别
            reduce_to = second
            reduce_cnt = largest - reduce_to
            if reduce_cnt * 1 <= k:  # 假设只有 1 个最大值（需完整逻辑）
                k -= reduce_cnt
                heapq.heappush(heap, -reduce_to)
            else:
                new_val = largest - k
                k = 0
                heapq.heappush(heap, -new_val)
        
        return sum(d * d for d in [-h for h in heap])
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 桶排序 + 贪心 | O(n + max_diff) | O(max_diff) |
| 最大堆 | O((n + k) log n) | O(n) |

## 关键点总结

1. k1 和 k2 可以合并为总操作数，因为操作可施加于任意一方以减小差值。
2. 贪心策略：优先减小最大差值，使用桶排序可以批量处理。
3. 桶排序中每次将最大差值整批下移到次大差值级别。

## 易错点

- 不能将 k1 和 k2 单独处理（合并更优）。
- 桶计数下移：将 `bucket[cur]` 个差值减少时，超出 k 的部分只能减少 k 次。
