## 题目描述

给你一个只包含字符 `'a'`、`'b'` 和 `'c'` 的字符串 `s`，你可以执行下面这个操作（操作可以执行任意次数）：
- 选择字符串 `s` 一个非空的前缀，这个前缀的所有字符都相同。
- 选择字符串 `s` 一个非空的后缀，这个后缀的所有字符都相同。
- 前缀和后缀在 `s` 中所有字符都不重叠。
- 前缀和后缀包含的字符相同。
- 同时删除前缀和后缀。

请你返回对字符串 `s` 执行上面操作任意次以后（可能 0 次），能得到字符串的最短长度。

**示例 1：**
```
输入：s = "ca"
输出：2
```

**示例 2：**
```
输入：s = "cabaabac"
输出：0
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含字母 `'a'`、`'b'` 和 `'c'`

## 解题思路

双指针：左指针从左，右指针从右。

如果两端字符相同，则可以同时删除两端所有相同字符（贪心：每次尽量多删）：
- 左指针跳过所有与当前字符相同的字符
- 右指针跳过所有与当前字符相同的字符
- 继续直到两端字符不同或指针交叉

## 代码实现

### 方法一：双指针贪心（推荐）

```python
class Solution:
    def minimumLength(self, s: str) -> int:
        left, right = 0, len(s) - 1
        
        while left < right and s[left] == s[right]:
            char = s[left]
            # 删除左端所有 char
            while left <= right and s[left] == char:
                left += 1
            # 删除右端所有 char
            while left <= right and s[right] == char:
                right -= 1
        
        return right - left + 1
```

### 方法二：递归版本

```python
class Solution:
    def minimumLength(self, s: str) -> int:
        def shrink(l, r):
            if l >= r or s[l] != s[r]:
                return r - l + 1
            char = s[l]
            # 跳过左端相同字符
            while l <= r and s[l] == char:
                l += 1
            # 跳过右端相同字符
            while l <= r and s[r] == char:
                r -= 1
            return shrink(l, r)
        
        return shrink(0, len(s) - 1)
```

## 复杂度分析

- **时间复杂度**：O(n)，每个字符最多被处理一次
- **空间复杂度**：O(1)（方法一）或 O(n) 递归栈（方法二）

## 关键点总结

1. 贪心：每次尽量多删两端相同字符
2. 删除完一对后继续判断新的两端是否相同
3. 当两端字符不同或指针交叉时停止

## 易错点

- 注意 `left <= right` 的边界条件，避免越界
- 递归版本中栈深度可能为 O(n)，大数据时用迭代
