## 题目描述

给你一个以字符串形式表述的布尔表达式 expression，返回该式的运算结果。

有效的表达式需遵循以下约定：

- `"t"`，运算结果为 True
- `"f"`，运算结果为 False
- `"!(subExpr)"`，运算结果为 subExpr 的逻辑非（NOT）
- `"&(subExpr1, subExpr2, ..., subExprn)"`，运算结果为所有内层表达式的逻辑与（AND）
- `"|(subExpr1, subExpr2, ..., subExprn)"`，运算结果为所有内层表达式的逻辑或（OR）

其中 subExpr 可以是任意有效的表达式。

**示例 1：**
```
输入：expression = "&(|(f))"
输出：false
解释：
首先，计算内层的 |(f)，结果为 false
然后，计算外层的 &(false)，结果为 false
```

**示例 2：**
```
输入：expression = "|(f,f,f,t)"
输出：true
解释：四个表达式的逻辑或运算，只要有一个为 true，结果就是 true
```

**示例 3：**
```
输入：expression = "!(&(f,t))"
输出：true
解释：
首先，计算 &(f,t)，false 和 true 的逻辑与结果为 false
然后，计算 !(false)，逻辑非运算结果为 true
```

**提示：**

- `1 <= expression.length <= 2 * 10^4`
- expression 由 `'('`、`')'`、`'&'`、`'|'`、`'!'`、`'t'`、`'f'` 和 `','` 组成

## 解题思路

这道题要求解析并计算布尔表达式的值。核心思想是使用**栈**来处理嵌套的表达式结构。

**基本思路：**

1. **遍历字符串**：从左到右扫描表达式的每个字符
2. **使用栈保存信息**：将遇到的字符（除了逗号）都压入栈中
3. **遇到右括号时计算**：当遇到 `')'` 时，说明一个完整的子表达式结束了，此时：
   - 从栈中弹出字符，直到遇到左括号 `'('`
   - 收集这些字符（都是 't' 或 'f'）
   - 再弹出一个字符，得到运算符（`'&'`、`'|'` 或 `'!'`）
   - 根据运算符和收集的值计算结果
   - 将结果（'t' 或 'f'）压回栈中
4. **最终结果**：栈中最后剩下的字符就是答案

**关键点：**
- `&` 运算：所有值都为真才为真（遇到一个 'f' 就是 false）
- `|` 运算：至少有一个值为真就为真（遇到一个 't' 就是 true）
- `!` 运算：对单个值取反

## Python 代码实现

### 方法一：栈（推荐）

```python
class Solution:
    def parseBoolExpr(self, expression: str) -> bool:
        stack = []
        
        for char in expression:
            # 跳过逗号
            if char == ',':
                continue
            
            # 遇到右括号，开始计算当前子表达式
            if char == ')':
                # 收集括号内的所有值
                values = []
                while stack[-1] != '(':
                    values.append(stack.pop())
                
                # 弹出左括号
                stack.pop()
                
                # 获取运算符
                operator = stack.pop()
                
                # 根据运算符计算结果
                if operator == '&':
                    # AND 运算：所有都为 't' 才为真
                    result = 't' if all(v == 't' for v in values) else 'f'
                elif operator == '|':
                    # OR 运算：至少有一个 't' 就为真
                    result = 't' if any(v == 't' for v in values) else 'f'
                else:  # operator == '!'
                    # NOT 运算：取反
                    result = 'f' if values[0] == 't' else 't'
                
                # 将结果压回栈
                stack.append(result)
            else:
                # 将其他字符（运算符、括号、't'、'f'）压入栈
                stack.append(char)
        
        # 栈中最后剩下的就是最终结果
        return stack[0] == 't'
```

### 方法二：递归解析

```python
class Solution:
    def parseBoolExpr(self, expression: str) -> bool:
        self.index = 0
        
        def parse():
            char = expression[self.index]
            self.index += 1
            
            # 如果是 't' 或 'f'，直接返回布尔值
            if char == 't':
                return True
            if char == 'f':
                return False
            
            # 记录运算符
            operator = char
            # 跳过左括号
            self.index += 1
            
            # 收集子表达式的结果
            values = []
            while expression[self.index] != ')':
                if expression[self.index] != ',':
                    values.append(parse())
                else:
                    self.index += 1
            
            # 跳过右括号
            self.index += 1
            
            # 根据运算符返回结果
            if operator == '&':
                return all(values)
            elif operator == '|':
                return any(values)
            else:  # operator == '!'
                return not values[0]
        
        return parse()
```

### 方法三：栈优化（使用布尔值）

```python
class Solution:
    def parseBoolExpr(self, expression: str) -> bool:
        stack = []
        
        for char in expression:
            if char in ',(':
                continue
            
            if char == ')':
                # 收集当前括号内的布尔值
                values = []
                while isinstance(stack[-1], bool):
                    values.append(stack.pop())
                
                # 获取运算符
                operator = stack.pop()
                
                # 计算结果
                if operator == '&':
                    result = all(values)
                elif operator == '|':
                    result = any(values)
                else:  # '!'
                    result = not values[0]
                
                stack.append(result)
            elif char in '&|!':
                stack.append(char)
            else:  # 't' or 'f'
                stack.append(char == 't')
        
        return stack[0]
```

## 复杂度分析

**方法一（栈）：**
- 时间复杂度：O(n)，其中 n 是表达式的长度。每个字符最多入栈和出栈各一次。
- 空间复杂度：O(n)，栈的最大深度取决于表达式的嵌套层数，最坏情况下为 O(n)。

**方法二（递归）：**
- 时间复杂度：O(n)，每个字符被访问一次。
- 空间复杂度：O(n)，递归调用栈的深度取决于嵌套层数。

**方法三（栈优化）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 图解示例

以 `expression = "!(&(f,t))"` 为例：

```
步骤1：遍历字符
'!' -> 入栈: ['!']
'(' -> 跳过逗号和左括号
'&' -> 入栈: ['!', '&']
'(' -> 跳过
'f' -> 入栈: ['!', '&', 'f']
't' -> 入栈: ['!', '&', 'f', 't']

步骤2：遇到第一个 ')'
收集值: ['t', 'f']
弹出 '('
获取运算符: '&'
计算: all(['f', 't']) -> 'f'
入栈: ['!', 'f']

步骤3：遇到第二个 ')'
收集值: ['f']
弹出 '('
获取运算符: '!'
计算: not 'f' -> 't'
入栈: ['t']

最终结果：true
```

## 关键点总结

1. **栈的使用**：栈是处理嵌套结构的理想数据结构，后进先出的特性完美匹配括号的嵌套关系
2. **遇到右括号时计算**：这是关键时机，此时一个完整的子表达式已经准备好
3. **运算符的处理**：
   - `&` 运算可以提前终止（遇到 false 就确定结果）
   - `|` 运算可以提前终止（遇到 true 就确定结果）
   - `!` 运算只有一个操作数
4. **字符映射**：可以直接用字符 't'/'f' 或布尔值 True/False，两种方式都可行
5. **逗号的处理**：逗号只是分隔符，可以直接跳过

## 易错点

1. **忘记跳过逗号**：逗号不参与计算，需要在遍历时跳过或在栈操作时忽略
2. **运算符和左括号的顺序**：运算符在左括号之前，需要先弹出左括号再弹出运算符
3. **NOT 运算的操作数**：NOT 只有一个操作数，而 AND 和 OR 可以有多个
4. **栈的最终状态**：正确的表达式计算完后栈中应该只剩一个元素
5. **字符类型混淆**：如果使用字符 't'/'f'，要注意与布尔值的转换
