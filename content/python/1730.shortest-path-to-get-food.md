## 题目描述

你现在很饿，想尽快找些东西吃。

你需要找出在给定网格中最短的找食物路径的长度。

网格中的格子有以下三种类型：
- `'*'` 表示你的位置（只有一个）
- `'#'` 表示不可通行的格子
- `'O'` 表示空格
- `'X'` 表示食物（可能有多个）

你每次移动可以走上下左右四个方向的格子。返回从 `'*'` 位置到任意 `'X'` 的最短路径长度，若不可达则返回 `-1`。

**示例 1：**
```
输入：grid = [["X","X","X","X","X","X"],["X","*","O","O","O","X"],["X","O","O","#","O","X"],["X","O","O","O","O","X"],["X","X","X","X","X","X"]]
输出：3
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`

## 解题思路

经典的 BFS 最短路问题。从起点 `'*'` 出发，BFS 搜索，遇到 `'X'` 即返回当前步数。

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # 找起点
        start = None
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '*':
                    start = (i, j)
                    break
            if start:
                break
        
        # BFS
        queue = deque([(start[0], start[1], 0)])
        visited = set()
        visited.add(start)
        
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        
        while queue:
            r, c, steps = queue.popleft()
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and (nr, nc) not in visited:
                    if grid[nr][nc] == 'X':
                        return steps + 1
                    if grid[nr][nc] != '#':
                        visited.add((nr, nc))
                        queue.append((nr, nc, steps + 1))
        
        return -1
```

### 方法二：使用修改标记代替 visited 集合

```python
from typing import List
from collections import deque

class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        
        start = None
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '*':
                    start = (i, j)
        
        queue = deque([(*start, 0)])
        # 用修改原格子的方式标记已访问
        grid[start[0]][start[1]] = '#'
        
        for r, c, steps in queue:
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    if grid[nr][nc] == 'X':
                        return steps + 1
                    if grid[nr][nc] == 'O' or grid[nr][nc] == '*':
                        grid[nr][nc] = '#'
                        queue.append((nr, nc, steps + 1))
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(m * n)，最坏情况下遍历所有格子
- **空间复杂度**：O(m * n)，队列和访问集合

## 关键点总结

1. 标准 BFS 求最短路
2. 遇到食物 `'X'` 立即返回当前步数
3. 避免重复访问

## 易错点

- 不能走 `'#'` 格
- 注意边界检查
