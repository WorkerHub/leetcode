## 题目描述

给你一个字符串 `s`，请你找出一个**最多个数**的子字符串集合，满足以下条件：
1. 子字符串互不重叠
2. 字符 `c` 在 `s` 中出现的每一个位置，必须都属于某一个子字符串（或者 `c` 不在任何选出的子字符串中）
3. 若子字符串包含字符 `c`，则 `c` 的所有出现位置都在该子字符串中

返回满足条件的最多个数的子字符串列表（**如果有多个解，返回总长度最小的那个**）。

**示例 1：**
```
输入：s = "adefaddaccc"
输出：["e","f","ccc"]
```

**示例 2：**
```
输入：s = "abbaccd"
输出：["d","bb","cc"]
```

## 解题思路

### 贪心策略

1. **预处理：** 对每个字符 `c`，找到其在 `s` 中的最左出现位置 `left[c]` 和最右出现位置 `right[c]`。

2. **扩展区间：** 对区间 `[left[c], right[c]]`，内部可能包含其他字符，需要将区间扩展直到稳定（包含所有内部字符的所有出现位置）。

3. **贪心选取：** 按区间右端点排序，用贪心（类似区间调度）选取不重叠的区间，同时跳过"内部包含 `left[c]` 在当前位置之前出现"的字符（那些字符的区间无法独立被包含）。

## 代码实现

### 方法一：预处理 + 贪心（推荐）

```python
from typing import List

class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        n = len(s)
        # 记录每个字符的最左和最右出现位置
        left = {}
        right = {}
        for i, c in enumerate(s):
            if c not in left:
                left[c] = i
            right[c] = i

        def get_right(c: str) -> int:
            """获取包含字符 c 所有出现位置的区间右端点（可能需要扩展）"""
            r = right[c]
            i = left[c]
            while i <= r:
                # 如果区间内有字符 d，需要扩展到 right[d]
                r = max(r, right[s[i]])
                i += 1
            return r

        # 收集有效区间（排除那些左端点不是该字符第一次出现的）
        intervals = []
        for c in set(s):
            r = get_right(c)
            # 只有当 left[c] 是区间内某字符的最左出现时才考虑
            intervals.append((r, left[c], c))

        # 按右端点排序，贪心选取不重叠的区间
        intervals.sort()
        ans = []
        last_right = -1
        for r, l, c in intervals:
            # 跳过左端点在已选区间内的区间
            if l > last_right:
                ans.append(s[l:r+1])
                last_right = r
        return ans
```

### 方法二：详细注释版本

```python
from typing import List

class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        n = len(s)
        # 初始化每个字符的左右边界
        char_left = [n] * 26
        char_right = [-1] * 26
        for i, c in enumerate(s):
            idx = ord(c) - ord('a')
            char_left[idx] = min(char_left[idx], i)
            char_right[idx] = max(char_right[idx], i)

        def expand_right(char_idx: int) -> int:
            """扩展右边界，直到稳定"""
            r = char_right[char_idx]
            l = char_left[char_idx]
            i = l
            while i <= r:
                ci = ord(s[i]) - ord('a')
                if char_right[ci] > r:
                    r = char_right[ci]
                i += 1
            return r

        # 构建候选区间，按右端点排序
        candidates = []
        for ci in range(26):
            if char_right[ci] == -1:
                continue  # 字符不存在
            r = expand_right(ci)
            candidates.append((r, char_left[ci]))

        candidates.sort()

        ans = []
        prev_right = -1
        for r, l in candidates:
            if l > prev_right:
                ans.append(s[l:r+1])
                prev_right = r

        return ans
```

## 复杂度分析

- **时间复杂度**：O(26 * N) = O(N)，每个字符最多扩展 N 步
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 每个字符对应一个区间 `[left[c], right[c]]`，但需要扩展到包含内部所有字符
2. 区间扩展：扫描区间内部，把所有字符的右边界纳入
3. 贪心按右端点排序，跳过左端点在已选区间内的区间

## 易错点

- 区间扩展时要迭代到稳定，不能只扩展一层
- 贪心条件是 `l > last_right`（左端点严格大于上一个区间的右端点）
