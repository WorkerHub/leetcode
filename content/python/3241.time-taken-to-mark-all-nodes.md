## 题目描述

给你一棵 `n` 个节点（编号 0 到 n-1）的无向树，以及一个整数数组 `edges`。

标记规则：
- 若节点编号为奇数，被标记后 1 秒后标记所有邻居
- 若节点编号为偶数，被标记后 2 秒后标记所有邻居

初始时只有节点 `i` 被标记，随时间传播。

返回数组 `ans`，其中 `ans[i]` 表示从节点 `i` 开始，标记**所有节点**所需的时间。

**提示：**
- `2 <= n <= 10^5`
- `edges.length == n - 1`

## 解题思路

对每个起始节点 `i`，需要计算从 `i` 出发标记所有节点的时间。

朴素做法：对每个起点做 BFS/DFS，时间 O(n^2)。

优化：换根 DP。

先以 0 为根计算，然后换根：当从节点 `i` 换到子节点 `j` 作为根时，`j` 的答案可以从 `i` 的答案推导。

## Python 代码实现

### 方法一：换根 DP（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def timeTaken(self, edges: List[List[int]]) -> List[int]:
        n = len(edges) + 1
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # 从节点 v 到达 u 需要的时间（v是偶数+2，奇数+1）
        def edge_time(v):
            return 2 if v % 2 == 0 else 1
        
        # 第一步：以 0 为根，计算每个节点子树的最大时间
        # dp_down[v] = 从 v 出发向下到子树中最远节点所需时间
        dp_down = [0] * n
        order = []  # 拓扑顺序（BFS）
        parent = [-1] * n
        visited = [False] * n
        
        from collections import deque
        q = deque([0])
        visited[0] = True
        while q:
            u = q.popleft()
            order.append(u)
            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    parent[v] = u
                    q.append(v)
        
        # 逆序计算 dp_down
        for u in reversed(order):
            for v in graph[u]:
                if v != parent[u]:
                    # v 是 u 的子节点
                    dp_down[u] = max(dp_down[u], dp_down[v] + edge_time(u))
        
        # 第二步：换根，计算 dp_up[v]（从 v 向上的最大时间）
        # ans[v] = max(dp_down[v], dp_up[v])
        dp_up = [0] * n
        ans = [0] * n
        ans[0] = dp_down[0]
        
        for u in order:
            # 找到 u 的子节点中 dp_down 最大和次大的
            children_vals = []
            for v in graph[u]:
                if v != parent[u]:
                    children_vals.append((dp_down[v] + edge_time(u), v))
            children_vals.sort(reverse=True)
            
            for v in graph[u]:
                if v != parent[u]:
                    # 从 v 换根后，v 的 dp_up
                    # dp_up[v] = max(dp_up[u], 选 u 子节点中排除 v 的最大值) + edge_time(v)
                    # u 这边的贡献：max(dp_up[u], 除 v 外的最大子树时间) + edge_time(v)
                    
                    # u 向上的最大时间
                    up_val = dp_up[u]
                    
                    # u 向下（除 v 方向）的最大时间
                    cur_v_time = dp_down[v] + edge_time(u)
                    if children_vals and children_vals[0][1] == v:
                        # v 贡献最大，选次大
                        down_val = children_vals[1][0] if len(children_vals) > 1 else 0
                    else:
                        down_val = children_vals[0][0] if children_vals else 0
                    
                    dp_up[v] = max(up_val, down_val) + edge_time(v)
                    ans[v] = max(dp_down[v], dp_up[v])
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，每个节点排序子节点
- 空间复杂度：O(n)

## 关键点总结

1. 换根 DP：先以任意节点为根计算向下的最大时间，再传递"向上"的信息
2. 边的权重取决于出发节点的奇偶性
3. 换根时需要找排除某个子节点后的最大值，用排序前两名解决

## 易错点

1. 边的时间取决于从哪个方向出发（节点的奇偶性）
2. 换根时要正确排除目标子节点的贡献
