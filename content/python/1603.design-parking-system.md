## 题目描述

请你给一个停车场设计一个停车系统。停车场总共有三种不同大小的车位：大、中和小，每种尺寸分别有固定数量的车位。

实现 `ParkingSystem` 类：
- `ParkingSystem(int big, int medium, int small)` 初始化 `ParkingSystem` 类，三个参数分别对应每种停车位的数量。
- `bool addCar(int carType)` 检查是否有 `carType` 对应的停车位。`carType` 有三种类型：大车为 `1`，中车为 `2`，小车为 `3`。**一辆车只能停在与它大小相同**的停车位中。如果没有空车位，返回 `false`，否则将该车停入车位并返回 `true`。

**示例：**
```
输入：["ParkingSystem", "addCar", "addCar", "addCar", "addCar"]
      [[1, 1, 0], [1], [2], [3], [1]]
输出：[null, true, true, false, false]
解释：
- 初始化：大车位 1，中车位 1，小车位 0
- addCar(1)：大车，有空位，返回 true，大车位剩 0
- addCar(2)：中车，有空位，返回 true，中车位剩 0
- addCar(3)：小车，无小车位，返回 false
- addCar(1)：大车，大车位已满，返回 false
```

**提示：**
- `0 <= big, medium, small <= 1000`
- `carType` 只有 `1`、`2`、`3`
- 最多调用 `addCar` 1000 次

## 解题思路

简单的计数器设计题。用一个数组或字典存储每种车位的剩余数量，每次调用 `addCar` 时检查对应类型的剩余数量即可。

## 代码实现

### 方法一：数组存储（推荐）

```python
class ParkingSystem:

    def __init__(self, big: int, medium: int, small: int):
        # 用列表存储三种车位数量，索引 0 不用，1=大，2=中，3=小
        self.spaces = [0, big, medium, small]

    def addCar(self, carType: int) -> bool:
        # 检查对应车位是否还有剩余
        if self.spaces[carType] > 0:
            self.spaces[carType] -= 1
            return True
        return False
```

### 方法二：字典存储

```python
class ParkingSystem:

    def __init__(self, big: int, medium: int, small: int):
        # 用字典存储各类型车位剩余数量
        self.spaces = {1: big, 2: medium, 3: small}

    def addCar(self, carType: int) -> bool:
        if self.spaces[carType] > 0:
            self.spaces[carType] -= 1
            return True
        return False
```

### 方法三：位运算压缩（进阶）

```python
class ParkingSystem:

    def __init__(self, big: int, medium: int, small: int):
        # 将三个数压缩到一个整数中（每种最多 1000，需要 10 位）
        # big 在高位，medium 在中位，small 在低位
        self.state = (big << 20) | (medium << 10) | small
        self.mask = (1 << 10) - 1  # 低 10 位掩码

    def addCar(self, carType: int) -> bool:
        shift = (3 - carType) * 10  # carType=1 -> shift=20, 2->10, 3->0
        count = (self.state >> shift) & self.mask
        if count > 0:
            self.state -= (1 << shift)
            return True
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数组存储 | O(1) | O(1) |
| 字典存储 | O(1) | O(1) |
| 位运算 | O(1) | O(1) |

## 关键点总结

1. 只需维护三种车位的剩余数量
2. 每次 `addCar` 只需 O(1) 时间
3. 数组下标直接对应车辆类型（1、2、3），避免额外映射
4. 方法一最简洁，推荐使用

## 易错点

- 忘记在有空位时将对应数量减 1
- 方法一中索引 0 不使用，需要初始化为 `[0, big, medium, small]`
- 注意 `carType` 是 1、2、3，不是 0 开头
