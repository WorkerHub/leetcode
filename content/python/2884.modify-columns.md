## 题目描述

给定一个 DataFrame `employees`，将 `salary` 列的所有值翻倍。

**示例：**
```
输入：salary 列包含原始薪资

输出：salary 列所有值 × 2
```

## Python 代码实现

### 方法一：直接列运算（推荐）

```python
import pandas as pd

def modifySalaryColumn(employees: pd.DataFrame) -> pd.DataFrame:
    employees['salary'] = employees['salary'] * 2
    return employees
```

### 方法二：apply 方法

```python
import pandas as pd

def modifySalaryColumn(employees: pd.DataFrame) -> pd.DataFrame:
    employees['salary'] = employees['salary'].apply(lambda x: x * 2)
    return employees
```

### 方法三：就地修改

```python
import pandas as pd

def modifySalaryColumn(employees: pd.DataFrame) -> pd.DataFrame:
    employees['salary'] *= 2
    return employees
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（就地修改）

## 关键点总结

1. `df['col'] *= 2` 就地翻倍，最简洁
2. 向量化操作（不要用循环）
3. `apply` 函数灵活但性能稍差于向量化操作
