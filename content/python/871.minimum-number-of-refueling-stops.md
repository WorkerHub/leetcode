## 题目描述

汽车从起点出发驶向目的地，该目的地位于出发位置东面 target 英里处。

沿途有加油站，用数组 stations 表示。其中 stations[i] = [positioni, fueli] 表示第 i 个加油站位于出发位置东面 positioni 英里处，并且有 fueli 升汽油。

假设汽车油箱的容量是无限的，其中最初有 startFuel 升燃料。它每行驶 1 英里就会用掉 1 升汽油。当汽车到达加油站时，它可能停下来加油，将所有汽油从加油站转移到汽车中。

为了到达目的地，汽车所必要的最低加油次数是多少？如果无法到达目的地，则返回 -1 。

**示例 1：**
```
输入：target = 1, startFuel = 1, stations = []
输出：0
解释：可以在不加油的情况下到达目的地。
```

**示例 2：**
```
输入：target = 100, startFuel = 1, stations = [[10,100]]
输出：-1
解释：无法抵达目的地，甚至无法到达第一个加油站。
```

**示例 3：**
```
输入：target = 100, startFuel = 10, stations = [[10,60],[20,30],[30,30],[60,40]]
输出：2
解释：
出发时有 10 升燃料。
开车来到距起点 10 英里处的加油站，消耗 10 升燃料。将汽油从 0 升加到 60 升。
然后，从 10 英里处的加油站开车前往 60 英里处的加油站（消耗 50 升燃料），
并将汽油从 10 升加到 50 升。然后开车抵达目的地。
总共加油 2 次，所以返回 2 。
```

**提示：**
- 1 <= target, startFuel <= 10^9
- 0 <= stations.length <= 500
- 1 <= positioni < positioni+1 < target
- 1 <= fueli < 10^9

## 解题思路

### 方法一思路：贪心 + 最大堆

**核心思想：**
- 尽可能少加油，每次加油选择之前经过的油量最大的加油站

**算法流程：**
1. 用最大堆存储经过但未加油的加油站
2. 模拟行驶过程
3. 当油不够时，选择堆中油量最大的站加油
4. 记录加油次数

## Python 代码实现

### 方法一：贪心 + 堆（推荐）⭐

```python
class Solution:
    def minRefuelStops(self, target: int, startFuel: int, stations: List[List[int]]) -> int:
        import heapq
        
        heap = []  # 最大堆（存储负值）
        fuel = startFuel
        pos = 0
        count = 0
        i = 0
        
        while fuel < target:
            # 将所有能到达的加油站加入堆
            while i < len(stations) and stations[i][0] <= fuel:
                heapq.heappush(heap, -stations[i][1])  # 负值实现最大堆
                i += 1
            
            # 如果没有可用的加油站
            if not heap:
                return -1
            
            # 选择油量最大的加油站
            fuel += -heapq.heappop(heap)
            count += 1
        
        return count
```

### 方法二：动态规划

```python
class Solution:
    def minRefuelStops(self, target: int, startFuel: int, stations: List[List[int]]) -> int:
        # dp[i] 表示加 i 次油能到达的最远距离
        dp = [startFuel] + [0] * len(stations)
        
        for i, (pos, fuel) in enumerate(stations):
            # 从后往前更新，避免重复使用
            for j in range(i, -1, -1):
                if dp[j] >= pos:
                    dp[j + 1] = max(dp[j + 1], dp[j] + fuel)
        
        # 找到最少加油次数
        for i, dist in enumerate(dp):
            if dist >= target:
                return i
        
        return -1
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n log n)，堆操作
- **空间复杂度**：O(n)

### 方法二：
- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：需要加油时，选择之前经过的油量最大的站
2. **最大堆**：动态维护可用的加油站
3. **DP 状态**：`dp[i]` 表示加 i 次油的最远距离
4. **模拟过程**：按顺序处理每个加油站

## 易错点

1. **堆的使用**：Python heapq 是最小堆，用负值实现最大堆
2. **DP 更新顺序**：必须从后往前，避免重复使用同一个站
3. **边界条件**：startFuel 就能到达目标
