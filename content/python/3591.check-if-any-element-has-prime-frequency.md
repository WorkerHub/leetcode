## 题目描述

给定一个整数数组 `nums`。如果数组中存在某个元素，其出现频次是质数，则返回 `true`，否则返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1,2,1]
输出：true
解释：1 出现 3 次（质数），2 出现 2 次（质数）。
```

**示例 2：**

```
输入：nums = [1,1,1,1]
输出：false
解释：1 出现 4 次，不是质数。
```

**提示：**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`

## 解题思路

步骤：
1. 统计每个元素的出现频次（使用 Counter）
2. 对每个频次，判断是否为质数
3. 若有任意一个频次是质数，返回 True

判断质数：对于正整数 n，若 n < 2 则非质数，否则枚举 2 到 sqrt(n) 判断是否有因子。

由于频次最大为 1000，直接判断即可。

## Python 代码实现

### 方法一：Counter + 质数判断（推荐）

```python
from typing import List
from collections import Counter

class Solution:
    def checkPrimeFrequency(self, nums: List[int]) -> bool:
        def is_prime(n: int) -> bool:
            if n < 2:
                return False
            if n == 2:
                return True
            if n % 2 == 0:
                return False
            i = 3
            while i * i <= n:
                if n % i == 0:
                    return False
                i += 2
            return True

        # 统计频次
        freq = Counter(nums)
        # 检查是否有质数频次
        return any(is_prime(cnt) for cnt in freq.values())
```

### 方法二：预筛质数

```python
from typing import List
from collections import Counter

class Solution:
    def checkPrimeFrequency(self, nums: List[int]) -> bool:
        # 预先筛质数，频次最大为 len(nums) <= 1000
        MAX_FREQ = len(nums) + 1
        is_prime = [True] * (MAX_FREQ + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(MAX_FREQ**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, MAX_FREQ + 1, i):
                    is_prime[j] = False

        freq = Counter(nums)
        return any(is_prime[cnt] for cnt in freq.values())
```

## 复杂度分析

- 时间复杂度：O(n + sqrt(max_freq))，Counter O(n)，质数判断 O(sqrt(max_freq))
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 用 Counter 统计每个元素频次
2. 对频次逐一判断是否为质数
3. 质数判断：枚举到 sqrt(n) 即可

## 易错点

1. 频次为 1 不是质数，不要漏判
2. 质数从 2 开始，2 本身是质数
3. 只需要有一个质数频次就返回 True
