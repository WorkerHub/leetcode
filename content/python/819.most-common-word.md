## 题目描述

给定一个段落 `paragraph` 和一个禁用单词列表 `banned`。返回出现次数最多的非禁用单词。

题目保证至少有一个非禁用单词，且答案唯一。

段落中的单词 **不区分大小写**，答案应以 **小写** 形式返回。

**示例:**
```
输入: paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
输出: "ball"
解释: 
"hit" 出现了 3 次，但它是禁用词。
"ball" 出现了 2 次（同时没有其他单词出现 2 次），所以它是段落中出现次数最多的，且不在禁用列表中的单词。
注意，段落中的单词不区分大小写，标点符号被忽略，"hit" 不在答案中，因为它是被禁用的词。
```

**提示:**
- `1 <= paragraph.length <= 1000`
- `paragraph` 由小写英文字母、空格和符号 `!?',;.` 组成
- `0 <= banned.length <= 100`
- `1 <= banned[i].length <= 10`
- `banned[i]` 仅由小写英文字母组成

## 解题思路

1. 将段落转为小写，提取所有单词
2. 统计非禁用单词的频率
3. 返回频率最高的单词

## Python 代码实现

### 方法一：正则表达式 + Counter（推荐）⭐

```python
from typing import List
from collections import Counter
import re

class Solution:
    def mostCommonWord(self, paragraph: str, banned: List[str]) -> str:
        # 提取所有单词（转为小写）
        words = re.findall(r'\w+', paragraph.lower())
        
        # 禁用词集合
        banned_set = set(banned)
        
        # 统计非禁用词频率
        count = Counter(word for word in words if word not in banned_set)
        
        # 返回频率最高的词
        return count.most_common(1)[0][0]
```

### 方法二：手动处理

```python
from typing import List
from collections import Counter

class Solution:
    def mostCommonWord(self, paragraph: str, banned: List[str]) -> str:
        # 转小写，替换标点为空格
        for char in "!?',;.":
            paragraph = paragraph.replace(char, " ")
        
        # 分割单词
        words = paragraph.lower().split()
        
        # 禁用词集合
        banned_set = set(banned)
        
        # 统计频率
        count = {}
        for word in words:
            if word not in banned_set:
                count[word] = count.get(word, 0) + 1
        
        # 找最大频率的词
        return max(count, key=count.get)
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 是段落长度，m 是禁用词长度
- **空间复杂度**：O(n)

## 关键点总结

1. **正则表达式**：`\w+` 匹配单词
2. **大小写转换**：统一转为小写
3. **集合查找**：禁用词用 set 存储
4. **Counter工具**：简化频率统计

## 易错点

1. **大小写**：必须转为小写
2. **标点符号**：需要正确处理
3. **禁用词检查**：不要统计禁用词
