## 题目描述

给你一个整数数组 `arr`，请你删除最小 `5%` 的数字和最大 `5%` 的数字后，剩余数字的平均值。

与**标准答案**误差在 `10^-5` 之内的答案都被视为正确答案。

**示例：**
```
输入：arr = [1,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,3]
输出：2.00000
```

**提示：**
- `20 <= arr.length <= 1000`
- `arr.length` 是 `20` 的倍数
- `0 <= arr[i] <= 10^5`

## 解题思路

1. 对数组排序
2. 计算要删除的元素数量：`remove = len(arr) * 5 // 100 = len(arr) // 20`
3. 对排序后的数组，跳过前 `remove` 个和后 `remove` 个元素，对中间部分求平均值

由于 `arr.length` 是 20 的倍数，5% 一定是整数。

## 代码实现

### 方法一：排序后切片（推荐）

```python
from typing import List

class Solution:
    def trimMean(self, arr: List[int]) -> float:
        arr.sort()
        n = len(arr)
        remove = n // 20  # 5% 的数量
        # 取中间部分
        trimmed = arr[remove: n - remove]
        return sum(trimmed) / len(trimmed)
```

### 方法二：内置函数精简写法

```python
from typing import List

class Solution:
    def trimMean(self, arr: List[int]) -> float:
        arr.sort()
        k = len(arr) // 20  # 去除的数量（5%）
        # 直接对中间部分求均值
        return sum(arr[k: len(arr) - k]) / (len(arr) - 2 * k)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序切片 | O(n log n) | O(n)（切片） |
| 精简写法 | O(n log n) | O(1) |

## 关键点总结

1. 5% 即 `n // 20`（题目保证 n 是 20 的倍数，结果为整数）
2. 排序后取 `arr[k: n-k]` 的均值
3. 注意返回浮点数，不是整数

## 易错点

- 去掉的是最小 5% 和最大 5%，共 10%，保留 90%
- 平均值计算：`sum / (n - 2*k)`，分母是保留元素的个数
