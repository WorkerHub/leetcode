## 题目描述

对于任何字符串，我们可以通过删除其中一些字符（也可能不删除）来构造该字符串的子序列。

给定源字符串 `source` 和目标字符串 `target`，返回源字符串 `source` 中能通过串联形成目标字符串 `target` 的子序列的最小数量。如果无法通过串联源字符串中的子序列来构造目标字符串，则返回 `-1`。

**示例 1：**
```
输入：source = "abc", target = "abcbc"
输出：2
解释：目标字符串 "abcbc" 可以由 "abc" 和 "bc" 形成，它们都是源字符串 "abc" 的子序列。
```

**示例 2：**
```
输入：source = "abc", target = "acdbc"
输出：-1
解释：由于目标字符串中包含字符 "d"，无法由源字符串的子序列构成。
```

**示例 3：**
```
输入：source = "xyz", target = "xzyxz"
输出：3
解释：目标字符串可以按如下方式构造： "xz" + "y" + "xz"。
```

**提示：**
- `1 <= source.length, target.length <= 1000`
- `source` 和 `target` 仅包含英文小写字母。

## 解题思路

这道题的核心是**贪心 + 双指针**：
- 每次尽可能多地从 `source` 中匹配 `target` 的字符
- 当 `source` 遍历完一遍后，如果 `target` 还没匹配完，就需要再用一次 `source`

**算法流程：**
1. 检查 `target` 中是否有 `source` 中不存在的字符，如果有返回 `-1`
2. 使用双指针，`i` 指向 `target`，`j` 指向 `source`
3. 每次尽可能多地匹配字符
4. 当 `source` 遍历完一轮，计数器加 1，`j` 重置为 0
5. 如果一轮都没匹配到任何字符，说明当前字符不存在，返回 `-1`

## Python 代码实现

### 方法一：贪心 + 双指针（推荐）

```python
class Solution:
    def shortestWay(self, source: str, target: str) -> int:
        """
        时间复杂度：O(m * n)，最坏情况下需要 m 次遍历 source
        空间复杂度：O(1)
        """
        # 检查 target 中的字符是否都在 source 中
        source_set = set(source)
        for char in target:
            if char not in source_set:
                return -1
        
        count = 0  # 需要的子序列数量
        i = 0  # target 的指针
        
        while i < len(target):
            j = 0  # source 的指针
            prev_i = i  # 记录本轮开始前的位置
            
            # 尽可能多地匹配字符
            while i < len(target) and j < len(source):
                if target[i] == source[j]:
                    i += 1
                j += 1
            
            # 一轮完成，计数加 1
            count += 1
            
            # 如果本轮没有匹配到任何字符（理论上不会发生，因为已检查）
            if i == prev_i:
                return -1
        
        return count
```

### 方法二：预处理 + 二分查找（优化）

```python
from collections import defaultdict
import bisect

class Solution:
    def shortestWay(self, source: str, target: str) -> int:
        """
        预处理 source 中每个字符的位置，使用二分查找
        时间复杂度：O(m + n log m)
        空间复杂度：O(m)
        """
        # 预处理：记录 source 中每个字符的所有位置
        char_positions = defaultdict(list)
        for i, char in enumerate(source):
            char_positions[char].append(i)
        
        count = 1  # 至少需要一次
        source_idx = 0  # source 的当前位置
        
        for char in target:
            # 字符不存在
            if char not in char_positions:
                return -1
            
            # 在当前位置之后查找字符
            positions = char_positions[char]
            idx = bisect.bisect_left(positions, source_idx)
            
            # 如果当前轮找不到，需要开始新的一轮
            if idx == len(positions):
                count += 1
                source_idx = positions[0] + 1
            else:
                source_idx = positions[idx] + 1
        
        return count
```

### 方法三：简化双指针

```python
class Solution:
    def shortestWay(self, source: str, target: str) -> int:
        """
        更简洁的双指针实现
        """
        source_chars = set(source)
        
        count = 0
        i = 0
        
        while i < len(target):
            # 检查字符是否存在
            if target[i] not in source_chars:
                return -1
            
            # 当前轮匹配
            matched = False
            for char in source:
                if i < len(target) and char == target[i]:
                    i += 1
                    matched = True
            
            # 如果一轮都没匹配到，说明有问题（理论上不会发生）
            if not matched:
                return -1
            
            count += 1
        
        return count
```

## 复杂度分析

**方法一：贪心 + 双指针**
- 时间复杂度：O(m × n)，最坏情况下 target 的每个字符都需要遍历 source
- 空间复杂度：O(|Σ|) = O(26) = O(1)，用于存储字符集合

**方法二：预处理 + 二分查找**
- 时间复杂度：O(m + n log m)，预处理 O(m)，每次二分查找 O(log m)
- 空间复杂度：O(m)，存储字符位置

## 关键点总结

1. **贪心策略**：每次尽可能多地从 `source` 中匹配字符
2. **字符检查**：先检查 `target` 中的字符是否都在 `source` 中
3. **双指针**：一个指针遍历 `target`，一个指针遍历 `source`
4. **优化方法**：预处理字符位置，使用二分查找加速

## 易错点

1. **字符不存在**：必须先检查 `target` 中是否有 `source` 中不存在的字符
2. **循环条件**：注意 `while` 循环的终止条件，避免无限循环
3. **计数时机**：每完成一轮 `source` 的遍历就计数加 1
4. **重置指针**：每轮结束后要重置 `source` 的指针
