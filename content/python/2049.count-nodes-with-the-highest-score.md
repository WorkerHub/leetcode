## 题目描述

给你一棵由 `n` 个节点组成的二叉树，节点编号从 0 到 `n-1`。`parents` 数组中 `parents[i]` 是节点 `i` 的父节点（`parents[0] == -1` 为根节点）。

**删除**节点 `x` 的分数计算方式：
- 将 `x` 删除后，树分裂为最多三个部分（左子树、右子树、x 的祖先部分）
- 分数 = 各非空部分节点数的乘积

返回分数**最高**的节点数目。

**示例 1：**
```
输入：parents = [-1,2,0,2,0]
输出：3
解释：删除节点 2 后，三部分大小为 2*1*2=4，是最高分
```

**提示：**
- `n == parents.length`
- `2 <= n <= 10^5`
- `0 <= parents[i] <= n - 1`（i != 0）
- `parents[0] == -1`

## 解题思路

对每个节点 `x`：
1. 左子树大小：`left[x]`
2. 右子树大小：`right[x]`
3. 祖先部分大小：`n - 1 - left[x] - right[x]`（总节点数减去以 x 为根的子树节点数）
4. 分数 = 三部分中非零部分的乘积

## 代码实现

### 方法一：DFS 求子树大小 + 枚举（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countHighestScoreNodes(self, parents: List[int]) -> int:
        n = len(parents)
        children = defaultdict(list)
        for i in range(1, n):
            children[parents[i]].append(i)

        subtree_size = [1] * n  # 子树节点数

        # DFS 计算子树大小（迭代后序遍历）
        order = []
        stack = [0]
        while stack:
            node = stack.pop()
            order.append(node)
            for child in children[node]:
                stack.append(child)

        for node in reversed(order):  # 后序：先处理叶子
            for child in children[node]:
                subtree_size[node] += subtree_size[child]

        # 计算每个节点的分数
        max_score = 0
        max_count = 0

        for x in range(n):
            score = 1
            remaining = n - 1  # 删除 x 后其他节点数

            for child in children[x]:
                sz = subtree_size[child]
                score *= sz
                remaining -= sz

            if remaining > 0:
                score *= remaining  # 祖先部分

            if score > max_score:
                max_score = score
                max_count = 1
            elif score == max_score:
                max_count += 1

        return max_count
```

### 方法二：递归 DFS

```python
from typing import List
from collections import defaultdict
import sys

sys.setrecursionlimit(200000)

class Solution:
    def countHighestScoreNodes(self, parents: List[int]) -> int:
        n = len(parents)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)

        subtree = [0] * n

        def dfs(node: int) -> int:
            size = 1
            for child in children[node]:
                size += dfs(child)
            subtree[node] = size
            return size

        dfs(0)

        max_score = 0
        count = 0

        for x in range(n):
            score = 1
            left_sz = subtree[children[x][0]] if len(children[x]) >= 1 else 0
            right_sz = subtree[children[x][1]] if len(children[x]) >= 2 else 0
            ancestor_sz = n - subtree[x]

            if left_sz > 0:
                score *= left_sz
            if right_sz > 0:
                score *= right_sz
            if ancestor_sz > 0:
                score *= ancestor_sz

            if score > max_score:
                max_score = score
                count = 1
            elif score == max_score:
                count += 1

        return count
```

## 复杂度分析

- 时间复杂度：O(n)，DFS + 枚举
- 空间复杂度：O(n)，子树大小数组和邻接表

## 关键点总结

1. 三个部分：左子树、右子树、祖先部分
2. 祖先部分大小 = `n - subtree_size[x]`（总节点数减以 x 为根的子树）
3. 零大小的部分不参与乘积计算

## 易错点

- 祖先部分可能为 0（删除根节点时），不参与乘积
- 左右子树可能为空（叶子节点或只有一个子节点）
- 分数可能很大，Python 不需要担心溢出
