## 题目描述

给你一个下标从 **0** 开始的正整数数组 `tasks`，表示需要按顺序完成的任务类型，以及一个正整数 `space`，表示两次执行**相同**类型任务之间所需的最少天数间隔。

返回执行所有任务所需的**最少天数**。

**示例 1：**
```
输入：tasks = [1,2,1,2,3,1], space = 3
输出：9
解释：任务 1 在第 1 天、第 5 天完成（间隔 4 >= 3）；任务 2 在第 2 天、第 6 天；任务 3 在第 7 天。
```

**示例 2：**
```
输入：tasks = [5,8,8,5], space = 2
输出：6
```

**提示：**
- `1 <= tasks.length <= 10^5`
- `1 <= tasks[i] <= 10^9`
- `1 <= space <= tasks.length`

## 解题思路

**贪心模拟：**
按顺序处理任务，对每种任务记录上次完成的天数。若当前天数与上次完成天数之差 < `space + 1`，则需要等待。

维护 `last_done[task_type]` = 该任务类型上次完成的天数，当前天数为 `day`。每个任务在 `max(day, last_done[task_type] + space + 1)` 天完成。

## 代码实现

### 方法一：哈希表模拟（推荐）

```python
from typing import List

class Solution:
    def taskSchedulerII(self, tasks: List[int], space: int) -> int:
        last_done = {}  # task_type -> 上次完成的天数
        day = 0
        
        for task in tasks:
            day += 1  # 至少要到下一天
            if task in last_done:
                # 需要等到 last_done[task] + space + 1 才能再次完成
                earliest = last_done[task] + space + 1
                if day < earliest:
                    day = earliest  # 等待到最早可以做的时候
            last_done[task] = day
        
        return day
```

### 方法二：明确注释版

```python
from typing import List

class Solution:
    def taskSchedulerII(self, tasks: List[int], space: int) -> int:
        # last[t] 表示任务类型 t 上次完成的天数
        last = {}
        day = 0  # 当前天数
        
        for t in tasks:
            day += 1  # 进入下一天
            if t in last:
                # 最早可以做 t 的天数
                min_day = last[t] + space + 1
                if day < min_day:
                    day = min_day  # 跳过等待天数
            last[t] = day
        
        return day
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表模拟 | O(n) | O(k)（k 为不同任务类型数） |

## 关键点总结

1. 按顺序处理任务，每次取 `max(当前天+1, 上次完成+space+1)` 作为当前任务完成天数。
2. 用哈希表记录每种任务的上次完成天数，O(1) 查找。
3. 无需预先知道有哪些任务类型，边处理边记录。

## 易错点

- 天数初始为 0，处理每个任务时先 `day += 1`（至少要过一天）再比较是否需要等待。
- 间隔 `space` 是指两次完成之间至少有 `space` 天不做该任务，即完成间隔 >= `space + 1`。
