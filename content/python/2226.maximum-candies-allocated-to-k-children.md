## 题目描述

给你一个下标从 0 开始的整数数组 `candies`，`candies[i]` 表示第 i 堆糖果的数量，和一个整数 `k`，表示小朋友的数量。

你可以将每堆糖果分成任意数量的**子堆**，但**不能**合并两堆。每位小朋友分配一个子堆，每个子堆至多被分给一个小朋友。

返回每位小朋友能得到糖果的**最大数目**。

**示例 1：**
```
输入：candies = [5,8,6], k = 3
输出：5
解释：将第2堆8分成(5,3)，每人得5。
```

**示例 2：**
```
输入：candies = [2,5], k = 11
输出：0
```

## 解题思路

**二分查找：** 对每人分得的糖果数 `m` 进行二分。

- 若每人 `m` 颗糖，那么每堆 `candies[i]` 能提供 `candies[i] // m` 个子堆。
- 若所有堆提供的子堆总数 >= k，则 `m` 可行。
- 求最大的可行 `m`。

二分范围：`[0, max(candies)]`（或 `sum(candies) // k`）。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def maximumCandies(self, candies: List[int], k: int) -> int:
        # 判断每人分 m 颗糖是否可行
        def feasible(m: int) -> bool:
            if m == 0:
                return True
            # 统计能提供的子堆总数
            return sum(c // m for c in candies) >= k

        # 二分查找最大的可行 m
        left, right = 0, max(candies)
        while left < right:
            mid = (left + right + 1) // 2  # 向上取整
            if feasible(mid):
                left = mid
            else:
                right = mid - 1

        return left
```

### 方法二：更明确的二分边界

```python
from typing import List

class Solution:
    def maximumCandies(self, candies: List[int], k: int) -> int:
        total = sum(candies)
        # 若总糖果数不足 k 个，直接返回 0
        if total < k:
            return 0

        lo, hi = 1, total // k

        while lo < hi:
            mid = (lo + hi + 1) // 2
            # 检查每人分 mid 颗时，能满足多少人
            if sum(c // mid for c in candies) >= k:
                lo = mid
            else:
                hi = mid - 1

        return lo
```

## 复杂度分析

- 时间复杂度：O(n log(max_candy))，二分 O(log(max_candy))，每次检查 O(n)。
- 空间复杂度：O(1)。

## 关键点总结

1. 答案具有单调性：m 越小越容易满足，m 越大越难。
2. 二分查找最大可行的 m，向上取整保证找到最大值。
3. 检查函数：各堆能提供的子堆总数是否 >= k。

## 易错点

- 二分上界是 `max(candies)` 而不是 `sum(candies)`（每人最多得到最大那堆的全部）。
- `(left + right + 1) // 2` 向上取整避免死循环（求最大可行值时使用）。
