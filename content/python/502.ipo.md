## 题目描述

假设力扣（LeetCode）即将开始 IPO。为了以更高的价格将股票卖给风险投资公司，力扣希望在 IPO 之前开展一些项目以增加其资本。

由于资源有限，它只能在 IPO 之前完成最多 `k` 个不同的项目。帮助力扣设计完成最多 `k` 个不同项目后得到最大总资本的方式。

给你 `n` 个项目。对于每个项目 `i`，它都有一个纯利润 `profits[i]`，和启动该项目需要的最小资本 `capital[i]`。

最初，你的资本为 `w`。当你完成一个项目时，你将获得纯利润，且利润将被添加到你的总资本中。

总而言之，从给定项目中选择最多 `k` 个不同项目的列表，以最大化最终资本，并输出最终可获得的最多资本。

答案保证在 32 位有符号整数范围内。

**示例 1：**
```
输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,2]
输出：4
解释：
由于你的初始资本为 0，你仅可以从 0 号项目开始。
在完成后，你将获得 1 的利润，你的总资本将变为 1。
此时你可以选择开始 1 号或 2 号项目。
由于你最多可以选择两个项目，所以你需要完成 2 号项目以获得最大的资本。
因此，输出最后最大化的资本，为 0 + 1 + 3 = 4。
```

**示例 2：**
```
输入：k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
输出：6
```

**提示：**
- `1 <= k <= 10^5`
- `0 <= w <= 10^9`
- `n == profits.length`
- `n == capital.length`
- `1 <= n <= 10^5`
- `0 <= profits[i] <= 10^4`
- `0 <= capital[i] <= 10^9`

## 解题思路

这是一道典型的贪心 + 堆的问题。核心思想是：**在每一步，从所有可以启动的项目中，选择利润最大的项目**。

### 核心观察：
1. 每次做项目都会增加资本，资本只增不减
2. 能做的项目范围会越来越大（因为资本增加）
3. 应该贪心地选择当前能做的项目中利润最大的

### 算法流程：
1. 将所有项目按启动资本从小到大排序
2. 使用最大堆维护当前可以做的项目的利润
3. 重复 k 次：
   - 将所有启动资本 ≤ 当前资本的项目加入最大堆
   - 从堆中取出利润最大的项目
   - 更新资本
4. 返回最终资本

### 为什么是贪心？
- 每次选择当前能做的项目中利润最大的，不会影响后续的选择
- 更高的资本能解锁更多项目，所以贪心策略是最优的

## Python 代码实现

### 方法一：贪心 + 最大堆（推荐）⭐

```python
import heapq
from typing import List

class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: List[int], capital: List[int]) -> int:
        """
        贪心 + 最大堆
        时间复杂度：O(n log n + k log n)
        空间复杂度：O(n)
        """
        n = len(profits)
        
        # 将项目按启动资本排序
        # 每个元素为 (启动资本, 利润)
        projects = sorted(zip(capital, profits))
        
        # Python 的 heapq 是最小堆，存储负数来实现最大堆
        max_heap = []
        
        # 当前项目索引
        i = 0
        
        # 最多做 k 个项目
        for _ in range(k):
            # 将所有当前资本可以启动的项目加入堆
            while i < n and projects[i][0] <= w:
                # 存储负利润，实现最大堆
                heapq.heappush(max_heap, -projects[i][1])
                i += 1
            
            # 如果没有可做的项目，提前结束
            if not max_heap:
                break
            
            # 选择利润最大的项目（堆顶）
            # 由于存的是负数，取反得到真实利润
            w += -heapq.heappop(max_heap)
        
        return w
```

### 方法二：优化版（避免重复排序）

```python
class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: List[int], capital: List[int]) -> int:
        """
        使用索引数组排序，避免创建新列表
        时间复杂度：O(n log n + k log n)
        空间复杂度：O(n)
        """
        n = len(profits)
        
        # 创建索引数组并排序
        indices = list(range(n))
        indices.sort(key=lambda i: capital[i])
        
        max_heap = []
        idx = 0
        
        for _ in range(k):
            # 将所有可启动的项目加入堆
            while idx < n and capital[indices[idx]] <= w:
                heapq.heappush(max_heap, -profits[indices[idx]])
                idx += 1
            
            if not max_heap:
                break
            
            w += -heapq.heappop(max_heap)
        
        return w
```

### 方法三：暴力解法（会超时，仅供理解）

```python
class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: List[int], capital: List[int]) -> int:
        """
        暴力解法：每次遍历所有项目找最优
        时间复杂度：O(k * n)
        空间复杂度：O(n)
        """
        n = len(profits)
        used = [False] * n  # 标记已使用的项目
        
        for _ in range(k):
            max_profit = -1
            max_idx = -1
            
            # 找到当前可做的最大利润项目
            for i in range(n):
                if not used[i] and capital[i] <= w:
                    if profits[i] > max_profit:
                        max_profit = profits[i]
                        max_idx = i
            
            # 没有可做的项目
            if max_idx == -1:
                break
            
            # 做这个项目
            w += profits[max_idx]
            used[max_idx] = True
        
        return w
```

## 复杂度分析

### 方法一（贪心 + 堆）：
- **时间复杂度**：O(n log n + k log n)
  - 排序：O(n log n)
  - k 次循环，每次最多 n 次堆操作，每次 O(log n)
- **空间复杂度**：O(n)，堆的大小最多为 n

### 方法三（暴力）：
- **时间复杂度**：O(k * n)，k 次循环，每次 O(n) 查找
- **空间复杂度**：O(n)，标记数组

## 关键点总结

1. **贪心策略**：每次选择当前能做的项目中利润最大的
2. **排序优化**：按启动资本排序，避免重复查找
3. **堆的使用**：最大堆快速获取最大利润项目
4. **提前终止**：如果没有可做的项目，提前结束循环
5. **Python 最小堆技巧**：存储负数实现最大堆

## 易错点

1. **堆的方向**：Python heapq 是最小堆，需要存负数
2. **边界条件**：k 可能大于项目数量，需要判断堆是否为空
3. **资本更新时机**：做完项目后立即更新资本，影响下一轮选择
4. **排序字段**：要按 capital 排序，不是 profits
5. **重复使用项目**：每个项目只能做一次，但用堆自然避免了这个问题

## 图解示例

以示例 1 为例：`k = 2, w = 0, profits = [1,2,3], capital = [0,1,2]`

```
初始状态：
项目: [(0,1), (1,2), (2,3)]  # (启动资本, 利润)
资本: 0

第 1 轮：
- 可做项目：capital <= 0 → 项目 0
- 堆：[-1]
- 选择：利润 1
- 资本：0 + 1 = 1

第 2 轮：
- 可做项目：capital <= 1 → 项目 0, 1
- 堆：[-2]（项目 0 已用）
- 选择：利润 2
- 资本：1 + 2 = 3

错误做法（选项目 2）：
第 2 轮如果选项目 2：
- capital = 2 > w = 1，无法启动！

正确做法应该先选利润较小但能做的项目。
```
