## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`。

定义 `diff` 矩阵：
- `diff[i][j] = onesRow_i + onesCol_j - zerosRow_i - zerosCol_j`

其中：
- `onesRow_i`：第 `i` 行中 `1` 的个数
- `onesCol_j`：第 `j` 列中 `1` 的个数
- `zerosRow_i`：第 `i` 行中 `0` 的个数
- `zerosCol_j`：第 `j` 列中 `0` 的个数

返回 `diff` 矩阵。

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10^5`
- `1 <= m * n <= 10^5`
- `grid[i][j] 是 0 或 1`

## 解题思路

**前缀和预处理：**

1. 预计算每行的 1 的个数 `row_ones[i]`，从而 `row_zeros[i] = n - row_ones[i]`
2. 预计算每列的 1 的个数 `col_ones[j]`，从而 `col_zeros[j] = m - col_ones[j]`
3. `diff[i][j] = row_ones[i] - (n - row_ones[i]) + col_ones[j] - (m - col_ones[j])`
   `= 2*row_ones[i] + 2*col_ones[j] - n - m`

## 代码实现

### 方法一：预计算行列 1 的个数（推荐）

```python
from typing import List

class Solution:
    def onesMinusZeros(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])

        # 预计算每行 1 的个数
        row_ones = [sum(row) for row in grid]
        # 预计算每列 1 的个数
        col_ones = [sum(grid[i][j] for i in range(m)) for j in range(n)]

        # 构建 diff 矩阵
        diff = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                # onesRow - zerosRow + onesCol - zerosCol
                # = row_ones[i] - (n - row_ones[i]) + col_ones[j] - (m - col_ones[j])
                diff[i][j] = 2 * row_ones[i] + 2 * col_ones[j] - n - m

        return diff
```

### 方法二：使用 numpy 风格的列表推导

```python
from typing import List

class Solution:
    def onesMinusZeros(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        row_ones = [sum(r) for r in grid]
        col_ones = [sum(grid[i][j] for i in range(m)) for j in range(n)]

        return [
            [2 * row_ones[i] + 2 * col_ones[j] - m - n for j in range(n)]
            for i in range(m)
        ]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 预计算 | O(m*n) | O(m+n) |

## 关键点总结

1. `onesRow - zerosRow = 2*onesRow - n`（因为 onesRow + zerosRow = n）
2. 提前统计行列的 1 数，避免 O(m*n*(m+n)) 的暴力
3. 最终公式：`2*row_ones[i] + 2*col_ones[j] - m - n`

## 易错点

- 行和列的 0 个数等于总长减 1 的个数
- 注意 m 和 n 的对应关系：`zerosRow = n - onesRow`，`zerosCol = m - onesCol`
