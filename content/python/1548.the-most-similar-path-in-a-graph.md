## 题目描述

给你 `n` 个城市和 `m` 条双向道路，每个城市有一个名字 `names[i]`。

给你一个目标路径 `targetPath`（城市名序列），找到图中最相似的路径（路径长度等于 `targetPath` 长度），使得对应位置名字不同的数目（编辑距离）最小。

返回最相似路径中的城市编号列表（若有多个，返回任意一个）。

**提示：**
- `2 <= n <= 100`
- `m == roads.length`
- `targetPath.length <= 100`

## 解题思路

### 动态规划

定义 `dp[i][v]` = 走了路径前 `i+1` 步（第 `i` 步在城市 `v`），与 `targetPath[0..i]` 之间的最小不同数。

**状态转移：**
`dp[i][v] = min(dp[i-1][u] + (names[v] != targetPath[i]))` for `u` in `adj[v]`

**回溯路径：** 用 `parent[i][v]` 记录 `dp[i][v]` 的来源节点，最后从最优终点回溯。

## 代码实现

### 方法一：DP + 路径回溯（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def mostSimilar(self, n: int, roads: List[List[int]], names: List[str],
                    targetPath: List[str]) -> List[int]:
        # 建邻接表
        adj = defaultdict(list)
        for u, v in roads:
            adj[u].append(v)
            adj[v].append(u)

        L = len(targetPath)
        INF = float('inf')

        # dp[i][v] = 走到第 i 步，当前在城市 v，最小不同数
        dp = [[INF] * n for _ in range(L)]
        parent = [[-1] * n for _ in range(L)]

        # 初始化第 0 步
        for v in range(n):
            dp[0][v] = 0 if names[v] == targetPath[0] else 1

        # 状态转移
        for i in range(1, L):
            for v in range(n):
                cost = 0 if names[v] == targetPath[i] else 1
                for u in adj[v]:
                    if dp[i-1][u] + cost < dp[i][v]:
                        dp[i][v] = dp[i-1][u] + cost
                        parent[i][v] = u

        # 找最优终点
        end = min(range(n), key=lambda v: dp[L-1][v])

        # 回溯路径
        path = []
        cur = end
        for i in range(L - 1, -1, -1):
            path.append(cur)
            cur = parent[i][cur]
        path.reverse()
        return path
```

### 方法二：使用二维 DP 数组（明确版）

```python
from typing import List

class Solution:
    def mostSimilar(self, n: int, roads: List[List[int]], names: List[str],
                    targetPath: List[str]) -> List[int]:
        from collections import defaultdict
        adj = defaultdict(list)
        for u, v in roads:
            adj[u].append(v)
            adj[v].append(u)

        L = len(targetPath)
        INF = float('inf')
        dp = [[INF] * n for _ in range(L)]
        prev = [[-1] * n for _ in range(L)]

        for v in range(n):
            dp[0][v] = int(names[v] != targetPath[0])

        for step in range(1, L):
            for v in range(n):
                mismatch = int(names[v] != targetPath[step])
                for u in adj[v]:
                    if dp[step-1][u] != INF:
                        val = dp[step-1][u] + mismatch
                        if val < dp[step][v]:
                            dp[step][v] = val
                            prev[step][v] = u

        # 找终点
        best_end = min(range(n), key=lambda v: dp[L-1][v])
        # 回溯
        result = [0] * L
        result[L-1] = best_end
        for i in range(L-2, -1, -1):
            result[i] = prev[i+1][result[i+1]]
        return result
```

## 复杂度分析

- **时间复杂度**：O(L * (N + M))，L 为路径长度，M 为边数
- **空间复杂度**：O(L * N)

## 关键点总结

1. DP 状态定义：`dp[step][v]` = 走到第 step 步，在城市 v，与目标的最小不同数
2. 转移时枚举前驱节点（邻居 u），取最小值
3. 用 `parent` 数组回溯实际路径

## 易错点

- 路径要回溯得到具体节点序列，注意 `parent` 记录的是前驱
- 孤立节点（无邻居）初始化时也需要处理
