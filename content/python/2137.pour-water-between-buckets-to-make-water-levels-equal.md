## 题目描述

给你一个**下标从 0 开始**的整数数组 `buckets`，其中 `buckets[i]` 表示第 `i` 个桶中水的体积。还给你一个整数 `loss`，代表每次向另一个桶转移水时的损耗百分比（0 到 100）。

你可以将一个桶中的水转移到另一个桶中，但每次转移会损耗 `loss%` 的水。

返回所有桶**水位相等**时的**最大水位**（精确到小数点后 5 位）。

**示例：**
```
输入：buckets = [1,2,7], loss = 90
输出：2.00000
解释：90% 损耗时，只能从大桶向小桶转移很少的水。最优是让中等和小桶都升到水位 2。
```

**提示：**
- `1 <= buckets.length <= 10^5`
- `0 <= buckets[i] <= 10^5`
- `0 <= loss <= 99`

## 解题思路

**二分查找答案**

二分目标水位 `mid`：
- 对于水位 > mid 的桶，可以输出 `(buckets[i] - mid)` 的水（转移时会损耗）。
- 对于水位 < mid 的桶，需要补入 `(mid - buckets[i])` 的水。

可行条件：供给（考虑损耗）>= 需求。
- 转移 `x` 单位的水，到达目的地只有 `x * (1 - loss/100)` 单位。
- 供给（有效水量）= `sum(max(0, b - mid)) * (1 - loss/100)`
- 需求 = `sum(max(0, mid - b))`

当供给 >= 需求时，水位 `mid` 可行。

## 代码实现

### 方法一：浮点二分查找（推荐）

```python
from typing import List

class Solution:
    def equalizeWater(self, buckets: List[int], loss: int) -> float:
        # 保留率
        retain = (100 - loss) / 100.0

        def can_equalize(target: float) -> bool:
            supply = 0.0  # 可以转移出去的有效水量（考虑损耗）
            demand = 0.0  # 需要补入的水量
            for b in buckets:
                if b > target:
                    supply += (b - target) * retain
                else:
                    demand += target - b
            return supply >= demand - 1e-9  # 考虑浮点误差

        lo, hi = 0.0, max(buckets)
        for _ in range(100):  # 足够多的迭代次数
            mid = (lo + hi) / 2
            if can_equalize(mid):
                lo = mid
            else:
                hi = mid

        return lo
```

### 方法二：精确迭代（更多次二分）

```python
from typing import List

class Solution:
    def equalizeWater(self, buckets: List[int], loss: int) -> float:
        factor = 1 - loss / 100

        def feasible(level: float) -> bool:
            give = sum(max(0.0, b - level) for b in buckets) * factor
            take = sum(max(0.0, level - b) for b in buckets)
            return give >= take - 1e-9

        lo, hi = 0.0, float(max(buckets))
        for _ in range(200):
            mid = (lo + hi) / 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid
        return round(lo, 5)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 浮点二分 | O(n * log(max/eps)) | O(1) |

200 次迭代对应精度约 max * 2^-200，远超所需精度。

## 关键点总结

1. 二分目标水位，判断转入量（含损耗）是否足够弥补转出量。
2. 有效供水 = 超出水 * retain，需水 = 缺少量之和。
3. 浮点二分用固定迭代次数代替精度判断，更稳定。

## 易错点

- 损耗发生在**转移**时，loss=0 表示无损耗，loss=100 表示所有水都损耗（此时 retain=0）。
- 浮点比较需要加一个小的容差（`1e-9`）。
