## 题目描述

给定两个数组 `instructions`（字符串数组，每个元素为 `"add"` 或 `"jump"`）和 `values`（整数数组），以及初始分数 `0`。从索引 `0` 开始执行：
- 若 `instructions[i] == "add"`：分数加上 `values[i]`，移动到 `i + 1`
- 若 `instructions[i] == "jump"`：移动到 `i + values[i]`（不改变分数）

若跳转到数组范围之外，停止执行。返回最终分数。

**示例 1：**

```
输入：instructions = ["add","jump","add"], values = [10, -1, 20]
输出：30
解释：
i=0: "add" 10，分数=10，移到 i=1
i=1: "jump" -1，移到 i=0
i=0: "add" 10，分数=20，移到 i=1
i=1: "jump" -1，移到 i=0
... 无限循环
```

**示例 2：**

```
输入：instructions = ["jump","add"], values = [2, 100]
输出：0
解释：i=0: "jump" 2，移到 i=2（越界），停止。分数 0。
```

**提示：**
- `1 <= instructions.length <= 10^5`
- `instructions[i]` 为 `"add"` 或 `"jump"`
- `-10^5 <= values[i] <= 10^5`

## 解题思路

直接模拟即可，但需要检测循环（如果同一个位置被访问两次，说明陷入循环，应停止）。

使用 `visited` 哈希集合记录已访问的索引，若重复访问则停止。

## Python 代码实现

### 方法一：模拟 + 循环检测（推荐）

```python
from typing import List

class Solution:
    def calculateScore(self, instructions: List[str], values: List[int]) -> int:
        n = len(instructions)
        score = 0
        i = 0
        visited = set()

        while 0 <= i < n:
            if i in visited:
                break  # 检测到循环，停止
            visited.add(i)

            if instructions[i] == "add":
                score += values[i]
                i += 1
            else:  # "jump"
                i += values[i]

        return score
```

### 方法二：使用标记数组

```python
from typing import List

class Solution:
    def calculateScore(self, instructions: List[str], values: List[int]) -> int:
        n = len(instructions)
        score = 0
        i = 0
        visited = [False] * n

        while 0 <= i < n:
            if visited[i]:
                break
            visited[i] = True

            if instructions[i] == "add":
                score += values[i]
                i += 1
            else:
                i += values[i]

        return score
```

## 复杂度分析

- 时间复杂度：O(n)，每个索引最多访问一次
- 空间复杂度：O(n)，visited 数组/集合

## 关键点总结

1. 模拟执行指令，维护当前索引和分数
2. 使用 visited 集合/数组检测循环
3. 跳出边界（< 0 或 >= n）时停止

## 易错点

1. `jump` 指令的目标是 `i + values[i]`，是相对跳转不是绝对跳转
2. 负数跳转也是合法的（可以向左跳）
3. 循环检测很重要，否则程序会无限运行
