## 题目描述

给你一棵绳索树的根节点，绳索树可以将长字符串表示为若干小字符串的树形结构。每个节点是叶节点（有字符串值 `val`）或内部节点（有左右子树，字符串为子树字符串拼接）。

返回整个绳索树表示的字符串中第 `k` 个字符（1-indexed）。

**数据范围：**
- 树节点数 1 到 10^3
- 0 <= Node.val.length <= 50
- 所有叶节点值长度之和 1 到 500

## 解题思路

DFS 构建完整字符串，然后取第 k 个字符。或者 DFS 时记录长度，剪枝后直接在目标子树中查找。

## Python 代码实现

### 方法一：DFS 构建完整字符串

```python
from typing import Optional

class RopeTreeNode:
    def __init__(self, len=0, val="", left=None, right=None):
        self.len = len
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def getKthCharacter(self, root: Optional[RopeTreeNode], k: int) -> str:
        def dfs(node) -> str:
            if not node:
                return ""
            if not node.left and not node.right:
                return node.val  # 叶节点
            return dfs(node.left) + dfs(node.right)

        return dfs(root)[k - 1]  # 1-indexed 转 0-indexed
```

### 方法二：DFS 剪枝（更高效）

```python
from typing import Optional

class Solution:
    def getKthCharacter(self, root: Optional[RopeTreeNode], k: int) -> str:
        def get_length(node) -> int:
            """获取节点代表的字符串长度"""
            if not node:
                return 0
            if node.val:
                return len(node.val)
            return node.len  # 若节点存储了长度

        def dfs(node, k) -> str:
            if not node:
                return ""
            if not node.left and not node.right:
                return node.val[k - 1]
            left_len = get_length(node.left)
            if k <= left_len:
                return dfs(node.left, k)
            else:
                return dfs(node.right, k - left_len)

        return dfs(root, k)
```

## 复杂度分析

- 方法一：时间复杂度 O(n * L)，L 为最大字符串长度
- 方法二：时间复杂度 O(log n)（平衡树时），空间复杂度 O(depth)

## 关键点总结

1. 叶节点存储实际字符串，内部节点合并子树字符串
2. 方法二利用左子树长度剪枝，直接定位到目标

## 易错点

1. k 是 1-indexed
2. 内部节点可能存储了子树的总长度（`len` 字段）
