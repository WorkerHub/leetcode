## 题目描述

给你一个整数数组 `prices`，它表示一个商店中不同巧克力的价格。同时给你一个整数 `money`，表示你初始拥有的钱数。

你必须购买 **恰好** 两块巧克力，而且购买的巧克力价格总和 **不能超过** `money`。

返回在购买两块巧克力后，你剩余的 **最大** 钱数。如果购买任意两块巧克力都超过了你拥有的钱，则返回 `money`（不购买任何巧克力）。

**示例 1：**
```
输入：prices = [1,2,2], money = 3
输出：0
解释：购买价格为 1 和 2 的巧克力，总费用 3 = money，剩余 0。
```

**示例 2：**
```
输入：prices = [3,2,3], money = 3
输出：3
解释：所有两两组合总费用均超过 3，返回 money = 3。
```

**提示：**
- `2 <= prices.length <= 50`
- `1 <= prices[i] <= 100`
- `1 <= money <= 100`

## 解题思路

只需找到最便宜的两块巧克力，即排序后取前两个最小值。若两个最小值之和不超过 `money`，返回剩余金额；否则返回 `money`。

## Python 代码实现

### 方法一：排序取前两小（推荐）

```python
from typing import List

class Solution:
    def buyChoco(self, prices: List[int], money: int) -> int:
        # 排序后前两个就是最小的两个价格
        prices.sort()
        cost = prices[0] + prices[1]
        # 如果负担得起，返回剩余；否则不购买，返回 money
        return money - cost if cost <= money else money
```

### 方法二：直接求两个最小值（不排序）

```python
from typing import List

class Solution:
    def buyChoco(self, prices: List[int], money: int) -> int:
        # 找出最小值和第二小值
        first = second = float('inf')
        for p in prices:
            if p <= first:
                second = first
                first = p
            elif p < second:
                second = p
        cost = first + second
        return money - cost if cost <= money else money
```

## 复杂度分析

- 方法一：时间复杂度 O(n log n)，空间复杂度 O(1)
- 方法二：时间复杂度 O(n)，空间复杂度 O(1)

## 关键点总结

1. 最大化剩余金额等价于最小化花费，即购买最便宜的两块
2. 负担不起时直接返回原始金额（不购买任何巧克力）
3. 方法二更高效，无需排序

## 易错点

1. 注意返回条件：`cost <= money`（等于时也可购买，剩余 0）
2. 不能只买一块，必须恰好购买两块
