## 题目描述

给你一个整数 `n`，表示比赛中的队伍数。比赛遵循以下规则：

- 如果当前队伍数是**偶数**，那么每支队伍都会被配对，进行 `n / 2` 场比赛，产生 `n / 2` 支队伍晋级下一轮
- 如果当前队伍数是**奇数**，那么将会随机轮空并晋级一支队伍，其余的队伍被配对，进行 `(n - 1) / 2` 场比赛，产生 `(n - 1) / 2 + 1` 支队伍晋级下一轮

返回在整个比赛过程中进行的**比赛总场数**。

**示例 1：**
```
输入：n = 7
输出：6
解释：
第 1 轮：3 场比赛，4 支队伍晋级（1 支轮空）
第 2 轮：2 场比赛，2 支队伍晋级
第 3 轮：1 场比赛，1 支队伍获胜
共 3 + 2 + 1 = 6 场比赛
```

**示例 2：**
```
输入：n = 14
输出：13
解释：
第 1 轮：7 场比赛，7 支队伍晋级
第 2 轮：3 场比赛，4 支队伍晋级（1 支轮空）
第 3 轮：2 场比赛，2 支队伍晋级
第 4 轮：1 场比赛，1 支队伍获胜
共 7 + 3 + 2 + 1 = 13 场比赛
```

**提示：** `1 <= n <= 200`

## 解题思路

**数学方法（最优）：** 每场比赛淘汰一支队伍，最终只剩 1 支队伍（冠军），所以总共淘汰了 `n - 1` 支队伍，对应 `n - 1` 场比赛。

**模拟方法：** 按照规则逐轮计算，直到只剩 1 支队伍。

## 代码实现

### 方法一：数学推导（推荐）

```python
class Solution:
    def numberOfMatches(self, n: int) -> int:
        # 每场比赛淘汰一支队伍，从 n 支到 1 支，共淘汰 n-1 支
        return n - 1
```

### 方法二：模拟

```python
class Solution:
    def numberOfMatches(self, n: int) -> int:
        total_matches = 0
        while n > 1:
            if n % 2 == 0:
                # 偶数：进行 n//2 场比赛，剩 n//2 支队伍
                total_matches += n // 2
                n //= 2
            else:
                # 奇数：进行 (n-1)//2 场比赛，剩 (n-1)//2 + 1 支队伍
                total_matches += (n - 1) // 2
                n = (n - 1) // 2 + 1
        return total_matches
```

## 复杂度分析

**方法一（数学）：**
- 时间复杂度：O(1)
- 空间复杂度：O(1)

**方法二（模拟）：**
- 时间复杂度：O(log n)，每轮队伍数减半
- 空间复杂度：O(1)

## 关键点总结

1. 数学方法一行解决：答案就是 `n - 1`
2. 数学证明：每场比赛恰好淘汰 1 支队伍，最终从 n 支到 1 支冠军，需淘汰 n-1 支
3. 模拟方法遵循题目描述逐轮计算，直观但不必要

## 易错点

1. 想复杂了，试图模拟所有轮次，其实一行代码就能解决
2. 奇数情况下，晋级队伍数为 `(n-1)//2 + 1`（包含轮空的那支），不是 `n//2`
