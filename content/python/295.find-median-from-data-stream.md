## 题目描述

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如：
- [2,3,4] 的中位数是 3
- [2,3] 的中位数是 (2 + 3) / 2 = 2.5

设计一个支持以下两种操作的数据结构：

- void addNum(int num) - 从数据流中添加一个整数到数据结构中。
- double findMedian() - 返回目前所有元素的中位数。

**示例 1：**
```
输入：
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出：
[null, null, null, 1.5, null, 2.0]

解释：
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr = [1, 2, 3]
medianFinder.findMedian(); // 返回 2.0
```

**提示：**
- -10^5 <= num <= 10^5
- 在调用 findMedian 之前，数据结构中至少有一个元素
- 最多调用 5 * 10^4 次 addNum 和 findMedian

**进阶：**
- 如果数据流中所有整数都在 0 到 100 范围内，你将如何优化你的算法？
- 如果数据流中 99% 的整数都在 0 到 100 范围内，你将如何优化你的算法？

## 解题思路

这是一道经典的数据流问题，核心是如何高效地维护中位数。

**方法对比：**

| 方法 | addNum | findMedian | 空间 | 说明 |
|------|--------|------------|------|------|
| 排序数组 | O(n) | O(1) | O(n) | 插入慢 |
| 双堆 | O(log n) | O(1) | O(n) | 最优解 |
| 平衡树 | O(log n) | O(log n) | O(n) | 需要额外操作 |

**双堆解法（推荐）：**

核心思想是维护两个堆：
- **大顶堆（max_heap）**：存储较小的一半数字
- **小顶堆（min_heap）**：存储较大的一半数字

**关键性质：**
1. 大顶堆的最大值 <= 小顶堆的最小值
2. 两个堆的大小差不超过 1
3. 中位数就在堆顶

**添加元素流程：**
1. 先加入大顶堆，然后将大顶堆的最大值移到小顶堆
2. 如果小顶堆过大，将小顶堆的最小值移回大顶堆
3. 保持：len(max_heap) == len(min_heap) 或 len(max_heap) == len(min_heap) + 1

## Python 代码实现

### 方法一：双堆（推荐）

```python
import heapq

class MedianFinder:
    """
    使用两个堆维护中位数
    - 大顶堆（用负数模拟）：存较小的一半
    - 小顶堆：存较大的一半
    """
    
    def __init__(self):
        # Python 的 heapq 是小顶堆，用负数模拟大顶堆
        self.max_heap = []  # 存较小的一半（用负数）
        self.min_heap = []  # 存较大的一半
    
    def addNum(self, num: int) -> None:
        """
        添加数字，时间复杂度 O(log n)
        """
        # 先加入大顶堆（用负数）
        heapq.heappush(self.max_heap, -num)
        
        # 将大顶堆的最大值移到小顶堆
        # 保证大顶堆的所有元素 <= 小顶堆的所有元素
        max_val = -heapq.heappop(self.max_heap)
        heapq.heappush(self.min_heap, max_val)
        
        # 平衡两个堆的大小
        # 保持大顶堆的元素个数 >= 小顶堆
        if len(self.min_heap) > len(self.max_heap):
            min_val = heapq.heappop(self.min_heap)
            heapq.heappush(self.max_heap, -min_val)
    
    def findMedian(self) -> float:
        """
        获取中位数，时间复杂度 O(1)
        """
        # 如果两个堆大小相等，中位数是两个堆顶的平均值
        if len(self.max_heap) == len(self.min_heap):
            return (-self.max_heap[0] + self.min_heap[0]) / 2.0
        # 否则，中位数是大顶堆的堆顶（大顶堆元素多一个）
        else:
            return float(-self.max_heap[0])
```

### 方法二：简化版双堆

```python
import heapq

class MedianFinder:
    """
    简化版本，逻辑更清晰
    """
    
    def __init__(self):
        self.small = []  # 大顶堆（负数）- 较小一半
        self.large = []  # 小顶堆 - 较大一半
    
    def addNum(self, num: int) -> None:
        # 添加到大顶堆
        heapq.heappush(self.small, -num)
        
        # 确保 small 的最大值 <= large 的最小值
        if self.small and self.large and (-self.small[0] > self.large[0]):
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        
        # 平衡大小（small 的元素可以多一个）
        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        if len(self.large) > len(self.small):
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)
    
    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0
```

### 方法三：排序数组（暴力，仅用于对比）

```python
class MedianFinder:
    """
    使用排序数组，添加时保持有序
    时间复杂度：addNum O(n)，findMedian O(1)
    """
    
    def __init__(self):
        self.nums = []
    
    def addNum(self, num: int) -> None:
        # 二分查找插入位置
        left, right = 0, len(self.nums)
        while left < right:
            mid = (left + right) // 2
            if self.nums[mid] < num:
                left = mid + 1
            else:
                right = mid
        self.nums.insert(left, num)
    
    def findMedian(self) -> float:
        n = len(self.nums)
        if n % 2 == 1:
            return float(self.nums[n // 2])
        else:
            return (self.nums[n // 2 - 1] + self.nums[n // 2]) / 2.0
```

### 方法四：使用 bisect 模块

```python
import bisect

class MedianFinder:
    """
    使用 Python 的 bisect 模块维护有序数组
    """
    
    def __init__(self):
        self.nums = []
    
    def addNum(self, num: int) -> None:
        # bisect.insort 会自动找到插入位置并插入
        bisect.insort(self.nums, num)
    
    def findMedian(self) -> float:
        n = len(self.nums)
        if n % 2 == 1:
            return float(self.nums[n // 2])
        else:
            return (self.nums[n // 2 - 1] + self.nums[n // 2]) / 2.0
```

### 方法五：桶排序优化（针对进阶问题1）

```python
class MedianFinder:
    """
    如果数据范围在 0-100，使用桶计数
    时间复杂度：addNum O(1)，findMedian O(100) = O(1)
    """
    
    def __init__(self):
        self.buckets = [0] * 101  # 0-100 的计数
        self.count = 0  # 总元素数
    
    def addNum(self, num: int) -> None:
        self.buckets[num] += 1
        self.count += 1
    
    def findMedian(self) -> float:
        # 找到中位数位置
        mid = (self.count + 1) // 2
        
        cumsum = 0
        for i in range(101):
            cumsum += self.buckets[i]
            if cumsum >= mid:
                if self.count % 2 == 1:
                    return float(i)
                else:
                    # 偶数个元素，需要找两个中间值
                    if cumsum - self.buckets[i] < mid:
                        # 两个中间值都是 i
                        return float(i)
                    else:
                        # 需要找下一个数
                        for j in range(i + 1, 101):
                            if self.buckets[j] > 0:
                                return (i + j) / 2.0
        return 0.0
```

## 复杂度分析

### 方法一（双堆）：

**时间复杂度：**
- addNum: O(log n) - 堆的插入和删除操作
- findMedian: O(1) - 直接访问堆顶

**空间复杂度：** O(n)
- 需要存储所有 n 个元素

### 方法三、四（排序数组）：

**时间复杂度：**
- addNum: O(n) - 插入操作需要移动元素
- findMedian: O(1) - 直接访问中间位置

**空间复杂度：** O(n)

### 方法五（桶排序）：

**时间复杂度：**
- addNum: O(1) - 数组访问
- findMedian: O(100) = O(1) - 固定范围遍历

**空间复杂度：** O(100) = O(1) - 固定大小数组

双堆方法图解：

```
示例：依次添加 1, 2, 3

步骤1：添加 1
small(大顶堆): [1]
large(小顶堆): []
中位数: 1

步骤2：添加 2
- 先将2加入small: [-2, -1]
- 将small最大值移到large: small=[-1], large=[2]
- 大小平衡，无需调整
small: [1]
large: [2]
中位数: (1 + 2) / 2 = 1.5

步骤3：添加 3
- 先将3加入small: [-3, -1]
- 将small最大值移到large: small=[-1], large=[2, 3]
- large过大，移回一个: small=[-2, -1], large=[3]
small: [2, 1]
large: [3]
中位数: 2

堆的状态（实际存储）：
small(负数表示): [-2, -1]  表示大顶堆 [2, 1]
large: [3]

结构示意：
较小一半 | 较大一半
  2  1   |   3
  ↑          ↑
大顶堆     小顶堆
```

## 关键点总结

1. **双堆平衡**：始终保持两个堆大小相差不超过 1
2. **堆的性质**：大顶堆的最大值 <= 小顶堆的最小值
3. **Python 堆技巧**：用负数模拟大顶堆
4. **插入顺序**：总是先插入大顶堆，再调整平衡
5. **中位数位置**：根据两个堆的大小决定中位数在哪

## 易错点

1. **忘记平衡堆的大小**
   ```python
   # 错误：只移动元素，不检查大小
   heapq.heappush(self.max_heap, -num)
   val = -heapq.heappop(self.max_heap)
   heapq.heappush(self.min_heap, val)
   # 忘记检查 min_heap 是否过大
   
   # 正确：要平衡大小
   if len(self.min_heap) > len(self.max_heap):
       val = heapq.heappop(self.min_heap)
       heapq.heappush(self.max_heap, -val)
   ```

2. **大顶堆的符号错误**
   ```python
   # 错误：忘记取负数
   heapq.heappush(self.max_heap, num)  # 错误！
   
   # 正确：要用负数
   heapq.heappush(self.max_heap, -num)
   
   # 错误：访问时忘记取负
   return self.max_heap[0]  # 错误！
   
   # 正确：要取负数
   return -self.max_heap[0]
   ```

3. **中位数计算错误**
   ```python
   # 错误：整数除法
   return (-self.max_heap[0] + self.min_heap[0]) / 2
   # 在 Python 3 中 / 已经是浮点除法，但为了安全：
   
   # 正确：确保返回浮点数
   return (-self.max_heap[0] + self.min_heap[0]) / 2.0
   ```

4. **初始化时的边界检查**
   ```python
   # 错误：没有检查堆是否为空
   if -self.max_heap[0] > self.min_heap[0]:
   # 如果 min_heap 为空会报错
   
   # 正确：先检查是否为空
   if self.small and self.large and (-self.small[0] > self.large[0]):
   ```
