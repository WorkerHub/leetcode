## 题目描述

设计一个类似堆栈的数据结构，将元素推入堆栈，并从堆栈中弹出出现频率最高的元素。

实现 FreqStack 类:
- FreqStack() 构造一个空的堆栈。
- void push(int val) 将一个整数 val 压入栈顶。
- int pop() 删除并返回堆栈中出现频率最高的元素。如果出现频率最高的元素不止一个，则移除并返回最接近栈顶的元素。

**提示：**
- 0 <= val <= 10^9
- push 和 pop 的操作数不大于 2 * 10^4
- 输入保证在调用 pop 之前堆栈中至少有一个元素

## 解题思路

使用两个哈希表：
1. freq: val → 出现次数
2. group: 频率 → 该频率下的元素栈

## Python 代码实现

```python
class FreqStack:
    def __init__(self):
        self.freq = {}  # val -> 频率
        self.group = {}  # 频率 -> 栈
        self.max_freq = 0
    
    def push(self, val: int) -> None:
        # 更新频率
        self.freq[val] = self.freq.get(val, 0) + 1
        f = self.freq[val]
        
        # 加入对应频率的栈
        if f not in self.group:
            self.group[f] = []
        self.group[f].append(val)
        
        # 更新最大频率
        self.max_freq = max(self.max_freq, f)
    
    def pop(self) -> int:
        # 从最大频率栈中弹出
        val = self.group[self.max_freq].pop()
        
        # 更新频率
        self.freq[val] -= 1
        
        # 如果最大频率栈空了，减小 max_freq
        if not self.group[self.max_freq]:
            self.max_freq -= 1
        
        return val
```

## 复杂度分析

- **时间复杂度**：push O(1)，pop O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **频率分组**：相同频率的元素在同一栈
2. **维护最大频率**：max_freq 记录当前最大频率
3. **栈的性质**：后进先出，满足题目要求
