## 题目描述

给你一个 `m x n` 的迷宫矩阵 `maze`（下标从 0 开始），矩阵中有空格子（`'.'`）和墙（`'+'`）。同时给你迷宫的入口 `entrance`，定义为 `[entrance_row, entrance_col]`，你从该格子开始。

每一步，你可以向上、下、左、右移动一个格子，不能进入墙格子，也不能离开迷宫。

**出口**是指**边界**上的**空格子**，**入口本身不算出口**。

返回从入口到最近出口的**最短路径步数**，若不存在出口则返回 `-1`。

**示例 1：**
```
输入：maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
输出：1
解释：maze[1][0] 是出口，步数为 1
```

**提示：**
- `maze[i][j]` 是 `'+'` 或 `'.'`
- `entrance.length == 2`

---

## 解题思路

### 核心思想：BFS 最短路

从入口出发进行 BFS，第一次到达边界空格子时即为最短路径。

关键点：
- 入口不算出口
- 边界格子（`i==0` 或 `i==m-1` 或 `j==0` 或 `j==n-1`）且为空格才算出口

## 代码实现

### 方法一：BFS（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        m, n = len(maze), len(maze[0])
        sr, sc = entrance

        queue = deque([(sr, sc, 0)])  # (行, 列, 步数)
        visited = {(sr, sc)}

        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while queue:
            r, c, steps = queue.popleft()

            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and maze[nr][nc] == '.' and (nr, nc) not in visited:
                    # 判断是否是出口（边界且非入口）
                    if nr == 0 or nr == m - 1 or nc == 0 or nc == n - 1:
                        return steps + 1
                    visited.add((nr, nc))
                    queue.append((nr, nc, steps + 1))

        return -1
```

### 方法二：原地标记（节省空间）

```python
from typing import List
from collections import deque

class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        m, n = len(maze), len(maze[0])
        sr, sc = entrance

        queue = deque([(sr, sc, 0)])
        maze[sr][sc] = '+'  # 标记入口为已访问

        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while queue:
            r, c, steps = queue.popleft()

            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and maze[nr][nc] == '.':
                    # 是出口
                    if nr == 0 or nr == m - 1 or nc == 0 or nc == n - 1:
                        return steps + 1
                    maze[nr][nc] = '+'  # 标记已访问
                    queue.append((nr, nc, steps + 1))

        return -1
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS（visited 集合） | O(mn) | O(mn) |
| BFS（原地标记） | O(mn) | O(mn)（队列） |

---

## 关键点总结

1. BFS 保证找到最短路径（步数最少）
2. 出口判断：在边界上的空格，且不是入口
3. 入口一开始就标记为已访问，防止走回入口

---

## 易错点

- 入口本身不算出口，要排除
- 访问标记必须在入队时设置（而非出队时），否则会重复入队
