## 题目描述

给你一个整数数组 `nums`，对于两个整数 `a` 和 `b`，如果将 `a` 的**恰好一对数字**互换后能等于 `b`（互换后的数字不能有前导零，除非恰好为 0），则称 `(a, b)` 为**近似相等对**。

**注意：** `a == b` 也被视为近似相等（互换同一位置的两个数字）。

返回下标 `i < j` 且 `nums[i]` 和 `nums[j]` 构成近似相等对的对数。

**示例 1：**
```
输入：nums = [3,12,30,17,21]
输出：2
```

**示例 2：**
```
输入：nums = [1,1,1,1,2]
输出：6
```

**提示：**
- `2 <= nums.length <= 100`
- `0 <= nums[i] <= 10^6`

## 解题思路

对每个数字生成所有可能的"互换一对数字"后的结果，包括不互换（自身）。然后用哈希表统计每个结果出现的次数，统计相同结果的对数。

生成一个数的所有一次交换变体：
- 将数字转为字符串，枚举所有数字对 (i, j) 交换

## Python 代码实现

### 方法一：枚举所有交换变体（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, nums: List[int]) -> int:
        def get_variants(x):
            s = list(str(x))
            n = len(s)
            variants = set()
            variants.add(x)  # 自身（不交换）
            for i in range(n):
                for j in range(i + 1, n):
                    s[i], s[j] = s[j], s[i]
                    # 检查前导零
                    if s[0] != '0':
                        variants.add(int(''.join(s)))
                    s[i], s[j] = s[j], s[i]
            return variants
        
        ans = 0
        for i in range(len(nums)):
            variants_i = get_variants(nums[i])
            for j in range(i + 1, len(nums)):
                if nums[j] in variants_i:
                    ans += 1
        return ans
```

### 方法二：哈希表计数

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, nums: List[int]) -> int:
        def get_variants(x):
            s = list(str(x))
            n = len(s)
            variants = {x}
            for i in range(n):
                for j in range(i + 1, n):
                    s[i], s[j] = s[j], s[i]
                    if s[0] != '0':
                        variants.add(int(''.join(s)))
                    s[i], s[j] = s[j], s[i]
            return variants
        
        # 对每个数字，统计它的所有变体
        cnt = defaultdict(int)
        ans = 0
        
        for x in nums:
            # 检查前面已处理的数字中有多少与 x 构成近似相等对
            variants = get_variants(x)
            for v in variants:
                ans += cnt[v]
            cnt[x] += 1
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 * D^2)，D 为数字位数（最多 7 位）
- 空间复杂度：O(n * D^2)

## 关键点总结

1. 生成一个数所有一次交换的变体（包括自身）
2. 两数近似相等 = 一个数是另一个数的变体
3. 注意前导零不合法

## 易错点

1. 不互换（a == b）也是近似相等
2. 交换后不能有前导零（首位不能为 0，除非数字本身就是 0）
