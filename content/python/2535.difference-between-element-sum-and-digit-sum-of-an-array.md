## 题目描述

给你一个正整数数组 `nums`。

- **元素和**：`nums` 中所有元素之和
- **数字和**：`nums` 中每个元素的每一位数字之和（各位之和的总和）

返回元素和与数字和的绝对差。

**示例 1：**

```
输入：nums = [1,15,6,3]
输出：9
解释：元素和 = 1+15+6+3 = 25，数字和 = 1+(1+5)+6+3 = 16，差 = |25-16| = 9。
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：0
解释：元素和 = 10，数字和 = 1+2+3+4 = 10，差 = 0。
```

**提示：**

- `1 <= nums.length <= 2000`
- `1 <= nums[i] <= 1000`

## 解题思路

直接计算元素和与数字和，取绝对差。

数字和：对每个数转为字符串逐位累加，或用取模操作逐位提取。

## Python 代码实现

### 方法一：字符串处理（推荐）

```python
from typing import List

class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        element_sum = sum(nums)
        digit_sum = sum(int(ch) for n in nums for ch in str(n))
        return abs(element_sum - digit_sum)
```

### 方法二：数学取模

```python
from typing import List

class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        element_sum = 0
        digit_sum = 0
        for n in nums:
            element_sum += n
            # 逐位提取数字
            temp = n
            while temp > 0:
                digit_sum += temp % 10
                temp //= 10
        return abs(element_sum - digit_sum)
```

## 复杂度分析

- 时间复杂度：O(n * d)，d 为元素的最大位数（本题 d <= 4）
- 空间复杂度：O(1)

## 关键点总结

1. 数字和 = 所有元素各位数字之和
2. 元素和 >= 数字和（因为每个元素 >= 其各位数字和），差非负，可省去 abs
3. Python 生成器表达式可以简洁地完成嵌套计算

## 易错点

1. 数字和是"每个元素每一位之和"，不是每个元素本身
2. 多位数如 15：数字和贡献 1+5=6，而不是 15
3. 结果取绝对值（虽然数学上元素和 >= 数字和，但保险起见用 abs）
