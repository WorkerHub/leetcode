## 题目描述

一个正整数如果能被 a 或 b 整除，那么它是神奇的。

给定三个整数 n, a, b，返回第 n 个神奇数字。由于答案可能很大，返回答案对 10^9 + 7 取模 后的值。

**提示：**
- 1 <= n <= 10^9
- 2 <= a, b <= 4 * 10^4

## 解题思路

**核心：** 二分查找 + 数学（容斥原理）

1. 二分答案 x
2. 计算 [1, x] 中神奇数字的个数：`x//a + x//b - x//lcm(a,b)`
3. 找到第一个使得个数 >= n 的 x

## Python 代码实现

```python
class Solution:
    def nthMagicalNumber(self, n: int, a: int, b: int) -> int:
        from math import gcd
        
        MOD = 10**9 + 7
        lcm = a * b // gcd(a, b)
        
        def count(x):
            """计算 [1,x] 中神奇数字的个数"""
            return x // a + x // b - x // lcm
        
        left, right = min(a, b), n * min(a, b)
        
        while left < right:
            mid = (left + right) // 2
            if count(mid) < n:
                left = mid + 1
            else:
                right = mid
        
        return left % MOD
```

## 复杂度分析

- **时间复杂度**：O(log(n × min(a,b)))
- **空间复杂度**：O(1)

## 关键点总结

1. **容斥原理**：避免重复计数
2. **最小公倍数**：lcm(a,b) = a*b/gcd(a,b)
3. **二分答案**：单调性保证
