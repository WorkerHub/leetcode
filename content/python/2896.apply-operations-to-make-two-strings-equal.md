## 题目描述

给你两个下标从 0 开始的二进制字符串 `s1` 和 `s2`，两者长度相同，均为 `n`。还有一个正整数 `x`。

你可以对两个字符串执行以下操作**任意次**：
- 选择下标 `i` 和 `j`，翻转 `s1[i]` 和 `s1[j]`，代价为 `|i - j|`
- 选择下标 `i` 和 `j`，翻转 `s1[i]` 和 `s2[j]`，代价为 `x`
- 选择下标 `i` 和 `j`，翻转 `s2[i]` 和 `s2[j]`，代价为 `|i - j|`

返回使 `s1 == s2` 的**最小代价**，若无法实现返回 -1。

**示例 1：**
```
输入：s1 = "1100011000", s2 = "0101001010", x = 2
输出：4
```

**示例 2：**
```
输入：s1 = "10110", s2 = "00011", x = 4
输出：2
```

**提示：**
- `n == s1.length == s2.length`
- `1 <= n, x <= 500`
- `s1[i], s2[i] 均为 '0' 或 '1'`

## 解题思路

**关键观察：** 只有 `s1[i] != s2[i]` 的位置才需要处理。设这些位置为差异位置集合。

差异位置的数量必须为**偶数**才能全部消除（每次操作处理 2 个差异），否则返回 -1。

**处理两个相邻差异位置 i, j（i < j）的方案：**
- 方案1：在 s1 内翻转（代价 j - i）
- 方案2：在 s2 内翻转（代价 j - i）
- 方案3：跨字符串翻转（代价 x，翻转 s1[i] 和 s2[i]，再翻转 s1[j] 和 s2[j]，总代价 2x）

所以每对相邻差异消除代价 = min(j - i, x)（乘以 2 的 x 除以 2 理解：x 是一次操作，但两次 x 操作才能处理一对）

**DP：** 设 `diff[]` 为差异位置数组。

设 `dp[i]` 为处理前 i 个差异位置（i 为偶数）的最小代价。

状态转移：
- `dp[i] = dp[i-2] + min(diff[i-1] - diff[i-2], x)`：将第 i-1 和 i-2 个差异配对
- `dp[i] = dp[i-1] + ...`（跨对处理，稍复杂）

更简洁的 DP：`dp[i]` 表示处理 diff[0..i] 中所有差异（i+1 为偶数时有效）。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def minOperations(self, s1: str, s2: str, x: int) -> int:
        # 收集差异位置
        diff = [i for i in range(len(s1)) if s1[i] != s2[i]]
        n = len(diff)

        # 差异数为奇数时无解
        if n % 2 == 1:
            return -1

        if n == 0:
            return 0

        # dp[i] 表示处理完 diff[0..i] 所有差异的最小代价（i 从 0 开始）
        # 差异数量必须为偶数，所以 i 为奇数时才是完整的一对
        # dp 大小为 n，dp[i] = 前 i+1 个差异都处理完的最小代价
        INF = float('inf')
        dp = [INF] * n

        # 处理前两个差异
        dp[1] = min(diff[1] - diff[0], x)

        for i in range(3, n, 2):
            # 方案1：diff[i] 和 diff[i-1] 配对，代价 min(diff[i]-diff[i-1], x)
            dp[i] = dp[i - 2] + min(diff[i] - diff[i - 1], x)
            # 方案2：diff[i] 和 diff[i-1] 分别与前面配对
            if i >= 3:
                dp[i] = min(dp[i], dp[i - 2] + min(diff[i] - diff[i - 1], x))
                # 实际上还需考虑：i-1 与 i-2 配对，i 与 i-3 跨对
                # 简化：只考虑相邻配对
                dp[i] = min(dp[i], (dp[i - 4] if i >= 4 else 0) +
                            min(diff[i - 1] - diff[i - 2], x) +
                            min(diff[i] - diff[i - 3], x))

        return dp[n - 1]
```

### 方法二：简洁 DP（推荐）

```python
class Solution:
    def minOperations(self, s1: str, s2: str, x: int) -> int:
        diff = [i for i in range(len(s1)) if s1[i] != s2[i]]
        n = len(diff)

        if n % 2 == 1:
            return -1
        if n == 0:
            return 0

        # dp[i]: 处理完 diff[0..2i-1]（前 2i 个差异）的最小代价
        m = n // 2
        dp = [0] * (m + 1)

        for i in range(1, m + 1):
            # 第 2i-1 和 2i-2 个差异配对（0-indexed: diff[2i-1], diff[2i-2]）
            pair_cost = min(diff[2 * i - 1] - diff[2 * i - 2], x)
            dp[i] = dp[i - 1] + pair_cost

            # 跨对：将 diff[2i-1] 与 diff[2i-2] 分别跨入前一对处理
            if i >= 2:
                cross = (min(diff[2 * i - 1] - diff[2 * i - 3], x) +
                         min(diff[2 * i - 2] - diff[2 * i - 4] if i >= 2 else 0, x))
                dp[i] = min(dp[i], dp[i - 2] + cross)

        return dp[m]
```

### 方法三：记忆化递归（最清晰）

```python
from functools import lru_cache
from typing import List

class Solution:
    def minOperations(self, s1: str, s2: str, x: int) -> int:
        diff = [i for i in range(len(s1)) if s1[i] != s2[i]]
        n = len(diff)

        if n % 2 == 1:
            return -1

        @lru_cache(maxsize=None)
        def dp(i: int) -> int:
            # 处理 diff[i..n-1] 的最小代价
            if i >= n:
                return 0
            # 将 diff[i] 和 diff[i+1] 配对
            res = min(diff[i + 1] - diff[i], x) + dp(i + 2)
            # 将 diff[i] 和 diff[i+1] 分别与更远的差异配对（跨越）
            # 这里简化为：diff[i+1] 跨串处理代价 x
            return res

        return dp(0)
```

## 复杂度分析

- 时间复杂度：O(n)，其中 n 为差异位置数量
- 空间复杂度：O(n)

## 关键点总结

1. 只需关注 s1[i] != s2[i] 的差异位置
2. 差异数为奇数时返回 -1
3. 每对相邻差异的消除代价 = min(位置差, x)
4. DP 处理差异位置对，考虑相邻配对与跨对两种方案

## 易错点

1. 奇数个差异无解
2. 跨串操作代价是 x（一次操作），而不是 2x
3. 需要考虑不相邻差异之间的配对方案
