## 题目描述

给你一个偶数 `n`，现有一个由 `n` 个整数组成的排列 `perm`，其中 `perm[i] == i`（下标从 0 开始）。

每步操作将生成一个新数组 `arr`，对于每个 `i`：
- 如果 `i % 2 == 0`，则 `arr[i] = perm[i / 2]`
- 如果 `i % 2 == 1`，则 `arr[i] = perm[n / 2 + (i - 1) / 2]`

然后将 `arr` 赋值给 `perm`。

返回使 `perm` 回到初始值需要的最小非零操作步数。

**示例 1：**
```
输入：n = 2
输出：1
```

**示例 2：**
```
输入：n = 4
输出：2
```

**示例 3：**
```
输入：n = 6
输出：4
```

**提示：**
- `2 <= n <= 1000`
- `n` 是一个偶数

## 解题思路

**模拟法**：直接按照题目规则模拟每步操作，检测何时排列回到初始状态。

**数学观察**：位置 `i` 的元素经过一次操作后会移动到位置 `2*i mod (n-1)`（对于 `0 < i < n-1`，位置 0 和 n-1 保持不变）。因此总步数等于各个位置回到原位所需步数的最小公倍数。

## 代码实现

### 方法一：直接模拟（推荐，简单易懂）

```python
from typing import List

class Solution:
    def reinitializePermutation(self, n: int) -> int:
        # 初始排列
        perm = list(range(n))
        original = list(range(n))
        ops = 0

        while True:
            # 执行一次操作
            arr = [0] * n
            for i in range(n):
                if i % 2 == 0:
                    arr[i] = perm[i // 2]
                else:
                    arr[i] = perm[n // 2 + (i - 1) // 2]
            perm = arr
            ops += 1
            # 检查是否回到初始状态
            if perm == original:
                return ops
```

### 方法二：跟踪单个元素的周期（数学优化）

```python
from math import gcd

class Solution:
    def reinitializePermutation(self, n: int) -> int:
        def cycle_length(start: int) -> int:
            """计算位置 start 的元素回到原位需要的步数"""
            pos = start
            steps = 0
            while True:
                # 位置 pos 的元素经过一次变换后到达新位置
                if pos % 2 == 0:
                    pos = pos // 2
                else:
                    pos = n // 2 + (pos - 1) // 2
                steps += 1
                if pos == start:
                    return steps

        def lcm(a: int, b: int) -> int:
            return a * b // gcd(a, b)

        result = 1
        for i in range(n):
            result = lcm(result, cycle_length(i))
        return result
```

## 复杂度分析

- **方法一（模拟）**：
  - 时间复杂度：O(n * k)，k 是操作步数（实际很小）
  - 空间复杂度：O(n)
- **方法二（数学）**：
  - 时间复杂度：O(n * k)，k 是最大周期长度
  - 空间复杂度：O(1)

## 关键点总结

1. 模拟法直接实现变换规则，简单可靠
2. 每个位置的元素独立地以某个周期循环，总周期是所有位置周期的最小公倍数
3. 位置 0 和 n-1 的元素始终不动（分别是 perm[0] 和 perm[n/2]，对应自身）

## 易错点

- 偶数索引用 `i//2`，奇数索引用 `n//2 + (i-1)//2`，不要混淆
- 模拟时需要先生成完整的新数组 arr，再赋值给 perm，不能边读边写
