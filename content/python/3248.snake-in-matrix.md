## 题目描述

给你一个 `n x n` 的矩阵（行列均从 0 开始编号），一条蛇初始位于位置 `(0, 0)`。

给你一个字符串数组 `commands`，每个命令为：
- `"UP"`：蛇向上移动一格
- `"DOWN"`：蛇向下移动一格
- `"LEFT"`：蛇向左移动一格
- `"RIGHT"`：蛇向右移动一格

返回执行所有命令后蛇所在位置的**格子编号**（格子编号 = 行号 * n + 列号）。

**示例 1：**
```
输入：n = 2, commands = ["RIGHT","DOWN"]
输出：3
解释：(0,0) -> (0,1) -> (1,1)，编号 = 1*2+1 = 3
```

**示例 2：**
```
输入：n = 3, commands = ["DOWN","RIGHT","UP"]
输出：1
```

**提示：**
- `2 <= n <= 10`
- `1 <= commands.length <= 100`
- 蛇不会移出矩阵

## 解题思路

简单模拟：维护当前行列坐标，根据命令更新，最后计算格子编号。

## Python 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def finalPositionOfSnake(self, n: int, commands: List[str]) -> int:
        row, col = 0, 0
        direction = {
            'UP': (-1, 0),
            'DOWN': (1, 0),
            'LEFT': (0, -1),
            'RIGHT': (0, 1)
        }
        for cmd in commands:
            dr, dc = direction[cmd]
            row += dr
            col += dc
        return row * n + col
```

### 方法二：直接用坐标变化

```python
from typing import List

class Solution:
    def finalPositionOfSnake(self, n: int, commands: List[str]) -> int:
        pos = 0  # 直接维护格子编号
        for cmd in commands:
            if cmd == 'RIGHT':
                pos += 1
            elif cmd == 'LEFT':
                pos -= 1
            elif cmd == 'DOWN':
                pos += n
            elif cmd == 'UP':
                pos -= n
        return pos
```

## 复杂度分析

- 时间复杂度：O(m)，m 为命令数量
- 空间复杂度：O(1)

## 关键点总结

1. 格子编号 = 行 * n + 列
2. DOWN 操作 = pos += n，UP 操作 = pos -= n
3. 题目保证不越界，不需要边界检查

## 易错点

1. 注意行列方向：UP 是行减小，DOWN 是行增大
2. 格子编号的计算用行号乘以 n 再加列号
