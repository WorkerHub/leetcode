## 题目描述

给你一个字符串数组 `words` 和一个二维数组 `queries`，其中 `queries[i] = [li, ri]`。

对每个查询，统计 `words[li..ri]` 中以元音字母开头且以元音字母结尾的字符串数目（元音字母为 a, e, i, o, u）。

返回长度为 `queries.length` 的数组 `ans`，其中 `ans[i]` 是第 i 个查询的答案。

**示例 1：**

```
输入：words = ["aba","bcb","ece","aa","e"], queries = [[0,2],[1,4],[1,1]]
输出：[2,3,0]
```

**提示：**

- `1 <= words.length <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

**前缀和**：预先计算 `prefix[i]` = words[0..i-1] 中满足条件的字符串数量。

对查询 [l, r]，答案 = prefix[r+1] - prefix[l]。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], queries: List[List[int]]) -> List[int]:
        vowels = set('aeiou')

        def is_vowel_string(w):
            return w[0] in vowels and w[-1] in vowels

        # 预计算前缀和
        n = len(words)
        prefix = [0] * (n + 1)
        for i, w in enumerate(words):
            prefix[i + 1] = prefix[i] + (1 if is_vowel_string(w) else 0)

        return [prefix[r + 1] - prefix[l] for l, r in queries]
```

### 方法二：直接计算（不预处理，适合少量查询）

```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], queries: List[List[int]]) -> List[int]:
        vowels = set('aeiou')
        is_vowel = [w[0] in vowels and w[-1] in vowels for w in words]

        prefix = [0] * (len(words) + 1)
        for i, v in enumerate(is_vowel):
            prefix[i+1] = prefix[i] + v

        return [prefix[r+1] - prefix[l] for l, r in queries]
```

## 复杂度分析

- 时间复杂度：O(n + q)，预处理 O(n)，每次查询 O(1)
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 前缀和将区间查询优化为 O(1)
2. 只需判断每个单词首字符和末字符是否为元音
3. 查询答案 = prefix[r+1] - prefix[l]

## 易错点

1. prefix 数组大小为 n+1，prefix[0] = 0
2. 查询是闭区间 [l, r]，对应前缀和差为 prefix[r+1] - prefix[l]
3. 字符串空字符的情况：题目保证 words[i] 非空，不需要额外判断
