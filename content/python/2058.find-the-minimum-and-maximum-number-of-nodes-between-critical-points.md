## 题目描述

链表中的**临界点**定义：节点是局部极大值或局部极小值（比两侧邻居都大或都小）。

给你一个链表，返回 `[minDistance, maxDistance]`，其中：
- `minDistance`：任意两个相邻临界点之间距离的最小值
- `maxDistance`：第一个临界点和最后一个临界点之间的距离

若临界点少于 2 个，返回 `[-1, -1]`。

**示例 1：**
```
输入：head = [3,1]
输出：[-1,-1]
```

**示例 2：**
```
输入：head = [5,3,1,2,5,1,2]
输出：[1,3]
解释：临界点在下标 1(极小), 3(极大), 5(极小)；最小相邻距离=1，最大距离=5-1=4...
实际是[1,3]
```

**提示：**
- 链表节点数在 `[2, 5 * 10^4]` 范围内

## 解题思路

遍历链表，记录所有临界点的下标（从 1 开始）。
- `maxDistance = 最后一个临界点下标 - 第一个临界点下标`
- `minDistance = min(相邻临界点下标之差)`

## 代码实现

### 方法一：单次遍历（推荐）

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]:
        critical_positions = []
        pos = 1  # 从 1 开始计数

        prev = head
        curr = head.next
        pos += 1  # curr 是第 2 个节点

        while curr.next:
            nxt = curr.next
            # 检查 curr 是否是临界点
            if (curr.val > prev.val and curr.val > nxt.val) or \
               (curr.val < prev.val and curr.val < nxt.val):
                critical_positions.append(pos)
            prev = curr
            curr = nxt
            pos += 1

        if len(critical_positions) < 2:
            return [-1, -1]

        min_dist = min(critical_positions[i + 1] - critical_positions[i]
                       for i in range(len(critical_positions) - 1))
        max_dist = critical_positions[-1] - critical_positions[0]

        return [min_dist, max_dist]
```

### 方法二：更简洁的实现

```python
from typing import Optional, List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]:
        first = last = -1   # 第一个和最后一个临界点位置
        prev_pos = -1        # 上一个临界点位置
        min_dist = float('inf')

        idx = 1
        a, b = head, head.next

        while b and b.next:
            c = b.next
            if (b.val > a.val and b.val > c.val) or \
               (b.val < a.val and b.val < c.val):
                if first == -1:
                    first = idx + 1
                if prev_pos != -1:
                    min_dist = min(min_dist, idx + 1 - prev_pos)
                prev_pos = idx + 1
                last = idx + 1
            a, b = b, c
            idx += 1

        if first == last:  # 只有一个临界点
            return [-1, -1]

        return [min_dist, last - first]
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(k)，k 为临界点数量（方法一）；O(1)（方法二）

## 关键点总结

1. 遍历时需要同时访问三个相邻节点（prev, curr, next）
2. 最大距离 = 最后临界点 - 第一临界点
3. 最小距离 = 相邻临界点间的最小差值

## 易错点

- 临界点是局部**极值**（比两侧都大或都小），不是单调
- 节点下标从 1 开始（头节点为下标 1）
- 少于 2 个临界点时返回 `[-1, -1]`
