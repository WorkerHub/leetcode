## 题目描述

与 3205 相同的跳跃规则，但数据范围更大：
- `2 <= nums.length <= 10^5`

每次从下标 `i` 跳到 `j`（`i < j`），得分 `(j - i) * nums[j]`。

返回从下标 `0` 跳到 `n-1` 的**最大总分**。

**提示：**
- `2 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

贪心 + 单调栈：

关键观察：最优路径只经过"后缀最大值"组成的单调递减序列。具体地，只需跳到那些比当前更大的元素。

用单调栈（从右到左维护单调递减序列），得到一系列关键节点。在这些节点上做贪心跳跃即可。

为什么贪心正确：如果跳过中间的某个较大节点而直接跳到更远处，中间这段的贡献会更小（因为跳过的节点更大，应该以它为目标）。

## Python 代码实现

### 方法一：单调栈贪心（推荐）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        # 从右到左构建单调递减栈（保存下标）
        # 只保留"有价值"的跳跃点：即从右往左单调递减的元素
        stack = []
        for i in range(n - 1, -1, -1):
            if not stack or nums[i] > nums[stack[-1]]:
                stack.append(i)
        stack.reverse()  # 从左到右，值单调递增
        
        # 贪心跳跃
        ans = 0
        prev = stack[0]  # 起点（应该是0）
        for k in range(1, len(stack)):
            j = stack[k]
            ans += (j - prev) * nums[j]
            prev = j
        
        return ans
```

### 方法二：直接单调栈（无需 reverse）

```python
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        # 找出所有后缀最大值的位置
        # 从右到左，维护一个单调递减栈
        suffix_max = []
        for i in range(n - 1, -1, -1):
            if not suffix_max or nums[i] >= nums[suffix_max[-1]]:
                suffix_max.append(i)
        
        # suffix_max 中从右到左是递增的位置，值是递减的
        # 我们需要从 0 开始跳到 n-1
        # 贪心：按顺序跳过 suffix_max 中的关键节点
        
        # 重新构建：保留从 0 开始能看到的所有"下一个更大"的节点
        suffix_max.reverse()  # 从左到右，值单调递增，位置递增
        
        ans = 0
        prev = 0
        for idx in suffix_max:
            ans += (idx - prev) * nums[idx]
            prev = idx
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，单调栈
- 空间复杂度：O(n)

## 关键点总结

1. 最优跳跃路径只经过"后缀最大值"节点
2. 单调栈从右到左维护递减序列，得到关键节点
3. 在关键节点之间贪心跳跃，累加得分

## 易错点

1. 单调栈的方向要搞清楚（从右到左，或从左到右）
2. 起点 0 必须包含在路径中，但不一定在单调栈中
