## 题目描述

给定一个非负整数数组 `nums`，每次操作可以选择一个子数组，将其中所有元素减少 1（前提是所有元素 >= 1，否则不能执行）。求将所有元素变为 0 的最少操作次数。

**示例 1：**

```
输入：nums = [1, 2, 1, 0]
输出：3
解释：
操作1: [1,2,1] -> [0,1,0,0]
操作2: [1] (第2个) -> [0,0,0,0]... 实际需要更仔细分析
```

**示例 2：**

```
输入：nums = [0, 0, 0]
输出：0
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 解题思路

这道题等价于"直方图中矩形的最少层数"问题。

关键观察：最少操作次数等于"相邻不同值的数量"或类似的单调栈计算。

具体来说，使用单调栈分析：对每个位置，比较当前值和前一个值，若当前值大于前一个值，则需要额外操作（对应直方图中的"新增层"）。

最少操作数 = 数组中"新增"（比前一个大）的部分之和（类似于 Histogram 问题）。

更精确：操作次数等于对数组取差分后，正差的总和（加上第一个非零元素）。

## Python 代码实现

### 方法一：差分 + 单调栈（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # 操作次数等于直方图的"层数"
        # 等价于：对 [0] + nums 取差分，正差分的和
        n = len(nums)
        ops = 0
        prev = 0

        for x in nums:
            if x > prev:
                ops += x - prev  # 新增的层数
            prev = x

        return ops
```

### 方法二：单调栈求解

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        stack = []  # 单调递增栈（存储高度）
        ops = 0

        for x in nums:
            # 弹出所有大于 x 的元素（它们的矩形在此截断）
            while stack and stack[-1] > x:
                stack.pop()
            # 若 x > 栈顶，说明有新的高度层
            if not stack or stack[-1] < x:
                ops += x - (stack[-1] if stack else 0)
                stack.append(x)
            # 若 x == 栈顶，不需要额外操作

        return ops
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(n)（方法二），O(1)（方法一）

## 关键点总结

1. 问题等价于直方图的层数统计
2. 只有当前值大于前一个值时，才需要增加操作数（差值为新增层数）
3. 差分数组中正值之和就是答案

## 易错点

1. 比较的是与前一个值的差（不是与 0 的差）
2. 第一个元素直接加到操作数（前置 0）
3. 值为 0 不需要操作
