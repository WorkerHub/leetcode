## 题目描述

给你两个正整数 `n` 和 `limit`。

将 `n` 颗糖果分给 3 个小朋友，每个小朋友至多获得 `limit` 颗糖果，求分配方案数。

**示例 1：**
```
输入：n = 5, limit = 2
输出：3
```

**示例 2：**
```
输入：n = 3, limit = 3
输出：10
```

**提示：**
- `1 <= n <= 10^6`
- `1 <= limit <= 10^6`

## 解题思路

n 和 limit 最大 10^6，暴力 O(n^2) 超时，需要更高效的方法。

枚举第一个小朋友的糖果数 a（从 0 到 min(n, limit)），对于固定 a，统计 b + c = n - a 且 b, c in [0, limit] 的方案数。

`b + c = m = n - a`，b 的范围：max(0, m - limit) <= b <= min(m, limit)。
方案数 = max(0, min(m, limit) - max(0, m - limit) + 1)。

整体 O(n) 枚举 a，加上上述 O(1) 计算，总时间 O(min(n, limit))。

## Python 代码实现

### 方法一：枚举一人（推荐）

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        ans = 0
        for a in range(min(n, limit) + 1):
            m = n - a  # 剩余给 b 和 c
            # b in [max(0, m-limit), min(m, limit)]
            lo = max(0, m - limit)
            hi = min(m, limit)
            if lo <= hi:
                ans += hi - lo + 1
        return ans
```

### 方法二：容斥公式 O(1)

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def C2(x: int) -> int:
            return x * (x - 1) // 2 if x >= 2 else 0

        return (C2(n + 2)
                - 3 * C2(n - limit + 1)
                + 3 * C2(n - 2 * limit)
                - C2(n - 3 * limit - 1))
```

## 复杂度分析

- 时间复杂度：O(min(n, limit))，方法一；O(1) 方法二
- 空间复杂度：O(1)

## 关键点总结

1. 固定一个人的分配，另外两人的方案数可以 O(1) 算出
2. 两数之和 = 固定值时，在各自有界约束下的方案数 = 有效范围长度
3. 容斥原理提供 O(1) 解法

## 易错点

1. lo > hi 时没有合法方案，需要检查
2. m - limit 可能为负，需用 max(0, m - limit)
3. 方案数 = hi - lo + 1（含端点）
