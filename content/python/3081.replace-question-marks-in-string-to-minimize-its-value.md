## 题目描述

给你一个字符串 `s`，其中包含小写字母和 `?` 字符。

定义字符串的"值"：对每个字符 `c`，其代价 = 在该字符左侧且小于 `c` 的不同字母的个数。字符串值 = 所有字符代价之和。

用小写字母替换所有 `?`，使字符串值最小，若有多种方案返回字典序最小的。

**提示：**
- `1 <= s.length <= 10^5`

## 解题思路

贪心：每个 `?` 替换为什么字母，使总代价最小。

**关键观察：** 字符 `c` 的代价是其左侧出现过的比 `c` 小的不同字母个数。这意味着每个字母应尽量少出现，且出现频率低的字母的代价更低。

**最优策略：** 用频率最低的字母替换 `?`（因为频率最低的字母在左侧出现最少，代价最小）。若有多个频率最低的字母，选字典序最小的。

具体步骤：
1. 统计已有字母的频率
2. `?` 的数量 = n - 非问号字符数
3. 贪心地从频率低的字母开始分配（尽量使用频率最低的字母填充 `?`）
4. 用最小堆按 (频率, 字母) 排序，每次取出频率最低的字母分配给 `?`

## Python 代码实现

### 方法一：贪心最小堆（推荐）

```python
from collections import Counter
import heapq

class Solution:
    def minimizeStringValue(self, s: str) -> str:
        # 统计已有字母频率
        freq = Counter(c for c in s if c != '?')
        q_count = s.count('?')

        # 用最小堆按频率从低到高分配字母
        heap = [(freq.get(chr(ord('a') + i), 0), chr(ord('a') + i)) for i in range(26)]
        heapq.heapify(heap)

        # 为每个 ? 分配字母
        assignments = []
        for _ in range(q_count):
            cnt, ch = heapq.heappop(heap)
            assignments.append(ch)
            heapq.heappush(heap, (cnt + 1, ch))

        # 字典序最小：对分配的字母排序
        assignments.sort()

        # 将字母按顺序填入 ?
        result = list(s)
        ptr = 0
        for i, c in enumerate(result):
            if c == '?':
                result[i] = assignments[ptr]
                ptr += 1

        return ''.join(result)
```

### 方法二：排序后填入

```python
from collections import Counter
import heapq

class Solution:
    def minimizeStringValue(self, s: str) -> str:
        freq = Counter(c for c in s if c != '?')
        q_count = s.count('?')

        # 为每个 ? 贪心选择当前最低频字母
        heap = [(freq.get(c, 0), c) for c in 'abcdefghijklmnopqrstuvwxyz']
        heapq.heapify(heap)

        chosen = []
        for _ in range(q_count):
            f, c = heapq.heappop(heap)
            chosen.append(c)
            heapq.heappush(heap, (f + 1, c))

        # 为让字符串字典序最小，将选定字母排序后按顺序放入 ?
        chosen.sort()

        res = list(s)
        idx = 0
        for i in range(len(res)):
            if res[i] == '?':
                res[i] = chosen[idx]
                idx += 1

        return ''.join(res)
```

## 复杂度分析

- 时间复杂度：O(n + q * log 26) = O(n)，q 为 ? 数量，log 26 = O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：每次将 ? 替换为当前频率最低的字母（代价最小）
2. 多个 ? 的分配结果排序后依次填入，保证字典序最小
3. 最小堆高效获取当前频率最低的字母

## 易错点

1. 贪心分配后必须将字母**排序**再按顺序填入 ?，这样字典序最小
2. 堆按 `(频率, 字母)` 排序，频率相同时字母字典序小的优先
