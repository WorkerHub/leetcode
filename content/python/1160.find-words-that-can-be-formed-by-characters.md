## 题目描述

给定一个单词数组 `words` 和一个字符串 `chars`。

如果一个单词可以由 `chars` 中的字符构成(每个字符只能使用一次),我们就说这个单词是好单词。

返回所有好单词的长度之和。

**示例 1:**

```
输入: words = ["cat","bt","hat","tree"], chars = "atach"
输出: 6
解释: 
可以形成的单词是 "cat" 和 "hat",长度之和为 3 + 3 = 6
```

**示例 2:**

```
输入: words = ["hello","world","leetcode"], chars = "welldonehoneyr"
输出: 10
解释: 
可以形成的单词是 "hello" 和 "world",长度之和为 5 + 5 = 10
注意 "leetcode" 不能形成,因为 chars 中只有一个 'l'
```

**提示:**
- `1 <= words.length <= 1000`
- `1 <= words[i].length, chars.length <= 100`
- 所有字符串都只包含小写英文字母

## 解题思路

这道题的核心是判断每个单词是否可以由 `chars` 中的字符组成。

**关键点:**
1. 统计 `chars` 中每个字符的出现次数
2. 对于每个单词,检查其每个字符在 `chars` 中的数量是否足够
3. 如果可以构成,累加单词长度

**解法步骤:**
1. 使用哈希表(或数组)统计 `chars` 中各字符的频次
2. 遍历每个单词:
   - 统计单词中各字符的频次
   - 比较单词字符频次和 `chars` 字符频次
   - 如果单词的所有字符频次都不超过 `chars`,则是好单词
3. 累加所有好单词的长度

## Python 代码实现

### 方法一: 哈希表计数(推荐)

```python
from typing import List
from collections import Counter

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        """
        使用 Counter 统计字符频次并比较
        """
        # 统计 chars 中每个字符的数量
        char_count = Counter(chars)
        total_length = 0
        
        for word in words:
            # 统计当前单词中每个字符的数量
            word_count = Counter(word)
            
            # 检查单词是否可以由 chars 构成
            # 方法: 检查单词中每个字符的数量是否不超过 chars 中的数量
            can_form = True
            for char, count in word_count.items():
                if count > char_count[char]:
                    can_form = False
                    break
            
            # 如果可以构成,累加长度
            if can_form:
                total_length += len(word)
        
        return total_length
```

### 方法二: 使用 Counter 的减法操作

```python
from typing import List
from collections import Counter

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        """
        使用 Counter 的减法,更简洁
        """
        char_count = Counter(chars)
        total_length = 0
        
        for word in words:
            word_count = Counter(word)
            # Counter 相减,如果结果中没有正数,说明可以构成
            # word_count - char_count 会保留正数部分
            if not (word_count - char_count):
                total_length += len(word)
        
        return total_length
```

### 方法三: 数组计数

```python
from typing import List

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        """
        使用数组统计,空间效率更高
        """
        # 统计 chars 中每个字符的数量(使用长度为26的数组)
        char_count = [0] * 26
        for ch in chars:
            char_count[ord(ch) - ord('a')] += 1
        
        total_length = 0
        
        for word in words:
            # 统计当前单词中每个字符的数量
            word_count = [0] * 26
            for ch in word:
                word_count[ord(ch) - ord('a')] += 1
            
            # 检查是否可以构成
            can_form = True
            for i in range(26):
                if word_count[i] > char_count[i]:
                    can_form = False
                    break
            
            if can_form:
                total_length += len(word)
        
        return total_length
```

### 方法四: 最简洁写法

```python
from typing import List
from collections import Counter

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        """
        一行流写法
        """
        char_count = Counter(chars)
        return sum(len(word) for word in words 
                   if not (Counter(word) - char_count))
```

## 复杂度分析

**时间复杂度**: O(n * m)
- n 为单词数量
- m 为平均单词长度(或 chars 长度)
- 需要遍历每个单词并统计字符频次

**空间复杂度**: O(1)
- 使用的额外空间是常数级的(最多26个字母)
- Counter 或数组的大小都不超过 26

## 关键点总结

1. 使用哈希表或数组统计字符频次
2. Counter 的减法操作: `Counter(a) - Counter(b)` 保留正数部分
3. 只有当单词的所有字符频次都不超过 chars 时才能构成
4. Python 的 Counter 提供了便捷的字符计数功能
5. 注意每个字符只能使用一次,需要比较频次而不是简单的包含关系

## 易错点

1. 忘记比较字符频次,只检查字符是否存在
2. 认为字符可以重复使用(实际上每个字符只能用一次)
3. 混淆"好单词"的定义: 是单词可以由 chars 组成,不是 chars 可以组成单词
4. 忘记累加单词长度,而不是单词数量
5. Counter 减法的理解错误
