## 题目描述

有 `n` 个城市，连通道路 `roads[i] = [u, v, cost]`（双向），苹果价格为 `appleCost[i]`（在城市 i 购买）。从城市 `k` 出发，可以驱车到任意城市购买苹果，返回时花费路程的 `k` 倍（往返代价）。

对每个城市，返回从该城市出发购买苹果的最小总代价。

**示例 1：**

```
输入：n = 4, roads = [[0,1,4],[0,2,2],[2,3,3]], appleCost = [56,42,102,150], k = 2
输出：[54,42,102,150]
```

**提示：**

- `2 <= n <= 10^5`
- `1 <= k <= 100`

## 解题思路

对每个出发城市 `s`，最小代价 = `min(appleCost[t] + dist(s, t) * (1 + k))` for all t。

其中 `(1 + k)` 是因为去程 1 倍 + 回程 k 倍。

等价于：在图上运行 Dijkstra，但权重变为边权 * (1 + k)，然后对每个城市 t，考虑以 `appleCost[t]` 为初始代价的多源最短路。

多源 Dijkstra：将每个城市 t 以 `appleCost[t]` 为初始距离加入优先队列，求到所有城市的最短距离。

## Python 代码实现

### 方法一：多源 Dijkstra（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minCost(self, n: int, roads: List[List[int]],
                appleCost: List[int], k: int) -> List[int]:
        graph = defaultdict(list)
        for u, v, w in roads:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # 多源 Dijkstra：每个城市作为源点，初始距离为 appleCost[i]
        dist = list(appleCost)
        heap = [(appleCost[i], i) for i in range(n)]
        heapq.heapify(heap)

        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for v, w in graph[u]:
                # 往返代价：路程 * (1 + k)
                nd = d + w * (1 + k)
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        return dist
```

### 方法二：对每个城市单独 Dijkstra（暴力）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minCost(self, n: int, roads: List[List[int]],
                appleCost: List[int], k: int) -> List[int]:
        graph = defaultdict(list)
        for u, v, w in roads:
            graph[u].append((v, w))
            graph[v].append((u, w))

        def dijkstra(src):
            dist = [float('inf')] * n
            dist[src] = 0
            heap = [(0, src)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in graph[u]:
                    if d + w < dist[v]:
                        dist[v] = d + w
                        heapq.heappush(heap, (d + w, v))
            return [appleCost[t] + dist[t] * (1 + k) for t in range(n)]

        result = []
        for s in range(n):
            result.append(min(dijkstra(s)))  # 对每个出发城市
        return result
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)（多源 Dijkstra），O(V * (V + E) log V)（暴力）
- 空间复杂度：O(V + E)

## 关键点总结

1. 多源 Dijkstra：将所有"购买点"作为虚拟源点
2. 往返代价 = 路程 * (1 + k)
3. 多源 Dijkstra 时间复杂度与单源相同

## 易错点

1. 往返是 1 倍去程 + k 倍回程 = (1+k) 倍路程
2. 多源 Dijkstra 初始化：每个城市以 appleCost 为初始距离
3. 优先队列中的比较确保最小距离优先处理
