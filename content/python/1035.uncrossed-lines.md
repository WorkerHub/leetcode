## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，我们在两条独立的水平线上按给定顺序写下 `nums1` 和 `nums2` 中的整数。

现在，我们可以绘制一些连接两个数字 `nums1[i]` 和 `nums2[j]` 的直线，这些直线需要同时满足：

- `nums1[i] == nums2[j]`
- 且绘制的直线不与任何其他连线（非水平线）相交

请注意，连线即使在端点也不能相交：每个数字只能属于一条连线。

以这种方法绘制线条，并返回可以绘制的最大连线数。

**示例 1：**
```
输入：nums1 = [1,4,2], nums2 = [1,2,4]
输出：2
解释：可以画出两条不交叉的线，如下所示：
我们无法画出第三条不相交的直线，因为从 nums1[1]=4 到 nums2[2]=4 的直线将与从 nums1[2]=2 到 nums2[1]=2 的直线相交。
```

**示例 2：**
```
输入：nums1 = [2,5,1,2,5], nums2 = [10,5,2,1,5,2]
输出：3
```

**示例 3：**
```
输入：nums1 = [1,3,7,1,7,5], nums2 = [1,9,2,5,1]
输出：2
```

**提示：**
- `1 <= nums1.length, nums2.length <= 500`
- `1 <= nums1[i], nums2[j] <= 2000`

## 解题思路

这道题的关键洞察是：**求不相交的连线的最大数量，等价于求两个数组的最长公共子序列（LCS）**。

**为什么等价？**

1. 如果两条线相交，说明它们在两个数组中的相对顺序是相反的
2. 要保证线不相交，就必须保证匹配的元素在两个数组中的相对顺序一致
3. 这正是最长公共子序列的定义

**动态规划思路：**

定义 `dp[i][j]` 表示 `nums1[0:i]` 和 `nums2[0:j]` 之间的最大连线数。

状态转移方程：
- 如果 `nums1[i-1] == nums2[j-1]`，则 `dp[i][j] = dp[i-1][j-1] + 1`（可以连一条线）
- 否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（从之前的状态继承）

边界条件：
- `dp[0][j] = 0`（nums1 为空）
- `dp[i][0] = 0`（nums2 为空）

## Python 代码实现

### 方法一：二维 DP（标准解法）

```python
from typing import List

class Solution:
    def maxUncrossedLines(self, nums1: List[int], nums2: List[int]) -> int:
        """
        使用二维 DP 求最长公共子序列
        
        Args:
            nums1: 第一个整数数组
            nums2: 第二个整数数组
            
        Returns:
            最大连线数
        """
        m, n = len(nums1), len(nums2)
        
        # 创建 DP 表，dp[i][j] 表示 nums1[0:i] 和 nums2[0:j] 的最大连线数
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 填充 DP 表
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    # 当前元素相等，可以连线
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 当前元素不等，继承之前的最大值
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        
        return dp[m][n]
```

### 方法二：空间优化的一维 DP

```python
from typing import List

class Solution:
    def maxUncrossedLines(self, nums1: List[int], nums2: List[int]) -> int:
        """
        使用滚动数组优化空间复杂度
        
        Args:
            nums1: 第一个整数数组
            nums2: 第二个整数数组
            
        Returns:
            最大连线数
        """
        m, n = len(nums1), len(nums2)
        
        # 只保留上一行和当前行
        dp = [0] * (n + 1)
        
        for i in range(1, m + 1):
            prev = 0  # 记录 dp[i-1][j-1]
            for j in range(1, n + 1):
                temp = dp[j]  # 保存 dp[i-1][j]
                if nums1[i - 1] == nums2[j - 1]:
                    dp[j] = prev + 1
                else:
                    dp[j] = max(dp[j], dp[j - 1])
                prev = temp  # 更新 prev 为下一次的 dp[i-1][j-1]
        
        return dp[n]
```

### 方法三：记忆化递归

```python
from typing import List
from functools import lru_cache

class Solution:
    def maxUncrossedLines(self, nums1: List[int], nums2: List[int]) -> int:
        """
        使用记忆化递归求解
        
        Args:
            nums1: 第一个整数数组
            nums2: 第二个整数数组
            
        Returns:
            最大连线数
        """
        @lru_cache(maxsize=None)
        def dfs(i: int, j: int) -> int:
            """
            返回 nums1[i:] 和 nums2[j:] 的最大连线数
            """
            # 边界条件：任一数组为空
            if i == len(nums1) or j == len(nums2):
                return 0
            
            # 如果当前元素相等，可以连线
            if nums1[i] == nums2[j]:
                return dfs(i + 1, j + 1) + 1
            
            # 否则尝试跳过一个元素
            return max(dfs(i + 1, j), dfs(i, j + 1))
        
        return dfs(0, 0)
```

## 复杂度分析

### 方法一：二维 DP
- **时间复杂度**：O(m × n)，其中 m 和 n 分别是两个数组的长度，需要填充整个 DP 表
- **空间复杂度**：O(m × n)，需要存储整个 DP 表

### 方法二：一维 DP
- **时间复杂度**：O(m × n)，时间复杂度不变
- **空间复杂度**：O(n)，只需要一维数组

### 方法三：记忆化递归
- **时间复杂度**：O(m × n)，每个状态只计算一次
- **空间复杂度**：O(m × n)，递归栈和缓存的空间

## 关键点总结

1. **问题转化**：不相交连线问题等价于最长公共子序列（LCS）问题
2. **状态定义**：`dp[i][j]` 表示前 i 个和前 j 个元素的最大连线数
3. **状态转移**：根据当前元素是否相等进行转移
4. **空间优化**：可以用滚动数组将空间优化到 O(n)
5. **本质理解**：连线不相交 ⇔ 匹配顺序一致 ⇔ 公共子序列

## 易错点

1. **索引问题**：DP 数组从 1 开始，访问 nums 时要减 1
2. **边界条件**：空数组的情况要正确初始化为 0
3. **问题理解**：要理解为什么等价于 LCS，而不是简单的贪心匹配
4. **空间优化时的变量保存**：使用一维数组时要注意保存 `dp[i-1][j-1]` 的值
