## 题目描述

一个二进制字符串是单调递增的，如果它包含若干个 0（可能没有），后面跟着若干个 1（也可能没有）。

给你一个二进制字符串 `s`，你可以将任意 `s[i]` 从 0 翻转为 1 或从 1 翻转为 0。

返回使 `s` 单调递增的最小翻转次数。

**示例 1：**
```
输入：s = "00110"
输出：1
解释：翻转最后一位得到 00111
```

**示例 2：**
```
输入：s = "010110"
输出：2
解释：翻转得到 011111，或者 000111
```

**示例 3：**
```
输入：s = "00011000"
输出：2
解释：翻转得到 00000000
```

**提示：**
- `1 <= s.length <= 20000`
- `s` 只包含字符 `'0'` 和 `'1'`

## 解题思路

这道题要求将二进制字符串变成单调递增（形如 `000...111` 的形式），关键观察是：最终的字符串会有一个分界点，分界点之前全是 0，分界点之后全是 1。

我们有两种主要的思路：

**思路1：枚举分界点**
- 对于每个位置 i，假设它是分界点（i 之前都是 0，i 及之后都是 1）
- 计算需要翻转的次数：i 之前的 1 的个数 + i 之后的 0 的个数
- 取所有可能的最小值

**思路2：动态规划**
- 定义状态：扫描到第 i 个字符时
  - `dp0`：将前 i 个字符变成全 0 需要的翻转次数
  - `dp1`：将前 i 个字符变成单调递增需要的翻转次数
- 状态转移：
  - 如果 `s[i] == '0'`：
    - `dp0` 不变（不需要翻转）
    - `dp1 = min(dp0, dp1) + 1`（翻转成 1）
  - 如果 `s[i] == '1'`：
    - `dp0 += 1`（翻转成 0）
    - `dp1 = min(dp0, dp1)`（保持为 1）

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
class Solution:
    def minFlipsMonoIncr(self, s: str) -> int:
        # dp0: 当前位置之前全变成0的翻转次数
        # dp1: 当前位置之前变成单调递增的最小翻转次数
        dp0, dp1 = 0, 0
        
        for char in s:
            if char == '0':
                # 遇到0，保持全0不需要翻转
                # 如果要单调递增，需要把0翻转成1
                dp0, dp1 = dp0, min(dp0, dp1) + 1
            else:  # char == '1'
                # 遇到1，全变成0需要翻转这个1
                # 单调递增可以保持这个1，取之前的最小值
                dp0, dp1 = dp0 + 1, min(dp0, dp1)
        
        return dp1
```

**时间复杂度**：O(n)，只需遍历一次字符串  
**空间复杂度**：O(1)，只用了两个变量

### 方法二：前缀和（枚举分界点）

```python
class Solution:
    def minFlipsMonoIncr(self, s: str) -> int:
        n = len(s)
        # 计算每个位置右侧0的个数（包含当前位置）
        zeros_right = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            zeros_right[i] = zeros_right[i + 1] + (1 if s[i] == '0' else 0)
        
        # 枚举每个分界点
        ones_left = 0  # 左侧1的个数
        min_flips = float('inf')
        
        for i in range(n + 1):
            # 分界点在i：左侧全0，右侧全1
            # 需要翻转：左侧的1 + 右侧的0
            min_flips = min(min_flips, ones_left + zeros_right[i])
            if i < n and s[i] == '1':
                ones_left += 1
        
        return min_flips
```

**时间复杂度**：O(n)  
**空间复杂度**：O(n)，需要额外数组存储右侧0的个数

### 方法三：简化版DP（计数法）

```python
class Solution:
    def minFlipsMonoIncr(self, s: str) -> int:
        # ones: 当前位置之前1的个数
        # flips: 到当前位置的最小翻转次数
        ones = 0
        flips = 0
        
        for char in s:
            if char == '1':
                ones += 1
            else:
                # 遇到0有两种选择：
                # 1. 把这个0翻转成1：flips + 1
                # 2. 把之前所有的1都翻转成0：ones
                flips = min(flips + 1, ones)
        
        return flips
```

**时间复杂度**：O(n)  
**空间复杂度**：O(1)

## 复杂度分析

三种方法的时间复杂度都是 O(n)，但：
- 方法一和方法三空间复杂度为 O(1)，更优
- 方法二需要 O(n) 的额外空间
- 推荐使用方法一或方法三，代码简洁且高效

## 关键点总结

1. **单调递增的本质**：字符串可以分为前半部分的 0 和后半部分的 1
2. **动态规划状态设计**：维护两个状态（全0 和 单调递增）
3. **状态转移的逻辑**：根据当前字符是 0 还是 1 做不同处理
4. **空间优化**：只需要两个变量，不需要数组
5. **贪心思想**：每次遇到 0 时，选择翻转它或翻转之前的 1

## 易错点

1. **边界情况**：字符串全是 0 或全是 1 的情况（返回 0）
2. **状态更新顺序**：需要同时更新两个状态，注意使用元组赋值
3. **理解 min(dp0, dp1)**：表示选择在当前位置之前或之后作为分界点
4. **方法三的逻辑**：遇到 0 时比较翻转当前 0 和翻转之前所有 1 的代价
