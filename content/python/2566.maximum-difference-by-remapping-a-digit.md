## 题目描述

给你一个整数 `num`，你可以把 `num` 中的某个数字 d1（0 到 9）映射为另一个数字 d2（0 到 9），使得 `num` 中所有出现 d1 的地方都替换为 d2。

找出最大值和最小值（两次独立的映射操作），返回 **最大值 - 最小值**。

**注意：** 可以将数字映射到自身（不改变），映射后不考虑前导零。

**示例 1：**

```
输入：num = 11891
输出：99009
解释：
- 最大：将 1 → 9，得 99899（或将某数字为 9）... 最优为将 1 → 9，得 99899
- 最小：将 1 → 0，得 00890 = 890，但需更优... 将 9 → 0 得 11001，将 1 → 0 得 00890 = 890
- 差 = 99899 - 890 = 99009
```

**提示：**

- `1 <= num <= 10^8`

## 解题思路

**最大化**：将最高位的非 9 数字映射为 9（贪心，替换第一个非 9 的数字）。

**最小化**：将最高位数字映射为 0（不管前导零，最终数值最小）。即把 `num` 的首位数字全部替换为 0。

## Python 代码实现

### 方法一：贪心字符串替换（推荐）

```python
class Solution:
    def minMaxDifference(self, num: int) -> int:
        s = str(num)

        # 最大化：找第一个不是 9 的数字，全部替换为 9
        max_val = num
        for ch in s:
            if ch != '9':
                max_val = int(s.replace(ch, '9'))
                break

        # 最小化：将首位数字全部替换为 0
        min_val = int(s.replace(s[0], '0'))

        return max_val - min_val
```

### 方法二：枚举所有映射

```python
class Solution:
    def minMaxDifference(self, num: int) -> int:
        s = str(num)
        results = []

        for d1 in '0123456789':
            for d2 in '0123456789':
                # 将 d1 替换为 d2
                new_s = s.replace(d1, d2)
                results.append(int(new_s))

        return max(results) - min(results)
```

## 复杂度分析

- 方法一时间复杂度：O(d)，d 为数字位数（最多 9 位）
- 方法二时间复杂度：O(100 * d)，枚举所有映射
- 空间复杂度：O(d)，字符串操作

## 关键点总结

1. 最大化：贪心将第一个非 9 的数字替换为 9
2. 最小化：将首位数字替换为 0，得到最小非负整数
3. `str.replace()` 一次性替换所有出现位置

## 易错点

1. 最大化时要找第一个非 9 的数字替换（不是最高位）
2. 最小化时替换首位为 0，可能产生前导零（Python int 转换自动去除）
3. 映射是全局的，所有相同数字都被替换
