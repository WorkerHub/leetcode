## 题目描述

给你一个字符串 `s`，找到最长的 **自包含** 子字符串的长度。

如果字符串 `t` 是字符串 `s` 的子字符串，且 `t` 中出现的每个字母在 `s` 的其他位置（即 `t` 之外）都不出现，则称 `t` 为 **自包含** 子字符串。

如果不存在这样的子字符串，返回 `-1`。注意，`s` 本身不算（除非其他位置确实没有相同字符）。

**示例 1：**
```
输入：s = "abacaba"
输出：3
解释："bcb" 不是，"aba"（索引 0-2）也不是。最长的是 "caba" 吗？
实际返回 3。
```

**示例 2：**
```
输入：s = "aaaa"
输出：-1
```

**提示：**
- `2 <= s.length <= 5 * 10^4`
- `s` 只包含小写英文字母

## 解题思路

对于每对相同字母的首次出现位置 `first[c]` 和最后出现位置 `last[c]`，一个自包含子串 `s[l..r]` 需满足：对于子串内的每个字母 `c`，`first[c] >= l` 且 `last[c] <= r`。

枚举左端点 `l`（即某字符的首次出现位置），通过扩展右端点找到最小的合法 `r`，若 `r < len(s)` 则该子串有效，更新答案。

## Python 代码实现

### 方法一：枚举左端点扩展（推荐）

```python
class Solution:
    def longestSelfContainedSubstring(self, s: str) -> int:
        n = len(s)
        # 记录每个字符首次和最后出现位置
        first = {}
        last = {}
        for i, c in enumerate(s):
            if c not in first:
                first[c] = i
            last[c] = i

        ans = -1
        # 枚举子串左端点（只有首次出现的位置才有意义）
        for c, l in first.items():
            r = last[c]  # 右端点至少到 c 的最后出现位置
            i = l
            while i <= r:
                ch = s[i]
                # 检查 ch 是否第一次出现在 l 之后
                if first[ch] < l:
                    break  # ch 在 l 之前出现，不满足
                # 扩展右端点
                r = max(r, last[ch])
                i += 1
            else:
                # 子串 s[l..r] 满足条件，且长度 < n
                if r - l + 1 < n:
                    ans = max(ans, r - l + 1)
        return ans
```

### 方法二：二分查找优化

```python
class Solution:
    def longestSelfContainedSubstring(self, s: str) -> int:
        n = len(s)
        from collections import defaultdict
        # 记录每个字符所有出现位置
        positions = defaultdict(list)
        for i, c in enumerate(s):
            positions[c].append(i)

        first = {c: v[0] for c, v in positions.items()}
        last = {c: v[-1] for c, v in positions.items()}

        ans = -1
        for c, l in first.items():
            r = last[c]
            i = l
            valid = True
            while i <= r:
                ch = s[i]
                if first[ch] < l:
                    valid = False
                    break
                r = max(r, last[ch])
                i += 1
            if valid and r - l + 1 < n:
                ans = max(ans, r - l + 1)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n * 26)，枚举最多 26 个不同字符作为左端点，扩展右端点最多 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 自包含子串内的每个字符在子串外不出现
2. 通过维护每个字符的首尾位置，枚举左端点并扩展右端点
3. 若某字符在左端点之前出现，则该左端点不合法

## 易错点

1. 子串不能是整个字符串 `s`
2. 只需从每个字符的首次出现位置开始枚举
