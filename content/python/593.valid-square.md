## 题目描述

给定2D空间中四个点的坐标 `p1`, `p2`, `p3`, `p4`，如果这四个点构成一个正方形，返回 `true`。

**示例：**
```
输入：p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,1]
输出：true
```

**提示：**
- `p1.length == p2.length == p3.length == p4.length == 2`
- `-10^4 <= xi, yi <= 10^4`

## Python 代码实现

```python
from typing import List

class Solution:
    def validSquare(self, p1: List[int], p2: List[int], p3: List[int], p4: List[int]) -> bool:
        """
        计算所有边的距离平方
        正方形：4条边相等，2条对角线相等
        
        时间复杂度：O(1)
        空间复杂度：O(1)
        """
        def dist_sq(p, q):
            return (p[0] - q[0])**2 + (p[1] - q[1])**2
        
        # 计算所有6条边的距离平方
        distances = [
            dist_sq(p1, p2), dist_sq(p1, p3), dist_sq(p1, p4),
            dist_sq(p2, p3), dist_sq(p2, p4), dist_sq(p3, p4)
        ]
        
        distances.sort()
        
        # 正方形：前4个距离相等（边），后2个相等（对角线）
        # 且边不为0
        return (distances[0] > 0 and
                distances[0] == distances[1] == distances[2] == distances[3] and
                distances[4] == distances[5] and
                distances[3] * 2 == distances[4])
```

## 关键点总结

1. **距离计算**：使用距离平方避免浮点数
2. **排序判断**：排序后检查4条边和2条对角线
3. **边界情况**：边长不能为0
