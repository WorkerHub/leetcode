## 题目描述

给你三个正整数 `a`、`b`、`c`，返回**单因子三元组**的数目。

若三元组 `(i, j, k)` 满足：
- `1 <= i <= a`，`1 <= j <= b`，`1 <= k <= c`
- `a + b + c` 整除 `i + j + k` **恰好一次**（即恰好有一个变量整除 `i + j + k`）

则称其为单因子三元组。

**注意**：这是一道会员题，以下是题目的理解和实现。

单因子三元组 `(i, j, k)` 满足：在 `a | (i+j+k)`、`b | (i+j+k)`、`c | (i+j+k)` 中，恰好有且仅有一个成立。

**提示：**
- `1 <= a, b, c <= 100`

## 解题思路

**枚举 + 整除判断**

数据范围 a, b, c <= 100，总三元组数最多 100^3 = 10^6，直接枚举即可。

对每个 `(i, j, k)`，计算 `s = i + j + k`，统计 `a | s`、`b | s`、`c | s` 中有多少个成立，若恰好为 1 则计数。

## 代码实现

### 方法一：直接枚举（推荐）

```python
class Solution:
    def singleDivisorTriplet(self, a: int, b: int, c: int) -> int:
        count = 0
        for i in range(1, a + 1):
            for j in range(1, b + 1):
                for k in range(1, c + 1):
                    s = i + j + k
                    # 统计有多少个变量整除 s
                    divides = (s % a == 0) + (s % b == 0) + (s % c == 0)
                    if divides == 1:
                        count += 1
        return count
```

### 方法二：数学优化（按余数分组）

```python
class Solution:
    def singleDivisorTriplet(self, a: int, b: int, c: int) -> int:
        # 预计算 1..a 中各 mod a 的频次，以此类推
        from collections import Counter

        def get_mod_count(n):
            cnt = Counter()
            for x in range(1, n + 1):
                cnt[x % n] += 1
            return cnt

        cnt_a = get_mod_count(a)
        cnt_b = get_mod_count(b)
        cnt_c = get_mod_count(c)

        count = 0
        for ra in range(a):
            for rb in range(b):
                for rc in range(c):
                    # 对应的 s mod a/b/c
                    s_mod_a = (ra + rb + rc) % a
                    s_mod_b = (ra + rb + rc) % b
                    s_mod_c = (ra + rb + rc) % c
                    divides = (s_mod_a == 0) + (s_mod_b == 0) + (s_mod_c == 0)
                    if divides == 1:
                        count += cnt_a[ra] * cnt_b[rb] * cnt_c[rc]
        return count
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(a * b * c) | O(1) |
| 数学优化 | O(a * b * c) | O(a + b + c) |

在 a, b, c <= 100 的限制下，两种方法都可接受。

## 关键点总结

1. 整除判断：`s % a == 0` 表示 `a | s`。
2. 恰好有一个整除：用三个布尔值相加 == 1 来判断。
3. 数据范围小，暴力枚举是最稳妥的方法。

## 易错点

- 三个条件互相独立，可能 0 个、1 个、2 个或 3 个整除 `s`，要恰好 == 1。
- `i, j, k` 的范围分别是 `[1, a]`、`[1, b]`、`[1, c]`，不是 `[0, ...]`。
