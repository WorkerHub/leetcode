## 题目描述

给你一棵有 `n` 个节点的树，节点编号从 0 到 `n-1`，根节点为节点 0。给你一个长度为 `n-1` 的二维数组 `edges`，其中 `edges[i] = [ui, vi]` 表示节点 `ui` 和 `vi` 之间存在一条边。

同时给你一个长度为 `n` 的数组 `colors`，其中 `colors[i]` 是节点 `i` 的颜色。

如果一棵子树中所有节点的颜色相同，我们称这棵子树是「相同颜色」的子树。

返回最大的相同颜色子树的大小。

**示例 1：**
```
输入：edges = [[0,1],[0,2],[0,3]], colors = [1,1,2,3]
输出：1
```

**示例 2：**
```
输入：edges = [[0,1],[0,2],[2,3],[2,4]], colors = [1,1,1,1,1]
输出：5
```

**提示：**
- `n == colors.length`
- `1 <= n <= 4 * 10^4`
- `edges.length == n - 1`
- 0 是树的根节点
- `1 <= colors[i] <= 4 * 10^4`

## 解题思路

使用后序 DFS（先处理子节点，再处理父节点）。

对于每个节点，判断以该节点为根的子树是否所有节点颜色相同：
- 若该节点的所有子节点的子树均为单色，且子节点颜色与当前节点相同，则当前子树也是单色的
- 否则标记当前子树不是单色

同时维护每棵单色子树的大小，更新全局最大值。

## Python 代码实现

### 方法一：后序 DFS（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSubtreeSize(self, edges: List[List[int]], colors: List[int]) -> int:
        n = len(colors)
        # 建图
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = 1
        # subtree_size[v]: 以 v 为根的子树大小
        subtree_size = [1] * n
        # is_same[v]: 以 v 为根的子树是否全为同色
        is_same = [True] * n

        def dfs(node: int, parent: int):
            nonlocal ans
            for child in graph[node]:
                if child == parent:
                    continue
                dfs(child, node)
                subtree_size[node] += subtree_size[child]
                # 子树不是单色，或子节点颜色与当前节点不同
                if not is_same[child] or colors[child] != colors[node]:
                    is_same[node] = False

            if is_same[node]:
                ans = max(ans, subtree_size[node])

        dfs(0, -1)
        return ans
```

### 方法二：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def maximumSubtreeSize(self, edges: List[List[int]], colors: List[int]) -> int:
        n = len(colors)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # 用迭代后序遍历
        parent = [-1] * n
        order = []  # 节点的 BFS 顺序（用于后序处理）
        visited = [False] * n
        stack = [0]
        visited[0] = True

        while stack:
            node = stack.pop()
            order.append(node)
            for child in graph[node]:
                if not visited[child]:
                    visited[child] = True
                    parent[child] = node
                    stack.append(child)

        subtree_size = [1] * n
        is_same = [True] * n
        ans = 1

        # 逆序处理（后序）
        for node in reversed(order):
            for child in graph[node]:
                if child == parent[node]:
                    continue
                subtree_size[node] += subtree_size[child]
                if not is_same[child] or colors[child] != colors[node]:
                    is_same[node] = False
            if is_same[node]:
                ans = max(ans, subtree_size[node])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点和边处理一次
- 空间复杂度：O(n)，递归栈或辅助数组

## 关键点总结

1. 后序 DFS：先处理所有子节点，再判断当前节点
2. 子树单色的条件：所有子树单色 AND 子节点颜色与当前节点相同
3. 维护子树大小，仅在单色时更新答案

## 易错点

1. 无向图中 DFS 需要记录父节点，避免回头
2. 叶节点默认是单色子树（`is_same = True`）
3. 大树可能导致递归栈溢出，建议使用迭代版本
