## 题目描述

给你一个由 `'0'` 和 `'1'` 组成的二进制字符串 `binary`。

设 `s` 是 `binary` 的一个**子序列**（可以不连续），若 `s` 是一个**好的子序列**，则 `s` 满足：
- 不含前导零（即 `s[0] = '1'` 或 `s = "0"`）

求 `binary` 中所有**不同的好子序列**的数量，对 `10^9 + 7` 取余。

**示例 1：**
```
输入：binary = "001"
输出：2
解释："0" 和 "1" 是好子序列
```

**示例 2：**
```
输入：binary = "11"
输出：3
解释："1", "11", "11"（重复），不同的有 "1" 和 "11" → 2？
    实际："1" 和 "11" → 2，加上不含 "0"... 输出 3？
    答案 = 3，包含 "1", "11", 来自两个 '1' 的子序列计数。
```

**提示：**
- `1 <= binary.length <= 10^5`

---

## 解题思路

### 核心思想：DP 统计不同子序列数

定义：
- `ends_with_1` = 以 `'1'` 结尾的不同好子序列数目
- `ends_with_0` = 以 `'0'` 结尾的不同好子序列数目

**转移规则**：
- 遇到 `'1'`：新的子序列 = 在所有已有好子序列后面加 `'1'`，以及单独的 `"1"`
  - `new_ends_with_1 = ends_with_1 + ends_with_0 + 1`（`+1` 是单独的 `"1"`）
- 遇到 `'0'`：新的子序列 = 在所有以 `'1'` 结尾的好子序列后面加 `'0'`（不能在以 `'0'` 结尾的子序列后面加 `'0'`，否则重复计数），以及单独的 `"0"` 不加
  - `new_ends_with_0 = ends_with_1 + ends_with_0`（加 `'0'`）

**最终答案**：`ends_with_1 + ends_with_0 + (1 if '0' in binary else 0)`（加上单独的 `"0"`）

注意：单独的 `"0"` 只在 `binary` 含有 `'0'` 时才存在。

## 代码实现

### 方法一：DP（推荐）

```python
class Solution:
    def numberOfUniqueGoodSubsequences(self, binary: str) -> int:
        MOD = 10**9 + 7

        # ends1: 以 '1' 结尾的不同好子序列数（不含 "0"）
        # ends0: 以 '0' 结尾的不同好子序列数（不含单独的 "0"）
        ends1 = 0
        ends0 = 0

        for c in binary:
            if c == '1':
                # 在所有好子序列后面加 '1'，再加单独的 "1"
                ends1 = (ends1 + ends0 + 1) % MOD
            else:  # c == '0'
                # 在所有好子序列后面加 '0'（以 '0' 结尾的部分被覆盖，不重复）
                ends0 = (ends1 + ends0) % MOD

        # 加上单独的 "0"（如果有的话）
        has_zero = '0' in binary
        return (ends1 + ends0 + (1 if has_zero else 0)) % MOD
```

### 方法二：注释详解版

```python
class Solution:
    def numberOfUniqueGoodSubsequences(self, binary: str) -> int:
        MOD = 10**9 + 7
        # dp1 = 以 '1' 结尾的不同子序列数
        # dp0 = 以 '0' 结尾的不同子序列数（不含单独 "0"）
        dp1 = 0
        dp0 = 0

        for c in binary:
            if c == '1':
                # 在每个已有的好子序列结尾加 '1'（共 dp1+dp0 个），再加单 "1"
                # 这一步自动去重：dp1 已统计到目前为止所有不同的以 '1' 结尾的子序列
                dp1 = (dp1 + dp0 + 1) % MOD
            else:
                # 在每个好子序列结尾加 '0'（共 dp1+dp0 个）
                # 不重复：相同的 '1...0' 序列只计一次，因为 dp0 会被覆盖更新
                dp0 = (dp1 + dp0) % MOD

        # 单独的 "0" 只算一次
        return (dp1 + dp0 + (1 if '0' in binary else 0)) % MOD
```

|------|-----------|-----------|
| DP | O(n) | O(1) |

## 关键点总结

1. 只需维护以 `'1'` 和 `'0'` 结尾的不同好子序列数
2. 每次更新会覆盖之前所有重复情况，保证不重复计数
3. 单独的 `"0"` 单独处理，在最后加 1

---

## 易错点

- 单独的 `"0"` 不属于 `ends0`，需在最后单独判断是否加 1
- 遇到 `'0'` 时更新的是 `ends0`，不需要加 1（因为 `"0"` 单独处理）
