## 题目描述

给定一棵有 `n` 个节点的加权树，以及若干查询。每个查询给出三个节点 `src1, src2, dest`，求包含从 `src1` 到 `dest` 的路径和从 `src2` 到 `dest` 的路径的最小权重子图的总边权。

**示例：**

```
输入：n = 6, edges = [[0,1,2],[0,2,3],[1,3,1],[1,4,4],[2,5,2]], 
     queries = [[3,4,5],[3,5,4]]
输出：[12, 10]
```

**提示：**
- `2 <= n <= 10^5`
- `1 <= queries.length <= 10^5`

## 解题思路

在树上，从 `src1` 到 `dest` 和从 `src2` 到 `dest` 的路径，其并集的最小权重等于：
- `dist(src1, dest) + dist(src2, dest) - dist(LCA(src1, src2), dest)` 的某种形式

实际上，两条路径的并集形成一个"Y"形结构，三条路径汇聚于某个节点 `meet`：
- 从 `src1` 到 `meet`
- 从 `src2` 到 `meet`
- 从 `meet` 到 `dest`

总权重 = `dist(src1, meet) + dist(src2, meet) + dist(meet, dest)`

最优的 `meet` 是使总权重最小的节点，它位于 `src1-dest`、`src2-dest`、`src1-src2` 三条路径的交汇处，即三条路径的 LCA 关系节点。

关键结论：`meet = LCA(src1, src2, dest)` 中两两LCA中距 dest 最近的那个。

## Python 代码实现

### 方法一：LCA + 树上距离（推荐）

```python
from typing import List
from collections import defaultdict
import math

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]],
                      queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        LOG = max(1, math.ceil(math.log2(n + 1)))
        depth = [0] * n
        dist_root = [0] * n  # 到根节点的距离
        parent = [[-1] * n for _ in range(LOG)]

        # DFS 建立树
        visited = [False] * n
        stack = [(0, -1, 0, 0)]
        order = []
        while stack:
            u, p, d, w = stack.pop()
            if visited[u]:
                continue
            visited[u] = True
            depth[u] = d
            dist_root[u] = w
            parent[0][u] = p if p != -1 else 0
            order.append(u)
            for v, wv in graph[u]:
                if not visited[v]:
                    stack.append((v, u, d+1, w+wv))

        # 二进制提升
        for k in range(1, LOG):
            for u in range(n):
                parent[k][u] = parent[k-1][parent[k-1][u]]

        def lca(u, v):
            if depth[u] < depth[v]:
                u, v = v, u
            diff = depth[u] - depth[v]
            for k in range(LOG):
                if diff >> k & 1:
                    u = parent[k][u]
            if u == v:
                return u
            for k in range(LOG-1, -1, -1):
                if parent[k][u] != parent[k][v]:
                    u = parent[k][u]
                    v = parent[k][v]
            return parent[0][u]

        def dist(u, v):
            l = lca(u, v)
            return dist_root[u] + dist_root[v] - 2 * dist_root[l]

        result = []
        for src1, src2, dest in queries:
            l12 = lca(src1, src2)
            l1d = lca(src1, dest)
            l2d = lca(src2, dest)

            # meet 是三个 LCA 中深度最大的（最靠近叶子）
            meet = max(l12, l1d, l2d, key=lambda x: depth[x])
            ans = dist(src1, meet) + dist(src2, meet) + dist(meet, dest)
            result.append(ans)

        return result
```

### 方法二：简化版（无二进制提升）

```python
from typing import List
from collections import defaultdict

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]],
                      queries: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        # 对小数据，用 BFS 计算所有点到根的距离和父节点
        parent = [-1] * n
        depth = [0] * n
        dist_root = [0] * n

        from collections import deque
        queue = deque([0])
        visited = {0}
        while queue:
            u = queue.popleft()
            for v, w in graph[u]:
                if v not in visited:
                    visited.add(v)
                    parent[v] = u
                    depth[v] = depth[u] + 1
                    dist_root[v] = dist_root[u] + w
                    queue.append(v)

        def lca(u, v):
            path_u, path_v = set(), set()
            while u != -1:
                path_u.add(u)
                u = parent[u]
            while v not in path_u:
                v = parent[v]
            return v

        def dist(u, v):
            l = lca(u, v)
            return dist_root[u] + dist_root[v] - 2 * dist_root[l]

        result = []
        for src1, src2, dest in queries:
            candidates = [lca(src1, src2), lca(src1, dest), lca(src2, dest)]
            meet = max(candidates, key=lambda x: depth[x])
            result.append(dist(src1, meet) + dist(src2, meet) + dist(meet, dest))

        return result
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，二进制提升 LCA
- 空间复杂度：O(n log n)，存储祖先表

## 关键点总结

1. 两条路径的并集形成 Y 形，汇合点 = 三个两两 LCA 中深度最大的
2. 树上距离 = `dist(u, root) + dist(v, root) - 2 * dist(LCA, root)`
3. 二进制提升实现 O(log n) 的 LCA 查询

## 易错点

1. 汇合点是三个两两 LCA 中深度最深的（不是最浅的）
2. 父节点数组初始化时根节点的父节点设为自身或 -1
3. 深度比较时要确保 LCA 在路径上
