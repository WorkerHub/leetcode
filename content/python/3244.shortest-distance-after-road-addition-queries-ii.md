## 题目描述

与 3243 相同的场景，但数据规模更大：
- `3 <= n <= 10^5`
- `1 <= queries.length <= 10^5`

每次添加从 `ui` 到 `vi` 的边后，返回从 0 到 n-1 的最短路径长度。

**保证**：不会有同样的查询出现两次（即不重复添加相同的边）。

**提示：**
- 所有 `queries[i] = [ui, vi]` 满足 `ui < vi`
- 图是有向无环图

## 解题思路

由于所有边从小到大，图是 DAG。最短路等于"跳过的节点数"的最小化。

关键观察：初始路径是 0 -> 1 -> 2 -> ... -> n-1，长度 n-1。每条捷径 `u -> v` 可以"跳过" `v - u - 1` 个节点（节省 `v - u - 1` 步）。

用**有序集合**维护当前最短路上的节点，每次添加边 `(u, v)` 时，删除 `u+1` 到 `v-1` 之间在路径上的节点，最短路长度减少删除的节点数。

用 Python 的 `SortedList` 或手动维护。

## Python 代码实现

### 方法一：有序集合维护最短路节点（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def shortestDistanceAfterQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        # 初始最短路上的节点：0, 1, 2, ..., n-1
        path = SortedList(range(n))
        
        ans = []
        for u, v in queries:
            # 删除路径上 (u, v) 之间的节点（不含 u 和 v）
            # 这些节点被新边跳过了
            # 找到 path 中大于 u 且小于 v 的所有节点，删除它们
            while True:
                idx = path.bisect_right(u)
                if idx < len(path) and path[idx] < v:
                    path.pop(idx)
                else:
                    break
            
            # 当前最短路长度 = 路径上的节点数 - 1
            ans.append(len(path) - 1)
        
        return ans
```

### 方法二：并查集/跳表（手动实现）

```python
from typing import List

class Solution:
    def shortestDistanceAfterQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        # 用 "下一个节点" 数组模拟有序集合
        # nxt[i] = 当前最短路上 i 之后的节点
        nxt = list(range(1, n + 1))  # nxt[i] = i+1（初始），nxt[n-1]=n（哨兵）
        
        ans = []
        length = n - 1  # 初始最短路长度
        
        for u, v in queries:
            # 跳过 u+1 到 v-1 之间的节点
            cur = nxt[u]  # u 的下一个节点
            while cur < v:
                length -= 1  # 删除一个节点
                next_cur = nxt[cur]
                nxt[cur] = v  # 让中间节点直接指向 v（路径压缩）
                cur = next_cur
            nxt[u] = v  # u 直接连到 v
            
            ans.append(length)
        
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O((n + q) log n)（SortedList 操作）
- 方法二：时间复杂度 O(n + q) 均摊（类似路径压缩）
- 空间复杂度：O(n)

## 关键点总结

1. 最短路 = 路径上的节点数 - 1
2. 添加新边 (u, v) 时，删除路径上 u 和 v 之间的所有中间节点
3. 用"下一个节点"数组 + 路径压缩实现 O(n + q) 均摊

## 易错点

1. 删除节点时要用路径压缩，否则重复扫描导致超时
2. 方法二中 nxt[cur] = v 的路径压缩是关键
