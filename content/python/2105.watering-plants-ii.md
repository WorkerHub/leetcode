## 题目描述

Alice 和 Bob 打算给园子里的 `n` 株植物浇水。植物排成一行，从左到右编号为 0 到 n-1。

- Alice 从最左侧出发，每次给一株植物浇水后向右移动。
- Bob 从最右侧出发，每次给一株植物浇水后向左移动。

当两人在同一株植物处相遇时，**水桶容量更大的人**给该植物浇水；若容量相同，则 **Alice** 给该植物浇水。

给你整数数组 `plants`，`capacityA` 和 `capacityB`，分别表示每株植物需要的水量、Alice 和 Bob 水桶的最大容量。两人初始时水桶都是满的。

请返回两人浇完所有植物需要重新装满水桶的**次数**。

**示例：**
```
输入：plants = [2,2,3,3], capacityA = 5, capacityB = 5
输出：1
解释：
- Alice 给 plants[0] 浇水，当前水量 5-2=3
- Bob 给 plants[3] 浇水，当前水量 5-3=2
- Alice 给 plants[1] 浇水，3-2=1
- Bob 无法给 plants[2] 浇水（2 < 3），重新装满水 -> 次数+1，然后浇水 5-3=2
共 1 次。
```

**提示：**
- `n == plants.length`
- `1 <= n <= 10^5`
- `1 <= plants[i] <= 10^6`
- `max(plants[i]) <= capacityA, capacityB <= 10^9`

## 解题思路

**双指针模拟**

- 左指针 `l` 从 0 出发（Alice），右指针 `r` 从 n-1 出发（Bob）。
- 每次 Alice 给 `plants[l]` 浇水，Bob 给 `plants[r]` 浇水。
- 若水量不足，先重新装满再浇水（次数 +1）。
- 当 `l == r` 时，选择容量大的人浇水（或 Alice）。

## 代码实现

### 方法一：双指针模拟（推荐）

```python
from typing import List

class Solution:
    def minimumRefill(self, plants: List[int], capacityA: int, capacityB: int) -> int:
        n = len(plants)
        l, r = 0, n - 1        # 左右指针
        wa, wb = capacityA, capacityB  # 当前水量
        refills = 0

        while l < r:
            # Alice 浇 plants[l]
            if wa < plants[l]:
                # 水量不足，重新装满
                wa = capacityA
                refills += 1
            wa -= plants[l]
            l += 1

            # Bob 浇 plants[r]
            if wb < plants[r]:
                wb = capacityB
                refills += 1
            wb -= plants[r]
            r -= 1

        # 相遇时，选容量大的人浇水（或 Alice）
        if l == r:
            person_water = wa if wa >= wb else wb
            person_cap = capacityA if wa >= wb else capacityB
            if person_water < plants[l]:
                refills += 1

        return refills
```

### 方法二：清晰版模拟

```python
from typing import List

class Solution:
    def minimumRefill(self, plants: List[int], capacityA: int, capacityB: int) -> int:
        n = len(plants)
        l, r = 0, n - 1
        wa, wb = capacityA, capacityB
        ans = 0

        while l < r:
            # 处理 Alice
            if wa < plants[l]:
                ans += 1
                wa = capacityA
            wa -= plants[l]
            l += 1

            # 处理 Bob
            if wb < plants[r]:
                ans += 1
                wb = capacityB
            wb -= plants[r]
            r -= 1

        # 中间植物（n 为奇数时存在）
        if l == r:
            # 选较大水桶的人
            if wa >= wb:
                if wa < plants[l]:
                    ans += 1
            else:
                if wb < plants[l]:
                    ans += 1

        return ans
```

## 关键点总结

1. 双指针分别模拟 Alice 从左、Bob 从右浇水。
2. 不足时先补满再浇，补满计数 +1。
3. 两指针相遇时（n 为奇数），选水量/容量更大的人，若不足也要补满。

## 易错点

- 相遇情况（`l == r`）需要单独处理，不能遗漏。
- 相遇时比较的是**当前水量** `wa >= wb`，而不是容量。
- 水量不足时先装满（更新为满容量），再减去所需水量。
