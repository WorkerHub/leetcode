## 题目描述

给你一个整数数组 `cards`，其中 `cards[i]` 表示第 `i` 张卡牌的值。如果两张卡牌数值相同，则视为一对。

返回包含**一对相同卡牌**所需的最少**连续**卡牌数，若不存在则返回 -1。

**示例 1：**
```
输入：cards = [3,4,2,3,4,7]
输出：4
解释：[3,4,2,3] 包含一对3，长度4；[4,2,3,4] 包含一对4，长度4。最少4。
```

**示例 2：**
```
输入：cards = [1,0,5,3]
输出：-1
```

## 解题思路

用哈希表记录每个值最近一次出现的位置，遍历时若当前值在哈希表中，计算窗口大小 `i - last[v] + 1`，更新最小值。

## 代码实现

### 方法一：哈希表（推荐）

```python
from typing import List

class Solution:
    def minimumCardPickup(self, cards: List[int]) -> int:
        last = {}   # 记录每个值最近出现的位置
        ans = float('inf')

        for i, v in enumerate(cards):
            if v in last:
                # 找到一对相同的，窗口大小 = i - last[v] + 1
                ans = min(ans, i - last[v] + 1)
            last[v] = i  # 更新最新位置

        return ans if ans != float('inf') else -1
```

### 方法二：滑动窗口（双端队列）

```python
from typing import List
from collections import Counter

class Solution:
    def minimumCardPickup(self, cards: List[int]) -> int:
        # 滑动窗口：维护无重复的窗口
        count = Counter()
        left = 0
        ans = float('inf')

        for right, v in enumerate(cards):
            count[v] += 1
            # 若出现重复
            while count[v] > 1:
                # 计算当前窗口大小
                ans = min(ans, right - left + 1)
                count[cards[left]] -= 1
                left += 1

        return ans if ans != float('inf') else -1
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(n)，哈希表。

## 关键点总结

1. 对每个值，只需关心它最近两次出现的位置（窗口越短越好）。
2. 方法一记录最近位置，每次遇到重复直接计算窗口大小，O(n) 时间。
3. 方法二滑动窗口在出现重复时收缩左边界，本质类似。

## 易错点

- 窗口大小是 `i - last[v] + 1`（包含两端），不是 `i - last[v]`。
- 多次出现同一值时，以最近的两次计算窗口最小（方法一自动处理：每次更新 `last[v]`）。
