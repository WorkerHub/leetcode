## 题目描述

给你一个整数数组 `nums`，你需要将其分割成若干个**严格递增**子序列，使得每个子序列都被"移除"后，数组变为空。

返回所需的**最少递增子序列数**。

**示例 1：**
```
输入：nums = [5,2,1,4,3]
输出：3
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 解题思路

这道题等价于求**最长非递增子序列**的长度（Dilworth 定理）：

将数组分成最少个严格递增子序列，等价于求最长"非严格递减"子序列长度（即最长不严格递减子序列）。

**Dilworth 定理**：将偏序集分成最少链的数目 = 最长反链的长度。

对于严格递增的链，反链是"非递增"的序列。

用耐心排序（类似 LIS 问题）：维护多个序列，每个序列末尾严格递增。贪心放置每个元素：找到末尾最小的且 >= 当前元素的序列，将其放入；若没有，新建序列。

序列数量 = 最长非递增子序列长度。

## Python 代码实现

### 方法一：贪心 + 二分查找（推荐）

```python
from typing import List
import bisect

class Solution:
    def minSubsequences(self, nums: List[int]) -> int:
        # 等价于最长不严格递减子序列长度（耐心排序）
        # 维护每个"堆"的顶部元素（严格递增堆）
        # 每个元素放到顶部 >= 当前元素 的最小堆上
        # 若无，新建堆
        
        # tails[i] 表示第 i+1 个序列的当前最后一个元素
        # 为了让序列严格递增，tails 需要是严格递减的（贪心）
        
        tails = []  # 降序排列，每个序列末尾值
        
        for x in nums:
            # 找到 tails 中最小的且 >= x 的位置
            # tails 是降序的，要找 >= x 的最右位置 -> bisect_left on reversed
            # 等价于在降序列表中找第一个 <= x 的... 
            # 用 bisect_left 在 tails（降序）中找 x：
            # bisect_left(tails, x, key=lambda v: -v)... Python 没有 key
            
            # 改用单调数组：tails 维护为降序
            # 找到最右边 >= x 的位置放入（替换为 x）
            # 如果所有都 < x，新建
            
            # 二分：在降序数组 tails 中找第一个 < x 的位置
            # 即找最后一个 >= x 的位置
            lo, hi = 0, len(tails)
            while lo < hi:
                mid = (lo + hi) // 2
                if tails[mid] >= x:
                    lo = mid + 1
                else:
                    hi = mid
            # lo 是第一个 < x 的位置
            # 如果 lo < len(tails)，用 x 替换 tails[lo]（使其更小，便于后续）
            # 如果 lo == len(tails)，新建
            if lo < len(tails):
                tails[lo] = x
            else:
                tails.append(x)
        
        return len(tails)
```

### 方法二：直接统计（利用问题特性）

```python
from typing import List
import bisect

class Solution:
    def minSubsequences(self, nums: List[int]) -> int:
        # 最少递增子序列数 = 最长非递增子序列长度
        # 用 LIS 算法求最长非递增子序列
        # 翻转问题：最长非递增子序列 = 在 nums 中找最长序列使得后者 <= 前者
        
        # 换成 LIS 变体：对 -nums 求 LIS（严格递增）
        # 最长非递增子序列 len = LIS(-nums) 的长度
        
        tails = []
        for x in nums:
            neg_x = -x
            pos = bisect.bisect_left(tails, neg_x)
            if pos == len(tails):
                tails.append(neg_x)
            else:
                tails[pos] = neg_x
        return len(tails)
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 最少分割成严格递增子序列 = 最长非递增子序列长度（Dilworth 定理）
2. 求最长非递增子序列等价于对取负后的数组求 LIS
3. 耐心排序 + 二分查找高效求解

## 易错点

1. 严格递增子序列对应非严格递减（即允许相等）的反链
2. 用 LIS 求非递增时要注意等号方向
