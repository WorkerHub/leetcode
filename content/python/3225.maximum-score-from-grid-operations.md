## 题目描述

给你一个 `n x n` 的整数矩阵 `grid`，初始每个格子可以是黑色（1）或白色（0）。

你可以对**某些列**执行操作：选择一列，将该列**从顶部**某行到**底部**的所有格子涂成黑色。

得分规则：对于每个黑色格子，如果它**右侧相邻**的格子是白色，则得 1 分。

返回所有操作后的**最大得分**。

**提示：**
- `1 <= n <= 100`
- `grid[i][j]` 为 0 或 1

## 解题思路

列 DP + 前缀和：

对于每列 `j`，它被涂黑的范围是 `[0, h-1]`（从第 0 行到第 h-1 行），`h` 可以是 0 到 n。

定义 `dp[j][h]` = 处理前 j 列，第 j 列涂黑到第 h 行时的最大得分。

转移时考虑第 j 列和第 j+1 列的涂黑高度关系，得分来自列 j 的黑格子右侧（列 j+1）的白格子。

用前缀和优化计算每对高度之间的得分贡献。

## Python 代码实现

### 方法一：列 DP + 前缀和（推荐）

```python
from typing import List

class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        
        # 预处理：col_prefix[j][i] = 第 j 列前 i 行中 1 的个数
        col_prefix = [[0] * (n + 1) for _ in range(n)]
        for j in range(n):
            for i in range(n):
                col_prefix[j][i + 1] = col_prefix[j][i] + grid[i][j]
        
        # dp[h] = 当前列涂黑到高度 h 时的最大得分（0 = 不涂）
        # 处理每对相邻列 (j, j+1)
        
        INF = float('-inf')
        # dp[j][h]: 第 j 列涂黑 h 行时的最大累积得分
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        
        for j in range(n - 1):
            ndp = [[INF] * (n + 1) for _ in range(1)]
            ndp = [INF] * (n + 1)
            # 枚举第 j 列高度 h1 和第 j+1 列高度 h2
            # 得分：第 j 列高度 h1 中，第 j+1 列（高度 h2）的白色格子数
            # 白色格子数 = h1 中 j+1 列的 0 数量
            # 分两部分：min(h1,h2) 部分无贡献（j+1 也是黑），剩余部分有贡献
            
            # 预计算 j+1 列的前缀白色数（即 0 的前缀和）
            white_prefix = [0] * (n + 1)
            for i in range(n):
                white_prefix[i + 1] = white_prefix[i] + (1 - grid[i][j + 1])
            
            for h2 in range(n + 1):
                best = INF
                for h1 in range(n + 1):
                    if dp[j][h1] == INF:
                        continue
                    # 第 j 列 [0, h1) 涂黑，第 j+1 列 [0, h2) 涂黑
                    # 得分：第 j 列黑格子（高度 h1）中，j+1 列是白色的行数
                    # = h1 行中 j+1 列白色格 - min(h1,h2) 行中 j+1 列白色格（被涂黑了）
                    score = white_prefix[h1] - white_prefix[min(h1, h2)]
                    val = dp[j][h1] + score
                    best = max(best, val)
                ndp[h2] = best
            dp[j + 1] = ndp
        
        return max(dp[n - 1]) if n > 1 else 0
```

### 方法二：简化版 DP

```python
from typing import List

class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        if n == 1:
            return 0
        
        # dp[h] 表示当前列涂黑高度为 h 时的最大得分
        dp = [0] * (n + 1)
        
        for j in range(n - 1):
            # 预处理右列的白色前缀和
            rwhite = [0] * (n + 1)
            for i in range(n):
                rwhite[i + 1] = rwhite[i] + (1 - grid[i][j + 1])
            
            new_dp = [0] * (n + 1)
            # 对于右列高度 h2，枚举左列高度 h1
            # 利用前缀最大值优化
            prefix_max = [float('-inf')] * (n + 2)
            for h1 in range(n + 1):
                # h1 <= h2 时：得分 = rwhite[h1] - rwhite[h1] + rwhite[h1] = ...
                # 先存 dp[h1] - rwhite[h1]（h1<=h2 情况）
                prefix_max[h1] = max(prefix_max[h1 - 1] if h1 > 0 else float('-inf'),
                                     dp[h1] + rwhite[h1])
            
            for h2 in range(n + 1):
                # h1 <= h2: score = rwhite[h1] - rwhite[h1] = 0? 不对
                # 重新推导：score = rwhite[h1] - rwhite[min(h1,h2)]
                # h1 <= h2: score = 0
                # h1 > h2: score = rwhite[h1] - rwhite[h2]
                
                # h1 <= h2: val = dp[h1] + 0
                opt1 = prefix_max[h2]  # max(dp[h1]) for h1<=h2
                
                # h1 > h2: val = dp[h1] + rwhite[h1] - rwhite[h2]
                # = (dp[h1] + rwhite[h1]) - rwhite[h2]
                # 用后缀最大值 suffix_max[h2+1] = max(dp[h1]+rwhite[h1]) for h1>h2
                new_dp[h2] = opt1  # 暂存
            
            # 后缀最大值
            suffix_max = [float('-inf')] * (n + 2)
            for h1 in range(n, -1, -1):
                suffix_max[h1] = max(suffix_max[h1 + 1], dp[h1] + rwhite[h1])
            
            for h2 in range(n + 1):
                opt1 = prefix_max[h2]  # h1<=h2
                opt2 = suffix_max[h2 + 1] - rwhite[h2]  # h1>h2
                new_dp[h2] = max(
                    opt1 if opt1 != float('-inf') else 0,
                    opt2 if opt2 != float('-inf') else 0
                )
            
            dp = new_dp
        
        return max(dp)
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 对每列枚举涂黑高度（0 到 n），用 DP 转移
2. 得分只来自相邻列的黑白界面
3. 用前缀/后缀最大值优化内层循环

## 易错点

1. 得分是当前列黑格子右侧相邻的白格子，不是全局统计
2. 注意初始 dp 数组的初值
