## 题目描述

请你仅使用两个队列实现一个后进先出（LIFO）的栈，并支持普通栈的全部四种操作（`push`、`top`、`pop` 和 `empty`）。

实现 `MyStack` 类：

- `void push(int x)` 将元素 x 压入栈顶。
- `int pop()` 移除并返回栈顶元素。
- `int top()` 返回栈顶元素。
- `boolean empty()` 如果栈是空的，返回 `true`；否则，返回 `false`。

**注意：**

- 你只能使用队列的基本操作 —— 也就是 `push to back`、`peek/pop from front`、`size` 和 `is empty` 这些操作。
- 你所使用的语言也许不支持队列。你可以使用 list（列表）或者 deque（双端队列）来模拟一个队列，只要是标准的队列操作即可。

**示例：**

```
输入：
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]
输出：
[null, null, null, 2, 2, false]

解释：
MyStack myStack = new MyStack();
myStack.push(1);
myStack.push(2);
myStack.top(); // 返回 2
myStack.pop(); // 返回 2
myStack.empty(); // 返回 False
```

**提示：**

- `1 <= x <= 9`
- 最多调用 `100` 次 `push`、`pop`、`top` 和 `empty`
- 每次调用 `pop` 和 `top` 都保证栈不为空

**进阶：** 你能否仅使用一个队列来实现栈？

## 解题思路

栈是**后进先出（LIFO）**，队列是**先进先出（FIFO）**。要用队列实现栈，关键是**反转队列的顺序**。

### 核心思想

1. **两个队列方法**：
   - 主队列：存储所有元素
   - 辅助队列：在 pop 操作时临时存储元素
   - pop 时将主队列的前 n-1 个元素移到辅助队列，弹出最后一个，再交换两个队列

2. **一个队列方法（推荐）**：
   - 每次 push 后，将新元素前面的所有元素重新入队
   - 这样队头始终是最新入栈的元素

### 算法流程（一个队列）

`push(x)` 操作：
1. 将 x 加入队列
2. 将 x 前面的所有元素依次出队再入队
3. 这样 x 就到了队头

例如：
- push(1)：队列 [1]
- push(2)：队列 [2, 1]（将 1 出队再入队）
- push(3)：队列 [3, 2, 1]（将 2, 1 依次出队再入队）

## Python 代码实现

### 方法一：单队列（推荐）

```python
from collections import deque

class MyStack:
    def __init__(self):
        self.queue = deque()

    def push(self, x: int) -> None:
        """将元素 x 压入栈顶"""
        n = len(self.queue)
        self.queue.append(x)
        # 将新元素前面的所有元素移到后面
        for _ in range(n):
            self.queue.append(self.queue.popleft())

    def pop(self) -> int:
        """移除并返回栈顶元素"""
        return self.queue.popleft()

    def top(self) -> int:
        """返回栈顶元素"""
        return self.queue[0]

    def empty(self) -> bool:
        """判断栈是否为空"""
        return len(self.queue) == 0
```

### 方法二：两个队列

```python
from collections import deque

class MyStack:
    def __init__(self):
        self.queue1 = deque()  # 主队列
        self.queue2 = deque()  # 辅助队列

    def push(self, x: int) -> None:
        """将元素 x 压入栈顶"""
        self.queue1.append(x)

    def pop(self) -> int:
        """移除并返回栈顶元素"""
        # 将 queue1 的前 n-1 个元素移到 queue2
        while len(self.queue1) > 1:
            self.queue2.append(self.queue1.popleft())
        # 弹出 queue1 的最后一个元素（栈顶）
        result = self.queue1.popleft()
        # 交换两个队列
        self.queue1, self.queue2 = self.queue2, self.queue1
        return result

    def top(self) -> int:
        """返回栈顶元素"""
        # 类似 pop，但不删除元素
        while len(self.queue1) > 1:
            self.queue2.append(self.queue1.popleft())
        result = self.queue1[0]
        # 将最后一个元素也移到 queue2
        self.queue2.append(self.queue1.popleft())
        # 交换队列
        self.queue1, self.queue2 = self.queue2, self.queue1
        return result

    def empty(self) -> bool:
        """判断栈是否为空"""
        return len(self.queue1) == 0
```

### 方法三：优化的两队列（push 时调整）

```python
from collections import deque

class MyStack:
    def __init__(self):
        self.queue1 = deque()
        self.queue2 = deque()

    def push(self, x: int) -> None:
        """将元素压入 queue2，然后将 queue1 的元素移到 queue2，最后交换"""
        self.queue2.append(x)
        while self.queue1:
            self.queue2.append(self.queue1.popleft())
        self.queue1, self.queue2 = self.queue2, self.queue1

    def pop(self) -> int:
        """直接从 queue1 弹出"""
        return self.queue1.popleft()

    def top(self) -> int:
        """直接返回 queue1 的队头"""
        return self.queue1[0]

    def empty(self) -> bool:
        """判断 queue1 是否为空"""
        return len(self.queue1) == 0
```

### 方法四：使用 Python list

```python
class MyStack:
    def __init__(self):
        self.queue = []

    def push(self, x: int) -> None:
        """将元素压入栈顶"""
        self.queue.append(x)
        # 将前面的元素移到后面
        for _ in range(len(self.queue) - 1):
            self.queue.append(self.queue.pop(0))

    def pop(self) -> int:
        """弹出栈顶元素"""
        return self.queue.pop(0)

    def top(self) -> int:
        """返回栈顶元素"""
        return self.queue[0]

    def empty(self) -> bool:
        """判断是否为空"""
        return len(self.queue) == 0
```

## 复杂度分析

**方法一：单队列（push 时调整）**
- `push(x)`：O(n)，需要将 n-1 个元素重新入队
- `pop()`：O(1)，直接出队
- `top()`：O(1)，直接访问队头
- `empty()`：O(1)
- 空间复杂度：O(n)，存储 n 个元素

**方法二：两队列（pop/top 时调整）**
- `push(x)`：O(1)，直接入队
- `pop()`：O(n)，需要移动 n-1 个元素
- `top()`：O(n)，需要移动 n-1 个元素
- `empty()`：O(1)
- 空间复杂度：O(n)

## 图解示例

单队列方法的 push 过程：

```
初始：queue = []

push(1)：
  queue.append(1) → [1]
  循环 0 次
  结果：[1]

push(2)：
  queue.append(2) → [1, 2]
  循环 1 次：
    popleft 1, append 1 → [2, 1]
  结果：[2, 1]

push(3)：
  queue.append(3) → [2, 1, 3]
  循环 2 次：
    popleft 2, append 2 → [1, 3, 2]
    popleft 1, append 1 → [3, 2, 1]
  结果：[3, 2, 1]

pop()：
  popleft() → 返回 3
  结果：[2, 1]

top()：
  queue[0] → 返回 2
  队列不变：[2, 1]
```

## 关键点总结

1. **核心思想**：通过重新排列队列元素，使队头始终是栈顶
2. **时间空间权衡**：push 慢但 pop/top 快 vs push 快但 pop/top 慢
3. **单队列优化**：减少了空间使用，逻辑更简洁
4. **队列操作**：只使用标准的队列操作（入队、出队）
5. **实现选择**：单队列方法更推荐，代码更简洁

## 易错点

1. **循环次数**：push 时循环 n-1 次（原有元素个数），而不是 n 次
2. **队列选择**：使用 deque 而不是 list，因为 list 的 pop(0) 是 O(n)
3. **top 实现**：注意不要修改队列，只是查看
4. **队列交换**：两队列方法中要记得交换队列
5. **边界条件**：题目保证 pop 和 top 时栈不为空，不需要额外检查
