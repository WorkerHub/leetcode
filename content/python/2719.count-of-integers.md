## 题目描述

给你两个数字字符串 `num1` 和 `num2`，以及两个整数 `min_sum` 和 `max_sum`。

统计在 `num1` 到 `num2` 之间（包括两端），满足以下条件的整数数目：
- 该整数各位数字之和 `s` 满足 `min_sum <= s <= max_sum`

返回符合条件的整数数目（对 `10^9 + 7` 取模）。

**示例 1：**
```
输入：num1 = "1", num2 = "12", min_sum = 1, max_sum = 8
输出：11
解释：1 到 12 中，各位数字之和在 [1,8] 的有 1,2,...,8,10,11,12，共 11 个
```

**提示：**
- `1 <= num1 <= num2 <= 10^22`
- `1 <= min_sum <= max_sum <= 400`

## 解题思路

**数位 DP**：利用前缀计数函数 `f(num)` = `[0, num]` 中满足条件的数的数量，答案 = `f(num2) - f(num1 - 1)`。

数位 DP 参数：
- `pos`：当前处理的位
- `tight`：是否还在上界限制内
- `sum`：已经累积的数字和

由于 `num1 - 1` 是大数字符串，可以改为 `f(num2) - f(num1) + (num1 本身是否满足条件)`。

## Python 代码实现

### 方法一：数位 DP（记忆化递归）

```python
from functools import lru_cache

class Solution:
    def count(self, num1: str, num2: str, min_sum: int, max_sum: int) -> int:
        MOD = 10**9 + 7

        def dp(s: str) -> int:
            # 统计 [0, s] 中满足条件的整数数
            n = len(s)

            @lru_cache(maxsize=None)
            def dfs(pos: int, digit_sum: int, tight: bool) -> int:
                if digit_sum > max_sum:
                    return 0
                if pos == n:
                    return 1 if digit_sum >= min_sum else 0

                limit = int(s[pos]) if tight else 9
                res = 0
                for d in range(0, limit + 1):
                    res += dfs(pos + 1, digit_sum + d, tight and d == limit)
                return res % MOD

            result = dfs(0, 0, True)
            dfs.cache_clear()
            return result

        # f(num2) - f(num1) + (num1 本身是否满足)
        ans = (dp(num2) - dp(num1) + MOD) % MOD
        # 加回 num1 本身（dp(num1) 包含了 num1，需检查 num1 是否满足）
        s1 = sum(int(c) for c in num1)
        if min_sum <= s1 <= max_sum:
            ans = (ans + 1) % MOD
        return ans
```

### 方法二：迭代数位 DP

```python
class Solution:
    def count(self, num1: str, num2: str, min_sum: int, max_sum: int) -> int:
        MOD = 10**9 + 7

        def count_up_to(s: str) -> int:
            n = len(s)
            # dp[tight][sum] -> 数量
            # 使用滚动
            dp = {(True, 0): 1}
            for i in range(n):
                ndp = {}
                for (tight, cur_sum), cnt in dp.items():
                    limit = int(s[i]) if tight else 9
                    for d in range(limit + 1):
                        nsum = cur_sum + d
                        if nsum > max_sum:
                            continue
                        ntight = tight and (d == limit)
                        key = (ntight, nsum)
                        ndp[key] = (ndp.get(key, 0) + cnt) % MOD
                dp = ndp
            return sum(cnt for (_, s), cnt in dp.items() if s >= min_sum) % MOD

        ans = (count_up_to(num2) - count_up_to(num1) + MOD) % MOD
        s1 = sum(int(c) for c in num1)
        if min_sum <= s1 <= max_sum:
            ans = (ans + 1) % MOD
        return ans
```

## 复杂度分析

- 时间复杂度：O(L * max_sum * 10)，L 为数字位数（最多 23）
- 空间复杂度：O(L * max_sum)

## 关键点总结

1. 数位 DP 模板：`tight` 标志是否仍受上界约束
2. 利用区间差值：答案 = f(num2) - f(num1 - 1)
3. 大数字符串的 `-1` 操作复杂，改为 f(num2) - f(num1) + (num1 是否满足)

## 易错点

1. 数字和上界 max_sum 可能达到 400（22位，每位9，最大198，但题目给400）
2. 取模后的差值可能为负，需 +MOD
