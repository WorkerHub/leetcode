## 题目描述

有 `n` 个 `(idKey, value)` 对，其中 `idKey` 是 `1` 到 `n` 之间的一个整数。

设计一个有序流，其中插入操作 `insert(idKey, value)` 会返回一个列表：从当前最小未插入 ID 开始，连续已插入的 `(idKey, value)` 对的 value 序列。

**示例：**
```
OrderedStream os(5);
os.insert(3,"ccc") -> []
os.insert(1,"aaa") -> ["aaa"]
os.insert(2,"bbb") -> ["bbb","ccc"]
os.insert(5,"eee") -> []
os.insert(4,"ddd") -> ["ddd","eee"]
```

## 解题思路

维护一个数组存储所有 `(idKey, value)` 对，以及一个指针 `ptr` 指向当前最小未返回的 ID。

每次插入时，将 value 存入对应位置，然后从 `ptr` 开始连续返回已插入的值。

## 代码实现

### 方法一：数组 + 指针（推荐）

```python
from typing import List

class OrderedStream:

    def __init__(self, n: int):
        self.data = [None] * (n + 1)  # 1-indexed
        self.ptr = 1  # 当前最小未返回 ID

    def insert(self, idKey: int, value: str) -> List[str]:
        self.data[idKey] = value
        result = []
        # 从 ptr 开始，连续返回已插入的值
        while self.ptr < len(self.data) and self.data[self.ptr] is not None:
            result.append(self.data[self.ptr])
            self.ptr += 1
        return result
```

### 方法二：字典存储

```python
from typing import List

class OrderedStream:

    def __init__(self, n: int):
        self.store = {}
        self.ptr = 1
        self.n = n

    def insert(self, idKey: int, value: str) -> List[str]:
        self.store[idKey] = value
        result = []
        while self.ptr <= self.n and self.ptr in self.store:
            result.append(self.store[self.ptr])
            self.ptr += 1
        return result
```

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| insert | O(k)（k 为当次返回的元素数） | O(n) |
| 总体 | O(n)（所有插入的总时间） | O(n) |

## 关键点总结

1. 维护指针 `ptr` 跟踪当前最小未返回 ID
2. 每次插入后从 `ptr` 开始收集连续已插入的值
3. 整个流程每个元素最多被访问两次（插入时 + 返回时），总 O(n)

## 易错点

- `data` 数组使用 1-indexed（空出 0 号位）
- `ptr` 从 1 开始，插入完一段连续数据后 ptr 会相应移动
