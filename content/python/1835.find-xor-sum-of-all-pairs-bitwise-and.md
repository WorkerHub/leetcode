## 题目描述

给你两个下标从 0 开始的数组 `arr1` 和 `arr2`，长度分别为 `n` 和 `m`。

**XOR 总和** 定义为对所有 `(i, j)` 数对（`0 <= i < n`，`0 <= j < m`），计算 `arr1[i] AND arr2[j]` 之和，然后将所有值 XOR 在一起。

返回该 XOR 总和。

**示例 1：**
```
输入：arr1 = [1,2,3], arr2 = [6,5]
输出：0
```

**示例 2：**
```
输入：arr1 = [12], arr2 = [4]
输出：4
```

## 解题思路

**位运算分配律**：

对于每一位 `b`，`(a AND b)` 的该位为 1 当且仅当 a 和 b 的该位都为 1。

对所有数对 XOR 的每一位独立分析：

第 b 位的 XOR 总和 = ⊕ over all i,j of (arr1[i][b] AND arr2[j][b])

由于 XOR 的自反性，若某位在所有数对中 AND 为 1 的出现次数为奇数，则结果该位为 1。

**关键性质**：`(a XOR b) AND c = (a AND c) XOR (b AND c)`（AND 对 XOR 有分配律）

因此：`⊕(arr1[i] AND arr2[j]) = (⊕arr1[i]) AND (⊕arr2[j])`

只需计算 arr1 全体 XOR 和 arr2 全体 XOR，然后 AND 即可！

## 代码实现

### 方法一：利用分配律（推荐，O(n+m) 时间）

```python
from typing import List
from functools import reduce
from operator import xor

class Solution:
    def getXORSum(self, arr1: List[int], arr2: List[int]) -> int:
        # (XOR of arr1) AND (XOR of arr2)
        xor1 = 0
        for x in arr1:
            xor1 ^= x
        xor2 = 0
        for x in arr2:
            xor2 ^= x
        return xor1 & xor2
```

### 方法二：Python 函数式写法（简洁版）

```python
from typing import List
from functools import reduce
from operator import xor

class Solution:
    def getXORSum(self, arr1: List[int], arr2: List[int]) -> int:
        return reduce(xor, arr1) & reduce(xor, arr2)
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(1)

## 关键点总结

1. AND 对 XOR 有分配律：`(a XOR b) AND c = (a AND c) XOR (b AND c)`
2. 利用该性质，所有数对 XOR 化简为 arr1 全体 XOR 与 arr2 全体 XOR 的 AND
3. 从 O(n*m) 优化到 O(n+m)

## 易错点

- 直接暴力枚举所有数对会 TLE（n, m 最多 10^5，总数对达 10^10）
- 分配律的方向：`⊕(arr1[i] AND arr2[j]) over all i,j`，不是先 AND 再外层 XOR
