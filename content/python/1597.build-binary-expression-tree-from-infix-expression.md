## 题目描述

中缀表达式是一种通用的算数表达式格式，如 `1+2*3` 或 `(1+2)*3`。

给你一个中缀表达式字符串 `s`，请你将其转换为一棵二叉表达式树（每个非叶节点是运算符，叶节点是操作数）。

操作数只含小写字母，运算符为 `+`、`-`、`*`、`/`，可能含括号。

返回该表达式树的根节点（树结构任意，但求值结果必须正确，且不含多余括号分组）。

**提示：**
- `1 <= s.length <= 100`
- 仅含数字 `'1'-'9'`、运算符 `+-*/`、括号 `()`

## 解题思路

### 双栈法（操作数栈 + 运算符栈）

与中缀转后缀（逆波兰表达式）类似，使用两个栈：
- `ops`：运算符栈（含括号）
- `nodes`：节点栈

**运算符优先级：** `*` 和 `/` 高于 `+` 和 `-`

**规则：**
1. 遇到操作数，压入 `nodes`
2. 遇到 `(`，压入 `ops`
3. 遇到 `)`，弹出并合并直到遇到 `(`
4. 遇到运算符，弹出优先级 ≥ 当前的运算符并合并，再压入
5. 最后弹出剩余所有运算符并合并

**合并操作：** 从 `nodes` 取出两个子树，构造以运算符为根的新节点，压回 `nodes`。

## 代码实现

### 方法一：双栈（推荐）

```python
class Node:
    def __init__(self, val=" ", left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def expTree(self, s: str) -> 'Node':
        # 运算符优先级
        priority = {'+': 1, '-': 1, '*': 2, '/': 2}

        ops = []    # 运算符栈
        nodes = []  # 节点栈

        def combine():
            """弹出一个运算符，合并两个节点"""
            op = ops.pop()
            right = nodes.pop()
            left = nodes.pop()
            node = Node(op, left, right)
            nodes.append(node)

        for ch in s:
            if ch == '(':
                ops.append(ch)
            elif ch == ')':
                # 合并到左括号
                while ops and ops[-1] != '(':
                    combine()
                ops.pop()  # 弹出 '('
            elif ch in priority:
                # 弹出优先级 >= 当前的运算符
                while ops and ops[-1] != '(' and ops[-1] in priority and priority[ops[-1]] >= priority[ch]:
                    combine()
                ops.append(ch)
            else:
                # 操作数，直接创建叶节点
                nodes.append(Node(ch))

        # 处理剩余运算符
        while ops:
            combine()

        return nodes[0]
```

### 方法二：递归下降解析

```python
class Node:
    def __init__(self, val=" ", left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def expTree(self, s: str) -> 'Node':
        self.i = 0

        def parse_expr():
            """解析加减表达式"""
            left = parse_term()
            while self.i < len(s) and s[self.i] in '+-':
                op = s[self.i]
                self.i += 1
                right = parse_term()
                left = Node(op, left, right)
            return left

        def parse_term():
            """解析乘除表达式"""
            left = parse_factor()
            while self.i < len(s) and s[self.i] in '*/':
                op = s[self.i]
                self.i += 1
                right = parse_factor()
                left = Node(op, left, right)
            return left

        def parse_factor():
            """解析原子：括号或操作数"""
            if s[self.i] == '(':
                self.i += 1  # 跳过 '('
                node = parse_expr()
                self.i += 1  # 跳过 ')'
                return node
            else:
                node = Node(s[self.i])
                self.i += 1
                return node

        return parse_expr()
```

## 复杂度分析

- **时间复杂度**：O(N)，遍历字符串一遍
- **空间复杂度**：O(N)，栈的大小

## 关键点总结

1. 双栈法：节点栈 + 运算符栈，遇到低优先级运算符时合并高优先级
2. 递归下降：自顶向下解析，优先级通过函数调用层次自然体现
3. 合并操作：取右子树（后压入的），取左子树，构造父节点

## 易错点

- 合并时注意左右顺序：先弹出的是右子树
- 遇到 `)` 要弹出运算符直到 `(`，然后把 `(` 也弹掉
- 双栈法中 `(` 不参与优先级比较
