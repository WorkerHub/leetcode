## 题目描述

给你两个字符串 `s` 和 `t`（长度相同），以及若干次操作：每次可以选择 `s` 中的一个字符，将其替换为字母表中前一个或后一个字母（循环：'z' -> 'a', 'a' -> 'z'）。

判断是否能通过若干次操作使 `s` 变为 `t`。

**示例 1：**

```
输入：s = "abc", t = "bca"
输出：true
解释：
- s[0]='a' -> 'b'（加 1）
- s[1]='b' -> 'c'（加 1）
- s[2]='c' -> 'a'（加 1，循环）
最终 "bca" == t。
```

**示例 2：**

```
输入：s = "az", t = "za"
输出：true
解释：s[0]='a'->'z'，s[1]='z'->'a'，得 "za"。
```

**提示：**
- `1 <= s.length == t.length <= 100`
- 字符串仅由小写字母组成

## 解题思路

每个字符可以通过若干次操作（+1 或 -1）变成任意其他字符，因此任意字符可以变成任意字符（通过足够多的操作）。

若操作次数无限制，任意字符串都可以变成任意字符串，答案总为 true。

若有操作次数限制 `k`（每个字符最多操作 k 次）：每个字符的最小转换步数 = `min(|ord(s[i]) - ord(t[i])|, 26 - |ord(s[i]) - ord(t[i])|)`（循环距离），只需检查是否都在 k 步内。

## Python 代码实现

### 方法一：无限制时（推荐）

```python
class Solution:
    def checkFeasibility(self, s: str, t: str) -> bool:
        # 若操作次数无限制，任意字符串都可以变成任意字符串
        return len(s) == len(t)
```

### 方法二：有操作次数限制 k

```python
class Solution:
    def checkFeasibility(self, s: str, t: str, k: int) -> bool:
        for a, b in zip(s, t):
            dist = abs(ord(a) - ord(b))
            min_dist = min(dist, 26 - dist)  # 循环最短距离
            if min_dist > k:
                return False
        return True
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个字符可以通过循环路径变成任意字符，最短路径为 `min(dist, 26 - dist)`。
2. 若无操作次数限制，答案总为 true（长度相同时）。
3. 有限制时，逐字符检查是否在 k 步内。

## 易错点

1. 字母表循环：'z' 和 'a' 之间距离为 1，不是 25。
2. 最小距离 = `min(|a-b|, 26 - |a-b|)`。
