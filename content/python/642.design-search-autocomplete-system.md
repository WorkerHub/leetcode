## 题目描述

为搜索引擎设计一个搜索自动补全系统。用户会输入一条语句（至少包含一个字母）。

对于每个输入字符，你需要返回历史中热度前 3 的句子。

**规则：**
1. 热度定义为历史上该句子被输入的次数
2. 返回的句子应按热度降序排列
3. 如果有多个句子热度相同，按 ASCII 码排序
4. 如果匹配的句子少于 3 个，全部返回

**示例：**
```
输入：
["AutocompleteSystem", "input", "input", "input", "input"]
[[["i love you", "island", "iroman", "i love leetcode"], [5, 3, 2, 2]], ["i"], [" "], ["a"], ["#"]]

输出：
[null, ["i love you", "island", "i love leetcode"], ["i love you", "i love leetcode"], [], []]
```

## Python 代码实现

### 方法一：字典树 + 哈希表

```python
from typing import List
import collections

class AutocompleteSystem:
    def __init__(self, sentences: List[str], times: List[int]):
        self.freq = collections.defaultdict(int)
        for i in range(len(sentences)):
            self.freq[sentences[i]] = times[i]
        self.cur_input = ""
    
    def input(self, c: str) -> List[str]:
        if c == '#':
            # 结束输入，保存到历史
            self.freq[self.cur_input] += 1
            self.cur_input = ""
            return []
        
        self.cur_input += c
        
        # 找出所有匹配的句子
        matches = []
        for sentence, freq in self.freq.items():
            if sentence.startswith(self.cur_input):
                matches.append((-freq, sentence))
        
        # 排序并返回前3个
        matches.sort()
        return [sentence for _, sentence in matches[:3]]
```

## 复杂度分析

- 时间复杂度：input 操作 O(n log n)，n 是句子总数
- 空间复杂度：O(m)，m 是所有句子的总长度

## 关键点总结

1. 使用哈希表存储句子频率
2. 每次输入时查找匹配的句子
3. 按规则排序并返回前3个
