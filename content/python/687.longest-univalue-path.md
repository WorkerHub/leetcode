## 题目描述

给定一个二叉树的根节点 root，返回最长的路径的长度，这个路径中的每个节点具有相同值。这条路径可以经过也可以不经过根节点。

两个节点之间的路径长度由它们之间的边数表示。

**示例 1：**
```
输入：root = [5,4,5,1,1,5]
输出：2
```

**示例 2：**
```
输入：root = [1,4,5,4,4,5]
输出：2
```

**提示：**
- 树的节点数在范围 [0, 10^4] 内
- -1000 <= Node.val <= 1000
- 树的深度不超过 1000

## 解题思路

使用深度优先搜索，对每个节点计算通过它的最长同值路径。

## Python 代码实现

### 方法一：DFS（推荐）

```python
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def longestUnivaluePath(self, root: Optional[TreeNode]) -> int:
        self.max_len = 0
        
        def dfs(node):
            """返回以 node 为起点向下延伸的最长同值路径长度"""
            if not node:
                return 0
            
            # 递归计算左右子树
            left_len = dfs(node.left)
            right_len = dfs(node.right)
            
            # 初始化当前节点向左右延伸的长度
            left_path = right_path = 0
            
            # 如果左孩子值相同，可以向左延伸
            if node.left and node.left.val == node.val:
                left_path = left_len + 1
            
            # 如果右孩子值相同，可以向右延伸
            if node.right and node.right.val == node.val:
                right_path = right_len + 1
            
            # 更新全局最大值（左路径 + 右路径）
            self.max_len = max(self.max_len, left_path + right_path)
            
            # 返回单侧最长路径
            return max(left_path, right_path)
        
        dfs(root)
        return self.max_len
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 是树的高度

## 关键点总结

1. 路径可以转弯（通过某个节点）
2. 返回值是单侧路径，全局答案是双侧之和
3. 只有值相同才能延伸

## 易错点

1. 混淆路径长度和节点数量
2. 没有正确处理转弯的情况
3. 忘记检查节点值是否相同
