## 题目描述

给定一个按升序排列的不同整数数组 `arr`，如果存在索引 `i` 使得 `arr[i] == i`，则称索引 `i` 为数组的**不动点**。

返回最小的不动点。如果不存在不动点，返回 `-1`。

**示例 1：**
```
输入：arr = [-10,-5,0,3,7]
输出：3
解释：对于给定的数组，arr[0] = -10, arr[1] = -5, arr[2] = 0, arr[3] = 3，因此输出 3。
```

**示例 2：**
```
输入：arr = [0,2,5,8,17]
输出：0
解释：arr[0] = 0，因此输出 0。
```

**示例 3：**
```
输入：arr = [-10,-5,3,4,7,9]
输出：-1
解释：不存在 arr[i] == i，因此返回 -1。
```

**提示：**
- `1 <= arr.length < 10^4`
- `-10^9 <= arr[i] <= 10^9`
- `arr` 中的所有元素互不相同
- `arr` 按升序排列

## 解题思路

这道题可以用线性扫描，但利用数组的**有序性**可以用**二分查找**优化。

**关键观察：**
1. 如果 `arr[i] > i`，则 `arr[i+1]` 只会更大（因为数组递增且唯一）
2. 如果 `arr[i] < i`，则 `arr[i-1]` 只会更小
3. 这意味着不动点具有**单调性**，可以二分查找

**二分策略：**
- 如果 `arr[mid] >= mid`，不动点可能在左侧（包括 `mid`）
- 如果 `arr[mid] < mid`，不动点一定在右侧

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def fixedPoint(self, arr: List[int]) -> int:
        """
        时间复杂度：O(log n)
        空间复杂度：O(1)
        """
        left, right = 0, len(arr) - 1
        result = -1
        
        while left <= right:
            mid = (left + right) // 2
            
            if arr[mid] == mid:
                # 找到不动点，但要继续找更小的
                result = mid
                right = mid - 1
            elif arr[mid] > mid:
                # 不动点可能在左侧
                right = mid - 1
            else:  # arr[mid] < mid
                # 不动点一定在右侧
                left = mid + 1
        
        return result
```

### 方法二：线性扫描

```python
from typing import List

class Solution:
    def fixedPoint(self, arr: List[int]) -> int:
        """
        线性扫描，简单直接
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        for i in range(len(arr)):
            if arr[i] == i:
                return i
            # 剪枝：如果 arr[i] > i，后面的只会更大
            if arr[i] > i:
                break
        return -1
```

### 方法三：优化的二分查找

```python
from typing import List

class Solution:
    def fixedPoint(self, arr: List[int]) -> int:
        """
        寻找最左侧的不动点
        """
        left, right = 0, len(arr) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            
            if arr[mid] >= mid:
                right = mid
            else:
                left = mid + 1
        
        # 检查 left 是否是不动点
        return left if left < len(arr) and arr[left] == left else -1
```

### 方法四：简洁的一行式

```python
from typing import List

class Solution:
    def fixedPoint(self, arr: List[int]) -> int:
        """
        Python 简洁写法
        """
        fixed_points = [i for i in range(len(arr)) if arr[i] == i]
        return fixed_points[0] if fixed_points else -1
```

## 复杂度分析

**方法一和方法三：二分查找**
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

**方法二：线性扫描**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法四：列表推导式**
- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 是不动点数量

## 图解示例

**示例 1：arr = [-10,-5,0,3,7]**

```
二分查找过程：

初始：left=0, right=4
mid=2, arr[2]=0 < 2, left=3

left=3, right=4
mid=3, arr[3]=3 = 3 ✓
result=3, right=2

left=3, right=2, 结束

答案：3
```

**示例 2：arr = [0,2,5,8,17]**

```
二分查找：

mid=2, arr[2]=5 > 2, right=1
mid=0, arr[0]=0 = 0 ✓
result=0, right=-1

结束，答案：0
```

**示例 3：arr = [-10,-5,3,4,7,9]**

```
检查每个位置：
i=0: arr[0]=-10 ≠ 0
i=1: arr[1]=-5 ≠ 1
i=2: arr[2]=3 ≠ 2
i=3: arr[3]=4 ≠ 3
i=4: arr[4]=7 ≠ 4
i=5: arr[5]=9 ≠ 5

答案：-1
```

**为什么二分有效？**

```
观察 arr[i] - i 的单调性：

arr = [-10, -5, 0, 3, 7]
i   = [  0,  1, 2, 3, 4]
差值 = [-10, -6,-2, 0, 3]

差值递增！当差值从负变为 0 或正时，找到不动点
```

## 关键点总结

1. **单调性**：`arr[i] - i` 具有单调性，可以二分
2. **找最小**：找到不动点后继续向左搜索
3. **剪枝优化**：线性扫描时，`arr[i] > i` 可以提前终止
4. **边界检查**：确保返回的索引是有效的不动点

## 易错点

1. **找最小**：找到一个不动点后不能立即返回，要继续找更小的
2. **边界条件**：数组为空、只有一个元素的情况
3. **二分终止**：确保循环能正确终止
4. **验证结果**：二分结束后要验证 `arr[left] == left`
