## 题目描述

给你一个字符串 `word`，每次可以在任意位置插入字母 `a`、`b` 或 `c`。请返回使 `word` 成为由 `abc` 重复组成的有效字符串所需的最少插入次数。

**示例 1：**
```
输入：word = "b"
输出：2
解释：插入 a 和 c 变成 "abc"，需要 2 次
```

**示例 2：**
```
输入：word = "aaa"
输出：6
解释：变成 "abcabcabc" 需要插入 6 个字符
```

**示例 3：**
```
输入：word = "abc"
输出：0
```

**数据范围：**
- 1 <= word.length <= 50
- word 只含 'a'、'b'、'c'

## 解题思路

贪心：将字符串尽量匹配多个 "abc" 片段。从左到右扫描，对每个字符，若它符合当前期望的下一个字符（a->b->c->a...），则继续；否则开始一个新的 "abc"，并计算需要补充的字符数。

最终统计每段 "abc" 需要补充的字符数之和。

## Python 代码实现

### 方法一：贪心模拟（推荐）

```python
class Solution:
    def addMinimum(self, word: str) -> int:
        ans = 0
        i = 0
        n = len(word)

        while i < n:
            # 尝试从当前位置匹配一个 "abc"（可能不完整）
            # 记录已匹配的字符序号（0=a, 1=b, 2=c）
            j = 0  # 期望的字符序号
            while i < n and ord(word[i]) - ord('a') == j:
                i += 1
                j += 1
                if j == 3:
                    break  # 完整匹配 abc
            # 这段匹配了 j 个字符，还需要补充 3 - j 个
            ans += 3 - j

        return ans
```

### 方法二：统计相邻字符变化

```python
class Solution:
    def addMinimum(self, word: str) -> int:
        # 统计需要多少个完整 abc 组
        # 当 word[i] <= word[i-1] 时（字符序不递增），开始新的一组
        n = len(word)
        groups = 1  # 至少一组
        for i in range(1, n):
            if word[i] <= word[i - 1]:
                groups += 1  # 新开一组
        # 每组需要 3 个字符，实际字符数为 n，需要补充 3 * groups - n
        return 3 * groups - n
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 尽量将字符贪心地归入当前 abc 组
2. 当下一个字符小于等于前一个时，需要开新的 abc 组
3. 最终答案 = 组数 * 3 - 字符串长度

## 易错点

1. 方法二：若 `word[i] <= word[i-1]` 则开新组（注意相等时也开新组，如 "aa"）
2. 每组一定有 3 个字符，不足的补全
