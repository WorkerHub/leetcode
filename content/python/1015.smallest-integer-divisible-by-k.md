## 题目描述

给定正整数 `k`，你需要找出可以被 `k` 整除的、仅包含数字 `1` 的最小正整数 `n` 的长度。

返回这个整数 `n` 的长度。如果不存在这样的 `n`，就返回 `-1`。

注意：`n` 可能不符合 64 位带符号整数。

**示例 1：**

```
输入：k = 1
输出：1
解释：最小的答案是 n = 1，其长度为 1。
```

**示例 2：**

```
输入：k = 2
输出：-1
解释：不存在可被 2 整除的正整数 n。
```

**示例 3：**

```
输入：k = 3
输出：3
解释：最小的答案是 n = 111，其长度为 3。
```

**提示：**

- `1 <= k <= 10^5`

## 解题思路

这道题的关键在于：我们不需要真正构造出这个可能非常大的数字，而是利用**模运算的性质**来判断。

### 核心观察

1. **构造规律**：我们要找的数字 n 只包含数字 1，即：
   - 长度为 1：n = 1
   - 长度为 2：n = 11
   - 长度为 3：n = 111
   - 长度为 4：n = 1111
   - ...

2. **数学性质**：如果一个数字 n 可以被 k 整除，那么 `n % k == 0`

3. **模运算递推**：假设当前数字的余数是 `remainder`，那么下一个数字（多加一个 1）的余数是：
   ```
   new_remainder = (remainder * 10 + 1) % k
   ```
   例如：`11 = 1 * 10 + 1`，`111 = 11 * 10 + 1`

4. **终止条件**：
   - 如果某个 `remainder == 0`，说明找到了答案
   - 如果出现了重复的余数，说明进入循环，永远找不到答案

5. **数学定理**：如果 k 能被 2 或 5 整除，则不存在解。因为：
   - 只包含 1 的数字一定是奇数（不能被 2 整除）
   - 只包含 1 的数字末位一定是 1（不能被 5 整除）

6. **鸽巢原理**：余数的可能取值范围是 `[0, k-1]`，共 k 个值。如果我们计算超过 k 次还没找到答案，必然会出现重复余数（鸽巢原理），此时返回 -1。

## Python 代码实现

### 方法一：模运算模拟（推荐）⭐

```python
class Solution:
    def smallestRepunitDivByK(self, k: int) -> int:
        # 如果 k 能被 2 或 5 整除，直接返回 -1
        # 因为只包含 1 的数字是奇数且末位为 1，不可能被 2 或 5 整除
        if k % 2 == 0 or k % 5 == 0:
            return -1
        
        # 初始化：长度为 1 的数字是 1
        remainder = 0
        
        # 最多尝试 k 次，根据鸽巢原理，超过 k 次必然出现重复余数
        for length in range(1, k + 1):
            # 计算新的余数：相当于在当前数字后面加一个 1
            # 例如：1 -> 11 -> 111 -> 1111
            remainder = (remainder * 10 + 1) % k
            
            # 如果余数为 0，说明当前长度的数字可以被 k 整除
            if remainder == 0:
                return length
        
        # 如果循环结束还没找到，返回 -1
        return -1
```

### 方法二：使用集合检测循环

```python
class Solution:
    def smallestRepunitDivByK(self, k: int) -> int:
        # 提前过滤不可能的情况
        if k % 2 == 0 or k % 5 == 0:
            return -1
        
        remainder = 0
        seen = set()  # 用于记录已出现的余数
        length = 0
        
        while True:
            # 计算新的余数
            remainder = (remainder * 10 + 1) % k
            length += 1
            
            # 找到答案
            if remainder == 0:
                return length
            
            # 出现重复余数，说明进入循环，无解
            if remainder in seen:
                return -1
            
            seen.add(remainder)
```

### 方法三：暴力模拟（不推荐，仅用于理解）

```python
class Solution:
    def smallestRepunitDivByK(self, k: int) -> int:
        # 这种方法会超时，仅用于理解题意
        if k % 2 == 0 or k % 5 == 0:
            return -1
        
        n = 1  # 从 1 开始
        length = 1
        
        # 限制最大尝试次数，避免无限循环
        while length <= k:
            if n % k == 0:
                return length
            # 构造下一个数字：11, 111, 1111...
            n = n * 10 + 1
            length += 1
        
        return -1
```

## 复杂度分析

**方法一（推荐）：**

- **时间复杂度**：O(k)
  - 最多循环 k 次，每次循环只做常数次运算
  - 根据鸽巢原理，余数的取值范围是 [0, k-1]，最多 k 次必然找到答案或出现重复

- **空间复杂度**：O(1)
  - 只使用了常数个变量（remainder、length）

**方法二：**

- **时间复杂度**：O(k)
  - 同方法一

- **空间复杂度**：O(k)
  - 使用了集合存储已出现的余数，最多存储 k 个

**方法三：**

- **时间复杂度**：O(k)
  - 虽然时间复杂度相同，但实际运行中可能因为大数运算导致超时

- **空间复杂度**：O(1)

## 关键点总结

1. **模运算优化**：不需要构造实际的大数，只需要追踪余数的变化
2. **提前剪枝**：k 能被 2 或 5 整除时，直接返回 -1
3. **鸽巢原理**：最多尝试 k 次，超过则必然出现循环
4. **递推公式**：`new_remainder = (old_remainder * 10 + 1) % k`
5. **数学性质**：理解为什么被 2 或 5 整除的 k 无解

## 易错点

1. **数字溢出**：不要尝试真正构造这个数字（可能超过 64 位整数），使用模运算
2. **无限循环**：忘记设置循环终止条件，导致死循环
3. **边界情况**：
   - k = 1 时，答案是 1
   - k 为偶数或 5 的倍数时，直接返回 -1
4. **余数理解**：`(a * 10 + 1) % k` 相当于在 a 后面添加一个数字 1 后的余数
5. **提前优化**：忘记判断 k % 2 == 0 或 k % 5 == 0 的情况
