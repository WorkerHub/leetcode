## 题目描述

给你一个字符串 `s` 和一个整数 `k`，返回一个数组 `ans`，其中 `ans[i]` 是字符串 `s` 的长度为 `k` 的子串 `s[i..i+k-1]` 中不同字符的数量。

**示例 1：**

```
输入：s = "aabccc", k = 3
输出：[2, 3, 2, 1]
解释：
- s[0..2] = "aab"，不同字符：{a, b} = 2
- s[1..3] = "abc"，不同字符：{a, b, c} = 3
- s[2..4] = "bcc"，不同字符：{b, c} = 2
- s[3..5] = "ccc"，不同字符：{c} = 1
```

**示例 2：**

```
输入：s = "abcd", k = 2
输出：[2, 2, 2]
```

**提示：**
- `1 <= k <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 解题思路

使用**滑动窗口 + 哈希表**：
1. 维护大小为 k 的窗口，用哈希表记录窗口内各字符出现次数。
2. 窗口右移时，加入新字符，移除最左字符。
3. 哈希表中键的数量即为不同字符数。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countDistinct(self, s: str, k: int) -> List[int]:
        n = len(s)
        freq = defaultdict(int)
        ans = []

        # 初始化第一个窗口
        for i in range(k):
            freq[s[i]] += 1

        ans.append(len(freq))

        # 滑动窗口
        for i in range(k, n):
            # 加入新字符
            freq[s[i]] += 1
            # 移除最左字符
            left_char = s[i - k]
            freq[left_char] -= 1
            if freq[left_char] == 0:
                del freq[left_char]
            ans.append(len(freq))

        return ans
```

### 方法二：数组计数（仅限小写字母）

```python
from typing import List

class Solution:
    def countDistinct(self, s: str, k: int) -> List[int]:
        n = len(s)
        cnt = [0] * 26
        distinct = 0
        ans = []

        for i in range(n):
            # 加入右端字符
            c = ord(s[i]) - ord('a')
            if cnt[c] == 0:
                distinct += 1
            cnt[c] += 1

            # 窗口达到大小 k 后处理
            if i >= k - 1:
                ans.append(distinct)
                # 移除左端字符
                lc = ord(s[i - k + 1]) - ord('a')
                cnt[lc] -= 1
                if cnt[lc] == 0:
                    distinct -= 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符入窗口和出窗口各一次
- 空间复杂度：O(min(k, 26)) = O(1)，窗口内不同字符数有限

## 关键点总结

1. 滑动窗口维护固定大小窗口，字符频率表记录状态。
2. 字符计数降为 0 时删除，保持哈希表大小等于不同字符数。
3. 使用数组替代哈希表可以减少常数因子。

## 易错点

1. 初始化第一个窗口后，从位置 k 开始滑动（不是从 0）。
2. 移除字符时检查频率是否为 0，为 0 则减少不同字符计数。
3. 返回数组长度应为 `n - k + 1`。
