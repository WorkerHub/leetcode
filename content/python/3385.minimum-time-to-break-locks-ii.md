## 题目描述

与 3376 相同的问题，但锁的数量更多（n <= 10^5），需要贪心或图论方法而非状压 DP。

每把锁有强度 `strength[i]`，当前能量 `X = 1 + 已破锁数 * K`。破开第 i 把锁的等待时间 = `ceil(X / strength[i]) * strength[i] - X`。

找最优顺序使总等待时间最小。

**提示：**
- `1 <= n <= 10^5`
- `1 <= strength[i] <= 10^9`
- `1 <= K <= 10^9`

## 解题思路

**贪心（复杂分析）：**

破开第 `j` 把锁（第 0 个破的）时，`X = 1`；第 `j` 个破（0 索引）时，`X = 1 + j * K`。

等待时间 = `ceil((1 + j * K) / strength[i]) * strength[i] - (1 + j * K)`。

这本质上是一个分配问题：将 n 把锁分配到 n 个"时间槽"（第 0, 1, ..., n-1 个破的顺序），使总等待时间最小。

**对每个时间槽 j，X = 1 + j * K**：

破锁 `i` 在时间槽 `j` 的代价 = `ceil(X / s_i) * s_i - X`。

这是一个最小权完美匹配问题（n 把锁，n 个时间槽），用 KM 算法或贪心近似。

由于 n 可达 10^5，需要高效解法。

**观察：** 当 K 很大时，`X = 1 + j * K ≈ j * K`，代价约为 `(ceil(j*K / s_i) - j) * K + s_i - 1`，较复杂。

**实用贪心：** 排序后按某种规则匹配（但最优解不一定是贪心）。

## Python 代码实现

### 方法一：状压 DP（适合 n <= 20）

```python
from typing import List
import math

class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        INF = float('inf')
        
        dp = [INF] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            num_opened = bin(mask).count('1')
            X = 1 + num_opened * K
            
            for i in range(n):
                if mask & (1 << i):
                    continue
                s = strength[i]
                need = math.ceil(X / s) * s
                wait = need - X
                new_mask = mask | (1 << i)
                dp[new_mask] = min(dp[new_mask], dp[mask] + wait)
        
        return dp[(1 << n) - 1]
```

### 方法二：贪心排序（启发式，不保证最优）

```python
from typing import List
import math

class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        
        # 按强度升序尝试（贪心：先破弱锁）
        # 注意：这不一定是最优解，但是一种合理的启发
        order = sorted(range(n), key=lambda i: strength[i])
        
        total = 0
        for j, i in enumerate(order):
            X = 1 + j * K
            s = strength[i]
            need = math.ceil(X / s) * s
            total += need - X
        
        return total
```

## 复杂度分析

**方法一（状压 DP）：**
- 时间复杂度：O(2^n * n)
- 适用 n <= 20

## 关键点总结

1. 破锁顺序影响每步的 X 值，进而影响等待时间。
2. 对大 n，状压 DP 超时，需要贪心或匈牙利算法等高级方法。
3. 实际竞赛中此题难度极高，完整最优解需要深入分析。

## 易错点

1. `X = 1 + j * K`，j 是第几把（0 索引）破的锁。
2. 等待时间计算：`ceil(X / s) * s - X`，使用 `math.ceil`。
3. 状压 DP 只适合小规模（n <= 20）。
