## 题目描述

给你一个字符串 `text` 和一个屏幕尺寸 `w x h`。你可以以任意字体大小显示该文本，字体大小的范围从 `fonts[0]` 到 `fonts[fonts.length - 1]`，`fonts` 数组是升序排列的。

有一个 `FontInfo` 接口可以获取字符在特定字体大小下的宽度和高度：
- `FontInfo.getWidth(fontSize, ch)` 返回字符 `ch` 在字体 `fontSize` 下的宽度
- `FontInfo.getHeight(fontSize)` 返回字体 `fontSize` 的高度

返回可以在屏幕上**完整显示** `text` 的**最大字体大小**。如果无法显示，返回 `-1`。

**条件：**
- 文字显示在一行中（不换行）
- 文本总宽度 <= `w` 且高度 <= `h`

## 解题思路

由于字体大小单调递增，可以使用**二分查找**：
- 字体越大，宽度和高度越大
- 找到满足条件（宽 <= w 且高 <= h）的最大字体

**计算文本宽度：** 对每个字体大小，累加 `text` 中每个字符的宽度之和。

## 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

# FontInfo 接口（由系统提供）
class FontInfo:
    def getWidth(self, fontSize: int, ch: str) -> int: ...
    def getHeight(self, fontSize: int) -> int: ...

class Solution:
    def maxFont(self, text: str, w: int, h: int, fonts: List[int], fontInfo: 'FontInfo') -> int:
        def can_fit(font_size: int) -> bool:
            """检查给定字体大小是否能显示文本"""
            # 检查高度
            if fontInfo.getHeight(font_size) > h:
                return False
            # 检查宽度
            total_width = sum(fontInfo.getWidth(font_size, c) for c in text)
            return total_width <= w
        
        # 二分查找最大可用字体大小
        lo, hi = 0, len(fonts) - 1
        ans = -1
        
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_fit(fonts[mid]):
                ans = fonts[mid]  # 当前字体可用，尝试更大的
                lo = mid + 1
            else:
                hi = mid - 1  # 字体太大，尝试更小的
        
        return ans
```

### 方法二：二分 + 预处理唯一字符

```python
from typing import List

class Solution:
    def maxFont(self, text: str, w: int, h: int, fonts: List[int], fontInfo: 'FontInfo') -> int:
        # 预处理：只需查询 text 中出现的不同字符的宽度
        unique_chars = set(text)
        char_count = {}
        for c in text:
            char_count[c] = char_count.get(c, 0) + 1
        
        def can_fit(font_size: int) -> bool:
            if fontInfo.getHeight(font_size) > h:
                return False
            total_width = sum(
                fontInfo.getWidth(font_size, c) * cnt
                for c, cnt in char_count.items()
            )
            return total_width <= w
        
        lo, hi = 0, len(fonts) - 1
        ans = -1
        
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_fit(fonts[mid]):
                ans = fonts[mid]
                lo = mid + 1
            else:
                hi = mid - 1
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二分查找 | O(|text| * log(|fonts|)) | O(1) |
| 预处理唯一字符 | O(|text| + 26 * log(|fonts|)) | O(26) |

预处理版本在 text 很长但字符种类少时更高效。

## 关键点总结

1. 字体大小单调递增，满足二分查找条件（具有单调性）
2. 二分时找满足条件的最大字体，用 `ans = fonts[mid]; lo = mid + 1` 记录并右移
3. 需要同时检查高度和宽度两个条件
4. 优化：预处理每个字符出现次数，避免重复查询

## 易错点

- 找最大可用字体：满足条件时向右搜索（`lo = mid + 1`），不满足时向左（`hi = mid - 1`）
- 初始 `ans = -1`，若全部不满足则返回 -1
- 宽度是 text 中所有字符宽度之和，不是唯一字符
