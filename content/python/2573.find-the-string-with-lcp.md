## 题目描述

给你一个 `n x n` 整数矩阵 `lcp`，其中 `lcp[i][j]` 表示字符串 `word` 的后缀 `word[i:]` 和后缀 `word[j:]` 的最长公共前缀长度。

返回符合以下条件的 **字典序最小** 的字符串 `word`：
- 长度为 n
- 对所有 `0 <= i <= j < n`，`LCP(word[i:], word[j:]) == lcp[i][j]`

若不存在，返回 `""`。

**示例 1：**

```
输入：lcp = [[4,0,2,0],[0,3,0,1],[2,0,2,0],[0,1,0,1]]
输出："abab"
```

**提示：**

- `1 <= n <= 1000`

## 解题思路

**贪心构造 + 验证**：

1. 构造：贪心从 'a' 开始，对每个位置 i，若 i 在之前某个位置 j 的 LCP 覆盖范围内，则 word[i] = word[j]；否则尝试分配最小的新字母
2. 验证：检查构造的字符串是否满足所有 lcp 条件

验证：计算实际 LCP，与给定 lcp 矩阵比较。

## Python 代码实现

### 方法一：贪心构造 + DP 验证（推荐）

```python
from typing import List

class Solution:
    def findTheString(self, lcp: List[List[int]]) -> str:
        n = len(lcp)
        word = [''] * n
        c = 0  # 当前使用的字母（0='a', 1='b', ...）

        # 贪心构造：对每个位置，若 lcp[i][j] > 0（j < i），则 word[i] = word[j]
        for i in range(n):
            if word[i]:
                continue
            if c >= 26:
                return ""
            word[i] = chr(ord('a') + c)
            c += 1
            # 根据 lcp[i][j] 填充后续位置
            for j in range(i + 1, n):
                if lcp[i][j] > 0:
                    word[j] = word[i]

        # 验证：计算实际 lcp 并与给定矩阵比较
        # 用 DP 计算实际 lcp
        real_lcp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if word[i] == word[j]:
                    real_lcp[i][j] = (real_lcp[i+1][j+1] if i+1 < n and j+1 < n else 0) + 1
                else:
                    real_lcp[i][j] = 0

        for i in range(n):
            for j in range(n):
                if real_lcp[i][j] != lcp[i][j]:
                    return ""

        return ''.join(word)
```

### 方法二：基于 lcp 直接构造

```python
from typing import List

class Solution:
    def findTheString(self, lcp: List[List[int]]) -> str:
        n = len(lcp)
        word = [0] * n  # 用数字表示字母（0='a',...）
        next_char = 0

        for i in range(n):
            if word[i] != 0:
                continue
            next_char += 1
            if next_char > 26:
                return ""
            word[i] = next_char
            for j in range(i + 1, n):
                if lcp[i][j] > 0:
                    word[j] = word[i]

        # 将 word 变为字符串
        s = ''.join(chr(ord('a') + w - 1) for w in word)

        # 验证
        n = len(s)
        check = [[0]*n for _ in range(n)]
        for i in range(n-1, -1, -1):
            for j in range(n-1, -1, -1):
                if s[i] == s[j]:
                    check[i][j] = (check[i+1][j+1] if i+1 < n and j+1 < n else 0) + 1

        return s if all(check[i][j] == lcp[i][j] for i in range(n) for j in range(n)) else ""
```

## 复杂度分析

- 时间复杂度：O(n²)，构造和验证均为 O(n²)
- 空间复杂度：O(n²)，lcp 验证矩阵

## 关键点总结

1. 贪心：尽量使用字典序小的字母
2. lcp[i][j] > 0 意味着 word[i] == word[j]，利用这个传播赋值
3. 构造后必须验证（贪心可能构造出不合法的字符串）

## 易错点

1. 若最终使用的字母种类超过 26，返回 ""
2. 验证步骤用 DP 逆序计算实际 LCP，不能省略
3. lcp[i][i] = n - i（后缀与自身 LCP 等于后缀长度），需验证
