## 题目描述

给你两个整数 `n` 和 `start`。你的任务是返回任意 `(0,1,2,...,2^n-1)` 的排列 `p`，并且满足：

- `p[0] = start`
- `p[i]` 和 `p[i+1]` 的二进制表示形式只有一位不同
- `p[0]` 和 `p[2^n -1]` 的二进制表示形式也只有一位不同

示例 1：
```
输入：n = 2, start = 3
输出：[3,2,0,1]
解释：这个排列的二进制表示是 (11,10,00,01)
     11 和 10 只有一位不同
     10 和 00 只有一位不同
     00 和 01 只有一位不同
     01 和 11 只有一位不同
```

示例 2：
```
输入：n = 3, start = 2
输出：[2,6,7,5,4,0,1,3]
解释：这个排列的二进制表示是 (010,110,111,101,100,000,001,011)
```

提示：
- `1 <= n <= 16`
- `0 <= start < 2^n`

## 解题思路

这道题本质上是格雷码（Gray Code）问题的变形。

### 格雷码的定义
格雷码是一个二进制数字系统，相邻两个数只有一位二进制数不同。

### 生成格雷码的公式
对于数字 i，其格雷码为：`gray(i) = i ^ (i >> 1)`

### 本题的解法
1. 生成标准的 n 位格雷码序列
2. 找到 start 在格雷码序列中的位置
3. 从该位置开始循环输出

或者更简单的方法：
- 生成格雷码后，与 start 异或，使序列从 start 开始

## Python 代码实现

### 方法一：格雷码公式 + 异或（推荐）

```python
from typing import List

class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        """
        使用格雷码公式生成序列
        
        Args:
            n: 位数
            start: 起始数字
            
        Returns:
            环形排列
        """
        # 生成标准格雷码序列
        result = []
        for i in range(1 << n):  # 2^n 个数
            gray = i ^ (i >> 1)
            result.append(gray)
        
        # 找到 start 在格雷码中的位置
        start_idx = result.index(start)
        
        # 从 start 位置开始循环排列
        return result[start_idx:] + result[:start_idx]
```

### 方法二：直接异或调整（最优）

```python
from typing import List

class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        """
        通过异或直接调整序列
        
        关键观察：如果标准格雷码是 [g0, g1, ..., gk]
        那么 [g0^s, g1^s, ..., gk^s] 也满足相邻只差一位
        且如果 gi = start，则 gi^s = start^s = 0
        所以我们让每个格雷码都异或 start
        """
        result = []
        for i in range(1 << n):
            gray = i ^ (i >> 1)
            # 直接异或 start，使得原本的 start 位置变成 0 位置
            # 然后再异或回 start，使得 0 位置变成 start
            result.append(gray ^ start)
        
        return result
```

### 方法三：递归生成格雷码

```python
from typing import List

class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        """
        递归生成格雷码，然后调整起始位置
        """
        def gray_code(n: int) -> List[int]:
            """递归生成 n 位格雷码"""
            if n == 0:
                return [0]
            
            # 获取 n-1 位的格雷码
            prev = gray_code(n - 1)
            
            # n 位格雷码 = [0 + prev, 1 + reverse(prev)]
            result = prev.copy()
            for i in range(len(prev) - 1, -1, -1):
                result.append((1 << (n - 1)) | prev[i])
            
            return result
        
        codes = gray_code(n)
        start_idx = codes.index(start)
        
        return codes[start_idx:] + codes[:start_idx]
```

### 方法四：位运算优化

```python
from typing import List

class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        """
        最简洁的写法
        """
        return [i ^ (i >> 1) ^ start for i in range(1 << n)]
```

### 方法五：回溯（仅用于理解，效率低）

```python
from typing import List

class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        """
        使用回溯搜索（会超时，仅用于理解）
        """
        target_len = 1 << n
        result = []
        visited = set()
        
        def backtrack(path: List[int]):
            if len(path) == target_len:
                # 检查首尾是否只差一位
                if bin(path[0] ^ path[-1]).count('1') == 1:
                    result.append(path[:])
                return
            
            current = path[-1]
            # 尝试翻转每一位
            for i in range(n):
                next_num = current ^ (1 << i)
                if next_num not in visited:
                    visited.add(next_num)
                    path.append(next_num)
                    backtrack(path)
                    path.pop()
                    visited.remove(next_num)
        
        visited.add(start)
        backtrack([start])
        
        return result[0] if result else []
```

## 复杂度分析

**方法一和方法二（推荐）：**
- 时间复杂度：O(2^n)
- 空间复杂度：O(2^n)

**方法三：**
- 时间复杂度：O(2^n)
- 空间复杂度：O(2^n)

**方法四：**
- 时间复杂度：O(2^n)
- 空间复杂度：O(1)，除了结果数组

**方法五：**
- 时间复杂度：O(n × 2^n × n!)，会超时
- 空间复杂度：O(2^n)

## 关键点总结

1. 理解格雷码的定义和性质
2. 格雷码公式：`gray(i) = i ^ (i >> 1)`
3. 异或的性质：`a ^ b ^ b = a`
4. 直接异或 start 可以调整序列起点
5. 格雷码保证相邻元素只差一位

## 易错点

1. 不知道格雷码公式
2. 循环数组时索引处理错误
3. 异或操作的理解不清楚
4. 忘记处理环形（首尾相连）的条件
5. 位移运算的优先级问题
