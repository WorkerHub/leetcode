## 题目描述

给定两个长度相同的整数数组 `nums1` 和 `nums2`，在每一步操作中，你可以交换 `nums1[i]` 和 `nums2[i]`。

例如，如果 `nums1 = [1,2,3,8]`，`nums2 = [5,6,7,4]`，你可以交换 `i = 3` 处的元素，得到 `nums1 = [1,2,3,4]` 和 `nums2 = [5,6,7,8]`。

返回使 `nums1` 和 `nums2` **严格递增** 所需操作的最小次数。题目数据保证给定的输入总是有解。

**示例 1:**
```
输入: nums1 = [1,3,5,4], nums2 = [1,2,3,7]
输出: 1
解释: 
交换 nums1[3] 和 nums2[3]。
之后序列为: nums1 = [1,3,5,7], nums2 = [1,2,3,4]
两个序列都是严格递增的。
```

**示例 2:**
```
输入: nums1 = [0,3,5,8,9], nums2 = [2,1,4,6,9]
输出: 1
```

**提示:**
- `2 <= nums1.length <= 10^5`
- `nums2.length == nums1.length`
- `0 <= nums1[i], nums2[i] <= 2 * 10^5`

## 解题思路

这是一道经典的动态规划问题。核心思想是：对于每个位置，我们需要决定是否交换该位置的元素，以使两个数组都严格递增。

**关键观察：**
1. 对于位置 `i`，只有两种状态：交换或不交换
2. 位置 `i` 的决策依赖于位置 `i-1` 的状态
3. 我们需要确保 `nums1[i] > nums1[i-1]` 且 `nums2[i] > nums2[i-1]`

**状态定义：**
- `keep[i]`：前 `i` 个位置，第 `i` 个位置**不交换**时的最小交换次数
- `swap[i]`：前 `i` 个位置，第 `i` 个位置**交换**时的最小交换次数

**状态转移：**
对于位置 `i`，有两种情况：

1. **原始就满足递增**：`nums1[i] > nums1[i-1]` 且 `nums2[i] > nums2[i-1]`
   - 如果位置 `i-1` 不交换，则位置 `i` 也可以不交换
   - 如果位置 `i-1` 交换，则位置 `i` 也必须交换

2. **交换后满足递增**：`nums1[i] > nums2[i-1]` 且 `nums2[i] > nums1[i-1]`
   - 如果位置 `i-1` 不交换，则位置 `i` 必须交换
   - 如果位置 `i-1` 交换，则位置 `i` 可以不交换

## Python 代码实现

### 方法一：动态规划（推荐）⭐

```python
from typing import List

class Solution:
    def minSwap(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        
        # keep[i]: 位置 i 不交换的最小交换次数
        # swap[i]: 位置 i 交换的最小交换次数
        keep = [float('inf')] * n
        swap = [float('inf')] * n
        
        # 初始状态
        keep[0] = 0  # 位置 0 不交换，交换次数为 0
        swap[0] = 1  # 位置 0 交换，交换次数为 1
        
        for i in range(1, n):
            # 情况1：原始状态满足递增
            if nums1[i] > nums1[i-1] and nums2[i] > nums2[i-1]:
                keep[i] = keep[i-1]  # i-1 不交换，i 也不交换
                swap[i] = swap[i-1] + 1  # i-1 交换，i 也交换
            
            # 情况2：交换后满足递增
            if nums1[i] > nums2[i-1] and nums2[i] > nums1[i-1]:
                keep[i] = min(keep[i], swap[i-1])  # i-1 交换，i 不交换
                swap[i] = min(swap[i], keep[i-1] + 1)  # i-1 不交换，i 交换
        
        return min(keep[n-1], swap[n-1])
```

### 方法二：空间优化的动态规划

```python
from typing import List

class Solution:
    def minSwap(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        
        # 只需要保存前一个位置的状态
        keep = 0  # 前一个位置不交换的最小交换次数
        swap = 1  # 前一个位置交换的最小交换次数
        
        for i in range(1, n):
            # 当前位置的状态
            curr_keep = float('inf')
            curr_swap = float('inf')
            
            # 情况1：原始状态满足递增
            if nums1[i] > nums1[i-1] and nums2[i] > nums2[i-1]:
                curr_keep = keep
                curr_swap = swap + 1
            
            # 情况2：交换后满足递增
            if nums1[i] > nums2[i-1] and nums2[i] > nums1[i-1]:
                curr_keep = min(curr_keep, swap)
                curr_swap = min(curr_swap, keep + 1)
            
            # 更新状态
            keep = curr_keep
            swap = curr_swap
        
        return min(keep, swap)
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(n)，使用两个长度为 n 的数组

### 方法二：
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(1)，只使用常量额外空间

## 关键点总结

1. **状态定义清晰**：分别记录交换和不交换的最小次数
2. **状态转移条件**：需要分别判断原始递增和交换后递增两种情况
3. **初始化重要**：第一个位置的状态是后续计算的基础
4. **空间优化**：由于只依赖前一个状态，可以优化到 O(1) 空间
5. **题目保证有解**：不需要处理无解的情况

## 易错点

1. **忘记考虑两种情况**：原始递增和交换后递增可能同时满足
2. **状态初始化错误**：`keep[0] = 0`, `swap[0] = 1` 很关键
3. **使用 min 更新时忘记初始化为无穷大**
4. **边界条件**：从位置 1 开始遍历，而不是 0
