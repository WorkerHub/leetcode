## 题目描述

给你一个长度为 `n` 的字符串 `s`，以及整数 `k`。

**子序列**是从字符串中按顺序选取若干字符组成的新字符串（不需要连续）。

找到满足以下条件的**最长子序列** `seq`：
- `seq` 自身重复 `k` 次是 `s` 的子序列（即 `seq * k` 是 `s` 的子序列）

如果有多个等长的最优答案，返回**字典序最大**的那个。如果不存在，返回空字符串。

**示例 1：**
```
输入：s = "letsleetcode", k = 2
输出："let"
解释："letlet" 是 s 的子序列
```

**示例 2：**
```
输入：s = "bb", k = 2
输出："b"
```

**提示：**
- `n == s.length`
- `2 <= n, k <= 2000`
- `s` 只含小写英文字母
- `n` 能被 `k` 整除

## 解题思路

**关键观察：**
1. 答案子序列长度最多为 `n / k`
2. 首先过滤：只有出现次数 `>= k` 的字符才能出现在答案中
3. 用**回溯**枚举所有可能的子序列，从最长的开始找

**检验子序列：** 给定候选 `seq`，判断 `seq * k` 是否是 `s` 的子序列。

**回溯策略：** 从长度最大（`n//k`）向下枚举，每层从可用字符（出现次数 >= k 的字符）中选字符追加，维护最大答案。

## 代码实现

### 方法一：BFS 枚举（按长度层序）

```python
from collections import Counter

class Solution:
    def longestSubsequenceRepeatedK(self, s: str, k: int) -> str:
        # 过滤出现次数 >= k 的字符（按字典序逆序，便于找字典序最大答案）
        freq = Counter(s)
        valid_chars = sorted([c for c in freq if freq[c] >= k], reverse=True)

        def is_subseq(sub: str) -> bool:
            # 检查 sub * k 是否是 s 的子序列
            i = 0  # s 的指针
            for _ in range(k):
                for c in sub:
                    while i < len(s) and s[i] != c:
                        i += 1
                    if i == len(s):
                        return False
                    i += 1
            return True

        # BFS：从空字符串开始，每次添加一个字符，找到最长满足条件的子序列
        from collections import deque
        queue = deque([""])
        ans = ""

        while queue:
            cur = queue.popleft()
            for c in valid_chars:
                candidate = cur + c
                if is_subseq(candidate):
                    if len(candidate) > len(ans) or (
                        len(candidate) == len(ans) and candidate > ans
                    ):
                        ans = candidate
                    queue.append(candidate)

        return ans
```

### 方法二：DFS 回溯（从长到短）

```python
from collections import Counter

class Solution:
    def longestSubsequenceRepeatedK(self, s: str, k: int) -> str:
        n = len(s)
        freq = Counter(s)
        # 只考虑出现次数 >= k 的字符，且按字典序降序排列
        valid_chars = sorted([c for c in freq if freq[c] >= k], reverse=True)
        max_len = n // k

        def is_subseq(sub: str) -> bool:
            idx = 0
            for _ in range(k):
                for c in sub:
                    while idx < n and s[idx] != c:
                        idx += 1
                    if idx >= n:
                        return False
                    idx += 1
            return True

        ans = [""]

        def dfs(path: list):
            cur = "".join(path)
            if len(path) > len(ans[0]) or (len(path) == len(ans[0]) and cur > ans[0]):
                ans[0] = cur

            if len(path) == max_len:
                return

            for c in valid_chars:
                path.append(c)
                if is_subseq("".join(path)):
                    dfs(path)
                path.pop()

        dfs([])
        return ans[0]
```

## 复杂度分析

- 时间复杂度：O(n * |valid_chars|^(n/k))，最坏情况下指数级，但实际剪枝效果好
- 空间复杂度：O(n/k)，递归深度

## 关键点总结

1. 只有出现次数 >= k 的字符才有可能出现在答案中
2. 答案长度最多为 `n // k`
3. BFS 层序枚举保证了先找到较长的答案
4. `is_subseq` 函数需要检验 `seq * k` 是 `s` 的子序列

## 易错点

- 字典序最大而非最小，枚举时从 `z` 到 `a` 的逆序
- BFS 找到的不一定是字典序最大（同长度中要取最大），需要维护答案
- `n // k` 是答案上界，不需要枚举更长的子序列
