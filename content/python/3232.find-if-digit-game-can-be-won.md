## 题目描述

给你一个整数数组 `nums`，Alice 和 Bob 玩游戏：

- Alice 选择所有**个位数**（1-9）的数字
- Bob 选择所有**两位数**（10-99）的数字

**注意：** 原始题目描述是：Alice 选单位数，Bob 选其余，然后比较两人选取数字的总和，总和较大的获胜。

如果 Alice 能赢（严格大于），返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：nums = [1,2,22,9,33,73]
输出：false
```

**示例 2：**
```
输入：nums = [1,2,3]
输出：false
```

**示例 3：**
```
输入：nums = [12]
输出：false
```

**提示：**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 99`

## 解题思路

直接计算 Alice（单位数之和）和 Bob（两位数之和），比较大小。

Alice 选 1-9，Bob 选 10-99。若 Alice 的总和 > Bob 的总和，Alice 赢。

## Python 代码实现

### 方法一：直接计算（推荐）

```python
from typing import List

class Solution:
    def canAliceWin(self, nums: List[int]) -> bool:
        alice = sum(x for x in nums if x < 10)   # 个位数
        bob = sum(x for x in nums if x >= 10)    # 两位数
        return alice > bob
```

### 方法二：一次遍历

```python
from typing import List

class Solution:
    def canAliceWin(self, nums: List[int]) -> bool:
        diff = 0
        for x in nums:
            if x < 10:
                diff += x   # Alice 得分
            else:
                diff -= x   # Bob 得分
        return diff > 0
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 区分个位数（1-9）和两位数（10-99）
2. 比较两人总和，Alice 严格大于才赢

## 易错点

1. 注意是严格大于（`>`），相等时 Alice 不赢
2. 数字范围 1-99，所以只有个位数和两位数两种情况
