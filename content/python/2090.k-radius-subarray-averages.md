## 题目描述

给你一个整数数组 `nums` 和整数 `k`，对于每个下标 `i`（`0 <= i < n`），计算以 `i` 为中心、半径为 `k` 的子数组 `nums[i-k..i+k]` 的**平均值**（向下取整）。如果 `i-k < 0` 或 `i+k >= n`，则对应位置的值为 `-1`。

返回长度为 `n` 的数组 `avgs`。

**示例：**
```
输入：nums = [7,4,3,9,1,8,5,2,6], k = 3
输出：[-1,-1,-1,5,4,4,-1,-1,-1]
解释：i=3 时，子数组 [7,4,3,9,1,8,5] 共 7 个，平均 37//7=5
```

**提示：**
- `n == nums.length`
- `1 <= n <= 10^5`
- `0 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

**前缀和 + 滑动窗口：**

窗口大小固定为 `2k+1`，用前缀和快速计算区间和，然后除以窗口大小。

## 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def getAverages(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        avgs = [-1] * n
        window = 2 * k + 1

        if window > n:
            return avgs

        # 构建前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # 计算每个合法位置的平均值
        for i in range(k, n - k):
            total = prefix[i + k + 1] - prefix[i - k]
            avgs[i] = total // window

        return avgs
```

### 方法二：滑动窗口（不用前缀和）

```python
from typing import List

class Solution:
    def getAverages(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        avgs = [-1] * n
        window = 2 * k + 1

        if window > n:
            return avgs

        # 计算第一个窗口 [0, 2k] 的和
        curr_sum = sum(nums[:window])
        avgs[k] = curr_sum // window

        # 滑动窗口
        for i in range(k + 1, n - k):
            curr_sum += nums[i + k] - nums[i - k - 1]
            avgs[i] = curr_sum // window

        return avgs
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(n) |
| 滑动窗口 | O(n) | O(1) |

## 关键点总结

1. 窗口大小固定为 `2k+1`，前缀和 O(1) 时间查询区间和
2. 有效的中心下标范围：`[k, n-k-1]`
3. 整数除法自动向下取整

## 易错点

- 当 `2k+1 > n` 时，没有合法位置，直接返回全 -1
- 前缀和索引：`prefix[i+k+1] - prefix[i-k]` 对应 `nums[i-k..i+k]`（包含两端）
- 中心范围是 `range(k, n-k)`，不是 `range(k, n-k+1)`
