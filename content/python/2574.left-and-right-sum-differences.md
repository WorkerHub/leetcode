## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，请你找出一个下标从 0 开始的整数数组 `answer`，其中：

- `answer.length == nums.length`
- `answer[i] = |leftSum[i] - rightSum[i]|`
- `leftSum[i]` 是数组 `nums` 中下标 `i` 左侧元素之和（不含 `i`）
- `rightSum[i]` 是数组 `nums` 中下标 `i` 右侧元素之和（不含 `i`）

**示例 1：**

```
输入：nums = [10,4,8,3]
输出：[15,1,11,22]
解释：
leftSum  = [0, 10, 14, 22]
rightSum = [15, 11,  3,  0]
answer   = [|0-15|, |10-11|, |14-3|, |22-0|] = [15, 1, 11, 22]
```

**提示：**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^5`

## 解题思路

预计算前缀和和后缀和，对每个位置计算差的绝对值。

## Python 代码实现

### 方法一：前缀和（推荐）

```python
from typing import List

class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        n = len(nums)
        left_sum = 0
        right_sum = sum(nums)
        answer = []

        for i in range(n):
            right_sum -= nums[i]  # 右侧和不含 i
            answer.append(abs(left_sum - right_sum))
            left_sum += nums[i]   # 左侧和不含 i（下次循环时更新）

        return answer
```

### 方法二：两次遍历

```python
from typing import List

class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]

        answer = []
        for i in range(n):
            left = prefix[i]           # sum(nums[0..i-1])
            right = prefix[n] - prefix[i+1]  # sum(nums[i+1..n-1])
            answer.append(abs(left - right))

        return answer
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 方法一优化：用变量维护左侧和和右侧和，边遍历边更新
2. 左侧和初始为 0，右侧和初始为总和
3. 每步：先用当前 nums[i] 更新右侧和，再计算差，最后更新左侧和

## 易错点

1. leftSum[i] 不含下标 i 的元素本身
2. 方法一中更新顺序：先减 right（去掉当前元素），再计算，最后加 left
3. 结果取绝对值
