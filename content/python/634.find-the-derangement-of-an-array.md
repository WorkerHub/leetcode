## 题目描述

在组合数学中，错排问题（也叫更列问题）是这样的：有 `n` 个元素，最初按 `[1, 2, 3, ..., n]` 升序排列。

我们要求这 `n` 个元素的一个排列，使得没有任何一个元素出现在它原来的位置上。

例如，对于 `n = 3`，错排有 `[2,3,1]` 和 `[3,1,2]`，而 `[1,3,2]` 不是错排，因为 1 还在原位。

给定一个整数 `n`，返回这个数组的错排数量。由于答案可能很大，返回答案对 `10^9 + 7` 取模的结果。

**示例 1：**

```
输入：n = 3
输出：2
解释：
原数组：[1, 2, 3]
错排：[2, 3, 1] 和 [3, 1, 2]
[1, 3, 2] 不是错排，因为 1 在原位
```

**示例 2：**

```
输入：n = 2
输出：1
解释：[2, 1] 是唯一的错排
```

**提示：**
- `1 <= n <= 10^6`

## 解题思路

错排问题是经典的组合数学问题，有明确的数学公式和递推关系。

**错排数公式（递推关系）：**

设 `D(n)` 表示 `n` 个元素的错排数，则有：

```
D(n) = (n - 1) × [D(n - 1) + D(n - 2)]
```

**边界条件：**
- `D(1) = 0`（1 个元素无法错排）
- `D(2) = 1`（[2, 1] 是唯一错排）

**公式推导思路：**

考虑第 `n` 个元素的位置：
1. 它可以放在前 `n-1` 个位置中的任意一个，有 `n-1` 种选择
2. 假设第 `n` 个元素放在位置 `i`（`i ≠ n`）：
   - **情况 1**：第 `i` 个元素放在位置 `n`
     - 剩余 `n-2` 个元素形成错排：`D(n-2)` 种
   - **情况 2**：第 `i` 个元素不放在位置 `n`
     - 可以看作 `n-1` 个元素的错排（第 `i` 个元素不能在位置 `i` 和位置 `n`）：`D(n-1)` 种

所以：`D(n) = (n-1) × [D(n-1) + D(n-2)]`

**通项公式（可选）：**

```
D(n) = n! × ∑((-1)^k / k!) for k from 0 to n
     ≈ n! / e（当 n 很大时）
```

但递推公式更适合编程实现。

## Python 代码实现

### 方法一：动态规划（推荐）

```python
class Solution:
    def findDerangement(self, n: int) -> int:
        """
        计算 n 个元素的错排数量
        
        参数:
            n: 元素个数
        
        返回:
            错排数量 mod 10^9+7
        """
        MOD = 10**9 + 7
        
        # 边界条件
        if n == 1:
            return 0
        if n == 2:
            return 1
        
        # DP 数组
        dp = [0] * (n + 1)
        dp[1] = 0
        dp[2] = 1
        
        # 递推
        for i in range(3, n + 1):
            dp[i] = (i - 1) * (dp[i - 1] + dp[i - 2]) % MOD
        
        return dp[n]
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)

### 方法二：空间优化（滚动变量）

```python
class Solution:
    def findDerangement(self, n: int) -> int:
        """空间优化到 O(1)"""
        MOD = 10**9 + 7
        
        if n == 1:
            return 0
        if n == 2:
            return 1
        
        # 只需要保存前两个状态
        prev2 = 0  # D(1)
        prev1 = 1  # D(2)
        
        for i in range(3, n + 1):
            current = (i - 1) * (prev1 + prev2) % MOD
            prev2 = prev1
            prev1 = current
        
        return prev1
```

**时间复杂度：** O(n)  
**空间复杂度：** O(1)

### 方法三：数学公式（通项公式）

```python
class Solution:
    def findDerangement(self, n: int) -> int:
        """
        使用通项公式：D(n) = n! × ∑((-1)^k / k!)
        注意：需要处理大数和取模
        """
        MOD = 10**9 + 7
        
        if n == 1:
            return 0
        
        # 计算 n!
        factorial = 1
        for i in range(2, n + 1):
            factorial = (factorial * i) % MOD
        
        # 计算交错和：1 - 1/1! + 1/2! - 1/3! + ... + (-1)^n / n!
        # 使用分数形式，避免浮点数
        result = 0
        sign = 1
        term = 1  # 当前项的分母的倒数（相对于 n!）
        
        for k in range(1, n + 1):
            term = (term * pow(k, MOD - 2, MOD)) % MOD  # term /= k（模逆元）
            result = (result + sign * term) % MOD
            sign *= -1
        
        return (factorial * result) % MOD
```

**注意：** 这个方法复杂度也是 O(n)，且需要计算模逆元，不如递推简单。

### 方法四：递归 + 记忆化

```python
class Solution:
    def findDerangement(self, n: int) -> int:
        """递归 + 记忆化"""
        MOD = 10**9 + 7
        memo = {}
        
        def dp(k: int) -> int:
            if k == 1:
                return 0
            if k == 2:
                return 1
            if k in memo:
                return memo[k]
            
            memo[k] = (k - 1) * (dp(k - 1) + dp(k - 2)) % MOD
            return memo[k]
        
        return dp(n)
```

## 复杂度分析

**方法一、二（DP）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n) 或 O(1)

**方法三（公式）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法四（递归）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)（递归栈 + 记忆化）

## 图解示例

**n = 1:**
```
原数组：[1]
没有错排（1 必须在位置 1）
D(1) = 0
```

**n = 2:**
```
原数组：[1, 2]
错排：[2, 1]
D(2) = 1
```

**n = 3:**
```
原数组：[1, 2, 3]
所有排列：
[1,2,3] ✗ (1在原位)
[1,3,2] ✗ (1在原位)
[2,1,3] ✗ (3在原位)
[2,3,1] ✓ (都不在原位)
[3,1,2] ✓ (都不在原位)
[3,2,1] ✗ (2在原位)

D(3) = 2
```

**递推验证：**
```
D(3) = (3-1) × [D(2) + D(1)]
     = 2 × [1 + 0]
     = 2 ✓
```

**n = 4:**
```
D(4) = (4-1) × [D(3) + D(2)]
     = 3 × [2 + 1]
     = 9
```

## 关键点总结

1. **递推公式**：`D(n) = (n-1) × [D(n-1) + D(n-2)]`
2. **边界条件**：`D(1) = 0, D(2) = 1`
3. **取模运算**：每次计算后立即取模，避免溢出
4. **空间优化**：只需保存前两个状态，可以 O(1) 空间
5. **组合数学**：错排是经典问题，记住公式即可

## 易错点

1. **边界条件**：
   ```python
   # 注意 D(1) = 0, D(2) = 1，不要搞混
   if n == 1:
       return 0
   if n == 2:
       return 1
   ```

2. **取模时机**：
   ```python
   # 错误：最后才取模，可能溢出
   dp[i] = (i - 1) * (dp[i - 1] + dp[i - 2])
   return dp[n] % MOD
   
   # 正确：每步都取模
   dp[i] = (i - 1) * (dp[i - 1] + dp[i - 2]) % MOD
   ```

3. **数组越界**：如果用数组，确保 `dp` 大小至少为 `n+1`

4. **理解公式**：不要死记硬背，理解为什么是 `(n-1) × [D(n-1) + D(n-2)]`

## 数学推导

**为什么 D(n) = (n-1) × [D(n-1) + D(n-2)]？**

考虑第 `n` 个元素：
- 它可以放在位置 `1, 2, ..., n-1` 中的任意一个，共 `n-1` 种选择
- 假设放在位置 `k`（`k ≠ n`）

现在考虑元素 `k`（原本应该在位置 `k`，但现在被占了）：

**情况 1：元素 k 放在位置 n**
- 元素 `n` 和元素 `k` 互换位置，相当于"配对"了
- 剩余 `n-2` 个元素需要错排：`D(n-2)` 种

**情况 2：元素 k 不放在位置 n**
- 元素 `k` 可以放在 `1, 2, ..., k-1, k+1, ..., n-1` 中的任意位置（除了 `k` 和 `n`）
- 这相当于 `n-1` 个元素的错排问题（把位置 `n` 看作"虚拟的位置 `k`"）：`D(n-1)` 种

所以总共有：`(n-1) × [D(n-1) + D(n-2)]` 种。
